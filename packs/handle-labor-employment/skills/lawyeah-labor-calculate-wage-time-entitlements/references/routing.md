# 边界与路由

## 正触发

明确单方立场、特定劳动者、地区、期间和工资／工时／休假项目，需要可复核测算或受限情景工作表。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 企业总体抽样、风险与整改 | 薪酬工时休假审计 | 不做总体外推或控制审计 |
| 离职补偿赔偿和结算 | 离职款项测算 | 不扩张退出项目 |
| 工伤待遇 | 工伤待遇计算 | 不混入工伤项目 |
| 退出路径合法性 | 对应退出评估 | 不推荐行动路径 |
| 请求抗辩、时效和程序 | 劳动争议评估 | 不代做总体争议成果 |
| 发薪记账或税务申报 | 对应财税操作 | 不执行支付申报 |

## 易混场景

单位委托测算一名员工也可正触发，但只能服务单位单方，不同时替劳动者优化。多人逐个请求但没有企业总体审计目标时可分对象运行；有总体、抽样、风险和整改目标时路由审计。关键参数缺失并不必然整体拒绝，已确认行继续、受影响金额形成情景或无法估计。
