# 关系识别方法

## 一般顺序

1. 按主体和时间区间核验法定主体资格；
2. 确定书面劳动合同是否真实、有效及覆盖本期间；
3. 对非劳动合同标签和无书面劳动合同场景核对实际履行；
4. 建立多个候选解释，不以用户使用的关系名称作为结论；
5. 为每个候选解释分别列支持、相反事实和仍缺信息。

## 六组履行事实

| 事实组 | 支持劳动管理或组织依附的观察 | 支持独立经营或成果交付的观察 |
| --- | --- | --- |
| 招聘与退出 | 组织决定录用、调岗、停工、退回或解除 | 自主选择交易对象并自行终止项目 |
| 人格与劳动管理 | 固定排班、考勤、请假审批、指令、考核、奖惩、退出控制 | 可拒单、自主安排时间、不受劳动纪律约束 |
| 经济结构 | 固定或周期报酬、价格由组织决定、主要依赖单一主体 | 自主定价、多客户经营、按成果结算、自担盈亏 |
| 组织归属 | 纳入岗位、班组或核心流程，持续提供本人劳动 | 自行组织人员、可替代履行、只验收成果 |
| 工具与风险 | 组织提供关键工具场所并承担主要经营风险 | 自备关键生产资料并承担成本、价格和履约风险 |
| 文件与外观 | 劳动合同、工资社保、工牌、规则和招聘记录一致指向主体 | 文件互相冲突或与实际履行冲突，需分别编号 |

业务属于组织的组成部分只是观察之一。业务质量控制、平台必要运营管理、现场安全要求或成果验收，均不单独等于支配性劳动管理。

## 派遣与外包

劳务派遣区分派遣单位的用人单位角色和用工单位的实际使用、管理及法定义务。外包标题下由发包方直接管理人员时，把“以外包名义实际按派遣形式用工”列为候选，但继续核查：

- 谁组织、替换和调度人员；
- 谁承担过程管理与交付责任；
- 对价按人员、工时还是成果计算；
- 谁承担质量、成本和经营风险；
- 发包方是直接劳动指挥还是只做成果、安全和质量管理；
- 派遣许可和完整业务协议。

缺少派遣许可本身不自动改变劳动关系主体。真正外包通常由承包方独立组织人员和过程，发包方主要验收成果。

## 关联单位交替或同时用工

先核验书面劳动合同的真实性、有效性、主体和覆盖期间。

- 已订立书面劳动合同且劳动者请求按合同确认劳动关系时，按该专门规则处理；实际履行冲突用于核对合同真实性、覆盖期间和其他单位的具体责任，不得一般化越过书面合同。
- 未订立书面劳动合同时，根据劳动者主张，按主体和时间区间综合管理、工作时间、工作内容、劳动报酬和社保确定关系主体。
- 无书面合同场景中的共同工资、福利责任不等于共同劳动关系，并需核对劳动者是否同意合法的责任安排。
- 相同法定代表人或股东只说明关联线索，不自动否认各单位的独立主体地位。

## 平台及合作用工

分别核对平台和合作企业的：

- 招聘和账号准入；
- 算法、规则、接单和退出控制；
- 时间、工作量和多平台经营自主；
- 订单价格、报酬决定和客户归属；
- 考核处罚、替代履行和实际管理；
- 报酬来源及站点、合作商与平台的业务链。

不能因使用平台 App 或平台设置必要运营规则就自动认定平台为用人单位，也不能因存在合作商就自动排除平台的实际角色。

## 违法转包、分包和挂靠

只在法定条件完整时识别特定用工主体责任：

- 适格承包人将承包业务转包或分包给不具备合法经营资格的组织或个人，并由后者招用劳动者；
- 不具备合法经营资格的组织或个人挂靠适格单位，并由其招用劳动者。

其他普通转包或分包不得直接套用。分别填写：

1. 劳动者与适格承包人或被挂靠单位是否存在劳动关系；
2. 劳动报酬支付责任主体；
3. 工伤保险责任承担单位候选；
4. 是否已有工伤认定等前置决定。

尚无工伤认定时，不得写成已经构成工伤或已经产生待遇支付责任。
