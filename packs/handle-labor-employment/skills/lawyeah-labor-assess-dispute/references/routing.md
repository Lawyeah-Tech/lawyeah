# 边界与路由

## 正触发

争议已发生，明确单方需要总体决定请求／抗辩、程序、证据和下一步，或在阶段转换前重评。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 仅关系与责任主体 | 关系识别 | 不扩张总体争议 |
| 个体工资工时休假精算 | 对应测算 | 不做详细工作表 |
| 离职或工伤精算 | 对应专项测算 | 不吞并金额成果 |
| 完整证据建案 | 证据任务 | 不生成全量卷宗 |
| 已决定谈判和解 | 和解任务 | 不代写协议 |
| 已决定仲裁申请／答辩／起诉 | 对应程序任务 | 不写可提交文书 |
| 生效文书执行 | 执行任务 | 不代做执行申请 |
| 在职未形成具体争议的全面诊断 | 在职权利／企业审计 | 不制造请求 |

## 易混场景

请求已经基本清楚但仍需比较是否提出、如何分流或哪些证据优先时正触发；请求、金额、主体和管辖均确认且只要申请书时负触发。社保、工伤和商业秘密事项可进入总体矩阵，但各自行政／专业入口必须分开。双边材料不等于可以同时代理双方，必须明确单方和材料权限。
