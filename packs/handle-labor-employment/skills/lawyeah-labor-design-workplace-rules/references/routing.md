# 边界与路由

## 正触发

单位侧目标是新建、修订、审查或如实补强劳动规章制度，并希望把文本、职工参与、公示覆盖、版本和实施证据作为一个统一成果。锁版正文或已完成的真实程序材料可作为等价输入。

## 负触发

| 主要目标 | 路由方向 | 本任务停止内容 |
| --- | --- | --- |
| 单个员工事实调查 | 工作场所调查 | 不作个案事实认定或处分建议 |
| 已选定路径的处分／解除实施 | 单位解除终止实施 | 不写通知、送达或结算包 |
| 比较个体退出路径 | 单位个体退出评估 | 不推荐解除理由或成本路径 |
| 争议中制度效力与请求抗辩 | 劳动争议评估 | 不代做争议意见或程序文书 |
| 集体合同谈判 | 对应集体协商任务 | 不代表任何一方谈判 |
| 只组织一次职代会 | 职工代表程序任务 | 不把会议组织冒充制度成果 |
| 完整隐私或数据合规评估 | 对应数据合规任务 | 只保留制度条款接口 |

## 易混场景

已有制度只缺程序仍正触发；目标是让制度在未来真实实施，不以补造历史为手段。已有制度被用于某个员工处分且用户只要决定或通知时负触发。集团统一政策仍按各用人单位、地点、人员和版本分别核验。公示或签收不完整时仍可形成部分成果和补正计划，但不得写已经全员生效。

仅有既有手册、程序和版本材料缺失，用户要求确认其“现在有效并可处罚所有员工”时，先纠正保证性目标但仍正触发制度审查与修订；只有已指定具体员工、具体既往行为或既有争议的效力判断才负触发。
