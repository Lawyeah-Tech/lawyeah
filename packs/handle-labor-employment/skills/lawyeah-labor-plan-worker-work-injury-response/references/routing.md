# 边界与路由

## 正触发

职工侧事故或职业暴露已经发生，主要目标仍是初期医疗、主体、角色、期限、证据和治疗保障；申请已提交或受理不自动结束。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 可提交认定申请包 | 职工工伤申请 | 不制作正式申请材料 |
| 医学、职业病或伤残结论 | 医疗／鉴定 | 不代作专业结论 |
| 劳动能力鉴定 | 鉴定准备 | 不吞并鉴定阶段 |
| 工伤待遇金额 | 待遇测算 | 不代算项目金额 |
| 认定决定后的行政救济 | 工伤行政挑战 | 不写复议诉讼文书 |
| 第三人侵权赔偿文书 | 侵权任务 | 只保留竞合接口 |
| 单位事故响应 | 单位工伤响应 | 不同时服务对立方 |

## 易混场景

补正通知不是不予受理；收件条不是受理文书；申请提交后医疗和证据行动继续。上下班交通、职业病、第三人和多主体事故均可正触发，但只形成条件分支。关系主体不明时不强制先运行另一 Skill，当前方案直接列主体候选和最小关系证据。
