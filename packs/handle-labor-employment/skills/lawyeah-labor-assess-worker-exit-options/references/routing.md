# 边界与路由

## 正触发

劳动者在若干退出或回应行动间选择，或已收到退出信号但仍需状态、证据、通知、权益和时序方案。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 单位设计解除终止 | 单位退出评估／实施 | 不服务对立方 |
| 只需离职精确金额 | 离职款项测算 | 不代算终值 |
| 已确认请求的仲裁申请 | 仲裁申请 | 不写可提交申请 |
| 只审查离职协议红线 | 协议审查 | 不吞并独立审查成果 |
| 争议请求抗辩和程序总体决策 | 劳动争议评估 | 不代做争议矩阵 |

## 易混场景

已停工、通知到达或协议签署后，如主要目标变成后果、请求和程序则路由争议；仍需决定如何澄清、继续履行或谈判时可正触发，但必须按真实状态。工资社保问题可作为退出理由候选和权益接口，不因存在这些问题自动转争议。人身危险不等待完整路径比较。
