# 边界与路由

## 正触发

单位已唯一选择一个劳动者的单方解除或法定终止路径，通知尚未执行，需要完整实施材料或停止复核。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 比较保留、改善、协商和单方路径 | 单位退出评估 | 不选路径 |
| 协商解除谈判和协议 | 协商解除 | 不把协商写成单方通知 |
| 劳动者辞职或应对 | 劳动者退出评估 | 不服务对立方 |
| 多人减员或经济性裁员 | 批量减员 | 不逐人镜像规避 |
| 通知已发后的撤回、补救或应诉 | 劳动争议／对应程序 | 不事后扩张理由 |
| 只需精确离职款项 | 离职款项测算 | 不吞并独立测算 |

## 易混场景

既定路径前提不成立时，本任务可以给停止和退回决策建议，但不能在同一实施包静默换成另一理由。事实尚未调查且没有决定性证据时不能因“已选路径”直接写通知。已发生停工停薪、关权限或系统离职时如实登记并优先止损，不写一切未开始。
