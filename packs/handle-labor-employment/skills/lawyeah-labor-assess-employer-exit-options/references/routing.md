# 边界与路由

## 正触发

单位侧针对一个劳动者、在不可逆决定前比较保留、改善、协商、解除或终止路径。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 已选路径的通知、工会、送达、结算 | 单位解除终止实施 | 不写通知或执行包 |
| 已选协商解除的谈判协议 | 协商解除 | 不代拟完整协议 |
| 劳动者辞职或被解除应对 | 劳动者退出评估 | 不同时服务对立方 |
| 多人减员、组织重组、经济性裁员 | 批量减员 | 不逐人镜像规避群体程序 |
| 争议请求、抗辩或程序 | 劳动争议评估 | 不生成争议成果 |
| 医学、鉴定和技术结论 | 对应专业路径 | 不冒充专业结论 |

## 易混场景

路径已选但发现关键前提缺失，若主要目标仍是比较是否改选可回到本任务；若仍坚持执行则负触发并停止实施。已经停工停薪或关权限时先如实记录，不按未行动评估。多人使用相同理由且由同一组织调整驱动时，先筛查批量减员，不机械拆成个体案。
