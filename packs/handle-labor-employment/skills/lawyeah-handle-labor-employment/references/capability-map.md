# 当前能力地图

| 用户当前目标 | 原子 Skill | 独立成果 | 不包含 |
| --- | --- | --- | --- |
| 判断已经发生的用工属于什么关系、谁可能承担用工责任 | `lawyeah-labor-identify-employment-relationship` | 主体关系图和责任主体识别意见 | 金额测算、仲裁诉讼方案、工伤认定结论 |
| 为实际用工起草劳动合同 | `lawyeah-labor-draft-employment-contract` | 劳动合同定稿及必需附件 | 一般商业合同、已签合同争议评估 |
| 建立或修订劳动规章制度 | `lawyeah-labor-design-workplace-rules` | 制度文本及民主、公示、实施包 | 个案处分决定、综合企业合规体系 |
| 审查单位工资、工时和休假合规 | `lawyeah-labor-audit-pay-time-leave` | 专项审计表、差额和补救方案 | 单个劳动者最终权益主张、离职补偿测算 |
| 测算个人工资、工时和休假权益 | `lawyeah-labor-calculate-wage-time-entitlements` | 可复核测算表和参数缺口 | 离职补偿、工伤待遇或诉讼请求整体设计 |
| 单位在个体退出前比较路径 | `lawyeah-labor-assess-employer-exit-options` | 路径、成本、证据缺口和停止条件矩阵 | 正式实施解除终止 |
| 劳动者评估辞职、被迫离职或协商退出 | `lawyeah-labor-assess-worker-exit-options` | 行动、通知、证据、权益和谈判方案 | 仲裁申请、完整金额测算 |
| 单位已经决定解除或终止并需执行 | `lawyeah-labor-implement-employer-termination` | 通知、工会、送达、结算和证据实施包 | 是否应当解除的前置方案比较 |
| 职工发生疑似工伤后的初期行动 | `lawyeah-labor-plan-worker-work-injury-response` | 期限、证据、通知和保障行动方案 | 工伤认定结论、鉴定或待遇测算 |
| 在仲裁、诉讼或和解前形成争议全貌 | `lawyeah-labor-assess-dispute` | 请求抗辩、程序、金额区间和关键缺口矩阵 | 立案文书、庭审代理或执行材料 |

路线图中的其他能力尚未进入当前安装候选包。不得因为能力名称存在于规划中就声称其可调用。
