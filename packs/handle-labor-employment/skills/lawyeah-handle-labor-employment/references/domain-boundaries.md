# 劳动领域边界

本表只说明领域归属，不代表相应劳动法能力已经安装。每次路由先核对 [当前能力地图](capability-map.md)；“当前候选包入口”写明未安装时，输出 `unavailable`，不得用邻近 Skill 代替。

| 相邻领域 | 当前候选包入口 | 尚未安装的劳动法侧成果 | 转交相邻领域的独立成果 |
| --- | --- | --- | --- |
| 合同 | `lawyeah-labor-draft-employment-contract` 仅处理劳动合同 | 其他用工专项协议审查与起草 | 一般商业外包、采购及其他商事合同 |
| 人身损害 | `lawyeah-labor-plan-worker-work-injury-response` 仅处理职工工伤初期行动 | 工伤认定申请与应对、劳动能力鉴定、工伤待遇测算和请求 | 第三人侵权责任及侵权损害赔偿 |
| 知识产权 | 未安装 | 竞业限制及劳动关系内保密安排 | 商业秘密权利基础、侵权和损失 |
| 数据隐私 | 未安装 | 员工监控、信息使用的劳动程序与劳动法后果 | 个人信息合法性、影响评估、跨境和安全专项 |
| 企业合规 | `lawyeah-labor-design-workplace-rules` 仅处理劳动规章制度 | 工作场所申诉、专项调查和纪律处分 | 企业级舞弊、反商业贿赂和综合整改 |
| 行政争议 | 工伤初期行动和争议总体评估仅按各自范围使用 | 工伤、社保、劳动监察的行政办理与专项证据成果 | 行政复议、行政诉讼的通用代理成果 |
| 投资并购 | 未安装 | 劳动尽调、员工转移和安置 | 交易结构、交割和项目统筹 |
| 破产 | 未安装 | 职工安置、劳动合同终止和待遇测算 | 职工债权申报、确认和破产分配 |
| 公司治理 | 未安装 | 高管劳动身份和员工激励的劳动后果 | 公司职务、股权和股东权利 |
| 税务 | 未安装 | 薪酬和激励安排的劳动权利与用工后果 | 税负、申报和税务争议 |
| 涉外 | `lawyeah-labor-identify-employment-relationship` 仅作中国大陆关系与责任主体受限识别 | 外国人在华用工专项意见、许可和完整权益安排 | 境外当地劳动法和跨法域准入监管 |
| 刑事 | 未安装 | 员工违法事项的劳动调查、处分和用工后果 | 刑事控告、辩护和刑事责任 |
| 建设工程 | 关系识别、个人权益测算或工伤初期行动仅按各自范围使用 | 农民工工资专项治理、单位工伤协调等未安装成果 | 工程合同、工程价款和施工责任 |

职业危害技术评价、安全生产工程结论和医学诊断需要有资质的专业机构完成。其劳动法后果也必须先核对当前能力地图；没有已安装入口时输出 `unavailable`。
