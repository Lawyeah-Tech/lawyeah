# 劳动用工与劳动争议能力导航

## 定位

说明本包的能力、边界和原子 Skill 全貌，并根据用户当前主要目标与预期成果定位入口。具体法律任务可以直接使用相应原子 Skill，无须先经过本 Guide。

本 Guide 不完成关系识别、合同起草、审计、测算、退出实施、工伤行动或争议评估，也不建立固定组合方案。

## 选择方法

读取 [选择方法](references/selection-method.md)，按“用户目标 + 独立专业成果 + 当前立场与阶段”选择一个主要原子 Skill。只有某项任务确实需要另一项已形成成果时，才按具体 Skill 声明的依赖处理；律师、机关、用户材料或其他来源提供的等价成果均可作为输入。

混合请求先列出各自可独立验收的成果和对应入口，再只问一个问题：用户这次要先取得哪一项成果。用户回答前不指定主要 Skill，也不暗示执行顺序；用户只询问是否必须按某顺序调用时，先明确回答“不必须”，再询问当前要启动哪一项。

## 当前原子能力

读取 [能力地图](references/capability-map.md) 查找本候选包已包含的 10 个 P0 原子 Skill。只推荐实际安装在本包中的 Skill，不声称路线图中的未发布能力已经可用。

## 领域边界

读取 [领域边界](references/domain-boundaries.md) 处理合同、人身损害、知识产权、数据隐私、企业合规、行政争议、并购、破产、公司治理、税务、涉外、刑事和建设工程等相邻成果。

当劳动专项成果与相邻领域成果同时存在时，将它们拆成各自独立任务；不要在劳动 Skill 内补造相邻领域结论。

## MCP 边界

当前候选包尚未承诺可用的运行时 Lawyeah MCP 契约，导航完全不依赖 MCP。若未来某个原子 Skill 明确声明可选工具，再按该 Skill 的具体业务节点和不可用行为处理；本 Guide 不代替它决定调用。

不得声称 MCP 已连接，不要求用户提供密钥或令牌，也不得因工具未注册、不可用或无结果推断没有法律依据。

## 输出

单一成果请求只输出：当前目标与成果、推荐的已安装原子 Skill、选择理由与排除项，以及启动所需的最小输入。

混合请求且用户尚未明确本次优先成果时，只输出：独立成果与入口清单、各自边界，以及“这次先取得哪一项成果”的一个问题；此时不指定主要 Skill，不规定固定执行顺序。
