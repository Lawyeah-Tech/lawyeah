# 不予立案或逾期未立案救济

## 任务与边界

针对公安机关不予立案或受案后逾期未作立案决定，按受案状态选择复议复核或检察立案监督材料。

仅服务于单一用户目标和独立成果：受案/不予立案/逾期状态文书表；送达日与期限核验表；复议复核或立案监督路径意见；材料、提交和留痕清单。不替代接案资格筛查，不扩展为完整案件代理，不承诺机关决定或裁判结果。`dependsOn: []`。

## 不处理范围

- 已立案后的撤案监督
- 初次刑事控告

## 最小输入

- 报案/控告主体与授权
- 受案回执、不予立案通知或逾期事实
- 送达日和已采取的救济
- 涉案事实与证据线索
- 公安机关和检察机关信息
- 适用法域、当前日期和时区、适用法律版本或待核验状态
- 主体身份（犯罪嫌疑人、被告人、被害人、证人或第三人）、年龄及未成年人/身心障碍/语言等特殊状态
- 诉讼阶段、措施类型、承办机关、关键文书、采取/送达时间及其原件或可回链副本
- 委托与授权证明、利益冲突筛查状态、允许采取的动作范围
- 仅收集完成本成果所需的最小个人信息；第三方信息脱敏，无法安全处理时停止

## 适用前置与安全分流

1. 未授权 A0 阶段仅允许不含案件事实的通用安全三分流、停止原因和最小非案件问题；先验证当前用户身份/关系及授权证明的可回链状态，验证前不确认人员是否被传唤、拘留、搜查或失联及其程序状态。身份或授权无法验证时停止并提示由本人、已核验的法定代理人或合格律师重新发起。
2. 完成身份/关系/授权门禁后进入授权后 A 阶段，再做安全三分流（即时危险/医疗或失踪风险/无即时危险），再询问最小缺失信息；前一阶段不收集完整卷宗、无关身份或第三方秘密。
3. A 阶段只收集安全风险、最小身份和程序状态，固定输出安全状态、停止/升级原因和下一步最小问题；B 阶段在 A 通过后才收集可回链文书、法域、日期和授权，固定输出缺失/冲突字段、文书回链状态、授权/冲突状态和进入 C 阶段门槛；C 阶段仅在 B 通过且法源工具返回逐项引文后输出条件性成果。每次阶段转换前要求用户确认，禁止复制不必要的原文。
4. 法域、阶段、主体、机关、措施、官方案由、日期或适用规则缺失/冲突时，不输出确定的权利、期限、机关或法律结论，只输出待核验事项。
5. 出现即时人身危险、医疗急症、自伤风险、疑似非法限制自由、失踪或脆弱人员风险时，先提示联系当地紧急服务、医疗机构或合格律师；仅在确认安全、必要且获适格授权时联系家属，不得把失联推定为刑事措施。
6. 仅在授权和冲突边界闭合后生成本成果范围内的条件性草案、核验表或路径意见；不得代提交、联系机关、冒充用户/律师，完整实体辩护或相邻救济文书一律停止。
7. 任何法律结论必须逐项绑定法域、法源名称/版本或生效日、条文引文、适用前提、核验时间、相反材料和条件性结论；法源工具无结果时停止。

## 执行方法

1. 先区分未受案、已受案未决定、不予立案、已立案后撤案四种状态
2. 核验文书、送达日、法定期限、复议复核层级和检察立案监督入口
3. 逐项整理原控告事实、补充材料、机关理由和反向证据
4. 选择复议、复核、立案监督或补充材料路径，避免重复初次控告
5. 形成可提交材料和期限留痕，不承诺立案或监督结果

## 阶段与主体门禁

- 主体角色只从：犯罪嫌疑人、被告人、被害人、控告人、自诉人、证人、第三人、近亲属、保证人、法定代理人、辩护人、诉讼代理人、机关工作人员中选择，并记录关系和权限；不明则停止。
- 程序状态只从：未受案、已受案未决定、立案侦查、审查起诉、审判中、判决/裁定后未生效—上诉准备期、上诉中、决定后救济中选择；记录具体审级、当前节点、状态变更事件和文书依据，禁止跨状态合并期限或动作。
- 只有当本成果目标明确要求实体定性时，才把官方案由/罪名作为待核验问题映射；其他成果仅核验影响本阶段动作的程序前提，禁止形成犯罪成立、实体抗辩或完整罪名意见。
- 任何代理、申请或提交成果均须记录申请主体资格、授权范围、受理机关、提交方式和“不代提交、不联系机关、不冒充用户或律师”的外部动作边界。
- `search_law` 仅接受指定法域内可回链的官方或批准标准法源；必须返回规范名称、发布机关、版本/生效日、逐项原文引文、适用前提、检索时间和来源标识。实践、模板、类案或权威性不明的结果不满足法源门禁，法律字段停止。
- 含法律规则、期限、机关路径、申请或权利处置的 C 阶段成果必须标记 `humanReviewRequired: true`；合格刑事法律专业人员确认前只能输出草案、核验表、缺口和停止事项，不得作为最终意见、提交文件或外部行动依据。
- 真正未受案、拒绝接收初次控告、无受案记录或仅属初次刑事控告时必须停止，不选择复议/复核/立案监督；仅有可回链受案记录或正式不予立案文书时进入 B/C。


## 高风险停止

- 受案状态、文书或送达日无法证明
- 已立案却误用不予立案救济
- 要求伪造受案材料、重复骚扰机关或威胁办案人员
- 把复议复核与检察监督层级混为一谈
- 法域、阶段、主体、机关、文书日期或授权缺失且会改变结论
- 工具不可用、法源冲突或无法获得逐项引文
- 任何即时安全风险未先完成合法紧急升级


## 输出

1. 受案/不予立案/逾期状态文书表
2. 送达日与期限核验表
3. 复议复核或立案监督路径意见
4. 材料、提交和留痕清单

输出必须逐字段保留材料来源、核验状态、反向材料和限制；采用三阶段渐进披露：A 安全与最小身份/状态，B 文书/授权/法域核验，C 法源核验后的条件性成果；未通过前一阶段不得展开下一阶段或复制敏感材料。每次阶段转换必须记录明确肯定回复、时间、会话标识和披露范围；没有可审计确认时停留在当前阶段。关键事实缺失或冲突时只交付停止形状，不补造事实。法源工具不可用、无结果或冲突时不得进入/交付 C 阶段，只能输出停止形状、已核验的非法律事实索引和最小补充事项，不得生成法律结论、期限、机关路径、申请或质证建议。
