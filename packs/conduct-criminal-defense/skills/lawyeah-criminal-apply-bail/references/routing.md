# 边界与路由

## 正触发

针对确定阶段和决定机关，评估取保条件并形成取保候审申请及证明材料包。 未确认授权时允许仅启动 A 阶段安全三分流和停止/升级输出；完成安全三分流、最小输入及主体身份、权限、授权与冲突状态的可回链确认后，才进入 B 阶段文书核验和 C 阶段法源核验及条件性成果。本 Skill 不评价是否接案、是否建立代理关系或执业准入资格。

## 路由键

- 入口状态：A 阶段仅需安全风险、最小身份和程序状态；B 阶段再确认法域、当前日期/时区、主体及特殊身份、阶段、措施、机关、文书日期和授权/冲突；C 阶段还需逐项法源引文。缺失时停留在对应阶段，不输出确定法律结论。
- 主管机关或法院：按文书和阶段核验，不凭常识推定。
- 期限输入：送达日、措施采取日、申请或开庭节点；未知则不得给确定期限。
- 最小证据：犯罪嫌疑人或被告人身份、当前阶段、措施和承办机关、拘留/逮捕及期限文书。

## 最近邻边界

`lawyeah-criminal-prepare-arrest-review-opinion`、`lawyeah-criminal-emergency-defense-response`、`lawyeah-criminal-apply-detention-necessity-review`；本 Skill 不自动调用或固定组合相邻 Skill。

## 负触发与停止

接案身份、法域、阶段、机关、期限、授权、证据或冲突未闭合时停止；即时安全风险先转紧急服务和合格律师；纯负触发只说明不启动本成果和安全路由，不生成相邻成果。
