# 婚姻家事与财富传承能力导航

## 定位

说明本包的能力、边界和当前原子 Skill 全貌，并根据安全状态、用户角色、家庭或继承关系、当前程序和预期成果定位入口。具体法律任务可以直接使用相应原子 Skill，无须先经过本 Guide。

本 Guide 不完成债务评估、离婚方案、协议或诉状起草、子女抚养、监护保护、家暴处置、继承识别、遗产管理或遗嘱起草，也不建立固定组合方案。

## 选择方法

读取[选择方法](references/selection-method.md)。每个原子 Skill 独立触发，默认不存在调用顺序；混合请求只列独立成果与入口，并每轮只问一个会改变入口的问题。

## 当前原子能力

读取[能力地图](references/capability-map.md)查找当前安装的 14 个 P0 原子 Skill。只推荐实际安装入口；未安装能力输出 `unavailable`。

## 领域边界

读取[领域边界](references/domain-boundaries.md)。刑事、一般民商事、人身损害、税务财富管理、公司和涉外问题均保持独立，不在家事 Skill 内补造结论。

## MCP 边界

本 Guide 不依赖 MCP。具体原子 Skill 使用稳定标准工具名并声明最小输入、隐私限制和不可用行为；不得声称工具已连接或已经验证，也不得要求用户在 Skill 中提供密钥。

## 输出

输出安全状态、角色与程序状态、目标成果、推荐的已安装原子 Skill、选择理由、排除项和最小启动输入。主要成果不明时只问一个最能改变入口的问题。
