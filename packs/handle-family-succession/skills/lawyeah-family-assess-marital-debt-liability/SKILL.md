# 夫妻债务责任评估

## 任务与边界

针对特定债务形成共同债务、个人债务、内部承担与外部债权人效力的受限意见。

仅处理已经识别的逐笔债务，交付逐债务责任表和抗辩与证据方案。不只按借款人姓名判断责任，不代替全面资产负债盘点、整体夫妻财产分割、公司责任、担保、执行或破产专项意见，不承诺裁判结果。`dependsOn: []`。

## 最小输入

- 每笔债务的债权人、名义债务人、形成日期、金额、币种、利息、期限和当前状态
- 合同、借据、转账交付、还款、催收、诉讼或执行材料的可回链位置
- 婚姻关系起止、分居或离婚状态，以及债务形成时的家庭经济状态
- 共同签名、追认、授权、知情、参与、受益和相反表示材料
- 资金进入账户、实际用途、共同生活或生产经营的流向材料
- 夫妻财产约定、离婚协议、内部清偿和债权人是否知悉的材料
- 用户身份类别、代表主体、授权依据或未核验状态、信息披露范围、利益冲突状态
- 主张主体与代理立场、适用法域、当前日期、案件机关、案号或无案号状态、程序阶段、送达或期限材料
- 只提供完成本成果所需的去标识化摘要；完整文书和第三人个人信息不得无目的上传工具

## 适用前置

1. 先确认用户站在债权人、举债配偶或非举债配偶哪一立场，并记录用户身份、代表主体、授权依据、信息披露范围和利益冲突。身份或权限未核验时，只输出通用事实清单、停止原因和最小补充事项，不输出针对第三人的个案责任结论或敏感材料摘要；立场冲突时分别列出主张，不替用户选边。
2. 逐笔建立债务编号。无法区分具体债务、金额或交易主体时，不输出总括性“全部共同／全部个人”结论。
3. 债务真实性、共同债务性质和夫妻内部承担是三个不同问题。前一层未闭合，不用后一层结论补足。
4. 法域、规则版本或会改变结论的法源引文缺失时，只保留事实证据矩阵、待核验问题和停止输出；不得给确定法律结论、机关路径、截止日或胜诉概率。
5. 发现虚构债务、事后补造、串通诉讼、赌博吸毒等违法活动或隐匿不利材料请求时，拒绝协助并保留合法证据保护建议。

## 执行方法

1. 核验债务真实存在：合同主体、交付、金额、利息、偿还、交易背景和异常关系逐项回链。
2. 检验共同意思表示：共同签名、事后追认、授权、共同决策或其他可验证表示分别记录；婚姻关系本身不替代这些事实。
3. 检验家庭日常生活：结合金额、收入财产、支出性质、频率和实际用途，同时记录非家庭用途反证。
4. 对超出家庭日常生活的一方个人名义债务，检验共同生活、共同生产经营或共同意思表示及相应证明责任，不把参与、受益或经营关系机械推定。
5. 先形成对外债权关系的条件性结论，再单独处理夫妻内部承担、协议和追偿；内部约定不得当然对抗第三人。
6. 对每项结论写出最强反向材料、证据缺口、法源状态和会改变结论的待核验事实。

具体判断字段读取[执行方法](references/method.md)，最近邻和停止路由读取[边界与路由](references/routing.md)，交付结构读取[输出合同](references/output-contract.md)。

## 高风险停止

- 债务主体、真实性、金额或交付事实无法最低限度核验
- 只有借条、一方自认或婚姻关系，要求直接认定共同债务
- 资金用途、共同意思表示或共同生产经营材料冲突且会改变结论
- 要求虚构、补造、隐匿债务或协助虚假诉讼
- 要求把违法活动债务包装为家庭债务
- 法源工具不可用、无结果、版本冲突或不能取得逐项可回链引文
- 要求代替公司、担保、执行、破产、刑事或税务专项判断

## 输出

1. 逐债务事实与真实性表
2. 对外责任与证明责任矩阵
3. 夫妻内部承担、协议与追偿表
4. 抗辩、证据缺口和合法补证方案
5. 不确定性、停止事项和相邻领域转介

所有法律结论采用“支持／不支持／冲突／待核验／停止”的条件性状态，逐项绑定事实来源、相反材料、适用前提、法域、规则版本或生效日、引文和核验时间。没有法源引文时，法律结论字段必须留空并使用停止输出。
