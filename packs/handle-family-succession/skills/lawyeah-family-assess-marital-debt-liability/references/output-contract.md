# 输出合同

## 逐债务固定字段

每笔债务必须包含：`debtId`、主张主体与立场、名义债权人／债务人、形成日期、金额利息期限、婚姻状态、真实性事实、共同意思表示、家庭日常生活、共同生活、共同生产经营、资金流和用途、已清偿情况、内部约定、第三人知情、支持材料、相反材料、证明责任、法源记录、对外责任状态、内部承担状态、限制和下一步。

事实记录包含材料名称、页码或记录标识、取得方式、日期、来源类别、核验状态和链条断点。法源记录包含 `jurisdiction`、`lawVersionOrEffectiveDate`、`citation`、`applicability`、`checkedAt`、`ruleStatus`。

## 正常输出

1. **逐债务事实与真实性表**：不把合同存在等同于款项交付或债务真实。
2. **对外责任与证明责任矩阵**：分别列共同意思表示、家庭日常生活、共同生活、共同生产经营及最强反向材料。
3. **内部承担、协议与追偿表**：与外部债权关系分层，明确第三人效力仍待何种事实和法源核验。
4. **抗辩与证据方案**：只列合法取得、保存、申请调取或核对事项，不指导窃取账户、冒充或隐匿材料。
5. **不确定性与转介**：公司、担保、执行、破产、刑事、税务等独立问题标记范围并停止实体结论。

所有成果固定包含 `scopeAndRole`、`identityAndAuthority`、`procedureState`、`factRows`、`ruleRows`、`counterMaterials`、`evidenceGaps`、`actionRows`、`deadlineRows`、`uncertainties`、`privacyRedactions`、`humanReviewRequired`。`identityAndAuthority` 记录用户身份、代表主体、授权依据、披露权限、利益冲突和核验状态。`procedureState` 记录机关、案号或无案号、程序类型、审级与阶段、当前节点、关键文书及送达凭证。

任何期限行必须单独记录机关、程序阶段、期间类别（实体请求权期间／诉讼程序期间／执行救济期间或其他）、启动事件及来源、起算日期和时区、期间口径、届满、延长补救、提交方式与回执；关键字段不明时不得计算截止日。每项程序行动必须记录法定入口、申请对象、受理主体、必要材料、提交方式、回执、适用法源和失败升级路径；关键字段缺失时不得指定程序路径。

## 停止输出

按“停止原因 → 成果状态：因停止条件未形成 → 已核实的非法律事实索引 → 最小补充事项 → 安全转介”输出。法源工具不可用时不得填写对外责任、内部承担、确定期限、机关路径或胜诉概率。

## 人工复核

任何可能用于谈判、诉讼、清偿、追偿或资产处分的成果均标记 `humanReviewRequired: true`。合格中国大陆法律专业人员复核前只能作为核验表和条件性草案，不得直接提交或实施。
