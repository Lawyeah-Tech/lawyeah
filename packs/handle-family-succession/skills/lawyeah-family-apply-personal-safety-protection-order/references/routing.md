# 边界与路由

## 正触发

即时安全已得到初步保障，现需法院作出具体人身安全保护措施，目标是针对家庭暴力或现实危险形成管辖、请求措施、证据和紧急保护令申请材料。

## 入口键

- 入口状态：即时安全已得到初步保障，现需法院作出具体人身安全保护措施
- 最低证据：暴力或现实危险线索、主体管辖和拟请求措施
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录

## 最近邻边界

- `lawyeah-family-plan-domestic-violence-safety`：本 Skill 达到其入口时停止当前实体扩展并转介；不自动调用。
- `lawyeah-family-enforce-personal-safety-order`：本 Skill 达到其入口时停止当前实体扩展并转介；不自动调用。
- 最近邻排除：危险正在发生且首先需要撤离报警和即时救助。
- 本 Skill 独立发展，`dependsOn: []`；等价前置成果可以由用户、律师、机构或其他 Skill 提供。

## 跨领域停止

发现刑事、公司、担保、破产、执行、税务、行政、医疗或境外法等独立专业问题时，只记录其对本成果的影响、待核验事项和转介对象，不补造相邻领域结论。

## 负触发

- 把保护令申请附属于必须先离婚
- 仅在事实关系和法定适用范围核实后进入；普通同居财产分割转同居财产原子，刑事或人身侵权事项转相邻领域

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
