# 边界与路由

## 正触发

继承已开始且核心争议是继承资格、继承权或遗嘱遗赠效力，目标是围绕继承人资格、继承权、遗嘱或遗赠效力形成原告请求和起诉材料。

## 入口键

- 入口状态：继承已开始且核心争议是继承资格、继承权或遗嘱遗赠效力
- 最低证据：死亡、身份、继承依据和争议事实材料
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录

## 最近邻边界

- `lawyeah-family-respond-inheritance-status-action`：识别到用户核心目标符合该最近邻 Skill 的入口条件时停止相邻实体扩展并转介；不自动调用。
- `lawyeah-family-assess-will-validity`：仅在目标是独立的遗嘱效力评估且不要求原告起诉材料时转介；为当前原告起诉材料所必需的遗嘱遗赠效力争点在本 Skill 内处理。；不自动调用。
- `lawyeah-family-file-estate-division-action`：识别到用户核心目标符合该最近邻 Skill 的入口条件时停止相邻实体扩展并转介；不自动调用。
- 最近邻排除：身份和效力无争议，仅争遗产范围或分割。
- 本 Skill 独立发展，`dependsOn: []`；等价前置成果可以由用户、律师、机构或其他 Skill 提供。

- 仅当用户目标是独立的遗嘱效力评估且不要求原告起诉材料时，才转遗嘱效力评估；若用户为原告并要求就继承资格、继承权或遗嘱遗赠效力形成起诉材料，该效力仅作为本 Skill 内争点，不停止目标成果。

## 跨领域停止

发现刑事、公司、担保、破产、执行、税务、行政、医疗或境外法等独立专业问题时，只记录其对本成果的影响、待核验事项和转介对象，不补造相邻领域结论。

## 负触发

- 遗产范围和份额均明确后的单纯分割诉讼
- 为被告或相对方形成答辩材料

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
