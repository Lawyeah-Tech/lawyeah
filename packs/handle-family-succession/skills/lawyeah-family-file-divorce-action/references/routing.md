# 边界与路由

## 正触发

已确定诉讼立场、主要请求和拟受理法院，目标是围绕特定法院和原告请求形成离婚起诉、证据目录及程序申请材料。

## 入口键

- 入口状态：已确定诉讼立场、主要请求和拟受理法院
- 最低证据：身份婚姻材料、请求事实和基础证据
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录

## 跨领域停止

发现刑事、公司、担保、破产、执行、税务、行政、医疗或境外法等独立专业问题时，只记录其对本成果的影响、待核验事项和转介对象，不补造相邻领域结论。

## 负触发

- 未核准管辖和请求即代为提交
- 为被告或相对方形成答辩材料

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
