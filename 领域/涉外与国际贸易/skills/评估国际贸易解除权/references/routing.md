# 边界与路由

## 正触发

拟解除或已收到解除，需要判断约定、法定或 CISG 路径，本次主成果不是发通知。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 发送解除通知 | `准备国际贸易解除通知` |
| 仍要履行的催告 | `准备国际贸易催告或补救通知` |
| 解除后返还清理 | `处理解除后返还仓储与结算` |
| 质量终局不谈解除 | `评估国际货物交付质量数量` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 海事停租或撤船 | 海事领域 |
| 未成争改解除条款 | 审查起草领域（本窗搁置） |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

已发解除通知但无解除权，合同可能仍有效。宽限期未满不得提前解除。
