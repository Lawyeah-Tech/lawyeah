# 边界与路由

## 正触发

已判断需要申请许可，本次主成果是申请材料包而不是再评估能不能出。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 尚未判断要不要许可 | `评估出口管制与制裁风险` |
| 管制调查答复 | `应对出口管制问询或调查` |
| 军品无资质仍要组卷 | 停止 |
| 数据出境评估 | 数据领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 拆分出口或改名绕名单 | 整体停止 |
| 走私或无证出口刑事 | 刑事领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

有合同不等于可以先出后补证。最终用户是经销商时必须继续穿透。
