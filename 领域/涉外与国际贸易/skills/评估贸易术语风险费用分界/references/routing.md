# 边界与路由

## 正触发

双方对 FOB、CIF 等费用、保险或风险转移发生争执，本次主成果是分界评估。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 改术语出稿 | 审查起草领域（本窗搁置） |
| 运输合同滞期扣船 | 海事领域 |
| 货物质量主轴 | `评估国际货物交付质量数量` |
| 货权单据专项 | `评估货权与结汇单据` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 租船、提单运输、共同海损 | 海事领域 |
| 把术语当准据法 | 纠正：术语不是实体法 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

CIF 到港损坏不自动是卖方责任。合同专条“卸至买方仓库”可能已修改术语，必须并列。
