# 提起中国法院涉外民事诉讼

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的原告立场下，形成起诉状、管辖连结点和送达方案红旗；有效仲裁未排除不得写应起诉；C 端网上立案只分流。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：决定向中国法院起诉且无有效仲裁阻挡，本次主成果是涉外起诉包。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 有效仲裁协议未排除仍要求写应起诉；
- 用户实为被告；
- 海事专属或船舶扣押主轴；
- C 端网上立案操作；

有效仲裁未排除不得写应起诉。C 端网上立案只分流。不代提交，不保证受理。

## 建立评估坐标

确认：授权；原被告；书面仲裁协议是否存在；管辖连结点；请求；涉外因素；被告境外地址；已有案号则停止生成起诉入口。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 合同和主体材料；`A#` 已确认请求；`R#` 法院文书；`C#` 管辖或仲裁条款；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 诉讼请求；`P#` 起诉请求；`V#` 稿件版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。未知金额不写零。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民事诉讼法涉外管辖、仲裁协议独立性、专属管辖。`search_template` 只借起诉状栏目。工具或管辖规则不可用时继续事实和请求清单；应否起诉和管辖结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　仲裁与专项闸

有效仲裁未排除不得写应起诉。海事、被告、C 端转出。

### 节点 2　主体与涉外因素

港澳台不写成外国。无涉外可能转一般争议。

### 节点 3　管辖连结点

并列待核，不选定唯一法院。不方便法院不是原告起诉理由。

### 节点 4　分项请求

禁止合成全部权益。未通知不得写起诉日已解除。

### 节点 5　送达保全与草稿

境外送达只标红旗。不代提交。

## 停止与安全

- `整体停止`：有效仲裁未排除仍要应起诉终稿；伪造授权。
- `字段停止`：管辖条文、仲裁协议效力、送达规则未核验。
- `目标停止`：主目标变为仲裁申请、应诉或网上立案操作。

严格按 [输出合同](references/output-contract.md) 交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
