# 边界与路由

## 正触发

决定向中国法院起诉且无有效仲裁阻挡，本次主成果是涉外起诉包。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 仲裁协议未排除 | `评估涉外管辖与仲裁协议` |
| 被告应诉 | `应对中国法院涉外民事诉讼` |
| 提起仲裁 | `提起中国涉外仲裁` |
| 海事专属 | 海事领域 |
| C 端网上立案 | 大众专项，只分流 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动争议先裁 | 劳动领域 |
| 离婚等家事 | 家事领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

有仲裁条款仍要求直接起诉时，先完成论坛闸。协议管辖不明不得硬写某中院。
