# 边界与路由

## 正触发

货款、资本项或担保项下无法收付，需要外汇合规判断。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 税负或退税 | 税务领域 |
| 贸易融资单据独立性 | `评估贸易融资单据争议` |
| ODI 准入 | `评估境外投资监管准入` |
| 分拆假贸易 | 拒绝并停止 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 转让定价 | 税务领域 |
| 名单命中 | `筛查交易对手与最终用户` |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

银行拒办不等于外汇局已作出处罚。有出口报关不等于服务费可以按货款项下付出。
