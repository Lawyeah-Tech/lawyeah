# 边界与路由

## 正触发

单独判断外商投资是否属于安全审查申报范围及能否实施投资。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 负面清单总评 | `评估外商准入与安全审查` |
| 信息报告 | `准备外商投资信息报告材料` |
| 交割条件清单 | 投资并购领域 |
| 预测审查结果 | 拒绝预测 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 经营者集中申报 | 竞争法领域 |
| 数据出境安全评估 | 数据领域 |
| 先交割后补报 | 停止该部分 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

清单外国民待遇仍可能要安全审查。持股 30% 加否决权可能已构成控制。
