# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、路径、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然获批、必然解除、必然承认或唯一必得总额。

安全审查办法第四条两支不得混用：军工及周边不问控制权；重要领域须取得实际控制权。实际控制权包括持股 50% 以上、不足 50% 但有重大影响、以及其他对经营人事财务技术有重大影响，协议控制必须评估。

`search_law` 返回已失效《合同法》及其解释、法释〔1999〕19 号、法释〔2007〕14 号或已废外资备案办法时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜审查支线｜领域或控制权要素｜申报必要性｜支持事实｜不利事实｜判断｜待核`。

至少分列：

- `Q-军 国防安全支线`
- `Q-控 重要领域加控制权`
- `Q-报 申报义务`
- `Q-停 审查期间停止实施`
- `Q-特 一般或特别审查接口`

同一事实支持多项时分别说明效果，不重复金额。构成违约不等于当然解除。约定外法不等于可以无证出口或绕开准入。

## 节点 0　专项分流

| 信号 | 处置 |
| --- | --- |
| 只要负面清单 | 评估外商准入与安全审查 |
| 交割文件、对价 | 投资并购领域 |
| 经营者集中 | 竞争法；可与本审查并行 |
| 数据出境安全评估 | 数据领域 |
用户要求先交割后申报：该部分整体停止。

## 节点 1　投资者与交易方式

1. 外国投资者包括直接和可识别间接上层。上层不明：外国投资者定性 `依据不足`。
2. 投资方式：新设、并购股权或资产、其他方式。协议控制、表决权安排、收益权纳入其他方式待核，不得直接排除。
3. 增资、间接收购、托管、认缴未实缴但已获表决权：均列入评估。

## 节点 2　国防安全支线

1. 军工、军工配套、军事设施和军工设施周边地域：不问控制权。
2. 是否“周边地域”必须回链地理位置和官方口径，不得凭“不在园区里”排除。
3. 材料不足：`Q-军` `依据不足`，标红旗。

## 节点 3　重要领域与控制权

1. 重要农产品、能源资源、重大装备、重要基础设施、重要运输、重要文化、重要信息技术和互联网、重要金融服务、关键技术及其他重要领域：逐项对照实际业务。
2. 控制权三情形分列，不得只看股比。否决权、董事提名、IP 许可绑定、财务总监委派均可能构成重大影响。
3. 若：领域命中但控制权依据不足 → 不得写成“可以不报”。
4. 工作机制办公室有权要求申报：当事人自认明显不在范围仍可能被要求报，标红旗。

## 节点 4　程序与停止实施

1. 决定审查后一般审查期间自决定之日起 30 个工作日等规则须核验。特别审查另计。
2. 审查期间当事人不得实施投资，包括不得完成过户、支付主要对价或实际接管。
3. 不得预测通过或禁止。附条件可能：只标接口。
4. 未申报而实施：法律责任红旗，不提供补救伪装。

## 节点 5　下一步

1. 输出：两支范围判断或依据不足、控制权表、停止实施提示、申报材料接口。
2. 不写申报书终稿，不写交割清单冒充并购成果。
3. 反垄断集中审查并行提示。
