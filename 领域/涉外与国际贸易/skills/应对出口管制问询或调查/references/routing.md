# 边界与路由

## 正触发

商务或海关已问询、约谈或立案调查出口管制事项，本次主成果是应对方案。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 尚未被问询的管制评估 | `评估出口管制与制裁风险` |
| 海关处罚告知为主 | `应对海关稽查或行政处罚` |
| 刑辩主成果 | 刑事领域 |
| 隐匿或改单 | 拒绝并停止 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 走私立案 | 刑事领域 |
| 数据执法调查为主 | 数据领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

问询不是已经认定违法。超范围主动交代可能扩大调查，但也不得虚假否认已知事实。
