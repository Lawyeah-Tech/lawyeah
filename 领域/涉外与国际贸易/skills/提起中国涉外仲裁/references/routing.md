# 边界与路由

## 正触发

已决定向中国仲裁机构提起涉外仲裁，且有可回链书面仲裁协议。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 协议是否绊住诉讼尚未判断 | `评估涉外管辖与仲裁协议` |
| 应诉 | `应对中国涉外仲裁` |
| 向中国法院起诉 | `提起中国法院涉外民事诉讼`（未安装则 `unavailable`） |
| 承认外国裁决 | `申请承认和执行外国仲裁裁决` |
| 海事仲裁 | 海事领域 |
| 外国机构或境外临时仲裁为主成果 | 说明本包只做中国机构涉外仲裁，其余 `unavailable` |

## 专项整案转出

劳动争议仲裁 → 劳动。无涉外因素的国内仲裁可由本任务结构承接，但须标明非涉外规则可能不同，关键字段待核。

## 易混

有仲裁条款但机构不存在时负触发回论坛原子，不硬写申请包。
