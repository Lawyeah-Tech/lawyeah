# 提起中国涉外仲裁

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的申请人立场下，形成可复核、不代提交的中国涉外仲裁申请包：仲裁申请书草稿、分项请求、机构与规则版本、语言与仲裁地、证据目录和保全接口。

`depends-on` 为空。接受等价评估、测算和仲裁协议材料。

## 工作边界

正触发：用户已决定向中国仲裁机构提起涉外仲裁，且存在可回链的书面仲裁协议表面覆盖本案。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 仲裁协议表面不成立仍要求申请；
- 已决定向法院起诉；
- 用户实为被申请人；
- 海事仲裁；
- 境外临时仲裁或外国机构申请作为主成果。

不代提交，不保证受理或胜诉。

## 建立申请坐标

确认：授权；申请人与被申请人；仲裁协议文本；机构；请求；规则版本；语言；仲裁地；已有案号则停止生成申请入口。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或机构文书；`C#` 合同或仲裁协议；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求；`P#` 仲裁请求；`V#` 稿件版本；`E#` 送达凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验仲裁协议、涉外仲裁和保全接口；`search_template` 只借申请书栏目。机构规则以该机构现行文本为准，技能不得冒充已核验规则条文。

工具或规则不可用时继续事实和请求清单；可仲裁性、组庭和期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [申请方法](references/method.md) 为准。

### 1. 协议闸、机构和专项分流

无书面协议或海事专属则负触发。机构名称必须可确定。

### 2. 主体适格与分项请求

继续履行、付款、违约金、赔偿、确认解除分列。确认解除未事先通知的，不得写成申请当日已解除。

### 3. 规则、语言、仲裁地和准据法

规则版本未核验则期限和组庭字段停止。

### 4. 证据目录与保全接口

保全只做红旗和转介，不写法院保全申请终稿。

### 5. 申请书草稿与提交核验

只交付草案和核验清单，不代提交。

## 停止与安全

- `整体停止`：立场不明；伪造协议或授权。
- `字段停止`：规则、协议效力、期限未核验。
- `目标停止`：主目标变为起诉或应诉。
