# 涉外与国际贸易领域边界

当前安装包是（P0+P1）。本表只说明归属。每次路由先核对 [当前能力地图](capability-map.md)；P2 及未安装入口输出 `unavailable`。

| 相邻 | 本包入口 | 转出 |
| --- | --- | --- |
| 合同审查与起草 | 无。未成争只要改合同或出稿：本窗搁置，只说明不实施 | 审查起草领域（用户单独策略）；C 端外贸合同风险审查只分流 |
| 投资并购 | 跨法域准入、负面清单、安全审查、ODI 监管接口 | 股权对价、交割、目标尽调、境内重组交易文件 |
| 税务 | 贸易价款、信用证、外汇收付合规接口 | 转让定价、常设机构所得税、出口退税争议、税负测算 |
| 海事海商 | 买卖合同下的货权与结汇单据 | 海上运输合同、船舶、海事保险、海事保全、共同海损 |
| 劳动 | 境外当地劳动法及跨境派遣准入监管 | 外国人在华用工、中国大陆劳动关系与劳动权益 |
| 数据 | 作为管制物项的数据出口接口 | 数据出境安全评估、个人信息出境专项 |
| 知识产权 | 技术进出口监管接口 | 权属、侵权主轴、海关知识产权备案作为权利保护时 |
| 竞争法 | 无 | 经营者集中申报 |
| 行政 | 海关稽查、贸易管制调查的实体接口 | 一般行政复议诉讼方法 |
| 刑事 | 评估中的走私、逃避商检、无证出口只标红旗 | 定罪、控告、辩护 |
| 家事 | 无 | 涉外离婚、境外财产作为家事主轴 |
| 合同争议一般包 | 具有涉外或管制要素的国际贸易争议 | 无涉外要素的一般境内合同成争 |

一般货物或服务夹带专项背景时，专项段只分流，不把专项规则写入本包结论。
