# 原子 Skill 选择方法

## 一、先识别成果

先问这一次要拿到什么可独立验收的成果，而不是按国别、贸易术语或法条名称匹配：

- 跨境事项总图；
- 准据法、强制规范、作准文本、主体能力、港澳台区际；
- 管辖或仲裁协议判断、管辖异议；
- 出口管制与制裁、许可材料、调查应对、名单筛查、反制裁阻断、不可靠实体；
- 外商准入、安全审查、信息报告、ODI 评估与申报、返程与协议控制、跨境担保；
- 货物履行、术语分界、信用证、独立保函、服务贸易、检验期、价款汇率、不可抗力、货权单据、解除权、解除后清理、框架订单；
- 海关归类估价原产地、稽查处罚、进口许可法检、技术进出口；
- 贸易救济风险、应诉、申请、反规避；
- 外汇收付、贸易融资单据；
- 催告、解除通知、质量索赔通知；
- 金钱测算；
- 证据与认证案卷、域外送达、域外取证、货物与通信保全；
- 和解谈判与和解协议；
- 中国涉外仲裁申请或答辩、反请求评估；
- 中国法院涉外起诉或应诉；
- 承认执行外国裁决或判决、撤销或不予执行、保全两造；
- 境外用工当地准入。

调解或仲调对接、民商事司法协助申请终稿、刑民交叉专项属 P2，输出 `unavailable`。

## 二、再确认上下文

只确认会改变入口的最小信息：

1. 单方立场与授权；
2. 事项是交易准入、管制筛查还是已经成争；
3. 是否已有仲裁条款、起诉状、清单命中或机关文书；
4. 本次要分析、发函、测算、建卷、申报还是程序文书；
5. 是否属于境内并购交易主体、纯税务、海事、在华劳动或数据出境专项。

## 三、处理混合请求

1. 列出每项可独立验收的成果及对应入口；
2. 只问：`这次要先取得哪一项成果？`；
3. 回答前不指定主要 Skill，不暗示必须先评估再发函或先评估再申报；
4. 用户确认后只启动所选入口；等价评估、测算或证据可由用户或律师提供。

## 四、停止

立场冲突、专项主轴或未成争改合同时，说明边界并转出，不代做。信息不足时每轮只追问一个最能改变入口的问题。未安装能力输出 `unavailable`。
