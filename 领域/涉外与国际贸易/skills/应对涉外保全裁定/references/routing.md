# 边界与路由

## 正触发

财产或行为已被保全，需要复议或担保置换。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 申请保全 | `申请涉外或仲裁保全` |
| 违反裁定转财产 | 拒绝并停止 |
| 海事扣船应对 | 海事领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 转移被保全财产 | 整体停止 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

提供担保不等于自动解封。复议期间通常仍须遵守裁定。
