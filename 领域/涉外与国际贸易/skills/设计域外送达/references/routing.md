# 边界与路由

## 正触发

需向境外主体送达诉讼或仲裁文书，本次主成果是送达路径设计。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 伪造签收 | 拒绝并停止 |
| 港澳台送达 | `评估涉港澳台法域与文书` |
| 域外取证 | `规划域外取证与公证认证` |
| C 端网上立案 | 大众专项，只分流 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 向船舶送达或海事保全 | 海事领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

仲裁约定邮箱送达成功不等于诉讼已送达。海牙公约保留可能禁止邮寄。
