# 准备境外投资备案或核准材料

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的申报义务人立场下，形成境外投资备案或核准材料包、路径和补正清单，不保证获批，不写并购协议。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：已决定走 ODI 申报，本次主成果是申报材料包而不是再评估能不能投。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未判断备案还是核准或是否禁止；
- 只要并购协议或交割文件；
- 要求保证获批或承诺时限；

不保证获批。不写并购协议。路径未定时回评估原子。

## 建立评估坐标

确认：已形成的路径判断或等价材料；投资主体；项目说明；决策文件；资金来源；尽调或可行性；是否敏感类；拟提交机关。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 已备材料；`A#` 内部决议；`R#` 既有批文；`C#` 投资协议要点；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 材料项；`V#` 材料包版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。未知金额不写零。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验发改 11 号令申报材料、商务部境外投资申报材料及系统填报口径。`search_template` 只借栏目。工具不可用时继续按已有材料编目；材料是否齐全的法定结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　路径闸

未定路径回评估。禁止类停止组卷。伪造停止。

### 节点 2　条线与机关

发改商务并行。共同投资不得漏报。

### 节点 3　决策和主体

决议须覆盖额度和目的地。穿透不得隐瞒。

### 节点 4　项目与敏感类

不得改行业名称规避。并购对价转并购。

### 节点 5　一致性与交付

数字不一致只部分形成。不代提交。

## 停止与安全

- `整体停止`：路径未定仍要终稿；伪造可研或决议；禁止类仍要包装通过。
- `字段停止`：现行材料清单、事权划分未核验。
- `目标停止`：主目标变为写并购协议或保证获批。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
