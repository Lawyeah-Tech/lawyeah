# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、路径、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然获批、必然解除、必然承认或唯一必得总额。

不得把系统自动回执写成核准决定。不得使用已废旧表格冒充现行申报材料。投资协议草案只作附件接口，不在本任务起草成交文本。

`search_law` 返回已失效《合同法》及其解释、法释〔1999〕19 号、法释〔2007〕14 号或已废外资备案办法时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜材料项｜对应条线｜必备或补正｜现状｜缺口｜判断｜待核`。

至少分列：

- `Q-决 内部决策文件`
- `Q-可 真实性合规性说明或可研`
- `Q-主 主体资格与穿透`
- `Q-投 投资协议或章程草案接口`
- `Q-敏 敏感类专项材料`

同一事实支持多项时分别说明效果，不重复金额。构成违约不等于当然解除。约定外法不等于可以无证出口或绕开准入。

## 节点 0　路径闸

若：尚未判断备案／核准／禁止 → 负触发，转 评估境外投资监管准入。
若：现有依据支持禁止类 → 停止组卷，不得制作“看起来能过”的材料。
若：主成果是 SPA → 转投资并购。
若：用户要求伪造可研、资金来源或决议日期 → 整体停止。

## 节点 1　条线与机关

1. 分列发改、商务、（如需）国资或行业主管部门。每条线的接收机关、系统、纸质要求待核。
2. 地方与国家事权按现行标准核验，不得凭旧金额一刀切。
3. 多主体共同投资：各中方是否分别申报待核，不得漏报。

## 节点 2　决策和主体材料

1. 董事会或股东会决议必须覆盖投资额、目的地、资金来源。决议日期晚于已对外签约日标红旗。
2. 营业执照、章程、审计或财报按机关清单核验。
3. 穿透到最终境内控制人。中间层用境外公司持股：提供登记和股权结构图，结构图不得隐瞒。

## 节点 3　项目与敏感类材料

1. 项目说明：产品、市场、落地主体、建设或并购进度。
2. 敏感类：按核准要求准备额外说明，不得改写行业名称规避。
3. 并购类：目标公司基本信息和交易要点只作申报附件，对价谈判和交割文件转并购。
4. 涉及出口管制物项：另附许可状态，不在 ODI 材料里写成已经可以出口。

## 节点 4　补正与一致性

1. 投资额、币种、持股比例在决议、协议、系统填报中必须一致。不一致则材料包标 `部分形成`。
2. 英文名称、注册地拼写与目标登记预核名一致。
3. 真实性声明不得由本技能代签。

## 节点 5　材料包交付

1. 输出：路径、材料清单、已齐／缺失／补正、风险提示。
2. 不代提交，不保证受理或获批。
3. 外汇登记材料单列接口，待前序手续完成后再组。
