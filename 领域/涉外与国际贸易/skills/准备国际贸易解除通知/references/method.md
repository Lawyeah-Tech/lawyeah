# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、路径、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然获批、必然解除、必然承认或唯一必得总额。

无解除权的通知不因对方未异议而生效。不得写“视为已解除且对方不得异议”。不得用已失效《合同法》通知规则。微信已读不等于到达。

`search_law` 返回已失效《合同法》及其解释、法释〔1999〕19 号、法释〔2007〕14 号或已废外资备案办法时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜解除路径｜催告是否已完成｜通知对象｜拟写效果｜判断｜待核`。

至少分列：

- `Q-权 解除权依据回链`
- `Q-催 催告必要是否已满足`
- `Q-到 到达设计`
- `Q-稿 发送前稿`
- `Q-异 异议应对`

同一事实支持多项时分别说明效果，不重复金额。构成违约不等于当然解除。约定外法不等于可以无证出口或绕开准入。

## 节点 0　权利闸

解除权未判断 → 转 assess-termination-right。须催告未催告 → 停止终稿，转催告原子。主成果是催告 → prepare-demand-notice。
伪造已催告或倒签解除：整体停止。

## 节点 1　对象与文本

1. 通知对象必须是合同相对方或其有权代理人。集团邮箱或业务员个人微信不足时标红旗。
2. 作准语言发正文；中文稿标明译文地位。
3. 合同版本和解除所依据的条款必须写进稿内回链。

## 节点 2　意思内容

1. 只写已支持的解除路径和事实。不得把质量争议写成已经构成根本违约，除非依据材料已支持。
2. 解除生效时点按准据法：通知到达或符合约定时。不得写发出即解除，除非规则支持并已核验。
3. 保留损害赔偿、退货、结算，但不在本稿算定金额。

## 节点 3　到达设计

1. 约定渠道、备份渠道、回证。域外送达升级转 plan-overseas-service。
2. 不得把已读、已发送写成到达。
3. 本任务不实际发送，不伪造签收。

## 节点 4　异议应对

1. 预判对方主张无解除权、催告不足、逾期除斥。
2. 不在本稿剥夺对方陈述。
3. 已收到对方解除而发反通知：先评对方通知效力，避免双方都“已解除”互相打架。

## 节点 5　文稿状态

1. 锁定唯一 V#。条件不足标不得发送。
2. 发送后清理转 wind-up 原子。

## 追加判断
若：解除权材料只支持部分货物 → 本稿只解除该部分，不得写成整份框架已解除。若：作准文本是英文 → 英文为正本，中文标明译文。若：相对方在境外且仅有社交媒体账号 → 到达设计标不足，转域外送达原子，不得把点赞写成到达。

若：同一事实同时支持请求和抗辩 → 分列效果，不合并成一笔结论，也不重复计算金额。
若：机关或机构文书的作出日与收到日冲突 → 两套起算并行，期限字段停止，不得挑选对用户有利的日期。
若：需要引用域外实体法而未能查明 → 不得用中国法填空冒充已查明，该路径标依据不足。
本任务不输出胜诉率、必然获批、必然撤销、必然承认或唯一必得总额。未知金额不写零。
