# 边界与路由

## 正触发

已决定行使解除权，需要发送前稿，且解除权已有等价判断或可回链条件。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 解除权评估 | `评估国际贸易解除权` |
| 催告履行 | `准备国际贸易催告或补救通知` |
| 须催告未催告仍要终稿 | 停止终稿 |
| 解除后清理 | `处理解除后返还仓储与结算` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 倒签解除或伪造催告 | 整体停止 |
| 海事撤船通知 | 海事领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

发出解除通知不等于解除已生效。对方沉默不等于同意。
