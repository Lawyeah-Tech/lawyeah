# 应对中国涉外仲裁

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的被申请人立场下，形成首次仲裁答辩包：期限卡、仲裁协议或管辖抗辩、逐项抗辩、证据目录、反请求接口。

`depends-on` 为空。

## 工作边界

正触发：已收到中国仲裁机构的仲裁通知或申请书，用户为被申请人，需要首次答辩。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 用户实为申请人；
- 中国法院应诉；
- 海事仲裁应诉；
- 只要逾期异议终稿且无实体。

不代提交。首次实体答辩是否放弃异议必须核验，未核验不得写已放弃。

## 建立应诉坐标

确认：授权；被申请人；收到日与送达方式；机构与案号；申请请求；仲裁协议；规则版本。口头“听说被申请”不得起算期限。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机构文书；`C#` 合同或仲裁协议；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 抗辩；`V#` 稿件版本；`E#` 送达凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验异议、答辩和撤销预告接口。机构规则以现行文本为准。规则不可用则期限字段停止，抗辩事实继续。

## 五个判断节点

执行顺序和停止条件以 [应诉方法](references/method.md) 为准。

### 1. 送达与期限卡

收到日无凭证不得起算。答辩期按规则核验。

### 2. 仲裁协议与管辖抗辩

先于实体。过期标逾期，不伪造成仍在期限内。

### 3. 逐项抗辩

对申请请求逐项回应，不把反请求写成已经提起。

### 4. 证据与反请求接口

反请求条件只评估，终稿转反请求原子或 `unavailable`。

### 5. 答辩草稿

不自认未核验事实。不代提交。

## 停止与安全

- `整体停止`：立场不明；伪造未收到。
- `字段停止`：送达日、规则期限未核验。
- `目标停止`：主目标变为主动申请或法院应诉。
