# 边界与路由

## 正触发

已收到中国机构涉外仲裁通知，用户为被申请人。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 主动申请 | `提起中国涉外仲裁` |
| 论坛判断尚未做且未进入程序 | `评估涉外管辖与仲裁协议` |
| 中国法院应诉 | `应对中国法院涉外民事诉讼`（未安装则 `unavailable`） |
| 反请求终稿 | `评估仲裁反请求`（未安装则 `unavailable`） |
| 海事仲裁 | 海事领域 |

## 专项整案转出

劳动仲裁应诉 → 劳动。

## 易混

对协议效力有异议仍正触发：先做异议和期限卡。过期后不得把异议写成仍在法定期限内。
