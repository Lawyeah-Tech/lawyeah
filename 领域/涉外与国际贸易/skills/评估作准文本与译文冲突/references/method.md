# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、路径、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然获批、必然解除、必然承认或唯一必得总额。

不得用已失效《合同法》第一百二十五条旧条号冒充现行解释规则。作准条款本身冲突或未签署时，不得挑选对用户有利的文本写成唯一作准。

`search_law` 返回已失效《合同法》及其解释、法释〔1999〕19 号、法释〔2007〕14 号或已废外资备案办法时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜冲突条款｜中文表述｜外文表述｜作准条款指向｜履行中实际使用文本｜法律效果差｜判断｜待核`。

至少分列：

- `Q-准 作准条款是否成立`
- `Q-冲 具体条款冲突点`
- `Q-履 履行中实际采用的文本`
- `Q-译 译文地位`
- `Q-解 解释规则路径`

同一事实支持多项时分别说明效果，不重复金额。构成违约不等于当然解除。约定外法不等于可以无证出口或绕开准入。

## 节点 0　专项分流

| 信号 | 处置 |
| --- | --- |
| 未成争，要改作准条款或统一文本 | 审查起草（搁置） |
| 主成果是发送催告或解除 | 转相应通知原子 |
| 信用证单据语言与合同语言冲突但主轴是不符点 | 评估信用证不符点与拒付 |
| 海事提单批注与买卖合同文本冲突且运输为主轴 | 海事领域 |

若：用户要求隐匿某一语言版本 → 整体停止。

## 节点 1　版本固定

1. 收集全部签署文本、附件、订单、形式发票、修改确认。扫描件页码、签署页必须可回链。
2. 若：只有一份译文没有外文签署页 → 外文是否存在 `依据不足`，不得把译文当作成准。
3. 电子签署与纸质签署文本不一致：分列 `V#`，不合并。
4. 事后邮件用另一语言修改：是否构成变更另列，不自动覆盖作准文本。

## 节点 2　作准条款

1. 作准条款可能规定：某一语言作准；各文本同等作准；冲突时协商；以签署地文本为准。原文定位。
2. 若：中英条款对“谁作准”表述相反 → 作准条款本身冲突，`Q-准` `依据不足`，进入解释规则，不选对用户有利的一版。
3. 若：合同写“英文作准”但双方一直用中文履行并出具中文发票 → `Q-履` 另列，履行行为可能影响解释，但不自动废止作准条款。
4. 仲裁规则或机构示范条款被复制时，核验是否被当事人实际勾选。

## 节点 3　冲突点法律效果

1. 每个冲突点写两版文字的法律效果差：数量、质量标准、检验期、解除权、违约金、管辖。
2. 效果无实质差异：记录但不升级为请求障碍。
3. 效果决定请求能否成立：该点进入主位争点，待证事实包括签署过程、磋商语言、行业含义。
4. CISG 适用时，解释应考虑国际贸易中同类当事人合理期待；未核验 CISG 则该解释路径停止。

## 节点 4　译文地位

1. 诉讼或仲裁中提交的译文不是作准文本，除非被约定或被双方确认。
2. 认证翻译只解决译文与原件对应，不解决哪一签署文本作准。
3. 若：需要对外发送通知 → 正文语言遵循作准文本；中文稿标明“译文，以作准文本为准”。通知终稿转相应原子。

## 节点 5　下一步

1. 输出冲突表、作准判断（或依据不足）、待证事实、对请求的影响。
2. 不重写合同。用户要统一文本：目标停止，审查起草搁置。
3. 下一步：补签署页、固定履行中使用的文本、转总图或通知原子。
