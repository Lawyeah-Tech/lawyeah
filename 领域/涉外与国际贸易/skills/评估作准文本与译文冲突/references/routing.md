# 边界与路由

## 正触发

中外文本冲突已经或即将决定请求、抗辩或履行标准能否成立，本次主成果是冲突评估而不是改合同。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改作准条款 | 审查起草领域（本窗搁置） |
| 催告通知终稿 | `准备国际贸易催告或补救通知` |
| 解除通知终稿 | `准备国际贸易解除通知` |
| 信用证不符点主轴 | `评估信用证不符点与拒付` |
| 准据法选择且无文本冲突 | `评估准据法与强制性规范` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 提单批注与租约文本主轴 | 海事领域 |
| 隐匿不利语言版本 | 整体停止 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

“英文作准”不等于中文履行行为没有解释意义，但也不能直接改写成中文作准。译文公证不等于作准。
