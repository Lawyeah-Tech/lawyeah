# 评估作准文本与译文冲突

## 任务目标

在明确、无利益冲突的单方立场下，形成作准条款解读、冲突点清单和待证事实，而不重写整份合同。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：中外文本冲突已经或即将决定请求、抗辩或履行标准能否成立，本次主成果是冲突评估而不是改合同。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 未成争只要改作准文本或重写合同（审查起草搁置）；
- 只要催告或解除通知终稿；
- 只要准据法选择且文本并无冲突；

不重写整份合同。未成争改文本走起草（搁置）。

## 建立评估坐标

确认：各语言版本及签署页；作准条款；冲突条款位置；已使用哪一版本履行或交单；翻译来源；是否有第三文本。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 文本表面；`A#` 当前一致／承认；`R#` 机关或机构对文本的认定；`C#` 作准条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 文本冲突假设；`V#` 评估版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。未知金额不写零。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典合同解释规则、法律适用法对意思表示解释的接口、CISG 解释规则是否适用。范本只借鉴栏目，不把示范作准条款写成已经约定。工具不可用时继续做文本对照；解释规则结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　专项分流

未成争改文本搁置。信用证或海事文本主轴转出。隐匿版本停止。

### 节点 2　版本固定

签署页必须可回链。只有译文不得当作成准。

### 节点 3　作准条款

作准条款自相冲突时依据不足，不选有利版本。

### 节点 4　冲突点效果

逐条写法律效果差。无实质差异不升级。

### 节点 5　译文与下一步

认证翻译不等于作准。不重写合同。

## 停止与安全

- `整体停止`：立场不明；隐匿某一语言版本。
- `字段停止`：合同解释规则、CISG 解释规则未核验。
- `目标停止`：主目标变为重写合同或直接发函。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
