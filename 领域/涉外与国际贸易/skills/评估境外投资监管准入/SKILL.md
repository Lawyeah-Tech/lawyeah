# 评估境外投资监管准入

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的申报义务人立场下，形成境外投资监管定性：项目类型、发改商务外汇接口、禁止或限制情形，而不做股权对价与交割文件。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：中国主体拟对外投资，需要判断备案、核准或限制，本次主成果是监管准入评估。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 股权对价、交割或目标尽调为主成果；
- 税务架构或税负测算为主成果；
- 已决定申报并只要材料终稿；
- 返程或协议控制架构设计；

不做股权对价与交割文件。并购交易主体转并购。税务架构转税务。不保证获批。

## 建立评估坐标

确认：投资主体及其穿透股东；投资目的地；行业和实际业务；投资额和出资方式；是否敏感国家和地区；是否已设立境外企业；是否涉及再投资；是否国有或上市公司。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 项目材料；`A#` 内部决议；`R#` 既有核准或备案；`C#` 投资协议要点；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 监管路径；`V#` 评估版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。未知金额不写零。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验企业境外投资管理办法、企业境外投资管理办法（发改 11 号令）及现行敏感类目录、商务部境外投资管理办法、外汇管理条例及资本项目规定。目录和金额门槛必须对照现行公布。工具不可用时继续做项目画像；备案或核准结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　专项分流

并购文件、税务、已决定申报、外商准入转出。分拆规避停止。

### 节点 2　投资画像

主体、类型、最终项目地、实际行业分列。自然人不得套企业规则。

### 节点 3　发改路径

敏感类走核准。金额门槛未核验不写死数字。

### 节点 4　商务与外汇

两条线并行。未完成不得写成可以购汇。

### 节点 5　禁止限制和下一步

国资上市另列。先汇出后补办停止。

## 停止与安全

- `整体停止`：立场不明；分拆规避核准；伪造境内决议。
- `字段停止`：敏感类目录、金额门槛、再投资规则未核验。
- `目标停止`：主目标变为写 SPA 或申报终稿。
