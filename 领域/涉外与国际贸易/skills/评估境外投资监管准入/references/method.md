# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、路径、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然获批、必然解除、必然承认或唯一必得总额。

不得使用已废止的境外投资项目核准和备案管理办法旧文本冒充 11 号令。不得把商务备案回执写成发改已核准。国资、上市公司、金融机构另有规则，未核验不得省略红旗。

`search_law` 返回已失效《合同法》及其解释、法释〔1999〕19 号、法释〔2007〕14 号或已废外资备案办法时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜监管条线｜义务主体｜路径（备案／核准／禁止／不适用）｜成立条件｜支持事实｜不利事实｜判断｜待核`。

至少分列：

- `Q-发 发改备案或核准`
- `Q-商 商务备案或核准`
- `Q-汇 外汇登记`
- `Q-禁 禁止或限制类`
- `Q-敏 敏感国家和地区或行业`

同一事实支持多项时分别说明效果，不重复金额。构成违约不等于当然解除。约定外法不等于可以无证出口或绕开准入。

## 节点 0　专项分流

| 信号 | 处置 |
| --- | --- |
| 主成果是 SPA、对价、交割、目标尽调 | 投资并购领域 |
| 税负最小化、转让定价、CFC | 税务领域 |
| 已决定申报只要材料包 | 准备境外投资备案或核准材料 |
| 返程、VIE 设计绕开 | 不提供绕开；可转评估原子但不设计 |
| 外商进入中国 | 评估外商准入与安全审查 |

若：用户要求拆分项目规避核准或伪造境内决策文件 → 该部分整体停止。

## 节点 1　投资画像

1. 投资主体：境内企业、事业单位还是自然人通过境内企业。自然人直接对外投资规则另核，不得套企业 ODI。
2. 投资类型：新设、并购、增资、再投资、中方控制的境外再投资。再投资是否仍要申报运行时核验。
3. 目的地、最终项目所在地、中间层注册地分列。用避税地持股不消灭最终项目地监管。
4. 行业用实际经营判断，不用投资协议标题粉饰。

## 节点 2　发改路径

1. 对照现行敏感类目录：敏感国家和地区、敏感行业。命中则评估核准而非备案。
2. 非敏感项目按投资主体和中方投资额评估备案层级（国家或地方）。金额门槛未核验则层级字段停止，不得写死“3 亿美元”。
3. 若：项目尚未取得内部决策或投资协议主要条款 → 路径可并列，不得写成已经可以报。
4. 恶意分拆、倒签开工：标红旗并停止规避建议。

## 节点 3　商务与外汇

1. 商务部企业境外投资证书路径与发改路径并行，不得互相替代。
2. 禁止类（危害国家利益、违反中国法、出口管制物项未许可等）对照商务规则核验。
3. 外汇登记以获发改和商务手续为常见前提，但具体银行审核口径待核。未完成前不得写成可以购汇汇出。
4. 内保外贷为境外融资提供担保：另转跨境担保原子，不在 ODI 结论里写成已经覆盖。

## 节点 4　禁止限制与特殊主体

1. 国有企业、中央企业、金融机构、上市公司附加程序单列红旗。
2. 涉及房地产、娱乐、体育俱乐部等限制方向：对照现行政策，不得凭记忆写“已经一律禁止”或“已经放开”。
3. 最终用户或物项触发出口管制：ODI 获批不等于可以出口，转管制原子。
4. 不得实施项：禁止类或核准前开工。

## 节点 5　下一步

1. 输出：三条监管条线的路径或依据不足、禁止限制红旗、补证、是否转申报原子。
2. 不保证获批。不写并购协议。
3. 用户坚持先汇出再补办：该部分整体停止。
