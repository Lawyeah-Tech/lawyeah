# 边界与路由

## 正触发

中国主体拟对外投资，需要判断备案、核准或限制，本次主成果是监管准入评估。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 申报材料终稿 | `准备境外投资备案或核准材料` |
| 外商准入 | `评估外商准入与安全审查` |
| 并购交易文件 | 投资并购领域 |
| 税务架构 | 税务领域 |
| 跨境担保专项 | `评估跨境担保与内保外贷监管` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权对价、交割、目标尽调 | 投资并购领域 |
| 转让定价、CFC、税负 | 税务领域 |
| 设计 VIE 绕开准入 | 拒绝并停止该部分 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

发改备案完成不等于商务证书已取得，更不等于外汇已登记。中间层在开曼不改变最终项目地敏感类判断。
