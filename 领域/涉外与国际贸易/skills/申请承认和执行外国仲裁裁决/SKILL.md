# 申请承认和执行外国仲裁裁决

## 任务目标

在明确、无利益冲突的权利人立场下，形成在中国申请承认和执行外国仲裁裁决的材料包：路径定性、作出地与公约适用、管辖法院连结点、申请书草稿、文书清单、期间待核和被申请人抗辩预判。

`depends-on` 为空。

## 工作边界

正触发：持有在中国领域外作出的仲裁裁决，需要在中国承认或执行。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 港澳台裁决认可；
- 内地仲裁机构裁决的执行；
- 外国法院判决承认；
- 用户为被申请人只要抗辩（转应对原子，未安装则 `unavailable`）；
- 代向法院提交。

不保证承认或执行。

## 建立申请坐标

确认：授权；裁决正本或经证明副本；仲裁协议；作出地；裁决日期；被申请人住所或财产所在地；是否仅申请承认；已申请或已裁定情况。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 裁决或法院文书；`C#` 仲裁协议；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径与抗辩预判；`V#` 稿件版本；`E#` 送达或执行凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民事诉讼法涉外编、纽约公约通知、司法审查规定和申请期间。`search_law` 对路径和期间为 required。法释引用的旧条号必须对照 2023 民事诉讼法。

工具不可用时继续文书编目；公约适用、管辖选定和期间字段停止。

## 五个判断节点

执行顺序和停止条件以 [申请方法](references/method.md) 为准。

### 1. 定性闸

外国裁决 / 内地裁决 / 港澳台 / 外国判决必须先分开。

### 2. 公约或互惠路径

互惠保留：另一缔约国领土内作出。商事保留运行时核验。

### 3. 管辖与期间

被申请人住所地或财产所在地中级人民法院。期间按现行法核验，不得写一律两年。

### 4. 文书与认证

裁决和协议文本、译文、认证状态。

### 5. 抗辩预判与草稿

第五条事由和公共秩序只作预判，不保证结果。不代提交。

## 停止与安全

- `整体停止`：立场不明；伪造裁决。
- `字段停止`：作出地、公约缔约状态、期间规则未核验。
- `目标停止`：主目标变为外国判决或港澳台认可。
