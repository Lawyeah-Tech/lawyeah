# 边界与路由

## 正触发

持外国仲裁裁决，需要在中国承认或执行。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 港澳台裁决或判决认可 | `评估涉港澳台法域与文书`（未安装则 `unavailable`） |
| 外国法院判决 | `申请承认和执行外国法院判决`（未安装则 `unavailable`） |
| 内地裁决执行 | 一般执行程序，不走本任务 |
| 被申请人抗辩 | `应对承认执行外国裁决或判决`（未安装则 `unavailable`） |
| 撤销内地涉外裁决 | `申请撤销涉外仲裁裁决`（未安装则 `unavailable`） |
| 尚未取得裁决，要先仲裁 | `提起中国涉外仲裁` |

## 专项整案转出

离婚外国判决 → 家事。海事保全本身 → 海事；外国海事裁决仍先完成本定性，海事执行措施转海事。

## 易混

中国机构在境外开庭作出的裁决国籍以仲裁地／作出地核验，不得仅因机构在中国写成内地裁决。临时仲裁在领域外作出的，按外国裁决路径评估，规则待核。
