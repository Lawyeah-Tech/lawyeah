# 边界与路由

## 正触发

托收、福费廷、出口押汇与基础合同冲突，需要融资关系评估。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 境内借贷主轴 | 金融领域 |
| 信用证不符点 | `评估信用证不符点与拒付` |
| 独立保函 | `评估独立保函与备用信用证` |
| 外汇收付阻塞 | `评估跨境收付与外汇合规` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 伪造单据套资 | 整体停止并刑事红旗 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

福费廷名称不等于真正无追索。银行已贴现不消灭基础质量请求，但可能影响谁是适格原告。
