# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、路径、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然获批、必然解除、必然承认或唯一必得总额。

名称是押汇或福费廷，实质可能是借贷。无追索约定必须原文核验例外（欺诈、无效单据）。不得用已失效《合同法》。

`search_law` 返回已失效《合同法》及其解释、法释〔1999〕19 号、法释〔2007〕14 号或已废外资备案办法时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜融资品种｜是否无追索｜与基础合同关系｜单据瑕疵｜追索或抗辩｜判断｜待核`。

至少分列：

- `Q-独 融资与基础买卖是否独立`
- `Q-索 追索条件`
- `Q-单 单据条件`
- `Q-基 基础买卖分流`
- `Q-金 是否实为借贷`

同一事实支持多项时分别说明效果，不重复金额。构成违约不等于当然解除。约定外法不等于可以无证出口或绕开准入。

## 节点 0　分流

境内贷款、保证、抵押为主 → 金融。信用证审单不符点 → 信用证原子。独立保函 → 独立保函原子。
伪造单据套取融资：停止并刑事红旗。

## 节点 1　品种定性

1. 托收（D/P、D/A）、出口押汇、福费廷、保理分列。
2. 协议写无追索但保留欺诈例外或单据无效例外：追索可能仍存在。
3. 银行未真实受让债权只是放贷：按借贷关系评估并转金融接口。

## 节点 2　单据与付款

1. 银行付款是终局买入还是垫款。垫款通常可追索。
2. 单据与融资协议约定不符：追索或拒付另列，基础质量另账。

## 节点 3　与基础买卖

1. 买方未付或货物不符：卖方对买方请求走货物或价款原子。
2. 银行对卖方追索不自动消灭卖方对买方的权利，注意双重受偿。
3. 债权是否已通知买方：未通知可能影响对买方主张。

## 节点 4　外汇与管制

融资项下收汇阻塞转外汇原子。名单命中转筛查。

## 节点 5　下一步

输出独立性、追索条件、与基础买卖分流。不把押汇改写成保证获付。

## 补充判断

若：协议标题为福费廷但银行保留一切单据瑕疵追索 → 按有追索贴现评估，不写成无追索卖断。
若：基础合同质量纠纷与银行追索同时发生 → 两套程序分账，注意卖方不得双重受偿同一货款。
若：债权转让未通知开证申请人或买方 → 对买方主张字段停止或标缺口。
若：融资协议约定适用外法 → 中国外汇真实性审核仍可能介入。
实质为流动资金贷款的，整案转金融并保留贸易背景接口。

## 追加判断
若：托收银行因买方拒付而向卖方追索 → 先核托收指示是否允许；D/P 与 D/A 效果不同。若：出口押汇后信用证被拒 → 银行追索与受益人对开证行权利分列。不得指导补造单据再交单。

若：同一事实同时支持请求和抗辩 → 分列效果，不合并成一笔结论，也不重复计算金额。
若：机关或机构文书的作出日与收到日冲突 → 两套起算并行，期限字段停止，不得挑选对用户有利的日期。
若：需要引用域外实体法而未能查明 → 不得用中国法填空冒充已查明，该路径标依据不足。
本任务不输出胜诉率、必然获批、必然撤销、必然承认或唯一必得总额。未知金额不写零。
