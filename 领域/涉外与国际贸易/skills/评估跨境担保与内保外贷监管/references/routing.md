# 边界与路由

## 正触发

内保外贷、外保内贷或跨境保证需要监管判断，且主债不是单纯境内借贷担保。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 境内借贷担保主轴 | 金融领域 |
| 独立保函索赔止付 | `评估独立保函与备用信用证` |
| 海事担保 | 海事领域 |
| 税务成本 | 税务领域 |
| ODI 准入总评 | `评估境外投资监管准入` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 船舶抵押、海事保全担保 | 海事领域 |
| 伪造回流或用途 | 整体停止 |
| 起草担保合同 | 审查起草领域（本窗搁置） |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

办了内保外贷登记不等于主债有效，也不等于资金可以自由回流。独立保函不适用从属保证抗辩。
