# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、路径、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然获批、必然解除、必然承认或唯一必得总额。

跨境担保外汇管理已从逐笔核准转为重点事后监管，但具体登记、银行审核和违规后果必须按现行规定核验，不得写“现在完全不用登记”。不得用已失效《担保法》条文。

`search_law` 返回已失效《合同法》及其解释、法释〔1999〕19 号、法释〔2007〕14 号或已废外资备案办法时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜担保类型｜资金流向｜监管接口｜与主债关系｜效力红旗｜判断｜待核`。

至少分列：

- `Q-内 内保外贷`
- `Q-外 外保内贷`
- `Q-其 其他跨境担保`
- `Q-登 登记或备案`
- `Q-效 民事效力与监管责任`

同一事实支持多项时分别说明效果，不重复金额。构成违约不等于当然解除。约定外法不等于可以无证出口或绕开准入。

## 节点 0　专项分流

| 信号 | 处置 |
| --- | --- |
| 主债是境内贷款、保证、抵押，无跨境资金 | 金融领域 |
| 见索即付保函或备用证索赔止付 | 评估独立保函与备用信用证 |
| 海事担保、船舶抵押、责任限制基金 | 海事领域 |
| 税务成本、资本弱化 | 税务领域 |
用户要求伪造资金用途或回流以骗取内保外贷：整体停止。

## 节点 1　结构定性

1. 内保外贷：境内担保人为境外债务人向境外债权人提供担保。
2. 外保内贷：境外担保人为境内债务人向境内债权人提供担保。
3. 其他跨境担保：担保人或债权人一方跨境但不属于上述两类。定性不明则三条并列待核。
4. 独立保函与从属性保证分列，不得把独立保函当成从属保证去谈主债抗辩。

## 节点 2　外汇与银行接口

1. 是否需要登记、向谁登记、由谁办理（银行还是债务人），对照现行规定。
2. 内保外贷资金是否允许回流境内：用途限制待核。违规回流标红旗。
3. 额度、集中登记、非银行担保人特殊规则未核验则额度字段停止。
4. 未按规定办理：监管责任与民事效力分列，不得直接写成担保无效或当然有效。

## 节点 3　民事效力与主债

1. 主债不成立、无效或已消灭时，从属保证效果按民法典核验；独立保函另评。
2. 公司对外担保的决议程序按公司法现行规则。跨境不免除决议。
3. 若：担保合同约定适用外法 → 中国外汇强制规范仍可能介入，转强制规范原子接口。
4. 保证期间、债权申报期间分列，不与诉讼时效混算。

## 节点 4　与 ODI、FDI、管制的交叉

1. 为境外投资项下融资提供担保：可能同时触发 ODI 或内保外贷，两条线都要列。
2. 担保受益人在制裁或管制名单：转筛查原子，不得建议继续出具。
3. 外商投资境内贷款的外保内贷：与外商投注差等旧口径是否仍适用必须核验，废止口径不得使用。

## 节点 5　下一步

1. 输出定性、登记接口、效力红旗、与主债关系、不得办理项。
2. 不算出税负。不写担保合同草稿（审查起草搁置，独立保函索赔另项）。
3. 用户坚持无登记放款并要求“补一份倒签登记”：停止。
