# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、论坛、管制、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然获批、必然解除或唯一必得总额。

`search_law` 返回已失效《合同法》及其解释、法释〔2007〕14 号或已废外资备案办法时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜关系假设｜提出方｜相对方｜法律效果｜成立条件｜支持事实｜不利事实｜控制方｜最强反方｜主备位｜判断｜待核`。

解除、继续履行、付款、违约金、赔偿、管制停止、准入申报分列。同一事实支持多项时分别说明效果，不重复金额。构成违约不等于当然解除。约定外法不等于可以无证出口。

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填总体评估十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 股权对价、交割、目标尽调、境内重组协议为主成果 | 投资并购领域 |
| 转让定价、常设机构所得税、出口退税争议为主成果 | 税务领域 |
| 租船、海上运输合同、船舶、海事保全、共同海损 | 海事领域 |
| 外国人在华用工、中国劳动合同、工伤 | 劳动领域 |
| 数据出境安全评估、个人信息出境专项 | 数据领域 |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

混合信号：跨境买卖或服务主轴可留本任务；专项只作为背景时在缺口标明。

## 节点 1　主体、文本版本、法域要素和程序状态

1. 固定合同、形式发票、订单、信用证、投资方案、补充协议的版本层级。中英文本冲突并列，不作准文本不明时不选对用户有利的一版。
2. 主体表记录签约名、注册地、履行名、付款名和可能责任主体。名称不一致不自动合并。
3. 法域要素表：主体国籍或注册地、经常居所、标的所在地、法律事实发生地、约定准据法、约定论坛。满足任一涉外因素即进入本领域坐标；均不满足且无管制或准入问题 → 负触发，转一般合同争议或相应境内领域。
4. 港澳台主体或财产单独一行，后续论坛不得写成“外国”。
5. 程序表逐动作记录协商、催告、申报、许可、仲裁、诉讼或执行：机关/机构、案号、文书、作出日、收到日、送达方式和效力凭证。口头转述、截图、“已读”不得写成已受理、已送达或期限已起算。
6. 同时掌握双方秘密或立场不明：整体停止策略输出。

## 节点 2　请求、抗辩与强制规范

每个 `Q#` 先写法律效果，再写成立条件。禁止合成“跨境权益”一笔。

默认主位候选按事实分别建立：

- `Q-履` 继续履行或补救
- `Q-催` 催告履行或指定合理期限
- `Q-解` 约定解除、法定解除或条约解除
- `Q-金` 价款、违约金、损害赔偿
- `Q-管` 停止出口、申请许可、切断受限制对手
- `Q-准` 负面清单、安全审查、信息报告、ODI 接口
- `Q-抗` 仲裁/管辖异议、检验逾期、信用证不符、强制规范

若：合同约定适用外国法或国际惯例 → 记录约定，同时单列中国强制性规定是否介入。强制规范类型对照法释〔2020〕18 号第八条运行时核验；核验失败则强制规范结论字段停止，约定记录继续。  
若：用户主张“约定纽约法所以不用中国出口许可” → `Q-管` 不得因约定外法写成现有依据不支持许可义务。  
若：CISG 是否适用未核验（营业地、保留、是否排除） → 条约路径 `依据不足`，国内法路径并列待核。

构成违约不等于当然解除。管制命中不等于合同自动无效，效力后果另列待核。

## 节点 3　管制、准入与论坛闸

本节点只做红旗和转介，不生成许可申请、安全审查申报或立案包。

### 3.1 出口管制与制裁

若：物项、技术、服务、目的地、进口商或最终用户任一不明 → 管制结论 `依据不足`，标红旗，转 `assess-export-control-and-sanctions`。  
若：用户要求拆分出口、改名绕名单或伪造最终用户 → 该部分整体停止。  
不得把用户口述的清单名称写成已核验命中。

### 3.2 投资准入

若：外国投资者直接或间接在境内投资 → 列负面清单和安全审查红旗，转 `assess-fdi-access` 做专项。不得把信息报告写成已获批准。  
若：交易文件本身是股权买卖或交割 → 目标停止，转投资并购领域。  
若：中国主体对外投资 → 留 ODI 接口，安装包无 ODI 原子则标 `unavailable`。

### 3.3 论坛

合同、补充协议或事后书面协议出现仲裁条款时：

1. 不得直接写“应向法院起诉”。
2. 或裁或诉、机构约定不明、未签字主体：效力标 `依据不足`，转 `assess-forum-and-arbitration`。
3. 书面形式、仲裁意思、事项覆盖、机构可确定且无或裁或诉冲突均获支持时，论坛主位写成仲裁。
4. 合同无效、被撤销或终止，不当然消灭仲裁协议。独立性规则须运行时核验现行《仲裁法》文本。

无仲裁协议或现有依据不支持其适用时，才把中国法院涉外诉讼列为可行入口。管辖连结点只列待核，不选定唯一法院。

## 节点 4　期限分类型

每种期间单独一行。禁止用三年诉讼时效去算解除权或检验索赔期。

| 类型 | 本任务允许的输出 | 禁止 |
| --- | --- | --- |
| 诉讼时效 | 起算事件、备选起算、中断候选 | 唯一截止日 |
| 解除权除斥 | 知悉日/催告日并行情景 | 与时效混算 |
| 检验 / 索赔期 | 约定检验期、合理期限、条约接口 | 签收=验收 |
| 仲裁请求期限 | 与诉讼时效分列，规则待核 | 用三年诉讼时效冒充 |
| 承认执行申请期间 | 只标红旗和转介 | 在总图里写死截止日期充作法律意见 |
| 管辖 / 仲裁异议期 | 已进入程序时标红旗 | 过期仍赶写异议终稿 |
| 许可、申报、改正期 | 机关文书载明的期间原文 | 编造“一律 30 日” |

日期冲突、送达不明：并行情景 + 字段停止。涉外诉讼审限不受普通审限条文限制，不得据此写成当事人没有期限。

## 节点 5　金额、证据和下一步

1. 分项列价款、质量扣减、迟延、违约金、损失、已付款。未知不写零。币种和汇率假设单列。约定违约金不是必得。
2. 许可被拒、不得实施投资、货物扣留、账户冻结等非金钱后果单列，不折成伪精确金额。
3. 证据矩阵列待证事实、支持与不利、控制方、认证需求（公证/附加证明书/领事认证待核）、合法取得、缺口和最晚时点。
4. 下一步按：管制或准入违法风险、期限灭失、易失证据、能否改变 `Q#`、可逆性排序。发送催告、许可申请、仲裁申请、承认执行标为转介，不在本包做出终稿。

若：主目标已变为其中任一终稿 → 目标停止。
