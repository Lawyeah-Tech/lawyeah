# 边界与路由

## 正触发

存在跨法域主体、跨境货物或服务、境外投资监管、出口管制或制裁，或中国涉外争议，单方需要总体决定请求、抗辩、申报、论坛、证据优先级和下一步。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |
| 评估管辖或仲裁条款本身 | `评估涉外管辖与仲裁协议` |
| 这票货或对手能不能出 | `评估出口管制与制裁风险` |
| 外商能不能进中国 | `评估外商准入与安全审查` |
| 发催告履行 | `准备国际贸易催告或补救通知` |
| 精算价款或损失 | `测算国际贸易价金与损害赔偿` |
| 完整证据卷 | `建立跨境争议证据与认证案卷` |
| 提起中国涉外仲裁 | `提起中国涉外仲裁` |
| 应对中国涉外仲裁 | `应对中国涉外仲裁` |
| 承认执行外国裁决 | `申请承认和执行外国仲裁裁决` |
| 解除通知 | `准备国际贸易解除通知`（未安装则 `unavailable`） |
| ODI 备案或核准材料 | `准备境外投资备案或核准材料`（未安装则 `unavailable`） |
| 贸易救济应诉问卷 | `准备贸易救济应诉材料`（未安装则 `unavailable`） |
| 境内并购交易主体 | 投资并购领域 |
| 纯税务、海事、在华劳动、数据出境 | 对应领域 |
| C 端外贸合同风险审查 | 大众专项，只分流不回改 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权对价、交割清单、目标尽调、境内重组协议 | 投资并购领域 |
| 转让定价、常设机构所得税、出口退税争议 | 税务领域 |
| 租船、海上货物运输合同、船舶、海事保全、共同海损 | 海事领域 |
| 外国人在华用工、中国劳动合同、工伤 | 劳动领域 |
| 数据出境安全评估、个人信息出境 | 数据领域 |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置） |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

请求尚未闭合、需比较申报、发函还是仲裁时正触发。主体、请求、论坛均确认且只要仲裁申请时负触发。有仲裁条款仍要求“直接起诉”时，先完成论坛闸，不改写成立案原子。清单名称被用户口头提及，不得写成已核验命中。
