# 评估跨境事项总图

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“跨境事项总体评估矩阵”：主体和程序状态、法域与强制规范红旗、管制与准入红旗、逐项请求／抗辩或申报义务、论坛与程序入口、期限待核、金额区间与非金钱后果、证据缺口、对方最强解释和下一步。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：存在跨法域主体、跨境货物或服务、境外投资监管、出口管制或制裁、或中国涉外争议，用户仍需决定请求、抗辩、申报、路线或下一步。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未成争，只要改合同或出稿（审查起草领域，本生产线搁置，只说明不实施）；
- 只要发送版催告、解除或索赔函；
- 只要精算工作表或完整证据卷；
- 已决定仲裁申请／起诉／答辩／承认执行并只要相应文书；
- 境内并购交易主体（对价、交割、目标尽调）；
- 纯跨境税务专项；
- 海上运输、船舶、海事保险专门事项。

本任务不生成发送版函件、许可申请终稿、可提交仲裁申请或诉状，不给胜诉率。

## 建立评估坐标

确认：使用者与授权；单方立场；相对方及可能责任主体；合同及附件或投资方案版本；货物／技术／服务描述；最终用户与目的地；法域；当前协商、催告、申报、仲裁、诉讼或执行状态；机关文书作出与送达；对方已知主张；关键材料及缺失。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩／申报义务；`V#` 评估版本；`E#` 发送／送达／履行凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验准据法强制规范、仲裁协议、出口许可、负面清单、期限；`search_practiced` 补路径与反例；特殊事实用 `search_case_by_fact`。不虚构案件系统。

工具不可用时继续事实、主体、程序文书状态和问题清单；法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 专项分流、主体和程序状态

先做并购交易主体、纯税务、海事、在华劳动、数据出境、审查起草分流，再固定文本版本、主体表和程序表。口头转述和“已读”不写成已受理、已送达或期限已起算。

### 2. 法域、强制规范与请求假设

每个 `Q#` 独立列法律效果、成立条件、支持及不利事实、控制方、最强反方、主备位和互斥。约定外法不消灭中国管制、准入和外汇强制规范。继续履行、催告、解除、付款、管制停止不得合成一笔“跨境权益”。

### 3. 管制、准入和论坛

出口管制、制裁、反制裁、负面清单、安全审查只做红旗和转介，不写许可或申报终稿。仲裁条款出现时不得直接写成应起诉。

### 4. 金额区间与非金钱后果

分项列价款、质量扣减、迟延、违约金、损失。未知不写零。币种和汇率假设单列。许可被拒、不得实施投资、货物扣留等非金钱结果单列。

### 5. 证据、反方和下一步

证据矩阵列待证事实、认证需求、控制方、合法取得、缺口和最晚时点。下一步按期限灭失、管制违法风险、易失证据、可逆性排序。发函、立案、申报终稿标为转介。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体无法建立；用户坚持伪造、规避许可、改名绕名单或违法取证。
- `字段停止`：法域、日期、文书送达、清单状态、动态规则未核验。
- `目标停止`：主目标已变为发函、精算、建卷、许可申请或程序文书。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
