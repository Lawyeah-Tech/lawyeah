# 边界与路由

## 正触发

境外文书需在中国使用，或中国文书需在境外使用，本次主成果是路径和材料而不是代办认证或证明实体权利。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 代办认证递件 | 不实施 |
| 完整证据卷 | `建立跨境争议证据与认证案卷` |
| 域外取证方案 | `规划域外取证与公证认证` |
| 港澳台文书定性 | `评估涉港澳台法域与文书` |
| 家事离婚承认 | 家事领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 船上扣押或海事证据保全 | 海事领域 |
| 刑事取证或违法跨境调取 | 停止并转刑事或拒绝 |
| 股权交割所需目标尽调文件包 | 投资并购领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

已加入海牙公约后，非缔约形成地仍可能要领事认证，不得一刀切。认证完成不等于实体权利成立。
