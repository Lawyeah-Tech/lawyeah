# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、路径、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然获批、必然解除、必然承认或唯一必得总额。

中国于 2023-11-07 施行《取消外国公文书认证要求的公约》。形成地是否缔约、文书是否属于公文书、是否属于公约排除范围，三项未核验不得选定唯一路径。不得沿用“出国文书一律双认证”作为现行规则。

`search_law` 返回已失效《合同法》及其解释、法释〔1999〕19 号、法释〔2007〕14 号或已废外资备案办法时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜文书｜形成地｜使用地｜使用目的｜候选路径｜成立条件｜材料｜失败分流｜判断｜待核`。

至少分列：

- `Q-公 公证`
- `Q-附 附加证明书（Apostille）`
- `Q-领 领事认证`
- `Q-免 条约或对等免除`
- `Q-译 译文与译本认证`

同一事实支持多项时分别说明效果，不重复金额。构成违约不等于当然解除。约定外法不等于可以无证出口或绕开准入。

## 节点 0　专项分流

| 信号 | 处置 |
| --- | --- |
| 用户要本技能去递件或代签 | 负触发，不代办 |
| 完整证据卷、举证责任分配 | 建立跨境争议证据与认证案卷 |
| 域外取证和司法协助方案 | 规划域外取证与公证认证 |
| 家事离婚判决承认 | 家事领域 |
| 海事证据保全或船上取证 | 海事领域 |

若：用户要求伪造公证书、空白附加证明书或买卖认证页 → 整体停止。

## 节点 1　文书定性

1. 每份文书写明：制作机关或私人、是否公文书、是否经过公证、原件还是副本、形成地。
2. 私文书通常先公证再进入附加证明书或领事认证；公文书是否可直接申请附加证明书运行时核验。
3. 若：文书是合同复印件或微信截图 → 先解决原件或公证事实，不能跳到附加证明书。
4. 裁判文书、仲裁裁决、身份登记、授权书、公司存续证明分列路径，不得一套材料打天下。

## 节点 2　公约路径与领事路径

1. 形成地和使用地均为公约缔约方且文书属于公约范围：优先评估附加证明书，不再叠加领事认证。
2. 形成地非缔约或文书被排除：评估领事认证或双边条约免除。
3. 若：缔约状态未核验 → `Q-附` 与 `Q-领` 并列待核，不得输出“现在都用海牙认证所以不用管”。
4. 中国出具、国外使用：中国附加证明书主管机关和办理入口运行时核验，不得编造一律外交部或一律地方外办。
5. 失败分流：被拒绝办理时升级材料、更换公证事项或改用司法协助，不伪造签收。

## 节点 3　材料、译文和时效

1. 最低材料：原件或经证明副本、身份或主体文件、使用目的说明、译文。缺原件标 `部分形成`。
2. 译文是否需翻译专用章或公证，按使用地和接收机关核验，不得一律要求或不要求。
3. 若：文书将过期（授权期限、登记摘录有效期）→ 标最晚办理时点，不编造“一律三个月”。
4. 电子公文书、电子附加证明书是否被接收机关接受：未核验则纸质路径并列。

## 节点 4　使用场景约束

1. 诉讼或仲裁：认证只解决形式，不解决证明力。不得写“认证后法院必然采信”。
2. 市场监管、银行、外汇、海关：按该机关现行窗口要求核验，窗口口头要求与法律形式冲突时并列。
3. 港澳台文书不走外国公文书路径，转区际安排或转介 评估涉港澳台法域与文书。
4. 合同约定“无需公证认证”不能约束中国法院或登记机关的强制形式。

## 节点 5　规划交付和下一步

1. 输出：逐份文书的推荐路径（或并列待核）、材料清单、失败分流、预计卡点。
2. 不代办，不保证时限，不把规划写成已认证。
3. 下一步：补原件、核验缔约状态、启动公证、转证据卷或域外取证。
4. 若：主目标变为违法跨境调取原件 → 整体停止。
