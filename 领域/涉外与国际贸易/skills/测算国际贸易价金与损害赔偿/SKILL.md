# 测算国际贸易价金与损害赔偿

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成可复核测算包：事件编号、分项工作表、币种与汇率假设、违约金调整接口、可预见／减损／双方违约、定金与已付款互斥、情景区间和缺口。

`depends-on` 为空。本任务**不认定违约已经成立**。

## 工作边界

正触发：国际货物或跨境服务已成争，需要价款、质量扣减、迟延、违约金或损失的可复核数字。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要定性总图；
- 共同海损、运费或滞期费主轴（海事）；
- 出口退税或税负测算（税务）；
- 只要发送版函件或仲裁申请。

不输出唯一必得总额。未知不写零。

## 建立测算坐标

确认：立场；合同及作准币种；拟测算项目；已付款、定金、质量扣款；损失构成与减损动作；准据法；法域。

用户希望唯一金额，不构成把未知写成零的授权。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关文书；`C#` 合同条款；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求假设；`EVT#` 同一经济事件；`M#` 测算行；`V#` 工作表版本；`E#` 付款凭证。

金额状态只用 `已核实金额`、`情景金额`、`无法估计`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典第 584、585、591、592 条、合同编通则解释和 CISG 损害赔偿规则是否适用。工具不可用时继续分项建账；调整结论和法定上限字段停止。

## 五个判断节点

执行顺序和停止条件以 [测算方法](references/method.md) 为准。

### 1. 专项分流和测算范围

海事、税务、侵权主轴转出。不把违约写成已经成立。

### 2. 事件编号与分项建账

价款、质量扣减、迟延、违约金、直接损失、可得利益、定金、已付款分列。币种单列。

### 3. 调整与条约接口

约定数字不是必得。过分高于对照损失。CISG 与国内法不得双计同一损失。

### 4. 可预见、减损、双方违约

各成一行，不合成“应赔”。

### 5. 互斥、情景区间和缺口

禁止唯一必得总额。表面有效仲裁不得写应起诉。

## 停止与安全

- `整体停止`：伪造流水、把未知当零、隐匿已收款。
- `字段停止`：准据法、调整规则、汇率依据未核验。
- `目标停止`：主目标变为总图、发函或仲裁申请。
