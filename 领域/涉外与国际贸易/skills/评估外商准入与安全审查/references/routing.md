# 边界与路由

## 正触发

外国投资者拟在中国境内投资，需要判断负面清单和安全审查，而不是写交易文件。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 股权买卖、交割、目标尽调 | 投资并购领域 |
| 经营者集中 | 竞争法领域 |
| 境外投资备案核准 | `评估境外投资监管准入`（未安装则 `unavailable`） |
| 安全审查专项深挖 | `评估外商投资安全审查`（未安装则 `unavailable`） |
| 信息报告填报 | `准备外商投资信息报告材料`（未安装则 `unavailable`） |
| 返程或 VIE 结构 | `评估返程投资与协议控制监管`（未安装则 `unavailable`） |
| 税负或架构税务 | 税务领域 |
| 只要总图 | `评估跨境事项总图` |

## 专项整案转出

境内中国投资者之间的股权交易无外国投资者 → 不属本任务。协议控制被用来绕开负面清单 → 不提供绕开方案，标停止并转返程原子或说明 `unavailable`。

## 易混

清单外行业仍可能要安全审查。信息报告完成不等于准入批准。审查期间签署交割文件仍可能构成“实施投资”。
