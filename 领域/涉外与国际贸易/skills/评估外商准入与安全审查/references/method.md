# 评估方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出“已经获批”或“清单外绝对安全”。

不得使用已失效的外商投资企业设立及变更备案管理暂行办法。不得把 2024 年版负面清单写成“已经不会再改”。条约更优惠待遇须有可回链条约依据。

## Q# 准入假设

固定列：`编号｜准入类型｜义务主体｜机关｜法律效果｜成立条件｜支持事实｜不利事实｜控制方｜最强反方｜主备位｜判断｜待核`。

至少分列：`Q-禁` 禁止实施；`Q-限` 限制措施可满足性；`Q-国` 清单外国民待遇；`Q-安` 安全审查申报；`Q-报` 信息报告；`Q-许` 行业许可接口。

## 节点 0　专项分流

| 信号 | 转出 |
| --- | --- |
| 主成果是 SPA、资产购买、交割清单、目标尽调 | 投资并购领域 |
| 营业额或控制权触发经营者集中 | 竞争法领域；可与安全审查并行，但不在本任务做集中申报 |
| 中国主体对外投资 | ODI 原子或 `unavailable` |
| 税负最小化架构 | 税务领域 |
| 用协议控制绕开禁止或限制 | 不提供绕开方案，该部分整体停止 |

## 节点 1　投资画像

1. 外国投资者包括直接投资者和可识别的间接上层。上层不明：外国投资者定性 `依据不足`。
2. 投资方式对照安全审查办法第二条：新设项目或企业、并购股权或资产、其他方式。协议控制、表决权安排、收益权纳入“其他方式”待核，不得直接排除。
3. 行业用实际经营业务判断，不用营业执照名称粉饰。多种业务分别对照清单。
4. 自贸试验区或特别措施另有清单的，运行时核验，不得凭记忆写“自贸区一律放开”。

---

## 节点 2　负面清单

1. 核验现行《外商投资准入特别管理措施（负面清单）》版本和施行日。2024 年版自 2024-11-01 施行；若已被更新，以更新文本为准。
2. 禁止类：现有依据支持不得实施。不得设计代持或 VIE 绕开。
3. 限制类：逐条核验股比、合资要求、高管国籍等。条件事实不足 → `Q-限` `依据不足`，不得写成可以交割。
4. 清单未列出的领域：给予国民待遇（外商投资法第四条），但仍可能受安全审查、行业许可、文化金融等现行措施约束。清单说明中的保留措施必须核验。
5. 经国务院有关主管部门审核并报国务院批准的特定投资例外，不得由本任务主张已经适用。
6. 国际条约更优惠待遇：须指出条约名称和条款，否则不得写入。

---

## 节点 3　安全审查

1. 主动申报范围（安全审查办法第四条）分两支：
   - 军工、军工配套等关系国防安全的领域，以及军事设施和军工设施周边地域投资：不问控制权。
   - 重要农产品、能源资源、重大装备、重要基础设施、重要运输、重要文化、重要信息技术和互联网、重要金融服务、关键技术及其他重要领域，并取得实际控制权。
2. 实际控制权包括：持股 50% 以上；持股不足 50% 但表决权对董事会或股东会决议有重大影响；其他对经营、人事、财务、技术有重大影响的情形。协议控制、否决权、董事提名权必须列入评估，不得只看股比。
3. 工作机制办公室有权要求申报。当事人认为明显不在范围仍可能被要求申报：标红旗。
4. 审查分为一般审查和特别审查。决定审查后一般审查期间自决定之日起 30 个工作日的规则须核验。审查期间当事人不得实施投资（第八条）。
5. 不得预测“会通过”或“会禁止”。材料清单见第六条，本任务只列接口，不写申报书终稿。
6. 反垄断法第 38 条：外资并购涉及国家安全的，集中审查之外仍须安全审查。两项并行，不互相替代。

---

## 节点 4　信息报告与行业许可

1. 信息报告（初始、变更、年度）按外商投资信息报告办法。未报告的后果是信用和行政处罚接口，不是“投资无效”的当然结论。
2. 不得把报告系统截图写成批准证书。
3. 金融、文化、电信、教育等行业许可或审批准入单独列表。清单未列不等于无许可。
4. 网络安全审查等并行制度只标接口，不在本任务做数据或网安结论。

---

## 节点 5　实施前停止与下一步

1. 禁止类或审查期间：停止实施投资，包括不得完成股权过户、支付主要对价或实际接管经营。
2. 限制条件未闭合：交割条件标待核，交易文件转并购领域。
3. 下一步：补结构事实、核验现行清单、准备安全审查材料、信息报告、转并购律师写交易文件。
4. 用户坚持抢先交割：该部分整体停止，不提供“先交割后补报”的方案。
