# 边界与路由

## 正触发

关键证据在境外，需要合法取证和认证规划。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 违法调取方案 | 拒绝并停止 |
| 境内证据建卷 | `建立跨境争议证据与认证案卷` |
| 只要认证 | `规划公证认证与附加证明书` |
| 船上取证 | 海事领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侵入邮箱或服务器 | 整体停止 |
| 司法协助申请终稿 | P2，输出 unavailable 接口 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

当地律师合法取证不等于可以规避海牙协助。云服务器在境外可能仍受当地数据法约束。
