# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、路径、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然获批、必然解除、必然承认或唯一必得总额。

港澳台不是外国。纽约公约和外国判决互惠路径不得套用。安排被修订或补充的，以现行文本条号为准，不得沿用已失效安排条文。

`search_law` 返回已失效《合同法》及其解释、法释〔1999〕19 号、法释〔2007〕14 号或已废外资备案办法时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜区际类型｜文书种类｜安排名称待核｜入口法院或机构｜成立条件｜支持事实｜不利事实｜判断｜待核`。

至少分列：

- `Q-定 区际定性（非外国）`
- `Q-裁 仲裁裁决认可`
- `Q-判 民商事判决认可`
- `Q-送 区际送达`
- `Q-证 区际取证或公证`

同一事实支持多项时分别说明效果，不重复金额。构成违约不等于当然解除。约定外法不等于可以无证出口或绕开准入。

## 节点 0　定性闸

| 文书或事实 | 处置 |
| --- | --- |
| 香港、澳门、台湾作出的裁决或判决 | 本任务正触发，禁止套公约 |
| 在中国领域外其他国家作出的裁决 | 负触发，转 申请承认和执行外国仲裁裁决 |
| 外国法院判决 | 负触发，转 申请承认和执行外国法院判决 |
| 离婚、收养、监护 | 家事领域 |
| 船舶扣押、海事赔偿责任限制 | 海事领域 |

作出地不明：区际定性 `依据不足`，停止安排适用结论。

## 节点 1　主体、财产和文书识别

1. 写明哪一方、哪笔财产、哪份文书位于香港、澳门或台湾。三地分列，不合成“港澳台一套办法”。
2. 仲裁裁决与法院判决分列；调解书、司法确认、仲裁和解的可认可性运行时核验，不得一律纳入或排除。
3. 若：财产同时在内地和香港 → 认可入口与执行财产地分列，不选定唯一策略冒充已可执行。

## 节点 2　安排入口

1. 香港、澳门民商事判决安排与仲裁裁决安排分别核验适用范围、排除事项、管辖法院。
2. 台湾地区民事判决、裁定、调解书、支付令的认可按现行规定核验，不得直接套港澳安排。
3. 若：文书属于安排明确排除的事项（例如部分知识产权效力、部分仲裁地）→ 标排除，不改写为外国路径。
4. 内地作出、需在港澳台认可：对向安排另列，本任务可做接口但不冒充已按对方法域完成。

## 节点 3　不予认可事由和期间

1. 专属管辖、程序权利、欺诈、公共秩序、既判冲突等事由按该安排文本分列，不得用纽约公约第五条替代。
2. 申请期间、中止、撤回按安排和民事诉讼法相关解释核验。不得写“一律两年”。
3. 已在一地申请认可又在另一地起诉：平行程序红旗，不指导重复获利。

## 节点 4　文书形式与送达取证

1. 区际文书传递、送达、取证走安排或互助协议，不走海牙送达公约的“外国”口径。
2. 公证认证：港澳文书在内地使用的证明手续按现行规定核验，不得要求外国领事认证。
3. 送达失败不得伪造签收。取证不得指导违法跨境调取。

## 节点 5　下一步

1. 输出：区际定性、安排入口、排除事项、文书和期间缺口、下一步是申请认可还是仅规划文书。
2. 申请认可的具体文书另转相应申请原子；本任务不代写申请书终稿，除非用户已转到该原子。
3. 用户坚持按纽约公约提交港澳裁决：负触发并说明定性错误。
