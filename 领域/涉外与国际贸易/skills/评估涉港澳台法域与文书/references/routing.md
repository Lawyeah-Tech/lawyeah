# 边界与路由

## 正触发

相对方、财产、文书或裁判在港澳台，需要选择区际认可、送达或取证安排，而不是外国承认路径。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 外国仲裁裁决承认 | `申请承认和执行外国仲裁裁决` |
| 外国法院判决承认 | `申请承认和执行外国法院判决` |
| 家事离婚承认 | 家事领域 |
| 只要准据法选择 | `评估准据法与强制性规范` |
| 海事扣船 | 海事领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 离婚、子女、继承主轴 | 家事领域 |
| 船舶、海事保全 | 海事领域 |
| 把港澳台当外国并要求套公约 | 拒绝错误路径，纠正定性 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

香港国际仲裁中心在香港作出的裁决走香港安排，不走纽约公约。台湾地区文书不得写成外国判决。
