# 评估涉港澳台法域与文书

## 任务目标

在明确、无利益冲突的单方立场下，形成区际定性、认可或协助安排入口、文书路径，而不把港澳台文书写成外国裁决或外国判决。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：相对方、财产、文书或裁判在港澳台，需要选择区际认可、送达或取证安排，而不是外国承认路径。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 把港澳台裁决或判决按外国文书处理；
- 家事离婚承认作为主成果；
- 只要普通准据法选择且无区际程序；
- 海事专属或船舶扣押主轴；

不按外国裁决或外国判决处理。家事离婚承认转家事。

## 建立评估坐标

确认：主体注册地或住所；财产所在地；文书作出地；要在内地使用还是在港澳台使用；已有裁决、判决还是仅有合同；安排文本版本待核。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 裁判或公证文书；`C#` 合同或安排条款；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 区际路径；`V#` 评估版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。未知金额不写零。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验内地与香港、澳门相互认可和执行民商事判决、仲裁裁决的安排，以及台湾地区有关法院民事判决的认可规定；送达和取证安排单独核验。安排文本以现行公布为准，被修订则以新文本为准。工具不可用时继续做区际定性；认可条件、期间字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　定性闸

港澳台不是外国。离婚转家事，扣船转海事。作出地不明则停止安排结论。

### 节点 2　主体财产文书识别

三地分列。裁决与判决分列。

### 节点 3　安排入口

判决安排与裁决安排分别核验。台湾不套港澳文本。

### 节点 4　不予认可与期间

不得用纽约公约第五条替代。不写一律两年。

### 节点 5　文书形式和下一步

不走外国领事认证。坚持套公约则纠正定性。

## 停止与安全

- `整体停止`：立场不明；坚持把港澳台文书当外国裁决提交。
- `字段停止`：安排现行文本、期间、排除事项未核验。
- `目标停止`：主目标变为家事离婚承认或海事扣船。
