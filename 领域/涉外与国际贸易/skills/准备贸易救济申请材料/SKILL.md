# 准备贸易救济申请材料

## 任务目标

在明确、无利益冲突的申请方立场下，形成申请要点、产业代表性和证据缺口；不保证立案。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：国内产业拟申请反倾销、反补贴或保障措施，本次主成果是申请材料要点。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 保证立案或征税；
- 应诉材料；
- 伪造产量或进口数据；

不保证立案。不伪造产业数据。

## 建立评估坐标

确认：申请措施类型；国内同类产品；申请人产量占比；进口来源；损害证据线索；是否已与商会沟通。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 产量和进口统计；`A#` 申请人范围；`R#` 既有调查史；`C#` 销售证据；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 申请项；`V#` 材料版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。未知金额不写零。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验反倾销条例申请条件和商务部立案实践接口。代表性比例必须对照现行条文。工具不可用时继续做申请人和产品编目；代表性是否满足的结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　任务闸

应诉转出。伪造停止。不保证立案。

### 节点 2　同类产品

税号只是线索。范围过宽过窄都影响损害。

### 节点 3　代表性

沉默不写成支持。关联进口商须披露。

### 节点 4　初步证据

未知不写零。其他致损因素必须列出。

### 节点 5　交付

缺公开文本不可称可提交。不代提交。

## 停止与安全

- `整体停止`：伪造数据；保证立案。
- `字段停止`：代表性门槛、立案条件未核验。
- `目标停止`：主目标变为应诉或保证征税。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
