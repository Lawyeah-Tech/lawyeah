# 边界与路由

## 正触发

国内产业拟申请反倾销、反补贴或保障措施，本次主成果是申请材料要点。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 应诉材料 | `准备贸易救济应诉材料` |
| 保证立案 | 拒绝保证 |
| 风险总评 | `评估反倾销反补贴保障措施风险` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 伪造产业数据 | 整体停止 |
| 联合抵制竞争法 | 竞争法领域红旗 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

商会支持信不是代表性的全部。进口统计口径与产品范围不一致时不能直接当倾销证据。
