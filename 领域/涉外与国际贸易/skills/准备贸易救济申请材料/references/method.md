# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、路径、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然获批、必然解除、必然承认或唯一必得总额。

申请书不得编造进口价格或国内产业亏损。代表性未达法定门槛则材料包标 `部分形成`，不伪称可以立案。

`search_law` 返回已失效《合同法》及其解释、法释〔1999〕19 号、法释〔2007〕14 号或已废外资备案办法时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜申请要件｜现状｜缺口｜判断｜待核`。

至少分列：

- `Q-产 同类产品`
- `Q-代 产业代表性`
- `Q-倾 倾销或补贴初步证据`
- `Q-损 损害初步证据`
- `Q-因 因果`

同一事实支持多项时分别说明效果，不重复金额。构成违约不等于当然解除。约定外法不等于可以无证出口或绕开准入。

## 节点 0　任务闸

应诉 → 应诉原子。保证立案 → 拒绝。伪造数据 → 停止。竞争法意义上的联合抵制 → 竞争法红旗。

## 节点 1　同类产品

1. 国内产品与进口产品的物理、用途、竞争性。范围过宽或过窄都影响立案和损害。
2. 税号只是线索。

## 节点 2　代表性

1. 申请人产量占国内同类产品的比例门槛按条例核验。
2. 支持者、反对者、沉默者分列。不得把未表态写成支持。
3. 关联进口商身份可能影响资格，必须披露。

## 节点 3　初步证据

1. 倾销或补贴的公开初步证据（价格、出口统计、补贴项目名单）。
2. 损害：产量、价格、利润、就业等指标时间线。未知不写零。
3. 因果：其他因素（需求下降、自我竞争）必须作为不利事实列出。

## 节点 4　保密与公开文本

申请书通常需公开文本。缺公开文本不得写成可提交。

## 节点 5　交付

输出要件表、代表性计算接口、证据缺口。不保证立案。不代提交。

## 补充判断

若：申请人同时进口被调查产品 → 资格和损害主张都受影响，必须披露，不得隐瞒进口身份。
若：产量数据来自行业协会估算而非企业报表 → 标为估算，不得写成已审计产量。
若：支持申请的企业事后撤回支持 → 代表性重新计算，材料包不得仍写原比例。
若：补贴项目清单抄自过期报告 → 不得写入申请书作为现行补贴。
立案前对外披露申请细节可能影响证据，标保密纪律。

## 追加判断
若：国内产业仅三家且两家反对申请 → 代表性现有依据不支持，材料包不得写成已满足。若：进口激增主要来自第三国而非被申请国 → 因果主张必须处理该不利事实。申请书草稿中的幅度测算只作内部接口，不写成机关必然采纳。

若：同一事实同时支持请求和抗辩 → 分列效果，不合并成一笔结论，也不重复计算金额。
若：机关或机构文书的作出日与收到日冲突 → 两套起算并行，期限字段停止，不得挑选对用户有利的日期。
若：需要引用域外实体法而未能查明 → 不得用中国法填空冒充已查明，该路径标依据不足。
本任务不输出胜诉率、必然获批、必然撤销、必然承认或唯一必得总额。未知金额不写零。
