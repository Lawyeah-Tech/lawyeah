# 边界与路由

## 正触发

已决定申请财产、行为或证据保全，且主轴不是海事扣船。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 海事保全扣船 | 海事领域 |
| 应对保全裁定 | `应对涉外保全裁定` |
| 自行货物公证 | `保全货物检验与电子通信证据` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 伪造财产线索 | 整体停止 |
| 违法定位账户 | 整体停止 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

仲裁案件保全仍可能要找法院。有担保不等于会裁定。
