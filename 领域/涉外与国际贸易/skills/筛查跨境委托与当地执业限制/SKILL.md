# 筛查跨境委托与当地执业限制

## 任务目标

在明确、无利益冲突的单方立场下，形成利益冲突表、当地执业红旗和合作律师接口，而不替代实体评估、不定境外执业资格。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：接案前需要判断利益冲突、当地出庭或咨询限制、共同代理安排，本次主成果是委托筛查。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 已接案且只要实体评估；
- 要求认定某人具有境外律师资格；
- 只要利益冲突意见对外出具给监管机构终稿且无事实；

不替代实体评估。不定境外执业资格。不提供无证执业方案。

## 建立评估坐标

确认：拟代表的一方；相对方及关联方；本所及经办律师已有委托；事项将发生的法域和程序（咨询、谈判、仲裁、诉讼、调查）；是否需要在境外出庭或签署当地文书；拟合作的当地律师。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 利益冲突检索记录；`A#` 客户确认；`R#` 已有委托或法院手续；`C#` 原委托范围；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 冲突或执业假设；`V#` 筛查版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。未知金额不写零。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。

- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验律师法、律师执业管理办法关于利益冲突和禁止行为，以及中国律师境外执业、与境外律师合作的现行规定。当地出庭资格以该法域规则为准，本任务不得认定资格成立。工具不可用时继续做冲突检索编目；执业许可结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　任务闸

已接案走实体原子。双方代理停止。不定境外资格。

### 节点 2　利益冲突检索

名单不全则不得写成可以接案。口头放弃不够。

### 节点 3　行为法域定性

中国法咨询与境外出庭分列。仲裁出庭资格待核。

### 节点 4　合作律师与委托范围

不保证某所资格。概括委托不足以授权和解或应调查。

### 节点 5　处置和下一步

只有继续、有条件、拒绝、引入当地律师四态。不给实体结论。

## 停止与安全

- `整体停止`：同时代表冲突双方；要求无证执业或伪造当地资格。
- `字段停止`：律师冲突规则、仲裁代理资格、当地出庭规则未核验。
- `目标停止`：主目标变为实体评估或出具境外资格认定。
