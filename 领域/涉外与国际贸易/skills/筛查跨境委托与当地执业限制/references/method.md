# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、路径、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然获批、必然解除、必然承认或唯一必得总额。

中国律师不得以中国执业证冒充境外出庭资格。不得指导无证从事当地法律服务。利益冲突不得用“客户说没问题”单独消除。

`search_law` 返回已失效《合同法》及其解释、法释〔1999〕19 号、法释〔2007〕14 号或已废外资备案办法时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜筛查项｜涉及主体｜法域｜限制类型｜支持事实｜不利事实｜处置｜判断｜待核`。

至少分列：

- `Q-冲 利益冲突`
- `Q-密 秘密与信息隔离`
- `Q-执 当地执业或出庭限制`
- `Q-合 合作律师接口`
- `Q-授 委托范围与授权`

同一事实支持多项时分别说明效果，不重复金额。构成违约不等于当然解除。约定外法不等于可以无证出口或绕开准入。

## 节点 0　任务闸

| 信号 | 处置 |
| --- | --- |
| 已决定接案且只要实体结论 | 负触发，转相应实体原子 |
| 要求出具“某人是某国律师”的资格认定 | 负触发，不定资格 |
| 要求规避当地无证执业查处 | 整体停止 |
| 刑辩接案手续为主 | 刑事领域 |

同时拟代表利益直接冲突的双方：整体停止策略输出。

## 节点 1　利益冲突检索

1. 列出本所、团队、经办律师对相对方、关联方、共同侵权人或共同申报义务人的既有委托和秘密。
2. 现委托与拟委托是否直接冲突、是否可在知情同意和隔离措施下继续，运行时核验律师法和执业规范。
3. 若：冲突检索未做或客户名单不全 → `Q-冲` `依据不足`，不得写成可以接案。
4. 曾经的对方顾问、数据室访问、报价阶段收到的对方秘密：单独标红旗。

## 节点 2　事项法域与行为定性

1. 将拟实施行为分成：中国法咨询、中国程序代理、境外法咨询、境外程序出庭或签署、与当地律师共同出具意见。
2. 仅提供中国法意见且不在境外持自己为当地律师：当地执业红旗较低，但仍须披露意见范围。
3. 若：用户要求中国律师在外国法院或外国仲裁庭以当地律师身份出庭 → `Q-执` 现有依据不支持，转合作律师。
4. 国际仲裁作为代理人的资格取决于仲裁地、机构和规则，未核验则字段停止，不得写“仲裁一定可以出庭”。

## 节点 3　合作律师接口

1. 需要当地律师时，输出接口：委托范围切割、共同利益冲突、秘密共享、费用、意见依赖边界。
2. 不得指定或保证某家境外律所具备资格。资格由对方自行证明，本任务只列核验项。
3. 共同代理协议若未成争而要起草：审查起草搁置，只列必备条款接口。
4. 当地律师与中国律师结论冲突时，本任务不选边冒充已统一。

## 节点 4　委托范围与授权

1. 委托合同范围必须能覆盖拟实施行为。概括“处理一切涉外事务”不足以授权出庭、和解或接受调查约谈。
2. 境外授权书形式转认证规划原子。
3. 若：客户要中国律师代为签署当地监管申报且当地法要求本地持证主体 → 标停止，改由当地合格主体签署。

## 节点 5　处置和下一步

1. 处置仅能是：可继续／有条件继续（知情同意+隔离）／必须拒绝／必须引入当地律师。不输出“可以无证做完”。
2. 下一步：完成冲突检索、限定委托范围、接洽当地律师、再进入实体原子。
3. 本筛查不是实体评估，不得在本节给出准据法或胜诉判断。
