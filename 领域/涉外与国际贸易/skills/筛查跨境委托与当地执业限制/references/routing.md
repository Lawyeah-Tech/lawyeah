# 边界与路由

## 正触发

接案前需要判断利益冲突、当地出庭或咨询限制、共同代理安排，本次主成果是委托筛查。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 已接案只要实体评估 | `评估跨境事项总图` |
| 认定境外律师资格 | 不定资格，只列核验项 |
| 无证执业方案 | 拒绝，整体停止 |
| 刑辩手续 | 刑事领域 |
| 起草共同代理协议 | 审查起草领域（本窗搁置） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 刑事辩护接案与会见 | 刑事领域 |
| 中国劳动争议代理手续 | 劳动领域 |
| 海事法院专门代理手续 | 可留本任务执业红旗，程序主轴转海事 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

能做中国法备忘录不等于能在当地出庭。客户放弃冲突必须有书面知情同意，口头不够。
