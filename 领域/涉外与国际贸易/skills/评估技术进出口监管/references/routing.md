# 边界与路由

## 正触发

技术许可或转让需要禁止、限制或自由类判断，本次主成果是监管分类。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 起草许可合同 | 审查起草领域（本窗搁置） |
| 权属侵权 | 知识产权领域 |
| 数据出境 | 数据领域 |
| 两用许可材料 | `准备两用物项或出口许可材料` |
| 把禁止类改自由类 | 拒绝并停止 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 出口管制物项技术 | `评估出口管制与制裁风险` |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

自由类登记完成不等于不受出口管制。专利许可备案不是技术进出口登记。
