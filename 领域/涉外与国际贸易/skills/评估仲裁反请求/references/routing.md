# 边界与路由

## 正触发

被申请人拟在中国涉外仲裁中提反请求，需要条件与期限判断。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 诉讼反诉 | `应对中国法院涉外民事诉讼` |
| 仲裁主请求 | `提起中国涉外仲裁` |
| 自动终稿且条件未闭合 | 停止终稿，只出草案 |
| 仲裁应诉总包 | `应对中国涉外仲裁` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 伪造反请求债权 | 整体停止 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

反请求不是自动抵销。逾期提出不必然被接受。
