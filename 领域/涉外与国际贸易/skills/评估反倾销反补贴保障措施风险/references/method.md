# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、路径、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然获批、必然解除、必然承认或唯一必得总额。

不得编造倾销幅度。正常价值、出口价格、损害与因果关系未核验不得写成“一定征税”。规避税率方案停止。

`search_law` 返回已失效《合同法》及其解释、法释〔1999〕19 号、法释〔2007〕14 号或已废外资备案办法时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜措施类型｜产品范围｜角色（应诉／申请）｜接口｜判断｜待核`。

至少分列：

- `Q-范 产品范围`
- `Q-倾 倾销接口`
- `Q-补 补贴接口`
- `Q-损 损害接口`
- `Q-分 应诉或申请分流`

同一事实支持多项时分别说明效果，不重复金额。构成违约不等于当然解除。约定外法不等于可以无证出口或绕开准入。

## 节点 0　任务闸

问卷终稿 → prepare-trade-remedy-response。国内申请材料 → prepare-trade-remedy-petition。第三国组装规避 → assess-anti-circumvention-origin。
保证不立案：拒绝。改产地伪装：停止。

## 节点 1　产品与程序画像

1. 税号、物理特征、用途决定产品范围，宣传名不决定。
2. 调查机关、立案日、登记应诉期限、抽样。外国程序规则未核验则期限字段停止。
3. 中国对内调查与国外对华调查分列，不得混用条例。

## 节点 2　倾销补贴损害接口

1. 倾销：正常价值与出口价格比较只列接口，不算幅度。
2. 补贴：专项性、利益、可诉性待核，不把所有政府优惠写成补贴。
3. 保障措施看进口激增与严重损害，不要求倾销。
4. 损害与因果材料不足：`依据不足`。

## 节点 3　税率与单独税率红旗

1. 历史税率、分别税率、全国税率只作红旗。
2. 关联出口商可能被合并，结构不明则标缺口。
3. 不得建议通过改发票价格做低倾销。

## 节点 4　分流

1. 已被立案且决定应诉 → 应诉原子。
2. 国内产业拟申请 → 申请原子。
3. 尚未决定：只输出风险和选项，不指定必须应诉。

## 节点 5　下一步

输出范围、接口、期限红旗、分流。不写问卷。不预测终裁。

## 补充判断

若：产品范围在立案公告与税则号不完全重合 → 以公告产品描述为主，税号只作线索，不得自行扩到公告未列型号。
若：中国作为进口调查国 → 适用中国反倾销、反补贴或保障措施条例；作为出口应诉方 → 适用进口国程序，两条不得混用条文。
若：关联出口商通过第三国开票 → 分别税率资格红旗，不提供改开票方案。
若：用户要“先不应诉看初裁” → 说明可能适用不利事实，但不代替客户作应诉决定。
损害指标未知时不写零，标缺口。
