# 边界与路由

## 正触发

出口市场立案或国内产业拟申请反倾销、反补贴或保障措施，需要风险和路径评估。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 问卷终稿 | `准备贸易救济应诉材料` |
| 申请材料 | `准备贸易救济申请材料` |
| 规避改产地 | `评估规避贸易救济与原产地风险` |
| 保证不征税 | 拒绝保证 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 改发票做低价格 | 整体停止 |
| 关税计算税负 | 税务领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

立案不等于已经征税。不应诉可能被用不利事实，但是否应诉由客户决定。
