# 评估反倾销反补贴保障措施风险

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成产品范围、倾销或补贴或损害接口、应诉或申请分流；不写调查问卷终稿。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：出口市场立案或国内产业拟申请反倾销、反补贴或保障措施，需要风险和路径评估。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 写调查问卷终稿；
- 保证不立案或不征税；
- 规避税率的改产地方案；

不写调查问卷终稿。不保证立案或税率。不提供规避伪装。

## 建立评估坐标

确认：产品；出口市场或进口国；已立案公告；调查期；出口商或国内产业角色；是否有单独税率历史；关联出口商。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 立案公告；`A#` 出口或产量数据线索；`R#` 调查机关文书；`C#` 销售合同；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 风险假设；`V#` 评估版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。未知金额不写零。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验反倾销条例、反补贴条例、保障措施条例及对应出口市场只作冲突输入。中国作为进口调查国的规则与作为出口应诉国的外国规则分列。工具不可用时继续做产品范围编目；倾销幅度或必然征税结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　任务闸

问卷、申请、规避转出。保证不立案拒绝。

### 节点 2　产品与程序

税号和物理特征定范围。中外程序分列。

### 节点 3　倾销补贴损害

只列接口不算幅度。保障措施不要求倾销。

### 节点 4　税率红旗

关联出口商可能合并。不得改发票。

### 节点 5　分流与下一步

不指定必须应诉。不预测终裁。

## 停止与安全

- `整体停止`：规避税率伪装；编造倾销幅度。
- `字段停止`：立案公告、应诉期限、条例条文未核验。
- `目标停止`：主目标变为问卷终稿或申请书。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
