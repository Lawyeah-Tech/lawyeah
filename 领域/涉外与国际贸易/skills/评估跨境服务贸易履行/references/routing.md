# 边界与路由

## 正触发

外包、许可实施或跨境服务未完成或拒付已成争，本次主成果是服务履行评估。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 数据出境专项 | 数据领域 |
| 在华用工 | 劳动领域 |
| 技术进出口分类 | `评估技术进出口监管` |
| 货物质量 | `评估国际货物交付质量数量` |
| 起草许可合同 | 审查起草领域（本窗搁置） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 出口管制技术服务 | `评估出口管制与制裁风险` |
| 境外用工当地法 | `评估境外用工当地法与派遣准入` |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

甲方未验收不等于可以无限期拒付。人员已入境工作不能只当服务成果验收处理。
