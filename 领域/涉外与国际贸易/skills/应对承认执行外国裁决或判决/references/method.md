# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、路径、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然获批、必然解除、必然承认或唯一必得总额。

公共秩序不用于重审实体。被申请人未获指定或陈述机会须有事实。不得指导转移财产。报核只标红旗。

`search_law` 返回已失效《合同法》及其解释、法释〔1999〕19 号、法释〔2007〕14 号或已废外资备案办法时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜文书类型｜抗辩事由｜事实｜程序权利｜判断｜待核`。

至少分列：

- `Q-类 裁决或判决`
- `Q-公 公约或条约抗辩`
- `Q-序 程序权利`
- `Q-序2 公共秩序`
- `Q-履 已履行`

同一事实支持多项时分别说明效果，不重复金额。构成违约不等于当然解除。约定外法不等于可以无证出口或绕开准入。

## 节点 0　定性闸

己方是权利人 → 相应申请原子。港澳台 → 区际。转移财产 → 停止。
裁决与判决抗辩清单不同，必须先定性。

## 节点 1　程序权利

1. 是否收到仲裁通知或起诉状、是否有机会陈述。
2. 缺席本身不等于程序违法。
3. 送达合法性按作出地和公约待核。

## 节点 2　公约或条约事由

1. 外国裁决：第五条第一、二项分列。
2. 外国判决：条约或民诉法事由，不套第五条。
3. 超裁、协议无效、不可仲裁分别回链。

## 节点 3　公共秩序

仅例外。普通违约金高低不够。与强制规范专项可转介。

## 节点 4　已履行与担保

已履行必须披露。提供担保暂缓执行只标接口，不保证。

## 节点 5　意见草稿

按类型组织抗辩。不代提交。禁止隐匿财产。

## 通用停止与并行情景

若：日期、地址或文本版本冲突 → 建并行情景，不选对用户有利的一版写成已确定。
若：规则未核验 → 依赖该规则的法律结论、期限或机关路径字段停止，不拒绝处理事实编目。
若：用户要求伪造、隐匿、规避许可、改名绕名单或违法取证 → 该部分整体停止。
海上运输、船舶、海事保全、共同海损一律转海事领域。
未成争只要改合同或出稿：审查起草本窗搁置，只说明不实施。

## 补充判断X
若：文书类型未定 → 停止承认抗辩结论。
若：已履行未披露 → 策略停止。
若：公共秩序仅因败诉 → 现有依据不支持。

若：同一事实同时支持请求和抗辩 → 分列效果，不合并成一笔结论，也不重复计算金额。
若：机关或机构文书的作出日与收到日冲突 → 两套起算并行，期限字段停止，不得挑选对用户有利的日期。
若：需要引用域外实体法而未能查明 → 不得用中国法填空冒充已查明，该路径标依据不足。
