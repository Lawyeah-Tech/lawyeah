# 边界与路由

## 正触发

已收到承认执行外国裁决或判决的申请，需要抗辩。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 权利人申请承认裁决 | `申请承认和执行外国仲裁裁决` |
| 权利人申请承认判决 | `申请承认和执行外国法院判决` |
| 转移财产 | 拒绝并停止 |
| 港澳台 | `评估涉港澳台法域与文书` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 隐匿财产 | 整体停止 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

承认程序不是上诉审。未参加外国程序不等于当然不予承认。
