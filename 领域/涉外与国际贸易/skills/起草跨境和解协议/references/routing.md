# 边界与路由

## 正触发

条件已谈拢，需要可签的跨境和解协议。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 条件未谈拢 | `谈判跨境争议和解方案` |
| 未成争补充协议 | 审查起草领域（本窗搁置） |
| 司法确认申请 | 另项，本任务不写申请终稿 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 和解安排违法履行 | 整体停止 |
| 处分未参与第三人权利 | 停止该条款 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

和解协议不是原买卖合同的普通补充。撤裁或撤诉手续未完成，和解可能只是合同。
