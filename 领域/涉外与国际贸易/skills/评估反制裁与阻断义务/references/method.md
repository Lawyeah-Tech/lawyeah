# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、路径、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然获批、必然解除、必然承认或唯一必得总额。

不得输出“为了做成生意可以先违反一边再补”。不定外国刑法。反制裁法项下的反制措施由有权部门决定，本任务不得虚构已发布的反制命令。

`search_law` 返回已失效《合同法》及其解释、法释〔1999〕19 号、法释〔2007〕14 号或已废外资备案办法时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜外国措施｜中国规范｜义务类型（报告／禁止执行／反制）｜民事接口｜判断｜待核`。

至少分列：

- `Q-阻 阻断办法报告与禁令`
- `Q-反 反制裁措施`
- `Q-报 报告义务`
- `Q-民 民事诉讼红旗`
- `Q-冲 合同继续履行冲突`

同一事实支持多项时分别说明效果，不重复金额。构成违约不等于当然解除。约定外法不等于可以无证出口或绕开准入。

## 节点 0　安全闸

规避方案、选边违法 → 停止。外国刑法定性 → 不定，可标境外律师接口。单纯名单筛查 → 筛查原子。
不可靠实体措施 → 该专项。

## 节点 1　冲突画像

1. 外国措施要求停止的行为，与在中国的合同义务或部门命令是否相反。
2. 无中国连结：阻断适用 `依据不足`。
3. 合同制裁条款不能授权违反中国强制规范。

## 节点 2　阻断办法

1. 报告时点、报告机关、禁止执行的命令是否已经作出，分列。
2. 未作出禁止执行命令时，不得写成已经禁止遵守外国法。
3. 报告内容不得含虚假。

## 节点 3　反制裁法

1. 反制措施种类（签证、财产、交易禁止等）以已公布措施为准。
2. 当事人是否被列入、是否与被列入主体交易：回链公布。
3. 民事诉讼请求停止执行外国措施的接口只标红旗，不写起诉状。

## 节点 4　合同效果

1. 继续履行可能撞上外国措施或中国禁令：履行不能转不可抗力原子接口。
2. 不得建议伪造履约地点规避。
3. 解除或中止另转相应原子。

## 节点 5　下一步

输出义务表、已公布措施、不得实施项、境外律师接口。不选边指导违法。

## 补充判断

若：中国部门已作出禁止执行某外国措施的命令 → 遵守该命令，不得再提供“按外国法履行”的方案。
若：仅有外国客户律师函而无中国命令 → 阻断禁止执行未成立，报告义务是否触发仍待核。
若：反制裁法项下民事诉讼拟请求赔偿 → 只标接口，不写起诉状，不定赔偿额。
若：合同约定“遵守所有外国制裁” → 该条款与中国强制规范冲突时标红旗，不指导履行该条款去违反中国法。
境外刑法、罚款风险只提示需境外律师，不给外国法结论。

若：同一事实同时支持请求和抗辩 → 分列效果，不合并成一笔结论，也不重复计算金额。
若：机关或机构文书的作出日与收到日冲突 → 两套起算并行，期限字段停止，不得挑选对用户有利的日期。
若：需要引用域外实体法而未能查明 → 不得用中国法填空冒充已查明，该路径标依据不足。
本任务不输出胜诉率、必然获批、必然撤销、必然承认或唯一必得总额。未知金额不写零。
