# 边界与路由

## 正触发

外国次级制裁与中国反制裁或阻断规则冲突，需要义务评估而不是选边规避。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 改名规避 | 拒绝并停止 |
| 名单筛查 | `筛查交易对手与最终用户` |
| 不可靠实体应对 | `应对不可靠实体清单` |
| 外国刑法定性 | 不定境外刑法 |
| 履行不能总评 | `评估不可抗力禁运与履行不能` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 已公布反制名单上的具体措施执行 | 按公布措施，不扩写 |
| 刑事诉讼 | 刑事领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

收到外国银行停运通知不等于中国已禁止执行该外国法。未报告可能违法，但报告不是选择遵守外国制裁的许可。
