# 评估反制裁与阻断义务

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成报告义务、禁令接口和民事诉讼红旗；不指导违反任一法域的规避；不定境外刑法。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：外国次级制裁与中国反制裁或阻断规则冲突，需要义务评估而不是选边规避。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 指导遵守外国制裁而违反中国阻断或相反的规避方案；
- 认定外国刑法罪与非罪；
- 只要名单筛查；

不指导违反任一法域的规避。不定境外刑法。

## 建立评估坐标

确认：外国限制的内容；中国反制裁措施或阻断办法是否可能适用；当事人国籍与所在；是否已收到外国禁令或中国部门禁止执行的命令；交易是否必须在中国履行。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 外国律师函或中国部门文书；`A#` 已中止履行；`R#` 反制裁或阻断决定；`C#` 合同制裁条款；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 义务假设；`V#` 评估版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。未知金额不写零。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验反外国制裁法、阻断外国法律与措施不当域外适用办法。具体反制清单以公布为准。工具不可用时继续做冲突事实编目；报告和禁令结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　安全闸

选边违法停止。外国刑法不定。筛查转出。

### 节点 2　冲突画像

无中国连结则阻断适用不足。合同条款不能授权违法。

### 节点 3　阻断办法

无禁止执行命令不得写成已禁止遵守外国法。

### 节点 4　反制裁法

以已公布措施为准。民事诉讼只标接口。

### 节点 5　合同与下一步

履行不能转不可抗力接口。不伪造履约地。

## 停止与安全

- `整体停止`：选边违法规避；虚构已发布反制命令。
- `字段停止`：阻断办法、反制裁法、已公布措施未核验。
- `目标停止`：主目标变为名单筛查或外国刑法意见。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
