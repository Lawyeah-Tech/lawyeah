# 边界与路由

## 正触发

见索即付保函或备用证发生索赔或拟止付，本次主成果是独立保函评估。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 从属性保证 | 金融领域 |
| 海事担保 | 海事领域 |
| 商业信用证不符点 | `评估信用证不符点与拒付` |
| 虚假索赔方案 | 拒绝并停止 |
| 止付申请终稿 | `申请涉外或仲裁保全` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 船舶释放担保 | 海事领域 |
| 境内普通保证期间 | 金融领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

独立保函项下不能用主债未到期来拒付。止付不是重新审理基础合同。
