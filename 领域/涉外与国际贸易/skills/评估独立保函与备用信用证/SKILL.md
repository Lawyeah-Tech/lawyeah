# 评估独立保函与备用信用证

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成独立性判断、欺诈例外红旗和止付接口；从属性保证转金融；海事担保转海事。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：见索即付保函或备用证发生索赔或拟止付，本次主成果是独立保函评估。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 从属性保证、普通保证期间主轴；
- 海事担保、扣船担保；
- 信用证商业单据不符点主轴；

从属性保证转金融。海事担保转海事。不指导虚假索赔。

## 建立评估坐标

确认：保函或备用证文本；开立人；受益人；申请人；索赔书及所附单据；适用 URDG 或 ISP 是否写明；基础交易；是否已向法院申请止付。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 保函和索赔表面；`A#` 开立人电文；`R#` 止付裁定；`C#` 保函条款；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 独立性或欺诈假设；`V#` 评估版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。未知金额不写零。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验法释〔2016〕24 号独立保函解释及后续是否被吸收或条号调整。惯例文本以保函引用为准。工具不可用时继续做文本和索赔对照；止付条件结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　定性闸

从属保证转金融。海事担保转海事。虚假索赔停止。

### 节点 2　独立性

按实质定性。名称是保函但内容从属则转出。

### 节点 3　索赔表面相符

只审表面。基础是否违约不决定付款义务。

### 节点 4　欺诈例外

普通违约不够。证据标准高。已有裁定不重写。

### 节点 5　止付与分账

止付转保全接口。付款后追偿另列。

## 停止与安全

- `整体停止`：虚构基础违约索赔；指导无裁定拒付。
- `字段停止`：独立保函解释、惯例文本、止付条件未核验。
- `目标停止`：主目标变为从属保证整案或海事担保。
