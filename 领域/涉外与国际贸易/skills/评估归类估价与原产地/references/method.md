# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、路径、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然获批、必然解除、必然承认或唯一必得总额。

不得指导伪报税号或拆分价格逃避税。特许权使用费是否计入完税价格按成交条件核验，不得一律计入或不计。原产地不是贴牌国家。

`search_law` 返回已失效《合同法》及其解释、法释〔1999〕19 号、法释〔2007〕14 号或已废外资备案办法时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜争点类型｜申报主张｜海关主张｜事实依据｜程序接口｜判断｜待核`。

至少分列：

- `Q-归 税则归类`
- `Q-价 完税价格`
- `Q-原 原产地`
- `Q-证 证据`
- `Q-济 复议诉讼分流`

同一事实支持多项时分别说明效果，不重复金额。构成违约不等于当然解除。约定外法不等于可以无证出口或绕开准入。

## 节点 0　专项分流

走私、逃避海关监管已刑事立案 → 刑事。出口退税、关税作为所得税税前扣除争议 → 税务。法检或许可证通关阻碍 → assess-import-license-inspection。
用户要求改税号或做阴阳合同降价：整体停止。

## 节点 1　商品画像

1. 实际货品、功能、材质、加工程度、是否成套。宣传名称不决定税号。
2. 税则注释、归类总规则待核。无样品或技术资料：归类 `依据不足`。
3. 预裁定是否存在：已有预裁定的拘束范围另列。

## 节点 2　完税价格

1. 成交价格是否调整：佣金、容器、包装、协助、特许权使用费、转售收益。
2. 关联交易价格是否被接受：转移定价税务评价转税务，海关估价仍按海关规则。
3. 运费保险费按到岸或离岸条件计入，术语分界转术语原子接口。
4. 未知金额不写零。

## 节点 3　原产地

1. 完全获得或实质性改变。第三国简单组装可能不改变原产地。
2. 优惠协定原产地与非优惠原产地分列，证书形式待核。
3. 规避反倾销税的改原产地转反规避原子。

## 节点 4　程序分流

1. 海关已作出决定：缴税、复议、诉讼时点按海关法和行政诉讼法接口核验，一般行政处罚方法转行政领域。
2. 尚未决定：补充说明和申请预裁定接口。
3. 不代报关。

## 节点 5　下一步

1. 输出争点表、证据缺口、不得实施的改单方案、复议诉讼红旗。
2. 精算税款转税务。刑案转刑事。

## 补充判断

若：同一货品在不同口岸被归入不同税号 → 并列两套主张，不把任一口岸口头口径写成全国统一税号。
若：特许权使用费与进口货物相关且作为进口条件 → 计入完税价格的候选成立条件待核，不得因“单独签了许可合同”直接排除。
若：原产地证签发地与实质性改变地不一致 → 证书形式和实体原产地分列，不单凭证书写成原产地已定。
若：用户要求把成套设备拆成零件报关以降低税率 → 该部分整体停止。
复议或诉讼时效未核验：程序字段停止，不输出唯一截止日。
