# 边界与路由

## 正触发

税则归类、完税价格或原产地已成争，本次主成果是海关争点评估。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 税负或退税测算 | 税务领域 |
| 走私刑案 | 刑事领域 |
| 许可法检通关 | `评估进口许可与检验检疫` |
| 改税号避税方案 | 拒绝并停止 |
| 反规避专项 | `评估规避贸易救济与原产地风险` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 海关行政处罚应对 | `应对海关稽查或行政处罚` |
| 一般行政复议方法 | 行政领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

海关归类预裁定不是税务处理决定。完税价格争议不等于走私。
