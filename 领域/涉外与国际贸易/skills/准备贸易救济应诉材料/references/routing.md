# 边界与路由

## 正触发

已决定应诉国外或国内贸易救济调查，本次主成果是应诉材料策略和草稿边界。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 尚未决定应诉 | `评估反倾销反补贴保障措施风险` |
| 申请材料 | `准备贸易救济申请材料` |
| 伪造成本 | 拒绝并停止 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 改账或删关联 | 整体停止 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

被抽样不等于已经获得分别税率。公开摘要不是把机密数字再写一遍。
