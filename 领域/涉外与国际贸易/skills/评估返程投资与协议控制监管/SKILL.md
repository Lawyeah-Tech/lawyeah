# 评估返程投资与协议控制监管

## 任务目标

在明确、无利益冲突的单方立场下，形成返程投资或协议控制的监管定性、披露与准入红旗，不设计避法架构，不起草控制协议。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：红筹、VIE 或协议控制触及准入或报告，需要监管定性而不是架构设计。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 设计避法或绕开禁止类的架构；
- 起草控制协议、投票权协议（审查起草搁置）；
- 只要并购交割文件；

不设计避法架构。不起草控制协议。审查起草本窗搁置。

## 建立评估坐标

确认：境内运营实体；境外上市或融资主体；中间层；协议控制文件是否已存在；行业是否禁止或限制外商；是否已有返程外汇或商务登记；实际控制人国籍。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 结构图和协议表面；`A#` 已确认控制；`R#` 既有登记；`C#` 控制协议条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 监管假设；`V#` 评估版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。未知金额不写零。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验返程投资外汇规定、外商投资法关于协议控制的接口、安全审查办法“其他方式”、信息报告对实际控制人的要求。工具不可用时继续画结构；效力与登记结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　安全闸

绕开禁止类停止。起草控制协议搁置。

### 节点 2　结构画像

逐层列 VIE 协议类型。实际控制人国籍决定返程定性。

### 节点 3　返程投资

未登记只标资金和合规后果，不写当然无效或完全无事。

### 节点 4　外资与禁止限制

禁止类不得设计 VIE。限制股比规避标红旗。

### 节点 5　审查披露和下一步

其他方式可能落入安全审查。不教唆隐瞒。

## 停止与安全

- `整体停止`：设计避法架构；隐瞒协议控制的申报方案。
- `字段停止`：返程外汇现行口径、清单对协议控制的政策未核验。
- `目标停止`：主目标变为起草控制协议或上市方案全文。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
