# 边界与路由

## 正触发

红筹、VIE 或协议控制触及准入或报告，需要监管定性而不是架构设计。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 设计避法架构 | 拒绝并停止 |
| 起草控制协议 | 审查起草领域（本窗搁置） |
| 安全审查专项判断 | `评估外商投资安全审查` |
| ODI 路径 | `评估境外投资监管准入` |
| 交割文件 | 投资并购领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 禁止类仍要 VIE 方案 | 停止该部分 |
| 税负与 CFC | 税务领域 |
| 境外上市全套 | 说明本任务只做监管红旗 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

返程未登记不等于结构当然无效，也不等于可以自由汇回。协议控制可能触发安全审查，即使股比为零。
