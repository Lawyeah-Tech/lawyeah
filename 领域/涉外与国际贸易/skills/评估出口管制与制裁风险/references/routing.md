# 边界与路由

## 正触发

拟出口或已成交，需要判断中国出口管制、制裁、不可靠实体或反制裁／阻断是否挡住交易。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 许可申请材料 | `准备两用物项或出口许可材料`（未安装则 `unavailable`） |
| 管制调查答复 | `应对出口管制问询或调查`（未安装则 `unavailable`） |
| 不可靠实体移出 | `应对不可靠实体清单`（未安装则 `unavailable`） |
| 只要对手筛查清单 | `筛查交易对手与最终用户`（未安装则 `unavailable`） |
| 只要反制裁民事诉讼 | `评估反制裁与阻断义务`（未安装则 `unavailable`） |
| 数据出境安全评估 | 数据领域 |
| 走私或出口管制犯罪辩护 | 刑事领域 |
| 规避许可或改名绕名单 | 拒绝，该部分整体停止 |
| 只要总体交易策略 | `评估跨境事项总图` |

## 专项整案转出

军品出口专营未取得资格 → 标停止，不提供变通。海关归类估价主轴可转 `assess-customs-classification-value-origin`（未安装则 `unavailable`）。海上运输本身转海事。

## 易混

合同已签且货已备妥，仍正触发：许可未核验不得写成可以发货。外国客户要求遵守其本国制裁而违反中国阻断时正触发，不得选边给出规避方案。
