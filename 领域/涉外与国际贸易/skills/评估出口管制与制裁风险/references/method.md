# 评估方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出“可以放心发货”或“必然获许可”。

不得把技能内置的清单俗称写成已核验命中。`search_law` 返回失效应诉规定或旧两用许可办法时记为噪声。教唆规避出口管制、伪造最终用户、擅自接受外国政府现场核查：该部分整体停止。

## Q# 管制假设

固定列：`编号｜管制类型｜义务主体｜相对方｜法律效果｜成立条件｜支持事实｜不利事实｜控制方｜最强反方｜主备位｜判断｜待核`。

至少分列：`Q-清` 清单许可；`Q-临` 临时管制；`Q-禁` 禁止出口；`Q-全` 全面管制（知道或应当知道）；`Q-用` 最终用户／用途变更报告；`Q-制` 制裁或不可靠实体措施；`Q-阻` 反制裁或阻断冲突。

## 节点 0　专项分流

| 信号 | 转出 |
| --- | --- |
| 军品且无军品出口资格 | 停止变通方案；军品条例路径标停止 |
| 数据出境安全评估为主成果 | 数据领域；仅当数据本身可能是管制物项时留接口 |
| 海关已刑事立案或走私侦查 | 刑事领域 |
| 用户要拆分出口、改税号伪装、改名绕名单 | 该部分整体停止 |

---

## 节点 1　交易画像

1. 固定出口经营者是否具备相应经营资格（出口管制法第十一条）。资格不明标待核，不得写成“一般进出口权即可”。
2. 物项描述必须落到货物、技术或服务。仅有商品名没有技术参数：归类 `依据不足`。
3. 记录目的地、进口商、最终用户、最终用途、运输和金融中介。缺失任一项不得给出“不需要许可”的结论。
4. 视为出口、再转让、国内向境外人员提供技术的事实单列，不得只看报关出境。

---

## 节点 2　清单、临时管制、禁止出口、全面管制

1. 清单命中：对照国务院商务主管部门现行两用物项出口管制清单或临时公告。未打开现行清单 → `Q-清` 字段停止。
2. 临时管制：条例第十二条规定期限每次不超过二年等规则运行时核验；过期公告不得当现行清单。
3. 禁止出口或禁止向特定目的地、组织、个人出口：条例第十三条，须有批准和公告依据。
4. 清单和临时管制之外，出口经营者知道或者应当知道，或得到管理部门通知，存在危害国家安全和利益、用于大规模杀伤性武器或其运载工具、用于恐怖主义目的等风险的，仍应申请许可（出口管制法第十二条）。不得因“不在清单上”写成无需许可。
5. 无法确定是否属于管制物项：记录咨询管理部门的接口，不得自行写成已经排除。

---

## 节点 3　最终用户、用途和中介

1. 最终用户应承诺未经允许不改变用途、不向第三方转让（第十六条）。缺少承诺：用途控制 `依据不足`。
2. 出口经营者或进口商发现最终用户或用途可能改变：立即报告义务标红旗。
3. 中介、货代、报关、电商平台、金融机构发现涉嫌违法应报告，不得为违法行为提供服务（条例第三十六条）。用户是中介时同样适用。
4. 发现或接到通知存在风险情形：按条例第三十五条报告、消除或减轻危害并配合调查。

---

## 节点 4　制裁、不可靠实体、反制裁与阻断

1. 中国不可靠实体清单、反制清单与外国制裁名单分列。命中必须回链公告，口述不算命中。
2. 改正期限未满：记录期限内不采取第十条措施的规则接口（不可靠实体清单规定第十一条），不得写成已经可以恢复交易。
3. 外国法律不当域外适用：阻断办法第六条评估因素运行时核验。遵守外国禁令侵害中国主体的民事诉讼（第九条）只作红旗。
4. 反外国制裁法及国务院令第 803 号措施由法定部门实施。不得编造处罚种类。
5. 中国措施与外国措施冲突：并列义务和停止项，不得设计“两边都不违规”的伪装结构。无法同时履行时字段停止，建议取得主管机关意见。

---

## 节点 5　许可路径、合同后果和下一步

1. 需要许可：转介 `prepare-export-license-file`。本任务不写申请表。不予许可的复议为最终裁决（出口管制法第四十一条）须核验后提示，不得写成还可以行政诉讼。
2. 管制违法不等于合同当然无效。合同能否履行、能否免责、能否解除分列待核，转总体评估或解除权原子。
3. 下一步按：停止出运、补许可、切断受限制对手、报告、保全证据排序。
4. 禁止动作：无许可出运、拆分规避、伪造最终用户文件、擅自接受外国现场核查（条例第四十三条）、为违法提供中介服务。
