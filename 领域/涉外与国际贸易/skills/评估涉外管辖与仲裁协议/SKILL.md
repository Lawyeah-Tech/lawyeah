# 评估管辖与仲裁协议

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“管辖与仲裁协议评估包”：协议文本回链、书面形式、仲裁意思、事项覆盖、机构是否选定或存在、或裁或诉、准据法接口、诉讼连结点、异议期限待核和主位论坛。

`depends-on` 为空。接受用户或其他来源的等价合同和程序文书。

## 工作边界

正触发：跨境或涉外事项需要选择法院或仲裁，或对方已提出管辖／仲裁异议，主成果是论坛判断而不是立案文书。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要起诉状、仲裁申请或答辩终稿；
- 异议期已过且唯一目标是赶写异议书；
- 海事专属管辖或劳动仲裁；
- 尚未成争，只要改管辖或仲裁条款（审查起草搁置）。

本任务不代写完整立案包，不保证受理，不在表面有效仲裁下写应起诉。

## 建立评估坐标

确认：使用者与授权；单方立场；各方注册地与送达地址；主合同、补充协议、单独仲裁协议；约定准据法与语言；当前起诉、仲裁、异议状态；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 论坛假设；`V#` 评估版本；`E#` 发送／送达凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验仲裁协议要件、独立性、涉外管辖、不方便法院和异议期限；`search_practiced` 补路径。`search_law` 对效力与期限为 required。

工具不可用时继续文本对照；效力、主位论坛和期限字段停止。

《仲裁法》版本、条号和施行日一律运行时核验。MCP 误标 2025 修订尚未施行时，以有权机关施行日为准。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。

### 1. 专项分流、文本和程序状态

海事专属、劳动仲裁整案转出。固定全部可能构成仲裁或管辖协议的文本。已进入程序的文书必须登记收到日。

### 2. 书面形式与仲裁意思

口头“以后仲裁”不构成书面协议。或裁或诉、仅写“依法解决”时仲裁意思 `依据不足`。

### 3. 事项覆盖与机构是否可确定

请求是否落入条款范围、机构是否存在或可确定、临时仲裁是否被现行法允许，三项独立判断。

### 4. 诉讼连结点与不方便法院

仅在仲裁不挡住诉讼时展开中国法院连结点。专属管辖、协议管辖、级别管辖和不方便法院分列待核。

### 5. 异议期限与主位输出

已进入程序则标异议期限红旗。过期不赶写终稿。主位论坛未核验完成不得选定。

## 停止与安全

- `整体停止`：立场不明；利益冲突；用户坚持伪造签署页。
- `字段停止`：仲裁法文本、管辖规则、送达日未核验。
- `目标停止`：主目标变为立案包或过期异议书。
