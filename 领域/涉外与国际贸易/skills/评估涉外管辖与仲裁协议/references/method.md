# 评估方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然受理或唯一有管辖权法院。不得在表面有效仲裁条款下写“应起诉”。

`search_law` 返回已失效《合同法》或旧条号与 2023 民事诉讼法、2025 仲裁法冲突时，以有权机关现行文本和施行日为准。无法核验则效力、论坛和期限字段停止。

## Q# 论坛假设

固定列：`编号｜论坛类型｜提出方｜相对方｜文本定位｜成立条件｜支持事实｜不利事实｜控制方｜最强反方｜主备位｜判断｜待核`。

至少分列：`Q-仲` 仲裁入口；`Q-诉` 中国法院诉讼；`Q-外诉` 外国法院（只作红旗，不提供外国法结论）；`Q-协管` 协议管辖；`Q-法定` 法定地域／级别管辖；`Q-异` 管辖或仲裁协议异议。

## 节点 0　专项分流

| 信号 | 转出 |
| --- | --- |
| 海上货物、船舶、海事保全、海事专属管辖 | 海事领域 |
| 劳动关系、劳动报酬、工伤 | 劳动领域 |
| 无涉外因素的一般境内合同 | 合同争议领域 |
| 未成争只要改条款 | 审查起草（搁置） |

---

## 节点 1　文本、主体和程序状态

1. 固定主合同、补充协议、订单、单独仲裁协议、事后书面协议。仲裁条款与管辖条款冲突时并列。
2. 未签字但可能被主张受约束的主体单独一行，约束力标 `依据不足`。
3. 程序表登记起诉、仲裁申请、应诉通知、首次开庭、已提出异议：机关、案号、作出日、收到日、送达方式。口头转述和“已读”不得起算异议期。
4. 若用户只要立案包 → 目标停止。  
   若异议期已过且唯一目标是赶写异议书 → 负触发，标逾期，不代写终稿。

---

## 节点 2　书面形式与仲裁意思

| 条件 | 判断 | 禁止写成 |
| --- | --- | --- |
| 无任何书面仲裁条款或单独协议 | `Q-仲` 现有依据不支持 | 仍须先仲裁 |
| 仅有口头约定 | 书面形式现有依据不支持 | 已存在仲裁协议 |
| 有条款但签署、电子确认或授权不明 | 书面形式 `依据不足` | 当然有效或无效 |
| “协商不成可诉讼可仲裁／依法解决” | 仲裁意思 `依据不足` | 选定唯一论坛 |
| 写明提交某机构仲裁 | 仲裁意思现有依据支持，仍须过事项和机构闸 | 条款当然有效 |

书面形式是否包含数据电文，必须 `search_law` 核验现行《仲裁法》后再落 `L#`。

---

## 节点 3　事项、机构、独立性

1. 将本案请求与“本合同争议／与本合同有关／明确排除事项”对照。未被覆盖的请求不得写入仲裁主位。
2. 机构名称能否指向唯一存在的机构。名称错误、两机构并列、仅写城市未写机构：机构要件 `依据不足`。
3. 临时仲裁：仅在现行法明确允许的情形下评估，否则标待核，不得凭记忆写自由贸易区例外已经成立。
4. 合同无效、被撤销或终止，不当然消灭仲裁协议。独立性条文运行时核验。
5. 当事人未选择仲裁协议准据法且机构或仲裁地不明时，可适用中国法认定效力的接口按法释〔2020〕18 号第十二条核验，不得直接写成已适用。

---

## 节点 4　诉讼连结点

仅当 `Q-仲` 现有依据不支持或其不适用已获支持时，展开中国法院入口。

1. 分列被告住所地、合同履行地、协议管辖、专属管辖、级别管辖、涉外集中管辖。连结点材料不足时不选定唯一法院。
2. 协议管辖不得违反级别管辖和专属管辖。不动产、港口作业等专属信号出现时停止自行指定。
3. 不方便法院按民事诉讼法第 282 条现行文本逐项核验，缺一项则不得建议驳回起诉。
4. 外国法院条款只记录，不提供该外国法下的管辖结论。
5. 港澳台连结点走区际安排接口，不写成外国法院。

---

## 节点 5　异议期限与主位

1. 已收到起诉状或仲裁通知：标异议期限红旗。期限规则未核验则截止日期字段停止，不写“还可以异议到某日”。
2. 首次实体答辩是否构成放弃异议，按机构规则和现行法核验；未核验不得写已放弃。
3. 输出主位论坛必须回链已支持的要件。任一关键要件未核验：主位未选定。
4. 本任务不写仲裁申请或起诉状。
