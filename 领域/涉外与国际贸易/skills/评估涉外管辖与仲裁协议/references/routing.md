# 边界与路由

## 正触发

跨境或涉外事项需要判断法院还是仲裁，或判断已有条款是否绊住中国法院。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要仲裁申请包 | `提起中国涉外仲裁` |
| 只要仲裁答辩 | `应对中国涉外仲裁` |
| 只要中国法院起诉 | `提起中国法院涉外民事诉讼`（未安装则 `unavailable`） |
| 过期后赶写管辖异议 | `提出涉外管辖异议`（未安装则 `unavailable`），并标逾期，不代写终稿 |
| 海事专属 | 海事领域 |
| 劳动仲裁 | 劳动领域 |
| 未成争改条款 | 审查起草（搁置） |
| 只要总体策略 | `评估跨境事项总图` |

## 专项整案转出

海上货物、船舶、海事保全 → 海事。劳动关系 → 劳动。境内无涉外因素的一般合同 → 合同争议领域。

## 易混

条款看起来像仲裁但机构不存在或或裁或诉时正触发，主位未选定。用户坚持“直接去中院起诉”且条款表面有效时，不改写成立案。
