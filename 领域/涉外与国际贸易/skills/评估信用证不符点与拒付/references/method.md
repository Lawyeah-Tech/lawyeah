# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、路径、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然获批、必然解除、必然承认或唯一必得总额。

信用证独立于基础合同。不得用基础货物质量直接写成银行应当拒付或应当付款。欺诈例外须达到司法解释标准，不得凭普通违约主张止付。不得指导伪造提单、发票或产地证。

`search_law` 返回已失效《合同法》及其解释、法释〔1999〕19 号、法释〔2007〕14 号或已废外资备案办法时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜单据或电文｜表面记载｜信用证要求｜是否表面不符｜银行处理时限｜救济｜判断｜待核`。

至少分列：

- `Q-表 表面相符`
- `Q-不 不符点清单`
- `Q-拒 拒付是否有效`
- `Q-欺 欺诈例外红旗`
- `Q-基 与基础合同分账`

同一事实支持多项时分别说明效果，不重复金额。构成违约不等于当然解除。约定外法不等于可以无证出口或绕开准入。

## 节点 0　专项分流

独立保函或备用证止付 → assess-independent-guarantee。基础质量主轴且结算无争 → 货物履行原子。伪造或变造单据 → 整体停止，刑事红旗。
贸易融资押汇、福费廷主轴 → assess-trade-finance-dispute。

## 节点 1　信用证文本与惯例

1. 固定开证行、通知行、议付或保兑、到期日、交单地、是否允许分批和转运。
2. 适用 UCP 600 或其他惯例必须写在证内或可回链。未写明则惯例适用 `依据不足`。
3. 修改未经受益人接受：对受益人是否约束待核，不得把银行单方修改写成已生效。

## 节点 2　交单与表面相符

1. 逐份单据对照信用证：发票、提单、保险单、产地证、装箱单、检验证。
2. 表面相符按单据之间、单据与信用证之间核对，不引入基础合同未要求的事实。
3. 若：不符点仅为拼写且银行已接受 → 记录，不事后扩大。
4. 电子交单规则未核验不得套纸质交单时限。

## 节点 3　拒付时限与方式

1. 银行拒付是否在惯例规定的拒付期限内、是否一次性提出、是否按指定方式通知，分列。
2. 逾期未拒付的效果按惯例和司法解释核验，不得写“一律视为接受”。
3. 开证申请人指示拒付：银行仍须独立审单，申请人指示不当然构成有效拒付理由。

## 节点 4　欺诈例外与止付

1. 欺诈例外适用于基础交易欺诈或单据欺诈的严格情形。普通质量纠纷不构成。
2. 止付程序转法院保全原子接口，本任务只标是否达到例外红旗。
3. 远期承兑后的止付条件更严，未核验则字段停止。

## 节点 5　救济分流

1. 对银行：要求付款、确认拒付无效、损害赔偿。对申请人：基础合同请求另列。
2. 两套请求不得重复受偿。
3. 不指导补造单据再交。过期交单的救济不是改日期。
