# 边界与路由

## 正触发

开证、交单、不符点或拒付已成争，本次主成果是信用证评估而不是基础合同质量终局。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 独立保函止付 | `评估独立保函与备用信用证` |
| 基础质量主轴 | `评估国际货物交付质量数量` |
| 伪造单据方案 | 拒绝并停止 |
| 押汇福费廷主轴 | `评估贸易融资单据争议` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 走私或骗汇刑事 | 刑事领域 |
| 海事提单物权主轴且无信用证争点 | 海事领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

银行已付款不消灭买方对卖方的质量请求。单据有不符点不自动证明货物不符。
