# 边界与路由

## 正触发

货物、样品或邮件可能灭失，需要及时保全，且主轴不是海事扣船。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 海事保全或扣船 | 海事领域 |
| 法院保全申请终稿 | `申请涉外或仲裁保全` |
| 完整建卷无灭失风险 | `建立跨境争议证据与认证案卷` |
| 入侵邮箱 | 拒绝并停止 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 擅自开海关监管货 | 停止 |
| 调换样品 | 整体停止 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

公证了取样过程不等于质量已不合格。删对自己不利的邮件是毁灭证据。
