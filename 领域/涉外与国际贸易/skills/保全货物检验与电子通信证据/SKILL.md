# 保全货物检验与电子通信证据

## 任务目标

在明确、无利益冲突的单方立场下，形成保全步骤、公证或鉴定分流和禁止动作；船上扣押或海事证据保全转海事。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：货物、样品或邮件可能灭失，需要及时保全，且主轴不是海事扣船。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 船上扣押或海事证据保全；
- 完整证据卷策略而无可灭失风险；
- 违法入侵邮箱保全；

船上扣押或海事证据保全转海事。禁止违法取证。

## 建立评估坐标

确认：货物位置；是否在第三方仓或海关监管；邮件和聊天控制方；灭失时点；是否已起诉或仲裁；鉴定需求。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 库存和邮件线索；`A#` 货物现状；`R#` 已有保全裁定；`C#` 检验条款；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 保全项；`V#` 步骤版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。未知金额不写零。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民事诉讼法证据保全、电子数据司法解释。工具不可用时继续做灭失风险编目；裁定必要性和管辖字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　海事与违法闸

扣船转海事。入侵停止。申请终稿转保全原子。

### 节点 2　货物样品

共同检验。海关监管货不得擅自开箱。

### 节点 3　电子通信

只保全己方账户和公开网页。禁选择性截图充当全部。

### 节点 4　公证鉴定

公证过程不是质量结论。方法须符合约定。

### 节点 5　裁定与禁止

紧急转申请原子。禁删不利邮件。

## 停止与安全

- `整体停止`：入侵邮箱；调换样品；擅自开海关监管货。
- `字段停止`：证据保全、电子数据规则未核验。
- `目标停止`：主目标变为海事扣船或法院保全终稿。
