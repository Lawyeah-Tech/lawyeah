# 边界与路由

## 正触发

解除或拒收后需要清理货物、货款和仓储，且解除是否成立已有等价判断或双方按已解除处理。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 重判解除是否成立 | `评估国际贸易解除权` |
| 海上留置或扣船 | 海事领域 |
| 精算终稿 | `测算国际贸易价金与损害赔偿` |
| 货物证据保全 | `保全货物检验与电子通信证据` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 非法弃货 | 整体停止 |
| 海关监管货物擅自处置 | 停止并标海关红旗 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

拒收不等于已经解除。货物在保税仓，清理受海关手续约束。
