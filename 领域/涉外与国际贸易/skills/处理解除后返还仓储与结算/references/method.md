# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、路径、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然获批、必然解除、必然承认或唯一必得总额。

解除后果与违约损害赔偿分列。不得在本任务重新判决解除有效来“顺便”清理。减损义务违反可能缩限可主张费用。

`search_law` 返回已失效《合同法》及其解释、法释〔1999〕19 号、法释〔2007〕14 号或已废外资备案办法时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜标的（货／款／费）｜现状｜请求方向｜减损｜负担候选｜判断｜待核`。

至少分列：

- `Q-货 货物返还或变卖`
- `Q-款 货款返还`
- `Q-仓 仓储保管费`
- `Q-运 回运或转售`
- `Q-损 减损义务`

同一事实支持多项时分别说明效果，不重复金额。构成违约不等于当然解除。约定外法不等于可以无证出口或绕开准入。

## 节点 0　前置闸

解除是否成立仍是主争点 → 转解除权原子。海上留置、船舶扣押 → 海事。精算终稿 → 测算原子。
货物可能灭失：先转保全原子接口。用户要求弃货污染或非法倾倒：停止。

## 节点 1　货物状态

1. 位置、数量、品质变化、是否海关监管、是否第三方仓储。
2. 所有权与风险：解除后风险是否仍按术语，待核。
3. 易腐货物：变卖减损优先于长途回运，变卖程序须合法。

## 节点 2　返还与付款

1. 已交货应返还或折价。已付款应返还。同时履行抗辩：对方未同时准备时标红旗。
2. 定金、预付款、已开信用证的处理分列。信用证已承兑：另评银行关系。
3. 未知余额不写零。

## 节点 3　仓储与费用

1. 仓储费、保险、回运、商检、销毁费用分列承担候选。
2. 因一方迟延受领导致的扩大仓储：扩大部分可能自行承担。
3. 承运人或仓库主张留置：海事或仓储法定留置分界，海上留置转海事。

## 节点 4　减损

1. 合理转售、改港口、就地处理。转售价格作为减损事实，盈亏接口转测算。
2. 不得指导以明显不合理低价卖给关联方制造损失。

## 节点 5　下一步

1. 输出清理表、费用负担情景、减损动作、不得实施项。
2. 通知对方提货或同意变卖：可转催告原子，不在本任务发解除通知。
3. 若：双方对解除成立有争议但仍共同要求先处理易腐货 → 清理表标明“以解除成立为条件”，变卖所得提存或双方共管，不写成已经终局归属。
4. 若：货物在保税区或海关监管仓 → 先核验海关手续，擅自提离标停止。
5. 若：仓储合同相对方主张留置且属于港口作业或海上货物 → 转海事，本任务只保留买卖项下费用接口。
6. 损害赔偿与返还清理分账：清理表不替代测算原子，也不把仓储费重复计入损失。

若：同一事实同时支持请求和抗辩 → 分列效果，不合并成一笔结论，也不重复计算金额。
若：机关或机构文书的作出日与收到日冲突 → 两套起算并行，期限字段停止，不得挑选对用户有利的日期。
若：需要引用域外实体法而未能查明 → 不得用中国法填空冒充已查明，该路径标依据不足。
本任务不输出胜诉率、必然获批、必然撤销、必然承认或唯一必得总额。未知金额不写零。
