# 边界与路由

## 正触发

国际货物或跨境服务已成争，仍要对方履行或补救，主成果是催告。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 解除通知 | `准备国际贸易解除通知`（未安装则 `unavailable`） |
| 质量索赔通知且不要求继续履行 | `准备质量数量索赔通知`（未安装则 `unavailable`） |
| 精算 | `测算国际贸易价金与损害赔偿` |
| 仲裁申请 | `提起中国涉外仲裁` |
| 海事货损函 | 海事领域 |
| 未成争改合同 | 审查起草（搁置） |
| 只要总图 | `评估跨境事项总图` |

## 专项整案转出

租船滞期、海上运输索赔 → 海事。信用证不符点拒付主轴 → `assess-letter-of-credit`（未安装则 `unavailable`），本催告只处理基础合同履行。

## 易混

用户把催告当解除函来写时负触发。已发出过催告须登记，不重复冒充首份。
