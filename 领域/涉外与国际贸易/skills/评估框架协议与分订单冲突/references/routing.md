# 边界与路由

## 正触发

框架、形式发票、订单、信用证不一致，需要判断哪一层构成约束及冲突如何处理。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 无文件冲突的履行评估 | `评估国际货物交付质量数量` |
| 信用证不符点 | `评估信用证不符点与拒付` |
| 重写框架 | 审查起草领域（本窗搁置） |
| 论坛条款效力 | `评估涉外管辖与仲裁协议` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 伪造订单确认 | 整体停止 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

开证不等于接受全部订单附加条款。框架仲裁条款可能绑住后续订单。
