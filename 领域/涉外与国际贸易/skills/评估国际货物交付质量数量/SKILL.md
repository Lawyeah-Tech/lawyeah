# 评估国际货物交付质量数量

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成交货节点、检验索赔期、违约形态和补救分流，不发索赔函；海运货损主轴转海事。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：国际货物买卖已出现迟延、短量或质量不符成争，本次主成果是履行评估而不是发函。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要索赔或催告通知终稿；
- 海运货损、共同海损或运输合同主轴；
- 只要检验期是否逾期的单项判断；
- 未成争改质量条款；

不发索赔函。海运货损主轴转海事。不判断质量本身的鉴定终局。

## 建立评估坐标

确认：合同与订单版本；贸易术语及版本；交货地；装运期；实际装运和到货；检验条款；已做检验；数量短量记录；质量标准；已付款。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 单据和检验报告表面；`A#` 双方承认的交付；`R#` 商检或鉴定；`C#` 合同交货与质量条款；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 履行假设；`V#` 评估版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。未知金额不写零。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典合同编买卖、CISG 交货与相符、检验期间接口。CISG 是否适用未核验不得直接套用。工具不可用时继续固定交货时间线；违约形态法律结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　专项分流

海事货损、发函、检验期专项、信用证主轴转出。伪造停止。

### 节点 2　交货节点

装运、到货、交单分列。术语版本不明则节点不足。

### 节点 3　数量与质量

多标准并列。单方检测不写成定论。

### 节点 4　检验期红旗与补救

逾期只标红旗。解除条件未核验不得写成已可解除。

### 节点 5　下一步

发函鉴定转介。提单清洁不消灭质量请求。

## 停止与安全

- `整体停止`：伪造检验或倒签到货；立场不明。
- `字段停止`：CISG 适用、术语版本、检验期间未核验。
- `目标停止`：主目标变为发函或海事货损整案。

严格按 [输出合同](references/output-contract.md) 交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
