# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、路径、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然获批、必然解除、必然承认或唯一必得总额。

构成不符不等于当然解除。签收不等于验收。提单批注与买卖合同质量分账。不得用已失效《合同法》条号。

`search_law` 返回已失效《合同法》及其解释、法释〔1999〕19 号、法释〔2007〕14 号或已废外资备案办法时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜违约形态｜交货节点｜标准依据｜支持事实｜不利事实｜补救候选｜判断｜待核`。

至少分列：

- `Q-迟 迟延交货或迟延收货`
- `Q-短 短量或溢装`
- `Q-质 质量不符`
- `Q-单 单据不符与货损分账`
- `Q-检 检验索赔期红旗`

同一事实支持多项时分别说明效果，不重复金额。构成违约不等于当然解除。约定外法不等于可以无证出口或绕开准入。

## 节点 0　专项分流

| 信号 | 处置 |
| --- | --- |
| 租船、海上运输合同、船舶、共同海损 | 海事领域 |
| 只要发索赔函 | 准备质量数量索赔通知 |
| 只要催告履行 | 准备国际贸易催告或补救通知 |
| 只要检验期是否逾期 | 评估检验与索赔期间 |
| 信用证不符点主轴 | 评估信用证不符点与拒付 |
用户要求伪造检验报告或倒签到货日：整体停止。

## 节点 1　交货节点

1. 按合同和贸易术语固定风险转移与交货完成节点。术语版本不明则节点 `依据不足`。
2. 装运期、到货期、交单期分列，不得用到货迟延直接写成装运违约。
3. 若：FOB 买方未及时派船 → 迟延责任候选在买方，不当然写成卖方迟延。
4. 部分交货、分批交货按批次评估，不合成一笔“整合同未履行”。

## 节点 2　数量与质量标准

1. 数量：合同数量、溢短装、实际卸货或收货数量、途耗约定分列。未知不写零。
2. 质量：约定标准、样品、说明书、法定标准。多标准冲突时并列，不选对用户有利的一个。
3. 检验报告方法、抽样、机构是否符合约定：不符则证明力 `依据不足`，不把单方检测写成已定论。
4. 表面不符与内在质量分列。

## 节点 3　检验索赔期红旗

1. 本任务只标红旗并转检验期原子，不把逾期写成质量一定败诉。
2. 签收、拆箱、使用、转售对异议期间的影响分列待核。
3. CISG 第 38、39 条未核验不得直接套“两年最长期”。

## 节点 4　补救分流

1. 补救候选分列：继续履行、修理更换、减价、损害赔偿、解除。互斥项不得重复金额。
2. 构成根本违约或约定解除条件未核验，不得写成已经可以解除。
3. 减价和损害赔偿接口转测算原子，本任务只列区间需求。
4. 货物在途或在码头的仓储、减损义务单列。海上留置转海事。

## 节点 5　下一步

1. 输出履行时间线、形态判断或依据不足、检验红旗、补救主备位。
2. 发函、鉴定、建卷标转介。不发索赔函。
