# 边界与路由

## 正触发

国际货物买卖已出现迟延、短量或质量不符成争，本次主成果是履行评估而不是发函。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 索赔通知 | `准备质量数量索赔通知` |
| 催告 | `准备国际贸易催告或补救通知` |
| 检验期专项 | `评估检验与索赔期间` |
| 信用证不符点 | `评估信用证不符点与拒付` |
| 海运货损主轴 | 海事领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 租船、提单运输合同、共同海损 | 海事领域 |
| 未成争改质量条款 | 审查起草领域（本窗搁置） |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

提单清洁不消灭买卖合同质量请求。信用证已付款不消灭质量不符。
