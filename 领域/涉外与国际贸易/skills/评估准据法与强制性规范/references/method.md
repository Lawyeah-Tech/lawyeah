# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、路径、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然获批、必然解除、必然承认或唯一必得总额。

不得把已失效《合同法》冲突规则写入 `L#`。法释〔2020〕18 号第八条强制规范类型必须运行时核验。不得把“约定纽约法”写成可以无证出口或绕开安全审查。

`search_law` 返回已失效《合同法》及其解释、法释〔1999〕19 号、法释〔2007〕14 号或已废外资备案办法时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜路径类型｜提出方｜连结因素｜法律效果｜成立条件｜支持事实｜不利事实｜控制方｜最强反方｜主备位｜判断｜待核`。

至少分列：

- `Q-自 意思自治`
- `Q-密 最密切联系`
- `Q-约 CISG 或国际惯例`
- `Q-强 中国强制性规范介入`
- `Q-序 公共秩序保留`

同一事实支持多项时分别说明效果，不重复金额。构成违约不等于当然解除。约定外法不等于可以无证出口或绕开准入。

## 节点 0　专项分流与任务闸

先于实体判断。命中任一项则整案转出，本任务只交付分流理由。

| 信号 | 处置 |
| --- | --- |
| 用户要的是总体请求、管制、论坛一张图 | 负触发，转 评估跨境事项总图 |
| 主成果是管辖或仲裁协议效力 | 负触发，转 评估涉外管辖与仲裁协议 |
| 主成果是强制规范清单本身且不要准据法路径 | 可转 评估强制性规范与公共秩序 |
| 港澳台区际法律适用为主轴 | 转 评估涉港澳台法域与文书 |
| 股权对价、交割文件 | 投资并购领域 |
| 租船、海上运输、船舶 | 海事领域 |
| 未成争只要改准据法条款 | 审查起草（本窗搁置） |

若：用户要求“选一个一定能赢的法” → 该请求停止，只并列路径，不输出唯一胜诉法。

## 节点 1　文本版本、主体连结和约定条款

1. 固定合同、订单、形式发票、补充协议的版本层级。中英文本对准据法条款不一致时并列，不作准文本不明时不挑选对用户有利的一版。
2. 主体表记录各方国籍、注册地、经常居所、营业地。名称不一致不自动合并。
3. 约定准据法必须落到可回链条款。口头“按香港法”“按 Incoterms 就是英国法”不得写成已约定。
4. 若：条款只写“按国际惯例”或“按 ICC 规则”而未点名实体法 → `Q-自` `依据不足`，惯例接口另列，不把程序规则写成实体准据法。
5. 若：事后书面协议变更准据法 → 登记变更日、形式和是否覆盖既已发生的争议；变更是否溯及未核验则效力字段停止。
6. 同时掌握双方秘密或立场不明：整体停止策略输出。

## 节点 2　意思自治是否成立

1. 涉外民事关系法律适用法第三条：当事人依照法律规定可以明示选择。是否“明示”、是否属于可选择范围，运行时核验。
2. 若：选择的是尚未生效或已废止的外国法文本 → 记录选择意图，适用版本 `依据不足`，不得用技能记忆补一条现行外国法。
3. 若：选择结果规避中国法律、行政法规的强制性规定 → 不得因约定外法消灭 `Q-强`。强制规范对照法释〔2020〕18 号第八条核验；核验失败则强制规范结论字段停止，约定记录继续。
4. 消费者、劳动合同等特殊类型若出现，先核验法律适用法的限制规则；本领域主轴是贸易和投资，劳动主轴转劳动。
5. 不得把仲裁地法、仲裁规则或法院地冲突规则直接写成合同准据法。论坛法与实体法分账。

## 节点 3　最密切联系、条约与惯例

1. 无有效选择或选择不覆盖争点时，建立 `Q-密`：履行地、标的所在地、营业地、谈判地、付款地并列，不凭“买方所在地一定更密切”定唯一法。
2. 特征性履行只作为待核方法，不是自动结论。
3. CISG：营业地是否在缔约国、中国保留、合同是否排除，三项未齐则条约路径 `依据不足`，国内法路径并列。
4. 若：用户主张“国际贸易一律适用 CISG” → 现有依据不支持该全称判断。
5. Incoterms、UCP 等惯例只约束其覆盖的费用、风险或单据，不自动成为合同其余部分的准据法。
6. 外国法查明不能时，按现行法律适用法及解释处理；不得用中国法直接填空冒充已查明外国法。

## 节点 4　强制性规范与公共秩序

1. 分列：外汇、出口管制、外商投资准入、海关、反垄断、金融审慎等可能介入的强制规范。约定外法不消灭这些接口。
2. 公共秩序只用于例外，不得用来重写全部合同权利。是否达到损害中华人民共和国社会公共利益运行时核验，不得凭“对我们不利”写入。
3. 若：用户要用公共秩序否定一份普通价款条款 → `Q-序` 通常 `依据不足`，并说明公共秩序不是违约抗辩的替代。
4. 港澳台强制规范与外国强制规范分列，不得写成“外国强制法”。
5. 本节点只做红旗和转介；完整强制规范清单可转专项原子，但不省略本节点最低交付。

## 节点 5　分争点路径、互斥和下一步

1. 每个实体争点（交货、质量、价款、解除、损害赔偿、担保）单独标注准据法路径，允许不同争点适用不同规则。
2. 禁止输出“本案应适用某法所以必然胜诉”。
3. 下一步：补作准文本、核验 CISG 保留、转论坛原子、转强制规范专项、转总图。发函和立案只作转介。
4. 若：主目标已变为改合同准据法条款 → 目标停止，审查起草搁置。
