# 边界与路由

## 正触发

单独委托判断适用哪一法域实体法或条约，且本次主成果不是总体评估或论坛判断。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 要总体评估矩阵 | `评估跨境事项总图` |
| 要管辖或仲裁协议效力 | `评估涉外管辖与仲裁协议` |
| 只要中国强制规范清单 | `评估强制性规范与公共秩序` |
| 涉港澳台区际法律适用为主 | `评估涉港澳台法域与文书` |
| 未成争改准据法条款 | 审查起草领域（本窗搁置） |
| 选定唯一胜诉法 | 拒绝该请求，只并列路径 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权对价、交割、目标尽调 | 投资并购领域 |
| 租船、海上运输、船舶、海事保全 | 海事领域 |
| 外国人在华劳动合同准据法 | 劳动领域 |
| 离婚、继承准据法 | 家事领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

合同里既有准据法条款又有仲裁条款时，本任务只评实体法路径；仲裁协议效力不得写成准据法结论。用户说“纽约法所以不用中国出口许可”时正触发强制规范红旗，不得选边消灭许可义务。
