# 评估准据法与强制性规范

## 任务目标

在明确、无利益冲突的单方立场下，形成准据法评估矩阵：意思自治是否成立、最密切联系备选、条约或国际惯例接口、中国强制性规范和公共秩序红旗、每个争点的法域路径，而不选定唯一胜诉法。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：单独委托判断适用哪一法域实体法或条约，且本次主成果不是总体评估或论坛判断。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要总体评估或论坛判断；
- 未成争只要改准据法条款（审查起草搁置）；
- 港澳台区际安排为主成果；
- 境内无涉外因素的一般合同准据法争执；

本任务不选定唯一胜诉法，不给胜诉率，不改写合同条款。

## 建立评估坐标

确认：使用者与授权；单方立场；合同及作准文本；约定准据法条款；营业地或经常居所；标的所在地；法律事实发生地；是否主张适用 CISG 或贸易惯例；已进入的仲裁或诉讼程序；对方已知准据法主张。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 准据法路径；`V#` 评估版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。未知金额不写零。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验《涉外民事关系法律适用法》、法释〔2020〕18 号、民法典合同编及 CISG 在中国的适用与保留；`search_practiced` 补最密切联系和强制规范接口。`search_law` 对强制性规范和公共秩序为 required。工具不可用时继续固定约定条款和连结因素；准据法结论、强制规范效力字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　专项分流与任务闸

先分流并购、海事、家事、论坛和总图。用户要唯一胜诉法则停止该请求。

### 节点 2　文本、连结与约定条款

固定版本和作准文本。口头选法不得写成已约定。程序规则不冒充实体法。

### 节点 3　意思自治

明示选择、可选择范围、强制规范介入分列。约定外法不消灭中国管制和准入。

### 节点 4　最密切联系与条约惯例

连结因素并列。CISG 三项未齐则条约路径依据不足。外国法未查明不得用中国法填空。

### 节点 5　强制规范、分争点路径和下一步

各争点可走不同规则。公共秩序不作普通抗辩。发函立案只转介。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；用户坚持指定唯一胜诉法并要求删去不利路径。
- `字段停止`：法律适用法条文、CISG 保留、强制规范类型未核验。
- `目标停止`：主目标变为改合同、选论坛或写起诉状。
