# 边界与路由

## 正触发

已决定履行初始、变更或年度报告，本次主成果是信息报告材料。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 负面清单或准入总评 | `评估外商准入与安全审查` |
| 安全审查专项 | `评估外商投资安全审查` |
| 交易文件 | 投资并购领域 |
| 把报告当批准 | 纠正表述，不输出该结论 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 经营者集中 | 竞争法领域 |
| 税务登记与税负 | 税务领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

市场监管变更登记完成仍可能漏做商务信息报告。协议控制不披露实际控制人不得作为方案。
