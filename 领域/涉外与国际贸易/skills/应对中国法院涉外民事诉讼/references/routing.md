# 边界与路由

## 正触发

收到涉外起诉状或应诉通知，本次主成果是应诉包。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 原告起诉 | `提起中国法院涉外民事诉讼` |
| 仲裁应诉 | `应对中国涉外仲裁` |
| 管辖异议书终稿 | `提出涉外管辖异议` |
| C 端 012 | 大众专项，只分流 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动应诉 | 劳动领域 |
| 海事应诉 | 海事领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

签收起诉状不等于放弃送达抗辩。先交实体答辩可能影响异议，必须先核验。
