# 边界与路由

## 正触发

检验期内需要固定质量或数量索赔意思，本次主成果是索赔通知而不是精算。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 检验期专项判断 | `评估检验与索赔期间` |
| 解除通知 | `准备国际贸易解除通知` |
| 精算终稿 | `测算国际贸易价金与损害赔偿` |
| 海事货损函 | 海事领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 伪造检验或倒签 | 整体停止 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

索赔通知不是解除。检验期过后发函可能只保留部分救济。
