# 边界与路由

## 正触发

收到内地涉外裁决后仍在法定期限内，本次主成果是撤销申请。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 不予执行 | `申请不予执行涉外或外国裁决` |
| 外国裁决承认抗辩 | `应对承认执行外国裁决或判决` |
| 过期仍要终稿 | 停止终稿 |
| 港澳台 | `评估涉港澳台法域与文书` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 重审实体当撤销 | 拒绝该写法 |
| 隐瞒已履行 | 停止策略 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

撤销窗口很短。不予执行是另一程序，管辖和事由都不同。
