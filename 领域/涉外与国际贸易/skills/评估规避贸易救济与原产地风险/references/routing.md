# 边界与路由

## 正触发

第三国组装或改税号被指规避贸易救济，需要争点评估而不是伪装方案。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 伪装避税方案 | 拒绝并停止 |
| 普通原产地无救济税 | `评估归类估价与原产地` |
| 应诉问卷 | `准备贸易救济应诉材料` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 伪造加工增值 | 整体停止 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

第三国有工厂不等于原产地已变。税号变了仍可能被反规避。
