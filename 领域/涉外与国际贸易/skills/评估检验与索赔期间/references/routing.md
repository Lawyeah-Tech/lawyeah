# 边界与路由

## 正触发

单独核验质量或数量通知是否逾期，本次主成果是期间判断而不是质量鉴定。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 质量是否不合格终局 | `评估国际货物交付质量数量` |
| 索赔函终稿 | `准备质量数量索赔通知` |
| 货物履行总评且期间无争 | `评估国际货物交付质量数量` |
| 海事货损通知 | 海事领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 倒签检验或伪造通知 | 整体停止 |
| 诉讼时效计算 | 不在本任务用时效冒充检验期 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

检验期逾期不等于卖方一定无须担责，可能仍影响解除或只能减价。诉讼时效另算。
