# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、路径、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然获批、必然解除、必然承认或唯一必得总额。

法释〔2020〕18 号第八条列举的强制规范涉及劳动者权益、食品或公共卫生安全、环境安全、外汇管制、反垄断、反倾销等，须运行时核验现行文本，不得凭记忆扩列或缩列。不得用已失效《合同法》第五十二条“违反法律行政法规强制性规定”旧口径替代现行民法典效力规则。

`search_law` 返回已失效《合同法》及其解释、法释〔1999〕19 号、法释〔2007〕14 号或已废外资备案办法时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜规范类型｜规范名称待核｜介入条件｜法律效果候选｜支持事实｜不利事实｜控制方｜最强反方｜判断｜待核`。

至少分列：

- `Q-强 法律适用中的强制性规定`
- `Q-序 公共秩序／社会公共利益`
- `Q-管 管制许可与禁止出口`
- `Q-准 外资准入与安全审查`
- `Q-汇 外汇与跨境担保`

同一事实支持多项时分别说明效果，不重复金额。构成违约不等于当然解除。约定外法不等于可以无证出口或绕开准入。

## 节点 0　专项分流

| 信号 | 处置 |
| --- | --- |
| 主成果是选定准据法 | 评估准据法与强制性规范 |
| 主成果是承认执行申请或抗辩书 | 转承认或应对原子 |
| 指导绕开许可、代持或改名 | 该部分整体停止 |
| 走私、无证出口已刑事立案 | 刑事领域 |

若：用户要把价款高低或普通迟延说成违反公共秩序 → 记录请求，但 `Q-序` 不得因此写成现有依据支持。

## 节点 1　相撞事实画像

1. 写明外法或境外文书将产生的具体效果：付款、交付、实施投资、披露、停止交易、执行财产。
2. 写明该效果将在中国发生的连结：履行、登记、进出口、资金跨境、对境内第三方效力。
3. 无中国连结：强制规范介入 `依据不足`，不得为了挡外法而虚构连结。
4. 港澳台安排下的公共秩序与外国公共秩序分列。

## 节点 2　强制性规定识别

1. 逐条候选规范写：制定机关、效力位阶、是否属于法律适用法意义上的强制性规定、介入条件。
2. 部门规章、规范性文件可能构成监管义务，但不当然等于法律适用法第八条的强制性规定。位阶不足时只标监管红旗，不写成合同当然无效。
3. 若：规范已废止或被替代（如旧外资备案办法）→ 记噪声，不写入 `L#`。
4. 出口许可、安全审查、外汇登记未完成：效果是不得实施或不得收付，不等于约定外法条款本身无效。分列 `Q-管` `Q-准` `Q-汇`。

## 节点 3　公共秩序

1. 公共秩序是例外，不是违约、管辖或执行的常规抗辩。
2. 承认执行场景：不得用公共秩序重审实体对错或重新计算违约金是否过高。
3. 若：仅因适用外法结果与中国任意性规范不同 → 通常不支持公共秩序。
4. 涉及制裁、出口管制、数据出境、金融审慎时，先走具体强制规范，能具体则不升格空泛公共秩序。
5. 是否损害社会公共利益运行时核验，结论只三态，不预测法院一定适用。

## 节点 4　后果分流

1. 可能后果分列：外法规则不适用、合同条款不发生该效力、不得履行、不得承认或执行、行政处罚或刑事红旗。禁止合成“全部无效所以不用付钱”。
2. 部分条款相撞时做部分排除，不当然否定全部合同。
3. 承认执行报核只标红旗，不预测最高法院结果。
4. 金额：因强制规范不能履行造成的损失另转测算原子，本任务不编伪精确数字。

## 节点 5　下一步与安全

1. 下一步：核验现行条文、补连结事实、转管制／准入／承认原子、向客户披露不得实施项。
2. 用户坚持按外法在中国实施被禁止行为：该部分整体停止，不提供变通。
3. 不把本评估写成“外法无效意见书”对外使用。
