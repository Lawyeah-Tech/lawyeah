# 边界与路由

## 正触发

约定外法或境外裁决、决定可能撞上中国强制规范或公共秩序，且本次主成果是强制规范与公共秩序评估。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 选定准据法路径 | `评估准据法与强制性规范` |
| 承认执行申请终稿 | `申请承认和执行外国仲裁裁决 或 apply-recognize-foreign-judgment` |
| 应对承认执行 | `应对承认执行外国裁决或判决` |
| 规避强制规范方案 | 拒绝，该部分整体停止 |
| 出口管制清单判断为主 | `评估出口管制与制裁风险` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 走私、逃避商检、无证出口刑事立案 | 刑事领域 |
| 经营者集中申报 | 竞争法领域 |
| 数据出境安全评估 | 数据领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

强制规范介入不等于合同全部无效，也不等于境外裁决必然不予承认。普通违约金调整走民法典，不走公共秩序。
