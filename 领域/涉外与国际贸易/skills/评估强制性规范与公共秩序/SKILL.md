# 评估强制性规范与公共秩序

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成中国强制性规范清单、公共秩序红旗和后果分流，而不把外法或境外裁决写成必然无效。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：约定外法或境外裁决、决定可能撞上中国强制规范或公共秩序，且本次主成果是强制规范与公共秩序评估。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要选定准据法路径；
- 只要承认执行申请或抗辩终稿；
- 要把普通违约抗辩包装成公共秩序；
- 指导规避中国强制规范；

不定外国法无效的必然结论。公共秩序不是重审实体对错的工具。

## 建立评估坐标

确认：约定或适用的外法；拟承认的裁决或判决；可能介入的管制、外汇、外资、海关、竞争、金融规范；交易结构；履行地是否在中国。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关文书；`C#` 合同或裁决主文；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 强制规范或公共秩序假设；`V#` 评估版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。未知金额不写零。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验法释〔2020〕18 号第八条、法律适用法第五条、民事诉讼法公共秩序条款、出口管制法、外商投资法、外汇条例等候选强制规范。`search_law` 对强制规范定性为 required。工具不可用时继续编目可能相撞的规范名称和事实；效力结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　专项分流

准据法总评、承认终稿、刑事、规避方案转出或停止。

### 节点 2　相撞事实画像

写明外法效果和中国连结。无连结不得虚构。

### 节点 3　强制性规定识别

位阶不足只标监管红旗。废止规范记噪声。

### 节点 4　公共秩序

例外适用。不重审实体。能走具体规范不升格空泛公共秩序。

### 节点 5　后果分流和下一步

部分排除。不得实施项对客户披露。不提供变通。

## 停止与安全

- `整体停止`：立场不明；要求设计规避强制规范的结构。
- `字段停止`：法释〔2020〕18 号第八条、具体监管条文未核验。
- `目标停止`：主目标变为改合同、写承认申请或刑事辩护。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
