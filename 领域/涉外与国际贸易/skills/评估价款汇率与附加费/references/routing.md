# 边界与路由

## 正触发

调价、汇率或滞期附加费已成争，本次主成果是价款构成评估而不是税负或精算终稿。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 税务汇兑损益 | 税务领域 |
| 精算终稿 | `测算国际贸易价金与损害赔偿` |
| 运输滞期主轴 | 海事领域 |
| 框架与订单冲突专项 | `评估框架协议与分订单冲突` |
| 外汇无法收付 | `评估跨境收付与外汇合规` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 共同海损分摊 | 海事领域 |
| 伪造价格指数 | 整体停止 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

信用证少付不等于价款已经变。卖方事后加燃油附加费，要看合同是否保留。
