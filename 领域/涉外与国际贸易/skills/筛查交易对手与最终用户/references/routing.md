# 边界与路由

## 正触发

签约或发货前需要做名单筛查，本次主成果是筛查而不是许可申请或总图。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 改名换壳方案 | 拒绝并停止 |
| 许可材料 | `准备两用物项或出口许可材料` |
| 反制裁阻断专项 | `评估反制裁与阻断义务` |
| 不可靠实体应对 | `应对不可靠实体清单` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 刑事制裁名单辩护 | 刑事领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

筛查未命中不等于没有全面管制（知道或应当知道）。经销商未穿透不等于最终用户已清。
