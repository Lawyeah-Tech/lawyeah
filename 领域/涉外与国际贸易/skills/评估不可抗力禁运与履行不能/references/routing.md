# 边界与路由

## 正触发

制裁、禁运、疫情或出口中止被主张影响履行，需要事件定性而不是许可申请。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 许可申请 | `准备两用物项或出口许可材料` |
| 管制清单判断 | `评估出口管制与制裁风险` |
| 商业困难改价 | `评估价款汇率与附加费` |
| 反制裁阻断专项 | `评估反制裁与阻断义务` |
| 起草不可抗力条款 | 审查起草领域（本窗搁置） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 海事绕航或船舶不能开航主轴 | 海事领域 |
| 伪造禁令 | 整体停止 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

被列入制裁名单不等于买卖合同自动解除，但继续履行可能违法。未通知可能只影响免责不消灭事件本身。
