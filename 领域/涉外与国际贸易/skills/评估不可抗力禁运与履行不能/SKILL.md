# 评估不可抗力禁运与履行不能

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成事件定性、通知减损、变更或解除分流；不作商业困难等于法律不能；管制许可走管制原子。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：制裁、禁运、疫情或出口中止被主张影响履行，需要事件定性而不是许可申请。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 把利润下降当成不可抗力要求改价；
- 只要出口许可材料；
- 未成争改不可抗力条款；

商业困难不等于法律不能。管制许可走管制原子。不指导假通知。

## 建立评估坐标

确认：事件种类与时间线；合同不可抗力条款；通知是否已发；受影响的具体义务；是否存在替代履行；准据法；是否同时涉及中国或外国管制。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 禁令或疫情文件；`A#` 已承认中止；`R#` 机关禁令；`C#` 不可抗力条款；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 事件假设；`V#` 评估版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。未知金额不写零。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典第一百八十条、第五百九十条及情势变更。具体制裁清单以主管机关现行公布为准。工具不可用时继续做事件时间线；是否构成不可抗力的结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　专项分流

许可、清单、商业改价、伪造转出或停止。

### 节点 2　事件时间线

订约后才发生才可能不能预见。新闻稿不是机关文书。

### 节点 3　因果与减损

利润下降原则上不是不可抗力。能替代须减损。

### 节点 4　法律效果

不能实现目的才评估解除。情势变更另条。

### 节点 5　下一步

解除通知和许可分别转介。

## 停止与安全

- `整体停止`：伪造禁令或疫情证明；要求对方违法继续出口。
- `字段停止`：不可抗力与情势变更条文、清单状态未核验。
- `目标停止`：主目标变为许可终稿或改价谈判冒充不可抗力。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
