# 边界与路由

## 正触发

签约名、履行名、境外注册或授权书冲突需要单独盘点，且本次主成果不是办设立或写并购主体文件。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 办理境外设立 | 不实施，说明本任务只做识别 |
| 并购主体文件或交割 | 投资并购领域 |
| 准据法判断 | `评估准据法与强制性规范` |
| 公证认证路径 | `规划公证认证与附加证明书` |
| 未成争改主体条款 | 审查起草领域（本窗搁置） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权对价、交割、目标尽调 | 投资并购领域 |
| 船舶所有权、光租识别为主轴 | 海事领域 |
| 家事当事人或监护能力 | 家事领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

同一集团多个签约名并存时正触发，不得凭集团品牌合并。授权书已过期仍要求写成“可以签”时停止该结论。
