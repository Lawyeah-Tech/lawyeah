# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、路径、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然获批、必然解除、必然承认或唯一必得总额。

不得用已失效《合同法》代理规则写入 `L#`。境外公司是否存在、是否善意存续，必须回链登记地材料，不得凭中文译名相同合并主体。

`search_law` 返回已失效《合同法》及其解释、法释〔1999〕19 号、法释〔2007〕14 号或已废外资备案办法时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜主体角色｜文本名称｜登记名称｜注册地｜授权文件｜签字人｜能力争点｜支持事实｜不利事实｜判断｜待核`。

至少分列：

- `Q-签 签约主体同一性`
- `Q-履 履行或收款主体`
- `Q-代 授权与代理链条`
- `Q-能 权利能力或行为能力`
- `Q-印 印章或电子签名`

同一事实支持多项时分别说明效果，不重复金额。构成违约不等于当然解除。约定外法不等于可以无证出口或绕开准入。

## 节点 0　专项分流

| 信号 | 处置 |
| --- | --- |
| 主成果是设立境外公司、开立离岸账户 | 负触发，不实施 |
| 股权对价、交割、目标尽调主体文件 | 投资并购领域 |
| 只要准据法 | 评估准据法与强制性规范 |
| 家事离婚当事人识别 | 家事领域 |
| 海事船舶所有人或光船承租人主轴 | 海事领域 |

若：用户要求伪造授权书、倒签董事会决议或使用已注销主体签约 → 该部分整体停止。

## 节点 1　名称对照表

1. 逐份合同、订单、发票、信用证、提单、保函列出显示名称、地址、注册号。
2. 译名、缩写、曾用名、集团品牌名分列，不因近似自动合并。
3. 若：签约名与信用证申请人或受益人不一致 → `Q-签` 与 `Q-履` 分列，不得写成同一主体已确认。
4. 若：仅有微信昵称或邮箱后缀 → 主体同一性 `依据不足`。
5. 港澳台登记与外国登记分列，不得写成“外国公司”。

## 节点 2　登记与存续

1. 境外主体是否依法设立、是否存续、是否进入清算或注销，回链登记地证书或等效摘录。无材料则 `Q-能` `依据不足`，不得用“听说还在经营”写成存续。
2. 中国主体用市场监管登记信息核对法定代表人、经营状态。经营异常或注销标红旗。
3. 若：用户提供的是宣传册或官网截图 → 只作 `D#`，不得升格为 `R#`。
4. 变更名称或吸收合并：登记变更日与签约日比较。签约日后才成立的主体，不得写成签约当时已有能力。

## 节点 3　授权链条

1. 授权书、董事会决议、股东会决议、公司章程对外代表规则分列。缺一环则链条 `依据不足`。
2. 境外授权书在中国使用：公证、附加证明书或领事认证路径转 规划公证认证与附加证明书，本任务只标认证缺口，不代办。
3. 若：授权范围仅限谈判不及签约，或已过期，或被撤销 → `Q-代` 现有依据不支持该次签署。
4. 转授权必须有书面依据。口头“老板同意了”不得写成已授权。
5. 法定代表人签字与代理人签字分列；印章与签字冲突时并列，不选对用户有利的一种。

## 节点 4　能力与代表权冲突

1. 权利能力、行为能力、越权代表、表见代理分列。表见代理不得在相对方是否善意未核验时写成已成立。
2. 若：章程限制对外担保或大额采购，而相对方是否知道未证 → 效力 `依据不足`。
3. 合伙、信托、基金、分支机构以自己名义签约：能否独立承担责任运行时核验，不得把分支机构径自写成总公司已约束。
4. 付款账户名与签约名不一致：收款主体另列，不自动视为债务加入或债权转让。

## 节点 5　缺口和下一步

1. 输出对照表：不得合并的名称、缺失的登记或授权、认证需求、最晚补证时点。
2. 能力缺口不得用“先签后补授权”方案补正，除非已有可回链的追认事实。
3. 下一步：补登记摘录、补授权、转认证规划、转总图或论坛。不办设立，不写并购 SPA。
4. 若：主目标变为改签约主体条款 → 目标停止，审查起草搁置。
