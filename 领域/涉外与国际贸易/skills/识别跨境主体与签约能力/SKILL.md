# 识别跨境主体与签约能力

## 任务目标

在明确、无利益冲突的单方立场下，形成跨境主体对照表：签约名、注册地、履行名、付款名、授权链条、能力缺口和不得合并的名称冲突。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：签约名、履行名、境外注册或授权书冲突需要单独盘点，且本次主成果不是办设立或写并购主体文件。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 要办理境外公司设立或变更；
- 并购交易主体文件、尽调或交割为主成果；
- 只要准据法或论坛判断；
- 未成争只要改签约主体条款（审查起草搁置）；

本任务不办境外设立，不证明实体权利成立，不给签约必然有效的结论。

## 建立评估坐标

确认：使用者与授权；拟代表的一方；各文本上的名称；注册证书或商业登记；授权书、董事会决议或股东会决议；签字人身份；印章或电子签名；付款账户名；已知更名或吸收合并。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 登记或公证文书；`C#` 合同主体条款；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 主体假设；`V#` 对照表版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。未知金额不写零。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典关于民事权利能力和代理、公司法对外代表、涉外民事关系法律适用法关于民事主体和代理的冲突规则。境外登记效力不得用中国规则直接替代。工具不可用时继续做名称对照和授权链条编目；能力成立与否的法律结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　专项分流

设立、并购主体、家事、海事整案转出。伪造授权整体停止。

### 节点 2　名称对照表

签约名、信用证名、发票名分列。近似译名不自动合并。

### 节点 3　登记与存续

回链登记地材料。官网截图不升格为登记证据。

### 节点 4　授权链条

缺一环则依据不足。境外授权书只标认证缺口。

### 节点 5　能力冲突和下一步

表见代理不在善意未证时写成已成立。不写先签后补方案。

## 停止与安全

- `整体停止`：立场不明；伪造授权或倒签决议；坚持使用已注销主体。
- `字段停止`：境外登记规则、代理冲突规则、认证要求未核验。
- `目标停止`：主目标变为办设立、写并购文件或改合同主体条款。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
