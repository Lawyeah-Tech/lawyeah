# 边界与路由

## 正触发

对方已申请执行涉外或外国裁决，被执行方需要不予执行或不予承认。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 撤销裁决 | `申请撤销涉外仲裁裁决` |
| 应对承认外国判决 | `应对承认执行外国裁决或判决` |
| 转移财产 | 拒绝并停止 |
| 港澳台 | `评估涉港澳台法域与文书` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 隐匿财产 | 整体停止 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

撤销期过后仍可能主张不予执行，但事由和法院不同。外国裁决用公约第五条，不用国内撤销事由。
