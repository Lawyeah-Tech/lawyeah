# 边界与路由

## 正触发

相对方或己方被列入或面临列入不可靠实体清单，需要措施和程序评估。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 保证移出 | 拒绝保证 |
| 一般名单筛查 | `筛查交易对手与最终用户` |
| 继续做禁止交易 | 拒绝并停止 |
| 管制许可申请 | `准备两用物项或出口许可材料` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 代持继续交易 | 整体停止 |
| 刑事 | 刑事领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

相对方被列入不等于本方合同自动无效，但继续履行可能违法。移出申请不是已经移出。
