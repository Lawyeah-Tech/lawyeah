# 边界与路由

## 正触发

跨境或涉外事项需要要件、举证、认证和补证矩阵。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要总图 | `评估跨境事项总图` |
| 只要仲裁申请 | `提起中国涉外仲裁` |
| 域外送达设计 | `设计域外送达`（未安装则 `unavailable`） |
| 域外取证路径 | `规划域外取证与公证认证`（未安装则 `unavailable`） |
| 公证认证手续本身 | `规划公证认证与附加证明书`（未安装则 `unavailable`） |
| 海事证据保全、扣船 | 海事领域 |
| 违法取证 | 拒绝 |

## 专项整案转出

走私侦查中的物证 → 刑事。船上货物扣押 → 海事。

## 易混

有认证需求仍正触发。只要“去使馆盖章”而没有争点要件时，转认证规划原子或 `unavailable`。
