# 建立跨境争议证据与认证案卷

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成跨境证据案卷矩阵：争点要件、举证责任、支持与不利材料、认证状态、控制方、合法取得、缺口、补证步骤和最晚时点。

`depends-on` 为空。本任务不是策略备忘，也不是仲裁申请。

## 工作边界

正触发：跨境或涉外事项需要单独建卷，或评估后要把要件、举证、认证做成可回链案卷。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要策略总图或仲裁申请；
- 海事证据保全或扣船为主成果；
- 用户要求违法跨境调取、入侵邮箱或伪造提单。

不能因对方控制而推定材料存在或有利于己方。

## 建立案卷坐标

确认：立场；待证争点；准据法和论坛；已持有材料及形成地；认证现状；对方或第三人控制的线索；举证期限状态。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关文书；`C#` 合同条款；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`EV#` 证据条目；`V#` 案卷版本；`E#` 送达或履行凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验举证责任、电子数据、域外证据形式和非法证据排除。工具不可用时继续材料编目；举证责任、举证期限、认证必要性的法律结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [建卷方法](references/method.md) 为准。

### 1. 专项分流、立场和争点要件

海事、刑事违法取证转出。把每个 `Q#` 拆成待证要件。

### 2. 举证责任分配

逐要件写谁主张、谁举证、转移条件。规则未核验则分配字段停止。

### 3. 支持、不利、控制方、认证和合法取得

境外书证单列公证、附加证明书或领事认证状态。缔约状态运行时核验。

### 4. 缺口、补证和最晚时点

不能合法取得的标停止，不给规避方案。

### 5. 保全红旗、禁止动作和转介

不代申请调查令或保全，不把案卷改写成仲裁申请。

## 停止与安全

- `整体停止`：立场不明。
- `该部分整体停止`：坚持伪造、隐匿、偷拷、非法侵入或违法跨境取证。
- `字段停止`：举证规则或认证规则未核验。
- `目标停止`：主目标变为策略总图或仲裁申请。
