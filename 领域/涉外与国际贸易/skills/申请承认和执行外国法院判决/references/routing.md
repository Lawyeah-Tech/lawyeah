# 边界与路由

## 正触发

持外国判决需在中国承认执行，且文书不是外国裁决或港澳台裁判。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 外国裁决 | `申请承认和执行外国仲裁裁决` |
| 港澳台认可 | `评估涉港澳台法域与文书` |
| 离婚判决 | 家事领域 |
| 应对承认 | `应对承认执行外国裁决或判决` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 家事离婚承认 | 家事领域 |
| 伪造判决 | 整体停止 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

外国法院调解书不一定都能走判决承认。互惠不是有大使馆就成立。
