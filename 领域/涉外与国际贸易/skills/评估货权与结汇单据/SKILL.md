# 评估货权与结汇单据

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成买卖合同下的货权节点、单据瑕疵和付款条件；运输合同、船舶、海事保全转海事。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：提单、仓单、发票在买卖合同下的货权或付款发生争执，且主轴不是运输合同。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 运输合同、船舶物权或扣船主轴；
- 只要信用证表面相符；
- 只要贸易术语费用分界；

运输合同、船舶、海事保全转海事。提单仅在买卖结汇货权语境下保留。

## 建立评估坐标

确认：买卖合同交货与单据条款；提单或仓单类型（记名、指示、不记名）；持有人；是否已转让；付款或信用证状态；货物所在。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 提单仓单发票表面；`A#` 持有现状；`R#` 登记或保全裁定；`C#` 单据条款；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 货权假设；`V#` 评估版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。未知金额不写零。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典物权和买卖交付、海商法中与提单相关但仅在买卖语境需要的接口。海商专项条文不在本任务展开。工具不可用时继续做持有链条编目；物权变动结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　海事闸

运输、扣船、船舶转海事。伪造提单停止。

### 节点 2　单据类型

提单、海运单、仓单分列。电放后持正本效力不足。

### 节点 3　货权节点

风险转移不等于所有权转移。保留所有权须原文。

### 节点 4　交单付款

未交约定单据可能阻却付款请求。信用证另项。

### 节点 5　转让与下一步

背书断裂则受让权利不足。扣船转海事。

## 停止与安全

- `整体停止`：伪造提单或指导无单放货补假单。
- `字段停止`：物权变动、提单类型效力未核验。
- `目标停止`：主目标变为运输合同或扣船。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
