# 边界与路由

## 正触发

提单、仓单、发票在买卖合同下的货权或付款发生争执，且主轴不是运输合同。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 运输合同或扣船 | 海事领域 |
| 信用证不符点 | `评估信用证不符点与拒付` |
| 术语费用分界 | `评估贸易术语风险费用分界` |
| 托收押汇 | `评估贸易融资单据争议` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 伪造提单或无单放货补假单 | 整体停止并刑事红旗 |
| 船舶物权 | 海事领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

持有提单不等于买卖合同下已付款。电放后仍要货权，必须另找合同与占有事实。
