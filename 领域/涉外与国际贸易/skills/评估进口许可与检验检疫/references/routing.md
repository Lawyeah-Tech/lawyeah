# 边界与路由

## 正触发

自动许可、进口许可证或法检阻碍通关，需要判断类型和补办路径。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 代报关 | 不实施 |
| 归类估价 | `评估归类估价与原产地` |
| 出口许可材料 | `准备两用物项或出口许可材料` |
| 伪报法检 | 拒绝并停止 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 食品药品注册整案 | 相应行业或行政接口 |
| 走私夹藏 | 刑事领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

货物已到港仍可能因无法检不能提货。自动许可未办不等于货物违法，但可能不能报关。
