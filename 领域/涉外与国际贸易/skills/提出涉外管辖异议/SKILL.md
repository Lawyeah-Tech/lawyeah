# 提出涉外管辖异议

## 任务目标

在明确、无利益冲突的被请求方立场下，形成异议书、不方便法院、专属管辖和逾期风险；与仲裁协议异议不同；过期停止终稿。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：已被起诉或被申请，需在法定期限提管辖异议。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 过期仍要异议终稿；
- 与仲裁协议异议混成同一主成果而不分账；
- 原告要选定管辖法院；

与仲裁协议异议不同。过期停止终稿。不保证异议成立。

## 建立评估坐标

确认：受诉法院；送达日；异议期限；协议管辖；专属管辖线索；不方便法院五项事实；是否已实体答辩。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 起诉状和条款；`A#` 送达事实；`R#` 应诉通知；`C#` 管辖条款；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 异议理由；`V#` 异议书版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。未知金额不写零。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民诉法管辖异议期限、涉外协议管辖、第 282 条不方便法院。工具不可用时继续固定送达日；异议是否仍可提的结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　期限闸

过期停止终稿。送达不明则期限字段停止。

### 节点 2　是否已放弃

应诉答辩效果待核。不写肯定已放弃。

### 节点 3　协议与专属

港口作业可能转海事。格式条款提示待核。

### 节点 4　不方便法院

五项都要填。缺一项该路径依据不足。

### 节点 5　仲裁另账与异议书

不与仲裁主成果打架。不代提交。

## 停止与安全

- `整体停止`：过期赶终稿；把不方便法院写成唯一口号而无五项事实。
- `字段停止`：异议期限、第 282 条、放弃异议规则未核验。
- `目标停止`：主目标变为仲裁协议专项或起诉。
