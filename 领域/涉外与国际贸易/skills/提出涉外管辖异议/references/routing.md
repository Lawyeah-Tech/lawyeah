# 边界与路由

## 正触发

已被起诉或被申请，需在法定期限提管辖异议。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 过期终稿 | 停止终稿 |
| 仲裁协议效力专项 | `评估涉外管辖与仲裁协议` |
| 原告起诉选法院 | `提起中国法院涉外民事诉讼` |
| 应诉总包且异议非主成果 | `应对中国法院涉外民事诉讼` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 海事专属或港口作业 | 海事领域 |
| 劳动仲裁管辖 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

提了管辖异议不等于可以不准备实体抗辩。不方便法院不是协议管辖的替代口号。
