# 评估境外用工当地法与派遣准入

## 任务目标

在明确、无利益冲突的单方立场下，形成境外用工准入监管、合同接口和与中国劳动边界；外国人在华用工和中国劳动权益转劳动。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：中国企业派人出境或在境外雇工，需要当地法与签证准入判断。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 外国人在华工作许可或中国劳动合同争议；
- 只要中国社会保险补缴；
- 未成争起草境外雇佣合同（搁置）；

外国人在华用工和中国劳动权益转劳动。不定境外执业或劳动资格的最终结论。

## 建立评估坐标

确认：派遣或当地雇佣；目的地；工作内容；停留期限；是否通过当地实体发薪；中国劳动合同是否仍在履行。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 派遣安排；`A#` 人员名单；`R#` 签证或许可；`C#` 劳动合同或派遣协议；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 准入假设；`V#` 评估版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。未知金额不写零。

## 律页能力增强

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验中国出境入境、对外劳务合作、劳动合同在境外履行的接口。当地签证和劳动法结论必须标境外律师核验，本任务不得写成已查明外国法。工具不可用时继续做安排画像；中国法接口结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　分流闸

在华用工和中国劳动权益转劳动。无资质外派停止。

### 节点 2　安排定性

内派、当地雇、劳务合作分列。长期出差升高许可红旗。

### 节点 3　中国法接口

境外履行仍可能适用部分强行规定。税负转税务。

### 节点 4　当地准入红旗

只列待核和当地律师接口。不定免签可工作。

### 节点 5　边界与下一步

回国劳动争议转劳动。不起草合同。不定外国法。

## 停止与安全

- `整体停止`：无资质外派方案；把外国劳动法写成已查明结论。
- `字段停止`：对外劳务合作、劳动合同域外适用未核验。
- `目标停止`：主目标变为在华用工或起草雇佣合同。
