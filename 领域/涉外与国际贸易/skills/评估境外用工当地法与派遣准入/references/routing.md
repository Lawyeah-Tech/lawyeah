# 边界与路由

## 正触发

中国企业派人出境或在境外雇工，需要当地法与签证准入判断。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 外国人在华用工或中国劳动权益 | 劳动领域 |
| 起草境外雇佣合同 | 审查起草领域（本窗搁置） |
| 船员派出海事主轴 | 海事领域 |
| 税负测算 | 税务领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 无资质经营性外派 | 整体停止 |
| 数据出境随人员携带专项 | 数据领域接口 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。海上运输、船舶、海事保险、海事保全、共同海损一律转海事领域，本任务只保留买卖结汇语境下的货权接口。

## 易混

持旅游签工作不是合规出差。中国劳动合同未解除不等于已满足当地工作许可。
