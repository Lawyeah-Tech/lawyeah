# 边界与路由

## 正触发

已收到与公司组织或股东权利有关的一审起诉状、应诉通知或等价被诉碎片，需要被告列法、请求拆解、送达与期限、程序和实体抗辩接口及答辩草稿。从零、碎片、送达未核验、无书面应诉授权仍正触发：有起诉状或应诉通知碎片则闸开或半开，出 `DB#` 草案，保持草案。本次不代提交、不选定法院是交付禁令，不是开窗条件。已读即送达、不答辩即败诉、有效仲裁仍当本案必审，仍正触发。同时要答辩草稿和管辖红旗时正触发，管辖只开时点接口。

双方秘密、伪造会议、倒签答辩、隐匿账簿、指使作伪证、抢夺印章证照、违法取证的停止，优先于负触发。上述信号不在下表。「草稿即已答辩」「已读即已送达」「不答辩即败诉」「有效仲裁仍当本案必审」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 原告起诉包 | `提起股东权利诉讼` |
| 决议不成立／无效／撤销之诉终稿 | `提起决议不成立无效或撤销之诉` |
| 查阅之诉终稿 | `提起查阅权诉讼` |
| 利润分配之诉终稿 | `提起利润分配之诉` |
| 股东代表诉讼终稿 | `提起股东代表诉讼` |
| 司法解散诉状 | `提起司法解散之诉` |
| 管辖或仲裁效力评估终稿，或只要管辖异议终稿且拒绝任何实体 | `评估股东争议管辖与仲裁条款` |
| 保全复议或担保置换终稿 | `应对股权冻结或行为保全` |
| 保全申请终稿 | `准备股权或公司财产保全` |
| 已过首次应诉的庭审提纲 | `准备股东与公司治理案件庭审` |
| 证据案卷终稿 | `建立公司治理与股东争议证据案卷` |
| 可签和解或退出协议全文 | `起草股东和解或退出协议` |
| 上诉状 | `提起公司治理案件上诉` |
| 劳动应诉 | 劳动领域 |
| 投并购交割 | 投资并购领域 |
| 破产衍生诉讼整体统筹 | 破产领域 |
| 婚家分割中的股权 | 婚家领域 |
| 合伙或个人独资 | 非公司主体 |

不得因「不代提交」或「不出反诉终稿」关窗。拟答辩草稿仍正触发，不得写成已答辩或保证驳回。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |

| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |

| 上市公司发行、持续信息披露主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「应诉」「答辩」「管辖」「仲裁」一词不是转出。
