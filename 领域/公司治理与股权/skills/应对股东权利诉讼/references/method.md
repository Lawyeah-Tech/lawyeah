# 应对股东权利诉讼方法

本文件是可执行判断节点。草稿不是已答辩。已读不是已送达。网交不是已提交。不提出答辩状不是当然败诉。有效仲裁不是本案必审。无股东资格不是可维持撤销。前置未完成不是代表诉讼已可审。选定某院不是管辖已定。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、保证驳回、已答辩、唯一必得总额、选定法院、代提交、未知写零。本任务不定罪，不写发送版答辩状，不写反诉状终稿。本窗闸名只能是答辩闸，禁止复用应诉闸、应对闸、起诉闸、立案闸、诉材闸、案卷闸、退出闸、决议闸、关系闸、僵局闸、和解闸、谈判闸。本窗 `DB#` 是答辩行。英文 id 禁止使用，一律用中文技能名 `应对股东权利诉讼`。主路径只用 `Q-辩`，禁止 `Q-应`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 2017 年民事诉讼法第一百二十五条、第一百二十七条当现行答辩或管辖异议、2017 年第二十六条当现行公司诉讼管辖、1993 年公司法第一百八十九条当现行代表诉讼、2018 年第一百五十一条或第二十二条当现行、MCP 把已施行的 2025 年仲裁法标尚未施行时记为噪声，以施行日为准。禁止指导隐匿账簿、伪造会议或抢夺印章。伤残等级与本窗无关。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现请求或抗辩扫描，不是默认闭集。
`DB#` 固定列：`编号｜被告列法｜对方请求类型｜送达与期限接口｜程序抗辩｜实体抗辩｜反诉接口｜证据目录｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。无 `E#` 不得写已答辩、已送达、已提交或保证驳回。`E#` 只作证据形态回链，不是发送闸。扫描不是闭集。缺项记 `G#`。承认只进 `S#`／`D#`，不得占用 `A#`。期限不得另开 `K#` 为主行。答辩期、举证期、管辖异议期、仲裁异议时点必须分列，禁止合成一张截止卡。

口头「已经被诉了」「微信已读就算送达」「已经答辩了」「不答辩就败了」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。已排期且主成果只要庭审提纲不得继续生成首次答辩入口终稿。

实务上：不提出答辩状不影响审理，不等于当然败诉。网上提交回执不是已答辩。公司设立、确认股东资格、分配利润、解散以及知情权、公司决议等由公司住所地管辖，连结点并列，不得保证某院。管辖异议须在提交答辩状期间提出；未提异议并应诉答辩或反诉的，有应诉管辖风险，不是本窗写成「已接受管辖闭集」。撤销之诉原告起诉时须有股东资格。决议之诉应列公司为被告。代表诉讼胜诉利益归公司；书面请求前置未闭合且无紧急事实，不得出代表诉讼已可审终稿。有有效仲裁协议，人民法院通常不予受理或驳回起诉，首次开庭前未异议视为放弃，不是「只能实体打」。

## 节点 0　分流、立场、答辩闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造会议或股东资格材料、倒签答辩状或送达回证、隐匿账簿、指使作伪证、虚假诉讼、抢夺印章证照、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `DB#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是原告起诉包 | 负触发 `提起股东权利诉讼` |
| 主成果是决议之诉终稿 | 负触发 `提起决议不成立无效或撤销之诉` |
| 主成果是查阅之诉终稿 | 负触发 `提起查阅权诉讼` |
| 主成果是分配之诉终稿 | 负触发 `提起利润分配之诉` |
| 主成果是代表诉讼终稿 | 负触发 `提起股东代表诉讼` |
| 主成果是司法解散诉状 | 负触发 `提起司法解散之诉` |
| 主成果是管辖或仲裁效力评估终稿，或只要管辖异议终稿且拒绝任何实体 | 负触发 `评估股东争议管辖与仲裁条款` |
| 主成果是保全复议或担保置换终稿 | 负触发 `应对股权冻结或行为保全` |
| 主成果是保全申请终稿 | 负触发 `准备股权或公司财产保全` |
| 主成果是已过首次应诉的庭审提纲 | 负触发 `准备股东与公司治理案件庭审` |
| 主成果是证据案卷终稿 | 负触发 `建立公司治理与股东争议证据案卷` |
| 主成果是可签和解或退出协议 | 负触发 `起草股东和解或退出协议` |
| 主成果是上诉状 | 负触发 `提起公司治理案件上诉` |
| 主成果是投并购交割 | 整案转投资并购 |
| 主成果是劳动应诉 | 整案转劳动 |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不代提交」「不选定法院」「不给胜诉率」「不出反诉终稿」 | 交付禁令，不是负触发 |

出现「应诉」「答辩」「管辖」「仲裁」一词不是转出。已读即送达、不答辩即败诉不是负触发，该格不支持。同时要答辩草稿和管辖红旗：本窗正触发，管辖只开时点接口，不出异议书终稿，实体 `DB#` 可留。

答辩闸打开（可出 `DB#` 草案，仍不得标「已答辩／已提交／已送达／保证驳回」）须同时满足：单方无冲突立场已闭合；主成果是首次一审答辩草稿，不是起诉包、不是管辖异议唯一成果、不是反诉终稿、不是庭审提纲；至少一项可编号起诉状、应诉通知、传票、举证通知或案号碎片。口头「已经被诉了」不算单独开闸材料。微信或邮箱收到的起诉状 PDF 可作被诉碎片，不得单独起算答辩期。仲裁条款出现不是关闸条件。

答辩闸部分打开：已有碎片，但送达日、资格、前置、管辖或仲裁未闭合；对应格待核；仍交十节。无书面应诉授权但立场已闭合且有碎片：部分打开，不是整体停止。

答辩闸关闭（仍正触发）：无一可编号碎片。「今天必须出已答辩／保证驳回终稿」而无最小碎片不得开闸。不出 `DB#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `DB#` 终稿，**第 7 节不得出可提交答辩状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已答辩」「已读即已送达」「微信转发即法定送达」「网交即已提交」「不答辩即败诉」「过期仍要可提交终稿」「有效仲裁仍当本案必审」「无股东资格仍可撤」「前置未完成仍已可审」「只列对立股东漏列公司即程序已闭合」「轻微瑕疵当然应驳回」「盈利即无解散之诉」「选定某院」「保证驳回」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `DB#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 答辩闸关闭，仍交十节，不是整体停止。
若 if 同时掌握该被告与对立股东或公司相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造会议或股东资格材料、倒签答辩状或送达回证、隐匿账簿、指使作伪证、虚假诉讼、抢夺印章证照或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个请求类型或被告切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `DB#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 被告 | 决议／查阅／分配／解散列公司；代表诉讼列加害董事或第三人、公司为第三人接口 | 决议之诉只列对立股东漏列公司即程序已闭合 |
| 原告适格抗辩 | 撤销之诉起诉时股东资格待核 | 无资格仍写成可维持撤销，或资格抗辩写成已胜诉 |
| 请求 | 查阅／决议／出资／分配／回购／代表诉讼／人格否认／解散分列 | 预先锁定保证驳回或本案必审 |
| 管辖 | 连结点并列；异议须在提交答辩状期间 | 选定唯一法院或此致某院 |
| 仲裁 | 条款表面与排除证据分列；首次开庭前异议 | 写成不影响审理、只能实体打 |

检索锚点（写入 `L#` 前须核验）：

- 民事诉讼法第一百二十八条答辩期、不提出答辩状不影响审理。噪声：2017 年第一百二十五条。
- 第一百三十条管辖异议期间与应诉管辖。噪声：2017 年第一百二十七条。
- 第二十七条公司住所地管辖。噪声：2017 年第二十六条。民诉解释第二十二条知情权、公司决议等依照第二十七条，仍引旧第二十六条须核验对应。
- 第九十条电子送达须同意且确认收悉。
- 公司法第二十六条撤销除斥；不成立／无效不适用该六十日。解释四第二条起诉时须有股东资格、第三条列公司为被告，旧第二十二条须核验对应现行第二十六条。
- 代表诉讼常见检索第一百八十九条：书面请求、三十日、紧急例外、利益归公司。噪声：1993 年第一百八十九条、2018 年第一百五十一条。
- 查阅第五十七条；不正当目的由公司举证；存在诉讼不是不正当目的已成立。分配解释四第十五条只开抗辩接口，禁止必得驳回。解散第二百三十一条。
- 仲裁法（2025 修订，施行日 2026-03-01）第五条或裁或审、第三十七条首次开庭前异议或视为放弃。噪声：MCP 标尚未施行但施行日已过；2017 年第五条、第二十六条未核验对应。民诉解释第二百一十六条只开接口。

不得暗示「不答辩就一定败诉」或「已读就算送达」。

## 节点 3　答辩行 `DB#`

按已出现请求类型扫描，不是默认闭集。每条须能指向被告列法、送达与期限、程序抗辩和实体抗辩。

无 `E#` 不得写已答辩、已送达、已提交或保证驳回。状态默认 `草案`。一次只推荐下一步。未知金额不写零。管辖连结点并列，禁止此致某院。证据目录绑定待证事实，不是已质证。反诉、保全只做红旗，不出终稿。答辩期、管辖异议期、举证期、仲裁异议时点分列，禁止合成唯一截止日。

热冲突强制处理：

- 草稿即已答辩／已读即已送达／网交即已提交／不答辩即败诉／过期仍要可提交／有效仲裁仍当本案必审／无资格仍可撤／前置未完成仍已可审／漏列公司即程序已闭合／选定某院／保证驳回／未知写零 → 该格不支持或字段停止；仍出其他 `DB#`。
- 无一碎片 → 关闸，不出 `DB#` 终稿，窗口不关。
- 指导伪造会议、倒签答辩、隐匿账簿、作伪证、抢夺印章 → 整体停止，不是该格不支持。

被告控制账簿不是推定对原告有利，也不是可隐匿。存在诉讼不是不正当目的已成立。轻微瑕疵须「轻微且对决议未产生实质影响」，不得空喊当然应驳回。无具体分配方案只开解释四第十五条抗辩接口，禁止必得驳回。盈利不是关闭解散接口的充分理由。

## 节点 4　管辖仲裁、保全、反诉与庭审接口

第 7 节只开接口，不得夹带 `DB#` 终稿、可提交答辩状、反诉状终稿或保全复议终稿绕闸。闸关闭时第 7 节可写「闸未开，转介待起诉状或应诉通知编号」，不得补写已答辩。十五日／六十日／三十日／一年／首次开庭前只开接口，不写唯一截止日，不选定法院。

下一步只转介：`评估股东争议管辖与仲裁条款`、`应对股权冻结或行为保全`、`准备股东与公司治理案件庭审`、`提起股东权利诉讼`、`建立公司治理与股东争议证据案卷`、`起草股东和解或退出协议`、`评估股东会董事会决议效力`、`评估股东知情查阅权`、`评估股东代表诉讼条件`、`评估公司僵局`。禁止此致某院。不选定法院。不代提交。

若 if 用户催促「已读就算送达／不答辩就败了／写完就算交了／某院一定管／保证能驳回／金额先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。
