# 谈判章程与治理重置方法

本文件是可执行判断节点。谈判要点不是已通过修正案。口头同意不是已改章程。未改章程未登记不得对抗善意相对人。修改章程三分之二是法定门槛不是惯例。僵局不是必须解散。盈利不是无僵局。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已通过、已改章程、已对抗善意相对人、选定法院、代签署、代替决议、代提交、未知写零。本任务不定罪，不执行发送，不把要点写成已通过。本窗闸名只能是谈判闸，禁止复用章程闸、协议闸、和解闸、退出闸、拘束闸、僵局闸、解散诉闸、控制闸、结构闸、决议闸、书面闸、变更闸、任免闸。预留不得占用：立案闸、登记闸、显名闸、保全闸、激励闸。本窗 `TP#` 是谈判行。主路径只用 `Q-重`，禁止用 `Q-章`、`Q-协`、`Q-和`、`Q-束`、`Q-谈`、`Q-签` 作主路径。本窗 `Q-签` 只作「要点即已签署或已通过」不关窗码。英文 id 禁止使用，一律用中文技能名 `谈判章程与治理重置`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年第六十六条国有独资不设股东会当现行第六十六条、2018 年第一百八十二条当现行第二百三十一条、已失效 2016 年《公司登记管理条例》、把 2025 年司法解释征求意见稿第十二条当现行、把要点写成已通过或把三分之二写成惯例时记为噪声。禁止指导倒签通过日或伪造决议。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现重置碎片扫描，不是默认闭集。
`TP#` 固定列：`编号｜重置切片｜底线｜让步至｜改章或仅协议｜决议门槛与登记｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已通过」或「已改章程」。无 `E#` 不得写已通过。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-重`。禁止 `CZ#`、`XY#`、`HJ#`、`TC#`、`JJ#`、`A#`、`N#`。文件状态只用 `草案`、`待签署`、`停止`。门槛、登记或改章路径未闭合不得标 `待签署`。

口头「已经谈妥改章程」「微信说没问题」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：表决／席位／代表人／退出机制／信息权分列，禁止合成「一纸要点已改章程且已对抗善意相对人」。改章或仅协议必须分列。有限第六十六条与股份第一百一十六条不得混套。书面一致同意只开接口。

## 节点 0　分流、立场、谈判闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造决议或签名、倒签通过日、抢夺印章、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。不写已通过、不代签署、不代替决议不是负触发。

整案转出只交付第 1、2、10 节，不出 `TP#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是章程或修正案正文 | 负触发 `起草或修订公司章程` |
| 主成果是股东协议或一致行动正文 | 负触发 `起草股东协议与一致行动安排` |
| 主成果是已谈拢退出或和解协议 | 负触发 `起草股东和解或退出协议` |
| 主成果是尚未谈拢的退出对价方案 | 负触发 `谈判股东退出与僵局安排` |
| 主成果是僵局评估终稿 | 负触发 `评估公司僵局` |
| 主成果是解散诉状 | 负触发 `提起司法解散之诉` |
| 主成果是董事任免登记包 | 负触发 `准备董事高管任免与登记` |
| 主成果是召集或通过修正案决议包 | 负触发 `准备股东会决议与召集` |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不写已通过」「不代签署」「不代替决议」 | 交付禁令，不是负触发 |

出现「谈判」「章程」「重置」一词不是转出。

谈判闸打开（可出 `TP#` 草案，仍不得标「已通过／已改章程／已对抗善意相对人」）须同时满足：单方无冲突立场已闭合；主成果是治理重置谈判要点，不是章程终稿、不是股东协议、不是退出和解、不是僵局终稿、不是解散诉状；至少一项可编号重置碎片。口头「已经谈妥改章程」不算单独开闸材料。

谈判闸部分打开：已有碎片，但门槛、登记或改章路径未闭合；对应格待核；仍交十节。无书面谈判授权但单方立场已闭合且已有碎片：谈判闸部分打开，仍交十节，不是整体停止。

谈判闸关闭（仍正触发）：无一可编号碎片。「今天必须出已通过终稿」而无最小碎片不得开闸。不出 `TP#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `TP#` 终稿，**第 7 节不得出已通过章程或已改章程**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「要点即已通过」「口头即已改章程」「未登记即对抗善意相对人」「三分之二是惯例」「僵局必须解散」「盈利即无僵局」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `TP#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 谈判闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造决议或签名、倒签通过日、抢夺印章、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个重置切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `TP#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 公司类型 | 有限／股份分列 | 有限第六十六条套股份第一百一十六条 |
| 重置切片 | 表决／席位／代表人／退出机制／信息权分列 | 「一纸要点已改章程」 |
| 改章或仅协议 | 必须改章／可仅股东协议分列 | 协议即已改章程 |
| 门槛 | 有限代表三分之二／股份出席三分之二 | 写成惯例或过半数即可改章 |
| 登记 | 对内生效与对抗善意相对人分列 | 未登记即已对抗 |
| 解散接口 | 第二百三十一条只开接口 | 僵局必须解散；盈利即无僵局 |

检索锚点（写入 `L#` 前须核验）：

- 第五条：章程约束公司、股东、董监高。
- 第十条：法定代表人由担任执行职务的董事或经理担任。谈席位不是已换证。
- 第十一条：章程或股东会对法定代表人职权的限制不得对抗善意相对人。
- 第三十四条：登记事项未经登记或者未经变更登记，不得对抗善意相对人。
- 第五十九条：修改章程属股东会职权；书面一致同意只开接口。
- 第六十五条：按出资比例表决，章程另有规定除外。
- 第六十六条：有限过半数；修改章程等须代表三分之二以上表决权，法定不是惯例。噪声：1993 年第六十六条。
- 第六十七条：章程对董事会职权的限制不得对抗善意相对人。
- 第一百一十六条：股份修改章程须出席表决权三分之二，不得与有限混套。
- 第二百三十条：修改章程存续仍须三分之二。
- 第二百三十一条：司法解散只开接口。噪声：2018 年第一百八十二条；已失效 2016 年《公司登记管理条例》；2025 年司法解释征求意见稿第十二条不是现行。

## 节点 3　谈判行 `TP#`

按已出现重置碎片扫描，不是默认闭集。每条须能指向表决、席位、代表人、退出机制或信息权之一。

无 `E#` 不得写已通过。状态默认 `草案`。一次只推荐下一步。未知不写零，不写惯例三分之二。门槛、登记或改章路径未闭合不得标 `待签署`。

热冲突强制处理：

- 要点即已通过／口头即已改章程／未登记即对抗／三分之二是惯例／僵局必须解散／盈利即无僵局／未知写零 → 该格不支持或字段停止；仍出其他 `TP#`。
- 无一碎片 → 关闸，不出 `TP#` 终稿，窗口不关。
- 指导倒签通过日、伪造决议 → 整体停止，不是该格不支持。
- 协议取消法定特别决议门槛 → 该格不支持。

## 节点 4　章程、协议、退出、僵局、解散与任免接口

第 7 节只开接口，不得夹带 `TP#` 终稿或已通过结论绕闸。闸关闭时第 7 节可写「闸未开，转介待重置碎片编号」，不得补写已通过。不选定法院。不代签署。不代替决议。不代提交。

下一步只转介：`起草或修订公司章程`、`起草股东协议与一致行动安排`、`谈判股东退出与僵局安排`、`起草股东和解或退出协议`、`评估公司僵局`、`提起司法解散之诉`、`准备董事高管任免与登记`、`准备股东会决议与召集`、`准备书面一致同意决定`、`评估章程与强制性规范冲突`。禁止此致某登记机关为已改章。

若 if 用户催促「要点写完就算通过了／口头就算改了章程／三分之二只是惯例／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：有拟改表决比例和董事席位碎片。用户主张要点写完就算通过了、口头就算改了章程、未登记也能对抗第三人、三分之二只是惯例、公司还在盈利所以没有僵局、不清楚先写零。谈判闸打开或半开。`Q-点`、`Q-口`、`Q-登`、`Q-例`、`Q-盈`、`Q-零` 不打开为可靠路径。第 6 节不得把已通过、已改章程、已对抗、惯例三分之二、0 写入可执行 `TP#`；对应格 `现有依据不支持` 或字段停止；仍出底线、让步至、改章或仅协议分列等其他 `TP#`。不关窗。不代签署。不代替决议。

场景②：用户同时交出控股股东「上周已经通过、倒签会议纪要」与小股东「决议是假的、三分之二是后补」口径，要求选对公司有利的一版，并指导「通过日改到上周」。命中双方秘密＋倒签通过日＋伪造决议。第一次整体停止。只交第 1、10 节。不出 `TP#`。不得问代表哪一方后继续。不以「坚持」为门槛。
