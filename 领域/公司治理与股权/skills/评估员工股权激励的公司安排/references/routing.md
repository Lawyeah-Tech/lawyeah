# 边界与路由

## 正触发

拟用股权、期权、限制性股权或持股平台做员工激励，需要公司侧结构比较。从零、碎片、口头沟通未核验、无书面评估授权仍正触发：有可编号工具或授予碎片则闸开或半开，出 `JL#` 草案，保持草案。本次不把口头承诺写成已授予、不写劳动合同或个税方案是交付禁令，不是开窗条件。口头即已授予、未行权即已是股东、平台即目标公司股东、离职即当然收回、激励即劳动报酬已变更、有限套第 162 条当然合法，仍正触发。

双方秘密、伪造授予协议、倒签行权或会议、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「口头承诺即已授予」「期权未行权即已是股东」「平台份额即目标公司股东」「离职即当然收回已登记股权」「激励即劳动报酬已变更」「有限套第 162 条当然合法」「股权激励当然套第 163 条资助例外」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 劳动合同、解除、经济补偿或劳动争议 | 劳动领域 |
| 个税或企业所得税方案 | 税务领域 |
| 决议、授予协议、名册安排等公司文件终稿 | `准备限制性股权或期权的公司文件` |
| 上市公司股权激励监管专案 | 证券监管 |
| 股权结构图 | `梳理股权结构与控制权` |
| 名册记载请求 | `准备股东名册与工商变更衔接` |
| 增资实施包 | `准备内部增资与认缴调整` |
| 老股转让协议 | `准备有限公司股权内部转让` |
| 代持效力或显名终局 | `评估股权代持效力与显名` |
| 合伙或个人独资入伙退伙（非平台工具比较） | 非公司主体 |

不得因「不把口头承诺写成已授予」或「不写劳动合同」关窗。拟公司侧结构比较仍正触发，不得写成已授予或已经是股东。

## 易混

本窗闸名只能是股权激励闸，不是合规「激励闸」，不是下一窗授予闸。`JL#` 不是合规 `RP#`，不是结构窗 `GQ#`，不是代持窗 `DT#`，不是名册窗 `MC#`，不是转让窗 `ZR#`。主路径是 `Q-激`，不是代表诉讼常用的 `Q-代`，也不是合规负触发转出码。口头承诺不是已授予。期权未行权不是已经是股东。平台份额不是目标公司股东。离职不是当然收回已登记股权。有限公司不得机械套用第 162 条。第 162 条是三分之二以上董事出席开会，第 163 条是全体董事三分之二以上通过，禁止混写。第 163 条第一款例外是员工持股计划。1993 年第五十六条不是现行名册条。2018 年第一百四十二条不是现行回购条。2018 年第五十七条不是现行一人规则。上市公司股权激励管理办法不得整部套有限。「授予日改到入职前」整体停止。本窗不执行发送，不代提交。不选定法院。
