# 边界与路由

## 正触发

公司内部权力配置需要股东协议或一致行动安排，不是外部交易交割。从零、碎片、对公司效力未核验、无书面起草授权仍正触发：有可编号权力配置碎片则闸开或半开，出 `XY#` 草案，保持草案。本次不代签署、不写已签署、不把协议写成已修改章程是交付禁令，不是开窗条件。草稿即已签署、口头即已拘束、协议即已改章程、签署即对公司生效，仍正触发。

双方秘密、伪造协议或签章、伪造一致行动、倒签签署日、抢夺印章、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。不代签署不是负触发。「草稿即已签署」「口头一致行动即已拘束」「股东协议即已改章程」「签署即对公司生效」「未签署股东亦受约束」不在下表。

## 易混

本窗闸名只能是协议闸，不是和解闸，不是拘束闸，不是谈判闸，不是章程闸，不是退出闸。`XY#` 不是 `HJ#`，不是 `BJ#`，不是 `CZ#`，不是 `TC#`。主路径是 `Q-协`，不是 `Q-和`，不是 `Q-束`，不是 `Q-签`，不是 `Q-谈`。本窗 `Q-签` 只作「草稿即已签署」不关窗码。草稿不是已签署。口头一致行动不是已生效拘束。股东协议不是已修改章程。签署不是对公司当然生效。未签署股东不受约束。1993 年第五条不是现行第五条。2018 年第十一条不是现行第五条。2025 年司法解释征求意见稿第十二条不是现行。《上市公司收购管理办法》一致行动定义不得套非上市有限公司当然适用。「签署日改到成立前」「未签的人名也先填上」整体停止。本窗不执行发送，不代签署，不代提交。不选定法院。不把协议写成已修改章程。
