# 起草股东协议与一致行动安排方法

本文件是可执行判断节点。草稿不是已签署。口头一致行动不是已生效拘束。股东协议不是已修改章程。签署不是对公司当然生效。未签署股东不受约束。概括一致行动不是覆盖未知表决。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已签署、已改章程、对公司已生效、选定法院、代签署、代提交、未知写零。本任务不定罪，不执行发送，不把协议写成已修改章程。本窗闸名只能是协议闸，禁止复用和解闸、拘束闸、谈判闸、章程闸、退出闸、转让闸、控制闸、结构闸、决议闸。预留不得占用：谈判闸、立案闸、登记闸、显名闸、保全闸、激励闸。本窗 `XY#` 是协议行。主路径只用 `Q-协`，禁止用 `Q-和`、`Q-束`、`Q-签`、`Q-谈` 作主路径。本窗 `Q-签` 只作「草稿即已签署」不关窗码。英文 id 禁止使用，一律用中文技能名 `起草股东协议与一致行动安排`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年第五条自主经营当现行第五条、2018 年第十一条当现行第五条、把 2025 年司法解释征求意见稿第十二条当现行、把《上市公司收购管理办法》一致行动定义套到非上市有限公司、把草稿写成已签署或把协议写成已改章程时记为噪声。禁止指导倒签签署日、伪造签章或伪造一致行动。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现权力配置碎片扫描，不是默认闭集。
`XY#` 固定列：`编号｜协议切片｜权力配置｜一致行动范围与期限｜章程冲突与对公司效力｜违约救济｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已签署」或「已改章程」。无 `E#` 不得写已签署。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-协`。禁止 `HJ#`、`BJ#`、`TC#`、`CZ#`、`A#`、`N#`。文件状态只用 `草案`、`待签署`、`停止`。覆盖议案、期限、签署主体或章程冲突未闭合不得标 `待签署`。

口头「我们一致行动」「微信说签了」「协议签了就能管公司」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：表决／提名／信息／增资／转让／僵局分列，禁止合成「一纸协议已改章程且对公司生效」。全体股东另有约定只在法律明文处。对内有效不是对公司当然生效。违约投票不是决议不成立。未签署股东不受约束。继续履行表决不得写成法院必然责令投票。

## 节点 0　分流、立场、协议闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造协议或签章、伪造一致行动、倒签签署日、抢夺印章、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。不代签署、不写已签署、不把协议写成已修改章程不是负触发。

整案转出只交付第 1、2、10 节，不出 `XY#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是判断既有协议是否拘束本次表决 | 负触发 `评估表决权拘束与一致行动` |
| 主成果是章程或修正案正文 | 负触发 `起草或修订公司章程` |
| 主成果是治理重置谈判要点 | 负触发 `谈判章程与治理重置` |
| 主成果是已谈拢退出或和解协议 | 负触发 `起草股东和解或退出协议` |
| 主成果是尚未谈拢的退出谈判方案 | 负触发 `谈判股东退出与僵局安排` |
| 主成果是只要强制规范冲突评估 | 负触发 `评估章程与强制性规范冲突` |
| 主成果是收购交割文件 | 负触发投资并购领域 |
| 主成果是一般买卖借款合同 | 审查起草领域，本窗搁置 |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不代签署」「不写已签署」「不把协议写成已修改章程」 | 交付禁令，不是负触发 |

出现「协议」「一致行动」「股东协议」一词不是转出。

协议闸打开（可出 `XY#` 草案，仍不得标「已签署／已改章程／对公司已生效」）须同时满足：单方无冲突立场已闭合；主成果是发送前内部权力配置或一致行动草稿，不是拘束评估、不是章程终稿、不是和解正文、不是交割文件；至少一项可编号权力配置碎片。口头「我们一致行动」不算单独开闸材料。

协议闸部分打开：已有碎片，但覆盖议案、期限、对公司效力或章程冲突未闭合；对应格待核；仍交十节。无书面起草授权但单方立场已闭合且已有碎片：协议闸部分打开，仍交十节，不是整体停止。

协议闸关闭（仍正触发）：无一可编号碎片。「今天必须出已签署终稿」而无最小碎片不得开闸。不出 `XY#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `XY#` 终稿，**第 7 节不得出已签署或已改章程**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已签署」「口头一致行动即已拘束」「股东协议即已改章程」「签署即对公司生效」「未签署股东亦受约束」「概括一致行动覆盖未知表决」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `XY#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 协议闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造协议或签章、伪造一致行动、倒签签署日、抢夺印章、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个协议切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `XY#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 公司类型 | 有限／股份分列 | 把上市收购办法一致行动定义套到非上市有限 |
| 签署人 | 拟签署股东／未签署股东／公司分列 | 未签署股东亦受约束 |
| 权力配置 | 表决／提名／信息／增资／转让／僵局分列 | 「一纸协议已改章程」 |
| 一致行动 | 覆盖议案类型、期限、退出条件 | 无期限即永久；覆盖未知议案 |
| 章程冲突 | 对内对外分列；改章只开决议接口 | 协议即已修改章程 |
| 对公司效力 | 相对性；全体股东另有约定只在法律明文处 | 签署即对公司当然生效 |
| 底线 | 查阅、催缴失权、特别决议门槛 | 协议取消法定底线 |

检索锚点（写入 `L#` 前须核验）：

- 第五条：章程对公司、股东、董事、监事、高级管理人员具有约束力；股东协议不当然同范围。噪声：1993 年第五条自主经营；2018 年第十一条。
- 第十一条：章程或股东会对法定代表人职权的限制不得对抗善意相对人。
- 第二十一条：股东不得滥用股东权利。
- 第二十五条至第二十七条：决议三项只开接口。内部违约不当然落入三项。
- 第三十四条：登记事项未经登记不得对抗善意相对人。
- 第五十一条、第五十二条：催缴与失权底线不得协议取消。
- 第五十七条：查阅法定路径不得取消。解释四第九条章程或股东协议实质性剥夺查阅复制权利的，公司以此拒绝的人民法院不予支持；仍引旧第三十三条、第九十七条，须核对应第五十七条、第一百一十条。
- 第五十九条：修改公司章程属股东会职权；书面一致同意只开接口。
- 第六十四条：全体股东另有约定只在法律明文处。
- 第六十五条：按出资比例行使表决权，章程另有规定的除外；章程另有规定不是协议另定当然改表决权。
- 第六十六条：过半数／三分之二特别决议不得协议取消。
- 第八十四条末款：章程另有规定只覆盖对外转让程序。
- 民法典第五百七十七条、第五百八十条、第五百八十五条。不得写成法院必然责令按约定投票。未知违约金不写零。噪声：已失效《合同法》；2025 年司法解释征求意见稿第十二条不是现行。

## 节点 3　协议行 `XY#`

按已出现权力配置碎片扫描，不是默认闭集。每条须能指向权力配置、一致行动范围或章程冲突接口之一。

无 `E#` 不得写已签署。状态默认 `草案`。一次只推荐下一步。未知对价或出资不写零。覆盖议案、期限、签署主体或章程冲突未闭合不得标 `待签署`。

热冲突强制处理：

- 草稿即已签署／口头即已拘束／协议即已改章程／签署即对公司生效／未签署股东亦受约束／概括覆盖未知／取消法定底线／未知写零 → 该格不支持或字段停止；仍出其他 `XY#`。
- 无一碎片 → 关闸，不出 `XY#` 终稿，窗口不关。
- 指导倒签签署日、伪造签章、伪造一致行动 → 整体停止，不是该格不支持。
- 协议取消查阅、催缴失权或特别决议门槛 → 该格不支持；只开章程或冲突窗接口。

## 节点 4　拘束评估、章程、和解、谈判与交割接口

下一步只转介：`评估表决权拘束与一致行动`、`起草或修订公司章程`、`评估章程与强制性规范冲突`、`谈判章程与治理重置`、`起草股东和解或退出协议`、`谈判股东退出与僵局安排`、`准备股东会决议与召集`、`准备书面一致同意决定`、`评估股东争议管辖与仲裁条款`。禁止此致某登记机关为已改章。

## 本任务回链纪律

本任务成果是「协议闸与协议行草案」。本窗不执行发送。不包含：已签署终稿、已改章程、对公司已生效、拘束评估终稿。禁止选边治愈。禁止草稿即已签署。禁止协议即已改章程。禁止指导倒签或伪造签章。协议闸打开 ≠ 已签署 ≠ 已改章程 ≠ 对公司已生效。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标协议终稿已形成。
风险档 A：伪造协议或签章、伪造一致行动、倒签签署日必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：有表决拘束、董事提名和增资限制碎片。用户主张草稿写完就算签了、口头就算一致行动、协议写了就算改了章程、未签的人也要受约束、概括覆盖以后所有议案、不清楚先写零。协议闸打开或半开。`Q-签`、`Q-口`、`Q-改`、`Q-外`、`Q-扩`、`Q-覆`、`Q-零` 不打开为可靠路径。第 6 节不得把已签署、已改章程、对公司已生效、覆盖未知、0 写入可执行 `XY#`；对应格 `现有依据不支持` 或字段停止；仍出权力配置分列、期限缺口、章程冲突接口等其他 `XY#`。不关窗。不代签署。不把协议写成已修改章程。

场景②：用户同时交出控股股东「上周已经签了、倒签成立前已约束」与小股东「签章是假的、一致行动是后补」口径，要求选对公司有利的一版，并指导「签署日改到成立前、未签的人名也先填上」。命中双方秘密＋倒签签署日＋伪造签章。第一次整体停止。只交第 1、10 节。不出 `XY#`。不得问代表哪一方后继续。不以「坚持」为门槛。
