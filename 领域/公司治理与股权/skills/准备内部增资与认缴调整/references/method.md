# 准备内部增资与认缴调整方法

本文件是可执行判断节点。认购意向不是已变更注册资本。沉默不是默认放弃。董事会不是股东会增资。股份默认无优先认购不是有限优先认缴可套。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已变更登记、已放弃、选定法院、代提交、未知写零、唯一公允价。本任务不定罪，不执行发送，不代提交。本窗闸名只能是增资闸，禁止复用召集闸、章程闸、变更闸、减资闸、决议闸。本窗 `ZZ#` 是增资行。英文 id 禁止使用，一律用中文技能名 `准备内部增资与认缴调整`。主路径只用 `Q-增`，禁止 `Q-评`、`Q-减`、`Q-章`、`Q-召` 作主路径。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 2018 年第三十四条当现行第二百二十七条、把有限优先认缴套股份、把沉默写成放弃时记为噪声。禁止指导倒签放弃或伪造增资决议。伤残等级与本窗无关。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现增资碎片扫描，不是默认闭集。
`ZZ#` 固定列：`编号｜增资切片｜方案与价格｜优先认缴｜特别决议要点｜章程修正接口｜登记核验｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。无 `E#` 不得写已通过、已放弃或已变更登记。`E#` 只作证据形态回链，不是发送闸。扫描不是闭集。缺项记 `G#`。承认只进 `S#`／`D#`，不得占用 `A#`。文件状态只用 `草案`、`待发送`、`待签署`、`停止`。优先认缴未闭合不得标 `待发送`。

口头「已经增完了」「大家默认放弃」「董事会批了就算」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：有限增资股东在同等条件下有权优先按实缴比例认缴，全体另有约定除外。股份发行新股默认无优先认购。未书面通知且无全体另定不得出可对抗未放弃股东的增资终稿。新增认缴五年与股份先缴后登记分列。

## 节点 0　分流、立场、增资闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、倒签放弃、伪造增资决议、倒签通过日、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `ZZ#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是外部融资交割 | 整案转投并购 |
| 主成果是优先认缴是否被侵害 | 负触发 `评估增资优先认缴权` |
| 主成果是减资 | 负触发 `准备减资通知与债权人保护` |
| 主成果是章程终稿独占 | 负触发 `起草或修订公司章程` |
| 主成果是召集或决议包独占 | 负触发 `准备股东会决议与召集` |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不代提交」「不写已变更注册资本」 | 交付禁令，不是负触发 |

出现「增资」「认缴」「优先」一词不是转出。认购意向即已变更登记不是负触发，该格不支持。尚未决定增资但主成果仍是增资包：正触发关闸，第 7 节开评估接口。

增资闸打开（可出 `ZZ#` 草案，仍不得标「已变更登记／已放弃／已通过」）须同时满足：单方无冲突立场已闭合；主成果是内部增资方案草案，不是交割清单、不是优先认缴侵害评估、不是减资、不是章程终稿独占；至少一项可编号增资决定碎片。口头「已经增完了」不算单独开闸材料。

增资闸部分打开：已有增资决定碎片，但优先认缴、价格或特别决议门槛未闭合；对应格待核；仍交十节。无书面增资授权但立场已闭合且有增资决定碎片：部分打开，不是整体停止。

增资闸关闭（仍正触发）：无一可编号增资决定碎片。「今天必须出已变更登记终稿」而无最小碎片不得开闸。不出 `ZZ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `ZZ#` 终稿，**第 7 节不得出已变更登记或交割清单**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「认购意向即已变更注册资本」「沉默即放弃」「董事会即股东会增资」「股份套有限优先认缴」「有限新增五年套股份先缴后登记」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `ZZ#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号增资决定碎片，then 增资闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与未获通知股东相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出倒签放弃、伪造增资决议、倒签通过日、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个增资切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `ZZ#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 类型 | 有限／股份分列 | 有限优先认缴套股份 |
| 方案 | 拟增注册资本、各股东认缴增减、出资日期 | 未知写零；未通过写成已增资 |
| 优先认缴 | 有限按实缴比例、同等条件；股份默认无 | 沉默即放弃；已读即放弃 |
| 决议 | 有限代表三分之二；股份出席三分之二 | 混套；董事会冒充股东会 |
| 缴付 | 有限新增自变更登记之日起五年待核；股份先缴后登记 | 混套 |
| 公积金转增 | 法定公积金留存不得少于转增前注册资本 25% | 全额转增仍可提交 |

检索锚点（写入 `L#` 前须核验）：

- 第五十九条：增减资是股东会职权。第三款书面一致须全体签名或盖章。
- 第六十六条／第一百一十六条：特别决议分列。第一百一十二条不准用第五十九条第三款。
- 第二百二十七条：有限优先按实缴比例；股份默认无优先认购。噪声：2018 年第三十四条。
- 第二百二十八条：有限新增依设立有限缴纳规定；股份新增依设立股份缴款规定。
- 第四十七条／第九十八条：五年与先缴分列。公司登记管理实施办法：有限新增自变更登记之日起五年；股份全额缴纳后办理变更登记。
- 第二百一十四条：公积金转增留存 25%。
- 第三十四条：未经变更登记不得对抗善意相对人。变更登记不是已增资完成的唯一证明。

不得暗示「认购意向一签执照就改好了」。

## 节点 3　增资行 `ZZ#`

按已出现增资方向扫描，不是默认闭集。有限与股份、货币与非货币、公积金转增分列。

无 `E#` 不得写已通过、已放弃或已变更登记。状态默认 `草案`。一次只推荐下一步。未知价格不写零。未书面通知且无全体另定不得出可对抗未放弃股东的增资终稿。放弃须有可回链意思表示。沉默是否视为放弃：依据不足则字段停止。不得把第八十四条对外转让三十日未答复视为放弃套进第二百二十七条优先认缴。未实缴新增资本不得写成已经实收。

热冲突强制处理：

- 认购意向即已变更登记／沉默即放弃／董事会即股东会增资／股份套有限优先／五年混套／全额转增／估数或写零 → 该格不支持或字段停止；仍出其他 `ZZ#`。
- 无一增资决定碎片 → 关闸，不出 `ZZ#` 终稿，窗口不关。
- 指导倒签放弃、伪造增资决议、倒签通过日 → 整体停止，不是该格不支持。

## 节点 4　优先认缴评估、减资、章程、召集与交割接口

第 7 节只开接口，不得夹带 `ZZ#` 终稿、已变更登记或交割清单绕闸。闸关闭时第 7 节可写「闸未开，转介待增资决定编号」，不得补写已变更登记。夹带非货币作价只开非货币窗接口。新章程只开起草接口。决议包只开召集窗接口。

下一步只转介：`评估增资优先认缴权`、`准备减资通知与债权人保护`、`起草或修订公司章程`、`准备股东会决议与召集`、`准备股东名册与工商变更衔接`。禁止此致某登记机关为唯一路径。不代提交。不保证核准。

若 if 用户催促「意向签了就算改好了／不说话就算放弃／股份也要按有限优先／价格不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 再执行清单

每个节点结束后回写：来源、判断、最强反方、是否字段停止。不得跳过增资闸直接给已变更登记或已放弃。

若 if 优先认缴、特别决议门槛、五年缴付、公积金留存、施行日未核验，then 该强制项字段停止，窗口不关。
判断状态只许三值。口头「已经增完了」不得写成 `ZZ#` 已变更登记。未知不写零。

## 本任务回链纪律

本任务成果是「增资闸与内部增资方案草案」。本窗不执行发送。不包含：已变更注册资本、已放弃证明、交割清单、可签署章程终稿独占。禁止选边治愈。禁止认购意向即已变更登记。禁止沉默即放弃。禁止指导倒签放弃或伪造增资决议。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标增资终稿已形成。
风险档 A：倒签放弃、伪造增资决议、倒签通过日必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：已有拟增注册资本的股东会议题碎片。用户主张认购意向签了就算执照改好了、其他股东不说话就算放弃、股份公司也要按有限优先认缴、价格不清楚先写零。增资闸打开或半开。`Q-完`、`Q-默`、`Q-股`、`Q-零` 不打开为可靠路径。第 6 节不得把已变更登记、已放弃、股份优先认缴、0 写入可执行 `ZZ#`；对应格 `现有依据不支持` 或字段停止；仍出第二百二十七条分列、第六十六条特别决议待核、五年缴付待核、通知缺口等其他 `ZZ#`。不关窗。不代提交。不出交割清单。若同时要求倒签放弃日或伪造通过决议 → 改走场景②。

场景②：用户同时交出公司「全体已默认放弃」口径与未获通知股东「从未收到增资通知」口径，要求选对己方有利的一版，并指导倒签放弃、今晚把增资决议先做出来。命中双方秘密＋倒签放弃＋伪造增资决议。第一次整体停止。只交第 1、10 节。不出 `ZZ#`。不得问代表哪一方后继续。不以「坚持」为门槛。
