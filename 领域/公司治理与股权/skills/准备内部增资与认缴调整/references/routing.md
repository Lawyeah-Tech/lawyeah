# 边界与路由

## 正触发

已决定内部增资或调整认缴，需要增资方案、优先认缴通知和登记核验，而非外部融资交割。从零、碎片、优先认缴未核验、无书面增资授权仍正触发：有增资决定碎片则闸开或半开，出 `ZZ#` 草案，保持草案。本次不代提交、不写已变更注册资本是交付禁令，不是开窗条件。认购意向即已变更登记、沉默即放弃、股份套有限优先认缴，仍正触发。

双方秘密、倒签放弃、伪造增资决议、倒签通过日、抢夺印章证照、违法取证的停止，优先于负触发。上述信号不在下表。「认购意向即已变更注册资本」「沉默即放弃」「董事会即股东会增资」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 外部融资交割、投资协议和先决条件 | 投资并购领域 |
| 优先认缴是否被侵害 | `评估增资优先认缴权` |
| 减资通知与债权人保护 | `准备减资通知与债权人保护` |
| 可签署章程终稿独占 | `起草或修订公司章程` |
| 召集或可签署决议包独占 | `准备股东会决议与召集` |
| 合伙或个人独资 | 非公司主体 |

不得因「不代提交」或「不写已变更注册资本」关窗。拟内部增资仍正触发，不得写成已变更登记或已放弃。尚未决定增资但主成果仍是增资包：正触发关闸，第 7 节开评估接口。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果、员工激励的劳动身份 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |
| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「增资」「认缴」「优先」一词不是转出。

## 必转介接口

| 只要召集或决议包 | `准备股东会决议与召集` |
| 只要名册与工商变更 | `准备股东名册与工商变更衔接` |

## 易混

本窗闸名只能是增资闸，禁止复用召集闸、章程闸、变更闸、减资闸。认购意向不是已变更注册资本。方案未通过不是已经增资完成。沉默不是默认放弃。已读不是放弃。董事会不是股东会增资。股份默认无优先认购不是有限优先认缴可套。有限新增认缴五年不是股份先缴后登记。未实缴新增资本不是已经实收。公积金转增须留存转增前注册资本百分之二十五。2018 年第三十四条不是现行第二百二十七条。本窗 `ZZ#` 不是召集窗 `ZJ#`，不是章程窗 `CZ#`，不是变更窗 `BG#`。「放弃日先倒签」「决议今晚补一份」整体停止。本窗不执行发送，不代提交。不保证核准。伤残等级与本窗无关。
