# 边界与路由

## 正触发

股权、账户、章证照或行为已被保全，需要依法复议、异议或担保置换。从零、碎片、五日未核验、无书面应对授权仍正触发：有可编号已作出保全文书碎片则闸开或半开，出 `FZ#` 草案，保持草案。本次不保证解除、不代提交、不选定法院是交付禁令，不是开窗条件。复议即已解除、交保即已解冻、异议即已排除、复议期间停止执行，仍正触发。

双方秘密、转移隐匿、违反裁定、串通解冻、换章对抗、抽逃作置换担保、伪造权属、倒签复议日、违法取证的停止，优先于负触发。上述信号不在下表。不保证解除不是负触发。「复议即已解除」「交保即已解冻」「异议即已排除」「复议期间停止执行」「冻结即无表决权」「行为保全交保即应当解除」「可以变更即应当解除」「保证解除」不在下表。转移隐匿不在下表，走整体停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 进攻性保全申请 | `准备股权或公司财产保全` |
| 账簿印章电子合法自固 | `保全公司账簿印章与电子治理记录` |
| 起诉包 | `提起股东权利诉讼` |
| 应诉实体而无复议或置换 | `应对股东权利诉讼` |
| 管辖或仲裁评估 | `评估股东争议管辖与仲裁条款` |
| 证照交接 | `准备证照印章管控与交接` |
| 控制权路径 | `评估控制权争夺与表决权约束` |
| 实体评估而无应对准备 | `评估公司治理与股东关系` |
| 劳动、破产、知产行为保全复议主轴 | 对应领域 |
| 合伙或个人独资 | 非公司主体 |

不得因「不保证解除」「不代提交」或「禁止转移隐匿」关窗。拟复议或置换草稿仍正触发，不得写成已解除或已解冻。

## 易混

本窗闸名只能是冻结闸，不是保全闸，不是封存闸，不是管辖闸，不是起诉闸。`FZ#` 不是 `BQ#`，不是 `FC#`，不是 `XG#`，不是 `SZ#`。主路径是 `Q-冻`，不是 `Q-保`，不是 `Q-账`。`Q-冻` 在邻窗是转介码，本窗打开为主路径。复议草稿不是已解除。交保不是已解冻。异议不是已排除。复议期间不是停止执行。财产纠纷第一百零七条不是行为保全当然交保即解除。解释第一百六十七条可以变更不是应当解除。1991 年第一百一十一条不是现行第一百一十一条。解释第一百七十一条五日、十日不得与第一百一十一条正文混写。执行复议申请书不是保全复议。「先把被冻股权过户」「今晚换章对抗」整体停止。本窗不执行发送，不代提交。不选定法院。不保证解除。
