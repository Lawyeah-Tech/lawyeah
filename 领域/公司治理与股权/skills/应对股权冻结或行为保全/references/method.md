# 应对股权冻结或行为保全方法

本文件是可执行判断节点。复议草稿不是已解除。交保不是已解冻。异议不是已排除。复议期间不是停止执行。口头传说不是已冻结。冻结股权不是已变更股东，不是默认无表决权。财产纠纷交保应当解除不是行为保全当然交保即解除。等值担保可以变更不是应当解除。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已解除、已解冻、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不保证解除。本窗闸名只能是冻结闸，禁止复用保全闸、封存闸、管辖闸、起诉闸、印章闸、案卷闸、控制闸、答辩闸、上诉闸。预留不得占用：立案闸。本窗 `FZ#` 是冻结行。主路径只用 `Q-冻`，禁止用 `Q-保`、`Q-账`、`Q-管`、`Q-诉`、`Q-印`、`Q-辩` 作主路径。本窗 `Q-签` 只作「复议或置换草稿即已提交」不关窗码。本窗 `Q-议` 只作「复议草稿即已解除」不关窗码。本窗 `Q-额` 只作「交保即已解冻」不关窗码。禁止用 `Q-换`（任免窗草稿即已换证）。禁止用 `Q-担`、`Q-线`、`Q-准`、`Q-到`（申请窗不关窗码）。英文 id 禁止使用，一律用中文技能名 `应对股权冻结或行为保全`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991 年第一百一十一条起诉条件当现行保全复议条、2017 年第一百零八条未核对应现行第一百一十一条、解释第一百七十一条 2015 文本「已被修改」未核 2022 对应、财产保全规定仍引旧第二百二十五条第二百二十七条未核对应、把复议写成已解除时记为噪声。禁止指导转移隐匿、违反裁定、串通解冻或换章对抗。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现已作出保全文书扫描，不是默认闭集。
`FZ#` 固定列：`编号｜文书切片｜措施与范围｜复议／异议接口｜担保置换｜经营限制｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已解除」或「已解冻」。无 `E#` 不得写已解除。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-冻`。禁止 `BQ#`、`FC#`、`XG#`、`SZ#`、`YZ#`、`A#`、`N#`。文件状态只用 `草案`、`待签署`、`停止`。五日、担保或经营限制未闭合不得标 `待签署`。

口头「听说冻了」「交保就能解」「复议期间先当没冻」「先把股权过户再说」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。财产保全与行为保全分列。诉前、诉中与执行分列。

实务上：复议期间不停止执行。财产纠纷交保应当解除；争议标的解除须经申请保全人同意。行为保全一般不因被申请人提供担保而解除，除非申请人同意。解释第一百六十七条是可以变更标的物，不是应当解除。冻结股权自公示发生效力，不等于已变更股东，不等于默认无表决权；股息红利须另行冻结。五日是申请复议期限，十日是法院审查期限，不得与第一百一十一条正文混写。

冻结闸关闭（仍正触发）：无一可编号碎片。「今天必须出已解除终稿」而无最小碎片不得开闸。不出 `FZ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `FZ#` 终稿，**第 7 节不得出已解冻或发送版复议**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「复议即已解除」「交保即已解冻」「异议即已排除」「复议期间停止执行」「冻结即无表决权」「行为保全交保即应当解除」「可以变更即应当解除」「保证解除」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `FZ#` 草案。

若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出转移隐匿、违反裁定处分被保全财产、串通解冻、换章对抗、抽逃作置换担保、伪造权属、倒签复议日或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

| 字段 | 必须记录 | 禁止 |

| 文书 | 裁定书、协助执行通知、冻结公示、送达回证分列 | 「听说冻了」升格已冻结；无文书指导先当没冻 |
| 标的与范围 | 某股权／某账户／某次会议／某枚印章分列 | 「全部财产已冻」；超范围冻结案外人当合法 |
| 复议／异议 | 对裁定内容不服走复议；对实施中的执行行为走书面异议；案外人基于实体权利走案外人异议 | 复议草稿即已解除；异议即已排除 |
| 担保置换 | 财产纠纷交保应当解除；争议标的须经申请保全人同意；等值担保可以变更；行为保全一般不因交保解除 | 交保即已解冻；抽逃公司资金作置换；行为保全套第一百零七条应当解除 |
| 经营限制 | 协助通知、公示、章程、表决与分红分列待核 | 冻结即已变更股东；冻结即无表决权；冻结当然及于分红 |
| 五日／十日 | 收到裁定书之日起五日向作出裁定的法院申请复议一次；法院十日审查；复议期间不停止执行 | 把十日写成第一百一十一条正文；复议期间停止执行 |

检索锚点（写入 `L#` 前须核验）：

- 民事诉讼法（2023 修正，施行日 2024-01-01）第一百一十一条可以申请复议一次；复议期间不停止裁定的执行。噪声：1991 年第一百一十一条起诉条件；2017 年第一百零八条。
- 第一百零七条财产纠纷案件被申请人提供担保应当裁定解除保全。不得写成行为保全当然交保即解除。
- 第一百零八条申请错误赔偿。
- 解释（2022 修正）第一百六十七条可以裁定变更保全标的物；可以 ≠ 应当，变更 ≠ 解除。
- 解释第一百七十一条五日申请复议、十日审查。噪声：2015 文本「已被修改」。不得把十日与第一百一十一条正文混写。
- 解释第一百七十二条利害关系人复议仍引旧第一百零八条须核对应第一百一十一条。
- 财产保全规定（2020）第二十二条财产纠纷充分有效担保应当准许解除，争议标的须经申请保全人同意；第二十五条送达之日起五日复议一次，法院十日审查。第二十六条、第二十条、第二十七条仍引旧第二百二十五条、第二百二十七条须核对应。
- 知产行为保全规定第十二条一般不因被申请人提供担保而解除，但是申请人同意的除外；不得写成公司治理默认路径。
- 股权强制执行规定第二条不得直接执行公司财产；第六条公示发生效力；第七条转让出质不得对抗申请执行人；第八条重大影响行为前报告，不是默认无表决权；第九条股息红利另行冻结。噪声：上市公司国有股规定股息及于孳息不得套非上市当然适用。

## 节点 3　冻结行 `FZ#`

按已出现已作出保全文书扫描，不是默认闭集。每条须能指向文书、措施或复议接口之一。

无 `E#` 不得写已解除。状态默认 `草案`。一次只推荐下一步。未知不写零，不保证解除。五日、担保或经营限制未闭合不得标 `待签署`。

热冲突强制处理：

- 复议即已解除／交保即已解冻／异议即已排除／复议期间停止执行／冻结即无表决权／行为保全交保即应当解除／可以变更即应当解除／保证解除／未知写零 → 该格不支持或字段停止；仍出其他 `FZ#`。
- 无一碎片 → 关闸，不出 `FZ#` 终稿，窗口不关。
- 指导转移隐匿、违反裁定、串通解冻、换章对抗 → 整体停止，不是该格不支持。
