# 边界与路由

## 正触发

已决定任免法定代表人、董事或高管，需要发送前公司文件和登记衔接。从零、碎片、权源未核验、无书面任免授权仍正触发：有可编号任免意思或身份碎片则闸开或半开，出 `RM#` 草案，保持草案。本次不代提交、不写已换证是交付禁令，不是开窗条件。未登记即已对抗、草稿即已换证、回执即已核准、董事会任免董事即权源已闭合，仍正触发。

双方秘密、伪造任免决议、倒签任职、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。抢章不是负触发。「未登记即已对抗」「草稿即已换证」「回执即已核准」「董事会任免董事即权源已闭合」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 劳动合同解除、补偿或违法解除赔偿 | 劳动领域 |
| 董事会决定草稿 | `准备董事会或执行董事决定` |
| 股东会召集通知 | `准备股东会决议与召集` |
| 忠实勤勉责任终局 | `评估董事高管忠实勤勉责任` |
| 证照印章交接包 | `准备证照印章管控与交接` |
| 控制权争夺评估 | `评估控制权争夺与表决权约束` |
| 合伙或个人独资 | 非公司主体 |

不得因「不代提交」或「不写已换证」关窗。拟任免草稿仍正触发，不得写成已换证或已对抗。

## 易混

本窗闸名只能是任免闸。`RM#` 不是董事窗 `DH#`，不是忠实窗 `ZS#`，不是设立窗 `XS#`，不是变更窗 `BG#`，不是企业合规报复行 `RF#`。未登记不是已对抗善意相对人。任免草稿不是已换证。网交回执不是已核准。董事会任免董事不是权源已闭合。2018 年第十三条不是现行第十条。1993 年第十条住所不是现行法定代表人条。抢章不是交接接口。「今晚去把章抢回来」「任职日期改到上周」整体停止。本窗不执行发送，不代提交。不选定法院。
