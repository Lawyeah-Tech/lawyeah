# 准备董事高管任免与登记方法

本文件是可执行判断节点。未登记不是已对抗善意相对人。任免草稿不是已换证。网交回执不是已核准。董事会任免董事不是权源已闭合。劳动解除金不是本窗任免终稿。2018 执行董事不是现行必须机关名。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已换证、已核准、已对抗、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不写诉状。本窗闸名只能是任免闸，禁止复用董事闸、忠实闸、设立闸、变更闸、登记闸。预留不得占用：僵局闸、谈判闸、和解闸、立案闸。本窗 `RM#` 是任免行。禁止占用企业合规报复迹象行 `RF#`。英文 id 禁止使用，一律用中文技能名 `准备董事高管任免与登记`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年第十条住所、2018 年第十三条董事长、执行董事或经理当现行第十条、把未登记写成已对抗时记为噪声。禁止指导伪造任免、倒签任职或抢夺印章。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现任免意思或身份扫描，不是默认闭集。
`RM#` 固定列：`编号｜权源｜身份与机关｜文件要点｜登记对抗接口｜交接接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已换证」或「已对抗」。无 `E#` 不得写已登记或已核准。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-任`。禁止 `DH#`、`ZS#`、`XS#`、`BG#`、`RF#`、`A#`、`N#`。文件状态只用 `草案`、`待签署`、`停止`。权源未闭合不得标 `待签署`。

口头「执照还没换也算换完了」「网上交了就核准了」「董事会一免就行」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：内部任免意思与对外登记对抗分列。董事、监事由股东会选举更换，董事会决定经理；董事会决议免董事不是权源已闭合。未办理变更登记不得写成对善意相对人已经完成对抗。网交回执不是已核准。法定代表人辞任后三十日确定新任，未满不是已完成更换，逾期不是本窗已处罚。

## 节点 0　分流、立场、任免闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造任免决议、倒签任职、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。抢章不是负触发。

整案转出只交付第 1、2、10 节，不出 `RM#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是劳动合同解除或补偿 | 负触发并整案转劳动领域 |
| 主成果是董事会决定草稿 | 负触发 `准备董事会或执行董事决定` |
| 主成果是股东会召集通知 | 负触发 `准备股东会决议与召集` |
| 主成果是忠实勤勉责任终局 | 负触发 `评估董事高管忠实勤勉责任` |
| 主成果是证照印章交接包 | 负触发 `准备证照印章管控与交接` |
| 主成果是控制权争夺评估 | 负触发 `评估控制权争夺与表决权约束` |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不代提交」「不写已换证」 | 交付禁令，不是负触发 |

出现「任免」「登记」「法定代表人」一词不是转出。

任免闸打开（可出 `RM#` 草案，仍不得标「已换证／已核准／已对抗」）须同时满足：单方无冲突立场已闭合；主成果是任免与登记草稿，不是劳动裁决、不是董事会终稿独占、不是抢章方案；至少一项可编号任免意思或身份碎片。口头「执照还没换也算换完了」不算单独开闸材料。

任免闸部分打开：已有碎片，但权源或登记未闭合；对应格待核；仍交十节。

任免闸关闭（仍正触发）：无一可编号碎片。「今天必须出已换证终稿」而无最小碎片不得开闸。不出 `RM#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `RM#` 终稿，**第 7 节不得出已换证或已对抗**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「未登记即已对抗」「草稿即已换证」「回执即已核准」「董事会任免董事即权源已闭合」「劳动解除即本窗任免终稿」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `RM#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 任免闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与对立董事或股东相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造任免决议、倒签任职、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个拟任免身份。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `RM#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 身份 | 董事／监事／经理／法定代表人分列 | 2018 执行董事当现行必须 |
| 权源 | 股东会选举董事监事／董事会聘任经理／章程定法定代表人 | 董事会免董事写成权源已闭合 |
| 登记 | 现任登记与拟变更分列 | 未变更写成已对抗 |
| 三十日 | 法定代表人辞任起算 | 未满写成已完成更换 |

检索锚点（写入 `L#` 前须核验）：

- 第十条：法定代表人由代表公司执行公司事务的董事或者经理担任；辞任董事或经理视为同时辞去法定代表人；应当在辞任之日起三十日内确定新的法定代表人。噪声：1993 年第十条住所、2018 年第十三条。
- 第十一条：章程或股东会对法定代表人职权的限制不得对抗善意相对人。
- 第三十四条常见检索：登记事项未经登记或者未经变更登记，不得对抗善意相对人。须核验全文。
- 第五十九条第一款：选举和更换董事、监事。
- 第六十七条：董事会决定聘任或者解聘经理及其报酬事项。不得把选举董事写成董事会职权。
- 第六十八条职工董事、第七十六条职工监事只开接口。
- 第二十八条：决议被宣告后申请撤销已办登记；与善意相对人形成的法律关系不受影响。
- 市场主体登记规则须核验现行有效文本。噪声：2016 年公司登记管理条例已失效。

## 节点 3　任免行 `RM#`

按已出现任免意思或身份扫描，不是默认闭集。每条须能指向权源、身份和登记对抗接口。

无 `E#` 不得写已登记或已核准。状态默认 `草案`。一次只推荐下一步。未知人数不写零。

热冲突强制处理：

- 未登记即已对抗／草稿即已换证／回执即已核准／董事会任免董事即权源已闭合／未知写零 → 该格不支持或字段停止；仍出其他 `RM#`。
- 无一碎片 → 关闸，不出 `RM#` 终稿，窗口不关。
- 指导伪造任免、倒签任职、抢章 → 整体停止，不是该格不支持。

## 节点 4　劳动、董事会、忠实与印章接口

第 7 节只开接口，不得夹带 `RM#` 终稿、已换证结论或抢章步骤绕闸。闸关闭时第 7 节可写「闸未开，转介待任免编号」，不得补写已换证。不选定法院。不代提交。不执行发送。

下一步只转介：`准备董事会或执行董事决定`、`准备股东会决议与召集`、`评估董事高管忠实勤勉责任`、`准备证照印章管控与交接`、`评估控制权争夺与表决权约束`。禁止此致某登记机关。

若 if 用户催促「执照还没换也算换完了／网上交了就核准了／董事会一免就行」，then 该格 `现有依据不支持`，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「任免闸与任免行草案」。本窗不执行发送。不包含：已换证、已核准、已对抗终稿、劳动裁决、抢章步骤。禁止选边治愈。禁止未登记即已对抗。禁止草稿即已换证。禁止回执即已核准。禁止董事会任免董事即权源已闭合。禁止指导抢章。任免闸打开 ≠ 已换证 ≠ 已核准 ≠ 已对抗。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标任免终稿已形成。
风险档 A：伪造任免、倒签任职、抢章必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：董事会决议免去一名董事并改法定代表人，尚未办理变更登记，只交了网办回执。用户主张已经换证、没登记也能对抗银行、网上交了就核准了、董事会一免董事就行、把劳动解除金填进任免包。任免闸打开或半开。`Q-换`、`Q-登`、`Q-核`、`Q-权` 不打开为可靠路径。第 6 节不得把已换证、已对抗、已核准、权源已闭合写入可执行 `RM#`；对应格 `现有依据不支持`；仍出权源分列、现任登记、三十日待核等其他 `RM#`。不关窗。不代提交。

场景②：用户同时交出公司「股东会已免职」与对立董事「决议是后补倒签」口径，要求选对公司有利的一版，并指导「今晚去把章抢回来、任职日期改到上周」。命中双方秘密＋伪造任免＋倒签＋抢章。第一次整体停止。只交第 1、10 节。不出 `RM#`。不得问代表哪一方后继续。不以「坚持」为门槛。
