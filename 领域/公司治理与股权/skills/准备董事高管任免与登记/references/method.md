# 任免与登记方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、论坛、期限、金额或文书状态的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然无效、必然失权、必然解散或唯一必得总额。

`search_law` 返回已失效《合同法》、1993／2004／2013／2018《公司法》或仍引用旧第二十二条、第三十三条、第七十一条且未核验对应关系的司法解释时，记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 以股权或资产收购、投资交割、尽调闭环为主要目标 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果、员工激励的劳动身份 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂、综合合规体系 | 企业合规领域 |
| 破产申请、重整计划、破产债权申报与分配 | 破产领域 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 合伙企业、个人独资的入伙退伙 | 非公司主体，不在本领域 |
| 上市公司发行、持续信息披露或证券监管主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

混合信号：公司组织或股东关系主轴可留本任务；专项只作为背景时在缺口标明，不把专项规则硬套进本领域结论。

## Q# 矩阵

固定列：`编号｜关系假设｜提出方｜相对方｜法律效果｜成立条件｜支持事实｜不利事实｜控制方｜最强反方｜主备位｜判断｜待核`。

分列产生机关、任职资格、法定代表人变更、登记对抗、印章交接。禁止把未通过选举写成已经任职。


## 节点 1　权源

1. 董事由股东会选举和更换，章程另有规定的职工董事除外。经理的聘任解聘由董事会决定。须运行时核验机关职权条款。
2. 法定代表人由代表公司执行公司事务的董事或经理担任，须核验第十条。变更法定代表人是公司义务，不得因原法定代表人拒不配合而写成无法变更的法律不能。
3. 劳动解除通知与公司法解聘是两条路径：补偿计算转劳动，本任务只做公司机关文件。

---

## 节点 2　文件

1. 股东会或董事会决议草稿转相应决议原子衔接；本任务列任免议案、就任文件和签字页。
2. 任职资格负面清单（被禁止担任董监高的情形）运行时核验。命中则现有依据不支持该人选。
3. 倒签任职或伪造选举：整体停止。

---

## 节点 3　登记

1. 法定代表人、董事、监事变更应当办理登记。具体时限运行时核验登记规则。
2. 本任务不代提交。材料冲突并列。

---

## 节点 4　善意相对人

1. 法定代表人的代表权争议：善意相对人保护只标接口。
2. 登记事项与真实任免不一致：对内对外分列，不写成已经统一。

---

## 节点 5　交接

证照印章合法交接转 `准备证照印章管控与交接`。禁止设计抢夺、隐匿或私刻。
