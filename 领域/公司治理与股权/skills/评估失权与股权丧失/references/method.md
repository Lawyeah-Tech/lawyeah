# 评估失权与股权丧失方法

本文件是可执行判断节点。催缴未闭合不是已失权。宽限期未满不是已失权。微信已读不是发出。解释三第十七条不是 2024 年后唯一失权路径。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然失权、已失权、选定法院、代提交、未知写零、唯一截止日。本任务不定罪，不出失权通知终稿，不写异议起诉状。本窗闸名只能是失权闸，禁止复用催缴闸、瑕疵闸、减资闸、决议闸。本窗 `SQ#` 是失权行。英文 id 禁止使用，一律用中文技能名 `评估失权与股权丧失`。主路径只用 `Q-失`，禁止 `Q-催`、`Q-减`、`Q-诉` 作主路径。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回解释三第十七条当 2024 年后唯一失权路径、2018 年无失权专条当现行、把催缴未闭合写成已失权时记为噪声。禁止指导倒签失权发出日或伪造董事会决议。伤残等级与本窗无关。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现催缴或失权通知碎片扫描，不是默认闭集。
`SQ#` 固定列：`编号｜失权切片｜催缴闭合｜董事会决议｜通知效果｜三十日异议｜六个月处理接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。无 `E#` 不得写已失权、已发出或异议期已届满。`E#` 只作证据形态回链，不是发送闸。扫描不是闭集。缺项记 `G#`。承认只进 `S#`／`D#`，不得占用 `A#`。

口头「已经失权了」「微信已读就算发出」「股东会除名就行」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。本窗不打开待发送。

实务上：书面催缴且宽限期自发出之日起不少于六十日并已届满，经董事会决议可以发出书面失权通知；自发出之日起丧失未缴纳出资的股权。可以向不是必须立即失权。已缴部分不得扩大丧失除非另有可核验规则。异议三十日自接到之日起，接到日不明建并行情景。

## 节点 0　分流、立场、失权闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、倒签失权发出日、伪造董事会失权决议、伪造失权通知、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `SQ#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是催缴书草稿 | 负触发 `准备催缴出资通知` |
| 主成果是出资瑕疵定性独占 | 负触发 `评估出资瑕疵催缴与加速到期` |
| 主成果是减资注销失权股权 | 负触发 `准备减资通知与债权人保护` |
| 主成果是异议起诉状 | 负触发 `提起股东权利诉讼` |
| 主成果是董事会决议包独占 | 负触发 `准备董事会或执行董事决定` |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不出失权通知终稿」「不写已失权」 | 交付禁令，不是负触发 |

出现「失权」「催缴」「六十日」一词不是转出。催缴未闭合即已失权不是负触发，该格不支持。催缴尚未发出但主成果仍是失权条件评估：正触发半开或关闸，第 7 节开催缴接口。

失权闸打开（可出 `SQ#` 草案，仍不得标「已失权／已发出／异议期已届满」）须同时满足：单方无冲突立场已闭合；主成果是失权条件评估草案，不是催缴书、不是减资终稿、不是起诉状；至少一项可编号催缴闭合碎片或失权通知碎片。口头「已经失权了」不算单独开闸材料。

失权闸部分打开：已有碎片，但发出日、宽限期或董事会决议未闭合；对应格待核；仍交十节。无书面评估授权但立场已闭合且有碎片：部分打开，不是整体停止。催缴未闭合：部分打开，不得写已失权。

失权闸关闭（仍正触发）：无一可编号催缴或失权通知碎片。「今天必须出已失权终稿」而无最小碎片不得开闸。不出 `SQ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `SQ#` 终稿，**第 7 节不得出已失权或失权通知终稿**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「催缴未闭合即已失权」「微信已读即发出」「解释三第十七条当唯一路径」「宽限期未满即已失权」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `SQ#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号催缴或失权通知碎片，then 失权闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被催缴股东相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出倒签失权发出日、伪造董事会失权决议、伪造失权通知、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个失权切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `SQ#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 催缴闭合 | 书面催缴、发出日、不少于六十日且已届满 | 未闭合写成已失权 |
| 机关 | 董事会决议；或第 75 条一名董事待核 | 监事会或股东会冒充董事会 |
| 通知 | 书面；发出日起丧失未缴股权 | 已读即发出；扩大到已缴股权 |
| 异议 | 接到之日起三十日 | 接到日不明写唯一截止日 |
| 后续 | 六个月内转让或减资注销接口 | 本窗出减资终稿 |

检索锚点（写入 `L#` 前须核验）：

- 第五十一条：董事会核查并书面催缴。
- 第五十二条：宽限期自发出之日起不得少于六十日；届满仍未履行，经董事会决议可以向该股东发出书面失权通知；自发出之日起丧失未缴纳出资的股权；丧失股权应依法转让或减资注销；六个月内未处理的，其他股东按出资比例足额缴纳；异议自接到之日起三十日内起诉。
- 第七十五条：一名董事行使董事会职权须核验规模较小或人数较少。
- 第一百零七条：第五十一条、第五十二条适用于股份有限公司。
- 噪声：解释三第十七条当 2024 年后唯一失权路径；2018 年无失权专条当现行。

不得暗示「催缴一发股权就没了」。董事会「可以向」不是必须立即失权。

## 节点 3　失权行 `SQ#`

按已出现催缴或失权通知碎片扫描，不是默认闭集。公司侧与被催缴股东侧分列立场，不得选边。

无 `E#` 不得写已失权、已发出或异议期已届满。状态默认 `草案`。一次只推荐下一步。未知不写零。催缴未闭合或宽限期未满：该格不支持已失权，仍出闭合缺口。发出日与接到日分列。微信已读不得单独起算发出。三十日异议自接到之日起；接到日不明建并行情景，不给唯一截止日。失权范围限于未缴纳出资的股权。六个月转让或减资注销只开接口。公司侧可出条件与通知要点清单，状态保持草案，不打开待发送。

热冲突强制处理：

- 催缴未闭合即已失权／宽限期未满即已失权／已读即发出／解释三当唯一路径／已缴一并丧失／必须立即失权／估数或写零 → 该格不支持或字段停止；仍出其他 `SQ#`。
- 无一催缴或失权通知碎片 → 关闸，不出 `SQ#` 终稿，窗口不关。
- 指导倒签发出日、伪造董事会决议、伪造失权通知 → 整体停止，不是该格不支持。

## 节点 4　催缴、减资、诉讼与决议接口

第 7 节只开接口，不得夹带 `SQ#` 终稿、已失权或失权通知终稿绕闸。闸关闭时第 7 节可写「闸未开，转介待催缴或通知编号」，不得补写已失权。催缴未闭合只开催缴窗接口。减资只开减资窗接口。异议起诉只开诉讼窗接口。

下一步只转介：`准备催缴出资通知`、`评估出资瑕疵催缴与加速到期`、`准备减资通知与债权人保护`、`提起股东权利诉讼`、`准备董事会或执行董事决定`。禁止此致某法院为唯一路径。不代提交。不执行发送。不出失权通知终稿。

若 if 用户催促「催缴发了就算失权／已读就算发出／股东会除名就行／截止日期就这一天／金额不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）
