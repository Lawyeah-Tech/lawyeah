# 边界与路由

## 正触发

宽限期届满拟发失权通知，或已收到失权通知，需要判断条件与异议路径。从零、碎片、催缴未闭合、无书面评估授权仍正触发：有催缴闭合或失权通知碎片则闸开或半开，出 `SQ#` 草案，保持草案。本次不出失权通知终稿、不写已失权是交付禁令，不是开窗条件。催缴未闭合即已失权、微信已读即发出、解释三第十七条当唯一路径，仍正触发。

双方秘密、倒签失权发出日、伪造董事会失权决议、伪造失权通知、抢夺印章证照、违法取证的停止，优先于负触发。上述信号不在下表。「催缴未闭合即已失权」「微信已读即发出」「解释三第十七条当唯一路径」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 催缴书草稿 | `准备催缴出资通知` |
| 出资瑕疵定性独占 | `评估出资瑕疵催缴与加速到期` |
| 减资注销失权股权 | `准备减资通知与债权人保护` |
| 异议起诉状 | `提起股东权利诉讼` |
| 董事会决议包独占 | `准备董事会或执行董事决定` |
| 合伙或个人独资 | 非公司主体 |

不得因「不出失权通知终稿」或「不写已失权」关窗。拟评失权条件仍正触发，不得写成已失权。催缴尚未发出但主成果仍是失权条件评估：正触发半开或关闸，第 7 节开催缴接口。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |
| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「失权」「催缴」「六十日」一词不是转出。

## 易混

本窗闸名只能是失权闸，禁止复用催缴闸、瑕疵闸、减资闸。催缴未闭合不是已失权。宽限期未满不是已失权。书面催缴不是已失权。今天发函不是失权已发生。微信已读不是发出。接到日不明不是可写唯一截止日。解释三第十七条不是 2024 年后唯一失权路径。失权范围不是已缴股权当然一并丧失。董事会可以向不是必须立即失权。监事会或股东会不是董事会失权。六个月处理不是本窗减资终稿。本窗 `SQ#` 不是催缴窗 `CJ#`，不是瑕疵窗 `XC#`，不是减资窗 `JZ#`。「发出日先倒签」「董事会决议今晚补一份」整体停止。本窗不执行发送，不代提交。不出失权通知终稿。不写已失权。伤残等级与本窗无关。
