# 边界与路由

## 正触发

隐名股东与名义股东争投资权益或显名。从零、碎片、合同未核验、无书面评估授权仍正触发：有可编号代持合意或出资碎片则闸开或半开，出 `DT#` 草案，保持草案。本次不把代持有效写成已是名册股东、不写还原文件是交付禁令，不是开窗条件。只有出资即代持已成立、代持有效即已是名册股东、隐名即可向公司主张、上市代持当然有效、半数不足即已显名、处分即当然追回，仍正触发。

双方秘密、伪造代持协议、倒签转账、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「只有出资即代持已成立」「代持有效即已是名册股东」「隐名即可向公司主张」「上市代持当然有效」「半数不足即已显名」「处分即当然追回」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| C 端代持退出大众方案 | 分流，不在本窗展开 |
| 上市公司股份代持监管 | 证券监管 |
| 还原变更文件 | `准备代持还原或显名变更` |
| 婚家股权归属 | 婚家领域 |
| 股权结构图 | `梳理股权结构与控制权` |
| 名册记载请求 | `准备股东名册与工商变更衔接` |
| 合伙或个人独资 | 非公司主体 |

不得因「不把代持有效写成已是名册股东」或「不写还原文件」关窗。拟代持路径评估仍正触发，不得写成已是名册股东或已显名。

## 易混

本窗闸名只能是代持闸。`DT#` 不是结构窗 `GQ#`，不是名册窗 `MC#`，不是转让窗 `ZR#`，不是董事窗 `DH#`。主路径是 `Q-持`，不是代表诉讼常用的 `Q-代`。只有出资不是代持已成立。代持有效不是已经是名册股东。隐名股东直接向公司主张股东权利原则上不支持除非完成显名。上市公司代持不是当然有效。半数同意不足不是已显名。名义股东处分不是当然追回。2011 年解释三第二十四条不是 2020 年修正后代持条。「协议日期改到出资前」整体停止。本窗不执行发送，不代提交。不选定法院。
