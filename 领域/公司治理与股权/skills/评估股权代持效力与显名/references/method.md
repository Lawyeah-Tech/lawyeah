# 评估股权代持效力与显名方法

本文件是可执行判断节点。只有出资不是代持已成立。代持有效不是已经是名册股东。隐名股东直接向公司主张股东权利原则上不支持除非完成显名。上市公司代持不是当然有效。半数同意不足不是已显名。名义股东处分不是当然追回。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已是名册股东、已显名、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不写还原文件。本窗闸名只能是代持闸，禁止复用结构闸、名册闸、转让闸、显名闸。预留不得占用：僵局闸、谈判闸、和解闸、立案闸。本窗 `DT#` 是代持行。主路径只用 `Q-持`，禁止用 `Q-代` 作主路径。禁止占用结构窗 `GQ#`、名册窗 `MC#`、转让窗 `ZR#`、董事窗 `DH#`。英文 id 禁止使用，一律用中文技能名 `评估股权代持效力与显名`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 2011 年解释三第二十四条记载名册义务当 2020 年修正后代持条、把只有出资写成代持已成立、把代持有效写成已经是名册股东时记为噪声。禁止指导伪造代持协议或倒签转账。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现代持合意或出资扫描，不是默认闭集。
`DT#` 固定列：`编号｜合意与资金｜合同效力｜投资权益｜显名条件｜善意第三人接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已是名册股东」或「已显名」。无 `E#` 不得写已显名。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-持`。禁止 `GQ#`、`MC#`、`ZR#`、`DH#`、`A#`、`N#`。

口头「钱是我出的就算代持」「合同有效就是股东了」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：代持合同如无法律规定的无效情形常按有效处理，但有效不等于股东资格。实际出资人可向名义股东主张投资权益，不得以名册或登记否认该合同权益。未经其他股东半数以上同意，不得请求公司变更股东、记载名册并办理登记。名义股东处分股权参照善意取得，造成损失可向名义股东索赔，不是当然追回股权。

## 节点 0　分流、立场、代持闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造代持协议、倒签转账、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `DT#` 终稿。

| 信号 | 处理 |

| 主成果是 C 端代持退出大众方案 | 负触发并分流 |
| 主成果是上市公司股份代持监管 | 负触发并整案转证券监管 |
| 主成果是还原变更文件 | 负触发 `准备代持还原或显名变更` |
| 主成果是婚家股权归属 | 负触发并整案转婚家 |
| 主成果是股权结构图 | 负触发 `梳理股权结构与控制权` |
| 主成果是名册记载请求 | 负触发 `准备股东名册与工商变更衔接` |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不把代持有效写成已是名册股东」「不写还原文件」 | 交付禁令，不是负触发 |

出现「代持」「隐名」「显名」一词不是转出。

代持闸打开（可出 `DT#` 草案，仍不得标「已是名册股东／已显名／代持已成立终稿」）须同时满足：单方无冲突立场已闭合；主成果是代持路径评估，不是还原文件、不是结构图；至少一项可编号代持合意或出资碎片。口头「钱是我出的就算代持」不算单独开闸材料。

代持闸部分打开：已有碎片，但合意、效力或半数同意未闭合；对应格待核；仍交十节。

代持闸关闭（仍正触发）：无一可编号碎片。「今天必须出已是名册股东终稿」而无最小碎片不得开闸。不出 `DT#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `DT#` 终稿，**第 7 节不得出已显名或还原文件**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「只有出资即代持已成立」「代持有效即已是名册股东」「隐名即可向公司主张股东权利」「上市代持当然有效」「半数不足即已显名」「处分即当然追回」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `DT#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 代持闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造代持协议、倒签转账、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个代持关系或出资版本。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `DT#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 主体 | 实际出资人／名义股东／公司分列 | 把公司写成代持合同相对方当然给付 |
| 合意 | 合同、转账、沟通分列 | 只有出资写成代持已成立 |
| 效力 | 一般有效／监管红旗／无效情形分列 | 上市代持写成当然有效 |
| 显名 | 其他股东半数以上同意待核 | 半数不足写成已显名 |

检索锚点（写入 `L#` 前须核验）：

- 解释三（2020 修正）第二十四条第一款：代持合同如无法律规定的无效情形应当认定有效。噪声：2011 年解释三第二十四条记载名册义务。
- 第二十四条第二款：实际出资人向名义股东主张投资权益应予支持；名义股东不得以名册或登记否认。
- 第二十四条第三款：未经其他股东半数以上同意，请求公司变更股东、签发出资证明书、记载名册章程并办理登记的，不予支持。
- 第二十五条：名义股东处分股权，实际出资人请求认定无效的，可以参照民法典第三百一十一条；造成损失可请求名义股东赔偿。
- 外商投资企业纠纷规定（一）第十七条：实际投资者直接向外企请求分配利润或其他股东权利，不予支持。
- 解释三仍引旧公司法第三十一条、第三十二条的，须核验对应现行名册与登记条。

只有出资而无代持意思：依据不足，不得写成代持已成立。

## 节点 3　代持行 `DT#`

按已出现代持合意或出资扫描，不是默认闭集。每条须能指向合意、效力或显名条件。

无 `E#` 不得写已显名。状态默认 `草案`。一次只推荐下一步。半数同意材料不足：显名请求依据不足，窗口不关。为规避外资准入、国资程序或上市禁令：效力字段标监管红旗，不得写成当然有效。

热冲突强制处理：

- 只有出资即代持已成立／代持有效即已是名册股东／隐名即可向公司主张／上市代持当然有效／半数不足即已显名／处分即当然追回／未知写零 → 该格不支持或字段停止；仍出其他 `DT#`。
- 无一碎片 → 关闸，不出 `DT#` 终稿，窗口不关。
- 指导伪造代持协议、倒签转账 → 整体停止，不是该格不支持。

## 节点 4　还原文件、名册、结构与婚家接口

第 7 节只开接口，不得夹带 `DT#` 终稿、已显名结论或还原文件绕闸。闸关闭时第 7 节可写「闸未开，转介待代持编号」，不得补写已显名。不选定法院。不代提交。

下一步只转介：`准备代持还原或显名变更`、`梳理股权结构与控制权`、`准备股东名册与工商变更衔接`、`准备有限公司股权内部转让`。禁止此致某法院。

若 if 用户催促「钱是我出的就算代持／合同有效就是股东了／半数不够也要显名」，then 该格 `现有依据不支持`，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：甲把钱打给乙，乙登记为股东，没有书面代持合同。用户主张钱是我出的就算代持、合同就算有效我也已经是名册股东、我要直接向公司要分红、上市那家公司代持当然有效、其他股东没过半数也要显名、乙把股权卖了必须追回来。代持闸打开或半开。`Q-出`、`Q-名`、`Q-司`、`Q-市`、`Q-半`、`Q-追` 不打开为可靠路径。第 6 节不得把代持已成立、已是名册股东、已显名写入可执行 `DT#`；对应格 `现有依据不支持`；仍出资金流向、合意缺口、半数同意待核等其他 `DT#`。不关窗。不写还原文件。
