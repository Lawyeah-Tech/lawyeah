# 评估股权代持效力与显名

## 任务目标

在明确、无利益冲突的单方立场下（实际出资人、名义股东、公司或其受托律师，互斥），形成代持效力与显名路径草案：代持闸、主体与强制接口、`Q#` 路径、`DT#` 代持行（合意与资金／合同效力／投资权益／显名条件／善意第三人接口／`E#` 回链）。本窗 `DT#` 是代持行草案，不是已是名册股东，不是已显名，不是还原变更文件终稿，不是投资权益已给付。本窗闸名只能是代持闸，禁止复用结构闸、名册闸、转让闸、显名闸。预留不得占用：僵局闸、谈判闸、和解闸、立案闸。本窗主行只能是 `DT#`，禁止 `GQ#`、`MC#`、`ZR#`、`DH#`、`A#`。主路径只用 `Q-持`，禁止用 `Q-代` 作主路径。代持闸打开不等于代持已成立不等于合同已有效不等于已是名册股东不等于已显名。只有出资不是代持已成立。代持有效不是已经是名册股东。隐名股东直接向公司主张股东权利原则上不支持除非完成显名。上市公司代持不是当然有效。半数同意不足不是已显名。名义股东处分不是当然追回。未知不写零。不代提交。不选定法院。不定罪。伤残等级与本窗无关，禁止折入。

`depends-on` 为空。主成果是还原变更文件转 `准备代持还原或显名变更`。主成果是股权结构图转 `梳理股权结构与控制权`。主成果是名册记载请求转 `准备股东名册与工商变更衔接`。主成果是转让协议终稿转 `准备有限公司股权内部转让`。主成果是婚家股权归属转婚家。主成果是上市公司股份代持监管转证券监管。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：隐名股东与名义股东争投资权益或显名。「这份代持算不算数」「能不能显名」仍正触发。合同、转账、半数同意未核验仍正触发：有可编号代持合意或出资碎片则代持闸打开或半开，第 6 节出 `DT#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出已是名册股东／已显名终稿」才关闸，仍交十节，第 6 节不出 `DT#` 终稿，窗口不关。用户要把只有出资写成代持已成立、把代持有效写成已经是名册股东、把隐名股东直接向公司主张股东权利写成当然支持、把上市公司代持写成当然有效、把半数同意不足写成已显名、把名义股东处分写成当然追回、把未知写成零，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `DT#` 草案。不得因「不把代持有效写成已是名册股东」「不写还原文件」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是 C 端代持退出大众方案；
- 主成果是上市公司股份代持监管（转证券监管）；
- 主成果是还原变更文件（转 `准备代持还原或显名变更`）；
- 主成果是婚家股权归属（转婚家）；
- 主成果是股权结构图（转 `梳理股权结构与控制权`）；
- 主成果是名册记载请求（转 `准备股东名册与工商变更衔接`）；
- 合伙企业或个人独资。

双方秘密、伪造代持协议、倒签转账、抢夺印章证照、隐匿账簿、违法取证**不在负触发表**，走整体停止。「只有出资即代持已成立」「代持有效即已是名册股东」「隐名即可直接向公司主张股东权利」「上市代持当然有效」「半数不足即已显名」「处分即当然追回」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不把代持有效写成已是名册股东」「不写还原文件」是交付禁令，不是负触发。主成果才转；出现「代持」「隐名」「显名」一词不是转出。

## 建立工作坐标

确认：评估授权；单方立场；代持合意与资金；公司类型；其他股东态度；是否涉及外资或上市；法域。

口头「钱是我出的就算代持」「合同有效就是股东了」只登记 `S#`／`V#`。不得升格代持已成立或已是名册股东，**不得单独算作开闸材料**。可编号代持合意或出资碎片可开闸。本窗不执行发送，不代提交。

立场只许实际出资人、名义股东、公司或其受托律师，互斥。同时掌握对立方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：代持闸关闭，仍交十节，不是整体停止。提出伪造代持协议、倒签转账、抢夺印章证照、隐匿账簿或违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 章程或股东协议；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`DT#` 代持行；`V#` 版本；`E#` 证据形态回链（代持合同、转账、沟通、名册登记、半数同意碎片，不是发送闸，不是已显名证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`GQ#`、`MC#`、`ZR#`、`DH#`。技能正文中的条号是检索锚点，不是已核验 `L#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。未知不写零。只有出资 ≠ 代持已成立。代持有效 ≠ 已经是名册股东。半数同意不足 ≠ 已显名。名义股东处分 ≠ 当然追回。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或裁判案例检索。本窗是代持评估，案例只比较事实差异与翻转条件，**不要**写成已是名册股东或当然有效。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现只有出资即代持已成立、代持有效即已是名册股东、隐名即可直接向公司主张、上市代持当然有效的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》当作现行。不得把 2011 年解释三第二十四条记载名册义务当作 2020 年修正后的代持条。解释三仍引旧公司法第三十一条、第三十二条的，须核验对应现行名册与登记条。MCP 效力字段与公布施行日冲突时，以施行日为准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的合同效力或显名条件保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：解释三（2020 修正）第二十四条：有限公司实际出资人与名义出资人订立合同，如无法律规定的无效情形应当认定有效；实际出资人向名义股东主张投资权益应予支持，名义股东不得以名册或登记否认；实际出资人未经公司其他股东半数以上同意请求公司变更股东、签发出资证明书、记载名册章程并办理登记的，不予支持。噪声：2011 年解释三第二十四条是记载名册义务。第二十五条：名义股东处分股权，实际出资人请求认定无效的，可以参照民法典第三百一十一条；造成损失可请求名义股东赔偿。外商投资企业纠纷规定（一）第十七条：实际投资者直接向外企请求分配利润或其他股东权利，不予支持。上市公司股份代持监管红旗不得写成当然有效。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变合同效力或显名条件的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补代持有效不等于股东资格、隐名股东须经其他股东过半数同意才能显名、只有出资而无代持意思依据不足、善意取得须尽注意义务的实务反例。
- `search_case_by_fact` 只比较事实差异与翻转条件：只有出资不是代持已成立、代持有效不是已经是名册股东；不写必然有效或已显名。无类案不得写成已是名册股东或已显名。禁止用 `search_template` 生成已显名决定或还原文件。

工具不可用时继续合意碎片和 `DT#` 编目；合同效力、显名条件、施行日字段停止。不得拒跑，不得凭记忆写成已是名册股东、已显名或上市代持当然有效。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、代持闸与不关窗

主成果才整案转出。双方秘密、伪造代持第一次停。只有出资即代持已成立不关窗。闸关仍交十节，第 6 节不出 `DT#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

实际出资人／名义股东／公司分列。有限／外资／上市分列。本节禁止出 `DT#` 终稿。

### 3. 代持闸与路径 `Q#`

本节禁止出 `DT#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-持`。

### 4. 代持行 `DT#`

合意与资金、合同效力、投资权益、显名条件、善意第三人。状态 `草案`。禁止升格已是名册股东、已显名。无 `E#` 不得写已显名。

### 5. 还原文件、名册、结构与婚家接口

还原文件转准备窗。名册记载转名册窗。第 7 节不得夹带 `DT#` 终稿或已显名结论绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造代持协议、倒签转账、抢夺印章证照、隐匿账簿或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：代持闸关闭，仍交十节，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：合意、合同效力、半数同意、善意取得、施行日未核验。只有出资即代持已成立、代持有效即已是名册股东、隐名即可向公司主张、上市代持当然有效、半数不足即已显名、处分即当然追回、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `DT#` 草案。
- `目标停止`：主目标变为还原文件终稿、已是名册股东终稿或已显名终稿。

禁止指导伪造代持协议或倒签转账。不给胜诉率。不定罪。不选定法院。不代提交。未知不写零。不写已是名册股东。伤残等级禁止折入。
