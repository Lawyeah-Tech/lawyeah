# 公司治理与股权领域边界

本表只说明归属。当前安装包是。每次路由先核对 [当前能力地图](capability-map.md)；未列入的入口（含 P2）输出 `unavailable`。

| 相邻 | 本包入口 | 转出 |
| --- | --- | --- |
| 合同审查与起草 | 章程、决议、股东协议等组织文件可在已安装原子中处理 | 一般交易合同审查起草本窗搁置，只说明不实施 |
| 投资并购 | 公司常态治理、股东权利 | 以投资、收购和交割为主要目标的项目 |
| 婚家 | 公司权利结构与股东权利实现 | 婚姻或继承关系中的股权归属与分配 |
| 劳动 | 公司职务、股权结构和股东权利 | 高管劳动身份、劳动合同权利和员工激励的劳动后果 |
| 企业合规 | 公司机关和股东权利 | 企业合规体系和内部调查 |
| 破产 | 自行解散接口以外的组织安排 | 破产申请、重整、破产分配 |
| 税务 | 分配和激励的公司侧接口 | 税负、申报和税务争议 |
| 刑事 | 评估中的虚假出资、职务侵占只标红旗 | 定罪、控告、辩护 |
| C 端创业股权／代持／股权转让／股东责任／公司关停 | 专业矩阵，不降成第一轮清单 | 大众专项成果，不回改 |

公司日常治理夹带专项背景时，专项段只分流，不把专项规则写入本包结论。
