# 公司治理与股权能力导航

## 定位

说明本领域包的能力、边界和当前原子 Skill 全貌，并根据单方立场、阶段和预期成果定位入口。具体法律任务可以直接使用相应原子 Skill，无须先经过本 Guide。

当前安装包是：P0 与 P1 均已安装。本 Guide 不完成总体评估、出资判断、决议效力、召集决议、股权转让、精算、证据卷、退出谈判、起诉或应诉，也不建立固定组合方案。

## 选择方法

读取 [选择方法](references/selection-method.md)，按“用户目标 + 独立专业成果 + 当前立场与阶段”选择一个主要原子 Skill。默认不存在调用顺序；用户、律师、机关或其他来源提供的等价成果均可作为输入。

混合请求先列出各自可独立验收的成果和对应入口，再只问一个问题：这次要先取得哪一项成果。用户回答前不指定主要 Skill。

## 当前原子能力

读取 [能力地图](references/capability-map.md) 查找本升级包已包含的全部 P0 与 P1 原子 Skill。只推荐实际安装在本包中的 Skill。未列入能力地图的其余能力（含 P2）输出 `unavailable`，不得由名称相近的 Skill 代做。

## 领域边界

读取 [领域边界](references/domain-boundaries.md)。一般交易合同审查起草本窗搁置；投并购交割、婚家股权分配、劳动激励劳动后果、综合合规、破产整案转出；C 端创业股权／代持／股权转让／股东责任／公司关停只分流。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1993、2004、2013、2018 年《公司法》文本当作 2024 年 7 月 1 日后的现行条号。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## MCP 边界

导航通常不必调用工具。原子 Skill 按各自判断节点使用已登记工具；工具不可用时只停止依赖该规则的字段。本 Guide 不得因 MCP 未安装而拒绝完成入口定位。

## 输出

单一成果请求只输出：当前目标与成果、推荐的已安装原子 Skill、选择理由与排除项，以及启动所需的最小输入。

混合请求且用户尚未明确本次优先成果时，只输出独立成果与入口清单，以及“这次先取得哪一项成果”的一个问题。
