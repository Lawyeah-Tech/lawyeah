# 边界与路由

## 正触发

需要把已有或拟挑战的股东会、董事会决议分成不成立、无效或可撤销路径。从零、碎片、通知未核验、无书面评估授权仍正触发：有决议或形成碎片则闸开或半开，出 `XL#` 草案，保持草案。本次不写诉状是交付禁令，不是开窗条件。轻微瑕疵即当然撤销、未开会即当然不成立、内容违章即当然无效、内容违法即写成可撤销、视频或电子通信开会即未召开、解释四其他情形即不成立口袋，仍正触发。

双方秘密、伪造决议、倒签会议、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「轻微瑕疵即当然撤销」「未开会即当然不成立」「内容违章即当然无效」「内容违法即写成可撤销」「视频或电子通信开会即未召开」「解释四其他情形即不成立口袋」「过了六十日仍可撤」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 公司治理与股东关系总图 | `评估公司治理与股东关系` |
| 发送版召集通知或可签署新决议 | `准备股东会决议与召集` |
| 可提交决议之诉诉状 | `提起决议不成立无效或撤销之诉` |
| 召集主持表决程序清单终稿 | `评估召集主持表决程序瑕疵` |
| 书面一致同意决定 | `准备书面一致同意决定` |
| 董事会或执行董事决定终稿 | `准备董事会或执行董事决定` |
| 出资瑕疵催缴或加速到期评估 | `评估出资瑕疵催缴与加速到期` |
| 股东权利诉讼文书 | `提起股东权利诉讼` |
| 合同效力而非公司决议 | 审查起草／合同领域 |
| 合伙或个人独资 | 非公司主体 |

不得因「不写诉状」或「不把轻微瑕疵写成当然撤销」关窗。拟效力路径评估仍正触发，不得写成已撤销或当然不成立。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |
| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「决议」「撤销」「股东会」一词不是转出。

## 易混

轻微瑕疵不是当然撤销。未开会不是当然不成立。内容违章不是当然无效。内容违法不是可撤销。视频或电子通信开会不是未召开。解释四「其他情形」不是 2024 年后不成立口袋。过了六十日不是仍可撤。无效或不成立不适用该六十日除斥。今天起诉不是已撤销。监事会决议不得直接套三项终局。股东会与董事会不得混写成同一决议。解释四仍引用旧第二十二条，不是 2024 年后现行条号。2018 年第二十二条第三款股东担保不是现行第二十六条。本窗 `XL#` 不是诉状，不是召集通知，不是关系窗 `GX#`，不是瑕疵窗 `XC#`，不是合规并行交卷行 `JY#`。本窗决议闸不是投并购路径表「决议闸」列。「开会日期改成章程那天」整体停止。本窗不执行发送，不代提交。不选定法院。
