# 决议效力方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、论坛、期限、金额或文书状态的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然无效、必然失权、必然解散或唯一必得总额。

`search_law` 返回已失效《合同法》、1993／2004／2013／2018《公司法》或仍引用旧第二十二条、第三十三条、第七十一条且未核验对应关系的司法解释时，记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

---

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 以股权或资产收购、投资交割、尽调闭环为主要目标 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果、员工激励的劳动身份 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂、综合合规体系 | 企业合规领域 |
| 破产申请、重整计划、破产债权申报与分配 | 破产领域 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 合伙企业、个人独资的入伙退伙 | 非公司主体，不在本领域 |
| 上市公司发行、持续信息披露或证券监管主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

混合信号：公司组织或股东关系主轴可留本任务；专项只作为背景时在缺口标明，不把专项规则硬套进本领域结论。

## 节点 1　决议文本和形成事实

1. 固定决议标题、日期、机关、出席名单、表决权数、书面签名。冲突并列。
2. 书面一致同意须核验现行第五十九条第三款：全体股东书面同意并签名或盖章。缺员不得补写成会议决议。
3. 一名董事或执行董事决定单独标注，不适用股东会表决权数门槛。

---

## 节点 2　效力三项

运行时核验第二十五条、第二十六条、第二十七条后再落判断。

| 条件 | 类型 | 禁止 |
| --- | --- | --- |
| 决议内容违反法律、行政法规 | 无效 | 写成可撤销以争取六十日 |
| 未召开、未表决、出席或同意数未达法或章程门槛 | 不成立 | 写成无效 |
| 召集程序、表决方式违法或违章，或内容只违章程 | 可撤销 | 忽略但书写成当然撤销 |

通知少发一日、签到瑕疵等，必须单独判断是否“仅有轻微瑕疵、对决议未产生实质影响”。依据不足则字段停止，不默认撤销。

---

## 节点 3　资格与期间

1. 请求撤销：原告应在起诉时具有股东资格。解释（四）第二条仍引用旧第二十二条的，须核验对应现行第二十六条，核验失败则资格规则字段停止。
2. 被告原则上为公司。
3. 期间：作出之日起六十日；未被通知股东自知道或应当知道之日起六十日，自作出之日起一年未行使则消灭。除斥不适用中止中断。
4. 无效或不成立无该六十日除斥，但仍须列诉讼时效待核，不编造“随时可诉无期限”。

---

## 节点 4　补正、重作与相对人

已实际履行且善意相对人的，标对外效力接口，不在本任务认定合同当然无效。可依法重新召集的，列为可逆替代，不强迫起诉。

---

## 节点 5　输出与停止

三项判断必须分列，允许部分成立。用户要起诉：最小交接后转 `file-resolution-action` 或 `file-shareholder-action`。用户要重开股东会：转 `prepare-shareholder-resolution`。
