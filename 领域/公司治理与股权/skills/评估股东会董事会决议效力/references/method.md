# 评估股东会董事会决议效力方法

本文件是可执行判断节点。轻微瑕疵不是当然撤销。未开会不是当然不成立。内容违章不是当然无效。内容违反法律、行政法规不是可撤销。视频或电子通信开会不是未召开。解释四「其他情形」不是 2024 年后不成立口袋。过了六十日不是仍可撤。无效或不成立不适用该六十日除斥。今天起诉不是已撤销。监事会决议不得直接套三项终局。股东会与董事会不得混写成同一决议。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然无效、当然撤销、唯一必得总额、选定法院、代提交、未知写零。本任务不定罪，不写诉状或新决议。本窗闸名只能是决议闸，禁止复用关系闸、瑕疵闸、催缴闸、失权闸、评估闸、止付闸、效力闸；效力只作行名 `XL#`。本窗决议闸禁止与投并购路径表「决议闸」列混用。本窗 `XL#` 是效力行。英文 id 禁止使用，一律用中文技能名 `评估股东会董事会决议效力`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年公司法第二十五条出资缴纳、第二十七条验资登记、2018 年第二十二条含股东提供相应担保、解释四仍引用旧第二十二条且未核验对应现行第二十六条、把解释四第五条第（五）项「其他情形」写成 2024 年后不成立口袋、把未开会写成当然不成立、把视频开会写成未召开、把轻微瑕疵写成当然撤销时记为噪声。禁止指导伪造决议或倒签会议。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现决议扫描，不是默认闭集。
`XL#` 固定列：`编号｜决议切片｜机关｜形成方式｜不成立接口｜无效接口｜可撤销接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已撤销」或「当然不成立」。无 `E#` 不得写已召开、已表决或已撤销。`E#` 只作证据形态回链，不是发送闸。扫描不是闭集。缺项记 `G#`。承认只进 `S#`／`D#`，不得占用 `A#`。

口头「通知晚了就算撤销」「没开会当然不成立」「今天起诉就算已撤销」只进 `S#`／`V#`，**不得单独算作开闸材料**。已读不得升格已送达。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：仅有轻微程序瑕疵且对决议未产生实质影响的，法院对是否撤销有裁量，不得写成当然撤销，也不得写成当然维持；依据不足则字段停止。该但书只覆盖召集程序或表决方式，内容违章不得套但书。不成立是能否认定决议存在的事实判断；可撤销是已成立决议的价值判断。内容违反法律、行政法规才走无效，不得降格可撤销抢六十日；内容只违反章程走可撤销。书面一致同意须全体股东在决定文件上签名或盖章，缺员不得补写成会议决议，也不得拿第六十条一人公司书面决定来救。章程未禁止时，电子通信开会、表决不是未召开。第二十七条四项穷尽，不得用解释四「其他情形」开口袋。

## 节点 0　分流、立场、决议闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造决议、倒签会议、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `XL#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是发送版召集或可签署新决议 | 负触发 `准备股东会决议与召集` |
| 主成果是可提交决议之诉诉状 | 负触发 `提起决议不成立无效或撤销之诉` |
| 主成果是程序清单终稿且不判断效力 | 负触发 `评估召集主持表决程序瑕疵` |
| 主成果是书面一致同意决定 | 负触发 `准备书面一致同意决定` |
| 主成果是董事会或执行董事决定终稿 | 负触发 `准备董事会或执行董事决定` |
| 主成果是关系总图 | 负触发 `评估公司治理与股东关系` |
| 主成果是出资瑕疵评估 | 负触发 `评估出资瑕疵催缴与加速到期` |

| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不写诉状」「不把轻微瑕疵写成当然撤销」 | 交付禁令，不是负触发 |

出现「决议」「撤销」「股东会」一词不是转出。

决议闸打开（可出 `XL#` 草案，仍不得标「已撤销／当然不成立／已无效」）须同时满足：单方无冲突立场已闭合；主成果是效力路径评估，不是诉状、不是新决议、不是程序清单终稿；至少一项可编号决议或形成碎片。口头「通知晚了」不算单独开闸材料。

决议闸部分打开：已有碎片，但机关或形成方式未闭合；对应格待核；仍交十节。

决议闸关闭（仍正触发）：无一可编号碎片。「今天必须出已撤销／已不成立终稿」而无最小碎片不得开闸。不出 `XL#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `XL#` 终稿，**第 7 节不得出诉状或新决议**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「轻微瑕疵即当然撤销」「未开会即当然不成立」「内容违章即当然无效」「内容违法即写成可撤销以抢六十日」「视频或电子通信开会即未召开」「解释四其他情形即不成立口袋」「无效或不成立适用六十日除斥」「过了六十日仍可撤」「今天起诉即已撤销」「监事会决议直接套三项终局」「股东会与董事会混写成同一决议」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `XL#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 决议闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与对立股东或对立董事相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造决议、倒签会议、抢夺印章证照、隐匿账簿、违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　机关、文本与形成方式

一行一个决议或形成版本。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `XL#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 机关 | 股东会／董事会／一名董事或执行董事分列 | 股东会与董事会混成同一决议 |
| 形成 | 会议决议／书面一致同意／执行董事决定分列 | 缺员书面决定补写成已召开会议 |
| 文本 | 标题、日期、出席、表决权、签名冲突并列 | 选对用户有利的一天当唯一作出日 |

检索锚点（写入 `L#` 前须核验）：

- 公司法第二十四条：电子通信开会、表决，章程另有规定除外；视频开会不是未召开。
- 第二十五条：内容违反法律、行政法规 → 无效接口；不得改可撤销抢六十日。
- 第二十六条：召集表决违法或违章，或内容只违章程 → 可撤销接口；轻微瑕疵但书只覆盖召集程序或表决方式，内容违章不得套但书；股东自作出之日起六十日；未被通知参加股东会的股东自知道或应当知道之日起六十日，且自作出之日起一年未行使则消灭。一年自作出日起算，不得径套董事会。
- 第二十七条：未召开、未表决、出席或同意数未达门槛 → 不成立接口，四项穷尽，无第五项。噪声：1993 年第二十七条验资登记；解释四第五条第（五）项「其他情形」。书面一致同意核验第五十九条第三款。第六十条是一人公司股东书面决定，禁止救缺员书面决议。
- 第二十八条：宣告后申请撤销已办登记，本窗不代办；与善意相对人形成的法律关系不受影响，本窗不认定合同当然无效。
- 第六十七条：章程对董事会职权的限制不得对抗善意相对人。
- 第十一条：章程或股东会对法定代表人职权的限制不得对抗善意相对人。
- 解释四第一条：确认无效或不成立的原告可为股东、董事、监事等，禁止写成只有股东能主张。
- 解释四第二条、第四条：仍引用旧第二十二条，须核验对应现行第二十六条；核验失败则资格／轻微瑕疵规则字段停止。
- 2018 年第二十二条第三款股东提供相应担保：公开文本已不在现行第二十六条，命中记噪声，不得当现行条。

一名董事或执行董事决定单独标注，不适用股东会表决权数门槛，也不得伪造「董事会会议」。监事会决议不是第二十五条至第二十七条的法定对象，三项终局只开接口。无效或不成立无该六十日除斥，但仍须列诉讼时效待核，禁止写「随时可诉无期限」。除斥不适用中止中断。期限必须分列：作出之日起六十日／未被通知六十日＋一年最长／无效不成立时效待核，禁止合成一个「起诉期限」，禁止写唯一截止日。

## 节点 3　效力行 `XL#`

按已出现决议扫描，不是默认闭集。每条须能指向机关、形成方式和只开接口的不成立／无效／可撤销。三项分列，允许部分成立，不得混写。

无 `E#` 不得写已召开、已表决或已撤销。状态 `草案`。一次只推荐下一步。未知金额不写零，不输出唯一必得总额。

热冲突强制处理：

- 轻微瑕疵即当然撤销／未开会即当然不成立／内容违章即当然无效／内容违法即写成可撤销／视频或电子通信开会即未召开／解释四其他情形即不成立口袋／无效或不成立适用六十日／过了六十日仍可撤／今天起诉即已撤销／监事会决议直接套三项终局 → 该格不支持或待核；仍出其他 `XL#`。
- 无一碎片 → 关闸，不出 `XL#` 终稿，窗口不关。
- 指导伪造决议、倒签会议、抢夺印章 → 整体停止，不是该格不支持。

解释四第二条原告起诉时须具有股东资格：请求撤销时核验；请求确认无效或不成立时核验解释四第一条（股东、董事、监事等），核验失败字段停止。被告原则上为公司，本窗不选定法院。

## 节点 4　召集、程序、诉讼与对外接口

第 7 节只开接口，不得夹带 `XL#` 终稿、诉状或新决议绕闸。闸关闭时第 7 节可写「闸未开，转介待决议编号」，不得补写已撤销。善意相对人、登记撤销只开 `第二十八条`／`第六十七条`／`第十一条` 接口，本窗不认定合同当然无效。可依法重新召集的，列为可逆替代，不强迫起诉。

下一步只转介：`准备股东会决议与召集`、`提起决议不成立无效或撤销之诉`、`评估召集主持表决程序瑕疵`、`准备书面一致同意决定`、`准备董事会或执行董事决定`、`评估公司治理与股东关系`。禁止此致某法院。不选定法院。不代提交。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：有限公司股东会通知晚发一日，决议内容只与章程细节冲突，作出已逾六十日。用户主张通知晚了当然撤销、内容违章当然无效、内容也违法所以改可撤销抢六十日、视频开过会等于没开会、过了六十日仍可撤、今天起诉就算已撤销，并把董事会纪要与股东会决议混成同一份。决议闸打开或半开。`Q-微`、`Q-无`、`Q-法`、`Q-电`、`Q-期` 不打开为可靠路径。第 6 节不得把已撤销、当然无效、已不成立写入可执行 `XL#`；对应格 `现有依据不支持`；仍出机关分列、形成方式、除斥待核等其他 `XL#`。不关窗。不写诉状。

场景②：用户同时交出公司「会议已召开」纪要与对立股东「那是倒签」口径，要求选对公司有利的一版，并指导「开会日期改成章程允许的那天」。命中双方秘密＋倒签会议。第一次整体停止。只交第 1、10 节。不出 `XL#`。不得问代表哪一方后继续。不以「坚持」为门槛。
