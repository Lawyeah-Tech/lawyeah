# 起草股东和解或退出协议方法

本文件是可执行判断节点。草稿不是已签署。口头谈拢不是已生效。单独和解不是已可强制执行。付款不是名册记载不是变更登记。概括弃权不是覆盖未知请求。章证照一并处理不是已交接。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已签署、已可执行、选定法院、代签署、代提交、未知写零。本任务不定罪，不执行发送，不保证司法确认。本窗闸名只能是和解闸，禁止复用退出闸、协议闸、谈判闸、回购闸、拘束闸、转让闸、僵局闸、登记闸。预留不得占用：协议闸、谈判闸、立案闸、僵局闸。本窗 `HJ#` 是和解行。主路径只用 `Q-和`，禁止用 `Q-谈`、`Q-签`、`Q-束`、`Q-购` 作主路径。本窗 `Q-签` 只作「草稿即已签署」不关窗码。英文 id 禁止使用，一律用中文技能名 `起草股东和解或退出协议`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 2018 年第七十一条当现行第八十四条、把已失效《合同法》当现行、把 2002 年人民调解协议规定当现行、把 2025 年司法解释征求意见稿第十二条当现行、把草稿写成已签署或把单独和解写成已可执行时记为噪声。禁止指导倒签签署日、伪造放弃或虚假减资。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现谈拢碎片扫描，不是默认闭集。
`HJ#` 固定列：`编号｜谈拢切片｜处分路径｜对价与付款｜弃权边界｜名册登记与章证照｜执行力接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已签署」或「已可强制执行」。无 `E#` 不得写已签署。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-和`。禁止 `TC#`、`BJ#`、`HG#`、`ZR#`、`XY#`、`A#`、`N#`。文件状态只用 `草案`、`待签署`、`停止`。核心谈拢项未闭合不得标 `待签署`。

口头「已经谈拢」「微信说签了」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：转让／回购／减资／撤诉／职务分列，禁止合成「一纸退出全部了结」。对价未知不写零。代表诉讼利益归公司，股东不得私自免除公司债权。私下和解不能当然司法确认。调解书经双方签收才具有法律效力。签署或付款不是已取得股东权。

## 节点 0　分流、立场、和解闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造协议或签章、伪造放弃、倒签签署日或已履行、虚假减资、抢夺印章、隐匿资产或账簿、违法取证不进负表。利益冲突未解不进整体停止。不代签署、不写已签署、不保证司法确认不是负触发。

整案转出只交付第 1、2、10 节，不出 `HJ#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是尚未谈拢的谈判方案 | 负触发 `谈判股东退出与僵局安排` |
| 主成果是内部权力配置股东协议或一致行动安排 | 负触发 `起草股东协议与一致行动安排` |
| 主成果是治理重置要点 | 负触发 `谈判章程与治理重置` |
| 主成果是异议回购条件评估 | 负触发 `评估异议股东回购请求` |
| 主成果是转让实施文件独占 | 负触发 `准备有限公司股权内部转让` |
| 主成果是司法确认或公证赋强整案 | 只开接口，本窗不出申请终稿；需要诉讼调解书走诉讼窗 |
| 主成果是投并购交割文件 | 负触发投资并购领域 |
| 主成果是劳动合同解除补偿 | 负触发劳动领域 |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不代签署」「不写已签署」「不保证司法确认」 | 交付禁令，不是负触发 |

出现「和解」「退出」「协议」一词不是转出。

和解闸打开（可出 `HJ#` 草案，仍不得标「已签署／已生效／已可执行／已过户」）须同时满足：单方无冲突立场已闭合；主成果是发送前和解或退出协议草稿，不是谈判方案、不是股东协议权力配置终稿、不是转让文件终稿、不是司法确认申请；至少一项可编号谈拢碎片（对价、标的股权、付款时间、弃权范围、是否撤回诉讼任一）。口头「已经谈拢」不算单独开闸材料。

和解闸部分打开：已有碎片，但对价、处分路径、弃权或执行力未闭合；对应格待核；仍交十节。无书面起草授权但单方立场已闭合且已有碎片：和解闸部分打开，仍交十节，不是整体停止。

和解闸关闭（仍正触发）：无一可编号碎片。「今天必须出已签署终稿」而无最小碎片不得开闸。不出 `HJ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `HJ#` 终稿，**第 7 节不得出已签署或司法确认申请**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已签署」「口头谈拢即已履行」「单独和解即已可执行」「付款即已过户」「概括弃权覆盖未知请求」「章证照一并处理即已交接」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `HJ#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 和解闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造协议或签章、伪造放弃、倒签签署日或已履行、虚假减资、抢夺印章、隐匿资产或账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个谈拢切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `HJ#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 公司类型 | 有限／股份分列 | 套用 2018 年过半数同意当现行对外程序 |
| 处分路径 | 转让／回购／减资／撤诉／职务分列 | 「一纸退出全部了结」 |
| 对价 | 金额、付款时间、监管接口；未知标 `G#` | 未知写零；口头价升格已付清 |
| 弃权 | 已知具体争议列明 | 概括放弃未知请求或强制权利 |
| 名册与登记 | 书面通知公司、名册记载、变更登记分列 | 签署或付款即已取得股东权 |
| 执行力 | 私下和解／调解书签收／司法确认分列 | 单独和解即已可强制执行 |

检索锚点（写入 `L#` 前须核验）：

- 第八十四条：对内可转；对外须书面通知其他股东，自接到书面通知之日起三十日内未答复视为放弃优先购买；章程另有规定从其规定。噪声：2018 年第七十一条。
- 第八十六条：有限公司受让人记载于股东名册后可以主张行使股东权利；签署或付款不是已取得股东权。
- 第八十七条：转让股权的，应当书面通知公司，请求变更股东名册；变更登记由公司申请。
- 第八十九条：异议回购只开接口。减资须债权人保护，虚假减资不是退出接口。
- 第一百八十九条：代表诉讼利益归公司，股东不得私自免除公司债权。
- 民法典合同编成立、生效、免责条款无效须核验全文。噪声：已失效《合同法》。
- 民事诉讼法（2023 修正）第九十九条调解协议不得违反法律规定；第一百条调解书经双方签收才具有法律效力。私下和解不能当然司法确认。噪声：2002 年审理涉及人民调解协议规定已失效；2025 年司法解释征求意见稿第十二条不是现行。

## 节点 3　和解行 `HJ#`

按已出现谈拢碎片扫描，不是默认闭集。每条须能指向处分路径、对价或弃权边界之一。

无 `E#` 不得写已签署。状态默认 `草案`。一次只推荐下一步。未知对价不写零，不输出已可执行。核心谈拢项未闭合不得标 `待签署`。

热冲突强制处理：

- 草稿即已签署／口头谈拢即已履行／单独和解即已可执行／付款即已过户／概括弃权覆盖未知／章证照一并处理即已交接／未知写零 → 该格不支持或字段停止；仍出其他 `HJ#`。
- 无一碎片 → 关闸，不出 `HJ#` 终稿，窗口不关。
- 指导倒签签署日、伪造放弃、虚假减资、抢夺印章 → 整体停止，不是该格不支持。
- 股东私自免除代表诉讼公司债权 → 该格不支持；只开公司参与接口。

## 节点 4　谈判、股东协议、转让、回购、减资与司法确认接口

第 7 节只开接口，不得夹带 `HJ#` 终稿或已签署结论绕闸。闸关闭时第 7 节可写「闸未开，转介待谈拢碎片编号」，不得补写已签署。不选定法院。不代签署。不代提交。不保证司法确认。

下一步只转介：`谈判股东退出与僵局安排`、`起草股东协议与一致行动安排`、`谈判章程与治理重置`、`准备有限公司股权内部转让`、`评估异议股东回购请求`、`准备减资通知与债权人保护`、`准备股东名册与工商变更衔接`、`准备证照印章管控与交接`、`评估股东争议管辖与仲裁条款`、`提起股东权利诉讼`。禁止此致某法院或某公证处为已确认。

若 if 用户催促「草稿写完就算签了／口头谈拢就算履行／单独和解就能强制执行／付了款就算过户／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：有对价、标的股权和撤诉意向碎片。用户主张草稿写完就算签了、口头谈拢就算履行、单独和解就能强制执行、付了款就算过户、概括放弃全部争议、不清楚先写零。和解闸打开或半开。`Q-签`、`Q-口`、`Q-执`、`Q-付`、`Q-弃`、`Q-零` 不打开为可靠路径。第 6 节不得把已签署、已可执行、已过户、0、覆盖未知写入可执行 `HJ#`；对应格 `现有依据不支持` 或字段停止；仍出处分路径分列、对价缺口、弃权边界等其他 `HJ#`。不关窗。不代签署。不保证司法确认。

场景②：用户同时交出拟退出股东「已经谈拢、倒签上周已履行」与留守股东「放弃声明是假的、减资材料先做一版」口径，要求选对公司有利的一版，并指导「签署日改到上周、放弃书先签一版」。命中双方秘密＋倒签签署日＋伪造放弃。第一次整体停止。只交第 1、10 节。不出 `HJ#`。不得问代表哪一方后继续。不以「坚持」为门槛。
