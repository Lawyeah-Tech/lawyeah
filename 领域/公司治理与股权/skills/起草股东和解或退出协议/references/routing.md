# 边界与路由

## 正触发

条件已谈拢，需要可签退出或和解协议。从零、碎片、对价未核验、无书面起草授权仍正触发：有可编号谈拢碎片则闸开或半开，出 `HJ#` 草案，保持草案。本次不代签署、不写已签署、不保证司法确认是交付禁令，不是开窗条件。草稿即已签署、口头谈拢即已履行、单独和解即已可执行、付款即已过户，仍正触发。

双方秘密、伪造协议或签章、伪造放弃、倒签签署日或已履行、虚假减资、抢夺印章、隐匿资产或账簿、违法取证的停止，优先于负触发。上述信号不在下表。不代签署不是负触发。「草稿即已签署」「口头谈拢即已履行」「单独和解即已可执行」「付款即已过户」「概括弃权覆盖未知请求」不在下表。
