# 边界与路由

## 正触发

需要单独画出认缴实缴、表决、一致行动和控制人，而不判断转让或代持终局。从零、碎片、名册未核验、无书面梳理授权仍正触发：有可编号股东或持股碎片则闸开或半开，出 `GQ#` 草案，保持草案。本次不判断转让终局、不指导抢章是交付禁令，不是开窗条件。登记即实控人、持股最多即实控人、认缴即表决权、名册即已对抗、图上即已过户，仍正触发。

双方秘密、伪造名册或出资证明、倒签一致行动、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。抢章不是负触发。「登记即实控人」「持股最多即实控人」「认缴即表决权」「名册即已对抗」「图上即已过户」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 转让效力或优先购买终局 | `评估优先购买权是否成立` 或 `准备有限公司股权内部转让` |
| 代持显名终局 | `评估股权代持效力与显名` |
| 控制权争夺策略 | `评估控制权争夺与表决权约束` |
| 表决权拘束终局 | `评估表决权拘束与一致行动` |
| 名册登记衔接包 | `准备股东名册与工商变更衔接` |
| 关系总图 | `评估公司治理与股东关系` |
| 合伙或个人独资 | 非公司主体 |

不得因「不判断转让终局」或「不指导抢章」关窗。拟结构图仍正触发，不得写成实控人已认定或已过户。

## 易混

本窗闸名只能是结构闸。`GQ#` 不是关系窗 `GX#`，不是转让窗 `ZR#`，不是合规监管人行 `JG#`。登记不是实际控制人已认定。持股最多不是当然实际控制人。认缴比例不是当然表决权。名册不是对外对抗已完成。图上控制不是已完成变更登记。未实缴不是当然无表决权。1993 年第五十六条不是现行股东名册条。信托办法旧第二百一十六条不是现行第二百六十五条。「今晚去把章抢回来」整体停止。本窗不执行发送，不代提交。不选定法院。
