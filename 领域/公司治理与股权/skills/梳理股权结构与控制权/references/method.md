# 梳理股权结构与控制权方法

本文件是可执行判断节点。登记不是实际控制人已认定。持股最多不是当然实际控制人。认缴比例不是当然表决权。名册不是对外对抗已完成。图上控制不是已完成变更登记。未实缴不是当然无表决权。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、实控人已认定、已过户、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不写诉状，不指导抢章。本窗闸名只能是结构闸，禁止复用关系闸、转让闸、控制闸、登记闸。预留不得占用：僵局闸、谈判闸、和解闸、立案闸。本窗 `GQ#` 是结构行。禁止占用关系窗 `GX#`、合规监管人行 `JG#`、他域 `ST#`。英文 id 禁止使用，一律用中文技能名 `梳理股权结构与控制权`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年第五十六条工会意见当现行股东名册、信托办法仍引旧第二百一十六条当现行第二百六十五条、把登记写成实际控制人已认定时记为噪声。禁止指导伪造名册或抢夺印章。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现股东或持股扫描，不是默认闭集。
`GQ#` 固定列：`编号｜三层主体｜认缴实缴｜表决权｜协议约束｜控制人接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「实控人已认定」或「已对外对抗」。无 `E#` 不得写已记载名册。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-构`。禁止 `GX#`、`ZR#`、`JG#`、`ST#`、`A#`、`N#`。

口头「登记上就是实控人」「谁持股多谁说了算」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：登记股东、股东名册、协议或代持三层并列，名称不一致不自动合并。对内对外效力分列，不写成已经统一。表决权原则上按出资比例，章程另有规定除外；未实缴是否限制表决核验失败则字段停止，不得默认无表决权或当然有表决权。控股股东与实际控制人定义分列；依据不足写无法形成结论，不因持股最多写成实际控制人。

## 节点 0　分流、立场、结构闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造名册或出资证明、倒签一致行动、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。抢章不是负触发。

整案转出只交付第 1、2、10 节，不出 `GQ#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是转让效力或优先购买终局 | 负触发 `评估优先购买权是否成立` 或 `准备有限公司股权内部转让` |
| 主成果是代持显名终局 | 负触发 `评估股权代持效力与显名` |
| 主成果是控制权争夺策略 | 负触发 `评估控制权争夺与表决权约束` |
| 主成果是表决权拘束终局 | 负触发 `评估表决权拘束与一致行动` |
| 主成果是名册登记衔接包 | 负触发 `准备股东名册与工商变更衔接` |
| 主成果是关系总图 | 负触发 `评估公司治理与股东关系` |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不判断转让终局」「不指导抢章」 | 交付禁令，不是负触发 |

出现「股权」「控制」「名册」一词不是转出。

结构闸打开（可出 `GQ#` 草案，仍不得标「实控人已认定／已对外对抗／已过户」）须同时满足：单方无冲突立场已闭合；主成果是结构图，不是转让终局、不是代持显名、不是争夺策略；至少一项可编号股东或持股碎片。口头「登记上就是实控人」不算单独开闸材料。

结构闸部分打开：已有碎片，但三层或表决权未闭合；对应格待核；仍交十节。

结构闸关闭（仍正触发）：无一可编号碎片。「今天必须出已认定实控人终稿」而无最小碎片不得开闸。不出 `GQ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `GQ#` 终稿，**第 7 节不得出已认定实控人或已过户**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「登记即实控人」「持股最多即实控人」「认缴即表决权」「名册即已对抗」「图上即已过户」「未实缴即无表决权」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `GQ#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 结构闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与对立股东相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造名册或出资证明、倒签一致行动、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个股东或持股版本。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `GQ#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 三层 | 登记／名册／协议或代持分列 | 名称不一致自动合并 |
| 资本 | 认缴、实缴分列 | 认缴写成已实缴 |
| 表决 | 出资比例或章程另定 | 未实缴默认无表决权 |
| 控制人 | 控股股东／实际控制人分列 | 持股最多写成实控人已认定 |

检索锚点（写入 `L#` 前须核验）：

- 有限股东名册常见检索第五十六条须核验全文。噪声：1993 年第五十六条工会意见。
- 第六十五条：股东会会议由股东按照出资比例行使表决权，章程另有规定除外。
- 第二百六十五条第二项控股股东、第三项实际控制人。持股最多不是当然实际控制人。登记不是实际控制人已认定。噪声：信托办法仍引旧第二百一十六条。
- 第三十四条常见检索：未经登记或未经变更登记不得对抗善意相对人。名册不是对外对抗已完成。
- 股份名册第一百零二条不得未核验套有限。类别股或特别表决权只开接口。
- 股权转让后名册变更常见检索须核验，本窗不写成已过户。

## 节点 3　结构行 `GQ#`

按已出现股东或持股扫描，不是默认闭集。每条须能指向三层主体、认缴实缴或表决权。

无 `E#` 不得写已记载名册。状态默认 `草案`。一次只推荐下一步。未知比例不写零。多层持股用箭头标明，循环持股标红旗待核，不写成已认定实控人。

热冲突强制处理：

- 登记即实控人／持股最多即实控人／认缴即表决权／名册即已对抗／图上即已过户／未实缴即无表决权／未知写零 → 该格不支持或字段停止；仍出其他 `GQ#`。
- 无一碎片 → 关闸，不出 `GQ#` 终稿，窗口不关。
- 指导伪造名册、倒签一致行动、抢章 → 整体停止，不是该格不支持。

协议约束只画进图，终局转 `评估表决权拘束与一致行动`。

## 节点 4　转让、代持、争夺与名册接口

第 7 节只开接口，不得夹带 `GQ#` 终稿、已认定实控人或抢章步骤绕闸。闸关闭时第 7 节可写「闸未开，转介待股东或持股编号」，不得补写已认定。不选定法院。不代提交。

下一步只转介：`评估优先购买权是否成立`、`准备有限公司股权内部转让`、`评估股权代持效力与显名`、`评估控制权争夺与表决权约束`、`评估表决权拘束与一致行动`、`准备股东名册与工商变更衔接`、`评估公司治理与股东关系`。禁止此致某登记机关。

若 if 用户催促「登记上就是实控人／谁持股多谁说了算／图画完就算过户」，then 该格 `现有依据不支持`，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：登记显示甲持股百分之五十一，名册记载乙，口头说有一致行动。用户主张登记就是实控人、认缴多少就多少票、名册已经对外对抗、图画完就算过户、未实缴的人没票。结构闸打开或半开。`Q-登`、`Q-票`、`Q-抗`、`Q-过` 不打开为可靠路径。第 6 节不得把实控人已认定、已对外对抗、已过户写入可执行 `GQ#`；对应格 `现有依据不支持`；仍出三层并列、认缴实缴分列、协议待核等其他 `GQ#`。不关窗。不判断代持终局。

场景②：用户同时交出公司「名册已改到买方」与对立股东「名册是后补、一致行动是倒签」口径，要求选对公司有利的一版，并指导「今晚去把章抢回来」。命中双方秘密＋伪造名册＋倒签一致行动＋抢章。第一次整体停止。只交第 1、10 节。不出 `GQ#`。不得问代表哪一方后继续。不以「坚持」为门槛。
