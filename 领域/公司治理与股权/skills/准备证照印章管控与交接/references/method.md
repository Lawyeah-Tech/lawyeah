# 准备证照印章管控与交接方法

本文件是可执行判断节点。占有不是合法权源。持章不是合法法定代表人。交接草稿不是已交接。网交回执不是已核准交接。登记法定代表人不是当然保管人。两套代表人抢先占有不是合法权源。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已交接、已核准、占有即权源、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不写可提交诉状终稿。本窗闸名只能是印章闸，禁止复用任免闸、控制闸、僵局闸、保全闸、登记闸。预留不得占用：僵局闸、谈判闸、和解闸、立案闸、显名闸。本窗 `YZ#` 是印章行。禁止占用优先认缴行 `YJ#`、出质行 `ZY#`。英文 id 禁止使用，一律用中文技能名 `准备证照印章管控与交接`。本窗 `Q-印` 不是合规领域「印发即生效」。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年第十条住所、2018 年第十三条董事长、执行董事或经理当现行第十条、1993 年第三十四条不得抽回出资当现行第三十四条、1991 年民事诉讼法第一百零三条协助执行罚款当现行行为保全、把占有写成合法权源时记为噪声。禁止指导抢夺、隐匿、私刻或倒签已交接。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现权源或物品扫描，不是默认闭集。
`YZ#` 固定列：`编号｜保管权源｜占有与清单｜合法交接｜保全接口｜禁止动作红旗｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已交接」或「占有即权源」。无 `E#` 不得写已交接或已核准。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-印`。禁止 `YJ#`、`ZY#`、`RM#`、`KZ#`、`JJ#`、`AJ#`、`A#`、`N#`。文件状态只用 `草案`、`待签署`、`停止`。权源未闭合不得标 `待签署`。

口头「章在我手里就是我说了算」「复印件就算交完了」「今晚去把章抢回来」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：章程或有效决议指定保管人优先；未指定时登记法定代表人常被当作法定保管人，但不是当然所有权人，也不是对抗公司返还请求的权源。原法定代表人职务终止后继续占有通常构成无权占有。两套对立法定代表人：权源冲突并列，不指导抢先占有。拒交停止私下强取，转证照返还诉讼和行为保全接口。持章对外可能对善意相对人生效，不得写成一律无效。

## 节点 0　分流、立场、印章闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造决议或交接、倒签已交接、抢夺印章证照、隐匿账簿、私刻、违法取证不进负表。利益冲突未解不进整体停止。抢章不是负触发。

整案转出只交付第 1、2、10 节，不出 `YZ#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是控制权争夺路径 | 负触发 `评估控制权争夺与表决权约束` |
| 主成果是任免登记包 | 负触发 `准备董事高管任免与登记` |
| 主成果是行为保全申请书且交接并非目标 | 负触发 `准备股权或公司财产保全` |
| 主成果是账簿或电子治理记录保全步骤 | 负触发 `保全公司账簿印章与电子治理记录` |
| 主成果是僵局解散评估 | 负触发 `评估公司僵局` |
| 主成果是已作出保全之应对 | 负触发 `应对股权冻结或行为保全` |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不代提交」「不写已交接」「不指导抢章」 | 交付禁令，不是负触发 |

出现「章」「证照」「交接」「法定代表人」一词不是转出。

印章闸打开（可出 `YZ#` 草案，仍不得标「已交接／已核准／占有即权源」）须同时满足：单方无冲突立场已闭合；主成果是合法管控与交接草稿，不是任免包、不是争夺终稿、不是保全申请独占、不是抢章方案；至少一项可编号权源或物品碎片。口头「章在我手里就是我说了算」不算单独开闸材料。

印章闸部分打开：已有碎片，但权源或现持有人未闭合；对应格待核；仍交十节。

印章闸关闭（仍正触发）：无一可编号碎片。「今天必须出已交接终稿」而无最小碎片不得开闸。不出 `YZ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `YZ#` 终稿，**第 7 节不得出已交接或抢章**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「占有即权源」「持章即合法法定代表人」「草稿即已交接」「回执即已核准」「未登记即已对抗」「抢先占有即合法」「持章对外一律无效」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `YZ#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 印章闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与对立董事或股东相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造决议或交接、倒签已交接或任职、抢夺印章证照、隐匿账簿、私刻、破解系统、侵入邮箱或 Ukey 或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个物品切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `YZ#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 主体 | 公司／原持有人／拟保管人分列 | 把持有人写成所有权人 |
| 权源 | 章程／决议／制度／代表人职务分列 | 占有写成合法权源；无法定或约定保管人时指定用户为当然保管人 |
| 物品 | 公章／合同章／财务章／发票专用章／法定代表人名章／营业执照正副本／许可证／Ukey／空白合同／会计账簿／电子邮箱管理员权限分列 | 未知件数写零 |
| 登记 | 现任登记与拟变更分列 | 未变更写成已对抗；持章写成已是合法法定代表人 |
| 三十日 | 法定代表人辞任起算 | 未满写成已完成交接 |

检索锚点（写入 `L#` 前须核验）：

- 第十条：法定代表人由代表公司执行公司事务的董事或者经理担任；辞任董事或经理视为同时辞去法定代表人；应当在辞任之日起三十日内确定新的法定代表人。三十日是补任期，不是诉讼时效，不是已完成交接。噪声：1993 年第十条住所、2018 年第十三条。
- 第十一条：章程或股东会对法定代表人职权的限制不得对抗善意相对人。持章对外可能对善意相对人生效，不得写成一律无效，也不得写成持章人已是合法法定代表人。
- 第三十四条：登记事项未经登记或者未经变更登记，不得对抗善意相对人。须核验全文。噪声：1993 年第三十四条不得抽回出资。
- 第三十五条：变更法定代表人的，变更登记申请书由变更后的法定代表人签署。持章的原代表人签署变更申请不是已核准交接。
- 民法典第二百三十五条无权占有返还原物只开接口。
- 民事诉讼法（2023 修正）第一百零三条诉讼中保全含行为保全；第一百零四条诉前保全。噪声：1991 年第一百零三条协助执行罚款。
- 民诉解释第五十条法定代表人以依法登记为准；变更后未完成登记，变更后的法定代表人要求代表法人参加诉讼的，人民法院可以准许，只开接口。
- 市场主体登记规则须核验现行有效文本。噪声：2016 年公司登记管理条例已失效。

## 节点 3　印章行 `YZ#`

按已出现权源或物品扫描，不是默认闭集。每条须能指向权源、占有与清单和保全接口。

无 `E#` 不得写已交接或已核准。状态默认 `草案`。一次只推荐下一步。未知件数不写零。

热冲突强制处理：

- 占有即权源／持章即合法法定代表人／草稿即已交接／回执即已核准／未登记即已对抗／抢先占有即合法／持章对外一律无效／未知写零 → 该格不支持或字段停止；仍出其他 `YZ#`。
- 无一碎片 → 关闸，不出 `YZ#` 终稿，窗口不关。
- 指导抢夺、隐匿、私刻、倒签已交接 → 整体停止，不是该格不支持。

## 节点 4　任免、控制、僵局、保全与账簿接口

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：法定代表人已内部变更、执照未换、原法定代表人仍持公章。用户主张章在我这就是我的、复印件交过了、登记还没改也无权要章、网上交了就核准了、持章对外一律无效、把未知件数写成零。印章闸打开或半开。`Q-占`、`Q-职`、`Q-单`、`Q-核`、`Q-登`、`Q-外` 不打开为可靠路径。第 6 节不得把已交接、占有即权源、已核准写入可执行 `YZ#`；对应格 `现有依据不支持`；仍出权源分列、物品清单、拒交诉讼接口等其他 `YZ#`。不关窗。不代提交。不指导强取。

场景②：用户同时交出公司「股东会已免职应交章」与对立董事「决议是后补倒签、章是我的」口径，要求选对公司有利的一版，并指导「今晚去把章抢回来、私刻一枚先用、交接日改到上周」。命中双方秘密＋伪造＋倒签＋抢夺＋私刻。第一次整体停止。只交第 1、10 节。不出 `YZ#`。不得问代表哪一方后继续。不以「坚持」为门槛。
