# 边界与路由

## 正触发

僵局或法定代表人变更后争章证照，需要合法管控与交接。从零、碎片、权源未核验、无书面交接授权仍正触发：有可编号权源或物品碎片则闸开或半开，出 `YZ#` 草案，保持草案。本次不代提交、不写已交接、不指导抢章是交付禁令，不是开窗条件。占有即权源、持章即合法法定代表人、草稿即已交接、回执即已核准、未登记即已对抗，仍正触发。

双方秘密、伪造决议或交接、倒签已交接或任职、抢夺印章证照、隐匿账簿、私刻、破解系统、违法取证的停止，优先于负触发。上述信号不在下表。抢章不是负触发。「占有即权源」「持章即合法法定代表人」「草稿即已交接」「回执即已核准」「未登记即已对抗」「抢先占有即合法」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 控制权争夺路径 | `评估控制权争夺与表决权约束` |
| 任免登记包 | `准备董事高管任免与登记` |
| 行为保全申请书且交接并非目标 | `准备股权或公司财产保全` |
| 账簿或电子治理记录保全步骤 | `保全公司账簿印章与电子治理记录` |
| 僵局解散评估 | `评估公司僵局` |
| 已作出保全之应对 | `应对股权冻结或行为保全` |
| 合伙或个人独资 | 非公司主体 |

不得因「不代提交」「不写已交接」或「不指导抢章」关窗。拟交接草稿仍正触发，不得写成已交接或占有即权源。

## 易混

本窗闸名只能是印章闸。`YZ#` 不是任免窗 `RM#`，不是控制窗 `KZ#`，不是出质窗 `ZY#`，不是优先认缴窗 `YJ#`，不是僵局窗 `JJ#`。主路径是 `Q-印`，不是合规印发，不是代持窗 `Q-持`。占有不是合法权源。持章不是合法法定代表人。交接草稿不是已交接。网交回执不是已核准交接。登记法定代表人不是当然保管人。两套代表人抢先占有不是合法权源。持章对外可能对善意相对人生效，不得写成一律无效。1993 年第十条住所不是现行法定代表人条。2018 年第十三条不是现行第十条。1993 年第三十四条不是现行登记对抗条。1991 年民事诉讼法第一百零三条不是现行行为保全条。「今晚去把章抢回来」「私刻一枚先用」「交接日改到上周」整体停止。本窗不执行发送，不代提交。不选定法院。
