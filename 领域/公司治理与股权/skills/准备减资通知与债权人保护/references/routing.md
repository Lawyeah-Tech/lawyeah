# 边界与路由

## 正触发

已决定减资，需要通知公告和清偿或担保安排，而非破产或增资。从零、碎片、清单未核验、无书面减资授权仍正触发：有减资决定碎片则闸开或半开，出 `JZ#` 草案，保持草案。本次不代提交、不写债务已经消灭是交付禁令，不是开窗条件。决议即债务消灭、编造已经过异议期、亏损减资向股东分配，仍正触发。

双方秘密、倒签通知或公告日、伪造资产负债表或财产清单、对已知债权人不通知（普通减资）、虚构已清偿、伪造减资决议、抢夺印章证照、违法取证的停止，优先于负触发。上述信号不在下表。「决议即债务消灭」「编造已经过异议期」「无清单仍待发送」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 破产清算或重整 | 破产领域 |
| 内部增资 | `准备内部增资与认缴调整` |
| 违法减资责任终局 | `评估股东对公司债务的补充清偿责任` |
| 召集或可签署决议包独占 | `准备股东会决议与召集` |
| 可签署章程终稿独占 | `起草或修订公司章程` |
| 纯形式变更套减资债权人程序 | `准备有限公司与股份公司形式变更` |
| 合伙或个人独资 | 非公司主体 |

不得因「不代提交」或「不写债务已经消灭」关窗。拟减资通知仍正触发，不得写成已经过异议期或债务已经消灭。尚未决定减资但主成果仍是减资包：正触发关闸，第 7 节开增资或决议接口。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |
| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「减资」「通知」「债权人」一词不是转出。

## 易混

本窗闸名只能是减资闸，禁止复用增资闸、变更闸、召集闸。减资决议不是债务已经消灭。未通知已知债权人不是已经有效完成。无资产负债表及财产清单不是可待发送。编造已经过异议期不是已届满。亏损减资不是可向股东分配，不是可免除出资义务，不适用第二百二十四条第二款但仍须三十日公告。普通减资不是可跳过十日通知。等比例减资不是定向减资当然有效。公示系统刊登不是已知债权人已接到通知。已读不是已通知。2018 年第一百七十七条不是现行第二百二十四条。纯形式变更不是减资债权人程序。本窗 `JZ#` 不是增资窗 `ZZ#`，不是召集窗 `ZJ#`，不是变更窗 `BG#`。「通知日先倒签」「资产负债表先做假」「已知债权人先别通知」整体停止。本窗不执行发送，不代提交。不保证核准。伤残等级与本窗无关。
