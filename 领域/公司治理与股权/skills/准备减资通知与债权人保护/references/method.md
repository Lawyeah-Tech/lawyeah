# 准备减资通知与债权人保护方法

本文件是可执行判断节点。减资决议不是债务已经消灭。未通知已知债权人不是已经有效完成。无资产负债表及财产清单不是可待发送。编造已经过异议期不是已届满。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、债务已消灭、已经过异议期、选定法院、代提交、未知写零、唯一必得清偿总额。本任务不定罪，不执行发送，不代提交。本窗闸名只能是减资闸，禁止复用增资闸、变更闸、召集闸、决议闸。本窗 `JZ#` 是减资行。英文 id 禁止使用，一律用中文技能名 `准备减资通知与债权人保护`。主路径只用 `Q-减`，禁止 `Q-增`、`Q-召`、`Q-形` 作主路径。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 2018 年第一百七十七条当现行第二百二十四条、把减资决议写成债务消灭、把亏损减资写成可向股东分配时记为噪声。禁止指导倒签通知或伪造资产负债表。伤残等级与本窗无关。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现减资碎片扫描，不是默认闭集。
`JZ#` 固定列：`编号｜减资切片｜路径分列｜资产负债表与财产清单｜通知公告｜清偿或担保｜登记核验｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。无 `E#` 不得写已通知、已经过异议期或债务已经消灭。`E#` 只作证据形态回链，不是发送闸。扫描不是闭集。缺项记 `G#`。承认只进 `S#`／`D#`，不得占用 `A#`。文件状态只用 `草案`、`待发送`、`停止`。无资产负债表及财产清单不得标 `待发送`。

口头「已经减完了」「债权人都知道了」「异议期过了」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：普通减资须编制资产负债表及财产清单，自决议之日起十日内通知债权人、三十日内公告；债权人接到通知三十日、未接到自公告四十五日可要求清偿或担保。弥补亏损减资不适用该债权人清偿担保程序，但仍须决议之日起三十日内公告，且不得向股东分配、不得免除出资义务。日期未核验不得编造已经过异议期。

## 节点 0　分流、立场、减资闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、倒签通知或公告日、伪造资产负债表或财产清单、对已知债权人不通知（普通减资）、虚构已清偿、伪造减资决议、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `JZ#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是破产清算或重整 | 整案转破产 |
| 主成果是内部增资 | 负触发 `准备内部增资与认缴调整` |
| 主成果是违法减资责任终局 | 负触发 `评估股东对公司债务的补充清偿责任` |
| 主成果是召集或决议包独占 | 负触发 `准备股东会决议与召集` |
| 主成果是章程终稿独占 | 负触发 `起草或修订公司章程` |
| 主成果是纯形式变更套减资债权人程序 | 负触发 `准备有限公司与股份公司形式变更` |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不代提交」「不写债务已经消灭」 | 交付禁令，不是负触发 |

出现「减资」「通知」「债权人」一词不是转出。决议即债务消灭不是负触发，该格不支持。尚未决定减资但主成果仍是减资包：正触发关闸，第 7 节开增资或决议接口。

减资闸打开（可出 `JZ#` 草案，仍不得标「已经过异议期／债务已经消灭／已通知」）须同时满足：单方无冲突立场已闭合；主成果是减资通知与债权人保护草案，不是破产、不是增资、不是责任终局；至少一项可编号减资决定碎片。口头「已经减完了」不算单独开闸材料。

减资闸部分打开：已有减资决定碎片，但资产负债表、债权人名单或期间未闭合；对应格待核；仍交十节。无书面减资授权但立场已闭合且有减资决定碎片：部分打开，不是整体停止。无资产负债表及财产清单：部分打开，不得标 `待发送`。

减资闸关闭（仍正触发）：无一可编号减资决定碎片。「今天必须出已过异议期终稿」而无最小碎片不得开闸。不出 `JZ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `JZ#` 终稿，**第 7 节不得出债务已消灭或已过异议期**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「决议即债务消灭」「编造已经过异议期」「无清单仍待发送」「亏损减资向股东分配」「亏损减资免除出资义务」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `JZ#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 债权人委托起草公司减资通知，then 整体停止。
若 if 单方立场已闭合但无一可编号减资决定碎片，then 减资闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与已知债权人或对立股东相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出倒签通知或公告日、伪造资产负债表或财产清单、对已知债权人不通知（普通减资）、虚构已清偿、伪造减资决议、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个减资切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `JZ#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 路径 | 普通／弥补亏损／定向分列 | 普通减资套亏损减资免通知；亏损减资向股东分配 |
| 清单 | 资产负债表及财产清单 | 无清单标待发送 |
| 决议 | 有限代表三分之二；股份出席三分之二 | 混套；董事会冒充股东会 |
| 通知公告 | 普通：十日通知、三十日公告；亏损：三十日公告 | 编造已经过异议期；已读即已通知 |
| 债权人 | 接到三十日／未接到自公告四十五日 | 公示刊登即已知债权人已接到 |
| 比例 | 默认按出资或持股比例；定向须另定 | 定向当然有效 |

检索锚点（写入 `L#` 前须核验）：

- 第二百二十四条第一款：编制资产负债表及财产清单。
- 第二百二十四条第二款：决议之日起十日内通知债权人，三十日内报纸或国家企业信用信息公示系统公告；债权人接到通知三十日、未接到自公告四十五日可要求清偿或担保。噪声：2018 年第一百七十七条。
- 第二百二十四条第三款：原则上按出资或持股比例减；法律另有规定、有限全体股东另有约定或股份章程另有规定除外。
- 第二百二十五条：先按第二百一十四条第二款补亏后仍有亏损才可减资补亏；不得向股东分配、不得免除出资或股款义务；不适用第二百二十四条第二款，但仍须决议之日起三十日内公告；减资后公积金未达注册资本百分之五十不得分配利润。
- 第二百二十六条：违法减资退还、恢复原状、赔偿只开接口，不写责任总额。
- 第五十九条、第六十六条、第一百一十六条：股东会职权与特别决议分列。第一百一十二条不准用第五十九条第三款。

不得暗示「决议一过债务就没了」。

## 节点 3　减资行 `JZ#`

按已出现减资路径扫描，不是默认闭集。普通减资、弥补亏损减资、定向减资分列。

无 `E#` 不得写已通知、已经过异议期或债务已经消灭。状态默认 `草案`。一次只推荐下一步。未知不写零。无资产负债表及财产清单不得标 `待发送`。决议日、通知日、公告日未核验：期间格字段停止，不得写成已经届满。公示系统刊登不是已知债权人已接到通知。已读不是已通知。普通减资不得省略十日通知。亏损减资不得向股东分配、不得免除出资，不适用第二百二十四条第二款但仍须三十日公告。定向减资缺另定：依据不足，不定有效。

热冲突强制处理：

- 决议即债务消灭／编造已经过异议期／无清单仍待发送／亏损减资向股东分配／普通减资免通知／估数或写零 → 该格不支持或字段停止；仍出其他 `JZ#`。
- 无一减资决定碎片 → 关闸，不出 `JZ#` 终稿，窗口不关。
- 指导倒签通知、伪造清单、对已知债权人不通知、虚构已清偿 → 整体停止，不是该格不支持。

## 节点 4　增资、决议、章程、责任与破产接口

第 7 节只开接口，不得夹带 `JZ#` 终稿、债务已消灭或已过异议期绕闸。闸关闭时第 7 节可写「闸未开，转介待减资决定编号」，不得补写已经过异议期。夹带增资只开增资窗接口。决议包只开召集窗接口。违法减资责任只开补充清偿接口。

下一步只转介：`准备内部增资与认缴调整`、`准备股东会决议与召集`、`起草或修订公司章程`、`评估股东对公司债务的补充清偿责任`、`准备股东名册与工商变更衔接`。禁止此致某登记机关为唯一路径。不代提交。不保证核准。不执行发送。

若 if 用户催促「决议过了债就没了／异议期肯定过了／没有清单也先发／亏损减资分点钱／金额不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「减资闸与减资通知债权人保护草案」。本窗不执行发送。不包含：债务消灭证明、已经过异议期证明、破产申请、已通过决议独占。禁止选边治愈。禁止决议即债务消灭。禁止编造已经过异议期。禁止指导倒签通知或伪造资产负债表。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标减资终稿已形成。
风险档 A：倒签通知、伪造清单、对已知债权人不通知、虚构已清偿必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：已有拟减注册资本的股东会议题碎片。用户主张决议一过债务就消灭了、没有资产负债表也先发通知、日期没核就写异议期过了、亏损减资还要给股东分钱、金额不清楚先写零。减资闸打开或半开。`Q-灭`、`Q-清`、`Q-过`、`Q-亏`、`Q-零` 不打开为可靠路径。第 6 节不得把债务已消灭、待发送、已经过异议期、向股东分配、0 写入可执行 `JZ#`；对应格 `现有依据不支持` 或字段停止；仍出路径分列、清单缺口、第二百二十四条期间待核、第二百二十五条禁分配等其他 `JZ#`。不关窗。不代提交。不执行发送。若同时要求不通知已知债权人、倒签通知日或伪造清单 → 改走场景②。

场景②：用户同时交出公司「债权人都通知过了」口径与已知债权人「从未收到通知」口径，要求选对己方有利的一版，并指导对已知债权人不发通知、倒签公告日、资产负债表先做假。命中双方秘密＋不通知已知债权人＋倒签通知＋伪造清单。第一次整体停止。只交第 1、10 节。不出 `JZ#`。不得问代表哪一方后继续。不以「坚持」为门槛。
