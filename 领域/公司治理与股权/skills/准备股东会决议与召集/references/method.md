# 召集与决议方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、论坛、期限、金额或文书状态的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然无效、必然失权、必然解散或唯一必得总额。

`search_law` 返回已失效《合同法》、1993／2004／2013／2018《公司法》或仍引用旧第二十二条、第三十三条、第七十一条且未核验对应关系的司法解释时，记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

---

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 以股权或资产收购、投资交割、尽调闭环为主要目标 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果、员工激励的劳动身份 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂、综合合规体系 | 企业合规领域 |
| 破产申请、重整计划、破产债权申报与分配 | 破产领域 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 合伙企业、个人独资的入伙退伙 | 非公司主体，不在本领域 |
| 上市公司发行、持续信息披露或证券监管主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

混合信号：公司组织或股东关系主轴可留本任务；专项只作为背景时在缺口标明，不把专项规则硬套进本领域结论。

## 节点 1　召集权、授权和发送闸

1. 默认召集顺序须核验现行第六十六条：董事会召集、董事长主持；董事会不能或不履行时监事会；监事会亦不召集时，代表十分之一以上表决权的股东可自行召集和主持。
2. 授权不明、召集权依据不足：不锁定 `待发送` 终稿。
3. 同时代表冲突股东：整体停止。
4. 用户要求倒签、伪造出席或事后补通知充作已合法召开：整体停止。

---

## 节点 2　通知、职权、表决

1. 通知期核验第六十四条：十五日前通知全体股东，章程另有规定或全体股东另有约定除外。不得编造“一律十五日且章程无效”。
2. 议案必须落在第五十九条股东会职权或章程规定职权内。发行公司债券可授权董事会，须核验条文。修改章程、增减资、合并分立解散、变更形式不得写成经理决定。
3. 表决门槛：普通决议与修改章程、增减资、合并分立解散、变更形式的特别决议分列，运行时核验现行比例，核验失败则门槛字段停止。
4. 关联交易回避：董事、控股股东或实际控制人相关议案须单列回避，核验失败则回避字段停止。

---

## 节点 3　草稿

1. 召集通知写明时间、地点、议题。决议写明出席、表决权、同意反对弃权、通过结论。
2. 书面一致同意路径：全体股东书面同意并签名或盖章，可以不召开会议。缺一人则本路径关闭。
3. 逐句回链来源。不把利润数字写成已确定可分金额。

---

## 节点 4　送达

按章程住所、约定邮箱和备份送达设计。每次尝试预列实施人、文本版本、渠道和回证。本任务不执行发送，不补造回证。

---

## 节点 5　状态词

通知状态只用 `草案`、`待发送`、`已发送待证明到达`、`停止`。没有会议事实和规则引文，禁止写 `已通过`。需要登记的事项只列接口，不代提交。
