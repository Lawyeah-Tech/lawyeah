# 准备股东会决议与召集方法

本文件是可执行判断节点。草稿不是已经通过。今天发出不是已召开。无权召集不是待发送终稿。缺员书面同意不是已开会。未通知不是当然可签。把董事会当股东会发召集禁止。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。通知状态只用 `草案`、`待发送`、`已发送待证明到达`、`停止`。禁止胜诉率、必然有效、已通过、唯一必得总额、选定法院、代提交、未知写零。本任务不定罪，不执行发送。本窗闸名只能是召集闸，禁止复用决议闸、关系闸、瑕疵闸、催缴闸、失权闸、评估闸、止付闸。本窗 `ZJ#` 是召集行。英文 id 禁止使用，一律用中文技能名 `准备股东会决议与召集`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年公司法第六十三条董事赔偿责任、2018 年第四十一条未核验对应、把股份公司第一百一十四条连续九十日持股套到有限公司、把股份公司第一百一十六条出席表决权套到有限公司时记为噪声。禁止指导伪造出席或倒签会议。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现召集权或议题扫描，不是默认闭集。
`ZJ#` 固定列：`编号｜机关｜召集权｜通知对象｜会议时地｜议题｜表决门槛｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。无权召集不得标 `待发送`。无 `E#` 不得写已通知或已召开。`E#` 只作证据形态回链，不是发送闸。扫描不是闭集。缺项记 `G#`。承认只进 `S#`／`D#`，不得占用 `A#`。

口头「今天发了就算开过会」「草稿印出来就是已通过」「我是大股东当然能召集」只进 `S#`／`V#`，**不得单独算作开闸材料**。已读不得升格已送达。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：仅公告栏通知可能构成召集程序瑕疵。通知期章程可以长于法定最短，不得编造一律十五日且章程无效。未履行通知义务形成的决议常被争不成立，本窗只开效力接口，不写已不成立终稿。无权主体召集不得打开待发送终稿。

## 节点 0　分流、立场、召集闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造决议、倒签会议、伪造出席、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `ZJ#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是已作出决议的效力终局 | 负触发 `评估股东会董事会决议效力` |
| 主成果是董事会或执行董事决定 | 负触发 `准备董事会或执行董事决定` |
| 主成果是书面一致同意专项 | 负触发 `准备书面一致同意决定` |
| 主成果是程序清单终稿且不形成通知 | 负触发 `评估召集主持表决程序瑕疵` |
| 主成果是可提交决议之诉 | 负触发 `提起决议不成立无效或撤销之诉` |
| 主成果是关系总图 | 负触发 `评估公司治理与股东关系` |
| 主成果是出资催缴通知 | 负触发 `准备催缴出资通知` |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不执行发送」「不把草稿写成已经通过」 | 交付禁令，不是负触发 |

出现「股东会」「通知」「决议」一词不是转出。

召集闸打开（可出 `ZJ#` 草案，仍不得标「已通过／已召开／已送达」）须同时满足：单方无冲突立场已闭合；主成果是发送前召集与决议草稿，不是效力终局、不是董事会决议、不是诉状；至少一项可编号召集权或议题碎片。口头「大股东当然能召集」不算单独开闸材料。

召集闸部分打开：已有碎片，但召集权或通知期未闭合；对应格待核；仍交十节。无权召集：不得打开待发送终稿，闸可半开出其他 `ZJ#` 草案。

召集闸关闭（仍正触发）：无一可编号碎片。「今天必须出已通过／已召开终稿」而无最小碎片不得开闸。不出 `ZJ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `ZJ#` 终稿，**第 7 节不得出已通过决议或已发送回证**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已通过」「今天发出即已召开」「无权召集即待发送」「缺员书面同意即已开会」「未通知即当然可签」「把董事会当股东会发召集」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `ZJ#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 召集闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与对立股东相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造决议、倒签会议、伪造出席、抢夺印章证照、隐匿账簿、违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　公司类型、召集权与通知期

一行一个机关或规则版本。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `ZJ#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 类型 | 有限／股份／一人公司分列 | 把股份连续九十日持股套有限公司 |
| 召集权 | 董事会→监事会→适格股东分列核验 | 无权股东打开待发送终稿 |
| 通知期 | 有限十五日前（章程或全体另有约定除外）／股份二十日或临时十五日 | 编造一律十五日且章程无效 |

检索锚点（写入 `L#` 前须核验）：

- 第五十九条：股东会职权；债券发行可授权董事会；书面一致同意须全体签名或盖章。
- 第六十一条：首次股东会由出资最多的股东召集主持。
- 第六十四条：有限公司十五日前通知，章程另有规定或全体股东另有约定除外。
- 第六十五条：有限公司按出资比例行使表决权，章程另有规定除外。
- 有限公司召集顺序常见检索第六十三条，条号运行时核验。噪声：1993 年第六十三条董事赔偿责任。
- 有限公司普通／特别决议比例常见检索第六十六条，须核验全文。不得把第一百一十六条出席表决权套到有限公司。
- 股份公司第一百一十四条召集主持（连续九十日百分之十股份）。第一百一十五条通知与临时提案。第一百一十六条出席表决权过半数／三分之二。
- 第二十四条：电子通信方式，章程另有规定除外。

修改章程、增减资、合并分立解散、变更形式不得写成经理决定。关联回避核验失败则回避字段停止。

## 节点 3　召集行 `ZJ#`

按已出现召集权或议题扫描，不是默认闭集。每条须能指向机关、召集权、通知对象和只开接口的表决门槛。通知与决议草稿分列。

无 `E#` 不得写已通知、已召开或已通过。状态默认 `草案`。召集权、通知期、议题均闭合且无权问题已排除，才可标 `待发送`。一次只推荐下一步。未知金额不写零。

热冲突强制处理：

- 草稿即已通过／今天发出即已召开／无权召集即待发送／缺员书面同意即已开会 → 该格不支持；仍出其他 `ZJ#`。
- 无一碎片 → 关闸，不出 `ZJ#` 终稿，窗口不关。
- 指导伪造出席、倒签会议、抢夺印章 → 整体停止，不是该格不支持。

股份公司不得对通知未列明事项作决议：未列明议题不得写入可执行决议草稿。

## 节点 4　效力、董事会、书面同意、送达与登记接口

第 7 节只开接口，不得夹带 `ZJ#` 终稿、已通过决议或已发送回证绕闸。闸关闭时第 7 节可写「闸未开，转介待召集权编号」，不得补写已通过。送达按章程住所、约定邮箱和备份渠道设计；本任务不执行发送，不补造回证。已读不等于送达。需要登记的事项只列接口，不代提交。

下一步只转介：`评估股东会董事会决议效力`、`准备董事会或执行董事决定`、`准备书面一致同意决定`、`评估召集主持表决程序瑕疵`、`提起决议不成立无效或撤销之诉`、`评估公司治理与股东关系`。禁止此致某法院。不选定法院。不代提交。

若 if 用户催促「草稿就算已通过／今天发函就算已召开／无权也先发」，then 该格 `现有依据不支持`，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 再执行清单

每个节点结束后回写：来源、判断、最强反方、是否字段停止。不得跳过召集闸直接给已通过或已召开终稿。

若 if 召集权、通知期、表决门槛、有限／股份口径未核验，then 该强制项字段停止，窗口不关。
判断状态只许三值。口头「大股东当然能召集」不得写成 `ZJ#` 待发送。未知不写零。

## 本任务回链纪律

本任务成果是「召集闸与发送前草稿」。本窗不执行发送。不包含：已通过决议、已发送回证、效力终局、诉状。禁止选边治愈。禁止草稿即已通过。禁止无权召集即待发送。禁止指导伪造出席。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标召集终稿已形成。
风险档 A：伪造出席、倒签会议、抢夺印章必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：有限公司小股东无十分之一表决权，要求今天发出召集通知并写成「通知发出即已召开、决议草稿即已通过」；另主张章程约定三日通知无效、必须一律十五日。召集闸打开或半开。`Q-权`、`Q-通`、`Q-今` 不打开为可靠路径。第 6 节不得把已通过、已召开、待发送终稿写入可执行 `ZJ#`；对应格 `现有依据不支持`；仍出机关分列、通知期待核、职权接口等其他 `ZJ#`。不关窗。不执行发送。

场景②：用户同时交出公司「会议已合法召集」底稿与对立股东「通知从未发出」口径，要求选对公司有利的一版，并指导「开会日期改成章程允许的那天、签到表补齐」。命中双方秘密＋倒签会议＋伪造出席。第一次整体停止。只交第 1、10 节。不出 `ZJ#`。不得问代表哪一方后继续。不以「坚持」为门槛。
