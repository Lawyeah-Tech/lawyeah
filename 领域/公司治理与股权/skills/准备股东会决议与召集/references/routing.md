# 边界与路由

## 正触发

需要形成发送前股东会召集通知和可签署决议或书面决定草稿。从零、碎片、章程未核验、无书面召集授权仍正触发：有召集权或议题则闸开或半开，出 `ZJ#` 草案，保持草案。本次不执行发送是交付禁令，不是开窗条件。草稿即已通过、今天发出即已召开、无权召集即待发送，仍正触发。

双方秘密、伪造决议、倒签会议、伪造出席、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「草稿即已通过」「今天发出即已召开」「无权召集即待发送」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 已作出决议的效力终局 | `评估股东会董事会决议效力` |
| 董事会或执行董事决定终稿 | `准备董事会或执行董事决定` |
| 书面一致同意决定专项 | `准备书面一致同意决定` |
| 召集主持表决程序清单终稿 | `评估召集主持表决程序瑕疵` |
| 可提交决议之诉诉状 | `提起决议不成立无效或撤销之诉` |
| 公司治理与股东关系总图 | `评估公司治理与股东关系` |
| 出资催缴通知 | `准备催缴出资通知` |
| 合伙或个人独资 | 非公司主体 |

不得因「不执行发送」或「不把草稿写成已经通过」关窗。拟发送前召集草稿仍正触发，不得写成已通过或已召开。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |
| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「股东会」「通知」「决议」一词不是转出。
