# 评估利润分配请求权方法

本文件是可执行判断节点。有利润不是已可强制分配。抽象利润分配请求权不是已决议具体债权。认缴比例不是分配比例。六个月执行期不是请求已成立。未知不写零。不输出唯一必得总额。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已确定债权、唯一必得总额、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不写诉状，不写测算终稿。本窗闸名只能是分配闸，禁止复用测算闸、查阅闸、查阅诉闸、起诉闸、回购闸。预留不得占用：僵局闸、谈判闸、和解闸、立案闸、控制闸、登记闸、显名闸。本窗 `FP#` 是分配行。主路径只用 `Q-分`，禁止用 `Q-测`、`Q-查`、`Q-代` 作主路径。禁止占用测算窗 `DJ#`、查阅窗 `CK#`、查阅诉窗 `CY#`、起诉窗 `SZ#`。英文 id 禁止使用，一律用中文技能名 `评估利润分配请求权`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年第二百一十条擅自发行、解释五一年完成分配未核验对应第二百一十二条六个月、把有利润写成已可强制分配时记为噪声，不得写入 `L#`。禁止指导伪造分配决议或倒签分配。财务数据冲突并列，不选对用户有利的报表。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现利润、决议或未支付碎片扫描，不是默认闭集。
`FP#` 固定列：`编号｜分配基础｜决议或具体方案｜抽象或具体债权｜执行期与返还接口｜比例接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「应得分红」或唯一必得总额。无 `E#` 不得写已决议债权。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-分`。禁止 `DJ#`、`CK#`、`CY#`、`SZ#`、`A#`、`N#`。决议后债权／无决议强制分配／违法分配返还分列。一行一个切片。金额未知写 `未知`／`G#`，禁止写 `0`。

口头「很赚钱就必须分」「没有决议也算到期债权」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：无载明具体分配方案的股东会决议，请求分配利润原则上应驳回；滥权导致不分给其他股东造成损失只开待核接口，不得默认强制分配。有有效具体方案决议后，请求权可转化为普通债权，后续经营恶化不当然消灭该债权，但仍须核验决议效力与可分配基础。长期不分红本身不等于滥权。法院不能替代公司作出分配方案。连续五年盈利不分且符合分配条件并对该决议投反对票：走异议回购，不写成已确定分红债权。

## 节点 0　分流、立场、分配闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造分配决议、倒签分配、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `FP#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 以股权或资产收购、投资交割、尽调闭环为主要目标 | 整案转投资并购 |
| 婚姻、离婚、继承中的股权归属与分割 | 整案转婚家 |
| 高管劳动合同、解除、竞业劳动后果 | 整案转劳动 |
| 企业级舞弊调查、反商业贿赂、综合合规体系 | 整案转企业合规 |
| 破产申请、重整计划、破产债权申报与分配 | 整案转破产 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 合伙企业、个人独资 | 整案转出，非公司主体 |
| 上市公司发行、持续信息披露或证券监管主轴 | 整案转证券监管／投资并购，本领域只保留公司机关接口 |
| 主成果是分项测算 | 负触发 `测算利润分配与股权回购对价` |
| 「不输出唯一可分数额」「不把无决议写成已确定债权」 | 交付禁令，不是负触发 |

出现「分红」「利润」一词不是转出。

分配闸打开（可出 `FP#` 草案，仍不得标「已可强制分配／已确定债权／唯一必得总额」）须同时满足：单方无冲突立场已闭合；主成果是分配条件评估，不是测算终稿、不是诉状；至少一项可编号利润、决议或未支付碎片。口头「很赚钱就必须分」不算单独开闸材料。

分配闸部分打开：已有碎片，但基础、决议或比例未闭合；对应格待核；仍交十节。

分配闸关闭（仍正触发）：无一可编号碎片。「今天必须出已确定债权终稿」而无最小碎片不得开闸。不出 `FP#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `FP#` 终稿，**第 7 节不得出已确定债权或唯一必得总额**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「有利润即强制分」「无决议即到期债权」「认缴即分配比例」「六个月即请求已成立」「未知写零」「唯一必得总额」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `FP#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 分配闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造分配决议、倒签分配、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个分配切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `FP#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 主体 | 股东／公司分列 | 把对立股东写成分配义务人 |
| 基础 | 补亏、法定公积金、所余利润分列 | 报表冲突选对用户有利一版 |
| 决议 | 有无载明具体方案的股东会决议 | 无决议写成已确定债权 |
| 比例 | 有限实缴／全体另定；股份持股／章程另定 | 认缴当分配比例 |

检索锚点（写入 `L#` 前须核验）：

- 第二百一十条：补亏、百分之十法定公积金、有限按实缴、全体另定除外；股份按持股、章程另定除外；公司持有的本公司股份不得分配。噪声：1993 年第二百一十条擅自发行。
- 第二百一十一条：违法分配退还与董监高赔偿。
- 第二百一十二条：决议作出之日起六个月内分配。噪声：解释五一年完成分配未核验对应。
- 解释四第十五条：无具体方案决议原则上驳回；滥权例外只开待核。
- 第八十九条、第一百六十一条：五年盈利不分走异议回购，不写成分红债权。

## 节点 3　分配行 `FP#`

按已出现利润、决议或未支付碎片扫描，不是默认闭集。每条须能指向基础、决议或比例。

无 `E#` 不得写已决议债权。状态默认 `草案`。一次只推荐下一步。利润数字未知：写 `未知`，禁止写零。滥权例外核验失败：依据不足，不得默认强制分配。

热冲突强制处理：

- 有利润即强制分／无决议即到期债权／认缴即分配比例／六个月即请求已成立／未知写零／唯一必得总额 → 该格不支持或字段停止；仍出其他 `FP#`。
- 无一碎片 → 关闸，不出 `FP#` 终稿，窗口不关。
- 指导伪造分配决议、倒签分配 → 整体停止，不是该格不支持。

## 节点 4　测算、起诉与回购接口

第 7 节只开接口，不得夹带 `FP#` 终稿、已确定债权或唯一必得总额绕闸。闸关闭时第 7 节可写「闸未开，转介待分配编号」，不得补写已确定债权。不选定法院。不代提交。

下一步只转介：`测算利润分配与股权回购对价`、`提起利润分配之诉`、`评估异议股东回购请求`。禁止此致某法院。

若 if 用户催促「很赚钱就必须分／没有决议也算到期债权／按认缴算唯一总额」，then 该格 `现有依据不支持`，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「分配闸与分配行草案」。本窗不执行发送。不包含：已可强制分配、已确定债权、唯一必得总额、测算终稿、诉状。禁止选边治愈。禁止有利润即强制分。禁止无决议即到期债权。禁止指导伪造决议。分配闸打开 ≠ 已可强制分配 ≠ 已决议具体债权 ≠ 六个月请求已成立。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标分配终稿已形成。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：公司连续盈利，股东会不作分配决议。用户主张很赚钱就必须分、无决议也是到期债权、按认缴算出唯一必得总额、六个月到了请求就成立。分配闸打开或半开。`Q-盈`、`Q-无`、`Q-认`、`Q-六` 不打开为可靠路径。第 6 节不得把已可强制分配、已确定债权写入可执行 `FP#`；对应格 `现有依据不支持`；仍出补亏公积金缺口、无具体方案、滥权待核等其他 `FP#`。不关窗。不写诉状。五年不分只开回购接口。

场景②：用户同时交出「公司口径：没有可分配利润」与「股东口径：把分配决议日期改到报表日前」，要求选对股东有利的一版。命中双方秘密＋倒签分配。第一次整体停止。只交第 1、10 节。不出 `FP#`。不得问代表哪一方后继续。不以「坚持」为门槛。
