# 边界与路由

## 正触发

公司盈利不分，或决议后不执行，需要判断请求权条件。从零、碎片、利润未核验、无书面评估授权仍正触发：有可编号利润、决议或未支付碎片则闸开或半开，出 `FP#` 草案，保持草案。本次不输出唯一可分数额、不把无决议写成已确定债权是交付禁令，不是开窗条件。有利润即强制分、无决议即到期债权，仍正触发。

双方秘密、伪造分配决议、倒签分配、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「有利润即强制分」「无决议即到期债权」「认缴即分配比例」「六个月即请求已成立」「未知写零」「唯一必得总额」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 分项测算或唯一可分数额精算 | `测算利润分配与股权回购对价` |
| 可提交分配诉状 | `提起利润分配之诉` |
| 五年盈利不分回购路径 | `评估异议股东回购请求` |
| 税负方案 | 税务领域 |
| 合伙或个人独资 | 非公司主体 |

不得因「不输出唯一可分数额」或「不把无决议写成已确定债权」关窗。要判断有没有分配请求权仍正触发，不得写成已可强制分配。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露或证券监管主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「分红」「利润」一词不是转出。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 只要分项测算 | `测算利润分配与股权回购对价` |
| 只要可提交分配诉状 | `提起利润分配之诉` |
| 只要五年不分回购 | `评估异议股东回购请求` |

## 易混

本窗闸名只能是分配闸，不是测算闸。`FP#` 不是测算窗 `DJ#`。主路径是 `Q-分`，不是 `Q-测`，不是 `Q-代`。有利润不是已可强制分配。抽象请求权不是已决议具体债权。认缴比例不是分配比例。六个月执行期不是请求已成立。1993 年第二百一十条不是现行分配条。解释五一年完成分配不是压过第二百一十二条六个月的现行规则。解释四第十五条滥权例外不是默认强制分配。五年盈利不分走异议回购，不写成分红债权。「分配决议日期改到报表日前」整体停止。本窗不执行发送，不代提交。不选定法院。不写诉状。不输出唯一必得总额。
