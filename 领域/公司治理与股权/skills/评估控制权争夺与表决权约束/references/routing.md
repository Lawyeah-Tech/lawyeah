# 边界与路由

## 正触发

争董事席位、法定代表人或表决权归属。从零、碎片、名册未核验仍正触发：有可编号股权、席位、代表人、名册或协议碎片则闸开或半开，出 `KZ#` 草案，保持草案。本次不指导抢章、不把名册写成已最终控制是交付禁令，不是开窗条件。名册即已最终控制、持股最多即当然实控人，仍正触发。

双方秘密、伪造决议、倒签会议或一致行动、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「名册即已最终控制」「持股最多即当然实控人」「认缴即当然表决权」「股东协议即对公司生效」「登记即已对抗」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 股权控制图 | `梳理股权结构与控制权` |
| 表决权拘束协议效力 | `评估表决权拘束与一致行动` |
| 任免登记包且争夺已结束 | `准备董事高管任免与登记` |
| 保全申请 | `准备股权或公司财产保全` |
| 合法印章交接 | `准备证照印章管控与交接` |
| 收购交割 | 投资并购领域 |
| 僵局解散 | `评估公司僵局` |
| 合伙或个人独资 | 非公司主体 |

不得因「不指导抢章」或「不把名册写成已最终控制」关窗。要判断争夺路径仍正触发，不得写成已最终控制。

## 易混

本窗闸名只能是控制闸，不是结构闸。`KZ#` 不是结构窗 `GQ#`。主路径是 `Q-争`，不是 `Q-构`，不是 `Q-束`。名册或登记不是已最终控制。持股最多不是当然实际控制人。认缴比例不是当然表决权。股东协议不是当然对公司发生效力。1993 年第十条不是现行法定代表人条。2018 年第十三条不是 2024 年 7 月 1 日后的现行条号。抢章不能补正权源，第一次整体停止。「把一致行动日期改到股东会前」整体停止。本窗不执行发送，不代提交。不选定法院。不指导抢章。
