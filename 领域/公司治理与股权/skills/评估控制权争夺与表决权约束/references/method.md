# 评估控制权争夺与表决权约束方法

本文件是可执行判断节点。名册或登记不是已最终控制。持股最多不是当然实际控制人。认缴比例不是当然表决权。股东协议不是当然对公司发生效力。未知不写零。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已最终控制、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不指导抢章。本窗闸名只能是控制闸，禁止复用结构闸、关系闸、转让闸、登记闸、任免闸、保全闸。预留不得占用：僵局闸、谈判闸、和解闸、立案闸、显名闸。本窗 `KZ#` 是争夺行。主路径只用 `Q-争`，禁止用 `Q-构`、`Q-束`、`Q-任` 作主路径。禁止占用结构窗 `GQ#`、关系窗 `GX#`、任免窗 `RM#`。英文 id 禁止使用，一律用中文技能名 `评估控制权争夺与表决权约束`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年第十条住所、2018 年第十三条、把名册写成已最终控制时记为噪声，不得写入 `L#`。禁止指导抢夺印章证照。禁止指导伪造决议或倒签一致行动。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现股权、席位、代表人、名册或协议碎片扫描，不是默认闭集。
`KZ#` 固定列：`编号｜权源切片｜席位或代表人｜名册登记对抗｜协议拘束接口｜临时措施红旗｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已最终控制」。无 `E#` 不得写已变更登记或已对抗。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-争`。禁止 `GQ#`、`GX#`、`ZR#`、`RM#`、`A#`、`N#`。一行一个切片。

口头「登记上就是我说了算」只进 `S#`／`V#`，**不得单独算作开闸材料**。结构窗 `GQ#` 不得单独开闸。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：法定代表人按章程由执行公司事务的董事或经理担任；辞任视为同时辞去法定代表人，三十日内确定新任。登记未变更不得对抗善意相对人。变更法定代表人的申请书由变更后的法定代表人签署。股东会选举更换董事监事。认缴不是当然表决权，章程另定待核。股东协议对内可拘束签约股东，对公司效力待核，不得默认对公司生效。持股最多不是当然实际控制人。名册记载不是已最终控制。抢章不能补正权源。保全、任免、印章交接只开接口。

## 节点 0　分流、立场、控制闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造决议、倒签会议或一致行动、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `KZ#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 以股权或资产收购、投资交割、尽调闭环为主要目标 | 整案转投资并购 |
| 婚姻、离婚、继承中的股权归属与分割 | 整案转婚家 |
| 高管劳动合同、解除、竞业劳动后果 | 整案转劳动 |
| 企业级舞弊调查、反商业贿赂、综合合规体系 | 整案转企业合规 |
| 破产申请、重整计划、破产债权申报与分配 | 整案转破产 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |

| 「不指导抢章」「不把名册写成已最终控制」 | 交付禁令，不是负触发 |

出现「控制」「表决」「法定代表人」一词不是转出。

控制闸打开（可出 `KZ#` 草案，仍不得标「已最终控制」）须同时满足：单方无冲突立场已闭合；主成果是控制权路径评估，不是结构图终稿、不是抢章步骤；至少一项可编号股权、席位、代表人、名册或协议碎片。口头「登记上就是我说了算」不算单独开闸材料。

控制闸部分打开：已有碎片，但权源、席位或登记未闭合；对应格待核；仍交十节。

控制闸关闭（仍正触发）：无一可编号碎片。不出 `KZ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `KZ#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「名册即已最终控制」「持股最多即当然实控人」「认缴即当然表决权」「股东协议即对公司生效」「登记即已对抗」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `KZ#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 控制闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造决议、倒签会议或一致行动、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 3　争夺行 `KZ#`

按已出现股权、席位、代表人、名册或协议碎片扫描，不是默认闭集。无 `E#` 不得写已变更登记或已对抗。状态默认 `草案`。抢章红旗出现：整体停止，不是该格不支持后继续出争夺步骤。

热冲突强制处理：

- 名册即已最终控制／持股最多即当然实控人／认缴即当然表决权／股东协议即对公司生效／登记即已对抗／未知写零 → 该格不支持或字段停止；仍出其他 `KZ#`。
- 无一碎片 → 关闸，不出 `KZ#` 终稿，窗口不关。
- 指导抢章、伪造决议、倒签一致行动 → 整体停止。
