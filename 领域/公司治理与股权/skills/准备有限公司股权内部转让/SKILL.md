# 准备有限公司股权内部转让

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1993、2004、2013、2018 年《公司法》文本当作 2024 年 7 月 1 日后的现行条号。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“有限公司股权转让实施包”：对内或对外路径、书面通知与同等条件、优先购买三十日、未缴出资责任、转让文件、名册与变更登记接口。签署协议不等于已经取得对内股东权。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：有限公司股权拟对内或对外转让，需要优先购买程序和名册登记衔接，且主目标不是投资并购交割。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主目标是收购、增资交割或尽调闭环；
- 主目标是离婚或继承分割过户；
- 只要评估代持效力；
- 股份公司上市流通或发行；
- 用户要求跳过书面通知并倒签其他股东放弃；

本任务不把签署协议写成已记载名册或已变更登记，不代提交，不给胜诉率。

## 建立评估坐标

确认：使用者与授权；单方立场；公司名称与类型；相对方及可能责任主体；章程／股东名册／登记版本；争议或拟办事项；法域；当前协商、通知、决议、仲裁、诉讼或执行状态；机关文书作出与送达；对方已知主张；关键材料及缺失。

同时掌握公司和对立股东双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 章程或股东协议条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`V#` 评估或稿件版本；`E#` 发送／送达／履行凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验 2023 年修订《公司法》及配套规定的现行条件和效力时点；`search_practiced` 补路径与反例；特殊事实用 `search_case_by_fact`，明确筛选用 `search_case_by_filter`。不虚构案件系统。

工具不可用时继续事实、主体、程序文书状态和问题清单；请求／抗辩的法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [转让方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 路径与章程另定

股东之间转让与对外转让分账。章程对股权转让另有规定的，先核验是否违反强制规范。

### 2. 优先购买

对外转让须书面通知数量、价格、支付方式和期限等。三十日内未答复视为放弃。两个以上股东行使时协商，不成按转让时出资比例。

### 3. 未缴出资

未届期股权由受让人缴纳，未按期则转让人补充责任。瑕疵出资转让可能连带。不得隐瞒未缴事实。

### 4. 文件与名册

转让文件、请求记载名册和变更登记分列。受让人自记载于股东名册时起可向公司主张股东权利。

### 5. 停止

倒签放弃声明、伪造其他股东签章：整体停止。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体、公司类型或章程文本无法建立；用户坚持伪造决议、倒签会议、抢夺印章证照、隐匿账簿或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为本任务禁止的终稿类型。
