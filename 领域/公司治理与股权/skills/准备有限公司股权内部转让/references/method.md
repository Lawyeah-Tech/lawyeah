# 准备有限公司股权内部转让方法

本文件是可执行判断节点。签署协议不是已取得对内股东权。付款不是已变更登记。通知发出不是优先购买已放弃。未答复不是当然放弃。把对外转让当内部转让禁止。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。文件状态只用 `草案`、`待发送`、`待签署`、`停止`。禁止胜诉率、必然有效、已取得股东权、唯一必得总额、选定法院、代提交、未知写零。本任务不定罪，不执行发送。本窗闸名只能是转让闸，禁止复用召集闸、决议闸、关系闸、瑕疵闸、催缴闸、优先购买闸。本窗 `ZR#` 是转让行。英文 id 禁止使用，一律用中文技能名 `准备有限公司股权内部转让`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年公司法第八十四条募股申请、第八十六条募股批准、2018 年第七十一条未核验对应、解释四第十七条半数同意程序当现行对外转让规则时记为噪声。禁止指导倒签放弃声明或伪造签章。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现转让碎片扫描，不是默认闭集。
`ZR#` 固定列：`编号｜转让切片｜对内对外路径｜同等条件｜名册接口｜登记接口｜未缴出资接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。无 `E#` 不得写已通知、已记载或已放弃。`E#` 只作证据形态回链，不是发送闸。扫描不是闭集。缺项记 `G#`。承认只进 `S#`／`D#`，不得占用 `A#`。

口头「签了就是股东」「款到了就过户了」「通知发出他们就算放弃」只进 `S#`／`V#`，**不得单独算作开闸材料**。已读不得升格已送达。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：名册对内、登记对外分列。仅签署转让协议或仅付款，不得写成已经取得对内股东权。对外书面通知要素缺失不得视为已合法通知。三十日起算不明则并行情景，不得写成唯一截止日已过。

## 节点 0　分流、立场、转让闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、倒签放弃声明、伪造其他股东签章、伪造决议、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `ZR#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是优先购买是否成立终稿 | 负触发 `评估优先购买权是否成立` |
| 主成果是名册与工商变更终稿 | 负触发 `准备股东名册与工商变更衔接` |
| 主成果是代持效力或显名 | 负触发 `评估股权代持效力与显名` |
| 主成果是出质约束终稿 | 负触发 `评估股权出质对治理与转让的约束` |
| 主成果是关系总图 | 负触发 `评估公司治理与股东关系` |
| 主成果是未缴出资责任精算 | 负触发 `评估出资瑕疵催缴与加速到期` |
| 主成果是投并购交割 | 整案转投资并购 |
| 主成果是婚家分割过户 | 整案转婚家 |
| 股份公司股份转让 | 整案转证券／股份规则 |
| 「不执行发送」「不把签署写成已记载名册」 | 交付禁令，不是负触发 |

出现「转让」「优先购买」「名册」一词不是转出。

转让闸打开（可出 `ZR#` 草案，仍不得标「已取得股东权／已变更登记／已放弃」）须同时满足：单方无冲突立场已闭合；主成果是股东之间转让草稿与名册登记接口，不是优先购买成立终稿、不是名册工商变更终稿、不是交割清单；至少一项可编号转让方、受让方或股权碎片。口头「签了就是股东」不算单独开闸材料。

转让闸部分打开：已有碎片，但对内对外路径或章程另定未闭合；对应格待核；仍交十节。

转让闸关闭（仍正触发）：无一可编号碎片。「今天必须出已取得股东权／已变更登记终稿」而无最小碎片不得开闸。不出 `ZR#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `ZR#` 终稿，**第 7 节不得出已记载名册或已变更登记**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「签署即已取得股东权」「付款即已变更登记」「通知即已放弃」「未答复即当然放弃」「把对外转让当内部转让」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `ZR#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 转让闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立两方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出倒签放弃声明、伪造其他股东签章、伪造决议、抢夺印章证照、隐匿账簿、违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　对内对外路径与章程另定

一行一个转让切片或规则版本。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `ZR#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 路径 | 股东之间／对外分列 | 把对外当内部跳过书面通知 |
| 章程 | 另有规定与强制规范冲突并列待核 | 章程禁止转让直接写成无效而不待核 |
| 主体 | 有限公司；股份公司不得套第八十四条 | 用第八十四条套股份 |

检索锚点（写入 `L#` 前须核验）：

- 第八十四条第一款：股东之间可以相互转让。
- 第八十四条第二款：对外书面通知数量、价格、支付方式和期限；三十日内未答复视为放弃；两人以上协商，不成按转让时出资比例。
- 第八十四条第三款：章程另有规定的从其规定。
- 第八十六条：书面通知公司变更名册；登记请求；受让人自记载于名册时起主张股东权利。未经登记不得对抗善意相对人，条号运行时核验（常见检索第三十四条），不得把 2018 年第三十二条当现行。
- 第八十八条：未届期由受让人缴纳、转让人补充；瑕疵出资连带，受让人善意则转让人承担。法释〔2024〕7 号第四条只开接口，且只覆盖第一款，第二款连带不得顺手溯及。
- 第八十五条：强制执行优先购买二十日只开接口。

解释四第十七条半数同意不是 2024 年后现行对外程序。2018 年第七十一条不得当现行条。

## 节点 2　转让闸与路径扫描

本节禁止出 `ZR#` 终稿。对内协议与对外通知分列，不得合成「已放弃且已取得股东权」。

| 编号 | 打开信号 | 本任务允许 | 禁止 | 转介 |
| --- | --- | --- | --- | --- |
| `Q-内` | 股东之间转让草稿与名册接口 | 转让闸；`ZR#` 草案 | 已取得股东权终稿 | 留本任务 |
| `Q-优` | 主成果是优先购买成立终稿 | 不打开 | 本窗出成立终稿 | `评估优先购买权是否成立` |
| `Q-名` | 主成果是名册工商变更终稿 | 不打开 | 本窗代提交登记 | `准备股东名册与工商变更衔接` |
| `Q-代` | 主成果是代持效力 | 不打开 | 本窗出显名终稿 | `评估股权代持效力与显名` |
| `Q-质` | 主成果是出质约束 | 不打开 | 本窗出出质终稿 | `评估股权出质对治理与转让的约束` |
| `Q-通` | 签署即已取得股东权 | 该格不支持 | 升格已记载名册 | 该格不支持 |
| `Q-弃` | 通知即已放弃／未答复即当然放弃 | 该格不支持 | 写成唯一截止日已过 | 该格不支持 |

## 节点 3　转让行 `ZR#`

按已出现转让碎片扫描，不是默认闭集。每条须能指向对内对外路径、名册接口和未缴出资接口。

无 `E#` 不得写已通知、已记载、已放弃或已登记。状态默认 `草案`。一次只推荐下一步。未知金额不写零。

热冲突强制处理：

- 签署即已取得股东权／付款即已变更登记／通知即已放弃／把对外当内部 → 该格不支持；仍出其他 `ZR#`。
- 无一碎片 → 关闸，不出 `ZR#` 终稿，窗口不关。
- 指导倒签放弃、伪造签章 → 整体停止，不是该格不支持。

不得向受让人隐瞒未缴事实。未缴出资只开 `评估出资瑕疵催缴与加速到期` 接口，本窗不输出唯一必得补缴总额。

## 节点 4　优先购买、名册、送达与登记接口

第 7 节只开接口，不得夹带 `ZR#` 终稿、已记载名册或已变更登记绕闸。闸关闭时第 7 节可写「闸未开，转介待转让编号」，不得补写已取得股东权。本任务可形成发送前通知，不执行发送，不补造回证。已读不等于送达。需要登记的事项只列接口，不代提交。

下一步只转介：`评估优先购买权是否成立`、`准备股东名册与工商变更衔接`、`评估股权代持效力与显名`、`评估股权出质对治理与转让的约束`、`评估出资瑕疵催缴与加速到期`、`评估公司治理与股东关系`。禁止此致某法院。不选定法院。不代提交。

若 if 用户催促「签了就是股东／款到了就过户／未答复就算放弃」，then 该格 `现有依据不支持`，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 再执行清单

每个节点结束后回写：来源、判断、最强反方、是否字段停止。不得跳过转让闸直接给已取得股东权或已变更登记终稿。

若 if 对内对外路径、章程另定、同等条件、三十日起算、名册版本未核验，then 该强制项字段停止，窗口不关。
判断状态只许三值。口头「签了就是股东」不得写成 `ZR#` 已记载。未知不写零。

## 本任务回链纪律

本任务成果是「转让闸与发送前草稿」。本窗不执行发送。不包含：已取得股东权证明、已变更登记、优先购买成立终稿。禁止选边治愈。禁止签署即已取得股东权。禁止付款即已变更登记。禁止指导倒签放弃。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标转让终稿已形成。
风险档 A：倒签放弃声明、伪造签章必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：有限公司股东甲把股权转给股东乙，用户主张「协议一签乙就是股东、款到了就过完户」，并把一笔对外意向写成内部转让以跳过书面通知。转让闸打开或半开。`Q-通`、`Q-登` 不打开为可靠路径。第 6 节不得把已取得股东权、已变更登记写入可执行 `ZR#`；对应格 `现有依据不支持`；仍出名册接口、未缴出资待核、对内对外分列等其他 `ZR#`。不关窗。不执行发送。不代提交。

场景②：用户同时交出公司「其他股东已知悉并放弃」声明与对立股东「从未收到通知」口径，要求选对转让方有利的一版，并指导「放弃日期改成通知发出那天」。命中双方秘密＋倒签放弃声明。第一次整体停止。只交第 1、10 节。不出 `ZR#`。不得问代表哪一方后继续。不以「坚持」为门槛。
