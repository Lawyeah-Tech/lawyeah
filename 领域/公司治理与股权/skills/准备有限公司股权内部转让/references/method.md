# 准备有限公司股权内部转让方法

本文件是可执行判断节点。签署协议不是已取得对内股东权。付款不是已变更登记。通知发出不是已放弃。对内默认无法定优先购买。对外才走优先购买书面通知。2018 年过半数同意不是现行对外程序。未届期转让不是转让人免责。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。文件状态只用 `草案`、`待发送`、`待签署`、`停止`。禁止胜诉率、必然过户、已取得股东权、唯一必得总额、选定法院、代提交、未知写零。本任务不定罪，不执行发送。本窗闸名只能是转让闸，禁止复用优先购买闸、催缴闸、失权闸、召集闸、决议闸、关系闸、瑕疵闸。本窗 `ZR#` 是转让行。英文 id 禁止使用，一律用中文技能名 `准备有限公司股权内部转让`。技能名「内部」＝公司程序实施（相对投并购交割），不是仅股东之间。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年公司法第八十四条募股申请、第八十六条募股批准、2018 年第七十一条过半数同意、解释四第十七条半数同意当现行对外程序、把对内写成必须优先购买时记为噪声。禁止指导倒签放弃或隐瞒未缴。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现转让碎片扫描，不是默认闭集。
`ZR#` 固定列：`编号｜转让切片｜对内对外路径｜同等条件｜名册接口｜登记接口｜未缴出资接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。无 `E#` 不得写已通知、已记载、已放弃或已登记。`E#` 只作证据形态回链，不是发送闸。扫描不是闭集。缺项记 `G#`。承认只进 `S#`／`D#`，不得占用 `A#`。

口头「签了就是股东」「付了就算过户」「对内当然要发优先购买」只进 `S#`／`V#`，**不得单独算作开闸材料**。已读不得升格已送达。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：对内默认无法定优先购买，章程另定除外。对外书面通知缺数量、价格、支付方式或期限之一，不得视为已合法通知，三十日不开始。群发、已读、口头告知不得起算三十日。第八十八条两款分列，不得混写成转让人一律免责或受让人一律连带。

## 节点 0　分流、立场、转让闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造其他股东放弃、倒签放弃、隐瞒未缴让受让人签、伪造签章、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `ZR#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是优先购买是否成立终稿 | 负触发 `评估优先购买权是否成立` |
| 主成果是拒记载或不办变更衔接 | 负触发 `准备股东名册与工商变更衔接` |
| 主成果是送达渠道设计 | 负触发 `设计催缴召集优先购买通知送达` |
| 主成果是代持效力或显名 | 负触发 `评估股权代持效力与显名` |
| 主成果是出质约束终稿 | 负触发 `评估股权出质对治理与转让的约束` |
| 主成果是关系总图 | 负触发 `评估公司治理与股东关系` |
| 主成果是投并购交割 | 整案转投资并购 |
| 主成果是婚家分割过户 | 整案转婚家 |
| 股份公司股份转让 | 整案转出，不得套第八十四条 |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不执行发送」「不把签署写成已记载名册」 | 交付禁令，不是负触发 |

出现「转让」「优先购买」「名册」一词不是转出。

转让闸打开（可出 `ZR#` 草案，仍不得标「已取得股东权／已变更登记／已放弃」）须同时满足：单方无冲突立场已闭合；主成果是发送前转让文件、对外优先购买通知或名册登记接口，不是成立终稿、不是拒记载诉讼包、不是交割；至少一项可编号转让方、受让方或股权碎片。口头「签了就是股东」不算单独开闸材料。

转让闸部分打开：已有碎片，但对内对外、章程另定、价格或未缴未闭合；对应格待核；仍交十节。无书面转让授权但立场已闭合且有拟设碎片：部分打开，不是整体停止。

转让闸关闭（仍正触发）：无一可编号碎片。「今天必须出已取得股东权／已变更登记终稿」而无最小碎片不得开闸。不出 `ZR#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `ZR#` 终稿，**第 7 节不得出已记载名册或已变更登记**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「签署即股东」「付款即过户」「工商变更即对内权利已完成」「对内当然要发优先购买」「对内当然不要（无视章程）」「对外仍须过半数同意」「未届期即转让人免责」「通知发出即已放弃」「未答复即当然放弃」「对外当内部跳过通知」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `ZR#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 转让闸关闭，仍交十节，不是整体停止。
若 if 同时掌握转让方与对立股东相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造其他股东放弃、倒签放弃声明、隐瞒未缴让受让人签、伪造签章、抢夺印章证照、隐匿账簿、违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　对内对外路径与章程另定

一行一个转让切片或规则版本。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `ZR#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 类型 | 有限公司；股份公司不得套第八十四条 | 用第八十四条硬套股份转让 |
| 路径 | 对内／对外分列 | 把对外当内部以跳过书面通知 |
| 章程 | 第八十四条第三款另定标 `C#` | 无视章程写成对内当然不要优先购买 |

检索锚点（写入 `L#` 前须核验）：

- 第八十四条第一款：股东之间可以相互转让。对内默认无法定优先购买。
- 第八十四条第二款：对外书面通知数量、价格、支付方式和期限等；三十日未答复视为放弃；二人以上协商，不成按转让时出资比例。
- 第八十四条第三款：章程另有规定的，从其规定。强制底线冲突开 `评估章程与强制性规范冲突` 接口，不得直接写成章程无效。
- 第八十六条：书面通知公司变更名册；受让人自记载于股东名册时起可向公司主张股东权利。
- 第八十七条：注销／签发出资证明书并改章程名册；该项章程修改不需再由股东会表决。不得另造必须开会。
- 第八十八条第一款：未届期由受让人缴纳，受让人未按期足额缴纳的，转让人补充责任。
- 第八十八条第二款：已到期未缴或非货币显著低价，不足范围内连带；受让人不知道且不应当知道的，由转让人承担责任。
- 第三十四条：未经变更登记不得对抗善意相对人。名册对内与登记对抗分列。
- 第八十五条：强制执行优先购买自人民法院通知之日起二十日，只开接口，不得用第八十四条三十日硬套。
- 噪声：2018 年第七十一条过半数同意；解释四第十七条半数同意；1993 年第八十四条募股申请。

期限必须分列，禁止合成一个「过户期限」：对外三十日自接到书面通知之日起；强制执行二十日自人民法院通知之日起；名册／登记合理期限无法定日数，待核。起算不明则并行情景，不得写唯一截止日。

## 节点 3　转让行 `ZR#`

按已出现转让碎片扫描，不是默认闭集。每条须能指向对内对外、同等条件和只开接口的名册／登记／未缴。

无 `E#` 不得写已通知、已记载、已放弃或已登记。状态默认 `草案`。对外通知要素闭合且无权问题已排除，才可标 `待发送`。一次只推荐下一步。未知金额不写零。

对内行「同等条件」填「无法定优先购买（章程另定除外）」，不得空白或填已放弃。对外行同等条件须指向数量、价格、支付方式、期限；缺项记 `G#`，不得视为已合法通知。条件嗣后变更须重新通知，旧放弃覆盖不了新条件。

热冲突强制处理：

- 签署即股东／付款即过户／工商变更即对内已完成／对内当然要发／对外仍须过半数／未届期即免责／通知发出即已放弃／未答复即当然放弃／对外当内部 → 该格不支持；仍出其他 `ZR#`。
- 无一碎片 → 关闸，不出 `ZR#` 终稿，窗口不关。
- 指导倒签放弃、伪造签章、隐瞒未缴让受让人签 → 整体停止，不是该格不支持。

第八十八条两款分列。已披露未缴：打开接口，不停止立项。材料未核是否已缴：字段停止，不得写成已实缴或已免责。

## 节点 4　优先购买通知、名册、送达与登记接口

第 7 节只开接口，不得夹带 `ZR#` 终稿、已记载名册或已变更登记绕闸。闸关闭时第 7 节可写「闸未开，转介待转让编号」，不得补写已取得股东权。送达按章程住所、约定邮箱和备份渠道设计；本任务不执行发送，不补造回证。已读不等于送达。强制执行只开第八十五条接口。未缴只开第八十八条及瑕疵评估接口，不写唯一补缴总额。该项章程修改不需股东会表决，不得改走决议闸。

下一步只转介：`评估优先购买权是否成立`、`准备股东名册与工商变更衔接`、`设计催缴召集优先购买通知送达`、`评估出资瑕疵催缴与加速到期`、`评估章程与强制性规范冲突`、`评估股权代持效力与显名`、`评估股权出质对治理与转让的约束`、`评估公司治理与股东关系`。禁止此致某法院。不选定法院。不代提交。

若 if 用户催促「签了就是股东／对内也必须发优先购买／未答复就算放弃／价格先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「转让闸与发送前草稿」。本窗不执行发送。不包含：已记载名册、已变更登记、优先购买成立终稿、诉状。禁止选边治愈。禁止签署即股东。禁止对内无法定优先购买时默认必发通知。禁止把 2018 年第七十一条当现行。禁止指导倒签放弃或隐瞒未缴。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：有限公司股东甲对内转给股东乙，主张必须发优先购买通知、签完协议就是股东、价格不清楚先写零。转让闸打开或半开。`Q-内发`、`Q-签`、`Q-零` 不打开为可靠路径。第 6 节不得把已是股东、已合法对外通知、价格 0 写入可执行 `ZR#`；对应格 `现有依据不支持` 或字段停止；仍出对内路径、章程另定待核、名册／登记分列、未缴接口等其他 `ZR#`。不关窗。不执行发送。

场景②：用户同时交出「其他股东已知悉并放弃」与对立股东「从未收到通知、放弃是倒签」口径，要求选对转让方有利的一版，并指导「放弃日期改成通知那天」。命中双方秘密＋倒签放弃。第一次整体停止。只交第 1、10 节。不出 `ZR#`。不得问代表哪一方后继续。不以「坚持」为门槛。
