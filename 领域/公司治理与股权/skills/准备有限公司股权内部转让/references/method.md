# 转让方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、论坛、期限、金额或文书状态的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然无效、必然失权、必然解散或唯一必得总额。

`search_law` 返回已失效《合同法》、1993／2004／2013／2018《公司法》或仍引用旧第二十二条、第三十三条、第七十一条且未核验对应关系的司法解释时，记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 以股权或资产收购、投资交割、尽调闭环为主要目标 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果、员工激励的劳动身份 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂、综合合规体系 | 企业合规领域 |
| 破产申请、重整计划、破产债权申报与分配 | 破产领域 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 合伙企业、个人独资的入伙退伙 | 非公司主体，不在本领域 |
| 上市公司发行、持续信息披露或证券监管主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

混合信号：公司组织或股东关系主轴可留本任务；专项只作为背景时在缺口标明，不把专项规则硬套进本领域结论。

## 节点 1　交易性质与章程

1. 主目标是投资并购交割、对赌或交割清单：整案转出投资并购。
2. 主目标是夫妻共同财产或继承分割：整案转出婚家。
3. 核验第八十四条：股东之间可以相互转让；对外转让受优先购买约束，章程另有规定的从其规定。章程禁止转让或设定法定以外同意权的，标强制规范冲突待核。
4. 股份公司适用不同规则，不得用第八十四条硬套。

---

## 节点 2　优先购买程序

1. 对外转让书面通知必须包含数量、价格、支付方式和期限等同等条件要素。要素缺失不得视为已合法通知。
2. 其他股东自接到书面通知之日起三十日内未答复的，视为放弃优先购买权。起算日不明则并行情景。
3. 两个以上股东主张优先购买：先协商比例，协商不成按转让时各自出资比例。
4. 本任务可形成发送前通知，不执行发送。倒签“已知悉并放弃”：整体停止。

---

## 节点 3　未缴出资与第八十八条

1. 转让已认缴未届期股权：受让人承担缴纳义务；受让人未按期足额缴纳的，转让人承担补充责任。
2. 未按期缴纳或非货币显著低价的股东转让：转让人与受让人在不足范围内连带；受让人不知道且不应当知道的，由转让人承担责任。
3. 时间效力核验法释〔2024〕7 号。不得向受让人隐瞒未缴事实。

---

## 节点 4　名册、权利起算和登记

1. 转让人应书面通知公司请求变更名册；需要变更登记的，请求公司办理。公司拒绝或合理期限不答复，转让人、受让人可诉讼。核验第八十六条。
2. 受让人自记载于股东名册时起可向公司主张股东权利。仅签署转让协议或仅付款，不得写成已经取得对内股东权。
3. 登记对抗善意第三人，与名册对内效力分列。

---

## 节点 5　文件状态

转让协议、通知、放弃声明、名册记载申请、登记材料分列版本。状态只用 `草案`、`待发送`、`待签署`、`停止`。不代提交登记。C 端股权转让包只分流，不把本任务降成过户清单。
