# 边界与路由

## 正触发

有限公司股东之间转让需要发送前协议草稿和名册登记接口。从零、碎片、章程未核验、无书面转让授权仍正触发：有转让方、受让方或股权则闸开或半开，出 `ZR#` 草案，保持草案。本次不执行发送是交付禁令，不是开窗条件。签署即已取得股东权、付款即已变更登记、把对外当内部，仍正触发。股东之间无优先购买争议仍正触发，因名册和未缴出资仍需处理。

双方秘密、倒签放弃声明、伪造其他股东签章、伪造决议、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「签署即已取得股东权」「付款即已变更登记」「通知即已放弃」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 优先购买是否成立终稿 | `评估优先购买权是否成立` |
| 名册与工商变更终稿 | `准备股东名册与工商变更衔接` |
| 代持效力或显名 | `评估股权代持效力与显名` |
| 出质对转让的约束终稿 | `评估股权出质对治理与转让的约束` |
| 公司治理与股东关系总图 | `评估公司治理与股东关系` |
| 未缴出资责任精算 | `评估出资瑕疵催缴与加速到期` |
| 投并购交割 | 投资并购领域 |
| 婚家分割过户 | 婚家领域 |
| 股份公司股份转让 | 证券／股份规则 |
| 合伙或个人独资 | 非公司主体 |

不得因「不执行发送」或「不把签署写成已记载名册」关窗。拟股东之间转让草稿仍正触发，不得写成已取得股东权或已变更登记。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |
| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「转让」「优先购买」「名册」一词不是转出。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 只要优先购买是否成立 | `评估优先购买权是否成立` |
| 只要名册工商变更终稿 | `准备股东名册与工商变更衔接` |
| 只要代持显名 | `评估股权代持效力与显名` |
| 只要出质约束 | `评估股权出质对治理与转让的约束` |
| 只要未缴出资责任 | `评估出资瑕疵催缴与加速到期` |

## 易混

签署协议不是已取得对内股东权。付款不是已变更登记。通知发出不是优先购买已放弃。未答复不是当然放弃。把对外转让当内部转让禁止。股份公司不得套第八十四条。解释四第十七条半数同意不是 2024 年后现行对外程序。未经登记不得对抗善意相对人，不得把 2018 年第三十二条当现行条。本窗 `ZR#` 不是召集窗 `ZJ#`，不是效力窗 `XL#`，不是关系窗 `GX#`。「放弃日期改成通知那天」整体停止。本窗不执行发送，不代提交。不选定法院。
