# 边界与路由

## 正触发

有限公司股权拟对内或对外转让，需要发送前转让文件、对外优先购买通知和／或名册登记接口。从零、碎片、章程未核验、无书面转让授权仍正触发：有转让方、受让方或股权碎片则闸开或半开，出 `ZR#` 草案，保持草案。本次不执行发送是交付禁令，不是开窗条件。签署即股东、对内当然要发优先购买、对外仍须过半数同意，仍正触发。对内无优先购买争议时仍正触发，因名册和未缴出资仍需处理。

双方秘密、伪造其他股东放弃、倒签放弃、隐瞒未缴让受让人签、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「签署即股东」「付款即过户」「对内当然要发优先购买」「对外仍须过半数同意」「未答复即当然放弃」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 优先购买是否成立终稿 | `评估优先购买权是否成立` |
| 公司拒记载或不办变更衔接 | `准备股东名册与工商变更衔接` |
| 只要送达渠道设计 | `设计催缴召集优先购买通知送达` |
| 代持效力或显名 | `评估股权代持效力与显名` |
| 出质对转让的约束终稿 | `评估股权出质对治理与转让的约束` |
| 公司治理与股东关系总图 | `评估公司治理与股东关系` |
| 投并购交割、尽调闭环 | 投资并购领域 |
| 离婚或继承分割过户 | 婚家领域 |
| 股份公司股份转让或上市流通 | 不得套第八十四条 |
| 合伙或个人独资 | 非公司主体 |

不得因「不执行发送」或「不把签署写成已记载名册」关窗。拟转让实施草稿仍正触发，不得写成已取得股东权或已放弃。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |
| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |
| 股份公司股份转让 | 不得套第八十四条 |

出现「转让」「优先购买」「名册」一词不是转出。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 只要优先购买是否成立 | `评估优先购买权是否成立` |
| 只要拒记载衔接 | `准备股东名册与工商变更衔接` |
| 只要送达设计 | `设计催缴召集优先购买通知送达` |
| 未缴或瑕疵出资 | `评估出资瑕疵催缴与加速到期` |
| 章程另定与强制规范冲突 | `评估章程与强制性规范冲突` |
| 强制执行优先购买 | 第八十五条二十日只开接口 |

## 易混

签署协议不是已取得对内股东权。付款不是已变更登记。工商变更不是对内权利已完成。对内默认无法定优先购买。对外不再要求其他股东过半数同意。通知发出不是已放弃。未答复不是当然放弃（起算不明则并行情景）。未届期转让不是转让人免责。第八十七条该项章程修改不需股东会表决。本窗 `ZR#` 不是召集窗 `ZJ#`，不是效力窗 `XL#`，不是关系窗 `GX#`。「放弃日期改成通知那天」整体停止。本窗不执行发送，不代提交。不选定法院。
