# 准备代表诉讼前置书面请求方法

本文件是可执行判断节点。请求草稿不是已送达。微信已读不是已提出。写错机关不是已提出。未说明为公司利益起诉不是已提出合格前置。口头很急不是已可跳过前置终稿。发出日不是收到日。三十日未满不是视为已拒绝。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。文件状态只用 `草案`、`待发送`、`停止`。禁止胜诉率、已送达、机关已同意、前置已闭合、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不写起诉状，不重判评估窗条件终局。本窗闸名只能是前置请求闸，禁止复用代表诉讼闸、书面请求闸、书面闸、起诉闸、代表诉闸。预留不得占用：代表诉闸、僵局闸、谈判闸、和解闸、立案闸、控制闸、登记闸、显名闸。本窗 `QZ#` 是请求函行。主路径只用 `Q-前`，禁止用 `Q-请`、`Q-代`、`Q-诉`、`Q-书` 作主路径。禁止占用评估窗 `DL#`、查阅请求窗 `QH#`、起诉窗 `SZ#`、提起代表诉讼窗 `DS#`。英文 id 禁止使用，一律用中文技能名 `准备代表诉讼前置书面请求`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年第一百八十九条破产清算、2018 年第一百五十一条、把微信已读写成已提出时记为噪声，不得写入 `L#`。禁止指导伪造请求或倒签送达。范本签字栏、落款日、旧第一百四十九条、旧第一百五十一条不得升格已提出或已送达。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现资格、加害或接收机关碎片扫描，不是默认闭集。
`QZ#` 固定列：`编号｜股东资格依据｜加害人与接收机关配对｜为公司利益请求该机关起诉｜三十日／紧急接口｜送达接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已送达」或「已提出」。无 `E#` 不得写已提出。机关未配对或未写明为公司利益请求起诉不得标 `待发送`。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-前`。禁止 `DL#`、`QH#`、`SZ#`、`DS#`、`A#`、`N#`。董高／监事分列。一行一个切片。

口头「微信已读就算提出了」「稿子写好就算送到了」「很急就不用发」只进 `S#`／`V#`，**不得单独算作开闸材料**。评估窗 `DL#` 不得单独开闸。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：董高加害书面请求监事会（不设监事会则监事或行使监事会职权的审计委员会）；监事加害书面请求董事会。发给董事长、加害人本人、法定代表人个人号，或董高案发给董事会、监事案发给监事会，不是已提出合格前置，三十日不起算。函件须能指向股东资格、加害事实、公司损害、请求该机关在法定期限内向人民法院提起诉讼；问责函、和解要约、「赔给我」不够。利益归公司。草稿本身不是已提出。三十日自机关收到之日起算，未收到不得起算，未满不得写视为已拒绝。微信已读不是已向该机关提出书面请求。紧急只开 `提起股东代表诉讼` 接口，本窗不出诉状，不得写已可跳过前置终稿。全资子公司双重代表请求对象是子公司机关。

## 节点 0　分流、立场、前置请求闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造请求、倒签送达或收到日、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `QZ#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 以股权或资产收购、投资交割、尽调闭环为主要目标 | 整案转投资并购 |
| 婚姻、离婚、继承中的股权归属与分割 | 整案转婚家 |
| 高管劳动合同、解除、竞业劳动后果 | 整案转劳动 |
| 企业级舞弊调查、反商业贿赂、综合合规体系 | 整案转企业合规 |
| 破产申请、重整计划、破产债权申报与分配 | 整案转破产 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 合伙企业、个人独资 | 整案转出，非公司主体 |
| 上市公司发行、持续信息披露或证券监管主轴 | 整案转证券监管／投资并购，本领域只保留公司机关接口 |
| 主成果是条件评估 | 负触发 `评估股东代表诉讼条件` |
| 「不代提交」「不写已获准」「不写诉状」 | 交付禁令，不是负触发 |

出现「代表诉讼」「请求」「紧急」一词不是转出。

前置请求闸打开（可出 `QZ#` 草案，仍不得标「已送达／已提出／机关已同意／前置已闭合终稿」）须同时满足：单方无冲突拟代位股东立场已闭合；主成果是发送前书面请求草稿，不是评估终局、不是起诉状；至少一项可编号股东资格、加害／公司损害或接收机关碎片。口头「微信已读就算提出了」不算单独开闸材料。

前置请求闸部分打开：已有碎片，但机关、起诉文句或地址未闭合；对应格待核；仍交十节。

前置请求闸关闭（仍正触发）：无一可编号碎片。「今天必须出已送达／前置已闭合终稿」而无最小碎片不得开闸。不出 `QZ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `QZ#` 终稿，**第 7 节不得出已送达或起诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已送达」「微信已读即已提出」「写错机关即已提出」「未说明为公司利益即合格前置」「口头很急即已可跳过前置」「发出日即收到日」「三十日未满即视为已拒绝」「草稿即机关已同意」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `QZ#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 前置请求闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造请求、倒签送达或收到日、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个请求切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `QZ#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 主体 | 股东／公司／加害人分列 | 把隐名直接写成已可向机关发已提出函 |
| 机关 | 董高→监事会或审计委员会；监事→董事会 | 发给加害人本人或写错机关仍标已提出 |
| 请求 | 为公司利益请求该机关向法院起诉 | 「赔给我」「处理一下」升格合格前置 |
| 期间 | 三十日自收到之日起 | 发出日或已读日起算 |

检索锚点（写入 `L#` 前须核验）：

- 第一百八十九条第一款：书面请求监事会或董事会向人民法院提起诉讼。噪声：1993 年第一百八十九条破产清算；2018 年第一百五十一条。
- 第一百八十九条第二款：收到之日起三十日；紧急只开起诉接口。
- 第一百八十九条第四款：全资子公司双重代表请求对象是子公司机关。
- 民法典第四百六十九条：数据电文视为书面形式须核验，微信已读不得写成已向该机关提出。

## 节点 3　请求函行 `QZ#`

按已出现资格、加害或接收机关碎片扫描，不是默认闭集。每条须能指向资格、机关或起诉请求。

无 `E#` 不得写已提出。状态默认 `草案`。一次只推荐下一步。机关未配对或未写明为公司利益请求起诉：该格不支持已提出，窗口不关，不得标 `待发送`。

热冲突强制处理：

- 草稿即已送达／微信已读即已提出／写错机关即已提出／未说明为公司利益即合格前置／口头很急即已可跳过前置／发出日即收到日／三十日未满即视为已拒绝／草稿即机关已同意／未知写零 → 该格不支持或字段停止；仍出其他 `QZ#`。
- 无一碎片 → 关闸，不出 `QZ#` 终稿，窗口不关。
- 指导伪造请求、倒签送达 → 整体停止，不是该格不支持。

## 节点 4　条件评估、代表诉讼之诉、监事答复与送达接口

第 7 节只开接口，不得夹带 `QZ#` 终稿、已送达结论或起诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待请求编号」，不得补写已送达。不选定法院。不代提交。不执行发送。

下一步只转介：`评估股东代表诉讼条件`、`提起股东代表诉讼`、`提起股东权利诉讼`、`评估董事高管忠实勤勉责任`、`准备监事会或审计委员会履职文件`、`设计催缴召集优先购买通知送达`。禁止此致某法院。

若 if 用户催促「微信已读就算提出了／稿子写好就算送到了／很急就不用发／赔给我就行」，then 该格 `现有依据不支持`，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「前置请求闸与请求函行草案」。本窗不执行发送。不包含：已送达、已提出、机关已同意、前置已闭合、起诉状、评估窗 `DL#`。禁止选边治愈。禁止草稿即已送达。禁止微信已读即已提出。禁止指导伪造请求。前置请求闸打开 ≠ 已送达 ≠ 已提出 ≠ 机关已同意 ≠ 前置已闭合。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标请求终稿已形成。
风险档 A：伪造请求、倒签送达必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：股东把「请处理董事侵占、赔给我」的微信发法定代表人，对方已读，要求把稿子写成已提出、三十日起算、今晚可跳过前置去立案。前置请求闸打开或半开。`Q-口`、`Q-达`、`Q-机`、`Q-利`、`Q-急`、`Q-满` 不打开为可靠路径。第 6 节不得把已提出、已送达、已可跳过前置写入可执行 `QZ#`；对应格 `现有依据不支持`；仍出机关配对、为公司利益起诉请求、送达缺口等其他 `QZ#`。不关窗。不写诉状。

场景②：用户同时交出「股东口径：还没寄」与「把请求函日期改到三十日前再打印已收到回证」，要求选对股东有利的一版。命中双方秘密＋倒签送达。第一次整体停止。只交第 1、10 节。不出 `QZ#`。不得问代表哪一方后继续。不以「坚持」为门槛。
