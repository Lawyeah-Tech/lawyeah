# 边界与路由

## 正触发

已支持先请求监事会或董事会起诉，需要发送前书面请求。从零、碎片、机关未核验、无书面评估授权仍正触发：有可编号股东资格、加害／公司损害或接收机关碎片则闸开或半开，出 `QZ#` 草案，保持草案。本次不代提交、不写已获准、不写诉状是交付禁令，不是开窗条件。草稿即已送达、微信已读即已提出、写错机关即已提出，仍正触发。

双方秘密、伪造请求、倒签送达或收到日、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「草稿即已送达」「微信已读即已提出」「写错机关即已提出」「未说明为公司利益即合格前置」「口头很急即已可跳过前置」「发出日即收到日」「三十日未满即视为已拒绝」「草稿即机关已同意」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 条件评估 | `评估股东代表诉讼条件` |
| 可提交代表诉讼起诉状 | `提起股东代表诉讼` |
| 股东直接损害诉讼 | `提起股东权利诉讼` |
| 监事会答复文件 | `准备监事会或审计委员会履职文件` |
| 送达设计独占 | `设计催缴召集优先购买通知送达` |
| 忠实勤勉实体终局 | `评估董事高管忠实勤勉责任` |
| 合伙或个人独资 | 非公司主体 |

不得因「不代提交」「不写已获准」或「不写诉状」关窗。已决定发前置函、要书面请求仍正触发，不得写成已送达或已提出。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露或证券监管主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「代表诉讼」「请求」「紧急」一词不是转出。

## 易混

本窗闸名只能是前置请求闸，不是评估窗代表诉讼闸，不是查阅准备窗书面请求闸，不是书面一致同意的书面闸。`QZ#` 不是评估窗 `DL#`，不是查阅请求窗 `QH#`，不是起诉窗 `SZ#`。主路径是 `Q-前`，不是查阅窗 `Q-请`，不是评估窗 `Q-代`，不是起诉 `Q-诉`。请求草稿不是已送达。微信已读不是已提出。写错机关不是已提出。未说明为公司利益起诉不是已提出合格前置。口头很急不是已可跳过前置终稿。1993 年第一百八十九条不是现行前置请求条。2018 年第一百五十一条不是 2024 年 7 月 1 日后的现行条号。范本旧第一百四十九条、第一百五十一条不得升格已提出。「请求函日期改到三十日前」整体停止。本窗不执行发送，不代提交。不选定法院。不写起诉状。
