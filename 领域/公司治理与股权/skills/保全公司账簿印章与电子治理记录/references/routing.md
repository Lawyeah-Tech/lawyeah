# 边界与路由

## 正触发

账簿、凭证、决议、邮箱、网盘或印章可能灭失，需要合法自固、公证分流或保全接口。从零、碎片、持有范围未核验仍正触发：有可编号对象或持有范围碎片则闸开或半开，出 `FC#` 草案，保持草案。本次不代提交、不写已封存、不指导抢夺是交付禁令，不是开窗条件。复制即已封存、哈希即已公证、申请即已准许、对方控制即内容有利，仍正触发。

双方秘密、抢夺、隐匿、破解、侵入、伪造倒签、违法取证的停止，优先于负触发。上述信号不在下表。抢夺不是负触发。「复制即已封存」「哈希即已公证」「申请即已准许」「对方控制即内容有利」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 证照印章交接包 | `准备证照印章管控与交接` |
| 法院财产、行为或证据保全申请书终稿 | `准备股权或公司财产保全` |
| 证据案卷矩阵 | `建立公司治理与股东争议证据案卷` |
| 查阅书面请求 | `准备查阅复制书面请求` |
| 查阅权评估 | `评估股东知情查阅权` |
| 已作出保全之应对 | `应对股权冻结或行为保全` |
| 控制权争夺路径 | `评估控制权争夺与表决权约束` |
| 合伙或个人独资 | 非公司主体 |

不得因「不代提交」「不写已封存」或「不指导抢夺」关窗。拟封存草稿仍正触发，不得写成已封存或已裁定。

## 易混

本窗闸名只能是封存闸，不是保全闸，不是印章闸，不是案卷闸。`FC#` 不是印章窗 `YZ#`，不是案卷窗 `AJ#`。主路径是 `Q-账`，不是 `Q-保`，不是 `Q-印`。复制不是已封存。哈希不是已公证。申请不是已裁定。对方控制不是内容有利。占有不是合法封存。公司法第五十七条不是抢簿权源。1991 年民事诉讼法第一百零三条不是现行行为保全条。「今晚去财务室把账本搬出来」「邮箱密码先破解」整体停止。本窗不执行发送，不代提交。不选定法院。不保证裁定。
