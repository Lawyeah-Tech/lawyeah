# 边界与路由

## 正触发

已有分配决议不执行，或已决定提起分配之诉。从零、碎片、方案未核验、无书面评估授权仍正触发：有可编号资格、决议或未支付碎片则闸开或半开，出 `FS#` 草案，保持草案。本次不代提交、不定法院、不写唯一必得总额是交付禁令，不是开窗条件。草稿即已立案、无具体方案即强制分配起诉终稿，仍正触发。无决议不是关窗。

双方秘密、伪造分配决议、倒签分配或起诉、虚假诉讼、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「草稿即已立案」「无具体方案即强制分配起诉终稿」「有利润即强制分起诉」「认缴即分配比例」「六个月即请求已成立」「滥权默认打开」「选定某院」「网交即已提交」不在下表。无决议、仲裁未核不进负表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 分配条件评估 | `评估利润分配请求权` |
| 分项测算 | `测算利润分配与股权回购对价` |
| 五年盈利不分回购路径 | `评估异议股东回购请求` |
| 概括股东诉讼 | `提起股东权利诉讼` |

不得因「不代提交」或「不定法院」关窗。已决定分配之诉仍正触发，不得写成已立案或已可强制分配起诉终稿。

## 易混

本窗闸名只能是分配诉闸，不是分配闸，不是测算闸，不是起诉闸。`FS#` 不是评估窗 `FP#`，不是测算窗 `DJ#`，不是起诉窗 `SZ#`。主路径是 `Q-给`，不是 `Q-分`，不是 `Q-代`。诉状草稿不是已立案。无具体方案决议不是已可强制分配起诉终稿。被告原则上是公司。六个月是执行期不是诉讼时效。1993 年第二百一十条不是现行分配起诉条。解释四第十五条滥权例外不是默认打开的起诉主路径。五年盈利不分走异议回购，不写成分配之诉终稿。「起诉状日期改到六个月前」整体停止。本窗不执行发送，不代提交。不选定法院。不写唯一必得总额。
