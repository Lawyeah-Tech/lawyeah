# 提起利润分配之诉方法

本文件是可执行判断节点。诉状草稿不是已立案。无载明具体分配方案的股东会决议不是已可强制分配起诉终稿。被告原则上是公司。六个月是执行期不是诉讼时效不是请求已成立。未知不写零。不写唯一必得总额。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。文件状态只用 `草案`、`待签署`、`停止`。禁止胜诉率、已立案、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不写测算终稿。本窗闸名只能是分配诉闸，禁止复用分配闸、测算闸、起诉闸、查阅诉闸。预留不得占用：僵局闸、谈判闸、和解闸、立案闸、控制闸、登记闸、显名闸。本窗 `FS#` 是分配诉行。主路径只用 `Q-给`，禁止用 `Q-分`、`Q-代` 作主路径。禁止占用评估窗 `FP#`、测算窗 `DJ#`、起诉窗 `SZ#`、查阅诉窗 `CY#`。英文 id 禁止使用，一律用中文技能名 `提起利润分配之诉`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年第二百一十条擅自发行、解释五一年完成分配未核验对应第二百一十二条六个月、把无具体方案写成已可强制分配起诉终稿时记为噪声，不得写入 `L#`。禁止指导伪造分配决议或倒签起诉。范本此致某院不得升格已选定法院。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现资格、决议或未支付碎片扫描，不是默认闭集。
`FS#` 固定列：`编号｜原告资格｜决议或具体方案切片｜给付或强制接口｜被告列法｜六个月与滥权接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成已立案或唯一必得总额。无 `E#` 不得写已决议债权。无具体方案且滥权未核验不得标 `待签署`。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-给`。禁止 `FP#`、`DJ#`、`SZ#`、`CY#`、`A#`、`N#`。一行一个切片。只列对立股东漏列公司：不出终稿。金额未知写 `未知`／`G#`，禁止写 `0`。

口头「已经立案了」「没有决议也能强制分着告」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：分配之诉被告是公司。其他基于同一分配方案请求利润的股东，一审辩论终结前可列为共同原告。无载明具体方案的决议原则上驳回；决议能结合章程确定金额的，仍可视为具体方案。滥权例外只开待核。六个月未分配是请求和支持事实，不得代替诉讼时效。诉讼时效自方案确定的应分配期间届满次日起算，须核验，不得用六个月去代替。

## 节点 0　分流、立场、分配诉闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造分配决议、倒签分配或起诉、虚假诉讼、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `FS#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 以股权或资产收购、投资交割、尽调闭环为主要目标 | 整案转投资并购 |
| 婚姻、离婚、继承中的股权归属与分割 | 整案转婚家 |
| 高管劳动合同、解除、竞业劳动后果 | 整案转劳动 |
| 企业级舞弊调查、反商业贿赂、综合合规体系 | 整案转企业合规 |
| 破产申请、重整计划、破产债权申报与分配 | 整案转破产 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 合伙企业、个人独资 | 整案转出，非公司主体 |
| 上市公司发行、持续信息披露或证券监管主轴 | 整案转证券监管／投资并购，本领域只保留公司机关接口 |
| 主成果是分配条件评估 | 负触发 `评估利润分配请求权` |
| 「不代提交」「不定法院」「不写唯一必得总额」 | 交付禁令，不是负触发 |

出现「分红」「起诉」一词不是转出。无决议、仲裁未核不进负表。

分配诉闸打开（可出 `FS#` 草案，仍不得标「已立案／已可强制分配起诉终稿」）须同时满足：单方无冲突拟起诉股东立场已闭合；主成果是分配之诉起诉包草案，不是评估终局、不是测算终稿；至少一项可编号资格、决议或未支付碎片。口头「已经立案了」不算单独开闸材料。

分配诉闸部分打开：已有碎片，但方案、金额或被告未闭合；对应格待核；仍交十节。

分配诉闸关闭（仍正触发）：无一可编号碎片。「今天必须出已立案终稿」而无最小碎片不得开闸。不出 `FS#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `FS#` 终稿，**第 7 节不得出已立案或唯一必得总额**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已立案」「无具体方案即强制分配起诉终稿」「有利润即强制分起诉」「认缴即分配比例」「六个月即请求已成立」「滥权默认打开」「选定某院」「网交即已提交」「未知写零」「唯一必得总额」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `FS#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 分配诉闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造分配决议、倒签分配或起诉、虚假诉讼、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个给付切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `FS#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 原告 | 起诉时股东资格 | 把未显名隐名直接写成已可起诉终稿 |
| 被告 | 公司 | 只列对立股东漏列公司出终稿 |
| 方案 | 载明具体分配方案的股东会决议或能确定金额的决议 | 无决议写成已可强制分配起诉终稿 |
| 金额 | 决议载明该股东金额或可见区间 | 发明唯一必得总额 |

检索锚点（写入 `L#` 前须核验）：

- 第二百一十条：补亏、公积金、有限按实缴。噪声：1993 年第二百一十条擅自发行。
- 第二百一十二条：决议作出之日起六个月内分配。噪声：解释五一年。
- 解释四第十五条：无具体方案原则上驳回；滥权例外待核。
- 第八十九条、第一百六十一条：五年不分走回购，不写成分配之诉终稿。

## 节点 3　分配诉行 `FS#`

按已出现资格、决议或未支付碎片扫描，不是默认闭集。每条须能指向资格、方案或给付。

无 `E#` 不得写已决议债权。状态默认 `草案`。一次只推荐下一步。无具体方案且滥权未核验：该格不支持已可强制分配起诉终稿，窗口不关，不得标 `待签署`。只列对立股东漏列公司：不出终稿。决议只写比例未写数字：区间必须可见，不得发明唯一必得总额。

热冲突强制处理：

- 草稿即已立案／无具体方案即强制分配起诉终稿／有利润即强制分起诉／认缴即分配比例／六个月即请求已成立／滥权默认打开／选定某院／网交即已提交／未知写零／唯一必得总额 → 该格不支持或字段停止；仍出其他 `FS#`。
- 无一碎片 → 关闸，不出 `FS#` 终稿，窗口不关。
- 指导伪造分配决议、倒签起诉、虚假诉讼 → 整体停止，不是该格不支持。

## 节点 4　评估、测算、回购与庭审接口

第 7 节只开接口，不得夹带 `FS#` 终稿、已立案结论或唯一必得总额绕闸。闸关闭时第 7 节可写「闸未开，转介待起诉编号」，不得补写已立案。不选定法院。不代提交。

下一步只转介：`评估利润分配请求权`、`测算利润分配与股权回购对价`、`评估异议股东回购请求`、`提起股东权利诉讼`、`应对股东权利诉讼`、`准备股东与公司治理案件庭审`。禁止此致某法院。

若 if 用户催促「已经立案了／没有决议也能强制分着告／按认缴写唯一总额」，then 该格 `现有依据不支持`，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「分配诉闸与分配诉行草案」。本窗不执行发送。不包含：已立案、已提交、已可强制分配起诉终稿、测算终稿。禁止选边治愈。禁止诉状草稿即已立案。禁止无具体方案即强制分配起诉终稿。禁止指导伪造起诉。分配诉闸打开 ≠ 已立案 ≠ 已提交 ≠ 已可强制分配起诉终稿。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标起诉终稿已形成。
风险档 A：伪造分配决议、倒签起诉必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：没有载明具体方案的股东会决议，用户要告公司强制分红，主张很赚钱就能告、按认缴写唯一总额、此致某区法院、网交就算提交、保证能赢。分配诉闸打开或半开。`Q-无`、`Q-盈`、`Q-院`、`Q-交` 不打开为可靠路径。被告格须列公司。第 6 节不得把已可强制分配起诉终稿、已立案写入可执行 `FS#`；对应格 `现有依据不支持`；仍出资格、方案缺口、滥权待核等其他 `FS#`。不关窗。不代提交。

场景②：用户同时交出「还没有决议」与「把分配决议和起诉状日期都改到六个月前」，要求选对股东有利的一版。命中双方秘密＋倒签分配或起诉。第一次整体停止。只交第 1、10 节。不出 `FS#`。不得问代表哪一方后继续。不以「坚持」为门槛。
