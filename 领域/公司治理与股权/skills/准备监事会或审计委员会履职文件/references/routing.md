# 边界与路由

## 正触发

需要监事会、一名监事或审计委员会检查、质询、召集股东会接口或答复代表诉讼前置请求，并形成发送前草稿。从零、碎片、三十日未核验、无书面履职授权仍正触发：有机关设置或履职议题碎片则闸开或半开，出 `JS#` 草案，保持草案。本次不执行发送、不写诉状是交付禁令，不是开窗条件。未见账簿即已经合规、三十日未满即已违法拒绝，仍正触发。

双方秘密、伪造未设机关开会、倒签检查记录、补签名造已通过、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「未见账簿即已经合规」「三十日未满即已违法拒绝」「两套机关同时已开会」不在下表。未设机关却要求出具监察报告走整体停止，不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 董事责任实体评估终局 | `评估董事高管忠实勤勉责任` |
| 股东会召集通知终稿 | `准备股东会决议与召集` |
| 代表诉讼前置请求 | `准备代表诉讼前置书面请求` |
| 代表诉讼诉状 | `提起股东代表诉讼` |
| 董事会或一名董事决定 | `准备董事会或执行董事决定` |
| 企业级内部调查终稿 | 企业合规领域 |
| 合伙或个人独资 | 非公司主体 |

不得因「不执行发送」或「不写诉状」关窗。拟履职草稿仍正触发，不得写成已经合规。
