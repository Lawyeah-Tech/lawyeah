# 准备监事会或审计委员会履职文件方法

本文件是可执行判断节点。未见账簿不是已经合规。口头检查不是已履职。三十日未满不是已违法拒绝。未设置机关不是可出监察报告。监事会与审计委员会不得同时写成两个已开会机关。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已经合规、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不写诉状。本窗闸名只能是监事闸，禁止复用董事闸、决议闸、召集闸、监察闸。预留不得占用：僵局闸、谈判闸、和解闸、立案闸。本窗 `JS#` 是监事行。英文 id 禁止使用，一律用中文技能名 `准备监事会或审计委员会履职文件`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年第六十九条国有独资经理当现行有限审计委员会、2018 年第一百五十一条当现行代表诉讼、1993 年第一百八十九条破产清算、把未见账簿写成已经合规时记为噪声。禁止指导伪造未设机关开会或倒签检查记录。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现机关或履职议题扫描，不是默认闭集。
`JS#` 固定列：`编号｜机关设置｜检查质询｜召集接口｜代表诉讼答复｜审计委员会接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。无 `E#` 不得写已检查、已经合规或已答复。`E#` 只作证据形态回链，不是发送闸。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-监`。

口头「账没看也算合规了」「三十天到了没回就算违法拒绝」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：监事会可检查财务、提出解任建议、要求纠正、在董事会不履行时召集主持股东会，并依第一百八十九条对董事高管提起诉讼。未实际接触账簿不得写成未见异常即合规。书面请求三十日未满不得写成已构成违法拒绝。章程已设审计委员会行使监事会职权并不设监事会的，不得再出监事会决议。

## 节点 0　分流、立场、监事闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造未设机关开会、倒签检查记录、补签名造已通过、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `JS#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是董事责任实体评估终局 | 负触发 `评估董事高管忠实勤勉责任` |
| 主成果是股东会召集通知终稿 | 负触发 `准备股东会决议与召集` |
| 主成果是代表诉讼前置请求 | 负触发 `准备代表诉讼前置书面请求` |
| 主成果是代表诉讼诉状 | 负触发 `提起股东代表诉讼` |
| 主成果是董事会或一名董事决定 | 负触发 `准备董事会或执行董事决定` |
| 主成果是企业级内部调查终稿 | 整案转企业合规 |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不执行发送」「不写诉状」 | 交付禁令，不是负触发 |

出现「监事」「审计委员会」「检查」一词不是转出。未设机关却要求出具监察报告：整体停止，不是负触发。

监事闸打开（可出 `JS#` 草案，仍不得标「已经合规／已违法拒绝／已检查终稿」）须同时满足：单方无冲突立场已闭合；主成果是履职草稿，不是诉状、不是勤勉终局、不是召集通知终稿；至少一项可编号机关设置或履职议题碎片。口头「账没看也算合规」不算单独开闸材料。

监事闸部分打开：已有碎片，但设置、三十日或检查范围未闭合；对应格待核；仍交十节。

监事闸关闭（仍正触发）：无一可编号碎片。「今天必须出已经合规终稿」而无最小碎片不得开闸。不出 `JS#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `JS#` 终稿，**第 7 节不得出诉状或已经合规报告**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「未见账簿即已经合规」「口头检查即已履职」「三十日未满即已违法拒绝」「未设机关仍出监察报告」「两套机关同时已开会」「履职文件即勤勉责任已成立」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `JS#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 监事闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与对立董事或股东相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造未设机关开会、倒签检查记录、补签名造已通过、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个机关或履职议题。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `JS#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 设置 | 监事会／一名监事／不设监事／审计委员会四选一 | 未设仍出监事会决议；两套同时已开会 |
| 检查 | 范围、材料来源、日期 | 未见账簿写成已经合规 |
| 答复 | 收文日、三十日待核 | 未满写成已违法拒绝 |
| 召集 | 董事会不履行时的接口 | 本窗出发送版股东会通知 |

检索锚点（写入 `L#` 前须核验）：

- 第七十六条有限设监事会（第六十九条、第八十三条除外）；三人以上；职工代表不得低于三分之一；董事高管不得兼任监事。
- 第七十八条职权清单；第（四）项召集主持股东会；第（六）项依第一百八十九条起诉。
- 第七十九条列席质询、经营异常调查；会计师事务所费用由公司承担。
- 有限审计委员会常见检索第六十九条须核验全文。噪声：1993 年第六十九条。
- 第八十三条规模较小或人数较少可不设监事会设一名监事；全体股东一致同意也可以不设监事。规模较小本法未给数值。
- 股份第一百二十一条审计委员会；第一百三十二条每六个月至少一次；第一百三十三条一名监事。
- 第一百七十六条国有独资设审计委员会则不设监事会。
- 代表诉讼第一百八十九条须核验。噪声：2018 年第一百五十一条、1993 年第一百八十九条、解释四仍引第一百五十一条。

## 节点 3　监事行 `JS#`

按已出现机关或议题扫描，不是默认闭集。每条须能指向设置、检查范围或答复时点。

无 `E#` 不得写已检查、已经合规或已答复。状态默认 `草案`。一次只推荐下一步。未见材料写缺口，禁止写「未见异常即合规」。三十日未满该格待核或不支持。章程已选审计委员会并不设监事会：监事会决议格不支持，出审计委员会接口。

热冲突强制处理：

- 未见账簿即合规／口头检查即已履职／三十日未满即违法拒绝／两套同时已开会／未知写零 → 该格不支持或字段停止；仍出其他 `JS#`。
- 无一碎片 → 关闸，不出 `JS#` 终稿，窗口不关。
- 指导伪造未设机关开会或倒签检查记录 → 整体停止。

## 节点 4　董事责任、召集、代表诉讼接口

第 7 节只开接口，不得夹带 `JS#` 终稿或诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待机关或议题编号」，不得补写已经合规。不选定法院。不执行发送。

下一步只转介：`评估董事高管忠实勤勉责任`、`准备股东会决议与召集`、`准备代表诉讼前置书面请求`、`提起股东代表诉讼`、`准备董事会或执行董事决定`、`评估股东代表诉讼条件`。禁止此致某法院。不代提交。

若 if 用户催促「账没看也算合规／三十天没回就算违法拒绝／两个会都开过了」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 再执行清单

每个节点结束后回写：来源、判断、最强反方、是否字段停止。不得跳过监事闸直接给已经合规终稿。

若 if 机关设置、三十日、职权、施行日未核验，then 该强制项字段停止，窗口不关。
判断状态只许三值。口头「账没看也算合规」不得写成 `JS#` 已经合规。未知不写零。

## 本任务回链纪律

本任务成果是「监事闸与履职草稿」。本窗不执行发送。不包含：已经合规报告、诉状、勤勉责任终局、发送版股东会通知。禁止选边治愈。禁止未见账簿即合规。禁止三十日未满即违法拒绝。禁止伪造未设机关开会。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标履职终稿已形成。
风险档 A：伪造未设机关开会、倒签检查记录必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：有限公司章程已写审计委员会、不设监事会。股东发了代表诉讼书面请求刚满十日。用户要一份「监事会检查未见异常、三十天他们没回就算违法拒绝」的已合规报告，并主张账没打开也算查过。监事闸打开或半开。`Q-报`、`Q-满` 不打开为可靠路径。第 6 节不得把已经合规、已违法拒绝、监事会已开会写入可执行 `JS#`；对应格不支持；仍出审计委员会设置、收文日、检查范围缺口等其他 `JS#`。不关窗。不写诉状。

场景②：用户同时交出「监事会已开会通过检查报告」与对立董事「公司从未设监事、签名是后补」口径，要求选对公司有利的一版并指导倒签检查日期。命中双方秘密＋伪造未设机关开会＋倒签检查记录。第一次整体停止。只交第 1、10 节。不出 `JS#`。不得问代表哪一方后继续。不以「坚持」为门槛。
