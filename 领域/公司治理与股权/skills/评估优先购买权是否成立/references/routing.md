# 边界与路由

## 正触发

对外转让未通知或同等条件有争议，需要判断优先购买权是否成立。从零、碎片、通知未核验、无书面评估授权仍正触发：有可编号转让或股东碎片则闸开或半开，出 `YX#` 草案，保持草案。本次不写转让协议终稿、不写合同当然无效是交付禁令，不是开窗条件。对内当然有优先购买、口头即已书面通知、未接到即已放弃、侵害即合同当然无效、仍须过半数同意，仍正触发。对内转让且章程无优先购买：该格不支持，窗口不关，不是负触发。

双方秘密、伪造放弃声明、倒签通知、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「对内当然有优先购买」「口头即已书面通知」「未接到即已放弃」「侵害即合同当然无效」「仍须过半数同意」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 转让协议终稿或交割 | `准备有限公司股权内部转让` 或投并购 |
| 股权结构图 | `梳理股权结构与控制权` |
| 代持显名终局 | `评估股权代持效力与显名` |
| 名册登记衔接包 | `准备股东名册与工商变更衔接` |
| 合伙或个人独资 | 非公司主体 |

不得因「不写转让协议终稿」或「不写合同当然无效」关窗。拟优先购买路径评估仍正触发，不得写成已放弃或合同已无效。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |
| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「优先购买」「对外转让」「三十日」一词不是转出。

## 易混

本窗闸名只能是优先购买闸。`YX#` 不是转让窗 `ZR#`，不是合规根因行 `YG#`。对内转让不是当然有法定优先购买。口头通知不是已完成书面通知。未接到书面通知起算不是三十日已放弃。侵害优先购买不是转让合同当然无效。2018 年第七十一条过半数同意不是现行对外程序。强制执行是第八十五条二十日，不是第八十四条三十日，也不是第八十七条。解释四第十七条征求同意半数不同意不是当然现行程序。股份不得套有限第八十四条。条件变更后旧放弃不是覆盖新条件。「通知日期改到三十日前」整体停止。本窗不执行发送，不代提交。不选定法院。
