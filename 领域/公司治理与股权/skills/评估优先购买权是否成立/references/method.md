# 评估优先购买权是否成立方法

本文件是可执行判断节点。对内转让不是当然有法定优先购买。口头通知不是已完成书面通知。未接到书面通知起算不是三十日已放弃。侵害优先购买不是转让合同当然无效。2018 年第七十一条过半数同意不是现行对外程序。强制执行是第八十五条二十日，不是第八十四条三十日可套。股份不得套有限第八十四条。条件变更后旧放弃不是覆盖新条件。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、合同当然无效、已放弃终稿、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不写转让协议终稿。本窗闸名只能是优先购买闸，禁止复用转让闸、关系闸、评估闸。预留不得占用：僵局闸、谈判闸、和解闸、立案闸。本窗 `YX#` 是优先购买行。禁止占用转让窗 `ZR#`、合规根因行 `YG#`。英文 id 禁止使用，一律用中文技能名 `评估优先购买权是否成立`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 2018 年第七十一条过半数同意当现行第八十四条、解释四第十七条征求同意半数不同意未核验对应现行第八十四条、把强制执行写成第八十七条或套普通三十日、把侵害优先购买写成合同当然无效时记为噪声。禁止指导伪造放弃声明或倒签通知。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现转让或股东扫描，不是默认闭集。
`YX#` 固定列：`编号｜对内对外｜书面通知｜同等条件｜期间与放弃｜章程另定与强制执行接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已放弃」或「合同已无效」。无 `E#` 不得写已书面通知或已到达。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-优`。禁止 `ZR#`、`YG#`、`GX#`、`A#`、`N#`。

口头「群里说过了」「没回就是放弃」「没通知合同就废了」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：现行对外转让不再要求其他股东过半数同意，书面通知同等条件即可。对内股东之间可以相互转让，无法定优先购买，除非章程另定。侵害优先购买通常支持按同等条件购买或赔偿，不支持以侵害为由认定合同无效。未通知不能当然解除已做交易。强制执行期间是法院通知之日起二十日，不是接到书面通知之日起三十日。

## 节点 0　分流、立场、优先购买闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造放弃声明、倒签通知、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `YX#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是转让协议终稿或交割 | 负触发 `准备有限公司股权内部转让` 或投并购 |
| 主成果是股权结构图 | 负触发 `梳理股权结构与控制权` |
| 主成果是代持显名终局 | 负触发 `评估股权代持效力与显名` |
| 主成果是名册登记衔接包 | 负触发 `准备股东名册与工商变更衔接` |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不写转让协议终稿」「不写合同当然无效」 | 交付禁令，不是负触发 |

出现「优先购买」「对外转让」「三十日」一词不是转出。对内转让且章程无优先购买：该格不支持，不是负触发。

优先购买闸打开（可出 `YX#` 草案，仍不得标「已放弃／合同已无效／已过户」）须同时满足：单方无冲突立场已闭合；主成果是优先购买路径评估，不是转让协议终稿；至少一项可编号转让或股东碎片。口头「群里说过了」不算单独开闸材料。

优先购买闸部分打开：已有碎片，但通知要件或期间未闭合；对应格待核；仍交十节。

优先购买闸关闭（仍正触发）：无一可编号碎片。「今天必须出已放弃／合同已无效终稿」而无最小碎片不得开闸。不出 `YX#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `YX#` 终稿，**第 7 节不得出合同已无效或转让终稿**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「对内当然有优先购买」「口头即已书面通知」「未接到即已放弃」「侵害即合同当然无效」「仍须过半数同意」「强制执行套三十日」「股份套第八十四条」「条件变更后旧放弃覆盖新条件」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `YX#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 优先购买闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立股东相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造放弃声明、倒签通知、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个转让切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `YX#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 类型 | 对内／对外／强制执行分列 | 对内当然打开优先购买 |
| 公司 | 有限／股份分列 | 股份套第八十四条 |
| 通知 | 数量、价格、支付方式、期限书面分列 | 口头升格已书面通知 |
| 期间 | 接到书面通知起三十日／法院通知起二十日分列 | 强制执行套普通三十日 |

检索锚点（写入 `L#` 前须核验）：

- 第八十四条第一款：股东之间可以相互转让。对内无法定优先购买，除非章程另定。
- 第八十四条第二款：对外书面通知数量、价格、支付方式和期限；同等条件优先购买；自接到书面通知之日起三十日内未答复视为放弃；两个以上协商，协商不成按转让时出资比例。
- 第八十四条第三款：章程另有规定从其规定。更严或放宽是否突破强制底线转 `评估章程与强制性规范冲突`。
- 噪声：2018 年第七十一条其他股东过半数同意、书面通知征求同意。
- 第八十五条：强制执行通知公司及全体股东；自人民法院通知之日起满二十日不行使视为放弃。不得用第八十四条三十日去套。噪声：stub 写成第八十七条。
- 解释四第十七条仍写征求同意、半数不同意，须核验对应现行第八十四条，不得当现行过半数程序。
- 解释四第十九条：章程未定或通知短于三十日则以三十日为准。
- 解释四第二十条：其他股东主张优先购买后转让股东反悔一般不予支持，章程或全体另有约定除外；合理损失可赔。
- 侵害优先购买不得当然写成合同无效，须核验解释四相应条。

缺任一实质通知要素：通知完整性依据不足，不得写成已完成书面通知。

## 节点 3　优先购买行 `YX#`

按已出现转让切片扫描，不是默认闭集。每条须能指向对内对外、书面通知或期间。

无 `E#` 不得写已书面通知或已到达。状态默认 `草案`。一次只推荐下一步。未知期间不写零，不写唯一截止日。已读、微信群消息不得升格法定书面通知到达。

热冲突强制处理：

- 对内当然有优先购买／口头即已书面通知／未接到即已放弃／侵害即合同当然无效／仍须过半数同意／强制执行套三十日／股份套第八十四条／旧放弃覆盖新条件／未知写零 → 该格不支持或字段停止；仍出其他 `YX#`。
- 无一碎片 → 关闸，不出 `YX#` 终稿，窗口不关。
- 指导伪造放弃声明、倒签通知 → 整体停止，不是该格不支持。

未通知即过户：优先购买权人可主张按同等条件购买或赔偿，核验失败字段停止，不得一律写转让无效。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：股东把股权转给另一名股东，同时还有一笔对外意向。用户主张对内也要优先购买、群里说过就算通知、没回就是放弃、没通知合同无效、还要其他股东过半数同意、拿股份规则套进来、强制执行也按三十日。优先购买闸打开或半开。`Q-内`、`Q-口`、`Q-弃`、`Q-无`、`Q-半`、`Q-股`、`Q-执` 不打开为可靠路径。第 6 节不得把已放弃、合同已无效、已书面通知写入可执行 `YX#`；对应格 `现有依据不支持`；仍出对内对外分列、通知要素缺口、期间起算待核等其他 `YX#`。不关窗。不写转让终稿。

场景②：用户同时交出「其他股东已书面放弃」与对立股东「放弃声明是后补、通知日期倒签」口径，要求选对转让方有利的一版，并指导「把通知日期改到三十日前」。命中双方秘密＋伪造放弃声明＋倒签通知。第一次整体停止。只交第 1、10 节。不出 `YX#`。不得问代表哪一方后继续。不以「坚持」为门槛。
