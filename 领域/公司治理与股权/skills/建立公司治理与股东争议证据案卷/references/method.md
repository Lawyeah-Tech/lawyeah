# 建立公司治理与股东争议证据案卷方法

本文件是可执行判断节点。账簿在对方控制不是推定内容有利。存在诉讼不是不正当目的。微信已读不是已送达。口头转告不是已送达。案卷矩阵不是已可提交诉状。红旗不是保全已完成。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已质证、已可提交、选定法院、代提交、未知写零。本任务不定罪，不写诉状，不指导抢夺。本窗闸名只能是案卷闸，禁止复用保全闸、起诉闸、关系闸、测算闸、转让闸、召集闸。本窗 `AJ#` 是案卷行。英文 id 禁止使用，一律用中文技能名 `建立公司治理与股东争议证据案卷`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年公司法第五十七条董事任职资格、解释四仍引用旧第三十三条未核验对应现行第五十七条、把存在诉讼写成不正当目的时记为噪声。禁止指导抢夺印章或违法取证。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现争点扫描，不是默认闭集。
`AJ#` 固定列：`编号｜待证事实｜材料｜形式｜控制方｜合法性｜缺口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。无 `E#` 不得写已入卷或已送达。`E#` 只作证据形态回链，不是发送闸。扫描不是闭集。缺项记 `G#`。承认只进 `S#`／`D#`，不得占用 `A#`。原件与复制件分列。

口头「已经备份」「微信已读」「先把公章拿回来」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：不正当目的由公司举证；仅凭双方存在诉讼不足以认定不正当目的。资料由第三人占有，公司仍负配合义务，不得据此推定内容有利于用户。

## 节点 0　分流、立场、案卷闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、抢夺印章证照、伪造或倒签决议、隐匿账簿、侵入财务或邮箱、违法调取个人信息、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `AJ#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是关系总图 | 负触发 `评估公司治理与股东关系` |
| 主成果是可提交诉状 | 负触发 `提起股东权利诉讼` |
| 主成果是答辩 | 负触发 `应对股东权利诉讼` |
| 主成果是保全申请终稿 | 负触发 `保全公司账簿印章与电子治理记录` |
| 主成果是查阅书面请求终稿 | 负触发 `准备查阅复制书面请求` |
| 主成果是查阅权评估终稿 | 负触发 `评估股东知情查阅权` |
| 劳动仲裁证据 | 整案转劳动领域 |
| 「不写诉状」「不提供违法取证方案」 | 交付禁令，不是负触发 |

出现「证据」「查阅」「保全」一词不是转出。

案卷闸打开（可出 `AJ#` 草案，仍不得标「已可提交／已质证／已保全」）须同时满足：单方无冲突立场已闭合；主成果是案卷矩阵，不是诉状、不是保全申请终稿、不是关系总图；至少一项可编号待证事实或材料碎片。口头「已经备份」不算单独开闸材料。

案卷闸部分打开：已有碎片，但控制方或合法性未闭合；对应格待核；仍交十节。

案卷闸关闭（仍正触发）：无一可编号碎片。「今天必须出已可提交诉状终稿」而无最小碎片不得开闸。不出 `AJ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `AJ#` 终稿，**第 7 节不得出诉状或保全申请**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「对方控制即推定有利」「存在诉讼即不正当目的」「已读即已送达」「口头转告即已送达」「案卷即诉状」「红旗即保全已完成」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `AJ#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 案卷闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与对立股东相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出抢夺印章证照、伪造或倒签决议、隐匿账簿、侵入财务或邮箱、违法调取个人信息、违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　争点到要件

按用户本次争点选择一条主轴，允许并列，但每条要件独立。本节禁止出 `AJ#` 终稿。

| 主轴 | 必须记录 | 禁止 |
| --- | --- | --- |
| 查阅 | 股东资格、书面请求、目的说明、十五日答复、不正当目的抗辩 | 存在诉讼即不正当目的 |
| 出资 | 认缴、到期或加速、实缴凭证、抽逃情形 | 本窗出失权终稿 |
| 决议 | 形成事实、内容、程序、资格、除斥 | 本窗出效力终稿 |
| 分配／回购 | 财务参数、决议、反对票 | 本窗出唯一必得价 |
| 代表诉讼 | 持股、书面请求、三十日或紧急情形 | 本窗出诉状 |
| 人格否认 | 滥用事实、严重损害、一人公司混同举证接口 | 本窗认定混同已成立 |
| 解散 | 百分之十表决权、严重困难、其他途径不能解决 | 本窗认定必须解散 |

不得用总图代替要件表。

检索锚点（写入 `L#` 前须核验）：

- 有限公司查阅常见检索第五十七条：书面请求、十五日、不正当目的由公司举证。噪声：1993 年第五十七条董事任职资格。
- 股份公司第一百一十条；会计账簿适用第五十七条第二款至第四款。
- 解释四第七条至第十条仍引旧第三十三条、第九十七条，须核验对应现行第五十七条、第一百一十条。
- 解释四第八条不正当目的情形，公司举证。
- 第二十三条第三款一人公司财产独立举证责任；本窗不认定混同已成立。

## 节点 3　案卷行 `AJ#`

按已出现待证事实扫描，不是默认闭集。每条须能指向材料、控制方和合法性。

无 `E#` 不得写已入卷、已送达或已质证。状态默认 `草案`。一次只推荐下一步。支持与不利必须能并列。对方控制标控制方和合法调取路径，禁止推定内容有利于用户。合法取得与诉讼可采分列。

热冲突强制处理：

- 对方控制即推定有利／存在诉讼即不正当目的／已读即已送达／案卷即诉状／红旗即保全已完成 → 该格不支持；仍出其他 `AJ#`。
- 无一碎片 → 关闸，不出 `AJ#` 终稿，窗口不关。
- 指导抢夺、伪造、违法取证 → 整体停止，不是该格不支持。

## 节点 4　查阅、保全、诉讼接口

第 7 节只开接口，不得夹带 `AJ#` 终稿、诉状或保全申请绕闸。闸关闭时第 7 节可写「闸未开，转介待争点编号」，不得补写已可提交。易失电子数据、账簿被转移、印章失控只标红旗，转介 `保全公司账簿印章与电子治理记录`，本窗不写保全申请终稿，不选定法院。

下一步只转介：`评估公司治理与股东关系`、`准备查阅复制书面请求`、`评估股东知情查阅权`、`保全公司账簿印章与电子治理记录`、`提起股东权利诉讼`、`应对股东权利诉讼`。禁止此致某法院。不选定法院。不代提交。

若 if 用户催促「对方拿着账就算对我们有利／打过官司就不能查阅／已读就算送达」，then 该格 `现有依据不支持`，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：股东要查阅账簿，公司主张「你们正在告我们所以是不正当目的、账在财务总监家里就算对你们有利、微信已读就是送达了」。案卷闸打开或半开。`Q-目`、`Q-控`、`Q-读` 不打开为可靠路径。第 6 节不得把不正当目的已成立、内容有利、已送达写入可执行 `AJ#`；对应格 `现有依据不支持`；仍出书面请求、十五日、控制方、合法调取路径等其他 `AJ#`。不关窗。不写诉状。

场景②：用户同时交出公司「账簿已完整」目录与对立股东「有利件被藏」口径，要求选对公司有利的一版，并指导「先把公章扣下来、邮箱密码拿到再编卷」。命中双方秘密＋抢夺印章＋隐匿。第一次整体停止。只交第 1、10 节。不出 `AJ#`。不得问代表哪一方后继续。不以「坚持」为门槛。
