# 评估控股股东实际控制人责任方法

本文件是可执行判断节点。持股最多不是当然实际控制人。仅有持股不是指示连带。控股不是已滥用。无实际执行事务不得套第一百八十条第三款。未知不写零。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已滥权、唯一必得总额、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不写诉状，不指导抢章。本窗闸名只能是控股闸，禁止复用控制闸、忠实闸、关联闸、否认闸、关系闸、结构闸、回购闸。预留不得占用：僵局闸、谈判闸、和解闸、立案闸、控制闸。本窗 `KG#` 是控股行。主路径只用 `Q-控`，禁止用 `Q-代`、`Q-购`、`Q-忠`、`Q-关`、`Q-争`、`Q-否` 作主路径。本窗 `Q-控` 不是关系窗「控股即已滥用」反路径。禁止占用争夺窗 `KZ#`、忠实窗 `ZS#`、关联窗 `GL#`、否认窗 `FR#`。英文 id 禁止使用，一律用中文技能名 `评估控股股东实际控制人责任`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年第二十一条国有企业改建、1993 年第一百八十条法定公益金、2018 年第二十条未拆现行第二十一条与第二十三条、把持股最多写成当然实控人时记为噪声，不得写入 `L#`。禁止指导伪造决议或抢夺印章证照。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现身份、滥权、执行事务或指示碎片扫描，不是默认闭集。
`KG#` 固定列：`编号｜身份切片｜滥权损害｜执行事务｜指示连带｜路径分账｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已滥权赔偿」或「大股东必须买走我」。无 `E#` 不得写已是实控人、已滥权、已执行事务或已指示。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-控`。禁止 `KZ#`、`ZS#`、`GL#`、`FR#`、`HG#`、`DL#`、`A#`、`N#`。一行一个切片。第二十一条、第一百八十条第三款、第一百九十二条分列。

口头「持股最多就是实控人」只进 `S#`／`V#`，**不得单独算作开闸材料**。争夺窗 `KZ#`、忠实窗 `ZS#` 不得单独开闸。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：第二百六十五条第二项控股股东（过半或表决权已足以对股东会决议产生重大影响）、第三项实际控制人（通过投资关系、协议或者其他安排能够实际支配公司行为的人）。持股最多不是当然实际控制人。第二十一条是对内滥权赔偿，不得吞第二十三条对债权人刺破。第二十二条关联损害只开关联窗。第一百八十条第三款须有不担任董事但实际执行公司事务的事实，无该事实则本条路径关闭，第二十一条仍可走，实体忠实勤勉转忠实窗。第一百九十二条须有对董事、高管的指示事实，仅有持股不构成指示。第八十九条第三款滥权回购、第一百八十九条代表诉讼、第一百九十条直接损害只开接口，不得与三笔责任合成「必须买走我」。时间效力规定第四条对第一百八十条第三款、第一百九十二条、第八十九条第三款只开待核。

## 节点 3　控股行 `KG#`

按已出现身份、滥权、执行事务或指示碎片扫描，不是默认闭集。无 `E#` 不得写已是实控人、已滥权、已执行事务或已指示。状态默认 `草案`。抢章、伪造、倒签红旗出现：整体停止。

热冲突强制处理：

- 持股最多即实控人／控股即已滥用／持股即指示／无执行事务仍套第一百八十条／三笔合成必须买走我／2018 条当现行／未知写零 → 该格不支持或字段停止；仍出其他 `KG#`。

路径分账格只开接口：公司损失 → 代表诉讼评估；严重损害下合理价格收购 → 异议回购；股东直接损害 → 第一百九十条；关联交易细节 → 关联窗。禁止写成已可代位、回购已成立或必须买走我。
