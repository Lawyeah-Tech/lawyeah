# 边界与路由

## 正触发

滥权、指示董事高管或实际执行公司事务致损，需要判断控制人责任。从零、碎片、身份未核验仍正触发：有可编号身份、滥权损害、执行事务或指示碎片则闸开或半开，出 `KG#` 草案，保持草案。本次不代替代表诉讼或回购、不指导抢章、不给胜诉率是交付禁令，不是开窗条件。持股最多即实控人、控股即已滥用，仍正触发。

双方秘密、伪造决议、倒签会议、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「持股最多即实控人」「控股即已滥用」「持股即指示」「无执行事务仍套第一百八十条」「三笔合成必须买走我」「2018 条当现行」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 代表诉讼条件终局 | `评估股东代表诉讼条件` |
| 代表诉讼起诉状 | `提起股东代表诉讼` |
| 第八十九条第三款回购终局 | `评估异议股东回购请求` |
| 关联识别或回避终局 | `评估关联交易与回避表决` |
| 担任董事高管的忠实勤勉终局 | `评估董事高管忠实勤勉责任` |
| 席位、章证或代表人争夺 | `评估控制权争夺与表决权约束` |
| 对债权人人格否认 | `评估法人人格否认` |
| 诉状或答辩终稿 | `提起股东权利诉讼` 或 `应对股东权利诉讼` |
| 合伙或个人独资 | 非公司主体 |

不得因「不代替代表诉讼或回购」或「不指导抢章」关窗。要判断控制人责任仍正触发，不得写成已滥权。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露或证券监管主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「控股」「实控」「指示」一词不是转出。

## 易混

本窗闸名只能是控股闸，不是控制闸，不是忠实闸，不是否认闸。`KG#` 不是 `KZ#` 不是 `ZS#` 不是 `FR#` 不是 `GL#`。主路径是 `Q-控`，不是 `Q-争`，不是 `Q-代`，不是 `Q-购`。本窗 `Q-控` 不是关系窗「控股即已滥用」反路径。持股最多不是当然实际控制人。仅有持股不是指示连带。无实际执行事务不得套第一百八十条第三款。控股不是已滥用。1993 年第二十一条不是现行滥权条。1993 年第一百八十条不是现行忠实条。2018 年第二十条不是 2024 年 7 月 1 日后的现行第二十一条。2018 年第二百一十六条「虽不是公司股东」不是现行实际控制人定义。解释五第一条仍引旧第二十一条须核对应现行第二十二条。「先把公章扣下来」整体停止。本窗不执行发送，不代提交。不选定法院。不写已滥权。不指导抢章。
