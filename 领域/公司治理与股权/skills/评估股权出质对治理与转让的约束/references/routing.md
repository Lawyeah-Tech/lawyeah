# 边界与路由

## 正触发

股权已出质或拟出质，影响表决、分红或转让。从零、碎片、登记未核验、无书面评估授权仍正触发：有可编号出质合同或登记碎片则闸开或半开，出 `ZY#` 草案，保持草案。本次不写担保合同主文、不指导隐匿过户是交付禁令，不是开窗条件。未登记即已对抗、出质即表决权转移、名册记载即已设立，仍正触发。

双方秘密、伪造出质登记或涂销、倒签质押合同或登记日、隐匿过户、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「未登记即已设立质权对抗」「出质即表决权当然转移」「合同有效即已设立」「名册记载即已设立」「未经同意转让即合同当然无效」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 担保合同、保证期间或实现担保物权程序 | 金融领域 |
| 转让协议终稿 | `准备有限公司股权内部转让` |
| 优先购买成立终局 | `评估优先购买权是否成立` |
| 名册记载或工商变更包 | `准备股东名册与工商变更衔接` |
| 股权结构图 | `梳理股权结构与控制权` |
| 冻结应对 | `应对股权冻结或行为保全` |
| 上市公司股份质押信息披露处罚 | 证券监管 |
| 合伙或个人独资 | 非公司主体 |

不得因「不写担保合同主文」或「不指导隐匿过户」关窗。拟出质治理约束评估仍正触发，不得写成已设立对抗或表决权已转移。
