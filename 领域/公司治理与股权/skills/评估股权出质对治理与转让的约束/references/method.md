# 评估股权出质对治理与转让的约束方法

本文件是可执行判断节点。未登记不是已设立质权对抗。出质不是表决权当然转移。书面合同有效不是质权已设立。名册记载不是出质登记设立。未经质权人同意转让不是合同当然无效。有限出质不是当然须其他股东过半数同意。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已设立对抗、表决权已转移、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不写担保合同主文，不指导隐匿过户。本窗闸名只能是出质闸，禁止复用转让闸、名册闸、优先购买闸、登记闸。预留不得占用：僵局闸、谈判闸、和解闸、立案闸、控制闸、显名闸。本窗 `ZY#` 是出质行。主路径只用 `Q-质`，禁止用 `Q-代` 作主路径。禁止占用转让窗 `ZR#`、名册窗 `MC#`、优先购买窗 `YX#`。英文 id 禁止使用，一律用中文技能名 `评估股权出质对治理与转让的约束`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《担保法》第七十八条记载名册生效、担保法解释第一百零三条、1993 年第一百六十条公司债券、2018 年第一百四十一条、把第四百四十三条写成合同当然无效时记为噪声，不得写入 `L#`。禁止指导伪造出质登记或隐匿过户。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现出质合同或登记碎片扫描，不是默认闭集。
`ZY#` 固定列：`编号｜有限或股份｜设立登记｜表决分红查阅｜再处分限制｜实现治理接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已设立对抗」或「表决权已转移」。无 `E#` 不得写已设立或已过户。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-质`。禁止 `ZR#`、`MC#`、`YX#`、`A#`、`N#`。有限／股份分列。一行一个切片。

口头「签了就算质押」「没登记也能对抗」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：质权自办理出质登记时设立，未登记则质权未设立，不是「已设立但不得对抗」。质押合同可依民法典第二百一十五条有效，与质权设立分列。出质后股权原则上不得转让，除非出质人与质权人协商同意；未经同意的转让合同不是当然无效，物权变动与善意取得本窗不断终局。表决权、查阅权原则上仍由记载于名册的股东行使，另有约定未核验则字段停止。分红或法定孳息是否由质权人收取，约定未核验则字段停止，不得写成当然丧失。有限出质不当然须其他股东过半数同意。限售期内股份可以出质，质权人不得在限售期内行使质权。公司不得接受本公司股份作为质权标的。

## 节点 1　主体与强制接口

一行一个出质切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `ZY#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 主体 | 出质人／质权人／公司分列 | 把质权人写成已经是名册股东 |
| 公司类型 | 有限／股份／上市分列 | 股份套有限第八十四条优先购买作设立条件 |
| 设立 | 书面合同与出质登记分列 | 未登记写成已设立对抗 |
| 权利 | 表决／分红／查阅分列 | 出质写成表决权当然转移 |

检索锚点（写入 `L#` 前须核验）：

- 民法典第四百四十条：可以转让的基金份额、股权可以出质。
- 第四百四十三条：质权自办理出质登记时设立；出质后不得转让，协商同意除外；价款提前清偿或提存。未登记＝质权未设立，不是已设立但不得对抗。
- 噪声：已失效《担保法》第七十八条有限出质适用转让规定、记载名册生效；担保法解释第一百零三条非上市股份记载名册生效。
- 股权出质登记办法（2020 修正）第二条：有限和未在证券登记结算机构登记的股份，办理出质登记适用该办法。
- 公司法第一百六十条第三款：限售期限内出质的，质权人不得在限制转让期限内行使质权。噪声：1993 年第一百六十条公司债券、2018 年第一百四十一条。
- 第一百六十二条末款：公司不得接受本公司的股份作为质权的标的。
- 有限第八十四条优先购买不是出质设立条件。实现后对外变价才开优先购买接口。

按已出现出质合同或登记碎片扫描，不是默认闭集。每条须能指向设立、存续权利或处分限制。

热冲突强制处理：

- 未登记即已对抗／出质即表决权转移／合同有效即已设立／名册即已设立／未经同意转让即合同当然无效／有限须过半数同意／未知写零 → 该格不支持或字段停止；仍出其他 `ZY#`。

- 指导伪造出质登记、隐匿过户 → 整体停止，不是该格不支持。
