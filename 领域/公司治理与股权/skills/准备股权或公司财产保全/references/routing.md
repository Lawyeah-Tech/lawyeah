# 边界与路由

## 正触发

已决定申请冻结股权、账户或行为保全。从零、碎片、担保未核验、无书面申请授权仍正触发：有可编号拟保全对象碎片则闸开或半开，出 `BQ#` 草案，保持草案。本次不保证裁定、不代提交、不选定法院是交付禁令，不是开窗条件。申请即已裁定、担保即已保全、线索即已冻结，仍正触发。

双方秘密、隐匿转移、抽逃作担保、抢夺破解、伪造担保、倒签申请日、违法取证的停止，优先于负触发。上述信号不在下表。不保证裁定不是负触发。「申请即已裁定」「担保即已保全」「线索即已冻结」「保证裁定」不在下表。隐匿转移不在下表，走整体停止。

## 易混

本窗闸名只能是保全闸，不是封存闸，不是管辖闸，不是起诉闸，不是冻结闸。`BQ#` 不是 `FC#`，不是 `XG#`，不是 `SZ#`。主路径是 `Q-保`，不是 `Q-账`，不是 `Q-冻`。`Q-保` 在邻窗是转介码，本窗打开为主路径。申请草稿不是已裁定。担保不是已保全。线索不是已冻结。诉前三十日不是已保全。1991 年第一百零三条不是现行第一百零三条。2012、2017 年第一百条不是现行第一百零三条。「先把钱转到个人卡再申请」整体停止。本窗不执行发送，不代提交。不选定法院。不保证裁定。
