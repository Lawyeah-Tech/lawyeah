# 准备股权或公司财产保全方法

本文件是可执行判断节点。申请草稿不是已裁定。担保不是已保全。线索不是已冻结。口头紧急不是四十八小时已裁。诉前措施不是起诉已完成。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已裁定、已冻结、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不保证裁定。本窗闸名只能是保全闸，禁止复用封存闸、管辖闸、起诉闸、印章闸、案卷闸、控制闸、止付闸、冻结闸。预留不得占用：立案闸、冻结闸。本窗 `BQ#` 是保全行。主路径只用 `Q-保`，禁止用 `Q-账`、`Q-管`、`Q-诉`、`Q-冻`、`Q-印` 作主路径。本窗 `Q-签` 只作「申请草稿即已提交」不关窗码。英文 id 禁止使用，一律用中文技能名 `准备股权或公司财产保全`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991 年第一百零三条协助执行罚款当现行行为保全条、2012 或 2017 年第一百条第一百零一条未核对应现行第一百零三条第一百零四条、财产保全规定仍引旧第一百条未核对应、知产行为保全规定仍引旧申请错误条、把申请写成已裁定时记为噪声。禁止指导隐匿转移、抽逃作担保或抢夺破解。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现拟保全对象扫描，不是默认闭集。
`BQ#` 固定列：`编号｜措施切片｜标的与范围｜必要性｜担保｜线索｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已裁定」或「已冻结」。无 `E#` 不得写已裁定。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-保`。禁止 `FC#`、`XG#`、`SZ#`、`YZ#`、`A#`、`N#`。文件状态只用 `草案`、`待签署`、`停止`。必要性、担保或三十日未闭合不得标 `待签署`。

口头「先冻住」「法院一定会准」「先把钱转走再申请」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。财产保全与行为保全分列。诉前与诉中分列。

实务上：诉中担保「可以」；诉前担保「应当」。四十八小时是紧急情形受理后的裁定期限，不是必准。三十日是起诉或仲裁期限，不是已保全。行为保全必要性高于一般财产保全。冻结股权不等于已变更股东。申请错误须赔，未知损失不写零。

## 节点 0　分流、立场、保全闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、隐匿转移、抽逃作担保、抢夺破解、伪造担保、倒签申请日、违法取证不进负表。利益冲突未解不进整体停止。不保证裁定、不代提交不是负触发。

整案转出只交付第 1、2、10 节，不出 `BQ#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是账簿合法封存 | 负触发 `保全公司账簿印章与电子治理记录` |
| 主成果是已作出保全之复议或置换 | 负触发 `应对股权冻结或行为保全` |
| 主成果是起诉包 | 负触发 `提起股东权利诉讼` |
| 主成果是管辖评估 | 负触发 `评估股东争议管辖与仲裁条款` |
| 主成果是证照交接 | 负触发 `准备证照印章管控与交接` |
| 主成果是控制权路径 | 负触发 `评估控制权争夺与表决权约束` |
| 主成果是实体评估而无申请准备 | 负触发 `评估公司治理与股东关系` |
| 劳动、破产、知产证据保全主轴 | 整案转出对应领域 |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不保证裁定」「不代提交」 | 交付禁令，不是负触发 |

出现「保全」「冻结」「担保」一词不是转出。

保全闸打开（可出 `BQ#` 草案，仍不得标「已裁定／已冻结／担保已足额」）须同时满足：单方无冲突申请方立场已闭合；主成果是保全申请草案，不是封存、不是起诉包、不是复议；至少一项可编号拟保全对象碎片。口头「先冻住」不算单独开闸材料。

保全闸部分打开：已有碎片，但类型、必要性、担保或三十日未闭合；对应格待核；仍交十节。无书面申请授权但单方立场已闭合且已有碎片：保全闸部分打开，仍交十节，不是整体停止。

保全闸关闭（仍正触发）：无一可编号碎片。「今天必须出已裁定终稿」而无最小碎片不得开闸。不出 `BQ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `BQ#` 终稿，**第 7 节不得出已冻结或发送版申请**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「申请即已裁定」「担保即已保全」「线索即已冻结」「保证裁定」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `BQ#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 保全闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出隐匿转移、抽逃作担保、抢夺破解、伪造担保、倒签申请日或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个措施切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `BQ#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 类型时点 | 财产／行为分列；诉前／诉中分列 | 证据保全冒充财产保全；诉前写成已立案后保全 |
| 标的 | 某股权／某账户／某次会议／某枚印章分列 | 「全部财产已冻」；超范围查封案外人 |
| 必要性 | 转移、毁损、抢章、即将违法变更登记等具体迹象 | 「对方不诚信」升格难以执行 |
| 担保 | 诉前应当／诉中可以分列；形式与数额待核 | 抽逃公司资金作担保；担保书即已保全 |
| 线索 | 登记机关、账号或权属表面；未知标 `G#` | 编造账号；未知写零 |
| 三十日 | 诉前采取后三十日内起诉或仲裁 | 写成已保全或可以只保全不起诉 |

检索锚点（写入 `L#` 前须核验）：

- 民事诉讼法（2023 修正，施行日 2024-01-01）第一百零三条诉讼保全含行为保全；可以责令担保；紧急四十八小时。噪声：1991 年第一百零三条；2012、2017 年第一百条。
- 第一百零四条诉前保全应当担保；采取后三十日未起诉或仲裁应解除。噪声：2017 年第一百零一条。
- 第一百零五条限于请求范围或与本案有关财物。
- 第一百零六条查封扣押冻结；不得重复查封冻结。
- 第一百零七条被申请人提供担保应当解除。
- 第一百零八条申请错误赔偿。噪声：知产行为保全规定仍引旧第一百零五条。
- 解释第一百五十二条诉前财产保全相当数额担保、行为保全数额由法院决定；诉讼中是否担保由法院决定。财产保全规定第五条仍引旧第一百条须核对应。

## 节点 3　保全行 `BQ#`

按已出现拟保全对象扫描，不是默认闭集。每条须能指向标的、必要性或线索之一。

无 `E#` 不得写已裁定。状态默认 `草案`。一次只推荐下一步。未知不写零，不保证裁定。必要性、担保或三十日未闭合不得标 `待签署`。

热冲突强制处理：

- 申请即已裁定／担保即已保全／线索即已冻结／保证裁定／未知写零 → 该格不支持或字段停止；仍出其他 `BQ#`。
- 无一碎片 → 关闸，不出 `BQ#` 终稿，窗口不关。
- 指导隐匿转移、抽逃作担保、抢夺破解 → 整体停止，不是该格不支持。

## 节点 4　封存、起诉、复议与管辖接口

第 7 节只开接口，不得夹带 `BQ#` 终稿或已冻结结论绕闸。闸关闭时第 7 节可写「闸未开，转介待保全碎片编号」，不得补写已裁定。不选定法院。不代提交。不保证裁定。

下一步只转介：`保全公司账簿印章与电子治理记录`、`应对股权冻结或行为保全`、`提起股东权利诉讼`、`评估股东争议管辖与仲裁条款`、`准备证照印章管控与交接`、`评估控制权争夺与表决权约束`。禁止此致某院。

若 if 用户催促「申请写完就算裁了／担保交了就算冻了／不清楚先写零／先把钱转走再申请」，then 该格 `现有依据不支持` 或字段停止；指导转移则整体停止。窗口不关除非命中整体停止。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：有股权登记主体和账户后四位碎片。用户主张申请写完就算裁了、担保交了就算冻了、线索写了账号就算冻住了、法院四十八小时一定会准、不清楚的金额先写零。保全闸打开或半开。`Q-准`、`Q-担`、`Q-线`、`Q-急`、`Q-零` 不打开为可靠路径。第 6 节不得把已裁定、已冻结、0 写入可执行 `BQ#`；对应格 `现有依据不支持` 或字段停止；仍出措施分列、必要性缺口、担保待核等其他 `BQ#`。不关窗。不代提交。不保证裁定。

场景②：用户同时交出公司「必须连夜冻结」与对立股东「对方在转移」口径，并指导「先把账上的钱转到我个人卡，回头再申请冻结对方股权」。命中双方秘密＋隐匿转移。第一次整体停止。只交第 1、10 节。不出 `BQ#`。不得问代表哪一方后继续。不以「坚持」为门槛。
