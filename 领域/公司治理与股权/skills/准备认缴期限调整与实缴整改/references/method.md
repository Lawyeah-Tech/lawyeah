# 准备认缴期限调整与实缴整改方法

本文件是可执行判断节点。调整方案不是已经公示完成。调整期限不是已实缴。剩余认缴出资期限自 2027 年 7 月 1 日起不足五年不是必须调整。已缴足不是必须调整。新设有限五年不是存量必须立刻套第四十七条。股份发起人 2027 年 6 月 30 日前缴足不是有限调整期限可套。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然核准、已经公示完成、已实缴、选定法院、代提交、未知写零、唯一截止日。本任务不定罪，不代提交登记或公示，不出减资终稿，不出催缴书。本窗闸名只能是认缴闸，禁止复用增资闸、减资闸、章程闸、设立闸、催缴闸、瑕疵闸、整改闸、登记闸。本窗 `RZ#` 是认缴整改行。英文 id 禁止使用，一律用中文技能名 `准备认缴期限调整与实缴整改`。主路径只用 `Q-调`，禁止 `Q-增`、`Q-减`、`Q-章`、`Q-设`、`Q-催` 作主路径。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回征求意见稿当现行、2018 条号当现行、把调整方案写成已经公示完成、把剩余不足五年写成必须调整时记为噪声。禁止指导倒签缴款日、垫资走账制造已实缴或伪造公示。伤残等级与本窗无关。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现存量或责令碎片扫描，不是默认闭集。
`RZ#` 固定列：`编号｜整改切片｜存量／新设分表｜是否必须调整｜方案分列｜章程公示登记接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。无 `E#` 不得写已经公示完成、已实缴或已备案。`E#` 只作证据形态回链，不是发送闸。扫描不是闭集。缺项记 `G#`。承认只进 `S#`／`D#`，不得占用 `A#`。

口头「已经改完了」「不用调」「今晚补缴款凭证」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。是否必须调整未闭合不得标 `待发送`。

实务上：先按成立日分表。2024-07-01 及以后新设有限走第四十七条五年，不是本窗存量整改，除非登记机关另有纠正。2024-06-30 及以前存量有限：剩余认缴出资期限自 2027-07-01 起超过五年的，应当在 2027-06-30 前调整至五年内并记载于章程；剩余不足五年或已缴足无需调整。存量股份发起人或股东应当在 2027-06-30 前全额缴纳，不得套有限「调整期限」。异常超长或超大注册资本走登记机关研判接口。方案分列：缩短章程出资日期、实际缴纳、减资消减剩余认缴；减资必须转减资窗，不得跳过债权人保护。调整合规不等于治愈历史抽逃。

出现「认缴」「五年」「整改」一词不是转出。调整方案即已经公示完成不是负触发，该格不支持。新设公司但主成果仍是存量整改：正触发关闸或半开，第 7 节开设立接口。

认缴闸打开（可出 `RZ#` 草案，仍不得标「已经公示完成／已实缴／已备案」）须同时满足：单方无冲突立场已闭合；主成果是认缴期限调整与实缴整改方案草案，不是增资包、不是减资终稿、不是设立包；至少一项可编号存量公司碎片或责令调整碎片。口头「已经改完了」不算单独开闸材料。

认缴闸部分打开：已有碎片，但成立日、章程出资日或是否必须调整未闭合；对应格待核；仍交十节。无书面整改授权但立场已闭合且有碎片：部分打开，不是整体停止。是否必须调整未闭合：部分打开，不得写已经公示完成或已实缴。

认缴闸关闭（仍正触发）：无一可编号存量或责令碎片。「今天必须出已经公示完成／已实缴终稿」而无最小碎片不得开闸。不出 `RZ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `RZ#` 终稿，**第 7 节不得出已经公示完成或已实缴**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「调整方案即已经公示完成」「调整期限即已实缴」「剩余不足五年即必须调整」「新设五年即存量必须立刻整改」「股份缴足套有限调整」「办理日起算五年即唯一截止日」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `RZ#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号存量或责令碎片，then 认缴闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与对立股东相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出倒签缴款日、垫资走账制造已实缴、伪造决议、伪造公示、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个整改切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `RZ#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 分表 | 存量有限／存量股份／新设有限 | 新设五年套存量必须立刻整改；股份缴足套有限调整 |
| 是否必须调整 | 剩余自 2027-07-01 起是否超过五年；是否已缴足；是否异常责令 | 剩余不足五年写成必须调整；已缴足写成必须调整 |
| 方案 | 缩短章程日期／实缴／减资接口 | 本窗出减资终稿；垫资走账当已实缴 |
| 公示登记 | 章程记载、二十个工作日公示、变更登记接口 | 方案草稿写成已经公示完成；网交回执写成已核准 |
| 例外 | 国家利益或重大公共利益例外待核 | 口头「涉及国家利益」写成已获同意 |

检索锚点（写入 `L#` 前须核验）：

- 第四十七条：新设有限自成立之日起五年内缴足。不是存量必须立刻套用。
- 第二百六十六条：施行前已登记公司逐步调整，具体实施办法由国务院规定。
- 国务院令第 784 号第二条：存量有限剩余自 2027-07-01 起超过五年的，应当在 2027-06-30 前调整至五年内并记载于章程；股份发起人 2027-06-30 前全额缴纳。例外须核验。
- 国务院令第 784 号第三条／实施办法第十条：明显异常可要求及时调整。认缴期限三十年以上、注册资本十亿元以上是研判信号，不是当然违法。
- 国务院令第 784 号第四条：相关信息产生之日起二十个工作日内公示。二十个工作日不是已公示完成。
- 国务院令第 784 号第六条：未调整责令改正；逾期未改正特别标注。责令改正不是已另册。
- 实施办法第八条：剩余不足五年或已缴足无需调整。存量股份「发起人」与「发起人或者股东」国务院令第二条与实施办法第八条表述不一致，须运行时核验，不得选有利的一条写成已适用。
- 实施办法第七条：有限增资自变更登记之日起五年，只约束新增认缴，不是存量第二条截止日，不得写成办理日起算五年即本窗唯一截止日。
- 实施办法第七条：有限增资自变更登记之日起五年，本窗只开增资接口。
- 噪声：征求意见稿当现行；2018 条号当现行；办理日起算五年当唯一截止日。

不得暗示「方案一出就已经合规」。地方登记实操与条文起算日冲突时并列待核，不写唯一截止日。

## 节点 3　认缴整改行 `RZ#`

按已出现存量或责令碎片扫描，不是默认闭集。公司侧与股东侧分列立场，不得选边。

无 `E#` 不得写已经公示完成、已实缴或已备案。状态默认 `草案`。一次只推荐下一步。未知不写零。剩余不足五年或已缴足：该格不支持必须调整，仍出分表。成立日不明建并行情景，不给唯一截止日。方案分列缩短章程日期、实际缴纳、减资接口；减资只开接口。公示二十个工作日待核，不得写成已公示完成。公司侧可出方案要点清单，状态保持草案，不打开待发送，不代提交。

热冲突强制处理：

- 调整方案即已经公示完成／调整期限即已实缴／剩余不足五年即必须调整／新设五年即存量必须立刻整改／股份缴足套有限调整／办理日起算五年即唯一截止日／估数或写零 → 该格不支持或字段停止；仍出其他 `RZ#`。
- 无一存量或责令碎片 → 关闸，不出 `RZ#` 终稿，窗口不关。
- 指导倒签缴款日、垫资走账制造已实缴、伪造决议或公示 → 整体停止，不是该格不支持。

## 节点 4　增资、减资、章程、设立、催缴与瑕疵接口

第 7 节只开接口，不得夹带 `RZ#` 终稿、已经公示完成或已实缴绕闸。闸关闭时第 7 节可写「闸未开，转介待成立日或章程编号」，不得补写已经公示完成。减资只开减资窗接口，不得跳过债权人保护。增资只开增资窗接口。新设只开设立窗接口。催缴／瑕疵／失权只开对应接口。税务只标可能涉及，不办申报。

下一步只转介：`准备内部增资与认缴调整`、`准备减资通知与债权人保护`、`起草或修订公司章程`、`准备公司设立文件与登记`、`评估出资瑕疵催缴与加速到期`、`准备催缴出资通知`、`评估失权与股权丧失`、`准备股东会决议与召集`。禁止此致某登记机关为唯一路径。不代提交。不执行发送。

若 if 用户催促「方案一出就算已经公示／改了期限就算已实缴／不足五年也必须调／新设也要按存量改／按办理日截止／金额不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
