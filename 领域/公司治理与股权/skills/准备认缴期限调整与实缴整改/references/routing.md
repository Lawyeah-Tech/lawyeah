# 边界与路由

## 正触发

存量公司需将剩余认缴出资期限调整至五年内，或异常认缴被登记机关要求调整，需要整改方案。从零、碎片、是否必须调整未闭合、无书面整改授权仍正触发：有存量公司或责令调整碎片则闸开或半开，出 `RZ#` 草案，保持草案。本次不代提交、不写已经公示完成是交付禁令，不是开窗条件。调整方案即已经公示完成、调整期限即已实缴、剩余不足五年即必须调整，仍正触发。

双方秘密、倒签缴款日、垫资走账制造已实缴、伪造决议、伪造公示、抢夺印章证照、违法取证的停止，优先于负触发。上述信号不在下表。「调整方案即已经公示完成」「调整期限即已实缴」「剩余不足五年即必须调整」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 内部增资或新增认缴 | `准备内部增资与认缴调整` |
| 减资消减剩余认缴 | `准备减资通知与债权人保护` |
| 可签署章程终稿独占 | `起草或修订公司章程` |
| 新设设立文件 | `准备公司设立文件与登记` |
| 出资瑕疵路径或催缴书 | `评估出资瑕疵催缴与加速到期`／`准备催缴出资通知` |
| 失权评估或失权通知 | `评估失权与股权丧失` |
| 税务申报或核定主轴 | 税务领域 |
| 合伙或个人独资 | 非公司主体 |

不得因「不代提交」或「不写已经公示完成」关窗。拟出调整方案仍正触发，不得写成已经公示完成或已实缴。新设公司但主成果仍是存量整改：正触发关闸或半开，第 7 节开设立接口。减资一词出现但主成果仍是期限调整：正触发，第 7 节开减资接口。

出现「认缴」「五年」「整改」一词不是转出。

## 易混
