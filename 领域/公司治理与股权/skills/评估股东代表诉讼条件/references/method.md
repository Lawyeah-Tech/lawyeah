# 评估股东代表诉讼条件方法

本文件是可执行判断节点。未书面请求不是已可代位起诉终稿。口头很急不是情况紧急。百分之一持股不是有限公司门槛。被告不是公司自己。胜诉利益不是归原告股东。股东直接损害不是代表诉讼已成立。公司已就同一事实起诉不是负触发关窗。未知不写零。不输出唯一必得总额。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已可代位、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不写诉状，不写前置发函终稿。本窗闸名只能是代表诉讼闸，禁止复用起诉闸、查阅诉闸、分配诉闸、书面请求闸、书面闸、忠实闸、答辩闸。预留不得占用：代表诉闸、前置请求闸、僵局闸、谈判闸、和解闸、立案闸、控制闸、登记闸、显名闸。本窗 `DL#` 是代表诉讼行。主路径只用 `Q-代`，禁止用 `Q-请`、`Q-诉`、`Q-直`、`Q-忠` 作主路径。禁止占用起诉窗 `SZ#`、书面请求窗 `QH#`、前置请求窗 `QZ#`、提起代表诉讼窗 `DS#`、忠实窗 `ZS#`。英文 id 禁止使用，一律用中文技能名 `评估股东代表诉讼条件`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年第一百八十九条破产清算、1993 年第一百八十八条合并分立登记、2018 年第一百五十一条未核验对应、把第一百八十八条写成程序条、把未书面请求写成已可代位时记为噪声，不得写入 `L#`。禁止指导伪造书面请求或倒签送达。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现资格、公司损害或前置请求碎片扫描，不是默认闭集。
`DL#` 固定列：`编号｜损害归属｜原告资格｜前置机关｜三十日或紧急｜被告与利益归属｜全资子公司接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已可代位」或胜诉利益归股东。无 `E#` 不得写已书面、已拒绝、已紧急、已可代位。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-代`。禁止 `SZ#`、`QH#`、`QZ#`、`DS#`、`ZS#`、`A#`、`N#`。公司损害／股东直接损害／他人侵害／全资子公司双重代表分列。一行一个切片。金额未知写 `未知`／`G#`，禁止写 `0`。

口头「很急就能告」「没发函也能告董事」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：有限公司股东即可提起，无持股比例、无连续一百八十日；百分之一和连续一百八十日只约束股份公司。解释一第四条：一百八十日为起诉时已期满的连续持股，合计持股为两个以上股东合计，仍引旧第一百五十一条须核验对应。前置：董高加害书面请求监事会（不设监事会的监事，或行使监事会职权的审计委员会，核验失败字段停止）；监事加害书面请求董事会。起算是收到之日，不是发出日、不是已读。拒绝可提前打开代位接口；三十日未满且无紧急具体事实：不得写已可代位起诉终稿。紧急须有转移资产、即将完成登记、时效即将届满等具体事实，「很急」不开。九民纪要第二十五条根本不存在机关起诉可能性只开待核，不得默认跳过前置。被告是加害董监高或他人；公司通常为第三人，不得写成原告或唯一被告。胜诉利益归公司。全资子公司双重代表是第一百八十九条第四款，不是第三款。公司已就同一事实起诉：代位必要性不支持，窗口不关。

## 节点 0　分流、立场、代表诉讼闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造书面请求或资格、倒签送达或起诉、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `DL#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 以股权或资产收购、投资交割、尽调闭环为主要目标 | 整案转投资并购 |
| 婚姻、离婚、继承中的股权归属与分割 | 整案转婚家 |
| 高管劳动合同、解除、竞业劳动后果 | 整案转劳动 |
| 企业级舞弊调查、反商业贿赂、综合合规体系 | 整案转企业合规 |
| 破产申请、重整计划、破产债权申报与分配 | 整案转破产 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 合伙企业、个人独资 | 整案转出，非公司主体 |
| 上市公司发行、持续信息披露或证券监管主轴 | 整案转证券监管／投资并购，本领域只保留公司机关接口 |
| 主成果是前置书面请求发函 | 负触发 `准备代表诉讼前置书面请求` |
| 「不写起诉状」「不把公司写成被告」 | 交付禁令，不是负触发 |

出现「代表诉讼」「起诉」「紧急」一词不是转出。

代表诉讼闸打开（可出 `DL#` 草案，仍不得标「已可代位／紧急已成立」）须同时满足：单方无冲突立场已闭合；主成果是代表诉讼条件评估，不是发函终稿、不是诉状；至少一项可编号股东资格、公司损害或前置请求碎片。口头「很急就能告」不算单独开闸材料。

代表诉讼闸部分打开：已有碎片，但资格、机关或紧急未闭合；对应格待核；仍交十节。

代表诉讼闸关闭（仍正触发）：无一可编号碎片。「今天必须出已可代位终稿」而无最小碎片不得开闸。不出 `DL#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `DL#` 终稿，**第 7 节不得出已可代位**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「未书面请求即已可代位」「口头很急即紧急」「有限套百分之一」「被告列公司」「胜诉利益归股东」「直接损害即代表诉讼已成立」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `DL#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 代表诉讼闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造书面请求或资格、倒签送达或起诉、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `DL#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 主体 | 拟代位股东／公司／加害人分列 | 把公司写成原告或唯一被告；把对立股东漏列加害人后出终稿 |
| 类型 | 有限／股份分列 | 有限套百分之一或连续一百八十日 |
| 损害 | 公司损害／股东直接损害分列 | 把第一百九十条直接损害写成代表诉讼已成立 |
| 机关 | 监事会／监事／审计委员会／董事会分列 | 机关写错仍升格已请求 |

检索锚点（写入 `L#` 前须核验）：

- 第一百八十八条：董监高对公司赔偿责任。噪声：1993 年第一百八十八条合并分立登记。不是本窗程序条。
- 第一百八十九条第一款：有限股东；股份连续一百八十日单独或合计百分之一；董高→监事会，监事→董事会。
- 第一百八十九条第二款：拒绝、收到之日起三十日未起诉、或情况紧急。
- 第一百八十九条第三款：他人侵犯公司合法权益。
- 第一百八十九条第四款：全资子公司双重代表。不得写成第三款。
- 噪声：1993 年第一百八十九条破产清算；2018 年第一百五十一条。
- 第一百九十条：股东直接诉讼，与本窗分账。
- 解释一第四条、解释四第二十三条至第二十六条仍引旧第一百五十一条须核验对应。
- 九民纪要第二十五条只开待核。

## 节点 3　代表诉讼行 `DL#`

按已出现资格、公司损害或前置请求碎片扫描，不是默认闭集。每条须能指向损害归属、资格或前置。

无 `E#` 不得写已书面、已拒绝、已紧急、已可代位。状态默认 `草案`。一次只推荐下一步。紧急核验失败：依据不足，不得默认跳过前置。全资子公司未核验第四款：不得写成当然可跨层起诉。

热冲突强制处理：

- 未书面请求即已可代位／口头很急即紧急／有限套百分之一／被告列公司／胜诉利益归股东／直接损害即代表诉讼已成立／未知写零 → 该格不支持或字段停止；仍出其他 `DL#`。
- 无一碎片 → 关闸，不出 `DL#` 终稿，窗口不关。
- 指导伪造书面请求、倒签送达 → 整体停止，不是该格不支持。

## 节点 4　前置发函、起诉、直接诉讼与忠实接口

第 7 节只开接口，不得夹带 `DL#` 终稿、已可代位或选定法院绕闸。闸关闭时第 7 节可写「闸未开，转介待代表诉讼编号」，不得补写已可代位。不选定法院。不代提交。

下一步只转介：`准备代表诉讼前置书面请求`、`提起股东代表诉讼`、`提起股东权利诉讼`、`评估董事高管忠实勤勉责任`、`评估控股股东实际控制人责任`、`评估股东争议管辖与仲裁条款`。禁止此致某法院。

若 if 用户催促「没发函也能告／很急就能告／有限也要百分之一／把赔偿打给我」，then 该格 `现有依据不支持`，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「代表诉讼闸与代表诉讼行草案」。本窗不执行发送。不包含：已可代位、紧急已成立、诉状、前置发函终稿、胜诉利益归股东。禁止选边治愈。禁止未书面请求即已可代位。禁止有限套百分之一。禁止指导伪造请求。代表诉讼闸打开 ≠ 已可代位起诉 ≠ 前置已闭合 ≠ 紧急已成立 ≠ 诉状可交。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标代表诉讼终稿已形成。
风险档 A：伪造书面请求、倒签送达必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：有限公司小股东主张董事侵占公司款项，未向监事会发书面请求，口头称很急，要求按百分之一持股门槛、把公司列为被告、胜诉款项打给自己。代表诉讼闸打开或半开。`Q-未`、`Q-急`、`Q-一`、`Q-司`、`Q-利` 不打开为可靠路径。第 6 节不得把已可代位、紧急已成立写入可执行 `DL#`；对应格 `现有依据不支持`；仍出有限股东资格、公司损害归属、正确请求机关等其他 `DL#`。不关窗。不写诉状。发函只开前置请求窗接口。

场景②：用户同时交出「公司口径：监事会已决定自行起诉」与「股东口径：把书面请求日期改到三十日前、补一份紧急说明」，要求选对股东有利的一版。命中双方秘密＋伪造请求／倒签送达。第一次整体停止。只交第 1、10 节。不出 `DL#`。不得问代表哪一方后继续。不以「坚持」为门槛。
