# 输出合同

按触发结果选择交付形状。代表诉讼闸未打开不得交付「已可代位起诉」或「紧急已成立」。禁止把未书面请求写成已可代位。禁止把口头很急写成情况紧急。禁止把百分之一写成有限公司门槛。禁止把公司写成被告。禁止把胜诉利益写成归原告股东。禁止把股东直接损害写成代表诉讼已成立。禁止输出唯一必得总额。禁止选边治愈。未知不写零。不定罪。不写诉状。不写前置发函终稿。本窗闸名只能是代表诉讼闸。本窗 `DL#` 是代表诉讼行草案，不是起诉窗 `SZ#`。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出 | 第 1 节（触发与分流）、第 2 节（来源）、第 10 节（交接）。不填第 5–9 节 |
| 整体停止 | 第 1 节（停止原因）、第 10 节。禁止 `DL#` 正文、选边、伪造请求或倒签步骤。双方秘密、伪造书面请求、倒签送达第一次即停，优先于负触发；无选边治愈，无「坚持」门槛 |
| 代表诉讼闸关闭（仍正触发） | 十节表头均出现；第 5 节只交闸／`Q#`；第 6 节不出 `DL#` 终稿；第 7 节不得出已可代位；不得改走负触发或只交 1+2+10 |
| 用户要未书面请求即已可代位、口头很急即紧急、有限套百分之一、被告列公司、胜诉利益归股东、直接损害即代表诉讼已成立、未知写零（不关窗） | 十节表头均出现；对应格填 `现有依据不支持` 或字段停止；闸已开仍出其他 `DL#` 草案；不得标终稿 `已形成` |
| 正触发且闸开 | 下列十节表头均出现；未核验格填待核；禁止为填满而写已可代位或紧急已成立 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入代表诉讼终稿已形成。双方秘密未解不得进入「部分形成」。每个 `DL#`／`Q#` 必须带来源和判断三值。`L#` 不得直接抄技能正文条号。稿件状态默认 `草案`。本窗不执行发送。代表诉讼闸打开不等于已可代位。利益冲突未解不是整体停止。

分流理由只放第 1 节。第 7 节只保留发函、起诉、直接诉讼与忠实接口，不得把 `DL#` 终稿或已可代位改放到第 7 节绕闸。

## 1. 触发、单方立场、代表诉讼闸与成果状态

谁要代表诉讼条件评估。立场互斥。代表诉讼闸是否打开。不得写「澄清代表哪一方后继续」。草案不是已可代位。利益冲突未解不是整体停止。

## 2. 来源登记与 MCP 调用表

`S/D/R/C/L/I/G/Q/DL/V/E`。口头「很急就能告」只登记 `S#`／`V#`。噪声命中须登记：1993 年第一百八十九条破产清算、1993 年第一百八十八条合并分立登记、2018 年第一百五十一条、把第一百八十八条当程序条。禁止 `N#`、`A#`、`SZ#`、`QH#`、`QZ#`、`DS#`、`ZS#`。

## 3. 主体、公司类型与损害归属

拟代位股东／公司／加害人分列。有限／股份分列。公司损害／股东直接损害分列。本节禁止出 `DL#` 终稿。

## 4. 资格、前置与紧急碎片

名册或持股、书面请求与收到凭证、拒绝或逾期、紧急具体事实及其 `E#`。口头不得升格已可代位。未知记 `G#`，禁止写零。本节禁止出 `DL#` 终稿。

## 5. 代表诉讼闸与路径矩阵 `Q#`

本节禁止出 `DL#` 终稿。无件则 `Q-代` 关闭，窗口不关。`Q-未`／`Q-急`／`Q-一`／`Q-司`／`Q-利`／`Q-已`／`Q-旧`／`Q-零` 不得打开已可代位或紧急已成立。`Q-前`／`Q-诉`／`Q-直`／`Q-忠`／`Q-控`／`Q-管` 只开接口或按主成果负触发。`Q-伪` 不是可打开路径。

## 6. 代表诉讼行 `DL#`

闸未开不得出代表诉讼终稿。闸已开且仅部分格被错误主张打中：仍出其他 `DL#` 草案，被打中的格填 `现有依据不支持`。无 `E#` 不得写已书面、已拒绝、已紧急、已可代位。状态 `草案`。禁止未书面请求即已可代位。禁止口头很急即紧急。禁止有限套百分之一。禁止被告列公司。禁止胜诉利益归股东。禁止直接损害即代表诉讼已成立。禁止本窗出诉状。

期间表六类必须出齐，未出现写「本任务未触发」：诉讼时效／除斥／催缴宽限期／查阅答复期／回购协议期／代表诉讼前置期。三十日标代表诉讼前置期，起算收到之日。六十日不是本窗前置期。

## 7. 前置发函、起诉、直接诉讼与忠实接口

发函只开 `准备代表诉讼前置书面请求`。诉状只开 `提起股东代表诉讼`。股东直接损害只开 `提起股东权利诉讼`。忠实勤勉只开 `评估董事高管忠实勤勉责任`。控股股东滥权只开 `评估控股股东实际控制人责任`。管辖仲裁只开 `评估股东争议管辖与仲裁条款`。本节不得夹带 `DL#` 终稿。不代提交。不选定法院。闸未开时只写「转介待代表诉讼编号」，不得补写已可代位。

## 8. 边界、转介与最强反方

须列未书面请求即已可代位、口头很急即紧急、有限套百分之一、被告列公司、胜诉利益归股东、直接损害即代表诉讼已成立、公司已起诉即关窗、两边选边等最强反方。

## 9. 风险与下一步

每项含可逆性，须按真实已发生动作写清（仅有公司损害未发函／已发函未满三十日／已主张很急直接告／已形成评估草稿），不得写成「可逆」或「待核」空词。一次只推荐下一步。禁止提交指令。不代提交。

## 10. 缺口、停止项与对方最强解释

须列对方最强解释：没发函也能告、很急就能跳过前置、有限也要百分之一、把公司列为被告、胜诉款项打给股东、这是股东自己的损害、公司已经在告所以本窗关掉、把请求日期改到三十日前。

本成果不是已可代位起诉、不是紧急已成立、不是起诉窗 `SZ#`、不是诉状。不定罪。草案不是已可代位。未书面请求不是已可代位起诉终稿。百分之一持股不是有限公司门槛。

## 综合提问的强制降级

用户同时问能不能替公司告、没发函行不行、很急能不能直接告，第 5–8、9 节仍只给接口和转介，对应格不支持，闸已开仍出其他 `DL#`。主成果是发函：负触发转 `准备代表诉讼前置书面请求`。提出伪造请求、倒签送达或双方秘密：第一次整体停止，只交第 1、10 节，不填第 5–9 节。
