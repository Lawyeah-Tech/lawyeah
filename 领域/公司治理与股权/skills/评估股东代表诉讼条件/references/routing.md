# 边界与路由

## 正触发

董监高或他人损害公司，股东拟代位起诉，需要判断条件。从零、碎片、前置未核验、无书面评估授权仍正触发：有可编号股东资格、公司损害或前置请求碎片则闸开或半开，出 `DL#` 草案，保持草案。本次不写起诉状、不把公司写成被告是交付禁令，不是开窗条件。未书面请求即已可代位、口头很急即紧急，仍正触发。

双方秘密、伪造书面请求或资格、倒签送达或起诉、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「未书面请求即已可代位」「口头很急即紧急」「有限套百分之一」「被告列公司」「胜诉利益归股东」「直接损害即代表诉讼已成立」「公司已起诉即关窗」「未知写零」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 前置书面请求发函 | `准备代表诉讼前置书面请求` |
| 可提交代表诉讼起诉状 | `提起股东代表诉讼` |
| 股东直接损害诉讼 | `提起股东权利诉讼` |
| 忠实勤勉实体终局 | `评估董事高管忠实勤勉责任` |
| 控股股东滥权赔偿 | `评估控股股东实际控制人责任` |
| 管辖或仲裁终局 | `评估股东争议管辖与仲裁条款` |
| 合伙或个人独资 | 非公司主体 |

不得因「不写起诉状」或「不把公司写成被告」关窗。要判断有没有代表诉讼条件仍正触发，不得写成已可代位。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露或证券监管主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「代表诉讼」「起诉」「紧急」一词不是转出。

## 易混

本窗闸名只能是代表诉讼闸，不是起诉闸，不是查阅诉闸，不是书面请求闸。`DL#` 不是起诉窗 `SZ#`。主路径是 `Q-代`，不是 `Q-请`，不是 `Q-诉`，不是 `Q-直`。未书面请求不是已可代位起诉终稿。口头很急不是情况紧急。百分之一持股不是有限公司门槛。被告不是公司自己。胜诉利益不是归原告股东。股东直接损害走第一百九十条，不在本窗写成代表诉讼已成立。公司已就同一事实起诉该格不支持，不是负触发关窗。第一百八十八条是责任基础，不是本窗程序条。全资子公司双重代表是第一百八十九条第四款，不是第三款。1993 年第一百八十九条不是现行代表诉讼条。2018 年第一百五十一条不是 2024 年 7 月 1 日后的现行条号。三十日自收到书面请求之日起算，不是发出日。「把请求日期改到三十日前」整体停止。本窗不执行发送，不代提交。不选定法院。不写诉状。
