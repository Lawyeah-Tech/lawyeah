# 边界与路由

## 正触发

已决定向人民法院提起与公司组织或股东权利有关的一审，需要原告适格、请求类型、被告列法、前置、管辖接口和证据目录。从零、碎片、仲裁未核验、无书面起诉授权仍正触发：有原告适格或请求类型碎片则闸开或半开，出 `SZ#` 草案，保持草案。本次不代提交、不选定法院是交付禁令，不是开窗条件。草稿即已立案、有效仲裁仍应直接起诉、无股东资格仍提撤销，仍正触发。

双方秘密、伪造决议或股东资格材料、倒签起诉状或会议、虚假诉讼、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「草稿即已立案」「有效仲裁仍应直接起诉」「无股东资格仍提撤销」「前置未完成仍写应起诉」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 决议不成立／无效／撤销之诉终稿 | `提起决议不成立无效或撤销之诉` |
| 查阅之诉终稿 | `提起查阅权诉讼` |
| 利润分配之诉终稿 | `提起利润分配之诉` |
| 股东代表诉讼终稿 | `提起股东代表诉讼` |
| 司法解散诉状 | `提起司法解散之诉` |
| 应诉答辩包 | `应对股东权利诉讼` |
| 管辖或仲裁效力评估终稿 | `评估股东争议管辖与仲裁条款` |
| 证据案卷终稿 | `建立公司治理与股东争议证据案卷` |
| 保全申请终稿 | `准备股权或公司财产保全` |
| 已立案后的庭审 | `准备股东与公司治理案件庭审` |
| 投并购交割清单 | 投资并购领域 |
| 劳动解除补偿谈判 | 劳动领域 |
| 合伙或个人独资 | 非公司主体 |

不得因「不代提交」或「不选定法院」关窗。拟起诉包仍正触发，不得写成已立案或应起诉。有效仲裁不是负触发关窗，该格不支持；主成果才是管辖仲裁评估终稿才转。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |
| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「起诉」「立案」「管辖」一词不是转出。

## 易混

本窗闸名只能是起诉闸，禁止复用立案闸。草稿不是已立案。有效仲裁不是应起诉。无股东资格不是可提决议撤销。前置未完成不是可提代表诉讼。决议之诉原则上以公司为被告。代表诉讼胜诉利益归公司。选定某院不是管辖已定。七日立案不是已保证。网交不是已提交。2017 年第一百一十九条不是现行起诉条件。2018 年第二十二条／第一百五十一条不是现行条文。仲裁法 2025 修订施行日 2026-03-01，MCP 标尚未施行时以施行日为准。本窗 `SZ#` 不是案卷窗 `AJ#`，不是退出窗 `TC#`，不是效力窗 `XL#`，不是企业合规诉材行 `QS#`，不是立案行 `LA#`。「今晚把章先拿走」「决议先补一份」整体停止。本窗不执行发送，不代提交。不选定法院。
