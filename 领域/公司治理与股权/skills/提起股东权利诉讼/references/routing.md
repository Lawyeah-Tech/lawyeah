# 边界与路由

## 正触发

已决定向人民法院准备与公司组织或股东权利有关的一审起诉文书，且仲裁未阻挡或已被可回链证据排除。「给我起诉状」仍正触发，保持草案。从零、碎片、前置或管辖未核验仍正触发：有请求或被告则闸开或半开，出 `LA#` 草案。本次不代提交、不选定法院是交付禁令，不是开窗条件。草案即已立案、有效仲裁仍应起诉、选定某院，仍正触发。概括混请求仍正触发。

双方秘密、伪造决议或证据、倒签会议或起诉状、虚假诉讼、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「草案即已立案」「有效仲裁仍应起诉」「选定某院」「网交即已提交」「类案必然立案」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 仅为决议不成立／无效／撤销之诉终稿 | `提起决议不成立无效或撤销之诉` |
| 仅为查阅之诉终稿 | `提起查阅权诉讼` |
| 仅为利润分配之诉终稿 | `提起利润分配之诉` |
| 仅为股东代表诉讼终稿 | `提起股东代表诉讼` |
| 仅为司法解散诉状 | `提起司法解散之诉` |
| 已收到起诉状、实为被告 | `应对股东权利诉讼` |
| 有效仲裁未排除仍要起诉 | `评估股东争议管辖与仲裁条款` |
| 证据案卷终稿 | `建立公司治理与股东争议证据案卷` |
| 保全申请终稿 | `准备股权或公司财产保全` |
| 已有案号或开庭 | `准备股东与公司治理案件庭审` |
| 只要评估总图 | `评估公司治理与股东关系` |
| 劳动、破产、投并购或婚家 | 对应领域 |

不得因「不代提交」或「不选定法院」关窗。拟起诉文书草案仍正触发，不得写成已立案或应起诉。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |
| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「起诉」「立案」「管辖」一词不是转出。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 只要决议之诉专项 | `提起决议不成立无效或撤销之诉` |
| 只要查阅之诉专项 | `提起查阅权诉讼` |
| 只要分配之诉专项 | `提起利润分配之诉` |
| 只要代表诉讼专项 | `提起股东代表诉讼` |
| 只要解散诉状 | `提起司法解散之诉` |
| 只要应诉 | `应对股东权利诉讼` |
| 仲裁或管辖评估 | `评估股东争议管辖与仲裁条款` |
| 保全红旗 | `准备股权或公司财产保全` |

## 易混

草案不是已立案。网交不是已提交。有效仲裁不是应起诉。类案不是必然立案。选定某院不是管辖已定。决议之诉不得漏列公司。代表诉讼利益不归原告个人。无分配决议不是已确定债权。持股不足百分之十不是应解散。2017 年民诉法第一百一十九条不是现行起诉条件。本窗 `LA#` 不是案卷窗 `AJ#`，不是诉材窗 `QS#`，不是起诉闸。本窗立案闸不是人身损害起诉闸。「起诉状日期改成时效没过那天」整体停止。本窗不执行发送，不代提交。不选定法院。
