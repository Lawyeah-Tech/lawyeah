# 提起股东权利诉讼方法

本文件是可执行判断节点。草案不是已立案。网交不是已提交。有效仲裁未排除不是应起诉。类案不是必然立案。不选定唯一法院。不代提交。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已立案、此致某院、唯一必得总额、选定法院、代提交、未知写零。本任务不定罪，不写发送版起诉状。本窗闸名只能是立案闸，禁止复用起诉闸、诉材闸、提交闸、保全闸、案卷闸。本窗 `LA#` 是立案行。英文 id 禁止使用，一律用中文技能名 `提起股东权利诉讼`。伤残等级与本窗无关。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 2017 年民诉法第一百一十九条、旧第二十六条、2018 年公司法条号未核验、把草案写成已立案时记为噪声。禁止指导伪造证据或倒签起诉。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现请求或被告扫描，不是默认闭集。
`LA#` 固定列：`编号｜请求类型｜原告／被告列法｜前置与期限接口｜管辖接口｜证据目录｜起诉状栏目衔接｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。无 `E#` 不得写已提交或已立案。`E#` 只作证据形态回链，不是发送闸。禁止 `P#` 绑定请求。扫描不是闭集。缺项记 `G#`。承认只进 `S#`／`D#`，不得占用 `A#`。

口头「交了就算立案」「某院一定管」「类案一定立」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：网上提交回执不是受理通知。仲裁条款表面有效未排除，法院通常不予受理。决议之诉原则上列公司为被告。代表诉讼利益归公司。撤销之诉起诉时须有股东资格。期限一类一行，禁止合成一个起诉期限。

## 节点 0　分流、立场、立案闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造决议或证据、倒签会议或起诉状、虚假诉讼、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `LA#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果仅为决议之诉终稿 | 负触发 `提起决议不成立无效或撤销之诉` |
| 主成果仅为查阅之诉终稿 | 负触发 `提起查阅权诉讼` |
| 主成果仅为利润分配之诉终稿 | 负触发 `提起利润分配之诉` |
| 主成果仅为代表诉讼终稿 | 负触发 `提起股东代表诉讼` |
| 主成果仅为司法解散诉状 | 负触发 `提起司法解散之诉` |
| 已收到起诉状、实为被告 | 负触发 `应对股东权利诉讼` |
| 仲裁表面有效未排除仍要起诉 | 负触发 `评估股东争议管辖与仲裁条款` |
| 主成果是证据案卷终稿 | 负触发 `建立公司治理与股东争议证据案卷` |
| 主成果是保全申请终稿 | 负触发 `准备股权或公司财产保全` |
| 已有案号或开庭通知 | 负触发 `准备股东与公司治理案件庭审` |
| 劳动／破产／投并购／婚家 | 整案转出 |
| 「不代提交」「不选定法院」 | 交付禁令，不是负触发 |

出现「起诉」「立案」「管辖」一词不是转出。概括混请求留本窗。

立案闸打开（可出 `LA#` 草案，仍不得标「已立案／应起诉／此致某院」）须同时满足：单方无冲突原告立场已闭合；已决定准备一审起诉文书；仲裁未出现或阻挡已被可回链证据排除；至少一项可编号请求碎片或明确被告。口头「交了就算立案」不算单独开闸材料。已有受理凭证或案号：不得继续生成起诉入口终稿。

立案闸部分打开：已有碎片，但资格、前置、管辖或仲裁未闭合；对应格待核；仍交十节。无书面起诉授权但立场已闭合且有碎片：部分打开，不是整体停止。

立案闸关闭（仍正触发）：无一可编号碎片。「今天必须出已立案终稿」而无最小碎片不得开闸。不出 `LA#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `LA#` 终稿，**第 7 节不得出发送版起诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草案即已立案」「有效仲裁仍应起诉」「选定某院」「网交即已提交」「类案必然立案」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `LA#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 立案闸关闭，仍交十节，不是整体停止。
若 if 同时掌握拟起诉股东与公司或对立股东相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造决议或证据、倒签会议或起诉状、虚假诉讼、抢夺印章证照、隐匿账簿、违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体、请求类型与前置期限接口

一行一个请求切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `LA#` 终稿。

| 请求 | 通常被告 | 禁止 |
| --- | --- | --- |
| 决议不成立／无效／撤销 | 公司 | 只列对立股东漏列公司 |
| 查阅 | 公司 | 把查阅写成金钱给付 |
| 分配 | 公司 | 无决议写成已确定债权 |
| 回购 | 公司 | 输出唯一合理价格 |
| 代表诉讼 | 加害董事／第三人，利益归公司 | 写成股东自己的损害赔偿 |
| 人格否认 | 股东或姐妹公司 | 给胜诉率 |
| 司法解散 | 公司 | 持股表决权不足百分之十仍写应解散 |

期限必须分列，禁止合成一个起诉期限：立案审查完备性（不写成必立案截止日）；诉讼时效待核；撤销除斥作出之日起六十日／未被通知六十日＋一年最长；不成立／无效不适用该六十日；失权异议三十日；催缴宽限期不少于六十日；查阅答复十五日；回购六十日协议／九十日起诉／收购后六个月清理；代表诉讼书面请求后三十日或紧急例外；股份公司代表诉讼连续一百八十日持股是资格期间不是起诉时效。日期冲突建并行情景。除斥可能届满则停止终稿，不得倒签起诉。

检索锚点（写入 `L#` 前须核验）：

- 民诉法第一百二十二条起诉条件。噪声：2017 年第一百一十九条。
- 公司组织诉讼常见第二十七条公司住所地。民诉法解释常见第二十二条须核验现行表述。约定地、侵权连结点并列。不选定唯一法院。
- 仲裁法常见第五条：有仲裁协议起诉不予受理，但协议无效除外。口头同意去法院、聊天已读不单独排除。
- 公司法第二十六条、第一百八十九条、第八十九条、第五十七条、第二百三十一条，条号写入 `L#` 前须核验全文。

## 节点 3　立案行 `LA#`

按已出现请求扫描，不是默认闭集。每条须能指向请求类型、原被告、前置期限和管辖接口。

无 `E#` 不得写已提交或已立案。状态默认 `草案`。一次只推荐下一步。未知金额不写零。证据目录绑待证事实，禁止 `P#`。仲裁未排除：该 `LA#` 不得标可执行终稿。前置未闭合且无紧急事实：该格停止或待核。

热冲突强制处理：

- 草案即已立案／有效仲裁仍应起诉／选定某院／网交即已提交／类案必然立案／未知写零 → 该格不支持或字段停止；仍出其他 `LA#`。
- 无一碎片 → 关闸，不出 `LA#` 终稿，窗口不关。
- 指导伪造证据、倒签起诉、虚假诉讼 → 整体停止，不是该格不支持。

## 节点 4　专项之诉、应诉、仲裁、保全与案卷接口

第 7 节只开接口，不得夹带 `LA#` 终稿或发送版起诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待请求／被告编号」，不得补写已立案。保全只做红旗，转 `准备股权或公司财产保全`。案卷转 `建立公司治理与股东争议证据案卷`。C 端网上立案只分流。不代提交。不保证立案。不选定法院。

下一步只转介：`应对股东权利诉讼`、`评估股东争议管辖与仲裁条款`、各专项提起原子、`建立公司治理与股东争议证据案卷`、`准备股权或公司财产保全`、`准备股东与公司治理案件庭审`。禁止此致某法院。不选定法院。不代提交。

若 if 用户催促「交了就算立案／去某院／类案一定立／金额先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「立案闸与起诉文书草案」。本窗不执行发送，不代提交。不包含：已立案证明、发送版起诉状、专项之诉终稿、答辩。禁止选边治愈。禁止草案即已立案。禁止有效仲裁仍应起诉。禁止指导伪造证据。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标起诉终稿已形成。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：有限公司小股东要「直接起诉、保证某区法院立案」。章程仲裁待核、决议之诉只告大股东、未分红写成已确定债权、代表诉讼赔偿给自己、金额先写零、保全红旗当申请终稿。立案闸打开或半开。`Q-仲`、`Q-院`、`Q-交`、`Q-零` 不打开为可靠路径。对应格不支持；仍出其他 `LA#` 草案与连结点并列。不关窗。不代提交。不选定法院。

场景②：用户同时交出公司「从未开会」与对立股东「会议合法召开」口径，要求选对原告有利的一版并指导倒签会议、伪造起诉材料或抢章。命中双方秘密＋伪造／抢章。第一次整体停止。只交第 1、10 节。不出 `LA#`。不得问代表哪一方后继续。不以「坚持」为门槛。
