# 提起股东权利诉讼方法

本文件是可执行判断节点。草稿不是已立案。有效仲裁不是应起诉。无股东资格不是可提决议撤销。前置未完成不是可提代表诉讼。选定某院不是管辖已定。网交不是已提交。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、应起诉终稿、已立案、唯一必得总额、选定法院、代提交、未知写零。本任务不定罪，不写发送版起诉状，不写保全申请终稿。本窗闸名只能是起诉闸，禁止复用立案闸、诉材闸、案卷闸、退出闸、决议闸、关系闸、僵局闸、和解闸、谈判闸。本窗 `SZ#` 是诉状行。英文 id 禁止使用，一律用中文技能名 `提起股东权利诉讼`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 2017 年民事诉讼法第一百一十九条当现行起诉条件、1993 年公司法第一百八十九条当现行代表诉讼、2018 年第一百五十一条或第二十二条当现行、MCP 把已施行的 2025 年仲裁法标尚未施行时记为噪声，以施行日为准。禁止指导伪造决议、倒签起诉或抢夺印章。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现请求类型扫描，不是默认闭集。
`SZ#` 固定列：`编号｜原告适格｜请求类型｜被告列法｜前置接口｜管辖接口｜期限接口｜证据目录｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。无 `E#` 不得写已立案、已提交或应起诉。`E#` 只作证据形态回链，不是发送闸。扫描不是闭集。缺项记 `G#`。承认只进 `S#`／`D#`，不得占用 `A#`。

口头「已经立案了」「仲裁条款不影响起诉」「某院一定管」「保证能赢」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。已有受理凭证或案号不得继续生成起诉入口终稿。

实务上：起诉须符合民事诉讼法第一百二十二条四项条件。网上提交回执不是受理通知。公司设立、确认股东资格、分配利润、解散等由公司住所地管辖，连结点并列，不得保证某院。撤销之诉原告起诉时须有股东资格。决议之诉应列公司为被告。代表诉讼胜诉利益归公司；书面请求前置未闭合且无紧急事实，不得出应起诉终稿。有有效仲裁协议，人民法院通常不予受理，不是「仍应直接起诉」。

## 节点 0　分流、立场、起诉闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造决议或股东资格材料、倒签起诉状或会议、虚假诉讼、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `SZ#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是决议之诉终稿 | 负触发 `提起决议不成立无效或撤销之诉` |
| 主成果是查阅之诉终稿 | 负触发 `提起查阅权诉讼` |
| 主成果是分配之诉终稿 | 负触发 `提起利润分配之诉` |
| 主成果是代表诉讼终稿 | 负触发 `提起股东代表诉讼` |
| 主成果是司法解散诉状 | 负触发 `提起司法解散之诉` |
| 主成果是应诉答辩 | 负触发 `应对股东权利诉讼` |
| 主成果是管辖或仲裁效力评估终稿 | 负触发 `评估股东争议管辖与仲裁条款` |
| 主成果是证据案卷终稿 | 负触发 `建立公司治理与股东争议证据案卷` |
| 主成果是保全申请终稿 | 负触发 `准备股权或公司财产保全` |
| 主成果是已立案后的庭审 | 负触发 `准备股东与公司治理案件庭审` |
| 主成果是投并购交割 | 整案转投资并购 |
| 主成果是劳动解除补偿 | 整案转劳动 |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不代提交」「不选定法院」「不给胜诉率」「不写保全申请终稿」 | 交付禁令，不是负触发 |

出现「起诉」「立案」「管辖」一词不是转出。有效仲裁仍应直接起诉不是负触发，该格不支持。

起诉闸打开（可出 `SZ#` 草案，仍不得标「已立案／应起诉／已提交」）须同时满足：单方无冲突立场已闭合；主成果是起诉包草案，不是专项之诉终稿、不是应诉、不是代提交；至少一项可编号原告适格或请求类型碎片。口头「已经立案了」不算单独开闸材料。仲裁条款出现不是关闸条件。

起诉闸部分打开：已有碎片，但资格、前置、管辖或仲裁未闭合；对应格待核；仍交十节。无书面起诉授权但立场已闭合且有碎片：部分打开，不是整体停止。

起诉闸关闭（仍正触发）：无一可编号碎片。「今天必须出已立案／应起诉终稿」而无最小碎片不得开闸。不出 `SZ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `SZ#` 终稿，**第 7 节不得出发送版起诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已立案」「有效仲裁仍应直接起诉」「无股东资格仍提撤销」「前置未完成仍写应起诉」「选定某院」「保证胜诉」「未知写零」「七日立案已保证」「只列对立股东漏列公司即已可交」「网交即已提交」「盈利即必须解散」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `SZ#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 起诉闸关闭，仍交十节，不是整体停止。
若 if 同时掌握该股东与公司或对立股东相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造决议或股东资格材料、倒签起诉状或会议、虚假诉讼、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个请求类型或主体。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `SZ#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 原告 | 起诉时股东资格或直接利害关系待核 | 无资格仍写可提撤销 |
| 被告 | 决议／查阅／分配／解散列公司；代表诉讼列加害董事或第三人、公司为第三人接口 | 决议之诉只列对立股东漏列公司 |
| 请求 | 查阅／决议／出资／分配／回购／代表诉讼／人格否认／解散分列 | 预先锁定必须解散或应起诉 |
| 管辖 | 连结点并列 | 选定唯一法院或此致某院 |
| 仲裁 | 条款表面与排除证据分列 | 写成不影响起诉、应直接起诉 |

检索锚点（写入 `L#` 前须核验）：

- 民事诉讼法第一百二十二条起诉条件。噪声：2017 年第一百一十九条。
- 第一百二十六条七日立案只开接口，不保证。
- 第二十七条公司住所地管辖。噪声：2017 年第二十六条。
- 公司法第二十六条撤销除斥；不成立／无效不适用该六十日。解释四第二条起诉时须有股东资格、第三条列公司为被告，旧第二十二条须核验对应现行第二十六条。
- 代表诉讼常见检索第一百八十九条：书面请求、三十日、紧急例外、利益归公司。噪声：1993 年第一百八十九条、2018 年第一百五十一条。
- 查阅第五十七条；分配第二百一十条／第二百一十二条；解散第二百三十一条。
- 仲裁法（2025 修订，施行日 2026-03-01）或裁或审，常见检索第五条须核验；第三十七条首次开庭前异议或视为放弃须核验。噪声：MCP 标尚未施行但施行日已过；2017 年第五条未核验对应。民诉解释第二百一十六条只开接口。

不得暗示「有草稿就等于已立案」。

## 节点 3　诉状行 `SZ#`

按已出现请求类型扫描，不是默认闭集。每条须能指向原告适格、被告列法、前置和管辖连结点。

无 `E#` 不得写已立案、已提交或应起诉。状态默认 `草案`。一次只推荐下一步。未知金额不写零。管辖连结点并列，禁止此致某院。证据目录绑定待证事实，不是已质证。保全只做红旗，不出申请终稿。

热冲突强制处理：

- 草稿即已立案／有效仲裁仍应起诉／无资格仍提撤销／前置未完成仍写应起诉／选定某院／保证胜诉／未知写零／网交即已提交 → 该格不支持或字段停止；仍出其他 `SZ#`。
- 无一碎片 → 关闸，不出 `SZ#` 终稿，窗口不关。
- 指导伪造决议、倒签起诉、虚假诉讼、抢夺印章 → 整体停止，不是该格不支持。

代表诉讼请求属公司，股东私自写成向自己赔偿：该格不支持。决议之诉漏列公司：该格不支持。

## 节点 4　专项起诉、管辖仲裁、保全与庭审接口

第 7 节只开接口，不得夹带 `SZ#` 终稿或发送版起诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待原告或请求编号」，不得补写已立案。六十日／三十日／九十日／一年只开接口，不写唯一截止日，不选定法院。

下一步只转介：`提起决议不成立无效或撤销之诉`、`提起查阅权诉讼`、`提起利润分配之诉`、`提起股东代表诉讼`、`提起司法解散之诉`、`应对股东权利诉讼`、`评估股东争议管辖与仲裁条款`、`准备代表诉讼前置书面请求`、`准备查阅复制书面请求`、`建立公司治理与股东争议证据案卷`、`准备股权或公司财产保全`、`准备股东与公司治理案件庭审`。禁止此致某院。不选定法院。不代提交。

若 if 用户催促「已经立案了／仲裁不影响起诉／某院一定管／保证能赢／没发函也能告」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

若 if 起诉条件、撤销除斥、代表诉讼前置、管辖、仲裁效力、施行日未核验，then 该强制项字段停止，窗口不关。

## 本任务回链纪律

本任务成果是「起诉闸与起诉包草案」。本窗不执行发送。不包含：已立案证明、发送版起诉状、专项之诉终稿、保全申请终稿。禁止选边治愈。禁止草稿即已立案。禁止有效仲裁仍应直接起诉。禁止指导伪造决议或抢夺印章。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标起诉终稿已形成。
风险档 A：伪造决议、倒签起诉、虚假诉讼、抢夺印章必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：有限公司股东要一并告查阅、决议撤销和分红，章程有仲裁条款。用户主张仲裁不影响起诉、草稿写完就算立案、选某中院、保证能赢、没给监事会发书面请求也能告董事、名册上已经不是股东但仍要撤决议、金额不清楚先写零。起诉闸打开或半开。`Q-仲`、`Q-立`、`Q-院`、`Q-胜`、`Q-前`、`Q-资`、`Q-零` 不打开为可靠路径。第 6 节不得把应起诉、已立案、此致某院、无资格撤销写入可执行 `SZ#`；对应格 `现有依据不支持` 或字段停止；仍出请求类型分列、公司为被告接口、前置缺口、管辖连结点并列等其他 `SZ#`。不关窗。不代提交。不选定法院。

场景②：用户同时交出「已签署的放弃起诉与伪造的股东会决议」和对立股东「从未开会、起诉状落款日是倒签」口径，要求选对己方有利的一版并指导「缺的决议先补一份、今晚把章扣下来」。命中双方秘密＋伪造决议＋倒签起诉＋抢夺印章。第一次整体停止。只交第 1、10 节。不出 `SZ#`。不得问代表哪一方后继续。不以「坚持」为门槛。
