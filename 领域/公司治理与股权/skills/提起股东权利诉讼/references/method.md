# 起诉方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、论坛、期限、金额或文书状态的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然无效、必然失权、必然解散或唯一必得总额。

`search_law` 返回已失效《合同法》、1993／2004／2013／2018《公司法》或仍引用旧第二十二条、第三十三条、第七十一条且未核验对应关系的司法解释时，记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

---

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 以股权或资产收购、投资交割、尽调闭环为主要目标 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果、员工激励的劳动身份 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂、综合合规体系 | 企业合规领域 |
| 破产申请、重整计划、破产债权申报与分配 | 破产领域 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 合伙企业、个人独资的入伙退伙 | 非公司主体，不在本领域 |
| 上市公司发行、持续信息披露或证券监管主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

混合信号：公司组织或股东关系主轴可留本任务；专项只作为背景时在缺口标明，不把专项规则硬套进本领域结论。

---
## 节点 1　分流与仲裁闸

1. 劳动、破产、婚家分割、投并购交割整案转出。
2. 章程或股东协议出现仲裁条款：不得直接写应起诉。表面有效且未排除则负触发。
3. 已有受理凭证或案号：停止生成起诉入口材料。
4. 决议之诉、查阅之诉、利润分配之诉、代表诉讼、司法解散已有专项且用户只要该专项终稿：可转介；未安装则本任务承接并标明请求类型。

---

## 节点 2　请求与当事人

| 请求 | 通常被告 | 禁止 |
| --- | --- | --- |
| 决议不成立／无效／撤销 | 公司 | 只列对立股东漏列公司 |
| 查阅 | 公司 | 把查阅写成金钱给付 |
| 出资催缴或补充责任 | 股东及依法连带主体 | 把未届期无加速事由写成已到期 |
| 分配 | 公司 | 无决议却写成已确定债权（例外待核） |
| 回购 | 公司 | 输出唯一合理价格 |
| 代表诉讼 | 加害董事／第三人，利益归公司 | 写成股东自己的损害赔偿 |
| 人格否认 | 股东或姐妹公司 | 给胜诉率 |
| 司法解散 | 公司 | 持股表决权不足百分之十仍写应解散 |

撤销之诉原告须在起诉时具有股东资格。代表诉讼核验第一百八十九条持股、书面请求和全资子公司规则。

---

## 节点 3　前置与期限

1. 代表诉讼：书面请求监事会或董事会，拒绝或三十日未起诉，或情况紧急。未闭合且无紧急事实：目标停止，转前置请求原子（未安装则本任务只列缺口，不出诉状终稿）。
2. 决议撤销除斥可能届满：字段停止或判断不支持，不得赶写倒签起诉。
3. 回购：决议作出六十日未达成协议，九十日内起诉。日期冲突并行情景。

---

## 节点 4　管辖、证据、保全

管辖连结点材料不足时不选定唯一法院。证据目录绑定 `P#` 请求。保全只做红旗，不写申请终稿。

---

## 节点 5　草稿与提交

按起诉状法定事项组织草稿。不代提交，不保证立案。C 端 011 只分流，本任务不降成大众立案包。
