# 边界与路由

## 正触发

要选法院还是仲裁，或章程、股东协议、转让协议出现仲裁或管辖条款。从零、碎片、签署人未核验、无书面评估授权仍正触发：有可编号条款或连结点碎片则闸开或半开，出 `XG#` 草案，保持草案。本次不选定法院、不代立案、不代写完整立案包是交付禁令，不是开窗条件。评估即已选定法院、仲裁条款当然有效、未签署股东亦受仲裁约束，仍正触发。

双方秘密、伪造仲裁协议、倒签签署日、抢夺印章、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。不选定法院不是负触发。「评估即已选定法院」「仲裁条款当然有效」「未签署股东亦受仲裁约束」「公司诉讼一律专属」「劳动仲裁前置套股东资格」「有效仲裁仍应直接起诉」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 起诉包 | `提起股东权利诉讼` |
| 上诉状 | `提起公司治理案件上诉` |
| 保全申请 | `准备股权或公司财产保全` |
| 首次答辩或异议书唯一成果 | `应对股东权利诉讼` |
| 庭审提纲 | `准备股东与公司治理案件庭审` |
| 起草章程争议解决条款 | `起草或修订公司章程` |
| 起草股东协议争议解决条款 | `起草股东协议与一致行动安排` |
| 劳动或破产主轴 | 对应领域 |
| 合伙或个人独资 | 非公司主体 |

不得因「不选定法院」「不代立案」或「不代写完整立案包」关窗。拟论坛评估仍正触发，不得写成已选定法院或应起诉。

## 易混

本窗闸名只能是管辖闸，不是起诉闸，不是答辩闸，不是庭审闸，不是上诉闸。`XG#` 不是 `SZ#`，不是 `SS#`，不是 `TS#`，不是 `DB#`，不是 `GX#`。主路径是 `Q-管`，不是 `Q-诉`，不是 `Q-上`。`Q-管` 在邻窗是转介码，本窗打开为主路径。评估不是已选定法院。仲裁条款不是当然有效。章程仲裁条款不是未签署股东已拘束。公司诉讼不是一律专属管辖。民诉第二十七条不是专属管辖。2017 年第二十六条不是现行第二十七条。2017 年第一百二十七条不是现行第一百三十条。仲裁法 2025 修订施行日 2026-03-01，MCP 标尚未施行以施行日为准。「把签署日改到入股前」整体停止。本窗不执行发送，不代立案，不代提交。不选定法院。不保证立案。
