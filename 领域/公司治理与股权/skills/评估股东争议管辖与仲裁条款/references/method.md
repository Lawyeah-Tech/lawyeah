# 评估股东争议管辖与仲裁条款方法

本文件是可执行判断节点。评估不是已选定法院。仲裁条款不是当然有效。章程仲裁条款对未签署股东待核。公司诉讼不是一律专属管辖。劳动仲裁前置不是股东资格前置。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已选定法院、应起诉终稿、选定法院、代立案、代提交、未知写零。本任务不定罪，不执行发送，不保证立案。本窗闸名只能是管辖闸，禁止复用起诉闸、答辩闸、庭审闸、上诉闸、案卷闸、和解闸、谈判闸、协议闸。预留不得占用：立案闸、保全闸。本窗 `XG#` 是管辖行。主路径只用 `Q-管`，禁止用 `Q-诉`、`Q-上`、`Q-审`、`Q-庭`、`Q-辩` 作主路径。本窗 `Q-签` 只作「评估即已选定法院」不关窗码。英文 id 禁止使用，一律用中文技能名 `评估股东争议管辖与仲裁条款`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 2017 年民诉第二十六条当现行第二十七条、2017 年第一百二十七条当现行第一百三十条、把 2017 年仲裁法未核对应写成现行、把 MCP「尚未施行」压过 2026-03-01 施行日、把第二十七条写成专属管辖、把劳动仲裁前置套公司诉讼时记为噪声。禁止指导伪造仲裁协议或倒签签署日。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现条款或连结点扫描，不是默认闭集。
`XG#` 固定列：`编号｜条款切片｜书面合意与覆盖｜机构可确定性｜可仲裁性接口｜连结点与异议期｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已选定法院」或「条款当然有效」。无 `E#` 不得写已选定或已排除。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-管`。禁止 `SZ#`、`SS#`、`TS#`、`DB#`、`GX#`、`A#`、`N#`。文件状态只用 `草案`、`待签署`、`停止`。书面合意、事项覆盖或连结点未闭合不得标 `待签署`。

口头「就在北京打」「某院一定管」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。章程／股东协议／转让协议冲突并列，不得选对用户有利的一版冒充唯一论坛。

实务上：仲裁条款通常限于签署人。解散等组织法请求仲裁机构可能无权仲裁。公司住所地是特殊地域管辖接口，不是当然专属。应诉答辩可能构成应诉管辖，只开风险接口。

## 节点 0　分流、立场、管辖闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造仲裁协议、倒签签署日、抢夺印章、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。不选定法院、不代立案不是负触发。

整案转出只交付第 1、2、10 节，不出 `XG#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是起诉包 | 负触发 `提起股东权利诉讼` |
| 主成果是上诉状 | 负触发 `提起公司治理案件上诉` |
| 主成果是保全申请 | 负触发 `准备股权或公司财产保全` |
| 主成果是首次答辩或异议书唯一成果 | 负触发 `应对股东权利诉讼` |
| 主成果是庭审提纲 | 负触发 `准备股东与公司治理案件庭审` |
| 主成果是起草章程争议解决条款 | 负触发 `起草或修订公司章程` |
| 主成果是起草股东协议争议解决条款 | 负触发 `起草股东协议与一致行动安排` |
| 劳动或破产主轴 | 整案转出对应领域 |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不选定法院」「不代立案」 | 交付禁令，不是负触发 |

出现「管辖」「仲裁」「立案」一词不是转出。

管辖闸打开（可出 `XG#` 草案，仍不得标「已选定法院／条款当然有效／已立案」）须同时满足：单方无冲突立场已闭合；主成果是论坛评估草案，不是起诉包、不是上诉状、不是保全申请；至少一项可编号争议解决条款或连结点碎片。口头「就在北京打」不算单独开闸材料。

管辖闸部分打开：已有碎片，但书面合意、事项覆盖、机构、可仲裁性或异议时点未闭合；对应格待核；仍交十节。无书面评估授权但单方立场已闭合且已有碎片：管辖闸部分打开，仍交十节，不是整体停止。

管辖闸关闭（仍正触发）：无一可编号碎片。「今天必须出此致某院终稿」而无最小碎片不得开闸。不出 `XG#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `XG#` 终稿，**第 7 节不得出立案包或应起诉终稿**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「评估即已选定法院」「仲裁条款当然有效」「未签署股东亦受仲裁约束」「公司诉讼一律专属」「劳动仲裁前置套股东资格」「有效仲裁仍应直接起诉」「保证立案」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `XG#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 管辖闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造仲裁协议、倒签签署日、抢夺印章、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个条款切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `XG#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 文本 | 章程／股东协议／转让协议冲突并列 | 选对用户有利的一版冒充唯一论坛 |
| 签署人 | 拟签署人／未签署股东／后加入股东分列 | 未签署股东亦受仲裁约束 |
| 请求类型 | 价款／资格／决议／查阅／分配／解散分列 | 一律能裁或一律不能裁 |
| 机构 | 约定机构能否确定 | 或裁或诉、机构不明仍当然有效 |
| 连结点 | 公司住所地与约定地并列 | 此致某院 |
| 异议 | 答辩期间／首次开庭前分列 | 已读即应诉管辖 |

检索锚点（写入 `L#` 前须核验）：

- 民事诉讼法（2023 修正，施行日 2024-01-01）第二十七条公司住所地管辖，是特殊地域管辖接口，不是当然专属。噪声：2017 年第二十六条。
- 第一百三十条管辖异议在提交答辩状期间提出；应诉答辩或反诉视为受诉法院有管辖权，级别管辖和专属管辖除外。噪声：2017 年第一百二十七条。
- 仲裁法（2025 修订，施行日 2026-03-01）第三条可仲裁范围；第四条无协议不受理；第五条或裁或审；第三十七条首次开庭前异议或视为放弃。MCP 标尚未施行以施行日为准。噪声：2017 年仲裁法条号未核对应。

## 节点 3　管辖行 `XG#`

按已出现条款或连结点扫描，不是默认闭集。每条须能指向文本、签署人或连结点之一。

无 `E#` 不得写已选定或已排除。状态默认 `草案`。一次只推荐下一步。未知不写零，不选定法院。书面合意、事项覆盖或连结点未闭合不得标 `待签署`。

热冲突强制处理：

- 评估即已选定法院／仲裁条款当然有效／未签署股东亦受约束／一律专属／劳动前置套股东资格／有效仍应直接起诉／未知写零 → 该格不支持或字段停止；仍出其他 `XG#`。
- 无一碎片 → 关闸，不出 `XG#` 终稿，窗口不关。
- 指导伪造仲裁协议、倒签签署日 → 整体停止，不是该格不支持。

## 节点 4　起诉、上诉、保全与起草接口

第 7 节只开接口，不得夹带 `XG#` 终稿或此致某院绕闸。闸关闭时第 7 节可写「闸未开，转介待评估碎片编号」，不得补写已选定。不选定法院。不代立案。不代提交。

下一步只转介：`提起股东权利诉讼`、`应对股东权利诉讼`、`提起公司治理案件上诉`、`准备股东与公司治理案件庭审`、`准备股权或公司财产保全`、`起草或修订公司章程`、`起草股东协议与一致行动安排`。禁止此致某院。

若 if 用户催促「评估完就算某院管了／章程写了就算全体受仲裁／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）
