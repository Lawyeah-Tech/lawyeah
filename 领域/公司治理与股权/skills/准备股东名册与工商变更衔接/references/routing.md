# 边界与路由

## 正触发

已发生转让、继承或增资，公司拒不记载名册或不办理变更登记，需要发送前记载请求和登记衔接。从零、碎片、名册未核验、无书面请求授权仍正触发：有可编号受让人或记载请求碎片则闸开或半开，出 `MC#` 草案，保持草案。本次不代提交、不把未记载写成已取得完整股东资格是交付禁令，不是开窗条件。草稿即已记载、登记完成即对内唯一时点、未记载即权利消灭、名册即已对外对抗、回执即已变更登记，仍正触发。无基础变动文书：闸关仍交十节，不是负触发，也不是整体停止。

双方秘密、伪造名册或出资证明、倒签记载、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「草稿即已记载」「登记完成即对内唯一时点」「未记载即权利消灭」「名册即已对外对抗」「回执即已变更登记」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 继承权属本身尚未确定 | 婚家领域 |
| 转让协议终稿 | `准备有限公司股权内部转让` |
| 优先购买成立终局 | `评估优先购买权是否成立` |
| 股权结构图 | `梳理股权结构与控制权` |
| 代持显名终局 | `评估股权代持效力与显名` |
| 股东权利诉讼诉状 | `提起股东权利诉讼` |
| 投并购交割清单主轴 | 投资并购领域 |
| 合伙或个人独资 | 非公司主体 |

不得因「不代提交」或「不把未记载写成已取得完整股东资格」关窗。拟记载请求草稿仍正触发，不得写成已记载或已变更登记。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |

| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「名册」「变更登记」「记载」一词不是转出。

## 易混

本窗闸名只能是名册闸。`MC#` 不是转让窗 `ZR#`，不是结构窗 `GQ#`，不是任免窗 `RM#`。记载请求草稿不是已记载名册。登记完成不是对内股东权已取得的唯一时点。未记载不是权利已消灭。名册记载不是对外对抗已完成。网交回执不是已变更登记。现行转让后改名册是第八十七条，不是第八十六条。1993 年第五十六条工会意见不是现行名册条。解释三仍引旧第三十一条、第三十二条，须核验对应现行。「记载日期改到签约当天」整体停止。本窗不执行发送，不代提交。不选定法院。
