# 准备股东名册与工商变更衔接方法

本文件是可执行判断节点。记载请求草稿不是已记载名册。登记完成不是对内股东权已取得的唯一时点。未记载不是权利已消灭。名册记载不是对外对抗已完成。网交回执不是已变更登记。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已记载、已变更登记、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不代提交登记。本窗闸名只能是名册闸，禁止复用转让闸、结构闸、任免闸、登记闸。预留不得占用：僵局闸、谈判闸、和解闸、立案闸。本窗 `MC#` 是名册行。禁止占用转让窗 `ZR#`、结构窗 `GQ#`、任免窗 `RM#`。英文 id 禁止使用，一律用中文技能名 `准备股东名册与工商变更衔接`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年第五十六条工会意见当现行名册、把转让后改名册写成第八十六条、解释三仍引旧第三十一条第三十二条未核验对应、把草稿写成已记载时记为噪声。禁止指导伪造名册或倒签记载。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现受让人或记载请求扫描，不是默认闭集。
`MC#` 固定列：`编号｜基础变动｜记载请求｜登记对抗接口｜权利起算｜拒绝抗辩接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已记载」或「已变更登记」。无 `E#` 不得写已记载。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-册`。禁止 `ZR#`、`GQ#`、`RM#`、`A#`、`N#`。文件状态只用 `草案`、`待发送`、`停止`。基础变动未闭合不得标 `待发送`。

口头「请求发出去就算记上了」「工商办完才算股东」「没上名册就没权利」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：名册侧重对内主张，登记侧重对外对抗，二者均非唯一设权。未记载不得写成权利已消灭，尤其公司恶意拒绝时。未记载也不得写成已经取得可对抗公司的完整股东资格。工商登记有相对优先的外观，但不具决定性。不代提交登记。

## 节点 0　分流、立场、名册闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造名册或出资证明、倒签记载、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `MC#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是继承权属本身 | 负触发并整案转婚家 |
| 主成果是转让协议终稿 | 负触发 `准备有限公司股权内部转让` |
| 主成果是优先购买成立终局 | 负触发 `评估优先购买权是否成立` |
| 主成果是股权结构图 | 负触发 `梳理股权结构与控制权` |
| 主成果是代持显名终局 | 负触发 `评估股权代持效力与显名` |
| 主成果是股东权利诉讼诉状 | 负触发 `提起股东权利诉讼` |
| 投并购交割清单主轴 | 整案转投资并购 |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不代提交」「不把未记载写成已取得完整股东资格」 | 交付禁令，不是负触发 |

出现「名册」「变更登记」「记载」一词不是转出。无基础变动文书：名册闸关闭，仍交十节，不是整体停止。

名册闸打开（可出 `MC#` 草案，仍不得标「已记载／已变更登记／已取得完整股东资格」）须同时满足：单方无冲突立场已闭合；主成果是记载请求草稿，不是转让终稿、不是继承权属终局；至少一项可编号受让人或记载请求碎片。口头「请求发出去就算记上了」不算单独开闸材料。

名册闸部分打开：已有碎片，但基础变动或拒绝理由未闭合；对应格待核；仍交十节。

名册闸关闭（仍正触发）：无一可编号碎片。「今天必须出已记载终稿」而无最小碎片不得开闸。不出 `MC#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `MC#` 终稿，**第 7 节不得出已记载或已变更登记**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已记载」「登记完成即对内唯一时点」「未记载即权利消灭」「名册即已对外对抗」「回执即已变更登记」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `MC#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 名册闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与对立股东相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造名册或出资证明、倒签记载、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个基础变动或记载请求。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `MC#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 基础 | 转让／增资／继承分列 | 继承权属未定仍写成已可记载 |
| 名册 | 现记载、拟记载分列 | 草稿升格已记载 |
| 登记 | 现登记、拟变更分列 | 回执升格已变更登记 |
| 起算 | 对内名册／对外登记分列 | 登记完成写成对内唯一时点 |

检索锚点（写入 `L#` 前须核验）：

- 有限股东名册常见检索第五十六条须核验全文：置备股东名册；记载于股东名册的股东可以依股东名册主张行使股东权利。噪声：1993 年第五十六条工会意见。
- 第八十七条：依照本法转让股权后，公司应当及时注销原出资证明书、向新股东签发，并相应修改章程和股东名册；对公司章程该项修改不需再由股东会表决。噪声：写成第八十六条。
- 第三十四条：登记事项发生变更应当依法办理变更登记；未经登记或未经变更登记不得对抗善意相对人。
- 解释三第二十三条仍引旧第三十一条、第三十二条，须核验对应现行名册与登记条；核验失败字段停止。
- 股份名册第一百零二条不得未核验套有限。
- 失效的公司登记管理条例不得当现行。

继承权属本身转婚家；本任务只在权属已可回链时做名册接口。

## 节点 3　名册行 `MC#`

按已出现受让人或记载请求扫描，不是默认闭集。每条须能指向基础变动和记载或登记接口。

无 `E#` 不得写已记载。状态默认 `草案`。一次只推荐下一步。公司拒绝记载：出书面请求草稿，状态不得标已记载。不代提交登记。完整起诉包转 `提起股东权利诉讼`。

热冲突强制处理：

- 草稿即已记载／登记完成即对内唯一时点／未记载即权利消灭／名册即已对外对抗／回执即已变更登记／未知写零 → 该格不支持或字段停止；仍出其他 `MC#`。
- 无一碎片 → 关闸，不出 `MC#` 终稿，窗口不关。
- 指导伪造名册、倒签记载 → 整体停止，不是该格不支持。

对内主张分红、表决、查阅：名册记载是重要依据，未记载且公司恶意拒绝时不得写成权利已消灭。对外对抗：登记外观分列。

## 节点 4　转让、优先购买、结构与诉讼接口

第 7 节只开接口，不得夹带 `MC#` 终稿、已记载结论或起诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待受让人或记载编号」，不得补写已记载。不选定法院。不代提交。不执行发送。

下一步只转介：`准备有限公司股权内部转让`、`评估优先购买权是否成立`、`梳理股权结构与控制权`、`评估股权代持效力与显名`、`提起股东权利诉讼`。禁止此致某登记机关。

若 if 用户催促「请求发出去就算记上了／工商办完才算股东／没上名册就没权利」，then 该格 `现有依据不支持`，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「名册闸与名册行草案」。本窗不执行发送。不包含：已记载名册、已变更登记、继承权属终局、转让协议终稿。禁止选边治愈。禁止草稿即已记载。禁止登记完成即对内唯一时点。禁止未记载即权利消灭。禁止指导伪造名册。名册闸打开 ≠ 已记载 ≠ 已变更登记 ≠ 对内股东权已取得。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标名册终稿已形成。
风险档 A：伪造名册、倒签记载必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：股权转让协议已签，公司拒不改名册、也未办变更登记。用户主张请求函发出去就算记上了、没上名册权利就灭了、工商办完才算股东、网交回执就是已变更。名册闸打开或半开。`Q-记`、`Q-灭`、`Q-登`、`Q-核` 不打开为可靠路径。第 6 节不得把已记载、权利已消灭、已变更登记写入可执行 `MC#`；对应格 `现有依据不支持`；仍出基础变动、现名册、拒绝理由等其他 `MC#`。不关窗。不代提交。

场景②：用户同时交出公司「名册已改到买方」与对立股东「记载是后补倒签」口径，要求选对受让人有利的一版，并指导「把记载日期改到签约当天」。命中双方秘密＋伪造名册＋倒签记载。第一次整体停止。只交第 1、10 节。不出 `MC#`。不得问代表哪一方后继续。不以「坚持」为门槛。
