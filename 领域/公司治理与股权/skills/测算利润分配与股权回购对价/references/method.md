# 测算利润分配与股权回购对价方法

本文件是可执行判断节点。公司很赚钱不是已有可分配利润。无分配决议不是已确定到期债权。认缴比例不是分配比例。六个月执行期不是请求已成立。未知不写零。不输出唯一必得总额。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。金额状态只用 `已核实金额`、`情景金额`、`无法估计`。禁止胜诉率、已确定给付、唯一必得价、选定法院、代提交、未知写零。本任务不定罪，不写诉状。本窗闸名只能是测算闸，禁止复用分配闸、回购闸、关系闸、瑕疵闸、转让闸、召集闸。本窗测算闸不是合规追偿测算闸；主行只能是 `DJ#`，禁止 `M#`、`EVT#`。本窗 `DJ#` 是对价行。伤残等级与本窗无关，禁止折进可分配利润或回购对价。英文 id 禁止使用，一律用中文技能名 `测算利润分配与股权回购对价`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年公司法第二百一十条擅自发行股票、第二百一十一条另立账册、把六个月执行期误写入第二百一十条、把未决议利润写成到期债权时记为噪声。禁止指导伪造报表或倒签分配决议。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事件扫描，不是默认闭集。
`DJ#` 固定列：`编号｜事件切片｜分配接口｜回购接口｜金额状态｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。无 `E#` 不得写已核实金额。`E#` 只作证据形态回链，不是发送闸。扫描不是闭集。缺项记 `G#`。承认只进 `S#`／`D#`，不得占用 `A#`。真实零必须有肯定来源。

口头「公司很赚钱」「市场价保底」「给我一个法院会支持的数」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：未作出分配决议前，不宜把起诉请求写成已确定给付之债。解释四第十五条：股东未提交载明具体分配方案的股东会决议而请求分配的，一般应驳回；滥权不分给其他股东造成损失的例外只开接口、待核，不得在本窗测算强制分配必得额。决议作出且方案具体的，请求权可转为普通债权，本窗只开接口，不认定请求已成立。回购合理价格用净资产、评估、近期转让、盈利能力等参数，禁止输出法院必支持的单点价格。未审计报表不得升格已核实金额。两套账、税务账与管理账冲突必须并列，金额用情景或无法估计，不得选对用户有利的一版；单纯账册冲突不是整体停止。

## 节点 0　分流、立场、测算闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造报表、倒签分配决议、伪造评估、抢夺印章、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `DJ#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是关系总图 | 负触发 `评估公司治理与股东关系` |
| 主成果是利润分配请求权终稿 | 负触发 `评估利润分配请求权` |
| 主成果是异议回购评估终稿 | 负触发 `评估异议股东回购请求` |
| 主成果是出资差额精算 | 负触发 `测算出资差额利息与抽逃金额` |
| 主成果是可提交诉状 | 负触发 `提起股东权利诉讼` 或 `提起利润分配之诉` |
| 主成果是投并购对价 | 整案转投资并购 |
| 「不认定请求已成立」「未知不写零」「不输出唯一必得总额」 | 交付禁令，不是负触发 |

出现「分红」「回购」「利润」一词不是转出。

测算闸打开（可出 `DJ#` 草案，仍不得标「已确定给付／唯一必得价」）须同时满足：单方无冲突立场已闭合；主成果是分项测算，不是请求权终稿、不是诉状、不是出资差额精算；至少一项可编号报表、决议、评估或事件碎片。口头「公司很赚钱」不算单独开闸材料。

测算闸部分打开：已有碎片，但报表或决议未闭合；对应格待核；仍交十节。

测算闸关闭（仍正触发）：无一可编号碎片。「今天必须出唯一必得总额」而无最小碎片不得开闸。不出 `DJ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `DJ#` 终稿，**第 7 节不得出诉状或分配决议**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「公司很赚钱即已有可分配利润」「无决议即到期债权」「认缴比例即分配比例」「未知写零」「唯一必得回购价格」「六个月执行期即请求已成立」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `DJ#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 测算闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与对立股东相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造报表、倒签分配决议、伪造评估、抢夺印章、隐匿账簿、违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　分配与回购分表

一行一个事件切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `DJ#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 类型 | 利润分配／违法分配返还／异议回购／滥权回购分列 | 同一利润既当可分配债权又当回购替代再相加 |
| 金额状态 | 已核实／情景／无法估计 | 未知写零；无肯定来源写真实零 |
| 转介 | 出资未缴、抽逃本息转 `测算出资差额利息与抽逃金额` | 本窗出出资差额终稿 |

检索锚点（写入 `L#` 前须核验）：

- 第二百一十条：先补亏，再提百分之十法定公积金（累计达注册资本百分之五十以上可不再提取），任意公积金经股东会决议，所余按实缴（有限）或持股（股份，章程另定除外）。公司持有的本公司股份不得分配。
- 第二百一十二条：股东会决议作出之日起六个月内分配。起算点是决议日。不得把六个月写入第二百一十条。六个月是董事会执行期接口，不是诉讼时效，不是把未决议利润写成到期债权。法释〔2024〕7 号对施行前分配决议的时限争议只开第二百一十二条接口。
- 第二百一十一条：违法分配退还；损失由股东及负有责任董监高赔偿。返还与赔偿分列。
- 有限公司异议回购常见检索第八十九条，须核验全文。第一款三项与第三款控股股东滥权分列；第三款是否适用第二款六十日／九十日待核，不得默认套用。股份公司第一百六十一条，公开发行股份的公司除外。
- 期限必须三分列，禁止合成一个「分配期限」或唯一截止日：（甲）第二百一十二条六个月＝决议日起执行期；（乙）第八十九条第二款六十日协议／九十日起诉＝异议回购程序接口，起算决议通过日；（丙）第八十九条收购后六个月内转让或注销＝库股清理接口，起算收购日，不是决议日。
- 解释四第十五条只开接口。噪声：1993 年第二百一十条擅自发行股票、第二百一十一条另立账册；2018 年第一百六十六条、第七十四条未核验。

## 节点 3　对价行 `DJ#`

按已出现事件扫描，不是默认闭集。每条须能指向分配或回购接口和金额状态。

无 `E#` 不得写已核实金额。未审计报表不得升格已核实。状态默认 `草案`。一次只推荐下一步。未知金额不写零，不输出唯一必得总额。参数不足只列已知、未知和鉴定接口。伤残等级不得写入分配或回购金额。

热冲突强制处理：

- 公司很赚钱即已有可分配利润／无决议即到期债权／认缴即分配比例／未知写零／唯一必得回购价／六个月即请求已成立 → 该格不支持或字段停止；仍出其他 `DJ#`。
- 无一碎片 → 关闸，不出 `DJ#` 终稿，窗口不关。
- 指导伪造报表、倒签分配决议、伪造评估 → 整体停止，不是该格不支持。

情景只改变列明未知变量。用户催唯一必得总额：字段停止，不因催促给出伪精确数字。

## 节点 4　请求权、回购、出资差额与诉讼接口

第 7 节只开接口，不得夹带 `DJ#` 终稿、诉状或分配决议绕闸。闸关闭时第 7 节可写「闸未开，转介待事件编号」，不得补写已确定给付。期限三分列只开接口：第二百一十二条六个月／第八十九条六十日／九十日／收购后六个月库股清理。禁止合成一个分配期限。不写唯一截止日，不选定法院。解释四第十五条滥权不分只开待核接口，不得测算强制分配必得额。

下一步只转介：`评估利润分配请求权`、`评估异议股东回购请求`、`测算出资差额利息与抽逃金额`、`提起利润分配之诉`、`提起股东权利诉讼`、`评估公司治理与股东关系`。禁止此致某法院。不选定法院。不代提交。

若 if 用户催促「很赚钱就能分／没有决议也能当债／先写零／给一个必得价」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`／`无法估计`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：有限公司无分配决议，用户主张「公司很赚钱就能分、认缴比例就是分配比例、利润不清楚先写零」，把第二百一十二条六个月、第八十九条九十日和收购后六个月写成同一个截止日，并要一个法院必支持的回购价，还要把伤残赔偿折进可分配利润。测算闸打开或半开。`Q-赚`、`Q-决`、`Q-认`、`Q-零`、`Q-价` 不打开为可靠路径。三类期限分列待核，禁止合成。伤残等级该格不支持。第 6 节不得把已有可分配利润、已确定给付、0、唯一必得价写入可执行 `DJ#`；对应格 `现有依据不支持` 或字段停止；仍出补亏／公积金接口、实缴待核、回购情景参数等其他 `DJ#`。不关窗。不认定请求已成立。

场景②：用户同时交出公司「已分红完毕」报表与对立股东「报表是倒签、利润被做假」口径，要求选对公司有利的一版，并指导「分配决议日期改到账上有钱那天」。命中双方秘密＋伪造报表＋倒签分配决议。第一次整体停止。只交第 1、10 节。不出 `DJ#`。不得问代表哪一方后继续。不以「坚持」为门槛。
