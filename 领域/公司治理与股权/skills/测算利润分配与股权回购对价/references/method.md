# 测算方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、论坛、期限、金额或文书状态的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然无效、必然失权、必然解散或唯一必得总额。

`search_law` 返回已失效《合同法》、1993／2004／2013／2018《公司法》或仍引用旧第二十二条、第三十三条、第七十一条且未核验对应关系的司法解释时，记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 以股权或资产收购、投资交割、尽调闭环为主要目标 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果、员工激励的劳动身份 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂、综合合规体系 | 企业合规领域 |

## 节点 1　范围和事件编号

1. 为同一经济事件分配 `EVT#`。利润分配、违法分配返还、异议回购、滥权回购分项。
2. 出资未缴、抽逃本息转 `calculate-contribution-shortfall`（未安装则只留接口）。
3. 不得把“公司很赚钱”写成已存在可分配利润。

## 节点 2　第二百一十条接口

运行时核验现行第二百一十条后再落参数：

1. 当年税后利润先弥补亏损，再提取百分之十列入法定公积金；累计额为注册资本百分之五十以上的，可以不再提取。
2. 提取法定公积金后，经股东会决议可提取任意公积金。
3. 弥补亏损和提取公积金后所余税后利润，按股东实缴出资比例分配，全体股东约定不按出资比例的除外。认缴未实缴不得直接按认缴比例计算，除非另有合法约定且已核验。
4. 股东会作出分配利润决议的，董事会应当在决议作出之日起六个月内分配。该六个月是执行期接口，不是把未决议利润写成到期债权。
5. 无合法分配决议时，一般不得把起诉请求写成已确定给付之债；例外条件标待核，不编造。

---

## 节点 3　违法分配

核验第二百一十一条：违反规定向股东分配的，股东应当退还；给公司造成损失的，股东及负有责任的董事、监事、高级管理人员应当承担赔偿责任。返还与赔偿分列，不合成一笔。

---

## 节点 4　回购合理价格

1. 第八十九条第一款三项、第三款控股股东滥权回购分列。股份公司另核第一百六十一条。
2. 六十日内不能达成协议、九十日内起诉是程序接口，不在本任务写诉状。
3. 合理价格参数：净资产、评估、近期转让、盈利能力。参数不足只列已知、未知和鉴定接口。禁止输出法院必支持的单点价格。
4. 公司收购的股权应在六个月内依法转让或注销，标清理接口。

---

## 节点 5　汇总与互斥

同一利润不得既当可分配债权又当回购替代再相加。情景只改变列明未知变量。用户坚持唯一必得总额：字段停止，不因催促给出伪精确数字。
