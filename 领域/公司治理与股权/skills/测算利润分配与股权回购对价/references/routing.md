# 边界与路由

## 正触发

需要可分配利润或回购合理价格的分项测算，不认定请求已成立。从零、碎片、报表未核验、无书面测算授权仍正触发：有事件、报表或价格碎片则闸开或半开，出 `DJ#` 草案，保持草案。本次不认定请求已成立、未知不写零是交付禁令，不是开窗条件。公司很赚钱即已有可分配利润、无决议即到期债权、未知写零，仍正触发。

双方秘密、伪造报表、倒签分配决议、伪造评估、抢夺印章、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「公司很赚钱即已有可分配利润」「无决议即到期债权」「未知写零」「唯一必得回购价格」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 公司治理与股东关系总图 | `评估公司治理与股东关系` |
| 利润分配请求权终稿 | `评估利润分配请求权` |
| 异议回购评估终稿 | `评估异议股东回购请求` |
| 出资差额或抽逃金额精算 | `测算出资差额利息与抽逃金额` |
| 可提交诉状 | `提起股东权利诉讼` 或 `提起利润分配之诉` |
| 投并购对价或交割 | 投资并购领域 |
| 保险、侵权或劳动报酬主轴 | 对应领域 |

不得因「不认定请求已成立」或「未知不写零」关窗。拟分项测算仍正触发，不得写成已确定给付或唯一必得总额。

出现「分红」「回购」「利润」一词不是转出。

## 易混

公司很赚钱不是已有可分配利润。无分配决议不是已确定到期债权。认缴比例不是分配比例。六个月执行期不是请求已成立。未知不写零。不输出唯一必得回购价格。六个月在第二百一十二条，不得写入第二百一十条。第二百一十二条六个月、第八十九条六十日／九十日、收购后六个月库股清理必须分列，禁止合成一个分配期限。解释四第十五条滥权不分只开接口。未审计报表不是已核实金额。两套账冲突并列，单纯账册冲突不是整体停止。伤残等级与本窗无关。本窗 `DJ#` 不是关系窗 `GX#`，不是转让窗 `ZR#`，不是效力窗 `XL#`，不是合规 `M#`／`EVT#`。本窗测算闸不是合规追偿测算闸。「分配决议日期改到账上有钱那天」整体停止。本窗不执行发送，不代提交。不选定法院。
