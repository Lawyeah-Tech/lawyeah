# 边界与路由

## 正触发

需要可分配利润或回购合理价格的分项测算，不要定性终局。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 定性总图 | `评估公司治理与股东关系` |
| 利润分配请求权评估 | `评估利润分配请求权`（未安装则本任务只做数字） |
| 异议回购评估 | `评估异议股东回购请求`（未安装则本任务只做价格接口） |
| 出资差额 | `测算出资差额利息与抽逃金额`（未安装则 `unavailable`） |
| 起诉 | `提起股东权利诉讼` |

## 专项整案转出

| 信号 | 转出 |
| --- | --- |
| 以股权或资产收购、投资交割、尽调闭环为主要目标 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果、员工激励的劳动身份 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂、综合合规体系 | 企业合规领域 |
| 破产申请、重整计划、破产债权申报与分配 | 破产领域 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 合伙企业、个人独资的入伙退伙 | 非公司主体，不在本领域 |
| 上市公司发行、持续信息披露或证券监管主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

公司日常治理夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

已有分配决议、只要执行金额时正触发。无任何财务参数却要“市场价保底”时，只输出缺口，不编造。
