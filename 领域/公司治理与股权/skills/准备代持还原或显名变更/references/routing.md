# 边界与路由

## 正触发

已决定还原或显名，需要内部同意与登记文件。从零、碎片、同意未核验、无书面还原授权仍正触发：有可编号还原决定或同意碎片则闸开或半开，出 `HY#` 草案，保持草案。本次不代提交、不重判代持是否有效是交付禁令，不是开窗条件。未同意即已显名、草稿即已变更登记、半数不足即可出终稿、回执即已核准、效力未闭合即可出终稿，仍正触发。效力未闭合：对应格待核，窗口不关；只有主成果变成效力评估才转评估窗。

双方秘密、伪造其他股东同意、倒签同意书、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「未同意即已显名」「草稿即已变更登记」「半数不足即可出终稿」「回执即已核准」「效力未闭合即可出终稿」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 代持是否有效或显名条件评估 | `评估股权代持效力与显名` |
| 上市公司股份代持清理监管报备 | 证券监管 |
| 投资权益诉讼而不办变更 | 代持评估或股东权利诉讼 |
| 名册记载请求独占 | `准备股东名册与工商变更衔接` |
| 合伙或个人独资 | 非公司主体 |

不得因「不代提交」或「不重判代持是否有效」关窗。拟还原文件草稿仍正触发，不得写成已显名或已变更登记。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |
| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露或股份代持监管主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「还原」「显名」「同意」一词不是转出。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 只要代持效力或显名条件 | `评估股权代持效力与显名` |
| 只要名册记载请求 | `准备股东名册与工商变更衔接` |
| 只要其他股东主张优先购买 | `评估优先购买权是否成立` |
| 只要股权结构图 | `梳理股权结构与控制权` |

## 易混

本窗闸名只能是还原闸。`HY#` 不是代持窗 `DT#`，不是名册窗 `MC#`，不是转让窗 `ZR#`。未同意不是已经显名。还原草稿不是已变更登记。半数同意不足不是可出还原终稿。网交回执不是已核准。效力未闭合不是可出还原终稿。一人公司不得机械套多股东半数。2011 年解释三第二十四条不是 2020 年修正后显名条。「把没签字的人签上」整体停止。本窗不执行发送，不代提交。不选定法院。
