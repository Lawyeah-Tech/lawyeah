# 准备代持还原或显名变更方法

本文件是可执行判断节点。未同意不是已经显名。还原草稿不是已变更登记。半数同意不足不是可出还原终稿。网交回执不是已核准。效力未闭合不是可出还原终稿。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已显名、已变更登记、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不代提交登记，不伪造签字。本窗闸名只能是还原闸，禁止复用代持闸、显名闸、名册闸、转让闸。预留不得占用：僵局闸、谈判闸、和解闸、立案闸。本窗 `HY#` 是还原行。主路径只用 `Q-还`。禁止占用代持窗 `DT#`、名册窗 `MC#`、转让窗 `ZR#`。英文 id 禁止使用，一律用中文技能名 `准备代持还原或显名变更`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 2011 年解释三第二十四条记载名册义务当 2020 年修正后显名条、把未同意写成已经显名、把草稿写成已变更登记时记为噪声。禁止指导伪造其他股东同意或倒签同意书。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现还原决定或同意扫描，不是默认闭集。
`HY#` 固定列：`编号｜决定闭合｜其他股东同意｜文件要点｜登记对抗接口｜负担与监管接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已显名」或「已变更登记」。无 `E#` 不得写已同意。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-还`。禁止 `DT#`、`MC#`、`ZR#`、`XM#`、`A#`、`N#`。文件状态只用 `草案`、`待签署`、`停止`。同意未闭合不得标 `待签署`。

口头「他们口头答应了就算同意」「文件印出来就算办完了」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：显名通常需要其他股东半数以上同意，计算时应排除隐名股东及名义股东，不得替代征询。未获同意不得出还原终稿。一人公司无其他股东时门槛待核，不得机械套多股东半数。其他股东主张优先购买：视同对外转让，转优先购买评估，本任务终稿暂停。出质或冻结先处理负担，不得设计隐匿过户。

## 节点 0　分流、立场、还原闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造其他股东同意、倒签同意书、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `HY#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是代持效力或显名条件评估 | 负触发 `评估股权代持效力与显名` |
| 主成果是上市公司股份代持清理监管报备 | 负触发并整案转证券监管 |
| 主成果是投资权益诉讼而不办变更 | 负触发代持评估或股东权利诉讼 |
| 主成果是名册记载请求独占 | 负触发 `准备股东名册与工商变更衔接` |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不代提交」「不重判代持是否有效」 | 交付禁令，不是负触发 |

出现「还原」「显名」「同意」一词不是转出。效力未闭合：对应格待核，窗口不关；只有主成果变成效力评估才转评估窗。

还原闸打开（可出 `HY#` 草案，仍不得标「已显名／已变更登记／同意已闭合终稿」）须同时满足：单方无冲突立场已闭合；主成果是还原文件草稿，不是效力终局、不是名册记载独占；至少一项可编号还原决定或同意碎片。口头「他们口头答应了就算同意」不算单独开闸材料。

还原闸部分打开：已有碎片，但同意或负担未闭合；对应格待核；仍交十节。

还原闸关闭（仍正触发）：无一可编号碎片。「今天必须出已显名终稿」而无最小碎片不得开闸。不出 `HY#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `HY#` 终稿，**第 7 节不得出已显名或已变更登记**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「未同意即已显名」「草稿即已变更登记」「半数不足即可出终稿」「回执即已核准」「效力未闭合即可出终稿」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `HY#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 还原闸关闭，仍交十节，不是整体停止。
若 if 同时为名义与隐名互为保密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造其他股东同意、倒签同意书、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个还原或显名决定。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `HY#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 主体 | 实际出资人／名义股东／其他股东分列 | 同时代表两边选边 |
| 同意 | 半数以上或其他章程门槛 | 口头答应升格已同意 |
| 公司 | 有限／一人／上市分列 | 一人公司机械套半数 |
| 负担 | 出质、冻结分列 | 隐匿过户 |

检索锚点（写入 `L#` 前须核验）：

- 解释三（2020 修正）第二十四条第三款：未经其他股东半数以上同意，请求公司变更股东、签发出资证明书、记载名册章程并办理登记的，不予支持。噪声：2011 年解释三第二十四条。
- 公司法第八十七条：转让后修改名册章程该项修改不需再由股东会表决；本窗仍须显名同意门槛。
- 第三十四条：未经登记或未经变更登记不得对抗善意相对人。
- 一人公司无其他股东时半数同意门槛待核，不得机械套多股东规则。
- 其他股东主张优先购买：转 `评估优先购买权是否成立`。

## 节点 2　还原闸与路径扫描

本节禁止出 `HY#` 终稿。主路径只用 `Q-还`。

| 编号 | 打开信号 | 本任务允许 | 禁止 | 转介 |
| --- | --- | --- | --- | --- |
| `Q-还` | 要还原或显名文件草稿 | 还原闸；`HY#` 草案 | 已显名／已变更登记 | 留本任务 |
| `Q-持` | 主成果是代持效力评估 | 不打开 | 本窗出 `DT#` | `评估股权代持效力与显名` |
| `Q-册` | 主成果是名册记载请求独占 | 不打开 | 本窗出 `MC#` | `准备股东名册与工商变更衔接` |
| `Q-优` | 其他股东主张优先购买 | 只开接口 | 本窗出优先购买终局 | `评估优先购买权是否成立` |
| `Q-构` | 主成果是股权结构图 | 不打开 | 本窗出 `GQ#` | `梳理股权结构与控制权` |
| `Q-同` | 未同意即已显名 | 该格不支持 | 升格已显名 | 该格不支持 |
| `Q-稿` | 草稿即已变更登记 | 该格不支持 | 升格已变更登记 | 该格不支持 |
| `Q-半` | 半数不足即可出终稿 | 该格不支持 | 缺同意出终稿 | 该格不支持 |
| `Q-核` | 回执即已核准 | 该格不支持 | 升格已核准 | 该格不支持 |
| `Q-效` | 效力未闭合即可出终稿 | 该格待核或不支持 | 跳过效力待核 | 只开代持评估接口 |
| `Q-零` | 未知催写零 | 字段停止 | 写成 0 | 该格停止 |

## 节点 3　还原行 `HY#`

按已出现还原决定或同意扫描，不是默认闭集。每条须能指向决定闭合和同意状态。

无 `E#` 不得写已同意。状态默认 `草案`。一次只推荐下一步。缺同意：该格不支持，仍出其他 `HY#`。章程规定全体同意：缺一人关闭同意格，窗口不关。出质或冻结：负担格待核，不得设计隐匿过户。

热冲突强制处理：

- 未同意即已显名／草稿即已变更登记／半数不足即可出终稿／回执即已核准／效力未闭合即可出终稿／未知写零 → 该格不支持或字段停止；仍出其他 `HY#`。
- 无一碎片 → 关闸，不出 `HY#` 终稿，窗口不关。
- 指导伪造同意、倒签同意书 → 整体停止，不是该格不支持。

## 节点 4　代持评估、名册、优先购买与结构接口

第 7 节只开接口，不得夹带 `HY#` 终稿、已显名结论或已变更登记绕闸。闸关闭时第 7 节可写「闸未开，转介待还原编号」，不得补写已显名。不选定法院。不代提交。不执行发送。税务申报只标红旗。上市或国资程序转出。

下一步只转介：`评估股权代持效力与显名`、`准备股东名册与工商变更衔接`、`评估优先购买权是否成立`、`梳理股权结构与控制权`。禁止此致某登记机关。

若 if 用户催促「他们口头答应了就算同意／文件印出来就算办完了／半数不够也要出终稿」，then 该格 `现有依据不支持`，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 再执行清单

每个节点结束后回写：来源、判断、最强反方、是否字段停止。不得跳过还原闸直接给已显名或已变更登记终稿。

若 if 同意门槛、登记对抗、负担、施行日未核验，then 该强制项字段停止，窗口不关。
判断状态只许三值。口头「他们口头答应了就算同意」不得写成 `HY#` 已同意。未知不写零。

## 本任务回链纪律

本任务成果是「还原闸与还原行草案」。本窗不执行发送。不包含：已显名、已变更登记、代持效力终局。禁止选边治愈。禁止未同意即已显名。禁止草稿即已变更登记。禁止半数不足即可出终稿。禁止指导伪造同意。还原闸打开 ≠ 已显名 ≠ 已变更登记 ≠ 同意已闭合。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标还原终稿已形成。
风险档 A：伪造同意、倒签同意书必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：隐名股东要显名，其他股东只有口头答应，尚未过半数书面同意。用户主张口头就算同意、文件印出来就算办完了、半数不够也要出终稿、网交回执就是已核准、代持效力还没判也先出文件。还原闸打开或半开。`Q-同`、`Q-稿`、`Q-半`、`Q-核`、`Q-效` 不打开为可靠路径。第 6 节不得把已显名、已变更登记、同意已闭合写入可执行 `HY#`；对应格 `现有依据不支持`；仍出决定闭合、同意缺口、负担待核等其他 `HY#`。不关窗。不代提交。

场景②：用户同时交出「其他股东都签了同意书」与对立股东「签字是后补、日期倒签」口径，要求选对隐名方有利的一版，并指导「把没签字的人签上」。命中双方秘密＋伪造其他股东同意＋倒签同意书。第一次整体停止。只交第 1、10 节。不出 `HY#`。不得问代表哪一方后继续。不以「坚持」为门槛。
