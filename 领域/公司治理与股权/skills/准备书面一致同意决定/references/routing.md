# 边界与路由

## 正触发

有限公司拟不召开股东会，由全体股东以书面形式一致表示同意并形成发送前决定草稿。从零、碎片、名册未核验、无书面决定授权仍正触发：有可编号股东或决定事项碎片则闸开或半开，出 `SM#` 草案，保持草案。本次不执行发送、不写已通过是交付禁令，不是开窗条件。缺一名即已通过、缺一名即已开会、书面决定即已开会、第六十条即救缺员、多数决即书面一致、草稿即已通过，仍正触发。缺一名仍要求写成已开会：正触发，该格不支持，不是负触发。

双方秘密、伪造缺席股东签名、倒签日期、补签名造已通过、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「缺一名即已通过」「缺一名即已开会」「书面决定即已开会」「第六十条即救缺员」「多数决即书面一致」「草稿即已通过」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 发送前召集通知 | `准备股东会决议与召集` |
| 效力三项终局 | `评估股东会董事会决议效力` |
| 程序表 | `评估召集主持表决程序瑕疵` |
| 可提交决议之诉诉状 | `提起决议不成立无效或撤销之诉` |
| 一人公司书面决定 | `准备一人公司特殊安排` |
| 董事会或执行董事决定草稿 | `准备董事会或执行董事决定` |
| 合伙或个人独资 | 非公司主体 |

不得因「不执行发送」或「不写已通过」关窗。拟书面决定草稿仍正触发，不得写成已通过或已开会。

## 易混

本窗闸名只能是书面闸。`SM#` 不是召集窗 `ZJ#`，不是效力窗 `XL#`，不是程序窗 `CX#`，不是决议诉窗 `XF#`，不是一人窗 `YR#`。缺一名股东不是已召开会议。缺一名股东不是已一致通过。书面决定不是已开会。一人公司第六十条不是可救缺员书面决议。多数决不是书面一致。草稿不是已经通过。股份不得未核验套有限第五十九条第三款。成立大会不是可改书面一致。第五十九条第三款覆盖第一款事项，不是董事会职权可冒充。范本会议决议栏目不是已召开。「把缺席那个人的名字签上」「日期倒签」整体停止。本窗不执行发送，不代提交。不选定法院。
