# 章程起草方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、论坛、期限、金额或文书状态的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然无效、必然失权、必然解散或唯一必得总额。

`search_law` 返回已失效《合同法》、1993／2004／2013／2018《公司法》或仍引用旧第二十二条、第三十三条、第七十一条且未核验对应关系的司法解释时，记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

---

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 以股权或资产收购、投资交割、尽调闭环为主要目标 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果、员工激励的劳动身份 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂、综合合规体系 | 企业合规领域 |
| 破产申请、重整计划、破产债权申报与分配 | 破产领域 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 合伙企业、个人独资的入伙退伙 | 非公司主体，不在本领域 |
| 上市公司发行、持续信息披露或证券监管主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

混合信号：公司组织或股东关系主轴可留本任务；专项只作为背景时在缺口标明，不把专项规则硬套进本领域结论。

## Q# 矩阵

固定列：`编号｜关系假设｜提出方｜相对方｜法律效果｜成立条件｜支持事实｜不利事实｜控制方｜最强反方｜主备位｜判断｜待核`。

分列新设章程、修正案、强制规范冲突、任意规范补充。禁止把修正案草稿写成已经通过。


## 节点 1　版本与权限

1. 新设：无现行章程，对照法定必载起草。已成立：必须固定最新章程、历史修正案和登记备案文本，冲突并列。
2. 修改章程属于股东会法定职权，须核验第五十九条。本任务不代替召集与决议原子；用户只要决议包则负触发。
3. 同时代表冲突股东就同一条款各写一版终稿：整体停止。

---

## 节点 2　强制规范

1. 必载事项缺漏：不输出“可签署终稿”，只出对照表和补句。
2. 下列内容不得写成任由章程取消：董事会催缴与失权底线、股东查阅会计账簿的法定路径、决议不成立／无效／撤销规则、司法解散门槛。具体条号运行时核验。
3. 出资期限短于或长于现行五年规则：新设有限公司须核验第四十七条；存量公司调整转 `准备认缴期限调整与实缴整改`。
4. 旧章程仍写“股东会除名未出资股东”且无董事会失权接口：标与 2024-07-01 后文本冲突，建议修订，不把旧解释第十七条写成现行唯一路径。

---

## 节点 3　任意规范

1. 股权对外转让、表决权、利润分配、董事人数、议事方式可以细化，但“章程另有规定”以现行法明确授权者为限。
2. 股东协议与章程冲突：对内约束标待核，对外不得对抗善意相对人处须提示。详细协议正文转 `起草股东协议与一致行动安排`。
3. 一般交易合同条款（供货、借款、担保主合同）不写入本章程任务。

---

## 节点 4　草稿纪律

1. 每条标注强制／任意／来源。数字、期限、比例未知则留空并标缺口，不写零、不写“按惯例三分之二”。
2. 修正案采用对照格式：原文、修订文、理由、需决议事项。
3. 用户要求倒签“早已通过的章程”：整体停止。

---

## 节点 5　接口

新设：签署页、股东名册初稿接口。成立后修订：转股东会决议原子＋登记接口。冲突评估终局转 `评估章程与强制性规范冲突`。
