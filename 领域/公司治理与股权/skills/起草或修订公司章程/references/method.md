# 起草或修订公司章程方法

本文件是可执行判断节点。草稿不是已通过。范本不是已签署。必载缺失不得用默认条款冒充已载明。新设有限出资期限突破五年不是任意条款。章程不得取消查阅或催缴失权底线。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已通过、已备案、选定法院、代签署、未知写零。本任务不定罪，不代替决议，不代提交。本窗闸名只能是章程闸，禁止复用选型闸、设立闸、登记闸、决议闸、召集闸。本窗 `CZ#` 是章程行。英文 id 禁止使用，一律用中文技能名 `起草或修订公司章程`。主路径只用 `Q-章`，禁止 `Q-设`、`Q-选` 作主路径。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 2018 年第二十五条旧必载、第十三条董事长或执行董事、解释三第十七条当 2024 年后唯一除名路径时记为噪声。禁止指导倒签通过日或伪造签名。伤残等级与本窗无关。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现条款碎片扫描，不是默认闭集。
`CZ#` 固定列：`编号｜章程切片｜版本与权限｜类型分列｜必载对照｜强制底线｜任意可写｜修正对照｜签署登记接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。无 `E#` 不得写已通过、已签署、已备案或已载明。`E#` 只作证据形态回链，不是发送闸。扫描不是闭集。缺项记 `G#`。承认只进 `S#`／`D#`，不得占用 `A#`。文件状态只用 `草案`、`待签署`、`停止`。可签署终稿仅当闸已开且有限第四十六条或股份第九十五条必载齐且强制底线未被取消；缺一项只出对照表。

口头「已经通过了」「范本签了就算章」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：修改章程是股东会法定职权。有限须代表三分之二以上表决权通过，股份须出席会议股东所持表决权三分之二以上通过，不得混套。签署不等于通过，通过不等于备案。

## 节点 0　分流、立场、章程闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、倒签通过日、伪造股东签名、伪造决议、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `CZ#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是只要冲突评估不改写 | 负触发 `评估章程与强制性规范冲突` |
| 主成果是召集或通过修正案 | 负触发 `准备股东会决议与召集` |
| 主成果是设立文件与登记包 | 负触发 `准备公司设立文件与登记` |
| 主成果是类型比较草案 | 负触发 `选择公司类型与机关结构` |
| 主成果是股东协议正文 | 负触发 `起草股东协议与一致行动安排` |
| 主成果是存量认缴期限调整 | 负触发 `准备认缴期限调整与实缴整改` |
| 主成果是形式变更包 | 负触发 `准备有限公司与股份公司形式变更` |
| 主成果是一般交易合同 | 整案转审查起草 |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不写已通过」「不代签署」「不代替决议」 | 交付禁令，不是负触发 |

出现「章程」「修正案」一词不是转出。草稿即已通过不是负触发，该格不支持。

章程闸打开（可出 `CZ#` 草案，仍不得标「已通过／已签署／可签署终稿已形成」）须同时满足：单方无冲突立场已闭合；主成果是章程或修正案草稿，不是冲突评估终稿、不是决议包、不是设立包独占、不是股东协议；至少一项可编号现行章程版本或拟设必载碎片。口头「已经通过了」不算单独开闸材料。

章程闸部分打开：已有碎片，但必载、代表人产生办法或出资期限未闭合；对应格待核；仍交十节。无书面起草授权但立场已闭合且有条款碎片：部分打开，不是整体停止。必载缺漏：闸可开或半开，不出可签署终稿，仍出对照表。

章程闸关闭（仍正触发）：无一可编号碎片。「今天必须出已通过／已签署终稿」而无最小碎片不得开闸。不出 `CZ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `CZ#` 终稿，**第 7 节不得出已通过或已备案**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已通过」「范本即已签署」「必载默认已载明」「章程即已代替决议」「打印即已备案」「取消查阅」「取消催缴失权」「突破五年当任意」「有限必载套股份」「惯例三分之二」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `CZ#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 章程闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立股东相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出倒签通过日、伪造股东签名、伪造决议、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个章程切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `CZ#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 类型 | 有限／股份分列 | 有限第四十六条套股份第九十五条 |
| 必载 | 两套清单对照，缺项记 `G#` | 范本填满冒充已载明 |
| 修改 | 第五十九条职权；有限第六十六条代表三分之二；股份第一百一十六条出席三分之二 | 写成惯例；混套有限与股份 |
| 底线 | 查阅、催缴失权、决议效力、司法解散不得取消 | 章程废除法定路径 |
| 五年 | 新设有限第四十七条 | 突破五年当任意；套发起人第九十八条 |

检索锚点（写入 `L#` 前须核验）：

- 第五条：章程约束力。
- 第四十六条／第九十五条：必载两套。
- 第四十七条：新设有限五年；存量转认缴窗。
- 第五十九条、第六十六条、第一百一十六条：修改职权与表决。
- 第五十一条、第五十二条：催缴失权底线。第五十七条：查阅底线。
- 第二十五条至第二十七条、第二百三十一条：不得章程废除。
- 第八十四条末款：转让程序「章程另有规定」，本窗不打开可取消优先购买。
- 第十条：法定代表人由执行事务的董事或经理担任。
- 噪声：2018 年第二十五条、第十三条、解释三第十七条。

不得暗示「草稿印出就算已经通过」。

## 节点 3　章程行 `CZ#`

按已出现条款扫描，不是默认闭集。新设与修正案分列。修正案必须原文／修订文／理由／需决议事项；未对照不得标已修订完成。

无 `E#` 不得写已通过、已签署或已备案。状态默认 `草案`。一次只推荐下一步。未知比例不写零、不写惯例三分之二。必载缺一项不出可签署终稿。强制底线被要求取消的格不支持，仍出其他 `CZ#`。

热冲突强制处理：

- 草稿即已通过／范本即已签署／取消查阅或催缴失权／突破五年／有限套股份／惯例三分之二／未知写零 → 该格不支持或字段停止；仍出其他 `CZ#`。
- 无一碎片 → 关闸，不出 `CZ#` 终稿，窗口不关。
- 指导倒签通过日、伪造签名、抢夺印章 → 整体停止，不是该格不支持。

法定代表人人选未定只载产生变更办法。股东协议对内待核，对外不得对抗善意相对人只提示。

## 节点 4　设立、冲突评估、决议与股东协议接口

第 7 节只开接口，不得夹带 `CZ#` 终稿、已通过文本或设立申请绕闸。闸关闭时第 7 节可写「闸未开，转介待章程版本编号」，不得补写已通过。新设签署与成立后修订登记分列，禁止合成「签完即已登记」。

下一步只转介：`评估章程与强制性规范冲突`、`准备股东会决议与召集`、`准备公司设立文件与登记`、`起草股东协议与一致行动安排`、`准备认缴期限调整与实缴整改`、`准备书面一致同意决定`、`准备一人公司特殊安排`。禁止此致某登记机关为唯一路径。不代签署。不代替决议。

若 if 用户催促「已经通过了／范本算签署／比例先写惯例三分之二」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：已成立有限，有现行章程版本。用户要把查阅账簿路径删掉、出资改无限、未知表决写惯例三分之二、网上范本算已签署、草稿印出即已通过。章程闸打开或半开。`Q-阅`、`Q-五`、`Q-例`、`Q-范`、`Q-过` 不打开为可靠路径。第 6 节不得把已通过、已签署、取消查阅、突破五年、惯例三分之二写入可执行 `CZ#`；对应格 `现有依据不支持` 或字段停止；仍出第四十六条对照、第四十七条五年待核、第五十九条／第六十六条法定三分之二、第五十一条／第五十二条与第五十七条底线保留等其他 `CZ#`。不出可签署终稿冒充已通过。不关窗。不代签署。不代替决议。若同时要求倒签「早已通过」日期 → 改走场景②整体停止。

场景②：用户同时交出对立股东相互冲突的秘密口径，要求选对己方有利的一版，并指导倒签通过日、伪造股东签名、今晚把章先刻好。命中双方秘密＋倒签通过日＋伪造签名＋抢夺印章。第一次整体停止。只交第 1、10 节。不出 `CZ#`。不得问代表哪一方后继续。不以「坚持」为门槛。
