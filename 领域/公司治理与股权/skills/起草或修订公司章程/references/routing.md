# 边界与路由

## 正触发

设立中或已成立公司需要可签署章程或修正案草稿。从零、碎片、必载未核验、无书面起草授权仍正触发：有现行章程版本或拟设必载碎片则闸开或半开，出 `CZ#` 草案，保持草案。本次不写已通过、不代签署、不代替决议是交付禁令，不是开窗条件。草稿即已通过、范本即已签署、取消查阅，仍正触发。

双方秘密、倒签通过日、伪造股东签名、伪造决议、抢夺印章证照、违法取证的停止，优先于负触发。上述信号不在下表。「草稿即已通过」「范本即已签署」「取消查阅」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要冲突评估不改写 | `评估章程与强制性规范冲突` |
| 只要召集或通过修正案 | `准备股东会决议与召集` |
| 设立文件与登记包 | `准备公司设立文件与登记` |
| 类型与机关比较草案 | `选择公司类型与机关结构` |
| 股东协议或一致行动正文 | `起草股东协议与一致行动安排` |
| 存量认缴期限调整 | `准备认缴期限调整与实缴整改` |
| 已决定有限改股份或相反 | `准备有限公司与股份公司形式变更` |
| 一般交易合同 | 审查起草领域（本窗搁置） |
| 合伙或个人独资 | 非公司主体 |

不得因「不写已通过」或「不代替决议」关窗。拟章程草稿仍正触发，不得写成已通过或已备案。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |
| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「章程」「修正案」一词不是转出。

## 易混

本窗闸名只能是章程闸，禁止复用选型闸、设立闸、登记闸、决议闸、召集闸。草稿不是已通过。范本不是已签署。打印不是已备案。必载缺失不是已载明。有限必载不是股份必载。法定三分之二不是惯例。新设有限五年不是任意无限。章程不得取消查阅或催缴失权。解释三第十七条不是 2024 年后唯一除名路径。2018 年第二十五条不是现行必载条。本窗 `CZ#` 不是选型窗 `XX#`，不是设立窗 `XS#`，不是渠道行 `CH#`，不是决议窗 `ZJ#`。「通过日先倒签」「今晚把章先刻好」整体停止。本窗不执行发送，不代签署。不代替决议。伤残等级与本窗无关。
