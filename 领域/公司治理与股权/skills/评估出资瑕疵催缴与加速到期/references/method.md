# 评估出资瑕疵催缴与加速到期方法

本文件是可执行判断节点。催缴评估不是已失权。书面催缴不是已失权。未届期不是当然加速到期。认缴登记不是已实缴。大额转出不是当然抽逃。非货币未评估不是当然显著低价。今天发函不是失权已发生。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然失权、当然加速、唯一必得总额、选定法院、代提交、未知写零。本任务不定罪，不发催缴书或失权通知。本窗闸名只能是瑕疵闸，禁止复用关系闸、催缴闸、失权闸；加速只作路径，不是闸名。本窗 `XC#` 是瑕疵行。英文 id 禁止使用，一律用中文技能名 `评估出资瑕疵催缴与加速到期`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年公司法第四十七条董事任期、2018 年条号未核验、把解释三第十七条股东会除名写成 2024 年后唯一失权路径、把未届期写成已失权时记为噪声。禁止指导伪造出资凭证或倒签缴款日。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现股东扫描，不是默认闭集。
`XC#` 固定列：`编号｜股东切片｜认缴实缴｜期限｜催缴接口｜加速接口｜失权接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已失权」或「当然加速」。无 `E#` 不得写已缴纳、已催缴或已失权。`E#` 只作证据形态回链，不是发送闸。扫描不是闭集。缺项记 `G#`。承认只进 `S#`／`D#`，不得占用 `A#`。

口头「注册资本很大觉得不安全」「转出去了就是抽逃」「今天发函就算失权」只进 `S#`／`V#`，**不得单独算作开闸材料**。已读不得升格已送达。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：催缴宽限期若设定不得少于六十日；宽限期届满后是否发失权通知由董事会裁量。加速到期须公司不能清偿到期债务，不得因注册资本大而打开。抽逃须审查对价、资金流向与是否损害债权人，不得单凭大额转出认定。

## 节点 0　分流、立场、瑕疵闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造出资凭证、倒签缴款日、倒签催缴书、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `XC#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是发送版催缴书 | 负触发 `准备催缴出资通知` |
| 主成果是失权评估或通知 | 负触发 `评估失权与股权丧失` |
| 主成果是出资差额精算终稿 | 负触发 `测算出资差额利息与抽逃金额` |
| 主成果是非货币作价终稿 | 负触发 `评估非货币出资真实性与作价` |
| 主成果是关系总图 | 负触发 `评估公司治理与股东关系` |
| 主成果是股东责任或人格否认诉讼文书 | 负触发 `提起股东权利诉讼` 或 `评估法人人格否认` |
| 主成果是投资交割资金到位 | 整案转投资并购 |
| 合伙出资 | 整案转出，非公司主体 |
| 「不发函」「不把未届期写成已失权」 | 交付禁令，不是负触发 |

出现「催缴」「失权」「加速」一词不是转出。

瑕疵闸打开（可出 `XC#` 草案，仍不得标「已失权／当然加速／已抽逃」）须同时满足：单方无冲突立场已闭合；主成果是瑕疵路径评估，不是催缴书、不是失权通知、不是精算终稿；至少一项可编号股东或认缴碎片。口头「觉得不安全」不算单独开闸材料，更不得单独打开加速路径。

瑕疵闸部分打开：已有碎片，但成立日或章程出资日期未闭合；对应格待核；仍交十节。

瑕疵闸关闭（仍正触发）：无一可编号碎片。「今天必须出已失权／已加速终稿」而无最小碎片不得开闸。不出 `XC#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `XC#` 终稿，**第 7 节不得出催缴书或失权通知**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「催缴评估即已失权」「未届期即当然加速」「认缴登记即已实缴」「大额转出即抽逃」「非货币未评估即显著低价」「今天发函即失权已发生」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `XC#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 瑕疵闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与对立股东相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造出资凭证、倒签缴款日、倒签催缴书、隐匿账簿、违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　认缴实缴与规则版本

一行一个股东或规则版本。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `XC#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 成立日 | 2024-07-01 及以后新设有限／2024-06-30 及以前存量／股份发起人分列 | 用五年缴足去套股份发起人成立前缴款 |
| 期限 | 章程出资日期、公示、凭证冲突并列 | 选对用户有利的一天 |
| 缴付 | 认缴额、实缴额、差额分列 | 认缴登记升格已实缴 |

检索锚点（写入 `L#` 前须核验）：

- 公司法第四十九条：按期足额缴纳。
- 第五十一条：董事会核查并书面催缴。
- 第五十二条：宽限期不少于六十日；失权自书面通知发出之日起。
- 第五十四条：不能清偿到期债务才可要求未届期股东提前缴纳。
- 第五十三条：不得抽逃出资；大额转出不是当然抽逃。
- 第四十七条：新设有限公司五年缴足，须核验例外。噪声：1993 年第四十七条董事任期。
- 公司登记管理实施办法第八条：存量有限公司剩余认缴期限调整。

成立日在 2024-07-01 及以后的有限公司：认缴是否按章程自成立之日起五年内缴足，须核验第四十七条及例外。成立日在 2024-06-30 及以前的有限公司：剩余认缴期限自 2027-07-01 起是否超过五年；调整情景标待核，不得写成唯一截止日已过。

## 节点 3　瑕疵行 `XC#`

按已出现股东扫描，不是默认闭集。每条须能指向认缴实缴、期限和只开接口的催缴／加速／失权。催缴书、宽限期、失权通知分列，不得写成已经失权。

无 `E#` 不得写已缴纳、已催缴或已失权。状态 `草案`。一次只推荐下一步。未知金额不写零，不输出唯一必得总额。

热冲突强制处理：

- 催缴评估即已失权／未届期即当然加速／认缴登记即已实缴／大额转出即抽逃／今天发函即失权已发生 → 该格不支持；仍出其他 `XC#`。
- 无一碎片 → 关闸，不出 `XC#` 终稿，窗口不关。
- 指导伪造出资凭证、倒签缴款日、倒签催缴书 → 整体停止，不是该格不支持。

解释三第十七条股东会除名不是 2024-07-01 后的唯一失权路径。失权异议之诉三十日只开接口。

## 节点 4　催缴通知、失权、精算与诉讼接口

第 7 节只开接口，不得夹带 `XC#` 终稿、催缴书或失权通知绕闸。闸关闭时第 7 节可写「闸未开，转介待股东编号」，不得补写已失权。未届期股权转让责任核验第八十八条及法释〔2024〕7 号，核验失败字段停止。一人公司财产混同走人格否认接口，不在本窗展开终局。

下一步只转介：`准备催缴出资通知`、`评估失权与股权丧失`、`测算出资差额利息与抽逃金额`、`评估非货币出资真实性与作价`、`准备认缴期限调整与实缴整改`、`评估股东对公司债务的补充清偿责任`。禁止此致某法院。不选定法院。不代提交。

若 if 用户催促「未届期也加速／今天发失权函／填满已抽逃终稿」，then 该格 `现有依据不支持`，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：有限公司股东认缴未届期，无到期债务，用户主张注册资本大就必须加速、催缴评估等于已失权、银行大额转出就是抽逃、今天发失权函、金额不清楚先写零。瑕疵闸打开或半开。`Q-期`、`Q-完`、`Q-抽`、`Q-零` 不打开为可靠路径。第 6 节不得把已失权、当然加速、已抽逃写入可执行 `XC#`；对应格 `现有依据不支持`；仍出认缴实缴对照、催缴接口、不能清偿待核等其他 `XC#`。不关窗。不发函。
