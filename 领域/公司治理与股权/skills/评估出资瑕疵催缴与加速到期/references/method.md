# 出资评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、论坛、期限、金额或文书状态的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然无效、必然失权、必然解散或唯一必得总额。

`search_law` 返回已失效《合同法》、1993／2004／2013／2018《公司法》或仍引用旧第二十二条、第三十三条、第七十一条且未核验对应关系的司法解释时，记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 以股权或资产收购、投资交割、尽调闭环为主要目标 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果、员工激励的劳动身份 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂、综合合规体系 | 企业合规领域 |
| 破产申请、重整计划、破产债权申报与分配 | 破产领域 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 合伙企业、个人独资的入伙退伙 | 非公司主体，不在本领域 |
| 上市公司发行、持续信息披露或证券监管主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

混合信号：公司组织或股东关系主轴可留本任务；专项只作为背景时在缺口标明，不把专项规则硬套进本领域结论。

## 节点 1　认缴、实缴和适用文本

1. 成立日在 2024-07-01 及以后的有限公司：全体股东认缴出资是否按章程自成立之日起五年内缴足，须核验现行第四十七条及另有规定例外。
2. 成立日在 2024-06-30 及以前的有限公司：剩余认缴期限自 2027-07-01 起是否超过五年；若是，调整截止情景标 2027-06-30 前，须核验《公司登记管理实施办法》第八条。已缴足或剩余不足五年标无需调整。
3. 股份公司发起人实缴规则与有限公司认缴规则分列，不得混用五年缴足去套发起人成立前缴款。
4. 章程日期、公示日期和银行凭证冲突时建并行情景，不选对用户有利的一天。

## 节点 2　瑕疵类型

| 事实 | 不得写成 |
| --- | --- |
| 认缴尚未到期且无法定加速事由 | 已构成未履行出资义务并应失权 |
| 股东从公司大额转出 | 当然抽逃 |
| 非货币未评估 | 当然显著低价 |
| 用户想今天发函 | 失权已发生 |

未按期足额缴纳：核验第四十九条。设立时其他股东连带：核验第五十条。抽逃：核验第五十三条及解释（三）第十二条情形，条号对应关系待核。

---

## 节点 3　催缴、失权、加速

1. **催缴**：公司成立后董事会应核查；未按期足额缴纳的，公司发书面催缴书。未及时核查致损，负有责任的董事可能赔偿。本任务不生成催缴书。
2. **宽限期与失权**：催缴书可载明宽限期，自发出之日起不得少于六十日。届满仍未履行，经董事会决议可发书面失权通知；自通知发出之日起丧失未缴纳出资的股权。异议之诉三十日。不得把解释（三）第十七条的股东会除名写成 2024-07-01 后的唯一路径。
3. **加速到期**：公司不能清偿到期债务时，公司或已到期债权的债权人有权要求未届期股东提前缴纳。无不能清偿事实不得打开加速闸。
4. 用户主目标变为发送催缴或失权：目标停止，转介相应通知原子（未安装则 `unavailable`）。

---

## 节点 4　责任范围

- 未出资本息范围内对公司不能清偿部分的补充赔偿责任，须核验解释（三）第十三条与 2023 文本是否仍支持，核验失败则字段停止。
- 未届期股权转让：受让人缴纳，未按期则转让人补充责任；瑕疵转让可能连带，善意受让例外。核验第八十八条及法释〔2024〕7 号。
- 一人公司财产混同走人格否认接口，不在本任务展开终局。

列出认缴实缴对照、付款凭证控制方、评估报告、抽逃资金流和董事会核查记录。禁止教唆做假出资材料或倒签缴款日。
