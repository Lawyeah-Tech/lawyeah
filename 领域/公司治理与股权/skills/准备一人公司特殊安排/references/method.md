# 准备一人公司特殊安排方法

本文件是可执行判断节点。隔离措施清单不是已独立。账户分开不是已独立。缺书面决定不是已合法决定。2018 一个自然人只能设一个一人有限不是现行。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已独立、已免连带、选定法院、代提交、未知写零。本任务不定罪，不写连带成立，不写不会被否认，不代提交。本窗闸名只能是一人闸，禁止复用选型闸、设立闸、章程闸、变更闸、条款闸、关系闸。本窗 `YR#` 是一人安排行。英文 id 禁止使用，一律用中文技能名 `准备一人公司特殊安排`。主路径只用 `Q-一`，禁止 `Q-选`、`Q-设`、`Q-章` 作主路径。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 2018 年第五十八条当一人再设限制、第六十三条当现行第二十三条第三款、把第五十九条第三款多股东书面一致套进一人决定时记为噪声。禁止指导倒签书面决定或补造隔离合同。伤残等级与本窗无关。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现一人碎片扫描，不是默认闭集。
`YR#` 固定列：`编号｜安排切片｜一人身份｜财产独立措施｜书面决定要点｜举证责任接口｜登记公示｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。无 `E#` 不得写已独立、已免连带、已合法决定、已签署或已置备。`E#` 只作证据形态回链，不是发送闸。扫描不是闭集。缺项记 `G#`。承认只进 `S#`／`D#`，不得占用 `A#`。文件状态只用 `草案`、`待签署`、`停止`。

口头「财产已经独立了」「决定早就做了」「不会被否认」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：第二十三条第三款举证责任在股东，本窗只开接口。第六十条一人有限不设股东会，书面决定须签名或盖章后置备。置备不是已对外对抗善意第三人。2018 年一人再设限制已删。

## 节点 0　分流、立场、一人闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、倒签书面决定、补造隔离合同、销毁账册、伪造签名、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `YR#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是人格否认终局评估 | 负触发 `评估法人人格否认` |
| 主成果是夫妻共同财产或继承归属 | 负触发婚家 |
| 主成果是设立登记包独占 | 负触发 `准备公司设立文件与登记` |
| 主成果是普通多股东章程终稿 | 负触发 `起草或修订公司章程` |
| 主成果是多股东书面一致 | 负触发 `准备书面一致同意决定` |
| 主成果是代持效力与显名终稿 | 负触发 `评估股权代持效力与显名` |
| 主成果是未出资或抽逃补充清偿 | 负触发 `评估股东对公司债务的补充清偿责任` |
| 主成果是类型比较 | 负触发 `选择公司类型与机关结构` |
| 主成果是投并购交割或尽调闭环 | 整案转投并购 |
| 主成果是破产重整 | 整案转破产 |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不写已独立」「不写连带成立」「不代提交」 | 交付禁令，不是负触发 |

出现「一人」「独立」「书面决定」一词不是转出。措施即已独立不是负触发，该格不支持。尚未确认一人身份但主成果仍是一人安排包：正触发关闸，第 7 节开选型或设立接口。

一人闸打开（可出 `YR#` 草案，仍不得标「已独立／已免连带／已合法决定」）须同时满足：单方无冲突立场已闭合；主成果是一人财产独立与书面决定安排草案，不是人格否认终局、不是婚家分割、不是设立包独占、不是多股东章程终稿；至少一项可编号一人身份碎片（登记或名册显示股东为一人，或拟设一人）。口头「财产已经独立了」不算单独开闸材料。仅有措施碎片而无一人身份碎片：不得开闸。

一人闸部分打开：已有一人身份碎片，但措施、书面决定或举证责任未闭合；对应格待核；仍交十节。无书面安排授权但立场已闭合且有拟设或已成立一人身份碎片：部分打开，不是整体停止。

一人闸关闭（仍正触发）：无一可编号一人身份碎片。「今天必须出已独立／已免连带终稿」而无最小身份碎片不得开闸。不出 `YR#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `YR#` 终稿，**第 7 节不得出已独立或已免连带**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「措施即已独立」「账户分开即已独立」「缺书面即已合法」「2018 一人只能设一个当现行」「一人股份自动套第六十条全文」「置备即对外对抗」「未知写零」「凭记忆必须年审或执照必须注独资」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `YR#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号一人身份碎片，then 一人闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立债权人、隐名投资人或配偶相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出倒签书面决定、补造隔离合同、补造租赁或借款合同掩盖混同、销毁账册、伪造签名、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个主体或强制接口。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `YR#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 身份 | 拟设／存续；自然人／法人；有限／股份 | 名义一人按一人关机关 |
| 措施 | 独立账户、独立账簿、往来、场所对价、关联担保、个人费用隔离 | 清单升格已独立或已免连带 |
| 书面决定 | 第 59 条第 1 款事项；签名或盖章；置备 | 缺书面写成已合法；倒签 |
| 举证接口 | 第 23 条第 3 款举证责任在股东 | 写连带成立或不会被否认 |
| 登记公示 | 执照独资标注、年审是否仍强制 | 凭 2018 写必须年审或必须注独资 |

检索锚点（写入 `L#` 前须核验）：

- 第二十三条：第一款纵向滥用连带；第二款横向混同连带；第三款一人不能证明财产独立则连带。本窗只开第三款接口。噪声：2018 年第六十三条。
- 第四十二条：有限一个以上五十个以下。一人有限合法。
- 第五十八条：现行是有限股东会组成。噪声：2018 年第五十八条一人再设限制。
- 第五十九条：第一款职权；第三款多股东书面一致须全体签名或盖章。不得与第六十条混套。
- 第六十条：一人有限不设股东会；前条第一款事项须书面、签名或盖章后置备。
- 第九十二条：股份发起人一人以上二百人以下。一人股份已允许。
- 第一百一十二条：第一款准用第五十九条第一、二款，不准用第三款；第二款第六十条不设股东会适用于一人股份。书面决定全文是否一并准用须核验，不得自动套第六十条全文，也不得写成一人股份必须开会。
- 2018 年第六十二条一人年报强制审计、2018 年第五十九条执照注明自然人独资或法人独资：是否仍由现行法或登记规章保留须核验；未核验字段停止。

不得暗示「措施清单一做就不会被否认」。

## 节点 3　一人安排行 `YR#`

按已出现一人身份扫描，不是默认闭集。有限与股份、拟设与存续、自然人与法人分列。

无 `E#` 不得写已独立、已免连带、已合法决定、已签署或已置备。状态默认 `草案`。一次只推荐下一步。未知不写零。措施清单不得出已独立结论。缺书面决定不得出已合法决定。代持名义一人不得关闭股东会。一人股份书面决定全文待核第 112 条第 2 款。

热冲突强制处理：

- 措施即已独立／账户分开即已独立／缺书面即已合法／2018 限制当现行／一人股份自动套第六十条全文／置备即对外对抗／估数或写零 → 该格不支持或字段停止；仍出其他 `YR#`。
- 无一一人身份碎片 → 关闸，不出 `YR#` 终稿，窗口不关。
- 指导倒签书面决定、补造隔离合同、销毁账册、抢夺印章 → 整体停止，不是该格不支持。

## 节点 4　设立、章程、书面一致、代持与人格否认接口

第 7 节只开接口，不得夹带 `YR#` 终稿、已独立或已免连带绕闸。闸关闭时第 7 节可写「闸未开，转介待一人身份编号」，不得补写已独立。夹带设立只开设立窗接口。新章程只开起草接口。人格否认终局只开评估窗接口。

下一步只转介：`选择公司类型与机关结构`、`准备公司设立文件与登记`、`起草或修订公司章程`、`准备书面一致同意决定`、`评估法人人格否认`、`评估股权代持效力与显名`、`评估股东对公司债务的补充清偿责任`。禁止此致某登记机关为唯一路径。不代提交。不代签署。

若 if 用户催促「措施清单一做就独立／缺的决定先倒签／2018 只能设一个还有效」，then 该格 `现有依据不支持` 或字段停止；提出倒签则改走整体停止，窗口不关仅适用于未提出伪造方法的错误主张。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「一人闸与一人安排草案」。本窗不执行发送。不包含：已独立证明、已免连带终稿、已合法决定、人格否认判决、设立登记包独占、可签署章程终稿独占。禁止选边治愈。禁止措施即已独立。禁止 2018 限制当现行。禁止指导倒签书面决定或补造隔离合同。

## 场景对抗（运行时自检，不写入用户可见闭集）
