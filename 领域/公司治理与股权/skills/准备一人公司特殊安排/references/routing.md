# 边界与路由

## 正触发

拟设或存续的一人公司需要财产独立措施、书面决定记载或第二十三条第三款举证责任接口，而不是人格否认终局、婚家定性、普通多股东章程或设立登记包独占。从零、碎片、措施未核验、无书面安排授权仍正触发：有一人身份碎片则闸开或半开，出 `YR#` 草案，保持草案。本次不写已独立、不写连带成立、不代提交是交付禁令，不是开窗条件。措施即已独立、缺书面即已合法、2018 一人只能设一个当现行，仍正触发。

双方秘密、倒签书面决定、补造隔离合同、补造租赁或借款合同掩盖混同、销毁账册、伪造签名、抢夺印章证照、违法取证的停止，优先于负触发。上述信号不在下表。「措施即已独立」「缺书面即已合法」「2018 一人只能设一个当现行」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 人格否认终局评估 | `评估法人人格否认` |
| 夫妻共同财产或继承归属 | 婚家领域 |
| 设立登记包独占 | `准备公司设立文件与登记` |
| 普通多股东章程或修正案终稿 | `起草或修订公司章程` |
| 多股东书面一致同意 | `准备书面一致同意决定` |
| 代持效力与显名终稿 | `评估股权代持效力与显名` |
| 未出资或抽逃补充清偿 | `评估股东对公司债务的补充清偿责任` |
| 类型比较草案 | `选择公司类型与机关结构` |
| 合伙或个人独资 | 非公司主体 |

不得因「不写已独立」或「不写连带成立」关窗。拟设或存续一人安排仍正触发，不得写成已独立或已免连带。尚未确认一人身份但主成果仍是一人安排包：正触发关闸，第 7 节开选型或设立接口。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |
| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「一人」「独立」「书面决定」一词不是转出。

## 易混

本窗闸名只能是一人闸，禁止复用选型闸、设立闸、章程闸、变更闸、条款闸、关系闸。隔离措施清单不是已独立。账户分开不是已独立。缺书面决定不是已合法决定。2018 一个自然人只能设一个一人有限不是现行。一人股份不得自动套第六十条全文。第六十条一人书面决定不是第五十九条第三款多股东书面一致。置备不是已对外对抗善意第三人。第二十三条第三款只开举证责任接口，不写连带成立。现行第五十八条是有限股东会组成，不是 2018 年一人再设限制。本窗 `YR#` 不是选型窗 `XX#`，不是设立窗 `XS#`，不是章程窗 `CZ#`。「决定日先倒签」「隔离合同先补造」「今晚把账做干净」整体停止。本窗不执行发送，不代提交，不代签署。不保证免责。伤残等级与本窗无关。
