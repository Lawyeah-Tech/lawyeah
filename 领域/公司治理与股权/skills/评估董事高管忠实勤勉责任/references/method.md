# 评估董事高管忠实勤勉责任方法

本文件是可执行判断节点。自我交易未经报告不是当然合同无效。竞业不是当然归入。商业判断失误不是当然违反勤勉。已报告决议不是当然免责。劳动合同解除不是本窗赔偿终局。刑责不是本窗定罪。未知损失不写零。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已违信终局、当然归入、选定法院、代提交、未知写零、唯一必得总额。本任务不定罪，不执行发送，不写诉状。本窗闸名只能是忠实闸，禁止复用董事闸、监事闸、责任闸、清偿闸、起诉闸。预留不得占用：僵局闸、谈判闸、和解闸、立案闸。本窗 `ZS#` 是忠实行。英文 id 禁止使用，一律用中文技能名 `评估董事高管忠实勤勉责任`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年第一百八十条法定公益金、2018 年第一百四十七条／第一百四十八条当现行、把归入写成第一百八十五条、把自我交易写成合同当然无效时记为噪声。禁止指导伪造批准或倒签决议。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现身份或行为扫描，不是默认闭集。
`ZS#` 固定列：`编号｜身份｜义务类型｜报告与决议抗辩｜回避接口｜损失与归入接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已违信」或「已归入」。无 `E#` 不得写已批准或已归入。`E#` 只作证据形态回链，不是发送闸。扫描不是闭集。缺项记 `G#`。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-忠`。禁止 `DH#`、`JS#`、`BC#`、`SZ#`、`A#`、`N#`。

口头「这单买卖当然无效」「判断错了就得赔」「口头说过就算批了」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：自我交易不以损害公司利益为认定前提，但仍不是合同当然无效；合同效力另开接口。商业判断规则通常审查是否充分知情、善意、无利益冲突，不审查决策对错本身；依据不足则不定责。已依法报告并决议通过可减弱相应忠实路径，仍须核验决议本身效力，不得写成当然免责。劳动解除、经济补偿与公司法责任不得合成一笔。

## 节点 0　分流、立场、忠实闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造批准或决议、倒签会议、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `ZS#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是劳动合同解除、补偿或劳动竞业 | 负触发并整案转劳动领域 |
| 主成果是刑责专项 | 负触发并整案转刑事，本窗不定罪 |
| 主成果是代表诉讼诉状 | 负触发 `提起股东代表诉讼` |
| 主成果是代表诉讼前置请求 | 负触发 `准备代表诉讼前置书面请求` |
| 主成果是关联交易实体评估 | 负触发 `评估关联交易与回避表决` |
| 主成果是控股股东责任终局 | 负触发 `评估控股股东实际控制人责任` |
| 主成果是任免登记包 | 负触发 `准备董事高管任免与登记` |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不写诉状」「不定罪」 | 交付禁令，不是负触发 |

出现「忠实」「勤勉」「自我交易」一词不是转出。劳动一词出现但主成果仍是公司法义务路径：正触发，劳动格不支持或只开接口。

忠实闸打开（可出 `ZS#` 草案，仍不得标「已违信／已归入／合同当然无效」）须同时满足：单方无冲突立场已闭合；主成果是责任路径评估，不是诉状、不是劳动裁决、不是刑事意见；至少一项可编号身份或行为碎片。口头「这单买卖当然无效」不算单独开闸材料。

忠实闸部分打开：已有碎片，但身份、报告决议或损失未闭合；对应格待核；仍交十节。

忠实闸关闭（仍正触发）：无一可编号碎片。「今天必须出已违信终稿」而无最小碎片不得开闸。不出 `ZS#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `ZS#` 终稿，**第 7 节不得出已违信结论或诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「自我交易即合同当然无效」「竞业即当然归入」「商业判断失误即当然违勤勉」「已报告决议即当然免责」「劳动解除即本窗赔偿」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `ZS#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 忠实闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与对立董事或股东相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造批准或决议、倒签会议、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个身份或行为。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `ZS#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 身份 | 董事／监事／高管／实际执行事务的控股股东或实际控制人分列 | 劳动身份写成公司法赔偿已成立 |
| 义务类型 | 忠实／勤勉／自我交易／机会／竞业分列 | 合成一笔「违信当然赔」 |
| 报告决议 | 是否报告、哪一机关、回避 | 口头说过即已批准 |
| 损失归入 | 公司损失与收入分列 | 未知写零或唯一必得总额 |

检索锚点（写入 `L#` 前须核验）：

- 第一百八十条：忠实与勤勉分列；控股股东、实际控制人不担任董事但实际执行公司事务的适用。噪声：1993 年第一百八十条法定公益金。
- 第一百八十一条：侵占、挪用、私存、贿赂、佣金归己、擅自披露等禁止行为。
- 第一百八十二条：自我交易应当报告并按章程经董事会或股东会决议；近亲属及关联人适用。未经报告不是当然合同无效。
- 第一百八十三条：不得谋取公司商业机会；已报告决议或公司不能利用的除外。
- 第一百八十四条：未经报告决议不得自营或为他人经营同类业务。
- 第一百八十五条：对第一百八十二条至第一百八十四条事项关联董事回避、不足三人提交股东会。只开接口。不得把归入写成本条。
- 第一百八十六条：违反第一百八十一条至第一百八十四条所得收入应当归公司所有。竞业不是当然归入可执行金额。
- 给公司造成损失的赔偿常见检索须核验全文，不得输出唯一必得总额。
- 第一百九十一条：对第三人故意或重大过失只开接口，本窗不写已对第三人赔偿终局。
- 第一百九十二条：指示连带只开 `评估控股股东实际控制人责任` 接口。
- 第二十二条：利用关联关系损害公司利益只开关联交易窗接口。
- 代表诉讼常见检索第一百八十九条须核验，本窗不写诉状。噪声：2018 年第一百五十一条。

## 节点 3　忠实行 `ZS#`

按已出现身份或行为扫描，不是默认闭集。每条须能指向身份、义务类型和报告决议或损失接口。

无 `E#` 不得写已批准或已归入。状态默认 `草案`。一次只推荐下一步。未知金额不写零，不输出唯一必得总额。

热冲突强制处理：

- 自我交易即合同当然无效／竞业即当然归入／商业判断失误即当然违勤勉／已报告决议即当然免责／劳动解除即本窗赔偿／未知写零 → 该格不支持或字段停止；仍出其他 `ZS#`。
- 无一碎片 → 关闸，不出 `ZS#` 终稿，窗口不关。
- 指导伪造批准、倒签决议 → 整体停止，不是该格不支持。

关联回避只开接口。指示连带只开控制股东窗。对第三人责任只开接口。

## 节点 4　劳动、代表诉讼、关联与控制股东接口

第 7 节只开接口，不得夹带 `ZS#` 终稿、已违信结论或诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待身份或行为编号」，不得补写已违信。不选定法院。不定罪。不代提交。

下一步只转介：`提起股东代表诉讼`、`准备代表诉讼前置书面请求`、`评估股东代表诉讼条件`、`评估关联交易与回避表决`、`评估控股股东实际控制人责任`、`准备董事高管任免与登记`、`准备监事会或审计委员会履职文件`。禁止此致某法院。

若 if 用户催促「这单买卖当然无效／判断错了就得赔／口头说过就算批了／把解除金填进来」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「忠实闸与忠实行草案」。本窗不执行发送。不包含：已违信终局、已归入金额、劳动裁决、刑事意见、代表诉讼起诉状。禁止选边治愈。禁止自我交易即合同当然无效。禁止竞业即当然归入。禁止商业判断失误即当然违勤勉。禁止已报告即当然免责。禁止指导伪造批准。忠实闸打开 ≠ 已违信 ≠ 已归入 ≠ 已赔偿。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：董事与公司签了一份未经董事会报告的采购合同，同时在外经营同类业务，一次投资判断失败。用户主张合同当然无效、竞业收入当然归入、判断错了就得赔、口头跟董事长说过就算批了、把劳动解除金填成公司法赔偿、损失未知写成零。忠实闸打开或半开。`Q-无`、`Q-归`、`Q-误`、`Q-免`、`Q-零` 不打开为可靠路径。第 6 节不得把合同已无效、已归入、已违勤勉写入可执行 `ZS#`；对应格 `现有依据不支持`；仍出身份、自我交易报告缺口、竞业碎片、勤勉注意待核等其他 `ZS#`。不关窗。不写诉状。不定罪。

场景②：用户同时交出公司「董事会已批准该自我交易」与对立股东「批准决议是后补倒签」口径，要求选对公司有利的一版，并指导「把批准日期改到签约前」。命中双方秘密＋伪造批准＋倒签决议。第一次整体停止。只交第 1、10 节。不出 `ZS#`。不得问代表哪一方后继续。不以「坚持」为门槛。
