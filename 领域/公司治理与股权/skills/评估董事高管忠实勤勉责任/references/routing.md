# 边界与路由

## 正触发

自我交易、公司机会、竞业或执行职务致损，需要判断公司法上忠实勤勉路径。从零、碎片、报告决议未核验、无书面评估授权仍正触发：有可编号身份或行为碎片则闸开或半开，出 `ZS#` 草案，保持草案。本次不写诉状、不定罪是交付禁令，不是开窗条件。自我交易即合同当然无效、竞业即当然归入、商业判断失误即当然违勤勉、已报告决议即当然免责，仍正触发。

双方秘密、伪造批准或决议、倒签会议、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「自我交易即合同当然无效」「竞业即当然归入」「商业判断失误即当然违勤勉」「已报告决议即当然免责」「劳动解除即本窗赔偿」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 劳动合同解除、补偿或劳动竞业限制 | 劳动领域 |
| 刑责专项 | 刑事（本窗不定罪） |
| 代表诉讼诉状 | `提起股东代表诉讼` |
| 代表诉讼前置请求 | `准备代表诉讼前置书面请求` |
| 关联交易实体评估 | `评估关联交易与回避表决` |
| 控股股东责任终局 | `评估控股股东实际控制人责任` |
| 任免登记包 | `准备董事高管任免与登记` |
| 合伙或个人独资 | 非公司主体 |

不得因「不写诉状」或「不定罪」关窗。拟责任路径评估仍正触发，不得写成已违信或已归入。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |
| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「忠实」「勤勉」「自我交易」一词不是转出。

## 易混

本窗闸名只能是忠实闸。`ZS#` 不是董事窗 `DH#`，不是监事窗 `JS#`，不是清偿窗 `BC#`。自我交易未经报告不是当然合同无效。竞业不是当然归入。商业判断失误不是当然违反勤勉。已报告决议不是当然免责。劳动合同解除不是本窗赔偿终局。刑责不是本窗定罪。归入是第一百八十六条，不是第一百八十五条。第一百八十五条是关联回避只开接口。1993 年第一百八十条法定公益金不是现行忠实勤勉。2018 年第一百四十七条／第一百四十八条不是现行条号。「批准日期改到签约前」整体停止。本窗不执行发送，不代提交。不选定法院。不定罪。
