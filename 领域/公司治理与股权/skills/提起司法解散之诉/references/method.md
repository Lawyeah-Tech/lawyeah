# 提起司法解散之诉方法

本文件是可执行判断节点。诉状草稿不是已立案。其他途径未穷尽且无两年失灵不是已可起诉终稿。盈利不是不得解散。一次流会不是经营管理严重困难。亏损不是必须解散。持股百分之十是表决权，不是当然出资额。被告是公司。同时申请清算不是应一并清算。判决效力及于全体股东。未知不写零。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。文件状态只用 `草案`、`待签署`、`停止`。禁止胜诉率、已立案、必须解散、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不指导伪造或抢章。本窗闸名只能是解散诉闸，禁止复用僵局闸、起诉闸、代表诉闸、查阅诉闸、分配诉闸、立案闸。预留不得占用：谈判闸、和解闸、立案闸、控制闸、登记闸、显名闸。本窗 `JF#` 是解散诉行。主路径只用 `Q-散`，禁止用 `Q-僵`、`Q-诉`、`Q-谈`、`Q-破` 作主路径。禁止占用评估窗 `JJ#`、概括起诉窗 `SZ#`、监事窗 `JS#`、代表诉窗 `DS#`。英文 id 禁止使用，一律用中文技能名 `提起司法解散之诉`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 2018 年第一百八十二条、解释二仍引旧第一百八十三条或第一百八十二条未核对应第二百三十一条、1991 年民事诉讼法第二十七条票据管辖时记为噪声，不得写入 `L#`。禁止指导伪造决议或倒签起诉。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现资格、失灵、替代途径或诉状草稿碎片扫描，不是默认闭集。
`JF#` 固定列：`编号｜原告资格｜严重困难切片｜重大损失接口｜其他途径不能解决｜被告与其他股东地位｜管辖调解接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已立案」。无 `E#` 不得写已持续两年、已穷尽其他途径或已达百分之十表决权。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-散`。禁止 `JJ#`、`SZ#`、`JS#`、`DS#`、`CY#`、`FS#`、`A#`、`N#`。一行一个切片。

口头「已经立案了」「必须解散」只进 `S#`／`V#`，**不得单独算作开闸材料**。评估窗 `JJ#` 不得单独开闸。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。百分之十未核、其他途径未核、被告未列公司不得标 `待签署`。

实务上：原告须在起诉时持有百分之十以上表决权，单独或合计待核；出资额不是当然表决权。经营管理严重困难的侧重点是机关运行障碍；解释二第一条两年以上无法召开或不能作出有效决议、董事长期冲突是受理情形，须核对应第二百三十一条。知情权、利润分配、亏损、资不抵债、吊销未清算为由提起解散，不予受理。其他途径未尝试且无客观不能则已可起诉终稿依据不足。被告为公司，其他股东为第三人；原告坚持以其他股东为被告，告知变更，坚持则驳回对该股东的起诉。解散之诉同时申请清算的，对清算申请不予受理。判决对公司全体股东有拘束力。公司住所地管辖，连结点并列，不选定法院。范本只借栏目。

## 节点 0　分流、立场、解散诉闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造决议或资格、倒签会议或起诉、虚假诉讼、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `JF#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 以股权或资产收购、投资交割、尽调闭环为主要目标 | 整案转投资并购 |
| 婚姻、离婚、继承中的股权归属与分割 | 整案转婚家 |
| 高管劳动合同、解除、竞业劳动后果 | 整案转劳动 |
| 企业级舞弊调查、反商业贿赂、综合合规体系 | 整案转企业合规 |
| 破产申请、重整计划、破产债权申报与分配 | 整案转破产 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 合伙企业、个人独资 | 整案转出，非公司主体 |
| 上市公司发行、持续信息披露或证券监管主轴 | 整案转证券监管／投资并购，本领域只保留公司机关接口 |
| 主成果是僵局评估且尚未决定起诉 | 负触发 `评估公司僵局` |
| 「不代提交」「不定法院」「不给胜诉率」 | 交付禁令，不是负触发 |

出现「解散」「起诉」「僵局」一词不是转出。

解散诉闸打开（可出 `JF#` 草案，仍不得标「已立案」）须同时满足：单方无冲突拟起诉股东立场已闭合；主成果是司法解散起诉包草案，不是僵局评估、不是破产申请；至少一项可编号表决权、机关失灵、失败召集或对峙碎片。口头「已经立案了」不算单独开闸材料。

解散诉闸部分打开：已有碎片，但百分之十、两年、其他途径、列法或管辖未闭合；对应格待核；仍交十节。

解散诉闸关闭（仍正触发）：无一可编号碎片。不出 `JF#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `JF#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已立案」「一次流会即已可起诉终稿」「盈利即不得解散」「亏损即必须解散」「出资额即百分之十门槛」「未尝试即其他途径已穷尽」「知情或分红即解散」「表决权不足即关窗」「漏列公司」「同时申请清算即应一并清算」「有效仲裁当然排除」「选定某院」「网交即已提交」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `JF#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 解散诉闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与对立股东相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造决议或资格、倒签会议或起诉、虚假诉讼、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 3　解散诉行 `JF#`

按已出现资格、失灵、替代途径或诉状草稿碎片扫描，不是默认闭集。无 `E#` 不得写已持续两年、已穷尽其他途径或已达百分之十。状态默认 `草案`。伪造、倒签、抢章红旗出现：整体停止。

热冲突强制处理：

- 草稿即已立案／一次流会即已可起诉终稿／盈利即不得解散／亏损即必须解散／出资额即百分之十门槛／未尝试即其他途径已穷尽／知情或分红即解散／表决权不足即关窗／漏列公司／同时申请清算即应一并清算／有效仲裁当然排除／选定某院／网交即已提交／未知写零 → 该格不支持或字段停止；仍出其他 `JF#`。
- 无一碎片 → 关闸，不出 `JF#` 终稿，窗口不关。
- 指导伪造决议、倒签起诉、抢章 → 整体停止。

管辖调解接口：公司住所地连结点并列，禁止此致某院。解释二第五条、解释五第五条调解只开接口，不是已调解成功。同时申请清算写入该接口：清算申请不予受理，不得写成解散并立即清算已可准。

## 节点 4　僵局评估、退出谈判、破产与庭审接口

第 7 节只开接口，不得夹带 `JF#` 终稿、已立案或破产申请书绕闸。不选定法院。不代提交。

下一步只转介：`评估公司僵局`、`谈判股东退出与僵局安排`、`谈判章程与治理重置`、`提起股东权利诉讼`、`准备股东与公司治理案件庭审`、`评估股东争议管辖与仲裁条款`、`准备股权或公司财产保全`。禁止此致某法院。

若 if 用户催促「已经立案了／必须解散／解散并立即清算」，then 该格 `现有依据不支持`，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：五五持股、两年开不成会、公司仍盈利。用户要诉状此致某区法院、把大股东列为被告、诉请解散并立即清算、网交就算立案、出资百分之十就算表决权、没找过下家也算其他途径穷尽。解散诉闸打开或半开。`Q-立`、`Q-清`、`Q-司`、`Q-院`、`Q-交`、`Q-资`、`Q-他` 不打开为可靠路径。若不提伪造或抢章，第 6 节仍出资格底稿、失灵切片、公司为被告等其他 `JF#`。不关窗。不代提交。不选定法院。
