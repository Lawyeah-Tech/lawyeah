# 提起股东代表诉讼方法

本文件是可执行判断节点。诉状草稿不是已立案。前置未闭合且无紧急具体事实不是已可起诉终稿。口头很急不是情况紧急。百分之一持股不是有限公司门槛。被告不是公司自己。胜诉利益不是归原告股东。调解处分公司利益不得由股东私自放弃。担保请求不是必须提供。未知不写零。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。文件状态只用 `草案`、`待签署`、`停止`。禁止胜诉率、已立案、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不写概括诉讼包。本窗闸名只能是代表诉闸，禁止复用代表诉讼闸、前置请求闸、起诉闸、查阅诉闸、分配诉闸、书面请求闸。预留不得占用：僵局闸、谈判闸、和解闸、立案闸、控制闸、登记闸、显名闸。本窗 `DS#` 是代表诉行。主路径只用 `Q-代诉`，禁止用 `Q-代`、`Q-前`、`Q-诉`、`Q-直` 作主路径。禁止占用评估窗 `DL#`、前置请求窗 `QZ#`、概括起诉窗 `SZ#`、查阅请求窗 `QH#`。英文 id 禁止使用，一律用中文技能名 `提起股东代表诉讼`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年第一百八十九条破产清算、2018 年第一百五十一条、解释四仍引旧第一百五十一条未核验对应、把公司写成唯一被告或把胜诉利益写成归股东时记为噪声，不得写入 `L#`。禁止指导伪造请求或倒签起诉。范本此致某院、原告写成公司、赔偿付给原告不得升格已选定法院、已可起诉或利益归股东。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现资格、公司损害、前置或紧急碎片扫描，不是默认闭集。
`DS#` 固定列：`编号｜原告资格｜前置或紧急接口｜被告与公司地位｜请求与利益归属｜管辖接口｜担保调解接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已立案」或「已可起诉终稿」。无 `E#` 不得写已拒绝、已逾期、已紧急。前置未闭合且紧急未核验不得标 `待签署`。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-代诉`。禁止 `DL#`、`QZ#`、`SZ#`、`QH#`、`A#`、`N#`。有限／股份分列。公司损害／股东直接损害分列。一行一个切片。把公司写成唯一被告：该格不支持，不出终稿。

口头「已经立案了」「很急就能告」只进 `S#`／`V#`，**不得单独算作开闸材料**。评估窗 `DL#`、前置窗 `QZ#` 不得单独开闸。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：原告是符合资格的股东，以自己名义为公司利益起诉。被告是加害董事、监事、高管或他人。公司应当列为第三人，不得写成原告或唯一被告；解释四第二十三条机关代表公司起诉列公司为原告，不是本窗列法。胜诉利益归公司，请求直接付给原告股东不予支持。合理费用是否由公司承担：请求部分或全部得到支持后才打开，本窗只开接口。调解须公司意思，章程未定机关时待核股东会，不得设计原告私自放弃公司债权。被告可能申请原告提供担保：只提示，不保证准许或驳回。前置未尽原则上驳回起诉；九民纪要第二十五条只开待核。公司已就同一事实起诉：代位必要性不支持，窗口不关。

## 节点 0　分流、立场、代表诉闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造资格或书面请求、倒签送达或起诉、虚假诉讼、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `DS#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 以股权或资产收购、投资交割、尽调闭环为主要目标 | 整案转投资并购 |
| 婚姻、离婚、继承中的股权归属与分割 | 整案转婚家 |
| 高管劳动合同、解除、竞业劳动后果 | 整案转劳动 |
| 企业级舞弊调查、反商业贿赂、综合合规体系 | 整案转企业合规 |
| 破产申请、重整计划、破产债权申报与分配 | 整案转破产 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 合伙企业、个人独资 | 整案转出，非公司主体 |
| 上市公司发行、持续信息披露或证券监管主轴 | 整案转证券监管／投资并购，本领域只保留公司机关接口 |
| 主成果是条件评估 | 负触发 `评估股东代表诉讼条件` |
| 「不代提交」「不定法院」「不给胜诉率」 | 交付禁令，不是负触发 |

出现「代表诉讼」「起诉」「紧急」一词不是转出。前置未闭合、三十日未满、口头紧急、仲裁条款、公司已起诉不进负表。

代表诉闸打开（可出 `DS#` 草案，仍不得标「已立案／已可起诉终稿」）须同时满足：单方无冲突拟起诉股东立场已闭合；主成果是代表诉讼起诉包草案，不是发函、不是概括诉讼；至少一项可编号资格、公司损害、前置或紧急碎片。口头「已经立案了」不算单独开闸材料。

代表诉闸部分打开：已有碎片，但前置、列法或紧急未闭合；对应格待核；仍交十节。

代表诉闸关闭（仍正触发）：无一可编号碎片。「今天必须出已立案终稿」而无最小碎片不得开闸。不出 `DS#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `DS#` 终稿，**第 7 节不得出已立案或概括诉讼**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已立案」「前置未闭合即已可起诉终稿」「口头很急即紧急」「有限套百分之一」「被告列公司」「胜诉利益归股东」「直接损害即代表诉讼已成立」「有效仲裁当然排除」「选定某院」「网交即已提交」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `DS#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 代表诉闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造资格或书面请求、倒签送达或起诉、虚假诉讼、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `DS#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 原告 | 起诉时股东资格；股份连续一百八十日单独或合计百分之一 | 有限套百分之一门槛 |
| 被告 | 加害董监高或他人 | 公司写成唯一被告 |
| 公司地位 | 通常第三人 | 写成原告；与解释四第二十三条机关起诉列法混写 |
| 利益 | 归公司 | 请求直接付给原告股东 |

检索锚点（写入 `L#` 前须核验）：

- 第一百八十九条：资格、书面请求、三十日、紧急、他人侵害、全资子公司第四款。噪声：1993 年第一百八十九条破产清算；2018 年第一百五十一条。
- 第一百八十八条：责任基础，不是程序条。
- 第一百九十条：直接诉讼分账。
- 解释四第二十三条：机关起诉列公司为原告，不是本窗。
- 解释四第二十四条：列公司为第三人；其他股东可共同原告。仍引旧第一百五十一条须核验对应。
- 解释四第二十五条：胜诉利益归公司。
- 解释四第二十六条：合理费用只开接口。
- 九民纪要第二十五条：前置豁免只开待核。

## 节点 3　代表诉行 `DS#`

按已出现资格、公司损害、前置或紧急碎片扫描，不是默认闭集。每条须能指向资格、前置或列法。

无 `E#` 不得写已拒绝、已逾期、已紧急。状态默认 `草案`。一次只推荐下一步。前置未闭合且紧急未核验：该格不支持已可起诉终稿，窗口不关，不得标 `待签署`。把公司写成唯一被告：不出终稿。

热冲突强制处理：

- 草稿即已立案／前置未闭合即已可起诉终稿／口头很急即紧急／有限套百分之一／被告列公司／胜诉利益归股东／直接损害即代表诉讼已成立／有效仲裁当然排除／选定某院／网交即已提交／未知写零 → 该格不支持或字段停止；仍出其他 `DS#`。
- 无一碎片 → 关闸，不出 `DS#` 终稿，窗口不关。
- 指导伪造请求、倒签起诉、虚假诉讼 → 整体停止，不是该格不支持。

## 节点 4　条件评估、前置发函、直接诉讼与庭审接口

第 7 节只开接口，不得夹带 `DS#` 终稿、已立案结论或概括诉讼绕闸。闸关闭时第 7 节可写「闸未开，转介待起诉编号」，不得补写已立案。不选定法院。不代提交。

下一步只转介：`评估股东代表诉讼条件`、`准备代表诉讼前置书面请求`、`提起股东权利诉讼`、`应对股东权利诉讼`、`准备股东与公司治理案件庭审`、`评估董事高管忠实勤勉责任`、`评估股东争议管辖与仲裁条款`。禁止此致某法院。

若 if 用户催促「已经立案了／没发函也能告／把赔偿打给我／把公司列为被告」，then 该格 `现有依据不支持`，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 再执行清单

每个节点结束后回写：来源、判断、最强反方、是否字段停止。不得跳过代表诉闸直接给已立案或已可起诉终稿。

若 if 前置、紧急具体事实、股份资格、列法、管辖或仲裁、施行日未核验，then 该强制项字段停止，窗口不关。
判断状态只许三值。口头「已经立案了」不得写成 `DS#` 已立案。未知不写零。

## 本任务回链纪律

本任务成果是「代表诉闸与代表诉行草案」。本窗不执行发送。不包含：已立案、已提交、已可起诉终稿、概括诉讼包、评估窗 `DL#`。禁止选边治愈。禁止诉状草稿即已立案。禁止公司为唯一被告。禁止利益归股东。禁止指导伪造起诉。代表诉闸打开 ≠ 已立案 ≠ 已提交 ≠ 已可起诉终稿 ≠ 前置已闭合。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标起诉终稿已形成。
风险档 A：伪造请求、倒签起诉必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：有限公司小股东要告董事侵占，未向监事会发书面请求，口头称很急，要求把公司列为被告、把赔偿打给自己、此致某区法院、网交就算提交、保证能赢。代表诉闸打开或半开。`Q-未`、`Q-急`、`Q-司`、`Q-利`、`Q-院`、`Q-交` 不打开为可靠路径。第 6 节不得把已可起诉终稿、已立案、利益归股东写入可执行 `DS#`；对应格 `现有依据不支持`；仍出资格、正确被告、公司第三人、前置缺口等其他 `DS#`。不关窗。不代提交。

场景②：用户同时交出「还没发前置函」与「把请求函和起诉状日期都改到三十日前」，要求选对股东有利的一版。命中双方秘密＋倒签起诉。第一次整体停止。只交第 1、10 节。不出 `DS#`。不得问代表哪一方后继续。不以「坚持」为门槛。
