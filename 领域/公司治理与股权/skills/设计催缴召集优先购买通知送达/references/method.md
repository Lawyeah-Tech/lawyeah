# 设计催缴召集优先购买通知送达方法

本文件是可执行判断节点。已读不是已送达。发出不是到达。接到书面通知不是已读截图。本窗不写通知实体内容。不执行发送。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已送达、已到达、选定法院、代提交、未知写零。本任务不定罪。本窗闸名只能是送达闸，禁止复用催缴闸、召集闸、优先购买闸、发送闸。预留不得占用：僵局闸、谈判闸、和解闸、立案闸。本窗 `SD#` 是送达行。主路径只用 `Q-送`，禁止用 `Q-达` 作主路径。英文 id 禁止使用，一律用中文技能名 `设计催缴召集优先购买通知送达`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年第八十四条募股申请、2018 年第七十一条未核验对应现行第八十四条、把已读写成已送达、把民事诉讼法第九十条未核验套进公司内部通知时记为噪声。禁止指导伪造回证或已读截图充到达。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现拟送文书种类或相对方扫描，不是默认闭集。
`SD#` 固定列：`编号｜文书种类接口｜地址权源｜渠道组合｜回证形态｜失败升级｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已送达」或「已到达」。无 `E#` 不得写已发出或已送达。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-送`。禁止 `CJ#`、`ZJ#`、`YX#`、`QH#`、`A#`、`N#`。文件状态只用 `草案`、`待签署`、`停止`。地址或渠道未闭合不得标 `待签署`。

口头「微信已读就算送到」「快递发出就算到达」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：催缴宽限期自**发出**之日起算，不是自到达或已读之日起算。优先购买三十日自**接到书面通知**之日起算，不是自已读截图之日起算。有限召集十五日前通知，章程另定除外。股份二十日前、临时十五日前。发出、接到、到达三分列。章程地址、名册地址、合同确认地址冲突并列，不得选边。拒收、无人签、退件只开失败升级接口，不得未核验写成已送达。民诉电子送达须同意，不得直接套公司内部通知。

## 节点 0　分流、立场、送达闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造回证、已读截图充到达、倒签交寄或签收、抢夺印章、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。伪造回证不是负触发。

整案转出只交付第 1、2、10 节，不出 `SD#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是催缴书正文 | 负触发 `准备催缴出资通知` |
| 主成果是召集通知或决议正文 | 负触发 `准备股东会决议与召集` |
| 主成果是优先购买书面通知正文 | 负触发 `准备有限公司股权内部转让` 或 `评估优先购买权是否成立` |
| 主成果是查阅书面请求正文 | 负触发 `准备查阅复制书面请求` |
| 主成果是代表诉讼前置请求正文 | 负触发 `准备代表诉讼前置书面请求` |
| 已发送且只要实体法律效果评估 | 负触发对应评估窗 |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不执行发送」「不写通知正文」「不写已送达」 | 交付禁令，不是负触发 |

出现「送达」「回证」「邮寄」「已读」一词不是转出。

送达闸打开（可出 `SD#` 草案，仍不得标「已发出／已送达／已到达」）须同时满足：单方无冲突立场已闭合；主成果是渠道与回证设计，不是通知正文独占、不是已送达证明、不是伪造到达方案；至少一项可编号拟送文书种类或相对方碎片。口头「微信已读就算送到」不算单独开闸材料。

送达闸部分打开：已有碎片，但地址或渠道未闭合；对应格待核；仍交十节。

送达闸关闭（仍正触发）：无一可编号碎片。「今天必须出已送达终稿」而无最小碎片不得开闸。不出 `SD#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `SD#` 终稿，**第 7 节不得出已送达或通知正文**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「已读即已送达」「微信转发即发出」「发出即到达」「已读截图即接到书面通知」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `SD#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 送达闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造回证、已读截图充到达、倒签交寄或签收、抢夺印章、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个拟送文书种类或相对方。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `SD#` 终稿。本节不写通知正文。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 种类 | 催缴／失权／召集／优先购买／查阅请求分列 | 本窗写正文 |
| 起算 | 发出／接到／到达分列 | 已读写成接到；发出写成到达 |
| 通知期 | 有限十五日（章程另定除外）／股份二十日／临时十五日／优先购买三十日／催缴宽限不少于六十日分列 | 合成一个到达日 |
| 地址 | 章程／名册／合同确认地址分列 | 冲突选边 |

检索锚点（写入 `L#` 前须核验）：

- 第五十一条书面催缴书由公司发出。第五十二条宽限期自**发出**之日起不得少于六十日。发出不是到达。
- 第六十四条有限股东会十五日前通知，章程另有规定或全体股东另有约定除外。
- 第一百一十五条股份二十日前、临时十五日前；公开发行股份的公司应当以公告方式作出通知。
- 第八十四条对外转让书面通知；自**接到书面通知**之日起三十日内未答复视为放弃。接到不是已读截图。噪声：1993 年第八十四条募股申请。
- 解释四第十九条收到通知后起算；期间短于三十日或未明确则为三十日。解释四第二十二条仍引旧第七十一条须核对应现行第八十四条。
- 民事诉讼法第九十条电子送达须受送达人同意，不得未核验套进公司内部通知。

## 节点 3　送达行 `SD#`

按已出现拟送文书种类或相对方扫描，不是默认闭集。每条须能指向地址权源、渠道和回证形态。

无 `E#` 不得写已发出或已送达。状态默认 `草案`。一次只推荐下一步。未知件数不写零。

热冲突强制处理：

- 已读即已送达／发出即到达／已读截图即接到书面通知／未知写零 → 该格不支持或字段停止；仍出其他 `SD#`。
- 无一碎片 → 关闸，不出 `SD#` 终稿，窗口不关。
- 指导伪造回证、已读截图充到达、倒签交寄 → 整体停止，不是该格不支持。
