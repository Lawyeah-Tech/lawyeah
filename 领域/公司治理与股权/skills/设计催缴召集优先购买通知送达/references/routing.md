# 边界与路由

## 正触发

发通知前需单独设计渠道和到达证据，而不写通知实体内容。从零、碎片、地址未核验、无书面送达授权仍正触发：有可编号拟送文书种类或相对方碎片则闸开或半开，出 `SD#` 草案，保持草案。本次不执行发送、不写通知正文、不写已送达是交付禁令，不是开窗条件。已读即已送达、发出即到达、已读截图即接到书面通知，仍正触发。

双方秘密、伪造回证、已读截图充到达、倒签交寄或签收、抢夺印章、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。伪造回证不是负触发。「已读即已送达」「发出即到达」「已读截图即接到书面通知」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 催缴书正文 | `准备催缴出资通知` |
| 召集通知或决议正文 | `准备股东会决议与召集` |
| 优先购买书面通知正文 | `准备有限公司股权内部转让` 或 `评估优先购买权是否成立` |
| 查阅书面请求正文 | `准备查阅复制书面请求` |
| 代表诉讼前置请求正文 | `准备代表诉讼前置书面请求` |
| 已发送且只要实体法律效果评估 | 对应评估窗 |
| 合伙或个人独资 | 非公司主体 |

不得因「不执行发送」「不写通知正文」或「不写已送达」关窗。拟送达设计仍正触发，不得写成已送达或已到达。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |
| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「送达」「回证」「邮寄」「已读」一词不是转出。

| 只要查阅书面请求正文 | `准备查阅复制书面请求` |

## 易混

本窗闸名只能是送达闸，不是催缴闸，不是召集闸，不是优先购买闸。`SD#` 不是催缴窗 `CJ#`，不是召集窗 `ZJ#`，不是优先购买窗 `YX#`。主路径是 `Q-送`，不是 `Q-达`。已读不是已送达。发出不是到达。接到书面通知不是已读截图。催缴宽限期自发出之日起算。优先购买三十日自接到书面通知之日起算。有限召集十五日前通知，章程另定除外。1993 年第八十四条不是现行对外转让通知条。2018 年第七十一条须核对应现行第八十四条。民事诉讼法第九十条不得未核验套公司内部通知。「把已读截图P成回证」「交寄日改到十五日前」整体停止。本窗不执行发送，不代提交。不选定法院。不写通知正文。
