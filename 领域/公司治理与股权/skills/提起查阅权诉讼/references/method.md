# 提起查阅权诉讼方法

本文件是可执行判断节点。诉状草稿不是已立案。十五日未满或账簿凭证未书面请求不是已可起诉终稿。账簿凭证诉讼请求写查阅，不得写成复制，除非核验支持复制。被告原则上是公司。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。文件状态只用 `草案`、`待签署`、`停止`。禁止胜诉率、已立案、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不写概括诉讼包。本窗闸名只能是查阅诉闸，禁止复用查阅闸、书面请求闸、起诉闸、书面闸、决议诉闸。预留不得占用：僵局闸、谈判闸、和解闸、立案闸、控制闸、登记闸、显名闸。本窗 `CY#` 是查阅诉行。主路径只用 `Q-查`，禁止用 `Q-阅`、`Q-请`、`Q-代` 作主路径。禁止占用评估窗 `CK#`、请求函窗 `QH#`、起诉窗 `SZ#`、合规可查性行 `CS#`。英文 id 禁止使用，一律用中文技能名 `提起查阅权诉讼`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年第五十七条任职禁入、2018 年第三十三条、解释四仍引旧第三十三条第九十七条未核验对应、把未书面写成第一款材料诉讼要件时记为噪声，不得写入 `L#`。禁止指导伪造请求或倒签起诉。范本此致某院不得升格已选定法院。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现资格、书面请求或拒绝逾期碎片扫描，不是默认闭集。
`CY#` 固定列：`编号｜原告资格｜材料切片｜查阅或复制｜前置接口｜被告与管辖接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已立案」或「已可起诉终稿」。无 `E#` 不得写已拒绝或已逾期。前置未闭合不得标 `待签署`。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-查`。禁止 `CK#`、`QH#`、`SZ#`、`CS#`、`A#`、`N#`。有限／股份分列。第一款材料与账簿凭证分列。一行一个切片。只列对立股东漏列公司：不出终稿。

口头「已经立案了」「十五日没到也能告」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：知情权义务主体是公司，不是其他股东或董监高。账簿凭证须书面请求，拒绝或逾期可诉；第一款材料可查阅并复制，书面加十五日不是该行法定诉讼要件，可标实务缺口。账簿凭证诉讼请求写查阅；复制权核验失败不得写入请求项。解释四第十条是判决主文应明确时间地点名录，不是本窗已准许中介。仲裁条款不是当然排除法定知情权诉讼，该格待核或字段停止，不得写成当然排除，也不得选定某院。

## 节点 0　分流、立场、查阅诉闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造资格或请求、倒签起诉或送达、虚假诉讼、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `CY#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 以股权或资产收购、投资交割、尽调闭环为主要目标 | 整案转投资并购 |
| 婚姻、离婚、继承中的股权归属与分割 | 整案转婚家 |
| 高管劳动合同、解除、竞业劳动后果 | 整案转劳动 |
| 企业级舞弊调查、反商业贿赂、综合合规体系 | 整案转企业合规 |
| 破产申请、重整计划、破产债权申报与分配 | 整案转破产 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 合伙企业、个人独资 | 整案转出，非公司主体 |
| 上市公司发行、持续信息披露或证券监管主轴 | 整案转证券监管／投资并购，本领域只保留公司机关接口 |
| 主成果是范围或不正当目的评估 | 负触发 `评估股东知情查阅权` |
| 「不代提交」「不定法院」「不给胜诉率」 | 交付禁令，不是负触发 |

出现「查阅」「起诉」一词不是转出。未书面、十五日未满、仲裁条款不进负表。

查阅诉闸打开（可出 `CY#` 草案，仍不得标「已立案／已可起诉终稿」）须同时满足：单方无冲突拟起诉股东立场已闭合；主成果是查阅之诉起诉包草案，不是发函、不是概括诉讼；至少一项可编号资格、书面请求或拒绝逾期碎片。口头「已经立案了」不算单独开闸材料。

查阅诉闸部分打开：已有碎片，但前置、范围或被告未闭合；对应格待核；仍交十节。

查阅诉闸关闭（仍正触发）：无一可编号碎片。「今天必须出已立案终稿」而无最小碎片不得开闸。不出 `CY#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `CY#` 终稿，**第 7 节不得出已立案或概括诉讼**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已立案」「未书面或十五日未满即已可起诉终稿」「账簿凭证当然可复制」「有效仲裁当然排除起诉」「选定某院」「网交即已提交」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `CY#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 查阅诉闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造资格或请求、倒签起诉或送达、虚假诉讼、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个材料切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `CY#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 原告 | 起诉时股东资格或解释四第七条例外 | 名册未载即当然无资格且关窗 |
| 被告 | 公司 | 只列对立股东漏列公司出终稿 |
| 材料 | 第一款／账簿／凭证分列 | 账簿凭证写成复制请求 |
| 前置 | 账簿凭证书面与十五日或拒绝 | 把书面十五日写成第一款诉讼要件 |

检索锚点（写入 `L#` 前须核验）：

- 第五十七条第二款：拒绝可诉。噪声：1993 年第五十七条任职禁入、2018 年第三十三条。
- 第一款材料：查阅并复制，书面加十五日不是该行法定诉讼要件。
- 账簿凭证：诉讼请求写查阅；复制核验失败不得写入。
- 第一百一十条：股份门槛，不得混套有限第五十七条全文。
- 解释四第七至十条仍引旧第三十三条、第九十七条，须核验对应。第十条是判决主文，不是本窗已准许中介。

## 节点 3　查阅诉行 `CY#`

按已出现资格、书面请求或拒绝逾期碎片扫描，不是默认闭集。每条须能指向资格、材料或前置。

无 `E#` 不得写已拒绝或已逾期。状态默认 `草案`。一次只推荐下一步。账簿凭证前置未闭合：该格不支持已可起诉终稿，窗口不关，不得标 `待签署`。只列对立股东漏列公司：不出终稿。

热冲突强制处理：

- 草稿即已立案／未书面或十五日未满即已可起诉终稿／账簿凭证当然可复制／有效仲裁当然排除起诉／选定某院／网交即已提交／未知写零 → 该格不支持或字段停止；仍出其他 `CY#`。
- 无一碎片 → 关闸，不出 `CY#` 终稿，窗口不关。
- 指导伪造请求、倒签起诉、虚假诉讼 → 整体停止，不是该格不支持。

## 节点 4　评估、书面请求、概括诉讼与庭审接口

第 7 节只开接口，不得夹带 `CY#` 终稿、已立案结论或概括诉讼绕闸。闸关闭时第 7 节可写「闸未开，转介待起诉编号」，不得补写已立案。不选定法院。不代提交。

下一步只转介：`评估股东知情查阅权`、`准备查阅复制书面请求`、`提起股东权利诉讼`、`应对股东权利诉讼`、`准备股东与公司治理案件庭审`。禁止此致某法院。

若 if 用户催促「已经立案了／十五日没到也能告／账簿当然能复印」，then 该格 `现有依据不支持`，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

每个节点结束后回写：来源、判断、最强反方、是否字段停止。不得跳过查阅诉闸直接给已立案或已可起诉终稿。

若 if 前置、复制范围、股份持股、管辖或仲裁、施行日未核验，then 该强制项字段停止，窗口不关。
判断状态只许三值。口头「已经立案了」不得写成 `CY#` 已立案。未知不写零。

## 本任务回链纪律

本任务成果是「查阅诉闸与查阅诉行草案」。本窗不执行发送。不包含：已立案、已提交、已可起诉终稿、概括诉讼包。禁止选边治愈。禁止诉状草稿即已立案。禁止账簿凭证当然可复制。禁止指导伪造起诉。查阅诉闸打开 ≠ 已立案 ≠ 已提交 ≠ 已可起诉终稿。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标起诉终稿已形成。
风险档 A：伪造请求、倒签起诉必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：股东要告公司查账簿凭证，微信说过要查，十五日未到。用户主张已经可以起诉终稿、账簿当然能复印、把对立股东也列为被告、此致某区法院、网交就算提交了、保证能赢。查阅诉闸打开或半开。`Q-前`、`Q-复`、`Q-院`、`Q-交` 不打开为可靠路径。被告格须列公司。第 6 节不得把已可起诉终稿、已立案写入可执行 `CY#`；对应格 `现有依据不支持`；仍出资格、材料切片、前置缺口等其他 `CY#`。不关窗。不代提交。

场景②：用户同时交出「还没寄请求」与「把请求函和起诉状日期都改到十五日前」，要求选对股东有利的一版。命中双方秘密＋倒签起诉。第一次整体停止。只交第 1、10 节。不出 `CY#`。不得问代表哪一方后继续。不以「坚持」为门槛。
