# 边界与路由

## 正触发

公司拒绝或逾期不答复，已决定提起查阅之诉。从零、碎片、前置未核验、无书面评估授权仍正触发：有可编号资格、书面请求或拒绝逾期碎片则闸开或半开，出 `CY#` 草案，保持草案。本次不代提交、不定法院、不给胜诉率是交付禁令，不是开窗条件。草稿即已立案、未书面或十五日未满即已可起诉终稿、账簿凭证当然可复制，仍正触发。

双方秘密、伪造资格或请求、倒签起诉或送达、虚假诉讼、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「草稿即已立案」「未书面或十五日未满即已可起诉终稿」「账簿凭证当然可复制」「有效仲裁当然排除起诉」「选定某院」「网交即已提交」不在下表。未书面、十五日未满、仲裁条款不进负表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 范围或不正当目的评估 | `评估股东知情查阅权` |
| 书面请求发函 | `准备查阅复制书面请求` |
| 概括股东诉讼 | `提起股东权利诉讼` |
| 应诉 | `应对股东权利诉讼` |
| 已立案庭审 | `准备股东与公司治理案件庭审` |
| 合伙或个人独资 | 非公司主体 |

不得因「不代提交」或「不定法院」关窗。已决定查阅之诉仍正触发，不得写成已立案或已可起诉终稿。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露或证券监管主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「查阅」「起诉」一词不是转出。

## 易混

本窗闸名只能是查阅诉闸，不是查阅闸，不是书面请求闸，不是起诉闸。`CY#` 不是评估窗 `CK#`，不是请求函窗 `QH#`，不是起诉窗 `SZ#`，不是合规可查性行 `CS#`。主路径是 `Q-查`，不是 `Q-阅`，不是 `Q-请`，不是 `Q-代`。诉状草稿不是已立案。账簿凭证诉讼请求写查阅不是复制。被告原则上是公司。第一款材料书面加十五日不是该行法定诉讼要件。1993 年第五十七条不是现行起诉条。2018 年第三十三条不是现行。解释四旧第三十三条、第九十七条须核验对应第五十七条、第一百一十条。「起诉状日期改到十五日前」整体停止。本窗不执行发送，不代提交。不选定法院。不写概括诉讼包。
