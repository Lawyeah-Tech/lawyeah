# 边界与路由

## 正触发

董事、监事、高管、控股股东或实际控制人的关联交易被质疑，需要识别、报告回避和效力赔偿接口。从零、碎片、关联路径未核验、无书面评估授权仍正触发：有可编号交易相对方或内部人碎片则闸开或半开，出 `GL#` 草案，保持草案。本次不写合同当然无效、不写诉状是交付禁令，不是开窗条件。未回避即合同当然无效、价格争议即当然关联、已报告即当然免责，仍正触发。

双方秘密、伪造回避声明、倒签批准、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「未回避即合同当然无效」「价格争议即当然关联」「已报告即当然免责」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 企业级内部调查或反舞弊合规体系 | 企业合规领域 |
| 调查回避名单 | `处理利益冲突与调查回避` |
| 忠实勤勉责任终局 | `评估董事高管忠实勤勉责任` |
| 决议效力三项终局 | `评估股东会董事会决议效力` |
| 董事会决定草稿 | `准备董事会或执行董事决定` |
| 代表诉讼诉状 | `提起股东代表诉讼` |
| 控股股东责任终局 | `评估控股股东实际控制人责任` |
| 一般买卖合同且无关联结构 | 审查起草／合同领域 |
| 合伙或个人独资 | 非公司主体 |

不得因「不写合同当然无效」或「不写诉状」关窗。拟关联路径评估仍正触发，不得写成合同已无效或已构成关联。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |
| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「关联」「回避」「自我交易」一词不是转出。

## 易混

本窗闸名只能是关联闸，不是关系闸。`GL#` 不是关系窗 `GX#`，不是调查回避窗 `AV#`，不是忠实窗 `ZS#`，不是董事窗 `DH#`，不是效力窗 `XL#`，不是合规并行交卷行 `JY#`。本窗 `Q-关` 不是关系窗主路径。未回避不是合同当然无效。价格争议不是当然关联交易。已报告决议不是当然免责。归入是第一百八十六条不是第一百八十五条。第一百八十五条是关联董事回避。第一百八十二条不得未核验准用控股股东。上市公司第一百三十九条不得套有限。1993 年第二十二条不是现行关联关系条。「批准日期改到签约前」整体停止。本窗不执行发送，不代提交。不选定法院。不定罪。
