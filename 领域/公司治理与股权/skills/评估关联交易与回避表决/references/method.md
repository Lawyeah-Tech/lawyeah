# 评估关联交易与回避表决方法

本文件是可执行判断节点。未回避不是合同当然无效。价格争议不是当然关联交易。已报告决议不是当然免责。归入是第一百八十六条不是第一百八十五条。第一百八十五条是关联董事回避。上市公司第一百三十九条不得未核验套有限。1993 年第二十二条章程记载不是现行关联关系条。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、合同当然无效、已归入终稿、选定法院、代提交、未知写零、唯一必得总额。本任务不定罪，不执行发送，不写诉状。本窗闸名只能是关联闸，禁止复用回避闸、忠实闸、董事闸、决议闸。预留不得占用：僵局闸、谈判闸、和解闸、立案闸。本窗 `GL#` 是关联行。英文 id 禁止使用，一律用中文技能名 `评估关联交易与回避表决`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年第二十二条章程记载当现行关联关系、把归入写成第一百八十五条、把未回避写成合同当然无效时记为噪声。禁止指导伪造回避声明或倒签批准。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现交易或内部人扫描，不是默认闭集。
`GL#` 固定列：`编号｜关联路径｜报告决议｜回避｜合同效力接口｜损害与归入接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「合同已无效」或「已构成关联」。无 `E#` 不得写已批准或已回避。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-关`。禁止 `AV#`、`ZS#`、`DH#`、`XL#`、`JY#`、`A#`、`N#`。

口头「没回避合同就废了」「贵就是关联」「口头说过就算批了」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：公司法并未禁止关联交易。无法指出相对方与内部人的关联路径时，不得因价格争议单独写成关联交易。未履行报告决议或应回避未回避：标程序瑕疵，合同对善意相对人与对公司内部追责分列，不得一律写成无效。已依法报告并决议通过可减弱路径，仍须核验决议效力和交易公允，不得写成当然免责。已履行程序若结果明显不公，赔偿接口仍打开。

## 节点 0　分流、立场、关联闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造回避声明、倒签批准、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `GL#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是企业级内部调查 | 负触发并整案转企业合规 |
| 主成果是调查回避名单 | 负触发 `处理利益冲突与调查回避` |
| 主成果是忠实勤勉责任终局 | 负触发 `评估董事高管忠实勤勉责任` |
| 主成果是决议效力三项终局 | 负触发 `评估股东会董事会决议效力` |
| 主成果是董事会决定草稿 | 负触发 `准备董事会或执行董事决定` |
| 主成果是代表诉讼诉状 | 负触发 `提起股东代表诉讼` |
| 主成果是控股股东责任终局 | 负触发 `评估控股股东实际控制人责任` |
| 一般买卖合同且无关联结构 | 整案转审查起草／合同领域 |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不写合同当然无效」「不写诉状」 | 交付禁令，不是负触发 |

出现「关联」「回避」「自我交易」一词不是转出。

关联闸打开（可出 `GL#` 草案，仍不得标「合同已无效／已构成关联／已归入」）须同时满足：单方无冲突立场已闭合；主成果是关联路径评估，不是诉状、不是调查回避终稿、不是效力三项终局；至少一项可编号交易相对方或内部人碎片。口头「没回避合同就废了」不算单独开闸材料。

关联闸部分打开：已有碎片，但关联路径或回避未闭合；对应格待核；仍交十节。

关联闸关闭（仍正触发）：无一可编号碎片。「今天必须出合同已无效终稿」而无最小碎片不得开闸。不出 `GL#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `GL#` 终稿，**第 7 节不得出合同已无效或诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「未回避即合同当然无效」「价格争议即当然关联」「已报告即当然免责」「归入写成第一百八十五条」「第一百三十九条套有限」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `GL#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 关联闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与对立董事或股东相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造回避声明、倒签批准、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个交易或内部人。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `GL#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 内部人 | 董事／监事／高管／控股股东／实际控制人分列 | 把控股股东未核验套第一百八十二条 |
| 相对方 | 近亲属、控制企业、其他关联人分列 | 价格贵即写成关联方 |
| 机关 | 有限／股份／上市分列 | 第一百三十九条套有限 |
| 回避 | 关联董事不得表决；不足三人交股东会 | 未回避写成合同已无效 |

检索锚点（写入 `L#` 前须核验）：

- 第二十二条：控股股东、实际控制人、董事、监事、高级管理人员不得利用关联关系损害公司利益；给公司造成损失的应当赔偿。噪声：1993 年第二十二条章程记载。
- 第二百六十五条第四项：关联关系定义；国家控股企业之间不仅因为同受国家控股而具有关联关系。第二项控股股东、第三项实际控制人分列。
- 第一百八十二条：董事、监事、高级管理人员自我交易应当报告并按章程经董事会或股东会决议；近亲属及关联人适用。不得未经核验写成控股股东准用本条。
- 第一百八十五条：对第一百八十二条至第一百八十四条事项关联董事不得表决、表决权不计入总数，无关联董事不足三人应当提交股东会。不是归入条。
- 第一百八十六条：违反第一百八十一条至第一百八十四条所得收入应当归公司所有。
- 第一百三十九条：上市公司关联董事书面报告与回避只开上市公司接口，不得套有限。
- 决议效力三项终局转 `评估股东会董事会决议效力`。合同对善意相对人只开接口，本窗不写合同当然无效。

无法指出关联路径：识别字段 `依据不足，无法形成结论`，不得因价格争议单独写成关联交易。

## 节点 3　关联行 `GL#`

按已出现交易或内部人扫描，不是默认闭集。每条须能指向关联路径、报告决议或回避。

无 `E#` 不得写已批准或已回避。状态默认 `草案`。一次只推荐下一步。未知金额不写零，不输出唯一必得总额。

热冲突强制处理：

- 未回避即合同当然无效／价格争议即当然关联／已报告即当然免责／归入写成第一百八十五条／第一百三十九条套有限／未知写零 → 该格不支持或字段停止；仍出其他 `GL#`。
- 无一碎片 → 关闸，不出 `GL#` 终稿，窗口不关。
- 指导伪造回避声明、倒签批准 → 整体停止，不是该格不支持。

回避不足三人只开股东会接口，本窗不硬过。合同对善意相对人与对公司内部追责分列。

## 节点 4　忠实、效力、代表诉讼与合规接口

第 7 节只开接口，不得夹带 `GL#` 终稿、合同已无效结论或诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待交易或内部人编号」，不得补写合同已无效。不选定法院。不定罪。不代提交。

下一步只转介：`评估董事高管忠实勤勉责任`、`评估股东会董事会决议效力`、`准备董事会或执行董事决定`、`提起股东代表诉讼`、`准备代表诉讼前置书面请求`、`评估控股股东实际控制人责任`、`处理利益冲突与调查回避`。禁止此致某法院。

若 if 用户催促「没回避合同就废了／贵就是关联／口头说过就算批了」，then 该格 `现有依据不支持`，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：董事近亲属与公司签采购合同，董事会未回避。用户主张合同当然无效、价格贵就是关联、口头跟董事长说过就算批了、把归入写成第一百八十五条、拿上市公司第一百三十九条套有限、损失未知写成零。关联闸打开或半开。`Q-无`、`Q-价`、`Q-免`、`Q-市`、`Q-零` 不打开为可靠路径。第 6 节不得把合同已无效、已构成关联、已归入写入可执行 `GL#`；对应格 `现有依据不支持`；仍出内部人、相对方、报告缺口、回避接口等其他 `GL#`。不关窗。不写诉状。

场景②：用户同时交出公司「董事会已批准并回避」与对立股东「回避声明是后补、批准日期倒签」口径，要求选对公司有利的一版，并指导「把批准日期改到签约前」。命中双方秘密＋伪造回避声明＋倒签批准。第一次整体停止。只交第 1、10 节。不出 `GL#`。不得问代表哪一方后继续。不以「坚持」为门槛。
