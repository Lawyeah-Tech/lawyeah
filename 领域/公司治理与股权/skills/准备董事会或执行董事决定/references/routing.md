# 边界与路由

## 正触发

需要董事会或一名董事作出经营、催缴核查、失权决议或其他董事会职权范围内决定，并形成发送前草稿。从零、碎片、职权未核验、无书面决定授权仍正触发：有职权或议题碎片则闸开或半开，出 `DH#` 草案，保持草案。本次不执行发送、不把草稿写成已经通过是交付禁令，不是开窗条件。草稿即已通过、创始人方便即已符合一名董事、董事会即已决定增减资，仍正触发。

双方秘密、伪造出席、倒签会议、补签名造已通过、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「草稿即已通过」「创始人方便即已符合一名董事」「董事会即已决定增减资」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 股东会法定职权事项 | `准备股东会决议与召集` |
| 已作出决议的效力终局 | `评估股东会董事会决议效力` |
| 催缴书正文 | `准备催缴出资通知` |
| 失权通知或失权条件终局 | `评估失权与股权丧失` |
| 关联交易实体评估 | `评估关联交易与回避表决` |
| 监事会或审计委员会履职文件 | `准备监事会或审计委员会履职文件` |
| 书面一致同意专项 | `准备书面一致同意决定` |
| 投并购交割清单 | 投资并购领域 |
| 劳动解除补偿谈判 | 劳动领域 |
| 合伙或个人独资 | 非公司主体 |

不得因「不执行发送」或「不把草稿写成已经通过」关窗。拟决定草稿仍正触发，不得写成已通过。事项含催缴或失权但主成果仍是董事会决议草稿：正触发，只开接口。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |
| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「董事会」「决议」「一名董事」一词不是转出。
