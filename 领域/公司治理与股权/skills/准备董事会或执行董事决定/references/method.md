# 准备董事会或执行董事决定方法

本文件是可执行判断节点。草稿不是已经通过。今天开会不是已通过。无权召集不是待发送终稿。创始人方便不是已符合一名董事。2018 执行董事不是现行必须机关名。董事会制订方案不是股东会已经决定。通知期章程未定不得编造一律三日。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已通过、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不写催缴书或失权通知终稿。本窗闸名只能是董事闸，禁止复用决议闸、召集闸、催缴闸、失权闸、评估闸、整改闸、决定闸、董事会闸。预留不得占用：僵局闸、谈判闸、和解闸、立案闸。本窗 `DH#` 是董事行。英文 id 禁止使用，一律用中文技能名 `准备董事会或执行董事决定`。技能中文名可保留「执行董事」历史称呼，正文一律用一名董事。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年第七十三条股份设立条件当现行有限定足数、2018 年执行董事当现行必须机关、2018 年第一百二十四条当现行第一百八十五条、一律三日或十日通知、把草稿写成已经通过时记为噪声。禁止指导伪造出席、倒签会议或补签名造已通过。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现职权或议题扫描，不是默认闭集。
`DH#` 固定列：`编号｜职权范围｜召集与定足数｜回避｜一名董事接口｜决议要点｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。无 `E#` 不得写已通过、已召开或待发送。`E#` 只作证据形态回链，不是发送闸。扫描不是闭集。缺项记 `G#`。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-董`。

口头「今天开了就算过了」「创始人方便就设执行董事」「草稿印出来就是已通过」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。职权未闭合或定足数未核验不得标 `待发送`。

实务上：有限董事会会议应当过半数出席、全体董事过半数通过、一人一票。股份董事会定足数常见检索第一百二十四条，不得未核验套有限。规模较小或人数较少可不设董事会设一名董事，本法未给数值，创始人方便不是已符合。回避后无关联董事不足三人应当提交股东会，本窗不硬过。伪造签名或未开会而作成决议，决议可能不成立。

## 节点 0　分流、立场、董事闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造出席、倒签会议、补签名造已通过、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `DH#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是股东会法定职权事项 | 负触发 `准备股东会决议与召集` |
| 主成果是已作出决议的效力终局 | 负触发 `评估股东会董事会决议效力` |
| 主成果是催缴书正文 | 负触发 `准备催缴出资通知` |
| 主成果是失权通知或失权条件终局 | 负触发 `评估失权与股权丧失` |
| 主成果是关联交易实体评估 | 负触发 `评估关联交易与回避表决` |
| 主成果是监事会或审计委员会履职文件 | 负触发 `准备监事会或审计委员会履职文件` |
| 主成果是书面一致同意专项 | 负触发 `准备书面一致同意决定` |
| 主成果是投并购交割 | 整案转投资并购 |
| 主成果是劳动解除补偿 | 整案转劳动 |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不执行发送」「不把草稿写成已经通过」 | 交付禁令，不是负触发 |

出现「董事会」「决议」「一名董事」一词不是转出。事项含催缴或失权但主成果仍是董事会决议草稿：正触发，第 7 节开接口。

董事闸打开（可出 `DH#` 草案，仍不得标「已通过／已召开／待发送终稿」）须同时满足：单方无冲突立场已闭合；主成果是董事会或一名董事决定草稿，不是股东会决议、不是催缴书、不是失权通知、不是效力终局；至少一项可编号职权或议题碎片。口头「今天开了就算过了」不算单独开闸材料。

董事闸部分打开：已有碎片，但职权、定足数、通知期或回避未闭合；对应格待核；仍交十节。无书面决定授权但立场已闭合且有碎片：部分打开，不是整体停止。

董事闸关闭（仍正触发）：无一可编号碎片。「今天必须出已通过终稿」而无最小碎片不得开闸。不出 `DH#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `DH#` 终稿，**第 7 节不得出已通过决议或催缴书**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已通过」「今天开会即已通过」「无权召集即待发送」「创始人方便即已符合一名董事」「2018 执行董事即现行必须」「董事会即已决定增减资」「一律三日或十日」「未知写零」「回避后不足三人仍硬过」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `DH#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 董事闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与对立董事或股东相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造出席、倒签会议、补签名造已通过、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个职权或议题。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `DH#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 机关 | 有限／股份；董事会／一名董事分列 | 2018 执行董事当现行必须；有限第七十五条套股份第一百二十八条 |
| 职权 | 与股东会法定职权分列 | 修改章程、增减资、合并分立解散、变更形式写成董事会已决 |
| 定足数 | 过半数出席、全体过半数、一人一票待核 | 出席不足仍写已通过 |
| 一名董事 | 规模较小或人数较少待核 | 创始人方便即已符合 |
| 回避 | 关联董事不计入；不足三人提交股东会 | 硬过 |

检索锚点（写入 `L#` 前须核验）：

- 第五十九条股东会职权。董事会制订方案不是已经决定。发行公司债券股东会可授权董事会。
- 第六十七条有限设董事会（第七十五条除外）。章程对董事会职权的限制不得对抗善意相对人。
- 第六十八条董事会三人以上；职工三百人以上除依法设监事会并有职工代表外董事会应当有职工代表。
- 第七十二条董事长召集主持，不能或不履行则副董事长，再由过半数董事推举。
- 有限董事会会议常见检索第七十三条：过半数出席、全体董事过半数通过、一人一票；议事方式除本法有规定外由章程规定。噪声：1993 年第七十三条股份设立条件。
- 第七十五条有限规模较小或人数较少可不设董事会设一名董事，可兼任经理。规模较小本法未给数值。
- 第五十一条、第五十二条催缴核查与失权通知须经董事会决议。本窗出决议草稿不是催缴书不是失权通知终稿。
- 第二十四条会议和表决可以采用电子通信方式，章程另有规定除外。视频开会不是未召开。
- 第一百二十条股份设董事会（第一百二十八条除外）。
- 第一百二十三条股份董事会每年度至少两次、召开十日前通知；不得套有限。
- 第一百二十四条股份过半数出席、全体过半数、一人一票、会议记录签名。不得把有限第七十三条未核验直接套股份。
- 第一百二十八条股份规模较小或人数较少可不设董事会设一名董事。有限第七十五条不是股份第一百二十八条可混套。
- 第一百八十五条对第一百八十二条至第一百八十四条事项，关联董事不得参与表决、表决权不计入总数；无关联董事不足三人应当提交股东会。噪声：1993 年第一百八十五条公司分立；2018 年第一百二十四条当现行未核验。
- 第一百三十九条上市公司关联董事报告与回避只开上市公司接口。

不得暗示「草稿印出来就是已通过」。

## 节点 3　董事行 `DH#`

按已出现职权或议题扫描，不是默认闭集。每条须能指向职权范围、召集定足数、回避和一名董事接口。

无 `E#` 不得写已通过、已召开或待发送。状态默认 `草案`。一次只推荐下一步。未知不写零。出席低于定足数不得写已通过。回避后不足三人：该格开股东会接口，不硬过。一名董事决定应书面，不得伪造董事会会议。

热冲突强制处理：

- 草稿即已通过／今天开会即已通过／无权召集即待发送／创始人方便即已符合／董事会即已决定增减资／一律三日／未知写零 → 该格不支持或字段停止；仍出其他 `DH#`。
- 无一碎片 → 关闸，不出 `DH#` 终稿，窗口不关。
- 指导伪造出席、倒签会议、补签名造已通过 → 整体停止，不是该格不支持。

## 节点 4　股东会、催缴、失权、关联、效力与监事接口

第 7 节只开接口，不得夹带 `DH#` 终稿、已通过决议或催缴书绕闸。闸关闭时第 7 节可写「闸未开，转介待职权或议题编号」，不得补写已通过。不写唯一开会日，不选定法院。不执行发送。

下一步只转介：`准备股东会决议与召集`、`评估股东会董事会决议效力`、`准备催缴出资通知`、`评估失权与股权丧失`、`评估关联交易与回避表决`、`准备监事会或审计委员会履职文件`、`准备书面一致同意决定`、`准备董事高管任免与登记`。禁止此致某法院。不代提交。

若 if 用户催促「今天开了就算过了／方便就设执行董事／增减资董事会拍板／通知一律三日」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：有限公司三人董事会要出经营决定，用户主张草稿印出来就算过了、创始人方便改成执行董事、增减资董事会直接拍板、通知一律三日、回避后只剩两人仍要硬过、金额不清楚先写零。董事闸打开或半开。`Q-过`、`Q-便`、`Q-增`、`Q-三`、`Q-零` 不打开为可靠路径。第 6 节不得把已通过、一名董事已符合、增减资已决写入可执行 `DH#`；对应格不支持或字段停止；仍出职权分列、定足数、回避后交股东会接口等其他 `DH#`。不关窗。不执行发送。

场景②：用户同时交出「全体董事已签字通过」纪要与两名董事「从未开会、签名是后补」口径，要求选对公司有利的一版并指导倒签会议日期、补造缺席董事签名。命中双方秘密＋倒签会议＋补签名造已通过。第一次整体停止。只交第 1、10 节。不出 `DH#`。不得问代表哪一方后继续。不以「坚持」为门槛。
