# 边界与路由

## 正触发

诉讼或仲裁即将开庭，需要争点、举证质证、询问或代理提纲。从零、碎片、举证期未核验、无书面代理授权仍正触发：有可编号开庭碎片则闸开或半开，出 `TS#` 草案，保持草案。本次不给胜诉率、不代开庭、不伪造是交付禁令，不是开窗条件。提纲即已开庭、口头已质证即已质证、网交即已提交、逾期即当然可提交，仍正触发。

双方秘密、伪造证据或笔录、倒签开庭材料、突袭违法证据、抢夺印章、隐匿账簿、指使作伪证、违法取证的停止，优先于负触发。上述信号不在下表。不代开庭不是负触发。「提纲即已开庭」「口头已质证即已质证」「网交即已提交」「逾期即当然可提交」「保证胜诉」「选定法院」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 尚未立案的起诉入口包 | `提起股东权利诉讼` 或对应专项起诉窗 |
| 首次答辩 | `应对股东权利诉讼` |
| 案卷编目终稿 | `建立公司治理与股东争议证据案卷` |
| 可签和解协议 | `起草股东和解或退出协议` |
| 上诉状 | `提起公司治理案件上诉` |
| 管辖或仲裁评估终稿 | `评估股东争议管辖与仲裁条款` |
| 保全申请终稿 | `准备股权或公司财产保全` |
| 鉴定申请终稿 | `准备股权价值或非货币出资鉴定` |
| 劳动庭或破产衍生庭主轴 | 对应领域 |
| 合伙或个人独资 | 非公司主体 |

不得因「不给胜诉率」「不代开庭」或「不伪造」关窗。拟庭审提纲仍正触发，不得写成已开庭或已胜诉。

## 易混

本窗闸名只能是庭审闸，不是起诉闸，不是答辩闸，不是案卷闸，不是和解闸。`TS#` 不是 `SZ#`，不是 `DB#`，不是 `AJ#`，不是 `HJ#`。主路径是 `Q-审`，不是 `Q-诉`，不是 `Q-庭`，不是 `Q-辩`。`Q-庭` 是邻窗转介码，本窗不打开为主路径。本窗 `Q-审` 是庭审主路径，不是选型窗审计委员会码。提纲不是已开庭。口头已质证不是已质证。网交不是已提交。逾期证据不是当然可提交。1991 年或 2017 年民诉不是现行。2008 年证据规定第四十三条不是现行。刑事再审开庭规定不是民事公司治理庭审。「账藏起来别质证」「倒签一份质证笔录」整体停止。本窗不执行发送，不代开庭，不代提交。不选定法院。不给胜诉率。
