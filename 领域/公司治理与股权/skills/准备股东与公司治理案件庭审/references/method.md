# 准备股东与公司治理案件庭审方法

本文件是可执行判断节点。提纲不是已开庭。口头已质证不是已质证。网交不是已提交。逾期证据不是当然可提交。调解提纲不是已和解生效。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已开庭、已质证、已胜诉、选定法院、代开庭、代提交、未知写零。本任务不定罪，不执行发送，不保证结果。本窗闸名只能是庭审闸，禁止复用起诉闸、答辩闸、案卷闸、和解闸、谈判闸、协议闸。预留不得占用：立案闸、保全闸。本窗 `TS#` 是庭审行。主路径只用 `Q-审`，禁止用 `Q-诉`、`Q-庭`、`Q-辩`、`Q-卷`、`Q-和`、`Q-上` 作主路径。本窗 `Q-签` 只作「提纲即已提交」不关窗码。本窗 `Q-审` 是庭审主路径，不是选型窗审计委员会码。英文 id 禁止使用，一律用中文技能名 `准备股东与公司治理案件庭审`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991 或 2017 年民诉旧条、2008 年证据规定当 2019 年修正文本、把刑事再审开庭规定套民事、把提纲写成已开庭或已胜诉时记为噪声。禁止指导伪造证据、突袭违法证据或倒签笔录。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现开庭碎片扫描，不是默认闭集。
`TS#` 固定列：`编号｜争点切片｜本证反证｜质证三性｜询问与承认风险｜调解权限接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已开庭」或「已胜诉」。无 `E#` 不得写已开庭或已质证。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-审`。禁止 `SZ#`、`DB#`、`AJ#`、`HJ#`、`A#`、`N#`。文件状态只用 `草案`、`待签署`、`停止`。举证期、出庭或争点未闭合不得标 `待签署`。

口头「明天开庭一定赢」「微信说质证完了」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。不利证据必须入列。鉴定人只问检材、基准日、标准、程序，不预测改鉴。调解底线不得处分无权处分的公司利益。

## 节点 0　分流、立场、庭审闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造证据或笔录、倒签开庭材料、突袭违法证据、抢夺印章、隐匿账簿、指使作伪证、违法取证不进负表。利益冲突未解不进整体停止。不给胜诉率、不代开庭、不伪造不是负触发。

整案转出只交付第 1、2、10 节，不出 `TS#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是尚未立案的起诉入口包 | 负触发 `提起股东权利诉讼` 或对应专项起诉窗 |
| 主成果是首次答辩 | 负触发 `应对股东权利诉讼` |
| 主成果是案卷编目终稿 | 负触发 `建立公司治理与股东争议证据案卷` |
| 主成果是可签和解协议 | 负触发 `起草股东和解或退出协议` |
| 主成果是上诉状 | 负触发 `提起公司治理案件上诉` |
| 主成果是管辖或仲裁评估终稿 | 负触发 `评估股东争议管辖与仲裁条款` |
| 主成果是保全申请终稿 | 负触发 `准备股权或公司财产保全` |
| 主成果是鉴定申请终稿 | 负触发 `准备股权价值或非货币出资鉴定` |
| 劳动庭或破产衍生庭主轴 | 整案转出对应领域 |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不给胜诉率」「不代开庭」「不伪造」 | 交付禁令，不是负触发 |

出现「庭审」「开庭」「质证」一词不是转出。

庭审闸打开（可出 `TS#` 草案，仍不得标「已开庭／已质证／已胜诉」）须同时满足：单方无冲突立场已闭合；主成果是争点、举证质证、询问或代理提纲，不是起诉包、不是答辩包、不是案卷终稿；至少一项可编号案号、传票、开庭通知、举证通知或争点碎片。口头「明天开庭」不算单独开闸材料。

庭审闸部分打开：已有碎片，但举证期、出庭或争点未闭合；对应格待核；仍交十节。无书面代理授权但单方立场已闭合且已有碎片：庭审闸部分打开，仍交十节，不是整体停止。

庭审闸关闭（仍正触发）：无一可编号碎片。「今天必须出已开庭终稿」而无最小碎片不得开闸。不出 `TS#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `TS#` 终稿，**第 7 节不得出已开庭笔录或保证结果**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「提纲即已开庭」「口头已质证即已质证」「网交即已提交」「逾期即当然可提交」「保证胜诉」「选定法院」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `TS#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 庭审闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造证据或笔录、倒签开庭材料、突袭违法证据、抢夺印章、隐匿账簿、指使作伪证或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个争点切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `TS#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 程序 | 诉讼／仲裁分列 | 选定某院为已定管辖 |
| 争点 | 资格／决议／出资／查阅／分配／代表诉讼／解散／程序分列 | 合成「全案一定赢」 |
| 举证期 | 通知载明期间与解释第九十九条分列 | 已读即逾期；口头即截止 |
| 出庭 | 传票、开庭通知、是否缺席分列 | 缺席当然胜诉或当然败诉 |
| 质证 | 三性与证明力分列 | 举证清单即已质证完毕 |
| 调解 | 权限与公司利益分列 | 调解提纲即已生效；股东私自免除公司债权 |

检索锚点（写入 `L#` 前须核验）：

- 民事诉讼法（2023 修正，施行日 2024-01-01）第七十一条证据应当在法庭上出示并由当事人互相质证。第一百三十九条开庭三日前通知。第一百四十条开庭核对与回避。第一百四十一条法庭调查顺序。第一百四十二条当事人在法庭上可以提出新的证据。噪声：1991 年、2017 年旧条。
- 民事诉讼法解释（2022 修正）第九十九条一审普通程序举证期限不得少于十五日。第一百零三条未经质证不得作为认定根据。第一百零四条三性质证。第一百零六条非法证据排除。第一百零七条调解妥协不得作为不利根据。
- 民事诉讼证据规定（2019 修正）审理前准备或调查询问中发表过质证意见的视为质证过。噪声：2008 年第四十三条。
- 公司法（2023 修订，施行日 2024-07-01）争点实体只开接口，本窗不写成实体终局。

## 节点 3　庭审行 `TS#`

按已出现争点碎片扫描，不是默认闭集。每条须能指向争点、本证或反证之一。不利证据必须入列。

无 `E#` 不得写已开庭或已质证。状态默认 `草案`。一次只推荐下一步。未知不写零，不给胜诉率。举证期、出庭或争点未闭合不得标 `待签署`。

热冲突强制处理：

- 提纲即已开庭／口头已质证即已质证／网交即已提交／逾期即当然可提交／保证胜诉／选定法院／未知写零 → 该格不支持或字段停止；仍出其他 `TS#`。
- 无一碎片 → 关闸，不出 `TS#` 终稿，窗口不关。
- 指导伪造证据、突袭违法证据、倒签笔录 → 整体停止，不是该格不支持。

## 节点 4　起诉、答辩、案卷、和解、上诉与鉴定接口

第 7 节只开接口，不得夹带 `TS#` 终稿或已开庭结论绕闸。闸关闭时第 7 节可写「闸未开，转介待开庭碎片编号」，不得补写已开庭。不选定法院。不代开庭。不代提交。不给胜诉率。

下一步只转介：`提起股东权利诉讼`、`应对股东权利诉讼`、`建立公司治理与股东争议证据案卷`、`起草股东和解或退出协议`、`提起公司治理案件上诉`、`评估股东争议管辖与仲裁条款`、`准备股权或公司财产保全`、`准备股权价值或非货币出资鉴定`。禁止此致某法院为已开庭。

若 if 用户催促「提纲写完就算开完了／口头就算质证完了／一定能赢／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 再执行清单

每个节点结束后回写：来源、判断、最强反方、是否字段停止。不得跳过庭审闸直接给已开庭或已胜诉。

若 if 举证期、出庭、非法证据排除、鉴定人到庭效果、施行日未核验，then 该强制项字段停止，窗口不关。
判断状态只许三值。口头「明天开庭一定赢」不得写成 `TS#` 已开庭。未知不写零。

## 本任务回链纪律

本任务成果是「庭审闸与庭审行草案」。本窗不执行发送。不包含：已开庭笔录、已质证闭环、已胜诉、起诉状终稿、答辩状终稿。禁止选边治愈。禁止提纲即已开庭。禁止保证胜诉。禁止指导伪造证据。庭审闸打开 ≠ 已开庭 ≠ 已质证 ≠ 已胜诉。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标庭审终稿已形成。
风险档 A：伪造证据或笔录、倒签开庭材料、突袭违法证据必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：有案号、开庭通知和决议效力争点碎片。用户主张提纲写完就算开完了、微信说质证完了、逾期证据当然能用、一定能赢、不清楚先写零。庭审闸打开或半开。`Q-纲`、`Q-证`、`Q-新`、`Q-胜`、`Q-零` 不打开为可靠路径。第 6 节不得把已开庭、已质证、已胜诉、0 写入可执行 `TS#`；对应格 `现有依据不支持` 或字段停止；仍出争点分列、本证反证、三性缺口等其他 `TS#`。不关窗。不代开庭。不给胜诉率。

场景②：用户同时交出公司「账藏起来别质证、倒签一份质证笔录」与对立股东「录音证明我们没质证」口径，要求选对公司有利的一版，并指导「明天把那本账拿出来突袭」。命中双方秘密＋伪造笔录＋突袭违法证据＋隐匿账簿。第一次整体停止。只交第 1、10 节。不出 `TS#`。不得问代表哪一方后继续。不以「坚持」为门槛。
