# 边界与路由

## 正触发

债权人主张股东或姐妹公司对公司债务连带，或被追责方抗辩人格否认。从零、碎片、债务未核验仍正触发：有可编号公司债碎片，或滥用、混同、一人身份碎片则闸开或半开，出 `FR#` 草案，保持草案。本次不出诉状、不写已连带、不给胜诉率是交付禁令，不是开窗条件。单一往来即当然否认、一人一定连带，仍正触发。

双方秘密、伪造账册、倒签隔离合同、补造往来、隐匿账簿、抢夺印章证照、违法取证的停止，优先于负触发。上述信号不在下表。「单一往来即当然否认」「部分混同即当然横向」「债不立即写否认」「否认即补充清偿」「一人一定连带或一定免责」「审计即已独立」「2018 条当现行」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未出资、抽逃或未届期加速补充清偿 | `评估股东对公司债务的补充清偿责任` |
| 一人隔离或书面决定安排终稿 | `准备一人公司特殊安排` |
| 控股股东或实际控制人对中小股东滥权 | `评估控股股东实际控制人责任` |
| 诉状、答辩或执行追加终稿 | `提起股东权利诉讼` 或 `应对股东权利诉讼` |
| 破产追加、重整或破产债权 | 破产领域 |
| C 端只要大众股东责任清单 | 大众专项，只分流 |
| 合伙或个人独资 | 非公司主体 |

不得因「不出诉状」或「不写已连带」关窗。要判断第二十三条三款仍正触发，不得写成已连带。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露或证券监管主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「否认」「混同」「连带」一词不是转出。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 只要未出资或抽逃补充清偿 | `评估股东对公司债务的补充清偿责任` |
| 只要一人隔离安排包 | `准备一人公司特殊安排` |
| 只要控股股东内部责任 | `评估控股股东实际控制人责任` |
| 只要诉状或应诉 | `提起股东权利诉讼` 或 `应对股东权利诉讼` |

## 易混

本窗闸名只能是否认闸，不是清偿闸，不是一人闸。`FR#` 不是 `BC#` 不是 `YR#` 不是 `GX#`。主路径是 `Q-否`，不是 `Q-责`，不是 `Q-一`，不是 `Q-人`。单一往来不是当然否认。部分混同不是当然横向否认。债不立则否认无附丽。人格否认连带不是未出资补充清偿。一人不能证明则连带，但不得写一定免责或一定成立。1993 年第二十三条不是现行否认条。2018 年第二十条、第六十三条不是 2024 年 7 月 1 日后的现行条号。九民纪要不得当制定法写入 `L#`。「今晚把账做一套」「把租借合同日期改到三年前」整体停止。本窗不执行发送，不代提交。不选定法院。不写已连带。不指导伪造账册。
