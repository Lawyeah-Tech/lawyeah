# 评估法人人格否认方法

本文件是可执行判断节点。单一往来不是当然否认。部分混同不是当然横向否认。债不立则否认无附丽。人格否认连带不是未出资补充清偿。一人不能证明则连带，但不得写一定免责或一定成立。未知不写零。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已连带、唯一必得总额、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不写诉状，不指导伪造账册。本窗闸名只能是否认闸，禁止复用清偿闸、一人闸、关系闸、瑕疵闸、评估闸、责任闸、补充闸。预留不得占用：僵局闸、谈判闸、和解闸、立案闸。本窗 `FR#` 是否认行。主路径只用 `Q-否`，禁止用 `Q-责`、`Q-一`、`Q-诉`、`Q-追`、`Q-人` 作主路径。禁止占用清偿窗 `BC#`、一人窗 `YR#`、关系窗 `GX#`。英文 id 禁止使用，一律用中文技能名 `评估法人人格否认`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年第二十三条注册资本最低限额、2018 年第二十条或第六十三条未核对应第二十三条、把单一往来写成当然否认时记为噪声，不得写入 `L#`。禁止指导伪造账册、倒签隔离合同或补造往来。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现公司债、滥用、混同或一人身份碎片扫描，不是默认闭集。
`FR#` 固定列：`编号｜否认切片｜债务基础｜纵向滥用｜横向混同｜一人举证｜范围与主体分列｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已连带」。无 `E#` 不得写已否认、横向已坐实或一人已不能证明独立。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-否`。禁止 `BC#`、`YR#`、`GX#`、`XC#`、`SZ#`、`A#`、`N#`。一行一个切片。纵向、横向、一人分列，禁止混成一笔无限连带。

口头「股东肯定连带」只进 `S#`／`V#`，**不得单独算作开闸材料**。清偿窗 `BC#`、一人窗 `YR#` 不得单独开闸。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：第二十三条第一款纵向否认，债权人侧证明滥用、逃避债务、严重损害债权人；责任主体是实施滥用的股东，其他股东不当然连带。第二款横向否认，股东利用其控制的两个以上公司实施前款，各公司对任一公司债务连带；人员、财产、业务、住所分列，部分混同不是当然横向。第三款一人公司，举证责任在股东，不能证明财产独立于股东自己的财产则连带；本窗列隔离证据与混同证据，不写一定免责、不写一定成立。债不立则否认无附丽。人格否认是个案突破有限责任，不是永久消灭法人资格。未出资、抽逃补充清偿范围不同，不得用否认替代或重复计同一笔。非一人公司不得以混同在执行中当然追加股东。九民纪要第十条至第十三条只作实务比较。

## 节点 0　分流、立场、否认闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造账册、倒签隔离合同、补造往来、隐匿账簿、抢章、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `FR#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 以股权或资产收购、投资交割、尽调闭环为主要目标 | 整案转投资并购 |
| 婚姻、离婚、继承中的股权归属与分割 | 整案转婚家 |
| 高管劳动合同、解除、竞业劳动后果 | 整案转劳动 |
| 企业级舞弊调查、反商业贿赂、综合合规体系 | 整案转企业合规 |
| 破产申请、重整计划、破产债权申报与分配 | 整案转破产 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 合伙企业、个人独资 | 整案转出，非公司主体 |
| 上市公司发行、持续信息披露或证券监管主轴 | 整案转证券监管／投资并购，本领域只保留公司机关接口 |
| 主成果是未出资或抽逃补充清偿 | 负触发 `评估股东对公司债务的补充清偿责任` |
| 「不出诉状」「不写已连带」「不给胜诉率」 | 交付禁令，不是负触发 |

出现「否认」「混同」「连带」一词不是转出。

否认闸打开（可出 `FR#` 草案，仍不得标「已连带」）须同时满足：单方无冲突立场已闭合；主成果是否认评估，不是诉状、不是补充清偿终稿、不是一人安排终稿；至少一项可编号公司债碎片，或滥用、混同、一人身份碎片。口头「股东肯定连带」不算单独开闸材料。

否认闸部分打开：已有碎片，但债额、混同四维或一人独立未闭合；对应格待核；仍交十节。债不立：闸可半开，债务基础格依据不足，不得写否认成立。

否认闸关闭（仍正触发）：无一可编号碎片。不出 `FR#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `FR#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「单一往来即当然否认」「部分混同即当然横向」「债不立即写否认」「否认即补充清偿」「一人一定连带或一定免责」「审计即已独立」「2018 条当现行」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `FR#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 否认闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造账册、倒签隔离或借款合同、补造往来、隐匿账簿、抢夺印章证照或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 3　否认行 `FR#`

按已出现公司债、滥用、混同或一人身份碎片扫描，不是默认闭集。无 `E#` 不得写已否认、横向已坐实或一人已不能证明独立。状态默认 `草案`。伪造、倒签、补造红旗出现：整体停止。

热冲突强制处理：

- 单一往来即当然否认／部分混同即当然横向／债不立即写否认／否认即补充清偿／一人一定连带或一定免责／审计即已独立／2018 条当现行／未知写零 → 该格不支持或字段停止；仍出其他 `FR#`。
- 无一碎片 → 关闸，不出 `FR#` 终稿，窗口不关。
- 指导伪造账册、倒签隔离、补造往来 → 整体停止。

范围与主体分列：纵向责任主体是实施滥用的股东；横向是各公司对任一公司债务连带；一人是该唯一股东。不得把三款混成一个无限连带金额。

## 节点 4　清偿、一人、控制人与诉讼接口

第 7 节只开接口，不得夹带 `FR#` 终稿、已连带或诉状绕闸。不选定法院。不代提交。

下一步只转介：`评估股东对公司债务的补充清偿责任`、`准备一人公司特殊安排`、`评估控股股东实际控制人责任`、`提起股东权利诉讼`、`应对股东权利诉讼`。禁止此致某法院。

若 if 用户催促「往来这么多就是混同／一人公司一定赔」，then 该格 `现有依据不支持`，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）
