# 选择公司类型与机关结构

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或文书范本检索。本窗是类型与机关比较草案，范本只借比较表栏目，**不要**升格「已选定／已登记／章程已载明／唯一最优」，**不要**用类案写成必然最优类型。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现股份即有限加大人数、以后好上市即必须股份、创始人方便即已符合规模较小、缺全体一致仍不设监事、有限一名董事加不设监事套股份、有限五年认缴套发起人实缴、比较表即已选定并完成登记的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《民法通则》《民法总则》或其解释当作现行规则。不得把 1993、2004、2013、2018 年《公司法》文本当作 2024 年 7 月 1 日后的现行条号。MCP 效力字段与公布施行日冲突时，以施行日为准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、人数条件、缴付时点或机关例外保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下（拟设股东／发起人、拟改制公司或其受托律师，互斥），形成公司类型与机关结构比较草案：选型闸、主体与强制接口、`Q#` 路径、`XX#` 选型行（类型对照／机关结构／出资缴付对照／必载缺口／登记接口／`E#` 回链）。本窗 `XX#` 是选型行草案，不是已选定证明，不是设立登记申请，不是可签署章程终稿。本窗闸名只能是选型闸，禁止复用设立闸、登记闸、章程闸、变更闸、一人闸、比较闸、类型闸、机关闸、关系闸、决议闸、召集闸。预留不得占用：催缴闸、失权闸、僵局闸、谈判闸、和解闸、立案闸。本窗主行只能是 `XX#`，禁止 `GX#`、`JG#`、`SZ#`、`DB#`。主路径只用 `Q-选`，禁止 `Q-设`。选型闸打开不等于已选定不等于已登记不等于章程已载明不等于已符合一名董事或不设监事条件不等于唯一最优。比较表不是已选定。比较表不是已登记。口头选定不是已选定。以后好上市不是必须设股份。创始人方便不是已符合规模较小或人数较少。有限加大人数不是股份。有限一名董事加不设监事不是股份可套。有限认缴五年不是股份发起人实缴。审计委员会不是已独立。缺全体股东一致同意不是可不设监事。必载缺失不得用默认条款冒充已载明。不锁定唯一最优类型。不写可签署章程终稿。不代提交登记。不选定法院。不写唯一截止日。未知不写零。不定罪。伤残等级与本窗无关，禁止折入。

`depends-on` 为空。主成果是已选定类型只要设立文件与登记转 `准备公司设立文件与登记`。主成果是可签署章程或修正案终稿转 `起草或修订公司章程`。主成果是已决定有限与股份形式变更转 `准备有限公司与股份公司形式变更`。主成果是一人公司财产独立或书面决定专项转 `准备一人公司特殊安排`。主成果是章程与强制性规范冲突评估终稿转 `评估章程与强制性规范冲突`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：设立或改制前需要比较有限／股份与董事会／一名董事、监事会／一名监事／不设监事、审计委员会，尚未进入登记提交。「给我选型建议」仍正触发，成果状态 `草案`，不代提交。人数、授权、必载未核验仍正触发：有可编号拟设主体、股东或发起人人数区间、拟办新设或改制碎片则选型闸打开或半开，第 6 节出 `XX#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出已选定／已登记终稿」才关闸，仍交十节，第 6 节不出 `XX#` 终稿，第 7 节不得出设立申请、已签署章程或已登记，窗口不关。用户要把股份写成有限加大人数、把以后好上市写成必须设股份、把创始人方便写成已符合规模较小、把缺全体一致写成可不设监事、把有限一名董事加不设监事套股份、把有限五年认缴套发起人实缴、把审计委员会写成已独立、把比较表写成已选定并完成登记、把必载缺失用默认条款冒充已载明、把未知写成零或唯一最优，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `XX#` 草案。不得因「不代提交」「不写已签署章程」「不选定唯一最优」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是已选定类型只要设立文件与登记材料（转 `准备公司设立文件与登记`）；
- 主成果是可签署章程或修正案终稿（转 `起草或修订公司章程`）；
- 主成果是已决定有限改股份或相反（转 `准备有限公司与股份公司形式变更`）；
- 主成果是一人公司财产独立、书面决定或举证责任安排终稿（转 `准备一人公司特殊安排`）；
- 主成果是章程与强制性规范冲突评估终稿且不比较类型（转 `评估章程与强制性规范冲突`）；
- 主成果是上市发行、持续信息披露或证券监管；
- 主成果是投并购交割；
- 合伙企业或个人独资选型。

双方秘密、倒签设立会议或创立大会、虚构股东或发起人人数、伪造决议、虚构实缴、抢夺印章证照、隐匿账簿、违法取证**不在负触发表**，走整体停止。「股份即有限加大人数」「以后好上市即必须股份」「创始人方便即已符合例外」「缺一致同意仍不设监事」「有限例外套股份」「五年认缴套发起人」「比较表即已选定或已登记」「唯一最优」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不代提交」「不写已签署章程」「不选定唯一最优」是交付禁令，不是负触发。主成果才转；出现「选型」「比较」「有限」「股份」一词不是转出。

## 建立工作坐标

确认：选型授权；单方立场（拟设股东／发起人、拟改制公司或其受托律师，互斥）；拟办新设或改制；拟股东或发起人人数区间；拟名称／住所／经营范围碎片；拟机关结构；法域；当前协商或登记状态。

口头「就设股份方便上市」「创始人方便」「已经选定了」只登记 `S#`／`V#`。不得升格已选定、必须股份或已符合例外，**不得单独算作开闸材料**。可编号拟设主体、人数区间或拟办新设／改制碎片可开闸。本窗不执行发送，不代提交，不写已签署章程。

立场只许拟设股东／发起人、拟改制公司或其受托律师，互斥。同时掌握对立拟股东或拟设主体相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。一方已开口且委托就是本件比较、且未掌握对方秘密时，可推定该方立场。无一可编号拟设碎片：选型闸关闭，仍交十节，不是整体停止。无书面选型授权但单方立场已闭合、且已有可编号拟设碎片：选型闸部分打开，仍交十节，不是整体停止。提出倒签设立会议或创立大会、虚构股东或发起人人数、伪造决议、虚构实缴、抢夺印章证照、隐匿账簿或违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 章程或股东协议草稿；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`XX#` 选型行；`V#` 版本；`E#` 证据形态回链（拟设碎片、人数区间、机关草稿、授权，不是发送闸，不是已选定证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`EV#`、`M#`、`F#`、`ACT#`、`A#`、`P#`、`EVT#`、`GX#`、`XC#`、`XL#`、`ZJ#`、`ZR#`、`DJ#`、`AJ#`、`TC#`、`SZ#`、`DB#`、`JG#`、`YS#`、`LA#`、`K#`。技能正文中的条号是检索锚点，不是已核验 `L#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。禁止合成「已选定闭环」。扫描不是闭集。未知不写零。比较表 ≠ 已选定。比较表 ≠ 已登记。以后好上市 ≠ 必须股份。创始人方便 ≠ 已符合例外。有限加大人数 ≠ 股份。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：公司法（2023 修订，施行日 2024-07-01）第四十二条有限由一个以上五十个以下股东出资设立。第九十二条股份发起人一人以上二百人以下，其中须有半数以上在中华人民共和国境内有住所。第四十七条有限注册资本为登记的全体股东认缴出资额，自成立之日起五年内缴足，法律、行政法规以及国务院决定对实缴、最低限额、出资期限另有规定的除外；存量公司出资期限调整只开接口，不得把存量过渡写成新设五年。第九十八条发起人应当在公司成立前按照其认购的股份全额缴纳股款，禁止与第四十七条五年认缴混用。第八十四条有限对外转让书面通知优先购买，不得套股份转让。第七十五条规模较小或者股东人数较少的有限公司可以不设董事会、设一名董事，该董事可以兼任经理；「规模较小或者股东人数较少」本法未给数值，创始人方便不是已符合。第六十九条有限可以按照章程在董事会中设置由董事组成的审计委员会，行使监事会职权，不设监事会或者监事；股份第一百二十一条另有三名以上及过半数独立性要求，不得反向套有限。第八十三条规模较小或人数较少可以不设监事会、设一名监事；经全体股东一致同意也可以不设监事；缺一致同意不得打开不设监事。第一百二十八条股份规模较小或人数较少可以设一名董事；第一百三十三条股份可以设一名监事，无「全体一致可不设监事」，不得把有限「一名董事＋不设监事」整包套股份。第十条法定代表人由代表公司执行公司事务的董事或者经理担任，人选未定不编造。第四十六条有限章程必载与第九十五条股份章程必载两套清单不得混用。噪声：2018 年执行董事、第五十一条一至二名监事、第十三条董事长／执行董事口径、第七十一条过半数同意对外转让；1993 年第四十七条董事任期当现行五年缴足。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变人数、缴付、一名董事或不设监事、审计委员会独立性或章程必载的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补规模较小须个案判断、无全体一致不得关监事、股份审计委员会独立性不能套有限第六十九条、发起设立实缴与有限五年不得混用、比较草稿被写成已设立的实务反例。
- `search_template` 只借比较表栏目（类型／人数／机关／出资缴付／必载／登记接口／缺口）。范本名称、签署日、选定结论、登记结论**不得**升格已选定、已登记或章程已载明。禁止用范本生成设立申请或可签署章程终稿。禁止用类案写成必然最优类型。

工具不可用时继续拟设碎片、人数区间和 `XX#` 编目；人数条件、五年／实缴、机关例外、必载清单、施行日字段停止。不得拒跑，不得凭记忆写成已选定、已符合规模或已登记。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、选型闸与不关窗

主成果才整案转出。双方秘密、倒签设立、虚构人数、抢夺印章第一次停。比较表即已选定、必须股份不关窗。闸关仍交十节，第 6 节不出 `XX#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

有限／股份、新设／改制分列。人数、缴付、流转、机关例外分列。本节禁止出 `XX#` 终稿。

### 3. 选型闸与路径 `Q#`

本节禁止出 `XX#` 终稿。有可编号拟设碎片：闸打开或半开。无一可编号件才关闸，窗口不关。口头「就设股份」不得单独开闸。主路径只用 `Q-选`，禁止 `Q-设`。不得预先锁定唯一最优或已登记。

### 4. 选型行 `XX#`

类型对照、机关结构、出资缴付、必载缺口、登记接口分列。状态 `草案`。禁止升格已选定、已登记、章程已载明。无 `E#` 不得写已选定或已登记。

### 5. 设立、章程、形式变更与一人接口

设立文件转 `准备公司设立文件与登记`。章程终稿转 `起草或修订公司章程`。形式变更转 `准备有限公司与股份公司形式变更`。一人专项转 `准备一人公司特殊安排`。第 7 节不得夹带 `XX#` 终稿、已签署章程或登记申请绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出倒签设立会议或创立大会、虚构股东或发起人人数、伪造决议、虚构实缴、抢夺印章证照、隐匿账簿、违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：选型闸关闭，仍交十节，不是整体停止。无书面选型授权但有可编号拟设碎片：选型闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：人数条件、五年缴足例外、发起人实缴、规模较小或人数较少、全体一致同意、审计委员会独立性、必载清单、施行日未核验。股份即有限加大人数、以后好上市即必须股份、创始人方便即已符合例外、缺一致同意仍不设监事、有限例外套股份、五年认缴套发起人、比较表即已选定或已登记、唯一最优、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `XX#` 草案。
- `目标停止`：主目标变为设立登记包、可签署章程终稿、形式变更终稿或一人专项终稿。

禁止指导倒签设立或虚构人数。不给胜诉率。不定罪。不选定法院。不代提交。未知不写零。不写唯一截止日。不锁定唯一最优类型。不写已签署章程。伤残等级禁止折入。
