# 边界与路由

## 正触发

设立或改制前需要比较有限／股份与机关结构，尚未进入登记提交。从零、碎片、人数未核验、无书面选型授权仍正触发：有拟设主体或人数区间则闸开或半开，出 `XX#` 草案，保持草案。本次不代提交、不写已签署章程、不选定唯一最优是交付禁令，不是开窗条件。比较表即已选定、以后好上市即必须股份、创始人方便即已符合例外，仍正触发。

双方秘密、倒签设立会议、虚构人数、虚构实缴、抢夺印章证照、违法取证的停止，优先于负触发。上述信号不在下表。「股份即有限加大人数」「以后好上市即必须股份」「比较表即已选定」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 已选定类型要设立文件与登记 | `准备公司设立文件与登记` |
| 只要可签署章程或修正案 | `起草或修订公司章程` |
| 已决定有限改股份或相反 | `准备有限公司与股份公司形式变更` |
| 一人公司财产独立或书面决定专项 | `准备一人公司特殊安排` |
| 只要章程与强制规范冲突、不比较类型 | `评估章程与强制性规范冲突` |
| 上市发行或持续信披 | 投资并购／证券监管 |
| 投并购交割 | 投资并购领域 |
| 合伙或个人独资 | 非公司主体 |

不得因「不代提交」或「不写已签署章程」关窗。拟比较草案仍正触发，不得写成已选定或已登记。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |
| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「选型」「比较」「有限」「股份」一词不是转出。

## 易混

本窗闸名只能是选型闸，禁止复用设立闸、登记闸、章程闸、变更闸。比较表不是已选定。比较表不是已登记。口头选定不是已选定。以后好上市不是必须设股份。创始人方便不是已符合一名董事或不设监事条件。有限加大人数不是股份。有限一名董事加不设监事不是股份可套。有限认缴五年不是股份发起人实缴。缺全体股东一致同意不是可不设监事。审计委员会不是已独立。2018 年执行董事不是现行机关名。2018 年第十三条不是现行法定代表人条。本窗 `XX#` 不是关系窗 `GX#`，不是设立窗主行，不是合规监管人行 `JG#`。「人数先虚报」「今晚把章先刻好」整体停止。本窗不执行发送，不代提交。不选定唯一最优。伤残等级与本窗无关。
