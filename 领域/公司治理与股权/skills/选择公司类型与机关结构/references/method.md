# 类型与机关比较方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、论坛、期限、金额或文书状态的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然无效、必然失权、必然解散或唯一必得总额。

`search_law` 返回已失效《合同法》、1993／2004／2013／2018《公司法》或仍引用旧第二十二条、第三十三条、第七十一条且未核验对应关系的司法解释时，记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 以股权或资产收购、投资交割、尽调闭环为主要目标 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果、员工激励的劳动身份 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂、综合合规体系 | 企业合规领域 |
| 破产申请、重整计划、破产债权申报与分配 | 破产领域 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

## Q# 矩阵

固定列：`编号｜关系假设｜提出方｜相对方｜法律效果｜成立条件｜支持事实｜不利事实｜控制方｜最强反方｜主备位｜判断｜待核`。

分列有限公司、股份公司、董事会、一名董事、监事会、审计委员会路径。禁止把“灵活治理”写成已经选定并完成登记。


## 节点 1　目标、人数和专项闸

1. 若主目标是发行上市、持续信息披露或证券监管：整案转出，本任务只保留“公司机关接口待核”一行。
2. 若主体拟用合伙企业或个人独资：负触发，不比较有限／股份。
3. 若已选定类型且只要设立文件：负触发，转 `准备公司设立文件与登记`。
4. 股东或发起人人数区间不明：类型结论字段停止，只列法定人数待核表。

---

## 节点 2　有限公司与股份公司

1. 有限责任公司：注册资本为登记的全体股东认缴出资额；缴付期限须核验现行第四十七条及例外。股权对外转让受优先购买和章程另定约束，须核验第八十四条。
2. 股份有限公司：发起设立与募集设立分列。发起人实缴与有限公司认缴五年规则不得混用。股份转让限制与有限公司优先购买不得互相套用。
3. 若用户以“以后好上市”作为唯一理由要求现在设股份公司：标为商业偏好，不写成法律强制。
4. 外商投资准入许可：转涉外领域，本任务只列公司类型比较。

---

## 节点 3　董事会、一名董事、监事与审计委员会

1. 有限公司设董事会；规模较小或者股东人数较少的，可以不设董事会、设一名董事，须核验现行第七十五条。不得把“创始人方便”写成已经符合规模或人数条件。
2. 有限公司可以按章程在董事会中设置由董事组成的审计委员会，行使监事会职权并不设监事会或监事，须核验第六十九条。审计委员会成员是否具备独立性、是否可同时担任经理：核验失败则字段停止。
3. 有限公司设监事会；规模较小或人数较少可设一名监事；经全体股东一致同意也可以不设监事，须核验第八十三条。缺全体一致同意材料：不设监事路径关闭。
4. 股份公司机关法定性高于有限公司。不得把有限公司“一名董事＋不设监事”直接套到股份公司。
5. 法定代表人由代表公司执行公司事务的董事或经理担任，须核验现行第十条。人选未定不编造。

---

## 节点 4　章程必载

1. 有限公司章程应当载明事项须核验第四十六条：名称住所、经营范围、注册资本、股东姓名或名称、出资额方式期限、公司机构及其产生办法职权议事规则、法定代表人产生办法和变更办法等。
2. 股份公司章程必载须核验第九十五条，不得用有限公司清单代替。
3. 冲突：用户草稿缺必载项，标 `依据不足`，不补造对用户有利的默认条款冒充已载明。

## 节点 5　比较表与转介

输出类型情景、机关情景、成本／治理约束和登记接口。不代提交。下一步只能是章程起草、设立准备或形式变更，不得跳到发行上市文件。
