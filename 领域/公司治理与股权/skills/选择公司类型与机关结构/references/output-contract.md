# 输出合同

按触发结果选择交付形状。选型闸未打开不得交付「已选定」或「已登记」。禁止把比较表写成已选定。禁止把以后好上市写成必须设股份。禁止把创始人方便写成已符合规模较小。禁止把有限例外套股份。禁止选边治愈。不锁定唯一最优类型。未知不写零。不定罪。不写已签署章程。不代提交登记。本窗闸名只能是选型闸。本窗 `XX#` 是选型行草案，不是设立申请，不是章程终稿。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出 | 第 1 节（触发与分流）、第 2 节（来源）、第 10 节（交接）。不填第 5–9 节 |
| 整体停止 | 第 1 节（停止原因）、第 10 节。禁止 `XX#` 正文、选边、倒签或虚构人数步骤。双方秘密、倒签设立、虚构人数、虚构实缴、抢夺印章第一次即停，优先于负触发；无选边治愈，无「坚持」门槛 |
| 选型闸关闭（仍正触发） | 十节表头均出现；第 5 节只交闸／`Q#`；第 6 节不出 `XX#` 终稿；第 7 节不得出设立申请、已签署章程或已登记；不得改走负触发或只交 1+2+10 |
| 用户要比较表即已选定、必须股份、方便即已符合例外、未知写零（不关窗） | 十节表头均出现；对应格填 `现有依据不支持` 或字段停止；闸已开仍出其他 `XX#` 草案；不得标终稿 `已形成` |
| 正触发且闸开 | 下列十节表头均出现；未核验格填待核；禁止为填满而写已选定、已登记或唯一最优 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入选型终稿已形成。双方秘密未解不得进入「部分形成」。每个 `XX#`／`Q#` 必须带来源和判断三值。`L#` 不得直接抄技能内条号。稿件状态默认 `草案`。本窗不执行发送。选型闸打开不等于已选定。利益冲突未解不是整体停止。

分流理由只放第 1 节。第 3 节不再写专项分流。第 7 节只保留设立、章程、形式变更与一人接口，不得把 `XX#` 终稿、已签署章程或登记申请改放到第 7 节绕闸。

## 1. 触发、单方立场、选型闸与成果状态

谁要比较。立场互斥。选型闸是否打开。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。不定罪。草案不是已选定。利益冲突未解不是整体停止。

## 2. 来源登记与 MCP 调用表

`S/D/R/C/L/I/G/Q/XX/V/E`。口头「就设股份」「已经选定了」只登记 `S#`／`V#`。`E#` 是证据形态回链，不是发送闸。MCP 未调用也留一行。噪声命中须登记：2018 执行董事、第五十一条一至二名监事、第十三条、第七十一条过半数同意、1993 第四十七条董事任期。禁止 `N#`、`A#`、`JG#`、`GX#`。

## 3. 主体与强制接口

有限／股份、新设／改制分列。人数、缴付、机关例外分列。本节禁止出 `XX#` 终稿。

## 4. 拟设碎片、人数出资与授权

拟设主体、人数区间、机关草稿及其 `E#`。口头不得升格已选定。资本未知记 `G#`，禁止写零。本节禁止出 `XX#` 终稿。

## 5. 选型闸与路径矩阵 `Q#`

本节禁止出 `XX#` 终稿。无件则 `Q-选` 关闭，窗口不关。`Q-市`／`Q-便`／`Q-套`／`Q-五`／`Q-监`／`Q-审`／`Q-定`／`Q-登`／`Q-优`／`Q-零` 不得打开必须股份、已符合例外、已选定、已登记、唯一最优或写零。`Q-立`／`Q-章`／`Q-形`／`Q-一` 只开接口或按主成果负触发。`Q-伪` 不是可打开路径。禁止 `Q-设`。

## 6. 选型行 `XX#`

闸未开不得出选型终稿。闸已开且仅部分格被错误主张打中：仍出其他 `XX#` 草案，被打中的格填 `现有依据不支持`。无 `E#` 不得写已选定或已登记。状态 `草案`。禁止比较表即已选定。禁止必须股份。禁止有限例外套股份。禁止本窗出设立申请或可签署章程。禁止唯一最优。

## 7. 设立、章程、形式变更与一人接口

设立文件只开 `准备公司设立文件与登记` 接口。章程终稿只开 `起草或修订公司章程` 接口。形式变更只开 `准备有限公司与股份公司形式变更` 接口。一人专项只开 `准备一人公司特殊安排` 接口。本节不得夹带 `XX#` 终稿。不代提交。闸未开时只写「转介待拟设编号」，不得补写已选定。

## 8. 边界、转介与最强反方

须列股份即有限加大人数、以后好上市即必须股份、创始人方便即已符合例外、缺一致同意仍不设监事、有限套股份、五年套发起人、比较表即已选定或已登记、唯一最优、未知写零、两边选边等最强反方。

## 9. 风险与下一步

每项含可逆性。一次只推荐下一步。只转介本包准备／起草原子。禁止提交指令、此致某登记机关。不代提交。不写唯一截止日。不选定唯一最优。

## 10. 缺口、停止项与对方最强解释

须列对方最强解释：股份就是有限加大人数、以后要上市现在必须股份、创始人方便所以一名董事和不设监事已经符合、没签字也能不设监事、有限那套直接套股份、五年认缴发起人也一样、比较表填完就算登记、缺的章程条款按范本算已载明、资本不清楚先写零、两边材料选边、人数先虚报成规模较小、今晚把章先刻好。

本成果不是已选定证明、不是设立登记申请、不是可签署章程、不锁定唯一最优。不定罪。草案不是已登记。比较表不是已选定。以后好上市不是必须股份。

## 综合提问的强制降级

用户同时问就设股份方不方便上市、一名董事算不算符合、比较表算不算登记，第 5–8、9 节仍只给接口和转介，对应格不支持，闸已开仍出其他 `XX#`。主成果是设立文件：负触发转 `准备公司设立文件与登记`。提出倒签设立、虚构人数、虚构实缴、抢章或双方秘密：第一次整体停止，只交第 1、10 节，不填第 5–9 节，不把伪造口子降级为不关窗继续出表。
