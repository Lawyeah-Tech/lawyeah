# 边界与路由

## 正触发

已决定专门起诉公司决议不成立、无效或撤销，需要请求类型、被告列法、除斥和起诉材料草案。从零、碎片、除斥未核验仍正触发：有决议切片或请求类型碎片则闸开或半开，出 `XF#` 草案。本次不代提交、不选定法院是交付禁令，不是开窗条件。轻微瑕疵即应撤销、只列对立股东、有效仲裁仍应直接起诉，仍正触发。

双方秘密、伪造决议、倒签会议或起诉状、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「轻微瑕疵即应撤销」「无资格仍提撤销」「只列对立股东即可交」「有效仲裁仍应直接起诉」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 效力评估终稿 | `评估股东会董事会决议效力` |
| 程序瑕疵表 | `评估召集主持表决程序瑕疵` |
| 概括股东诉讼 | `提起股东权利诉讼` |
| 应诉答辩 | `应对股东权利诉讼` |
| 管辖或仲裁效力评估终稿 | `评估股东争议管辖与仲裁条款` |
| 已立案后的庭审 | `准备股东与公司治理案件庭审` |
| 合伙或个人独资 | 非公司主体 |

不得因「不代提交」关窗。有效仲裁不是负触发关窗，该格不支持。

出现「决议」「撤销」「起诉」一词不是转出。

## 易混

本窗闸名只能是决议诉闸。草稿不是已立案。轻微瑕疵不是当然应撤销。无股东资格不是可提撤销。只列对立股东不是可交终稿。不成立四项穷尽。无效或不成立不适用撤销六十日。2018 年第二十二条不是现行撤销条。1993 年第二十五条／第二十七条不是现行效力条。本窗 `XF#` 不是效力窗 `XL#`，不是概括起诉窗 `SZ#`。「起诉状日期倒签进六十日」整体停止。本窗不执行发送，不代提交。不选定法院。
