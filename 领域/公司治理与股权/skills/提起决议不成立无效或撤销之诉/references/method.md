# 提起决议不成立无效或撤销之诉方法

本文件是可执行判断节点。草稿不是已立案。轻微瑕疵不是当然应撤销。无股东资格不是可提撤销。只列对立股东不是可交终稿。有效仲裁不是应起诉。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、应撤销终稿、已立案、选定法院、代提交、未知写零。本任务不定罪，不代提交。本窗闸名只能是决议诉闸，禁止复用决议闸、起诉闸、答辩闸、召集闸。预留不得占用：僵局闸、谈判闸、和解闸、立案闸。本窗 `XF#` 是决议诉行。英文 id 禁止使用，一律用中文技能名 `提起决议不成立无效或撤销之诉`。技能名无顿号。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年第二十五条出资、第二十七条验资、2018 年第二十二条当现行撤销条、解释四其他情形当不成立口袋、2017 年民诉第一百一十九条当现行起诉条件时记为噪声。禁止指导伪造决议或倒签起诉。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现决议切片扫描，不是默认闭集。
`XF#` 固定列：`编号｜原告资格｜请求类型｜被告列法｜除斥接口｜管辖接口｜证据目录｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。无 `E#` 不得写已立案或应撤销。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-决`。

口头「已经立案了」「迟一天就必须撤」「告大股东就行」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。已有案号不得继续生成起诉入口终稿。

实务上：决议之诉原则上以公司为被告。撤销原告须在起诉时具有股东资格。召集程序或表决方式仅有轻微瑕疵且对决议未产生实质影响的，通常不支持撤销。不成立限于第二十七条四项，不得另开口袋。

## 节点 0　分流、立场、决议诉闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造决议、倒签会议或起诉状、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `XF#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是效力评估终稿 | 负触发 `评估股东会董事会决议效力` |
| 主成果是程序瑕疵表 | 负触发 `评估召集主持表决程序瑕疵` |
| 主成果是概括股东诉讼 | 负触发 `提起股东权利诉讼` |
| 主成果是应诉答辩 | 负触发 `应对股东权利诉讼` |
| 主成果是管辖或仲裁效力评估终稿 | 负触发 `评估股东争议管辖与仲裁条款` |
| 主成果是已立案后的庭审 | 负触发 `准备股东与公司治理案件庭审` |
| 合伙或个人独资 | 整案转出 |
| 「不代提交」「不选定法院」 | 交付禁令，不是负触发 |

出现「决议」「撤销」「起诉」一词不是转出。有效仲裁仍应直接起诉不是负触发，该格不支持。

决议诉闸打开须同时满足：单方无冲突立场已闭合；主成果是决议之诉起诉包草案；至少一项可编号决议切片或请求类型碎片。口头「已经立案了」不算单独开闸材料。

决议诉闸部分打开：已有碎片，但资格、除斥或被告列法未闭合；对应格待核；仍交十节。

决议诉闸关闭（仍正触发）：无一可编号碎片。不出 `XF#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `XF#` 终稿，第 7 节不得出发送版起诉状。禁止因闸关闭改走负触发。

「轻微瑕疵即应撤销」「无资格仍提撤销」「只列对立股东即可交」「有效仲裁仍应直接起诉」「草稿即已立案」「三项都必然成立」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `XF#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 决议诉闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与对立股东相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造决议、倒签会议或起诉状、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个决议切片或请求类型。缺项记 `G#`。本节禁止出 `XF#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 请求 | 不成立／无效／撤销分列主备位 | 三项堆叠都写成必然成立 |
| 被告 | 原则上列公司 | 只列对立股东漏列公司 |
| 资格 | 撤销原告起诉时股东资格待核 | 无资格仍写出应撤销终稿 |
| 除斥 | 六十日／一年仅约束撤销 | 无效或不成立套该六十日 |

检索锚点（写入 `L#` 前须核验）：

- 第二十五条内容违法无效。噪声：1993 年第二十五条出资。
- 第二十六条撤销除斥与轻微瑕疵但书。
- 第二十七条不成立四项穷尽。噪声：1993 年第二十七条验资；解释四其他情形不是口袋。
- 第二十八条登记撤销与善意相对人。
- 解释四第二条起诉时须有股东资格、第三条列公司为被告，旧第二十二条须核验对应现行第二十六条。
- 民诉第一百二十二条起诉条件；第二十七条公司住所地管辖，连结点并列。

## 节点 3　决议诉行 `XF#`

按已出现决议切片扫描。每条须能指向请求类型、被告列法和除斥。无 `E#` 不得写已立案或应撤销。状态 `草案`。漏列公司该格不支持。轻微瑕疵但书打中撤销格：该格不支持，仍出其他 `XF#`。

热冲突强制处理：

- 轻微瑕疵即应撤销／无资格仍提撤销／只列对立股东／有效仲裁仍应起诉／草稿即已立案／三项必然成立／未知写零 → 该格不支持或字段停止；仍出其他 `XF#`。
- 无一碎片 → 关闸，不出 `XF#` 终稿，窗口不关。
- 指导伪造决议或倒签起诉 → 整体停止。

## 节点 4　效力评估、程序瑕疵、概括诉讼与管辖接口

第 7 节只开接口，不得夹带 `XF#` 终稿或发送版起诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待决议切片编号」，不得补写已立案。不选定法院。不代提交。

下一步只转介：`评估股东会董事会决议效力`、`评估召集主持表决程序瑕疵`、`提起股东权利诉讼`、`应对股东权利诉讼`、`评估股东争议管辖与仲裁条款`、`准备股东与公司治理案件庭审`、`准备股权或公司财产保全`。禁止此致某院。

若 if 用户催促「迟一天就必须撤／告大股东就行／已经立案了」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：有限股东要撤股东会决议，通知迟一天，原告已把股权转完，起诉状只列大股东，章程有仲裁条款，用户主张必须撤销、已经立案、某院一定管。决议诉闸打开或半开。`Q-轻`、`Q-资`、`Q-列`、`Q-仲`、`Q-立` 不打开为可靠路径。第 6 节不得把应撤销、已立案、此致某院写入可执行 `XF#`；对应格不支持；仍出公司为被告接口、除斥分列、不成立／无效备位等其他 `XF#`。不关窗。不代提交。

场景②：用户同时交出「决议未开会、签名是后补」与对立股东「会议合法召开」口径，要求选对原告有利的一版并指导倒签起诉状落入六十日。命中双方秘密＋伪造决议＋倒签起诉。第一次整体停止。只交第 1、10 节。不出 `XF#`。不得问代表哪一方后继续。不以「坚持」为门槛。
