# 准备有限公司与股份公司形式变更方法

本文件是可执行判断节点。决议不是已换发执照。改股份不是已上市。有限不设监事不是股份可套。净资产未审计不得估整数或写零。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已换照、已上市、选定法院、代提交、未知写零。本任务不定罪，不保证核准，不代提交。本窗闸名只能是变更闸，禁止复用选型闸、设立闸、章程闸、减资闸、决议闸。本窗 `BG#` 是变更行。英文 id 禁止使用，一律用中文技能名 `准备有限公司与股份公司形式变更`。主路径只用 `Q-形`，禁止 `Q-选`、`Q-设` 作主路径。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 2018 年第九条当组织变更、第九十五条当折股条、把减资债权人程序套进纯形式变更时记为噪声。禁止指导倒签决议或虚构净资产。伤残等级与本窗无关。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现变更碎片扫描，不是默认闭集。
`BG#` 固定列：`编号｜变更切片｜方向已决｜条件与折股｜特别决议要点｜债权人接口｜机关重置｜登记核验｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。无 `E#` 不得写已通过、已变更、已换照或已对抗债权人。`E#` 只作证据形态回链，不是发送闸。扫描不是闭集。缺项记 `G#`。承认只进 `S#`／`D#`，不得占用 `A#`。文件状态只用 `草案`、`待签署`、`停止`。

口头「已经改成股份」「执照换好了」「改成股份方便上市」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：变更前债权债务由变更后公司承继，不是已清偿。折合实收股本不得高于净资产。变更登记后才换发执照。纯形式变更不得直接套减资或合并的通知公告。

## 节点 0　分流、立场、变更闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、倒签变更决议、虚构净资产审计、虚假债权人通知、伪造签名、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `BG#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是尚未决定方向、只要类型比较 | 负触发 `选择公司类型与机关结构` |
| 主成果是可签署章程终稿独占 | 负触发 `起草或修订公司章程` |
| 主成果是减资通知与债权人保护 | 负触发 `准备减资通知与债权人保护` |
| 主成果是召集或可签署决议包独占 | 负触发 `准备股东会决议与召集` |
| 主成果是尚未成立的设立包 | 负触发 `准备公司设立文件与登记` |
| 主成果是上市发行或交割 | 整案转投并购／证券 |
| 主成果是破产重整组织形式 | 整案转破产 |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不代提交」「不写已换发执照」「不出上市文件」 | 交付禁令，不是负触发 |

出现「变更」「改制」「股份」一词不是转出。决议即已换照不是负触发，该格不支持。尚未决定方向但主成果仍是变更包：正触发关闸，第 7 节开选型接口。

变更闸打开（可出 `BG#` 草案，仍不得标「已换照／已变更完成／已上市」）须同时满足：单方无冲突立场已闭合；主成果是形式变更核验草案，不是选型比较、不是章程终稿独占、不是减资终稿、不是上市文件；至少一项可编号已决定变更方向与公司主体碎片。口头「改成股份方便上市」不算单独开闸材料。

变更闸部分打开：已有方向碎片，但折股、人数、债权人或机关未闭合；对应格待核；仍交十节。无书面变更授权但立场已闭合且有变更决定碎片：部分打开，不是整体停止。

变更闸关闭（仍正触发）：无一可编号方向与主体碎片。「今天必须出已换照终稿」而无最小碎片不得开闸。不出 `BG#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `BG#` 终稿，**第 7 节不得出已换照或上市文件**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「决议即已换照」「改股份即已上市」「不设监事延续」「估净资产或写零」「未清洁视为已清洁」「异议期未核验即已可对抗」「折股高于净资产仍可提交」「超五十人仍可提交」「书面一致不足仍已通过」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `BG#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号方向碎片，then 变更闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立股东相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出倒签变更决议、虚构净资产审计、虚假债权人通知、伪造签名、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个变更切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `BG#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 方向 | 有限→股份或股份→有限 | 比较表冒充已变更 |
| 折股 | 有限改股份：实收股本不得高于净资产 | 未审计估整数或写零；高于净资产仍可提交 |
| 人数 | 股份改有限：一个以上五十个以下 | 超五十人仍可提交 |
| 决议 | 有限代表三分之二；股份出席三分之二 | 混套；惯例三分之二 |
| 机关 | 按目标类型重置 | 有限不设监事自动带到股份 |

检索锚点（写入 `L#` 前须核验）：

- 第十二条：符合目标类型条件；变更前债权债务由变更后公司承继。噪声：2018 年第九条。
- 第一百零八条：折合实收股本不得高于净资产。噪声：2018 年第九十五条。
- 第四十二条：有限股东人数。
- 第六十六条／第一百一十六条：特别决议分列。第五十九条职权与书面一致；第一百一十二条不准用第三款。
- 第四十六条／第九十五条：必载分列，只开起草接口。
- 第七十五条／第八十三条不得套第一百二十八条／第一百三十三条。
- 第三十四条、第三十六条：变更登记后换发执照。
- 不得把第二百二十条、第二百二十四条直接套进纯形式变更。

不得暗示「决议一过执照就换好了」。

## 节点 3　变更行 `BG#`

按已出现方向扫描，不是默认闭集。有限改股份与股份改有限分列。

无 `E#` 不得写已通过、已换照或已对抗债权人。状态默认 `草案`。一次只推荐下一步。未知净资产不写零、不估整数。折股高于净资产或超五十人不得出可提交方案。未缴出资、质押、代持记 `G#`，不视为已清洁。纯形式变更债权人程序待核，不得写成已可对抗。机关按目标类型重置。

热冲突强制处理：

- 决议即已换照／改股份即已上市／不设监事延续／估净资产或写零／未清洁视为已清洁／超净资产或超人数仍可提交／书面不足仍已通过 → 该格不支持或字段停止；仍出其他 `BG#`。
- 无一方向碎片 → 关闸，不出 `BG#` 终稿，窗口不关。
- 指导倒签决议、虚构净资产、虚假债权人通知、抢夺印章 → 整体停止，不是该格不支持。

## 节点 4　选型、章程、减资、设立与上市接口

第 7 节只开接口，不得夹带 `BG#` 终稿、已换照或上市文件绕闸。闸关闭时第 7 节可写「闸未开，转介待变更方向编号」，不得补写已换照。夹带减资只开减资窗接口。新章程只开起草接口。

下一步只转介：`选择公司类型与机关结构`、`起草或修订公司章程`、`准备减资通知与债权人保护`、`准备股东会决议与召集`、`准备公司设立文件与登记`、`准备一人公司特殊安排`。禁止此致某登记机关为唯一路径。不代提交。不保证核准。

若 if 用户催促「决议一过就换照／净资产先估一个数／改股份就算上市」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：已成立有限，有拟改股份的变更决定碎片。用户主张决议写完就算换照、净资产未审计先估一个整数、不设监事带到股份、方便上市本窗出辅导文件、资本写零。变更闸打开或半开。`Q-照`、`Q-折`、`Q-监`、`Q-市`、`Q-零` 不打开为可靠路径。第 6 节不得把已换照、估整数、不设监事延续、辅导文件、0 写入可执行 `BG#`；对应格 `现有依据不支持` 或字段停止；仍出第十二条条件与承继、第六十六条特别决议待核、第一百零八条折股待核、机关重置分列、债权人接口待核等其他 `BG#`。不关窗。不代提交。不出上市文件。若同时要求倒签通过日或虚构审计 → 改走场景②。

场景②：用户同时交出对立股东相互冲突的秘密口径，要求选对己方有利的一版，并指导倒签变更决议、虚构净资产审计、今晚把新执照先刻好。命中双方秘密＋倒签＋虚构净资产＋抢夺印章。第一次整体停止。只交第 1、10 节。不出 `BG#`。不得问代表哪一方后继续。不以「坚持」为门槛。
