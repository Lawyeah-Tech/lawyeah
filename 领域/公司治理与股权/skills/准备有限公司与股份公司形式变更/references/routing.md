# 边界与路由

## 正触发

已决定有限改股份或股份改有限，需要变更条件、特别决议要点、债权人接口、机关重置和登记核验，而非发行上市交割。从零、碎片、折股未核验、无书面变更授权仍正触发：有变更决定碎片则闸开或半开，出 `BG#` 草案，保持草案。本次不代提交、不写已换发执照、不出上市文件是交付禁令，不是开窗条件。决议即已换照、改股份即已上市，仍正触发。

双方秘密、倒签变更决议、虚构净资产审计、虚假债权人通知、伪造签名、抢夺印章证照、违法取证的停止，优先于负触发。上述信号不在下表。「决议即已换照」「改股份即已上市」「不设监事延续」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 尚未决定方向、只要类型比较 | `选择公司类型与机关结构` |
| 可签署章程终稿独占 | `起草或修订公司章程` |
| 减资通知与债权人保护 | `准备减资通知与债权人保护` |
| 召集或可签署决议包独占 | `准备股东会决议与召集` |
| 尚未成立的设立登记包 | `准备公司设立文件与登记` |
| 上市发行、辅导或交割 | 投资并购／证券监管 |
| 破产重整组织形式 | 破产领域 |
| 合伙或个人独资 | 非公司主体 |

不得因「不代提交」或「不写已换发执照」关窗。拟变更核验仍正触发，不得写成已换照或已上市。尚未决定方向但主成果仍是变更包：正触发关闸，第 7 节开选型接口。

## 易混

本窗闸名只能是变更闸，禁止复用选型闸、设立闸、章程闸、减资闸。决议不是已换发执照。草稿不是已变更完成。改股份不是已上市。有限不设监事不是股份可套。有限五年认缴不是发起人折股实缴。净资产未审计不是可估整数。折股本高于净资产不是可提交方案。股份改有限超五十人不是可提交方案。纯形式变更不是减资或合并的债权人程序。现行第十二条是组织变更，第九条是经营范围。2018 年第九十五条不是现行折股条。本窗 `BG#` 不是选型窗 `XX#`，不是设立窗 `XS#`，不是章程窗 `CZ#`。「通过日先倒签」「净资产报告先做假」「今晚把新执照先刻好」整体停止。本窗不执行发送，不代提交。不保证核准。不出上市文件。伤残等级与本窗无关。
