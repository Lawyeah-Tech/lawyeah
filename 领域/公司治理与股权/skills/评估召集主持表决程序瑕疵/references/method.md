# 评估召集主持表决程序瑕疵方法

本文件是可执行判断节点。通知迟一天不是当然可撤销。无权召集不是本窗不成立终局。视频或电子通信开会不是未召开。已读不是已送达。轻微瑕疵不是当然撤销。评估不是起诉状。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、应撤销终局、不成立终局、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不写诉状或新决议。本窗闸名只能是程序闸，禁止复用召集闸、决议闸、决议诉闸、起诉闸、瑕疵闸。预留不得占用：僵局闸、谈判闸、和解闸、立案闸。本窗 `CX#` 是程序行。英文 id 禁止使用，一律用中文技能名 `评估召集主持表决程序瑕疵`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年第六十三条董事赔偿责任当现行有限召集顺序、把第六十六条表决当召集、把股份第一百一十四条连续九十日持股套有限、把 2018 条号未核验当现行、把迟一天写成当然可撤销、把无权召集写成不成立终局、把视频开会写成未召开时记为噪声。禁止指导伪造通知或倒签签到。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现会议切片或通知碎片扫描，不是默认闭集。
`CX#` 固定列：`编号｜会议切片｜召集权｜通知期与议题｜主持｜表决计算｜轻微与实质影响接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「应撤销」或「不成立终局」。无 `E#` 不得写已送达、已召开或已表决。`E#` 只作证据形态回链，不是发送闸，不是已送达证明。扫描不是闭集。缺项记 `G#`。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-程`。禁止 `ZJ#`、`XL#`、`XF#`、`XC#`、`A#`、`N#`。

口头「迟一天就必须撤」「微信已读就算送到了」「视频开过会等于没开会」「无权召集当然不成立」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：仅有轻微程序瑕疵且对决议未产生实质影响的，是否撤销由效力窗终局，本窗只开接口，不得写成当然撤销，也不得写成当然维持；依据不足则字段停止。该但书只覆盖召集程序或表决方式。无权召集、未实际表决、出席未达门槛只开不成立接口，本窗不写不成立终局。章程未禁止时，电子通信开会不是未召开。有限通知期章程另有规定或全体股东另有约定除外，不得把迟一天一律写成可撤销。已读、微信回执不是法定送达。董事会通知期与关联回避只开接口，不得编造一律三日或十日，不得把股份十日通知套有限。

「迟一天即应撤销」「无权召集即不成立终局」「视频或电子通信开会即未召开」「已读即已送达」「轻微即当然撤销」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `CX#` 草案。

## 节点 1　主体与强制接口

一行一个会议切片或通知版本。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `CX#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 会议种类 | 股东会／董事会／一名董事分列 | 股东会与董事会混成同一切片 |
| 公司类型 | 有限／股份分列 | 把股份通知期或九十日持股套有限 |
| 通知期 | 有限十五日（章程或全体另有除外）／股份二十日或临时十五日分列 | 迟一天一律应撤销；编造董事会一律三日或十日 |
| 召集权 | 顺序、首次会、持股比例待核 | 无权召集即本窗不成立终局 |
| 回避 | 关联董事回避只开接口 | 本窗写成应撤销或无效终局 |

检索锚点（写入 `L#` 前须核验）：

- 公司法第六十四条：有限召开股东会应当于会议召开十五日前通知全体股东；章程另有规定或者全体股东另有约定的除外。不得把迟一天一律写成可撤销。
- 有限股东会召集顺序常见检索第六十三条须运行时核验。噪声：1993 年第六十三条董事赔偿责任；不得把第六十六条表决当召集；不得把股份第一百一十四条连续九十日持股百分之十套有限。
- 第六十一条：首次股东会由出资最多的股东召集和主持。
- 股份第一百一十四条：召集主持顺序；连续九十日以上单独或合计持有公司百分之十以上股份的股东可自行召集，不得套有限。
- 第一百一十五条：股份股东会二十日前通知；临时股东会十五日前；不得对通知中未列明的事项作出决议。不得套有限第十五条。
- 第二十四条：电子通信方式开会、表决，章程另有规定除外；视频开会不是未召开。
- 第二十六条：轻微瑕疵但书只开接口，本窗不写应撤销终局。该但书只覆盖召集程序或表决方式。
- 第二十七条：不成立四项不在本窗写成终局。无权召集、未召开、未表决只开接口。
- 有限表决常见检索第六十五条、第六十六条须核验全文；不得把第一百一十六条出席表决权套有限。
- 有限董事会会议常见检索第七十二条召集主持、第七十三条过半数出席、全体董事过半数通过、一人一票。噪声：1993 年第七十三条股份设立条件。
- 股份董事会通知常见检索第一百二十三条须核验：每年度至少两次、十日以前通知；临时会议可以另定。不得把十日套有限董事会。
- 第一百八十五条：对第一百八十二条至第一百八十四条事项关联董事不得表决，不足三人提交股东会；只开接口。噪声：1993 年第一百八十五条分立、2018 年第一百二十四条当现行。
- 书面一致同意核验第五十九条第三款，本窗不写成已开会。

董事会通知期与关联回避只开接口。章程未定不得编造一律三日或十日。

## 节点 3　程序行 `CX#`

按已出现会议切片或通知碎片扫描，不是默认闭集。每条须能指向会议种类、召集权、通知期或表决计算。轻微与实质影响只开接口。

无 `E#` 不得写已送达、已召开或已表决。状态默认 `草案`。一次只推荐下一步。未知期间不写零，不输出唯一截止日或唯一必得总额。已读、微信回执不得升格法定送达。

热冲突强制处理：

- 迟一天即应撤销／无权召集即不成立终局／视频开会即未召开／已读即已送达／轻微即当然撤销／未知写零 → 该格不支持或字段停止；仍出其他 `CX#`。
- 无一碎片 → 关闸，不出 `CX#` 终稿，窗口不关。
- 指导伪造通知、倒签签到、抢夺印章 → 整体停止，不是该格不支持。

有限与股份通知期、召集顺序、表决权计算分列，不得混套。董事会通知期、关联回避不足三人只开接口，本窗不写效力终局。
