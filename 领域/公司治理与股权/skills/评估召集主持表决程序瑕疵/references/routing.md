# 边界与路由

## 正触发

单独委托核验股东会或董事会召集、主持、表决程序，而不要求效力三项终局。从零、碎片、通知期未核验、无书面评估授权仍正触发：有可编号会议切片或通知碎片则闸开或半开，出 `CX#` 草案，保持草案。本次不写应撤销、不写诉状是交付禁令，不是开窗条件。迟一天即应撤销、无权召集即不成立终局、视频开会即未召开、已读即已送达、轻微即当然撤销，仍正触发。拟召开会议的程序表仍正触发；未实际开会不是一律负触发。

双方秘密、伪造通知或签到、倒签会议、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「迟一天即应撤销」「无权召集即不成立终局」「视频开会即未召开」「已读即已送达」「轻微即当然撤销」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 效力三项终局 | `评估股东会董事会决议效力` |
| 发送前召集通知 | `准备股东会决议与召集` |
| 书面一致同意决定 | `准备书面一致同意决定` |
| 可提交决议之诉诉状 | `提起决议不成立无效或撤销之诉` |
| 董事会或执行董事决定草稿 | `准备董事会或执行董事决定` |
| 合伙或个人独资 | 非公司主体 |

不得因「不写应撤销」或「不写诉状」关窗。拟程序表仍正触发，不得写成应撤销或不成立终局。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |
| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「通知」「召集」「表决」「程序」一词不是转出。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 只要效力三项终局 | `评估股东会董事会决议效力` |
| 只要发送前召集通知 | `准备股东会决议与召集` |
| 只要书面一致同意 | `准备书面一致同意决定` |
| 只要可提交决议之诉 | `提起决议不成立无效或撤销之诉` |
| 只要董事会决定草稿 | `准备董事会或执行董事决定` |
| 只要关联回避是否影响效力 | `评估关联交易与回避表决` |

## 易混

本窗闸名只能是程序闸。`CX#` 不是召集窗 `ZJ#`，不是效力窗 `XL#`，不是决议诉窗 `XF#`，不是瑕疵窗 `XC#`。通知迟一天不是当然可撤销。无权召集不是本窗不成立终局。视频或电子通信开会不是未召开。已读不是已送达。轻微瑕疵不是当然撤销。有限第十五条通知期不是股份第二十日。第六十六条是表决不是召集。1993 年第六十三条不是现行召集顺序。股份第一百一十四条九十日持股不得套有限。董事会通知期不得编造一律三日或十日。评估不是起诉状。「通知日期改到十五日前」「未到场的人补签到」整体停止。本窗不执行发送，不代提交。不选定法院。
