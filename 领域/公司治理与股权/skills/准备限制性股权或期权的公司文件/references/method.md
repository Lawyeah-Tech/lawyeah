# 准备限制性股权或期权的公司文件方法

本文件是可执行判断节点。决议草稿不是已通过。未通过决议不是已经授予。授予草稿不是已行权。期权台账不是股东名册。口头承诺不是已授予。网交回执不是已核准。有限公司不得机械套用第 162 条库存股。股权激励不是当然第 163 条资助例外。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。文件状态只用 `草案`、`待签署`、`停止`。禁止胜诉率、已通过、已经授予、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不写劳动方案，不写个税方案，不重判评估窗工具比较。本窗闸名只能是授予闸，禁止复用股权激励闸、激励闸、代持闸、名册闸、转让闸、决议闸、章程闸、一人闸。预留不得占用：僵局闸、谈判闸、和解闸、立案闸、控制闸、登记闸、显名闸。本窗 `SY#` 是授予行。主路径只用 `Q-授`，禁止用 `Q-激` 或 `Q-代` 作主路径。禁止占用评估窗 `JL#`、合规窗 `RP#`、代持窗 `DT#`、名册窗 `MC#`、转让窗 `ZR#`。英文 id 禁止使用，一律用中文技能名 `准备限制性股权或期权的公司文件`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年第五十六条工会、2018 年第一百四十二条回购、2018 年第五十七条一人专节、把上市公司股权激励管理办法整部套有限、把第 162 条出席写成第 163 条全体通过、把股权激励写入第 163 条第一款当然例外时记为噪声，不得写入 `L#`。禁止指导伪造决议或倒签授予日。范本签字栏、落款日、通过结论不得升格已通过或已经授予。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现决议或授予碎片扫描，不是默认闭集。
`SY#` 固定列：`编号｜工具类型｜决议闭合｜授予文件要点｜限制回购公司接口｜名册或台账接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已通过」或「已经授予」。无 `E#` 不得写已通过或已记载名册。决议未闭合不得标 `待签署`。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-授`。禁止 `JL#`、`RP#`、`DT#`、`MC#`、`ZR#`、`A#`、`N#`。强制分列：有限／股份 × 实股／期权／限制性股权／平台份额。一行一个工具切片。价格未知记 `G#`，禁止写零。

口头「已经答应给你股份」「文件印出来就算授予了」只进 `S#`／`V#`，**不得单独算作开闸材料**。评估窗 `JL#` 不得单独开闸。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：股东会或董事会决议草稿在未依法作出前不是公司意思。未通过决议不能把授予协议升格已经授予。期权、限制性股权在行权或解除限制前通常进激励台账，不是股东名册。持股平台名册不等于目标公司名册。增资路径须闭合优先认缴或全体另定，未闭合不得标待签署。不得用公司文件剥夺法定劳动权利。用户要求在授予文件里写解除劳动合同无补偿：劳动条款删除并转劳动。

## 节点 0　分流、立场、授予闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造决议或授予协议、倒签会议或授予日、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `SY#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 以股权或资产收购、投资交割、尽调闭环为主要目标 | 整案转投资并购 |
| 婚姻、离婚、继承中的股权归属与分割 | 整案转婚家 |
| 高管劳动合同、解除、竞业劳动后果、员工激励的劳动身份（主轴） | 整案转劳动 |
| 企业级舞弊调查、反商业贿赂、综合合规体系 | 整案转企业合规；禁止复用激励闸与 `RP#` |
| 破产申请、重整计划、破产债权申报与分配 | 整案转破产 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 合伙企业、个人独资的入伙退伙（无公司侧授予） | 整案转出，非公司主体 |
| 上市公司发行、持续信息披露或证券监管主轴 | 整案转证券监管／投资并购，本领域只保留公司机关接口 |
| 主成果是尚未选定工具 | 负触发 `评估员工股权激励的公司安排` |
| 「不写劳动合同或个税方案」「不把决议草稿写成已通过」 | 交付禁令，不是负触发 |

出现「期权」「授予」「决议」一词不是转出。劳动、税务、上市作为背景且主轴仍是公司文件草稿时留本任务，第 7 节只开接口。

授予闸打开（可出 `SY#` 草案，仍不得标「已通过／已经授予／待提交终稿」）须同时满足：单方无冲突立场已闭合；主成果是决议或授予文件草稿，不是劳动方案、不是个税、不是评估窗工具比较；工具已选定；至少一项可编号决议或授予文件碎片（计划草案、额度、授权草稿、授予协议草稿、期权台账、拟增资／转让／回购／平台入伙议题）。口头「已经答应给你股份」不算单独开闸材料。评估窗 `JL#` 不算单独开闸材料。

授予闸部分打开：已有碎片，但权源、决议门槛或协议未闭合；对应格待核；仍交十节。

授予闸关闭（仍正触发）：无一可编号碎片。「今天必须出已通过／已授予终稿」而无最小碎片不得开闸。不出 `SY#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `SY#` 终稿，**第 7 节不得出已授予或劳动方案**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「决议草稿即已通过」「未通过决议即已经授予」「授予草稿即已行权」「期权台账即股东名册」「口头即已授予」「回执即已核准」「有限套第 162 条当然合法」「股权激励当然套第 163 条资助例外」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `SY#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 授予闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造决议或授予协议、倒签会议或授予日、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个工具切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `SY#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 主体 | 公司／拟激励对象／老股东分列 | 把员工写成已经是名册股东 |
| 公司类型 | 有限／股份／一人分列 | 有限套第 162 条库存股 |
| 工具 | 实股／期权／限制性股权／平台份额分列 | 期权台账写成股东名册 |
| 权源 | 增资／老股转让／股份回购／平台入伙分列 | 路径未定写成已经授予 |

检索锚点（写入 `L#` 前须核验）：

- 第五十六条：有限公司应当置备股东名册；记载于股东名册的股东可以依名册主张行使股东权利。噪声：1993 年第五十六条工会。
- 第五十五条：出资证明书。
- 第三十四条：未经登记或未经变更登记不得对抗善意相对人。
- 第四十二条：有限由一个以上五十个以下股东出资设立。
- 第五十九条：股东会职权。增资减资等特别决议门槛须核验第六十六条，不得把股份出席表决权套有限。
- 第六十条：只有一个股东的有限公司不设股东会。一人因激励变成多人：该条关闭，须开股东会。
- 授权董事会办理授予须范围闭合；超越授权标缺口。
- 第一百八十五条：关联董事回避。不得把上市公司激励办法回避规则整部套有限。
- 第二百二十七条：有限增资时股东在同等条件下有权按实缴比例优先认缴，全体股东约定除外。
- 第八十四条：有限对外转让书面通知与三十日。
- 第一百六十二条：股份公司收购本公司股份用于员工持股计划或股权激励。有限不得机械套用。噪声：2018 年第一百四十二条。第 162 条是三分之二以上董事**出席**开会。
- 第一百六十三条：禁止财务资助，员工持股计划除外。第 163 条是**全体董事**三分之二以上通过。不得把股权激励写入第一款当然例外。
- 上市公司股权激励管理办法不得整部套有限。

决议草稿而无作出记录：依据不足，不得写成已通过。期权台账不是股东名册。

## 节点 3　授予行 `SY#`

按已出现决议或授予碎片扫描，不是默认闭集。每条须能指向工具、决议闭合或授予文件要点。

无 `E#` 不得写已通过或已记载名册。状态默认 `草案`。一次只推荐下一步。额度或价格不足：对应格依据不足，窗口不关。为规避外资准入、国资程序或上市禁令：监管红旗字段待核，不得写成当然可提交。

热冲突强制处理：

- 决议草稿即已通过／未通过决议即已经授予／授予草稿即已行权／期权台账即股东名册／口头即已授予／回执即已核准／有限套第 162 条当然合法／股权激励当然套第 163 条资助例外／未知写零 → 该格不支持或字段停止；仍出其他 `SY#`。
- 无一碎片 → 关闸，不出 `SY#` 终稿，窗口不关。
- 指导伪造决议、倒签授予日 → 整体停止，不是该格不支持。
- 用户要求在授予文件里写解除劳动合同无补偿 → 劳动条款删除并转劳动，不在本任务设计违法劳动安排。

## 本任务回链纪律

本任务成果是「授予闸与授予行草案」。本窗不执行发送。不包含：已通过、已经授予终稿、劳动方案、个税方案、评估窗 `JL#`。禁止选边治愈。禁止决议草稿即已通过。禁止未通过决议即已经授予。禁止期权台账即股东名册。禁止指导伪造决议。授予闸打开 ≠ 已通过 ≠ 已经授予 ≠ 已行权 ≠ 已是名册股东。
