# 边界与路由

## 正触发

已选定公司侧激励工具，需要决议、授予和名册或台账安排。从零、碎片、决议未核验、无书面评估授权仍正触发：有可编号决议或授予文件碎片则闸开或半开，出 `SY#` 草案，保持草案。本次不把决议草稿写成已通过、不写劳动合同或个税方案是交付禁令，不是开窗条件。决议草稿即已通过、未通过决议即已经授予、期权台账即股东名册、口头即已授予，仍正触发。

双方秘密、伪造决议或授予协议、倒签会议或授予日、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「决议草稿即已通过」「未通过决议即已经授予」「授予草稿即已行权」「期权台账即股东名册」「口头即已授予」「回执即已核准」不在下表。

不得因「不把决议草稿写成已通过」或「不写劳动合同」关窗。已选定工具、要公司文件仍正触发，不得写成已通过或已经授予。

## 易混

本窗闸名只能是授予闸，不是评估窗股权激励闸，不是合规「激励闸」。`SY#` 不是评估窗 `JL#`，不是合规 `RP#`，不是代持窗 `DT#`，不是名册窗 `MC#`，不是转让窗 `ZR#`。主路径是 `Q-授`，不是评估窗 `Q-激`，不是代表诉讼常用的 `Q-代`。决议草稿不是已通过。未通过决议不是已经授予。期权台账不是股东名册。口头承诺不是已授予。有限公司不得机械套用第 162 条。第 162 条是三分之二以上董事出席开会，第 163 条是全体董事三分之二以上通过，禁止混写。第 163 条第一款例外是员工持股计划。1993 年第五十六条不是现行名册条。2018 年第一百四十二条不是现行回购条。上市公司股权激励管理办法不得整部套有限。「授予日改到入职前」整体停止。本窗不执行发送，不代提交。不选定法院。
