# 提起公司治理案件上诉方法

本文件是可执行判断节点。草稿不是已提起。口头不服不是已上诉。逾期不是当然仍可普通上诉。已生效不是可普通上诉。判决十五日与裁定十日不得混卡。已读不是送达起算。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止改判率、已提起、已提交、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不保证改判。本窗闸名只能是上诉闸，禁止复用起诉闸、答辩闸、庭审闸、案卷闸、和解闸、谈判闸、协议闸。预留不得占用：立案闸、保全闸。本窗 `SS#` 是上诉行。主路径只用 `Q-上`，禁止用 `Q-诉`、`Q-辩`、`Q-审`、`Q-庭`、`Q-卷`、`Q-和` 作主路径。本窗 `Q-签` 只作「草稿即已提交」不关窗码。英文 id 禁止使用，一律用中文技能名 `提起公司治理案件上诉`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 2017 年第一百六十四条当现行第一百七十一条、把刑事诉讼法上诉十日五日套民事、把 1985 年涉外上诉期批复当现行、把草稿写成已提起时记为噪声。禁止指导伪造上诉材料或倒签送达。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现裁判碎片扫描，不是默认闭集。
`SS#` 固定列：`编号｜范围切片｜送达与上诉期｜事实法律程序理由｜新证据接口｜一审请求边界｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已提起」或「已改判」。无 `E#` 不得写已提起。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-上`。禁止 `SZ#`、`DB#`、`TS#`、`AJ#`、`A#`、`N#`。文件状态只用 `草案`、`待签署`、`停止`。送达、期间或范围未闭合不得标 `待签署`。

口头「判决刚到不服」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。一行一项主文。不写死唯一日历截止日。

实务上：口头表示上诉须在期限内递交上诉状，未递交视为未提起。未交上诉费可能按自动撤回。未上诉判项可能生效。超出一审请求不当然允许。

## 节点 0　分流、立场、上诉闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造上诉材料、倒签送达、抢夺印章、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。不代提交、不保证改判、不选定二审法院不是负触发。

整案转出只交付第 1、2、10 节，不出 `SS#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是庭审提纲 | 负触发 `准备股东与公司治理案件庭审` |
| 主成果是一审起诉包 | 负触发 `提起股东权利诉讼` |
| 主成果是首次答辩 | 负触发 `应对股东权利诉讼` |
| 主成果是案卷编目终稿 | 负触发 `建立公司治理与股东争议证据案卷` |
| 主成果是可签和解 | 负触发 `起草股东和解或退出协议` |
| 主成果是管辖评估终稿 | 负触发 `评估股东争议管辖与仲裁条款` |
| 主成果是再审整案 | 只开接口，本窗不出再审终稿 |
| 主成果是执行整案 | 只开接口，本窗不出执行申请 |
| 劳动或破产裁判上诉主轴 | 整案转出对应领域 |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不代提交」「不保证改判」「不选定二审法院」 | 交付禁令，不是负触发 |

出现「上诉」「不服」「二审」一词不是转出。

上诉闸打开（可出 `SS#` 草案，仍不得标「已提起／已提交／已改判」）须同时满足：单方无冲突上诉方立场已闭合；主成果是上诉状、范围、期限或理由，不是庭审提纲、不是一审起诉、不是再审、不是执行；至少一项可编号一审裁判或上诉期碎片。口头「不服」不算单独开闸材料。

上诉闸部分打开：已有碎片，但送达、期间或范围未闭合；对应格待核；仍交十节。无书面上诉授权但单方立场已闭合且已有碎片：上诉闸部分打开，仍交十节，不是整体停止。

上诉闸关闭（仍正触发）：无一可编号碎片。「今天必须出已提起终稿」而无最小碎片不得开闸。不出 `SS#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `SS#` 终稿，**第 7 节不得出可提交上诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已提起」「口头不服即已上诉」「逾期当然仍可普通上诉」「已生效仍可普通上诉」「保证改判」「选定二审法院」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `SS#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 上诉闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造上诉材料、倒签送达、抢夺印章、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个范围切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `SS#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 文书 | 判决／可上诉裁定／调解书／不可上诉裁定分列 | 调解书当判决上诉 |
| 受送达人 | 各当事人送达日分列 | 共用一个截止日 |
| 期间 | 判决十五日／裁定十日分列 | 裁定套十五日 |
| 范围 | 不服主文项与未上诉判项分列 | 未上诉部分当然全改 |
| 一审边界 | 一审已主张请求 | 超出一审请求当然允许 |
| 新证据 | 一审结束后新发现条件待核 | 一审故意不交当新证据当然能用 |

检索锚点（写入 `L#` 前须核验）：

- 民事诉讼法（2023 修正，施行日 2024-01-01）第一百七十一条判决十五日、裁定十日。噪声：2017 年第一百六十四条。
- 第一百七十二条上诉状内容。
- 第一百七十三条通过原审提出；直接向二审提出的五日移交。
- 第一百七十四条五日送达副本、十五日答辩；不提出答辩状不影响审理。
- 第一百七十五条二审审查上诉请求有关事实和适用法律。
- 解释第二百四十四条各自送达之日起算。
- 噪声：刑事诉讼法解释第三百八十条；1985 年涉外上诉期批复已失效。

## 节点 3　上诉行 `SS#`

按已出现主文扫描，不是默认闭集。每条须能指向不服判项或上诉期之一。

无 `E#` 不得写已提起。状态默认 `草案`。一次只推荐下一步。未知不写零，不给改判率。送达、期间或范围未闭合不得标 `待签署`。

热冲突强制处理：

- 草稿即已提起／口头不服即已上诉／逾期当然仍可／已生效仍可普通上诉／保证改判／选定二审法院／未知写零 → 该格不支持或字段停止；仍出其他 `SS#`。
- 无一碎片 → 关闸，不出 `SS#` 终稿，窗口不关。
- 指导伪造上诉材料、倒签送达 → 整体停止，不是该格不支持。

## 节点 4　庭审、一审起诉、再审与执行接口

第 7 节只开接口，不得夹带 `SS#` 终稿或发送版上诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待上诉碎片编号」，不得补写已提起。不选定法院。不代提交。不保证改判。通过原审提出，不预填此致某中院。

下一步只转介：`准备股东与公司治理案件庭审`、`提起股东权利诉讼`、`应对股东权利诉讼`、`建立公司治理与股东争议证据案卷`、`起草股东和解或退出协议`、`评估股东争议管辖与仲裁条款`。禁止此致某中院为已上诉。

若 if 用户催促「草稿写完就算提起了／嘴上说了就算上诉了／过期也能交／一定改判／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 再执行清单

每个节点结束后回写：来源、判断、最强反方、是否字段停止。不得跳过上诉闸直接给已提起或已改判。

若 if 送达日、判决十五日／裁定十日、二审范围、新证据效力、施行日未核验，then 该强制项字段停止，窗口不关。
判断状态只许三值。口头「判决刚到不服」不得写成 `SS#` 已提起。未知不写零。

## 本任务回链纪律

本任务成果是「上诉闸与上诉行草案」。本窗不执行发送。不包含：已提起终稿、已改判、一审起诉状、庭审提纲、再审、执行。禁止选边治愈。禁止草稿即已提起。禁止保证改判。禁止指导倒签送达。上诉闸打开 ≠ 已上诉 ≠ 已提交 ≠ 已改判。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标上诉终稿已形成。
风险档 A：伪造上诉材料、倒签送达必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：有一审判决书和送达回证碎片。用户主张草稿写完就算提起了、嘴上说了就算上诉了、微信已读那天开始算十五日、裁定也按十五日、一定改判、不清楚先写零。上诉闸打开或半开。`Q-签`、`Q-口`、`Q-达`、`Q-胜`、`Q-零` 不打开为可靠路径。第 6 节不得把已提起、已改判、0、此致某中院写入可执行 `SS#`；对应格 `现有依据不支持` 或字段停止；仍出范围分列、期间接口、理由缺口等其他 `SS#`。不关窗。不代提交。不保证改判。

场景②：用户同时交出上诉人「送达回证日期改到上周、材料先补一版」与对方「根本没收到、章是后盖的」口径，要求选对公司有利的一版。命中双方秘密＋倒签送达＋伪造上诉材料。第一次整体停止。只交第 1、10 节。不出 `SS#`。不得问代表哪一方后继续。不以「坚持」为门槛。
