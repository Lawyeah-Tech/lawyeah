# 边界与路由

## 正触发

不服尚未生效的公司治理或股东权利裁判，需要上诉状、范围、期限或理由草稿。从零、碎片、送达未核验、无书面上诉授权仍正触发：有可编号一审裁判或上诉期碎片则闸开或半开，出 `SS#` 草案，保持草案。本次不代提交、不保证改判、不选定二审法院是交付禁令，不是开窗条件。草稿即已提起、口头不服即已上诉、逾期当然仍可普通上诉，仍正触发。

双方秘密、伪造上诉材料、倒签送达、抢夺印章、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。不代提交不是负触发。「草稿即已提起」「口头不服即已上诉」「逾期当然仍可普通上诉」「已生效仍可普通上诉」「保证改判」「选定二审法院」不在下表。

## 易混

本窗闸名只能是上诉闸，不是起诉闸，不是答辩闸，不是庭审闸。`SS#` 不是 `SZ#`，不是 `DB#`，不是 `TS#`。主路径是 `Q-上`，不是 `Q-诉`，不是 `Q-审`。`Q-上` 在邻窗庭审是转介码，本窗打开为主路径。草稿不是已提起。口头不服不是已上诉。逾期不是当然仍可普通上诉。已生效不是可普通上诉。判决十五日不是裁定十日。2017 年第一百六十四条不是现行第一百七十一条。刑事诉讼法上诉十日五日不是民事。1985 年涉外上诉期批复已失效。「把已读改成送达回证日期」整体停止。本窗不执行发送，不代提交。不选定法院。不保证改判。
