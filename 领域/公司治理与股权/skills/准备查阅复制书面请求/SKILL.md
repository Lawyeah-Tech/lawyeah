# 准备查阅复制书面请求

## 任务目标

在明确、无利益冲突的单方立场下（股东或其受托律师，互斥），形成发送前查阅书面请求草稿：书面请求闸、主体与强制接口、`Q#` 路径、`QH#` 请求函行（股东身份依据／材料范围／目的说明／中介与保密／送达接口／`E#` 回链）。本窗 `QH#` 是请求函行草案，不是已送达，不是已提出，不是已获准，不是查阅之诉起诉状，不是评估窗 `CK#`。本窗闸名只能是书面请求闸，禁止复用查阅闸、书面闸、起诉闸、名册闸。预留不得占用：僵局闸、谈判闸、和解闸、立案闸、控制闸、登记闸、显名闸。本窗主行只能是 `QH#`，禁止 `CK#`、`SM#`、`SZ#`、`MC#`、`A#`。主路径只用 `Q-请`，禁止用 `Q-阅`、`Q-书`、`Q-代` 作主路径。书面请求闸打开不等于已送达不等于已提出不等于已获准不等于待提交终稿。请求草稿不是已送达。微信已读不是已提出。未说明目的不是已提出账簿凭证查阅请求。十五日自书面提出起算，未满不是公司已违法拒绝。账簿凭证须书面说明目的，不得当然写成可复制。未知不写零。不代提交。不执行发送。不选定法院。不定罪。伤残等级与本窗无关，禁止折入。

`depends-on` 为空。主成果是范围或不正当目的评估转 `评估股东知情查阅权`。主成果是查阅之诉起诉状转 `提起查阅权诉讼`。主成果是名册记载请求独占转 `准备股东名册与工商变更衔接`。主成果是送达设计独占转 `设计催缴召集优先购买通知送达`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：已决定行使查阅，需要书面说明目的的请求书。「给我查账函」「把请求写出了」仍正触发。目的、范围、地址未核验仍正触发：有可编号股东身份或拟查材料碎片则书面请求闸打开或半开，第 6 节出 `QH#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出已送达／已获准终稿」才关闸，仍交十节，第 6 节不出 `QH#` 终稿，窗口不关。用户要把草稿写成已送达、把微信已读写成已提出、把未说明目的写成已提出账簿请求、把十五日未满写成违法拒绝、把账簿凭证写成当然可复制、把草稿写成已获准、把未知写成零，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `QH#` 草案。不得因「不代提交」「不写已获准」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是范围或不正当目的评估（转 `评估股东知情查阅权`）；
- 主成果是查阅之诉起诉状（转 `提起查阅权诉讼`）；
- 主成果是名册记载请求独占（转 `准备股东名册与工商变更衔接`）；
- 主成果是送达设计独占（转 `设计催缴召集优先购买通知送达`）；
- 合伙企业或个人独资。

双方秘密、伪造查阅请求、倒签送达、抢夺印章证照、隐匿账簿、违法取证**不在负触发表**，走整体停止。「草稿即已送达」「微信已读即已提出」「未说明目的即已提出账簿请求」「十五日未满即违法拒绝」「账簿凭证当然可复制」「草稿即已获准」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不代提交」「不写已获准」是交付禁令，不是负触发。主成果才转；出现「查阅」「请求」一词不是转出。尚未评估且只要定性才转评估窗；已决定查阅、目的未核验仍正触发。

## 建立工作坐标

确认：查阅决定；单方立场；公司类型；拟查材料；目的草稿；章程住所；法域。

口头「微信已读就算提出了」「稿子写好就算送到了」只登记 `S#`／`V#`。不得升格已提出或已送达，**不得单独算作开闸材料**。评估窗 `CK#` 不得单独开闸。可编号股东身份或拟查材料碎片可开闸。本窗不执行发送，不代提交，不伪造签字。

立场只许股东或其受托律师。同时掌握公司与股东相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：书面请求闸关闭，仍交十节，不是整体停止。提出伪造查阅请求、倒签送达、抢夺印章证照、隐匿账簿或违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 章程或股东协议；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`QH#` 请求函行；`V#` 版本；`E#` 证据形态回链（身份依据、拟查清单、目的草稿、章程住所，不是发送闸，不是已提出证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`CK#`、`SM#`、`SZ#`、`MC#`。技能正文中的条号是检索锚点，不是已核验 `L#`。文件状态只用 `草案`、`待发送`、`停止`。目的未闭合或账簿凭证未写目的不得标 `待发送`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。未知不写零。草稿 ≠ 已送达。微信已读 ≠ 已提出。未说明目的 ≠ 已提出账簿请求。十五日未满 ≠ 违法拒绝。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或文书范本检索。本窗是请求函草稿准备，范本只借查阅申请栏目，**不要**升格「已提出／已送达／已获准」。范本引用 2018 年第三十三条记为噪声。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现草稿即已送达、微信已读即已提出、未说明目的即已提出账簿请求的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把 1993 年第五十七条任职禁入当作现行查阅条。不得把 2018 年第三十三条当作现行书面请求条。解释四仍引旧第三十三条的，须核验对应现行第五十七条。MCP 效力字段与公布施行日冲突时，以施行日为准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的书面门槛、目的或施行日保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：公司法（2023 修订，施行日 2024-07-01）第五十七条第一款查阅并复制章程、名册、股东会记录、董事会监事会决议、财报。第二款查阅账簿、凭证须向公司提出书面请求并说明目的；十五日自书面请求之日起算。噪声：1993 年第五十七条任职禁入、2018 年第三十三条。目的不得空白或仅写「了解经营」即标已提出账簿请求。第一百一十条股份查账簿凭证另有连续一百八十日、单独或合计百分之三门槛，适用第五十七条第二、三、四款。数据电文是否构成向公司提出的书面请求须核验，微信已读不得写成已提出。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变书面门槛或目的要求的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补律师函只要表明查阅请求、范围及目的可视为书面请求、仅写了解经营可能不足、未书面不得起算十五日、草稿不等于已送达的实务反例。
- `search_template` 只借查阅申请书栏目。范本签字栏、落款日、已读回执、旧第三十三条不得升格已提出、已送达或已获准。禁止用范本生成已寄出请求或起诉状。

工具不可用时继续身份碎片和 `QH#` 编目；书面门槛、目的、施行日字段停止。不得拒跑，不得凭记忆写成已送达、已提出或已获准。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、书面请求闸与不关窗

主成果才整案转出。双方秘密、伪造请求第一次停。草稿即已送达不关窗。闸关仍交十节，第 6 节不出 `QH#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

股东／公司分列。有限／股份分列。第一款材料与账簿凭证分列。本节禁止出 `QH#` 终稿。

### 3. 书面请求闸与路径 `Q#`

本节禁止出 `QH#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-请`。

### 4. 请求函行 `QH#`

身份依据、材料范围、目的说明、中介与保密、送达接口。状态 `草案`。禁止升格已送达、已提出、已获准。无 `E#` 不得写已提出。目的未闭合不得标 `待发送`。

### 5. 查阅评估、查阅之诉与送达接口

范围评估转评估窗。起诉状转查阅之诉窗。第 7 节不得夹带 `QH#` 终稿或已送达结论绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造查阅请求、倒签送达、抢夺印章证照、隐匿账簿或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：书面请求闸关闭，仍交十节，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：目的、书面门槛、股份持股、施行日未核验。草稿即已送达、微信已读即已提出、未说明目的即已提出账簿请求、十五日未满即违法拒绝、账簿凭证当然可复制、草稿即已获准、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `QH#` 草案。
- `目标停止`：主目标变为评估窗终稿、查阅之诉起诉状、已送达终稿或已获准终稿。禁止把「已送达」「已获准」当作用户错误主张时的目标停止；那是不关窗。

禁止指导伪造查阅请求或倒签送达。不给胜诉率。不定罪。不选定法院。不代提交。未知不写零。不写已送达。伤残等级禁止折入。不得请求与股东权利无关的个人隐私材料或违法取得的材料。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。书面请求闸关闭仍交十节，第 6 节不出 `QH#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `QH#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。书面请求闸未打开时不得交付「已送达」或「已获准」。边界见 [路由](references/routing.md)。
