# 准备查阅复制书面请求方法

本文件是可执行判断节点。请求草稿不是已送达。微信已读不是已提出。未说明目的不是已提出账簿凭证查阅请求。十五日未满不是公司已违法拒绝。账簿凭证不是当然可复制。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。文件状态只用 `草案`、`待发送`、`停止`。禁止胜诉率、已送达、已获准、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不写起诉状，不重判评估窗范围终局。本窗闸名只能是书面请求闸，禁止复用查阅闸、书面闸、起诉闸、名册闸。预留不得占用：僵局闸、谈判闸、和解闸、立案闸、控制闸、登记闸、显名闸。本窗 `QH#` 是请求函行。主路径只用 `Q-请`，禁止用 `Q-阅`、`Q-书`、`Q-代` 作主路径。禁止占用评估窗 `CK#`、书面一致窗 `SM#`、起诉窗 `SZ#`、名册窗 `MC#`。英文 id 禁止使用，一律用中文技能名 `准备查阅复制书面请求`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年第五十七条任职禁入、2018 年第三十三条、解释四仍引旧第三十三条未核验对应、把微信已读写成已提出时记为噪声，不得写入 `L#`。禁止指导伪造查阅请求或倒签送达。范本签字栏、落款日、旧第三十三条不得升格已提出或已送达。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现身份或拟查材料碎片扫描，不是默认闭集。
`QH#` 固定列：`编号｜股东身份依据｜材料范围｜目的说明｜中介与保密｜送达接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已送达」或「已提出」。无 `E#` 不得写已提出。目的未闭合或账簿凭证未写目的不得标 `待发送`。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-请`。禁止 `CK#`、`SM#`、`SZ#`、`MC#`、`A#`、`N#`。有限／股份分列。第一款材料与账簿凭证分列。一行一个切片。

口头「微信已读就算提出了」「稿子写好就算送到了」只进 `S#`／`V#`，**不得单独算作开闸材料**。评估窗 `CK#` 不得单独开闸。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：账簿、凭证查阅须向公司提出书面请求并说明目的，目的不得空白或仅写「了解经营」即标已提出。律师函只要表明查阅请求、范围及目的，实务上常可视为书面请求，但仍须能指向公司、材料与目的，草稿本身不是已提出。十五日自书面提出之日起算，未提出不得起算，未满不得写已违法拒绝。微信已读不是已向公司提出书面请求。复制项与查阅账簿凭证必须分写。

## 节点 0　分流、立场、书面请求闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造查阅请求、倒签送达、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `QH#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 以股权或资产收购、投资交割、尽调闭环为主要目标 | 整案转投资并购 |
| 婚姻、离婚、继承中的股权归属与分割 | 整案转婚家 |
| 高管劳动合同、解除、竞业劳动后果 | 整案转劳动 |
| 企业级舞弊调查、反商业贿赂、综合合规体系 | 整案转企业合规 |
| 破产申请、重整计划、破产债权申报与分配 | 整案转破产 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 合伙企业、个人独资 | 整案转出，非公司主体 |
| 上市公司发行、持续信息披露或证券监管主轴 | 整案转证券监管／投资并购，本领域只保留公司机关接口 |
| 主成果是范围或不正当目的评估 | 负触发 `评估股东知情查阅权` |
| 「不代提交」「不写已获准」 | 交付禁令，不是负触发 |

出现「查阅」「请求」一词不是转出。

书面请求闸打开（可出 `QH#` 草案，仍不得标「已送达／已提出／已获准终稿」）须同时满足：单方无冲突股东立场已闭合；主成果是发送前书面请求草稿，不是评估终局、不是起诉状；至少一项可编号股东身份或拟查材料碎片。口头「微信已读就算提出了」不算单独开闸材料。

书面请求闸部分打开：已有碎片，但目的、范围或地址未闭合；对应格待核；仍交十节。

书面请求闸关闭（仍正触发）：无一可编号碎片。「今天必须出已送达／已获准终稿」而无最小碎片不得开闸。不出 `QH#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `QH#` 终稿，**第 7 节不得出已送达或起诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已送达」「微信已读即已提出」「未说明目的即已提出账簿请求」「十五日未满即违法拒绝」「账簿凭证当然可复制」「草稿即已获准」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `QH#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 书面请求闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造查阅请求、倒签送达、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个请求切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `QH#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 主体 | 股东／公司分列 | 把隐名直接写成已可向公司发已提出函 |
| 公司类型 | 有限／股份分列 | 股份跳过百分之三门槛直接写账簿请求为已闭合 |
| 材料 | 第一款复制项／账簿／凭证分列 | 账簿凭证写成当然可复制 |
| 目的 | 账簿凭证必须具体目的 | 「了解经营」升格已提出 |

检索锚点（写入 `L#` 前须核验）：

- 第五十七条第一款：查阅并复制章程、名册、股东会记录、董事会监事会决议、财报。
- 第二款：查阅账簿、凭证须书面请求并说明目的；十五日自书面请求之日起算。噪声：1993 年第五十七条任职禁入、2018 年第三十三条。
- 第三款：可委托中介。请求中预列中介在场，不得写成公司已同意。
- 第一百一十条：股份查账簿凭证的持股门槛。噪声：1993 年第一百一十条。
- 解释四第十条：诉讼获支持后中介辅助，本窗不得写成请求函已获准中介复制。

## 节点 3　请求函行 `QH#`

按已出现身份或拟查材料碎片扫描，不是默认闭集。每条须能指向身份、范围或目的。

无 `E#` 不得写已提出。状态默认 `草案`。一次只推荐下一步。账簿凭证目的空白：该格不支持已提出，窗口不关，不得标 `待发送`。

热冲突强制处理：

- 草稿即已送达／微信已读即已提出／未说明目的即已提出账簿请求／十五日未满即违法拒绝／账簿凭证当然可复制／草稿即已获准／未知写零 → 该格不支持或字段停止；仍出其他 `QH#`。
- 无一碎片 → 关闸，不出 `QH#` 终稿，窗口不关。
- 指导伪造查阅请求、倒签送达、抢账簿 → 整体停止，不是该格不支持。
- 用户要求把草稿标题写成「公司同意函」→ 该格不支持，不得改走目标停止吞不关窗；主成果变成要公司同意函终稿才目标停止。

## 节点 4　查阅评估、查阅之诉与送达接口

第 7 节只开接口，不得夹带 `QH#` 终稿、已送达结论或起诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待请求编号」，不得补写已送达。不选定法院。不代提交。不执行发送。

下一步只转介：`评估股东知情查阅权`、`提起查阅权诉讼`、`设计催缴召集优先购买通知送达`、`准备股东名册与工商变更衔接`。禁止此致某法院。

若 if 用户催促「微信已读就算提出了／稿子写好就算送到了／了解经营就够了」，then 该格 `现有依据不支持`，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「书面请求闸与请求函行草案」。本窗不执行发送。不包含：已送达、已提出、已获准、起诉状、评估窗 `CK#`。禁止选边治愈。禁止草稿即已送达。禁止微信已读即已提出。禁止指导伪造请求。书面请求闸打开 ≠ 已送达 ≠ 已提出 ≠ 已获准。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标请求终稿已形成。
风险档 A：伪造查阅请求、倒签送达必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：股东要查账簿凭证，草稿只写「了解经营」，微信给法定代表人发了截图对方已读。用户主张已读就是已提出、稿子写好就算送到、十五日没到也能告违法拒绝、账簿当然能复印、把标题改成公司同意函。书面请求闸打开或半开。`Q-口`、`Q-达`、`Q-目`、`Q-满`、`Q-复`、`Q-准` 不打开为可靠路径。第 6 节不得把已提出、已送达、已获准写入可执行 `QH#`；对应格 `现有依据不支持`；仍出身份、范围分列、目的缺口等其他 `QH#`。不关窗。不代提交。

场景②：用户同时交出「股东口径：还没寄」与「把请求函日期改到十五日前再打印已送达回证」，要求选对股东有利的一版。命中双方秘密＋倒签送达。第一次整体停止。只交第 1、10 节。不出 `QH#`。不得问代表哪一方后继续。不以「坚持」为门槛。
