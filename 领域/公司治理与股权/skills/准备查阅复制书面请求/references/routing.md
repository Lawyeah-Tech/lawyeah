# 边界与路由

## 正触发

已决定行使查阅，需要书面说明目的的请求书。从零、碎片、目的未核验、无书面评估授权仍正触发：有可编号股东身份或拟查材料碎片则闸开或半开，出 `QH#` 草案，保持草案。本次不代提交、不写已获准是交付禁令，不是开窗条件。草稿即已送达、微信已读即已提出、未说明目的即已提出账簿请求，仍正触发。

双方秘密、伪造查阅请求、倒签送达、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「草稿即已送达」「微信已读即已提出」「未说明目的即已提出账簿请求」「十五日未满即违法拒绝」「账簿凭证当然可复制」「草稿即已获准」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 范围或不正当目的评估 | `评估股东知情查阅权` |
| 查阅之诉起诉状 | `提起查阅权诉讼` |
| 名册记载请求独占 | `准备股东名册与工商变更衔接` |
| 送达设计独占 | `设计催缴召集优先购买通知送达` |
| 合伙或个人独资 | 非公司主体 |

不得因「不代提交」或「不写已获准」关窗。已决定查阅、要书面请求仍正触发，不得写成已送达或已提出。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露或证券监管主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「查阅」「请求」一词不是转出。

## 易混

本窗闸名只能是书面请求闸，不是评估窗查阅闸，不是书面一致同意的书面闸。`QH#` 不是评估窗 `CK#`，不是书面一致窗 `SM#`，不是起诉窗 `SZ#`。主路径是 `Q-请`，不是评估窗 `Q-阅`，不是书面一致 `Q-书`，不是代表诉讼 `Q-代`。请求草稿不是已送达。微信已读不是已提出。未说明目的不是已提出账簿凭证查阅请求。1993 年第五十七条不是现行查阅条。2018 年第三十三条不是现行书面请求条。范本旧第三十三条不得升格已提出。「请求函日期改到十五日前」整体停止。本窗不执行发送，不代提交。不选定法院。不写起诉状。
