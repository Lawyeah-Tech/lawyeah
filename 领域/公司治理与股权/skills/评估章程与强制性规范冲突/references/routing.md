# 边界与路由

## 正触发

章程中的表决、转让、任期、出资、查阅或机关条款被质疑违反强制性规范，需要对照而不立即改写。从零、碎片、版本未核验、无书面评估授权仍正触发：有可编号章程条款则闸开或半开，出 `TK#` 草案，保持草案。本次不改写新章程、不把冲突写成决议当然无效是交付禁令，不是开窗条件。冲突即决议当然无效、冲突即设立无效，仍正触发。

双方秘密、选边有利章程版本、伪造备案文本、倒签修正案、伪造签名、抢夺印章证照、违法取证的停止，优先于负触发。上述信号不在下表。「冲突即决议当然无效」「冲突即设立无效」「另有规定即取消底线」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 可签署章程或修正案草稿 | `起草或修订公司章程` |
| 决议不成立／无效／可撤销终局 | `评估股东会董事会决议效力` |
| 召集或通过修正案 | `准备股东会决议与召集` |
| 出资催缴或加速到期 | `评估出资瑕疵催缴与加速到期` |
| 股东协议或一致行动正文 | `起草股东协议与一致行动安排` |
| 设立文件与登记包 | `准备公司设立文件与登记` |
| 类型比较草案 | `选择公司类型与机关结构` |
| 存量认缴期限调整 | `准备认缴期限调整与实缴整改` |
| 一般交易合同 | 审查起草领域（本窗搁置） |
| 合伙或个人独资 | 非公司主体 |

不得因「不改写」或「不把冲突写成决议当然无效」关窗。拟对照仍正触发，不得写成当然无效或设立无效。无一章程文本：正触发关闸，不是负触发，也不是整体停止。

## 专项整案转出

| 主轴信号 | 路由 |

| 上市公司发行、持续信息披露主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「章程」「冲突」「无效」一词不是转出。
