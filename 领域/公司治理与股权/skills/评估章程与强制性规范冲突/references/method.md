# 评估章程与强制性规范冲突方法

本文件是可执行判断节点。冲突不是决议当然无效。冲突不是设立无效。章程另有规定不是可取消查阅或催缴失权。新设有限突破五年不是任意有效。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、当然无效、设立无效、选定法院、代提交、未知写零。本任务不定罪，不改写新章程，不写决议效力终稿。本窗闸名只能是条款闸，禁止复用章程闸、冲突闸、对照闸、决议闸、设立闸。本窗 `TK#` 是条款对照行。英文 id 禁止使用，一律用中文技能名 `评估章程与强制性规范冲突`。主路径只用 `Q-冲`，禁止 `Q-章` 作主路径。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 2018 年第二十二条、第二十五条、第三十三条、第七十一条、解释三第十七条当 2024 年后唯一除名路径时记为噪声。禁止指导选边有利版本或伪造备案。伤残等级与本窗无关。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现条款碎片扫描，不是默认闭集。
`TK#` 固定列：`编号｜条款切片｜文本层级｜强制或任意｜冲突后果｜决议接口｜修订接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。无 `E#` 不得写已适用、已无效、已备案或已改章。`E#` 只作证据形态回链，不是发送闸。扫描不是闭集。缺项记 `G#`。承认只进 `S#`／`D#`，不得占用 `A#`。文本层级必须并列登记章程、未备案修正案、视同改章程的决议、股东协议，不选有利一版。

口头「这条肯定违法」「冲突了决议就无效」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：内容违反法律、行政法规才走无效接口；内容违章或程序违章走可撤销接口。章程冲突判断的是该条款现有依据是否支持其适用，不是宣布设立无效，也不是决议当然无效。

## 节点 0　分流、立场、条款闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、选边有利章程版本、伪造备案文本、倒签修正案、伪造签名、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。无一章程文本不进整体停止。

整案转出只交付第 1、2、10 节，不出 `TK#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是可签署章程或修正案草稿 | 负触发 `起草或修订公司章程` |
| 主成果是决议效力终局 | 负触发 `评估股东会董事会决议效力` |
| 主成果是召集或通过修正案 | 负触发 `准备股东会决议与召集` |
| 主成果是出资催缴或加速到期 | 负触发 `评估出资瑕疵催缴与加速到期` |
| 主成果是股东协议正文 | 负触发 `起草股东协议与一致行动安排` |
| 主成果是设立登记包 | 负触发 `准备公司设立文件与登记` |
| 主成果是类型比较 | 负触发 `选择公司类型与机关结构` |
| 主成果是存量认缴调整 | 负触发 `准备认缴期限调整与实缴整改` |
| 主成果是一般交易合同 | 整案转审查起草 |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不改写新章程」「不把冲突写成决议当然无效」 | 交付禁令，不是负触发 |

出现「章程」「冲突」「无效」一词不是转出。冲突即决议当然无效不是负触发，该格不支持。

条款闸打开（可出 `TK#` 草案，仍不得标「当然无效／设立无效／已修订」）须同时满足：单方无冲突立场已闭合；主成果是对照评估，不是改写终稿、不是决议效力终局、不是设立包；至少一项可编号章程条款碎片。口头「这条肯定违法」不算单独开闸材料。

条款闸部分打开：已有碎片，但类型、版本层级或条号对应未闭合；对应格待核；仍交十节。无书面评估授权但立场已闭合且有条款碎片：部分打开，不是整体停止。

条款闸关闭（仍正触发）：无一可编号条款碎片。「今天必须出当然无效终稿」而无最小碎片不得开闸。不出 `TK#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `TK#` 终稿，**第 7 节不得出新章程或决议当然无效**。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把无文本写成整体停止。

「冲突即决议当然无效」「冲突即设立无效」「另有规定即取消底线」「突破五年即任意」「有限必载套股份」「股东协议即已改章程」「解释三第十七条即唯一除名」「实践中都有效」「保证赢」「选定某院」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `TK#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号条款碎片，then 条款闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立股东相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出选边有利章程版本、伪造备案、倒签修正案、伪造签名、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制／任意接口

一行一个条款切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `TK#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 文本层级 | 登记章程／未备案修正案／视同改章程的决议／股东协议并列 | 选有利一版合并 |
| 强制底线 | 查阅、催缴失权、决议三项、解散、人格否认接口 | 章程取消底线 |
| 任意授权 | 仅现行明确授权（第八十四条末款程序、第六十五条、第二百一十条、第二十四条） | 写成可取消优先购买 |
| 后果 | 条款现有依据是否支持其适用 | 设立无效；决议当然无效 |

检索锚点（写入 `L#` 前须核验）：

- 第二十五条至第二十七条：无效／可撤销／不成立，不得章程废除；冲突不是决议当然无效。
- 第五十七条／第一百一十条：查阅底线分列。
- 第五十一条／第五十二条：催缴失权底线。
- 第二百三十一条：司法解散不得章程废除。第二十三条人格否认只开接口。
- 第四十六条／第九十五条：必载两套，缺项不是设立无效。
- 第四十七条：新设有限五年，不是任意。
- 第六十六条／第一百一十六条：修改章程表决分列。
- 第八十四条末款：转让程序另有规定，不打开可取消优先购买。
- 噪声：2018 年第二十二条、解释三第十七条。

不得暗示「冲突了决议就当然无效」。

## 节点 3　条款行 `TK#`

按已出现条款扫描，不是默认闭集。每条须能指向强制底线或任意授权，并分列冲突后果。

无 `E#` 不得写已适用、已无效或已改章。状态默认 `草案`。一次只推荐下一步。未知不写零。后果只判断该条款现有依据是否支持其适用；已作决议只开效力接口。善意相对人只开第十一条／第二十八条／第六十七条接口，不写交易合同效力终局。

热冲突强制处理：

- 冲突即决议当然无效／冲突即设立无效／另有规定即取消底线／突破五年／有限套股份／选有利一版／未知写零 → 该格不支持或字段停止；仍出其他 `TK#`。
- 无一碎片 → 关闸，不出 `TK#` 终稿，窗口不关。
- 指导选边有利版本、伪造备案、倒签、抢夺印章 → 整体停止，不是该格不支持。

未知条款不得解释为对用户有利的任意规范。修订只列应删应改要点，不输出完整新章程。
