# 边界与路由

## 正触发

增资未给现有股东优先认缴或比例争议。从零、碎片、通知未核验、无书面评估授权仍正触发：有可编号增资切片、实缴比例、通知／全体另定或放弃碎片则闸开或半开，出 `YJ#` 草案，保持草案。本次不写交易文件、不写当然无效是交付禁令，不是开窗条件。沉默即放弃、认缴即优先认缴比例，仍正触发。

双方秘密、伪造放弃、倒签通知或增资决议、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「沉默即放弃」「认缴即优先认缴比例」「股份套有限第一款」「第八十四条三十日套第二百二十七条」「未通知即登记当然无效」「稀释即当然无效」「未签字全体另定已排除」「未知写零」「唯一公允价」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 内部增资实施方案 | `准备内部增资与认缴调整` |
| 外部融资交割或投资协议 | 投资并购领域 |
| 决议效力终稿 | `评估股东会董事会决议效力` |
| 稀释后控制图 | `梳理股权结构与控制权` |
| 对外转让优先购买 | `评估优先购买权是否成立` |
| 名册或登记包 | `准备股东名册与工商变更衔接` |
| 合伙或个人独资 | 非公司主体 |

不得因「不写交易文件」或「不写当然无效」关窗。要判断优先认缴是否成立或被侵害仍正触发，不得写成已放弃或登记当然无效。

## 易混

本窗闸名只能是优先认缴闸，不是增资闸，不是优先购买闸。`YJ#` 不是增资准备窗 `ZZ#`，不是优先购买窗 `YX#`。主路径是 `Q-评`，不是 `Q-增`，不是 `Q-优`。认缴比例不是优先认缴比例。沉默不是默认放弃。已读不是已放弃。第八十四条三十日未答复视为放弃不得套第二百二十七条。股份不得机械套有限公司第二百二十七条第一款。未通知不是增资登记当然无效。稀释不是当然无效。1993 年第二百二十七条不是现行优先认缴条。2018 年第三十四条不是 2024 年 7 月 1 日后的现行条号。「把放弃函日期改到股东会前」整体停止。本窗不执行发送，不代提交。不选定法院。不写交割清单。不输出唯一公允价。
