# 评估增资优先认缴权方法

本文件是可执行判断节点。认缴比例不是优先认缴比例。沉默不是默认放弃。已读不是已放弃。第八十四条三十日未答复视为放弃不得套第二百二十七条。股份不得机械套有限公司第二百二十七条第一款。未通知不是增资登记当然无效。稀释不是当然无效。未知不写零。不输出唯一公允价。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已放弃、登记当然无效、选定法院、代提交、未知写零、唯一公允价。本任务不定罪，不执行发送，不写增资实施终稿，不写交割清单。本窗闸名只能是优先认缴闸，禁止复用增资闸、优先购买闸、认缴闸、转让闸、决议闸。预留不得占用：僵局闸、谈判闸、和解闸、立案闸、控制闸、登记闸、显名闸。本窗 `YJ#` 是优先认缴行。主路径只用 `Q-评`，禁止用 `Q-增`、`Q-优`、`Q-转` 作主路径。禁止占用增资准备窗 `ZZ#`、优先购买窗 `YX#`、认缴窗 `RZ#`。英文 id 禁止使用，一律用中文技能名 `评估增资优先认缴权`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年第二百二十七条复议行政诉讼、2018 年第三十四条、把第八十四条三十日套进第二百二十七条、把未通知写成登记当然无效时记为噪声，不得写入 `L#`。禁止指导伪造放弃或倒签增资决议。估值冲突并列，不选对用户有利的一版。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现增资切片、实缴比例、通知或放弃碎片扫描，不是默认闭集。
`YJ#` 固定列：`编号｜有限或股份｜同等条件与实缴比例｜通知或全体另定｜放弃范围｜稀释与救济接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已放弃」或「登记当然无效」。无 `E#` 不得写已书面通知或已放弃。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-评`。禁止 `ZZ#`、`YX#`、`RZ#`、`A#`、`N#`。有限／股份分列。一行一个切片。金额未知写 `未知`／`G#`，禁止写 `0`。

口头「不说话就算放弃」「执照改了就无效」只进 `S#`／`V#`，**不得单独算作开闸材料**。增资准备窗 `ZZ#` 不得单独开闸。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：有限增资，股东在同等条件下有权优先按实缴出资比例认缴；全体另定除外。被稀释股东未签字的「全体约定」依据不足。基准是实缴不是认缴。股份增发默认无优先认购，章程或股东会另定除外，不得套有限第一款。第八十四条对外转让三十日视为放弃不得套本条。沉默、已读不是默认放弃。书面放弃不及于嗣后变更的价格或额度。侵害优先认缴不等于增资登记当然无效；优先认缴规定是否效力性强制规范待核，不得默认写成决议当然无效。救济分列：确认侵害、按同等条件认缴、赔偿、挑战决议。决议终局转效力窗。实施方案转增资准备窗。

## 节点 0　分流、立场、优先认缴闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造放弃、倒签通知或增资决议、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `YJ#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 以股权或资产收购、投资交割、尽调闭环为主要目标 | 整案转投资并购 |
| 婚姻、离婚、继承中的股权归属与分割 | 整案转婚家 |
| 高管劳动合同、解除、竞业劳动后果 | 整案转劳动 |
| 企业级舞弊调查、反商业贿赂、综合合规体系 | 整案转企业合规 |
| 破产申请、重整计划、破产债权申报与分配 | 整案转破产 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 合伙企业、个人独资 | 整案转出，非公司主体 |
| 上市公司发行、持续信息披露或证券监管主轴 | 整案转证券监管／投资并购，本领域只保留公司机关接口 |
| 主成果是内部增资实施方案 | 负触发 `准备内部增资与认缴调整` |
| 「不写交易文件」「不写当然无效」 | 交付禁令，不是负触发 |

出现「增资」「优先」「稀释」一词不是转出。

优先认缴闸打开（可出 `YJ#` 草案，仍不得标「已放弃／登记当然无效」）须同时满足：单方无冲突立场已闭合；主成果是优先认缴条件评估，不是增资实施终稿、不是交割；至少一项可编号增资切片、实缴比例、通知／全体另定或放弃碎片。口头「不说话就算放弃」不算单独开闸材料。

优先认缴闸部分打开：已有碎片，但实缴、通知或全体另定未闭合；对应格待核；仍交十节。

优先认缴闸关闭（仍正触发）：无一可编号碎片。「今天必须出已放弃／登记当然无效终稿」而无最小碎片不得开闸。不出 `YJ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `YJ#` 终稿，**第 7 节不得出已放弃或登记当然无效**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「沉默即放弃」「认缴即优先认缴比例」「股份套有限第一款」「第八十四条三十日套第二百二十七条」「未通知即登记当然无效」「稀释即当然无效」「未签字全体另定已排除」「未知写零」「唯一公允价」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `YJ#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 优先认缴闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造放弃、倒签通知或增资决议、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 3　优先认缴行 `YJ#`

按已出现增资切片、实缴比例、通知或放弃碎片扫描，不是默认闭集。每条须能指向类型、实缴或通知。

无 `E#` 不得写已书面通知或已放弃。状态默认 `草案`。一次只推荐下一步。全体另定核验失败：依据不足，不得升格已排除。同等条件不明：字段停止，不写唯一公允价。

热冲突强制处理：

- 沉默即放弃／认缴即优先认缴比例／股份套有限第一款／第八十四条三十日套第二百二十七条／未通知即登记当然无效／稀释即当然无效／未签字全体另定已排除／未知写零／唯一公允价 → 该格不支持或字段停止；仍出其他 `YJ#`。
- 无一碎片 → 关闸，不出 `YJ#` 终稿，窗口不关。
- 指导伪造放弃、倒签增资决议 → 整体停止，不是该格不支持。
