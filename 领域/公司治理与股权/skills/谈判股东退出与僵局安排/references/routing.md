# 边界与路由

## 正触发

股东关系仍可谈退出、回购、减资退出或僵局下的安排，需要底线、让步、章证照、弃权和执行力提示。从零、碎片、对价未核验、无书面谈判授权仍正触发：有相对人或标的股权则闸开或半开，出 `TC#` 草案，保持草案。本次不写已签署协议是交付禁令，不是开窗条件。口头谈拢即已签署、僵局必须解散、盈利即无僵局，仍正触发。两派无法开会但仍愿谈价格时正触发。

双方秘密、伪造放弃、倒签退出协议、虚假减资、抢夺印章证照、隐匿资产或账簿、违法取证的停止，优先于负触发。上述信号不在下表。「口头谈拢即已签署」「僵局必须解散」「盈利即无僵局」「概括弃权覆盖未知请求」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 已谈拢可签协议全文 | `起草股东和解或退出协议` |
| 司法解散诉状 | `提起司法解散之诉` |
| 僵局评估终稿 | `评估公司僵局` |
| 治理重置要点终稿 | `谈判章程与治理重置` |
| 转让文件终稿 | `准备有限公司股权内部转让` |
| 回购对价精算 | `测算利润分配与股权回购对价` |
| 投并购交割清单 | 投资并购领域 |
| 劳动解除补偿谈判 | 劳动领域 |
| 合伙或个人独资 | 非公司主体 |

不得因「不写已签署协议」或「不写解散诉状」关窗。拟谈判方案仍正触发，不得写成已签署或必须解散。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |

| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |

| 破产申请、重整计划、破产债权 | 破产领域 |
| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「退出」「僵局」「和解」一词不是转出。
