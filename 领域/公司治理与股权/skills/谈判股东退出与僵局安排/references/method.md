# 谈判股东退出与僵局安排方法

本文件是可执行判断节点。谈判方案不是已签署协议。口头同意不是已退出。僵局不是必须解散。盈利不是无僵局。概括弃权不得覆盖未知请求。单独和解不是已可强制执行。付款不是已过户。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然解散、已签署、唯一必得总额、选定法院、代签署、未知写零。本任务不定罪，不写已签署协议，不写解散诉状。本窗闸名只能是退出闸，禁止复用僵局闸、和解闸、返还闸、关系闸、转让闸、案卷闸、测算闸。本窗 `TC#` 是退出行。英文 id 禁止使用，一律用中文技能名 `谈判股东退出与僵局安排`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 2018 年第一百八十二条当现行解散条、解释二未核验对应现行第二百三十一条、把口头同意写成已退出、把类案写成必然谈成时记为噪声。禁止指导虚假减资或抢夺印章。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现相对人或标的扫描，不是默认闭集。
`TC#` 固定列：`编号｜相对人｜标的股权｜退出接口｜底线｜让步至｜弃权范围｜章证照与账户｜执行力提示｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。无 `E#` 不得写已退出、已签署、已交接或已可执行。`E#` 只作证据形态回链，不是发送闸。扫描不是闭集。缺项记 `G#`。承认只进 `S#`／`D#`，不得占用 `A#`。

口头「已经谈拢」「不谈就解散」「微信说没问题」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：仅和解协议通常无直接强制执行力。司法确认、调解书、公证赋强分列条件，未核验不得写成已可强制执行。用户未明示放弃的不得写入弃权。概括「再无任何争议」覆盖未知查阅、代表诉讼或损害赔偿：该格 `现有依据不支持`。代表诉讼处分的是公司请求，股东私自免除：该格不支持。盈利公司也可能机关失灵。

## 节点 0　分流、立场、退出闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造放弃、倒签退出协议、虚假减资、抢夺印章证照、隐匿资产或账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `TC#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是已谈拢可签协议全文 | 负触发 `起草股东和解或退出协议` |
| 主成果是司法解散诉状 | 负触发 `提起司法解散之诉` |
| 主成果是僵局评估终稿 | 负触发 `评估公司僵局` |
| 主成果是治理重置要点 | 负触发 `谈判章程与治理重置` |
| 主成果是转让文件终稿 | 负触发 `准备有限公司股权内部转让` |
| 主成果是回购对价精算 | 负触发 `测算利润分配与股权回购对价` |
| 主成果是投并购交割 | 整案转投资并购 |
| 主成果是劳动解除补偿 | 整案转劳动 |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不写已签署协议」「不写解散诉状」 | 交付禁令，不是负触发 |

出现「退出」「僵局」「和解」一词不是转出。

退出闸打开（可出 `TC#` 草案，仍不得标「已签署／必须解散／已可执行」）须同时满足：单方无冲突立场已闭合；主成果是谈判方案，不是可签协议、不是解散诉状、不是僵局终局；至少一项可编号相对人或标的股权／对价碎片。口头「已经谈拢」不算单独开闸材料。

退出闸部分打开：已有碎片，但对价、章证照或执行力未闭合；对应格待核；仍交十节。无书面谈判授权但立场已闭合且有碎片：部分打开，不是整体停止。

退出闸关闭（仍正触发）：无一可编号碎片。「今天必须出已签署／必须解散终稿」而无最小碎片不得开闸。不出 `TC#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `TC#` 终稿，**第 7 节不得出已签署协议或解散诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「口头谈拢即已签署」「僵局必须解散」「盈利即无僵局」「概括弃权覆盖未知请求」「章证照一并处理即已交接」「未知对价写零」「单独和解即已可执行」「付款即已过户」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `TC#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 退出闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与对立股东相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造放弃、倒签退出协议、虚假减资、抢夺印章证照、隐匿资产或账簿、违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个相对人或路径。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `TC#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 路径 | 转让／第八十九条回购／减资／治理重置／解散接口分列，按可逆性排序 | 预先锁定必须解散 |
| 表决权 | 解散接口百分之十单独或合计待核 | 写成资格已具备 |
| 盈利 | 盈利不排除僵局，也不等于必须解散 | 盈利即无僵局或必须解散 |

检索锚点（写入 `L#` 前须核验）：

- 第八十四条：对内可转；对外书面通知优先购买。
- 第八十六条：受让人自记载名册时起主张股东权利。付款、签署不是已过户。
- 第八十九条：异议回购；六十日协议／九十日起诉；收购后六个月库股清理分列。
- 减资须债权人保护。跳过通知、公告、清偿或担保不得写成已退出。
- 第二百三十一条：百分之十以上表决权、严重困难、重大损失、其他途径不能解决。噪声：2018 年第一百八十二条。
- 私下和解不能当然司法确认。公证赋强只提示不保证。伤残等级与本窗无关。

不得暗示「不谈就一定解散」。

## 节点 3　退出行 `TC#`

按已出现相对人或标的扫描，不是默认闭集。每条须能指向退出接口、底线、弃权和章证照分项。

无 `E#` 不得写已退出、已签署、已交接或已可执行。状态默认 `草案`。一次只推荐下一步。未知对价不写零。章证照：法定代表人、公章财务章合同章、执照、U盾、账簿分列保管人、交接时点和未交接后果。禁止「一并处理」省略，禁止教唆抢夺。

热冲突强制处理：

- 口头谈拢即已签署／僵局必须解散／盈利即无僵局／概括弃权／章证照一并处理／未知写零／单独和解即已可执行／付款即已过户 → 该格不支持或字段停止；仍出其他 `TC#`。
- 无一碎片 → 关闸，不出 `TC#` 终稿，窗口不关。
- 指导伪造放弃、虚假减资、抢夺印章 → 整体停止，不是该格不支持。

弃权须列明请求权类型和相对人。用户未明示不得写入。代表诉讼请求属公司，股东私自免除该格不支持。

## 节点 4　协议、解散、僵局与测算接口

第 7 节只开接口，不得夹带 `TC#` 终稿、已签署协议或解散诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待相对人编号」，不得补写已签署。执行力分列：仅和解＝合同效力、通常无直接强制执行力；司法确认／调解书／公证赋强未核验则字段停止，不得写成已可强制执行。名册记载、变更登记、付款三分列。

下一步只转介：`起草股东和解或退出协议`、`提起司法解散之诉`、`评估公司僵局`、`谈判章程与治理重置`、`准备有限公司股权内部转让`、`测算利润分配与股权回购对价`、`评估异议股东回购请求`、`准备减资通知与债权人保护`、`准备证照印章管控与交接`。禁止此致某法院。不选定法院。不代签署。不代提交。

若 if 用户催促「已经谈拢就算签了／不谈就解散／再无任何争议／对价先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 再执行清单

每个节点结束后回写：来源、判断、最强反方、是否字段停止。不得跳过退出闸直接给已签署或必须解散终稿。

若 if 百分之十表决权、减资债权人保护、执行力、回购期限未核验，then 该强制项字段停止，窗口不关。
判断状态只许三值。口头「已经谈拢」不得写成 `TC#` 已签署。未知不写零。

## 本任务回链纪律

本任务成果是「退出闸与谈判方案草案」。本窗不执行发送，不代签署。不包含：已签署协议、解散诉状、僵局终局。禁止选边治愈。禁止口头谈拢即已签署。禁止僵局必须解散。禁止指导虚假减资或抢夺印章。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：有限公司五五持股、两年开不成有效会、公司仍盈利。一方口头说价格谈拢，要求写「再无任何争议」、章证照一并交给留守方、对价先写零，并主张不签就按 2018 年第一百八十二条必须解散。退出闸打开或半开。`Q-口`、`Q-必`、`Q-盈`、`Q-弃`、`Q-证`、`Q-零` 不打开为可靠路径。第 6 节不得把已签署、必须解散、已交接、0 写入可执行 `TC#`；对应格不支持或字段停止；仍出转让／回购／减资／重置分列与章证照分项等其他 `TC#`。不关窗。不写协议终稿。

场景②：用户同时交出「对方已书面放弃全部未知债权、减资不通知债权人、今晚把章抢走」与对立股东「从未放弃、账上资金已转走」口径，要求选对己方有利的一版并指导倒签放弃、隐匿资产或抢章。命中双方秘密＋伪造放弃＋虚假减资＋抢夺印章。第一次整体停止。只交第 1、10 节。不出 `TC#`。不得问代表哪一方后继续。不以「坚持」为门槛。
