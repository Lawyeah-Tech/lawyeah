# 边界与路由

## 正触发

回购、转让或出资不实需要鉴定事项和检材，而不是预测意见。从零、碎片、基准日未核验、无书面鉴定授权仍正触发：有可编号待鉴定碎片则闸开或半开，出 `JD#` 草案，保持草案。本次不预测鉴定意见、未知不写零、不输出唯一公允价是交付禁令，不是开窗条件。申请即已作出、评估报告即司法鉴定、谈判价即结论，仍正触发。

双方秘密、补造账册、伪造评估、倒签基准日、抢夺账簿、违法取证的停止，优先于负触发。上述信号不在下表。预测鉴定意见不是负触发。「申请即已作出」「评估报告即司法鉴定」「谈判价即结论」「最有利一天即唯一基准日」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 非货币可出资性或作价评估 | `评估非货币出资真实性与作价` |
| 出资差额或抽逃精算 | `测算出资差额利息与抽逃金额` |
| 利润或回购测算工作表 | `测算利润分配与股权回购对价` |
| 异议回购条件评估 | `评估异议股东回购请求` |
| 账簿合法封存 | `保全公司账簿印章与电子治理记录` |
| 知识产权权属鉴定整案 | 知识产权领域 |
| 可提交诉状 | `提起股东权利诉讼` |
| 合伙或个人独资 | 非公司主体 |

不得因「不预测鉴定意见」「未知不写零」或「不输出唯一公允价」关窗。拟鉴定准备仍正触发，不得写成已作出或唯一公允价。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |
| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |
| 知识产权权属鉴定整案 | 知识产权领域 |

出现「鉴定」「评估」「公允价」一词不是转出。

## 易混

本窗闸名只能是鉴定闸，不是非货币闸，不是测算闸，不是差额闸。`JD#` 不是 `FB#`，不是 `CE#`，不是 `DJ#`，不是 `FC#`。主路径是 `Q-鉴`，不是 `Q-非`，不是 `Q-测`。申请草稿不是鉴定意见。评估报告不是司法鉴定。测算工作表不是鉴定。历史谈判价不是鉴定结论。2018 年第二十七条不是现行第四十八条。「检材先补一套账」「基准日改到对我们有利那天」整体停止。本窗不执行发送，不代提交。不选定法院。不预测鉴定意见。不输出唯一公允价。
