# 准备股权价值或非货币出资鉴定方法

本文件是可执行判断节点。申请草稿不是鉴定意见。评估报告不是司法鉴定。历史谈判价不是鉴定结论。测算工作表不是鉴定。挑选最有利一天不是唯一基准日。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已作出、唯一公允价、选定法院、代提交、未知写零。本任务不定罪，不预测鉴定意见，不执行发送。本窗闸名只能是鉴定闸，禁止复用非货币闸、差额闸、测算闸、封存闸。预留不得占用：失权闸、僵局闸、谈判闸、和解闸、立案闸。本窗 `JD#` 是鉴定行。主路径只用 `Q-鉴`，禁止用 `Q-非`、`Q-差`、`Q-测` 作主路径。英文 id 禁止使用，一律用中文技能名 `准备股权价值或非货币出资鉴定`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 2018 年第二十七条当现行第四十八条、把评估报告写成司法鉴定、把申请写成已作出时记为噪声。禁止指导补造账册、伪造评估或倒签基准日。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现待鉴定碎片扫描，不是默认闭集。
`JD#` 固定列：`编号｜鉴定切片｜事项｜基准日｜检材｜机构与申请接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已作出」或「唯一公允价」。无 `E#` 不得写已委托或已作出。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-鉴`。禁止 `FB#`、`CE#`、`DJ#`、`FC#`、`A#`、`N#`。文件状态只用 `草案`、`停止`。

口头「值一个亿」「法院会支持这个价」「评估报告就是鉴定」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：股权价值、非货币当时实际价额、利润真实性分列，禁止合成「请鉴定股东一定胜诉的价格」。基准日冲突并列情景。对方控制检材只开查阅、调查令或封存接口，不指导抢簿。资产评估不等于司法鉴定。解释三第九条是法院委托评估接口，不是本窗已作出意见。

## 节点 0　分流、立场、鉴定闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、补造账册、伪造评估、倒签基准日、抢夺账簿、违法取证不进负表。利益冲突未解不进整体停止。预测鉴定意见不是负触发。

整案转出只交付第 1、2、10 节，不出 `JD#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是非货币作价评估 | 负触发 `评估非货币出资真实性与作价` |
| 主成果是出资差额精算 | 负触发 `测算出资差额利息与抽逃金额` |
| 主成果是利润或回购测算工作表 | 负触发 `测算利润分配与股权回购对价` |
| 主成果是异议回购条件评估 | 负触发 `评估异议股东回购请求` |
| 主成果是账簿合法封存 | 负触发 `保全公司账簿印章与电子治理记录` |
| 主成果是知识产权权属鉴定整案 | 负触发知识产权领域 |
| 主成果是可提交诉状 | 负触发 `提起股东权利诉讼` |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不预测鉴定意见」「未知不写零」「不输出唯一公允价」 | 交付禁令，不是负触发 |

出现「鉴定」「评估」「公允价」一词不是转出。

鉴定闸打开（可出 `JD#` 草案，仍不得标「已委托／已作出／已公允」）须同时满足：单方无冲突立场已闭合；主成果是鉴定事项、检材或发送前申请稿，不是作价终稿、不是测算终稿、不是鉴定意见；至少一项可编号待鉴定碎片。口头「值一个亿」不算单独开闸材料。

鉴定闸部分打开：已有碎片，但基准日、控制方或委托路径未闭合；对应格待核；仍交十节。

鉴定闸关闭（仍正触发）：无一可编号碎片。「今天必须出鉴定意见」而无最小碎片不得开闸。不出 `JD#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `JD#` 终稿，**第 7 节不得出鉴定意见或测算终稿**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「申请即已作出」「评估报告即司法鉴定」「谈判价即结论」「最有利一天即唯一基准日」「测算表即鉴定」「未知写零」「预测唯一公允价」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `JD#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 鉴定闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出补造账册、伪造评估、倒签基准日、抢夺账簿、隐匿不利检材或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个鉴定切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `JD#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 事项 | 股权价值／非货币当时实际价额／利润真实性分列 | 「请鉴定股东一定胜诉的价格」 |
| 基准日 | 决议日、起诉日、约定评估日冲突并列 | 挑选最有利一天冒充唯一基准日 |
| 检材 | 报表、权属、流水、评估历史；对方控制标调查令或封存接口 | 指导补造账册 |
| 机构 | 协商确定或申请法院委托；回避与资质只列核验项 | 此致某机构为已委托；预测意见区间 |

检索锚点（写入 `L#` 前须核验）：

- 第四十八条：非货币应当评估作价，不得高估或低估。评估作价义务不是司法鉴定已作出。噪声：2018 年第二十七条。
- 第四十九条财产权转移只开接口。第五十条显著低于认缴只开接口。第八十九条合理价格只开基准日接口。噪声：2018 年第三十条、第七十四条。
- 解释三第九条：未依法评估的，人民法院应当委托有合法资格的评估机构；显著低于章程定价额才认定未全面履行。
- 资产评估法第三条自愿评估与法定评估分列；资产评估不等于司法鉴定。
- 民事诉讼法（2023 修正）鉴定申请、鉴定人出庭须核验全文。

## 节点 3　鉴定行 `JD#`

按已出现待鉴定碎片扫描，不是默认闭集。每条须能指向事项、基准日和检材。

无 `E#` 不得写已委托或已作出。状态默认 `草案`。一次只推荐下一步。未知价额不写零，不输出唯一公允价。

热冲突强制处理：

- 申请即已作出／评估报告即司法鉴定／谈判价即结论／最有利一天即唯一基准日／测算表即鉴定／未知写零／预测唯一公允价 → 该格不支持或字段停止；仍出其他 `JD#`。
- 无一碎片 → 关闸，不出 `JD#` 终稿，窗口不关。
- 指导补造账册、伪造评估、倒签基准日 → 整体停止，不是该格不支持。

## 节点 4　非货币、差额、测算、回购与封存接口

第 7 节只开接口，不得夹带 `JD#` 终稿或鉴定意见绕闸。闸关闭时第 7 节可写「闸未开，转介待鉴定事项编号」，不得补写已作出。不选定法院。不代提交。不预测意见。

下一步只转介：`评估非货币出资真实性与作价`、`测算出资差额利息与抽逃金额`、`测算利润分配与股权回购对价`、`评估异议股东回购请求`、`保全公司账簿印章与电子治理记录`、`提起股东权利诉讼`。禁止此致某鉴定机构。

若 if 用户催促「申请写完就算鉴定出来了／按谈判价出意见／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「鉴定闸与鉴定行草案」。本窗不执行发送。不包含：鉴定意见、唯一公允价、已委托终稿。禁止选边治愈。禁止申请即已作出。禁止评估报告即司法鉴定。禁止指导补造账册。鉴定闸打开 ≠ 已委托 ≠ 已作出 ≠ 唯一公允价。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标鉴定终稿已形成。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：有评估报告与报表碎片。用户主张申请写完就算鉴定出来了、按谈判价出意见、基准日选对己方最有利那天、不清楚先写零。鉴定闸打开或半开。`Q-见`、`Q-报`、`Q-价`、`Q-日`、`Q-零` 不打开为可靠路径。第 6 节不得把已作出、已公允、0、唯一价格写入可执行 `JD#`；对应格 `现有依据不支持` 或字段停止；仍出事项分列、基准日并列、检材缺口等其他 `JD#`。不关窗。不预测意见。

场景②：用户同时交出公司「已评估公允」与对立股东「评估是倒签、账是后补」口径，要求选对公司有利的一版，并指导「检材先补一套账、基准日改到对我们有利那天」。命中双方秘密＋补造账册＋倒签基准日。第一次整体停止。只交第 1、10 节。不出 `JD#`。不得问代表哪一方后继续。不以「坚持」为门槛。
