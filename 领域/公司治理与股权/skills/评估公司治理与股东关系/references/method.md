# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、论坛、期限、金额或文书状态的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然无效、必然失权、必然解散或唯一必得总额。

`search_law` 返回已失效《合同法》、1993／2004／2013／2018《公司法》或仍引用旧第二十二条、第三十三条、第七十一条且未核验对应关系的司法解释时，记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

---

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 以股权或资产收购、投资交割、尽调闭环为主要目标 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果、员工激励的劳动身份 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂、综合合规体系 | 企业合规领域 |
| 破产申请、重整计划、破产债权申报与分配 | 破产领域 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 合伙企业、个人独资的入伙退伙 | 非公司主体，不在本领域 |
| 上市公司发行、持续信息披露或证券监管主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

混合信号：公司组织或股东关系主轴可留本任务；专项只作为背景时在缺口标明，不把专项规则硬套进本领域结论。

## Q# 矩阵

固定列：`编号｜关系假设｜提出方｜相对方｜法律效果｜成立条件｜支持事实｜不利事实｜控制方｜最强反方｜主备位｜判断｜待核`。

查阅、催缴、失权、决议效力、分配、回购、代表诉讼、人格否认、解散分列。同一事实支持多项时分别说明效果，不重复金额。

---

## 节点 1　主体、章程版本和机关状态

1. 固定章程、修正案、股东名册、出资证明书、登记公示、股东协议的版本层级。冲突并列，不选对用户有利的一版冒充唯一文本。
2. 主体表记录登记股东、实际出资人、董事、法定代表人、可能责任主体。名称不一致不自动合并。名册记载与登记不一致时分列对内对外效力，不写成已经统一。
3. 机关表记录股东会、董事会或一名董事、监事会或审计委员会是否依法设置，以及现行召集权人。
4. 程序表逐动作记录催缴、失权、召集、决议、仲裁、诉讼：机关、案号、文书、作出日、收到日、送达方式和效力凭证。
5. 同时掌握双方秘密或立场不明：整体停止策略输出。

---

## 节点 2　请求与抗辩假设

每个 `Q#` 先写法律效果，再写成立条件。禁止合成“股东权益”一笔。

默认主位候选按事实分别建立：

- `Q-阅` 查阅复制
- `Q-催` 书面催缴或加速到期（本身不是失权）
- `Q-失` 失权
- `Q-决` 决议不成立／无效／可撤销
- `Q-分` 利润分配或违法分配返还
- `Q-购` 异议回购或滥权回购
- `Q-代` 代表诉讼
- `Q-人` 人格否认或一人公司连带
- `Q-僵` 司法解散
- `Q-抗` 资格、除斥、不正当目的、仲裁／管辖异议

主备位和互斥必须可见。`Q-僵` 与内部退出不得同时写成均已成立且必须解散。

---

## 节点 3　论坛与期限分类型

1. 章程、股东协议出现仲裁条款时，不得直接写“应向法院起诉”。效力标待核，转介论坛原子或在缺口标明。
2. 每种期间单独一行。禁止用三年诉讼时效去算决议撤销或失权异议。
3. 决议撤销：股东自决议作出之日起六十日；未被通知股东自知道或应当知道之日起六十日，自决议作出之日起一年未行使则消灭。须运行时核验现行第二十六条。
4. 关键日期冲突建并行情景，不给唯一截止日。

---

## 节点 4　金额区间

分项：未出资本息、抽逃返还、可分配利润、回购合理价格、损害赔偿。未知不写零，不输出唯一必得总额。合理价格和利润参数不足时只列接口。

---

## 节点 5　证据与下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制账簿印章而推定内容有利。

下一步按期限灭失、易失证据、改变请求抗辩、可逆性排序。催缴通知、失权通知、召集决议、起诉、应诉、精算、完整证据卷只写转介条件和最小交接。禁止指导伪造、抢夺或违法取证。
