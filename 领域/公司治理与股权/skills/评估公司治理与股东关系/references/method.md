# 评估公司治理与股东关系方法

本文件是可执行判断节点。登记不是已是实质股东。名册不是对外对抗已完成。控股不是已滥用。人格否认不是已成立。僵局不是必须解散。章程印发不是治理已有效。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然解散、必然失权、唯一必得总额、选定法院、代提交、未知写零。本任务不定罪，不写发送版催缴或诉状。本窗闸名只能是关系闸，禁止复用评估闸、催缴闸、决议闸、止付闸。本窗 `GX#` 是关系行。英文 id 禁止使用，一律用中文技能名 `评估公司治理与股东关系`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年公司法第二十一条国有企业改建、2018 年条号未核验对应关系、把登记写成已股东、把控股写成已滥用、把僵局写成必须解散时记为噪声。禁止指导伪造决议或抢夺印章。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现主体扫描，不是默认闭集。
`GX#` 固定列：`编号｜主体切片｜持股与名册登记｜机关角色｜冲突点｜打开接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「股东权益」一笔。无 `E#` 不得写已股东、已对抗或已滥用。`E#` 只作证据形态回链，不是发送闸。扫描不是闭集。缺项记 `G#`。承认只进 `S#`／`D#`，不得占用 `A#`。

口头「登记上就是股东」「大股东当然滥用」「必须解散」只进 `S#`／`V#`，**不得单独算作开闸材料**。已读不得升格已送达或已通过。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：实际出资人不当然取得股东资格，须结合名册、登记与行使权利综合判断。控制股东滥用须考量商业合理性，司法介入保持谦抑。解散须通过其他途径不能解决，不要求穷尽一切但不得写成必须解散。

## 节点 0　分流、立场、关系闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造决议、倒签会议、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `GX#` 终稿。

混合信号：公司组织或股东关系主轴可留本任务。出现「股东」「章程」「僵局」一词不是转出。

关系闸打开（可出 `GX#` 草案，仍不得标「已股东／已滥用／必须解散」）须同时满足：单方无冲突立场已闭合；主成果是关系总图，不是催缴通知、不是决议、不是诉状；至少一项可编号主体、名册或机关碎片。口头「登记上就是」不算单独开闸材料。

关系闸部分打开：已有碎片，但章程版本或登记未闭合；对应格待核；仍交十节。

关系闸关闭（仍正触发）：无一可编号碎片。「今天必须出已股东／必须解散终稿」而无最小碎片不得开闸。不出 `GX#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `GX#` 终稿，**第 7 节不得出催缴通知、决议或诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「登记即已股东」「名册即对外对抗」「控股即已滥用」「人格否认已成立」「僵局必须解散」「章程印发即治理已有效」「仲裁条款即应起诉」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `GX#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 关系闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与对立股东相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造决议、倒签会议、抢夺印章证照、隐匿账簿、违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体、章程版本与机关

一行一个主体或文本版本。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `GX#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 公司类型 | 有限／股份／一人公司分列 | 合伙套公司法机关 |
| 文本版本 | 章程、名册、登记、股东协议冲突并列 | 选对用户有利的一版冒充唯一文本 |
| 机关 | 股东会、董事会或一名董事、监事会或审计委员会是否依法设置 | 口头「已经开会」升格已通过 |

检索锚点（写入 `L#` 前须核验）：

- 公司法（2023 修订）第二十一条：不得滥用股东权利。
- 第二十三条：人格否认；一人公司财产混同分列。
- 名册与登记分列；未经登记不得对抗善意相对人。有限公司名册常见检索第五十六条，条号运行时核验，不得把 2018 年第三十二条直接当现行条。噪声：1993 年第二十一条、解释三旧条号未核验。法释〔2024〕7 号时间效力只开接口。

名称不一致不自动合并。名册记载与登记不一致时分列对内对外效力，不写成已经统一。

## 节点 3　关系行 `GX#`

按已出现主体扫描，不是默认闭集。每条须能指向持股或名册登记、机关角色和只开接口的冲突。登记、控股、章程印发单独不足支撑已股东、已滥用或治理已有效。

无 `E#` 不得写已股东、已对抗或已滥用。状态 `草案`。一次只推荐下一步。未知金额不写零，不输出唯一必得总额。

热冲突强制处理：

- 登记即股东／名册即对抗／控股即滥用／人格否认已成立／僵局必须解散 → 该格不支持；仍出其他 `GX#`。
- 无一碎片 → 关闸，不出 `GX#` 终稿，窗口不关。
- 指导伪造决议、倒签、抢夺印章、隐匿账簿 → 整体停止，不是该格不支持。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：有限公司小股东出示工商登记，主张自己就是实质股东、大股东控股当然滥用、公司必须解散、保证胜诉、选定某中院、金额不清楚先写零。关系闸打开或半开。`Q-登`、`Q-控`、`Q-僵`、`Q-人` 不打开为可靠路径。第 6 节不得把已股东、已滥用、必须解散写入可执行 `GX#`；对应格 `现有依据不支持`；仍出名册／登记冲突、机关设置、查阅／催缴／决议接口等其他 `GX#`。不关窗。不写诉状。不选定法院。
