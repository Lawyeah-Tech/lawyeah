# 边界与路由

## 正触发

公司组织、股东权利、股权安排或僵局问题已出现，需要总图再决定催缴、查阅、作决议或诉讼。从零、碎片、章程未核验、无书面评估授权仍正触发：有主体或机关则闸开或半开，出 `GX#` 草案，保持草案。登记即股东、控股即滥用、僵局必须解散，仍正触发。

双方秘密、伪造决议、倒签会议、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「登记即已股东」「控股即已滥用」「僵局必须解散」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 出资瑕疵催缴或加速到期评估 | `评估出资瑕疵催缴与加速到期` |
| 决议效力判断 | `评估股东会董事会决议效力` |
| 发送版催缴或失权通知 | `准备催缴出资通知` |
| 可签署决议或召集通知 | `准备股东会决议与召集` |
| 知情查阅权终稿 | `评估股东知情查阅权` |
| 利润分配请求权终稿 | `评估利润分配请求权` |
| 异议回购终稿 | `评估异议股东回购请求` |
| 代表诉讼条件终稿 | `评估股东代表诉讼条件` |
| 僵局或司法解散终稿 | `评估公司僵局` |
| 人格否认终稿 | `评估法人人格否认` |
| 可提交诉状 | `提起股东权利诉讼` |
| 可提交答辩 | `应对股东权利诉讼` |
| 投资收购交割 | 投资并购领域 |
| 婚姻或继承中的股权归属 | 婚家领域 |
| 合伙或个人独资 | 非公司主体 |

不得因「不写发送版催缴」或「不写诉状」关窗。拟关系总图仍正触发，不得写成已股东或必须解散。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂、综合合规体系 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |
| 合伙企业、个人独资入伙退伙 | 非公司主体 |
| 上市公司发行、持续信息披露主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

公司日常治理夹带专项背景时，专项段只分流。出现「股东」「章程」「僵局」一词不是转出。

## 易混

登记不是已是实质股东。名册不是对外对抗已完成。控股不是已滥用。人格否认不是已成立。僵局不是必须解散。章程印发不是治理已有效。仲裁条款不是应起诉。查阅催缴决议不得合成一笔股东权益。本窗 `GX#` 不是催缴通知，不是决议，不是诉状。「会议纪要倒签、公章先扣」整体停止。本窗不执行发送，不代提交。不选定法院。
