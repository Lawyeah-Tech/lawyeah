# 边界与路由

## 正触发

公司组织、股东权利、股权安排或僵局问题已出现，单方需要总体决定请求、抗辩、论坛、证据优先级和下一步。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 评估出资瑕疵或加速到期本身 | `评估出资瑕疵催缴与加速到期` |
| 只判断决议效力 | `评估股东会董事会决议效力` |
| 发催缴通知 | `准备催缴出资通知`（未安装则 `unavailable`） |
| 作出股东会决议 | `准备股东会决议与召集` |
| 办理股权转让 | `准备有限公司股权内部转让` |
| 精算利润或回购 | `测算利润分配与股权回购对价` |
| 完整证据卷 | `建立公司治理与股东争议证据案卷` |
| 退出谈判 | `谈判股东退出与僵局安排` |
| 起诉 | `提起股东权利诉讼` |
| 应诉 | `应对股东权利诉讼` |
| 投并购／婚家／劳动／合规／破产 | 对应领域 |
| C 端创业股权／代持／股东责任 | 大众专项，只分流不回改 |

## 专项整案转出

| 信号 | 转出 |
| --- | --- |
| 以股权或资产收购、投资交割、尽调闭环为主要目标 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果、员工激励的劳动身份 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂、综合合规体系 | 企业合规领域 |
| 破产申请、重整计划、破产债权申报与分配 | 破产领域 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 合伙企业、个人独资的入伙退伙 | 非公司主体，不在本领域 |
| 上市公司发行、持续信息披露或证券监管主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

公司日常治理夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

请求尚未闭合、需比较查阅、催缴、作决议或起诉时正触发。主体、请求、论坛均确认且只要诉状时负触发。
