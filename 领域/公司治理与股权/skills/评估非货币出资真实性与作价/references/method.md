# 评估非货币出资真实性与作价方法

本文件是可执行判断节点。未评估不是当然显著低价。合同一签不是已实缴。评估报告不是已公允。劳务不是当然能出资。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已公允、当然虚假出资、选定法院、代提交、未知写零、唯一公允价。本任务不定罪，不预测鉴定意见，不写催缴书。本窗闸名只能是非货币闸，禁止复用瑕疵闸、催缴闸、测算闸、鉴定闸。本窗 `FB#` 是非货币行。英文 id 禁止使用，一律用中文技能名 `评估非货币出资真实性与作价`。主路径只用 `Q-非`，禁止 `Q-催`、`Q-鉴`、`Q-测` 作主路径。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 2018 年第二十七条当现行第四十八条、把未评估写成当然显著低价、把合同一签写成已实缴时记为噪声。禁止指导伪造评估报告或倒签过户日。伤残等级与本窗无关。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现标的碎片扫描，不是默认闭集。
`FB#` 固定列：`编号｜标的切片｜可出资性｜权属负担｜转移手续｜作价争点｜责任接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。无 `E#` 不得写已实缴、已公允或当然显著低价。`E#` 只作证据形态回链，不是发送闸。扫描不是闭集。缺项记 `G#`。承认只进 `S#`／`D#`，不得占用 `A#`。

口头「这个专利值一个亿」「合同签了就算实缴」「有评估报告就是公允」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。

实务上：非货币须可估价、可依法转让并办理财产权转移。评估作价是法定义务，但无评估不等于当然显著低价。显著低价须有比较基准，基准缺失则依据不足。

## 节点 0　分流、立场、非货币闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造评估报告、伪造权属证书、倒签过户日、隐匿担保负担、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `FB#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是货币未缴或抽逃定性 | 负触发 `评估出资瑕疵催缴与加速到期` |
| 主成果是鉴定事项和检材 | 负触发 `准备股权价值或非货币出资鉴定` |
| 主成果是催缴书或失权通知 | 负触发 `准备催缴出资通知` 或 `评估失权与股权丧失` |
| 主成果是差额精算 | 负触发 `测算出资差额利息与抽逃金额` |
| 主成果是知识产权权属整案 | 负触发知识产权领域 |
| 主成果是投并购交割 | 整案转投并购 |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不预测鉴定」「不写已虚假出资」 | 交付禁令，不是负触发 |

出现「非货币」「作价」「评估」一词不是转出。未评估即当然低价不是负触发，该格不支持。尚未确认标的但主成果仍是非货币评估：正触发关闸，第 7 节开鉴定接口。

非货币闸打开（可出 `FB#` 草案，仍不得标「已实缴／已公允／当然低价」）须同时满足：单方无冲突立场已闭合；主成果是非货币真实性与作价评估草案，不是鉴定意见、不是催缴书、不是货币抽逃定性；至少一项可编号非货币标的碎片。口头「值一个亿」不算单独开闸材料。

非货币闸部分打开：已有标的碎片，但权属、转移或比较基准未闭合；对应格待核；仍交十节。无书面评估授权但立场已闭合且有标的碎片：部分打开，不是整体停止。

非货币闸关闭（仍正触发）：无一可编号标的碎片。「今天必须出已实缴／已公允终稿」而无最小碎片不得开闸。不出 `FB#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `FB#` 终稿，**第 7 节不得出鉴定意见或催缴书**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「未评估即当然显著低价」「合同一签即已实缴」「评估报告即已公允」「劳务当然能出资」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `FB#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号标的碎片，then 非货币闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与出资股东相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造评估报告、伪造权属证书、倒签过户日、隐匿担保负担、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个标的切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `FB#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 标的 | 实物／知识产权／土地使用权／股权／债权／数据或虚拟财产待核 | 劳务当然能出资 |
| 可出资性 | 可估价、可依法转让；禁目待核 | 凭记忆写一律合法或一律禁止 |
| 权属负担 | 处分权、共有、质押、查封 | 隐匿负担；共有未同意写成已可处分 |
| 转移 | 过户、交付、债权通知 | 合同一签即已实缴 |
| 作价 | 评估报告与比较基准 | 无基准写当然低价；预测鉴定；唯一公允价 |
| 责任 | 第 50／88／99 条接口 | 写已连带成立；写已构成犯罪 |

检索锚点（写入 `L#` 前须核验）：

- 第四十八条：可估价并可依法转让；应当评估作价。噪声：2018 年第二十七条。
- 第四十九条第二款：非货币应当依法办理财产权转移手续。
- 第五十条：设立时其他股东连带，只开接口。
- 第八十八条：转让后连带，只开接口。
- 第九十八条、第九十九条：股份发起人准用，不得与有限混套。
- 第二百五十二条：虚假出资罚款只开登记处罚接口，不定罪。
- 公司登记管理实施办法第六条：数据、网络虚拟财产须法律对权属有规定。
- 市场主体登记管理条例第十三条：劳务、信用、自然人姓名、商誉、特许经营权或设定担保的财产等须核验。设定担保的财产不自动写成无效，标负担。

不得暗示「没有评估报告出资就假了」。

## 节点 3　非货币行 `FB#`

按已出现标的扫描，不是默认闭集。实物、知识产权、土地使用权、股权、债权分列。数据或网络虚拟财产另列待核。

无 `E#` 不得写已实缴、已公允或当然显著低价。状态默认 `草案`。一次只推荐下一步。未知价额不写零。无比较基准不得写当然显著低价。未过户、未交付、债权未通知不得写已实缴。劳务等禁目未核验字段停止，主张当然能出资该格不支持。

热冲突强制处理：

- 未评估即当然低价／合同一签即已实缴／评估报告即已公允／劳务当然能出资／估数或写零 → 该格不支持或字段停止；仍出其他 `FB#`。
- 无一标的碎片 → 关闸，不出 `FB#` 终稿，窗口不关。
- 指导伪造评估报告、伪造权属、倒签过户、隐匿负担 → 整体停止，不是该格不支持。

## 节点 4　瑕疵、催缴、鉴定与精算接口

第 7 节只开接口，不得夹带 `FB#` 终稿、鉴定意见或催缴书绕闸。闸关闭时第 7 节可写「闸未开，转介待标的编号」，不得补写已实缴。需要鉴定事项只开鉴定窗接口。货币抽逃只开瑕疵窗接口。

下一步只转介：`评估出资瑕疵催缴与加速到期`、`准备催缴出资通知`、`准备股权价值或非货币出资鉴定`、`测算出资差额利息与抽逃金额`。禁止此致某鉴定机构为唯一路径。不预测鉴定。不代提交。

若 if 用户催促「没评估就是低价／合同签了就算实缴／报告在就是公允／劳务也能入股／价额不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：已有专利出资认缴记载与评估报告碎片。用户主张没另做鉴定就是当然低价、许可合同一签就算实缴、评估报告就是已公允、劳务也能抵出资、价额不清楚先写零。非货币闸打开或半开。`Q-低`、`Q-签`、`Q-公`、`Q-劳`、`Q-零` 不打开为可靠路径。第 6 节不得把当然低价、已实缴、已公允、劳务合法、0 写入可执行 `FB#`；对应格 `现有依据不支持` 或字段停止；仍出可出资性待核、权属负担、转移手续缺口、比较基准 `G#`、第五十条接口等其他 `FB#`。不关窗。不预测鉴定。不出催缴书。若同时要求伪造评估或倒签过户 → 改走场景②。

场景②：用户同时交出公司与出资股东相互冲突的秘密口径，要求选对己方有利的一版，并指导把评估报告日期倒签、过户日改成成立日前、负担先别写。命中双方秘密＋伪造评估＋倒签过户＋隐匿负担。第一次整体停止。只交第 1、10 节。不出 `FB#`。不得问代表哪一方后继续。不以「坚持」为门槛。
