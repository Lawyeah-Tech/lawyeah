# 边界与路由

## 正触发

实物、知识产权、土地使用权、股权、债权等非货币财产出资的真实性、权属转移或显著低价需要判断，而不是直接出鉴定意见或催缴书。从零、碎片、评估未核验、无书面评估授权仍正触发：有标的碎片则闸开或半开，出 `FB#` 草案，保持草案。本次不预测鉴定、不写已虚假出资是交付禁令，不是开窗条件。未评估即当然低价、合同一签即已实缴、评估报告即已公允，仍正触发。

双方秘密、伪造评估报告、伪造权属证书、倒签过户日、隐匿担保负担、抢夺印章证照、违法取证的停止，优先于负触发。上述信号不在下表。「未评估即当然显著低价」「合同一签即已实缴」「评估报告即已公允」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 货币未缴或抽逃定性 | `评估出资瑕疵催缴与加速到期` |
| 鉴定事项和检材 | `准备股权价值或非货币出资鉴定` |
| 催缴书或失权通知 | `准备催缴出资通知` 或 `评估失权与股权丧失` |
| 出资差额精算终稿 | `测算出资差额利息与抽逃金额` |
| 知识产权权属争议整案 | 知识产权领域 |
| 合伙或个人独资 | 非公司主体 |

不得因「不预测鉴定」或「不写已虚假出资」关窗。拟评非货币仍正触发，不得写成已实缴或已公允。尚未确认标的但主成果仍是非货币评估：正触发关闸，第 7 节开鉴定接口。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |
| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「非货币」「作价」「评估」一词不是转出。

## 必转介接口

| 信号 | 转介 |
| --- | --- |

| 只要鉴定事项和检材 | `准备股权价值或非货币出资鉴定` |
| 只要差额精算 | `测算出资差额利息与抽逃金额` |
| 知识产权权属成讼 | 知识产权领域 |

## 易混

本窗闸名只能是非货币闸，禁止复用瑕疵闸、催缴闸、测算闸、鉴定闸。未评估不是当然显著低价。合同一签不是已实缴。未办理财产权转移不是已实缴。评估报告不是已公允。口头作价不是已评估。劳务不是当然能出资。设定担保的财产不是当然无效。第 50 条设立时其他股东连带不是已连带成立。第 252 条虚假出资罚款不是已构成犯罪。本窗 `FB#` 不是瑕疵窗 `XC#`，不是催缴窗 `CJ#`，不是测算窗 `DJ#`。「评估日期先倒签」「过户日改成成立日前」「负担先别写」整体停止。本窗不执行发送，不代提交。不预测鉴定。伤残等级与本窗无关。
