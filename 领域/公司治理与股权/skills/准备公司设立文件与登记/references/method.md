# 设立文件方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、论坛、期限、金额或文书状态的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然无效、必然失权、必然解散或唯一必得总额。

`search_law` 返回已失效《合同法》、1993／2004／2013／2018《公司法》或仍引用旧第二十二条、第三十三条、第七十一条且未核验对应关系的司法解释时，记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

---

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 以股权或资产收购、投资交割、尽调闭环为主要目标 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果、员工激励的劳动身份 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂、综合合规体系 | 企业合规领域 |
| 破产申请、重整计划、破产债权申报与分配 | 破产领域 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 合伙企业、个人独资的入伙退伙 | 非公司主体，不在本领域 |
| 上市公司发行、持续信息披露或证券监管主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

混合信号：公司组织或股东关系主轴可留本任务；专项只作为背景时在缺口标明，不把专项规则硬套进本领域结论。

## Q# 矩阵

固定列：`编号｜关系假设｜提出方｜相对方｜法律效果｜成立条件｜支持事实｜不利事实｜控制方｜最强反方｜主备位｜判断｜待核`。

分列章程签署、出资缴付、机关产生、登记申请。禁止把“材料已齐”写成公司已经成立。


## 节点 1　设立闸

1. 公司类型未选定：负触发，转 `选择公司类型与机关结构`。
2. 主目标是外商投资准入许可、负面清单审批或安全审查：转涉外，本任务只列公司设立接口。
3. 主目标是一般交易合同：目标停止，本窗搁置。
4. 用户要求在登记前对外以公司名义缔约并倒签成立日：整体停止。

---

## 节点 2　股东、发起人与出资

1. 有限公司：列股东姓名或名称、认缴出资额、出资方式、出资日期。成立日后认缴期限须核验第四十七条。
2. 非货币出资：须可估价并可依法转让；权属转移手续未设计则出资条款字段停止。评估缺失不写成“作价已公允”。
3. 股份公司发起人实缴规则与有限认缴分表。不得用“先登记后实缴”去套发起人成立前缴款义务。
4. 一人有限公司：标财产独立和人格否认举证责任接口，详细安排转 `准备一人公司特殊安排`。

---

## 节点 3　章程与首次机关

1. 章程必载对照第四十六条或第九十五条。缺项列入缺口，不编默认经营范围或注册资本。
2. 法定代表人、董事、监事或审计委员会产生办法必须可执行。规模较小不设董事会或监事会的，核验第七十五条、第八十三条条件。
3. 首次股东会或创立大会事实不足：不得写“已选举完成”。书面一致同意须全体签名或盖章。

---

## 节点 4　登记材料

1. 清单至少覆盖：登记申请、章程、股东或发起人主体资格、法定代表人董事监事任职、住所使用、出资相关文件。具体栏目以运行时核验的登记规则为准。
2. 住所无法证明、人员身份冲突、名称预先核准过期：相应行标停止，不建议使用虚假地址。
3. 本任务不代提交，不保证核准。

---

## 节点 5　状态与转介

文件状态只用 `草案`、`待签署`、`停止`。需要修订章程正文转 `起草或修订公司章程`。需要股东会决议原子处理首次会议转相应决议技能。
