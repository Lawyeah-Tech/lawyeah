# 准备公司设立文件与登记方法

本文件是可执行判断节点。材料齐不是已成立。网交回执不是已核准。有限认缴五年不是股份发起人成立前全额缴纳。评估缺失不是作价已公允。书面一致不足不是已选举完成。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已成立、已核准、选定法院、代提交、未知写零。本任务不定罪，不保证核准，不代提交。本窗闸名只能是设立闸，禁止复用选型闸、登记闸、章程闸、变更闸、关系闸、决议闸。本窗 `XS#` 是设立行。英文 id 禁止使用，一律用中文技能名 `准备公司设立文件与登记`。主路径只用 `Q-设`，禁止 `Q-选` 作主路径。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 2018 年第七条当成立日、第十三条董事长或执行董事、第二十六条无限认缴、第五十一条执行董事、1993 年第四十七条董事任期当五年缴足时记为噪声。禁止指导倒签设立、虚构实缴或虚假住所。伤残等级与本窗无关。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现设立碎片扫描，不是默认闭集。
`XS#` 固定列：`编号｜拟设切片｜类型已选｜股东或发起人与出资｜章程必载缺口｜机关产生｜登记核验｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。无 `E#` 不得写已成立、已核准、已提交或已选举。`E#` 只作证据形态回链，不是发送闸。扫描不是闭集。缺项记 `G#`。承认只进 `S#`／`D#`，不得占用 `A#`。文件状态只用 `草案`、`待签署`、`停止`。

口头「材料齐了就算成立」「网交了就算核准」「已经选好了」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：营业执照签发日期为公司成立日期。申请人对材料真实性负责。住所须合法使用证明。名称申报过期不是仍有效。不保证核准。不代提交。

## 节点 0　分流、立场、设立闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、倒签设立会议或创立大会、虚构实缴、虚假住所方法、伪造决议、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `XS#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是类型与机关比较草案 | 负触发 `选择公司类型与机关结构` |
| 主成果是可签署章程或修正案终稿 | 负触发 `起草或修订公司章程` |
| 主成果是一人财产独立或书面决定专项 | 负触发 `准备一人公司特殊安排` |
| 主成果是已决定有限⇄股份形式变更 | 负触发 `准备有限公司与股份公司形式变更` |
| 主成果是非货币真实性或作价终稿 | 负触发 `评估非货币出资真实性与作价` |
| 主成果是外资准入许可 | 整案转涉外 |
| 主成果是一般交易合同 | 整案转审查起草 |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不代提交」「不保证核准」「不写已成立」 | 交付禁令，不是负触发 |

出现「设立」「登记」「章程」一词不是转出。材料齐即已成立不是负触发，该格不支持。类型未选但主成果仍是设立包：正触发，设立闸关闭，第 7 节开选型接口，不得改走负触发。

设立闸打开（可出 `XS#` 草案，仍不得标「已成立／已核准／已提交」）须同时满足：单方无冲突立场已闭合；主成果是设立文件与登记核验，不是选型比较、不是章程终稿独占、不是一人专项终稿；至少一项可编号已选定类型碎片。口头「材料齐了」不算单独开闸材料。有类型已选但出资、住所未闭合：部分打开。

设立闸部分打开：已有类型已选碎片，但出资、机关、住所或名称未闭合；对应格待核；仍交十节。无书面设立授权但立场已闭合且有类型已选碎片：部分打开，不是整体停止。

设立闸关闭（仍正触发）：无一可编号类型已选碎片。「今天必须出已成立／已核准终稿」而无最小碎片不得开闸。不出 `XS#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `XS#` 终稿，**第 7 节不得出已提交或已核准**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「材料齐即已成立」「网交即已核准」「先登记后实缴套发起人」「五年套发起人」「虚假住所可用」「预核过期仍保证核准」「必载缺失用默认冒充已载明」「书面一致不足仍已选举」「未知写零」「保证核准」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `XS#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号类型已选碎片，then 设立闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立拟股东相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出倒签设立会议或创立大会、虚构实缴、虚假住所方法、伪造决议、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个拟设切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `XS#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 类型 | 有限／股份／一人分列 | 比较表冒充已选定后出设立终稿 |
| 缴付 | 有限第四十七条与股份第九十八条分列 | 五年套发起人；先登记后实缴套发起人 |
| 必载 | 有限第四十六条／股份第九十五条分列 | 缺项补造默认已载明 |
| 机关 | 第十条、第七十五条／第八十三条、第一百二十八条／第一百三十三条分列 | 有限例外整包套股份 |
| 登记 | 第二十九条至第三十三条；成立日＝执照签发日 | 材料齐＝已成立；网交＝已核准 |

检索锚点（写入 `L#` 前须核验）：

- 第二十九条至第三十三条：申请、材料真实、符合条件才登记、登记事项、执照签发日为成立日。
- 第四十七条／第九十八条：有限五年认缴与发起人成立前全额缴纳。
- 第四十八条：非货币可估价可转让，应当评估作价。
- 第四十六条／第九十五条：章程必载两套清单。
- 第十条：法定代表人由执行事务的董事或经理担任。
- 第五十九条第三款：书面一致须全体签名或盖章。第六十条是一人书面决定，不得冒充多股东书面一致。
- 第四十四条：设立时民事活动；倒签成立日整体停止。
- 噪声：2018 年第七条、第十三条、第二十六条、第五十一条。

不得暗示「材料齐了就算公司已经成立」。

## 节点 3　设立行 `XS#`

按已出现拟设切片扫描，不是默认闭集。每条须能指向类型已选、出资分列和登记核验。

无 `E#` 不得写已成立、已核准、已提交或已选举。状态默认 `草案`。一次只推荐下一步。未知资本不写零。第四十七条／第九十八条、第四十六条／第九十五条必须分列。住所无法证明该行停止，不建议虚假地址。名称申报过期该格不支持。

热冲突强制处理：

- 材料齐即已成立／网交即已核准／五年套发起人／虚假住所可用／保证核准／未知写零／书面不足仍已选举 → 该格不支持或字段停止；仍出其他 `XS#`。
- 无一类型已选碎片 → 关闸，不出 `XS#` 终稿，窗口不关。
- 指导倒签设立、虚构实缴、虚假住所方法、抢夺印章 → 整体停止，不是该格不支持。

必载缺项记 `G#`，禁止补造默认条款。法定代表人人选未定不编造。外商投资准入只开涉外接口。

## 节点 4　选型、章程、形式变更与一人接口

第 7 节只开接口，不得夹带 `XS#` 终稿、已签署章程或已核准申请绕闸。闸关闭时第 7 节可写「闸未开，转介待类型已选编号」，不得补写已成立。五年／实缴、名称保留、成立大会三十日分列，禁止合成一个截止日。

下一步只转介：`选择公司类型与机关结构`、`起草或修订公司章程`、`准备一人公司特殊安排`、`准备有限公司与股份公司形式变更`、`评估非货币出资真实性与作价`、`准备股东会决议与召集`、`准备书面一致同意决定`、`准备董事高管任免与登记`。禁止此致某登记机关为唯一路径。不代提交。不保证核准。

若 if 用户催促「材料齐了就算成立／网交就算核准／资本先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）
