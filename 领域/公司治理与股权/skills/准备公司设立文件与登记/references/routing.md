# 边界与路由

## 正触发

类型已选定或用户咬住设立包，需要章程签署核验、出资安排、机关产生和登记材料清单，尚未代提交。从零、碎片、出资未核验、无书面设立授权仍正触发：有已选定类型碎片则闸开或半开，出 `XS#` 草案，保持草案。本次不代提交、不保证核准、不写已成立是交付禁令，不是开窗条件。材料齐即已成立、网交即已核准、五年套发起人，仍正触发。

双方秘密、倒签设立会议、虚构实缴、虚假住所方法、抢夺印章证照、违法取证的停止，优先于负触发。上述信号不在下表。「材料齐即已成立」「网交即已核准」「五年套发起人」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 类型与机关比较草案 | `选择公司类型与机关结构` |
| 只要可签署章程或修正案 | `起草或修订公司章程` |
| 一人公司财产独立或书面决定专项 | `准备一人公司特殊安排` |
| 已决定有限改股份或相反 | `准备有限公司与股份公司形式变更` |
| 非货币出资真实性或作价终稿 | `评估非货币出资真实性与作价` |
| 外资准入许可、负面清单或安全审查 | 涉外领域 |
| 一般交易合同 | 审查起草领域（本窗搁置） |
| 合伙或个人独资 | 非公司主体 |

不得因「不代提交」或「不写已成立」关窗。拟设立核验仍正触发，不得写成已成立或已核准。类型未选但主成果仍是设立包：正触发关闸，第 7 节开选型接口。
