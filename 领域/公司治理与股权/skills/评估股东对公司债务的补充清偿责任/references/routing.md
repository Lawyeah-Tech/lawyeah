# 边界与路由

## 正触发

债权人主张股东在未出资、抽逃或未届期加速下，对公司不能清偿部分负责，需要类型化评估。从零、碎片、不能清偿未闭合、无书面评估授权仍正触发：有公司债或认缴／抽逃碎片则闸开或半开，出 `BC#` 草案，保持草案。本次不出诉状、不写已补充清偿是交付禁令，不是开窗条件。不能清偿即已补充清偿成立、未届期即当然补全部公司债、征求意见稿当现行，仍正触发。

双方秘密、伪造出资凭证、倒签缴款日、伪造不能清偿证明、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「不能清偿即已补充清偿成立」「未届期即当然补全部公司债」「征求意见稿当现行」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 出资瑕疵路径或催缴书 | `评估出资瑕疵催缴与加速到期` 或 `准备催缴出资通知` |
| 失权评估或失权通知 | `评估失权与股权丧失` |
| 出资差额精算终稿 | `测算出资差额利息与抽逃金额` |
| 人格否认专项终局 | `评估法人人格否认` |
| 减资通知终稿 | `准备减资通知与债权人保护` |
| 诉状、答辩或执行追加申请终稿 | `提起股东权利诉讼` 或 `应对股东权利诉讼` |
| 破产债权申报整案 | 破产领域 |
| C 端股东责任只要大众清单 | 大众专项，只分流 |
| 合伙或个人独资 | 非公司主体 |

不得因「不出诉状」或「不写已补充清偿」关窗。拟评补充清偿条件仍正触发，不得写成已补充清偿。公司主成果是内部催缴或加速路径：负触发转瑕疵窗。人格否认一词出现但主成果仍是补充清偿评估：正触发，第 7 节开否认接口。

| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |

| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |

| 上市公司发行、持续信息披露主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「补充清偿」「加速」「抽逃」一词不是转出。

## 易混

本窗闸名只能是清偿闸，禁止复用瑕疵闸、催缴闸、失权闸、测算闸、否认闸、责任闸、补充闸。主路径只用 `Q-责`，禁止占用减资窗 `Q-清`。不能清偿不是已补充清偿成立。未届期不是当然补全部公司债。未届期股东在金钱债权执行中不是当然可追加。公司住所地或执行法院不是唯一管辖已定。认缴登记不是已实缴。大额转出不是当然抽逃。第 54 条提前缴纳不是已对债权人补充清偿。解释三第十三条不是已被征求意见稿废止。征求意见稿不是现行。第 88 条第 1 款不是当然溯及 2024 年 7 月 1 日前转让。人格否认连带不是本窗补充清偿。一人财产混同连带不是本窗补充清偿。第 50 条、第 88 条第 2 款连带只开接口。第 226 条违法减资不是本窗减资终稿。本窗 `BC#` 不是瑕疵窗 `XC#`，不是催缴窗 `CJ#`，不是失权窗 `SQ#`，不是测算窗 `DJ#`。「缴款日先倒签」「不能清偿证明今晚补一份」整体停止。本窗不执行发送，不代提交。不出诉状。不出执行追加终稿。不写已补充清偿。伤残等级与本窗无关。
