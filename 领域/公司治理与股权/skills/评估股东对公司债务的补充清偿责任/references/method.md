# 评估股东对公司债务的补充清偿责任方法

本文件是可执行判断节点。不能清偿不是已补充清偿成立。未届期不是当然补全部公司债。认缴登记不是已实缴。大额转出不是当然抽逃。第 54 条提前缴纳不是已对债权人补充清偿。征求意见稿不是现行。第 88 条第 1 款不是当然溯及。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然追到、已补充清偿、选定法院、代提交、未知写零、唯一截止日、唯一必得总额。本任务不定罪，不出诉状终稿，不出执行追加申请终稿，不写催缴书或失权通知。本窗闸名只能是清偿闸，禁止复用瑕疵闸、催缴闸、失权闸、测算闸、否认闸、责任闸、补充闸。本窗 `BC#` 是清偿行。英文 id 禁止使用，一律用中文技能名 `评估股东对公司债务的补充清偿责任`。主路径只用 `Q-责`，禁止 `Q-瑕`、`Q-催`、`Q-失`、`Q-否`、`Q-测`、`Q-诉`、`Q-清`、`Q-追` 作主路径。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回征求意见稿当现行、2018 条号当现行、法释〔2024〕7 号第四条当第八十八条第一款当然溯及、把不能清偿写成已补充清偿时记为噪声。禁止指导伪造出资凭证、倒签缴款日或伪造不能清偿证明。伤残等级与本窗无关。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现公司债或认缴／抽逃碎片扫描，不是默认闭集。
`BC#` 固定列：`编号｜清偿切片｜债务基础｜不能清偿｜责任类型｜范围上限｜主体分列｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。无 `E#` 不得写已补充清偿、不能清偿已坐实或已抽逃。`E#` 只作证据形态回链，不是发送闸。扫描不是闭集。缺项记 `G#`。承认只进 `S#`／`D#`，不得占用 `A#`。

口头「股东要还全部债」「认缴这么大肯定能追」「转出去了就是抽逃」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。本窗不打开待发送。

实务上：公司债务须先固定债权人、金额、到期与争议；公司债依据不足则股东责任字段停止。不能清偿是打开第 54 条提前缴纳或解释三补充赔偿的条件碎片，不是已补充清偿成立。已届期未出资的债权人请求与未届期第 54 条提前缴纳分列，不得合成「股东现在就要还全部公司债」。抽逃须审查对价与资金流向。第 88 条第 1 款补充责任与第 88 条第 2 款连带分列；第 88 条第 1 款仅适用于 2024 年 7 月 1 日之后发生的未届期转让。人格否认连带转否认窗，本窗不写否认成立。

## 节点 0　分流、立场、清偿闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造出资凭证、倒签缴款日、伪造不能清偿证明、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `BC#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是出资瑕疵路径或催缴书 | 负触发 `评估出资瑕疵催缴与加速到期` 或 `准备催缴出资通知` |
| 主成果是失权评估或失权通知 | 负触发 `评估失权与股权丧失` |
| 主成果是出资差额精算终稿 | 负触发 `测算出资差额利息与抽逃金额` |
| 主成果是人格否认专项终局 | 负触发 `评估法人人格否认` |
| 主成果是减资通知终稿 | 负触发 `准备减资通知与债权人保护` |
| 主成果是诉状、答辩或执行追加申请终稿 | 负触发 `提起股东权利诉讼` 或 `应对股东权利诉讼` |
| 破产申请、重整、破产债权申报 | 整案转出，破产领域 |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不出诉状」「不写已补充清偿」 | 交付禁令，不是负触发 |

出现「补充清偿」「加速」「抽逃」一词不是转出。不能清偿即已补充清偿不是负触发，该格不支持。公司债尚未生效但主成果仍是补充清偿评估：正触发半开或关闸，第 7 节开债务基础缺口。

清偿闸打开（可出 `BC#` 草案，仍不得标「已补充清偿／不能清偿已坐实／已抽逃／人格否认成立」）须同时满足：单方无冲突立场已闭合；主成果是补充清偿评估草案，不是催缴书、不是诉状、不是否认终局、不是精算终稿；至少一项可编号公司债碎片或认缴／抽逃碎片。口头「股东要还全部债」不算单独开闸材料。

清偿闸部分打开：已有碎片，但不能清偿、认缴实缴或转让时点未闭合；对应格待核；仍交十节。无书面评估授权但立场已闭合且有碎片：部分打开，不是整体停止。不能清偿未闭合：部分打开，不得写已补充清偿成立。

清偿闸关闭（仍正触发）：无一可编号公司债或认缴／抽逃碎片。「今天必须出已补充清偿终稿」而无最小碎片不得开闸。不出 `BC#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `BC#` 终稿，**第 7 节不得出已补充清偿、诉状或执行追加终稿**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「不能清偿即已补充清偿成立」「未届期即当然补全部公司债」「未届期即执行中当然可追加」「认缴登记即已实缴」「大额转出即抽逃」「第 54 条即已对债权人补充清偿」「征求意见稿当现行」「第 88 条第 1 款当然溯及」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `BC#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号公司债或认缴／抽逃碎片，then 清偿闸关闭，仍交十节，不是整体停止。
若 if 同时掌握债权人与被追责股东相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造出资凭证、倒签缴款日、伪造不能清偿证明、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个清偿切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `BC#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 债务基础 | 债权人、金额、到期、争议 | 公司债未立仍写股东已补充清偿 |
| 不能清偿 | 到期未获清偿的碎片与缺口 | 不能清偿写成已补充清偿成立；生效判决未执行到位写成唯一证明或可不证 |
| 已届期未出资 | 章程出资日期已届、实缴缺口 | 未届期套已届期补充 |
| 未届期加速 | 第 54 条不能清偿＋提前缴纳 | 提前缴纳写成已对债权人补充清偿；无不能清偿打开加速 |
| 抽逃 | 对价、流向、法定程序 | 大额转出即抽逃 |
| 转让 | 转让日、第 88 条第 1／2 款分列 | 第 88 条第 1 款溯及 2024-07-01 前转让 |
| 连带接口 | 第 50 条、第 88 条第 2 款、第 23 条 | 本窗写成连带已成立或人格否认已成立 |

检索锚点（写入 `L#` 前须核验）：

- 第四十九条：按期足额缴纳；未按期向公司足额缴纳并赔偿公司损失。对债权人请求不是本条自动等于已补充清偿。
- 第五十条：有限设立时其他股东在出资不足范围内连带，只开接口。
- 第五十三条：不得抽逃；返还＋负有责任董监高连带赔偿。大额转出不是当然抽逃。
- 第五十四条：不能清偿到期债务时，公司或已到期债权人可要求未届期股东提前缴纳。提前缴纳不是已对债权人补充清偿。九民纪要四种例外不是第五十四条唯一路径。
- 第八十八条第一款：未届期转让由受让人缴纳；受让人未按期则转让人补充责任。2024-12-24 批复：仅适用于 2024-07-01 之后发生的未届期转让。
- 第八十八条第二款：未按期或非货币显著低价转让，转让人与受让人出资不足范围内连带；受让人不知且不应知则转让人担责。只开接口。
- 第二百二十六条：违法减资只开接口，不写责任总额。
- 解释三第十三条第二款：未出资本息范围内对不能清偿部分补充赔偿。是否仍与 2023 文本对应须核验，不得写成已被征求意见稿废止。
- 噪声：征求意见稿第二十一条当现行；法释〔2024〕7 号第四条当第八十八条第一款当然溯及；2018 条号当现行。

不得暗示「认缴登记股东就要还全部公司债」。第 54 条「有权要求提前缴纳」不是已对债权人补充清偿成立。

## 节点 3　清偿行 `BC#`

按已出现公司债或认缴／抽逃碎片扫描，不是默认闭集。债权人侧与被追责股东侧分列立场，不得选边。

无 `E#` 不得写已补充清偿、不能清偿已坐实或已抽逃。状态默认 `草案`。一次只推荐下一步。未知不写零。不能清偿未闭合：该格不支持已补充清偿成立，仍出不能清偿缺口。已届期未出资补充与未届期第 54 条提前缴纳分列。抽逃与违法分配、关联交易分列。转让日与 2024-07-01 分列。范围上限以未出资本息或抽逃本息为情景上限，不得写成对公司全部债务无限连带，除非人格否认另案支持且本窗只开接口。已向公司或债权人承担的部分不得重复。利息精算转测算窗。金额不明建并行情景，不给唯一必得总额。公司侧或债权人侧可出条件清单，状态保持草案，不打开待发送，不出执行追加终稿。

热冲突强制处理：

- 不能清偿即已补充清偿／未届期即当然补全部债／未届期即执行中当然可追加／认缴即已实缴／大额转出即抽逃／第 54 条即已对债权人补充清偿／征求意见稿当现行／第 88 条第 1 款当然溯及／估数或写零 → 该格不支持或字段停止；仍出其他 `BC#`。
- 无一公司债或认缴／抽逃碎片 → 关闸，不出 `BC#` 终稿，窗口不关。
- 指导伪造出资凭证、倒签缴款日、伪造不能清偿证明 → 整体停止，不是该格不支持。

## 节点 4　瑕疵、失权、精算、否认与诉讼接口

第 7 节只开接口，不得夹带 `BC#` 终稿、已补充清偿、诉状或执行追加终稿绕闸。闸关闭时第 7 节可写「闸未开，转介待公司债或认缴编号」，不得补写已补充清偿。内部催缴或加速路径只开瑕疵窗接口。失权只开失权窗接口。精算只开测算窗接口。人格否认只开否认窗接口。破产已受理整案转出。

下一步只转介：`评估出资瑕疵催缴与加速到期`、`准备催缴出资通知`、`评估失权与股权丧失`、`测算出资差额利息与抽逃金额`、`评估法人人格否认`、`准备减资通知与债权人保护`、`提起股东权利诉讼`、`应对股东权利诉讼`。禁止此致某法院为唯一路径。不代提交。不执行发送。不出诉状或执行追加终稿。

若 if 用户催促「不能清偿就算股东已经要还／未届期也要还全部债／认缴登记就是已实缴／转出去就是抽逃／第 54 条已经是补充清偿／征求意见稿已经替代解释三／2018 年转让也按第 88 条第 1 款／金额不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 再执行清单

每个节点结束后回写：来源、判断、最强反方、是否字段停止。不得跳过清偿闸直接给已补充清偿。

若 if 公司债金额、到期、不能清偿、认缴实缴、转让时点、施行日未核验，then 该强制项字段停止，窗口不关。
