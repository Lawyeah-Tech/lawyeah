# 股东责任评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、论坛、期限、金额或文书状态的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然无效、必然失权、必然解散或唯一必得总额。

`search_law` 返回已失效《合同法》、1993／2004／2013／2018《公司法》或仍引用旧第二十二条、第三十三条、第七十一条且未核验对应关系的司法解释时，记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 以股权或资产收购、投资交割、尽调闭环为主要目标 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果、员工激励的劳动身份 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂、综合合规体系 | 企业合规领域 |
| 破产申请、重整计划、破产债权申报与分配 | 破产领域 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 合伙企业、个人独资的入伙退伙 | 非公司主体，不在本领域 |
| 上市公司发行、持续信息披露或证券监管主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

混合信号：公司组织或股东关系主轴可留本任务；专项只作为背景时在缺口标明，不把专项规则硬套进本领域结论。

## Q# 矩阵

固定列：`编号｜关系假设｜提出方｜相对方｜法律效果｜成立条件｜支持事实｜不利事实｜控制方｜最强反方｜主备位｜判断｜待核`。

分列未出资本息补充责任、抽逃返还、加速到期、违法减资、人格否认连带。禁止合成一笔“股东要还公司全部债”。


## 节点 1　基础债务

1. 先固定公司对外债务的债权人、金额、到期和争议。公司债务依据不足：股东责任整体无法形成结论。
2. 破产程序已受理：转破产领域申报与分配，本任务只交最小接口。

---

## 节点 2　类型

1. 未履行或未全面履行出资义务：在未出资本息范围内对公司不能清偿的部分承担补充赔偿责任。是否仍支持及条号，须核验解释（三）与 2023 文本对应关系。
2. 抽逃出资：抽逃本息范围内补充责任，须核验第五十三条及解释情形，不得单凭大额转出认定。
3. 加速到期：公司不能清偿到期债务时，公司或已到期债权人可要求未届期股东提前缴纳，须核验第五十四条。无不能清偿事实不得打开。
4. 违法减资：第二百二十六条接口，不与未出资重复计同一笔。
5. 人格否认连带：转 `评估法人人格否认`，本任务只分账不写否认成立。

---

## 节点 3　范围

1. 补充责任以未出资本息或抽逃本息为上限情景，不得写成对公司全部债务无限连带，除非人格否认另案支持。
2. 股东已向公司或债权人承担的部分不得重复。金额未知不写零。
3. 利息计算转 `测算出资差额利息与抽逃金额`，本任务只列接口。

---

## 节点 4　主体

1. 瑕疵股权转让：第八十八条及法释〔2024〕7 号，转让人／受让人分列，核验失败字段停止。
2. 设立时其他股东对非货币显著低价连带：第五十条。
3. 一人公司财产混同：举证责任在股东，详见第二十三条，不在此展开否认全部要件。

---

## 节点 5　C 端与诉讼

C 端股东责任评估只分流不回改。用户要起诉或应诉转相应诉讼原子。不输出胜诉率。
