# 准备催缴出资通知方法

本文件是可执行判断节点。催缴书草稿不是已发出。催缴书不是已失权。已读不是已送达。宽限期少于六十日不是可执行。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已失权、已发出、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不写失权通知终稿。本窗闸名只能是催缴闸，禁止复用瑕疵闸、失权闸、关系闸、决议闸、发送闸。本窗 `CJ#` 是催缴行。英文 id 禁止使用，一律用中文技能名 `准备催缴出资通知`。主路径只用 `Q-催`，禁止 `Q-评`、`Q-失` 作主路径。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 2018 年无催缴失权专条当现行、解释三第十七条当 2024 年后唯一失权路径、把催缴书写成已失权时记为噪声。禁止指导倒签催缴发出日或伪造董事会决议。伤残等级与本窗无关。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现未缴碎片扫描，不是默认闭集。
`CJ#` 固定列：`编号｜催缴切片｜权源｜股东与差额｜宽限期接口｜后果提示｜送达接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。无 `E#` 不得写已发出、已送达或已失权。`E#` 只作证据形态回链，不是发送闸。扫描不是闭集。缺项记 `G#`。承认只进 `S#`／`D#`，不得占用 `A#`。文件状态只用 `草案`、`待发送`、`停止`。权源或差额未闭合不得标 `待发送`。

口头「该缴了」「今天发函就算失权」「微信已读就算送到」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：宽限期自公司发出催缴书之日起不得少于六十日。发出之日与到达之日并行，不编唯一到达日。催缴未闭合不得出失权通知。未届期无不能清偿事实不得走第五十一条催缴。

## 节点 0　分流、立场、催缴闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、倒签催缴发出日、伪造董事会催缴决议、冒充董事会抬头、伪造出资凭证、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `CJ#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是尚未判断催缴条件 | 负触发 `评估出资瑕疵催缴与加速到期` |
| 主成果是失权评估或失权通知终稿 | 负触发 `评估失权与股权丧失` |
| 主成果是出资差额精算 | 负触发 `测算出资差额利息与抽逃金额` |
| 主成果是送达设计独占 | 负触发 `设计催缴召集优先购买通知送达` |
| 主成果是董事会决议包独占 | 负触发 `准备董事会或执行董事决定` |
| 主成果是债权人加速到期起诉状 | 负触发评估窗加速路径或诉讼原子 |
| 主成果是投并购交割 | 整案转投并购 |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不执行发送」「不写已失权」 | 交付禁令，不是负触发 |

出现「催缴」「失权」「六十日」一词不是转出。催缴书即已失权不是负触发，该格不支持。尚未判断催缴条件但主成果仍是催缴书：正触发关闸，第 7 节开评估接口。

催缴闸打开（可出 `CJ#` 草案，仍不得标「已发出／已送达／已失权」）须同时满足：单方无冲突立场已闭合；主成果是发送前催缴书草案，不是瑕疵评估独占、不是失权通知、不是精算终稿；至少一项可编号未按期缴纳股东碎片。口头「该缴了」不算单独开闸材料。

催缴闸部分打开：已有未缴碎片，但权源、差额或宽限期未闭合；对应格待核；仍交十节。无书面催缴授权但立场已闭合且有未缴碎片：部分打开，不是整体停止。

催缴闸关闭（仍正触发）：无一可编号未缴碎片。「今天必须出已发出／已失权终稿」而无最小碎片不得开闸。不出 `CJ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `CJ#` 终稿，**第 7 节不得出失权通知或已发出证明**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「催缴书即已失权」「已读即送达」「宽限期少于六十日」「未届期当然催缴」「发出即失权」「监事会或经理名义即董事会催缴」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `CJ#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 被催缴股东委托起草公司催缴书，then 整体停止。
若 if 单方立场已闭合但无一可编号未缴碎片，then 催缴闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被催缴股东相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出倒签催缴发出日、伪造董事会催缴决议、冒充董事会抬头、伪造出资凭证、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个催缴切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `CJ#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 权源 | 董事会核查；或第 75 条一名董事 | 监事会／经理冒充董事会；未核验规模写成已符合 |
| 股东与差额 | 认缴、实缴、差额、章程出资日期 | 未知写零；未届期当已到期 |
| 宽限期 | 自发出之日起不少于六十日 | 写成三十日或章程短于六十日可执行 |
| 后果 | 可依法失权的提示 | 写成已经失权；解释三除名当唯一路径 |
| 送达 | 章程地址与备份渠道接口 | 已读即送达；编唯一到达日 |

检索锚点（写入 `L#` 前须核验）：

- 第四十九条：按期足额缴纳；未按期还应当赔偿损失，只开接口。
- 第五十一条：董事会核查后由公司发书面催缴；董事未及时催缴致损负赔偿责任，只开接口。
- 第五十二条：宽限期自发出之日起不得少于六十日；届满仍未履行经董事会决议可发失权通知。本窗不出失权终稿。
- 第五十四条：不能清偿到期债务才可要求未届期股东提前缴纳。不得与第五十一条合成一封函。
- 第七十五条：一名董事行使董事会职权，规模较小或人数较少须核验。
- 第一百零七条：第五十一条、第五十二条适用于股份有限公司。
- 噪声：解释三第十七条当 2024 年后唯一失权路径。

不得暗示「催缴书一发股权就没了」。

## 节点 3　催缴行 `CJ#`

按已出现未缴股东扫描，不是默认闭集。有限与股份、董事会与一名董事分列。

无 `E#` 不得写已发出、已送达或已失权。状态默认 `草案`。一次只推荐下一步。未知差额不写零。宽限期不得写成少于六十日。未届期无第五十四条事实不得出可发送催缴稿。后果只写「宽限期届满后公司可依法决议失权」，不得写已经失权。送达只开接口，已读不是发出。

热冲突强制处理：

- 催缴书即已失权／已读即送达／宽限期少于六十日／未届期当然催缴／发出即失权／监事会名义即董事会催缴／估数或写零 → 该格不支持或字段停止；仍出其他 `CJ#`。
- 无一未缴碎片 → 关闸，不出 `CJ#` 终稿，窗口不关。
- 指导倒签发出日、伪造董事会决议、冒充抬头、伪造凭证 → 整体停止，不是该格不支持。

## 节点 4　评估、失权、精算、送达与决议接口

第 7 节只开接口，不得夹带 `CJ#` 终稿、已发出证明或失权通知绕闸。闸关闭时第 7 节可写「闸未开，转介待未缴股东编号」，不得补写已发出。夹带加速只开评估窗第五十四条接口。详细送达只开送达窗接口。

下一步只转介：`评估出资瑕疵催缴与加速到期`、`评估失权与股权丧失`、`测算出资差额利息与抽逃金额`、`设计催缴召集优先购买通知送达`、`准备董事会或执行董事决定`。禁止此致某股东为唯一已发出路径。不执行发送。不代提交。

若 if 用户催促「发了就算失权／已读就算送到／宽限写成三十天／资本不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 再执行清单

每个节点结束后回写：来源、判断、最强反方、是否字段停止。不得跳过催缴闸直接给已发出或已失权。

若 if 权源、章程出资日期、宽限期、加速事由、施行日未核验，then 该强制项字段停止，窗口不关。
判断状态只许三值。口头「今天发函就算失权」不得写成 `CJ#` 已失权。未知不写零。

## 本任务回链纪律

本任务成果是「催缴闸与发送前催缴书草案」。本窗不执行发送。不包含：已发出证明、已失权、失权通知终稿、精算终稿独占。禁止选边治愈。禁止催缴书即已失权。禁止宽限期少于六十日。禁止指导倒签发出日或伪造董事会决议。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标催缴终稿已形成。
风险档 A：倒签发出日、伪造董事会决议、冒充抬头、伪造出资凭证必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：已有章程出资日期与未缴差额碎片。用户主张催缴书写完就算已经失权、微信已读就算送到、宽限期写成三十日赶时间、未届期也一起催、差额不清楚先写零。催缴闸打开或半开。`Q-权`、`Q-读`、`Q-短`、`Q-期`、`Q-零` 不打开为可靠路径。第 6 节不得把已失权、已送达、三十日宽限、未届期催缴、0 写入可执行 `CJ#`；对应格 `现有依据不支持` 或字段停止；仍出第五十一条权源待核、不少于六十日宽限期接口、差额 `G#`、失权只作后果提示等其他 `CJ#`。不关窗。不执行发送。不出失权通知。若同时要求倒签发出日或伪造董事会决议 → 改走场景②。

场景②：用户同时交出公司与被催缴股东相互冲突的秘密口径，要求选对己方有利的一版，并指导倒签催缴发出日、今晚把董事会决议先做出来。命中双方秘密＋倒签发出日＋伪造董事会决议。第一次整体停止。只交第 1、10 节。不出 `CJ#`。不得问代表哪一方后继续。不以「坚持」为门槛。
