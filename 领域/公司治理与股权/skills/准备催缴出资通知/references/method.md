# 催缴通知方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、论坛、期限、金额或文书状态的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然无效、必然失权、必然解散或唯一必得总额。

`search_law` 返回已失效《合同法》、1993／2004／2013／2018《公司法》或仍引用旧第二十二条、第三十三条、第七十一条且未核验对应关系的司法解释时，记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 以股权或资产收购、投资交割、尽调闭环为主要目标 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果、员工激励的劳动身份 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂、综合合规体系 | 企业合规领域 |
| 破产申请、重整计划、破产债权申报与分配 | 破产领域 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 合伙企业、个人独资的入伙退伙 | 非公司主体，不在本领域 |
| 上市公司发行、持续信息披露或证券监管主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

混合信号：公司组织或股东关系主轴可留本任务；专项只作为背景时在缺口标明，不把专项规则硬套进本领域结论。

## Q# 矩阵

固定列：`编号｜关系假设｜提出方｜相对方｜法律效果｜成立条件｜支持事实｜不利事实｜控制方｜最强反方｜主备位｜判断｜待核`。

催缴、宽限期、失权通知分列。禁止把本任务草稿写成失权已发生。


## 节点 1　权源

1. 公司成立后董事会应当对股东出资情况进行核查；未按期足额缴纳的，公司应当向该股东发出书面催缴书。须核验第五十一条。
2. 不设董事会而设一名董事的，由该董事行使董事会催缴职权，须核验第七十五条衔接。
3. 尚未评估是否未按期缴纳：负触发，转 `评估出资瑕疵催缴与加速到期`。
4. 用户要求以监事会或经理名义发出催缴并冒充董事会：整体停止。

---

## 节点 2　对象与金额

1. 列股东、认缴、实缴、差额、章程出资日期。金额来源必须回链；未知差额不写零。
2. 未届出资期限且无法定加速事由：不得打开催缴未履行闸。加速须核验第五十四条不能清偿到期债务。
3. 非货币不实或抽逃：催缴书不得直接写成“抽逃已认定”，应分事实描述与请求缴纳／返还。

---

## 节点 3　宽限期

1. 催缴书可以载明缴纳宽限期；宽限期自公司发出催缴书之日起，不得少于六十日。须核验第五十二条衔接。
2. 章程规定短于六十日：该条款不得执行，通知仍按不少于六十日起草。
3. 宽限期起算用“发出之日”情景，与“收到之日”并行标注，不编唯一到达日。

---

## 节点 4　草稿与送达

1. 催缴书至少写明：公司、股东、未缴出资、依据、宽限期届满日计算接口、后果提示（可依法失权，但不得写成已经失权）。
2. 送达按章程地址和备份渠道设计，转介 `设计催缴召集优先购买通知送达` 可承接详细送达。本任务不执行发送。
3. 状态只用 `草案`、`待发送`、`停止`。

---

## 节点 5　失权分闸

宽限期未设计或用户要求“发出即失权”：目标停止。失权评估与通知转 `评估失权与股权丧失`。解释（三）股东会除名不得写入本催缴书作为 2024-07-01 后的唯一路径。
