# 边界与路由

## 正触发

需要对未按期缴纳股东发出书面催缴，需要发送前催缴书和不少于六十日宽限期，而不是失权通知终稿、瑕疵路径评估独占或精算终稿。从零、碎片、权源未核验、无书面催缴授权仍正触发：有未缴碎片则闸开或半开，出 `CJ#` 草案，保持草案。本次不执行发送、不写已失权是交付禁令，不是开窗条件。催缴书即已失权、已读即送达、宽限期少于六十日，仍正触发。

双方秘密、倒签催缴发出日、伪造董事会催缴决议、冒充董事会抬头、伪造出资凭证、抢夺印章证照、违法取证的停止，优先于负触发。上述信号不在下表。「催缴书即已失权」「已读即送达」「宽限期少于六十日」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 尚未判断催缴条件 | `评估出资瑕疵催缴与加速到期` |
| 失权评估或失权通知终稿 | `评估失权与股权丧失` |
| 出资差额精算终稿 | `测算出资差额利息与抽逃金额` |
| 送达设计独占 | `设计催缴召集优先购买通知送达` |
| 董事会决议包独占 | `准备董事会或执行董事决定` |
| 债权人加速到期起诉状 | 评估窗加速路径或诉讼原子 |
| 合伙或个人独资 | 非公司主体 |

不得因「不执行发送」或「不写已失权」关窗。拟发催缴书仍正触发，不得写成已发出或已失权。尚未判断催缴条件但主成果仍是催缴书：正触发关闸，第 7 节开评估接口。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |
| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「催缴」「失权」「六十日」一词不是转出。

## 易混

本窗闸名只能是催缴闸，禁止复用瑕疵闸、失权闸、关系闸、发送闸。催缴书草稿不是已发出。催缴书不是已失权。已读不是已送达。宽限期少于六十日不是可执行。章程短于六十日不是可执行。未届期不是当然催缴。发出不是已失权。监事会或经理名义不是董事会催缴。解释三第十七条不是 2024 年后唯一失权路径。第五十四条加速不是第五十一条催缴。本窗 `CJ#` 不是评估窗 `XC#`，不是失权窗终稿。「发出日先倒签」「董事会决议今晚补一份」整体停止。本窗不执行发送，不代提交。不写已失权。伤残等级与本窗无关。
