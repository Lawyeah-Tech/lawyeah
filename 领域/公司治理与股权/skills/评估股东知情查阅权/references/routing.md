# 边界与路由

## 正触发

拟查阅或公司拟拒绝，需要判断范围与不正当目的。从零、碎片、书面未核验、无书面评估授权仍正触发：有可编号资格或查阅请求碎片则闸开或半开，出 `CK#` 草案，保持草案。本次不写诉状、不写已获准是交付禁令，不是开窗条件。未书面即违法拒绝、账簿凭证当然可复制、曾起诉即不正当目的，仍正触发。

双方秘密、伪造查阅请求、倒签送达、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「未书面即违法拒绝」「十五日未满即违法拒绝」「账簿凭证当然可复制」「2018 否定凭证」「股份套有限第五十七条全文」「曾起诉即不正当目的」「口头即已书面」「名册未载即当然无资格」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 书面请求发函 | `准备查阅复制书面请求` |
| 查阅之诉起诉状 | `提起查阅权诉讼` |
| 概括股东诉讼 | `提起股东权利诉讼` |
| 名册记载请求独占 | `准备股东名册与工商变更衔接` |
| 合伙或个人独资 | 非公司主体 |

不得因「不写诉状」或「不写已获准」关窗。拟判断范围与不正当目的仍正触发，不得写成已获准或当然可复制。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露或证券监管主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「查阅」「起诉」一词不是转出。

## 易混

本窗闸名只能是查阅闸，不是知情闸，不是下一窗书面请求闸。`CK#` 不是名册窗 `MC#`，不是起诉窗 `SZ#`。主路径是 `Q-阅`，不是代表诉讼常用的 `Q-代`。账簿凭证不是当然可复制。未书面或十五日未满不是已违法拒绝。不正当目的由公司举证。曾起诉不是当然不正当目的。1993 年第五十七条不是现行查阅条。1993 年第一百一十条不是现行股份查阅条。2018 年第三十三条不是否定凭证的现行依据。解释四旧第三十三条、第九十七条须核验对应第五十七条、第一百一十条。「请求函日期改到十五日前」整体停止。本窗不执行发送，不代提交。不选定法院。不写诉状。
