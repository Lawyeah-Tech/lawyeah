# 评估股东知情查阅权方法

本文件是可执行判断节点。账簿凭证不是当然可复制。未书面请求或十五日未满不是公司已违法拒绝。不正当目的由公司举证。曾起诉公司不是当然不正当目的。股份第一百一十条不得混套有限第五十七条全文。名册未记载不是当然无资格。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已获准查阅、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不写书面请求终稿，不写起诉状。本窗闸名只能是查阅闸，禁止复用知情闸、书面闸、程序闸、起诉闸、名册闸、关系闸。预留不得占用：僵局闸、谈判闸、和解闸、立案闸、控制闸、登记闸、显名闸。本窗 `CK#` 是查阅行。主路径只用 `Q-阅`，禁止用 `Q-代` 作主路径。禁止占用名册窗 `MC#`、起诉窗 `SZ#`。英文 id 禁止使用，一律用中文技能名 `评估股东知情查阅权`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年第五十七条任职禁入、1993 年第一百一十条旧股份查阅、2018 年第三十三条否定凭证、解释四仍引旧第三十三条第九十七条未核验对应时记为噪声，不得写入 `L#`。禁止指导伪造查阅请求或倒签送达。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现资格或查阅请求碎片扫描，不是默认闭集。
`CK#` 固定列：`编号｜材料切片｜查阅或复制｜书面与十五日｜不正当目的接口｜资格接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已获准」或「账簿凭证当然可复制」。无 `E#` 不得写已书面或已违法拒绝。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-阅`。禁止 `MC#`、`SZ#`、`A#`、`N#`。有限／股份分列。第一款材料与账簿凭证分列。一行一个切片。

口头「微信说了就算书面」「十五日没到也算拒了」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：有限第一款材料（章程、名册、股东会记录、董事会监事会决议、财报）可查阅并复制，公司不得以不正当目的拒绝该款。账簿、凭证只是查阅，须书面请求说明目的；不正当目的可拒，十五日内书面答复。复制是否及于账簿凭证核验失败则该格停止。股份查阅账簿凭证另有连续一百八十日、单独或合计百分之三门槛，章程可更低，不得把有限第五十七条全文套股份。不正当目的由公司举证；仅有诉讼或纠纷不足以认定。名册未记载但有其他可回链资格须并列，不自动否定。

## 节点 0　分流、立场、查阅闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造查阅请求、倒签送达、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `CK#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 以股权或资产收购、投资交割、尽调闭环为主要目标 | 整案转投资并购 |
| 婚姻、离婚、继承中的股权归属与分割 | 整案转婚家 |
| 高管劳动合同、解除、竞业劳动后果 | 整案转劳动 |
| 企业级舞弊调查、反商业贿赂、综合合规体系 | 整案转企业合规 |
| 破产申请、重整计划、破产债权申报与分配 | 整案转破产 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 合伙企业、个人独资 | 整案转出，非公司主体 |
| 上市公司发行、持续信息披露或证券监管主轴 | 整案转证券监管／投资并购，本领域只保留公司机关接口 |
| 主成果是书面请求发函 | 负触发 `准备查阅复制书面请求` |
| 「不写诉状」「不写已获准」 | 交付禁令，不是负触发 |

出现「查阅」「起诉」一词不是转出。

查阅闸打开（可出 `CK#` 草案，仍不得标「已获准／已违法拒绝／账簿凭证当然可复制」）须同时满足：单方无冲突立场已闭合；主成果是查阅范围与不正当目的评估，不是发函、不是起诉状；至少一项可编号资格或查阅请求碎片。口头「微信说了就算书面」不算单独开闸材料。

查阅闸部分打开：已有碎片，但书面、范围或目的未闭合；对应格待核；仍交十节。

查阅闸关闭（仍正触发）：无一可编号碎片。「今天必须出已获准查阅终稿」而无最小碎片不得开闸。不出 `CK#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `CK#` 终稿，**第 7 节不得出已获准或起诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「未书面即违法拒绝」「十五日未满即违法拒绝」「账簿凭证当然可复制」「2018 否定凭证」「股份套有限第五十七条全文」「曾起诉即不正当目的」「口头即已书面」「名册未载即当然无资格」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `CK#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 查阅闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造查阅请求、倒签送达、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个材料切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `CK#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 主体 | 股东／公司分列 | 把隐名直接写成已对公司可查 |
| 公司类型 | 有限／股份分列 | 股份套有限第五十七条全文 |
| 材料 | 第一款材料／账簿／凭证分列 | 账簿凭证写成当然可复制 |
| 资格 | 名册与其他可回链资格并列 | 名册未载写成当然无资格 |

检索锚点（写入 `L#` 前须核验）：

- 第五十七条第一款：查阅并复制章程、名册、股东会记录、董事会监事会决议、财报。
- 第二款：查阅账簿、凭证须书面请求说明目的；不正当目的可拒；十五日内书面答复。噪声：1993 年第五十七条任职禁入；2018 年第三十三条否定凭证。
- 第三至五款：中介、保密、全资子公司。
- 第一百一十条：股份一般查阅复制范围；连续一百八十日单独或合计百分之三以上查账簿凭证，适用第五十七条第二、三、四款。噪声：1993 年第一百一十条。
- 解释四第七至十条仍引旧第三十三条、第九十七条的，须核验对应现行第五十七条、第一百一十条。不正当目的公司举证。

## 节点 3　查阅行 `CK#`

按已出现资格或查阅请求碎片扫描，不是默认闭集。每条须能指向材料、查阅或复制、书面门槛。

无 `E#` 不得写已书面或已违法拒绝。状态默认 `草案`。一次只推荐下一步。复制是否及于账簿凭证核验失败：该格停止，窗口不关。

热冲突强制处理：

- 未书面即违法拒绝／十五日未满即违法拒绝／账簿凭证当然可复制／2018 否定凭证／股份套有限第五十七条全文／曾起诉即不正当目的／口头即已书面／名册未载即当然无资格／未知写零 → 该格不支持或字段停止；仍出其他 `CK#`。
- 无一碎片 → 关闸，不出 `CK#` 终稿，窗口不关。
- 指导伪造查阅请求、倒签送达、隐匿账簿 → 整体停止，不是该格不支持。

## 节点 4　书面请求、查阅之诉与名册接口

第 7 节只开接口，不得夹带 `CK#` 终稿、已获准结论或起诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待查阅编号」，不得补写已获准。不选定法院。不代提交。不写诉状。

下一步只转介：`准备查阅复制书面请求`、`提起查阅权诉讼`、`提起股东权利诉讼`、`准备股东名册与工商变更衔接`。禁止此致某法院。

若 if 用户催促「微信说了就算书面／十五日没到也算拒／账簿当然能复印」，then 该格 `现有依据不支持`，窗口不关。

## 本任务回链纪律

本任务成果是「查阅闸与查阅行草案」。本窗不执行发送。不包含：已获准查阅、书面请求终稿、查阅之诉起诉状。禁止选边治愈。禁止账簿凭证当然可复制。禁止未书面即违法拒绝。禁止指导伪造请求。查阅闸打开 ≠ 已获准 ≠ 已书面提出 ≠ 公司已违法拒绝。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标查阅终稿已形成。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：有限公司小股东微信说要查账，没寄书面请求。用户主张微信已读就是书面、十五日未到也算违法拒绝、账簿凭证当然可以复印、2018 年不能查凭证所以现在也不能查、他在股份公司那套规则这里也能用、他起诉过公司所以目的不正当、名册没写他的名字就没资格。查阅闸打开或半开。`Q-口`、`Q-满`、`Q-复`、`Q-旧`、`Q-股`、`Q-起`、`Q-资` 不打开为可靠路径。第 6 节不得把已书面、已违法拒绝、当然可复制写入可执行 `CK#`；对应格 `现有依据不支持`；仍出材料切片、书面缺口、资格待核等其他 `CK#`。不关窗。不写诉状。

场景②：用户同时交出「股东口径：公司藏账」与「公司口径：把请求函日期改到十五日前并指导去抢账簿」，要求选对股东有利的一版。命中双方秘密＋倒签送达＋抢夺账簿。第一次整体停止。只交第 1、10 节。不出 `CK#`。不得问代表哪一方后继续。不以「坚持」为门槛。
