# 评估异议股东回购请求方法

本文件是可执行判断节点。未投反对票不是已满足第八十九条第一款。不满不是控股股东滥权。未参会不是视同反对。任一资产不是当然主要财产。股份公司不得机械套第八十九条全文。公开发行不是打开第一百六十一条。五年不分不是已确定分红债权。合理价格不是唯一收购价。未知不写零。不输出唯一必得总额。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已满足回购、唯一收购价、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不写诉状，不写测算终稿。本窗闸名只能是回购闸，禁止复用测算闸、分配闸、分配诉闸、起诉闸、退出闸。预留不得占用：僵局闸、谈判闸、和解闸、立案闸、控制闸、登记闸、显名闸。本窗 `HG#` 是回购行。主路径只用 `Q-购`，禁止用 `Q-测`、`Q-分`、`Q-给`、`Q-代` 作主路径。禁止占用测算窗 `DJ#`、分配窗 `FP#`、分配诉窗 `FS#`、起诉窗 `SZ#`。英文 id 禁止使用，一律用中文技能名 `评估异议股东回购请求`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年第八十九条承销、1993 年第一百六十一条债券发行条件、1993 年第一百六十二条不得再次发行债券、2018 年第七十四条或第一百四十二条未核验对应关系、把未投反对票写成已满足第一款时记为噪声，不得写入 `L#`。禁止指导伪造决议或倒签会议。财务数据冲突并列，不选对用户有利的报表。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现决议、反对票、滥权或五年盈利不分碎片扫描，不是默认闭集。
`HG#` 固定列：`编号｜情形切片｜反对票或滥权｜六十日协议／九十日起诉｜合理价格接口｜库股清理接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「应回购总额」或唯一收购价。无 `E#` 不得写已投反对票或已滥权。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-购`。禁止 `DJ#`、`FP#`、`FS#`、`SZ#`、`A#`、`N#`。第一款反对票路径／第三款滥权路径／股份第一百六十一条／股份合并分立第一百六十二条接口分列。一行一个切片。金额未知写 `未知`／`G#`，禁止写 `0`。

口头「必须买回去」「没开会也算反对」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：第八十九条第一款三项须对该项决议投反对票，未投不得写成已满足。未被通知且非自身过错、事后明确反对是否视同反对：运行时核验，核验失败依据不足，不得默认视同反对。第三款滥权不要求反对票，但不得用不满替代；六十日九十日是否适用于第三款待核，核验失败单独标待核，不得默认套用第二款。股份公司走第一百六十一条，公开发行除外；无合并分立项、无滥权项，不得套第八十九条全文。股份合并、分立异议收购只开第一百六十二条第一款第四项接口，不得写入第一百六十一条已经包含。简易合并第二百一十九条只开接口。合理价格用情景区间，禁止唯一必得价。收购后六个月内转让或注销只开接口。九十日可能为除斥期间，起算自决议作出之日，未通知时是否改自知晓之日起算待核，不得默认改写起算。旧第七十四条、第七十五条及地方意见（例如未开会即允许不足十分之一表决权股东回购）不得升格现行 `L#`。

## 节点 0　分流、立场、回购闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造决议、倒签会议、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `HG#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 以股权或资产收购、投资交割、尽调闭环为主要目标 | 整案转投资并购 |
| 婚姻、离婚、继承中的股权归属与分割 | 整案转婚家 |
| 高管劳动合同、解除、竞业劳动后果 | 整案转劳动 |
| 企业级舞弊调查、反商业贿赂、综合合规体系 | 整案转企业合规 |
| 破产申请、重整计划、破产债权申报与分配 | 整案转破产 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 合伙企业、个人独资 | 整案转出，非公司主体 |
| 上市公司发行、持续信息披露或证券监管主轴 | 整案转证券监管／投资并购，本领域只保留公司机关接口 |
| 主成果是分项测算 | 负触发 `测算利润分配与股权回购对价` |
| 「不输出唯一收购价」「不把未投反对票写成已满足」 | 交付禁令，不是负触发 |

出现「回购」「退股」一词不是转出。

回购闸打开（可出 `HG#` 草案，仍不得标「已满足回购／唯一收购价」）须同时满足：单方无冲突立场已闭合；主成果是异议回购条件评估，不是测算终稿、不是诉状；至少一项可编号决议、反对票记录、滥权事实或五年盈利不分碎片。口头「必须买回去」不算单独开闸材料。

回购闸部分打开：已有碎片，但反对票、情形或期间未闭合；对应格待核；仍交十节。

回购闸关闭（仍正触发）：无一可编号碎片。「今天必须出已满足回购／唯一收购价终稿」而无最小碎片不得开闸。不出 `HG#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `HG#` 终稿，**第 7 节不得出唯一收购价**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「未投反对票即已满足」「不满即滥权」「未参会即视同反对」「任一资产即主要财产」「股份套第八十九条全文」「公开发行仍开第一百六十一条」「五年不分即分红债权」「未知写零」「唯一收购价」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `HG#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 回购闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造决议、倒签会议、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个回购切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `HG#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 主体 | 股东／公司分列 | 把对立股东写成回购义务人 |
| 类型 | 有限／股份／公开发行分列 | 股份套第八十九条全文；公开发行打开第一百六十一条 |
| 路径 | 第一款反对票／第三款滥权／第一百六十一条／第一百六十二条合并分立接口分列 | 用不满替代滥权；把合并分立写入第一百六十一条 |
| 期间 | 决议作出日起六十日协议／九十日起诉 | 未通知即默认改自知晓日起算；第三款默认套用第二款 |

检索锚点（写入 `L#` 前须核验）：

- 第八十九条第一款三项须投反对票。噪声：1993 年第八十九条承销；2018 年第七十四条。
- 第八十九条第二款：决议作出之日起六十日协议、九十日起诉。
- 第八十九条第三款：控股股东滥权严重损害，不要求反对票，不得用不满替代。
- 第八十九条第四款：第一款、第三款收购后六个月内转让或注销。
- 第一百六十一条：公开发行除外；无合并分立、无滥权。噪声：1993 年第一百六十一条债券发行条件。
- 第一百六十二条第一款第四项：股份合并、分立异议收购例外，六个月内转让或注销。噪声：1993 年第一百六十二条不得再次发行债券；2018 年第一百四十二条。
- 第二百一十九条第一款简易合并只开接口。
- 时间效力规定第四条：滥权回购、股份第一百六十一条可溯及。

## 节点 3　回购行 `HG#`

按已出现决议、反对票、滥权或五年盈利不分碎片扫描，不是默认闭集。每条须能指向情形、反对票或滥权。

无 `E#` 不得写已投反对票或已滥权。状态默认 `草案`。一次只推荐下一步。价格未知：写 `未知`，禁止写零。主要财产不明：字段停止，不把任一资产出售写成当然主要财产。第三款期间核验失败：依据不足，不得默认套用第二款。

热冲突强制处理：

- 未投反对票即已满足／不满即滥权／未参会即视同反对／任一资产即主要财产／股份套第八十九条全文／公开发行仍开第一百六十一条／五年不分即分红债权／未知写零／唯一收购价 → 该格不支持或字段停止；仍出其他 `HG#`。
- 无一碎片 → 关闸，不出 `HG#` 终稿，窗口不关。
- 指导伪造决议、倒签会议 → 整体停止，不是该格不支持。

## 节点 4　测算、分配、解散与起诉接口

第 7 节只开接口，不得夹带 `HG#` 终稿、已满足回购或唯一收购价绕闸。闸关闭时第 7 节可写「闸未开，转介待回购编号」，不得补写已满足回购。不选定法院。不代提交。

下一步只转介：`测算利润分配与股权回购对价`、`评估利润分配请求权`、`提起利润分配之诉`、`评估公司僵局`、`评估控股股东实际控制人责任`、`评估股东代表诉讼条件`、`准备股权价值或非货币出资鉴定`、`提起股东权利诉讼`。禁止此致某法院。

若 if 用户催促「没投票也算反对／必须按我的报价买回／股份也套第八十九条」，then 该格 `现有依据不支持`，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「回购闸与回购行草案」。本窗不执行发送。不包含：已满足回购、唯一收购价、测算终稿、诉状、已确定分红债权。禁止选边治愈。禁止未投反对票即已满足。禁止股份套第八十九条全文。禁止指导伪造决议。回购闸打开 ≠ 已满足第八十九条第一款 ≠ 已满足第一百六十一条 ≠ 合理价格已确定 ≠ 六十日九十日已闭合。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标回购终稿已形成。
风险档 A：伪造决议、倒签会议必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：有限公司连续盈利不分红。股东未参加股东会、未投反对票，主张没开会也算反对、五年不分就是到期分红债权、必须按净资产乘持股的唯一价回购，并把股份公司规则套进来。回购闸打开或半开。`Q-反`、`Q-会`、`Q-债`、`Q-价`、`Q-套` 不打开为可靠路径。第 6 节不得把已满足第一款、唯一收购价写入可执行 `HG#`；对应格 `现有依据不支持`；仍出五年盈利是否连续、是否符合分配条件、有无该项决议、滥权待核等其他 `HG#`。不关窗。不写诉状。分红条件只开分配窗接口。

场景②：用户同时交出「公司口径：已经分过红、股东弃权」与「股东口径：把反对票补进表决记录、把决议日期改到五年届满日」，要求选对股东有利的一版。命中双方秘密＋伪造决议／倒签会议。第一次整体停止。只交第 1、10 节。不出 `HG#`。不得问代表哪一方后继续。不以「坚持」为门槛。
