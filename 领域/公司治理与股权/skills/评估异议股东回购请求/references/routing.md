# 边界与路由

## 正触发

对合并、分立、转让主要财产、五年盈利不分等投反对票，或控股股东滥权，需要判断回购请求。从零、碎片、反对票未核验、无书面评估授权仍正触发：有可编号决议、反对票记录、滥权事实或五年盈利不分碎片则闸开或半开，出 `HG#` 草案，保持草案。本次不输出唯一收购价、不把未投反对票写成已满足是交付禁令，不是开窗条件。未投反对票即已满足、不满即滥权，仍正触发。

双方秘密、伪造决议、倒签会议、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「未投反对票即已满足」「不满即滥权」「未参会即视同反对」「任一资产即主要财产」「股份套第八十九条全文」「公开发行仍开第一百六十一条」「五年不分即分红债权」「未知写零」「唯一收购价」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 分项测算或唯一收购价精算 | `测算利润分配与股权回购对价` |
| 强制分红条件 | `评估利润分配请求权` |
| 可提交分配诉状 | `提起利润分配之诉` |
| 司法解散 | `评估公司僵局` |
| 控制股东赔偿责任 | `评估控股股东实际控制人责任` |
| 代表诉讼条件 | `评估股东代表诉讼条件` |
| 鉴定 | `准备股权价值或非货币出资鉴定` |
| 可提交回购起诉状 | `提起股东权利诉讼` |
| 合伙或个人独资 | 非公司主体 |

不得因「不输出唯一收购价」或「不把未投反对票写成已满足」关窗。要判断有没有异议回购请求仍正触发，不得写成已满足回购。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露或证券监管主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「回购」「退股」一词不是转出。

## 易混

本窗闸名只能是回购闸，不是测算闸，不是分配闸，不是退出闸。`HG#` 不是测算窗 `DJ#`，不是分配窗 `FP#`。主路径是 `Q-购`，不是 `Q-测`，不是 `Q-分`，不是 `Q-代`。未投反对票不是已满足第八十九条第一款。不满不是控股股东滥权。未参会不是视同反对。任一资产不是当然主要财产。股份公司不得机械套第八十九条全文。第一百六十一条无合并分立项、无滥权项，公开发行除外。股份合并分立异议收购走第一百六十二条第一款第四项接口，不是第一百六十一条已经包含。公开发行不是打开第一百六十一条。五年不分走异议回购，不写成分红债权。1993 年第八十九条不是现行异议回购条。2018 年第七十四条不是 2024 年 7 月 1 日后的现行条号。第三款期间是否同款待核，不得默认套用第二款。「把反对票补进表决记录」整体停止。本窗不执行发送，不代提交。不选定法院。不写诉状。不输出唯一收购价。
