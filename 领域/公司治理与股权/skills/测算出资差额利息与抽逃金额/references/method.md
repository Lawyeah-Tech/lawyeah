# 测算出资差额利息与抽逃金额方法

本文件是可执行判断节点。大额转出不是当然抽逃。认缴登记不是已实缴。未届期不是已到期必缴额。未缴与抽逃就同一笔资金不得双计。未知不写零。不输出唯一必得总额。不认定瑕疵已成立。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。金额状态只用 `已核实金额`、`情景金额`、`无法估计`。禁止胜诉率、已抽逃终稿、唯一必得总额、选定法院、代提交、未知写零。本任务不定罪，不写催缴书，不写诉状。本窗闸名只能是差额闸，禁止复用测算闸、瑕疵闸、催缴闸、失权闸、清偿闸、非货币闸。本窗差额闸不是利润回购窗测算闸；主行只能是 `CE#`，禁止 `DJ#`、`YZ#`、`A#`。主路径只用 `Q-差`，禁止用 `Q-测`、`Q-抽` 作主路径。伤残等级与本窗无关，禁止折入本息或抽逃额。英文 id 禁止使用，一律用中文技能名 `测算出资差额利息与抽逃金额`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年第四十九条董事会十日通知、1993 年第五十三条监事任期、2018 年第三十五条当现行第五十三条、把大额转出写成当然抽逃、把未知写成零时记为噪声。禁止指导伪造出资凭证或倒签缴款日。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现资金切片扫描，不是默认闭集。
`CE#` 固定列：`编号｜资金切片｜未缴接口｜抽逃接口｜利息与已承担｜金额状态｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。无 `E#` 不得写已核实金额。`E#` 只作证据形态回链，不是发送闸，不是已抽逃证明。扫描不是闭集。缺项记 `G#`。承认只进 `S#`／`D#`，不得占用 `A#`。真实零必须有肯定来源。同一笔资金不得未缴与抽逃双计。

口头「转出去了就是抽逃」「先写一个法院会支持的数」「不清楚先写零」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：认缴减已核实实缴得未缴本金；凭证、验资、过户日冲突建并行情景，不得选边。抽逃只把符合表征且有资金流、损害公司权益的金额列入情景，不得把全部分红或正常往来写入抽逃。利息起算、利率须运行时核验；失败则利息字段停止，禁止套民间借贷利率当已核实出资利息。已向公司补缴或已向债权人承担的金额扣减并回链。第五十三条返还与第四十九条损失、董监高连带分列，不得合成一笔必得总额。解释三第十三条、第十四条「本息」与 2023 年第五十三条「损失」对应关系待核，不得写唯一利息必得。

## 节点 0　分流、立场、差额闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造出资凭证、倒签缴款日、伪造资金流、抢夺印章、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。未知写零、唯一必得总额不是负触发。

整案转出只交付第 1、2、10 节，不出 `CE#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是催缴、失权或加速路径 | 负触发 `评估出资瑕疵催缴与加速到期` |
| 主成果是发送版催缴书 | 负触发 `准备催缴出资通知` |
| 主成果是失权评估或通知 | 负触发 `评估失权与股权丧失` |
| 主成果是利润或回购价格测算 | 负触发 `测算利润分配与股权回购对价` |
| 主成果是补充清偿评估终稿 | 负触发 `评估股东对公司债务的补充清偿责任` |
| 主成果是非货币作价终稿 | 负触发 `评估非货币出资真实性与作价` |
| 主成果是鉴定事项 | 负触发 `准备股权价值或非货币出资鉴定` |

| 主成果是投并购资金到位 | 整案转投资并购 |
| 合伙或个人独资 | 整案转出，非公司主体 |
| 「不认定瑕疵已成立」「未知不写零」「不输出唯一必得总额」 | 交付禁令，不是负触发 |

出现「差额」「利息」「抽逃」「本息」一词不是转出。

差额闸打开（可出 `CE#` 草案，仍不得标「已抽逃／唯一必得总额／已到期必缴」）须同时满足：单方无冲突立场已闭合；主成果是分项测算，不是瑕疵路径终稿、不是催缴书、不是利润回购测算、不是诉状；至少一项可编号认缴实缴、资金流或已承担碎片。口头「转出去了就是抽逃」不算单独开闸材料。

差额闸部分打开：已有碎片，但起算日、利率、资金流或凭证冲突未闭合；对应格待核；仍交十节。

差额闸关闭（仍正触发）：无一可编号碎片。「今天必须出唯一必得总额」而无最小碎片不得开闸。不出 `CE#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `CE#` 终稿，**第 7 节不得出催缴书或诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「大额转出即抽逃」「认缴登记即已实缴」「未届期即已到期必缴」「同一笔双计」「未知写零」「唯一必得总额」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `CE#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 差额闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与对立股东相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造出资凭证、倒签缴款日、伪造资金流、抢夺印章、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　未缴与抽逃分表

一行一个资金切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `CE#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 类型 | 未缴本金／抽逃本金／利息／已承担扣减分列 | 同一笔既当未缴又当抽逃再相加；利润回购混进本表 |
| 到期 | 已届期／尚未到期情景／加速接口分列 | 未届期写成已到期必缴额 |
| 金额状态 | 已核实／情景／无法估计 | 未知写零；无肯定来源写真实零 |
| 转介 | 利润、回购转 `测算利润分配与股权回购对价` | 本窗出利润回购终稿 |

检索锚点（写入 `L#` 前须核验）：

- 第四十九条：按期足额缴纳；未按期除足额缴纳外赔偿公司损失。本窗只开金额接口。噪声：1993 年第四十九条董事会十日通知。
- 第五十三条：不得抽逃；返还抽逃的出资；损失由负有责任董监高与该股东连带。返还与赔偿分列。大额转出不是当然抽逃。噪声：1993 年第五十三条监事任期；2018 年第三十五条。
- 第五十条设立时其他股东连带、第八十八条转让人／受让人责任只开接口。
- 第五十一条催缴、第五十二条宽限期自发出之日起不得少于六十日只开接口；宽限期不是利息起算，不是诉讼时效。
- 第五十四条不能清偿才加速；未届期且无不能清偿不得写成已到期必缴。
- 解释三第十二条抽逃表征须损害公司权益；第十三条未出资本息、第十四条抽逃本息与现行第五十三条「损失」对应待核。第十三条第四款仍引旧第一百四十七条须核对应现行第一百八十条。噪声：2011 年解释三第十三条引旧第一百四十八条；2025 年征求意见稿第二十八条不是现行。
- 利息起算 ≠ 催缴宽限期 ≠ 诉讼时效。禁止合成一个「出资期限」或唯一截止日。

## 节点 3　差额行 `CE#`

按已出现资金切片扫描，不是默认闭集。每条须能指向未缴或抽逃接口和金额状态。

无 `E#` 不得写已核实金额。未审计流水不得升格已核实抽逃。状态默认 `草案`。一次只推荐下一步。未知金额不写零，不输出唯一必得总额。同一笔资金未缴与抽逃互斥，先对切片再计列。伤残等级不得写入本息或抽逃额。

热冲突强制处理：

- 大额转出即抽逃／认缴即已实缴／未届期即已到期必缴／同一笔双计／未知写零／唯一必得总额 → 该格不支持或字段停止；仍出其他 `CE#`。
- 无一碎片 → 关闸，不出 `CE#` 终稿，窗口不关。
- 指导伪造出资凭证、倒签缴款日、伪造流水 → 整体停止，不是该格不支持。

情景只改变列明未知变量。用户催唯一必得总额：字段停止，不因催促给出伪精确数字。

## 节点 4　瑕疵、催缴、失权、清偿与诉讼接口

第 7 节只开接口，不得夹带 `CE#` 终稿、催缴书或诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待资金切片编号」，不得补写已抽逃或唯一必得总额。利息起算、催缴宽限期、诉讼时效三分列只开接口。禁止合成一个出资期限。不写唯一截止日，不选定法院。

下一步只转介：`评估出资瑕疵催缴与加速到期`、`准备催缴出资通知`、`评估失权与股权丧失`、`测算利润分配与股权回购对价`、`评估股东对公司债务的补充清偿责任`、`评估非货币出资真实性与作价`、`提起股东权利诉讼`。禁止此致某法院。不代提交。

若 if 用户催促「转出去了就是抽逃／先写零／给一个必得总额」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`／`无法估计`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：股东认缴后将出资款转入公司账户数日转出，另有一笔未届期未缴。用户主张转出就是抽逃、未缴与抽逃加倍计算、按民间借贷利率自公司成立日起息、不清楚的金额先写零、要一个法院必支持的本息总额。差额闸打开或半开。`Q-抽`、`Q-双`、`Q-期`、`Q-息`、`Q-零` 不打开为可靠路径。第 6 节不得把已抽逃、双计、0、唯一必得总额写入可执行 `CE#`；对应格 `现有依据不支持` 或字段停止；仍出认缴实缴分列、资金流情景、利息待核、已承担缺口等其他 `CE#`。不关窗。不认定瑕疵已成立。

场景②：用户同时交出公司「验资后次日全额转出」流水与对立股东「是往来借款、缴款日其实更早」口径，要求选对公司有利的一版，并指导「把缴款日改到转出前、补一份借款合同」。命中双方秘密＋伪造凭证＋倒签缴款日。第一次整体停止。只交第 1、10 节。不出 `CE#`。不得问代表哪一方后继续。不以「坚持」为门槛。
