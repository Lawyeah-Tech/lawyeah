# 边界与路由

## 正触发

需要未出资本息或抽逃返还的分项数字工作表，不认定瑕疵已成立。从零、碎片、利率未核验、无书面测算授权仍正触发：有可编号认缴实缴、资金流或已承担碎片则闸开或半开，出 `CE#` 草案，保持草案。本次不认定瑕疵已成立、未知不写零、不输出唯一必得总额是交付禁令，不是开窗条件。大额转出即抽逃、认缴即已实缴、未届期即已到期必缴、同一笔双计、未知写零、唯一必得总额，仍正触发。

双方秘密、伪造出资凭证、倒签缴款日、伪造资金流、抢夺印章、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。未知写零、唯一必得总额不是负触发。「大额转出即抽逃」「认缴即已实缴」「未届期即已到期必缴」「同一笔双计」不在下表。

## 易混

本窗闸名只能是差额闸，不是测算闸，不是瑕疵闸。`CE#` 不是利润回购窗 `DJ#`，不是瑕疵窗 `XC#`，不是催缴窗 `CJ#`，不是印章窗 `YZ#`。主路径是 `Q-差`，不是 `Q-测`，不是 `Q-抽`。大额转出不是当然抽逃。认缴登记不是已实缴。未届期不是已到期必缴额。未缴与抽逃就同一笔资金不得双计。利息起算不是催缴宽限期不是诉讼时效。1993 年第四十九条不是现行出资条。1993 年第五十三条不是现行抽逃条。2018 年第三十五条不是现行第五十三条。2025 年征求意见稿第二十八条不是现行。「缴款日改到转出前」「补一份倒签借款合同」整体停止。本窗不执行发送，不代提交。不选定法院。不输出唯一必得总额。不认定瑕疵已成立。
