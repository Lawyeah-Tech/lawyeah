# 边界与路由

## 正触发

机关失灵或两派无法形成有效决议，需要判断僵局事实、替代退出与司法解散接口。从零、碎片、两年持续未核验仍正触发：有可编号机关失灵、失败召集表决、对峙或瘫痪、章程或名册碎片则闸开或半开，出 `JJ#` 草案，保持草案。本次不写解散诉状、不把盈利写成无僵局是交付禁令，不是开窗条件。盈利即无僵局、一次流会即已符合解散，仍正触发。

双方秘密、伪造决议、倒签会议、抢夺印章证照、隐匿账簿、违法取证的停止，优先于负触发。上述信号不在下表。「盈利即无僵局」「一次流会即已符合解散」「亏损即必须解散」「出资额即百分之十门槛」「未尝试即其他途径不能解决」「知情或分红即解散」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 已决定提起司法解散之诉 | `提起司法解散之诉` |
| 仍可谈退出或僵局安排 | `谈判股东退出与僵局安排` |
| 治理重置谈判 | `谈判章程与治理重置` |
| 控制权争夺路径 | `评估控制权争夺与表决权约束` |
| 异议回购终稿 | `评估异议股东回购请求` |
| 破产申请、重整或破产债权 | 破产领域 |
| 合伙或个人独资 | 非公司主体 |

不得因「不直接写解散诉状」或「盈利不等于无僵局」关窗。要判断僵局与出路仍正触发，不得写成必须解散。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产收购、投资交割、尽调闭环 | 投资并购领域 |
| 婚姻、离婚、继承中的股权归属与分割 | 婚家领域 |
| 高管劳动合同、解除、竞业劳动后果 | 劳动领域 |
| 企业级舞弊调查、反商业贿赂 | 企业合规领域 |
| 破产申请、重整计划、破产债权 | 破产领域 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 合伙企业、个人独资 | 非公司主体 |
| 上市公司发行、持续信息披露或证券监管主轴 | 证券监管／投资并购，本领域只保留公司机关接口 |

出现「僵局」「解散」一词不是转出。

## 易混

本窗闸名只能是僵局闸，不是控制闸，不是退出闸，不是起诉闸。`JJ#` 不是 `KZ#` 不是 `TC#` 不是 `JG#` 不是 `JM#`。主路径是 `Q-僵`，不是 `Q-争`，不是 `Q-谈`，不是 `Q-散`。盈利不是无僵局。一次会议未开不是经营管理严重困难。亏损不是必须解散。持股百分之十是表决权，不是当然出资额。未召开不等于无法召开。2018 年第一百八十二条不是 2024 年 7 月 1 日后的现行解散条。解释二仍引旧第一百八十三条或第一百八十二条须核对应第二百三十一条。指导案例 8 号不得当一般规则。「把会议纪要倒签到两年前」整体停止。本窗不执行发送，不代提交。不选定法院。不写诉状。不指导抢章。
