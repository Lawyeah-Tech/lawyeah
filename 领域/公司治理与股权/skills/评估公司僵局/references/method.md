# 评估公司僵局方法

本文件是可执行判断节点。盈利不是无僵局。一次会议未开不是经营管理严重困难。亏损不是必须解散。持股百分之十是表决权，不是当然出资额。其他途径未尝试不是已满足。未知不写零。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必须解散、已无僵局、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不写诉状，不指导抢章。本窗闸名只能是僵局闸，禁止复用关系闸、控制闸、退出闸、谈判闸、和解闸、立案闸、起诉闸、回购闸。预留不得占用：谈判闸、和解闸、立案闸、显名闸。本窗 `JJ#` 是僵局行。主路径只用 `Q-僵`，禁止用 `Q-争`、`Q-谈`、`Q-散`、`Q-购` 作主路径。禁止占用合规监管人行 `JG#`、合规中间人行 `JM#`、控制窗 `KZ#`、退出窗 `TC#`、关系窗 `GX#`。英文 id 禁止使用，一律用中文技能名 `评估公司僵局`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 2018 年第一百八十二条、解释二仍引旧第一百八十三条或第一百八十二条未核对应第二百三十一条、把盈利写成无僵局时记为噪声，不得写入 `L#`。禁止指导伪造决议、倒签会议或抢夺印章证照。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现失灵、失败召集、对峙或名册碎片扫描，不是默认闭集。
`JJ#` 固定列：`编号｜失灵切片｜持续不能形成有效决议｜盈利或亏损接口｜替代路径｜百分之十表决权与解散／破产接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「必须解散」。无 `E#` 不得写已持续两年无法形成有效决议、已穷尽其他途径或已达百分之十表决权。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-僵`。禁止 `JG#`、`JM#`、`KZ#`、`TC#`、`GX#`、`SZ#`、`A#`、`N#`。一行一个切片。

口头「必须解散」「还赚钱所以没僵局」只进 `S#`／`V#`，**不得单独算作开闸材料**。控制窗 `KZ#`、退出窗 `TC#`、关系窗 `GX#` 不得单独开闸。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：经营管理发生严重困难的侧重点是机关运行障碍，不是单纯亏损或盈利。持续两年以上无法召开股东会或不能作出有效决议、董事长期冲突且无法通过股东会解决，是解释二第一条的受理情形，须核对应第二百三十一条。未召开不等于无法召开。一次会议未召开或一次未通过，依据不足构成经营管理严重困难。公司仍盈利不能单独写成无僵局；严重亏损也不自动等于司法解散已成立。知情权、利润分配请求权受损，或亏损、财产不足以偿还全部债务，不是解散诉讼的受理事由。持有百分之十以上表决权是原告门槛，按名册和章程计算，单独或合计待核；出资额不是当然表决权。通过其他途径不能解决：未尝试且无客观不能事实则解散路径依据不足。不能清偿到期债务且明显缺乏清偿能力只开破产接口。本窗不写诉状。

## 节点 0　分流、立场、僵局闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造决议、倒签会议、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `JJ#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 以股权或资产收购、投资交割、尽调闭环为主要目标 | 整案转投资并购 |
| 婚姻、离婚、继承中的股权归属与分割 | 整案转婚家 |
| 高管劳动合同、解除、竞业劳动后果 | 整案转劳动 |
| 企业级舞弊调查、反商业贿赂、综合合规体系 | 整案转企业合规 |
| 破产申请、重整计划、破产债权申报与分配 | 整案转破产 |
| 尚未形成公司组织或股东关系目标，只要改一般交易合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 合伙企业、个人独资 | 整案转出，非公司主体 |
| 上市公司发行、持续信息披露或证券监管主轴 | 整案转证券监管／投资并购，本领域只保留公司机关接口 |
| 主成果是已决定提起解散之诉 | 负触发 `提起司法解散之诉` |
| 「不直接写解散诉状」「盈利不等于无僵局」 | 交付禁令，不是负触发 |

出现「僵局」「解散」一词不是转出。

僵局闸打开（可出 `JJ#` 草案，仍不得标「必须解散」）须同时满足：单方无冲突立场已闭合；主成果是僵局评估，不是解散诉状、不是退出谈判终稿、不是控制争夺终稿；至少一项可编号机关失灵、失败召集表决、对峙或瘫痪、章程或名册碎片。口头「必须解散」不算单独开闸材料。

僵局闸部分打开：已有碎片，但两年持续、百分之十或替代路径未闭合；对应格待核；仍交十节。

僵局闸关闭（仍正触发）：无一可编号碎片。不出 `JJ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `JJ#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「盈利即无僵局」「一次流会即已符合解散」「亏损即必须解散」「出资额即百分之十门槛」「未尝试即其他途径不能解决」「知情或分红即解散」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `JJ#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 僵局闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造决议、倒签会议、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 3　僵局行 `JJ#`

按已出现失灵、失败召集、对峙或名册碎片扫描，不是默认闭集。无 `E#` 不得写已持续两年、已穷尽其他途径或已达百分之十表决权。状态默认 `草案`。伪造两套决议、倒签、抢章红旗出现：整体停止，不是该格不支持后继续出解散步骤。

热冲突强制处理：

- 盈利即无僵局／一次流会即已符合解散／亏损即必须解散／出资额即百分之十门槛／未尝试即其他途径不能解决／知情或分红即解散／未知写零 → 该格不支持或字段停止；仍出其他 `JJ#`。
- 无一碎片 → 关闸，不出 `JJ#` 终稿，窗口不关。
- 指导伪造决议、倒签会议、抢章 → 整体停止。

表决权不足百分之十：解散接口关闭，僵局事实仍可编。不能清偿到期债务：只开破产接口，不得写成应解散或应破产的唯一结论。

## 节点 4　解散起诉、退出谈判、争夺与重置接口

第 7 节只开接口，不得夹带 `JJ#` 终稿、必须解散或诉状绕闸。不选定法院。不代提交。

下一步只转介：`提起司法解散之诉`、`谈判股东退出与僵局安排`、`谈判章程与治理重置`、`评估控制权争夺与表决权约束`、`评估异议股东回购请求`、`准备证照印章管控与交接`。禁止此致某法院。

若 if 用户催促「还赚钱所以没僵局／开一次会没开成就该解散」，then 该格 `现有依据不支持`，窗口不关。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：五五持股、两年开不成会、公司仍盈利。用户主张必须解散、一次流会已经够、持股百分之十就是出资百分之十、没找过下家也算其他途径不能解决、先写诉状。僵局闸打开或半开。`Q-盈`、`Q-会`、`Q-资`、`Q-他`、`Q-散` 不打开为可靠路径。若不提伪造或抢章，第 6 节仍出失灵切片、表决权底稿、替代路径空白等其他 `JJ#`。不关窗。不写诉状。不写必须解散。

场景②：用户同时交出「甲方口径：从未形成有效决议」与「乙方口径：把会议纪要倒签到两年前、先扣公章」，要求选对甲方有利的一套。命中双方秘密＋倒签＋抢章。第一次整体停止。只交第 1、10 节。不出 `JJ#`。不得问代表哪一方后继续。
