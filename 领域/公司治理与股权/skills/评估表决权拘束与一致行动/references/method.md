# 评估表决权拘束与一致行动方法

本文件是可执行判断节点。股东协议一般不对公司发生效力。违约投票不是决议不成立、无效或可撤销。未签署股东不受约束。委托通知公司不是委托对内已生效。法院必然责令按某人投票该格不支持。未知不写零。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、对公司已生效、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不指导伪造投票或倒签一致行动。本窗闸名只能是拘束闸，禁止复用控制闸、结构闸、决议闸、书面闸、关系闸、起诉闸。预留不得占用：僵局闸、谈判闸、和解闸、立案闸、显名闸。本窗 `BJ#` 是拘束行。主路径只用 `Q-束`，禁止用 `Q-争`、`Q-构`、`Q-诉` 作主路径。禁止占用控制窗 `KZ#`、结构窗 `GQ#`、决议窗 `XL#`。英文 id 禁止使用，一律用中文技能名 `评估表决权拘束与一致行动`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年第六十六条国有独资、1993 年第一百一十八条董事会委托其他董事、2018 年第二十二条、把华电改票当一般规则、把内部违约写成决议不成立时记为噪声，不得写入 `L#`。禁止指导伪造决议、伪造投票或倒签一致行动。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现协议、签署人、覆盖议案或委托碎片扫描，不是默认闭集。
`BJ#` 固定列：`编号｜签署人与覆盖议案｜对内拘束｜对公司／机关效力｜违约救济｜章程冲突接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「对公司已生效」。无 `E#` 不得写已向公司提交授权委托书、已按委托计票或已对公司生效。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-束`。禁止 `KZ#`、`GQ#`、`XL#`、`SM#`、`GX#`、`SZ#`、`A#`、`N#`。一行一个切片。

口头「协议签了就能管公司」只进 `S#`／`V#`，**不得单独算作开闸材料**。控制窗 `KZ#`、结构窗 `GQ#` 不得单独开闸。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：股东之间约定如何行使表决权，不违反强制规范的，对签署股东可有拘束；未签署股东不受约束。公司未签署则对公司／机关效力待核，不得默认对公司生效。股东违反约定仍出席并投票，公司按出席股东意思形成的决议，不因内部违约当然不成立或无效；决议三项分类转效力窗。表决权委托对内效力与是否已向公司提交授权委托书分列：通知公司影响计票外观，不等于委托合同对内已生效。继续履行（强制按约定投票）可能落入民法典第五百八十条不适于强制履行，核验失败则救济字段停止，不得写成法院必然责令按某人意志投票。损害赔偿、违约金未知不写零。章程强制规范与机关运行以章程和公司法为准，协议冲突只开接口。华电改票／（2017）赣民申 367 是例外待核，不得当一般规则。2025 年公司法司法解释征求意见稿第十二条不是现行规则。

## 节点 0　分流、立场、拘束闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造决议、伪造投票、倒签会议或一致行动、抢夺印章证照、隐匿账簿、违法取证不进负表。利益冲突未解不进整体停止。

出现「表决」「协议」「一致行动」一词不是转出。

拘束闸打开（可出 `BJ#` 草案，仍不得标「对公司已生效」）须同时满足：单方无冲突立场已闭合；主成果是拘束评估，不是结构图终稿、不是争夺策略、不是决议三项终稿、不是股东协议草稿；至少一项可编号协议、签署人、覆盖议案或委托碎片。口头「协议签了就能管公司」不算单独开闸材料。

拘束闸部分打开：已有碎片，但签署人、覆盖议案或对公司效力未闭合；对应格待核；仍交十节。

拘束闸关闭（仍正触发）：无一可编号碎片。不出 `BJ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `BJ#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「股东协议即对公司生效」「违约投票即决议不成立」「未签署股东亦受约束」「委托已通知公司即对内已生效」「法院必然责令按某人投票」「华电改票当一般规则」「认缴即当然表决权」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `BJ#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 拘束闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造决议、伪造投票、倒签会议或一致行动、抢夺印章证照、隐匿账簿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 3　拘束行 `BJ#`

按已出现协议、签署人、覆盖议案或委托碎片扫描，不是默认闭集。无 `E#` 不得写已向公司提交授权委托书、已按委托计票或已对公司生效。状态默认 `草案`。伪造投票、倒签红旗出现：整体停止，不是该格不支持后继续出拘束步骤。

热冲突强制处理：

- 股东协议即对公司生效／违约投票即决议不成立／未签署股东亦受约束／委托已通知公司即对内已生效／法院必然责令按某人投票／华电改票当一般规则／认缴即当然表决权／未知写零 → 该格不支持或字段停止；仍出其他 `BJ#`。
- 无一碎片 → 关闸，不出 `BJ#` 终稿，窗口不关。
- 指导伪造投票、倒签一致行动、抢章 → 整体停止。

对公司／机关效力格：公司未签署则默认待核或不支持，不得写成对公司当然生效。授权委托书是否提交只影响计票外观，不决定委托合同对内效力。决议对外：内部违约不当然导致不成立、无效或可撤销，只开效力窗接口。

违约救济格：第五百七十七条打开继续履行／赔偿／补救接口；第五百八十条除外待核，不得写法院必然责令按某人投票；第五百八十五条违约金未知不写零。华电改票／（2017）赣民申 367 只比较事实差异，不得当一般规则写入可执行格。

## 节点 4　争夺、结构、决议、章程与起草接口

第 7 节只开接口，不得夹带 `BJ#` 终稿、对公司已生效或决议当然不成立绕闸。不选定法院。不代提交。

若 if 用户催促「协议签了就能管公司／违约了决议就没了／法院必须责令按约定投票」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。
