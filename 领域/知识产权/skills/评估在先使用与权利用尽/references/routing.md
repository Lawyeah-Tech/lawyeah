# 边界与路由

## 正触发

主张商标先用或专利权利用尽。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 合法来源／定牌 | 评估定牌加工与合法来源抗辩 |
| 总体抗辩 | 评估被控侵权抗辩路径 |
| 合理使用作品 | 评估合理使用与法定许可 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动、数据合规、反垄断 | 对应领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

专利申请日前的制造可以先用，申请日后扩产通常不行。权利人售出的正品再销售一般用尽，但维修是否重构要另核。
