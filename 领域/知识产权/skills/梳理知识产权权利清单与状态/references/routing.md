# 边界与路由

## 正触发

需单独把注册、申请、许可、转让、续展做成可回链清单。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 侵权终局对照 | 评估侵权是否成立 |
| 事项总图 | 评估知识产权事项 |
| 续展变更转让代办 | P2 handle-trademark-renewal-and-change；未安装则 unavailable |
| 未成争转让出稿 | 审查起草领域（本窗搁置） |
| 权属争议实体 | 评估权属与职务成果归属 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 竞业或劳动保密 | 劳动领域 |
| 个人信息、出境、网安 | 数据隐私领域 |
| 经营者集中、垄断协议、滥用支配 | 竞争法领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

“把公司名下商标专利都列出来并告诉我能不能告”是混合请求：本任务只交清单；能否告转总图或侵权对照。有证书仍缺许可备案时不得写成可对外维权主体已闭合。
