# 边界与路由

## 正触发

初审公告期内要异议。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 已注册无效 | 准备商标无效宣告 |
| 被异议答辩 | 应对商标异议 |
| 驳回复审 | 准备商标驳回复审材料 |
| 公告期已过 | 整体停止异议终稿 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动、数据合规、反垄断 | 对应领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

异议不是无效。公告即将届满时不得用“先交再补”掩盖已过期。驰名按需认定不得写成荣誉称号。
