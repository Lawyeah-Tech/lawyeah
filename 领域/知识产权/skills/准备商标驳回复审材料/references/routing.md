# 边界与路由

## 正触发

收到驳回，需复审理由、证据和期限卡。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 新申请核验 | 准备商标注册申请前核验 |
| 异议 | 准备商标异议材料 |
| 授权确权行政诉讼 | P2 prepare-trademark-review-litigation，unavailable |
| 期间已过仍要终稿 | 整体停止 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动、数据合规、反垄断 | 对应领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

部分驳回与全部驳回分列，不得把可分割商品上的成功希望写成全部指定商品将核准。引证商标可共存不等于审查员必须接受。
