# 边界与路由

## 正触发

需海关依职权或依申请保护，权利人准备备案。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 已扣货确认 | 处理海关扣留与确认侵权 |
| 民事起诉 | 提起知识产权民事一审 |
| 平台投诉 | 准备平台投诉与通知删除材料 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动、数据合规、反垄断 | 对应领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。
