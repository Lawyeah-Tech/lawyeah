# 测算方法

不认定侵权已成立。未知不写零。不输出唯一必得总额。MCP 把 2025-10-15 已施行的《反不正当竞争法》标成尚未施行时，以施行日为准并记冲突。专利法第六十五条、著作权法第四十九条作为现行赔偿条号时记噪声，分别按第七十一条、第五十四条核验。

## 节点 0　分流

劳动竞业违约金转劳动。反垄断罚款转竞争法。只要总图转评估。合同违约金主轴转合同争议。

## 节点 1　事件与假设

为同一侵权实施期间分配 `EVT#`。权利类型分账。持续侵权赔偿向前推算三年（商标民事解释第 18 条口径）只作期间接口，不把过时效写成全部为零。

金额状态：`已核实金额`、`情景金额`、`无法估计`。真实零必须有肯定来源。

## 节点 2　分项

| 项目 | 规则 |
| --- | --- |
| 实际损失 | 销量减少×合理利润；减少量不明可用侵权销量×权利人单利 |
| 侵权获利 | 侵权销量×侵权单利；完全以侵权为业可用销售利润（专利规定口径，须核验是否类推） |
| 许可费倍数 | 许可真实、可比；明显不合理不得直接用 |
| 法定赔偿 | 损失、获利、许可费均难以确定时打开；商标／专利／著作权／反法上限分别核验（常见 500 万元档，以现行条为准） |
| 惩罚性 | 单独行，不与法定赔偿暗加 |
| 合理开支 | 调查取证和符合规定的律师费；一般在基数外 |

账簿主要由侵权人掌握且权利人已尽力举证：责令提供账簿接口（专利法第 71 条第 4 款等，运行时核验），拒不提供可参考权利人主张，仍不得把主张写成已核实。

## 节点 3　惩罚性

法释〔2021〕4 号：起诉时明确数额、计算方式和事实；故意包括商标法第 63 条第 1 款和反法相应恶意条款（2025 年对应第 22 条第 3 款，2019 年为第 17 条第 3 款）。基数为损失、违法所得或获利，不含合理开支。行政罚款或刑事罚金已执行完毕不免除惩罚性，但确定倍数时可综合。

## 节点 4　互斥

损失、获利、许可费倍数一般选用，不叠加。法定赔偿与精确计算不双计。惩罚性以选定基数乘倍数，不另起第三套基数。

## 节点 5　汇总纪律

禁止唯一必得总额。用户路径写成起诉时只标管辖红旗，不写诉状。
