# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、路径、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然侵权、必然下架或唯一必得总额。

`search_law` 返回已失效《合同法》、1990 年《著作权法》同号旧义或 1993 年反法定义时记为噪声，不得写入 `L#`。MCP 把 2025 年 10 月 15 日已施行的《反不正当竞争法》标成尚未施行时，以施行日为准并记录冲突。

## Q# 矩阵

固定列：`编号｜关系假设｜提出方｜相对方｜权利类型｜法律效果｜成立条件｜支持事实｜不利事实｜控制方｜最强反方｜主备位｜判断｜待核`。

停止侵害、赔偿、惩罚性、合理开支、确认不侵权、行政查处分列。同一事实支持多项时分别说明效果，不重复金额。

---

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填总体评估十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 竞业限制效力、补偿、违约金或劳动保密安排 | 劳动领域 |
| 个人信息合法性、重要数据、跨境、网络安全体系 | 数据隐私领域 |
| 经营者集中、垄断协议、滥用支配地位、平台强制低于成本定价 | 竞争法领域 |
| 尚未成争，只要许可、转让或共存出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 只要第一轮大众平台内容商标评估 | C 端 `只要第一轮大众平台内容商标评估`，只分流不回改 |
| 域名抢注或域名投诉主成果 | 留接口，转 `评估域名与标识冲突`（未安装则 `unavailable`） |
| 植物新品种、集成电路布图、地理标志主轴 | 留接口，转 `评估植物新品种布图设计或地理标志`（未安装则 `unavailable`） |

混合信号：标识或作品保护主轴可留本任务；专项只作为背景时在缺口标明。

## 节点 1　权利对象、权属和程序状态

1. 分权利类型建立对象：商标图样与核定商品；专利权利要求与被控技术方案；作品版本；商业秘密密点。冲突并列，不选对用户有利的一版冒充唯一对象。
2. 权属链记录形成主体、职务/委托/合作、继受、许可投诉权限。付款、下载、雇佣无条款、素材库会员或网上公开不得写成完整权属。
3. 程序表逐动作记录协商、警告、平台、海关、行政、诉讼或执行：机关/平台、案号、文书、作出日、收到日、送达方式和效力凭证。口头转述、截图、“已读”不得写成已受理、已送达或期限已起算。
4. 同时掌握双方秘密或立场不明：整体停止策略输出。

## 节点 2　请求与抗辩假设

每个 `Q#` 先写法律效果，再写成立条件。禁止合成“知产权益”一笔。

默认主位候选按事实分别建立：

- `Q-停` 停止侵害、销毁、下架或断开链接
- `Q-通` 警告或平台通知（接口，不发函）
- `Q-禁` 行为保全（接口）
- `Q-金` 损害赔偿（损失 / 获利 / 许可费）
- `Q-惩` 惩罚性赔偿（故意且情节严重）
- `Q-支` 合理开支
- `Q-行` 行政查处（接口）
- `Q-抗` 权属、不落入保护范围、合法来源、合理使用、权利用尽、先用、时效、管辖、无效

权属不能回链：侵权类 `Q#` 标 `依据不足，无法形成结论`，不进入发送或立案终稿接口。

单位或被控方立场：逐项回应对方已知主张，并列己方最强抗辩，不把反诉或无效写成已经提起。

## 节点 3　路径与期限

分别判断：协商、警告、平台、海关、行政、民事、刑事交叉。本任务不写立案包或投诉终稿。

### 3.1 路径分账

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 标识相同或作品相似 | 已经构成侵权 |
| 用户想今天发函 | 对方必须下架或已经自认 |
| 有注册证或登记证 | 权属和保护范围已闭合 |
| 对方未在平台声明期内声明 | 侵权已确定 |

刑事信号（假冒注册商标、制售、侵犯商业秘密达到刑事追诉）只标红旗，转 `assess-civil-criminal-overlap`（未安装则 `unavailable`）和刑事领域，不定罪。

### 3.2 期限分类型

| 类型 | 规则锚点 | 本任务允许的输出 | 禁止 |
| --- | --- | --- | --- |
| 诉讼时效 | 民法典第 188 条一般为三年；商标民事解释第 18 条持续侵权推算 | 起算事件、持续侵权接口 | 唯一截止日；过时效=全部败诉 |
| 异议 / 无效除斥 | 商标法、专利法运行时核验 | 公告日、除斥情景 | 与时效混算 |
| 答辩 / 管辖异议 | 民诉及知产管辖规定，运行时核验 | 已进入程序时标红旗 | 编造唯一答辩截止日 |
| 海关确认期 | 海关知识产权保护条例，运行时核验 | 扣留通知原文期间 | 把海关期写成诉讼时效 |
| 诉前保全后起诉期 | 民诉及行为保全规定，运行时核验 | 条件公式 | 未核验写成一律 15 日或 30 日 |

日期冲突、送达不明：并行情景 + 字段停止。

## 节点 4　金额区间与惩罚性接口

本任务只建区间和接口，不替代 `calculate-damages`。

1. 分项：实际损失、侵权获利、许可费倍数、法定赔偿、惩罚性、合理开支。未知不写零，不输出唯一必得总额。
2. 商标法第 63 条、专利法第 71 条、著作权法第 54 条、反法第 22 条（2025；2019 行为对照第 17 条）运行时核验后再写上限和倍数。旧条号（专利法第六十五条、著作权法第四十九条）记噪声。
3. 惩罚性：故意（含商标恶意）且情节严重。基数不含合理开支（法释〔2021〕4 号第 5 条），除非现行法另有规定且已核验。
4. 合理开支可另计，不折进法定赔偿上限，除非核验后的条文另有安排。

参数不足：只列已知参数、未知参数和专项测算接口。

程序动作记录机关/平台、案号、文书、作出、收到、送达、效力。期限每行只对应一种期间类型和一个起算事件。

## 金额区间表

固定列：项目、性质、期间、参数、来源、已付、未知、互斥／抵扣、范围、专项测算接口。

## 证据与下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。

下一步按期限灭失、易失证据、改变请求抗辩、可逆性排序。警告、禁令、起诉、应诉、精算、完整证据卷只写转介条件和最小交接。禁止指导伪造、隐匿、威胁或违法取证。
