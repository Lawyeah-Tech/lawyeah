# 边界与路由

## 正触发

已出现使用、登记冲突、警告、下架、海关、行政或诉讼信号，单方需要总体决定请求、抗辩、路径、证据优先级和下一步。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 竞业或劳动保密 | 劳动领域 |
| 数据合规主轴 | 数据隐私领域 |
| 反垄断或市场秩序主轴 | 竞争法领域 |
| 未成争许可转让出稿 | 审查起草领域（本窗搁置，只说明） |
| 只要侵权终局对照 | `评估侵权是否成立` |
| 只要商业秘密三要件 | `评估商业秘密权利与侵权` |
| 发警告或平台通知 | `准备侵权警告函` |
| 行为保全 | `准备知识产权行为保全申请` |
| 精算赔偿 | `测算知识产权损害赔偿` |
| 完整证据卷 | `建立知识产权证据案卷` |
| 起诉 | `提起知识产权民事一审` |
| 应诉 | `应对知识产权民事一审` |
| 行政投诉 | `准备知识产权行政查处投诉` |
| C 端 036／077／初检／登记／警告函／建设 | 大众专项，只分流不回改 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 竞业补偿、竞业违约金、劳动合同保密条款效力 | 劳动领域 |
| 个人信息影响评估、出境、网安等保 | 数据隐私领域 |
| 经营者集中申报、垄断协议、滥用支配 | 竞争法领域 |
| 假冒制售已进入刑事立案 | 刑事领域；本任务只留红旗 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

请求尚未闭合、需比较先发函还是先保全时正触发。主体、请求、论坛均确认且只要诉状时负触发。有注册证仍要求“直接认定侵权”时，先完成权属和对象对照接口，不改写成侵权原子终局。
