# 评估知识产权事项

## 任务目标

在明确、无利益冲突的单方立场下，形成“知识产权事项总体评估矩阵”：权利对象与权属链、程序状态、逐项请求／抗辩、路径入口、期限待核、金额区间与非金钱后果、证据缺口、对方最强解释和下一步。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：已出现使用、登记冲突、警告、下架、海关、行政或诉讼信号，用户仍需决定请求、抗辩、路径或下一步。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主轴是竞业限制或劳动关系内保密义务（劳动领域）；
- 主轴是个人信息、重要数据、跨境或网络安全体系（数据隐私）；
- 主轴是经营者集中、垄断协议、滥用支配地位或平台强制低于成本定价（竞争法）；
- 尚未成争，只要许可、转让或共存协议出稿（审查起草领域，本生产线搁置，只说明不实施）；
- 只要发送版警告或平台通知；
- 只要侵权终局对照、精算工作表或完整证据卷；
- 已决定起诉／应诉／行为保全／行政投诉并只要相应文书。

本任务不生成发送版警告函、可提交诉状或答辩、保全申请或行政投诉终稿，不给胜诉率。

## 建立评估坐标

确认：使用者与授权；单方立场；相对方及可能责任主体；权利类型与对象；法域；当前协商、通知、平台、海关、行政、诉讼或执行状态；机关文书作出与送达；对方已知主张；关键材料及缺失。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 权利文件或条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`V#` 评估版本；`E#` 发送／送达／使用凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1990 年《著作权法》同号旧义或 1993 年《反不正当竞争法》定义当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验权属、侵权类型、赔偿、期间、管辖和 2025 年反法条号；`search_practiced` 补路径与反例；特殊事实用 `search_case_by_fact`。不虚构案件系统。MCP 把 2025-10-15 已施行的反法标成尚未施行时，以施行日为准并记冲突。

工具不可用时继续事实、主体、程序文书状态和问题清单；请求／抗辩的法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 专项分流、权利对象和程序状态

先做劳动／隐私／竞争／审查起草分流，再固定权利类型、对象版本和程序表。口头转述和“已读”不写成已受理、已送达或期限已起算。

### 2. 权属链与请求抗辩假设

每个 `Q#` 独立列法律效果、成立条件、支持及不利事实、控制方、最强反方、主备位和互斥。停止侵害、赔偿、惩罚性、合理开支、确认不侵权不得合成一笔“知产权益”。权属不能回链时侵权请求标依据不足。

### 3. 路径、通知和期限

民事、行政、平台、海关、刑事交叉分列。仲裁条款出现时不得直接写成应起诉。期限分列时效、除斥、异议、答辩、海关确认，不混算。

### 4. 金额区间与非金钱后果

分项列损失、获利、许可费倍数、法定赔偿、惩罚性接口、合理开支。未知不写零。停止侵害、销毁、下架、刊登声明等非金钱结果单列。

### 5. 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。下一步按期限灭失、易失证据、能否改变 `Q#`、可逆性排序。发函、禁令、立案、精算标为转介。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或对象无法建立；用户坚持伪造权属、隐匿、威胁刑事或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为发函、精算、建卷、禁令、行政投诉或程序文书。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
