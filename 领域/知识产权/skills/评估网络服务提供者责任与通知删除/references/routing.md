# 边界与路由

## 正触发

平台或权利人需判断通知、必要措施和扩大部分。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 投诉终稿 | 准备平台投诉与通知删除材料 |
| 反通知终稿 | 应对平台下架与反通知 |
| 警告函 | 准备侵权警告函 |
| 数据合规或反垄断监管 | 对应领域 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 个人信息或网安义务整案 | 数据隐私 |
| 平台强制低价或滥用支配 | 竞争法 |
| 劳动 | 劳动领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

知道或应知侵权仍可能承担责任，不等于通知到达前一律免责。直播间与店铺身份不同，必要措施也可能不同。
