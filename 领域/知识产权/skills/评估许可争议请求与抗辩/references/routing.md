# 边界与路由

## 正触发

已成争的许可范围、费用、终止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争出稿 | 审查起草搁置 |
| 转让争议 | 评估转让权属争议 |
| 和解谈判参数 | 谈判知识产权和解方案 |
| 第三人侵权 | 评估侵权是否成立 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 标准必要专利滥用定价 | 竞争法 |
| 劳动、数据合规 | 对应领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

未备案许可在合同双方间仍可能有效。普通许可人通常不能单独告第三人。逾期未付费不当然使许可追溯消灭。
