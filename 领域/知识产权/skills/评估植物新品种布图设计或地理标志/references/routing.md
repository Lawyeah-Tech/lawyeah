# 边界与路由

## 正触发

主轴是品种权、集成电路布图或地理标志。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 普通专利对照 | 评估专利权利要求与被控技术方案对照 |
| 普通商标 | 评估商标近似与混淆可能性 |
| 刑事辩护 | 刑事领域 |
| 行政投诉普通商标专利 | 准备知识产权行政查处投诉 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 种子法刑事 | 刑事领域；细节待核 |
| 劳动、数据合规、反垄断 | 对应领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

品种权不是发明专利。地理标志可能是专门标志或集体／证明商标，路径不同。布图保护期和登记要求不同于著作权。
