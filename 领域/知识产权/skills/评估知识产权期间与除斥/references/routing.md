# 边界与路由

## 正触发

单独委托核验时效、除斥、异议、答辩或海关确认期。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 实体侵权结论 | 评估侵权是否成立 |
| 事项总图 | 评估知识产权事项 |
| 应诉答辩包 | 应对知识产权民事一审 |
| 海关扣留处置 | 处理海关扣留与确认侵权 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动仲裁时效或劳动除斥 | 劳动领域 |
| 数据合规整改期 | 数据隐私领域 |
| 反垄断调查期限 | 竞争法领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

持续销售多年不等于全部请求已过时效。电商法十五日不得写成诉讼时效。海关三个工作日确认不得写成民事答辩期。
