# 边界与路由

## 正触发

软件代码或文档权属或侵权对照。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 商业秘密源码 | 评估商业秘密权利与侵权 |
| 一般作品权属 | 评估作品权属与合作委托职务作品 |
| 开源合规整案 | 可留接口；本任务不做终局 |
| 实质性相似纯美术作品 | 评估作品实质性相似与接触 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动、数据合规、反垄断 | 对应领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

软件登记样本通常是部分源码，不能代表全部版本。GPL 传染主张不等于著作权权属转移。反向工程接口见被控抗辩。
