# 边界与路由

## 正触发

域名抢注、投诉或标识与域名冲突。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 代提交投诉 | 不实施；本任务只给路径 |
| 商标近似精评 | 评估商标近似与混淆可能性 |
| 仿冒装潢字号 | 评估仿冒与有一定影响的标识保护 |
| 纯注册手续 | 不收录 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动、数据合规、反垄断 | 对应领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

先注先得不是对抗恶意抢注的绝对抗辩。域名争议胜诉不等于商标侵权诉讼胜诉。
