# 边界与路由

## 正触发

出现假冒、制售、侵犯商业秘密刑责信号。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 无刑事信号的民事总图 | 评估知识产权事项 |
| 刑事辩护或控告终稿 | 刑事领域 |
| 普通行政投诉 | 准备知识产权行政查处投诉 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 定罪、控告、辩护、羁押 | 刑事领域 |
| 劳动、数据合规、反垄断 | 对应领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

商标近似民事侵权不等于假冒注册商标罪。民事调解不当然消灭已立案的公诉。商业秘密刑事门槛与民事三要件不同。
