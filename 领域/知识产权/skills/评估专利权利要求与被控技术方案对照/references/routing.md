# 边界与路由

## 正触发

需特征一一对应或等同。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 无效终稿 | 准备专利无效宣告 |
| FTO 总表 | 评估专利自由实施风险 |
| 总体侵权多种权利 | 评估侵权是否成立 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动、数据合规、反垄断 | 对应领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

说明书实施例不是保护范围本身。从属权利要求更窄，独立项不落入则从属通常不落入。
