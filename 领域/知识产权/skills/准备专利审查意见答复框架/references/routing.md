# 边界与路由

## 正触发

收到审查意见，需答复策略；正式改权项交代理。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 申请前风险 | 评估专利申请公开与权属风险 |
| 无效答辩 | 应对专利无效宣告 |
| 权项终稿 | 专利代理 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动、数据合规、反垄断 | 对应领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

删掉区别技术特征可能克服对比文件，也可能导致修改超范围或保护范围不可接受。创造性意见不是必须全面认输。
