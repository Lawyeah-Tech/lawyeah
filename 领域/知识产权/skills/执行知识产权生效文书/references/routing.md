# 边界与路由

## 正触发

持停止侵权或金钱判决未获履行。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未生效上诉 | 提起知识产权案件上诉 |
| 再审 | P2，unavailable |
| 被执行异议 | P2 resist-enforcement，unavailable |
| 重审实体 | 不实施 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动、数据合规、反垄断执行 | 对应领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

停止侵权主文需要监督，不是自动完成。迟延履行金与迟延履行利息分列。案外人异议不在本任务实体裁判。
