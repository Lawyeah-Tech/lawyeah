# 边界与路由

## 正触发

需判断接触加实质性相似。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 权属 | 评估作品权属与合作委托职务作品 |
| 合理使用 | 评估合理使用与法定许可 |
| 软件代码对照 | 评估计算机软件著作权与权属 |
| 总体侵权多权利 | 评估侵权是否成立 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动、数据合规、反垄断 | 对应领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

题材撞车不是侵权。后作品水平更高不否定复制。平台推荐算法导致“看见过”不等于法律上的接触已经证明。
