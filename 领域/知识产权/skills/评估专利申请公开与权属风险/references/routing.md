# 边界与路由

## 正触发

拟申请，需判断公开风险、权属和是否应交专利代理。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 撰写权项 | 专利代理；本任务不实施 |
| 审查意见答复 | 准备专利审查意见答复框架 |
| C 端初检包 | 只分流不回改 |
| 商业秘密建设 | 建设商业秘密权利基础与保护措施 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 职务发明奖励报酬劳动争议 | 劳动领域可并行，权属留本任务 |
| 数据合规或出口管制 | 数据隐私或升级停止 |
| 反垄断 | 竞争法领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

交底书不等于权利要求。先发论文再申请通常丧失新颖性，宽限期只在法定情形且须核验。软件方法可能既是专利客体风险又是软件著作权对象。
