# 专利申请前风险评估方法

不撰写权利要求。不实施 C 端初检包。已公开不得写成新颖性已具备。MCP 把 2025-10-15 已施行的《反不正当竞争法》标成尚未施行时，以施行日为准并记冲突。旧条号（专利法第六十五条、著作权法第四十九条、反法第九条当现行定义）记噪声。search_law 返回已失效《合同法》时不得写入 L#。

## 节点 0　分流

用户要权项终稿：停止撰写，分流专利代理。只要大众查新表：C 端初检只分流。已有审查意见：转答复原子。技术信息要以秘密保护且不申请：转商业秘密建设。国家秘密或出口管制：停止并升级，不按普通申请硬做。

## 节点 1　公开史

逐项登记：论文、会议、预印本、展会、招标、销售、开源仓库、宣传视频的日期与内容边界。若公开日早于拟申请日且不属于宽限期法定情形：新颖性标现有依据不支持或高风险依据不足，不得教用户“改几个参数就当没公开”。宽限期（中国政府主办或承认的展会、规定的学术会议、他人未经申请人同意泄露等）必须逐项核验并在申请时声明，未核验字段停止。

## 节点 2　权属

职务发明法定归属与约定奖励分列。共同完成人漏列将导致权属无效风险，必须列出已知完成人。委托开发无约定时申请权归属运行时核验。申请人与完成人冲突：申请主体闸关闭至澄清。

## 节点 3　保密审查

任何单位或个人将在中国完成的发明或实用新型向国外申请：保密审查红旗。未完成审查不得建议直接向境外提交。本任务不填写外国申请书。

## 节点 4　客体与代理

智力活动规则、疾病诊断治疗方法等客体风险只标接口。权利要求撰写、说明书充分公开和单一性必须由专利代理完成。本任务可列出交底应覆盖的技术问题、方案、效果栏目，但不写成权利要求文本。

## 节点 5　与秘密双轨

同一技术方案一边准备公开申请一边当商业秘密对外许可：必须提示公开后秘密性可能消灭。禁止为申请而伪造实验数据。
## 补充判断闸

若公开日早于拟申请日且不属于宽限期法定情形：新颖性标不支持或高风险依据不足，不得教“改几个参数当没公开”。宽限期必须逐项核验并在申请时声明，未核验字段停止。若申请人与完成人冲突：申请主体闸关闭。向国外申请或国际申请未完成保密审查：境外路径停止。同一方案一边公开申请一边当商业秘密对外许可：必须提示秘密性可能消灭。不撰写权利要求。
## 回链、期限与停止清单

本任务成果是「评估专利申请公开与权属风险」。核心目标：拟申请，需判断公开风险、权属和是否应交专利代理；申请方。排除：不实施 C 端初检材料包；不撰写权利要求。每一条会改变判断、期限或路径的陈述必须回链 `S#/D#/A#/R#/C#/L#/E#`。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然结果或唯一必得金额。未知金额不写零。

若立场或授权不明、利益冲突未解、基础主体或对象无法建立：整体停止策略输出。若法域、日期、文书送达或动态规则未核验：仅停止依赖该规则的法律结论、期限或机关路径字段，事实编目继续。若用户坚持伪造、隐匿、威胁刑事或违法取证：该部分整体停止。

期限每行只对应一种期间类型和一个起算事件。作出日与送达日分列。口头转述、“已读”、微信回复不得写成已受理、已送达或期限已起算。日期冲突则并行情景并字段停止，禁止混算成唯一截止日。

劳动竞业或劳动保密、数据合规、反垄断或市场秩序主轴整案转出，不把专项规则写入本任务结论。未成争许可、转让或共存出稿：审查起草本窗搁置，只说明不实施。未安装的相邻原子或 P2 输出 `unavailable`，不得由名称相近的 Skill 代做。C 端相邻商品只分流不回改。
