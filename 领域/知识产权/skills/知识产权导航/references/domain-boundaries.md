# 知识产权领域边界

本表只说明归属。当前安装包是。每次路由先核对 [当前能力地图](capability-map.md)；未安装的 P2 入口输出 `unavailable`。

| 相邻 | 本包入口 | 转出 |
| --- | --- | --- |
| 劳动 | 商业秘密权利基础、侵权和损失 | 竞业限制、劳动关系内保密义务 |
| 数据隐私 | 作品、标识、技术信息作为知识产权客体 | 个人信息、重要数据、数据跨境、网络安全体系 |
| 竞争法 | 仿冒混淆、商业秘密 | 经营者集中、垄断协议、滥用支配地位、以市场秩序为主的不正当竞争 |
| 合同审查与起草 | 无。未成争只要许可、转让或共存出稿：本窗搁置，只说明不实施 | 审查起草领域（用户单独策略） |
| 刑事 | 评估中的刑民交叉只标红旗 | 定罪、控告、辩护 |
| 行政争议 | 行政查处投诉实体材料 | 行政复议诉讼文书主成果 |
| C 端 036 | 专业总图或对照，不降成平台初评 | 大众第一轮内容商标评估 |
| C 端 077 / 专利申请初检 / 版权登记 | 专业确权争议或核验接口 | 大众申请或登记材料包 |
| C 端警告函 / 商业秘密建设 | 专业警告包或泄密后评估 | 大众发函或预防建设 |
| C 端 011 / 012 | 专业起诉或应诉包 | 大众网上立案或民事答辩 |

一般内容或商标夹带劳动、数据或竞争背景时，专项段只分流，不把专项规则写入本包结论。
