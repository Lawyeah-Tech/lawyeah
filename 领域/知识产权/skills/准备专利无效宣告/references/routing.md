# 边界与路由

## 正触发

要以现有技术等无效对方专利。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 应对无效 | 应对专利无效宣告 |
| 民事现有技术抗辩 | 评估被控侵权抗辩路径 / assess-infringement |
| 确权行政诉讼 | P2，unavailable |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动、数据合规、反垄断 | 对应领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

提出无效不等于专利已无效。对比文件晚于申请日不能当现有技术。评价报告不能替代无效决定。
