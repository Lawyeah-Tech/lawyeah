# 准备知识产权行为保全申请

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1990 年《著作权法》同号旧义或 1993 年《反不正当竞争法》定义当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的申请方立场下，形成“知识产权行为保全申请包”：稳定性、难以弥补损害、利益衡量、公共利益、担保与反担保、申请书框架和错误申请赔偿风险。不保证裁定，不执行送达。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、评估、测算和证据清单。

## 工作边界

正触发：需立即停止制造、销售、许诺销售、传播或即将实施的侵权行为，用户需要行为保全申请，而不是只要财产保全或起诉状。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要财产保全终稿；
- 只要起诉状；
- 已被裁定、要应对保全；
- 权利明显不稳定且用户拒绝披露评价报告或无效风险；
- 竞业、数据合规或反垄断主轴；

本任务不保证裁定，不教唆违反已生效裁定，不把申请写成已经停止侵权。

## 建立工作坐标

确认：使用者与授权；单方立场；相对方；权利类型与对象；法域；当前通知、平台、行政、诉讼或执行状态；关键材料及缺失。拟保全行为范围、起诉或仲裁准备状态、担保能力、实用新型／外观评价报告。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 权利文件或条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`V#` 版本；`E#` 发送／送达／使用凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验法释〔2018〕21 号、专利法／商标法／著作权法诉前停止侵害条款、民诉保全期限。

MCP 把 2025-10-15 已施行的《反不正当竞争法》标成尚未施行时，以施行日为准并记冲突。

工具不可用时继续事实、对象和问题清单；法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流与保全对象

财产保全另转。被申请人应对走 respond 原子。明确责令停止的具体行为，禁止“全行业封杀”。

### 2. 权利稳定性

注册／授权状态、无效撤销程序、评价报告。实用新型和外观设计稳定性不足时字段停止或限制申请范围。

### 3. 难以弥补与衡量

按法释〔2018〕21 号第 7 条逐项：事实基础、难以弥补或难以执行、损益比较、公共利益。商誉或市场渠道变化可列，但不得写成必然无法弥补。

### 4. 担保与错误申请

担保方式、额度和反担保。申请错误可能赔偿。展会或时效性销售可标紧迫，仍须回链事实。

### 5. 申请框架与起诉衔接

诉前保全后须在核验后的法定期限内起诉；未核验则期限字段停止，不得写成一律 15 日或 30 日。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或对象无法建立；用户坚持伪造、隐匿、威胁刑事或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为财产保全、应诉或保证裁定。
