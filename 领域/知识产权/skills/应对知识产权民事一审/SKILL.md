# 应对知识产权民事一审

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1990 年《著作权法》同号旧义或 1993 年《反不正当竞争法》定义当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的被告立场下，形成首次应诉答辩包：答辩期限卡、原告请求拆解、答辩草稿、管辖／仲裁／无效红旗、反诉或确认不侵权接口和证据意见。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、评估、测算和证据清单。

## 工作边界

正触发：知产被告已收到起诉状或应诉通知，需要答辩和抗辩红旗，而不是只要一份管辖异议终稿或大众答辩包。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 用户实为原告；
- 劳动应诉；
- 只要管辖异议终稿且无实体；
- 只要和解方案；
- 反垄断应诉主轴；

本任务不自动生成无效宣告终稿，不保证免于缺席或胜诉，不指导隐匿证据。

## 建立工作坐标

确认：使用者与授权；单方立场；相对方；权利类型与对象；法域；当前通知、平台、行政、诉讼或执行状态；关键材料及缺失。每份机关文书的作出日、送达日、送达方式和效力凭证。作出日与送达日不明时期限字段停止。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。口头转述和“已读”不写成已受理、已送达或期限已起算。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 权利文件或条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`P#` 诉讼或投诉请求；`J#` 管辖连结点；`K#` 期限卡；`V#` 版本；`E#` 发送／送达／使用凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验答辩期间、管辖异议期间、应诉管辖、无效对诉讼中止的影响。

MCP 把 2025-10-15 已施行的《反不正当竞争法》标成尚未施行时，以施行日为准并记冲突。

工具不可用时继续事实、对象和问题清单；法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 被告立场与材料权限

原告材料与己方内部文件分权登记。不得用原告未向被告披露的秘密撰写答辩。

### 2. 期限卡

每份文书单独一行。普通程序以收到起诉状副本之日起算。已读不等于送达。

### 3. 请求拆解与红旗

承认、否认、不知、抗辩分列。管辖、仲裁、权利无效、合法来源、先用、权利用尽先做红旗。

### 4. 答辩草稿与反诉接口

反诉或另行无效只评估条件和中止风险，不自动生成无效终稿。

### 5. 证据与禁止

不利证据必须进入最强反方。拒绝隐匿和虚假陈述。C 端 012 只分流。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或对象无法建立；用户坚持伪造、隐匿、威胁刑事或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为管辖异议终稿、无效终稿、二审或和解协议正文。
