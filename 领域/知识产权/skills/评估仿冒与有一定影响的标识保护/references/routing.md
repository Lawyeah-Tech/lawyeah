# 边界与路由

## 正触发

主目标是制止混淆仿冒，而非反垄断。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 注册商标近似 | 评估商标近似与混淆可能性 |
| 域名争议程序 | 评估域名与标识冲突 |
| 反垄断或数据抓取市场秩序 | 竞争法领域 |
| 商业秘密 | 评估商业秘密权利与侵权 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 经营者集中、垄断协议、滥用支配、强制低于成本 | 竞争法 |
| 数据抓取作为市场秩序主轴 | 竞争法 |
| 数据合规 | 数据隐私 |
| 劳动 | 劳动领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

有一定影响不是驰名。字号登记在先不当然击败在后有一定影响的商品装潢，须看混淆。
