# 准备知识产权行政查处投诉

## 任务目标

在明确、无利益冲突的主张方立场下，形成“知识产权行政查处投诉包”：主管机关与管辖、违法事实、证据清单、与民事／刑事并行提示和提交前核验。不保证立案或处罚。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、评估、测算和证据清单。

## 工作边界

正触发：拟向市场监督管理部门或管理专利工作的部门等投诉查处商标、专利、著作权或商业秘密侵权行为。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 反垄断调查或经营者集中；
- 只要民事起诉状；
- 主成果是行政复议或行政诉讼文书；
- 劳动监察主轴；
- 用户要保证处罚或查封；

本任务不保证立案处罚，不代提交，不把行政投诉写成已经认定侵权。

## 建立工作坐标

确认：使用者与授权；单方立场；相对方；权利类型与对象；法域；当前通知、平台、行政、诉讼或执行状态；关键材料及缺失。被投诉人住所或行为地、权利文件、侵权实物或网页、是否同时民事起诉或报案。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。口头转述和“已读”不写成已受理、已送达或期限已起算。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 权利文件或条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`P#` 诉讼或投诉请求；`J#` 管辖连结点；`K#` 期限卡；`V#` 版本；`E#` 发送／送达／使用凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1990 年《著作权法》同号旧义或 1993 年《反不正当竞争法》定义当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验商标法第 60 条、专利行政裁决办法、2025 年反法第 26 条、著作权行政处罚规则现行文本。

MCP 把 2025-10-15 已施行的《反不正当竞争法》标成尚未施行时，以施行日为准并记冲突。

工具不可用时继续事实、对象和问题清单；法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流与主管机关

反垄断转竞争法。专利侵权行政裁决与商标／商业秘密市监查处分列。复议诉讼文书转行政领域。

### 2. 管辖与受理条件

专利侵权纠纷由侵权行为地或被请求人住所地管理部门管辖（国知局令第 81 号，须核验）。商标／商业秘密按市监层级核验。

### 3. 事实与请求

写清权利、被控行为、持续状态。请求责令停止、没收、罚款接口须回链条文，不编造罚款必得额。

### 4. 与民事／刑事并行

行政与民事可并行；已给予行政处罚的，法院可不再民事制裁（商标解释第 21 条口径）。刑事信号只红旗。

### 5. 投诉草稿

只交付提交前稿。不代提交，不保证立案。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或对象无法建立；用户坚持伪造、隐匿、威胁刑事或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为复议诉讼文书、民事起诉或反垄断调查。
