# 边界与路由

## 正触发

己方商标被异议，需答辩。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 提出异议 | 准备商标异议材料 |
| 应对无效 | 应对商标无效宣告 |
| 民事应诉 | 应对知识产权民事一审 |
| 撤三答辩 | 应对商标撤三 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动、数据合规、反垄断 | 对应领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

异议答辩不是民事答辩。未按期答辩可能仅依现有材料裁决，不得写成“视为认可全部异议理由”除非已核验条文如此。
