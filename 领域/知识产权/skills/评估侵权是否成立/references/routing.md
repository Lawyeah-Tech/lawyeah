# 边界与路由

## 正触发

权属可回链或仅差已核验登记查询，权利对象和被控使用已可识别，需要对照是否落入保护范围。权属不能回链时本任务只做缺口编目，不输出侵权终局。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要总图 | `评估知识产权事项` |
| 商业秘密三要件 | `评估商业秘密权利与侵权` |
| 发警告或平台通知 | `准备侵权警告函` |
| 起诉 / 应诉 | `提起知识产权民事一审` / `应对知识产权民事一审` |
| 竞业或劳动保密 | 劳动领域 |
| 数据合规 / 反垄断 | 对应领域 |
| C 端 036 | 大众初评，只分流 |

## 易混

“有注册证就是侵权”负触发到本任务的范围节点，不得跳过对照。用户要发函：对照可做，发送稿转警告原子。
