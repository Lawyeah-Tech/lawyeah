# 边界与路由

## 正触发

要选知产法院、中院或普通院，或对方提管辖异议。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 完整起诉包 | 提起知识产权民事一审 |
| 完整应诉包 | 应对知识产权民事一审 |
| 劳动仲裁 | 劳动领域 |
| 确认不侵权管辖 | 提起确认不侵权之诉 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动争议仲裁前置 | 劳动领域 |
| 反垄断行政执法或经营者集中 | 竞争法领域 |
| 数据出境评估管辖 | 数据隐私领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

知产法院不是所有商标纠纷的唯一法院。网络侵权服务器所在地不是当然连结点，须核验现行解释。协议约定“由甲方所在地法院”在格式条款场景可能无效，不得直接写成已取得管辖。
