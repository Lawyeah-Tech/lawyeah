# 边界与路由

## 正触发

需单独做标识、商品类似和混淆。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 总体侵权终局 | 评估侵权是否成立 |
| 仿冒有一定影响标识 | 评估仿冒与有一定影响的标识保护 |
| 异议或无效书 | 对应商标行政原子 |
| 驰名按需认定 | P2，unavailable |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动、数据合规、反垄断 | 对应领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

区分表同类不等于必然类似。旗舰店关键词投放可能混淆但要单独描述使用形态。驰名跨类不在本任务打开认定。
