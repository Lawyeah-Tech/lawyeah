# 边界与路由

## 正触发

己方商标被撤三，需使用证据或正当理由。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 提出撤三 | 准备商标撤三申请 |
| 无效答辩 | 应对商标无效宣告 |
| 民事应诉 | 应对知识产权民事一审 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动、数据合规、反垄断 | 对应领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

续展成功不等于已使用。内部样品或仅转让商标本身通常不够。许可未备案不当然否定被许可人使用的事实，但对抗和证明力须核验。
