# 边界与路由

## 正触发

拟维权或被诉，需判断权利被无效或撤销的风险。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 商标无效终稿 | 准备商标无效宣告 |
| 专利无效终稿 | 准备专利无效宣告 |
| 撤三申请 | 准备商标撤三申请 |
| 侵权对照终局 | 评估侵权是否成立 |
| 反诉或另行无效对诉讼影响 | 评估反诉或另行无效对诉讼的影响 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动、数据合规、反垄断 | 对应领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

有注册证不等于稳定。实用新型有评价报告不等于专利有效。提出无效不等于诉讼必然中止。
