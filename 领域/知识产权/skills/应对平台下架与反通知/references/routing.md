# 边界与路由

## 正触发

商品或内容被下架，被通知方需反通知或声明。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 投诉方通知 | 准备平台投诉与通知删除材料 |
| 站外回函 | 应对侵权警告函或律师函 |
| 平台责任评估 | 评估网络服务提供者责任与通知删除 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动、数据合规、反垄断 | 对应领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

提交声明不等于必然恢复。权利人在十五日内起诉后平台可能维持措施。
