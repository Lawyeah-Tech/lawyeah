# 边界与路由

## 正触发

主张方权属可回链，需要发送前警告函，而不是只要平台投诉终稿。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要平台投诉或通知删除终稿 | `准备平台投诉与通知删除材料`（未安装则 `unavailable`） |
| 被发函一方 | `应对侵权警告函或律师函` 或 C 端 093 |
| 只要对照或总图 | `评估侵权是否成立` / `assess-ip-matter` |
| 行为保全 | `准备知识产权行为保全申请` |
| 起诉 | `提起知识产权民事一审` |
| C 端普通内容商标发函 | 只分流，不回改 |

## 易混

权属未闭合却要求“先发着”：不打开终稿闸。用户要求写“不删就追究刑事责任”：整体停止该请求，不提供替换威胁句。
