# 准备侵权警告函

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1990 年《著作权法》同号旧义或 1993 年《反不正当竞争法》定义当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的权利主张方立场下，于权属可回链时形成“发送前侵权警告函包”：发送闸、发送前警告函、错误通知风险、送达设计。平台下架通知只给路径接口，终稿转 `准备平台投诉与通知删除材料`（未安装则 `unavailable`）。本任务不执行发送，不定侵权成立，不威胁刑事。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、评估、测算和证据清单。

## 工作边界

正触发：权属可回链或仅差可核验登记查询，用户需要发送前侵权警告函，而不是只要评估、诉状或只要平台投诉终稿。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 用户是被发函一方；
- 权属不能回链仍要可发送终稿；
- 只要平台投诉或通知删除终稿；
- 只要侵权对照或总图；
- 已决定起诉或保全并只要相应文书；
- 竞业、数据合规或反垄断主轴；

本任务不执行发送，不伪造送达，不把准备起诉写成已经构成侵权。

## 建立工作坐标

确认：使用者与授权；单方立场；相对方；权利类型与对象；法域；当前通知、平台、行政、诉讼或执行状态；关键材料及缺失。拟签发主体、拟发送日、约定或平台渠道、被控对象原文或可定位地址。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 权利文件或条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`V#` 版本；`E#` 发送／送达／使用凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典第 1195–1196 条、电子商务法第 42–45 条、法释〔2020〕9 号；`search_template` 只借通知栏目。

MCP 把 2025-10-15 已施行的《反不正当竞争法》标成尚未施行时，以施行日为准并记冲突。

工具不可用时继续事实、对象和问题清单；法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 发送闸与权属

权属不能回链或缺少被控原文／定位时不打开可发送终稿闸。

### 2. 路径选择

警告函与平台通知可并行。电商法通知—声明—十五日与民法典第 1195–1196 条合理期限不得互换。

### 3. 发送前正文

只写已支持的主体、对象、行为描述、成比例请求和异议／反通知窗口。逐句回链。禁止刑事威胁和“已经构成侵权”。

### 4. 错误通知与反通知

必须展示错误／恶意通知责任和声明后等待规则。法释〔2020〕9 号 20 工作日不是默认等待期。

### 5. 送达与状态词

通知状态只用草案／待发送／已发送待证明到达／停止。已读不等于到达。不执行发送。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或对象无法建立；用户坚持伪造、隐匿、威胁刑事或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：依法不能打开发送闸；主目标已变为平台投诉终稿、应诉、起诉或刑事威胁。
