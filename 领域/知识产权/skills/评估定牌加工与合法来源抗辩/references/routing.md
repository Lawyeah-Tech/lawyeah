# 边界与路由

## 正触发

代工出口或销售者主张合法来源。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 总体抗辩地图 | 评估被控侵权抗辩路径 |
| 先用或权利用尽 | 评估在先使用与权利用尽 |
| 加工合同出稿 | 审查起草搁置 |
| 完整应诉 | 应对知识产权民事一审 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动、数据合规、反垄断 | 对应领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

有进货发票不等于已尽合理注意。境外商标授权在中国贴牌出口仍可能落入中国商标权。合法来源抗辩成功通常不自动消灭停止请求。
