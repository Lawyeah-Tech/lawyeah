# 边界与路由

## 正触发

需主张故意且情节严重。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 普通测算 | 测算知识产权损害赔偿 |
| 完整起诉 | 提起知识产权民事一审 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动、数据合规、反垄断惩罚性 | 对应领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

收到过警告仍继续可能支持故意，但不是唯一标准。行政处罚次数是情节因素，不自动等于法定最高倍。
