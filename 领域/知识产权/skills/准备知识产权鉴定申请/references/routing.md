# 边界与路由

## 正触发

需技术或作品对比鉴定。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 自行公证取证 | 保全网页公证与侵权购买取证 |
| 证据保全 | 准备证据保全申请 |
| 权项对照法律判断 | 评估专利权利要求与被控技术方案对照 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动、数据合规、反垄断 | 对应领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

技术调查官意见不是鉴定意见。单方鉴定可能被重新鉴定。鉴定费负担另核。
