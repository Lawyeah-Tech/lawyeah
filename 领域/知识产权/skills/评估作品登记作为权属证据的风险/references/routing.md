# 边界与路由

## 正触发

争议前判断登记能否补强权属表面证据。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| C 端登记包 | 只分流不回改 |
| 权属终局 | 评估作品权属与合作委托职务作品 |
| 软件对照 | 评估计算机软件著作权与权属 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动保密或竞业 | 劳动领域 |
| 数据合规、反垄断 | 对应领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

登记日期晚于争议发生可能证明力弱。他人抢先登记不消灭真实作者权利，但增加举证负担。
