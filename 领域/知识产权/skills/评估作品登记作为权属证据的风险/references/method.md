# 作品登记风险评估方法

登记不等于权利成立。不实施 C 端登记包。不代办理。MCP 把 2025-10-15 已施行的《反不正当竞争法》标成尚未施行时，以施行日为准并记冲突。旧条号（专利法第六十五条、著作权法第四十九条、反法第九条当现行定义）记噪声。search_law 返回已失效《合同法》时不得写入 L#。

## 节点 0　分流

用户只要填表清单：C 端登记包只分流。权属已成争要终局路径：转 `assess-copyright-ownership`。软件源码既要登记又要比对：登记风险本任务，对照转软件原子。

## 节点 1　自动保护

确认法域为中国大陆：著作权自作品创作完成之日起产生，不以登记为要件。用户认为“不登记就没有版权”：纠正并写入来源。境外登记（如外国版权局）只作完成时间辅助，不写成中国权利成立条件。

## 节点 2　证明力

作品登记证书通常可作为权属表面证据，对方提出相反证据仍可推翻。若创作底稿、源文件时间戳已经充分：登记的边际证明力可能有限，标依据不足是否值得作为优先动作。若拟登记主体与真实作者不一致：登记可能固化错误，判断为现有依据不支持仓促登记。

## 节点 3　权属缺口闸

职务、委托、视听、合作未约定时，先评估权属再决定以谁的名义登记。共同作品一方单独登记：冲突红旗。将公有领域素材或他人作品登记：停止并禁止。

## 节点 4　诉讼接口

即使已登记，侵权诉讼仍通常需要接触和实质性相似的表达比对。登记样本与诉讼主张版本不一致：减损证明力。登记信息错误更正程序只标接口。

## 节点 5　纪律

不保证登记通过或对抗第三人。不指导倒签完成日期。不提交完整未发表作品全文到不可控渠道。
## 补充判断闸

中国大陆著作权自创作完成产生，不以登记为要件；用户认为“不登记就没有版权”必须纠正。若拟登记主体与真实作者不一致：判断为现有依据不支持仓促登记。共同作品一方单独登记：冲突红旗。将公有领域素材或他人作品拿去登记：停止并禁止。登记样本与诉讼主张版本不一致会减损证明力。不代办理，不实施 C 端填表包，不保证对抗第三人。
