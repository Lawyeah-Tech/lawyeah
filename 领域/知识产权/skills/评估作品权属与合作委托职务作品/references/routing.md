# 边界与路由

## 正触发

争作者、职务、委托、视听作品归属。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 劳动保密竞业 | 劳动领域 |
| 登记利弊 | 评估作品登记作为权属证据的风险 |
| 实质性相似 | 评估作品实质性相似与接触 |
| 软件代码 | 评估计算机软件著作权与权属 |
| 一般职务发明含专利 | 评估权属与职务成果归属 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动保密或竞业 | 劳动领域 |
| 数据合规、反垄断 | 对应领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

署名为单位不等于个人不是作者。委托付款不等于委托作品归委托人。视听作品中的剧本、音乐可单独权属。
