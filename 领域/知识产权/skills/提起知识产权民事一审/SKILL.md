# 提起知识产权民事一审

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1990 年《著作权法》同号旧义或 1993 年《反不正当竞争法》定义当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的原告立场下，形成可复核、不代提交的“知识产权民事一审起诉包”：起诉状草稿、分项诉讼请求、专门管辖连结点、证据目录、惩罚性接口和保全红旗。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、评估、测算和证据清单。

## 工作边界

正触发：用户已决定向人民法院提起知识产权民事一审，且无表面有效的仲裁协议阻挡或阻挡已被可回链证据排除。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 用户实为被告；
- 劳动或反垄断主轴；
- 只要大众网上立案包且请求论坛已闭合；
- 仲裁条款表面有效且未排除仍要求直接起诉；
- 只要行为保全终稿；

本任务不代提交、不保证受理或胜诉，不写保全申请终稿。

## 建立工作坐标

确认：使用者与授权；单方立场；相对方；权利类型与对象；法域；当前通知、平台、行政、诉讼或执行状态；关键材料及缺失。原告适格与许可起诉资格、被告、权利文件、被控行为地、仲裁条款及排除证据。已有案号或受理凭证时停止生成起诉入口。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。口头转述和“已读”不写成已受理、已送达或期限已起算。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 权利文件或条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`P#` 诉讼或投诉请求；`J#` 管辖连结点；`K#` 期限卡；`V#` 版本；`E#` 发送／送达／使用凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民诉起诉条件、法释〔2022〕13 号管辖、许可人起诉资格、惩罚性解释。

MCP 把 2025-10-15 已施行的《反不正当竞争法》标成尚未施行时，以施行日为准并记冲突。

工具不可用时继续事实、对象和问题清单；法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、起诉决定和仲裁闸

劳动／反垄断整案转出。仲裁条款出现时不得直接写应起诉。

### 2. 主体与分项请求

停止侵害、销毁、赔偿、惩罚性、合理开支、消除影响分列。独占／排他／普通被许可人起诉资格按解释核验。

### 3. 管辖

侵权行为地、储藏地、查封扣押地、被告住所地、知产法院和级别管辖分列。材料不足不选定唯一法院。

### 4. 证据目录与保全红旗

证据绑定请求。保全只做红旗。诉前保全后须在核验期限内起诉。

### 5. 起诉状与提交核验

只交付草案。C 端 011 只作渠道分流，不降成大众立案包。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或对象无法建立；用户坚持伪造、隐匿、威胁刑事或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为保全终稿、应诉或代提交。
