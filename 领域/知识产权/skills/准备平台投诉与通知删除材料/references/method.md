# 平台投诉通知方法

不保证下架。不执行发送。权属不能回链不打开待发送闸。MCP 把 2025-10-15 已施行的《反不正当竞争法》标成尚未施行时，以施行日为准并记冲突。旧条号（专利法第六十五条、著作权法第四十九条、反法第九条当现行定义）记噪声。search_law 返回已失效《合同法》时不得写入 L#。

## 节点 0　分流

只要站外函：转警告原子。被投诉方：转反通知。只要责任定性：转平台责任原子。劳动／隐私／竞争转出。

## 节点 1　发送闸

同时满足：主张方立场；权属链闭合或仅差已核验登记查询；被控链接或 SKU 可定位且已保全；请求限于删除、断开、下架特定对象；已展示错误通知风险；未要求刑事威胁。缺任一项：只给不可发送占位。

## 节点 2　要素

通知包含：权利人身份、权属初步证明、侵权事实定位、联系方式。平台额外表格只借鉴栏目。禁止写入 DMCA 伪证宣誓或外国制定法作为中国平台的唯一依据。

## 节点 3　等待规则

电商平台：声明后十五日。其他网络服务：合理期限，司法解释最长不超过 20 工作日的例外不得写成默认。两者不得互换。

## 节点 4　错误通知

通知错误致损承担民事责任；恶意错误通知加重。权属未核实的批量投诉标高风险。专利或实用新型建议提示评价报告接口。

## 节点 5　纪律

不代提交。已读不等于平台已采取必要措施。禁止对明显不侵权内容施压下架。
## 补充判断闸

权属不能回链或链接不能定位：不打开待发送闸。请求必须限于删除、断开或下架特定对象，禁止要求全店封杀或交出账号。专利或实用新型建议提示评价报告接口。批量投诉缺少逐条定位：错误通知风险升高。禁止写入 DMCA 伪证宣誓作为中国平台的唯一依据。不代提交。已读不等于平台已采取必要措施。不保证下架。
## 回链、期限与停止清单

本任务成果是「准备平台投诉与通知删除材料」。核心目标：对象在平台，需通知删除；主张方。排除：与警告函可并行；不保证下架。每一条会改变判断、期限或路径的陈述必须回链 `S#/D#/A#/R#/C#/L#/E#`。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然结果或唯一必得金额。未知金额不写零。

若立场或授权不明、利益冲突未解、基础主体或对象无法建立：整体停止策略输出。若法域、日期、文书送达或动态规则未核验：仅停止依赖该规则的法律结论、期限或机关路径字段，事实编目继续。若用户坚持伪造、隐匿、威胁刑事或违法取证：该部分整体停止。

期限每行只对应一种期间类型和一个起算事件。作出日与送达日分列。口头转述、“已读”、微信回复不得写成已受理、已送达或期限已起算。日期冲突则并行情景并字段停止，禁止混算成唯一截止日。

劳动竞业或劳动保密、数据合规、反垄断或市场秩序主轴整案转出，不把专项规则写入本任务结论。未成争许可、转让或共存出稿：审查起草本窗搁置，只说明不实施。未安装的相邻原子或 P2 输出 `unavailable`，不得由名称相近的 Skill 代做。C 端相邻商品只分流不回改。

交付前检查：`depends-on` 为空；不把已失效《合同法》或 1990 年著作权法同号旧义、1993 年反法定义写入现行 `L#`；2025-10-15 已施行的《反不正当竞争法》以施行日为准。本成果不是胜诉承诺，也不是代提交。
