# 边界与路由

## 正触发

对象在平台，主张方需通知删除。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 站外警告函 | 准备侵权警告函 |
| 平台责任评估 | 评估网络服务提供者责任与通知删除 |
| 反通知 | 应对平台下架与反通知 |
| 权属不能回链 | 先补权属 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动、数据合规、反垄断 | 对应领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

平台提交成功不等于已下架。批量投诉缺少逐条定位会触发错误通知风险。
