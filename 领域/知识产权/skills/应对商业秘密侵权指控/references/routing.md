# 边界与路由

## 正触发

已被警告或起诉侵犯商业秘密。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 主张方评估 | 评估商业秘密权利与侵权 |
| 建设措施 | 建设商业秘密权利基础与保护措施 |
| 竞业 | 劳动领域 |
| 民事完整应诉 | 应对知识产权民事一审 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动竞业 | 劳动领域 |
| 刑事立案 | 刑事领域，本任务只留红旗 |
| 数据合规、反垄断 | 对应领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

未签保密协议不等于当然无措施，但对方措施不足是抗辩。员工一般知识技能不得被对方标成单位秘密。
