# 边界与路由

## 正触发

争职务作品或发明、委托、合作、继受，需要权属链。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 劳动保密或竞业 | 劳动领域 |
| 作品权属且仅著作权争点 | 评估作品权属与合作委托职务作品 |
| 软件代码对照 | 评估计算机软件著作权与权属 |
| 未成争转让出稿 | 审查起草（本窗搁置） |
| 转让未登记争议已成争 | 评估转让权属争议 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动关系内保密义务、竞业 | 劳动领域 |
| 数据合规 | 数据隐私领域 |
| 反垄断 | 竞争法领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

发了工资不等于单位当然享有作品或专利权。登记在个人名下不等于个人终局权利人。付款给工作室不等于委托约定已覆盖权属。
