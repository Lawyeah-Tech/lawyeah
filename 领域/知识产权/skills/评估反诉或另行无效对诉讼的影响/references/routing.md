# 边界与路由

## 正触发

被告拟无效或确认不侵权，评估对诉讼影响。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 无效终稿 | 准备专利无效宣告 / prepare-trademark-invalidation |
| 确认不侵权起诉 | 提起确认不侵权之诉 |
| 稳定性评估 | 评估权利稳定性与被无效风险 |
| 普通应诉 | 应对知识产权民事一审 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动、数据合规、反垄断 | 对应领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

提出无效不等于必然中止。确认不侵权反诉与另行起诉的管辖可能不同。评价报告不是无效决定。
