# 边界与路由

## 正触发

己方专利被请求无效。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 提出无效 | 准备专利无效宣告 |
| 民事应诉 | 应对知识产权民事一审 |
| 审查意见答复 | 准备专利审查意见答复框架 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动、数据合规、反垄断 | 对应领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

民事中的现有技术抗辩成立不等于专利被无效。无效程序中主动删权项可能触发禁止反悔，影响并行侵权诉讼。
