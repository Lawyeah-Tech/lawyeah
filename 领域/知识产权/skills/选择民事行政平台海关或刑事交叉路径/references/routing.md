# 边界与路由

## 正触发

路径未闭合，需比较民事、行政、平台、海关或刑事交叉及不可逆性。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 完整起诉包 | 提起知识产权民事一审 |
| 行政投诉终稿 | 准备知识产权行政查处投诉 |
| 平台通知终稿 | 准备平台投诉与通知删除材料 |
| 海关备案或扣留 | 准备知识产权海关备案 / handle-customs-detention |
| 事项总图而非路径比较 | 评估知识产权事项 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 竞业或劳动保密 | 劳动领域 |
| 数据合规主轴 | 数据隐私领域 |
| 反垄断或市场秩序主轴 | 竞争法领域 |
| 定罪、控告、辩护 | 刑事领域；本任务只留红旗 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

“先发函还是直接起诉”正触发。已经写好诉状只问“还要不要再投诉”时，本任务只比较剩余路径，不重写诉状。出现假冒注册商标数量或商业秘密重大损失信号时不得用行政投诉代替刑事红旗。
