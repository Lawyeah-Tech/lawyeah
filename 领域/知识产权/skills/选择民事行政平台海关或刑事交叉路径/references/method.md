# 路径选择方法

每个会改变论坛选择的节点必须回链来源、规则核验状态和不可逆提示。不得输出“先民事必赢”或唯一最优路径。MCP 把 2025-10-15 已施行的《反不正当竞争法》标成尚未施行时，以施行日为准并记冲突。旧条号（专利法第六十五条、著作权法第四十九条、反法第九条当现行定义）记噪声。search_law 返回已失效《合同法》时不得写入 L#。

## 节点 0　分流

劳动竞业／保密、数据合规、反垄断整案转出。用户已决定起诉／投诉／发函／海关并只要相应文书：目标停止，转对应原子。假冒、制售、侵犯商业秘密已达刑事追诉信号：刑事整案转刑事领域，本任务只在比较表留红旗，不定罪。

## 节点 1　先固定对象与权属闸

若权属不能回链：民事起诉和警告发送闸关闭，只保留补证、协商或查询路径。若对象是未注册标识且主目标是仿冒：民事反法路径可列，商标行政投诉以注册商标为前提的字段停止。若对象是商业秘密：行政投诉和刑事红旗可列，平台“通知删除”可能不足以固定密点，须明示。

## 节点 2　路径分账

对每一候选路径填写：入口机关或平台、证明负担、可获得的停止／金钱／销毁效果、错误启动后果、失败后是否还能走其他路径、是否不可逆。

| 路径 | 已能支持时允许写 | 不得写成 |
| --- | --- | --- |
| 协商／警告 | 发送前接口 | 对方必须停用或已经自认 |
| 平台通知 | 通知要素待备 | 十五日届满=侵权确定 |
| 海关 | 备案或扣留确认接口 | 海关必然没收 |
| 行政查处 | 投诉管辖待核 | 必然立案处罚 |
| 民事 | 请求类型待核 | 必然受理或胜诉 |
| 刑事交叉 | 追诉红旗 | 已经构成犯罪 |

## 节点 3　互斥与并行

- 若平台内链接与站外工厂同时存在：平台通知与民事／行政可并行，不互相消灭。
- 若海关已扣货：确认期优先于普通协商，过期未确认可能放行，见海关原子。
- 若已申请诉前行为保全：核验起诉期限，未核验则字段停止，不得写成可以无限期只拿裁定不立案。
- 若表面有效仲裁条款存在：民事起诉路径标阻却，先转管辖原子。
- 刑事立案后民事可否继续：运行时核验；未核验不得写“必须中止”或“必须并行”。

## 节点 4　期限接口

诉讼时效、异议除斥、平台声明期、海关确认期、诉前保全后起诉期、行政处罚时效分列，每行一种期间。禁止输出唯一截止日。日期冲突则并行情景 + 字段停止。

## 节点 5　失败分流与安全

每条路径写：若不受理／不制止／放行／不构成，下一接口是什么。禁止指导伪造权属、钓鱼取证或威胁刑事换民事和解。反垄断调查或数据抓取主轴不得伪装成本任务的“行政路径”。
## 补充判断闸

若权属不能回链：关闭民事起诉与可发送警告闸，只保留补证、协商和查询。若海关已扣货：确认期优先于普通发函，过期未确认按放行情景分流。若表面有效仲裁条款存在：民事起诉路径标阻却，先转管辖原子。若假冒相同商标且数量金额待核：刑事只红旗，不得用行政投诉代替。若用户已选定唯一路径并只要文书：目标停止并转介对应原子，本任务不再比较论坛。
