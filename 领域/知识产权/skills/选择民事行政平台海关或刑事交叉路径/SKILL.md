# 选择民事、行政、平台、海关或刑事交叉路径

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1990 年《著作权法》同号旧义或 1993 年《反不正当竞争法》定义当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“保护路径比较表”：民事、行政、平台、海关、刑事交叉的互斥与并行、期限接口、失败分流和不可逆提示。本任务不写完整起诉或行政投诉包，不定罪。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、评估、测算和证据清单。

## 工作边界

正触发：路径尚未闭合，需要比较论坛与不可逆性后再决定先发函、先投诉、先海关、先民事或只做刑事红旗。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 已决定起诉并只要起诉状（转提起民事一审）；
- 已决定行政投诉并只要投诉包；
- 只要平台通知终稿或海关备案终稿；
- 要定罪或刑事辩护策略（刑事）；
- 主轴是劳动、数据合规或反垄断；

本任务不生成可提交诉状、行政投诉终稿或刑事报案书，不给胜诉率。

## 建立工作坐标

确认：使用者与授权；单方立场；相对方；权利类型与对象；法域；当前通知、平台、行政、诉讼或执行状态；关键材料及缺失。已采取的警告、下架、海关、行政或诉讼动作及文书送达。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。口头转述和“已读”不写成已受理、已送达或期限已起算。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 权利文件或条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`V#` 版本；`E#` 发送／送达／使用凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民事、行政、海关和电商通知期间；`search_practiced` 补双轨并行反例。

MCP 把 2025-10-15 已施行的《反不正当竞争法》标成尚未施行时，以施行日为准并记冲突。旧条号（专利法第六十五条、著作权法第四十九条、反法第九条当现行定义）记噪声。search_law 返回已失效《合同法》时不得写入 L#。

工具不可用时继续事实、对象和问题清单；法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　分流与目标闭合

先分流劳动／隐私／竞争／刑事整案。用户已选定唯一路径并只要文书：目标停止并转介对应原子。

### 节点 2　路径分账

民事、行政、平台、海关、刑事交叉分列成本、证明负担、不可逆性和失败后果，禁止合成“全面维权”。

### 节点 3　互斥与并行

平台通知与民事可并行；海关扣留有确认期；刑事立案后民事可否并行须运行时核验，未核验则字段停止。

### 节点 4　期限接口

时效、异议、海关确认、诉前保全后起诉期分列，不输出唯一截止日。

### 节点 5　失败分流

每条路径写失败后可转哪一条。刑事只留红旗，不定罪。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或对象无法建立；用户坚持伪造、隐匿、威胁刑事或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为完整起诉包、行政投诉终稿、刑事策略或数据／反垄断整案。
