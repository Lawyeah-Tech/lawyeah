# 边界与路由

## 正触发

已受警告或被威胁起诉，需确认不侵权。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 普通应诉 | 应对知识产权民事一审 |
| 警告回复 | 应对侵权警告函或律师函 |
| 反诉影响评估 | 评估反诉或另行无效对诉讼的影响 |
| 无警告无威胁 | 诉的利益闸关闭 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动、数据合规、反垄断 | 对应领域 |

一般标识或作品夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。未安装的相邻原子输出 `unavailable`，不得由名称相近的 Skill 代做。

## 易混

催告对方起诉的函有助于固定诉的利益，但不是唯一形式。确认之诉胜诉不当然获得赔偿。
