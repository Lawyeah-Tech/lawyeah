# 边界与路由

## 正触发

需要判断转包、违法分包或肢解发包是否成立。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 劳务／专业分包／劳动界限 | `评估劳务分包与专业分包界限` |
| 解除权 | `评估施工合同解除权` |
| 实际施工人请求 | `评估实际施工人请求` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

发包人说“转包了所以可以马上解除”时正触发：本任务只定性，解除另项。
