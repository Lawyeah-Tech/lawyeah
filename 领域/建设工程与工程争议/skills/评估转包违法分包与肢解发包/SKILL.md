# 评估转包、违法分包与肢解发包

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“转包／违法分包／肢解发包定性矩阵”：行为定性、合同效力后果、连带责任接口。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：争议焦点是转包、违法分包、再分包或肢解发包是否成立。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未成争，只要改施工合同或出稿（审查起草领域，本生产线搁置，只说明不实施）；
- 一般买卖、服务、租赁等无工程建设过程的合同争议（转合同争议解决）；
- 商品房买卖、开发销售或物业服务主轴（转房地产）；
- 农民工劳动关系、工资或工伤待遇主轴（转劳动）；
- 合法专业分包／劳务分包界限走专项；
- 不自动解除；
- 只要解除通知终稿；

定性成立不等于已经解除。合法专业分包与劳务分包走界限原子。不自动输出解除通知。

## 建立评估坐标

确认：总包合同范围；分包合同范围；主体结构是否被分包；分包人资质；发包人是否同意；现场谁在施工；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`V#` 评估或稿件版本；`E#` 发送／送达／履行凭证。 另用 `SC#` 标行为定性，`CF#` 标效力后果。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典第 791、806 条，建筑法和解释（一）第 1 条第二款。

工具不可用时继续事实、主体、程序文书状态和问题清单；请求／抗辩的法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [转包违法分包方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　行为识别

转包是承包人把全部或将其承包的全部建设工程支解以后以分包名义转给第三人。违法分包包括无资质分包、主体结构分包、再分包等，须逐项核验现行条文。

### 节点 2　与合法分包界限

专业分包经发包人同意且分包人有资质、劳务分包只包劳务不包主要材料与主体结构时，不得写成违法分包。界限不清转专项原子。

### 节点 3　合同效力后果

转包、违法分包所订合同依据解释（一）第 1 条第二款可能无效。无效不等于无价款，保留第 793 条接口。

### 节点 4　解除与连带接口

发包人可以解除（第 806 条第一款）只是路径，不写成已经解除。质量连带、实际施工人请求另建接口。

### 节点 5　下一步

解除权评估或解除通知另项。实际施工人对外请求另项。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体、工程或文本无法建立；用户坚持伪造签证、隐匿不利资料、威胁、破坏现场或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为本任务不得交付的终稿。
