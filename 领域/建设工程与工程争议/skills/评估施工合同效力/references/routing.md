# 边界与路由

## 正触发

施工合同效力本身是本项委托的独立成果。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 总体争议总图 | `评估建设工程争议` |
| 确认之诉诉状 | `提起施工合同效力确认之诉` |
| 实际施工人身份 | `评估实际施工人请求` |
| 黑白合同结算依据终局 | `评估黑白合同与结算依据` |
| 未成争改合同 | 审查起草领域（搁置） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

用户说“合同无效所以对方拿不到钱”仍可能正触发：本任务必须纠正为第 793 条接口，而不是改写成价款测算终稿。
