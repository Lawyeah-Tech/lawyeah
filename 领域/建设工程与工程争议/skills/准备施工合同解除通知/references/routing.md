# 边界与路由

## 正触发

解除权材料已支持发送，需要发送前解除通知。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 催告付款或索赔 | `准备工程索赔或催告付款通知` |
| 停工通知 | `准备停工通知` |
| 只要评估解除权 | `评估施工合同解除权` |
| 确认解除之诉 | `提起建设工程一审` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

发包人因转包要解除：可能正触发，但仍须先有支持发送的事实，不能仅因存在分包协议就发函。
