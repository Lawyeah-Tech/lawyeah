# 发函方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、效力、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然无效、必然优先受偿或唯一必得总额。

`search_law` 返回已失效《合同法》及其解释、法释〔2004〕14 号、法释〔2018〕20 号或法释〔2002〕16 号（六个月优先受偿）时记为噪声，不得写入 `L#`。实务检索若出现“实际施工人当然享有优先受偿”“优先受偿期限六个月”或把解释（一）第 43 条写成 2026-06-30 后新受理一审的现行突破相对性规则，记为噪声。法释〔2026〕12 号《建工解释（二）》自 2026-06-30 施行；施行后新受理的一审建工案件适用该解释，与解释（一）不一致的以解释（二）为准。写入 `L#` 前仍须核验条号、施行日与本案一审受理时点。不得把已失效的法释〔2018〕20 号误当作现行解释（二）。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## 节点 0　分流

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

只要催告：负触发。依法须催告且未完成：目标停止。

---

## 节点 1　发送闸

解除权评估或等价材料未支持发送：不产出发送前终稿。同时掌握双方秘密：整体停止。

---

## 节点 2　催告闭合

运行时核验第 563、806 条。

| 路径 | 催告 |
| --- | --- |
| 承包人转包、违法分包，发包人解除 | 条文未以催告为必要，仍须核验约定是否另设催告 |
| 发包人不履行协助义务或材料不符强制标准致无法施工 | 必须催告 + 合理期限 |
| 迟延主要债务 | 原则上先催告 |
| 约定解除条件成就 | 核对该当条件，成就 ≠ 已发出通知 |

合理期限不得编造一律 15 日。

---

## 节点 3　正文

逐句回链。必须保留：已完工程在质量合格时请求相应价款（第 806 条第三款）；不合格参照第 793 条。禁止：已解除；优先受偿已实现；倒签。

---

## 节点 4　到达

通知到达对方时解除（第 565 条）。未通知而直接起诉主张解除：仅在确认该主张后，自起诉状副本送达时解除——评估或发函阶段不得把“准备起诉”写成已经解除。微信已读 ≠ 到达。

---

## 节点 5　异议与状态

对方未异议不能补正解除权缺失。状态保持 `待发送`。除斥期间冲突建并行情景，不给唯一截止日。
