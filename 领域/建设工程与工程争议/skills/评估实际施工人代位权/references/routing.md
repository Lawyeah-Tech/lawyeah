# 边界与路由

## 正触发

转包人怠于向发包人行使到期债权，实际施工人拟代位。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 对相对方起诉或挂靠知情起诉 | `准备实际施工人对发包人起诉材料` |
| 普通合同代位 | 合同争议解决领域 |
| 发包人欠付范围 | `评估发包人欠付范围内责任` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

用户把代位理解成“直接告发包人要全额”时，必须纠正为代位要件和额度上限。
