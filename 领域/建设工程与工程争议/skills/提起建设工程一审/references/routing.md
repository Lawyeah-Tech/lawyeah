# 边界与路由

## 正触发

已决定起诉且仲裁不阻挡，需要一审起诉包。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 仲裁申请 | `提起建设工程仲裁` |
| 应诉 | `应对建设工程一审` |
| 只要评估 | `评估建设工程争议` |
| 实际施工人专项起诉且本包未安装该原子 | 输出 unavailable，不降成本任务的普通承包人诉状 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

有效仲裁未排除仍要求“先起诉试试”：负触发，不得改写成立案原子。
