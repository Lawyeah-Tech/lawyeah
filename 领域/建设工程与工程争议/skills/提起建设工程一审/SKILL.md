# 提起建设工程一审

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的原告立场下，形成可复核、不代提交的“建设工程一审起诉包”：起诉状草稿、分项诉讼请求（可含工程价款、折价补偿、优先受偿、确认效力）、管辖连结点、证据目录和保全红旗。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：建设工程已成争，用户已决定向人民法院提起一审，且无表面有效的仲裁协议阻挡诉讼，或阻挡已被可回链证据排除。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未成争，只要改施工合同或出稿（审查起草领域，本生产线搁置，只说明不实施）；
- 一般买卖、服务、租赁等无工程建设过程的合同争议（转合同争议解决）；
- 商品房买卖、开发销售或物业服务主轴（转房地产）；
- 农民工劳动关系、工资或工伤待遇主轴（转劳动）；
- 仲裁条款表面有效且未被排除，用户仍要求直接起诉；
- 已决定申请仲裁；
- 已收到起诉状、用户实为被告；

本任务不代提交、不保证受理或胜诉，不写保全申请终稿，不把有效仲裁写成应起诉。利息违约金与优先受偿必须分列。

## 建立评估坐标

确认：原告立场；被告及共同被告、第三人；拟提出的请求；仲裁条款及排除证据；工程所在地；是否已有案号。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`V#` 评估或稿件版本；`E#` 发送／送达／履行凭证。 另用 `P#` 标诉讼请求，`J#` 标管辖连结点。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验起诉条件、管辖、仲裁阻却、优先受偿、第 793 条；`search_template` 只借起诉状栏目。

工具不可用时继续事实、主体、程序文书状态和问题清单；请求／抗辩的法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [起诉方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 专项分流、起诉决定和仲裁阻却闸

劳动、一般合同、房地产主轴转出。仲裁条款出现时不得直接写应起诉；表面有效且未排除则负触发。

### 2. 主体适格与分项诉讼请求

承包人、实际施工人、发包人身份决定请求结构。工程价款、折价补偿、优先受偿、确认无效、修复费用、工期违约金分列。优先额不得写入利息违约金。实际施工人作原告：主位对转包人／违法分包人给付。2026-06-30 后新受理一审不得把发包人写成欠付范围内给付被告（解释（二）第 6 条）；对发包人只列代位或挂靠知情（第 4、7 条）。旧案才保留第 43 条时点接口。

### 3. 管辖连结点

分列被告住所地、工程所在地、协议管辖、专属管辖和级别管辖。连结点不足时不选定唯一法院。

### 4. 证据目录与保全红旗

证据按待证事实绑定请求。保全只做红旗。鉴定只做接口。

### 5. 起诉状草稿与提交核验

只交付草案和核验清单，不代提交，不保证立案或胜诉。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体、工程或文本无法建立；用户坚持伪造签证、隐匿不利资料、威胁、破坏现场或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为本任务不得交付的终稿。


## 交付
