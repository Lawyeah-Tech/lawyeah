# 评估资质、挂靠与借用名义

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“资质与挂靠评估矩阵”：资质等级对照、借用名义要件、竣工前取得资质例外、内部协议对外效力接口。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：争议焦点是承包人有无资质、是否超资质、是否借用资质或挂靠，需要单独闭合该争点。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未成争，只要改施工合同或出稿（审查起草领域，本生产线搁置，只说明不实施）；
- 一般买卖、服务、租赁等无工程建设过程的合同争议（转合同争议解决）；
- 商品房买卖、开发销售或物业服务主轴（转房地产）；
- 农民工劳动关系、工资或工伤待遇主轴（转劳动）；
- 内部承包结算走内部承包原子；
- 农民工劳动关系转劳动；
- 只要总体效力总图而不拆资质争点；

本任务不把内部承包一律写成挂靠，不处理劳动报酬，不生成确认之诉诉状。竣工前取得相应资质的例外必须运行时核验。

## 建立评估坐标

确认：使用者与授权；单方立场；名义承包人与实际施工控制人；建筑业企业资质证书等级、承包范围和有效期；工程类别与规模；内部协议或管理费约定；竣工或验收时点；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`V#` 评估或稿件版本；`E#` 发送／送达／履行凭证。 另用 `QA#` 标资质对照，`AF#` 标挂靠要件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验解释（一）第 1、4 条和民法典第 153、791 条；`search_practiced` 补挂靠与内部承包界限反例。

工具不可用时继续事实、主体、程序文书状态和问题清单；请求／抗辩的法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [资质挂靠方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　资质证书与承包范围对照

并列企业资质等级、承包范围、工程类别和规模。项目经理个人注册不等于企业有资质。证书过期、被吊销或与承包范围错配必须单独成行，不得合并成一句“没有资质”。

### 节点 2　借用名义与挂靠要件

没有资质的人借用有资质企业名义，须有实际施工控制、资金投入、材料采购或现场管理迹象。仅有管理费或项目经理内部承包协议，不得直接升格为挂靠。

### 节点 3　竣工前取得资质例外

超越资质但竣工前取得相应资质的，当事人请求按无效处理时，运行时核验解释（一）第 4 条后再落判断。核验失败则例外字段停止。无资质或借用名义不得套用该例外。

### 节点 4　内部协议对外效力接口

挂靠人与被挂靠人之间的管理费、利润分配协议对外不能对抗发包人。对内可支持性转内部承包原子，本任务只建接口。

### 节点 5　最强反方与效力接口

最强反方：合法联合体、内部承包、劳务分包。效力终局转效力原子。农民工工资身份转劳动。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体、工程或文本无法建立；用户坚持伪造签证、隐匿不利资料、威胁、破坏现场或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为本任务不得交付的终稿。
