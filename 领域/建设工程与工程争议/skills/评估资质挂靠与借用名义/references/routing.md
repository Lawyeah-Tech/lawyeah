# 边界与路由

## 正触发

无资质、超资质、借用资质或挂靠是否成立需要单独评估。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 内部承包结算 | `评估内部承包与挂靠内部结算` |
| 总体效力终局 | `评估施工合同效力` |
| 对外实际施工人请求 | `评估实际施工人请求` |
| 农民工工资或劳动关系 | 劳动领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

用户把内部承包说成挂靠时仍可能正触发：必须并列两条路径，不得预先选定对用户有利的定性。
