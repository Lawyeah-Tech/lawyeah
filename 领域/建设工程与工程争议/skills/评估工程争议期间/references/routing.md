# 边界与路由

## 正触发

需要单独核验工程争议中的各类期间。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 优先受偿实体 | `评估工程价款优先受偿` |
| 质量实体 | `评估工程质量缺陷与验收` |
| 解除权实体 | `评估施工合同解除权` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

用户问“还来不来得及”时正触发：必须分类型回答，不得给一个总截止日期。
