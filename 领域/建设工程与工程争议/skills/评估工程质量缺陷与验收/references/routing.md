# 边界与路由

## 正触发

验收不合格、保修或地基主体质量争议。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 擅自使用专项 | `评估擅自使用与验收拟制` |
| 质量鉴定 | `准备工程质量或修复费用鉴定` |
| 产品致人损害 | 人身损害与侵权赔偿领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

发包人已入住又主张全部装修质量时，先适用第 14 条限制再看地基主体除外。
