# 边界与路由

## 正触发

结算报送后对方拖延审核或不签认。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 以审计为准 | `评估以审计为准条款` |
| 进度款 | `评估进度款与节点付款` |
| 造价鉴定 | `准备工程造价鉴定申请` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

发包人说“没审计就不能结”时，先看是否存在审计条款，再决定是否转出。
