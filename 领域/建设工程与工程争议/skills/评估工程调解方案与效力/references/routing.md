# 边界与路由

## 正触发

需要评估法院、仲裁或行业调解方案与效力。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 谈判底线 | `谈判工程和解方案` |
| 协议起草 | `起草工程和解或结算协议` |
| 庭审提纲 | `准备工程案件庭审` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

法官建议调解并要求当场放弃优先受偿时，必须单独评估该放弃。
