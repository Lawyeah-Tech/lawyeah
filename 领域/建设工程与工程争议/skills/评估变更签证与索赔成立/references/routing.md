# 边界与路由

## 正触发

设计变更、现场签证或索赔报告是否构成调整。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争补签 | 审查起草领域（搁置） |
| 固定价鉴定闸 | `评估固定价与据实结算争议` |
| 工期顺延 | `评估工期延误与顺延` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

承包人没有任何签证但现场明显增项时仍可能正触发：走事实补证，不补假签证。
