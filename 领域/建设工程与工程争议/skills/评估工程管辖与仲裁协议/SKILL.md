# 评估工程管辖与仲裁协议

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“工程管辖与仲裁协议评估矩阵”：协议效力、或裁或诉、工程所在地连结点、异议期限。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：要选择法院还是仲裁，或对方已提出管辖／仲裁异议，需要单独闭合论坛。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未成争，只要改施工合同或出稿（审查起草领域，本生产线搁置，只说明不实施）；
- 一般买卖、服务、租赁等无工程建设过程的合同争议（转合同争议解决）；
- 商品房买卖、开发销售或物业服务主轴（转房地产）；
- 农民工劳动关系、工资或工伤待遇主轴（转劳动）；
- 不代写完整立案包；
- 劳动仲裁转劳动；
- 只要起诉状或仲裁申请书；

本任务不代写完整立案包。合同无效不当然消灭仲裁协议。劳动仲裁整段转劳动。

## 建立评估坐标

确认：使用者与授权；合同及补充协议中的争议解决条款；工程所在地；被告住所地；是否已起诉或已申请仲裁；异议提出日与送达日；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`V#` 评估或稿件版本；`E#` 发送／送达／履行凭证。 另用 `FO#` 标论坛，`OB#` 标异议期限。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验仲裁法、民事诉讼法管辖和工程所在地连结点；仲裁协议独立性。

工具不可用时继续事实、主体、程序文书状态和问题清单；请求／抗辩的法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [管辖仲裁方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　仲裁协议识别

写明机构、事项和或裁或诉。机构不明、或裁或诉、选定两个机构：效力标待核。合同无效不当然消灭仲裁条款。

### 节点 2　诉讼管辖连结点

分列工程所在地、被告住所地、协议管辖、专属管辖和级别管辖。连结点不足时不选定唯一法院。

### 节点 3　异议期限

应诉管辖、首次开庭前仲裁异议、提交答辩状期间管辖异议必须分列。逾期不得写成异议已成立。

### 节点 4　起诉与仲裁互斥闸

有效仲裁协议阻挡诉讼。表面有效且未排除时不得写应起诉。劳动仲裁转劳动。

### 节点 5　下一步

管辖异议书转 `object-to-jurisdiction`。仲裁协议异议转 `object-to-arbitration`。立案包另项。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体、工程或文本无法建立；用户坚持伪造签证、隐匿不利资料、威胁、破坏现场或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为本任务不得交付的终稿。
