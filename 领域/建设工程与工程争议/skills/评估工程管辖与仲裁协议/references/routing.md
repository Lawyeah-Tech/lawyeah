# 边界与路由

## 正触发

需要选择法院或仲裁，或应对管辖／仲裁异议。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 管辖异议书 | `提出工程案件管辖异议` |
| 仲裁协议异议材料 | `准备工程仲裁协议异议` |
| 起诉包 | `提起建设工程一审` |
| 劳动仲裁 | 劳动领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

有仲裁条款仍要求“直接起诉”时，先完成本任务论坛闸，不得直接转起诉原子。
