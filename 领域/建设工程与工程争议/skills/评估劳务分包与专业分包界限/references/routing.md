# 边界与路由

## 正触发

一份协议需要判断是劳务分包、专业分包还是劳动关系。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 转包违法分包终局 | `评估转包违法分包与肢解发包` |
| 已是劳动关系 | 劳动领域 |
| 实际施工人工程款 | `评估实际施工人请求` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

班组负责人既要工程款又要工资时，先完成本任务定性，再决定留下哪一请求。
