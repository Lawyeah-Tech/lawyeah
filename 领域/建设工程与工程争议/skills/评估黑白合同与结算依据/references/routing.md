# 边界与路由

## 正触发

备案中标合同与另行协议实质性内容不一致，需要确定结算依据。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 招投标效力本身 | `评估招投标与中标效力` |
| 未成争补签 | 审查起草领域（搁置） |
| 签证增减项成立 | `评估变更签证与索赔成立` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

用户要求“按对我们有利的那份结”仍可能正触发：必须并列冲突并按现行规则建层级，不得改写成代拟阴合同。
