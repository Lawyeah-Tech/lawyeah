# 边界与路由

## 正触发

规划许可、中标备案或付款走账由第三方掌握。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 现场保全 | `保全工地现场与隐蔽工程证据` |
| 证据总卷 | `建立工程证据与鉴定方案` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

用户要求把对方老板个人全部银行卡打一遍时必须收窄到与工程款有关的账户和时段。
