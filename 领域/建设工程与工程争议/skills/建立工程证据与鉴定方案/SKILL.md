# 建立工程证据与鉴定方案

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“工程证据与鉴定方案”：要件、举证责任、现场和资料矩阵、鉴定启动或不应鉴定、合法补证。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：单独委托盘点举证责任、现场资料和鉴定是否必要。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未成争，只要改施工合同或出稿（审查起草领域，本生产线搁置，只说明不实施）；
- 一般买卖、服务、租赁等无工程建设过程的合同争议（转合同争议解决）；
- 商品房买卖、开发销售或物业服务主轴（转房地产）；
- 农民工劳动关系、工资或工伤待遇主轴（转劳动）；
- 只要策略总图或诉状；
- 要求预测鉴定意见或造价结论；
- 要求指导抢工、毁场或伪造签证；

本任务不替代总体策略或诉状，不预测鉴定意见，不指导违法取证。

## 建立评估坐标

确认：单方立场；待证请求；现场是否仍可进入；图纸、联系单、签证、影像、检测报告、结算资料控制方；是否已有诉前咨询意见；固定价约定。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`V#` 评估或稿件版本；`E#` 发送／送达／履行凭证。 另用 `EV#` 标证据，`ID#` 标鉴定事项。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验解释（一）第 11、14、30、32 条；`search_practiced` 补不宜鉴定情形。

工具不可用时继续事实、主体、程序文书状态和问题清单；请求／抗辩的法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [证据与鉴定方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 要件与举证责任

按 `Q#` 拆待证事实：合同文本、完成工程量、质量、付款、签证到达、实际施工投入。不能因对方控制资料推定内容有利。

### 2. 现场与资料矩阵

隐蔽工程、影像、试验、监理日志、施工日志、材料进场、资金走账分列控制方、原件、合法性、灭失风险。

### 3. 鉴定启动闸

造价、质量、修复费用专门性问题，法院认为需要鉴定应向负有举证责任的一方释明（第 32 条）。不申请、不缴费、不提供材料承担举证不能。

### 4. 不应鉴定闸

固定价且无应计量增减：造价鉴定不应启动。双方已达成结算协议或明确受诉前咨询约束：重新鉴定标不支持或待核。未按约定结算程序本身不是启动鉴定的充分条件。

### 5. 合法补证与禁止项

公证保全、见证取样、申请调查令只列合法路径。禁止破坏现场、伪造签证、偷录违法取得的材料写成可采。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体、工程或文本无法建立；用户坚持伪造签证、隐匿不利资料、威胁、破坏现场或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为本任务不得交付的终稿。
