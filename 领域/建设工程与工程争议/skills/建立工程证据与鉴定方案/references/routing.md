# 边界与路由

## 正触发

需要证据矩阵或鉴定是否启动的独立成果。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 策略总图 | `评估建设工程争议` |
| 造价鉴定申请书 | `准备工程造价鉴定申请` |
| 质量鉴定申请书 | `准备工程质量或修复费用鉴定` |
| 现场紧急保全 | `保全工地现场与隐蔽工程证据` |
| 诉状 | `提起建设工程一审` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

固定总价合同一方开口就要鉴定：正触发本任务，结论可能是不应鉴定，而不是自动转鉴定申请。
