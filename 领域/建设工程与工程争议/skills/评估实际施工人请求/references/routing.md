# 边界与路由

## 正触发

实际施工人身份、对相对方折价补偿，以及对发包人的代位或挂靠知情路径是本项独立成果。新受理一审不得把第 43 条突破相对性写成现行给付。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 农民工工资工伤 | 劳动领域 |
| 普通承包人总图 | `评估建设工程争议` |
| 起诉状终稿 | `准备实际施工人对发包人起诉材料` |
| 优先受偿终局（承包人） | `评估工程价款优先受偿` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |
