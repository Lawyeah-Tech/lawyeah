# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、效力、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然无效、必然优先受偿或唯一必得总额。

`search_law` 返回已失效《合同法》及其解释、法释〔2004〕14 号、法释〔2018〕20 号或法释〔2002〕16 号（六个月优先受偿）时记为噪声，不得写入 `L#`。实务检索若出现“实际施工人当然享有优先受偿”“优先受偿期限六个月”或把解释（一）第 43 条写成 2026-06-30 后新受理一审的现行突破相对性规则，记为噪声。法释〔2026〕12 号《建工解释（二）》自 2026-06-30 施行；施行后新受理的一审建工案件适用该解释，与解释（一）不一致的以解释（二）为准。写入 `L#` 前仍须核验条号、施行日与本案一审受理时点。不得把已失效的法释〔2018〕20 号误当作现行解释（二）。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填总体评估十节实体结论。

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

混合信号：工程施工主轴可留本任务；商品房销售或农民工工资只作为背景时在缺口标明，不把房地产或劳动规则硬套进工程结论。

## 节点 1　主体链、文本版本和程序状态

1. 固定招标文件、投标文件、中标通知书、备案合同、补充协议、会议纪要、签证、索赔报告、结算书的版本层级。冲突并列。
2. 主体表记录：发包人、承包人、专业分包、劳务分包、实际施工人、项目经理、付款账户名、发票抬头。挂靠或内部承包不自动合并为同一主体。
3. 程序表逐动作记录催告、停工、解除、鉴定、仲裁、诉讼或执行：机关/机构、案号、文书、作出日、收到日、送达方式和效力凭证。口头转述、微信已读不得写成已受理、已送达或期限已起算。
4. 同时掌握双方秘密或立场不明：整体停止策略输出。

## 节点 2　效力接口与请求抗辩

每个 `Q#` 先写法律效果，再写成立条件。禁止合成“工程权益”一笔。

默认主位候选按事实分别建立：

- `Q-效` 合同有效或无效（接口，终局转效力原子）
- `Q-价` 工程价款或无效后的折价补偿（民法典第 793 条）
- `Q-优` 建设工程价款优先受偿（接口，终局转优先受偿原子）
- `Q-实` 实际施工人向转包人／违法分包人／发包人主张（接口）
- `Q-工` 工期顺延或工期违约金
- `Q-质` 修复、减少价款或质量抗辩
- `Q-催` 催告付款或指定合理期限
- `Q-解` 约定解除或法定解除（含第 806 条）
- `Q-抗` 同时履行、质量抗辩、时效、仲裁／管辖异议、擅自使用限制

构成违约不等于当然解除。合同无效不等于无价款。实际施工人不是当然优先受偿权人。

主备位和互斥必须可见。`Q-解` 与继续施工不得同时写成均已成立。

## 节点 3　催告、解除与论坛

本节点只判断路径，不生成发送版通知。

### 3.1 先分账

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 对方欠付进度款 | 已构成法定解除 |
| 用户想今天发函 | 解除权已行使或合同已解除 |
| 存在转包 | 发包人已经解除 |
| 对方未在异议期内异议 | 即使无解除权也已解除 |

### 3.2 法定／特别解除

运行时核验民法典第 563、806 条后再落判断。核验失败则本节点字段停止。

1. 承包人转包、违法分包：发包人可以解除。
2. 发包人提供的主要材料设备不符合强制性标准或不履行协助义务，致使无法施工，经催告后合理期限仍未履行：承包人可以解除。
3. 一般迟延主要债务：原则上先催告 + 合理期限；不得编造“一律 15 日”。
4. 解除后已完工程质量合格的，按约定支付相应工程价款；不合格参照第 793 条。

### 3.3 仲裁协议优先闸

合同或补充协议出现仲裁条款时不得直接写“应向法院起诉”。或裁或诉、机构不明：效力标 `依据不足`，转介管辖原子。合同无效不当然消灭仲裁协议。

## 节点 4　期限分类型

每种期间单独一行。禁止用三年诉讼时效去算优先受偿，也禁止用十八个月去挡普通金钱请求。

| 类型 | 规则锚点 | 本任务允许的输出 | 禁止 |
| --- | --- | --- | --- |
| 诉讼时效 | 第 188 条一般为三年 | 起算事件、备选起算、中断候选 | 唯一截止日 |
| 优先受偿 | 解释（一）第 41 条最长十八个月，自发包人应当给付之日起算 | 起算事件并行情景 | 写成六个月；与时效混算 |
| 解除权除斥 | 第 564、199 条 | 知悉日/催告日并行情景 | 适用中止中断 |
| 结算审核期 | 合同约定 | 条款原文、是否已起算 | 把约定期写成法定除斥 |
| 质量异议／保修 | 合同及质量条例，运行时核验 | 约定检验期、保修期、地基主体除外 | 签收=验收；擅自使用=合格 |

日期冲突、送达不明：并行情景 + 字段停止。

## 节点 5　金额区间与鉴定红旗

本任务只建区间和接口，不替代价款测算或鉴定申请。

1. 分项：合同价、已完产值、增减项、已付款、质保金、利息、违约金、修复费用。未知不写零。
2. 出现固定价约定：鉴定标红旗，转介固定价／鉴定原子，不把重新计量写成当然权利。
3. 优先受偿额不得计入利息、违约金、损害赔偿金（解释（一）第 40 条）。
4. 无效合同：验收合格才打开第 793 条折价补偿接口；验收不合格走修复分流。
5. 参数不足：只列已知参数、未知参数和专项测算接口。
