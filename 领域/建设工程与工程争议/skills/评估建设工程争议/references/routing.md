# 边界与路由

## 正触发

建设工程已成争，单方需要总体决定请求、抗辩、论坛、鉴定优先级和下一步。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |
| 只判断合同是否无效 | `评估施工合同效力` |
| 只判断实际施工人请求 | `评估实际施工人请求` |
| 只判断优先受偿 | `评估工程价款优先受偿` |
| 精算工程价款 | `测算工程价款与结算` |
| 完整证据卷或鉴定方案 | `建立工程证据与鉴定方案` |
| 发催告或索赔函 | `准备工程索赔或催告付款通知` |
| 发解除通知 | `准备施工合同解除通知` |
| 和解条件 | `谈判工程和解方案` |
| 起诉 | `提起建设工程一审` |
| 应诉 | `应对建设工程一审` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

请求尚未闭合、需比较是否提出解除或先催告时正触发。主体、请求、论坛均确认且只要诉状时负触发。有仲裁条款仍要求“直接起诉”时，先完成论坛闸。
