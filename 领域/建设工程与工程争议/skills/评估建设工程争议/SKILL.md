# 评估建设工程争议

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“建设工程争议总体评估矩阵”：主体链和程序状态、合同效力接口、事实时间线、逐项请求／抗辩、论坛与程序入口、期限待核、价款区间与非金钱后果、鉴定红旗、证据缺口、对方最强解释和下一步。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：施工、设计、监理或工程总承包已形成价款、工期、质量、签证、鉴定、实际施工人或优先受偿争议，用户仍需决定请求、抗辩、路线或下一步。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未成争，只要改施工合同或出稿（审查起草领域，本生产线搁置，只说明不实施）；
- 一般买卖、服务、租赁等无工程建设过程的合同争议（转合同争议解决）；
- 商品房买卖、开发销售或物业服务主轴（转房地产）；
- 农民工劳动关系、工资或工伤待遇主轴（转劳动）；
- 只要发送版催告、停工或解除函；
- 只要精算工作表、完整鉴定申请或完整证据卷；
- 已决定起诉／仲裁申请／答辩／开庭／执行并只要相应文书；

本任务不生成发送版解除函、可提交诉状或答辩、保全申请或鉴定申请终稿，不给胜诉率。

## 建立评估坐标

确认：使用者与授权；单方立场（发包人／承包人／实际施工人／分包人）；相对方及可能责任主体；合同、中标文件、补充协议、签证版本；工程地点与标的；争议事项；法域；当前协商、催告、鉴定、仲裁、诉讼或执行状态；机关文书作出与送达；对方已知主张；关键材料及缺失。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`V#` 评估或稿件版本；`E#` 发送／送达／履行凭证。 另用 `P#` 标优先受偿接口，`ID#` 标鉴定红旗。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验效力、第 793 条折价补偿、优先受偿、鉴定启动及法释〔2026〕12 号第 6、7、23 条时点；`search_practiced` 补路径与反例；特殊事实用 `search_case_by_fact`。不虚构案件系统。

工具不可用时继续事实、主体、程序文书状态和问题清单；请求／抗辩的法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 专项分流、主体链和文本版本

先做相邻整案转出。再固定招标文件、中标通知、备案合同、补充协议、签证和结算资料的版本层级。冲突并列，不选对用户有利的一版冒充唯一文本。主体表记录发包人、承包人、分包人、实际施工人、付款名和发票名，名称不一致不自动合并。

### 2. 效力接口与请求抗辩假设

效力只建接口：无资质、挂靠、必须招标、转包违法分包标红旗，终局判断转效力原子。每个 `Q#` 独立列法律效果。继续施工、催告付款、解除、工程价款、优先受偿、质量修复、工期违约金不得合成一笔“工程权益”。合同无效不等于无价款。实际施工人对发包人不得默认解释（一）第 43 条欠付范围；新受理一审只建代位或挂靠知情接口。

### 3. 论坛、催告／解除和期限

仲裁条款出现时不得直接写成应起诉。催告与解除分账。期限分列诉讼时效、优先受偿十八个月、解除除斥、质量异议／保修、约定结算审核期，不混算。不得把已失效的六个月优先受偿写成现行规则。

### 4. 价款区间、鉴定红旗与非金钱后果

分项列已完工程价款、增减项、已付款、质保金、利息、违约金。未知不写零。固定价约定出现时鉴定标红旗而非当然启动。优先受偿范围不含利息、违约金、损害赔偿。退场、修复、资料移交等非金钱结果单列。

### 5. 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。下一步按期限灭失、现场易失证据、能否改变 `Q#`、可逆性排序。发送解除函、立案、精算、鉴定申请标为转介。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体、工程或文本无法建立；用户坚持伪造签证、隐匿不利资料、威胁、破坏现场或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为本任务不得交付的终稿。
