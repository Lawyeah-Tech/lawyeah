# 谈判工程和解方案

## 任务目标

在明确、无利益冲突的单方立场下，形成仍可谈的“工程和解方案”：争点让步表、价款工期质量底线、弃权范围（含优先受偿与实际施工人请求）、执行力提示。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：工程争议仍可谈判，用户需要底线和条件，而不是马上签署协议或提交诉辩。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未成争，只要改施工合同或出稿（审查起草领域，本生产线搁置，只说明不实施）；
- 一般买卖、服务、租赁等无工程建设过程的合同争议（转合同争议解决）；
- 商品房买卖、开发销售或物业服务主轴（转房地产）；
- 农民工劳动关系、工资或工伤待遇主轴（转劳动）；
- 条件已谈拢，只要可签和解协议正文；
- 只要答辩状或起诉状；
- 未成争只要补签补充协议（审查起草，搁置）；

必须用可见语句写明：单独和解协议无强制执行力。放弃优先受偿须提示建筑工人利益和第 42 条风险。

## 建立评估坐标

确认：单方立场；仍可谈的事实；拟放弃和拟坚持的 `Q#`；付款来源；是否涉及优先受偿或实际施工人；第三人担保。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`V#` 评估或稿件版本；`E#` 发送／送达／履行凭证。 另用 `N#` 标让步项，`W#` 标弃权项。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验和解、优先受偿放弃、调解效力；不保证对方履行。

工具不可用时继续事实、主体、程序文书状态和问题清单；请求／抗辩的法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [和解方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 仍可谈闸

已有生效裁判只余执行：转执行和解。一方明确拒绝谈判且已立案只要素状：负触发。

### 2. 争点让步表

价款、工期违约金、质量修复、质保金、优先受偿、实际施工人请求、退场资料分列。禁止合成“打包了结”一笔而不列放弃项。

### 3. 底线与明示确认

金钱底线、非金钱底线、程序动作底线分列。未获明示确认的放弃请求不得写入成交条件。

### 4. 弃权范围

逐项写清是否放弃优先受偿、利息、违约金、对第三人的请求、未知质量损害。概括“永不追究”不得作为成交条款。损害建筑工人利益的优先权放弃标第 42 条风险。

### 5. 执行力与下一步

单独和解无强制执行力。司法确认、仲裁调解书、公证赋强、诉讼调解书只列转介。有效仲裁不得写成谈不拢即应起诉。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体、工程或文本无法建立；用户坚持伪造签证、隐匿不利资料、威胁、破坏现场或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为本任务不得交付的终稿。


## 交付
