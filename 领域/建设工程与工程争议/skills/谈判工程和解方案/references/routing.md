# 边界与路由

## 正触发

仍可谈，需要底线和弃权范围。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 可签协议正文 | `起草工程和解或结算协议` |
| 执行力补强 | `办理工程和解执行力补强` |
| 应诉 | `应对建设工程一审` |
| 未成争补协议 | 审查起草（搁置） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

用户说“签个结算单了结”但未谈弃权范围：正触发本任务，不得直接转协议起草。
