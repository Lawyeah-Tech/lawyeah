# 边界与路由

## 正触发

对方依仲裁条款推进，己方主张协议无效或不适用。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 法院管辖异议 | `提出工程案件管辖异议` |
| 仲裁应诉实体 | `应对建设工程仲裁` |
| 论坛评估 | `评估工程管辖与仲裁协议` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

用户在法院案件里主张“有仲裁所以法院不该管”时，先分清是管辖异议还是协议效力确认。
