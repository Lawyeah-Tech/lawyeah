# 边界与路由

## 正触发

节点未付或形象进度争议需要评估进度款。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 竣工结算 | `评估竣工结算与逾期不结算` |
| 停工权 | `评估停工权是否成立` |
| 催告函 | `准备工程索赔或催告付款通知` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

用户把未付进度款直接写成可以解除合同时，本任务只建催告／停工接口。
