# 边界与路由

## 正触发

工程款优先、抵押权和购房人权利冲突。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 优先受偿实体 | `评估工程价款优先受偿` |
| 商品房买卖主轴 | 房地产物业领域 |
| 案外人执行异议 | `准备购房人或抵押权人执行异议` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

银行主张抵押权在先故工程款不能优先时正触发。
