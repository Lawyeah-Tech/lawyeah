# 测算工程价款与结算

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成可复核的“工程价款分项测算表”：结算依据、已完工程、增减项、已付、质保金、利息接口、固定价／鉴定接口。不认定合同有效或质量已合格。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：需要可复核的工程款数字，且用户接受测算建立在明示假设上。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未成争，只要改施工合同或出稿（审查起草领域，本生产线搁置，只说明不实施）；
- 一般买卖、服务、租赁等无工程建设过程的合同争议（转合同争议解决）；
- 商品房买卖、开发销售或物业服务主轴（转房地产）；
- 农民工劳动关系、工资或工伤待遇主轴（转劳动）；
- 只要定性总图不要分项测算；
- 要求输出法院必支持的唯一总额；
- 把利息、违约金写入优先受偿额且拒绝拆分；

本任务**不认定**合同有效、质量合格或违约已成立。测算行建立在明示 `Q#` 假设上。未知不写零。

## 建立评估坐标

确认：单方立场；结算依据文本；计价方式（固定总价／综合单价／据实）；已完工程范围；签证变更；已付款；质保金；拟计息期间；鉴定或审计状态。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`V#` 评估或稿件版本；`E#` 发送／送达／履行凭证。 另用 `M#` 标测算行，`EVT#` 标经济事件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验第 793、799 条和解释（一）第 19、24 条及固定价鉴定规则；利息条文运行时核验。

工具不可用时继续事实、主体、程序文书状态和问题清单；请求／抗辩的法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [测算方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 假设、结算依据和事件编号

先挂 `Q-价`、`Q-效`、`Q-质` 假设。结算文本冲突并列，不选对用户有利的一版。每个经济事件分配 `EVT#`。未知值写 `unknown`，真实零必须有肯定来源。

### 2. 分项建账

合同价、已完产值、设计变更增减、签证、索赔、已付款、质保金、违约金、利息分列。禁止合成“应结总额”后抹掉互斥。

### 3. 固定价、审计与鉴定闸

约定固定价且无应计量增减项：重新造价鉴定标不应启动接口。以审计为准条款只建接口。诉前共同委托咨询是否约束运行时核验解释（一）第 30 条。

### 4. 无效、质量与第 793 条

无效假设下须有质量合格才能打开参照约定折价。不合格走修复费用，不把合同价照抄为已核实金额。

### 5. 利息、优先受偿隔离与汇总

利息另列，不得写入优先受偿额。情景汇总必须显示互斥。无法代入得数的行用 `无法估计`。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体、工程或文本无法建立；用户坚持伪造签证、隐匿不利资料、威胁、破坏现场或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为本任务不得交付的终稿。
