# 测算方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、效力、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然无效、必然优先受偿或唯一必得总额。

`search_law` 返回已失效《合同法》及其解释、法释〔2004〕14 号、法释〔2018〕20 号或法释〔2002〕16 号（六个月优先受偿）时记为噪声，不得写入 `L#`。实务检索若出现“实际施工人当然享有优先受偿”“优先受偿期限六个月”或把解释（一）第 43 条写成 2026-06-30 后新受理一审的现行突破相对性规则，记为噪声。法释〔2026〕12 号《建工解释（二）》自 2026-06-30 施行；施行后新受理的一审建工案件适用该解释，与解释（一）不一致的以解释（二）为准。写入 `L#` 前仍须核验条号、施行日与本案一审受理时点。不得把已失效的法释〔2018〕20 号误当作现行解释（二）。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

---

本任务**不认定**合同有效、质量合格或违约已经成立。测算行建立在明示假设上。

## 节点 0　分流

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

只要定性总图：负触发。

---

## 节点 1　范围、假设、结算文本

1. 固定单方立场、待算项目和排除项。
2. 每个金钱主张先挂独立 `Q#` 假设。
3. 结算依据层级：招标文件／中标通知／备案合同／补充协议／实际履行合同。冲突并列。
4. 未知写 `unknown`。禁止把查不到的签证或窝工损失写成零后加总。

---

## 节点 2　分项建账

每个 `M#` 固定列：

`编号｜项目｜性质｜EVT#｜Q# 假设｜参数｜未舍入公式｜已付／扣减｜互斥／抵扣｜金额状态｜判断｜待核｜来源`

默认分项：

| 项目 | 计入规则 |
| --- | --- |
| 合同价／已完产值 | 按计价方式和完成范围 |
| 设计变更增减 | 有约定从约定；不能协商一致可参照签约时当地计价标准（解释（一）第 19 条，须核验） |
| 签证／索赔 | 先定性是否成立，再计数 |
| 已付款 | 按资金流向，不按口头标签 |
| 质保金 | 先核质保条件 |
| 违约金 | 进入调整接口，不是必得 |
| 利息 | 另列；不得写入优先额 |

顺序：假设 → 参数和公式 → 已付扣减 → 金额状态。无法代入用 `无法估计`。

---

## 节点 3　固定价、审计、鉴定

运行时核验解释（一）关于固定价不予鉴定的现行条文。

if 约定按固定价结算且无重大设计变更或增减项事实:
    then 造价鉴定接口标不应启动，相关行不得用市场价重做。
if 存在应计量的变更部分:
    then 仅该部分打开鉴定或当地计价接口，不推翻固定价整体。
if 约定以财政审计为准:
    then 转介审计条款原子；审计未出且条款效力未核验时对应行 `无法估计`。
诉前共同委托咨询：解释（一）第 30 条，双方明确受约束的除外才当然准许重新鉴定。

---

## 节点 4　无效与质量假设

无效 + 验收合格：参照约定折价，不是把利润条款全部有效化。无效 + 不合格：修复费用另列；修复后仍不合格不得输出参照约定的已核实金额。发包人过错责任另列。

---

## 节点 5　利息、优先隔离、汇总

利息计付标准和起算运行时核验。没有约定起算日不得编造。优先受偿额另表且剔除利息、违约金、损害赔偿。多情景并列，禁止单一“应判金额”。
