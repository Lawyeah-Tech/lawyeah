# 边界与路由

## 正触发

需要可复核的工程价款数字。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 定性总图 | `评估建设工程争议` |
| 优先受偿是否成立 | `评估工程价款优先受偿` |
| 造价鉴定申请 | `准备工程造价鉴定申请` |
| 固定价应否鉴定的专项 | `评估固定价与据实结算争议` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

用户给一份结算书只要“看看能要多少”正触发。用户只要鉴定申请书负触发。
