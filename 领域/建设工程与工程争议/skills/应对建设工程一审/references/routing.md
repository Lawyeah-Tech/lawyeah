# 边界与路由

## 正触发

已收到建设工程起诉状，需要首次应诉。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 主动起诉 | `提起建设工程一审` |
| 只要管辖异议 | `提出工程案件管辖异议` |
| 已决定反诉终稿 | `准备工程反诉或仲裁反请求` |
| 劳动应诉 | 劳动领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

第三人被追加的转包人：正触发本任务，抗辩结构按第三人地位写，不改写成原告起诉包。
