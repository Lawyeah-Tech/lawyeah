# 应对建设工程一审

## 任务目标

在明确、无利益冲突的被告立场下，形成首次应诉答辩包：期限卡、答辩草稿、效力与质量工期抗辩、欠付范围、鉴定抗辩、反诉评估接口。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：已收到建设工程一审起诉状或应诉通知，用户为被告或第三人。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未成争，只要改施工合同或出稿（审查起草领域，本生产线搁置，只说明不实施）；
- 一般买卖、服务、租赁等无工程建设过程的合同争议（转合同争议解决）；
- 商品房买卖、开发销售或物业服务主轴（转房地产）；
- 农民工劳动关系、工资或工伤待遇主轴（转劳动）；
- 劳动争议应诉；
- 用户实为原告、只要起诉状；
- 只要管辖异议终稿且无任何实体抗辩委托；

本任务不把反诉写成已经提起。不得指导隐匿付款证据或破坏现场。

## 建立评估坐标

确认：被告立场；起诉状和证据送达日；答辩期限；原告请求；已付款和结算；质量工期反请求意向；仲裁协议；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`V#` 评估或稿件版本；`E#` 发送／送达／履行凭证。 另用 `D#` 标抗辩，`T#` 标期限卡。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验答辩期限、管辖异议期限、第 793 条、擅自使用、鉴定释明；期间规则未核验则期限字段停止。

工具不可用时继续事实、主体、程序文书状态和问题清单；请求／抗辩的法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [应诉方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 期限卡与程序动作

答辩期、管辖异议期、仲裁协议异议期分列。口头“刚收到”不得起算。过期字段标红旗，不伪造未逾期。

### 2. 逐项抗辩

主体不适格、合同无效、质量不合格、擅自使用限制之例外、已付清、固定价不应鉴定、优先受偿过期或范围错误。发包人被接受转包／违法分包人追索折价补偿或赔偿：新受理一审打开解释（二）第 6 条不予支持；被主张代位则检验怠于与到期债权；挂靠则检验订立时是否知道或应当知道。2026-06-30 前已受理一审才谈第 43 条欠付范围。不得用“不同意全部诉讼请求”代替逐项。

### 3. 对发包人路径与质量工期反诉接口

发包人被实际施工人追索：先写受理时点，再决定第 6 条、第 4 条、代位或旧案欠付范围。质量修复须核验是否已通知承包人修复（解释（二）第 16 条）。工期违约金反诉只评估是否另立，不自动生成反诉状终稿。

### 4. 鉴定与证据

对鉴定事项、检材和固定价闸提出抗辩要点。不利资料不得建议隐匿。

### 5. 答辩草稿与下一步

按答辩状结构组织草稿。反诉、管辖异议、鉴定申请只作转介。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体、工程或文本无法建立；用户坚持伪造签证、隐匿不利资料、威胁、破坏现场或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为本任务不得交付的终稿。


## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
