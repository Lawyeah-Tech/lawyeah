# 边界与路由

## 正触发

执行中拟分期或以物抵债。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 诉讼和解起草 | `起草工程和解或结算协议` |
| 申请执行 | `执行工程生效文书` |
| 商品房买卖 | 房地产物业领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

被执行人提出用未网签房屋抵工程款时，必须转房地产接口并警示无法过户风险。
