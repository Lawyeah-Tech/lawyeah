# 边界与路由

## 正触发

购房人或抵押权人对抗工程款执行。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 商品房买卖主轴 | 房地产物业领域 |
| 被执行人异议 | `应对工程案件执行` |
| 优先与抵押冲突评估 | `评估优先受偿与抵押权购房人冲突` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

购房人要求在本任务里解除商品房买卖合同并退房时，实体转房地产。
