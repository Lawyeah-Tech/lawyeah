# 边界与路由

## 正触发

已判断可停工，需要发送前停工函。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 停工权评估 | `评估停工权是否成立` |
| 解除通知 | `准备施工合同解除通知` |
| 催告付款 | `准备工程索赔或催告付款通知` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

用户把停工函写成解除函时，必须拆开或转解除通知原子。
