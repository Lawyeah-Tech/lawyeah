# 边界与路由

## 正触发

必须招标未招、串标、中标无效或未招先定需要单独评估。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 黑白合同结算层级 | `评估黑白合同与结算依据` |
| 总体效力 | `评估施工合同效力` |
| 非建设工程采购招标 | 合同争议解决领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

用户拿着备案合同和补充协议问“按哪份结”时负触发，应转黑白合同原子。
