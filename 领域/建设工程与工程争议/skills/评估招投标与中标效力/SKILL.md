# 评估招投标与中标效力

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“招投标与中标效力评估矩阵”：必须招标判断、中标效力、重新招标风险、结算依据接口。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：争议焦点是必须招标而未招、串标、中标无效或未招先定。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未成争，只要改施工合同或出稿（审查起草领域，本生产线搁置，只说明不实施）；
- 一般买卖、服务、租赁等无工程建设过程的合同争议（转合同争议解决）；
- 商品房买卖、开发销售或物业服务主轴（转房地产）；
- 农民工劳动关系、工资或工伤待遇主轴（转劳动）；
- 黑白合同结算走专项；
- 一般采购招投标非建设工程转合同争议；
- 只要总体效力总图；

本任务不重写招标文件，不把自愿招标失败写成必须招标，不终局改写结算文本层级。

## 建立评估坐标

确认：使用者与授权；项目资金来源与规模；是否属于法定必须招标；招标公告、投标文件、中标通知书；另行协议；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`V#` 评估或稿件版本；`E#` 发送／送达／履行凭证。 另用 `BD#` 标必须招标，`AW#` 标中标效力。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验招标投标法、必须招标范围和解释（一）第 1 条第三项、第 2、22 条。

工具不可用时继续事实、主体、程序文书状态和问题清单；请求／抗辩的法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [招投标方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　必须招标闸

必须招标来自法律和项目资金、规模，不来自用户口头“应该招标”。依据不足则 `BD#` 标待核。自愿招标项目不得升格为必须招标。

### 节点 2　招标程序与中标效力

串标、泄露标底、未招先定、应当招标而未招标，须有可回链事实。价格偏低本身不等于中标无效。

### 节点 3　未招先定与实质性谈判

中标前就实质性内容达成协议或先定后招，单独成行。不得把澄清答疑一律写成实质性谈判。

### 节点 4　结算依据接口

中标合同与招标文件、投标文件、中标通知书不一致时，只建解释（一）第 22 条接口，终局转黑白合同原子。

### 节点 5　重新招标风险与下一步

中标无效不等于工程白干。质量合格仍保留第 793 条接口。重新招标只作风险提示，不写成已启动。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体、工程或文本无法建立；用户坚持伪造签证、隐匿不利资料、威胁、破坏现场或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为本任务不得交付的终稿。
