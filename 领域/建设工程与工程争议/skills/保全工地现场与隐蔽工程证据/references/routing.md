# 边界与路由

## 正触发

隐蔽工程或现场影像可能灭失。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 鉴定申请 | `准备工程造价鉴定申请` 或质量鉴定原子 |
| 调查令 | `申请工程案件调查令或取证` |
| 证据总卷 | `建立工程证据与鉴定方案` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

用户提出连夜浇筑把问题盖住时必须整体停止并禁止。
