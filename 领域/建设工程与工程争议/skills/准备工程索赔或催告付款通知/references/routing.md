# 边界与路由

## 正触发

仍要对方付款、确认签证或补救，需要发送前催告或索赔函。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 解除通知 | `准备施工合同解除通知` |
| 停工通知 | `准备停工通知` |
| 精算 | `测算工程价款与结算` |
| 优先受偿行使材料 | `准备优先受偿权行使材料` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

函件标题写“索赔函”但正文要求解除：按解除原子处理，本任务负触发。
