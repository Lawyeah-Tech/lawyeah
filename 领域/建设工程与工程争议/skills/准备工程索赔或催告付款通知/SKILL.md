# 准备工程索赔或催告付款通知

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成仍要对方付款、签证确认或补救的“发送前催告或索赔通知包”：请求事项、期限依据、送达留痕、不得把逾期未复写成请求已成立。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：工程已成争，用户仍希望对方付款、确认签证或修复，需要发送前催告或索赔函。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未成争，只要改施工合同或出稿（审查起草领域，本生产线搁置，只说明不实施）；
- 一般买卖、服务、租赁等无工程建设过程的合同争议（转合同争议解决）；
- 商品房买卖、开发销售或物业服务主轴（转房地产）；
- 农民工劳动关系、工资或工伤待遇主轴（转劳动）；
- 本次主成果是解除通知或停工通知；
- 只要精算终稿或诉状；
- 依法路径已是解除且用户拒绝改发催告；

本任务不生成解除通知或停工通知终稿，不执行发送，不伪造送达，不把逾期未答复写成索赔已成立。

## 建立评估坐标

确认：单方立场；催告事项（付款／签证／修复／提供图纸场地）；合同关于索赔期限和送达渠道的约定；已完成工程或签证事实；拟签发主体和拟发送日。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`V#` 评估或稿件版本；`E#` 发送／送达／履行凭证。 通知状态只用 `草案`、`待发送`、`已发送待证明到达`、`已到达`、`停止`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验催告、付款期限、第 807 条催告与解除催告的区别；`search_template` 只借函件栏目。

工具不可用时继续事实、主体、程序文书状态和问题清单；请求／抗辩的法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [催告方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流与发送闸

解除或停工是主成果则负触发。主体、合同版本和相对人必须固定。索赔数字必须回链测算或明示估算假设，未知不写零。

### 2. 催告事项与期限

付款催告、签证确认催告、修复催告、协助义务催告分列。约定索赔期限是否已过标待核，过期不得假装仍在期限内。合理期限不得编造一律 15 日。

### 3. 发送前正文

只写已支持的主体、工程、事项、金额假设、履行方式和异议窗口。不宣称对方已违约解除，不倒签，不把优先受偿写成已经行使完毕。

### 4. 到达设计

按约定渠道、合同地址、备份送达和失败升级。已读不等于到达。本任务不执行发送。

### 5. 与解除／停工隔离

正文不得混写“逾期未付视为解除”除非该自动解除条款已核验且条件已成就。需要解除或停工：转介对应原子。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体、工程或文本无法建立；用户坚持伪造签证、隐匿不利资料、威胁、破坏现场或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为本任务不得交付的终稿。


## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
