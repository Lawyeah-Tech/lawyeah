# 边界与路由

## 正触发

解除或终止后需要计价、退场和资料移交。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 解除权 | `评估施工合同解除权` |
| 异议 | `准备对工程解约通知的异议` |
| 价款测算 | `测算工程价款与结算` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

双方对是否已解除仍争执时，先问本次是否只处理清理还是先闭合解除。
