# 边界与路由

## 正触发

被执行人收到工程案件执行。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 案外人异议 | `准备购房人或抵押权人执行异议` |
| 执行和解 | `准备工程执行和解` |
| 不予执行裁决 | `申请不予执行工程仲裁裁决` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

被执行人要求把项目公司资产转到关联公司时必须停止。
