# 边界与路由

## 正触发

已决定申请诉前或诉中财产保全。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 必要性评估 | `评估工程案件财产保全必要性` |
| 应对裁定 | `应对工程案件保全裁定` |
| 调查令 | `申请工程案件调查令或取证` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

用户提供来路不明的账户清单时，必须核验来源合法性。
