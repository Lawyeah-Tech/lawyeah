# 边界与路由

## 正触发

已决定以实际施工人身份起诉相对方，或对发包人提起代位、挂靠知情之诉。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 普通承包人起诉 | `提起建设工程一审` |
| 身份评估 | `评估实际施工人请求` |
| 发包人应诉欠付范围 | `评估发包人欠付范围内责任` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

实际施工人要求把发包人写成欠付范围或全额连带给付被告时，新受理一审必须停止该终稿，改写为对相对方给付加代位或第 4 条。
