# 原子 Skill 选择方法

## 一、先识别成果

先问这一次要拿到什么可独立验收的成果，而不是按施工、设计或法条名称匹配。当前可独立验收的成果包括：

P0：争议总图；合同效力判断；实际施工人请求边界；优先受偿判断；工程价款测算；证据与鉴定方案；催告或索赔通知；解除通知；和解方案；一审起诉包；一审应诉包。

P1：资质挂靠；招投标中标效力；黑白合同结算依据；管辖与仲裁协议；分类型期间表；管辖异议书；仲裁协议异议；设计监理或总承包界面；转包违法分包定性；劳务／专业分包／劳动界限；内部承包结算；实际施工人起诉材料（对相对方给付，对发包人代位或挂靠知情）；发包人被追索路径与账册；实际施工人代位；进度款；竣工结算；质保金返还；优先受偿行使材料；欠付利息测算；以审计为准；固定价与鉴定闸；材料调差；优先与抵押购房人冲突；工期延误；质量缺陷；签证索赔；停工权；解除权评估；停工通知；解除异议；发包人协助义务；擅自使用；解除后清理；现场证据保全；造价鉴定申请；质量鉴定申请；鉴定异议；保全必要性；保全申请；应对保全；调查令；和解协议草稿；执行力补强；调解方案；仲裁申请；效力确认之诉；优先受偿之诉；庭审提纲；上诉；撤销裁决；不予执行裁决；仲裁应诉；二审答辩；反诉评估；反诉状；执行申请；应对执行；案外人执行异议；执行和解。

刑民交叉与再审属于 P2，输出 `unavailable`。

## 二、再确认上下文

只确认会改变入口的最小信息：

1. 单方立场与授权（发包人／承包人／实际施工人／分包人／案外人）；
2. 争议是否已经形成；
3. 是否已有仲裁条款、起诉状、解除通知、鉴定意见或执行文书；
4. 本次要分析、发函、测算、建卷、谈判还是程序文书；
5. 是否属于一般合同、房地产、劳动或环境能源专项。

## 三、处理混合请求

1. 列出每项可独立验收的成果及对应入口；
2. 只问：`这次要先取得哪一项成果？`；
3. 回答前不指定主要 Skill，不暗示必须先评估再发函；
4. 用户确认后只启动所选入口；等价评估、测算或证据可由用户或律师提供。

## 四、停止

立场冲突、专项主轴或未成争改合同时，说明边界并转出，不代做。信息不足时每轮只追问一个最能改变入口的问题。未安装入口（含 P2）输出 `unavailable`。
