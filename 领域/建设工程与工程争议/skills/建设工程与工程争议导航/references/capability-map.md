# 当前能力地图

当前安装包是****（P0 + P1）。共 11 个 P0 原子 + 59 个 P1 原子。未列入的 P2（刑民交叉、再审）必须输出 `unavailable`，不得由名称相近的 Skill 代做。

| 单独盘点证据和鉴定是否启动 | `建立工程证据与鉴定方案` | 举证责任、资料矩阵、不应鉴定闸 | 预测鉴定意见、诉状 |
| 仍要对方付款、签证确认或补救 | `准备工程索赔或催告付款通知` | 发送前催告或索赔稿 | 解除通知、逾期即已成立 |

| 决定起诉且无有效仲裁阻挡 | `提起建设工程一审` | 起诉状、请求、管辖、证据目录 | 代提交；有效仲裁未排除 |
| 已收到起诉状，要首次应诉 | `应对建设工程一审` | 期限卡、答辩草稿、反诉接口 | 劳动应诉、主动起诉 |
