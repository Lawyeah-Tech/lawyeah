# 建设工程领域边界

本表只说明归属。每次路由先核对 [当前能力地图](capability-map.md)；未安装入口输出 `unavailable`。

| 相邻 | 本包入口 | 转出 |
| --- | --- | --- |
| 合同审查与起草 | 无。未成争只要改施工合同或出稿：本窗搁置，只说明不实施 | 审查起草领域（用户单独策略） |
| 合同争议解决 | 无一般买卖服务实体方法 | 无工程建设过程的一般合同争议 |
| 房地产物业 | 仅保留优先受偿与购房人、抵押权冲突接口 | 商品房买卖、开发销售、物业服务主轴 |
| 劳动 | 无工资工伤方法 | 农民工劳动关系、工资、工伤 |
| 环境能源 | 无监管合规方法 | 环评、排污、能源项目监管本身 |
| 刑事 | 评估中的刑民交叉只标红旗 | 定罪、控告、辩护 |

施工过程和工程责任留本领域，不因同时涉及合同或房地产而转移。
