# 准备对解除通知的异议

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的相对方立场下，形成异议函、继续施工或付款主张，以及确认之诉分流。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：已收到解除通知，需要异议或主张合同未解除。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未成争，只要改施工合同或出稿（审查起草领域，本生产线搁置，只说明不实施）；
- 一般买卖、服务、租赁等无工程建设过程的合同争议（转合同争议解决）；
- 商品房买卖、开发销售或物业服务主轴（转房地产）；
- 农民工劳动关系、工资或工伤待遇主轴（转劳动）；
- 不产出确认之诉诉状；
- 只要判断对方是否有解除权；

不产出确认之诉诉状。未异议不等于对方解除权被补正。继续施工或停止施工的风险必须标明。

## 建立评估坐标

确认：解除通知原文与到达日；己方催告或履行情况；质量与付款状态；是否拟继续施工；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`V#` 评估或稿件版本；`E#` 发送／送达／履行凭证。 另用 `OBJ#` 标异议，`ST#` 标合同状态主张。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验第 565 条异议和确认解除效力路径。

工具不可用时继续事实、主体、程序文书状态和问题清单；请求／抗辩的法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [解除异议方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　到达与文本

固定解除通知到达日和解除理由。理由不明则逐项反驳受限。

### 节点 2　解除权缺失抗辩

催告未完成、条件未成就、除斥可能经过、对方违约在先。判断用三态，不写对方“违法解除必然无效”。

### 节点 3　异议函

明确不同意解除、合同继续有效、已完工程价款保留。不得辱骂或威胁。

### 节点 4　继续履行选择

继续施工可能扩大损失，停工可能被指违约。两条路径风险并列，由用户选择。

### 节点 5　确认之诉分流

需要形成力时转效力确认或普通诉讼，本任务不写诉状。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体、工程或文本无法建立；用户坚持伪造签证、隐匿不利资料、威胁、破坏现场或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为本任务不得交付的终稿。


## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
