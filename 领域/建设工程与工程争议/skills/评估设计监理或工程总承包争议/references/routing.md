# 边界与路由

## 正触发

设计、监理或工程总承包界面争议需要单独评估。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 施工价款主轴 | `评估建设工程争议` |
| 环境能源监管 | 环境能源领域 |
| 工期延误 | `评估工期延误与顺延` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

EPC 项目里同时欠施工进度款时，先问本次要闭合的是界面责任还是施工价款。
