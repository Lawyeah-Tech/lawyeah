# 边界与路由

## 正触发

已判断可主张优先受偿，需要行使材料。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 优先受偿评估 | `评估工程价款优先受偿` |
| 优先受偿之诉 | `提起优先受偿权确认或实现之诉` |
| 与抵押购房人冲突评估 | `评估优先受偿与抵押权购房人冲突` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

用户要求把违约金一并优先受偿时，本任务必须剔除。
