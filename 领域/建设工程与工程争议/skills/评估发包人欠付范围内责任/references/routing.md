# 边界与路由

## 正触发

发包人被追索，需要判断解释（二）路径并框定账册风险。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 总体应诉 | `应对建设工程一审` |
| 实际施工人起诉 | `准备实际施工人对发包人起诉材料` |
| 代位权 | `评估实际施工人代位权` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 尚未成争，只要改施工合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 一般买卖、服务、租赁、承揽且无工程建设过程 | 合同争议解决领域 |
| 商品房买卖、开发销售、物业服务主轴 | 房地产物业领域 |
| 农民工劳动关系、工资、工伤待遇 | 劳动领域 |
| 环评、排污许可、能源项目监管本身 | 环境能源领域 |
| 定罪、控告、辩护 | 刑事领域 |

## 易混

发包人说“我已经把钱给总包了”时正触发：先判断路径是否成立，再核验付款对象和账册。
