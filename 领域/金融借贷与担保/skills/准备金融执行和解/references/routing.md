# 边界与路由

## 正触发

执行中拟分期或以物抵债，主成果是执行和解要点，而不是普通庭外和解或放弃生效债权。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估 | 评估金融借贷担保争议 |
| 诉讼中和解协议 | 起草还款和解协议 |
| 强制执行申请 | 执行金融生效文书 |
| 被执行人异议 | 应对金融执行 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 破产和解 | 破产领域 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

执行中对方要分期并解封房子，正触发本任务。还没判决要签和解，走起草或谈判原子。
