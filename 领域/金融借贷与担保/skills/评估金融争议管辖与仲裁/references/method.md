# 评估方法

判断只用三态。有效仲裁协议未经排除，不得输出“应向法院起诉”。不得编造全国统一由某金融法院管辖。

## 节点 0　专项转出

海事专属、破产衍生诉讼集中管辖、行政诉讼：转出。未成争改条款：审查起草搁置。

## 节点 1　仲裁协议

对照现行《仲裁法》及司法解释运行时核验：

1. 是否有请求仲裁的意思表示；
2. 是否有仲裁事项且覆盖本案请求（含保证、物保、利息）；
3. 是否选定仲裁委员会或依法可确定；
4. 是否书面（含合同书、信件、数据电文）；
5. 是否或裁或诉、既约定仲裁又约定起诉。

处理规则：

- 或裁或诉：通常仲裁协议无效，但已选择其一且对方未在规定节点异议的，可能视为放弃，须运行时核验。
- 只写“提交有关仲裁机构”但机构不明：可能无效，不擅自指定机构。
- 主合同仲裁、担保合同诉讼或相反：对担保人是否受仲裁约束标 `依据不足`，不选对用户有利的一种。
- 主合同无效不当然消灭仲裁协议。

独立保函、保理、融资租赁可能另有争议解决条款，必须分文件摘录。

## 节点 2　诉讼管辖

无仲裁或仲裁现有依据不支持适用时，才评估诉讼入口。

| 连结点 | 材料 | 禁止 |
| --- | --- | --- |
| 被告住所地 | 注册地、经常居住地证据 | 把原告所在地写成当然管辖 |
| 合同履行地 | 约定履行地、实际履行地、争议标的为给付货币时的规则待核 | 自行指定对用户最近的法院 |
| 协议管辖 | 书面、与争议有实际联系、不违反级别与专属 | 格式条款管辖未提示仍写成一定有效 |
| 不动产担保 | 可能涉及不动产所在地 | 所有金融案件都按不动产专属 |
| 金融法院 | 所在地专门管辖范围待核 | 编造全国金融案件均归金融法院 |

级别管辖按标的和省级标准待核，本任务不编造具体中院门槛数字。

## 节点 3　特别程序与仲裁互斥

实现担保物权特别程序：担保财产所在地或登记地基层法院。有仲裁条款时按担保制度解释第 45 条接口，不在本任务写成“有仲裁就不能特别程序”或相反的绝对句。

支付令、公证执行另项。

## 节点 4　已进入程序

已收到起诉状：答辩期内管辖异议转 `object-to-jurisdiction`。已首次开庭未提异议：应诉管辖接口，本任务不写出过期异议书。已进入仲裁：管辖权异议按仲裁规则，不按民诉答辩期计算。

## 节点 5　输出

论坛矩阵、互斥、待核连结点。不写完整起诉状或仲裁申请。不指导制造虚假住所或倒签补充协议抢管辖。

---

## 判断纪律与 if/then

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然免责、必然全额支持或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》《担保法》及其解释时记为噪声，不得写入 `L#`。MCP 未安装、无结果或冲突时，不拒绝执行；依赖未核验规则的法律结论、期限或机关路径字段停止。

### 节点执行顺序

1. 先专项分流：一般合同、并购交割、破产申报、未成争审查起草、刑民定罪主轴，命中则整案转出或搁置，不填本任务实体终局。
2. 再固定主体、文本版本、程序文书与送达。口头转述、“已读”、截图不得写成已受理、已送达或期限已起算。
3. 每个请求或抗辩独立建 `Q#`：法律效果、成立条件、支持与不利事实、控制方、最强反方、主备位、互斥。禁止合成一笔“贷款权益”或“担保权益”。
4. 期限分类型：诉讼时效、保证期间、除斥、约定催告期、程序异议期各占一行，禁止混算或输出唯一截止日充作法律意见。
5. 金额分项：本金、利息、罚息、复利、费用、已还。民间借贷 LPR 四倍不得套用金融机构贷款。

### if / then

| 条件 | then |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出，先澄清代表哪一方 |
| 用户坚持伪造流水、隐匿还款、暴力催收、伪造送达或违法取证 | 整体停止，不提供规避方案 |
| 主目标已变为其他原子的文书或总图 | 目标停止，按路由表转介 |
| 关键日期、送达或动态规则未核验 | 字段停止，并列情景，不选对用户最有利的一天 |
| 有效仲裁协议未经排除，用户要求直接起诉 | 不得写应起诉；转论坛或仲裁入口 |
| 破产已受理而用户要个别清偿、执行或申报 | 标红旗，申报转破产领域，本包不做申报 |
| 未成争只要改合同或出稿 | 审查起草本窗搁置，只说明不实施 |
| C 端相邻商品被点名 | 只分流，不回改、不降成大众包 |

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。下一步按期限灭失、易失证据、能否改变 `Q#`、可逆性排序。禁止指导伪造、隐匿、威胁或违法取证。
