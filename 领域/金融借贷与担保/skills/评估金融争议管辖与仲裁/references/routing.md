# 边界与路由

## 正触发

用户要选择法院还是仲裁，或对方已提出管辖／仲裁异议，金融借贷或担保争议已形成，本次主成果是论坛判断而不是完整立案包。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估总图 | 评估金融借贷担保争议 |
| 只要精算终稿 | 测算本金利息罚息复利 |
| 已决定起诉或应诉 | file-first-instance / defend-first-instance |
| 写管辖异议书 | 提出金融案件管辖异议 |
| 起诉包 | 提起金融借贷担保一审 |
| 仲裁申请包 | 提起金融仲裁 |
| 实现担保物权管辖 | 准备实现担保物权申请 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 海事专属管辖 | 海事领域 |
| 破产衍生诉讼集中管辖 | 破产领域 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

主合同有仲裁、保证合同无仲裁，正触发本任务分层，而不是直接把保证人列为共同被告起诉。用户只要起诉状且仲裁条款表面有效，先完成本任务或负触发至起诉原子的仲裁闸。
