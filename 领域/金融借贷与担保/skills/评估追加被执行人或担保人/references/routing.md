# 边界与路由

## 正触发

拟追加未列明担保人或股东，主成果是追加条件评估，而不是普通执行申请或股东出资整案。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估 | 评估金融借贷担保争议 |
| 普通执行申请 | 执行金融生效文书 |
| 股东出资或人格否认 | 公司治理领域 |
| 被执行人异议 | 应对金融执行 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 破产追加或合并破产 | 破产领域 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

判决只列公司，想追加保证人股东，正触发本任务，结论常常是另诉而非追加。已有执行依据要对公司本身执行，走执行原子。
