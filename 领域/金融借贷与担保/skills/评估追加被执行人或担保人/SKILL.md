# 评估追加被执行人或担保人

## 任务目标

在明确、无利益冲突的申请执行人立场下，形成追加条件、证据和风险。股东出资责任转公司治理；破产追加转破产。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：拟追加未列明担保人或股东，主成果是追加条件评估，而不是普通执行申请或股东出资整案。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要普通执行立案；
- 股东出资加速、人格否认整案；
- 破产管理人追加；
- 被执行人侧异议；
- 未取得执行依据；

股东出资责任转公司治理。破产追加转破产。不保证法院追加。

## 建立评估坐标

确认：使用者与授权；申请执行人立场；生效文书列明的当事人；拟追加对象及理由（一般保证人、变更后主体、合伙、无偿受让）；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 陈述；`D#` 文书；`A#` 承认；`R#` 执行卷；`C#` 担保合同；`L#` 规则；`I#` 判断；`G#` 缺口；`Q#` 追加争点；`V#` 版本；`E#` 主体变更凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《担保法》及其解释当作现行规则。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验变更追加执行当事人规定。工具不可用时继续主体事实；追加应否支持字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　公司治理／破产闸

抽逃出资、未届出资、人格否认整案：转公司治理。破产：转破产。

### 节点 2　法定追加情形

执行异议复议规定列明的情形逐项对照。不在清单内的“觉得他有钱”不支持。

### 节点 3　担保人

生效文书未列保证人：通常应另诉，不能执行里直接追加，除非符合法定情形。

### 节点 4　风险

追加错误赔偿、异议、拖延。

### 节点 5　证据

主体变更、无偿转让、合伙协议。禁止伪造。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或文本无法建立；用户坚持伪造流水、隐匿还款、暴力催收、伪造送达或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为本任务以外的文书或总图。
