# 边界与路由

## 正触发

循环授信或最高额保证的期间、决算日或余额范围存在争议，用户需要债权确定与覆盖矩阵，而不是普通单笔保证终局。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估总图 | 评估金融借贷担保争议 |
| 普通保证方式与期间终局 | 评估保证责任 |
| 最高额抵押设立与顺位 | 评估抵押质押设立与对抗 / assess-security-priority |
| 保证主张通知 | 准备保证债务主张通知 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 破产受理导致债权确定 | 确定接口可留，申报转破产 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

循环贷还在发生，银行按历史累计发生额追保证人，正触发本任务做确定与余额分层。单笔借条保证走普通保证评估。
