# 边界与路由

## 正触发

已成争，争点落在利率、服务费、砍头息、利滚利或罚息是否受保护，用户需要效力分层而不是精算终稿。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估总图 | 评估金融借贷担保争议 |
| 只要精算终稿 | 测算本金利息罚息复利 |
| 只要发送催收或保证函 | 对应通知原子 |
| 已决定起诉或应诉 | file-first-instance / defend-first-instance |
| 精算工作表 | 测算本金利息罚息复利 |
| 格式条款提示说明终局 | 评估金融格式条款 |
| 信用卡账单专项 | 评估信用卡与消费贷争议 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 刑民交叉高息、套路贷 | 只标红旗，不定罪，刑事成果转刑事 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

用户说“算一下能要多少利息”但没有流水和分段日期，正触发本任务做效力接口，而不是硬出精算终稿。银行贷款要求按四倍 LPR 砍掉罚息，负触发该结论。
