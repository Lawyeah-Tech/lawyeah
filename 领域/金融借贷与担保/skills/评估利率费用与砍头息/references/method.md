# 评估方法

判断只用三态。不得把约定利率写成法院必支持数额，不得把民间借贷保护上限套到金融机构贷款。

LPR 数字必须核验合同成立时点的一年期报价。未核验则上限字段停止，只保留“成立时一年期 LPR × 4”公式。

## 节点 0　产品与目标闸

1. 用户只要分项测算工作表：目标停止，转 `calculate-loan-balance`。
2. 出借人是金融机构：本任务可评估合同费率条款是否异常、是否提示说明，但四倍 LPR 保护上限标“不适用”，复利罚息另列待核。
3. 信用卡、消费贷账单：可留费用分层，盗刷与停卡走信用卡原子。
4. 一般合同违约金：转合同争议。

## 节点 1　名义本金与实际出借

1. 比对借条金额、放款流水、预先扣除的利息、保证金、渠道费、会员费。
2. 民法典第 670 条：借款的利息不得预先在本金中扣除；利息预先扣除的，应当按照实际借款数额返还借款并计算利息。
3. 民间借贷规定关于本金认定：预先扣除的利息，人民法院应当将实际出借的金额认定为本金。
4. 服务费付给关联第三方：不自动视为合法独立服务。看是否有真实服务、是否由出借人指定、是否与放款捆绑。无真实服务迹象则按变相利息接口，不直接写成“费用全部无效所以本金也消灭”。

## 节点 2　借期内利率

民间借贷：

- 合同成立时一年期 LPR 四倍为司法保护上限；
- 未约定利息，出借人主张借期内利息的，不予支持（逾期另议）；
- 约定不明，自然人之间不支持借期内利息；其他民间借贷可参照 LPR 接口，须运行时核验现行条文。

金融机构：

- 不适用上述四倍规则；
- 关注是否超出监管允许或构成不当高息，依据不足则字段停止；
- 不得用民间借贷案例反推银行贷款无效。

## 节点 3　逾期、罚息、复利、违约金

分项建 `Q-息` `Q-罚` `Q-复` `Q-违` `Q-费`，期间不得重叠计。

| 材料 | 本任务处理 | 禁止 |
| --- | --- | --- |
| 既约定逾期利率又约定违约金 | 分层，是否调整或择一待核 | 全部累加写成必得 |
| 利滚利、复利 | 标是否计入本金再计息 | 直接宣布合法或当然无效 |
| 砍头息已扣 | 调实际本金 | 再按名义本金计满息 |
| 已付高息 | 冲抵接口 | 自动认定全部合法或全部应退 |

民间借贷逾期利率、违约金、其他费用之和不得超出保护上限的规则须运行时核验。已付超出部分是否冲抵本金，只给情景。

## 节点 4　格式条款与提示

加速、复利、高额违约金若位于格式条款：标格式条款评估接口，不在本任务做提示说明终局。签前审查搁置。

## 节点 5　输出

只输出效力分层、参数清单和测算接口。禁止唯一必得总额。禁止指导做两套账或销毁扣费凭证。

## 判断纪律与 if/then

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然免责、必然全额支持或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》《担保法》及其解释时记为噪声，不得写入 `L#`。MCP 未安装、无结果或冲突时，不拒绝执行；依赖未核验规则的法律结论、期限或机关路径字段停止。

### 节点执行顺序

1. 先专项分流：一般合同、并购交割、破产申报、未成争审查起草、刑民定罪主轴，命中则整案转出或搁置，不填本任务实体终局。
2. 再固定主体、文本版本、程序文书与送达。口头转述、“已读”、截图不得写成已受理、已送达或期限已起算。
3. 每个请求或抗辩独立建 `Q#`：法律效果、成立条件、支持与不利事实、控制方、最强反方、主备位、互斥。禁止合成一笔“贷款权益”或“担保权益”。
4. 期限分类型：诉讼时效、保证期间、除斥、约定催告期、程序异议期各占一行，禁止混算或输出唯一截止日充作法律意见。
5. 金额分项：本金、利息、罚息、复利、费用、已还。民间借贷 LPR 四倍不得套用金融机构贷款。

### if / then

| 条件 | then |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出，先澄清代表哪一方 |
| 用户坚持伪造流水、隐匿还款、暴力催收、伪造送达或违法取证 | 整体停止，不提供规避方案 |
| 主目标已变为其他原子的文书或总图 | 目标停止，按路由表转介 |
| 关键日期、送达或动态规则未核验 | 字段停止，并列情景，不选对用户最有利的一天 |
| 有效仲裁协议未经排除，用户要求直接起诉 | 不得写应起诉；转论坛或仲裁入口 |
| 破产已受理而用户要个别清偿、执行或申报 | 标红旗，申报转破产领域，本包不做申报 |
| 未成争只要改合同或出稿 | 审查起草本窗搁置，只说明不实施 |
| C 端相邻商品被点名 | 只分流，不回改、不降成大众包 |

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。下一步按期限灭失、易失证据、能否改变 `Q#`、可逆性排序。禁止指导伪造、隐匿、威胁或违法取证。
