# 边界与路由

## 正触发

银行扣划存款或主张抵销，已成争，主成果是抵销是否成立，而不是帮助转移账户资金逃避扣划。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估 | 评估金融借贷担保争议 |
| 只要精算终稿 | 测算本金利息罚息复利 |
| 执行扣划异议 | 应对金融执行 |
| 保全扣划 | 应对金融案件保全裁定 |
| 加速是否成立 | 评估加速到期与提前收回 |
| 格式条款授权扣划 | 评估金融格式条款 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 破产抵销权 | 破产领域 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

银行从借款人结算户扣走到期贷款，正触发本任务。客户要求马上把钱转到亲属卡避扣，停止。
