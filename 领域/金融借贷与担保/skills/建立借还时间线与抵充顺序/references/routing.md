# 边界与路由

## 正触发

需要单独把放款、还款、抵充做成可回链时间线，主成果是事件表而不是欠款总额或效力结论。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估 | 评估金融借贷担保争议 |
| 精算欠款总额 | 测算本金利息罚息复利 |
| 利率费用效力 | 评估利率费用与砍头息 |
| 调查令调流水 | 申请调查令调取流水 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 破产撤销个别清偿时间线 | 破产领域接口 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

双方对还了多少各执一词，正触发本任务先做时间线，而不是直接给一个欠款数。
