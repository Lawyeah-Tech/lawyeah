# 边界与路由

## 正触发

票据贴现、回购式融资或票据担保已成争，主成果是票据关系与原因关系分层。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估 | 评估金融借贷担保争议 |
| 融资总定性 | 识别融资安排法律性质 |
| 普通借款起诉 | 提起金融借贷担保一审 |
| 独立保函／信用证 | 评估独立保函 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 海事提单 | 海事领域 |
| 票据诈骗 | 刑事领域，不定罪 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

银承贴现后前手主张没有真实贸易，正触发本任务。海运提单被扣，转海事。
