# 边界与路由

## 正触发

银行、AMC、保理或其他受让人受让或被告知转让后发生争议，主成果是转让对债务人和保证人的效力，而不是保理基础交易真实性或破产申报。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估总图 | 评估金融借贷担保争议 |
| 已决定起诉或应诉 | file-first-instance / defend-first-instance |
| 保理真实性或第 768 条顺位 | 评估保理真实性与通知 |
| 保理通知应收账款债务人 | 准备保理债权转让通知 |
| 保证人是否仍担责实体 | 评估保证责任 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 破产程序内债权申报或重整转让 | 破产领域 |
| 不良资产包并购交割 | 投资并购领域 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

债务人收到 AMC 公告但未收到银行个别通知，正触发本任务，而不是直接改向 AMC 还款结论。保理三方结构走保理原子。
