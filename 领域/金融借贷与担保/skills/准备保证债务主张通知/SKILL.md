# 准备保证债务主张通知

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《担保法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的债权人立场下，形成保证期间内向保证人主张的发送前稿：方式与对象回链、期间情景、发送前主张稿、到达设计，以及一般保证不得以本函代替对债务人起诉的明示。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：已有保证条款，用户已决定在保证期间内向保证人主张，本次主成果是发送前主张通知。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 本次主成果是对主债务人催收或加速（转 `prepare-collection-notice`）；
- 只要保证责任评估，不发函；
- 一般保证且用户要把本函当成“已经在期间内对债务人起诉”；
- 独立保函交单索款；
- 未成争改保证合同；一般合同、并购、破产申报。

本任务不把发送写成保证责任已确定，不替用户实际发送。

## 建立评估坐标

确认：使用者与授权；债权人立场；保证人及通知接收主体；保证方式原文；主债务履行期限；已知催收和诉讼；物保并存；约定送达渠道；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 主张项；`T#` 期间情景；`V#` 稿件版本；`E#` 发送／送达凭证。文稿状态只用 `草案`、`发送前复核`、`不得发送`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验第 686、692、693 条、解释第 31、32、34 条和时间效力规定第 27 条。对行权对象和期间效果为 required。工具不可用时继续稿件结构；期间是否仍在、对象是否正确字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 方式与对象闸

先对照保证方式。一般保证：本函不能代替对债务人提起诉讼或申请仲裁。连带：本函须构成对保证人的请求，对象和内容须可回链。方式不明：现行默认一般保证，不得按连带发出“请立即代偿”终稿，除非用户接受 `不得发送` 或改为并行情景。

### 2. 期间情景

列出约定期间、视为无约定、六个月情景；施行前合同另列时间效力规定第 27 条二年／六个月情景。关键日期冲突则并行情景，不给唯一届满日。期间明显可能已届满：稿件标 `不得发送` 或只作出示风险的草案，并转介保证评估。

### 3. 主张内容回链

主张范围回链第 691 条或约定。不得把未支持的律师费、复利写成已决。主债金额未知不写零。

### 4. 发送前稿

锁定 `V#`。写明主债、保证合同、请求事项和权利保留。禁止写“保证人签收即不得再抗辩”。

### 5. 到达设计

约定渠道、备份渠道、回证。已读不等于到达。抄送主债务人不得写成已对债务人起诉。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或文本无法建立；用户坚持伪造流水、隐匿还款、暴力催收、伪造送达或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为本任务以外的文书或总图。
