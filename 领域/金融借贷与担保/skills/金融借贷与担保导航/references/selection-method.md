# 原子 Skill 选择方法

## 一、先识别成果

先问这一次要拿到什么可独立验收的成果，而不是按银行贷款、民间借贷或法条名称匹配：

- 争议总图；保证责任；催收或加速通知；保证主张通知；本金利息测算；证据案卷；实现担保物权申请；和解方案；一审起诉；一审应诉（P0）；
- 民间借贷效力、融资定性、利率费用、放贷资质、论坛仲裁、时效与保证期间、加速条件、电子签约、债权转让、管辖异议、格式条款；
- 公司对外担保、独立保函、最高额保证、保证追偿评估或起诉、人保物保并存；
- 抵押质押设立对抗、顺位、让与担保、应收或股权出质、应对实现申请、涂销变更、动产超级优先、办登诉讼；
- 借还时间线、提前还款、银行抵销、加速后清算、公证催收或赋强、执行赋强文书；
- 电子证据保全、保全必要性、保全申请、应对保全、调查令、鉴定异议；
- 和解协议正文、庭外重组、执行力补强；
- 程序选择、支付令、仲裁申请或应诉、庭审、上诉或二审答辩、反诉评估或准备；
- 保理、保理通知、融资租赁、租赁物取回、信用卡、银行理财、委托贷款、票据融资、网贷平台；
- 执行申请、应对执行、追加被执行人、执行和解、破产入口分流、夫妻共债交叉。

## 二、再确认上下文

只确认会改变入口的最小信息：

1. 单方立场与授权（债权人 / 债务人 / 保证人 / 物上保证人）；
2. 争议是否已经形成；
3. 是否已有仲裁条款、起诉状、催收函或保证期间届满风险；
4. 本次要分析、发函、测算、建卷、谈判、特别程序还是诉讼文书；
5. 是否属于一般合同、并购交割或已进入破产程序。

## 三、处理混合请求

1. 列出每项可独立验收的成果及对应入口；
2. 只问：`这次要先取得哪一项成果？`；
3. 回答前不指定主要 Skill，不暗示必须先评估再发函；
4. 用户确认后只启动所选入口；等价评估、测算或证据可由用户或律师提供。

## 四、停止

立场冲突、一般合同主轴、并购交割、破产程序内申报或未成争改合同时，说明边界并转出，不代做。信息不足时每轮只追问一个最能改变入口的问题。
