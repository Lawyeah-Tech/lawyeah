# 金融借贷担保领域边界

本表只说明归属。每次路由先核对 [当前能力地图](capability-map.md)；未安装入口输出 `unavailable`。

| 相邻 | 本包入口 | 转出 |
| --- | --- | --- |
| 合同审查与起草 | 无。未成争只要改合同或出稿：本窗搁置，只说明不实施 | 审查起草领域（用户单独策略） |
| 一般合同争议 | 无 | 买卖、服务、承揽等一般履行、解除、违约金主轴 |
| 投资并购 | 融资借贷和增信安排可留 | 以股权或资产交易交割为主要成果 |
| 破产重整 | `route-to-bankruptcy` 仅识别分流（本包未安装则 `unavailable` 并说明转破产） | 破产债权申报、重整计划、清算分配 |
| 婚家 | 配偶签字与共债只做接口 | 夫妻共同债务整案 |
| 公司治理 | 公司对外担保决议可评估 | 股东出资、人格否认整案 |
| 刑事 | 评估中的刑民交叉只标红旗 | 定罪、控告、辩护 |
| C 端保证评估 / 利息测算 | 专业保证矩阵或复利/LPR/担保测算 | 大众第一轮争点或普通单利测算 |
| C 端 011 / 012 | 专业起诉/应诉包 | 大众网上立案或民事答辩 |

一般借贷夹带买卖或服务背景时，非金融段只分流，不把一般合同规则写成金融结论。
