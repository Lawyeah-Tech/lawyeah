# 边界与路由

## 正触发

已收到仲裁申请，主成果是答辩与协议抗辩，而不是反客为主提交仲裁申请或法院起诉。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估 | 评估金融借贷担保争议 |
| 程序尚未选定 | 选择诉讼仲裁支付令或特别程序 |
| 提起仲裁 | 提起金融仲裁 |
| 法院应诉 | 应对金融借贷担保一审 |
| 反请求终稿 | 准备金融反诉或仲裁反请求 |
| 法院管辖异议 | 提出金融案件管辖异议 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 撤销或不予执行涉外裁决 | 跨境／司法审查交叉 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

保证人收到仲裁通知但保证合同无仲裁条款，正触发本任务先协议抗辩。收到的是法院传票，走诉讼应诉。
