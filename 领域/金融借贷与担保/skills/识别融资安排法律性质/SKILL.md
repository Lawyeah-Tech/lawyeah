# 识别融资安排法律性质

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《担保法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成融资安排定性路径：名股实债、售后回租、名为买卖实为借贷、让与担保功能识别，以及应适用借款、担保、融资租赁或保理规则的分流。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：交易文件名称与资金占用、回购、保底或担保功能可能不一致，已成争或即将成争，用户需要法律性质识别和规则分流，而不是重写交易文件或完成并购交割。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 以股权或资产交割、对价调整为主要成果（转投资并购）；
- 只要改交易文件或出稿（审查起草搁置）；
- 性质已无争议，只要催收、起诉或实现担保；
- 单纯民间借贷成立或单纯保证评估；
- 破产程序内重整计划或申报；

本任务不重写交易文件，不完成并购交割，不把合同名称写成唯一性质，不给胜诉率。

## 建立评估坐标

确认：使用者与授权；单方立场；交易各方；全套文件名称与资金流向；是否有回购、保底、固定收益、过户或租赁外衣；法域；当前争议阶段。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 定性假设；`V#` 评估版本；`E#` 资金与登记凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典借款、担保、融资租赁、保理及让与担保实务口径；`search_practiced` 补名实不符路径。工具不可用时继续资金流向和文件结构；规则适用结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　并购与破产闸

主要成果是股权或资产交割、对价调整、交割条件：整案转投资并购。破产已受理要申报或重整：转破产。未成争只要改文件：审查起草搁置。

### 节点 2　资金流向与权利外观

先画资金占用、固定收益、回购、过户、登记和风险承担，再看文件名称。名称是证据之一，不是定性结论。

### 节点 3　定性假设分列

名股实债、售后回租、名为买卖实为借贷、让与担保、融资租赁、保理、委托贷款分别建 `Q#`，互斥关系必须可见。不得预先锁定“就是借贷”。

### 节点 4　担保功能识别

过户、让与、保证金、回购是否具有担保功能。有担保功能不自动等于典型抵押已设立，清算义务和流质禁止另标。

### 节点 5　规则分流

定性只到规则接口：借款返还、担保物权实现、融资租赁取回、保理通知。不在本任务写实现申请或重做交易文件。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或文本无法建立；用户坚持伪造流水、隐匿还款、暴力催收、伪造送达或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为本任务以外的文书或总图。
