# 边界与路由

## 正触发

交易文件名称与资金占用、回购、保底或担保功能可能不一致，已成争或即将成争，用户需要法律性质识别和规则分流，而不是重写交易文件或完成并购交割。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估总图 | 评估金融借贷担保争议 |
| 只要精算终稿 | 测算本金利息罚息复利 |
| 只要发送催收或保证函 | 对应通知原子 |
| 已决定起诉或应诉 | file-first-instance / defend-first-instance |
| 让与担保专项 | 评估让与担保 |
| 融资租赁专项 | 评估融资租赁性质与取回 |
| 保理专项 | 评估保理真实性与通知 |
| 委托贷款专项 | 评估委托贷款结构 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 股权或资产并购交割整案 | 投资并购领域 |
| 证券虚假陈述或私募合格投资者整案 | 投资并购／证券交叉 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

文件写股权投资但约定到期无条件回购本息，正触发本任务。用户只要把回购协议改得更像股权，负触发至审查起草（搁置）。售后回租不是当然融资租赁。
