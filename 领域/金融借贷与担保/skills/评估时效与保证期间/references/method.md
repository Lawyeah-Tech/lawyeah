# 评估方法

判断只用三态。禁止输出“保证责任已消灭且无需再审其他条件”的实体终局。禁止唯一截止日。

`search_law` 返回已失效《担保法》“约定不明视为两年或连带”时记为噪声。

## 节点 0　目标闸

用户要的是保证人还要不要还：转 `assess-guarantee-liability`，本任务只提供期间附件。用户要发函：转通知原子。日期全无：只列表格框架，届满字段停止。

## 节点 1　诉讼时效

1. 普通时效三年，自权利人知道或应当知道权利受到损害以及义务人之日（第 188 条）。
2. 分期履行：自最后一期履行期限届满之日起算（第 189 条）。
3. 加速到期后时效是否自加速通知到达或约定加速日起算，建并行情景，须运行时核验，不擅自锁定。
4. 中断：请求、同意履行、起诉或申请仲裁等，须有送达或受理凭证。微信已读不等于中断已发生。
5. 法院不主动适用时效，本任务不得写“法院会依职权驳回”。

## 节点 2　保证期间

1. 保证期间是确定保证人承担保证责任的期间，不发生中止、中断和延长（第 692 条）。
2. 约定早于主债务履行期或与之同时届满的，视为没有约定。
3. 没有约定或约定不明确：自主债务履行期限届满之日起六个月。
4. “直至本息还清时为止”视为约定不明，六个月（解释第 32 条）。这不是无限期，也不是“过期一定免责”的实体终局。
5. 施行前成立的保证合同，期间没有约定或约定不明确的，按时间效力规定第 27 条并列二年／六个月情景：约定不明且主债务履行期限届满至民法典施行之日不满二年的，当事人可主张二年；没有约定且届满至施行日不满六个月的，当事人可主张六个月。不得把解释第 32 条六个月写成施行前合同的唯一届满日。
6. 一般保证：期间内须对**债务人**起诉或申请仲裁（第 693 条第一款）。
7. 连带责任保证：期间内须**请求保证人**（第 693 条第二款）。
8. 撤诉效果按解释第 31 条分一般／连带，本任务只列情景。

主债务履行期不明：自债权人请求债务人履行的宽限期届满之日起算保证期间。

## 节点 3　保证债务诉讼时效

与保证期间分列。第 694 条：一般保证自保证人拒绝承担保证责任的权利消灭之日起算；连带责任保证自债权人在保证期间内请求保证人承担保证责任之日起算。不得用保证期间代替该时效。

## 节点 4　其他期间

- 撤销权除斥、保证合同可撤销：单独一行。
- 约定催告期、加速宽限期：按合同原文，不写成法定保证期间。
- 管辖异议期、上诉期：已进入程序时标红旗，本任务不写出异议截止日期充作法律意见。

## 节点 5　并行情景

关键日期冲突：至少列出“按约定届满日／按催告宽限期／按加速日”三套公式，判断标依据不足。禁止指导倒签催收或伪造送达抢时效。

## 判断纪律与 if/then

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然免责、必然全额支持或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》《担保法》及其解释时记为噪声，不得写入 `L#`。MCP 未安装、无结果或冲突时，不拒绝执行；依赖未核验规则的法律结论、期限或机关路径字段停止。

### 节点执行顺序

1. 先专项分流：一般合同、并购交割、破产申报、未成争审查起草、刑民定罪主轴，命中则整案转出或搁置，不填本任务实体终局。
2. 再固定主体、文本版本、程序文书与送达。口头转述、“已读”、截图不得写成已受理、已送达或期限已起算。
3. 每个请求或抗辩独立建 `Q#`：法律效果、成立条件、支持与不利事实、控制方、最强反方、主备位、互斥。禁止合成一笔“贷款权益”或“担保权益”。
4. 期限分类型：诉讼时效、保证期间、除斥、约定催告期、程序异议期各占一行，禁止混算或输出唯一截止日充作法律意见。
5. 金额分项：本金、利息、罚息、复利、费用、已还。民间借贷 LPR 四倍不得套用金融机构贷款。

### if / then

| 条件 | then |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出，先澄清代表哪一方 |
| 用户坚持伪造流水、隐匿还款、暴力催收、伪造送达或违法取证 | 整体停止，不提供规避方案 |
| 主目标已变为其他原子的文书或总图 | 目标停止，按路由表转介 |
| 关键日期、送达或动态规则未核验 | 字段停止，并列情景，不选对用户最有利的一天 |
| 有效仲裁协议未经排除，用户要求直接起诉 | 不得写应起诉；转论坛或仲裁入口 |
| 破产已受理而用户要个别清偿、执行或申报 | 标红旗，申报转破产领域，本包不做申报 |
| 未成争只要改合同或出稿 | 审查起草本窗搁置，只说明不实施 |
| C 端相邻商品被点名 | 只分流，不回改、不降成大众包 |

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。下一步按期限灭失、易失证据、能否改变 `Q#`、可逆性排序。禁止指导伪造、隐匿、威胁或违法取证。
