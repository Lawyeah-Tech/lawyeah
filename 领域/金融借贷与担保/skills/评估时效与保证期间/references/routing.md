# 边界与路由

## 正触发

用户单独委托核验诉讼时效与保证期间，金融借贷或担保已成争或即将行权，本次主成果是期间表而不是保证责任实体结论。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估总图 | 评估金融借贷担保争议 |
| 只要精算终稿 | 测算本金利息罚息复利 |
| 已决定起诉或应诉 | file-first-instance / defend-first-instance |
| 保证责任实体结论 | 评估保证责任 |
| 发送保证主张通知 | 准备保证债务主张通知 |
| 最高额保证决算期 | 评估最高额保证 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 破产程序中申报期间 | 破产领域，本任务不做申报期计算终局 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

用户问“还能不能告保证人”，若只要期间表则正触发；若要实体免责结论，转保证评估。把催收借款人短信写成保证期间已中断，是本任务必须挡住的错误。
