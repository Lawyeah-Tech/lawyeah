# 准备催收或加速到期通知

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《担保法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的债权人立场下，形成向主债务人催收或宣布加速到期的发送前稿：请求回链、加速条件待核、发送前稿、约定渠道＋备份渠道＋回证的最低送达留痕设计。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：金融借贷已成争，用户已决定向主债务人催收逾期款项或宣布加速到期，本次主成果是发送前通知而不是保证主张或起诉状。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 本次主成果是向保证人主张保证责任（转 `prepare-guarantee-claim-notice`）；
- 尚未成争，只要改合同或出稿（审查起草领域，本生产线搁置）；
- 只要精算终稿、证据卷、诉状或实现担保物权申请；
- 一般合同催告、并购交割、破产申报。

本任务不把催收写成已经判决或已经加速生效，不替用户实际发送。未经核验加速条件，不得写“本通知到达即全部到期且不可争议”。

## 建立评估坐标

确认：使用者与授权；债权人立场；主债务人及通知接收主体；主合同版本；被催收的本金利息；拟加速的约定条款；已发出过的催收；约定送达渠道、已知地址和电子账号；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 催收请求项；`V#` 催收稿版本；`E#` 发送／送达／履行凭证。文稿状态只用 `草案`、`发送前复核`、`不得发送`。本任务形成的文本一律视为未发送。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验催收、加速条件、通知到达和时效中断；`search_template` 只借鉴函件栏目结构。`search_law` 对加速效果和法律效果表述为 required。工具不可用时继续事实回链和稿件结构；加速是否生效、时效中断和到达效果字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 主成果闸

确认本次主成果是对主债务人的催收或加速通知。对保证人主张、只要诉状或未成争改合同，负触发。已发出的催收如实登记，不重复冒充首份。

### 2. 催收事项与事实回链

每个 `Q#` 写明到期日、已还、尚欠项目和支持事实。名义金额不得自动等同实际本金。砍头息迹象只标接口，不在函中把争议本金写成已决。

### 3. 加速条件闸

仅催收不加速时，不得写入全部提前到期。拟加速时核对应条款或第 673 条用途违约等法定接口；条件未闭合则加速语句字段停止或稿件标 `不得发送`。

### 4. 发送前稿

锁定唯一 `V#`。正文只写已支持的主体、合同版本、事实、请求、权利保留。默认不得写“本函到达即判决生效”。保证人可抄送，但抄送不等于对保证人完成期间内行权，须在交接中明示。

### 5. 送达留痕

最低交付约定渠道、备份渠道和回证字段。微信已读不等于到达。本任务不实际发送。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或文本无法建立；用户坚持伪造流水、隐匿还款、暴力催收、伪造送达或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为本任务以外的文书或总图。
