# 边界与路由

## 正触发

已被申请拍卖变卖担保财产，主成果是异议与实质性争议分层，而不是帮助转移财产或主动申请实现。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估 | 评估金融借贷担保争议 |
| 申请人准备实现申请 | 准备实现担保物权申请 |
| 普通一审应诉 | 应对金融借贷担保一审 |
| 执行拍卖应对 | 应对金融执行 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 海事船舶拍卖 | 海事领域 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

收到实现担保物权申请，主张贷款已还清，正触发本任务。已被判决进入执行拍卖，转执行应对。要求连夜过户给亲属，停止。
