# 边界与路由

## 正触发

应收账款或股权出质的设立、通知或处分限制成为争点，主成果是出质效力，而不是保理顺位或实现申请。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或办理登记出稿 | 审查起草领域（本窗搁置） |
| 只要实现担保物权申请书 | 准备实现担保物权申请 |
| 只要总体评估 | 评估金融借贷担保争议 |
| 保理真实性与第 768 条 | 评估保理真实性与通知 |
| 一般抵押设立 | 评估抵押质押设立与对抗 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 上市公司股份质押监管 | 证券交叉只标红旗 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

同一笔应收既办理了质押登记又做了保理，正触发本任务评估出质，顺位转保理原子。用户要去统一登记系统填表，未成争则搁置。
