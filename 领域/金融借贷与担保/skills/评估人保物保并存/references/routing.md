# 边界与路由

## 正触发

同一债务既有保证又有抵押或质押，用户需要实现顺序和选择权分层，而不是直接提交实现申请或保证通知。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估总图 | 评估金融借贷担保争议 |
| 普通保证方式与期间终局 | 评估保证责任 |
| 实现担保物权申请 | 准备实现担保物权申请 |
| 保证主张通知 | 准备保证债务主张通知 |
| 追偿评估 | 评估保证人追偿权 |
| 让与担保定性 | 评估让与担保 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 破产中担保权行使与别除 | 破产领域 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

同一贷款既有房抵又有法人连带保证，问先执行谁，正触发本任务。用户已决定拍卖房子，转实现申请原子。
