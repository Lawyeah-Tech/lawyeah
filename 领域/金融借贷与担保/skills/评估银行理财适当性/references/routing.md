# 边界与路由

## 正触发

银行理财亏损后争适当性、告知或刚兑表述，主成果是适当性与因果，而不是证券虚假陈述整案。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估 | 评估金融借贷担保争议 |
| 融资安排总定性 | 识别融资安排法律性质 |
| 证券虚假陈述／私募 | 投资并购或证券交叉 |
| 委托贷款 | 评估委托贷款结构 |
| C 端委托理财 | 大众包只分流 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 行政罚没、监管通报 | 合规或行政交叉 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

银行理财亏了，销售时说稳赚，正触发本任务。股市跟庄亏了要告上市公司，转证券交叉。
