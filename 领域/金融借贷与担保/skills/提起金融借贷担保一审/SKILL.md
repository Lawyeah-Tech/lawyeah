# 提起金融借贷担保一审

## 任务目标

在明确、无利益冲突的原告立场下，形成可复核、不代提交的“金融借贷担保一审起诉包”：起诉状草稿、分项诉讼请求（可含保证人、物上保证人、优先受偿）、管辖连结点、证据目录和保全红旗。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：金融借贷或担保已成争，用户已决定向人民法院提起一审，且无表面有效的仲裁协议阻挡诉讼，或阻挡已被可回链证据排除。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未成争，只要改合同（审查起草搁置）；
- 只要总体评估、和解方案、催收或保证函；
- 仲裁条款表面有效且未被排除，用户仍要求“直接起诉”；
- 已决定申请实现担保物权特别程序；
- 已收到起诉状、用户实为被告；
- 一般合同、并购交割、破产申报、劳动专属。

C 端 011 只分流。本任务不代提交，不保证受理或胜诉，不把有效仲裁写成应起诉。

## 建立评估坐标

确认：使用者与授权；原告立场；被告及拟列保证人、物上保证人；主合同与担保合同；拟提出的请求；仲裁条款及排除证据；管辖连结点；法域。已有受理凭证或案号时，停止生成起诉入口材料。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`P#` 诉讼请求；`J#` 管辖连结点；`V#` 稿件版本；`E#` 凭证。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 仲裁阻却与程序选择闸

仲裁条款出现时不得直接写应起诉。表面有效且未排除则负触发。拟走实现担保物权特别程序且无实质性争议：负触发至该申请原子。

### 2. 主体与分项请求

原告须与本案有直接利害关系，被告须明确。本金、利息、罚息、保证责任、优先受偿分列，禁止合成“贷款权益”。以诉讼方式行使担保物权的，应当以债务人和担保人作为共同被告。一般保证期间内未列债务人：期间效果字段停止并明示风险。

### 3. 管辖连结点

分列被告住所地、合同履行地、协议管辖、专属管辖和级别管辖。连结点材料不足时不选定唯一法院。

### 4. 证据目录与保全红旗

证据按待证事实绑定请求。保全只做红旗，不写保全申请终稿。

### 5. 起诉状草稿与提交核验

按起诉状法定事项组织草稿。不代提交，不保证立案或胜诉。不把本包改写成 C 端 011。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或文本无法建立；用户坚持伪造流水、隐匿还款、暴力催收、伪造送达或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为本任务以外的文书或总图。
