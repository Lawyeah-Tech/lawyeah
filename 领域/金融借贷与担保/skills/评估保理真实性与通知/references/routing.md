# 边界与路由

## 正触发

争基础交易真实性、通知或保理优先顺位，主成果是保理专项矩阵。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估 | 评估金融借贷担保争议 |
| 普通债权转让 | 评估金融债权转让 |
| 保理通知函 | 准备保理债权转让通知 |
| 应收质押 | 评估应收账款或股权质押 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 破产中保理财产权属 | 破产领域 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

保理后债务人说基础买卖是假的，正触发本任务。只是银行把贷款债权卖给 AMC，走转让原子。
