# 识别破产程序入口并分流

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《担保法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成破产入口红旗、个别清偿风险和交接。不做破产债权申报；申报转破产领域。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：出现破产受理、重整或集中清偿信号，主成果是识别与分流，而不是申报债权或制定重整计划。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 用户要在本包完成债权申报、重整计划或债权人会议策略；
- 无任何破产信号的普通催收；
- 庭外重组无破产原因（转庭外重组原子）；
- 强制清算公司登记整案；
- 指导个别抢先扣款规避破产撤销；

不做破产债权申报。申报转破产领域。不指导个别抢清偿。

## 建立评估坐标

确认：使用者与授权；立场；债务人名称；受理裁定、预重整、集中管辖公告；个别诉讼或执行状态；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 陈述；`D#` 公告；`A#` 承认；`R#` 受理裁定；`C#` 合同；`L#` 规则；`I#` 判断；`G#` 缺口；`Q#` 入口红旗；`V#` 版本；`E#` 裁定与送达。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验破产法受理效果、个别清偿、申报期接口，仅用于识别分流。工具不可用时继续程序事实；申报期计算字段停止并转出。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　信号识别

受理裁定、指定管理人、申报公告、重整／和解／清算、实质合并。传闻不足。

### 节点 2　个别程序效果

保全解除、执行中止、新诉限制。本任务只指出应交接，不操作破产程序。

### 节点 3　个别清偿风险

受理后个别清偿无效；受理前临界期偏颇清偿可能撤销。禁止建议抢扣。

### 节点 4　担保

别除权、保证人追偿申报均转破产领域。

### 节点 5　交接清单

最小材料包交给破产领域：文书、债权计算、担保、未结诉讼。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或文本无法建立；用户坚持伪造流水、隐匿还款、暴力催收、伪造送达或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为本任务以外的文书或总图。
