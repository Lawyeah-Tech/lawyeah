# 边界与路由

## 正触发

出现破产受理、重整或集中清偿信号，主成果是识别与分流，而不是申报债权或制定重整计划。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估 | 评估金融借贷担保争议 |
| 庭外重组无受理 | 评估庭外重组方案 |
| 保证责任是否仍可追 | 评估保证责任 |
| 继续个别执行 | 受理后应停止并转破产 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 债权申报、重整计划、债权人会议 | 破产领域（本包不做申报） |
| 强制清算登记 | 公司清算交叉 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

看到法院受理重整公告，问贷款还能不能执行，正触发本任务并转出。用户要你在本包填申报表，停止并转破产。
