# 边界与路由

## 正触发

金融借贷或担保争议的和解条件已谈拢，需要可签协议正文，而不是谈判方案或司法确认手续。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估 | 评估金融借贷担保争议 |
| 谈判方案尚未谈拢 | 谈判金融和解与分期 |
| 司法确认或赋强补强 | 办理金融和解执行力补强 |
| 执行中和解 | 准备金融执行和解 |
| 未成争补签借款合同 | 审查起草搁置 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 破产和解或重整计划 | 破产领域 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

分期方案已经微信谈定，要写成协议，正触发本任务。还在谈能打几折，走谈判原子。没纠纷只想补一纸借条，搁置。
