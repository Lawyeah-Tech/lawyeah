# 边界与路由

## 正触发

收到上诉状，主成果是二审答辩，而不是自己提起上诉或重做一审。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估 | 评估金融借贷担保争议 |
| 主动上诉 | 提起金融案件上诉 |
| 一审应诉 | 应对金融借贷担保一审 |
| 庭审提纲 | 准备金融案件庭审 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 再审 | 本包未安装则 unavailable |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

对方上诉了要写答辩，正触发本任务。自己也想改判，期限未过应并行上诉原子。
