# 评估放贷资质与职业放贷

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《担保法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成放贷资质与职业放贷争点表：是否未依法取得放贷资格、是否以营利为目的向不特定对象放贷、无效后果分层，以及担保人过错接口。不定罪。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：对方被指职业放贷、无牌放贷或非法金融，民事争议已形成，用户需要资质争点和无效后果，而不是刑事定性或总体效力终局。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主目标是定罪、报案材料或刑事辩护（转刑事）；
- 只要民间借贷成立交付总评且无资质争点；
- 只要利率精算或催收函；
- 尚未成争只要设计放贷结构（审查起草搁置）；
- 金融机构牌照行政处罚整案；

本任务不定罪，不替代效力总评，不把职业放贷迹象写成已经犯罪，刑民交叉只标红旗。

## 建立评估坐标

确认：使用者与授权；单方立场；出借人身份与是否持牌；放贷笔数、对象是否特定、是否公开招揽、利率水平；担保人是否知情；法域；有无刑事立案。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 承认；`R#` 机关文书；`C#` 合同；`L#` 已核验规则；`I#` 判断；`G#` 缺口；`Q#` 资质争点；`V#` 版本；`E#` 多笔放贷与招揽凭证。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　刑民交叉闸

出现非法吸收公众存款、集资诈骗、骗取贷款、套路贷刑事立案或明确报案目标：民事本任务可继续资质与效力接口，但罪名、强制措施和辩护整案转刑事。不定罪。

### 节点 2　持牌与主体

区分金融机构、地方金融组织、一般民事主体。持牌不自动使所有费率合法；无牌不自动等于刑事犯罪。

### 节点 3　职业放贷迹象

出借人未依法取得放贷资格，以营利为目的向社会不特定对象提供贷款，多笔、高频、公开招揽、格式合同、固定团队。单笔亲友借款不得写成职业放贷。

### 节点 4　民事无效与返还

符合规定无效情形的，合同无效，返还实际取得款项与过错赔偿分列。不得写成“无效即不用还本金”。

### 节点 5　担保人过错接口

主合同无效后担保合同效力及担保人过错，只留接口，不展开保证评估终局。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或文本无法建立；用户坚持伪造流水、隐匿还款、暴力催收、伪造送达或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为本任务以外的文书或总图。
