# 边界与路由

## 正触发

对方被指职业放贷、无牌放贷或非法金融，民事争议已形成，用户需要资质争点和无效后果，而不是刑事定性或总体效力终局。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估总图 | 评估金融借贷担保争议 |
| 只要精算终稿 | 测算本金利息罚息复利 |
| 已决定起诉或应诉 | file-first-instance / defend-first-instance |
| 民间借贷成立交付总评 | 评估民间借贷成立与效力 |
| 网贷平台责任 | 评估网贷平台责任 |
| 刑民交叉整案 | 刑事领域；本包 P2 专项未安装则 unavailable |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 集资诈骗、非法吸收公众存款辩护或控告 | 刑事领域 |
| 金融牌照行政处罚、撤销许可 | 行政或监管合规交叉，本任务不做处罚决定书 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

借款人主张“对方是职业放贷所以我不用还”，正触发本任务做无效与返还分层，而不是直接免债。用户要写刑事报案书，负触发。
