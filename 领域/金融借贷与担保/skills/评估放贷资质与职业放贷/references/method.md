# 评估方法

判断只用三态。禁止输出构成某罪、应当追究刑事责任或胜诉率。刑事立案只作为程序事实登记。

## 节点 0　分流

1. 用户只要刑事控告书、罪名分析或辩护词：负触发，转刑事领域。
2. 无资质争点、只争交付或利率：转对应原子。
3. 网贷平台信息中介或联合放贷：可并行标接口，平台责任终局转 `assess-online-lending-platform`。
4. 破产已受理：转破产。

## 节点 1　出借人资质事实

固定：工商或金融许可、经营范围是否含放贷、是否地方金融组织名录、是否以贷为业的公开宣传、放贷笔数与借款人是否不特定、是否使用格式合同和催收团队。

名称不一致不合并。配偶、关联公司轮流出借：并列，不自动合并为同一职业放贷主体，除非有控制与资金混同迹象。

## 节点 2　职业放贷与无牌放贷

运行时核验民间借贷规定关于“未依法取得放贷资格而以营利为目的向社会不特定对象提供贷款”的无效条文，以及九民纪要职业放贷人口径。

| 事实 | 处理 | 禁止 |
| --- | --- | --- |
| 向不特定多数人反复放贷并收取高息 | 职业放贷迹象，无效接口 | 写成已构成非法经营罪 |
| 仅向亲友或单位内部特定人出借 | 通常不支持职业放贷 | 因无牌就当然无效 |
| 持牌小贷超范围或超杠杆 | 监管与合同效力分列待核 | 直接套用民间借贷职业放贷 |
| 平台撮合、资金来自多人 | 转网贷平台原子 | 在本任务认定平台有罪 |

单笔金额巨大本身不是职业放贷。年化利率高低单独走利率原子。

## 节点 3　民事后果

1. 合同无效：返还实际取得的本金；已收利息、费用按过错和不当得利接口，不编造全国统一“利息全退”或“利息全留”。
2. 担保：主合同无效，担保合同无效，但法律另有规定除外；担保人有过错仍可能承担相应民事责任。本任务不输出保证人“一定免责”。
3. 已履行部分与未履行部分分列。
4. 仲裁协议独立性：主合同无效不当然消灭仲裁条款。

## 节点 4　刑民交叉红旗

非法放贷刑事案件若干问题的意见、非法吸收公众存款与民间借贷的界限，只作红旗：

- 是否面向社会公开宣传；
- 是否承诺保本高息；
- 资金是否归集后转贷；
- 是否已刑事立案、查封。

红旗命中：提示民事程序可能中止或证据共用，不做刑事结论，不指导毁灭证据。

## 节点 5　输出

资质争点表、无效后果分层、担保过错接口、刑事红旗。下一步只含补证与转介。禁止指导继续无牌放贷或隐匿放贷清单。

## 判断纪律与 if/then

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然免责、必然全额支持或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》《担保法》及其解释时记为噪声，不得写入 `L#`。MCP 未安装、无结果或冲突时，不拒绝执行；依赖未核验规则的法律结论、期限或机关路径字段停止。

### 节点执行顺序

1. 先专项分流：一般合同、并购交割、破产申报、未成争审查起草、刑民定罪主轴，命中则整案转出或搁置，不填本任务实体终局。
2. 再固定主体、文本版本、程序文书与送达。口头转述、“已读”、截图不得写成已受理、已送达或期限已起算。
3. 每个请求或抗辩独立建 `Q#`：法律效果、成立条件、支持与不利事实、控制方、最强反方、主备位、互斥。禁止合成一笔“贷款权益”或“担保权益”。
4. 期限分类型：诉讼时效、保证期间、除斥、约定催告期、程序异议期各占一行，禁止混算或输出唯一截止日充作法律意见。
5. 金额分项：本金、利息、罚息、复利、费用、已还。民间借贷 LPR 四倍不得套用金融机构贷款。

### if / then

| 条件 | then |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出，先澄清代表哪一方 |
| 用户坚持伪造流水、隐匿还款、暴力催收、伪造送达或违法取证 | 整体停止，不提供规避方案 |
| 主目标已变为其他原子的文书或总图 | 目标停止，按路由表转介 |
| 关键日期、送达或动态规则未核验 | 字段停止，并列情景，不选对用户最有利的一天 |
| 有效仲裁协议未经排除，用户要求直接起诉 | 不得写应起诉；转论坛或仲裁入口 |
| 破产已受理而用户要个别清偿、执行或申报 | 标红旗，申报转破产领域，本包不做申报 |
| 未成争只要改合同或出稿 | 审查起草本窗搁置，只说明不实施 |
| C 端相邻商品被点名 | 只分流，不回改、不降成大众包 |

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。下一步按期限灭失、易失证据、能否改变 `Q#`、可逆性排序。禁止指导伪造、隐匿、威胁或违法取证。
