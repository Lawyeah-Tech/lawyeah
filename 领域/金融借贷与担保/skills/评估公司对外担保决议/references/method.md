# 评估方法

判断只用三态。未见决议不得写成“担保一定无效且相对人零权利”。不展开股东出资整案。

不得把已失效《公司法》（2005 文本条号）或《担保法》当作现行规则而不核验。

## 节点 0　分流

追股东、人格否认、董监高责任：转公司治理。普通保证方式与期间：转保证评估。独立保函：转独立保函原子。未成争做决议模板：搁置。

## 节点 1　公司类型与章程

1. 有限责任公司、股份有限公司、上市公司、国有、一人公司分列。
2. 摘录章程：担保决策机关、限额、对股东担保的特别程序。
3. 章程未规定机关：按公司法及解释的推定规则运行时核验，不擅自指定“只能股东会”。

## 节点 2　决议

1. 为他人担保：董事会或股东会决议，看章程。
2. 为股东或实际控制人担保：股东会决议，关联股东回避。
3. 决议真实性：签名、出席、表决比例。伪造决议不当然导致善意相对人零保护。
4. 决议越权（超限额、错机关）：相对人善意审查是否触及该瑕疵。

## 节点 3　相对人善意

担保制度解释第 7 条口径（运行时核验）：相对人在订立担保合同时对决议进行了合理审查，通常可以认定构成善意，担保合同对公司发生效力；反之公司可主张不发生效力。

审查内容通常包括：决议机关是否符合章程、签字与表决是否表面齐备。不要求相对人核实每一位股东签字笔迹，除非有明显异常。

上市公司：公开披露的决议或公告可能构成特别规则，依据不足则待核。

## 节点 4　例外

解释第 8 条等例外（运行时核验）：金融机构开立保函、公司为其全资子公司担保、担保合同系由单独或共同持有三分之二以上对担保事项有表决权的股东签字同意等。命中例外可支持对公司发生效力，仍须回链事实。

一人有限公司为其股东担保：可能无法形成回避决议，规则待核，不得直接套普通有限公司结论。

## 节点 5　不发生效力后的责任

对公司不发生效力的，相对人可请求过错赔偿责任，范围通常不超过债务人不能清偿部分，过错比例待核。法定代表人越权的内部追责不在本任务展开。禁止指导倒签决议或伪造股东会签名。

## 判断纪律与 if/then

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然免责、必然全额支持或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》《担保法》及其解释时记为噪声，不得写入 `L#`。MCP 未安装、无结果或冲突时，不拒绝执行；依赖未核验规则的法律结论、期限或机关路径字段停止。

### 节点执行顺序

1. 先专项分流：一般合同、并购交割、破产申报、未成争审查起草、刑民定罪主轴，命中则整案转出或搁置，不填本任务实体终局。
2. 再固定主体、文本版本、程序文书与送达。口头转述、“已读”、截图不得写成已受理、已送达或期限已起算。
3. 每个请求或抗辩独立建 `Q#`：法律效果、成立条件、支持与不利事实、控制方、最强反方、主备位、互斥。禁止合成一笔“贷款权益”或“担保权益”。
4. 期限分类型：诉讼时效、保证期间、除斥、约定催告期、程序异议期各占一行，禁止混算或输出唯一截止日充作法律意见。
5. 金额分项：本金、利息、罚息、复利、费用、已还。民间借贷 LPR 四倍不得套用金融机构贷款。

### if / then

| 条件 | then |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出，先澄清代表哪一方 |
| 用户坚持伪造流水、隐匿还款、暴力催收、伪造送达或违法取证 | 整体停止，不提供规避方案 |
| 主目标已变为其他原子的文书或总图 | 目标停止，按路由表转介 |
| 关键日期、送达或动态规则未核验 | 字段停止，并列情景，不选对用户最有利的一天 |
| 有效仲裁协议未经排除，用户要求直接起诉 | 不得写应起诉；转论坛或仲裁入口 |
| 破产已受理而用户要个别清偿、执行或申报 | 标红旗，申报转破产领域，本包不做申报 |
| 未成争只要改合同或出稿 | 审查起草本窗搁置，只说明不实施 |
| C 端相邻商品被点名 | 只分流，不回改、不降成大众包 |

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。下一步按期限灭失、易失证据、能否改变 `Q#`、可逆性排序。禁止指导伪造、隐匿、威胁或违法取证。
