# 边界与路由

## 正触发

公司或相对人争担保是否对公司发生效力，已成争，主成果是决议与善意审查矩阵，而不是追股东或人格否认。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估总图 | 评估金融借贷担保争议 |
| 已决定起诉或应诉 | file-first-instance / defend-first-instance |
| 保证方式与期间实体 | 评估保证责任 |
| 独立保函 | 评估独立保函 |
| 追股东出资或人格否认 | 公司治理领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 上市公司信息披露、并购担保交割 | 证券交叉或投资并购 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

银行称“有公章所以公司担保有效”，公司称“没开股东会所以无效”，正触发本任务做善意审查分层。用户要起诉股东认缴加速，转公司治理。
