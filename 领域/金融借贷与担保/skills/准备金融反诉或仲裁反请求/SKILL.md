# 准备反诉或仲裁反请求

## 任务目标

在明确、无利益冲突的反诉原告立场下，形成反诉状或仲裁反请求及证据。与本诉答辩分开验收。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：已决定反诉或提出仲裁反请求，主成果是反诉包，而不是本诉答辩或可行性评估。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未决定是否反诉；
- 只要本诉答辩；
- 独立起诉；
- 牵连明显不成立仍要求硬写；
- 刑事反诉；

与本诉答辩分开验收。不代提交。不把反诉写成已抵销本诉全部请求。

## 建立评估坐标

确认：使用者与授权；反诉原告立场；本诉案号；反请求；期限；仲裁或诉讼；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 陈述；`D#` 材料；`A#` 承认；`R#` 文书；`C#` 条款；`L#` 规则；`I#` 判断；`G#` 缺口；`P#` 反诉请求；`V#` 稿件；`E#` 凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《担保法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验反诉时限与请求；`search_template` 只借栏目。工具不可用时继续请求结构；时限届满结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　时限闸

超过反诉或反请求期限：停止终稿或标失权。

### 节点 2　请求

返还、赔偿、涂销分列。未知不写零。

### 节点 3　事实

与本诉事实对照，避免自相矛盾。

### 节点 4　证据

独立证据目录。

### 节点 5　稿件

反诉状／反请求书。答辩书不在本任务交付。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或文本无法建立；用户坚持伪造流水、隐匿还款、暴力催收、伪造送达或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为本任务以外的文书或总图。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
