# 边界与路由

## 正触发

银行通道或委托贷款责任争议已形成，主成果是三方责任分层，而不是大众委托理财包或监管处罚决定。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估 | 评估金融借贷担保争议 |
| 融资安排总定性 | 识别融资安排法律性质 |
| 银行理财适当性 | 评估银行理财适当性 |
| 自营贷款催收或起诉 | 对应催收／起诉原子 |
| C 端委托理财 | 大众包只分流 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 信托、资管计划交割 | 投资并购或信托交叉 |
| 通道罚则 | 监管合规，本任务只标红旗 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

企业通过银行委托贷款放给项目公司，银行说自己只是通道，正触发本任务。个人找朋友理财亏了，分流 C 端。
