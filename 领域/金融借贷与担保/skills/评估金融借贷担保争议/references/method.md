# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然加速、必然免责或唯一必得总额。

`search_law` 返回已失效《合同法》《担保法》及其解释时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜关系假设｜提出方｜相对方｜法律效果｜成立条件｜支持事实｜不利事实｜控制方｜最强反方｜主备位｜判断｜待核`。

还款、加速、保证、实现担保物权、利息、罚息、费用分列。同一事实支持多项时分别说明效果，不重复金额。构成逾期不等于当然加速，更不等于保证责任已确定。

---

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填总体评估十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 买卖、服务、承揽等一般履行、质量、解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割、对价调整、交割条件为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 劳动关系、劳动报酬、解除劳动合同 | 劳动领域 |

混合信号：金融借贷或担保主轴可留本任务；一般买卖或家事只作为背景时在缺口标明，不把专项规则硬套进金融结论。

## 节点 1　主体、增信结构和程序状态

1. 固定主合同、借据、担保合同、最高额合同、转让通知、对账单、电子签约文本的版本层级。冲突并列，不选对用户有利的一版冒充唯一文本。
2. 主体表记录贷款人/出借人、借款人、保证人、抵押人/出质人、实际收款人和可能责任主体。名称不一致不自动合并。配偶未签字不写成“配偶一定无责”。
3. 增信表分列：保证（一般/连带/约定不明）、抵押、质押、让与担保、独立保函、保理、融资租赁。独立保函不得按典型保证期间处理，标接口转专项。
4. 程序表逐动作记录协商、催收、保证主张、加速、仲裁、诉讼、实现担保物权或执行：机关/机构、案号、文书、作出日、收到日、送达方式和效力凭证。口头转述、截图、“已读”不得写成已受理、已送达或期限已起算。
5. 同时掌握双方秘密或立场不明：整体停止策略输出。

## 节点 2　请求与抗辩假设

每个 `Q#` 先写法律效果，再写成立条件。禁止合成“贷款权益”一笔。

默认主位候选按事实分别建立，不得预先锁定加速或实现担保：

- `Q-还` 到期返还本金及约定利息
- `Q-催` 催告履行或指定合理期限（本身不是加速）
- `Q-加` 约定或法定加速到期、提前收回（第 673 条用途违约等须回链）
- `Q-保` 保证责任（方式、期间、范围接口，不替代保证评估终局）
- `Q-物` 实现担保物权或优先受偿
- `Q-息` 借期内利息
- `Q-罚` 逾期利息、罚息、复利、违约金
- `Q-抗` 未交付、砍头息、利率上限、时效、保证期间、仲裁/管辖、先诉抗辩

单位或被请求方立场：逐项回应对方已知主张，并列己方最强抗辩，不把反诉写成已经提起。

主备位和互斥必须可见。`Q-加` 与继续按原期限履行不得同时写成均已成立。利息与罚息期间不得重叠计。

专项评估（民间借贷效力、保证责任、利率费用、保理、融资租赁）可在矩阵中留接口，不在本任务做专项终局。

## 节点 3　催收、保证主张还是实现担保

本节点只判断路径，不生成发送版通知或申请。

### 3.1 先分账

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 对方逾期 | 已构成加速到期 |
| 用户想今天发函 | 保证期间内已对保证人行权 |
| 对借款人发了催收 | 已对一般保证人完成期间内行权 |
| 有抵押登记 | 特别程序必然准许拍卖 |

### 3.2 路径分流

1. **仍要主债务人履行**：催收是否必要、合理期限待核。转介 `prepare-collection-notice`。
2. **拟加速或提前收回**：核对应条件是否成就；成就不等于已经发出有效通知。用途违约走第 673 条接口，须运行时核验。
3. **拟向保证人主张**：先看保证方式。一般保证：期间内原则上须对**债务人**提起诉讼或申请仲裁（第 693 条）。连带：期间内须**请求保证人**。对象错误则不得写成已行权。转介保证评估或保证主张通知。
4. **拟实现担保物权**：有无实质性争议。无争议且条件成就可转特别程序；有争议转诉讼。本任务不写申请书。

### 3.3 输出

| 条件 | 本任务输出 | 转介 |
| --- | --- | --- |
| 仍希望主债务人还款，催收必要或有用 | 催收是否必要、到达与时效接口 | `prepare-collection-notice` |
| 保证期间可能届满 | 对象、方式、期间情景、不可逆提示 | `assess-guarantee-liability` / `prepare-guarantee-claim-notice` |
| 用户坚持今天发出催收或保证函终稿 | 目标停止 | 对应通知原子，不在本包出稿 |

## 节点 4　论坛、仲裁与程序入口

分别判断：协商、催收、仲裁、诉讼、实现担保物权特别程序、保全红旗、执行。本任务不写立案包或申请书。

### 4.1 仲裁协议优先闸

合同、担保合同或事后书面协议中出现仲裁条款时：

1. 不得直接写“应向法院起诉”。
2. 分列：是否书面；是否有请求仲裁的意思；仲裁事项是否覆盖本案及担保；是否选定机构；是否或裁或诉。
3. 主合同与担保合同仲裁条款不一致：效力标 `依据不足`，转介管辖原子（本包未安装则 `unavailable`）。
4. 书面形式、仲裁意思、事项覆盖、机构可确定且无或裁或诉冲突均获支持时，论坛主位写成仲裁。仅在已核验的无效、不覆盖，或依法视为放弃且事实可回链时，才评估诉讼入口。
5. 主合同无效不当然消灭仲裁协议。独立性规则须运行时核验现行《仲裁法》文本。

### 4.2 诉讼与特别程序

无仲裁协议或仲裁协议现有依据不支持其适用时，才把一审诉讼列为可行入口。实现担保物权特别程序另列：管辖为担保财产所在地或登记地基层法院（民诉法第 207 条，条号运行时核验）。有实质性争议不得推荐特别程序作为唯一入口。

已收到起诉状或仲裁申请：目标停止，转 `defend-first-instance`，不把本任务改写成答辩状。

保全只做红旗，不写保全申请。出现破产受理信号：标红旗并转介破产领域，不做申报。

## 节点 5　期限分类型

每种期间单独一行。禁止用三年诉讼时效去算保证期间，也禁止用保证期间去挡普通金钱请求。

| 类型 | 规则锚点 | 本任务允许的输出 | 禁止 |
| --- | --- | --- | --- |
| 诉讼时效 | 第 188 条一般为三年；分期履行自最后一期届满（第 189 条） | 起算事件、备选起算、中断候选、条件公式 | 唯一截止日；法院主动审查时效的表述 |
| 保证期间 | 第 692、693 条；解释第 32 条；施行前合同另核时间效力规定第 27 条 | 约定/视为无约定/六个月情景；施行前并列二年／六个月；行权对象 | 与时效混算；适用中止中断；“至本息还清”当成无限期；把第 27 条写成方式已改一般保证 |
| 保证债务时效 | 第 694 条 | 与保证期间分列 | 用保证期间代替时效 |
| 约定催告期 / 加速宽限期 | 合同条款 | 条款原文定位、是否已起算 | 把约定期写成法定保证期间 |
| 仲裁/管辖异议期 | 程序法，运行时核验 | 已进入程序时标红旗 | 在评估里写出异议书截止日期充作法律意见 |

日期冲突、送达不明、知悉日不明：并行情景 + 字段停止，不选对用户最有利的一天。

## 节点 6　金额区间与利率接口

本任务只建区间和接口，不替代 `calculate-loan-balance`。

1. 分项：实际本金、借期内利息、逾期利息/罚息、复利、费用、违约金、已还。未知不写零，不输出唯一必得总额。
2. 名义金额不得自动等同实际本金。预扣利息按实际出借额计本（第 670 条；民间借贷规定第 26 条）。
3. 民间借贷约定利率超过合同成立时一年期 LPR 四倍的部分不受保护（规定第 25、29 条）。**金融机构及其分支机构贷款不适用该规定**（规定第 1 条）。
4. 不得把约定数字写成必得。复利、罚息、服务费是否计入保护上限分别标待核。
5. 清偿抵充顺序有约定从约定，无约定参照第 560、561 条，不在本任务选定唯一冲抵。

参数不足：只列已知参数、未知参数和专项测算接口。

## 程序与期限表

程序动作记录机关、案号、文书、作出、收到、送达、效力。期限每行只对应一种期间类型和一个起算事件。关键日期冲突则并行情景。

## 金额区间表

固定列：项目、性质、期间、参数、来源、已付、未知、互斥／抵扣、范围、专项测算接口。参数不足不输出唯一总额。

## 证据与下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。

下一步按期限灭失、易失证据、改变请求抗辩、可逆性排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。

催收通知、保证主张通知、实现担保物权申请、起诉、应诉、精算、完整证据卷只写转介条件和最小交接，不在本方法生成那些终稿。禁止指导伪造、隐匿、暴力催收或违法取证。
