# 边界与路由

## 正触发

金融借贷、保证、抵押质押、保理或融资租赁已成争，单方需要总体决定请求、抗辩、论坛、证据优先级和下一步。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |
| 只判断保证责任 | `评估保证责任` |
| 向主债务人催收或加速 | `准备催收或加速到期通知` |
| 向保证人主张 | `准备保证债务主张通知` |
| 精算本金利息 | `测算本金利息罚息复利` |
| 完整证据卷 | `建立金融借贷担保证据案卷` |
| 实现担保物权申请 | `准备实现担保物权申请` |
| 和解条件 | `谈判金融和解与分期` |
| 起诉 | `提起金融借贷担保一审` |
| 应诉 | `应对金融借贷担保一审` |
| 一般合同／并购交割／破产申报 | 对应领域 |
| C 端保证评估／利息测算／微信追偿 | 大众专项，只分流不回改 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 买卖、服务、承揽等一般履行解除 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报、重整计划、清算分配 | 破产领域 |
| 劳动关系、工资、解除劳动合同 | 劳动领域 |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

请求尚未闭合、需比较催收、主张保证还是实现担保时正触发。主体、请求、论坛均确认且只要诉状时负触发。有仲裁条款仍要求“直接起诉”时，先完成论坛闸，不改写成立案原子。
