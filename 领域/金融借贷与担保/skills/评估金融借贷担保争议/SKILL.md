# 评估金融借贷担保争议

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《担保法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“金融借贷担保争议总体评估矩阵”：主体和增信结构、事实时间线、逐项请求／抗辩、论坛与程序入口、时效与保证期间待核、金额区间、证据缺口、对方最强解释和下一步。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：金融借贷、保证、抵押质押、保理或融资租赁已形成偿还、增信或实现争议，用户仍需决定请求、抗辩、路线或下一步。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未成争，只要改合同或出稿（审查起草领域，本生产线搁置，只说明不实施）；
- 只要发送版催收、加速或保证主张函；
- 只要精算工作表或完整证据卷；
- 已决定起诉／仲裁申请／答辩／实现担保物权／开庭／执行并只要相应文书；
- 一般买卖服务等合同争议、股权或资产并购交割、已进入破产程序的申报或分配。

本任务不生成发送版催收函、保证主张函、可提交诉状或答辩、实现担保物权申请，不给胜诉率。

## 建立评估坐标

确认：使用者与授权；单方立场（债权人／债务人／保证人／物上保证人）；相对方及可能责任主体；主合同、担保合同及附件版本；争议事项；法域；当前协商、催收、仲裁、诉讼或执行状态；机关文书作出与送达；对方已知主张；关键材料及缺失。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`V#` 评估版本；`E#` 发送／送达／履行凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验借款、保证期间、利率上限、加速、担保物权和期限；`search_practiced` 补路径与反例；特殊事实用 `search_case_by_fact`，明确筛选用 `search_case_by_filter`。不虚构案件系统。

工具不可用时继续事实、主体、程序文书状态和问题清单；请求／抗辩的法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 主体、增信结构和程序状态

先做专项分流，再固定主合同、担保合同、转让通知和对账单冲突，并列主体、保证人、物上保证人和程序表。口头转述和“已读”不写成已受理、已送达或期限已起算。

### 2. 请求与抗辩假设

每个 `Q#` 独立列法律效果、成立条件、支持及不利事实、控制方、最强反方、主备位和互斥。还款、加速、保证、实现担保物权、利息、罚息不得合成一笔“贷款权益”。构成违约不等于当然加速，更不等于保证责任已确定。

### 3. 论坛、催收／保证主张和期限

仲裁条款出现时不得直接写成应起诉。催收与保证主张分账：对主债务人催收不当然构成对保证人行权。期限分列诉讼时效、保证期间、除斥、约定催告期，不混算。

### 4. 金额区间与非金钱后果

分项列本金、利息、罚息、复利、费用、已还。未知不写零。民间借贷 LPR 四倍只标接口，且不套用金融机构贷款。实现担保物权、取回租赁物等非金钱结果单列。

### 5. 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。下一步按期限灭失、易失证据、能否改变 `Q#`、可逆性排序。发送催收／保证函、特别程序、立案、精算标为转介，不在本包做出发送终稿。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或文本无法建立；用户坚持伪造流水、隐匿还款、暴力催收或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为发函、精算、建卷、和解协议或程序文书。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
