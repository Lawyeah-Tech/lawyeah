# 边界与路由

## 正触发

电子签约、人脸识别、短信验证码引发成立或到达争议，金融借贷已成争，用户需要意思表示与举证分层，而不是鉴定意见书。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估总图 | 评估金融借贷担保争议 |
| 只要精算终稿 | 测算本金利息罚息复利 |
| 已决定起诉或应诉 | file-first-instance / defend-first-instance |
| 电子数据鉴定意见 | 鉴定机构；本任务只列送检事项 |
| 证据保全步骤主成果 | 保全转账与电子证据 |
| 格式条款效力终局 | 评估金融格式条款 |
| 网贷平台责任 | 评估网贷平台责任 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 跨境电子签名、境外平台取证 | 标跨境红旗，复杂冲突法不在本任务终局 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

借款人说“我只收过验证码没签合同”，正触发本任务。用户要一份司法鉴定书正文，负触发。
