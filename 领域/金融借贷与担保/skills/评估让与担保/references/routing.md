# 边界与路由

## 正触发

名为转让实为担保已成争，用户需要识别和清算义务，而不是完成股权交割或直接确认归债权人所有。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或办理登记出稿 | 审查起草领域（本窗搁置） |
| 只要实现担保物权申请书 | 准备实现担保物权申请 |
| 只要总体评估 | 评估金融借贷担保争议 |
| 融资安排总定性 | 识别融资安排法律性质 |
| 典型抵押设立 | 评估抵押质押设立与对抗 |
| 股权并购交割 | 投资并购领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 上市公司股份转让与减持合规 | 证券交叉 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

签了股权转让但约定还清借款就回购，债权人主张股权已是自己的，正触发本任务。用户要完成股东名册和公司治理交割，转投资并购。
