# 边界与路由

## 正触发

鉴定意见作出后不服，主成果是异议与补充／重新鉴定申请接口，而不是自行出具估价报告充当鉴定。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估 | 评估金融借贷担保争议 |
| 实现担保物权申请 | 准备实现担保物权申请 |
| 执行分配方案异议 | 应对金融执行 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程造价鉴定 | 建设工程领域 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

评估公司把抵押房产评得很低，正触发本任务。用户要你按评估师格式重写一份鉴定书，负触发。
