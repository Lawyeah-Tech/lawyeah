# 提出担保物价值鉴定异议

## 任务目标

在明确、无利益冲突的单方立场下，形成担保物价值鉴定异议点、补充或重新鉴定材料。不重新做鉴定意见。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：鉴定意见作出后不服，主成果是异议与补充／重新鉴定申请接口，而不是自行出具估价报告充当鉴定。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 鉴定尚未作出只要选机构；
- 自行出具替代鉴定意见书；
- 只要实现申请或执行分配；
- 对法律适用不满而无鉴定方法问题；
- 未成争商业估价；

不重新做鉴定意见。不保证法院准许重新鉴定。

## 建立评估坐标

确认：使用者与授权；立场；案号；鉴定委托事项、机构、意见书送达日；异议期限；担保物类型；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 陈述；`D#` 鉴定意见；`A#` 承认；`R#` 文书；`C#` 合同；`L#` 规则；`I#` 判断；`G#` 缺口；`Q#` 异议点；`V#` 版本；`E#` 送达与比较材料。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民诉法鉴定异议、补充鉴定、重新鉴定条件。工具不可用时继续意见书文本对照；应否重新鉴定结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　期限

收到鉴定意见后提出异议的期间未核验则字段停止。

### 节点 2　异议点

检材失真、方法错误、基准日错误、比较案例不当、超委托范围、鉴定人不具备资格。

### 节点 3　补充 vs 重新

部分遗漏走补充；根本性方法或资格问题走重新鉴定。不得两者无差别堆砌。

### 节点 4　材料

相反估价、权属面积差异、他项权利、租金或成交实例。不冒充鉴定人。

### 节点 5　效果

异议不等于必然重新鉴定。拍卖保留价接口只标。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或文本无法建立；用户坚持伪造流水、隐匿还款、暴力催收、伪造送达或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为本任务以外的文书或总图。
