# 边界与路由

## 正触发

多债权人庭外展期、削债或置换，尚未进入破产程序，主成果是约束力与风险，而不是法院重整计划。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估 | 评估金融借贷担保争议 |
| 单债权人谈判 | 谈判金融和解与分期 |
| 破产入口识别 | 识别破产程序入口并分流 |
| 已受理重整计划 | 破产领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 债券持有人会议、公司债重组 | 证券／公司交叉只标接口 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

三家银行加若干供应商要一起展期，正触发本任务。法院已裁定受理重整，转破产。
