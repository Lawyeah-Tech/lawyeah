# 评估庭外重组方案

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《担保法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成庭外重组评估：约束力、集体行动风险、破产入口红旗。不制定重整计划；破产内方案转破产。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：多债权人庭外展期、削债或置换，尚未进入破产程序，主成果是约束力与风险，而不是法院重整计划。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 破产已受理要重整计划或申报；
- 单债权人普通和解谈判；
- 制定具有破产法效力的重整计划；
- 未成争只要设计债券发行（搁置）；
- 并购交割整案；

不制定重整计划。破产内方案转破产。不把部分债权人签字写成约束全体。

## 建立评估坐标

确认：使用者与授权；立场（债务人／某债权人／保证人）；债权人结构；拟议展期或削债要点；有无银行团或协议；是否出现破产原因；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 陈述；`D#` 方案；`A#` 承认；`R#` 文书；`C#` 原合同与银团条款；`L#` 规则；`I#` 判断；`G#` 缺口；`Q#` 约束力争点；`V#` 版本；`E#` 签字与违约凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验合同相对性、银团多数决、破产撤销个别清偿。工具不可用时继续签字范围表；约束力结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　破产闸

已受理破产：整案转破产。仅有破产原因迹象：本任务标红旗并评估个别清偿风险，仍可继续庭外分析。

### 节点 2　约束力

未签字债权人原则上不受约束。银团或协议中的多数决条款须核验是否覆盖本次削债。

### 节点 3　集体行动

交叉违约、加速、抢先查封、保证人追索。方案须揭示这些破裂点。

### 节点 4　个别清偿撤销

若随后进入破产，临界期内偏颇清偿可能被撤销。本任务只标红旗，不做破产撤销诉讼。

### 节点 5　与单边和解

单债权人分期：转谈判或起草和解。本任务针对多债权人结构。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或文本无法建立；用户坚持伪造流水、隐匿还款、暴力催收、伪造送达或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为本任务以外的文书或总图。
