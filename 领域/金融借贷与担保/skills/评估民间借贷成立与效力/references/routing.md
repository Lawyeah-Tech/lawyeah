# 边界与路由

## 正触发

自然人、法人或非法人组织之间的民间借贷已成争，争点落在合同是否成立、本金是否交付、是否虚假诉讼、是否无效或可撤销，用户需要专项效力矩阵而不是总体评估或利率终局。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估总图 | 评估金融借贷担保争议 |
| 只要精算终稿 | 测算本金利息罚息复利 |
| 只要发送催收或保证函 | 对应通知原子 |
| 已决定起诉或应诉 | file-first-instance / defend-first-instance |
| 金融机构贷款效力 | 按金融借款合同处理，不套民间借贷规定 |
| 职业放贷或无牌放贷专项 | 评估放贷资质与职业放贷 |
| 利率砍头息终局 | 评估利率费用与砍头息 |
| 电子签约鉴定 | 评估电子借款成立与送达 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 非法集资、骗贷、套路贷刑事主轴 | 刑事领域；本任务只标红旗不定罪 |
| 夫妻共债是否成立 | 评估夫妻共债交叉并分流 后转婚家 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

有借条但无转账，正触发本任务而不是直接测算欠款。已确认金融机构贷款却要求按民间借贷无效处理，负触发。虚假诉讼红旗不是本任务的定罪结论。
