# 评估方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出一定成立、一定无效、一定虚假诉讼或胜诉率。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。民间借贷规定条号运行时核验。

## 节点 0　产品类型分流

1. 出借人是商业银行、农商行、村镇银行、消费金融公司、信托、持牌小贷或网络小贷：本任务负触发，按金融借款合同处理，不得套用民间借贷成立与利率规则。
2. 名为民间借贷、资金实际来自金融机构套取：不在本节点写成已无效，转入节点 4 无效接口并保留转贷知情争点。
3. 一般买卖、投资并购交割、破产申报：整案转出。
4. 用户只要总体评估、精算或诉状：目标停止。

## 节点 1　合意是否成立

1. 摘录借条、借款合同、微信确认、电子签约文本，冲突并列，不选对用户有利的一版。
2. 自然人之间借款：民法典第 679 条，自贷款人提供借款时成立。没有提供借款的事实，不得写成合同已成立并产生返还义务。
3. 非自然人之间：书面形式或其他可认定合意的材料。只有对账单或催收短信，不能单独写成已订立借款合同。
4. 电子签约、验证码、人脸：只标电子成立接口，鉴定终局转 `assess-electronic-loan`。
5. 代理签字、代持、配偶代签：名称不一致不合并；无权代理按效力待定，不写成一定约束被代理人。

## 节点 2　本金是否交付

交付是返还请求的独立要件，与“有借条”分账。

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 借条金额与转账金额不一致 | 借条金额就是实际本金 |
| 现金交付只有口头陈述 | 现金已交付且金额确定 |
| 资金先入借款人再当日转回 | 已完成有效交付 |
| 第三方代付且无指示关系 | 出借人已完成交付 |

1. 银行转账：核对付款人、收款人、时间、附言、是否经第三方。第三方代付须有指示或事后追认迹象。
2. 现金：时间、地点、在场人、大额来源、后续消费或存款痕迹。缺任一项则交付结论字段停止。
3. 预扣利息、保证金、服务费：名义金额不得等同实际本金，转利率费用原子，本任务只标“实际出借额待核”。
4. 循环倒贷、以贷还贷：新旧交付分列，不把借新还旧自动写成新债已独立交付。

## 节点 3　虚假诉讼红旗

只做红旗，不作刑事定性。

- 出借人收入、财产与出借金额显著不符且无资金来源说明；
- 大额现金、无取现或来源凭证；
- 原被告身份密切、诉讼中高度配合、对关键事实无争议却无资金痕迹；
- 同一出借人对多名不特定对象短期高频放贷（同时转职业放贷接口）；
- 诉状与转账主体、时间明显错位。

红旗成立不等于请求应驳回。处理：并列最强反方、补证项，必要时提示法院可能依职权审查，不指导伪造补证。

## 节点 4　无效、可撤销

运行时核验民间借贷规定关于无效的现行条文后再落判断。核验失败则效力结论字段停止。

默认争点分列，禁止合成“合同有问题”：

- `Q-转贷` 套取金融机构信贷资金转贷；
- `Q-集资转贷` 以向其他营利法人借贷或向本单位职工集资取得的资金转贷，且借款人事先知道或应当知道；
- `Q-无资质` 未依法取得放贷资格而以营利为目的向社会不特定对象提供贷款；
- `Q-虚假` 违背公序良俗或虚假意思表示；
- `Q-撤销` 欺诈、胁迫、显失公平，注意除斥期间。

无效后果：返还实际取得的款项与赔偿损失分列。不得写成“无效即本金不用还”。担保从属性接口转保证或物保评估，主合同无效不当然导致担保人零责任。

职业放贷、非法经营、非法吸收公众存款：只标刑民交叉红旗，不定罪，不替代 `assess-lender-qualification`。

## 节点 5　输出与转介

| 条件 | 本任务输出 | 转介 |
| --- | --- | --- |
| 成立与交付争点已分层 | 争点表、红旗、后果接口 | 总体评估或证据卷 |
| 利率、砍头息成为主目标 | 实际本金待核接口 | `assess-interest-and-fees` / `calculate-loan-balance` |
| 要发催收或起诉 | 目标停止 | 对应通知或立案原子 |
| 金融机构贷款被误送入本任务 | 负触发 | 金融借款合同路径 |

禁止指导伪造借条、补做现金收条或隐匿还款。
