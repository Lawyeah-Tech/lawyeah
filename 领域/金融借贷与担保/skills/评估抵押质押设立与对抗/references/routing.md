# 边界与路由

## 正触发

争担保是否设立、能否对抗第三人，已成争，主成果是分层效力矩阵，而不是拍卖申请或未成争登记材料。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或办理登记出稿 | 审查起草领域（本窗搁置） |
| 只要实现担保物权申请书 | 准备实现担保物权申请 |
| 只要总体评估 | 评估金融借贷担保争议 |
| 让与担保 | 评估让与担保 |
| 应收／股权出质专项 | 评估应收账款或股权质押 |
| 顺位与超级优先 | 评估担保物权顺位 |
| 请求办理抵押登记诉讼 | 准备请求办理抵押登记诉讼 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 海事船舶、航空器特殊登记 | 海事或专门登记领域 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

动产抵押未登记，第三人主张抵押权不存在，正触发本任务做设立与对抗分层。用户要立刻拍卖，转实现申请。
