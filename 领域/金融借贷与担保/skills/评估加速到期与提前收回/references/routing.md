# 边界与路由

## 正触发

拟宣布或已被宣布全部到期，金融借贷已成争，用户需要条件成就判断，而不是发送加速通知或起诉。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估总图 | 评估金融借贷担保争议 |
| 只要精算终稿 | 测算本金利息罚息复利 |
| 已决定起诉或应诉 | file-first-instance / defend-first-instance |
| 发送加速通知 | 准备催收或加速到期通知 |
| 加速后清算表 | 处理加速到期后清算 |
| 格式条款是否纳入 | 评估金融格式条款 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 破产受理后个别清偿与加速 | 破产领域 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

银行发了逾期提醒但未写“全部提前到期”，正触发本任务判断是否已加速，而不是直接按全部本金起诉。用户说“帮我写一封加速函”，负触发至催收原子。
