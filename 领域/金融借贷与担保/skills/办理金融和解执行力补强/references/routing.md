# 边界与路由

## 正触发

和解条件已有或将有协议，用户要补强执行力，主成果是路径比较和材料，而不是再谈条件或普通执行。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估 | 评估金融借贷担保争议 |
| 和解协议正文 | 起草还款和解协议 |
| 赋强公证从零准备 | 准备公证催收或赋强公证 |
| 已有执行依据 | 执行金融生效文书 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 破产和解协议认可 | 破产领域 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

私下签了分期协议，担心对方不还又不能直接执行，正触发本任务。只要把协议字句写漂亮，走起草原子。
