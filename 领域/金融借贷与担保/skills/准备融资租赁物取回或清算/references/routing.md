# 边界与路由

## 正触发

已决定取回或参照担保物权实现，主成果是路径与材料，而不是再定性。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估 | 评估金融借贷担保争议 |
| 融资安排总定性 | 识别融资安排法律性质 |
| 定性与取回条件 | 评估融资租赁性质与取回 |
| 全部租金起诉 | 提起金融借贷担保一审 / file-arbitration |
| 实现担保物权 | 准备实现担保物权申请 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 破产取回权 | 破产领域 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。
