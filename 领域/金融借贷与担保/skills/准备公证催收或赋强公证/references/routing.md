# 边界与路由

## 正触发

需公证固定催收或办理赋强公证，主成果是公证事项与材料清单，而不是执行证书或保证出证。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估 | 评估金融借贷担保争议 |
| 只要精算终稿 | 测算本金利息罚息复利 |
| 普通催收通知 | 准备催收或加速到期通知 |
| 持赋强文书申请执行 | 执行赋强公证债权文书 |
| 和解后再赋强 | 办理金融和解执行力补强 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 涉外公证认证 | 跨境红旗 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

银行要公证送达催收短信，正触发本任务的催收公证分支。已经有赋强公证书要去法院执行，走执行赋强原子。
