# 边界与路由

## 正触发

已决定通知应收账款债务人，主成果是发送前通知，而不是保理真实性总评。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估 | 评估金融借贷担保争议 |
| 保理真实性与顺位 | 评估保理真实性与通知 |
| 普通债权转让评估 | 评估金融债权转让 |
| 催收主债务人借款 | 准备催收或加速到期通知 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 破产管理人统一通知 | 破产领域 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

保理合同已签，要通知买方把货款付给保理公司，正触发本任务。还在争这单买卖是不是假的，先走保理评估。
