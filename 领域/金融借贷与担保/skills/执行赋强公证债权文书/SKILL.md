# 执行赋强公证债权文书

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《担保法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的权利人立场下，形成执行赋强公证路径：执行证书条件、异议、申请材料。与普通判决执行不同。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：持赋强公证书要执行证书或申请执行，主成果是赋强执行包，而不是普通胜诉判决的执行。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 执行依据是判决、调解书或仲裁裁决；
- 尚无赋强公证书只要去办公证；
- 债务人要起诉不予执行整案且用户是债务人主成果——可转出说明；
- 破产已受理个别执行应中止；
- 指导伪造执行证书；

与普通判决执行不同。不保证公证处出具执行证书或法院受理。

## 建立评估坐标

确认：使用者与授权；权利人立场；公证书与赋强范围；债务履行情况；申请执行证书的材料；管辖执行法院；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 陈述；`D#` 公证书；`A#` 承认；`R#` 执行证书；`C#` 债权文书；`L#` 规则；`I#` 判断；`G#` 缺口；`P#` 执行请求；`V#` 版本；`E#` 履行与公证凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验公证法、民诉法关于公证债权文书执行及不予执行事由。工具不可用时继续文书与履行事实；证书可否出具字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　依据识别

执行依据须是赋强公证书＋执行证书。缺执行证书不得写成可直接立案执行。判决执行转普通执行原子。

### 节点 2　执行证书

向公证机构申请，证明不履行或未完全履行。余额争议巨大时公证机构可能不出证。

### 节点 3　管辖与申请

被执行人住所地或财产所在地法院。申请书列公证书编号、金额、财产线索。

### 节点 4　不予执行风险

公证文书确有错误、违背自愿、债权不真实等不予执行事由只标红旗。

### 节点 5　担保范围

未纳入赋强的保证人或抵押物，不得写入本次执行对象，须另案。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或文本无法建立；用户坚持伪造流水、隐匿还款、暴力催收、伪造送达或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为本任务以外的文书或总图。
