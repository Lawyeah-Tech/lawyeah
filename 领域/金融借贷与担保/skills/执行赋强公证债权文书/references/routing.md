# 边界与路由

## 正触发

持赋强公证书要执行证书或申请执行，主成果是赋强执行包，而不是普通胜诉判决的执行。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估 | 评估金融借贷担保争议 |
| 只要精算终稿 | 测算本金利息罚息复利 |
| 普通判决执行 | 执行金融生效文书 |
| 尚无赋强公证书 | 准备公证催收或赋强公证 |
| 执行和解 | 准备金融执行和解 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 破产受理后个别执行 | 破产领域 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

手里有赋强公证书但没有执行证书，正触发本任务先办证书。手里是胜诉判决，走普通执行原子。
