# 评估方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出一定免责、一定全额承担或胜诉率。

`search_law` 返回已失效《担保法》及其解释时记为噪声。不得把“约定不明=连带责任保证”或“约定不明=二年保证期间”写入 `L#`。

---

## 节点 0　分流与独立保函闸

| 信号 | 处理 |
| --- | --- |
| 见索即付、独立于基础交易、载明单据和最高金额 | 停止典型保证终局；独立保函接口；本包未安装则 `unavailable` |
| 只要发送版保证函 | 负触发至 `prepare-guarantee-claim-notice` |
| 一般买卖服务主轴、无资金增信 | 转合同争议 |
| 破产已受理要申报 | 转破产，不做申报 |
| 未成争改担保合同 | 审查起草搁置 |

抵押、质押与保证夹在同一份文件：拆成两行，分别进入人保/物保接口，不合成一种担保。

---

## 节点 1　文本与主体

1. 摘录保证条款原文，区分独立保证合同与主合同保证条款。
2. 主体表：保证人签字/盖章人、债权人、主债务人、配偶、公司机关。名称不一致不合并。
3. 公司作保证人、未见股东会或董事会决议：只标公司对外担保与相对人善意审查接口（解释第 7、8 条），不输出“未出示决议=一定无效”。
4. 机关法人、以公益为目的的非营利法人不得为保证人（第 683 条）：只作主体不适格审查点；无效后仍可能有过错赔偿。

## 节点 2　方式与范围

运行时核验第 686 条后再落判断。核验失败则方式结论字段停止，原文摘录继续。

| 材料里实际写了什么 | 本任务处理 | 不得改写成 |
| --- | --- | --- |
| 债务人不能履行或无力偿还时才承担责任 | 一般保证迹象 | 一般保证所以一定不用还 |
| 债务人不履行即承担、无条件承担、连带责任保证 | 连带责任保证迹象 | 写了连带就一定有效且必须立刻全额还 |
| 对保证方式没有约定或只写“担保/保证” | 约定不明；现行默认一般保证 | 当然连带；或当然已经免责 |
| “直至本息还清时为止” | 期间约定不明，不是方式条款 | 无限期保证 |

解释第 25 条：有“债务人应当先承担责任”意思的，认定为一般保证；有“不履行即承担”且无先承担意思的，认定为连带。本任务只对照原文迹象，不代替法院认定。

范围规范钩子是第 691 条：主债权及其利息、违约金、损害赔偿金和实现债权的费用；另有约定的按约定。只摘录是否限本金、是否含利息罚息律师费。

施行前成立的合同：方式约定不明原则上适用当时法律（担保法默认连带）。不得引用时间效力规定第 27 条作为方式已经改为一般保证的依据。不输出“现在一定是一般保证所以不用还”。

## 节点 3　保证期间与行权对象

1. 保证期间是确定保证人承担保证责任的期间，不发生中止、中断和延长（第 692 条）。
2. 约定早于主债务履行期限或与之同时届满的，视为没有约定。没有约定或约定不明确的，保证期间为主债务履行期限届满之日起六个月。
3. “直至本息还清时为止”等类似内容，视为约定不明，期间为届满之日起六个月（解释第 32 条）。这是期间计算钩子，**不是“过期了一定免责”**。施行前成立的保证合同，期间没有约定或约定不明确的，按时间效力规定第 27 条并列情景：约定不明且主债务履行期限届满至民法典施行之日不满二年的，当事人可主张二年；没有约定且届满至施行日不满六个月的，当事人可主张六个月。不得把施行后的六个月默认写成施行前合同的唯一届满公式。
4. 主债务履行期限没有约定或约定不明确的，自债权人请求债务人履行的宽限期届满之日起算。
5. **一般保证**：债权人未在保证期间对**债务人**提起诉讼或申请仲裁的，保证人不再承担保证责任（第 693 条第一句）。仅向保证人发催收短信，通常不够。
6. **连带责任保证**：债权人未在保证期间**请求保证人**承担保证责任的，保证人不再承担保证责任（第 693 条第二句）。请求形式、送达和内容均可能被反方攻击。
7. 一般保证在期间内起诉后又撤诉，届满前未再起诉或申请仲裁的，保证人主张不再承担，法院应予支持（解释第 31 条第一款）。连带责任保证在期间内起诉后又撤诉，但起诉状或仲裁申请书副本已送达保证人的，应认定已在期间内行使权利（同条第二款）。
8. 保证责任消灭后，保证人仅在催款通知书上签字、盖章或按指印，债权人请求继续承担的，不予支持；但有证据证明成立了新的保证合同的除外（解释第 34 条）。
9. 保证期间与诉讼时效必须分列。第 694 条：一般保证自先诉抗辩权消灭之日起算保证债务诉讼时效；连带责任保证自债权人在期间内请求保证人之日起算。

关键日期冲突建并行情景，不给唯一届满日充作法律意见。没有送达事实和规则引文，禁止写“保证责任已经消灭”。

## 节点 4　先诉抗辩、主从与人保物保

1. 一般保证人在主合同纠纷未经审判或仲裁，并就债务人财产依法强制执行仍不能履行前，有权拒绝承担；但债务人下落不明且无财产、已受理债务人破产、债权人有证据证明财产不足或丧失履行能力、保证人书面放弃的除外（第 687 条）。先诉抗辩不是“一定不用还”，也不是“可以不出庭”。
2. 保证合同是从合同；主合同无效的，保证合同无效，但法律另有规定的除外。保证合同被确认无效后，有过错的仍可能承担相应民事责任（第 682 条）。**主合同无效不等于保证人一定免责。**
3. 保证人享有债务人对债权人的抗辩；债务人放弃抗辩的，保证人仍有权抗辩（第 701 条）。
4. 债权转让未通知保证人的，对保证人不发生效力；约定禁止转让且未经保证人书面同意的，保证人对受让人不再承担（第 696 条）。债务承担未经保证人书面同意，保证人对加重部分不承担（第 697 条）。本任务不确认转让或展期已经免责。
5. 既有物的担保又有人的担保：有约定从约定；无约定或不明时，债务人自己提供的物保应先实现；第三人提供物保的，债权人可选择（第 392 条）。只分层，不排责任顺序结论。
6. 最高额保证期间计算按解释第 30 条留接口，不在本任务做最高额终局。
