# 评估保证责任

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《担保法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“保证责任评估矩阵”：保证文本分层、方式迹象、范围、保证期间与行权对象、先诉抗辩、人保物保接口、主从效力、最强反方和下一步。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价主债事实、催收记录和测算。

## 工作边界

正触发：已有或可描述的保证条款，单方需要判断方式、期间、范围或是否仍可能担责，而不是今天发出主张函。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 本次主成果是发送版保证主张通知；
- 见索即付、独立于基础交易的独立保函要一次终局；
- 只要总体借贷总图、精算或诉状；
- 尚未成争，只要改担保合同（审查起草领域，本窗搁置）；
- 一般合同争议、并购交割、破产申报；
- 用户只要 C 端保证争点清单。

本任务不生成发送版保证函，不输出“一定免责”或“一定全额还”，不给胜诉率。

## 建立评估坐标

确认：使用者与授权；单方立场；保证人、债权人和主债务人；保证合同或主合同保证条款原文；主债务履行期限；已知催收、起诉或仲裁；物保并存；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`T#` 期间情景；`V#` 评估版本；`E#` 发送／送达／履行凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验第 686、687、692–694、392 条、担保制度解释第 25、31、32、34 条和时间效力规定第 27 条；`search_practiced` 补行权对象与期间反例。工具不可用时继续原文摘录和期间情景；方式认定、期间届满效果和法律结论字段停止。

引用保证合同章时使用 2021-01-01 施行文本。1995 年《担保法》及其解释已失效；不得把“约定不明=连带”或“约定不明=二年”写成现行默认。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 文本分层与独立保函闸

先按实际文字分层：独立合同还是主合同条款、最高额还是单笔、是否夹带抵押质押。见索即付或独立于基础交易：停止典型保证终局，转独立保函接口。

### 2. 保证方式与范围

有“债务人不能履行时才承担”迹象的，列一般保证；有“不履行即承担、无条件承担”且无先承担意思的，列连带迹象。没有约定或只写“担保/保证”：现行默认一般保证（第 686 条）。施行前合同的方式约定不明适用当时法律，不得用时间效力规定第 27 条改写成一般保证，不输出“现在一定是一般保证所以不用还”。

### 3. 保证期间与行权对象

期间不发生中止、中断、延长。“直至本息还清”视为约定不明，期间为主债务履行期限届满之日起六个月。施行前成立的合同，期间未约定或约定不明时按时间效力规定第 27 条并列二年／六个月情景，不得一律写成六个月。一般保证：期间内须对**债务人**起诉或申请仲裁。连带：期间内须**请求保证人**。仅向错误对象发函不得写成已行权。

### 4. 先诉抗辩、主从效力和人保物保

一般保证先诉抗辩及例外分列。主合同无效，保证合同原则上无效，但过错仍可能担责。人保物保有约定从约定；无约定时债务人自己的物保应先实现。

### 5. 最强反方与下一步

并列债权人最强主张和保证人最强抗辩。发送主张函、起诉或应诉只作转介。禁止指导伪造保证、倒签补签或隐匿催收。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；保证文本无法建立；用户坚持伪造保证、倒签或隐匿催收。
- `字段停止`：主债履行期限、送达、方式原文、动态规则未核验。
- `目标停止`：主目标已变为发送版保证函、诉状或独立保函止付。
