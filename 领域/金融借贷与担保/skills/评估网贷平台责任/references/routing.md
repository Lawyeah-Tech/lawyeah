# 边界与路由

## 正触发

平台被指自融、担保或未尽审核，民事争议已形成，主成果是责任分层，而不是定罪。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估 | 评估金融借贷担保争议 |
| 职业放贷出借人 | 评估放贷资质与职业放贷 |
| 电子合同成立 | 评估电子借款成立与送达 |
| 保证责任实体 | 评估保证责任 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 非法集资刑事 | 刑事领域，不定罪 |
| P2 刑民交叉专项 | 未安装则 unavailable |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

P2P 出借人要平台刚兑，正触发本任务分层。用户要写刑事报案书定集资诈骗，转刑事。
