# 评估金融格式条款

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《担保法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成金融格式条款评估：异常条款识别、提示说明举证、排除或限制权利条款效力意见。签前格式审查走审查领域（搁置）。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：已成争，对方以格式条款主张加速、复利、管辖、弃权或限责，用户需要效力分层，而不是签前改模板。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未成争，只要审查或改银行格式合同（审查起草搁置）；
- 只要利率保护上限精算；
- 只要总体评估或起诉；
- 一般消费合同格式条款整案但无金融借贷主轴；
- 指导如何把异常条款藏进合同；

签前格式审查走审查领域（本窗搁置）。不把未提示写成全部合同无效。

## 建立评估坐标

确认：使用者与授权；单方立场；被主张的格式条款原文与位置；签约流程（纸质／电子、勾选、加黑、单独确认）；争议效果（加速、复利、仲裁、失权）；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 陈述；`D#` 文本；`A#` 承认；`R#` 文书；`C#` 格式条款定位；`L#` 规则；`I#` 判断；`G#` 缺口；`Q#` 条款效力争点；`V#` 版本；`E#` 提示说明凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典第 496–498 条格式条款规则及金融消费者保护相关规定。工具不可用时继续条款摘录与签约流程；效力结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　成争闸

未成争改模板：负触发，审查起草搁置。已成争才继续。

### 节点 2　是否格式条款

预先拟定、重复使用、未与对方协商。双方逐条商议的费率或担保范围，不得仅因印在银行模板上就当然按格式条款处理。

### 节点 3　提示说明

免除或减轻己方责任、加重对方、限制对方主要权利的条款，须采取合理方式提示并按请求说明。电子折叠、外链、小字是常见攻击点。

### 节点 4　无效情形

不合理地免除或减轻责任、加重对方责任、限制主要权利，或符合民法典其他无效情形。不因存在格式条款就认定整个合同未成立。

### 节点 5　解释与后果

对格式条款有两种以上解释的，应当作出不利于提供方的解释。后果只及于该条款，利率、管辖、加速分别处理。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或文本无法建立；用户坚持伪造流水、隐匿还款、暴力催收、伪造送达或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为本任务以外的文书或总图。
