# 边界与路由

## 正触发

已成争，对方以格式条款主张加速、复利、管辖、弃权或限责，用户需要效力分层，而不是签前改模板。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估总图 | 评估金融借贷担保争议 |
| 已决定起诉或应诉 | file-first-instance / defend-first-instance |
| 签前审查银行模板 | 审查起草领域（搁置） |
| 利率保护上限 | 评估利率费用与砍头息 |
| 管辖／仲裁条款论坛 | 评估金融争议管辖与仲裁 |
| 加速条件实体 | 评估加速到期与提前收回 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 一般消费合同无金融主轴 | 合同争议或消费者保护交叉，按主轴转出 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

银行以小字复利条款主张利滚利，正触发本任务。客户拿来空白合同要“审一下再签”，负触发并说明搁置。
