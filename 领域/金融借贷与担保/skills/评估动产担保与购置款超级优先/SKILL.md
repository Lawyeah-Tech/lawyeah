# 评估动产担保与购置款超级优先

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《担保法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成动产担保与购置款超级优先评估：公示、宽限期、超级优先是否支持。不写实现申请。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：动产担保、浮动抵押或购置款对抗成为争点，主成果是公示与超级优先条件，而不是拍卖申请。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 不动产抵押无动产争点；
- 只要一般顺位表且无购置款或浮动抵押事实；
- 只要实现申请；
- 未成争登记材料（搁置）；
- 海事船舶抵押；

不写实现申请。不把交付后超过宽限期的登记写成超级优先。

## 建立评估坐标

确认：使用者与授权；立场；动产描述；浮动抵押财产范围；购置款合同与交付日；登记日；在先担保；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 陈述；`D#` 材料；`A#` 承认；`R#` 登记；`C#` 条款；`L#` 规则；`I#` 判断；`G#` 缺口；`Q#` 超级优先争点；`V#` 版本；`E#` 交付与登记凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典第 396、403、404、411、416 条。工具不可用时继续交付与登记时间线；超级优先结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　动产与浮动识别

普通动产抵押、浮动抵押（现有及将有的生产设备、原材料、半成品、产品）分列。

### 节点 2　公示

合同生效设立，登记对抗。正常经营活动中已支付合理价款并取得抵押财产的买受人，不受追及的规则须核验。

### 节点 3　购置款条件

主债权是价款、标的物已交付、十日内登记。缺一不可。

### 节点 4　与留置、在先抵押

超级优先原则上仍劣后于留置权。宽限期外登记按一般顺位。

### 节点 5　转介

一般顺位总表可转顺位原子。实现申请另项。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或文本无法建立；用户坚持伪造流水、隐匿还款、暴力催收、伪造送达或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为本任务以外的文书或总图。
