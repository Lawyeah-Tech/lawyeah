# 边界与路由

## 正触发

动产担保、浮动抵押或购置款对抗成为争点，主成果是公示与超级优先条件，而不是拍卖申请。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估 | 评估金融借贷担保争议 |
| 一般顺位总表 | 评估担保物权顺位 |
| 设立对抗分层 | 评估抵押质押设立与对抗 |
| 实现申请 | 准备实现担保物权申请 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 海事船舶优先权 | 海事领域 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

设备供应商主张购置款抵押优先于银行先登记的浮动抵押，正触发本任务核对十日宽限期。
