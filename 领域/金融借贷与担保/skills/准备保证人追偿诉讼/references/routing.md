# 边界与路由

## 正触发

保证人已决定提起追偿诉讼，具备代偿或确定承担的事实，主成果是追偿起诉包，而不是普通出借人起诉借款人。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估总图 | 评估金融借贷担保争议 |
| 普通保证方式与期间终局 | 评估保证责任 |
| 追偿条件评估 | 评估保证人追偿权 |
| 原债权人起诉 | 提起金融借贷担保一审 |
| 仲裁申请 | 提起金融仲裁 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 债务人破产 | 破产领域申报，不另诉个别清偿 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

保证人已代偿，要告借款人和其他保证人，正触发本任务。银行要告借款人，走普通起诉原子。
