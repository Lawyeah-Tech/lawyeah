# 准备保证人追偿诉讼

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《担保法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的保证人立场下，形成追偿诉讼材料：起诉状、追偿范围、共同担保分担请求、管辖与证据目录。与普通借款起诉不同。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：保证人已决定提起追偿诉讼，具备代偿或确定承担的事实，主成果是追偿起诉包，而不是普通出借人起诉借款人。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 原债权人起诉借款人和保证人；
- 尚未评估能否追偿且关键条件明显不支持；
- 只要追偿条件评估不要诉状；
- 有效仲裁未排除仍要求直接起诉；
- 破产申报；

与普通借款起诉不同。不代提交。不把未支付写成已取得追偿权。

## 建立评估坐标

确认：使用者与授权；保证人原告立场；被告（债务人／其他担保人）；代偿凭证；原判决或和解；仲裁条款；管辖连结点；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 陈述；`D#` 材料；`A#` 承认；`R#` 原判决；`C#` 条款；`L#` 规则；`I#` 判断；`G#` 缺口；`P#` 诉讼请求；`J#` 管辖；`V#` 稿件；`E#` 代偿凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验追偿权、共同担保分担、起诉条件与管辖；`search_template` 只借起诉状栏目。工具不可用时继续主体与代偿事实；请求法律结论和管辖选定字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　原告适格与仲裁闸

原告须是已承担或依法受让追偿权的保证人。原合同仲裁条款是否约束追偿待核；表面有效未排除则负触发。

### 节点 2　被告与请求

债务人是主位被告。其他担保人仅在现有依据支持分担时列入。请求分列本金代偿、利息、费用，禁止合成“保证损失”。

### 节点 3　范围

不超过实际承担且属于保证范围的部分。超额自愿承担单独说明风险。

### 节点 4　证据

保证合同、代偿凭证、原债证明、其他担保人合同、份额约定。

### 节点 5　稿件

起诉状草稿。不代提交，不保证胜诉。C 端 011 只分流。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或文本无法建立；用户坚持伪造流水、隐匿还款、暴力催收、伪造送达或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为本任务以外的文书或总图。
