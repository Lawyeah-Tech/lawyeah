# 边界与路由

## 正触发

已加速或终止后需清算本息费用，双方不再以本任务重开加速效力之争，或加速效力已另有结论可引用。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估 | 评估金融借贷担保争议 |
| 只要精算终稿 | 测算本金利息罚息复利 |
| 加速是否成立 | 评估加速到期与提前收回 |
| 发送加速通知 | 准备催收或加速到期通知 |
| 银行抵销 | 评估银行抵销与扣款 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 破产清算分配 | 破产领域 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

加速函已发出，双方要算“现在到底欠多少口径”，正触发本任务。还在争这封函有没有效，走加速评估。
