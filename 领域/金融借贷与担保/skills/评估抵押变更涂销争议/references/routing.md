# 边界与路由

## 正触发

争应否变更、涂销或继续登记，已成争，主成果是条件与异议，而不是代为提交登记申请。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估 | 评估金融借贷担保争议 |
| 请求办理抵押登记诉讼 | 准备请求办理抵押登记诉讼 |
| 实现担保物权 | 准备实现担保物权申请 |
| 未成争登记材料 | 审查起草搁置 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 对登记行为提起行政诉讼 | 行政领域 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

贷款还清银行拖延注销抵押，正触发本任务。客户拿着空白注销表要代填代交，负触发并说明不代办。
