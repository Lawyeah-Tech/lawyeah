# 边界与路由

## 正触发

关键流水或登记由第三方掌握，诉讼或仲裁中需要依法调取，主成果是申请与范围，而不是私下买数据。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估 | 评估金融借贷担保争议 |
| 完整证据卷策略 | 建立金融借贷担保证据案卷 |
| 自行保全己方电子证据 | 保全转账与电子证据 |
| 刑事查询 | 刑事领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 个人信息保护行政处罚风险 | 数据隐私交叉只提示 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

需要对方对公账户放款流水证明交付，正触发本任务。要求提供对方全部银行卡和通讯录，停止。
