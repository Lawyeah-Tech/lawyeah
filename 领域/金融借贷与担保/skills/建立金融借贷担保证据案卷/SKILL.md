# 建立金融借贷担保证据案卷

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《担保法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“金融借贷担保证据案卷矩阵”：争点要件与举证责任、支持与不利材料、控制方、合法取得、缺口、补证步骤和最晚时点。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：金融借贷或担保已成争，单方需要单独盘点交付、担保、催收或期间举证责任和合法补证。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要策略总图、精算或诉状；
- 要求违法调取流水、侵入系统或隐匿不利证据；
- 一般合同、并购尽调、破产债权申报卷。

本任务不替代总体策略或诉状，不给胜诉率，不保证机关采纳。

## 建立评估坐标

确认：使用者与授权；单方立场；争点范围；已持有材料及来源；对方或第三人控制的材料；法域；程序阶段。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`EV#` 证据；`V#` 案卷版本；`E#` 发送／送达／履行凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验举证责任、电子数据、调查令条件；`search_practiced` 补举证缺口。工具不可用时继续材料登记和缺口表；举证责任转移和法律结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 要件与举证责任

按 `Q#` 拆交付、利率、保证、担保物权设立、催收到达、期间。提出方、举证责任、转移/倒置条件分列。已读不等于到达。

### 2. 证据矩阵

每份材料标支持/不利、形成主体、时间、控制方、取得方式、合法性。对方控制的条目不得填写虚构内容。

### 3. 冲突与完整性

同一转账的冲突版本、缺失页、断链电子签约、无法核对原件的复印件并列，不选对用户有利的一版。

### 4. 合法补证与最晚时点

补证步骤必须合法。调查令、公证、保全只写转介。期限类型标明诉讼时效／保证期间／除斥／举证期之一。

### 5. 禁止动作

记录伪造流水、隐匿还款、偷拷银行系统等要求，并对该部分实施停止。不提供替代违法方案。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或文本无法建立；用户坚持伪造流水、隐匿还款、暴力催收、伪造送达或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为本任务以外的文书或总图。
