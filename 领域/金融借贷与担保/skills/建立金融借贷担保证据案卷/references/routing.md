# 边界与路由

## 正触发

需要单独盘点交付、担保、催收或期间的举证责任和合法补证。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 策略总图 | `评估金融借贷担保争议` |
| 起诉 / 应诉 | `file-first-instance` / `defend-first-instance` |
| 违法调取流水 | 整体停止，不转介取证方案 |
| 调查令终稿 | `申请调查令调取流水`（未安装则 `unavailable`） |
| 一般合同证据卷 | 合同争议领域 |

## 易混

用户说“帮我把能打赢的证据列出来”仍可正触发，但必须并列不利证据，不得删不利项。
