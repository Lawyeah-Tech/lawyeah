# 边界与路由

## 正触发

已决定走特别程序拍卖变卖担保财产，且尚未支持必须改走诉讼的实质性争议。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未设立，要办登或赔偿 | `准备请求办理抵押登记诉讼`（未安装则 `unavailable`） |
| 有实质性争议，要普通诉讼 | `提起金融借贷担保一审` |
| 被申请人要异议 | `应对实现担保物权申请`（未安装则 `unavailable`） |
| 普通金钱给付、无担保物权 | `file-first-instance` |
| 海事船舶担保 | 海事领域 |
| 破产程序内处置 | 破产领域 |

## 易混

有抵押合同但未登记的不动产抵押，不是当然可拍卖。先分层设立，再决定特别程序或办登/诉讼。
