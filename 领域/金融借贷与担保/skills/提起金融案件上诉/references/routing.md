# 边界与路由

## 正触发

不服未生效裁判，已决定上诉，主成果是上诉包，而不是重写一审起诉或已生效再审。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估 | 评估金融借贷担保争议 |
| 程序尚未选定 | 选择诉讼仲裁支付令或特别程序 |
| 二审答辩 | 应对金融案件二审 |
| 一审起诉 | 提起金融借贷担保一审 |
| 仲裁裁决救济 | 撤销／不予执行接口，不可上诉 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 再审 | 本包未列再审原子则 unavailable |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

一审判决刚送达要上诉，正触发本任务。判决生效半年要再审，本包不实施再审。
