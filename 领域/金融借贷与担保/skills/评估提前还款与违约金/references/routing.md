# 边界与路由

## 正触发

拟提前还或被收取提前还款违约金，借贷已成争或履行中发生费用争议，主成果是可否提前与费用效力，而不是精算终稿。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估 | 评估金融借贷担保争议 |
| 只要精算终稿 | 测算本金利息罚息复利 |
| 加速到期条件 | 评估加速到期与提前收回 |
| 格式条款 | 评估金融格式条款 |
| 利率保护上限 | 评估利率费用与砍头息 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 破产加速与个别清偿 | 破产领域 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

借款人要提前结清，银行要收剩余全部利息，正触发本任务。银行因逾期宣布全部到期，走加速评估。
