# 边界与路由

## 正触发

抵押合同已生效但未登记，债权人已决定起诉请求协助办理登记或赔偿，主成果是办登诉讼包，而不是拍卖特别程序。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估 | 评估金融借贷担保争议 |
| 实现担保物权特别程序 | 准备实现担保物权申请 |
| 涂销或变更评估 | 评估抵押变更涂销争议 |
| 普通金钱给付起诉 | 提起金融借贷担保一审 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 告登记机关不作为 | 行政领域 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

签了抵押合同一直没办他项权，债权人要告对方去登记，正触发本任务。已经登记要拍卖，走特别程序。
