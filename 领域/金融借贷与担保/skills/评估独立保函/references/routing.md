# 边界与路由

## 正触发

见索即付或独立于基础交易的保函已成争，用户需要独立性、相符交单和欺诈止付分层，而不是普通保证期间计算。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估总图 | 评估金融借贷担保争议 |
| 普通保证方式与期间终局 | 评估保证责任 |
| 典型保证期间与先诉抗辩 | 评估保证责任 |
| 公司对外担保决议 | 评估公司对外担保决议 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 复杂跨境信用证／制裁合规整案 | 跨境或合规领域，本任务只标红旗 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

银行保函写“见索即付”，受益人交单，申请人以工程未完工拒付，正触发本任务做欺诈例外分层，而不是按普通保证先诉抗辩。文本只写连带保证，负触发。
