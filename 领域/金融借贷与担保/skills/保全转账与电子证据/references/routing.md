# 边界与路由

## 正触发

聊天、转账、电子签约可能灭失，用户需要合法保全步骤，而不是完整策略卷或违法获取对方手机。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估 | 评估金融借贷担保争议 |
| 完整证据卷策略 | 建立金融借贷担保证据案卷 |
| 电子成立鉴定终局 | 评估电子借款成立与送达 |
| 调查令调流水 | 申请调查令调取流水 |
| 财产保全申请 | 准备金融财产保全申请 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 跨境取证、境外平台 | 跨境红旗 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

担心对方撤回微信转账记录，正触发本任务。要求提供对方验证码或去黑客取证，停止。
