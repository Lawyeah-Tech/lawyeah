# 保全转账与电子证据

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《担保法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成转账与电子证据保全步骤、公证分流和禁止动作。不指导违法取证。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：聊天、转账、电子签约可能灭失，用户需要合法保全步骤，而不是完整策略卷或违法获取对方手机。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 要求侵入账户、购买个人信息、木马或秘密录音违法方案；
- 只要完整要件证据矩阵；
- 只要鉴定意见；
- 未成争只要做合同存证产品选型（可作最小提示后结束）；
- 一般合同无支付电子证据主轴；

不指导违法取证。不替代鉴定。不保证公证处受理。

## 建立评估坐标

确认：使用者与授权；立场；证据类型（微信、银行、App、邮件）；保管人；灭失风险；是否已进入诉讼；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 陈述；`D#` 电子材料；`A#` 承认；`R#` 文书；`C#` 约定送达；`L#` 规则；`I#` 判断；`G#` 缺口；`E#` 现有载体；`V#` 保全方案版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验电子数据证据规则、公证保全与非法证据排除。工具不可用时继续合法步骤清单；证据能力结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　合法边界

只能保全己方控制或依法申请调取的材料。禁止窃取、购买公民个人信息、劫持验证码。

### 节点 2　优先级

按易失性：即时通讯、验证码、临时下载链接、银行流水、电子签约存证。

### 节点 3　步骤

原始载体固定、屏幕录制加哈希、公证或时间戳、向平台申请出证、诉讼中申请责令提交或调查令。

### 节点 4　公证分流

争议大、金额高、对方可能否认：建议公证保全。本任务不代办公证。

### 节点 5　与鉴定

完整性被质疑：列送检事项，不写鉴定意见。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或文本无法建立；用户坚持伪造流水、隐匿还款、暴力催收、伪造送达或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为本任务以外的文书或总图。
