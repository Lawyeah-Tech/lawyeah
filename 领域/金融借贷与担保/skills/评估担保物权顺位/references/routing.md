# 边界与路由

## 正触发

同一财产上多个担保或主张购置款超级优先，已成争，主成果是顺位表而不是拍卖申请。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或办理登记出稿 | 审查起草领域（本窗搁置） |
| 只要实现担保物权申请书 | 准备实现担保物权申请 |
| 只要总体评估 | 评估金融借贷担保争议 |
| 设立与对抗分层 | 评估抵押质押设立与对抗 |
| 动产购置款细节 | 评估动产担保与购置款超级优先 |
| 人保物保顺序 | 评估人保物保并存 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 破产别除与清偿顺序 | 破产领域 |
| 建设工程价款优先 | 建设工程领域接口 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

后登记的设备抵押主张购置款超级优先，正触发本任务核对宽限期。用户要提交拍卖申请，转特别程序原子。
