# 边界与路由

## 正触发

被告或被申请人拟反诉／反请求，尚未决定提交，主成果是是否提、风险和请求轮廓。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估 | 评估金融借贷担保争议 |
| 反诉状终稿 | 准备金融反诉或仲裁反请求 |
| 本诉答辩 | 应对金融借贷担保一审 / defend-arbitration |
| 独立起诉 | 提起金融借贷担保一审 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 刑事附带民事 | 刑事领域 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

被告想要回多付的高息，还没决定是否反诉，正触发本任务。已经决定下周交反诉状，走准备原子。
