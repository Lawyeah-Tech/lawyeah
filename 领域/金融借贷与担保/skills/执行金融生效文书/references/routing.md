# 边界与路由

## 正触发

持判决、调解书、裁决未获履行，主成果是执行立案包，而不是再审实体或追加被执行人评估。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估 | 评估金融借贷担保争议 |
| 赋强公证执行 | 执行赋强公证债权文书 |
| 追加被执行人 | 评估追加被执行人或担保人 |
| 被执行人应对 | 应对金融执行 |
| C 端执行申请 | 大众包只分流 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 破产受理后个别执行 | 破产领域 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

赢了官司对方不给钱，正触发本任务。还想把股东拉进来当被执行人，走追加评估。
