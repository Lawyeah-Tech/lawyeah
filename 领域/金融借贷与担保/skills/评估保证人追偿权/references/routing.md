# 边界与路由

## 正触发

保证人已付或即将承担责任，要判断能否向债务人或其他担保人追偿，主成果是追偿条件与份额，而不是起诉状。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估总图 | 评估金融借贷担保争议 |
| 普通保证方式与期间终局 | 评估保证责任 |
| 准备追偿起诉状 | 准备保证人追偿诉讼 |
| 人保物保顺序实体 | 评估人保物保并存 |
| 向保证人主张责任 | 评估保证责任 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 债务人破产后追偿权申报 | 破产领域 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

保证人刚被判决连带但尚未付款，问能不能先告借款人，正触发本任务评估条件，而不是直接写追偿诉状。已决定起诉则转追偿诉讼原子。
