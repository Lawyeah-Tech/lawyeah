# 边界与路由

## 正触发

债权条件需要比较多条程序入口，主成果是程序选择，而不是任何一种完整申请书。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估 | 评估金融借贷担保争议 |
| 起诉包 | 提起金融借贷担保一审 |
| 仲裁申请包 | 提起金融仲裁 |
| 支付令申请 | 申请金融金钱支付令 |
| 实现担保物权申请 | 准备实现担保物权申请 |
| 论坛条款效力 | 评估金融争议管辖与仲裁 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 破产程序入口 | 识别破产程序入口并分流 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

有抵押、对方可能否认借款，问走拍卖快还是起诉，正触发本任务，结论通常不能单走特别程序。已决定起诉，走起诉原子。
