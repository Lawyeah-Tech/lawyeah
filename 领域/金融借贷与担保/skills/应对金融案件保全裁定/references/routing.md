# 边界与路由

## 正触发

账户或担保物已被保全，主成果是复议、异议或置换担保，而不是转移财产。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估 | 评估金融借贷担保争议 |
| 完整证据卷策略 | 建立金融借贷担保证据案卷 |
| 写保全申请 | 准备金融财产保全申请 |
| 执行异议 | 应对金融执行 |
| 案外人异议之诉 | P2 未安装则 unavailable；提示转执行救济 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 破产中保全解除 | 破产领域 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

账户被诉前冻结，想用保证金换经营户，正触发本任务。想连夜把钱转到亲友卡，停止。
