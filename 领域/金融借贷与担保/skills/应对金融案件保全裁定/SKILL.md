# 应对保全裁定

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《担保法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的被保全方立场下，形成复议或担保置换方案。不提供转移隐匿方案。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：账户或担保物已被保全，主成果是复议、异议或置换担保，而不是转移财产。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 申请方写保全申请；
- 要求转移、隐匿、另开账户规避冻结；
- 执行查封主轴（已进入执行）；
- 未保全只评估必要性；
- 破产中个别保全解除整案；

不提供转移隐匿方案。不保证复议成功。

## 建立评估坐标

确认：使用者与授权；被保全方立场；裁定内容、送达日、复议期限；被冻财产性质；能否提供置换担保；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 陈述；`D#` 裁定；`A#` 承认；`R#` 文书；`C#` 条款；`L#` 规则；`I#` 判断；`G#` 缺口；`Q#` 复议／置换争点；`V#` 版本；`E#` 送达与权属凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验保全复议、超标的解封、担保置换。工具不可用时继续裁定与财产事实；复议期限届满结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　安全与期限

转移隐匿：停止。复议期限未核验：字段停止。

### 节点 2　复议理由

超标的、错误对象、无权属、担保已足、情况不紧急、申请人未提供担保。

### 节点 3　置换

提供等额现金或可靠担保请求解除对经营账户或住房的查封。

### 节点 4　第三人

案外人权属：执行异议或案外人程序接口，本任务只标，P2 异议之诉未安装则 unavailable。

### 节点 5　稿件

复议申请或置换申请草稿。不代提交。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或文本无法建立；用户坚持伪造流水、隐匿还款、暴力催收、伪造送达或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为本任务以外的文书或总图。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
