# 提出金融案件管辖异议

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《担保法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的被请求方立场下，形成管辖异议书草稿、连结点证据和逾期风险说明。与仲裁协议异议不同；过期停止。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：已被起诉或被申请，需在法定期限提出管辖权异议，主成果是异议书而非实体答辩或仲裁协议效力总评。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 异议期已过仍要求提交管辖异议终稿；
- 主目标是仲裁协议效力或仲裁管辖权异议；
- 原告侧选择管辖或评估论坛；
- 只要实体答辩；
- 海事专属或行政管辖整案；

与仲裁协议异议不同。过期停止。不保证异议成立，不把实体无理当成管辖错误。

## 建立评估坐标

确认：使用者与授权；被请求方立场；受诉法院、案号、起诉状送达日、答辩期满日；管辖条款；连结点材料；是否已应诉答辩实体；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 陈述；`D#` 材料；`A#` 承认；`R#` 受理与送达文书；`C#` 管辖条款；`L#` 规则；`I#` 判断；`G#` 缺口；`P#` 异议请求；`V#` 稿件版本；`E#` 送达凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民事诉讼法答辩期内提出管辖异议、应诉管辖、协议管辖和专属管辖。工具不可用时继续送达日与条款摘录；异议期限届满结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　期限闸

未核验起诉状送达日和答辩期满日：期限字段停止，不得写出可提交终稿。已过期：整体停止管辖异议终稿，转实体答辩并明示失权风险。

### 节点 2　异议类型

级别管辖、地域管辖、专属管辖、协议管辖、应诉管辖分列。仲裁协议阻却不是本任务主成果。

### 节点 3　连结点证据

住所、履行地、协议管辖文本、不动产所在地。材料不足不选定“唯一正确法院”，只攻击受诉法院连结点。

### 节点 4　异议书草稿

请求移送或驳回、事实与理由、证据目录。不夹带实体免责长文。

### 节点 5　复议与并行

裁定后复议接口只标。不指导为拖时间滥提异议。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或文本无法建立；用户坚持伪造流水、隐匿还款、暴力催收、伪造送达或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为本任务以外的文书或总图。
