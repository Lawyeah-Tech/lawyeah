# 边界与路由

## 正触发

已被起诉或被申请，需在法定期限提出管辖权异议，主成果是异议书而非实体答辩或仲裁协议效力总评。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草领域（本窗搁置） |
| 只要总体评估总图 | 评估金融借贷担保争议 |
| 已决定起诉或应诉 | file-first-instance / defend-first-instance |
| 论坛选择尚未被诉 | 评估金融争议管辖与仲裁 |
| 仲裁协议异议／仲裁应诉 | 应对金融仲裁 |
| 实体答辩 | 应对金融借贷担保一审 |
| 上诉 | 提起金融案件上诉 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 海事专属管辖异议 | 海事领域 |
| 行政诉讼管辖 | 行政领域 |
| 买卖、服务、承揽等一般履行解除，资金提供不是主轴 | 合同争议领域 |
| 以股权或资产交割为主要成果 | 投资并购领域 |
| 破产已受理、申报债权、重整计划、清算分配 | 破产领域（本包不做申报） |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

金融主轴夹带一般买卖或家事背景时，非金融段只分流，不把专项规则写入本任务结论。

## 易混

答辩期内既要提管辖异议又要写实体答辩，正触发本任务完成异议书，实体部分转应诉原子。过期后要求“补一个管辖异议试试”，停止。
