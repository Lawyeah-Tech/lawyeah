# 评估多式联运海运区段责任方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：区段识别、网状或统一责任制接口、海运段海商法适用

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　合同与区段事实

先固定是否构成多式联运合同，再固定损坏或灭失发生区段。

若：只有港到港提单、无其他区段 → 转货损评估，本任务负触发。
若：封识完好、开箱才发现损坏且无区段记录 → 区段不明。
若：海运舱单、理货或卸船已记录残损 → 海运段接口打开。
若：内陆车祸或铁路记录已证明损坏 → 海运段责任现有依据不支持。

## 节点 2　责任制接口

网状责任制与统一责任制只建接口，不编造合同没有的制度。

若：合同约定损坏区段确定时适用该区段法律 → 按约定接口，仍核验强制规则。
若：区段不明且合同约定统一责任 → 按约定评估，海运限额不得自动写入。
若：合同沉默且区段不明 → 责任基础依据不足，禁止输出海运 SDR。
若：多式联运经营人与区段承运人同时被主张 → 分列，不合并限额。

## 节点 3　海运段海商法适用

仅当损坏确定发生在海运区段时展开第四章接口。

若：海运段装港卸港均为中国港口 → 海运段仍受第二条第二款约束，免责限额停止。
若：国际海运段确定 → 可转介货损评估的免责与通知节点。
若：海运段不确定 → 不得展开第五十一条、第五十六条结论。
若：舱面货或活动物仅在海运段出现 → 区段不明时该特别规则停止。

## 节点 4　主体

多式联运经营人、海运实际承运人、内陆车队分列。

若：经营人以自己名义签全程单 → 经营人主位打开。
若：货代仅代理且披露各区段承运人 → 不当然写成多式联运经营人。
若：需要主体总表 → 可转 identify-carrier-and-parties。
若：纯报关或内陆货代无海运因素 → 转合同争议。

## 节点 5　时效与下一步

海运段确定时才用货损一年接口；区段不明时期间分列待核。

若：用户硬要按海运一年起诉且区段不明 → 标风险，期间字段不单写一年。
若：需要货损免责展开 → 转 评估货损货差迟延索赔 并交接区段结论。
若：需要通知 → 转 准备货损通知或索赔保留。
若：公路铁路航空主轴已清楚 → 整案转出。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
