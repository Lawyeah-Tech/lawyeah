# 边界与路由

## 正触发

全程提单或联运单下货损区段不明或海运段明确，需要区段识别和海商法适用判断。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 纯公路、铁路或航空主轴 | 相应领域或合同争议 |
| 不明区段硬套海运限额 | 停止限额字段 |
| 港到港纯海运货损 | 评估货损货差迟延索赔 |
| 无单放货 | 评估无单放货责任 |
| CIF 货款 | 涉外 |

## 易混

全程无船承运人签发联运单不等于损坏发生在海运段。区段不明不得当然适用海商法第四章限额。内陆段承运人不是当然的实际承运人。


## 专项转出

- 纯海运货损转 评估货损货差迟延索赔
- 货代识别转 评估海上货运代理争议
