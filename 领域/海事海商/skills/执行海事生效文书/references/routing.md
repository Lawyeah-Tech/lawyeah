# 边界与路由

## 正触发

持有判决、调解书或裁决未获履行，权利人需要执行申请。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 重审实体 | 停止重审 |
| 复杂追加被执行人或拒执刑责 | 升级分流 |
| 文书尚未生效 | 上诉或履行期未满 |
| 被执行人异议包 | 应对海事执行 |
| 一般民事执行无船舶线索且无海事文书 | 合同争议执行路径 |

## 易混

执行不是二审。仲裁裁决执行可能遇到不予执行抗辩。扣船执行与诉前扣船不同。金额以文书为准，未知利息不编造。


## 专项转出

- 应对执行转 应对海事执行
- 不予执行裁决转 申请不予执行海事仲裁裁决

本包未安装的入口一律输出 `unavailable`，不得由名称相近的 Skill 代做。相邻已完成领域和 C 端 109 只分流，不代做其实体结论。
