# 海事海商领域边界

当前安装包是。本表只说明归属。每次路由先核对 [当前能力地图](capability-map.md)；未安装入口（含 P2）输出 `unavailable`。

| 相邻 | 本包入口 | 转出 |
| --- | --- | --- |
| 合同审查与起草 | 无。未成争只要改租约、提单或造船合同：本窗搁置，只说明不实施 | 审查起草领域（用户单独策略） |
| 合同争议解决 | 无。一般买卖、服务、承揽已成争 | 合同争议领域 |
| 涉外与国际贸易 | 无。CIF/FOB 货款、信用证、出口管制、制裁、CISG 买卖主轴 | 涉外领域 |
| 劳动 | 船员工资、遣返、船上人身伤亡的海事请求和扣船可留 | 劳动合同解除、经济补偿、社保公积金主轴 |
| 人身损害 | 海上旅客、船员营运伤亡、船舶碰撞人身请求留本包 | 陆上交通事故或场所侵权无海船特征 |
| 建设工程 | 无 | 港口码头施工价款、工期、质量 |
| 环境能源 / 行政 | 船舶油污民事赔偿可留 | 岸上排污许可、环评、海事行政处罚复议诉讼 |
| 公司治理 | 无 | 船舶作为股权标的的股东权利 |
| 刑事 | 评估中的刑民交叉只标红旗 | 定罪、逃逸犯罪侦查、辩护 |
| C 端运输货损 | 专业货损评估，不降成快递限额 | 大众快递搬家第一轮索赔 |
| C 端 011 | 专业海事起诉包 | 大众网上立案材料且请求论坛已闭合 |
| C 端 012 | 专业海事应诉包 | 大众民事答辩 |

货物曾经上船，但主请求是货款、信用证或一般买卖违约时，整案转出，不把海运背景写入本包结论。
