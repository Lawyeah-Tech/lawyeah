# 边界与路由

## 正触发

货代以自己名义签单、转委托或未依指示放货，需要识别其是代理人还是承运人。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 纯报关或内陆货代无海运因素 | 合同争议或涉外 |
| 货损总评估且承运人已明确 | 评估货损货差迟延索赔 |
| 无单放货且货代不是放货主体 | 评估无单放货责任 |
| 未成争起草货代协议 | 审查起草本窗搁置 |
| CIF 货款 | 涉外 |

## 易混

货代发票不等于承运人身份。HOUSE 提单以货代为承运人时不能再用“只是代理”抗辩完结。转委托未披露不等于当然免责。未依指示放货可能同时触发代理违约和无单放货接口。


## 专项转出

- 承运人识别转 识别承运人实际承运人与责任主体
- 无单放货转 评估无单放货责任
