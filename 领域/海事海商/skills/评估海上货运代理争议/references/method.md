# 评估海上货运代理争议方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：货代与无船承运人识别、签单即承运人风险、转委托权限

---

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　身份识别

代理人与契约承运人/无船承运人必须先分列。

若：货代以自己名义签发运输单证 → 承运人责任接口打开，不得只写代理。
若：货代披露承运人且仅代订舱 → 代理接口打开，仍核验是否越权。
若：身份条款与签章冲突 → 并列，不自动取对货代有利的身份条款。
若：无船承运人备案状态未核验 → 备案字段停止，不据此单独写成合同无效。

## 节点 2　转委托

转委托是否经同意、是否披露次级承运人分别判断。

若：委托书禁止转委托而货代转委托 → 越权接口打开。
若：转委托已披露且委托人未反对 → 代理范围内责任另核履行过错。
若：次级承运人造成货损 → 货代是承运人则进入承运人责任；仅为代理则过错与选任另核。
若：转委托链断裂 → 主体依据不足。

## 节点 3　放货与指示

未依托运人或持单人指示放货单独建 Q#。

若：正本提单仍在、货代指示码头放货 → 无单放货或代理违约并行，转无单放货专项补责任。
若：委托人书面电放、货代未执行造成滞期 → 代理违约接口，不写成无单放货。
若：指示冲突 → 并列，货代自行选择的风险标出。
若：纯报关延误无海运单证 → 转合同争议。

## 节点 4　费用与留置主张

订舱费、包干费、垫付运费分列。货代主张留置须有占有和合法债权。

若：包干费包含运费且货代已签单 → 费用性质不影响承运人身份。
若：货代无占有却主张海商法货物留置 → 现有依据不支持。
若：需要运费留置评估 → 转 freight-and-cargo-lien。
若：费用是货款 → 转涉外。

## 节点 5　时效与下一步

货代作为承运人时按运输请求时效；作为代理人时按委托或合同争议时效待核。

若：身份未定 → 两套时效并行，不输出唯一截止日。
若：需要主体总表 → 转 identify-carrier-and-parties。
若：需要货损免责 → 转货损评估。
若：用户要求伪造委托书 → 整体停止。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
