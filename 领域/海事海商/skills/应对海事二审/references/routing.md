# 边界与路由

## 正触发

已收到上诉状，被上诉方需要二审答辩。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 主动上诉 | 提起海事上诉 |
| 一审应诉 | 应对海事一审 |
| 对仲裁裁决异议 | 撤销或不予执行原子 |
| 逾期不答辩却要当作已提反上诉 | 停止该写法 |
| 一般民事二审无海事 | 合同争议 |

## 易混

被上诉人提交答辩不是上诉。可以附带上诉或另行上诉的条件须核验，不得默示已提出。二审新证据限制同样适用于被上诉人。


## 专项转出

- 主动上诉转 提起海事上诉
- 庭审转 准备海事庭审
