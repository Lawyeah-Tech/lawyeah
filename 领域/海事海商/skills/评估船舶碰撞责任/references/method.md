# 评估船舶碰撞责任方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：碰撞定义、过失比例接口、内河互碰排除、连带或按份

---

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　碰撞定义与适用范围

两艘或两艘以上船舶在海上或与海相通水域发生接触，或浪损等间接碰撞。内河船互碰排除海船解释第一条。

若：两艘均为内河船且不满足海商法船舶定义 → 不得适用碰撞解释第一条，改标其他侵权路径待核。
若：海船与内河船碰撞 → 适用范围运行时核验，不得直接套用或直接排除。
若：无接触但兴波导致他船受损 → 浪损接口打开。
若：岸上设施被碰 → 碰撞船舶责任打开，设施请求另列。

## 节点 2　过失事实

航行规则违反只作事实接口，不输出唯一过失比例数字。

若：VDR、日志、AIS 冲突 → 并列，不选对用户有利版本。
若：一船停泊被碰 → 在航船过失接口打开，停泊船是否点灯另核。
若：不可抗力或原因不明 → 核验各方无过失时责任自负规则。
若：用户要求伪造日志 → 整体停止。

## 节点 3　对内对外责任结构

互有过失碰撞：对船舶相互按过失比例；第三人人身与财产的连带或按份必须核验。

若：仅两船互损无第三人 → 按过失比例接口，数字待鉴定或测算。
若：第三人人身伤亡 → 标连带接口待核。
若：第三人财产损害 → 标按份或连带待核，不得记忆写成一律连带。
若：引航员过失 → 不当然免除船舶所有人责任。

## 节点 4　请求与时效

修理、船期、货物、人身分列。时效两年自碰撞之日起。

若：用户要停航损失终稿 → 转 calculate-collision-damages。
若：油污为主请求 → 转 pollution。
若：起算不用碰撞日而用发现日 → 纠正为第二百六十一条接口，另有规则则待核。
若：需要责任限制 → 转 limitation-of-liability，与单位限制分列。

## 节点 5　论坛与下一步

碰撞常有扣船和专属连结点。本任务不写扣船申请。

若：拟扣船 → 转 assess-ship-arrest。
若：需要鉴定碰撞原因 → 转 prepare-survey。
若：内河行政调查为主 → 行政调查只作证据，本任务不替代调查结论。
若：准据法争议 → 转 applicable-law。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
