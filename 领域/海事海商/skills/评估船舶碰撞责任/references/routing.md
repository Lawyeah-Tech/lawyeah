# 边界与路由

## 正触发

海船碰撞或浪损，需要过失比例和请求结构，而不是停航损失精算终稿。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 内河船互碰却套用海船碰撞解释第一条 | 停止套用 |
| 停航损失精算终稿 | 测算碰撞财产停航与船期损失 |
| 岸上车辆相撞 | 人身损害或合同争议 |
| 只要油污基金 | 评估船舶油污与污染责任 |
| 未成争审查航行规则手册 | 不实施 |

## 易混

浪损可以构成碰撞。双方过失碰撞对第三人财产通常按份，对人身可能连带，必须核验条文。内河船互碰不适用海船碰撞解释第一条。有碰撞不等于当然可限制责任。


## 专项转出

- 损失测算转 测算碰撞财产停航与船期损失
- 油污转 评估船舶油污与污染责任
