# 排序船舶优先权抵押权留置权方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：第二十二条至第二十五条顺位表、救助后发生优先权、时效消灭

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　项目识别

只有第二十二条列明项目才进入优先权。工资、人身伤亡、港口规费、救助、侵权财产赔偿分项核对。

若：请求是普通货款或借款 → 不进入优先权。
若：船员工资或遣返 → 第一项接口，劳动仲裁另分流。
若：油污或沉船打捞费用是否属于优先权 → 运行时核验，不得记忆写入。
若：项目事实不能回链 → 该行依据不足。

## 节点 2　第二十三条顺序与救助后发生

同类按比例；救助报酬优先权后于其发生的优先权反而居前。

若：存在后发生的救助 → 该救助报酬排在其救助之前发生的优先权之前。
若：多次救助 → 后发生的救助优先于先发生的救助。
若：时间线不明 → 顺序字段停止。
若：用户要求把抵押插进优先权之前 → 现有依据不支持。

## 节点 3　第二十五条抵押与留置

船舶优先权先于船舶留置权，船舶抵押权后于船舶留置权。条号运行时核验。

若：修船人丧失占有 → 留置权现有依据不支持。
若：抵押已登记 → 进入抵押行，仍位于优先权和留置之后。
若：建造中船舶负担 → 特别规则待核。
若：司法费用、保管费 → 按第二十四条优先拨付接口，不并入第二十二条项目。

## 节点 4　消灭

优先权自产生之日起一年不行使消灭；转让船舶的催告期间另核。

若：一年期间届满未扣船或未起诉行使 → 优先权消灭接口打开，债权可能仍在。
若：期间起算日不明 → 消灭字段停止。
若：已进入拍卖债权登记 → 转 register-claim-for-auction 交接顺位表。
若：把优先权消灭写成债权消灭 → 纠正。

## 节点 5　输出边界

本任务出顺位表，不代替法院分配裁定。

若：用户只要裁定主文 → 目标停止。
若：基金债权人分配 → 标与第十一章基金的交叉，不在本任务算基金金额。
若：船员只要劳动仲裁 → 转劳动并保留优先权提示。
若：伪造救助时间以抢顺位 → 整体停止。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
