# 边界与路由

## 正触发

拍卖或受偿前需要排列船舶优先权、抵押权和留置权顺序。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 代替拍卖分配裁定 | 不代替裁定 |
| 船员工资只要劳动仲裁 | 劳动 |
| 只要设立基金 | 设立海事赔偿责任限制基金 |
| 一般债权人分配无船舶负担 | 执行或破产领域视情况分流 |
| 未成争设计抵押结构 | 审查起草搁置 |

## 易混

救助报酬优先权在其救助之后发生的优先权之前。诉讼费用和司法拍卖费用优先拨付不等于船舶优先权。优先权一年不行使消灭，与债权诉讼时效不同。


## 专项转出

- 拍卖债权登记转 登记债权并参与拍卖分配
- 抵押效力转 评估船舶抵押与登记对抗
