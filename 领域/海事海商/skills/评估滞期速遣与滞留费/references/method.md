# 评估滞期速遣与滞留费方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：时间起算、除外、滞期或滞留定性与计算接口

---

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　文件与递交

NOR、装卸准备就绪和港口限制必须回链。口头“已经到了”不得写成 NOR 有效。

若：NOR 在检疫或海关放行前递交且条款要求全部手续完成 → 起算依据不足或不支持。
若：NOR 被收货人拒收但条款允许视为送达 → 并列条款与拒收事实。
若：SOF 与航海日志时间冲突 → 不选对用户有利的一版。
若：无租约、只有班轮滞期条款 → 按班轮条款评估，不套 GENCON 默示。

## 节点 2　装卸时间起算与除外

起算、中断、除外分列。已进入滞期后“一旦滞期永远滞期”仅在约定或可核验习惯支持时标接口。

若：天气停工但条款无除外 → 不得自行扣除。
若：港口拥挤是否算 laytime 条款沉默 → 依据不足。
若：节假日是否计入须回链条款，不得按记忆港口习惯写成已决。
若：装卸时间总数与分港计算冲突 → 并列情景。

## 节点 3　滞期与滞留定性

滞期是装卸时间用尽后的约定费用。滞留是租约未覆盖的迟延损失接口。

若：仍在约定装卸时间内 → 滞期请求现有依据不支持。
若：装卸时间已满且费率有约定 → 滞期定性打开，是否调整待核，不得当然写成违约金。
若：迟延发生在装卸时间机制之外（如等泊无 NOR 机制） → 标滞留或损害赔偿接口。
若：速遣主张 → 须有完成提前和费率，不得用滞期费率反向冒充。

## 节点 4　责任主体

航次租家、托运人、收货人谁承担滞期须回链提单和租约。

若：提单未并入滞期条款 → 对持单人请求依据不足。
若：滞期与运费留置一并主张 → 转运费留置原子交接。
若：需要租约解除或撤船 → 转租约总评估。
若：CIF/FOB 买方未及时收货被写成承运人滞期免责依据 → 纠正主体。

## 节点 5　计算接口

本任务给出可计算参数，不输出唯一必得总额。

若：费率、时间参数齐全 → 列出计算接口，精算可转测算原子。
若：参数缺失 → 未知不写零。
若：用户要求按违约金调减公式处理 → 仅标待核，不得直接改写成已调整。
若：时效 → 按租船两年接口，不套货损一年。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
