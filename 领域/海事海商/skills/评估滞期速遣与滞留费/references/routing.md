# 边界与路由

## 正触发

装卸时间、NOR、滞期或 detention 成为争议，需要起算、除外和定性。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 把滞期当然写成违约金 | 停止该定性 |
| 租约总评估或撤船 | 评估航次期租光租争议 |
| 只要精算终稿且定性未闭合 | 先完成本任务再转测算 |
| 一般仓储超时费 | 合同争议 |
| 未成争起草滞期条款 | 审查起草本窗搁置 |

## 易混

滞期费常按约定费率连续计算，不等于法院必然按违约金调整。滞留费（detention）与滞期费不是同一概念。NOR 未有效递交不得起算。天气除外只在条款支持时扣除。

- 租约总评估转 评估航次期租光租争议
- 数字工作表转 测算货损运费滞期与限制后金额
