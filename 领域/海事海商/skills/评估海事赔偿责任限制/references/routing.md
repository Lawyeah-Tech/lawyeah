# 边界与路由

## 正触发

事故后责任人拟限制赔偿责任，或请求人拟打破限制。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 设立基金申请包 | 设立海事赔偿责任限制基金 |
| 单位责任限制（件数公斤） | 评估单位责任限制 |
| 油污公约请求未经核验除外 | 评估船舶油污与污染责任 |
| 碰撞过失比例 | 评估船舶碰撞责任 |
| 保证法院必准限制 | 停止该保证 |

## 易混

第十一章限制不是第四章单位限制。救助报酬、共同海损分摊、油污、劳务合同等可能除外。设立基金不等于责任成立。故意或明知轻率丧失限制。

- 设基金转 设立海事赔偿责任限制基金
- 单位限制转 评估单位责任限制
