# 评估海事赔偿责任限制方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：可限制请求清单、第二百零八条除外、丧失限制条件，与单位限制分列

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　责任人资格

船舶所有人、救助人等法定主体才可限制。承租人、经营人是否纳入运行时核验。

若：请求针对货代且非船舶所有人 → 限制资格依据不足。
若：光租人被当作所有人 → 资格待核。
若：主体不明 → 先补识别。
若：用户不是责任人也不是请求人 → 立场停止。

## 节点 2　可限制请求清单

第二百零七条列明类型才可限制。在船上发生的人身伤亡、财产损害、迟延等分项核对。

若：请求是船上人身伤亡或财产损害 → 可限制接口打开。
若：请求是与营运直接相关的港口工程损害等 → 核验是否落入。
若：请求性质不明 → 该行依据不足。
若：与单位限制被合成一笔数字 → 强制分列。

## 节点 3　第二百零八条除外

救助款项、共同海损分摊、油污、核能、劳务合同等除外必须逐项。

若：救助报酬或特别补偿 → 不得限制。
若：共同海损分摊 → 不得限制。
若：油污损害赔偿且公约或除外条文覆盖 → 不得用第十一章限制吞并。
若：沉船打捞清除费用 → 标除外待核。

## 节点 4　丧失限制

故意或明知可能造成损失而轻率作为或不作为。

若：材料支持故意或轻率 → 限制权利现有依据不支持。
若：仅事故严重 → 不得写成已经丧失。
若：船员过失是否视为责任人本人轻率不明 → 依据不足。
若：请求人要挑战基金程序 → 转 challenge-limitation。

## 节点 5　金额接口与基金

本任务不算基金申请，只建吨位和 SDR 接口。

若：吨位或 SDR 未核验 → 金额停止。
若：已决定申请设立基金 → 转 establish-limitation-fund。
若：沿海或内河特别限额规定可能适用 → 另核，不得直接用国际吨位表。
若：未知写成零 → 拒绝。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
