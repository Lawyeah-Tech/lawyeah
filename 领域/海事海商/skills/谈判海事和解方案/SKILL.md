# 谈判海事和解方案

## 任务目标

在明确、无利益冲突的单方立场下，形成仍可协商的“海事和解方案表”：争点与让步档位、放船或换保条件、弃权范围、单独和解无执行力的明示。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：海事已成争，相对方或程序尚未切断协商可能，用户需要条件和让步方案，而不是已谈拢后的可签协议正文。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 条件已谈拢只要可签协议正文；
- 只要答辩或只要扣船申请；
- 要求写永不追究且覆盖未知油污或第三人伤亡；
- 未成争改租约（审查起草搁置）；
- 指导以和解掩盖逃逸或污染犯罪；

不生成可签署和解协议终稿，不代办司法确认，不保证对方履行。

## 建立评估坐标

确认：已形成争点；是否已扣船；对方报价；P&I 是否介入；仲裁条款。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` `D#` `A#` `R#` `C#` `L#` `I#` `G#` `Q#` `N#` `W#` `V#` `E#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验弃权、时效中断、调解书和解释第二十五条和解延长期限。工具不可用时继续报价表；弃权效力和执行力字段停止。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号、2000 货规时记为噪声，不得写入 `L#`。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 仍可谈状态

已扣船、已立案只要协商渠道未切断仍可正触发。用户只要答辩则负触发。

### 2. 争点让步表

货损、运费、滞期、放船担保、责任限制放弃分列档位。不得合成一笔打包了结而省略互斥。

### 3. 放船与担保

和解以放船为条件时写担保替换、法院认可和三十日风险。口头同意放船不等于裁定解除。

### 4. 弃权范围

未获明示确认不得放弃现有请求。覆盖未知人身伤亡、未知污染或“永不追究”：字段停止或负触发。

### 5. 执行力

单独和解无强制执行力必须明示。司法确认、仲裁调解书、法院调解只转介。有效仲裁不得写谈不拢就去海事法院。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或航次无法建立；用户坚持伪造航海日志、倒签提单、逃船、威胁或违法登轮取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为其他原子的终稿。
