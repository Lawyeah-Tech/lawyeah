# 识别承运人实际承运人与责任主体方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：承运人、实际承运人、契约相对人对照表，签单授权与责任接口，不替代货损总评估或无单放货专项

---

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　单证版本与签单名义

先固定提单、海运单、电放指示和订舱的版本层级。签章、承运人栏、页眉船名冲突并列，不选对用户有利的一版。

若：只有订舱确认、没有提单或海运单 → 契约相对人按订舱主体建立，承运人字段标依据不足。
若：提单正面承运人栏、签章和页眉船名三者冲突 → 三者并列写入主体表，禁止用身份条款直接覆盖签章。
若：电放或海运单 → 仍识别契约承运人，但不得把持单人当然写成物权权利人。
若：一式多份正本签发给不同主体 → 各持有人分列，不合并为同一权利人。

## 节点 2　承运人与实际承运人

契约承运人按与托运人订立海上货物运输合同的人认定；实际承运人按接受委托或转委托实际从事运输的人认定。

若：班轮公司以自己名义签发提单 → 现有依据支持其为契约承运人，实际承运人另核是否同一主体。
若：无船承运人签发 HOUSE 提单、海船公司签发 SEA 提单 → 两套承运人关系分列，货方持哪一套单证决定主位请求对象。
若：期租下船长签发船东提单 → 实际承运人接口指向登记船东或光租人，契约承运人仍可能是租家或无船承运人。
若：光船租赁已登记 → 光租人进入实际承运人或船舶经营人接口，登记船东不得当然列为契约承运人。

## 节点 3　货代、无船承运人与授权

货代以自己名义签单时标承运人责任接口；仅代理订舱且披露承运人时标代理人接口。不得把货代当然写成承运人。

若：货代提单以货代为承运人、未披露实际承运人 → 货代进入契约承运人主位，转委托权限另核。
若：货代仅在订舱栏出现且有承运人签章提单 → 货代不当然进入承运人栏，委托范围另证。
若：签单授权、船长授权或代理协议缺失 → 签单效力字段依据不足，不得伪造授权。
若：用户要把货代一律写成承运人以便扣船 → 停止该写法，回到单证表面。

## 节点 4　租约链与责任接口

航次租船、定期租船、光船租赁分列。NYPE、GENCON 只作事实文本，不写成中国法当然条款。

若：只有航次租约、没有提单 → 契约相对人按租约当事人建立，承运人定义改核第六章接口。
若：提单并入租约但并入文句不明 → 并入范围依据不足，主体表仍按提单表面建立。
若：连环转租 → 每一环出租人/承租人分列，不把头程租家写成对货方当然承运人。
若：船舶经营人、管理人名称出现 → 单独一行，未经签单或委托不得并入承运人。

## 节点 5　可诉主体与下一步

输出主位、备位和互斥。承运人与实际承运人可并列。扣船、货损评估、无单放货只转介。

若：主位主体名称无法与任何单证或登记回链 → 整体停止策略结论，只列缺口。
若：需要判断无单放货 → 转 评估无单放货责任，本任务只留主体表。
若：需要判断货损免责或时效 → 转 评估货损货差迟延索赔。
若：拟扣船 → 转 评估扣船必要性与可扣船舶 或 prepare-ship-arrest，本任务不写申请。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
