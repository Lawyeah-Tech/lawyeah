# 边界与路由

## 正触发

提单、订舱、船东、租家或货代名称冲突，需要先锁定可诉或可抗辩主体，而不是立刻做货损或无单放货终局。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 货损责任期间、免责或时效总评估 | 评估货损货差迟延索赔 |
| 无单放货是否成立 | 评估无单放货责任 |
| 只要扣船申请 | 准备扣押船舶申请 |
| CIF/FOB 货款或信用证主轴 | 涉外 |
| 未成争改提单身份条款 | 审查起草本窗搁置 |

## 易混

货代出现在订舱栏不等于货代是承运人。登记船东不等于契约承运人。身份条款不能自动覆盖正面签章。光船承租人与期租人不得合并。


## 专项转出

- 货损总评估转 评估货损货差迟延索赔
- 货代专项转 评估海上货运代理争议
- 船舶权属转 评估船舶所有权登记与权属
