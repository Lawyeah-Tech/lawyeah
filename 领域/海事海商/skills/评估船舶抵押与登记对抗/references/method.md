# 评估船舶抵押与登记对抗方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：抵押效力、登记对抗，以及与优先权、留置权的顺位接口

---

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　设立与登记

书面抵押和登记对抗分列。未登记不得对抗第三人。

若：仅有借款合同无抵押条款 → 抵押权依据不足。
若：已签抵押合同未登记 → 对内效力与对抗效力分列。
若：登记船名、份额与合同不一致 → 并列，对抗范围依据不足。
若：建造中船舶抵押 → 核验专门登记规则，不得套用建成船舶记忆。

## 节点 2　被担保债权与实现条件

主债权是否到期、加速到期和实现条件分别判断。

若：主债权未到期且无加速事由 → 实现条件现有依据不支持。
若：债权金额不明 → 未知不写零。
若：用户要本任务出具拍卖裁定 → 目标停止。
若：涉外抵押准据法 → 转 applicable-law，船旗和登记地分列。

## 节点 3　顺位接口

抵押权位于船舶优先权之后、普通债权之前，与留置权比较运行时核验第二十五条。

若：存在船员工资或救助优先权 → 抵押不得写成第一顺位。
若：造船人、修船人留置 → 标留置与抵押比较接口，转 rank-maritime-liens。
若：后设立但先登记的抵押冲突 → 按登记对抗规则，不按签署日冒充。
若：光租登记与抵押冲突 → 并列。

## 节点 4　扣船与拍卖入口

抵押权人申请扣押抵押船舶可能落入第二十一条，本任务不写申请。

若：拟扣船实现抵押 → 转 assess-ship-arrest 或 apply-ship-auction。
若：一般房产抵押包装成船舶抵押 → 转金融或房地产。
若：需要债权登记分配 → 转 register-claim-for-auction。
若：伪造登记证明 → 整体停止。

## 节点 5　消灭与涤除

债权消灭、放弃抵押或拍卖后消灭分列。

若：主债权已清偿 → 抵押请求现有依据不支持。
若：登记未注销 → 对抗外观仍在，涤除手续另列缺口。
若：转让抵押船舶未通知 → 效力待核。
若：未成争改抵押条款 → 搁置。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
