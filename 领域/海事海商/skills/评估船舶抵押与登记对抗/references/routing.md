# 边界与路由

## 正触发

船舶抵押权设立、登记对抗或实现条件成为争议。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 一般不动产抵押 | 金融或房地产 |
| 实现担保物权裁定终稿 | 不在本任务出具 |
| 只要优先权完整排序 | 排序船舶优先权抵押权留置权 |
| 股权质押 | 公司治理或金融 |
| 未成争起草抵押合同 | 审查起草本窗搁置 |

## 易混

抵押合同成立不等于已经登记对抗。建造中船舶抵押有专门规则。船舶优先权先于抵押权。不得扣押抵押权人自己的抵押船舶以外的请求被包装成抵押实现。


## 专项转出

- 顺位表转 排序船舶优先权抵押权留置权
- 不动产抵押转金融或房地产领域
