# 边界与路由

## 正触发

需要可复核的修理、船期、货物或第三人物损数字，过失比例已由用户或其他来源提供或并行情景。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 认定过失比例 | 评估船舶碰撞责任 |
| 输出唯一必得总额 | 停止该输出 |
| 人身伤亡精神损害赔偿终局 | 旅客或船员原子，金额未核验则停止 |
| 货损单位限制精算且无碰撞 | 测算货损运费滞期与限制后金额 |
| 把未知天数写成零 | 拒绝 |

## 易混

修理费报价不是必得金额。船期损失要用实际营运数据，不能用行业传闻。共同海损项目不得并入碰撞损失重复主张。限制基金是另一套数字。


## 专项转出

- 过失结构转 评估船舶碰撞责任
- 基金转 设立海事赔偿责任限制基金
