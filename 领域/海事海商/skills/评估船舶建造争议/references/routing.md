# 边界与路由

## 正触发

造船进度、质量、分期款或弃船成为争议。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 起草建造合同 | 审查起草本窗搁置 |
| 船厂施工劳务或工资 | 劳动 |
| 已建成船舶的二手买卖 | 评估船舶买卖争议 |
| 港口土建工程 | 建设工程 |
| 只要实现担保物权裁定 | 不在本任务终稿 |

## 易混

分期款未付不等于买方已取得所有权。弃船是合同权利，不是抛弃船舶优先权意义上的弃船。船厂留置权与抵押权顺位另核。SAJ 或 NEWBUILDCON 只作事实文本。
