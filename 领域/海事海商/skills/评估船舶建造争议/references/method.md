# 评估船舶建造争议方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：所有权归属、分期款、弃船或解除接口与担保

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　合同与阶段

确认在建船舶和合同版本。岸上车间加工不等于已经交船。

若：船舶已签署交船议定书并登记 → 此后争议更可能是买卖或质量保证，分流通知。
若：尚未安放龙骨且争议是意向金 → 仍按造船前期评估，标合同是否成立待核。
若：港口码头土建混在造船合同 → 工程部分转建设工程。
若：劳务工资是工人主请求 → 转劳动。

## 节点 2　所有权归属

建造中船舶所有权依约定；无约定则依据不足，不得写成当然归船厂或买方。

若：合同约定所有权归买方且已部分付款 → 对内归属接口打开，对抗第三人仍看登记或占有。
若：合同约定交船前归船厂 → 买方主张所有权现有依据不支持。
若：双方都主张所有权且无条款 → 依据不足。
若：需要登记对抗 → 转 ship-title 或 ship-mortgage。

## 节点 3　分期款、质量与弃船

各期款条件、迟延交船、质量缺陷和弃船权分列。

若：弃船条款条件未成就 → 不得写成已经合法弃船。
若：买方停付分期 → 卖方停工或解约接口打开，同时标买方反请求。
若：质量争议无检验 → 转 prepare-survey，本任务不预测鉴定。
若：退款保函条件与弃船通知不匹配 → 保函接口依据不足。

## 节点 4　担保

退款保函、履约保函、建造中船舶抵押分列。

若：保函文本准据法为外国法 → 执行力待核。
若：船厂主张留置在建船舶 → 与抵押权顺位转 rank-maritime-liens 接口。
若：用户要出具实现担保物权裁定 → 本任务不写裁定终稿。
若：检索引用已失效合同法 → 噪声。

## 节点 5　论坛与下一步

造船合同常有外国仲裁。未排除仲裁不得写起诉。

若：存在仲裁条款 → 转论坛或仲裁原子。
若：拟扣在建船舶或船用物料 → 转扣船或扣货原子并核验清单。
若：未成争改合同 → 搁置。
若：用户要求伪造进度证书 → 整体停止。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
