# 边界与路由

## 正触发

请求人主张责任人无权限制或基金设立程序违法。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 重做基金申请 | 设立海事赔偿责任限制基金 |
| 单位限制抗辩 | 评估单位责任限制 |
| 实体碰撞或货损总评估 | 对应评估原子 |
| 责任人侧设立基金 | 设立海事赔偿责任限制基金 |
| 逾期仍要终稿 | 停止终稿 |

## 易混

反对基金金额不等于已经证明丧失限制。程序违法与实体丧失限制是两条异议。公告期内未异议的失权风险须核验。油污除外是请求性质问题，不是轻率问题。


## 专项转出

- 基金申请转 设立海事赔偿责任限制基金
- 限制评估转 评估海事赔偿责任限制
