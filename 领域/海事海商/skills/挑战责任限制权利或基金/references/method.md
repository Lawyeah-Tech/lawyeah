# 挑战责任限制权利或基金方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：异议点、故意或明知轻率、程序期限

---

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　期限闸

异议期间自公告或收到通知起算，送达不明则字段停止。

若：材料支持异议期已过且只要终稿 → 负触发，停止终稿。
若：公告日与收到日冲突 → 并行情景。
若：尚未公告 → 可准备实体异议点，程序期限未起算。
若：授权不明 → 整体停止。

## 节点 2　请求性质除外

救助、共同海损、油污、打捞等除外请求应排除在基金外。

若：请求属于第二百零八条 → 主位异议：不得限制或不得纳入本基金。
若：请求性质不明 → 依据不足。
若：全部请求都可限制 → 除外异议不支持，转丧失限制或金额异议。
若：油污另有公约基金 → 标分流。

## 节点 3　丧失限制

故意或明知可能造成损失而轻率。

若：仅有事故后果严重 → 丧失限制依据不足。
若：开航前已知关键缺陷仍开航的证据存在 → 轻率接口打开。
若：证据来自违法取得的 VDR → 不得使用，转合法保全。
若：责任人本人与船员行为归属不明 → 字段依据不足。

## 节点 4　程序与金额

管辖、公告、担保不足、吨位错误分列。

若：吨位证书与申请不一致 → 金额异议打开。
若：担保不可执行 → 程序异议打开。
若：法院选择无连结点 → 管辖异议接口，可转 object-to-jurisdiction。
若：用户要重写对方的基金申请 → 目标停止。

## 节点 5　异议材料

保持待提交。不保证法院否定限制。

若：需要实体索赔起诉 → 转 file-first-instance，本任务只出异议。
若：需要债权登记 → 转 register-claim-for-auction。
若：伪造适航缺陷证据 → 整体停止。
若：只要评估限制权利而不异议 → 转 assess-limitation-of-liability。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
