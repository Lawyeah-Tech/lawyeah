# 边界与路由

## 正触发

交货当时或法定期限内需要发出损坏通知或索赔函。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 把逾期通知写成请求权已消灭 | 停止该写法 |
| 起诉状 | 提起海事一审 |
| 货损责任总评估终局 | 评估货损货差迟延索赔 |
| 无单放货通知 | 评估无单放货责任 |
| 未成争修改通知条款 | 审查起草本窗搁置 |

## 易混

未在交付当时通知只产生初步证据效果，不是索赔权消灭。表面损坏与非表面损坏期间不同。迟延损失通知与灭失损坏通知不混算。向货代发函不等于已向承运人通知。


## 专项转出

- 责任评估转 评估货损货差迟延索赔
- 检验申请转 准备海事检验鉴定申请
