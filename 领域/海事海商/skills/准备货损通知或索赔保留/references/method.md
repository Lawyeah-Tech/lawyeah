# 准备货损通知或索赔保留方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：发送前通知、表面与非表面损坏分流和到达设计

---

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　损坏类型与期间

表面损坏交付当时通知；非表面损坏自交付次日起连续七日；集装箱可能十五日，运行时核验。

若：损坏在卸货当场可见且未通知 → 标初步证据风险，仍可发保留函，不得写成权利消灭。
若：开箱后发现且仍在非表面期间内 → 通知闸打开。
若：期间是否届满日期冲突 → 字段停止，仍可发函但须标逾期争议。
若：沿海运输通知规则与第四章不同 → 分列待核，不套用记忆期间。

## 节点 2　接收人与渠道

通知应到达契约承运人或其代理人。只发给报关行不得写成已通知承运人。

若：承运人名称冲突 → 主送并列主体，抄送实际承运人。
若：仅有口头向理货声明 → 书面补发，口头不写成已经完成第八十一条。
若：联合检验已完成并签署 → 通知必要性下降，仍可发索赔保留。
若：用户要求倒签通知日期 → 整体停止。

## 节点 3　函件内容

载明船名航次、提单号、损坏概貌、保留索赔权利。不在通知里自认原因。

若：损坏范围尚未检验 → 写“损坏程度待检”，不得编造吨数。
若：用户要把“承运人全责”写入通知 → 删除定性结论，只保留事实与权利保留。
若：同时主张迟延 → 迟延通知期间另核第五十条、第八十二条。
若：需要鉴定 → 转 prepare-survey，本任务只保留检验安排接口。

## 节点 4　到达设计

记录发送方式、地址来源和拟制到达。未发出不得写成已通知。

若：邮箱或地址无法回链到承运人单证 → 到达设计依据不足。
若：准备公证送达或快递 → 列出凭证要求，不保证对方签收。
若：期间将尽 → 标优先发送，不因追求完美检验而压过期间。
若：对方已书面确认收到损坏情况 → 仍保留正式函件接口。

## 节点 5　与诉讼、评估的分界

本任务不写诉状，不认定责任。

若：用户只要责任结论 → 转货损评估。
若：用户要起诉 → 转起诉原子。
若：保险索赔材料 → 转 prepare-insurance-claim。
若：通知已逾期且用户只要“权利还在”的保证 → 拒绝保证，只说明初步证据效果。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
