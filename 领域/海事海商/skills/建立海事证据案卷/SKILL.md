# 建立海事证据案卷

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“海事证据案卷矩阵”：要件、举证责任、航海资料与单证、支持与不利、控制方、合法补证和最晚时点。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：海事已成争，单方需要单独盘点举证责任和补证，而不是只要策略总图或诉状。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要策略备忘或起诉状；
- 要求登轮窃取日志、VDR 或非法破解系统；
- 只要扣船申请终稿；
- 一般合同证据无海事专门材料；

本成果不是策略备忘，不是起诉状。不能推定对方控制的材料存在或有利。

## 建立评估坐标

确认：争点清单；已持有的提单、日志摘录、检验报告、照片、AIS；哪些材料在船长、船东、码头或海事局控制下。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` `D#` `A#` `R#` `C#` `L#` `I#` `G#` `Q#` `EV#` `V#` `E#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验证明责任、检验期间和海事证据保全条件；`search_practiced` 补航海资料举反证路径。工具不可用时继续材料登记；举证责任法律结论字段停止。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号、2000 货规时记为噪声，不得写入 `L#`。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 争点要件与举证责任

货损、适航、免责、通知、时效分列举证责任。不能把对方控制写成已证明。

### 2. 证据矩阵

每份材料标支持/不利、形成主体、时间、控制方、取得方式、合法性。日志事后补记标完整性冲突。

### 3. 航海资料与电子数据

航海日志、车钟、海图、VDR/SVDR、AIS、舱单、封铅照片分列。对方控制不得虚构内容。

### 4. 缺口与合法补证

联合检验、海事证据保全、调查令只写转介。不能合法取得则停止推定。

### 5. 禁止动作

拒绝偷拍机舱、收买船员隐匿记录、伪造海事声明。该部分不进入正表。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或航次无法建立；用户坚持伪造航海日志、倒签提单、逃船、威胁或违法登轮取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为其他原子的终稿。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
