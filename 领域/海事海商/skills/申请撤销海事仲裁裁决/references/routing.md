# 边界与路由

## 正触发

收到海事仲裁裁决后，不利方拟在法定期限内申请撤销。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 不予执行申请 | 申请不予执行海事仲裁裁决 |
| 对法院判决上诉 | 提起海事上诉 |
| 重审实体对错当作撤销事由 | 停止该写法 |
| 逾期终稿 | 停止终稿 |
| 国外裁决承认撤销路径未核验却套用国内撤销 | 待核分流 |

## 易混

撤销与不予执行是两条救济，法定事由和管辖法院不同。实体错误通常不是撤销事由。国内裁决与涉外裁决规则可能不同。


## 专项转出

- 不予执行转 申请不予执行海事仲裁裁决
- 上诉转 提起海事上诉
