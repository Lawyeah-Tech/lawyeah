# 设立海事赔偿责任限制基金方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：申请材料、金额利息、公告和对扣船的影响

---

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　申请资格与法院

责任人资格和有管辖权的海事法院必须先闭合。

若：限制权利评估尚未做且明显存在第二百零八条除外占主请求 → 先转评估，本任务标除外缺口。
若：事故相关诉讼已在某海事法院 → 通常向该法院申请，条号核验。
若：尚未起诉也未仲裁 → 按事故影响地等连结点列待选法院，不指定唯一。
若：申请人不是所有人或法定责任人 → 资格依据不足。

## 节点 2　金额与利息

人身基金与财产基金分列。利息标准和起算待核，不得把未核验的 LPR 写成唯一数字。

若：吨位未知 → 金额字段停止。
若：同时有人身和财产请求 → 两套基金或分项待核。
若：利息按何标准未核验 → 利息字段停止。
若：用户要求把油污请求金额算进第十一章基金 → 标除外，不得计入。

## 节点 3　担保形式

现金、银行担保或其他法院认可担保。境外保函执行力待核。

若：仅有 P&I 俱乐部信件无法院认可记录 → 是否足以设立基金依据不足。
若：担保金额低于法定基金加利息 → 不足。
若：需要评估保函 → 可转 letter-of-undertaking 补效力。
若：伪造存款证明 → 整体停止。

## 节点 4　公告、登记与扣船影响

公告和债权登记期间运行时核验。对已扣船舶的影响不得写成自动全球解除。

若：船舶已在本院扣押且基金已设 → 标申请解除扣押接口，是否准许不保证。
若：船舶在境外被扣 → 中国基金对境外扣押的效果依据不足。
若：已知请求人需通知 → 列入清单，遗漏风险标出。
若：需要债权登记指引 → 转 register-claim-for-auction 说明基金登记差异。

## 节点 5　申请书状态

材料保持待提交。不保证准许设立。

若：用户要把“不承认责任”漏写 → 补写基金不等于责任成立。
若：请求人已提出异议期限 → 转 challenge-limitation 交接。
若：只要实体限制权利意见 → 转评估原子。
若：指导转移船舶逃避已知请求人 → 整体停止。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
