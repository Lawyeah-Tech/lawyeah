# 边界与路由

## 正触发

已决定向海事法院申请设立海事赔偿责任限制基金。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 尚未判断有无限制权利 | 评估海事赔偿责任限制 |
| 把基金设立写成责任已成立 | 停止该写法 |
| 单位责任限制计算 | 评估单位责任限制 |
| 油污专项基金未经分流 | 评估船舶油污与污染责任 |
| 请求人异议包 | 挑战责任限制权利或基金 |

## 易混

基金设立不等于责任成立，也不等于限制权利已被确认。担保利息按 LPR 或其他标准必须待核。油污公约请求可能不能纳入该基金。设立后对扣船的影响按海诉法，不得记忆写成必然解除一切扣押。


## 专项转出

- 限制权利转 评估海事赔偿责任限制
- 异议转 挑战责任限制权利或基金
