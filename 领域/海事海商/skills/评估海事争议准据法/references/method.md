# 评估海事争议准据法方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：强制适用海商法或条约的范围、约定选法效力、待核外国法缺口

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　争议定性与强制适用

先定请求属于海上货物运输、船舶物权、碰撞、救助还是保险，再判断强制适用。

若：装港卸港均为中国港口的货物运输 → 第四章强制排除，不得约定适用第四章免责限额。
若：中国港口之间旅客运输限额特别规定被主张排除 → 运行时核验，核验失败则字段停止。
若：船舶优先权、抵押权争议 → 核验船旗国法接口，登记对抗另核中国登记规则。
若：定性是一般买卖货款 → 整案转涉外或合同争议。

## 节点 2　约定选法

书面选法须回链条款。口头“用英国法”不得写成已约定。

若：条款选择外国法且事项属于可约定范围 → 约定效力待核，外国法内容另列缺口。
若：条款仅选择仲裁地或管辖地 → 不得写成已选定实体法。
若：提单 hinterland 与租约选法冲突 → 并列，主位未选定。
若：约定排除中国强制规则 → 该排除现有依据不支持。

## 节点 3　碰撞、船旗与侵权行为地

碰撞准据法按同一船旗、不同船旗和侵权行为地分情景，不输出唯一外国法结论。

若：同一国籍船舶碰撞 → 核验船旗国法接口。
若：不同国籍且在公海碰撞 → 核验法院地法或海商法规定，条号运行时核验。
若：碰撞发生在一国领海或内水 → 核验侵权行为地法。
若：船旗或碰撞地不明 → 准据法字段依据不足。

## 节点 4　条约与外国法缺口

国际条约优先适用以中国缔结或参加且事项覆盖为前提。外国法内容未核验不得编造。

若：主张适用某油污或救助公约 → 核验对中国生效范围和案件是否落入。
若：外国法条文未被用户或检索提供 → 外国法内容字段停止。
若：条约与海商法冲突 → 只列冲突和待核位阶，不擅自选一条冒充已决。
若：需要论坛判断 → 转 评估海事管辖专属管辖与仲裁。

## 节点 5　输出边界

本任务只建准据法地图，不认定责任或金额。

若：用户只要实体货损结论 → 目标停止，转货损评估并交接准据法接口。
若：用户要把 Incoterms CIF 写成承运人责任依据 → 停止该写法。
若：纯海关、外汇或出口管制 → 转涉外。
若：选法条款需要改写且尚未成争 → 审查起草搁置。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
