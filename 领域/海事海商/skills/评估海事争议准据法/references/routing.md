# 边界与路由

## 正触发

提单 hinterland、租约选法、碰撞地或船旗导致准据法争议，需要判断强制适用与约定效力。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 把 Incoterms 写成准据法 | 停止该写法 |
| 纯跨境监管、制裁或出口管制 | 涉外 |
| 只要管辖或仲裁协议效力 | 评估海事管辖专属管辖与仲裁 |
| 未成争起草选法条款 | 审查起草本窗搁置 |
| CIF/FOB 货款主轴 | 涉外 |

## 易混

选仲裁地不等于选定实体法。船旗法不是碰撞的唯一连结点。hinterland 诉讼地条款不是准据法条款。Incoterms 只划分买卖双方费用风险。


## 专项转出

- 管辖仲裁转 评估海事管辖专属管辖与仲裁
- 油污公约范围转 评估船舶油污与污染责任
