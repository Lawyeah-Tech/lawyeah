# 边界与路由

## 正触发

船舶保险拒赔、解除或委付，被保险人或保险人需要承保与抗辩判断。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 一般财产险无船舶 | 保险或合同争议 |
| 货物保险理赔 | 评估海上货物保险理赔 |
| 无单放货当作船舶保险责任 | 通常不支持，转货险核验除外 |
| 保赔会籍争议主轴 | 未安装则 unavailable |
| 未成争审查保险条款 | 审查起草搁置 |

## 易混

保证条款违反可能使保险人解除，不等于当然拒赔一切。委付须构成推定全损且经接受。两年时效自保险事故发生。协会船舶条款只作事实文本。
