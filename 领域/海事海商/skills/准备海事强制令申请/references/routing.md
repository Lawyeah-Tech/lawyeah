# 边界与路由

## 正触发

需要立即放货、签发单证或为或不为一定行为，已决定申请海事强制令。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 保证裁定 | 停止保证 |
| 扣船或扣货 | 对应扣押原子 |
| 应对已被下达的强制令 | 未安装则 unavailable |
| 一般行为保全无海事特征 | 合同争议，须核验是否应走海诉法 |
| 未成争改单证条款 | 审查起草搁置 |

## 易混

海事强制令不是扣船。放货强制令不解决货款。错误申请须赔偿。与民事诉讼法行为保全的关系必须核验，不得只凭记忆互换。


## 专项转出

- 扣船转 准备扣押船舶申请
- 应对强制令未安装则 unavailable

本包未安装的入口一律输出 `unavailable`，不得由名称相近的 Skill 代做。相邻已完成领域和 C 端 109 只分流，不代做其实体结论。
