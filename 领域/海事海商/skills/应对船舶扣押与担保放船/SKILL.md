# 应对船舶扣押与担保放船

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的被请求人立场下，形成“应对扣船包”：裁定与送达登记、复议或异议、担保放船方案、不自认声明、放船后诉讼或仲裁衔接。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：船舶已被海事法院裁定扣押或即将执行扣押，被请求人需要复议、异议或提供担保以释放船舶。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 用户要主动申请扣对方船；
- 用户要求把船开走、关闭 AIS 或藏匿；
- 只要实体答辩、船舶尚未被扣；
- 把提供担保写成承认请求成立；
- 一般查封不动产应对（转合同争议）；

禁止指导逃船、关闭定位藏匿船舶或伪造放船文书。提供担保必须附加不自认声明。

## 建立评估坐标

确认：被请求人与授权；扣船裁定作出日、执行日、送达日；被扣船识别；请求人主张的海事请求；已要求的担保种类和金额；是否有 P&I 保函可出具。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验第十七条复议五日、利害关系人异议、担保放船和解释第二十五条。工具不可用时继续裁定登记；复议期限截止日字段停止。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号、2000 货规时记为噪声，不得写入 `L#`。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 裁定登记与材料权限

作出日、执行日、送达日分列。口头“已经扣了”不得起算复议期。原告材料不得直接当作被请求人已掌握的秘密。

### 2. 复议与异议分流

当事人对裁定不服：收到裁定书之日起五日申请复议一次，复议不停止执行。利害关系人异议理由成立则解除对其财产的保全。逾期标风险，不编造仍有效的截止日。

### 3. 担保放船

充分可靠担保可申请释放。担保形式、金额、出具人、准据法分列。P&I 保函是否被该海事法院接受标待核。提供担保不等于承认责任。

### 4. 请求清单与错误扣船接口

核验请求是否落入第二十一条、是否扣错船或姐妹船条件缺失。可能错误扣船时标索赔接口，不在本任务起诉。

### 5. 放船后程序

请求人三十日内须起诉或仲裁。被请求人准备应诉或仲裁答辩只作转介。禁止建议逃船。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或航次无法建立；用户坚持伪造航海日志、倒签提单、逃船、威胁或违法登轮取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为其他原子的终稿。
