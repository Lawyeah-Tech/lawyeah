# 提出海事管辖异议方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：管辖异议书、连结点证据和逾期风险，过期停止终稿

---

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　权限与期限闸

被告授权不明整体停止。送达日不明则期限字段停止，不得编唯一截止日。

若：作出日被当成送达日 → 纠正，期限不得起算。
若：材料支持异议期已过且用户只要终稿 → 负触发，停止终稿。
若：共同被告利益冲突未澄清 → 整体停止策略。
若：尚未送达起诉状 → 不得起算异议期，本任务只准备连结点。

## 节点 2　专门管辖与专属管辖

先判断是否应由海事法院管辖，再判断地域和专属。

若：纠纷无船舶、海上运输或通海水域特征 → 可主张不属海事法院专门管辖。
若：港口作业、船舶污染或海洋勘探开发落入海诉法第七条 → 协议管辖不得排除专属。
若：受诉法院缺乏任何连结点 → 地域异议主位打开。
若：连结点冲突 → 并列，不虚构“唯一正确法院”以外的必胜表述。

## 节点 3　协议管辖、扣船后管辖与仲裁红旗

书面管辖协议与扣船后管辖分列。出现仲裁条款时转仲裁异议，不在本任务终局。

若：存在有效仲裁协议 → 转 准备海事仲裁协议异议，本任务只标红旗。
若：已扣船且无管辖或仲裁协议 → 扣船法院可能取得管辖，异议须回应第十九条。
若：协议管辖违反专门或专属管辖 → 该协议不得作为受诉依据。
若：协议文本未回链 → 协议效力依据不足。

## 节点 4　异议书组织

按受诉法院、异议理由、连结点和请求事项组织。状态保持待提交。

若：期限字段仍停止 → 不得交付可提交终稿。
若：事实需要伪造船籍港或碰撞地 → 整体停止。
若：用户同时要实体答辩终稿 → 实体转应诉原子，本任务只出异议书。
若：只想换一个更有利的海事法院而无连结点 → 现有依据不支持。

## 节点 5　失权与并行

提示应诉失权和异议被驳回后的实体风险，不保证裁定。

若：已提交实体答辩未提管辖 → 标失权风险，是否仍可提运行时核验。
若：需要反诉评估 → 转 评估海事反诉或抵销。
若：需要应诉答辩 → 转 应对海事一审。
若：裁定已作出要上诉 → 转 提起海事上诉。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
