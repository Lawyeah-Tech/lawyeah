# 边界与路由

## 正触发

已被起诉，需要在法定期限内提出海事管辖异议。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 仲裁协议效力或仲裁异议 | 准备海事仲裁协议异议 |
| 异议期已过还要赶写终稿 | 停止终稿，只标逾期 |
| 尚未被诉，只要选论坛 | 评估海事管辖专属管辖与仲裁 |
| 一般合同管辖无海事连结点 | 合同争议 |
| 主动起诉包 | 提起海事一审 |

## 易混

仲裁协议异议不是管辖异议。专门管辖不等于本案受诉法院当然正确。扣船地不是唯一连结点。答辩期内未提异议的失权风险与实体抗辩分开。


## 专项转出

- 仲裁异议转 准备海事仲裁协议异议
- 论坛总评估转 评估海事管辖专属管辖与仲裁
