# 提起海事一审

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的原告立场下，形成可复核、不代提交的“海事一审起诉包”：起诉状草稿、分项诉讼请求、专门／专属管辖连结点、证据目录和扣船／保全红旗。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：海事已成争，用户已决定向海事法院提起一审，且无表面有效的仲裁协议阻挡，或阻挡已被可回链证据排除。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 一般合同一审（转合同争议）；
- 仲裁条款表面有效且未排除仍要求直接起诉；
- 已决定申请仲裁；
- 用户实为被告；
- 只要扣船申请终稿；
- CIF/FOB 货款主轴；

不代提交，不保证受理或胜诉，不把有效仲裁写成应起诉。

## 建立评估坐标

确认：原告适格；被告及共同被告；拟请求；管辖连结点；仲裁排除证据；是否已扣船及三十日是否临近。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` `D#` `A#` `R#` `C#` `L#` `I#` `G#` `Q#` `P#` `J#` `V#` `E#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验起诉条件、海诉法第六七条、第十九条、受案范围法释〔2016〕4 号。工具不可用时继续事实和目录；管辖选定和请求法律结论字段停止。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号、2000 货规时记为噪声，不得写入 `L#`。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 仲裁阻却与领域分流

表面有效仲裁未排除则负触发。一般合同或货款主轴转出。已有受理案号则停止生成起诉入口。

### 2. 主体与分项请求

货损、运费、确认无单放货责任、责任限制异议分列。禁止合成海事权益。

### 3. 管辖连结点

专门管辖、专属管辖、扣船地、船籍港、转运港、协议管辖分列。材料不足不选定唯一法院。

### 4. 证据目录与扣船红旗

证据绑定请求。已扣船标三十日内必须完成本起诉或改仲裁。不写扣船申请终稿。

### 5. 起诉状与提交核验

只交付草案和核验清单，不代提交，不保证受理。C 端 011 只分流。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或航次无法建立；用户坚持伪造航海日志、倒签提单、逃船、威胁或违法登轮取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为其他原子的终稿。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
