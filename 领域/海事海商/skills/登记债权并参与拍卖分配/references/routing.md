# 边界与路由

## 正触发

船舶拍卖或基金设立后，债权人需要登记债权并主张优先权。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 重审实体除非确权之诉 | 确权另案接口 |
| 申请拍卖本身 | 申请拍卖船舶 |
| 优先权抽象排序无登记程序 | 排序船舶优先权抵押权留置权 |
| 一般破产债权申报无船舶拍卖 | 破产领域 |
| 逾期登记仍要视同已登记终稿 | 停止该写法 |

## 易混

债权登记不是重新起诉。有异议可能要确权诉讼。优先权必须在登记中主张否则可能视为普通债权。基金登记与拍卖登记期间可能不同。


## 专项转出

- 申请拍卖转 申请拍卖船舶
- 顺位转 排序船舶优先权抵押权留置权
