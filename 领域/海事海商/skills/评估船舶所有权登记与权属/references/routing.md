# 边界与路由

## 正触发

登记船东与实际所有人不一致，或船舶共有、光租登记成为争议。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 代提交登记申请 | 不代办 |
| 公司股权确权 | 公司治理 |
| 船舶买卖价款违约总评估 | 评估船舶买卖争议 |
| 只要抵押顺位 | 评估船舶抵押与登记对抗 或 rank-maritime-liens |
| 未成争设计持股架构 | 审查起草或公司治理 |

## 易混

登记是对抗要件，不等于当事人内部出资约定无效。隐名持船不等于可以对抗扣船债权人。光租登记不是所有权登记。公司名下船舶的股东争议是股权问题。

- 买卖争议转 评估船舶买卖争议
