# 评估船舶所有权登记与权属方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：登记对抗、共有份额、光租登记和权属证据

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　登记外观

以登记簿记载建立对抗外观，冲突材料并列。

若：登记所有人与营运发票抬头不一致 → 并列，不自动合并。
若：登记尚未完成 → 对抗第三人依据不足。
若：用户要本任务代为向登记机关提交 → 不代办。
若：军用或公务船 → 本任务通常负触发。

## 节点 2　内部权属

出资、约定和实际控制只解决内部关系，不当然对抗第三人。

若：有书面共有协议但未登记共有 → 内部份额可评，对外对抗不足。
若：主张隐名所有且要排除抵押权人 → 现有依据通常不支持对抗。
若：标的其实是船东公司股权 → 转公司治理。
若：买卖未交船 → 转 ship-sale-dispute。

## 节点 3　光租与经营人

光租登记影响经营人和责任主体，不改变所有权登记本身。

若：光租已登记 → 光租人进入经营接口，所有权人仍为登记船东。
若：光租未登记 → 不得对抗第三人主张已转移经营。
若：期租被写成光租 → 纠正类型。
若：需要承运人识别 → 转 identify-carrier-and-parties。

## 节点 4　共有与处分

共有人处分船舶的同意要件运行时核验。

若：未经其他共有人同意设定抵押 → 抵押效力接口打开并转 mortgage 原子。
若：份额不明 → 份额字段依据不足。
若：共有人内部债权被写成船舶优先权 → 纠正。
若：需要拍卖变现 → 转拍卖或执行原子。

## 节点 5　证据与扣押现状

权属证据合法取得。已扣押或查封时处分受限。

若：船舶已被扣押 → 标处分限制，转应对扣船或执行原子。
若：证据来自违法登轮 → 整体停止。
若：需要保全登记外观证据 → 转 preserve-voyage-evidence 或证据保全。
若：行政诉讼撤销登记是主目标 → 转行政，本任务只留民事权属接口。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
