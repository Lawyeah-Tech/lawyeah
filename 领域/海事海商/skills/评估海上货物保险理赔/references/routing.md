# 边界与路由

## 正触发

货损后向保险人索赔或遭拒，需要条款、除外和检验判断。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 把 CIF 卖方义务写成保险责任已成立 | 停止该写法 |
| 船舶保险 | 评估船舶保险承保与拒赔 |
| 承运人货损责任总评估 | 评估货损货差迟延索赔 |
| 信用证单据不符 | 涉外 |
| 未成争审查保险条款 | 审查起草搁置 |

## 易混

CIF 只说明卖方应投保，不证明损失属于承保风险。一切险不是一切原因。无单放货常属除外或非承保。仓至仓期间须核验。
