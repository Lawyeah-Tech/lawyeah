# 评估海上货物保险理赔方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：条款承保、除外、检验和代位接口

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　保险利益与期间

索赔人须有保险利益。期间按仓至仓或条款约定。

若：损失发生时索赔人已无保险利益 → 请求依据不足。
若：CIF 卖方已转移风险和保险单 → 买方接口打开，卖方再索赔依据不足。
若：期间在仓库外延不明 → 期间字段依据不足。
若：无保单只有买卖合同约定卖方应投保 → 不得写成保险责任已成立。

## 节点 2　条款与风险

A/B/C 或国内一切险、水渍、平安险分列。

若：条款为 C 而损失是偷窃或淡水雨淋 → 承保通常不支持，除非扩展。
若：条款为 A 仍须核除外 → 不得写成必然赔。
若：原因不明 → 近因依据不足。
若：包装不足或固有缺陷 → 除外接口。

## 节点 3　无单放货与迟延

无单放货、交货延误商业损失通常除外或非承保。

若：损失是无单放货货款落空 → 标除外待核，转 delivery-without-bl 对承运人。
若：迟延本身无约定扩展 → 商业损失通常不赔。
若：共同海损分摊 → 按条款可有接口，转 GA。
若：用户把贸易违约写成保险事故 → 纠正。

## 节点 4　检验与索赔条件

及时通知和检验是理赔条件接口，不是诉讼时效本身。

若：未检验且货物已处理 → 损失证明依据不足。
若：需要检验申请 → 转 prepare-survey 或 prepare-insurance-claim。
若：时效两年自事故发生 → 单独一行。
若：保险人已赔 → 转 subrogation。

## 节点 5　代位与对承运人

未赔付不得写成已取得代位。

若：被保险人已单独与承运人签署免除 → 代位可能受损，标红旗。
若：需要向承运人索赔评估 → 转 cargo-claim。
若：金额未知 → 不写零。
若：伪造检验照片 → 整体停止。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
