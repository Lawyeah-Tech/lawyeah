# 应对海事一审

## 任务目标

在明确、无利益冲突的被告立场下，形成首次海事应诉答辩包：答辩期限卡、原告请求拆解、答辩草稿、管辖／仲裁／责任限制红旗、反诉评估接口和证据意见。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：海事案件被告已收到起诉状或应诉通知，需要答辩、请求拆解和抗辩红旗，而不是只要一份管辖异议终稿或大众答辩包。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 用户实为原告；
- 只要管辖异议终稿且无实体；
- 一般民事答辩无海事专门争点（可分流 C 端 012 或合同争议）；
- 劳动应诉；
- 已决定只谈和解、只要谈判方案；

不自动生成反诉状终稿，不保证免于缺席，不指导隐匿证据。

## 建立评估坐标

确认：每份文书作出日与送达日；原告请求；是否已扣船；仲裁条款；是否考虑责任限制或基金。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` `D#` `A#` `R#` `C#` `L#` `I#` `G#` `Q#` `K#` `H#` `V#` `E#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验答辩期间、管辖异议期间、应诉管辖、责任限制抗辩。工具不可用时继续文书登记和拆解；截止日和法律结论字段停止。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号、2000 货规时记为噪声，不得写入 `L#`。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 被告立场和材料权限

原告材料与己方内部文件分权。不得用原告未向被告披露的秘密撰写答辩。劳动应诉转出。

### 2. 答辩期限卡

作出日与送达日分列。普通程序以收到起诉状副本之日起算。送达不明则期限字段停止。

### 3. 请求拆解与红旗

承认、否认、不知、抗辩分列。仲裁条款、专属管辖、第四章排除、单位限制、基金分列红旗。未提管辖异议并应诉可能被视为接受受诉法院管辖，但不自动消灭仲裁争点。

### 4. 答辩草稿与反诉接口

反诉运费或滞期只评估条件，不自动生成反诉状终稿。责任限制不是反诉。

### 5. 证据与禁止

不利航海资料必须进入最强反方。拒绝隐匿日志或伪造海事声明。C 端 012 只分流。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或航次无法建立；用户坚持伪造航海日志、倒签提单、逃船、威胁或违法登轮取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为其他原子的终稿。
