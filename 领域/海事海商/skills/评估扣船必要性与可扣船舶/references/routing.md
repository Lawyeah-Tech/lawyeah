# 边界与路由

## 正触发

尚未决定申请，需要判断海事请求、当事船或姐妹船、担保和错误扣船风险。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 扣船申请书终稿 | 准备扣押船舶申请 |
| 一般财产保全 | 合同争议 |
| 船舶已被扣要放船 | 应对船舶扣押与担保放船 |
| 货款信用证请求包装成扣船 | 涉外，清单关闭 |
| 扣货或扣燃油 | 准备扣押船载货物或燃油申请 |

## 易混

有海事纠纷不等于可以扣船。姐妹船有所有权抵押等限制。错误扣船产生船期损失。三十日是扣后起诉或仲裁期，不是国内十五日。

- 申请书转 准备扣押船舶申请
- 放船转 应对船舶扣押与担保放船
