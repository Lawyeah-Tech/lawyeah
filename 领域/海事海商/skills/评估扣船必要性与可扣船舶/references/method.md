# 评估扣船必要性与可扣船舶方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：第二十一条请求清单对照、可扣船舶、担保和三十日期限红旗

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　清单闸

逐项对照第二十一条二十二项。非清单请求不得扣船，执行生效文书除外。

若：请求是货损、租约、碰撞、救助、船员报酬、抵押或买卖等清单类型且事实可回链 → 清单闸打开。
若：请求是国际贸易货款或一般借款 → 闸关闭，负触发。
若：定性不明 → 依据不足，不出“应当扣船”。
若：已有生效文书要执行 → 执行扣船另核，不与诉前扣船混用。

## 节点 2　可扣船舶

当事船优先。姐妹船须被请求人所有或光租，且请求类型允许。

若：当事船已确定且被请求人对其负责 → 当事船主位。
若：拟扣姐妹船而请求是所有权或抵押争议 → 通常不得扣其他船，条号核验。
若：军用或公务船 → 不得扣。
若：船名或 IMO 不能识别 → 可扣性依据不足。

## 节点 3　必要性与错误扣船

本任务不判断“应当扣船”，只列必要性因素和错误风险。

若：对方已提供充分担保 → 扣船必要性下降，错误风险上升。
若：请求金额远低于船价且可扣货 → 标比例风险。
若：主体可能扣错船东 → 最高风险红旗。
若：用户只要吓唬对方 → 标错误扣船赔偿。

## 节点 4　担保与三十日

申请人担保和扣后三十日必须提示。

若：无法提供法院可能要求的担保 → 申请可行性下降。
若：已决定申请 → 转 prepare-ship-arrest。
若：有仲裁协议 → 提示扣后仍应仲裁。
若：沿用十五日国内保全期 → 纠正。

## 节点 5　分流

一般保全、扣货、强制令分开。

若：目标是放货签单行为 → 转 injunction。
若：目标是船载货物或燃油 → 转 cargo-or-bunker-arrest。
若：已被扣 → 转 respond-to-ship-arrest。
若：指导逃船 → 整体停止。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
