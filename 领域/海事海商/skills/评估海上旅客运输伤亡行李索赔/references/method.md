# 评估海上旅客运输伤亡行李索赔方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：运送期间、限额、港口间旅客限额特别规定和时效

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　旅客运输关系

须有海上旅客运输合同或客票事实。无海船特征转人身损害。

若：事故发生在景区码头且无客票运输 → 转人身损害。
若：内河渡船是否适用海商法船舶定义不明 → 适用范围字段停止。
若：旅客与船员身份冲突 → 船员走船员原子或劳动，不并入本任务终局。
若：免费乘船或随船家属 → 合同关系依据不足，并列其他请求基础。

## 节点 2　运送期间

旅客及其自带行李、托运行李的运送期间分别判断。

若：伤亡发生在登离船舷梯且属运送期间 → 责任期间打开。
若：旅客在岸上宾馆自行活动受伤 → 运送期间现有依据不支持。
若：托运行李在港口仓库损坏 → 行李期间另核，不与旅客人身混算。
若：期间事实冲突 → 并行情景。

## 节点 3　责任与限额

过错或法定责任基础运行时核验。国内港口间旅客运输限额特别规定必须显式核验。

若：两港均为中国港口 → 展开特别限额接口，禁止用记忆国际限额数字。
若：国际旅客运输 → 核验第五章限额及条约是否适用。
若：承运人故意或明知轻率 → 丧失限制接口打开。
若：限额数字未经核验 → 金额字段停止，未知不写零。

## 节点 4　时效与保险

旅客运输时效单独一行，不套货损一年或人身损害三年冒充已决。

若：时效条文未核验 → 期限字段停止。
若：存在承运人责任保险或旅客意外险 → 只建接口，不认定保险赔付。
若：需要碰撞责任分摊 → 转碰撞原子，本任务只留旅客对承运人请求。
若：用户要定罪意见 → 停止该输出，刑民交叉只标红旗。

## 节点 5　下一步

鉴定、起诉、和解只转介。

若：伤残或死因不明 → 转检验鉴定原子。
若：拟扣船 → 核验第二十一条人身伤亡项。
若：陆上交通无海船 → 整案转人身损害。
若：只要刑事控告 → 转刑事领域。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
