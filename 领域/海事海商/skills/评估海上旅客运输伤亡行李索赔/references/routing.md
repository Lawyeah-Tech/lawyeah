# 边界与路由

## 正触发

客票旅客伤亡或行李灭失，旅客方或承运人需要运送期间、限额和时效判断。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 陆上景区或无海船特征的轮渡 | 人身损害 |
| 刑事责任认定 | 刑事领域 |
| 船员工资或船员工伤主轴 | 评估船员工资遣返或船上人身伤亡 或劳动 |
| 货损 | 评估货损货差迟延索赔 |
| 行政处罚复议 | 行政 |

## 易混

旅客不是船员。港口之间海上旅客运输可能有特别限额，不得直接套用国际航线记忆数字。运送期间外的码头摔伤不一定是海上旅客运输责任。行李与自带行李限额不同。


## 专项转出

- 船员伤亡转 评估船员工资遣返或船上人身伤亡
