# 边界与路由

## 正触发

已决定提出海事反诉或仲裁反请求，反诉原告需要状纸和证据。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 与本诉答辩混在一份终稿验收 | 答辩走应诉原子 |
| 尚未评估能否反诉 | 评估海事反诉或抵销 |
| 另案独立起诉冒充反诉 | 提起海事一审 |
| 一般合同反诉 | 合同争议 |
| 逾期仍要当作已受理的反诉终稿 | 停止终稿 |

## 易混

反诉状与答辩状分开验收。仲裁反请求格式按仲裁规则。反诉请求必须独立具体。牵连未闭合不应出终稿。
