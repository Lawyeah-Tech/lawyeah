# 边界与路由

## 正触发

已决定向保险人递交船舶或货物保险索赔材料。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 保证赔付 | 停止保证 |
| 代位求偿状 | 评估海上保险代位求偿 或起诉原子 |
| 承保争议总评估终局 | 对应 hull 或 cargo 保险评估 |
| 承运人索赔函 | 准备货损通知或索赔保留 |
| 未成争设计投保方案 | 审查起草搁置 |

## 易混

材料齐全不等于必然赔付。检验报告不是司法鉴定。向保险人索赔时限与向承运人通知期间、诉讼时效分列。


## 专项转出

- 承保评估转 hull 或 cargo 保险原子
- 代位转 评估海上保险代位求偿
