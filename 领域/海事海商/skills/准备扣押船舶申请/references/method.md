# 扣船申请方法

判断只用三态。发送闸未打开不得交付可提交终稿。不得沿用国内十五日扣船期。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号、2000 货规时记为噪声，不得写入 `L#`。

## 节点 0　分流

一般保全转合同争议。货款信用证不在第二十一条：整案转涉外，本任务负触发。已被扣押要放船：转 `respond-to-ship-arrest`。

## 节点 1　闭口清单闸

逐项核验海诉法第二十一条二十二项。  
若：请求是船舶营运造成的财产灭失损坏、运输协议、船载货物损坏、租用协议、船员劳动报酬、碰撞、救助、抵押、买卖等清单内类型，且事实可回链 → 清单闸打开。  
若：请求是国际贸易货款、股权转让款、一般借款 → 闸关闭，负触发。  
若：定性不明 → `依据不足`，不出终稿。  
第二十二条：非第二十一条请求不得扣船，执行生效法律文书除外。除外必须有生效文书，不得用“差不多生效”打开闸。

## 节点 2　船舶识别

记载船名、IMO、呼号、船籍港、现在停泊地。当事船优先。姐妹船：被请求人所有或光租的其他船舶，且请求不属于所有权、占有、抵押权等限制扣姐妹船的类型（第二十三条，运行时核验）。军用、政府公务船不得扣。20 总吨以下小型船艇是否属于海商法船舶另核。

不能立即查明被请求人名称：依第二十五条仍可申请，申请书以船舶识别替代人名，不得虚构船东。

## 节点 3　担保

核验海诉法第七十六条和法释〔2015〕6 号第五条。申请人担保应相当于扣押期间维持费用、船期损失和被请求人提供担保的费用。参数不足标待核，不得写成“法院不会要担保”。限额担保不足须追加，否则可能解除扣押。

## 节点 4　申请书

法定事项：请求人、海事请求、申请理由、船舶状况、担保。逐句回链。不倒签、不伪造船位。状态保持 `待提交`。48 小时裁定只作程序提示，不保证准许。

## 节点 5　三十日与论坛

核验第二十八条和解释第二十五条：扣押船舶超过三十日未起诉或未按仲裁协议申请仲裁，法院应及时解除保全或返还担保。双方和解或另约担保期限，须申请法院认可，口头延长无效。  
有仲裁协议：提示三十日内申请仲裁，禁止写“扣了就可以去海事法院实体起诉”。  
再扣：第二十四条，同一请求原则上不得再扣已被扣押过的船舶，例外须逐项核验。
