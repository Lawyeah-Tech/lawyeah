# 边界与路由

## 正触发

已决定申请扣船，请求可能落入第二十一条，需要申请包和三十日提示。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 尚未决定是否扣 | `评估扣船必要性与可扣船舶` 或 `unavailable`，专业版回 `assess-dispute` |
| 已被扣要放船 | `应对船舶扣押与担保放船` |
| 扣货或燃油 | `准备扣押船载货物或燃油申请` 或 `unavailable` |
| 一般保全 | 合同争议 |
| 货款信用证 | 涉外 |
| 起诉状 | `提起海事一审` |

## 易混

有货损不等于第二十一条已闭合。扣船不消灭仲裁协议。
