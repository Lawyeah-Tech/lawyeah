# 评估航次期租光租争议方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：租约类型识别、请求抗辩、NYPE 或 GENCON 只作事实文本、时效两年接口

---

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　租约类型

航次租船、定期租船、光船租赁必须先定性。名称与权利义务冲突时按权利义务。

若：出租人提供船员并负责航行，租金按时间计算 → 定期租船接口。
若：出租人仅提供空船，承租人配备船员 → 光船租赁接口，登记另核。
若：按航次提供整船或部分舱位、运费按货量 → 航次租船接口。
若：名为租船实为货物运输且有提单对外 → 对第三人责任另转货损或主体原子。

## 节点 2　请求与抗辩分列

租金、停租、撤船、交还船、燃油、速度索赔、停租期间工资分列，不得合成“租约权益”。

若：主张停租 → 须回链停租条款和离线事实，时间日志冲突并列。
若：主张撤船 → 核验违约性质、通知和宽限期，未通知不得写成已撤船。
若：交船船况或还船损坏 → 交还船检验分列，不与碰撞请求合并。
若：格式合同条款与海商法强制规定冲突 → 强制规定优先，格式只作事实文本。

## 节点 3　光租登记与对第三人

光租未登记不得对抗第三人的效果单独标出。

若：光租已登记 → 光租人进入经营和责任接口。
若：光租未登记却要对第三人主张已转移 → 对抗效力依据不足。
若：期租人签发提单 → 对货方可能进入承运人接口，不消灭租约内部请求。
若：需要船舶权属 → 转 评估船舶所有权登记与权属。

## 节点 4　时效与论坛

租船争议两年接口，不得用货损一年冒充。仲裁条款出现时不得直接写起诉。

若：航次租船请求 → 核验第二百五十七条第二款两年。
若：船舶租用合同请求 → 核验第二百五十九条两年。
若：租约含伦敦或 CMAC 仲裁 → 转论坛原子或仲裁程序原子。
若：滞期是唯一数字争议 → 转滞期原子，本任务只留定性。

## 节点 5　边界

不起草租约。一般租赁转出。

若：尚未成争只要改条款 → 审查起草搁置。
若：标的是岸上设备租赁 → 转合同争议。
若：拟扣船 → 转扣船原子并核验第二十一条租用协议项。
若：拟和解 → 转谈判或起草和解原子。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
