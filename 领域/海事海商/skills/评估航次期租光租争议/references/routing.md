# 边界与路由

## 正触发

租约下停租、撤船、交还船、燃油或租金争议已形成，需要类型识别和请求抗辩。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 起草或审查租约 | 审查起草本窗搁置 |
| 滞期精算 | 评估滞期速遣与滞留费 |
| 一般设备或房屋租赁 | 合同争议 |
| 只要货损对第三人责任 | 评估货损货差迟延索赔 |
| CIF 货款 | 涉外 |

## 易混

航次租船不是定期租船。停租不是当然解除。NYPE、GENCON 英文格式不是中国法条文。撤船条件未成就不得写成已经合法撤船。


## 专项转出

- 滞期转 评估滞期速遣与滞留费
- 论坛转 评估海事管辖专属管辖与仲裁
