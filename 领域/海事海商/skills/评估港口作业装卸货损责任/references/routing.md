# 边界与路由

## 正触发

港内装卸、仓储、理货导致货损或船损，需要作业合同与承运人责任分界。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 港口建设工程价款或工期 | 建设工程 |
| 港外陆运 | 合同争议 |
| 承运人责任期间内的海运货损 | 评估货损货差迟延索赔 |
| 海关处罚 | 行政 |
| 未成争起草港口作业合同 | 审查起草本窗搁置 |

## 易混

港口作业纠纷专属港口所在地海事法院，不等于承运人当然免责。装卸公司不是当然的实际承运人。理货签证不是司法鉴定。港外拖车不属于本任务。


## 专项转出

- 海运货损转 评估货损货差迟延索赔
- 港口工程转建设工程领域
