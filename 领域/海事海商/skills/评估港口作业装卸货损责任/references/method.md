# 评估港口作业装卸货损责任方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：港口作业专属管辖、作业合同与承运人责任分界

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　作业与区段

损害必须发生在港口作业、仓储或理货环节。

若：损害发生在海上航程且卸船前已存在 → 转货损评估。
若：港外公路运输损坏 → 转合同争议。
若：码头土建质量或工程款 → 转建设工程。
若：作业区与海运责任期间重叠 → 两套请求分列，不互相吞并。

## 节点 2　合同相对人

货方委托作业与船方委托作业责任通道不同。

若：承运人责任期间覆盖装卸且承运人转包港作 → 货方可对承运人主位，港作内部追偿另账。
若：货方直接与港作订立作业合同 → 港作相对人打开。
若：理货单位仅出签证 → 不当然承担货损赔偿责任。
若：作业主体名称与实际装卸人冲突 → 并列。

## 节点 3　过错与证据

残损是否作业导致须回链交接记录，不能因“在港口发现”推定港作过错。

若：装船前已有原残批注 → 作业致损依据不足。
若：作业中碰撞船舶或集装箱坠落有当场记录 → 作业过错接口打开。
若：只有交货时发现、无区段证据 → 依据不足。
若：需要鉴定 → 转 prepare-survey。

## 节点 4　管辖

港口作业纠纷专属港口所在地海事法院。协议管辖不得排除专属。

若：用户要在外地普通法院起诉港口作业 → 标专属管辖障碍。
若：同时告承运人运输合同 → 管辖分列，运输合同不一定专属该港。
若：仲裁条款覆盖作业合同 → 转论坛或仲裁异议原子。
若：只要管辖异议书 → 转 object-to-jurisdiction。

## 节点 5　限额与下一步

不得把海商法第四章单位限制当然适用于港口作业人。

若：港作主张适用承运人限额 → 现有依据通常不支持，除非另有可核验依据。
若：拟扣船 → 核验请求是否落入第二十一条。
若：工程款包装成作业费 → 转建设工程。
若：用户要求伪造理货单 → 整体停止。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
