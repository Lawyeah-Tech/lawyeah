# 评估货损货差迟延索赔

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“货损货差迟延评估”：第四章是否适用、责任期间、损坏通知效果、适航与免责接口、单位限制接口、一年时效和主体。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：已发生货物灭失、损坏、短少、货物受污或迟延，货方或承运人需要判断请求或抗辩是否立得住，而不是只要扣船申请或精算终稿。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主轴是船舶燃油、货油泄漏或海域污染（转 `assess-pollution`，本包未安装则 `unavailable`）；
- 主轴是无单放货（转 `assess-delivery-without-bl`，本包未安装则 `unavailable`）；
- 只要扣船申请或起诉状；
- 只要唯一限额数字；
- CIF/FOB 货款或信用证主轴；
- 纯公路铁路航空、海运区段不能识别；
- 未成争改提单条款（审查起草搁置）；

本任务不生成扣船申请、诉状或唯一限额，不给胜诉率。

## 建立评估坐标

确认：单方立场；提单/运单；船名航次；装港卸港；集装箱与否；交付或应当交付日；损坏发现日；是否已发通知；货值与件数。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` `D#` `A#` `R#` `C#` `L#` `I#` `G#` `Q#` `V#` `E#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验第二条、第四十六条、第五十一条、第五十六条、第八十一条、第二百五十七条。工具不可用时继续事实；免责、限额、时效字段停止。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号、2000 货规时记为噪声，不得写入 `L#`。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 第四章适用范围

装港卸港均为中国港口时不得适用第四章免责和单位限制。港到港不明则适用范围字段停止。

### 2. 责任期间与掌管

集装箱自接收至交付；非集装箱自装上船至卸下船。期间外堆存另账。

### 3. 损坏通知与迟延定义

未通知只是初步证据，不是请求权消灭。迟延须有明确约定交付时间。六十日未交付可认为灭失，须核验第五十条。

### 4. 适航、免责与单位限制接口

第 47 条开航前谨慎处理适航；第 51 条免责分项举证；第 56 条只建接口不输出必得限额。故意或明知可能造成损失而轻率不得限制。

### 5. 主体、时效和下一步

承运人与实际承运人可并列。时效一年自交付或应当交付。扣船、精算、起诉只转介。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或航次无法建立；用户坚持伪造航海日志、倒签提单、逃船、威胁或违法登轮取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为其他原子的终稿。
