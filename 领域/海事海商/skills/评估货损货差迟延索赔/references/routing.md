# 边界与路由

## 正触发

货损、货差、货物受污或迟延已成争，需要责任期间、通知、免责和时效判断。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 无单放货 | `评估无单放货责任` 或 `unavailable` |
| 船舶燃油、货油泄漏或海域污染主轴 | `评估船舶油污与污染责任` 或 `unavailable` |
| 扣船申请 | `准备扣押船舶申请` |
| 精算 | `测算货损运费滞期与限制后金额` |
| 总图 | `评估海事海商争议` |
| 货款信用证 | 涉外 |
| 沿海运输硬套第四章限额 | 停止该字段，不转出本任务 |

## 易混

有残损不等于承运人不能免责。未通知不等于已过时效。
