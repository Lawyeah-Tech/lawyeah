# 边界与路由

## 正触发

已宣布共同海损或收到分摊账单，需要成立要件和可分摊项目。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 代替理算书 | 不代替理算 |
| 单独海损并入共同海损 | 停止并入 |
| 只要出具担保 | 准备共同海损担保与分摊抗辩 |
| 救助报酬成立本身 | 评估海难救助报酬 |
| 未成争选择理算规则条款 | 审查起草搁置 |

## 易混

宣布共同海损不等于已经成立。单独海损由单方承担。时效自理算结束起一年，不是自事故日。约克-安特卫普规则只在约定或可核验时适用。


## 专项转出

- 担保转 准备共同海损担保与分摊抗辩
- 救助转 评估海难救助报酬
