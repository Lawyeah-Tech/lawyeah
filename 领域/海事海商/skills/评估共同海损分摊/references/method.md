# 评估共同海损分摊方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：共同海损成立、理算规则、可分摊项目和自理算结束起算的时效

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　成立四要素

共同危险、有意合理措施、共同安全或利益、特殊牺牲或费用。

若：危险仅影响单票货物 → 共同海损成立不支持。
若：措施是正常营运费用 → 不得列入。
若：船舶本身不适航导致危险且承运人不可免责 → 分摊抗辩接口打开。
若：要素事实冲突 → 成立字段依据不足。

## 节点 2　项目识别

牺牲、救助报酬、避难港费用等可分摊项目与单独海损分列。

若：货物自然特性损坏 → 单独海损，不得并入。
若：救助报酬为共同安全 → 可进入分摊接口。
若：修理中的以新换旧或其他扣减 → 只标理算接口，不代替理算书。
若：用户要求把商业迟延利润写入共同海损 → 通常不支持，待核。

## 节点 3　理算规则

合同约定的理算规则是事实文本。未约定则按海商法第十章。

若：约定约克-安特卫普某年规则 → 作为事实，条文内容未提供则细节停止。
若：理算尚未结束 → 时效未起算，本任务可评成立与项目。
若：理算书已出且用户要推翻数字 → 列抗辩点，不重做理算。
若：理算人选择有争议 → 并列。

## 节点 4　分摊方与时效

船方、货方、运费方分摊。时效自理算结束之日起一年。

若：用户自事故日起算一年 → 纠正。
若：理算结束日不明 → 时效字段停止。
若：货方未提供分摊担保 → 转 prepare-ga-security 标留置风险。
若：保险人已出具分摊保证 → 交接保险原子。

## 节点 5　与责任、保险的边界

共同海损成立不消灭货损请求，也不等于保险已赔。

若：货方同时主张货损 → 分列，避免重复受偿。
若：需要保险分摊 → 转 cargo-insurance 或 hull-insurance。
若：需要出具担保 → 转 prepare-ga-security。
若：伪造牺牲事实 → 整体停止。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
