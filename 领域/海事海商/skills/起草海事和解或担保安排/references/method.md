# 起草海事和解或担保安排方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：和解或担保草稿、弃权边界和放船条件

---

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　条件闭合闸

未谈拢的关键点不得在草稿中擅自填写。

若：金额、弃权或放船任一未谈拢 → 退回谈判原子，或只出待填结构但关键数字留空并标明未谈拢，不得编造。
若：用户说“按惯例写弃权一切” → 限缩为已披露请求，未知人身或第三人请求不擅自放弃。
若：尚未成争只要改租约 → 审查起草搁置。
若：只要谈判策略 → 转 negotiate-settlement。

## 节点 2　当事人与授权

船东、租家、保险人、俱乐部必须对号。越权签署无效风险。

若：P&I 代签但无授权 → 效力依据不足。
若：共有船舶一方签署处分 → 标共有同意缺口。
若：保险人未加入却要约束代位 → 代位处理必须单列。
若：对方主体与扣船被请求人不一致 → 放船条款可能落空。

## 节点 3　弃权、担保与放船

弃权边界、付款安排、担保替换和放船步骤分列。

若：存在扣船 → 放船以担保或付款为条件，步骤写清申请解除。
若：放弃船舶优先权未经明示 → 不得解释为已放弃。
若：检索回到已失效合同法 → 噪声，改核民法典。
若：需要执行力 → 转 confirm-settlement-enforceability，本任务正文提示无执行力。

## 节点 4　文本

可签草稿，状态待签署。不保证对方接受最终用印稿。

若：英文与中文文本冲突未约定作准语言 → 补作准条款。
若：含违法逃税或逃避强制打捞 → 删除并停止该部分。
若：保密条款不得妨碍向法院或保险人披露 → 写入例外。
若：用户要求倒签和解日期影响时效 → 整体停止。

## 节点 5　与确认、执行的交接

单独和解无执行力必须明示。

若：用户需要司法确认 → 转确认原子。
若：只需谈判表 → 本任务负触发。
若：执行阶段和解 → 交接 enforce 原子。
若：一般民事和解模板无扣船放船 → 可借鉴栏目但必须改写海事条件。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
