# 边界与路由

## 正触发

收到 P&I 保函、银行保函或法院担保，需要判断能否放船。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 把保函写成请求已成立 | 停止该写法 |
| 境外保函执行力当作已决 | 待核 |
| 共同海损分摊担保 | 准备共同海损担保与分摊抗辩 |
| 主动扣船申请 | 准备扣押船舶申请 |
| 未成争起草保函格式 | 审查起草搁置 |

## 易混

提供担保不是自认责任。P&I 俱乐部信件与银行保函执行力不同。法院认可的担保与私下保函不同。金额不足应追加，不是必然拒绝放船或必然接受。


## 专项转出

- 放船程序转 应对船舶扣押与担保放船
- 共同海损担保转 准备共同海损担保与分摊抗辩
