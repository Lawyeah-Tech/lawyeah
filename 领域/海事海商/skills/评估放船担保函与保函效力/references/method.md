# 评估放船担保函与保函效力方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：担保主体、金额、准据法、可执行性和替换条件

---

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　担保与请求隔离

先写明担保不构成责任承认。

若：对方要求在保函中承认责任 → 拒绝该条款。
若：己方提供担保仅为放船 → 在文本保留责任抗辩。
若：无扣船或无请求金额 → 评估依据不足。
若：共同海损担保被误送本任务 → 转 prepare-ga-security。

## 节点 2　主体与执行力

银行、保险公司、P&I、母公司分列。境外出具人在中国的执行力待核。

若：中国银行见索即付保函且法院可接受 → 执行力接口打开。
若：外国 P&I LOU 且无中国资产或互保安排 → 执行力依据不足。
若：出具人签名权限不明 → 依据不足。
若：已被法院裁定认可的担保 → 放船程序接口打开，实体仍未决。

## 节点 3　金额、范围与准据法

金额应覆盖请求、利息、费用的合理范围，未知不写零。

若：保函金额明显低于已主张请求且无减请求安排 → 不足。
若：准据法为外国法、管辖在外国 → 标中国扣船法院控制力风险。
若：范围排除油污或人身 → 与本案请求对照。
若：有效期短于可能的诉讼周期 → 续期风险。

## 节点 4　替换与放船

可否用保函替换现金或解除扣押，由法院裁定，本任务不保证。

若：被请求人要求立即放船而法院未裁定 → 不得写成已经可开航。
若：请求人无合理理由拒绝充分担保 → 标异议风险。
若：需要应对扣船程序 → 转 respond-to-ship-arrest。
若：需要和解一揽子担保 → 转 draft-settlement。

## 节点 5　下一步

不把接受保函写成实体和解。

若：文本需要可签和解 → 转 draft-settlement。
若：执行阶段的担保 → 转 enforce 或 resist-enforcement。
若：伪造保函 → 整体停止。
若：一般信用证保函无扣船 → 转涉外或金融。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
