# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然扣船、必然受理或唯一必得总额。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜关系假设｜提出方｜相对方｜法律效果｜成立条件｜支持事实｜不利事实｜控制方｜最强反方｜主备位｜判断｜待核`。

货损、运费、滞期、无单放货、碰撞、优先权、保险、责任限制分列。同一事实支持多项时分别说明效果，不重复金额。有货损不等于当然可扣船。

## 节点 0　领域分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填总体评估十节实体结论。

| 信号 | 转出 |
| --- | --- |
| CIF/FOB 货款、信用证拒付、出口管制、制裁、CISG 买卖主轴 | 涉外与国际贸易 |
| 一般买卖、服务、承揽、租赁动产，无海商法或海事程序专门规则 | 合同争议解决 |
| 尚未成争，只要改租约、提单、造船或保险条款 | 审查起草领域（本窗搁置，只说明不实施） |
| 劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 | 劳动领域 |
| 陆上交通事故、场所侵权，无海船或海上运输特征 | 人身损害 |
| 港口码头施工价款、工期、质量、实际施工人 | 建设工程 |
| 岸上排污许可、环评、海事行政处罚复议诉讼 | 环境能源或行政 |

混合信号：货损或扣船是主轴、贸易条款只是背景时留本任务，贸易段只分流。货物曾经上船但主请求是货款时整案转出。

## 节点 1　主体、航次、单证和程序状态

1. 固定提单、海运单、电放、租约、订舱、保险单的版本层级。冲突并列，不选对用户有利的一版冒充唯一文本。
2. 主体表记录登记船东、光船承租人、期租/程租人、契约承运人、实际承运人、签单货代、托运人、收货人、提单持有人、保险人。名称不一致不自动合并。货代以自己名义签单时标承运人责任接口，不在本任务终局。
3. 航次表：船名、IMO/呼号、航次、装港、卸港、接货地、交货地、开航日、交付或应当交付日。装港与卸港均为中华人民共和国港口时，记下“第四章排除红旗”。
4. 程序表逐动作记录协商、货损通知、扣船、担保、仲裁、诉讼或执行：机关/机构、案号、文书、作出日、收到日、送达方式和效力凭证。口头转述、截图、“已读”不得写成已受理、已送达、已扣押或期限已起算。
5. 同时掌握双方秘密或立场不明：整体停止策略输出。

若：用户只要扣船申请 → 目标停止，转 `prepare-ship-arrest`。  
若：用户只要货损专项终局且材料已足够 → 可转 `assess-cargo-claim`，本任务只留最小交接。

## 节点 2　请求与抗辩假设

每个 `Q#` 先写法律效果，再写成立条件。禁止合成“海事权益”一笔。

默认主位候选按事实分别建立：

- `Q-货` 货物灭失、损坏
- `Q-迟` 迟延交付（须有明确约定时间，海商法第五十条）
- `Q-运` 运费、亏舱费
- `Q-滞` 滞期或滞留
- `Q-放` 无单放货（接口，不替代专项）
- `Q-碰` 碰撞或浪损
- `Q-优` 船舶优先权
- `Q-限` 单位责任限制或海事赔偿责任限制（抗辩接口）
- `Q-仲` 仲裁或管辖异议
- `Q-扣` 扣船必要性（红旗，不写申请）

单位或承运人立场：逐项回应对方已知主张，并列己方最强抗辩，不把反诉写成已经提起。

主备位和互斥必须可见。`Q-货` 成立不等于 `Q-扣` 成立。单位限制与基金限制不得合并成一个数字。

## 节点 3　沿海排除、责任期间和通知

本节点只判断路径，不生成发送版通知或扣船申请。

### 3.1 第四章适用范围

运行时核验海商法第二条后再落判断。核验失败则货损免责和单位限制字段停止，事实与问题清单继续。

若：装港和卸港均为中国港口，且请求依据是海上货物运输合同 → 不得适用第四章关于承运人免责和单位限制的规定；改标沿海/民法典运输合同待核，并引用法释〔2001〕18 号一年时效接口。  
若：国际航线或海江直达且第四章适用条件获支持 → 才展开第 46、51、56 条接口。  
若：港到港不明 → 适用范围 `依据不足`，禁止输出限额数字。

### 3.2 责任期间

集装箱：装货港接收至卸货港交付，货物处于承运人掌管之下。非集装箱：装上船至卸下船。责任期间外的港区堆存另账，不把整段物流写成承运人当然掌管。

### 3.3 损坏通知

表面损坏：交付当时通知。非表面损坏：交付次日起连续七日（集装箱可能十五日）待核。未通知不得写成索赔权消灭，只标初步证据效果。迟延造成经济损失的通知期间另核，不与灭失损坏通知混算。

## 节点 4　论坛、扣船红旗与分类型时效

分别判断：协商、通知、扣船、仲裁、海事诉讼、基金、执行。本任务不写立案包或扣船申请。

### 4.1 仲裁协议优先闸

提单 hinterland、租约仲裁条款或事后书面协议中出现仲裁条款时：

1. 不得直接写“应向海事法院起诉”。
2. 分列：是否书面；是否有请求仲裁的意思；事项是否覆盖；机构是否选定或存在；是否或裁或诉。
3. 或裁或诉、机构不明：效力标 `依据不足`，转介 `assess-forum-and-arbitration`。
4. 扣船申请本身不消灭仲裁协议。海诉法第十九条：有诉讼管辖协议或仲裁协议的，扣船后仍受该协议约束。

### 4.2 专门管辖与专属管辖

海事侵权、海商合同由海事法院专门管辖（海诉法解释第一条）。港口作业、船舶污染、海洋勘探开发合同另核专属管辖（海诉法第七条）。连结点只列待核，不选定唯一海事法院。

### 4.3 扣船红旗

仅当请求可能落入海诉法第二十一条闭口清单、存在可识别船舶、有错误扣船风险或船期紧迫时标红旗。本任务不判断“应当扣船”，不写申请书。非第二十一条请求（包括一般货款）禁止标为可扣船。

### 4.4 时效分类型

| 类型 | 规则锚点 | 本任务允许的输出 | 禁止 |
| --- | --- | --- | --- |
| 货损向承运人索赔 | 第 257 条一年，自交付或应当交付 | 起算事件、备选起算、中断候选 | 用三年普通时效；唯一截止日 |
| 沿海内河货损 | 法释〔2001〕18 号一年 | 与国际航线分列 | 套用第四章限额 |
| 航次租船 | 第 257 条第二款两年 | 自知道或应当知道权利被侵害 | 与货损一年混算 |
| 船舶租用 | 第 259 条两年 | 同上 | 用货损一年 |
| 碰撞 | 第 261 条两年 | 自碰撞之日起 | 与货损混算 |
| 共同海损 | 第 263 条一年 | 自理算结束 | 自事故日冒充 |
| 海上保险 | 第 264 条两年 | 自保险事故发生 | 自索赔函日冒充 |
| 扣船后起诉/仲裁 | 海诉法第 28 条、解释第 25 条三十日 | 已扣船时标红旗 | 国内十五日（失效） |

日期冲突、交付日不明：并行情景 + 字段停止。

## 节点 5　金额区间与两套限制

本任务只建区间和接口，不替代 `calculate-cargo-limitation`。

1. 分项：CIF/发票货值、修理、贬值、运费、滞期、船期、共同海损分摊。未知不写零，不输出唯一必得总额。Incoterms 只说明价金构成，不写成承运人责任依据。
2. 单位责任限制（第 56 条）与海事赔偿责任限制基金（第十一章）分列。第四章不适用时单位限制字段停止。
3. 第 56 条参数不足时只列件数/公斤/SDR/申报价值未知项，不编 666.67 SDR 结论。
4. 基金请求是否属于第 207 条、是否落入第 208 条除外，只标接口。
5. 无单放货赔偿范围转专项，不在总图输出必得货值。

参数不足：只列已知参数、未知参数和专项测算接口。

程序动作记录机关、案号、文书、作出、收到、送达、效力。期限每行只对应一种期间类型和一个起算事件。

## 证据与下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定航海日志或 VDR 内容有利。

下一步按期限灭失、易失证据、改变请求抗辩、可逆性排序。扣船申请、起诉、应诉、精算、完整证据卷只写转介条件和最小交接。禁止指导伪造日志、倒签提单、逃船或违法登轮。
