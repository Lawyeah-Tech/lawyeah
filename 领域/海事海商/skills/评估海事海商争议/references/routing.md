# 边界与路由

## 正触发

海事海商已成争，单方需要总体决定请求、抗辩、论坛、证据优先级和下一步。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争，改租约、提单或造船合同 | 审查起草领域（本窗搁置，只说明） |
| CIF/FOB 货款、信用证、出口管制 | 涉外与国际贸易 |
| 一般买卖服务已成争 | 合同争议解决 |
| 评估管辖或仲裁条款本身 | `评估海事管辖专属管辖与仲裁` |
| 只判断货损请求或抗辩 | `评估货损货差迟延索赔` |
| 申请扣船 | `准备扣押船舶申请` |
| 应对扣船 | `应对船舶扣押与担保放船` |
| 精算货损或限制后金额 | `测算货损运费滞期与限制后金额` |
| 完整证据卷 | `建立海事证据案卷` |
| 和解条件 | `谈判海事和解方案` |
| 起诉 | `提起海事一审` |
| 应诉 | `应对海事一审` |
| 劳动主轴 / 陆上侵权 / 工程 | 对应领域 |
| C 端运输货损／011／012 | 大众专项，只分流不回改 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 货款、信用证、管制制裁 | 涉外与国际贸易 |
| 无海运专门规则的一般合同 | 合同争议解决 |
| 劳动合同解除补偿社保 | 劳动领域 |
| 陆上人身侵权 | 人身损害 |
| 港口施工价款工期质量 | 建设工程 |

海运只作背景时，专项段只分流，不把海商法写入一般贸易结论。

## 易混

请求尚未闭合、需比较是否扣船或先发货损通知时正触发。主体、请求、论坛均确认且只要扣船申请或诉状时负触发。有仲裁条款仍要求“直接起诉”时，先完成论坛闸，不改写成立案原子。
