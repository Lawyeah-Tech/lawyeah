# 评估海事海商争议

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“海事海商争议总体评估矩阵”：主体和航次单证状态、事实时间线、逐项请求／抗辩、海事专门／专属管辖与仲裁闸、分类型时效待核、金额区间与非金钱后果、证据缺口、对方最强解释和下一步。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：海上货物或旅客运输、船舶租用建造买卖抵押、碰撞污染救助共同海损、海上保险或海事保全已形成争议，用户仍需决定请求、抗辩、路线或下一步。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未成争，只要改租约、提单或造船合同（审查起草领域，本生产线搁置，只说明不实施）；
- 主轴是 CIF/FOB 货款、信用证、出口管制或一般买卖服务（转涉外或合同争议）；
- 只要发送版扣船申请、货损通知或担保函；
- 只要精算工作表或完整证据卷；
- 已决定起诉／仲裁申请／答辩／扣船／放船并只要相应文书；
- 船员劳动合同解除、经济补偿、社保公积金主轴（转劳动）；
- 陆上人身侵权无海船特征（转人身损害）。

本任务不生成扣船申请、可提交诉状或答辩、强制令或执行申请，不给胜诉率。

## 建立评估坐标

确认：使用者与授权；单方立场；相对方及可能责任主体（登记船东、光租人、承运人、实际承运人、货代、保险人）；航次、船名、IMO、提单/租约版本；争议事项；装港卸港是否均为中国港口；法域；当前协商、扣船、仲裁、诉讼或执行状态；机关文书作出与送达；对方已知主张；关键材料及缺失。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同或单证条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`V#` 评估版本；`E#` 发送／送达／履行凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验海商法适用范围、时效、专属管辖、扣船清单、责任期间；`search_practiced` 补路径与反例；特殊事实用 `search_case_by_fact`，明确筛选用 `search_case_by_filter`。不虚构案件系统。

工具不可用时继续事实、主体、程序文书状态和问题清单；请求／抗辩的法律结论及期限字段停止。

`search_law` 返回已失效《合同法》、1994 诉前扣船规定或 2000 货规时记为噪声，不得写入 `L#`。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 领域分流、主体、航次和单证

先做国际贸易／一般合同／劳动／工程分流，再固定船名、航次、提单或租约版本、签单主体。装港卸港均为中国港口时，货损请求不得直接套用第四章免责和单位限制。

### 2. 请求与抗辩假设

每个 `Q#` 独立列法律效果、成立条件、支持及不利事实、控制方、最强反方、主备位和互斥。货损、运费、滞期、无单放货、碰撞、优先权、责任限制不得合成一笔“海事权益”。有货损不等于当然可扣船。

### 3. 论坛、扣船红旗和分类型时效

仲裁条款出现时不得直接写成应向海事法院起诉。专属管辖、专门管辖、扣船后管辖分列。时效按请求类型分行，禁止用三年普通时效冒充货损一年。扣船只做红旗，不写申请。

### 4. 金额区间与两套限制接口

分项列货值、运费、滞期、修理、船期。未知不写零。单位责任限制与海事赔偿责任限制基金分列接口，禁止合成一笔限额。

### 5. 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。下一步按期限灭失、易失航海资料、能否改变 `Q#`、可逆性排序。扣船、立案、精算标为转介。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或航次无法建立；用户坚持伪造航海日志、倒签提单、逃船、威胁或违法登轮取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为扣船申请、精算、建卷、和解协议或程序文书。
