# 边界与路由

## 正触发

船舶已被扣押，具备拍卖条件，申请人拟申请拍卖。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 尚未扣船就要拍卖 | 先转扣船原子 |
| 保证准许拍卖 | 停止保证 |
| 债权登记包 | 登记债权并参与拍卖分配 |
| 一般动产变卖无船舶 | 执行或合同争议 |
| 错误拍卖风险不提示 | 必须明示 |

## 易混

扣押不等于可以立即拍卖。活扣或提供担保后应解除时不得强拍。司法费用和船员遣返等优先拨付不是优先权本身。拍卖错误可能产生巨额赔偿。


## 专项转出

- 债权登记转 登记债权并参与拍卖分配
- 扣船转 准备扣押船舶申请
