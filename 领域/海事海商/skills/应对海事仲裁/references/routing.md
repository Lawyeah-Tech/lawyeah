# 边界与路由

## 正触发

已收到海事仲裁申请，被申请方需要答辩和协议抗辩。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 申请方立案包 | 提起海事仲裁 |
| 法院一审应诉 | 应对海事一审 |
| 只要协议异议终稿且不做答辩准备 | 准备海事仲裁协议异议 |
| 反请求终稿 | 准备海事反诉 |
| 一般商事仲裁无海事 | 合同争议 |

## 易混

被申请人权限与申请人不同。首次实体答辩可能影响协议异议。仲裁规则期限不是民诉答辩期。反请求要单独任务或明确接口。


## 专项转出

- 协议异议转 准备海事仲裁协议异议
- 反请求转 评估海事反诉或抵销 或 prepare-counterclaim
