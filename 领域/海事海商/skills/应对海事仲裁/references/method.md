# 应对海事仲裁方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：答辩、仲裁协议抗辩和证据

---

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　送达与期限

每份通知单独一行。规则期限未核验则字段停止。

若：送达不明 → 不编截止日。
若：期限极短 → 先提交协议异议和最低答辩，保留补充。
若：授权不明或共同被申请人冲突 → 整体停止策略。
若：其实是法院起诉状 → 转 defend-first-instance。

## 节点 2　协议抗辩

无效、未覆盖、机构错误须在规则时点提出。

若：要系统做协议异议 → 转 object-to-arbitration，本任务保留红旗。
若：已决定接受仲裁 → 协议抗辩关闭，进入实体。
若：实体反请求与协议异议并行 → 标弃权风险。
若：协议明显覆盖仍要无理由否认 → 依据不支持。

## 节点 3　实体答辩

责任期间、免责、时效、限制、无单放货抗辩分列。

若：沿海运输申请人引用第四章限额 → 标排除抗辩。
若：需要承运人免责专项 → 转 assess-carrier-defenses 交接。
若：不利事实不得删除。
若：需要反请求评估 → 转 assess-counterclaim。

## 节点 4　证据

按规则提交。伪造日志整体停止。

若：关键证据在对方 → 申请文件出示或法院协助接口。
若：需要庭审提纲 → 转 prepare-hearing。
若：用户要按申请方模板互换立场直接改请求 → 禁止，权限不同。
若：一般合同答辩 → 转出。

## 节点 5　程序动作

指定仲裁员、语言、开庭方式。

若：仲裁员选定时限未核验 → 字段停止但仍列动作。
若：要提管辖法院 → 纠正论坛。
若：要撤销尚未作出的裁决 → 负触发。
若：和解 → 转谈判。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
