# 边界与路由

## 正触发

对方已申请执行海事仲裁裁决，被执行方要提出不予执行。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 撤销裁决申请 | 申请撤销海事仲裁裁决 |
| 一般执行行为异议 | 应对海事执行 |
| 主动申请执行该裁决 | 执行海事生效文书 |
| 把实体算错当成不予执行唯一事由而不核验 | 停止该写法 |
| 国外裁决承认异议路径未核验 | 待核分流 |

## 易混

不予执行在执行法院提出，撤销通常另案。曾放弃异议可能影响事由。公共利益事由不得滥用。与执行行为异议分开写。


## 专项转出

- 撤销转 申请撤销海事仲裁裁决
- 执行行为异议转 应对海事执行
