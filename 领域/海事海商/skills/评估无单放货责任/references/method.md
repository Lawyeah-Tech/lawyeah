# 评估无单放货责任方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：无单放货成立条件、赔偿范围、时效和保险人除外接口

---

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　单证与放货事实

先确认存在有效正本提单且承运人未收回正本即交付货物。

若：单证是海运单或已完成电放 → 负触发，不按无单放货认定。
若：全套正本仍在持有人手中且货物已被他人提走 → 放货事实打开，主体另核。
若：一式多份中一份已被收回 → 其余正本效力与放货合法性分列。
若：放货记录、提货人身份缺失 → 放货事实依据不足。

## 节点 2　请求人资格

请求人须是合法正本持有人。银行、贸易卖方、收货人名称冲突并列。

若：请求人仅持副本或扫描件 → 持有人资格依据不足。
若：背书不连续 → 资格字段停止或依据不足。
若：请求人主轴是未收到货款 → 整案转涉外，本任务只交接单证事实。
若：承运人身份不明 → 先转主体识别，本任务主体字段停止。

## 节点 3　抗辩：电放、保函、海关强制

电放须有权利人指示。保函不当然免除对持单人的责任。海关强制交付须有法律文书。

若：托运人电放指示与正本持有人冲突 → 并列，不得只采承运人有利版本。
若：提货保函存在 → 保函是追偿接口，不当然消灭持单人请求。
若：主张海关强制交付但无法律文书 → 抗辩依据不足。
若：卸港强制规则未核验 → 抗辩法律结论停止。

## 节点 4　赔偿范围、时效与保险除外

赔偿通常对应货物价值接口，不输出必得总额。时效按货损或无单放货专项规则核验，不得用三年普通时效替代。

若：交付或应当交付日不明 → 时效字段停止。
若：货物保险条款将无单放货除外 → 标保险除外接口，不在本任务认定保险责任。
若：货方同时主张货损 → 货损另账，不并入无单放货一笔。
若：金额参数不足 → 未知不写零。

## 节点 5　下一步

扣船、起诉、保险索赔只转介。

若：拟扣船 → 转扣船评估或申请，核验是否落入第二十一条。
若：拟向保险人索赔 → 转 评估海上货物保险理赔 并提示除外。
若：拟起诉 → 转 提起海事一审 或选程序原子。
若：用户要求倒签电放或伪造收回正本 → 整体停止。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
