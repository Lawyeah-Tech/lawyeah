# 边界与路由

## 正触发

正本提单持有人主张承运人未收回正本即放货，或承运人抗辩海关强制交付、电放或海运单。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 电放或海运单交货 | 不按无单放货展开 |
| 信用证拒付或不符点 | 涉外 |
| 货损货差迟延 | 评估货损货差迟延索赔 |
| 只要扣船申请 | 评估扣船必要性与可扣船舶 或 prepare-ship-arrest |
| 未成争改提单放货条款 | 审查起草本窗搁置 |

## 易混

电放指示完成不是无单放货。海运单凭身份交货不是无单放货。海关强制交付须有法律依据和事实，不能口头主张。正本持有人不等于货款债权人。


## 专项转出

- 提单效力转 评估提单效力转让与物权凭证功能
- 货险除外转 评估海上货物保险理赔
