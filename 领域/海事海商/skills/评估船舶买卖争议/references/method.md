# 评估船舶买卖争议方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：所有权移转、登记对抗、违约请求和扣船入口

---

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　合同与标的

确认是船舶买卖而非股权或造船。

若：交易结构是转让船东公司股权 → 转并购。
若：标的仍在建造且按造船合同结算 → 转造船争议。
若：尚未成争只要改 MOA → 审查起草搁置。
若：标的是无登记的小艇且是否属于海商法船舶不明 → 适用范围待核。

## 节点 2　所有权移转与登记

当事人之间移转与登记对抗第三人分列。

若：已交船未登记 → 对第三人对抗效力依据不足，对内效力按合同和交付判断。
若：登记仍在卖方名下且卖方再卖第三人 → 标双重处分风险，转 title 原子补登记事实。
若：买方已付款未交船 → 违约请求打开，所有权是否已移转依据不足或按约定。
若：登记材料冲突 → 不选对用户有利的一版。

## 节点 3　船况、文件与价款

交船时船况、证书、无负担保证和价款分列 Q#。

若：交船检验已签署无保留 → 事后船况主张须有隐藏缺陷或其他法定基础。
若：抵押未涤除 → 卖方权利瑕疵接口打开。
若：价款未付且卖方拟扣船 → 核验第二十一条买卖项，转扣船评估。
若：用户要求伪造无负担证明 → 整体停止。

## 节点 4　解除、违约与担保

解除权、违约金和定金分列，适用民法典合同编待核，不得引用已失效合同法作为现行依据。

若：检索回到已失效合同法 → 记噪声，改核民法典。
若：解约条件未成就 → 不得写成已经解除。
若：需要担保物权实现裁定终稿 → 本任务不出具，转抵押原子说明。
若：涉外选法 → 转 applicable-law。

## 节点 5　扣船与下一步

买卖价款或交船争议可能落入扣船清单，本任务不写申请。

若：拟扣当事船 → 转 assess-ship-arrest。
若：权属本身成争 → 转 assess-ship-title。
若：需要起诉 → 转 file-first-instance 并核验仲裁条款。
若：需要和解交船安排 → 转 draft-settlement。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
