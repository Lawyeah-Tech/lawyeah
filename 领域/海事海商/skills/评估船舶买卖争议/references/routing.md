# 边界与路由

## 正触发

船舶买卖的交船、船况、文件或价款成为争议。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 起草船舶买卖合同 | 审查起草本窗搁置 |
| 收购船东公司股权 | 并购 |
| 造船进度或弃船 | 评估船舶建造争议 |
| 一般动产买卖无船舶登记 | 合同争议 |
| 只要权属登记行政诉讼 | 行政或 ship-title |

## 易混

交船不等于登记完成。登记对抗不是所有权在当事人之间的唯一要件。股权收购不是船舶买卖。MOA 格式只作事实文本。
