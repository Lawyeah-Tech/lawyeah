# 评估运费滞期费与货物留置方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：费用性质、留置对象、通知和错误留置风险

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　费用定性

运费、亏舱费、滞期费、滞留费、堆存费分列，不得合成“港口费用”。

若：费用实际是货款或开证费 → 整案转出。
若：预付运费已注明 shipper 承担且已支付凭证存在 → 承运人再向收货人主张运费依据不足。
若：到付运费记载于提单 → 收货人接口打开，仍核验是否已支付。
若：滞期与 detention 未区分 → 转滞期原子补定性，本任务只留留置接口。

## 节点 2　债务人与单证

谁有义务支付必须回链提单或租约，不得向无关持单人主张。

若：租约运费债务人与提单持有人不一致 → 两套请求分列。
若：运费到付但提单转让后未记载 → 对持单人请求依据不足。
若：亏舱费仅在租约出现 → 不得当然写入对收货人的留置权。
若：主体不明 → 先转主体识别。

## 节点 3　留置对象与通知

留置限于未受偿的货物。通知对象和方式须可回链。

若：货物已交付且承运人丧失占有 → 留置权现有依据不支持。
若：拟留置的是船用物料或无关第三方货物 → 对象不支持。
若：未发通知且条文要求通知 → 程序字段依据不足。
若：货物价值明显高于债权且可部分留置 → 标过度留置风险。

## 节点 4　拍卖清偿与错误留置

留置后拍卖清偿按法定程序。错误留置不因“还有争议”而免责。

若：用户要求不经法院径自变卖且路径未核验 → 该路径字段停止。
若：债权本身依据不足仍要留置 → 标错误留置红旗。
若：货方提供充分担保 → 继续留置的必要性下降，错误风险上升。
若：需要扣货保全而非留置 → 转 准备扣押船载货物或燃油申请。

## 节点 5　与优先权、扣船的分界

货物留置不是船舶优先权，也不是扣船。

若：目标是扣船 → 转扣船原子。
若：目标是船舶优先权排序 → 转 排序船舶优先权抵押权留置权。
若：需要滞期精算 → 转滞期或测算原子。
若：一般仓库保管人主张留置 → 转合同争议。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
