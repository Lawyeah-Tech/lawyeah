# 边界与路由

## 正触发

承运人或出租人主张运费、亏舱费、滞期并拟留置货物。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 一般仓储留置或物流扣货 | 合同争议 |
| 滞期精算工作表 | 评估滞期速遣与滞留费 或 calculate-cargo-limitation |
| 货款当作运费 | 涉外或合同争议 |
| 船舶优先权排序 | 排序船舶优先权抵押权留置权 |
| 未成争改运费到付条款 | 审查起草本窗搁置 |

## 易混

到付运费与预付运费风险不同。滞期费不是当然的违约金。留置对象限于货物和残存运费等法定范围，不得留置无关财产。错误留置产生货损和船期风险。


## 专项转出

- 滞期精算转 评估滞期速遣与滞留费
- 扣押船载货物转 准备扣押船载货物或燃油申请
