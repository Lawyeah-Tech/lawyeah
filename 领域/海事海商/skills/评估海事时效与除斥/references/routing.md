# 边界与路由

## 正触发

单独委托核验一年、两年或油污三年等期间是否届满，需要分类型期间表。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 用三年普通时效冒充货损一年 | 停止该写法 |
| 损坏通知期间当成诉讼时效 | 分列，不混算 |
| 只要货损免责或责任成立 | 评估货损货差迟延索赔 |
| 扣船后三十日起诉期当成诉讼时效 | 分列程序期间 |
| 一般合同时效无海事请求类型 | 合同争议 |

## 易混

通知期间不是诉讼时效。扣船三十日不是货损一年。共同海损一年自理算结束，不是自事故日。保险两年自保险事故发生，不是自拒赔函日当然起算。


## 专项转出

- 货损实体转 评估货损货差迟延索赔
- 碰撞实体转 评估船舶碰撞责任
- 保险实体转 评估船舶保险承保与拒赔 或 assess-cargo-insurance
