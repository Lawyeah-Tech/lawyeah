# 评估海事时效与除斥方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：分类型期间表：货损一年、租船两年、碰撞两年、共同海损一年、保险两年、油污三年各占一行

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　请求类型分列

每一种请求单独一行期间。禁止合成“海事时效三年”。

若：请求是国际航线货损向承运人索赔 → 核验第二百五十七条一年，自交付或应当交付。
若：请求是沿海港口之间货损 → 核验法释〔2001〕18 号一年，不得套用第四章限额，也不得改写成三年。
若：请求是航次租船或船舶租用 → 核验两年，自知道或应当知道权利被侵害。
若：请求类型不明 → 期间字段停止，先补请求定性。

## 节点 2　起算事件

每行只绑定一个起算事件。日期冲突则并行情景，不输出唯一截止日。

若：交付日与应当交付日冲突 → 两套起算并列，结论字段停止。
若：碰撞请求 → 自碰撞之日起核验第二百六十一条两年。
若：共同海损分摊 → 自理算结束之日起一年，不得自宣布共同海损日起算冒充。
若：海上保险 → 自保险事故发生之日起两年，拒赔日只作中断候选。

## 节点 3　油污与特别期间

油污三年及其他特别期间单独一行，不得用货损一年或普通三年替代。

若：船舶油污损害赔偿 → 核验三年及最长期间，公约与国内法分流待核。
若：向第三人追偿 → 九十日或其他追偿期间另账，不并入主请求时效。
若：旅客人身伤亡 → 核验旅客运输专章期间，不与货损一年混算。
若：优先权行使期间 → 与诉讼时效分列，优先权消灭不当然等于债权消灭。

## 节点 4　中断、中止与程序期间

起诉、仲裁、扣船、承认分列。口头催告不得写成已经中断。

若：已扣船但未起诉或仲裁 → 标海诉法三十日红旗，该三十日不是诉讼时效本身。
若：损坏通知已发出 → 只影响初步证据，不得写成时效已中断或已消灭。
若：送达日不明 → 中断效力依据不足。
若：对方主张普通三年已保护货损 → 现有依据不支持该替代，除非请求已定性为非货损运输请求。

## 节点 5　届满效果与下一步

届满只停止该请求的时效结论，不认定实体无责。对方时效抗辩未提出时不写成法院必然释明。

若：材料支持期间已满 → 该请求时效判断为现有依据支持抗辩，实体责任仍不在本任务认定。
若：材料支持未满 → 现有依据不支持届满，仍提示起算争议。
若：需要实体评估 → 转对应货损、碰撞、保险或租约原子。
若：拟立案或扣船 → 转相应程序原子并交接期间表。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
