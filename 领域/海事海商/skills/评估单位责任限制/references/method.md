# 评估单位责任限制方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：计算基数、SDR 接口、声明价值和丧失限制条件，不定法院必支持限额

---

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　适用闸

第四章排除后不得输出 SDR 限额结论。

若：装港卸港均为中国港口 → 单位限制字段停止。
若：第四章适用条件获支持 → 展开第五十六条接口，数字仍待核验 SDR 与件数。
若：迟延交付经济损失 → 另核第五十七条，不得与灭失损坏限额混算。
若：责任尚未评估却只要限额 → 可建接口，但必须写明不认定责任已成立。

## 节点 2　件数与公斤基数

每件或每个其他货运单位 666.67 SDR，或按毛重每公斤 2 SDR，以高者为准，条号和数额运行时核验。

若：件数与公斤参数均缺失 → 不输出数字，只列未知项。
若：集装箱内货物件数在提单上载明 → 按载明件数接口计算，不得擅自改成一箱一件。
若：提单未载明箱内件数 → 集装箱是否作为一件待核，并列情景。
若：活动物或舱面货另有约定 → 不套普通货限额。

## 节点 3　申报价值

托运人申报并记载于提单的价值高于限额时，按其声明。

若：提单记载申报价值 → 限额主位改按声明价值，仍核验是否有效记载。
若：仅发票货值、未在提单记载 → 不得当成第五十六条声明价值。
若：申报价值被指不实 → 并列争议，不输出唯一基数。
若：CIF 价格被写成已申报 → 纠正，Incoterms 价金不是声明价值。

## 节点 4　丧失限制

故意或明知可能造成损失而轻率作为或不作为，不得援引限制。

若：材料支持承运人故意或轻率 → 限制抗辩现有依据不支持。
若：仅有货损严重 → 不得据此写成已经丧失限制。
若：实际承运人行为是否归责于契约承运人不明 → 丧失限制字段依据不足。
若：与第十一章基金丧失条件被混用 → 分列，本任务只处理单位限制。

## 节点 5　测算接口

本任务建参数和情景，精算转测算原子。

若：用户要可复核工作表 → 转 测算货损运费滞期与限制后金额。
若：用户要基金金额 → 转 评估海事赔偿责任限制 或 establish-limitation-fund。
若：汇率或 SDR 当日值未核验 → 金额字段停止。
若：未知参数被要求写成零 → 拒绝。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
