# 边界与路由

## 正触发

需要判断件数或公斤限额、申报价值或是否丧失单位责任限制。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 设立海事赔偿责任限制基金 | 设立海事赔偿责任限制基金 |
| 海事赔偿责任限制权利评估 | 评估海事赔偿责任限制 |
| 沿海运输仍输出 666.67 SDR | 停止该字段 |
| 要唯一必得限额数字 | 停止终局数字 |
| 货损责任是否成立的总评估 | 评估货损货差迟延索赔 |

## 易混

单位责任限制不是海事赔偿责任限制基金。集装箱是否算一件必须核验约定和条文。申报价值高于限额从其声明，不是当然再限制。故意或轻率丧失限制。


## 专项转出

- 精算转 测算货损运费滞期与限制后金额
- 基金转 评估海事赔偿责任限制
