# 边界与路由

## 正触发

已实施救助或被索救助报酬，需要成立要件和报酬因素。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 合同拖航当然写成救助 | 评估海上拖航责任 |
| 纯清污费用不加区分 | 评估船舶油污与污染责任 或另判 |
| 共同海损分摊账单 | 评估共同海损分摊 |
| 未成争起草救助合同 | 审查起草本窗搁置 |
| 一般海上劳务费 | 合同争议 |

## 易混

无效果无报酬是原则，特别补偿是例外。船长签订的救助合同可能约束船东和货方。拖航费率作业不是救助。清污不一定构成救助。


## 专项转出

- 拖航转 评估海上拖航责任
- 清污转 评估船舶油污与污染责任
