# 评估海难救助报酬方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：救助成立、报酬因素、特别补偿和时效两年

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　危险与自愿

被救物处于海上危险，救助须自愿而非既有义务的当然履行。

若：预先拖航合同按固定费率、无海上危险 → 转 towage。
若：船员救助本船 → 通常不构成对所有人的救助报酬请求。
若：危险已经消除后才到达 → 救助成立依据不足。
若：强制机关清污且无救助效果争点 → 费用另判，不当然写成救助报酬。

## 节点 2　效果

无效果无报酬。部分效果按获救价值接口。

若：船舶仍全损且无财产获救 → 报酬主位不支持，看特别补偿。
若：部分货物获救 → 按获救价值建接口，数字未知不写零。
若：效果争议 → 依据不足。
若：用户要求虚构获救价值 → 整体停止。

## 节点 3　报酬因素与合同

第九百章考虑因素只建接口。合同约定报酬须审查显失公平或危险中签署的待核规则。

若：存在 LOF 或固定报酬合同 → 合同文本作为事实，是否可调整待核。
若：船长代签 → 对船东货方约束力待核，不得直接写成无效或当然有效。
若：报酬主张超过获救价值 → 标上限接口。
若：需要准据法 → 转 applicable-law。

## 节点 4　特别补偿

对环境构成损害威胁的船舶或货物救助，特别补偿独立于无效果无报酬。

若：无环境威胁事实 → 特别补偿依据不足。
若：有威胁且采取了防止或减轻环境损害的措施 → 特别补偿接口打开。
若：清污费用已被行政机关另案追偿 → 避免双重计算。
若：条文未核验 → 字段停止。

## 节点 5　时效、担保与优先权

救助报酬时效两年。救助款项常有船舶优先权。

若：自救助终止日起算两年可能届满 → 标红旗。
若：拟扣船或留置获救物 → 转扣船或优先权原子。
若：共同海损分摊救助费 → 转 GA 原子。
若：用户要把拖航改成救助以提高金额 → 纠正。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
