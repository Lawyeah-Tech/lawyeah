# 准备共同海损担保与分摊抗辩方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：担保形式、范围、抗辩点和不提供担保的留置风险

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　请求与货物控制

谁在要求担保、货物是否仍在承运人或理算人控制下。

若：货物已交付且无合同留置安排 → 不提供担保的留置风险下降，仍可能有对人请求。
若：货物未交付并被要求担保 → 标留置或拒绝交付风险。
若：担保格式来自境外理算人 → 准据法和执行力待核。
若：无任何共同海损宣布 → 本任务依据不足。

## 节点 2　担保形式与范围

平均协议、保证金、银行保函、保险人分摊保证分列。

若：保险人愿意出保证 → 优先评估保证范围是否覆盖理算结果。
若：要求现金保证金远超可能分摊 → 标超额风险，金额未知不写零。
若：保函准据法为外国法 → 执行力待核。
若：用户要把“承认共同海损成立”写入担保 → 删除该承认。

## 节点 3　分摊抗辩

不适航、非共同危险、项目不属于共同海损等抗辩独立于是否提供担保。

若：成立抗辩已在 GA 评估中打开 → 担保函注明权利保留。
若：只抗辩金额不抗辩成立 → 担保可限最高额。
若：抗辩事实无证据 → 依据不足，仍可权利保留。
若：需要完整成立评估 → 转 assess-general-average。

## 节点 4　不提供担保的后果

承运人可留置货物或拒绝交付，路径运行时核验。

若：用户决定不提供任何担保 → 明示留置和迟延风险，不指导藏货。
若：货物即将腐烂 → 标紧急处理接口，可转强制令或扣货原子。
若：货方提供充分替代担保仍被拒 → 标不合理拒绝接口。
若：需要放船保函而非 GA 担保 → 转 letter-of-undertaking。

## 节点 5　文本状态

担保草稿保持待签署。不保证理算结果。

若：对方要求预先放弃一切抗辩 → 标高风险，默认不写入。
若：未成争改租约 GA 条款 → 搁置。
若：伪造保险人保证 → 整体停止。
若：需要保险索赔 → 转 prepare-insurance-claim。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
