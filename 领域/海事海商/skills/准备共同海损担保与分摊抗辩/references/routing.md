# 边界与路由

## 正触发

需要出具共同海损担保、保险分摊保证，或抗辩分摊请求。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 把提供担保写成承认分摊成立 | 停止该写法 |
| 代替理算 | 评估共同海损分摊 |
| 一般放船 P&I 保函无共同海损 | 评估放船担保函与保函效力 |
| 未成争设计担保条款 | 审查起草搁置 |
| 只要货损免责 | 评估货损货差迟延索赔 |

## 易混

出具平均协议或担保不等于承认共同海损成立。保险人分摊保证不是承运人责任认定。不提供担保可能导致货物被留置。


## 专项转出

- 成立评估转 评估共同海损分摊
- 放船保函转 评估放船担保函与保函效力
