# 评估海上拖航责任方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：拖航合同责任分配、承拖方免责和时效一年

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　拖航与救助分流

先判断是约定拖航还是遇险救助。定性冲突时救助报酬走救助原子。

若：被拖物处于危险之中且拖轮按“无效果无报酬”作业 → 转 salvage。
若：预先订立拖航合同、按费率作业、危险并非救助意义上的海上危险 → 本任务打开。
若：先拖航后改为救助或相反 → 两段分列，不合并报酬。
若：用户要把便宜拖航改写成高额救助 → 纠正定性。

## 节点 2　适拖与指挥

被拖方使被拖物适拖，承拖方使拖轮适航并谨慎拖带。指挥权依合同。

若：被拖物不适拖且承拖方不知情 → 被拖方责任接口打开。
若：拖轮不适航 → 承拖方责任接口打开。
若：指挥权约定与实际指挥冲突 → 并列。
若：证书和检验缺失 → 适拖适航字段依据不足。

## 节点 3　免责与第三人

承拖方免责条件运行时核验。对第三人损害按侵权或碰撞接口另列。

若：合同免除承拖方过失责任且事项属于可约定范围 → 约定效力待核。
若：造成第三人船舶碰撞 → 转碰撞原子，本任务只留拖航内部追偿。
若：拖带船队内部互损 → 按合同分配，不套旅客限额。
若：港口作业公司主张作业合同 → 转港口原子。

## 节点 4　时效

海上拖航请求时效一年接口，起算运行时核验。

若：起算日不明 → 时效字段停止。
若：用户用三年普通时效替代 → 纠正为拖航专章待核期间。
若：同时存在救助报酬两年主张 → 分列。
若：期间规则未核验 → 法律结论停止。

## 节点 5　下一步

扣船、鉴定、限制基金只转介。

若：需要责任限制 → 转 limitation-of-liability。
若：需要检验 → 转 prepare-survey。
若：未成争改合同 → 搁置。
若：指导逃逸被拖物 → 整体停止。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
