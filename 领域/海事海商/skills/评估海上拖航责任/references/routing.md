# 边界与路由

## 正触发

拖航中发生船损、货损或第三人损害，需要合同责任分配和免责判断。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 救助与拖航定性冲突且救助报酬是主目标 | 评估海难救助报酬 |
| 港口装卸作业损害 | 评估港口作业装卸货损责任 |
| 一般陆上拖车 | 合同争议或人身损害 |
| 未成争起草拖航合同 | 审查起草本窗搁置 |
| 只要共同海损分摊 | 评估共同海损分摊 |

## 易混

拖航合同不是救助合同。承拖方指挥过失与被拖方适拖义务不同。港口内移泊是否属于海上拖航须核验。一年时效不得用货损一年或普通三年替代而不核验。

- 救助转 评估海难救助报酬
- 碰撞转 评估船舶碰撞责任
