# 准备海事仲裁协议异议方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：可提交的异议或效力确认材料、期限和效力争点

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　文本回链

每个仲裁条款必须回链到提单背面、租约或事后协议。口头约定不得写成书面仲裁协议。

若：只有“到时候仲裁”的聊天记录 → 书面形式依据不足。
若：租约仲裁与提单诉讼条款冲突 → 并列，不选对用户有利的一版冒充唯一。
若：提单声称并入租约但无租约文本 → 并入范围依据不足。
若：机构名称不存在或只写“海事仲裁” → 机构可否确定待核。

## 节点 2　效力三要件

请求仲裁的意思、事项覆盖、机构选定或可确定分别判断。

若：条款写可诉讼可仲裁 → 仲裁意思依据不足。
若：事项只覆盖租约租金、对方却把货损拉进仲裁 → 事项覆盖依据不足或不支持。
若：机构明确且存在 → 机构要件打开，其余要件继续。
若：适用的《仲裁法》文本未核验 → 效力法律结论字段停止。

## 节点 3　提单持有人与并入

持单人是否受租约仲裁约束单独判断，不当然及于收货人。

若：并入文句只写 freight 未写 arbitration → 仲裁并入依据不足。
若：持单人未参与租约谈判 → 不得因此单独写成条款无效，须核验并入和知晓。
若：HOUSE 提单与 SEA 提单指向不同机构 → 两套协议分列。
若：用户要求伪造并入章 → 整体停止。

## 节点 4　程序入口与期限

法院首次开庭前、仲裁首次答辩前或其他法定时点运行时核验。逾期停止终稿。

若：已在仲裁中提交实体反请求未提协议异议 → 标弃权风险。
若：对方在法院起诉、己方要以仲裁协议抗辩 → 材料按管辖异议接口交接，本任务出协议效力部分。
若：期限不明 → 字段停止，不出可提交终稿。
若：要申请确认仲裁协议效力 → 列出机关路径待核，不保证受理。

## 节点 5　与实体抗辩隔离

本任务不审理货损、滞期或碰撞实体。

若：用户把“没有货损”写成仲裁协议无效理由 → 纠正，实体不决定协议效力。
若：需要应诉仲裁 → 转 应对海事仲裁。
若：需要法院管辖异议 → 转 提出海事管辖异议。
若：协议有效且决定参加仲裁 → 目标停止，转应诉或评估。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
