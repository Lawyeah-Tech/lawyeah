# 边界与路由

## 正触发

对方依租约或提单仲裁条款推进，己方主张仲裁协议无效或不适用。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 法院管辖异议书 | 提出海事管辖异议 |
| 实体货损或租约抗辩 | 对应评估或应诉原子 |
| 作为申请方提起仲裁 | 提起海事仲裁 |
| 一般民商事仲裁无海事单证 | 合同争议 |
| 未成争改仲裁条款 | 审查起草本窗搁置 |

## 易混

法院管辖异议与仲裁协议异议权限不同。提单并入租约仲裁不等于并入已经完成。应诉实体不等于承认仲裁协议。或裁或诉不是有效仲裁意思。


## 专项转出

- 法院管辖异议转 提出海事管辖异议
- 仲裁应诉转 应对海事仲裁
