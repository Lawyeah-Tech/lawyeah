# 边界与路由

## 正触发

已决定向海事法院申请海事证据保全。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 代替自行合法固定 | 保全航海资料船载货物与电子证据 |

## 易混

证据保全不是扣船。申请提取范围必须具体。保全所得证据用途受限。自行固定能完成时不必申请。
