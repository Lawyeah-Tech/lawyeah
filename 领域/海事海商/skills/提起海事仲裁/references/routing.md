# 边界与路由

## 正触发

存在有效仲裁协议且已决定申请海事仲裁。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 向海事法院起诉 | 提起海事一审 |
| 仲裁协议异议 | 准备海事仲裁协议异议 |
| 被申请方答辩 | 应对海事仲裁 |
| 完整庭审提纲 | 准备海事庭审 |
| 协议无效仍要仲裁终稿 | 停止终稿 |

## 易混

起诉与仲裁互斥。CMAC 或其他机构规则不同，须核验现行规则。扣船后仍应在三十日内申请仲裁。申请书不是裁决书。
