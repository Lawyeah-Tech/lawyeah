# 边界与路由

## 正触发

燃油、货油泄漏或有害物质污染，请求人或责任人需要公约与国内法分流。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 岸上工厂排污 | 环境能源 |
| 海事行政处罚复议诉讼 | 行政 |
| 碰撞过失比例终局且无污染 | 评估船舶碰撞责任 |
| 清污费用被写成救助报酬 | 评估海难救助报酬 另判 |
| 指导逃避强制清污 | 整体停止 |

## 易混

燃油污染与货油污染可能适用不同公约或国内制度。油污民事赔偿不是行政处罚。油污请求常常不能限制或另有基金。岸上储罐泄漏不是船舶油污。
