# 边界与路由

## 正触发

争议焦点是提单是否正本、是否完成转让、是物权凭证还是仅运输合同证明。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 无单放货责任是否成立 | 评估无单放货责任 |
| 未成争起草或审查提单条款 | 审查起草本窗搁置 |
| 只要货损免责或单位限制 | 评估货损货差迟延索赔 |
| 信用证拒付或单据不符点主轴 | 涉外 |
| 海运单或电放却要写成可转让提单 | 停止该写法 |

## 易混

持有复印件不等于持有正本。电放成功不等于签发了可转让提单。指示提单未背书不得写成已完成转让。记名提单的转让效果必须运行时核验，不得用记忆规则冒充。


## 专项转出

- 无单放货转 评估无单放货责任
- 强制签发或放单转 准备海事强制令申请
