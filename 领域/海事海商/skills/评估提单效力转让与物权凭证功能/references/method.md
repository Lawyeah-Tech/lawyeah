# 评估提单效力转让与物权凭证功能方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：单证性质、转让链条、持有人权利，以及与海运单、电放的分流

---

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　单证定性

先区分正本提单、副本、海运单、电放和提货单。定性不明则物权凭证字段停止。

若：表面记载为海运单或 waybill → 不得写成物权凭证，按运输合同证明处理。
若：已电放且承运人凭电放放货 → 不得按无单放货专项展开，本任务只确认单证已非正本流转。
若：只有副本或扫描件、正本下落不明 → 持有人权利依据不足。
若：套用已失效《合同法》解释提单效力 → 记为噪声，改核海商法和民法典运输合同待核条文。

## 节点 2　签发与记载

核验签发人、签发地、货物记载和批注。批注与清洁提单争议只建接口，不替代货损评估。

若：未签发任何运输单证 → 本任务负触发，转主体识别或货损评估。
若：预借或倒签被主张 → 效力争点单列，禁止指导倒签。
若：货物记载与实际装载冲突 → 并列，不得只保留对用户有利的一栏。
若：批注不清或手写覆盖打印 → 记载效力依据不足。

## 节点 3　转让链条

按记名、指示、不记名分别判断背书和交付。链条断裂则现持有人权利停止终局。

若：指示提单缺少连续背书 → 现持有人权利依据不足。
若：空白背书后交付有争议 → 交付事实与控制方分列，不写成已经转让。
若：记名提单声称已转让 → 转让规则运行时核验，核验失败则字段停止。
若：银行因信用证持有提单 → 持有地位与担保利益分列，不自动写成货主。

## 节点 4　持有人权利与提货

正本持有人请求提货或主张控制权时，只判断单证功能，不审理无单放货赔偿。

若：正本仍在流转且承运人已放货 → 转无单放货专项，本任务只确认单证仍有效力争议。
若：全套正本已收回 → 持单索赔接口关闭，改核运输合同下其他请求。
若：一式三份中一份已提货 → 其余正本效力待核，不得写成全部失效或全部有效。
若：用户只要签发新单或改单 → 审查起草搁置，或紧迫放单转海事强制令原子。

## 节点 5　与贸易单证分流

信用证、发票、装箱单只作背景。主请求是货款或不符点时整案转涉外。

若：主请求是开证行拒付 → 整案转涉外，本任务只交接单证性质。
若：Incoterms 被写成准据法 → 纠正为价金风险划分，不作为单证效力依据。
若：需要识别承运人 → 转 识别承运人实际承运人与责任主体。
若：需要评估货损 → 转 评估货损货差迟延索赔。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
