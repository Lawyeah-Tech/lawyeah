# 选择海事诉讼仲裁或扣船先行方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：程序适配、三十日期限、仲裁阻却和成本

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　论坛闸

有效仲裁协议未排除时，实体路径以仲裁为主位，法院起诉受阻。

若：表面有效仲裁协议覆盖本案请求 → 不得推荐直接起诉作为主位。
若：协议效力明显依据不足 → 并列诉讼与仲裁情景，转论坛原子补强。
若：专属管辖仅影响法院选择，不消灭仲裁 → 分列。
若：一般合同无海事 → 转出。

## 节点 2　扣船先行

仅当清单请求、可识别船舶和错误扣船风险可接受时打开。

若：船舶即将离港且请求落入第二十一条 → 扣船先行接口打开，仍须三十日内起诉或仲裁。
若：对方已提供充分担保 → 扣船必要性下降。
若：无船舶线索 → 扣船路径关闭。
若：用户只要申请书 → 转 prepare-ship-arrest。

## 节点 3　直接起诉或仲裁

无扣船时比较送达、执行和成本。

若：被告在中国有其他财产 → 直接起诉或仲裁可为主位。
若：唯一财产是船舶且即将消失 → 直接程序风险高。
若：时效临近 → 以能中断或行使权利的程序为先，不因追求扣船完美而误期。
若：需要完整立案包 → 转 file-first-instance 或 file-arbitration。

## 节点 4　成本与可逆性

担保、律师费、船期错误赔偿、仲裁费用分列。未知不写零。

若：申请人无力提供扣船担保 → 扣船路径可行性下降。
若：仲裁地在境外 → 标承认执行成本。
若：和解仍可能 → 标谈判并行，不强制选程序。
若：C 端网上立案心态 → 纠正为专业海事程序。

## 节点 5　输出

给出适配比较，不指定唯一法院，不写完整申请。

若：用户未选路径 → 只比较，不擅自启动申请。
若：混合请求要同时出三套文书 → 列出入口并只问先做哪一项。
若：被请求方立场 → 本任务负触发。
若：指导逃船后再谈程序 → 整体停止。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
