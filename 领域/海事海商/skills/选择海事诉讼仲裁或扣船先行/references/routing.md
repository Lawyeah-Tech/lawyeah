# 边界与路由

## 正触发

主张方需要比较先扣船、先仲裁或直接向海事法院起诉。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 完整扣船或起诉申请书 | 对应准备或起诉原子 |
| 被请求方应诉策略主轴 | 应对海事一审 或 defend-arbitration |
| 一般合同选诉讼或仲裁无海事 | 合同争议 |
| 货款信用证主轴 | 涉外 |
| 未成争选论坛条款 | 审查起草搁置 |

## 易混

有仲裁协议则扣船后实体仍应仲裁。扣船不是必经程序。直接起诉可能错过船舶。成本高不等于更能执行。


## 专项转出

- 扣船申请转 准备扣押船舶申请
- 起诉转 提起海事一审
- 仲裁申请转 提起海事仲裁
