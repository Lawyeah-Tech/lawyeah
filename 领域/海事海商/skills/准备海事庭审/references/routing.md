# 边界与路由

## 正触发

诉讼或仲裁即将开庭，单方代理需要争点和庭审提纲。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 代替立案 | 起诉或仲裁申请原子 |
| 仅和解不想开庭 | 谈判海事和解方案 |
| 鉴定异议终稿 | 提出海事鉴定异议 |
| 上诉状 | 提起海事上诉 |
| 一般民事庭审无海事争点 | 合同争议 |

## 易混

庭审提纲不是新的起诉状。未举证的事实不能在提纲里当成已认定。对鉴定意见的质证不等于重新鉴定。仲裁与诉讼程序语言不同。


## 专项转出

- 立案转起诉或仲裁申请原子
- 鉴定异议转 提出海事鉴定异议
