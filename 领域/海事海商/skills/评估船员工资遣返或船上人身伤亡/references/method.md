# 评估船员工资遣返或船上人身伤亡方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：海事请求定性、优先权顺位接口、扣船入口，以及与劳动仲裁的分流

---

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　身份与主轴分流

先确认船员因任职船舶产生的工资、遣返或营运伤亡。纯解除补偿转劳动。

若：请求只是解除劳动合同经济补偿、社保补缴，明确不要优先权或扣船 → 转劳动。
若：请求是在船工作期间工资、遣返费或船上伤亡 → 本任务打开。
若：身份是旅客或码头工人 → 转旅客或港口作业原子。
若：用户要代办工伤认定表格提交 → 不代办，只标劳动接口。

## 节点 2　海事请求定性

工资、遣返、人身伤亡分列 Q#。登记船东、光租人、船舶管理人不自动合并。

若：工资期间与在船事实不能回链 → 请求依据不足。
若：伤亡发生在休假陆上交通 → 船上营运伤亡依据不足，转劳动或人身损害。
若：光租已登记 → 光租人进入责任主体接口。
若：主体冲突 → 转 ship-title 或 identify-carrier 补登记，不在本任务终局权属。

## 节点 3　优先权与扣船入口

船员工资和在营运中人身伤亡可能落入第二十二条优先权。扣船只做入口，不写申请。

若：请求落入第二十二条第一项或第二项接口 → 标优先权红旗，顺位转 rank-maritime-liens。
若：优先权一年行使期间可能届满 → 期间字段待核，不得用普通时效冒充。
若：拟扣船 → 转 assess-ship-arrest，核验第二十一条船员劳动报酬或人身伤亡项。
若：船舶已拍卖 → 转登记债权原子。

## 节点 4　与劳动仲裁并行

劳动仲裁前置是否挡住海事诉讼必须运行时核验，不得记忆“一律先仲裁”。

若：用户只要劳动仲裁且不要海事程序 → 转劳动，本任务只留优先权提示。
若：已在劳动仲裁主张同一工资 → 标重复请求风险，海事请求是否仍可独立待核。
若：外籍船员或境外签约 → 准据法和社保接口待核。
若：刑民交叉（重大责任事故） → 只标红旗，不定罪。

## 节点 5　金额与下一步

工资和伤亡赔偿未知不写零。不输出劳动能力鉴定结论。

若：伤残等级未定 → 金额字段停止。
若：需要和解 → 转谈判原子并提示优先权放弃风险。
若：需要起诉 → 转 file-first-instance 并交接劳动仲裁红旗。
若：用户要求隐匿船舶逃避工资 → 整体停止。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
