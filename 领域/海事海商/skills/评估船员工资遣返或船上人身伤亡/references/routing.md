# 边界与路由

## 正触发

船员工资、遣返、社保费用或营运中人身伤亡拟主张海事请求、优先权或扣船。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 纯劳动合同解除和经济补偿主轴 | 劳动 |
| 代办工伤认定 | 劳动或不代办 |
| 旅客伤亡 | 评估海上旅客运输伤亡行李索赔 |
| 一般陆上工伤无船舶营运 | 劳动或人身损害 |
| 只要劳动仲裁申请书且无海事请求 | 劳动 |

## 易混

船员工资可以同时是劳动债权和船舶优先权，不等于劳动仲裁已经吸收扣船。工伤认定不是本任务成果。船员与旅客、引航员、港口工人不是同一身份。
