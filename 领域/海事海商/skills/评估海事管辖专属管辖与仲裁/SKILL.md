# 评估海事管辖专属管辖与仲裁

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“海事管辖与仲裁协议评估”：专门管辖、专属管辖、扣船后管辖、仲裁协议文本回链、或裁或诉、异议期限待核和主位论坛。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：海事海商已成争，需要选择海事法院还是仲裁；或对方已提出管辖／仲裁协议异议，用户仍需评估该异议是否绊住程序，而不是只要可提交异议书终稿。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 一般合同管辖或劳动仲裁主轴；
- 只要起诉状、仲裁申请书或完整立案包；
- 异议期已过且用户唯一目标是赶写异议书；
- 只要扣船申请终稿；
- CIF/FOB 货款或信用证主轴（转涉外）；
- 尚未成争，只要改管辖／仲裁条款或出稿（审查起草搁置）；

本任务不生成管辖异议书终稿、起诉状或扣船申请，不给胜诉率，不选定唯一海事法院。

## 建立评估坐标

确认：使用者与授权；单方立场；相对方及未签字可能约束主体；提单 hinterland、租约仲裁、协议管辖文本；是否已扣船；起诉状／仲裁申请／应诉通知的作出与送达。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` `D#` `A#` `R#` `C#` `L#` `I#` `G#` `Q#` `V#` `E#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验海诉法第六、七、十九条，专门管辖解释，仲裁协议要件和异议期限。工具不可用时继续文本回链；效力、主位论坛和期限字段停止。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号、2000 货规时记为噪声，不得写入 `L#`。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 领域分流、主体和程序状态

先转出一般合同、劳动仲裁和国际贸易货款。再固定提单/租约版本和仲裁／管辖条款冲突。程序表记录扣船、起诉、仲裁申请、应诉通知和已提出的异议。口头转述不得写成已送达或异议期限已起算。

### 2. 专门管辖与专属管辖

海事侵权和海商合同由海事法院专门管辖，不等于已选定某一家海事法院。港口作业、船舶污染、海洋勘探开发另核海诉法第七条专属。连结点只列待核。

### 3. 仲裁意思、事项覆盖和机构

分别判断书面形式、请求仲裁的意思、事项是否覆盖本案、机构是否选定或存在。机构不明或或裁或诉标 `依据不足`，不选定唯一论坛。

### 4. 扣船后管辖与协议独立性

扣船后可向扣船法院或其他有管辖权的海事法院起诉，但当事人之间订有诉讼管辖协议或仲裁协议的除外。合同无效不当然消灭仲裁协议。

### 5. 异议期限待核和转出

已进入程序时标异议期限红旗，不编造截止日期，不写异议书终稿。用户只要起诉状则目标停止。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或航次无法建立；用户坚持伪造航海日志、倒签提单、逃船、威胁或违法登轮取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为其他原子的终稿。
