# 测算货损运费滞期与限制后金额

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“海事金钱可复核测算包”：事件编号、分项工作表、单位限制与基金限制分列接口、SDR/汇率待核、互斥和情景区间。本任务不认定责任已经成立。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：海事已成争，单方需要货值、运费、滞期、修理、船期或限制后金额的可复核数字工作表。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要定性总图；
- 只要扣船申请或诉状；
- 保险或陆上侵权主轴；
- 用户要求把未知写成零或输出唯一必得总额；
- 沿海运输仍要求直接套用第 56 条限额作为结论；

未知不写零。真实零必须有肯定来源。不输出唯一必得总额。

## 建立评估坐标

确认：测算项目与排除项；发票/CIF 构成；件数与毛重；是否申报价值；滞期条款；已付款；汇率时点。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` `D#` `A#` `R#` `C#` `L#` `I#` `G#` `Q#` `EVT#` `M#` `V#` `E#`。金额状态只用 `已核实金额`、`情景金额`、`无法估计`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验第五十六条、第二百零七至二百一十三条、责任限制解释第二十一条 LPR。工具不可用时继续分项建账；限额和利息法律结论字段停止。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号、2000 货规时记为噪声，不得写入 `L#`。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 测算范围和第四章闸

先确认是否适用第四章。沿海港到港不得输出第 56 条限额结论。本任务不把责任写成已成立。

### 2. 事件编号与分项建账

同一经济事件分配 EVT#。货值、修理、贬值、运费、滞期、船期、共同海损分摊分列。未知不写零。

### 3. 单位限制参数

件数认定（包装/集装箱是否一件）、毛重、SDR、声明价值、丧失限制条件。参数缺一项则该行 `无法估计`。

### 4. 基金限制接口

与单位限制分列。第 208 条除外（救助、共同海损、公约油污等）不得纳入可限制总额。利息按 LPR 待核。

### 5. 互斥、情景和缺口

滞期与滞留不得双计同一时间。情景只改变列明变量。禁止唯一必得总额。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或航次无法建立；用户坚持伪造航海日志、倒签提单、逃船、威胁或违法登轮取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为其他原子的终稿。
