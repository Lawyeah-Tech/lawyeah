# 边界与路由

## 正触发

需要联合检验、商检或司法鉴定确认残损或碰撞事实。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 预测鉴定意见 | 停止预测 |
| 对已作出鉴定提出异议 | 提出海事鉴定异议 |
| 只要自行拍照固定 | 保全航海资料船载货物与电子证据 |
| 工程造价鉴定无船舶 | 建设工程 |
| 未成争指定“自己人”出具假报告 | 整体停止 |

## 易混

联合检验、保险检验、商检和司法鉴定权限不同。鉴定事项过宽会被退回。不得在申请里写期望结论。
