# 边界与路由

## 正触发

保险人已赔付，拟向承运人或第三人追偿。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 未赔付写成已取得代位 | 停止该写法 |
| 无单放货保险除外未核验 | 先核货险除外 |
| 被保险人向保险人索赔包 | 准备海上保险索赔材料 |
| 一般责任险代位无海运 | 保险或合同争议 |
| 未成争设计代位条款 | 审查起草搁置 |

## 易混

权益转让书不是代位的唯一要件，但赔付必须真实。保险人不能取得大于被保险人的权利。承运人对被保险人的抗辩可对抗保险人。货损一年时效可能已所剩无几。


## 专项转出

- 承运人责任转 评估货损货差迟延索赔
- 起诉转 提起海事一审
