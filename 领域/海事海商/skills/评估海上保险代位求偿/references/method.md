# 评估海上保险代位求偿方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：代位条件、时效和对承运人抗辩的承继

---

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　赔付与代位发生

实际支付保险赔偿后才取得代位。预赔或通融须核验是否构成赔付。

若：尚未支付 → 不得写成已取得代位。
若：通融赔付且保单除外本可拒赔 → 代位基础依据不足或不支持。
若：只取得权益转让书未付款 → 代位未完成。
若：部分赔付 → 代位范围限于已赔部分。

## 节点 2　被保险人原权利

第三人责任须可回链。无单放货若属保险除外，须解释为何仍赔及代位是否成立。

若：原请求是无单放货且条款除外 → 标红旗，代位可能因赔付基础动摇。
若：被保险人已免除第三人责任 → 代位受损。
若：原权利主体不是被保险人 → 代位依据不足。
若：需要承运人责任评估 → 转 cargo-claim 或 collision 并交接代位身份。

## 节点 3　抗辩承继

责任期间、免责、通知初步证据、单位限制、时效均可由第三人向保险人主张。

若：被保险人未及时通知承运人 → 保险人承受该初步证据效果。
若：沿海运输不得限制 → 保险人也不能主张或否认超出被保险人地位的部分。
若：仲裁协议约束被保险人 → 保险人追偿论坛受约束接口。
若：单位限制参数不足 → 金额接口停止。

## 节点 4　时效

追偿时效按原请求类型，不因保险赔付而当然重新起算两年。

若：货损一年即将届满 → 最高优先级提示起诉或仲裁。
若：保险人主张自赔付日起算普通时效 → 该主张待核，不得写成已决。
若：日期不明 → 字段停止。
若：需要扣船 → 转 assess-ship-arrest，请求人写保险人代位。

## 节点 5　下一步

本任务不出代位起诉状终稿，除非用户目标转为起诉原子。

若：已决定起诉 → 转 file-first-instance。
若：已决定仲裁 → 转 file-arbitration。
若：被保险人拒绝协助提供单证 → 标协助义务接口。
若：伪造赔付凭证 → 整体停止。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
