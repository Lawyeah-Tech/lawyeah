# 应对海事执行方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：适格异议和履行安排

---

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　安全闸

任何逃船、过户藏匿、拆卸关键设备逃避执行的方案整体停止。

若：用户征求如何把船开到境外躲避 → 整体停止。
若：正常营运但须向法院报备 → 合法报备接口。
若：文书未指向该船 → 标扣错财产异议。
若：主动执行 → 转 enforce-instrument。

## 节点 2　异议适格

执行行为违法、主体错误、超范围、案外人权属分列。实体败诉不是异议理由。

若：理由只是一审认定货损错误 → 不支持作为执行异议。
若：执行超出生效文书金额 → 行为异议打开。
若：船舶属案外人且有登记 → 案外人异议接口。
若：仲裁裁决执行 → 是否走不予执行专项另核。

## 节点 3　期限与材料

异议期限运行时核验。逾期停止终稿。

若：送达不明 → 期限字段停止。
若：需要权属证据 → 转 ship-title 交接，不在执行里重新确权终局。
若：伪造登记 → 整体停止。
若：一般执行异议模板 → 加入船舶登记与优先权负担。

## 节点 4　履行安排

分期、替代担保、放船换担保。不写成自认超出文书的债务。

若：可提供充分担保解除执行扣押 → 转 letter-of-undertaking 接口。
若：和解减让 → 转 draft-settlement 并经执行法院确认接口。
若：完全无履行能力 → 据实说明，不指导转移。
若：需要拍卖程序中登记自己的优先权 → 转 register-claim-for-auction。

## 节点 5　升级

拒执罪风险只提示停止违法，不展开辩护。

若：已出现拒执刑事风险 → 民事部分可继续合法异议，刑事转出。
若：追加被执行人通知 → 升级，本任务只做初步适格。
若：对不予执行裁决要专项 → 转 resist-award-enforcement。
若：对撤销裁决 → 转 set-aside-award。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
