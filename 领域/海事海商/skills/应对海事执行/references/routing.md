# 边界与路由

## 正触发

被执行人收到执行或船舶被委托扣押，需要适格异议或履行安排。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 隐匿转移船舶 | 整体停止 |
| 重审实体败诉理由 | 停止当执行异议 |
| 主动申请执行 | 执行海事生效文书 |
| 不予执行仲裁裁决专项 | 申请不予执行海事仲裁裁决 |
| 一般执行异议无海事财产 | 合同争议执行路径 |

## 易混

执行异议不是上诉。案外人异议与债务人异议不同。提供担保请求暂缓拍卖不等于否定文书。逃船是禁止事项。


## 专项转出

- 申请执行转 执行海事生效文书
- 不予执行裁决转 申请不予执行海事仲裁裁决
