# 边界与路由

## 正触发

承运人或船东拟援引航海过失、火灾、天灾或托运人过错，需要抗辩表和举证责任。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 货损总评估或通知时效总图 | 评估货损货差迟延索赔 |
| 沿海运输硬套第四章免责 | 停止套用 |
| 只要单位责任限制数字 | 评估单位责任限制 |
| 无单放货 | 评估无单放货责任 |
| 一般公路承运人免责 | 合同争议或相应运输领域 |

## 易混

管货过失不是航海过失。开航后不适航不得用开航前适航抗辩偷换。火灾免责不覆盖承运人本人过失。未通知不等于可以免责。


## 专项转出

- 货损总评估转 评估货损货差迟延索赔
- 单位限制转 评估单位责任限制
