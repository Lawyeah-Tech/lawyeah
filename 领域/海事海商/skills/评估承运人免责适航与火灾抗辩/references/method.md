# 评估承运人免责适航与火灾抗辩方法

本文件是可执行判断节点，不是栏目说明书。每个会改变主体、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然扣船或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《海商法》《海事诉讼特别程序法》《仲裁法》《民事诉讼法》及司法解释的条号与施行日一律运行时核验后写入 `L#`。不得沿用记忆条号当作已核验规则。

本任务成果：第四十七条、第五十一条抗辩表、举证责任和不能免责的故意或明知

## 节点 0　分流

先于实体判断。命中负触发则整案转出或停止终稿，只交付分流理由和最小交接。

若：主轴是 CIF/FOB 货款、信用证拒付、出口管制、制裁或 CISG 买卖 → 整案转涉外，不把“货物曾经上船”写成海事请求。
若：一般买卖、服务、承揽或陆上仓储，无海商法或海事程序专门规则 → 转合同争议。
若：尚未成争，只要改租约、提单、造船或保险条款 → 审查起草本窗搁置，只说明不实施。
若：劳动合同解除、经济补偿、社保公积金，不以船舶优先权或扣船为成果 → 转劳动。
若：陆上交通事故或场所侵权，无海船或海上运输特征 → 转人身损害。

## 节点 1　第四章适用范围闸

装港卸港均为中国港口时不得适用第四章免责清单。

若：装港和卸港均为中华人民共和国港口 → 第四章不适用，免责清单字段停止，改标沿海或民法典运输合同待核。
若：其中一港在境外或海江直达满足海上货物运输 → 可展开第四十七、五十一条，仍须核验文本。
若：港口事实冲突 → 并行情景，免责结论停止。
若：多式联运海运区段不明 → 转 评估多式联运海运区段责任，不得硬套海运免责。

## 节点 2　适航抗辩

开航前和开航当时谨慎处理使船舶适航、妥善配备船员和供应品、使货舱适货。

若：开航前未进行合理检查的事实被材料支持 → 适航抗辩现有依据不支持。
若：缺陷发生于开航之后且承运人已尽开航前谨慎处理 → 可进入后续免责项，仍须分项举证。
若：船员证书、船舶证书缺失 → 适航字段依据不足或对承运人不利。
若：用户要求倒签适航文件 → 整体停止。

## 节点 3　第五十一条分项

航海过失、火灾、天灾、战争、托运人过错、包装不足等逐项举证，不得打包写成“不可抗力”。

若：主张船长驾驶或管理船舶过失 → 须与管货过失切割，管货过失不得免责。
若：主张火灾 → 须排除承运人本人过失或私谋，本人范围待核。
若：主张托运人申报不实或包装不良 → 须回链申报单和装箱证据。
若：多项免责同时主张 → 分列主备位，互斥时不得叠加。

## 节点 4　举证责任与故意明知

承运人主张免责原则上负举证责任。故意或明知可能造成损失而轻率作为不得免责或限制。

若：免责事实完全由货方控制且无反证接口 → 仍不得把举证责任整体推给货方，除非条文支持。
若：存在故意或轻率迹象 → 免责和限制字段标红旗，转单位限制原子。
若：火灾原因不明 → 火灾免责依据不足。
若：活动物或舱面货另有约定 → 另核第五十二条、第五十三条，不套普通货免责。

## 节点 5　与总评估、限额的交接

本任务不替代货损总评估，不输出限额数字。

若：需要通知、时效或主体总图 → 转 评估货损货差迟延索赔。
若：需要件数或公斤限额 → 转 评估单位责任限制。
若：需要海事赔偿责任限制基金 → 转 评估海事赔偿责任限制。
若：用户只要胜诉率 → 拒绝该输出。

## 停止后仍可交付

字段停止时继续交付已闭合事实、来源表、待核清单和最小交接。整体停止时只交付停止理由、已固定坐标和禁止动作，不输出策略或可提交终稿。

禁止指导伪造日志、倒签或预借提单、逃船、藏匿船舶、威胁或违法登轮取证。
