# 评估承运人免责适航与火灾抗辩

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“评估承运人免责适航与火灾抗辩”：第四十七条、第五十一条抗辩表、举证责任和不能免责的故意或明知

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：承运人或船东拟援引航海过失、火灾、天灾或托运人过错，需要抗辩表和举证责任。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 货损总评估或通知时效总图（转 评估货损货差迟延索赔）
- 沿海运输硬套第四章免责（转 停止套用）
- 只要单位责任限制数字（转 评估单位责任限制）
- 无单放货（转 评估无单放货责任）
- 一般公路承运人免责（转 合同争议或相应运输领域）

本任务不给胜诉率，不把一般国际贸易货款或信用证主轴做成海事结论。未成争的租约、提单或造船合同审查起草本窗搁置，只说明不实施。

## 建立评估坐标

确认：使用者与授权；单方立场；相对方及可能责任主体；航线港口、开航前检查、航海日志、火灾报告、货物申报与包装、集装箱交接、第四章是否适用；法域；当前协商、扣船、仲裁、诉讼或执行状态；机关文书作出与送达；对方已知主张；关键材料及缺失。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同或单证条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`V#` 评估版本；`E#` 发送／送达／履行凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验海商法第四十七条适航、第四十八条管货、第五十一条免责清单、第五十二条活动物、第五十九条丧失限制；`search_practiced` 补路径与反例；特殊事实用 `search_case_by_fact`，明确筛选用 `search_case_by_filter`。不虚构案件系统。

工具不可用时继续事实、主体、程序文书状态和问题清单；法律结论、期限或机关路径字段停止。

`search_law` 返回已失效《合同法》、法发〔1994〕14 号诉前扣船规定、《国内水路货物运输规则》或《经济合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　第四章适用范围闸

装港卸港均为中国港口时不得适用第四章免责清单。
### 节点 2　适航抗辩

开航前和开航当时谨慎处理使船舶适航、妥善配备船员和供应品、使货舱适货。
### 节点 3　第五十一条分项

航海过失、火灾、天灾、战争、托运人过错、包装不足等逐项举证，不得打包写成“不可抗力”。
### 节点 4　举证责任与故意明知

承运人主张免责原则上负举证责任。故意或明知可能造成损失而轻率作为不得免责或限制。
### 节点 5　与总评估、限额的交接

本任务不替代货损总评估，不输出限额数字。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或航次无法建立；用户坚持伪造航海日志、倒签提单、逃船、威胁、隐匿转移船舶或违法登轮取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为其他原子的终稿。
