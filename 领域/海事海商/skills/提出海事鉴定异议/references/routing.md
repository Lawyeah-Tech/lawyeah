# 边界与路由

## 正触发

检验或鉴定意见作出后不服，需要异议点和补充或重新鉴定材料。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 重新做一份鉴定意见冒充法院委托 | 停止 |
| 尚未鉴定只要申请 | 准备海事检验鉴定申请 |
| 对裁判上诉 | 提起海事上诉 |
| 工程鉴定异议无海事检材 | 建设工程 |
| 逾期仍要重新鉴定终稿 | 停止终稿并标失权 |

## 易混

对检验报告提意见不等于司法重新鉴定。重新鉴定有法定事由，不是因为结论不利。不得隐瞒对本方不利的鉴定。


## 专项转出

- 初次申请转 准备海事检验鉴定申请
- 庭审质证转 准备海事庭审
