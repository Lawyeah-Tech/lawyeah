# 边界与路由

## 正触发

主管机关责令打捞或第三人主张清除费用，需要责任主体和费用性质。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 指导逃避主管机关强制打捞 | 整体停止 |
| 救助报酬主轴 | 评估海难救助报酬 |
| 岸上建筑物拆除 | 建设工程或行政 |
| 纯行政处罚复议 | 行政 |
| 油污民事总图无沉船 | 评估船舶油污与污染责任 |

## 易混

强制打捞费用不一定是救助报酬。沉船清除费用常常不得限制责任。所有权人放弃船舶不当然免除打捞义务。行政处罚与民事费用分列。


## 专项转出

- 救助转 评估海难救助报酬
- 油污转 评估船舶油污与污染责任
