# 边界与路由

## 正触发

航海日志、VDR、舱单或货况可能灭失，需要合法保全步骤。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 指导登轮窃取资料 | 整体停止 |
| 海事证据保全申请书终稿 | 准备海事证据保全申请 |
| 完整证据案卷策略 | 建立海事证据案卷 |
| 鉴定申请 | 准备海事检验鉴定申请 |
| 一般陆上微信证据无航海资料 | 合同争议证据方法 |

## 易混

自行合法复制不是证据保全裁定。VDR 有覆盖周期。登轮须有法定权限或同意。申请书走专门原子。


## 专项转出

- 申请书转 准备海事证据保全申请
- 案卷目录转 建立海事证据案卷
