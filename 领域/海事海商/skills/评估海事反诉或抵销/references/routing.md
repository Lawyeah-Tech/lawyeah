# 边界与路由

## 正触发

被请求方拟以运费、滞期或碰撞对请求提出反诉或抵销，需要条件判断。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 自动生成反诉状终稿 | 准备海事反诉 |
| 本诉答辩包 | 应诉原子 |
| 无牵连的新案包装成反诉 | 另案起诉或仲裁 |
| 一般合同反诉无海事 | 合同争议 |
| 未成争抵销条款设计 | 审查起草搁置 |

## 易混

抗辩不是反诉。抵销与反诉效果不同。仲裁中反请求受协议事项限制。碰撞对请求可能必须一并处理，但仍要核验管辖。


## 专项转出

- 反诉状转 准备海事反诉
- 应诉转对应诉讼或仲裁应诉原子
