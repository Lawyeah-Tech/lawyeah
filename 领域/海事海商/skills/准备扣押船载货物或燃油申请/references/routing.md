# 边界与路由

## 正触发

已决定扣押船载货物、船用燃油或物料。

## 负触发表

| 主要目标 | 路由 |
| --- | --- |
| 扣押船舶 | 准备扣押船舶申请 |
| 一般仓储查封 | 合同争议 |
| 承运人行使货物留置评估 | 评估运费滞期费与货物留置 |
| 货款无海事请求 | 涉外或合同争议 |
| 指导隐匿货物 | 整体停止 |

## 易混

扣货、扣燃油与扣船是不同制度。扣货后起诉或仲裁期限通常是十五日，不得套用扣船三十日。留置权行使不是扣押裁定。


## 专项转出

- 扣船转 准备扣押船舶申请
- 货物留置转 评估运费滞期费与货物留置
