# 边界与路由

## 正触发

仍可谈判减免、展期或以股抵债，要让步表和执行力说明。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 已签字协议审查 | 审查起草领域（本窗搁置） |
| 法定和解草案 | `准备和解协议草案` |
| 重整计划 | `准备重整计划草案` |
| 预重整效力 | `评估预重整或庭外重组` |
| 普通并购 | 投资并购领域 |

## 专项整案转出

见方法节点 0。一般借贷担保实现、公司治理日常只分流。审查起草本窗搁置，只说明不实施。

## 易混

谈判方案不是已签字合同审查。也不是法定和解协议。庭外签字约束不了未签字债权人。
