# 谈判庭外或程序内债务调整

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把已失效《企业破产法（试行）》或 1991 年民事诉讼法企业法人破产还债程序当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

形成“让步表、弃权、与法定程序衔接和执行力”。已签字协议审查走审查（搁置）。普通并购转投资并购。

`depends-on` 为空。接受用户、律师、管理人、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：仍可谈减免、展期或以股抵债，需要谈判方案而非法定文书终稿。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 已签字协议只要审查修订（审查起草，本窗搁置）；
- 普通并购交割（投资并购）；
- 法定和解协议或重整计划终稿；

庭外协议对未签字方无破产法约束力。个别清偿风险须揭示。不保证对方接受。

## 建立评估坐标

确认：是否已受理、谈判对手、让步底线、是否拟转法定程序、有无已签字文本。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 底线；`D#` 对手意向；`R#` 程序；`L#` 规则；`I#` 判断；`Q#` 让步情景。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_practiced` 补谈判与衔接；涉及法定效果时 `search_law` 核验个别清偿与协议效力。

工具不可用时继续事实、主体、程序文书状态和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　文本闸

已签字只要改合同：搁置转审查起草。

### 节点 2　让步表

本金、息、期限、担保、以股抵债分列。未知不写零。

### 节点 3　执行力

庭外无强制执行力，除非另有可核验的公证或文书。

### 节点 4　程序衔接

谈成后如何进入和解、重整或避免个别清偿撤销。

### 节点 5　并购转出

以股抵债的股权文件转投资并购。

## 停止与安全

- `整体停止`：以谈判掩护个别清偿或转移。
- `字段停止`：个别清偿撤销规则未核验且用户要“先还自己人没事”。
- `目标停止`：主目标变为审查已签协议或法定草案终稿。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
