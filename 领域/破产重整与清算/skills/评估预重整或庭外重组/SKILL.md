# 评估预重整或庭外重组

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把已失效《企业破产法（试行）》或 1991 年民事诉讼法企业法人破产还债程序当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在尚未裁定受理的前提下，形成“预重整／庭外重组效力边界表”：与法定重整的接口、协议约束力、招募投资人边界。不可写成已进入重整，预重整无权接管财产。

`depends-on` 为空。接受用户、律师、管理人、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：尚未受理，债务人 or 主要债权人拟做预重整、庭外协议或招募投资人，需要效力边界和转法定程序接口。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 法院已裁定重整，只要可行性或计划草案；
- 普通股权或资产收购交割（投资并购）；
- 尚未成争，只要改投资协议或重组合同（审查起草，本窗搁置）；
- 要管理人立即接管公章和账户；

预重整不是法定重整。庭外协议对未签字债权人无破产法上的约束力。个别清偿风险必须可见。普通并购转投资并购。

## 建立评估坐标

确认：是否已申请或已受理；预重整是否有法院或政府文件；主要债权人名单与意向；投资人接触材料；是否已个别清偿。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 陈述；`D#` 意向或备忘；`R#` 预重整工作函；`L#` 规则；`I#` 判断；`G#` 缺口；`Q#` 效力假设。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验重整章节与地方预重整口径；未见现行有效规则则预重整效力字段停止。`search_practiced` 补庭外重组与受理衔接。

工具不可用时继续事实、主体、程序文书状态和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　受理闸

已裁定受理或重整：负触发，转可行性或计划原子。口头“政府已经让我们预重整”不写成已进入法定程序。

### 节点 2　文件性质

备忘录、框架协议、债权人委员会意向、法院预重整工作指引分列。未签字不得写成已约束全体债权人。

### 节点 3　效力边界

预重整无权接管财产、无权当然中止执行。执行与担保实现仍可能继续，转金融只作背景。

### 节点 4　与法定重整接口

预重整成果如何进入申请、计划草案、表决，只列接口，不写计划终稿。

### 节点 5　并购与审查分流

普通交割转投资并购。只要改交易文件：审查起草本窗搁置。

## 停止与安全

- `整体停止`：把预重整包装成已受理；指导边谈边转移资产。
- `字段停止`：地方预重整规则未核验。
- `目标停止`：主目标变为法定重整计划或普通并购交割。
