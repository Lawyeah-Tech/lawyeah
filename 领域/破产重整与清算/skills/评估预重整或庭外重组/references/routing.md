# 边界与路由

## 正触发

尚未受理，拟预重整、庭外协议或招募投资人，需要效力边界。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 已进入重整，要可行性 | `评估重整可行性` |
| 要重整计划草案 | `准备重整计划草案` |
| 庭外让步谈判本身 | `谈判庭外或程序内债务调整` |
| 普通并购交割 | 投资并购领域 |
| 只要改重组合同 | 审查起草领域（本窗搁置） |
| 路径总图 | `评估破产重整和解路径` |

## 专项整案转出

见方法节点 0。一般借贷担保实现、公司治理日常只分流。审查起草本窗搁置，只说明不实施。

## 易混

预重整不是重整期间。庭外协议不是和解协议。招募投资人不是投资并购交割。
