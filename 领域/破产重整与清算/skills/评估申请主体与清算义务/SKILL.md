# 评估申请主体与清算义务

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把已失效《企业破产法（试行）》或 1991 年民事诉讼法企业法人破产还债程序当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“申请权与清算义务对照表”：谁有权申请、清算义务人是否必须申请、材料门槛差异。不代替申请书。

`depends-on` 为空。接受用户、律师、管理人、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：争议谁有权或谁必须提出破产申请；立场为债务人、债权人或清算义务人之一。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要申请书终稿（转对应申请原子）；
- 章程、股东会、日常股东争议（公司治理）；
- 能自行清算且足额清偿，只要普通清算安排（公司治理或 C 端 070）；
- 程序外催收（金融）；

公司日常治理只分流。清算义务人强制申请与债务人自愿申请材料门槛不同，不得混用。不保证法院认可申请权。

## 建立评估坐标

确认：使用者与授权；债务人解散、吊销、清算状态；申请人身份；股东、董事、清算组成员；已知债权人；是否已有申请在案。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 陈述；`D#` 登记或决议；`R#` 解散或强清文书；`C#` 章程职权；`L#` 规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验破产法第 7 条、公司法解散清算及清算义务人条文（2023 文本，不得用 2018 年旧义）；`search_practiced` 补强制申请实务。

工具不可用时继续事实、主体、程序文书状态和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　专项分流与角色锁定

先分流日常治理。同时代表债务人与某一债权人时整体停止。名称不一致不自动合并。

### 节点 2　自愿申请权

债务人、债权人申请权分列。债权人不能直接申请和解。出资人申请重整只在已核验的法定窗口打开。

### 节点 3　清算义务人强制申请

已解散未清算或未清算完毕且资产不足：核验公司法与破产法第 7 条第三款接口。能足额自行清算则不进本领域。

### 节点 4　材料门槛差异

债务人须财务职工接口；债权人主要证明到期债权和不能清偿；清算义务人须解散与资产不足接口。不得要求债权人提交完整账册作为申请前提。

### 节点 5　互斥与转介

已有债权人申请未裁定：评估异议／并案，不平行再交冲突申请。申请书只转介对应原子。

## 停止与安全

- `整体停止`：立场冲突；指导假清算或隐匿债务。
- `字段停止`：公司法清算义务人条号未核验；解散状态不明。
- `目标停止`：主目标变为申请书或日常股东会。
