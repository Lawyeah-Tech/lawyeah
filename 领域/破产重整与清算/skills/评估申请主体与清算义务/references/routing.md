# 边界与路由

## 正触发

争议谁有权或谁必须申请破产，需要申请权与清算义务对照，不要申请书。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 债务人申请书 | `准备债务人破产申请` |
| 债权人申请书 | `准备债权人破产申请` |
| 清算义务人申请书 | `准备清算义务人破产申请` |
| 强制清算转破产条件 | `评估强制清算转破产` |
| 章程或股东会日常 | 公司治理领域 |
| 路径总图 | `评估破产重整和解路径` |

## 专项整案转出

见方法节点 0。一般借贷担保实现、公司治理日常只分流。审查起草本窗搁置，只说明不实施。

## 易混

申请权评估不是申请书。清算义务人强制申请与债务人自愿申请不得混稿。日常人格否认或股东会争议转公司治理。
