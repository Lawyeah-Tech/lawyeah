# 申请主体评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变路径、受理、申报、顺位、撤销、取回、重整或分配结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然确认、唯一清偿率或唯一截止日。

`search_law` 返回已失效《企业破产法（试行）》、1991 年民诉法破产还债程序、已失效《合同法》或其解释时记为噪声，不得写入 `L#`。2002 年《最高人民法院关于审理企业破产案件若干问题的规定》与 2006 年企业破产法冲突的表述（包括“违约金不作为破产债权”）不得当现行主规则。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

企业破产法、公司法清算条文、司法解释的版本、条号和施行日一律运行时核验后写入 `L#`。不得沿用记忆条号。

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 破产尚未受理，主目标是催收、支付令、诉讼、仲裁或强制执行 | 金融借贷担保领域或 C 端 047／013 |
| 保证、抵押、质押、保理、融资租赁的程序外实现 | 金融借贷担保领域 |
| 职工安置、裁员方案、劳动合同终止实施、工资加班经济补偿测算 | 劳动领域 |
| 尚未进入程序，只要改合同、投资或交易文件 | 审查起草领域（本窗搁置，只说明不实施） |
| 普通股权或资产收购交割统筹 | 投资并购领域 |
| 章程、股东会、日常股东争议 | 公司治理领域 |
| 日常合规体系或内部调查 | 企业合规领域 |
| 虚假破产、妨害清算等需要定罪或辩护 | 刑事领域 |
| 自然人还债且不在已核验试点条例范围 | C 端 056；全国个人破产字段停止 |
| 只要关停对照或简易注销且未出现破产原因 | C 端 070 |

混合信号：企业已进入或即将进入法定破产程序的主轴可留本任务；金融实现或劳动安置只作为背景时在缺口标明，不把邻域规则硬套进本任务结论。

## 节点 1　角色与治理分流

若：主目标是章程修改、股东会召集、股权确权或董事任免 → 整案转公司治理，本任务只标破产接口。  
若：同时掌握债务人与某一债权人的对立策略 → 整体停止，先澄清代表哪一方。  
若：简易注销且未出现资产不足 → 转 C 端 070，不把清算义务人强制申请套上去。

---

## 节点 2　第 7 条申请权分列

运行时核验破产法第 7 条现行文本。

| 申请人 | 可申请程序 | 禁止写成 |
| --- | --- | --- |
| 债务人 | 重整、和解或清算 | 无须任何机关决议即可发送 |
| 债权人 | 重整或清算 | 债权人直接申请和解 |
| 清算义务人 | 破产清算（强制） | 与债务人自愿重整混为同一申请 |
| 出资人 | 仅在已核验窗口（如债权人申请清算后、宣告前申请重整） | 任何时候都可自行申请清算 |

若：用户是保证人、不是主债权人 → 申请权 `依据不足`，除非另有已核验的代位或受让事实。  
若：分支机构以自己名义申请总部破产 → 主体不适格，不打开发送闸。

---

## 节点 3　清算义务人强制申请

公司法 2023 文本条号运行时核验，不得用 2018 年旧义。  
已解散未清算或未清算完毕，且资产不足以清偿债务：清算义务人依法应当申请破产清算。

若：解散决议或吊销文书未见 → 解散状态字段停止。  
若：清算组已能证明财产足以清偿已知债务 → 现有依据不支持强制破产申请，转自行清算或公司治理。  
若：用户要求“做一套假清算报告再申请” → 整体停止。

强制清算转入的起算与材料交接转 `assess-compulsory-liquidation-conversion`，本节点只判断申请义务是否打开。

---

## 节点 4　材料门槛

- 债务人：财产状况、债权债务清册、财务报告、职工接口。未知不写零。  
- 债权人：到期债权与不能清偿初步证明；不得因缺少债务人完整财务而拒绝整理门槛，也不得编造财务。  
- 清算义务人：解散／未清算事实、资产不足迹象、义务人身份证明。

材料是否“齐全”的法律结论依赖未核验条文则字段停止。本任务不产出发送前申请书。

---

## 节点 5　互斥

已有债权人申请未裁定：优先评估债务人异议窗口，不平行再交一份债务人申请冒充唯一路径。  
宣告破产后不得打开重整申请权。  
下一步只转介对应申请原子或异议原子。
