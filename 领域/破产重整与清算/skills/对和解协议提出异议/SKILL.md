# 对和解协议提出异议

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把已失效《企业破产法（试行）》或 1991 年民事诉讼法企业法人破产还债程序当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

形成“异议和不予认可事由”。与重整计划异议不同。

`depends-on` 为空。接受用户、律师、管理人、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：债权人认为和解协议欺诈、损害其合法权益或程序违法。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 对重整计划异议；
- 债务人写协议草案；
- 指导恶意阻挠会议；

不予认可事由与计划强制批准保护标准不同。担保债权人本就可能不受协议约束。不保证法院不予认可。

## 建立评估坐标

确认：协议文本、表决过程、隐瞒财产线索、异议人是否受协议约束。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`C#` 协议；`D#` 欺诈线索；`R#` 表决；`L#` 规则；`I#` 判断。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验第 98、99、103 条。

工具不可用时继续事实、主体、程序文书状态和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　对象闸

文书须是和解协议不是重整计划。

### 节点 2　事由

欺诈、程序违法、损害债权人一般利益。

### 节点 3　担保例外

不受约束的担保债权人异议重点不同。

### 节点 4　与计划异议差异

无第 87 条清算比较强制结构。

### 节点 5　禁止恶意

不提供搅会方案。

## 停止与安全

- `整体停止`：恶意阻挠或伪造欺诈证据。
- `字段停止`：不予认可事由条文未核验。
- `目标停止`：主目标变为计划异议或草案。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
