# 准备破产债权申报

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把已失效《企业破产法（试行）》或 1991 年民事诉讼法企业法人破产还债程序当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的债权人立场下，形成“发送前破产债权申报包”：公告期限原文、本金利息停点、担保／连带／抵销标记、证据目录和申报表结构。

`depends-on` 为空。接受用户、律师、管理人、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：人民法院已裁定受理破产申请，用户是债权人，目标是在申报期内准备申报材料。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未受理，要催收、执行或选程序（金融或 C 端 047／013）；
- 只要路径总图或破产申请；
- 职工法定项目（工资、医疗伤残抚恤、个人账户基本养老／医疗、法定补偿金）主轴——这些不必申报，转清单异议或劳动测算；
- 用户只要大众普通货款材料清单且明确要 C 端 052；
- 劳动安置或 N+1 终稿（劳动）；

C 端 052 只分流：专业包处理担保、抵销、争议债权和顺位接口，不降成 052，不回改 052。期限只摘原文，不换算唯一截止日。

## 建立评估坐标

确认：公告或管理人通知全文；案号；管理人；申报期限原文；债权基础；已收；担保；互负债务；生效文书；是否已个别受偿。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`N#` 公告裁定通知；`C#` 合同；`P#` 履行付款；`R#` 对账或生效文书；`S#` 陈述；`L#` 规则；`I#` 判断；`G#` 缺口；`Q#` 申报项；`V#` 稿件版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验第 16、19、45、46、48、49、56 条；`search_template` 只借申报表栏目。

工具不可用时继续事实、主体、程序文书状态和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 受理闸与期限原文

无受理裁定、公告且无管理人通知：不得输出可提交终稿。期限只摘原文。禁止把最短三十日、最长三个月加成 YYYY-MM-DD。禁止套用公司法清算三十日／四十五日。原文显示可能已过：停止普通终稿，只做补报风险交接。

### 2. 债权性质分流

职工法定项目：标明不必申报，转清单更正或劳动。担保、抵销、连带单独标记。普通金钱债权继续。

### 3. 金额与停息

本金、利息、违约金、已收分行。计息停点是受理日，不是申报日。受理后新息一般不列入。未知不写零。不输出清偿率。

### 4. 证据与申报表结构

管理人当期表格优先。未见则结构稿，标发送前复核。不得保证确认。

### 5. 个别清偿与执行中止

受理后个别受偿标红旗。并行执行申请整段转 013 交接，不继续生成执行终稿。

## 停止与安全

- `整体停止`：伪造债权、隐匿已收、倒签、要求保证分配。
- `字段停止`：受理日、期限原文、利率规则未核验。
- `目标停止`：主目标变为债权表异议、确认之诉或劳动待遇测算。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
