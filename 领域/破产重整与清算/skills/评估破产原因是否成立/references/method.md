# 原因核验方法

本文件是可执行判断节点，不是栏目说明书。每个会改变路径、受理、申报、顺位、撤销、取回、重整或分配结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然确认、唯一清偿率或唯一截止日。

`search_law` 返回已失效《企业破产法（试行）》、1991 年民诉法破产还债程序、已失效《合同法》或其解释时记为噪声，不得写入 `L#`。2002 年《最高人民法院关于审理企业破产案件若干问题的规定》与 2006 年企业破产法冲突的表述（包括“违约金不作为破产债权”）不得当现行主规则。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

企业破产法、公司法清算条文、司法解释的版本、条号和施行日一律运行时核验后写入 `L#`。不得沿用记忆条号。

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 破产尚未受理，主目标是催收、支付令、诉讼、仲裁或强制执行 | 金融借贷担保领域或 C 端 047／013 |
| 保证、抵押、质押、保理、融资租赁的程序外实现 | 金融借贷担保领域 |
| 职工安置、裁员方案、劳动合同终止实施、工资加班经济补偿测算 | 劳动领域 |
| 尚未进入程序，只要改合同、投资或交易文件 | 审查起草领域（本窗搁置，只说明不实施） |
| 普通股权或资产收购交割统筹 | 投资并购领域 |
| 章程、股东会、日常股东争议 | 公司治理领域 |
| 日常合规体系或内部调查 | 企业合规领域 |
| 虚假破产、妨害清算等需要定罪或辩护 | 刑事领域 |
| 自然人还债且不在已核验试点条例范围 | C 端 056；全国个人破产字段停止 |
| 只要关停对照或简易注销且未出现破产原因 | C 端 070 |

混合信号：企业已进入或即将进入法定破产程序的主轴可留本任务；金融实现或劳动安置只作为背景时在缺口标明，不把邻域规则硬套进本任务结论。

## 节点 1　主体与个人破产闸

1. 固定债务人名称、统一社会信用代码、企业法人资格。分支机构名称不得自动并入总部。
2. 若：用户是自然人、个体工商户或个人独资且主债是个人消费或经营混合 → 先核验是否存在现行有效的地方个人破产条例且事实落在该法域。核验失败或落在条例外：个人破产结论字段停止，转 C 端 056。
3. 若：银行、证券、保险或上市公司 → 特别程序字段停止或标接口，不把普通企业原因规则写成已够用。
4. 同时掌握双方秘密或立场不明：整体停止策略输出。

## 节点 2　不能清偿到期债务

运行时核验解释一第 2 条后再落判断。核验失败则本节点法律结论字段停止，事实清单继续。

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 单笔货款逾期 | 已具备破产原因 |
| 正在另案诉讼、尚无生效确认 | 债权已确定到期 |
| 已部分清偿但清册把已收款抹掉 | 未清偿余额为零或全额 |
| 用户“准备今天申请” | 法院应当认定不能清偿 |

若：债权成立、履行期届满、未完全清偿三项同时可回链 → `Q-不能清偿` 可标现有依据支持。  
若：缺任一项 → 该项 `依据不足`，不得用另外两项补成原因成立。  
若：履行期未届满，除非依法视为到期的法定情形已核验 → 不得写入不能清偿。

---

## 节点 3　资产不足以清偿全部债务

资产侧与负债侧必须分列来源。账面净资产为负但大量或然债务、未入账担保或未审存货时，并列 `账面情景` 与 `评估情景`，禁止挑选有利一版写成终局资不抵债。

若：只有一张未经审计的内部试算表 → 资不抵债结论字段停止，试算表只作 `D#`。  
若：资产评估与账面冲突 → 两套数字都进入 `Q#`，判断写 `依据不足，无法形成结论` 或并列情景，不得平均。  
未知金额不写零。

---

## 节点 4　明显缺乏清偿能力

运行时核验解释一第 4 条情形（资金严重不足、财产不能变现、法定代表人下落不明且无人管理财产、经强制执行无法清偿等）。未核验条文则本节点停止法律结论。

若：仍在经营且账户有余额 → 不得写成当然不具备原因，只记录与第 4 条各款的对照缺口。  
若：执行终结本次执行或长期无财产 → 可作为支持事实之一，仍不得单独写成法院必须受理。  
若：用户只主张“市场不好、明年可能好转” → 现有依据不支持据此否定原因。

---

## 节点 5　反证、保证人与输出边界

解释一第 1 条第二款：相关当事人对债务人的给付义务或连带责任，不得单独用来否定债务人具备破产原因。保证人、抵押人“还有钱”写入不利／反方栏，不得写成债务人不具备原因。

明显丧失清偿能力可能只打开重整候选接口，不得据此写应清算。下一步只转介路径评估或申请原子，本任务不产出发送前申请。禁止补造对账单或倒签催告日。
