# 边界与路由

## 正触发

单独核验企业是否具备破产原因，不要整张路径总图或申请书。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 要清算／重整／和解总图 | `评估破产重整和解路径` |
| 债务人已决定申请 | `准备债务人破产申请` |
| 债权人已决定申请 | `准备债权人破产申请` |
| 程序外催收或执行 | 金融领域或 C 端 047／013 |
| 自然人还债 | C 端 056；试点个人破产未安装则 `unavailable` |

## 专项整案转出

见方法节点 0。一般借贷担保实现、公司治理日常只分流。审查起草本窗搁置，只说明不实施。

## 易混

原因专项评估不吞并路径总图。已决定申请且只要申请书时负触发。保证人有清偿能力不能写成债务人无原因。
