# 边界与路由

## 正触发

刚受理，需要列出中止、保全解除、个别清偿无效和已发生行为。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 尚未受理 | `评估破产重整和解路径` |
| 要申报 | `准备破产债权申报` |
| 要撤销已发生清偿 | `准备破产撤销或无效之诉` |
| 执行申请或担保实现 | 金融领域 |
| 抵销定性 | `评估破产抵销` |

## 专项整案转出

见方法节点 0。一般借贷担保实现、公司治理日常只分流。审查起草本窗搁置，只说明不实施。

## 易混

受理效果清单不是执行申请。受理后付款不是“先清一笔没问题”。未见到裁定不得写已中止。
