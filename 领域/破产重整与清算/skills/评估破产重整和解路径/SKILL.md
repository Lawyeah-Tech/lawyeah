# 评估破产重整和解路径

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把已失效《企业破产法（试行）》或 1991 年民事诉讼法企业法人破产还债程序当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“破产重整和解路径总体评估矩阵”：主体和程序状态、清偿危机事实时间线、破产原因情景、清算／重整／和解比较、受理后效果、缺口、对方最强解释和下一步。

`depends-on` 为空。接受用户、律师、管理人、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：中国大陆企业法人或依法可适用企业破产法的组织已出现不能清偿到期债务、资不抵债或明显缺乏清偿能力迹象，用户仍需决定是否进入法定程序以及选哪一条轨道。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主目标是破产程序外催收、支付令、诉讼或执行（金融或 C 端 047／013）；
- 只要发送版破产申请、申报表或撤销起诉状；
- 只要精算工作表或完整证据卷；
- 职工安置、劳动合同终止或劳动待遇测算（劳动）；
- 尚未出现破产原因，只要关停对照或简易注销（C 端 070）；
- 自然人还债且不在已核验试点条例范围（C 端 056）；

本任务不生成发送版申请书、可提交申报或撤销诉状，不给受理率或清偿率。C 端 052／070／056／047 只分流，不回改。

## 建立评估坐标

确认：使用者与授权；单方立场；债务人主体类型；相对方及可能申请权人；法域；是否已解散、强制清算或被申请；当前执行、保全、诉讼状态；资产负债与到期债务材料；职工与税务缺口是否仅作背景；关键材料及缺失。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 章程决议或合同定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径假设；`V#` 评估版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验破产法第 2、7 条，解释一第 1–5 条，公司法转破产接口；`search_practiced` 补路径与反例；特殊事实用 `search_case_by_fact`。不虚构案件系统。

工具不可用时继续事实、主体、程序文书状态和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 专项分流、主体适格和个人破产闸

先做专项分流。自然人且无法核验试点条例：个人破产字段停止，转 056。金融机构或上市公司特别程序标接口，不假装普通企业规则已经够用。名称不一致不自动合并。

### 2. 破产原因情景

分列不能清偿到期债务、资产不足以清偿全部债务、明显缺乏清偿能力、明显丧失清偿能力可能（仅重整）。连带责任人仍有清偿能力不得写成债务人不具备原因。解释一未核验则原因结论字段停止。

### 3. 清算、重整、和解比较

清算、重整、和解分列法律效果、申请权人、材料负担、营业能否继续、表决负担和不可逆后果。构成不能清偿不等于当然应清算。债权人依法不能直接申请和解。

### 4. 受理后效果与期限接口

个别清偿无效、执行中止、停止计息、管理人接管只列效果，不写成已经发生。未见到受理裁定不得写申报期截止日。

### 5. 证据、反方和下一步

下一步按原因灭失风险、易失财产、申请不可逆性排序。申请、申报、撤销、安置、催收只标转介，不在本包做出发送终稿。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体无法建立；用户坚持隐匿财产、虚假破产、毁账或违法取证。
- `字段停止`：法域、原因规则、解散清算状态、动态规则未核验。
- `目标停止`：主目标已变为申请书、申报、测算终稿、证据卷或衍生诉讼文书。
