# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变路径、受理、申报、顺位或撤销结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然确认、唯一清偿率或唯一截止日。

`search_law` 返回已失效《企业破产法（试行）》、1991 年民诉法破产还债程序、已失效《合同法》或其解释时记为噪声，不得写入 `L#`。2002 年《最高人民法院关于审理企业破产案件若干问题的规定》与 2006 年企业破产法冲突的表述（包括“违约金不作为破产债权”）不得当现行主规则。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

企业破产法、公司法清算条文的版本、条号和施行日一律运行时核验后写入 `L#`。不得沿用记忆条号。


## Q# 路径矩阵

固定列：`编号｜路径｜提出方｜相对方｜法律效果｜成立条件｜支持事实｜不利事实｜控制方｜最强反方｜主备位｜判断｜待核`。

至少分列：`Q-清` 破产清算；`Q-整` 重整；`Q-和` 和解；`Q-强` 强制清算转破产；`Q-庭` 继续庭外重组；`Q-金` 程序外债权实现（转出）；`Q-劳` 职工安置接口（转出）。构成不能清偿不等于当然清算。

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 破产尚未受理，主目标是催收、支付令、诉讼、仲裁或强制执行 | 金融借贷担保领域或 C 端 047／013 |
| 保证、抵押、质押、保理、融资租赁的程序外实现 | 金融借贷担保领域 |
| 职工安置、裁员方案、劳动合同终止实施、工资加班经济补偿测算 | 劳动领域 |
| 尚未进入程序，只要改合同、投资或交易文件 | 审查起草领域（本窗搁置，只说明不实施） |
| 普通股权或资产收购交割统筹 | 投资并购领域 |
| 章程、股东会、日常股东争议 | 公司治理领域 |
| 日常合规体系或内部调查 | 企业合规领域 |
| 虚假破产、妨害清算等需要定罪或辩护 | 刑事领域 |
| 自然人还债且不在已核验试点条例范围 | C 端 056；全国个人破产字段停止 |
| 只要关停对照或简易注销且未出现破产原因 | C 端 070 |

混合信号：企业已进入或即将进入法定破产程序的主轴可留本任务；金融实现或劳动安置只作为背景时在缺口标明，不把邻域规则硬套进本任务结论。

## 节点 1　主体适格、解散状态和个人破产闸

1. 固定债务人名称、统一社会信用代码、企业法人资格、分支机构。名称不一致不自动合并。
2. 已解散未清算或未清算完毕：单列清算义务人是否依法必须申请破产清算。公司法 2023 文本条号运行时核验；不得用 2018 年旧义。
3. 若：用户是自然人、个体工商户或个人独资且主债是个人消费或经营混合 → 先核验是否存在现行有效的地方个人破产条例且事实落在该法域。核验失败或落在条例外：个人破产结论字段停止，转 C 端 056，不把企业破产法直接套到个人免责。
4. 若：银行、证券、保险或上市公司 → 特别程序字段停止或标接口，不把普通企业受理规则写成已够用。
5. 同时掌握双方秘密或立场不明：整体停止策略输出。

## 节点 2　破产原因情景

运行时核验破产法第 2 条和解释一第 1–4 条后再落判断。核验失败则本节点法律结论字段停止，事实与问题清单继续。

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 单笔到期未付 | 已具备破产原因 |
| 资产负债表为负但大量或然债务未入账 | 已资不抵债终局 |
| 仍在经营、账户有余额 | 当然不具备原因 |
| 保证人仍有钱 | 债务人不具备原因（解释一第 1 条第二款相反） |
| 用户想今天申请 | 法院应当受理 |

1. **不能清偿到期债务**（解释一第 2 条）：债权成立、履行期届满、未完全清偿三项同时存在才支持。诉讼未决的债权标并行情景。
2. **资产不足以清偿全部债务**：资产与负债均需材料；账面数与评估数冲突则并列，不选对用户有利的一版。
3. **明显缺乏清偿能力**：解释一第 4 条情形（资金严重不足、财产不能变现、法定代表人下落不明、经执行无法清偿等）逐项对照，未核验条文则字段停止。
4. **明显丧失清偿能力可能**：只打开重整候选，不得据此写应清算。
5. 关键日期或报表冲突建并行情景，不给唯一原因结论。

## 节点 3　清算、重整、和解比较

本节点只判断路径，不生成申请书。

若：用户只要庭外减免且明确拒绝进法院 → `Q-庭` 可作主位，但须写明无执行力、个别清偿风险，并转 `negotiate-debt-adjustment`（未安装则 `unavailable`）。  
若：财产明显不足、无营业价值、无投资人线索 → `Q-清` 可作主位候选，仍不得写“应当受理”。  
若：有持续经营、主要债权人意向或投资人接触 → `Q-整` 可并列，转介可行性原子，不在本任务做可行性终局。  
若：债权人要求申请和解 → 现有依据不支持债权人直接申请和解；写明仅债务人可申请和解。  
若：已在强制清算且资产不足 → `Q-强` 打开，转介强制清算转破产原子（未安装则记录接口）。

主备位和互斥必须可见。`Q-清` 与 `Q-整` 不得同时写成均已成立为唯一正确轨道。

## 节点 4　受理后效果（尚未受理不得写成已发生）

分别列出，且每项绑定“仅在裁定受理后”：

- 个别清偿无效（第 16 条）；
- 执行程序中止（第 19 条）；
- 附利息债权停止计息（第 46 条）；
- 指定管理人、通知债权人、确定申报期（第 45 条：最短三十日、最长三个月，只作期间名称，不换算截止日）。

没有受理裁定或案号，禁止写“已破产”“已免责”“申报期至某日”。

## 节点 5　证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。

下一步按财产流失、原因证据灭失、申请不可逆性排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。

申请书、申报、撤销、安置、催收只写转介条件和最小交接。禁止指导隐匿、转移、虚假申报或毁账。
