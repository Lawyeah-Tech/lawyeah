# 边界与路由

## 正触发

中国大陆企业已现清偿危机，单方需要总体决定是否进入法定破产、重整或和解，以及下一步。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 程序外催收、支付令、诉讼或执行 | 金融领域或 C 端 047／013 |
| 出债务人申请 | `准备债务人破产申请` |
| 出债权人申请 | `准备债权人破产申请` |
| 对已收到的申请提异议 | `对破产受理提出异议` |
| 已受理，要申报 | `准备破产债权申报` |
| 精算顺位 | `测算债权额性质与清偿顺位` |
| 完整证据卷 | `建立破产程序证据案卷` |
| 判断重整是否可行 | `评估重整可行性` |
| 职工安置或待遇测算 | 劳动领域 |
| 关停对照且无破产原因 | C 端 070 |
| 自然人还债 | C 端 056；试点个人破产未安装则 `unavailable` |

## 专项整案转出

见方法节点 0。一般企业夹带欠薪或担保时，专项段只分流。

## 易混

尚在比较清算还是重整时正触发。主体、路径、申请权人均确认且只要申请书时负触发。尚未受理却要求“直接写申报表”时，先完成本任务或提示尚未起算申报期，不改写成申报原子。
