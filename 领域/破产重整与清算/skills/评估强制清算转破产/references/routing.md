# 边界与路由

## 正触发

强制清算中或拟强清时出现资不抵债，要判断转破产条件与起算点。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 清算义务人申请书 | `准备清算义务人破产申请` |
| 申请权本身 | `评估申请主体与清算义务` |
| 能足额自行清算 | 公司治理或普通清算，不进本领域 |
| 简易注销 | C 端 070 |
| 撤销起算在已转入后的诉讼 | `准备破产撤销或无效之诉` |

## 专项整案转出

见方法节点 0。一般借贷担保实现、公司治理日常只分流。审查起草本窗搁置，只说明不实施。

## 易混

强清案号不是破产案号。转入起算不得默认用破产受理日。能足额清偿的强清不进本领域。
