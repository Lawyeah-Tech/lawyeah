# 破产重整清算领域边界

本表只说明归属。每次路由先核对 [当前能力地图](capability-map.md)；未安装入口输出 `unavailable`。

| 相邻 | 本包入口 | 转出 |
| --- | --- | --- |
| 金融借贷担保 | 已受理后的申报、别除权在分配中的范围、担保债权确认 | 破产程序外的催收、支付令、执行、担保物权实现 |
| 劳动用工 | 职工债权清单、异议、破产分配顺位 | 职工安置、劳动合同终止实施、工资加班经济补偿测算 |
| 合同审查与起草 | 无。未进入程序只要改合同或出稿：本窗搁置，只说明不实施 | 审查起草领域（用户单独策略） |
| 投资并购 | 重整投资与计划衔接的程序接口 | 普通股权或资产收购交割统筹 |
| 公司治理 | 清算义务人强制申请、出资追收的破产接口 | 章程、股东会、日常股东争议 |
| 企业合规 | 无 | 日常合规体系和内部调查 |
| 刑事 | 评估中的刑民交叉只标红旗 | 定罪、控告、辩护 |
| 合同争议 | 破产撤销／无效 | 民法典债权人撤销权、一般合同一审 |
| C 端 052 | 专业申报，含担保／抵销／争议债权接口 | 大众普通无争议金钱债权材料清单 |
| C 端 070 | 已现破产原因则进入本包 | 尚未出现原因的关停对照、简易注销 |
| C 端 056 | 仅已核验试点条例下的个人破产适格（本包未安装则 `unavailable`） | 全国个人还债规划 |
| C 端 047 | 已受理则申报，不再选支付令／诉讼 | 尚未受理时的程序选择 |

一般企业夹带专项背景时，专项段只分流，不把金融实现或劳动安置规则写入本包结论。
