# 边界与路由

## 正触发

要判断税、滞纳金、统筹社保在破产程序内的性质与顺位。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 税务实体争议 | 税务领域 |
| 社保补缴或工伤路径 | 劳动领域 |
| 职工个人账户清单 | `编制职工债权清单` |
| 瀑布测算 | `测算分配瀑布与清偿区间` |
| 普通债权测算 | `测算债权额性质与清偿顺位` |

## 专项整案转出

见方法节点 0。一般借贷担保实现、公司治理日常只分流。审查起草本窗搁置，只说明不实施。

## 易混

税款滞纳金不是当然与税款本金同一顺位。个人账户社保不是税款。税务复议不在本任务做。
