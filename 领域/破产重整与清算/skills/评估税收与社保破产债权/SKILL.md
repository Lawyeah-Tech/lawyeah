# 评估税收与社保破产债权

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把已失效《企业破产法（试行）》或 1991 年民事诉讼法企业法人破产还债程序当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

形成“税、滞纳金、统筹社保在程序内的性质、顺位和滞纳金停止点”。税务争议实体转税务。社保补缴路径转劳动。

`depends-on` 为空。接受用户、律师、管理人、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：税务机关、社保机构或债务人／管理人需要判断税款、滞纳金、罚款、统筹社保在破产中的申报确认与顺位。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 税务核定、复议、诉讼实体（税务）；
- 社保补缴、工伤待遇路径（劳动）；
- 职工个人账户项目编制（职工清单原子）；
- 唯一清偿率测算；

税款与职工个人账户项目不得混行。滞纳金停止点须核验，不得沿用失效合同法或 2002 年冲突规定。罚款性质待核，不得一律当普通债权或一律排除。

## 建立评估坐标

确认：税种与所属期；滞纳金起算；罚款决定；社保统筹与个人账户拆分；受理日。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`R#` 税务或社保文书；`T#` 所属期；`L#` 规则；`I#` 判断；`G#` 缺口；`Q#` 顺位假设。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验第 113 条、税收征管与破产衔接口径、滞纳金是否随受理停止。

工具不可用时继续事实、主体、程序文书状态和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　拆分

本金、滞纳金、罚款、滞纳金加收、社会保险统筹部分、个人账户部分分列。

### 节点 2　顺位

第 113 条税款与社保统筹接口。职工个人账户走职工清单。

### 节点 3　停止点

受理后滞纳金、罚息是否停止，运行时核验。未核验则停止点字段停止。

### 节点 4　实体转出

应纳税额争议转税务。补缴路径转劳动。

### 节点 5　申报

谁申报、是否视同申报待核。未知不写零。

## 停止与安全

- `整体停止`：指导隐匿税基或伪造完税。
- `字段停止`：第 113 条、滞纳金停止规则未核验。
- `目标停止`：主目标变为税务复议或劳动补缴。
