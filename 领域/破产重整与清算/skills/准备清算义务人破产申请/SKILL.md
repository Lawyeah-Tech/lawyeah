# 准备清算义务人破产申请

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把已失效《企业破产法（试行）》或 1991 年民事诉讼法企业法人破产还债程序当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在已解散未清算或未清算完毕且资产不足时，形成“清算义务人强制申请发送前材料”：义务人身份、解散与资产不足接口、申请书草稿。能足额自行清算不进。假清算停止。

`depends-on` 为空。接受用户、律师、管理人、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：清算义务人已决定依法申请破产清算，解散事实与资产不足有材料支持。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 能足额自行清算；
- 债务人自愿申请重整或和解（转债务人申请）；
- 债权人申请（转债权人申请）；
- 假清算、补造清算报告；
- 简易注销（C 端 070）；

本任务只形成待提交材料，不代提交，不保证受理。申请目的限于破产清算，不得顺手写成重整提高受理率。

## 建立评估坐标

确认：解散或吊销文书；清算义务人范围与授权；资产不足材料；已知债务；是否已有强清或债权人申请。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`R#` 解散或吊销；`C#` 义务人决议；`D#` 财产；`L#` 规则；`I#` 判断；`G#` 缺口；`V#` 稿件版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验破产法第 7 条第三款、第 8 条及公司法清算义务人条文；`search_template` 只借申请书栏目。

工具不可用时继续事实、主体、程序文书状态和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　义务与授权闸

身份不是清算义务人则负触发。无内部授权或多人义务人互相推诿：授权字段停止。假清算整体停止。

### 节点 2　解散与资产不足

两要件分列。能足额清偿则目标停止。未知不写零。

### 节点 3　程序类型锁定

强制申请对应破产清算。要重整须另有已核验窗口，不得在本申请书混写。

### 节点 4　材料与职工接口

按第 8 条能提交的提交；清算未完的说明缺口。安置方案转劳动。

### 节点 5　管辖与不可逆

连结点待核。不代提交。禁止隐匿剩余财产。

## 停止与安全

- `整体停止`：假清算；隐匿债务或剩余财产；立场不明。
- `字段停止`：公司法义务人条号、解散状态未核验。
- `目标停止`：能足额自行清算或主目标变为重整申请。
