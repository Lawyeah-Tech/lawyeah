# 边界与路由

## 正触发

已解散未清算或未清算完毕且资产不足，清算义务人要提出破产清算申请。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 申请权尚有争议 | `评估申请主体与清算义务` |
| 强制清算转破产条件 | `评估强制清算转破产` |
| 债务人自愿重整或和解 | `准备债务人破产申请` |
| 能足额自行清算 | 不进本领域 |
| 简易注销 | C 端 070 |

## 专项整案转出

见方法节点 0。一般借贷担保实现、公司治理日常只分流。审查起草本窗搁置，只说明不实施。

## 易混

清算义务人申请不是债务人重整申请。假清算报告不能当申请附件。能足额清偿应自行清算。
