# 分配方案方法

本文件是可执行判断节点，不是栏目说明书。每个会改变路径、受理、申报、顺位、撤销、取回、重整或分配结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然确认、唯一清偿率或唯一截止日。

`search_law` 返回已失效《企业破产法（试行）》、1991 年民诉法破产还债程序、已失效《合同法》或其解释时记为噪声，不得写入 `L#`。2002 年《最高人民法院关于审理企业破产案件若干问题的规定》与 2006 年企业破产法冲突的表述（包括“违约金不作为破产债权”）不得当现行主规则。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

企业破产法、公司法清算条文、司法解释的版本、条号和施行日一律运行时核验后写入 `L#`。不得沿用记忆条号。

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 破产尚未受理，主目标是催收、支付令、诉讼、仲裁或强制执行 | 金融借贷担保领域或 C 端 047／013 |
| 保证、抵押、质押、保理、融资租赁的程序外实现 | 金融借贷担保领域 |
| 职工安置、裁员方案、劳动合同终止实施、工资加班经济补偿测算 | 劳动领域 |
| 尚未进入程序，只要改合同、投资或交易文件 | 审查起草领域（本窗搁置，只说明不实施） |
| 普通股权或资产收购交割统筹 | 投资并购领域 |
| 章程、股东会、日常股东争议 | 公司治理领域 |
| 日常合规体系或内部调查 | 企业合规领域 |
| 虚假破产、妨害清算等需要定罪或辩护 | 刑事领域 |
| 自然人还债且不在已核验试点条例范围 | C 端 056；全国个人破产字段停止 |
| 只要关停对照或简易注销且未出现破产原因 | C 端 070 |

混合信号：企业已进入或即将进入法定破产程序的主轴可留本任务；金融实现或劳动安置只作为背景时在缺口标明，不把邻域规则硬套进本任务结论。


---

## 节点 1　前提

分配方案以已确认或依法可分配的债权为基础。大量债权未决：应提存或说明，不得当不存在。财产尚未变价：可做预分配结构，但须标明待变现，禁止把评估值写成已分配现金。

---

## 节点 2　第 113 条

顺序：破产费用和共益债务随时清偿前提下，职工债权 → 社保税费 → 普通破产债权。别除权就担保物优先，不进入本表混排。约定劣后、股东借款劣后待核。禁止为关联方插队。

职工待遇测算转劳动；方案只引用职工清单总额状态。

---

## 节点 3　提存

诉讼未决债权、未受领、附生效条件、担保物估价超过债权部分等提存情形运行时核验第 117–119 条。未核验则提存范围字段停止。提存期限与归属不明不编造。

---

## 节点 4　程序

方案提交债权人会议讨论，再请法院裁定认可（条文待核）。异议转 `object-to-distribution-plan`。本任务不伪造会议通过。

---

## 节点 5　数字

每层用已核实／情景／无法估计。用户索要“普通债权清偿率就是 x%”：拒绝唯一比率。多次分配须编号，已分配不得让补报债权人回转，除非另有已核验依据。
