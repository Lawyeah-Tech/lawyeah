# 边界与路由

## 正触发

需要选择或核验破产案件受理法院，出现住所地、集中管辖或关联管辖争议。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 申请书 | 对应债务人／债权人／清算义务人申请原子 |
| 实质合并实体判断 | `评估关联企业实质合并` |
| 海事或船舶管辖 | 海事领域 |
| 金融机构特别程序 | 未安装则 `unavailable`；日常合规转企业合规 |
| 执行管辖 | 金融或执行程序 |

## 专项整案转出

见方法节点 0。一般借贷担保实现、公司治理日常只分流。审查起草本窗搁置，只说明不实施。

## 易混

管辖评估不是申请书。登记住所不等于当然唯一连结点。关联管辖不是当然实质合并。
