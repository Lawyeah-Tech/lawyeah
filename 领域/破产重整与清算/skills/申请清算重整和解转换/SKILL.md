# 申请清算重整和解转换

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把已失效《企业破产法（试行）》或 1991 年民事诉讼法企业法人破产还债程序当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在已受理某一程序、宣告破产前，形成“转换条件、时点与材料表”。宣告破产后不得假装仍可重整。

`depends-on` 为空。接受用户、律师、管理人、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：案件已裁定受理清算、重整或和解之一，拟在宣告破产前转换为另一程序。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未受理，只要选路径或首次申请；
- 已宣告破产仍要求转入重整或和解；
- 只要可行性终局或计划草案终稿；
- 对不予受理上诉；

转换窗口在宣告破产前关闭。债权人依法不能直接申请和解。转换不是重新立案，须回链原案号。

## 建立评估坐标

确认：受理裁定与程序类型；是否已宣告；申请人身份；转换方向；出资人持股；债权人态度材料。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`R#` 受理或宣告裁定；`S#` 陈述；`D#` 意向；`L#` 规则；`I#` 判断；`G#` 缺口；`Q#` 转换方向。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验第 70、78、95 条及宣告前转换窗口；`search_practiced` 补转换实务。

工具不可用时继续事实、主体、程序文书状态和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　阶段闸

未见受理裁定：负触发。已宣告：转换重整／和解字段停止。

### 节点 2　主体与方向

清算转重整、重整转清算、转和解分列。债权人申请和解现有依据不支持。

### 节点 3　法定时点与条件

出资人申请重整的持股比例等运行时核验。未核验则条件字段停止，不打开发送闸。

### 节点 4　材料

转换申请草稿、可行性或协议接口。不代替计划或和解协议终稿。

### 节点 5　互斥与不可逆

宣告后不得假装窗口仍在。不保证法院准许转换。

## 停止与安全

- `整体停止`：伪造未宣告状态；指导边转换边转移资产。
- `字段停止`：第 70、95 条条件未核验。
- `目标停止`：尚未受理或已宣告仍要重整。
