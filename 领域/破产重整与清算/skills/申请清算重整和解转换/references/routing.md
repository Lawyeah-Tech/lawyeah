# 边界与路由

## 正触发

已受理某一程序，拟在宣告破产前转换为清算、重整或和解。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 尚未受理，选路径 | `评估破产重整和解路径` |
| 首次申请 | 对应申请原子 |
| 重整可行性 | `评估重整可行性` |
| 终止重整并宣告 | `申请终止重整并宣告破产` |
| 已宣告仍要重整 | 负触发；窗口已关闭 |

## 专项整案转出

见方法节点 0。一般借贷担保实现、公司治理日常只分流。审查起草本窗搁置，只说明不实施。

## 易混

转换不是重新立案。宣告后不能假装仍可重整。债权人不能直接申请和解。
