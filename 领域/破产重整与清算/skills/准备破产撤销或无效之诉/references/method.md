# 诉讼准备方法

本文件是可执行判断节点，不是栏目说明书。每个会改变路径、受理、申报、顺位或撤销结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然确认、唯一清偿率或唯一截止日。

`search_law` 返回已失效《企业破产法（试行）》、1991 年民诉法破产还债程序、已失效《合同法》或其解释时记为噪声，不得写入 `L#`。2002 年《最高人民法院关于审理企业破产案件若干问题的规定》与 2006 年企业破产法冲突的表述（包括“违约金不作为破产债权”）不得当现行主规则。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

企业破产法、公司法清算条文的版本、条号和施行日一律运行时核验后写入 `L#`。不得沿用记忆条号。

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 破产尚未受理，主目标是催收、支付令、诉讼、仲裁或强制执行 | 金融借贷担保领域或 C 端 047／013 |
| 保证、抵押、质押、保理、融资租赁的程序外实现 | 金融借贷担保领域 |
| 职工安置、裁员方案、劳动合同终止实施、工资加班经济补偿测算 | 劳动领域 |
| 尚未进入程序，只要改合同、投资或交易文件 | 审查起草领域（本窗搁置，只说明不实施） |
| 普通股权或资产收购交割统筹 | 投资并购领域 |
| 章程、股东会、日常股东争议 | 公司治理领域 |
| 日常合规体系或内部调查 | 企业合规领域 |
| 虚假破产、妨害清算等需要定罪或辩护 | 刑事领域 |
| 自然人还债且不在已核验试点条例范围 | C 端 056；全国个人破产字段停止 |
| 只要关停对照或简易注销且未出现破产原因 | C 端 070 |

混合信号：企业已进入或即将进入法定破产程序的主轴可留本任务；金融实现或劳动安置只作为背景时在缺口标明，不把邻域规则硬套进本任务结论。


若：破产尚未受理，主轴是民法典第 538、539 条 → 整案转合同争议撤销权原子，不把破产一年／六个月套上去。

## 节点 1　原告适格

若：管理人拒绝追收且债权人拟代表全体 → 核验解释二第 23 条。未核验则代表诉讼字段停止。  
若：个别债权人只为自己抢回财产 → 现有依据不支持，停止。

---

## 节点 2　定性

| 行为 | 条文 | 窗口 |
| --- | --- | --- |
| 无偿转让、不合理价格、新增物权担保、提前清偿、放弃债权 | 第 31 条 | 受理前一年 |
| 具备第 2 条第一款情形下的个别清偿 | 第 32 条 | 受理前六个月 |
| 隐匿销毁放弃债权、虚构债务或承认不真实债务 | 第 33 条 | 无效，不适用一年／六个月替代定性 |

同一事实可竞合时分列主备位，不双计返还。

---

## 节点 3　起算与例外

- 强制清算转入：起算为裁定受理强制清算申请之日（解释二第 10 条），必须核验。  
- 提前清偿的债务在受理前已到期：解释二第 12 条一般不支持撤销，但六个月且具备原因的除外。  
- 个别清偿使债务人财产受益：第 32 条但书，须有可回链受益事实。  
日期冲突建并行情景，不选有利一天。

---

## 节点 4　请求

返还财产、确认无效、恢复登记分列。金额未知不写零。不保证执行回款。

---

## 节点 5　草稿与禁止

起诉状法定事项。不代提交。禁止倒签、补造合同、指导相对人销毁凭证。
