# 准备破产撤销或无效之诉

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把已失效《企业破产法（试行）》或 1991 年民事诉讼法企业法人破产还债程序当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的管理人或代表全体债权人立场下，形成“发送前破产撤销或无效诉讼包”：行为定性、临界期起算、起诉材料、最强抗辩。

`depends-on` 为空。接受用户、律师、管理人、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：已受理破产，怀疑受理前一年或六个月内的无偿转让、不合理价格、新增担保、提前清偿、个别清偿，或隐匿销毁放弃债权等无效行为，需要起诉追回。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 未受理，走民法典债权人撤销权（合同争议）；
- 只要证据卷或路径总图；
- 相对人应诉（未安装则 `unavailable`）；
- 指导转移或补造对价；

本任务不保证追回。强制清算转入时撤销起算点按解释二核验，不得默认用受理日。

## 建立评估坐标

确认：受理日或强制清算受理日；行为日；相对人；对价；是否个别清偿；是否无效行为迹象；授权来自管理人还是债权人代表。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`R#` 受理或强清裁定；`T#` 行为；`D#` 材料；`L#` 规则；`I#` 判断；`G#` 缺口；`P#` 诉讼请求；`V#` 稿件版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验第 31–34 条、解释二第 10、12、44 条。

工具不可用时继续事实、主体、程序文书状态和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 主体与授权

原则上管理人起诉。债权人代表全体追收须符合解释二第 23 条已核验条件。双方代理停止。

### 2. 行为定性

第 31 条一年期、第 32 条六个月个别清偿、第 33 条无效分列，不得混用除斥。

### 3. 起算点

一般自受理日起算临界期。行政清理或强制清算转入按解释二第 10 条。提前清偿例外按第 12 条。未核验则起算字段停止。

### 4. 请求与抗辩

返还财产或恢复原状。相对人支付对价、个别清偿使债务人受益、到期债务例外须逐项对照。

### 5. 起诉草稿

不代提交。禁止倒签行为日。

## 停止与安全

- `整体停止`：伪造交易时点或对价；利益冲突未解。
- `字段停止`：起算规则、行为日未核验。
- `目标停止`：主目标变为民法典撤销或应诉。
