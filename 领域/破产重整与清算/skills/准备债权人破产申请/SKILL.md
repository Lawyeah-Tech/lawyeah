# 准备债权人破产申请

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把已失效《企业破产法（试行）》或 1991 年民事诉讼法企业法人破产还债程序当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的债权人立场下，形成“发送前债权人破产申请包”：到期债权证明、不能清偿初步证明、申请书草稿、债务人异议风险和不可逆提示。

`depends-on` 为空。接受用户、律师、管理人、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：债权人已决定对具备企业破产法适用资格的债务人申请重整或破产清算，主债为到期未获完全清偿。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 债务人自己申请（转债务人申请）；
- 尚未受理，主目标是执行、支付令或普通诉讼（金融或 C 端 047／013）；
- 只要申报已受理案件的债权（转申报原子）；
- 要求债务人完整财务账册作为申请前提；
- 申请和解（债权人依法不能直接申请和解）；

本任务不代提交，不保证受理。债权人通常难以掌握债务人完整财产，不得因缺少完整财务而拒绝整理申请，也不得编造债务人财务。

## 建立评估坐标

确认：使用者与授权；债权人与债务人名称；债权基础、到期日、未清偿余额；生效文书或合同；已采取的催收或执行；拟申请清算还是重整；是否已通知或已知其他程序；关键材料及缺失。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 生效文书或执行记录；`C#` 合同定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 申请目的；`V#` 稿件版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验第 7 条第二款、第 8、10 条及解释一；`search_template` 只借申请书栏目。

工具不可用时继续事实、主体、程序文书状态和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 专项分流和程序外实现闸

主目标仍是查封拍卖或支付令则负触发，转金融。已受理则改走申报。不得把破产申请写成加快执行的手段而不核对原因。

### 2. 到期债权是否成立

债权成立、到期、未完全清偿三项分列。诉讼未决标并行情景。保证人有清偿能力不阻却对债务人申请。

### 3. 不能清偿的初步证明

债权人材料门槛低于债务人。可用催告未果、执行不能、公开信息、停止经营等。不得编造债务人资产负债表。解释一未核验则原因结论字段停止。

### 4. 申请目的与异议窗口

只能申请重整或清算，不能申请和解。预列债务人七日异议和法院审查。

### 5. 申请书与不可逆

正文只写已支持事实。禁止虚假夸大、倒签催告。不代提交。

## 停止与安全

- `整体停止`：立场不明；伪造债权；把未到期债权写成已到期；指导虚假破产。
- `字段停止`：法域、原因规则、到期日未核验。
- `目标停止`：主目标变为执行申请或申报。
