# 评估关联企业实质合并

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把已失效《企业破产法（试行）》或 1991 年民事诉讼法企业法人破产还债程序当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在人格混同或财产混同、拟合并破产时，形成“混同事实、合并利弊与个别债权人受损情景表”。不当然合并。

`depends-on` 为空。接受用户、律师、管理人、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：关联企业出现人格或财产混同，债权人、管理人或债务人需要判断是否申请或抗辩实质合并破产。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 日常人格否认、股东损害债权人责任且无人破产（公司治理）；
- 只要关联管辖而不涉及实体合并；
- 指导把优质资产并进一家再逃避另一家债务；
- 普通合并分立交割（投资并购或公司治理）；

实质合并不是当然结果。个别债权人因合并而清偿下降必须单列。公司治理日常人格否认只分流。

## 建立评估坐标

确认：各企业名称与案号；股权与董事交叉；资金、账户、员工、经营混同材料；各企业债权人结构；是否已分别受理。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 陈述；`D#` 账册或资金流；`R#` 各案裁定；`L#` 规则；`I#` 判断；`G#` 缺口；`Q#` 合并／分别情景。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 与 `search_practiced` 核验实质合并现行口径（会议纪要或司法解释类规则未核验则法律结论字段停止）。不把指导性案例写成必然结果。

工具不可用时继续事实、主体、程序文书状态和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　分别破产与主体清单

各企业分别列主体、案号、债权人结构。名称相似不自动合并。

### 节点 2　混同事实分账

财产、人员、业务、意思表示、债务混同分列。单一交叉任职不得写成已混同终局。

### 节点 3　利弊与个别受损

合并节约成本与打击偏颇须对照个别债权人清偿下降情景。未知清偿率不写零、不写唯一比率。

### 节点 4　程序接口

分别受理、关联管辖、合并裁定待核。管辖评估另项。

### 节点 5　治理转出与禁止

无破产程序的人格否认转公司治理。禁止指导制造或消灭混同证据。

## 停止与安全

- `整体停止`：伪造混同或补造隔离；指导转移资产制造合并条件。
- `字段停止`：实质合并规则未核验。
- `目标停止`：主目标变为日常人格否认或普通并购。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
