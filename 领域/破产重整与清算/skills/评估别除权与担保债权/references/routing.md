# 边界与路由

## 正触发

有抵押质押留置，要判断破产程序内优先受偿范围。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 程序外实现担保 | 金融领域 |
| 工程价款优先 | 工程领域 |
| 保证人或然债权 | `评估未到期或然与保证人债权` |
| 顺位精算 | `测算债权额性质与清偿顺位` |
| 临界期新增担保撤销 | `准备破产撤销或无效之诉` |

## 专项整案转出

见方法节点 0。一般借贷担保实现、公司治理日常只分流。审查起草本窗搁置，只说明不实施。

## 易混

别除权不是程序外拍卖令。人保不是别除权。工程优先不是本任务能终局的物权担保。
