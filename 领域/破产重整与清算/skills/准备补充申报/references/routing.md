# 边界与路由

## 正触发

申报期已过、最后分配前，债权人要补充申报。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 申报期内首次申报 | `准备破产债权申报` |
| 对补报结果异议 | `对债权表提出异议` |
| 职工法定项目 | `对职工债权清单提出异议` 或编制清单 |
| 分配已完成要追回 | 追加分配未安装则 `unavailable` |

## 专项整案转出

见方法节点 0。一般借贷担保实现、公司治理日常只分流。审查起草本窗搁置，只说明不实施。

## 易混

补充申报不是无风险的首次申报。不能参与已经完成的分配。职工法定项目通常不必补报。
