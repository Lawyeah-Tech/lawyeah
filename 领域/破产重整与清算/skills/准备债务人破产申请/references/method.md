# 申请方法

本文件是可执行判断节点，不是栏目说明书。每个会改变路径、受理、申报、顺位或撤销结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然确认、唯一清偿率或唯一截止日。

`search_law` 返回已失效《企业破产法（试行）》、1991 年民诉法破产还债程序、已失效《合同法》或其解释时记为噪声，不得写入 `L#`。2002 年《最高人民法院关于审理企业破产案件若干问题的规定》与 2006 年企业破产法冲突的表述（包括“违约金不作为破产债权”）不得当现行主规则。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

企业破产法、公司法清算条文的版本、条号和施行日一律运行时核验后写入 `L#`。不得沿用记忆条号。


申请状态只用 `草案`、`待提交`、`已提交待证明接收`、`已受理`、`停止`。没有法院签收或裁定，禁止写 `已受理`。

---

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 破产尚未受理，主目标是催收、支付令、诉讼、仲裁或强制执行 | 金融借贷担保领域或 C 端 047／013 |
| 保证、抵押、质押、保理、融资租赁的程序外实现 | 金融借贷担保领域 |
| 职工安置、裁员方案、劳动合同终止实施、工资加班经济补偿测算 | 劳动领域 |
| 尚未进入程序，只要改合同、投资或交易文件 | 审查起草领域（本窗搁置，只说明不实施） |
| 普通股权或资产收购交割统筹 | 投资并购领域 |
| 章程、股东会、日常股东争议 | 公司治理领域 |
| 日常合规体系或内部调查 | 企业合规领域 |
| 虚假破产、妨害清算等需要定罪或辩护 | 刑事领域 |
| 自然人还债且不在已核验试点条例范围 | C 端 056；全国个人破产字段停止 |
| 只要关停对照或简易注销且未出现破产原因 | C 端 070 |

混合信号：企业已进入或即将进入法定破产程序的主轴可留本任务；金融实现或劳动安置只作为背景时在缺口标明，不把邻域规则硬套进本任务结论。

## 节点 1　申请闸、授权和冲突角色

若：路径评估或等价材料不支持申请 → 目标停止，转 `assess-procedure-route`，不产出发送前终稿。  
若：无股东会／董事会／法律要求的机关决议，或决议权限冲突 → 授权字段停止，不打开发送闸。  
若：用户同时想“一边申请破产一边把存货卖掉先收回自己的钱” → 整体停止违法部分，写明受理后个别清偿无效风险。  
若：实为债权人 → 负触发，转 `prepare-creditor-petition`。  
若：已解散未清算或未清算完毕、用户是清算义务人且主目标是强制申请破产清算 → 负触发，转 `prepare-liquidation-obligor-petition`（未安装则 `unavailable`），不得改写成自愿重整或和解申请。

## 节点 2　程序类型

| 条件 | 本任务 | 禁止 |
| --- | --- | --- |
| 材料支持清算且无重整资源 | 申请目的写破产清算 | 顺手写成重整提高受理率 |
| 材料支持重整或有明显丧失清偿能力可能 | 可写重整，可行性缺口转介 | 把可行性写成已成立 |
| 用户要和解 | 仅债务人可申请；须有协议草案接口 | 写成债权人申请和解 |
| 已有债权人申请未裁定 | 评估异议／并案／转换，不平行冲突申请 | 假装本案空白 |

类型必须单一主位。主备位转换只作为说明，不在同一份申请书写两个互斥目的。

## 节点 3　第 8 条材料与职工接口

运行时核验第 8 条现行文本。核验失败则“材料是否齐全”的法律结论字段停止，已交文件清单继续。

分项核对：申请书；财产状况说明；债务清册；债权清册；有关财务会计报告；职工安置预案；职工工资支付和社会保险费用情况。

- 未知金额不写零，不编造审计数。
- 职工安置预案只保留结构接口：人数、合同状态、欠薪是否存在。安置方案、裁员程序、N+1 测算转劳动，本任务不得输出劳动待遇终稿。
- 税务欠缴只作清册记载，税务争议转税务领域。

若：清册与报表冲突 → 并列，不选有利版本。  
若：用户要求“把某债权人先拿掉” → 整体停止，不得指导隐匿债务。

---

## 节点 4　管辖与提交

分列债务人住所地、主要办事机构所在地、集中管辖名单待核。材料不足不选定唯一法院。不代登录全国企业破产重整案件信息网，不代提交。

网上立案渠道可提示，但不把本包改写成大众立案包。

---

## 节点 5　不可逆与复核

预列法院可能的补正、不予受理事由和债权人最强异议。成果保持 `待提交`。禁止倒签决议日期、补造审计报告或伪造送达。
