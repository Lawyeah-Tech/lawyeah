# 边界与路由

## 正触发

债务人已决定申请重整、和解或破产清算，需要发送前申请包。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要路径总图 | `评估破产重整和解路径` |
| 清算义务人强制申请且用户不是债务人机关 | `准备清算义务人破产申请`；未安装则 `unavailable` |
| 债权人申请 | `准备债权人破产申请` |
| 对债权人申请提异议 | `对破产受理提出异议` |
| 职工安置或待遇测算 | 劳动领域 |
| 关停对照且无申请决定 | C 端 070 |
| 程序外融资或催收 | 金融领域 |

## 专项整案转出

见方法节点 0。

## 易混

已决定申请且决议可回链时正触发。仍在比较要不要进法院时负触发。已收到债权人申请通知时，先判断异议还是转换，不默认再交一份债务人申请。
