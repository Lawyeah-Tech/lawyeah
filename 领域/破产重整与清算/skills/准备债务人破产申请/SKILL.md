# 准备债务人破产申请

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把已失效《企业破产法（试行）》或 1991 年民事诉讼法企业法人破产还债程序当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的债务人立场下，于路径评估或等价材料已经支持提出申请时，形成“发送前债务人破产申请包”：申请闸、程序类型、申请书草稿、原因与财务接口、职工说明接口、不可逆提示。

`depends-on` 为空。接受用户、律师、管理人、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：债务人已决定向人民法院申请重整、和解或破产清算，且路径评估或等价材料支持提出申请。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要路径总图，尚未决定申请；
- 用户实为债权人（转债权人申请）；
- 清算义务人强制申请是主目标且用户不是债务人机关（转 `准备清算义务人破产申请`；未安装则 `unavailable`）；
- 只要职工安置或待遇测算（劳动）；
- 主目标是程序外融资或催收（金融）；
- 要求保证受理或当天立案；

本任务只形成待提交材料，不代提交，不保证受理，不把提交写成已经受理。C 端 070 只分流。

## 建立评估坐标

确认：使用者与授权；债务人机关决议；拟申请的程序类型；法域；住所地与管辖线索；资产负债、审计或报表；到期债务清单；职工人数与欠薪是否仅作说明；是否已有债权人申请或强制清算；关键材料及缺失。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 决议章程定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 程序类型；`V#` 稿件版本；`E#` 送达或提交凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验破产法第 7、8、10 条及重整／和解专门条件；`search_template` 只借申请书栏目；`search_practiced` 补材料缺口。不虚构法院收案系统。

工具不可用时继续事实、主体、程序文书状态和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 专项分流、决议授权和申请闸

先做专项分流。路径评估或等价材料必须已经支持申请。仅有“经营不下去”或股东口头同意，不得打开发送闸。

### 2. 程序类型锁定

重整、和解、清算三选一并回链依据。债权人不能申请和解。已有债权人申请时评估是否改为异议或转换，不平行再交一份冲突申请冒充唯一路径。

### 3. 申请书法定事项与财务接口

按第 8 条组织：申请目的、事实理由、财产状况说明、债务清册、债权清册、财务报告、职工安置预案及工资支付社保接口。安置预案只列接口，不定安置方案，待遇测算转劳动。未知不写零。

### 4. 管辖与提交设计

住所地、主要办事机构、集中管辖只列待核连结点，材料不足不选定唯一法院。不代提交。

### 5. 不可逆提示与禁止事项

提交后难以当作没发生。禁止隐匿财产、虚假清册、毁账。成果状态保持待提交。

## 停止与安全

- `整体停止`：立场或授权不明；无有效机关决议；用户坚持虚假清册、隐匿债务或毁账。
- `字段停止`：法域、程序类型条件、管辖、财务数据未核验。
- `目标停止`：主目标变为债权人申请、受理异议、申报或安置方案。
