# 评估工伤与第三人侵权竞合

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“工伤与第三人侵权竞合分账”：民事请求与工伤待遇各自程序入口、医疗费等项目重复禁止、可并行项目、交接劳动包条件。不办理工伤认定、劳动能力鉴定或工伤待遇。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算、鉴定和证据清单。

## 工作边界

正触发：工作中或上下班途中因用人单位以外的第三人导致人身损害，需要比较民事侵权请求与工伤待遇两套成果。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是工伤认定、劳动能力鉴定或工伤待遇测算（转劳动）；
- 无法定工伤统筹关系、纯个人之间劳务（转 `评估提供劳务受害`）；
- 只要向第三人索赔的总体侵权总图且无需分账（转 `评估人身侵权责任`）；
- 诊疗过错主轴（转医疗医药）；
- 海事船舶事故（转海事）。

本任务不代办工伤认定，不出具工伤待遇结论，不给胜诉率。工伤三段整案转劳动。

## 建立工作坐标

确认：使用者与授权；单方立场；受害人与用人单位关系材料；第三人身份；事故是否发生在工作时间工作场所或上下班合理路径；是否已申请工伤认定；民事协商或诉讼状态；医疗费支付方；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 劳动关系或劳务材料；`R#` 工伤认定或事故文书；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 分账项目；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验第三人侵权与工伤保险的并行和医疗费禁止重复；`search_practiced` 补分账口径与反例。不虚构案件系统。

工具不可用时继续事实、主体、程序文书状态和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [竞合分账方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　用工关系与整案转出

依法应参加工伤统筹的劳动者，工伤三段转劳动。个人之间劳务走提供劳务受害专项。

### 节点 2　第三人与事故场景

固定第三人是否属于用人单位以外。上下班第三人侵权可留民事。

### 节点 3　项目分账与重复禁止

医疗费等实际支出禁止重复受偿。残疾赔偿金与一次性伤残补助金是否并行须核验，不得凭记忆写成一律双得或一律互斥。

### 节点 4　程序入口并行

民事起诉与工伤认定可并行，互不等待，除非用户选择暂停。

### 节点 5　交接劳动包与输出纪律

交接只含用工事实、事故时间地点、已付清单。不代写工伤申请。

## 停止与安全

- `整体停止`：立场不明；用户坚持同一张医疗费票据向工伤基金和第三人全额双领；伪造劳动关系。
- `字段停止`：用工关系性质、第三人身份、已付医疗费来源或现行分账规则未核验。
- `目标停止`：主目标变为工伤认定申请、劳动能力鉴定或工伤待遇测算。
