# 边界与路由

## 正触发

工作中或上下班途中因用人单位以外的第三人导致人身损害，需要比较民事侵权请求与工伤待遇两套成果。

受害人开口且委托范围是分账比较时，不因口语化咨询整体停止。双方秘密、双领同一票据或隐瞒第三人赔偿套基金的停止，优先于负触发。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 办理工伤认定、劳鉴或待遇 | 劳动领域 |
| 个人之间劳务受害 | `评估提供劳务受害` |
| 只要第三人责任总图 | `评估人身侵权责任` |
| 只要测算终稿 | `测算人身损害赔偿` |
| 医疗损害鉴定 | 医疗医药领域 |
| 海事 | 海事领域 |

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 同事执行工作任务致害 | `评估用人者责任`；第三人身份待核 |
| 上下班机动车事故民事段 | `评估道路交通事故责任与保险先行` |
| 基金已付医疗费追偿 | `应对保险代位求偿` |
| 金额参数 | `测算人身损害赔偿` |
| 民事评残 | `准备伤残鉴定材料`（闸关则禁止启动） |
| 民事时效 | `评估人身损害诉讼时效` |
| 向第三人起诉 | `提起人身损害一审` |

## 易混

“上班被车撞了，工伤和肇事方怎么分”正触发。“帮我做工伤认定”整段转劳动。“只问第三人赔多少项目”若无需分账可走测算或总体评估，但仍应标工伤入口红旗。同事叉车撞伤不是当然第三人侵权。
