# 边界与路由

## 正触发

工作中或上下班途中因用人单位以外的第三人导致人身损害，需要比较民事侵权请求与工伤待遇两套成果。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 办理工伤认定或待遇 | 劳动领域 |
| 个人之间劳务受害 | `评估提供劳务受害` |
| 只要第三人责任总图 | `评估人身侵权责任` |
| 医疗损害鉴定 | 医疗医药领域 |
| 海事 | 海事领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 工伤认定、劳动能力鉴定、工伤待遇 | 劳动领域 |
| 诊疗过错主轴 | 医疗医药领域 |
| 海上运输或船舶 | 海事领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“上班被车撞了，工伤和肇事方怎么分”正触发。“帮我做工伤认定”整段转劳动。“只问第三人赔多少项目”若无需分账可走测算或总体评估，但仍应标工伤入口红旗。
