# 竞合分账方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、论坛、期限、主体或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然责任比例或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

每个赔偿项目单独分账。禁止写成“工伤和民事可以各拿一份全部损失”。

---

## 节点 0　用工关系与整案转出

若 if 材料支持劳动关系或应参加工伤保险的用工，then 工伤认定、劳动能力鉴定、停工留薪和工伤待遇整段转劳动，本任务只做与第三人的民事分账。
若 if 个人之间提供劳务或无偿帮工，then 负触发至 `评估提供劳务受害`，不得套用工伤基金规则。
若 if 用工关系依据不足，then 并行列出“可能劳动 / 可能劳务”两条，民事第三人请求可继续，工伤入口只标待核，不写成已认定工伤。
用人单位作为赔偿义务人的民事请求：现有依据支持告知转劳动，不在本任务出具用人单位民事赔偿结论。

## 节点 1　第三人与事故场景

第三人指用人单位以外的侵权人。同事执行工作任务致害可能走用人者责任，不一定是“第三人侵权”。
若 if 上下班机动车事故，then 民事走交通事故与保险先行专项接口，工伤申请仍转劳动。
若 if 第三人不明，then 民事被告行停止或转介 `评估侵权人不明路径`，工伤入口仍转劳动。
事故认定书不写成工伤认定，也不写成民事终局比例。

## 节点 2　项目分账与重复禁止

逐项建立 `Q#`：医疗费、护理费、误工或停工留薪、残疾赔偿金、一次性伤残补助金、丧葬费、死亡赔偿金、精神损害。
若 if 同一张医疗费发票已由工伤基金或用人单位报销，then 对第三人主张该笔：现有依据不支持全额再得，只保留差额或追偿接口。
若 if 精神损害，then 工伤待遇通常不覆盖，民事请求可单列，成立条件转介精神损害评估，不在本任务酌定唯一金额。
残疾类项目：运行时核验现行司法解释关于第三人侵权与工伤保险的关系，未核验则并行情景，不输出“两个残补都必得”。
未知已付不写零，标待核。

## 节点 3　程序入口并行

不得写“必须先拿工伤认定才能起诉第三人”。也不得写“起诉了就不能再认工伤”。
若 if 用户只要民事总图，then 本任务仍须标出劳动包交接条件，避免漏申请工伤。
若 if 第三人已全额赔偿医疗费，then 提示工伤基金可能追偿，转介 `应对保险代位求偿` 的基金分列说明。
诉讼时效与工伤申请期限分列，禁止混算。

## 节点 4　交接劳动包与输出纪律

交接清单：用人单位名称、入职或用工凭证、事故时间地点、第三人信息、医疗费支付方、是否已报工伤。
本任务不预测伤残等级，不计算一次性伤残补助金。
禁止指导隐瞒第三人赔偿以套取工伤基金。


## 证据与下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。

下一步按期限灭失、易失证据、改变请求抗辩、可逆性排序。相邻文书或评估只写转介条件和最小交接。禁止指导伪造伤情、隐匿既往、威胁、倒签或违法取证。

劳动包交接只给最小事实和已付清单，不在本任务填写工伤待遇表。

## 本任务回链纪律

本任务成果是「评估工伤与第三人侵权竞合」：工作中或上下班因第三人受伤，需比较两套成果；单方。
不得把本成果写成相邻原子终稿。不包含：不办理工伤认定、劳动能力鉴定或工伤待遇；该三段转劳动。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`，已停止字段逐行列出待核事项。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接：已固定事实时间线、主体表和缺口。
风险档 A：不可逆文书或期限字段必须单独标可逆性。
