# 评估过错与原因力

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成「过错形态与原因力表」：已主张的受害人过错、第三人原因分列形态、发生与扩大分列、原因力序位、减轻或免除接口。不输出唯一责任百分比，不把事故认定书写成民事终局，不替代总体评估、自甘风险专项、参与度鉴定、共同侵权终稿或保险分账。

`depends-on` 为空。接受等价事实、认定书、监控、测算和证据清单。

## 工作边界

正触发：需要单独判断受害人过错能否减轻或免除、第三人原因是否切断被告责任，或事故认定书与民事过错如何对照。己方主张与对方主张均可。用户要唯一百分比仍正触发，该格字段停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要总体责任总图（转 `评估人身侵权责任`）；
- 只要自甘风险是否成立或公平分担终稿（转 `评估自甘风险与公平分担`）；
- 只要共同侵权连带、按份或补充责任终稿（转 `评估共同侵权与连带按份`）；
- 只要参与度鉴定或既往伤病因果终稿（转 `评估因果关系与既往伤病`）；
- 只要道交保险分账终稿（转 `评估道路交通事故责任与保险先行`）；
- 只要认定书复核终稿（转 `复核交通事故认定`）；
- 只要测算终稿（转 `测算人身损害赔偿`）；
- 诊疗过错参与度主轴（转医疗医药）；
- 只要工伤认定、劳鉴或待遇且无需民事过失相抵（转劳动）。第三人主张受害人过错时本窗可留，工伤三段转劳动。

用户要三七开、70% 或全责数字：不关窗。指导篡改认定书、删除不利事实或隐匿监控：整体停止，不走负触发。

本任务不选定法院，不写唯一截止日，不代提交复核或鉴定申请，不给胜诉率。

## 建立工作坐标

确认：使用者与授权；单方立场；谁在主张减轻或免除；受害人行为；第三人行为；事故认定书、复核或调解记录；监控或行车记录仪控制方；鉴定参与度文书；是否机动车与行人；法域。口头「交警说他全责」不得写成比例已生效。

同时掌握双方秘密或未解利益冲突：`整体停止`，不得以选边治愈，也不得改走负触发去出总图或三七开。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料；`R#` 认定书、复核、鉴定；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`F#` 过错行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。原因力只用序位 `主要` / `同等` / `次要` / `轻微` / `待核`，或区间。禁止唯一百分比。技能正文中的条号是检索锚点，不是已核验 `L#`。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验过失相抵、受害人故意免除、第三人原因、道路交通安全法第七十六条、认定书证明力等将被写入 `L#` 的现行规则；不可用则这些字段停止，且不得填唯一百分比。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变减轻或免除结论的条文正文再写入 `L#`。不得编造 `regulation_id`，也不得把摘要条号写成已核验 `L#`。
- `search_practiced` 补认定书与民事过错对照、未系安全带等保护性规定的实务反例。

工具不可用时继续行为编目和主张清单。不得凭记忆写三七开，或把认定书比例写成民事终局。

## 判断节点

执行顺序和停止条件以 [过错原因力方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流与主张清单

先登记已主张的减轻免除。未主张的不替对方发明。自甘风险、总图、连带按份终稿负触发。夹带工伤或就医时民事过错段可留。

### 2. 受害人过错形态

发生与扩大分列。第一千一百七十三条只减轻不免除。故意免除走第一千一百七十四条，不得与过失相抵混写。

### 3. 第三人原因

第一千一百七十五条不当然切断被告安保、教育机构或共同侵权义务。原因力用序位。

### 4. 认定书、道交第七十六条与举证

认定书只作证据。机动车与行人须有证据证明行人过错才可适当减轻。百分之十上限仅机动车没有过错时的接口。

### 5. 邻接接口与输出纪律

自甘风险、公平责任、参与度、保险分账只标转介。用户要唯一百分比则该格停止，比较表仍交付。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；指导篡改认定书或复核结论；删除不利事实；隐匿、覆盖或拒不提交监控、行车记录仪；伪造痕迹。整体停止优先于负触发。第一次提出即停，不以「坚持」为门槛。
- `字段停止`：过错形态、保护性规定、第七十六条、认定书证明力、无过错责任分则减免或参与度规则未核验；用户要唯一百分比的数字格。
- `目标停止`：主目标变为总体评估、自甘风险成立意见、医疗参与度鉴定、保险分账、认定复核、索赔函终稿或测算总额。

禁止指导伪造伤情、隐匿既往、篡改认定书或违法取证。不给胜诉率。
