# 评估过错与原因力

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“过错形态与原因力表”：受害人过错、第三人原因、故意、过失形态、减轻或免除接口。不输出唯一责任比例，不替代总体评估。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算、鉴定和证据清单。

## 工作边界

正触发：对方主张受害人过错、第三人原因、自甘风险或过失相抵，需要单独判断能否减轻或免除。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要总体责任总图（转 `评估人身侵权责任`）；
- 只要自甘风险专项结论（转 `评估自甘风险与公平分担`）；
- 要求输出唯一责任百分比；
- 诊疗过错参与度主轴（转医疗医药）；
- 工伤责任划分（转劳动）。

本任务不输出唯一责任比例，不替代总体评估或精算。

## 建立工作坐标

确认：使用者与授权；单方立场；被请求方已知抗辩；受害人行为；第三人行为；保护性规定是否涉及；事故认定书记载；鉴定参与度；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料；`R#` 事故认定或鉴定；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`F#` 过错行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典第一千一百七十三条至第一千一百七十六条；`search_practiced` 补过失相抵与原因力比较口径。不虚构案件系统。

工具不可用时继续事实、主体、程序文书状态和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [过错原因力方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　分流与抗辩清单

列出对方已主张的过错、第三人、自甘风险。自甘风险展开转专项。

### 节点 2　受害人过错形态

故意、重大过失、一般过失分列。不得把未系安全带等行为直接写成全部免除。

### 节点 3　第三人原因与原因力

第三人行为可能中断或并行。分别侵权转连带按份专项。

### 节点 4　与自甘风险、公平责任接口

自愿参加文体活动不当然免责。均无过错不当然公平分担。

### 节点 5　输出纪律

每项减轻免除单独判断。不替代总体评估。

## 停止与安全

- `整体停止`：立场不明；用户要求把事故认定书改写成唯一民事比例并删除不利事实。
- `字段停止`：过错形态、保护性规定或参与度规则未核验。
- `目标停止`：主目标变为总体评估、自甘风险专项或医疗参与度鉴定。
