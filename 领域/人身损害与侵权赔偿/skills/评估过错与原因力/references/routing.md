# 边界与路由

## 正触发

对方主张受害人过错、第三人原因、自甘风险或过失相抵，需要单独判断能否减轻或免除。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 总体责任总图 | `评估人身侵权责任` |
| 自甘风险专项 | `评估自甘风险与公平分担` |
| 共同侵权形态 | `评估共同侵权与连带按份` |
| 诊疗参与度主轴 | 医疗医药领域 |
| 工伤内部分责 | 劳动领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 工伤待遇责任划分 | 劳动领域 |
| 诊疗过错与病历 | 医疗医药领域 |
| 海事碰撞责任 | 海事领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“对方说我闯红灯所以他没事”正触发。“整件事有没有责任、下一步怎么办”走总体评估。“篮球撞伤是不是自甘风险”走自甘风险专项。
