# 边界与路由

## 正触发

需要单独判断受害人过错能否减轻或免除、第三人原因是否切断被告责任，或事故认定书与民事过错如何对照。己方或对方主张均可。用户要唯一百分比仍正触发，比例格字段停止。

受害人开口且委托范围是过错比较时，不因口语化咨询整体停止。双方秘密、篡改认定书、删除不利事实或隐匿监控的停止，优先于负触发。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要总体责任总图 | `评估人身侵权责任` |
| 只要自甘风险成立或公平分担终稿 | `评估自甘风险与公平分担` |
| 只要连带、按份或补充责任终稿 | `评估共同侵权与连带按份` |
| 只要参与度或既往伤病因果终稿 | `评估因果关系与既往伤病` |
| 只要道交保险分账 | `评估道路交通事故责任与保险先行` |
| 只要认定书复核 | `复核交通事故认定` |
| 只要测算终稿 | `测算人身损害赔偿` |
| 诊疗过错参与度主轴 | 医疗医药领域 |
| 只要工伤三段且无需民事过失相抵 | 劳动领域 |
| 场所安保终稿 | `评估场所安全保障义务` |
| 教育机构责任终稿 | `评估教育机构责任` |

「要三七开」不在本表。

## 易混

「对方说我闯红灯所以他没事」正触发。「所以三七开、我只赔 30%」仍正触发，比例格停止。「整件事有没有责任、下一步怎么办」走总体评估。「篮球撞伤是不是自甘风险」走自甘风险专项。「商场说是第三人打的我免责」正触发本窗比较，安保终稿转场所专项。「只要把认定书改成全责」整体停止，不走负触发。
