# 输出合同

按触发结果选择交付形状。禁止唯一责任百分比。禁止把事故认定书写成民事终局比例。禁止对同一相对方把过失相抵写成免除。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出（主成果仅工伤三段且无需民事过失相抵；诊疗主轴；海事） | 第 1、2、10 节。禁止过错比例表。劳务受害或第三人民事过错不走本行 |
| 整体停止 | 第 1、10 节。禁止形态表、序位、对照和改写方案。双方秘密、篡改认定书、删除不利事实、隐匿监控时，整体停止优先于负触发 |
| 正触发且可比较 | 下列十节表头均出现；用户要唯一百分比时第 4、5、7 节数字格填 `待核` 或 `依据不足，无法形成结论`，表头仍在；禁止省略后改填三七开 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。双方秘密未解不得进入「部分形成」。每个 `F#` 必须带来源和判断三值。

## 1. 触发、单方立场、授权与成果状态

写明谁在主张减轻或免除、受限字段。双方秘密未解不得进入「部分形成」。

## 2. 来源登记与 MCP 调用表

认定书、复核、调解、监控、鉴定必须编号。口头全责只登记 `S#`。`L#` 不得直接抄技能内条号。MCP 未调用也留一行。

## 3. 已主张减轻免除清单

未主张的不替对方发明。用户要三七开记为用户请求，不升格为已成立抗辩。

## 4. 受害人过错形态表

发生与扩大分列。故意免除与过失相抵分列。效果列只写减轻接口或免除接口，禁止填唯一百分比。闯红灯、未系安全带、未戴头盔不得写成全部免除。

## 5. 第三人原因与原因力序位

禁止唯一百分比。被告另有安保、教育机构或共同侵权义务时不得写当然免责，只标转介。

## 6. 自甘风险、公平责任接口

不打开则填 `不打开`。不写成立或不成立。不把自愿参加写成当然免责。不把《侵权责任法》第二十四条当现行。

## 7. 认定书与民事对照、道交第七十六条

认定书、复核、调解分列，只作证据。不自动映射三七开。百分之十上限仅机动车没有过错时的接口。交强险不得按本窗比例扣减。无认定书无监控时对照格 `依据不足，无法形成结论`。

## 8. 最强反方与证据缺口

监控控制方、合法取得、保存通知不等于保全。检材、标准、委托事项。不得因对方控制推定内容有利。

## 9. 下一步

只转介：总图、道交保险、认定复核、场所安保、教育机构、共同侵权、因果关系与既往伤病、自甘风险、测算、发函、评残闸。禁止在此写索赔函或复核申请终稿。禁止把序位写成已核定份额带出窗。

## 10. 缺口、停止项与提示

须列对方最强解释（认定书即民事终局、主次责即三七开、闯红灯即故意全免、第三人干的被告免责、医学参与度即法律原因力、机动车次责只赔百分之十、要数字就必须关窗）与证据缺口。

本成果不是责任比例鉴定、判决主文、保险分账或总图。
