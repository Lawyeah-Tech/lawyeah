# 过错原因力方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、论坛、期限、主体或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然责任比例或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

`F#` 固定列：`主体｜行为｜形态（故意/重大过失/一般过失/无过错）｜规范保护目的｜原因力候选｜减轻或免除效果｜判断｜待核`。

---

## 节点 0　分流与抗辩清单

先登记对方主张。未主张的减轻事由不得主动替对方发明，除非材料表面已显示且对用户有重大风险。
若 if 主成果是文体活动固有风险，then 转介 `评估自甘风险与公平分担`，本任务只留接口。
若 if 主轴是诊疗过错参与度，then 转医疗。
若 if 工伤内部责任划分，then 转劳动。

## 节点 1　受害人过错形态

运行时核验第一千一百七十三条：被侵权人对同一损害的发生或扩大有过错的，可以减轻侵权人责任。
若 if 受害人故意，then 另核第一千一百七十四条，免除效果与减轻效果不得混写。
若 if 受害人违反保护自己的注意义务，then 写形态和原因力候选，不输出“三七开”唯一比例。
未成年人受害人过错：核验监护人过错接口，转介 `评估未成年或无行为能力受害人代理`。
无民事行为能力人在教育机构受害：不得简单用受害人过错抵销学校义务，转介教育机构专项。

## 节点 2　第三人原因与原因力

运行时核验第一千一百七十五条：损害是因第三人造成的，第三人承担侵权责任。
若 if 第三人行为与被告行为对同一损害均有原因力，then 不得写成被告当然免责，转介 `评估共同侵权与连带按份`。
若 if 只有“对方说是第三人干的”而无材料，then 依据不足，无法形成结论。
原因力用区间或序位（主要/同等/次要/轻微）表达，禁止唯一百分比。

## 节点 3　与自甘风险、公平责任接口

自甘风险成立条件转专项。本任务只判断对方主张是否属于第一千一百七十六条场景。
均无过错主张：核验第一千一百八十六条须法律规定，不得凭公平观念直接分担。
旧解释“根据实际情况分担”口径不得当作现行一般规则。

## 节点 4　输出纪律

事故认定书责任比例与民事过错对照表必须可见。不一致时并列，不自动采用交警比例。
鉴定“参与度百分之三十”不得直接写成赔偿乘以百分之三十，须说明检材、标准和对法律原因力的映射缺口。
本任务不输出唯一责任比例，不给胜诉率。


## 证据与下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。

下一步按期限灭失、易失证据、改变请求抗辩、可逆性排序。相邻文书或评估只写转介条件和最小交接。禁止指导伪造伤情、隐匿既往、威胁、倒签或违法取证。

事故认定书比例只作 `R#`，必须另做民事过错对照。

## 本任务回链纪律

本任务成果是「评估过错与原因力」：对方主张受害人过错、第三人原因或自甘风险；单方。
不得把本成果写成相邻原子终稿。不包含：不输出唯一责任比例；不替代总体评估。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`，已停止字段逐行列出待核事项。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接：已固定事实时间线、主体表和缺口。
风险档 A：不可逆文书或期限字段必须单独标可逆性。
