# 过错原因力方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。原因力只用序位 `主要` / `同等` / `次要` / `轻微` / `待核`，或区间。禁止唯一责任百分比、三七开、70% 或全责数字。未知金额不写零。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》（含第二十四条、第二十六条、第二十七条）、民法通则第一百三十一条、2003 年人身损害赔偿解释第二条（侵权人故意或重大过失则受害一般过失不减轻；无过错责任须受害重大过失才相抵）时记为噪声，不得写入 `L#`。2022 年人身损害赔偿解释已删除该第二条，禁止当现行。

`F#` 交付列：`主体｜行为｜形态候选｜发生或扩大｜规范保护目的｜原因力序位｜减轻或免除接口｜证明负担方｜来源｜判断`。形态是开放取值，不是闭集。禁止在效果列填唯一百分比。

## 节点 0　分流与主张清单

整案转出只交付第 1、2、10 节。

先登记谁在主张减轻或免除。未主张的减轻事由不得主动替对方发明，除非材料表面已显示且对用户有重大风险——此时只标红旗，仍不替对方写成已成立。
若 if 主成果是文体活动固有风险是否成立或公平分担终稿，then 负触发至 `评估自甘风险与公平分担`。
若 if 主成果只要总体责任总图，then 负触发至 `评估人身侵权责任`。
若 if 主成果只要连带、按份或补充责任终稿，then 负触发至 `评估共同侵权与连带按份`。
若 if 主轴是诊疗过错参与度，then 转医疗。
若 if 主成果仅是工伤认定、劳鉴或待遇且无需民事过失相抵，then 整案转劳动。工作中或上下班因第三人受伤、需要判断受害人过错的，民事段留本窗，工伤三段转劳动并转介 `评估工伤与第三人侵权竞合`。
若 if 主成果只要认定书复核，then 负触发至 `复核交通事故认定`。

口头转述、截图和「已读」不得写成认定书已送达、复核期已起算或比例已生效。

## 节点 1　受害人过错形态

检索锚点：民法典第一千一百七十三条。被侵权人对同一损害的发生或者扩大有过错的，可以减轻侵权人的责任。只减轻，不得写成免除。发生过错与扩大过错分列。
检索锚点：民法典第一千一百七十四条。损害是因受害人故意造成的，行为人不承担责任。与第一千一百七十三条分列，禁止把闯红灯、未系安全带、未戴头盔升格为故意全免。
道路交通安全法第七十六条第二款：交通事故的损失由非机动车驾驶人、行人故意碰撞机动车造成的，机动车一方不承担赔偿责任。故意碰撞才可能走该款全免，须核验，不得把一般违章写成故意碰撞。

若 if 受害人违反保护自己的注意义务（未系安全带、未戴头盔等），then 多为扩大损害的过错候选，写形态和原因力序位，不输出唯一比例，不全部免除。
未成年人受害人过错：不得简单用儿童行为抵销；监护人过错接口转介 `评估未成年或无行为能力受害人代理`。
无民事行为能力人或限制民事行为能力人在教育机构受害：不得用受害人过错抵销学校义务，转介 `评估教育机构责任`。
互殴或正当防卫定性先转介 `评估打架伤害民事路径`，本窗不写防卫成立。

主张第一千一百七十三条减轻的一方举证，通常是被告或保险人。不得把受害人自证无过错写成责任成立条件。无过错责任下，侵权人过错不是成立要件；受害人过错只走分则减免接口，转入产品、高度危险、饲养动物专项。禁止因受害一般过失写成无过错责任不成立。禁止把已删除的 2003 年解释第二条当现行相抵门槛。

故意侵权人面对受害人过失能否相抵：实务分裂，该格 `待核`，不得写成必然相抵或必然不相抵。

## 节点 2　第三人原因与原因力

检索锚点：民法典第一千一百七十五条。损害是因第三人造成的，第三人应当承担侵权责任。仅当材料支持损害**全部**由第三人造成、被告无独立义务时，才考虑切断被告责任。
若 if 被告另有安全保障义务，then 不当然免责，转介 `评估场所安全保障义务`（相应补充，禁止改写连带）。
若 if 教育机构场所内因校外人员或同学致害，then 转介 `评估教育机构责任`。
若 if 第三人行为与被告行为对同一损害均有原因力且形态是共同实施、教唆帮助、共同危险或分别侵权，then 转介 `评估共同侵权与连带按份`，本窗不写连带或按份终稿。
若 if 只有「对方说是第三人干的」而无材料，then 依据不足，无法形成结论。

原因力用序位或区间。禁止唯一百分比。不得因对方控制监控而推定内容有利或直接填主要原因力。

## 节点 3　认定书、道交第七十六条与保险接口

事故认定书、复核结论、调解记录分列，只作 `R#`。检索锚点：道路交通事故损害赔偿解释关于认定书证明力的条款（条号运行时核验）。人民法院应依法审查并确认相应证明力，有相反证据可以推翻。不得写成民事终局比例。主责、次责、同等、全部责任不得自动映射三七开、二八开。交警「全部责任」或「主要责任」不得直接写成民法典第一千二百一十七条的故意或重大过失。

检索锚点：道路交通安全法第七十六条。机动车之间按过错比例分担，本窗仍不填唯一数字，只标接口。机动车与非机动车驾驶人、行人：非机动车或行人没有过错的，由机动车一方承担赔偿责任；有证据证明非机动车或行人有过错的，根据过错程度**适当减轻**；机动车一方没有过错的，承担不超过百分之十的赔偿责任。百分之十是机动车没有过错时的法定上限接口，不是全案唯一比例，也不是机动车次责时的地板。次责机动车不得套用百分之十。故意碰撞才可能全免。

交强险在限额内先行，不得按本窗民事减轻比例扣减交强险。保险分账转入 `评估道路交通事故责任与保险先行`。次责或无责不得关闭该车交强险接口。

保存通知不等于法院保全。监控、行车记录仪升级转介 `准备监控保存通知` 或保全专项。本窗不写保全申请。

## 节点 4　邻接接口

自甘风险成立条件转 `评估自甘风险与公平分担`。本任务只判断对方主张是否属于第一千一百七十六条场景接口，不写成立或不成立。无关则该节填 `不打开`。
均无过错主张：检索锚点民法典第一千一百八十六条，须依照法律规定分担，不得凭公平观念直接分担。已废止《侵权责任法》第二十四条不得当现行。
鉴定参与度转入 `评估因果关系与既往伤病`。禁止把医学参与度百分比写成法律原因力，禁止直接乘赔偿。无鉴定则法律原因力不得用口述百分比填数。检材、标准、委托事项必须编号入 `R#`。
金额参数转入 `测算人身损害赔偿`。鉴定闸关闭不得转介启动评残。

用户要唯一百分比：比例格字段停止，比较表、形态和序位仍交付。禁止省略后改填三七开。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过分流直接给比例。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密且未获冲突豁免，then 整体停止，不得选边治愈。
若 if 用户提出篡改认定书、删除不利事实、隐匿覆盖监控、伪造痕迹、伪造伤情或隐匿既往，then 整体停止；第一次提出即停。
若 if 口头「他闯红灯」或「交警说全责」无认定书无监控，then 该事实 `依据不足，无法形成结论`，不得写成已证明。
若 if 日期、送达或动态规则未核验，then 期限字段停止，不编造唯一截止日，不选定法院。
若 if 金额或比例参数不足，then 该行标未知或 `待核`，禁止写零或三七开冒充已核定。

判断状态只许三值。禁止胜诉率。

## 本任务回链纪律

本任务成果是「过错形态与原因力表」。不包含：唯一责任百分比、总图、自甘风险成立意见、参与度鉴定、共同侵权终稿、保险分账、认定复核终稿。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接：已固定行为时间线、主张清单和缺口。
风险档 A：不可逆文书或期限字段必须单独标可逆性。
