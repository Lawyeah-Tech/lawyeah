# 边界与路由

## 正触发

经营场所、公共场所或群众性活动中发生人身损害，需要判断管理人组织者的安保义务及第三人介入时的补充责任。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 教育机构在校伤害 | `评估教育机构责任` |
| 施工地面地下 | `评估施工地面地下设施致害` |
| C 端场所摔伤准备 | 大众专项，只分流 |
| 共同实施打架 | `评估打架伤害民事路径` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 场所内职工工伤 | 劳动领域 |
| 场所内诊疗过错 | 医疗医药领域 |
| 港口船舶 | 海事领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“商场地滑摔了”正触发。“学校操场摔了”走教育机构。“工地没有护栏”走施工专项。“小偷打人商场要不要赔”是补充责任正触发。
