# 边界与路由

## 正触发

经营场所、公共场所或群众性活动中发生人身损害，需要判断管理人、组织者的安保义务及第三人介入时的相应补充。用户要「损害即全责」或「补充改连带」仍正触发。场所未制止互殴时 1198 补充可正触发。

双方秘密、编造监控、破坏现场或违法调取的停止，优先于负触发。不得改走负触发去出全责、补充或抗辩方案。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 总体责任总图 | `评估人身侵权责任` |
| 主体名单终稿 | `评估责任主体与保险覆盖` |
| 只要 1168–1172 形态终稿 | `评估共同侵权与连带按份` |
| 过错百分比 | `评估过错与原因力` |
| 自甘风险或公平分担终稿 | `评估自甘风险与公平分担` |
| 教育机构在园在校 | `评估教育机构责任` |
| 施工地面地下 | `评估施工地面地下设施致害` |
| 物件脱落或高空抛物 | `评估物件脱落坠落与高空抛物` |
| 只要打架互殴、防卫或刑民分流终稿 | `评估打架伤害民事路径` |
| 侵权人不明查明终稿 | `评估侵权人不明路径` |
| 铁路航空运输过程承运人 | `评估铁路航空等非海事承运人人身损害` |
| 监控保存通知发送稿 | `准备监控保存通知` |
| 测算或伤残 | `测算人身损害赔偿` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 场所内职工工伤 | 劳动领域 |
| 场所内诊疗过错 | 医疗医药领域 |

## 易混

「商场地滑摔了」正触发。「学校操场摔了」走教育机构。「工地没有护栏」走施工专项。「楼上砸下来」走物件专项。「高铁运行中烫伤」走承运人。「小偷打人商场要不要赔」是第二款相应补充正触发，不得写成连带。「商场要和打人的连带」仍正触发，连带格现有依据不支持。「监控在商场所以一定拍到」不得推定内容有利。「大学食堂摔了」通常走本窗，幼儿园在园走教育机构。
