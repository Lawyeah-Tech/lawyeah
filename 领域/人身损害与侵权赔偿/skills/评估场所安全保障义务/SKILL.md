# 评估场所安全保障义务

## 任务目标

在明确、无利益冲突的单方立场下，形成经营场所、公共场所或群众性活动组织者是否违反民法典第一千一百九十八条安全保障义务的判断，以及第三人侵权时相应补充责任（含执行顺序）与追偿接口。不定伤残，不办监控调取，不选定法院，不保证必得，不输出唯一责任比例，不把相应补充改写成连带。

`depends-on` 为空。主体名单终稿转 `评估责任主体与保险覆盖`。1168–1172 形态终稿转 `评估共同侵权与连带按份`。在园在校转 `评估教育机构责任`。

## 工作边界

正触发：经营场所、公共场所或群众性活动中发生人身损害，需要判断管理人、组织者的安保义务及第三人介入时的相应补充。用户要「损害即全责」或「补充改连带」仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关。场所未制止互殴时，1198 补充可正触发；互殴本身终稿另转。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要总体责任总图（转 `评估人身侵权责任`）；
- 只要主体名单终稿（转 `评估责任主体与保险覆盖`）；
- 只要 1168–1172 形态终稿（转 `评估共同侵权与连带按份`）；
- 只要过错百分比（转 `评估过错与原因力`）；
- 只要自甘风险或公平分担终稿（转 `评估自甘风险与公平分担`）；
- 教育机构在园在校主轴（转 `评估教育机构责任`）；
- 施工地面地下设施主轴（转 `评估施工地面地下设施致害`）；
- 物件脱落或高空抛物主轴（转 `评估物件脱落坠落与高空抛物`）；
- 只要打架互殴、防卫或刑民分流终稿（转 `评估打架伤害民事路径`）；
- 只要侵权人不明查明终稿（转 `评估侵权人不明路径`）；
- 铁路航空运输过程承运人终稿（转 `评估铁路航空等非海事承运人人身损害`）；
- 只要监控保存通知发送稿（转 `准备监控保存通知`）；
- 只要测算或伤残（转 `测算人身损害赔偿`）；
- 只要起诉状（转 `提起人身损害一审`）；
- C 端公共场所摔倒只要大众准备清单（只分流）。

C 端场所摔伤只分流，本任务不降级实施。

## 建立工作坐标

确认：使用者与授权；单方立场；场所经营者、管理者、群众性活动组织者、物业、商户、场地出租人分列；损害如何发生；是否有第三人及是否确定；监控、保洁、安保配置材料的控制方；法域。

口头「监控已删」「商场全责」只登记 `S#`。私人住宅默认不是本条经营场所。

同时掌握双方秘密或受害人与场所利益冲突未解：`整体停止`，不得以选边治愈，也不得改走负触发去出全责、补充或抗辩方案。提出编造监控内容、破坏现场、违法调取或伪造伤情：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 现场照片、监控、巡检表面；`R#` 文书；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 义务行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。接口状态只用 `打开`、`不打开`、`待核`。形态只用 `自己责任（过错）`、`相应补充`、`不打开`、`待核`。技能正文中的条号是检索锚点，不是已核验 `L#`。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验民法典第一千一百九十八条两款、相应补充执行顺序等将被写入 `L#` 的现行规则；不可用则义务是否违反、相应范围和执行顺序字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变安保义务、相应补充或追偿结论的条文正文再写入 `L#`。不得编造 `regulation_id`，也不得把摘要条号写成已核验 `L#`。
- `search_practiced` 补合理限度、组织者与出租人分列、第三人不明时补充是否成立的实务反例。

工具不可用时继续场所类型、管理人、事发经过和监控控制方编目；法律效果字段停止。已失效《侵权责任法》第三十七条、2003 年人身损害赔偿解释第六条不得默写为现行 `L#`。

## 判断节点

执行顺序和停止条件以 [场所安保方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场与主体分列

在园在校、施工、物件、承运人运输过程整案或负触发转出。物业、商户、主办方、出租人分列。双方秘密或编造监控提出即停。

### 2. 第一款自己责任与过错

不得仅因发生损害推定过错。湿滑未警示只是义务违反候选。

### 3. 第三人、相应补充与执行顺序

不得改写连带，不得补充即全额，不得与第三人同一执行顺序。第三人不明则待核。

### 4. 监控与易失证据

不能因场所控制监控推定内容有利。只转介保存通知，不办调取。

### 5. 邻接红旗与转介

教育机构、施工、物件、承运人、自甘风险、过错、不明路径只标打开或不打开。不定伤残，不选定法院。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；提出编造监控内容、破坏现场、违法调取或伪造伤情。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。
- `字段停止`：义务范围、相应补充范围或执行顺序未核验。用户要损害即全责、补充改连带或必得总额则该格停止，窗口不关。
- `目标停止`：主目标变为教育机构、施工、物件、承运人、共同侵权形态、监控调取或起诉状终稿。

禁止指导编造监控、破坏现场或违法取证。不给胜诉率。不选定法院。不保证必得。
