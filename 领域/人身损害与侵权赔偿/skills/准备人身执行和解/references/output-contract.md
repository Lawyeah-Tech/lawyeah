# 输出合同

按触发结果选择交付形状。和解闸未打开不得交付可提交终稿或保证法院认可。禁止选定唯一执行法院或预填「此致某院」。禁止已读、截图、口头答应当已记入笔录或期间起算。禁止把执行和解写成新判决、新执行名义、可司法确认或公证赋强。禁止保证出具以物抵债裁定。禁止分期或以物抵债写成当然消灭迟延利息。禁止未明示写入放弃已生效债权。禁止未知金额写零。禁止选边治愈。禁止隐匿、倒签或伪造权属步骤。不代签署、不代报法院。不定残。不保证法院认可、中止、解封或恢复。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 和解闸关闭或节点 0 整案转出 | 第 1、2、10 节：关闭理由、对账待核和最小补证。可附停止的 `K#`／`Agr#`／`W#`／`Res#`／`D#`。禁止要点终稿、保证法院认可、保证以物抵债裁定、唯一截止日、选定法院。对第三人民事执行和解可留时不得因工伤整案转出 |
| 整体停止 | 第 1、10 节。禁止方案包、过户步骤、选边、隐匿或倒签方法。双方秘密、指导隐匿转移换和解、过户到他人名下、虚假申报、倒签和解日期、伪造抵债物权属第一次即停，优先于负触发；无选边治愈，无「坚持」门槛 |
| 用户要默示弃权、保证认可、保证必然恢复或中止、把和解当新名义或可确认、已读起算、选定某院、未知写零、协议抵债写成裁定（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；闸未开则仍只交 1、2、10；不得改走负触发关窗；不得标要点终稿 `已形成` 或保证认可 |
| 正触发且闸开（可部分开） | 下列十节表头均出现；记入笔录、中止、恢复期间、时效中断、迟延利息、权属未核验格待核；一行一项；禁止为填满而写保证法院认可、默示弃权、此致某院、新执行名义或已有抵债裁定 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入要点终稿已形成。双方秘密未解不得进入「部分形成」。每个 `K#`／`Agr#`／`W#`／`Res#`／`D#` 必须带来源和三值判断。`L#` 不得直接抄技能内条号。记入笔录等于新名义、分期消灭利息、保证认可若返回则记噪声。稿件状态默认 `草案`。

## 1. 触发、单方立场、授权与成果状态

和解闸开、部分开或关。单方立场必须标明（权利人或被执行人）。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。稿件默认 `草案`。不代签署、不代报法院。不保证法院认可。

## 2. 来源登记与 MCP 调用表

`S/R/D/E/L/I/G/K/Agr/W/Res/V`。口头差不多了、已读只登记 `S#`／`V#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 期限卡与剩余债权对账 `K#`

记入笔录日、分期每期、恢复执行申请期间、申请执行时效中断待核。已读不得起算。已到位扣减。对账不清不得写结清。未知不写零。

## 4. 分期或抵债方案 `Agr#`

分期、以物抵债协议、第三人代履行分列。担保人、代履行人须本人同意。估值待核，禁止唯一市场价。保险付款不当然消灭其余请求。

## 5. 弃权确认 `W#`

未明示不放弃本金、迟延履行利息、迟延履行金和后续治疗。分期或以物抵债不是当然消灭迟延利息。未知伤残概括弃权停止。

## 6. 违约恢复执行 `Res#`

不履行可申请恢复原生效文书，已履行扣除。不是自动恢复。不保证受理。另诉与恢复择一，本窗不写另诉状。执行和解一般不能当新执行名义。中止是可以不是必然。

## 7. 抵债物与物权负担 `D#`

权属、负担、估值、过户税费待核。以物抵债协议不得写成已有抵债裁定。不动产过户不代办。隐瞒负担走整体停止。

## 8. 要点稿

草案。不代签署、不代报法院。不保证法院记入笔录、裁定中止或出具以物抵债裁定。不预填此致某院。不利的未弃权、权属负担和恢复执行风险必须入稿。闸未开则本节停止。

## 9. 下一步与转介

转介执行申请、被执行应对、和解补强、协议起草、后续治疗另诉、工伤竞合只点名。不写成「签署并报法院即结案」指令。不代签署。不保证认可或到位。

## 10. 缺口、停止项与提示

须列对方最强解释：分期了利息就算了、报了法院一定认、记入笔录就是新判决、和解等于司法确认或赋强、违约自动恢复、一期没到也能恢复全部、房子抵了就算过户、以物抵债协议就是抵债裁定、担保人没签字也能直接执行、微信已读就算和解、此致某院、未知写零、两边材料都给你选边、先过户到亲戚名下再谈不执行、倒签笔录、工伤还在认所以对司机的分期不能做。

本成果不是已提交和解、不是新执行名义、不是以物抵债裁定、不是司法确认或赋强、不是执行申请、不是被执行异议、不是一审和解协议、不保证法院认可、不是唯一截止日、不是选定法院。不代签署。不代报法院。
