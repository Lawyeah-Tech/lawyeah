# 边界与路由

## 正触发

人身损害案件已进入执行程序，拟分期、以物抵债、第三人代履行或变更履行方式。「执行里想分期，别放弃本金」正触发。默示放弃剩余债权或迟延利息、分期即消灭迟延利息、保证法院认可或出具以物抵债裁定、把执行和解当新执行名义或可司法确认、已读即已和解、选定某院、未知写零、保证到位，仍正触发：和解闸可关，对应格停止，窗口不关。工伤待遇执行与第三人民事执行同时出现，仍正触发：工伤段分流劳动，对第三人 `Agr#`／`Res#` 可留。

双方秘密、指导隐匿转移换和解、过户到他人名下、虚假申报、倒签和解日期、伪造抵债物权属的停止，优先于负触发。不得改走负触发去出一方要点。默示弃权、保证认可、把和解当新名义、已读起算不在下表。隐匿倒签不在下表。

| 主要目标 | 路由 |

| 纯工伤待遇执行和解且无第三人民事执行名义 | 劳动领域 |
| C 端只要大众准备包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「把房子过户到亲戚名下换不执行」「倒签和解日期」「两边材料都给你选边」不在本表，走整体停止。默示放弃剩余债权不在本表，是正触发闸关。

## 易混

「执行里想分期，别放弃本金」正触发。「判决前先写一份和解」走起草。「判决生效了对方不给钱，先申请执行」走执行申请。「我是被执行人，执行通知来了要异议」走执行应对。「怕签了不给钱，要司法确认或赋强」走执行力补强，本窗不得把执行和解写成可确认。「分期了利息就算了、报了某院一定认、记入笔录就是新判决、房子抵了就算过户」仍正触发；和解闸关；各格不支持。「工伤还在认，和司机分期」正触发，对司机方案可留，工伤段分流。「两边材料都给你，先过户到亲戚名下再谈不执行」整体停止。
