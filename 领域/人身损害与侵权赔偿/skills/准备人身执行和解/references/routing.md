# 边界与路由

## 正触发

执行中拟分期或以物抵债。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 一审和解协议 | `起草人身损害和解协议` |
| 申请执行 | `执行人身损害生效文书` |
| 被执行异议 | `应对人身损害执行` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 以物抵债涉及不动产过户登记争议 | 房地产红旗 |
| 劳动执行和解 | 劳动领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“执行里想分期，别放弃本金”正触发。“判决前和解”走起草。“只想冻财产”走执行申请。
