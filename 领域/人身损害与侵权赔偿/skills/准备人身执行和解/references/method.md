# 执行和解方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。稿件状态只用 `草案`、`和解闸关闭`、`提交前待核`、`停止`。禁止准许率、必然恢复、唯一截止日、选定法院、自行宣布伤残等级、保证法院认可、保证出具以物抵债裁定、代签署、代报法院、未知写零、把执行和解写成新执行名义。本任务不代签署、不代报法院。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、已失效《合同法》、2017 年民事诉讼法约第二百三十条／第二百三十九条／第二百五十三条直接当现行、记入笔录等于新判决、执行和解可司法确认或赋强、分期当然消灭迟延利息、以物抵债协议等于抵债裁定、和解成立必然中止并解封、违约即自动恢复、已读即已和解时记为噪声，不得写入 `L#`。禁止指导隐匿、转移财产换和解、虚假申报、倒签和解日期或执行笔录。

`K#` 固定列：`编号｜事件类型（和解记入笔录日／双方提交或认可书面协议日／分期每期到期日／恢复执行申请期间／申请执行时效中断待核／原申请执行期间交叉红旗）｜执行案号｜原生效文书类型与案号｜权利人／被执行人／担保人或代履行人分列｜记入笔录或提交认可日（待核）｜是否双方签名或盖章｜当期或协议履行末日｜起算事件（约定履行期间最后一日／该期届满日／中断后重新计算待核）｜期间类型与长度待核｜待核截止｜已读截图不得起算｜过期是否只停该行提交稿且窗口不关｜状态｜来源回链`。一事件一卡。口头答应、微信已读、截图不得填记入笔录日或截止日。不写死唯一日历截止日。

`Agr#` 固定列：`编号｜方案类型（分期金钱／以物抵债协议／第三人代履行／变更履行主体或方式）｜付款人或交付人｜权利人｜每期或抵债标的｜金额或估值（估值待核，禁止写成唯一市场价）｜账户或交付安排｜担保人是否本人同意并向法院承诺接受直接强制执行｜代履行人是否书面同意｜是否消灭被执行人债务待核｜工伤待遇段（分流劳动，不写入民事结论）｜保险付款是否消灭对侵权人其余请求（默认不当然消灭）｜判断三值｜状态｜来源回链`。一行一类。担保人或第三人未同意该行停止。

`W#` 固定列：`编号｜拟放弃项目（本金／迟延履行利息／迟延履行金／后续治疗／未知伤残／其他）｜是否用户单独明示｜相对人｜期间｜判断三值｜可否写入要点稿（未明示＝否；未知伤残概括弃权＝否，用户明示不能治愈）｜状态｜来源回链`。默认不放弃已生效债权、迟延利息和后续治疗。分期或以物抵债不是当然消灭迟延利息。

`Res#` 固定列：`编号｜路径（申请恢复原生效法律文书／就和解协议另诉只红旗，禁止打包保证两条都赢）｜哪一期或哪项违约｜违约事实回链｜已履行扣减回链｜拟恢复范围（未履行部分；加速须协议明示）｜迟延利息／迟延履行金（未明示放弃不得写成已消灭；参数待核禁写零）｜是否已经当事人申请（非自动）｜法院审查结果待核（可恢复／可不予恢复：已履行完毕、期限未届至、正在依约履行）｜担保执行格（缺向法院承诺则停止）｜中止效果待核（不得写必然停一切措施）｜执行和解是否被写成新执行名义（是则该格不支持）｜状态｜来源回链`。

`D#` 固定列：`编号｜抵债物识别｜登记权利人｜占有人｜抵押／查封／租赁等负担｜权属凭证｜估值来源（待核，禁止唯一市场价）｜过户税费待核｜路径（仅和解协议安排／执行程序裁定抵债待核｜协议不得写成已有裁定）｜不动产过户是否本窗代办（否）｜隐瞒负担（是则整体停止）｜判断三值｜状态｜来源回链`。

口头「差不多了」、微信已读、PDF 截图只进 `S#`／`V#`，不得升格 `R#` 已记入笔录或 `K#` 已起算。

## 节点 0　分流、立场、和解闸与不关窗

整案转出或闸关闭只交付第 1、2、10 节或标注停止的 `K#`／`Agr#`／`W#`／`Res#`／`D#`，不得交付可提交终稿，不得标保证法院认可。闸部分打开时：仅对可回链的分期或对账行给出草案，弃权、抵债裁定、恢复执行未核验行停止或不打开。

| --- | --- |

| 主成果是被执行人执行异议或履行安排 | 负触发 `应对人身损害执行` |
| 主成果是司法确认、诉讼调解书或公证赋强手续 | 负触发 `办理人身和解执行力补强` |

和解闸打开（可出 `Agr#`／`Res#` 草案，仍不代签署、不保证法院认可）须同时满足：单方无冲突立场与授权；案件已进入执行程序；主成果是分期或以物抵债要点，不是一审协议、执行申请、异议终稿或补强手续；拟交付不含默示弃权、保证法院认可、保证以物抵债裁定、选定唯一法院、发送版、代签署、未知写零、指导隐匿。

闸关闭（仍正触发）：默示放弃剩余债权或迟延利息；分期即消灭迟延利息；保证法院认可或出具以物抵债裁定；把执行和解当新执行名义或可司法确认；已读即已和解；选定某院；未知写零；保证到位或过户完成；尚未核验权属仍要可提交抵债终稿。闸未开则仍只交 1、2、10 节。

「默示弃权」「保证认可」「保证必然恢复」「把和解当新名义」「已读起算」「选定法院」「未知写零」**不关窗**。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或权利人与被执行人同时交材料争同一份和解稿，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出隐匿、转移、毁损财产、过户到他人名下换不执行、虚假申报、倒签和解日期或执行笔录、伪造抵债物权属或隐瞒负担换抵债、胁迫或刑事逼签，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　期限卡与剩余债权 `K#`

检索锚点：在执行中双方自行和解达成协议的，执行员应当将协议内容记入笔录，由双方签名或者盖章。申请恢复执行原生效法律文书，适用申请执行期间的规定；当事人不履行和解协议的，申请恢复执行期间自和解协议约定履行期间的最后一日起计算。申请执行期间因达成执行中的和解协议而中断，其期间自和解协议约定履行期限的最后一日起重新计算——中断效果与起算必须运行时核验，不得凭记忆写死唯一日历日。2023 修正后执行和解、申请执行期间、迟延履行利息常见条文须运行时核验，2017 年约第二百三十条、第二百三十九条、第二百五十三条不得默写为现行 `L#`。司法解释若仍引旧条号，正文规则可用，旧条号引用是噪声。

已读、截图、口头答应不得起算。记入笔录须有执行员笔录且双方签名或盖章才可填。分期一期一卡；某一期违约是否导致全部剩余加速，以协议明示为准，未约定则字段停止。超过原申请执行时效仍要恢复执行：红旗 + 该稿格停，不关窗；超过时效提出申请法院仍应受理，被执行人异议成立才可能不予执行。

对账：已执行到位必须扣减。对账不清不得写结清。未知金额不写零。保险人限额内付款不当然消灭对侵权人其余请求。工伤待遇段分流，不冲第三人未重复部分。

## 节点 2　方案 `Agr#` 与弃权 `W#`

当事人可以自愿协商变更权利义务主体、履行标的、期限、地点和方式。和解协议一般采用书面形式。委托代理人代为执行和解须特别授权。双方必须自愿。

分期：列期数、每期金额、付款人、账户。不写「分期即结清全部债务」。以物抵债：协议安排与裁定抵债分列（见节点 4）。第三人代履行须其书面同意及范围闭合，否则该行停止。担保人加入须本人同意；向人民法院承诺在被执行人不履行时自愿接受直接强制执行的，恢复执行后可依申请及约定直接裁定执行担保财产或保证人财产。缺签字或缺向法院承诺，担保执行格停止。不得把担保人径行变更为被执行人。

`W#`：未明示不得写入放弃本金、迟延履行利息或迟延履行金。分期或以物抵债不是当然消灭迟延利息。未知伤残、未知手术、后续治疗默认保留；覆盖未知损害的概括弃权不得因用户书面明示风险而写入要点稿。未成年人、死亡近亲属不得代弃权，转介 `评估未成年或无行为能力受害人代理`／`评估死亡赔偿权利人与分配`。

## 节点 3　违约恢复执行 `Res#`

检索锚点：申请执行人因受欺诈、胁迫与被执行人达成和解协议，或者当事人不履行和解协议的，人民法院可以根据当事人的申请，恢复对原生效法律文书的执行。被执行人一方不履行的，申请执行人可以申请恢复执行原生效法律文书，也可以就履行执行和解协议向执行法院提起诉讼；恢复执行后，对就履行执行和解协议提起的诉讼，人民法院不予受理。申请恢复执行，人民法院经审查理由成立的裁定恢复执行；和解已履行完毕、履行期限尚未届至或条件尚未成就、被执行人正在依约履行的，裁定不予恢复执行。恢复执行后，已经履行部分应当依法扣除。履行完毕的，人民法院作执行结案处理。

恢复不是自动恢复。不保证受理或必然恢复。另诉与恢复择一，本窗不写另诉状终稿。执行和解协议一般不具有强制执行力；记入笔录、双方签名盖章 ≠ 新判决、≠ 诉讼调解书签收生效、≠ 可直接强制执行的新名义。要把和解升格为调解书、司法确认或赋强，转介 `办理人身和解执行力补强`，本窗该格不支持，窗口不关。

和解协议达成后符合共同提交、一方提交他方认可或口头记入笔录并由各方签名盖章等情形的，人民法院**可以**裁定中止执行；中止后申请解除查封、扣押、冻结的，人民法院**可以**准许。不得写成和解成立即必然停止一切执行措施或必然解封。

## 节点 4　抵债物 `D#` 与要点稿

两条路径必须分列：

- 路径 A（本窗和解协议）：当事人达成以物抵债执行和解协议的，人民法院**不得依据该协议作出以物抵债裁定**。协议本身一般不能直接申请强制执行，也不当然发生物权变动。
- 路径 B（执行程序裁定抵债，待核另列）：须申请执行人同意，且不损害其他债权人合法权益等条件运行时核验。未经申请执行人同意不得强制以物抵债。申请执行人不同意抵债方案，不得据此要求其承担迟延利息方面的不利后果。

权属、抵押、查封、租赁负担待核。负担不明则 `D#` 停止，不得写成可过户终稿。隐瞒负担换抵债走整体停止。不动产过户不是本窗代办。估值不得写成唯一市场价。过户税费待核。

要点稿栏目：当事人、执行案号、原生效文书、剩余债权对账、分期或抵债安排、未放弃项目、违约恢复执行、已履行扣除。状态默认 `草案`。不代签署、不代报法院。不利的未弃权、权属负担、恢复执行风险必须入稿。闸未开不得标要点终稿 `已形成`。不得预填「此致某院」。不保证法院记入笔录、裁定中止或出具以物抵债裁定。

| --- | --- | --- |
| 判决前协议正文 | 负触发 | `起草人身损害和解协议` |
| 判决前谈判档 | 负触发 | `谈判人身损害和解` |
| 权利人执行申请 | 负触发 | `执行人身损害生效文书` |

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过和解闸直接给保证法院认可、默示弃权、新执行名义或自动恢复。

若 if 日期、送达、记入笔录或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if 金额参数不足，then 该行标未知，禁止写零。
若 if C 端只要大众准备包，then 只分流不回改。

判断状态只许三值。口头转述、截图和「已读」不得写成已记入笔录、已中止、已放弃或期限已起算。事故认定书、调解记录不得单独写成执行名义。

## 本任务回链纪律

本任务成果是「不代签署的人身损害执行和解要点」：和解闸、`K#`、`Agr#`、`W#`、`Res#`、`D#`。必须包含：未明示不放弃已生效债权；分期或以物抵债不是当然消灭迟延利息；不履行可申请恢复原生效文书且已履行扣除；执行和解一般不能当新执行名义；以物抵债协议不得写成已有抵债裁定。不包含：一审和解协议终稿、强制执行申请、被执行异议、司法确认／赋强手续。禁止保证法院认可。禁止选定法院。禁止选边治愈。禁止把默示弃权写成负触发或整体停止。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标要点终稿已形成。双方秘密未解不得进入「部分形成」。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接。
风险档 A：放弃本金或迟延利息、以物抵债过户、恢复执行后的不可逆处分必须单独标可逆性。
