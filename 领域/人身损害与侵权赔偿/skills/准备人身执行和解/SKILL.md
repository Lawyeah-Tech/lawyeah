# 准备人身执行和解

## 任务目标

在明确、无利益冲突的单方立场下，形成不代签署、不代报法院的人身损害执行和解包：和解闸、`K#` 期限卡、`Agr#` 分期或抵债方案、`W#` 弃权边界、`Res#` 违约恢复执行、`D#` 抵债物权属。不放弃已生效债权除非用户明示。分期或以物抵债不是当然消灭迟延履行利息或迟延履行金。执行和解协议一般不能直接当新执行名义。不履行可申请恢复对原生效法律文书的执行，已履行部分应扣除；恢复须申请并经审查，不是自动恢复。双方必须自愿。不保证法院认可和解、记入笔录、裁定中止或出具以物抵债裁定。不选定法院。不写死唯一截止日。未知金额不写零。未知伤残不得概括弃权。后续治疗另诉默认保留。

`depends-on` 为空。尚未进入执行或判决前和解转 `起草人身损害和解协议`／`谈判人身损害和解`。权利人强制执行申请转 `执行人身损害生效文书`。被执行人异议转 `应对人身损害执行`。要把和解升格为诉讼调解书、司法确认或公证赋强转 `办理人身和解执行力补强`。保险了结审查转 `审查保险一次性了结弃权`。后续治疗另诉转 `准备后续治疗费另诉`。

## 工作边界

正触发：人身损害案件已进入执行程序，拟分期、以物抵债、第三人代履行或变更履行方式。「执行里想分期，别放弃本金」正触发。默示放弃剩余债权或迟延利息、分期即消灭迟延利息、保证法院认可或出具以物抵债裁定、把执行和解当新执行名义或可司法确认、已读即已和解、选定某院、未知写零、保证到位、尚未核验过户仍要可提交终稿，仍正触发：和解闸可关，对应格填 `现有依据不支持` 或字段停止，窗口不关，不得改走负触发，不得标和解要点终稿已形成。工伤待遇执行与第三人民事执行同时出现：本窗正触发，工伤段分流劳动，对第三人的 `Agr#`／`Res#` 可留。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是尚未进入执行或判决前的和解协议正文（转 `起草人身损害和解协议`）；
- 主成果是判决前让步档、底线或未闭合报价（转 `谈判人身损害和解`）；
- 主成果是权利人强制执行申请、金额或财产线索（转 `执行人身损害生效文书`）；
- 主成果是被执行人执行异议或履行安排（转 `应对人身损害执行`）；
- 主成果是私下和解司法确认、诉讼调解书或公证赋强手续（转 `办理人身和解执行力补强`）；
- 主成果是保险人一次性了结或权益转让审查（转 `审查保险一次性了结弃权`）；
- 主成果是后续治疗费另诉（转 `准备后续治疗费另诉`）；
- 纯工伤待遇执行和解且无第三人民事执行名义（转劳动）；
- C 端只要大众准备包（只分流）；
- 未成争改合同（审查起草搁置）。

默示放弃剩余债权、保证法院认可、保证必然恢复或中止、把执行和解当新名义或可确认、已读起算、选定法院、未知写零、保证过户**不在负触发表**，窗口不关。双方秘密、指导隐匿转移换和解、过户到亲戚名下、虚假申报、倒签和解日期、伪造抵债物权属**不在负触发表**，走整体停止。

## 建立工作坐标

确认：使用者与授权；单方立场（权利人或被执行人分列，不得同时代表）；执行案号与原生效文书；剩余本金与已履行；拟分期或抵债财产；是否明示放弃迟延利息或本金；担保人或代履行人是否本人同意；法域。

口头「差不多了」「微信已读就算和解了」「报了法院一定认」「分期了利息就算了」只登记 `S#`／`V#`。不得升格为已记入笔录、双方已签名盖章、已中止、已放弃迟延利息或已过户。用户坚持「此致某院」「保证出抵债裁定」不构成选定法院或保证认可的授权。委托代理人代为执行和解须特别授权；普通代理不足以放弃本金或迟延利息。

同时掌握双方秘密，或权利人与被执行人同时交材料争同一份和解稿：`整体停止`，不得以选边治愈，也不得改走负触发去出一方要点。权利人或被执行人已开口且委托范围就是本方执行和解要点、且未掌握对方秘密时，可推定该单方立场。只要同时掌握双方秘密，无例外整体停止。提出隐匿、转移、毁损财产、把财产过户到亲戚或他人名下换不执行、虚假申报、倒签和解日期或执行笔录、伪造抵债物权属或负担、胁迫或刑事逼签弃权：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`R#` 执行案、生效文书、执行笔录；`D#` 抵债物权属、估值、负担；`E#` 送达、签收或记入笔录凭证；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`K#` 期限卡；`Agr#` 方案；`W#` 弃权；`Res#` 恢复执行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。稿件状态只用 `草案`、`和解闸关闭`、`提交前待核`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。本任务默认 `草案`，不代签署、不代报法院。禁止「保证法院认可」「此致某院」「已读即和解」「分期即放弃利息」「协议等同判决」。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：在执行中，双方当事人自行和解达成协议的，执行员应当将协议内容记入笔录，由双方当事人签名或者盖章；申请执行人因受欺诈、胁迫与被执行人达成和解协议，或者当事人不履行和解协议的，人民法院可以根据当事人的申请，恢复对原生效法律文书的执行；当事人可以自愿协商变更权利义务主体、履行标的、期限、地点和方式；和解协议达成后符合提交或记入笔录条件的，人民法院可以裁定中止执行，不是必然停止一切措施；当事人达成以物抵债执行和解协议的，人民法院不得依据该协议作出以物抵债裁定；被执行人一方不履行的，申请执行人可以申请恢复执行原生效法律文书，也可以就履行执行和解协议向执行法院提起诉讼（择一）；恢复执行后已履行部分应当扣除；申请恢复执行期间自和解协议约定履行期间的最后一日起计算；未按指定期间履行金钱给付义务的，应当加倍支付迟延履行期间的债务利息，分期未明示放弃不得写成已消灭。技能正文条号不是 `L#`。噪声：2017 年民事诉讼法约第二百三十条、第二百三十九条、第二百五十三条直接当现行；记入笔录等于新判决或新执行名义；执行和解可司法确认或公证赋强；分期当然消灭迟延利息；以物抵债协议等于已作出抵债裁定；和解成立必然中止并解封；违约即自动恢复；已读或截图即已和解或期间已起算；保证法院认可；选定唯一法院；未知写零；默示弃权有效；担保人未向法院承诺仍直接执行担保财产。不可用则记入笔录效果、中止、恢复期间、时效中断、迟延利息、以物抵债过户字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变记入笔录效果、中止或恢复条件、时效中断、以物抵债裁定资格或迟延利息结论的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补私下协议未提交法院不当然中止、恢复须审查可能不予恢复、以物抵债协议不等于抵债裁定、担保人未承诺不能直接执行、分期未放弃迟延利息仍可追索的实务反例。
- `search_template` 只借执行和解笔录或协议栏目，不把范本当法定格式、已提交文本、发送版或指定唯一执行法院，不得把范本概括弃权带进主文。

工具不可用时继续 `K#`／`Agr#`／`W#`／`Res#`／`D#` 编目与剩余债权对账；记入笔录效果、中止、恢复期间、时效中断、迟延利息、以物抵债过户字段停止。不得凭记忆写成必然中止、自动恢复、协议可直接强制执行、司法确认或保证法院认可。

## 判断节点

执行顺序和停止条件以 [执行和解方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、和解闸与不关窗

工伤三段分流，对第三人民事执行和解可留。双方秘密、隐匿转移换和解、倒签第一次停。默示弃权、保证法院认可、把和解当新名义不关窗。主成果是执行申请或一审协议才负触发。

### 2. 期限卡与剩余债权 `K#`

记入笔录日、分期每期到期、恢复执行申请期间、申请执行时效中断待核。已读、截图不得起算。对账不清不得写结清。未知不写零。

### 3. 方案 `Agr#` 与弃权 `W#`

分期、以物抵债、第三人代履行分列。担保人、代履行人须本人同意。未明示不得写入放弃本金、迟延利息或后续治疗。未知伤残概括弃权停止。

### 4. 恢复执行 `Res#`

不履行可申请恢复原生效文书，已履行扣除。不是自动恢复。不保证受理。另诉与恢复择一，本窗不写另诉状。执行和解一般不能当新执行名义。

### 5. 抵债物 `D#` 与要点稿

以物抵债协议不得写成已有抵债裁定。权属负担待核。不动产过户不代办。草稿不代签署、不代报法院。不保证法院认可。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；权利人与被执行人同时交材料；提出隐匿、转移、毁损财产或过户到他人名下换不执行；虚假申报；倒签和解日期或执行笔录；伪造抵债物权属或隐瞒负担换抵债；胁迫、刑事逼签或用和解掩盖犯罪。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：记入笔录效果、中止、恢复期间、时效中断、迟延利息、抵债物权属或过户未核验。和解闸未开则提交稿停止，窗口不关。用户要默示弃权、保证认可、保证必然恢复或中止、把和解当新名义或可确认、已读起算、选定法院、未知写零、协议抵债写成裁定则该格停止，窗口不关。
- `目标停止`：主目标变为一审和解协议、强制执行申请、被执行异议、司法确认／诉讼调解书／公证赋强、保险了结审查或另诉终稿。默示弃权、保证认可不在目标停止。

禁止指导隐匿转移、虚假申报、倒签或逼签。不给准许率。不选定法院。不代签署、不代报法院。不编唯一截止日。不把未知写成零。不定残。不保证法院认可、中止、解封、恢复或出具以物抵债裁定。
