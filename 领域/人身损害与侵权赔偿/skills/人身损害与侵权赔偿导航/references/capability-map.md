# 当前能力地图

当前安装包是，包含全部 P0 与全部 P1。未列入的 P2 输出 `unavailable`。

| 用户当前目标 | 原子 Skill | 独立成果 | 不包含 |
| --- | --- | --- | --- |

| 要判断谁可能赔、保险怎么覆盖 | `评估责任主体与保险覆盖` | 责任主体图、连带按份补充、交强险商业三者接口 | 保险拒赔终稿、工伤待遇 |
| 要核验诉讼时效 | `评估人身损害诉讼时效` | 时效并行情景、中断中止、二十年 | 唯一截止日、管辖终局、立案包 |
| 已决定书面索赔，要发送前稿 | `准备侵权索赔通知` | 发送前通知、项目表、送达留痕 | 精算终稿、起诉状、已认责 |
| 治疗相对稳定或死亡，要启动伤残或死因鉴定 | `准备伤残鉴定材料` | 鉴定事项、检材、机构分流、申请稿 | 预测等级、医疗损害鉴定、劳动能力鉴定 |
| 要可复核的赔偿项目数字 | `测算人身损害赔偿` | 分项测算、计入接口、互斥抵扣 | 认定责任已成立、唯一必得总额 |
| 单独盘点举证责任和补证 | `建立人身损害证据案卷` | 要件、举证、材料矩阵、合法补证 | 策略总图、诉状、违法取证 |
| 仍可谈，要底线和弃权范围 | `谈判人身损害和解` | 让步表、条件、执行力提示 | 已签字和解、未知伤残概括弃权 |
| 决定起诉 | `提起人身损害一审` | 起诉状、请求、管辖、证据目录 | 代提交；工伤待遇之诉；医疗主轴；海事 |
| 已收到起诉状，要首次应诉 | `应对人身损害一审` | 期限卡、答辩草稿、反诉评估接口 | 劳动应诉、医疗应诉、主动起诉 |

| 对方主张受害人过错、第三人原因或自甘风险 | `评估过错与原因力` | 过错形态、原因力、减轻免除接口 | 唯一责任比例；总体评估 |

| 已被起诉，法定期限内提管辖异议 | `提出人身案件管辖异议` | 异议书、连结点证据、逾期风险 | 与实体答辩混写；过期仍提交 |

| 比较保险理赔、调解、起诉、先予执行 | `选择诉讼调解或保险先行` | 程序适配、成本、失败分流 | 完整申请书 |

| 立案后追加用人者、场所、保险人 | `追加变更责任主体` | 追加或变更申请、新主体事实 | 不必要地重做整份起诉状 |

| 前案未覆盖的后续治疗或新鉴定要另诉 | `准备后续治疗费另诉` | 另诉材料、既判力边界 | 仅评估后续治疗 |
