# 人身损害领域边界

当前安装包是。本表只说明归属。每次路由先核对 [当前能力地图](capability-map.md)；未安装入口输出 `unavailable`。

| 相邻 | 本包入口 | 转出 |
| --- | --- | --- |
| 劳动 | 第三人侵权民事请求；工伤与第三人竞合分账 | 工伤认定、劳动能力鉴定、工伤待遇 |
| 医疗医药 | 一般损害赔偿项目方法；产品致害中的非诊疗段 | 诊疗过错、病历真实性、医疗损害鉴定；药品器械监管主轴 |
| 海事 | 无 | 海上运输、船舶事故、海事保全 |
| 刑事 | 刑民交叉分流；打架民事路径；刑附民比较 | 定罪、控告、辩护 |
| 合同争议 | 人身侵权主轴；违约与侵权竞合选择 | 纯违约质量价款、未成争审查起草（本窗搁置） |
| 建设工程 | 施工地面地下致人身损害 | 工程价款工期质量造价鉴定 |
| 婚家 | 未成年代理人；死亡赔偿近亲属清单 | 监护变更、继承析产、遗产管理 |
| 行政 | 事故认定复核的民事证明力 | 对认定书或公安的行政诉讼 |
| 环境能源 | 高度危险作业人身段 | 环境生态修复、环境公益 |
| 审查起草 | 无 | 未成争只要改合同或出稿：本窗搁置，只说明不实施 |
| C 端 007 | 专业评估或通知，不降成 72 小时准备清单 | 大众事故后准备 |
| C 端 006 | 专业测算与交通专项 | 普通未定残大众测算 |
| C 端场所摔伤 | 场所安保专业评估 | 大众场所准备包 |
| C 端保险理赔 | 专业保险索赔或拒赔 | 大众理赔材料 |
| C 端 011 | 专业起诉包或直接诉保险人 | 大众网上立案材料且请求论坛已闭合 |
| C 端 012 | 专业应诉包 | 大众民事答辩 |
| P2 | 无 | 群体伤害、再审、检察监督、案外人执行异议：`unavailable` |

一般人身侵权夹带工伤、诊疗或海事背景时，专项段只分流，不把专项规则写入本包结论。
