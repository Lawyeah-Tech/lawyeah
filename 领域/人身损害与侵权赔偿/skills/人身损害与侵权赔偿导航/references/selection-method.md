# 原子 Skill 选择方法

当前安装包是，按成果选入口，不按交通事故、摔伤、打架或法条名称匹配。

## 一、先识别成果

- 责任总图；责任主体与保险覆盖；诉讼时效；管辖连结点；管辖异议。
- 工伤与第三人竞合分账；违约与侵权选择；过错原因力；连带按份；用人者；提供劳务受害；自甘风险；未成年代理人。
- 交通保险先行；承运人；场所安保；产品致害；动物；物件坠落抛物；施工地面地下；高度危险；教育机构；打架民事；侵权人不明。
- 索赔通知；监控保存通知；保险索赔；拒赔应对；救助基金；事故认定复核；送达设计。
- 伤残鉴定申请；鉴定异议；因果与既往；伤残等级争议；死亡权利人；精神损害；后续治疗评估；测算。
- 证据案卷；现场电子保全；保全必要性；保全申请；应对保全；先予执行；调查令；公证。
- 和解谈判；和解协议；保险了结弃权；执行力补强；调解评估；程序选择。
- 一审起诉；直接起诉保险人；追加被告；刑附民选择；庭审；上诉；后续治疗另诉。
- 一审应诉；反诉抵销；二审应对；保险人应诉；保险代位。
- 执行申请；执行应对；执行和解；刑民分流；产品惩罚性。

## 二、再确认上下文

只确认会改变入口的最小信息：

1. 单方立场与授权；
2. 损害是否已经发生；
3. 是否涉及工伤认定待遇、诊疗过错鉴定或海事；
4. 本次要分析、发函、鉴定、测算、建卷、谈判、保全还是程序文书；
5. 是否已有起诉状、事故认定书、鉴定意见或生效文书。

## 三、处理混合请求

1. 列出每项可独立验收的成果及对应入口；
2. 只问：`这次要先取得哪一项成果？`；
3. 回答前不指定主要 Skill，不暗示必须先评估再发函或鉴定；
4. 用户确认后只启动所选入口；等价评估、测算或证据可由用户或律师提供。

## 四、停止与 P2

立场冲突、工伤认定待遇主轴、医疗损害鉴定主轴、海事主轴或未成争改合同时，说明边界并转出，不代做。

下列 P2 未列入本升级包，输出 `unavailable`：群体伤害策略、再审、检察监督、案外人执行异议。

信息不足时每轮只追问一个最能改变入口的问题。
