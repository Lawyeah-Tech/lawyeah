# 谈判人身损害和解方法

本文件是可执行判断节点。要点不是已签署。口头谈拢不是已生效。单独和解不是已可强制执行。永不追究不得覆盖未知伤残。未稳定不得概括放弃伤残或后续治疗。先按十级不是成交。构成侵权不是项目必得。保险人限额内付款不当然消灭对侵权人其余请求。报价草稿不是当然中断时效。已读不是到达。打包了结不是分项已闭合。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已签署、已可执行、选定法院、代签署、代提交、未知写零、预测等级。本任务不定罪，不定残，不执行发送，不把要点写成已签署。本窗闸名只能是人谈闸，禁止复用方案闸、和解闸、谈判闸、让步闸、谈拢闸、评估闸、争议闸、侵权闸、鉴定闸、人测闸、求偿闸。预留不得占用：立案闸、和解闸、起诉闸、鉴定闸。本窗 `RN#` 是人谈行。主路径只用 `Q-人谈`，禁止用 `Q-方`、`Q-和`、`Q-谈`、`Q-责`、`Q-签`、`Q-执` 作主路径。本窗 `Q-签` 只作「要点即已签署」不关窗码。本窗 `Q-执` 只作「单独和解即已可强制执行」不关窗码。英文 id 禁止使用，一律用中文技能名 `谈判人身损害和解`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991 年民事诉讼法第五十三条共同诉讼当现行第五十三条自行和解、2017 年第九十七条、2012 年第一百九十四条当现行第二百零五条、2021 年第二百零一条和第二百零二条、已失效 2002 年人民调解协议规定、已失效《侵权责任法》或《合同法》、把要点写成已签署或把单独和解写成已可执行时记为噪声。禁止指导伪造伤情、隐瞒已收款、骗保或以刑逼民。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现争点碎片扫描，不是默认闭集。
`RN#` 固定列：`编号｜争点切片｜底线｜让步至｜弃权范围｜执行力路径｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已签署」或「已可强制执行」。无 `E#` 不得写已签署。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-人谈`。禁止 `FA#`、`HJ#`、`N#`、`W#`、`TP#`、`RB#`、`A#`。文件状态只用 `草案`、`停止`。禁止标 `待签署`。

口头「已经谈拢」「微信说没问题」「已读就算到了」「先按十级」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：医疗／误工／护理／伤残或死亡／精神损害／后续治疗／已付扣减分列，禁止合成「一笔了结且已可强制执行」。单独和解必须明示无强制执行力。未获用户就具体范围的明示确认，不得把现有请求写成已放弃。无死亡且治疗未相对稳定：伤残、护理依赖、后续治疗＝`保留另行主张`，禁止先按十级折现。

出现「谈判」「和解」「方案」一词不是转出。自称成交但分项、付款人、弃权或后续治疗保留未闭合：正触发留本窗，不得转起草。

人谈闸打开（可出 `RN#` 草案，仍不得标「已签署／已生效／已可强制执行」）须同时满足：单方无冲突立场已闭合；主成果是和解方案要点，不是可签协议、不是赋强手续、不是调解终稿、不是起诉状、不是答辩状；至少一项可编号争点切片、报价档位或弃权碎片。口头「已经谈拢」不算单独开闸材料。已起诉、已仲裁或已保全，只要协商渠道未切断，仍可开闸。无死亡且治疗未相对稳定：人谈闸打开或半开，伤残相关格 `保留另行主张`，窗口不关。

人谈闸部分打开：已有碎片，但弃权范围、执行力路径或论坛未闭合；对应格待核；仍交十节。无书面谈判授权但单方立场已闭合且已有碎片：人谈闸部分打开，仍交十节，不是整体停止。

人谈闸关闭（仍正触发）：无一可编号碎片。「今天必须出已签署终稿」而无最小碎片不得开闸。不出 `RN#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `RN#` 终稿，**第 7 节不得出已签署协议或已可执行**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「要点即已签署」「口头谈拢即已生效」「单独和解即已可执行」「永不追究覆盖未知」「先按十级」「构成侵权即项目必得」「保险付款即消灭其余请求」「打包了结即分项已闭合」「已读即已到达」「报价即已中断时效」「谈不拢即应起诉」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `RN#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 人谈闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出隐瞒已收款或基金已付以提高要价、骗保、以和解掩盖犯罪、以刑逼民签弃权、伪造伤情或票据、倒签或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛，不得该部分停后继续出其余档。

## 节点 3　人谈行 `RN#`

按已出现争点碎片扫描，不是默认闭集。每条须能指向争点、底线、让步至、弃权或执行力路径之一。

无 `E#` 不得写已签署。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止标 `待签署`。未稳定：伤残、护理依赖、后续治疗不得写入确定数字或十级；只写 `保留另行主张`。

热冲突强制处理：

- 要点即已签署／口头即已生效／单独和解即已可执行／永不追究覆盖未知／先按十级／构成侵权即项目必得／保险付款即消灭其余／打包了结／已读即到达／报价即已中断时效／谈不拢即应起诉／未知写零 → 该格不支持或字段停止；仍出其他 `RN#`。
- 无一碎片 → 关闸，不出 `RN#` 终稿，窗口不关。
- 指导隐瞒已收款、骗保、以刑逼民、伪造倒签 → 整体停止，不是该格不支持，不得继续出其余档。
- 有效仲裁协议下写应起诉 → 该格不支持，论坛字段停止。

## 节点 4　协议、赋强、调解、起诉接口

第 7 节只开接口，不得夹带 `RN#` 终稿或已签署结论绕闸。闸关闭时第 7 节可写「闸未开，转介待争点编号」，不得补写已签署或已可执行。不选定法院。不代签署。不代提交。未稳定不得转介启动评残。

下一步只转介：`起草人身损害和解协议`、`审查保险一次性了结弃权`、`办理人身和解执行力补强`、`评估人身调解方案与效力`、`选择诉讼调解或保险先行`、`准备人身执行和解`、`评估人身侵权责任`、`测算人身损害赔偿`、`准备伤残鉴定材料`、`准备侵权索赔通知`、`建立人身损害证据案卷`、`评估后续治疗费另行主张`、`评估死亡赔偿权利人与分配`、`评估人身损害诉讼时效`、`评估工伤与第三人侵权竞合`、`提起人身损害一审`、`应对人身损害一审`、`分流刑民交叉`、`评估道路交通事故责任与保险先行`。禁止此致某院。有效仲裁不得写成谈不拢即应起诉。

若 if 用户催促「要点写完就算签了／口头就算生效／单独和解就能强制执行／永不追究全部／先按十级／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`／`保留另行主张`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「人谈闸与人谈行草案」。本窗不执行发送。不包含：已签署和解协议、已可强制执行、调解书、司法确认裁定、起诉状。禁止选边治愈。禁止要点即已签署。禁止口头即已生效。禁止单独和解即已可执行。禁止指导隐瞒已收款、骗保或以刑逼民。人谈闸打开 ≠ 已签署 ≠ 已生效 ≠ 已可强制执行。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标方案终稿已形成。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：机动车事故有认定书和急诊病历，治疗未相对稳定，无鉴定。用户主张要点写完就算签了、微信已读就算到了、单独和解就能强制执行、永不追究包括以后评残和二次手术、先按十级折现、交强险限额付完对驾驶人就了结、不清楚营养费先写零、谈不拢去某区法院。人谈闸打开或半开。`Q-签`、`Q-口`、`Q-执`、`Q-永`、`Q-残`、`Q-包`、`Q-读`、`Q-零`、`Q-院` 不打开为可靠路径。伤残、后续治疗 `保留另行主张`。`Q-伤鉴` 不打开。第 6 节不得把已签署、已生效、已可执行、覆盖未知、十级、0、应起诉写入可执行 `RN#`；对应格 `现有依据不支持` 或字段停止；仍出医疗费分列、底线、单独和解无执行力、保险不消灭其余等其他 `RN#`。不关窗。不代签署。不选定法院。不定残。
