# 输出合同

按触发结果选择交付形状。禁止把口头报价写成协议已成立。禁止用虚构十级填满让步表。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出 | 第 1、2、10 节。禁止让步表、弃权档和执行力终稿 |
| 整体停止 | 第 1、10 节。禁止可谈档、弃权文本、付款安排。双方秘密、隐瞒已收款、骗保、刑事逼签或要求本窗写概括弃权文本时，整体停止优先于负触发；不得改走起草协议完成选边 |
| 鉴定闸关闭或未鉴定但仍正触发 | 十节表头均出现。伤残、护理依赖和后续治疗档必须 `保留另行主张`。禁止这些项目的确定金钱底线或打包成交额。禁止转介启动评残。已发生医疗、误工等可谈档可部分形成。本行优先于「正触发且可谈」 |
| 正触发且可谈 | 下列十节表头均出现；字段停止的单元格填 `依据不足，无法形成结论` 或 `待核`，禁止省略后改填估计成交额 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。每个 `N#`、`W#` 必须带状态。

## 1. 触发、单方立场、授权与成果状态

必须写明单方立场、授权范围、冲突筛查、合意闸和鉴定闸是否打开。双方秘密未解不得进入“部分形成”。口头报价不得写成已成交。未成年人或无／限制行为能力受害人：法定代理人弃权不得写死本人其后仍可主张的部分。

## 2. 来源登记与 MCP 调用表

`S/D/R/L/I/G/Q/N/W/V`。MCP 未调用也留一行。`L#` 不得直接抄技能内条号。

## 3. 治疗稳定、鉴定与程序状态

未稳定信号必须可见。已起诉、仲裁条款、保险报案分列。

## 4. 争点让步表

项目分列，不得只给一个打包数。伤残未鉴定不得折现。测算数字只作接口。可让档不得写成诉讼自认。禁止协议条文、落款或发送版。

## 5. 底线

金钱、非金钱、期限、程序动作分列。已收款必须计入。禁止把未知当零。

## 6. 弃权范围

未知伤残、未知手术或永不追究一切：该档停止，用户明示不能治愈。保险人付款默认不消灭其余请求。未成年人弃权未核验则字段停止。禁止在本窗改写了结书条款。

## 7. 付款与保险接口

谁付、何时付、凭证。不输出交强险分账终稿。分期与担保只标接口。

## 8. 执行力路径

单独和解无强制执行力必须明示。诉讼调解书须写签收后生效（最后一方签收日）。司法确认须调解组织主持且双方共同申请；私下和解不能确认。禁止把三十日写成唯一截止日或失权日。有效仲裁条款不得写成应起诉。手续只转介。

## 9. 风险与下一步

转介协议起草（仅合意闸已过）、保险弃权审查、执行力补强、测算、起诉或应诉。鉴定闸关闭时不得转介启动评残，不得把“先签了结再评残”写成无风险路径。时效只标并行情景，分相对人，禁止唯一届满日。

## 10. 缺口、停止项与提示

须列对方最强解释（已口头成交、概括弃权有效、保险付款消灭全部请求、单独和解可强制执行）与证据缺口。

本成果不是已签字协议，不保证对方履行，不是司法确认裁定或调解书。
