# 边界与路由

## 正触发

仍可协商，需要让步档、弃权和执行力提示。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 可签和解协议正文 | `起草人身损害和解协议`（未安装则 `unavailable`） |
| 保险一次性了结文本审查 | `审查保险一次性了结弃权`（未安装则 `unavailable`） |
| 只要答辩 | `应对人身损害一审` |
| 只要起诉 | `提起人身损害一审` |
| 工伤待遇了结 | 劳动领域 |
| 概括放弃未知伤残 | 负触发或字段停止 |

## 易混

“还能不能谈、底线在哪”正触发。对方已拿出印好的弃权书要你签字，主成果是审查该文本时负触发。
