# 边界与路由

## 正触发

人身损害争议仍可谈，单方需要底线、让步、弃权范围和执行力提示，而不是已谈拢后的可签协议正文。从零、碎片、弃权未核验、无书面谈判授权仍正触发：有可编号争点、报价档位或弃权碎片则闸开或半开，出 `RN#` 草案，保持草案。本次不写已签署、不代签署、不定残、不选定法院是交付禁令，不是开窗条件。要点即已签署、口头即已生效、单独和解即已可执行、永不追究覆盖未知、先按十级、未知写零，仍正触发。把保险付款写成消灭其余请求、把打包了结写成分项已闭合，仍正触发：该格不支持，不改负触发关窗。

双方秘密、隐瞒已收款、骗保、以和解掩盖犯罪、以刑逼民签弃权、伪造倒签的停止，优先于负触发。上述信号不在下表。不写已签署不是负触发。「要点即已签署」「口头谈拢即已生效」「单独和解即已可执行」「永不追究覆盖未知」「先按十级」不在下表。隐瞒已收款不在下表，走整体停止。

## 易混

本窗闸名只能是人谈闸，不是方案闸，不是和解闸，不是谈判闸，不是鉴定闸，不是人测闸。`RN#` 不是 `FA#`，不是 `HJ#`，不是 `N#`，不是 `W#`。主路径是 `Q-人谈`，不是 `Q-方`，不是 `Q-和`，不是 `Q-谈`。`方案闸`／`FA#`／`Q-方` 是合同包 `谈判合同和解方案`。`和解闸`／`HJ#`／`Q-和` 留给 `起草人身损害和解协议`。`Q-谈` 是公司治理退出谈判窗。邻窗 `评估人身侵权责任`、`测算人身损害赔偿`、`建立人身损害证据案卷`、`准备侵权索赔通知` 的谈判转介改挂 `Q-人谈`。要点不是已签署。口头谈拢不是已生效。单独和解不是已可强制执行。永不追究不是覆盖未知。未稳定不得概括放弃伤残。先按十级不是成交。保险人限额内付款不是消灭其余请求。1991 年民诉第五十三条共同诉讼不是现行自行和解条。2021 年第二百零一条不是现行司法确认条。提出「垫付款先藏起来、拿刑事报案逼签」整体停止。本窗不代签署。不代提交。不选定法院。不定残。不写已签署。不保证履行。
