# 边界与路由

## 正触发

仍可协商，需要让步档、具体弃权范围和执行力提示，而不是可签正文或保险了结审查。

受害人开口且委托范围是谈判方案时，不因口语化咨询整体停止。双方秘密、概括弃权、骗保或刑事逼签的停止，优先于负触发。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 合意闸已过且只要可签和解协议正文 | `起草人身损害和解协议`（未安装则 `unavailable`）。自称成交但未闭合则留本窗 |
| 保险一次性了结或权益转让文本审查 | `审查保险一次性了结弃权`（未安装则 `unavailable`，本窗只留红旗） |
| 司法确认、诉讼调解书或公证赋强手续 | `办理人身和解执行力补强` |
| 法院／人民调解方案效力比较 | `评估人身调解方案与效力` |
| 保险先行还是诉讼调解的路径选择 | `选择诉讼调解或保险先行` |
| 只要答辩 | `应对人身损害一审` |
| 只要起诉 | `提起人身损害一审` |
| 只要测算终稿 | `测算人身损害赔偿` |
| 工伤待遇了结 | 劳动领域 |

“签一份永不追究、未知伤残也一并了结”不是负触发，是停止。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 条件已谈拢要落纸 | `起草人身损害和解协议` |
| 保险人印好的了结／权益转让 | `审查保险一次性了结弃权` |
| 需要强制执行力 | `办理人身和解执行力补强` |
| 伤残未鉴定且鉴定闸已打开、用户要申请材料 | `准备伤残鉴定材料`。闸关闭则禁止转介启动，本窗伤残档 `保留另行主张`；金额接口 `测算人身损害赔偿` |
| 未发生后续治疗 | `评估后续治疗费另行主张` |
| 死亡近亲属争议 | `评估死亡赔偿权利人与分配` |
| 工作中第三人 | `评估工伤与第三人侵权竞合` |
| 时效将满或磋商是否中断 | `评估人身损害诉讼时效` |
| 交强险分账 | `评估道路交通事故责任与保险先行` |
| 刑事在侦或报案施压 | `分流刑民交叉` |

## 易混

“还能不能谈、底线在哪”正触发。对方已拿出印好的弃权书要你签字，主成果是审查该文本时负触发。口头“就八万吧”不是协议已成立，本窗只记报价版本。未稳定却要“一次性了结永不追究”走停止，不转介起草协议。
