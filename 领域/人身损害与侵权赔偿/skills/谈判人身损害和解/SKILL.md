# 谈判人身损害和解

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成仍可协商的“人身损害和解方案表”：争点与让步档位、谈判底线、具体弃权范围、付款安排、后续治疗保留、单独和解无强制执行力的明示，以及诉讼调解或司法确认的转介条件。

`depends-on` 为空。未获用户就具体弃权范围的明示确认，不得把现有请求写成已放弃。

## 工作边界

正触发：人身损害争议仍可谈，需要条件和让步方案，而不是已谈拢后的可签协议正文。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 合意闸已过且只要和解协议正文（转 `起草人身损害和解协议`）；自称成交但分项、付款人、弃权范围或后续治疗保留未闭合：本窗继续，不得转起草；
- 主成果是审查保险人一次性了结或权益转让文本（转 `审查保险一次性了结弃权`；未安装则 `unavailable`，本任务只标红旗）；
- 主成果是司法确认、诉讼调解书或公证赋强手续（转 `办理人身和解执行力补强`）；
- 主成果是比较法院／人民调解方案效力（转 `评估人身调解方案与效力`）；
- 对方已起诉且用户只要答辩（转 `应对人身损害一审`）；
- 只要起诉状（转 `提起人身损害一审`）；
- 只要测算终稿或唯一必得总额（转 `测算人身损害赔偿`）；
- 工伤待遇一次性了结为主成果（转劳动）；
- 海事专门和解。

要求写覆盖未知伤残、未知手术或“永不追究一切人身损害”的概括弃权：不是负触发，走停止。骗保、以和解掩盖犯罪、用刑事报案逼签民事弃权：走停止。

本任务不生成可签署终稿，不给胜诉率，不定残，不选定法院，不输出唯一时效截止日。

## 建立谈判坐标

确认：使用者与授权；单方立场；相对方与保险人；治疗是否稳定；鉴定状态；已报价、已付款与已拒绝事项；程序阶段；仲裁条款线索。

口头报价、微信“行”或“已读”不得写成协议已成立。同时掌握双方秘密或未解利益冲突：`整体停止`，不得以选边治愈，也不得改走负触发去起草可签协议。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料；`R#` 机关文书；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 争点；`N#` 让步档；`W#` 弃权范围；`V#` 方案版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。档位状态只用 `可谈`、`保留另行主张`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验弃权效力、诉讼时效中断、调解书、司法确认、分期支付与担保等将被写入 `L#` 的现行规则；不可用则这些字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变弃权或执行力结论的条文正文再写入 `L#`。不得编造 `regulation_id`，也不得把摘要条号写成已核验 `L#`。
- `search_practiced` 补未稳定和解、保险结案和司法确认不受理情形。
- `search_template` 只借栏目名，禁止输出协议条文、落款或发送版。
- 特殊事实可用 `search_case_by_fact`。案例只比较差异，不写成必然成交或口头报价已成立。

工具不可用时继续报价表和争点分列；弃权效力、时效中断、执行力和司法确认期限字段停止。

## 判断节点

执行顺序和停止条件以 [谈判方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 仍可谈、鉴定闸和分流

协商渠道未切断仍可正触发。工伤待遇主轴转出。治疗未稳定或未鉴定：伤残和后续治疗档只能保留另行主张，禁止虚构十级折现，禁止概括弃权。

### 2. 争点让步表

医疗、误工、护理、伤残或死亡、精神损害、后续治疗分列。不得只给一个打包数。测算数字只作接口，本窗不定残、不输出唯一必得总额。

### 3. 弃权范围

必须具体到项目、期间和已知伤情。未知伤残、未知手术、近亲属独立请求或“永不追究一切”：该弃权档停止，用户明示不能治愈。本窗不改写了结书。

### 4. 付款与保险

写明谁付、何时付、凭证。保险人限额内付款不当然消灭对侵权人其余请求。已收款必须入底价，隐瞒已收款停止。

### 5. 执行力

单独和解无强制执行力必须明示。诉讼调解书、司法确认、公证赋强只转介。有效仲裁条款不得写成谈不拢就去法院。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；隐瞒已收款以提高要价；以和解掩盖犯罪、指导骗保、用刑事报案逼签民事弃权；用户要本窗写出概括弃权文本。整体停止优先于负触发。不以「坚持」为门槛。未知伤残等概括弃权夹带在谈判中：正触发，该弃权档停止，明示不能治愈。
- `字段停止`：弃权效力、执行力条件、司法确认期限或时效中断未核验。
- `目标停止`：主目标变为可签协议、保险弃权审查终稿、司法确认手续、答辩或起诉。

禁止指导伪造伤情提高和解金、威胁曝光或隐匿已收款。不给胜诉率。
