# 谈判人身损害和解

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成仍可协商的“人身损害和解方案表”：争点与让步档位、谈判底线、弃权范围、付款安排、后续治疗保留、单独和解无执行力的明示，以及司法确认或诉讼调解的转介条件。

`depends-on` 为空。

## 工作边界

正触发：人身损害争议仍可谈，用户需要条件和让步方案，而不是已谈拢后的可签协议正文。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 条件已谈拢，只要和解协议正文；
- 要求写覆盖未知伤残、未知手术或“永不追究一切人身损害”的概括弃权；
- 对方已起诉且用户只要答辩；
- 工伤待遇一次性了结为主成果（转劳动）；
- 保险人结案协议审查为主成果（未安装则 `unavailable`，本任务只标红旗）。

本任务不生成可签署终稿，不放弃用户现有请求，除非用户就具体弃权范围作出明示确认。

## 建立谈判坐标

确认：使用者与授权；单方立场；相对方与保险人；治疗是否稳定；鉴定状态；已报价与已拒绝事项；程序阶段。口头报价不得写成协议已成立。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料；`R#` 机关文书；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 争点；`N#` 让步档；`W#` 弃权范围；`V#` 方案版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验弃权、诉讼时效中断、调解书和司法确认条件。工具不可用时继续报价表；弃权效力和执行力字段停止。

## 五个判断节点

执行顺序和停止条件以 [谈判方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 仍可谈与分流

已起诉只要协商渠道未切断仍可正触发。工伤待遇主轴转出。

### 2. 争点让步表

项目分列，不得合成“打包了结一个数”而不拆医疗、误工、伤残和后续治疗。

### 3. 弃权范围

未稳定或未鉴定时，概括放弃后续伤残：字段停止或负触发。须用户明示具体范围。

### 4. 付款与保险

写明交强险、商业三者、侵权人谁付、何时付、凭证。保险人付款不当然消灭对侵权人其余请求，除非弃权闭合。

### 5. 执行力

单独和解无强制执行力必须明示。司法确认、诉讼调解书只转介。

## 停止与安全

- `整体停止`：立场不明；用户坚持以和解掩盖犯罪或指导骗保。
- `字段停止`：弃权范围或执行力条件未核验。
- `目标停止`：主目标变为可签协议、答辩或起诉。
