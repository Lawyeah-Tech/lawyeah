# 评估未成年或无行为能力受害人代理

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的监护人或代理人立场下，形成“法定代理、时效特殊起算和监护人过错接口”。家事监护变更转婚家。教育机构责任另项。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算、鉴定和证据清单。

## 工作边界

正触发：受害人为未成年人或无民事行为能力、限制民事行为能力人，监护人或代理人需要单独判断谁能主张、时效如何起算、监护人过错如何影响。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 监护资格变更、撤销或指定（转婚家）；
- 教育机构责任为主成果（转 `评估教育机构责任`）；
- 受害人具有完全民事行为能力；
- 工伤未成年工待遇主轴（转劳动）。

本任务不办理监护变更，不替代教育机构责任评估。

## 建立工作坐标

确认：使用者与授权；受害人年龄或行为能力材料；监护人身份；谁实际主张赔偿；侵害发生日与知悉日；是否性侵害未成年人特殊时效；教育机构是否同时入局；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 户口、出生医学、监护材料；`R#` 文书；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 代理行；`T#` 时效行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验总则编代理、第一百九十条第一百九十一条、侵权编监护人过错和教育机构条文。不虚构案件系统。

工具不可用时继续事实、主体、程序文书状态和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [代理时效方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　行为能力与代理人

确定受害人行为能力。诉讼或主张须由法定代理人。

### 节点 2　时效特殊起算

法定代理结束前后的时效分列。性侵害未成年人特殊规则不得扩张。

### 节点 3　监护人过错接口

监护人未尽职责可能减轻侵权人责任，但不消灭未成年人固有请求。

### 节点 4　教育机构接口

在园在校损害转教育机构专项，本任务只留代理和时效。

### 节点 5　赔偿金监管与输出

赔偿金一般归受害人，监护人保管。不办遗产或监护变更。

## 停止与安全

- `整体停止`：立场冲突（两名监护人争夺代理且未授权本方）；伪造年龄。
- `字段停止`：行为能力、法定代理人、特殊时效条文未核验。
- `目标停止`：主目标变为监护变更或教育机构责任终稿。
