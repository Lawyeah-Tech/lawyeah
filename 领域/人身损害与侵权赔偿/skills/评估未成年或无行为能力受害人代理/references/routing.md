# 边界与路由

## 正触发

受害人为未成年人或无民事行为能力、限制民事行为能力人，需要判断谁能作为法定代理人主张人身损害赔偿，或 190、191、对第三人时效红旗，或监护人过错是否消灭请求。抗辩方提问亦可。用户要等到十八岁、写死截止日或代签概括弃权，仍正触发，该格字段停止。

伪造年龄、双方秘密、两监护人争夺且掌握双方材料：整体停止，优先于负触发。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 主成果仅监护变更、撤销或指定 | 婚家领域 |
| 主成果仅教育机构责任终稿 | `评估教育机构责任` |
| 材料已闭合完全行为能力且不问代理或特殊时效 | `评估人身侵权责任` 或 `评估人身损害诉讼时效` |
| 主成果仅工伤未成年工待遇 | 劳动领域 |
| 受害人已死亡且主问死亡分配 | `评估死亡赔偿权利人与分配` |
| 被监护人致害要 1188 终稿 | `评估责任主体与保险覆盖` |
| 只要完整时效表或唯一截止日 | `评估人身损害诉讼时效` |
| 只要过错百分比终稿 | `评估过错与原因力` |
| 只要起诉状 | `提起人身损害一审` |

「要等到十八岁」「要写死截止日」「要代签弃权」不在本表。十六周岁视为完全不在本表当然关窗。

## 必转介接口

| 信号 | 转介 |
| --- | --- |

| 监护人未看管、过失相抵 | `评估过错与原因力` |
| 在园在校、接送途中是否教育机构 | `评估教育机构责任` |
| 死亡赔偿近亲属 | `评估死亡赔偿权利人与分配` |
| 未成年人致害、1188 | `评估责任主体与保险覆盖` |
| 教唆帮助无或限制行为能力人 | `评估共同侵权与连带按份` |
| 监护人即侵权人、要撤销指定 | 婚家监护变更 |
| 概括弃权、和解文本 | `谈判人身损害和解`、`审查保险一次性了结弃权` |
| 列法、起诉 | `提起人身损害一审` |
| 家长代签自愿参加文体活动 | `评估自甘风险与公平分担` |

## 易混

「孩子受伤谁出面告、时效从哪天算」正触发。「等到十八岁再告车祸」仍正触发，191 不打开，等待格不支持。「母亲撞的、父亲要签了结」正触发，禁弃权，打开 190。「要改监护人」监护段转婚家，代理红旗可留。「学校没看住」主成果是教育机构；谁出面告可留本窗。「对方小孩撞的谁赔」走责任主体 1188，不走本窗。
