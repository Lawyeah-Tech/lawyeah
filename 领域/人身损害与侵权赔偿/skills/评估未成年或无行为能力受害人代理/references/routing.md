# 边界与路由

## 正触发

受害人为未成年人或无民事行为能力、限制民事行为能力人，监护人或代理人需要单独判断谁能主张、时效如何起算、监护人过错如何影响。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 监护变更撤销 | 婚家领域 |
| 教育机构责任主成果 | `评估教育机构责任` |
| 完全行为能力受害人 | 负触发，转总体评估或时效评估 |
| 未成年工伤待遇 | 劳动领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 监护变更、抚养 | 婚家领域 |
| 工伤待遇 | 劳动领域 |
| 校园医疗损害 | 医疗医药领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“孩子受伤谁出面告、时效从哪天算”正触发。“要改监护人”转婚家。“学校没看住”主成果是教育机构责任。
