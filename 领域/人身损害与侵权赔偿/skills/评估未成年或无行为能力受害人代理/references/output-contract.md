# 输出合同

按触发结果选择交付形状。禁止唯一截止日。禁止普通伤害等到十八岁。禁止把 190 用到第三人。禁止代签概括弃权。禁止办监护令。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出（主成果仅工伤待遇；诊疗主轴；海事；未成争改合同） | 第 1、2、10 节。禁止代理策略、时效结论、学校举证、1188 表 |
| 整体停止 | 第 1、10 节。禁止代理人选边、放弃请求、时效结论、截止日。双方秘密、伪造年龄、两监护人争夺未授权本方时，整体停止优先于负触发 |
| 正触发且可判断 | 下列十节表头均出现；无对法定代理人请求则 190 `不打开`；无性侵害则 191 `不打开`；教育机构、1188、死亡分配、监护令不打开则填 `不打开`；用户要等到十八岁或唯一截止日：该格 `现有依据不支持` 或 `待核`；禁止省略后改填 191 或截止日 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。双方秘密未解不得进入「部分形成」。每个 `A#`/`T#` 必须带证明负担方和判断三值。

## 1. 触发、单方立场、授权与成果状态

写明代理人是否闭合、是否夹带学校或死亡分配、受限字段。双方秘密未解不得进入「部分形成」。

## 2. 来源登记与 MCP 调用表

户口、出生医学证明、离婚判决、指定监护文书分列编号。口头年龄、口头监护只登记 `S#`。`L#` 不得直接抄技能内条号。MCP 未调用也留一行。

## 3. 行为能力与法定代理人闭合

分列无行为能力、限制行为能力、视为完全待核。原告应为受害人本人，法定代理人署明。未授权近亲属不得代列。冲突则该字段停止，不得擅自放弃请求。离婚不当然消灭另一方监护。本窗不指定监护人。

## 4. 190 / 191 / 解释第三十六条 / 194 红旗

四行分列。190 仅对其法定代理人。191 仅未成年人性侵害。对第三人标法定代理人知悉红旗，转时效评估。禁止唯一截止日。禁止受害人知悉日作为对第三人的起算锚点。

## 5. 监护人过错接口

不消灭未成年人固有请求。形态转介过错评估。禁止在本窗写减轻比例。

## 6. 邻接不打开表

教育机构、1188、1169 第二款、死亡分配、监护令：不打开则填 `不打开`。打开也只转介。

## 7. 赔偿金归属

归受害人，监护人保管。禁止指导挪用。禁止代签概括弃权。

## 8. 利益冲突

监护人即侵权人：对该人代理权限停止，打开 190。两监护人争夺：不得选边。用户要弃权文本：该格停止。

## 9. 下一步

只转介时效、过错、教育机构、责任主体、婚家、一审、和解审查。禁止在此写诉状、监护令或截止日。不选定法院。

## 10. 缺口、停止项与提示

须列对方最强解释（等到十八岁才起算、190 适用驾驶人学校保险人、父亲已知仍可再等、离婚后无抚养权不能告、父亲可代签了结、监护人未看管则孩子无权索赔、要截止日就必须给日期、选边即可继续、口述年龄即可当原告）与证据缺口。

本成果不是监护令、起诉状、教育机构终稿、死亡分配终稿、1188 终稿、唯一截止日或弃权协议。
