# 代理时效方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。190、191、解释第三十六条状态只用 `打开` / `不打开` / `待核`。禁止唯一截止日、等到十八岁的普通伤害策略、胜诉率。未知金额不写零。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。代理权限、时效红旗、监护人过错三条线不得混成一句「小孩案子特殊」。

`A#` 交付列：`行为能力｜监护关系｜法定代理人是否闭合｜利益冲突｜证明负担方｜来源｜判断`。
`T#` 交付列：`190｜191｜解释第三十六条｜194｜打开或不打开｜证明负担方｜来源｜判断`。户口、出生医学证明、离婚判决、指定监护文书必须分列。

## 节点 0　分流与代理人闭合

整案转出只交付第 1、2、10 节。

检索锚点：民法典第十九条、第二十条。不满八周岁为无民事行为能力人；八周岁以上未成年人为限制民事行为能力人。口头「孩子还小」「孩子十二岁」只登记 `S#`，无户口或出生医学证明则行为能力 `依据不足`。
十六周岁以上以自己劳动收入为主要生活来源视为完全民事行为能力：检索锚点第十八条，**待核**，不得当然负触发关窗。人身损害赔偿请求、起诉、和解弃权不是纯获利益行为，通常仍须法定代理人。
成年无或限制民事行为能力须鉴定或法院认定文书，不得用「精神不好」升格。

检索锚点：第二十三条、第二十七条。监护人是法定代理人。父母是未成年子女的监护人。离婚、未直接抚养，不当然消灭另一方监护，除非撤销或另行指定。口头「我是监护人」「跟我过」只登记 `S#`。离婚判决只证明抚养安排，不单独写成独占代理。
主张自己有权代理的一方证明监护关系。未授权近亲属（祖父母、旁系）不得代列原告或代弃请求。法定代理人互相推诿时，法院可指定其中一人；本窗不指定。
限制民事行为能力人可独立实施纯获利益行为，但人身损害赔偿主张通常由法定代理人代理。

若 if 父母双方意见冲突，then 代理权限字段停止，不得擅自代表未授权一方放弃请求、和解或领款。
若 if 同时掌握两监护人秘密或争夺且未授权本方，then 整体停止，不得选边治愈。
若 if 监护人本身是侵权人，then 对该监护人的代理权限停止；打开 190 红旗；家事变更转婚家。本窗不指定替代监护人、不写监护令、不「另寻路径」在本窗完成。
若 if 受害人已死亡且主问近亲属分配，then 负触发或目标停止，转 `评估死亡赔偿权利人与分配`。
若 if 问的是被监护人致害谁赔，then 1188 填 `不打开`，转 `评估责任主体与保险覆盖`。

## 节点 1　时效红旗

禁止输出唯一截止日。完整并行情景转 `评估人身损害诉讼时效`。

第一百九十条：无民事行为能力人或限制民事行为能力人**对其法定代理人**的请求权，诉讼时效期间自该法定代理终止之日起计算。仅当义务人是该法定代理人时 `打开`。禁止用于驾驶人、学校、保险人等第三人。监护人即侵权人时对本条打开。

第一百九十一条：未成年人遭受**性侵害**的损害赔偿请求权，自受害人年满十八周岁之日起计算。主张 191 的一方证明未成年人加性侵害，缺一不可。普通车祸、摔伤、校园伤害 `不打开`。用户要等到十八岁再告普通伤害：该格 `现有依据不支持`，窗口仍开。视为完全行为能力的未成年人遭受性侵害，起算仍以年满十八周岁为红旗，待核。

对第三人的普通三年：检索锚点民法典第一百八十八条；总则编解释第三十六条（法释〔2022〕6 号，条号运行时核验）：无或限制民事行为能力人的权利受到损害的，诉讼时效期间自其**法定代理人**知道或者应当知道权利受到损害以及义务人之日起计算，法律另有规定的除外。**删除受害人知悉日作为对第三人的并行起算锚点。** 本窗只标红旗，不写届满日。法定代理人资格未证则该行待核。

第一百九十四条：诉讼时效期间的最后六个月内，无或限制民事行为能力人没有法定代理人，或者法定代理人死亡、丧失民事行为能力、丧失代理权的，时效中止。只标红旗，转时效评估。
总则编解释第三十七条：原法定代理人造成损害且在代理终止后才知道的，转时效评估，本窗不写唯一终止日。

## 节点 2　监护人过错接口

对方主张监护人未看管：转介 `评估过错与原因力`。本任务只标：监护人过错**不消灭**未成年人固有请求。禁止在本窗写减轻比例或过失相抵序位。
禁止把监护人未尽职责写成未成年人无权索赔。
侵权人是其他未成年人时，其监护人责任走 1188，本窗填 `不打开`，转责任主体或共同侵权。教唆帮助无或限制行为能力人的第一千一百六十九条第二款不在本窗写终稿。

## 节点 3　邻接不打开

幼儿园、学校责任不在此展开过错推定或相应补充。接送途中、校外培训是否属于教育机构：本窗不判断，转 `评估教育机构责任`。该节填 `不打开`。
死亡赔偿近亲属分配填 `不打开`。
监护令、撤销指定填 `不打开`。
起诉状填 `不打开`。不选定法院。原告应为受害人本人，法定代理人应署明，仅作红旗。

---

## 节点 4　赔偿金与弃权

赔偿金一般归受害人，监护人保管。检索锚点：第三十四条、第三十五条。处分被监护人财产须为被监护人利益。禁止指导监护人挪用赔偿金。禁止法定代理人擅自放弃未成年人重大请求或代签概括弃权和解。用户要弃权或和解文本：该格停止，转介 `谈判人身损害和解` 或 `审查保险一次性了结弃权`。
本任务不生成起诉状。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过专项分流直接给等到十八岁或唯一截止日。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密且未获冲突豁免，then 整体停止，不得选边治愈。
若 if 用户提出伪造年龄、改出生日期、伪造伤情、隐匿既往、倒签或违法取证，then 整体停止；第一次提出即停。
若 if 日期、送达或动态规则未核验，then 期限字段停止，不编造唯一截止日，不选定法院。
若 if 金额参数不足，then 该行标未知，禁止写零。

口头转述、截图和「已读」不得写成已受理、已送达或代理已成立。判断状态只许三值。禁止胜诉率。

## 本任务回链纪律

本任务成果是「法定代理人闭合表」。不包含：完整时效表、教育机构终稿、死亡分配、监护令、起诉状、1188 终稿。禁止 191 扩张到普通伤害；禁止 190 用于第三人；禁止监护人过错消灭未成年人请求。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接。
风险档 A：不可逆文书或期限字段必须单独标可逆性。
