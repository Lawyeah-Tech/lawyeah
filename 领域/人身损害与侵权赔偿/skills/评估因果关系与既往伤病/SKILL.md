# 评估因果关系与既往伤病

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“事实因果、法律因果、参与度接口和鉴定分流”。不作医学诊断。诊疗过错主轴转医疗。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算、鉴定和证据清单。

## 工作边界

正触发：对方主张既往伤病、自身疾病或介入因素切断或降低因果，需要单独判断。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 诊疗过错或医疗损害鉴定主轴（转医疗）；
- 只要伤残等级条款争议（转 `评估伤残等级争议`）；
- 要求作出医学诊断或直接写参与度百分比。

不作医学诊断，不输出唯一参与度百分比。

## 建立工作坐标

确认：使用者与授权；单方立场；事故或侵害事实；既往病史材料；对方主张；已有鉴定参与度；介入治疗或第二次外伤；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 病历、影像、既往史；`R#` 鉴定；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Cau#` 因果行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验因果关系一般规则和人身损害赔偿中既往伤病的实务口径须结合现行解释。不虚构案件系统。

工具不可用时继续事实、主体、程序文书状态和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [因果关系方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　医疗主轴分流

诊疗过错转医疗。就医记录可留作损害证据。

### 节点 2　事实因果

时间顺序、机制吻合、排除明显无关。

### 节点 3　法律因果与相当性

相当因果关系待核，不写成必然医学证明标准或必然民事推定。

### 节点 4　参与度接口

参与度鉴定事项、检材、对赔偿项目的映射。

### 节点 5　输出纪律

既往史必须入卷，不得为用户删除。

## 停止与安全

- `整体停止`：立场不明；用户坚持隐匿既往病史。
- `字段停止`：法律因果规则、参与度鉴定事项未核验。
- `目标停止`：主目标变为医疗损害鉴定或自行诊断。
