# 评估因果关系与既往伤病

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成 `Cau#` 表：事实因果、法律相当因果、既往伤病与介入因素分列、特殊体质接口（待核）、参与度鉴定事项与检材、对赔偿项目的映射缺口（不填数字）。不作医学诊断。不输出唯一参与度百分比。有既往伤病不等于侵权人不赔，也不等于当然按参与度打折。第一千一百七十三条减轻须受害人过错；参与度鉴定不是第一千一百七十三条本身。不写过错百分比终稿、伤残等级争议终稿、鉴定异议文书、医疗损害鉴定或测算。

`depends-on` 为空。过错百分比转 `评估过错与原因力`。等级比较转 `评估伤残等级争议`。异议稿转 `提出伤残鉴定异议或重新鉴定`。分项金额转 `测算人身损害赔偿`。诊疗过错转医疗。

## 工作边界

正触发：需要单独判断既往伤病、自身疾病、特殊体质、介入因素是否切断或降低法律因果，或参与度鉴定事项如何开口。主张全部由本次侵权造成、或对方主张切断或降低，均可。用户要「有病就不赔」「参与度百分之四十打全部项目」「蛋壳一律全赔」「时间先后即因果」「直接写参与度百分比」仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要过错形态、原因力或唯一责任百分比终稿（转 `评估过错与原因力`）；
- 只要伤残等级争议比较终稿（转 `评估伤残等级争议`）；
- 只要鉴定异议或重新鉴定文书（转 `提出伤残鉴定异议或重新鉴定`）；
- 诊疗过错或医疗损害鉴定主轴（转医疗）；
- 只要测算或必得总额（转 `测算人身损害赔偿`）；
- 只要起诉状（转 `提起人身损害一审`）；
- 工伤认定、劳动能力鉴定或工伤待遇主轴且无民事因果争点（转劳动）；
- C 端只要大众准备包（只分流）；
- 未成争改合同（审查起草搁置）。

「写参与度百分比」「有病就不赔」「作出医学诊断」不在负触发表。指导隐匿既往走整体停止，不走负触发。

## 建立工作坐标

确认：使用者与授权；单方立场；事故或侵害事实；既往病史材料；对方或己方主张；已有鉴定参与度表面；介入治疗或第二次外伤；法域。

口头「本来就有病」「医生说有关系」「保险说四六开」只登记 `S#`。

同时掌握双方秘密或受害人与侵权人、保险人利益冲突未解：`整体停止`，不得以选边治愈，也不得改走负触发去出因果表。提出隐匿既往、删除或裁剪病历、伪造无既往证明、按索赔或拒赔口径改诊断、威胁医务人员或鉴定人：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 病历、影像、既往史；`R#` 鉴定；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Cau#` 因果行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。接口状态只用 `打开`、`不打开`、`待核`。技能正文中的条号和公报、指导性案例不是已核验 `L#`。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民法典第一千一百六十五条因果关系；第一千一百七十三条过失相抵须受害人过错（特殊体质不是过错，不得单靠本条减免）；第一千一百七十五条第三人造成损害。特殊体质一般不得单独作为减轻事由须运行时核验，不得凭记忆写一律全赔或一律减免。不可用则法律因果、体质减免开闭、项目映射字段停止。噪声：已失效《侵权责任法》第二十六条、第二十七条，2003 年人身损害赔偿解释已删除过失相抵条文。禁止把指导性案例第二十四号或公报案例写成 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变减免或映射的条文正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补有既往不等于不赔、参与度不得打全部项目、介入因素不必然中断的实务反例。
- `search_case_by_fact` 对特殊体质、既往伤病叠加外伤等只比较差异与翻转条件，不写必然全赔或必然减免，不编造案号。

工具不可用时继续时间线、病历表面、介入因素编目；法律效果字段停止。不得凭记忆写有病不赔、蛋壳全赔或百分之四十打全部。

## 判断节点

执行顺序和停止条件以 [因果关系方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场与不关窗

诊疗过错转医疗。错误主张不关窗。双方秘密或隐匿既往提出即停。

### 2. 事实因果

只有时间先后依据不足。介入因素分列，不必然中断。

### 3. 法律因果与特殊体质

相当性待核。1173 须过错。特殊体质待核，禁止一律全赔或一律减免。

### 4. 参与度接口与映射缺口

鉴定百分比须质证，不是当然法律结论。不得乘全部项目。不宣布唯一百分比。

### 5. 鉴定分流与纪律

只转介。既往史必须入卷，不得为用户删除。不定残，不选定法院。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；提出隐匿既往、删病历、伪造无既往证明、改诊断、威胁医务人员或鉴定人。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。
- `字段停止`：法律因果规则、特殊体质减免开闭、参与度事项未核验。用户要唯一参与度百分比、有病就不赔、蛋壳一律全赔或时间先后即因果则该格停止，窗口不关。
- `目标停止`：主目标变为过错百分比终稿、等级争议终稿、异议文书、医疗鉴定、测算、诉状或自行诊断。

禁止指导隐匿既往或伪造病历。不给胜诉率。不选定法院。不保证必得。不代提交。本窗不定残、不作医学诊断。
