# 因果关系方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。接口状态只用 `打开`、`不打开`、`待核`。禁止胜诉率、唯一参与度百分比、唯一责任比例、必得总额、选定法院、伤残等级。未知金额不写零。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。指导性案例、公报案例只可作类案比较材料，不得写入 `L#`。`search_law` 返回已失效《侵权责任法》第二十六条、第二十七条，2003 年人身损害赔偿解释已删除过失相抵条文，或已失效《合同法》时记为噪声，不得写入 `L#`。禁止把特殊体质写成已核验的第一千一百七十三条减免。禁止用刑事或工伤因果关系标准完成本窗民事终稿。

`Cau#` 固定列：`编号｜主张人｜主张分型（事实因果表面/特殊体质/既往独立原因力/介入切断或降低/参与度意见质证）｜指向损害项目｜材料表面作用机制｜证明负担方｜来源｜判断｜待核`。一行一主张。禁止在效果列填唯一百分比。

## 节点 0　分流、立场与不关窗

整案转出只交付第 1、2、10 节。

| 信号 | 处理 |
| --- | --- |
| 诊疗过错、病历真实性或医疗损害鉴定主轴 | 转医疗；本次就医可留作损害证据 |
| 工伤认定、劳动能力鉴定或工伤待遇主轴且无民事因果争点 | 转劳动；民事因果段可留则留，仍不得套工伤认定标准 |
| 海事 | 转海事 |
| 未成争只要改合同 | 审查起草本窗搁置 |

「有病就不赔」「参与度百分之四十打全部项目」「蛋壳一律全赔」「时间先后即因果」「直接写参与度百分比」**不关窗**。

二次手术：原侵权后果可留本窗；新诊疗过错段转医疗。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出隐匿既往、删除或裁剪病历、伪造无既往证明、按索赔或拒赔口径改诊断、威胁医务人员或鉴定人，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　证明负担

| 主张分型 | 通常主张人 | 最低表面 | 禁止写法 |
| --- | --- | --- | --- |
| 事实因果表面 | 主张全部由本次侵权造成的一方 | 侵害在先、损害在后；病历或影像表面描述与机制可对应 | 口头「肯定是这次」；本窗读片；仅时间先后即已证 |
| 切断或降低 | 主张切断或降低的一方（通常被告或保险人） | 既往或介入如何作用于该损害项目（哪份材料哪一页、何种机制候选） | 口头「本来就有病」升格切断；未交旧病历即无既往或即有病 |
| 特殊体质 | 主张因此减免的一方 | 须指向可核验规则；检索锚点包括指导性案例第二十四号，规则待核 | 「蛋壳一律全赔」或「一律减免」写成已核验 |
| 参与度鉴定意见 | 引用该意见作为减赔或抗辩的一方 | 委托事项、检材、结论页码；拟映射项目 | 百分比即法律结论；未质证即采信；自动乘全部项目 |
| 行为过失相抵 | 不在本窗终稿 | — | 把未系安全带写成参与度；转 `评估过错与原因力` |

不能因对方、医院或保险人控制病历而推定既往存在或内容有利于任一方。不能因一方未提交既往就推定无既往。未提交记 `G#`。证明妨碍是否发生、发生后能否推定，未核验则字段停止。

## 节点 2　事实因果

若只有时间先后，事实因果填 `依据不足，无法形成结论`。机制吻合、排除明显无关。用户要时间先后即因果：该格 `现有依据不支持` 或不足，窗口不关。

介入因素分行：自身摔倒、第二次碰撞、不遵医嘱、第三人、后续诊疗。不得写成必然中断。不作影像读片诊断，只指出材料表面描述冲突。

---

## 节点 3　法律因果与特殊体质

侵权赔偿一般相当因果关系，待核。不写成必然医学证明标准或必然民事推定。刑事或工伤因果关系、劳动能力鉴定标准不得直接套用。

检索锚点第一千一百六十五条。第一千一百七十三条减轻须被侵权人对同一损害的发生或扩大有过错。特殊体质、骨质疏松、颈椎病本身不是过错，禁止用第一千一百七十三条当本窗减免终稿。过错形态转 `评估过错与原因力`。第一千一百七十五条第三人造成损害由第三人承担；不当然切断被告独立义务。

受害人特殊体质一般不得单独作为减轻侵权人责任的事由，运行时核验；未核验字段停止。禁止凭记忆写「蛋壳脑袋一律全赔」或「有病就不赔」。用户要这两种终稿：该格 `现有依据不支持` 或待核，窗口不关。指导性案例第二十四号不是 `L#`。

有既往伤病不等于侵权人不赔，也不等于当然按参与度打折。

## 节点 4　参与度接口与映射缺口

参与度鉴定是证据，须出示、质证，不是当然法律结论。百分比不得自动乘到医疗费、护理费、残疾赔偿金、精神损害等全部项目。精神损害、医疗费与残疾赔偿金映射可能不同，逐项标缺口 `待核`。

无鉴定：参与度格 `待核`；残疾类项目标无法估计，转介 `准备伤残鉴定材料`。禁止本窗宣布「参与度百分之四十」。用户要唯一百分比：数字格停止，接口表仍交付，窗口不关。

已有法院委托意见不服：转介 `提出伤残鉴定异议或重新鉴定`，本窗不写重新鉴定开闭终稿。`R#` 须标「待质证」。

## 节点 5　鉴定分流与输出纪律

需要因果或参与度鉴定材料：转介 `准备伤残鉴定材料`，本窗只交最小交接（争点、已编号检材线索）。治疗是否稳定不在本窗打开伤残闸。不出鉴定申请终稿。

既往史必须入卷，不得为用户删除。下一步只转介鉴定材料、异议、等级争议、过错窗、测算、发函、起诉。不选定法院。本窗不定残。不填测算数字。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过节点 0 直接写有病不赔或百分之四十打全部。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if 金额参数不足，then 该行标未知，禁止写零。
若 if C 端只要大众准备包，then 只分流不回改。

判断状态只许三值。

## 本任务回链纪律

本任务成果是「事实因果、法律因果、既往与介入分列、特殊体质待核、参与度接口」。不包含：过错百分比终稿、伤残等级争议终稿、鉴定异议文书、医疗损害鉴定、测算、诉状、医学诊断。禁止有病就不赔。禁止参与度打全部项目。禁止蛋壳一律全赔或一律减免。禁止时间先后即因果。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接。
