# 边界与路由

## 正触发

需要单独判断既往伤病、自身疾病、特殊体质、介入因素与法律因果，或参与度鉴定接口。主张全部由本次造成、或对方主张切断或降低，均可。用户要「有病就不赔」「参与度百分之四十打全部项目」「蛋壳一律全赔」「时间先后即因果」「直接写参与度百分比」仍正触发。

双方秘密、隐匿既往、伪造病历的停止，优先于负触发。不得改走负触发去出因果表。写百分比不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 过错形态、原因力或唯一责任百分比终稿 | `评估过错与原因力` |
| 伤残等级争议比较终稿 | `评估伤残等级争议` |
| 鉴定异议或重新鉴定文书 | `提出伤残鉴定异议或重新鉴定` |
| 诊疗过错或医疗损害鉴定 | 医疗医药领域 |
| 测算或必得总额 | `测算人身损害赔偿` |
| 起诉状 | `提起人身损害一审` |
| 工伤认定、劳鉴或待遇且无民事因果争点 | 劳动领域 |
| C 端只要大众准备包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「写参与度百分之四十」不在本表。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 诊疗过错、病历真实性 | 医疗医药领域 |
| 职业病工伤待遇主轴 | 劳动领域 |
| 死因刑事 | 刑事领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 受害人行为过错、1173 百分比 | `评估过错与原因力` |
| 两份等级打架 | `评估伤残等级争议` |
| 已有意见要异议稿 | `提出伤残鉴定异议或重新鉴定` |

| 调取旧病历 | `申请人身案件调查令或取证` |
| 分别侵权医学分割 | `评估共同侵权与连带按份` 只标接口 |

## 易混

「对方说我本来就有颈椎病所以他不赔」正触发；有病不赔格不支持或待核。「鉴定写参与度百分之四十，全部项目打四折」正触发；映射格只标缺口，不算总额。「帮我写成参与度百分之四十」正触发，百分比格停止。「蛋壳脑袋一律全赔」正触发，特殊体质格待核。「出事之后才疼所以一定有因果」正触发，时间先后格不足或不支持。「医生开错刀」转医疗。「鉴定等级条款用错」走等级争议。「帮我写重新鉴定申请」走异议窗。「所以只赔百分之三十或三七开」若争受害人过错走过错窗；若争参与度则本窗百分比格停止。「把既往史从材料里拿掉」第一次提出即整体停止。
