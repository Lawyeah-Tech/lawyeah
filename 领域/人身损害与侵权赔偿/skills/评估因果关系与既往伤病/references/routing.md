# 边界与路由

## 正触发

对方主张既往伤病、自身疾病或介入因素切断或降低因果，需要单独判断。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 诊疗过错鉴定 | 医疗医药领域 |
| 伤残条款争议 | `评估伤残等级争议` |
| 鉴定异议文书 | `提出伤残鉴定异议或重新鉴定` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 诊疗过错、病历真实性 | 医疗医药领域 |
| 职业病工伤 | 劳动领域 |
| 死因刑事 | 刑事领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“对方说我本来就有颈椎病”正触发。“医生开错刀”转医疗。“鉴定等级条款用错”走等级争议。
