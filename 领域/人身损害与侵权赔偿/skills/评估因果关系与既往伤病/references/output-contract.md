# 输出合同

按触发结果选择交付形状。禁止有病就不赔。禁止参与度百分之四十打全部项目。禁止蛋壳一律全赔或一律减免。禁止时间先后即因果。禁止唯一参与度百分比。禁止分项测算数字。禁止医学诊断或读片。禁止选边治愈。禁止代提交、选定法院。本窗不定残。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出（诊疗或医疗鉴定主轴；工伤劳鉴待遇主轴；海事；未成争改合同） | 第 1、2、10 节。禁止因果表、参与度百分比、映射金额 |
| 整体停止 | 第 1、10 节。禁止因果策略、选边方案、删病历步骤、无既往证明草稿。双方秘密、隐匿既往、删病历、伪造无既往或威胁改诊断时，整体停止优先于负触发；第一次提出即停，无选边治愈，无「坚持」门槛 |
| 用户要「有病就不赔」或「参与度百分之四十打全部」或「蛋壳一律全赔」或「时间先后即因果」或「写参与度百分比」（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；不得改走负触发关窗；成果不得标 `已形成` |
| 正触发且可评估 | 下列十节表头均出现；未核验的法律因果、特殊体质、参与度映射单元格填 `依据不足，无法形成结论` 或 `待核`；禁止为填满而写全赔、不赔或唯一百分比 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。双方秘密未解不得进入「部分形成」。每个 `Cau#` 必须带来源、证明负担方和判断三值。`L#` 不得直接抄技能内条号或公报案例。

## 1. 触发、单方立场、授权与成果状态

争点是否因果。双方秘密未解不得进入「部分形成」。

## 2. 来源登记与 MCP 调用表

病历既往史必须编号。口述旧病、保险口头百分比只登记 `S#`。MCP 未调用也留一行。侵权责任法第二十六条、公报当 `L#` 若返回则记噪声。

## 3. 医疗或工伤分流

诊疗主轴转出。本次就医可留作损害证据。工伤因果标准不得套民事。

## 4. 事实因果表

介入因素分列。时间先后格不支持或不足。不读片。

## 5. 法律因果与特殊体质

相当性待核。1173 须过错。特殊体质待核。有病不赔格不支持或待核。蛋壳一律全赔格待核或不支持。

## 6. 参与度接口

鉴定意见标待质证。禁止唯一百分比结论。无鉴定则待核，不宣布百分之四十。

## 7. 对赔偿项目的映射缺口

不得一律相乘医疗费、残疾赔偿金、精神损害。不填测算数字。

## 8. 最强反方与证据缺口

隐匿既往。不得因未交旧病历推定无既往。不得因对方控制病历推定有病。

## 9. 鉴定分流与下一步

只转介准备材料、异议、等级争议、过错窗、测算。不出鉴定申请终稿。不选定法院。不定残。

## 10. 缺口、停止项与提示

须列对方最强解释（有病就不赔、参与度百分之四十打全部项目、蛋壳一律全赔、时间先后即因果、参与度即法律原因力、未交旧病历即无既往、对方管病历所以推定有旧病、口头四六开已生效、选边即可继续）与证据缺口。

本成果不是医学诊断、不是过错百分比终稿、不是等级争议、不是异议文书、不是医疗鉴定、不是测算、不是诉状。
