# 准备侵权索赔通知

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的主张方立场下，形成“发送前侵权索赔通知包”：发送闸、通知正文、项目表（未知不写零）、到达设计、异议应对要点。

`depends-on` 为空。接受用户、律师或其他来源的等价评估、测算和证据清单。本任务不执行发送，不伪造送达。

## 工作边界

正触发：人身损害已发生，现有材料支持发出书面索赔，用户需要发送前稿和送达设计。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要总体评估或只要精算工作表；
- 材料尚不支持指明义务人和损害事实，用户却要“先发函吓人”；
- 只要起诉状或鉴定申请；
- 工伤认定申请或医疗损害鉴定申请；
- 海事事故。

本任务不生成诉状或鉴定申请，不把发送写成对方已认责，不给胜诉率。

## 建立发函坐标

确认：使用者与授权；主张方立场；拟发送对象（行为人、用人者、场所、保险人）；拟主张项目；评估或等价材料；法域；拟签发主体、拟发送日和送达渠道。

同时掌握双方秘密时先停。用户希望唯一金额，不构成把未知写成零的授权。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关文书；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求；`V#` 通知版本；`E#` 送达设计。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。通知状态只用 `草案`、`待发送`、`已发送待证明到达`、`已到达`、`停止`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验请求权基础和时效中断到达条件；`search_template` 只借通知栏目。工具不可用时继续事实和结构；中断效力和责任结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [发函方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 发送闸

义务人可指明、损害事实有材料支持。仅有情绪或“想今天发函”不得打开闸。工伤或医疗主轴转出。

### 2. 收件人与请求范围

按主体评估或等价材料列收件人。项目分列，未知标待补，禁止虚高总额。

### 3. 发送前正文

只写已支持事实、保留权利、答复期限待核、附件清单。不写罪名，不写必然胜诉，不倒签。

### 4. 到达设计

约定渠道、户籍或经营地址、备份送达和失败升级。已读不等于到达。本任务不执行发送。

### 5. 时效与不可逆提示

到达可能中断时效，须提示保留回证。成果保持 `待发送`。

## 停止与安全

- `整体停止`：立场不明；用户坚持伪造伤情、威胁曝光、倒签或违法取证。
- `字段停止`：责任结论、时效中断、答复法定期限未核验。
- `目标停止`：主目标变为诉状、鉴定或精算。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。发送闸未打开时不得交付发送前终稿。边界见 [路由](references/routing.md)。
