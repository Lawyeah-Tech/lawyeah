# 准备侵权索赔通知

## 任务目标

在明确、无利益冲突的单方立场下（受害人、近亲属或其受托律师，互斥），形成发送前侵权索赔通知草案：求偿闸、收件人与项目碎片、`Q#` 路径、`QC#` 求偿行（收件人切片／项目与金额假设／到达渠道与回证／中断接口／打开接口／`E#` 回链）。本窗 `QC#` 是求偿行草案，不是已发送，不是已到达，不是已中断，不是必得总额，不是精算终稿，不是起诉状，不是发送版。本窗闸名只能是求偿闸，禁止复用发送闸、催告闸、索赔闸、通知闸、主张闸、评估闸、侵权闸、名单闸、时效闸、鉴定闸、起诉闸、精算闸、立案闸。预留不得占用：立案闸、鉴定闸、起诉闸、精算闸、管辖闸、发送闸。本窗主行只能是 `QC#`，禁止 `QG#`、`TB#`、`LX#`、`SH#`、`HF#`、`CG#`、`QT#`、`A#`、`N#`、`M#`。主路径只用 `Q-求`，禁止用 `Q-函`、`Q-索`、`Q-告`、`Q-钟`、`Q-责`、`Q-体`、`Q-签`、`Q-日`、`Q-险`、`Q-诉` 作主路径。邻窗 `Q-求` 只作转介进本窗；本窗打开为主路径，不是已发出、不是已到达、不是已中断、不是必得、不是应起诉。求偿闸打开不等于已发送不等于已到达不等于已中断时效不等于项目必得不等于对方已认责不等于待发送终稿。草稿不是已发送。口头或已读不是到达。发出不是当然已中断。发错主体不当然中断对真正义务人。对保险人到达不当然中断对侵权人。认定书不是民事终局比例。构成侵权不是伤残已定。构成侵权不是项目必得。诉讼外索赔函无法定答复期。逾期不是视为同意。未知不写零。不执行发送。不代提交。不写精算终稿。不写起诉状。不选定法院。不定残。不定罪。不保证胜诉。

`depends-on` 为空。主成果是侵权总图转 `评估人身侵权责任`。主成果是精算工作表转 `测算人身损害赔偿`。主成果是只设计送达不写正文转 `设计人身案件通知送达`。主成果是起诉包转 `提起人身损害一审`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：人身损害已发生，主张方需要发送前索赔通知、项目表和到达设计，而不是只要总图或只要诉状。「今晚发函」「已读就算到了」「发出即中断」「不清楚先写零」「逾期视为同意」仍正触发，成果状态 `草案`。金额、到达、收件人未核验仍正触发：有可编号拟收件人名称或地址线索，且侵害或损害碎片可编号则求偿闸打开或半开，第 6 节出 `QC#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出发送版／必得／已中断终稿」才关闸，仍交十节，第 6 节不出 `QC#` 终稿，第 7 节不得出发送版、精算终稿或起诉状，窗口不关。用户要把草稿写成已发送、把已读写成到达、把发出写成当然中断、把未知写成零、把未稳定写成十级确定残金、把认定书写成终局乘数、把答复期写成法定七日、把逾期写成视为同意，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `QC#` 草案。不得因「不执行发送」「不写精算终稿」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是侵权总图（转 `评估人身侵权责任`）；
- 主成果是主体保险表终稿（转 `评估责任主体与保险覆盖`）；
- 主成果是时效表终稿（转 `评估人身损害诉讼时效`）；
- 主成果是管辖终稿或异议书（转 `评估人身损害管辖` 或 `提出人身案件管辖异议`）；
- 主成果是交强险或商业三者分账终稿（转 `评估道路交通事故责任与保险先行`）；
- 主成果是精算工作表（转 `测算人身损害赔偿`）；
- 主成果是伤残鉴定申请终稿（转 `准备伤残鉴定材料`）；
- 主成果是只设计送达不写正文（转 `设计人身案件通知送达`）；
- 主成果是保险一次性了结或弃权审查终稿（转 `审查保险一次性了结弃权`）；
- 主成果是向保险公司提交理赔申请材料（转 `准备交强险商业险索赔材料`）；
- 主成果是监控保存通知正文（转 `准备监控保存通知`）；
- 主成果是可提交一审起诉包（转 `提起人身损害一审`）；
- 主成果是首次应诉答辩（转 `应对人身损害一审`）；
- 主成果是完整证据卷（转 `建立人身损害证据案卷`）；
- 主成果是工伤认定、劳动能力鉴定或工伤待遇（转劳动领域；夹带第三人只开 `评估工伤与第三人侵权竞合` 接口）；
- 主成果是诊疗过错、病历或医疗损害鉴定（转医疗医药领域）；
- 海上运输或船舶事故（转海事领域）；
- 尚未发生损害，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）。

双方秘密、倒签、伪造送达或回证、虚增伤情金额、威胁曝光、违法取证**不在负触发表**，走整体停止。「草稿即已发送」「已读即到达」「发出即中断」「未知写零」「逾期视为同意」「先按十级」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不执行发送」「不写精算终稿」「不写起诉状」是交付禁令，不是负触发。主成果才转；出现「索赔」「发函」一词不是转出。综合提问夹带告谁、法院、金额终稿：窗口不关，对应格只开接口或负触发总图。

## 建立工作坐标

确认：发送授权；单方立场；拟收件人（行为人、用人者、场所、交强险／商业三者保险人）；拟主张项目；治疗是否相对稳定；了结或弃权文本；渠道；法域。

口头「今晚发函」「已读就算到了」只登记 `S#`／`V#`。不得升格已发送、已到达、已中断或必得，**不得单独算作开闸材料**。可编号拟收件人名称或地址线索，且侵害或损害碎片可编号可开闸。本窗不执行发送，不代提交，不写精算终稿，不写起诉状。

立场只许受害人、近亲属或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：求偿闸关闭，仍交十节，不是整体停止。无书面授权但单方立场已闭合、且已有碎片：求偿闸部分打开，仍交十节，不是整体停止。提出倒签、伪造送达或回证、虚增伤情金额、威胁曝光或违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。开口不等于立场闭合。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 保单、了结或弃权文本；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`QC#` 求偿行；`V#` 版本；`E#` 证据形态回链（授权、旧函、项目碎片形态，不是发送闸，不是已发送证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`QG#`、`TB#`、`LX#`、`SH#`、`HF#`。技能正文中的条号是检索锚点，不是已核验 `L#`。文件状态只用 `草案`、`待提交`、`停止`。金额或到达未闭合不得标 `待提交`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止合成「已经发出并中断」一笔。未知不写零。草稿 ≠ 已发送。已读 ≠ 到达。发出 ≠ 当然中断。认定书 ≠ 民事终局。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或文书范本检索。本窗是索赔通知草稿，范本只借索赔函栏目，**不要**升格「已发送／已到达／已中断／必得／已认责」，**不要**改写成起诉状。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现草稿即已发送、已读即到达、发出即中断、认定书即终局、项目必得的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条、交强险旧限额、把民诉电子送达须同意套到诉讼外当作现行规则。道交解释（二）法释〔2026〕9 号自 2026-06-30 施行；MCP 标「尚未施行」以施行日为准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的到达、中断、必得保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民法典第一百三十七条非对话到达相对人生效，已读不是到达。第一百四十条沉默不是意思表示。第一百九十五条中断须向义务人提出可识别请求且到达。时效规定（2020 修正）第八条书面或数据电文到达或应当到达；签收人范围分列。第一千一百七十九条项目类型不是闭集必得。第一千一百八十三条严重精神损害，不得编造法定下限。第一千二百一十三条先交强险再商业三者，本窗只开顺序与收件人候选，不是函面必列共同被告。人身损害赔偿解释（2022）被扶养人计入两金，禁止双计。噪声：已失效侵权责任法；2003 解释已删除条；交强险旧限额 11 万／1 万；1991 年道路交通事故处理办法项目条；把保险核定三十日写成诉讼外法定答复期。技能正文条号不是 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变到达、中断或收件人结论的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补草稿不是已发送、已读不是到达、发出不是当然中断、发错主体不中断真正义务人、认定书不是民事终局、构成侵权不是项目必得、未知不写零、答复期非法定、发送不是认责的反例。
- `search_template` 只借索赔函栏目（当事人／事件与损害／请求项目／金额待核／保留权利／非法定答复／附件／渠道回证）。范本总额栏、逾期视为同意句、此致某院、落款日、送达回证不得升格已发送、已到达、必得或待发送终稿。禁止改写成起诉状。禁止用催告、解除通知或民事起诉状改头换面。禁止用范本生成发送版。

工具不可用时继续收件人、项目碎片和 `QC#` 编目；到达、中断、必得字段停止。不得拒跑，不得凭记忆写成已发送、已中断或必得。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、求偿闸与不关窗

主成果才整案转出。双方秘密、倒签、伪造送达第一次停。草稿即已发送、已读即到达、发出即中断不关窗。闸关仍交十节，第 6 节不出 `QC#` 终稿。利益冲突未解不是整体停止。

### 2. 收件人与项目碎片

行为人、用人者、场所、交强险、商业三者分列。未稳定不得写确定残金。本节禁止出 `QC#` 终稿。

### 3. 求偿闸与路径 `Q#`

本节禁止出 `QC#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-求`。

### 4. 求偿行 `QC#`

收件人切片、项目与金额假设、到达渠道与回证、中断接口。状态 `草案`。禁止升格已发送、已到达、已中断、必得。无 `E#` 不得写已发送。

### 5. 精算、鉴定、时效、送达与起诉接口

精算、鉴定、时效、送达设计、起诉只开接口。第 7 节不得夹带 `QC#` 终稿、发送版或起诉状绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出倒签、伪造送达或回证、虚增伤情金额、威胁曝光或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：求偿闸关闭，仍交十节，不是整体停止。无书面授权但有碎片：求偿闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：金额、到达、中断、伤残、施行日未核验。草稿即已发送、已读即到达、发出即中断、未知写零、逾期视为同意、先按十级、认定书即终局：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `QC#` 草案。
- `目标停止`：主目标变为精算终稿、鉴定申请、起诉包或只设计送达。禁止把「草稿即已发送」当作用户错误主张时的目标停止；那是不关窗。

禁止指导倒签、伪造送达或虚增伤情。不给胜诉率。不定罪。不定残。不选定法院。不执行发送。不代提交。未知不写零。不写精算终稿。不写起诉状。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。求偿闸关闭仍交十节，第 6 节不出 `QC#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `QC#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。求偿闸未打开时不得交付「已发送」或「必得」。边界见 [路由](references/routing.md)。
