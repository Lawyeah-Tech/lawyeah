# 准备侵权索赔通知方法

本文件是可执行判断节点。草稿不是已发送。口头或已读不是到达。发出不是当然已中断。发错主体不当然中断对真正义务人。对保险人到达不当然中断对侵权人。认定书不是民事终局比例。构成侵权不是伤残已定。构成侵权不是项目必得。诉讼外索赔函无法定答复期。逾期不是视为同意。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已发送、已到达、已中断终稿、必得总额、选定法院、代提交、未知写零。本任务不定罪，不定残，不执行发送，不写精算终稿或起诉状。本窗闸名只能是求偿闸，禁止复用发送闸、催告闸、索赔闸、通知闸、评估闸、侵权闸、名单闸、时效闸、鉴定闸、起诉闸。预留不得占用：立案闸、鉴定闸、起诉闸、发送闸。本窗 `QC#` 是求偿行。主路径只用 `Q-求`，禁止用 `Q-函`、`Q-索`、`Q-告`、`Q-钟`、`Q-责`、`Q-签` 作主路径。本窗 `Q-签` 只作「稿即已发送、已到达、已中断或已提交」不关窗码。本窗 `Q-读` 只作「已读即到达或即中断」不关窗码。本窗 `Q-日` 只作「唯一截止日或法定七日十五日答复期」不关窗码。英文 id 禁止使用，一律用中文技能名 `准备侵权索赔通知`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条、交强险旧限额、把民诉电子送达须同意套到诉讼外时记为噪声。禁止指导倒签、伪造送达或虚增伤情。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现收件人或项目碎片扫描，不是默认闭集。
`QC#` 固定列：`编号｜收件人切片｜项目与金额假设｜到达渠道与回证｜中断接口｜打开接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已经发出并中断」一笔。无 `E#` 不得写已发送、已到达或已中断。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-求`。禁止 `QG#`、`TB#`、`LX#`、`SH#`、`HF#`、`A#`、`N#`。一行一个收件人。文件状态只用 `草案`、`待提交`、`停止`。金额或到达未闭合不得标 `待提交`。

口头「今晚发函」「已读就算到了」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。函面、落款、寄出、拟制四类日期均不得早于本次形成日。

实务上：交强险保险人是收件人候选，不是发函法定必列。共同被告不是连带。本车人员受害与开门杀致车外第三人分两行。未稳定不得写确定残金。被扶养人生活费计入两金，禁止双计。

## 节点 0　分流、立场、求偿闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、倒签、伪造送达或回证、虚增伤情、威胁曝光、违法取证不进负表。利益冲突未解不进整体停止。不执行发送、不写精算终稿、不写起诉状不是负触发。

整案转出只交付第 1、2、10 节，不出 `QC#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是侵权总图 | 负触发 `评估人身侵权责任` |
| 主成果是主体保险表终稿 | 负触发 `评估责任主体与保险覆盖` |
| 主成果是时效表终稿 | 负触发 `评估人身损害诉讼时效` |

| 主成果是精算工作表 | 负触发 `测算人身损害赔偿` |
| 主成果是伤残鉴定申请终稿 | 负触发 `准备伤残鉴定材料` |

| 主成果是工伤认定／劳鉴／待遇 | 整案转劳动；夹带第三人只开 `评估工伤与第三人侵权竞合` |
| 主成果是诊疗过错／病历／医疗鉴定 | 整案转医疗医药 |
| 海上运输或船舶事故 | 整案转海事 |
| 尚未发生损害，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 「不执行发送」「不写精算终稿」「不写起诉状」 | 交付禁令，不是负触发 |

混合信号：工作中第三人伤害，民事函可留，工伤期限只红旗。出现「索赔」「发函」一词不是转出。出现了结或弃权：对该相对人字段停止，转介 `审查保险一次性了结弃权`，窗口不关。

求偿闸打开（可出 `QC#` 草案，仍不得标「已发送／已到达／已中断／必得」）须同时满足：单方无冲突立场已闭合；主成果是索赔通知草稿，不是总图、不是精算、不是诉状；至少一名可编号拟收件人名称或地址线索，且侵害或损害碎片可编号。口头「今晚发函」不算单独开闸材料。

求偿闸部分打开：已有碎片，但金额、到达或收件人未闭合；对应格待核；仍交十节。无书面授权但单方立场已闭合且已有碎片：求偿闸部分打开，仍交十节，不是整体停止。

求偿闸关闭（仍正触发）：无一可编号碎片。「今天必须出发送版／必得／已中断终稿」而无最小碎片不得开闸。不出 `QC#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `QC#` 终稿，**第 7 节不得出发送版、精算终稿或起诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已发送」「已读即到达」「发出即中断」「未知写零」「逾期视为同意」「先按十级」「认定书即终局」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `QC#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 求偿闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出倒签、伪造送达或回证、虚增伤情金额、威胁曝光或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　收件人与项目碎片

一行一个收件人。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `QC#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 收件人 | 行为人、用人者、场所、交强险、商业三者分列 | 合成唯一义务人；登记车主当然连带终局 |
| 项目 | 已支持事实与金额状态分列；未稳定不得写确定残金 | 1179 闭集必得；先按十级；精神损害法定下限 |
| 互斥 | 医保／工伤已付、了结弃权红旗 | 被扶养人与两金双计 |

检索锚点（写入 `L#` 前须核验）：民法典第一百三十七条、第一百九十五条、第一千一百七十九条、第一千一百八十三条、第一千二百一十三条；时效规定第八条；人身损害赔偿解释被扶养人计入两金。噪声：侵权责任法；2003 解释已删除条；交强险旧限额。

交强险保险人是收件人候选，不是发函法定必列。审理中应当共同被告不得写入函面「依法必须把保险公司列为收件人」。本车人员受害与开门杀致车外第三人分两行。不得把本车人员请求写成当然交强险请求。认定书只作事实叙述附件，不得写成民事终局比例或「依法按全责」。不得因次责丢掉该车交强险收件人。

## 节点 3　求偿行 `QC#`

按已出现收件人扫描，不是默认闭集。每条须能指向收件人、项目或到达接口之一。正文只写已支持事实、保留权利、非法定答复、附件清单。禁止罪名、以刑逼民、终局比例、保证胜诉、虚假票据、倒签、威胁曝光、「逾期视为同意」、滞纳金、伤残等级预测。

无 `E#` 不得写已发送、已到达或已中断。状态 `草案`。一次只推荐下一步。未知金额不写零，不输出必得总额。未稳定：残疾赔偿金、护理依赖、误工截止不得写入确定数字、十级或系数；函面只写「另行核算／鉴定后主张」。

热冲突强制处理：

- 草稿即已发送／已读即到达／发出即中断／未知写零／逾期视为同意／先按十级／认定书即终局 → 该格不支持或字段停止；仍出其他 `QC#`。
- 无一碎片 → 关闸，不出 `QC#` 终稿，窗口不关。
- 指导倒签、伪造送达、虚增伤情、威胁曝光 → 整体停止，不是该格不支持。

到达渠道预列实施人、文本版本、渠道、地址、回证、失败升级。优先书面可核验渠道。诉讼文书电子送达与诉讼外信件／数据电文主张分列。微信已读、无回复、口头转述不得单独写成已到达。本窗不执行发送，不补造回证。用户事后送达事实只开时效窗或送达设计窗接口，本窗不得升格已发送或已到达。

## 节点 4　精算、鉴定、时效、送达与起诉接口

第 7 节只开接口，不得夹带 `QC#` 终稿、发送版、精算终稿或起诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待收件人编号」，不得补写已发送或必得。不选定法院。不代提交。不执行发送。未稳定不得转介启动鉴定。需要合法催告到达设计转介 `设计人身案件通知送达`。

下一步只转介：`评估人身侵权责任`、`评估责任主体与保险覆盖`、`评估人身损害诉讼时效`、`设计人身案件通知送达`、`测算人身损害赔偿`、`准备伤残鉴定材料`、`提起人身损害一审`、`审查保险一次性了结弃权`、`评估道路交通事故责任与保险先行`、`评估工伤与第三人侵权竞合`、`评估侵权人不明路径`、`准备交强险商业险索赔材料`、`建立人身损害证据案卷`、`谈判人身损害和解`、`评估人身损害管辖`、`分流刑民交叉`、`准备监控保存通知`。禁止此致某院。

若 if 用户催促「今晚发出就算送到／已读就是中断／不清楚先写零／逾期视为同意／先按十级」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「求偿闸与发送前索赔通知草案」。本窗不执行发送。不包含：发送版、精算终稿、起诉状、已到达证明。禁止选边治愈。禁止草稿即已发送。禁止已读即到达。禁止发出即中断。禁止指导倒签或伪造送达。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标求偿终稿已形成。
风险档 A：倒签、伪造送达或回证、虚增伤情、威胁曝光必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：机动车事故有认定书和急诊病历，治疗未相对稳定。用户主张今晚发出就算送到、微信已读就是中断、保险公司接了函对驾驶人也断了、认定书全责就按全责写乘数、先按十级写残疾金、不清楚营养费先写零、请于七日内答复逾期视为同意、去某区法院。求偿闸打开或半开。`Q-签`、`Q-读`、`Q-报`、`Q-认`、`Q-残`、`Q-零`、`Q-日`、`Q-视`、`Q-院` 不打开为可靠路径。第 6 节不得把已发送、已中断、终局乘数、十级、0、法定七日写入可执行 `QC#`；对应格 `现有依据不支持` 或字段停止；仍出收件人分列、已支持医疗费、另行核算残金、非法定答复、渠道回证预列等其他 `QC#`。不关窗。不执行发送。不选定法院。不定残。

场景②：用户同时交出己方「必须今晚发出」与对方「从未收到」口径，并指导「落款改到上周、补一份已签收」。命中双方秘密＋倒签＋伪造送达。第一次整体停止。只交第 1、10 节。不出 `QC#`。不得问代表哪一方后继续。不以「坚持」为门槛。
