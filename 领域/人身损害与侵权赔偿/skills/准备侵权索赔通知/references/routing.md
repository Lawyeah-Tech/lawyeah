# 边界与路由

## 正触发

人身损害已发生，主张方需要发送前索赔通知、项目表和到达设计。从零、碎片、金额或到达未核验仍正触发：有可编号拟收件人名称或地址线索且侵害或损害碎片可编号则闸开或半开，出 `QC#` 草案，保持草案。本次不执行发送、不写精算终稿是交付禁令，不是开窗条件。草稿即已发送、已读即到达、发出即中断，仍正触发。把未稳定写成十级、把逾期写成视为同意，仍正触发：该格不支持，不改负触发关窗。

双方秘密、倒签、伪造送达的停止，优先于负触发。上述信号不在下表。不执行发送不是负触发。「草稿即已发送」「已读即到达」「发出即中断」「未知写零」「逾期视为同意」「先按十级」不在下表。

## 易混

本窗闸名只能是求偿闸，不是发送闸，不是催告闸，不是索赔闸，不是侵权闸，不是时效闸，不是起诉闸。`QC#` 不是 `HF#`，不是 `SH#`，不是 `CG#`，不是 `QG#`，不是 `LX#`。主路径是 `Q-求`，不是 `Q-函`，不是 `Q-索`，不是 `Q-告`，不是 `Q-责`，不是 `Q-钟`。`发送闸`／`HF#`／`Q-函` 是合同包 `准备解除通知`。`索赔闸`／`SH#`／`Q-索` 是合同包 `准备索赔或违约金主张通知`。邻窗 `评估人身侵权责任` 与 `评估人身损害诉讼时效` 的索赔通知转介已改挂 `Q-求`。草稿不是已发送。已读不是到达。发出不是当然中断。认定书不是民事终局。民法通则不是现行。已失效侵权责任法不是现行。提出「落款改到上周、补一份已签收」整体停止。本窗不执行发送，不代提交。不选定法院。不定残。不写发送版。不写必得总额。不保证胜诉。
