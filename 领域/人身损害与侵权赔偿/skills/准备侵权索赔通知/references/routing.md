# 边界与路由

## 正触发

材料已能支持书面索赔，需要发送前通知和送达设计。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要总图，或综合提问夹带管辖／精算终稿 | `评估人身侵权责任` |
| 只要主体名单 | `评估责任主体与保险覆盖` |
| 精算 | `测算人身损害赔偿` |
| 鉴定申请 | `准备伤残鉴定材料`（鉴定闸未开则停止转介启动） |
| 起诉 | `提起人身损害一审` |
| 只设计送达不写正文 | `设计人身案件通知送达`（未安装则 `unavailable`） |
| 保险一次性了结、权益转让为主成果 | `审查保险一次性了结弃权` |
| 工伤认定或医疗损害鉴定主轴 | 劳动／医疗领域 |
| C 端大众准备包 | 只分流不回改 |

受害人开口且委托范围是索赔通知时，不因口语化咨询整体停止。双方秘密、倒签或威胁曝光的整体停止，优先于负触发。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 收件人、借用、未投保形态待核 | `评估责任主体与保险覆盖` |
| 时效并行情景、中断能否成立 | `评估人身损害诉讼时效` |
| 交强险分账、无责限额 | `评估道路交通事故责任与保险先行` |
| 向保险公司提交理赔申请材料 | `准备交强险商业险索赔材料` |
| 治疗未稳定却要定残金额 | 鉴定闸关闭；转介条件见 `准备伤残鉴定材料` |
| 了结／弃权文本 | `审查保险一次性了结弃权` |
| 工作中第三人 | `评估工伤与第三人侵权竞合` |

## 易混

“先发函主张权利并留痕”正触发。还不知道找谁却要发函：仍正触发，发送闸关闭，不出终稿，转介主体或侵权人不明路径，不以负触发溜走。发送闸关闭时只交付关闭理由和补证。
