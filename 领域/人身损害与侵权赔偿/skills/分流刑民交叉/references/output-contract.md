# 输出合同

按触发结果选择交付形状。分流闸未打开不得交付分流终稿或定罪结论。禁止有刑事就不能民事。禁止先刑后民一律中止。禁止逃逸或酒驾对受害人当然拒赔交强险。禁止选定法院。禁止已读、口头已抓当立案。禁止代报案。禁止选边治愈。不定罪。不定残。不代提交。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 分流闸关闭或节点 0 整案转出 | 第 1、2、10 节。禁止定罪、刑事辩护终稿、附民比较终稿。对第三人 `Civ#` 可留时不得因工伤整案转出 |
| 整体停止 | 第 1、10 节。禁止 `Spl#`／`Civ#` 策略包、选边、入罪或出罪步骤。双方秘密、伪造伤情、谅解换假证、干预定罪第一次即停，优先于负触发；无选边治愈，无「坚持」门槛 |
| 用户要有刑事就不能民事、保证中止、逃逸拒赔、定罪、选定某院、尚未刑事出附民终稿（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；闸未开则仍只交 1、2、10；不得改走负触发关窗；不得标分流终稿 `已形成` |
| 正触发且闸开 | 下列十节表头均出现；未核验格填待核；禁止为填满而定罪、保证中止或写成交强险当然拒赔 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入分流终稿已形成。双方秘密未解不得进入「部分形成」。每个 `Spl#`／`Civ#` 必须带来源和判断三值。`L#` 不得直接抄技能内条号。有刑事就必须中止、逃逸拒赔若返回则记噪声。稿件状态默认 `草案`。

## 1. 触发、单方立场、授权与成果状态

谁需要刑民边界。分流闸是否打开。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。不定罪。稿件默认 `草案`。

## 2. 来源登记与 MCP 调用表

`S/R/D/L/I/G/Spl/Civ/V`。口头已抓、已读只登记 `S#`／`V#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 信号 `Spl#`

分级分列。不定罪。口头已抓不得填已立案。轻微伤可能只治安。

## 4. 民事可继续 `Civ#`

对第三人、交强险、商业三者、救助基金、工伤分袋。先刑后民不是一律中止。逃逸不是交强险对受害人当然拒赔。

## 5. 转刑事停止项

辩护、强制措施、会见、控告、定罪、量刑停止并转刑事。不写步骤。

## 6. 附民接口红旗

物质损失可附民只提示。精神损害开闭待核。保险人通常需另行民事。比较终稿不在本窗。

## 7. 谅解与保险逃逸

民事弃权范围只红旗。量刑转刑事。交强险与商业险分袋。救助基金只转介，不保证拨付。

## 8. 工伤与邻接拆分

工伤段分流，民事可留。高空抛物实体只转介。拒执只打红旗。

## 9. 下一步与转介

转介附民比较、打架路径、交通保险、认定书、救助基金、诉保、刑事领域只点名。不打开则填 `不打开`。不写成报案指令、立案指令或发送版。不代提交。不选定机关。

## 10. 缺口、停止项与提示

须列对方最强解释：有刑事就不能民事、保证先刑后民必须中止、逃逸所以交强险拒赔、这就是交通肇事罪、微信已读就算立案、附民当然能要精神损害、两边材料选边写、先做假伤情再报案、用谅解换改伤情、口述截止日必须写入。

本成果不是定罪、不是刑事辩护、不是附民状、不是打架请求表、不是报案回执、不是发送版、不是唯一截止日、不是选定法院。不代提交。不定罪。
