# 刑民分流方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。稿件状态只用 `草案`、`分流闸关闭`、`提交前待核`、`停止`。禁止胜诉率、定罪结论、唯一截止日、选定法院、自行宣布伤残等级、保证中止、代提交、未知写零。本任务不定罪，不代报案，不代提交。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、已失效法释〔2000〕47 号、2012 年刑诉解释旧条、2017 年民事诉讼法约第一百五十条直接当现行中止条、把有刑事写成必须中止一切民事、把逃逸或酒驾或交强险条例第二十二条写成对第三人人身当然拒赔、把附民精神损害写成当然能要或另行民事永远不能要、把口头已抓写成已立案、轻微伤即定罪时记为噪声，不得写入 `L#`。禁止指导伪造伤情入罪或出罪、用谅解换假证或干预定罪。

`Spl#` 固定列：`编号｜信号类型（故意伤害／交通肇事／逃逸／过失致人重伤死亡／高空抛物／拒执／其他）｜分级（仅行政／可能刑事／已受案／已立案｜口头已抓不得填已立案）｜伤情表面（轻微伤／轻伤待核／死亡｜不得自行定级）｜来源（S#／R#）｜是否已告知附民权利（待核）｜判断三值｜状态｜来源回链`。一信号一行。不定罪。

`Civ#` 固定列：`编号｜民事袋（对第三人侵权／交强险／商业三者／救助基金／工伤待遇｜禁止混袋）｜是否可继续（可／中止待核／停止）｜中止是否以另一案结果为必要（是／否／待核）｜逃逸或酒驾对受害人交强险（不当然拒赔／追偿另袋）｜判断三值｜转介｜状态｜来源回链`。

口头「已经抓了」、微信已读只进 `S#`／`V#`，不得升格 `R#` 已立案或 `Spl#` 已立案。

## 节点 0　分流、立场、分流闸与不关窗

整案转出或闸关闭只交付第 1、2、10 节或标注停止的 `Spl#`／`Civ#`，不得交付定罪结论、刑事辩护终稿或附民比较终稿。闸部分打开时：仅对可回链的信号或民事袋给出草案，其余行停止或不打开。

| 信号 | 处理 |
| --- | --- |
| 主成果是刑事辩护、控告、强制措施或会见 | 负触发刑事领域 |
| 已进入刑事（至少有受案或立案 `R#`）且主成果是附民比较或附民状 | 负触发 `评估刑附民与另行起诉` |
| 尚未刑事也要出附民终稿 | **正触发**，该格不支持，窗口不关，不出附民终稿 |
| 主成果是尚未刑事的打架请求表 | 负触发 `评估打架伤害民事路径` |
| 主成果是交通保险先行且不要刑民边界 | 负触发 `评估道路交通事故责任与保险先行` |
| 主成果是认定书复核 | 负触发 `复核交通事故认定` |
| 主成果是救助基金或垫付申请 | 负触发 `申请道路救助基金或垫付` |
| 主成果是一审起诉状 | 负触发 `提起人身损害一审` |
| 纯民事无刑事信号 | 负触发相应民事原子 |
| 纯工伤且无第三人刑事或民事信号 | **整案转劳动，交第 1、2、10 节**，不是负触发一句；夹带第三人则本窗正触发，工伤段分流，`Civ#` 可留并转介 `评估工伤与第三人侵权竞合` |
| 未成争改合同 | 审查起草本窗搁置 |

分流闸打开（可出 `Spl#`／`Civ#` 草案，仍不定罪、不代提交）须同时满足：单方无冲突立场与授权；存在可编号的刑事或行政违法信号；主成果是刑民边界，不是刑事辩护终稿、已进入刑事的附民比较终稿、打架请求表或起诉状。用户要定罪、保证中止、逃逸拒赔、选定法院、尚未刑事出附民终稿：**仍开闸**，只关对应格，不阻 `Spl#`／`Civ#` 草案。伪造伤情、谅解换假证、干预定罪不在开闸清单，走整体停止。

闸关闭（仍正触发）：无任何信号却要定罪；完全无材料却要「保证民事必须中止」。闸未开则仍只交 1、2、10 节。

「有刑事就不能民事」「保证先刑后民中止」「逃逸交强险当然拒赔」「定罪」「选定法院」「尚未刑事出附民终稿」**不关窗**。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或受害人与可能责任人、保险人争同一份刑民策略且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出伪造伤情以入罪或出罪、用民事谅解换假证、倒签谅解、干预定罪或量刑交易，then 整体停止；第一次提出即停，不以「坚持」为门槛。不得改走负触发把干预定罪交到刑事领域当步骤。

## 节点 1　信号 `Spl#`

检索锚点：本任务不判断构成何罪。故意伤害、交通肇事、逃逸、过失致人重伤死亡、高空抛物只作信号。轻微伤表面可能仅治安，民事接口转 `评估打架伤害民事路径`，本窗不定罪、不定级。口头轻伤、「已经抓了」不得填 `Spl#` 已立案。

三套逃逸分列待核，禁止混行：刑法交通肇事逃逸（不定罪）、道路交通安全法逃逸（行政信号）、交强险与追偿意义上的逃逸（保险袋）。本窗只作 `Spl#` 信号。

已受案与已立案分列。口头「已经抓了」不得填已立案。已读、截图不得起算任何刑事或附民期间。

高空抛物刑民：本窗只标信号，实体转 `评估物件脱落坠落与高空抛物`。拒执：只打红旗，转介 `应对人身损害执行`，不给对抗执行或逃避履行步骤。车不明与人逃逸分袋：车不明转介 `评估侵权人不明路径`，人逃逸且车辆已查明则交强险袋可留。

## 节点 2　民事可继续 `Civ#`

检索锚点：本案必须以另一案的审理结果为依据，而另一案尚未审结的，中止诉讼。2023 年民事诉讼法常见第一百五十三条第五项一类，条号运行时核验，不是 `L#`。2017 年约第一百五十条不得默写为现行 `L#`。不是「有刑事线索就一律中止一切民事」。交强险直接请求、救助基金垫付、对保险人的保险合同纠纷通常不因肇事刑事而当然中止，待核。刑事未决不得据此否定民事赔偿请求。

逃逸：机动车参加交强险的，保险人在限额内赔偿；机动车不明、未投保或抢救费用超过限额，救助基金垫付后可追偿。检索锚点：民法典第一千二百一十六条。无证、醉酒、故意制造事故对第三人人身，交强险限额内赔后追偿。检索锚点：道路交通事故损害赔偿解释第十五条一类。逃逸、酒驾**不是**对受害人当然拒赔交强险。人逃逸且车辆已查明：交强险限额内仍可能赔，追偿另袋；车不明或未投保：救助基金接口，申请终稿转 `申请道路救助基金或垫付`。商业险免责待核，不得抄进交强险袋。

工伤待遇与交通肇事或第三人伤害同时：工伤段分流劳动，对第三人 `Civ#` 可留。

## 节点 3　转刑事停止项与谅解

定罪、无罪、强制措施、会见、控告状、量刑意见：本窗停止，转刑事领域。不写步骤。

谅解：民事弃权范围只红旗，展开转 `起草人身损害和解协议`／`审查保险一次性了结弃权`。量刑效果转刑事。本窗不写刑事事实认定、证据采信、定罪或量刑步骤；刑事和解从宽是否适用待核并转刑事领域，不得在本窗写成「和解不得从宽」或「和解等于已定罪」。用谅解换假证＝整体停止。

附民接口：被害人因犯罪遭受物质损失可提起附带民事诉讼。因犯罪主张精神损失在附民或另行民事中的开闭须运行时核验；不得写成附民当然能要，也不得写成另行民事永远不能要。检索锚点：2021 年刑诉解释第一百七十五条一类。本窗只红旗，比较终稿仅在已进入刑事且主成果是比较时转 `评估刑附民与另行起诉`。保险人通常需另行民事，本窗只红旗。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过分流闸直接给定罪、保证中止或逃逸拒赔。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if C 端只要大众准备包，then 只分流不回改。

判断状态只许三值。口头转述、截图和「已读」不得写成已立案、已告知附民或期限已起算。事故认定书不得单独写成刑事定罪或民事终局比例。

## 本任务回链纪律

本任务成果是「不代提交的刑民边界与民事可继续对照」。必须包含：分流闸；不定罪；有刑事不关民事窗；先刑后民不是一律中止；逃逸不是交强险对受害人当然拒赔。不包含：刑事辩护终稿、附民比较终稿、打架请求表、起诉状。禁止选边治愈。禁止把有刑事就不能民事、保证中止、定罪写成负触发或整体停止（伪造伤情、干预定罪除外）。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标分流终稿已形成。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接。
风险档 A：伪造伤情、谅解换假证、干预定罪必须单独标可逆性。
