# 边界与路由

## 正触发

出现故意伤害、交通肇事、逃逸等刑事线索，需要刑民边界和停止项。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 刑事辩护控告 | 刑事领域 |
| 附民路径终稿 | `评估刑附民与另行起诉` |
| 无刑事信号的民事 | 相应民事原子 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 全部刑事成果 | 刑事领域 |
| 工伤认定不影响刑事 | 劳动并行 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“这事会不会变成交通肇事，民事还能不能告”正触发。“帮我做无罪”转刑事。“已经起诉了选附民”走附民专项。
