# 边界与路由

## 正触发

出现故意伤害、交通肇事、逃逸、过失致人重伤死亡或高空抛物等刑事信号，需要刑民边界和停止项。「这事会不会变成交通肇事，民事还能不能告」正触发。有刑事就不能民事、保证先刑后民必须中止、逃逸或酒驾交强险当然拒赔、定罪、选定某院、尚未刑事也要附民终稿，仍正触发：分流闸可关，对应格停止，窗口不关。工伤待遇与对第三人事故同时出现，仍正触发：工伤段分流劳动，对第三人 `Civ#` 可留。

双方秘密、伪造伤情入罪或出罪、用谅解换假证、干预定罪的停止，优先于负触发。不得改走负触发去出一方分流或把干预定罪交到刑事当步骤。有刑事就不能民事、保证中止、逃逸拒赔、定罪不在下表。伪造伤情、双方秘密不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 刑事辩护、控告状、强制措施或会见 | 刑事领域 |
| 附民与另行起诉比较或附民状 | `评估刑附民与另行起诉` |
| 尚未刑事或只要打架民事请求表 | `评估打架伤害民事路径` |
| 交通责任与保险先行且不要刑民边界 | `评估道路交通事故责任与保险先行` |
| 认定书复核终稿 | `复核交通事故认定` |
| 救助基金或垫付申请终稿 | `申请道路救助基金或垫付` |
| 一审起诉状 | `提起人身损害一审` |
| 纯民事且无刑事信号 | 相应民事原子 |
| 纯工伤待遇且无第三人刑事或民事信号 | 劳动领域 |
| C 端只要大众准备包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「先做假伤情再报案」「用谅解换改鉴定」不在本表，走整体停止。不得因「要求定罪」把民事窗关掉；定罪请求本身若主成果是刑事辩护才负触发刑事。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 全部刑事成果且不要民事边界 | 刑事领域 |
| 仅工伤待遇且无第三人 | 劳动领域 |
| 海事 | 海事领域 |
| 指导伪造伤情、谅解换假证或干预定罪 | 整体停止；刑事只打红旗，不得用来出步骤 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。对第三人 `Civ#` 可留。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 附民或另诉比较 | `评估刑附民与另行起诉` |
| 打架民事请求 | `评估打架伤害民事路径` |
| 交通保险先行 | `评估道路交通事故责任与保险先行` |
| 认定书 | `复核交通事故认定` |
| 救助基金 | `申请道路救助基金或垫付` |
| 诉保 | `直接起诉保险公司` |
| 保险人应诉 | `保险公司应对直接索赔` |
| 工伤第三人 | `评估工伤与第三人侵权竞合` |
| 高空抛物实体 | `评估物件脱落坠落与高空抛物` |
| 精神损害 | `评估精神损害赔偿` |
| 时效 | `评估人身损害诉讼时效` |
| 拒执 | `应对人身损害执行`（只红旗） |
| 刑事辩护 | 刑事领域 |

## 易混

「这事会不会变成交通肇事，民事还能不能告」正触发。「有刑事就不能民事、保证必须中止、逃逸交强险拒赔、这就是交通肇事罪」正触发不关窗，对应格不支持。「帮我做无罪」主成果是刑事辩护才负触发刑事。「已经起诉了选附民」负触发 `评估刑附民与另行起诉`。「只是互殴要赔偿清单」负触发打架路径。「两边材料都给你、先做假伤情」整体停止。
