# 分流刑民交叉

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成不代提交的刑民边界包：分流闸、`Spl#` 信号分级（仅行政／可能刑事／已受案／已立案）、`Civ#` 民事可继续行、转刑事停止项。不定罪。不定伤残。不写刑事辩护、强制措施、会见、控告状终稿。不默认起草附民比较终稿。不保证民事不被中止。不选定法院。不写死唯一截止日。有刑事线索不是当然关闭民事窗。先刑后民不是一律中止一切民事。逃逸、酒驾不是交强险对受害人当然拒赔。

`depends-on` 为空。附民与另行起诉比较转 `评估刑附民与另行起诉`。尚未刑事的打架请求表转 `评估打架伤害民事路径`。交通保险先行转 `评估道路交通事故责任与保险先行`。认定书复核转 `复核交通事故认定`。救助基金转 `申请道路救助基金或垫付`。对保险人起诉转 `直接起诉保险公司`。定罪、辩护、量刑转刑事领域。拒执只打红旗，不给出对抗步骤。

## 工作边界

正触发：出现故意伤害、交通肇事、逃逸、过失致人重伤死亡或高空抛物等刑事信号，需要刑民边界和停止项。「这事会不会变成交通肇事，民事还能不能告」正触发。有刑事就不能民事、保证先刑后民必须中止、逃逸或酒驾交强险当然拒赔、保证附民能要精神损害、选定某院、口头已立案即起算、尚未刑事也要附民终稿、定罪，仍正触发：分流闸可关，对应格填 `现有依据不支持` 或字段停止，窗口不关，不得改走负触发，不得标分流终稿已形成，不得写成已定罪。工伤待遇与对第三人事故同时出现：本窗正触发，工伤段分流劳动，对第三人的 `Civ#` 可留。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是刑事辩护、控告状、强制措施或会见方案（转刑事领域）；
- 主成果是附民与另行起诉比较终稿或附民状（转 `评估刑附民与另行起诉`）；
- 主成果是尚未刑事或只要打架民事请求表（转 `评估打架伤害民事路径`）；
- 主成果是交通责任与保险先行分账且不要刑民边界（转 `评估道路交通事故责任与保险先行`）；
- 主成果是认定书复核终稿（转 `复核交通事故认定`）；
- 主成果是救助基金或垫付申请终稿（转 `申请道路救助基金或垫付`）；
- 主成果是一审起诉状（转 `提起人身损害一审`）；
- 纯民事且无刑事信号；
- 纯工伤待遇且无第三人刑事或民事信号（转劳动）；
- C 端只要大众准备包（只分流）；
- 未成争改合同（审查起草搁置）。

有刑事就不能民事、保证中止、逃逸交强险当然拒赔、定罪、选定法院、尚未刑事出附民终稿**不在负触发表**，窗口不关。双方秘密、伪造伤情入罪或出罪、用谅解换假证、干预定罪**不在负触发表**，走整体停止。

## 建立工作坐标

确认：使用者与授权；单方立场（受害人／可能责任人分列，不得同时策略）；事实信号；是否已报案、受案或刑事立案（分列，口头不算）；民事请求目标；是否夹带交强险、救助基金或工伤；法域。

口头「已经抓了」「已经立案」、截图、「已读」只登记 `S#`／`V#`。不得升格为已刑事立案、已告知附民权利、期间已起算或已定罪。用户坚持「这就是交通肇事罪」「保证民事必须中止」不构成定罪或打开中止格的授权。

同时掌握双方秘密，或受害人与可能责任人、保险人同时交材料争同一份刑民策略：`整体停止`，不得以选边治愈，也不得改走负触发去出一方分流或转刑事把干预定罪交出去。一方已开口且委托范围就是本方刑民边界、且未掌握对方秘密时，可推定该单方立场。只要同时掌握双方秘密，无例外整体停止。提出伪造伤情以入罪或出罪、用民事谅解换假证或假鉴定、倒签谅解、干预定罪或量刑交易：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`R#` 受案回执、立案告知、事故认定；`D#` 伤情、票据；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Spl#` 信号；`Civ#` 民事可继续；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。稿件状态只用 `草案`、`分流闸关闭`、`提交前待核`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。本任务默认 `草案`，不代提交。不定罪。禁止「有刑事就不能民事」「逃逸交强险当然拒赔」「此致某院」「已读即立案」。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：被害人因人身权利受到犯罪侵犯遭受物质损失的，有权在刑事诉讼过程中提起附带民事诉讼；因犯罪主张精神损失，附带民事诉讼或单独提起民事诉讼，人民法院一般不予受理；本案必须以另一案的审理结果为依据而另一案尚未审结的，中止诉讼，不是有刑事线索就一律中止一切民事；机动车驾驶人发生交通事故后逃逸，该机动车参加交强险的，由保险人在交强险限额内赔偿；机动车不明、未投保或抢救费用超过限额的，由道路交通事故社会救助基金垫付；无证、醉酒等致第三人人身损害，请求交强险限额内赔偿应予支持，保险人赔后可追偿。技能正文条号不是 `L#`。噪声：已失效《侵权责任法》、已失效法释〔2000〕47 号刑事附带民事诉讼范围规定、2012 年刑诉解释旧条、有刑事就必须中止一切民事、逃逸或酒驾对受害人当然拒赔交强险、保证附民能要精神损害、口头或已读即已立案、选定法院、定罪、尚未刑事即可出附民终稿。不可用则中止条件、附民接口、精神损害开闭、交强险逃逸赔付字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变中止条件、附民接口、精神损害开闭或交强险逃逸赔付结论的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补先刑后民不是一律中止、刑事未决不得据此否定民事请求、逃逸交强险仍应限额内赔、轻微伤常走治安加民事、不保证中止的实务反例。
- `search_template` 只借分流说明栏目，不把范本当报案格式、已提交文本或指定唯一机关。

工具不可用时继续 `Spl#`／`Civ#` 编目与事实信号；中止、附民接口、精神损害开闭、交强险逃逸赔付字段停止。不得凭记忆写成有刑事就不能民事、逃逸交强险当然拒赔、保证中止或已定罪。

## 判断节点

执行顺序和停止条件以 [刑民分流方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、分流闸与不关窗

工伤三段分流，对第三人 `Civ#` 可留。双方秘密、伪造伤情、谅解换假证第一次停。有刑事就不能民事、保证中止、逃逸拒赔、定罪不关窗。主成果是附民比较或刑事辩护才负触发。

### 2. 信号 `Spl#`

仅行政／可能刑事／已受案／已立案分列。不定罪。口头已抓、已读不得升格立案。轻微伤可能只治安，民事走打架路径接口。

### 3. 民事可继续 `Civ#`

对第三人侵权、交强险、救助基金、工伤分列。先刑后民不是一律中止。逃逸不是交强险对受害人当然拒赔。商业险免责待核，不得与交强险混行。

### 4. 转刑事停止项

辩护、强制措施、会见、控告、定罪、量刑一律停止并转刑事。谅解的量刑效果转刑事；民事弃权范围只红旗。拒执只打红旗。

### 5. 转介与草稿

附民比较只转介。不代报案、不代提交。第 9 节不得写成报案或立案指令。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；受害人与可能责任人、保险人同时交材料；伪造伤情以入罪或出罪；用民事谅解换假证、串供或改伤情换从轻；倒签谅解；干预定罪或量刑交易。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。不得改走负触发「转刑事」把干预定罪交出去。
- `字段停止`：中止条件、附民接口、精神损害开闭、交强险逃逸赔付未核验。分流闸未开则比较终稿停止，窗口不关。用户要有刑事就不能民事、保证中止、逃逸交强险当然拒赔、定罪、选定法院、尚未刑事出附民终稿则该格停止，窗口不关。
- `目标停止`：主目标变为刑事辩护或控告、附民比较终稿、打架请求表、交通保险先行终稿、认定书复核、救助基金申请或起诉状。有刑事就不能民事、保证中止、定罪不在目标停止。

禁止指导伪造伤情、假证、倒签谅解或干预定罪。不定罪。不给胜诉率。不选定法院。不代提交。不编唯一截止日。不把未知写成零。不定残。不保证中止或附民范围。不把逃逸写成交强险对受害人当然拒赔。
