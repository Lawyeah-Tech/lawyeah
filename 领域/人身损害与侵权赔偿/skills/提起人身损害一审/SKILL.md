# 提起人身损害一审

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的原告立场下，形成可复核、不代提交的“人身损害一审起诉包”：起诉状草稿、分项诉讼请求、管辖连结点、证据目录、保全或先予执行红旗。

`depends-on` 为空。接受等价评估、测算、主体表和证据清单。

## 工作边界

正触发：人身损害已发生，用户已决定向人民法院提起一审，且不属于工伤待遇之诉、医疗损害主轴或海事专属。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 用户实为被告；
- 工伤认定或工伤待遇仲裁／诉讼为主成果；
- 诊疗过错医疗损害诉讼为主成果；
- 海事专属；
- 只要总体评估、索赔函或和解方案；
- 表面有效仲裁条款未排除且用户仍要求直接起诉。

C 端 011 只分流：用户只要大众网上立案材料且主体请求论坛已闭合时可提及 011；本技能仍负责专业请求判断，不回改 011。

本任务不代提交，不保证受理或胜诉，不写保全申请终稿。

## 建立起诉坐标

确认：使用者与授权；原告及近亲属；被告及保险人；拟请求；法域；事故认定、鉴定、保险状态；管辖连结点材料；是否已有案号。已有受理凭证时停止生成起诉入口。

同时掌握双方秘密时先停。口头转述不得写成已受理。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料；`R#` 机关文书；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求假设；`P#` 诉讼请求；`J#` 管辖连结点；`V#` 稿件版本；`E#` 送达凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验起诉条件、管辖、时效、交强险保险人诉讼地位；`search_template` 只借起诉状栏目。工具不可用时继续事实和证据目录；请求法律结论、管辖选定和期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [起诉方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 专项分流和起诉决定

工伤待遇、医疗主轴、海事转出。仲裁未排除不得写应起诉。

### 2. 原告适格与被告清单

死亡案件核验近亲属。保险人是否列为被告单独判断。不得编造被告。

### 3. 分项诉讼请求

第一千一百七十九条项目和精神损害分列。被扶养人生活费计入残疾或死亡赔偿金，禁止双计。未知不写零。

### 4. 管辖连结点

侵权行为地或被告住所地。材料不足不选定唯一法院。

### 5. 起诉状、证据目录与红旗

只交付草案。保全和先予执行只做红旗。不保证七日内立案。

## 停止与安全

- `整体停止`：立场不明；用户坚持虚假陈述或伪造票据。
- `字段停止`：管辖、时效、保险人地位未核验。
- `目标停止`：主目标变为保全终稿、鉴定申请或应诉。
