# 提起人身损害一审

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的原告立场下，形成可复核、不代提交的“人身损害一审起诉包”：起诉状草稿、分项诉讼请求、管辖连结点、证据目录、保全或先予执行红旗。

`depends-on` 为空。接受等价评估、测算、主体表和证据清单。本任务不代提交，不保证受理或胜诉。

## 工作边界

正触发：人身损害已发生，用户已决定向人民法院提起一审，且不属于工伤待遇之诉、医疗损害主轴或海事专属。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 用户实为被告（转 `应对人身损害一审`）；
- 主体、请求或“该不该告”尚未闭合，只要总图（转 `评估人身侵权责任`）；
- 只要索赔函或和解方案（转对应原子）；
- 工伤认定或工伤待遇仲裁／诉讼为主成果（转劳动）；
- 诊疗过错医疗损害诉讼为主成果（转医疗）；
- 海事专属（转海事）；
- 只要保全或先予执行申请终稿（转对应原子）；
- 只要大众网上立案材料且主体请求论坛已闭合（C 端 011，只分流，本任务不降级实施）。

本任务不代提交，不保证受理或胜诉，不选定唯一法院，不写保全或先予执行申请终稿，不输出唯一时效截止日或伤残等级。

## 建立起诉坐标

确认：使用者与授权；原告及近亲属；被告及保险人名称变体；拟请求；法域；事故认定、鉴定、保险状态；管辖连结点材料；是否已有案号。已有受理凭证时停止生成起诉入口。口头转述和“已读”不得写成已受理。

同时掌握双方秘密或未解利益冲突：`整体停止`，不得以选边治愈，也不得改走负触发去提交或应诉。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料；`R#` 机关文书；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求假设；`P#` 诉讼请求；`J#` 管辖连结点；`V#` 稿件版本；`E#` 送达凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。请求金额状态只用 `已核实金额`、`情景金额`、`无法估计`。技能正文中的条号是检索锚点，不是已核验 `L#`。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验起诉条件、管辖、时效、交强险保险人诉讼地位等将被写入 `L#` 的现行规则；不可用则这些字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变受理、管辖或被告地位的条文正文再写入 `L#`。不得编造 `regulation_id`，也不得把摘要条号写成已核验 `L#`。
- `search_practiced` 补立案登记、交强险共同被告和明确被告实务。
- `search_template` 只借起诉状栏目，不把范本当现行法或已提交文本。
- 特殊事实可用 `search_case_by_fact`。案例只比较差异，不写成必然受理或胜诉。

工具不可用时继续事实和证据目录；请求法律结论、管辖连结点效力、保险人地位和期限字段停止。本任务任何情况下都不选定唯一受诉法院。2017 年民事诉讼法第一百一十九条、第二十八条、第一百二十三条不得默写为现行 `L#`。

## 判断节点

执行顺序和停止条件以 [起诉方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、起诉闸和鉴定闸

工伤待遇、医疗主轴、海事转出。仲裁未排除：诉讼入口停止，不得写应起诉。已有案号停止起诉入口。任一未相对稳定信号（含内固定未取）：已发生费用可请求，残疾金无法估计，禁止转介启动评残，起诉状不得写评残申请或预估等级。

### 2. 原告适格与被告清单

死亡案件核验近亲属，不得擅自代表未授权亲属，不得把未到场近亲属列为共同原告或声明其已放弃。交强险保险人应当列为共同被告；垫付医疗费不等于限额内已赔清且无异议，不得因此删除。用户坚持只告司机：清单仍保留交强险接口并字段停止，不得从被告栏删除。商业三者仅在当事人请求时加入。不得编造被告，不得把全体业主或仅车牌／「肇事司机」写成确定被告。

### 3. 分项诉讼请求

项目分列。被扶养人生活费计入残疾或死亡赔偿金，禁止双计。未知不写零。不输出唯一必得总额。

### 4. 管辖连结点

侵权行为实施地、结果发生地、各被告住所地分列。**任何情况下都不选定唯一法院**，起诉状不得预填「此致某院」。公路等事故另核事故发生地等连结点。

### 5. 起诉状、证据目录与红旗

只交付草案。不利事实不得删除。保全和先予执行只做红旗。不保证七日内立案。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；用户提出虚假陈述、伪造票据或编造被告。整体停止优先于负触发。不以「坚持」为门槛。
- `字段停止`：管辖、时效、保险人地位、起诉条件条文未核验。
- `目标停止`：主目标变为保全终稿、鉴定申请、应诉、管辖异议或测算终稿。

禁止指导伪造、隐匿不利事实或代提交。不给胜诉率。
