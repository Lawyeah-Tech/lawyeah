# 提起人身损害一审方法

本文件是可执行判断节点。草稿不是已立案。网交回执不是已受理。口头或已读不是已送达。此致某院不是管辖已定。构成侵权不是伤残已定。构成侵权不是项目必得。过时效不是不能立案。交强险保险人应当列为共同被告。垫付医疗费不是可不列。未稳定不得填写确定残疾金。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已立案、应起诉、选定法院、代提交、未知写零、预测等级。本任务不定罪，不定残，不执行发送，不把草稿写成已立案。本窗闸名只能是起诉闸，禁止复用立案闸、鉴定闸、答辩闸、管辖闸、评估闸、侵权闸、人测闸、求偿闸。预留不得占用：立案闸、鉴定闸、答辩闸。本窗 `RQ#` 是诉状行。主路径只用 `Q-诉`，禁止用 `Q-责`、`Q-伤鉴`、`Q-人测`、`Q-人谈`、`Q-辩`、`Q-签`、`Q-院` 作主路径。本窗 `Q-签` 只作「草稿即已提交或已立案」不关窗码。英文 id 禁止使用，一律用中文技能名 `提起人身损害一审`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991 年民事诉讼法第一百二十二条开庭公告、2017 年第一百一十九条当现行起诉条件、2017 年第二十八条当现行侵权管辖、2017 年第一百二十三条当现行立案登记、2012 年道交解释第二十五条当现行共同被告条、已失效《侵权责任法》、把草稿写成已立案或把过时效写成不能立案时记为噪声。禁止指导伪造诉状、编造被告、倒签落款或虚假诉讼。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现请求碎片扫描，不是默认闭集。
`RQ#` 固定列：`编号｜请求切片｜原告适格与被告明确｜仲裁阻却与排除｜管辖连结点｜证据目录与保全红旗｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已立案」或「应起诉」。无 `E#` 不得写已立案。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-诉`。禁止 `QT#`、`SZ#`、`P#`、`J#`、`A#`、`N#`。文件状态只用 `草案`、`停止`。禁止标 `待提交` 为已立案。请求金额旁注只用 `已核实`、`情景`、`无法估计`。

口头「已经立案了」「过了就不能立」「某院一定管」「先按十级」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：医疗／误工／护理／伤残或死亡／精神损害／后续治疗／已付扣减分列。交强险应当共同被告，垫付不是除外。未稳定：残疾金、护理依赖 `无法估计`，禁止十级写入请求，禁止转介启动评残。材料不足不选定唯一法院。保全只做红旗。

## 节点 0　分流、立场、起诉闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、虚假诉讼、伪造票据或诉状、编造被告、倒签落款、违法取证不进负表。利益冲突未解不进整体停止。不代提交、不选定法院、不定残、不保证立案不是负触发。禁止把鉴定闸写进本窗节点 0。

整案转出只交付第 1、2、10 节，不出 `RQ#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是侵权总图或「该不该告」 | 负触发 `评估人身侵权责任` |
| 主成果是应诉答辩，用户为被告 | 负触发 `应对人身损害一审` |
| 主成果是索赔通知且不起诉 | 负触发 `准备侵权索赔通知` |
| 主成果是和解方案 | 负触发 `谈判人身损害和解` |
| 主成果是测算工作表 | 负触发 `测算人身损害赔偿` |
| 主成果是鉴定申请稿 | 负触发 `准备伤残鉴定材料` |
| 主成果是完整证据卷 | 负触发 `建立人身损害证据案卷` |
| 主成果是管辖终稿或异议书 | 负触发 `评估人身损害管辖` 或 `提出人身案件管辖异议` |
| 主成果是时效表终稿 | 负触发 `评估人身损害诉讼时效` |
| 主成果是保全申请终稿 | 负触发 `评估证据或财产保全必要性` 或 `准备财产或证据保全申请` |
| 主成果是先予执行申请终稿 | 负触发 `申请先予执行医疗费` |

| 主成果是保险人诉讼地位专项且不要完整起诉包 | 负触发 `直接起诉保险公司` |
| 主成果是已立案后庭审 | 负触发 `准备人身案件庭审` |
| 工伤待遇主轴 | 整案转劳动；夹带第三人只开 `评估工伤与第三人侵权竞合` |
| 诊疗过错医疗损害主轴 | 整案转医疗医药 |
| 海上运输或船舶事故 | 整案转海事 |
| 「不代提交」「不选定法院」「不定残」「不保证立案」 | 交付禁令，不是负触发 |

出现「起诉」「立案」「管辖」一词不是转出。司机加交强险的完整起诉包留本窗。

起诉闸打开（可出 `RQ#` 草案，仍不得标「已立案／已提交／应起诉」）须同时满足：单方无冲突立场已闭合；主成果是一审起诉包，不是答辩、不是保全终稿、不是总图、不是鉴定申请；至少一项可编号原告适格、请求类型或损害碎片。口头「已经立案了」不算单独开闸材料。表面有效仲裁未排除仍可开或半开，对应格不支持，不出起诉状终稿。无死亡且治疗未相对稳定：起诉闸打开或半开，残疾金格 `无法估计`，窗口不关。

起诉闸部分打开：已有碎片，但仲裁排除、管辖连结点、交强险地位或主体未闭合；对应格待核；仍交十节。无书面起诉授权但单方立场已闭合且已有碎片：起诉闸部分打开，仍交十节，不是整体停止。

起诉闸关闭（仍正触发）：无一可编号碎片。「今天必须出已立案终稿」而无最小碎片不得开闸。不出 `RQ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `RQ#` 终稿，**第 7 节不得出发送版起诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已立案」「网交即已受理」「有效仲裁仍应直接起诉」「过时效即不能立案」「此致某院即管辖已定」「构成侵权即项目必得」「先按十级」「垫付即可不列交强险」「未知写零」「七日立案已保证」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `RQ#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 起诉闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出虚假诉讼、伪造票据或诉状、编造被告、倒签落款或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。
若 if 已有受理凭证或案号，then 目标停止，转 `准备人身案件庭审`，不得继续生成起诉入口终稿。

## 节点 3　诉状行 `RQ#`

按已出现请求碎片扫描，不是默认闭集。每条须能指向请求、主体、仲裁、管辖或证据目录之一。

无 `E#` 不得写已立案。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止此致某院。未稳定：残疾金、护理依赖不得写入确定数字或十级。用户坚持只告司机：交强险行保留并字段停止，不得删除。

热冲突强制处理：

- 草稿即已立案／网交即已受理／有效仲裁仍应起诉／过时效即不能立案／此致某院／先按十级／垫付即可不列交强险／未知写零／七日立案已保证 → 该格不支持或字段停止；仍出其他 `RQ#`。
- 无一碎片 → 关闸，不出 `RQ#` 终稿，窗口不关。
- 指导虚假诉讼、伪造、编造被告、倒签 → 整体停止，不是该格不支持。
- 有效仲裁未排除 → 该格不支持，不出起诉状终稿，窗口不关。

## 节点 4　管辖、保全、鉴定与庭审接口

第 7 节只开接口，不得夹带 `RQ#` 终稿或发送版起诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待请求编号」，不得补写已立案。不选定法院。不代提交。未稳定不得转介启动评残。保全只列红旗。

下一步只转介：`评估人身侵权责任`、`评估责任主体与保险覆盖`、`评估人身损害管辖`、`提出人身案件管辖异议`、`评估人身损害诉讼时效`、`测算人身损害赔偿`、`准备伤残鉴定材料`、`建立人身损害证据案卷`、`谈判人身损害和解`、`准备侵权索赔通知`、`应对人身损害一审`、`直接起诉保险公司`、`申请先予执行医疗费`、`评估证据或财产保全必要性`、`准备财产或证据保全申请`、`评估死亡赔偿权利人与分配`、`评估道路交通事故责任与保险先行`、`准备人身案件庭审`。禁止此致某院。

若 if 用户催促「草稿写完就算立案了／过了就不能立／只告司机删交强险／先按十级／此致某院／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`／`无法估计`，禁止写 `0`。

若 if 起诉条件、仲裁协议效力、管辖连结点、交强险地位、施行日未核验，then 该强制项字段停止，窗口不关。

## 本任务回链纪律

本任务成果是「起诉闸与诉状行草案」。本窗不执行发送。不包含：已立案、已受理、发送版起诉状、保全终稿、鉴定申请。禁止选边治愈。禁止草稿即已立案。禁止过时效即不能立案。禁止指导伪造或虚假诉讼。起诉闸打开 ≠ 已立案 ≠ 应起诉 ≠ 管辖已定。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标起诉终稿已形成。
风险档 A：虚假诉讼、伪造、编造被告、倒签必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：机动车事故有认定书和急诊病历，治疗未相对稳定，保险公司已垫抢救费。用户主张草稿写完就算立案了、网交回执就算受理、过了三年就不能立、只告司机把交强险删掉、先按十级写残金、此致某区法院、不清楚营养费先写零。起诉闸打开或半开。`Q-签`、`Q-交`、`Q-职`、`Q-列`、`Q-残`、`Q-院`、`Q-零` 不打开为可靠路径。残疾金 `无法估计`。`Q-伤鉴` 不打开。交强险行保留并字段停止，不得删除。第 6 节不得把已立案、不能立案、十级、0、此致某院写入可执行 `RQ#`；对应格 `现有依据不支持` 或字段停止；仍出已发生医疗费请求、交强险共同被告接口、连结点并列等其他 `RQ#`。不关窗。不代提交。不选定法院。不定残。

场景②：用户同时交出己方「必须今晚立案、落款改到上周、被告先编个名字」与对方「从未侵权」口径。命中双方秘密＋倒签＋编造被告。第一次整体停止。只交第 1、10 节。不出 `RQ#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代违法方案。
