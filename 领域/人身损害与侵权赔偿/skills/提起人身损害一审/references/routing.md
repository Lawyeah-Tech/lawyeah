# 边界与路由

## 正触发

人身损害已发生，用户已决定向人民法院提起一审，需要起诉状草稿、分项请求、管辖连结点和证据目录。从零、碎片、管辖未核验、无书面起诉授权仍正触发：有可编号原告适格、请求类型或损害碎片则闸开或半开，出 `RQ#` 草案，保持草案。本次不代提交、不选定法院、不定残、不保证立案是交付禁令，不是开窗条件。草稿即已立案、过时效即不能立案、此致某院、垫付即可不列交强险、先按十级、未知写零，仍正触发。

双方秘密、虚假诉讼、伪造、编造被告、倒签落款的停止，优先于负触发。上述信号不在下表。不代提交不是负触发。「草稿即已立案」「网交即已受理」「过时效即不能立案」「此致某院即管辖已定」「垫付即可不列交强险」「先按十级」不在下表。虚假诉讼不在下表，走整体停止。

## 易混

本窗闸名只能是起诉闸，不是立案闸，不是鉴定闸，不是答辩闸，不是侵权闸。`RQ#` 不是 `QT#`，不是 `SZ#`，不是 `P#`，不是 `J#`。主路径是 `Q-诉`，不是 `Q-责`，不是 `Q-伤鉴`，不是 `Q-签`。`QT#` 是合同包 `提起合同纠纷一审`。`SZ#` 是公司治理 `提起股东权利诉讼`。起诉闸与 `Q-诉` 跨包复用，行分列为本窗 `RQ#`。邻窗 `评估人身侵权责任`、`测算人身损害赔偿`、`准备伤残鉴定材料`、`准备侵权索赔通知`、`建立人身损害证据案卷`、`谈判人身损害和解` 的起诉转介已挂 `Q-诉`。草稿不是已立案。网交回执不是已受理。过时效不是不能立案。垫付不是可不列交强险。此致某院不是管辖已定。1991 年民诉第一百二十二条开庭公告不是现行起诉条件。2012 年道交解释第二十五条不是现行共同被告条。提出「被告先编个名字、落款改到上周」整体停止。本窗不代提交。不选定法院。不定残。不写已立案。不保证七日立案。
