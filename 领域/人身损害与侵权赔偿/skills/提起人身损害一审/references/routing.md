# 边界与路由

## 正触发

已决定提起人身损害一审，需要起诉包，而不是总图、发函或应诉。

受害人开口且委托范围是起诉草稿时，不因口语化咨询整体停止。双方秘密、伪造或编造被告的停止，优先于负触发。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 该不该告、只要总图 | `评估人身侵权责任` |
| 被告应诉 | `应对人身损害一审` |
| 工伤待遇之诉 | 劳动领域 |
| 医疗损害主轴 | 医疗医药领域 |
| 海事 | 海事领域 |
| 只要评估、发函或和解方案 | 对应原子 |
| 只要管辖终稿 | `评估人身损害管辖` |
| 只要保全或先予执行申请终稿 | `评估证据或财产保全必要性` / `准备财产或证据保全申请` / `申请先予执行医疗费` |
| 只要大众网上立案 | C 端 011，只分流不回改 |
| 主成果是保险人诉讼地位专项终稿 | `直接起诉保险公司`；未安装则本任务内做保险人被告接口。司机＋交强险完整起诉包留本窗；分账终稿转 `评估道路交通事故责任与保险先行` |

表面有效仲裁条款未排除：不是“可以选边起诉”，也不是整案负触发；诉讼入口停止并转管辖原子，第 7 节禁止。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 连结点冲突、专属、仲裁、级别 | `评估人身损害管辖` |
| 知悉日不明或分相对人时效 | `评估人身损害诉讼时效` |
| 主体名称变体、未投保、借用 | `评估责任主体与保险覆盖` |
| 交强险分账、限额 | `评估道路交通事故责任与保险先行` |
| 金额参数不足 | `测算人身损害赔偿` |
| 治疗相对稳定且要评残 | `准备伤残鉴定材料`（闸关则禁止启动） |
| 死亡近亲属未闭合 | `评估死亡赔偿权利人与分配` |
| 工作中第三人 | `评估工伤与第三人侵权竞合` |
| 紧急医疗费 | `申请先予执行医疗费` |
| 已立案后追加或变更被告 | `追加变更责任主体`。诉前列交强险共同被告是本窗工作 |

## 易混

主体请求未闭合、用户仍在问“该不该告”时负触发至评估。已决定告且要诉状时正触发。未稳定“先按十级立案”：本窗鉴定闸关闭，残疾金无法估计，不转介启动评残。交强险已垫医疗费 ≠ 不必列保险公司为共同被告，须核验是否已在限额内赔付且当事人无异议。
