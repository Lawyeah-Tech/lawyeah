# 输出合同

按触发结果选择交付形状。禁止选定唯一法院。禁止把草稿写成已提交。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出 | 第 1、2、10 节。禁止请求矩阵、诉状草稿 |
| 整体停止 | 第 1、10 节。禁止诉状、被告清单、管辖结论。双方秘密或伪造时，整体停止优先于负触发 |
| 仲裁未排除或已有案号 | 第 1、2、4、10 节。禁止第 7 节起诉入口 |
| 鉴定闸关闭但仍正触发 | 十节表头均出现。残疾金、护理依赖确定额必须 `无法估计` 或另行主张。禁止转介启动评残。已发生费用请求可部分形成。本行优先于「正触发且可起草」 |
| 正触发且可起草 | 下列十节表头均出现；字段停止的单元格填 `依据不足，无法形成结论` 或 `待核`，禁止省略后改填选定法院、十级或必得总额 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。每个 `P#` 必须带金额状态。

## 1. 触发、单方立场、授权与成果状态

写明已决定起诉、冲突筛查和鉴定闸。双方秘密未解不得进入“部分形成”。

## 2. 来源登记与 MCP 调用表

`S/D/R/L/I/G/Q/P/J/V/E`。MCP 未调用也留一行。`L#` 不得直接抄技能内条号。

## 3. 原告适格与被告清单

死亡案件列近亲属授权，不得擅自代表未授权亲属。交强险应当共同被告接口及已赔例外必须可见。不得编造被告，不得列全体业主为确定连带被告。

## 4. 专项分流与仲裁红旗

工伤、医疗、海事命中则停止起诉入口。仲裁未排除不得写应起诉。已有案号停止起诉入口。

## 5. 逐项诉讼请求矩阵

项目分列。禁止被扶养人与两金双计必得。未知不写零。未鉴定不得填十级。不输出唯一必得总额。时效不得写毫无争议。

## 6. 管辖连结点表

实施地、结果发生地、各被告住所地分列。**禁止选定唯一法院**，即使用户指定某区。公路等事故另列事故发生地等。保险人住所地不得单独写成唯一管辖。级别管辖只待核。

## 7. 起诉状草稿

标注发送前复核，不代提交。不利事实不得删除。禁止谩骂。不得预填唯一受诉法院。鉴定闸关闭时不得写评残申请、预估等级或“评残后一并判决”。时效不得写毫无争议或唯一届满日。

## 8. 证据目录与保全／先予执行红旗

原件／副本、控制方必填。不附保全或先予执行申请终稿。

## 9. 风险与提交核验

不保证受理或胜诉。不保证七日内立案；补正后起算必须可见。C 端 011 只分流。

## 10. 缺口、停止项与提示

须列对方最强解释（管辖、时效、主体不适格、项目互斥、保险限额、未列交强险、仲裁条款）与证据缺口。

本成果不是立案回执、胜诉意见或已提交起诉状。
