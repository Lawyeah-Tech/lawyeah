# 保全现场监控与电子证据

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成合法固定步骤包：保全闸、`Psv#` 分载体步骤、完整性说明、禁止动作、邻居转介。不等于法院证据保全，不是搜查令。不写保存通知、调查令、公证事项或保全申请终稿。不指导侵入机房、收买监控员、私下拷贝或改元数据。不编法定覆盖天数。不因对方控制推定画面存在或内容有利。截图、转发压缩包、已读、口头「已经拷了」不得写成原件已固定或已保全。

`depends-on` 为空。保存函转 `准备监控保存通知`。是否申请法院保全转 `评估证据或财产保全必要性`／`准备财产或证据保全申请`。调查令转 `申请人身案件调查令或取证`。公证事项转 `准备人身案件公证保全`。建卷矩阵转 `建立人身损害证据案卷`。送达专项转 `设计人身案件通知送达`。

## 工作边界

正触发：现场、己方行车记录仪或手机视频、聊天可能灭失，需要合法固定步骤。不知机位、时段或覆盖天数仍正触发：保全闸可关，只交关闭理由和补证，不出完整步骤终稿。用户要「依法只循环七天」「今天必须拷完」「截图就算原件」「拒不给监控即败诉」仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关。工伤待遇与第三人／场所现场或己方电子同时出现：本窗正触发，工伤段分流劳动，现场与己方载体步骤可留。工地人身损害现场拍照正触发，不得因「工地／现场资料」误转建设工程；工程款、工期、质量、造价才转工程。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要保存通知正文（转 `准备监控保存通知`）；
- 已决定申请法院证据或财产保全且只要申请书（转 `准备财产或证据保全申请`）；尚未决定则转 `评估证据或财产保全必要性`；
- 只要调查令或法院取证申请终稿（转 `申请人身案件调查令或取证`）；
- 只要公证保全事项终稿（转 `准备人身案件公证保全`）；
- 只要建卷矩阵（转 `建立人身损害证据案卷`）；
- 只要送达渠道专项（转 `设计人身案件通知送达`）；
- 只要场所安保责任成立终稿（转 `评估场所安全保障义务`）；
- 只要索赔通知正文（转 `准备侵权索赔通知`）；
- 工程款、工期、质量、造价主轴（转建设工程领域）；
- C 端只要大众准备包（只分流）；
- 未成争改合同（审查起草搁置）。

侵入系统、破解密码、收买监控员、私下拷贝、偷拍卫生间／更衣室／住宅内部、改元数据、摆拍冒充原始现场、双方秘密**不在负触发表**，走整体停止。

## 建立工作坐标

确认：使用者与授权；单方立场；现场是否仍可合法进入；设备控制方分列（己方／对方／第三人）；聊天账号归属；行车记录仪是否循环覆盖及线索来源；已有介质是原始载体、导出文件还是截图；法域。

口头「一周就覆盖」「已经拷了」「物业已读就算保住了」只登记 `S#`。不得编造法定覆盖天数，不得把截图或已读写成已保全。

同时掌握双方秘密，或受害人与场所、物业、承运人同时交材料争同一份监控或步骤：`整体停止`，不得以选边治愈，也不得改走负触发去出一方步骤。受害人已开口且委托范围就是合法固定步骤、且未掌握对方秘密时，可推定主张方立场。只要同时掌握双方秘密，无例外整体停止。提出侵入系统、破解密码、收买监控员、私下拷贝、闯入封闭场所、偷拍隐私空间、窃听、改元数据、摆拍冒充原始现场：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 已有照片视频或导出文件；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Psv#` 步骤；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。步骤状态只用 `草案步骤`、`已实施待核原件`、`闸关闭`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。本任务默认 `草案步骤`，不代实施、不代提交。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：视听资料应提供原始载体；电子数据应提供原件（制作者与原件一致的副本或直接来源的打印件等输出介质视为原件）；以严重侵害他人合法权益、违反法律禁止性规定或严重违背公序良俗的方法形成或获取的证据不得作为认定根据；非法侵入计算机信息系统、非法获取计算机信息系统数据的禁止；诉讼外保存通知不等于民诉证据保全裁定；诉前证据保全须情况紧急且向证据所在地、被申请人住所地或有管辖权的人民法院申请，本窗不写申请书、不选定法院。技能正文条号不是 `L#`。噪声：已失效《侵权责任法》、把覆盖 7/15/30 天写成法定、截图即原件、已读或口头已拷即已保全、私录一律无效或一律合法、拒不给监控即败诉、保存步骤写成保全裁定、哈希作为真实性唯一法定核验。不可用则原件规则、排除效果、保全法律效果字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变原件、排除或保全入口的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补覆盖周期行业差异、对方控制不等于画面有利、保存通知不等于法院保全、截图不等于原件的实务反例。
- `search_case_by_fact` 只比较差异与翻转条件，不写成必然采信或必然排除。

工具不可用时继续载体编目和控制方登记；原件、排除、保全效果字段停止。不得凭记忆写法定覆盖天数或必然败诉。

## 判断节点

执行顺序和停止条件以 [现场电子保全方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、保全闸与不关窗

工伤三段分流，第三人／场所现场与己方载体可留。工地人身现场可留，造价才转工程。双方秘密或侵入第一次停。错误主张不关窗。

### 2. 现场合法性

仅合法可进入范围。不得闯入封闭工地或住宅。卫生间、更衣室、病房、宿舍偷拍第一次停。不得移动关键物证而不记录。

### 3. 己方电子数据与视听资料

导出原始文件，保留生成时间与设备。完整上下文。截图、转发包不得标原件已固定。不改元数据。

### 4. 对方控制载体只分流

只登记控制方、时段线索、覆盖红旗并点名转介。不得指导自助拷贝。不得推定存在或有利。

### 5. 完整性、禁止清单与邻接拆分

哈希可选核验，不是唯一法定。调查令常见前提是诉讼中法院签发。书证提出命令以诉讼中法院责令为前提。邻居终稿不写。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；受害人与场所同时交材料争同一份监控；提出侵入系统、破解密码、收买监控员、私下拷贝、闯入封闭场所、偷拍隐私空间、窃听、改元数据、摆拍冒充原始现场、威胁或伪造回证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：电子数据原件规则、非法证据排除、公证要件、调查令签发前提、诉前保全条件未核验。用户要法定覆盖天数、今天必须拷完、截图即原件、拒不给即败诉则该格停止，窗口不关；闸未开仍不出完整步骤终稿。
- `目标停止`：主目标变为保存通知、调查令、公证事项、法院保全申请、建卷矩阵、送达专项或索赔函终稿。法定七日或今天必须拷完不在目标停止。

禁止指导侵入、收买、私下拷贝或改元数据。不给胜诉率。不选定法院。不代实施。不代提交。不编唯一截止日。
