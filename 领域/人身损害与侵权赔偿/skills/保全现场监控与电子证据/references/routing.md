# 边界与路由

## 正触发

现场、己方行车记录仪或手机视频、聊天可能灭失，需要合法固定步骤。不知机位、时段或覆盖天数仍正触发，保全闸可关。用户要「依法只循环七天」「今天必须拷完」「截图就算原件」「拒不给监控即败诉」仍正触发。工伤待遇与第三人／场所现场或己方电子同时出现，仍正触发：工伤段分流劳动，现场与己方载体可留。工地人身损害现场拍照仍正触发，不得因工地关键词转工程。

双方秘密、同时交材料、侵入、收买、私下拷贝、偷拍隐私空间的停止，优先于负触发。不得改走负触发去出步骤或函。侵入不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 保存通知正文 | `准备监控保存通知` |
| 法院保全申请书 | `准备财产或证据保全申请` |
| 尚未决定是否申请法院保全 | `评估证据或财产保全必要性`；本窗合法自助步骤可留 |
| 调查令或法院取证申请终稿 | `申请人身案件调查令或取证` |
| 公证保全事项终稿 | `准备人身案件公证保全` |
| 建卷矩阵 | `建立人身损害证据案卷` |
| 送达渠道专项 | `设计人身案件通知送达` |
| 场所安保责任成立终稿 | `评估场所安全保障义务` |
| 索赔通知正文 | `准备侵权索赔通知` |
| 工程款、工期、质量、造价 | 建设工程领域 |
| C 端只要大众准备包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「直接去机房拷」「收买监控员」「从门缝拍卫生间」不在本表，走整体停止。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 仅工伤待遇且无第三人／场所现场或己方电子 | 劳动领域 |
| 病历封存或医疗鉴定检材终稿 | 医疗医药领域；场所现场与己方手机视频可留 |
| 海事专门程序 | 海事领域 |
| 工程造价主轴 | 建设工程；人身现场与己方电子不得误转 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。第三人／场所现场与己方载体可留。

## 易混

「行车记录仪要循环了，现场也要拍」正触发。「写一份让物业留监控的函」走保存通知。「还不知道哪台摄像头，但今天必须拷完，依法只有七天」仍正触发，闸可关，不编截止日，不写拷盘。「直接去机房拷」「给监控员好处费」第一次提出即整体停止。「公共区域都能拍，我从门缝拍卫生间监控」整体停止。「微信已读、截图发你，算保住了」仍正触发；已读和截图不得升已保全。「要法院保全裁定」走保全申请或必要性评估。「工伤也要认，商场监控还在转，我手机有几段」正触发，己方步骤可留，工伤段分流。「工地砸伤，今晚翻围挡进去拍」翻围挡第一次停；合法可进入范围内的现场步骤可留，不得转工程。
