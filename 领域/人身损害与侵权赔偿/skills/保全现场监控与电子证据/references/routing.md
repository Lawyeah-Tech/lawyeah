# 边界与路由

## 正触发

现场、监控、聊天、行车记录仪可能灭失，需要合法保全步骤。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 保存通知函 | `准备监控保存通知` |
| 调查令申请 | `申请人身案件调查令或取证` |
| 公证实施 | `准备人身案件公证保全` |
| 工程造价现场 | 建设工程领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 违法取证 | 停止 |
| 病历封存主轴 | 医疗医药领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“行车记录仪要循环了，现场也要拍”正触发。“写一份让物业留监控的函”走保存通知。“去机房黑进硬盘”停止。
