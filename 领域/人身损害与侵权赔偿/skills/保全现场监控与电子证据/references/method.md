# 现场电子保全方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。步骤状态只用 `草案步骤`、`已实施待核原件`、`闸关闭`、`停止`。禁止胜诉率、必然采信、必然败诉、唯一覆盖天数、选定法院、自行宣布伤残等级。未知金额不写零。本任务不写保存函、调查令、公证事项或保全申请终稿，不代实施，不指导违法取证。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文、把覆盖 7/15/30 天写成法定、把截图或已读写成原件已固定或已保全、把私录写成一律无效或一律合法、把拒不给监控写成必然败诉、把保存步骤写成民诉证据保全裁定、把哈希写成真实性唯一法定核验时记为噪声，不得写入 `L#`。禁止指导侵入系统、收买监控员或私下拷贝。

`Psv#` 固定列：`编号｜载体类型（现场可进入区域／己方手机或行车记录仪／聊天原设备／对方或第三人控制监控）｜控制方｜拟时段（猜测标S#）｜合法进入或取得依据｜本窗合法自助动作｜原始载体或原件位置｜保管链｜哈希或可信时间戳（可选核验，不得写成唯一法定）｜弱形式红旗（截图／转发压缩包／已读／口头已拷）｜状态｜转介（只点技能名）｜来源回链`。一行一个载体。禁止合成「全场监控一律已固定」。对方或第三人控制行不得填进入机房或私下拷贝。

视听资料与电子数据分列。原始载体优先于副本。己方控制才允许本窗自助步骤。

## 节点 0　分流、立场、保全闸与不关窗

整案转出或闸关闭只交付第 1、2、10 节，不交完整 `Psv#` 步骤终稿。闸部分打开时：仅对已满足条件的己方／现场行给出草案步骤，对方控制行只分流。

| 信号 | 处理 |
| --- | --- |
| 只要保存通知正文 | 负触发 `准备监控保存通知` |
| 已决定法院证据或财产保全申请书 | 负触发 `准备财产或证据保全申请` |
| 尚未决定是否申请法院保全 | 转 `评估证据或财产保全必要性`；本窗合法自助步骤可留 |
| 只要调查令或法院取证申请终稿 | 负触发 `申请人身案件调查令或取证` |
| 只要公证事项终稿 | 负触发 `准备人身案件公证保全`；本窗可将公证列为转介名 |
| 只要建卷矩阵 | 负触发 `建立人身损害证据案卷` |
| 只要送达渠道专项 | 负触发 `设计人身案件通知送达` |
| 只要 1198 成立终稿 | 负触发 `评估场所安全保障义务` |
| 工程款、工期、质量、造价主轴 | 转建设工程；工地人身损害现场与己方电子**不得**因「现场资料」误转 |
| 主轴仅工伤认定、劳鉴或待遇，且无第三人／场所现场或己方电子 | 整案转劳动；夹带第三人侵权或场所／车辆现场电子则本窗正触发，工伤段分流，步骤可留并转介 `评估工伤与第三人侵权竞合` |
| 诊疗过错、病历封存或医疗鉴定检材终稿 | 转医疗；场所现场与己方手机视频可留 |
| 海事专门程序 | 转海事 |
| 未成争只要改合同 | 审查起草本窗搁置 |

保全闸打开条件（对某一行，同时满足）：单方无冲突立场与授权；该载体在己方控制可导出，或现场仍可合法进入；主成果是合法固定步骤而非函、令、公证或申请终稿。

闸关闭（仍正触发）：全部载体均不知机位与控制方；现场已无法合法进入且无己方介质；目的是威慑或「今晚必须拷完」而无合法路径。「今天必须拷完」本身不得开闸。己方已有原始导出时，该行可开，不因对方监控不明而整表关闸。

「依法只循环七天」「今天必须拷完」「截图就算原件」「拒不给监控即败诉」**不关窗**。闸未开则仍只交 1、2、10 节。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或受害人与场所、物业、承运人同时交材料争同一份监控或步骤且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出侵入系统、破解密码、收买监控员、私下拷贝、闯入封闭工地或住宅、偷拍卫生间／更衣室／病房／宿舍／住宅内部、窃听、秘密定位、改元数据或时间戳、摆拍重建冒充原始现场、伪造回证、威胁或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　现场合法性

人身损害现场可记录：方位、地面状况、警示标志、照明、散落物位置。不得移动关键物证位置而不记录。

仅合法可进入范围。公共通道、已获许可的经营场所外沿、事故发生后仍开放的路面，可拍现场方位。禁止把「公共区域拍摄可」写成闭集：卫生间、更衣室、病房、宿舍、住宅内部、入户门内侧不是本窗拍摄对象；提出从门缝、隐蔽镜头或翻围挡拍摄上述空间，第一次即整体停止。

封闭工地、他人住宅不得指导闯入。未获许可进入则该行字段停止，改分流保存通知／公证／调查令／法院保全必要性，不给出入机房或翻围挡步骤。工地人身现场在可合法进入范围内拍摄，不得因工地关键词整案转工程。

无人机、隐蔽摄像头、跟踪尾随取证：第一次提出即停。

## 节点 2　己方电子数据与视听资料

己方行车记录仪、手机视频、聊天账号：导出原始文件，保留生成时间、设备与完整上下文。不得只截有利句。多份备份。哈希或可信时间戳可选核验，不得写成真实性唯一法定方法。

检索锚点：视听资料应提供原始载体；电子数据应提供原件；制作者与原件一致的副本或直接来源于电子数据的打印件等输出介质，视为原件。存储在电子介质中的录音、录像，适用电子数据规则。条号不是 `L#`。

弱形式红旗：截图、转发压缩包、二次压缩、已读、口头「已经拷了」不得标 `已实施待核原件` 为原件已固定，也不得写成已保全。最多登记为弱形式 `D#`，状态保持待核。

禁止指导修改时间戳、元数据或补拍后冒充事发当时。聊天须完整上下文。私录对话不是一律排除，也不是一律合法；提出偷录隐私空间或违反禁止性规定的方法，第一次即停。未核验排除规则则采信效果字段停止，仍须停止指导该类取证。

## 节点 3　对方控制载体只分流

对方或第三人控制的监控、物业机房、平台后台、他车记录仪：只登记控制方、时段线索、覆盖风险红旗，并点名转介。不能因对方控制而推定材料存在或内容有利。不得指导自助拷贝、远程登录、收买或进入机房。

失败升级只点转介名，本窗不写那些终稿：

- `准备监控保存通知`
- `评估证据或财产保全必要性`／`准备财产或证据保全申请`
- `申请人身案件调查令或取证`（常见前提是诉讼中人民法院签发，地区实践待核，不保证存在，不选定法院）
- `准备人身案件公证保全`（公证保全 ≠ 已鉴定，可被反证）
- `设计人身案件通知送达`

诉讼外保存通知不等于民诉证据保全裁定，不是搜查令。诉前证据保全须情况紧急，本窗不写申请书。书证提出命令或无正当理由拒不提交的推定，以诉讼中人民法院责令为前提，诉前不得写成已成立。用户要「不留就是输」：该格 `现有依据不支持` 或待核，窗口不关。

覆盖周期通常较短：标紧急红旗。不编造全国唯一法定 7／15／30 天，除非用户材料给出该场所或设备的周期线索并标 `S#`／`D#`。用户要「依法只循环七天」：该格 `现有依据不支持` 或待核，窗口不关，不得倒计时唯一截止日。

## 节点 4　完整性、禁止清单与邻接拆分

完整性说明只写：原始载体优先、保管链、未改元数据、弱形式红旗。哈希可选。公证内容经公证的电子数据，人民法院应当确认其真实性，但有相反证据足以推翻的除外——本窗不写公证书，不把公证写成不可推翻。

禁止清单命中即整体停止，不提供方法，不改走发函／公证／调查令包装：侵入、破解、收买、私下拷贝、闯入、偷拍隐私空间、窃听、改元数据、摆拍冒充原始现场、伪造回证。

邻接拆分：保存函、调查令、公证事项、保全申请、建卷、送达、1198 成立，一律目标停止或负触发并点名，不附终稿。

本任务不计算唯一覆盖截止日。不选定法院。不代实施。不代提交。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过保全闸直接给完整步骤终稿或已保全结论。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日或法定覆盖天数。
若 if C 端只要大众准备包，then 只分流不回改。

判断状态只许三值。口头转述、截图和「已读」不得写成已受理、已送达、已保全、原件已固定或覆盖期限已起算。事故认定书、调解记录不得单独写成民事终局比例。

## 本任务回链纪律

本任务成果是「人身损害现场与己方电子证据的合法固定步骤」。不包含：保存通知正文、调查令、公证事项、法院保全申请、建卷矩阵、送达专项、索赔函、1198 成立、工程造价。禁止侵入。禁止选边治愈。禁止截图当原件。禁止已读当已保全。禁止对方控制推定画面有利。禁止法定覆盖七天。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标步骤终稿已形成。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接：已固定载体表、控制方和缺口。
风险档 A：不可逆取证或期限字段必须单独标可逆性。
