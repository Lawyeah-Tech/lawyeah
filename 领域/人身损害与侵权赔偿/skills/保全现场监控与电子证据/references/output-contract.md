# 输出合同

按触发结果选择交付形状。保全闸未打开不得交付完整步骤终稿。禁止把本窗步骤写成法院证据保全裁定或搜查令。禁止侵入、破解、收买监控员或私下拷贝步骤。禁止偷拍卫生间、更衣室、住宅内部。禁止改元数据。禁止把截图、转发压缩包、已读或口头「已经拷了」写成原件已固定或已保全。禁止法定覆盖七天或唯一倒计时。禁止拒不给监控即败诉。禁止因对方控制推定画面存在或有利。禁止选边治愈。禁止吞并保存函、调查令、公证事项、保全申请终稿。不选定法院。不代实施。不代提交。不定残。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 保全闸关闭或节点 0 整案转出 | 第 1、2、10 节：关闭理由和最小补证。禁止完整 `Psv#` 步骤终稿。第三人／场所现场或己方可留时不得因工伤或工地整案转出 |
| 整体停止 | 第 1、10 节。禁止步骤、渠道、侵入或收买方法。双方秘密、同时交材料、侵入、收买、私下拷贝、偷拍隐私空间第一次即停，优先于负触发；无选边治愈，无「坚持」门槛 |
| 用户要「法定覆盖七天」或「今天必须拷完」或「截图即原件」或「拒不给即败诉」（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；闸未开则仍只交 1、2、10；不得改走负触发关窗；成果不得标步骤终稿 `已形成` |
| 正触发且闸开（可部分开） | 下列十节表头均出现；原件、排除、保全效果未核验的单元格填 `依据不足，无法形成结论` 或 `待核`；对方控制行只分流；禁止为填满而宣布已保全、必然采信或法定覆盖天数 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入步骤终稿已形成。双方秘密未解不得进入「部分形成」。每个 `Psv#` 必须带来源和状态。`L#` 不得直接抄技能内条号。七日法定覆盖、截图即原件、拒不给即败诉若返回则记噪声。步骤状态默认 `草案步骤`。

## 1. 触发、单方立场、授权与成果状态

保全闸开、部分开或关。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。步骤状态默认 `草案步骤`。

## 2. 来源登记与 MCP 调用表

载体、控制方、已有介质形态（原始载体／导出／截图）分列。口述覆盖天数、已经拷了只登记 `S#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 保全闸与现场合法范围

紧急只作红旗。禁止全国唯一覆盖天数。「今天必须拷完」不得开闸。未获许可不得写闯入步骤。工地人身现场可留，造价才转工程。

## 4. 己方载体 `Psv#`

行车记录仪、手机、聊天分行。原始文件、完整上下文。截图、转发包标弱形式红旗，不得升原件已固定。不改元数据。

## 5. 对方控制载体分流

只登记控制方、时段线索、覆盖红旗。不得推定存在或有利。不得指导拷盘。保存函、公证、调查令、法院保全只点转介名，不写终稿。

## 6. 完整性与弱形式

原始载体优先。保管链。哈希可选，不是唯一法定。已读、口头已拷不是已保全。

## 7. 禁止动作清单

侵入、收买、私下拷贝、偷拍隐私空间、窃听、改元数据、摆拍冒充原始现场。第一次提出即停。不提供方法。

## 8. 与鉴定、公证、调查令的关系

本窗步骤不代替鉴定。公证 ≠ 鉴定，可被反证。调查令常见前提是诉讼中签发。书证提出命令以诉讼中责令为前提，诉前不得写成已成立。不打开则填 `不打开`。

## 9. 风险与下一步

不代实施。转介保存通知、保全必要性、调查令、公证、建卷。不选定法院。不写那些终稿。不编唯一覆盖截止日。

## 10. 缺口、停止项与提示

须列对方最强解释：依法只循环七天、今天必须拷完、截图或已读即已保全、拒不给就是输、公共区域都能拍所以卫生间也可以、去机房拷一份、选边即可继续、保存步骤就是保全裁定。

本成果不是法院保全、不是搜查令、不是保存函、不是调查令、不是公证事项、不是建卷矩阵、不保证采信或妨碍推定。不代实施。
