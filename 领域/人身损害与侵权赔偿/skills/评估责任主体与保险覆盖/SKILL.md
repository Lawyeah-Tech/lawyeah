# 评估责任主体与保险覆盖

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“责任主体与保险覆盖表”：可能义务人、关系假设、连带／按份／补充、交强险与商业三者接口、未投保接口、追加条件和缺口。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事故认定、保单和主体材料。

## 工作边界

正触发：人身损害已发生，单方需要判断“该列谁、保险能否进、以什么责任形态进”，而不是只要总体策略或只要诉状。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要总体归责总图，不要主体表；
- 主成果是工伤用人单位待遇或工伤认定；
- 主成果是医疗损害鉴定或海事事故；
- 只要保险拒赔终稿或直接起诉保险人的完整诉状；
- 已决定只谈和解、只要谈判方案。

本任务不生成诉状、不保证保险人在限额内全额赔付，不把事故认定书写成民事终局。

## 建立主体坐标

确认：使用者与授权；单方立场；受害人；已知行为人、车辆或物件、用人单位或接受劳务方、场所、产品、投保义务人、交强险和商业三者保险人；保单期间与分项限额材料；法域；当前程序状态。

同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 保单或合同定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`PTY#` 主体；`INS#` 保险接口；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验用人者、场所补充、产品、交强险顺序、未投保、提供劳务；`search_practiced` 补追加路径。工具不可用时继续主体编目；责任形态和法律限额字段停止。

## 五个判断节点

执行顺序和停止条件以 [主体方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 专项分流和名单建立

先做工伤待遇、医疗鉴定、海事整案转出。列出全部名称变体，不合并相似名称。

### 2. 关系假设与责任形态

每个 `PTY#` 写关系假设、成立条件、连带／按份／补充／追偿。补充责任不得写成全部连带。

### 3. 保险覆盖

交强险先于商业三者，再由侵权人。本车人员、被保险人是否属于交强险受害人须核验条例。精神损害优先只标接口。

### 4. 未投保、盗抢、转让未登记

未投保、投保义务人与驾驶人分离、盗抢、多次转让未登记须运行时核验现行条文，不得凭记忆写条号。

### 5. 追加条件与缺口

写明缺少保单、行驶证、劳动关系或场所登记时不得选定唯一义务人。下一步只转介，不写诉状。

## 停止与安全

- `整体停止`：立场不明；主体名单无法建立；用户坚持虚构被告或伪造保单。
- `字段停止`：保险限额、责任形态规则未核验。
- `目标停止`：主目标变为诉状、拒赔终稿或工伤待遇。
