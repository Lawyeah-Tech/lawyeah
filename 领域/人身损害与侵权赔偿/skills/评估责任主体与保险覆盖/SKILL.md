# 评估责任主体与保险覆盖

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“责任主体与保险覆盖表”：名称变体、关系假设、形态**候选**（待核）、交强险／商业三者能否进入、未投保接口、应当共同被告红旗、追加条件和缺口。

`depends-on` 为空。数人侵权的连带／按份终稿转 `评估共同侵权与连带按份`。交强险分项限额分配、精神损害优先如何入账转 `评估道路交通事故责任与保险先行`。本任务回答「该列谁、保险能不能进」，不回答「先赔哪一笔、赔多少」。

## 工作边界

正触发：人身损害已发生，单方需要判断“该列谁、保险能否进、以什么关系假设进”，而不是只要总体策略或只要诉状。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要总体归责总图，不要主体表（转 `评估人身侵权责任`）；综合提问还夹带时效、法院、金额时仍转总图并强制降级；
- 只要交强险商业三者分账终稿（转 `评估道路交通事故责任与保险先行`）；
- 只要连带／按份展开终稿（转 `评估共同侵权与连带按份`）；
- 只要执行工作任务用人者展开（转 `评估用人者责任`）；
- 侵权人逃逸或暂时不明为主轴（转 `评估侵权人不明路径`）；
- 主成果是工伤用人单位待遇或工伤认定（转劳动）；
- 主成果是医疗损害鉴定或海事事故；
- 只要保险拒赔终稿或直接起诉保险人的完整诉状；
- 主体已闭合且只要诉状（转 `提起人身损害一审`）；
- 已决定只谈和解、只要谈判方案。

本任务不生成诉状、不保证保险人在限额内全额赔付、不选定唯一被告、不输出限额内必得额，不把事故认定书写成民事终局。

## 建立主体坐标

确认：使用者与授权；单方立场；受害人及法定代理人；已知行为人、车辆或物件、用人单位或接受劳务方、派遣单位与用工单位、场所、教育机构、产品、投保义务人、交强险和商业三者保险人；借用／租赁／挂靠／转让／盗抢线索；保单期间与分项限额材料；了结／弃权文本是否出现；法域；当前程序状态。

同时掌握双方秘密或未解利益冲突：`整体停止`，不得以选边治愈，也不得改走负触发去起草诉状。受害人已开口且委托范围就是主体表时，推定单方立场；仅当当事人无法建立或授权范围无法确定时，才因授权不明整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 保单、合同、了结或弃权文本；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`PTY#` 主体；`INS#` 保险接口；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。形态状态只用 `打开接口`、`不打开`、`待核`。技能正文中的条号是检索锚点，不是已核验 `L#`。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验用人者／派遣、场所补充执行顺序、1209–1215、未投保、交强险共同被告、本车人员除外、教育机构；不可用则责任形态和法律限额字段停止，名单编目继续。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，用其核验将改变主体或保险接口的条文正文，再写入 `L#`。未暴露不得编造 `regulation_id`。
- `search_practiced` 补追加路径、挂靠、开门杀、弃权。
- 不虚构保单号、公司或案件系统。

## 判断节点

执行顺序和停止条件以 [主体方法](references/method.md) 为准。这里只列入口。

### 1. 专项分流和名单扫描

先做工伤待遇、医疗鉴定、海事整案转出。按已出现事实扫描，不是闭集。名称变体不合并，不选定唯一义务人。

### 2. 关系假设与形态候选

每个 `PTY#` 写关系假设、成立条件、形态候选、支持不利、判断和待核。租赁借用禁止所有人当然连带。补充责任必须带执行顺序。数人形态终稿转共同侵权专项。

### 3. 保险能否进入

机动车事故一律打开交强险接口，不因认定书无责而关闭。保险人应当共同被告只标红旗。分项限额未核验则停止数字。开门杀不得以乘车人不是被保险人拒赔。

### 4. 未投保、盗抢、转让、挂靠、报废

分条核验。禁止把租赁分离套到盗抢。禁止未投保写成连带。

### 5. 追加、弃权与缺口

缺少行驶证、保单、用工登记时不得选定唯一被告。出现了结／权益转让必须红旗并转介。不写诉状。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；主体名单无法建立；用户坚持虚构被告或伪造保单。整体停止优先于负触发。
- `字段停止`：保险限额、责任形态规则、保险人诉讼地位未核验。
- `目标停止`：主目标变为诉状、拒赔终稿、交强险分账终稿或工伤待遇。

禁止指导虚构被告、伪造保单或违法取证。不给胜诉率。
