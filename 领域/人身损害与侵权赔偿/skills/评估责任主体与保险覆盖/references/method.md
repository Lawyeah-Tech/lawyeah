# 主体与保险方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出唯一必得承担额或胜诉率。

`search_law` 返回已失效《侵权责任法》或 2003 年解释已删除雇主无过错、安保旧条时记为噪声。

## 节点 0　专项分流

| 信号 | 转出 |
| --- | --- |
| 只要用人单位工伤认定或工伤待遇 | 劳动领域 |
| 诊疗过错或医疗损害鉴定主轴 | 医疗医药 |
| 船舶、海上人身伤亡 | 海事 |
| 只要总体策略不要主体表 | `评估人身侵权责任` |

工作中第三人侵权：用人单位工伤段分流，第三人、车辆、保险人可留本任务。

## 节点 1　名单建立

固定列：`PTY#｜名称变体｜角色假设｜关系事实｜支持｜不利｜控制方｜判断`。

默认扫描：行为人；机动车使用人、所有人、管理人；投保义务人；交强险保险人；商业三者保险人；用人者或接受劳务方；场所经营者、管理者、活动组织者；产品生产者、销售者；教育机构；建筑物所有人、管理人、使用人、物业；近亲属权利人。

名称、车牌、保单号、统一社会信用代码不一致：并列，不合并。口头“就是那家店”不得写成已确定经营者。

## 节点 2　责任形态

运行时核验后再落形态。核验失败则形态字段停止，名单继续。

| 关系假设 | 默认形态 | 禁止 |
| --- | --- | --- |
| 共同实施或教唆帮助 | 连带候选 | 把帮助写成当然全部责任而不核验 |
| 分别侵权且各自足以造成全部损害 | 连带候选 | 与部分原因按份混写 |
| 分别侵权且原因力可分 | 按份候选 | 写成连带 |
| 场所未尽安保且第三人致害 | 相应补充责任 | 写成与第三人全部连带；引用 2003 年解释第六条 |
| 用人者对工作人员致害 | 用人者责任，追偿另列 | 把工伤待遇写成用人者民事终局 |
| 提供劳务受害 | 按各自过错 | 把应参加工伤统筹的职工留在本形态终局 |
| 教育机构 + 第三人 | 教育机构相应补充 | 写成监护人免责 |

补充责任承担后向第三人追偿只标接口，本任务不写追偿诉状。

## 节点 3　交强险与商业三者

1. 机动车一方责任：先交强险限额，再商业三者约定，仍不足由侵权人（民法典第一千二百一十三条）。
2. 交强险受害人为本车人员、被保险人以外的人。乘客、驾驶人本人是否落入交强险须按座位和保单核验，依据不足则 `INS#` 停止。
3. 当事人同时起诉侵权人和保险公司时，按该条确定顺序。被侵权人请求交强险优先赔偿精神损害，道路交通事故损害赔偿解释支持，本任务只标接口，不分配具体元。
4. 分项限额（死亡伤残、医疗费用、财产损失）以现行条款和保单为准，咨询记忆中的数字不得写成已核验限额。
5. 商业三者免责、酒驾、无证、逃逸须回链条款原文，不得概括“商业险一定不赔”或“一定赔”。

## 节点 4　未投保、盗抢、转让

运行时核验道路交通事故损害赔偿解释与侵权责任编解释（一）：

- 未依法投保交强险：投保义务人在交强险责任限额范围内的赔偿请求可评估；投保义务人与侵权人不是同一人时，合并请求的形态须核验 2024 年解释第二十一条，不得写成无限连带。
- 多次转让未登记：最后一次转让并交付的受让人候选。
- 盗抢：盗窃人、抢劫人或抢夺人；与使用人分离时连带候选。保险人在交强险限额内垫付抢救费用后追偿只标接口。

无法核验则相应 `PTY#` 形态停止。

## 节点 5　追加与缺口

缺少行驶证、保单、用工登记、场所营业执照：主体判断标 `依据不足`，列出合法补证，不选定唯一被告。

本任务不写起诉状。用户路径写成起诉时，只输出可评估的被告清单和保险接口，转介起诉原子。禁止编造不存在的公司或保单。
