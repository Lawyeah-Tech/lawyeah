# 评估责任主体与保险覆盖方法

本文件是可执行判断节点。租赁借用不是所有人当然连带。未投保不是连带。无责不是关闭交强险。认定书不是民事终局比例。登记车主不是当然责任。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、唯一被告、限额内必得、选定法院、代提交、未知写零。本任务不定罪，不定残，不写诉状或分账终稿。本窗闸名只能是名单闸，禁止复用侵权闸、评估闸、争议闸、主体闸、保险闸、鉴定闸、发送闸、起诉闸。预留不得占用：立案闸、鉴定闸、发送闸、起诉闸。本窗 `TB#` 是主体保险行。主路径只用 `Q-体`，禁止用 `Q-责`、`Q-险`、`Q-总`、`Q-诉` 作主路径。英文 id 禁止使用，一律用中文技能名 `评估责任主体与保险覆盖`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条、2012 年道交解释第十九条限额内连带、交强险旧限额 11 万／1 万、1991 年道路交通事故处理办法第三十一条垫付、把民法典第七百四十九条一般租赁免责套进第一千二百零九条时记为噪声。禁止指导虚构被告、伪造保单或顶包。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现名称或保单碎片扫描，不是默认闭集。
`TB#` 固定列：`编号｜名称变体｜角色假设｜关系事实｜形态候选｜保险能否进入｜打开接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「该告谁」一笔。无 `E#` 不得写已锁定义务人、应当共同被告已闭合或应起诉。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-体`。禁止 `PTY#`、`INS#`、`QG#`、`ZT#`、`A#`、`N#`。

口头「就是那家店」「车主当然赔」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：机动车事故一律打开交强险接口，不因认定书无责关闭。1213 只开顺序。解释（一）第二十一条共同承担不得默写连带。1209 使用人承担该机动车一方，所有人仅过错范围内相应责任。应当共同被告只标红旗。

## 节点 0　分流、立场、名单闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、虚构被告、伪造保单、倒签、顶包、违法取证不进负表。利益冲突未解不进整体停止。不写诉状、不选定唯一被告不是负触发。

整案转出只交付第 1、2、10 节，不出 `TB#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是侵权总图 | 负触发 `评估人身侵权责任` |
| 主成果是交强险或商业三者分账终稿 | 负触发 `评估道路交通事故责任与保险先行` |
| 主成果是连带或按份展开终稿 | 负触发 `评估共同侵权与连带按份` |
| 主成果是用人者展开 | 负触发 `评估用人者责任` |
| 主成果是提供劳务受害终稿 | 负触发 `评估提供劳务受害` |
| 主成果是场所安保终稿 | 负触发 `评估场所安全保障义务` |
| 侵权人逃逸或暂时不明为主轴 | 负触发 `评估侵权人不明路径` |
| 主成果是工伤认定或待遇 | 整案转劳动 |
| 主成果是医疗损害鉴定 | 整案转医疗医药 |
| 海上运输或船舶事故 | 整案转海事 |
| 主成果是保险拒赔终稿 | 负触发 `应对保险拒赔减赔` |
| 主体已闭合且只要起诉包 | 负触发 `提起人身损害一审` 或 `直接起诉保险公司` |
| 主成果是追加申请书 | 负触发 `追加变更责任主体` |
| 「不写诉状」「不选定唯一被告」「不定残」 | 交付禁令，不是负触发 |

混合信号：工作中第三人侵权，工伤段分流，第三人／车／保险人可留本窗。出现「保险」「被告」「交强险」一词不是转出。

名单闸打开（可出 `TB#` 草案，仍不得标「唯一被告／限额内必得／应起诉」）须同时满足：单方无冲突立场已闭合；主成果是主体保险表，不是总图、不是分账、不是诉状；至少一项可编号名称、车牌、保单、用工或场所碎片。口头「就是那家店」不算单独开闸材料。

名单闸部分打开：已有碎片，但关系形态、交强险能否进入、未投保共同承担未闭合；对应格待核；仍交十节。无书面评估授权但单方立场已闭合且已有碎片：名单闸部分打开，仍交十节，不是整体停止。

名单闸关闭（仍正触发）：无一可编号碎片。「今天必须出唯一被告／限额内必得终稿」而无最小碎片不得开闸。不出 `TB#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `TB#` 终稿，**第 7 节不得出诉状或分账**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「唯一被告」「限额内必得」「无责关交强险」「未投保即连带」「所有人当然连带」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `TB#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 名单闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出虚构被告、伪造保单、倒签出险、顶包或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 3　主体保险行 `TB#`

按已出现名称或关系切片扫描，不是默认闭集。每条须能指向名称变体、关系或保险接口之一。

无 `E#` 不得写已锁定义务人或应起诉。状态 `草案`。一次只推荐下一步。未知金额不写零，不输出限额内必得额。

热冲突强制处理：

- 唯一被告／限额内必得／无责关交强险／未投保即连带／所有人当然连带／未知写零 → 该格不支持或字段停止；仍出其他 `TB#`。
- 无一碎片 → 关闸，不出 `TB#` 终稿，窗口不关。
- 指导虚构被告、伪造保单、顶包 → 整体停止，不是该格不支持。

## 节点 4　分账、连带、用人者与起诉接口

第 7 节只开接口，不得夹带 `TB#` 终稿、诉状或分账绕闸。闸关闭时第 7 节可写「闸未开，转介待名称编号」，不得补写唯一被告或应起诉。不选定法院。不代提交。

下一步只转介：`评估人身侵权责任`、`评估道路交通事故责任与保险先行`、`评估共同侵权与连带按份`、`评估用人者责任`、`评估提供劳务受害`、`评估场所安全保障义务`、`评估教育机构责任`、`评估产品致人损害`、`评估侵权人不明路径`、`申请道路救助基金或垫付`、`直接起诉保险公司`、`提起人身损害一审`、`追加变更责任主体`、`评估工伤与第三人侵权竞合`、`审查保险一次性了结弃权`、`准备侵权索赔通知`。禁止此致某院。

若 if 用户催促「车主当然赔／未投保就是连带／无责就别找交强险／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：借用他人小客车撞人，认定书使用人无责、车主有行驶证。用户主张车主当然连带、无责就别找交强险、未投保就是连带、限额内先写十八万必得、去某区法院告、不清楚先写零。名单闸打开或半开。`Q-主`、`Q-无`、`Q-连写`、`Q-必`、`Q-院`、`Q-零` 不打开为可靠路径。第 6 节不得把当然连带、关交强险、必得、0 写入可执行 `TB#`；对应格 `现有依据不支持` 或字段停止；仍出名称变体、1209 使用人全部／所有人过错范围、1213 顺序接口、解释（一）第二十一条共同承担红旗等其他 `TB#`。不关窗。不写诉状。不选定法院。

场景②：用户同时交出己方「必须告车主和保险公司」与对方「从未出借」口径，并指导「补一份倒签的借用合同、保单期间改到事故前」。命中双方秘密＋伪造保单＋倒签。第一次整体停止。只交第 1、10 节。不出 `TB#`。不得问代表哪一方后继续。不以「坚持」为门槛。
