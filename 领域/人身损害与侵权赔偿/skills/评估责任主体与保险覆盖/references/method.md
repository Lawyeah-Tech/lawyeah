# 主体与保险方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。形态状态只用 `打开接口`、`不打开`、`待核`。不得输出唯一被告、唯一必得承担额、胜诉率或诉状。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》或 2003 年解释已删除雇主无过错、安保旧条时记为噪声。MCP 效力字段与施行日冲突时，以施行日为准；无法核验则该形态字段停止。

## PTY# 矩阵

固定列：`PTY#｜名称变体｜角色假设｜关系事实｜形态候选｜支持｜不利｜控制方｜状态｜转介｜待核`。

名称、车牌、保单号、统一社会信用代码不一致：并列，不合并。口头“就是那家店”不得写成已确定经营者。

## 节点 0　专项分流

**整案转出**（只交付第 1、2、10 节）：

| 信号 | 转出 |
| --- | --- |
| 主成果是用人单位工伤认定或工伤待遇 | 劳动领域 |
| 诊疗过错或医疗损害鉴定主轴 | 医疗医药 |
| 船舶、海上人身伤亡 | 海事 |
| 只要总体策略不要主体表，或综合提问夹带时效／法院／金额 | `评估人身侵权责任` |
| 只要交强险分账终稿 | `评估道路交通事故责任与保险先行` |
| 侵权人逃逸或暂时不明为主轴 | `评估侵权人不明路径` |

工作中第三人侵权：用人单位工伤段分流并转介 `评估工伤与第三人侵权竞合`；第三人、车辆、保险人可留本任务。两套程序并行，医疗费禁止双领。同事执行任务致害：并列用人者／第三人待核，不锁定。

受害人是无／限制民事行为能力人：法定代理人必须单列，转介 `评估未成年或无行为能力受害人代理`。

人身损害事实本身构成疑似故意犯罪：刑民交叉至少 `待核`，转介 `分流刑民交叉`。

出现了结、权益转让或概括弃权：主体表可部分形成，必须红旗「请求可能已受弃权约束」，转介 `审查保险一次性了结弃权`。禁止写“先签保险再告侵权人”为无风险路径。

## 节点 1　名单扫描

按**已出现事实**扫描，不是闭集，也不是无事实铺开全部角色。

默认候选（命中才打开）：

- 行为人、监护人（未成年人致害）；
- 机动车使用人、所有人、管理人、挂靠人与被挂靠人、投保义务人；
- 交强险保险人、商业三者保险人；
- 用人者、工作人员（工作人员不当然对外连带）、劳务派遣单位与用工单位、接受劳务方、承揽人与定作人；
- 场所经营者、管理者、活动组织者；
- 教育机构；
- 产品生产者、销售者；
- 高度危险作业人、占有人、经营人；
- 施工人、发包分包；
- 动物饲养人、管理人；
- 建筑物所有人、管理人、使用人、物业；可能加害的建筑物使用人（补偿，禁止全体业主连带）；
- 近亲属权利人、受害人法定代理人；
- 道路救助基金管理机构（已发生抢救费且逃逸／未投保／超限额时打开，未就医无抢救费不得作为默认下一步）。

## 节点 3　保险能否进入

本节点判断接口和诉讼地位，不做分账终稿。展开转介 `评估道路交通事故责任与保险先行`。

1. 机动车事故（含道路以外通行比照条例第四十三条、解释（二）第五条）一律打开交强险接口，不因认定书无责、次责或「不是道路上」而关闭。
2. 承保交强险的保险公司：道路交通事故损害赔偿中**应当列为共同被告**（已在责任限额范围内实际赔付且当事人无异议除外）。本任务只标红旗，不写起诉状。商业三者仅在当事人请求时加入。
3. 赔偿顺序须核验第一千二百一十三条，只作接口。分项限额（死亡伤残／医疗费用／财产损失；有责／无责）必须运行时核验。未核验则数字和「限额内必得」停止。禁止把医疗费写入死亡伤残限额，禁止用已废止的 11 万／1 万旧限额。多车多份分列，不得简单相加冒充必得，也不得因次责丢掉该车交强险。
4. 精神损害请求交强险优先：须被侵权人或近亲属提出，只标接口，转交通专项分配。
5. 交强险受害人为本车人员、被保险人以外的人。乘客、驾驶人本人是否落入须按座位、时空位置和保单核验，依据不足则 `INS#` 停止。
6. 开门杀：乘车人责任属于该机动车一方；保险人不得以乘车人不是被保险人或其允许的驾驶人为由拒赔交强险／商业三者。检索锚点：解释（二）第二条。本车人员受害与开门杀致第三人分两行。
7. 驾驶人离开本车后因自身过错被本车碰撞碾压：请求本车交强险、商业三者，现有依据支持不打开，须核验解释（一）第二十二条。
8. 商业三者免责、酒驾、无证、逃逸须回链条款原文，不得概括“一定不赔”或“一定赔”。驾驶证过期未注销，保险人不得仅以此拒赔（解释（二）第四条），只标接口。
9. 医保基金、工伤保险基金已付医疗费和救助基金垫付的抢救费、丧葬费，不得再向侵权人重复主张该部分。检索锚点：解释（二）第十条。
10. 已发生抢救费用且逃逸、未投保或超医疗限额：转介 `申请道路救助基金或垫付`。未就医、无抢救费不得把基金申请写成默认下一步。

## 节点 4　未投保、盗抢保险接口

- 未依法投保交强险：投保义务人在交强险责任限额范围内的赔偿请求可评估。投保义务人与事故责任人不是同一人：责任人承担全部；投保义务人在限额内**共同承担责任**，禁止写成连带（含「限额内连带」「无限连带」）。检索锚点：解释（一）第二十一条。同一人时另核道交解释第十六条第一款。禁止默写条号为 `L#`。
- 盗抢：保险人在交强险限额内垫付抢救费用后追偿只标接口；有保单时保险人诉讼地位仍待核，不得因盗抢直接从被告表删除交强险公司。财产损失是否赔付须核验条例，不得概括。原所有人／管理人不因被盗抢当然担责。
- 逃逸且机动车不明或未投保：救助基金垫付接口，转介专项。

无法核验则相应 `PTY#`／`INS#` 形态停止。

## 节点 5　追加与缺口

缺少行驶证、保单、用工登记、场所营业执照、借用关系证据：主体判断标 `依据不足`，列出合法补证，不选定唯一被告。

本任务不写起诉状。用户路径写成起诉时，只输出可评估的被告清单接口和保险红旗，转介起诉原子。禁止编造不存在的公司或保单。用户要求唯一被告名单或限额内必得额：该两字段停止。
