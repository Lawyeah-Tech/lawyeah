# 边界与路由

## 正触发

人身损害已发生，单方需要判断该列谁、保险能否进。从零、碎片、关系或保单未核验仍正触发：有可编号名称、车牌、保单、用工或场所碎片则闸开或半开，出 `TB#` 草案，保持草案。本次不写诉状、不选定唯一被告是交付禁令，不是开窗条件。唯一被告、未投保即连带、无责关交强险，仍正触发。把所有人写成当然连带、把限额内写成必得，仍正触发：该格不支持，不改负触发关窗。

双方秘密、虚构被告、伪造保单的停止，优先于负触发。上述信号不在下表。不写诉状不是负触发。「唯一被告」「限额内必得」「无责关交强险」「未投保即连带」「所有人当然连带」「未知写零」不在下表。

| 主要目标 | 路由 |
| --- | --- |
| 侵权总图 | `评估人身侵权责任` |

| 场所安保终稿 | `评估场所安全保障义务` |
| 逃逸或暂时不明为主轴 | `评估侵权人不明路径` |
| 工伤认定或待遇 | 劳动领域 |
| 医疗损害鉴定 | 医疗医药领域 |

## 易混

本窗闸名只能是名单闸，不是侵权闸，不是评估闸，不是主体闸，不是保险闸，不是起诉闸。`TB#` 不是 `QG#`，不是 `PTY#`，不是 `INS#`，不是 `ZT#`。主路径是 `Q-体`，不是 `Q-责`，不是 `Q-险`，不是 `Q-总`，不是 `Q-诉`。`侵权闸`／`QG#`／`Q-责` 是 `评估人身侵权责任`。`Q-险` 是交强险分账专项。租赁借用不是所有人当然连带。未投保不是连带。无责不是关闭交强险。已失效《侵权责任法》不是现行。2012 年道交解释第十九条限额内连带不是现行解释（一）第二十一条。民法典第七百四十九条不是机动车第一千二百零九条。提出「补一份倒签借用合同、保单期间改到事故前」整体停止。本窗不代提交。不选定法院。不定残。不写诉状。不保证限额内全额。
