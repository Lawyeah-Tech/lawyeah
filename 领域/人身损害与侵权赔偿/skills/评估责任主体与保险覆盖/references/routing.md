# 边界与路由

## 正触发

人身损害已发生，需要单独判断可能义务人、责任形态和保险覆盖。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 总体责任总图 | `评估人身侵权责任` |
| 工伤认定或待遇 | 劳动领域 |
| 医疗损害鉴定 | 医疗医药领域 |
| 海事 | 海事领域 |
| 保险拒赔终稿 | `应对保险拒赔减赔`（未安装则 `unavailable`） |
| 直接起诉保险人完整诉状 | `直接起诉保险公司`（未安装则 `unavailable`） |
| 一审起诉包 | `提起人身损害一审` |
| 精算 | `测算人身损害赔偿` |

## 易混

“列谁当被告、保单能不能进”正触发。“这件事有没有责任、下一步怎么办”走总体评估。已决定起诉且主体已闭合，只要诉状，负触发。
