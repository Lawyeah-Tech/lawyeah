# 边界与路由

## 正触发

人身损害已发生，需要单独判断可能义务人、关系假设和保险能否进入。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 总体责任总图，或综合提问夹带时效／法院／金额 | `评估人身侵权责任` |
| 只要交强险商业三者分账终稿 | `评估道路交通事故责任与保险先行` |
| 只要连带按份展开终稿 | `评估共同侵权与连带按份` |
| 只要执行工作任务用人者展开 | `评估用人者责任` |
| 侵权人逃逸或暂时不明为主轴 | `评估侵权人不明路径` |
| 工伤认定或待遇 | 劳动领域 |
| 医疗损害鉴定 | 医疗医药领域 |
| 海事 | 海事领域 |
| 保险拒赔终稿 | `应对保险拒赔减赔`（未安装则 `unavailable`） |
| 直接起诉保险人完整诉状 | `直接起诉保险公司`（未安装则 `unavailable`） |
| 主体已闭合且只要一审起诉包 | `提起人身损害一审` |
| 精算 | `测算人身损害赔偿` |
| 保险一次性了结、权益转让、概括弃权为主成果 | `审查保险一次性了结弃权` |

综合「告谁＋怎么办＋赔多少」转总图。受害人开口且委托范围是主体表时，不因口语化咨询整体停止。双方秘密或授权不明的整体停止，优先于「今天出起诉状」的负触发。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 机动车事故、借用租赁、开门杀、未投保、道路以外 | `评估道路交通事故责任与保险先行` |
| 数人、两车、教唆帮助 | `评估共同侵权与连带按份` |
| 执行工作任务、劳务派遣 | `评估用人者责任` |
| 个人劳务 | `评估提供劳务受害` |
| 教育机构 | `评估教育机构责任` |
| 场所安保 | `评估场所安全保障义务` |
| 产品 | `评估产品致人损害` |
| 高度危险 | `评估高度危险作业致害` |
| 动物／物件／施工 | 对应专项 |
| 高空抛物不明或逃逸 | `评估侵权人不明路径`；已发生抢救费另转 `申请道路救助基金或垫付` |
| 工伤第三人 | `评估工伤与第三人侵权竞合` |
| 无／限制行为能力受害人 | `评估未成年或无行为能力受害人代理` |
| 保险人诉讼地位要变成诉状 | `直接起诉保险公司` / `提起人身损害一审` |
| 需要追加被告 | `追加变更责任主体` |
| 了结弃权文本 | `审查保险一次性了结弃权` |

## 易混

“列谁当被告、保单能不能进”正触发。“这件事有没有责任、下一步怎么办”走总体评估。“交强险先赔哪一笔、限额怎么分”走交通专项。已决定起诉且主体已闭合，只要诉状，负触发。
