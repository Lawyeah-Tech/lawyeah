# 边界与路由

## 正触发

被上诉人已收到上诉状或二审应诉材料，需要二审答辩、对方请求拆解或新证据意见。「对方上诉了，我要答辩」正触发。已读起算十五日、保证维持或驳回上诉、选定某中院、期限过了仍要可提交答辩、本方也不服但只要答辩、未上诉部分二审全改、超出一审请求当然允许对方、附带上诉当然成立，仍正触发：应对闸可关，对应格停止，窗口不关。工伤待遇与对第三人民事裁判同时出现，仍正触发：工伤段分流劳动，对第三人 `Ans#` 可留。本方仍在己方上诉期内不服，即使对方已上诉，本窗答辩正触发；上诉并行转介，答辩不替代上诉，**不得关答辩窗**。

双方秘密、伪造新证据、倒签送达的停止，优先于负触发。不得改走负触发去出一方答辩。本方也不服、已读起算、保证维持、过期仍要答辩、调解书普通答辩不在下表。伪造倒签不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要上诉状终稿且不要答辩 | `提起人身损害上诉` |
| 一审答辩状或首次应诉答辩包 | `应对人身损害一审` |
| 已排期二审质证询问提纲 | `准备人身损害庭审` |
| 反诉状终稿 | `评估反诉或抵销` |
| 后续治疗另诉 | `准备后续治疗费另诉`／`评估后续治疗费另行主张` |
| 主成果已是再审或检察监督文书 | P2 `unavailable`（用户仍要普通二审答辩则闸关不关窗） |
| 纯工伤待遇二审且无第三人 | 劳动领域 |
| 医疗损害二审主轴 | 医疗医药领域 |
| 海事二审 | 海事领域 |
| 刑事二审 | 刑事领域 |
| C 端只要大众答辩包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「本方也不服所以先关答辩窗」「补造二审新鉴定」「把已读改成送达回证日期」「两边材料都给你选边」不在本表。前一项窗口不关、并行转介上诉窗；后三项走整体停止。

## 易混

「对方上诉了，我要答辩」正触发。「我也不服判决」：若只要上诉状且不要答辩，走上诉窗；若既要答辩又不服，本窗正触发，上诉并行转介，**不得关答辩窗**。「一审刚被诉」走一审应诉。「判决生效很久了」：闸关，再审 P2 unavailable，窗口不关，不沉默。「微信已读上诉状 PDF，从已读算十五日，保证维持，此致某中院，过几天逾期仍要按普通答辩交」仍正触发；已读不得起算；保证维持、选定中院各格不支持；过期只停提交稿。「调解书签了对方还上诉」闸关，一般不得上诉，窗口不关。「工伤还在认，要对司机和交强险的二审答辩」正触发，第三人 `Ans#` 可留。「两边材料都给你选边、补一份二审新鉴定」整体停止。
