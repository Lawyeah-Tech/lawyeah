# 边界与路由

## 正触发

收到上诉状，需要二审答辩。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 主动上诉 | `提起人身损害上诉` |
| 一审应诉 | `应对人身损害一审` |
| 再审 | `unavailable`（P2） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 刑事二审 | 刑事领域 |
| 劳动二审或诉讼 | 劳动领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“对方上诉了，我要答辩”正触发。“我也不服判决”走上诉。“一审刚被诉”走一审应诉。
