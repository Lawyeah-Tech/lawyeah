# 二审应对方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。稿件状态只用 `草案`、`应对闸关闭`、`提交前待核`、`停止`。禁止胜诉率、必然责任比例、唯一必得总额、唯一截止日、选定法院、自行宣布伤残等级、保证维持、保证驳回上诉、代提交。未知金额不写零。本任务不代提交。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、已失效《合同法》、2017 年民事诉讼法旧答辩／二审条号（约第一百六十七条、第一百六十八条一类）、把已读或截图写成答辩期起算、把保证维持或选定某中院写成可执行、把附带上诉写成当然成立、把不提交答辩状写成缺席、把刑事全面审查写入民事二审时记为噪声，不得写入 `L#`。禁止指导伪造新证据、倒签送达或作伪证。

`K#` 固定列：`编号｜文书名称｜文书类型（上诉状副本／二审应诉通知／举证通知／一审判决／可上诉裁定／调解书／其他）｜受送达人（驾驶人／所有人／保险人分列）｜作出日｜送达日｜送达方式｜效力凭证｜电子送达是否同意及到达｜期间类型（二审答辩／举证／己方判决上诉红旗／己方裁定上诉红旗）｜起算事件｜期间长度待核｜待核截止｜不提交答辩是否影响审理（不影响审理，≠缺席）｜状态｜来源回链`。一受送达人一卡。禁止共用。口头截止日只进 `S#`。已读、截图、作出日、落款日不得填送达日。答辩期与己方上诉期红旗分列，禁止混成唯一日历截止日。己方上诉期行只红旗并转介 `提起人身损害上诉`，不在本窗打开可交上诉状。

`Ap#` 固定列：`编号｜对方不服一审主文项｜对方上诉请求（撤销／改判／发回／其他）｜一审对应认定或判项｜是否超出一审请求（否／待核／现有依据不支持）｜金额状态（已核实／情景／无法估计，禁止写零）｜对方理由块（事实认定／法律适用／程序违法）｜对方新证据及逾期主张｜未上诉判项效力风险｜例外是否打开（禁止性规定／国家／社会／他人合法权益，默认待核，禁止写成当然全改）｜拟答入口（承认／否认／不知／法律反驳）｜状态｜来源回链`。一行一项对方主文。禁止一行打包「驳回全部上诉」或「二审全改」。本方独立上诉请求不得写入本窗可交 `Ap#`。

`Ans#` 固定列：`编号｜对应 Ap#｜应答（承认／否认／不知／法律反驳）｜事实回链｜不利一审认定是否入列（必须入）｜是否构成独立上诉请求（默认否；是则该格停止并转介上诉窗，本窗不关）｜是否超出一审独立新请求（是则不打开可交）｜是否二审反诉候选（只红旗，不写终稿）｜本方新证据及逾期理由｜鉴定人拒不出庭红旗｜判断三值｜状态（草案／应对闸关闭／停止）｜来源回链`。驾驶人自认不得写入保险人承认栏。

口头「对方上诉了」、微信已读、PDF 下载只进 `S#`／`V#`，不得升格 `R#` 已送达或期限已起算。

## 节点 0　分流、立场、应对闸与不关窗

整案转出或闸关闭只交付第 1、2、10 节或标注停止的 `K#`／`Ap#`／`Ans#`，不得交付答辩终稿，不得标保证维持或驳回上诉。闸部分打开时：仅对送达可回链且文书可答辩的部分给出草案，其余行停止或不打开。

| 信号 | 处理 |
| --- | --- |
| 只要上诉状终稿且不要答辩 | 负触发 `提起人身损害上诉` |
| 既要答辩又不服一审 | **本窗正触发**出 `Ans#`；上诉并行转介 `提起人身损害上诉`；**不得关窗、不得互踢** |
| 主成果是一审答辩 | 负触发 `应对人身损害一审` |
| 已排期二审只要质证询问 | 负触发 `准备人身损害庭审` |
| 主成果是反诉状终稿 | 负触发 `评估反诉或抵销`；二审反诉本窗只红旗 |
| 主成果是后续治疗另诉 | 负触发 `准备后续治疗费另诉`／`评估后续治疗费另行主张` |
| 主成果已是再审或检察监督文书 | P2 `unavailable`；用户仍要普通二审答辩则闸关不关窗 |
| 纯工伤待遇二审且无第三人 | 整案转劳动；夹带对第三人民事裁判则本窗正触发，工伤段分流，`Ans#` 可留并转介 `评估工伤与第三人侵权竞合` |
| 医疗损害二审主轴 | 转医疗 |
| 海事二审 | 转海事 |
| 刑事二审 | 转刑事 |
| 未成争只要改合同 | 审查起草本窗搁置 |

应对闸打开（可出 `Ans#` 草案，仍不代提交、不保证维持／驳回）须同时满足：单方无冲突被上诉方立场与授权；主成果是二审答辩／补充证据意见，不是上诉状终稿、一审答辩、庭审提纲、反诉状、后续治疗另诉；对方上诉状或等价 `R#` 可回链，或明确登记缺口并停止截止日；拟交付不含保证维持／驳回、选定中院、已读起算、伪造新证据、倒签送达、未知写零。

闸关闭（仍正触发）：送达不明或仅口头「对方上诉了」；已读／截图当答辩起算；写死唯一截止日；保证驳回上诉／维持原判；选定某中院；新证据当然能用或当然失权；未上诉部分要求二审全改；答辩写入独立上诉请求或附带上诉当然成立；二审保证准许反诉；过期仍要可提交答辩终稿；调解书签收后对方仍要普通二审答辩终稿；未知写零。闸未开则仍只交 1、2、10 节。过期：十节表头可出现，提交稿停止。

「本方也不服」「已读起算」「保证维持」「选定中院」「过期仍要答辩稿」「调解书普通答辩」**不关窗**。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或原被告、保险人与驾驶人同时交材料争同一份二审答辩策略且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出伪造二审新证据、倒签送达回证、把已读改成送达日、指导作伪证、隐匿一审不利自认，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　期限卡 `K#`

检索锚点：原审人民法院收到上诉状，应当在五日内将上诉状副本送达对方当事人；对方当事人在收到之日起十五日内提出答辩状；不提出答辩状的，不影响人民法院审理。2023 修正后常见第一百七十四条一类，条号运行时核验，不是 `L#`。2017 年约第一百六十七条不得默写为现行 `L#`。领域内无住所当事人期间可能为三十日，待核。

作出日 ≠ 送达日 ≠ 已读／截图／发送成功／落款日。电子送达须当事人同意，并以到达特定系统之日为送达日，未核验则截止日停止。一受送达人一卡。驾驶人、所有人、保险人分送不得共用截止日。

不提出答辩状不影响审理，**不等于**已经缺席或已承认；缺席风险与二审审理另核，**不保证免于不利结果**。过期：提交稿停止，窗口不关，仍可出草案并标逾期风险，不得标按时提交保证。

己方上诉期红旗：判决十五日、裁定十日，从对该当事人的送达起算，与答辩期分列。仍在期内且不服：只转介，不在本窗打开可交上诉状。

## 节点 2　对方上诉请求 `Ap#`

检索锚点：第二审人民法院应当围绕上诉请求进行审理；未提出的请求原则上不予审理，但一审判决违反法律禁止性规定或损害国家利益、社会公共利益、他人合法权益的除外。民诉解释二审范围条款（检索中或作第三百二十一条一类）运行时核验，条号不是 `L#`。禁止把刑事「全面审查不受上诉范围限制」写入民事 `L#`。

一行对照对方一项主文。未上诉判项可能生效，风险必须明示。例外一律待核，禁止写成二审当然全改。超出一审已主张的独立新请求（含一审未主张的后续治疗、精神损害）：该格 `现有依据不支持` 或待核，不得写入可交答辩反请求；转介 `评估后续治疗费另行主张`／`准备后续治疗费另诉`。未知金额不写零。不定残。

调解书经双方当事人签收后即具有法律效力，一般不得上诉。对方把调解书当判决上诉：该行答辩闸关，窗口不关。人民调解、保险调解、交警调解不是本窗二审对象。

## 节点 3　答辩行 `Ans#` 与新证据

承认、否认、不知、法律反驳分列。不利一审认定必须入列，不得假装不存在。禁止把可让步金额或驾驶人责任比例写成诉讼自认。驾驶人自认不得写入保险人承认栏；用户坚持按驾驶人全责写保险人答辩：该承认字段停止；冲突未解整体停止。事故认定书不是民事终局。

独立上诉请求写入答辩：该格停止并转介 `提起人身损害上诉`，本窗不关。禁止主张附带上诉当然成立。

新证据须说明逾期理由；是否采纳待核。既非当然能用，也非一律失权。不得指导补造「一审客观不能」叙事。对方新证据做质证预案。鉴定人拒不出庭则该鉴定意见不得作为认定根据：本窗只红旗，终稿转 `准备人身损害庭审`。

二审反诉：可以根据当事人自愿原则调解；调解不成告知另行起诉；双方同意由二审一并审理的除外。本窗不写反诉状终稿，不保证准许，转 `评估反诉或抵销`。

## 节点 4　答辩状草稿与转介

草稿栏目：当事人、原审法院与案号、针对的上诉请求、答辩意见、证据。状态默认 `草案`。不代提交。禁止预填「此致某某市中级人民法院」为唯一路径。上一级由审级法定。用户点名某院只登记 `S#`。闸未开不得标答辩终稿 `已形成`。

| 接口 | 本窗 | 转介 |
| --- | --- | --- |
| 本方独立上诉 | 只红旗，不写上诉状 | `提起人身损害上诉` |
| 一审答辩 | 负触发 | `应对人身损害一审` |
| 已排期质证询问 | 负触发 | `准备人身损害庭审` |

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过应对闸直接给保证维持、已读起算、选定中院或过期可提交终稿。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if 金额参数不足，then 该行标未知，禁止写零。
若 if C 端只要大众准备包，then 只分流不回改。

判断状态只许三值。口头转述、截图和「已读」不得写成已受理、已送达或期限已起算。事故认定书不得单独写成民事终局比例。驾驶人自认不得写成保险人自认。

## 本任务回链纪律

本任务成果是「不代提交的二审答辩草稿、期限卡与对方请求拆解」。必须包含：应对闸、答辩不替代上诉且不关窗、已读不得起算、过期只停提交稿。不包含：上诉状终稿、一审答辩、庭审提纲、反诉状、后续治疗另诉。禁止保证维持或驳回。禁止选定中院。禁止选边治愈。禁止伪造新证据。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标答辩终稿已形成。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接。
风险档 A：答辩期、未上诉部分生效、伪造送达必须单独标可逆性。
