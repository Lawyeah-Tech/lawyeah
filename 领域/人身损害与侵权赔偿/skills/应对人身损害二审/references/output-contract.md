# 输出合同

按触发结果选择交付形状。应对闸未打开不得交付答辩终稿或保证维持。禁止选定唯一二审法院或预填「此致某中院」。禁止已读、截图、作出日、落款日当答辩起算。禁止把答辩写成独立上诉请求或附带上诉当然成立。禁止未上诉部分二审全改。禁止逾期证据当然能用或当然失权。禁止过期仍出可提交答辩终稿。禁止胜诉率。禁止代提交。禁止未知金额写零。禁止选边治愈。不定残。不保证维持或驳回上诉。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 应对闸关闭或节点 0 整案转出 | 第 1、2、10 节：关闭理由、送达待核和最小补证。可附停止的 `K#`／`Ap#`／`Ans#`。禁止答辩终稿、保证维持、唯一截止日、选定中院。对第三人可留时不得因工伤整案转出。既要答辩又不服时不得因「应先上诉」整案转出 |
| 整体停止 | 第 1、10 节。禁止 `Ans#` 策略包、选边、伪造或倒签方法。双方秘密、伪造新证据、倒签送达第一次即停，优先于负触发；无选边治愈，无「坚持」门槛 |
| 用户要已读起算、保证维持、选定某中院、过期仍要答辩终稿、本方也不服应先关窗、附带上诉当然成立（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；闸未开则仍只交 1、2、10；过期则草稿节停止；不得改走负触发关窗；不得标答辩终稿 `已形成` |
| 正触发且闸开（可部分开） | 下列十节表头均出现；期限、范围、新证据未核验格待核；一行一项；禁止为填满而写保证维持、此致某中院、已读起算或过期可提交终稿 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入答辩终稿已形成。双方秘密未解不得进入「部分形成」。每个 `K#`／`Ap#`／`Ans#` 必须带来源和三值判断。`L#` 不得直接抄技能内条号。已读起算、保证维持、附带上诉当然成立若返回则记噪声。稿件状态默认 `草案`。

## 1. 触发、单方立场、授权与成果状态

应对闸开、部分开或关。文书类型与送达必须标明。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。稿件默认 `草案`。不代提交。不保证维持或驳回。本方不服只转介，不关窗。

## 2. 来源登记与 MCP 调用表

`S/R/D/E/L/I/G/K/Ap/Ans/V`。口头刚到、已读只登记 `S#`／`V#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 期限卡 `K#`

自收到上诉状副本起算，期间长度待核，常见十五日。已读不得起算。一受送达人一卡。不写死唯一日历截止日。不提交不影响审理 ≠ 缺席。己方上诉期只红旗。过期提交稿停止。

## 4. 对方上诉请求 `Ap#`

一行一项主文。未上诉部分可能生效。超出一审请求待核。例外待核，禁止二审当然全改。调解书行不得打开可提交。

## 5. 答辩行 `Ans#`

承认、否认、不知、法律反驳分列。不利认定必须入列。独立上诉请求该格停止。驾驶人自认不得写成保险人自认。

## 6. 新证据意见

对方质证与本方逾期理由分列。失权非绝对，亦非当然能用。鉴定人拒不出庭只红旗。

## 7. 答辩状草稿

当事人、案号、针对的上诉请求、意见。不预填此致某中院。草案，不代提交。过期则本节停止。不得改写成上诉状。

## 8. 二审反诉与邻接分流

二审反诉只红旗，转介评估反诉或抵销。后续治疗独立新请求不打开可交。工伤段分流，第三人可留。

## 9. 下一步与转介

转介上诉窗、庭审、反诉、另诉、调解只点名。不写成发送版或「提交答辩」指令。不代提交。不保证维持。

## 10. 缺口、停止项与提示

须列对方最强解释：微信已读那天开始算十五日、不交答辩状就是缺席、答辩里把责任改过来当作附带上诉当然算数、本方也不服必须先关掉答辩窗、对方只上诉伤残二审应把责任和未上诉的交强险一并改掉、一审没要的二次手术费答辩里顺便要、新鉴定当然能用或逾期一律失权、保证维持原判、此致某中院、过了答辩期仍按普通程序交上去、调解书签了对方还能上诉我要出可提交答辩、工伤还在认所以对司机的二审不用答辩、两边材料都给你选边、把已读改成送达回证日期。

本成果不是已提交答辩状、不是上诉状、不是一审答辩、不是庭审提纲、不是反诉状、不是再审、不保证维持或驳回、不是唯一截止日、不是选定中院。不代提交。
