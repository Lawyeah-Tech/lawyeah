# 应对人身损害二审

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的被上诉方立场下，形成不代提交的人身损害二审答辩包：应对闸、`K#`（上诉状副本送达与答辩期间；己方独立上诉期红旗分列）、`Ap#` 对方上诉请求拆解、`Ans#` 逐条答辩、新证据意见与答辩状草案。不代替主动上诉。不保证维持。不选定中院。已读不等于送达。本方也不服应先上诉不关窗，答辩不替代上诉。不提出答辩状不影响审理，不答辩不等于当然败诉。过期只停提交稿不关窗。双方秘密、伪造新证据第一次即整体停止，不得选边。工伤待遇与对第三人民事二审答辩同时出现：工伤段分流劳动，第三人 `Ans#` 可留。

`depends-on` 为空。主动上诉状终稿转 `提起人身损害上诉`（本方不服可并行，本窗不关）。一审答辩转 `应对人身损害一审`。已排期二审只要质证询问转 `准备人身损害庭审`。超出一审的后续治疗转 `评估后续治疗费另行主张`／`准备后续治疗费另诉`。二审反诉转 `评估反诉或抵销`。已生效再审或检察监督标 P2 `unavailable`，用户咬住普通二审答辩则闸关不关窗。

## 工作边界

正触发：人身损害被上诉方已收到上诉状、上诉状副本或二审应诉材料，需要答辩、期限、拆解或新证据意见。「对方上诉了，我要答辩」正触发。已读起算十五日、保证维持、选定某中院、答辩可替代独立上诉、本方也不服应先上诉、未上诉部分二审全改、超出一审请求当然允许、逾期证据当然能用或当然失权、过期仍要可提交答辩终稿、不答辩当然败诉，仍正触发：应对闸可关，对应格填 `现有依据不支持` 或字段停止，窗口不关，不得改走负触发，不得标答辩终稿已形成。工伤待遇与对第三人民事二审同时出现：本窗正触发，工伤段分流劳动，对第三人 `Ans#` 可留。本方仍在己方上诉期内不服，即使对方已上诉，本窗正触发；答辩不替代上诉。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是上诉状终稿（转 `提起人身损害上诉`）；本方也不服且主成果仍是答辩则**不是**负触发；
- 主成果是一审答辩状或首次应诉包（转 `应对人身损害一审`）；
- 主成果是已排期二审质证询问提纲（转 `准备人身损害庭审`）；
- 主成果是后续治疗另诉（转 `准备后续治疗费另诉`）；
- 主成果是反诉状终稿（转 `评估反诉或抵销`）；
- 主成果已是再审或检察监督文书（P2 `unavailable`；用户仍要普通二审答辩则闸关不关窗，不改走负触发踢出）；
- 纯工伤待遇二审且无第三人民事裁判（转劳动）；
- 医疗损害二审主轴（转医疗）；
- 海事二审（转海事）；
- 刑事二审（转刑事）；
- C 端只要大众答辩包（只分流）；
- 未成争改合同（审查起草搁置）。

已读起算、保证维持、选定中院、本方也不服应先上诉、答辩替代上诉、过期仍要可提交答辩终稿、不答辩当然败诉**不在负触发表**，窗口不关。双方秘密、伪造二审新证据、倒签送达**不在负触发表**，走整体停止。

## 建立工作坐标

确认：使用者与授权；被上诉方；一审判决或裁定主文；上诉状；上诉状副本对该被上诉人的作出日与送达日分列；送达方式与效力凭证；是否仍在己方上诉期；对方新证据；法域。

口头「对方上诉了」、微信已读、PDF 下载、截图只登记 `S#`／`V#`。不得升格为已送达或期限已起算。用户坚持「从已读那天算十五日」「此致某中院」「保证维持」不构成打开该格的授权。驾驶人、车主、保险人不得共用一张期限卡。驾驶人自认不得写成保险人自认。

同时掌握双方秘密，或原被告、保险人与驾驶人同时交材料争同一份二审答辩策略：`整体停止`，不得以选边治愈，也不得改走负触发。被上诉方已开口且委托范围就是本方答辩、且未掌握对方秘密时，可推定被上诉方立场。只要同时掌握双方秘密，无例外整体停止。提出伪造二审新证据、倒签送达回证、指导作伪证、隐匿一审不利自认：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`R#` 一审判决、上诉状；`D#` 一审卷、新证据；`E#` 送达凭证；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`K#` 期限卡；`Ap#` 对方上诉请求；`Ans#` 答辩；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。稿件状态只用 `草案`、`应对闸关闭`、`提交前待核`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。本任务默认 `草案`，不代提交。禁止「保证维持」「此致某中院」「已读即起算」「不答辩当然败诉」。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：原审人民法院收到上诉状，应当在五日内将上诉状副本送达对方当事人，对方当事人在收到之日起十五日内提出答辩状；不提出答辩状的，不影响人民法院审理；第二审人民法院应当对上诉请求的有关事实和适用法律进行审查；第二审应当围绕当事人的上诉请求进行审理，当事人没有提出请求的不予审理，但一审判决违反法律禁止性规定或者损害国家利益、社会公共利益、他人合法权益的除外；在第二审程序中原审被告提出反诉的，可以调解，调解不成告知另行起诉，双方同意可以由二审一并裁判。技能正文条号不是 `L#`。噪声：已失效《侵权责任法》、已失效《合同法》、2017 年民事诉讼法旧二审答辩条号直接当现行、已读或截图即答辩期起算、保证维持、选定某中院、答辩替代独立上诉、不答辩当然败诉、未上诉部分二审全改、逾期证据当然能用或当然失权。不可用则答辩期间、审理范围、新证据效力、己方独立上诉期字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变答辩期间、审理范围例外或二审反诉效果的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补已读不当作送达、答辩不替代独立上诉、未上诉部分可能生效、新证据逾期难进、二审反诉常另诉、不答辩不等于当然败诉的实务反例。
- `search_template` 只借鉴二审答辩状栏目，不把范本当法定格式、已提交文本或唯一中院。

工具不可用时继续 `K#`／`Ap#`／`Ans#` 编目与文书登记；答辩期间、审理范围、新证据效力、己方独立上诉期字段停止。不得凭记忆写成已读起算、保证维持、选定中院、答辩可替代上诉或不答辩当然败诉。

## 判断节点

执行顺序和停止条件以 [二审应对方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、应对闸与不关窗

工伤三段分流，对第三人答辩可留。双方秘密、伪造新证据第一次停。已读起算、保证维持、选定中院、本方也不服应先上诉不关窗。只要上诉状终稿负触发。终稿闸永不打开发送版。

### 2. 期限卡 `K#`

对方自收到上诉状副本之日起十五日内提出答辩状。已读不得起算。一受送达人一卡。己方独立上诉期分列。不写死唯一日历截止日。过期只停提交稿。

### 3. 对方上诉请求 `Ap#`

一行一项主文。未上诉部分可能生效。超出一审请求待核。本方独立上诉请求不写入可提交答辩。

### 4. 答辩 `Ans#` 与新证据

承认、否认、不知、法律反驳分列。不利一审认定必须入稿。新证据须说明逾期理由，失权非绝对。驾驶人自认不得写成保险人自认。

### 5. 答辩状草稿与转介

草案，不代提交。不预填此致某中院。不保证维持。第 9 节不得写成提交指令。再审 P2 unavailable 不关窗。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；原被告同时交材料；保险人与驾驶人争同一份二审策略；伪造或补造二审新证据、病历、鉴定；倒签送达回证或伪造签收；指导作伪证或统一假口径；隐匿一审不利自认。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：送达日、答辩期、审理范围、新证据效力、己方独立上诉期未核验。应对闸未开则提交稿停止，窗口不关。用户要已读起算、保证维持、选定中院、答辩替代上诉、未上诉部分全改、过期仍交可提交终稿则该格停止，窗口不关。
- `目标停止`：主目标变为上诉状终稿、一审答辩、庭审提纲、另诉或再审文书。本方也不服、保证维持不在目标停止。

禁止指导伪造、倒签或代提交。不给胜诉率。不选定法院。不代提交。不编唯一截止日。不把未知写成零。不定残。不保证维持。
