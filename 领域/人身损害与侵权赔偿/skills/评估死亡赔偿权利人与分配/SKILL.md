# 评估死亡赔偿权利人与分配

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文、已失效《继承法》或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的权利人或抗辩方立场下，形成 `P#` 近亲属与请求分配表：死亡事实；第一千零四五条近亲属闭集逐名编目；死亡赔偿金性质（一般不是遗产，不得按继承编第一千一百二十七条第一顺序排除或遗嘱处分）；无全体书面一致且无未到场权利人闭合时不得输出唯一分配比例，也不得把「均等」写成已核验必得；丧葬费定额请求与第一千一百八十一条第二款实际支出人分列、同一票据不双计；漏列不等于权利消灭、未授权亲属份额不得被本方放弃。不测算金额。不写抚慰金必得额。不办遗产管理。不代写起诉状。不代追加当事人。

`depends-on` 为空。金额转 `测算人身损害赔偿`。近亲属精神损害转 `评估精神损害赔偿`。工亡待遇转劳动，第三人侵权民事段转介 `评估工伤与第三人侵权竞合`。未成年子女或遗腹子主张代理转 `评估未成年或无行为能力受害人代理`。原告列名与漏列风险转 `提起人身损害一审`。未授权近亲属弃权转 `谈判人身损害和解` / `审查保险一次性了结弃权`。

## 工作边界

正触发：受害人死亡，近亲属范围或死亡赔偿金、丧葬费分配有争议；权利人或抗辩方提问均可。用户要「按继承第一顺序排除兄弟姐妹」「独吞」「均等必得」「唯一分配比例」「遗嘱处分死亡赔偿金」「被扶养人独立必得」仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关。工亡待遇与第三人侵权死亡赔偿同时出现：本窗正触发，工亡段分流劳动，民事死亡赔偿、近亲属清单、丧葬费可留。遗产房屋存款与死亡赔偿同时出现：遗产段分流婚家，死亡赔偿留本窗。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 受害人未死亡；
- 主轴仅是遗产管理、继承析产或房屋存款分割，且不问死亡赔偿金或丧葬费（转婚家）；
- 主轴仅是一次性工亡补助金、供养亲属抚恤金或工伤丧葬补助金分配，且无第三人侵权民事死亡赔偿争点（转劳动）；
- 只要分项金额或必得总额（转 `测算人身损害赔偿`）；
- 只要近亲属精神抚慰金终稿（转 `评估精神损害赔偿`）；
- 只要起诉状或发送版索赔通知（转 `提起人身损害一审` / `准备侵权索赔通知`）；
- 只要监护令或未成年受害人未死亡的代理表（转婚家或 `评估未成年或无行为能力受害人代理`）；
- C 端只要大众准备包（只分流）；
- 未成争改合同（审查起草搁置）。

「给一份独吞方案」「按继承法分」不在负触发表。

## 建立工作坐标

确认：使用者与授权；单方立场（权利人侧或抗辩方侧，不得同时代表互争份额的多名近亲属）；死亡事实材料；户口与亲属关系材料；配偶、父母、子女、兄弟姐妹、祖父母、外祖父母、孙子女、外孙子女是否被提到；非婚生、收养、继子女、遗腹子线索；是否已有部分亲属起诉；丧葬票据持有人；是否夹带工亡或遗产；法域。

口头「我是第一顺序所以独吞」「继子不是亲的」只登记 `S#`。

同时掌握双方秘密、或互争同一笔死亡赔偿金的多名近亲属同时交材料：`整体停止`，不得以选边治愈，也不得改走负触发、遗产析产或工亡关窗去出对一方有利的清单。提出伪造户籍、收养、解除收养、继子女或亲子关系、户口迁入、倒签亲属证明：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 户口、亲属关系、收养、继子女、丧葬票据分列；`R#` 死亡证明、火化证明、户籍注销、起诉状列名；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`P#` 近亲属或支出人行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。接口状态只用 `打开`、`不打开`、`待核`。技能正文中的条号是检索锚点，不是已核验 `L#`。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民法典第一千零四十五条近亲属闭集、第一千一百八十一条近亲属请求与实际支出人、法释〔2022〕14 号第一条（死亡受害人近亲属，不含 2003 年解释第一条旧「被扶养人独立主体」）、第十四条至第十六条（丧葬费、死亡赔偿金、被扶养人生活费计入）。技能正文条号不是 `L#`。噪声：已失效《侵权责任法》第十八条、2003 年解释第一条旧赔偿权利人、已失效《继承法》、把继承编第一千一百二十七条第一顺序或遗嘱规则当作死亡赔偿金分配法、把第九百九十四条死者人格权顺位套到第一千一百八十一条。不可用则近亲属是否有权、死亡赔偿金是否遗产、分配比例和法律效果字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变近亲属闭集、支出人请求或计入结论的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补有配偶父母子女时其他近亲属能否请求、均等是否被当作必得、工亡补助与民事死亡赔偿分列的实务反例。
- `search_case_by_fact` 仅比较兄弟姐妹请求、继子女或收养争议、遗腹子、部分亲属先诉的差异与翻转条件，不写成必须排除或必须全列、必须均等。

工具不可用时继续死亡事实、户口亲属材料和丧葬票据编目；法律效果字段停止。不得凭记忆按继承第一顺序排除兄弟姐妹或输出均等必得。

## 判断节点

执行顺序和停止条件以 [死亡权利人方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场与不关窗

仅遗产转婚家。仅工亡待遇且无第三人转劳动。第三人侵权民事段可留。错误主张不关窗。双方秘密或伪造亲属关系提出即停。

### 2. 近亲属清单

按第一千零四十五条闭集逐名可见。不得增删。不得按继承第一顺序从矩阵删行。非婚生、养子女、形成扶养关系的继子女材料不足该行待核。遗腹子或胎儿第十六条接口待核，不得写成已有独立诉权或已排除。

### 3. 死亡赔偿金性质与分配

一般不是遗产。不得用遗嘱或遗赠处分。无全体书面一致且无未到场权利人闭合 → 禁止唯一比例，禁止把均等写成已核验必得。被扶养人生活费计入死亡赔偿金，不另列独立赔偿权利人。

### 4. 丧葬费实际支出人

定额丧葬费走近亲属路径；实际支出人可请求已付合理费用。同一票据不双计。垫付标扣减或追偿，不写成第三人责任消灭。

### 5. 漏列、未授权与邻接接口

漏列不等于权利消灭。不得代弃未授权份额。不代追加。不写诉状。精神损害、保险金、工亡、遗产、测算只标接口。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；多名近亲属同时交材料或争同一笔死亡赔偿金；提出伪造户籍、收养、解除收养、继子女或亲子关系、倒签亲属证明。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：近亲属闭集、死亡赔偿金是否遗产、分配规则、支出人请求、被扶养人计入未核验。用户要独吞、均等必得、按继承第一顺序排除、遗嘱处分死亡赔偿金或被扶养人独立必得则该格停止，窗口不关。
- `目标停止`：主目标变为遗产管理终稿、工亡待遇分配终稿、测算、精神抚慰金终稿、起诉状或监护令。独吞方案不在目标停止。

禁止指导伪造亲属关系或代签未授权亲属弃权。不给胜诉率。不选定法院。不保证必得总额。不代提交。不办遗产管理。
