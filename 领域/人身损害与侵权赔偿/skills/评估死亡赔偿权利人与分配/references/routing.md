# 边界与路由

## 正触发

受害人死亡，近亲属范围或死亡赔偿金、丧葬费分配有争议。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 继承析产 | 婚家领域 |
| 工亡待遇 | 劳动领域 |
| 受害人未死亡 | 负触发 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗产管理继承 | 婚家领域 |
| 工亡待遇 | 劳动领域 |
| 刑事被害人救济 | 刑事领域并行 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“人死了谁有权要死亡赔偿金”正触发。“房子怎么分”转婚家。“工亡补助怎么领”转劳动。
