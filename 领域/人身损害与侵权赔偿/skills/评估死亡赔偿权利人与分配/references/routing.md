# 边界与路由

## 正触发

受害人死亡，近亲属范围或死亡赔偿金、丧葬费分配有争议。权利人或抗辩方提问均可。用户要「按继承第一顺序排除兄弟姐妹」「独吞」「均等必得」「唯一分配比例」「遗嘱处分死亡赔偿金」「被扶养人独立必得」仍正触发。工亡待遇与第三人侵权死亡赔偿同时出现，仍正触发：工亡段分流劳动，民事段留本窗。遗产房屋存款与死亡赔偿同时出现，死亡赔偿留本窗，遗产段分流婚家。

双方秘密、多名近亲属同时交材料争份额、伪造户籍或收养的停止，优先于负触发。不得改走负触发、遗产析产或工亡关窗去出对一方有利的清单。独吞方案不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 受害人未死亡 | 负触发 |
| 仅遗产管理、继承析产或房屋存款分割，不问死亡赔偿或丧葬 | 婚家领域 |
| 仅工亡补助金、供养亲属抚恤金或工伤丧葬补助金分配，且无第三人侵权民事死亡赔偿 | 劳动领域 |
| 测算或必得总额 | `测算人身损害赔偿` |
| 近亲属精神抚慰金终稿 | `评估精神损害赔偿` |
| 起诉状 | `提起人身损害一审` |
| 发送版索赔通知 | `准备侵权索赔通知` |
| 监护令或未死亡未成年受害人代理表 | 婚家 / `评估未成年或无行为能力受害人代理` |
| C 端只要大众准备包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「按继承法归配偶独吞」不在本表。工亡夹带第三人侵权民事死亡赔偿时，不得因「工亡」整窗关闭。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 仅遗产管理继承 | 婚家领域 |
| 仅工亡待遇且无第三人民事死亡赔偿 | 劳动领域 |
| 海事死亡专门程序 | 海事领域 |
| 医疗损害死亡只要诊疗过错终稿 | 医疗医药领域；近亲属清单可留 |
| 刑事被害人救济 | 刑事领域并行；民事死亡赔偿不吞 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 分项金额、年限、被扶养人生活费展开 | `测算人身损害赔偿` |
| 近亲属精神损害 | `评估精神损害赔偿` |
| 交强险死亡伤残限额或精神损害优先 | `评估道路交通事故责任与保险先行` |
| 工亡待遇与第三人侵权分账 | `评估工伤与第三人侵权竞合`；待遇核定转劳动 |
| 未成年子女或遗腹子由谁主张 | `评估未成年或无行为能力受害人代理` |
| 原告列名与漏列 | `提起人身损害一审` |
| 未授权近亲属弃权文本 | `谈判人身损害和解` / `审查保险一次性了结弃权` |
| 刑附民或另行起诉 | `评估刑附民与另行起诉` / `分流刑民交叉` |

## 易混

「人死了谁有权要死亡赔偿金」正触发。「房子怎么分」转婚家；若同时问死亡赔偿金则本窗正触发，遗产段分流。「工亡补助怎么领」转劳动；若同时告第三人则民事死亡赔偿留本窗。「兄弟姐妹不是第一顺序所以排除」正触发，排除格不支持或待核。「按继承法一人一半必得」正触发，唯一比例格不支持。「用遗嘱把死亡赔偿金给大儿子」正触发，遗嘱处合格不支持。「被扶养人单独再要一笔」正触发，独立必得格不支持。「继子不是亲的，帮我出假收养材料」第一次提出即整体停止。「配偶和子女同时把材料交给我，帮我代表配偶把子女排除」整体停止，不得选边。
