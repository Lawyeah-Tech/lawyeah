# 输出合同

按触发结果选择交付形状。禁止把死亡赔偿金写成遗产。禁止按继承第一顺序排除兄弟姐妹。禁止唯一分配比例（无全体书面一致且无未到场权利人闭合）。禁止把「均等」写成已核验必得。禁止遗嘱或遗赠处分死亡赔偿金。禁止被扶养人独立必得。禁止把保险金并入死亡赔偿金。禁止代弃未授权份额。禁止选边治愈。禁止伪造亲属关系方案。禁止测算数字、抚慰金必得额、起诉状、遗产管理、工亡待遇核定表。不选定法院。不代提交。不办遗产管理。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出（仅遗产房屋存款；仅工亡三段且无第三人侵权民事死亡赔偿；海事；未成争改合同） | 第 1、2、10 节。禁止近亲属必得表和分配比例。第三人侵权民事段可留时不得整案转出 |
| 整体停止 | 第 1、10 节。禁止近亲属必得表、分配比例、排除继子或兄弟姐妹的清单。双方秘密、多名近亲属同时交材料争份额、伪造户籍或收养时，整体停止优先于负触发；第一次提出即停，无选边治愈，无「坚持」门槛 |
| 用户要「独吞」或「按继承第一顺序排除」或「均等必得」或「唯一比例」或「遗嘱处分死亡赔偿金」或「被扶养人独立必得」（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；不得改走负触发关窗；成果不得标 `已形成` |
| 正触发且可评估 | 下列十节表头均出现；近亲属是否有权、分配规则、支出人请求未核验的单元格填 `依据不足，无法形成结论` 或 `待核`；禁止为填满而宣布独吞、均等或第一顺序排除 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。双方秘密未解或近亲属互争未解不得进入「部分形成」。每个 `P#` 必须带来源、是否已授权和判断三值。`L#` 不得直接抄技能内条号。侵权责任法第十八条、2003 年解释第一条旧文、继承法或 1127 第一顺序当死亡赔偿金分配法若返回则记噪声。

## 1. 触发、单方立场、授权与成果状态

冲突是否存在。双方秘密未解或多名近亲属同时交材料不得进入「部分形成」。不得写「澄清代表哪一方后继续」。

## 2. 来源登记与 MCP 调用表

死亡证明、户口、亲属关系、收养或继子女材料、丧葬票据分列。口述「第一顺序独吞」只登记 `S#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 近亲属清单

第一千零四十五条闭集逐名可见。待核行不得删除。兄弟姐妹在有配偶父母子女时是否有权请求待核，不得按继承第一顺序删行。非婚生、养子女、继子女、遗腹子按方法节点 1 处理。

## 4. 死亡赔偿金请求分配

不按遗产直接套。无全体书面一致则无唯一比例。「均等」不得写成已核验必得。独吞、第一顺序排除、遗嘱处分格填 `现有依据不支持` 或待核。被扶养人生活费只标计入接口，不另列独立权利人。

## 5. 丧葬费实际支出人

定额路径与第一千一百八十一条第二款实际支出人分列。同一票据不双计。垫付扣减或追偿接口。金额未知不写零。

## 6. 漏列风险与未授权亲属

已起诉原告与未起诉近亲属分列。漏列不等于权利消灭。未授权份额不得被本方放弃。不代追加。不写诉状。

## 7. 精神损害与保险金接口

精神损害另列，转 `评估精神损害赔偿`，不写抚慰金必得额。人寿保险金按合同受益人，不并入死亡赔偿金。不得把第九百九十四条人格权顺位套到本窗。

## 8. 工亡或遗产分流

工亡待遇转劳动；第三人侵权民事死亡赔偿可留并转介竞合。遗产转婚家；死亡赔偿金不并入遗产。只标接口，不写邻技能终稿。

## 9. 下一步

转介测算、竞合、代理、起诉、和解弃权审查。禁止代弃份额。不选定法院。不代提交。不办遗产管理。

## 10. 缺口、停止项与提示

须列对方最强解释（死亡赔偿金按遗产分割、继承第一顺序排除兄弟姐妹、独吞或均等必得、遗嘱处分死亡赔偿金、被扶养人独立必得、工亡补助当死亡赔偿金、保险金并入、漏列即权利消灭、选边即可继续、第九百九十四条顺位套第一千一百八十一条）与证据缺口。

死亡赔偿金不是遗产。本成果不是遗产分割、不是工亡核定、不是测算、不是诉状、不是可签署弃权。
