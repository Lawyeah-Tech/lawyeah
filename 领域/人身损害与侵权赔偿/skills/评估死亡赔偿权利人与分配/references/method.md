# 死亡权利人方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。接口状态只用 `打开`、`不打开`、`待核`。禁止胜诉率、必然责任比例、唯一分配比例（除非书面一致且无未到场权利人闭合）、唯一必得总额、选定法院。未知金额不写零。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》第十八条、2003 年人身损害赔偿解释第一条旧「赔偿权利人」（含被扶养人独立主体）、已失效《继承法》、把继承编第一千一百二十七条第一顺序或遗嘱、法定继承规则当作死亡赔偿金分配规范，或把民法典第九百九十四条死者人格权请求顺位套到第一千一百八十一条时记为噪声，不得写入 `L#`。禁止把死亡赔偿金写成遗产。禁止按第一顺序排除兄弟姐妹。禁止把被扶养人生活费写成独立必得请求。

`P#` 固定列：`编号｜姓名或称谓｜与死者关系（1045 闭集内类别）｜材料（户口/收养/继子女扶养/出生医学证明/其他）｜是否已授权本方｜是否已起诉｜请求类型（死亡赔偿金/丧葬定额/1181 第二款实际支出/精神损害接口/保险金不并入）｜判断｜待核`。一行一名自然人的一个请求类型。禁止合成「第一顺序已在所以其他人排除」或「均等必得」。

整案转出只交付第 1、2、10 节。

本窗**永不**出具遗产分割方案、工亡待遇核定表、起诉状或可签署弃权。用户同时要测算或起诉：本窗清单与邻窗并行，本窗不写金额终稿或诉状。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密、或互争同一笔死亡赔偿金的多名近亲属同时交材料且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发、遗产析产或工亡关窗。

## 节点 1　近亲属清单

检索锚点：民法典第一千零四十五条第三款近亲属闭集＝配偶、父母、子女、兄弟姐妹、祖父母、外祖父母、孙子女、外孙子女。第一千一百八十一条第一款：被侵权人死亡的，近亲属有权请求侵权责任。法释〔2022〕14 号第一条：赔偿权利人＝直接受害人以及死亡受害人的近亲属。未核验不得增（叔伯堂表、姻亲、事实伴侣）不得从闭集删行。

清单必须按闭集**逐名可见**。材料不足标待核，不得从矩阵删行。有配偶、父母、子女时，兄弟姐妹等其他近亲属**是否有权请求死亡赔偿金须核验**，不得按继承编第一千一百二十七条第一顺序当然排除，也不得当然全部列入已核验权利人。抗辩方主张不适格：逐名核对，不得因「第一顺序已在」直接驳回。

| 关系行 | 最低表面 | 禁止写法 |
| --- | --- | --- |
| 配偶、父母、子女 | 户口、结婚证、出生医学证明或死亡证明记载 | 「通常在列」写成已核验闭集外排除依据；口头自称即闭合 |
| 兄弟姐妹、祖父母、外祖父母、孙子女、外孙子女 | 户口或亲属关系材料；有权请求死亡赔偿金字段待核 | 按继承第一顺序删除；按第九百九十四条人格权顺位删除 |
| 非婚生子女 | 民法典第一千零七十一条同等权利；亲子材料 | 「不是领证生的」排除 |
| 养子女 | 第一千一百一十一条；合法收养材料 | 口头「不是亲的」排除；指导补假收养 |
| 继子女 | 第一千零七十二条受抚养教育；扶养事实材料 | 口头「未形成扶养」即排除；伪造解除收养或改口踢出 |
| 遗腹子 / 胎儿 | 第十六条接口待核 | 写成已有独立诉权或已排除；把抚养费写成已核验独立必得 |

未授权亲属不得被本方放弃其份额。部分亲属已起诉：`P#` 只把已授权原告标为「已起诉」，未起诉行保持可见并记漏列风险，不代追加。

用户要按第一顺序排除兄弟姐妹或把继子踢出清单：该行判断 `现有依据不支持` 或待核，窗口不关；不得删行。

## 节点 2　死亡赔偿金性质与分配

死亡赔偿金一般不是遗产，不得按遗产规则直接分割，不得用遗嘱或遗赠处分。人寿保险金按保险合同受益人，本窗不分配；受益人争议不改写成近亲属清单。

被扶养人生活费计入死亡赔偿金。检索锚点：法释〔2022〕14 号第十六条。本窗只标权利人侧接口：被扶养人不是第一千一百八十一条近亲属闭集外的第四类原告；不另作独立必得请求。金额展开转 `测算人身损害赔偿`。2003 年解释第一条旧「被扶养人独立主体」是噪声。

无全体书面一致、且存在未到场或未授权权利人 → **禁止输出唯一分配比例**，也**禁止把「均等」写成已核验必得**。单方书面不等于全体一致。用户要独吞、均等必得、按继承第一顺序必得或唯一比例：该格 `现有依据不支持` 或字段停止，窗口不关。

分配规则未核验则分配法律效果字段停止。实务上出现的「均等」或「协商」最多作待核参考，不得升格 `L#`。

## 节点 3　丧葬费实际支出人

定额丧葬费计算转 `测算人身损害赔偿`（检索锚点：解释第十四条）。本窗只分主体：

- 定额丧葬费请求主体走近亲属路径，待核；
- 第一千一百八十一条第二款：支付医疗费、丧葬费等合理费用的人有权请求，但侵权人已经支付的除外；
- 票据持有人与近亲属不一致时分列；同一票据不得由近亲属定额请求与实际支出人请求双计；
- 单位或第三人垫付：标扣减或追偿接口，禁止写成第三人侵权责任消灭。

金额未知标未知，禁止写零。

## 节点 4　漏列、未授权与邻接接口

漏列不等于权利消灭。本窗不代追加当事人，不写起诉状，不选定法院。未授权近亲属份额不得被本方在和解或保险了结中放弃；弃权文本转 `谈判人身损害和解` / `审查保险一次性了结弃权`。

| 接口 | 本窗 | 转介 |
| --- | --- | --- |
| 分项金额、年限、被扶养人生活费展开 | 只标计入，不测算 | `测算人身损害赔偿` |
| 近亲属精神损害 | 另列接口，不写抚慰金必得额；不得把第九百九十四条顺位套到本窗死亡赔偿 | `评估精神损害赔偿` |
| 交强险死亡伤残限额或精神损害优先 | 只标接口 | `评估道路交通事故责任与保险先行` |
| 一次性工亡补助金、供养亲属抚恤金 | 转劳动；民事死亡赔偿可留 | `评估工伤与第三人侵权竞合` |
| 遗产房屋存款 | 转婚家；死亡赔偿不并入遗产 | 婚家领域 |
| 未成年子女或遗腹子由谁主张 | 只标代理闭合接口 | `评估未成年或无行为能力受害人代理` |
| 原告列名 | 只给 `P#` 与漏列风险 | `提起人身损害一审` |
| 刑附民或刑事被害人救济 | 并行，不吞民事死亡赔偿 | `评估刑附民与另行起诉` / `分流刑民交叉` |

刑事被害人救济并行时专项段只分流，不把专项规则写入本任务结论。

## 本任务回链纪律

本任务成果是「死亡赔偿近亲属清单与分配接口」。不包含：遗产分割或遗产管理终稿、工亡待遇核定、测算数字、精神抚慰金必得额、起诉状、可签署弃权、监护令。禁止按继承第一顺序排除。禁止死亡赔偿金当遗产。禁止选边治愈。禁止代弃未授权份额。禁止被扶养人独立必得。禁止把保险金并入死亡赔偿金。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接：已固定死亡事实、`P#` 可见行和缺口。
