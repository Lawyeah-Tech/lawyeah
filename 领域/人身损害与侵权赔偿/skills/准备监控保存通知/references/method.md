# 保存通知方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。通知状态只用 `草案`、`待发送`、`已发送待证明到达`、`已到达`、`停止`。禁止胜诉率、必然败诉、唯一覆盖天数、法定七日答复、选定法院、自行宣布伤残等级。未知金额不写零。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文、把诉讼外保存函写成民诉证据保全裁定、把拒不保存写成必然证明妨碍败诉或 1198 全责、把覆盖 7/15/30 天或七日答复写成法定时记为噪声，不得写入 `L#`。禁止指导侵入系统或私下拷贝。

`N#` 固定列：`版本｜状态（草案/待发送/停止）｜收件人｜事件时空｜载体与通道方位｜保存起止（缓冲须标S#）｜不得覆盖或删除｜答复方式（标明非法定）｜保留权利｜禁止夹带认责/罪名/索赔项目表/全盘拷贝｜来源回链`。
`E#` 固定列：`实施人｜文本版本｜渠道｜地址｜回证｜失败升级（只点转介名）`。一行一个收件人。禁止合成「全城监控一律保存」。

拟制日＝本次形成本任务成果之日。函面、落款、寄出、拟制四类日期均不得早于本次形成日。

## 节点 0　分流、立场、发送闸与不关窗

整案转出或闸关闭只交付第 1、2、10 节，不交 `N#`/`E#` 发送前终稿。

| 信号 | 处理 |
| --- | --- |
| 只要索赔通知正文或项目表 | 负触发 `准备侵权索赔通知`；禁止「用户明确合并」后在本窗夹带索赔表 |
| 只要现场、聊天或行车记录仪步骤 | 负触发 `保全现场监控与电子证据` |
| 已决定法院证据保全申请书 | 负触发 `准备财产或证据保全申请` |
| 尚未决定是否保全 | 负触发或并行转 `评估证据或财产保全必要性`；本窗保存函可留 |
| 只要送达渠道专项、不写保存正文 | 负触发 `设计人身案件通知送达` |
| 只要调查令或公证保全终稿 | 负触发对应原子 |
| 主轴仅工伤认定、劳鉴或待遇，且无第三人/场所民事监控争点 | 整案转劳动；夹带第三人侵权或场所/车辆监控可能覆盖则本窗正触发，工伤段分流，保存函可留并转介 `评估工伤与第三人侵权竞合` |
| 诊疗过错或医疗鉴定终稿 | 转医疗；场所监控保存函可留 |
| 海事专门程序 | 转海事 |
| 未成争只要改合同 | 审查起草本窗搁置 |

发送闸打开条件（同时满足）：单方无冲突立场与授权；至少一名收件人有名称或地址线索；载体类型加大致地点；拟保存时段可标 `S#` 或更强来源；主成果是保存通知而非保全申请、索赔函或调查令。

闸关闭（仍正触发）：完全不知地点与时段；收件人无线索；目的是威慑、侵入或今晚必须发出而无最小事实；「今天必须发」本身不得开闸。合法二次催告（已寄过一次、补时段或补送达）不受「对方未回复不得打开闸」误关。

「唯一覆盖天数」「七日法定答复」「逾期即证明妨碍败诉」「今天必须发出发送版」**不关窗**。闸未开则仍只交 1、2、10 节。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或受害人与场所、物业、承运人同时交材料争同一份监控且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出侵入系统、破解密码、收买监控员、私下拷贝、伪造回证、倒签或把本稿写成此前已发出、威胁曝光或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　收件人与时段定位

收件人分列：场所经营者、物业服务人、承运人、车队、停车场或实际控制监控的主体。收件人无线索：闸关闭，依据不足。不选定唯一义务人。不得把收件人写成「依法已负安保义务故必须保存」；1198 成立转 `评估场所安全保障义务`，本窗该格不支持或待核。

时段用事故前后缓冲，避免无限期。通道名称、摄像头大致方位写入通知，猜测须标明 `S#`。覆盖周期通常较短：标紧急红旗，但不编造具体法定天数，除非用户材料给出该场所或设备的周期线索。用户要「依法只循环七天」：该格 `现有依据不支持` 或待核，窗口不关。

通知范围只限与争议相关的特定机位和时段。禁止要求打包全部硬盘、全时段或无关第三人画面。个人信息与网络安全规则未核验则范围限缩字段停止，不得扩大。

## 节点 2　发送前正文

写明事件时间地点、保存对象、不得覆盖或删除、回复渠道。法律后果只作保留权利。不写罪名，不写必然败诉，不以刑逼民。不夹带完整索赔项目表。不承认不确定责任。

指定答复期间只能标明非法定；逾期不产生认责、失权、同意或证明妨碍当然成立的效果。用户要七日/十五日法定答复：该格 `现有依据不支持` 或待核，窗口不关。

逐句回链 `S/D`。状态 `草案` 或 `待发送`。

---

## 节点 3　到达设计

约定工商地址、现场签收、邮寄、邮箱等候选和回证。本任务不执行发送，不补造回证。微信已读、孤立截图、口头转述最多升到 `已发送待证明到达`，不得升 `已到达`，也不得据此起算覆盖倒计时或视为保存义务已激活。

只要送达渠道专项、不写保存正文：负触发 `设计人身案件通知送达`。本窗只留最小 `E#`。

失败升级只点转介名：`评估证据或财产保全必要性`、`准备财产或证据保全申请`、`申请人身案件调查令或取证`、`准备人身案件公证保全`、`保全现场监控与电子证据`。本窗不写那些终稿。不选定法院。

## 节点 4　与法院保全及证明妨碍

保存通知不等于已经保全，不是搜查令。民诉证据保全条号运行时核验，本窗不写申请书。

拒不保存的证明妨碍效果待核。检索锚点：诉讼中责令提交及无正当理由拒不提交的规则；视听资料是否适用、诉前通知能否直接推定，一律待核。禁止写成必然败诉或举证责任倒置闭集。用户要「不留就是输」：该格 `现有依据不支持` 或待核，窗口不关。

时效中断主要是索赔通知争点；保存函不当然中断时效。到达中断效果字段停止，转 `准备侵权索赔通知` / `评估人身损害诉讼时效`。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过发送闸直接给发送前终稿。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日或法定覆盖天数。
若 if C 端只要大众准备包，then 只分流不回改。

判断状态只许三值。口头转述、截图和「已读」不得写成已受理、已送达、覆盖期限已起算或保存义务已激活。

## 本任务回链纪律

本任务成果是「发送前监控保存通知与最小到达设计」。不包含：法院保全申请、现场电子证据步骤、索赔通知正文、送达专项终稿、调查令、公证保全事项、场所安保责任成立。禁止侵入。禁止倒签。禁止选边治愈。禁止把拒不保存写成必然败诉。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标发送前终稿已形成。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接。
风险档 A：不可逆文书或期限字段必须单独标可逆性。
