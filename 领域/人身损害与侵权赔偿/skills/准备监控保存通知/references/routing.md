# 边界与路由

## 正触发

监控、巡检或后台记录可能被覆盖，需要发送保存通知并设计到达证明。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 法院保全申请 | `准备财产或证据保全申请` |
| 侵入系统 | 整体停止 |
| 索赔通知正文 | `准备侵权索赔通知` |
| 送达渠道专项 | `设计人身案件通知送达` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 违法调取个人信息或侵入系统 | 停止并禁止 |
| 工程现场造价资料 | 建设工程领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“监控一周就覆盖，先发函让他们留着”正触发。“直接去机房拷”停止。“要法院保全裁定”走保全申请。
