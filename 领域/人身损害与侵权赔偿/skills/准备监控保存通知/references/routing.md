# 边界与路由

## 正触发

监控、巡检或后台记录可能被覆盖，需要发送前保存通知和到达设计。不知地点、时段或收件人仍正触发，发送闸关闭。用户要「依法只循环七天」「七日法定答复」「逾期即证明妨碍败诉」「今天必须发出发送版」仍正触发。工伤待遇与第三人/场所民事监控同时出现，仍正触发：工伤段分流劳动，保存函可留。

双方秘密、受害人与场所同时交材料、侵入、收买监控员、倒签已发出的停止，优先于负触发。不得改走负触发去出函或现场步骤。侵入不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 法院保全申请书 | `准备财产或证据保全申请` |
| 尚未决定是否保全 | `评估证据或财产保全必要性`；本窗保存函可留 |
| 现场、聊天或行车记录仪合法保全步骤 | `保全现场监控与电子证据` |
| 索赔通知正文或项目表 | `准备侵权索赔通知` |
| 只要送达渠道专项、不写保存正文 | `设计人身案件通知送达` |
| 调查令终稿 | `申请人身案件调查令或取证` |
| 公证保全事项 | `准备人身案件公证保全` |
| 场所安保责任成立终稿 | `评估场所安全保障义务` |
| 收件人完全不明且主问谁是侵权人 | `评估侵权人不明路径`；保存闸可并行关闭 |
| C 端只要大众准备包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「直接去机房拷」「收买监控员」不在本表，走整体停止。工地人身损害监控保存不得因造价资料误转建设工程。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 仅工伤待遇且无第三人/场所民事监控 | 劳动领域 |
| 医疗损害鉴定终稿 | 医疗医药领域；场所保存函可留 |
| 海事专门程序 | 海事领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。第三人/场所监控保存可留。

## 易混

「监控一周就覆盖，先发函让他们留着」正触发。「还不知道哪个口、哪个点，但今天必须发出」仍正触发，发送闸关闭，只交 1、2、10 节。「直接去机房拷」第一次提出即整体停止。「给监控员好处费拷一份」整体停止。「要法院保全裁定」走保全申请或必要性评估。「写一份让物业留监控的函」正触发。「顺便把索赔项目和伤残金额写进去」转索赔通知，本窗不合并。「已经判场所全责所以必须留」正触发，安保成立格不支持或待核，保存函可不认责继续。「工伤也要认，商场监控还在转」正触发，保存函可留，工伤段分流。
