# 输出合同

按触发结果选择交付形状。发送闸未打开不得交付发送前终稿。禁止把保存函写成法院保全裁定或搜查令。禁止侵入、破解、收买监控员或私下拷贝步骤。禁止倒签或把本稿写成此前已发出。禁止唯一法定覆盖天数。禁止七日法定答复。禁止拒不保存即必然败诉或举证责任倒置闭集。禁止夹带索赔项目表。禁止选边治愈。不执行发送。不选定法院。不代提交。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 发送闸关闭或节点 0 整案转出 | 第 1、2、10 节：关闭理由和最小补证。禁止 `N#`/`E#` 发送前终稿。第三人/场所保存可留时不得因工伤整案转出 |
| 整体停止 | 第 1、10 节。禁止正文、渠道、倒签或侵入步骤。双方秘密、受害人与场所同时交材料、侵入、收买、倒签时，整体停止优先于负触发；第一次提出即停，无选边治愈，无「坚持」门槛 |
| 用户要「唯一覆盖天数」或「七日法定答复」或「必然败诉」或「今天必须发出发送版」（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；闸未开则仍只交 1、2、10；不得改走负触发关窗；成果不得标发送前终稿 `已形成` |
| 正触发且闸开 | 下列十节表头均出现；保存义务、妨碍效果、到达未核验的单元格填 `依据不足，无法形成结论` 或 `待核`；禁止为填满而宣布已保全、必然败诉或已送达 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入发送前终稿已形成。双方秘密未解不得进入「部分形成」。每个 `N#`/`E#` 必须带来源和状态。`L#` 不得直接抄技能内条号。七日法定答复、覆盖天数法定、拒不保存即败诉若返回则记噪声。

## 1. 触发、单方立场、授权与成果状态

发送闸开或关。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。通知状态默认 `草案` 或 `待发送`。

## 2. 来源登记与 MCP 调用表

地点、时段、机位、收件人分列。口述覆盖天数只登记 `S#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 发送闸、载体与覆盖风险

紧急只作红旗。禁止全国唯一覆盖天数。无材料不编截止日。「今天必须发」不得开闸。

## 4. 收件人与时段定位

场所、物业、承运人、车队分列。通道方位猜测标 `S#`。避免无限期。只限特定机位和时段。不评估安保成立。

## 5. 发送前保存通知 `N#`

只要保存，不认责，不写罪名，不夹索赔表，不要求全盘拷贝。答复期标明非法定。状态 `草案`/`待发送`。逐句可回链。禁止倒签。

## 6. 到达设计 `E#`

最小列。不执行发送。已读不等于到达，不得起算覆盖倒计时。只要送达专项则转介。

## 7. 禁止事项与合法升级接口

侵入第一次停。保全、调查令、公证、现场电子只转介，不写终稿。不等于已经保全。

## 8. 最强异议

无保存义务、已覆盖、无权调取、通知无效、选边即可继续、拒不保存即必然败诉。

## 9. 风险与下一步

不执行发送。用户回报送达事实后再升状态。转介建卷、保全必要性、索赔通知（并行不合并）、调查令或公证。不选定法院。

## 10. 缺口、停止项与提示

须列对方最强解释（依法只循环七天、七日法定答复、逾期即证明妨碍、不留就是输、保存函就是保全裁定、去机房拷一份、选边即可继续）与证据缺口。

本成果不是法院保全、不是搜查令、不是索赔函、不是调查令、不是公证保全、不保证妨碍推定。不执行发送。
