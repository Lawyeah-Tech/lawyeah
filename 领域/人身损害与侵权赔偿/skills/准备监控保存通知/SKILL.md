# 准备监控保存通知

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成发送前保存通知包：发送闸、`N#` 保存通知草案、时段与机位定位、最小 `E#` 到达设计。本任务不执行发送，不伪造送达，不等于法院证据保全，不是搜查令，不指导侵入系统或私下拷贝。不夹带完整索赔项目表。不写保全申请、调查令、公证保全事项或现场取证步骤终稿。

`depends-on` 为空。索赔正文转 `准备侵权索赔通知`。现场合法保全步骤转 `保全现场监控与电子证据`。是否申请法院保全转 `评估证据或财产保全必要性` / `准备财产或证据保全申请`。只要送达渠道专项转 `设计人身案件通知送达`。

## 工作边界

正触发：监控、巡检或后台记录可能被覆盖，需要发送前保存通知和到达设计。不知地点、时段或收件人仍正触发：发送闸关闭，只交关闭理由和补证，不出发送前终稿。用户要「依法只循环七天」「七日法定答复」「逾期即证明妨碍败诉」「今天必须发出发送版」仍正触发：对应格填 `现有依据不支持` 或字段停止，闸未开则仍不出发送前终稿，窗口不关。工伤待遇与第三人/场所民事监控同时出现：本窗正触发，工伤段分流劳动，保存函可留。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 已决定申请法院证据保全且只要申请书（转 `准备财产或证据保全申请`）；尚未决定则转 `评估证据或财产保全必要性`；
- 只要现场、聊天或行车记录仪合法保全步骤（转 `保全现场监控与电子证据`）；
- 只要索赔通知正文或项目表（转 `准备侵权索赔通知`）；
- 只要送达渠道专项、不写保存正文（转 `设计人身案件通知送达`）；
- 只要调查令终稿（转 `申请人身案件调查令或取证`）；
- 只要公证保全事项（转 `准备人身案件公证保全`）；
- 只要场所安保责任成立终稿（转 `评估场所安全保障义务`）；
- C 端只要大众准备包（只分流）；
- 未成争改合同（审查起草搁置）。

侵入系统、破解密码、收买监控员、私下拷贝、倒签已发出**不在负触发表**，走整体停止。

## 建立工作坐标

确认：使用者与授权；单方立场；场所、车辆或机位线索；拟保存时段；收件人名称或地址线索；拟签发主体与拟发送日；法域。

口头「一周就覆盖」「已经删了」只登记 `S#`。不得编造法定覆盖天数。

同时掌握双方秘密，或受害人与场所、物业、承运人同时交材料争同一份监控：`整体停止`，不得以选边治愈，也不得改走负触发去出函。受害人已开口且委托范围就是保存通知、且未掌握对方秘密时，可推定主张方立场。只要同时掌握双方秘密，无例外整体停止。提出侵入系统、破解密码、收买监控员私下拷贝、伪造回证、倒签落款或把本稿写成此前已发出：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 现场照片、场所信息、工商地址；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`N#` 通知稿；`E#` 送达设计；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。通知状态只用 `草案`、`待发送`、`已发送待证明到达`、`已到达`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。本任务默认 `草案` 或 `待发送`，不执行发送。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：诉讼外保存通知性质（不等于民诉证据保全裁定）；非法获取计算机信息系统数据、非法侵入或非法控制的禁止；意思表示到达与回证；书证提出命令或拒不提交推定以诉讼中法院责令为前提，诉前不得写成已成立。个人信息与网络安全只核验通知范围须限缩到特定机位和时段。技能正文条号不是 `L#`。噪声：已失效《侵权责任法》、2003 年解释已删除条文、把七日答复写成法定、把覆盖 7/15/30 天写成法定、把拒不保存写成必然败诉或 1198 全责、把保存函写成保全裁定。不可用则保存义务、妨碍效果、到达字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变保存义务、到达或禁止自助取证的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补覆盖周期行业差异、保存通知不等于法院保全、拒不保存不等于必然败诉、已读不等于到达的实务反例。
- `search_template` 只借保存通知栏目，不把范本当法定格式或法定七日。

工具不可用时继续地点、时段、收件人和正文结构；法律效果字段停止。不得凭记忆写法定覆盖天数或必然败诉。

## 判断节点

执行顺序和停止条件以 [保存通知方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、发送闸与不关窗

工伤三段分流，场所或第三人保存函可留。不知地点时段仍正触发，闸关闭。侵入第一次停。错误主张不关窗。

### 2. 收件人与时段定位

场所经营者、物业、承运人、车队分列。猜测标 `S#`。避免无限期。不评估安保成立。

### 3. 发送前正文

只要求保存特定机位与时段。不认责、不写罪名、不夹索赔表、不要求全盘拷贝。答复期标明非法定。

### 4. 到达设计

最小 `E#`。不执行发送。已读不等于到达。只要送达专项则转介。

### 5. 升级接口

拒不保存或通知失败：只标转介法院保全必要性、调查令、公证或现场电子证据。本窗不写那些终稿。不等于已经保全。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；受害人与场所同时交材料；提出侵入系统、破解密码、收买监控员、私下拷贝、伪造回证、倒签或把本稿写成此前已发出、威胁曝光。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：保存义务规范、证明妨碍效果、到达与时效中断未核验。用户要唯一覆盖天数、七日法定答复、必然败诉或今天必须发出则该格停止，窗口不关；闸未开仍不出发送前终稿。
- `目标停止`：主目标变为法院保全申请、索赔通知正文、现场取证步骤、调查令、公证保全或送达专项终稿。

禁止指导侵入或私下拷贝。不给胜诉率。不选定法院。不代发送。不倒签。
