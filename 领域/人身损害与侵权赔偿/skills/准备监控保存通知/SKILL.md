# 准备监控保存通知

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“保存通知、时段定位、送达设计”。不等于法院保全。不指导侵入系统。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算、鉴定和证据清单。

## 工作边界

正触发：监控、巡检或后台记录可能被覆盖，需要发送保存通知并设计到达证明。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 已决定申请法院证据保全（转 `准备财产或证据保全申请`）；
- 要求侵入系统、破解密码或私下拷贝；
- 只要通知实体索赔内容（转索赔通知）。

本任务不等于法院保全，不执行发送，不指导侵入系统。

## 建立工作坐标

确认：使用者与授权；单方立场；场所或车辆；监控大致位置；可能覆盖周期；收件人；拟保存时段；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 现场照片、场所信息；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`N#` 通知稿；`E#` 送达设计；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验证据保存义务和非法获取计算机信息系统数据的禁止；`search_template` 只借通知栏目。不虚构案件系统。

工具不可用时继续事实、主体、程序文书状态和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [保存通知方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　保存闸

确有易失载体和大致时段才能打开闸。

### 节点 2　收件人与时段

场所经营者、物业、承运人、车队。

### 节点 3　通知正文

只要求保存，不承认不确定责任，不威胁。

### 节点 4　送达设计

转介送达专项或在此做最小设计。

### 节点 5　与法院保全关系

通知失败或拒不保存，升级评估保全必要性。

## 停止与安全

- `整体停止`：立场不明；用户要求侵入系统或收买监控员私下拷贝。
- `字段停止`：保存义务规范、送达中断时效效果未核验。
- `目标停止`：主目标变为法院保全申请或索赔通知正文。
