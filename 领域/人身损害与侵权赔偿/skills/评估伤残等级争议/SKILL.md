# 评估伤残等级争议

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，对已存在的多份民事人体损伤致残鉴定意见形成 `Gde#` 比较矩阵：标准名称、版本、施行日待核，条款描述差异，检材与稳定时点，委托程序与质证，采信分流与重新鉴定必要性接口。不自行宣布新等级。不取两份等级平均值。不预先采信对用户有利的一份。冲突本身不当然重新鉴定。单方委托不是当然无效。法院委托不是当然采信。不把人身损害赔偿解释当评残标准。不写异议文书终稿、首次鉴定申请、测算、诉状或庭审质证终稿。

`depends-on` 为空。异议稿转 `提出伤残鉴定异议或重新鉴定`（可并行）。尚未委托转 `准备伤残鉴定材料`。参与度转 `评估因果关系与既往伤病`。金额转 `测算人身损害赔偿`。质证提纲转 `准备人身损害庭审`。

## 工作边界

正触发：双方或多份鉴定结论、条款或标准冲突，或对国家标准、行业标准适用有争议，需要比较而非出具新等级。用户要「采信己方鉴定」「两份取平均」「必须某级」「单方鉴定无效」「冲突所以必须重鉴」仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关。两份意见同时存在且用户还要给法院的异议稿：本窗正触发，异议窗并行，本窗不写异议终稿。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚无任何民事致残意见，只要首次申请（转 `准备伤残鉴定材料`）；
- 只要异议或重新鉴定文书终稿且无比较需求（转 `提出伤残鉴定异议或重新鉴定`）；
- 只要测算或残疾额（转 `测算人身损害赔偿`）；
- 只要起诉状（转 `提起人身损害一审`）；
- 只要庭审质证或询问提纲终稿（转 `准备人身损害庭审`）；
- 医疗损害责任程度分级主轴（转医疗）；
- 劳动能力鉴定或工伤待遇主轴（转劳动）；
- 人体损伤程度（轻伤、重伤）当伤残主轴（说明不是本窗）；
- C 端只要大众准备包（只分流）；
- 未成争改合同（审查起草搁置）。

「宣布某级」「必须九级」不在负触发表。

## 建立工作坐标

确认：使用者与授权；单方立场；每份鉴定的标准名称、版本、施行日线索、条款、等级、检查日；委托类型（协商共同、诉前单方、法院委托）；是否诉讼内；检材序列；质证状态；法域。

口头「已是九级」「单方无效」「取平均」只登记 `S#`。

同时掌握双方秘密或受害人与侵权人、保险人各持一份鉴定同时交材料：`整体停止`，不得以选边治愈，也不得改走负触发去出比较表。提出伪造或裁剪影像、隐瞒完整序列、按索赔或拒赔口径改诊断、威胁或收买鉴定人、倒签：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 多份鉴定、病历、影像；`R#` 法院委托文书；`L#` 运行时已核验规则或标准；`I#` 判断；`G#` 缺口；`Gde#` 比较行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。接口状态只用 `打开`、`不打开`、`待核`。技能正文中的条号和标准名是检索锚点，不是已核验 `L#`。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：两院三部《人体损伤致残程度分级》名称、版本、施行日待核；多部位晋级规则须按所用标准运行时核验；2019 年修正民事诉讼证据规定鉴定意见质证、第四十条重新鉴定事由、第四十一条单方委托意见反驳并申请鉴定不是重新鉴定。不可用则标准符合性、晋级、质证法律效果、重鉴开闭字段停止。噪声：已废止 GB 18667-2002、工伤劳鉴标准当民事评残、人体损伤程度当伤残、已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文。禁止把人身损害赔偿解释条款当作评残标准写入 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变标准开闭或质证效果的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补单方委托不等于无效、多份鉴定不得平均、冲突不等于必须重鉴、不得未质证即采信己方的实务反例。

工具不可用时继续编目鉴定与检材差异；法律效果字段停止。不得凭记忆宣布某级、平均值或必须重鉴。

## 判断节点

执行顺序和停止条件以 [等级争议方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场与不关窗

劳鉴、医疗分级、无鉴定转出。错误主张不关窗。双方秘密或伪造提出即停。

### 2. 鉴定清单

每份单独登记。不预先采信对用户有利的一份。不宣布哪份已采信。

### 3. 标准适用

施行日待核。废止道路标准不得当现行。不得自行晋级。人体损伤程度不是伤残。

### 4. 检材、时点与程序

治疗未稳定定残是攻击点，不等于本窗宣布新等级。单方委托不是当然无效。法院委托不是当然采信。

### 5. 重鉴接口与测算接口

冲突不当然重新鉴定。文书闸转异议窗。等级未闭合则残疾赔偿金无法估计。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；提出伪造或裁剪影像、隐瞒完整序列、改诊断、威胁或收买鉴定人、倒签。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。
- `字段停止`：标准名称、版本、施行日、晋级规则、质证规则未核验。用户要采信己方、平均等级、必须某级、单方无效或冲突必须重鉴则该格停止，窗口不关。
- `目标停止`：主目标变为首次鉴定申请、异议文书终稿、测算、诉状、庭审、医疗或劳鉴。自行定级不在目标停止。

禁止指导伪造影像或威胁鉴定人。不给胜诉率。不选定法院。不保证必得。不代提交。本窗不定残。
