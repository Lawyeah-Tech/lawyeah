# 边界与路由

## 正触发

双方或多份鉴定结论、条款或标准冲突，或对国家标准、行业标准适用有争议，需要比较而非出具新等级。用户要「采信己方鉴定」「两份取平均」「必须某级」「单方鉴定无效」「冲突所以必须重鉴」仍正触发。两份意见同时存在且用户还要给法院的异议稿，仍正触发，异议窗并行。

双方秘密、伪造影像、隐瞒完整序列或威胁鉴定人的停止，优先于负触发。不得改走负触发去出比较表。宣布某级不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 首次鉴定申请 | `准备伤残鉴定材料` |
| 只要异议或重新鉴定文书终稿且无比较需求 | `提出伤残鉴定异议或重新鉴定` |
| 测算或残疾额 | `测算人身损害赔偿` |
| 起诉状 | `提起人身损害一审` |
| 庭审质证或询问提纲终稿 | `准备人身损害庭审` |
| 医疗损害责任程度分级 | 医疗医药领域 |
| 劳动能力鉴定或工伤待遇 | 劳动领域 |
| 人体损伤程度当伤残主轴 | 说明不是本窗 |
| C 端只要大众准备包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「帮我写成九级」不在本表。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动能力鉴定主轴 | 劳动领域 |
| 医疗损害责任程度 | 医疗医药领域 |

## 必转介接口

| 信号 | 转介 |
| --- | --- |

| 出庭质证终稿 | `准备人身损害庭审` |

## 易混

「两份鉴定一个十级一个九级怎么评」正触发。「帮我写成九级」正触发，定级格停止。「对这份鉴定提异议」走异议原子；若同时要比对则并行。「还没鉴定帮我申请」走准备材料。「所以赔多少」走测算。「单方的不算数」正触发，单方无效格不支持或待核。「打架了必须重做」正触发，必须重鉴格不支持或待核。「两级平均算九级」正触发，平均格不支持。「把对方影像裁了只留有利的」第一次提出即整体停止。
