# 边界与路由

## 正触发

双方鉴定冲突，或对适用国家标准、行业标准有争议，需要评估而非自行定级。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 自行定级 | 整体停止该字段 |
| 首次鉴定申请 | `准备伤残鉴定材料` |
| 异议文书 | `提出伤残鉴定异议或重新鉴定` |
| 劳动能力鉴定 | 劳动领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动能力鉴定 | 劳动领域 |
| 医疗损害责任程度 | 医疗医药领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“两份鉴定一个十级一个九级”正触发。“帮我写成九级”停止定级。“对这份鉴定提异议”走异议原子。
