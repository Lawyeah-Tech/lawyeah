# 等级争议方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。接口状态只用 `打开`、`不打开`、`待核`。禁止胜诉率、必然采信、唯一必得总额、选定法院、自行宣布伤残等级。未知金额不写零。

技能正文和本文件中的条号、标准名是检索锚点，不是已核验 `L#`。`search_law` 返回已废止 GB 18667-2002《道路交通事故受伤人员伤残评定》、职工工伤劳动能力鉴定标准当民事评残、《人体损伤程度鉴定标准》当伤残、已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文，或把人身损害赔偿解释条款当作评残标准时记为噪声，不得写入 `L#`。禁止把两份等级平均值写成法律结论。

`Gde#` 固定列：`编号｜意见书文号｜委托类型（协商共同/诉前单方/法院委托）｜标准名称版本施行日（待核）｜条款号｜结论等级摘录｜检材与检查日｜程序与质证状态｜主张分型（采信该份/不采信该份/第四十一条申请法院鉴定/第四十条重鉴接口）｜主张人｜证明负担方｜判断｜待核`。一行一份意见的一个主张。禁止合成「采信对用户有利的一份」或「冲突所以必须重做」。

## 节点 0　分流、立场与不关窗

整案转出只交付第 1、2、10 节。

| 信号 | 处理 |
| --- | --- |
| 医疗损害责任程度分级主轴 | 转医疗 |
| 劳动能力鉴定或工伤待遇主轴且无民事评残争点 | 转劳动；夹带劳鉴只分流，不得用劳鉴等级完成本窗民事终稿 |
| 海事专门鉴定 | 转海事 |
| 未成争只要改合同 | 审查起草本窗搁置 |
| 尚无任何民事致残意见、只要首次申请 | 负触发 `准备伤残鉴定材料` |

「采信己方鉴定」「两份取平均」「必须某级」「单方鉴定无效」「冲突所以必须重鉴」**不关窗**。

本窗**永不**出具异议书终稿。用户同时要异议稿：本窗比较矩阵与异议窗并行。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出伪造或裁剪影像、隐瞒完整序列、按索赔或拒赔口径改诊断、威胁或收买鉴定人、倒签或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　证明负担与并列登记

鉴定意见须出示、质证。未经质证不得作为认定事实的根据。两份意见并列登记。不预先采信对用户有利的一份，也不宣布哪份已采信。口头「已读」、截图、出具日不等于已质证、已送达。

| 主张分型 | 通常主张人 | 最低表面 | 禁止写法 |
| --- | --- | --- | --- |
| 应采信意见 A | 引用该意见主张残疾系数的一方 | 标准已公开条款号与意见书页码如何对应；检材页码或日期；检查时点与治疗稳定线索；委托程序与检材是否经质证 | 有利即采信；未质证即认定；本窗宣布已采信 |
| 不应采信意见 B | 攻击该意见的一方 | 质证攻击点逐点对应：条款与检材不符页码、序列不完整、检查日未稳定、超范围、资质、回避、签字 | 「我觉得不公」；冲突即无效；隐瞒完整序列后只打有利切片 |
| 对单方意见反驳并申请法院鉴定 | 反驳单方委托的一方 | 证据规定第四十一条：有证据或理由足以反驳并申请人民法院委托鉴定。本窗只标接口，转 `准备伤残鉴定材料` | 写成第四十条重新鉴定；本窗改级；单方意见当然作废 |
| 对法院委托意见申请重新鉴定 | 主张重鉴的一方 | 第四十条事由逐项待核。可补正或补充鉴定或补充质证的，接口不打开。文书闸转 `提出伤残鉴定异议或重新鉴定` | 两份冲突当然打开重鉴；本窗写异议终稿或「应当准许」 |
| 标准用错 | 主张不应当适用该标准的一方 | 标准名称、版本、施行日、鉴定日 | 因事故日早于 2017-01-01 即选用废止道路标准；轻伤当伤残；劳鉴十级打民事九级 |

不能因对方控制病历或影像推定序列完整或内容有利于任一方。未提交记 `G#`。

单方委托证明力风险分列，不是当然无效。法院委托不是当然采信。用户要单方鉴定无效：该格 `现有依据不支持` 或待核，窗口不关。

## 节点 2　标准适用

先比标准，再比检材和检查时点，再比程序。鉴定日在《人体损伤致残程度分级》施行日及以后的，民事人体损伤致残鉴定原则上适用该分级；不得因事故日较早即选用已废止 GB 18667-2002。标准名称、版本、施行日未核验则符合性字段停止。

条款符合性只指出描述差异，不宣布新等级。用户要必须某级或采信己方：该格 `现有依据不支持` 或待核，窗口不关。

多个部位：晋级规则须核验所用标准，未核验晋级字段停止，不得自行晋级。不得用工伤劳鉴晋级规则完成本窗民事终稿。人体损伤程度（轻微伤、轻伤、重伤）不是伤残。

---

## 节点 3　检材与时点

影像序列是否完整、是否遗漏手术记录。治疗未稳定即定残是常见攻击点，不等于本窗宣布新等级。两份检查间隔中病情变化：标介入因素，转介 `评估因果关系与既往伤病`。不作读片诊断。

---

## 节点 4　重新鉴定分流

冲突本身不当然导致重新鉴定。用户要冲突必须重鉴：该格 `现有依据不支持` 或待核，窗口不关。是否打开第四十条接口转异议窗逐项核验。本窗只标 `打开`、`不打开` 或 `待核`。不制作异议书终稿。

---

## 节点 5　对测算的接口

不得取两份等级平均值当作法律结论。用户要平均等级：该格 `现有依据不支持`，窗口不关。不输出唯一必得系数。等级未闭合则残疾赔偿金标无法估计，转 `测算人身损害赔偿`。2022 年后城乡统一不影响等级条款本身，测算转介精算原子。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过节点 0 直接宣布采信己方或新等级。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if 金额参数不足，then 该行标未知，禁止写零。
若 if C 端只要大众准备包，then 只分流不回改。

判断状态只许三值。

## 本任务回链纪律

本任务成果是「伤残等级争议比较矩阵与分流」。不包含：自行定级、异议文书终稿、首次鉴定申请、测算、诉状、庭审质证终稿、劳鉴或医疗分级。禁止平均值。禁止单方当然无效。禁止冲突必须重鉴。禁止未质证即采信己方。禁止废止道路标准或工伤标准当现行民事评残。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接。
