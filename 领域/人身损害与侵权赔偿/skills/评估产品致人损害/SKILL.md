# 评估产品致人损害

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的权利人或生产者、销售者立场下，形成缺陷产品致人身损害路径：缺陷候选（制造、设计、警示）、生产者与销售者对外请求路径、召回与惩罚性接口、质量鉴定与伤残鉴定分流。不预测鉴定，不定伤残，不选定法院，不保证必得，不把一切伤害写成缺陷，不把消法价款三倍与人身惩罚性加总。

`depends-on` 为空。惩罚性倍数终稿转 `评估产品惩罚性赔偿`。择一比较转 `选择人身损害违约侵权竞合路径`。纯合同质量价款转合同争议。

## 工作边界

正触发：产品使用中发生人身损害，需要判断缺陷候选、生产者或销售者对外路径、召回与惩罚性接口或鉴定分流。用户要「受伤即缺陷」或「价款三倍加人身惩罚性必得」仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 无人身伤害的纯质量价款、修理更换退货（转合同争议）；
- 诊疗过错或医疗损害鉴定主轴（转医疗医药）；
- 只要惩罚性赔偿倍数终稿（转 `评估产品惩罚性赔偿`）；
- 只要违约侵权择一终稿（转 `选择人身损害违约侵权竞合路径`）；
- 只要总体责任总图（转 `评估人身侵权责任`）；
- 只要主体名单终稿（转 `评估责任主体与保险覆盖`）；
- 只要测算或伤残（转 `测算人身损害赔偿` 或 `准备伤残鉴定材料`）；
- 只要起诉状（转 `提起人身损害一审`）；
- 只要唯一时效截止日（转 `评估人身损害诉讼时效`）；
- 未成争改买卖条款（审查起草搁置）。

药品、医疗器械因诊疗使用导致的损害鉴定主轴转医疗；作为流通物的出厂缺陷可留本窗，产品缺陷只作并行红旗，不写医疗终稿。监管处罚决定不是本成果。

## 建立工作坐标

确认：使用者与授权；单方立场；产品名称、批次、序列号；生产者、销售者、平台是否自营；缺陷表现候选；人身损害；召回信息；是否食品药品；是否自行改装或过期使用；法域。

网购截图、口述发票不得写成原件或已成立买卖。召回公告不是缺陷终局。

同时掌握双方秘密或受害人与生产者、销售者利益冲突未解：`整体停止`，不得以选边治愈，也不得改走负触发去出路径。提出倒签购买凭证、伪造批次、隐瞒改装或伪造伤情：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 发票、包装、批次表面；`R#` 召回公告、鉴定；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。接口状态只用 `打开`、`不打开`、`待核`。技能正文中的条号是检索锚点，不是已核验 `L#`。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验民法典第一千二百零二条至第一千二百零七条、产品质量法缺陷定义与抗辩、销售者不能指明生产者等将被写入 `L#` 的现行规则；不可用则缺陷是否成立、对外请求、追偿终局和惩罚性开闭字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变缺陷定义、对外路径或惩罚性接口的条文正文再写入 `L#`。不得编造 `regulation_id`，也不得把摘要条号写成已核验 `L#`。
- `search_practiced` 补制造设计警示分列、平台地位、不能指明生产者、召回公告证明力的实务反例。

工具不可用时继续产品批次、主体名称变体、损害事实和召回公告编目；法律效果字段停止。已失效《侵权责任法》第四十一条至第四十七条、已失效《合同法》质量条款不得默写为现行 `L#`。

## 判断节点

执行顺序和停止条件以 [产品致害方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场与禁止事项

诊疗主轴转医疗。双方秘密或倒签凭证提出即停。药品器械流通缺陷可留窗。

### 2. 缺陷候选与因果

伤害不等于缺陷。制造、设计、警示只建候选。不预测鉴定。三抗辩由主张免责方举证待核。

### 3. 生产者、销售者对外路径

可向生产者或销售者请求，不是必须同时告两边，不是第一千一百六十八条连带。平台不是当然生产者。

### 4. 召回、惩罚性与竞合接口

未召回不等于明知。三倍与第一千二百零七条分列，禁止加总。择一比较转竞合窗。

### 5. 鉴定分流与下一步

质量鉴定不是起诉前置。实物保全优先于拆机。不定伤残，不选定法院。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；提出倒签购买凭证、伪造批次、隐瞒改装、伪造伤情或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。
- `字段停止`：缺陷定义、对外请求条件、不能指明生产者、平台地位、三抗辩或惩罚性明知未核验。用户要伤害即缺陷、平台当然连带或三倍加人身惩罚性必得则该格停止，窗口不关。
- `目标停止`：主目标变为纯合同质量诉讼、医疗损害鉴定、惩罚性倍数终稿、竞合比较表、测算或起诉状。

禁止指导倒签发票、隐瞒改装、伪造批次或破坏检材。不给胜诉率。不选定法院。不保证必得。
