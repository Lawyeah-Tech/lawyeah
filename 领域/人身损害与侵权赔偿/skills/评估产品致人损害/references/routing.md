# 边界与路由

## 正触发

缺陷产品造成人身损害，需要判断生产者、销售者路径及召回、惩罚性、鉴定分流。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 纯合同质量 | 合同争议领域 |
| 药品器械诊疗主轴 | 医疗医药领域 |
| 惩罚性专项终稿 | `评估产品惩罚性赔偿` |
| 未成争审查起草 | 本窗搁置 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 诊疗过错、医疗损害鉴定 | 医疗医药领域 |
| 生产一线职工工伤 | 劳动领域 |
| 海上货损人身 | 海事领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“热水袋爆炸烫伤”正触发。“药吃错是医生的问题”转医疗。“只想退货退款无受伤”转合同争议。
