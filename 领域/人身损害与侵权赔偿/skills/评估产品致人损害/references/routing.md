# 边界与路由

## 正触发

产品使用中发生人身损害，需要判断缺陷候选、生产者或销售者对外路径、召回与惩罚性接口或鉴定分流。用户要「受伤即缺陷」「平台当然连带」或「三倍加人身惩罚性必得」仍正触发。

双方秘密、倒签购买凭证、伪造批次、隐瞒改装或违法取证的停止，优先于负触发。不得改走负触发去出路径或退货策略。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 纯合同质量价款、修理更换退货 | 合同争议领域 |
| 诊疗过错或医疗损害鉴定主轴 | 医疗医药领域 |
| 惩罚性倍数终稿 | `评估产品惩罚性赔偿` |
| 违约侵权择一终稿 | `选择人身损害违约侵权竞合路径` |
| 总体责任总图 | `评估人身侵权责任` |
| 主体名单终稿 | `评估责任主体与保险覆盖` |
| 测算或伤残 | `测算人身损害赔偿` / `准备伤残鉴定材料` |
| 起诉状 | `提起人身损害一审` |
| 唯一时效截止日 | `评估人身损害诉讼时效` |
| 未成争审查起草 | 本窗搁置 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 诊疗过错、医疗损害鉴定 | 医疗医药领域；流通缺陷只留红旗 |
| 生产一线职工工伤 | 劳动领域 |
| 海上货损人身 | 海事领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

「热水袋爆炸烫伤」正触发。「只想退货退款无受伤」转合同争议。「药吃错是医生操作问题」转医疗；药本身是假劣药可留本窗红旗。「立刻告平台连带并按三倍加人身惩罚性算必得」仍正触发，连带格与加总格现有依据不支持。「必须先做质量鉴定才能立案」该格现有依据不支持。「倒签订单赶上召回」第一次提出即整体停止。
