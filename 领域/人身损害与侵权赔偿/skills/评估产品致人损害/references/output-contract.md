# 输出合同

按触发结果选择交付形状。禁止伤害即缺陷。禁止把价款三倍与人身惩罚性加总。禁止把生产者与销售者写成必须同时告或真正连带。禁止预测鉴定结论。禁止选定法院、伤残等级、必得总额。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出（工伤待遇或劳鉴主轴；诊疗过错或医疗损害鉴定主轴；海事；未成争改买卖合同） | 第 1、2、10 节。禁止缺陷成立结论、对外请求策略、惩罚性倍数、鉴定预测 |
| 整体停止 | 第 1、10 节。禁止请求、抗辩、金额、选边方案。双方秘密、倒签购买凭证、伪造批次、隐瞒改装或违法取证时，整体停止优先于负触发；第一次提出即停，无选边治愈，无「坚持」门槛 |
| 用户要「一切伤害即缺陷」或「三倍加人身惩罚性必得」或「平台当然连带」（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；不得改走负触发关窗；成果不得标 `已形成` |
| 正触发且可评估 | 下列十节表头均出现；缺陷定义、对外路径、追偿终局、平台地位、召回效果、惩罚性开闭、鉴定分流未核验的单元格填 `依据不足，无法形成结论` 或 `待核`；禁止为填满而编造缺陷、倍数、伤残或必得额 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。双方秘密未解不得进入「部分形成」。每个 `Q#` 必须带判断三值和证明负担方。

## 1. 触发、单方立场、授权与成果状态

是否存在人身损害。双方秘密未解不得进入「部分形成」。

## 2. 来源登记与 MCP 调用表

批次、发票、召回公告、截图分列。截图不得写成原件。`L#` 不得直接抄技能内条号。MCP 未调用也留一行。

## 3. 产品与医疗、合同、工伤分流

诊疗主轴转出，流通缺陷可留并行红旗。监管处罚不是本成果。车辆部件交强险转介交通专项。

## 4. 缺陷与因果候选

伤害不等于缺陷。制造、设计、警示分列候选。两肢与三抗辩待核。不预测鉴定。对方控制实物不得推定缺陷内容。

## 5. 生产者、销售者对外路径

可向生产者或销售者请求，不是必须同时告两边。追偿另列。不能指明生产者待核。平台默认不是生产者。运输仓储不阻断对外。

## 6. 召回与惩罚性接口

未召回不等于明知。第一千二百零七条只标打开或不打开。消法三倍、食安十倍与人身惩罚性分列，禁止加总。不写倍数终稿。

## 7. 合同竞合红旗

只标打开。比较表转竞合窗。禁止同一相对方双份全额。

## 8. 鉴定分流

质量鉴定不是起诉前置。质量鉴定与伤残鉴定分开。闸关不得转介启动评残。实物保全优先于拆机。

## 9. 下一步

转介发函、保全实物、测算或起诉。不定伤残。不选定法院。时效与质量异议分列，截止日停止。

## 10. 缺口、停止项与提示

须列对方最强解释（受伤即缺陷、改装可瞒、召回公告即终局、销售者不能指明仍免责、平台当然连带或当然免责、必须两边都告、先鉴定才能立案、三倍加 1207 双份惩罚必得、异议期满不能告产品责任、选边即可继续）与证据缺口。

本成果不是缺陷鉴定书、不是惩罚性倍数、不是诉状、不是评残、不是必得总额。
