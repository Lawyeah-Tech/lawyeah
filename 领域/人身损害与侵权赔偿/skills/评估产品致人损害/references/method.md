# 产品致害方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。接口状态只用 `打开`、`不打开`、`待核`。禁止胜诉率、唯一责任比例、限额内必得、选定法院、伤残等级。未知金额不写零。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》第四十一条至第四十七条、2003 年人身损害赔偿解释已删除条文、已失效《合同法》质量检验异议条款或合同法解释（一）第三十条时记为噪声，不得写入 `L#`。2001 年民事证据规定第四条第六项不得写成受害人无需证明缺陷与因果。不得把一切伤害写成缺陷。不得把消法价款三倍与第一千二百零七条加总。不得把生产者与销售者写成第一千一百六十八条真正连带。

`Q#` 固定列：`编号｜角色｜对外或对内｜请求权基础｜缺陷候选｜抗辩或追偿｜证明负担方｜期间类型｜判断｜待核`。一行一主体。生产者、销售者、平台、运输仓储者不得合成「厂家一方」。

## 节点 0　分流、立场与禁止事项

整案转出只交付第 1、2、10 节。

| 信号 | 处理 |
| --- | --- |
| 诊疗过错、病历真实性或医疗损害鉴定主轴 | 转医疗；产品缺陷仅作并行红旗，不写医疗终稿 |
| 工伤待遇或劳动能力鉴定主轴 | 转劳动 |
| 海上货损人身 | 转海事 |
| 未成争只要改买卖条款或出稿 | 审查起草本窗搁置 |

药品、医疗器械作为流通物的出厂缺陷可留本窗。监管处罚、召回行政决定不是本成果。负触发不得写成「凡药品器械即转医疗」。

纯质量无人身、只要惩罚性终稿、只要竞合比较表、只要总图或主体名单、只要测算诉状或唯一截止日：负触发至对应原子。

车辆部件缺陷致交通事故：本窗可留产品路径；交强险先行转 `评估道路交通事故责任与保险先行`，不得吞分账。

「受伤即缺陷」「平台当然连带」「价款三倍加人身惩罚性必得」「必须同时告两边」「先鉴定才能起诉」**不关窗**。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密且未获冲突豁免，then 整体停止，不得选边治愈。
若 if 提出倒签购买凭证、伪造批次或合格证、隐瞒改装、调包送检、伪造伤情或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　缺陷候选、因果与鉴定禁令

检索锚点《产品质量法》第四十六条：缺陷指存在危及人身、他人财产安全的不合理危险；产品有保障人体健康和人身、财产安全的国家标准、行业标准的，是指不符合该标准。两肢分列待核。符合国标不等于当然无不合理危险。

检索锚点民法典第一千二百零二条：因产品存在缺陷造成他人损害的，生产者应当承担侵权责任。无过错以**缺陷已证**为前提，不是伤害即无过错全责。

爆炸、烫伤、断裂只建制造、设计、警示候选。使用不当、过期、自行改装标不利事实，不写成当然免责结论，原因力转 `评估过错与原因力`。既往伤病转 `评估因果关系与既往伤病`。

生产者免责三抗辩检索锚点《产品质量法》第四十一条：未将产品投入流通；投入流通时引起损害的缺陷尚不存在；当时科学技术水平尚不能发现缺陷。主张免责的生产者举证，待核。不得把三抗辩写成受害人必须先排除的起诉条件。

主张产品责任的一方就产品同一性、缺陷候选、损害、因果建档。生产者无过错不等于受害人无需任何证据。是否转移证明负担运行时核验，禁止默写法定整案倒置。食品药品「初步证明后质量问题举证」仅食品药品待核，禁止默用于普通工业品。

质量鉴定不是起诉前置。不预测缺陷鉴定结论，不定伤残等级。质量鉴定与人体损伤鉴定分列。鉴定闸未开不得转介启动评残。实物、包装、批次、说明书保全**优先于拆机送检**。对方控制仓库不得推定同批次必然缺陷。禁止指导破坏性拆解或调包送检。

召回公告、行政处罚不是缺陷终局，只作 `R#`。

## 节点 2　生产者、销售者对外路径与对内追偿

检索锚点民法典第一千二百零三条：被侵权人可以向生产者请求赔偿，也可以向销售者请求赔偿。不是必须同时告两边才成立。对外选择请求不是第一千一百六十八条真正连带。用户要写成 1168 连带或必须两边都告：该格 `现有依据不支持`，窗口不关。

销售者赔偿后，属于生产者责任的，销售者有权向生产者追偿。因销售者过错使产品存在缺陷的，生产者赔偿后有权向销售者追偿。追偿另列，不阻断受害人对外请求。

销售者不能指明生产者**或**供货者：对外仍可被请求；能否终局核验《产品质量法》第四十二条第二款，未核验字段停止。能指明则对内追偿，不阻断对外选择。发票缺失不等于当然终局。

运输者、仓储者等第三人因过错使产品存在缺陷：检索锚点第一千二百零四条，生产者、销售者赔偿后追偿；一般不阻断对外请求，不得写成未列运输者就不能告厂家。

网络平台默认不是生产者。自营才进入销售者格。非自营：检索锚点消费者权益保护法第四十四条、电子商务法第三十八条，未核验不得写当然连带、当然生产者或当然免责。网购截图不等于发票原件，不等于平台自营终局。

社会团体或中介机构承诺保证：另列待核，本窗不写当然连带终稿。

排除妨碍、消除危险检索锚点第一千二百零五条，缺陷危及人身财产安全即可打开接口，不要求已发生全部损害，不另造一套赔偿总额。

解释（一）第十九条产品自损可与其他财产损害一并依 1202、1203 主张：只标接口，本窗主成果仍是人身损害。

## 节点 3　召回、惩罚性与竞合接口

检索锚点第一千二百零六条：缺陷投入流通后发现的，生产者、销售者应当及时采取停止销售、警示、召回等补救措施；未及时采取或补救不力造成损害扩大的，对扩大损害承担责任。违反召回可作缺陷或过错证据，不单独写成另一套总额。未召回不等于第一千二百零七条明知。

第一千二百零七条明知缺陷仍然生产、销售，或未有效补救，造成死亡或健康严重损害：只标 `打开`／`不打开`／`待核`，倍数终稿转 `评估产品惩罚性赔偿`。

消费者权益保护法第五十五条第一款价款三倍、第二款损失二倍以下、食品安全法第一百四十八条十倍价款或三倍损失，与 1207 分列。禁止加总为双份惩罚。非食品不得套十倍。本窗不写倍数、不写惩罚性必得。用户要三倍加人身惩罚性必得：加总格 `现有依据不支持`，窗口不关。

有人身可标竞合红旗，比较终稿转 `选择人身损害违约侵权竞合路径`。修理更换退货与侵权人身项目禁止对同一相对方双份全额。本窗不锁定主备位。

## 节点 4　期间、管辖类型与输出纪律

产品责任诉讼时效与买卖质量异议期间**分列**。检索锚点《产品质量法》第四十五条（二年及交付最初消费者十年、安全使用期例外）与民法典第一百八十八条并行情景。检验异议期间检索锚点合同编第六百二十一条，只约束合同质量主张，不当然消灭产品责任请求。截止日字段停止，展开转 `评估人身损害诉讼时效`。禁止唯一届满日。

管辖只列制造地、销售地、侵权行为地、被告住所地等**类型**，转 `评估人身损害管辖`。住院地默认不打开。不选定法院。不写起诉状或追偿状。

金额不足标未知，禁止写零。C 端只要大众包：只分流。
