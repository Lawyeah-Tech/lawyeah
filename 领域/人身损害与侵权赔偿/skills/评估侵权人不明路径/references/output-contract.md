# 输出合同

按触发结果选择交付形状。禁止编造被告。禁止保证找到侵权人。禁止全体业主连带。禁止补偿即全额连带。禁止用 1170 告全楼。禁止救助基金必得全残。禁止监控未拍到即全楼赔。禁止告交警队。禁止「无名氏一定能立案」或「不明一律不能起诉」。禁止选定法院、必得总额。禁止指导跟踪、闯入、人肉搜索。本窗不定罪。不写起诉状。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出（工伤待遇或劳鉴主轴；诊疗过错主轴；海事不明船；未成争改合同） | 第 1、2、10 节。禁止路径成立结论、全楼名单、基金必得 |
| 整体停止 | 第 1、10 节。禁止请求、抗辩、金额、选边方案、被告清单、取证步骤、诉状。双方秘密、伪造车牌或楼层或姓名、跟踪闯入收买监控室、人肉搜索或伪造伤情时，整体停止优先于负触发；第一次提出即停，无选边治愈，无「坚持」门槛 |
| 用户要「全楼连带必得」或「救助基金必得全残」或「监控没拍到所以全楼赔」或「必须找到人才能起诉」或「编一个被告就能立案」且未提交伪造身份（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；不得改走负触发关窗去出诉状；成果不得标 `已形成` |
| 正触发且可评估 | 下列十节表头均出现；分型、基金条件、1254 接口、民诉被告条件未核验的单元格填 `依据不足，无法形成结论` 或 `待核`；禁止为填满而编造被告、保证找到人或必得额 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。双方秘密未解不得进入「部分形成」。每个 `Q#` 必须带判断三值和证明负担方。`L#` 不得直接抄技能内条号。

## 1. 触发、单方立场、授权与成果状态

不明类型。双方秘密未解不得进入「部分形成」。

## 2. 来源登记与 MCP 调用表

报警、事故证明分列。口述某车某户、监控一定拍到只登记 `S#`。MCP 未调用也留一行。侵权责任法第八十七条、2003 解释第四条、交强险十一万若返回则记噪声。

## 3. 分型与禁止编造

车辆不明逃逸、车已查明人逃逸、抛物不明、其他不明分列。猜测姓名不得作被告。

## 4. 机动车逃逸接口

保险人路径或救助基金只标开闭。不保证拨付。不写申请表。全残必得格填 `现有依据不支持`。禁止告交警队。已废止十一万或一万不得当必得。

## 5. 抛物与其他不明接口

1254 补偿与物业只标接口，终稿转物件窗。公安调查义务必列。全体业主连带格、1170 告全楼格填 `现有依据不支持`。补偿不是全额。

## 6. 合法查明手段

报警、保存通知、调查令、公证只转介。不办调取。不能因控制方推定监控有利。禁止跟踪、闯入、人肉。

## 7. 诉讼入口红旗

明确被告条件待核。禁止无名氏一定能立案。禁止不明一律驳回。本窗不写起诉状。不选定法院。

## 8. 邻接红旗与追加

1170、1198、1201、交通分账、物件 1254：打开、不打开或待核。查明后转 `追加变更责任主体`，不写追加申请终稿。

## 9. 下一步

转介保存通知、基金申请、物件窗、交通专项、追加、先予执行医疗费。监控覆盖周期优先。不明不等于时效不走。不写唯一截止日。住院地不得必有权。

## 10. 缺口、停止项与提示

须列对方最强解释（编一个车牌就能立案、全楼连带必得、1170 告全楼、救助基金必得全残、监控没拍到所以全楼赔、已删即物业全责、必须找到人才能起诉、不明一律不能立案、可以告交警队、交强险十一万必得、选边即可继续）与证据缺口。

不保证找到侵权人。本成果不是起诉状、不是基金申请终稿、不是 1254 终稿、不是必得总额。
