# 边界与路由

## 正触发

肇事逃逸、高空抛物人或侵权人暂时不明，权利人需要可执行的查明和过渡救济路径。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 编造被告起诉 | 整体停止 |
| 救助基金申请终稿 | `申请道路救助基金或垫付` |
| 高空抛物责任展开 | `评估物件脱落坠落与高空抛物` |
| 交通保险分账 | `评估道路交通事故责任与保险先行` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 刑事逃逸或抛物犯罪 | 刑事领域 |
| 工伤第三人不明 | 劳动领域并行 |
| 海事碰撞不明船 | 海事领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“车跑了人也不知道是谁”正触发。“已经知道是哪辆车”走交通专项。“只要填救助基金表”走申请专项。
