# 边界与路由

## 正触发

肇事逃逸、高空抛物人或侵权人暂时不明，权利人需要可执行的查明和过渡救济路径。用户要「全楼连带必得」「救助基金必得全残」「监控没拍到所以全楼赔」「必须找到人才能起诉」「编一个被告就能立案」仍正触发。车辆已查明仅驾驶人逃逸，本窗仍可评持续查明与保险人接口。刑责线索而用户仍要民事查明，仍正触发。

双方秘密、伪造车牌或楼层或姓名、跟踪闯入或人肉搜索的停止，优先于负触发。不得改走负触发去出诉状或查明方案。编造被告不在下表。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 工伤待遇或劳动能力鉴定 | 劳动领域；民事不明路径可另开 |
| 诊疗过错 | 医疗医药领域 |
| 海事碰撞不明船 | 海事领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

「车跑了人也不知道是谁」正触发。「已经知道是哪辆车只要分账」走交通专项；驾驶人仍逃逸则保险人接口可留本窗。「只要填救助基金表」走申请专项。「不知道哪家扔的把全楼告了」仍正触发：连带格现有依据不支持，补偿展开转物件窗。「编个名字就能立案」未交伪造身份则不关窗，该格不支持或待核。「帮我填个假车牌当被告」第一次提出即整体停止。「监控没拍到所以全楼赔」不关窗，该格不支持。
