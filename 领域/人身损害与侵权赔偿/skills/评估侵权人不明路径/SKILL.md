# 评估侵权人不明路径

## 任务目标

在明确、无利益冲突的权利人立场下，形成侵权人不明路径表：逃逸机动车、抛物不明、其他不明行为人分列；交强险抢救垫付、道路救助基金、第一千二百五十四条查明与补偿、物业必要措施、合法查明手段、民诉明确被告条件一律只作接口。不编造被告。不保证找到侵权人。不把可能加害人补偿或全体业主写成连带必得。不把救助基金写成全残必得。不把监控未拍到写成全楼赔。不定罪。不写 1254 补偿终稿、救助基金申请终稿、交强险分账、1170、起诉状、监控调取或侦查。

`depends-on` 为空。1254 补偿终稿转 `评估物件脱落坠落与高空抛物`。基金申请转 `申请道路救助基金或垫付`。交强险分账转 `评估道路交通事故责任与保险先行`。1170 转 `评估共同侵权与连带按份`。诉状转 `提起人身损害一审`。

## 工作边界

正触发：肇事逃逸、高空抛物人或侵权人暂时不明，权利人需要可执行的查明和过渡救济路径。用户要「全楼连带必得」「救助基金必得全残」「监控没拍到所以全楼赔」「必须找到人才能起诉」「编一个被告就能立案」仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关。车辆已查明仅驾驶人逃逸：本窗可评保险人与持续查明接口是否打开，分账终稿仍转交通专项。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要总体责任总图（转 `评估人身侵权责任`）；
- 只要主体名单终稿（转 `评估责任主体与保险覆盖`）；
- 高空抛物责任或 1254 补偿展开终稿（转 `评估物件脱落坠落与高空抛物`）；
- 只要救助基金申请终稿（转 `申请道路救助基金或垫付`）；
- 交通保险分账终稿（转 `评估道路交通事故责任与保险先行`）；
- 只要 1170 或 1168–1172 形态终稿（转 `评估共同侵权与连带按份`）；
- 场所 1198 终稿（转 `评估场所安全保障义务`）；
- 教育机构 1199–1201 终稿（转 `评估教育机构责任`）；
- 只要测算或伤残（转 `测算人身损害赔偿` 或 `准备伤残鉴定材料`）；
- 只要起诉状（转 `提起人身损害一审`）；
- 只要监控保存通知发送稿（转 `准备监控保存通知`）；
- 只要调查令终稿（转 `申请人身案件调查令或取证`）；
- 只要选定法院（转 `评估人身损害管辖`）；
- 只要唯一时效截止日（转 `评估人身损害诉讼时效`）；
- 定罪、控告或侦查（转刑事或 `分流刑民交叉`）；
- C 端只要大众准备包（只分流）；
- 未成争改合同（审查起草搁置）。

编造被告、伪造车牌或楼层**不在负触发表**，走整体停止。全体业主连带、基金必得全残不在负触发表。

刑责只分流，民事查明不关窗。刑事逃逸或抛物犯罪不得整案踢出本窗。

## 建立工作坐标

确认：使用者与授权；权利人立场；分型（车辆不明逃逸、车已查明人逃逸、抛物不明、其他不明）；已报警或报案；车辆是否查明；交强险或救助基金线索；物业或道路管理人；监控控制方；抢救费是否已发生；法域。

口头「就是那辆车」「就是某层某户」「监控一定拍到」只登记 `S#`。猜测姓名不得写入可提交当事人栏。

同时掌握双方秘密或受害人与物业、可能加害人圈利益冲突未解：`整体停止`，不得以选边治愈，也不得改走负触发去出查明方案或诉状。提出伪造车牌、楼层、被告姓名、跟踪、闯入、收买监控室、人肉搜索、伪造伤情或违法取证：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 报警回执、监控申请表面；`R#` 事故证明、受案回执表面；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。接口状态只用 `打开`、`不打开`、`待核`。技能正文中的条号是检索锚点，不是已核验 `L#`。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：道路救助基金或交强险抢救垫付的开闭条件（通常限于抢救费用或丧葬费用，不是全残必得）；车辆已查明驾驶人逃逸时保险人路径接口；民诉明确被告条件（不保证可诉也不保证不可诉）；第一千二百五十四条公安调查义务只作接口。不可用则路径开闭、基金条件、立案条件字段停止。禁止把 1254 补偿、解释一第二十四条第二十五条、1170、道交法第七十六条分账写成**本窗** `L#` 终稿。已失效《侵权责任法》第八十七条、2003 年人身损害赔偿解释第四条、已废止交强险十一万或一万不得写入 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变基金开闭、保险人接口或立案条件的条文正文再写入 `L#`。不得编造 `regulation_id`，也不得把摘要条号写成已核验 `L#`。
- `search_practiced` 补不明被告立案实践差异、逃逸后对已查明车辆保险人索赔、救助基金不保证拨付、物业未保存监控不等于全楼连带的实务反例。

工具不可用时继续分型、报警、监控控制方、车辆是否查明、抢救费是否已发生编目；法律效果字段停止。不得凭记忆写编造被告可立案、全楼连带、基金必得或告交警队。

## 判断节点

执行顺序和停止条件以 [侵权人不明方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、分型与不关窗

先分逃逸、抛物、其他。双方秘密或伪造身份提出即停。错误主张不关窗。

### 2. 机动车逃逸接口

车辆不明走救助基金接口。车已查明人逃逸可能打开保险人路径。禁止告交警队当被告。

### 3. 抛物与其他不明接口

1254 补偿与物业只标接口。1170 不得告全楼。公安调查义务必列。

### 4. 合法查明手段

报警、保存通知、调查令、公证只转介。禁止违法取证。

### 5. 诉讼入口与追加

明确被告条件待核。查明后转追加。不写起诉状。不保证找到人。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；提出伪造车牌、楼层、被告姓名、跟踪、闯入、收买监控室、人肉搜索、伪造伤情或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。
- `字段停止`：救助基金条件、民诉被告条件、1254 接口未核验。用户要全楼连带、基金必得全残、监控未拍到即全楼赔、必须找到人才能起诉或编一个就能立案则该格停止，窗口不关。
- `目标停止`：主目标变为 1254 终稿、基金申请终稿、交强险分账、1170、起诉状、调取或侦查。

禁止指导编造被告或违法查明。不给胜诉率。不选定法院。不保证必得。不代申请、不代提交。
