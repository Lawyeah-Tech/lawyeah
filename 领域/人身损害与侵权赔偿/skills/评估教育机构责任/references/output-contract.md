# 输出合同

按触发结果选择交付形状。禁止在校即全责。禁止 1200 套 1199 推定。禁止把同学写成 1201 第三人连带。禁止补充改连带、补充即全额、与第三人同一执行顺序。禁止用 1186 各打五十替代。禁止写 1198/1188/1176/打架/处分/监护令终稿。禁止选定法院、伤残等级、必得总额。禁止指导伪造值班、威胁学生证人或违法调监控。禁止代提交。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出（教师工伤或劳鉴主轴；校医诊疗过错主轴；海事；未成争改招生托管合同） | 第 1、2、10 节。禁止路径成立结论、全责方案、补充比例、执行顺位终局 |
| 整体停止 | 第 1、10 节。禁止请求、抗辩、金额、选边方案、被告清单、取证步骤。双方秘密、伪造值班、威胁或利诱学生证人、编造监控、违法进校调监控或伪造伤情时，整体停止优先于负触发；第一次提出即停，无选边治愈，无「坚持」门槛 |
| 用户要「在校即全责」或「同学按 1201 第三人连带」或「补充改连带」（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；不得改走负触发关窗；成果不得标 `已形成` |
| 正触发且可评估 | 下列十节表头均出现；能力、期间、举证结构、补充范围、第十四条执行顺序未核验的单元格填 `依据不足，无法形成结论` 或 `待核`；禁止为填满而编造全责、1201 或必得额 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。双方秘密未解不得进入「部分形成」。每个 `Q#` 必须带判断三值和证明负担方。`L#` 不得直接抄技能内条号。

## 1. 触发、单方立场、授权与成果状态

行为能力分界。双方秘密未解不得进入「部分形成」。

## 2. 来源登记与 MCP 调用表

入学、值班、晨检、门卫、监控分列。口述已删、学校全责只登记 `S#`。`L#` 不得抄技能内条号。MCP 未调用也留一行。侵权责任法 38–40、2003 解释第七条若返回则记噪声。

## 3. 学习生活期间与主体分列

校外活动、接送、滞留待核。培训机构是否「其他教育机构」并行待核。一行一主体。

## 4. 第一千一百九十九条、第一千二百条分表

证明负担分列。在校即全责格填 `现有依据不支持`。1200 套推定格填 `现有依据不支持`。学校能够证明尽到职责则不承担。

## 5. 加害人类型

同学 vs 教职工职务 vs 机构以外第三人 vs 不明。同学 1201 格填 `不打开` 或 `现有依据不支持`。教职工职务并列用人者接口，不得默认 1201。

## 6. 第一千二百零一条与解释一第十四条

仅机构以外第三人打开。形态=`相应补充`。执行顺序：就第三人财产强制执行后仍不能履行的范围内与过错相应；未核验则待核。仅起诉学校：释明追加接口，不代提交。第三人不确定：先行与过错相应，不是全额连带。追偿接口打开，不附状。

## 7. 邻接红旗与法定代理

1188、1176、1198、打架、不明路径：打开、不打开或待核。法定代理只转 `评估未成年或无行为能力受害人代理`。不办监护令。1176 不消灭管理职责。

## 8. 证据与禁止事项

值班表、监控周期。不能因学校控制推定内容有利。只转介 `准备监控保存通知`，不办调取。禁止指导威胁学生证人或私下对质。校内事故报告不是民事终局。

## 9. 下一步

转介主体名单、追加第三人、保存通知、过错窗、打架窗、测算、发函、起诉、管辖、时效。不定伤残。不选定法院。学校所在地、结果发生地、各被告住所地并列待核。不写诉状。不写唯一时效截止日。

## 10. 缺口、停止项与提示

须列对方最强解释（在校就是全责、1199 是无过错绝对责任、1200 也要学校自证、同学也是 1201 第三人所以学校连带、补充即连带或全额、可与第三人同时执行、第三人不明则学校全额、监控在学校即拍到或已删即全责、校内事故报告等于学校免责、大学生食堂按 1199、旧第三十八条至第四十条或 2003 解释第七条、1186 各打五十、处分决定就是民事终局、必须先工伤、选边即可继续）与证据缺口。

本成果不是处分决定、不是监护令、不是 1188 终稿、不是 1198 终稿、不是诉状、不是必得总额。
