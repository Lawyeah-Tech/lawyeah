# 边界与路由

## 正触发

无民事行为能力人或限制民事行为能力人在幼儿园、学校或其他教育机构学习生活期间受到人身损害，需要判断教育机构 1199、1200 或 1201。用户要「在校即全责」「同学按 1201 第三人连带」「补充改连带」仍正触发。

双方秘密、伪造值班、威胁学生证人或违法调监控的停止，优先于负触发。不得改走负触发去出全责或免责方案。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 教师工伤待遇或劳动能力鉴定 | 劳动领域 |
| 校医诊疗过错 | 医疗医药领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

「幼儿园孩子被同学抓伤」正触发 1199，1201 不打开；对方家长 1188 只转介。「校外人员翻墙打伤学生」1201 与解释一第十四条候选。「大学食堂摔了」走 1198，不是本窗。「要撤销对方家长监护」或「要学校开除对方」负触发。「课间篮球撞伤要学校免责」本窗评估学校职责，1176 不消灭管理职责、不写 1176 终稿。「把同学当第三人要学校连带」仍正触发，1201 格与连带格不支持。「伪造值班表让同学改口」第一次提出即整体停止。
