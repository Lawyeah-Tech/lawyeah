# 边界与路由

## 正触发

无民事行为能力人或限制民事行为能力人在幼儿园、学校或其他教育机构学习生活期间受到人身损害，需要判断教育机构责任。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 监护变更 | 婚家领域 |
| 校园纪律学籍 | 负触发，非本成果 |
| 完全行为能力场所伤害 | `评估场所安全保障义务` |
| 校内诊疗过错 | 医疗医药领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 监护变更抚养 | 婚家领域 |
| 校医诊疗过错 | 医疗医药领域 |
| 教师工伤 | 劳动领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“幼儿园孩子被同学抓伤”正触发。“要撤销对方家长监护”转婚家。“大学食堂摔了”通常走场所安保。
