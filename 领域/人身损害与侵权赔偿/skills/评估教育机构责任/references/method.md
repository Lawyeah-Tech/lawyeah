# 教育机构责任方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。接口状态只用 `打开`、`不打开`、`待核`。形态只用 `自己责任（过错推定）`、`自己责任（过错）`、`相应补充`、`不打开`、`待核`。禁止胜诉率、唯一责任比例、必得总额、选定法院、伤残等级。未知金额不写零。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》第三十八条至第四十条、2003 年人身损害赔偿解释第七条已删除校园条款、已失效《合同法》，或把《学生伤害事故处理办法》当法律时记为噪声，不得写入 `L#`。禁止用第一千一百八十六条各打五十替代 1199–1201。禁止把同学写成第一千二百零一条第三人。禁止把解释一第十四条套进商场 1198 或物业抛物第二十四条、第二十五条。禁止把解释一第二十四条、第二十五条灌进校园 1201。

`Q#` 固定列：`编号｜行为能力｜机构类型｜是否学习生活期间｜路径条｜加害人类型（同学/教职工职务/机构以外第三人/不明）｜形态｜执行顺序｜证明负担方｜1188/1176/1198 接口｜判断｜待核`。一行一主体。幼儿园举办者、学校法人、培训机构、校车承运人、对方未成年监护人、教职工用人者不得合成「校方一方」。同学与学校不得合成连带一方。

## 节点 0　分流、立场、能力、期间与不关窗

整案转出只交付第 1、2、10 节。

| 信号 | 处理 |
| --- | --- |
| 教师工伤认定、劳动能力鉴定或工伤待遇主轴 | 转劳动 |
| 校医诊疗过错或医疗损害鉴定主轴 | 转医疗医药 |
| 海事 | 转海事 |
| 未成争只要改招生或托管合同 | 审查起草本窗搁置 |

「在校即全责」「同学按 1201 第三人连带」「补充改连带」**不关窗**。

行为能力检索锚点：总则编第十八条至第二十一条。八周岁以上一般为限制民事行为能力，走 1200，不得套 1199。十六周岁以上以自己的劳动收入为主要生活来源视为完全民事行为能力：1199/1200 可能 `不打开`，待核，或改走 1198。口头「孩子还小」「小学低龄」只登记 `S#`。无证件则能力字段停止。成年无/限制行为能力人在特殊教育机构：待核并行。

学习生活期间：学校组织的校外活动、纳入管理的校车接送可打开候选。放学后擅自滞留、自行提前离校、家长迟接：不得默认仍在期间，也不得默认已脱离，依据不足则字段停止。校外培训是否「其他教育机构」并行待核。

完全民事行为能力大学生普通场所：负触发至场所窗。用户坚持用 1199 告大学：1199 格 `现有依据不支持`，转 1198。打开教育机构路径后，本窗不写 1198 终稿，禁止同一失职两笔必得。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。同学互伤时两家加学校三方冲突尤其如此。
若 if 提出伪造值班记录、威胁或利诱学生证人、编造监控、违法进校调监控、倒签巡检、私下找未成年对质、伪造伤情或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　证明负担

过错推定不等于无过错责任，也不等于原告无需证明基础事实。1199、1200、1201 禁止揉成一条法律效果。

| 路径 | 形态 | 主张方须证 | 相对方须证 | 禁止写法 |
| --- | --- | --- | --- | --- |
| **1199** 无民事行为能力、无 1201 第三人 | 自己责任（过错推定） | 原告仍须证：无民事行为能力、损害、学习生活期间 | **教育机构**证明已尽教育、管理职责 | 在校即全责；受害人先证学校过错；材料不足写成必赔 |
| **1200** 限制民事行为能力、无 1201 第三人 | 自己责任（过错） | **主张未尽职责的一方**证明：限制行为能力、损害、期间、**未尽教育管理职责**及因果 | 学校可反证已尽职责，**不是**法定倒置 | 套 1199 推定；因监控在校方而倒置 |
| **1201** 教育机构以外的第三人 | 第三人直接 + 学校相应补充 | 主张第三人侵权的一方证第三人行为及因果；主张补充的一方证学校未尽**管理**职责 | 学校抗辩已尽管理职责；补充范围与第十四条执行顺位未核验则停止 | 补充即连带或全额；同学默认 1201 |
| 基础事实 | — | 行为能力、入学关系、事发时段由主张该事实的一方证明 | — | 口头年龄、口头在校升格为已证 |

校方控制值班表、晨检、门卫登记、监控：控制方只进矩阵，不得推定内容有利，也不得因口述「已删」即全责。诉前不得写拒不提交推定已成立。校内事故报告、调解记录不得单独写成民事终局比例或学校已免责。

## 节点 2　第一千一百九十九条无民事行为能力路径

检索锚点：无民事行为能力人在幼儿园、学校或者其他教育机构学习、生活期间受到人身损害的，幼儿园、学校或者其他教育机构应当承担侵权责任；但是，能够证明尽到教育、管理职责的，不承担侵权责任。

过错推定，不是无过错，不是绝对全责，不是在园在校即全赔。能够证明尽到教育、管理职责则不承担。材料不足：学校免责格 `依据不足，无法形成结论`，不得升格必赔。用户要绝对全责必得：该格 `现有依据不支持`，窗口不关。1186 默认 `不打开`。1173 过失相抵只标过错窗接口，本窗不输出唯一相抵比例。

## 节点 3　第一千二百条限制民事行为能力路径

检索锚点：限制民事行为能力人在学校或者其他教育机构学习、生活期间受到人身损害，学校或者其他教育机构未尽到教育、管理职责的，应当承担侵权责任。

过错责任。不得套 1199「学校自证已尽」。课间体育、校运会可标 1176 接口，转 `评估自甘风险与公平分担`；本窗不写 1176 终稿。1176 即使打开，也不消灭学校管理职责。课间追逐不得默认打开 1176。用户要学校因自甘风险免责：该格 `现有依据不支持` 或待核，窗口不关。

## 节点 4　同学、教职工与第一千二百零一条、解释一第十四条

**同学、同园幼儿互致伤害：** 1201 格 `不打开`。学校走 1199 或 1200 自己责任。加害学生监护人 1188 只标接口，转 `评估责任主体与保险覆盖`。不得写成学校与监护人法定连带；1168 须另有共同实施事实，转共同侵权窗，本窗不写终稿。互殴主轴转 `评估打架伤害民事路径`，本窗只评学校职责。用户要把同学写成 1201 第三人连带：1201 格与连带格 `现有依据不支持`，窗口不关。

**执行教育管理职务的教师、在编保安：** 通常不是 1201 第三人。职务致害并列 `评估用人者责任` 接口，本窗不写替代终稿。外包门卫是否「以外」待核，不得默认 1201 全额补充。

**教育机构以外的第三人**（校外闯入等）：打开 1201。检索锚点：由第三人承担侵权责任；教育机构未尽到管理职责的，承担相应的补充责任；承担补充责任后可以向第三人追偿。

解释一第十四条（法释〔2024〕12 号，条号须核验）：第三人与教育机构作为共同被告且依法应承担侵权责任的，判决应明确教育机构在人民法院就第三人的财产依法强制执行后仍不能履行的范围内，承担与其过错相应的补充责任。被侵权人仅起诉教育机构的，人民法院应当向原告释明申请追加实施侵权行为的第三人；本窗只标释明接口，转 `追加变更责任主体`，不代提交追加申请。第三人不确定的，未尽到管理职责的教育机构先行承担与其过错相应的责任；承担责任后向已经确定的第三人追偿。禁止把「先行」写成全额垫付或最终无追偿的自己责任。转介 `评估侵权人不明路径`。禁止套用 1254 可能加害人补偿。用户要补充改连带、补充即全额、与第三人同一执行顺序：该格 `现有依据不支持`，窗口不关。未核验则执行顺序字段停止，禁止默写百分之二十至三十。

## 节点 5　邻接禁令与输出纪律

本窗不写：1198 场所终稿；1188 监护人终稿；1176 或 1186 终稿；1168–1172 形态终稿；打架互殴终稿；处分决定；监护令；测算；起诉状。合法路径：报警、转介监控保存通知、调查令。禁止违法进校、收买门卫拷贝监控、指导私下找未成年对质。不能因学校控制监控推定内容有利。保存通知不等于法院保全。

不选定法院。学校所在地、结果发生地、各被告住所地并列待核，住院地不得写成必有权。口头转述、截图和「已读」不得写成已受理、已送达或期限已起算。未成年人时效另转时效窗。不把 190 用到学校。普通校园伤害不得套 191。
