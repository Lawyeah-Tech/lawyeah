# 评估教育机构责任

## 任务目标

在明确、无利益冲突的单方立场下，形成无民事行为能力人或限制民事行为能力人在幼儿园、学校或其他教育机构学习生活期间人身损害的分路径：第一千一百九十九条过错推定（教育机构能够证明尽到教育、管理职责的不承担，不是在校即全责）；第一千二百条过错责任（不得套用第一千一百九十九条推定）；第一千二百零一条仅当教育机构以外的第三人侵权且机构未尽管理职责时打开相应补充（含解释一第十四条执行顺序、释明追加、第三人不确定时先行与追偿）。同学互致伤害不得写入第一千二百零一条。不定伤残，不办监控调取，不选定法院，不保证必得。不把补充改成连带。不写 1198 场所终稿、1188 加害人监护人终稿、1176 自甘风险终稿、打架互殴终稿、监护令、校园处分、测算或起诉状。

`depends-on` 为空。大学生完全行为能力普通场所转 `评估场所安全保障义务`。加害学生监护人终稿转 `评估责任主体与保险覆盖`。课间体育自甘风险终稿转 `评估自甘风险与公平分担`。互殴终稿转 `评估打架伤害民事路径`。法定代理闭合转 `评估未成年或无行为能力受害人代理`。

## 工作边界

正触发：无民事行为能力人或限制民事行为能力人在幼儿园、学校或其他教育机构学习生活期间受到人身损害，需要判断教育机构 1199、1200 或 1201。用户要「在校即全责」「同学按 1201 第三人连带」「补充改连带」仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要总体责任总图（转 `评估人身侵权责任`）；
- 只要主体名单终稿（转 `评估责任主体与保险覆盖`）；
- 只要 1168–1172 形态终稿（转 `评估共同侵权与连带按份`）；
- 只要过错百分比（转 `评估过错与原因力`）；
- 完全民事行为能力人普通场所伤害，或大学食堂等非 1199/1200 主体（转 `评估场所安全保障义务`）；
- 只要自甘风险或公平分担终稿（转 `评估自甘风险与公平分担`）；
- 只要打架互殴、防卫或刑民分流终稿（转 `评估打架伤害民事路径`）；
- 只要加害人监护人 1188 终稿；
- 监护变更、指定或撤销（转婚家）；
- 只要受害人侧法定代理闭合终稿（转 `评估未成年或无行为能力受害人代理`）；
- 只要校园纪律处分或学籍处理；
- 校内诊疗过错主轴（转医疗）；
- 教师工伤主轴（转劳动）；
- 只要测算或伤残（转 `测算人身损害赔偿` 或 `准备伤残鉴定材料`）；
- 只要起诉状（转 `提起人身损害一审`）；
- 只要监控保存通知发送稿（转 `准备监控保存通知`）；
- 只要唯一时效截止日（转 `评估人身损害诉讼时效`）；
- 只要选定法院（转 `评估人身损害管辖`）；
- 未成争改招生或托管合同（审查起草搁置）；
- C 端只要大众准备包（只分流）。

学校组织的校外活动可打开本窗。放学后擅自滞留、自行提前离校不得默认仍在期间或已脱离。

## 建立工作坐标

确认：使用者与授权；单方立场；受害人年龄与行为能力（检索锚点总则编第十八条至第二十一条）；教育机构类型（含校外培训是否「其他教育机构」待核）；是否学习生活期间；加害人是同学、执行职务的教职工还是教育机构以外的第三人；值班、晨检、门卫、监控的控制方；法域。

口头「学校全责」「同学也是第三人」「监控已删」只登记 `S#`。口头年龄不得升格为已确定行为能力。

同时掌握双方秘密或受害学生家长与学校、双方家长利益冲突未解：`整体停止`，不得以选边治愈，也不得改走负触发去出全责或免责方案。提出伪造值班记录、威胁或利诱学生证人、编造监控、违法进校调监控、倒签巡检或伪造伤情：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 入学、值班、晨检、门卫、监控表面；`R#` 校方说明、警情、事故报告表面；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 责任行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。接口状态只用 `打开`、`不打开`、`待核`。形态只用 `自己责任（过错推定）`、`自己责任（过错）`、`相应补充`、`不打开`、`待核`。技能正文中的条号是检索锚点，不是已核验 `L#`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民法典第一千一百九十九条、第一千二百条、第一千二百零一条；解释一第十四条执行顺序、仅起诉教育机构释明追加、第三人不确定时先行与追偿（条号须核验）。不可用则路径开闭、举证结构、补充范围与执行顺序字段停止。已失效《侵权责任法》第三十八条至第四十条、2003 年人身损害赔偿解释第七条已删除校园条款，不得写入 `L#`。《学生伤害事故处理办法》不得当法律 `L#`。禁止把 1198、1188、1176 当本窗 `L#` 终稿。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变 1199/1200 开闭、1201 第三人范围或第十四条执行顺序的条文正文再写入 `L#`。不得编造 `regulation_id`，也不得把摘要条号写成已核验 `L#`。
- `search_practiced` 补同学伤害不是 1201、尽到职责可不承担、八周岁以上不得推定、校外培训是否其他教育机构、第十四条不得套商场或抛物的实务反例。

工具不可用时继续年龄、机构类型、期间、同学或校外人员、值班监控控制方编目；法律效果字段停止。不得凭记忆写在校即全责、同学即 1201 连带或补充即连带。

## 判断节点

执行顺序和停止条件以 [教育机构责任方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、能力、期间与加害人分列

同学与机构以外第三人分列。双方秘密或伪造值班、威胁证人提出即停。

### 2. 第一千一百九十九条无民事行为能力路径

过错推定，不是绝对责任，也不是受害人先证明学校过错。能够证明尽到教育、管理职责则不承担。

### 3. 第一千二百条限制民事行为能力路径

过错责任。不得套 1199 推定。1176 只标接口，不消灭管理职责。

### 4. 第一千二百零一条与解释一第十四条

仅教育机构以外的第三人。同学默认 1201 不打开。补充不是连带、不是全额、不是同一执行顺序。

### 5. 邻接红旗与输出纪律

1188、1176、1198、打架、处分、监护令只标接口。不定伤残，不选定法院。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；提出伪造值班记录、威胁或利诱学生证人、编造监控、违法进校调监控、倒签巡检或伪造伤情。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。
- `字段停止`：行为能力分界、学习生活期间、尽职证明结构、第十四条执行顺序未核验。用户要在校即全责、同学当 1201 连带或补充改连带则该格停止，窗口不关。
- `目标停止`：主目标变为处分、监护令、1188、1198、1176、打架、测算或起诉状。

禁止指导伪造值班、威胁学生证人或违法调监控。不给胜诉率。不选定法院。不保证必得。不代提交。
