# 评估教育机构责任

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“教育机构过错及第三人相应补充责任意见”。校园纪律处分不是本成果。监护变更转婚家。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算、鉴定和证据清单。

## 工作边界

正触发：无民事行为能力人或限制民事行为能力人在幼儿园、学校或其他教育机构学习生活期间受到人身损害，需要判断教育机构责任。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要校园纪律处分或学籍处理；
- 监护变更（转婚家）；
- 完全民事行为能力大学生普通场所伤害且无教育机构特别规则需求（转场所安保）；
- 校内诊疗过错主轴（转医疗）。

无民事行为能力与限制民事行为能力适用不同举证结构，不得混写。

## 建立工作坐标

确认：使用者与授权；单方立场；受害人年龄与行为能力；教育机构类型；损害发生在教学管理期间还是校外；是否第三人进入校园侵权；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 入学、值班、监控；`R#` 校方说明、警情；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 责任行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典第一千一百九十九条至第一千二百零一条。不虚构案件系统。

工具不可用时继续事实、主体、程序文书状态和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [教育机构责任方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　主体与期间

必须在学习生活期间。监护变更转婚家。

### 节点 2　无民事行为能力路径

不得写成绝对责任，也不得要求受害人先证明学校过错。

### 节点 3　限制民事行为能力路径

未尽教育管理职责才担责，不得直接套无行为能力推定。

### 节点 4　第三人相应补充

校外人员进入侵权，学校相应补充，不得写成与第三人连带。

### 节点 5　输出纪律

纪律处分不是本成果。校医诊疗过错转医疗。

## 停止与安全

- `整体停止`：立场不明；用户坚持伪造值班记录或威胁学生证人。
- `字段停止`：行为能力分界、教育机构尽到教育管理职责的证明结构未核验。
- `目标停止`：主目标变为纪律处分、监护变更或医疗损害。
