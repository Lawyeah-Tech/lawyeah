# 提出管辖异议

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的被请求方立场下，形成“管辖异议包”：异议书草稿、连结点证据、异议期限和逾期风险。与实体答辩分开。过期停止。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算、鉴定和证据清单。

## 工作边界

正触发：已被提起人身损害诉讼，需要在法定期限内提出管辖异议。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未被诉，只要管辖连结点图（转 `评估人身损害管辖`）；
- 异议期已过仍要求提交；
- 只要实体答辩（转 `应对人身损害一审`）；
- 劳动仲裁管辖（转劳动）；
- 海事专属程序（转海事）。

本任务与实体答辩分开，不保证异议成立，过期整体停止生成提交稿。

## 建立工作坐标

确认：使用者与授权；被告立场；起诉状和应诉通知书；送达日期和送达方式；答辩期满日待核；受诉法院；拟主张的有权法院连结点；是否已应诉实体；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 起诉状；`R#` 应诉通知、送达回证；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`J#` 连结点；`V#` 异议稿版本；`E#` 送达。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验管辖异议期限、应诉管辖和裁定上诉；`search_template` 只借异议书栏目。不虚构案件系统。

工具不可用时继续事实、主体、程序文书状态和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [管辖异议方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　期限闸

先核送达与异议期间。过期停止提交稿。

### 节点 2　异议理由与连结点

只写管辖，不写实体无责。

### 节点 3　异议书草稿

只交付草案。不代提交。

### 节点 4　与答辩的关系

实体答辩另项。可提示同步准备但不在此写答辩终稿。

### 节点 5　裁定后路径

对管辖权裁定上诉红旗。

## 停止与安全

- `整体停止`：立场不明；送达日已超过异议期且无恢复理由仍要求提交；用户坚持虚假住所地。
- `字段停止`：送达日、异议期限条文或专属规则未核验。
- `目标停止`：主目标变为实体答辩、管辖评估总图或上诉实体。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
