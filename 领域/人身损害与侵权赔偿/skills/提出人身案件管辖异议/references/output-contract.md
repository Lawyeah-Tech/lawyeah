# 输出合同

按触发结果选择交付形状。禁止把已读写成送达。禁止选定唯一法院。禁止把住院地写成事故发生地或结果发生地终局。禁止把保险人营业部写成对驾驶人当然有管辖。禁止代提交。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出（工伤待遇或劳动仲裁管辖；诊疗主轴；海事专属；未成争改合同） | 第 1、2、10 节。禁止异议书、连结点选定、期限截止日、应诉策略 |
| 整体停止 | 第 1、10 节。禁止异议草稿、选边、提交。双方秘密、保险人与驾驶人冲突未解、虚构住所地、倒签协议管辖或伪造事故地点时，整体停止优先于负触发；第一次提出即停，无选边治愈，无「坚持」门槛 |
| 期间已过（不关窗） | 十节表头可出现；第 6 节提交稿停止；第 3 节只交逾期风险与专属／级别／专门管辖例外待核；不得改走负触发关窗，不得生成可提交异议书 |
| 送达不明或条文未核验 | 正触发窗口仍开；第 3 节截止日字段停止；第 6 节不得写成可提交；单元格填 `依据不足，无法形成结论` 或 `待核` |
| 已实体答辩或反诉、异议权待核 | 十节表头出现；第 7 节应诉管辖风险必须在草稿前明示；异议是否仍可提未核验则第 6 节停止 |
| 正触发且可形成异议包 | 下列十节表头均出现；无仲裁／专属则第 5 节填 `不打开`；拟移送地只作 `J#` 打开／待核，禁止填唯一法院；字段停止的单元格待核，禁止省略后改填截止日或唯一法院 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。稿件状态只用 `草案`、`发送前待核`、`停止`。双方秘密未解不得进入「部分形成」。每个 `K#`／`J#` 必须带判断三值。

## 1. 触发、单方立场、授权与成果状态

写明被告或被诉保险人立场、冲突筛查、期限闸是否打开、受限字段。双方秘密或共同应诉冲突未解不得进入「部分形成」。

## 2. 来源登记与 MCP 调用表

`S/D/R/C/L/I/G/J/K/E/V`。送达回证、电子送达同意、到达特定系统记录分列编号。口头截止日、已读截图只登记 `S#` 或 `D#` 表面。`L#` 不得直接抄技能内条号。MCP 未调用也留一行。

## 3. 送达与异议期限卡

每份机关文书、每一受送达人单独一张 `K#`。作出日与送达日分列。已读不等于送达。不得用应诉通知作出日、立案日或已读起算。用户口述唯一截止日则截止日停止，口述只登记来源。期间类型分列：管辖异议／答辩／仲裁协议异议／举证／裁定上诉／保全复议；简易、小额、涉外另卡，不得默写普通程序十五日。不与三年诉讼时效混算。过期则本节点交逾期风险与专属／级别／专门例外待核，不编恢复期间截止日。

## 4. 异议理由与连结点证据

只写管辖，不写实体无责。实施地与结果发生地分列，冲突并列。住院地默认不打开。保险人营业部对未列驾驶人不生效。不利连结点不得删除。任何情况下都不选定唯一法院。移送请求不等于指定唯一受移送法院。

## 5. 仲裁或专属、专门法院红旗

文本必须回链。不打开则填 `不打开`。仲裁异议期间与管辖异议期间分列。保单仲裁不当然关闭对侵权人及交强险的诉讼入口。铁路专门管辖命中则普通区法院移送稿不得打开。

## 6. 异议书草稿

草案，不代提交，不得写成已提交。过期、送达不明或异议权未核验则本节省略为 `停止`。禁止预填此致某院或「移送唯一的某区法院」。实体无责段进入则该稿停止。

## 7. 应诉管辖风险

已实体答辩、情况说明或提出反诉则明示。级别管辖、专属管辖和专门法院除外须可见。保全或先予执行不等于已接受管辖。一人应诉不当然消灭其他未被送达被告的异议权。

## 8. 与实体答辩的拆分

不附答辩终稿。同时要答辩则转介 `应对人身损害一审`，并标明不得在异议裁定前提交实体答辩。不附反诉状。

## 9. 裁定后路径

成立：移送后实体答辩入口。驳回：对裁定上诉期间待核，送达不明则停止，不编唯一截止日。本窗不写上诉状或二审实体答辩。不把管辖权裁定写成实体胜败。

## 10. 缺口、停止项与提示

须列对方最强解释（已读即送达、应诉通知作出日起算、住院地即事故地、营业部覆盖司机、答辩里顺便写管辖、过期仍出可提交稿、选边即可继续、口述截止日必须写入、必须移送某区）与证据缺口。

本成果不是已提交异议书、不是实体答辩终稿、不是起诉状、不是唯一截止日、不是唯一受诉或拟移送法院。不保证异议成立。
