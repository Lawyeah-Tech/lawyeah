# 边界与路由

## 正触发

人身损害被告或被诉保险人已被起诉或已收到起诉状、应诉通知，需要准备管辖异议包。异议期已过仍要处理管辖问题，仍属正触发：提交稿停止，窗口不关。

双方秘密、虚构住所地、倒签协议管辖或违法取证的停止，优先于负触发。不得改走负触发去出异议书或答辩。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 尚未被诉只要连结点图 | `评估人身损害管辖` |
| 只要实体答辩终稿或首次应诉答辩包 | `应对人身损害一审` |
| 只要起诉状 | `提起人身损害一审` |
| 只要诉讼时效截止日 | `评估人身损害诉讼时效` |
| 只要反诉状终稿 | `评估反诉或抵销` |
| 只要管辖权裁定上诉状或二审实体答辩 | `提起人身损害上诉` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 工伤待遇仲裁或诉讼管辖 | 劳动领域 |
| 诊疗过错医疗损害诉讼主轴 | 医疗医药领域 |
| 船舶、海上人身伤亡、海事保全 | 海事领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 连结点展开、住院地或营业部是否打开 | `评估人身损害管辖` |
| 实体答辩草稿 | `应对人身损害一审` |
| 原告立案包 | `提起人身损害一审` |
| 三年时效截止日 | `评估人身损害诉讼时效` |
| 铁路、航空非海事承运人专门管辖 | `评估铁路航空等非海事承运人人身损害` |
| 交强险保险人住所与分账 | `评估道路交通事故责任与保险先行`；被告地位 `评估责任主体与保险覆盖` |
| 直接诉保专项 | `直接起诉保险公司` |
| 反诉状 | `评估反诉或抵销` |
| 管辖权裁定上诉状 | `提起人身损害上诉` |

## 易混

「传票到了，这个法院管不着」正触发，成果是异议期限卡、连结点证据和异议书草稿，不是「应移送某区法院」。「还没被诉，想知道去哪告」走管辖评估。「答辩里顺便说没责任也没管辖」应拆开，本任务只做异议，实体答辩另窗且裁定前不得提交。「微信已读起诉状 PDF，后天截止，立刻交去某区」正触发，但已读不起算、口述截止日不写入期限卡、不选定唯一法院。异议期已过不是负触发。保险人营业部所在地不等于对司机有管辖。住院地不得当然打开。
