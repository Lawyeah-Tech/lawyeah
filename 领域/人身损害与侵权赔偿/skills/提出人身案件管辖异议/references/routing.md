# 边界与路由

## 正触发

已被提起人身损害诉讼，需要在法定期限内提出管辖异议。

## 负触发

| 主要目标 | 路由 |
| --- | --- |

| 劳动仲裁管辖 | 劳动领域 |
| 海事专属 | 海事领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 工伤待遇仲裁管辖 | 劳动领域 |
| 医疗损害主轴 | 医疗医药领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“传票到了，这个法院管不着”正触发。“还没被诉，想知道去哪告”走管辖评估。“答辩里顺便说没责任也没管辖”应拆开，本任务只做异议。
