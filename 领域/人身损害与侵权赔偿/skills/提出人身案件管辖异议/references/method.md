# 管辖异议方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。连结点状态只用 `打开`、`待核`、`不选定`。期限状态只用 `待核`、`情景`、`停止`。稿件状态只用 `草案`、`发送前待核`、`停止`。**任何情况下都不选定唯一法院**，不输出胜诉率、唯一截止日或「本案只能由某院管辖」。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文、已失效《合同法》，或把 2017 年民事诉讼法第二十八条、第一百二十五条、第一百二十七条直接写成现行条号时记为噪声。2017 年可上诉裁定或上诉期间旧条号（约第一百五十四条、第一百六十四条一类）同样记为噪声。民诉法 2023 修正后编号必须运行时核验。

`K#` 固定列：`文书名称｜受送达人｜作出日｜送达日｜送达方式｜效力凭证｜期间类型｜起算事件｜期间长度待核｜待核截止｜状态`。一受送达人一卡。驾驶人、车辆所有人、保险人不得共用一张卡。
`J#` 固定列：`编号｜连结类型｜地点事实｜来源｜对哪一被告生效｜支持｜不利｜判断｜待核`。展开连结点法转介 `评估人身损害管辖`，本窗只用于攻击受诉法院无管辖权。

期间类型必须分列，禁止闭集成一个截止日：`管辖异议期间`／`答辩期间`／`仲裁协议异议`／`举证期限`／`管辖权异议裁定上诉期间`／`保全或先予执行复议`／`简易或小额答辩期间`／`涉外答辩期间`。

## 节点 0　分流、立场与禁止事项

整案转出只交付第 1、2、10 节，禁止异议草稿和选定法院。

| 信号 | 处理 |
| --- | --- |
| 工伤待遇仲裁或诉讼管辖 | 转劳动 |
| 诊疗过错医疗损害诉讼主轴 | 转医疗医药 |
| 船舶、海上人身伤亡、海事保全 | 转海事 |

尚未被诉只要连结点、只要答辩终稿、只要起诉状、只要时效截止日、只要反诉状或上诉状：负触发至对应原子，不是本节点整案转出。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发去出异议书或答辩。
若 if 保险人与驾驶人共同应诉而利益冲突未解，then 整体停止。
若 if 提出虚构住所地、伪造事故地点、倒签协议管辖或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。

## 节点 1　期限闸

管辖异议应当在提交答辩状期间提出。检索锚点：现行民事诉讼法第一百三十条第一款（2023 修正，条号须核验）。起算事件是**收到起诉状副本之日**，不是应诉通知作出日、立案日、法院内部流转日、起诉状落款日。

普通程序答辩期间检索锚点：现行民事诉讼法第一百二十八条（十五日，条号仍须核验）。**不得把十五日默写为已核验 `L#`。** 简易程序、小额程序、涉外答辩期间运行时核验；不明则截止日字段停止。被告不提出答辩状不影响审理，**不等于**已经缺席，也不等于已接受管辖。

电子送达须有当事人同意或法定条件，并以送达信息到达受送达人特定系统之日为送达日。检索锚点：现行民事诉讼法第九十条（条号须核验）。发送成功、邮件打开、微信已读、截图均不是送达日。无同意或无到达凭证：送达日与截止日字段停止。保险人与驾驶人的电子送达同意分人核验。

口头转述、截图、「已读」不得写成已送达或期限已起算。用户口述「后天截止」「必须今天交」只登记 `S#`，禁止写入 `K#` 截止日。仅有应诉通知、起诉状副本未送达：答辩期间与管辖异议期间两行截止日均停止。作出日不得代替送达日。

若 if 期间已过，then **提交稿停止，窗口不关**：不生成可提交异议书；仍须开口登记应诉是否已成就、级别管辖、专属管辖、铁路等专门管辖例外，一律 `待核`，不写成「过期仍必须审查」或「过期后什么都不能主张」。不编恢复期间的唯一截止日。答辩期届满后因原告增加请求导致标的额越级的级别异议：检索锚点《最高人民法院关于审理民事级别管辖异议案件若干问题的规定》第三条，该例外待核，不得写成普通地域异议仍可交。

一人应诉不当然消灭其他未被送达被告的异议权，效力待核，不得写成全案已接受管辖。

## 节点 2　应诉管辖、保全、专属与仲裁红旗

先于连结点和异议草稿。

未提出管辖异议，并应诉答辩**或者提出反诉**的，视为受诉人民法院有管辖权，但违反级别管辖和专属管辖规定的除外。检索锚点：现行民事诉讼法第一百三十条第二款（2023 修正增加「或者提出反诉」，条号须核验）。就案件实体内容进行答辩、陈述，可以认定为应诉答辩。检索锚点：民事诉讼法解释关于应诉答辩的条款（条号待核；解释若仍引用 2017 年第 127 条，记为噪声，不得把旧条号写入 `L#`）。铁路运输法院等**专门管辖**不能用应诉管辖治愈。

当事人在提交答辩状期间提出管辖异议，又针对起诉状内容进行答辩的，法院仍应审查管辖异议。本家族纪律更严：拟提异议或异议未决，实体答辩草稿停止或标明不得在裁定前提交。本窗**不写**答辩终稿，转介 `应对人身损害一审`。提出反诉可能单独成就应诉管辖风险；抵销、已付款不是反诉。本窗不写反诉状，转介 `评估反诉或抵销`。

保全或先予执行**不消灭**异议权，也不等于应诉管辖。复议期间与管辖异议期间分列。不得用保全裁定作出日起算异议期。本窗不写保全复议终稿。

专属检索锚点：现行民事诉讼法第三十四条。不动产纠纷、港口作业、继承遗产分列待核。人身损害因建筑物倒塌主张不动产所在地专属：侵权之诉不当然等于不动产纠纷，`待核`，不得当然接受也不得当然排除。港口作业人身伤亡可能落入港口所在地专属，待核。

铁路旅客运输、铁路行车事故或铁路作业造成的人身损害：标铁路运输法院专门管辖红旗，**普通民诉入口停止**，不得把区法院连结点标 `打开`，也不得写成「应移送某区法院」。转介 `评估铁路航空等非海事承运人人身损害`。城市轨道交通是否适用铁路专门管辖：依据不足则红旗待核。口头「交警说在我们这儿告」不得写成专属或指定管辖已成立。

仲裁协议异议时点与管辖异议期间**分列两张卡**。诉讼中以书面仲裁协议提出异议，检索锚点为仲裁法「首次开庭前」条款（条号待核），**不得把答辩十五日写成仲裁异议截止**。表面有效且未排除：不得写应向某院提出管辖异议即可解决问题；覆盖人身侵权请求须待核。交强险或商业三者保单中的仲裁，约束的是投保人与保险人的合同争议，**不当然阻断**受害人对侵权人及交强险保险人的法定共同被告诉讼。机构不明或或裁或诉：诉讼入口停止，不得写应向某院应诉。

级别管辖：标的额和受诉地标准须运行时核验。材料不足不选定级别；材料充足也**不选定**中院或基层为唯一结论。逾期后级别是否仍可主张、法院是否应依职权处理：待核红旗，不生成可提交地域异议书。

## 节点 3　异议理由与连结点

理由限于受诉法院无管辖权。不得在异议书中展开伤残、过错、金额或实体无责；实体段进入异议书则该稿不得标 `草案` 以外的可发送状态，应标 `停止` 或删实体段后重评。

连结点继承 `评估人身损害管辖` 纪律，本窗不重写一套连结点法：

- 侵权管辖检索锚点：现行民事诉讼法第二十九条。实施地与结果发生地分列，冲突并列。住院抢救地**默认不打开**：不得写成第三十条事故发生地，也不得当然写成第二十九条结果发生地；竞合强制 `待核`。持续治疗跨多个医院：后续就医地不得当然扩张。
- 公路等事故检索锚点：现行民事诉讼法第三十条。住院就医地不得认定为经常居住地。检索锚点：民事诉讼法解释第四条。
- 各被告住所地分列。检索锚点：现行民事诉讼法第二十二条。营业部、营销服务部不等于法人住所，也不当然等于有当事人能力的分公司；驾驶人未列为共同被告时，保险人住所不能产生对司机的管辖。
- 禁止把信息网络侵权「被侵权人住所地视为结果发生地」、对不在中国领域内被告的原告住所地规则、运输**合同**始发地／目的地，套用于普通场所人身损害。
- 用户点名某院只登记 `S#`，不得升格为协议管辖、指定管辖或唯一有权法院。

每个 `J#` 独立判断。不利连结点不得删除。**移送请求不等于选定唯一受移送法院。** 异议请求只写「受诉法院无管辖权，裁定移送有管辖权的人民法院」；候选连结点并列 `打开`／`待核`／`不选定`，禁止写成「本案只能由某区法院管辖」或「请移送唯一的某区法院」。

## 节点 4　异议书草稿、答辩拆分与裁定后路径

栏目可借鉴：当事人、案号、异议请求、事实与理由（只写管辖）、证据、受送达法院。范本只借栏目，不预填此致某院。级别管辖异议与地域管辖异议分列。不利连结点必须进入理由。不保证裁定支持。不代提交。不得写成已提交。

若 if 期间已过或送达不明或应诉管辖是否已成立未核验，then 本节稿件状态 `停止`，不生成可提交文本。
若 if 用户同时要答辩状，then 本窗不附实体答辩终稿，转介 `应对人身损害一审`；拟提异议则实体草稿标明不得在裁定前提交。
若 if 用户要立刻交到某区，then 该选定字段停止，口述只登记 `S#`。

异议成立：标移送后实体答辩入口，转介 `应对人身损害一审`。异议驳回：对管辖权异议裁定可以上诉。检索锚点：现行民事诉讼法第一百五十七条第二项、第一百七十一条第二款（裁定送达之日起十日，条号须核验，不得默写）。上诉期间自裁定**送达**日起算；已读裁定不等于送达；送达不明则截止日停止。本窗不写上诉状或二审实体答辩，转介 `提起人身损害上诉`。不把管辖权裁定写成实体胜败。驳回后实体答辩期限风险并行，不编新的唯一截止日。

## 证据与禁止

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口。不能因对方控制而推定材料存在或内容有利。地点冲突并列。禁止虚构住所地、倒签协议管辖、伪造事故地点。第一次提出即停。

下一步按期限灭失、易失证据、改变请求抗辩、可逆性排序。相邻文书只写转介条件和最小交接。禁止指导伪造、隐匿、威胁、倒签或违法取证。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过专项分流直接给唯一法院或唯一截止日。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if 金额参数不足，then 该行标未知，禁止写零冒充已发生。
若 if 主轴是工伤认定、劳动能力鉴定或工伤待遇，then 整案转劳动领域。
若 if 主轴是诊疗过错、病历真实性或医疗损害鉴定，then 整案转医疗医药领域。
若 if 主轴是海上运输、船舶碰撞或海事保全，then 整案转海事领域。
若 if 尚未发生损害且只要改合同或出稿，then 审查起草本窗搁置，只说明不实施。

口头转述、截图和「已读」不得写成已受理、已送达或期限已起算。判断状态只许三值。禁止胜诉率、必然责任比例和唯一必得总额。

## 本任务回链纪律

本任务成果是「管辖异议包」：已被起诉后的期限卡、连结点证据和异议书草稿；被请求方。不包含：实体答辩终稿、起诉状、时效唯一截止日、反诉状、上诉状、唯一受诉或拟移送法院。过期只停提交稿，不关窗。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`，已停止字段逐行列出待核事项。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接：已固定事实时间线、主体表、`K#` 和缺口。
风险档 A：不可逆文书或期限字段必须单独标可逆性。
