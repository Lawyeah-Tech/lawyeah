# 边界与路由

## 正触发

治疗相对稳定或死亡已发生，需要伤残、三期、护理依赖或因果鉴定申请材料。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 医疗损害鉴定 | 医疗医药领域 |
| 劳动能力鉴定／工伤待遇 | 劳动领域 |
| 已有鉴定只要异议或重新鉴定 | `提出伤残鉴定异议或重新鉴定`（未安装则 `unavailable`） |
| 只要测算 | `测算人身损害赔偿` |
| 只要总图，或综合提问夹带管辖／金额终稿 | `评估人身侵权责任` |
| 起诉 | `提起人身损害一审` |
| 治疗未稳定却要“先评十级” | 本窗鉴定闸关闭，不转介启动 |

受害人开口且委托范围是鉴定申请材料时，不因口语化咨询整体停止。双方秘密、伪造病历或指定等级的整体停止，优先于负触发。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 参与度、既往伤病 | `评估因果关系与既往伤病` |
| 工作中第三人 + 劳动能力鉴定 | `评估工伤与第三人侵权竞合`；劳动能力鉴定转劳动 |
| 伤残未出意见却要金额 | `测算人身损害赔偿`（残疾行必须 `无法估计`） |
| 已有鉴定要推翻 | `提出伤残鉴定异议或重新鉴定` |

## 易混

“能不能评残、材料怎么递”正触发。“评完能拿多少钱”走测算，且未出意见时残疾赔偿金不得估计为确定值。治疗未稳定时只输出闸门关闭，不写申请终稿。工伤劳动能力鉴定与民事人体损伤致残不是同一事项。
