# 边界与路由

## 正触发

人身损害已发生，申请方需要伤残、三期、护理依赖、因果、后续治疗、辅助器具或死因鉴定的发送前材料。从零、碎片、稳定或标准未核验仍正触发：有可编号待鉴定事项或检材碎片则闸开或半开，出 `JT#` 草案，保持草案。本次不预测等级、不代提交是交付禁令，不是开窗条件。先按十级、申请即已出具、单方委托即法院委托，仍正触发。把废止道路标准写成现行、把未知写成零，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造病历、倒签鉴定日的停止，优先于负触发。上述信号不在下表。不预测等级不是负触发。「申请即已出具」「先按十级」「单方委托即法院委托」「废止道路标准即现行」「未知写零」不在下表。

## 易混

本窗闸名只能是鉴定闸，不是伤残闸，不是申鉴闸，不是求偿闸，不是侵权闸，不是鉴异闸。`JT#` 不是 `APP#`，不是 `JA#`，不是 `JD#`，不是 `QG#`。主路径是 `Q-伤鉴`，不是 `Q-鉴`，不是 `Q-申鉴`，不是 `Q-残`，不是 `Q-责`。`申鉴闸`／`JA#`／`Q-申鉴` 是合同包 `准备质量或损失鉴定申请`。`Q-鉴`／`JD#` 是公司治理 `准备股权价值或非货币出资鉴定`。邻窗 `评估人身侵权责任`、`评估人身损害诉讼时效`、`准备侵权索赔通知` 的鉴定转介已改挂 `Q-伤鉴`。治疗未稳定不是开评残切片。申请不是已出具。单方委托不是法院委托。GB 18667-2002 不是现行。GB/T 16180 不是民事致残终稿。提出「出院诊断改成没有既往、鉴定日改到上周」整体停止。本窗不代提交。不选定法院或鉴定机构。不定残。不预测等级。不保证准许或采信。
