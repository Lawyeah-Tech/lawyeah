# 边界与路由

## 正触发

治疗相对稳定或死亡已发生，需要伤残、三期、护理依赖或因果鉴定申请材料。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 医疗损害鉴定 | 医疗医药领域 |
| 劳动能力鉴定／工伤待遇 | 劳动领域 |
| 只要测算 | `测算人身损害赔偿` |
| 已有鉴定只要异议 | `提出伤残鉴定异议或重新鉴定`（未安装则 `unavailable`） |
| 只要总图 | `评估人身侵权责任` |
| 起诉 | `提起人身损害一审` |

## 易混

“能不能评残、材料怎么递”正触发。“评完能拿多少钱”走测算，且未出意见时残疾赔偿金不得估计为确定值。治疗未稳定时只输出闸门关闭，不写申请终稿。
