# 输出合同

按触发结果选择交付形状。鉴定闸未打开不得交付申请终稿。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向 |
| 伤残闸关闭或整案转出 | 第 1、2、3、10 节：关闭理由和稳定条件／转介。禁止第 4–7 节事项表和申请稿 |
| 整体停止 | 第 1、10 节。禁止事项表、申请稿、送检策略。双方秘密或改病历时，整体停止优先于负触发 |
| 正触发且伤残闸打开 | 下列十节均出现；禁止填入等级或系数 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。等级状态只用 `未鉴定`、`已有意见待质证`、`停止`。

## 1. 触发、单方立场、授权与成果状态

必须写明单方立场、授权范围、冲突筛查和伤残闸是否打开。

## 2. 来源登记与 MCP 调用表

`S/D/R/L/I/G/APP/V`。MCP 未调用也留一行。`L#` 不得直接抄技能内标准名或条号。

## 3. 治疗稳定或死亡事实

材料不足则闸门关闭理由。内固定未取、计划内二次手术必须可见。

## 4. 鉴定事项表

每项 `APP#` 独立。禁止预测等级、禁止“按十级出具”。

## 5. 检材与控制方

病历冲突并列。禁止补造或改诊断。

## 6. 标准与机构分流

标准名称、版本、施行日待核。不得指定唯一机构为必选。不得用废止道路交通事故伤残标准或工伤劳动能力标准完成本任务终稿。

## 7. 申请稿

发送前草案。诉中为致法院申请书，诉前为致机构委托书。不写预期结论，不预填唯一鉴定所。本任务不代提交。

## 8. 不可逆与最强反方

单方委托风险、参与度不利、病历冲突、重新鉴定不是当然权利。

## 9. 风险与下一步

转介测算、异议、因果专项或起诉。闸关闭时不得把“去做法医鉴定”写成下一步。

## 10. 缺口、停止项与提示

本成果不是鉴定意见，不是伤残等级，不是赔偿总额。
