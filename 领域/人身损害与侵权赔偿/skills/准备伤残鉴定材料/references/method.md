# 鉴定申请方法

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。禁止预测伤残等级、系数或必得金额。技能正文中的条号和标准名是检索锚点，不是已核验 `L#`。

---

## 节点 0　鉴定闸

先于事项展开。闸关闭或整案转出时只交付第 1、2、10 节。

| 条件 | 处理 |
| --- | --- |
| 主成果是诊疗过错、病历或医疗事故技术鉴定 | 整案转医疗医药 |
| 主成果是劳动能力鉴定以申请工伤待遇 | 整案转劳动；民事伤残鉴定与工伤劳动能力鉴定分轨，禁止用工伤标准完成本任务终稿 |
| 海事船舶伤亡专门鉴定 | 转海事 |
| 无死亡事实且出现急救未结束、骨折未固定、内固定未取、计划内二次手术未做、烧伤未拆痂等任一未相对稳定信号 | **伤残程度、护理依赖**闸关闭，只交付稳定条件清单，禁止转介启动评残。**后续治疗必要性与费用**可单列打开并转介 `评估后续治疗费另行主张`。三期未稳定不得写成确定截止日 |
| 已有工伤劳动能力鉴定、医疗事故技术鉴定或刑事伤情鉴定 | 不是本窗已有民事致残鉴定，不得负触发到异议，不得当预期等级 |
| 已有法院委托的民事人体损伤致残鉴定且本次只要异议或重新鉴定 | 负触发至 `提出伤残鉴定异议或重新鉴定` |
| 综合提问夹带总图、管辖、金额终稿 | 转 `评估人身侵权责任` |
| 双方秘密、伪造病历、指定等级、按索赔口径改诊断 | 整体停止 |

打开伤残闸：治疗相对稳定的材料支持，且无上列未稳定信号。用户口述“差不多好了”或只要“先把申请写了”不得单独打开伤残闸。死亡案件的死因／范围鉴定不受伤残稳定闸。保险人、被告等参与方使用本技能：成果限于选定机构、检材异议、回避；申请稿节字段停止，不得以受害人名义出申请终稿。

工作中第三人伤害：民事人体损伤致残鉴定可留；劳动能力鉴定工伤用途整段转劳动，并转介 `评估工伤与第三人侵权竞合`。

## 节点 1　事项拆分

每个 `APP#` 固定列：`事项｜待证事实｜与赔偿项目的接口｜检材｜标准待核｜程序路径｜判断`。

默认分项，禁止合成：

- 人体损伤致残程度；
- 误工期、护理期、营养期；
- 护理依赖程度；
- 后续治疗必要性与费用评估；
- 辅助器具配置评估；
- 外伤与损害之间的因果关系或参与度；
- 死亡原因（仅死亡案件）。

不得把“鉴定十级”“是否构成十级伤残”写成事项。口头“大概十级”不得写入 APP# 和申请稿；坚持“请按十级出具”＝整体停止。不得把医疗过错鉴定事项写入本包申请稿；混合提问时第 7 节不得出现诊疗过错事项。因果关系若指向诊疗行为本身：该 `APP#` 转出医疗。参与度／既往伤病争点转介 `评估因果关系与既往伤病`，本任务只列事项接口。

## 节点 2　检材

清单：身份材料、完整门急诊和住院病历、手术记录、影像及报告、复查记录、已有鉴定、事故材料。记录原件控制方。缺关键手术或影像：相应事项 `依据不足`，不建议用口头病史替代。

禁止指导补造病历、修改影像日期或要求医生按索赔口径改诊断。已发现病历冲突：并列，写入最强反方。

---

## 节点 3　标准与机构

民事人身损害致残评定：司法鉴定机构和鉴定人进行人体损伤致残程度鉴定，检索锚点为两院三部《人体损伤致残程度分级》（2017-01-01 施行）。GB 18667-2002《道路交通事故受伤人员伤残评定》已废止。鉴定日在 2017-01-01 及以后的，司法鉴定统一适用《人体损伤致残程度分级》，不得因事故日早于施行日选用废止道路标准。只有生效委托或有权机关文书明确适用旧标准才可待核，用户口头指定不算核验。职工工伤与职业病致残等级标准不得写成非工伤民事评残默认，也不得用于完成本任务民事终稿。工地受伤走提供劳务者受害时尤其不得默用工伤标准。

致残评定标准名称、版本和施行日一律运行时核验后写入 `L#`。损伤发生日与鉴定日冲突时并列待核，不得凭记忆选标准。

程序路径分列：

1. 双方协商共同委托；
2. 诉前单方委托：须提示证明力弱于法院委托鉴定意见，对方可能不认可，且可能被当作自认线索。诉讼中对方有证据或理由足以反驳并申请鉴定的，法院应予准许。检索锚点：民事诉讼证据规定第四十一条。此为申请法院委托鉴定，不是对单方意见的重新鉴定。
3. 诉讼中申请法院委托：在指定期间提出并预交费用；准许后组织双方协商确定具备资格的鉴定人，协商不成由法院指定。鉴定材料须经质证，争议材料由法院认定，不得交鉴定机构自选。检索锚点：民诉解释第一百二十一条、民事诉讼证据规定第三十条至第三十四条。当事人只向法院申请，由办案机关委托鉴定机构，不得做成直接发给某一鉴定所的诉中委托书。

不得指定唯一机构为“必须去的鉴定所”。未进入诉讼时，不得把法院名册写成已经指定。死因走法医病理，伤残、三期、护理依赖走法医临床，不得捆成一项，不得交给无相应执业类别的机构。

已有法院委托鉴定意见、本次要重新鉴定：本任务负触发至异议原子。重新鉴定不是当然权利，只适用于法院已委托的鉴定意见。检索锚点：民事诉讼证据规定第四十条——鉴定人不具备相应资格、鉴定程序严重违法、鉴定意见明显依据不足，或不能作为证据使用的其他情形，才应当准许；瑕疵能通过补正、补充鉴定或补充质证解决的，不予准许重新鉴定。

## 节点 4　申请稿与不可逆

申请稿按路径拆开：诉前协商或单方＝致鉴定机构的委托书草案，并保留单方不被采信与自认风险；诉中＝致法院的鉴定申请书（事项、检材、期间、预交、质证、协商或指定），不预填唯一鉴定所。不写预期等级，不写“请按十级出具”。

不可逆提示必须出现：事项过窄可能遗漏护理依赖；事项过宽可能引入不利参与度；单方委托意见可能不被采信但仍可能被对方当作自认线索；重新鉴定有程序条件，不是当然权利。

本任务不代提交，不联系鉴定人施压。
