# 鉴定申请方法

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。禁止预测伤残等级、系数或必得金额。技能正文中的条号和标准名是检索锚点，不是已核验 `L#`。

---

## 节点 0　鉴定闸

先于事项展开。闸关闭或整案转出时只交付第 1、2、10 节。

| 条件 | 处理 |
| --- | --- |
| 主成果是诊疗过错、病历或医疗事故技术鉴定 | 整案转医疗医药 |
| 主成果是劳动能力鉴定以申请工伤待遇 | 整案转劳动；民事伤残鉴定与工伤劳动能力鉴定分轨，禁止用工伤标准完成本任务终稿 |
| 海事船舶伤亡专门鉴定 | 转海事 |
| 急救未结束、骨折未固定、内固定未取、计划内二次手术未做、烧伤未拆痂且无死亡事实 | 鉴定闸关闭；只交付稳定条件清单，禁止转介“先评一个十级” |
| 已有鉴定且本次只要异议或重新鉴定 | 负触发至 `提出伤残鉴定异议或重新鉴定` |
| 综合提问夹带总图、管辖、金额终稿 | 转 `评估人身侵权责任` |
| 双方秘密、伪造病历、指定等级、按索赔口径改诊断 | 整体停止 |

打开闸：治疗相对稳定的材料支持，或受害人死亡需要死因／损害范围鉴定；申请方或参与方授权清楚。用户口述“差不多好了”不得单独打开闸。死亡案件的死因／范围鉴定不受伤残稳定闸。

工作中第三人伤害：民事人体损伤致残鉴定可留；劳动能力鉴定工伤用途整段转劳动，并转介 `评估工伤与第三人侵权竞合`。

## 节点 1　事项拆分

每个 `APP#` 固定列：`事项｜待证事实｜与赔偿项目的接口｜检材｜标准待核｜程序路径｜判断`。

默认分项，禁止合成：

- 人体损伤致残程度；
- 误工期、护理期、营养期；
- 护理依赖程度；
- 后续治疗必要性与费用评估；
- 辅助器具配置评估；
- 外伤与损害之间的因果关系或参与度；
- 死亡原因（仅死亡案件）。

不得把“鉴定十级”写成事项。不得把医疗过错鉴定事项写入本包申请稿。因果关系若指向诊疗行为本身：该 `APP#` 转出医疗。参与度／既往伤病争点转介 `评估因果关系与既往伤病`，本任务只列事项接口。

## 节点 2　检材

清单：身份材料、完整门急诊和住院病历、手术记录、影像及报告、复查记录、已有鉴定、事故材料。记录原件控制方。缺关键手术或影像：相应事项 `依据不足`，不建议用口头病史替代。

禁止指导补造病历、修改影像日期或要求医生按索赔口径改诊断。已发现病历冲突：并列，写入最强反方。

---

## 节点 3　标准与机构

民事人身损害致残评定：司法鉴定机构和鉴定人进行人体损伤致残程度鉴定，检索锚点为两院三部《人体损伤致残程度分级》（2017-01-01 施行）。GB 18667-2002《道路交通事故受伤人员伤残评定》已废止，不得冒充现行标准，除非核验表明该争议损伤发生在标准交替前且委托明确适用旧标准。职工工伤与职业病致残等级标准不得用于完成本任务民事终稿。

致残评定标准名称、版本和施行日一律运行时核验后写入 `L#`。损伤发生日与鉴定日冲突时并列待核，不得凭记忆选标准。

程序路径分列：

1. 双方协商共同委托；
2. 诉前单方委托（须提示对方可能不认可；诉讼中对方有证据或理由足以反驳并申请鉴定的，法院应予准许。检索锚点：民事诉讼证据规定第四十一条）；
3. 诉讼中申请法院委托：准许后组织双方协商确定具备资格的鉴定人，协商不成由法院指定。检索锚点：民诉解释第一百二十一条。

不得指定唯一营利机构为“必须去的鉴定所”。未进入诉讼时，不得把法院名册写成已经指定。

已有鉴定、本次要重新鉴定：本任务负触发至异议原子。重新鉴定不是当然权利。检索锚点：民事诉讼证据规定第四十条——鉴定人不具备相应资格、鉴定程序严重违法、鉴定意见明显依据不足，或不能作为证据使用的其他情形，才应当准许；瑕疵能通过补正、补充鉴定或补充质证解决的，不予准许重新鉴定。

## 节点 4　申请稿与不可逆

申请稿只写当事人、鉴定事项原文、检材目录、用途（协商／诉讼）和联系方式。不写预期等级，不写“请按十级出具”。

不可逆提示必须出现：事项过窄可能遗漏护理依赖；事项过宽可能引入不利参与度；单方委托意见可能不被采信但仍可能被对方当作自认线索；重新鉴定有程序条件，不是当然权利。

本任务不代提交，不联系鉴定人施压。
