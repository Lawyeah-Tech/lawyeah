# 准备伤残鉴定材料方法

本文件是可执行判断节点。治疗未稳定不是开评残切片。先按十级不是开鉴定闸。口述「差不多好了」不是已稳定。申请不是已出具鉴定意见。单方委托不是法院委托。工伤劳鉴不是民事人体损伤致残。废止道路标准不是现行。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已委托、已出具、已准许、选定法院或鉴定所、代提交、未知写零、预测等级。本任务不定罪，不定残，不代提交。本窗闸名只能是鉴定闸，禁止复用伤残闸、申鉴闸、评估闸、求偿闸、侵权闸、鉴异闸。预留不得占用：立案闸、起诉闸、鉴异闸、发送闸。本窗 `JT#` 是鉴定行。主路径只用 `Q-伤鉴`，禁止用 `Q-鉴`、`Q-申鉴`、`Q-残`、`Q-签`、`Q-责` 作主路径。本窗 `Q-签` 只作「草稿即已提交、已委托或已作出」不关窗码。本窗 `Q-残` 只作「先按十级或伤残已定」不关窗码。英文 id 禁止使用，一律用中文技能名 `准备伤残鉴定材料`。

技能正文和本文件中的条号、标准名是检索锚点，不是已核验 `L#`。`search_law` 返回 GB 18667-2002、1991 年道路交通事故处理办法向公安机关十五日评残、2008 年证据规定第二十八条、1991／2017 年民诉旧条号、GB/T 16180 当民事终稿时记为噪声。禁止指导伪造病历、改诊断或威胁鉴定人。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事项或检材碎片扫描，不是默认闭集。
`JT#` 固定列：`编号｜鉴定切片｜事项｜标准与稳定｜检材｜机构与申请接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已经评残」一笔。无 `E#` 不得写已委托或已作出。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-伤鉴`。禁止 `APP#`、`JA#`、`JD#`、`A#`、`N#`。一行一个鉴定切片。文件状态只用 `草案`、`停止`。

口头「差不多好了」「先按十级」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：诉中优先申请法院委托。诉前协商共同委托次之。诉前单方委托打开但必须挂风险格。已有法院委托意见要推翻负触发异议窗。内固定未取不是一律关闸，评残切片字段停止或半开。死因切片不受治疗稳定闸。

## 节点 0　分流、立场、鉴定闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造病历、改诊断、倒签鉴定日、威胁鉴定人不进负表。利益冲突未解不进整体停止。不预测等级、不代提交不是负触发。

整案转出只交付第 1、2、10 节，不出 `JT#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是侵权总图 | 负触发 `评估人身侵权责任` |
| 主成果是精算工作表 | 负触发 `测算人身损害赔偿` |
| 已有法院委托民事致残意见且只要异议或重鉴 | 负触发 `提出伤残鉴定异议或重新鉴定` |
| 主成果是多份意见比较终稿 | 负触发 `评估伤残等级争议` |
| 主成果是参与度或既往伤病终稿 | 负触发 `评估因果关系与既往伤病` |
| 主成果是后续治疗费另诉条件终稿 | 负触发 `评估后续治疗费另行主张` |
| 主成果是索赔通知或起诉包 | 负触发 `准备侵权索赔通知` 或 `提起人身损害一审` |
| 主成果是医疗损害鉴定 | 整案转医疗医药 |
| 主成果是劳动能力鉴定或工伤待遇 | 整案转劳动；夹带第三人只开 `评估工伤与第三人侵权竞合` |
| 人体损伤程度当伤残主轴 | 说明不是本窗；可开 `分流刑民交叉` 接口 |
| 海事船舶伤亡专门鉴定 | 整案转海事 |
| 尚未发生损害，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 「不预测等级」「不代提交」 | 交付禁令，不是负触发 |

混合信号：工作中第三人伤害，民事评残可留，劳鉴段只红旗。出现「鉴定」「十级」一词不是转出。仅有诉前单方意见要走证据规定第四十一条：正触发本窗。

鉴定闸打开（可出 `JT#` 草案，仍不得标「已委托／已出具／已准许」）须同时满足：单方无冲突立场已闭合；主成果是鉴定申请草稿，不是总图、不是测算、不是异议；至少一项可编号待鉴定事项或检材碎片。口头「先按十级」不算单独开闸材料。伤残程度、护理依赖切片另须相对稳定材料才打开申请接口。

鉴定闸部分打开：已有碎片，但稳定、标准或启动路径未闭合；对应格待核；仍交十节。无死亡且治疗未相对稳定：评残／护理依赖申请接口不打开，闸半开仍出其他 `JT#`（三期、后续治疗、死因不受稳定闸）。无书面授权但单方立场已闭合且已有碎片：鉴定闸部分打开，仍交十节，不是整体停止。

鉴定闸关闭（仍正触发）：无一可编号碎片。「今天必须出鉴定意见」而无最小碎片不得开闸。不出 `JT#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `JT#` 终稿，**第 7 节不得出申请终稿或鉴定意见**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「申请即已出具」「先按十级」「单方委托即法院委托」「废止道路标准即现行」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `JT#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 鉴定闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造病历、改诊断、倒签鉴定日、威胁鉴定人或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　切片、稳定与检材碎片

一行一个鉴定切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `JT#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 切片 | 致残程度、三期、护理依赖、后续治疗、辅助器具、外伤因果或参与度、死因分列 | 合成「鉴定一下能赔多少」；请按十级出具 |
| 稳定 | 治疗终结或临床效果稳定材料；死因不受此闸 | 口述稳定升格已稳定；内固定未取一律关闸 |
| 检材 | 病历、影像、手术记录连续性、原件控制方 | 口头病史顶替关键手术／影像 |

检索锚点（写入 `L#` 前须核验）：民诉第七十九条；证据规定第三十条至第三十四条、第四十条、第四十一条；《人体损伤致残程度分级》施行日与鉴定时机。噪声：GB 18667-2002；1991 年道路交通事故处理办法第四十二条；GB/T 16180 当民事终稿。

## 节点 3　鉴定行 `JT#`

按已出现切片扫描，不是默认闭集。每条须能指向事项、检材或启动接口之一。诉前：致机构委托书草案，保留单方不被采信风险。诉中：致法院鉴定申请书草案，不预填唯一鉴定所。

无 `E#` 不得写已委托或已作出。状态 `草案`。一次只推荐下一步。未知不写零，不预测等级或系数。

热冲突强制处理：

- 申请即已出具／先按十级／单方即法院委托／废止道路标准即现行／未知写零 → 该格不支持或字段停止；仍出其他 `JT#`。
- 无一碎片 → 关闸，不出 `JT#` 终稿，窗口不关。
- 指导伪造病历、改诊断、倒签、威胁鉴定人 → 整体停止，不是该格不支持。

## 节点 4　测算、异议、因果、工伤与起诉接口

第 7 节只开接口，不得夹带 `JT#` 终稿、发送版申请或鉴定意见绕闸。闸关闭时第 7 节可写「闸未开，转介待事项编号」，不得补写已委托或十级。不选定法院或鉴定所。不代提交。未稳定不得转介启动评残。

下一步只转介：`评估人身侵权责任`、`测算人身损害赔偿`、`提出伤残鉴定异议或重新鉴定`、`评估伤残等级争议`、`评估因果关系与既往伤病`、`评估后续治疗费另行主张`、`评估工伤与第三人侵权竞合`、`准备侵权索赔通知`、`评估人身损害诉讼时效`、`建立人身损害证据案卷`、`提起人身损害一审`、`准备人身损害庭审`、`评估死亡赔偿权利人与分配`、`申请人身案件调查令或取证`、`评估责任主体与保险覆盖`、`评估道路交通事故责任与保险先行`、`分流刑民交叉`。禁止此致某所。

若 if 用户催促「差不多好了先评／先按十级／此致某所／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 再执行清单

每个节点结束后回写：来源、判断、最强反方、是否字段停止。不得跳过鉴定闸直接给已委托或十级终稿。

若 if 标准、稳定、检材质证、启动路径、施行日未核验，then 该强制项字段停止，窗口不关。
判断状态只许三值。口头「差不多好了」不得写成 `JT#` 已稳定。未知不写零。

## 本任务回链纪律

本任务成果是「鉴定闸与发送前鉴定申请草案」。本窗不代提交。不包含：鉴定意见、已委托证明、必得残金。禁止选边治愈。禁止申请即已出具。禁止先按十级开闸。禁止指导伪造病历或威胁鉴定人。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标鉴定终稿已形成。
风险档 A：伪造病历、改诊断、倒签、威胁鉴定人必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：机动车事故有急诊和住院病历，内固定未取，治疗未相对稳定。用户主张差不多好了先评、请按十级出具、用道路旧标准、此致某鉴定所、不清楚护理依赖先写零。鉴定闸打开或半开。评残／护理依赖申请接口不打开。`Q-稳`、`Q-残`、`Q-路`、`Q-院`、`Q-零` 不打开为可靠路径。第 6 节不得把十级、已委托、0 写入可执行 `JT#`；对应格 `现有依据不支持` 或字段停止；仍出三期切片、后续治疗接口、检材缺口、诉中申请法院委托路径等其他 `JT#`。不关窗。不代提交。不定残。

场景②：用户同时交出己方「必须评十级」与对方「伤情不实」口径，并指导「把出院诊断改成没有既往、鉴定日改到上周」。命中双方秘密＋改诊断＋倒签。第一次整体停止。只交第 1、10 节。不出 `JT#`。不得问代表哪一方后继续。不以「坚持」为门槛。
