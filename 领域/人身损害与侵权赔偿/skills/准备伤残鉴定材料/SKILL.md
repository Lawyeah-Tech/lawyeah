# 准备伤残鉴定材料

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的申请方或参与方立场下，于治疗相对稳定或死亡事实已经发生时，形成“伤残或相关鉴定申请包”：鉴定闸、鉴定事项、适用标准待核、检材清单、机构分流、申请稿和不可逆提示。

`depends-on` 为空。本任务不预测等级，不代替鉴定机构出具意见。

## 工作边界

正触发：人身损害已发生，治疗相对稳定或受害人死亡，用户需要启动人体损伤致残程度、三期、护理依赖、因果关系或死因相关鉴定的申请材料。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 治疗明显未稳定，用户只要“先鉴定一个十级”；
- 主成果是医疗损害鉴定（诊疗过错／病历）；
- 主成果是劳动能力鉴定以主张工伤待遇（转劳动）；
- 只要测算数字或只要诉状；
- 海事事故专门鉴定。

本任务不输出伤残等级或系数，不保证机构受理或意见有利于申请人。

## 建立鉴定坐标

确认：使用者与授权；受害人；损伤部位与诊断材料；末次手术或治疗稳定线索；拟鉴定事项；法域与拟适用标准线索；已有鉴定；诉讼或协商阶段；检材控制方。

同时掌握双方秘密时先停。用户指定等级不构成预测授权。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 病历材料；`R#` 机关或已有鉴定；`L#` 运行时已核验规则或标准；`I#` 判断；`G#` 缺口；`APP#` 鉴定事项；`V#` 申请版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。等级状态只用 `未鉴定`、`已有意见待质证`、`停止`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验鉴定程序、重新鉴定条件和人身损害项目与鉴定的接口；`search_template` 只借申请书栏目。工具不可用时继续检材编目；标准选择和法律效果字段停止。

## 五个判断节点

执行顺序和停止条件以 [鉴定方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 鉴定闸与专项分流

医疗损害鉴定、劳动能力鉴定工伤用途、未稳定治疗先停止或转出。

### 2. 事项拆分

致残程度、误工护理营养期限、护理依赖、因果关系、辅助器具、死因分列，禁止合成“鉴定一下能赔多少”。

### 3. 检材与标准

病历、影像、手术记录连续性。标准名称运行时核验，不得用废止标准。

### 4. 机构与程序

协商选定、诉前自行委托、诉中法院委托分列风险。自行委托可能不被采信须明示。

### 5. 申请稿与不可逆提示

事项和检材选择可能锁定意见范围。不预测等级。

## 停止与安全

- `整体停止`：立场不明；用户坚持伪造病历、指定等级或威胁鉴定人。
- `字段停止`：标准、程序规则未核验。
- `目标停止`：主目标变为医疗鉴定、劳动能力鉴定或测算终稿。

严格按 [输出合同](references/output-contract.md) 十节交付。鉴定闸未打开不得交付申请终稿。边界见 [路由](references/routing.md)。
