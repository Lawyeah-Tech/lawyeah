# 准备伤残鉴定材料

## 任务目标

在明确、无利益冲突的单方立场下（受害人、近亲属或其受托律师，互斥），形成发送前伤残或相关鉴定申请草案：鉴定闸、鉴定切片与检材、`Q#` 路径、`JT#` 鉴定行（鉴定切片／事项／标准与稳定／检材／机构与申请接口／`E#` 回链）。本窗 `JT#` 是鉴定行草案，不是鉴定意见，不是已委托，不是已作出，不是已准许，不是测算终稿。本窗闸名只能是鉴定闸，禁止复用伤残闸、申鉴闸、评估闸、求偿闸、侵权闸、名单闸、时效闸、检材闸、申请闸、鉴异闸、发送闸、起诉闸、精算闸、立案闸。预留不得占用：立案闸、起诉闸、精算闸、管辖闸、鉴异闸、发送闸。本窗主行只能是 `JT#`，禁止 `APP#`、`JA#`、`JD#`、`QG#`、`TB#`、`LX#`、`QC#`、`A#`、`N#`。主路径只用 `Q-伤鉴`，禁止用 `Q-鉴`、`Q-申鉴`、`Q-残`、`Q-签`、`Q-责`、`Q-体`、`Q-钟`、`Q-求`、`Q-测`、`Q-诉` 作主路径。邻窗 `Q-伤鉴` 只作转介进本窗；本窗打开为主路径，不是已委托、不是已作出、不是已采信。鉴定闸打开不等于已委托不等于已准许不等于已出具意见不等于伤残已定不等于待提交终稿。治疗未稳定不是开评残切片。先按十级不是开鉴定闸。口述「差不多好了」不是已稳定。申请不是已出具鉴定意见。单方委托不是法院委托。评估报告、刑事伤情、工伤劳鉴不是民事人体损伤致残。GB 18667-2002 道路交通事故受伤人员伤残评定已废止，不是现行。GB/T 16180 工伤劳鉴标准不是民事致残终稿。人体损伤程度鉴定不是伤残。未知不写零。不预测等级。不代提交。不选定法院或鉴定机构。不定残。不定罪。不保证准许或采信。

`depends-on` 为空。主成果是侵权总图转 `评估人身侵权责任`。主成果是已有法院委托意见且只要异议转 `提出伤残鉴定异议或重新鉴定`。主成果是精算工作表转 `测算人身损害赔偿`。主成果是医疗损害鉴定转医疗医药领域。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：人身损害已发生，申请方需要伤残、三期、护理依赖、因果、后续治疗、辅助器具或死因鉴定的发送前材料。「先按十级」「差不多好了」「今晚先评」仍正触发，成果状态 `草案`。稳定、标准、机构未核验仍正触发：有可编号待鉴定事项或检材碎片则鉴定闸打开或半开，第 6 节出 `JT#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出鉴定意见／已委托终稿」才关闸，仍交十节，第 6 节不出 `JT#` 终稿，第 7 节不得出申请终稿或鉴定意见，窗口不关。用户要把申请写成已出具、把单方委托写成法院委托、把先按十级写入事项、把废止道路标准写成现行、把未知写成零，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `JT#` 草案。不得因「不预测等级」「不代提交」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是侵权总图（转 `评估人身侵权责任`）；
- 主成果是精算工作表（转 `测算人身损害赔偿`）；
- 已有法院委托民事致残意见且只要异议或重新鉴定（转 `提出伤残鉴定异议或重新鉴定`）；
- 主成果是多份意见比较终稿（转 `评估伤残等级争议`）；
- 主成果是参与度或既往伤病终稿（转 `评估因果关系与既往伤病`）；
- 主成果是后续治疗费另诉条件终稿（转 `评估后续治疗费另行主张`）；
- 主成果是索赔通知或起诉包（转 `准备侵权索赔通知` 或 `提起人身损害一审`）；
- 主成果是诊疗过错、病历或医疗损害鉴定（转医疗医药领域）；
- 主成果是劳动能力鉴定或工伤待遇（转劳动领域；夹带第三人只开 `评估工伤与第三人侵权竞合` 接口）；
- 人体损伤程度（轻伤／重伤）当伤残主轴（说明不是本窗）；
- 海事船舶伤亡专门鉴定（转海事领域）；
- 尚未发生损害，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）。

双方秘密、伪造或裁剪病历影像、按索赔口径改诊断、倒签鉴定日、威胁鉴定人、违法取证**不在负触发表**，走整体停止。「申请即已出具」「先按十级」「单方委托即法院委托」「废止道路标准即现行」「未知写零」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不预测等级」「不代提交」是交付禁令，不是负触发。主成果才转；出现「鉴定」「评残」「十级」一词不是转出。仅有诉前单方意见、要走证据规定第四十一条申请法院鉴定：正触发本窗，不得写成第四十条重新鉴定。

## 建立工作坐标

确认：评估或申请授权；单方立场；损伤部位与诊断材料；治疗稳定或死亡事实；拟鉴定事项；法域与标准线索；已有鉴定；诉讼或协商阶段；检材控制方。

口头「差不多好了」「先按十级」「今晚先评」只登记 `S#`／`V#`。不得升格已稳定、已委托或已出具，**不得单独算作开闸材料**。可编号待鉴定事项或检材碎片可开闸。本窗不代提交，不选定唯一鉴定机构，不预测等级。

立场只许受害人、近亲属或其受托律师，互斥。保险人／被告等参与方：闸可半开，申请稿节字段停止，不得以受害人名义出申请终稿。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：鉴定闸关闭，仍交十节，不是整体停止。无书面授权但单方立场已闭合、且已有碎片：鉴定闸部分打开，仍交十节，不是整体停止。提出伪造病历、改诊断、倒签鉴定日、威胁鉴定人或违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。开口不等于立场闭合。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 病历材料表面；`R#` 机关或已有鉴定文书；`C#` 委托或授权文本；`L#` 运行时已核验规则或标准；`I#` 判断；`G#` 缺口；`Q#` 路径；`JT#` 鉴定行；`V#` 版本；`E#` 证据形态回链（检材、权源、质证、授权、旧鉴定文书形态，不是已委托证明，不是已出具意见）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`APP#`、`JA#`、`JD#`、`QG#`。技能正文中的条号和标准名是检索锚点，不是已核验 `L#`。文件状态只用 `草案`、`停止`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止合成「已经评残」一笔。未知不写零。申请 ≠ 已出具。单方委托 ≠ 法院委托。口述稳定 ≠ 已稳定。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或文书范本检索。本窗是鉴定申请草稿，范本只借申请书／检材目录／事项／回避栏目，**不要**升格「已委托／已出具／已准许／已评残」。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现申请即已出具、单方即法院委托、废止道路标准即现行、先按十级的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已废止 GB 18667-2002、GB/T 16180 当民事终稿、1991 年道路交通事故处理办法向公安机关十五日评残、2001 年或 2008 年证据规定旧自行委托条、1991／2017 年民诉旧条号当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的标准、期间或准许保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民诉（2023 修正）第七十九条当事人可以申请鉴定，协商确定鉴定人，协商不成由人民法院指定；未申请而法院认为需要的应当委托。证据规定（2019 修正）第三十条释明并指定申请期间；第三十一条逾期不申请或不预交视为放弃申请，不是实体已败诉；第三十四条未经质证不得作为鉴定根据。第四十条重新鉴定不是当然权利。第四十一条自行委托意见对方足以反驳并申请鉴定，法院应予准许，不是第四十条重新鉴定。两院三部《人体损伤致残程度分级》自 2017-01-01 施行，司法鉴定机构和鉴定人统一适用；鉴定时机为治疗终结或临床效果稳定后。噪声：GB 18667-2002 已于 2017-03-23 废止；1991 年道路交通事故处理办法第四十二条向公安机关十五日评残；GB/T 16180 仅职工工伤劳鉴；《人体损伤程度鉴定标准》轻伤重伤不是伤残；2008 年证据规定第二十八条旧自行委托条。技能正文条号和标准名不是 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变启动、标准或重新鉴定接口的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补申请不是已出具、单方不是法院委托、劳鉴不是民事评残、未稳定评残、重新鉴定非当然、废止道路标准不是现行的反例。
- `search_template` 只借鉴定申请书、委托事项、检材目录、回避声明栏目。范本意见栏、机构栏、落款日、此致某院或某所不得升格已委托、已作出、已准许。禁止用鉴定意见书、工伤劳鉴申请、道路评残表、起诉状或合同质量鉴定申请改头换面。

工具不可用时继续检材和 `JT#` 编目；标准、期间、准许字段停止。不得拒跑，不得凭记忆写成已委托、已出具或十级。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、鉴定闸与不关窗

主成果才整案转出。双方秘密、伪造病历、倒签鉴定日第一次停。申请即已出具、先按十级不关窗。闸关仍交十节，第 6 节不出 `JT#` 终稿。利益冲突未解不是整体停止。

### 2. 切片、稳定与检材碎片

致残程度、三期、护理依赖、因果、后续治疗、辅助器具、死因分列。未稳定不得打开评残／护理依赖申请接口。本节禁止出 `JT#` 终稿。

### 3. 鉴定闸与路径 `Q#`

本节禁止出 `JT#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-伤鉴`。

### 4. 鉴定行 `JT#`

鉴定切片、事项、标准与稳定、检材、机构与申请接口。状态 `草案`。禁止升格已委托、已出具、已准许、十级。无 `E#` 不得写已委托或已作出。

### 5. 测算、异议、因果、工伤与起诉接口

测算、异议、因果、工伤竞合、起诉只开接口。第 7 节不得夹带 `JT#` 终稿或鉴定意见绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造或裁剪病历影像、按索赔口径改诊断、倒签鉴定日、威胁鉴定人或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：鉴定闸关闭，仍交十节，不是整体停止。无书面授权但有碎片：鉴定闸部分打开，不是整体停止。利益冲突未解：不是整体停止。指定十级写入事项：该格不支持，不是整体停止。
- `字段停止`：标准、稳定、检材质证、启动路径、施行日未核验。申请即已出具、先按十级、单方委托即法院委托、废止道路标准即现行、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `JT#` 草案。
- `目标停止`：主目标变为测算终稿、异议终稿、医疗鉴定或起诉包。禁止把「先按十级」当作用户错误主张时的目标停止；那是不关窗。

禁止指导伪造病历或威胁鉴定人。不给胜诉率。不定罪。不定残。不选定法院或鉴定机构。不代提交。未知不写零。不预测等级。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。鉴定闸关闭仍交十节，第 6 节不出 `JT#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `JT#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。鉴定闸未打开时不得交付「已委托」或「已出具」。边界见 [路由](references/routing.md)。
