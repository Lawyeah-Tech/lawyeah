# 输出合同

按触发结果选择交付形状。补强闸未打开不得交付手续终稿或保证成功。禁止私下微信或当面和解写成可司法确认。禁止签字即可强制执行或协议等同判决。禁止保证确认或赋强。禁止选定唯一法院或唯一公证处，禁止预填「此致某院」。禁止写死三十日日历截止或把已读写成期间已起算。禁止调解书送达即生效、拒收仍可执行。禁止公证保全写成赋强。禁止用补强固化未知伤残概括弃权。禁止未知金额写零。禁止选边治愈。禁止倒签或伪造调解组织步骤。不代申请。不定残。不保证确认或赋强。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 补强闸关闭或节点 0 整案转出 | 第 1、2、10 节：关闭理由、无执行力明示和最小补证。可附标注停止的 `Pth#`。禁止手续终稿、保证确认、唯一截止日。对第三人民事补强可留时不得因工伤整案转出 |
| 整体停止 | 第 1、10 节。禁止 `Pth#` 材料包、申请草稿、选边、倒签或伪造调解组织方法。双方秘密、倒签调解日期、伪造人民调解组织、要求产出含未知损害概括弃权的确认／赋强主文第一次即停，优先于负触发；无选边治愈，无「坚持」或「高风险确认」门槛 |
| 用户要私下确认、保证赋强、写死三十日、选定某法院、签字即可执行、金额待定仍赋强（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；闸未开则仍只交 1、2、10；不得改走负触发关窗；成果不得标手续终稿 `已形成` 或保证成功 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入手续终稿已形成。双方秘密未解不得进入「部分形成」。每个 `Pth#` 必须带来源和三值判断。`L#` 不得直接抄技能内条号。私下微信可确认、协议等同判决、保证确认、三十日失权若返回则记噪声。稿件状态默认 `草案`。

## 1. 触发、单方立场、授权与成果状态

补强闸开、部分开或关。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。稿件默认 `草案`。不代申请。

## 2. 来源登记与 MCP 调用表

`S/D/R/L/I/G/Pth/W/V`。口头差不多了、已读只登记 `S#`／`V#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 无执行力明示与补强闸

单独民事和解仅合同拘束力，不能直接申请强制执行，必须明示。闸未开不得标手续终稿已形成。禁止协议等同判决。

## 4. 三条路径 `Pth#`

诉讼调解书、人民调解后司法确认、公证赋强分列。材料不足不锁定推荐。私下微信不能走司法确认。争议未闭合不打开赋强。管辖或公证处连结点并列，不选唯一。

## 5. 诉讼调解书条件

须立案或调解立案，成本另列。双方签收生效，最后一方签收日。送达过程≠已签收。拒收不得写成已可执行。

## 6. 司法确认条件与三十日

依法设立的调解组织主持 + 双方共同申请。三十日是期间长度，不是失权日，已读不得起算。逾期仍可就履行或内容起诉。不保证确认。不符驳回可另诉。

## 7. 公证赋强条件与保全区分

给付确定、身份清、债务人书面承诺接受强制执行。概括弃权未知伤残不得固化。公证事项不合法只停赋强格。保全公证 ≠ 赋强。不保证出具执行证书。

## 8. 可逆性风险档 A 与弃权接口

确认裁定、调解书签收、赋强执行证书一旦作出更难反悔。未知伤残、后续治疗默认保留。拟写入确认／赋强主文的概括弃权停止。转介起草窗的 `W#`，本窗不写协议正文。

## 9. 材料清单、失败分流与不代申请草稿

分路径列材料与 `G#`。失败回普通协议或诉讼。已有执行名义才转执行原子。草稿不代申请。不得预填唯一法院。转介起草、起诉、执行、公证保全只点名。

## 10. 缺口、停止项与提示

须列对方最强解释：签字就能强制执行、协议等同判决、私下微信可司法确认、三十日过了就没权利了、已读已经起算、调解书送达即生效拒收也能执行、未立案也能出可执行调解书、保证某区法院确认或某公证处赋强、代申请一定过、金额待定仍可赋强、公证保全就是赋强、保险了结等于人民调解、确认完还能轻易反悔、为了能执行把永不追究写进确认主文无风险、选边即可继续、倒签日期或补一个调解组织就能确认、工伤在认所以对司机的分期不能赋强比较。

本成果不是已提交申请、不是确认裁定、不是调解书、不是赋强公证书、不是执行申请、不是协议正文、不保证确认或赋强、不是唯一截止日。不代申请。
