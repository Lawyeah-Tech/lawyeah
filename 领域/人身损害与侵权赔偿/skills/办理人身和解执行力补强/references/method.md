# 执行力补强方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。稿件状态只用 `草案`、`补强闸关闭`、`提交前待核`、`停止`。禁止准许率、必然获准、唯一截止日、选定法院或唯一公证处、自行宣布伤残等级、必得总额。未知金额不写零。本任务不代申请、不代签署、不代到场，不保证确认或赋强。确认、调解书签收或赋强成功后更难反悔，可逆性必须单列（风险档 A）。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、已失效《合同法》、把私下微信和解写成可司法确认、把签字写成即可强制执行、把调解书送达写成已生效可执行、把三十日写成失权日、把已读写成期间已起算、把公证保全写成赋强、把未知伤残概括弃权写成经确认当然有效、把人身损害写成全国统一可赋强或全国统一不能赋强时记为噪声，不得写入 `L#`。禁止指导倒签、伪造人民调解组织或骗保。

`Pth#` 固定列：`编号｜路径类型（诉讼调解书／人民调解后司法确认／公证赋强）｜程序前提（已立案法院调解／依法设立调解组织主持且双方共同申请／给付确定+债务人书面承诺接受强制执行）｜和解文本来源（微信当面只S#／人民调解协议／法院调解笔录）｜给付是否确定（确定额／分期凭证／争议未闭合则该路径不打开）｜债务人是否承诺接受强制执行（仅赋强；未承诺则赋强不打开）｜双方行为（调解书双方签收；确认须双方共同申请；赋强须债务人承诺）｜权利人适格（本人／法定代理人／近亲属逐名）｜拟确认或拟赋强主文是否含未知伤残概括弃权（含则该行停止，不得补强固化）｜期间（确认：自调解协议生效日起三十日＝期间长度，不是日历截止，已读不得起算；调解书：最后一方签收日；赋强：受理规则待核）｜管辖或公证处连结点并列（不选唯一）｜材料缺口｜失败分流（不予确认／不受理／未出具执行证书 → 起诉或普通协议；已有确认裁定或赋强公证书才转执行原子）｜可逆性（确认／调解书签收／赋强执行证书后更难反悔，风险档A）｜状态（可比较／闸关／字段停止／不打开）｜来源回链`。一行一条路径。禁止一行打包「三条都保证能执行」。

口头报价、微信「行／已读／差不多了」只进 `V#`／`S#`，不得升格 `Pth#` 前提或期间起算。

## 节点 0　分流、立场、补强闸与不关窗

整案转出或闸关闭只交付第 1、2、10 节或标注缺口的路径比较，不得交付手续终稿，不得标确认或赋强 `已形成`。闸部分打开时：仅对前提可回链的路径给出材料草稿，其余行停止或不打开。

| 信号 | 处理 |
| --- | --- |
| 主成果是协议正文或草稿 | 负触发 `起草人身损害和解协议` |
| 主成果是让步档、底线或未闭合报价 | 负触发 `谈判人身损害和解` |
| 主成果是保险人了结或权益转让审查 | 负触发 `审查保险一次性了结弃权` |
| 主成果是调解方案效力或反悔窗口比较 | 负触发 `评估人身调解方案与效力` |
| 主成果是保险先行还是诉讼调解的选择 | 负触发 `选择诉讼调解或保险先行` |
| 已有生效判决、调解书或确认裁定只要执行申请 | 负触发 `执行人身损害生效文书` |
| 执行中分期或以物抵债 | 负触发 `准备人身执行和解` |
| 只要证据固定或送达过程公证 | 负触发 `准备人身案件公证保全`；保全公证 ≠ 赋强 |
| 只要起诉状终稿 | 负触发 `提起人身损害一审`；未立案要拿调解书时本窗闸可关并转介起诉，窗口不关 |
| 只要测算终稿 | 负触发 `测算人身损害赔偿` |
| 纯工伤待遇确认或劳动调解仲裁执行且无第三人民事给付 | 整案转劳动；夹带对第三人民事给付则本窗正触发，工伤段分流，`Pth#` 可留并转介 `评估工伤与第三人侵权竞合` |
| 诊疗过错或医疗鉴定终稿 | 转医疗；对医疗机构的民事给付补强可留 |
| 海事专门和解执行力 | 转海事 |
| 未成争只要改合同 | 审查起草本窗搁置 |

补强闸打开（可出路径比较＋材料草稿，仍不得标已确认／已赋强／必能执行）须同时满足：单方无冲突立场与授权；主成果是补强路径／材料，不是协议可签终稿、调解利弊、生效执行或执行和解；该行路径前提能回链（诉讼调解：已立案或用户接受「未立案须起诉或调解立案、成本另列」；司法确认：已有依法设立调解组织主持的生效调解协议且双方愿共同申请；赋强：给付确定、身份清、债务人书面承诺接受强制执行）；拟确认／拟赋强主文不含未知伤残、未知手术或「永不追究一切」。

闸关闭（仍正触发）：尚未有闭合和解条件；私下微信／当面要求司法确认；金额待定／争议未闭合要求赋强；把签字普通协议当调解书；未立案当调解书已可执行；已读起算三十日或写唯一失权日；保证确认／赋强成功；选定唯一法院或公证处；要求代申请；保险了结文本当人民调解协议；公证保全当赋强。「保证确认」「私下微信去某院确认」本身不得开闸写成手续终稿。

「尚未有和解条件」「私下微信要确认」「保证赋强」「写死三十日」「选定法院」「签字即可执行」「金额待定仍赋强」**不关窗**。闸未开则仍只交 1、2、10 节。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或受害人与侵权人、保险人同时交材料争同一份确认／赋强稿且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出倒签调解日期、出险日或人民调解协议落款日，伪造、假冒或补办人民调解组织或假调解笔录，指导骗保、以确认掩盖犯罪、刑事逼签，隐瞒已收款仍要把总额写成确定给付，或要求把覆盖未知伤残、未知手术或「永不追究一切」写入拟确认或拟赋强主文，then 整体停止；第一次提出即停，不以「坚持」或「高风险确认」为门槛。

## 节点 1　无执行力明示与 `Pth#` 编目

普通民事和解原则上仅合同拘束力，必须明示不能直接申请强制执行。禁止协议等同判决、签完即可执行、口头差不多了即已可申请确认。

三条路径只比较、不代申请、不保证获准、不选定法院或公证处。材料不足不锁定「推荐路径」。一行一条，禁止合成「一定能强制执行」。

检索锚点：民事法律行为对当事人具有法律约束力，不等于强制执行名义。条号不是 `L#`。未核验则执行力结论字段停止，仍必须写出「单独和解不能直接申请强制执行」的明示，该明示不依赖 `L#`。

## 节点 2　诉讼调解书与司法确认

**诉讼调解书。** 须已立案或请求调解立案，未立案成本另列，不得写成未立案即可出可执行调解书。调解书经双方当事人签收后发生法律效力，生效日以最后一方签收日为准。送达过程、邮寄回执、「已读」≠ 已签收。一方拒收：调解不成，不得写成已可申请执行。当事人各方同意在调解协议上签名或盖章后即发生法律效力的，须经人民法院审查确认，不得把微信签名写成该效果。检索锚点：现行民事诉讼法调解书条款（2023 修正后常见第一百条，须运行时核验）。条号不是 `L#`。

**人民调解后司法确认。** 入口是经依法设立的调解组织调解达成的协议，双方自调解协议生效之日起三十日内共同向人民法院申请。私下微信、当面和解、保险一次性了结文本，都不是人民调解协议，该 `Pth#` `现有依据不支持`，窗口不关。不得「签完再补一个调解组织」。三十日是共同申请期间长度，不是请求权失权日，不是未核验日历截止；已读、截图、口头答应不得起算。逾期可能不予受理确认申请，但仍可就协议履行或内容起诉（检索锚点：人民调解法第三十二条、第三十三条；现行民事诉讼法司法确认条款，常见第二百零一条／二百零五条管辖与共同申请、第二百零二条／二百零六条确认有效可执行、不符驳回可另诉）。条号不是 `L#`。未核验则期间效果与管辖字段停止，不得写死某日某院。

确认后裁定调解协议有效的，一方不履行可申请执行；不符合法律规定的，裁定驳回，当事人可变更协议、达成新协议或另行起诉。不保证确认。管辖连结点并列（邀请调解的法院／当事人住所地／标的物所在地／调解组织所在地基层法院等），不选定唯一法院，申请书不得预填「此致某院」。

拟确认主文含未知伤残、未知手术或「永不追究一切」：该行停止，不得为执行力固化未知损害。确认成功后更难反悔，可逆性风险档 A 必须可见。

## 节点 3　公证赋强

赋强打开须同时：具有给付货币、物品或有价证券的内容；债权债务关系明确，对给付内容无异议；债权文书载明债务人不履行时愿意接受强制执行的承诺。检索锚点：公证债权文书赋强条件；范围可包括以支付赔偿金为内容的协议，但公证处是否受理人身损害赔偿待核，不得写成全国统一可赋强或全国统一不能赋强。条号不是 `L#`。

给付不确定、分期「后续另说」、身份不明、争议未闭合、概括弃权未知伤残：赋强行 `现有依据不支持` 或字段停止，不得固化。未载明接受强制执行承诺：不能直接申请执行。公证事项不合法、不真实（公证法不得出具公证书接口）＝**赋强字段停止**，诉讼调解书与司法确认仍可比较，禁止整案停另两条路径。

公证保全、发送过程公证、网页保全 **不等于** 赋强债权文书或执行证书。转介 `准备人身案件公证保全`，本窗不写保全事项终稿。

已出具赋强公证书并符合条件的，可不经诉讼申请执行；本窗不写执行申请终稿，转介 `执行人身损害生效文书`。不保证出具执行证书。不选定唯一公证处。

## 节点 4　材料、失败分流与不代申请草稿

材料清单分路径：身份与授权、和解或调解文本、调解组织主持证明、立案或受理线索、给付确定依据、债务人承诺、双方共同申请意思、近亲属逐名授权。缺哪项列 `G#`，不得编造已具备。

草稿栏目只借范本结构。状态默认 `草案`。闸打开且无停止的 `Pth#` 才得标 `提交前待核`。不代申请、不代签署、不代到场、不编已受理。不利事实不删除。管辖或公证处连结点并列，不得预填唯一机关。

失败分流：确认驳回、赋强不受理、调解书未被签收 → 回普通协议（起草窗）或起诉／继续诉讼。已有确认裁定、生效调解书或赋强执行证书才转执行原子。不得把失败写成「换一家保证能过」。

可逆性：调解书签收、确认裁定、赋强执行证书一旦作出，未知伤残概括弃权几乎锁死。必须写入风险档 A。用户要「确认完还能轻易反悔」：该格 `现有依据不支持`，窗口不关。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过补强闸直接给可提交终稿、保证确认或选定法院。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if C 端只要大众准备包，then 只分流不回改。

判断状态只许三值。口头转述、截图和「已读」不得写成已受理、已签收、已确认、已赋强或期限已起算。事故认定书、调解记录不得单独写成民事终局比例并据此必须确认。

## 本任务回链纪律

本任务成果是「不代申请的人身损害和解执行力补强路径比较与材料准备」。必须包含：单独和解无强制执行力明示。不包含：协议正文终稿、调解方案效力评估、生效文书执行申请、执行和解、证据保全公证、保险了结审查。禁止私下微信可确认。禁止保证确认或赋强。禁止写死三十日。禁止选定法院。禁止用补强固化未知伤残概括弃权。禁止选边治愈。禁止倒签或伪造调解组织。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标手续终稿已形成。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接。
风险档 A：确认、调解书签收或赋强执行名义字段必须单独标可逆性。
