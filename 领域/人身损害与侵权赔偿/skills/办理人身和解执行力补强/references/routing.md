# 边界与路由

## 正触发

已有或即将达成和解，需要补强强制执行力。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 协议起草 | `起草人身损害和解协议` |
| 已有生效文书执行 | `执行人身损害生效文书` |
| 调解利弊评估 | `评估人身调解方案与效力` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动调解仲裁执行 | 劳动领域 |
| 公证事项不合法 | 停止赋强 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“怕对方签了不给钱”正触发。“协议还没写”走起草。“判决已经生效”走执行。
