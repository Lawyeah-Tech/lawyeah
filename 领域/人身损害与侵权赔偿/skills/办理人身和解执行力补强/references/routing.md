# 边界与路由

## 正触发

已有或即将达成给付和解，需要补强强制执行力。尚未有闭合和解条件、私下微信或当面和解要司法确认、保证确认或赋强成功、写死三十日、选定某法院、签字就能强制执行、金额待定仍要赋强、未立案当调解书已可执行，仍正触发：补强闸可关，对应格停止，窗口不关。工伤待遇与对第三人民事给付补强同时出现，仍正触发：工伤段分流劳动，对第三人 `Pth#` 可留。

双方秘密、倒签调解日期、伪造人民调解组织、要求产出含未知损害概括弃权的确认／赋强主文的停止，优先于负触发。不得改走负触发去出一方手续。尚未有和解条件、保证赋强、私下微信要确认不在下表。倒签伪造不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 和解协议正文或草稿 | `起草人身损害和解协议` |
| 让步档、底线或未闭合报价方案 | `谈判人身损害和解` |
| 保险人了结或权益转让文本审查 | `审查保险一次性了结弃权` |
| 法院／人民调解方案效力或反悔窗口比较 | `评估人身调解方案与效力` |
| 保险先行还是诉讼调解的路径选择 | `选择诉讼调解或保险先行` |
| 已有生效判决、调解书或确认裁定的强制执行申请 | `执行人身损害生效文书` |
| 执行中分期或以物抵债 | `准备人身执行和解` |
| 证据固定或送达过程公证 | `准备人身案件公证保全` |
| 起诉状终稿 | `提起人身损害一审` |
| 分项测算终稿 | `测算人身损害赔偿` |
| 纯工伤待遇确认或劳动调解仲裁执行且无第三人民事给付 | 劳动领域 |
| C 端只要大众准备包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「把调解日期倒签到上周」「公章用某社区人民调解委员会做成已调解」不在本表，走整体停止。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 仅工伤待遇确认或劳动调解仲裁执行且无第三人民事给付 | 劳动领域 |
| 诊疗过错或医疗鉴定终稿 | 医疗医药领域；对医疗机构的民事给付补强可留 |
| 海事专门和解执行力 | 海事领域 |
| 指导倒签、伪造调解组织、骗保或以确认掩盖犯罪 | 整体停止 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。对第三人民事补强可留。公证事项不合法只停赋强字段，不整案转出另两条路径。

## 易混

「怕对方签了不给钱，要能强制执行」正触发。「协议还没写」走起草。「判决已经生效」走执行。「执行里再分期」走执行和解。「先把网页和监控公证下来」走保全公证，不是赋强。「微信八万了结，残了也不再赔，去某区法院司法确认，保证赋强成功，三十天过了就没权利了」仍正触发；补强闸关；私下微信不能确认；保证赋强、写死三十日、选定法院各格不支持。「工伤还在认，和司机的分期要赋强防跑路」正触发，对司机路径可比较，工伤段分流。「两边材料都给你，选边办确认，日期改到上周并盖某调委会章」整体停止。
