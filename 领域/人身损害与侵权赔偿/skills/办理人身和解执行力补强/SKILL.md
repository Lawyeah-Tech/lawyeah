# 办理人身和解执行力补强

## 任务目标

在明确、无利益冲突的单方立场下，形成人身损害和解执行力补强包：补强闸、`Pth#` 三条路径比较（诉讼调解书／人民调解后司法确认／公证赋强）、单独和解无强制执行力明示、材料清单、失败分流、可逆性风险。不代申请、不代签署、不代到场。不保证法院确认或公证赋强。不选定唯一法院或唯一公证处。不写死三十日日历截止。确认裁定、调解书签收或赋强执行证书一旦作出，反悔窗口窄，必须升格风险档 A。未知伤残、后续治疗默认保留，不得为了「能执行」写入拟确认或拟赋强主文。

`depends-on` 为空。协议正文转 `起草人身损害和解协议`。让步档转 `谈判人身损害和解`。保险了结审查转 `审查保险一次性了结弃权`。调解利弊转 `评估人身调解方案与效力`。已有生效文书要执行转 `执行人身损害生效文书`。执行中分期转 `准备人身执行和解`。证据或送达过程公证转 `准备人身案件公证保全`。尚未起诉拿调解书转介 `提起人身损害一审`。

## 工作边界

正触发：已有或即将达成给付和解，需要补强强制执行力。尚未有闭合和解条件、私下微信或当面和解要司法确认、保证确认或赋强成功、写死三十日、选定某法院、签字就能强制执行、金额待定仍要赋强、未立案当调解书已可执行，仍正触发：补强闸可关，对应格填 `现有依据不支持` 或字段停止，窗口不关，不得改走负触发，不得标手续终稿已形成。工伤待遇与对第三人民事给付补强同时出现：本窗正触发，工伤段分流劳动，对第三人的 `Pth#` 可留。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是和解协议正文或草稿（转 `起草人身损害和解协议`）；
- 主成果是让步档、底线或未闭合报价方案（转 `谈判人身损害和解`）；
- 主成果是审查保险人一次性了结或权益转让文本（转 `审查保险一次性了结弃权`）；
- 主成果是比较法院／人民调解方案效力或反悔窗口（转 `评估人身调解方案与效力`）；
- 主成果是保险先行还是诉讼调解的路径选择（转 `选择诉讼调解或保险先行`）；
- 已有生效判决、调解书或确认裁定只要强制执行申请（转 `执行人身损害生效文书`）；
- 执行程序中的分期或以物抵债（转 `准备人身执行和解`）；
- 只要证据固定或送达过程公证（转 `准备人身案件公证保全`）；
- 只要起诉状终稿（转 `提起人身损害一审`）；
- 只要测算终稿（转 `测算人身损害赔偿`）；
- 纯工伤待遇确认或劳动调解仲裁执行且无第三人民事给付（转劳动）；
- C 端只要大众准备包（只分流）；
- 未成争改合同（审查起草搁置）。

尚未有和解条件、私下微信要确认、保证赋强、写死三十日、选定法院、签字即可执行**不在负触发表**，窗口不关。倒签调解日期、伪造人民调解组织、双方秘密、要求把未知伤残概括弃权写入拟确认或拟赋强主文**不在负触发表**，走整体停止。

## 建立工作坐标

确认：使用者与授权；单方立场；和解文本来源（微信／当面只登记 `S#`，人民调解协议、法院调解笔录另登 `D#`／`R#`）；是否已立案；调解组织是否依法设立；给付是否确定；债务人是否承诺接受强制执行；双方是否愿共同申请或共同到场；拟确认／拟赋强主文是否含未知伤残或「永不追究一切」；权利人适格（法定代理人、近亲属逐名）；法域。

口头「差不多了」、微信「行／已读」只登记 `S#`／`V#`。不得升格为已有人民调解协议、期间已起算、已签收调解书或已可申请执行。用户坚持「保证确认」「交到某区法院」不构成选定法院或保证获准的授权。

同时掌握双方秘密，或受害人与侵权人、保险人同时交材料争同一份确认／赋强稿：`整体停止`，不得以选边治愈，也不得改走负触发去出一方手续。受害人已开口且委托范围就是执行力补强、且未掌握对方秘密时，可推定单方立场。只要同时掌握双方秘密，无例外整体停止。提出倒签调解日期或出险日、伪造或假冒人民调解组织、补办假调解笔录、指导骗保、以确认掩盖犯罪、要求把覆盖未知伤残或「永不追究一切」写入拟确认或拟赋强主文：第一次提出即整体停止，不以「坚持」或「高风险确认」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 和解或调解文本；`R#` 立案、调解组织或公证受理线索；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Pth#` 路径；`W#` 拟写入确认／赋强主文的弃权；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。稿件状态只用 `草案`、`补强闸关闭`、`提交前待核`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。不准许率。本任务默认 `草案`，不代申请。禁止「保证确认」「协议等同判决」。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：私下民事和解原则上仅合同拘束力，不能直接申请强制执行；诉讼调解书经双方当事人签收后发生法律效力，生效日以最后一方签收日为准；经依法设立的调解组织调解达成调解协议，双方可自调解协议生效之日起三十日内共同申请司法确认；符合规定的，裁定调解协议有效，一方不履行的可申请执行；不符合的，裁定驳回，当事人可变更协议或另行起诉；公证债权文书赋强须以给付为内容、债权债务明确、债务人承诺接受强制执行。技能正文条号不是 `L#`。噪声：已失效《侵权责任法》、已失效《合同法》、签字即可强制执行、私下微信和解可司法确认、调解书送达即生效、拒收仍可执行、三十日＝失权日、已读起算、保证确认或赋强、选定唯一法院、代申请、协议等同判决、未知伤残概括弃权经确认即当然有效、公证保全＝赋强、人身损害全国统一可赋强或全国统一不能赋强。不可用则确认条件、调解书生效时点、三十日效果、赋强受理字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变司法确认范围、赋强条件、申请期间或执行力结论的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补私下和解不受理司法确认、争议未闭合人身损害赋强不受理、确认失败回诉讼、公证处受理范围地区差异、不保证确认成功的实务反例。
- `search_template` 只借司法确认申请、调解书内容栏目或赋强公证申请栏目，不把范本当法定格式、已提交文本、发送版或指定唯一法院／公证处。

工具不可用时继续 `Pth#` 编目与无执行力明示；条件、期间、管辖、赋强效力字段停止。不得凭记忆写成私下和解可强制执行或保证确认。

## 判断节点

执行顺序和停止条件以 [执行力补强方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、补强闸与不关窗

工伤三段分流，对第三人民事补强可留。双方秘密、倒签、伪造调解组织第一次停。尚未有和解条件、私下微信要确认、保证赋强不关窗。只要协议草稿负触发。

### 2. 无执行力明示与 `Pth#` 编目

单独民事和解仅合同拘束力，必须明示不能直接申请强制执行。三条路径分列，禁止打包保证能执行。

### 3. 诉讼调解书与司法确认

调解书须双方签收，送达过程≠已生效。司法确认须依法设立的调解组织主持且双方共同申请。私下微信或当面和解不能确认。三十日是期间长度，已读不得起算。

### 4. 公证赋强

给付确定、身份清、债务人书面承诺接受强制执行。争议未闭合、金额待定、概括弃权未知伤残：赋强行停止。公证事项不合法只停赋强格，另两条仍可比较。公证保全≠赋强。

### 5. 材料、失败分流与不代申请草稿

材料不足不锁定推荐路径。失败回诉讼或普通协议。不保证成功。不代申请。已有确认裁定或赋强公证书才转执行原子。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；受害人与侵权人、保险人同时交材料；倒签调解日期、出险日或人民调解协议落款日；伪造、假冒或补办「依法设立的人民调解组织」或假调解笔录；指导骗保、伪造伤情或票据、以确认掩盖犯罪、刑事逼签；隐瞒已收款仍要把总额写成确定给付；要求把覆盖未知伤残、未知手术或「永不追究一切」写入拟确认或拟赋强主文。整体停止优先于负触发。不以「坚持」或「高风险确认」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：司法确认范围、调解书生效时点、三十日期间效果、赋强受理条件、管辖未核验。补强闸未开则手续终稿停止，窗口不关。用户要私下确认、保证确认或赋强、写死三十日、选定唯一法院、签字即可执行或金额待定仍赋强则该格停止，窗口不关。
- `目标停止`：主目标变为协议起草、谈判方案、保险弃权审查、调解利弊评估、生效文书执行申请、执行和解、证据公证或起诉状。尚未有和解条件、保证赋强不在目标停止。

禁止指导倒签、伪造调解组织或骗保。不给准许率。不选定法院。不代申请。不编唯一截止日。不把未知写成零。不定残。不保证确认或赋强。
