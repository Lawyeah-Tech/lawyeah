# 边界与路由

## 正触发

同一人身损害事实下，既可能主张客运、旅游或其他非诊疗服务合同或产品买卖合同违约，又可能对合同相对方主张人身侵权，需要比较或排列主备位接口。客运、旅游在窗内。诊疗过错即使存在医疗服务合同也不在窗内。

受害人开口且委托范围是路径比较时，不因口语化咨询整体停止。双方秘密、对同一相对方双份全额或伪造合同的停止，优先于负触发。对不同被告一并主张不是负触发。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同或出稿 | 审查起草（本窗搁置） |
| 诊疗过错主轴 | 医疗医药领域 |
| 纯质量价款无人身伤害 | 合同争议领域 |
| 海事运输 | 海事领域 |
| 只要产品惩罚性终稿 | `评估产品惩罚性赔偿` |
| 只要产品缺陷路径终稿 | `评估产品致人损害` |
| 只要承运人责任、限额或专门法院终稿 | `评估铁路航空等非海事承运人人身损害` |
| 只要管辖选定 | `评估人身损害管辖` |
| 只要时效截止日 | `评估人身损害诉讼时效` |
| 只要测算终稿 | `测算人身损害赔偿` |
| 只要起诉状 | `提起人身损害一审` |
| 只要工伤与第三人分账 | `评估工伤与第三人侵权竞合` |
| 只要侵权总图且无需竞合比较 | `评估人身侵权责任` |

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 铁路、航空旅客伤害的归责、限额、专门法院 | `评估铁路航空等非海事承运人人身损害` |
| 道路客运或他车导致的急刹、交强险顺序 | `评估道路交通事故责任与保险先行` |
| 缺陷产品、生产者销售者 | `评估产品致人损害` |
| 明知缺陷或欺诈的惩罚性、消法三倍 | `评估产品惩罚性赔偿` |
| 场所、景区、酒店安保 | `评估场所安全保障义务` |
| 司机执行工作任务 | `评估用人者责任` |
| 告谁、交强险或责任险能否进共同被告 | `评估责任主体与保险覆盖` |
| 精神损害严重性与酌定 | `评估精神损害赔偿` |
| 分项数字 | `测算人身损害赔偿` |
| 民事评残 | `准备伤残鉴定材料`（闸关则禁止启动） |
| 时效起算或截止日 | `评估人身损害诉讼时效` |
| 连结点效力或选定法院 | `评估人身损害管辖` |
| 已选定后的起诉 | `提起人身损害一审` |
| 已选定后的发函 | `准备侵权索赔通知` |
| 工作中或上下班夹带第三人/客运伤害 | `评估工伤与第三人侵权竞合` |

## 易混

「坐车受伤，告违约还是侵权」正触发。「把服务合同改得更安全」是审查起草，搁置。「产品和经营者怎么赔」若主成果是缺陷产品责任，转 `评估产品致人损害`，本任务只做路径比较。「跟团游大巴出事，旅行社和车队一起告」正触发：对旅行社适用择一比较，对实际承运人并行编目，不是第一百八十六条全球互斥。「只要精神抚慰金多少」转 `评估精神损害赔偿`。「选侵权就能避开仲裁」禁止写成结论。
