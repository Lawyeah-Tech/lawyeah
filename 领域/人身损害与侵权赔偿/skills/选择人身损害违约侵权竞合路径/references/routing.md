# 边界与路由

## 正触发

同一事实可主张客运、旅游、医疗服务以外的服务或产品合同违约，同时可主张人身侵权，需要选择或主备位排列。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争改合同 | 审查起草（本窗搁置） |
| 诊疗过错主轴 | 医疗医药领域 |
| 纯质量价款无人身伤害 | 合同争议领域 |
| 海事运输 | 海事领域 |
| 只要产品惩罚性终稿 | `评估产品惩罚性赔偿` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 诊疗过错、医疗损害鉴定 | 医疗医药领域 |
| 工伤待遇 | 劳动领域 |
| 海上运输 | 海事领域 |
| 未成争审查起草 | 本窗搁置，只说明 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“坐车受伤，告违约还是侵权”正触发。“把服务合同改得更安全”是审查起草，搁置。“产品和经营者怎么赔”若主成果是缺陷产品责任，可转产品致害专项，本任务只做路径比较。
