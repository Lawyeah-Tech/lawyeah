# 竞合选择方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。项目可主张性只用 `可主张`、`不可主张`、`待核`、`无法估计`。不得输出胜诉率、必然路径或唯一必得总额。未知金额不写零。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、已失效《合同法》（含第一百二十二条）、合同法解释（一）第三十条、2010 年旅游纠纷规定第二十一条（违约之诉不支持精神损害）或写「违约以过错为主」的旧说时记为噪声，不得写入 `L#`。

两条路径分列 `Q-违` 与 `Q-侵`。不得合成「合同侵权责任」一笔。用户未选定不得锁定主备位。

---

## 节点 0　分流与合同版本

整案转出只交付第 1、2、10 节。

若 if 主轴是诊疗过错、病历真实性或医疗损害鉴定，then 转医疗医药，即使存在医疗服务合同。
若 if 尚未发生损害只要改条款或出稿，then 审查起草本窗搁置，只说明不实施。
若 if 无人身伤害只有质量价款，then 转合同争议领域。
若 if 海上运输、船舶碰撞或海事保全，then 整案转海事。
若 if 主成果只要承运人责任、限额或铁路航空专门法院，then 负触发至 `评估铁路航空等非海事承运人人身损害`。
若 if 主成果只要产品缺陷路径，then 负触发至 `评估产品致人损害`。
若 if 主成果只要工伤与第三人分账，then 负触发至 `评估工伤与第三人侵权竞合`；出差或上下班夹带客运伤害时，本窗可留对承运人的竞合比较，工伤分账只标接口。

合同扫描件、电子订单、发票、客票冲突并列，不选有利版本冒充唯一文本。口头转述的条款不得覆盖文本 `D#`。截图不得标原件。

## 节点 1　同一相对方与不同被告

检索锚点：民法典第一百八十六条。因当事人一方的违约行为损害对方人身权益、财产权益的，受损害方有权选择请求其承担违约责任或者侵权责任。择一只约束**同一合同相对方的同一行为**。

若 if 请求针对同一相对方的同一违约/侵权事实，then 两列比较后由受害人选择；禁止对同一相对方就同一损失双份全额。用户提出双份全额：整体停止，第一次提出即停。
若 if 另有合同外第三人（实际承运人、司机、旅游辅助服务者、生产者、场所经营者），then 对该第三人的请求**不是**第一百八十六条全球互斥。可与对相对方的请求并行编目；同一医疗费、残疾赔偿金等项目填平，不得双份领取。禁止把「一起告旅行社和实际承运人」写成负触发。
旅游纠纷规定（2020 修正）第三条：因旅游经营者方面的同一原因造成人身损害，对**旅游经营者**按当事人选择的案由审理。第四条：因辅助服务者原因导致经营者违约，仅诉经营者时可以追加辅助服务者为第三人。两处只作检索锚点，主体分列待核。

禁止把预备合并写成当然可以。竞合择一与顺位预备实务分裂，该格 `待核`。起诉结构转入 `提起人身损害一审`，本窗不写请求项。合同法解释（一）第三十条（一审开庭以前变更选择）已废止，禁止当现行；变更时点按民诉解释第二百三十二条、证据规定第五十三条运行时核验。

## 节点 2　两路径成立条件比较格

`Q-违`：合同成立及生效、义务内容、违反事实、与人身损害的因果。客运事实命中时，承运人旅客伤亡比较格检索锚点为民法典第八百二十三条：承运人对运输过程中旅客的伤亡承担赔偿责任；免责为旅客自身健康原因，或承运人证明伤亡是旅客故意、重大过失造成。禁止把违约写成以过错为主。本窗只填比较格，承运人责任意见、限额、专门法院转入 `评估铁路航空等非海事承运人人身损害`；道路客运交强险顺序转入 `评估道路交通事故责任与保险先行`。
`Q-侵`：一般过错或产品、机动车、场所等特殊路径只打转介红旗，条件终稿分别转入总体评估或场景专项。产品缺陷：侵权产品责任与买卖违约分列，惩罚性接口转 `评估产品惩罚性赔偿`。场所/景区/酒店：安保过错转入 `评估场所安全保障义务`。司机执行任务转入 `评估用人者责任`。
举证责任必须分列：`Q-违` 通常证合同与违约事实，第八百二十三条免责由承运人证；一般侵权由主张方证过错；产品对生产者的缺陷与因果按产品专项待核。不得合成一笔举证。

## 节点 3　时效、管辖、仲裁比较

时效：一般均为三年，起算事件可能不同。分列情景，不输出唯一截止日，细节转介 `评估人身损害诉讼时效`。口头转述、截图和「已读」不得写成已催告到达、已受理或期限已起算。

管辖：合同履行地或被告住所地 vs 侵权行为地或被告住所地，只列连结点**类型**。**任何情况下都不选定唯一法院**。人身侵权损害赔偿的协议管辖不得标打开。违约路径协议管辖只登记 `C#`，不升格为唯一受诉法院。用户点名某院只登记 `S#`。铁路旅客运输等专门管辖红旗命中：普通民诉入口停止，转介承运人专项，不写死某铁路运输法院。住院地默认不打开。细节转介 `评估人身损害管辖`。

仲裁：

- 不得直接写「选侵权就能避开仲裁」。
- 合同仲裁条款对**基于该合同、针对合同相对方**的侵权之诉原则上可能有约束力，须核验，不写必然约束或必然不约束。未核验则对该相对方的诉讼入口字段停止。
- 合同外第三人（生产者、实际承运人、司机、场所经营者）不当然受该仲裁约束，其诉讼入口不得因相对方仲裁而整案关闭。
- 或裁或诉、机构不明：对该相对方诉讼入口停止待核。
- 交强险保单仲裁不阻断对侵权人及交强险法定共同被告起诉；保险接口转入 `评估责任主体与保险覆盖`。禁止「已赔可不列」。

## 节点 4　赔偿范围与精神损害

检索锚点：民法典第九百九十六条。因违约损害对方人格权并造成严重精神损害，受损害方选择请求承担违约责任的，不影响其请求精神损害赔偿。禁止写成「违约通常不赔精神损害」或「侵权路径通常更直接」。未核验严重性或人格权损害时，该格 `待核`，不写成违约必得或必不得。酌定与金额转入 `评估精神损害赔偿`。2010 年旅游纠纷规定第二十一条（违约之诉不支持精神损害）为噪声。

检索锚点：民法典第五百八十四条。违约损害赔偿受可预见规则约束，与侵权固有利益路径分列。禁止把违约金与全部侵权项目简单相加。禁止把残疾赔偿金默认为违约可得利益。

检索锚点：民法典第五百零六条。造成对方人身损害的免责条款无效。客票、行程单、格式须知上的免责条款表面存在不等于有效。

惩罚性：民法典第一千二百零七条与消费者权益保护法第五十五条分列，只标接口，转入 `评估产品惩罚性赔偿`。禁止把价金三倍与人身惩罚性加总为双份惩罚。本窗不写倍数或总额。

被扶养人生活费只作计入接口。未知不写零。金额参数转入 `测算人身损害赔偿`。鉴定闸关闭不得转介启动评残。

## 节点 5　选择、互斥与既判力

选择权主体是受害人。法院可释明法律关系性质（证据规定第五十三条待核），技能不得代选，也不得把释明写成应当改选某路径。

用户未选定：只输出比较表，不擅自锁定主备位。
已选定：写明对**该相对方**放弃另一路径的程序效果和再主张风险。不得删除对照列。
一条路径已经裁判实现：另一请求权对同一相对方有消灭风险，标 `待核`。
败诉后再主张另一路径：构成民诉解释第二百四十七条重复起诉的风险 `待核`。禁止写成「败诉后一定可以再告另一条」。

保险能否因路径选择进入共同被告：只标接口，转入 `评估责任主体与保险覆盖`。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过专项分流直接给实体结论。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密且未获冲突豁免，then 整体停止，不得选边治愈。
若 if 用户提出对同一相对方同一损失双份全额，或指导伪造合同、变造客票、倒签仲裁条款、伪造伤情、隐匿既往、威胁或违法取证，then 整体停止；第一次提出即停。
若 if 日期、送达、仲裁约束或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日，不选定法院。
若 if 金额参数不足，then 该行标未知或 `无法估计`，禁止写零冒充已发生。

事故认定书、调解记录不得单独写成民事终局比例。判断状态只许三值。

## 本任务回链纪律

本任务成果是「违约与侵权竞合比较表」。不包含：承运人责任意见、产品缺陷路径、精神损害酌定、测算总额、选定法院、起诉状、工伤分账矩阵。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`，已停止字段逐行列出待核事项。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接：已固定事实时间线、合同版本、主体表和缺口。
风险档 A：不可逆文书或期限字段必须单独标可逆性。
