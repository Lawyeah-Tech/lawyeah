# 竞合选择方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、论坛、期限、主体或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然责任比例或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

两条路径分列 `Q-违` 与 `Q-侵`。选择后互斥须可见。不得引用已失效《合同法》第一百二十二条当作现行条文。现行选择权锚点为民法典第一百八十六条，须运行时核验。

## 节点 0　分流与合同版本

若 if 主轴是诊疗过错或病历真实性，then 转医疗医药，即使存在医疗服务合同。
若 if 尚未发生损害只要改条款，then 审查起草本窗搁置，只说明不实施。
若 if 无人身伤害只有质量价款，then 转合同争议领域。
合同扫描件、电子订单、发票、客票冲突并列，不选有利版本冒充唯一文本。

## 节点 1　两条路径成立条件

`Q-违`：合同成立及生效、义务内容、违反事实、与人身损害的因果。客运承运人责任条件须核验合同编运输合同，不得凭记忆写无过错或过错。
`Q-侵`：按一般过错或产品、机动车等特殊路径分别建条件，转介总体评估或场景专项，本任务只比较。
若 if 产品缺陷致人身损害，then 侵权产品责任与买卖合同违约分列，惩罚性赔偿接口转 `评估产品惩罚性赔偿`。
不得把两条路径合成“合同侵权责任”一笔。

## 节点 2　时效、管辖、仲裁比较

时效：一般均为三年，但起算事件可能不同。分列，不输出唯一截止日，细节转介时效评估。
管辖：合同履行地或被告住所地 vs 侵权行为地或被告住所地。仲裁条款若覆盖合同请求，对侵权请求是否约束须核验，未核验则诉讼入口字段停止。
不得直接写“选侵权就能避开仲裁”。

## 节点 3　赔偿范围与精神损害

若 if 用户主要追求精神损害，then 标明侵权路径通常更直接，违约路径是否支持须核验，未核验不写成违约必得精神损害。
若 if 用户主要追求合同约定的违约金，then 标明与侵权损害赔偿的互斥或吸收关系待核，禁止把违约金与全部侵权项目简单相加。
被扶养人生活费只作计入接口。未知不写零。

## 节点 4　选择、主备位与禁止双赔

用户未选定：输出比较表，不擅自锁定。
已选定：写明放弃另一路径的程序效果和再主张风险。
起诉状中把两套请求写成预备合并可以，但金额不得叠加为双份。
本任务不生成诉状终稿。


## 证据与下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。

下一步按期限灭失、易失证据、改变请求抗辩、可逆性排序。相邻文书或评估只写转介条件和最小交接。禁止指导伪造伤情、隐匿既往、威胁、倒签或违法取证。

未选定前不得在起诉包中同时把两套请求写成可叠加总额。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过专项分流直接给实体结论。

若 if 使用者与授权或单方立场无法闭合，then 整体停止，不输出请求、抗辩或金额结论。
若 if 同时掌握双方秘密且未获冲突豁免，then 先停止策略输出，只列需要用户选择的代表方。
若 if 主轴是工伤认定、劳动能力鉴定或工伤待遇，then 整案转劳动领域，本任务只交最小分流理由。
若 if 主轴是诊疗过错、病历真实性或医疗损害鉴定，then 整案转医疗医药领域。
若 if 主轴是海上运输、船舶碰撞或海事保全，then 整案转海事领域。
若 if 尚未发生损害且只要改合同或出稿，then 审查起草本窗搁置，只说明不实施。
若 if 用户坚持伪造伤情、隐匿既往、倒签、威胁或违法取证，then 整体停止并记录禁止事项。
若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if 金额参数不足，then 该行标未知，禁止写零冒充已发生。
若 if C 端 007、006、场所摔伤、保险理赔、011、012 或工伤初期测算只要大众准备包，then 只分流不回改。

口头转述、截图和“已读”不得写成已受理、已送达或期限已起算。事故认定书、调解记录不得单独写成民事终局比例。

判断状态只许三值。禁止胜诉率、必然责任比例和唯一必得总额。

## 本任务回链纪律

本任务成果是「选择违约与侵权竞合路径」：同一事实可主张客运、服务或产品违约与侵权；单方。
不得把本成果写成相邻原子终稿。不包含：人身伤害主轴留本领域；未成争改合同转审查（搁置）；不双份重复索赔。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`，已停止字段逐行列出待核事项。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接：已固定事实时间线、主体表和缺口。
风险档 A：不可逆文书或期限字段必须单独标可逆性。
