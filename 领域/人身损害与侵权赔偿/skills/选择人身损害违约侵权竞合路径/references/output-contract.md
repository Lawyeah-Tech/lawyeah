# 输出合同

按触发结果选择交付形状。禁止对同一相对方双份全额。禁止把不同被告的并行请求写成民法典第一百八十六条全球互斥。禁止选定唯一法院。禁止代写诉状。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出（诊疗主轴 / 纯质量价款 / 海事；主成果仅未成争改合同则搁置说明） | 第 1、2、10 节。禁止比较矩阵、金额、管辖选定、主备位策略 |
| 整体停止 | 第 1、10 节。禁止请求矩阵和选择策略。双方秘密、对同一相对方双份全额、伪造合同时，整体停止优先于负触发 |
| 正触发且可比较 | 下列十节表头均出现；未核验的单元格填 `依据不足，无法形成结论` 或 `待核` 或 `无法估计`；禁止省略后改填估计数、零、唯一法院或双份总额 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。双方秘密未解不得进入「部分形成」。每个比较格必须带可主张性状态。

## 1. 触发、单方立场、授权与成果状态

写明是否构成对同一相对方的竞合、是否另有合同外第三人、受限字段。双方秘密未解不得进入「部分形成」。

## 2. 来源登记与 MCP 调用表

合同、客票、订单冲突版本必须编号。`L#` 不得直接抄技能内条号。MCP 未调用也留一行。

## 3. 合同文本与义务定位

冲突版本并列，不选有利版本。口头转述不得覆盖 `D#`。不在此写承运人免责成立或产品缺陷成立。

## 4. `Q-违` 与 `Q-侵` 成立条件与主体、举证

两列分列，不合成一笔。列明合同相对方与合同外第三人。举证责任分列。特殊侵权、产品缺陷、承运人归责、场所安保只标转介。

## 5. 时效管辖仲裁比较表

起算情景分列，不输出唯一截止日。连结点类型分列，不选定唯一法院；人身侵权协议管辖不得打开；用户点名某院只作 `S#`。仲裁对相对方与对第三人分列；禁止写选侵权当然避开仲裁。专门法院只红旗转介。

## 6. 赔偿范围比较

精神损害、违约金、惩罚性、可得利益**是否可主张**分列。金额只作接口或 `无法估计`，未知不写零。第九百九十六条未核验不得写成违约必得或必不得精神损害。惩罚性倍数转入 `评估产品惩罚性赔偿`。禁止把消法价金三倍与人身惩罚性加总。

## 7. 用户选定状态与互斥

用户未选定：只出比较表，不填主备位锁定。已选定：写明对该相对方放弃另一路径的程序效果。预备合并是否准许 `待核`。裁判实现后另一请求权消灭风险、败诉后再主张另一路径的重复起诉风险均 `待核`。禁止「败诉后一定可以再告另一条」。禁止金额叠加为双份。

## 8. 最强反方

格式条款、仲裁、第五百零六条人身伤害免责（表面存在不等于有效）、承运人免责抗辩、一事不再理。不把未出示的免责条款写成已存在。

## 9. 下一步

只转介：总图、主体保险、时效、管辖、测算、精神损害、产品/承运人/道路交通/工伤竞合、评残闸、发函、起诉。禁止在此写诉状或发送函。鉴定闸关闭不得转介启动评残。

## 10. 缺口、停止项与提示

须列对方最强解释（选侵权当然避开仲裁、违约必不得精神损害、两条路径金额相加、客运绝对无过错、不同被告也必须择一、败诉后一定可以再告另一条）与证据缺口。

本成果不是诉状、承运人意见、产品路径、测算、管辖选定或工伤分账。
