# 选择人身损害违约侵权竞合路径

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成「违约与侵权竞合比较表」：对合同相对方的 `Q-违` 与 `Q-侵` 分列成立条件、时效起算情景、管辖连结点类型、仲裁红旗、举证责任、主体范围和项目可主张性；写明同一相对方择一与不同被告并行的分界。不出具承运人责任意见、产品缺陷路径、精神损害酌定、测算总额、选定法院或诉状。

`depends-on` 为空。接受等价事实、合同文本、测算、鉴定和证据清单。

## 工作边界

正触发：同一人身损害事实下，既可能主张客运、旅游或其他非诊疗服务合同或产品买卖合同违约，又可能对合同相对方主张人身侵权，需要比较或排列主备位接口。客运、旅游在窗内。诊疗过错即使存在医疗服务合同也不在窗内。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未成争，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）；
- 诊疗过错医疗损害主轴（转医疗医药）；
- 纯合同质量价款无人身伤害（转合同争议）；
- 海事运输（转海事）；
- 只要产品惩罚性终稿（转 `评估产品惩罚性赔偿`）；
- 只要承运人责任、限额或铁路航空专门法院终稿（转 `评估铁路航空等非海事承运人人身损害`）；
- 只要管辖选定或唯一截止日（转 `评估人身损害管辖` / `评估人身损害诉讼时效`）；
- 只要测算终稿或起诉状（转 `测算人身损害赔偿` / `提起人身损害一审`）；
- 只要工伤与第三人分账（转 `评估工伤与第三人侵权竞合`）；
- 只要侵权总图且无需竞合比较（转 `评估人身侵权责任`）。

对同一相对方提出双份全额、伪造合同或双方秘密，走整体停止，不走负触发。对不同被告一并主张不是负触发。

本任务不生成发送版解约函或诉状。不把已失效法律当作现行请求权基础。不选定唯一法院。不输出唯一截止日或必得总额。

## 建立工作坐标

确认：使用者与授权；单方立场；合同名称与版本；是否客运、旅游、产品买卖或非诊疗服务；人身损害事实；仲裁或协议管辖条款；已主张路径；可能被告是否超出合同相对方；法域。

同时掌握双方秘密或未解利益冲突：`整体停止`，不得以选边治愈，也不得改走负触发去出比较策略或诉状。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 合同、客票、订单；`R#` 机关文书；`C#` 条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q-违` / `Q-侵` 比较格；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。项目可主张性只用 `可主张`、`不可主张`、`待核`、`无法估计`。技能正文中的条号是检索锚点，不是已核验 `L#`。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验选择权、违约路径精神损害、人身伤害免责条款、违约损失范围、客运比较格等将被写入 `L#` 的现行规则；不可用则这些字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变择一、互斥或违约路径精神损害可赔性的条文正文再写入 `L#`。不得编造 `regulation_id`，也不得把摘要条号写成已核验 `L#`。
- `search_practiced` 补仲裁条款是否约束基于该合同的侵权之诉、预备合并与禁止双赔的实务反例。

工具不可用时继续合同版本、损害事实和两列编目。不得凭记忆写成违约以过错为主、违约必不得精神损害，或选侵权当然避开仲裁。

## 判断节点

执行顺序和停止条件以 [竞合选择方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流与合同版本

医疗、海事、未成争改合同、纯质量价款整案转出。先固定冲突版本，不选有利文本。

### 2. 同一相对方与不同被告

民法典第一百八十六条择一只约束同一相对方的同一行为。合同外第三人可并行请求，同一项目填平。

### 3. 两路径成立条件比较格

`Q-违` 看合同义务违反；`Q-侵` 看归责与损害。不合成「合同侵权责任」。承运人、产品、场所只标转介。

### 4. 时效、管辖、仲裁比较

起算情景和连结点类型分列。不选定法院，不写唯一截止日。不得写选侵权当然避开仲裁。

### 5. 赔偿范围、选择与互斥

精神损害、违约金、惩罚性、可得利益分列可主张性。用户未选定只出比较表，不代选。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；提出对同一相对方同一损失双份全额重复受偿；伪造或变造合同、客票、仲裁条款。整体停止优先于负触发。不以「坚持」为门槛。
- `字段停止`：合同效力、选择权规则、违约路径精神损害可赔性、仲裁对侵权请求的约束、专门管辖未核验。
- `目标停止`：主目标变为未成争审查起草、纯合同质量诉讼、医疗损害鉴定、承运人责任终稿、产品缺陷终稿、管辖选定、时效截止日、测算总额或起诉状。

禁止指导伪造合同、倒签条款或把两条路径金额叠加为双份。不给胜诉率。
