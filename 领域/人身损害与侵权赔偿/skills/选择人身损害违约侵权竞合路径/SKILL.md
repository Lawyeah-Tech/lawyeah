# 选择违约与侵权竞合路径

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“违约与侵权请求权选择表”：两条路径的时效、管辖、赔偿范围、举证责任和互斥效果。人身伤害主轴留本领域。未成争改合同转审查起草（本窗搁置）。不支持双份重复索赔。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算、鉴定和证据清单。

## 工作边界

正触发：同一事实可主张客运、旅游、医疗服务以外的服务或产品合同违约，同时可主张人身侵权，需要选择或主备位排列。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未成争，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）；
- 诊疗过错医疗损害主轴（转医疗医药）；
- 纯合同质量价款无人身伤害（转合同争议）；
- 要求就同一损失双份全额索赔；
- 海事运输（转海事）。

人身伤害主轴留本领域。不生成发送版解约函或诉状。不把已失效法律当作现行请求权基础。

## 建立工作坐标

确认：使用者与授权；单方立场；合同名称与版本；是否客运、旅游、产品买卖或服务；人身损害事实；仲裁条款；已主张路径；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 合同文本；`R#` 机关文书；`C#` 条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典第一百八十六条选择权、合同编承运人义务和侵权责任编竞合效果；`search_practiced` 补精神损害在违约路径中的限制。不虚构案件系统。

工具不可用时继续事实、主体、程序文书状态和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [竞合选择方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　分流与合同版本

医疗主轴转医疗。未成争改合同搁置。先固定合同文本版本。

### 节点 2　两条路径成立条件

违约路径看合同义务违反；侵权路径看归责与损害。构成违约不等于构成侵权。

### 节点 3　时效、管辖、仲裁比较

违约与侵权时效起算和管辖连结点可能不同，分表比较。

### 节点 4　赔偿范围与精神损害

精神损害、惩罚性、可得利益在两路径可能不同，必须分列。

### 节点 5　选择、主备位与禁止双赔

主位一条、备位一条。同一损失不得双份全额。

## 停止与安全

- `整体停止`：立场不明；用户坚持同一损失双份全额重复受偿；伪造合同。
- `字段停止`：合同效力、选择权规则、精神损害在违约路径中的可赔性未核验。
- `目标停止`：主目标变为未成争审查起草、纯合同质量诉讼或医疗损害鉴定。
