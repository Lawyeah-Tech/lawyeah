# 测算人身损害赔偿

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“人身损害赔偿可复核测算包”：事件编号、分项工作表、被扶养人计入接口、地区参数待核、已付扣减、责任情景层和缺口。本任务**不认定侵权已经成立**，**不预测伤残等级**。

`depends-on` 为空。接受用户、会计、鉴定或其他来源的等价参数。

## 工作边界

正触发：人身损害已发生，单方需要医疗、误工、护理、残疾或死亡、精神损害等项目的可复核数字工作表。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要定性总图，不要分项测算；
- 主成果是工伤待遇测算（转劳动）；
- 主成果是医疗损害鉴定；
- 只要发送版索赔函或诉状；
- 海事专门赔偿限额主轴。

本任务不生成函件或诉状，不给胜诉率，不输出唯一必得总额。

## 建立测算坐标

确认：使用者与授权；单方立场；拟测算项目；法域；受诉或拟处理地区；经常居住地；基准日；年龄；误工与护理事实；鉴定状态；已付款与报销。

用户希望唯一金额，不构成把未知写成零的授权。伤残未鉴定不得填等级。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 票据病历；`R#` 鉴定或统计资料；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 责任假设；`EVT#` 同一损害事件；`M#` 测算行；`V#` 工作表版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。金额状态只用 `已核实金额`、`情景金额`、`无法估计`。未知不写零。真实零必须有肯定来源。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验第一千一百七十九条、第一千一百八十三条、人身损害赔偿解释第十二条至第二十二条、交强险顺序。工具不可用时继续分项建账；地区标准、计入规则、年限字段停止。

## 五个判断节点

执行顺序和停止条件以 [测算方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、假设和事件编号

工伤待遇测算转出。责任只作假设层。不把侵权写成已经成立。

### 2. 分项建账

医疗、护理、交通、营养、住院伙食、误工、辅助器具、残疾或死亡赔偿金、丧葬、精神损害分列。未知不写零。

### 3. 残疾死亡与被扶养人计入

2022-05-01 后不得用农村标准压低。被扶养人生活费计入残疾或死亡赔偿金，禁止双计必得。“上一年度”待核。

### 4. 已付、保险与重复受偿

医保、交强险、垫付、工伤基金已付医疗费逐笔记扣。同一损失不得重复。

### 5. 情景区间和缺口

责任比例只作独立情景。汇总区分已核实、情景和无法估计。禁止唯一必得总额。

## 停止与安全

- `整体停止`：立场不明；用户坚持伪造票据、隐瞒已收款、把未知当零。
- `字段停止`：统计口径、解释条文、等级参数未核验。
- `目标停止`：主目标变为总图、发函、鉴定预测或诉状。
