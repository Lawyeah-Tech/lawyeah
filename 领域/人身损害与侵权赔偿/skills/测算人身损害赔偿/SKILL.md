# 测算人身损害赔偿

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“人身损害赔偿可复核测算包”：事件编号、分项工作表、被扶养人计入接口、地区参数待核、已付扣减、独立责任情景层和缺口。

本任务**不认定侵权已经成立**，**不预测伤残等级或系数**，**不输出唯一必得总额或保险人必担额**。

`depends-on` 为空。接受用户、会计、鉴定或其他来源的等价参数。用户希望唯一金额，不构成把未知写成零、填十级或把咨询日统计值写成已核定的授权。

## 工作边界

正触发：人身损害已发生，单方需要医疗、误工、护理、营养、住院伙食、交通、辅助器具、残疾或死亡、丧葬、精神损害等项目的可复核数字工作表，而不是定性总图。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要定性总图、归责路径或综合提问夹带管辖／时效终稿（转 `评估人身侵权责任`）；
- 主成果是工伤待遇、停工留薪或劳动能力鉴定测算（转劳动）；
- 主成果是医疗损害鉴定；
- 主成果是鉴定申请稿（转 `准备伤残鉴定材料`）；
- 只要发送版索赔函或诉状（转 `准备侵权索赔通知` / `提起人身损害一审`）；
- 只要交强险或商业三者分账终稿（转 `评估道路交通事故责任与保险先行`）；
- 只要精神损害酌定终稿或唯一抚慰金额（转 `评估精神损害赔偿`）；
- 只要死亡赔偿近亲属范围与分配（转 `评估死亡赔偿权利人与分配`）；
- 只要后续治疗费另诉条件（转 `评估后续治疗费另行主张`）；
- 未定残大众测算或场所摔伤大众包（C 端 006，只分流，本任务不降级实施）；
- 海事专门赔偿限额主轴。

本任务不生成函件或诉状，不给胜诉率，不定残，不选定法院，不输出唯一必得总额。

## 建立测算坐标

确认：使用者与授权；单方立场；拟测算项目与排除项；法域；受诉或拟处理地区；经常居住地；基准日；年龄；误工与护理事实；治疗稳定与鉴定状态；已付款、基金支付与报销。

同时掌握双方秘密或未解利益冲突：`整体停止`，不得以选边治愈，也不得改走负触发去出对一方有利的必得表或转介发送版函件。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 票据病历；`R#` 鉴定或统计资料；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 责任或等级假设；`EVT#` 同一损害事件；`M#` 测算行；`V#` 工作表版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。金额状态只用 `已核实金额`、`情景金额`、`无法估计`。未知不写零，真实零必须有肯定来源。技能正文中的条号是检索锚点，不是已核验 `L#`。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验赔偿项目、计入、年限、上一年度时点、城乡标准、超龄误工、基金已付和交强险限额等将被写入 `L#` 的现行规则；不可用则这些字段停止。
- 已有检索真实返回的 `regulation_id` 且宿主暴露 `get_law_detail` 时，用其核验将改变计入、年限、扣减或限额的条文正文，再写入 `L#`。未暴露则不得编造 `regulation_id`，也不得把 `search_law` 摘要条号或技能正文条号写成已核验 `L#`。
- `search_practiced` 补受诉地区统计口径、住院伙食／营养实务和已付扣减口径。
- 特殊事实可用 `search_case_by_fact`。案例只比较差异，不写成必得总额。

工具不可用时继续分项建账、票据回链和已付编目；地区标准、计入规则、年限、城乡标准、扣减法律效果和限额字段停止。

## 判断节点

执行顺序和停止条件以 [测算方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、鉴定闸和假设层

工伤待遇测算、医疗鉴定、海事、C 端 006 整案转出。责任比例、交强险限额、伤残等级只作假设或材料载明，不得写成已决。无死亡事实且出现任一未相对稳定信号：鉴定闸关闭，残疾赔偿金、计入其中的被扶养人、护理依赖、误工／护理／营养截止均为 `无法估计`，禁止转介启动评残，禁止十级或系数假设。

### 2. 分项建账

医疗、护理、交通、营养、住院伙食、住宿、误工、辅助器具、残疾或死亡赔偿金、丧葬、精神损害、后续治疗、被扶养人计入行分列。未知不写零，不得从矩阵删除。已核实金额是毛损失，不得乘责任比例。

### 3. 残疾死亡与被扶养人计入

被扶养人生活费展开后计入残疾或死亡赔偿金，禁止双计必得。无材料保留行并标 `无法估计`。城乡标准和“上一年度”时际分列待核。

### 4. 已付、保险与重复受偿

基金已付、垫付、交强险已赔逐笔记扣接口。基金已付不得写成第三人责任消灭。商业健康险禁止一律扣减。交强险只标接口，不输出保险人必担额。

### 5. 情景区间和缺口

责任比例只作独立情景。汇总区分已核实、情景和无法估计。禁止唯一必得总额，禁止把中位情景包装成请求额。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密或利益冲突未解；用户坚持伪造票据、隐瞒已收款、把未知当零、按指定等级出确定残疾额。整体停止优先于负触发。
- `字段停止`：统计口径、解释条文、等级参数、限额、扣减规则未核验。
- `目标停止`：主目标变为总图、发函、鉴定申请、交强险分账、精神损害酌定、死亡分配、后续治疗另诉或工伤待遇终稿。

禁止指导伪造、隐匿或把未知当零。不给胜诉率。

严格按 [输出合同](references/output-contract.md) 交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。节点 0 整案转出、鉴定闸关闭或整体停止时不得用情景数字填满十节实体。边界见 [路由](references/routing.md)。
