# 测算人身损害赔偿

## 任务目标

在明确、无利益冲突的单方立场下（受害人、近亲属、被指侵权人或其受托律师，互斥），形成人身损害赔偿分项测算草案：人测闸、项目切片与参数、`Q#` 路径、`RS#` 人测行（项目切片／事件与假设／参数与未舍入公式／已付／扣减／互斥／计入接口／`E#` 回链）。本窗 `RS#` 是人测行草案，不是必得总额，不是已确定给付，不是索赔函，不是诉状，不是鉴定意见，不是交强险分账终稿。本窗闸名只能是人测闸，禁止复用鉴定闸、精算闸、测算闸、评估闸、侵权闸、名单闸、时效闸、求偿闸、索赔闸、发送闸。预留不得占用：立案闸、起诉闸、管辖闸、鉴定闸。本窗主行只能是 `RS#`，禁止 `M#`、`EVT#`、`SJ#`、`JT#`、`QC#`、`QG#`、`A#`、`N#`。主路径只用 `Q-人测`，禁止用 `Q-测`、`Q-残`、`Q-必`、`Q-签`、`Q-责`、`Q-伤鉴`、`Q-求`、`Q-诉`、`Q-险`、`Q-总` 作主路径。邻窗 `Q-人测` 只作转介进本窗；本窗打开为主路径，不是已核实、不是必得、不是侵权已成立、不是已立案。人测闸打开不等于侵权已成立不等于伤残已定不等于项目必得不等于交强险已分账不等于保险人必担不等于待提交终稿。构成侵权不是项目必得。未知不是零。被扶养人生活费不是与残疾或死亡赔偿金并列相加。治疗未稳定不是先按十级。分项测算草案不是唯一必得总额。交强险限额不是保险人必担额。基金已付不是第三人责任消灭。认定书不是民事终局比例。咨询日统计值不是已核定上一年度。超龄不是误工当然为零。住院天数不是误工期。伤残等级数字不是乘数。本任务不认定侵权已经成立。不预测伤残等级。不输出唯一必得总额。不写发送版索赔函或诉状。不选定法院。不代提交。不定残。不定罪。不保证胜诉。

`depends-on` 为空。主成果是侵权总图转 `评估人身侵权责任`。主成果是鉴定申请稿转 `准备伤残鉴定材料`。主成果是交强险分账终稿转 `评估道路交通事故责任与保险先行`。主成果是起诉包转 `提起人身损害一审`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：人身损害已发生，单方需要医疗、误工、护理、营养、住院伙食、交通、辅助器具、残疾或死亡、丧葬、精神损害等项目的可复核分项测算，而不是只要总图或只要诉状。「必须赔多少」「今天必须出一个数」「先按十级」仍正触发，成果状态 `草案`。参数、城乡时际、扣减未核验仍正触发：有可编号票据、病历、项目切片、已付或可编号缺口则人测闸打开或半开，第 6 节出 `RS#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出法院支持的一个数」才关闸，仍交十节，第 6 节不出 `RS#` 终稿，第 7 节不得出必得额、索赔函或诉状，窗口不关。用户要把未知写成零、把先按十级写入确定残金、把构成侵权写成项目必得、把被扶养人与两金双计、把测算写成侵权已成立，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `RS#` 草案。不得因「不定侵权已成立」「不给必得总额」改走负触发关窗。利益冲突未解不是整体停止。无死亡且治疗未相对稳定：不关窗、不关人测闸；残疾金、计入其中的被扶养人、护理依赖、持续误工截止为 `无法估计`；禁止转介启动评残。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是侵权总图（转 `评估人身侵权责任`）；
- 主成果是鉴定申请稿（转 `准备伤残鉴定材料`）；
- 主成果是索赔通知且不做精算（转 `准备侵权索赔通知`）；
- 主成果是可提交一审起诉包（转 `提起人身损害一审`）；
- 主成果是首次应诉答辩（转 `应对人身损害一审`）；
- 主成果是交强险或商业三者分账终稿（转 `评估道路交通事故责任与保险先行`）；
- 主成果是精神损害酌定终稿（转 `评估精神损害赔偿`）；
- 主成果是死亡近亲属范围与分配（转 `评估死亡赔偿权利人与分配`）；
- 主成果是后续治疗另诉条件终稿（转 `评估后续治疗费另行主张`）；
- 主成果是完整证据卷（转 `建立人身损害证据案卷`）；
- 主成果是和解条件（转 `谈判人身损害和解`）；
- 主成果是工伤待遇或劳动能力鉴定测算（转劳动领域；夹带第三人只开 `评估工伤与第三人侵权竞合` 接口）；
- 主成果是医疗损害鉴定（转医疗医药领域）；
- 海事专门赔偿限额主轴（转海事领域）；
- C 端大众测算包（只分流，本窗不降级实施）；
- 尚未发生损害，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）。

双方秘密、伪造或裁剪票据病历、虚增损失、隐匿已收款、倒签基准日、违法取证凑测算**不在负触发表**，走整体停止。「先按十级」「未知写零」「构成侵权即项目必得」「测算即已成立」「今天必须出一个数」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不定侵权已成立」「不给必得总额」「不写诉状」是交付禁令，不是负触发。主成果才转；出现「测算」「残金」「必得」一词不是转出。

## 建立工作坐标

确认：测算授权；单方立场；拟测算项目与排除项；法域；受诉或拟处理地区；经常居住地；基准日；年龄；误工与护理事实；治疗稳定与鉴定状态；已付款、基金支付与报销。

口头「必须赔多少」「今天必须出一个数」「先按十级」只登记 `S#`／`V#`。不得升格必得或已核实，**不得单独算作开闸材料**。可编号票据、病历、项目切片、已付或可编号缺口可开闸。本窗不执行发送，不代提交，不定侵权已成立。

立场只许受害人、近亲属、被指侵权人或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：人测闸关闭，仍交十节，不是整体停止。无书面测算授权但单方立场已闭合、且已有碎片：人测闸部分打开，仍交十节，不是整体停止。提出伪造票据、虚增损失、隐匿已收款、倒签基准日或违法取证凑测算：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。开口不等于立场闭合。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 票据病历表面；`R#` 鉴定或统计资料；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`RS#` 人测行；`V#` 版本；`E#` 证据形态回链（票据、鉴定、统计公报、病历形态，不是已核实证明，不是必得证明，不是侵权已成立证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`M#`、`EVT#`、`SJ#`、`JT#`。技能正文中的条号是检索锚点，不是已核验 `L#`。金额旁注只用 `已核实`、`情景`、`无法估计`。未知不写零。真实零必须有肯定来源。无 `E#` 不得写已核实。不输出唯一必得总额。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。构成侵权 ≠ 项目必得。未知 ≠ 零。被扶养人 ≠ 与两金并列相加。治疗未稳定 ≠ 先按十级。测算 ≠ 侵权已成立。认定书 ≠ 民事终局比例。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或裁判案例检索。本窗是分项测算，**不要**用 `search_template` 生成精算终稿、必得总额、索赔函或诉状。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现构成侵权即项目必得、未知写零、先按十级、被扶养人双计、基金已付即责任消灭的反例；案例只比较事实差异与翻转条件，不写成必然结果。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除城乡或农村口径、2003 年解释第十六条构筑物条当作现行计入两金条、交强险旧限额 11 万／1 万、已废止 GB 18667-2002 当作现行规则。道交解释（二）法释〔2026〕9 号自 2026-06-30 施行；MCP 标「尚未施行」以施行日为准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的地区标准、计入、年限、限额保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民法典第一千一百七十九条项目类型不是闭集必得。第一千一百八十三条严重精神损害，本窗金额不得已核实。人身损害赔偿解释（2022 修正）第十六条被扶养人生活费计入残疾或死亡赔偿金，禁止双计；噪声：2003 年解释第十六条是构筑物条。第十二条定残之日起按二十年。第十七条被扶养人按城镇居民人均消费支出。第十八条就高。第二十二条上一年度是一审法庭辩论终结时的上一统计年度，咨询日统计值不是已核定。第二十四条 2022-05-01 当日及以后发生的侵权适用本解释，禁止农村标准压低两金。第六条第二款后续治疗费可待实际发生后另行起诉。道交解释（二）第六条超龄有证据证明误工损失应支持，不是超龄当然为零。第一千二百一十三条交强险顺序只开接口，不出保险人必担额。噪声：已失效侵权责任法；2003 解释已删除城乡口径；交强险旧限额 11 万／1 万。技能正文条号不是 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变计入、年限、扣减或限额的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补构成侵权不是项目必得、未知不写零、先按十级、被扶养人双计、基金已付不是责任消灭、超龄不是误工当然为零的反例。
- `search_case_by_fact` 只比较事实差异与翻转条件：超龄仍可能有误工、轻残不得满额生活费、基金已付不消灭其余民事请求。无类案不得写成必得或已核实终稿。测算类禁止用 `search_template` 生成精算终稿、必得总额、索赔函或诉状。

工具不可用时继续分项建账、票据回链和 `RS#` 编目；地区标准、计入、年限、限额字段停止。不得拒跑，不得凭记忆写成必得或侵权已成立。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、人测闸与不关窗

主成果才整案转出。双方秘密、伪造票据、隐匿已收款第一次停。构成侵权即项目必得、未知写零、先按十级不关窗。闸关仍交十节，第 6 节不出 `RS#` 终稿。利益冲突未解不是整体停止。

### 2. 项目切片与强制接口

医疗、三期、两金、被扶养人计入、已付、交强险接口分列。本节禁止出 `RS#` 终稿。

### 3. 人测闸与路径 `Q#`

本节禁止出 `RS#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-人测`。

### 4. 人测行 `RS#`

项目切片、参数与未舍入公式、已付／扣减、互斥／计入接口。状态 `草案`。禁止升格必得、已核实终稿、侵权已成立。无 `E#` 不得写已核实。

### 5. 鉴定、精神、后续、分账与起诉接口

鉴定、精神、后续、死亡权利人、交通分账、起诉只开接口。第 7 节不得夹带 `RS#` 终稿或必得额绕闸。未稳定不得转介启动评残。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造票据、虚增损失、隐匿已收款、倒签基准日或违法取证凑测算。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：人测闸关闭，仍交十节，不是整体停止。无书面测算授权但有碎片：人测闸部分打开，不是整体停止。利益冲突未解：不是整体停止。把未知写成零或先按十级：该格字段停止或不支持，窗口不关，不是整体停止。
- `字段停止`：统计口径、计入规则、年限、限额、扣减、施行日未核验。构成侵权即项目必得、未知写零、先按十级、测算即已成立、被扶养人双计：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `RS#` 草案。
- `目标停止`：主目标变为总图、发函、鉴定申请、交强险分账、精神损害酌定、死亡分配、后续治疗另诉或起诉包。禁止把「未知写零」或「先按十级」当作用户错误主张时的目标停止；那是不关窗。

禁止指导伪造票据或隐匿已收款。不给胜诉率。不定罪。不定残。不选定法院。不代提交。未知不写零。不输出唯一必得总额。不定侵权已成立。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。人测闸关闭仍交十节，第 6 节不出 `RS#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `RS#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。人测闸未打开时不得交付「必得总额」或「侵权已成立」。边界见 [路由](references/routing.md)。
