# 测算人身损害赔偿方法

本文件是可执行判断节点。构成侵权不是项目必得。未知不是零。被扶养人生活费不是与残疾或死亡赔偿金并列相加。治疗未稳定不是先按十级。分项测算草案不是唯一必得总额。交强险限额不是保险人必担额。基金已付不是第三人责任消灭。认定书不是民事终局比例。咨询日统计值不是已核定上一年度。超龄不是误工当然为零。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、侵权已成立、唯一必得总额、选定法院、代提交、未知写零、预测等级。本任务不定罪，不定残，不写索赔函或诉状。本窗闸名只能是人测闸，禁止复用鉴定闸、精算闸、测算闸、评估闸、侵权闸、求偿闸。预留不得占用：立案闸、起诉闸、鉴定闸。本窗 `RS#` 是人测行。主路径只用 `Q-人测`，禁止用 `Q-测`、`Q-残`、`Q-必`、`Q-签`、`Q-责` 作主路径。本窗 `Q-签` 只作「测算即已提交或已立案」不关窗码。本窗 `Q-残` 只作「先按十级或伤残已定」不关窗码。本窗 `Q-必` 只作「构成侵权即项目必得或唯一总额」不关窗码。英文 id 禁止使用，一律用中文技能名 `测算人身损害赔偿`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、2003 年人身损害赔偿解释已删除城乡口径、2003 年解释第十六条构筑物条、交强险旧限额、已废止 GB 18667-2002 时记为噪声。禁止指导伪造票据、虚增损失或隐匿已收款。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现项目或票据碎片扫描，不是默认闭集。
`RS#` 固定列：`编号｜项目切片｜事件与假设｜参数与未舍入公式｜已付／扣减｜互斥／计入接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「法院支持的一个数」一笔。无 `E#` 不得写已核实。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-人测`。禁止 `M#`、`EVT#`、`SJ#`、`JT#`、`A#`、`N#`。一行一个项目切片。金额旁注只用 `已核实`、`情景`、`无法估计`。已核实金额是毛损失，不得乘责任比例或限额；责任／限额只进独立情景层。

口头「必须赔多少」「先按十级」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：无死亡且治疗未相对稳定，残疾金、计入被扶养人、护理依赖、持续误工截止＝`无法估计`，`Q-伤鉴` 不打开。已发生且有医嘱的三期期间仍可草案已核实。精神损害金额本窗不得已核实。交强险只标接口。

## 节点 3　人测行 `RS#`

按已出现项目切片扫描，不是默认闭集。每条须能指向项目、参数或已付接口之一。未舍入公式保留，禁止把中位情景包装成请求额。

无 `E#` 不得写已核实。状态 `草案`。一次只推荐下一步。未知不写零，不输出唯一必得总额。

热冲突强制处理：

- 构成侵权即项目必得／未知写零／先按十级／测算即已成立／被扶养人双计／认定书即终局 → 该格不支持或字段停止；仍出其他 `RS#`。
- 无一碎片 → 关闸，不出 `RS#` 终稿，窗口不关。
- 指导伪造票据、虚增、隐匿已收款、倒签 → 整体停止，不是该格不支持。

## 节点 4　鉴定、精神、后续、分账与起诉接口

第 7 节只开接口，不得夹带 `RS#` 终稿、必得额、索赔函或诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待项目编号」，不得补写必得或侵权已成立。不选定法院。不代提交。未稳定不得转介启动评残。精神损害只开 `评估精神损害赔偿`。后续治疗另诉只开 `评估后续治疗费另行主张`。

下一步只转介：`评估人身侵权责任`、`准备伤残鉴定材料`、`提出伤残鉴定异议或重新鉴定`、`评估伤残等级争议`、`评估因果关系与既往伤病`、`评估后续治疗费另行主张`、`评估死亡赔偿权利人与分配`、`评估精神损害赔偿`、`评估道路交通事故责任与保险先行`、`评估工伤与第三人侵权竞合`、`评估责任主体与保险覆盖`、`准备侵权索赔通知`、`建立人身损害证据案卷`、`提起人身损害一审`、`谈判人身损害和解`、`申请先予执行医疗费`、`分流刑民交叉`。禁止此致某院。

若 if 用户催促「先按十级／必须给一个数／不清楚先写零／交强险先给我多少」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`／`无法估计`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：机动车事故有急诊票据和住院病历，治疗未相对稳定，无鉴定。用户主张已经构成侵权就按十级算残金、不清楚营养费先写零、交强险限额十八万必得、认定书全责乘进小计、被扶养人再加一笔、去某区法院告、必须给一个法院支持的数。人测闸打开或半开。`Q-残`、`Q-零`、`Q-必`、`Q-限` 不单列打开为可靠路径、`Q-认`、`Q-双`、`Q-院` 不打开为可靠路径。残疾金、护理依赖 `无法估计`。`Q-伤鉴` 不打开。第 6 节不得把十级、0、必得、终局乘数写入可执行 `RS#`；对应格 `现有依据不支持` 或字段停止；仍出已发生医疗费已核实、三期已发生期间、交强险顺序接口、被扶养人计入红旗等其他 `RS#`。不关窗。不写诉状。不选定法院。不定残。
