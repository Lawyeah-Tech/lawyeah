# 测算方法

本文件是可执行判断节点。本任务不认定侵权已经成立。测算行建立在明示假设上：若某 `Q#` 成立，则对应 `M#` 如何计算。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。金额状态只用 `已核实金额`、`情景金额`、`无法估计`。未知不写零。真实零必须有肯定来源。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、2003 年人身损害赔偿解释已删除城乡农村标准或已删除条文、已废止 GB 18667-2002，或已废止交强险 11 万／1 万限额时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

`已核实金额` = 毛损失（可回链票据或已核验口径），**不得**乘责任比例、交强险限额或伤残系数。责任比例、限额覆盖只出现在独立情景层。

## 节点 0　专项分流、鉴定闸和安全

先于实体建账。闸关闭或整案转出时按输出合同减节交付。

**整案转出**（只交付第 1、2、10 节）：

| 信号 | 转出 |
| --- | --- |
| 工伤待遇、停工留薪、一次性伤残补助金或劳动能力鉴定测算 | 劳动领域 |
| 医疗损害鉴定主轴 | 医疗医药 |
| 海事赔偿限额 | 海事 |
| 只要策略总图，或综合提问夹带管辖／时效终稿 | `评估人身侵权责任` |
| 未定残大众测算、场所摔伤大众包（C 端 006） | 大众专项；本任务不降级实施，也不回改 006 |

**鉴定闸**（与 `准备伤残鉴定材料` 同一信号集）：

无死亡事实且出现急救未结束、住院治疗未结束、骨折未固定、内固定未取、计划内二次手术未做、烧伤未拆痂等**任一**未相对稳定信号：伤残程度、护理依赖闸关闭。残疾赔偿金、计入其中的被扶养人、护理依赖、误工／护理／营养截止一律 `无法估计`。**禁止**转介启动评残，禁止十级或系数假设，禁止把过早鉴定意见写入 `已核实金额`。用户口述“差不多好了／先按十级谈”不得开闸。死亡案件的死亡赔偿金、丧葬费不受此闸；死因鉴定转介鉴定原子。后续治疗必要性与费用可单列，未发生不得写零，转介 `评估后续治疗费另行主张`。

打开伤残闸：治疗相对稳定的材料支持，且无上列未稳定信号。闸开且用户要申请材料：转介鉴定原子，本窗仍不定级、不设系数。伤残未鉴定或等级／系数未核验：残疾赔偿金及计入其中的被扶养人相应部分均为 `无法估计`。

**安全：** 双方秘密、伪造票据、隐瞒已收款、把未知当零、坚持指定等级写入确定残疾额：整体停止，提出即停，优先于负触发。不得选边继续出表，不得转介发送版函件把假参数带出。

用途是一次性伤残补助金、停工留薪或劳动能力鉴定委员会路径：整案转劳动。仅当同时向第三人主张民事项目时，民事测算可留，劳鉴段仍转劳动，并转介 `评估工伤与第三人侵权竞合`。

## 节点 1　假设、事件、参数槽和时际

1. 固定单方立场、拟算项目和排除项。
2. 责任比例、交强险限额、伤残等级均为假设或材料载明，不得写成已决。事故认定书不是民事终局。
3. 为同一损害事件分配 `EVT#`。禁止重复计入同一票据或同一收入损失。
4. 地区统计值必须写：发布机关、地区、指标名称、统计年度、适用时点、来源文书。缺任一列，该统计值字段停止。咨询日统计值只能作 `情景金额`。检索锚点：人身损害赔偿解释第二十二条——“上一年度”是一审法庭辩论终结时的上一统计年度。禁止用网络摘要冒充统计公报、出差伙食标准或护工报酬。
5. 年龄、定残日、死亡日不明：相应年限行 `无法估计`。
6. **两套时际不得混用：**
   - 人身损害赔偿解释（法释〔2022〕14 号）城乡统一和项目口径：按**侵权行为发生日**。检索锚点：该解释第二十四条。发生在 2022-05-01 当日及以后：禁止用农村标准压低残疾／死亡赔偿金和被扶养人生活费。发生在该日之前：城乡是否仍区分标 `待核`，禁止把新标准回套旧侵权，也禁止把旧农村标准用于新侵权。
   - 道交解释（二）（法释〔2026〕9 号）：自 2026-06-30 施行；**施行后尚未终审的案件适用**。事故日早于施行日但案件未终审，不得以事故日排除。检索锚点：该解释第十二条。超龄误工、致残后诉讼中他因死亡、多被扶养人年封顶算法、基金已付不得由当事人再向侵权人主张，道路场景走此条时际。

## 节点 2　分项建账

每个 `M#` 固定列：`编号｜项目｜Q# 假设｜参数｜未舍入公式｜已付／扣减｜互斥｜金额状态｜判断｜待核｜来源`。

项目必须可被看见，未知不得从矩阵删除：医疗费、后续治疗费、护理费、交通费、营养费、住院伙食补助、住宿费、误工费、辅助器具费、残疾赔偿金、死亡赔偿金、丧葬费、精神损害、被扶养人生活费（展开计算，汇总计入残疾或死亡赔偿金）。

| 项目 | 计入规则（检索锚点） | 禁止 |
| --- | --- | --- |
| 医疗费 | 医药费、住院费等收款凭证结合病历确定；按一审法庭辩论终结前**实际发生**数额。赔偿义务人对必要性和合理性有异议的，由异议方举证。检索锚点：解释第六条 | 把自费药一律剔除或一律计入；把辩论终结后票据算进本次；把必要性改成权利人额外门槛 |
| 后续治疗费 | 已发生可计入医疗费；根据医疗证明或鉴定结论**必然发生**的可一并；其余待实际发生后另行主张。检索锚点：解释第六条第二款 | 未发生写成零或无鉴定地编一笔必然发生；另诉条件做成终稿 |
| 护理费 | 护理人收入或当地同类护工报酬、人数、期限分列。原则上一人，医疗机构或鉴定机构有明确意见的可参照确定人数。期限至恢复生活自理；因残疾不能恢复的最长不超过二十年。定残后按护理依赖程度并结合辅助器具确定级别。检索锚点：解释第八条 | 用住院天数自动代替护理期；网络摘要冒充护工价；鉴定闸关闭时把护理依赖写成已核实 |
| 交通费 | 受害人及其必要陪护人员因就医或转院实际发生；正式票据，并与就医地点、时间、人数、次数相符。检索锚点：解释第九条 | 无票据补零；用“合理估计往返 N 次”填已核实 |
| 营养费 | 根据伤残情况参照医疗机构意见确定。检索锚点：解释第十一条 | 无意见默认每天固定金额；无意见时删行。无意见 = `无法估计` |
| 住院伙食补助 | 可参照当地国家机关一般工作人员出差伙食补助标准。检索锚点：解释第十条第一款 | 用网络摘要冒充出差标准 |
| 住宿费 | 确有必要到外地治疗且因客观原因不能住院，本人及陪护人员实际发生的住宿费和伙食费的合理部分。检索锚点：解释第十条第二款 | 无外地治疗事实编住宿费 |
| 误工费 | 误工时间和收入状况。误工时间根据医疗机构证明；因伤致残持续误工的，可计算至定残日前一天。有固定收入按实际减少的收入；无固定收入按最近三年平均收入，不能证明的可参照受诉地相同或相近行业上一年度职工平均工资。检索锚点：解释第七条 | 用住院天数自动代替误工期；仅因达到或超过法定退休年龄写成零 |
| 辅助器具费 | 普通适用器具的合理费用；特殊需要参照配制机构意见。更换周期和赔偿期限参照配制机构意见。检索锚点：解释第十三条 | 未评估时编造品牌价款；奢侈品牌当已核实 |
| 残疾赔偿金 | 根据丧失劳动能力程度或伤残等级，按受诉法院所在地上一年度城镇居民人均可支配收入，自定残之日起按二十年。六十周岁以上每增一岁减一年；七十五周岁以上按五年。因伤致残但实际收入没有减少，或伤残较轻但造成职业妨害严重影响劳动就业的，可作相应调整。检索锚点：解释第十二条 | 未鉴定填十级或系数；把等级数字当乘数（十当 10）；2022-05-01 当日及以后用农村标准压低；咨询日统计值写成已核定 |
| 死亡赔偿金 | 受诉地上一年度城镇人均可支配收入 × 年限，年限规则同残疾赔偿金。检索锚点：解释第十五条。同一侵权行为造成多人死亡的，可以以相同数额确定死亡赔偿金，只标接口。检索锚点：民法典第一千一百八十条 | 与被扶养人生活费双计必得；按遗产规则分割（转死亡权利人原子）；道路案件致残后诉讼中他因死亡时改成死亡赔偿金或两金叠加（道路场景检索道交解释（二）第七条，仍按解释第十二条定型化计算残疾赔偿金，其他场景待核） |
| 丧葬费 | 受诉地上一年度职工月平均工资标准，以六个月总额计算。检索锚点：解释第十四条 | 把宴席全部当作丧葬费 |
| 精神损害 | 人身权益受到侵害且造成严重精神损害。检索锚点：民法典第一千一百八十三条、解释第二十三条、精神损害解释。金额本窗不得已核实；用户明示情景只能标 `情景金额`。酌定转 `评估精神损害赔偿` | 编造最低金额、地区行情价或十级惯例必得；未请求即自动优先计入交强险 |

**超龄误工：** 不得仅因达到或超过法定退休年龄把误工写成零。道路场景检索锚点：道交解释（二）第六条。其他场景同样不得凭年龄一笔勾销，须运行时核验。

**年限与系数：** 六十减一、七十五按五年、伤残赔偿系数来源一律运行时核验后写入 `L#`。未核验则年限和系数字段停止，对应行不得变 `已核实金额`。

鉴定闸关闭或未定残：误工截止 `无法估计`，禁止用住院天数顶替。护理人数、必要性、期限缺一，该行不能变 `已核实金额`。

## 节点 3　被扶养人计入与就高

被扶养人生活费计入残疾赔偿金或者死亡赔偿金。检索锚点：解释第十六条。计算按解释第十七条展开，但汇总时计入残疾／死亡赔偿金，**禁止**再与该两金并列相加输出必得或情景小计。

展开规则（未核验则该行停止，不得编造）：

- 根据扶养人丧失劳动能力程度，按受诉法院所在地上一年度**城镇居民人均消费支出**（不是人均可支配收入）；
- 被扶养人为未成年人的，计算至十八周岁；无劳动能力又无其他生活来源的，计算二十年；六十周岁以上每增一岁减一年；七十五周岁以上按五年；
- 被扶养人是受害人依法应当承担扶养义务的未成年人，或者丧失劳动能力又无其他生活来源的成年近亲属；
- 还有其他扶养人的，赔偿义务人只赔偿受害人依法应当负担的部分；
- 被扶养人有数人的：先按丧失劳动能力程度计算**单个**被扶养人生活费，再相加；相加后**年**赔偿总额以不超过上一年度城镇居民人均消费支出额为限。道路场景检索锚点：道交解释（二）第八条；解释第十七条第二款同步核验。禁止先加总再拿一年标准去砍成错误算法，也禁止不封顶。

无身份、扶养关系、无劳动能力或消费支出口径材料：该行必须保留，状态 `无法估计` + `G#`，**不得删行、不得写零**。

就高：权利人举证住所地或经常居住地城镇居民人均可支配收入高于受诉法院所在地的，残疾／死亡赔偿金可以按更高标准；被扶养人生活费相关标准依照同一原则。检索锚点：解释第十八条。无证据不得主动就高。

## 节点 4　已付、保险、工伤医疗费

逐笔分列，不得合成一行：医保统筹、新农合、工伤基金已付医疗费、道路救助基金垫付的抢救费／丧葬费、交强险已赔、对方垫付、单位垫付、费用补偿型医疗险、给付型人身保险金。

纪律：

1. 当事人就基本医疗保险基金、工伤保险基金已经支付的医疗费用，或道路救助基金垫付的抢救费用、丧葬费用，再向侵权人主张该部分：现有依据支持不予支持该部分请求。检索锚点：道交解释（二）第十条（道路场景；其他场景核验社会保险法第三十条、第四十二条及先行支付规则）。从**受害人向侵权人主张的该部分**扣除，并红旗：追偿主体是基金／救助基金管理机构，可合并审理；**禁止**写成“基金已付则第三人全部民事责任消灭”。
2. 社会保险法第四十二条：第三人原因工伤，基金先行支付医疗费后向第三人追偿；第三人已支付的医疗费用除外。其余工伤待遇是否冲抵第三人民事项目必须核验并转介 `评估工伤与第三人侵权竞合`，**不得**写成一律全部抵扣或一律双得。
3. 同一医疗费不得由受害人重复主张。
4. **商业健康险禁止一律扣减。** 费用补偿型是否扣减运行时核验；定额给付型人身保险金原则上不作为医疗费已付，待核。不得与医保统筹写在同一扣减结论里。
5. 交强险已赔：只记已付。分项限额（死亡伤残／医疗费用／财产损失；有责／无责）必须运行时核验。未核验或即使核验：本任务**不输出保险人必担额**，分账终稿转 `评估道路交通事故责任与保险先行`。禁止把医疗费写入死亡伤残限额。禁止用已废止的 11 万／1 万旧限额。禁止把记忆中的 18 万／1.8 万写成已核验必得。
6. 精神损害请求交强险优先：须被侵权人或近亲属提出。检索锚点：道交解释第十三条第二款（条号运行时核验）。只标接口，不自动优先，不保证交强险覆盖全部精神损害，不增加限额。

## 节点 5　情景与汇总

责任情景只使用材料载明比例或用户明示假设，并声明事故认定书不是民事终局。责任比例**不得**写入 `已核实金额` 单元格，不得把认定书比例乘进第 8 节已核实小计。

项目情景（保守／中位／扩展）不是必填算术。参数不足则该乘积层停止，不得用情景数字填满未知行。禁止把中位情景包装成“建议诉讼请求额”。禁止输出唯一必得总额。禁止输出交强险或商业三者限额内必得额。用户催促“给一个数／先按十级算／没有票据就估”时保持 `部分形成并明确受限字段`。

汇总表必须分列：已核实小计、情景小计、无法估计项目名单。已核实小计只含毛损失已核实行，不含责任比、不含限额覆盖。

**定期金与继续给付：** 一审法庭辩论终结前已经发生的费用、死亡赔偿金以及精神损害抚慰金，应当一次性给付。检索锚点：解释第二十条。定期金只作接口（须提供担保等，运行时核验），本表不改写为定期金方案。超过确定的护理期限、辅助器具费给付年限或残疾赔偿金给付年限而请求继续给付：转介另诉／后诉接口，判令继续给付五至十年**不是本表必得延长期**。检索锚点：解释第十九条。

伤残未鉴定或鉴定闸关闭：残疾赔偿金、计入其中的被扶养人、护理依赖、误工截止均为 `无法估计`，不编造等级。
