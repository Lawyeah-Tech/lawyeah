# 输出合同

按触发结果选择交付形状。禁止在缺输入时用情景数字填满栏目。禁止把中位情景包装成请求额。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出（工伤待遇／医疗鉴定／海事／C 端 006） | 第 1、2、10 节。禁止第 5–8 节实体数字 |
| 鉴定闸关闭但仍正触发（已有票据等可建账材料） | 十节表头均出现。残疾赔偿金、计入被扶养人、护理依赖必须 `无法估计`；三期已发生且有医嘱的期间可已核实，未稳定截止不得写成确定日。禁止填等级、未核验系数或确定残疾额。禁止转介启动评残。本行优先于「正触发且可建账」 |
| 整体停止 | 第 1、10 节。禁止分项表、情景汇总、必得额。双方秘密、伪造票据、隐瞒已收款或把未知当零时，整体停止优先于负触发；不得改走发函或起诉完成选边 |
| 正触发且可建账 | 下列十节表头均出现；字段停止的单元格填 `依据不足，无法形成结论`、`待核` 或 `无法估计`，禁止省略后改填估计数或零 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。金额状态只用 `已核实金额`、`情景金额`、`无法估计`。每个 `M#` 必须带金额状态。

## 1. 触发、单方立场、授权与成果状态

必须写明单方立场、授权范围、冲突筛查和鉴定闸是否打开。双方秘密未解不得进入“部分形成”。

## 2. 来源登记与 MCP 调用表

`S/D/R/L/I/G/Q/EVT/M/V`。MCP 未调用也留一行。`L#` 不得直接抄技能内条号。

## 3. 责任与等级假设层

材料载明或用户授权假设。事故认定书不是民事终局。伤残等级／系数未鉴定不得进入已核实。

## 4. 参数与地区口径表

强制列：发布机关、地区、指标名称、统计年度、适用时点（一审辩论终结／咨询日情景）、来源文书。缺任一列，该统计值字段停止。上一年度待核。禁止网络摘要冒充统计公报、出差伙食或护工报酬。

## 5. 分项测算表

完整 `M#` 字段。未知不写零，不得删行。已核实金额是毛损失，不得乘责任比例或限额。已核验伤残系数写入残疾赔偿金公式；系数未核验不得已核实。

## 6. 被扶养人计入接口

展开计算后并入残疾／死亡赔偿金单元格，不得再与两金相加，也不得进入第 8 节已核实小计。伤残案件须乘已核验丧失劳动能力程度，禁止轻残满额。数人须先各算再加总，年总额以城镇人均消费支出为限。无材料保留行，`无法估计`。

## 7. 已付、保险与重复受偿

基金已付从受害人向侵权人主张的该部分扣除，追偿主体是基金，禁止写成第三人责任消灭。商业健康险禁止一律扣减。不输出保险人必担额。

## 8. 多情景汇总

已核实／情景／无法估计分列。禁止唯一必得总额。禁止限额内必得额。禁止把认定书比例乘进已核实小计。被扶养人展开行不得与已计入后的两金再加一次。项目情景不是必填算术。

## 9. 风险与下一步

转介鉴定、主体保险、精神损害、后续治疗、死亡权利人、交通分账、工伤竞合或起诉。鉴定闸关闭时不得把“去评残拿确定值”写成下一步。

## 10. 缺口、停止项与提示

须列对方最强解释（例如事故认定书比例终局、农村标准、重复受偿、未鉴定等级、基金已付则责任消灭、超龄无误工、咨询日统计值已核定）与证据缺口。

本成果不是责任认定、鉴定意见、判决金额、交强险分账终稿或死亡赔偿分配方案。
