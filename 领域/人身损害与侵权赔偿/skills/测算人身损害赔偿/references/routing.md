# 边界与路由

## 正触发

需要可复核的人身损害赔偿分项数字工作表，而不是定性总图、鉴定申请或保险分账终稿。

受害人开口且委托范围是分项测算时，不因口语化咨询整体停止。双方秘密、伪造票据、隐瞒已收款或把未知当零的整体停止，优先于负触发。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要总图，或综合提问夹带管辖／时效终稿 | `评估人身侵权责任` |
| 工伤待遇／劳动能力鉴定测算 | 劳动领域 |
| 医疗损害鉴定 | 医疗医药领域 |
| 启动鉴定或只要申请稿 | `准备伤残鉴定材料`（鉴定闸未开则本窗停止，不转介启动） |
| 发索赔函 | `准备侵权索赔通知` |
| 起诉 | `提起人身损害一审` |
| 交强险或商业三者分账终稿、保险人必担额 | `评估道路交通事故责任与保险先行` |
| 精神损害酌定终稿或唯一抚慰金额 | `评估精神损害赔偿` |
| 死亡近亲属范围与分配 | `评估死亡赔偿权利人与分配` |
| 后续治疗费另诉条件 | `评估后续治疗费另行主张` |
| 未定残大众测算、场所摔伤大众包（C 端 006） | 大众专项，只分流不回改、不降级实施 |
| 海事赔偿限额 | 海事领域 |

已有票据和参数、要工作表时正触发。未鉴定却要求残疾赔偿金确定值：该行无法估计，不改写成鉴定预测，也不改走负触发。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 治疗相对稳定且用户要评残材料 | `准备伤残鉴定材料`（闸关闭则禁止启动） |
| 伤残意见要推翻 | `提出伤残鉴定异议或重新鉴定`；等级争点 `评估伤残等级争议` |
| 参与度、既往伤病影响项目 | `评估因果关系与既往伤病` |
| 精神损害是否严重或交强险优先能否成立 | `评估精神损害赔偿`（本窗金额不得已核实） |
| 未发生后续治疗费 | `评估后续治疗费另行主张` |
| 死亡近亲属或丧葬支出人争议 | `评估死亡赔偿权利人与分配` |
| 机动车已付、限额、精神损害优先入账 | `评估道路交通事故责任与保险先行`（本窗只扣已付、只标接口） |
| 工作中第三人 + 工伤待遇并行 | `评估工伤与第三人侵权竞合`；劳动能力鉴定／待遇转劳动 |
| 要发函、起诉、先予执行、和解或建卷 | 对应原子；本窗只给最小交接 |

## 易混

“住院花了多少、误工怎么算、缺哪些参数”正触发。“评完能拿多少钱”仍可正触发，但未出意见时残疾赔偿金、护理依赖和误工截止必须 `无法估计`。“交强险先赔我多少”负触发到交通专项，本窗不输出限额内必得额。用户催“给一个数”不是把未知当零或填十级的授权。
