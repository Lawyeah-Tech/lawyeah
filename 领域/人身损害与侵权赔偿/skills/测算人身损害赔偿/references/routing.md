# 边界与路由

## 正触发

人身损害已发生，单方需要医疗、误工、护理、残疾或死亡等项目的可复核分项测算。从零、碎片、参数或扣减未核验仍正触发：有可编号票据、病历、项目切片或已付碎片则闸开或半开，出 `RS#` 草案，保持草案。本次不定侵权已成立、不给必得总额是交付禁令，不是开窗条件。先按十级、未知写零、构成侵权即项目必得，仍正触发。把被扶养人与两金双计、把测算写成已成立，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造票据、隐匿已收款的停止，优先于负触发。上述信号不在下表。不定侵权已成立不是负触发。「构成侵权即项目必得」「未知写零」「先按十级」「测算即已成立」「被扶养人双计」不在下表。

## 易混

本窗闸名只能是人测闸，不是鉴定闸，不是精算闸，不是测算闸，不是侵权闸，不是求偿闸。`RS#` 不是 `M#`，不是 `EVT#`，不是 `SJ#`，不是 `JT#`。主路径是 `Q-人测`，不是 `Q-测`，不是 `Q-残`，不是 `Q-必`，不是 `Q-责`。`精算闸`／`SJ#`／`Q-测` 是合同包 `测算违约金与损害赔偿`。`鉴定闸`／`JT#`／`Q-伤鉴` 是 `准备伤残鉴定材料`。`测算闸` 是公司治理对价测算。邻窗 `评估人身侵权责任`、`准备伤残鉴定材料`、`准备侵权索赔通知` 的测算转介已改挂 `Q-人测`。构成侵权不是项目必得。未知不是零。被扶养人不是与两金并列相加。2003 年解释第十六条构筑物条不是现行计入两金条。提出「垫付款先藏起来、发票日期改到上周」整体停止。本窗不代提交。不选定法院。不定残。不写必得总额。不定侵权已成立。不保证胜诉。
