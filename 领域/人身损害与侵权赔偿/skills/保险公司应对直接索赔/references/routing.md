# 边界与路由

## 正触发

交强险或商业三者保险人被直接起诉。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 受害人直接起诉包 | `直接起诉保险公司` |
| 投保人完整应诉 | `应对人身损害一审` |
| 拒赔咨询尚未被诉 | `应对保险拒赔减赔` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 骗保刑事 | 刑事红旗 |
| 再保险合同 | 超出本任务 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“我们是保险公司，被受害人告了”正触发。“我是司机要答辩”走一审应诉。“还没被诉只是拒赔函”走拒赔应对。
