# 边界与路由

## 正触发

交强险或商业三者保险人已被直接起诉或已收到起诉状／应诉通知，需要保险部分应诉。「我们是保险公司，被受害人告了」正触发。酒驾所以交强险当然拒赔、垫付后不是适格被告、保证免赔或限额内零赔、已读起算、选定某院、驾驶人全责写成保险人自认，仍正触发：应诉闸可关，对应格停止，窗口不关。工伤待遇与第三人保险人被诉同时出现，仍正触发：工伤段分流劳动，本窗 `Ins#` 可留。投保人同时要完整侵权抗辩：本窗保险部分正触发，过错展开并行转介，**不得关本窗**。

双方秘密、伪造勘查、倒签出险、隐瞒对受害人先赔后追偿、骗保的停止，优先于负触发。不得改走负触发去出一方答辩或诉状。酒驾当然拒赔、垫付后不是被告、保证免赔、已读起算、选定法院不在下表。伪造倒签不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 用户是原告、起诉保险人诉状或被告列 | `直接起诉保险公司` |
| 投保人完整侵权抗辩或一审实体答辩终稿 | `应对人身损害一审`（保险部分可并行） |
| 尚未被诉的拒赔减赔拆解 | `应对保险拒赔减赔` |
| 索赔材料包 | `准备交强险商业险索赔材料` |
| 分账或第七十六条对照 | `评估道路交通事故责任与保险先行` |
| 代位求偿起诉状 | `应对保险代位求偿` |
| 管辖异议书终稿 | `提出人身案件管辖异议` |
| 了结弃权审查 | `审查保险一次性了结弃权` |
| 测算终稿 | `测算人身损害赔偿` |
| 纯工伤劳动应诉且无第三人保险人被诉 | 劳动领域 |
| C 端只要大众准备包 | 只分流 |
| 未成争改合同或重写产品 | 审查起草搁置 |

「受害人告我们」不在本表，是正触发。不得因「受害人起诉保险人」关窗去写原告诉状。「改勘查」「倒签出险」「两边材料都给你选边」不在本表，走整体停止。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 仅工伤劳动应诉且无第三人保险人被诉 | 劳动领域 |
| 医疗损害主轴 | 医疗医药领域；保险民事应诉可留 |
| 海事 | 海事领域 |
| 指导伪造勘查、倒签出险、隐瞒先赔后追偿或骗保 | 整体停止 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。第三人保险人应诉可留。骗保不得改走刑事整案转出继续给拒赔步骤。

## 易混

「我们是保险公司，被受害人告了」正触发，不得转去写原告诉状。「我是司机要答辩」走一审应诉；若同时要保险袋，本窗可并行。「还没被诉只是拒赔函」走拒赔应对。「酒驾所以交强险一毛不赔、垫过了就不是被告、保证免赔、已读起算、此致某院、按驾驶人全责写保险人自认」仍正触发；各格不支持或字段停止；窗口不关。「工伤还在认，受害人也告了交强险」正触发，保险 `Ins#` 可留。「两边材料都给你选边、改勘查把酒驾拿掉」整体停止。
