# 输出合同

按触发结果选择交付形状。应诉闸未打开不得交付答辩终稿或保证免赔。禁止选定唯一法院或预填「此致某院」。禁止已读、截图、作出日当答辩起算。禁止酒驾交强险对受害人当然拒赔。禁止垫付后写成不适格被告闭集。禁止驾驶人自认写成保险人自认。禁止未知金额写零。禁止胜诉率。禁止代提交。禁止选边治愈。不定残。不保证免赔或限额内零赔。不重写产品。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 应诉闸关闭或节点 0 整案转出 | 第 1、2、10 节：关闭理由、送达待核和最小补证。可附停止的 `K#`／`Ins#`／`Rec#`。禁止答辩终稿、保证免赔、唯一截止日、选定法院。对第三人保险人可留时不得因工伤整案转出 |
| 整体停止 | 第 1、10 节。禁止 `Ins#` 策略包、选边、伪造勘查或隐瞒先赔后追偿步骤。双方秘密、伪造勘查、倒签出险、骗保第一次即停，优先于负触发；无选边治愈，无「坚持」门槛 |
| 用户要酒驾当然拒赔、垫付后不是被告、保证免赔、已读起算、选定某院、驾驶人自认当保险人自认（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；闸未开则仍只交 1、2、10；过期则草稿节停止；不得改走负触发关窗；不得标答辩终稿 `已形成` |
| 正触发且闸开（可部分开） | 下列十节表头均出现；限额、免责、先赔后追偿未核验格待核；一行一袋；禁止为填满而写保证免赔、此致某院、已读起算或酒驾当然拒赔 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入答辩终稿已形成。双方秘密未解不得进入「部分形成」。每个 `K#`／`Ins#`／`Rec#` 必须带来源和三值判断。`L#` 不得直接抄技能内条号。酒驾当然拒赔、保证免赔若返回则记噪声。稿件状态默认 `草案`。

## 1. 触发、单方立场、授权与成果状态

应诉闸开、部分开或关。保险人立场必须标明。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。稿件默认 `草案`。不代提交。不保证免赔。

## 2. 来源登记与 MCP 调用表

`S/D/R/E/C/L/I/G/K/Ins/Rec/V`。口头拒赔、已读、驾驶人口头全责只登记 `S#`／`V#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 期限卡 `K#`

自收到起诉状副本起算，期间长度待核。已读不得起算。保险人与驾驶人分卡。不写死唯一日历截止日。过期提交稿停止。管辖异议只红旗。

## 4. 保险抗辩 `Ins#`

交强险与商业三者分袋。酒驾／无证／逃逸对受害人可能先赔后追偿。垫付入账，不等于不适格。商业险免责须提示说明事实。精神损害优先不得隐瞒也不得自动优先。已赔分列扣减。未知不写零。

## 5. 诉讼地位

交强险共同被告地位不因垫付当然消灭。限额内已赔清且无异议待核。商业三者地位待核条款。不得编造保单。

## 6. 追偿接口 `Rec#`

对象、依据、是否须先赔受害人、另案或反诉路径分列。不保证追回。不得对抗本诉受害人请求。

## 7. 答辩草稿

保险部分。不利条款、已垫付、先赔后追偿接口必须入稿。驾驶人自认不得写入保险人承认栏。草案，不代提交。不预填此致某院。过期则本节停止。

## 8. 与投保人抗辩分工

过错、责任比例转一审应诉并行。本窗不写投保人完整侵权抗辩终稿。保险人与驾驶人争同一策略则整体停止。

## 9. 下一步与转介

转介一审应诉、拒赔窗、代位求偿、分账、管辖异议、工伤竞合只点名。不写成发送版或「提交答辩」指令。不代提交。不保证免赔。

## 10. 缺口、停止项与提示

须列对方最强解释：酒驾所以交强险一毛不赔、垫过抢救费所以不是被告、保证限额内零赔、微信已读那天开始算十五日、此致某区法院、按驾驶人口头全责写保险人自认、免责条款一律有效、精神损害保证不进交强险、认定书就是保险免责、旧十一万限额、未知先写零、工伤还在认所以保险不用应诉、两边材料都给你选边、改勘查把酒驾拿掉、对受害人不说先赔后追偿。

本成果不是原告诉状、不是投保人完整侵权抗辩、不是未起诉拒赔拆解、不是代位起诉状、不是发送版、不保证免赔、不是唯一截止日、不是选定法院。不代提交。
