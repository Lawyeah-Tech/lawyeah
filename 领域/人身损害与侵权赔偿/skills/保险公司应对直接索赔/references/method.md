# 保险人应诉方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。稿件状态只用 `草案`、`应诉闸关闭`、`提交前待核`、`停止`。禁止胜诉率、必然责任比例、唯一必得总额、唯一截止日、选定法院、自行宣布伤残等级、保证免赔、保证限额内零赔、代提交。未知金额不写零。本任务不代提交。不重写保险产品。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》（含第四十八条至第五十三条）、已失效《合同法》、交强险条例第二十二条旧口径对受害人人身当然不赔、已废止交强险十一万或一万旧档、把已读写成答辩期起算、把保证免赔或选定某院写成可执行、把驾驶人自认写成保险人自认时记为噪声，不得写入 `L#`。禁止指导伪造勘查、倒签出险、隐瞒酒驾或对受害人隐瞒先赔后追偿。

`K#` 固定列：`编号｜受送达人（保险人／有当事人能力的分支机构；不得与驾驶人共用一卡）｜文书名称｜作出日｜送达日｜送达方式｜效力凭证｜期间类型（答辩／管辖异议／举证，分列）｜起算事件｜期间长度待核｜待核截止｜状态｜来源回链`。一保险人一卡。已读、截图、作出日不得填送达日。口述截止只进 `S#`。过期：提交稿停止，窗口不关。

`Ins#` 固定列：`编号｜险种袋（交强险／商业三者，禁止一行混袋）｜抗辩类型（主体／分项限额／非交强险事故／重复索赔与已赔扣减／提示说明免责／未缴保费／医保外／本车人员除外／核定）｜所引条款或函面原文｜对受害人效果（可主张／先赔后追偿／不打开／待核）｜对投保人或致害人效果｜提示说明事实（有／无／待核）｜判断三值｜状态｜来源回链`。酒驾／无证／逃逸对受害人人身禁止写成当然拒赔。驾驶人陈述不得写入保险人承认栏。

`Rec#` 固定列：`编号｜追偿对象（驾驶人／投保人／不法使用人／其他）｜依据（法定交强险追偿／约定／待核）｜是否须先对受害人赔付｜相对人是否本诉原告｜路径（本诉接口／反诉转评估反诉或抵销／另案转应对保险代位求偿）｜金额状态（已核实／情景／无法估计；未知不写零）｜状态｜来源回链`。本窗只列接口，不写追偿起诉状终稿，不保证追回。

口头「酒驾一毛不赔」、微信已读、驾驶人口头全责只进 `S#`／`V#`，不得升格 `R#` 已送达、`K#` 已起算或保险人自认。

## 节点 0　分流、立场、应诉闸与不关窗

整案转出或闸关闭只交付第 1、2、10 节或标注停止的 `K#`／`Ins#`／`Rec#`，不得交付答辩终稿，不得标保证免赔。闸部分打开时：仅对可回链的保险袋给出草案，其余行停止或不打开。

| 信号 | 处理 |
| --- | --- |
| 用户是原告、主成果是起诉保险人诉状 | 负触发 `直接起诉保险公司` |
| 主成果是投保人完整侵权抗辩终稿 | 负触发 `应对人身损害一审`；保险部分可并行，不得关本窗 |
| 尚未被诉、只要拒赔拆解 | 负触发 `应对保险拒赔减赔` |
| 只要索赔材料包 | 负触发 `准备交强险商业险索赔材料` |
| 只要分账或第七十六条对照 | 负触发 `评估道路交通事故责任与保险先行` |
| 主成果是代位求偿起诉状 | 负触发 `应对保险代位求偿` |
| 只要管辖异议书终稿 | 负触发 `提出人身案件管辖异议`；本窗只留红旗 |
| 纯工伤劳动应诉且无第三人保险人被诉 | 整案转劳动；夹带第三人保险人被诉则本窗正触发，工伤段分流，`Ins#` 可留并转介 `评估工伤与第三人侵权竞合` |
| 医疗损害主轴 | 转医疗；保险民事应诉可留 |
| 海事 | 转海事 |
| 未成争改合同或重写产品 | 审查起草本窗搁置 |

应诉闸打开（可出 `Ins#` 草案，仍不代提交、不保证免赔）须同时满足：单方无冲突保险人立场与授权；主成果是保险人应诉，不是原告诉状、投保人全抗辩终稿、未起诉拒赔拆解；保险人已被直接起诉或已收到起诉状／应诉通知；至少一名保险人名称可识别，不得编造保单号顶上；拟交付不含保证免赔、酒驾当然拒赔、选定法院、已读起算、驾驶人自认＝保险人自认、伪造勘查。

闸关闭（仍正触发）：保证免赔或限额内零赔；酒驾交强险当然拒赔；垫付后不是适格被告；选定某院；已读起算；驾驶人自认＝保险人自认；未知写零；发送版／代提交；过期仍要可提交答辩终稿。闸未开则仍只交 1、2、10 节。过期：十节表头可出现，提交稿停止。

「酒驾当然拒赔」「垫付后不是被告」「保证免赔」「已读起算」「选定法院」「驾驶人自认当保险人自认」**不关窗**。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或受害人与保险人、保险人与驾驶人／投保人同时交材料争同一份应诉策略且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出伪造或改勘查、倒签出险、隐瞒酒驾骗保、对受害人隐瞒交强险先赔后追偿，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　期限卡 `K#`

检索锚点：人民法院应当在立案之日起五日内将起诉状副本发送被告，被告应当在收到之日起十五日内提出答辩状；不提出答辩状的，不影响人民法院审理。2023 修正后常见第一百二十八条一类，条号运行时核验，不是 `L#`。2017 年旧条号不得默写为现行 `L#`。

作出日 ≠ 送达日 ≠ 已读／截图／发送成功。电子送达须当事人同意并以到达特定系统之日为送达日，未核验则截止日停止。保险人与驾驶人分卡，不得共用截止日。管辖异议期间与答辩期间分列。拟提管辖异议：实体答辩草稿停止或标明不得在异议裁定前提交；异议书终稿转 `提出人身案件管辖异议`。未提管辖异议并应诉答辩或提出反诉，可能视为受诉法院有管辖权（级别／专属除外），须红旗。

过期：提交稿停止，窗口不关。不提出答辩状不影响审理 ≠ 免于不利结果，不保证免于缺席。

## 节点 2　保险抗辩 `Ins#`

检索锚点：道路交通事故损害赔偿中，承保交强险的保险公司应当列为共同被告，但该保险公司已经在交强险责任限额范围内予以赔偿且当事人无异议的除外；垫付不等于除外。无证驾驶、醉酒、服用国家管制的精神药品或麻醉药品后驾驶、故意制造交通事故等情形，交强险对第三人人身损害可能限额内赔偿后向侵权人追偿，不等于对受害人当然拒赔。同时起诉侵权人与保险人的赔偿顺序：先由承保交强险的保险公司在责任限额范围内予以赔偿，不足部分由承保商业三者的保险公司按保险合同赔偿，仍不足由侵权人赔偿。精神损害在交强险内优先赔偿须被侵权人或近亲属提出。条号运行时核验，不是 `L#`。

| 抗辩 | 本窗 | 禁止写法 |
| --- | --- | --- |
| 酒驾／无证／逃逸／吸毒后驾驶 | 对受害人人身：先赔后追偿或待核 | 当然拒赔；用追偿对抗本诉受害人 |
| 垫付医疗费 | 已付入账扣减；地位通常仍应诉 | 垫过了所以不是适格被告 |
| 限额内已赔清且当事人无异议 | 地位抗辩待核 | 口头「赔过了」升格无异议 |
| 商业三者免责 | 须提示说明事实；材料不足则效力依据不足 | 当然免赔；免责一律无效 |
| 医保外 | 待核 | 一律有效或一律无效 |
| 精神损害交强险优先 | 原告接口；不得隐瞒该解释存在 | 当然不进或当然进；自动优先 |
| 已赔／基金 | 分列扣减 | 未知写零；重复扣减无凭证 |
| 认定书 | 证明力待核 | 单独写成保险免责闭集或民事终局 |

商业三者诉讼地位与直接请求须核验条款，未核验不得当然无地位。不代替投保人主张受害人过错的全部事实展开，转 `应对人身损害一审` 并行。驾驶人自认不得写入保险人承认栏；用户坚持按驾驶人全责写保险人答辩：该承认字段停止。旧交强险限额不得默写。

## 节点 3　追偿接口 `Rec#`

交强险向侵权人追偿的诉讼时效，检索锚点为自保险公司实际赔偿之日起计算，条号运行时核验。本窗不保证追偿成立，不写追偿状终稿。相对人是本诉原告时，不得把追偿做成对抗受害人请求的本诉抗辩。路径：另案转 `应对保险代位求偿`；若用户要把追偿当反诉，只红旗并转 `评估反诉或抵销`。未实际赔付不得打开已核实追偿额。

## 节点 4　答辩草稿与转介

草稿栏目：保险人当事人、案号、针对的保险请求、分袋抗辩、已赔扣减、证据。状态默认 `草案`。不利条款、已垫付、酒驾先赔后追偿接口必须入稿，删除视为隐匿。不代提交。禁止预填「此致某院」。闸未开不得标答辩终稿 `已形成`。

| 接口 | 本窗 | 转介 |
| --- | --- | --- |
| 原告起诉保险人 | 负触发 | `直接起诉保险公司` |
| 投保人过错／责任比例 | 只接口 | `应对人身损害一审` |
| 尚未被诉拒赔拆解 | 负触发 | `应对保险拒赔减赔` |
| 代位／追偿起诉状 | 只红旗 | `应对保险代位求偿` |
| 分账数字 | 不得已核实未知 | `评估道路交通事故责任与保险先行`／`测算人身损害赔偿` |
| 管辖异议书 | 只红旗 | `提出人身案件管辖异议` |
| 工伤第三人 | 工伤段分流；保险可留 | `评估工伤与第三人侵权竞合` |

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过应诉闸直接给保证免赔、酒驾当然拒赔、已读起算或选定法院。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if 金额参数不足，then 该行标未知，禁止写零。
若 if C 端只要大众准备包，then 只分流不回改。

判断状态只许三值。口头转述、截图和「已读」不得写成已受理、已送达或期限已起算。事故认定书不得单独写成保险免责闭集。驾驶人自认不得写成保险人自认。

## 本任务回链纪律

本任务成果是「不代提交的保险人应诉草稿、分袋抗辩与追偿接口」。必须包含：应诉闸、酒驾对受害人不得当然拒赔、垫付不等于不适格、驾驶人自认≠保险人自认、已读不得起算。不包含：原告诉状、投保人完整侵权抗辩终稿、未起诉拒赔拆解、代位起诉状。禁止保证免赔。禁止选定法院。禁止选边治愈。禁止伪造勘查或隐瞒先赔后追偿。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标答辩终稿已形成。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接。
风险档 A：答辩期、对受害人隐瞒先赔后追偿、伪造勘查必须单独标可逆性。
