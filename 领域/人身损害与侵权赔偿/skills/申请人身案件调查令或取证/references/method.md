# 调查令方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。稿件状态只用 `草案`、`申请闸关闭`、`提交前待核`、`停止`。禁止签发率、必然签发、唯一截止日、选定法院、自行宣布伤残等级。未知金额不写零。本任务不代提交，不保证签发，调查令不是全国统一法定。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、把调查令写成全国一律存在、把尚未起诉写成应当签发、把空白全城写成可提交、把保存函写成已取证、把对方控制写成画面有利、把诉前拒不提交写成推定已成立时记为噪声，不得写入 `L#`。禁止指导黑客调取、购买个人信息、收买监控员或伪造调查令。

`Inv#` 固定列：`编号｜路径类型（律师调查令／法院调查收集申请／闸关闭只分流）｜时机（诉中可开闸／尚未起诉闸关）｜申请人｜持有人｜对象（机位+时段／病历相关部分／保险与事故相关档案／登记最小字段；猜测标S#）｜待证事实｜自行收集努力｜客观原因不能自行收集（三值）｜范围特定化｜调查令地区实践（待核，不保证存在）｜用途限制（仅本案）｜隐私限缩｜管辖连结点并列（不选唯一）｜签发效果（不保证签发）｜书证提出命令（诉前不打开）｜状态｜转介（只点技能名）｜来源回链`。一行一个调取对象。禁止合成「医院保险公司监控一律调取」。

## 节点 0　分流、立场、申请闸与不关窗

整案转出或闸关闭只交付第 1、2、10 节，不交申请书终稿、应当签发或唯一法院。闸部分打开时：仅对已特定且已诉讼的行给出草案，诉前行、过宽行只分流。

| 信号 | 处理 |
| --- | --- |
| 只要保存通知正文 | 负触发 `准备监控保存通知` |
| 只要现场合法固定步骤 | 负触发 `保全现场监控与电子证据` |
| 只要公证事项终稿 | 负触发 `准备人身案件公证保全` |
| 已决定或尚未决定法院保全 | 负触发 `准备财产或证据保全申请`／`评估证据或财产保全必要性` |
| 只要建卷矩阵 | 负触发 `建立人身损害证据案卷` |
| 只要起诉状终稿 | 负触发 `提起人身损害一审`；尚未起诉时本窗闸关并转介起诉，窗口不关 |
| 只要先予执行终稿 | 负触发 `申请先予执行医疗费` |
| 病历封存或医疗鉴定主轴 | 转医疗；对医院作为第三人的侵权病历调查可留 |
| 工程款工期质量造价 | 转建设工程；工地人身监控或病历**不得**因「现场资料」误转 |
| 主轴仅工伤认定、劳鉴或待遇，且无第三人监控／病历／保险／登记 | 整案转劳动；夹带第三人对象则本窗正触发，工伤段分流，`Inv#` 可留并转介 `评估工伤与第三人侵权竞合` |
| 海事专门程序 | 转海事 |
| 未成争只要改合同 | 审查起草本窗搁置 |

申请闸打开条件（对某一行，同时满足）：单方无冲突申请方立场与授权；主成果是调查令或法院调查收集申请草稿；该行持有人可特定，材料名称加时段或最小字段可特定；已进入诉讼或有立案／受理 `R#`；已有自行收集努力（书面申请或保存通知被拒 `D#`），或现有依据支持明显不会配合。

闸关闭（仍正触发）：尚未起诉、无 `R#`；持有人、时段、字段均不能特定；从未自行收集且非明显不配合；「保证签发」「今晚必须交」本身不得开闸写成应当签发。尚未起诉转介 `提起人身损害一审`，并点名保存通知／公证／诉前保全，本窗不代写那些终稿。合法二次申请（已申请一次、补范围或补持有人）不受「对方未回复不得打开闸」误关。

「保证签发」「尚未起诉仍要终稿」「空白全城」「调查令全国都有」「选定唯一法院」**不关窗**。闸未开则仍只交 1、2、10 节。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或受害人与场所、医院、保险人同时交材料争同一份调取且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出黑客调取、购买个人信息、收买监控员、侵入系统、伪造调查令、空白全库且拒绝限缩、出售扩散病历、倒签已签发，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　自行收集努力与客观原因

检索锚点：当事人及其诉讼代理人因客观原因不能自行收集的证据，人民法院应当调查收集。证据由国家有关部门保存且当事人无权查阅调取、涉及国家秘密商业秘密或个人隐私、因其他客观原因不能自行收集的，可申请法院调查收集。条号不是 `L#`。

已发保存通知或书面申请被拒：该行必要性可支持。从未尝试：原则上关闸，先转介 `准备监控保存通知`，除非现有依据支持明显不会配合。不得把未尝试写成已具备客观原因。

不能因对方控制推定材料存在或内容有利。口头「肯定有监控」只登记 `S#`。

## 节点 2　对象与范围

持有人、材料名称、时段或最小字段必须特定。禁止空白调查令。禁止「该商场全部监控一个月」「全库病历」「全城摄像头」。过宽格 `现有依据不支持`，须限缩到事发点前后或与争议相关部分，窗口不关。拒绝限缩：第一次整体停止。

保险投保和理赔档案：仅与本次事故相关部分。人口或车辆登记：最小必要字段。病历：仅与争议相关；无关隐私申请限缩或保密，禁止扩散。

---

## 节点 3　调查令或法院调查

律师调查令是地方实践，不是全国统一法定。未核验不得写成全国均有、必然存在、必然签发。无调查令地区：调查令行关闭，走人民法院调查收集书面申请。不得把法院调查申请伪装成已签发调查令。

申请书应载明：被调查人姓名或单位名称、住所地等基本情况、所要调查收集的证据名称或内容、需要由人民法院调查收集的原因、待证事实、明确线索。举证期限届满前提出——期间未核验不得写唯一日历截止。

管辖连结点并列，申请书不得预填「此致某院」。不保证签发。不代提交。不编文书号。

书证提出命令或无正当理由拒不提交的推定，以诉讼中人民法院责令为前提，诉前不得写成已成立。用户要「不给就是输」：该格 `现有依据不支持` 或待核，窗口不关。

---

## 节点 4　用途、保密与申请草稿

用途仅本案。禁止出售、扩散病历、保险档案或无关第三人画面。调查核实负有保密义务——检索锚点待核，不得写成已经授权公开。

草稿状态 `草案` 或 `提交前待核`。不代提交。不得写依法应当签发。不利事实不删除。保存函、现场步骤、公证、保全只点转介名。

人民法院委托外地法院调查的三十日等期间是法院之间的期间，不是申请人今晚截止。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过申请闸直接给可提交终稿或应当签发。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if C 端只要大众准备包，then 只分流不回改。

判断状态只许三值。口头转述、截图和「已读」不得写成已受理、已签发或期限已起算。事故认定书不得单独写成民事终局并据此必须调查令。

## 本任务回链纪律

本任务成果是「不代提交的调查令或法院调查取证申请草稿」。不包含：保存函、现场步骤、保全申请、公证事项、起诉状、先予执行、建卷矩阵。禁止保证签发。禁止空白全城。禁止调查令全国一律。禁止违法调取。禁止选边治愈。禁止对方控制推定有利。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标申请终稿已形成。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接。
风险档 A：不可逆申请或违法取证字段必须单独标可逆性。
