# 边界与路由

## 正触发

监控、病历、保险或登记由第三方掌握，需要调查令或人民法院调查收集。尚未起诉、不知持有人或时段、用户要保证签发、空白全城或调查令全国都有仍正触发：申请闸可关，对应格停止，窗口不关。工伤待遇与对第三人对象同时出现，仍正触发：工伤段分流劳动，对第三人 `Inv#` 可留。工地人身监控或病历仍正触发，不得因工地关键词转工程。

双方秘密、同时交材料、黑客调取、购买个人信息、收买监控员、伪造调查令的停止，优先于负触发。不得改走负触发去出申请书。保证签发、尚未起诉不在下表。违法调取不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 保存通知正文 | `准备监控保存通知` |
| 现场、聊天或行车记录仪合法固定步骤 | `保全现场监控与电子证据` |
| 公证保全事项终稿 | `准备人身案件公证保全` |
| 法院保全申请书 | `准备财产或证据保全申请` |
| 尚未决定是否保全 | `评估证据或财产保全必要性` |
| 建卷矩阵 | `建立人身损害证据案卷` |
| 起诉状 | `提起人身损害一审` |
| 先予执行终稿 | `申请先予执行医疗费` |
| 病历封存或医疗鉴定主轴 | 医疗医药领域；侵权病历调查可留 |
| 工程造价主轴 | 建设工程领域 |
| C 端只要大众准备包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「我去黑客调出来」「买份登记」「给监控员好处费」不在本表，走整体停止。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 仅工伤档案且无第三人对象 | 劳动领域 |
| 病历封存或医疗鉴定终稿 | 医疗医药领域；侵权病历调查可留 |
| 海事专门程序 | 海事领域 |
| 指导违法获取公民个人信息或侵入系统 | 整体停止；刑事只打红旗，不得用来出步骤 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。对第三人监控、病历、保险或登记可留。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 尚未起诉 | `提起人身损害一审`（闸关不关窗） |
| 先发函让物业留监控 | `准备监控保存通知` |
| 己方现场或行车记录仪步骤 | `保全现场监控与电子证据` |
| 公证过程或现状 | `准备人身案件公证保全` |
| 是否申请法院保全 | `评估证据或财产保全必要性`／`准备财产或证据保全申请` |
| 建卷 | `建立人身损害证据案卷` |
| 工伤与第三人 | `评估工伤与第三人侵权竞合` |
| 场所责任成立 | `评估场所安全保障义务` |

## 易混

「医院和保险公司不给档案」正触发。「我去黑客调出来」第一次提出即整体停止。「只要公证网页」走公证。「还没起诉，保证签发空白全城监控调查令，此致某院今晚交」仍正触发；闸关；保证签发、空白全城、唯一法院各格不支持。「工伤也要认，物业不给事发口二十分钟监控」正触发，`Inv#` 可留，工伤段分流。「工地砸伤要调塔吊那路监控」正触发，不得转工程。「两边材料都给你，选边写调查令」整体停止。
