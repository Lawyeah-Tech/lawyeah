# 边界与路由

## 正触发

监控、病历、保险或登记由第三方掌握，需要调查令或法院调查。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 违法自行调取 | 整体停止 |
| 公证现状 | `准备人身案件公证保全` |
| 病历封存医疗主轴 | 医疗医药领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 违法获取公民个人信息 | 停止并刑事红旗 |
| 劳动用工档案调查 | 劳动领域并行 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“医院和保险公司不给档案”正触发。“我去黑客调出来”停止。“只要公证网页”走公证。
