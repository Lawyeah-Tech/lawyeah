# 输出合同

按触发结果选择交付形状。申请闸未打开不得交付申请书终稿。禁止保证签发或签发率。禁止选定唯一法院或预填「此致某院」。禁止写死唯一日历截止。禁止空白全城全时段。禁止把调查令写成全国一律存在。禁止把保存函、现场步骤或公证写成已取证或保全裁定。禁止因对方控制推定存在或有利。禁止诉前把拒不提交写成推定已成立。禁止选边治愈。禁止黑客、购买个人信息或收买监控员步骤。不代提交。不定残。不保证签发。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 申请闸关闭或节点 0 整案转出 | 第 1、2、10 节：关闭理由、程序前提待核和最小补证。禁止申请书终稿、应当签发、唯一法院。对第三人调查可留时不得因工伤或工地整案转出 |
| 整体停止 | 第 1、10 节。禁止 `Inv#`、申请书、选边、侵入或购买方法。双方秘密、黑客调取、购买个人信息、收买监控员、伪造调查令、空白全库拒绝限缩第一次即停，优先于负触发；无选边治愈，无「坚持」门槛 |
| 用户要保证签发、尚未起诉出终稿、空白全城或全国均有令（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；闸未开则仍只交 1、2、10；不得改走负触发关窗；成果不得标申请终稿 `已形成` 为应当签发 |
| 正触发且闸开（可部分开） | 下列十节表头均出现；调查令存在性、客观原因、范围未核验的单元格填 `依据不足，无法形成结论` 或 `待核`；一行一对象；禁止为填满而宣布应当签发、空白全城或预填唯一法院 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入申请终稿已形成。双方秘密未解不得进入「部分形成」。每个 `Inv#` 必须带来源和三值判断。`L#` 不得直接抄技能内条号。保证签发、全国均有令、空白全城若返回则记噪声。稿件状态默认 `草案`。

## 1. 触发、单方立场、授权与成果状态

申请闸开、部分开或关。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。稿件默认 `草案`。

## 2. 来源登记与 MCP 调用表

`S/D/R/L/I/G/Inv/V`。口述保证签发、全部监控一个月只登记 `S#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 申请闸、程序前提与自行努力

诉中可开闸。尚未起诉闸关并转介起诉、保存通知或诉前保全。未尝试自行收集则必要性弱。

## 4. 对象与范围 `Inv#`

持有人、时段、最小字段分列。禁止空白、全城全时段、全库病历。拒绝限缩整体停止。

## 5. 调查令或法院调查选择

地区实践待核。不保证存在。无令地区走法院调查收集。不保证签发。不选定法院。

## 6. 用途限制与保密

仅本案。禁止出售扩散。无关隐私限缩。

## 7. 申请书草稿

被调查人、证据名称或内容、原因、待证事实、明确线索。草案，不代提交。不得写依法应当签发。不得预填唯一法院。

## 8. 与保全、公证、保存函的关系

只点转介名。保存函≠调查令≠保全裁定≠搜查令。书证提出命令诉前不打开。

## 9. 下一步

不代提交。转介起诉、保存通知、公证、保全或建卷只点名。不选定法院。

## 10. 缺口、停止项与提示

须列对方最强解释：保证签发、尚未起诉也能拿到令、调查令全国都有、空白全城先开再限缩、对方控制即画面有利、不给就是输、保存函就是调查令、选边即可继续、黑客拷一份、买份登记。

本成果不是已签发调查令、不是搜查令、不是保全裁定、不是保存函、不是公证、不保证签发、不是唯一截止日。不代提交。
