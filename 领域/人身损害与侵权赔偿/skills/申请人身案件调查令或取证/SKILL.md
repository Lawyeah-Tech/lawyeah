# 申请人身案件调查令或取证

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的申请方立场下，形成不代提交的调查令或法院调查取证申请包：申请闸、`Inv#` 分对象、自行收集努力、特定范围、调查令地区待核或法院调查收集、用途限制、申请书草案。调查令不是全国统一法定，未核验不保证存在。不保证签发。不等于搜查令。范围必须必要且特定，禁止空白调查。用途仅本案。不能因对方控制推定材料存在或内容有利。书证提出命令或拒不提交推定以诉讼中法院责令为前提，诉前不得写成已成立。

`depends-on` 为空。保存函转 `准备监控保存通知`。现场步骤转 `保全现场监控与电子证据`。公证转 `准备人身案件公证保全`。是否保全转 `评估证据或财产保全必要性`／`准备财产或证据保全申请`。尚未起诉转介 `提起人身损害一审`。建卷转 `建立人身损害证据案卷`。

## 工作边界

正触发：监控、病历、保险或登记由第三方掌握，需要调查令或人民法院调查收集。尚未起诉、不知持有人或时段、用户要「保证签发」「空白全城监控」「调查令全国都有」仍正触发：申请闸可关，对应格填 `现有依据不支持` 或字段停止，窗口不关。工伤待遇与对第三人监控、病历、保险或登记同时出现：本窗正触发，工伤段分流劳动，对第三人的 `Inv#` 可留。工地人身损害监控或病历正触发，不得因「工地／造价资料」误转建设工程。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要保存通知正文（转 `准备监控保存通知`）；
- 只要现场、聊天或行车记录仪合法固定步骤（转 `保全现场监控与电子证据`）；
- 只要公证保全事项终稿（转 `准备人身案件公证保全`）；
- 已决定或尚未决定法院保全（转 `准备财产或证据保全申请`／`评估证据或财产保全必要性`）；
- 只要建卷矩阵（转 `建立人身损害证据案卷`）；
- 只要起诉状终稿（转 `提起人身损害一审`）；
- 只要先予执行终稿（转 `申请先予执行医疗费`）；
- 病历封存或医疗损害鉴定主轴（转医疗；对医院作为第三人的侵权病历调查可留）；
- 工程款、工期、质量、造价主轴（转建设工程）；
- C 端只要大众准备包（只分流）；
- 未成争改合同（审查起草搁置）。

保证签发、尚未起诉、空白全城**不在负触发表**，窗口不关。黑客调取、购买个人信息、收买监控员、伪造调查令、双方秘密**不在负触发表**，走整体停止。

## 建立工作坐标

确认：使用者与授权；申请方；持有人；材料名称与时段或最小字段；已自行收集的努力；是否已立案；法域与地区调查令实践线索。

口头「保证签发」「全部监控一个月」「全国都有调查令」只登记 `S#`。不得写入应当签发或全国均有。

同时掌握双方秘密，或受害人与场所、医院、保险人同时交材料争同一份调取：`整体停止`，不得以选边治愈，也不得改走负触发去出一方申请。受害人已开口且委托范围就是调查令或法院调查申请、且未掌握对方秘密时，可推定申请方立场。只要同时掌握双方秘密，无例外整体停止。提出黑客调取、购买个人信息、收买监控员、侵入系统、伪造调查令、空白全库且拒绝限缩：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 自行取证记录、保存通知回证；`R#` 立案或受理；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Inv#` 申请行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。稿件状态只用 `草案`、`申请闸关闭`、`提交前待核`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。不准许率。本任务默认 `草案`，不代提交。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：当事人及其诉讼代理人因客观原因不能自行收集的证据，人民法院应当调查收集；申请书应载明被调查人基本情况、证据名称或内容、原因、待证事实和明确线索；证据由国家有关部门保存当事人无权查阅、涉及国家秘密商业秘密或个人隐私、因其他客观原因不能自行收集的，可申请法院调查收集；律师调查令属地区实践须标明待核，不保证存在；范围须必要且特定；非法获取计算机信息系统数据、非法侵入、侵犯公民个人信息禁止。技能正文条号不是 `L#`。噪声：已失效《侵权责任法》、保证签发、尚未起诉即可保证有令、空白全城监控、选定唯一法院、调查令等于搜查令或保全裁定、保存函等于已取证、对方控制即画面有利、拒不提交诉前即推定成立。不可用则调查令存在性、法院调查事由、管辖效力字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变调查收集条件、范围或禁止自助取证的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补调查令地区有无、诉中前提、超范围被拒、空白或全时段难准许、不保证签发的实务反例。
- `search_template` 只借调查令或法院调查取证申请书栏目，不把范本当法定格式、已提交文本或指定唯一法院。

工具不可用时继续当事人、持有人、对象编目与 `Inv#`；调查令存在性、法院调查事由、管辖效力字段停止。不得凭记忆写应当签发、全国均有调查令或唯一法院。

## 判断节点

执行顺序和停止条件以 [调查令方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、申请闸与不关窗

工伤三段分流，对第三人调查可留。工地人身可留。双方秘密或违法调取第一次停。尚未起诉、保证签发不关窗。

### 2. 自行收集努力与客观原因

未合法申请或保存通知被拒，必要性弱。不得因对方控制推定存在或有利。

### 3. 对象与范围 `Inv#`

持有人、时段、内容必须特定。禁止空白、全城全时段、全库病历。拒绝限缩第一次停。

### 4. 调查令或法院调查

调查令地区待核，不保证存在。无令地区走法院调查收集。不保证签发。不选定法院。

### 5. 用途、保密与申请草稿

仅本案。禁止出售扩散。草案不代提交。书证提出命令诉前不打开。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；受害人与持有人同时交材料；提出黑客调取、购买个人信息、收买监控员、侵入系统、伪造调查令、空白全库且拒绝限缩、出售扩散病历、倒签已签发。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：调查令地方规则、法院调查事由、管辖未核验。尚未起诉则申请书终稿停止，窗口不关。用户要保证签发、空白全城或全国均有令则该格停止，窗口不关。
- `目标停止`：主目标变为保存函、现场步骤、保全申请、公证、起诉状、先予执行或建卷终稿。保证签发、尚未起诉不在目标停止。

禁止指导违法调取。不给签发率。不选定法院。不代提交。不编唯一截止日。不把保存函写成已取证。
