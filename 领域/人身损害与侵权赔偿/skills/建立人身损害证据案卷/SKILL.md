# 建立人身损害证据案卷

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“人身损害证据案卷矩阵”：争点要件、举证责任、支持材料、不利材料、控制方、合法取得、缺口、补证步骤和最晚时点。

`depends-on` 为空。本任务不是策略备忘，也不是起诉状。

## 工作边界

正触发：人身损害已发生，单独委托建卷，或需要把归责、损害、保险和过错要件做成可回链案卷。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要策略总图或只要诉状；
- 用户要求偷拷监控、购买隐私、非法侵入或统一证人口径；
- 主成果是工伤行政卷宗或医疗损害鉴定检材包；
- 海事专门证据。

本任务不生成诉状或胜诉率，不指导伪造、隐匿或违法取证。

## 建立案卷坐标

确认：使用者与授权；单方立场；待证争点；法域；举证期限或监控覆盖风险；已持有材料；对方或第三人控制的监控、病历、保单线索。

同时掌握双方秘密时先停。不能因对方控制而推定材料存在或有利于己方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关文书；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 争点；`EV#` 证据条目；`V#` 案卷版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验举证责任、书证提出、电子数据、举证期限和非法证据排除。工具不可用时继续材料编目；分配和排除的法律结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [建卷方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流与要件

把每个 `Q#` 拆成行为、过错或特殊归责、损害、因果、主体、保险。工伤行政要件转劳动。

### 2. 举证责任

一般过错由主张方证明过错。高度危险、动物、堆放物等特殊路径须核验现行条文后再写推定或倒置，不得凭记忆把场所安保写成过错推定。

### 3. 支持、不利、控制方、合法取得

监控、病历、行车记录仪、聊天分列。首次要求违法取证：该部分整体停止。

### 4. 缺口与最晚时点

保存通知、公证、调查令、法院保全只列合法步骤和转介。期限分类型。

### 5. 禁止动作

不指导摆拍重建现场、诱导证言、隐匿既往病史。

## 停止与安全

- `整体停止`：立场不明；基础事实无法建立。
- `该部分整体停止`：用户就某材料坚持伪造、隐匿、非法侵入或购买隐私。
- `字段停止`：举证责任或非法证据排除规则未核验。
- `目标停止`：主目标变为诉状或违法取证方案。
