# 建立人身损害证据案卷

## 任务目标

在明确、无利益冲突的单方立场下（受害人、近亲属、被指侵权人或其受托律师，互斥），形成人身损害证据案卷草案：人据闸、待证要件与材料碎片、`Q#` 路径、`RJ#` 人据行（待证要件／材料形态／支持／不利／控制方／合法取得／`E#` 回链）。本窗 `RJ#` 是人据行草案，不是诉状，不是保全终稿，不是已质证，不是已入卷。本窗闸名只能是人据闸，禁止复用证据闸、案卷闸、鉴定闸、人测闸、侵权闸、名单闸、时效闸、求偿闸、现证闸、举证闸、调令闸、保全闸、评估闸、争议闸。预留不得占用：立案闸、起诉闸、管辖闸、鉴定闸。本窗主行只能是 `RJ#`，禁止 `EV#`、`JE#`、`AJ#`、`JT#`、`RS#`、`QG#`、`A#`、`N#`。主路径只用 `Q-人据`，禁止用 `Q-据`、`Q-卷`、`Q-责`、`Q-人测`、`Q-伤鉴`、`Q-求`、`Q-诉`、`Q-现`、`Q-调令`、`Q-举证` 作主路径。邻窗 `Q-人据` 只作转介进本窗；本窗打开为主路径，不是已入卷、不是已质证。人据闸打开不等于已入卷不等于已质证不等于已提交不等于已立案不等于已保全不等于已公证不等于伤残已定不等于侵权已成立。截图不是电子数据原件。对方控制不得推定存在或有利。材料缺失不是事件未发生。认定书不是举证责任转移。场所安保不是过错推定。普通保存通知不是证据保全。复制不是已固定。哈希不是已公证。已读不是到达。红旗不是保全已完成。案卷不是诉状。治疗未稳定不得转介启动评残。未知不写零。不写诉状。不写保全申请终稿。不指导违法取证。不选定法院。不代提交。不定残。不定罪。不保证采信。不保证胜诉。

`depends-on` 为空。主成果是侵权总图转 `评估人身侵权责任`。主成果是鉴定申请稿转 `准备伤残鉴定材料`。主成果是测算工作表转 `测算人身损害赔偿`。主成果是起诉包转 `提起人身损害一审`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：人身损害已发生，单方需要把已出现争点做成可回链的要件、举证责任、材料与合法补证矩阵，而不是只要总图或只要诉状。「已经备份」「对方一定有监控」「今天必须齐证」「先按十级」仍正触发，成果状态 `草案`。控制方、原件、合法性未核验仍正触发：有可编号待证要件或材料碎片则人据闸打开或半开，第 6 节出 `RJ#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须齐证终稿」才关闸，仍交十节，第 6 节不出 `RJ#` 终稿，第 7 节不得出诉状、保全终稿或已质证，窗口不关。用户要把对方控制写成内容有利、把截图写成原件、把缺失写成未发生、把案卷写成已质证、把未知写成零，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `RJ#` 草案。不得因「不写诉状」「不指导违法取证」改走负触发关窗。利益冲突未解不是整体停止。无死亡且治疗未相对稳定：不关人据闸；伤残或护理依赖送检格停止或 `无法估计`；禁止转介启动评残。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是侵权总图（转 `评估人身侵权责任`）；
- 主成果是测算工作表（转 `测算人身损害赔偿`）；
- 主成果是鉴定申请稿（转 `准备伤残鉴定材料`）；
- 主成果是索赔通知且不建卷（转 `准备侵权索赔通知`）；
- 主成果是可提交一审起诉包（转 `提起人身损害一审`）；
- 主成果是首次应诉答辩（转 `应对人身损害一审`）；
- 主成果是现场或电子保全步骤（转 `保全现场监控与电子证据`）；
- 主成果是保存通知正文（转 `准备监控保存通知`）；
- 主成果是公证保全（转 `准备人身案件公证保全`）；
- 主成果是调查令或法院调查（转 `申请人身案件调查令或取证`）；
- 主成果是保全必要性或申请稿（转 `评估证据或财产保全必要性` 或 `准备财产或证据保全申请`）；
- 主成果是工伤行政卷或劳动能力鉴定材料（转劳动领域；夹带第三人只开 `评估工伤与第三人侵权竞合` 接口）；
- 主成果是医疗损害鉴定检材或病历封存（转医疗医药领域）；
- 海事专门证据（转海事领域）；
- C 端大众准备包（只分流，本窗不降级实施）；
- 尚未发生损害，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）。

双方秘密、伪造、隐匿、偷拷监控、购买个人信息、非法侵入、秘密定位、统一证人口径、摆拍冒充原始现场、违法取证**不在负触发表**，走整体停止。「对方控制即有利」「截图即原件」「案卷即已质证」「未知写零」「先按十级」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不写诉状」「不指导违法取证」「不代提交」是交付禁令，不是负触发。主成果才转；出现「证据」「案卷」一词不是转出。

## 建立工作坐标

确认：建卷授权；单方立场；待证争点；法域；诉讼或协商阶段；已持有材料；对方或第三人控制的监控、病历、保单线索；举证期限或覆盖风险线索。

口头「已经备份」「对方电脑里一定有」「今天必须齐证」只登记 `S#`／`V#`。不得升格已入卷或已质证，**不得单独算作开闸材料**。可编号待证要件或材料碎片可开闸。本窗不执行发送，不代提交，不指导违法取证。

立场只许受害人、近亲属、被指侵权人或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：人据闸关闭，仍交十节，不是整体停止。无书面授权但单方立场已闭合、且已有碎片：人据闸部分打开，仍交十节，不是整体停止。提出伪造、隐匿、偷拷、非法侵入、统一证人口径或违法取证：第一次提出即整体停止，不以「坚持」为门槛，不得给替代违法方案。利益冲突未解：不是整体停止。开口不等于立场闭合。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关文书；`C#` 保单了结或弃权文本；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`RJ#` 人据行；`V#` 版本；`E#` 证据形态回链（载体、控制方、原件或复制、提取人，不是已质证证明，不是已入卷证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`EV#`、`JE#`、`JT#`。技能正文中的条号是检索锚点，不是已核验 `L#`。合法取得判断只用三值。未知不写零。无 `E#` 不得写已入卷。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。截图 ≠ 原件。对方控制 ≠ 存在或有利。缺失 ≠ 未发生。认定书 ≠ 举证责任转移。保存通知 ≠ 证据保全。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或裁判案例检索。本窗是证据矩阵，**不要**用 `search_template` 生成已入卷、已质证、诉状或保全终稿。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现对方控制即有利、截图即原件、认定书即转移举证责任、场所安保即过错推定的反例；案例只比较事实差异与翻转条件，不写成必然采信。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除场所推定条、2001 年证据规定第三十四条逾期失权、1991／2017 年民诉旧条号、证据规定第二十五条所引旧民诉第八十一条当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的分配、排除、期限或保全法律效果保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民诉（2023 修正）第六十七条当事人对自己提出的主张有责任提供证据；第六十八条及时举证与逾期说明。民诉解释第九十条、第九十一条。民法典第一千一百六十五条过错责任，法律规定才推定。第一千一百九十八条场所安保是过错责任加第三人相应补充，不是过错推定。民诉第八十四条证据保全。解释第一百一十二条书证提出须诉讼中申请法院责令，诉前不得写成拒不提交即内容真实。证据规定（2019）第十四条、第十五条电子数据原件；第三十四条鉴定材料须经质证。噪声：1991／2017 民诉旧第六十四条、第八十一条；2001 年证据规定第三十四条逾期失权；2003 解释已删除场所推定。技能正文条号不是 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变分配、排除或期限的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补对方控制不是有利、截图不是原件、认定书不是举证责任转移、场所安保不是过错推定、保存通知不是保全的反例。
- `search_case_by_fact` 只比较事实差异与翻转条件。无类案不得写成已入卷或已质证。禁止用类案补造监控或病历内容。建立类禁止用 `search_template` 升格已入卷、已质证、诉状或保全终稿。

工具不可用时继续材料编目和控制方登记；举证责任、非法排除、举证期限、保全法律效果字段停止。不得拒跑，不得凭记忆写成已入卷或已质证。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、人据闸与不关窗

主成果才整案转出。双方秘密、伪造、偷拷、违法取证第一次停。对方控制即有利、截图即原件、案卷即已质证不关窗。闸关仍交十节，第 6 节不出 `RJ#` 终稿。利益冲突未解不是整体停止。禁止把鉴定闸写进本窗节点 0。

### 2. 待证要件与强制接口

行为、归责、损害连续、因果既往、主体保险、受害人过错、已付基金分列。本节禁止出 `RJ#` 终稿。

### 3. 人据闸与路径 `Q#`

本节禁止出 `RJ#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-人据`。

### 4. 人据行 `RJ#`

待证要件、材料形态、支持／不利、控制方、合法取得。状态 `草案`。禁止升格已入卷、已质证、已保全。无 `E#` 不得写已入卷。

### 5. 保全、鉴定、测算与起诉接口

保存、保全、公证、调查令、鉴定、测算、起诉只开接口。第 7 节不得夹带 `RJ#` 终稿或诉状绕闸。未稳定不得转介启动评残。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造、隐匿、偷拷监控、非法侵入、统一证人口径、摆拍冒充原始现场或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。不得给替代违法方案。无一可编号碎片：人据闸关闭，仍交十节，不是整体停止。无书面授权但有碎片：人据闸部分打开，不是整体停止。利益冲突未解：不是整体停止。禁止把单点违法取证降级为其余目录继续编目。
- `字段停止`：举证责任、书证提出、电子数据原件、非法排除、举证期限、保全条件、施行日未核验。对方控制即有利、截图即原件、案卷即已质证、未知写零、先按十级：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `RJ#` 草案。
- `目标停止`：主目标变为诉状、鉴定申请、测算终稿、保全或调查令终稿。禁止把「对方控制即有利」当作用户错误主张时的目标停止；那是不关窗。

禁止指导伪造、隐匿、威胁或违法取证。不给胜诉率。不定罪。不定残。不选定法院。不代提交。未知不写零。不写诉状。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。人据闸关闭仍交十节，第 6 节不出 `RJ#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `RJ#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。人据闸未打开时不得交付「已入卷」或「已质证」。边界见 [路由](references/routing.md)。
