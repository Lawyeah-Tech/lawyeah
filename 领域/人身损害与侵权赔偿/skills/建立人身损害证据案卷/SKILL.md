# 建立人身损害证据案卷

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“人身损害证据案卷矩阵”：争点要件、举证责任、支持与不利材料、控制方、合法取得、缺口、合法补证接口和最晚时点。

`depends-on` 为空。本任务不是策略总图、鉴定申请、测算终稿、保全申请或起诉状。

## 工作边界

正触发：人身损害已发生，需要把已出现争点做成可回链的要件—举证—材料—补证矩阵。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要策略总图或综合提问夹带管辖／时效／金额终稿（转 `评估人身侵权责任`）；
- 只要诉状或答辩（转 `提起人身损害一审` / `应对人身损害一审`）；
- 主成果是工伤行政卷宗或劳动能力鉴定材料（转劳动）；
- 主成果是医疗损害鉴定检材或病历封存（转医疗）；
- 只要测算工作表（转 `测算人身损害赔偿`）；
- 只要鉴定申请稿（转 `准备伤残鉴定材料`，闸未开则不转介启动）；
- 只要保存通知、诉前／诉中保全申请、调查令或公证保全终稿（转对应原子）；
- 未定残大众准备包（C 端 007，只分流，本任务不降级实施）；
- 海事专门证据。

用户要求偷拷监控、购买个人信息、非法侵入、秘密定位、统一证人口径、伪造或隐匿材料：不是负触发，走停止。

本任务不生成诉状或胜诉率，不指导伪造、隐匿或违法取证，不选定法院，不输出唯一举证截止日。

## 建立案卷坐标

确认：使用者与授权；单方立场；待证争点；法域；诉讼或协商阶段；已持有材料；对方或第三人控制的监控、病历、保单线索；举证期限或覆盖风险线索。

同时掌握双方秘密或未解利益冲突：`整体停止`，不得以选边治愈，也不得改走负触发去出对一方有利的案卷或转介发送版函件。不能因对方控制而推定材料存在或内容有利。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关文书；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 争点；`EV#` 证据条目；`V#` 案卷版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。合法取得状态只用 `现有依据支持合法`、`现有依据不支持合法`、`依据不足，无法形成结论`。技能正文中的条号是检索锚点，不是已核验 `L#`。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验举证责任、书证提出命令、电子数据原件、非法证据排除、举证期限和证据保全入口等将被写入 `L#` 的现行规则；不可用则这些字段停止。
- 已有检索真实返回的 `regulation_id` 且宿主暴露 `get_law_detail` 时，用其核验将改变分配、排除或期限的条文正文，再写入 `L#`。未暴露则不得编造 `regulation_id`，也不得把摘要条号或技能正文条号写成已核验 `L#`。
- `search_practiced` 补监控调取、病历复制、认定书证明力和补证时点实务。
- 特殊事实可用 `search_case_by_fact`。案例只比较差异，不写成证据必然采信。

工具不可用时继续材料编目和控制方登记；举证责任分配、非法证据排除、举证期限和保全法律效果字段停止。

## 判断节点

执行顺序和停止条件以 [建卷方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、安全和要件拆分

工伤行政卷、医疗鉴定检材、海事整案转出。按已出现事实拆 `Q#`，不是默认闭集。鉴定闸关闭时不得转介启动评残。

### 2. 举证责任

一般过错由主张方证明过错。特殊路径的推定或倒置必须核验现行条文后才写。场所安保不得写成过错推定。事故认定书、鉴定意见不转移举证责任。

### 3. 编目、不利材料和合法取得

支持与不利并列。截图不是电子数据原件。对方控制不得推定存在。首次要求违法取证：该部分或整体停止。

### 4. 缺口与合法补证接口

保存通知、公证、调查令、法院保全只列接口和转介，不出申请终稿。普通保存通知不等于证据保全。

### 5. 时点与禁止

最晚时点能确定才写日期，否则写触发事件。禁止伪造、摆拍冒充原始现场、隐匿既往、威胁证人鉴定人。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；基础事实无法建立；用户提出全面违法取证方案。整体停止优先于负触发。不以「坚持」为门槛。
- `该部分整体停止`：用户就某材料提出伪造、隐匿、非法侵入、购买隐私、统一证人口径或秘密定位。第一次提出即停，不提供方法。
- `字段停止`：举证责任、非法证据排除、举证期限或保全条件未核验。
- `目标停止`：主目标变为诉状、鉴定申请、测算终稿、保全或调查令终稿。

禁止指导伪造、隐匿、威胁或违法取证。不给胜诉率。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。节点 0 整案转出或整体停止时不得填满十节实体。边界见 [路由](references/routing.md)。
