# 建立人身损害证据案卷方法

本文件是可执行判断节点。截图不是电子数据原件。对方控制不得推定存在或有利。材料缺失不是事件未发生。认定书不是举证责任转移。场所安保不是过错推定。普通保存通知不是证据保全。复制不是已固定。哈希不是已公证。已读不是到达。红旗不是保全已完成。案卷不是诉状。治疗未稳定不得转介启动评残。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已入卷、已质证、选定法院、代提交、未知写零。本任务不定罪，不定残，不写诉状，不指导违法取证。本窗闸名只能是人据闸，禁止复用证据闸、案卷闸、鉴定闸、人测闸、侵权闸、名单闸、时效闸、求偿闸、现证闸、举证闸、调令闸、保全闸、评估闸、争议闸。预留不得占用：立案闸、起诉闸、管辖闸、鉴定闸。本窗 `RJ#` 是人据行。主路径只用 `Q-人据`，禁止用 `Q-据`、`Q-卷`、`Q-责`、`Q-人测`、`Q-伤鉴`、`Q-求`、`Q-诉`、`Q-现`、`Q-调令`、`Q-举证` 作主路径。英文 id 禁止使用，一律用中文技能名 `建立人身损害证据案卷`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991 年民诉第六十七条公证证明、1991 年第八十四条公告送达、2017 年民诉旧条号、2001 年证据规定第十四条分类编号、第三十四条逾期失权、2015 年民诉解释第九十条已被修改文本、已失效《侵权责任法》、2003 年人身损害赔偿解释已删除场所推定条、把对方控制写成内容有利或把截图写成原件时记为噪声。禁止指导伪造、隐匿、偷拷监控、购买个人信息、非法侵入、秘密定位、统一证人口径、摆拍冒充原始现场或违法取证。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现待证要件或材料碎片扫描，不是默认闭集。
`RJ#` 固定列：`编号｜待证要件｜材料形态｜支持／不利｜控制方｜合法取得｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已经入卷」一笔。无 `E#` 不得写已入卷。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-人据`。禁止 `EV#`、`JE#`、`AJ#`、`JT#`、`RS#`、`QG#`、`A#`、`N#`。一行一个待证要件或材料碎片。

口头「已经备份」「对方一定有监控」「今天必须齐证」「先按十级」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。支持材料与不利材料并列。

实务上：对方控制不得推定存在或有利。截图与原件分列。认定书是证据不是举证责任转移。场所安保是过错责任加第三人相应补充，不是过错推定。保存通知不是证据保全。未稳定不得转介启动评残。伪造或违法取证第一次整体停止，不得该部分停后继续编其余目录。

## 节点 0　分流、立场、人据闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造、隐匿、偷拷监控、购买个人信息、非法侵入、秘密定位、统一证人口径、摆拍冒充原始现场、违法取证不进负表。利益冲突未解不进整体停止。不写诉状、不指导违法取证、不代提交不是负触发。禁止把鉴定闸写进本窗节点 0。

整案转出只交付第 1、2、10 节，不出 `RJ#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是侵权总图 | 负触发 `评估人身侵权责任` |
| 主成果是测算工作表 | 负触发 `测算人身损害赔偿` |
| 主成果是鉴定申请稿 | 负触发 `准备伤残鉴定材料` |
| 主成果是索赔通知且不建卷 | 负触发 `准备侵权索赔通知` |
| 主成果是可提交一审起诉包 | 负触发 `提起人身损害一审` |
| 主成果是首次应诉答辩 | 负触发 `应对人身损害一审` |
| 主成果是现场或电子保全步骤 | 负触发 `保全现场监控与电子证据` |
| 主成果是保存通知正文 | 负触发 `准备监控保存通知` |
| 主成果是公证保全 | 负触发 `准备人身案件公证保全` |
| 主成果是调查令或法院调查 | 负触发 `申请人身案件调查令或取证` |
| 主成果是保全必要性或申请稿 | 负触发 `评估证据或财产保全必要性` 或 `准备财产或证据保全申请` |
| 主成果是和解谈判要点 | 负触发 `谈判人身损害和解` |
| 主成果是工伤行政卷或劳动能力鉴定材料 | 整案转劳动；夹带第三人只开 `评估工伤与第三人侵权竞合` |
| 主成果是医疗损害鉴定检材或病历封存 | 整案转医疗医药 |
| 海事专门证据 | 整案转海事 |
| C 端大众准备包 | 只分流，本窗不降级实施 |
| 尚未发生损害，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 「不写诉状」「不指导违法取证」「不代提交」 | 交付禁令，不是负触发 |

出现「证据」「案卷」一词不是转出。混合信号：工作中被第三人撞伤，民事卷可留，工伤行政段只分流。

人据闸打开（可出 `RJ#` 草案，仍不得标「已入卷／已质证／已保全／伤残已定」）须同时满足：单方无冲突立场已闭合；主成果是证据矩阵，不是诉状、不是函、不是精算、不是鉴定申请；至少一项可编号待证要件或材料碎片。口头「已经备份」不算单独开闸材料。

人据闸部分打开：已有碎片，但控制方、合法性或原件未闭合；对应格待核；仍交十节。无书面授权但单方立场已闭合且已有碎片：人据闸部分打开，仍交十节，不是整体停止。无死亡且治疗未相对稳定：人据闸打开或半开；伤残或护理依赖送检格停止或 `无法估计`；禁止转介启动评残。

人据闸关闭（仍正触发）：无一可编号碎片。「今天必须齐证终稿」而无最小碎片不得开闸。不出 `RJ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `RJ#` 终稿，**第 7 节不得出诉状、保全终稿或已质证**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「对方控制即存在或有利」「截图即原件」「材料缺失即未发生」「认定书即举证责任转移」「场所安保即过错推定」「保存通知即证据保全」「复制或哈希即已固定或已公证」「已读即到达」「口头理齐即已入卷」「案卷即已质证或已立案」「红旗即保全已完成」「先按十级」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `RJ#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 人据闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造、隐匿、偷拷监控、购买个人信息、非法侵入、秘密定位、统一证人口径、摆拍冒充原始现场或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛，不得给替代违法方案，不得该部分停后继续编其余目录。利益冲突未解不是整体停止。

## 节点 1　待证要件与强制接口

一行一个待证要件。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `RJ#` 终稿。行为、归责、损害连续、因果既往、主体保险、受害人过错、已付基金分列，不得合成「侵权责任」一笔。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 要件 | 行为、归责、损害连续、因果既往、主体保险、受害人过错、已付基金分列 | 合成「案卷齐了」；构成侵权写成伤残已定 |
| 材料 | 原件／复制／电子／口头／认定书／病历／保单分列 | 截图升格原件；复制升格已固定 |
| 控制方 | 己方／对方／第三人 | 对方控制推定存在或有利 |
| 合法取得 | 取得方式、合法性判断三值 | 指导偷拷、侵入、隐匿、摆拍冒充原始 |

检索锚点（写入 `L#` 前须核验）：民事诉讼法（2023 修正）第六十七条当事人对自己提出的主张有责任提供证据；第六十八条及时举证与逾期说明。民诉解释（2022 修正）第九十条、第九十一条。民法典第一千一百六十五条过错责任，法律规定才推定。第一千一百九十八条场所安保是过错责任加第三人相应补充，不是过错推定。民诉第八十四条证据保全（噪声：1991 年第八十四条是公告送达）。解释第一百一十二条书证提出须诉讼中申请法院责令，诉前不得写成拒不提交即内容真实。解释第一百零六条非法证据排除。证据规定（2019）第十四条电子数据范围、第十五条电子数据原件；第三十四条鉴定材料须经质证（噪声：2001 年第三十四条逾期失权）。第四十一条单方委托对方反驳申请法院鉴定不是重鉴。噪声：1991／2017 民诉旧第六十四条、第八十一条；2001 年证据规定第十四条分类编号。

场所安保不得直接写成过错推定。受害人就安保义务人未尽义务提出具体事实后，义务人是否应证明已履行：实务观点待核，**不得**写成法定举证责任倒置。特殊侵权的举证责任必须运行时核验现行条文后再写。无对应事实不得打开该分配。

## 节点 3　人据行 `RJ#`

按已出现待证要件或材料碎片扫描，不是默认闭集。每条须能指向要件、材料或控制方之一。

无 `E#` 不得写已入卷。状态默认 `草案`。一次只推荐下一步。未知不写零。

编目纪律：

- 监控、巡检、行车记录仪、平台后台：记录拟覆盖时段和覆盖风险，**不**因控制方存在而推定画面存在。手机翻拍、截图、未经授权的转存只作副本，不得标原件，不得指导当场拷贝第三人系统。
- 病历：按就诊机构连续编号，冲突并列，不得选对用户有利的一版。
- 聊天、短信、邮件：保留原设备上下文；截图只作副本。当事人以电子数据作为证据的，应当提供原件；与原件一致的副本、打印件或其他可显示输出介质视为原件。检索锚点：证据规定第十四条、第十五条。
- 视听资料应提供原始载体。检索锚点：第十五条第一款。
- 不利材料必须入卷，包括既往伤病、饮酒、闯红灯、未遵医嘱、已收款、基金已付、和解／弃权文本。提出删除不利材料视为隐匿，第一次整体停止，不得该部分停后继续编其余目录。
- 事故认定书：可以作为证据，有相反证据可以推翻；**不是**举证责任转移的法定依据，也不是民事责任比例终局。
- 不能单独作为认定案件事实的根据：当事人陈述、存有疑点的视听资料或电子数据、无法与原件核对的复制件等，只标红旗，不作三性裁决。

热冲突强制处理：

- 对方控制即有利／截图即原件／缺失即未发生／认定书即转移举证责任／场所安保即过错推定／保存通知即保全／复制即已固定／已读即到达／案卷即已质证／未知写零／先按十级 → 该格不支持或字段停止；仍出其他 `RJ#`。
- 无一碎片 → 关闸，不出 `RJ#` 终稿，窗口不关。
- 指导伪造、隐匿、偷拷、违法取证 → 整体停止，不是该格不支持，不得继续编其余目录。

## 节点 4　保全、鉴定、测算与起诉接口

第 7 节只开接口，不得夹带 `RJ#` 终稿或诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待要件编号」，不得补写已入卷。不代提交。不选定法院。未稳定不得转介启动评残。普通保存通知不得写成民诉第八十四条证据保全。诉前不得适用解释第一百一十二条拒不提交推定。
