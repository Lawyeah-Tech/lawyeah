# 边界与路由

## 正触发

需要人身损害要件、举证责任、材料和合法补证矩阵，而不是总图、诉状或某一份申请终稿。

受害人开口且委托范围是建卷时，不因口语化咨询整体停止。双方秘密、伪造、隐匿或违法取证的停止，优先于负触发。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 总图，或综合提问夹带管辖／时效／金额终稿 | `评估人身侵权责任` |
| 诉状或答辩 | `提起人身损害一审` / `应对人身损害一审` |
| 测算工作表 | `测算人身损害赔偿` |
| 鉴定申请稿 | `准备伤残鉴定材料`（闸未开则本窗停止，不转介启动） |
| 现场监控紧急保全方案 | `保全现场监控与电子证据`（未安装则 `unavailable`，本任务只留红旗） |
| 保存通知正文 | `准备监控保存通知` |
| 公证保全 | `准备人身案件公证保全` |
| 调查令或法院取证申请 | `申请人身案件调查令或取证` |
| 保全必要性或保全申请稿 | `评估证据或财产保全必要性` / `准备财产或证据保全申请` |
| 工伤行政卷 | 劳动领域 |
| 医疗鉴定检材 | 医疗医药领域 |
| C 端 007 | 大众准备，只分流不回改 |

“今晚去物业把监控拷出来／买份定位记录”不是负触发，是停止。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 监控即将覆盖 | `准备监控保存通知`；情况紧急 `保全现场监控与电子证据` |
| 书证或电子数据在对方控制且已进入诉讼 | `申请人身案件调查令或取证` |
| 原件或现场状态易失需公证 | `准备人身案件公证保全` |
| 需法院保全 | 先 `评估证据或财产保全必要性` |
| 治疗相对稳定且要评残 | `准备伤残鉴定材料` |
| 参与度、既往伤病 | `评估因果关系与既往伤病` |
| 工作中第三人 | `评估工伤与第三人侵权竞合` |
| 金额缺口 | `测算人身损害赔偿`（未知不写零） |
| 要发函或起诉 | `准备侵权索赔通知` / `提起人身损害一审` |

## 易混

“证据够不够、还缺什么合法材料”正触发。“怎么偷到监控”停止。只要策略不要矩阵时负触发。未稳定却要“先把十级鉴定材料备上”：本窗鉴定闸关闭，不转介启动。
