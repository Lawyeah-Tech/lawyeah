# 输出合同

按触发结果选择交付形状。禁止在缺输入时用估计材料填满栏目。禁止把保存通知写成法院保全。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出 | 第 1、2、10 节。禁止要件表、举证分配和补证终稿 |
| 该部分整体停止（单类违法取证） | 十节表头可在；该 `EV#` 只写停止原因，不给方法。其余合法编目可部分形成 |
| 整体停止 | 第 1、10 节。禁止案卷矩阵、补证步骤、选边策略。双方秘密或全面违法取证时，整体停止优先于负触发 |
| 鉴定闸关闭但仍正触发 | 十节表头均出现。伤残／护理依赖送检行必须停止或 `无法估计`，禁止转介启动评残。已有病历、现场、保险材料可编目。本行优先于「正触发且可建卷」 |
| 正触发且可建卷 | 下列十节表头均出现；字段停止的单元格填 `依据不足，无法形成结论` 或 `待核`，禁止省略后改填估计材料 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。每个 `EV#` 必须带合法取得判断。

## 1. 触发、单方立场、授权与成果状态

必须写明单方立场、授权范围、冲突筛查和鉴定闸是否打开。双方秘密未解不得进入“部分形成”。

## 2. 来源登记与 MCP 调用表

`S/D/R/L/I/G/Q/EV/V`。MCP 未调用也留一行。`L#` 不得直接抄技能内条号。

## 3. 争点要件表

完整 `Q#` 字段。只拆已出现事实。禁止铺开未出现的特殊侵权倒置。

## 4. 举证责任分配

未核验则字段停止。事故认定书、鉴定意见不写成举证责任转移。场所安保不得写成过错推定。

## 5. 证据编目

支持与不利并列。控制方、取得方式、原件或原始载体、合法取得必填。监控翻拍、聊天截图、转存文件标明副本。对方控制不得推定存在。公证真实性可反驳。

## 6. 易失证据与保全红旗

覆盖风险和触发事件。普通保存通知不等于法院保全。紧急固定、公证、保全申请只标转介。

## 7. 缺口与合法补证

只列合法步骤和转介原子。不交付保存通知、调查令、保全申请或鉴定申请终稿。

## 8. 最强反方材料

既往、过错、已付、弃权、认定书不利记载必须可见。

## 9. 风险与下一步

每项含可逆性。保存通知、保全、调查令、公证、鉴定、测算、起诉只作为转介。鉴定闸关闭时不得把“去评残”写成下一步。

## 10. 缺口、停止项与提示

本成果不是诉状、证据三性裁决、保全裁定或鉴定意见。禁止违法取证。
