# 边界与路由

## 正触发

已收到人身损害起诉状或应诉通知，需要首次答辩包，而不是管辖异议终稿或起诉状。

被告或保险人开口且委托范围是应诉草稿时，不因口语化咨询整体停止。双方秘密、保险人与驾驶人冲突、隐匿或伪造的停止，优先于负触发。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 原告起诉 | `提起人身损害一审` |
| 尚未收到文书、只是担心被告 | `评估人身侵权责任` |
| 只要管辖异议书终稿，或同时要异议书 | `提出人身案件管辖异议`（未安装则 `unavailable`）；本窗只留红旗 |
| 劳动应诉 | 劳动领域 |
| 医疗损害应诉 | 医疗医药领域 |
| 海事 | 海事领域 |
| 只要和解方案 | `谈判人身损害和解` |
| 只要反诉状终稿 | `评估反诉或抵销` |
| 大众答辩包 | C 端 012，只分流不回改 |

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 要写管辖异议书 | `提出人身案件管辖异议`；连结点展开 `评估人身损害管辖` |
| 时效抗辩要截止日 | `评估人身损害诉讼时效`（本窗只红旗） |
| 交强险限额、分项 | `评估道路交通事故责任与保险先行` |
| 金额抗辩要测算 | `测算人身损害赔偿` |
| 反诉条件 | `评估反诉或抵销` |
| 保险人限额、免责、追偿主成果 | `保险公司应对直接索赔`；分账 `评估道路交通事故责任与保险先行`。本窗只拆请求接口 |
| 庭审准备 | `准备人身损害庭审` |
| 过错、参与度 | `评估过错与原因力`；`评估因果关系与既往伤病` |

## 易混

保险人被单独或共同起诉时正触发，须拆限额抗辩，不得把驾驶人自认写成保险人自认。用户尚未收到文书、只是担心被告时负触发至评估。微信已读起诉状 PDF 不是答辩期间起算。只要管辖异议仍可与本任务并行红旗，但不在本窗出异议书终稿。
