# 边界与路由

## 正触发

已收到人身损害起诉状或应诉通知，需要首次答辩包。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 原告起诉 | `提起人身损害一审` |
| 只要管辖异议终稿 | `提出人身案件管辖异议`（未安装则 `unavailable`） |
| 劳动应诉 | 劳动领域 |
| 医疗损害应诉 | 医疗医药领域 |
| 海事 | 海事领域 |
| 只要和解方案 | `谈判人身损害和解` |
| 大众答辩包 | C 端 012，只分流 |

## 易混

保险人被单独或共同起诉时正触发，须拆限额抗辩。用户尚未收到文书、只是担心被告时负触发至评估。
