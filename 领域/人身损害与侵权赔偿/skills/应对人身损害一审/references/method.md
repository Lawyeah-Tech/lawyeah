# 应对人身损害一审方法

本文件是可执行判断节点。草稿不是已答辩。口头不是已答辩。已读不是已送达。不提出答辩状不是当然败诉。逾期只停该提交稿。承认请求不是当然认责。构成侵权不是伤残已定。认定书不是民事终局。无责不是关闭交强险。未投保不是当然连带。过时效须抗辩才审。驾驶人自认不是保险人自认。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已答辩、当然败诉、选定法院、代提交、未知写零。本任务不定罪，不定残，不执行发送，不把草稿写成已答辩。本窗闸名只能是答辩闸，禁止复用应诉闸、应对闸、起诉闸、立案闸、鉴定闸、管辖闸、评估闸。预留不得占用：立案闸、起诉闸、鉴定闸。本窗 `RD#` 是答辩行。主路径只用 `Q-辩`，禁止用 `Q-诉`、`Q-责`、`Q-伤鉴`、`Q-应`、`Q-签`、`Q-院` 作主路径。本窗 `Q-签` 只作「草稿即已提交答辩」不关窗码。英文 id 禁止使用，一律用中文技能名 `应对人身损害一审`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991 年民事诉讼法第一百二十八条调解判决、第一百三十条缺席判决、2017 年第一百二十五条当现行答辩期、2017 年第一百二十七条当现行管辖异议、已失效民法总则第一百九十三条、已失效《侵权责任法》、把草稿写成已答辩或把无责写成关闭交强险时记为噪声。禁止指导伪造答辩、隐匿证据或倒签。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现被诉碎片扫描，不是默认闭集。
`RD#` 固定列：`编号｜请求抗辩切片｜主体与保险人地位｜期限与缺席风险｜管辖／时效抗辩接口｜证据与自认红旗｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已答辩」或「当然败诉」。无 `E#` 不得写已答辩。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-辩`。禁止 `DB#`、`RQ#`、`K#`、`H#`、`A#`、`N#`。文件状态只用 `草案`、`停止`。禁止标 `待提交` 为已答辩。期限嵌在「期限与缺席风险」列：作出日／送达日／答辩期／管辖异议期／举证期分列，禁止一张截止卡。

口头「已经被诉了」「微信已读就算送达」「已经答辩了」「不答辩就败了」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：驾驶人承认栏与保险人承认栏分列。交强险不得以对抗被保险人的酒驾、无证、逃逸对受害人拒赔。未稳定：残疾金、护理依赖抗辩格 `无法估计`。保全只做红旗。反诉只开接口。

## 节点 0　分流、立场、答辩闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造或倒签答辩、隐匿证据、虚假诉讼、虚假陈述、违法取证不进负表。利益冲突未解不进整体停止。不代提交、不选定法院、不定残、不出反诉终稿不是负触发。禁止把鉴定闸写进本窗节点 0。

整案转出只交付第 1、2、10 节，不出 `RD#` 终稿。

出现「应诉」「答辩」「管辖」一词不是转出。同时要答辩草稿与管辖红旗仍正触发，异议只开接口。

答辩闸打开（可出 `RD#` 草案，仍不得标「已答辩／已提交／当然败诉」）须同时满足：单方无冲突立场已闭合；主成果是首次答辩草稿，不是起诉包、不是异议终稿、不是反诉终稿、不是庭审提纲；至少一项可编号起诉状、应诉通知或案号碎片。口头「已经被诉了」不算单独开闸材料。无死亡且治疗未相对稳定：答辩闸打开或半开，残疾金抗辩格 `无法估计`，窗口不关。

答辩闸部分打开：已有碎片，但送达、管辖、时效或保险人地位未闭合；对应格待核；仍交十节。无书面应诉授权但单方立场已闭合且已有碎片：答辩闸部分打开，仍交十节，不是整体停止。

答辩闸关闭（仍正触发）：无一可编号碎片。「今天必须出已答辩／保证驳回终稿」而无最小碎片不得开闸。不出 `RD#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `RD#` 终稿，**第 7 节不得出可提交答辩状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已答辩」「口头即已答辩」「已读即已送达」「网交即已提交」「不答辩即当然败诉」「过期仍要可提交」「认定书即民事终局」「无责即关交强险」「过时效即当然免责或法院依职权驳回」「应诉即管辖已定」「先按十级」「未知写零」「保证驳回」「此致某院」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `RD#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 答辩闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造或倒签答辩或送达回证、隐匿证据、虚假诉讼、虚假陈述或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。
若 if 已排期且主成果只要庭审提纲，then 目标停止，转 `准备人身损害庭审`。

## 节点 3　答辩行 `RD#`

按已出现被诉碎片扫描，不是默认闭集。每条须能指向请求抗辩、保险人地位、期限、管辖／时效或自认红旗之一。

无 `E#` 不得写已答辩。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止此致某院。拟提管辖异议：实体草稿停止或标明不得在裁定前提交。逾期只停该提交稿，仍出其他 `RD#`。

热冲突强制处理：

- 草稿即已答辩／已读即送达／不答辩即败诉／认定书即终局／无责即关交强险／过时效即当然免责／先按十级／未知写零／保证驳回 → 该格不支持或字段停止；仍出其他 `RD#`。
- 无一碎片 → 关闸，不出 `RD#` 终稿，窗口不关。
- 指导伪造答辩、隐匿、倒签、虚假诉讼 → 整体停止，不是该格不支持。

## 节点 4　管辖、反诉、庭审接口

第 7 节只开接口，不得夹带 `RD#` 终稿或可提交答辩状绕闸。闸关闭时第 7 节可写「闸未开，转介待被诉编号」，不得补写已答辩。不选定法院。不代提交。未稳定不得转介启动评残。反诉只开 `评估反诉或抵销`。

下一步只转介：`提起人身损害一审`、`评估人身侵权责任`、`评估人身损害管辖`、`提出人身案件管辖异议`、`评估人身损害诉讼时效`、`评估反诉或抵销`、`准备人身损害庭审`、`建立人身损害证据案卷`、`谈判人身损害和解`、`测算人身损害赔偿`、`准备伤残鉴定材料`、`评估责任主体与保险覆盖`、`评估道路交通事故责任与保险先行`、`保险公司应对直接索赔`、`应对人身案件保全裁定`、`应对人身损害二审`、`评估过错与原因力`、`评估因果关系与既往伤病`。禁止此致某院。

若 if 用户催促「草稿写完就算答辩了／已读就算送到／不答辩就败了／认定书无责交强险关掉／过了法院会看／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`／`无法估计`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「答辩闸与答辩行草案」。本窗不执行发送。不包含：已答辩、已提交、发送版答辩状、反诉状终稿、管辖异议终稿。禁止选边治愈。禁止草稿即已答辩。禁止认定书即终局。禁止无责即关交强险。禁止指导伪造或隐匿。答辩闸打开 ≠ 已答辩 ≠ 已送达 ≠ 当然败诉。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标答辩终稿已形成。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：机动车事故被告收到起诉状，治疗未相对稳定。用户主张草稿写完就算答辩了、微信已读就算送到、不答辩就败了、认定书无责交强险关掉、过了三年法院会依职权驳回、先按十级认残金、不清楚营养费先写零、此致某院。答辩闸打开或半开。`Q-签`、`Q-读`、`Q-败`、`Q-认`、`Q-无`、`Q-职`、`Q-残`、`Q-零`、`Q-院` 不打开为可靠路径。残疾金抗辩格 `无法估计`。交强险地位接口保留。第 6 节不得把已答辩、已送达、当然败诉、终局、关交强险、0 写入可执行 `RD#`；对应格 `现有依据不支持` 或字段停止；仍出请求拆解、送达待核、时效须主张、保险人分栏等其他 `RD#`。不关窗。不代提交。不选定法院。不定残。

场景②：用户同时交出己方「必须今晚交、落款改到上周、监控先藏起来」与对方「全责十级」口径。命中双方秘密＋倒签＋隐匿。第一次整体停止。只交第 1、10 节。不出 `RD#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代违法方案。
