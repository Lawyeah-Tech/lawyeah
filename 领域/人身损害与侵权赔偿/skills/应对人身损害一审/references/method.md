# 应诉方法

本文件是可执行判断节点。不得指导隐匿或虚假陈述。不代提交，不保证免于缺席或胜诉。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。期限状态只用 `待核`、`情景`、`停止`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文，或把 2017 年民事诉讼法第一百二十五条、第一百二十七条直接写成现行条号时记为噪声。民诉法 2023 修正后答辩、管辖异议条款编号必须运行时核验。

## 节点 0　分流、权限和安全

**整案转出**（只交付第 1、2、10 节）：

| 信号 | 转出 |
| --- | --- |
| 劳动争议或工伤待遇应诉 | 劳动领域 |
| 医疗损害应诉主轴 | 医疗医药 |
| 海事 | 海事 |

用户为原告：负触发至 `提起人身损害一审`。只要管辖异议终稿且无实体：负触发至 `提出人身案件管辖异议`（未安装则 `unavailable`，可与本任务并行红旗）。只要和解方案、反诉状终稿：负触发至对应原子。尚未收到文书：负触发至评估。C 端 012 只分流，不降级实施。

原告起诉状、对方律师函和己方内部文件分权。不得用原告未向被告披露的秘密撰写答辩。保险人客户与驾驶人共同应诉时，利益冲突未解则整体停止，不得选边出稿，不得把驾驶人陈述写成保险人自认。双方秘密未解：整体停止，优先于负触发。

## 节点 1　期限卡

每份 `K#`：文书名称、作出日、送达日、送达方式、效力凭证、期间类型、起算事件、待核截止。类型必须标明期间种类，开口登记，禁止闭集成唯一截止日。常见类型：`答辩期间`／`管辖异议期间`／`举证期限`／`保全或先予执行复议`／`鉴定申请期间`／`仲裁异议`／`上诉`。一受送达人一卡：驾驶人与保险人送达日不同不得共用一个 `K#`。仅有应诉通知、起诉状副本未送达：答辩和管辖异议截止日停止。

纪律：

1. 普通程序答辩期间自**收到起诉状副本之日**起算，不得用应诉通知作出日、立案日或法院内部流转日代替送达日。检索锚点：现行民事诉讼法答辩条款（2023 修正后常见为第一百二十八条，十五日，条号仍须核验）。被告不提出答辩状不影响审理，**不等于**已经缺席；缺席判决另核传票传唤不到庭等条件。两套风险分列红旗，**不保证免于缺席**。用户口述「后天截止」只登记 `S#`，禁止写入 `K#` 截止日。
2. 电子送达须有当事人同意或法定条件，并以送达信息到达受送达人特定系统之日为送达日；发送成功、邮件打开、已读均不是送达日。无同意或无到达凭证：送达日字段停止。保险人与驾驶人的电子送达同意分人核验。微信已读、截图不得写成已送达。
3. 简易程序、小额诉讼答辩期间运行时核验，不得默写十五日。涉外答辩期间另核。
4. 管辖异议应当在提交答辩状期间提出。检索锚点：现行民事诉讼法第一百三十条第一款（条号须核验）。与答辩期间分列，日期不明则两行都停止，不编唯一截止日。
5. 举证期限与答辩期间分列。管辖异议被驳回后重新指定举证期限只标接口，不编新的唯一截止日。
6. 逾期风险只作红旗。作出日或送达日不明：期限字段 `停止`。

## 节点 2　请求拆解

逐项 `Q#`：承认／否认／不知／抗辩。禁止概括“全部不认”而不拆项目。禁止把可让步金额或驾驶人责任比例写成诉讼自认。对己不利事实既不承认也不否认、经说明询问后仍不明确的，可能视为承认；不得把关键事实一律标「不知」来规避。共同被告中一人自认不得写成约束保险人。

常见抗辩接口（按已出现请求打开，不是闭集铺开）：

- 主体：非行为人、非用人者、非经营者、非本车外受害人；租赁借用所有人仅过错范围内共同承担，禁止当然连带。
- 归责：无过错、已尽安保、第三人原因、自甘风险、受害人故意或过错。场所安保不得写成原告须自证倒置。
- 因果：既往伤病、参与度、治疗中断。
- 项目：票据与治疗无回链、重复主张医保或交强险已付、被扶养人双计、未鉴定填十级、农村标准误用。未发生后续治疗不得被写成已发生。
- 保险：限额、分项须回链保单。交强险对受害人不得以对抗被保险人的酒驾、无证、逃逸等事由拒赔，赔偿后追偿只标接口；商业三者免责才走条款。分账终稿转 `评估道路交通事故责任与保险先行`。精神损害交强险优先是原告接口，保险人可记录请求但不得隐瞒该解释存在，也不得自动优先。
- 时效：分相对人并行情景，禁止唯一届满日，转介 `评估人身损害诉讼时效`。

事故认定书不利时，可列复核或民事证明力争议，不得教唆否认已亲历的事实。认定书不是民事责任终局，也不是保险人当然免责。

保险人抗辩不得把投保人、驾驶人陈述直接写成保险人自认，也不得写入保险人承认栏。用户仅为保险公司且要求按驾驶人口头全责撰写保险人答辩：该承认字段停止；共同代理而冲突未解：整体停止。限额、免责、追偿主成果转介 `保险公司应对直接索赔` 或 `评估道路交通事故责任与保险先行`，本窗只留接口。

## 节点 3　答辩草稿、应诉管辖与反诉

按拆解组织答辩草稿。不利事实必须写入。不代提交，稿件状态只用 `草案`／`发送前待核`／`停止`，禁止写成已提交。

**应诉管辖风险必须在草稿前明示：** 当事人未提出管辖异议，并应诉答辩或者提出反诉的，视为受诉人民法院有管辖权，但违反级别管辖和专属管辖规定的除外。检索锚点：现行民事诉讼法第一百三十条第二款（2023 修正增加“或者提出反诉”，条号须核验）。就实体内容答辩、陈述可能被认定为应诉答辩。拟提管辖异议或异议未决：实体答辩草稿字段停止，或标明不得在异议裁定前向法院提交实体答辩；本窗不写异议书终稿，转介 `提出人身案件管辖异议`。

表面有效仲裁条款未排除：仲裁异议期间与答辩期间分列，首次开庭前提出的接口待核，不得把答辩十五日当成仲裁异议截止日。实体答辩或反诉可能被视为放弃仲裁，须红旗；诉讼入口按管辖原子处理，本窗不得写应向某院应诉。

已付款、医保、交强险已付、基金已付、垫付：在原告请求范围内是抗辩或抵销接口，**不是**反诉，不得为冲医疗费而提起返还垫付反诉以免做成应诉管辖。互殴致原告伤害等独立反请求才评估反诉牵连、管辖、时效和风险，**不写反诉状终稿**。用户同时要答辩草稿和反诉状：本窗只留红旗。需要反诉状转介 `评估反诉或抵销`（未安装则 `unavailable`）。真反诉须再挂应诉管辖红旗。

## 节点 4　证据与禁止

证据按抗辩绑定。不利监控、聊天、既往、已付款必须写入 `Q#`、证据目录和答辩事实，不得只用第 10 节顶替入卷；删除视为隐匿，该部分停止。禁止隐匿监控、删除聊天、伪造不在场证明或指使证人。第一次提出即停止该部分，不以「坚持」为门槛。仅持有他方内部卷（只代理驾驶人却使用保险人拒赔底稿）按双方秘密整体停止。2017 年缺席判决旧条号（约第一百四十四条）不得默写为现行 `L#`。

原告未向本方披露的材料不得写入答辩。C 端 012 只分流，不把本节改成大众填空答辩。
