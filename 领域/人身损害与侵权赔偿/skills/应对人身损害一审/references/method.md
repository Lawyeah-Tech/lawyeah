# 应诉方法

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得指导隐匿或虚假陈述。

---

## 节点 0　分流与权限

| 信号 | 处理 |
| --- | --- |
| 劳动争议或工伤待遇应诉 | 转劳动 |
| 医疗损害应诉主轴 | 转医疗 |
| 海事 | 转海事 |
| 用户为原告 | 负触发至起诉原子 |
| 只要管辖异议终稿且无实体 | 负触发至管辖异议原子（未安装则 `unavailable`，可注明与本任务并行） |

原告起诉状、对方律师函和己方内部文件分权。不得用原告未向被告披露的秘密撰写答辩。保险人客户与驾驶人共同应诉时，利益冲突未解则停止策略输出。

---

## 节点 1　期限卡

每份 `K#`：文书名称、作出日、送达日、送达方式、效力凭证、期间类型、起算事件、待核截止。

普通程序答辩期间自收到起诉状副本之日起算，不得用应诉通知作出日代替送达日。电子送达须有同意或法定条件，否则送达日字段停止。已读不等于送达。

管辖异议期间与答辩期间分列。逾期风险只作红旗，日期不明不编唯一截止日。

---

## 节点 2　请求拆解

逐项 `Q#`：承认／否认／不知／抗辩。禁止概括“全部不认”而不拆项目。

常见抗辩接口：

- 主体：非行为人、非用人者、非经营者、非本车外受害人；
- 归责：无过错、已尽安保、第三人原因、自甘风险、受害人故意或过错；
- 因果：既往伤病、参与度、治疗中断；
- 项目：票据与治疗无回链、重复主张医保或交强险已付、被扶养人双计、农村标准误用或就高无证据；
- 保险：限额、分项、免责、酒驾无证逃逸条款（须回链保单）；
- 时效。

事故认定书不利时，可列复核或民事证明力争议，不得教唆否认已亲历的事实。

保险人抗辩不得把投保人陈述直接写成保险人自认。交强险精神损害优先是原告接口，保险人可记录请求但不得隐瞒该解释存在。

---

## 节点 3　答辩草稿与反诉

按拆解组织答辩草稿。不利事实必须写入。反诉（互殴致原告伤害、已超额垫付返还）只评估牵连、管辖、时效和风险，不自动生成反诉状。需要反诉状则转介（未安装则 `unavailable`）。

未提管辖异议并应诉答辩，可能被视为接受受诉法院管辖。须在草稿前明示该风险。

---

## 节点 4　证据与禁止

证据按抗辩绑定。禁止隐匿监控、删除聊天、伪造不在场证明或指使证人。第一次提出即停止该部分。

C 端 012 只分流，不把本节改成大众填空答辩。
