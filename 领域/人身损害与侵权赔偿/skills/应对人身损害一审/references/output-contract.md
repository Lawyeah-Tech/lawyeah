# 输出合同

按触发结果选择交付形状。禁止把已读写成送达。禁止把驾驶人自认写成保险人自认。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出 | 第 1、2、10 节。禁止答辩草稿和期限截止日 |
| 整体停止 | 第 1、10 节。禁止答辩草稿、策略抗辩。双方秘密或保险人与驾驶人冲突未解时，整体停止优先于负触发 |
| 拟提管辖异议或异议未决 | 第 1、2、3、4、6、10 节。第 7 节实体答辩草稿字段停止或标明不得在异议裁定前提交。禁止本窗出异议书终稿 |
| 正触发且可应诉 | 下列十节表头均出现；送达不明则第 4 节截止日停止；字段停止的单元格填 `依据不足，无法形成结论` 或 `待核`，禁止省略后改填唯一截止日 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。稿件状态只用 `草案`、`发送前待核`、`停止`。

## 1. 触发、单方立场、授权与成果状态

写明被告或保险人立场、冲突筛查。双方秘密或共同应诉冲突未解不得进入“部分形成”。

## 2. 来源登记与 MCP 调用表

`S/D/R/L/I/G/Q/K/H/V/E`。MCP 未调用也留一行。`L#` 不得直接抄技能内条号。

## 3. 文书登记与材料权限

作出日与送达日分列。已读不等于送达。原告未披露材料不得入答辩。

## 4. 答辩期限卡

期间类型分列：答辩／管辖异议／举证。送达不明或用户口述唯一截止日则截止日停止，口述只登记来源。不得用应诉通知作出日或已读起算。不答辩不等于缺席。不保证免于缺席。

## 5. 原告请求拆解

承认、否认、不知、抗辩分列。禁止概括全部不认。保险人与侵权人抗辩分列。驾驶人口头全责不得写入保险人承认栏。

## 6. 管辖与时效红旗

未提异议并应诉或反诉的风险必须在草稿前明示。级别管辖和专属管辖除外须可见。时效分相对人，禁止唯一届满日。管辖异议书、反诉状终稿只转介，本窗不写。

## 7. 答辩草稿

不利事实不得删除。驾驶人自认不得写成保险人自认。拟提管辖异议时本节省略或标明不得提交。不代提交。不得写成已提交。

## 8. 反诉评估接口

不附反诉状终稿。提出反诉可能构成应诉管辖须红旗。

## 9. 证据与禁止事项

不利证据必须写入拆解、证据目录和答辩事实。隐匿、伪造提出即停。

## 10. 缺口、停止项与提示

须列对方最强解释与不利证据，不得删除。

本成果不是免于缺席或胜诉意见，不是已提交答辩状。C 端 012 只分流。
