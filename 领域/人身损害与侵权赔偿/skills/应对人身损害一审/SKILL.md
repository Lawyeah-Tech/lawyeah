# 应对人身损害一审

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的被告或被诉保险人立场下，形成首次应诉答辩包：答辩期限卡、原告请求拆解、答辩草稿、管辖抗辩红旗、反诉评估接口和证据意见。

`depends-on` 为空。原告侧材料不得直接当作被告已掌握或已授权使用的秘密。本任务不代提交，不保证免于缺席或胜诉。

## 工作边界

正触发：人身损害被告或被诉保险人已收到起诉状或应诉通知，需要答辩、请求拆解和期限判断，而不是只要一份管辖异议终稿、也不是只要大众答辩包。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 用户实为原告、只要起诉状（转 `提起人身损害一审`）；
- 尚未收到文书、只是担心被告（转 `评估人身侵权责任`）；
- 只要管辖异议书终稿，或同时要异议书（转 `提出人身案件管辖异议`；未安装则 `unavailable`；本窗只留红旗）；
- 劳动应诉或工伤待遇应诉（转劳动）；
- 医疗损害应诉主轴（转医疗）；
- 海事应诉（转海事）；
- 已决定只谈和解、只要谈判方案（转 `谈判人身损害和解`）；
- 只要反诉状终稿（转 `评估反诉或抵销`）；
- 普通民事被告只要大众答辩包（C 端 012，只分流，本任务不降级实施）。

本任务**不写**管辖异议书终稿、反诉状终稿、和解协议正文或起诉状。用户同时要答辩草稿和异议书／反诉状：本窗只留红旗并转介。不保证免于缺席或胜诉，不指导隐匿或虚假陈述，不编唯一截止日。

## 建立应诉坐标

确认：使用者与授权；被告或保险人立场；收到的起诉状、应诉通知、举证通知；每份文书的作出日、送达日、送达方式和效力凭证；法域；材料来源与使用权限。

口头转述、截图、“已读”不得写成已送达。作出日与送达日不明时，期限字段停止，不编唯一截止日。同时掌握双方秘密，或保险人与驾驶人共同应诉而利益冲突未解：`整体停止`，不得以选边治愈，也不得改走负触发去出答辩或起诉。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料；`R#` 机关文书；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 原告请求；`K#` 期限卡；`H#` 抗辩；`V#` 稿件版本；`E#` 送达凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。期限状态只用 `待核`、`情景`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验答辩期间、管辖异议期间、应诉管辖、保险人抗辩和时效等将被写入 `L#` 的现行规则；不可用则这些字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变期限或应诉管辖结论的条文正文再写入 `L#`。不得编造 `regulation_id`，也不得把摘要条号写成已核验 `L#`。
- `search_practiced` 补电子送达、简易程序答辩期和缺席风险实务。
- `search_template` 只借答辩状栏目，不把范本当现行法或已提交文本。

工具不可用时继续文书登记和请求拆解；期限截止日和法律结论字段停止。2017 年民事诉讼法第一百二十五条、第一百二十七条不得默写为现行 `L#`。

## 判断节点

执行顺序和停止条件以 [应诉方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场和材料权限

劳动、医疗、海事应诉转出。原告材料与己方内部文件分权登记。保险人与驾驶人冲突未解则整体停止。

### 2. 答辩期限卡

每份机关文书单独一行。送达不明或用户口述唯一截止日：截止日字段停止，口述只登记 `S#`。管辖异议期间、举证期限分列，不得混成唯一截止日。

### 3. 请求拆解与管辖红旗

承认、否认、不知、抗辩分列。驾驶人自认不得写入保险人承认栏；用户坚持按驾驶人全责写保险人答辩：该承认字段停止。限额分账终稿转交通／保险专项。拟提管辖异议：实体草稿停止或标明不得在裁定前提交。

### 4. 答辩草稿与反诉接口

反诉只评估条件与风险，**不写**反诉状终稿。不代提交。

### 5. 证据与禁止事项

不利证据必须进入最强反方。拒绝隐匿既往、伪造监控或虚假陈述。提出即停。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；保险人与驾驶人利益冲突未解；用户提出隐匿证据、虚假陈述或伪造。整体停止优先于负触发。不以「坚持」为门槛。
- `字段停止`：作出日或送达日不明、动态规则未核验。
- `目标停止`：主目标变为管辖异议终稿、反诉状终稿、和解协议正文或起诉状。

禁止指导隐匿、伪造或代提交。不给胜诉率，不保证免于缺席。
