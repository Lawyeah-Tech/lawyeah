# 应对人身损害执行

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的被执行人立场下，形成不代提交的人身损害执行应对包：应对闸、`K#` 期限卡、`Obj#` 适格异议行（对执行行为／金额已履行／超范围或生活必需；禁止执行中改判）、`Pay#` 已履行与豁免财产。不保证解封或中止执行。不选定法院。不写死唯一截止日。未知金额不写零。

`depends-on` 为空。权利人申请执行转 `执行人身损害生效文书`。执行中分期或以物抵债转 `准备人身执行和解`。保全裁定复议转 `应对人身案件保全裁定`。尚未生效要上诉转 `提起人身损害上诉`。案外人异议之诉 P2 `unavailable`，本窗不代做。对执行依据不服转再审 P2，不在执行中改判。

## 工作边界

正触发：被执行人收到人身损害案件执行通知、报告财产令或查封冻结扣划裁定，需要执行行为异议或履行安排。「执行通知来了，金额算错了」正触发。已读起算异议期、保证必须解封、选定某院、过期仍要可提交异议终稿、申请执行时效过了当然不用还、执行中改判、未知已付写零，仍正触发：应对闸可关，对应格填 `现有依据不支持` 或字段停止，窗口不关，不得改走负触发，不得标异议终稿已形成。工伤待遇执行异议与第三人民事执行同时出现：本窗正触发，工伤段分流劳动，民事 `Obj#` 可留。被执行人主张超范围误冻生活必需或唯一住房：仍正触发限缩异议，不保证必须解封。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是权利人强制执行申请或财产线索（转 `执行人身损害生效文书`）；
- 主成果是执行中分期或以物抵债和解协议（转 `准备人身执行和解`）；
- 主成果是保全裁定复议或担保置换（转 `应对人身案件保全裁定`）；
- 主成果是尚未生效裁判的上诉状（转 `提起人身损害上诉`）；
- 主成果是先予执行申请（转 `申请先予执行医疗费`）；
- 纯案外人主张权属、只要案外人异议之诉或案外人对执行标的异议终稿（P2 `unavailable`；一句负触发，不填十节，本窗不代做）；
- 主成果已是再审或检察监督文书（P2 `unavailable`）；
- 纯工伤待遇执行且无第三人民事执行（转劳动）；
- C 端只要大众准备包（只分流）；
- 未成争改合同（审查起草搁置）。

隐匿转移、虚假申报、倒签过户、双方秘密**不在负触发表**，走整体停止。已读起算、保证解封、过期仍要异议稿、时效当然免责、执行中改判**不在负触发表**，窗口不关。

## 建立工作坐标

确认：使用者与授权；被执行人；执行案号；执行通知与裁定分列；作出日与送达日分列；送达方式与效力凭证；已履行凭证；生活必需或唯一住房线索；法域。

口头「已经送到」「微信已读就算到了」「后天截止」「必须今晚解封」只登记 `S#`。不得写入期限卡或保证解封。

同时掌握双方秘密，或权利人与被执行人同时交材料争同一份异议或解封方案，或保险人与驾驶人争同一份执行应对：`整体停止`，不得以选边治愈，也不得改走负触发。被执行人已开口且委托范围就是执行异议或履行安排、且未掌握对方秘密时，可推定被执行方立场。只要同时掌握双方秘密，无例外整体停止。提出隐匿、转移、毁损财产、把房子过户到亲戚名下、虚假申报财产、倒签过户或履行凭证：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`R#` 执行通知、裁定；`D#` 履行凭证、必要生活费用；`E#` 送达凭证；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`K#` 期限卡；`Obj#` 异议行；`Pay#` 已履行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。稿件状态只用 `草案`、`应对闸关闭`、`提交前待核`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。本任务默认 `草案`，不代提交。禁止「保证解封」「此致某院」「已读即起算」「过了两年当然不用还」。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：当事人、利害关系人认为执行行为违反法律规定的，可以向负责执行的人民法院提出书面异议；人民法院应当自收到书面异议之日起十五日内审查；对裁定不服的，可以自裁定送达之日起十日内向上一级人民法院申请复议；异议审查和复议期间原则上不停止执行；查封、扣押、冻结财产应当保留被执行人及其所扶养家属的生活必需费用和生活必需品；超过申请执行时效期间提出申请的，人民法院应当受理，被执行人对申请执行时效提出异议且审查成立的，裁定不予执行；被执行人拒绝报告或虚假报告财产的，可以罚款、拘留。技能正文条号不是 `L#`。噪声：2017 年民事诉讼法约第二百二十五条、第二百二十七条、第二百三十九条直接当现行、已读起算、保证解封、执行中改判、选定唯一法院、未知写零、案外人异议由本窗代做、隐匿转移可解封、过期仍出可提交异议终稿、复议期间停止执行、时效过了当然不用还。不可用则异议期间、复议效果、生活必需保留、申请执行时效抗辩、财产报告义务字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变异议期间、复议效果、生活必需保留、申请执行时效抗辩或财产报告义务结论的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补已读不当作送达、异议不当然停执行、唯一住房可查封、无凭证不得扣减、虚假申报有处罚、案外人异议之诉另走的实务反例。
- `search_template` 只借执行异议申请或财产报告栏目，不把范本当法定格式、已提交文本、发送版或指定唯一执行法院。

工具不可用时继续 `K#`／`Obj#`／`Pay#` 编目与执行文书事实；期限、停止执行、时效、解封字段停止。不得凭记忆写已读起算、保证解封、选定法院、执行中改判或未知写零。

## 判断节点

执行顺序和停止条件以 [执行应对方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、应对闸与不关窗

工伤三段分流，民事执行应对可留。双方秘密、隐匿转移、虚假申报第一次停。已读起算、保证解封、过期、时效当然免责、执行中改判不关窗。权利人申请负触发。案外人异议之诉一句负触发不填十节。

### 2. 期限卡 `K#`

自送达起算。已读、作出日不得起算。法院审查十五日自收到书面异议之日起算，不是当事人提出期间。复议常见十日，长度待核。过期只停异议稿。审查和复议期间原则上不停止执行。

### 3. 异议行 `Obj#`

对执行行为、超范围、计算错误、时效抗辩分列。对执行依据不服不得写入改判项。生活必需限缩待核，不保证解封。案外人标的异议不打开。

### 4. 已履行 `Pay#`

有凭证才支持扣减。未知不写零。迟延利息参数待核。不得承诺减免。

### 5. 草稿与邻接拆分

草案不代提交。分期转介执行和解。实体不服转再审 P2。不保证中止。不预填此致某院。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；权利人与被执行人同时交材料；保险人与驾驶人争同一份执行应对；提出隐匿、转移、毁损财产、把财产过户到亲戚名下、虚假申报财产、倒签过户或履行凭证、倒签送达。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：送达日、异议期限、复议效果、生活必需范围、申请执行时效未核验。应对闸未开则提交稿停止，窗口不关。用户要已读起算、保证解封、选定法院、过期仍交普通终稿、时效当然免责、执行中改判、未知写零则该格停止，窗口不关。
- `目标停止`：主目标变为权利人执行申请、执行和解终稿、保全复议、案外人异议之诉、上诉状或再审。保证解封、过期仍要异议稿不在目标停止。

禁止指导隐匿转移或虚假申报。不给解封率。不保证中止。不选定法院。不代提交。不编唯一截止日。不把未知写成零。不定残。不在执行中改判。

严格按 [输出合同](references/output-contract.md) 交付。应对闸未打开时不得交付异议终稿或保证解封。节点 0 整案转出或整体停止时不得填满十节实体。过期则异议稿停止。边界见 [路由](references/routing.md)。
