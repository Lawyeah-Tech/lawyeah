# 边界与路由

## 正触发

被执行人收到人身损害案件执行通知。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 隐匿转移 | 整体停止 |
| 权利人申请执行 | `执行人身损害生效文书` |
| 案外人异议 | `unavailable`（P2） |
| 执行和解文本 | `准备人身执行和解` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 拒不执行判决裁定犯罪风险 | 刑事红旗 |
| 劳动待遇执行异议 | 劳动领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“执行通知来了，金额算错了”正触发。“把房子过户到亲戚名下”停止。“车是我的不是被执行人的”案外人 P2。
