# 边界与路由

## 正触发

被执行人收到人身损害案件执行通知、报告财产令或查封冻结扣划裁定，需要执行行为异议或履行安排。「执行通知来了，金额算错了」正触发。已读起算异议期、保证必须解封、选定某院、过期仍要可提交异议终稿、申请执行时效过了当然不用还、执行中改判，仍正触发：应对闸可关，对应格停止，窗口不关。工伤待遇执行异议与第三人民事执行同时出现，仍正触发：工伤段分流劳动，民事 `Obj#` 可留。被执行人主张超范围误冻生活必需：仍正触发限缩异议，不保证解封。

双方秘密、隐匿转移、虚假申报、倒签过户的停止，优先于负触发。不得改走负触发去出一方异议稿或过户步骤。已读起算、保证解封、过期、时效当然免责、执行中改判不在下表。隐匿过户不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 权利人强制执行申请或财产线索 | `执行人身损害生效文书` |
| 执行中分期或以物抵债 | `准备人身执行和解` |
| 保全裁定复议或担保置换 | `应对人身案件保全裁定` |
| 尚未生效裁判的上诉状 | `提起人身损害上诉` |
| 先予执行申请终稿 | `申请先予执行医疗费` |
| 纯案外人异议之诉／案外人对执行标的异议 | P2 `unavailable`；一句负触发，不填十节，本窗不代做 |
| 再审或检察监督文书 | P2 `unavailable` |
| 纯工伤待遇执行且无第三人民事执行 | 劳动领域 |
| C 端只要大众准备包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「把房子过户到亲戚名下」「申报表倒签少报」「两边材料选边」不在本表，走整体停止。不得因「要求隐匿」写成负触发关窗。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 仅工伤待遇执行且无第三人民事执行 | 劳动领域 |
| 医疗损害主轴 | 医疗医药领域；民事执行应对可留 |
| 海事 | 海事领域 |
| 指导隐匿转移、虚假申报、倒签过户 | 整体停止 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。民事执行应对可留。拒执只打红旗，不出步骤。

## 易混

「执行通知来了，金额算错了」正触发。「微信已读起算、保证解封、此致某院、过了两年当然不用还、过期仍要异议终稿」正触发不关窗，闸可关，各格不支持。「把房子过户到亲戚名下」整体停止，不是负触发。「车是我爸的不是被执行人的」案外人 P2，一句负触发不填十节。「我要上诉改判」主成果是上诉或再审才转出；执行中改判该格不支持，窗口不关。「权利人要申请执行」走权利人窗。「想分期」走执行和解。
