# 输出合同

按触发结果选择交付形状。应对闸未打开不得交付异议终稿或保证解封。禁止选定唯一执行法院或预填「此致某院」。禁止已读、截图、作出日当异议期起算。禁止执行中改判。禁止保证中止或必须解封。禁止未知已付或利息写零。禁止胜诉率。禁止代提交。禁止选边治愈。不定残。禁止指导隐匿转移或虚假申报。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 应对闸关闭或节点 0 整案转出 | 第 1、2、10 节：关闭理由、送达待核和最小补证。可附停止的 `K#`／`Obj#`／`Pay#`。禁止异议终稿、保证解封、唯一截止日、选定法院。对民事执行可留时不得因工伤整案转出 |
| 整体停止 | 第 1、10 节。禁止 `Obj#`／`Pay#` 策略包、选边、过户或虚假申报步骤。双方秘密、隐匿转移、虚假申报、倒签过户第一次即停，优先于负触发；无选边治愈，无「坚持」门槛 |
| 用户要已读起算、保证解封、选定某院、过期仍交、时效当然免责、执行中改判（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；闸未开则仍只交 1、2、10；过期则异议稿节停止；不得改走负触发关窗；不得标异议终稿 `已形成` |
| 正触发且闸开（可部分开） | 下列十节表头均出现；期限、解封、时效未核验格待核；一行一类；禁止为填满而写保证解封、此致某院、已读起算或执行中改判 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入异议终稿已形成。双方秘密未解不得进入「部分形成」。每个 `K#`／`Obj#`／`Pay#` 必须带来源和三值判断。`L#` 不得直接抄技能内条号。已读起算、保证解封、时效当然免责若返回则记噪声。稿件状态默认 `草案`。

## 1. 触发、单方立场、授权与成果状态

应对闸开、部分开或关。被执行人立场必须标明。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。稿件默认 `草案`。不代提交。不保证解封。

## 2. 来源登记与 MCP 调用表

`S/R/D/E/L/I/G/K/Obj/Pay/V`。口头已读只登记 `S#`／`V#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 期限卡 `K#`

自送达起算。已读不得起算。审查十五日自收到书面异议之日起。复议常见十日待核。过期只停异议稿。审查和复议期间原则上不停止执行。

## 4. 异议行 `Obj#`

对执行行为、超范围、计算错误、时效抗辩分列。生活必需限缩待核，不保证解封。对执行依据不服不得改判。案外人不打开。

## 5. 已履行 `Pay#`

有凭证才扣减。未知不写零。不得承诺减免。分期只转介。

## 6. 财产报告与禁止事项

须如实报告。指导虚假申报、隐匿、过户到亲戚名下第一次整体停止。拒执只打红旗，不出步骤。

## 7. 异议草稿

草案，不代提交。过期则本节停止。不预填此致某院。

## 8. 工伤、保险与邻接分流

工伤段分流，民事可留。执行和解、权利人申请、保全复议只转介。案外人 P2。

## 9. 下一步与转介

转介执行申请窗、执行和解、保全复议、再审只点名。不写成发送版或「先转出资金再等裁定」指令。不代提交。不保证中止。

## 10. 缺口、停止项与提示

须列对方最强解释：微信已读就算异议期起算、过了两年申请的当然不用还、唯一住房必须解封、先提异议法院就不能划卡、此致某区法院、过了异议期也照交、判决不公平执行里把伤残改了、车是我爸的你们一并写案外人诉、两边材料都给你选边、把房子过户到亲戚名下、财产申报往前倒签少报。

本成果不是已提交异议、不是权利人执行申请、不是执行和解、不是保全复议、不是案外人异议之诉、不是再审、不是发送版、不保证解封、不是唯一截止日、不是选定法院。不代提交。禁止隐匿。
