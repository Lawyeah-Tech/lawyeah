# 执行应对方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。稿件状态只用 `草案`、`应对闸关闭`、`提交前待核`、`停止`。禁止胜诉率、必然责任比例、唯一必得总额、唯一截止日、选定法院、自行宣布伤残等级、保证解封、保证中止执行、代提交、未知写零、执行中改判。本任务不代提交。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、已失效《合同法》、2017 年民事诉讼法约第二百二十五条、第二百二十七条、第二百三十九条直接当现行、已读起算、保证解封、执行中改判、复议期间停止执行、时效过了当然不用还时记为噪声，不得写入 `L#`。禁止指导隐匿转移、虚假申报、倒签过户或违法取证。

`K#` 固定列：`编号｜文书名称｜文书类型（执行通知／执行裁定／查封冻结扣划裁定／报告财产令／其他）｜受送达人（被执行人）｜作出日｜送达日｜送达方式｜效力凭证｜期间类型（对执行行为异议提出／法院审查十五日／异议裁定复议／申请执行时效抗辩／财产报告，待核）｜起算事件｜期间长度待核｜待核截止｜过期是否只停提交稿｜稿件状态｜来源回链`。一受送达人一卡。禁止已读、作出日、口头告知起算。不写死唯一日历截止日。法院审查十五日＝收到书面异议之日起，不是当事人提出期间。复议常见自异议裁定送达之日起十日，长度待核。当事人提出窗口待核（常见执行程序终结前）。

`Obj#` 固定列：`编号｜分型（执行行为违法／超范围查封／计算错误或重复执行／申请执行时效抗辩／生活必需限缩／执行管辖｜禁止写成对执行依据实体改判）｜措施对象｜请求类型（撤销／限缩／中止／不予执行／保留生活必需）｜理由类型｜裁定或通知记载｜材料表面冲突｜判断三值｜是否请求停止处分（原则上不停止，担保停止待核）｜稿件是否可写入｜工伤待遇段（分流劳动，不写入民事结论）｜来源回链`。一行一类对象。案外人标的异议不打开。对执行依据不服不得写入改判项。

`Pay#` 固定列：`编号｜主文给付项｜依据文书与案号｜已履行凭证｜已履行金额（未知不写零）｜未履行｜迟延利息（参数待核，禁止写零）｜必要生活费用／豁免财产线索｜分期或以物抵债意愿（只转介，本窗不写和解终稿）｜状态｜来源回链`。无凭证不得扣减。不得承诺减免。不得保证解封。

口头「已经送到」、微信已读、截图只进 `S#`／`V#`，不得升格 `R#` 已送达或 `K#` 已起算。

## 节点 0　分流、立场、应对闸与不关窗

整案转出或闸关闭只交付第 1、2、10 节或标注停止的 `K#`／`Obj#`／`Pay#`，不得交付异议终稿，不得标保证解封。闸部分打开时：仅对可回链的民事执行行为给出草案，其余行停止或不打开。

| 信号 | 处理 |
| --- | --- |
| 主成果是权利人强制执行申请或财产线索 | 负触发 `执行人身损害生效文书` |
| 主成果是执行中分期或以物抵债 | 负触发 `准备人身执行和解` |
| 主成果是保全裁定复议或担保置换 | 负触发 `应对人身案件保全裁定` |
| 主成果是尚未生效裁判的上诉状 | 负触发 `提起人身损害上诉` |
| 主成果是先予执行申请 | 负触发 `申请先予执行医疗费` |
| 纯案外人主张权属、案外人异议之诉 | P2 `unavailable`；一句负触发，不填十节，本窗不代做 |
| 对执行依据不服、再审或检察监督 | P2 `unavailable`；本窗 `Obj#` 不得写入改判项 |
| 纯工伤待遇执行且无第三人民事执行 | 整案转劳动；夹带第三人民事执行则本窗正触发，工伤段分流，`Obj#` 可留并转介 `评估工伤与第三人侵权竞合` |
| 拒不执行判决裁定犯罪步骤 | 刑事红旗；指导隐匿走整体停止，不给出步骤 |
| 未成争改合同 | 审查起草本窗搁置 |

应对闸打开（可出 `Obj#`／`Pay#` 草案，仍不代提交、不保证解封）须同时满足：单方无冲突被执行人立场与授权；已有执行通知、裁定或等价 `R#`；主成果是执行行为异议或履行安排，不是权利人执行申请、案外人异议之诉、执行和解终稿、保全复议、再审；拟交付不含隐匿转移、虚假申报、倒签过户、执行中改判、选定某院、保证解封、发送版、代提交、未知写零。

闸关闭（仍正触发）：送达不明仍要写死截止；已读／截图／作出日起算；过期仍要可提交异议终稿；保证解封唯一住房或生活必需当然解封；保证异议期间中止执行；对执行依据不服要求本窗改判；「时效过了当然不用还」；未知利息写零；选定某院。闸未开则仍只交 1、2、10 节。过期：十节表头可出现，异议草稿节停止；`Pay#` 与合法履行安排可留。

「已读起算」「保证解封」「过期仍交」「时效当然免责」「执行中改判」「选定法院」**不关窗**。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或权利人与被执行人同时交材料争同一份异议／解封方案，或保险人与驾驶人争同一份执行应对且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出隐匿、转移、毁损财产、把财产过户到亲戚名下、虚假申报财产、倒签过户或履行凭证、倒签送达，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　期限卡 `K#`

检索锚点：当事人、利害关系人认为执行行为违反法律规定的，可以向负责执行的人民法院提出书面异议；人民法院应当自收到书面异议之日起十五日内审查；对裁定不服的，可以自裁定送达之日起十日内向上一级人民法院申请复议。2023 修正后常见第二百三十六条一类，条号运行时核验，不是 `L#`。2017 年约第二百二十五条不得默写为现行 `L#`。异议审查和复议期间原则上不停止执行。当事人提出窗口待核（常见执行程序终结前）；禁止默写自作出日起十五日。已读、截图、作出日不得起算。过期：异议稿停止，窗口不关。

## 节点 2　异议行 `Obj#`

一行一类执行行为。超范围查封、计算错误、重复执行、申请执行时效抗辩、生活必需限缩分列。生活必需费用和必需品应当保留，待核，不保证必须解封。唯一住房可查封，符合条件仍可能处置，待核。

申请执行时效：超过二年提出申请的，人民法院应当受理；被执行人提出异议且审查成立的，裁定不予执行。不得写成当然失权、当然不用还。

对执行依据不服（生效前实体事由）告知再审或其他程序，本窗该格 `现有依据不支持`。基于执行依据生效后的实体事由排除执行待核，不得默写为改判。案外人标的异议不打开，转 P2。

---

## 节点 3　已履行 `Pay#`

有凭证则支持扣减。无凭证：依据不足，不得口头冲销。未知不写零。迟延利息参数待核。不得承诺减免已生效债权。驾驶人付款不得写入保险人已履行栏。酒驾、无证不是交强险判项当然停止执行。时效抗辩须被执行人主动提出，不得写成法院应主动适用。分期或以物抵债只转介 `准备人身执行和解`，本窗不写和解终稿。

---

## 节点 4　草稿与邻接拆分

草稿栏目：被执行人、执行案号、异议请求、事实理由。状态默认 `草案`。不代提交。不利已履行缺口、未生效风险必须入稿。闸未开不得标异议终稿 `已形成`。财产报告须如实；指导虚假申报第一次整体停止。拒执只打红旗，不出步骤。

| 接口 | 本窗 | 转介 |
| --- | --- | --- |
| 权利人申请执行 | 负触发 | `执行人身损害生效文书` |
| 执行和解 | 负触发终稿 | `准备人身执行和解` |
| 保全复议 | 负触发 | `应对人身案件保全裁定` |
| 案外人异议之诉 | 一句负触发 | P2 `unavailable` |
| 对依据不服 | 该格不支持 | 再审 P2 |
| 工伤待遇 | 分流；民事可留 | `评估工伤与第三人侵权竞合` |
| 保险人应诉（尚未进入执行） | 负触发 | `保险公司应对直接索赔` |
| 保险人已被列为被执行人 | 本窗正触发 | 应诉原子只红旗 |
| 拒执风险 | 只打红旗，不给步骤 | `分流刑民交叉` |

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过应对闸直接给保证解封、已读起算、选定法院或隐匿步骤。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if 金额参数不足，then 该行标未知，禁止写零。
若 if C 端只要大众准备包，then 只分流不回改。

判断状态只许三值。口头转述、截图和「已读」不得写成已送达、已受理或期限已起算。事故认定书、调解记录不得单独写成民事终局比例或当然解封。

## 本任务回链纪律

本任务成果是「不代提交的被执行人异议草稿、期限卡与已履行对照」。必须包含：应对闸、隐匿第一次整体停止、已读不得起算、过期只停异议稿、不保证解封。不包含：权利人执行申请、执行和解终稿、保全复议、案外人异议之诉、再审。禁止保证解封。禁止选定法院。禁止选边治愈。禁止把隐匿写成负触发。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标异议终稿已形成。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接。
风险档 A：隐匿指导、虚假申报、倒签过户必须单独标可逆性。
