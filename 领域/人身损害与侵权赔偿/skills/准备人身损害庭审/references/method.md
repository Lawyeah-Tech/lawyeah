# 庭审准备方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。稿件状态只用 `草案`、`庭审闸关闭`、`开庭前待核`、`停止`。禁止胜诉率、准许率、唯一必得总额、唯一截止日、选定法院、自行宣布伤残等级、保证结果、代出庭。未知金额不写零。本任务不代提交、不代出庭。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、已失效《合同法》、2008 年民事诉讼证据规定已被修改文本、2017 年民事诉讼法旧举证或鉴定人出庭条号直接当现行、把已读或口头写成逾期起算、把缺席写成当然胜诉、把鉴定人不到庭写成全案必败时记为噪声，不得写入 `L#`。禁止指导作伪证、隐匿不利证据或违法取证。

`Hrg#` 固定列：`编号｜行类型（争点／证据／询问）｜块或对象（责任／因果／损害／保险／程序；或当事人／证人／鉴定人／专家辅助人）｜待证或问题｜本方材料或开放封闭标记｜不利点解释（证据行必填，空则该行停止）｜禁止事项（诱导作伪／羞辱／统一口径／藏匿）｜逾期或出庭条件（待核；已读口头不得填截止日）｜合法取得或排除主张（仅合法主张）｜状态｜来源回链`。一行一块、一份证据或一个询问对象。禁止一行打包「全案必赢」。鉴定人行只允许问检材、标准名称与施行日、程序、依据；禁止羞辱、禁止诱导等级或参与度。

口头「下周开庭」、微信已读、截图只进 `S#`／`V#`，不得升格 `R#` 已送达、已排期或期限已起算。

## 节点 0　分流、立场、庭审闸与不关窗

整案转出或闸关闭只交付第 1、2、10 节或标注停止的 `Hrg#`，不得交付提纲终稿，不得标保证结果。闸部分打开时：仅对传票或排期可回链的部分给出草案，其余行停止或不打开。

| 信号 | 处理 |
| --- | --- |
| 主成果是起诉状或立案包 | 负触发 `提起人身损害一审`；尚未立案要提纲时闸关不关窗 |
| 主成果是首次应诉答辩 | 负触发 `应对人身损害一审` |
| 主成果是证据案卷矩阵 | 负触发 `建立人身损害证据案卷` |
| 主成果是和解方案或可签协议 | 负触发 `谈判人身损害和解` |
| 主成果是调解方案与效力 | 负触发 `评估人身调解方案与效力`；庭上调解只留接口 |
| 主成果是鉴定异议或重新鉴定申请 | 负触发 `提出伤残鉴定异议或重新鉴定` |
| 主成果是上诉状 | 负触发 `提起人身损害上诉` |
| 主成果是二审答辩 | 负触发 `应对人身损害二审`；已排期二审开庭且主成果是质证询问留本窗 |
| 刑事案件庭审辩护 | 转刑事；民事并行部分只分流 |
| 纯工伤仲裁开庭且无第三人 | 整案转劳动；夹带对第三人民事庭审则本窗正触发，工伤段分流，`Hrg#` 可留并转介 `评估工伤与第三人侵权竞合` |
| 医疗损害庭审主轴 | 转医疗 |
| 海事庭审 | 转海事 |
| 未成争只要改合同 | 审查起草本窗搁置 |

庭审闸打开（可出 `Hrg#` 草案，仍不代出庭、不保证结果）须同时满足：单方无冲突立场与授权；主成果是争点／举证质证／询问／鉴定到庭提纲，不是起诉状、答辩、建卷矩阵、和解方案、鉴定异议或上诉状终稿；已有开庭传票、开庭通知或排期 `R#` 表面；拟交付不含保证结果、指定唯一论坛、已读起算逾期、把藏匿不利材料写成可接受。

闸关闭（仍正触发）：尚未立案或无传票 `R#` 也要提纲；保证胜诉；选定某院；已读、截图、口头起算举证或开庭逾期；新证据当然能用或逾期一律作废；缺席当然胜诉或当然败诉；鉴定人必须到庭否则鉴定作废或全案必败；鉴定人一律不用到庭。闸未开则仍只交 1、2、10 节。口头「下周开庭」不够开闸。

「尚未立案要提纲」「保证胜诉」「已读起算」「选定法院」**不关窗**。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或原被告同时交材料争同一份提纲且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出指导作伪证、统一证人口径、隐匿不利证据、庭上否认已有病历、伪造伤情、威胁证人或鉴定人，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　程序核对

须核验：传票或排期表面、当事人身份与授权、证人通知、鉴定人出庭条件。缺席风险分列：原告无正当理由不到庭可按撤诉；被告经传票传唤无正当理由拒不到庭可缺席判决。检索锚点：民事诉讼法缺席与按撤诉条款。条号不是 `L#`。**不等于**请求当然成立或当然驳回；本方仍须举证。不保证免于缺席。

举证期限由人民法院确定。逾期提供须说明理由；拒不说明或理由不成立的，可以不予采纳，或采纳但予以训诫、罚款。与案件基本事实相关的逾期证据是否仍可采纳，待核。已读、口头、截图不得起算，不写唯一截止日。检索锚点：民事诉讼法及时举证与逾期条款。条号不是 `L#`。不得写「新的就能用」或「逾期一律作废」。

传票上的法院只登记 `R#`。不得改选、预填「此致某院」或建议换院开庭。管辖终稿转管辖或异议原子。

## 节点 2　争点与举证

按责任、因果、损害、保险、程序开口组织争点，不是默认闭集。无争议事实不得当争点。保险限额与过错分列，不得合成「全责所以限额内全赔」。驾驶人自认不得写成保险人自认。事故认定书、调解记录不得单独写成民事终局比例。

每份证据一行：待证事实、证明目的、三性预案、**不利点解释必填**。删除不利病历、饮酒、闯灯、已收款、基金已付、不利监控或自认聊天＝隐匿，该行或整体停止。不得只用第 10 节顶替入列。对方控制不得推定材料存在或内容有利。截图、翻拍标明副本。

非法证据排除只作合法主张：严重侵害合法权益、违反法律禁止性规定或严重违背公序良俗的方法形成或获取的证据不得作为认定事实根据——待核。不得指导补拍、侵入、购买隐私；不得写当然排除或当然可质证使用。

## 节点 3　询问提纲

当事人、证人、鉴定人、有专门知识的人分列，不得混行。开放问题与封闭问题搭配。禁止诱导作伪。禁止给「统一口径」示范问答。

鉴定人：当事人对鉴定意见有异议或人民法院认为有必要出庭的，鉴定人应当出庭；拒不出庭的，该鉴定意见不得作为认定事实的根据。检索锚点：民事诉讼法鉴定人出庭条款及民事诉讼证据规定。条号不是 `L#`。条件未成就则出庭行停止。效果待核：不得写成全案必败，不得写成当然重新鉴定（异议终稿转 `提出伤残鉴定异议或重新鉴定`）。询问只问检材、标准名称与施行日、程序、依据；不得羞辱；不得问「是不是该评十级」。

---

## 节点 4　庭上调解接口

庭上调解只转介 `谈判人身损害和解` 或 `评估人身调解方案与效力`。底线与用户已有方案一致则引用，不 depends-on。不在本窗写可签协议或效力评估终稿。不承诺结果。

---

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过庭审闸直接给保证结果、选定法院或删除不利证据。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if C 端只要大众准备包，then 只分流不回改。

判断状态只许三值。口头转述、截图和「已读」不得写成已受理、已送达或期限已起算。事故认定书不得单独写成民事终局比例。

## 本任务回链纪律

本任务成果是「不代出庭的庭审争点、举证质证与询问提纲草案」。必须包含：不利证据入列、鉴定人只问检材标准程序。不包含：起诉状、答辩、建卷矩阵、和解方案、鉴定异议、上诉状。禁止保证结果。禁止选定法院。禁止已读起算。禁止作伪或隐匿。禁止选边治愈。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标提纲终稿已形成。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接。
风险档 A：作伪、隐匿、逾期失权字段必须单独标可逆性。
