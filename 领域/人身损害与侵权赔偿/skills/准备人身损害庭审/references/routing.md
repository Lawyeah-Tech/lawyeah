# 边界与路由

## 正触发

已开庭或即将开庭，需要庭审准备。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 立案起诉 | `提起人身损害一审` |
| 仅和解 | `谈判人身损害和解` |
| 上诉状 | `提起人身损害上诉` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 刑事案件庭审 | 刑事领域 |
| 劳动仲裁开庭 | 劳动领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“下周开庭，争点和问鉴定人”正触发。“还没立案”走起诉。“只想调解数字”走谈判或调解评估。
