# 边界与路由

## 正触发

已开庭或即将开庭，需要争点、举证质证或询问提纲。「下周开庭，争点和问鉴定人」正触发。尚未立案也要庭审提纲、保证胜诉、已读起算逾期、选定某院、新证据当然能用、缺席当然胜诉、鉴定人必须到庭否则鉴定作废，仍正触发：庭审闸可关，对应格停止，窗口不关。工伤待遇与对第三人民事庭审同时出现，仍正触发：工伤段分流劳动，对第三人 `Hrg#` 可留。已排期二审开庭且主成果是质证询问，留本窗。

双方秘密、指导作伪证、隐匿不利证据的停止，优先于负触发。不得改走负触发去出一方提纲。尚未立案要提纲、保证胜诉不在下表。作伪隐匿不在下表。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 仅工伤仲裁开庭且无第三人 | 劳动领域 |
| 医疗损害庭审主轴 | 医疗医药领域 |
| 海事庭审 | 海事领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。对第三人庭审可留。

## 易混

「下周开庭，争点和问鉴定人」正触发。「还没立案，先做开庭问鉴定人提纲」：窗口不关，庭审闸关，转介起诉，不得写成负触发踢走。「只想调解数字」走谈判或调解评估。「判决刚送达只要上诉状」走上诉。「刚收到上诉状只要二审答辩」走二审应对。「二审已排期只要问鉴定人」留本窗。「保证这套问法能赢、选某区法院、微信已读所以举证明天截止」仍正触发；保证结果、选定法院、已读起算各格不支持。「工伤还在认，对司机和交强险已传票」正触发，第三人提纲可留，工伤段分流。「两边材料都给你选边、既往和喝酒别写进提纲、问鉴定人往十级引」整体停止。
