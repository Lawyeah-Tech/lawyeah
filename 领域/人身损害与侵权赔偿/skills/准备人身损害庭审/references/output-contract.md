# 输出合同

按触发结果选择交付形状。庭审闸未打开不得交付提纲终稿或保证结果。禁止选定唯一法院或预填「此致某院」。禁止尚未立案出已排期提纲。禁止已读或口头起算逾期。禁止缺席当然胜诉或当然败诉。禁止鉴定人不到庭写成全案必败或当然重新鉴定。禁止新证据当然能用或逾期一律作废。禁止藏匿不利证据。禁止诱导作伪或羞辱鉴定人。禁止胜诉率。禁止代出庭。禁止未知金额写零。禁止选边治愈。不保证结果。不定残。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 庭审闸关闭或节点 0 整案转出 | 第 1、2、10 节：关闭理由、程序前提待核和最小补证。可附标注停止的 `Hrg#`。禁止提纲终稿、保证结果、唯一截止日。对第三人可留时不得因工伤整案转出 |
| 整体停止 | 第 1、10 节。禁止 `Hrg#` 策略包、选边、作伪或隐匿方法。双方秘密、指导作伪证、隐匿不利证据第一次即停，优先于负触发；无选边治愈，无「坚持」门槛 |
| 用户要尚未立案出提纲、保证胜诉、已读起算、选定某院（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；闸未开则仍只交 1、2、10；不得改走负触发关窗；成果不得标提纲终稿 `已形成` 或保证结果 |
| 正触发且闸开（可部分开） | 下列十节表头均出现；逾期、出庭、缺席、排除未核验的单元格填 `依据不足，无法形成结论` 或 `待核`；一行一块或一证；禁止为填满而宣布保证结果、选定某院或删除不利证据 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入提纲终稿已形成。双方秘密未解不得进入「部分形成」。每个 `Hrg#` 必须带来源和三值判断。证据行不利点解释为空则该行停止。`L#` 不得直接抄技能内条号。保证胜诉、已读即逾期、藏匿可接受若返回则记噪声。稿件状态默认 `草案`。

## 1. 触发、单方立场、授权与成果状态

庭审闸开、部分开或关。传票或排期 `R#` 必须标明。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。稿件默认 `草案`。不代出庭。

## 2. 来源登记与 MCP 调用表

`S/D/R/L/I/G/Hrg/V`。口头下周开庭、已读只登记 `S#`／`V#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 程序核对

传票、身份、鉴定人出庭条件、缺席风险分列。已读不得起算。不选定法院。不保证免于缺席。

## 4. 争点清单

责任、因果、损害、保险、程序分块。无争议不得当争点。保险限额与过错分列。驾驶人自认不得写入保险人。

## 5. 举证质证预案

每份证据含三性与**不利点解释**。不利病历必须入列。逾期是否采纳待核。排除只作合法主张。

## 6. 询问提纲

当事人、证人、鉴定人分列。鉴定人只问检材、标准、程序、依据。禁止诱导作伪和羞辱。

## 7. 法律适用待核点

逾期、出庭、缺席、排除未核验则该格停止。不定残。不给胜诉率。

## 8. 庭上调解接口

只转介谈判或调解评估。不写可签协议。不替代本窗。

## 9. 下一步与转介

补证、申请鉴定人出庭、开庭核对只点名。转介起诉、应诉、建卷、鉴定异议、上诉只点名。不代出庭。

## 10. 缺口、停止项与提示

须列对方最强解释：还没立案先把开庭提纲写好并保证能赢、微信已读举证通知所以明天截止、新证据当然能用或逾期一律作废、对方不到庭我们当然赢、鉴定人不到庭鉴定作废全案必败、就某区法院开、不利病历庭上不提或否认、问鉴定人往十级上引、两边材料都给你选边、工伤还在认所以对司机开庭不用准备。

本成果不是起诉状、不是答辩、不是建卷矩阵、不是和解方案、不是鉴定异议、不是上诉状、不是已开庭笔录、不保证结果、不是唯一截止日。不代出庭。
