# 提出伤残鉴定异议或重新鉴定

## 任务目标

在明确、无利益冲突的单方立场下，针对已有法院委托的民事人体损伤致残、三期、护理依赖或因果关系鉴定意见，形成书面异议点、补充或重新鉴定路径选择与发送前草稿。重新鉴定不是当然权利。不重做鉴定意见，不改鉴定机构内部方法，不自行宣布新等级，不代提交，不保证法院准许。不写首次鉴定申请终稿、伤残等级争议比较终稿、测算、诉状或庭审质证终稿。

`depends-on` 为空。尚未委托转 `准备伤残鉴定材料`。双方意见冲突比较终稿转 `评估伤残等级争议`。参与度转 `评估因果关系与既往伤病`。出庭质证终稿转 `准备人身损害庭审`。

## 工作边界

正触发：法院委托的人身损害相关鉴定意见已作出，用户不服并需要书面异议、补充鉴定或重新鉴定材料。用户要「必须重新鉴定」「必须改成某级」「过期了所以没戏」「用工伤标准打民事鉴定」仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关。两份意见同时存在且用户要给法院的异议稿：本窗正触发可与等级争议窗并行。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 鉴定尚未委托，只要首次申请（转 `准备伤残鉴定材料`）；
- 仅有诉前单方委托意见、要申请法院鉴定（证据规定第四十一条路径，转 `准备伤残鉴定材料`；本窗不得写成第四十条重新鉴定）；
- 主成果是双方意见冲突比较表（转 `评估伤残等级争议`）；
- 只要测算或残疾额（转 `测算人身损害赔偿`）；
- 只要起诉状（转 `提起人身损害一审`）；
- 只要选定法院（转 `评估人身损害管辖`）；
- 只要庭审质证或询问提纲终稿（转 `准备人身损害庭审`）；
- 医疗损害鉴定异议主轴（转医疗）；
- 劳动能力鉴定复查或工伤待遇主轴（转劳动）；
- 人体损伤程度（轻伤、重伤）当伤残主轴（说明不是本窗；刑民程度鉴定另分）；
- C 端只要大众准备包（只分流）；
- 未成争改合同（审查起草搁置）。

「要求直接改等级或重写鉴定书」不在负触发表。

## 建立工作坐标

确认：使用者与授权；单方立场；委托类型（法院委托或单方委托）；意见书文号；送达日（不是出具日）；法院是否指定书面异议期间；检材清单；是否诉讼中；拟用标准名称、版本、施行日线索；法域。

口头「已读」「过期了」「必须九级」只登记 `S#`。

同时掌握双方秘密或受害人与侵权人、保险人利益冲突未解：`整体停止`，不得以选边治愈，也不得改走负触发去出异议稿。提出伪造或裁剪影像、隐瞒完整序列、按索赔口径改诊断、威胁或收买鉴定人、倒签：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 鉴定意见、病历、影像；`R#` 法院通知、送达材料；`L#` 运行时已核验规则或标准；`I#` 判断；`G#` 缺口；`Q#` 异议点；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。接口状态只用 `打开`、`不打开`、`待核`。技能正文中的条号和标准名是检索锚点，不是已核验 `L#`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：2019 年修正民事诉讼证据规定指定期间书面异议、补充鉴定、第四十条重新鉴定事由（鉴定人不具备相应资格、鉴定程序严重违法、鉴定意见明显依据不足、不能作为证据使用的其他情形；可通过补正、补充鉴定、补充质证或重新质证解决的不予准许重新鉴定）、第四十一条对单方委托意见有证据反驳并申请鉴定不是重新鉴定；民诉法 2023 鉴定人出庭与拒不出庭效果（条号运行时核验）。不可用则期限、出庭效果、重新鉴定开闭字段停止。噪声：已废止 GB 18667-2002、2001 年证据规定第二十七条、修正前民诉鉴定条号、工伤劳鉴标准当本窗终稿。不得把《人体损伤致残程度分级》口头指定写成已核验 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变期限、出庭效果或重新鉴定开闭的条文正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补程序瑕疵不等于当然重新鉴定、补充优先于推倒、鉴定人未出庭不等于自动重新鉴定的实务反例。
- `search_template` 只借鉴异议或重新鉴定申请栏目，不把范本当现行法。

工具不可用时继续编目意见书、送达、检材；法律效果字段停止。不得凭记忆写必须重新鉴定或唯一截止日。

## 判断节点

执行顺序和停止条件以 [鉴定异议方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、委托类型、立场与不关窗

医疗、劳鉴、无意见书转出。单方委托打掉走准备材料。双方秘密或伪造提出即停。

### 2. 期限闸

指定期间以送达起算，不得按出具日或已读。过期不关窗。不编造唯一截止日。

### 3. 程序瑕疵与出庭接口

回避、资质、检材、超范围、签字。鉴定人出庭与有专门知识的人分列。拒不出庭不等于当然重新鉴定。

### 4. 实体分歧与路径选择

对照标准公开条款与检材。不改等级。遗漏优先补充。第四十条事由待核才打开重新鉴定。

### 5. 材料包与纪律

发送前草稿。不代提交。不保证准许。禁止隐瞒完整序列。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；提出伪造或裁剪影像、隐瞒完整序列、改诊断、威胁或收买鉴定人、倒签。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。
- `字段停止`：指定期间、重新鉴定法定事由、标准名称版本施行日未核验。用户要必须重新鉴定、必须改成某级、过期关窗或用工伤标准打民事鉴定则该格停止，窗口不关。
- `目标停止`：主目标变为首次鉴定申请、等级争议比较终稿、测算、诉状、庭审、医疗或劳鉴。

禁止指导伪造影像或威胁鉴定人。不给胜诉率。不选定法院。不保证必得。不代提交。本窗不定残。
