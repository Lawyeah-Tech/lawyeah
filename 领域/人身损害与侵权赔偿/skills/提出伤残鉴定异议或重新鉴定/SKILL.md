# 提出鉴定异议或重新鉴定

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“鉴定异议点、补充或重新鉴定材料”。不重做鉴定意见，不改鉴定机构内部方法。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算、鉴定和证据清单。

## 工作边界

正触发：鉴定意见已作出，用户不服并需要异议、补充鉴定或重新鉴定材料。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 鉴定尚未委托，只要首次申请（转 `准备伤残鉴定材料`）；
- 要求本技能直接改等级或重写鉴定书；
- 医疗损害鉴定异议主轴（转医疗）；
- 劳动能力鉴定复查（转劳动）。

不预测新等级，不攻击鉴定人人格，不指导收买鉴定人。

## 建立工作坐标

确认：使用者与授权；单方立场；鉴定委托主体；意见书文号和送达日；异议期限；检材清单；是否诉讼中；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 鉴定意见、病历、影像；`R#` 法院通知；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 异议点；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民诉鉴定异议、补充鉴定、重新鉴定条件；`search_practiced` 补常见程序瑕疵。不虚构案件系统。

工具不可用时继续事实、主体、程序文书状态和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [鉴定异议方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　分流与期限闸

医疗鉴定、劳动能力鉴定转出。期限以送达日起算。

### 节点 2　程序瑕疵点

回避、资质、检材移交、超范围、签字。

### 节点 3　实体分歧点

标准条款、条款符合性、三期、护理依赖、参与度。不改内部方法。

### 节点 4　补充或重新鉴定选择

补充针对遗漏；重新针对法定事由。

### 节点 5　材料包与纪律

异议函或申请草稿、对照表、检材补交清单。

## 停止与安全

- `整体停止`：立场不明；用户要求伪造影像或威胁鉴定人。
- `字段停止`：异议期限、重新鉴定法定事由未核验。
- `目标停止`：主目标变为首次鉴定申请、医疗损害鉴定或劳动能力鉴定。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
