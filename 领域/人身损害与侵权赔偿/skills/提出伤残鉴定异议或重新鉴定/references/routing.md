# 边界与路由

## 正触发

法院委托的人身损害相关鉴定意见已作出，用户不服并需要书面异议、补充鉴定或重新鉴定材料。用户要「必须重新鉴定」「必须改成某级」「过期了所以没戏」「用工伤标准打民事鉴定」仍正触发。两份意见同时存在且用户要给法院的异议稿，仍正触发。

双方秘密、伪造影像、隐瞒完整序列或威胁鉴定人的停止，优先于负触发。不得改走负触发去出异议稿。改等级不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 首次鉴定申请 | `准备伤残鉴定材料` |
| 仅诉前单方意见、申请法院鉴定 | `准备伤残鉴定材料` |
| 双方意见冲突比较终稿 | `评估伤残等级争议` |
| 测算或残疾额 | `测算人身损害赔偿` |
| 起诉状 | `提起人身损害一审` |
| 选定法院 | `评估人身损害管辖` |
| 庭审质证或询问提纲终稿 | `准备人身损害庭审` |
| 医疗损害鉴定 | 医疗医药领域 |
| 劳动能力鉴定或工伤待遇 | 劳动领域 |
| 人体损伤程度当伤残主轴 | 说明不是本窗 |
| C 端只要大众准备包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「必须改成九级」不在本表。

## 易混

「十级我不服要重新鉴定」正触发；「必须重做」格不支持或待核。「还没鉴定，帮我申请」走首次鉴定。「两份鉴定打架怎么评」走等级争议；若同时要给法院的异议稿则本窗并行。「单方十级我要重新鉴定」走准备材料的法院鉴定申请，不走第四十条。「用工伤十级打民事」不关窗。「过了所以没了」不关窗。「改成九级再算赔偿或写诉状」测算或诉状负触发。「轻伤鉴定帮我改成九级」不是本窗伤残。
