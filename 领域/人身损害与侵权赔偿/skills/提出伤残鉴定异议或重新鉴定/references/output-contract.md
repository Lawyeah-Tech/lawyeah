# 输出合同

按触发结果选择交付形状。禁止必须重新鉴定。禁止自行宣布新等级。禁止用废止道路评残标准或工伤劳鉴标准改写民事评残。禁止把人体损伤程度鉴定写成伤残。禁止按出具日或已读起算唯一截止日。过期不关窗。禁止保证法院准许。禁止代提交。异议函是发送前草稿不是发送版。禁止选定法院。本窗不定残。不重做鉴定书。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出（医疗鉴定主轴；劳鉴或工伤主轴；海事专门鉴定；未成争改合同） | 第 1、2、10 节。禁止异议稿、重新鉴定事由、等级 |
| 整体停止 | 第 1、10 节。禁止异议策略、选边方案、检材挑选步骤。双方秘密、伪造影像、隐瞒完整序列、威胁或收买鉴定人时，整体停止优先于负触发；第一次提出即停，无选边治愈，无「坚持」门槛 |
| 用户要「必须重新鉴定」或「必须改成某级」或「过期关窗」或「用工伤标准打民事鉴定」（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；不得改走负触发关窗；成果不得标 `已形成` |
| 正触发且可评估 | 下列十节表头均出现；期限、第四十条事由、标准名称版本施行日未核验的单元格填 `依据不足，无法形成结论` 或 `待核`；禁止为填满而宣布新等级或「法院应当准许」 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。双方秘密未解不得进入「部分形成」。每个 `Q#` 必须带判断三值和证明负担方。`L#` 不得直接抄技能内条号或标准名。

## 1. 触发、单方立场、授权与成果状态

委托类型。双方秘密未解不得进入「部分形成」。

## 2. 来源登记与 MCP 调用表

意见书文号、页码、送达材料。口述已读、出具日只登记 `S#`。MCP 未调用也留一行。GB 18667、2001 证据规定、修正前民诉条号若返回则记噪声。

## 3. 期限闸

指定期间、送达日。不明则截止日停止。过期标逾期风险，不关窗。不写唯一截止日。

## 4. 程序瑕疵清单

逐点回链页码与检材。无对照则该点不支持。鉴定人出庭与有专门知识的人分列。拒不出庭不等于当然重新鉴定。

## 5. 实体分歧对照表

不改等级。标准名称版本施行日待核。禁止废止道路标准、工伤标准、轻伤当伤残。

## 6. 补充或重新鉴定选择

遗漏优先补充。第四十条事由逐项待核。可补正则重新鉴定不打开。单方意见只标第四十一条转出。必须重新鉴定格填 `现有依据不支持` 或待核。

## 7. 申请或异议草稿

发送前草稿。不代提交。不预填唯一法院或鉴定机构。逾期则提交稿停止或全文标逾期风险。

## 8. 检材补交清单

完整序列、控制方、合法来源。禁止只摘有利切片。

## 9. 下一步

转介等级争议、因果、庭审、测算。不定残。不选定法院。不写诉状。不办庭审。

## 10. 缺口、停止项与提示

须列对方最强解释（必须重新鉴定、必须改成某级、过期作废、出具日已起算、已读已起算、我觉得不公所以一定重做、未出庭所以鉴定作废并必重做、用工伤十级打民事、废止道路标准仍可用、轻伤就是十级、选边即可继续、法院应当准许）与证据缺口。

不重做鉴定书。不保证准许。本成果不是等级争议终稿、不是测算、不是诉状、不是庭审提纲。
