# 鉴定异议方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。接口状态只用 `打开`、`不打开`、`待核`。禁止胜诉率、唯一责任比例、必得总额、选定法院、自行宣布伤残等级。未知金额不写零。

技能正文和本文件中的条号、标准名是检索锚点，不是已核验 `L#`。`search_law` 返回已废止 GB 18667-2002《道路交通事故受伤人员伤残评定》、2001 年民事诉讼证据规定第二十七条、修正前民诉鉴定条号、工伤职工劳动能力鉴定标准当民事评残、人体损伤程度鉴定标准当伤残等级、已失效《侵权责任法》或 2003 年人身损害赔偿解释已删除条文时记为噪声，不得写入 `L#`。禁止把「我觉得不公」写成第四十条事由已成立。

`Q#` 固定列：`编号｜主张人｜路径分型（书面异议/补充鉴定/重新鉴定/申请鉴定人出庭/有专门知识的人/对单方意见申请法院鉴定）｜意见书页码与结论摘录｜对照检材或标准公开条款｜对应法定事由（待核）｜证明负担方｜判断｜待核`。一行一结论。禁止合成「整体不公故必须重新鉴定」。

## 节点 0　分流、委托类型、立场与不关窗

整案转出只交付第 1、2、10 节。

| 信号 | 处理 |
| --- | --- |
| 医疗损害鉴定异议主轴 | 转医疗 |
| 劳动能力鉴定或工伤待遇主轴 | 转劳动 |
| 海事专门鉴定 | 转海事 |
| 未成争只要改合同 | 审查起草本窗搁置 |
| 尚无意见书、只要首次申请 | 负触发 `准备伤残鉴定材料` |
| 仅诉前单方委托意见、要打掉并申请法院鉴定 | 负触发 `准备伤残鉴定材料`（第四十一条不是第四十条） |

「必须重新鉴定」「必须改成某级」「过期了所以没戏」「用工伤标准打民事鉴定」**不关窗**。

两份意见同时存在且用户要异议文书：本窗正触发，比较哪份该采信转 `评估伤残等级争议` 并行，本窗不写比较终稿。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出伪造或裁剪影像、隐瞒完整序列、按索赔口径改诊断、威胁或收买鉴定人、倒签或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　期限闸

人民法院收到鉴定书后应将副本送交当事人。当事人对鉴定书内容有异议的，应当在人民法院**指定期间内以书面方式**提出（检索锚点：2019 年修正民事诉讼证据规定第三十七条，条号须核验）。

指定期间不是全国唯一法定期限。以**送达**起算，不得按出具日、口头宣读、截图或「已读」起算。送达日或指定期间不明：截止日字段停止，不编造唯一截止日。用户说「过期了」不关窗；提交稿标逾期风险待核或提交稿字段停止。过期不关窗。

---

## 节点 2　证明负担与程序瑕疵

主张异议的一方须指出意见书哪一页哪一结论与哪一份检材或所用标准已公开条款不一致。「我觉得不公」「等级太低」不构成程序瑕疵，该格 `现有依据不支持`。

程序瑕疵每点独立 `Q#`：回避、鉴定人资格、检材是否经质证、是否超委托范围、签字盖章。无对照则该点 `现有依据不支持`。

鉴定人出庭与有专门知识的人出庭**分列**。有异议的当事人申请鉴定人出庭。无正当理由拒不出庭的，鉴定意见不得作为认定事实的根据——效果待核。因拒不出庭申请重新鉴定是否应予准许，运行时核验，**不得直接写成当然重新鉴定**。本窗不办庭审，不写询问提纲终稿。专家辅助人意见不是鉴定意见。

## 节点 3　实体分歧

对照所用标准名称、条款号与检材描述不一致之处。标准名称、版本、施行日一律运行时核验。民事人身损害致残检索锚点为《人体损伤致残程度分级》。不得用已废止道路交通事故受伤人员伤残评定改写异议。不得用职工工伤劳动能力鉴定标准完成本窗终稿。人体损伤程度（轻微伤、轻伤、重伤）不是伤残等级。

不得自行宣布新的伤残等级。用户要必须改成某级：该格 `现有依据不支持`，窗口不关。参与度、既往伤病转 `评估因果关系与既往伤病`。不得把实体分歧单独写成第四十条已成立。

## 节点 4　补充鉴定或重新鉴定选择

遗漏事项、需解释说明：优先补正、补充鉴定、补充质证或重新质证。

重新鉴定接口仅在对应法定事由打开（检索锚点：证据规定第四十条）：鉴定人不具备相应资格；鉴定程序严重违法；鉴定意见明显依据不足；鉴定意见不能作为证据使用的其他情形。主张重新鉴定的一方对上述**逐项**举证，缺项则该事由格 `依据不足，无法形成结论`。瑕疵能通过补正、补充鉴定、补充质证或重新质证解决的，重新鉴定接口 **不打开**。材料不足不写「必须重新鉴定」。用户要必须重新鉴定：该格 `现有依据不支持` 或待核，窗口不关。不保证法院准许。准许后原鉴定意见不得作为认定案件事实的依据——仅当接口打开且规则已核验才写。

对单方自行委托意见：有证据或理由足以反驳并申请人民法院委托鉴定，走第四十一条，**不得写成重新鉴定**。

---

## 节点 5　材料包、检材与输出纪律

异议函或申请书为发送前草稿，不是发送版，不代提交，不预填唯一法院或鉴定机构。检材补交须合法来源、完整序列。禁止指导挑选只对己方有利的切片、隐瞒完整序列。不能因对方控制病历或影像推定内容有利。未质证材料不得作为鉴定依据。

不预测新等级。不把新系数交给测算窗。本窗不定残。不选定法院。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过节点 0 直接写必须重新鉴定或新九级。

若 if 日期、送达或指定期间未核验，then 截止日和法律效果字段停止，不编造唯一截止日。
若 if 金额参数不足，then 该行标未知，禁止写零。
若 if C 端只要大众准备包，then 只分流不回改。

判断状态只许三值。
