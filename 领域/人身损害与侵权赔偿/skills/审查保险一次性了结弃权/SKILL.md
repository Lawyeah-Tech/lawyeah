# 审查保险一次性了结弃权

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的权利人或被保险人立场下，形成保险人一次性了结或权益转让的审查包：审查闸、文本版本、`C#` 条款定位、`W#` 逐句拆解、未知伤残与对侵权人余额风险、对价对照、权益转让是否超额、可逆性接口。不代签署。不给唯一公平价。未稳定或伤残未鉴定，不得建议签署概括弃权。口头「只是走个手续」、微信已读不得写成范围已限缩或已签署。保险人限额内付款不当然消灭对侵权人其余请求。交强险受害人直接请求不得被被保险人单方弃权消灭。权益转让须与实际赔付对应。已签可逆性低，不承诺能撤销。不定残。未知金额不写零。

`depends-on` 为空。普通侵权和解起草转 `起草人身损害和解协议`。谈判档转 `谈判人身损害和解`。材料包转 `准备交强险商业险索赔材料`。拒赔拆解转 `应对保险拒赔减赔`。代位终稿转 `应对保险代位求偿`。测算转 `测算人身损害赔偿`。索赔通知对受约束相对人的发送闸，须待本窗支持请求仍可主张。

## 工作边界

正触发：保险人拿出结案协议、一次性了结或权益转让，需要审查弃权范围和风险。仅口头手续、无书面文本、治疗未稳定、用户要「可以放心签」「保证能撤销」「放弃对侵权人一切请求当然必要」仍正触发：审查闸可关，对应格填 `现有依据不支持` 或停止，窗口不关，不得标可以放心签署或审查终稿已形成。工伤待遇与第三人交强险或商业三者了结同时出现：本窗正触发，工伤段分流劳动，了结审查可留。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是双方侵权和解协议草稿（转 `起草人身损害和解协议`）；
- 主成果是让步档或底线（转 `谈判人身损害和解`）；
- 只要理赔材料包（转 `准备交强险商业险索赔材料`）；
- 只要发送前索赔通知（转 `准备侵权索赔通知`）；
- 只要拒赔拆解（转 `应对保险拒赔减赔`）；
- 只要代位求偿抗辩终稿（转 `应对保险代位求偿`）；
- 只要测算终稿或唯一公平价（转 `测算人身损害赔偿`）；
- 只要司法确认或赋强手续（转 `办理人身和解执行力补强`）；
- 只要起诉保险人（转 `直接起诉保险公司`）；
- 纯工伤待遇一次性了结且无第三人保险了结（转劳动）；
- C 端只要大众准备包（只分流）；
- 未成争改合同（审查起草搁置）。

未稳定概括弃权、保证能撤销、口头手续、可以放心签**不在负触发表**，窗口不关。倒签出险、隐瞒伤情骗保、双方秘密、要求产出含未知损害概括弃权的可签终稿**不在负触发表**，走整体停止。

## 建立工作坐标

确认：使用者与授权；权利人或被保险人（受害人直接请求与被保险人索赔分列）；协议文本版本与骑缝或电子确认；治疗是否相对稳定、鉴定状态；对价与已赔金额；法域。

口头「只是走个手续」、微信已读只登记 `S#`／`V#`。不得升格为范围已限缩或已签署。用户坚持「可以放心签」不构成把未知伤残写入可签弃权的授权。

同时掌握双方秘密，或受害人与保险人、被保险人与保险人同时交材料争同一了结审查包：`整体停止`，不得以选边治愈，也不得改走负触发去出一方签章意见。受害人已开口且委托范围就是审查了结文本、且未掌握对方秘密时，可推定权利人或被保险人立场。只要同时掌握双方秘密，无例外整体停止。提出隐瞒伤情、倒签出险、伪造票据、指导骗保、要求把覆盖未知伤残或「永不追究一切」写入可签终稿：第一次提出即整体停止，不以「坚持」或「高风险确认」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 结案协议、批单；`C#` 条款定位；`R#` 认定书或赔付凭证；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`W#` 弃权行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。稿件状态只用 `审查草稿`、`审查闸关闭`、`未签修改建议`、`已签救济受限`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。不准许率。本任务不代签署。禁止「可以放心签署」。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：保险合同编格式条款提示说明；免除保险人依法应承担的义务等无效接口；保险人赔付后在赔偿金额范围内代位，不影响被保险人就未获赔部分向第三者索赔；交强险被侵权人直接请求权；造成对方人身损害的免责条款无效接口；重大误解、欺诈、显失公平可撤销接口。技能正文条号不是 `L#`。噪声：已失效《侵权责任法》、已失效《合同法》、口头手续即范围已限缩、概括放弃未知伤残当然有效、可以放心签署概括弃权、保险人付款消灭对侵权人全部请求、被保险人签字消灭受害人交强险直接请求、保证能撤销、唯一公平价、代签署。不可用则弃权效力、可撤销、代位范围、直接请求字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变弃权范围、可撤销或代位结论的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补未稳定一次性了结、放弃对侵权人一切请求、口头手续、权益转让超额、重大误解难撤销的实务反例。

工具不可用时继续 `W#` 编目与文本对照；效力与可逆性字段停止。不得凭记忆写成可以放心签署概括弃权或保证能撤销。

## 判断节点

执行顺序和停止条件以 [保险弃权审查方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、审查闸与不关窗

工伤三段分流，第三人保险了结可留。双方秘密或骗保第一次停。未稳定概括弃权、保证能撤销、口头手续不关窗。

### 2. 文本版本 `C#`

骑缝、附件、电子确认、口头冲突并列。口头不得升格为已限缩。

### 3. 弃权逐句拆解 `W#`

对保险人、对侵权人、未知伤残、精神损害、权益转让分列。对侵权人弃权不是结算当然必要。交强险直接请求不得被被保险人单方消灭。

### 4. 对价与伤残状态

未鉴定不得建议概括弃权。不给唯一公平价。未知不写零。

### 5. 权益转让、代位与可逆性

转让不得超额。已签可逆性低，不承诺能撤销。未签只出修改建议。不代签署。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；受害人与保险人同时交材料；隐瞒伤情、倒签出险、伪造票据、指导骗保；以了结掩盖犯罪；刑事逼签；要求把覆盖未知伤残或「永不追究一切」写入可签终稿。整体停止优先于负触发。不以「坚持」或「高风险确认」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：弃权效力、可撤销事由、代位范围、交强险直接请求、提示说明未核验。审查闸未开则签章意见停止，窗口不关。用户要可以放心签、保证能撤销、唯一公平价或放弃对侵权人一切请求当然必要则该格停止，窗口不关。
- `目标停止`：主目标变为普通和解起草、谈判方案、索赔材料、索赔通知、拒赔拆解、代位终稿或测算终稿。可以放心签、保证能撤销不在目标停止。

禁止指导隐瞒伤情、倒签或骗保。不给胜诉率。不选定法院。不代签署。不编唯一截止日。不把未知写成零。不定残。不给唯一公平价。
