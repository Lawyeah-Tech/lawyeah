# 保险弃权审查方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。稿件状态只用 `审查草稿`、`审查闸关闭`、`未签修改建议`、`已签救济受限`、`停止`。禁止胜诉率、唯一公平价、选定法院、自行宣布伤残等级、可以放心签署。未知金额不写零。本任务不代签署。口头手续不得升格为范围已限缩。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、已失效《合同法》、把口头手续写成范围已限缩、把概括放弃未知伤残写成当然有效、把可以放心签署概括弃权、把保险人付款写成消灭对侵权人全部请求、把被保险人签字写成消灭受害人交强险直接请求、把保证能撤销写入结论时记为噪声，不得写入 `L#`。禁止指导隐瞒伤情、倒签出险或骗保。

`C#` 固定列：`编号｜险种袋（交强险／商业三者，禁止混袋）｜文书版本（纸质骑缝／电子确认／口头S#，口头不得升C#）｜条款或了结书原文｜提示说明事实（有／无／待核）｜格式条款接口待核｜效力判断三值｜来源回链`。

`W#` 固定列：`编号｜签署状态（未签修改／已签救济受限）｜相对人（交强险保险人／商业三者／侵权人／用人者／近亲属独立请求）｜项目｜期间｜已知伤情｜治疗稳定｜鉴定状态｜授权（本人／法定代理人／近亲属逐名）｜是否覆盖未知伤残或未知手术（默认否；覆盖则停止）｜是否放弃对侵权人一切请求（默认否；是则停止）｜保险人付款是否消灭其余请求（默认否）｜交强险直接请求是否仍打开（被保险人单方签署默认不消灭）｜权益转让是否限于已赔金额｜可逆性（只作接口，不承诺能撤销）｜状态（可建议修改／默认保留／停止／已签仅救济接口；禁止可以放心签署）｜来源回链`。一行一相对人×一项目×一期间。禁止一行打包「一切权利」。

## 节点 0　分流、立场、审查闸与不关窗

整案转出或闸关闭只交付第 1、2、10 节或标注停止的逐句拆解，不得交付签章意见，不得标审查终稿已形成或可以放心签署。

| 信号 | 处理 |
| --- | --- |
| 主成果是双方侵权和解草稿 | 负触发 `起草人身损害和解协议`；本窗不改写侵权和解正文 |
| 主成果是让步档或底线 | 负触发 `谈判人身损害和解`；印好了结书不在谈判窗改条款 |
| 只要理赔材料包 | 负触发 `准备交强险商业险索赔材料` |
| 只要发送前索赔通知 | 负触发 `准备侵权索赔通知`；对本窗认定仍可主张的相对人，发送闸才可能打开 |
| 只要拒赔拆解 | 负触发 `应对保险拒赔减赔` |
| 只要代位抗辩终稿 | 负触发 `应对保险代位求偿` |
| 只要测算终稿或唯一公平价 | 负触发 `测算人身损害赔偿` |
| 只要司法确认或赋强 | 负触发 `办理人身和解执行力补强` |
| 只要起诉保险人 | 负触发 `直接起诉保险公司` |
| 纯工伤待遇了结且无第三人保险了结 | 整案转劳动；夹带交强险或商业三者了结则本窗正触发，工伤段分流，审查可留并转介 `评估工伤与第三人侵权竞合` |
| 诊疗过错或医疗鉴定终稿 | 转医疗；对责任保险了结可留 |
| 海事专门保险 | 转海事 |
| 未成争只要改合同 | 审查起草本窗搁置 |

审查闸打开（可部分开，须同时满足）：单方无冲突立场与授权；受害人直接请求与被保险人索赔分列；主成果是保险人了结或权益转让文本审查；至少一份可编号文本或可逐句的书面条款。口头手续不能开闸写成范围已限缩。

闸关闭（仍正触发）：仅口头手续、已读、截图转述，无文本版本；自称已签但落款、骑缝、电子确认冲突未闭合；未稳定或未鉴定却要审查覆盖未知伤残的概括弃权；被保险人单方文本要写成消灭受害人交强险请求；用户要当然有效、必须撤销、唯一公平价、先签再评残无风险。

「可以放心签」「保证能撤销」「口头只是手续」「放弃对侵权人一切请求当然必要」「未稳定也可以一次性了结」**不关窗**。闸未开则仍只交 1、2、10 节。

鉴定闸（与起草、谈判同一信号）：急救未结束、骨折未固定、内固定未取、计划内二次手术未做、烧伤未拆痂、伤残未鉴定 → 覆盖伤残、后续治疗、对侵权人一切请求的 `W#` 只能停止或默认保留。禁止「先签保险再告侵权人」无风险路径。鉴定闸关闭不关窗。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或受害人与保险人、被保险人同时交材料争同一了结审查包且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出隐瞒伤情、倒签出险、伪造票据、指导骗保、以了结掩盖犯罪、刑事逼签、要求把覆盖未知伤残或「永不追究一切」写入可签终稿，then 整体停止；第一次提出即停，不以「坚持」或「高风险确认」为门槛。

## 节点 1　文本版本

多页骑缝、附件、电子确认、中英文冲突并列，不得合并成「已限缩」。口头「只是走个手续」只登记 `S#`，不得写入 `C#` 已限缩。微信已读不得升格为已签署。

格式条款提示说明须有事实回链。未提示不当然一律无效，已提示不当然一律有效。检索锚点：保险合同编提示说明与免除保险人依法应承担义务等无效接口。条号不是 `L#`。未核验则效力格停止。

---

## 节点 2　弃权范围拆解

对保险人弃权、对侵权人弃权、未知伤残与后续治疗、精神损害、权益转让必须分行。放弃对侵权人的请求 **不是** 保险结算当然必要，必须标红；默认不消灭对侵权人、用人者及其他义务人的余额请求。要对某相对人放弃已知项目：必须项目、期间、相对人具体，且鉴定闸已开，否则该行停止。

交强险被侵权人直接请求不得被被保险人单方弃权消灭。受害人未到场、未授权：该 `W#` `现有依据不支持` 或停止。精神损害未提出或未单独列明，不得视为已弃，不得打包进「一切权利」。

未知伤残、未知手术、未知护理依赖、「永不追究一切」：该 `W#` 提出即停止，用户明示不能治愈。禁止「建议删除或保留，用户坚持则高风险确认」。未稳定不得建议签署概括弃权。用户要求本窗产出含上述概括弃权的可签终稿：整体停止。

未成年人、死亡近亲属：不得代弃权；一人不得代全体。转介 `评估未成年或无行为能力受害人代理`／`评估死亡赔偿权利人与分配`，该行停止。

---

## 节点 3　对价与伤残状态

伤残未闭合：现有依据不支持「可以放心签署概括弃权」。已鉴定：对照测算区间作风险，转介 `测算人身损害赔偿`，本窗不定残、不给唯一公平价。未知金额不写零。医保、工伤基金、已垫付须可见，禁止双领口径。

对价明显不足只作风险提示，不写成必然显失公平已成立。

---

## 节点 4　权益转让、代位与可逆性

权益转让范围须与保险人实际赔付且可代位项目对应。超额转让风险明示，不得建议签署超额转让。检索锚点：保险人自赔偿保险金之日起，在赔偿金额范围内代位；不影响被保险人就未获赔部分向第三者索赔。展开转 `应对保险代位求偿`，本窗不代做代位终稿。

未签：只出修改建议与拒签风险，删除或限缩概括弃权、保留后续治疗、分相对人、限缩转让至已赔金额。已签：只评估救济受限。重大误解、欺诈、显失公平、格式条款无效只作接口，可逆性低，不承诺能撤销，不选定法院，不写唯一起诉截止日。不指导伪造误解。不代签署、不代发送、不编已签字生效意见。

造成对方人身损害的免责条款无效接口：运行时核验，未核验则字段停止，不得写成「自愿放弃人身损害」当然有效。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过审查闸直接给可以放心签署或保证能撤销。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if C 端只要大众准备包，then 只分流不回改。

判断状态只许三值。口头转述、截图和「已读」不得写成已签署、范围已限缩或期限已起算。事故认定书不得单独写成民事终局并据此必须了结。

## 本任务回链纪律

本任务成果是「不代签署的保险了结或权益转让审查」。不包含：和解协议草稿、谈判方案、索赔材料、索赔通知、拒赔拆解、代位终稿、测算终稿、可以放心签署概括弃权。禁止口头手续升格。禁止对侵权人弃权写成结算当然必要。禁止被保险人单方消灭受害人交强险请求。禁止选边治愈。禁止倒签骗保。禁止未知写零。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标审查终稿已形成。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接。
风险档 A：不可逆弃权或骗保字段必须单独标可逆性。
