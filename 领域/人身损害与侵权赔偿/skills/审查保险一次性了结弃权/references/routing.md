# 边界与路由

## 正触发

保险人拿出结案协议、一次性了结或权益转让，需要审查弃权范围和风险。仅口头手续、治疗未稳定、用户要可以放心签、保证能撤销、放弃对侵权人一切请求当然必要仍正触发：审查闸可关，对应格停止，窗口不关。工伤待遇与第三人交强险或商业三者了结同时出现，仍正触发：工伤段分流劳动，了结审查可留。

双方秘密、隐瞒伤情、倒签出险、要求产出含未知损害概括弃权可签终稿的停止，优先于负触发。不得改走负触发去出一方签章意见。可以放心签、保证能撤销、口头手续不在下表。骗保倒签不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 双方侵权和解协议草稿 | `起草人身损害和解协议` |
| 让步档或底线 | `谈判人身损害和解` |
| 理赔材料包 | `准备交强险商业险索赔材料` |
| 发送前索赔通知 | `准备侵权索赔通知` |
| 拒赔拆解 | `应对保险拒赔减赔` |
| 代位求偿抗辩终稿 | `应对保险代位求偿` |
| 测算终稿或唯一公平价 | `测算人身损害赔偿` |
| 司法确认或赋强手续 | `办理人身和解执行力补强` |
| 起诉保险人 | `直接起诉保险公司` |
| 纯工伤待遇了结且无第三人保险了结 | 劳动领域 |
| C 端只要大众准备包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「倒签出险日」「伤情先别告诉核赔」不在本表，走整体停止。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 仅工伤待遇了结且无第三人保险了结 | 劳动领域 |
| 诊疗过错或医疗鉴定终稿 | 医疗医药领域；责任保险了结可留 |
| 海事专门保险 | 海事领域 |
| 指导隐瞒伤情或倒签骗保 | 整体停止；刑事只打红旗，不得用来出审查意见 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。对第三人交强险或商业三者了结可留。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 要改写成侵权和解正文 | `起草人身损害和解协议` |
| 只要档位底线 | `谈判人身损害和解` |
| 尚未交材料 | `准备交强险商业险索赔材料` |
| 对受约束相对人发索赔函 | `准备侵权索赔通知`（须本窗支持请求仍可主张） |
| 拒赔理由拆解 | `应对保险拒赔减赔` |
| 超额转让或追偿展开 | `应对保险代位求偿` |
| 金额区间 | `测算人身损害赔偿` |
| 未稳定评残 | `准备伤残鉴定材料`（闸关闭禁止转介启动） |
| 后续治疗 | `评估后续治疗费另行主张` |
| 死亡近亲属 | `评估死亡赔偿权利人与分配` |
| 未成年人 | `评估未成年或无行为能力受害人代理` |
| 工伤与第三人 | `评估工伤与第三人侵权竞合` |
| 交强险分账 | `评估道路交通事故责任与保险先行` |
| 时效 | `评估人身损害诉讼时效` |
| 起诉保险人 | `直接起诉保险公司` |

## 易混

「保险公司让签一次性了结」正触发。「和肇事方写和解」走起草。「材料还没交」走索赔材料。「骨折还没固定，业务员说走个手续不影响评残，我知道风险也要签，保证以后能撤销」仍正触发；闸可关；概括弃权停止，明示不能治愈；口头手续不得升格；不承诺能撤销。「下班被撞，商业险要被保险人放弃对司机一切权利并全部转让」正触发，工伤段分流，对侵权人弃权标红，转让不得超额。「车主先签了结，受害人还能不能找交强险」正触发；被保险人单方不消灭受害人直接请求。「倒签到保单期内，伤情先别写全」整体停止。
