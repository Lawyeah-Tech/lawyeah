# 边界与路由

## 正触发

保险人拿出结案协议或权益转让，需要审查弃权范围和未知伤残风险。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 普通和解起草 | `起草人身损害和解协议` |
| 理赔材料 | `准备交强险商业险索赔材料` |
| 隐瞒伤情骗保 | 整体停止 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 骗保刑事 | 停止并刑事红旗 |
| 工伤了结 | 劳动领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“保险公司让签一次性了结”正触发。“和肇事方写和解”走起草。“材料还没交”走索赔材料。
