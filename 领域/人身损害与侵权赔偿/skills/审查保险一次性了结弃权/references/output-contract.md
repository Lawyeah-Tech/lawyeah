# 输出合同

按触发结果选择交付形状。审查闸未打开不得交付签章意见或审查终稿已形成。禁止可以放心签署概括弃权。禁止口头手续升格为范围已限缩。禁止保证能撤销。禁止唯一公平价。禁止选定法院。禁止自行定残。禁止未知金额写零。禁止代签署、发送版。禁止选边治愈。禁止倒签或隐瞒伤情。禁止把对侵权人弃权写成保险结算当然必要。禁止被保险人单方了结消灭受害人交强险直接请求。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 审查闸关闭或节点 0 整案转出 | 第 1、2、10 节，可附标注停止的逐句拆解。禁止签章意见、可以放心签署。对第三人保险了结可留时不得因工伤整案转出 |
| 整体停止 | 第 1、10 节。禁止 `W#` 可签意见、选边、倒签方法。双方秘密、隐瞒伤情、倒签出险、要求产出含未知损害概括弃权的可签终稿第一次即停，优先于负触发；无选边治愈，无「坚持」或「高风险确认」门槛 |
| 用户要可以放心签、保证能撤销、口头手续已限缩、放弃对侵权人一切请求当然必要（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或停止；闸未开则仍只交 1、2、10；不得改走负触发关窗；成果不得标审查终稿 `已形成` 或可以放心签署 |
| 正触发且闸开（可部分开） | 下列十节表头均出现；未签与已签分形；效力、代位、可撤销未核验的单元格填 `依据不足，无法形成结论` 或 `待核`；禁止为填满而宣布可以放心签、保证能撤销或对侵权人请求已消灭 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入审查终稿已形成。双方秘密未解不得进入「部分形成」。每个 `C#`／`W#` 必须带来源和状态。`L#` 不得直接抄技能内条号。口头已限缩、概括弃权当然有效、保证能撤销若返回则记噪声。稿件状态默认 `审查草稿`。

## 1. 触发、单方立场、授权与成果状态

审查闸开、部分开或关。签署状态未签或已签必须标明。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。不代签署。

## 2. 来源登记与 MCP 调用表

`S/D/C/R/L/I/G/W/V`。口头手续、已读只登记 `S#`／`V#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 文本版本 `C#`

骑缝、附件、电子确认、中英文冲突并列。口头不得升格。险种分袋。

## 4. 弃权逐句拆解 `W#`

对保险人、对侵权人、未知伤残、精神损害、权益转让分列。交强险直接请求是否仍打开必须可见。

## 5. 未知伤残与鉴定闸

未稳定不得建议概括弃权。覆盖未知则停止，明示不能治愈。禁止先签再评残无风险。

## 6. 对价对照

只对照测算区间作风险。不给唯一公平价。未知不写零。不定残。

## 7. 权益转让与代位

须与实际赔付对应。超额红旗。不影响未获赔部分。转介代位专项，不写代位终稿。

## 8. 未签修改建议或已签救济

未签：删除或限缩概括弃权、分相对人、保留后续治疗。已签：救济受限，可逆性低，不承诺能撤销。不选定法院。

## 9. 禁止骗保与下一步

隐瞒伤情、倒签第一次停。转介测算、鉴定、索赔通知、拒赔、代位、起草只点名。不代签署。

## 10. 缺口、停止项与提示

须列对方最强解释：只是走个手续不影响以后评残、可以放心签概括弃权、坚持并书面知情就能签、交强险已赔所以对司机不能再要、被保险人签字受害人也不能再向交强险要、转让全部权益哪怕只赔了医疗费、签完保证能撤销、选某法院起诉、先签保险再告侵权人无风险、工伤处理所以本窗不用审了结书。

本成果不是可签了结书、不是和解协议、不是材料包、不是拒赔拆解、不保证能撤销、不是唯一公平价。不代签署。
