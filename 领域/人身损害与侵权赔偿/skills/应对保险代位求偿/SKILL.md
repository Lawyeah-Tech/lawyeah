# 应对保险代位求偿

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成不代提交的保险代位应对包：代位闸、`Pay#` 实赔分袋、`Sub#` 代位范围（以实际赔付且可代位项目为限）、`H#` 重复受偿对照、第三人对被保险人抗辩接口、放弃请求效果待核。不保证追回。不选定法院。未实赔不得打开已核实代位额。人身保险金与商业代位分列。交强险法定追偿与商业代位分列。工伤基金或医保追偿与民事代位分列，基金行分流劳动，商业 `Sub#` 可留。尚未赔付就要追偿、保证追回、人身保险当然可代位、此致某院不关窗。双方秘密、伪造赔付、指导同一票据两头领第一次即整体停止，不得选边。主成果才是直接索赔应诉才转 `保险公司应对直接索赔`。

`depends-on` 为空。保险人被诉应诉转 `保险公司应对直接索赔`（`Rec#` 只接口）。原告诉保包转 `直接起诉保险公司`。了结弃权审查转 `审查保险一次性了结弃权`。反诉状转 `评估反诉或抵销`。工伤基金追偿段转劳动并转介 `评估工伤与第三人侵权竞合`。测算转 `测算人身损害赔偿`。

## 工作边界

正触发：保险人拟就已赔或声称已赔项目向第三者追偿，或第三人、受害方被保险人追索已获医疗费等。「保险公司赔完来找我追偿」「受害人两边都领了医疗费」正触发。尚未实际赔付就要代位、保证全额追回、人身保险金当然可代位、家庭成员当然能追、被保险人已放弃所以当然不能追或当然能追、工伤基金追偿等于商业代位、未知写零、选定某院，仍正触发：代位闸可关，对应格填 `现有依据不支持` 或字段停止，窗口不关，不得改走负触发，不得标代位状终稿已形成。工伤基金追偿与商业代位同时出现：本窗正触发，基金段分流劳动，商业 `Sub#` 可留。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是保险人被直接起诉的应诉答辩终稿（转 `保险公司应对直接索赔`）；
- 主成果是受害人侧起诉保险人的诉保包（转 `直接起诉保险公司`）；
- 只要了结弃权或权益转让审查终稿（转 `审查保险一次性了结弃权`）；
- 只要反诉状终稿（转 `评估反诉或抵销`）；
- 投保人或第三人完整侵权抗辩且不要代位段（转 `应对人身损害一审`）；
- 只要测算终稿（转 `测算人身损害赔偿`）；
- 纯工伤待遇、工伤认定或基金追偿且无商业代位或第三人分账（转劳动／`评估工伤与第三人侵权竞合`）；
- C 端只要大众准备包（只分流）；
- 未成争改合同（审查起草搁置）。

「尚未赔付就要代位」「指导重复领取」「工伤基金追偿当作普通商业代位而不分列」**不是负触发**。前两项：未实赔闸关不关窗；指导双领走整体停止。第三项：分列，基金段分流，商业行可留，窗口不关。双方秘密、伪造赔付、倒签赔付日**不在负触发表**，走整体停止。

## 建立工作坐标

确认：使用者与授权；单方立场（已赔保险人追偿 **或** 被追索第三人／受害方，不得同时策略）；险种袋；实赔凭证与赔付日；基础侵权关系；被保险人是否家庭成员；是否放弃对第三者请求及时点；是否夹带工伤基金或医保已付；法域。

口头「已经赔了」、截图、核赔单只登记 `S#`／`V#`。不得升格为已实际划付或时效已起算。用户坚持「此致某院」「保证追回」不构成打开该格的授权。

同时掌握双方秘密，或保险人与被追索人同时交材料争同一份代位策略：`整体停止`，不得以选边治愈，也不得改走负触发。一方已开口且委托范围就是本方代位或抗辩、且未掌握对方秘密时，可推定该方立场。只要同时掌握双方秘密，无例外整体停止。提出伪造赔付凭证或权益转让、倒签赔付日、指导同一票据两头领、隐瞒基金已付套取商业代位：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 赔付凭证、权益转让；`R#` 文书；`Pay#` 实赔；`Sub#` 代位行；`H#` 重复受偿；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。稿件状态只用 `草案`、`代位闸关闭`、`提交前待核`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。本任务默认 `草案`，不代提交。禁止「保证追回」「此致某院」「未赔可代位」「人身保险当然可代位」。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：保险人自向被保险人赔偿保险金之日起，在赔偿金额范围内代位行使被保险人对第三者请求赔偿的权利；被保险人已经从第三者取得损害赔偿的，保险人赔偿保险金时可以相应扣减；保险人行使代位权利，不影响被保险人就未取得赔偿的部分向第三者请求赔偿；保险事故发生后、保险人未赔偿保险金之前，被保险人放弃对第三者请求赔偿的权利的，保险人不承担赔偿保险金的责任；保险人向被保险人赔偿保险金后，被保险人未经保险人同意放弃对第三者请求赔偿的权利的，该行为无效；除被保险人的家庭成员或者其组成人员故意造成保险事故外，保险人不得对其行使代位；人身保险的保险人不得向第三者行使代位请求赔偿的权利；交强险对无证、醉酒、故意制造事故等致第三人人身损害的，限额内赔偿后可向侵权人追偿，与商业代位分袋。技能正文条号不是 `L#`。噪声：已失效《侵权责任法》、已失效《合同法》、2002 年保险法旧代位条号、未赔付即可代位、人身保险当然可代位、超额代位、保证追回、工伤基金等于商业代位、选定某院、已读即时效起算。不可用则代位范围、人身保险禁止代位、放弃效果、交强险追偿、基金分列、时效字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变代位范围、人身保险禁止代位、放弃效果或追偿时效的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补未实赔代位被驳、人身保险代位被驳、超额代位、同一医疗费重复受偿、基金追偿与商业代位必须分列的实务反例。
- `search_template` 只借鉴代位起诉状或被追索答辩状栏目，不把范本当法定格式、已提交文本或唯一法院。

工具不可用时继续 `Pay#`／`Sub#`／`H#` 编目与事实；代位范围、人身保险禁止代位、放弃效果、交强险追偿、基金分列、时效字段停止。不得凭记忆写成未赔付可代位、人身保险当然可代位、保证追回或基金混入商业代位。

## 判断节点

执行顺序和停止条件以 [代位求偿方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、代位闸与不关窗

工伤基金段分流劳动，商业代位可留。双方秘密、伪造赔付、指导双领第一次停。未实赔、保证追回、人身保险当然可代位不关窗。主成果是直接索赔应诉才负触发。

### 2. 实赔分袋 `Pay#`

一险种一袋。口头核赔不得升格已划付。未实际支付不得打开已核实代位额。

### 3. 代位范围 `Sub#`

以实赔且可代位项目为限。不影响未获赔部分。人身保险金原则上不打开。交强险法定追偿与商业代位分列。家庭成员非故意不得代位。

### 4. 抗辩与放弃

第三人可主张其对被保险人的抗辩。赔前放弃与赔后未经同意放弃分列待核。时效已读不得起算。

### 5. 重复受偿 `H#` 与转介

同一票据两头领该格不支持。指导双领整体停止。不代提交。不保证追回。第 9 节不得写成提交指令。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；保险人与被追索人争同一策略；伪造或虚增赔付、权益转让；倒签赔付日；指导同一票据两头领；隐瞒基金已付套取商业代位。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：代位范围、人身保险禁止代位、放弃效果、交强险追偿、基金分列、时效未核验。代位闸未开则提交稿停止，窗口不关。用户要未赔可代位、保证追回、人身保险当然可代位、选定某院、未知写零则该格停止，窗口不关。
- `目标停止`：主目标变为直接索赔应诉、诉保包、了结审查、反诉状、测算或纯工伤待遇。未赔就要代位、保证追回不在目标停止。

禁止指导伪造赔付、倒签、双领或代提交。不给胜诉率。不选定法院。不代提交。不编唯一截止日。不把未知写成零。不定残。不保证追回。
