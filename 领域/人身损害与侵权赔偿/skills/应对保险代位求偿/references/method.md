# 代位求偿方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。稿件状态只用 `草案`、`代位闸关闭`、`提交前待核`、`停止`。禁止胜诉率、追回率、唯一必得总额、唯一截止日、选定法院、自行宣布伤残等级、保证追回、代提交。未知金额不写零。本任务不代提交。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、已失效《合同法》、2002 年保险法旧代位条号、把未赔付写成可代位、把人身保险写成当然可代位、把工伤基金写成商业代位、把已读写成时效起算时记为噪声，不得写入 `L#`。禁止指导伪造赔付、倒签、同一票据两头领。

`Pay#` 固定列：`编号｜险种袋（交强险法定追偿／财产或责任保险代位／人身保险金／工伤基金／医保，禁止一行混袋）｜赔付对象｜项目｜凭证种类｜赔付日｜是否已实际支付｜金额状态（已核实／情景／无法估计；未知不写零）｜可否代位（可／不可／待核）｜来源回链`。口头核赔、截图只进 `S#`。

`Sub#` 固定列：`编号｜主张立场（已赔保险人／被追索第三人／被追索受害人，一行一立场）｜相对人｜绑 Pay#｜代位项目｜是否超出实赔｜未获赔部分是否仍打开（默认打开）｜家庭成员或组成人员｜故意造成事故（是／否／待核）｜放弃时点（赔前／赔后／无）｜第三人可援用对被保险人抗辩｜判断三值｜状态（草案／闸关闭／停止）｜来源回链`。

`H#` 固定列：`编号｜同一票据或同一填平项目｜已领来源（受害人／保险人／基金／第三人）｜是否禁止双领｜已返还或已扣减｜判断三值｜状态｜来源回链`。

口头「已经赔了」、微信已读只进 `S#`／`V#`，不得升格已划付或时效已起算。

## 节点 0　分流、立场、代位闸与不关窗

整案转出或闸关闭只交付第 1、2、10 节或标注停止的表，不得交付代位状终稿，不得标保证追回。闸部分打开时：仅对可回链实赔行给出草案，其余行停止或不打开。

| 信号 | 处理 |
| --- | --- |
| 主成果是保险人被直接起诉的应诉答辩 | 负触发 `保险公司应对直接索赔` |
| 主成果是受害人侧诉保包 | 负触发 `直接起诉保险公司` |
| 只要了结弃权或权益转让审查终稿 | 负触发 `审查保险一次性了结弃权` |
| 只要反诉状终稿 | 负触发 `评估反诉或抵销` |
| 投保人或第三人完整侵权抗辩且不要代位段 | 负触发 `应对人身损害一审` |
| 只要测算终稿 | 负触发 `测算人身损害赔偿` |
| 纯工伤待遇或基金追偿且无商业代位或第三人分账 | 整案转劳动并转介 `评估工伤与第三人侵权竞合`；夹带商业代位则本窗正触发，基金段分流，`Sub#` 可留 |
| 医疗损害主轴 | 转医疗；保险代位民事段可留 |
| 海事 | 转海事 |
| 未成争改合同 | 审查起草本窗搁置 |

代位闸打开（可出 `Sub#` 草案，仍不代提交、不保证追回）须同时满足：单方无冲突立场与授权（保险人追偿 **或** 被追索抗辩，不得同时策略）；主成果是代位范围／抗辩／追偿草稿，不是直接索赔应诉、诉保包、了结审查、工伤待遇终稿；拟打开的 `Sub#` 有可编号实赔 `Pay#`；拟交付不含伪造赔付、指导双领、保证追回、此致某院、未知写零、人身保险金当然代位、工伤基金混入商业代位结论。

闸关闭（仍正触发）：尚未实际赔付却要已核实代位额或代位状终稿；人身保险金主张当然代位；超额代位；非故意家庭成员要追；保证追回；选定某院；未知写零；发送版／代提交；把工伤基金写成普通商业代位而不分列（该行关，商业行可部分开）。闸未开则仍只交 1、2、10 节。过期：十节表头可出现，提交稿停止。

「尚未赔付就要追偿」「保证追回」「人身保险当然可代位」「工伤基金等于商业代位」「此致某院」**不关窗**。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或保险人与被追索人争同一份代位策略且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出伪造赔付、倒签赔付日、指导同一票据两头领、隐瞒基金已付套取商业代位，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　实赔分袋 `Pay#`

检索锚点：保险法（2015 修正）第六十条。保险人自向被保险人赔偿保险金之日起，在赔偿金额范围内代位。条号不是 `L#`。未实际支付不得打开已核实代位额。权益转让书不等于实赔。一险种一袋，禁止混袋。

交强险酒驾／无证／故意制造事故等对第三人人身损害的限额内赔偿后追偿，检索锚点为道路交通事故损害赔偿解释第十五条，时效自保险公司实际赔偿之日起计算，与商业代位分袋。工伤基金、医保已付另袋，不得写入商业代位结论。

## 节点 2　代位范围 `Sub#`

以实赔且可代位项目为限。超额代位 `现有依据不支持`。保险人行使代位权利，不影响被保险人就未取得赔偿的部分向第三者请求赔偿。精神损害、死亡赔偿金是否可代位待核，不得一律主张。

人身保险：保险人给付保险金后，不享有向第三者追偿的权利；被保险人或受益人仍有权向第三者请求。检索锚点保险法第四十六条。人寿、意外、健康及费用补偿型例外须核验，**不得写成当然可代位或当然一律不可的闭集**。该格通常不打开或待核，窗口不关。

家庭成员或其组成人员：除故意造成保险事故外，不得对其行使代位。检索锚点保险法第六十二条。

交强险法定追偿不得写成保险法第六十条同一闭集。追偿不对抗本案受害人的直接索赔。

## 节点 3　抗辩与放弃

第三人可以主张其对被保险人的抗辩（过错、因果、时效、已付）。检索锚点：代位是法定债权转让，抗辩可随同。时效分列，已读、截图、作出日不得起算。交强险追偿时效以实际赔偿之日为锚点。不写死唯一日历截止日。

放弃：保险事故发生后、保险人未赔偿保险金之前，被保险人放弃对第三者请求赔偿的权利的，保险人不承担赔偿保险金的责任。保险人向被保险人赔偿保险金后，被保险人未经保险人同意放弃对第三者请求赔偿的权利的，该行为无效。检索锚点保险法第六十一条。赔前／赔后分列待核。展开审查转 `审查保险一次性了结弃权`。保险法解释四第九条、第十条、第十一条、第十三条运行时核验：订立前已放弃、未通知第三者重复清偿、未协助致使不能代位、被保险人已起诉时可合并或共同原告。

## 节点 4　重复受偿与转介

同一票据或同一填平项目两头领取：该 `H#` `现有依据不支持`。已返还或已扣减必须入账。仅询问是否合法＝不关窗。指导双领＝整体停止。

保险人起诉第三人的代位起诉包留本窗，不进 `提起人身损害一审` 普通侵权总包。要把追偿当反诉：只红旗，转 `评估反诉或抵销`。不代提交。不保证追回。禁止预填此致某院。第 9 节不得写成提交指令。

| 接口 | 本窗 | 转介 |
| --- | --- | --- |
| 保险人被诉应诉 | 负触发 | `保险公司应对直接索赔` |
| 原告诉保 | 负触发 | `直接起诉保险公司` |
| 了结弃权文本 | 放弃效果待核 | `审查保险一次性了结弃权` |
| 工伤基金追偿 | 分列；基金段分流 | `评估工伤与第三人侵权竞合`／劳动 |
