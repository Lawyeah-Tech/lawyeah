# 边界与路由

## 正触发

保险人已赔付后向第三人追偿，或受害方被追索已获医疗费。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 直接索赔诉讼 | 起诉或应诉保险人原子 |
| 工伤基金追偿主轴 | 劳动领域（本任务仅分列） |
| 保险弃权审查 | `审查保险一次性了结弃权` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 工伤基金追偿 | 劳动领域 |
| 医保追偿 | 另行标红旗 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“保险公司赔完来找我追偿”正触发。“受害人两边都领了医疗费”也是正触发。“工伤基金来追”劳动分列。
