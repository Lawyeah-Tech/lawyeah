# 边界与路由

## 正触发

保险人拟就已赔或声称已赔项目向第三者追偿，或第三人、受害方被追索。「保险公司赔完来找我追偿」正触发。「受害人两边都领了医疗费」正触发。尚未实际赔付就要代位、保证追回、人身保险金当然可代位、家庭成员当然能追、工伤基金等于商业代位、选定某院、未知写零，仍正触发：代位闸可关，对应格停止，窗口不关。工伤基金追偿与商业代位同时出现，仍正触发：基金段分流劳动，商业 `Sub#` 可留。

双方秘密、伪造赔付、倒签赔付日、指导同一票据两头领的停止，优先于负触发。不得改走负触发去出一方状。「尚未赔付就要代位」「工伤基金不分列」「指导重复领取」不在下表。伪造双领不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 保险人被直接起诉的应诉答辩终稿 | `保险公司应对直接索赔` |
| 受害人侧起诉保险人的诉保包 | `直接起诉保险公司` |
| 了结弃权或权益转让审查终稿 | `审查保险一次性了结弃权` |
| 反诉状终稿 | `评估反诉或抵销` |
| 投保人或第三人完整侵权抗辩且不要代位段 | `应对人身损害一审` |
| 测算终稿 | `测算人身损害赔偿` |
| 纯工伤待遇或基金追偿且无商业代位或第三人分账 | 劳动领域／`评估工伤与第三人侵权竞合` |
| C 端只要大众准备包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「未赔先追」「保证追回」「此致某院」「人身保险当然可代位」不在本表。「同一发票两边全额领、赔付日往前倒、两边材料选边」不在本表，走整体停止。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 仅工伤基金追偿且无商业代位或第三人分账 | 劳动领域 |
| 医疗损害主轴 | 医疗医药领域；保险代位民事段可留 |
| 海事 | 海事领域 |
| 指导伪造赔付、倒签或同一票据两头领 | 整体停止 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。商业代位可留。

## 易混

「保险公司赔完来找我追偿」正触发。「还没打款先写代位状保证追回、此致某院」仍正触发；闸关；未实赔不得已核实额；窗口不关；不得转直接索赔应诉，除非主成果变成「我们被受害人告了」。「工伤基金来追已报医疗费，商业险也要代位」正触发；基金段分流；商业行可留；不得整案转劳动。「意外伤害保险金一并代位」该格不支持或待核，窗口不关。「同一发票两边全额领、两边材料选边、赔付日往前倒」整体停止。
