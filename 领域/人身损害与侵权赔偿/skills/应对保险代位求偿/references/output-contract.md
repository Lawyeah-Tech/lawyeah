# 输出合同

按触发结果选择交付形状。代位闸未打开不得交付代位状终稿或保证追回。禁止选定唯一法院或预填「此致某院」。禁止已读、截图、核赔单当实赔或时效起算。禁止未实赔打开已核实代位额。禁止人身保险金当然可代位。禁止把交强险法定追偿与商业代位混袋。禁止把工伤基金混成商业代位而不分列。禁止未知金额写零。禁止胜诉率。禁止代提交。禁止选边治愈。不定残。第 9 节不得写成提交指令。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 代位闸关闭或节点 0 整案转出 | 第 1、2、10 节：关闭理由、实赔待核和最小补证。可附停止的 `Pay#`／`Sub#`／`H#`。禁止代位状终稿、保证追回、唯一截止日、选定某院。工伤基金可留商业行时不得整案转出 |
| 整体停止 | 第 1、10 节。禁止 `Sub#` 策略包、选边、伪造或双领方法。双方秘密、伪造赔付、指导同一票据两头领第一次即停，优先于负触发；无选边治愈，无「坚持」门槛 |
| 用户要未赔可代位、保证追回、人身保险当然可代位、家庭成员当然能追、基金等于商业代位、选定某院、未知写零（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；闸未开则仍只交 1、2、10；不得改走负触发关窗；不得标代位状终稿 `已形成` |
| 正触发且闸开（可部分开） | 下列十节表头均出现；实赔、范围、放弃未核验格待核；一行一袋；禁止为填满而写保证追回、此致某院、未赔可代位或人身保险当然可代位 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入代位状终稿已形成。双方秘密未解不得进入「部分形成」。每个 `Pay#`／`Sub#`／`H#` 必须带来源和三值判断。`L#` 不得直接抄技能内条号。未赔可代位、人身保险当然可代位、基金等于商业代位若返回则记噪声。稿件状态默认 `草案`。

## 1. 触发、单方立场、授权与成果状态

代位闸开、部分开或关。立场必须标明保险人追偿 **或** 被追索抗辩，不得同时策略。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。稿件默认 `草案`。不代提交。

## 2. 来源登记与 MCP 调用表

`S/D/R/Pay/Sub/H/L/I/G/V`。口头已经赔了、已读只登记 `S#`／`V#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 实赔分袋 `Pay#`

一险种一袋。是否已实际划付必须标明。未实际支付不得打开已核实额。交强险法定追偿、商业代位、人身保险金、工伤基金、医保分列。

## 4. 代位范围 `Sub#`

以实赔为限。不影响未获赔部分。超额不支持。人身保险金原则上不打开。家庭成员非故意不得代位。交强险法定追偿不得混入商业代位闭集。

## 5. 不可代位项目待核

人身保险金、精神损害、死亡赔偿金等分列待核，不得一律主张或一律消灭。

## 6. 第三人抗辩与放弃

过错、因果、时效、已付可对保险人主张。赔前放弃与赔后未经同意放弃分列。已读不得起算。不写死唯一截止日。

## 7. 重复受偿 `H#`

同一票据两头领该格不支持。已返还或已扣减入账。指导双领不在本节继续编策略，走整体停止。

## 8. 草稿接口

代位起诉或被追索答辩要点。草案，不代提交。不预填此致某院。闸未开则本节停止。不保证追回。

## 9. 下一步与转介

转介直接索赔应诉、诉保、竞合、弃权、反诉、一审、测算、时效只点名。不写成发送版或提交指令。不选定法院。不代提交。

## 10. 缺口、停止项与提示

须列对方最强解释：还没打款先按核定额追、保证全额追回、此致某区法院、意外伤害保险金一并代位、未获赔的精神损害当然消灭、家庭成员也一并告、工伤基金来追就是商业代位、同一发票两边全额领、赔付日往前倒、已读那天起算三年、两边材料都给你选边。

本成果不是已提交代位状、不是直接索赔应诉、不是诉保包、不是了结审查、不是反诉状、不是测算终稿、不是工伤待遇表、不保证追回、不是唯一截止日、不是选定法院。不代提交。
