# 输出合同

按触发结果选择交付形状。禁止唯一内部分担百分比。禁止把补充、补偿或用人者替代写成连带。禁止编造被告。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出（主成果仅工伤三段且无需对外形态；诊疗主轴；海事） | 第 1、2、10 节。禁止形态表 |
| 整体停止 | 第 1、10 节。禁止形态表、50%、被告清单和改写方案。双方秘密、编造被告、伪造在场名单、隐匿监控时，整体停止优先于负触发 |
| 正触发且可比较 | 下列十节表头均出现；用户要唯一百分比时第 6、8 节数字格填 `待核` 或 `依据不足，无法形成结论`；用户要把补充改写连带时第 7 节填 `现有依据不支持`，不关窗；禁止省略后改填各 50% 或全体连带 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。双方秘密未解不得进入「部分形成」。每个 `Q#` 必须带证明负担方和判断三值。

## 1. 触发、单方立场、授权与成果状态

写明是否需要对同一损害比较对外形态、受限字段。双方秘密未解不得进入「部分形成」。

## 2. 来源登记与 MCP 调用表

行为时间线、认定书、监控必须编号。口头「一起的」只登记 `S#`。`L#` 不得直接抄技能内条号。MCP 未调用也留一行。

## 3. 行为人与角色表

场所、用人者、保险人、教育机构、可能加害人单独标记，不并入共同加害人。不得列入未确定的路人或全体业主。

## 4. 共同实施或教唆帮助

意思联络必须回链。互殴不等于当然共同实施侵害第三人。监护人相应责任只标接口。证明负担方可见。

## 5. 共同危险判断

不得把业主全体、可能加害人、不明逃逸写入。免责须能够确定具体侵权人；禁止「自证不是我即免」。范围须为已实施危险行为的确定行为人。

## 6. 分别侵权足以或不足

连带或按份或待核。禁止唯一百分比。认定书不得升格为已核验「足以」。

## 7. 补充、补偿、替代禁令

不打开则填 `不打开`。明示不得改写连带。执行顺序只标接口，不写场所或物业终稿。

## 8. 追偿接口

不附追偿状。不填唯一内部分担。第一百七十八条平均规则待核。

## 9. 证据缺口与下一步

只转介：过错原因力、因果分割、保险、场所、用人者、打架、侵权人不明、发函、立案。禁止在此写起诉状或追偿状。监控在对方控制不得推定共同实施。

## 10. 缺口、停止项与提示

须列对方最强解释（一起的就是连带、认定书共同即民事连带、监控在对方即已共同实施、自证不是我即免、直接结合即连带、补充可改连带、全体业主可当共同危险、对内 50% 即对外份额、要数字就必须关窗）与证据缺口。

本成果不是场所安保意见、用人者替代意见、高空补偿方案、查明路径、保险分账、内部分担判决或起诉状。
