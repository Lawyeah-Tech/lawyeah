# 边界与路由

## 正触发

需要单独判断数人对同一损害的对外形态（共同实施、教唆帮助、共同危险、分别侵权足以或不足）。己方或对方主张均可。用户要唯一内部分担百分比或要把补充改写成连带，仍正触发，该格字段停止。

受害人开口且委托范围是形态比较时，不因口语化咨询整体停止。双方秘密、编造被告或伪造在场名单的停止，优先于负触发。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要总体责任总图 | `评估人身侵权责任` |
| 只要场所补充终稿且无需 1168–1172 | `评估场所安全保障义务` |
| 只要教育机构责任终稿 | `评估教育机构责任` |
| 只要用人者替代且无共同实施 | `评估用人者责任` |
| 只要高空抛物补偿终稿 | `评估物件脱落坠落与高空抛物` |
| 只要侵权人不明查明路径 | `评估侵权人不明路径` |
| 只要交强险或多车保险分账 | `评估道路交通事故责任与保险先行` |
| 只要工伤与第三人分账 | `评估工伤与第三人侵权竞合` |
| 只要打架或防卫终稿 | `评估打架伤害民事路径` |
| 只要过错原因力终稿 | `评估过错与原因力` |
| 只要起诉状 | `提起人身损害一审` |

「要各 50%」「要把补充改成连带」不在本表。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 场所第三人致害、相应补充 | `评估场所安全保障义务` |

| 个人之间劳务 | `评估提供劳务受害` |

| 该列谁、保险能否进 | `评估责任主体与保险覆盖` |
| 互殴、防卫 | `评估打架伤害民事路径` |
| 过失相抵、原因力序位 | `评估过错与原因力` |

| 教唆帮助无或限制行为能力人、监护人 | `评估未成年或无行为能力受害人代理` |

| 已选定后起诉 | `提起人身损害一审` |
| 追加被告 | `追加变更责任主体` |
| 监控在对方控制 | `准备监控保存通知` |

## 易混

「两个人一起打第三者，能不能一起赔」正触发；「一起的所以各 50%」仍正触发，数字格停止。「商场没保安，小偷把人打了」主成果是场所补充。「单位员工撞人」主成果是用人者替代。「楼上砸下来全楼赔」不是共同危险，转高空抛物。「找不到人怎么查」转侵权人不明。「要把商场和打人的写成连带」正触发，第 7 节禁令格 `现有依据不支持`，不关窗。指导把未入镜路人或全体业主列为被告：整体停止。
