# 边界与路由

## 正触发

存在多名行为人、教唆帮助、共同危险或分别实施，需要判断对外连带或按份以及对内追偿。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 场所对第三人补充责任 | `评估场所安全保障义务` |
| 用人者替代责任 | `评估用人者责任` |
| 工伤与第三人分账 | `评估工伤与第三人侵权竞合` |
| 高空抛物可能加害人 | `评估物件脱落坠落与高空抛物` |
| 总体总图 | `评估人身侵权责任` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 工伤待遇 | 劳动领域 |
| 医疗损害多数医疗机构责任主轴 | 医疗医药领域 |
| 海事共同海损或船舶碰撞 | 海事领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“两个人一起打的，能不能一起赔”正触发。“商场没保安，小偷把人打了”主成果是场所补充责任。“单位员工撞人”主成果是用人者责任。
