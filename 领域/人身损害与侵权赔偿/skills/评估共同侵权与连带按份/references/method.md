# 连带按份方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。对外形态只用 `连带` / `按份` / `待核` / `不打开`。禁止唯一内部分担百分比、三七开、各 50%。未知金额不写零。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》第八条至第十四条、2003 年人身损害赔偿解释第三条（直接结合即连带、间接结合即按份）、第四条（证明不是自己造成即免责）、第五条（放弃部分共同侵权人）时记为噪声，不得写入 `L#`。已失效《侵权责任法》第八十七条不得当作高空抛物或共同危险现行规则。

`Q#` 交付列：`主体｜行为｜形态候选｜对外效果｜证明负担方｜来源｜判断`。形态不是闭集四选一。补充、相应责任、补偿、替代不得填进连带格。

---

## 节点 0　分流与行为人编目

整案转出只交付第 1、2、10 节。

先建行为人表。场所经营者、用人者、保险人、教育机构、可能加害人另标角色，不并入共同加害人。名称不一致不合并。
口头「他们一起的」只登记 `S#`。若 if 无行为时间空间描述，then 共同实施 `依据不足，无法形成结论`，不得填连带。
不得因对方控制监控而推定共同实施。保存通知不等于法院保全。

若 if 主成果只要场所或教育机构补充终稿且无需 1168–1172 比较，then 负触发至对应专项。
若 if 主成果只要用人者替代且无共同实施事实，then 负触发至 `评估用人者责任`。
若 if 主成果只要高空抛物补偿或物业抛物终稿，then 负触发至 `评估物件脱落坠落与高空抛物`。
若 if 主成果只要查明不明侵权人，then 负触发至 `评估侵权人不明路径`。
若 if 主成果只要保险分账，then 负触发至 `评估道路交通事故责任与保险先行`。
若 if 主轴是诊疗过错多数医疗机构，then 转医疗。
若 if 主成果仅是工伤三段且无需对外形态，then 整案转劳动。同事执行任务致害默认转 `评估用人者责任` 与工伤竞合，不得先写成 1168。

用户要把补充改写成连带：不关窗，连带格 `现有依据不支持`。用户要各 50%：不关窗，数字格停止。

## 节点 1　共同实施、教唆帮助

检索锚点：民法典第一千一百六十八条。二人以上共同实施侵权行为，造成他人损害的，应当承担连带责任。主张对外连带的一方证明共同实施。不得仅因多人在场、同车、同局写成共同侵权。不得用直接结合或间接结合分类。
互殴：须按人对被侵权人编目。互殴彼此不等于当然共同实施侵害第三人。防卫或互殴定性转介 `评估打架伤害民事路径`。过失相抵转介 `评估过错与原因力`。
共同故意或共同过失是否均走第一千一百六十八条：运行时核验，未核验则该格 `待核`，不得两套口径各写一套。

检索锚点：民法典第一千一百六十九条。教唆、帮助他人实施侵权行为的，应当与行为人承担连带责任。主张方证明教唆或帮助行为。
教唆、帮助无民事行为能力人或限制民事行为能力人实施侵权行为的，教唆帮助人应当承担侵权责任，不得与被教唆人写成连带。监护人未尽到监护职责的，承担相应的责任，形态待核，转介 `评估未成年或无行为能力受害人代理`。不得漏监护人接口，也不得把「相应责任」填进全额连带格。

## 节点 2　共同危险

检索锚点：民法典第一千一百七十条。二人以上实施危及他人人身、财产安全的行为，其中一人或者数人的行为造成他人损害，能够确定具体侵权人的，由侵权人承担责任；不能确定具体侵权人的，行为人承担连带责任。
行为人必须是已实施危险行为的**确定范围**。被侵权人证明危险行为范围、损害、不能确定具体侵权人即可。具体谁造成的证明负担倒置，但免责条件是**能够确定具体侵权人**。禁止写成「证明损害不是自己造成即免责」。该旧说对应已删除的 2003 年解释第四条，为噪声。
禁止把全体业主、可能加害人、监控未拍到的路人、肇事逃逸不明驾驶人写入共同危险圈。不明逃逸转介 `评估侵权人不明路径`。高空抛物可能加害人补偿转介 `评估物件脱落坠落与高空抛物`。指导编造未入镜路人或伪造在场名单：整体停止。

## 节点 3　分别侵权足以或不足

检索锚点：民法典第一千一百七十一条。二人以上分别实施侵权行为造成同一损害，每个人的侵权行为都足以造成全部损害的，行为人承担连带责任。主张连带的一方证明「足以」。
检索锚点：民法典第一千一百七十二条。能够确定责任大小的，各自承担相应的责任；难以确定责任大小的，平均承担责任。平均规则须运行时核验，未核验则按份金额字段停止。禁止输出唯一内部分担百分比。
两车先后撞击、医学上无法分割：标「足以 / 不足」待核，转介 `评估因果关系与既往伤病`，不直接写全额连带。原因力序位转介 `评估过错与原因力`。事故认定书上的「共同导致 / 同等 / 主次」不得升格为已核验的第一千一百六十八条或第一千一百七十一条。
交强险限额内先行与侵权人连带或按份不是同一层，转入 `评估道路交通事故责任与保险先行` 和 `评估责任主体与保险覆盖`。

## 节点 4　禁令与追偿接口

若 if 角色是未尽安保义务的场所，then 形态为相应补充，转介 `评估场所安全保障义务`，本任务不得改写成与第三人连带。
教育机构因校外人员或同学致害：相应补充，转介 `评估教育机构责任`。
物业未采取必要措施防止抛物坠落：相应补充或相应责任，可能加害人给予适当补偿，均不是连带。检索锚点：民法典第一千二百五十四条；法释〔2024〕12 号第二十四条、第二十五条（物业补充在就具体侵权人财产强制执行后仍不能履行的范围内等，条号运行时核验）。本窗只标禁令接口，不写物业终稿。
用人者对外是替代责任，不是共同侵权，除非另有共同实施事实。工作人员不当然对外连带。禁止写成单位与员工各一半。转介 `评估用人者责任`。
产品生产者与销售者：不真正连带路径转介 `评估产品致人损害`，不得写成第一千一百六十八条。

追偿：检索锚点民法典第一百七十八条。对外连带清偿后对内追偿条件单列。难以确定责任大小时平均分担须核验，仍禁止写死 50%。不在本任务制作追偿起诉状。补充义务人对第三人追偿、用人者对工作人员追偿分列接口，不合成一行。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过专项分流直接给全体连带。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密且未获冲突豁免，then 整体停止，不得选边治愈。
若 if 用户提出编造被告、伪造在场名单、把未入镜路人列为共同危险被告、隐匿覆盖监控、伪造伤情或隐匿既往，then 整体停止；第一次提出即停。
若 if 日期、送达或动态规则未核验，then 期限字段停止，不编造唯一截止日，不选定法院。
若 if 金额或份额参数不足，then 该行标未知或 `待核`，禁止写零或各 50% 冒充已核定。

口头转述、截图和「已读」不得写成已受理或共同实施已证明。事故认定书、调解记录不得单独写成民事连带终局。判断状态只许三值。禁止胜诉率。

## 本任务回链纪律

本任务成果是「对外责任形态比较表」。不包含：场所安保终稿、用人者替代终稿、高空抛物补偿、侵权人不明查明、保险分账、唯一内部分担判决、起诉状。禁止把补充写成连带；禁止把用人者替代写成共同侵权；禁止把全体业主或可能加害人写成第一千一百七十条。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接。
风险档 A：不可逆文书或期限字段必须单独标可逆性。
