# 评估共同侵权与连带按份

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成「对外责任形态比较表」：共同实施、教唆帮助、共同危险、分别侵权足以或不足、补充或补偿禁令、追偿接口。不把补充、补偿或用人者替代写成连带。不输出唯一内部分担百分比。不替代场所、用人者、高空抛物、侵权人不明或保险分账终稿。

`depends-on` 为空。接受等价事实、认定书、监控和证据清单。

## 工作边界

正触发：需要单独判断数人对同一损害的对外形态（共同实施、教唆帮助、共同危险、分别侵权足以或不足）。己方或对方主张均可。用户要唯一内部分担百分比或要把补充改写成连带，仍正触发，该格字段停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要总体责任总图（转 `评估人身侵权责任`）；
- 只要场所对第三人的补充责任终稿且无需 1168–1172 比较（转 `评估场所安全保障义务`）；
- 只要教育机构责任终稿（转 `评估教育机构责任`）；
- 只要用人者替代责任且无共同实施事实（转 `评估用人者责任`）；
- 只要高空抛物可能加害人补偿终稿（转 `评估物件脱落坠落与高空抛物`）；
- 只要侵权人不明查明路径（转 `评估侵权人不明路径`）；
- 只要交强险或多车保险分账（转 `评估道路交通事故责任与保险先行`）；
- 只要工伤与第三人分账（转 `评估工伤与第三人侵权竞合`）；
- 只要打架、防卫终稿（转 `评估打架伤害民事路径`）；
- 只要过错原因力终稿（转 `评估过错与原因力`）；
- 只要起诉状（转 `提起人身损害一审`）。

编造被告、伪造在场名单或指导隐匿监控：整体停止，不走负触发。

本任务不选定法院，不写唯一截止日，不代提交追偿状或起诉状，不给胜诉率。

## 建立工作坐标

确认：使用者与授权；单方立场；各行为人行为时间空间；有无针对同一被侵权人的共同实施；教唆帮助事实；各行为是否足以造成全部损害；场所、用人者、保险人是否同时入局；法域。口头「他们一起的」不得写成共同实施已证明。

同时掌握双方秘密或未解利益冲突：`整体停止`，不得以选边治愈，也不得改走负触发去出连带或业主共同危险。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料；`R#` 认定书或机关文书；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 形态行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。对外形态只用 `连带` / `按份` / `待核` / `不打开`。补充、相应责任、补偿、替代只作禁令或转介，不得写入连带格。禁止唯一百分比。技能正文中的条号是检索锚点，不是已核验 `L#`。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验共同实施、教唆帮助、共同危险、分别侵权足以或不足、连带追偿等将被写入 `L#` 的现行规则；补充、补偿、替代条文只核验不得改写连带。不可用则形态和禁令字段停止，且不得填各 50%。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变对外形态或共同危险免责的条文正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补意思联络证明、「足以」、共同危险免责口径的实务反例。

工具不可用时继续行为人编目。不得凭记忆写全体连带、直接结合即连带，或证明不是自己造成即免责。

## 判断节点

执行顺序和停止条件以 [连带按份方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 主体与行为编目

每人一行为时间线。场所、用人者、保险人、可能加害人单独标记。只有「他们一起的」则共同实施依据不足。

### 2. 共同实施、教唆帮助

不得仅因多人在场。互殴不等于当然共同实施侵害第三人。教唆帮助无或限制行为能力人不得与被教唆人写成连带。

### 3. 共同危险

行为人须为已实施危险行为的确定范围。免责须能够确定具体侵权人。禁止全体业主、可能加害人、不明逃逸。

### 4. 分别侵权足以或不足

各自足以：连带。不足以：按份。难以确定大小：平均规则待核。禁止唯一金额。

### 5. 禁令与追偿接口

补充、补偿、替代不得改写连带。追偿只留接口，不写追偿状，不填内部分担百分比。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；编造被告或伪造在场名单；指导把未入镜路人列为共同危险被告；隐匿、覆盖监控；伪造伤情。整体停止优先于负触发。第一次提出即停，不以「坚持」为门槛。
- `字段停止`：意思联络、足以造成全部损害、共同危险免责、平均分担规则未核验；用户要唯一百分比的数字格；用户要把补充改写连带的连带格。
- `目标停止`：主目标变为场所、用人者、高空抛物、侵权人不明、保险分账、打架路径或起诉状终稿。

禁止指导伪造在场名单或违法取证。不给胜诉率。
