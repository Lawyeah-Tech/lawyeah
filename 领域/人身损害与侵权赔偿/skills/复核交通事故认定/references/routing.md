# 边界与路由

## 正触发

对事故认定书的事实或责任不服，需要复核。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 民事保险分账 | `评估道路交通事故责任与保险先行` |
| 行政诉讼 | 行政领域 |
| 期限已过只要民事抗辩 | 本任务仅证明力节，不生成复核稿 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 对公安的行政诉讼 | 行政领域 |
| 交通肇事刑事 | 刑事领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“认定书说我全责，要复核”正触发。“不用复核，直接打民事”走交通专项或应诉。“告交警队”转行政。
