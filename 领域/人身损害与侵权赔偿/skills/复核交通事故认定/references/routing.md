# 边界与路由

## 正触发

对道路交通事故认定书或事故证明的事实、证据、适用法律、责任划分或程序不服，需要准备复核或书面异议包。复核期已过、送达不明、已起诉、用户要必须改责仍正触发：提交稿或改责格停止，窗口不关。仅对赔偿金额不服仍正触发，复核申请格不支持，转民事。工伤与第三人机动车同时出现，仍正触发：工伤段分流，复核袋可留。停车场或道路以外争能否按道路认定程序复核，仍可正触发，受理条件待核。

双方秘密、伪造痕迹、改监控、倒签送达的停止，优先于负触发。不得改走负触发去出复核稿。过期只要民事抗辩不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 交强险或商业险分账 | `评估道路交通事故责任与保险先行` |
| 过错百分比或三七开终稿 | `评估过错与原因力` |
| 行政诉讼状告公安或交警队 | 行政领域；本窗不写行政起诉状 |
| 交通肇事辩护或定罪 | `分流刑民交叉`／刑事；复核袋可留则留 |
| 管辖连结点图或异议书 | `评估人身损害管辖`／`提出人身案件管辖异议` |
| 起诉状或实体答辩 | `提起人身损害一审`／`应对人身损害一审` |
| 监控保全步骤终稿 | `保全现场监控与电子证据` |
| 不是道路交通事故认定或事故证明且不要复核该文书 | 负触发 |

过期只要民事抗辩 **不是** 负触发。复核不是行政复议替代。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 仅工伤待遇且无道路认定不服 | 劳动领域 |
| 对公安的行政诉讼 | 行政领域 |
| 海事专门程序 | 海事领域 |
| 指导伪造痕迹或改监控 | 整体停止；刑事只打红旗，不得用来出策略 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。第三人道路认定复核袋可留。交通肇事不定罪、不写刑辩。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 分账、限额 | `评估道路交通事故责任与保险先行` |
| 过错形态与比例 | `评估过错与原因力` |
| 主体与保险 | `评估责任主体与保险覆盖` |
| 易失监控 | `保全现场监控与电子证据`／`准备监控保存通知` |
| 起诉或应诉 | `提起人身损害一审`／`应对人身损害一审` |
| 工伤与第三人 | `评估工伤与第三人侵权竞合` |
| 刑民交叉 | `分流刑民交叉` |
| 救助基金 | `申请道路救助基金或垫付` |
| 时效 | `评估人身损害诉讼时效`；不与复核三日混算 |

## 易混

「认定书说我全责，要复核」正触发。「不用复核，直接打民事」走交通专项、过错或应诉；若同时要复核则本窗可留。「告交警队」转行政，本窗不写状。「微信已读就算送达，按三日写死截止，必须改成三七开」仍正触发；已读不得起算，截止日停止，改责格不支持。「过期了还能不能打民事」仍正触发；提交稿停止，证明力节保留。「两边材料都给你，刹车痕不够就改一改」整体停止。
