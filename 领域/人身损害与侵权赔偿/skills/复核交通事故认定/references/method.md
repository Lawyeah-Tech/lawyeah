# 认定复核方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。期限状态只用 `待核`、`情景`、`停止`。稿件状态只用 `草案`、`发送前待核`、`停止`。禁止胜诉率、必然改责、唯一责任百分比、选定唯一复核机关、唯一截止日未核验仍写入。未知金额不写零。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文、已失效《合同法》、2009 年《道路交通事故处理程序规定》把简易程序或道路以外一律排除复核、把诉讼受理写成必然不予受理，或把认定书写成民事终局、把已读写成送达时记为噪声。

`K#` 固定列：`文书名称｜受送达人｜作出日｜送达日｜送达方式｜效力凭证｜程序类型（简易/一般，待核）｜起算事件｜期间长度待核｜待核截止｜稿件状态`。一受送达人一卡。驾驶人、所有人、保险人不得共用一张卡。

`Rev#` 固定列：`编号｜请求类型（事实/证据/适用法律/责任划分/程序）｜认定书记载｜材料表面冲突｜判断｜待核｜稿件是否可写入`。一行一点。

## 节点 0　分流、立场、禁止与不关窗

整案转出只交付第 1、2、10 节，不交复核稿、截止日或改责方案。

| 信号 | 处理 |
| --- | --- |
| 只要交强险或商业险分账 | 负触发 `评估道路交通事故责任与保险先行` |
| 只要过错百分比或三七开终稿 | 负触发 `评估过错与原因力` |
| 只要行政诉讼状告公安或交警队 | 负触发转行政；本窗不写行政起诉状 |
| 只要交通肇事辩护或定罪 | 负触发 `分流刑民交叉`／刑事；复核袋可留则留，本窗不定罪 |
| 只要管辖或异议书 | 负触发 `评估人身损害管辖`／`提出人身案件管辖异议` |
| 只要起诉状或实体答辩 | 负触发 `提起人身损害一审`／`应对人身损害一审` |
| 只要监控保全步骤终稿 | 负触发 `保全现场监控与电子证据` |
| 主轴仅工伤待遇且无道路认定不服 | 整案转劳动；夹带第三人机动车认定不服则本窗正触发，工伤段分流，复核袋可留并转介 `评估工伤与第三人侵权竞合` |
| 海事专门程序 | 转海事 |
| 未成争改合同 | 审查起草搁置 |

「认定书即民事终局」「必须改责」「已读起算」「过期关窗」**不关窗**。过期仍正触发。仅金额不服仍正触发。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或保险人与驾驶人冲突未解且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出伪造刹车痕迹、顶包改认定、改监控、倒签送达、威胁或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　期限闸 `K#`

检索锚点：《道路交通事故处理程序规定》（公安部令第146号，2018年5月1日施行）第七十一条：当事人对道路交通事故认定或者出具道路交通事故证明有异议的，可以自认定书或证明**送达之日起三日内**提出书面复核申请；逾期不予受理；同一事故的复核以一次为限。条号和「三日」不是已核验 `L#`。未核验则截止日停止，不得编唯一数字截止日。

起算事件是送达日，不是作出日、交警口头告知日、微信已读、截图、邮件打开。送达不明：期限字段停止。用户口述「后天截止」只登记 `S#`。

一般程序：向上一级公安机关交通管理部门书面复核；机关名称待核，不编造。简易程序与一般程序分卡待核；不得把 2009 年旧规定「简易一律不得复核」写入 `L#`。

期间已过：提交稿停止，窗口不关；第 7 节民事证明力必须保留。复核不是民事起诉前置；复核期内仍可起诉。一方已向人民法院提起诉讼并经受理：复核命运待核（现行规定常见为告知法院，2009 年「必然终止/不予受理」是噪声），第 6 节不得在未核验时当作有效提交。

## 节点 2　复核范围 `Rev#`

打开：事实是否清楚、证据是否确实充分、适用法律是否正确、责任划分是否公正、调查及认定程序是否合法。仅对赔偿金额不服或调解不成：复核申请 `不打开`，该格 `现有依据不支持`，窗口不关，转分账、测算或起诉。不得请求复核机关直接判决民事赔偿或指定民事百分比。新证据必须说明为何未在调查中提交。不利事实不得从草稿删除。用户要「必须改成次责或三七开」：该格 `现有依据不支持` 或字段停止，窗口不关。

## 节点 3　证据对照与民事证明力

指出认定书与监控、行车记录仪、痕迹、证人材料表面冲突，并列登记。不确定的测速或刹车分析不作鉴定替代。不得因对方控制推定材料存在或内容有利。易失监控转介 `保全现场监控与电子证据`／`准备监控保存通知`，本窗不写保全终稿。

检索锚点：道路交通事故损害赔偿解释关于认定书证明力的条款（条号运行时核验）。人民法院应依法审查并确认相应证明力，有相反证据可以推翻。不得写成民事终局比例，也不得写「认定书毫无用处」。主责、次责、同等、全部责任不得自动映射三七开、二八开。复核维持不等于民事终局。交警「全部责任」不得直接写成民法典第一千二百一十七条的故意或重大过失。

## 节点 4　申请草稿与邻接拆分

草稿栏目：申请人、认定书或证明文号、复核请求、理由、主要证据、受理机关（上一级或作出机关，待核）。状态 `草案` 或 `发送前待核`。不代提交，不得写成已提交。过期、送达不明、起诉后终止未核验：本节 `停止`。禁止预填民事百分比或行政起诉请求。复核不是行政复议申请书。

告交警队：转行政，不附行政起诉状。交通肇事：只打红旗，转 `分流刑民交叉`，不写辩护词。分账、过错、管辖、起诉状、答辩、救助基金只点名转介。不打开则填 `不打开`。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过期限闸直接给可提交终稿或改责承诺。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if C 端只要大众准备包，then 只分流不回改。

判断状态只许三值。口头转述、截图和「已读」不得写成已受理、已送达或期限已起算。

## 本任务回链纪律

本任务成果是「认定复核期限卡、复核点与不代提交草稿」。不包含：分账终稿、过错百分比、行政诉讼状、刑事辩护、管辖异议、起诉状、实体答辩、监控保全终稿、必改责保证。禁止认定书即民事终局。禁止已读起算。禁止过期关窗。禁止选边治愈。禁止伪造痕迹。
