# 输出合同

按触发结果选择交付形状。期限闸未开或过期不得交付可提交复核终稿。禁止把认定书写成民事终局比例。禁止主次责自动映射三七开。禁止已读、作出日起算。禁止过期关窗。禁止必须改责保证。禁止仅金额不服仍出复核终稿。禁止选边治愈。禁止伪造痕迹或改监控步骤。不代提交。不选定唯一复核机关。不写行政诉讼状。不定残。不保证复核改变责任。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出 | 第 1、2、10 节。禁止复核稿、截止日、改责方案。第三人车祸复核袋可留时不得因工伤整案转出 |
| 整体停止 | 第 1、10 节。禁止草稿、选边、改认定步骤。双方秘密、顶包、伪造痕迹、倒签送达第一次即停，无「坚持」门槛 |
| 期间已过（不关窗） | 十节表头可出现；第 6 节提交稿 `停止`；第 3 节只交逾期风险；第 7 节民事证明力必须在；不得改走负触发关窗 |
| 送达不明或条文未核验 | 窗口仍开；第 3 节截止日停止；第 6 节不得写成可提交 |
| 已起诉、复核是否终止未核验 | 十节表头在；终止效果待核；第 6 节停止或标明不得在终止未核时当作有效提交 |
| 用户要必须改责、认定书即民事终局或已读起算（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；成果不得标 `已形成` |
| 正触发且可形成复核包 | 下列十节表头均出现；仅金额不服则第 4 节 `不打开`；未核验格填待核；禁止为填满而宣布必改责或民事三七开 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。双方秘密未解不得进入「部分形成」。每个 `K#`/`Rev#` 必须带来源和判断三值。`L#` 不得直接抄技能内条号。已读起算、认定书即终局、2009 简易一律不得复核若返回则记噪声。稿件状态默认 `草案` 或 `发送前待核`。

## 1. 触发、单方立场、授权与成果状态

谁不服哪份认定书或事故证明。期限闸是否打开。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。

## 2. 来源登记与 MCP 调用表

认定书文号、送达回证、电子送达到达记录分列。口头全责、已读截图只登记 `S#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 期限卡 `K#`

作出日与送达日分列。已读、发送成功、口头告知不得起算。简易与一般分卡。不与三年诉讼时效混算。过期只停提交稿。用户口述唯一截止日则截止日停止。

## 4. 复核请求范围 `Rev#`

事实、证据、适用法律、责任划分、程序分列。仅赔偿金额 `不打开`。不得请求机关直接判决民事赔偿。不得把必须改成无责或三七开写成请求结论。

## 5. 证据对照

认定书记载与监控、行车记录仪、痕迹、证人表面冲突并列。不确定的测速、刹车分析不作鉴定替代。新证据须说明未在调查中提交的原因。不利事实不得删。

## 6. 申请草稿

申请人、文号、复核请求、理由、主要证据、受理机关（待核，不编造）。草案，不代提交。过期、送达不明、已起诉终止未核验：本节 `停止`。禁止预填民事百分比或行政起诉请求。不是行政复议申请书。

## 7. 民事证明力提示

认定书、复核结论只作 `R#`。人民法院依法审查，相反证据可以推翻。复核维持不等于民事终局。复核不是起诉前置。主次责不得映射三七开。本窗不写分账表、过错百分比终稿。

## 8. 邻接拆分

告交警队：转行政，不附行政起诉状。交通肇事：只打红旗。分账、过错、管辖、起诉状、答辩只点名转介。不打开则填 `不打开`。

## 9. 下一步

按期限灭失、易失证据、改变请求抗辩、可逆性排序。只转介：分账、过错、主体保险、监控保全、起诉或应诉、工伤竞合、救助基金、刑民分流。不写那些终稿。不选定法院。

## 10. 缺口、停止项与提示

须列对方最强解释：认定书即民事终局、必须改责否则不能起诉、已读即送达、作出日起算、过期关窗或不能再打民事、仅金额也可复核、选边即可继续、口述截止日必须写入、顶包改认定就能过。本成果不是已提交复核申请、不是民事终局比例、不是分账、不是起诉状或行政状。不保证复核改变责任。
