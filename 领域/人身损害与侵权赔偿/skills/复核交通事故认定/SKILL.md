# 复核交通事故认定

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成不代提交的认定复核包：`K#` 期限卡、`Rev#` 复核点、证据对照、复核申请草稿、民事证明力提示。不重写交警结论为民事终局比例。不定唯一责任百分比。不写分账、过错百分比终稿、行政诉讼状、刑事辩护或起诉状。不代提交。不保证复核改变责任。

`depends-on` 为空。分账转 `评估道路交通事故责任与保险先行`。过错百分比转 `评估过错与原因力`。告交警队转行政领域。民事起诉转 `提起人身损害一审`。

## 工作边界

正触发：对道路交通事故认定书或道路交通事故证明的事实、证据、适用法律、责任划分或调查认定程序不服，需要准备复核或书面异议包。复核期已过、送达不明、已起诉、用户要「必须改责」仍正触发：提交稿或改责格停止，窗口不关。仅对赔偿金额不服仍正触发：复核申请格 `现有依据不支持`，转民事，窗口不关。工伤与第三人机动车同时出现：本窗正触发，工伤段分流劳动，复核袋可留。停车场或道路以外争的是能否按道路认定程序复核：仍可正触发，受理条件待核。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要交强险或商业险分账（转 `评估道路交通事故责任与保险先行`）；
- 只要过错百分比或三七开终稿（转 `评估过错与原因力`）；
- 只要行政诉讼状告公安或交警队（转行政领域，本窗不写行政起诉状）；
- 只要交通肇事辩护或定罪（转 `分流刑民交叉`／刑事领域，复核袋可留则留）；
- 只要管辖或异议书（转 `评估人身损害管辖`／`提出人身案件管辖异议`）；
- 只要起诉状或实体答辩（转 `提起人身损害一审`／`应对人身损害一审`）；
- 只要监控保全步骤终稿（转 `保全现场监控与电子证据`）；
- 不是道路交通事故认定或事故证明，且不要复核该文书。

过期只要民事抗辩 **不是** 负触发。复核不是行政诉讼，也不是行政复议的替代。

## 建立工作坐标

确认：使用者与授权；单方立场；认定书或事故证明文号；作出日与送达日分列；送达方式与效力凭证；简易程序或一般程序；不服要点；新证据；是否已起诉；法域。

口头转述、截图、「已读」不得写成已送达。作出日不得代替送达日。用户口述唯一截止日或「立刻交到某支队」只登记 `S#`，不得写入期限卡或选定唯一复核机关。

同时掌握双方秘密，或保险人与驾驶人共同委托而利益冲突未解：`整体停止`，不得以选边治愈，也不得改走负触发去出复核稿。提出伪造刹车痕迹、顶包改认定、隐匿或改监控、倒签送达：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 认定书、监控、痕迹；`R#` 送达凭证、复核结论；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`K#` 期限卡；`Rev#` 复核点；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。期限状态只用 `待核`、`情景`、`停止`。稿件状态只用 `草案`、`发送前待核`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：认定书或事故证明送达之日起提出书面复核；一般程序向上一级公安机关交通管理部门；复核范围含事实、证据、适用法律、责任划分、调查及认定程序；仅对赔偿金额不服不是复核对象；同一事故复核以一次为限。技能正文「三日」不是 `L#`。噪声：2009年旧规定把简易程序或道路以外一律排除复核、把诉讼受理写成必然不予受理或必然终止、已失效《侵权责任法》、把认定书写成民事终局、把已读写成送达。不可用则期限、机关、范围、简易能否复核、起诉后复核命运字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变起算、受理或终止的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补已读不等于送达、简易与一般分列、起诉后复核告知或终止、认定书民事证明力非终局的实务反例。
- `search_template` 只借复核申请栏目，不预填上一级机关、不把范本当现行法或已提交文本。

工具不可用时继续编目认定书与送达事实；截止日和法律结论字段停止。不得凭记忆写死三日截止或选定唯一复核机关。

## 判断节点

执行顺序和停止条件以 [认定复核方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、禁止与不关窗

工伤三段分流，道路复核袋可留。双方秘密或伪造痕迹第一次停。错误主张不关窗。

### 2. 期限闸 `K#`

自送达日起算。已读、作出日不得起算。过期不关窗，提交稿停止。简易与一般分卡待核。

### 3. 复核范围 `Rev#`

事实、证据、适用法律、责任划分、程序。仅金额不服不打开。不得请求机关直接判决民事赔偿。

### 4. 证据对照与民事证明力

冲突并列。认定书不是民事终局，也不是毫无用处。主次责不得映射三七开。

### 5. 申请草稿与邻接拆分

草案，不代提交。过期或送达不明则稿件停止。行政诉讼不写状。交通肇事只打红旗。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；保险人与驾驶人冲突未解；提出伪造刹车痕迹、顶包改认定、改监控、倒签送达或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：送达日不明、电子送达无到达凭证、复核期限或范围未核验、简易程序能否复核未核验、起诉后复核命运未核验。过期则提交稿停止，窗口不关。用户要必须改责、认定书即民事终局或已读起算则该格停止，窗口不关。
- `目标停止`：主目标变为分账、过错百分比终稿、行政诉讼状、刑事辩护、管辖异议、起诉状或实体答辩。必须改责不在目标停止。

禁止指导伪造痕迹、改监控或倒签送达。不代提交。不给胜诉率。不保证复核改变责任。不选定唯一复核机关。不定残。
