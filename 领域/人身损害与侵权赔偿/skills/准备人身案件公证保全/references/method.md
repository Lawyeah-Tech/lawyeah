# 公证准备方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。稿件状态只用 `草案`、`办理闸关闭`、`提交前待核`、`停止`。禁止采信率、必然采信、唯一截止日、选定唯一公证处或法院、自行宣布伤残等级。未知金额不写零。本任务不代办理、不代预约、不代到场。公证不等于鉴定，不等于法院保全裁定。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、把公证书写成不可推翻、把公证写成鉴定或法院保全裁定、把送达过程写成已到达、把预先打开页面写成已固定、把今晚办完写成法定截止时记为噪声，不得写入 `L#`。禁止指导倒签、对未发生过程作假或预先打开不明页面冒充现场。

`Not#` 固定列：`编号｜分型（送达过程公证／网页现状／邮件／聊天／现场物体；伤残等级、死因、产品质量、法律结论填不打开）｜待证事实（仅过程或现状）｜对象（猜测标S#）｜控制方｜合法进入或账号归属｜操作约束（公证员监督下操作；不得预先打开不明页面、改时间戳）｜材料｜询问提纲（含不利问题）｜鉴定分流｜与法院保全（不互斥，不写申请终稿）｜到达效果（送达公证≠已到达）｜证明力（可被反证）｜公证处程序待核（费用、是否必须本人到场，不选唯一）｜状态｜转介（只点技能名）｜来源回链`。一行一事项。禁止合成「网页聊天现场函件一律公证」。

## 节点 0　分流、立场、办理闸与不关窗

整案转出或闸关闭只交付第 1、2、10 节，不交办理前终稿、应当采信或唯一公证处。闸部分打开时：仅对已特定的过程或现状行给出草案，伤残、法律结论行标 `不打开`。

| 信号 | 处理 |
| --- | --- |
| 只要伤残鉴定材料包 | 负触发 `准备伤残鉴定材料`；用户夹带现场或发送过程时本窗过程/现状行可留 |
| 只要法院保全申请书 | 负触发 `准备财产或证据保全申请`；公证与法院保全不互斥，本窗不写申请终稿 |
| 尚未决定是否保全 | 负触发 `评估证据或财产保全必要性` |
| 只要保存通知正文 | 负触发 `准备监控保存通知` |
| 只要现场合法固定步骤 | 负触发 `保全现场监控与电子证据` |
| 只要调查令终稿 | 负触发 `申请人身案件调查令或取证` |
| 只要送达渠道专项、不办公证 | 负触发 `设计人身案件通知送达` |
| 只要索赔通知正文 | 负触发 `准备侵权索赔通知` |
| 只要建卷矩阵 | 负触发 `建立人身损害证据案卷` |
| 只要赋强公证或执行证书 | 负触发 `办理人身和解执行力补强` |
| 病历封存或医疗鉴定主轴 | 转医疗；场所或第三人侵权现状可留 |
| 工程款工期质量造价 | 转建设工程；工地人身现场或网页现状**不得**因「现场资料」误转 |
| 主轴仅工伤认定、劳鉴或待遇，且无第三人送达或现状 | 整案转劳动；夹带对第三人发送过程或现场现状则本窗正触发，工伤段分流，`Not#` 可留并转介 `评估工伤与第三人侵权竞合` |
| 海事专门程序 | 转海事 |
| 未成争只要改合同 | 审查起草本窗搁置 |

办理闸打开条件（对某一行，同时满足）：单方无冲突立场与授权；主成果是公证事项、材料与询问提纲；对象可特定为已发生或可当场操作的发送过程或现场／网页／聊天现状；原件、现场或账号有最小可办公证线索；网页／邮件／聊天尚未在公证员监督外打开不明页面。

闸关闭（仍正触发）：对象、地点、账号无线索；现场已无法合法进入且无己方账号；目的是「证明十级」「保证采信」「今晚必须办完」而无最小对象。「今晚必须办完」「保证采信」本身不得开闸写成应当出证。

「用公证代替鉴定」「法律结论背书」「保证采信」「选定唯一公证处」「今晚办完」**不关窗**。闸未开则仍只交 1、2、10 节。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或受害人与场所、相对人同时交材料争同一份公证事项且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出倒签、对未发生过程作假、预先打开不明页面或改时间戳冒充现场、侵入或收买后送公证、伪造过程，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　事项定性

送达过程公证：固定发送行为与现场记录，不证函件内容真实，不对时效中断或已到达作承诺。检索锚点：送达过程与意思表示到达分列；微信已读、发送成功不得单独写成已到达。到达与中断转 `设计人身案件通知送达`／`评估人身损害诉讼时效`／`准备侵权索赔通知`。

保全证据公证：现场坑洞、网页宣传、邮箱原文、聊天界面现状。待证事实仅过程或现状。伤残等级、死因、产品缺陷、参与度、过错比例、对方应当赔偿：该行 `不打开` 或 `现有依据不支持`，转介鉴定或责任评估，窗口不关。

公证机构不得为不真实、不合法的事项出具公证书。事项不真实、不合法不予办理。条号不是 `L#`。

## 节点 2　材料清单与操作提纲

身份证件、现场地址、原始载体。账号密码由本人在公证员监督下输入。不得让公证员使用申请人预先打开的不明页面。网页、邮件、聊天须在公证员监督下从清机或公证处设备操作。电子数据操作步骤写入提纲。预先打开、改时间戳后再让公证员「看见」：第一次整体停止，不提供补救作假步骤。

不能因对方控制推定监控存在或内容有利。对方控制行只登记控制方、时段线索，转介保存通知、调查令或法院保全必要性，本窗不写进入机房步骤。

---

## 节点 3　询问提纲与证明力

询问须含不利问题：时间、地点、对象、如何发现、是否原件、页面是否事先打开、账号是否本人。避免公证后被指隐瞒。

检索锚点：经过法定程序公证证明的法律事实和文书，人民法院应当作为认定事实的根据，但有相反证据足以推翻的除外。电子数据的内容经公证机关公证的，人民法院应当确认其真实性，但有相反证据足以推翻的除外。不得把「可以确认」五种情形套到公证电子数据条款上，也不得把「应当确认」写成不可推翻。不保证采信。不保证胜诉。不代替鉴定。

---

## 节点 4　公证处程序与邻接拆分

费用、是否必须由当事人到场，以该公证处规则为准，待核。不得写成全国统一必须到场或统一收费。公证处连结点并列，申请书不得预填「此致某公证处」。不代预约、不代办理、不编公证书编号。

公证与法院证据保全不互斥。失败升级只点转介名：`评估证据或财产保全必要性`、`准备财产或证据保全申请`、`申请人身案件调查令或取证`、`保全现场监控与电子证据`、`准备监控保存通知`。本窗不写那些终稿，不得写成「公证失败后才允许法院保全」。

草稿状态 `草案` 或 `提交前待核`。不代办理。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过办理闸直接给可办理终稿或应当采信。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if C 端只要大众准备包，then 只分流不回改。

判断状态只许三值。口头转述、截图和「已读」不得写成已公证、已到达、已保全或期限已起算。事故认定书不得单独写成民事终局并据此必须公证。

## 本任务回链纪律

本任务成果是「不代办理的送达过程或现状保全公证准备」。不包含：鉴定终稿、法院保全申请、保存函、现场步骤、调查令、送达专项、索赔正文、建卷、赋强。禁止代替鉴定。禁止保证采信。禁止选定唯一公证处。禁止倒签。禁止预先打开冒充现场。禁止选边治愈。禁止把送达过程写成已到达。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标办理终稿已形成。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接。
风险档 A：不可逆公证过程或作假字段必须单独标可逆性。
