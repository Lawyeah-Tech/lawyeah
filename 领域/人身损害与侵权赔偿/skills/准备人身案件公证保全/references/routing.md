# 边界与路由

## 正触发

需要公证处固定发送过程或现场、网页、聊天现状。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 伤残鉴定 | `准备伤残鉴定材料` |
| 法院保全 | `准备财产或证据保全申请` |
| 送达渠道设计不办公证 | `设计人身案件通知送达` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 医疗病历封存公证主轴 | 医疗医药领域 |
| 工程造价 | 建设工程领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“把发函过程和坑拍下来公证”正触发。“公证说我构成九级”不代替鉴定。“直接法院保全”走保全申请。
