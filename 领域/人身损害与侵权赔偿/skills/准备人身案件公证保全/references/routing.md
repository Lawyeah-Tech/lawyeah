# 边界与路由

## 正触发

需要公证处固定发送过程或现场、网页、聊天现状。不知对象、用户要公证证明十级伤残、保证法院采信、选定某公证处或今晚办完仍正触发：办理闸可关，对应格停止，窗口不关。工伤待遇与对第三人送达过程或现场现状同时出现，仍正触发：工伤段分流劳动，对第三人 `Not#` 可留。工地人身现场或网页现状公证仍正触发，不得因工地关键词转工程。

双方秘密、同时交材料、倒签、对未发生过程作假、预先打开不明页面冒充现场的停止，优先于负触发。不得改走负触发去出提纲。代替鉴定、保证采信不在下表。倒签作假不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 伤残鉴定材料包 | `准备伤残鉴定材料` |
| 法院保全申请书 | `准备财产或证据保全申请` |
| 尚未决定是否保全 | `评估证据或财产保全必要性` |
| 保存通知正文 | `准备监控保存通知` |
| 现场合法固定步骤 | `保全现场监控与电子证据` |
| 调查令或法院取证申请终稿 | `申请人身案件调查令或取证` |
| 送达渠道专项、不办公证实施 | `设计人身案件通知送达` |
| 索赔通知正文 | `准备侵权索赔通知` |
| 建卷矩阵 | `建立人身损害证据案卷` |
| 赋强公证或执行证书 | `办理人身和解执行力补强` |
| 病历封存或医疗鉴定主轴 | 医疗医药领域；侵权现状可留 |
| 工程造价主轴 | 建设工程领域 |
| C 端只要大众准备包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「让公证员倒签昨天已送达」「对还没发的函假装公证发送」不在本表，走整体停止。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 仅工伤待遇且无第三人送达或现状 | 劳动领域 |
| 病历封存或医疗鉴定终稿 | 医疗医药领域；场所或第三人侵权现状可留 |
| 海事专门程序 | 海事领域 |
| 指导倒签或对未发生过程作假 | 整体停止 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。对第三人送达过程或现场现状可留。

## 易混

「把发函过程和坑拍下来公证」正触发。「公证说我构成九级并保证法院采信，就去某公证处今晚办完」仍正触发；伤残、采信、唯一公证处、今晚办完各格不支持；过程或现状行可留。「直接法院保全」走保全申请，本窗不写申请终稿，二者不互斥。「我把页面先打开等公证员来看」若用于冒充现场第一次整体停止；操作提纲须写公证员监督下由本人打开。「工伤也要认，对肇事方的催告还要公证发送过程」正触发，送达过程行可留，工伤段分流。「工地坑洞要公证，顺便造价资料」人身现场可留，造价转工程。「两边材料都给你，选边写公证提纲」整体停止。
