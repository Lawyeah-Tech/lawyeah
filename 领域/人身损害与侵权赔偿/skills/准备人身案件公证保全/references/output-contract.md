# 输出合同

按触发结果选择交付形状。办理闸未打开不得交付办理前终稿。禁止保证采信或采信率。禁止选定唯一公证处或唯一法院。禁止写死今晚必须办完。禁止把公证写成鉴定意见或伤残等级。禁止把送达过程写成已到达。禁止把公证写成法院保全裁定。禁止把预先打开页面写成已固定。禁止选边治愈。禁止倒签或对未发生过程作假。不代预约。不代办理。不定残。不保证采信。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 办理闸关闭或节点 0 整案转出 | 第 1、2、10 节：关闭理由和最小补证。禁止办理终稿、应当采信、唯一公证处。对第三人送达或现状可留时不得因工伤或工地整案转出 |
| 整体停止 | 第 1、10 节。禁止 `Not#`、询问提纲、选边、倒签或作假步骤。双方秘密、同时交材料、倒签、对未发生过程作假、预先打开不明页面冒充现场第一次即停，优先于负触发；无选边治愈，无「坚持」门槛 |
| 用户要代替鉴定、保证采信、唯一公证处或今晚办完（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；闸未开则仍只交 1、2、10；不得改走负触发关窗；成果不得标办理终稿 `已形成` 为十级已证或法院必采信 |
| 正触发且闸开（可部分开） | 下列十节表头均出现；公证范围、证明力、费用未核验的单元格填 `依据不足，无法形成结论` 或 `待核`；送达与现状分列；禁止为填满而宣布应当采信、选定唯一公证处或预填已到达 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入办理终稿已形成。双方秘密未解不得进入「部分形成」。每个 `Not#` 必须带来源和三值判断。`L#` 不得直接抄技能内条号。保证采信、公证等于鉴定、送达过程等于已到达若返回则记噪声。稿件状态默认 `草案`。

## 1. 触发、单方立场、授权与成果状态

办理闸开、部分开或关。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。稿件默认 `草案`。不代办理。

## 2. 来源登记与 MCP 调用表

`S/D/L/I/G/Not/V`。口述一定采信、已经打开、某公证处今晚办完只登记 `S#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 办理闸与事项分型

送达过程与现状保全分表。伤残、法律结论不打开。不知对象则闸关闭。

## 4. 材料清单与操作约束

原件、现场、账号。本人在公证员监督下操作。禁止预先打开不明页面。电子数据步骤写入提纲。

## 5. 询问提纲

含不利问题。时间、地点、对象、如何发现、是否原件、页面是否事先打开。

## 6. 证明力提示

可被反证。电子数据经公证应当确认真实性，仍可推翻。不代替鉴定。不保证采信。送达过程不等于已到达。

## 7. 公证处程序待核

费用、是否必须本人到场待核。连结点并列。不选定唯一公证处。不代预约。

## 8. 与法院保全、调查令、保存函的关系

不互斥。只点转介名。公证≠裁定≠调查令≠保存函。不得写成公证失败才允许法院保全。

## 9. 下一步

不代办理。转介鉴定、保全、调查令、保存函、送达设计或索赔通知只点名。不选定法院或公证处。

## 10. 缺口、停止项与提示

须列对方最强解释：公证构成十级、保证法院采信、公证书不可推翻、送达过程就是已到达、已读单独中断时效、公证等于法院保全、选定某公证处今晚必须办完、预先打开就算固定、选边即可继续、倒签昨天已发。

本成果不是公证书、不是鉴定意见、不是法院保全、不是调查令、不是已到达、不保证采信、不是唯一截止日。不代办理。
