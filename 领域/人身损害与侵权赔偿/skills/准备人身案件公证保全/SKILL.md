# 准备人身案件公证保全

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成不代办理的公证准备包：办理闸、`Not#` 送达过程公证与保全证据公证分表、材料清单、操作与询问提纲、证明力提示。公证证明过程或现状，不代替伤残、死因、产品缺陷或参与度鉴定。不等于法院证据保全裁定，二者不互斥。不等于调查令、保存函或现场自助步骤。公证书可被相反证据推翻。电子数据内容经公证的，人民法院应当确认其真实性，但仍可被反证。送达过程公证不等于意思表示已到达，已读不得单独到达。不保证采信。不选定唯一公证处。网页、邮件、聊天须在公证员监督下操作。

`depends-on` 为空。伤残鉴定转 `准备伤残鉴定材料`。法院保全转 `评估证据或财产保全必要性`／`准备财产或证据保全申请`。保存函转 `准备监控保存通知`。现场步骤转 `保全现场监控与电子证据`。调查令转 `申请人身案件调查令或取证`。只要送达渠道不办公证转 `设计人身案件通知送达`。索赔正文转 `准备侵权索赔通知`。赋强公证转 `办理人身和解执行力补强`。

## 工作边界

正触发：需要公证处固定发送过程或现场、网页、聊天现状。不知对象、用户要「公证构成十级」「保证法院采信」「选定某公证处」「今晚必须办完」「用公证代替鉴定」仍正触发：办理闸可关，对应格填 `现有依据不支持` 或字段停止，窗口不关。工伤待遇与对第三人送达过程或现场现状同时出现：本窗正触发，工伤段分流劳动，对第三人的 `Not#` 可留。工地人身现场或网页现状公证正触发，不得因「工地／造价资料」误转建设工程。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要伤残鉴定材料包（转 `准备伤残鉴定材料`）；
- 只要法院保全申请书（转 `准备财产或证据保全申请`）；
- 尚未决定是否保全（转 `评估证据或财产保全必要性`）；
- 只要保存通知正文（转 `准备监控保存通知`）；
- 只要现场合法固定步骤（转 `保全现场监控与电子证据`）；
- 只要调查令或法院取证申请终稿（转 `申请人身案件调查令或取证`）；
- 只要送达渠道专项、不办公证实施（转 `设计人身案件通知送达`）；
- 只要索赔通知正文（转 `准备侵权索赔通知`）；
- 只要建卷矩阵（转 `建立人身损害证据案卷`）；
- 只要赋强公证或执行证书（转 `办理人身和解执行力补强`）；
- 病历封存或医疗鉴定主轴（转医疗；场所或第三人侵权现状可留）；
- 工程款、工期、质量、造价主轴（转建设工程）；
- C 端只要大众准备包（只分流）；
- 未成争改合同（审查起草搁置）。

代替鉴定、保证采信、选定唯一公证处、今晚办完**不在负触发表**，窗口不关。倒签、对未发生过程作假、双方秘密、预先打开不明页面冒充现场**不在负触发表**，走整体停止。

## 建立工作坐标

确认：使用者与授权；单方立场；公证目的（送达过程或现状保全）；对象；原件、现场或账号线索；页面是否已在公证员监督外打开；法域。

口头「法院一定采信」「我已经打开了」「就去某公证处今晚办完」只登记 `S#`。不得预填唯一公证处，不得写成已公证或必然采信。

同时掌握双方秘密，或受害人与场所、相对人同时交材料争同一份公证事项：`整体停止`，不得以选边治愈，也不得改走负触发去出一方提纲。受害人已开口且委托范围就是公证准备、且未掌握对方秘密时，可推定申请方立场。只要同时掌握双方秘密，无例外整体停止。提出倒签、对未发生发送或打开过程作假、预先打开不明页面或改时间戳后再让公证员「看见」、侵入或收买后送公证：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 拟公证对象、原件、账号；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Not#` 事项；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。稿件状态只用 `草案`、`办理闸关闭`、`提交前待核`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。不准许率。本任务默认 `草案`，不代办理、不代预约、不代到场。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：保全证据属于公证事项；公证机构不得为不真实、不合法的事项出具公证书；经过法定程序公证证明的法律事实和文书，人民法院应当作为认定事实的根据，但有相反证据足以推翻的除外；电子数据的内容经公证机关公证的，人民法院应当确认其真实性，但仍可被反证。技能正文条号不是 `L#`。噪声：已失效《侵权责任法》、公证构成十级伤残、保证法院采信、公证书不可推翻、选定唯一公证处、今晚必须办完即法定截止、公证等于鉴定或法院保全裁定、送达过程等于已到达、预先打开页面等于已固定。不可用则公证范围、证明力、程序效力字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变公证范围、真实性推定或可反证效果的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补公证可被反证、不代替鉴定、预先打开页面被质疑、送达公证只证过程不对时效中断作承诺、公证处受理范围地区差异、不保证今晚办完的实务反例。
- `search_template` 只借公证申请栏目，不把范本当法定格式、已受理文本或指定唯一公证处。

工具不可用时继续 `Not#` 事项、材料与询问提纲编目；公证范围、证明力、程序效力字段停止。不得凭记忆写应当采信、唯一公证处或伤残等级。

## 判断节点

执行顺序和停止条件以 [公证准备方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、办理闸与不关窗

工伤三段分流，对第三人送达或现状可留。工地人身可留。双方秘密或倒签第一次停。代替鉴定、保证采信不关窗。

### 2. 事项定性 `Not#`

送达过程与现状保全分表。伤残、死因、产品缺陷、法律结论不打开。送达过程不等于已到达。

### 3. 材料清单与操作提纲

原件、账号由本人在公证员监督下输入。禁止预先打开不明页面。电子数据步骤写入提纲。

### 4. 询问提纲与证明力

含不利问题。可被反证。不代替鉴定。不等于法院保全。不保证采信。

### 5. 公证处程序与邻接拆分

费用、是否必须本人到场待核。不选定唯一公证处。不代预约。保全、调查令、保存函、鉴定只点转介名。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；受害人与场所同时交材料；提出倒签、对未发生过程作假、预先打开不明页面或改时间戳冒充现场、侵入或收买后送公证、伪造过程。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：公证事项是否属于公证范围、证明力规则、费用或到场规则未核验。用户要代替鉴定、保证采信、唯一公证处或今晚办完则该格停止，窗口不关。闸未开仍不出办理终稿。
- `目标停止`：主目标变为鉴定终稿、法院保全申请、保存函、现场步骤、调查令、送达专项、索赔正文、建卷或赋强终稿。代替鉴定、保证采信不在目标停止。

禁止指导倒签或作假。不给采信率。不选定公证处或法院。不代办理。不编唯一截止日。不把送达过程写成已到达。
