# 评估后续治疗费另行主张

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的权利人立场下，形成“另行主张条件、与前案既判力、鉴定接口”。不把未知后续费写成已发生零。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算、鉴定和证据清单。

## 工作边界

正触发：已一次性赔偿或判决后，仍需后续手术或康复，需要判断能否另行主张。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 前案尚未处理且只要把后续费写入本次测算（转测算原子）；
- 只要另诉状终稿（转 `准备后续治疗费另诉`）；
- 把未知后续费写成已发生零。

未知后续费不得写零。本任务评估条件，不制作另诉状。

## 建立工作坐标

确认：使用者与授权；权利人立场；前案文书或协议；是否保留后续治疗权利；目前医疗建议；新发生费用票据；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 前案文书、协议、新病历；`R#` 判决调解；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 后续行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验人身损害赔偿解释关于后续治疗费和既判力相关程序规则。不虚构案件系统。

工具不可用时继续事实、主体、程序文书状态和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [后续治疗评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　前案或协议范围

读判决主文、调解书、和解协议弃权条款。

### 节点 2　费用性质

已发生、必然发生、可能发生三档。

### 节点 3　既判力与重复主张

前案已判并执行的同一笔不得再要。

### 节点 4　鉴定接口

后续手术必要性、时点、费用合理性。

### 节点 5　输出纪律

未知不写零。不制作另诉状。

## 停止与安全

- `整体停止`：立场不明；用户坚持把尚未发生的手术费写成已经票据化。
- `字段停止`：既判力范围、后续治疗费条件未核验。
- `目标停止`：主目标变为另诉状终稿或把未知写成零。
