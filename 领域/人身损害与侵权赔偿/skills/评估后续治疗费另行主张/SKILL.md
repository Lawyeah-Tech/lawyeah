# 评估后续治疗费另行主张

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的权利人或抗辩方立场下，形成 `Q#` 后续治疗费行：前案文书范围；弃权或保留；费用三档（已发生 / 医疗证明或鉴定结论确定必然发生可一并 / 其余待实际发生后另行主张）；既判力与新事实待核；鉴定接口；时效红旗。不把未知或未发生写成已发生零。不编造必然发生必得额。不写另诉状。不写唯一截止日。不写鉴定委托终稿。不把解释第十九条继续给付当成后续治疗费闭集。不核定工伤待遇。

`depends-on` 为空。分项数字转 `测算人身损害赔偿`。另诉草稿转 `准备后续治疗费另诉`。概括弃权文本转 `审查保险一次性了结弃权`。时效展开转 `评估人身损害诉讼时效`。与原损害因果转 `评估因果关系与既往伤病`。工伤待遇转劳动，第三人侵权民事段转介 `评估工伤与第三人侵权竞合`。

## 工作边界

正触发：需要判断后续治疗费属已发生、必然发生可一并，还是待实际发生后另行主张；或前案、调解、和解、保险了结后能否再主张。权利人、抗辩方或保险人单方提问均可。用户要「未知写零」「无证明编必然发生必得」「已经判过绝对不能再告」「概括弃权当然阻断」仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关。工伤旧伤复发待遇与第三人侵权民事后续治疗同时出现：本窗正触发，工伤段分流劳动，民事三档与既判力可留。不要求必须已经一次性赔偿才能进窗；测算窗把「另诉条件」转来时仍正触发。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要分项测算数字或把后续费估进本次总表（转 `测算人身损害赔偿`）；
- 只要另诉状或发送版文书终稿（转 `准备后续治疗费另诉`）；
- 只要概括弃权或保险一次性了结文本审查终稿（转 `审查保险一次性了结弃权`）；
- 只要和解可签档（转 `谈判人身损害和解`）；
- 只要护理、辅助器具或残疾赔偿金年限届满后的继续给付终稿（解释第十九条接口，不是本窗）；
- 只要紧急医疗费先予执行申请（转 `申请先予执行医疗费`）；
- 主轴仅是工伤旧伤复发待遇，且无第三人侵权民事后续治疗（转劳动）；
- 只要起诉状（转 `提起人身损害一审` 或 `准备后续治疗费另诉`）；
- C 端只要大众准备包（只分流）；
- 未成争改合同（审查起草搁置）。

「把未知写成零」不在负触发表。

## 建立工作坐标

确认：使用者与授权；单方立场（权利人侧或抗辩方侧，不得同时代表互争同一笔后续费的双方）；前案判决主文、调解书、和解或保险了结文本；弃权或保留条款；新病历与医嘱；新票据；是否已执行同一笔；是否机动车或工伤夹带；法域。

口头「医生说以后要二次手术」「已经判过不能再告」只登记 `S#`。微信「已读」截图不得写成判决已生效或已执行。

同时掌握双方秘密，或受害人与侵权人、保险人同时交材料争同一笔后续治疗费：`整体停止`，不得以选边治愈，也不得改走负触发去出可主张意见或拒赔稿。提出伪造未发生手术票据、把未发生写成已发生、倒签病历或保留条款：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 新病历、医嘱、票据、鉴定分列；`R#` 判决主文、调解书、和解或保险了结、执行回执；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 后续治疗费行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。接口状态只用 `打开`、`不打开`、`待核`。技能正文中的条号是检索锚点，不是已核验 `L#`。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：法释〔2022〕14 号第六条第二款三档；民法典第一千一百七十九条医疗费口径；既判力与后诉新事实规则（民诉法及民诉解释相关条号运行时核验）。时效另起算只核红旗。解释第十九条继续给付只核分流，不得写入本窗后续治疗结论。技能正文条号不是 `L#`。噪声：已失效《侵权责任法》、2003 年解释已删除条文（含旧医疗费条号串到现行第六条）、把第十九条五年至十年写成后续治疗费必得延长、把可能发生写成已发生零、把概括弃权写成当然消灭。不可用则另主张开闭、既判力、弃权效力字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变三档、既判力开闭或弃权效果的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补无鉴定不得编必然发生、概括弃权不是当然阻断、主文已判不等于新发生不能另主张、工伤旧伤复发待遇不等于第三人民事消灭的实务反例。
- `search_case_by_fact` 只比较二次手术、内固定取出、康复、概括弃权后再主张的差异与翻转条件，不写成必须另诉或必须驳回。

工具不可用时继续编目前案文书、弃权条款、新病历与票据；法律效果字段停止。不得凭记忆写零、必得额、当然阻断或必须另诉。

## 判断节点

执行顺序和停止条件以 [后续治疗评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场与不关窗

仅工伤待遇且无第三人转劳动。第十九条继续给付不是本窗。错误主张不关窗。双方秘密或伪造票据提出即停。

### 2. 前案文书与弃权或保留

主文、调解、和解、了结分列。概括弃权不是当然阻断。不指导倒签反悔。

### 3. 费用三档

已发生须票据与因果。必然发生须医疗证明或鉴定结论。其余待实际发生后另行主张。未知不写零。

### 4. 既判力与重复主张

同一已发生项目已判并执行，该格通常不支持再要。新发生或未纳入主文的必然发生分列待核。「已经判过绝对不能再告」不关窗。

### 5. 鉴定、时效与邻接

鉴定只标接口。时效只打红旗。第十九条、工伤、测算、另诉只分流。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；受害人与侵权人或保险人同时交材料；提出伪造未发生票据、把未发生写成已发生、倒签病历或保留条款。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：既判力范围、第六条三档、弃权效力、时效规则未核验。用户要写零、编造必然发生必得、绝对不能再告或弃权当然阻断则该格停止，窗口不关。
- `目标停止`：主目标变为测算终稿、另诉状、弃权审查终稿、时效截止日、鉴定委托、第十九条继续给付或工伤待遇核定。写零不在目标停止。

禁止指导伪造票据或倒签反悔。不给胜诉率。不选定法院。不宣布伤残等级。不保证必得总额。不代提交。不写另诉状。
