# 边界与路由

## 正触发

已一次性赔偿或判决后，仍需后续手术或康复，需要判断能否另行主张。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 本次一并测算后续费 | `测算人身损害赔偿` |
| 另诉状终稿 | `准备后续治疗费另诉` |
| 保险了结弃权审查 | `审查保险一次性了结弃权` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 后续治疗中的新诊疗过错 | 医疗医药领域 |
| 工伤旧伤复发待遇 | 劳动领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“当时判了，现在又要二次手术”正触发。“还没起诉，把后续手术也估进去”走测算。“帮我写另诉状”走另诉原子。
