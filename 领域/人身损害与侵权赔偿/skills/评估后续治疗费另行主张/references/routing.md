# 边界与路由

## 正触发

需要判断后续治疗费属已发生、必然发生可一并，还是待实际发生后另行主张；或前案、调解、和解、保险了结后能否再主张。权利人、抗辩方或保险人单方提问均可。用户要「未知写零」「无证明编必然发生必得」「已经判过绝对不能再告」「概括弃权当然阻断」仍正触发。工伤旧伤复发待遇与第三人侵权民事后续治疗同时出现，仍正触发：工伤段分流劳动，民事段留本窗。测算窗把「另诉条件」转来，仍正触发。

双方秘密、受害人与保险人同时交材料、伪造未发生票据或倒签的停止，优先于负触发。不得改走负触发去出可主张意见、拒赔稿或写零。写零不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 分项测算数字或把后续费估进本次总表 | `测算人身损害赔偿` |
| 另诉状或发送版文书终稿 | `准备后续治疗费另诉` |
| 概括弃权或保险一次性了结文本审查终稿 | `审查保险一次性了结弃权` |
| 和解可签档 | `谈判人身损害和解` |
| 护理、辅助器具或残疾金年限届满继续给付终稿 | 解释第十九条接口，不是本窗 |
| 紧急医疗费先予执行申请 | `申请先予执行医疗费` |
| 仅工伤旧伤复发待遇，且无第三人民事后续治疗 | 劳动领域 |
| 起诉状 | `提起人身损害一审` / `准备后续治疗费另诉` |
| C 端只要大众准备包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「把未知写成零」不在本表。工伤夹带第三人侵权民事后续治疗时，不得因「旧伤复发」整窗关闭。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 仅工伤待遇且无第三人民事后续费 | 劳动领域 |
| 医疗损害鉴定终稿 | 医疗医药领域；民事后续费可留 |
| 海事专门程序 | 海事领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

「当时判了，现在又要二次手术」正触发。「还没起诉，把后续手术也估进去」走测算；若问的是另诉条件则本窗正触发，金额转测算。「帮我写另诉状」走另诉原子。「后续治疗费先填零」正触发，写零格不支持。「医生口头说还要开刀，先报三万必得」正触发，必然发生格不支持或待核。「已经判过绝对不能再告」正触发，既判力格待核或对该笔不支持。「签过今后一切费用不再要，所以当然没了」正触发，当然阻断格不支持或待核。「护理到期再要五年」不是本窗，走解释第十九条接口。「工伤旧伤复发，能不能找肇事方要取内固定」正触发，民事段留本窗。「两边材料都给你，代表保险人打掉二次手术」整体停止，不得选边。「没做的手术先开张票」第一次提出即整体停止。
