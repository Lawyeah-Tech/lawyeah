# 输出合同

按触发结果选择交付形状。禁止未知或未发生写成已发生零。禁止无医疗证明或鉴定编造必然发生必得额。禁止「已经判过」整窗关闭。禁止概括弃权当然阻断。禁止把解释第十九条继续给付写成后续治疗费闭集。禁止选边治愈。禁止伪造票据或倒签方案。禁止测算数字、另诉状、弃权审查终稿、时效截止日、鉴定委托、工伤待遇核定、起诉状。不定残。不选定法院。不代提交。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出（仅工伤待遇且无第三人民事后续费；医疗鉴定终稿；海事；第十九条继续给付主轴；未成争改合同） | 第 1、2、10 节。禁止三档表和既判力开闭。第三人侵权民事段可留时不得整案转出 |
| 整体停止 | 第 1、10 节。禁止可主张意见、拒赔稿、倒签反悔步骤。双方秘密、受害人与保险人同时交材料、伪造未发生票据时，整体停止优先于负触发；第一次提出即停，无选边治愈，无「坚持」门槛 |
| 用户要「未知写零」或「编造必然发生必得」或「已判绝对不能再告」或「概括弃权当然阻断」（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；不得改走负触发关窗；成果不得标 `已形成` |
| 正触发且可评估 | 下列十节表头均出现；三档、既判力、弃权效力未核验的单元格填 `依据不足，无法形成结论` 或 `待核`；禁止为填满而宣布可另诉、必得额或已过时效 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。双方秘密未解不得进入「部分形成」。每个 `Q#` 必须带来源、主张人、三档和判断三值。`L#` 不得直接抄技能内条号。2003 年解释已删除条文、第十九条当后续治疗闭集若返回则记噪声。

## 1. 触发、单方立场、授权与成果状态

冲突是否存在。双方秘密未解或受害人与保险人同时交材料不得进入「部分形成」。不得写「澄清代表哪一方后继续」。

## 2. 来源登记与 MCP 调用表

前案主文、调解、和解或了结、新病历、新票据、鉴定分列。口述二次手术、已经判过只登记 `S#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 前案文书范围

判决主文项目、调解协议、和解或保险了结覆盖范围逐项可见。未提交前案则既判力字段停止，不推定没判过或都判过。截图已读不得写成已生效或已执行。

## 4. 弃权或保留

明确保留后续治疗 → 闸可打开或待核。概括放弃「今后一切费用」标阻断风险，转介弃权审查，本窗不指导倒签反悔，也不得写成请求已消灭。「当然阻断」格填不支持或待核。

## 5. 费用三档

已发生：票据 + 与原损害因果。必然发生：须医疗证明或鉴定结论。其余待实际发生后另行主张。未知不写零。禁止口述升格。禁止合成一笔「还能要」。

## 6. 既判力与重复主张

同一已发生项目已判并执行：该格通常不支持再要。新发生、未纳入主文的必然发生、明确保留、新鉴定是否新事实：分列待核。「已经判过绝对不能再告」不关窗。不写另诉状。不选定法院。

## 7. 鉴定接口

必要性、与原伤因果、费用合理性只标接口。不预测费用。不写委托终稿。不定残。

## 8. 时效红旗与第十九条分流

后续费可能另起算，只打红旗，禁止唯一截止日。超过护理、辅助器具或残疾金年限的继续给付转解释第十九条接口，不是本窗后续治疗费行。工伤旧伤复发待遇转劳动，第三人民事可留。保险弃权只分流。

## 9. 下一步

转介测算（情景金额）、另诉窗、弃权审查、鉴定材料、时效表、工伤竞合、起诉。不选定法院。不代提交。不写诉状。

## 10. 缺口、停止项与提示

须列对方最强解释（未知应写零、无鉴定也可报必然发生、已判绝对不能再告、概括弃权当然阻断、第十九条就是后续治疗、工伤待遇已覆盖所以民事不能要、选边即可继续）与证据缺口。

未知不写零。本成果不是测算、不是另诉状、不是弃权审查终稿、不是时效裁定、不是鉴定委托、不是继续给付判决、不是诉状。
