# 后续治疗评估方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。接口状态只用 `打开`、`不打开`、`待核`。禁止胜诉率、必然责任比例、唯一必得总额、选定法院、自行宣布伤残等级、唯一截止日。未知金额不写零。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文（含旧医疗费条号串到现行第六条）、已失效《合同法》、把法释〔2022〕14 号第十九条继续给付写成后续治疗费另诉闭集或五至十年必得延长、把可能发生写成已发生零、把概括弃权写成当然消灭时记为噪声，不得写入 `L#`。禁止口述医嘱升格必然发生。禁止「已经判过」整窗关闭。

`Q#` 固定列：`编号｜主张或抗辩方｜前案文书（判决主文/调解/和解/保险了结/无）｜弃权或保留（明确保留/概括放弃今后一切/未触及/待核）｜费用三档（已发生/必然发生/其余另行主张）｜表面材料（票据/医疗证明或鉴定/仅口述）｜既判力（打开/不打开/待核）｜鉴定接口｜时效红旗｜邻接分流｜判断｜待核`。一行一个费用主张。禁止合成「后续费一共还能要」或「二次手术依法 N 万」。

## 节点 0　分流、立场与不关窗

整案转出只交付第 1、2、10 节。

| 信号 | 处理 |
| --- | --- |
| 只要分项测算数字或把后续费估进本次总表 | 负触发 `测算人身损害赔偿` |
| 只要另诉状或发送版文书 | 负触发 `准备后续治疗费另诉` |
| 只要弃权或保险了结文本审查终稿 | 负触发 `审查保险一次性了结弃权` |
| 只要护理、辅助器具或残疾金年限届满继续给付终稿 | 负触发说明走解释第十九条接口，不是本窗 |
| 只要先予执行医疗费申请 | 负触发 `申请先予执行医疗费` |
| 主轴仅工伤旧伤复发待遇，且无第三人侵权民事后续治疗 | 整案转劳动；夹带第三人只分流，民事三档与既判力可留并转介 `评估工伤与第三人侵权竞合` |
| 诊疗过错、病历真实性或医疗损害鉴定终稿 | 转医疗；民事后续费与原损害因果可留 |
| 海事专门程序 | 转海事 |
| 未成争只要改合同 | 审查起草本窗搁置 |

「未知写零」「编造必然发生必得」「已经判过绝对不能再告」「概括弃权当然阻断」**不关窗**。

本窗**永不**出具测算数字、另诉状、弃权效力终稿、时效截止日、鉴定委托、第十九条继续给付方案或起诉状。用户同时要测算或另诉：本窗 `Q#` 与邻窗并行，本窗金额不得已核实。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或受害人与侵权人、保险人同时交材料争同一笔后续费且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出伪造未发生手术票据、把未发生写成已发生、倒签病历或保留条款、威胁或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　前案文书与弃权或保留

前案材料分列：判决主文项目、调解书、和解协议、保险一次性了结、执行回执。未提交不得推定「没判过」或「都判过」。口头「已读」、截图不得写成已生效或已执行。

| 条款形态 | 本窗 | 禁止写法 |
| --- | --- | --- |
| 明确保留后续治疗费 | 另行主张闸可 `打开` 或 `待核` | 保留条款单独打开既判力闸并保证可诉 |
| 概括放弃「今后一切费用」 | 标阻断风险，效力待核，转 `审查保险一次性了结弃权` | 当然消灭全部后续治疗请求；指导倒签反悔或伪造保留条款 |
| 未触及后续治疗 | 既判力格对照主文项目，待核 | 写成已覆盖或已放弃 |
| 治疗尚未相对稳定即概括弃权 | 标高风险，转谈判/弃权审查；本窗不建议签署 | 本窗修订可签弃权 |

用户要「概括弃权当然阻断」：该格 `现有依据不支持` 或待核，窗口不关。本窗不写弃权效力终稿，不指导倒签反悔。

## 节点 2　费用三档

检索锚点：法释〔2022〕14 号第六条第二款。医疗费按照一审法庭辩论终结前实际发生的数额确定；器官功能恢复训练所必要的康复费、适当的整容费以及其他后续治疗费，赔偿权利人可以待实际发生后另行起诉；根据医疗证明或者鉴定结论确定必然发生的费用，可以与已经发生的医疗费一并予以赔偿。条号不是 `L#`。

| 档 | 最低表面 | 禁止写法 |
| --- | --- | --- |
| 已发生 | 可回链票据 + 与原损害因果；必要性合理性由权利人举证表面，赔偿义务人异议承担相应举证责任（第六条第一款只打红旗，不是倒置闭集） | 无票据写已发生；未知写零；把未发生做成已开票 |
| 必然发生可一并 | 医疗**证明**或鉴定结论可回链；禁止口述「医生说还要二次手术」、微信医嘱、门诊主诉升格 | 无证明编一笔必得额；把必然发生写成必须另诉 |
| 其余待实际发生后另行主张 | 未发生金额标未知 | 写零冒充已发生；因现在估不出而关窗 |

金额展开转 `测算人身损害赔偿`，本窗不得已核实。用户要写零或编造必然发生必得：该格 `现有依据不支持` 或字段停止，窗口不关。

与原损害因果、既往、参与度转 `评估因果关系与既往伤病`，本窗只标接口。

## 节点 3　既判力与重复主张

前案已判并执行的**同一笔已发生费用**再要：该格通常 `现有依据不支持`。裁判时尚未发生、亦非当时可确定的必然发生费用，是否构成新请求或新事实待核。检索锚点：民诉重复起诉与裁判生效后发生新事实再次起诉的规则，条号运行时核验。禁止凭记忆写唯一再审入口或唯一另诉法院。

抗辩「已经判过不能再告」不关窗：只填既判力格 `待核` 或对该笔 `现有依据不支持`。新鉴定改变伤残是否构成新事实待核，禁止写成必须另诉或必须再审。另诉材料只标接口，转 `准备后续治疗费另诉`。无前案文书则既判力字段停止，不编造主文。

## 节点 4　鉴定、时效与邻接

鉴定必要性、时点、费用合理性只标接口。转 `准备伤残鉴定材料`；多份打架转 `评估伤残等级争议`。本窗不预测费用，不定残，不写鉴定委托书终稿。

后续费时效可能从实际发生之日起算，只标红旗，展开转 `评估人身损害诉讼时效`。禁止唯一截止日、剩余天数。事故日不得吞掉后续费时钟。

| 接口 | 本窗 | 转介 |
| --- | --- | --- |
| 分项金额 | 不得已核实 | `测算人身损害赔偿` |
| 另诉草稿 | 不写状 | `准备后续治疗费另诉` |
| 护理/辅助器具/残疾金年限届满继续给付 | 只打红旗，不是本窗闭集 | 解释第十九条接口；禁止写成五至十年必得延长，也禁止用第十九条否定第六条第二款 |
| 工伤旧伤复发待遇 | 转劳动 | `评估工伤与第三人侵权竞合`；第三人民事可留；医疗费禁止双领红旗 |
| 紧急已发生医疗费 | 与未发生后续费分列 | `申请先予执行医疗费` |
| 保险免责或了结 | 只分流 | `审查保险一次性了结弃权` / `应对保险拒赔减赔` |

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
