# 评估精神损害赔偿

## 任务目标

在明确、无利益冲突的单方立场下，形成 `Q#` 精神损害行：自然人人身权益是否受到侵害；严重精神损害是否成立（三值）；酌定因素只作待核清单，不输出唯一金额或可执行区间；交强险优先接口开闭（须提出、只改死亡伤残限额内排序、不增加限额、未投保无接口）；与残疾赔偿金、死亡赔偿金不替代、不吸收。不测算分项数字。不写交强险分账。不编死亡近亲属闭集。不写刑附民受理终稿。不代选违约或侵权路径。不代写起诉状。

`depends-on` 为空。金额情景转 `测算人身损害赔偿`。交强险分账转 `评估道路交通事故责任与保险先行`。死亡近亲属清单转 `评估死亡赔偿权利人与分配`。违约路径可主张性转 `选择人身损害违约侵权竞合路径`。刑附民开闭转 `评估刑附民与另行起诉`。工伤待遇转劳动，第三人侵权民事段转介 `评估工伤与第三人侵权竞合`。

## 工作边界

正触发：人身伤害已成争，需要单独判断是否构成严重精神损害，或是否在交强险死亡伤残限额内优先赔偿精神损害。权利人或抗辩方、保险人提问均可。用户要「必须 N 万」「十级惯例必得」「评残即当然成立」「无残即当然不成立」「优先等于加限额」「未提出也自动优先」仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关。工伤待遇与第三人侵权精神损害同时出现：本窗正触发，工伤段分流劳动，民事严重性与交强险优先可留。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要总测算表或分项必得总额（转 `测算人身损害赔偿`）；
- 只要交强险商业险分账或限额内必得额（转 `评估道路交通事故责任与保险先行`）；
- 只要死亡近亲属清单或分配终稿（转 `评估死亡赔偿权利人与分配`）；
- 只要刑附民或另行起诉开闭终稿（转 `评估刑附民与另行起诉`）；
- 只要违约与侵权择一比较表（转 `选择人身损害违约侵权竞合路径`）；
- 主轴仅是工伤认定、劳鉴或工伤待遇，且无第三人侵权民事精神损害（转劳动）；
- 仅具有人身意义的特定物受损、无人身伤害（说明不是本窗人身伤害主轴，不得写成「商业化」）；
- 仅肖像、名称等人格权商业化或侵权获利，无人身伤害（人格权路径）；
- 只要起诉状或发送版索赔通知（转 `提起人身损害一审` / `准备侵权索赔通知`）；
- C 端只要大众准备包（只分流）；
- 未成争改合同（审查起草搁置）。

「给一个必得数字」不在负触发表。

## 建立工作坐标

确认：使用者与授权；单方立场；受害人是自然人还是法人；伤害后果材料（伤残鉴定、死亡证明、毁容或外观、病历、心理咨询分列）；是否机动车事故及交强险是否已由被侵权人或近亲属**提出**优先赔精神损害；近亲属是否已列名（只标接口）；是否夹带工伤、刑事或违约路径；法域。

口头「很痛苦」「已经评残」「十级惯例五万」只登记 `S#`。心理咨询、自评量表、门诊主诉「抑郁／失眠」只登记 `D#`，不得写成医学诊断。

同时掌握双方秘密，或受害人与侵权人、保险人同时交材料争同一笔抚慰金或交强险优先：`整体停止`，不得以选边治愈，也不得改走负触发去出成立意见或拒赔稿。提出伪造精神疾病诊断、伪造伤残、隐瞒既往、倒签心理材料、裁剪病历：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 伤残、病历、心理咨询、门诊主诉分列；`R#` 死亡证明、起诉或保险索赔中是否已提出优先；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 精神损害行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。接口状态只用 `打开`、`不打开`、`待核`。技能正文中的条号是检索锚点，不是已核验 `L#`。

- `search_law` 核验将被写入 `L#` 的现行规则：民法典第一千一百八十三条；精神损害赔偿解释（2020 修正）酌定因素；法释〔2022〕14 号第二十三条；道交解释精神损害优先条款（2020 修正后常见为第十三条第二款，条号运行时核验）。刑诉解释第一百七十五条第二款只核验红旗，本窗不写受理终稿。技能正文条号不是 `L#`。噪声：已失效《侵权责任法》第二十二条、2001 年精神损害解释把残疾赔偿金或死亡赔偿金当作精神损害的旧口径、2003 年人身损害赔偿解释已删除条文、2010 年旅游纠纷规定第二十一条、把第九百九十四条顺位套到近亲属抚慰金、把交强险优先写成增加限额。不可用则成立效果、酌定法律效果、优先开闭字段停止。

- `search_practiced` 补未评残仍可能支持、轻微伤通常不足、伤残不是当然成立、地区酌定不是必得、优先须请求、工伤待遇不覆盖不等于民事消灭的实务反例。
- `search_case_by_fact` 只比较差异与翻转条件，不写成必须 N 万或必须优先加限额。

工具不可用时继续编目后果材料与是否已提出优先；法律效果字段停止。不得凭记忆写十级惯例必得、评残即成立或未提出自动优先。

## 判断节点

执行顺序和停止条件以 [精神损害方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场与不关窗

仅工伤待遇且无第三人转劳动。仅特定物或商业化无人身伤害转出。错误主张不关窗。双方秘密或伪造诊断提出即停。

### 2. 成立条件

自然人 + 人身权益 + 严重精神损害。谁主张谁举证。伤残不是唯一门槛，也不是当然成立。轻微擦伤通常依据不足，窗口不关。法人主张本条：该格不支持。心理咨询不是医学诊断。

### 3. 酌定因素

过错、手段场合、后果、获利、履行能力、受诉地生活水平只作待核因素。禁止唯一金额，禁止把区间写成可执行必得。

### 4. 交强险优先接口

须被侵权人或近亲属提出。只改死亡伤残限额内排序。不增加限额。未提出不得自动优先。未投保无此接口。本窗不分配数字。

### 5. 邻接接口

不替代残疾或死亡赔偿金。死亡权利人、刑附民、996、工伤第三人、测算、拒赔只标接口。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；受害人与侵权人或保险人同时交材料；提出伪造精神疾病诊断、伪造伤残、隐瞒既往、倒签心理材料。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：严重性标准、交强险优先规则、刑附民红旗未核验。用户要必得额、评残即成立、无残即不成立、优先加限额或未提出自动优先则该格停止，窗口不关。
- `目标停止`：主目标变为测算终稿、交强险分账、死亡清单、刑附民开闭终稿、996 择一表、起诉状或工伤待遇核定。必得额不在目标停止。

禁止指导伪造诊断。不给胜诉率。不选定法院。不宣布伤残等级。不保证必得总额。不代提交。
