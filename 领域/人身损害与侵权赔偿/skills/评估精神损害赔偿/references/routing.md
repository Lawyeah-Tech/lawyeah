# 边界与路由

## 正触发

需要单独判断是否构成严重精神损害，或是否在交强险中优先赔偿精神损害。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 总测算 | `测算人身损害赔偿` |
| 刑附民范围 | `评估刑附民与另行起诉` |
| 保险拒赔精神损害 | `应对保险拒赔减赔` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 医疗损害精神抚慰主轴鉴定 | 医疗医药领域 |
| 工伤无精神损害项目时的劳动待遇 | 劳动领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“能不能要精神抚慰金、交强险先赔这个”正触发。“把所有项目算出一个数”走测算。“附带民事能不能要精神损害”走刑附民。
