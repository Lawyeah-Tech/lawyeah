# 边界与路由

## 正触发

人身伤害已成争，需要单独判断是否构成严重精神损害，或是否在交强险死亡伤残限额内优先赔偿精神损害。权利人、抗辩方或保险人提问均可。用户要「必须 N 万」「十级惯例必得」「评残即当然成立」「无残即当然不成立」「优先等于加限额」「未提出也自动优先」仍正触发。工伤待遇与第三人侵权精神损害同时出现，仍正触发：工伤段分流劳动，民事段留本窗。

双方秘密、受害人与保险人同时交材料、伪造诊断或伤残的停止，优先于负触发。不得改走负触发去出成立意见、拒赔稿或必得额。必得额不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 总测算或分项必得总额 | `测算人身损害赔偿` |
| 交强险商业险分账或限额内必得 | `评估道路交通事故责任与保险先行` |
| 死亡近亲属清单或分配终稿 | `评估死亡赔偿权利人与分配` |
| 刑附民或另行起诉开闭终稿 | `评估刑附民与另行起诉` |
| 违约与侵权择一比较表 | `选择人身损害违约侵权竞合路径` |
| 仅工伤认定、劳鉴或待遇，且无第三人民事精神损害 | 劳动领域 |
| 仅 1183 第二款特定物、无人身伤害 | 说明不是本窗人身伤害主轴 |
| 仅肖像名称商业化或侵权获利，无人身伤害 | 人格权路径 |
| 起诉状 | `提起人身损害一审` |
| 发送版索赔通知 | `准备侵权索赔通知` |
| C 端只要大众准备包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「给一个必得数字」不在本表。工伤夹带第三人侵权民事精神损害时，不得因「工伤无此项目」整窗关闭。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 仅工伤待遇且无第三人民事精神损害 | 劳动领域 |
| 医疗损害鉴定终稿 | 医疗医药领域；民事抚慰金成立可留 |
| 海事死亡专门程序 | 海事领域 |
| 刑事被害人救济 | 刑事领域并行；本窗只打红旗，不写受理终稿 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 分项金额或情景抚慰金 | `测算人身损害赔偿` |
| 交强险分账、限额排序数字 | `评估道路交通事故责任与保险先行` |
| 死亡近亲属谁主张 | `评估死亡赔偿权利人与分配` |
| 刑附民或因犯罪的精神损失程序 | `评估刑附民与另行起诉` / `分流刑民交叉` |
| 违约路径可主张性 | `选择人身损害违约侵权竞合路径` |
| 工伤待遇与第三人分账 | `评估工伤与第三人侵权竞合`；待遇核定转劳动 |
| 保险免责不赔精神损害 | `应对保险拒赔减赔` |
| 索赔材料包 | `准备交强险商业险索赔材料` |
| 伤残意见打架或要异议稿 | `评估伤残等级争议` / `提出伤残鉴定异议或重新鉴定` |
| 原告列名 | `提起人身损害一审` |

## 易混

「能不能要精神抚慰金、交强险先赔这个」正触发。「把所有项目算出一个数」走测算。「附带民事能不能要精神损害」走刑附民；若同时问民事严重性则本窗正触发，程序开闭只打红旗。「评残了所以依法五万」正触发，必得额格不支持。「没评残就不能要」正触发，无残即不成立格不支持。「优先赔就能多要一层限额」正触发，加限额格不支持。「没跟保险公司说也先把精神损害排进去」正触发，未提出自动优先格不支持。「工伤没有这一项，能不能找肇事方要」正触发，民事段留本窗。「法人名誉也要抚慰金」正触发，成立格不支持。「两边材料都给你，代表保险人打掉抑郁诊断」整体停止，不得选边。「诊断可以找熟的医生补一份」第一次提出即整体停止。
