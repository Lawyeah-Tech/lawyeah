# 输出合同

按触发结果选择交付形状。禁止唯一抚慰金额。禁止把区间写成可执行必得。禁止评残即当然成立。禁止无残即当然不成立。禁止交强险优先增加限额。禁止未提出自动优先。禁止把残疾赔偿金或死亡赔偿金写成精神损害。禁止选边治愈。禁止伪造诊断方案。禁止测算数字、交强险分账、死亡清单、刑附民受理终稿、996 择一表、起诉状。不定残。不选定法院。不代提交。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出（仅工伤三段且无第三人民事；医疗鉴定终稿；海事；仅特定物无人身伤害；未成争改合同） | 第 1、2、10 节。禁止成立表、酌定区间和优先排序。第三人侵权民事段可留时不得整案转出 |
| 整体停止 | 第 1、10 节。禁止成立表、酌定区间、优先排序、诊断补证步骤。双方秘密、受害人与保险人同时交材料、伪造诊断或伤残时，整体停止优先于负触发；第一次提出即停，无选边治愈，无「坚持」门槛 |
| 用户要「必得额」或「评残即成立」或「无残即不成立」或「优先加限额」或「未提出自动优先」（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；不得改走负触发关窗；成果不得标 `已形成` |
| 正触发且可评估 | 下列十节表头均出现；严重性、优先规则未核验的单元格填 `依据不足，无法形成结论` 或 `待核`；禁止为填满而宣布成立、必得额或自动优先 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。双方秘密未解不得进入「部分形成」。每个 `Q#` 必须带来源、主张人和判断三值。`L#` 不得直接抄技能内条号。侵权责任法第二十二条、2001 解释旧残疾金口径、旅游纠纷规定第二十一条若返回则记噪声。

## 1. 触发、单方立场、授权与成果状态

冲突是否存在。双方秘密未解或受害人与保险人同时交材料不得进入「部分形成」。不得写「澄清代表哪一方后继续」。

## 2. 来源登记与 MCP 调用表

伤残、死亡、毁容、病历、心理咨询分列。口述金额、已评残、很痛苦只登记 `S#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 成立条件

自然人 + 人身权益 + 严重精神损害。法人该格不支持。伤残非唯一门槛亦非当然。轻微擦伤通常依据不足。心理咨询不是医学诊断。口头痛苦不得写入成立格。

## 4. 酌定因素

过错、手段场合、后果、获利、履行能力、受诉地生活水平只作待核因素。禁止唯一金额。禁止可执行区间。道歉不影响成立。

## 5. 交强险优先接口

须被侵权人或近亲属提出。未提出不得自动优先。只改死亡伤残限额内排序。不增加限额。未投保无此接口。本窗不分配数字。「优先＝加限额」格填不支持或待核。

## 6. 与残疾赔偿金、死亡赔偿金、护理误工

不替代、不吸收。金额展开转测算。禁止把两金写成精神损害。

## 7. 权利人与死亡近亲属接口

死亡案件谁主张只标接口，不编闭集。禁止用第九百九十四条顺位排除兄弟姐妹。口头「第一顺序独吞抚慰金」只登记 `S#`。

## 8. 刑附民、违约 996、工伤第三人

只分流。刑诉解释第一百七十五条第二款只打红旗，禁止写成必支持或必不受理。996 不代选。工伤待遇转劳动，第三人民事可留。

## 9. 下一步

转介测算（情景金额）、道交分账、保险索赔或拒赔、死亡权利人、刑附民、竞合、起诉。不选定法院。不定残。不代提交。不写诉状。

## 10. 缺口、停止项与提示

须列对方最强解释（唯一必得额、评残即成立、无残即不成立、优先加限额、未请求自动优先、法人有权、道歉消灭请求、精神金替代残疾金、工伤无此项目所以民事也不能要、刑附民一律可以或一律不行、选边即可继续）与证据缺口。

不编造抚慰金必得额。本成果不是测算、不是分账、不是死亡清单、不是刑附民裁定、不是诉状。
