# 精神损害方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。接口状态只用 `打开`、`不打开`、`待核`。禁止胜诉率、必然责任比例、唯一抚慰金额、可执行必得区间、选定法院、自行宣布伤残等级。未知金额不写零。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》第二十二条、2001 年精神损害赔偿解释把残疾赔偿金或死亡赔偿金当作精神损害的旧口径、2003 年人身损害赔偿解释已删除条文、2010 年旅游纠纷规定第二十一条、已失效《合同法》、把民法典第九百九十四条死者人格权顺位套到近亲属抚慰金资格，或把交强险优先写成增加限额时记为噪声，不得写入 `L#`。禁止把伤残写成成立的充分条件。禁止未提出写成自动优先。

`Q#` 固定列：`编号｜主张人｜损害后果表面（伤残/死亡/毁容/病历/心理咨询分列）｜严重性判断｜酌定因素（过错/手段场合/后果/获利/履行能力/受诉地生活水平，均待核）｜交强险优先（打开/不打开/待核｜是否已提出）｜与残疾或死亡赔偿金关系｜邻接分流｜待核`。一行一个主张人的一个请求。禁止合成「十级＝N 万」或「依法五万」。

## 节点 0　分流、立场与不关窗

整案转出只交付第 1、2、10 节。

| 信号 | 处理 |
| --- | --- |
| 只要测算或分项必得总额 | 负触发 `测算人身损害赔偿` |
| 只要交强险分账或限额内必得 | 负触发 `评估道路交通事故责任与保险先行` |
| 只要死亡近亲属清单 | 负触发 `评估死亡赔偿权利人与分配` |
| 只要刑附民开闭终稿 | 负触发 `评估刑附民与另行起诉` |
| 只要违约侵权择一表 | 负触发 `选择人身损害违约侵权竞合路径` |
| 主轴仅工伤认定、劳鉴或待遇，且无第三人侵权民事精神损害 | 整案转劳动；夹带第三人只分流，民事严重性与交强险优先可留并转介 `评估工伤与第三人侵权竞合` |
| 诊疗过错、病历真实性或医疗损害鉴定终稿 | 转医疗；民事抚慰金成立可留，鉴定段分流 |
| 海事死亡专门程序 | 转海事 |
| 仅 1183 第二款特定物、无人身伤害 | 负触发，说明不是本窗人身伤害主轴，不得写成「商业化」 |
| 仅肖像名称商业化或侵权获利，无人身伤害 | 负触发，人格权路径 |
| 未成争只要改合同 | 审查起草本窗搁置 |

「必须 N 万」「十级惯例必得」「评残即成立」「无残即不成立」「优先加限额」「未提出自动优先」**不关窗**。

本窗**永不**出具测算数字、交强险分账、死亡近亲属闭集、刑附民受理裁定意见、996 择一终稿或起诉状。用户同时要测算或分账：本窗 `Q#` 与邻窗并行，本窗金额不得已核实。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或受害人与侵权人、保险人同时交材料争同一笔抚慰金或交强险优先且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出伪造精神疾病诊断、伪造伤残、隐瞒既往、倒签心理材料、裁剪病历、威胁或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　成立条件

检索锚点：民法典第一千一百八十三条第一款。待证事实分列，谁主张谁举证：

| 待证 | 通常主张人 | 最低表面 | 禁止写法 |
| --- | --- | --- | --- |
| 侵害自然人人身权益 | 请求精神损害的一方 | 生命、身体、健康等材料可回链 | 法人主张本条；财产损失直接当人身权益 |
| 造成严重精神损害 | 同上 | 后果材料：死亡证明、伤残意见、毁容或外观病历、持续治疗线索；心理咨询只作表面 | 口头「很痛苦」写成已成立；门诊「抑郁／失眠」写成医学诊断；咨询记录升格精神疾病 |
| 与侵权行为的相当因果关系 | 同上 | 时间线与病历或鉴定对应 | 因对方控制材料推定有利 |

伤残鉴定证明的是残疾程度，**不是** 1183 的唯一门槛，也**不是**当然成立。死亡、严重毁容只标后果候选，仍须回链事实。无伤残 ≠ 必然不成立；有伤残 ≠ 必然成立。用户要「评残即成立」或「无残即不成立」：该格 `现有依据不支持` 或待核，窗口不关。

轻微擦伤、疼痛短暂就医、无严重后果材料：严重性格 `依据不足，无法形成结论` 或 `现有依据不支持`。用户仍要必得额：金额格不支持，窗口不关。

法人或非法人组织主张第一千一百八十三条精神损害：成立格 `现有依据不支持`。法人名誉等另标人格权接口，不关窗。

对方已书面道歉：不影响成立判断，最多进酌定因素待核，不得写成请求消灭。

单方心理鉴定、单方伤残意见 = `D#`，证明力待质证，本窗不得写成已核验严重后果。异议或重鉴转 `提出伤残鉴定异议或重新鉴定` / `评估伤残等级争议`。本窗不写重鉴开闭终稿，不定残。

## 节点 2　酌定因素

检索锚点：精神损害赔偿解释（2020 修正）酌定条款；法释〔2022〕14 号第二十三条。因素包括侵权人过错程度、目的方式场合、造成后果、获利情况、经济能力、受理诉讼法院所在地平均生活水平。全部待核。

禁止输出唯一金额。禁止把「可给区间」写成可执行必得额或已核实金额。禁止「十级惯例 N 万」「地区行情价」。参数不足则金额标未知，禁止写零。用户要唯一抚慰金或必得额：该格 `现有依据不支持` 或字段停止，窗口不关。数字情景转 `测算人身损害赔偿`，测算行不得已核实。

## 节点 3　交强险优先接口

检索锚点：道交解释关于精神损害优先的条款（2020 修正后常见为第十三条第二款，条号运行时核验）；人身伤亡范围含第一千一百七十九条和第一千一百八十三条各项损害（常见为第十一条，条号待核）。

| 条件 | 接口 |
| --- | --- |
| 机动车事故，已投保交强险，被侵权人或近亲属**已提出**优先赔偿精神损害 | `打开` 或规则未核验则 `待核`；只改变死亡伤残限额内排序 |
| 未提出 | 不得自动优先；接口 `不打开` 或 `待核` |
| 未投保或非机动车事故 | 无此接口 |
| 用户要「优先＝增加限额」或「优先覆盖全部精神损害」 | 该格 `现有依据不支持`，窗口不关 |

本窗不分配限额数字，不写分账表。分账转 `评估道路交通事故责任与保险先行`。保险免责声称不赔精神损害：转 `应对保险拒赔减赔`，本窗不写条款效力终稿。

## 节点 4　邻接接口

| 接口 | 本窗 | 转介 |
| --- | --- | --- |
| 分项金额、情景抚慰金 | 不得已核实 | `测算人身损害赔偿` |
| 交强险商业险分账 | 只标优先开闭 | `评估道路交通事故责任与保险先行` |
| 死亡近亲属谁主张 | 只标接口，不编闭集；禁止用第九百九十四条顺位完成资格或排除兄弟姐妹 | `评估死亡赔偿权利人与分配` |
| 刑附民或因犯罪另行起诉精神损失 | 只打红旗。检索锚点：刑诉解释第一百七十五条第二款「一般不予受理」。禁止写成必支持或必不受理终稿，也不得据此关闭纯民事 1183 扫描 | `评估刑附民与另行起诉` / `分流刑民交叉` |
| 违约路径精神损害可主张性 | 只标 996 接口，不代选路径；旅游纠纷规定第二十一条是噪声 | `选择人身损害违约侵权竞合路径` |
| 工伤待遇无精神损害项目 | 待遇转劳动；第三人侵权民事可留 | `评估工伤与第三人侵权竞合` |
| 护理、误工、残疾或死亡赔偿金 | 不替代、不吸收精神损害 | `测算人身损害赔偿` |
| 后续治疗另诉 | 不打开 | `评估后续治疗费另行主张` |

刑事被害人救济并行时专项段只分流，不把专项规则写入本任务结论。1183 第二款特定物与第一款人身伤害分列，不得与人格权商业化混行。
