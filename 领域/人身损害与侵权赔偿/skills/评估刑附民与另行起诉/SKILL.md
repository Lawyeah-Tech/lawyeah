# 评估刑附民与另行起诉

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的权利人立场下，形成刑附民与另行民事的路径比较包：选择闸、`Pth#`（刑附民／另行民事；保险或直接请求只红旗）、范围袋与主体袋分列、可并行与重复主张红旗、管辖时效红旗。不定罪。不默认起草附民状。不保证附民范围。不选定法院。不写死时效。被害人因犯罪行为遭受物质损失，可在刑事诉讼过程中提起附带民事诉讼；侦查、审查起诉期间也可向公安机关或检察院提出并随案移送。精神损害在附民中一般不予受理须运行时核验，不得写成附民当然能要或另行民事永远不能要。死亡赔偿金、残疾赔偿金与纯民事口径可能不同，必须分列待核。保险人、场所、用人者通常不是刑事案件被告人，列入附民待核，完整列主体通常需另行民事。

`depends-on` 为空。刑民总分流转 `分流刑民交叉`。尚未刑事的打架请求表转 `评估打架伤害民事路径`。刑终后对侵权人的普通起诉包转 `提起人身损害一审`。对保险人完整列被告转 `直接起诉保险公司`。精神损害成立转 `评估精神损害赔偿`。时效展开转 `评估人身损害诉讼时效`。定罪、控告、辩护、量刑意见转刑事领域。

## 工作边界

正触发：同一伤害进入刑事程序，需要选择附带民事或另行民事。「人已经被抓了，附带民事还是另案告」正触发。尚未刑事也要出附民终稿、保证附民能要精神损害、刑附民一律不能要或一律能要残疾或死亡赔偿金、保险人当然列入附民、选定某院、已提附民又另诉同一损失无风险、已读告知起算期间，仍正触发：选择闸可关，对应格填 `现有依据不支持` 或字段停止，窗口不关，不得改走负触发，不得标比较终稿已形成。工伤待遇与对第三人附民或另诉同时出现：本窗正触发，工伤段分流劳动，对第三人的 `Pth#` 可留。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是刑民交叉总分流（转 `分流刑民交叉`）；
- 主成果是尚未刑事或只要打架民事请求表（转 `评估打架伤害民事路径`）；
- 主成果是刑事辩护、控告状或刑事程序权利文书（转刑事领域）；
- 主成果是一审起诉状或立案包（转 `提起人身损害一审`）；
- 主成果是保险人直接起诉状（转 `直接起诉保险公司`）；
- 主成果是追加变更申请（转 `追加变更责任主体`）；
- 主成果是精神损害成立或金额（转 `评估精神损害赔偿`）；
- 主成果是测算终稿（转 `测算人身损害赔偿`）；
- 刑事已终结只要执行（转执行原子）；
- 纯工伤待遇且无第三人路径（转劳动）；
- C 端只要大众准备包（只分流）；
- 未成争改合同（审查起草搁置）。

尚未刑事出附民终稿、保证附民范围、保险人当然列入附民、选定法院**不在负触发表**，窗口不关。双方秘密、用民事谅解换假证、干预定罪**不在负触发表**，走整体停止。

## 建立工作坐标

确认：使用者与授权；权利人；刑事阶段及立案告知 `R#`；被告人；物质损失；是否已告知附带民事权利；是否已提附民及范围；保险人、场所、用人者是否拟列；法域。

口头「已经抓了」「已经立案」、截图、「已读」只登记 `S#`／`V#`。不得升格为已受理附民、期间已起算或已告知权利。用户坚持「保证附民能拿精神损害」「保险公司当然列进附民」不构成打开该格的授权。

同时掌握双方秘密，或权利人与被告人、保险人同时交材料争同一份附民或另诉策略：`整体停止`，不得以选边治愈，也不得改走负触发。权利人已开口且委托范围就是路径比较、且未掌握对方秘密时，可推定权利人立场。只要同时掌握双方秘密，无例外整体停止。提出用民事谅解换假伤情或假鉴定、倒签谅解、干预定罪或量刑交易、伪造伤情入罪或抬高请求：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`R#` 立案告知、起诉书、受案回执；`D#` 损失票据、谅解或调解文本；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Pth#` 路径；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。稿件状态只用 `草案`、`选择闸关闭`、`比较待核`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。不准许率。本任务默认 `草案`，不代提交，不定罪。禁止「附民当然能要精神损害」「保险人当然列入附民」「此致某院」。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：被害人因犯罪行为遭受物质损失可在刑事诉讼过程中提起附带民事诉讼；侦查、审查起诉期间可向公安机关或检察院提出并随案移送；附民范围以物质损失为原则；因犯罪主张精神损失在附民或另诉中的开闭须核验；保险人、场所等非刑事被告人不当然列入附民；已提附民与另诉同一损失的重复风险；刑事裁判生效后可另行提起民事诉讼。技能正文条号不是 `L#`。噪声：已失效《侵权责任法》、已失效《合同法》、保证附民能要精神损害、保险人当然列入附民、尚未刑事即可出附民终稿、选定某院、唯一截止日、口头或已读即已告知或期限已起算、一律不能要或一律能要残疾或死亡赔偿金、保证附民范围。不可用则附民范围、精神损害开闭、保险人地位、另行起诉时点与中止字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变附民范围、精神损害开闭、保险人可否列入或另行起诉时点的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补附民精神损害常不受理、交强险保险人常需另行民事、已提附民再诉同一损失被拦、刑事未结民事中止争议的实务反例。

工具不可用时继续 `Pth#` 编目与事实；附民范围、精神损害开闭、保险人地位、另行起诉时点字段停止。不得凭记忆写成保证附民能要精神损害、保险人当然列入附民、尚未刑事也能出附民终稿或选定法院。

## 判断节点

执行顺序和停止条件以 [刑附民选择方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、选择闸与不关窗

工伤三段分流，对第三人路径可留。双方秘密、谅解换假证第一次停。尚未刑事、保证附民范围不关窗。只要刑民总分流或打架请求表负触发。

### 2. 路径 `Pth#`

附民与另行分列。侦查审查起诉可随案移送。一审未提、二审调解不成告知另诉待核。刑终后可另行。不选定某庭。

### 3. 范围袋

物质损失项目分列。精神损害、残疾赔偿金、死亡赔偿金各格待核。禁止绝对句。未知不写零。

### 4. 主体袋与重复主张

保险人、场所、用人者列入附民待核，通常需另行。已提附民又就同一物质损失另诉该格不支持。

### 5. 谅解民事效果与转介

本窗只标弃权范围。量刑转刑事。不代写附民状。时效、精神损害、保险人起诉只点名。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；权利人与被告人、保险人同时交材料；用民事谅解换假证、串供或改伤情换从轻；干预定罪或量刑交易；倒签谅解或收条；伪造伤情入罪或抬高请求。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。不得改走负触发「转刑事」把干预定罪交出去。
- `字段停止`：附民范围、精神损害开闭、残疾或死亡赔偿金口径、保险人地位、另行起诉时点、时效中止未核验。选择闸未开则比较终稿停止，窗口不关。用户要保证附民范围、保险人当然列入、尚未刑事出附民终稿或选定法院则该格停止，窗口不关。
- `目标停止`：主目标变为刑民总分流、打架请求表、一审起诉包、保险人起诉状、追加申请、刑事程序权利文书、附民起诉状终稿。尚未刑事、保证附民范围不在目标停止。

禁止指导假证、倒签谅解或干预定罪。不定罪。不给胜诉率。不选定法院。不代提交。不编唯一截止日。不把未知写成零。不定残。不保证附民范围。
