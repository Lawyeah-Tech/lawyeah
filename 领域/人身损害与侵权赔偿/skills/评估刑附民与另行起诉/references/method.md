# 刑附民选择方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。稿件状态只用 `草案`、`选择闸关闭`、`比较待核`、`停止`。禁止胜诉率、准许率、唯一必得总额、唯一截止日、选定法院、自行宣布伤残等级、定罪、保证附民范围。未知金额不写零。本任务不代提交，不默认起草附民状。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、已失效《合同法》、把附民写成当然能要精神损害、把另行民事写成永远不能要精神损害、把残疾或死亡赔偿金写成一律能要或一律不能要、把保险人写成当然列入附民、把尚未刑事写成可出附民终稿、把口头或已读写成期间已起算时记为噪声，不得写入 `L#`。禁止指导用民事谅解换假证或干预定罪。

`Pth#` 固定列：`编号｜路径类型（刑附民／另行民事／可并行分项／不打开）｜刑事阶段门槛（未立案不打开附民／侦查审查起诉向公安或检察院提出并随案移送／一审／二审只调解或告知另诉待核／刑终后另诉）｜提起机关或论坛（不选定某庭）｜可列主体（刑事被告人／未被追究刑事责任的共同侵害人／保险人／用人单位／场所，各格打开／不打开／待核）｜物质损失项目（医疗护理交通误工／辅助具／丧葬等分列，未知不写零）｜精神损害格｜残疾赔偿金格｜死亡赔偿金格｜已提附民或调解履行表面｜重复主张风险｜时效中止或中断接口（只标转时效窗，无唯一截止日）｜谅解弃权范围（只民事）｜状态｜来源回链`。一行一路径或一条可并行分项。禁止合成「附民=全套民事」或「先附民不够再另诉去某院」。

口头「已经抓了」「已经立案」、截图、「已读」只进 `S#`／`V#`，不得升格 `R#` 已受理附民或期间已起算。

## 节点 0　分流、立场、选择闸与不关窗

整案转出或闸关闭只交付第 1、2、10 节或标注停止的 `Pth#`，不得交付附民或另行终稿，不得标保证附民范围。闸部分打开时：仅对阶段可回链的路径给出比较，其余行停止或不打开。

| 信号 | 处理 |
| --- | --- |
| 主成果是刑民交叉总分流 | 负触发 `分流刑民交叉`；已进入刑事且主成果是附民选择留本窗 |
| 尚未刑事或只要打架民事请求表 | 负触发 `评估打架伤害民事路径`；用户咬住本窗要比附民时闸关不关窗 |
| 刑事辩护、控告或量刑意见文书 | 负触发刑事领域；不得把干预定罪改走负触发交出去 |
| 主成果是一审起诉状 | 负触发 `提起人身损害一审` |
| 主成果是保险人起诉状 | 负触发 `直接起诉保险公司` |
| 主成果是追加变更申请 | 负触发 `追加变更责任主体` |
| 只要精神损害成立或金额 | 负触发 `评估精神损害赔偿`；本窗只打开闭红旗 |
| 只要测算终稿 | 负触发 `测算人身损害赔偿` |
| 刑事已终结只要执行 | 负触发执行原子 |
| 纯工伤待遇且无第三人路径 | 整案转劳动；夹带对第三人附民或另诉则本窗正触发，工伤段分流，`Pth#` 可留并转介 `评估工伤与第三人侵权竞合` |
| 诊疗过错或医疗鉴定终稿 | 转医疗 |
| 海事专门程序 | 转海事 |
| 未成争只要改合同 | 审查起草本窗搁置 |

选择闸打开（可出 `Pth#` 比较，仍不得标应当只走某条、保证附民范围、出附民状终稿）须同时满足：单方无冲突权利人立场与授权；主成果是附民 vs 另诉比较，不是附民状、不是定罪、不是刑民总分流、不是打架请求表终稿；同一伤害已进入刑事诉讼（至少有立案告知、受案回执或起诉书 `R#` 表面）；拟比较组合不含「已提附民又就同一物质损失另诉无风险」「用谅解换假证或定罪」。

闸关闭（仍正触发）：尚未立案刑事也要出附民终稿；保证附民能要精神损害；刑附民一律不能要或一律能要残疾或死亡赔偿金；保险人当然列入附民；选定某院；已读起算期间；已提附民又另诉同一损失无风险；要求本窗出具附民起诉状终稿。闸未开则仍只交 1、2、10 节。口头「已经抓了」不够开闸。

「尚未刑事出附民终稿」「保证附民范围」「保险人当然列入附民」「选定法院」**不关窗**。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或权利人与被告人、保险人同时交材料争同一份策略且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出用民事谅解换假证、干预定罪、倒签谅解、伪造伤情，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　路径 `Pth#` 与阶段

被害人因犯罪行为遭受**物质损失**，有权在刑事诉讼过程中提起附带民事诉讼。侦查、审查起诉期间可向公安机关或检察院提出，随案移送。检索锚点：刑事诉讼法附带民事诉讼条款。条号不是 `L#`。

一审期间未提起的，可在二审提起，法院可调解；调解不成告知刑事判决生效后另行提起民事诉讼。未提起附民的，可在刑事判决生效后另行提起民事诉讼。二审不得写成与一审相同的附民必准路径。

非法占有、处置被害人财产的追缴退赔路径：被害人提起附带民事诉讼，人民法院可能不予受理。该格待核，不得写成人身损害医疗费当然走追缴。

本窗只并列论坛（随刑事案件／民事侵权地与被告住所地），**不选定某刑庭或某民庭**，不预填「此致某院」。

## 节点 2　范围袋

物质损失项目分列：医疗费、护理费、交通费、误工、辅助器具、丧葬等。未知不写零。不定残。不输出唯一必得总额。

精神损害：附民中人民法院一般不予受理须运行时核验。禁止写成「附民当然能要」或「另行民事也永远不能要」。民法典精神损害条款与刑诉解释冲突是待核，不是本窗终局。只打开闭红旗，成立或金额转 `评估精神损害赔偿`。

残疾赔偿金、死亡赔偿金：与纯民事口径可能不同，必须分列待核。禁止全国一律能要或一律不能要。被告人赔偿能力、调解范围只标风险，不写成保证全套。死亡权利人转 `评估死亡赔偿权利人与分配`。

调解或和解赔偿范围可不受附民法定口径限制，只标民事效果，不保证履行或从轻。

## 节点 3　主体袋与重复主张

附民依法负有赔偿责任的主体可包括：刑事被告人、未被追究刑事责任的共同侵害人、监护人、遗产继承人、对物质损失依法应承担赔偿责任的其他单位和个人。检索锚点：刑事诉讼法解释附带民事赔偿责任人。条号不是 `L#`。在逃同案犯原则上不列为附民被告，待到案后另提，已获足额赔偿除外。

保险人、场所、用人者通常**不是**刑事案件被告人。列入附民各格待核，不得写成当然可以或当然不行。完整列交强险或商业三者通常需另行民事，转介 `直接起诉保险公司`（交强险应当共同被告，垫付 ≠ 可不列）。工作人员犯罪不影响用人单位依法承担民事责任，刑事案件追缴退赔可在民事中扣减。侵权行为人涉嫌刑事、被保险人请求保险人支付保险金，原则上分别审理。

已提起附带民事又就**同一物质损失**另行起诉：该格 `现有依据不支持` 或字段停止，窗口不关。对被告人走附民、对保险人走另行，可作为可并行分项，须分损失项目，禁止打包无风险。

## 节点 4　谅解、时效与转介

谅解、退赔对量刑的影响转刑事领域。本窗只标民事弃权范围：写了谅解不等于民事请求已消灭；追缴、退赔、罚金不等于附民已赔清。强迫和解无效接口待核。不指导用民事谅解换假证。

时效中止或中断只标接口，不写死唯一截止日。已读、口头告知不得起算。对被告人主张不当然覆盖对保险人。展开转 `评估人身损害诉讼时效`。

不代写附民起诉状终稿。用户要状：起诉入口关闭，比较表可留，转介刑事领域附民材料包（若宿主未安装则 `unavailable`）或刑终后 `提起人身损害一审`。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过选择闸直接给保证附民范围、保险人当然列入或选定法院。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if C 端只要大众准备包，then 只分流不回改。

判断状态只许三值。口头转述、截图和「已读」不得写成已受理、已告知权利或期限已起算。事故认定书、刑事立案告知不得单独写成民事终局比例。

## 本任务回链纪律

本任务成果是「不代提交的刑附民与另行民事路径比较」。必须包含：范围袋分列待核、保险人通常需另行。不包含：附民状终稿、一审诉状、刑民总分流、打架请求表、定罪或刑事程序权利文书。禁止保证附民范围。禁止选定法院。禁止尚未刑事出附民终稿。禁止选边治愈。禁止谅解换假证。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标比较终稿已形成。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接。
风险档 A：已提附民、谅解弃权字段必须单独标可逆性。
