# 边界与路由

## 正触发

同一伤害进入刑事程序，需要选择附带民事或另行民事。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 刑事控告辩护 | 刑事领域 |
| 尚未刑事的打架民事 | `评估打架伤害民事路径` |
| 刑民交叉总分流 | `分流刑民交叉` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 刑事程序权利 | 刑事领域 |
| 交通肇事附民中的保险分账 | 可并行交通专项 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“人已经被抓了，附带民事还是另案告”正触发。“帮他做无罪辩护”转刑事。“还没立案刑事”走打架民事或刑民分流。
