# 边界与路由

## 正触发

同一伤害进入刑事程序，需要选择附带民事或另行民事。「人已经被抓了，附带民事还是另案告」正触发。尚未刑事也要出附民终稿、保证附民能要精神损害、保险人当然列入附民、选定某院、已提附民又另诉同一损失无风险，仍正触发：选择闸可关，对应格停止，窗口不关。工伤待遇与对第三人附民或另诉同时出现，仍正触发：工伤段分流劳动，对第三人 `Pth#` 可留。

双方秘密、用民事谅解换假证、干预定罪的停止，优先于负触发。不得改走负触发「转刑事」把干预定罪交出去。尚未刑事、保证附民范围不在下表。谅解换假证不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 刑民交叉总分流 | `分流刑民交叉` |
| 尚未刑事或只要打架民事请求表 | `评估打架伤害民事路径` |
| 刑事辩护、控告状或刑事程序权利文书 | 刑事领域 |
| 一审起诉状或立案包 | `提起人身损害一审` |
| 保险人直接起诉状 | `直接起诉保险公司` |
| 追加变更申请 | `追加变更责任主体` |
| 精神损害成立或金额 | `评估精神损害赔偿` |
| 分项测算终稿 | `测算人身损害赔偿` |
| 死亡赔偿权利人与分配 | `评估死亡赔偿权利人与分配` |
| 刑事已终结只要执行 | 执行原子 |
| 纯工伤待遇且无第三人路径 | 劳动领域 |
| C 端只要大众准备包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「用谅解换假鉴定」「两边材料都给你选边」不在本表，走整体停止。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 仅工伤待遇且无第三人路径 | 劳动领域 |
| 诊疗过错或医疗鉴定终稿 | 医疗医药领域 |
| 海事专门程序 | 海事领域 |
| 指导假证、倒签谅解或干预定罪 | 整体停止 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。对第三人附民或另诉可留。交通肇事附民中的保险分账可并行交通专项，本窗只打保险人列入附民红旗。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 刑事线索但主成果是能不能民事 | `分流刑民交叉` |
| 未立案或只要打架请求表 | `评估打架伤害民事路径` |
| 刑终后对侵权人起诉包 | `提起人身损害一审` |
| 要对交强险或商业三者完整列被告 | `直接起诉保险公司` |
| 纯民事精神损害成立 | `评估精神损害赔偿` |
| T-报案、T-刑终展开 | `评估人身损害诉讼时效` |
| 死亡近亲属争议 | `评估死亡赔偿权利人与分配` |
| 工作中第三人 | `评估工伤与第三人侵权竞合` |
| 已立案漏列保险人 | `追加变更责任主体` |
| 管辖连结点展开 | `评估人身损害管辖` |
| 定罪、控告、辩护、量刑、谅解对量刑 | 刑事领域 |

## 易混

「人已经被抓了，附带民事还是另案告」正触发。「帮他做无罪辩护」转刑事。「还没立案刑事」：窗口不关，选择闸关，转介分流或打架民事，不得写成负触发踢走。「附民把十级残疾金、精神抚慰金、交强险保险公司一起写上，保证能拿，就这个刑庭判」仍正触发；范围袋待核；保险人通常另行；保证范围、选定法院各格不支持。「工伤还在认，要对打人者附民或另诉」正触发，第三人路径可留，工伤段分流。「两边材料都给你选边、用谅解换假鉴定换从轻」整体停止。
