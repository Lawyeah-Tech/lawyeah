# 输出合同

按触发结果选择交付形状。选择闸未打开不得交付比较终稿或保证附民范围。禁止选定唯一法院或预填「此致某院」。禁止尚未刑事出附民终稿。禁止精神损害一律能要或一律不能要。禁止残疾或死亡赔偿金一律能要或一律不能要。禁止保险人当然列入附民。禁止已提附民又另诉同一损失无风险。禁止已读起算期间。禁止定罪。禁止代写附民状。禁止未知金额写零。禁止胜诉率。禁止选边治愈。不代提交。不定残。不保证附民范围。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 选择闸关闭或节点 0 整案转出 | 第 1、2、10 节：关闭理由、阶段待核和最小补证。可附标注停止的 `Pth#`。禁止附民终稿、保证范围、唯一截止日。对第三人可留时不得因工伤整案转出 |
| 整体停止 | 第 1、10 节。禁止 `Pth#` 比较包、选边、假证或干预定罪方法。双方秘密、用民事谅解换假证、干预定罪第一次即停，优先于负触发；无选边治愈，无「坚持」门槛 |
| 用户要尚未刑事出附民终稿、保证附民能要精神损害、保险人当然列入附民、选定某院（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；闸未开则仍只交 1、2、10；不得改走负触发关窗；成果不得标比较终稿 `已形成` 或保证附民范围 |
| 正触发且闸开（可部分开） | 下列十节表头均出现；范围、精神损害开闭、保险人地位、另行时点未核验的单元格填 `依据不足，无法形成结论` 或 `待核`；一行一路径；禁止为填满而宣布保证范围、保险人当然列入或选定某院 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入比较终稿已形成。双方秘密未解不得进入「部分形成」。每个 `Pth#` 必须带来源和三值判断。`L#` 不得直接抄技能内条号。保证附民能要精神损害、保险人当然列入、尚未刑事即可出附民终稿若返回则记噪声。稿件状态默认 `草案`。

## 1. 触发、单方立场、授权与成果状态

选择闸开、部分开或关。刑事阶段及 `R#` 必须标明。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。稿件默认 `草案`。不定罪。不代提交。

## 2. 来源登记与 MCP 调用表

`S/R/D/L/I/G/Pth/V`。口头已经抓了、已读告知只登记 `S#`／`V#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 路径比较 `Pth#`

附民与另行分列。阶段门槛可见。可并行分项单独成行。不选定某庭。

## 4. 范围袋

物质损失项目分列。精神损害、残疾赔偿金、死亡赔偿金各格待核。禁止绝对句。未知不写零。

## 5. 主体袋

刑事被告人、共同侵害人、保险人、用人单位、场所各格打开或待核。保险人通常需另行。

## 6. 重复主张风险

已提附民又就同一物质损失另诉该格不支持。对被告人附民与对保险人另行可并行，须分项目。

## 7. 管辖与时效红旗

刑事审判法院与民事连结点并列，不选定。时效中止只标接口，已读不得起算，不写死截止日。

## 8. 谅解民事效果

只标弃权范围。不等于请求消灭。量刑转刑事。不指导换假证。

## 9. 下一步与转介

提起附民、等待刑终后另诉、或对保险人另行只点名。不代写附民状。转介一审、直接起诉保险公司、精神损害、时效、刑民分流只点名。

## 10. 缺口、停止项与提示

须列对方最强解释：附民当然能要精神损害、另行民事永远不能要精神损害、刑附民一律不能要或一律能要十级残疾金和死亡赔偿金、保险公司当然列进附民、还没立案先把附民递进某区刑庭并保证准许、已提附民同一医疗费再去民庭没有风险、告知短信已读期间已经起算、必须先刑后民刑终前民事一律不能动、谅解写了从轻民事就不用标弃权、追缴退赔等于附民已赔清、工伤还在认所以对第三人不能附民或另诉、两边材料都给你选边、用谅解换假鉴定换从轻。

本成果不是附民状、不是一审诉状、不是定罪意见、不是刑事程序权利文书、不保证附民范围、不是唯一截止日。不代提交。不定罪。
