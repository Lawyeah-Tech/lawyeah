# 保全必要性方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。建议状态只用 `建议转介申请`、`不打开`、`依据不足`、`闸关闭`、`停止`。禁止准许率、胜诉率、必然准许、唯一截止日、选定法院、自行宣布伤残等级。未知金额不写零。本任务不写申请书，不代提交，不保证裁定。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文、把保存通知或现场步骤写成保全裁定、把先予执行写成保全、把保险认责写成当然不必保全、把三十日写成未核验日历截止、把一律免担保或一律百分之三十担保、把保证准许写入结论时记为噪声，不得写入 `L#`。禁止指导虚构转移或查封生活必需。

`H-证#` 与 `H-财#` 必须分表，禁止合成「全案一律必要」。固定列：`编号｜分型（证据保全／财产保全）｜对象（猜测标S#）｜控制方或登记名义｜紧急或难以取得／难以执行事实（回链S/D/R）｜条件判断（三值）｜管辖连结点并列（不选唯一）｜担保（诉前应当／诉中可以责令，额度待核）｜错误赔偿｜保险覆盖对必要性影响（仅财产表；不关闭证据表）｜范围红旗（超请求／案外人／生活必需）｜替代手段（只点技能名）｜时机（诉前／诉中／仲裁前）｜诉前三十日红旗（只写期间长度）｜建议｜状态｜来源回链`。一行一类对象。禁止「冻结一切财产」。

## 节点 0　分流、立场、评估闸与不关窗

整案转出或闸关闭只交付第 1、2、10 节，不交完整 `H#` 必要性终稿。闸部分打开时：仅对已有最小事实的表给出对照，另一表标 `依据不足` 或 `不打开`。

| 信号 | 处理 |
| --- | --- |
| 已决定申请且只要申请书 | 负触发 `准备财产或证据保全申请` |
| 只要先予执行医疗费或生活费 | 负触发 `申请先予执行医疗费`；不得把给付改写成查封 |
| 只要保存通知正文 | 负触发 `准备监控保存通知`；用户同时要「要不要申请法院保全」则本窗正触发，保存函只转介 |
| 只要现场合法固定步骤 | 负触发 `保全现场监控与电子证据` |
| 只要调查令或公证事项终稿 | 负触发对应原子 |
| 已被保全只要复议或担保置换 | 负触发 `应对人身案件保全裁定` |
| 主轴仅工伤待遇且无对第三人财产或易失证据 | 整案转劳动；夹带第三人车辆／账户／场所监控则本窗正触发，工伤段分流，`H#` 可留并转介 `评估工伤与第三人侵权竞合` |
| 诊疗过错或医疗鉴定终稿 | 转医疗；对医疗机构财产或场所监控的必要性可留 |
| 海事扣船或海事保全 | 转海事 |
| 工程款工期质量造价 | 转建设工程；工地人身对第三人财产保全不得误转 |
| 未成争只要改合同 | 审查起草本窗搁置 |

评估闸打开条件（对某一行，同时满足）：单方无冲突立场与授权；该行对象可标 `S#` 或更强来源；至少有灭失／转移／难以执行的具体事实或可标注为单方陈述的具体事件，而非纯情绪；主成果是必要性评估而非申请书。

闸关闭（仍正触发）：完全无证据对象也无财产线索；目的是「必须冻且保证准许」而无事实。「今天必须申请」「必须冻结」本身不得开闸写成建议＝申请。仅有「担心」无回链事实：该行 `依据不足`，不关窗。

「必须冻结」「保证准许」「保险已赔就不必保」「写死三十日截止」「保存函已读就算已保全」**不关窗**。闸未开则仍只交 1、2、10 节。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或受害人与被申请人同时交材料争同一份冻结或证据保全方案且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出虚构转移、倒签紧急事实、查封无关案外人生活必需且拒绝限缩、以保全骚扰无关案外人、违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　对象分型

证据保全与财产保全分表。监控、行车记录仪、聊天、现场状态走 `H-证#`。银行存款、车辆、房产、股权走 `H-财#`。两者可并行，不得一张总票。

先予执行（紧急医疗费、必要生活费）是给付，不是冻结或固定，不进 `H#`。用户把「先让医院有钱」写成查封账户：该财产行 `现有依据不支持` 作为保全必要性结论，并转介 `申请先予执行医疗费`，窗口不关。

不能因对方控制而推定监控存在或内容有利，也不能因「有车」无号牌无登记而写成必须冻结该车。

## 节点 2　法定条件对照

检索锚点，条号不是 `L#`。未核验则条件格停止。

**证据保全：** 证据可能灭失或者以后难以取得。诉前另须情况紧急。管辖连结点并列：证据所在地、被申请人住所地、对案件有管辖权的人民法院。材料不足则并列待核，不选唯一法院。

**财产保全：** 可能因当事人一方的行为或者其他原因，使判决难以执行或者造成当事人其他损害。诉前另须情况紧急，不立即申请将使合法权益受到难以弥补的损害。管辖连结点并列：被保全财产所在地、被申请人住所地、对案件有管辖权的人民法院。不选唯一。

仅有担心、对方未回微信、正常经营，不得写成转移已支持。转移迹象必须回链 `S#`／`D#`／`R#`。口述「肯定在过户」只登记 `S#`，条件判断至多 `依据不足`。

用户要「不申请就必然无法执行／必然败诉」：该格 `现有依据不支持`，窗口不关。

## 节点 3　担保、错误赔偿、范围与保险

诉前财产保全申请人应当提供担保，不提供则裁定驳回申请——检索锚点，未核验不得写成人身损害一律免担保。诉中保全人民法院可以责令担保。证据保全参照保全章，担保应当或可以待核。额度、形式待核，禁止默写唯一比例（含百分之三十）。

申请有错误的，申请人应当赔偿被申请人因保全所遭受的损失。必须明示。超范围、案外人财产、生活所必需物品（执行规范待核）单列红旗。线索指向生活必需且用户拒绝限缩仍要求「应当查封」：整体停止。

保险覆盖只写入财产表：交强险在案、商业三者立案、保险人口头认责，可以**降低**财产保全必要性，仍须个案。认责 ≠ 足额 ≠ 已支付；免责、分项限额、伤残未定、保险人争议待核。保险覆盖**不关闭**证据保全表，也不得写成财产保全当然不必要。用户要「保险已赔就不必保」：该格 `现有依据不支持` 或待核，窗口不关。

无力担保：该行必要性再评估，标申请受阻，不改走「必须先冻」。

## 节点 4　时机、替代手段与输出纪律

时机分列诉前、诉中、仲裁前。诉前保全后三十日内不依法提起诉讼或者申请仲裁的，人民法院应当解除保全。三十日是期间长度锚点，不是未核验的唯一日历截止日。起算点未核验则截止日字段停止。微信已读、裁定作出日、口头告知不得单独起算。用户要写死「某月某日必须起诉否则败诉／自动解封」：该格停止，窗口不关。

人民法院对情况紧急的申请须在四十八小时内作出裁定，是对法院的期间，不是申请人「今晚必须交」的截止日，不得写入用户唯一期限。

替代手段只点技能名，本窗不写那些终稿：

- `准备监控保存通知`
- `保全现场监控与电子证据`
- `准备人身案件公证保全`
- `申请人身案件调查令或取证`
- `设计人身案件通知送达`
- `准备财产或证据保全申请`（仅当建议＝转介申请）
- `申请先予执行医疗费`
- `评估责任主体与保险覆盖`

保存通知、现场合法固定、公证、调查令 **不等于** 法院保全裁定。物业已读、口头「已经拷了」不是已保全。

输出纪律：不写申请书。不保证准许。不选定法院。不代提交。建议最多 `建议转介申请`，不得写成「应当准许」或「必须冻结」。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过评估闸直接给必须申请或必然准许。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if C 端只要大众准备包，then 只分流不回改。

判断状态只许三值。口头转述、截图和「已读」不得写成已受理、已送达、已保全或期限已起算。事故认定书、调解记录不得单独写成民事终局比例并据此必须保全。

## 本任务回链纪律

本任务成果是「证据保全与财产保全的分表必要性评估」。不包含：申请书、先予执行终稿、保存函、现场步骤、调查令、公证事项、应对裁定、送达专项。禁止保证准许。禁止保险认责当然关闭保全。禁止写死三十日。禁止选边治愈。禁止虚构转移。禁止查封生活必需步骤。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标必要性终稿已形成。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接：已固定分型、线索缺口和建议状态。
