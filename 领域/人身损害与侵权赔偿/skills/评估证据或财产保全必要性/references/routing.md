# 边界与路由

## 正触发

担心转移财产或证据灭失，尚未决定是否申请保全。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 已决定写申请 | `准备财产或证据保全申请` |
| 先予执行医疗费 | `申请先予执行医疗费` |
| 保存通知 | `准备监控保存通知` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 海事保全 | 海事领域 |
| 劳动仲裁保全 | 劳动领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“要不要先冻他的车”正触发。“申请书怎么写”走申请原子。“先让医院有钱做手术”走先予执行。
