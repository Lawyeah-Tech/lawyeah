# 边界与路由

## 正触发

担心转移财产或证据灭失，尚未决定是否向法院申请保全。无线索、不知保单、用户要必须冻结、保证准许、保险已赔就不必保或写死三十日截止仍正触发：评估闸可关，对应格停止，窗口不关。工伤待遇与对第三人财产或易失证据同时出现，仍正触发：工伤段分流劳动，对第三人 `H#` 可留。

双方秘密、同时交材料、虚构转移、查封案外人生活必需、以保全骚扰的停止，优先于负触发。不得改走负触发去出 `H#` 或申请书。虚构转移不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 已决定申请且只要申请书 | `准备财产或证据保全申请` |
| 先予执行医疗费或生活费 | `申请先予执行医疗费` |
| 只要保存通知正文 | `准备监控保存通知`；同时问要不要法院保全则本窗可留 |
| 现场、聊天或行车记录仪合法固定步骤 | `保全现场监控与电子证据` |
| 调查令终稿 | `申请人身案件调查令或取证` |
| 公证保全事项终稿 | `准备人身案件公证保全` |
| 已被保全只要复议或担保置换 | `应对人身案件保全裁定` |
| 送达渠道专项 | `设计人身案件通知送达` |
| 建卷矩阵 | `建立人身损害证据案卷` |
| C 端只要大众准备包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「把岳父房子一起封了吓他」「先做一份假过户记录」不在本表，走整体停止。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 仅工伤待遇且无对第三人财产或易失证据 | 劳动领域 |
| 劳动仲裁保全且无民事第三人对象 | 劳动领域 |
| 病历封存或医疗鉴定终稿 | 医疗医药领域；对医疗机构财产或场所监控可留 |
| 海事扣船或海事保全 | 海事领域 |
| 工程造价主轴 | 建设工程；人身对第三人财产保全不得误转 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。对第三人财产或易失证据可留。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 建议申请且用户确认要文书 | `准备财产或证据保全申请` |
| 紧急手术费或生活费给付 | `申请先予执行医疗费` |
| 要物业留监控的函 | `准备监控保存通知` |
| 己方现场或行车记录仪步骤 | `保全现场监控与电子证据` |
| 调查令 | `申请人身案件调查令或取证` |
| 公证事项 | `准备人身案件公证保全` |
| 已被裁定 | `应对人身案件保全裁定` |
| 保险覆盖、主体 | `评估责任主体与保险覆盖` |
| 工伤与第三人 | `评估工伤与第三人侵权竞合` |
| 起诉准备 | `提起人身损害一审` |

## 易混

「要不要先冻他的车」正触发。「申请书怎么写」走申请原子。「先让医院有钱做手术」走先予执行，不得写成查封。「监控一周就覆盖，要不要申请法院证据保全，还是先发函」正触发；证据表对照替代手段，保存函只转介。「交强险认了就不必保全」仍正触发；保险只降低财产表必要性，不关窗。「不知道他有没有房子，必须全部冻结并保证准许，写死三十日」仍正触发；闸可关，必须冻结与保证准许格不支持，三十日字段停止。「工伤还在认，对方要卖车」正触发，财产表可留，工伤段分流。「两边材料都给你，选边冻谁」整体停止。
