# 输出合同

按触发结果选择交付形状。评估闸未打开不得交付完整必要性终稿。禁止代写申请书。禁止保证准许或准许率。禁止选定法院。禁止写死三十日日历截止。禁止把保存通知、现场步骤、公证或调查令写成法院保全裁定。禁止把先予执行写成保全。禁止把保险认责写成当然不必保全。禁止选边治愈。禁止虚构转移或查封生活必需步骤。不代提交。不定残。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 评估闸关闭或节点 0 整案转出 | 第 1、2、10 节：关闭理由和最小补证。禁止完整 `H#` 终稿、申请书、截止日。对第三人保全可留时不得因工伤整案转出 |
| 整体停止 | 第 1、10 节。禁止 `H#`、冻结对象、选边、虚构转移方法。双方秘密、同时交材料、查封案外人生活必需、虚构转移、骚扰第一次即停，优先于负触发；无选边治愈，无「坚持」门槛 |
| 用户要必须冻结、保证准许、保险已赔就不必保或写死三十日（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；闸未开则仍只交 1、2、10；不得改走负触发关窗；成果不得标必要性终稿 `已形成` 为必须申请或必然准许 |
| 正触发且闸开（可部分开） | 下列十节表头均出现；条件、担保、期限未核验的单元格填 `依据不足，无法形成结论` 或 `待核`；证据表与财产表分列；禁止为填满而宣布必须申请、必然准许或保险已赔即关闭 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入必要性终稿已形成。双方秘密未解不得进入「部分形成」。每个 `H-证#`／`H-财#` 必须带来源和三值判断。`L#` 不得直接抄技能内条号。保证准许、三十日日历截止、保险当然不必保若返回则记噪声。建议默认 `依据不足` 或 `建议转介申请`，不得写成应当准许。

## 1. 触发、单方立场、授权与成果状态

评估闸开、部分开或关。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。尚未决定申请。

## 2. 来源登记与 MCP 调用表

`S/D/R/C/L/I/G/H/V`。口述转移、口头认责、已读截图只登记 `S#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 评估闸与对象分型

证据保全与财产保全分表。先予执行不进本表。「必须冻结」不得开闸。无线索则闸关闭或该行依据不足。

## 4. 证据保全行 `H-证#`

灭失或难以取得。诉前紧急待核。管辖连结点并列。替代手段只点名。不等于已保全。

## 5. 财产保全行 `H-财#`

难以执行或其他损害。诉前紧急与难以弥补待核。转移必须回链。保险覆盖只降低必要性，不关窗。

## 6. 担保与错误赔偿

诉前应当担保，诉中可以责令。额度待核，禁止默写百分之三十。申请错误应赔偿。无力担保标受阻。

## 7. 范围红旗与生活必需

超请求、案外人财产、生活所必需物品。拒绝限缩仍要求查封生活必需则整体停止。不选定法院。

## 8. 时机与诉前三十日

三十日只作期间长度。已读、作出日不得起算。四十八小时是对法院的期间，不是申请人今晚截止。未核验不写日历日。

## 9. 替代手段与下一步

只点转介名：保存通知、现场固定、公证、调查令、申请书、先予执行、主体保险。不附那些终稿。建议最多转介申请。

## 10. 缺口、停止项与提示

须列对方最强解释：必须冻结否则无法执行、保证准许、保险认责就不必保、三十日写死截止、保存函或已读即已保全、先予执行就是查封、选边即可继续、查封唯一住房和生活费卡、口述转移即已支持。

本成果不是申请书、不是裁定、不是先予执行、不是保存函、不保证准许、不是唯一截止日。不代提交。
