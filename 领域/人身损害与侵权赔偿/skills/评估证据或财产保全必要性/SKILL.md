# 评估证据或财产保全必要性

## 任务目标

在明确、无利益冲突的单方立场下，形成保全必要性评估包：评估闸、证据保全行 `H-证#` 与财产保全行 `H-财#` 分表、担保与错误赔偿、时机红旗、替代手段转介。尚未决定申请。不代写申请书。不保证准许。不选定法院。不计算唯一截止日。先予执行不是保全。保存通知、现场合法固定、公证、调查令不等于法院保全裁定。保险人认责或交强险在案不是财产保全当然不必要，更不关闭证据保全表。

`depends-on` 为空。已决定写申请转 `准备财产或证据保全申请`。紧急医疗费转 `申请先予执行医疗费`。保存函转 `准备监控保存通知`。现场步骤转 `保全现场监控与电子证据`。已被裁定转 `应对人身案件保全裁定`。

## 工作边界

正触发：担心转移财产或证据灭失，尚未决定是否向法院申请保全。无线索、不知保单、用户要「必须冻结」「保证准许」「保险已赔就不必保」「写死三十日截止」仍正触发：评估闸可关，对应格填 `现有依据不支持` 或字段停止，窗口不关。工伤待遇与对第三人财产或易失证据同时出现：本窗正触发，工伤段分流劳动，对第三人的 `H#` 可留。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 已决定申请且只要申请书（转 `准备财产或证据保全申请`）；
- 只要先予执行医疗费或生活费（转 `申请先予执行医疗费`）；
- 只要保存通知正文（转 `准备监控保存通知`）；
- 只要现场、聊天或行车记录仪合法固定步骤（转 `保全现场监控与电子证据`）；
- 只要调查令终稿（转 `申请人身案件调查令或取证`）；
- 只要公证事项终稿（转 `准备人身案件公证保全`）；
- 已被保全且只要复议或担保置换（转 `应对人身案件保全裁定`）；
- 只要送达专项（转 `设计人身案件通知送达`）；
- 只要建卷矩阵（转 `建立人身损害证据案卷`）；
- C 端只要大众准备包（只分流）；
- 未成争改合同（审查起草搁置）。

虚构转移、查封案外人生活必需、以保全骚扰、双方秘密**不在负触发表**，走整体停止。

## 建立工作坐标

确认：使用者与授权；单方立场；诉讼或诉前阶段；证据对象与控制方；财产线索与权属；转移或灭失事实来源；担保能力；保险覆盖材料；法域。

口头「他肯定在卖车」「依法三十天不诉就完了」「保险公司认了就不用冻」只登记 `S#`。不得把口述转移写成已支持，不得写死唯一日历截止日，不得选定法院。

同时掌握双方秘密，或受害人与被申请人同时交材料争同一份冻结或证据保全方案：`整体停止`，不得以选边治愈，也不得改走负触发去出一方 `H#`。受害人已开口且委托范围就是必要性评估、且未掌握对方秘密时，可推定主张方立场。只要同时掌握双方秘密，无例外整体停止。提出虚构转移、倒签紧急事实、查封无关案外人生活必需且拒绝限缩、以保全骚扰：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 财产或证据线索；`R#` 立案或机关文书；`C#` 保单或认责材料；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`H-证#`／`H-财#` 必要性行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。建议状态只用 `建议转介申请`、`不打开`、`依据不足`、`闸关闭`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。不准许率。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：财产保全以可能使判决难以执行或造成其他损害为条件；诉前财产保全另须情况紧急、不立即申请将使合法权益受到难以弥补的损害，申请人应当提供担保，向被保全财产所在地、被申请人住所地或对案件有管辖权的人民法院申请；采取保全措施后三十日内不依法起诉或申请仲裁应解除（三十日是期间长度，不是未核验的日历截止日）；证据保全以证据可能灭失或以后难以取得为条件，诉前须情况紧急；申请有错误应赔偿被申请人因保全所遭受的损失；诉中保全可以责令担保。技能正文条号不是 `L#`。噪声：已失效《侵权责任法》、保证准许、保险认责即不必保全、写死三十日日历截止、保存通知或现场步骤等于裁定、先予执行等于保全、一律免担保或一律百分之三十担保、生活必需当然可查封。不可用则条件、担保、期限字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变条件、担保或期限的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补保险覆盖降低但不关闭必要性、无线索难准许、超范围错误赔偿、诉前期限实践差异的反例。
- `search_case_by_fact` 只比较差异与翻转条件，不写成必然准许或必然驳回。

工具不可用时继续分型与线索编目；条件、担保、期限字段停止。不得凭记忆写三十日截止或必然准许。

## 判断节点

执行顺序和停止条件以 [保全必要性方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、评估闸与不关窗

工伤三段分流，对第三人保全可留。双方秘密或虚构转移第一次停。错误主张不关窗。先予执行负触发。

### 2. 对象分型

证据保全与财产保全分表，不得合成一张总票。先予执行不进 `H#`。

### 3. 法定条件对照

财产：难以执行或其他损害；诉前另核紧急与难以弥补。证据：可能灭失或以后难以取得；诉前另核紧急。仅担心无事实则依据不足。

### 4. 担保、错误赔偿、范围与保险

诉前应当担保，诉中可以责令。申请错误应赔偿。生活必需与案外人财产红旗。保险认责不关窗。

### 5. 时机、替代手段与输出纪律

三十日只作期间长度。替代只点转介名。不写申请书。不保证准许。不选定法院。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；受害人与被申请人同时交材料；提出虚构转移或倒签紧急事实、查封无关案外人生活必需且拒绝限缩、以保全骚扰、违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：保全条件、担保应当或可以、诉前期间起算、管辖连结点未核验。用户要必须冻结、保证准许、保险已赔就不必保或写死三十日则该格停止，窗口不关；闸未开仍不出完整 `H#` 终稿。
- `目标停止`：主目标变为申请书、先予执行、保存函、现场步骤、调查令、公证、应对裁定或送达终稿。必须冻结或保证准许不在目标停止。

禁止指导虚构转移或查封生活必需。不给准许率。不选定法院。不代写申请。不代提交。不编唯一截止日。
