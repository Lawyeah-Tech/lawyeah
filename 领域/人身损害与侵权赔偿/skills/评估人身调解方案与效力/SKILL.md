# 评估人身调解方案与效力

## 任务目标

在明确、无利益冲突的单方立场下，形成人身损害调解方案评估包：评估闸、`Med#` 分表（法院诉讼调解／人民调解／保险调解／交警或派出所调解分列）、效力类型、反悔窗口、弃权与鉴定闸、与庭审成本比较（无胜诉率）、执行力红旗（手续只转介）。不替用户决定接受。不保证能反悔。不代签署、不代申请确认或赋强。不写协议正文、不写庭审提纲、不出让步档、不审印好了结书终稿、不选「先保险还是先起诉」路径终稿。未知伤残、后续治疗默认保留，不得建议接受覆盖未知损害的概括弃权。调解书签收或司法确认后更难反悔，升格风险档 A。

`depends-on` 为空。协议正文转 `起草人身损害和解协议`。让步档转 `谈判人身损害和解`。保险了结审查转 `审查保险一次性了结弃权`。确认或赋强手续转 `办理人身和解执行力补强`。先理赔还是先诉先调转 `选择诉讼调解或保险先行`。庭审提纲转 `准备人身损害庭审`。

## 工作边界

正触发：面对法院调解、人民调解、保险调解或交警／派出所调解方案，需要判断效力、反悔窗口和风险。保证能反悔、包干未知伤残、写死反悔日、选定某法院、口头答应或已读即已生效、送达即生效、派出所调解可强制执行、保险调解消灭对侵权人，仍正触发：评估闸可关，对应格填 `现有依据不支持` 或字段停止，窗口不关，不得改走负触发，不得标接受意见已形成。工伤待遇与对第三人法院或保险调解同时出现：本窗正触发，工伤段分流劳动，对第三人的 `Med#` 可留。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是庭审提纲或发问策略（转 `准备人身损害庭审`）；
- 主成果是和解协议正文或草稿（转 `起草人身损害和解协议`）；
- 主成果是让步档、底线或未闭合报价方案（转 `谈判人身损害和解`）；
- 主成果是审查保险人一次性了结或权益转让文本（转 `审查保险一次性了结弃权`）；
- 主成果是司法确认、诉讼调解书或公证赋强手续（转 `办理人身和解执行力补强`）；
- 主成果是比较保险理赔、调解、起诉、先予执行哪条更适配（转 `选择诉讼调解或保险先行`）；
- 只要起诉状终稿（转 `提起人身损害一审`）；
- 只要测算终稿或唯一必得总额（转 `测算人身损害赔偿`）；
- 已有生效调解书只要强制执行申请（转 `执行人身损害生效文书`）；
- 执行中分期或以物抵债（转 `准备人身执行和解`）；
- 纯工伤待遇或劳动调解且无第三人民事调解（转劳动）；
- C 端只要大众准备包（只分流）；
- 未成争改合同（审查起草搁置）。

保证能反悔、包干未知伤残、写死反悔日、选定法院、送达即生效、口头已生效**不在负触发表**，窗口不关。「签不签这份方案」本身不是负触发。倒签、伪造人民调解组织、双方秘密、要求产出含未知伤残概括弃权的可以放心签接受意见**不在负触发表**，走整体停止。

## 建立工作坐标

确认：使用者与授权；单方立场；主持方类型；方案文本来源（口头／已读只登记 `S#`／`V#`，笔录、调解书草案、人民调解协议、保险调解记录另登 `D#`／`R#`）；是否已立案；是否双方签收或拒收；调解组织是否依法设立；治疗是否相对稳定、鉴定状态；拟接受主文是否含未知伤残或「永不追究一切」；付款人分列；权利人适格；已收款；法域。

口头「差不多了」、微信「行／已读」、EMS 妥投只登记 `S#`／`V#`。不得升格为已生效、已签收、期间已起算或已可执行。用户坚持「保证能反悔」「可以放心签」不构成建议接受概括弃权的授权。

同时掌握双方秘密，或受害人与侵权人、保险人同时交材料争同一份接受意见：`整体停止`，不得以选边治愈，也不得改走负触发去出一方意见。受害人已开口且委托范围就是评估这份方案、且未掌握对方秘密时，可推定单方立场。只要同时掌握双方秘密，无例外整体停止。提出倒签调解日期或出险日、伪造或假冒人民调解组织、指导骗保、以调解掩盖犯罪、刑事逼签、要求产出覆盖未知伤残或「永不追究一切」的可以放心签接受意见：第一次提出即整体停止，不以「坚持」「用户已理解」或「高风险确认」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 调解方案、笔录、调解书草案；`R#` 立案、签收或拒收、调解组织；`C#` 保单或保险调解记录；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Med#` 方案行；`W#` 拟接受弃权；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。稿件状态只用 `草案`、`评估闸关闭`、`评估待核`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。不准许率。本任务默认 `草案`，不代签署。禁止「建议接受」「可以放心签」「保证能反悔」。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：诉讼调解书经双方当事人签收后发生法律效力，生效日以最后一方签收日为准；送达过程不等于签收，一方拒收则调解不成；人民调解协议具有合同拘束力，原则上不能直接申请强制执行；司法确认须依法设立的调解组织主持且双方共同申请；保险调解或限额内付款不当然消灭对侵权人其余请求；交强险被侵权人直接请求不得被被保险人单方调解放弃；重大误解、欺诈、胁迫、显失公平可撤销只作接口。技能正文条号不是 `L#`。噪声：已失效《侵权责任法》、已失效《合同法》、调解书送达即生效、拒收仍可执行、口头答应或已读即已生效、三十日＝失权日、已读起算、派出所调解可强制执行、私下微信可司法确认、保险调解消灭对侵权人全部请求、被保险人签字消灭交强险直接请求、保证能反悔、建议接受未稳定包干、选定唯一法院、唯一反悔截止日。不可用则生效时点、确认期间、可撤销、执行力、直接请求字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变生效时点、反悔窗口或执行力结论的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补口头调解当生效、未稳定包干、人民调解未确认无执行力、调解书签收后难反悔、派出所无执行力、保险调解不消灭侵权人的实务反例。

工具不可用时继续 `Med#` 编目与方案拆解；生效时点、确认期间、可撤销、执行力字段停止。不得凭记忆写成送达即生效或建议接受未稳定包干。

## 判断节点

执行顺序和停止条件以 [调解评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、评估闸与不关窗

工伤三段分流，对第三人调解可留。双方秘密、倒签、伪造调解组织第一次停。保证能反悔、包干未知伤残、送达即生效不关窗。只要协议正文或确认手续负触发。

### 2. 主持方、文本形态与效力类型

法院调解书、人民调解协议、保险调解、交警或派出所调解分列。口头已读不得升格。送达 ≠ 签收。

### 3. 方案拆解 `Med#`

打包总额须还原项目。付款人分列。未稳定不得建议包干。覆盖未知伤残的接受建议停止。

### 4. 反悔窗口与执行力

签收前可反悔；签收或确认后难推翻，不保证能反悔。未核验不写截止日。派出所一般无强制执行力。补强手续只转介。

### 5. 与庭审成本比较、不替用户决定

只列成本、时间、执行风险。无胜诉率。不代替庭审策略。不勾选「接受」。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；受害人与侵权人、保险人同时交材料；倒签调解日期、出险日或人民调解协议落款日；伪造、假冒或补办人民调解组织或假调解笔录；指导骗保、隐瞒伤情、以调解掩盖犯罪、刑事逼签；要求产出覆盖未知伤残、未知手术或「永不追究一切」的可以放心签接受意见。整体停止优先于负触发。不以「坚持」「用户已理解」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：调解书生效时点、反悔规则、司法确认期间、保险调解拘束范围未核验。评估闸未开则接受意见停止，窗口不关。用户要保证能反悔、送达即生效、包干未知伤残、写死反悔日或选定法院则该格停止，窗口不关。
- `目标停止`：主目标变为庭审提纲、协议正文、谈判档、保险了结审查终稿、确认赋强手续、保险先行路径选择、起诉状或测算终稿。保证能反悔、包干未知伤残不在目标停止。

禁止指导倒签、伪造调解组织或骗保。不给胜诉率。不选定法院。不代签署。不编唯一截止日。不把未知写成零。不定残。不保证能反悔。不建议接受概括弃权。
