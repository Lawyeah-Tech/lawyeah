# 调解评估方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。稿件状态只用 `草案`、`评估闸关闭`、`评估待核`、`停止`。禁止胜诉率、必然责任比例、唯一必得总额、唯一截止日、选定法院、自行宣布伤残等级。未知金额不写零。本任务不代签署、不代申请确认或赋强，不替用户决定接受，不保证能反悔。调解书签收或司法确认后更难反悔，可逆性必须单列（风险档 A）。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、已失效《合同法》、把调解书送达写成已生效、把口头答应或已读写成已生效、把三十日写成失权日、把派出所调解写成可强制执行、把保险调解写成消灭对侵权人全部请求、把私下微信写成可司法确认、把未稳定包干写成可建议接受时记为噪声，不得写入 `L#`。禁止指导倒签、伪造人民调解组织或骗保。

`Med#` 固定列：`编号｜主持方（法院诉讼调解／人民调解／保险调解／交警或派出所调解／私下微信或当面只S#）｜文本形态（调解书草案／不制作调解书的笔录／人民调解协议／保险调解记录／派出所调解记录／口头或已读仅S#）｜项目还原（医疗／误工／护理／伤残或死亡／精神损害／后续治疗；打包须拆开；未知不写零）｜付款人（交强险／商业三者／侵权人／用人者分列）｜是否覆盖未知伤残或永不追究（覆盖则该行停止，不得建议接受）｜鉴定闸（未稳定不得建议包干）｜效力类型（双方签收后生效可执行／笔录签名盖章后生效／仅合同拘束力／待司法确认／仅约束保险部分／一般无强制执行力）｜成立或生效时点（最后一方签收日／笔录签名盖章日／未签收；送达过程与已读不得起算）｜拒收效果（调解不成应及时判决／仍可另诉）｜执行力（可申请执行／仅合同须另诉或转介补强／派出所一般无）｜对侵权人余额是否仍在（默认是）｜交强险直接请求是否仍打开（被保险人单方默认不消灭）｜反悔窗口（签收前可反悔；确认或签收后难推翻；可撤销只作接口，不写死某日）｜可逆性（签收／确认后风险档A）｜状态（可比较／闸关／字段停止／不打开）｜来源回链`。一行一主持方×一文本×一分项簇。禁止一行打包「都能执行／都能反悔／建议签」。

口头报价、微信「行／已读／差不多了」、EMS 妥投只进 `V#`／`S#`，不得升格 `Med#` 已生效或期间起算。

## 节点 0　分流、立场、评估闸与不关窗

整案转出或闸关闭只交付第 1、2、10 节或标注停止的 `Med#`，不得交付接受意见，不得标评估终稿 `已形成`，不得勾选「接受」。闸部分打开时：仅对文本可回链且不含未知伤残概括弃权的行给出比较，其余行停止或不打开。

| 信号 | 处理 |
| --- | --- |
| 主成果是庭审提纲或发问策略 | 负触发 `准备人身损害庭审`；本窗只列成本时间执行风险一列 |
| 主成果是协议正文或草稿 | 负触发 `起草人身损害和解协议`；「签不签这份方案」仍留本窗 |
| 主成果是让步档、底线或未闭合报价 | 负触发 `谈判人身损害和解` |
| 主成果是保险人了结或权益转让审查 | 负触发 `审查保险一次性了结弃权`；保险调解方案效力可留本窗，印好了结书不在本窗逐句审 |
| 主成果是司法确认、调解书或赋强手续 | 负触发 `办理人身和解执行力补强`；本窗只评该不该接受及效力，不办手续 |
| 主成果是先理赔还是先诉、先调、先予执行 | 负触发 `选择诉讼调解或保险先行` |
| 只要起诉状终稿 | 负触发 `提起人身损害一审` |
| 只要测算终稿 | 负触发 `测算人身损害赔偿` |
| 已有生效调解书只要执行申请 | 负触发 `执行人身损害生效文书` |
| 执行中分期或以物抵债 | 负触发 `准备人身执行和解` |
| 纯工伤待遇或劳动调解且无第三人民事调解 | 整案转劳动；夹带对第三人法院或保险调解则本窗正触发，工伤段分流，`Med#` 可留并转介 `评估工伤与第三人侵权竞合` |
| 诊疗过错或医疗鉴定终稿 | 转医疗；对医疗机构的民事调解方案可留 |
| 海事专门调解 | 转海事 |
| 未成争只要改合同 | 审查起草本窗搁置 |

评估闸打开（可出 `Med#` 比较，仍不得标建议接受或保证能反悔）须同时满足：单方无冲突立场与授权；主成果是方案利弊／效力／反悔比较，不是协议可签终稿、让步档、保险了结审查、补强手续、庭审提纲或路径选择终稿；该行有可编号书面方案或笔录（口头／已读不能开闸写成已生效）；主持方可归入 `Med#` 类型；拟接受主文不含未知伤残、未知手术或「永不追究一切」。

闸关闭（仍正触发）：口头答应／已读要写成已生效；调解书送达即生效或拒收仍可执行；反悔写死某日或已读起算三十日；司法确认或签收后仍轻易反悔；派出所调解＝可强制执行；私下微信当司法确认已可办；保险调解消灭对侵权人余额；被保险人单方消灭交强险直接请求；未稳定包干可建议接受；保证能撤销；选定唯一法院。「保证能反悔」「包干未知伤残」本身不得开闸写成建议接受。

「保证能反悔」「包干未知伤残」「写死反悔日」「选定法院」「送达即生效」「口头已生效」「派出所可执行」「保险消灭侵权人」**不关窗**。闸未开则仍只交 1、2、10 节。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或受害人与侵权人、保险人同时交材料争同一份接受意见且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出倒签调解日期、出险日或人民调解协议落款日，伪造、假冒或补办人民调解组织或假调解笔录，指导骗保、以调解掩盖犯罪、刑事逼签，或要求产出覆盖未知伤残、未知手术或「永不追究一切」的可以放心签接受意见，then 整体停止；第一次提出即停，不以「坚持」「用户已理解」为门槛。

## 节点 1　主持方、文本形态与效力类型

效力必须分列，禁止揉成「调解书送达生效」。

**法院诉讼调解书。** 经双方当事人签收后发生法律效力，生效日以最后一方签收日为准。送达过程、邮寄回执、妥投、微信已读、拍照转发 ≠ 签收。一方拒收：调解不成，法院应及时判决，不得写成已可申请执行。当事人各方同意在调解协议上签名或盖章后即发生法律效力的，须经人民法院审查确认，不得把微信签名写成该效果。不制作调解书、记入笔录并由相关人员签名盖章即生效的，仅适用于法律列明类型，人身损害赔偿金钱给付一般仍出调解书。检索锚点：现行民事诉讼法调解书条款（2023 修正后常见第一百条、第一百零一条，须运行时核验）。条号不是 `L#`。未立案不得写成可出可执行诉讼调解书。

**人民调解协议。** 具有合同性质法律约束力，原则上不能直接申请强制执行。司法确认须依法设立的调解组织主持且双方共同申请；私下微信、当面和解、保险了结文本都不是人民调解协议。三十日是共同申请期间长度，不是请求权失权日，已读不得起算。逾期仍可就履行或内容起诉。手续转介 `办理人身和解执行力补强`，本窗不办。检索锚点：人民调解法第三十二条、第三十三条；现行民事诉讼法司法确认条款。条号不是 `L#`。

**保险调解。** 通常只约束保险部分。限额内付款默认不消灭对侵权人、用人者其余请求。被保险人单方调解不得消灭受害人交强险直接请求。印好了结或权益转让主成果转 `审查保险一次性了结弃权`。先理赔还是先诉转 `选择诉讼调解或保险先行`。

**交警或派出所损害赔偿调解。** 民事赔偿部分一般无强制执行力。交警制作的道路交通事故损害赔偿调解书不等于法院调解书。当事人提起诉讼则调解终止。事故认定加调解记录不得写成民事终局比例。不得「派出所调解后再补一个调委会」凑确认。未即时履行的治安或刑事和解，附带民事调解书另循刑事诉讼规则，本窗只打红旗并转介 `分流刑民交叉`，不写刑事和解终稿。

## 节点 2　方案拆解 `Med#`

打包一笔必须还原为项目，对照测算区间作风险，不给唯一公平价，不定残。未知金额不写零。谁付哪一笔必须可见。

鉴定闸：急救未结束、骨折未固定、内固定未取、计划内二次手术未做、烧伤未拆痂、伤残未鉴定 → 伤残赔偿金、护理依赖、后续治疗相关行只能保留另行主张，**不得建议接受包干或概括弃权**。只标「高风险」不够。鉴定闸关闭不关窗。

覆盖未知伤残、未知手术、未知护理依赖、「永不追究一切」：该 `Med#`／`W#` 停止，不得建议接受。用户理解、书面明示、坚持均不能治愈。要求把该建议写成评估结论：整体停止。

已收款、医保、工伤基金、垫付必须入账提示。隐瞒已收款以提高或压低方案：整体停止。未成年人、死亡近亲属不得由一人代全体弃权；漏列转介相应原子，该行停止。

## 节点 3　反悔窗口与执行力

反悔因类型而异，未核验不写「还能反悔到某日」。已读、截图不得起算。

- 诉讼调解：签收前反悔，法院应判决；签收后原则上不得上诉式反悔，再审口极窄，可逆性风险档 A。
- 人民调解：确认前仅合同拘束，可就履行或内容起诉；确认裁定有效后可申请执行，难推翻，风险档 A。
- 保险调解／普通协议：可撤销（重大误解、欺诈、胁迫、显失公平）只作接口，不承诺能撤销，不写唯一截止日。
- 「确认完／签收后还能轻易反悔」「保证能反悔」：该格 `现有依据不支持`，窗口不关。

执行力：单独民事和解或人民调解未确认不能直接申请强制执行，必须明示。诉讼调解书签收后可执行。派出所一般无。补强路径只点转介名，本窗不写申请草稿。不得选定唯一法院或唯一公证处。

## 节点 4　与庭审成本比较、不替用户决定

只列时间、费用、执行风险、证据灭失风险的对照，禁止胜诉率、必然责任比例、唯一必得总额。庭审策略细节转 `准备人身损害庭审`。不代替庭审策略。

不替用户决定接受。禁止「建议接受」「应当签字」「可以放心签」。第 9 节只能列选项接口（改条件／继续评估缺口／转介起草或庭审），不得把「接受」写成默认下一步。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过评估闸直接给接受意见或保证能反悔。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if C 端只要大众准备包，then 只分流不回改。

判断状态只许三值。口头转述、截图和「已读」不得写成已受理、已签收、已生效或期限已起算。事故认定书、调解记录不得单独写成民事终局比例。

## 本任务回链纪律

本任务成果是「不替用户决定接受的人身损害调解方案效力与反悔评估」。必须包含：效力分型、签收≠送达、未知伤残不得建议接受。不包含：协议正文、谈判让步表、保险了结审查终稿、确认赋强手续、庭审提纲、保险先行路径选择终稿。禁止送达即生效。禁止保证能反悔。禁止建议接受概括弃权。禁止选定法院。禁止选边治愈。禁止倒签或伪造调解组织。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标接受意见已形成。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接。
风险档 A：调解书签收或司法确认后的反悔字段必须单独标可逆性。
