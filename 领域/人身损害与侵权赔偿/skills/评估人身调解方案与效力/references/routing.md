# 边界与路由

## 正触发

面对法院调解、人民调解或保险公司调解，需要判断是否接受及效力。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 庭审准备 | `准备人身损害庭审` |
| 协议起草 | `起草人身损害和解协议` |
| 执行力补强 | `办理人身和解执行力补强` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动调解 | 劳动领域 |
| 刑事和解主轴 | 刑事领域并行 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“法官给了个调解数，签不签”正触发。“写协议”走起草。“准备开庭问什么”走庭审。
