# 边界与路由

## 正触发

面对法院调解、人民调解、保险调解或交警／派出所调解方案，需要判断效力、反悔窗口和风险。「签不签这份方案」正触发。保证能反悔、包干未知伤残、写死反悔日、选定某法院、口头答应或已读即已生效、送达即生效、派出所调解可强制执行、保险调解消灭对侵权人，仍正触发：评估闸可关，对应格停止，窗口不关。工伤待遇与对第三人法院或保险调解同时出现，仍正触发：工伤段分流劳动，对第三人 `Med#` 可留。

双方秘密、倒签调解日期、伪造人民调解组织、要求产出含未知损害概括弃权的可以放心签接受意见的停止，优先于负触发。不得改走负触发去出一方接受意见。保证能反悔、包干未知伤残不在下表。倒签伪造不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 庭审提纲或发问策略 | `准备人身损害庭审` |
| 和解协议正文或草稿 | `起草人身损害和解协议` |
| 让步档、底线或未闭合报价方案 | `谈判人身损害和解` |
| 保险人了结或权益转让文本审查 | `审查保险一次性了结弃权` |
| 司法确认、诉讼调解书或公证赋强手续 | `办理人身和解执行力补强` |
| 保险理赔、调解、起诉、先予执行哪条更适配 | `选择诉讼调解或保险先行` |
| 起诉状终稿 | `提起人身损害一审` |
| 分项测算终稿 | `测算人身损害赔偿` |
| 已有生效调解书的强制执行申请 | `执行人身损害生效文书` |
| 执行中分期或以物抵债 | `准备人身执行和解` |
| 纯工伤待遇或劳动调解且无第三人民事调解 | 劳动领域 |
| C 端只要大众准备包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「把调解日期倒签到上周」「公章用某社区人民调解委员会做成已调解」「两边材料都给你选边出该不该签」不在本表，走整体停止。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 仅工伤待遇或劳动调解且无第三人民事调解 | 劳动领域 |
| 诊疗过错或医疗鉴定终稿 | 医疗医药领域；对医疗机构的民事调解方案可留 |
| 海事专门调解 | 海事领域 |
| 指导倒签、伪造调解组织、骗保或以调解掩盖犯罪 | 整体停止 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。对第三人法院或保险调解可留。

| 信号 | 转介 |
| --- | --- |
| 条件未谈只要档位底线 | `谈判人身损害和解` |
| 谈拢后要协议正文 | `起草人身损害和解协议` |
| 保险人印好了结书 | `审查保险一次性了结弃权` |

## 易混

「法官给了个调解数，签不签、签了还能不能反悔」正触发。「协议还没写」走起草。「还在谈底线」走谈判。「保险公司拿来一份印好的了结书」走弃权审查。「要去法院确认或赋强」走补强。「先理赔还是先起诉」走保险先行选择。「准备开庭问什么」走庭审。「鉴定还没出，八万包干今后伤残永不追究，送达就算生效，保证还能反悔，材料交到某区法院」仍正触发；评估闸关；送达 ≠ 签收；不得建议接受概括弃权；不保证能反悔；不选定法院。「工伤还在认，法院同时调司机和交强险」正触发，对第三人方案可留，工伤段分流。「两边材料都给你，选边告诉我们该不该接受」整体停止。
