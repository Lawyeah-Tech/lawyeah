# 输出合同

按触发结果选择交付形状。评估闸未打开不得交付接受意见或保证能反悔。禁止调解书送达即生效。禁止口头答应或已读写成已生效。禁止写死反悔日历截止。禁止选定唯一法院。禁止建议接受覆盖未知伤残的概括弃权。禁止派出所调解写成可强制执行。禁止保险调解写成消灭对侵权人全部请求。禁止被保险人单方消灭交强险直接请求。禁止胜诉率。禁止未知金额写零。禁止选边治愈。禁止倒签或伪造调解组织步骤。不代签署。不定残。不保证能反悔。不替用户决定接受。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 评估闸关闭或节点 0 整案转出 | 第 1、2、10 节：关闭理由、效力待核和最小补证。可附标注停止的 `Med#`。禁止接受意见、保证能反悔、唯一截止日。对第三人调解可留时不得因工伤整案转出 |
| 整体停止 | 第 1、10 节。禁止 `Med#` 接受包、选边、倒签或伪造调解组织方法。双方秘密、倒签调解日期、伪造人民调解组织、要求产出含未知损害概括弃权的可以放心签接受意见第一次即停，优先于负触发；无选边治愈，无「坚持」或「用户已理解」门槛 |
| 用户要保证能反悔、包干未知伤残、写死反悔日、选定某法院、送达即生效、口头已生效（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；闸未开则仍只交 1、2、10；不得改走负触发关窗；成果不得标接受意见 `已形成` 或保证能反悔 |
| 正触发且闸开（可部分开） | 下列十节表头均出现；生效时点、反悔规则、确认期间未核验的单元格填 `依据不足，无法形成结论` 或 `待核`；主持方分列；禁止为填满而宣布建议接受、送达即生效或保证能反悔 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入接受意见已形成。双方秘密未解不得进入「部分形成」。每个 `Med#` 必须带来源和三值判断。`L#` 不得直接抄技能内条号。送达即生效、口头已生效、保证能反悔若返回则记噪声。稿件状态默认 `草案`。

## 1. 触发、单方立场、授权与成果状态

评估闸开、部分开或关。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。稿件默认 `草案`。不代签署。不替用户决定接受。

## 2. 来源登记与 MCP 调用表

`S/D/R/C/L/I/G/Med/W/V`。口头差不多了、已读、妥投只登记 `S#`／`V#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 评估闸与主持方分型

法院／人民调解／保险／交警或派出所分列。口头已读不得升格。工伤夹带第三人可留。

## 4. 方案拆解 `Med#`

打包须还原项目。付款人分列。未知不写零。鉴定闸关闭不得建议包干。覆盖未知伤残则该行停止。

## 5. 效力类型：签收 ≠ 送达

诉讼调解书双方签收生效，最后一方签收日。送达过程 ≠ 签收。拒收＝调解不成。人民调解仅合同拘束力。保险通常只约束保险部分。派出所一般无强制执行力。

## 6. 反悔窗口

未核验不写截止日。已读不得起算。签收或确认后难推翻。可撤销只作接口，不承诺能反悔。保证能反悔该格不支持。

## 7. 弃权、交强险直接请求与余额

对侵权人余额默认仍在。被保险人单方不得消灭受害人交强险直接请求。未知伤残默认保留。

## 8. 执行力红旗与补强转介

单独协议不能直接执行必须明示。手续转介 `办理人身和解执行力补强`，本窗不办。不选定法院。

## 9. 与庭审成本比较和下一步接口

只列时间、费用、执行风险。无胜诉率。不代替庭审策略。不得把「接受」写成默认下一步。转介起草、谈判、庭审、一审、测算只点名。

## 10. 缺口、停止项与提示

须列对方最强解释：调解书送达或妥投即生效、拒收仍可执行、口头答应或已读已经生效、还能反悔到某日、三十日过了就没权利、司法确认后仍可轻易反悔、派出所笔录可直接执行、保险调解消灭对司机全部请求、被保险人签字受害人不能再向交强险要、伤残未出包干可以放心签、私下微信可司法确认、建议接受永不追究、选某法院起诉一定能撤、选边即可继续、倒签日期或补一个调解组织就能确认、工伤在认所以对司机的法院调解不用评。

本成果不是接受意见、不是可签协议、不是确认申请、不是庭审提纲、不是保险了结审查、不是路径选择终稿、不保证能反悔、不是唯一截止日。不代签署。不替用户决定接受。
