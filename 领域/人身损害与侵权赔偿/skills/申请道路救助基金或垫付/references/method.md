# 救助基金方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。接口状态只用 `打开`、`不打开`、`待核`。申请状态只用 `草案`、`待递交`、`停止`。禁止胜诉率、必得拨付额、选定法院、自行宣布伤残等级、唯一截止日。未知金额不写零。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文、已失效《合同法》、2009 年救助基金管理试行办法七十二小时口径、已废止交强险十一万或一万，或把基金写成全残必得、基金已付等于全部民事责任消灭、把七日写成全国唯一申请或拨付截止日时记为噪声。

`A#` 固定列：`编号｜入口袋（交强险垫付/救助基金，禁止一行混袋）｜垫付项目（抢救费/丧葬费）｜情形（逃逸/未投保/超交强险医疗限额，待核）｜申请人（医院/受害人/近亲属，分行）｜控制方｜材料缺口｜判断｜待核｜来源回链`。一行一袋一项。

## 节点 0　分流、立场、申请闸与不关窗

整案转出或闸关闭只交付第 1、2、10 节，不交 `A#` 终稿、必拨承诺或诉状。

| 信号 | 处理 |
| --- | --- |
| 保单齐全、只要常规索赔材料包 | 负触发 `准备交强险商业险索赔材料` |
| 只要分账或限额内必得 | 负触发 `评估道路交通事故责任与保险先行` / `测算人身损害赔偿` |
| 只要侵权人不明总路径 | 负触发 `评估侵权人不明路径` |
| 只要起诉状 | 负触发 `提起人身损害一审` / `直接起诉保险公司` |
| 只要认定复核 | 负触发 `复核交通事故认定` |
| 只要先予执行医疗费 | 负触发 `申请先予执行医疗费` |
| 只要拒赔拆解 | 负触发 `应对保险拒赔减赔` |
| 非道路且与机动车无关的普通侵权 | 负触发 |
| 主轴仅工伤待遇且无第三人机动车 | 整案转劳动；夹带第三人机动车则本窗正触发，工伤段分流，垫付袋可留并转介 `评估工伤与第三人侵权竞合` |
| 海事救助 | 转海事 |
| 未成争改合同 | 审查起草搁置 |

申请闸打开条件（同时满足）：单方无冲突立场与授权；机动车道路交通事故或机动车通行已发生；至少一袋入口可指称；抢救费或丧葬费已发生或可编目。无抢救费、无丧葬费不得默认打开基金。不得以「今天必须交」「七日内必须拨付」开闸。

道路以外机动车（含停车场通行）：交强险垫付袋可待核；基金袋待核，不得仅因停车场一律负触发关窗。

「保证拨付」「残疾金写入基金」「七日唯一截止」**不关窗**。闸未开则仍只交 1、2、10 节。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或受害人与保险人、基金管理机构、医院同时争同一垫付包且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出虚构逃逸、伪造未投保、伪造费用套取垫付、顶包改认定、威胁或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　入口袋与情形

交强险保险公司垫付抢救费用与救助基金垫付是两条入口，禁止混成「都能要」。

交强险垫付袋：保险人已查明，且表面属于交强险抢救费用垫付或先赔后追偿口径（检索锚点：交强险条例关于未取得驾驶资格、醉酒、盗抢期间、被保险人故意等垫付抢救费用）。本窗只编该垫付最小材料，不写常规理赔 `M#` 全包。保单齐全、正常三者人身损害走索赔材料窗。

基金袋：检索锚点：道路交通安全法关于救助基金；交强险条例第二十四条；《道路交通事故社会救助基金管理办法》（第107号，2022年1月1日施行）第十四条。表面具备下列之一才打开：抢救费用超过交强险责任限额；肇事机动车未参加交强险；机动车肇事后逃逸。三项分列待核，禁止合成「逃逸所以全残基金必得」。逃逸车辆若已查明仍投保交强险，保险人可能仍在限额内赔偿，基金与交强险衔接待核，禁止写成逃逸则交强险一毛不赔、只能走基金。

## 节点 2　垫付项目开闭

基金垫付项目仅：人身伤亡的丧葬费用、部分或全部抢救费用。残疾赔偿金、误工、护理、精神损害填 `不打开` 或 `现有依据不支持`。用户要基金覆盖全残：该格不支持，窗口不关。

一般垫付受害人自接受抢救之时起七日内的抢救费用；特殊情况超过七日须医疗机构书面说明。七日是费用期间口径，禁止写成全国唯一申请截止日或必拨日。2009年试行办法七十二小时是噪声。具体额度、分级审核、丧葬费用上限以核验后的办法和当地细则为准，未核验则金额字段停止，禁止写零冒充已拨。

医保、工伤基金、交强险已付医疗费单列扣减。超医疗限额：仅超额抢救费可进基金袋，不得把全案医疗费并入。

2022年办法垫付对象含本车人员和被保险人，相对2009试行办法扩大；是否打开须核验，不得凭记忆排除或当然纳入。

## 节点 3　材料与当地程序

当地管理机构名称、账号、表格、审核时限以核验或用户材料为准，不得编造。材料不足列出缺口，闸开时可出 `草案`，不得升 `已提交`。交警书面通知基金管理机构、医疗机构申请抢救费、近亲属申请丧葬费：只标接口开闭和待核材料，不写交警内部通知终稿。口头「交警说可以走基金」、已读不得写成已受理或已拨付。不代提交。

---

## 节点 4　追偿返还与转介

基金垫付后有权向道路交通事故责任人追偿。权利人嗣后从侵权人或保险人获得同一抢救费或丧葬费的，可能需返还已垫付部分。禁止指导领取基金后再向侵权人全额重复主张同一抢救费或丧葬费。残疾赔偿金、精神损害、误工等其余项目不因垫付消灭。禁止写成「基金已付则全部民事责任消灭」。工伤基金追偿与救助基金追偿分列。

不替代侵权诉讼。诉状转 `提起人身损害一审`。找不到人怎么告转 `评估侵权人不明路径`。测算扣减转 `测算人身损害赔偿`。先予执行转 `申请先予执行医疗费`。逃逸刑责只打红旗，本窗不定罪。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过申请闸直接给待提交终稿或必拨承诺。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if 金额参数不足，then 该行标未知，禁止写零。
若 if C 端只要大众准备包，then 只分流不回改。

判断状态只许三值。口头转述、截图和「已读」不得写成已受理、已送达、已拨付或期限已起算。

## 本任务回链纪律

本任务成果是「交强险抢救垫付或救助基金垫付申请包」。不包含：保险索赔材料包终稿、分账、拒赔拆解、侵权人不明总路径、测算数字、起诉状、先予执行终稿、认定复核、工伤待遇核定、必得拨付额。禁止保证拨付。禁止残疾金写入基金。禁止虚构逃逸。禁止选边治愈。禁止编造机关名称。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标待提交终稿已形成。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接。
风险档 A：不可逆文书或期限字段必须单独标可逆性。
