# 输出合同

按触发结果选择交付形状。申请闸未打开不得交付待提交终稿。禁止保证拨付。禁止把残疾金、误工、精神损害写入基金。禁止把七日写成全国唯一申请或拨付截止日。禁止2009年七十二小时口径。禁止混成交强险垫付与基金都能要。禁止编造当地管理机构名称、账号或表格。禁止同一抢救费双领。禁止写成基金已付则全部民事责任消灭。禁止选边治愈。禁止虚构逃逸方案。不代提交。不选定法院。不定残。不替代侵权诉讼。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 申请闸关闭或节点 0 整案转出 | 第 1、2、10 节。禁止 `A#` 终稿、必拨承诺、诉状。第三人车辆垫付可留时不得因工伤整案转出 |
| 整体停止 | 第 1、10 节。禁止申请草稿、选边、虚构逃逸步骤。双方秘密、同时争同一垫付包、虚构逃逸或伪造费用时，整体停止优先于负触发；第一次提出即停，无选边治愈，无「坚持」门槛 |
| 用户要保证拨付、残疾金写入基金或七日唯一截止（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；闸未开则仍只交 1、2、10；不得改走负触发关窗；成果不得标 `已形成` |
| 正触发且闸开 | 下列十节表头均出现；开闭条件、七日口径、机关路径、追偿未核验填 `依据不足，无法形成结论` 或 `待核`；禁止为填满而宣布必拨或残疾金进基金 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。双方秘密未解不得进入「部分形成」。每个 `A#` 必须带来源、入口袋、项目和判断三值。`L#` 不得直接抄技能内条号。七十二小时、基金全残必得、基金已付民事责任消灭若返回则记噪声。申请状态默认 `草案` 或 `待递交`。

## 1. 触发、单方立场、授权与成果状态

申请闸开或关。医院申请人与近亲属分列。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。

## 2. 来源登记与 MCP 调用表

事故证明、费用、逃逸或未投保表面分列。口述逃逸、交警说可以走基金只登记 `S#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 申请闸、入口袋与情形

交强险垫付袋与基金袋分行。基金情形：逃逸、未投保、超医疗限额。禁止混袋。道路以外基金待核。保单齐全常规理赔不在本窗做全包。

## 4. `A#` 申请行

固定列全填。一行一袋一项。未知费用不写零。不因对方控制推定材料有利。

## 5. 垫付项目开闭

抢救费、丧葬费才可能打开。残疾、误工、护理、精神 `不打开`。七日是费用期间口径。超七日须医疗机构书面说明待核。用户要基金覆盖全残：该格不支持，窗口不关。

## 6. 材料与当地程序待核

身份、事故证明、诊断、费用、账户、当地表格。不编造机关、账号与全国统一格式。不把当地审核时限写成法定唯一截止。交警书面通知只标接口。

## 7. 追偿、返还与禁止双领

基金向责任人追偿。权利人嗣后获赔可能返还垫付部分。禁止指导领基金后再向侵权人全额重复主张同一抢救费或丧葬费。其余民事请求不消灭。工伤追偿分列。

## 8. 最强异议

保证拨付、残疾金进基金、七日必拨、口头逃逸即打开基金、选边即可继续、交了申请就必得、逃逸则交强险当然不赔、基金已付则不能再起诉。

## 9. 禁止事项与转介

只点名：材料包、分账、测算、不明路径、诉状、先予执行、认定复核、拒赔、工伤竞合、死亡权利人。不写那些终稿。不选定法院。不代提交。

## 10. 缺口、停止项与提示

须列对方最强解释与证据缺口。本成果不是材料包、分账、不明路径总图、诉状、测算、工伤待遇或认定复核。不代提交。不保证拨付。
