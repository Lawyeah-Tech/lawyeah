# 边界与路由

## 正触发

机动车道路交通事故已发生抢救费用或丧葬费用，需要交强险保险公司垫付抢救费用，或表面符合救助基金垫付（超过交强险限额、未投保、逃逸）。无书面通知仍正触发，闸可关。道路以外机动车事故：交强险垫付袋可待核，基金袋待核。工伤与第三人机动车同时出现，仍正触发：工伤段分流，垫付袋可留。用户要保证拨付、把残疾金写入基金或把七日写成唯一截止仍正触发。

双方秘密、同时争同一垫付包、虚构逃逸、伪造费用的停止，优先于负触发。不得改走负触发去出申请稿。保证拨付不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 保单齐全的常规交强险或商业三者索赔 | `准备交强险商业险索赔材料` |
| 道路交通分账或限额内必得数字 | `评估道路交通事故责任与保险先行` / `测算人身损害赔偿` |
| 侵权人不明总路径或怎么告 | `评估侵权人不明路径` |
| 起诉状 | `提起人身损害一审` / `直接起诉保险公司` |
| 认定复核 | `复核交通事故认定` |
| 先予执行医疗费 | `申请先予执行医疗费` |
| 拒赔拆解 | `应对保险拒赔减赔` |
| 非道路且与机动车无关的普通侵权 | 负触发 |
| 纯车损无人身 | 负触发 |
| C 端只要大众准备包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「保证拨付」「残疾金写入基金」不在本表。停车场机动车不得仅因非道路一律关窗。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 仅工伤待遇且无第三人机动车 | 劳动领域 |
| 海事救助 | 海事领域 |
| 指导虚构逃逸套取基金 | 整体停止；刑事只打红旗，不得用来出策略 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。第三人车辆垫付袋可留。

## 必转介接口

| 信号 | 转介 |
| --- | --- |

## 易混

「肇事逃逸，抢救费没人出」正触发。「保单齐全只是还没报案」走保险索赔，不得默认走基金。「帮我把侵权人告了、找不到人怎么办」走起诉或不明路径。「保证一周内拨付，残疾金也走基金」仍正触发，保证拨付格与残疾金格不支持。「停车场撞人，不是道路所以基金没有」正触发，基金袋待核，不得一律关窗。「两边材料都给你，代表我们出基金申请，逃逸证明可以补」整体停止。
