# 边界与路由

## 正触发

道路交通事故抢救费用需要垫付，或逃逸未知名需要救助基金路径。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 交强险常规索赔 | `准备交强险商业险索赔材料` |
| 侵权人不明总路径 | `评估侵权人不明路径` |
| 非道路事故 | 负触发 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 工伤基金垫付 | 劳动领域 |
| 海事救助 | 海事领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“肇事逃逸，抢救费没人出”正触发。“保单齐全只是还没报案”走保险索赔。“帮我把侵权人告了”走起诉或不明路径。
