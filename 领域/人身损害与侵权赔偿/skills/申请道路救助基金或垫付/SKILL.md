# 申请道路救助基金或垫付

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的权利人立场下，形成垫付申请包：申请闸、`A#` 行（入口袋交强险垫付或救助基金、垫付项目抢救费或丧葬费、情形、材料缺口、判断、待核）、追偿与返还提示。不保证拨付。不替代对侵权人或保险人的其余请求。不代提交。不编造当地管理机构名称、账号或表格。不写保险索赔材料包终稿、分账、侵权人不明总路径或起诉状。

`depends-on` 为空。保单齐全的常规理赔转 `准备交强险商业险索赔材料`。分账转 `评估道路交通事故责任与保险先行`。找不到人怎么告转 `评估侵权人不明路径`。诉状转 `提起人身损害一审`。

## 工作边界

正触发：机动车道路交通事故已发生抢救费用或丧葬费用，需要交强险保险公司垫付抢救费用，或符合救助基金垫付表面（抢救费用超过交强险限额、肇事机动车未参加交强险、机动车肇事后逃逸）。无书面通知仍正触发，闸可关。道路以外机动车事故：交强险垫付袋可待核打开，基金袋待核，不得仅因停车场一律关窗。工伤与第三人机动车同时出现：本窗正触发，工伤段分流劳动，垫付袋可留。用户要「保证拨付」「把残疾金精神损害写入基金」「七日必须拨付」仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 保单齐全、只要常规交强险或商业三者索赔材料包（转 `准备交强险商业险索赔材料`）；
- 只要分账或限额内必得数字（转 `评估道路交通事故责任与保险先行` / `测算人身损害赔偿`）；
- 只要侵权人不明总路径或怎么告（转 `评估侵权人不明路径`）；
- 只要起诉状（转 `提起人身损害一审` / `直接起诉保险公司`）；
- 只要认定复核（转 `复核交通事故认定`）；
- 只要先予执行医疗费（转 `申请先予执行医疗费`）；
- 只要拒赔拆解（转 `应对保险拒赔减赔`）；
- 非道路且与机动车无关的普通侵权；
- 纯车损无人身；
- C 端只要大众准备包（只分流）；
- 未成争改合同（审查起草搁置）。

「保证拨付」「残疾金写入基金」不在负触发表。

## 建立工作坐标

确认：使用者与授权；单方立场；是否机动车道路交通事故；抢救医院与已发生费用；是否逃逸、未投保或超交强险医疗限额表面；交强险保险人是否已查明；死亡与丧葬线索；当地救助基金管理机构线索（待核，不编造）；法域。

口头「交警说可以走基金」、已读只登记 `S#`。不得写成已受理、已拨付或期限已起算。

同时掌握双方秘密，或受害人与保险人、基金管理机构、医院同时争同一垫付包：`整体停止`，不得以选边治愈，也不得改走负触发去出申请稿。提出虚构逃逸、伪造未投保、伪造费用套取基金或垫付：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 病历、费用清单、事故证明；`R#` 交警文书；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`A#` 申请行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。接口状态只用 `打开`、`不打开`、`待核`。申请状态只用 `草案`、`待递交`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。本任务默认 `草案` 或 `待递交`，不执行递交。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：道路交通安全法关于抢救费用与救助基金垫付追偿；交强险条例第二十四条（超过限额、未投保、逃逸时垫付丧葬费用和抢救费用，基金追偿）；《道路交通事故社会救助基金管理办法》（财政部等令第107号，2022年1月1日施行）一般自接受抢救起七日内、超过七日须医疗机构书面说明，垫付对象含本车人员和被保险人。交强险保险公司垫付抢救费用与基金分袋。技能正文条号不是 `L#`。噪声：2009年试行办法七十二小时口径、已失效《侵权责任法》、已废止交强险十一万或一万、把基金写成全残必得、基金已付等于全部民事责任消灭、把七日写成全国唯一申请或拨付截止日。不可用则开闭条件、七日口径、对象范围、追偿效果、机关路径字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变入口、范围或七日口径的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补保险人垫付与基金衔接、医院代申请、当地表格差异、不保证拨付、口头逃逸不等于基金已打开的实务反例。
- `search_template` 只借申请栏目，不把范本当法定格式，不编造当地管理机构名称或表格。

工具不可用时继续编目事故、费用和保单表面；法律效果字段停止。不得凭记忆写必拨、机关名或唯一截止日。

## 判断节点

执行顺序和停止条件以 [救助基金方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、申请闸与不关窗

工伤三段分流，第三人垫付袋可留。错误主张不关窗。双方秘密或虚构逃逸第一次停。

### 2. 入口袋与情形

交强险垫付袋与基金袋分行。基金情形：超限额、未投保、逃逸。禁止混成都能要。保单齐全常规理赔转索赔材料窗。

### 3. 垫付项目开闭

抢救费、丧葬费才可能打开。残疾金、误工、精神损害不打开。七日是费用期间口径，不是唯一截止日。

### 4. 材料与当地程序

不编造机关、账号、表格。草稿待递交。交警书面通知只标接口。

### 5. 追偿返还与转介

禁止同一抢救费双领。其余民事请求不因垫付消灭。不替代诉讼。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；受害人与保险人、基金或医院同时争同一垫付包；提出虚构逃逸、伪造未投保、伪造费用套取垫付。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：垫付范围、申请机关、七日口径、追偿规则、当地程序未核验。用户要保证拨付、残疾金写入基金或唯一截止日则该格停止，窗口不关。
- `目标停止`：主目标变为索赔材料包、分账、不明路径总图、起诉状、测算、认定复核或先予执行终稿。保证拨付不在目标停止。

禁止指导虚构逃逸或伪造费用。不给胜诉率。不选定法院。不定残。不代提交。不保证拨付。不编造机关名称。
