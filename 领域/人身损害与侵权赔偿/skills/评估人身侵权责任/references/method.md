# 评估人身侵权责任方法

本文件是可执行判断节点。构成侵权不是伤残已定。构成侵权不是项目必得。认定书不是民事终局比例。口头或已读不是已送达。无责不是关闭交强险。先按十级不是开鉴定闸。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已构成侵权、应起诉、唯一必得总额、选定法院、代提交、未知写零。本任务不定罪，不定残，不写发送版索赔函、鉴定申请或诉状。本窗闸名只能是侵权闸，禁止复用争议闸、评估闸、鉴定闸、发送闸、起诉闸、答辩闸、管辖闸、精算闸、案卷闸、和解闸。预留不得占用：立案闸、鉴定闸、发送闸、起诉闸、精算闸。本窗 `QG#` 是侵权总图行。主路径只用 `Q-责`，禁止用 `Q-总`、`Q-侵`、`Q-诉`、`Q-测`、`Q-过` 作主路径。英文 id 禁止使用，一律用中文技能名 `评估人身侵权责任`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文、民法通则第一百零六条、交强险旧限额、把认定书写成民事终局或把构成侵权写成项目必得时记为噪声。禁止指导伪造伤情、隐匿既往或倒签。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现侵害碎片扫描，不是默认闭集。
`QG#` 固定列：`编号｜侵害切片｜请求抗辩｜论坛期限｜金额接口｜打开接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「侵权责任」一笔。无 `E#` 不得写已构成侵权、已送达或应起诉。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-责`。禁止 `ZT#`、`A#`、`M#`、`EV#`、`PTY#`、`N#`。`Q-过` 至 `Q-抗` 只作侵害切片或打开接口标签，不是主路径。

口头「已经构成侵权了」「先按十级」「认定书就是三七开」只进 `S#`／`V#`，**不得单独算作开闸材料**。已读不得升格已送达。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：过错、过错推定、无过错分列，法律规定才推定或无过错。认定书是证据不是民事终局比例。交强险不因无责关闭。被扶养人生活费计入两金，禁止双计必得。未稳定不得启动评残。

## 节点 0　分流、立场、侵权闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造伤情、隐匿既往、倒签、违法取证不进负表。利益冲突未解不进整体停止。不写发送版函、不定残、不选定法院不是负触发。

整案转出只交付第 1、2、10 节，不出 `QG#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是主体保险表终稿 | 负触发 `评估责任主体与保险覆盖` |
| 主成果是时效表终稿 | 负触发 `评估人身损害诉讼时效` |
| 主成果是管辖连结点终稿或异议书 | 负触发 `评估人身损害管辖` 或 `提出人身案件管辖异议` |
| 主成果是交强险或商业三者分账终稿 | 负触发 `评估道路交通事故责任与保险先行` |
| 主成果是发送版索赔函 | 负触发 `准备侵权索赔通知` |
| 主成果是伤残鉴定申请终稿 | 负触发 `准备伤残鉴定材料` |

| 主成果是诊疗过错／病历／医疗鉴定 | 整案转医疗医药 |

混合信号：工作中被第三人撞伤、车祸后就医，民事总图可留，专项段只分流。出现「保险」「鉴定」「起诉」一词不是转出。

侵权闸打开（可出 `QG#` 草案，仍不得标「已构成侵权／伤残已定／应起诉／必得总额」）须同时满足：单方无冲突立场已闭合；主成果是侵权总图，不是函、不是鉴定申请、不是诉状；至少一项可编号侵害、认定书、病历、保单或程序碎片。口头「已经构成侵权了」不算单独开闸材料。

侵权闸部分打开：已有碎片，但归责、送达、限额或治疗稳定未闭合；对应格待核；仍交十节。无书面评估授权但单方立场已闭合且已有碎片：侵权闸部分打开，仍交十节，不是整体停止。

侵权闸关闭（仍正触发）：无一可编号碎片。「今天必须出已构成侵权／应起诉／十级终稿」而无最小碎片不得开闸。不出 `QG#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `QG#` 终稿，**第 7 节不得出索赔函、鉴定申请或诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「构成侵权即伤残已定」「构成侵权即项目必得」「认定书即民事终局」「已读即已送达」「无责即关交强险」「先按十级」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `QG#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 侵权闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造伤情、隐匿既往、倒签出险或鉴定日、违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 3　总图行 `QG#`

按已出现侵害切片扫描，不是默认闭集。每条须能指向侵害、请求抗辩或论坛接口之一。

无 `E#` 不得写已构成侵权、已送达或应起诉。状态 `草案`。一次只推荐下一步。未知金额不写零，不输出唯一必得总额。

热冲突强制处理：

- 构成侵权即伤残已定／构成侵权即项目必得／认定书即终局／已读即送达／无责即关交强险／先按十级／未知写零 → 该格不支持或字段停止；仍出其他 `QG#`。
- 无一碎片 → 关闸，不出 `QG#` 终稿，窗口不关。
- 指导伪造伤情、隐匿既往、倒签 → 整体停止，不是该格不支持。

## 节点 4　主体保险、鉴定、管辖与诉讼接口

第 7 节只开接口，不得夹带 `QG#` 终稿、索赔函、鉴定申请或诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待侵害编号」，不得补写已构成侵权或应起诉。期限分列，不混算，不写唯一截止日。不选定法院。不代提交。未稳定不得转介启动鉴定。

下一步只转介：`评估责任主体与保险覆盖`、`评估人身损害诉讼时效`、`评估人身损害管辖`、`测算人身损害赔偿`、`建立人身损害证据案卷`、`准备侵权索赔通知`、`准备伤残鉴定材料`、`评估道路交通事故责任与保险先行`、`评估工伤与第三人侵权竞合`、`提起人身损害一审`、`应对人身损害一审`、`谈判人身损害和解`、`选择人身损害违约侵权竞合路径`、`分流刑民交叉`。禁止此致某院。

若 if 用户催促「已经侵权就算十级了／认定书就是终局／无责就别找交强险／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：机动车事故有认定书和急诊病历，治疗未相对稳定。用户主张认定书三七开就是民事终局、已经构成侵权就按十级谈、无责一方交强险关掉、去某区法院告、不清楚的误工先写零。侵权闸打开或半开。`Q-认`、`Q-残`、`Q-必`、`Q-院`、`Q-零` 不打开为可靠路径。鉴定启动不打开。第 6 节不得把终局比例、十级、必得、0 写入可执行 `QG#`；对应格 `现有依据不支持` 或字段停止；仍出侵害分列、交强险顺序红旗、金额接口、稳定条件缺口等其他 `QG#`。不关窗。不写诉状。不选定法院。不定残。

场景②：用户同时交出己方「对方全责必须十级」与对方「受害人既往伤病」口径，并指导「把病历改成没有既往、出险日改到上周」。命中双方秘密＋伪造＋倒签＋隐匿既往。第一次整体停止。只交第 1、10 节。不出 `QG#`。不得问代表哪一方后继续。不以「坚持」为门槛。
