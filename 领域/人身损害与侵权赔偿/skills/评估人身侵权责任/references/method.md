# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然责任比例或唯一必得总额。

`search_law` 返回已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜关系假设｜提出方｜相对方｜法律效果｜成立条件｜支持事实｜不利事实｜控制方｜最强反方｜主备位｜判断｜待核`。

医疗费、误工、护理、残疾赔偿金、死亡赔偿金、精神损害分列。同一事实支持多项时分别说明效果，不重复金额。构成侵权不等于项目必得。

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填总体评估十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 主成果是工伤认定、劳动能力鉴定、停工留薪或工伤待遇 | 劳动领域 |
| 主成果是诊疗过错、病历真实性或医疗损害鉴定 | 医疗医药领域 |
| 海上货物、船舶碰撞、海上人身伤亡专门责任 | 海事领域 |
| 尚未发生损害，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

混合信号：工作中被第三人撞伤，民事请求可留本任务，工伤三段只分流；就医记录作为损害证据可留，诊疗过错争点转医疗。铁路运输法院或海事法院专属红旗单列，不硬做成普通民诉结论。

## 节点 1　主体、材料版本和程序状态

1. 主体表记录受害人、近亲属、行为人、车辆或物件控制人、用人者、场所经营者管理者、产品生产者销售者、交强险与商业三者保险人。名称不一致不自动合并。
2. 材料表固定事故认定书、保险单、病历、鉴定、调解记录的版本。冲突并列，不选对用户有利的一版冒充唯一事实。
3. 程序表逐动作记录报警、保险报案、鉴定、协商、诉讼或执行：机关/机构、案号、文书、作出日、收到日、送达方式和效力凭证。口头转述、截图、“已读”不得写成已受理、已送达或期限已起算。
4. 事故认定书、调解记录或垫付收据不得单独写成责任已成立或比例已终局。
5. 同时掌握双方秘密或立场不明：整体停止策略输出。

## 节点 2　归责路径与请求抗辩

每个 `Q#` 先写法律效果，再写成立条件。禁止合成“侵权责任”一笔。

默认主位候选按事实分别建立，不得预先锁定某一特殊侵权：

- `Q-过` 一般过错责任（民法典第一千一百六十五条，须运行时核验）
- `Q-用` 用人者责任或提供劳务（第一千一百九十一条至第一千一百九十三条）
- `Q-场` 场所或群众性活动安全保障及第三人补充责任（第一千一百九十八条）
- `Q-产` 产品责任
- `Q-交` 机动车交通事故与交强险先行（第一千二百零八条至第一千二百一十三条）
- `Q-物` 动物、物件脱落、高空抛物、施工地面地下
- `Q-金` 第一千一百七十九条项目（医疗、护理、交通、营养、住院伙食、误工、辅助器具、残疾或死亡赔偿金、丧葬费）
- `Q-精` 精神损害赔偿（第一千一百八十三条）
- `Q-抗` 受害人过错、第三人原因、自甘风险、时效、管辖

单位或被请求方立场：逐项回应对方已知主张，并列己方最强抗辩，不把反诉写成已经提起。

场所安保不得凭 2003 年解释第六条写成过错推定。依法应参加工伤统筹的劳动者向用人单位主张民事赔偿：现有依据支持转劳动告知，不在本任务出具工伤待遇结论。因用人单位以外的第三人侵权：第三人民事请求可留。

主备位和互斥必须可见。`Q-场` 补充责任不得与第三人全部连带混写。精神损害与交强险优先赔偿只标接口，不在本任务做保险分配终稿。

## 节点 3　保险先行、论坛和期限

本节点只判断路径，不生成发送版索赔通知、鉴定申请或诉状。

### 3.1 保险分账

机动车一方责任时，先交强险限额，再商业三者约定，仍不足由侵权人（第一千二百一十三条）。被侵权人请求交强险优先赔偿精神损害，解释支持，但本任务只标接口。未投保交强险：投保义务人在限额范围内的责任须运行时核验侵权责任编解释（一），不得凭记忆写条号。

### 3.2 论坛

普通人身损害诉讼入口为侵权行为地或被告住所地。出现有效仲裁条款（客运、旅游等）时不得直接写应起诉，转介管辖原子。海事、铁路运输专属红旗不得忽略。

### 3.3 期限分类型

| 类型 | 规则锚点 | 本任务允许的输出 | 禁止 |
| --- | --- | --- | --- |
| 诉讼时效 | 第 188 条一般为三年；自知道或应当知道权利受损及义务人 | 起算事件、备选起算、中断候选 | 唯一截止日；事故日当然起算 |
| 事故认定复核 | 运行时核验道交规定 | 红旗和转介 | 把复核期写成民事时效 |
| 鉴定异议 | 运行时核验程序规则 | 已有鉴定时标红旗 | 在评估里写异议截止日期充法律意见 |
| 答辩／上诉 | 程序法 | 已进入程序时标红旗 | 用三年时效去算答辩期 |

日期冲突、知悉日不明、义务人后查明：并行情景 + 字段停止。

## 节点 4　金额区间

本任务只建区间和接口，不替代测算原子。

1. 分项：医疗费、护理费、交通费、营养费、住院伙食补助、误工、辅助器具、残疾赔偿金、死亡赔偿金、丧葬费、精神损害。未知不写零。
2. 被扶养人生活费计入残疾赔偿金或死亡赔偿金，禁止双计必得。
3. 2022-05-01 后发生的侵权，不得使用农村标准压低残疾／死亡赔偿金。就高标准须权利人举证住所地或经常居住地。
4. “上一年度”是一审法庭辩论终结时的上一统计年度，咨询日统计值只作情景，不写成已核定。
5. 医保、交强险、对方垫付、工伤基金已付医疗费逐笔扣减接口，同一票据不得重复主张。
6. 伤残未鉴定：残疾赔偿金行标 `无法估计`，转介鉴定原子，不编造十级或系数。

程序动作记录机关、案号、文书、作出、收到、送达、效力。期限每行只对应一种期间类型和一个起算事件。

固定列：项目、性质、期间、参数、来源、已付、未知、互斥／抵扣、范围、专项测算接口。参数不足不输出唯一总额。

## 证据与下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。

下一步按期限灭失、易失证据、改变请求抗辩、可逆性排序。索赔通知、鉴定申请、起诉、应诉、精算、完整证据卷只写转介条件和最小交接。禁止指导伪造、隐匿、威胁或违法取证。
