# 评估方法

本文件是可执行判断节点。会改变路径是否打开、转介哪一原子、期限或金额接口的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。路径状态只用 `打开接口`、`不打开`、`待核`。不得输出胜诉率、必然责任比例、唯一必得总额、选定法院、唯一截止日、伤残等级或系数。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜路径｜提出方｜相对方｜法律效果假设｜成立条件｜支持事实｜不利事实｜控制方／证明负担红旗｜最强反方｜互斥／转介｜状态｜待核`。

归责路径与赔偿项目分表。`Q-金` 不放进归责扫描。同一事实支持多项时分别说明效果，不重复金额。构成侵权不等于项目必得。

## 节点 0　专项分流

先于实体判断。

**整案转出**（本任务只交付第 1 节分流理由、第 2 节来源、第 10 节最小交接，不填第 5–9 节实体结论）：

| 信号 | 转出 |
| --- | --- |
| 主成果是工伤认定、劳动能力鉴定、停工留薪或工伤待遇 | 劳动领域 |
| 主成果是诊疗过错、病历真实性或医疗损害鉴定 | 医疗医药领域 |
| 海上货物、船舶碰撞、海上人身伤亡专门责任 | 海事领域 |
| 尚未发生损害，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 主成果已是主体保险表、时效表、管辖终稿、交强险分账终稿、鉴定申请或精算 | 对应原子；本任务负触发 |

**混合信号，民事总图可留，专项只分流：**

- 工作中、工作场所或上下班合理路径被用人单位以外的第三人伤害：民事请求留本任务；必须转介 `评估工伤与第三人侵权竞合`；工伤认定、劳动能力鉴定、工伤待遇整段转劳动；两套程序可并行、互不等待；医疗费等实际支出禁止双领；其余项目是否并行必须运行时核验，禁止记忆成“一律双得”或“一律互抵”。工伤认定申请期限单独红旗，不得与民事时效混算。
- 同事执行工作任务致害：先并列“用人者／第三人”待核，不锁定为第三人侵权。
- 依法应参加工伤统筹的劳动者向用人单位主张民事赔偿：现有依据支持转劳动告知，本任务不出具工伤待遇或对用人单位的民事终局。
- 个人劳务（非工伤统筹）：转介 `评估提供劳务受害`，不套工伤基金。
- 就医记录作为损害证据可留。诊疗过错争点转医疗。同一事件并存交通／产品与诊疗介入时，交通／产品段留本任务；原因力只标接口，转介 `评估因果关系与既往伤病`；禁止把后续医疗机构写成前序侵权人的当然免责。
- 铁路行车、航空事故：普通民诉入口字段停止，转介 `评估铁路航空等非海事承运人人身损害` 与 `评估人身损害管辖`。
- 客运、旅游等书面仲裁条款：不得直接写应起诉，转介管辖原子。
- 刑事在侦或已起诉：转介 `分流刑民交叉`；附带民事另诉接口转 `评估刑附民与另行起诉`。死亡案件转介 `评估死亡赔偿权利人与分配`。
- 人身损害事实本身构成故意伤害、故意杀人或其他疑似故意犯罪（如校外人员进入教室打伤幼儿），即使用户未说已经立案：刑民交叉至少 `待核`，转介 `分流刑民交叉`；不得因未陈述「已经立案」而关闭。

## 节点 1　主体、材料版本和程序状态

1. 名称表记录受害人、近亲属、法定代理人、行为人、车辆或物件控制人、用人者、场所经营者管理者、教育机构、产品生产者销售者、交强险与商业三者保险人。名称不一致不自动合并，不在本任务选定唯一义务人。受害人是无／限制民事行为能力人时，法定代理人必须单列，并转介 `评估未成年或无行为能力受害人代理`；不得用「近亲属」顶替。展开其余主体转介 `评估责任主体与保险覆盖`。
2. 材料表固定事故认定书、保险单、病历、鉴定、调解记录、了结／弃权／权益转让文本的版本。冲突并列，不选对用户有利的一版冒充唯一事实。调解中为达成协议而认可的事实，不得写成诉讼自认。
3. 程序表逐动作记录报警、保险报案、鉴定、协商、诉讼或执行：机关/机构、案号、文书、作出日、收到日、送达方式和效力凭证。口头转述、截图、“已读”不得写成已受理、已送达、到达或期限已起算。电子数据须原设备上下文，不得凭孤立截图写成已到达。
4. 事故认定书、调解记录或垫付收据不得单独写成责任已成立或比例已终局。公安交管部门的全部／主要责任，不得直接写成民法典第一千二百一十七条“故意或重大过失”。
5. 出现保险人一次性了结、权益转让或概括弃权：民事总图可部分形成，但必须红旗「请求可能已受弃权约束」，转介 `审查保险一次性了结弃权`。未鉴定或治疗未稳定下概括放弃未知伤残、后续治疗或对侵权人权利，标不可逆高风险。禁止写“先签保险再告侵权人”为无风险路径。禁止由 `谈判人身损害和解` 代做该审查。
6. 同时掌握双方秘密或立场不明：整体停止策略输出，不得选边继续。整体停止优先于负触发路由：用户即使要求今天寄索赔函、按十级或给胜诉率，也只交付停止原因，不得转介 `准备侵权索赔通知` 完成选边。

未投保交强险：投保义务人在交强险限额范围内的责任须运行时核验。禁止凭记忆写成投保义务人与侵权人**连带责任**。解释（一）第二十一条覆盖投保义务人与事故责任人不是同一人；同一人时另核道交解释第十六条第一款。禁止默写条号为已核验 `L#`。

驾驶人离开本车后因自身过错被本车碰撞碾压：请求本车交强险、商业三者，现有依据支持不打开，须核验解释（一）第二十二条；车上人员责任保险另核。

## 节点 3　保险先行、论坛和期限红旗

本节点只判断路径和红旗，不生成发送版索赔通知、鉴定申请、管辖异议或诉状。展开分别转介 `评估道路交通事故责任与保险先行`、`评估人身损害管辖`、`评估人身损害诉讼时效`。

### 3.1 保险接口

机动车事故（含道路以外通行比照）一律打开保险接口，不因认定书无责、次责而关闭交强险。

分列、不得合成一行：

1. 赔偿顺序须核验第一千二百一十三条：先交强险责任限额，再商业三者约定，仍不足由侵权人。
2. 分项限额（死亡伤残／医疗费用／财产损失；有责／无责）必须运行时核验。未核验则金额和“限额内必得”字段停止。禁止把医疗费写入死亡伤残限额，禁止用已废止的 11 万／1 万旧限额。
3. 多车多份交强险分列，不得简单相加冒充必得，也不得因“次责”丢掉该车交强险。
4. 精神损害请求交强险优先：须被侵权人或近亲属提出，解释支持方向须核验道交解释第十三条第二款；只标接口，不自动优先、不保证交强险覆盖全部精神损害。
5. 承保交强险的保险公司诉讼地位：道路交通事故损害赔偿中应当列为共同被告（已在责任限额范围内实际赔付且当事人无异议除外）。本任务只标「应当共同被告」红旗，不写起诉状。商业三者仅在当事人请求时加入。
6. 医保基金、工伤保险基金已付医疗费和道路救助基金垫付的抢救费、丧葬费，不得再向侵权人重复主张该部分；追偿主体是基金／救助基金管理机构。检索锚点：道交解释（二）第十条。禁止写成“基金已付则第三人全部民事责任消灭”。
7. 逃逸、未知名：转介 `评估侵权人不明路径`。已发生抢救费用急需垫付时，另转介 `申请道路救助基金或垫付`；未就医、无抢救费时不得把救助基金申请写成默认下一步。紧急医疗费给付转介 `申请先予执行医疗费`，本任务不起草申请。

### 3.2 论坛红旗

管辖连结点须运行时核验现行《民事诉讼法》地域管辖条款（2023 修正后侵权诉讼常见为侵权行为地或被告住所地，对应条号不得凭记忆写入 `L#`）。侵权行为地包括实施地和结果发生地，须分列待核。公路、铁路、水上、航空事故另核事故发生地／车辆或船舶最先到达地／航空器最先降落地。产品致人身损害另核制造地、销售地、服务提供地。

出现下列任一，普通民诉入口字段停止，转介 `评估人身损害管辖`：铁路运输法院专门管辖红旗；海事法院；有效仲裁条款；协议管辖是否覆盖人身侵权未核验。

本任务不选定受诉法院，不输出“应向某区法院起诉”。

### 3.3 期限分类型

每种期间单独一行。类型必须标明下列之一：`诉讼时效`／`事故认定复核`／`鉴定异议`／`答辩或上诉`／`工伤或劳动申请期限`。

| 类型 | 本任务允许的输出 | 禁止 |
| --- | --- | --- |
| 诉讼时效 | 并行情景：侵害发生、义务人查明、治疗相对稳定或定残、死亡及近亲属知悉、无／限制行为能力人法定代理人知悉；三年与二十年分列；对驾驶人、用人者、保险人分相对人 | 唯一截止日；事故日当然起算；保险报案当然中断对侵权人的时效；微信已读当成到达 |

## 节点 4　金额接口与鉴定闸

本任务只建项目清单和测算接口，不替代 `测算人身损害赔偿`。

### 4.1 鉴定闸

无死亡事实且出现急救未结束、骨折未固定、计划内二次手术未做、内固定未取、烧伤未拆痂等治疗明显未相对稳定信号：鉴定闸关闭。残疾赔偿金、护理依赖、误工截止均为 `无法估计`。**禁止**转介 `准备伤残鉴定材料` 启动鉴定。只列稳定条件缺口。用户口述“差不多好了”或“先按十级谈”不得开闸。禁止任何十级或系数假设。死亡案件的死因／范围鉴定不受此闸。

闸已打开（治疗相对稳定或死亡事实）且用户要申请材料：转介鉴定原子，本任务仍不定级。

### 4.2 项目清单

分项必须可被看见：医疗费、护理费、交通费、营养费、住院伙食补助、误工、辅助器具、残疾赔偿金、死亡赔偿金、丧葬费、精神损害、后续治疗费、被扶养人生活费（计算展开，汇总计入残疾或死亡赔偿金）。未知不写零，不得从矩阵删除。

纪律：

1. 被扶养人生活费计入残疾赔偿金或死亡赔偿金，禁止与两金并列相加输出必得双份。无被扶养人材料时该行 `无法估计` + `G#`（身份、扶养关系、无劳动能力、消费支出口径）。
2. 侵权行为发生在 2022-05-01 当日及以后：禁止用农村标准压低残疾／死亡赔偿金。发生在该日之前：城乡是否仍区分标 `待核`，禁止把新标准回套旧侵权，也禁止把旧农村标准用于新侵权。就高须权利人举证住所地或经常居住地。
3. “上一年度”是一审法庭辩论终结时的上一统计年度。咨询日统计值只作情景，不写成已核定。
4. 超龄但有误工损失证据：不得仅因达到法定退休年龄把误工写成零。检索锚点：道交解释（二）第六条（道路交通事故场景）；其他场景同样不得凭年龄一笔勾销，须运行时核验。
5. 后续治疗费未发生：`无法估计`，转介 `评估后续治疗费另行主张`，禁止写成零或被一次性了结吞掉。
6. 同一票据、基金已付、对方垫付逐笔扣减接口，不得重复主张。
