# 边界与路由

## 正触发

人身权益已受损，单方需要路径总图：扫描归责、标出请求抗辩接口、列出必须转介的专项和下一步，而不是只要某一专项终稿。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 工伤认定、劳动能力鉴定或工伤待遇 | 劳动领域 |
| 诊疗过错、病历或医疗损害鉴定 | 医疗医药领域 |
| 海上运输或船舶事故 | 海事领域 |
| 评估谁可能赔、保险怎么覆盖 | `评估责任主体与保险覆盖` |
| 只判断诉讼时效 | `评估人身损害诉讼时效` |
| 只判断管辖连结点或要异议书 | `评估人身损害管辖` / `提出人身案件管辖异议`（未安装则 `unavailable`） |
| 只要交强险商业三者分账终稿 | `评估道路交通事故责任与保险先行` |
| 发索赔通知 | `准备侵权索赔通知` |
| 启动伤残鉴定 | `准备伤残鉴定材料`（鉴定闸未开则本窗停止，不转介启动） |
| 精算赔偿项目 | `测算人身损害赔偿` |
| 完整证据卷 | `建立人身损害证据案卷` |
| 和解条件 | `谈判人身损害和解` |
| 保险一次性了结、权益转让、概括弃权 | `审查保险一次性了结弃权` |
| 起诉 | `提起人身损害一审` |
| 应诉 | `应对人身损害一审` |
| 未成争改合同 | 审查起草领域（本窗搁置，只说明） |
| 未定残的大众测算、场所摔伤大众包 | 大众专项，只分流不回改 |

综合提问（总图 + 告谁／保险／时效／法院／金额）仍正触发本任务，但按输出合同强制降级为接口和转介，不改走负触发。受害人开口且委托范围是总图时，不因口语化咨询整体停止。

双方秘密或授权不明的整体停止，优先于「主成果是发送版索赔函」的负触发。

## 总图必转介接口

事实命中即打开接口，本任务不代做终稿。未安装则该接口标 `unavailable`。

| 信号 | 转介 |
| --- | --- |
| 机动车事故、未投保、开门杀、借用租赁、道路以外通行 | `评估道路交通事故责任与保险先行`；保险人诉讼地位与拒赔另见 `直接起诉保险公司` / `应对保险拒赔减赔` |
| 工作中或上下班 + 用人单位以外第三人 | `评估工伤与第三人侵权竞合`；工伤三段转劳动 |
| 高压、高速轨道、高度危险活动或危险物 | `评估高度危险作业致害` |
| 幼儿园、学校等教育机构 | `评估教育机构责任` |
| 数人、两车或多车、教唆帮助、分别侵权 | `评估共同侵权与连带按份` |
| 文体活动固有风险或主张公平分担 | `评估自甘风险与公平分担` |
| 用人者、劳务派遣、执行任务 | `评估用人者责任` |
| 个人劳务 | `评估提供劳务受害` |
| 铁路航空非海事承运人 | `评估铁路航空等非海事承运人人身损害` |
| 产品缺陷 | `评估产品致人损害` |
| 场所安保 | `评估场所安全保障义务` |
| 动物／物件／高空抛物／施工地面地下 | 对应专项原子 |
| 死亡近亲属范围 | `评估死亡赔偿权利人与分配` |
| 既往伤病或诊疗介入原因力 | `评估因果关系与既往伤病` |
| 后续治疗费另主张 | `评估后续治疗费另行主张` |
| 刑民交叉、刑附民，或人身损害事实本身构成疑似故意犯罪 | `分流刑民交叉` / `评估刑附民与另行起诉` |
| 无／限制民事行为能力受害人 | `评估未成年或无行为能力受害人代理` |
| 认定书不服 | `复核交通事故认定` |
| 侵权人逃逸或暂时不明 | `评估侵权人不明路径` |
| 已发生抢救费且需垫付 | `申请道路救助基金或垫付` |
| 紧急医疗费先予执行 | `申请先予执行医疗费` |
| 违约与侵权竞合（客运、旅游等） | `选择人身损害违约侵权竞合路径` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 工伤认定申请、劳动能力鉴定、工伤待遇测算或仲裁 | 劳动领域 |
| 诊疗过错、病历封存、医疗事故鉴定 | 医疗医药领域 |
| 船舶、海上人身伤亡、海事保全 | 海事领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

请求尚未闭合、需比较归责路径或是否先保险后起诉时正触发，但保险、管辖、时效、测算只出红旗。主体、请求、论坛均确认且只要诉状时负触发。工作中受伤但主成果是向第三人索赔时正触发，同时把工伤三段和竞合原子标转介。治疗未稳定时“先鉴定一个十级”负触发鉴定原子，本任务鉴定闸关闭。
