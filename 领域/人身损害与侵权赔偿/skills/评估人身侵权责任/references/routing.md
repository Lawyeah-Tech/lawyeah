# 边界与路由

## 正触发

生命、身体或健康已经受到侵害，单方需要侵权责任总图再决定主体保险、鉴定、测算或诉讼。从零、碎片、归责或限额未核验仍正触发：有可编号侵害、认定书、病历、保单或程序碎片则闸开或半开，出 `QG#` 草案，保持草案。本次不写发送版函、不定残、不选定法院是交付禁令，不是开窗条件。构成侵权即伤残已定、认定书即终局，仍正触发。把构成侵权写成项目必得、把无责写成关闭交强险、把先按十级写成开鉴定，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造伤情、隐匿既往的停止，优先于负触发。上述信号不在下表。不写发送版函不是负触发。「构成侵权即伤残已定」「构成侵权即项目必得」「认定书即民事终局」「已读即已送达」「无责即关交强险」「先按十级」「未知写零」不在下表。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 工伤认定、劳动能力鉴定、工伤待遇 | 劳动领域 |
| 诊疗过错、病历真实性、医疗损害鉴定 | 医疗医药领域 |
| 海上货物、船舶碰撞、海上人身伤亡 | 海事领域 |

一般交通事故夹带工伤或就医时，民事总图可留，专项段只分流。出现「保险」「鉴定」「起诉」一词不是转出。C 端只要大众填空页时只分流，不把本包降成填空式结论，不回改。

## 易混

本窗闸名只能是侵权闸，不是争议闸，不是评估闸，不是鉴定闸，不是发送闸，不是起诉闸。`QG#` 不是 `ZT#`，不是 `M#`，不是 `EV#`，不是 `PTY#`。主路径是 `Q-责`，不是 `Q-总`，不是 `Q-侵`，不是 `Q-诉`，不是 `Q-过`。`争议闸`／`ZT#`／`Q-总` 是合同包 `评估合同争议`，人身包不得借用。`Q-侵` 是竞合窗比较格。构成侵权不是伤残已定。构成侵权不是项目必得。认定书不是民事终局比例。无责不是关闭交强险。已失效《侵权责任法》不是现行。2003 年人身损害赔偿解释已删除场所推定条不是现行。提出「把病历改成没有既往、出险日改到上周」整体停止。本窗不代提交。不选定法院。不定残。不写发送版。不保证胜诉。
