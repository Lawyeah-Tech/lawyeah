# 边界与路由

## 正触发

人身权益已受损，单方需要总体决定请求、抗辩、论坛、证据优先级和下一步。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 工伤认定、劳动能力鉴定或工伤待遇 | 劳动领域 |
| 诊疗过错、病历或医疗损害鉴定 | 医疗医药领域 |
| 海上运输或船舶事故 | 海事领域 |
| 评估谁可能赔、保险怎么覆盖 | `评估责任主体与保险覆盖` |
| 只判断诉讼时效 | `评估人身损害诉讼时效` |
| 只判断管辖连结点 | `评估人身损害管辖`（未安装则 `unavailable`） |
| 发索赔通知 | `准备侵权索赔通知` |
| 启动伤残鉴定 | `准备伤残鉴定材料` |
| 精算赔偿项目 | `测算人身损害赔偿` |
| 完整证据卷 | `建立人身损害证据案卷` |
| 和解条件 | `谈判人身损害和解` |
| 起诉 | `提起人身损害一审` |
| 应诉 | `应对人身损害一审` |
| 未成争改合同 | 审查起草领域（本窗搁置，只说明） |
| C 端 007／006 | 大众专项，只分流不回改 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 工伤认定申请、劳动能力鉴定、工伤待遇测算或仲裁 | 劳动领域 |
| 诊疗过错、病历封存、医疗事故鉴定 | 医疗医药领域 |
| 船舶、海上人身伤亡、海事保全 | 海事领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

请求尚未闭合、需比较归责路径或是否先保险后起诉时正触发。主体、请求、论坛均确认且只要诉状时负触发。工作中受伤但主成果是向第三人索赔时正触发，同时把工伤三段标转介。
