# 评估人身侵权责任

## 任务目标

在明确、无利益冲突的单方立场下（受害人、近亲属、被指侵权人或其受托律师，互斥），形成人身侵权责任总图草案：侵权闸、主体与材料版本、`Q#` 路径、`QG#` 侵权总图行（侵害切片／请求抗辩／论坛期限／金额接口／打开接口／`E#` 回链）。本窗 `QG#` 是总图行草案，不是索赔函，不是鉴定申请，不是诉状，不是精算终稿，不是伤残已定，不是应起诉。本窗闸名只能是侵权闸，禁止复用争议闸、评估闸、鉴定闸、发送闸、起诉闸、答辩闸、管辖闸、论坛闸、精算闸、人测闸、案卷闸、和解闸、谈判闸、保全闸、立案闸。预留不得占用：立案闸、鉴定闸、发送闸、起诉闸、人测闸、论坛闸、管辖闸。本窗主行只能是 `QG#`，禁止 `ZT#`、`QT#`、`A#`、`N#`、`M#`、`EV#`、`PTY#`、`INS#`、`Pth#`、`EVT#`。主路径只用 `Q-责`，禁止用 `Q-总`、`Q-侵`、`Q-诉`、`Q-测`、`Q-人测`、`Q-卷`、`Q-函`、`Q-求`、`Q-鉴`、`Q-伤鉴`、`Q-辖`、`Q-体`、`Q-险`、`Q-过` 作主路径。邻窗 `Q-责` 只作转介进本窗；本窗打开为主路径，不是已构成侵权、不是伤残已定、不是应起诉。侵权闸打开不等于已构成侵权不等于伤残已定不等于认定书即民事终局不等于应起诉不等于交强险已分账不等于待提交终稿。构成侵权不是伤残已定。构成侵权不是项目必得。认定书不是民事终局比例。口头或已读不是已送达。准备起诉不是责任已锁定。无责不是关闭交强险。先按十级不是开鉴定闸。未知不写零。不写发送版索赔函或诉状。不选定法院。不写唯一截止日。不输出唯一必得总额。不定残。不定罪。不保证胜诉。不代提交。

`depends-on` 为空。主成果是主体保险表转 `评估责任主体与保险覆盖`。主成果是时效表转 `评估人身损害诉讼时效`。主成果是管辖终稿转 `评估人身损害管辖`。主成果是交强险分账转 `评估道路交通事故责任与保险先行`。主成果是发送版索赔函转 `准备侵权索赔通知`。主成果是鉴定申请转 `准备伤残鉴定材料`。主成果是精算工作表转 `测算人身损害赔偿`。主成果是起诉包转 `提起人身损害一审`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：生命、身体或健康已经受到侵害，单方需要侵权责任总图再决定主体保险、鉴定、测算或诉讼。「已经构成侵权了」「先按十级谈」「认定书就是三七开」「去某区法院告」仍正触发，成果状态 `草案`。归责、送达、限额未核验仍正触发：有可编号侵害、认定书、病历、保单或程序碎片则侵权闸打开或半开，第 6 节出 `QG#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出已构成侵权／应起诉／十级终稿」才关闸，仍交十节，第 6 节不出 `QG#` 终稿，第 7 节不得出索赔函、鉴定申请或诉状，窗口不关。用户要把构成侵权写成伤残已定或项目必得、把认定书写成民事终局、把已读写成已送达、把无责写成关闭交强险、把先按十级写成开鉴定、把未知写成零或唯一必得总额，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `QG#` 草案。不得因「不写发送版函」「不定残」「不选定法院」改走负触发关窗。利益冲突未解不是整体停止。无死亡且治疗明显未相对稳定：鉴定只红旗关闭启动，窗口不关，仍交十节。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是主体保险表终稿（转 `评估责任主体与保险覆盖`）；
- 主成果是时效表终稿（转 `评估人身损害诉讼时效`）；
- 主成果是管辖连结点终稿或异议书（转 `评估人身损害管辖` 或 `提出人身案件管辖异议`）；
- 主成果是交强险或商业三者分账终稿（转 `评估道路交通事故责任与保险先行`）；
- 主成果是发送版索赔函（转 `准备侵权索赔通知`）；
- 主成果是伤残鉴定申请终稿（转 `准备伤残鉴定材料`）；
- 主成果是精算工作表（转 `测算人身损害赔偿`）；
- 主成果是完整证据卷（转 `建立人身损害证据案卷`）；
- 主成果是和解谈判要点（转 `谈判人身损害和解`）；
- 主成果是可提交一审起诉包（转 `提起人身损害一审`）；
- 主成果是首次应诉答辩（转 `应对人身损害一审`）；
- 主成果是工伤认定、劳动能力鉴定或工伤待遇（转劳动领域；夹带第三人只开 `评估工伤与第三人侵权竞合` 接口）；
- 主成果是诊疗过错、病历或医疗损害鉴定（转医疗医药领域）；
- 海上运输或船舶事故（转海事领域）；
- 尚未发生损害，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）。

双方秘密、伪造伤情、隐匿既往、倒签出险或鉴定日、违法取证**不在负触发表**，走整体停止。「构成侵权即伤残已定」「构成侵权即项目必得」「认定书即民事终局」「已读即已送达」「无责即关交强险」「先按十级」「未知写零」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不写发送版函或诉状」「不定残」「不选定法院」是交付禁令，不是负触发。主成果才转；出现「保险」「鉴定」「起诉」一词不是转出。综合提问仍正触发，第 5–7 节只给接口。

## 建立工作坐标

确认：评估授权；单方立场（受害人、近亲属、被指侵权人或其受托律师，互斥）；受害人与可能赔偿义务人、保险人的名称变体；事故或侵害事实；法域；当前协商、保险、鉴定、诉讼状态。

口头「已经构成侵权了」「先按十级」「认定书就是三七开」只登记 `S#`／`V#`。不得升格已构成侵权、伤残已定或应起诉，**不得单独算作开闸材料**。可编号侵害事实、认定书、病历、保单或程序碎片可开闸。已读不等于送达。本窗不执行发送，不代提交，不写索赔函、鉴定申请或诉状。

立场只许受害人、近亲属、被指侵权人或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：侵权闸关闭，仍交十节，不是整体停止。无书面评估授权但单方立场已闭合、且已有碎片：侵权闸部分打开，仍交十节，不是整体停止。提出伪造伤情、隐匿既往、倒签出险或鉴定日、违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 保险条款、书面约定、了结或弃权文本；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`QG#` 侵权总图行；`V#` 版本；`E#` 证据形态回链（侵害、认定书、病历、保单形态，不是发送闸，不是已构成侵权证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`ZT#`、`M#`、`EV#`、`PTY#`。技能正文中的条号是检索锚点，不是已核验 `L#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止合成「侵权责任」一笔。扫描不是闭集。未知不写零。构成侵权 ≠ 伤残已定。构成侵权 ≠ 项目必得。认定书 ≠ 民事终局。已读 ≠ 送达。无责 ≠ 关闭交强险。先按十级 ≠ 开鉴定。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或裁判案例检索。本窗是侵权总图，**不要**用 `search_template` 或文书范本生成索赔函、鉴定申请、诉状或「已构成侵权」证明。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现认定书即终局、构成侵权即必得、无责即关交强险、已读即送达、口述十级即开鉴定的反例；案例只比较事实差异与翻转条件，不写成必然结果。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文、已失效《合同法》当作现行规则。不得把交强险旧限额 11 万／1 万当已核验。道交解释（二）法释〔2026〕9 号自 2026-06-30 施行；MCP 标「尚未施行」以施行日为准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的归责、限额、期限或论坛结论保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民法典（施行日 2021-01-01）第一千一百六十五条过错责任；法律规定推定过错的，行为人不能证明自己没有过错的应当承担侵权责任。第一千一百六十六条无过错责任须法律有规定。第一千一百七十九条人身损害赔偿项目：医疗费、护理费、交通费、营养费、住院伙食补助费等合理费用以及误工减少的收入；残疾加辅助器具费与残疾赔偿金；死亡加丧葬费与死亡赔偿金。构成侵权不是项目必得。第一千一百八十三条严重精神损害可请求精神损害赔偿。第一百八十八条诉讼时效三年自知道或应当知道权利受损以及义务人起算，二十年自权利受损；事故日不是当然唯一起算。第一千二百一十三条机动车损害先交强险限额内赔偿，再商业三者约定，仍不足侵权人赔偿；无责不是关闭交强险。人身损害赔偿解释（法释〔2022〕14 号）被扶养人生活费计入残疾赔偿金或死亡赔偿金，禁止与两金双计必得；2022-05-01 后发生的侵权适用。侵权责任编解释（一）未投保投保义务人与事故责任人不是同一人时共同承担，不得默写连带为已核验。噪声：已失效《侵权责任法》；2003 年人身损害赔偿解释已删除场所推定、校园过错等条；民法通则第一百零六条；已失效《合同法》；交强险旧限额。技能正文条号不是 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变归责、限额或期限的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补认定书不是民事终局、构成侵权不是项目必得、无责不是关闭交强险、已读不是送达、口述十级不是开鉴定的实务反例。
- `search_case_by_fact` 只比较事实差异与翻转条件。无类案不得写成已构成侵权或应起诉。评估类禁止用 `search_template` 生成索赔函、鉴定申请、诉状或「已构成侵权」证明。

工具不可用时继续主体、材料版本和 `QG#` 编目；归责、限额、期限、论坛字段停止。不得拒跑，不得凭记忆写成已构成侵权或应起诉。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、侵权闸与不关窗

主成果才整案转出。双方秘密、伪造伤情、隐匿既往第一次停。构成侵权即伤残已定、认定书即终局不关窗。闸关仍交十节，第 6 节不出 `QG#` 终稿。利益冲突未解不是整体停止。

### 2. 主体、材料版本与程序状态

受害人、可能义务人、保险人名称变体分列。认定书、病历、保单、了结文本冲突并列。口头不得升格已送达或已构成侵权。本节禁止出 `QG#` 终稿。

### 3. 侵权闸与路径 `Q#`

本节禁止出 `QG#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-责`。`Q-过` 至 `Q-抗` 只作切片或打开接口标签，不是主路径。

### 4. 总图行 `QG#`

侵害切片、请求抗辩、论坛期限、金额接口、打开接口分列。状态 `草案`。禁止升格已构成侵权、伤残已定、应起诉、必得总额。无 `E#` 不得写已构成侵权。

### 5. 主体保险、鉴定、管辖与诉讼接口

主体保险、鉴定、管辖、测算、发函、起诉只开接口。第 7 节不得夹带 `QG#` 终稿或发送版函绕闸。未稳定不得转介启动鉴定。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造伤情、隐匿既往、倒签出险或鉴定日、违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：侵权闸关闭，仍交十节，不是整体停止。无书面评估授权但有碎片：侵权闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：认定书效力、送达、归责开闭、交强险限额、时效起算、管辖连结点、施行日未核验。构成侵权即伤残已定、构成侵权即项目必得、认定书即民事终局、已读即送达、无责即关交强险、先按十级、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `QG#` 草案。
- `目标停止`：主目标变为发送版函、鉴定申请终稿、精算终稿、案卷终稿、起诉或答辩终稿。禁止把「构成侵权即伤残已定」当作用户错误主张时的目标停止；那是不关窗。

禁止指导伪造伤情、隐匿既往或倒签。不给胜诉率。不定罪。不定残。不选定法院。不代提交。未知不写零。不写唯一截止日。不输出唯一必得总额。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。侵权闸关闭仍交十节，第 6 节不出 `QG#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `QG#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。侵权闸未打开时不得交付「已构成侵权」或「应起诉」。边界见 [路由](references/routing.md)。
