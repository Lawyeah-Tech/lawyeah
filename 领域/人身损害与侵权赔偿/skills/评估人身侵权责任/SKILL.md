# 评估人身侵权责任

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“人身侵权责任总体评估矩阵”：主体和程序状态、事实时间线、归责路径、逐项请求／抗辩、论坛与程序入口、期限待核、金额区间与非金钱后果、证据缺口、对方最强解释和下一步。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：生命、身体或健康已经受到侵害，用户仍需决定请求、抗辩、路线或下一步。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是工伤认定、劳动能力鉴定或工伤待遇（转劳动）；
- 主成果是诊疗过错、病历或医疗损害鉴定（转医疗医药）；
- 海上运输或船舶事故（转海事）；
- 只要发送版索赔函、鉴定申请或精算工作表；
- 已决定起诉／答辩／开庭／执行并只要相应文书；
- 尚未发生损害，只要改合同或出稿（审查起草领域，本生产线搁置，只说明不实施）。

本任务不生成发送版索赔函、鉴定申请、可提交诉状或答辩，不给胜诉率。

## 建立评估坐标

确认：使用者与授权；单方立场；受害人与可能赔偿义务人、保险人；事故或侵害事实；法域；当前协商、保险、鉴定、诉讼或执行状态；机关文书作出与送达；对方已知主张；关键材料及缺失。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 保险条款或书面约定定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`V#` 评估版本；`E#` 发送／送达／履行凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验归责、项目、时效、管辖、交强险顺序、工伤竞合；`search_practiced` 补路径与反例；特殊事实用 `search_case_by_fact`，明确筛选用 `search_case_by_filter`。不虚构案件系统。

工具不可用时继续事实、主体、程序文书状态和问题清单；请求／抗辩的法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 专项分流、主体和程序状态

先做工伤、医疗、海事整案转出，再固定受害人、行为人、用人者、场所、产品、保险人。口头转述和“已读”不写成已受理、已送达或期限已起算。事故认定书只作为 `R#` 或 `D#`，不得写成民事终局比例。

### 2. 归责路径与请求抗辩假设

每个 `Q#` 独立列法律效果、成立条件、支持及不利事实、控制方、最强反方、主备位和互斥。一般过错、用人者、场所补充责任、产品、机动车、动物、物件不得合成一笔“侵权责任”。构成侵权不等于项目必得。

### 3. 论坛、保险先行和期限

交强险出现时不得跳过保险接口直接写成只诉个人。期限分列诉讼时效、鉴定异议、事故认定复核、答辩或上诉，不混算。知悉日或义务人不明则截止日停止。

### 4. 金额区间与非金钱后果

分项列医疗、护理、误工、残疾或死亡、精神损害。被扶养人生活费只做计入接口，不与残疾／死亡赔偿金双计。未知不写零。停止侵害、赔礼道歉等非金钱结果单列。

### 5. 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。下一步按期限灭失、易失证据、能否改变 `Q#`、可逆性排序。发函、鉴定、立案、精算标为转介。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或侵害事实无法建立；用户坚持伪造伤情、隐匿既往、威胁或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为发函、鉴定申请、精算、建卷、和解协议或程序文书。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
