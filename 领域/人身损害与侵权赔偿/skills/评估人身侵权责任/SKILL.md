# 评估人身侵权责任

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“人身侵权责任路径总图”：专项分流、主体与材料版本、按已出现事实扫描的归责路径假设、请求／抗辩接口、必须转介的相邻原子，以及期限、保险、管辖、金额的**待核红旗**（不是这些专项的终稿）。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。用户顺口问“告谁、保险怎么赔、哪天到期、去哪个法院、能赔多少”时，本任务只给接口、并行情景和转介，不产出可验收的主体保险表、唯一截止日、选定法院或分项精算。

## 工作边界

正触发：生命、身体或健康已经受到侵害，单方仍需一张**路径总图**来决定先核哪条归责、先转哪项专项，而不是只要某一专项终稿。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是工伤认定、劳动能力鉴定或工伤待遇（转劳动）；
- 主成果是诊疗过错、病历真实性或医疗损害鉴定（转医疗医药）；
- 海上运输或船舶事故（转海事）；
- 主成果是发送版索赔函、鉴定申请、精算工作表、管辖异议书、诉状或答辩；
- 只要主体保险表、只要时效表、只要管辖连结点、只要交强险分账终稿（转对应原子）；
- 尚未发生损害，只要改合同或出稿（审查起草领域，本生产线搁置，只说明不实施）。

本任务不生成发送版索赔函、鉴定申请、可提交诉状或答辩，不选定管辖法院，不给胜诉率，不定残等级或系数。

## 建立评估坐标

确认：使用者与授权；单方立场；受害人与可能赔偿义务人、保险人的**名称变体**（不合并、不选定唯一义务人）；事故或侵害事实；法域；当前协商、保险、鉴定、诉讼或执行状态；机关文书作出与送达；了结／弃权／权益转让文本是否出现；对方已知主张；关键材料及缺失。

同时掌握双方秘密或未解利益冲突：`整体停止`，不得以“选边”治愈，也不得改走负触发去起草或转介发送版索赔函。受害人已开口且委托范围就是总图时，推定单方立场并强制降级；仅当当事人无法建立或授权范围无法确定时，才因授权不明整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 保险条款、书面约定、了结或弃权文本；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径接口；`V#` 评估版本；`E#` 发送／送达／履行凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。路径状态只用 `打开接口`、`不打开`、`待核`。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验归责、项目、时效、管辖、交强险顺序、未投保、工伤竞合、教育机构／高度危险等将被写入 `L#` 的现行规则；不可用则这些字段停止。
- 已有检索真实返回的 `regulation_id` 且宿主暴露 `get_law_detail` 时，用其核验将改变路径、期限或限额的条文正文，再写入 `L#`。未暴露则不得编造 `regulation_id`，也不得把 `search_law` 摘要条号在未核验效力时点前写成已核验 `L#`。
- `search_practiced` 补鉴定闸、弃权、举证倒置与路径反例。
- 特殊事实用 `search_case_by_fact`，明确筛选用 `search_case_by_filter`。案例只比较差异，不写成必然结果。不虚构案件系统。

工具不可用时继续事实、主体名称变体、程序文书状态和问题清单；请求／抗辩的法律结论、期限、管辖入口和保险限额字段停止。技能正文中的条号是检索锚点，不是已核验 `L#`。

## 判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 专项分流、主体和程序状态

先做工伤待遇、医疗鉴定、海事整案转出。混合信号（工作中被第三人撞伤、车祸后就医）民事总图可留，专项段只分流。口头转述和“已读”不写成已受理、已送达或期限已起算。事故认定书、调解记录、垫付收据只作为 `R#` 或 `D#`，不得写成民事终局比例。出现了结、权益转让或概括弃权文本时必须红旗并转介。

### 2. 路径扫描与请求抗辩接口

按**已出现事实**扫描路径，不是默认闭集，也不是无事实就铺开全部特殊侵权。每个打开的 `Q#` 只写法律效果假设、成立条件、支持及不利事实、控制方／证明负担红旗、最强反方、与其他路径的互斥，以及转介哪一原子。禁止合成“侵权责任”一笔。构成侵权不等于项目必得。本任务不输出特殊侵权的终局形态或唯一比例。

### 3. 保险、论坛和期限红旗

机动车事故一律打开保险接口，不因认定书无责而关闭交强险。只标顺序、分项限额待核、保险人诉讼地位红旗和未投保接口，不做保险分配终稿。管辖只列连结点类型和专属／仲裁红旗，不选定法院。期限分列诉讼时效并行情景、认定复核、鉴定异议、答辩上诉、工伤申请，不混算，不输出唯一截止日。

### 4. 金额接口与鉴定闸

只建项目清单和测算接口。未知不写零。被扶养人生活费必须保留计入行，禁止与两金双计必得。无死亡事实且治疗明显未相对稳定时鉴定闸关闭，禁止转介启动伤残鉴定，禁止十级或系数假设。

### 5. 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。下一步按期限灭失、易失证据、能否改变路径、可逆性排序。发函、鉴定、立案、精算、弃权审查、交通专项、工伤竞合只写转介条件和最小交接。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密或利益冲突未解；基础主体或侵害事实无法建立；用户坚持伪造伤情、隐匿既往、威胁或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则、限额、条号未核验。
- `目标停止`：主目标已变为发函、鉴定申请、精算、建卷、和解协议、弃权审查终稿、管辖终稿或程序文书。

禁止指导伪造、隐匿、威胁或违法取证。不给胜诉率。
