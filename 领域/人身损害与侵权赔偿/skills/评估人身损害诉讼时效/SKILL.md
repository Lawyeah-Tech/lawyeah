# 评估人身损害诉讼时效

## 任务目标

在明确、无利益冲突的单方立场下（受害人、近亲属、被指侵权人或其受托律师，互斥），形成人身损害诉讼时效表草案：时效闸、相对人与期间类型、`Q#` 路径、`LX#` 时效行（相对人与期间类型切片／起算事件并行／中断中止或二十年／届满风险／打开接口／`E#` 回链）。本窗 `LX#` 是时效行草案，不是已届满证明，不是唯一截止日，不是催告函，不是诉状。本窗闸名只能是时效闸，禁止复用期间闸、期限闸、除斥闸、时线闸、评估闸、侵权闸、名单闸、争议闸、鉴定闸、发送闸、起诉闸、答辩闸、管辖闸、精算闸、立案闸。预留不得占用：立案闸、鉴定闸、发送闸、起诉闸、精算闸、管辖闸。本窗主行只能是 `LX#`，禁止 `T#`、`QJ#`、`SX#`、`QG#`、`TB#`、`XL#`、`A#`、`N#`、`XS#`。主路径只用 `Q-钟`，禁止用 `Q-期`、`Q-历`、`Q-时`、`Q-效`、`Q-日`、`Q-签`、`Q-责`、`Q-体`、`Q-总`、`Q-险`、`Q-诉` 作主路径。邻窗 `Q-钟` 只作转介进本窗；本窗打开为主路径，不是已届满、不是应起诉。时效闸打开不等于已届满不等于已中断不等于已中止不等于二十年已过不等于法院将主动审查不等于可发函不等于应起诉不等于唯一截止日不等于待提交终稿。事故日不是当然唯一起算。三年须自知道或应当知道权利受损以及义务人。二十年自权利受损日起算，不是三年的替代，不适用中止中断。已读不是到达。口头告知交警不是到达。保险报案不当然中断对侵权人。持续治疗不是中止。过时效不是不能立案。法院不依职权适用时效。未成年人普通损害不套第一百九十一条。第一百九十条只对法定代理人本人。保险金请求期间与三年并列待核。产品缺陷二年及十年与三年并列待核。三年时效不是鉴定异议期、事故认定复核期、工伤申请期限或答辩期。未知不写零。不写唯一截止日。不写发送版催告或诉状。不选定法院。不代提交。不定残。不定罪。不保证胜诉。

`depends-on` 为空。主成果是侵权总图转 `评估人身侵权责任`。主成果是发送版催告转 `准备侵权索赔通知`。主成果是管辖终稿转 `评估人身损害管辖`。主成果是起诉包转 `提起人身损害一审`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：人身损害已发生，单方需要分列民事赔偿请求的诉讼时效起算情景、中断中止或二十年，而不是只要总图或只要诉状。「事故那天就算三年」「最晚哪天起诉」「还剩几天」「过了就不能立案」仍正触发，成果状态 `草案`。知悉日、义务人、到达未核验仍正触发：有可编号侵害日、知悉或义务人碎片、催告到达、报案回执或起诉提交碎片则时效闸打开或半开，第 6 节出 `LX#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出唯一截止日／剩余天数终稿」才关闸，仍交十节，第 6 节不出 `LX#` 终稿，第 7 节不得出唯一截止日或催告函，窗口不关。用户要把事故日写成当然唯一起算、把已读写成到达、把保险报案写成当然中断对侵权人、把持续治疗写成中止、把过时效写成不能立案、把法院写成会主动审查、把未知写成零或唯一截止日，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `LX#` 草案。不得因「不写唯一截止日」「不给剩余天数」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是侵权总图（转 `评估人身侵权责任`）；
- 主成果是主体保险表终稿（转 `评估责任主体与保险覆盖`）；
- 主成果是管辖连结点终稿或异议书（转 `评估人身损害管辖` 或 `提出人身案件管辖异议`）；
- 主成果是交强险或商业三者分账终稿（转 `评估道路交通事故责任与保险先行`）；
- 主成果是发送版索赔函或催告（转 `准备侵权索赔通知`）；
- 主成果是伤残鉴定申请终稿（转 `准备伤残鉴定材料`）；
- 主成果是可提交一审起诉包（转 `提起人身损害一审`）；
- 主成果是首次应诉答辩（转 `应对人身损害一审`）；
- 主成果是工伤认定、劳动能力鉴定、工伤待遇或劳动仲裁时效（转劳动领域；夹带第三人只开 `评估工伤与第三人侵权竞合` 接口）；
- 主成果是诊疗过错、病历或医疗损害鉴定（转医疗医药领域）；
- 海上运输或船舶事故（转海事领域）；
- 尚未发生损害，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）。

双方秘密、倒签催告、伪造签收或中断材料、隐匿送达、违法取证**不在负触发表**，走整体停止。「事故日当然起算」「唯一截止日」「已读即中断」「持续治疗即中止」「保险报案当然中断对侵权人」「过期不能立案」「法院主动审查时效」「未知写零」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不写唯一截止日」「不给剩余天数」「不选定法院」是交付禁令，不是负触发。主成果才转；出现「时效」「三年」「截止日」一词不是转出。综合提问夹带告谁、法院、金额：窗口不关，对应格只开接口或负触发总图。

## 建立工作坐标

确认：评估授权；单方立场；侵害发生日；受害人知悉损害与义务人的候选日期；治疗持续、定残或死亡日期；已有催告、索赔、保险报案、报警或起诉；法域；机关文书作出与送达。

口头「应该还没过期」「最晚哪天起诉」「还剩几天」只登记 `S#`／`V#`。不得升格已届满或唯一截止日，**不得单独算作开闸材料**。可编号侵害日、知悉或义务人碎片、催告到达、报案回执、起诉提交碎片可开闸。本窗不执行发送，不代提交，不写函或诉状。

立场只许受害人、近亲属、被指侵权人或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：时效闸关闭，仍交十节，不是整体停止。无书面评估授权但单方立场已闭合、且已有碎片：时效闸部分打开，仍交十节，不是整体停止。提出倒签催告、伪造签收或中断材料、隐匿送达或违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。开口不等于立场闭合。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 催告、了结或弃权文本；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`LX#` 时效行；`V#` 版本；`E#` 证据形态回链（知悉、送达、到达、报案形态，不是发送闸，不是已届满证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`T#`、`QJ#`、`SX#`、`QG#`、`TB#`。技能正文中的条号是检索锚点，不是已核验 `L#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止合成「本案已过期」一笔。未知不写零。事故日 ≠ 当然唯一起算。已读 ≠ 到达。保险报案 ≠ 当然中断对侵权人。持续治疗 ≠ 中止。过时效 ≠ 不能立案。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或裁判案例检索。本窗是时效表，**不要**用 `search_template` 生成截止日证明、催告函或诉状。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现事故日当然起算、已读即到达、保险报案当然中断对侵权人、过期不能立案、法院主动审查时效的反例；案例只比较事实差异与翻转条件，不写成必然结果。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《民法通则》二年时效或人身伤害一年时效、民通意见「伤害明显从受伤害之日起算」、已失效《侵权责任法》、法释〔2018〕12 号民法总则诉讼时效解释、保险法 1995 年第二十六条「二年不行使而消灭」、产品质量法 1993 年第四十五条行政处罚条、2008 年诉讼时效规定第十三条（与起诉同等效力，现行已改码）当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的届满、中断或保险金期间保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民法典第一百八十八条普通时效三年，自权利人知道或者应当知道权利受到损害以及义务人之日起计算；自权利受到损害之日起超过二十年的，人民法院不予保护。总则编解释第三十五条：三年可以中止、中断，不适用延长；二十年不适用中止、中断。第一百九十条对法定代理人的请求自法定代理终止之日起计算，不得用于驾驶人、学校、保险人等第三人。第一百九十一条仅未成年人遭受性侵害自年满十八周岁起算，普通车祸、打架、校园伤害不得套用。总则编解释第三十六条无／限制行为能力人对第三人自法定代理人知悉损害以及义务人起算。第三十七条原法定代理人损害且终止后才知悉，适用第一百八十八条第二款和解释第三十六条。第一百九十二条义务人可以提出时效抗辩；届满后同意履行或自愿履行不得再抗辩或请求返还。第一百九十三条人民法院不得主动适用诉讼时效。时效规定（2020 修正）第二条当事人未提出抗辩，人民法院不应对诉讼时效问题进行释明。民诉解释第二百一十九条超过时效仍应受理，抗辩成立的驳回诉讼请求，不是不予立案。第一百九十四条中止仅在最后六个月，障碍消除之日起满六个月届满，不是剩余期间接着算。第一百九十五条中断。时效规定第八条提出履行请求须到达或应当到达；已读、口头告知交警、无上下文截图不是到达。第十条提交起诉状或口头起诉之日起中断，不是立案受理日。第十二条向人民调解委员会等提出保护请求之日起中断。第十三条报案或控告之日起中断；不立案、撤销、不起诉自知道或应当知道该决定之日起重新计算；刑事案件进入审理阶段从刑事裁判文书生效之日起重新计算。噪声：2008 年时效规定第十三条是与起诉同等效力事项，不是现行第十三条报案条。保险法（2015 修正）第二十六条人寿保险以外二年、人寿保险五年，自知道或应当知道保险事故发生之日起计算，与第一百八十八条并列待核，禁止写死；1995 年「消灭」表述不是现行。产品质量法（2018 修正）第四十五条二年及交付最初消费者满十年，与第一百八十八条并列待核；1993 年第四十五条行政处罚条是噪声。噪声：民法通则第一百三十五条二年、第一百三十六条人身伤害一年；民通意见伤害明显从受伤害日起算；民法总则诉讼时效解释已失效；医疗事故一年。技能正文条号不是 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变起算、中断或届满接口的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补事故日当然起算、已读即到达、保险报案当然中断对侵权人、过期不能立案、法院主动审查、持续治疗即中止的反例。
- `search_case_by_fact` 只比较事实差异与翻转条件：事故日不是当然起算；已读不是到达；保险报案不当然中断对侵权人；后续治疗费可能另起算。无类案不得写成已届满或唯一截止日。评估类禁止用 `search_template` 生成截止日证明、催告函或诉状。

工具不可用时继续日期碎片和 `LX#` 编目；届满、中断、保险金期间字段停止。不得拒跑，不得凭记忆写成已届满或唯一截止日。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、时效闸与不关窗

主成果才整案转出。双方秘密、倒签催告、伪造中断材料第一次停。事故日当然起算、唯一截止日、已读即中断、过期不能立案不关窗。闸关仍交十节，第 6 节不出 `LX#` 终稿。利益冲突未解不是整体停止。

### 2. 相对人、知悉与义务人事实

驾驶人、用人者、保险人分列。无／限制行为能力必须出现法定代理人知悉候选。本节禁止出 `LX#` 终稿。

### 3. 时效闸与路径 `Q#`

本节禁止出 `LX#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-钟`。

### 4. 时效行 `LX#`

相对人与期间类型切片、起算事件并行、中断中止或二十年、届满风险。状态 `草案`。禁止升格已届满、唯一截止日、应起诉。无 `E#` 不得写已中断、已到达或已届满。

### 5. 催告、鉴定、管辖与起诉接口

催告发送、鉴定、产品、保险分账、管辖、起诉只开接口。第 7 节不得夹带 `LX#` 终稿、唯一截止日或催告函绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出倒签催告、伪造签收或中断材料、隐匿送达或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：时效闸关闭，仍交十节，不是整体停止。无书面评估授权但有碎片：时效闸部分打开，不是整体停止。利益冲突未解：不是整体停止。禁止把「日期均无法建立」写成整体停止。
- `字段停止`：知悉日、义务人、到达、中断、二十年、保险金期间、施行日未核验。事故日当然起算、唯一截止日、已读即中断、持续治疗即中止、保险报案当然中断对侵权人、过期不能立案、法院主动审查、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `LX#` 草案。
- `目标停止`：主目标变为侵权总图终稿、管辖终稿、诉状、答辩或发送版函。禁止把「唯一截止日」当作用户错误主张时的目标停止；那是不关窗。

禁止指导倒签催告或伪造中断证据。不给胜诉率。不定罪。不定残。不选定法院。不代提交。未知不写零。不写唯一截止日。
