# 评估人身损害诉讼时效

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“诉讼时效待核表”：三年时效起算并行情景、中断中止候选、二十年最长保护、与鉴定异议或事故认定复核等其他期间的分列红旗。不输出唯一截止日。不选定受诉法院。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实和文书。

## 工作边界

正触发：人身损害已发生，单独委托核验民事赔偿请求是否可能罹于时效，或评估中该判断成为主成果。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要管辖连结点或管辖异议书；
- 只要完整立案包或答辩状；
- 工伤认定申请期限或劳动仲裁时效（转劳动）；
- 只要总体责任总图。

本任务不代写异议书或诉状，不保证某法院受理，不给唯一届满日。

## 建立期间坐标

确认：使用者与授权；单方立场；侵害发生日；受害人知悉损害与义务人的候选日期；治疗持续或死亡日期；已有催告、索赔、保险报案或起诉；法域；机关文书作出与送达。

同时掌握双方秘密或立场不明时先停策略输出。口头“应该还没过期”不得写成时效未届满。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关文书；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`T#` 期间行；`V#` 版本；`E#` 送达凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典第一百八十八条、未成年人特殊起算、中断中止。工具不可用时继续日期编目；届满结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [时效方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 专项分流

工伤行政期限、海事、只要管辖或诉状则转出或负触发。

### 2. 时效起算并行情景

三年一般时效自知道或应当知道权利受损**以及**义务人之日起算。事故日、查清义务人日、治疗相对稳定日、死亡日、近亲属知悉日冲突时并行，不选有利日。

### 3. 中断中止与二十年

索赔通知到达、同意履行、提起诉讼或申请仲裁为中断候选，须有送达或受理凭证。二十年最长保护另列。

### 4. 其他期间红旗

事故认定复核、鉴定异议、答辩、上诉、管辖异议各占一行，禁止与三年时效混算。管辖连结点本身转介管辖评估。

### 5. 输出纪律

每行只对应一种期间和一个起算事件。任一要件缺失：截止日字段停止。

## 停止与安全

- `整体停止`：立场不明；日期均无法建立；用户坚持倒签催告以制造中断。
- `字段停止`：知悉日、义务人、送达日或现行条文未核验。
- `目标停止`：主目标变为管辖图、异议书、诉状或答辩。
