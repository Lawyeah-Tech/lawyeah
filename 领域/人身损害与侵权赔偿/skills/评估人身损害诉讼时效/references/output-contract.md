# 输出合同

按触发结果选择交付形状。禁止用情景数字填满截止日。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向 |
| 节点 0 整案转出 | 第 1、2、10 节 |
| 整体停止 | 第 1、10 节。禁止时效结论、催告策略。双方秘密或倒签请求时，整体停止优先于负触发 |
| 正触发 | 下列十节均出现；截止日未核验的单元格填 `待核` 或 `依据不足，无法形成结论` |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。用户要唯一届满日或剩余天数时，不得写成已形成。

## 1. 触发、单方立场、授权与成果状态

## 2. 来源登记与 MCP 调用表

`S/D/A/R/L/I/G/T/V/E`。MCP 未调用也留一行。`L#` 不得直接抄技能内条号。

## 3. 当事人与知悉／义务人事实

无／限制行为能力人必须出现法定代理人知悉候选。

## 4. 时效起算并行情景

事故日、义务人查明日、稳定日、死亡日、代理人知悉日分列。禁止唯一截止日。治疗未稳定必须打开 T-稳定且截止日停止。

## 5. 中断、中止与二十年

每项回链凭证。已读不等于到达。保险报案与对侵权人的中断分列。报案控告单独一行。二十年从权利受损害日起算。

## 6. 其他期间红旗

复核、鉴定异议、答辩、上诉、管辖异议、工伤申请与三年时效分表。不展开管辖连结点终局。

## 7. 相对人分列

侵权人、用人者、保险人各自时效行。对保险人的保险金请求期间与侵权三年并列待核，禁止写死二年或三年。

## 8. 最强反方

对方将主张事故当日已经起算、已过二十年、中断未到达、保险金请求已过特别时效、监护人侵权应走第一百九十条，或法院应依职权驳回。反方清单须可见：未抗辩不得主动适用、超过时效仍应受理、报案可能已中断、二十年不能中断。

## 9. 风险与下一步

转介管辖评估、异议、起诉、补证或索赔通知。不写异议书、催告发送稿或诉状。禁止下一步写成“倒签一份催告”。

## 10. 缺口、停止项与提示

本成果不是届满通知、管辖结论或剩余天数计算书。
