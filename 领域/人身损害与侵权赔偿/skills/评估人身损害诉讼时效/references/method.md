# 时效方法

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。禁止唯一截止日、剩余天数或胜诉率。本任务不选定受诉法院，不写催告发送稿。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《民法通则》两年时效、第一百三十六条人身伤害一年时效或已失效《侵权责任法》时记为噪声。

## 节点 0　专项分流

**整案转出**（只交付第 1、2、10 节）：

| 信号 | 转出 |
| --- | --- |
| 工伤认定申请期限、劳动仲裁时效 | 劳动领域；人身损害民事时效可留则留，工伤期限不得写入民事时效表 |
| 船舶、海上事故 | 海事领域 |
| 只要管辖连结点或异议书 | `评估人身损害管辖` 或 `提出人身案件管辖异议` |
| 只要起诉包或答辩状 | `提起人身损害一审` / `应对人身损害一审` |
| 只要总体总图，或综合提问夹带告谁／法院／金额 | `评估人身侵权责任` |
| 工作中或上下班第三人伤害且问工伤期限 | 民事时效可留；工伤申请期限红旗转 `评估工伤与第三人侵权竞合` 和劳动领域 |

管辖连结点可作红旗一行，不得在本任务展开法院清单。

双方秘密或用户坚持倒签催告：整体停止，只交第 1、10 节。

## 节点 1　时效起算并行情景

运行时核验民法典第一百八十八条：向人民法院请求保护民事权利的诉讼时效期间为三年；法律另有规定的，依照其规定；自权利人知道或者应当知道权利受到损害**以及义务人**之日起计算；自权利受到损害之日起超过二十年的，人民法院不予保护，有特殊情况的，人民法院可以根据权利人的申请决定延长。

默认并列所有已出现信号的情景，不得合并成一天，不得因用户只报事故日就只留 T-事故：

| 情景 | 起算事件 | 打开信号 | 禁止 |
| --- | --- | --- | --- |
| T-事故 | 侵害发生日 | 有侵害日 | 事故日当然起算一切人身损害；单独写成届满日 |
| T-义务人 | 查清或应当查清义务人日 | 逃逸、身份后查明、保险人后披露，或义务人不明 | 义务人不明仍写截止日 |
| T-稳定 | 治疗相对稳定日 | 损害范围当时无法确定；仍在治疗 | 治疗未稳定仍用事故日写出届满日 |
| T-定残 | 伤残鉴定意见作出日 | 已鉴定或拟鉴定 | 与 T-稳定捆成一行 |
| T-死亡 | 死亡日 | 受害人死亡 | 用受害人本人知悉日顶替近亲属 |
| T-亲属 | 近亲属知道或应当知道日 | 受害人死亡 | 与死亡日捆成一行 |
| T-代理 | 法定代理人知悉损害以及义务人日 | 无或限制民事行为能力人 | 用近亲属顶替法定代理人；把第一百九十条用到第三人身上 |
| T-191 | 年满十八周岁当日 | **仅**未成年人遭受性侵害 | 普通打架、车祸、校园伤害套用本行 |

未成年人普通人身损害不得错误套用第一百九十一条。无／限制行为能力人普通伤害走 T-代理，须核验总则编解释关于法定代理人知悉的规则。第一百九十条（对法定代理人的请求自代理终止起算）不得用于驾驶人、学校、保险人等第三人。

已发生医疗费与残疾赔偿金、后续治疗费分项目并列。后续治疗费可能另起算，转介 `评估后续治疗费另行主张`，本任务不得用事故日吞掉后续费时钟。

日期冲突、知悉日不明、义务人后查明、治疗未相对稳定、用户只要唯一届满日或剩余天数：**截止日字段一律停止**，只给情景表。不得以「无并行情景」为由写出届满日。

对驾驶人、用人者、保险人的时效相对人必须分列，不得合成一行。

## 节点 2　中断、中止、二十年

中断须运行时核验第一百九十五条，并回链事实。候选包括：权利人向义务人提出履行请求且**到达**；义务人同意履行；提起诉讼或申请仲裁；与起诉同等效力的事项。

到达规则（检索锚点：诉讼时效规定关于“提出履行请求”）：

- 书面主张须签名盖章按印，或能以其他方式证明到达；
- 信件或数据电文须到达或应当到达；微信“已读”、口头告知交警、截图无上下文，不得写成到达；
- 向义务人的代理人、财产代管人或遗产管理人提出，可以中断；
- 对保险人的保险报案、索赔到达，**不当然**中断对侵权人的时效；须分相对人；
- 权利人向人民调解委员会或依法有权解决民事纠纷的组织提出保护请求，从提出之日起中断候选；
- 权利人向公安机关、人民检察院、人民法院报案或控告并请求保护民事权利：从报案或控告之日起中断候选。机关决定不立案、撤销案件或不起诉：从权利人知道或应当知道该决定之日起重新计算。刑事案件进入审理阶段：从刑事裁判文书生效之日起重新计算。检索锚点：诉讼时效规定第十三条。无报案回执则该中断行待核。

中止须核验第一百九十四条：在时效期间**最后六个月内**因不可抗力或其他障碍不能行使请求权。不得用“一直在治病”“一直协商”概括成中止。

二十年最长保护从**权利受到损害之日**起算，与三年分列，不得互相替代。普通时效适用中止中断；二十年适用延长、不适用中止中断。

时效抗辩由当事人主张。本任务不得写“法院会主动审查并驳回”。

禁止指导倒签催告、伪造签收或补做中断证据。用户要求倒签：整体停止。

## 节点 3　对保险人的请求 vs 对侵权人的请求

必须分表，禁止合成“对保险公司也是三年”或“对保险公司一定是两年”的唯一结论。

- 对侵权人、用人者的人身损害赔偿：普通时效三年并行情景（节点 1）。
- 被保险人或受益人向保险人请求赔偿或给付保险金：须运行时核验《保险法》第二十六条（人寿保险以外二年、人寿保险五年，自知道或应当知道保险事故发生之日起算）与民法典第一百八十八条“法律另有规定的，依照其规定”是否冲突。司法实践存在二年与三年之争。本任务只并列两种情景并标 `待核`，**禁止写死唯一期间**。交强险保险人作为道路交通事故损害赔偿共同被告时的请求，不得直接套用保险金请求时效而不加待核。

保险合同其他争议（非保险金请求）不得用第二十六条顶替。

## 节点 4　禁止混算的其他期间

每种期间单独一行。类型必须标明。

| 类型 | 处理 | 禁止 |
| --- | --- | --- |
| 管辖异议期、答辩期、上诉期 | 单独红旗；以送达日起算，作出日不得代替送达日 | 用三年时效去算答辩期 |
| 事故认定复核 | 红旗转介 `复核交通事故认定`；逾期只影响行政复核 | 写成民事时效或索赔前置 |
| 鉴定异议／重新鉴定 | 已有鉴定时标红旗 | 编截止日期充法律意见 |
| 诉前保全后起诉期限 | 红旗 | 与三年时效混算 |
| 工伤或劳动申请期限 | 仅红旗，转劳动或工伤竞合 | 写入民事时效行；本任务出具工伤截止日法律意见 |
| 先予执行、救助基金 | 只转介 | 当成本任务期间结论 |

不得用答辩期去挡实体请求时效。

## 节点 5　输出纪律

每行 `T#` 只对应一种期间类型、一个相对人和一个起算事件。输出公式和待核项。

本任务不把“将于某年某月某日届满”或“还剩 N 天”写成法律结论。并行情景、义务人不明、治疗未稳定、保险二年争点或刑民重新起算任一存在，截止日字段停止。

本任务不写催告函发送稿。需要发函时转介 `准备侵权索赔通知`，且不得为制造中断而倒签。
