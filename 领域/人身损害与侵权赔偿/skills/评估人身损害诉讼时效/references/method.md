判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。禁止唯一截止日或胜诉率。本任务不选定受诉法院。

## 节点 1　时效起算

运行时核验民法典第一百八十八条：三年；自权利人知道或者应当知道权利受到损害**以及义务人**之日起计算；法律另有规定除外；自权利受到损害之日起超过二十年的，人民法院不予保护，特殊情况可申请延长。

建立并行情景，不得合并成一天：

| 情景 | 起算事件 | 何时采用 |
| --- | --- | --- |
| T-事故 | 侵害发生日 | 当场知悉行为人且损害已明确 |
| T-义务人 | 查清或应当查清义务人日 | 逃逸、侵权人后查明、保险人后披露 |
| T-稳定 | 治疗相对稳定或定残日 | 损害范围当时无法知道 |
| T-死亡 | 死亡日及近亲属知悉日 | 受害人死亡 |
| T-代理 | 法定代理人知悉日 | 无或限制行为能力人，核验总则编解释第三十六条 |
| T-191 | 年满十八周岁当日 | 仅未成年人遭受性侵害，核验第一百九十一条；其他伤害不得套用 |

未成年人普通人身损害不得错误套用第一百九十一条。日期冲突：全部列出，截止日字段停止。

对驾驶人、用人者、保险人的时效相对人分列。保险报案到达保险人，不当然中断对侵权人的时效。

## 节点 2　中断、中止、二十年

中断候选须有可回链事实：权利人向义务人提出履行请求且到达、义务人同意履行、提起诉讼或申请仲裁。微信“已读”不等于到达。

中止须有法定障碍事实，不得用“一直在治病”概括。

二十年最长保护从权利受到损害之日起算，与三年分列，不得互相替代。

时效抗辩由当事人主张，本任务不得写“法院会主动审查并驳回”。

## 节点 3　禁止混算的其他期间

| 类型 | 处理 |
| --- | --- |
| 管辖异议期、答辩期、上诉期 | 单独红旗；以送达日起算，作出日不得代替送达日 |
| 事故认定复核期 | 单独红旗 |
| 鉴定异议／重新鉴定 | 单独红旗 |
| 诉前保全后起诉期限 | 红旗 |
| 工伤认定申请期限 | 转劳动，不写入民事时效表充数 |

不得用三年时效去算管辖异议或答辩期，也不得用答辩期去挡实体请求时效。

## 节点 4　输出纪律

每行 `T#` 只对应一种期间和一个起算事件。输出公式和待核项，不输出“将于某年某月某日届满”作为法律结论，除非起算事件、送达和现行条文均已核验且无并行情景。任一要件缺失：字段停止。
