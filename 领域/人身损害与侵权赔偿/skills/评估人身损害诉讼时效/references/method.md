# 评估人身损害诉讼时效方法

本文件是可执行判断节点。事故日不是当然唯一起算。三年须自知道或应当知道权利受损以及义务人。二十年自权利受损日起算，不是三年的替代，不适用中止中断。已读不是到达。保险报案不当然中断对侵权人。持续治疗不是中止。过时效不是不能立案。法院不依职权适用时效。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已届满终稿、唯一截止日、剩余天数、选定法院、代提交、未知写零。本任务不定罪，不定残，不写发送版催告或诉状。本窗闸名只能是时效闸，禁止复用期间闸、期限闸、除斥闸、时线闸、评估闸、侵权闸、名单闸、鉴定闸、发送闸、起诉闸。预留不得占用：立案闸、鉴定闸、发送闸、起诉闸。本窗 `LX#` 是时效行。主路径只用 `Q-钟`，禁止用 `Q-期`、`Q-历`、`Q-时`、`Q-效`、`Q-日`、`Q-签`、`Q-责` 作主路径。本窗 `Q-时` 只作「三年混算鉴定异议、复核、答辩、上诉或工伤申请」不关窗码。本窗 `Q-日` 只作「唯一截止日或剩余天数」不关窗码。本窗 `Q-签` 只作「评估即已届满或已提交」不关窗码。英文 id 禁止使用，一律用中文技能名 `评估人身损害诉讼时效`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《民法通则》二年或人身伤害一年、民通意见伤害明显从受伤害日起算、已失效《侵权责任法》、法释〔2018〕12 号、保险法 1995 年第二十六条「消灭」、产品质量法 1993 年第四十五条行政处罚条、2008 年时效规定第十三条（与起诉同等效力）时记为噪声。禁止指导倒签催告或伪造中断证据。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现相对人或期间碎片扫描，不是默认闭集。
`LX#` 固定列：`编号｜相对人与期间类型切片｜起算事件并行｜中断中止或二十年｜届满风险｜打开接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「本案已过期」一笔。无 `E#` 不得写已届满、已中断或已到达。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-钟`。禁止 `T#`、`QJ#`、`SX#`、`QG#`、`TB#`、`A#`、`N#`。一行一个相对人、一种期间类型。

口头「应该还没过期」「最晚哪天起诉」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：治疗相对稳定、定残是实务争点，不是法定「另有规定」。对保险人保险金请求与对侵权人三年分列待核。后续治疗费可能另起算，事故日不得吞掉。

时效闸打开（可出 `LX#` 草案，仍不得标「已届满／唯一截止日／应起诉」）须同时满足：单方无冲突立场已闭合；主成果是时效表，不是总图、不是函、不是诉状；至少一项可编号侵害日、知悉或义务人碎片、催告到达、报案回执或起诉提交碎片。口头「应该还没过期」不算单独开闸材料。

时效闸部分打开：已有碎片，但知悉日、义务人、到达或中断未闭合；对应格待核；仍交十节。无书面评估授权但单方立场已闭合且已有碎片：时效闸部分打开，仍交十节，不是整体停止。

时效闸关闭（仍正触发）：无一可编号碎片。「今天必须出唯一截止日／剩余天数终稿」而无最小碎片不得开闸。不出 `LX#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `LX#` 终稿，**第 7 节不得出唯一截止日或催告函**。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把「日期均无法建立」写成整体停止。

「事故日当然起算」「唯一截止日」「已读即中断」「持续治疗即中止」「保险报案当然中断对侵权人」「过期不能立案」「法院主动审查时效」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `LX#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 时效闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出倒签催告、伪造签收或中断材料、隐匿送达或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 3　时效行 `LX#`

按已出现相对人与期间类型扫描，不是默认闭集。每条须能指向相对人、起算事件或中断接口之一。期间类型：三年普通时效／二十年最长保护／保险金请求期间（二年与三年并列待核）／产品缺陷二年及十年并列待核。复核三日、鉴定异议、答辩、上诉、管辖异议、工伤申请只进红旗或打开接口，不进本行当民事时效。

无 `E#` 不得写已届满、已中断或已到达。状态 `草案`。一次只推荐下一步。未知不写零，不输出唯一截止日或剩余天数。并行情景、义务人不明、治疗未稳定、保险二年争点或刑民重新起算任一存在，届满风险格停止或待核。

热冲突强制处理：

- 事故日当然起算／唯一截止日／已读即中断／持续治疗即中止／保险报案当然中断对侵权人／过期不能立案／法院主动审查／未知写零 → 该格不支持或字段停止；仍出其他 `LX#`。
- 未成年人普通损害套第一百九十一条、第一百九十条套第三人 → 该格不支持；仍出其他 `LX#`。
- 无一碎片 → 关闸，不出 `LX#` 终稿，窗口不关。
- 指导倒签催告、伪造中断材料 → 整体停止，不是该格不支持。

中断须回链到达形态：时效规定第八条书面须到达或应当到达；已读不是到达。对保险人报案不当然中断对侵权人。提交起诉状日起中断，不是立案日。报案控告走时效规定第十三条，2008 年第十三条不得写入 `L#`。中止须最后六个月法定障碍；障碍消除之日起满六个月届满。二十年从权利受到损害日起算，不适用中止中断；三年不适用延长。

## 节点 4　催告、鉴定、管辖与起诉接口

第 7 节只开接口，不得夹带 `LX#` 终稿、唯一截止日或催告函绕闸。闸关闭时第 7 节可写「闸未开，转介待日期编号」，不得补写已届满或应起诉。不选定法院。不代提交。需要合法催告转介 `准备侵权索赔通知`，禁止倒签。未稳定不得转介启动鉴定。产品缺陷转介 `评估产品致人损害`。刑民报案转介 `分流刑民交叉` 或 `评估刑附民与另行起诉`。

下一步只转介：`评估人身侵权责任`、`评估责任主体与保险覆盖`、`评估人身损害管辖`、`提出人身案件管辖异议`、`准备侵权索赔通知`、`设计人身案件通知送达`、`提起人身损害一审`、`应对人身损害一审`、`评估工伤与第三人侵权竞合`、`分流刑民交叉`、`评估未成年或无行为能力受害人代理`、`复核交通事故认定`、`准备伤残鉴定材料`、`评估后续治疗费另行主张`、`评估刑附民与另行起诉`、`评估侵权人不明路径`、`评估产品致人损害`、`评估道路交通事故责任与保险先行`。禁止此致某院。

若 if 用户催促「事故那天就算三年／最晚哪天起诉／已读了就是中断／过了就不能立案／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

场景①：机动车事故有认定书和急诊病历，治疗未相对稳定，伤残未鉴定。用户主张从事故当日起算三年已经过了、微信已读就是中断、保险公司接了报案对驾驶人也中断了、过了就不能立案、法院会依职权驳回、最晚哪天起诉写死一天、不清楚先写零。时效闸打开或半开。`Q-当`、`Q-读`、`Q-报`、`Q-职`、`Q-日`、`Q-零` 不打开为可靠路径。第 6 节不得把唯一起算、已中断、不能立案、0 写入可执行 `LX#`；对应格 `现有依据不支持` 或字段停止；仍出事故日／义务人／稳定日并行、对驾驶人与对保险人分列、1213 接口红旗、截止日停止等其他 `LX#`。不关窗。不写催告函。不选定法院。
