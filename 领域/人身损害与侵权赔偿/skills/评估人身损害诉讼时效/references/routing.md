# 边界与路由

## 正触发

需要单独核验人身损害民事赔偿请求的诉讼时效起算情景、中断中止或二十年。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 总体责任总图，或综合提问夹带告谁／法院／金额 | `评估人身侵权责任` |
| 管辖连结点 | `评估人身损害管辖`（未安装则 `unavailable`） |
| 管辖异议书 | `提出人身案件管辖异议`（未安装则 `unavailable`） |
| 起诉包 | `提起人身损害一审` |
| 应诉答辩 | `应对人身损害一审` |
| 发送版催告或索赔通知 | `准备侵权索赔通知` |
| 工伤认定或劳动仲裁期限 | 劳动领域；民事时效可留时本窗只标工伤期限红旗 |
| 海事专属 | 海事领域 |

受害人开口且委托范围是时效表时，不因口语化咨询整体停止。双方秘密或倒签催告的整体停止，优先于负触发。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 还要主体、保险、管辖、金额 | `评估人身侵权责任` |
| 工作中第三人 + 工伤申请期限 | `评估工伤与第三人侵权竞合` |
| 刑民交叉、已报案或在侦 | `分流刑民交叉` |
| 无／限制行为能力受害人 | `评估未成年或无行为能力受害人代理` |
| 治疗未稳定却要定残起算 | 鉴定闸见 `准备伤残鉴定材料`；本窗 T-稳定截止日停止 |
| 需要制造中断的合法催告 | `准备侵权索赔通知`，禁止倒签 |

## 易混

治疗仍在继续、义务人刚查到、需要并行情景时正触发。用户只要“去哪个法院告”时负触发至管辖评估。用户要求“告诉我还有几天”而日期冲突或要件缺失时，字段停止，不得编唯一剩余天数。对保险公司的请求不得直接写成与侵权人同一行。
