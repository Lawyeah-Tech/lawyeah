# 边界与路由

## 正触发

人身损害已发生，单方需要分列民事赔偿请求的诉讼时效起算情景、中断中止或二十年。从零、碎片、知悉或到达未核验仍正触发：有可编号侵害日、知悉或义务人碎片、催告到达、报案回执或起诉提交碎片则闸开或半开，出 `LX#` 草案，保持草案。本次不写唯一截止日、不给剩余天数是交付禁令，不是开窗条件。事故日当然起算、已读即中断、过期不能立案，仍正触发。把持续治疗写成中止、把保险报案写成当然中断对侵权人，仍正触发：该格不支持，不改负触发关窗。

双方秘密、倒签催告、伪造中断材料的停止，优先于负触发。上述信号不在下表。不写唯一截止日不是负触发。「事故日当然起算」「唯一截止日」「已读即中断」「过期不能立案」「法院主动审查」「未知写零」不在下表。

## 易混

本窗闸名只能是时效闸，不是期间闸，不是时线闸，不是评估闸，不是侵权闸，不是名单闸，不是起诉闸。`LX#` 不是 `T#`，不是 `QJ#`，不是 `SX#`，不是 `QG#`，不是 `TB#`。主路径是 `Q-钟`，不是 `Q-期`，不是 `Q-历`，不是 `Q-时`，不是 `Q-效`，不是 `Q-责`。`期间闸`／`QJ#`／`Q-期` 是合同包 `评估争议期间`，人身包不得借用。`时线闸`／`SX#`／`Q-历` 是合同包 `建立双向履行时间线`。`Q-时` 是混算不关窗码，不是本窗主路径。`Q-效` 是公司治理决议效力主路径；邻窗 `评估人身侵权责任` 的时效转介已改挂 `Q-钟`。事故日不是当然唯一起算。已读不是到达。保险报案不当然中断对侵权人。持续治疗不是中止。过时效不是不能立案。民法通则二年／一年不是现行三年。民通意见伤害明显从受伤害日起算不是现行唯一起算。保险法 1995 年第二十六条「消灭」不是现行诉讼时效表述。2008 年时效规定第十三条不是现行报案中断条。提出「催告函日期改到去年、补一份已签收」整体停止。本窗不代提交。不选定法院。不定残。不写发送版。不写唯一截止日。不保证胜诉。
