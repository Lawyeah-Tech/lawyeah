# 边界与路由

## 正触发

需要单独核验人身损害民事赔偿请求的诉讼时效起算情景。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 总体责任总图 | `评估人身侵权责任` |
| 管辖连结点 | `评估人身损害管辖`（未安装则 `unavailable`） |
| 管辖异议书 | `提出人身案件管辖异议`（未安装则 `unavailable`） |
| 起诉包 | `提起人身损害一审` |
| 应诉答辩 | `应对人身损害一审` |
| 工伤认定或劳动仲裁期限 | 劳动领域 |
| 海事专属 | 海事领域 |

## 易混

治疗仍在继续、义务人刚查到、需要并行情景时正触发。用户只要“去哪个法院告”时负触发至管辖评估。用户要求“告诉我还有几天”而日期冲突时，字段停止，不得编唯一剩余天数。
