# 执行人身损害生效文书

## 任务目标

在明确、无利益冲突的权利人立场下，形成不代提交的人身损害生效文书执行包：执行闸、`K#` 期限卡、`Enf#` 执行请求（本金分项／已履行扣减／迟延利息待核）、`Clue#` 财产线索。不重审实体。不保证控制财产或执行到位。不选定法院。不写死唯一截止日。未知利息不写零。

`depends-on` 为空。主成果是上诉状转 `提起人身损害上诉`。被执行人应对转 `应对人身损害执行`。执行中分期或以物抵债转 `准备人身执行和解`。私下和解不能直接执行转 `办理人身和解执行力补强`。先予执行转 `申请先予执行医疗费`。保全冻结转 `准备财产或证据保全申请`。保险未赔另案转 `保险公司应对直接索赔`／`直接起诉保险公司`。后续治疗另诉不得写入本执行申请。

## 工作边界

正触发：持有人身损害判决、调解书、司法确认裁定或赋强公证债权文书，主张未获履行，需要执行申请、金额或财产线索。「判决生效了对方不给钱」正触发。文书未生效仍要执行、已读起算二年、保证控制财产、选定某院、过期仍要可提交执行稿、未知利息写零、把私下和解当执行名义、把工伤待遇裁决混入民事主文，仍正触发：执行闸可关，对应格填 `现有依据不支持` 或字段停止，窗口不关，不得改走负触发，不得标执行申请终稿已形成。工伤待遇执行与第三人民事生效文书同时出现：本窗正触发，工伤段分流劳动，民事 `Enf#` 可留。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是尚未生效裁判的上诉状（转 `提起人身损害上诉`）；
- 主成果是被执行人执行异议或履行安排（转 `应对人身损害执行`）；
- 主成果是执行中分期或以物抵债（转 `准备人身执行和解`）；
- 主成果是私下和解司法确认、诉讼调解书或公证赋强手续（转 `办理人身和解执行力补强`）；
- 主成果是紧急医疗费先予执行申请（转 `申请先予执行医疗费`）；
- 主成果是财产或证据保全申请（转 `准备财产或证据保全申请`）；
- 主成果是后续治疗费另诉（转 `准备后续治疗费另诉`）；
- 主成果已是再审或检察监督文书（P2 `unavailable`；用户仍要普通执行则闸关不关窗）；
- 纯工伤待遇执行且无第三人民事生效文书（转劳动）；
- 刑事责令退赔执行终稿（转刑事或执行交叉红旗）；
- C 端只要大众准备包（只分流）；
- 未成争改合同（审查起草搁置）。

未生效仍要执行、过期仍要普通执行稿、保证控制财产、选定法院、已读起算、利息写零**不在负触发表**，窗口不关。双方秘密、伪造财产线索陷害案外人、伪造文书、倒签签收、违法查询个人信息**不在负触发表**，走整体停止。

## 建立工作坐标

确认：使用者与授权；权利人（死亡案件近亲属逐名）；生效文书类型与案号；作出日、送达日、签收日、上诉期满日分列；履行期间；已履行部分；财产线索来源；法域。

口头「判决刚到」「已经生效」、微信已读、PDF 截图只登记 `S#`／`V#`。不得升格为已生效、期间已起算或已控制财产。用户坚持「此致某院」「保证把房子控住」不构成选定法院或保证到位的授权。

同时掌握双方秘密，或权利人与被执行人同时交材料争同一份执行申请：`整体停止`，不得以选边治愈，也不得改走负触发。提出伪造财产线索陷害案外人、伪造生效文书、倒签送达或签收、指导违法查询公民个人信息：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`R#` 生效文书；`D#` 履行凭证、财产线索；`E#` 送达或签收凭证；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`K#` 期限卡；`Enf#` 执行请求；`Clue#` 财产线索；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。稿件状态只用 `草案`、`执行闸关闭`、`提交前待核`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。本任务默认 `草案`，不代提交。禁止「保证控制财产」「此致某院」「已读即生效」「利息写零」。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：申请执行的期间为二年，从法律文书规定履行期间的最后一日起计算，未规定履行期间的从法律文书生效之日起计算；该期间适用诉讼时效中止、中断的规定；由第一审人民法院或者与第一审人民法院同级的被执行的财产所在地人民法院执行；调解书经双方当事人签收后即具有法律效力；被执行人未按指定期间履行金钱给付义务的，应当加倍支付迟延履行期间的债务利息。技能正文条号不是 `L#`。噪声：2017 年民事诉讼法约第二百三十九条直接当现行、未生效即可强制执行、已读或截图即生效或期间起算、调解书送达即生效、选定唯一法院、保证控制财产、未知写零、重审实体改判、私下和解可直接执行、过期仍出可提交普通执行终稿。不可用则生效、申请执行期间、管辖、迟延利息字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变文书生效时点、申请执行期间、执行管辖或迟延履行利息结论的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补未生效难立案执行、已读不当作签收、超过申请执行时效提出申请法院仍应受理但被执行人异议成立可不予执行、财产线索须合法来源、不保证控制财产的实务反例。
- `search_template` 只借执行申请书或财产线索表栏目，不把范本当法定格式、已提交文本、发送版或指定唯一执行法院。

工具不可用时继续 `K#`／`Enf#`／`Clue#` 编目与文书履行事实；生效、申请执行期间、管辖、迟延利息字段停止。不得凭记忆写未生效可执行、唯一截止日、选定法院、保证控制财产或未知写零。

## 判断节点

执行顺序和停止条件以 [执行申请方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、执行闸与不关窗

工伤三段分流，民事执行可留。双方秘密、伪造线索陷害案外人第一次停。未生效仍要执行、过期、保证控制财产、选定法院不关窗。主成果是上诉状才负触发。

### 2. 期限卡 `K#`

申请执行期间常见二年。有履行期间的自最后一日起算，无期间的自生效之日起算。中止中断待核。调解书双方签收生效，送达≠签收。已读不得起算。过期只停提交稿不关窗。超过时效提出申请法院仍应受理，被执行人异议成立才可能不予执行。

### 3. 执行请求 `Enf#`

一行一项主文。已履行扣减。迟延利息参数未知不写零。不重审实体。保险未赔另案红旗。后续治疗另诉不得写入。执行追加只红旗。

### 4. 财产线索 `Clue#`

合法来源。猜测须标明。禁止陷害案外人。不保证控制财产。

### 5. 申请草稿与转介

草案不代提交。管辖连结点并列，不预填此致某院。不保证立案或到位。执行和解、被执行应对只转介。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；权利人与被执行人同时交材料；伪造财产线索陷害案外人；伪造生效文书；倒签送达或签收；指导违法查询公民个人信息。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：生效时点、申请执行期间、管辖、迟延利息未核验。执行闸未开则提交稿停止，窗口不关。用户要未生效仍执行、已读起算、保证控制财产、选定法院、利息写零、过期仍交普通终稿则该格停止，窗口不关。
- `目标停止`：主目标变为上诉状、被执行应对、执行和解、先予执行、和解补强、保全或另诉终稿。未生效仍要执行、保证控制财产不在目标停止。

禁止指导伪造线索、倒签签收或违法查人。不给到位率。不选定法院。不代提交。不编唯一截止日。不把未知写成零。不定残。不保证控制财产。不重审实体。
