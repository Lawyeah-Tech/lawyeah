# 输出合同

按触发结果选择交付形状。执行闸未打开不得交付执行申请终稿或保证控制财产。禁止选定唯一执行法院或预填「此致某院」。禁止已读、截图、作出日当生效或期间起算。禁止调解书送达即生效。禁止未生效写成可提交执行终稿。禁止过期仍出可提交普通执行终稿。禁止未知利息写零。禁止重审实体改判。禁止胜诉率。禁止代提交。禁止选边治愈。不定残。不保证控制财产或执行到位。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 执行闸关闭或节点 0 整案转出 | 第 1、2、10 节：关闭理由、生效待核和最小补证。可附停止的 `K#`／`Enf#`／`Clue#`。禁止执行终稿、保证控制财产、唯一截止日、选定法院。对民事执行可留时不得因工伤整案转出 |
| 整体停止 | 第 1、10 节。禁止 `Enf#`／`Clue#` 策略包、选边、伪造线索或倒签签收步骤。双方秘密、伪造财产线索陷害案外人、伪造文书、倒签签收、违法查人信息第一次即停，优先于负触发；无选边治愈，无「坚持」门槛 |
| 用户要未生效仍执行、已读起算二年、保证控制财产、选定某院、过期仍交、利息写零（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；闸未开则仍只交 1、2、10；过期则草稿节停止；不得改走负触发关窗；不得标执行申请终稿 `已形成` |
| 正触发且闸开（可部分开） | 下列十节表头均出现；生效、期间、利息未核验格待核；一行一项；禁止为填满而写保证控制财产、此致某院、已读起算或未生效可执行 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入执行申请终稿已形成。双方秘密未解不得进入「部分形成」。每个 `K#`／`Enf#`／`Clue#` 必须带来源和三值判断。`L#` 不得直接抄技能内条号。未生效可执行、保证控制财产若返回则记噪声。稿件状态默认 `草案`。

## 1. 触发、单方立场、授权与成果状态

执行闸开、部分开或关。权利人立场必须标明。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。稿件默认 `草案`。不代提交。不保证控制财产。

## 2. 来源登记与 MCP 调用表

`S/R/D/E/L/I/G/K/Enf/Clue/V`。口头刚到、已读只登记 `S#`／`V#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 期限卡 `K#`

申请执行期间常见二年。有履行期间的自最后一日起算，无期间的自生效之日起算。中止中断待核。调解书双方签收。已读不得起算。过期只停提交稿。超过时效仍应受理，异议成立才可能不予执行。

## 4. 执行请求 `Enf#`

一行一项主文。已履行扣减。迟延利息参数未知不写零。不重审实体。保险另案红旗。另诉额不得写入。

## 5. 财产线索 `Clue#`

合法来源。猜测须标明。禁止陷害案外人。不保证控制财产。

## 6. 管辖连结点

一审法院与财产所在地同级法院分列。不选定唯一法院。不预填此致某院。

## 7. 申请草稿

草案，不代提交。过期则本节停止。不利已履行、未生效风险必须入稿。

## 8. 保险、工伤与邻接分流

保险未赔不改判。工伤段分流，民事可留。执行追加只红旗。执行和解、被执行应对只转介。

## 9. 下一步与转介

转介执行应对、执行和解、上诉、先予执行、和解补强、保全只点名。不写成发送版或「立案执行」指令。不代提交。不保证到位。

## 10. 缺口、停止项与提示

须列对方最强解释：判决刚到微信已读就算两年、保证先把房子控住、此致某区法院、还没生效也要执行、利息先写零、过了两年也照交、调解书送达就算生效、私下和解也能强制执行、工伤待遇裁决和民事判决一起写进同一份申请、执行里把保险公司追加进来改判限额、后续治疗八十万一并执行、两边材料都给你选边、编一套案外人房产线索让法院去查身份证。

本成果不是已提交执行申请、不是被执行应对、不是执行和解、不是上诉状、不是先予执行、不是和解补强、不是发送版、不保证控制财产、不是唯一截止日、不是选定法院。不代提交。不重审实体。
