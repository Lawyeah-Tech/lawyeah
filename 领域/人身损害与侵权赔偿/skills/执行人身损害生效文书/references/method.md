# 执行申请方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。稿件状态只用 `草案`、`执行闸关闭`、`提交前待核`、`停止`。禁止胜诉率、必然责任比例、唯一必得总额、唯一截止日、选定法院、自行宣布伤残等级、保证控制财产、保证执行到位、代提交、未知写零、重审实体改判。本任务不代提交。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、已失效《合同法》、2017 年民事诉讼法约第二百三十九条直接当现行、未生效即可强制执行、已读或截图即生效、调解书送达即生效、保证控制财产、选定某院时记为噪声，不得写入 `L#`。禁止指导伪造线索陷害案外人、倒签签收或违法查询公民个人信息。

`K#` 固定列：`编号｜文书名称｜文书类型（判决／裁定／调解书／确认裁定／赋强执行证书／其他）｜权利人／被执行人分列｜作出日｜生效事件（上诉期满未上诉／双方签收／确认裁定作出／执行证书｜待核）｜生效日｜履行期间末日｜申请执行期间类型（二年／中止中断待核／涉外待核）｜起算事件｜期间长度待核｜待核截止｜过期是否只停提交稿｜状态｜来源回链`。一文书一卡。口头「已经生效」、已读、截图、作出日不得填生效日。不写死唯一日历截止日。

`Enf#` 固定列：`编号｜依据文书与案号｜申请执行人（死亡案件近亲属逐名或标缺口）｜被执行人｜主文给付项（一行一项）｜已履行扣减回链｜未履行本金｜迟延履行利息／迟延履行金（参数待核，禁止写零冒充、禁止默写唯一利率）｜申请执行费用红旗｜措施请求（查询／冻结／划拨／评估拍卖；给付≠保全申请终稿）｜管辖连结点并列（一审法院／与一审同级的财产所在地，不选唯一）｜工伤待遇段（分流劳动，不写入民事结论）｜保险另案红旗（不改判）｜后续治疗另诉红旗（不得写入本执行申请）｜状态｜来源回链`。禁止一行打包改判、加伤残等级、把未生效主文写成可执行、把私下和解写成执行依据。

`Clue#` 固定列：`编号｜类型（账户／不动产／车辆／股权／保险权益／工资／其他）｜识别信息｜来源合法性（公开／当事人提供／律师调查令待核｜违法手段标停止）｜是否案外人｜与被执行人关系待核｜拟措施｜猜测已标明｜状态｜来源回链`。猜测必须标明。禁止指导违法查人信息。禁止编造线索陷害案外人。不保证控制财产。

口头「判决刚到」、微信已读、PDF 截图只进 `S#`／`V#`，不得升格 `R#` 已生效或 `K#` 已起算。

## 节点 0　分流、立场、执行闸与不关窗

整案转出或闸关闭只交付第 1、2、10 节或标注停止的 `K#`／`Enf#`／`Clue#`，不得交付执行申请终稿，不得标保证控制财产。闸部分打开时：仅对已生效且可回链的给付项给出草案，其余行停止或不打开。

| 信号 | 处理 |
| --- | --- |
| 主成果是尚未生效裁判的上诉状 | 负触发 `提起人身损害上诉` |
| 未生效仍要执行（主成果仍是执行申请） | **正触发**，执行闸关，窗口不关 |
| 主成果是被执行人执行异议或履行安排 | 负触发 `应对人身损害执行` |
| 主成果是执行中分期或以物抵债 | 负触发 `准备人身执行和解` |
| 主成果是私下和解司法确认、诉讼调解或公证赋强手续 | 负触发 `办理人身和解执行力补强` |
| 主成果是先予执行申请 | 负触发 `申请先予执行医疗费` |
| 主成果是保全申请 | 负触发 `准备财产或证据保全申请` |
| 主成果是后续治疗另诉 | 负触发 `准备后续治疗费另诉`；另诉额不得写入本执行申请 |
| 再审或检察监督文书 | P2 `unavailable`；用户仍要普通执行则闸关不关窗 |
| 纯工伤待遇执行且无第三人民事生效文书 | 整案转劳动；夹带第三人民事生效文书则本窗正触发，工伤段分流，`Enf#` 可留并转介 `评估工伤与第三人侵权竞合` |
| 刑事责令退赔 | 转刑事或执行交叉红旗；民事生效文书可留 |
| 未成争改合同 | 审查起草本窗搁置 |

执行闸打开（可出 `Enf#`／`Clue#` 草案，仍不代提交、不保证控制财产）须同时满足：单方无冲突权利人立场与授权；主成果是强制执行申请／金额／线索，不是上诉状、被执行异议、执行和解、先予执行、和解补强；依据文书已生效或生效事件可回链（调解书双方签收、判决上诉期满未上诉、确认裁定、赋强执行证书等），缺口则该行不打开可提交；拟交付不含重审实体改判、选定唯一法院、唯一截止日、发送版、代提交、未知写零、保证控制财产、伪造线索。

闸关闭（仍正触发）：未生效仍要执行；仅已读／截图当生效；申请执行期间过期仍要普通可提交稿；写死唯一截止日；选定某院；保证控制财产；未知利息写零；把工伤待遇裁决混入民事主文且不分列；把后续治疗另诉额写入执行申请；重审实体。闸未开则仍只交 1、2、10 节。过期：十节表头可出现，申请草稿节停止。

「未生效仍要执行」「已读起算」「保证控制财产」「选定法院」「过期仍交」「利息写零」**不关窗**。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或权利人与被执行人同时交材料争同一份执行申请且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出伪造财产线索陷害案外人、伪造生效文书、倒签送达或签收、指导违法查询公民个人信息，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　期限卡 `K#`

检索锚点：申请执行的期间为二年。法律文书规定履行期间的，从最后一日起计算；未规定履行期间的，从法律文书生效之日起计算。申请执行时效的中止、中断，适用法律有关诉讼时效中止、中断的规定。2023 修正后常见第二百四十六条一类，条号运行时核验，不是 `L#`。2017 年约第二百三十九条不得默写为现行 `L#`。申请执行时效期间、计算方法以及中止中断事由不得约定变更；预先放弃时效利益无效。

超过申请执行时效期间提出申请的，人民法院应当受理；被执行人对申请执行时效提出异议且审查成立的，裁定不予执行。过期：提交稿停止，窗口不关，不得写成当然失权关窗。

调解书经双方当事人签收后即具有法律效力。送达过程 ≠ 签收。拒收不得写成已可执行。已读、截图不得起算。判决须上诉期满未上诉或二审生效。口头「判决刚到」不得升格已生效。司法确认裁定、赋强公证债权文书可作为执行依据；私下和解不能直接申请强制执行。

执行管辖：由第一审人民法院或者与第一审人民法院同级的被执行的财产所在地人民法院执行。连结点分列，不选定唯一法院，不预填「此致某院」。

## 节点 2　执行请求 `Enf#`

申请执行条件检索锚点：法律文书已经生效；申请执行人是生效法律文书确定的权利人或其继承人、权利承受人；法律文书有给付内容且执行标的和被执行人明确；义务人在期限内未履行义务；属于受申请执行的人民法院管辖。七日内立案或裁定不予受理待核，不保证立案。

一行一项主文。已履行必须扣减。迟延履行利息自指定履行期间届满之日起计算，参数未核验不写零，禁止默写唯一利率；未明确放弃的，执行中仍可追索待核。精神损害与物质损失按主文，不重开实体。保险未赔部分仍可能向保险人另案，不在执行中改判。后续治疗另诉额不得写入本执行申请。执行追加被执行人不是诉讼追加，本窗只红旗，终稿不在本窗。死亡赔偿权利人争议转 `评估死亡赔偿权利人与分配`。

## 节点 3　财产线索 `Clue#`

合法来源。猜测须标明。不能因对方控制而推定材料存在或内容有利。不得指导侵入、购买公民个人信息、伪造案外人财产关系。不保证查询、冻结或控制财产。执行通知不等于已控制财产。

---

## 节点 4　申请草稿与转介

草稿栏目：申请执行人、被执行人、依据文书、请求、线索。状态默认 `草案`。不代提交。不利已履行、未生效风险必须入稿。闸未开不得标执行申请终稿 `已形成`。

| 接口 | 本窗 | 转介 |
| --- | --- | --- |
| 尚未生效要上诉 | 负触发（主成果是上诉状） | `提起人身损害上诉` |
| 被执行人应对 | 负触发 | `应对人身损害执行` |
| 执行和解 | 负触发 | `准备人身执行和解` |
| 私下和解要执行力 | 负触发 | `办理人身和解执行力补强` |
| 先予执行 | 负触发 | `申请先予执行医疗费` |
| 保全冻结 | 负触发 | `准备财产或证据保全申请` |
| 保险未赔另案 | 只红旗 | `保险公司应对直接索赔`／`直接起诉保险公司` |
| 工伤待遇 | 分流；民事可留 | `评估工伤与第三人侵权竞合` |
| 后续治疗另诉 | 不得写入执行申请 | `准备后续治疗费另诉` |

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过执行闸直接给保证控制财产、未生效可执行、选定法院或利息写零。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if 金额参数不足，then 该行标未知，禁止写零。
若 if C 端只要大众准备包，then 只分流不回改。

判断状态只许三值。口头转述、截图和「已读」不得写成已生效、已送达、已立案或期限已起算。事故认定书、调解记录不得单独写成民事终局比例或执行名义。

## 本任务回链纪律

本任务成果是「不代提交的执行申请草稿、期限卡与财产线索」。必须包含：执行闸、未生效只关闸不关窗、过期只停提交稿、调解书签收生效、已读不得起算。不包含：上诉状、被执行应对、执行和解、先予执行、和解补强、另诉。禁止保证控制财产。禁止选定法院。禁止选边治愈。禁止把未生效写成负触发或整体停止（伪造除外）。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标执行申请终稿已形成。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接。
风险档 A：未生效名义、过期时效、伪造线索必须单独标可逆性。
