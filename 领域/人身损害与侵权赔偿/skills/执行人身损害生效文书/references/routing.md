# 边界与路由

## 正触发

持有人身损害判决、调解书、司法确认裁定或赋强公证债权文书，主张未获履行，需要执行申请、金额或财产线索。「判决生效了对方不给钱」正触发。文书未生效仍要执行、已读起算二年、保证控制财产、选定某院、过期仍要可提交执行稿、未知利息写零，仍正触发：执行闸可关，对应格停止，窗口不关。工伤待遇执行与第三人民事生效文书同时出现，仍正触发：工伤段分流劳动，民事 `Enf#` 可留。

双方秘密、伪造财产线索陷害案外人、伪造文书、倒签签收、违法查询个人信息的停止，优先于负触发。不得改走负触发去出一方执行申请。未生效仍要执行、过期、保证控制财产、选定法院、已读起算不在下表。伪造陷害不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 尚未生效裁判的上诉状 | `提起人身损害上诉` |
| 被执行人执行异议或履行安排 | `应对人身损害执行` |
| 执行中分期或以物抵债 | `准备人身执行和解` |
| 私下和解司法确认、诉讼调解或公证赋强手续 | `办理人身和解执行力补强` |
| 紧急医疗费先予执行 | `申请先予执行医疗费` |
| 财产或证据保全 | `准备财产或证据保全申请` |
| 后续治疗费另诉 | `准备后续治疗费另诉` |
| 再审或检察监督文书 | P2 `unavailable`（用户仍要普通执行则闸关不关窗） |
| 纯工伤待遇执行且无第三人民事生效文书 | 劳动领域 |
| 刑事责令退赔执行终稿 | 刑事或执行交叉红旗 |
| C 端只要大众准备包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「文书未生效仍要执行」不在本表，是正触发闸关。不得因未生效关窗。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 仅工伤待遇执行且无第三人民事生效文书 | 劳动领域 |
| 医疗损害主轴 | 医疗医药领域；民事执行可留 |
| 海事 | 海事领域 |
| 指导伪造线索陷害案外人、伪造文书、倒签签收或违法查人 | 整体停止 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。民事执行可留。

## 易混

「判决生效了对方不给钱」正触发。「判决刚到、已读就算两年、保证控房、此致某院、还没生效也要执行、利息写零」正触发不关窗，闸关，各格不支持。「我要上诉」：主成果是上诉状才负触发；未生效仍要执行留本窗闸关。「我是被执行人」走执行应对。「私下和解要强制执行」走执行力补强，不能直接当执行名义。「工伤待遇裁决和司机民事调解书一起执行」正触发，工伤段分流，民事可留。「两边材料都给你、编案外人房产线索」整体停止。
