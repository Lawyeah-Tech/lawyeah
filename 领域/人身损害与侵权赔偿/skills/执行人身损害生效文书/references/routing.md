# 边界与路由

## 正触发

持有人身损害判决、调解书等生效文书未获履行。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未生效上诉 | `提起人身损害上诉` |
| 被执行人应对 | `应对人身损害执行` |
| 工伤待遇执行 | 劳动领域 |
| 再审 | `unavailable`（P2） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 工伤仲裁裁决执行 | 劳动领域 |
| 刑事责令退赔执行 | 刑事或执行交叉红旗 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“判决生效了对方不给钱”正触发。“我要上诉”走上诉。“我是被执行人”走执行应对。
