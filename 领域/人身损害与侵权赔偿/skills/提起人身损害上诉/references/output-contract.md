# 输出合同

按触发结果选择交付形状。上诉闸未打开不得交付上诉状终稿或保证改判。禁止选定唯一二审法院或预填「此致某中院」为唯一路径。禁止已读、截图、作出日当送达起算。禁止判决与裁定期间混用或写死唯一日历截止日。禁止调解书普通上诉终稿。禁止超出一审请求当然允许。禁止未上诉部分二审全改。禁止逾期证据当然能用或当然失权。禁止过期仍出可提交普通上诉状。禁止胜诉率。禁止代提交。禁止未知金额写零。禁止选边治愈。不定残。不保证改判。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 上诉闸关闭或节点 0 整案转出 | 第 1、2、10 节：关闭理由、送达待核和最小补证。可附停止的 `K#`／`Ap#`。禁止上诉状终稿、保证改判、唯一截止日、选定中院。对第三人可留时不得因工伤整案转出 |
| 整体停止 | 第 1、10 节。禁止 `Ap#` 策略包、选边、伪造或倒签方法。双方秘密、伪造新证据、倒签送达第一次即停，优先于负触发；无选边治愈，无「坚持」门槛 |
| 用户要已读起算、保证改判、选定某中院、调解书也要上诉、期限过了仍要普通上诉状（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；闸未开则仍只交 1、2、10；过期则草稿节停止；不得改走负触发关窗；不得标上诉状终稿 `已形成` |
| 正触发且闸开（可部分开） | 下列十节表头均出现；期限、范围、新证据未核验格待核；一行一项；禁止为填满而写保证改判、此致某中院、已读起算或过期可提交 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入上诉状终稿已形成。双方秘密未解不得进入「部分形成」。每个 `K#`／`Ap#` 必须带来源和三值判断。`L#` 不得直接抄技能内条号。已读起算、保证改判、调解书可上诉若返回则记噪声。稿件状态默认 `草案`。

## 1. 触发、单方立场、授权与成果状态

上诉闸开、部分开或关。文书类型与送达 `R#`／`E#` 必须标明。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。稿件默认 `草案`。不代提交。

## 2. 来源登记与 MCP 调用表

`S/R/D/E/L/I/G/K/Ap/V`。口头刚到、已读只登记 `S#`／`V#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 期限卡 `K#`

判决十五日、裁定十日，从对该上诉人的送达起算。已读不得起算。一受送达人一卡。不写死唯一日历截止日。

## 4. 上诉请求范围 `Ap#`

一行一项主文。未上诉部分可能生效。超出一审请求待核。调解书行不得打开可提交。

## 5. 理由结构

事实认定、法律适用、程序违法分列。禁止只写不公平。认定书不是民事终局。

## 6. 新证据说明

逾期理由必填或明示无。失权非绝对，亦非当然能用。不得编造一审客观不能。

## 7. 上诉状草稿

当事人、案号、请求、理由。通过原审提出。不预填此致某中院。草案，不代提交。过期则本节停止。

## 8. 再审分流

已生效或过期：再审／检察监督 P2 `unavailable`。窗口不关。不沉默。

## 9. 下一步与转介

原审提交、缴费期间分列待核。转介二审答辩、庭审、后续治疗另诉只点名。不写成发送版指令。

## 10. 缺口、停止项与提示

须列对方最强解释：微信已读那天开始算十五日、裁定也按十五日、调解书可以上诉、直接寄某中院并选定该院、一审没请求的二次手术费二审当然可加、只上诉伤残等级二审应把责任和未上诉的交强险一并改掉、新鉴定当然能用或逾期一律失权、保证改判、过了上诉期仍按普通程序交上去不要推到再审、工伤还在认所以对司机的判决不用上诉、两边材料都给你选边、把已读改成送达回证日期。

本成果不是已提交上诉状、不是二审答辩、不是再审、不是一审重做、不保证改判、不是唯一截止日、不是选定中院。不代提交。
