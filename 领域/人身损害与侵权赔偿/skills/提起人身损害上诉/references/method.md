# 上诉方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。稿件状态只用 `草案`、`上诉闸关闭`、`提交前待核`、`停止`。禁止胜诉率、改判率、唯一必得总额、唯一截止日、选定法院、自行宣布伤残等级、保证改判、代提交。未知金额不写零。本任务不代提交。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、已失效《合同法》、2017 年民事诉讼法旧上诉条号直接当现行、把已读或截图写成上诉期起算、把调解书写成可普通上诉、把过期写成仍可提交、把保证改判或选定某中院写成可执行时记为噪声，不得写入 `L#`。禁止指导伪造新证据、倒签送达或作伪证。

`K#` 固定列：`编号｜文书名称｜文书类型（判决／可上诉裁定／不可上诉裁定／调解书／其他）｜受送达人（驾驶人／所有人／保险人分列）｜作出日｜送达日｜送达方式｜效力凭证｜电子送达是否同意及到达｜期间类型（判决上诉／裁定上诉／上诉费缴纳／补正／涉外／小额终审无上诉期）｜起算事件｜期间长度待核｜待核截止｜状态｜来源回链`。一受送达人一卡。禁止共用。口头截止日只进 `S#`。已读、截图、作出日不得填送达日。

`Ap#` 固定列：`编号｜不服一审主文项｜一审对应请求（无则标未在一审主张）｜上诉请求（撤销／改判／发回／维持部分；调解书行不得打开可提交）｜是否超出一审请求（否／待核／现有依据不支持）｜金额状态（已核实／情景／无法估计，禁止写零冒充）｜理由块（事实认定／法律适用／程序违法，禁止只写不公平）｜新证据及逾期理由（无则空，不得编造）｜对未上诉判项的效力风险｜状态（草案／上诉闸关闭／停止）｜来源回链`。一行一项主文。禁止一行打包「全案改判」。

口头「判决刚到」、微信已读、PDF 下载只进 `S#`／`V#`，不得升格 `R#` 已送达或期限已起算。

## 节点 0　分流、立场、上诉闸与不关窗

整案转出或闸关闭只交付第 1、2、10 节或标注停止的 `K#`／`Ap#`，不得交付上诉状终稿，不得标保证改判。闸部分打开时：仅对送达可回链且文书可上诉的部分给出草案，其余行停止或不打开。

| 信号 | 处理 |
| --- | --- |
| 主成果是一审起诉状或立案包 | 负触发 `提起人身损害一审` |
| 主成果是一审答辩 | 负触发 `应对人身损害一审` |
| 主成果是二审答辩终稿 | 负触发 `应对人身损害二审`；本方仍在己方上诉期不服则本窗正触发，答辩不替代上诉 |
| 已排期二审只要质证询问 | 负触发 `准备人身损害庭审` |
| 主成果是后续治疗另诉 | 负触发 `准备后续治疗费另诉`／`评估后续治疗费另行主张`；超出一审的独立新请求不写进可交上诉请求 |
| 主成果已是再审或检察监督文书 | P2 `unavailable`；用户仍要普通上诉则闸关不关窗 |
| 纯工伤待遇上诉且无第三人 | 整案转劳动；夹带对第三人民事裁判则本窗正触发，工伤段分流，`Ap#` 可留并转介 `评估工伤与第三人侵权竞合` |
| 医疗损害上诉主轴 | 转医疗 |
| 海事上诉 | 转海事 |
| 刑事上诉 | 转刑事 |
| 未成争只要改合同 | 审查起草本窗搁置 |

上诉闸打开（可出 `Ap#` 草案，仍不代提交、不保证改判）须同时满足：单方无冲突上诉方立场与授权；主成果是上诉状／范围／期限／理由，不是一审重做、一审答辩、二审答辩、再审；文书为未生效且依法可上诉的判决，或依法可上诉的裁定（调解书不够开闸）；起算事件可回链为对该上诉人的送达，或明确登记缺口并停止截止日；拟交付不含保证改判、指定某中院、已读起算、过期仍出可提交普通上诉状、伪造新证据。

闸关闭（仍正触发）：送达不明或仅有作出日、口头「判决刚到」；已读 PDF／截图当送达；判决十五日与裁定十日混用或写死唯一日历截止日；调解书、小额终审、不可上诉裁定仍要普通上诉状；向某中院直接上诉并选定该院；超出一审请求当然允许；未上诉部分要求二审全改；逾期证据当然能用或当然失权；保证改判；上诉期已过或裁判已生效仍要按普通上诉提交。闸未开则仍只交 1、2、10 节。过期：十节表头可出现，提交稿停止。

「已读起算」「保证改判」「选定中院」「调解书普通上诉」「过期仍要普通上诉状」**不关窗**。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或原被告同时交材料争同一份上诉策略且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出伪造新证据、倒签送达回证、指导作伪证、隐匿一审不利自认，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　期限卡 `K#`

当事人不服地方人民法院第一审判决的，有权在判决书送达之日起十五日内向上一级人民法院提起上诉；不服裁定的，十日。检索锚点：现行民事诉讼法上诉期间条款（2023 修正后常见第一百七十一条一类，须运行时核验）。条号不是 `L#`。2017 年约第一百六十四条不得默写为现行 `L#`。

作出日 ≠ 送达日 ≠ 已读／截图／发送成功。电子送达须当事人同意，并以到达特定系统之日为送达日，未核验则截止日停止。领域内无住所当事人期间可能为三十日，待核，不得默写十五日。因不可抗力或其他正当理由耽误的，可在障碍消除后十日内申请顺延，是否准许由法院决定，待核。

一受送达人一卡。驾驶人、所有人、保险人分送不得共用截止日。管辖权异议裁定等可上诉裁定另开十日卡，不得与判决十五日混用。小额诉讼程序判决一般不得上诉，该行不打开可提交。缴费期间与上诉期间分列，不得混成一个截止日。

## 节点 2　上诉范围 `Ap#`

一行对照一审主文一项。未上诉判项可能生效，风险必须明示。二审原则上围绕上诉请求审理；未提出的请求原则上不予审理，但一审判决违反法律禁止性规定或损害国家利益、社会公共利益、他人合法权益的除外，例外一律待核，禁止写成二审当然全改。检索锚点：民事诉讼法二审审理范围条款。条号不是 `L#`。

超出一审已主张的独立新请求（含一审未主张的后续治疗、精神损害、被扶养人）：该格 `现有依据不支持` 或待核，不得写入可交上诉请求；转介 `评估后续治疗费另行主张`／`准备后续治疗费另诉`。禁止「二审顺便把伤残从十级改九级并新加被扶养人」。不定残。未知金额不写零。

调解书经双方当事人签收后即具有法律效力，一般不得上诉。检索锚点：民事诉讼法调解书效力条款。条号不是 `L#`。拒收则调解不成，走判决路径待核。人民调解、保险调解、交警调解不是本窗上诉对象。

## 节点 3　理由与新证据

事实认定、法律适用、程序违法分列。不把情绪性「不公平」当理由。事故认定书、调解记录不得单独写成民事终局。驾驶人自认不得写成保险人自认。

新证据须说明逾期理由；是否采纳待核。既非当然能用，也非一律失权。不得指导补造「一审客观不能」叙事。二审新鉴定接口只红旗，终稿转鉴定异议或庭审窗。

## 节点 4　上诉状草稿与转介

上诉状应当通过原审人民法院提出，并按照对方当事人人数提出副本。当事人直接向第二审人民法院上诉的，第二审人民法院应将上诉状移交第一审人民法院。检索锚点：上诉状提出与移交条款。条号不是 `L#`。这不是选定该中院为唯一二审法院的授权。上一级由审级法定。禁止预填「此致某某市中级人民法院」为唯一路径。用户点名某院只登记 `S#`。

草稿栏目：当事人、原审法院与案号、收到裁判时间、上诉请求、理由、证据。状态默认 `草案`。不代提交、不代缴费。对方已上诉不免除本方在己方上诉期内独立上诉；答辩不替代上诉，转介 `应对人身损害二审` 可并行。再审、检察监督属 P2，输出 `unavailable`，窗口不关。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过上诉闸直接给保证改判、已读起算、选定中院或过期可提交。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if C 端只要大众上诉包，then 只分流不回改。

判断状态只许三值。口头转述、截图和「已读」不得写成已受理、已送达或期限已起算。事故认定书不得单独写成民事终局比例。

## 本任务回链纪律

本任务成果是「不代提交的上诉状草稿、期限卡与范围理由」。必须包含：送达起算、过期只停提交稿。不包含：一审起诉状、一审答辩、二审答辩、再审、后续治疗另诉。禁止保证改判。禁止选定中院。禁止已读起算。禁止调解书普通上诉终稿。禁止选边治愈。禁止伪造新证据。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标上诉状终稿已形成。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接。
风险档 A：上诉期、未上诉部分生效、伪造送达必须单独标可逆性。
