# 边界与路由

## 正触发

不服尚未生效的人身损害判决或可上诉裁定，需要上诉状、范围、期限或理由。「判决刚到，要上诉」正触发。已读起算十五日、保证改判、选定某中院、调解书也要上诉、期限过了仍要普通上诉状、超出一审请求当然允许、未上诉部分二审全改，仍正触发：上诉闸可关，对应格停止，窗口不关。工伤待遇与对第三人民事裁判同时出现，仍正触发：工伤段分流劳动，对第三人 `Ap#` 可留。本方仍在己方上诉期内不服，即使对方已上诉，本窗正触发；答辩不替代上诉。

双方秘密、伪造新证据、倒签送达的停止，优先于负触发。不得改走负触发去出一方上诉状。已读起算、保证改判、过期仍要普通上诉、调解书普通上诉不在下表。伪造倒签不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 一审起诉状或立案包 | `提起人身损害一审` |
| 一审答辩状 | `应对人身损害一审` |
| 二审答辩终稿 | `应对人身损害二审` |
| 已排期二审质证询问提纲 | `准备人身损害庭审` |
| 后续治疗另诉 | `准备后续治疗费另诉`／`评估后续治疗费另行主张` |
| 主成果已是再审或检察监督文书 | P2 `unavailable`（用户仍要普通上诉则闸关不关窗） |
| 生效裁判要执行 | `执行人身损害生效文书` |
| 纯工伤待遇上诉且无第三人 | 劳动领域 |
| 医疗损害上诉主轴 | 医疗医药领域 |
| 海事上诉 | 海事领域 |
| 刑事上诉 | 刑事领域 |
| C 端只要大众上诉包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「补造二审新鉴定」「把已读改成送达回证日期」「两边材料都给你选边」不在本表，走整体停止。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 仅工伤待遇上诉且无第三人 | 劳动领域 |
| 医疗损害上诉主轴 | 医疗医药领域 |
| 海事上诉 | 海事领域 |
| 刑事上诉 | 刑事领域 |
| 指导伪造新证据、倒签送达或作伪证 | 整体停止 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。对第三人上诉可留。

| 信号 | 转介 |

| 生效要执行 | `执行人身损害生效文书` |

## 易混

「判决刚到，要上诉」正触发。「对方上诉了」：若本方只要答辩走二审应对；本方仍要独立上诉且在己方期内，本窗正触发。「判决生效很久了」：闸关，再审 P2 unavailable，窗口不关，不沉默。「微信已读判决 PDF，从已读算十五日，保证改判，此致某中院，过几天逾期仍要按普通上诉交」仍正触发；已读不得起算；保证改判、选定中院各格不支持；过期只停提交稿。「调解书签了不服要上诉」闸关，一般不得上诉，窗口不关。「工伤还在认，要对司机和交强险的判决上诉」正触发，第三人 `Ap#` 可留。「两边材料都给你选边、补一份二审新鉴定」整体停止。
