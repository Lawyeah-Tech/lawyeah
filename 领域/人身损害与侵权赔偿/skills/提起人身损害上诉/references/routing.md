# 边界与路由

## 正触发

不服尚未生效的人身损害裁判，需要上诉。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 已生效再审 | `unavailable`（P2） |
| 被上诉答辩 | `应对人身损害二审` |
| 重做一审起诉 | `提起人身损害一审` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 刑事上诉 | 刑事领域 |
| 劳动裁决司法审查 | 劳动领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“判决刚到，要上诉”正触发。“对方上诉了”走二审应对。“判决生效很久了”再审 P2 unavailable。
