# 提起人身损害上诉

## 任务目标

在明确、无利益冲突的上诉方立场下，对尚未生效的人身损害判决或裁定形成不代提交的上诉包：上诉闸、`K#` 期限卡、`Ap#` 范围与理由、上诉状草稿。不保证改判。不选定某中院。上诉状通过原审人民法院提出，由原审移送上一级。已读不等于送达。判决上诉期自判决书送达之日起十五日内，裁定十日，期间长度待核，不写死唯一日历截止日。过期只停提交稿不关窗。调解书经双方签收即生效，一般不得上诉。未上诉部分可能生效。二审原则上不超出一审诉讼请求。新证据须说明逾期理由，逾期失权非绝对。

`depends-on` 为空。被上诉答辩转 `应对人身损害二审`。一审起诉包转 `提起人身损害一审`。一审答辩转 `应对人身损害一审`。已排期二审只要质证询问转 `准备人身损害庭审`。超出一审的后续治疗转 `评估后续治疗费另行主张`／`准备后续治疗费另诉`。已生效再审或检察监督标 P2 `unavailable`，用户咬住本窗不关窗。

## 工作边界

正触发：不服尚未生效的人身损害判决或可上诉裁定，需要上诉状、范围、期限或理由。「判决刚到，要上诉」正触发。已读起算十五日、保证改判、选定某中院、调解书也要上诉、期限过了仍要普通上诉状、超出一审请求当然允许、未上诉部分二审全改、逾期证据当然能用或当然失权，仍正触发：上诉闸可关，对应格填 `现有依据不支持` 或字段停止，窗口不关，不得改走负触发，不得标上诉状终稿已形成。工伤待遇与对第三人民事裁判同时出现：本窗正触发，工伤段分流劳动，对第三人的 `Ap#` 可留。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是一审起诉状或立案包（转 `提起人身损害一审`）；
- 主成果是一审答辩状（转 `应对人身损害一审`）；
- 主成果是二审答辩终稿（转 `应对人身损害二审`）；
- 主成果是已排期二审质证询问提纲（转 `准备人身损害庭审`）；
- 主成果是后续治疗另诉（转 `准备后续治疗费另诉`）；
- 主成果已是再审或检察监督文书（P2 `unavailable`；用户仍要普通上诉则闸关不关窗，不改走负触发踢出）；
- 纯工伤待遇上诉且无第三人民事裁判（转劳动）；
- 医疗损害上诉主轴（转医疗）；
- 海事上诉（转海事）；
- 刑事上诉（转刑事）；
- C 端只要大众上诉包（只分流）；
- 未成争改合同（审查起草搁置）。

已读起算、保证改判、选定中院、调解书普通上诉、过期仍要普通上诉状**不在负触发表**，窗口不关。双方秘密、伪造新证据、倒签送达**不在负触发表**，走整体停止。

## 建立工作坐标

确认：使用者与授权；上诉方；判决或裁定主文；作出日与送达日分列；送达方式与效力凭证；上诉请求与一审已主张对照；新证据及逾期说明；法域。

口头「判决刚到」、微信已读、PDF 下载、截图只登记 `S#`／`V#`。不得升格为已送达或期限已起算。用户坚持「从已读那天算十五日」「此致某中院」不构成打开该格的授权。驾驶人、车主、保险人不得共用一张期限卡。

同时掌握双方秘密，或原被告、保险人与驾驶人同时交材料争同一份上诉策略：`整体停止`，不得以选边治愈，也不得改走负触发。上诉方已开口且委托范围就是本方上诉状、且未掌握对方秘密时，可推定上诉方立场。只要同时掌握双方秘密，无例外整体停止。提出伪造新证据、倒签送达回证、指导作伪证、隐匿一审不利自认：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`R#` 判决书或裁定书；`D#` 一审卷、新证据；`E#` 送达凭证；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`K#` 期限卡；`Ap#` 上诉请求；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。稿件状态只用 `草案`、`上诉闸关闭`、`提交前待核`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。不准许率。本任务默认 `草案`，不代提交。禁止「保证改判」「此致某中院」「已读即起算」。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：当事人不服地方人民法院第一审判决的，有权在判决书送达之日起十五日内向上一级人民法院提起上诉；不服裁定的十日；上诉状应当通过原审人民法院提出；调解书经双方当事人签收后即具有法律效力，一般不得上诉；第二审人民法院应当围绕上诉请求进行审理，未提出的请求原则上不予审理，但一审判决违反法律禁止性规定或损害国家利益、社会公共利益、他人合法权益的除外。技能正文条号不是 `L#`。噪声：已失效《侵权责任法》、已失效《合同法》、2017 年民事诉讼法旧上诉条号直接当现行、已读或截图即上诉期起算、过期仍可按普通上诉提交、调解书可普通上诉、保证改判、选定某中院、超出一审请求当然允许。不可用则上诉期限、审理范围、新证据效力、调解书可否上诉字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变上诉期间、裁定与判决区分或调解书效力的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补已读不当作送达、未上诉部分生效、新证据难进、调解书不能当判决上诉、超一审请求受限的实务反例。
- `search_template` 只借鉴上诉状栏目，不把范本当现行法、已提交文本或唯一二审法院。

工具不可用时继续 `Ap#` 编目与文书登记；上诉期限、审理范围、新证据效力、调解书可否上诉字段停止。不得凭记忆写成已读起算、保证改判、选定中院或过期仍可提交。

## 判断节点

执行顺序和停止条件以 [上诉方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、上诉闸与不关窗

工伤三段分流，对第三人上诉可留。双方秘密、伪造新证据第一次停。过期、已读起算、保证改判、调解书普通上诉不关窗。只要二审答辩负触发。

### 2. 期限卡 `K#`

判决十五日、裁定十日，从对该上诉人的送达起算。已读不得起算。一受送达人一卡。不写死唯一日历截止日。

### 3. 上诉范围 `Ap#`

一行一项主文。未上诉部分可能生效。超出一审请求待核。调解书行不得打开可提交。

### 4. 理由与新证据

事实认定、法律适用、程序违法分列。新证据须说明逾期理由，失权非绝对。禁止只写不公平。

### 5. 上诉状草稿与转介

通过原审提出。不预填此致某中院。不代提交。不保证改判。再审 P2 unavailable 不关窗。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；原被告同时交材料；伪造新证据或补造病历鉴定；倒签送达回证或伪造签收；指导作伪证或统一假口径；隐匿一审不利自认。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：送达日、上诉期、二审范围、新证据效力、调解书可否上诉未核验。上诉闸未开则提交稿停止，窗口不关。用户要已读起算、保证改判、选定中院、调解书普通上诉、过期仍交普通上诉状则该格停止，窗口不关。
- `目标停止`：主目标变为二审答辩终稿、一审起诉包、庭审提纲、后续治疗另诉。过期仍要普通上诉、保证改判不在目标停止。

禁止指导伪造、倒签或代提交。不给胜诉率。不选定法院。不代提交。不编唯一截止日。不把未知写成零。不定残。不保证改判。
