# 边界与路由

## 正触发

高度危险作业、高速轨道运输工具、高压、民用核设施、易燃易爆剧毒放射性等造成人身损害，需要判断无过错责任及减免限额。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 环境生态修复 | 环境能源领域 |
| 海事船舶 | 海事领域 |
| 普通道路交强险 | `评估道路交通事故责任与保险先行` |
| 一般施工地面坑 | `评估施工地面地下设施致害` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 生态修复环境公益 | 环境能源领域 |
| 船舶海上 | 海事领域 |
| 作业人员工伤 | 劳动领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“高压线击伤”正触发。“高速公路开车追尾”仍可能是交通专项。“化工厂泄漏要修生态”转环境。
