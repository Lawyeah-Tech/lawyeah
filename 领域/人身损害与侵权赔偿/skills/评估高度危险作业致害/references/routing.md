# 边界与路由

## 正触发

民用核设施、民用航空器、高度危险物、高空高压地下挖掘或高速轨道运输工具、遗失抛弃或非法占有高度危险物造成人身损害，需要判断无过错路径、按条减免或法定限额。用户要「无过错即绝对全责必得」「一般过失也减免」「约定限额约束受害人」「有警示即免责」「非法进入即自甘风险全免」仍正触发。

双方秘密、进入危险区取证、破坏警示或伪造无警示的停止，优先于负触发。不得改走负触发去出全责或免责方案。

## 易混

「高压线击伤路人」正触发 1240，减免不得套 1238。「小孩翻入变电站」1240 与 1243 分列，1176 不打开。「人行道开挖没护栏摔了」负触发走 1258，不升格地下挖掘。「隧道盾构、矿山地下挖掘、爆破」本窗，不按 1258。「高铁路外第三人」可留 1240；「高铁旅客运输伤害」走 823，本窗不写承运人终稿。「高速公路开车追尾」仍是交通专项，车速高不升格。「化工厂泄漏要修生态」转环境，人身段可标接口。「探险进爆破区就是自甘风险」不得用 1176 替代 1239/1240/1243。「无过错所以全赔」「一般过失也减责」「合同写了限额」不关窗。「进现场拍照证明没牌子」第一次提出即整体停止。
