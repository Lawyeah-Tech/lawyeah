# 输出合同

按触发结果选择交付形状。禁止无过错即绝对全责必得。禁止一般过失减免。禁止 1237/1238/1239/1240 减免串用。禁止把 1243 写入 1240。禁止用 1176 替代高度危险减免。禁止无明文主张 1244 限额。禁止约定限额约束受害人。禁止把未核验限额当必得或当零。禁止写 1258/823/交强险/1176/测算/诉状终稿。禁止选定法院、伤残等级、必得总额。禁止指导进入危险区取证。禁止代提交。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出（作业人员工伤待遇或劳鉴主轴；诊疗过错主轴；环境修复主轴；海事；未成争改作业合同） | 第 1、2、10 节。禁止路径成立结论、全责方案、限额数字、选定法院 |
| 整体停止 | 第 1、10 节。禁止请求、抗辩、金额、选边方案、被告清单、取证步骤。双方秘密、进入危险区取证、破坏警示、伪造无警示、翻越围栏拍照、倒签巡检或伪造伤情时，整体停止优先于负触发；第一次提出即停，无选边治愈，无「坚持」门槛 |
| 用户要「无过错即绝对全责必得」或「一般过失也减免」或「约定限额约束受害人」或「有警示即免责」或「非法进入即自甘风险全免」（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；不得改走负触发关窗；成果不得标 `已形成` |
| 正触发且可评估 | 下列十节表头均出现；分条、减免、1243、限额未核验的单元格填 `依据不足，无法形成结论` 或 `待核`；禁止为填满而编造全责、免责、限额或必得额 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。双方秘密未解不得进入「部分形成」。每个 `Q#` 必须带判断三值和证明负担方。`L#` 不得直接抄技能内条号。

## 1. 触发、单方立场、授权与成果状态

危险类型入座。作业人员、旅客还是地面第三人。双方秘密未解不得进入「部分形成」。

## 2. 来源登记与 MCP 调用表

许可、警示、调查分列。口述没牌子、调查组说免责只登记表面。`L#` 不得抄技能内条号。MCP 未调用也留一行。侵权责任法 69–77、触电解释、铁路十五万若返回则记噪声。

## 3. 分型与经营人分列

1236 不得单独定全责。营运人、经营者、占有人、使用人、所有人、非法占有人一行一主体。工伤应转出则停止无过错实体结论。禁止「必须先工伤才能起诉」。

## 4. 第一千二百三十七条至第一千二百四十条分表

核设施、航空器、危险物、高空高压地下挖掘高速轨道各行各条。减免串用格填 `现有依据不支持`。一般过失减免格填 `现有依据不支持`。绝对全责必得格填 `现有依据不支持`。

## 5. 第一千二百四十一条、第一千二百四十二条

遗失抛弃与非法占有分列。交管不是所有人当然免责。被盗不是所有人当然免责。连带不是当然全额。

## 6. 第一千二百四十三条非法进入（独立节）

禁止并入第 4 节 1240。措施与警示两项未核验则减免待核。1176 `不打开`。小孩翻入待核，不得当然免责或当然不适用。

## 7. 第一千二百四十四条限额接口

无明文不打开。数字未核验则停止，禁止写零。约定限额不当然约束受害人。故意或重大过失不得主张限额。禁止十五万、四十万、三亿默写为必得。

## 8. 邻接红旗与证据禁止

1258、823、交强险、1176、物件、工伤：打开、不打开或待核，不写那些终稿。不进入危险区，不翻围栏，不挪牌再拍。事故调查报告不是民事终局。转介保存通知或调查令，不办调取。

## 9. 下一步

转介主体名单、承运人窗、施工窗、过错窗、工伤竞合、测算、发函、起诉、管辖、时效。不定伤残。不选定法院。作业地、结果发生地、各被告住所地并列待核。不写诉状。不写唯一时效截止日。

## 10. 缺口、停止项与提示

须列对方最强解释（无过错即绝对全责必得、一般过失也减免、把 1243 当 1240 免责、用 1238 套触电、用不可抗力免核设施或航空器、无明文主张限额、约定限额约束受害人、挖坑按高度危险、高铁旅客按 1240 吞 823、高速公路因车速高升格、调查报告已免责、有一块牌子即免责、小孩翻入即自甘风险全免、必须先工伤才能起诉、选边即可继续）与证据缺口。

本成果不是承运人终稿、不是施工终稿、不是工伤认定、不是诉状、不是必得总额。
