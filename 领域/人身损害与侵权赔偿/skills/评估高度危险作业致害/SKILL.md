# 评估高度危险作业致害

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成民法典第一千二百三十六条至第一千二百四十四条分路径：1236 一般条款不得写成绝对全责必得；1237 民用核设施、1238 民用航空器、1239 高度危险物、1240 高空高压地下挖掘高速轨道的减免分条核验、禁止串用；1241 遗失抛弃与 1242 非法占有单列；1243 未经许可进入与 1240 分节点；1244 限额无法律明文不得主张，约定限额不当然约束受害人，行为人故意或重大过失不得主张限额。不定伤残，不保证必得，不选定法院。不写 1258 地面施工终稿、823 承运人终稿、交强险分账、1176 自甘风险终稿、测算或起诉状。

`depends-on` 为空。地面施工挖坑转 `评估施工地面地下设施致害`。铁路航空旅客运输转 `评估铁路航空等非海事承运人人身损害`。普通道路机动车转 `评估道路交通事故责任与保险先行`。文体活动自甘风险转 `评估自甘风险与公平分担`。环境修复转环境能源。海事转海事。

## 工作边界

正触发：民用核设施、民用航空器、易燃易爆剧毒高放射性强腐蚀性高致病性等高度危险物、高空高压地下挖掘或高速轨道运输工具、遗失抛弃或非法占有高度危险物造成人身损害，需要判断无过错路径、按条减免或法定限额。用户要「无过错即绝对全责必得」「一般过失也减免」「约定限额约束受害人」「有警示即免责」「非法进入即自甘风险全免」仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要总体责任总图（转 `评估人身侵权责任`）；
- 只要主体名单终稿（转 `评估责任主体与保险覆盖`）；
- 只要 1168–1172 形态终稿（转 `评估共同侵权与连带按份`）；
- 只要过错百分比（转 `评估过错与原因力`）；
- 公共场所或道路挖坑、修缮安装地下设施或窨井主轴（转 `评估施工地面地下设施致害`）；
- 铁路、航空、城市轨道旅客运输过程承运人终稿（转 `评估铁路航空等非海事承运人人身损害`）；
- 普通道路机动车交强险或道交法 76 主轴（转 `评估道路交通事故责任与保险先行`）；
- 文体活动自甘风险或法定公平分担终稿（转 `评估自甘风险与公平分担`）；
- 建筑物倒塌、脱落坠落或高空抛物主轴（转 `评估物件脱落坠落与高空抛物`）；
- 经营场所一般摔伤且非高度危险作业（转 `评估场所安全保障义务`）；
- 环境生态修复或环境公益（转环境能源）；
- 海事油污或船舶（转海事）；
- 作业人员自身受害、工伤认定、劳动能力鉴定或工伤待遇主轴（转劳动；第三人可另开 `评估工伤与第三人侵权竞合`）；
- 只要测算或伤残（转 `测算人身损害赔偿` 或 `准备伤残鉴定材料`）；
- 只要起诉状（转 `提起人身损害一审`）；
- 只要唯一时效截止日（转 `评估人身损害诉讼时效`）；
- 只要选定法院（转 `评估人身损害管辖`）；
- 未成争改作业许可或免责条款（审查起草搁置）；
- C 端只要大众准备包（只分流）。

车速高不升格高速轨道。路面锥桶挖坑不升格地下挖掘。隧道盾构、矿山地下挖掘、爆破、高压击伤路人留本窗。

## 建立工作坐标

确认：使用者与授权；单方立场；危险类型入座（不得先用 1236 定全责）；营运人、经营者、占有人、使用人、所有人、非法占有人名称变体；受害人是作业人员、旅客还是地面第三人；是否未经许可进入（只预留 1243 行）；故意、重大过失、不可抗力、战争武装冲突暴乱候选；限额有无法律明文；法域。

口头「绝对无过错全赔」「没看到牌子」只登记 `S#`。事故调查报告只登记 `R#` 表面。

同时掌握双方秘密或受害人与经营人利益冲突未解：`整体停止`，不得以选边治愈，也不得改走负触发去出全责或免责方案。提出进入危险区域取证、破坏或挪走警示、伪造无警示、翻越围栏拍照、倒签巡检或伪造伤情：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 作业许可、警示、围栏表面；`R#` 事故调查或通报表面；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 责任行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。接口状态只用 `打开`、`不打开`、`待核`。技能正文中的条号是检索锚点，不是已核验 `L#`。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：1236–1244 分条。1237 免责是战争、武装冲突、暴乱等或受害人故意，不是一般不可抗力。1238 仅受害人故意，不是不可抗力。1239 与 1240 是故意或不可抗力免责、仅被侵权人重大过失可减轻，一般过失不减。1243 不得并入 1240，不是 1176。1244 限额须法律明文，故意或重大过失不得主张限额。不可用则路径开闭、分条减免、1243 效果、限额数字字段停止。已失效《侵权责任法》第六十九条至第七十七条、已废止触电人身损害赔偿解释、已删除铁路旅客十五万、华沙公约旧额，不得写入 `L#`。禁止把 1258、823、1176 当本窗 `L#` 终稿。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变分条开闭、减免、1243 或 1244 的条文正文再写入 `L#`。不得编造 `regulation_id`，也不得把摘要条号写成已核验 `L#`。
- `search_practiced` 补分条减免反例、1243 对未成年人是否足够、1240 与 1258 分界、高速轨道第三人与旅客 823 分界、约定限额对受害人的实务反例。

工具不可用时继续危险类型、经营人名称变体、许可警示表面、是否进入区域和损害编目；法律效果字段停止。不得凭记忆写绝对全责、一般过失免责、不可抗力套核设施或航空器、十五万或四十万必得。

## 判断节点

执行顺序和停止条件以 [高度危险方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、分型

1258、823、交强险、1176、环境、海事、工伤整案或负触发转出。双方秘密或进入危险区取证提出即停。

### 2. 第一千二百三十六条一般条款

无过错一般入口。有具体条时优先具体条。禁止写成绝对全责必得。

### 3. 第一千二百三十七条至第一千二百四十条分表

核设施、航空器、危险物、高空高压地下挖掘高速轨道减免禁止串行。

### 4. 第一千二百四十一条、第一千二百四十二条与第一千二百四十三条

遗失抛弃、非法占有单列。非法进入独立行，不得写入 1240。

### 5. 第一千二百四十四条与邻接红旗

无明文不打开限额。约定限额不当然约束受害人。823、1258、1176 只标接口。不定伤残，不选定法院。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；提出进入危险区域取证、破坏警示、伪造无警示、翻越围栏拍照、倒签巡检或伪造伤情。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。
- `字段停止`：分条未入座、减免未核验、1243 措施与警示未核验、限额无明文或数字未核验。用户要绝对全责必得、一般过失减免、约定限额约束受害人、有警示即免责或非法进入即 1176 全免则该格停止，窗口不关。
- `目标停止`：主目标变为 1258、823、交强险、1176、环境、海事、工伤认定、测算或起诉状。

禁止指导进入危险区取证。不给胜诉率。不选定法院。不保证必得。不代提交。
