# 评估高度危险作业致害

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“高度危险作业无过错路径、减免条件和限额接口”。环境生态修复转环境能源。海事转海事。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算、鉴定和证据清单。

## 工作边界

正触发：高度危险作业、高速轨道运输工具、高压、民用核设施、易燃易爆剧毒放射性等造成人身损害，需要判断无过错责任及减免限额。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 环境生态修复或环境公益（转环境能源）；
- 海事油污或船舶（转海事）；
- 普通道路交通事故交强险主轴（转交通专项）；
- 一般场所摔伤。

无过错不等于不得减免。限额必须有法律明文。

## 建立工作坐标

确认：使用者与授权；单方立场；危险活动或危险物类型；经营人；受害人是否非法进入；是否故意；限额或保险；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 作业许可、警示；`R#` 事故调查；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 责任行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典第一千二百三十六条至第一千二百四十四条。不虚构案件系统。

工具不可用时继续事实、主体、程序文书状态和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [高度危险方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　定性与分流

环境修复、海事、普通交强险转出。

### 节点 2　无过错路径

经营人承担无过错责任，法律另有规定除外。

### 节点 3　减免条件

受害人故意、不可抗力、非法进入因条而异，禁止串用。

### 节点 4　限额接口

限额须法律明文。约定限额不当然约束受害人。

### 节点 5　输出纪律

不进入危险区域取证。不给唯一总额。

## 停止与安全

- `整体停止`：立场不明；用户坚持进入危险区域取证。
- `字段停止`：作业定性、减免事由、法定限额未核验。
- `目标停止`：主目标变为环境修复、海事或普通交通分账。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
