# 另诉方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。稿件状态只用 `草案`、`另诉闸关闭`、`提交前待核`、`停止`。禁止胜诉率、必然责任比例、唯一必得总额、唯一截止日、选定法院、自行宣布伤残等级、保证可诉、保证受理、代提交。未知金额不写零。尚未发生且无医疗证明或鉴定结论确定必然发生的费用，禁止写死确定额。本任务不代提交。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、已失效《合同法》、2003 年人身损害赔偿解释已删除条文、把法释〔2022〕14 号第十九条继续给付写成后续治疗另诉闭集、把已判写成绝对不能再告、把概括弃权写成当然消灭、把保证可诉或选定某院写成可执行、把未知写零或未发生写死确定额时记为噪声，不得写入 `L#`。禁止指导伪造新票据、倒签手术日、隐瞒前案已判项目或作伪证。

`Res#` 固定列：`编号｜文书类型（判决主文／调解书／和解／保险了结／执行回执／无）｜前案项目原文｜已判或已执行（是／否／待核）｜保留或弃权（明确保留后续治疗／概括放弃今后一切／未触及／待核）｜相对人｜是否覆盖未知后续治疗（是／否／待核）｜新事实是否进入（打开／不打开／待核）｜判断三值｜待核`。一行一前案项目。禁止合成「前案已经处理过所以整案不能告」。无前案文书则整表字段停止，不编造主文。口头了结、已读截图只进 `S#`。

`P#` 固定列：`编号｜请求项目｜新事实类型（新发生费用／新手术／新鉴定／仅旧事实再评残）｜发生日与票据日｜金额状态（已核实／情景／无法估计；禁止未知写零；禁止未发生写死确定额）｜与原侵害因果｜回链 Res#｜重复起诉风险（该格不支持／待核／未显示）｜管辖连结红旗｜时效红旗｜判断三值｜待核｜来源回链`。一行一请求。禁止一行打包「后续费一共还能要」。闸未开该行不得标可提交。

口头「已经判过」「一次性了结」「医生说还要开刀」只进 `S#`，不得升格 `R#` 已覆盖或 `D#` 必然发生。

## 节点 0　分流、立场、另诉闸与不关窗

整案转出或闸关闭只交付第 1、2、10 节或标注停止的 `Res#`／`P#`，不得交付另诉终稿，不得标保证可诉或保证受理。闸部分打开时：仅对可回链为前案未纳入或裁判后新发生／新鉴定的行给出草案，其余行停止或不打开。

| 信号 | 处理 |
| --- | --- |
| 只要评估能否主张、三档开闭或尚未决定另诉 | 负触发 `评估后续治疗费另行主张` |
| 无前案后续治疗事实、第一次人身损害起诉包 | 负触发 `提起人身损害一审` |
| 裁判尚未生效、要改一审判项 | 负触发 `提起人身损害上诉`；超出一审的独立新请求不得写入可交上诉请求 |
| 要可签和解或保留条款草稿 | 负触发 `起草人身损害和解协议`／`谈判人身损害和解` |
| 要弃权文本审查终稿 | 负触发 `审查保险一次性了结弃权` |
| 前案「不给钱」要强制执行 | 负触发 `执行人身损害生效文书` |
| 只要分项测算数字或唯一必得总额 | 负触发 `测算人身损害赔偿` |
| 只要鉴定委托或申请终稿 | 负触发 `准备伤残鉴定材料` |
| 只要时效唯一截止日 | 负触发 `评估人身损害诉讼时效` |
| 护理、辅助器具或残疾金年限届满继续给付终稿 | 负触发说明走解释第十九条接口，不是本窗 |
| 纯工伤旧伤复发待遇且无第三人侵权民事另诉 | 整案转劳动；夹带对第三人民事另诉则本窗正触发，工伤段分流，`P#` 可留并转介 `评估工伤与第三人侵权竞合` |
| 诊疗过错、病历真实性或医疗损害鉴定终稿 | 转医疗；原侵害后续治疗民事段可留 |
| 海事专门程序 | 转海事 |
| 未成争只要改合同 | 审查起草本窗搁置 |

另诉闸打开（可出 `P#` 草案与起诉状栏目，仍不代提交、不保证受理／可诉）须同时满足：单方无冲突权利人立场与授权；主成果是另诉材料，不是仅评估、不是首次一审总包、不是执行前案、不是上诉改判；至少一行可回链为前案未纳入或裁判后新发生／新鉴定，或主文／调解书明确保留后续治疗，或明确登记缺口并停止该行终稿；拟交付不含保证可诉、保证受理、选定某院、未发生手术写死额、发送版、代提交、伪造票据。

闸关闭（仍正触发）：前案同一已发生项目已判并执行仍要保证可诉；概括弃权当然阻断或当然不阻断；仅对旧鉴定再评残当然可另诉；同一笔重复起诉；选定某院或预填此致某院；尚未发生手术写死确定额；保证受理；未知写零；时效从判决生效日起唯一截止；调解书明确保留后续治疗，用户称已一次性了结所以不能诉。闸未开则仍只交 1、2、10 节或停止的 `Res#`／`P#`。

「前案已覆盖仍保证可诉」「概括弃权当然阻断」「选定某院」「尚未发生手术写死确定额」「保证受理」「已判绝对不能再告」「同一笔重复起诉」「未知写零」**不关窗**。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或受害人与侵权人、保险人同时交材料争同一份另诉策略且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出伪造新票据、把未发生做成已开票、倒签手术日／入院日／票据日、伪造新鉴定、隐瞒前案已判并执行的同一项目或要求从草稿删掉已判项目，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　既判力对照 `Res#`

前案材料分列：判决主文项目、调解书、和解协议、保险一次性了结、执行回执。未提交不得推定「没判过」或「都判过」。口头「已读」、截图不得写成已生效或已执行。

| 条款形态 | 本窗 | 禁止写法 |
| --- | --- | --- |
| 同一已发生项目已判并执行 | 该行通常 `现有依据不支持`；窗口不关 | 负触发关窗；整体停止；保证可诉 |
| 主文／调解书明确保留后续治疗 | 闸可 `打开` 或 `待核`，不保证可诉／受理 | 保留条款单独保证可诉；口头「已了结」吞掉保留 |
| 概括放弃「今后一切费用」 | 标阻断风险，效力待核，转 `审查保险一次性了结弃权` | 当然阻断；当然不阻断；指导倒签反悔或伪造保留条款 |
| 未触及后续治疗 | 既判力格对照主文项目，待核 | 写成已覆盖或已放弃 |
| 无前案文书 | 整表字段停止 | 编造主文；推定都没判过或都判过 |

检索锚点：民诉重复起诉与裁判生效后发生新事实再次起诉的规则，条号运行时核验。同一债权拆分起诉原则上剩余不得另案，不得凭记忆写成当然可拆。禁止把既判力结论当成触发器或安全停止。

用户要「已经判过绝对不能再告」或「前案已覆盖请直接出可诉保证」：该格 `现有依据不支持` 或待核，窗口不关。调解书保留后续治疗、用户称已一次性了结所以不能诉：保留行仍编，「所以不能诉」格不支持，口头了结不升格。

## 节点 2　另诉请求 `P#`

检索锚点：法释〔2022〕14 号第六条第二款。器官功能恢复训练所必要的康复费、适当的整容费以及其他后续治疗费，赔偿权利人可以待实际发生后另行起诉；根据医疗证明或者鉴定结论确定必然发生的费用，可以与已经发生的医疗费一并予以赔偿。条号不是 `L#`。解释第十九条继续给付不是本窗闭集。

| 新事实形态 | 本窗 | 禁止写法 |
| --- | --- | --- |
| 新发生费用、新手术、新票据、新康复 | 可打开该行或待核；须回链原侵害 | 无票据写成已发生；口述升格已开刀 |
| 医疗证明或鉴定确定必然发生、前案未纳入 | 可待核打开；金额情景，不得已核实冒充已发生 | 无证明写死确定额；把必然发生写成必须已发生 |
| 尚未发生且无证明／鉴定确定必然发生 | 金额 `无法估计` 或待实际发生后另行主张 | 写死八十万；未知写零 |
| 仅对旧事实再评残（如十级改九级、无新手术） | 该格通常不支持或待核；可能走再审／鉴定异议；窗口不关 | 当然可另诉；当然必须再审；合成「后续费一共还能要」 |

因果仍须回链原侵害。缺链该格停止或待核，转 `评估因果关系与既往伤病`，不编造。新伤残鉴定若仅再评价旧事实，不自动转再审终稿（再审 P2 `unavailable` 不关窗）。金额展开转 `测算人身损害赔偿`，本窗不得把未知写成已核实。用户要写零或写死未发生额：该格 `现有依据不支持` 或字段停止，窗口不关。

同一笔费用再立一次案：对应 `P#` `现有依据不支持`，**不关窗，不整体停止**。整体停止留给伪造等。

## 节点 3　管辖时效红旗

管辖：侵权行为实施地、结果发生地、各被告住所地分列。公路等事故另核事故发生地等连结点。管辖可能与前案不同。**任何情况下都不选定受诉法院**，起诉状不得预填「此致某院」。用户点名某院只登记 `S#`。亦不得把「必须在某医院手术」写成唯一路径。展开转 `评估人身损害管辖`。

时效：后续费时钟可能与前案不同，或从实际发生日起算，只打红旗。禁止「自前案判决生效日起三年届满」唯一截止。事故日不得吞掉后续费时钟。展开转 `评估人身损害诉讼时效`。已读、截图、作出日不得起算。

被告是否变化：交强险应当列为共同被告的接口转 `直接起诉保险公司`，本窗只标红旗，不选定被告策略终稿。商业三者未核验不得当然列。

## 节点 4　起诉状草稿与转介

草稿栏目：当事人、前案案号与文书、新事实、诉讼请求、证据目录（前案文书、新票据、新病历、新鉴定分列）。状态默认 `草案`。不利事实（已判项目、弃权文本、工伤已领）不得删除。不代提交、不保证受理、不保证可诉。闸未开不得标另诉终稿 `已形成`。

| 接口 | 本窗 | 转介 |
| --- | --- | --- |
| 三档开闭或尚未决定另诉 | 不写评估终稿 | `评估后续治疗费另行主张` |
| 分项金额 | 不得已核实未知 | `测算人身损害赔偿` |
| 概括弃权文本 | 不写效力终稿，不指导倒签 | `审查保险一次性了结弃权` |
| 与原损害因果、既往、参与度 | 只标接口 | `评估因果关系与既往伤病` |
| 鉴定申请 | 不写委托终稿，不定残 | `准备伤残鉴定材料`；多份打架转 `评估伤残等级争议` |
| 工伤待遇与第三人分账 | 工伤段分流；民事 `P#` 可留；医疗费禁止双领红旗 | `评估工伤与第三人侵权竞合` |
| 护理／辅助器具／残疾金年限届满继续给付 | 只打红旗，不是本窗闭集 | 解释第十九条接口 |
| 无前案第一次起诉 | 负触发 | `提起人身损害一审` |
| 裁判未生效要改判 | 负触发 | `提起人身损害上诉` |
| 前案要执行 | 负触发 | `执行人身损害生效文书` |

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过另诉闸直接给保证可诉、选定某院、写死未发生额或发送版。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if 金额参数不足，then 该行标未知，禁止写零，禁止未发生写死确定额。
若 if C 端只要大众准备包，then 只分流不回改。

判断状态只许三值。口头转述、截图和「已读」不得写成已受理、已送达、判决已生效或已执行。事故认定书、调解记录不得单独写成民事终局比例。

## 本任务回链纪律

本任务成果是「不代提交的后续治疗费或新鉴定另诉草稿、既判力对照与分列请求」。必须包含：另诉闸、`Res#`／`P#` 分列、覆盖争点不关窗、概括弃权不是当然阻断、未知不写零。不包含：评估三档终稿、首次一审总包、上诉状、执行申请、弃权审查终稿、测算数字、鉴定委托。禁止保证可诉或受理。禁止选定法院。禁止选边治愈。禁止伪造新票据或倒签手术日。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标另诉终稿已形成。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接。
风险档 A：既判力、伪造票据、倒签手术日必须单独标可逆性。
