# 输出合同

按触发结果选择交付形状。另诉闸未打开不得交付另诉终稿或保证可诉。禁止选定唯一法院或预填「此致某院」为唯一路径。禁止已读、截图、作出日当判决已生效或已执行。禁止未知或未发生写成已发生零。禁止尚未发生手术写死确定额。禁止保证可诉、保证受理。禁止概括弃权当然阻断或当然不阻断。禁止已判绝对不能再告整窗关闭。禁止仅对旧事实再评残当然可另诉。禁止把解释第十九条继续给付写成后续治疗另诉闭集。禁止发送版、代提交。禁止胜诉率。禁止选边治愈。不定残。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 另诉闸关闭或节点 0 整案转出 | 第 1、2、10 节：关闭理由、既判力待核和最小补证。可附停止的 `Res#`／`P#`。禁止另诉终稿、保证可诉、保证受理、唯一截止日、选定某院、写死未发生额。对第三人可留时不得因工伤整案转出 |
| 整体停止 | 第 1、10 节。禁止 `P#` 策略包、起诉状草稿、选边、伪造或倒签步骤。双方秘密、伪造新票据、倒签手术日、隐瞒前案已判项目第一次即停，优先于负触发；无选边治愈，无「坚持」门槛 |
| 用户要前案已覆盖仍保证可诉、概括弃权当然阻断、选定某院、尚未发生手术写死确定额、保证受理、已判绝对不能再告、同一笔重复起诉、未知写零（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；闸未开则仍只交 1、2、10；不得改走负触发关窗；不得标另诉终稿 `已形成` |
| 正触发且闸开（可部分开） | 下列十节表头均出现；既判力、新事实、金额未核验格待核；一行一项；禁止为填满而写保证可诉、此致某院、写死未发生额或未知写零 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入另诉终稿已形成。双方秘密未解不得进入「部分形成」。每个 `Res#`／`P#` 必须带来源和三值判断。`L#` 不得直接抄技能内条号。已判绝对不能再告、概括弃权当然阻断、保证可诉若返回则记噪声。稿件状态默认 `草案`。

## 1. 触发、单方立场、授权与成果状态

另诉闸开、部分开或关。文书类型与覆盖关系必须标明。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。稿件默认 `草案`。不代提交。不保证可诉或受理。

## 2. 来源登记与 MCP 调用表

`S/R/D/L/I/G/Res/P/V`。口头已了结、已读只登记 `S#`／`V#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 既判力对照 `Res#`

主文／调解／和解／保险了结／执行回执一行一项。同一已发生项目已判并执行：该格通常不支持。明确保留：闸可开或待核。概括弃权：效力待核，不是当然阻断。无前案文书则字段停止。禁止合成整案不能告。

## 4. 另诉请求 `P#`

新发生费用、新手术、新鉴定才可能构成后诉新事实。仅对旧事实再评残该格通常不支持或待核。金额已核实／情景／无法估计分列。未知不写零。尚未发生禁止写死确定额。因果回链原侵害。回链 `Res#`。

## 5. 重复起诉与覆盖争点

同一笔再立一案：该格不支持，窗口不关。前案已覆盖仍保证可诉：该格不支持，窗口不关。不得改走整体停止或负触发。

## 6. 管辖时效红旗

连结点分列，不选定法院，不得预填此致某院。时效只打红旗，禁止自判决生效日起唯一截止。已读不得起算。

## 7. 起诉状与证据目录草稿

当事人、前案案号、新事实、请求、证据。草案，不代提交。不利事实不得删除。闸未开则本节停止。不保证受理。

## 8. 弃权、工伤与邻接分流

概括弃权转弃权审查，本窗不指导倒签反悔。工伤段分流劳动，第三人 `P#` 可留。第十九条继续给付不是本窗。鉴定、测算、时效只标接口。

## 9. 下一步与转介

转介评估窗、测算、弃权审查、鉴定材料、时效表、管辖、工伤竞合、一审／上诉／执行只点名。不写成发送版指令。不代提交。不保证立案。

## 10. 缺口、停止项与提示

须列对方最强解释：前案已覆盖所以绝对不能再告、概括弃权当然阻断或当然不阻断、签了也能告不用核验、对旧鉴定再评残当然可另诉、同一笔再立一次案、还没做的手术先按八十万写进请求、此致某区法院、时效从判决生效日算某年某月某日到期、调解书保留了但已经一次性了结所以不能诉、未知后续费先写零、保证立案保证受理、工伤走完了民事当然没了、两边材料都给你选边、没做的手术先开张票、倒签手术日、把已判项目从草稿删掉。

本成果不是评估三档终稿、不是首次一审总包、不是上诉状、不是执行申请、不是弃权审查终稿、不是测算数字、不是鉴定委托、不是发送版、不保证可诉或受理、不是唯一截止日、不是选定法院。不代提交。
