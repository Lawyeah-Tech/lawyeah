# 边界与路由

## 正触发

权利人已决定就前案后的后续治疗费、新手术、新票据或新鉴定另诉，需要另诉材料、既判力对照或起诉状草稿。「二次手术票据齐了，要再起诉」正触发。前案已覆盖仍保证可诉、概括弃权当然阻断或当然不阻断、选定某院、尚未发生手术写死确定额、保证受理、已判绝对不能再告、仅对旧事实再评残当然可另诉、同一笔重复起诉、未知写零、时效从判决生效日起唯一截止，仍正触发：另诉闸可关，对应格停止，窗口不关。工伤旧伤复发待遇与第三人侵权民事另诉同时出现，仍正触发：工伤段分流劳动，对第三人 `P#` 可留。调解书明确保留后续治疗、用户称已一次性了结所以不能诉，仍正触发：保留行仍编，口头了结不升格。

双方秘密、伪造新票据、倒签手术日、隐瞒前案已判项目的停止，优先于负触发。不得改走负触发去出一方另诉状。前案已覆盖、概括弃权当然阻断、保证可诉、选定某院、写死未发生额、保证受理、同一笔重复起诉、未知写零不在下表。伪造倒签不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要评估能否主张、三档开闭或尚未决定另诉 | `评估后续治疗费另行主张` |
| 无前案后续治疗事实、第一次人身损害起诉包 | `提起人身损害一审` |
| 裁判尚未生效、要改一审判项 | `提起人身损害上诉` |
| 要可签和解或保留条款草稿 | `起草人身损害和解协议`／`谈判人身损害和解` |
| 弃权或保险了结文本审查终稿 | `审查保险一次性了结弃权` |
| 前案「不给钱」要强制执行 | `执行人身损害生效文书` |
| 分项测算数字或唯一必得总额 | `测算人身损害赔偿` |
| 鉴定委托或申请终稿 | `准备伤残鉴定材料` |
| 时效唯一截止日 | `评估人身损害诉讼时效` |
| 护理、辅助器具或残疾金年限届满继续给付终稿 | 解释第十九条接口，不是本窗 |
| 纯工伤旧伤复发待遇且无第三人侵权民事另诉 | 劳动领域 |
| C 端只要大众准备包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「前案已覆盖所以不能告」「保证可诉」「此致某院」「手术还没做先写八十万」「保证受理」「未知先写零」「同一笔再立一案」不在本表，窗口不关。「补造新票据」「倒签手术日」「两边材料都给你选边」不在本表，走整体停止。工伤夹带第三人侵权民事另诉时，不得因「旧伤复发」整窗关闭。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 仅工伤待遇且无第三人侵权民事另诉 | 劳动领域 |
| 医疗损害鉴定终稿 | 医疗医药领域；原侵害后续治疗民事段可留 |
| 海事专门程序 | 海事领域 |
| 指导伪造新票据、倒签手术日或隐瞒前案已判项目 | 整体停止 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。对第三人另诉可留。

## 易混

「二次手术票据齐了，要再起诉，前案医疗费已判并执行，对方说已经覆盖、签过今后一切不再要所以当然没了，保证能立案，此致某区法院，手术还没做的部分先写八十万，后续费先填零」正触发；已覆盖行不支持；新发生行待核；概括弃权不是当然阻断；保证可诉／选定法院／写死未发生额／写零各格不支持；不代提交；不得负触发关窗。

「能不能再要」走评估。「前案判决不给钱」走执行。「还没起诉过」走一审。「一审刚判要加二次手术费」走上诉，超出一审的独立新请求不得塞进上诉请求。

「工伤旧伤复发走完了，要对肇事司机另诉取钢板」正触发，第三人 `P#` 可留，不得整案转劳动。

「新鉴定把当时十级改成九级，没有新手术」正触发；仅再评价旧事实该格待核或不支持，不关窗，不保证可诉。

「调解书写了后续治疗费待实际发生后另行主张，用户称已经一次性了结所以不能诉」正触发；保留行仍编；口头了结不升格；「所以不能诉」格不支持。

「两边材料都给你选边、没做的手术先开张票、倒签手术日」整体停止，第一次提出即停，不得选边，无「坚持」门槛，不得改走负触发出一方诉状。
