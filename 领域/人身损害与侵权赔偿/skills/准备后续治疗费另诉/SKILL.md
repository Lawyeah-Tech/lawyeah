# 准备后续治疗费另诉

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的权利人立场下，于另诉闸打开后形成不代提交的后续治疗费或新鉴定另诉包：另诉闸、`Res#` 既判力对照、`P#` 另诉请求（覆盖关系／新事实／金额状态分列）、管辖连结点、起诉状与证据目录草稿。不保证可诉或受理。不选定法院。不写死唯一截止日。不把未知或未发生写成已发生零。不把尚未发生的手术写死确定额。

`depends-on` 为空。未决定另诉或只要三档开闭转 `评估后续治疗费另行主张`。无前案第一次起诉转 `提起人身损害一审`。裁判尚未生效、要改一审判项转 `提起人身损害上诉`。执行前案转 `执行人身损害生效文书`，不得把另诉费用写进执行申请。紧急已发生医疗费转 `申请先予执行医疗费`。被告互殴反请求或已付款抵销转 `评估反诉或抵销`，本窗不出反诉状。概括弃权文本转 `审查保险一次性了结弃权`。金额展开转 `测算人身损害赔偿`。工伤待遇转劳动，第三人侵权民事段转介 `评估工伤与第三人侵权竞合`。

## 工作边界

正触发：权利人已决定就前案后的后续治疗费、新手术、新票据或新鉴定另诉，需要另诉材料、既判力对照或起诉状草稿。「二次手术票据齐了，要再起诉」正触发。前案已覆盖仍保证可诉、概括弃权当然阻断或当然不阻断、选定某院、尚未发生手术写死确定额、保证受理、已判绝对不能再告、仅对旧事实再评残当然可另诉、同一笔重复起诉、未知写零、时效从判决生效日起唯一截止，仍正触发：另诉闸可关，对应格填 `现有依据不支持` 或字段停止，窗口不关，不得改走负触发，不得标另诉终稿已形成。工伤旧伤复发待遇与第三人侵权民事另诉同时出现：本窗正触发，工伤段分流劳动，第三人 `P#` 可留。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要评估能否主张、三档开闭或尚未决定另诉（转 `评估后续治疗费另行主张`）；
- 无前案后续治疗事实、第一次人身损害起诉包（转 `提起人身损害一审`）；
- 裁判尚未生效、要改一审判项（转 `提起人身损害上诉`；超出一审的独立新请求不得塞进上诉请求）；
- 要可签和解或保留条款草稿（转 `起草人身损害和解协议`／`谈判人身损害和解`）；
- 要弃权文本审查终稿（转 `审查保险一次性了结弃权`）；
- 前案「不给钱」要强制执行（转 `执行人身损害生效文书`）；
- 主成果是紧急医疗费先予执行申请终稿（转 `申请先予执行医疗费`）；
- 主成果是反诉状或抵销终稿（转 `评估反诉或抵销`）；
- 只要分项测算数字或唯一必得总额（转 `测算人身损害赔偿`）；
- 只要鉴定委托或申请终稿（转 `准备伤残鉴定材料`）；
- 只要时效唯一截止日（转 `评估人身损害诉讼时效`）；
- 护理、辅助器具或残疾金年限届满后的继续给付终稿（解释第十九条接口，不是本窗）；
- 纯工伤旧伤复发待遇且无第三人侵权民事另诉（转劳动）；
- C 端只要大众准备包（只分流）；
- 未成争改合同（审查起草搁置）。

前案已覆盖、概括弃权当然阻断、保证可诉、选定某院、写死未发生额、保证受理、同一笔重复起诉、未知写零**不在负触发表**，窗口不关。双方秘密、伪造新票据、倒签手术日、隐瞒前案已判项目**不在负触发表**，走整体停止。

## 建立工作坐标

确认：使用者与授权；单方权利人立场（不得同时代表互争同一笔另诉的双方）；前案判决主文、调解书、和解或保险了结文本；执行回执；弃权或保留条款；新病历、医嘱、手术日与票据日分列；新鉴定是否仅再评价旧事实；被告是否变化；法域。

口头「已经判过不能再告」「签过今后一切不再要」「已经一次性了结」只登记 `S#`。微信已读截图不得写成判决已生效或已执行。用户坚持「保证可诉」「此致某院」「手术还没做先写八十万」不构成打开该格的授权。

同时掌握双方秘密，或受害人与侵权人、保险人同时交材料争同一份另诉策略：`整体停止`，不得以选边治愈，也不得改走负触发去出一方另诉状。提出伪造新票据、把未发生做成已开票、倒签手术日／入院日／票据日、伪造新鉴定、隐瞒前案已判并执行的同一项目或要求从草稿中删掉已判项目：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`R#` 前案文书、执行回执；`D#` 新病历、医嘱、票据、鉴定分列；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Res#` 既判力对照；`P#` 另诉请求；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。金额状态只用 `已核实`、`情景`、`无法估计`。稿件状态只用 `草案`、`另诉闸关闭`、`提交前待核`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。本任务默认 `草案`，不代提交。禁止「保证可诉」「保证受理」「此致某院」「未知写零」。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：法释〔2022〕14 号第六条第二款待实际发生后另行起诉与必然发生可一并；民法典第一千一百七十九条医疗费口径；民诉重复起诉与裁判生效后新事实再次起诉；起诉条件与侵权管辖连结点。时效另起算只核红旗。解释第十九条继续给付只核分流，不得写入本窗另诉闭集。技能正文条号不是 `L#`。噪声：已失效《侵权责任法》、2003 年解释已删除条文、已判绝对不能再告、概括弃权当然消灭、保证可诉或受理、选定某院、未发生写死确定额、未知写零、把第十九条写成后续治疗另诉闭集。不可用则既判力开闭、后诉条件、管辖效力和期限字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变既判力开闭、另诉条件或管辖连结点效果的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补已判同一项目再要通常受阻、新发生或明确保留才可能另诉、概括弃权不是当然阻断、未发生不得写死确定额、不保证受理的实务反例。
- `search_template` 只借起诉状栏目，不把范本当法定格式、已提交文本、发送版或指定唯一受诉法院。

工具不可用时继续 `Res#`／`P#` 编目、前案文书与新票据事实；既判力开闭、后诉条件、管辖效力和期限字段停止。不得凭记忆写成保证可诉、保证受理、选定法院或前案已覆盖当然可再告。

## 判断节点

执行顺序和停止条件以 [另诉方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、另诉闸与不关窗

工伤三段分流，第三人另诉可留。双方秘密、伪造新票据、倒签手术日第一次停。前案已覆盖、概括弃权当然阻断、保证可诉、选定某院、写死未发生额、保证受理不关窗。只要评估能否主张负触发。

### 2. 既判力对照 `Res#`

主文／调解／和解／保险了结／执行回执一行一项。同一已发生项目已判并执行：该格通常不支持。明确保留：闸可开或待核，不保证可诉。无前案文书：既判力字段停止。口头了结、已读不得升格。

### 3. 另诉请求 `P#`

新发生费用、新手术、新鉴定才可能构成后诉新事实。仅对旧事实再评残该格通常不支持或待核，不关窗。未知不写零。尚未发生且无医疗证明或鉴定确定必然发生：金额无法估计，禁止写死确定额。因果须回链原侵害。

### 4. 管辖时效红旗

管辖连结点分列，不选定法院，诉状不得预填此致某院。时效可能与前案不同或从实际发生日起算，只打红旗。禁止自前案判决生效日起唯一截止。

### 5. 起诉状草稿与转介

当事人、请求、前案文书、新证据目录。草案，不代提交。闸未开不得标另诉终稿已形成。不保证受理。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；受害人与侵权人或保险人同时交材料；提出伪造新票据、把未发生做成已开票、倒签手术日／入院日／票据日、伪造新鉴定、隐瞒前案已判项目或要求从草稿删掉已判项目。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：既判力范围、后诉新事实、管辖连结点效力、时效规则未核验。另诉闸未开则提交稿停止，窗口不关。用户要保证可诉、保证受理、选定某院、写死未发生额、未知写零、概括弃权当然阻断、已判绝对不能再告则该格停止，窗口不关。
- `目标停止`：主目标变为仅评估终稿、首次一审总包、上诉状、执行申请、先予执行、反诉状、弃权审查终稿、测算数字或鉴定委托。保证可诉、前案已覆盖仍要另诉不在目标停止。

禁止指导伪造票据、倒签手术日或代提交。不给胜诉率。不选定法院。不代提交。不编唯一截止日。不把未知写成零。不定残。不保证可诉或受理。
