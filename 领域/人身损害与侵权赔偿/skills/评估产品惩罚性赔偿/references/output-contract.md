# 输出合同

按触发结果选择交付形状。惩罚闸未打开不得交付惩罚性终稿或必得额。禁止三倍与 1207 加总。禁止事后召回当然明知。禁止唯一倍数。禁止选定法院。禁止已读升格明知。禁止选边治愈。不定残。不代提交。不保证支持惩罚性。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 惩罚闸关闭或节点 0 整案转出 | 第 1、2、10 节。禁止必得倍数、加总。产品 `Pun#` 可留时不得因工伤整案转出 |
| 整体停止 | 第 1、10 节。禁止 `Know#`／`Pun#` 策略包、选边、伪造召回步骤。双方秘密、伪造召回或内部邮件、倒签凭证、隐瞒改装第一次即停，优先于负触发；无选边治愈，无「坚持」门槛 |
| 用户要受伤即惩罚性、召回即明知、三倍加 1207 必得、唯一倍数、选定某院（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；闸未开则仍只交 1、2、10；不得改走负触发关窗；不得标惩罚性终稿 `已形成` |
| 正触发且闸开 | 下列十节表头均出现；未核验格填待核；禁止为填满而写必得倍数或加总 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入惩罚性终稿已形成。双方秘密未解不得进入「部分形成」。每个 `Know#`／`Harm#`／`Pun#` 必须带来源和判断三值。`L#` 不得直接抄技能内条号。召回即明知、三倍加 1207 若返回则记噪声。稿件状态默认 `草案`。

## 1. 触发、单方立场、授权与成果状态

谁主张哪一袋惩罚性。惩罚闸是否打开。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。稿件默认 `草案`。不保证支持。

## 2. 来源登记与 MCP 调用表

`S/D/R/L/I/G/Know/Harm/Pun/V`。口头都知道、召回截图只登记 `S#`／`V#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 明知或未有效补救 `Know#`

生产者与销售者分列。事后召回不等于事发前明知。行业都知道不得写成明知。

## 4. 死亡或健康严重损害 `Harm#`

死亡须文书。不作医学诊断，不定残。轻微过敏通常不打开。

## 5. 惩罚性行 `Pun#`

1207、消法价款三倍、消法损失二倍以下、食安十倍分列。禁止加总。倍数待核，禁止唯一必得。

## 6. 与补偿性并存

医疗费、残疾、死亡、精神损害另列。不得用惩罚性吸收补偿性。基数未核验不得写死。

## 7. 证据清单

召回、处罚、内部通知、批次、实物、病历。不能因对方控制而推定内部材料有利。

## 8. 刑事与医疗红旗

伪劣商品刑事只分流。医疗产品二倍以下只红旗。诊疗主轴转医疗。

## 9. 下一步与转介

转介产品致害、竞合、测算、保全、起诉只点名。不打开则填 `不打开`。不写成起诉指令或发送版。不代提交。不选定法院。

## 10. 缺口、停止项与提示

须列对方最强解释：受伤就是惩罚性、召回了就是事发前明知、三倍加 1207 一起要、二倍或三倍必得、此致某院、轻微过敏也算健康严重损害、厂家都知道所以内部一定有邮件、两边材料选边、先伪造召回函、利息或倍数先写零。

本成果不是补偿性缺陷总图、不是价款三倍终稿、不是起诉状、不是发送版、不是唯一倍数、不是选定法院、不保证支持惩罚性。不代提交。不定残。
