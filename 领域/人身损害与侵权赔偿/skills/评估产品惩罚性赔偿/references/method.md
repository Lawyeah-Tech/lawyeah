# 产品惩罚性方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。稿件状态只用 `草案`、`惩罚闸关闭`、`提交前待核`、`停止`。禁止胜诉率、唯一必得总额、唯一倍数、唯一截止日、选定法院、自行宣布伤残等级、代提交、未知写零。本任务不代提交，不保证支持惩罚性。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》第四十七条、1993 年消费者权益保护法施行条当第五十五条、2025 年食品安全法尚未施行文本当现行、把事后召回写成事发前明知、把三倍与 1207 加总、把唯一二倍或三倍当必得时记为噪声，不得写入 `L#`。禁止指导伪造召回、倒签凭证、隐瞒改装或破坏检材。

`Know#` 固定列：`编号｜主体（生产者／销售者／平台自营待核，一行一主体）｜时点（事发前／投入流通后／事后）｜形态（仍生产销售／未及时警示召回／补救不力）｜材料（召回公告／处罚／内部通知／同类事故／无）｜是否升格明知（禁止仅凭事后召回或行业都知道）｜判断三值｜状态｜来源回链`。

`Harm#` 固定列：`编号｜后果（死亡／健康严重损害／不打开）｜文书（死亡证明／病历／鉴定｜口头不算）｜是否自行诊断或定残（禁止）｜与伤残等级接口（只红旗）｜判断三值｜状态｜来源回链`。轻微过敏、财产损失单独通常不打开。

`Pun#` 固定列：`编号｜规范袋（民法典1207／消法价款三倍／消法损失二倍以下／食安十倍或损失三倍／医疗产品二倍以下红旗｜禁止一行加总）｜是否食品药品｜基数待核｜倍数待核（禁止写死唯一倍数或必得额）｜与补偿性并存（不得吸收）｜判断三值｜状态｜来源回链`。

口头「厂家都知道」、截图、已读只进 `S#`／`V#`，不得升格 `Know#` 已明知。

## 节点 0　分流、立场、惩罚闸与不关窗

整案转出或闸关闭只交付第 1、2、10 节或标注停止的 `Know#`／`Harm#`／`Pun#`，不得交付惩罚性终稿或必得额。

| 信号 | 处理 |
| --- | --- |
| 主成果是补偿性缺陷路径 | 负触发 `评估产品致人损害` |
| 主成果是无人身严重后果的价款三倍 | 负触发消费者或合同路径；本窗只分列 |
| 主成果是诊疗过错或医疗鉴定 | 整案转医疗；流通物出厂缺陷可留 |
| 主成果是竞合择一 | 负触发 `选择人身损害违约侵权竞合路径` |
| 主成果是测算或评残 | 负触发对应原子 |
| 主成果是起诉状 | 负触发 `提起人身损害一审` |
| 纯工伤且无产品缺陷 | 整案转劳动；夹带产品致害则本窗正触发，工伤段分流，`Pun#` 可留 |
| 伪劣商品刑事辩护或控告 | 只打红旗，转 `分流刑民交叉`／刑事；民事 `Pun#` 可留 |
| 未成争改买卖条款 | 审查起草本窗搁置 |

惩罚闸打开（可出 `Pun#` 草案，仍不代提交、不保证支持）须同时满足：单方无冲突权利人立场与授权；死亡或健康严重损害有可回链材料或明确缺口；主成果是 1207 或分列惩罚性评估，不是补偿性总图、纯价款三倍、医疗鉴定或起诉状；拟交付不含伪造召回、加总双份惩罚、唯一必得倍数、选定法院。

闸关闭（仍正触发）：无死亡或健康严重损害却要惩罚性终稿；仅事后召回就要打开事发前明知；要三倍加 1207 必得；唯一二倍或三倍；选定某院。闸未开则仍只交 1、2、10 节。

「受伤即惩罚性」「召回即明知」「三倍加 1207 必得」「唯一倍数」「选定法院」**不关窗**。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或受害人与生产者、销售者争同一份惩罚性策略且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出伪造召回或内部邮件、倒签购买凭证、隐瞒改装、破坏检材、伪造伤情，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　明知或未有效补救 `Know#`

检索锚点：民法典第一千二百零七条。明知缺陷仍然生产、销售，**或者**没有依据第一千二百零六条采取有效补救措施。二者选择关系，具备其一即可作为主观候选，不得写成必须同时具备，也不得把事后召回单独写成事发前明知。第一千二百零六条：投入流通后发现缺陷应及时停止销售、警示、召回；未及时补救或补救不力造成损害扩大的，对扩大损害承担责任。召回费用由生产者、销售者负担，本窗不写召回令。

生产者与销售者分列，各自明知待核，不得当然写成连带惩罚。平台不是当然生产者。行政处罚、召回公告、同类事故只作候选，不是终局。不能因对方控制内部邮件即推定内容有利。

## 节点 2　死亡或健康严重损害 `Harm#`

死亡须死亡证明等 `R#`。健康严重损害须病历或鉴定材料，本窗不作医学诊断，不定残。伤残等级只转介 `准备伤残鉴定材料`／`评估伤残等级争议`。轻微过敏、单纯财产损失通常不打开 1207。用户要把轻微伤写成健康严重损害：该格 `现有依据不支持` 或待核，窗口不关。

医疗产品：明知缺陷仍生产销售造成患者死亡或健康严重损害，被侵权人请求损失及二倍以下惩罚性赔偿的接口，检索锚点为医疗损害责任解释第二十三条一类。诊疗主轴转医疗；流通缺陷可留，该行待核，不得把二倍默写为 1207 唯一倍数。

## 节点 3　惩罚性行 `Pun#` 与分列

1207「相应的惩罚性赔偿」不是闭集倍数，禁止写死二倍或三倍必得。消法第五十五条第一款欺诈价款三倍（不足五百元为五百元，法律另有规定的除外）与第二款损失二倍以下，与 1207 分列。食品安全法第一百四十八条第二款十倍价款或损失三倍（不足一千元为一千元）仅食品；非食品不得套。2025 年修正尚未施行文本不得当现行 `L#`。食品药品惩罚性解释（法释〔2024〕9 号）只作食品药品袋检索锚点，不把知假买假争点写成普通工业品规则。

禁止把价款三倍、损失二倍、食安十倍与 1207 加总为双份或多份惩罚。用户要加总必得：加总格 `现有依据不支持`，窗口不关。补偿性医疗费、残疾、死亡、精神损害另列，不得用惩罚性吸收，也不得在基数未核验时把补偿项目重复计入惩罚。

## 节点 4　证据与转介

证据：批次与实物、召回与处罚、内部通知、死亡或病历、购买凭证。调查令只转介。实物保全优先于拆机，转 `准备财产或证据保全申请`。不代提交。第 9 节不得写成起诉指令。伪劣商品刑事只红旗。

| 接口 | 本窗 | 转介 |
| --- | --- | --- |
| 补偿性缺陷路径 | 负触发 | `评估产品致人损害` |
| 价款三倍无人身严重后果 | 负触发 | 消费者或合同 |
| 竞合择一 | 负触发 | `选择人身损害违约侵权竞合路径` |
| 测算／评残 | 只红旗或负触发 | `测算人身损害赔偿`／`准备伤残鉴定材料` |
| 精神损害 | 补偿性另列 | `评估精神损害赔偿` |
| 起诉状 | 负触发 | `提起人身损害一审` |
| 医疗产品诊疗 | 分流；流通可留 | 医疗医药 |
| 伪劣刑事 | 只红旗 | `分流刑民交叉` |

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过惩罚闸直接给必得倍数、三倍加总或召回即明知。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if 金额或倍数参数不足，then 该行标未知，禁止写零或写死唯一倍数。
若 if C 端只要大众准备包，then 只分流不回改。

判断状态只许三值。口头转述、截图和「已读」不得写成已明知、已受理或倍数已核验。召回公告、处罚决定不得单独写成民事终局明知。

## 本任务回链纪律

本任务成果是「不代提交的 1207 惩罚性评估与分列对照」。必须包含：惩罚闸；三要件缺一不可；消法、食安与 1207 分列禁止加总；事后召回不等于事发前明知。不包含：补偿性缺陷总图、纯价款三倍终稿、医疗鉴定、测算、起诉状。禁止选边治愈。禁止把受伤即惩罚性、三倍加总、召回即明知写成负触发或整体停止（伪造除外）。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标惩罚性终稿已形成。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接。
风险档 A：伪造召回、隐瞒改装、破坏检材必须单独标可逆性。
