# 边界与路由

## 正触发

明知产品存在缺陷仍生产销售，造成死亡或健康严重损害，需要惩罚性赔偿判断。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 补偿性产品责任 | `评估产品致人损害` |
| 三倍价款无人身严重后果 | 消费者或合同路径，本任务分列 |
| 药品器械诊疗 | 医疗医药领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 医疗损害惩罚性若另有规定 | 医疗医药领域 |
| 生产销售伪劣商品刑事 | 刑事红旗 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“厂家早就知道会爆炸还在卖，人死了要惩罚性”正触发。“只是退一赔三没受伤”不是本主成果。“普通产品伤人无明知”走产品致害。
