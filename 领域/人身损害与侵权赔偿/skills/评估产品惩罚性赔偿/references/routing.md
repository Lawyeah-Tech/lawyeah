# 边界与路由

## 正触发

主张明知产品存在缺陷仍生产、销售，或未采取有效补救，造成死亡或健康严重损害，需要惩罚性赔偿判断。「厂家早就知道会爆炸还在卖，人死了要惩罚性」正触发。受伤即惩罚性、事后召回当然明知、消法三倍加 1207 必得、唯一二倍或三倍、选定某院、轻微过敏当健康严重损害，仍正触发：惩罚闸可关，对应格停止，窗口不关。工伤待遇与产品致害同时出现，仍正触发：工伤段分流劳动，产品 `Pun#` 可留。

双方秘密、伪造召回或内部邮件、倒签凭证、隐瞒改装的停止，优先于负触发。不得改走负触发去出一方惩罚性稿。受伤即惩罚性、召回即明知、三倍加总、唯一倍数不在下表。伪造、双方秘密不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 补偿性产品责任、缺陷候选或对外路径 | `评估产品致人损害` |
| 无人身严重后果的价款三倍、退一赔三 | 消费者或合同路径 |
| 诊疗过错或医疗损害鉴定 | 医疗医药领域 |
| 违约侵权择一终稿 | `选择人身损害违约侵权竞合路径` |
| 测算或伤残鉴定 | `测算人身损害赔偿`／`准备伤残鉴定材料` |
| 起诉状 | `提起人身损害一审` |
| 纯工伤待遇且无产品缺陷 | 劳动领域 |
| C 端只要大众准备包 | 只分流 |
| 未成争改买卖条款 | 审查起草搁置 |

「只是退一赔三没受伤」负触发消费者路径。「普通产品伤人无明知」走 `评估产品致人损害`。不得因「要求三倍加 1207」关窗。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 诊疗过错或医疗鉴定 | 医疗医药领域；流通缺陷可留 |
| 仅工伤待遇且无产品缺陷 | 劳动领域 |
| 伪劣商品刑事辩护或控告 | 刑事或 `分流刑民交叉`；民事 `Pun#` 可留 |
| 指导伪造召回、倒签凭证、隐瞒改装或破坏检材 | 整体停止 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。产品 `Pun#` 可留。

## 易混

「厂家早就知道会爆炸还在卖，人死了要惩罚性」正触发。「受伤就是惩罚性、召回了就是明知、三倍加 1207 必得、二倍写死」正触发不关窗，对应格不支持。「只是退一赔三没受伤」负触发消费者路径。「普通产品伤人、没有明知材料」负触发或转 `评估产品致人损害`。「两边材料都给你、先做一份召回函」整体停止。
