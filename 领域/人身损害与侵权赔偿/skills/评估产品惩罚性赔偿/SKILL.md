# 评估产品惩罚性赔偿

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的权利人立场下，形成“惩罚性条件、与补偿性并存、证据”。消费者三倍价金路径与人身惩罚性分列。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算、鉴定和证据清单。

## 工作边界

正触发：明知产品存在缺陷仍生产销售，造成死亡或健康严重损害，需要惩罚性赔偿判断。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要补偿性产品责任（转 `评估产品致人损害`）；
- 消费者三倍价款无人身严重后果（合同或消费者路径分列，不在此当主成果）；
- 药品器械诊疗主轴（转医疗）。

惩罚性与补偿性并存，不得互相替代。倍数或金额须核验，不编造唯一倍数。

## 建立工作坐标

确认：使用者与授权；权利人；产品批次；明知证据；死亡或健康严重损害；已主张补偿性项目；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 召回、内部邮件、行政处罚；`R#` 鉴定死亡证明；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Pun#` 惩罚性行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典第一千二百零七条及消费者权益保护法三倍路径的区分。不虚构案件系统。

工具不可用时继续事实、主体、程序文书状态和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [产品惩罚性方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　分流

补偿性产品责任、医疗器械诊疗、三倍价款。

### 节点 2　明知或未有效补救

召回隐瞒、屡次处罚、内部已知仍出货。

### 节点 3　死亡或健康严重损害

死亡清晰。严重损害需材料，不作医学诊断。

### 节点 4　与补偿性并存

医疗费残疾死亡精神损害仍按补偿性。惩罚性另列。

### 节点 5　证据与输出

行政处罚、召回文件、同类事故、内部通知。

## 停止与安全

- `整体停止`：伪造明知证据；隐瞒自身严重改装。
- `字段停止`：明知要件、严重健康损害标准、倍数规则未核验。
- `目标停止`：主目标变为补偿性产品责任或纯三倍价款。
