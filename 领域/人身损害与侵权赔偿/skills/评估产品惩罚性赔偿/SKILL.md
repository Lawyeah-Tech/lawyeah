# 评估产品惩罚性赔偿

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的权利人立场下，形成不代提交的人身惩罚性评估包：惩罚闸、`Know#` 明知或未有效补救、`Harm#` 死亡或健康严重损害、`Pun#` 惩罚性行（民法典第一千二百零七条与消法价款三倍、消法损失二倍以下、食安十倍价款或损失三倍分列，禁止加总）。补偿性项目另列，不得互相吸收。不编造唯一倍数或必得额。不定残。不选定法院。不保证支持惩罚性。

`depends-on` 为空。补偿性缺陷路径转 `评估产品致人损害`。择一比较转 `选择人身损害违约侵权竞合路径`。测算转 `测算人身损害赔偿`。精神损害成立转 `评估精神损害赔偿`。药品器械诊疗主轴转医疗；流通物出厂缺陷可留。伪劣商品刑事只打红旗，转 `分流刑民交叉`。

## 工作边界

正触发：主张明知产品存在缺陷仍生产、销售，或未采取有效补救，造成死亡或健康严重损害，需要惩罚性赔偿判断。「厂家早就知道会爆炸还在卖，人死了要惩罚性」正触发。受伤即惩罚性、事后召回当然明知、消法三倍加 1207 必得、唯一二倍或三倍、选定某院、未知写零、轻微过敏当健康严重损害，仍正触发：惩罚闸可关，对应格填 `现有依据不支持` 或字段停止，窗口不关，不得改走负触发，不得标惩罚性终稿已形成。工伤待遇与产品致害同时出现：本窗正触发，工伤段分流劳动，产品 `Pun#` 可留。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是补偿性产品责任、缺陷候选或生产者销售者对外路径（转 `评估产品致人损害`）；
- 主成果是无人身严重后果的价款三倍、退一赔三（转消费者或合同路径；本窗只分列红旗）；
- 主成果是诊疗过错或医疗损害鉴定（转医疗医药）；医疗产品惩罚性二倍以下接口只红旗，流通缺陷可留本窗；
- 主成果是违约侵权择一终稿（转 `选择人身损害违约侵权竞合路径`）；
- 主成果是测算或伤残鉴定（转 `测算人身损害赔偿`／`准备伤残鉴定材料`）；
- 主成果是起诉状（转 `提起人身损害一审`）；
- 纯工伤待遇且无产品缺陷（转劳动）；
- C 端只要大众准备包（只分流）；
- 未成争改买卖条款（审查起草搁置）。

受伤即惩罚性、召回即明知、三倍加 1207 必得、唯一倍数、选定法院**不在负触发表**，窗口不关。双方秘密、伪造召回或内部邮件、倒签购买凭证、隐瞒改装、伪造伤情**不在负触发表**，走整体停止。

## 建立工作坐标

确认：使用者与授权；权利人；产品名称、批次；生产者、销售者分列；明知或补救时点；死亡或健康严重损害材料；已主张补偿性项目；是否食品药品；是否自行改装或过期使用；法域。

口头「厂家都知道」、召回截图、已读只登记 `S#`／`V#`。不得升格事发前明知、已立案或倍数已核验。用户坚持「三倍加惩罚性必得」「此致某院」不构成打开该格的授权。

同时掌握双方秘密，或受害人与生产者、销售者同时交材料争同一份惩罚性策略：`整体停止`，不得以选边治愈，也不得改走负触发。权利人已开口且委托范围就是惩罚性评估、且未掌握对方秘密时，可推定权利人立场。只要同时掌握双方秘密，无例外整体停止。提出伪造召回公告或内部邮件、倒签购买凭证、隐瞒自行改装或破坏检材、伪造伤情：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 召回、处罚、内部通知、批次；`R#` 死亡证明、鉴定；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Know#` 明知或补救；`Harm#` 后果；`Pun#` 惩罚性行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。稿件状态只用 `草案`、`惩罚闸关闭`、`提交前待核`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。本任务默认 `草案`，不代提交。禁止「必得二倍」「三倍加 1207」「召回即明知」「此致某院」。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：明知产品存在缺陷仍然生产、销售，或者没有依据前条规定采取有效补救措施，造成他人死亡或者健康严重损害的，被侵权人有权请求相应的惩罚性赔偿；产品投入流通后发现缺陷应及时停止销售、警示、召回；消费者权益保护法欺诈价款三倍与明知缺陷致死亡或健康严重损害的损失二倍以下，与 1207 分列；食品安全法十倍价款或损失三倍仅食品；医疗产品惩罚性常见损失二倍以下待核，诊疗主轴转医疗。技能正文条号不是 `L#`。噪声：已失效《侵权责任法》第四十七条、1993 年消费者权益保护法施行条当第五十五条、2025 年食品安全法尚未施行文本当现行、受伤即惩罚性、事后召回当然明知、三倍与 1207 加总、唯一二倍或三倍必得、非食品套十倍、选定法院、未知写零。不可用则明知、严重损害、倍数、分列加总字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变明知、未有效补救、健康严重损害或倍数结论的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补事后召回不等于事发前明知、惩罚性倍数由法院酌定而非固定倍数、消法与 1207 不得加总、轻微损害打不开 1207 的实务反例。
- `search_template` 只借请求栏目，不把范本当法定倍数、已提交文本或指定法院。

工具不可用时继续 `Know#`／`Harm#`／`Pun#` 编目与批次、损害事实；明知、严重损害、倍数字段停止。不得凭记忆写成召回即明知、三倍加 1207 必得或唯一倍数。

## 判断节点

执行顺序和停止条件以 [产品惩罚性方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、惩罚闸与不关窗

工伤三段分流，产品 `Pun#` 可留。双方秘密、伪造召回、隐瞒改装第一次停。受伤即惩罚性、三倍加总、召回即明知不关窗。主成果是补偿性路径才负触发。

### 2. 明知或未有效补救 `Know#`

生产者与销售者分列。事后召回不等于事发前明知，也不当然排除。行业都知道不得写成明知。内部邮件未出示不得推定有利。

### 3. 死亡或健康严重损害 `Harm#`

死亡须文书。健康严重损害需材料，不作医学诊断，不定残。轻微过敏通常不打开。伤残等级只是接口。

### 4. 惩罚性行 `Pun#` 与分列

1207、消法价款三倍、消法损失二倍以下、食安十倍分列。禁止加总。补偿性另列不得吸收。倍数未核验字段停止，不编造必得额。

### 5. 证据与转介

行政处罚、召回、同类事故只作候选。不代提交。第 9 节不得写成起诉指令。刑事只打红旗。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；受害人与生产者、销售者同时交材料；伪造召回公告或内部明知材料；倒签购买凭证或批次；隐瞒自行改装或破坏检材；伪造伤情。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：明知、未有效补救、健康严重损害标准、倍数或分列规则未核验。惩罚闸未开则终稿停止，窗口不关。用户要受伤即惩罚性、召回即明知、三倍加 1207 必得、唯一倍数、选定法院、未知写零则该格停止，窗口不关。
- `目标停止`：主目标变为补偿性产品责任、纯价款三倍、医疗鉴定、竞合比较、测算或起诉状。受伤即惩罚性、三倍加总不在目标停止。

禁止指导伪造召回、倒签凭证、隐瞒改装或破坏检材。不给胜诉率。不选定法院。不代提交。不编唯一倍数或截止日。不把未知写成零。不定残。不保证支持惩罚性。不把三倍与 1207 加总。
