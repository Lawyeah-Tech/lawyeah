# 边界与路由

## 正触发

人身损害已发生，存在或声称存在交强险或商业三者，需要向保险人准备材料包。保单未交齐、限额未核验、不知是否已报案、尚未评残仍正触发。用户要「限额内必得」「按旧十一万先交」「精神损害不用提出也优先」「酒驾所以交强险一毛不赔」仍正触发。工伤待遇与第三人车辆同时出现，仍正触发：工伤段分流劳动，材料包可留。

双方秘密、受害人与保险人同时交材料、伪造票据、顶包、隐瞒酒驾骗保的停止，优先于负触发。不得改走负触发去出材料包或拒赔稿。必得额不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 道路交通分账或限额内必得数字 | `评估道路交通事故责任与保险先行` / `测算人身损害赔偿` |
| 已经拒赔或减赔拆解 | `应对保险拒赔减赔` |
| 起诉保险人的请求和地位 | `直接起诉保险公司` |
| 对侵权人催告函或项目表 | `准备侵权索赔通知` |
| 精神损害酌定终稿 | `评估精神损害赔偿` |
| 了结弃权审查 | `审查保险一次性了结弃权` |
| 救助基金或抢救费垫付申请 | `申请道路救助基金或垫付` |
| 纯车损且无人身 | 负触发 |
| C 端只要大众理赔清单 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「写成必得」不在本表。未投保交强险不得把商业三者材料袋一并关闭。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 仅工伤待遇且无第三人车辆 | 劳动领域 |
| 医疗责任保险主轴 | 医疗医药领域 |
| 海事专门程序 | 海事领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。第三人车辆交强险或商业三者材料包可留。

## 易混

「先向保险公司交材料」正触发。「交强险怎么分、必得多少」走分账或测算。「保险公司拒了」走拒赔专项。「连保险公司一起告」走直接起诉。「给对方司机发催告」走索赔通知。「按旧十一万先把申请交上去，精神损害也优先」仍正触发，必得额与旧限额格不支持，未提出则优先不打开。「酒驾所以交强险一毛不赔」仍正触发，该格不支持或待核。「未投保交强险但有商业三者」正触发，商业险材料袋继续。「工伤也要认，对方车交强险还在」正触发，材料包可留，工伤段分流。「两边材料都给你，按对我们有利的出包，发票可以补」整体停止，不得选边。
