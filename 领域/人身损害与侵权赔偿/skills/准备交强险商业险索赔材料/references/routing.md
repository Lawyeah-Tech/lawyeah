# 边界与路由

## 正触发

向承保交强险或商业三者的保险人索赔人身损害，需要材料包和分项限额接口。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 拒赔拆解 | `应对保险拒赔减赔` |
| 直接起诉保险人 | `直接起诉保险公司` |
| C 端保险理赔 | 大众专项，只分流 |
| 纯车损 | 保险相邻或负触发 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 工伤保险待遇申报 | 劳动领域 |
| 医疗责任保险主轴 | 医疗医药领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“先向保险公司交材料”正触发。“保险公司拒了”走拒赔专项。“连保险公司一起告”走直接起诉。
