# 输出合同

按触发结果选择交付形状。材料闸未打开不得交付递交终稿。禁止限额内必得。禁止默写已废止十一万、一万。禁止未提出即自动精神损害优先。禁止酒驾逃逸无证等于交强险对受害人当然不赔。禁止按民事比例扣交强险。禁止未投保写成连带。禁止选边治愈。禁止伪造票据或顶包步骤。不代报案。不代提交。不保证赔付。不选定法院。不定残。不是诉状、不是分账、不是拒赔拆解、不是催告函。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 材料闸关闭或节点 0 整案转出 | 第 1、2、10 节。禁止 `M#` 终稿、限额数字、申请草稿。第三人车辆材料可留时不得因工伤整案转出 |
| 整体停止 | 第 1、10 节。禁止材料包、限额表、递交稿、选边、隐瞒指导。双方秘密、受害人与保险人同时交材料、伪造票据、顶包时，整体停止优先于负触发；第一次提出即停，无选边治愈，无「坚持」门槛 |
| 用户要必得额、旧十一万、未提出自动优先或酒驾交强险当然不赔（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；闸未开则仍只交 1、2、10；不得改走负触发关窗；成果不得标 `已形成` |
| 正触发且闸开 | 下列十节表头均出现；限额、直接请求权、免责未核验填 `依据不足，无法形成结论` 或 `待核`；禁止为填满而宣布必得或酒驾当然不赔 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。双方秘密未解不得进入「部分形成」。每个 `M#` 必须带来源、险种袋、控制方和缺口。`L#` 不得直接抄技能内条号。旧限额、酒驾当然拒赔、未提出自动优先若返回则记噪声。

## 1. 触发、单方立场、授权与成果状态

材料闸开或关。受害人直接请求与被保险人索赔分列。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。申请状态默认 `草案` 或 `待递交`。

## 2. 来源登记与 MCP 调用表

保单、认定书、票据、鉴定分袋。口述保单、已报案只登记 `S#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 险种袋与请求权人

交强险与商业三者分行。商业三者直接请求未核验不得当然打开。本车人员除外待核。未投保不关闭商业险材料袋。

## 4. `M#` 材料清单

固定列：险种｜控制方｜是否必须｜缺口。医保已报单列。未知不写零。伤残鉴定不是开窗前提。不因对方控制推定有利。

## 5. 限额接口（待核）

死亡伤残、医疗、财产 × 有责、无责只标接口。禁止填已核验必得数字。禁止旧十一万。禁止按民事比例扣。不写分账终稿。

## 6. 精神损害优先接口

须被侵权人或近亲属提出。未提出填 `不打开`。不增加限额。未投保无此接口。不酌定金额。

## 7. 向保险人递交的申请草稿

草案或待递交。不是侵权催告，不是诉状。不代报案不代交。了结文本只红旗。

## 8. 免责与最强异议

酒驾、逃逸、无证、本车人员、医保外。交强险酒驾不等于对受害人当然不赔。展开转拒赔专项，本窗不拆终稿。

## 9. 风险与下一步

只点转介：分账、测算、催告、直接起诉、救助基金、弃权、工伤竞合、送达、鉴定。不选定法院。不执行递交。

## 10. 缺口、停止项与提示

须列对方最强解释（交了材料就必得、旧十一万、未提出也自动优先、酒驾交强险当然不赔、认定书比例扣限额、选边即可继续、顶包改认定、先签了结再交材料无风险）与证据缺口。

本成果不是分账、催告函、诉状、测算、拒赔意见或限额内必得。不代报案。不代提交。
