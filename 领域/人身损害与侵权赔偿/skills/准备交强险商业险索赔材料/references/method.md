# 保险索赔方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。接口状态只用 `打开`、`不打开`、`待核`。申请状态只用 `草案`、`待递交`、`停止`。禁止胜诉率、限额内必得总额、选定法院、自行宣布伤残等级、唯一截止日。未知金额不写零。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》第四十八条至第五十三条、2003 年人身损害赔偿解释已删除条文、已失效《合同法》，或把已废止交强险死亡伤残十一万、医疗一万旧限额写成现行标准时记为噪声。把未投保写成连带、按民事比例扣交强险、未提出即自动精神损害优先、酒驾逃逸无证等于交强险对受害人人身当然不赔，同样记为噪声。

`M#` 固定列：`编号｜材料名｜险种（交强险/商业三者分袋，禁止一行混袋）｜控制方｜是否必须｜缺口｜来源回链`。一行一项。多车、多份保单不得合并。

## 节点 0　分流、立场、材料闸与不关窗

整案转出或闸关闭只交付第 1、2、10 节，不交 `M#` 终稿、限额数字或申请草稿。

| 信号 | 处理 |
| --- | --- |
| 只要分账或限额内必得数字 | 负触发 `评估道路交通事故责任与保险先行` / `测算人身损害赔偿` |
| 已经拒赔只要拆解 | 负触发 `应对保险拒赔减赔` |
| 只要起诉保险人 | 负触发 `直接起诉保险公司` |
| 只要对侵权人催告 | 负触发 `准备侵权索赔通知` |
| 只要精神损害酌定 | 负触发 `评估精神损害赔偿` |
| 只要了结弃权审查 | 负触发 `审查保险一次性了结弃权`；对该了结相对人材料闸关闭 |
| 只要救助基金或垫付申请 | 负触发 `申请道路救助基金或垫付` |
| 主轴仅工伤认定、劳鉴或待遇，且无第三人车辆 | 整案转劳动；夹带第三人机动车则本窗正触发，工伤段分流，材料包可留并转介 `评估工伤与第三人侵权竞合` |
| 医疗责任保险主轴 | 转医疗 |
| 海事专门程序 | 转海事 |
| 纯车损无人身 | 负触发 |
| 未成争改合同 | 审查起草本窗搁置 |

材料闸打开条件（同时满足）：单方无冲突立场与授权；至少一袋险种可指称；人身损害材料可编目；主成果是向保险人的材料包，而非分账、诉状、催告或拒赔终稿。

闸关闭（仍正触发）：保单与收件保险人无线索；受害人是否本车人员完全不明。不得以「今天必须交上去」打开闸。

「限额内必得」「旧十一万」「未提出自动优先」「酒驾交强险当然不赔」**不关窗**。闸未开则仍只交 1、2、10 节。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或受害人与保险人、被保险人与保险人同时交材料争同一理赔包且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出伪造票据、顶包、改认定、倒签出险、隐瞒酒驾骗保、威胁或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　险种袋与请求权人

交强险与商业三者分袋。检索锚点：交强险条例对被侵权人的赔偿；保险法责任保险第三者请求；民法典第一千二百一十三条顺序。条号不是 `L#`。

交强险被侵权人直接请求：运行时核验后再写入 `L#`，技能正文不得当成已核验。商业三者：被保险人索赔与受害人直接请求分列，未核验不得写成当然直接请求。

本车人员、被保险人除外、开门杀、驾驶人下车后被撞：分两行，依据不足该行停止。未投保交强险：限额层转 `评估道路交通事故责任与保险先行`（限额内共同承担，禁止连带）；若另有商业三者，商业险材料袋继续，不得因未投保交强险一并关窗。救助基金只标接口。

认定书只作 `R#`。不是民事责任终局，不是交强险拒赔依据闭集。主次责不得映射三七开后关掉材料包。口头全责不得写入 `R#`。

## 节点 2　材料清单

每项标明险种袋、控制方、是否必须、缺口。未知项目不写零，不得从矩阵删除。不能因对方控制而推定材料存在或内容有利。

医保、工伤基金已报医疗费单列，禁止与交强险医疗分项或侵权人医疗费双计。伤残鉴定不是打开材料包的前提；无鉴定则死亡伤残相关行待核，医疗费用分项可先编目。口头已报案、微信已读不得写成保险人已受理或核定期已起算。不代报案。

身份、保单或标志、认定书、病历票据、银行卡、鉴定意见（闸未开不得写成必须已评残）分列。

## 节点 3　限额接口与精神损害优先

限额数字须核验现行标准。死亡伤残、医疗费用、财产损失 × 有责、无责只标接口。未核验不得填数字。禁止默写已废止十一万、一万。禁止按民事比例或认定书主次责扣交强险。打开接口不等于限额内必得。本窗不产出分账终稿，分账转 `评估道路交通事故责任与保险先行`。用户要必得额或旧限额：该格 `现有依据不支持` 或字段停止，窗口不关。

精神损害优先：须被侵权人或近亲属**提出**。未提出填 `不打开`。只改变死亡伤残限额内排序，不增加总额。未投保无此接口。本窗不酌定抚慰金，转 `评估精神损害赔偿`。

商业三者是否含精神损害看条款原文，未核验待核。

## 节点 4　申请草稿与拒赔红旗

向保险人递交的理赔申请只出 `草案` 或 `待递交`。不是对侵权人催告，不是诉状。不执行递交，不补造回证。到达设计最小，专项转 `设计人身案件通知送达`。不保证时限内赔付。诉讼外理赔函答复期不是法定义务期间。

酒驾、逃逸、无证：本窗只打红旗。交强险对受害人人身损害可能仍在限额内赔偿、事后向致害人追偿；禁止写成对受害人当然不赔。商业三者免责只标条款接口。展开转 `应对保险拒赔减赔`。本窗不写拒赔拆解终稿。禁止指导隐瞒。

出现一次性了结、权益转让：对该相对人闸关闭，转 `审查保险一次性了结弃权`。抢救费且逃逸、未投保或超医疗限额：转 `申请道路救助基金或垫付`。直接起诉只点转介。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过材料闸直接给递交终稿或必得额。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if 金额参数不足，then 该行标未知，禁止写零。
若 if C 端只要大众准备包，then 只分流不回改。

判断状态只许三值。口头转述、截图和「已读」不得写成已受理、已送达或期限已起算。

## 本任务回链纪律

本任务成果是「交强险或商业三者索赔材料包」。不包含：道路交通分账终稿、拒赔拆解、起诉状、测算工作表、精神损害酌定、侵权催告函、弃权效力终稿、救助基金申请、限额内必得。禁止旧限额默写。禁止酒驾当然拒赔受害人。禁止选边治愈。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标递交终稿已形成。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接。
风险档 A：不可逆文书或期限字段必须单独标可逆性。
