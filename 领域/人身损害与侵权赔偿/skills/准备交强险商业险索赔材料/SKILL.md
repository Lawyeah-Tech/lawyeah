# 准备交强险商业险索赔材料

## 任务目标

在明确、无利益冲突的权利人或被保险人立场下，形成向保险人递交的材料包：材料闸、`M#` 行（险种分袋、控制方、是否必须、缺口）、分项限额接口待核、精神损害优先开闭、理赔申请草案。不代报案，不代提交，不保证赔付。不写道路交通分账终稿、拒赔拆解、起诉状、测算数字、对侵权人催告函、弃权效力终稿或救助基金申请。

`depends-on` 为空。分账转 `评估道路交通事故责任与保险先行`。拒赔拆解转 `应对保险拒赔减赔`。诉状转 `直接起诉保险公司`。金额转 `测算人身损害赔偿`。优先是否打开转 `评估精神损害赔偿`。对侵权人催告转 `准备侵权索赔通知`。

## 工作边界

正触发：人身损害已发生，存在或声称存在交强险或商业三者，需要向保险人准备材料包。保单未交齐、限额未核验仍正触发，数字格停止。不知是否已报案仍正触发，不代报案。伤残鉴定不是开窗前提。用户要「限额内必得」「按旧十一万先交」「精神损害不用提出也优先」「酒驾所以交强险一毛不赔」仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关。工伤待遇与第三人车辆同时出现：本窗正触发，工伤段分流劳动，交强险或商业三者材料包可留。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要道路交通分账或限额内必得数字（转 `评估道路交通事故责任与保险先行` / `测算人身损害赔偿`）；
- 已经拒赔或减赔只要拆解理由（转 `应对保险拒赔减赔`）；
- 只要起诉保险人的请求和地位（转 `直接起诉保险公司`）；
- 只要对侵权人催告函或项目表（转 `准备侵权索赔通知`）；
- 只要精神损害酌定终稿（转 `评估精神损害赔偿`）；
- 只要了结弃权审查（转 `审查保险一次性了结弃权`）；
- 只要救助基金或抢救费垫付申请（转 `申请道路救助基金或垫付`）；
- 纯车损且无人身；
- C 端只要大众理赔清单（只分流）；
- 未成争改合同（审查起草搁置）。

「写成必得」不在负触发表。

## 建立工作坐标

确认：使用者与授权；单方立场（受害人直接请求与被保险人索赔分列）；保单表面；认定书只作 `R#`；损失项目只编目不测算；是否已由被侵权人或近亲属**提出**精神损害优先；了结文本红旗；法域。

口头「已经打电话报案」「业务员已读」只登记 `S#`。微信保单截图只作 `D#` 表面，不得写成限额已核验。认定书主次责不得映射三七开。

同时掌握双方秘密，或受害人与保险人、被保险人与保险人同时交材料争同一理赔包：`整体停止`，不得以选边治愈，也不得改走负触发去出材料包。提出伪造票据、顶包、改认定、倒签出险、隐瞒酒驾骗保：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 保单、票据、认定书；`R#` 文书；`C#` 条款；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`M#` 材料行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。接口状态只用 `打开`、`不打开`、`待核`。申请状态只用 `草案`、`待递交`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。本任务默认 `草案` 或 `待递交`，不执行递交。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：交强险被侵权人直接请求；交强险条例分项限额现行标准（禁止已废止死亡伤残十一万、医疗一万旧档）；精神损害优先须被侵权人或近亲属提出、只改死亡伤残限额内排序、不增加限额；酒驾、逃逸、无证不等于交强险对受害人人身当然不赔（可能限额内赔偿后追偿）；商业三者直接请求与免责以合同及保险法为准。技能正文条号不是 `L#`。噪声：已失效《侵权责任法》第四十八条至第五十三条、旧限额、未投保连带、按民事比例扣交强险、未提出自动优先、酒驾等于交强险当然拒赔。不可用则限额数字、直接请求、优先开闭、免责效果字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变限额、请求权或优先开闭的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补本车人员、医保已报防双计、交材料不等于时限内必赔、酒驾不等于对受害人当然拒赔的实务反例。
- `search_template` 只借理赔申请栏目，不把保司表格当法定格式或法定七日必赔。

工具不可用时继续编目保单、票据、认定书；法律效果字段停止。不得凭记忆填旧十一万或必得额。

## 判断节点

执行顺序和停止条件以 [保险索赔方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、材料闸与不关窗

工伤三段分流，第三人车辆材料包可留。错误主张不关窗。双方秘密或伪造第一次停。

### 2. 险种袋与请求权人

交强险与商业三者分袋。交强险直接请求须核验。商业三者直接请求未核验不得当然打开。本车人员除外待核。

### 3. 材料清单

`M#` 固定列。医保已报单列。伤残鉴定不是开窗前提。未知不写零。

### 4. 限额接口与精神损害优先

分项限额待核。禁止旧十一万。优先须提出，不增加限额。不写分账终稿。

### 5. 申请草稿与拒赔红旗

草案，不代提交。酒驾逃逸无证只打红旗转拒赔，禁止概括交强险当然不赔。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；受害人与保险人同时交材料；提出伪造票据、顶包、改认定、倒签出险、隐瞒酒驾骗保。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：分项限额、直接请求权、商业三者免责、优先规则未核验。用户要必得额、旧十一万、未提出自动优先或酒驾交强险当然不赔则该格停止，窗口不关。
- `目标停止`：主目标变为分账终稿、拒赔拆解、起诉状、测算、催告函、弃权审查或救助基金申请。必得额不在目标停止。

禁止指导伪造票据、顶包或隐瞒酒驾。不给胜诉率。不选定法院。不定残。不代报案。不代提交。不保证赔付。
