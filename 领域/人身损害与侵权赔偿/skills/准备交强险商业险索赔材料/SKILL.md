# 准备交强险商业险索赔材料

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的权利人或被保险人立场下，形成“理赔材料包、分项限额、精神损害优先接口”。C 端保险理赔只分流。拒赔争议另项。不保证赔付。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算、鉴定和证据清单。

## 工作边界

正触发：向承保交强险或商业三者的保险人索赔人身损害，需要材料包和分项限额接口。

负触发并输出 `触发判定：负触发，未启动本任务`：

- C 端只要大众理赔清单（只分流）；
- 已经拒赔只要拆解理由（转 `应对保险拒赔减赔`）；
- 纯车损财产且无人身（可转保险相邻）；
- 不保证赔付仍要求写成必得。

不保证赔付。材料包不是起诉状。C 端保险理赔与拒赔准备只分流。

## 建立工作坐标

确认：使用者与授权；权利人或被保险人；保单号险种；事故认定；损失项目；是否已报案；精神损害是否优先；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 保单、票据、认定书；`R#` 文书；`C#` 条款；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`M#` 材料行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验交强险条例、条款分项限额和被侵权人直接请求权。不虚构案件系统。

工具不可用时继续事实、主体、程序文书状态和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [保险索赔方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　险种与请求权人

交强险被侵权人可直接请求。商业三者看条款和法律规定。

### 节点 2　材料清单

身份、保单、认定书、病历票据、银行卡、伤残鉴定。

### 节点 3　分项限额与精神损害优先

死亡伤残、医疗费用分项。优先不增加总额。

### 节点 4　索赔函与递交

理赔申请草稿，不是侵权索赔通知替代。

### 节点 5　拒赔预兆

酒驾逃逸无证等红旗，展开转拒赔专项。

## 停止与安全

- `整体停止`：立场不明；用户坚持伪造票据或顶包。
- `字段停止`：分项限额、直接请求权、条款免责未核验。
- `目标停止`：主目标变为拒赔诉讼或纯财产车损。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
