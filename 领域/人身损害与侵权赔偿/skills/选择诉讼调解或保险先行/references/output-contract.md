# 输出合同

按触发结果选择交付形状。选择闸未打开不得交付路径终稿或保证准许。禁止保险先行替代或阻断诉讼。禁止拒赔才是起诉条件。禁止交强险未赔就不能起诉。禁止选定唯一法院或预填「此致某院」。禁止写死时效或索赔日历截止。禁止已读起算或中断。禁止先予执行写成保全或基金。禁止基金已付写成已经先予执行。禁止未稳定概括弃权后再诉无风险。禁止胜诉率。禁止未知金额写零。禁止选边治愈。禁止倒签或骗保步骤。不代申请。不定残。不保证准许。不写文书终稿。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 选择闸关闭或节点 0 整案转出 | 第 1、2、10 节：关闭理由、路径待核和最小补证。可附标注停止的 `Proc#`。禁止路径终稿、保险已替代诉讼、应当准许、唯一截止日。对第三人路径可留时不得因工伤整案转出 |
| 整体停止 | 第 1、10 节。禁止 `Proc#` 路径包、选边、倒签或骗保方法。双方秘密、倒签出险、要求产出含未知损害概括弃权的可执行路径意见第一次即停，优先于负触发；无选边治愈，无「坚持」或「用户已理解」门槛 |
| 用户要保险替代诉讼、保证先予执行、选定某法院、写死时效、未稳定先签了结再起诉（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；闸未开则仍只交 1、2、10；不得改走负触发关窗；成果不得标路径终稿 `已形成` 或保证准许 |
| 正触发且闸开（可部分开） | 下列十节表头均出现；直接请求、先予执行前提、仲裁、时效未核验的单元格填 `依据不足，无法形成结论` 或 `待核`；路径分列；禁止为填满而宣布应当只走某条、保险已替代诉讼或选定唯一法院 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入路径终稿已形成。双方秘密未解不得进入「部分形成」。每个 `Proc#` 必须带来源和三值判断。`L#` 不得直接抄技能内条号。拒赔再转诉讼、保险替代诉讼、保证准许若返回则记噪声。稿件状态默认 `草案`。

## 1. 触发、单方立场、授权与成果状态

选择闸开、部分开或关。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。稿件默认 `草案`。不代申请。不写文书终稿。

## 2. 来源登记与 MCP 调用表

`S/D/C/R/L/I/G/Proc/V`。口头先赔就能结、已读、口头报案只登记 `S#`／`V#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 目标排序与选择闸

抢救费、易失证据、总赔偿分列。闸未开不得标路径终稿已形成。工伤夹带第三人可留。

## 4. 路径比较 `Proc#`

交强险索赔、商业三者、调解、起诉侵权人、直接请求保险人、先予执行分列；保全与基金只红旗。一行一路径。材料不足不锁定推荐。

## 5. 可并行组合

交强险索赔∥起诉侵权人∥直接请求保险人默认并行。基金∥保险垫付∥先予执行准备可并行。保全∥诉讼可并行。禁止写成必须先理赔。

## 6. 互斥与不可逆

概括弃权与同一请求再诉不得写成可并行无风险。调解书签收、一次性了结升格风险档 A。未稳定包干路径停止。转介弃权审查，本窗不审印好了结书。

## 7. 管辖、仲裁与时效红旗

连结点并列，不选定法院。仲裁未排除则诉讼入口停止，窗口不关。时效只打红旗，已读不得起算，不写死截止日。转介管辖与时效专项。

## 8. 紧急资金：先予执行 ≠ 保全 ≠ 基金

给付不是冻结。尚未起诉只关申请闸。基金已拨 ≠ 已经先予执行。保证裁定该格不支持。本窗不写申请书。

## 9. 失败分流与转介

下一跳只点原子名：诉状、材料包、先予执行、基金、保全、调解效力、了结审查、分账、直接起诉保险人。比较中夹带文书：文书段停止并转介。

## 10. 缺口、停止项与提示

须列对方最强解释：必须先找保险公司拒了再告、交强险没赔完就不能起诉、保险先行已经替代诉讼、限额内付款司机就不用再赔、被保险人签字受害人不能再向交强险要、先签了结以后再诉无风险、保证先予执行今晚裁、基金在办等于已经先予执行、先予执行就是冻账户、谈不拢去某区法院、已读或口头报案时效已经中断、认定书全责所以只能先保险、工伤还在认所以不能告司机、选边即可继续、倒签出险日就能先理赔。

本成果不是诉状、不是申请书、不是材料包、不是调解接受意见、不是了结审查、不是分账终稿、不保证准许、不是唯一截止日。不代申请。保险先行不替代诉讼。
