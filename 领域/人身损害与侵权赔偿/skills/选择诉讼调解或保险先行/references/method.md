# 程序选择方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。稿件状态只用 `草案`、`选择闸关闭`、`比较待核`、`停止`。禁止胜诉率、必然责任比例、唯一必得总额、唯一截止日、选定法院、自行宣布伤残等级、保证准许。未知金额不写零。本任务不代申请、不写文书终稿，不把保险先行写成替代或阻断诉讼。拒赔不是起诉前提。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、已失效《合同法》、把保险先行写成诉讼前置、把拒赔写成起诉条件、把交强险未赔写成不能起诉、把先予执行写成保全、把基金已付写成已经先予执行、把口头或已读写成时效已中断、把未稳定了结写成再诉无风险时记为噪声，不得写入 `L#`。禁止指导倒签出险、骗保或伪造逃逸套基金。

`Proc#` 固定列：`编号｜路径类型（交强险索赔／商业三者索赔／调解／起诉侵权人／直接请求保险人／先予执行／保全／救助基金）｜目标匹配（抢救费／易失证据／总赔偿）｜前提（保单表面／已立案／紧急事实／仲裁排除／治疗稳定）｜可并行（默认：交强险索赔∥起诉侵权人∥直接请求保险人；基金∥保险垫付∥先予执行准备；保全∥诉讼）｜互斥红旗（有效概括弃权 vs 同一请求再诉待核；有效仲裁 vs 起诉某院）｜成本（时间／费用／举证；无胜诉率、无必得额）｜不可逆点（签收调解书／签署了结／未知伤残概括弃权）｜失败下一跳｜管辖仲裁红旗（连结点并列，不选定）｜时效红旗（中断中止接口，不写死截止日；已读不得起算）｜状态（可比较／闸关／字段停止／不打开）｜转介原子｜来源回链`。一行一路径。禁止一行打包「先保险，拒了再告」或「谈不拢去某院」。禁止把先予执行、保全、基金合成「先拿钱」。禁止把交强险与商业三者合成「找保险公司」。

口头「先赔就能结」、微信已读、口头报案只进 `S#`／`V#`，不得升格 `Proc#` 已受理、已理赔或时效已中断。

## 节点 0　分流、立场、选择闸与不关窗

整案转出或闸关闭只交付第 1、2、10 节或标注停止的 `Proc#`，不得交付路径终稿，不得标保险已替代诉讼或先予执行应当准许。闸部分打开时：仅对前提可回链的行给出比较，其余行停止或不打开。

| 信号 | 处理 |
| --- | --- |
| 主成果已是起诉状或一审立案包 | 负触发 `提起人身损害一审`；比较未完成时比较留本窗，诉状段目标停止 |
| 主成果已是起诉保险人诉状 | 负触发 `直接起诉保险公司`；本窗不写地位和诉状 |
| 主成果已是索赔材料包 | 负触发 `准备交强险商业险索赔材料` |
| 主成果已是先予执行申请书 | 负触发 `申请先予执行医疗费`；尚未起诉本窗闸可关申请行，窗口不关 |
| 主成果已是基金或垫付申请 | 负触发 `申请道路救助基金或垫付`；并行 ≠ 已经先予执行 |
| 主成果已是保全必要性或申请 | 负触发 `评估证据或财产保全必要性`／`准备财产或证据保全申请` |
| 主成果已是某份调解方案效力评估 | 负触发 `评估人身调解方案与效力` |
| 主成果已是让步档或协议草稿 | 负触发 `谈判人身损害和解`／`起草人身损害和解协议` |
| 主成果已是保险人了结审查 | 负触发 `审查保险一次性了结弃权` |
| 主成果已是交强险分账或第七十六条对照 | 负触发 `评估道路交通事故责任与保险先行` |
| 只要总体责任总图 | 负触发 `评估人身侵权责任` |
| 只要测算终稿 | 负触发 `测算人身损害赔偿` |
| 纯工伤待遇或劳动程序且无第三人程序 | 整案转劳动；夹带对第三人保险／诉讼／先予执行则本窗正触发，工伤段分流，`Proc#` 可留并转介 `评估工伤与第三人侵权竞合` |
| 诊疗过错或医疗鉴定终稿 | 转医疗；对医疗机构的民事程序比较可留 |
| 海事专门程序 | 转海事 |
| 未成争只要改合同 | 审查起草本窗搁置 |

选择闸打开（可出 `Proc#` 比较，仍不得标应当只走某条或保证准许）须同时满足：单方无冲突主张方立场与授权；主成果是程序适配比较，不是任一文书或接受意见终稿；人身损害已发生或声称已发生；至少两条路径需要比较；拟比较组合不含「未稳定概括弃权后再诉无风险」。

闸关闭（仍正触发）：保险先行替代或阻断诉讼；交强险未赔就不能起诉；拒赔才是起诉条件；保证先予执行准许或今晚必裁；选定唯一法院；写死唯一时效或索赔截止日；已读起算；未稳定先签了结再起诉无风险；先予执行＝保全＝基金；仲裁未核验或表面有效却写应起诉某院。闸未开则仍只交 1、2、10 节。

「保险替代诉讼」「保证先予执行」「选定法院」「写死时效」「未稳定先签了结再起诉」**不关窗**。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或受害人与侵权人、保险人同时交材料争同一份路径意见且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出倒签出险日、入院日或了结落款日，伪造票据、顶包、隐瞒伤情骗保，以路径选择掩盖犯罪，或要求产出覆盖未知伤残、未知手术或「永不追究一切」且仍可执行的路径意见，then 整体停止；第一次提出即停，不以「坚持」或「用户已理解」为门槛。

## 节点 1　目标排序与 `Proc#` 编目

目标分列，路径随目标打开，禁止用一个打包建议覆盖三类目标。

- **抢救费：** 交强险索赔、救助基金或交强险抢救垫付、先予执行（须诉中）、保险垫付。并行须标明。基金／垫付 ≠ 已经先予执行。
- **易失证据：** 保存通知或保全必要性。本窗只红旗，终稿转保全原子。
- **总赔偿：** 鉴定后诉讼或调解、商业三者索赔、直接请求保险人。未鉴定不得建议包干了结换快赔。

每条路径必须填 `Proc#` 固定列。材料不足不锁定「应当只走某条」。

## 节点 2　保险先行与并行

交强险被侵权人可直接请求保险人。交强险索赔、直接请求保险人、起诉侵权人 **默认可并行**。禁止「必须先理赔」「拒赔再转诉讼」「交强险没赔完就不能告」。该主张该格 `现有依据不支持`，窗口不关。检索锚点：交强险被侵权人直接请求；同时起诉侵权人和保险公司的赔偿责任顺序。条号不是 `L#`。

保险人限额内付款默认不消灭对侵权人、用人者其余请求。被保险人单方调解或了结不得消灭受害人交强险直接请求。理赔进行中诉讼入口不关，只标时效与弃权红旗。理赔函、口头报案、已读 **不当然** 中断诉讼时效，展开转 `评估人身损害诉讼时效`，本窗不写死届满日。

商业三者直接请求未核验不得当然打开，该行待核。列保险人诉状终稿转 `直接起诉保险公司`，本窗只点名。索赔材料包转 `准备交强险商业险索赔材料`。分账终稿转 `评估道路交通事故责任与保险先行`。

## 节点 3　调解、起诉、仲裁与管辖红旗

调解路径只比较成本、时间、执行力风险和不可逆点（签收调解书、司法确认后难反悔）。「这份方案签不签」转 `评估人身调解方案与效力`。私下微信不能当人民调解去确认，转介 `办理人身和解执行力补强`，本窗不办手续。

起诉侵权人与直接请求保险人分列。有效书面仲裁协议：诉讼入口字段停止，**不得写应起诉某院**，窗口不关。或裁或诉约定效力待核。管辖连结点并列（侵权地、被告住所地、保险人住所地等），不选定唯一法院，不预填「此致某院」。展开转 `评估人身损害管辖`。事故认定书不得写成民事终局并据此只能调解或只能先保险。

未立案要先予执行或诉讼调解书：成本另列并转介 `提起人身损害一审`，本窗不写诉状。

## 节点 4　先予执行、保全、基金与互斥分流

**先予执行** 是给付，不是查封冻结，一般在受理后终审判决前。三项条件未核验则该行待核。尚未起诉：申请闸关闭，窗口不关，转介 `申请先予执行医疗费` 与起诉。保证裁定、今晚必裁、把伤残金精神损害写入先予执行必得：该格不支持。本窗不写申请书。

**保全** 是冻结或固定。与先予执行可并行，文书必须分开。本窗只红旗，转介保全原子。

**救助基金或交强险抢救垫付** 可与保险、诉讼、先予执行准备并行，**不等于** 已经先予执行。转介 `申请道路救助基金或垫付`。

**互斥：** 「放弃其余一切／永不追究」与同一请求继续起诉、继续向侵权人要余额，不得写成可并行无风险。印好了结转 `审查保险一次性了结弃权`。未稳定或未知伤残概括弃权作为可执行路径：该 `Proc#` 停止，窗口不关。用户理解不能治愈。要求产出该路径意见：整体停止。调解书签收、确认裁定后难再诉，只作不可逆红旗。

失败下一跳只点转介名：理赔受阻 → 直接请求或起诉；先予执行不准 → 基金／保险垫付／继续诉讼；调解失败 → 起诉或普通协议。不得写成「换一家保证能过」。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过选择闸直接给应当只走某条、保证准许或选定法院。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if C 端只要大众准备包，then 只分流不回改。

判断状态只许三值。口头转述、截图和「已读」不得写成已受理、已理赔、已裁定或期限已起算。事故认定书、调解记录不得单独写成民事终局比例。

## 本任务回链纪律

本任务成果是「不写文书终稿的人身损害程序适配比较」。必须包含：保险与诉讼可并行、拒赔不是起诉前提。不包含：诉状、索赔材料包、先予执行申请、基金申请、保全申请、调解接受意见、保险了结审查、交强险分账终稿。禁止保险先行替代诉讼。禁止保证准许。禁止选定法院。禁止写死时效。禁止未稳定了结后再诉无风险。禁止选边治愈。禁止倒签骗保。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标路径终稿已形成。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接。
风险档 A：概括弃权、调解书签收、一次性了结字段必须单独标可逆性。
