# 边界与路由

## 正触发

需要比较保险理赔、调解、起诉、先予执行哪一条更适配当前目标。先保险就能替代或阻断诉讼、交强险未赔就不能起诉、保证先予执行准许、选定某法院、写死时效截止、未稳定先签了结再起诉、先予执行等于保全或基金，仍正触发：选择闸可关，对应格停止，窗口不关。工伤待遇与对第三人保险或诉讼同时出现，仍正触发：工伤段分流劳动，对第三人 `Proc#` 可留。比较中夹带「顺便写诉状」：比较留本窗，文书段转介。

双方秘密、倒签出险骗保、要求产出含未知损害概括弃权的可执行路径意见的停止，优先于负触发。不得改走负触发去出一方路径。保险替代诉讼、保证先予执行不在下表。倒签骗保不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 起诉状或一审立案包 | `提起人身损害一审` |
| 同时或单独起诉保险人的诉状 | `直接起诉保险公司` |
| 交强险或商业三者索赔材料包 | `准备交强险商业险索赔材料` |
| 先予执行申请书 | `申请先予执行医疗费` |
| 救助基金或垫付申请 | `申请道路救助基金或垫付` |
| 保全必要性或保全申请 | `评估证据或财产保全必要性`／`准备财产或证据保全申请` |
| 某份调解方案效力或反悔评估 | `评估人身调解方案与效力` |
| 让步档或协议草稿 | `谈判人身损害和解`／`起草人身损害和解协议` |
| 保险人了结或权益转让审查 | `审查保险一次性了结弃权` |
| 交强险分账或第七十六条对照 | `评估道路交通事故责任与保险先行` |
| 总体责任总图 | `评估人身侵权责任` |
| 分项测算终稿 | `测算人身损害赔偿` |
| 纯工伤待遇或劳动程序且无第三人程序 | 劳动领域 |
| C 端只要大众准备包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「倒签出险日先理赔」「隐瞒伤情签了结再起诉」「两边材料都给你选边」不在本表，走整体停止。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 仅工伤待遇或劳动程序且无第三人程序 | 劳动领域 |
| 诊疗过错或医疗鉴定终稿 | 医疗医药领域；对医疗机构的民事程序比较可留 |
| 海事专门程序 | 海事领域 |
| 指导倒签、骗保、伪造逃逸套基金或以路径掩盖犯罪 | 整体停止 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。对第三人保险、诉讼或先予执行可留。

## 易混

「先找保险公司还是先起诉」正触发。「起诉状写好」走起诉。「总责怎么看」走总体评估。「交强险限额怎么分」走保险先行分账。「这份法官调解签不签」走调解效力。「保险公司拿来印好了结书」走弃权审查。「先冻他房子」走保全，本窗不写冻结。「人还在 ICU，先保险就行不用起诉，保证先予执行今晚裁，交某区法院，伤没评先签了结不够再告」仍正触发；选择闸关；保险与诉讼默认可并行；保证准许、选定法院、写死时效、未稳定了结再诉各格不支持。「工伤还在认，对司机和交强险要比先赔还是先告」正触发，第三人路径可留，工伤段分流。「两边材料都给你，选边告诉我们走哪条」整体停止。
