# 边界与路由

## 正触发

需要比较保险理赔、调解、起诉、先予执行哪一条更适配当前目标。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 已决定起诉 | `提起人身损害一审` |
| 已决定保险索赔 | `准备交强险商业险索赔材料` |
| 总体评估 | `评估人身侵权责任` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 工伤程序 | 劳动领域 |
| 医疗损害鉴定前置 | 医疗医药领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“先找保险公司还是先起诉”正触发。“起诉状写好”走起诉。“总责怎么看”走总体评估。
