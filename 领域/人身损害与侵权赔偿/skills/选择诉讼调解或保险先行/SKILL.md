# 选择诉讼调解或保险先行

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的主张方立场下，形成人身损害程序适配包：选择闸、`Proc#` 分表（交强险索赔／商业三者索赔／调解／起诉侵权人／直接请求保险人／先予执行；保全与救助基金只作红旗）、目标排序、可并行与互斥、成本、不可逆点、失败分流。不写完整申请书或诉状。不代申请。不保证准许或保险时限。不选定法院。不写死时效截止。不定残。无胜诉率。保险理赔与对侵权人、保险人诉讼原则上可并行，拒赔不是起诉条件。交强险被侵权人可直接请求保险人。保险人限额内付款不当然消灭对侵权人其余请求。被保险人单方了结不得消灭受害人交强险直接请求。先予执行是给付不是冻结。基金垫付并行不等于已经先予执行。

`depends-on` 为空。诉状转 `提起人身损害一审` 或 `直接起诉保险公司`。索赔材料包转 `准备交强险商业险索赔材料`。先予执行申请转 `申请先予执行医疗费`。基金申请转 `申请道路救助基金或垫付`。保全转 `评估证据或财产保全必要性`／`准备财产或证据保全申请`。调解签不签转 `评估人身调解方案与效力`。交强险分账转 `评估道路交通事故责任与保险先行`。印好了结转 `审查保险一次性了结弃权`。

## 工作边界

正触发：需要比较保险理赔、调解、起诉、先予执行哪一条更适配当前目标。先保险就能替代或阻断诉讼、交强险未赔就不能起诉、保证先予执行准许、选定某法院、写死时效截止、未稳定先签了结再起诉、先予执行等于保全或基金、仲裁未核验却写应起诉，仍正触发：选择闸可关，对应格填 `现有依据不支持` 或字段停止，窗口不关，不得改走负触发，不得标路径终稿已形成。工伤待遇与对第三人保险或诉讼同时出现：本窗正触发，工伤段分流劳动，对第三人的 `Proc#` 可留。比较中夹带「顺便写诉状」：比较留本窗，文书段目标停止并转介，不得因过宽「已决定只要文书」关窗，也不得本窗代写。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果已是起诉状或一审立案包（转 `提起人身损害一审`）；
- 主成果已是同时或单独起诉保险人的诉状（转 `直接起诉保险公司`）；
- 主成果已是交强险或商业三者索赔材料包（转 `准备交强险商业险索赔材料`）；
- 主成果已是先予执行申请书（转 `申请先予执行医疗费`）；
- 主成果已是救助基金或垫付申请（转 `申请道路救助基金或垫付`）；
- 主成果已是保全必要性或保全申请（转 `评估证据或财产保全必要性`／`准备财产或证据保全申请`）；
- 主成果已是某份调解方案效力或反悔评估（转 `评估人身调解方案与效力`）；
- 主成果已是让步档或协议草稿（转 `谈判人身损害和解`／`起草人身损害和解协议`）；
- 主成果已是保险人了结或权益转让审查（转 `审查保险一次性了结弃权`）；
- 主成果已是交强险分账或第七十六条对照（转 `评估道路交通事故责任与保险先行`）；
- 只要总体责任总图（转 `评估人身侵权责任`）；
- 只要测算终稿（转 `测算人身损害赔偿`）；
- 纯工伤待遇或劳动程序且无第三人程序（转劳动）；
- C 端只要大众准备包（只分流）；
- 未成争改合同（审查起草搁置）。

保险先行替代诉讼、保证先予执行、选定法院、写死时效、未稳定先签了结再起诉**不在负触发表**，窗口不关。倒签出险、骗保、双方秘密、要求产出含未知伤残概括弃权的可执行路径意见**不在负触发表**，走整体停止。

## 建立工作坐标

确认：使用者与授权；主张方；目标排序（抢救费／固定证据／总赔偿）；交强险与商业三者分袋；是否已立案；治疗是否相对稳定、鉴定状态；资金紧急程度；证据是否易失；仲裁或协议管辖表面；拟路径是否含概括弃权；已收款或垫付；法域。

口头「先赔就能结」、微信已读、口头报案只登记 `S#`／`V#`。不得升格为已受理、已理赔、时效已中断或已可执行。用户坚持「保证先赔」「交某区法院」不构成选定法院或保证准许的授权。

同时掌握双方秘密，或受害人与侵权人、保险人同时交材料争同一份路径意见：`整体停止`，不得以选边治愈，也不得改走负触发去出一方策略。受害人已开口且委托范围就是程序比较、且未掌握对方秘密时，可推定主张方立场。只要同时掌握双方秘密，无例外整体停止。提出倒签出险日或入院日、伪造票据、顶包、隐瞒伤情骗保、以路径选择掩盖犯罪、要求产出覆盖未知伤残或「永不追究一切」且仍可执行的路径意见：第一次提出即整体停止，不以「坚持」或「用户已理解」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 保单、票据、认定书表面；`C#` 保险索赔或了结线索；`R#` 立案或调解组织；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Proc#` 路径；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。稿件状态只用 `草案`、`选择闸关闭`、`比较待核`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。不准许率。本任务默认 `草案`，不代申请。禁止「应当只走某条」「保证先赔」「拒赔再转诉讼」。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：交强险被侵权人可直接请求保险人；保险理赔与对侵权人诉讼原则上可并行，拒赔不是起诉条件；保险人限额内付款不当然消灭对侵权人其余请求；被保险人单方了结不得消灭受害人交强险直接请求；书面仲裁协议对起诉入口的限制；先予执行须权利义务关系明确等诉中前提（本窗只比较）。技能正文条号不是 `L#`。噪声：已失效《侵权责任法》、已失效《合同法》、保险先行替代或阻断诉讼、拒赔才可起诉、交强险未赔不能起诉、保证先予执行准许、选定唯一法院、唯一时效截止日、口头或已读即已受理或时效已中断、未稳定了结后仍可执行地再诉、先予执行等于保全、基金已付等于已经先予执行、认定书即民事终局。不可用则诉讼入口、直接请求、先予执行前提、时效中断与仲裁效果字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变起诉入口、直接请求、先予执行前提或时效中断结论的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补先理赔不当然替代诉讼、未稳定一次性了结锁死再诉、尚未起诉难先予执行、仲裁条款排除起诉、调解签收后难再诉的实务反例。

工具不可用时继续目标排序与 `Proc#` 编目；诉讼入口、直接请求、先予执行前提、时效与仲裁字段停止。不得凭记忆写成保险先行替代诉讼、保证准许、选定法院或写死截止日。

## 判断节点

执行顺序和停止条件以 [程序选择方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、选择闸与不关窗

工伤三段分流，对第三人路径可留。双方秘密、倒签骗保第一次停。保险替代诉讼、保证先予执行不关窗。只要文书终稿负触发。

### 2. 目标排序与 `Proc#` 编目

抢救费、易失证据、总赔偿分列。一行一路径。禁止写成「先保险，拒了再告」。

### 3. 保险先行与并行

交强险明确时默认并行。拒赔不是起诉前提。直接请求单独成行。商业三者直接请求未核验不得当然打开。

### 4. 调解、起诉、仲裁与管辖红旗

管辖、时效只作红旗，不选定法院、不写死截止日。仲裁未排除不得写应起诉。调解签不签转效力评估窗。

### 5. 先予执行、保全、基金与互斥分流

给付 ≠ 冻结 ≠ 垫付。尚未起诉只关申请闸。概括弃权与再诉互斥，该组合停止。失败下一跳只点转介名。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；受害人与侵权人、保险人同时交材料；倒签出险日、入院日或了结落款日；伪造票据、顶包、隐瞒伤情骗保；以路径选择掩盖犯罪；要求产出覆盖未知伤残、未知手术或「永不追究一切」且仍可执行的路径意见。整体停止优先于负触发。不以「坚持」或「用户已理解」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：诉讼入口、直接请求、先予执行前提、仲裁排除、时效中断未核验。选择闸未开则路径终稿停止，窗口不关。用户要保险替代诉讼、保证先予执行、选定法院、写死时效或未稳定先签了结再起诉则该格停止，窗口不关。
- `目标停止`：主目标变为诉状、索赔材料包、先予执行申请、基金申请、保全申请、调解接受意见、保险了结审查、交强险分账终稿。保险替代诉讼、保证先予执行不在目标停止。比较中夹带文书：文书段目标停止并转介，比较留本窗。

禁止指导倒签、骗保或伪造逃逸套基金。不给胜诉率。不选定法院。不代申请。不编唯一截止日。不把未知写成零。不定残。不保证准许。保险先行不替代诉讼。
