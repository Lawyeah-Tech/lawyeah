# 边界与路由

## 正触发

建筑物、构筑物倒塌塌陷，或其搁置物悬挂物脱落坠落，或抛掷物坠落物造成人身损害，需要判断责任主体、补偿或物业措施。用户要「全体业主连带」「补偿即全额连带」「伤害即无过错全责」仍正触发。仅有抛物刑责线索而用户仍要民事路径，仍正触发。

双方秘密、编造抛物人、私闯调监控或伪造伤情的停止，优先于负触发。不得改走负触发去出补偿或抗辩。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 总体责任总图 | `评估人身侵权责任` |
| 主体名单终稿 | `评估责任主体与保险覆盖` |
| 1168–1172 形态终稿 | `评估共同侵权与连带按份` |
| 场所安保主成果且非抛物坠落 | `评估场所安全保障义务` |
| 施工堆物、地面施工、塔吊或脚手架 | `评估施工地面地下设施致害` |
| 侵权人不明查明终稿 | `评估侵权人不明路径` |
| 定罪、控告状或强制措施 | 刑事领域 / `分流刑民交叉` |
| 测算或伤残 | `测算人身损害赔偿` / `准备伤残鉴定材料` |
| 起诉状 | `提起人身损害一审` |
| 唯一时效截止日 | `评估人身损害诉讼时效` |
| 监控保存通知发送稿 | `准备监控保存通知` |
| 未成争改物业或装修合同 | 审查起草搁置 |

「全体业主连带」不在本表。

## 易混

「楼上掉下来花盆」正触发。「不知道哪家扔的，把全楼告了」仍正触发：连带格现有依据不支持，走可能加害人补偿待核，不是负触发关窗。「塔吊掉物」走施工专项。「监控没拍到所以全楼连带」不关窗，该格不支持。「私闯某户锁被告」第一次提出即整体停止。
