# 边界与路由

## 正触发

建筑物、构筑物及其搁置物悬挂物脱落坠落，或抛掷物坠落物造成人身损害，需要判断责任主体和补偿。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 施工堆物或地面施工 | `评估施工地面地下设施致害` |
| 刑事高空抛物 | 刑事领域 |
| 侵权人不明综合路径 | `评估侵权人不明路径` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 高空抛物犯罪 | 刑事领域 |
| 物业员工工伤 | 劳动领域 |
| 港口装卸坠落 | 海事领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“楼上掉下来花盆”正触发。“不知道哪家扔的，把全楼告了”必须纠正为补偿路径。“塔吊掉物”走施工专项。
