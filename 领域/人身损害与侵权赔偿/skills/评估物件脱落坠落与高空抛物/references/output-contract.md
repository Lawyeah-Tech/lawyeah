# 输出合同

按触发结果选择交付形状。禁止全体业主连带。禁止把补偿写成全额连带。禁止把伤害写成无过错全责。禁止编造被告。禁止选定法院、伤残等级、必得总额。本窗不定罪。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出（物业员工工伤或劳鉴主轴；诊疗过错主轴；港口装卸或海事坠落；未成争改物业装修合同） | 第 1、2、10 节。禁止路径成立结论、补偿方案、连带名单、执行顺序终局 |
| 整体停止 | 第 1、10 节。禁止请求、抗辩、金额、选边方案、被告清单。双方秘密、编造抛物人、私闯调监控或伪造伤情时，整体停止优先于负触发；第一次提出即停，无选边治愈，无「坚持」门槛 |
| 用户要「全体业主连带」或「补偿即全额连带」或「伤害即无过错全责」（不关窗） | 十节表头可出现；连带格、补偿全额格或无过错全责格填 `现有依据不支持` 或字段停止；不得改走负触发关窗；成果不得标 `已形成` |
| 正触发且可评估 | 下列十节表头均出现；1252/1253/1254 开闭、可能加害人范围、补偿是否适当、物业措施、24/25 执行顺序未核验的单元格填 `依据不足，无法形成结论` 或 `待核`；禁止为填满而编造连带、无过错全责、伤残或必得额 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。双方秘密未解不得进入「部分形成」。每个 `Q#` 必须带判断三值和证明负担方。`L#` 不得直接抄技能内条号。

## 1. 触发、单方立场、授权与成果状态

脱落、倒塌或抛物分型。双方秘密未解不得进入「部分形成」。

## 2. 来源登记与 MCP 调用表

现场、监控、报警分列。口述某户不得写成已确定侵权人。`L#` 不得抄技能内条号。MCP 未调用也留一行。

## 3. 分型判断

倒塌、脱落坠落、抛掷不明分列。无法区分则并行，不选有利分型。施工堆物、塔吊不在此终稿。

## 4. 倒塌塌陷路径

检索锚点第一千二百五十二条。建设单位与施工单位连带候选。因所有人、管理人、使用人或第三人原因则另列。禁止用倒塌处理花盆。

## 5. 脱落坠落过错推定

检索锚点第一千二百五十三条。不是无过错全责。能证明没有过错则不承担。专有与共有待核。伤害即无过错全责格 `现有依据不支持`。

## 6. 可能加害人补偿

检索锚点第一千二百五十四条。已查明侵权人则补偿格不打开。补偿不是连带、不是当然全额。全体业主连带格 `现有依据不支持`。能证明自己不是侵权人是补偿圈排除，不是 1170。

## 7. 物业必要措施与执行顺序

与补偿分列。解释一第二十四条、第二十五条待核。禁止物业与业主连带、禁止同一执行顺序。未核验则执行顺序停止。不写商场 1198 终稿。

## 8. 查明接口

不编造被告。监控未拍到不升格全楼连带。转介侵权人不明路径。刑责只转介刑民交叉，本窗不定罪。公安调查义务不得省略成可选项。

## 9. 下一步

转介监控保存、主体名单、测算、起诉、时效、伤残材料。不定伤残。不选定法院。不写诉状。

## 10. 缺口、停止项与提示

须列对方最强解释（全体业主连带、补偿即全额连带、伤害即无过错全责、监控没有就是全楼的、物业该和业主一起赔到位、自证不是我即可按 1170 免责、花盆应按倒塌找建设单位、选边即可继续）与证据缺口。

本成果不是刑事控告、不是评残、不是诉状、不是必得总额。
