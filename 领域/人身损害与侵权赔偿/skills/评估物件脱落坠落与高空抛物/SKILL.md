# 评估物件脱落坠落与高空抛物

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成第一千二百五十二条倒塌、第一千二百五十三条脱落坠落过错推定、第一千二百五十四条可能加害人补偿与物业必要措施（含解释一第二十四条、第二十五条执行顺序）分路径。不定伤残，不保证必得，不选定法院，不编造被告，不定罪。不把可能加害人补偿或全体业主写成连带必得，不把补偿写成全额连带，不把伤害写成所有人、管理人、使用人无过错全责。

`depends-on` 为空。1168–1172 形态终稿转 `评估共同侵权与连带按份`。商场酒店 1198 转 `评估场所安全保障义务`。地面施工或塔吊转 `评估施工地面地下设施致害`。查明终稿转 `评估侵权人不明路径`。

## 工作边界

正触发：建筑物、构筑物倒塌塌陷，或其搁置物悬挂物脱落坠落，或抛掷物坠落物造成人身损害，需要判断责任主体、补偿或物业措施。用户要「全体业主连带」「补偿即全额连带」「伤害即所有人无过错全责」仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要总体责任总图（转 `评估人身侵权责任`）；
- 只要主体名单终稿（转 `评估责任主体与保险覆盖`）；
- 只要 1168–1172 形态终稿（转 `评估共同侵权与连带按份`）；
- 场所安保主成果且非抛物坠落（转 `评估场所安全保障义务`）；
- 施工堆物、地面施工、塔吊或脚手架主轴（转 `评估施工地面地下设施致害`）；
- 只要侵权人不明查明终稿（转 `评估侵权人不明路径`）；
- 主目标为定罪、控告状或强制措施（转刑事或 `分流刑民交叉`）；
- 只要测算或伤残（转 `测算人身损害赔偿` 或 `准备伤残鉴定材料`）；
- 只要起诉状（转 `提起人身损害一审`）；
- 只要唯一时效截止日（转 `评估人身损害诉讼时效`）；
- 只要监控保存通知发送稿（转 `准备监控保存通知`）；
- 未成争改物业或装修合同（审查起草搁置）。

仅有抛物刑责线索而用户仍要民事补偿或物业责任：本窗正触发，刑责只分流不定罪。

## 建立工作坐标

确认：使用者与授权；单方立场；脱落物或抛物性质；能否确定具体侵权人；物业措施表面；建筑物所有人、管理人、使用人；是否已报警；专有或共有待核；法域。

口头「就是某层某户」、监控截图不得写成已确定侵权人或监控内容已查明。

同时掌握双方秘密或受害人与物业、业主利益冲突未解：`整体停止`，不得以选边治愈，也不得改走负触发去出补偿或抗辩。提出编造具体楼层抛物人、私闯调监控、伪造伤情或违法取证：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 现场、监控、物业记录表面；`R#` 报警回执；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 责任行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。接口状态只用 `打开`、`不打开`、`待核`。技能正文中的条号是检索锚点，不是已核验 `L#`。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验民法典第一千二百五十二条至第一千二百五十四条、解释一第二十四条和第二十五条等将被写入 `L#` 的现行规则；不可用则路径开闭、补偿范围和执行顺序字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变路径开闭、补偿是否全额或物业执行顺序的条文正文再写入 `L#`。不得编造 `regulation_id`，也不得把摘要条号写成已核验 `L#`。
- `search_practiced` 补脱落与抛掷并行、可能加害人范围、补偿是否全额、专有共有、物业措施与 24/25 执行顺序的实务反例。

工具不可用时继续分型、主体名称变体、物业措施表面、报警与监控控制方编目；法律效果字段停止。已失效《侵权责任法》第八十五条至第八十七条不得默写为现行 `L#`。

## 判断节点

执行顺序和停止条件以 [物件坠落方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场与分型

倒塌、脱落坠落、抛掷不明分表。无法区分则并行。施工堆物转施工专项。双方秘密或编造抛物人提出即停。

### 2. 倒塌塌陷

第一千二百五十二条与脱落、抛物分列。禁止用倒塌规则处理花盆或外墙皮。

### 3. 脱落坠落过错推定

第一千二百五十三条不是无过错全责。能证明没有过错则不承担。伤害不等于定责。

### 4. 可能加害人补偿与物业措施

补偿不是连带、不是当然全额。物业与补偿分列，执行顺序核验解释一第二十四条、第二十五条。禁止全体业主连带。

### 5. 查明与输出纪律

不编造被告。监控未拍到不升格全楼连带。刑责只分流不定罪。不定伤残，不选定法院。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；提出编造抛物人、私闯调监控、伪造伤情或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。
- `字段停止`：分型、可能加害人范围、补偿是否适当、物业措施或 24/25 执行顺序未核验。用户要全体业主连带、补偿全额连带或伤害即无过错全责则该格停止，窗口不关。
- `目标停止`：主目标变为刑事控告、施工终稿、场所 1198 终稿、共同侵权形态、不明查明、测算或起诉状。

禁止指导编造被告或私闯取证。不给胜诉率。不选定法院。不保证必得。本窗不定罪。
