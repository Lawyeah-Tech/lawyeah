# 评估铁路航空等非海事承运人人身损害

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成铁路、航空、城市轨道等非海上承运人人身损害责任条件、专门法院红旗、限额与公约接口。客票与车次航班只作上下文，不按航班车次复制方法。不选定法院，不办事故调查，不定伤残，不保证限额内必得，不输出竞合择一终稿或交强险分账。

`depends-on` 为空。管辖连结点表转 `评估人身损害管辖`。择一比较转 `选择人身损害违约侵权竞合路径`。道路交强险分账转 `评估道路交通事故责任与保险先行`。

## 工作边界

正触发：旅客或相关人员在铁路、航空、城市轨道等非海上运输中受伤，需要判断承运人责任条件、专门法院红旗或限额与公约接口。公路客运班车夹带道路交通事故仍可正触发：本窗留承运人合同接口，交强险展开转交通专项。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要交强险或商业三者分账终稿（转 `评估道路交通事故责任与保险先行`）；
- 船舶或海上运输（转海事）；
- 只要管辖连结点表或选定法院（转 `评估人身损害管辖`）；
- 只要违约侵权择一终稿（转 `选择人身损害违约侵权竞合路径`）；
- 车站或机场场所主轴、只要场所安保终稿（转 `评估场所安全保障义务`）；
- 只要总体责任总图（转 `评估人身侵权责任`）；
- 只要过错百分比（转 `评估过错与原因力`）；
- 只要测算或伤残（转 `测算人身损害赔偿`）；
- 只要起诉状（转 `提起人身损害一审`）；
- 只要唯一时效截止日（转 `评估人身损害诉讼时效`）；
- 未成争改运输条款（审查起草搁置）。

按航班号或车次要求各写一套互不通用的规则：不负触发关窗，车次航班只作参数，方法结构保持同一套。

## 建立工作坐标

确认：使用者与授权；单方立场；运输方式；客票或行程单；伤害发生阶段（进站、上、下、运行、经停、出站）；受害人是旅客还是非旅客；是否第三人侵权；缔约承运人与实际承运人；专门管辖或仲裁条款；法域。

口头「铁路法院唯一有权」、客票截图限额、口述十七万或四十万不得写成已核验。调查报告不是民事终局。

同时掌握双方秘密或旅客与承运人利益冲突未解：`整体停止`，不得以选边治愈，也不得改走负触发去出责任、限额或法院策略。提出隐瞒自身疾病骗赔、伪造客票、伪造伤情或违法取证：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 客票、行程单表面；`R#` 事故调查或车站记录；`C#` 运输条款或仲裁；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。接口状态只用 `打开`、`不打开`、`待核`。管辖入口只用 `打开`、`待核`、`停止`、`不选定`。技能正文中的条号是检索锚点，不是已核验 `L#`。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验民法典第八百二十三条、铁路法、事故日有效民用航空法、铁路运输法院专门管辖、限额公布和国际公约等将被写入 `L#` 的现行规则；不可用则归责、免责、限额、公约和专门法院效力字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变责任条件、免责、限额或专门管辖的条文正文再写入 `L#`。不得编造 `regulation_id`，也不得把摘要条号写成已核验 `L#`。
- `search_practiced` 补城市轨道交通是否适用铁路专门管辖、客运免责举证、航空仲裁覆盖人身请求、公约与国内法冲突的实务反例。

工具不可用时继续运输方式、客票和阶段编目；法律结论、限额和法院入口字段停止。已废止铁路旅客十五万限额、华沙旧额、已失效《合同法》第三百零二条不得默写为现行 `L#`。

## 判断节点

执行顺序和停止条件以 [承运人损害方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场与禁止事项

海事整案转出。高铁航班禁止套道交法第七十六条和交强险。双方秘密或骗赔提出即停。

### 2. 阶段、旅客身份与承运人归责

运输过程旅客伤亡检索锚点第八百二十三条。不得写成绝对无过错或绝对过错。非旅客不得套客票路径。

### 3. 第三人双向接口与竞合入口

不得只告一端。不得把第八百二十三条降格为场所补充责任。择一终稿转竞合专项。

### 4. 专门管辖与仲裁红旗

铁路运输法院是专门管辖不是专属管辖。普通民诉入口可停止，仍不选定唯一法院。城市轨道交通待核。

### 5. 限额、公约与转介

数字未核验则停止。不办调查。不定伤残。不保证限额内必得。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；提出隐瞒自身疾病骗赔、伪造客票、伪造伤情或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。
- `字段停止`：归责、免责、限额、公约适用或专门管辖规则未核验。用户要限额内必得或唯一法院则该格停止，窗口不关。
- `目标停止`：主目标变为交强险分账、管辖选定、竞合择一、测算、起诉状或事故调查结论。

禁止指导隐瞒疾病、伪造客票或违法取证。不给胜诉率。不选定法院。不保证限额内必得。
