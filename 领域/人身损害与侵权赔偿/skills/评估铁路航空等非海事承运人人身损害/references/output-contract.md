# 输出合同

按触发结果选择交付形状。禁止选定唯一法院。禁止限额内必得。禁止把已废止十五万或华沙旧额写成现行。禁止把调查报告写成民事终局。禁止用道交法第七十六条或交强险套高铁、航班。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出（海事；工伤待遇或劳鉴主轴；诊疗过错主轴；未成争改条款） | 第 1、2、10 节。禁止责任成立结论、限额数字、选定法院、竞合择一、交强险分账 |
| 整体停止 | 第 1、10 节。禁止责任策略、限额、选边。双方秘密、隐瞒疾病骗赔、伪造客票或伪造伤情时，整体停止优先于负触发；第一次提出即停，无选边治愈，无「坚持」门槛 |
| 用户要限额内必得、调查结论、伤残等级或唯一铁路／航空法院（不关窗） | 十节表头可出现；对应格字段停止；不得改走负触发关窗；成果不得标 `已形成` |
| 正触发且可评估 | 下列十节表头均出现；归责、免责、专门管辖、限额、公约未核验的单元格填 `依据不足，无法形成结论` 或 `待核`；禁止省略后改填必得额或选定法院 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。双方秘密未解不得进入「部分形成」。每个 `Q#` 必须带判断三值。

## 1. 触发、单方立场、授权与成果状态

运输方式、旅客或非旅客、阶段必须写明。双方秘密未解不得进入「部分形成」。

## 2. 来源登记与 MCP 调用表

客票、行程单、调查记录、条款分列。口述限额、截图只登记 `S#` 或 `D#` 表面。`L#` 不得直接抄技能内条号。MCP 未调用也留一行。

## 3. 承运人责任条件与免责待核

第八百二十三条不得写成绝对无过错或绝对过错。免责举证在承运人。航空「完全由于本人健康状况」与第八百二十三条自身健康分列。非旅客不得套客票路径。客运合同旅客伤害不适用铁路运输人身损害解释。

## 4. 第三人介入接口

可识别第三人与承运人双向编目。不得只告一端。不得把第八百二十三条降格为第一千一百九十八条补充责任终稿。

## 5. 违约与侵权竞合入口

只标入口与差异红旗。择一、第九百九十六条、预备合并转 `选择人身损害违约侵权竞合路径`。禁止双份全额。禁止写选侵权当然避开仲裁。

## 6. 专门法院与仲裁红旗

铁路运输法院是专门管辖，不是专属管辖。普通民诉入口可停止，仍不选定唯一法院。城市轨道交通待核。航空打开事故管辖连结点类型，不创造航空专门法院。仲裁表面有效未排除则对该相对方诉讼入口停止。住院地默认不打开。

## 7. 限额与国际公约红旗

数字未核验则停止。禁止十五万、十七万、四十万、华沙旧额默写。国际运输定义待核后再比蒙特利尔与国内法。公约两年与三年时效分列。打开接口不等于限额内必得。

## 8. 证据缺口

监控、客运记录、客票原件。不能因对方控制而推定存在或有利。不办事故调查。调查报告不是民事终局。

## 9. 下一步

转介管辖、竞合、交通专项、场所、高度危险、测算、发函或起诉。不定伤残。不选定法院。公路班车交强险展开转交通专项。

## 10. 缺口、停止项与提示

须列对方最强解释（客运绝对无过错、须先证铁路有过错、十七万封顶、铁路法院唯一有权、地铁当然铁路法院、选侵权避开仲裁、只告第三人、只告路局、隐瞒疾病即可获赔、调查报告即民事终局、航班适用华沙、交强险套高铁）与证据缺口。

本成果不是事故调查结论、不是限额内必得、不是选定法院、不是竞合择一终稿。
