# 边界与路由

## 正触发

旅客或相关人员在铁路、航空、城市轨道等非海上运输中受伤，需要判断承运人责任条件、专门法院红旗或限额与公约接口。公路客运班车夹带道路交通事故仍可正触发：本窗留承运人合同接口。

双方秘密、隐瞒疾病骗赔、伪造客票或伪造伤情的停止，优先于负触发。不得改走负触发去出责任、限额或法院策略。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要交强险或商业三者分账终稿 | `评估道路交通事故责任与保险先行` |
| 海事船舶、通海水域 | 海事领域 |
| 只要管辖连结点表或选定法院 | `评估人身损害管辖` |
| 只要违约侵权择一终稿 | `选择人身损害违约侵权竞合路径` |
| 车站或机场场所主轴 | `评估场所安全保障义务` |
| 总体责任总图 | `评估人身侵权责任` |
| 过错百分比 | `评估过错与原因力` |
| 测算或伤残 | `测算人身损害赔偿` |
| 起诉状 | `提起人身损害一审` |
| 唯一时效截止日 | `评估人身损害诉讼时效` |
| 未成争改运输条款 | 审查起草搁置 |

按航班号或车次要求各写一套规则：不负触发，车次航班只作参数。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 海上运输、船舶 | 海事领域 |
| 机场或车站医疗机构诊疗过错 | 医疗医药领域 |
| 铁路职工工伤 | 劳动领域 |

一般陆上运输夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 连结点展开、应诉管辖、住院地 | `评估人身损害管辖` |
| 择一、第九百九十六条、预备合并 | `选择人身损害违约侵权竞合路径` |
| 公路班车交强险分账 | `评估道路交通事故责任与保险先行` |
| 候车厅、安检前、机场公区场所 | `评估场所安全保障义务` |
| 高速轨道或航空器对非旅客、地面第三人 | `评估高度危险作业致害` |
| 项目金额、伤残 | `测算人身损害赔偿` |
| 三年或公约两年并行情景 | `评估人身损害诉讼时效` |
| 出差或上下班夹带客运 | `评估工伤与第三人侵权竞合` |

## 易混

「高铁上被开水烫伤」正触发。「高速路开车相撞」走交通专项。「游轮」转海事。「该去哪个铁路法院」走管辖评估，本窗只留专门管辖红旗且不选定。「客运和侵权选哪条」走竞合窗。「立刻按十七万算必得」正触发，但限额格停止。「地铁摔伤该去铁路法院」专门管辖待核，不得当然打开或关闭。公路班车急刹：承运人合同留本窗，交强险转交通专项，禁止用百分之十套铁路或航空。
