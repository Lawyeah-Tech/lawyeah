# 边界与路由

## 正触发

旅客或第三人在铁路、航空等非海上运输中受伤，需要判断承运人责任和论坛。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 道路交强险事故 | `评估道路交通事故责任与保险先行` |
| 海事船舶 | 海事领域 |
| 违约侵权选择终稿 | `选择人身损害违约侵权竞合路径` |
| 未成争改条款 | 审查起草搁置 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 海上运输、船舶 | 海事领域 |
| 机场或车站医疗机构诊疗过错 | 医疗医药领域 |
| 铁路职工工伤 | 劳动领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“高铁上被开水烫伤”正触发。“高速路开车相撞”走交通专项。“游轮”转海事。
