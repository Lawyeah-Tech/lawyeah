# 承运人损害方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。接口状态只用 `打开`、`不打开`、`待核`。管辖入口只用 `打开`、`待核`、`停止`、`不选定`。禁止胜诉率、唯一责任百分比、限额内必得总额、选定法院、伤残等级。未知金额不写零。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、已失效《合同法》（含第三百零二条、第一百二十二条）、2003 年人身损害赔偿解释已删除条文，或把已删除的铁路旅客人身伤亡十五万元、自带行李二千元限额、已废止强制险「十五万加二万等于十七万」、华沙公约旧额写成现行标准时记为噪声。道路交通安全法第七十六条、交强险分项用于高铁或航班，同样记为噪声。

`Q#` 固定列：`编号｜运输方式｜受害人身份｜时空阶段｜主体｜请求权类型｜归责免责层｜举证分配｜限额层｜管辖入口｜时效情景｜第三人接口｜判断｜待核`。一行一路径。航班车次只作参数，禁止按航班号或车次复制互不相同的方法结构。

## 节点 0　分流、立场与禁止事项

整案转出只交付第 1、2、10 节。

| 信号 | 处理 |
| --- | --- |
| 船舶、通海水域、海上运输 | 转海事 |
| 工伤待遇或劳动能力鉴定主轴 | 转劳动；客运伤害接口可留，分账转 `评估工伤与第三人侵权竞合` |
| 机场或车站医疗机构诊疗过错主轴 | 转医疗医药 |
| 未成争只要改运输条款或出稿 | 审查起草本窗搁置 |

只要交强险分账、管辖选定、竞合择一、场所安保终稿、总图、过错百分比、测算、起诉状或唯一时效截止日：负触发至对应原子，不是本节点整案转出。

公路客运班车同时构成道路交通事故：**正触发可留**承运人合同 `Q#`；交强险展开必须转 `评估道路交通事故责任与保险先行`。禁止用第七十六条百分之十写入本窗承运人行，更禁止写入铁路或航空行。高铁、普铁旅客、航班人身损害**禁止**套交强险或道交法第七十六条。

车站候车厅、安检前、机场公共区域摔伤主轴：转 `评估场所安全保障义务`。高速轨道或民用航空器对非旅客、地面第三人：标 `评估高度危险作业致害` 接口（第一千二百四十条、第一千二百三十八条），本窗不吞减免终稿，减免条件禁止与第八百二十三条串用。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密且未获冲突豁免，then 整体停止，不得选边治愈。
若 if 提出隐瞒自身疾病骗赔、伪造客票、伪造伤情、隐匿既往或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　阶段、身份与承运人归责

进站、候车候机、上或下交通工具、运行、经停、出站分列。阶段不明不得用「买了票」推定已在运输过程中。

受害人身份分列：持票旅客；免票、优待票或经许可无票（检索锚点第八百二十三条第二款，待核）；未经许可无票；非旅客（道口、线路行走坐卧、作业）；地面第三人。非旅客**不得**写入旅客第八百二十三条客票路径。

缔约承运人与实际承运人、铁路运输企业、航空公司分列，客票是合同初步证据 `D#`，不是责任主体终局。旅行社与实际承运人并行，不是第一百八十六条全球互斥。

检索锚点民法典第八百二十三条：承运人对运输过程中旅客的伤亡承担赔偿责任；伤亡是旅客自身健康原因造成的，或承运人证明伤亡是旅客故意、重大过失造成的除外。这是带法定免责的严格责任形态，**不是**以过错为主，也**不是**没有免责的绝对责任。免责举证在承运人。不得把第一千一百七十三条过失相抵的减责与第八百二十三条除外合成一格。第三人原因不是第八百二十三条免责事由。

非旅客铁路行车或运营事故：检索锚点铁路法第五十八条及《最高人民法院关于审理铁路运输人身损害赔偿纠纷案件适用法律若干问题的解释》（2021 修正，2022-01-01 施行）。**铁路运输企业在客运合同履行过程中造成旅客人身损害的赔偿纠纷，不适用该解释。** 违章通过平交道口、在铁路线路上行走坐卧等不得与旅客第八百二十三条串用。

航空旅客：事件须发生在民用航空器上或旅客上、下民用航空器过程中。检索锚点为事故日有效《民用航空法》旅客伤亡条款（修订前常见为第一百二十四条，2025 年修订后条号须核验）。「完全由于旅客本人的健康状况造成」与第八百二十三条「自身健康原因」文义不同，禁止合成一格。进站未上机、出站已离开航空器，不得当然打开该条。

自带物品与托运行李检索锚点第八百二十四条，与人身伤亡分列，禁止用已删除的自带行李二千元限额污染人身格。

调查报告、事故认定书只作 `R#`，不是民事终局。本窗不办事故调查。民事起诉不以调查完成为前置。

## 节点 2　第三人双向接口与竞合入口

可识别第三人与承运人必须双向编目。不得只告第三人漏承运人，也不得只告承运人漏第三人。承运人对旅客仍可能打开第八百二十三条或航空特别法；安保或救助义务另列，**不得**把客运严格责任改写成第一千一百九十八条补充责任终稿。第一千一百九十八条车站、机场场所补充是另一行，不得写成连带，也不得吞掉第八百二十三条。

违约与侵权竞合：本窗只标 `Q-违`／`Q-侵` 入口及精神损害、限额、仲裁、专门管辖等路径差异红旗。择一、第九百九十六条、预备合并转 `选择人身损害违约侵权竞合路径`。禁止对同一相对方双份全额。禁止写「选侵权当然避开仲裁」。格式免责或限额条款表面存在不等于有效。检索锚点民法典第五百零六条。

## 节点 3　专门管辖、协议管辖与仲裁

铁路运输法院是**专门管辖**，不是不动产式专属管辖。检索锚点：法释〔2012〕10 号第三条。铁路旅客和行李包裹运输合同、铁路行车事故及其他铁路运营事故人身损害赔偿：标专门管辖红旗，**普通民诉入口停止**，区法院连结点不得标 `打开`。任何情况下都不选定唯一法院，含某铁路运输法院。用户口述「铁路法院唯一有权」只登记 `S#`。没有铁路运输法院的地区由高级人民法院指定，仍不在本窗选定。专门管辖不能用应诉管辖治愈。细节转介 `评估人身损害管辖`。

城市轨道交通是否适用铁路专门管辖：依据不足则红旗待核，不得当然写入铁路运输法院，也不得擅自写成普通民诉已打开。

航空没有铁路式专门法院。可列事故管辖连结点**类型**（事故发生地、航空器最先降落地、被告住所地等，条号须核验）。住院地默认不打开。

协议管辖只登记 `C#`。人身侵权损害赔偿的协议管辖不得标 `打开`。仲裁或协议管辖表面有效且未排除覆盖人身请求：对该相对方诉讼入口停止待核。机构不明或或裁或诉同样停止。合同外第三人（车厢或机舱侵权人）不当然受客票仲裁约束，不得整案关闭入口。

## 节点 4　限额、公约时际与输出纪律

限额数字必须运行时核验。未核验则数字格停止。禁止把记忆中的国内航空四十万、蒙特利尔 SDR、已删除十五万写成已核验必得。打开接口不等于限额内必得。用户催必得总额：该格停止，窗口不关，成果不得标 `已形成`。

国际运输先判断是否属于公约项下国际运输（出发地、目的地、约定经停等，待核），再比事故发生日有效的民用航空法与中国参加的 1999 年蒙特利尔公约。华沙体系旧限额不得当主规则，仅在蒙特利尔不适用的残余航线待核。国内段不得未核验就套公约限额。公约两年期间与民法典三年分列，禁止混成一个截止日；展开转 `评估人身损害诉讼时效`。

客运合同旅客伤害不适用铁路运输人身损害解释，不得用该解释的路外减免覆盖持票旅客。

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口。不能因对方控制而推定监控或客运记录存在或内容有利。禁止指导隐瞒疾病、伪造客票或违法取证。
