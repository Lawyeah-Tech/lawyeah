# 输出合同

按触发结果选择交付形状。禁止唯一责任百分比。禁止把受害写成无过错全赔。禁止把补偿写成必须先告第三人或过错全赔。禁止编造被告或虚构保险。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出（主成果仅工伤三段且无个人劳务空间；诊疗主轴；海事） | 第 1、2、10 节。禁止过错分担表、帮工结论、补偿表。单位用工走负触发一句，不走本行 |
| 整体停止 | 第 1、10 节。禁止分担表、全赔方案、改口文本、倒签工钱、伪造拒绝帮工。双方秘密、改口规避工伤、虚构无第三人时，整体停止优先于负触发 |
| 正触发且可判断 | 下列十节表头均出现；用户要全赔或三七开时第 4、6、7 节数字格填 `待核` 或 `依据不足，无法形成结论`；承揽、1191、自甘风险、工伤不打开则填 `不打开`；禁止省略后改填全额或三七开 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。双方秘密未解不得进入「部分形成」。每个 `Q#` 必须带证明负担方和判断三值。

## 1. 触发、单方立场、授权与成果状态

写明受害还是致第三人、是否夹带工伤、受限字段。双方秘密未解不得进入「部分形成」。

## 2. 来源登记与 MCP 调用表

转账、聊天、工钱、日结、拒绝帮工分列编号。口头「帮忙」只登记 `S#`。`L#` 不得直接抄技能内条号。MCP 未调用也留一行。

## 3. 关系分流

劳动、个人劳务、承揽、单位用工并列，不选有利版本。双方均为个人未证明则 1192 不打开。应参保则劳动入口转介。

## 4. 有偿劳务受害过错分担

序位，非唯一比例。禁止旧无过错全赔。用户要全赔则该格不支持或待核。

## 5. 无偿帮工与拒绝

不打开则填 `不打开`。致害与受害分列。拒绝须文本或证人；口头拒绝只作 `S#`。受害侧拒绝后受益范围补偿待核。不写自甘风险成立。

## 6. 个人之间致第三人的对外责任与对内追偿

仅双方个人打开。提供劳务方不当然对外连带。故意或重大过失追偿待核。不附追偿状。单位用工不走本行。

## 7. 第三人侵权与接受劳务一方补偿

可并行请求。禁止必须先告第三人。补偿不等于全额替代。不明转侵权人不明。禁止虚构无第三人。

## 8. 邻接接口

工伤、1191、自甘风险、承揽、共同侵权、保险：不打开则填 `不打开`。有保单才标覆盖，不保证赔付；无保单不虚构交强险或雇主责任险。

## 9. 下一步

只转介测算、发函、过错、主体、用人者、竞合、起诉。禁止在此写诉状或总额。不选定法院。

## 10. 缺口、停止项与提示

须列对方最强解释（叫来的就全赔、无过错也全赔、三七开、自愿即自甘风险、双方无过错各一半、明确拒绝即零补偿、应参保改口劳务、无第三人、口头即雇佣、修屋顶即劳务不是承揽、必须先告第三人、补偿即全赔、无交强险也有三者险、要某区法院就必须出诉状）与证据缺口。

本成果不是工伤认定、劳动关系确认、用人者替代意见、自甘风险成立、过错终稿、承揽终稿或起诉状。
