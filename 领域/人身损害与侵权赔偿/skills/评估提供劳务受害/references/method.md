# 劳务受害方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。过错分担只用序位。禁止唯一责任百分比、三七开、全赔数字。未知金额不写零。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》第三十五条、2003 年人身损害赔偿解释第十一条（雇员受害雇主无过错也赔）、第十三条、第十四条（旧帮工条号）时记为噪声，不得写入 `L#`。受害侧不得写成雇主无过错全赔。

民法典第一千一百九十二条为两款：第一款含致第三人损害、对内追偿、受害双方过错三句；第二款为第三人侵权与接受劳务一方补偿。无偿帮工检索锚点为 2022 年人身损害赔偿解释第四条、第五条，运行时核验是否仍有效。

`Q#` 交付列：`关系假设｜有偿无偿｜拒绝帮工｜过错序位｜第三人侵权｜补偿接口｜对外形态｜证明负担方｜来源｜判断`。转账、聊天、工钱、日结必须分列。

## 节点 0　关系分流

整案转出只交付第 1、2、10 节。

双方均为个人未证明：第一千一百九十二条不打开，该格 `依据不足，无法形成结论`。
若 if 接受劳务方是单位，或个体工商户从业人员执行工作任务，then 负触发至劳动或 `评估用人者责任`。检索锚点：解释（一）第十五条。
若 if 依法应参加工伤统筹（含家政公司员工、工地长期带班、转包给无用工主体资格的个人后聘用的工人），then 工伤三段转劳动；有第三人则转介 `评估工伤与第三人侵权竞合`。本窗不写对单位的民事终局。
若 if 用户要把应参保劳动者改口个人劳务以规避工伤，then 整体停止；不走「可能劳动 / 可能个人劳务」并行来完成改口。
若 if 关系性质依据不足，then 并行「可能劳动 / 可能个人劳务 / 可能承揽」，不选有利版本；个人劳务结论字段停止或标明受限。
口头或微信「帮忙」「明天来修一下」只作邀约候选，不得升格为劳务或帮工已成立。

## 节点 1　有偿劳务受害

检索锚点：民法典第一千一百九十二条第一款第三句。提供劳务一方因劳务受到损害的，根据双方各自的过错承担相应的责任。主张对方有过错的一方证明该过错。禁止写成雇主无过错也全赔。禁止唯一百分比，只用序位。
工钱、口头约定、日结转账只作关系证据，不写成工伤待遇标准。
用户要全赔或三七开：数字格字段停止，比较表仍交付。
一般过失相抵、认定书对照转介 `评估过错与原因力`，本窗不写 1173 终稿。
自愿帮忙不是文体活动固有风险，自甘风险格填 `不打开`，转介 `评估自甘风险与公平分担`，不写成立或不成立。双方均无过错不是当然适用第一千一百八十六条。

## 节点 2　无偿帮工与拒绝

检索锚点：2022 年人身损害赔偿解释第四条、第五条（条号运行时核验）。
帮工致人损害（第四条）：被帮工人承担赔偿责任；可向故意或重大过失帮工人追偿；被帮工人明确拒绝帮工的，不承担赔偿责任。本款无「受益范围补偿」。
帮工受害（第五条）：根据帮工人和被帮工人各自的过错承担相应的责任；被帮工人明确拒绝帮工的，不承担赔偿责任，但可以在受益范围内予以适当补偿。因第三人受害可请求第三人赔偿，也可请求被帮工人适当补偿，补偿后追偿。
明确拒绝必须回链文本或证人。口头拒绝只登记 `S#`，不得写成已阻断。
不得把自愿帮忙写成当然自担全部损害，也不得写成被帮工人当然全赔。2003 年解释第十三条、第十四条为噪声。

## 节点 3　第三人补偿与致第三人对外

检索锚点：民法典第一千一百九十二条第二款。提供劳务期间因第三人行为造成提供劳务一方损害的，提供劳务一方有权请求第三人承担侵权责任，也有权请求接受劳务一方给予补偿。接受劳务一方补偿后，可以向第三人追偿。
补偿与第三人侵权可并行，禁止写成必须先告第三人。补偿不等于全额替代赔偿，也不是接受劳务一方的过错全赔。补偿金额 `待核`，转入 `测算人身损害赔偿` 只作接口。
第三人可指明则列民事请求。不明则转介 `评估侵权人不明路径`，不编造被告。
禁止虚构无第三人。有第三人且应参保：转介工伤竞合，不在本窗用补偿替代工伤入口。

个人之间因劳务致第三人损害：检索锚点第一千一百九十二条第一款第一、二句。由接受劳务一方承担侵权责任；可向故意或重大过失的提供劳务一方追偿。仅双方均为个人时打开。单位用工转 `评估用人者责任`。提供劳务方不当然对外连带，禁止各一半。追偿是对内接口，不附追偿状。

## 节点 4　邻接与输出纪律

个人劳务关系本身不产生交强险。第三人机动车事故可转介 `评估道路交通事故责任与保险先行`。家庭险或雇主责任险只作覆盖接口，不保证赔付；无保单不得虚构。
承揽、定作终稿填 `不打开`，转介主体评估。
C 端临时用工受伤准备包只分流，不把本任务降成大众准备包。
本任务不生成起诉状，不选定法院，不写唯一截止日。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过专项分流直接给全赔。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密且未获冲突豁免，then 整体停止，不得选边治愈。
若 if 用户提出改口规避工伤、虚构无第三人、倒签工钱、伪造拒绝帮工、伪造伤情或隐匿既往，then 整体停止；第一次提出即停。
若 if 日期、送达或动态规则未核验，then 期限字段停止，不编造唯一截止日，不选定法院。
若 if 金额或份额参数不足，then 该行标未知或 `待核`，禁止写零或三七开冒充已核定。

口头转述、截图和「已读」不得写成已受理、已送达或劳务已成立。事故认定书、调解记录不得单独写成民事终局比例。判断状态只许三值。禁止胜诉率。
