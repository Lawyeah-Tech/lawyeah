# 边界与路由

## 正触发

个人之间提供劳务或无偿帮工过程中提供劳务一方或帮工人受害，需要判断双方过错和第三人。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 应参加工伤的劳动者 | 劳动领域 |
| 执行任务致第三人损害 | `评估用人者责任` |
| 工伤与第三人分账 | `评估工伤与第三人侵权竞合` |
| C 端临时用工准备 | 大众专项，只分流 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 工伤认定待遇 | 劳动领域 |
| 医疗损害 | 医疗医药领域 |
| 海事劳务 | 海事领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“邻居叫我修屋顶摔了”正触发。“工地包工头长期带班受伤”可能是劳动，先分流。“员工开车撞行人”是用人者对外责任。
