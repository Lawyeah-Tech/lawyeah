# 边界与路由

## 正触发

双方均为个人的提供劳务或无偿帮工中，提供劳务一方受害，需要判断双方过错或第三人补偿；或个人之间因劳务致第三人损害，需要判断接受劳务一方对外责任。己方或对方主张均可。用户要全赔或三七开，仍正触发，该格字段停止。

用户要把应参保劳动者改口个人劳务、虚构无第三人、倒签工钱或伪造拒绝帮工：整体停止，优先于负触发。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 主成果仅工伤三段且无个人劳务空间 | 劳动领域 |
| 应参保劳动者对单位的路径 | 劳动领域 |
| 家政公司等单位用工 | 劳动或 `评估用人者责任` |
| 单位工作人员执行任务致第三人 | `评估用人者责任` |
| 只要总体责任总图 | `评估人身侵权责任` |
| 只要工伤与第三人分账 | `评估工伤与第三人侵权竞合` |
| 只要过错原因力终稿 | `评估过错与原因力` |
| 只要自甘风险或公平分担终稿 | `评估自甘风险与公平分担` |
| 只要承揽定作人过错终稿 | `评估责任主体与保险覆盖` |
| 只要起诉状 | `提起人身损害一审` |
| C 端临时用工准备包 | 大众专项，只分流 |

「要全赔」「要三七开」不在本表。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 应参保、包工头长期带班、转包无用工主体资格 | 劳动；有第三人则 `评估工伤与第三人侵权竞合` |
| 单位工作人员、个体户从业人员 | `评估用人者责任` |
| 承揽、定作 | `评估责任主体与保险覆盖` |
| 过失相抵、认定书对照 | `评估过错与原因力` |
| 自愿参加文体活动固有风险 | `评估自甘风险与公平分担` |
| 第三人不明 | `评估侵权人不明路径` |
| 第三人机动车 | `评估道路交通事故责任与保险先行` |
| 分项数字 | `测算人身损害赔偿` |
| 已选定后起诉 | `提起人身损害一审` |

## 易混

「邻居叫我修屋顶摔了」可进窗，先分流劳务 / 承揽 / 劳动；「你叫我来的你全赔」仍正触发，全赔格停止。「私人叫邻居帮忙搬家具砸伤路人」是本窗第一款前两句，不转用人者。「员工开车撞行人」是用人者。「工地包工头长期带班受伤」走劳动或工伤竞合；改口个人劳务或虚构无第三人整体停止。「自愿上屋顶」不是自甘风险终稿。
