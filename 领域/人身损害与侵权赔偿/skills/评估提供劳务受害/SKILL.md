# 评估提供劳务受害

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成「个人劳务与帮工表」：提供劳务一方或帮工人受害的双方过错分担、明确拒绝帮工、第三人侵权与接受劳务一方补偿接口；因劳务致第三人损害时，仅双方均为个人才打开接受劳务一方对外责任与对内追偿。不办工伤认定，不确认劳动关系，不输出唯一百分比，不把自愿帮忙写成自甘风险成立。

`depends-on` 为空。接受等价事实、转账、聊天和证据清单。

## 工作边界

正触发：双方均为个人的提供劳务或无偿帮工中，提供劳务一方受害，需要判断双方过错或第三人补偿；或个人之间因劳务致第三人损害，需要判断接受劳务一方对外责任。己方或对方主张均可。用户要全赔或三七开，仍正触发，该格字段停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果仅是劳动关系确认、工伤认定、劳鉴或待遇，且无个人劳务空间（转劳动）；
- 依法应参加工伤统筹的劳动者受害对单位的路径（转劳动）；家政公司员工作为用人单位用工（转劳动或 `评估用人者责任`）；
- 单位工作人员执行工作任务致第三人损害（转 `评估用人者责任`）；
- 只要总体责任总图（转 `评估人身侵权责任`）；
- 只要工伤与第三人分账（转 `评估工伤与第三人侵权竞合`）；
- 只要过错原因力终稿（转 `评估过错与原因力`）；
- 只要自甘风险成立或公平分担终稿（转 `评估自甘风险与公平分担`）；
- 只要承揽定作人过错终稿（转 `评估责任主体与保险覆盖`）；
- 只要起诉状（转 `提起人身损害一审`）。

用户要把应参保劳动者改口个人劳务以规避工伤：整体停止，不走负触发。关系不明：并列可能劳动 / 可能个人劳务，不选有利版本，不关窗。

本任务不选定法院，不写唯一截止日，不代提交起诉状，不虚构交强险或雇主责任险，不给胜诉率。

## 建立工作坐标

确认：使用者与授权；单方立场；提供劳务方与接受劳务方是否均为个人；有偿还是无偿；是否明确拒绝帮工；有无第三人；伤害如何发生；是否夹带承揽或劳动特征；法域。口头或微信「帮忙」「明天来修一下」不得写成劳务或帮工已成立。

同时掌握双方秘密或未解利益冲突：`整体停止`，不得以选边治愈，也不得改走负触发去出全赔或改口方案。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 转账、聊天、工钱、日结分列；`R#` 文书；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 分担行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。过错分担只用序位 `主要` / `同等` / `次要` / `轻微` / `待核`。补偿只用 `补偿接口打开` / `不打开` / `待核`。禁止唯一百分比和全赔数字。技能正文中的条号是检索锚点，不是已核验 `L#`。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验个人劳务受害双方过错、第三人补偿、无偿帮工现行条件等将被写入 `L#` 的规则；不可用则法律效果字段停止，且不得填全赔或三七开。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变分担、拒绝帮工或补偿结论的条文正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补劳动与劳务界限、拒绝帮工、补偿不是全赔的实务反例。

工具不可用时继续关系、工钱、拒绝帮工和第三人编目。不得凭记忆写雇主无过错也全赔、必须先告第三人，或把 2003 年解释第十一条、第十三条、第十四条当现行。

## 判断节点

执行顺序和停止条件以 [劳务受害方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 关系分流

双方须为个人。应参保转劳动。单位用工转用人者。承揽并行待核。改口规避工伤即停。

### 2. 有偿劳务受害

第一款末句：双方过错分担，禁止无过错全赔，禁止唯一百分比。

### 3. 无偿帮工与拒绝

致害与受害分列。明确拒绝须文本或证人回链。受害侧拒绝后可有受益范围补偿，待核。

### 4. 第三人补偿与致第三人对外

第二款补偿不等于全额替代，也不是必须先告第三人。个人之间致第三人打开第一款前两句，不转用人者。

### 5. 邻接与输出纪律

工伤、1191、自甘风险、承揽、保险不打开则填 `不打开`。用户要全赔或三七开则数字格停止。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；把应参保劳动者改口个人劳务以规避工伤；虚构无第三人；倒签工钱或日结；伪造拒绝帮工声明；伪造伤情。整体停止优先于负触发。第一次提出即停，不以「坚持」为门槛。
- `字段停止`：劳务与劳动界限、帮工拒绝、过错分担、补偿规则未核验；用户要全赔或三七开的数字格。
- `目标停止`：主目标变为工伤认定、用人者对外终稿、自甘风险成立、过错终稿或起诉状。

禁止指导改口规避工伤或倒签约定。不给胜诉率。
