# 输出合同

按触发结果选择交付形状。拒赔闸未打开不得交付拆解终稿。禁止酒驾、无证、逃逸等于交强险对受害人人身当然不赔。禁止免责一律无效或未提示即当然无效。禁止必须改赔或限额内必得。禁止默写旧十一万。禁止按民事比例扣交强险。禁止把认定书写成保险免责闭集。禁止选边治愈。禁止隐瞒酒驾或倒签步骤。禁止重写产品条款正文。不代提交投诉或起诉。不保证改赔。不选定法院。不定残。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 拒赔闸关闭或节点 0 整案转出 | 第 1、2、10 节。禁止 `Q#` 终稿、改赔承诺、诉状。第三人车辆拒赔可留时不得因工伤整案转出 |
| 整体停止 | 第 1、10 节。禁止拆解策略、选边、隐瞒指导。双方秘密、同时交包、伪造倒签骗保时，整体停止优先于负触发；第一次提出即停，无选边治愈，无「坚持」门槛 |
| 用户要酒驾交强险当然不赔、免责一律无效、必须改赔必得或夹带重写产品（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；闸未开则仍只交 1、2、10；不得改走负触发关窗；成果不得标 `已形成` |
| 正触发且闸开 | 下列十节表头均出现；免责效力、交强险范围、提示说明、时限未核验填 `依据不足，无法形成结论` 或 `待核`；禁止为填满而宣布必改赔或酒驾当然不赔 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。双方秘密未解不得进入「部分形成」。每个 `Q#` 必须带来源、险种袋、条款或函面原文和判断三值。`L#` 不得直接抄技能内条号。条例第二十二条旧口径、旧限额、免责一律无效若返回则记噪声。

## 1. 触发、单方立场、授权与成果状态

拒赔闸开或关。受害人直接请求与被保险人索赔分列。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。

## 2. 来源登记与 MCP 调用表

拒赔函、口头 `S#`、保单条款、认定书分列。口述拒赔、已读只登记 `S#`。MCP 未调用也留一行。噪声命中须登记。

## 3. `Q#` 理由行

固定列：险种袋｜拒赔或减赔理由｜所引条款或函面原文｜交强险判断｜商业险判断｜待核。一行一理由。禁止混袋。口头不得升书面决定。

## 4. 交强险抗辩限制

酒驾、无证、逃逸：对受害人人身可能限额内赔后追偿，禁止「当然不赔」。分项用尽才可能支持减赔。追偿不对抗受害人。本车人员待核。

## 5. 商业三者免责与提示说明

提示说明须事实。未提示不当然无效也不当然有效。医保外待核。驾驶证过期尚未注销不得仅以此拒赔。认定书非免责闭集。期限未核验不编唯一截止日。

## 6. 定损、医保外与鉴定接口

对照票据或鉴定。禁止「协商十级」锁定。不定残。后续治疗只转介。

## 7. 复效、投诉路径

可选。不保证受理或改赔。不代提交。诉讼外答复期非法定义务期间。投诉机关与路径待核，不把内部复议写成行政复议。

## 8. 最强异议

酒驾当然不赔、免责已提示故全免、未提示故一律无效、材料不全即拒赔闭集、认定书即免责、选边即可继续、改产品条款即可必赔。

## 9. 禁止事项与转介

只点名：材料包、分账、测算、直接起诉、保险人应诉、弃权、基金、工伤竞合、伤残异议、后续治疗。不写那些终稿。不选定法院。

## 10. 缺口、停止项与提示

须列对方最强解释与证据缺口。本成果不是材料包、分账、诉状、弃权意见、测算、基金申请或保险人答辩。不保证改赔。不重写产品。
