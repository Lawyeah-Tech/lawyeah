# 边界与路由

## 正触发

保险人拒赔、减赔或定损争议，被保险人或受害方需要拆解理由。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 尚未拒赔的材料包 | `准备交强险商业险索赔材料` |
| 直接起诉保险人 | `直接起诉保险公司` |
| 纯财产车损 | 保险相邻 |
| 保险了结弃权 | `审查保险一次性了结弃权` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 骗保刑事风险 | 刑事领域红旗 |
| 工伤保险拒付 | 劳动领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“保险公司说酒驾不赔人”正触发。“还没递材料”走索赔材料。“让我签一次性了结”走弃权审查。
