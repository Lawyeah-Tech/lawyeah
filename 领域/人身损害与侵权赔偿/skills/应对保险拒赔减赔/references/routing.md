# 边界与路由

## 正触发

已出现拒赔、减赔或人伤定损争议。书面、口头、短信、定损单均可。无书面函仍正触发，闸可关。工伤待遇与第三人车辆同时出现，仍正触发：工伤段分流劳动，拒赔袋可留。用户要「酒驾所以交强险一毛不赔」「免责一律无效」「必须改赔必得」或夹带「重写产品」仍正触发。

双方秘密、同时交同一拒赔包、伪造经过、倒签出险、隐瞒酒驾骗保的停止，优先于负触发。不得改走负触发或刑事整案转出去出拆解稿。必须改赔不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 尚未拒赔的材料包 | `准备交强险商业险索赔材料` |
| 道路交通分账或限额内必得数字 | `评估道路交通事故责任与保险先行` / `测算人身损害赔偿` |
| 起诉保险人的请求和地位 | `直接起诉保险公司` |
| 保险人已被诉只要应诉 | `保险公司应对直接索赔` |
| 了结弃权审查 | `审查保险一次性了结弃权` |
| 救助基金或垫付申请 | `申请道路救助基金或垫付` |
| 纯车损且无人身 | 保险相邻 |
| C 端只要大众理赔清单 | 只分流 |
| 未成争只要改条款出稿 | 审查起草搁置 |

「重写产品」「酒驾当然不赔」「免责一律无效」「必须改赔」不在本表。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 仅工伤待遇且无第三人车辆 | 劳动领域 |
| 医疗责任保险主轴 | 医疗医药领域 |
| 海事专门程序 | 海事领域 |
| 指导骗保 | 整体停止；刑事只打红旗，不得用来出策略 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。第三人车辆拒赔袋可留。

## 易混

「保险公司说酒驾不赔人」正触发，当然不赔格不支持或待核。「还没递材料」走索赔材料。「让我签一次性了结」走弃权审查。「连保险公司一起告」走直接起诉。「帮我改免责条款产品」夹在拒赔里不关窗，该格不支持。「必须全额改赔」仍正触发，必得格不支持。「两边材料都给你，代表我们出改赔意见」整体停止，不得选边。「酒驾先别告诉保险公司，倒签出险」第一次提出即整体停止。
