# 拒赔应对方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。接口状态只用 `打开`、`不打开`、`待核`。禁止胜诉率、必须改赔、限额内必得总额、选定法院、自行宣布伤残等级、唯一截止日。未知金额不写零。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》第四十八条至第五十三条、2003 年人身损害赔偿解释已删除条文、已失效《合同法》，把交强险条例第二十二条旧口径写成对受害人人身当然不赔，把已废止交强险十一万或一万旧档当现行，把免责一律无效或未提示即当然无效，把认定书写成保险免责闭集时记为噪声。

`Q#` 固定列：`编号｜险种袋（交强险/商业三者，禁止一行混袋）｜拒赔或减赔理由｜所引条款或函面原文｜交强险判断｜商业险判断｜待核｜来源回链`。一行一理由。多份保单不得合并。

## 节点 0　分流、立场、拒赔闸与不关窗

整案转出或闸关闭只交付第 1、2、10 节，不交 `Q#` 终稿、改赔承诺或诉状。

| 信号 | 处理 |
| --- | --- |
| 尚未拒赔只要材料包 | 负触发 `准备交强险商业险索赔材料` |
| 只要分账或限额内必得数字 | 负触发 `评估道路交通事故责任与保险先行` / `测算人身损害赔偿` |
| 只要起诉保险人 | 负触发 `直接起诉保险公司` |
| 保险人已被诉只要应诉 | 负触发 `保险公司应对直接索赔` |
| 只要了结弃权 | 负触发 `审查保险一次性了结弃权` |
| 只要救助基金或垫付申请 | 负触发 `申请道路救助基金或垫付` |
| 主轴仅工伤待遇且无第三人车辆 | 整案转劳动；夹带交强险或商业三者拒赔则本窗正触发，工伤段分流，`Q#` 可留并转介 `评估工伤与第三人侵权竞合` |
| 医疗责任保险主轴 | 转医疗 |
| 海事专门程序 | 转海事 |
| 纯车损无人身 | 负触发 |
| 未成争只要改条款出稿 | 审查起草本窗搁置 |
| 指导骗保、隐瞒酒驾、倒签、顶包 | 整体停止，不改走刑事整案转出去出策略 |

拒赔闸打开条件（同时满足）：单方无冲突立场与授权；至少一条可编号的拒赔、减赔或人伤定损主张；至少一袋险种可指称。无书面函仍正触发，闸可关，只交 1、2、10 节。

「酒驾交强险当然不赔」「免责一律无效」「必须改赔必得」「重写产品」**不关窗**。闸未开则仍只交 1、2、10 节。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或受害人与保险人、被保险人与保险人同时交材料争同一拒赔包且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出伪造经过、顶包、倒签出险、隐瞒酒驾骗保、威胁或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　拒赔文书与 `Q#` 理由行

作出日、送达日、所引条款号、事实主张分列。口头拒赔、微信已读不得写成已送达书面决定，不得单独起算核定期或异议期。无文书：先固定沟通记录，对应格待核。

交强险与商业三者分袋。禁止一行混成「酒驾不赔」。用户主张必须改赔：该格 `现有依据不支持` 或字段停止，窗口不关。

---

## 节点 2　交强险抗辩限制

检索锚点：交强险条例；道交解释关于无证、醉酒、吸毒后驾驶、故意制造事故时交强险对第三人人身损害仍可能在限额内赔偿、保险人赔偿后向侵权人追偿。条例第二十二条垫付抢救费用、不赔偿财产损失的旧口径，不得写成对受害人人身当然拒赔。

酒驾、无证、逃逸：对受害人人身该格禁止「当然不赔」；未核验则待核。保险人之间或对致害人的追偿不当然对抗受害人。分项限额用尽：减赔可能支持，须对账，不得默写旧十一万。本车人员、未在投保机动车使用：待核。用户要「一毛不赔」：该格 `现有依据不支持` 或待核，窗口不关。

---

## 节点 3　商业险免责与提示说明

检索锚点：保险法关于格式条款提示说明、免除保险人责任条款、核定与拒绝赔偿通知（常见为第十七条、第十九条、第二十三条，条号运行时核验）。未提示可能不生效力，但须有提示方式、投保单、字体标志等事实；不得一律宣告无效，也不得一律有效。医保外用药条款效力待核。事故认定书不是保险合同的唯一免责依据，也不是民事终局。驾驶证过期尚未注销不得仅以此拒赔（道交解释（二）相关条号作检索锚点）。用户要「免责一律无效」：该格 `现有依据不支持` 或待核，窗口不关。

核定、拒赔通知时限未核验则期限字段停止。禁止从报案日、出具日或已读日起算唯一届满日。投诉或内部复议路径待核，不得把内部复议写成行政复议，不得写死唯一机关。

---

## 节点 4　定损接口与复效分流

人伤定损过低：对照票据和鉴定。伤残未评定：不得接受以「协商十级」锁定。本窗不定残。后续治疗争议转 `评估后续治疗费另行主张`。鉴定异议转 `提出伤残鉴定异议或重新鉴定`。

金融监管投诉只作可选路径说明，不保证受理或改赔，不代提交。诉讼只转介 `直接起诉保险公司`，不写诉状，不选定法院。保险人已被诉转 `保险公司应对直接索赔`。了结文本转 `审查保险一次性了结弃权`。限额数字转分账或测算。材料缺口转 `准备交强险商业险索赔材料`。逃逸、未投保或超医疗限额的抢救费转 `申请道路救助基金或垫付`。禁止指导伪造事故经过。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过拒赔闸直接给改赔承诺。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if 金额参数不足，then 该行标未知，禁止写零。
若 if C 端只要大众准备包，then 只分流不回改。

判断状态只许三值。口头转述、截图和「已读」不得写成已受理、已送达或期限已起算。

## 本任务回链纪律

本任务成果是「交强险或商业三者拒赔减赔理由拆解」。不包含：材料包终稿、分账、起诉状、弃权效力、测算、救助基金申请、保险人答辩。禁止酒驾对受害人当然不赔。禁止免责一律无效。禁止必须改赔。禁止选边治愈。禁止重写产品条款正文。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标拆解终稿已形成。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接。
风险档 A：不可逆文书或期限字段必须单独标可逆性。
