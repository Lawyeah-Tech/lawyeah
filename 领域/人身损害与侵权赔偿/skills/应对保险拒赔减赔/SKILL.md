# 应对保险拒赔减赔

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的被保险人或受害方立场下，形成“拒赔理由拆解、条款与免责、复效或诉讼分流”。不重写保险产品。纯财产车损可转保险相邻。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算、鉴定和证据清单。

## 工作边界

正触发：保险人拒赔、减赔或定损争议，被保险人或受害方需要拆解理由。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未索赔只要材料包（转 `准备交强险商业险索赔材料`）；
- 纯财产车损无人身（可转保险相邻）；
- 要求重写保险产品条款。

不重写产品。免责条款提示说明义务须核验，不得凭记忆宣告一律无效。

## 建立工作坐标

确认：使用者与授权；被保险人或受害人；拒赔通知全文；保单条款版本；事故事实；是否交强险；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 拒赔函、条款；`R#` 认定书；`C#` 条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 抗辩拆解；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验保险合同编格式条款、交强险不得抗辩事由和商业险免责。不虚构案件系统。

工具不可用时继续事实、主体、程序文书状态和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [拒赔应对方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　拒赔文书登记

理由逐条编号，不概括“他们不赔”。

### 节点 2　交强险特殊规则

交强险对受害人的抗辩受限，须核验条例。

### 节点 3　商业险免责与提示

免责条款提示说明、医保外用药、核定。

### 节点 4　定损与鉴定

人伤定损过低：对照票据和鉴定。

### 节点 5　复效协商或诉讼

复议、投诉、诉讼分流。不保证结果。

## 停止与安全

- `整体停止`：立场不明；用户坚持倒签出险或隐瞒酒驾骗保。
- `字段停止`：免责效力、交强险法定赔偿范围未核验。
- `目标停止`：主目标变为重写产品或纯车损案件。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
