# 应对保险拒赔减赔

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的被保险人或受害方立场下，形成拒赔拆解包：拒赔闸、`Q#` 行（险种袋、拒赔理由、所引条款、交强险与商业险分列判断、待核）、复效或投诉分流。不保证改赔。不重写保险产品。不写材料包终稿、分账数字、起诉状、弃权效力、测算、救助基金申请或保险人答辩。

`depends-on` 为空。尚未拒赔的材料包转 `准备交强险商业险索赔材料`。分账转 `评估道路交通事故责任与保险先行`。诉状转 `直接起诉保险公司`。保险人应诉转 `保险公司应对直接索赔`。了结文本转 `审查保险一次性了结弃权`。

## 工作边界

正触发：已出现拒赔、减赔或人伤定损争议。书面函、口头、短信、定损单均可；无书面函仍正触发，闸关则只交关闭理由。工伤待遇与第三人车辆同时出现：本窗正触发，工伤段分流劳动，交强险或商业三者拒赔袋可留。用户要「酒驾所以交强险一毛不赔」「免责条款一律无效」「必须改赔必得」或夹带「重写产品条款」仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未拒赔只要材料包（转 `准备交强险商业险索赔材料`）；
- 只要分账或限额内必得数字（转 `评估道路交通事故责任与保险先行` / `测算人身损害赔偿`）；
- 只要起诉保险人的请求和地位（转 `直接起诉保险公司`）；
- 保险人已被诉只要应诉（转 `保险公司应对直接索赔`）；
- 只要了结弃权审查（转 `审查保险一次性了结弃权`）；
- 只要救助基金或垫付申请（转 `申请道路救助基金或垫付`）；
- 纯车损且无人身；
- C 端只要大众理赔清单（只分流）；
- 未成争只要改条款出稿（审查起草搁置）。

「重写产品」「酒驾当然不赔」「免责一律无效」「必须改赔」不在负触发表。

## 建立工作坐标

确认：使用者与授权；单方立场（受害人直接请求与被保险人索赔分列）；拒赔文本逐条；保单与条款版本；交强险与商业三者分袋；认定书只作 `R#`；法域。

口头拒赔、微信已读只登记 `S#`。不得写成已送达书面决定，不得据此起算唯一异议期或核定期。

同时掌握双方秘密，或受害人与保险人、被保险人与保险人同时交材料争同一拒赔包：`整体停止`，不得以选边治愈，也不得改走负触发去出拆解稿。提出伪造事故经过、顶包、倒签出险、隐瞒酒驾骗保：第一次提出即整体停止，不以「坚持」为门槛。既有酒驾、逃逸作为事实的民事分袋，在未提出隐瞒指导前可编目。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 拒赔函、条款、定损单；`R#` 认定书；`C#` 条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 拒赔理由行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。接口状态只用 `打开`、`不打开`、`待核`。技能正文中的条号是检索锚点，不是已核验 `L#`。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：交强险对受害人人身（酒驾、无证、逃逸可能限额内赔偿后向致害人追偿，不等于当然拒赔）；保险合同编格式条款提示说明；商业三者免责以合同及保险法为准；医保外不得一律无效或有效；驾驶证过期尚未注销不得仅以此拒赔。技能正文条号不是 `L#`。噪声：已失效《侵权责任法》第四十八条至第五十三条、已废止交强险十一万或一万旧档、把交强险条例第二十二条旧口径写成对受害人人身当然不赔、免责一律无效、未提示即当然无效、认定书即保险免责、必须改赔。不可用则免责效力、交强险法定范围、提示说明效果、期限字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变先赔后追偿、免责效力或提示说明效果的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补酒驾不等于对受害人当然拒赔、未提示不当然无效、医保外不一律无效、定损偏低、驾驶证过期未注销的实务反例。
- `search_template` 只借复议或投诉栏目，不把表格当法定格式或法定时限内必改赔。

工具不可用时继续编目函面原文和理由行；法律效果字段停止。不得凭记忆写当然不赔、一律无效或唯一截止日。

## 判断节点

执行顺序和停止条件以 [拒赔应对方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、拒赔闸与不关窗

工伤三段分流，第三人拒赔袋可留。错误主张不关窗。双方秘密或骗保第一次停。

### 2. 拒赔文书与 `Q#` 理由行

作出日、送达日、所引条款、事实主张分列。禁止一行混袋。口头不得升书面决定。

### 3. 交强险抗辩限制

酒驾、无证、逃逸对受害人人身可能限额内赔后追偿。保险人追偿不当然对抗受害人。分项用尽减赔须对账。

### 4. 商业险免责与提示说明

提示说明须事实。医保外待核。认定书不是免责闭集。驾驶证过期尚未注销不得仅以此拒赔。

### 5. 定损接口与复效分流

不得接受协商十级锁定。不定残。投诉可选，不保证、不代提交。诉讼只转介。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；受害人与保险人同时交材料；提出伪造经过、顶包、倒签出险、隐瞒酒驾骗保。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：免责效力、交强险法定范围、提示说明事实、限额、核定或拒赔时限未核验。用户要酒驾当然不赔、免责一律无效、必须改赔或重写产品则该格停止，窗口不关。
- `目标停止`：主目标变为材料包、分账、起诉状、弃权、测算、救助基金或保险人应诉终稿。必须改赔不在目标停止。

禁止指导隐瞒酒驾、倒签或伪造经过。不给胜诉率。不选定法院。不定残。不代提交投诉或起诉。不保证改赔。不重写产品。
