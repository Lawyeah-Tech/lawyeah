# 边界与路由

## 正触发

财产或证据已被保全，被保全方需要复议、限缩或担保置换。复议期已过、送达不明、用户要必须解除、已读起算或写死截止仍正触发：复议稿或解除格停止，窗口不关。工伤待遇与对第三人冻结同时出现，仍正触发：工伤段分流劳动，对第三人 `Rsp#` 可留。被保全人主张超范围含误冻案外人财产或生活必需，仍正触发限缩复议。

双方秘密、同时交材料、转移隐匿、倒签送达的停止，优先于负触发。不得改走负触发去出复议稿或转账步骤。转移隐匿不在下表。保证解除不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 申请方续封或新申请书 | `准备财产或证据保全申请`（标明不是复议） |
| 尚未决定是否申请保全 | `评估证据或财产保全必要性` |
| 先予执行医疗费或生活费 | `申请先予执行医疗费` |
| 管辖异议书 | `提出人身案件管辖异议` |
| 实体答辩 | `应对人身损害一审` |
| 起诉状 | `提起人身损害一审` |
| 执行中异议终稿 | `应对人身损害执行` |
| 纯案外人异议之诉或案外人执行异议终稿 | 案外人执行异议专项；未安装则路由去向 `unavailable`；本窗不写该诉、不填十节 |
| C 端只要大众准备包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「把钱转到老婆卡上」「倒签送达回证」不在本表，走整体停止。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 仅工伤待遇且无对第三人保全措施 | 劳动领域 |
| 海事扣船解除 | 海事领域 |
| 指导隐匿转移 | 整体停止；刑事只打红旗，不得用来出步骤 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。对第三人冻结应对可留。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 申请方续封或新保全 | `准备财产或证据保全申请` |
| 是否申请尚未决定 | `评估证据或财产保全必要性` |
| 紧急医疗费给付 | `申请先予执行医疗费` |
| 执行中异议 | `应对人身损害执行` |
| 管辖 | `评估人身损害管辖`／`提出人身案件管辖异议` |
| 实体抗辩 | `应对人身损害一审` |
| 工伤与第三人 | `评估工伤与第三人侵权竞合` |
| 主体与保险 | `评估责任主体与保险覆盖` |
| 诉前三十日未起诉红旗 | `提起人身损害一审` |

## 易混

对先予执行裁定不服要复议：本窗可留，不得把给付改写成查封解除；只要申请先予执行终稿仍负触发 `申请先予执行医疗费`。
「账户被冻了怎么解」正触发。「帮我把钱转到别人名下」第一次提出即整体停止。「车是我爸的不是被告的」：纯案外人要异议之诉则负触发专项；被保全人主张误冻父亲车辆仍正触发超范围复议，不关窗、不代异议之诉。「微信已读就算送达，按五日写死截止，保函必须今晚解」仍正触发；已读不得起算，截止日停止，保证解除格不支持。「过期了还能不能复议」仍正触发；复议稿停止，担保置换可留。「两边材料都给你，选边写解除」整体停止。「原告只要续封」负触发申请原子，本窗不出复议。
