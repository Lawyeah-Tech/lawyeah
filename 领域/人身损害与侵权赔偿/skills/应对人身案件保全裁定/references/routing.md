# 边界与路由

## 正触发

财产或证据已被保全，被保全方需要复议、异议或担保置换。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 申请保全 | `准备财产或证据保全申请` |
| 隐匿转移 | 整体停止 |
| 案外人异议 | `unavailable`（P2） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 海事扣船解除 | 海事领域 |
| 隐匿财产犯罪风险 | 刑事红旗 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“账户被冻了怎么解”正触发。“帮我把钱转到别人名下”停止。“车是我的不是被告的”属案外人 P2。
