# 输出合同

按触发结果选择交付形状。应对闸未打开或过期不得交付可提交复议终稿。禁止保证解除。禁止已读、作出日起算。禁止过期关窗。禁止选定唯一法院。禁止把实体无责写成应当解冻。禁止选边治愈。禁止转移隐匿步骤。禁止复议期间停止执行。不代提交。不定残。不保证解除。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 应对闸关闭或节点 0 整案转出 | 第 1、2、10 节。禁止复议终稿、唯一截止日、保证解除。对第三人冻结可留时不得因工伤整案转出 |
| 整体停止 | 第 1、10 节。禁止 `Rsp#`、复议稿、选边、转移方法。双方秘密、转账至他人名下、倒签送达、毁损被保全物第一次即停，优先于负触发；无选边治愈，无「坚持」门槛 |
| 期间已过（不关窗） | 十节表头可出现；复议稿 `停止`；担保置换评估可留；不得改走负触发关窗 |
| 送达不明或条文未核验 | 窗口仍开；截止日停止；复议稿不得写成可提交 |
| 用户要已读起算、保证解除或写死截止（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；闸未开则仍只交 1、2、10；成果不得标复议终稿 `已形成` 为应当解除 |
| 正触发且闸开 | 下列十节表头均出现；未核验格填待核；禁止为填满而宣布必解除或写死截止 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开或过期不得进入可提交复议终稿已形成。双方秘密未解不得进入「部分形成」。每个 `K#`/`Rsp#` 必须带来源和判断三值。`L#` 不得直接抄技能内条号。已读起算、保证解除、财产纠纷应当解除套人身损害若返回则记噪声。稿件状态默认 `草案`。

## 1. 触发、单方立场、授权与成果状态

谁对哪份保全裁定不服。应对闸是否打开。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。稿件默认 `草案`。

## 2. 来源登记与 MCP 调用表

裁定文号、送达回证、电子送达到达记录分列。口头解冻、已读截图只登记 `S#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 期限卡 `K#`

作出日与送达日分列。已读、发送成功、口头告知不得起算。不与三年诉讼时效混算。过期只停复议稿。明示复议期间不停止执行。用户口述唯一截止日则截止日停止。

## 4. 复议请求 `Rsp#`

超范围、无必要、担保不足、主体错误、生活必需分列。实体无责不得作唯一理由。财产与证据分表。不得请求机关直接判决民事无责。

## 5. 担保置换

形式、额度待核。保险保函只是候选。不保证解除。人身侵权套用财产纠纷应当解除待核。争议标的须申请人同意待核。

## 6. 禁止事项

转移、隐匿、毁损、擅自处分、把冻结资金转到他人名下。第一次提出即停。不提供方法。妨害民事诉讼或拒执只打红旗。

## 7. 申请草稿

被保全人、文号、请求、理由、担保材料、受理机关（待核，不编造）。草案，不代提交。过期或送达不明：本节 `停止`。禁止预填应当解除或实体无责。

## 8. 对实体案件的影响

保全裁定、复议结论不是民事终局。复议驳回不等于实体已败。错误赔偿只作提示。本窗不写分账、过错百分比终稿。

## 9. 邻接拆分与下一步

续封／新申请、先予执行、管辖异议、实体答辩、起诉、执行异议、案外人异议只点名转介。不打开则填 `不打开`。不选定法院。

## 10. 缺口、停止项与提示

须列对方最强解释：已读即送达、保证解除、等额保函当天必须解、复议期间可以先转出资金、过期关窗什么都不能主张、实体无责即应解冻、选边即可继续、转到亲属名下就能解、口述截止日必须写入、案外人异议由本窗代做。

本成果不是已提交复议、不是解除裁定、不是申请保全、不是案外人异议之诉、不保证解除、不是唯一截止日。不代提交。
