# 应对保全方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。期限状态只用 `待核`、`情景`、`停止`。稿件状态只用 `草案`、`提交前待核`、`停止`。禁止准许率、必然解除、唯一截止日、选定法院、自行宣布伤残等级。未知金额不写零。本任务不代提交，不保证解除，不提供转移隐匿方案。

技能正文和本文件中的条号、「五日」是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、把已读写成送达、把复议期间写成停止执行、把提供担保写成人身损害当然解除、把实体无责写成应当解冻、把转移隐匿写成解冻方法时记为噪声，不得写入 `L#`。禁止指导转移、隐匿、毁损或擅自处分被保全财产或证据。

`K#` 固定列：`文书名称｜受送达人｜作出日｜送达日｜送达方式｜效力凭证｜期间类型（保全复议／提供担保解除／诉前三十日红旗／执行中异议，待核）｜起算事件｜期间长度待核｜待核截止｜稿件状态`。一受送达人一卡。禁止把已读、作出日、口头告知写成起算。

`Rsp#` 固定列：`编号｜分型（财产／证据）｜保全对象｜请求类型（复议／担保置换／限缩／解除）｜理由类型（超范围／无保全必要／担保不足／主体错误／生活必需）｜裁定记载｜材料表面冲突｜判断（三值）｜担保候选（形式待核，不保证解除）｜范围红旗｜稿件是否可写入｜来源回链`。一行一类对象。财产与证据分表。

## 节点 0　分流、立场、应对闸与不关窗

整案转出或闸关闭只交付第 1、2、10 节，不交复议终稿、唯一截止日或保证解除。

| 信号 | 处理 |
| --- | --- |
| 申请方只要续封或新申请书 | 负触发 `准备财产或证据保全申请`；标明不是复议 |
| 尚未决定是否申请保全 | 负触发 `评估证据或财产保全必要性` |
| 只要先予执行医疗费或生活费 | 负触发 `申请先予执行医疗费` |
| 只要管辖异议或实体答辩 | 负触发对应原子 |
| 只要起诉状 | 负触发 `提起人身损害一审` |
| 只要执行中异议终稿 | 负触发 `应对人身损害执行`；过期后执行异议只转介，本窗不写终稿 |
| 纯案外人主张权属、只要异议之诉 | 负触发案外人执行异议专项；未安装则路由去向 `unavailable`；本窗不写异议之诉、不填十节。被保全人主张超范围含误冻案外人财产仍正触发限缩复议 |
| 主轴仅工伤待遇且无对第三人保全措施 | 整案转劳动；夹带第三人车辆／账户／场所证据冻结则本窗正触发，工伤段分流，`Rsp#` 可留并转介 `评估工伤与第三人侵权竞合` |
| 诊疗过错或医疗鉴定终稿 | 转医疗；对医疗机构财产冻结的应对可留 |
| 海事扣船解除 | 转海事 |
| 未成争只要改合同 | 审查起草本窗搁置 |

应对闸打开条件（对某一行，同时满足）：单方无冲突被保全方立场与授权；已有保全裁定或等价 `R#`；主成果是复议或担保置换草稿，不是申请保全、先予执行、案外人异议之诉或实体答辩。

闸关闭（仍正触发）：无裁定文本也无送达事实却要「保证解冻」；完全无对象线索却要「撤销一切冻结」。「必须今晚解」「已读起算」本身不得开闸写成应当解除。

「已读起算」「保证解除」「写死截止」「过期仍要可提交复议稿」「实体无责即应解冻」**不关窗**。闸未开则仍只交 1、2、10 节。过期仍正触发：复议稿停止，担保置换评估可留。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或受害人与被保全人同时交材料争同一份解冻方案且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出转移、隐匿、毁损、擅自处分被保全财产或证据、把冻结资金转到他人名下、倒签送达、威胁或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　期限卡 `K#`

检索锚点：对保全或者先予执行的裁定不服，可以申请复议一次；复议期间不停止裁定的执行。财产保全专门规定常见自裁定**送达之日起五日**内申请复议、人民法院十日内审查；与民事诉讼法一般条款的期间长度可能不一致，一律待核。条号和「五日」「十日」不是已核验 `L#`。未核验则截止日停止，不得编唯一日历截止日，也不得在五日与十日之间默写唯一数字。

起算事件是送达日，不是作出日、微信已读、截图、邮件打开、口头告知。送达不明：期限字段停止。用户口述「后天截止」只登记 `S#`。

复议以一次为限。未核验不得起草第二次复议。复议期间不停止执行：不得写成「先等复议再遵守裁定」或「复议期间可以先转出资金」。

期间已过：复议稿停止，窗口不关；第 4 节担保置换评估必须可留。不得改走负触发关窗。诉前保全后三十日内未起诉应解除，是对申请方的期间，被保全方不得据此写成自己已胜诉；该红旗转介 `准备财产或证据保全申请`／`提起人身损害一审`，本窗只标待核。

## 节点 2　复议理由 `Rsp#`

打开：超范围、无保全必要、申请人担保不足、主体错误、生活必需或与本案无关财物被查封。生活必需超范围须回链清单。证据保全范围过宽导致无关病历或商业秘密：请求限缩，不请求毁损或发还后擅自删除。

不得把实体无责、事故认定书次责、交强险在案写成唯一复议理由。保险覆盖可以降低财产保全必要性，不等于裁定应当撤销。用户要「无责所以必须解冻」：该格 `现有依据不支持` 或待核，窗口不关。

财产行与证据行分表。不得合成「撤销一切冻结」。不利事实不得从草稿删除。

## 节点 3　担保置换

被申请人提供担保，人民法院裁定解除保全——检索锚点须运行时核验。财产保全专门规定常见：财产纠纷案件中被保全人或第三人提供充分有效担保请求解除的，人民法院应当裁定准许；被保全财产为争议标的的，解除须经申请保全人同意。人身损害赔偿不是当然「财产纠纷」闭集，争议标的例外待核，**不得写成等额保函即应当解除**。证据保全提供金钱担保尤其不得写成当然解封。

保险保函只是候选，是否接受由法院决定。用户要「保函法院必须收、当天解冻」：该格 `现有依据不支持` 或待核，窗口不关。不保证解除。变更保全标的物（等值担保财产）同样待核。

## 节点 4　草稿与邻接拆分

草稿栏目：申请人（被保全人）、裁定文号、复议或解除请求、理由、担保材料、受理机关（作出裁定的人民法院，待核，不编造）。状态 `草案` 或 `提交前待核`。不代提交。过期、送达不明：复议稿 `停止`。禁止预填应当解除、实体无责或「此致某院」以外的唯一选定。

申请有错误应赔偿被申请人因保全所遭受的损失：只作提示，不等于本窗已判决赔偿，转实体或另诉接口待核。

邻接：续封／新申请只点 `准备财产或证据保全申请`。执行异议只点 `应对人身损害执行`。案外人异议之诉不写。先予执行、管辖异议、实体答辩、起诉状只点名转介。不打开则填 `不打开`。

擅自处分已保全财产可能构成妨害民事诉讼，情节严重可能触及拒不执行，只打红旗，不给步骤。
