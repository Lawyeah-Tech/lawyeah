# 应对人身案件保全裁定

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的被保全方立场下，形成不代提交的应对包：应对闸、`K#` 期限卡、`Rsp#` 复议或担保置换行、不保证解除的担保候选、复议或解除草稿。复议期间不停止执行。不保证解除。不选定法院。不计算唯一截止日。保全裁定不等于实体败诉。不提供转移、隐匿、毁损或擅自处分被保全财产或证据的方案。

`depends-on` 为空。申请方续封或新申请转 `准备财产或证据保全申请`。尚未决定转 `评估证据或财产保全必要性`。紧急医疗费转 `申请先予执行医疗费`。执行中异议转 `应对人身损害执行`。纯案外人异议之诉不由本窗代做。

## 工作边界

正触发：财产或证据已被保全，被保全方需要复议、限缩或担保置换。对先予执行裁定不服申请复议可留本窗，给付义务不得改写成查封解除。复议期已过、送达不明、用户要「必须解除」「已读起算」「写死截止」仍正触发：复议稿或解除格停止，窗口不关。工伤待遇与对第三人冻结同时出现：本窗正触发，工伤段分流劳动，对第三人的 `Rsp#` 可留。被保全当事人主张超范围含误冻案外人财产或生活必需：仍正触发限缩复议，不关窗。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 申请方只要续封或新申请书（转 `准备财产或证据保全申请`，标明不是复议）；
- 尚未决定是否申请保全（转 `评估证据或财产保全必要性`）；
- 只要先予执行医疗费或生活费（转 `申请先予执行医疗费`）；
- 只要管辖异议或实体答辩（转 `提出人身案件管辖异议`／`应对人身损害一审`）；
- 只要起诉状（转 `提起人身损害一审`）；
- 只要执行中异议终稿（转 `应对人身损害执行`）；
- 纯案外人主张权属、只要案外人异议之诉或案外人执行异议终稿（转案外人执行异议专项；未安装则路由去向标 `unavailable`，本窗一句负触发，不填十节、不代做异议之诉）；
- C 端只要大众准备包（只分流）；
- 未成争改合同（审查起草搁置）。

转移隐匿、倒签送达、双方秘密**不在负触发表**，走整体停止。保证解除、已读起算、过期要复议稿**不在负触发表**，窗口不关。

## 建立工作坐标

确认：使用者与授权；被保全方；裁定文号与内容；作出日与送达日分列；送达方式与效力凭证；财产或证据对象；可提供的担保；法域。

口头「已经送到」「微信已读就算到了」「后天截止」「等额保函必须今晚解」只登记 `S#`。不得写入期限卡或保证解除。

同时掌握双方秘密，或受害人与被保全人同时交材料争同一份解冻方案：`整体停止`，不得以选边治愈，也不得改走负触发去出一方复议稿。被保全人已开口且委托范围就是复议或担保置换、且未掌握对方秘密时，可推定被保全方立场。只要同时掌握双方秘密，无例外整体停止。提出转移、隐匿、毁损、擅自处分被保全财产或证据、把冻结资金转到他人名下、倒签送达：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 裁定、权属、清单；`R#` 送达凭证；`C#` 担保或保险材料；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`K#` 期限卡；`Rsp#` 应对行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。期限状态只用 `待核`、`情景`、`停止`。稿件状态只用 `草案`、`提交前待核`、`停止`。技能正文中的条号和「五日」是检索锚点，不是已核验 `L#`。本任务默认 `草案`，不代提交。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：对保全裁定不服可申请复议一次，复议期间不停止执行；复议起算为裁定送达日而非已读或作出日；财产保全复议常见自送达之日起五日（期间长度待核，技能正文五日不是 `L#`）；被保全人提供担保请求解除由法院审查，人身侵权不得直接套「财产纠纷提供充分担保即应当解除」，争议标的解除可能须申请保全人同意，待核；保全限于请求范围或与本案有关财物；申请有错误应赔偿被申请人因保全所遭受的损失（不等于本窗已判决赔偿）。噪声：已失效《侵权责任法》、已读起算、保证解除、写死截止、选定唯一法院、实体无责即应解除、转移隐匿可解冻、案外人异议由本窗代做、复议期间先停止执行。不可用则复议期限、解除条件、担保效力和机关路径字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变复议期间、解除条件或担保效果的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补已读不等于送达、过期复议稿应停但仍可评估担保置换、保险保函是否接受由法院决定、生活必需超范围复议、不保证解除的实务反例。
- `search_template` 只借复议申请或解除申请栏目，不把范本当法定格式、已提交文本或指定唯一法院。

工具不可用时继续裁定、送达与 `Rsp#` 编目；期限和法律结论字段停止。不得凭记忆写唯一截止日或必然解除。

## 判断节点

执行顺序和停止条件以 [应对保全方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、应对闸与不关窗

工伤三段分流，对第三人冻结可留。双方秘密或隐匿第一次停。错误主张不关窗。申请方续封负触发。

### 2. 期限卡 `K#`

自送达日起算。已读、作出日不得起算。过期不关窗，复议稿停止，担保置换可留。复议期间不停止执行。

### 3. 复议理由 `Rsp#`

超范围、无必要、担保不足、主体错误、生活必需分列。实体无责不得作唯一理由。财产与证据分表。

### 4. 担保置换

形式待核。不保证解除。保险保函只是候选。人身侵权套用财产纠纷应当解除待核。

### 5. 草稿与邻接拆分

草案，不代提交。过期或送达不明则复议稿停止。案外人异议之诉不写。执行异议只转介。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；受害人与被保全人同时交材料；提出转移、隐匿、毁损、擅自处分被保全财产或证据、把冻结资金转到他人名下、倒签送达、威胁或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：送达日不明、复议期限或解除条件未核验。过期则复议稿停止，窗口不关。用户要已读起算、保证解除或写死截止则该格停止，窗口不关。
- `目标停止`：主目标变为申请保全、必要性评估、先予执行、管辖异议、实体答辩、起诉状、执行异议终稿或案外人异议之诉。必须解除不在目标停止。

禁止指导转移隐匿。不给胜诉率。不保证解除。不选定法院。不代提交。不编唯一截止日。
