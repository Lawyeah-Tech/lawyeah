# 评估人身损害管辖

## 任务目标

在明确、无利益冲突的单方立场下，形成“人身损害管辖连结点表”：侵权行为实施地、结果发生地、事故管辖连结点、各被告住所地或经常居住地、级别管辖待核、专属红旗、仲裁条款红旗。不代写管辖异议书，不与时效混算截止日，**任何情况下都不选定唯一法院**。

`depends-on` 为空。接受等价事实、测算、鉴定和证据清单。

## 工作边界

正触发：人身损害已发生，单独委托核验受诉法院连结点、级别或专属，或评估中该判断成为主成果。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要管辖异议书终稿（转 `提出人身案件管辖异议`）；
- 只要诉讼时效截止日（转 `评估人身损害诉讼时效`）；
- 只要完整起诉包（转 `提起人身损害一审`）；
- 只要答辩状或应诉草稿（转 `应对人身损害一审`）；
- 只要责任总图（转 `评估人身侵权责任`）；
- 工伤待遇仲裁或诉讼管辖（转劳动）；
- 医疗损害主轴管辖（转医疗医药）；
- 海上运输或船舶事故（转海事）。

本任务不代写异议书或诉状，不保证某法院受理，不给胜诉率，不选定唯一法院。

## 建立工作坐标

确认：使用者与授权；单方立场；各可能被告名称与住所地材料；侵害实施地和结果发生地；事故认定书或病历记载地点；保险人所在地；客运或旅游合同中的仲裁或协议管辖条款；是否已有案号或应诉行为；法域。口头“应该在某地起诉”不得写成连结点已成立。

同时掌握双方秘密或未解利益冲突：`整体停止`，不得以选边治愈，也不得改走负触发去写异议书或起诉状。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关文书；`C#` 协议管辖或仲裁条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`J#` 连结点；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。连结点状态只用 `打开`、`待核`、`不选定`。技能正文中的条号是检索锚点，不是已核验 `L#`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验侵权管辖、事故管辖、专属、协议管辖、仲裁和应诉管辖等将被写入 `L#` 的现行规则；不可用则这些字段停止，且不得选定唯一法院。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变连结点效力的条文正文再写入 `L#`。不得编造 `regulation_id`，也不得把摘要条号写成已核验 `L#`。
- `search_practiced` 补铁路运输法院、级别管辖标准和专门法院路径。

工具不可用时继续事实、主体、程序文书状态和问题清单。2017 年民事诉讼法第二十八条不得默写为现行侵权管辖 `L#`。

## 判断节点

执行顺序和停止条件以 [管辖方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 专项分流与专属红旗

工伤、医疗、海事整案转出。铁路运输法院专门管辖命中则普通民诉入口停止。

### 2. 侵权行为地与事故管辖

实施地与结果发生地分列。公路等事故另列事故发生地、车辆最先到达地等；住院地默认不打开。

### 3. 被告住所地与保险人

各被告分别建行。保险人住所地不对未列为当事人的驾驶人生效。

### 4. 协议管辖与仲裁红旗

表面有效未排除时不得写应向某法院起诉。或裁或诉则诉讼入口停止。

### 5. 应诉管辖与输出纪律

已应诉未提异议的风险单列。任何情况下都不选定唯一法院。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；连结事实全部无法建立；用户提出虚构住所地或倒签协议管辖。整体停止优先于负触发。不以「坚持」为门槛。
- `字段停止`：法域、住所地、侵权行为地、仲裁条款效力或级别管辖标准未核验。
- `目标停止`：主目标已变为异议书、起诉状、时效唯一截止日或总体责任总图。

禁止指导虚构住所地、倒签协议管辖或违法取证。不给胜诉率。
