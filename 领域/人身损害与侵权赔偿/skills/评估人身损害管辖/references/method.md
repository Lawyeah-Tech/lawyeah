# 管辖方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、论坛、期限、主体或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然责任比例或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

`J#` 固定列：`编号｜连结类型｜地点事实｜来源｜对哪一被告生效｜支持｜不利｜判断｜待核`。

每个连结点独立判断。不得把“保险公司所在地一定可以”写成对全部被告生效。

## 节点 0　专项分流与专属红旗

先于实体连结点。命中任一项则本任务只交付分流理由和最小交接。

| 信号 | 处理 |
| --- | --- |
| 工伤待遇仲裁或诉讼管辖 | 转劳动 |
| 诊疗过错医疗损害诉讼主轴 | 转医疗医药 |
| 船舶、海上人身伤亡、海事保全 | 转海事 |
| 已决定提管辖异议且只要异议书 | 负触发至 `提出人身案件管辖异议` |
| 只要三年时效截止日 | 负触发至 `评估人身损害诉讼时效` |

若  if 材料显示铁路旅客运输人身损害，then 标铁路运输法院专属红旗，不得写成普通侵权行为地法院当然有权。
若 if 材料显示海上旅客或船舶碰撞，then 整案转海事，不在本任务展开连结点表。
口头转述“交警说在我们这儿告”不得写成专属或指定管辖已成立。

## 节点 1　侵权行为地连结点

运行时核验民事诉讼法关于侵权诉讼由侵权行为地或被告住所地人民法院管辖的条文。侵权行为地包括实施地和结果发生地，二者冲突时并行列入 `J#`，不选对用户有利的一处冒充唯一。

若 if 道路交通事故发生地与住院抢救地不一致，then 两地均列为候选，判断分别为现有依据支持或依据不足，不得合并。
若 if 只有微信聊天提到“在某商场摔的”而无现场或病历地点，then 实施地字段停止。
若 if 持续治疗跨多个医院，then 结果发生地以最初损害显现地为候选，后续就医地不得当然扩张为全部有权法院。
事故认定书、门诊病历封面、监控截图上的地点冲突并列，不删不利地点。

## 节点 2　被告住所地与保险人

自然人以户籍地为住所，经常居住地另证。法人或其他组织以主要办事机构所在地为住所。名称不一致不自动合并。

若 if 被告为机动车驾驶人、车辆所有人和交强险保险人，then 三人住所地分列，不得用保险人营业部地址代替驾驶人连结点。
若 if 商业三者保险人是否列为被告尚未闭合，then 其住所地只作备位 `J#`，主位不锁定。
若 if 只有手机号归属地或微信号，then 住所地依据不足，无法形成结论。
级别管辖：标的额和基层或中级标准须运行时核验受诉地标准，材料不足不选定级别。

## 节点 3　协议管辖与仲裁红旗

若 if 运输合同、旅游合同或保险条款存在仲裁条款，then 先判断是否覆盖人身损害请求、是否书面、机构是否特定。机构不明或或裁或诉：诉讼入口字段停止，不得直接写应起诉。
若 if 格式条款协议管辖与侵权法定管辖冲突，then 并列风险，效力须核验民法典合同编格式条款和民诉协议管辖条件，未核验则不选定。
若 if 用户主张“当时没注意仲裁条款”，then 该主张只作 `S#`，不得写成条款当然无效。
不得把已失效法律中的协议管辖旧口径写入 `L#`。

## 节点 4　应诉管辖与输出纪律

若 if 已有应诉答辩且未提管辖异议的材料，then 标应诉管辖风险红旗，是否已丧失异议权须核验民诉及解释，未核验则字段停止。
若 if 连结点均依据不足，then 交付缺口清单，不编造“可在原告所在地起诉”。
输出每行 `J#` 只对应一个连结类型和一个地点。禁止输出“某法院百分之百有权”或胜诉率。
本任务不生成异议书、起诉状或时效唯一截止日。


## 证据与下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。

下一步按期限灭失、易失证据、改变请求抗辩、可逆性排序。相邻文书或评估只写转介条件和最小交接。禁止指导伪造伤情、隐匿既往、威胁、倒签或违法取证。

时效并行情景只作红旗一行，展开计算转介 `评估人身损害诉讼时效`。

## 本任务回链纪律

本任务成果是「评估人身损害管辖」：单独委托核验侵权行为地、被告住所地、级别或专属；单方。
不得把本成果写成相邻原子终稿。不包含：不代写管辖异议书；不与时效混算截止日。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`，已停止字段逐行列出待核事项。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接：已固定事实时间线、主体表和缺口。
风险档 A：不可逆文书或期限字段必须单独标可逆性。
