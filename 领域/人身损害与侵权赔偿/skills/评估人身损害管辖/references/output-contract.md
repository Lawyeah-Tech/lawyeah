# 输出合同

按触发结果选择交付形状。禁止选定唯一法院。禁止把交警口头指定写成管辖已成立。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出 | 第 1、2、10 节。禁止连结点表和选定法院 |
| 整体停止 | 第 1、10 节。禁止连结点结论、异议策略。双方秘密未解时，整体停止优先于负触发 |
| 铁路运输法院专门管辖红旗 | 第 1、2、7、10 节。普通民诉入口停止，第 4–6 节区法院连结点不得标打开 |
| 仲裁未排除（运输／旅游等覆盖人身请求待核） | 第 1、2、7、10 节。诉讼入口停止，不得写应向某院起诉。交强险保单仲裁不当然关闭对侵权人／交强险的诉讼入口 |
| 正触发且可评估 | 下列十节表头均出现；字段停止的单元格填 `依据不足，无法形成结论` 或 `待核`，禁止省略后改填唯一法院 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。每个 `J#` 必须带判断。

## 1. 触发、单方立场、授权与成果状态

写明是否正触发及受限字段。双方秘密未解不得进入“部分形成”。

## 2. 来源登记与 MCP 调用表

`S/D/R/C/L/I/G/J/V`。MCP 未调用也留一行。`L#` 不得直接抄技能内条号。

## 3. 主体与已进入程序状态

已有案号、应诉或送达必须分列。口头转述不得写成已受理。

## 4. 侵权行为地与事故管辖连结点表

实施地与结果发生地分列，冲突并列。公路等事故另列事故发生地、车辆最先到达地。住院地不得当然扩张。

## 5. 各被告住所地或经常居住地表

对哪一被告生效必须可见。保险人单独一行，不得替代驾驶人连结点。

## 6. 级别管辖待核

标的额和标准未核验则停止。核验后仍不选定唯一级别法院。

## 7. 专属、协议管辖与仲裁红旗

铁路运输法院、海事、仲裁机构不明必须可见。表面有效仲裁不得写应起诉。

## 8. 应诉管辖风险

未提异议并应诉或反诉的风险明示。级别管辖和专属除外须可见。

## 9. 证据缺口与下一步

补证住所地、条款原件、事故地点的合法路径。异议书、起诉状只转介。

## 10. 缺口、停止项与提示

须列对方最强解释（原告所在地当然有权、保险人地址覆盖司机、交警指定、住院地即事故地）与证据缺口。

本成果不是异议书、起诉状或时效意见，不保证受理，不选定唯一法院。
