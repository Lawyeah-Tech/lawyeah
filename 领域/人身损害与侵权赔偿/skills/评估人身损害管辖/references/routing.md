# 边界与路由

## 正触发

人身损害已发生，单独委托核验受诉法院连结点、级别或专属，而不是要异议书或起诉状。

受害人开口且委托范围是连结点表时，不因口语化咨询整体停止。双方秘密、虚构住所地或倒签协议管辖的停止，优先于负触发。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要管辖异议书 | `提出人身案件管辖异议` |
| 只要诉讼时效表 | `评估人身损害诉讼时效` |
| 只要起诉包 | `提起人身损害一审` |
| 只要应诉 | `应对人身损害一审` |
| 工伤待遇管辖 | 劳动领域 |
| 医疗损害主轴 | 医疗医药领域 |
| 海事专属 | 海事领域 |
| 总体责任总图 | `评估人身侵权责任` |

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 要写异议书 | `提出人身案件管辖异议` |
| 铁路、航空非海事承运人 | `评估铁路航空等非海事承运人人身损害` |
| 交强险保险人住所与分账 | `评估道路交通事故责任与保险先行`；被告地位 `评估责任主体与保险覆盖` |
| 直接诉保专项 | `直接起诉保险公司` |
| 时效截止日 | `评估人身损害诉讼时效` |

## 易混

“这个案子该去哪个法院”正触发，但成果是连结点表，不是“应向某区法院起诉”。“起诉期限过没过”走时效评估。“已经被起诉，要在十五日内提异议”走管辖异议原子。连结点和时效禁止合成一个截止日。保险人营业部所在地不等于对司机有管辖。
