# 边界与路由

## 正触发

人身损害已发生，单独委托核验受诉法院连结点、级别或专属，或评估中该判断成为主成果。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要管辖异议书 | `提出人身案件管辖异议` |
| 只要诉讼时效表 | `评估人身损害诉讼时效` |
| 只要起诉包 | `提起人身损害一审` |
| 只要应诉 | `应对人身损害一审` |
| 工伤待遇管辖 | 劳动领域 |
| 医疗损害主轴 | 医疗医药领域 |
| 海事专属 | 海事领域 |
| 总体责任总图 | `评估人身侵权责任` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 工伤认定、劳动能力鉴定、工伤待遇 | 劳动领域 |
| 诊疗过错、病历、医疗损害鉴定 | 医疗医药领域 |
| 船舶、海上人身伤亡、海事保全 | 海事领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“这个案子该去哪个法院”正触发。“起诉期限过没过”走时效评估。“已经被起诉，要在十五日内提异议”走管辖异议原子。连结点和时效禁止合成一个截止日。
