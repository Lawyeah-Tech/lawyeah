# 评估反诉或抵销

## 任务目标

在明确、无利益冲突的本诉被告立场下，形成反诉与抵销评估包：评估闸、`CC#` 反请求（相对人限于本诉原告、牵连、程序时点）、`Set#` 抵销或已付款抗辩（相对人、种类、到期分列）、应诉管辖红旗、标注待核的草案要点。不自动生成反诉状终稿。不保证准许或受理。不选定法院。不写死唯一截止日。未知不写零。

`depends-on` 为空。只要答辩包终稿转 `应对人身损害一审`。只要管辖异议书转 `提出人身案件管辖异议`。打架防卫与互殴比例转 `评估打架伤害民事路径`。无本诉主动起诉转 `提起人身损害一审`。保险分账转 `保险公司应对直接索赔`／`评估道路交通事故责任与保险先行`。金额展开转 `测算人身损害赔偿`。二审反诉时点转介 `应对人身损害二审`，本窗仍评估准许风险，不保证二审一并审理。

## 工作边界

正触发：本诉被告拟评估互殴等独立反请求、已付款能否扣减，或能否抵销。用户要反诉状终稿、发送版、保证准许、选定某院、保险垫付当然抵销全部、还手即防卫必须反诉、辩论终结后或二审仍保证准许、未知写零、本诉抗辩当成反诉、对保险人当然提人身反诉，仍正触发：评估闸可关，对应格填 `现有依据不支持` 或字段停止，窗口不关，**不得改走负触发踢回 `应对人身损害一审`**（答辩窗已把反诉状终稿转来本窗），不得标反诉状终稿已形成。工伤劳动反申请与民事互殴反诉同时出现：本窗正触发，工伤段分流劳动，民事 `CC#` 可留。刑事程序中无刑事反诉：不定罪，民事反诉可留。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要一审答辩包、期限卡或无反请求的实体答辩终稿（转 `应对人身损害一审`）；
- 只要管辖异议书终稿（转 `提出人身案件管辖异议`）；
- 只要打架民事总路径、正当防卫或互殴比例终稿，而无反诉／抵销程序问题（转 `评估打架伤害民事路径`）；
- 无本诉、主动起诉（转 `提起人身损害一审`）；
- 只要后续治疗另诉包（转 `准备后续治疗费另诉`）；
- 只要保险分账或保险先行终稿（转 `保险公司应对直接索赔`／`评估道路交通事故责任与保险先行`）；
- 只要测算数字或唯一必得总额（转 `测算人身损害赔偿`）；
- 纯工伤劳动反申请且无民事互殴反诉（转劳动）；
- C 端只要大众准备包（只分流）；
- 未成争改合同（审查起草搁置）。

反诉状终稿、保证准许、选定某院、保险垫付当然抵销、还手必须反诉、辩论终结后保证准许、未知写零、同一笔重复抵销**不在负触发表**，窗口不关。双方秘密、虚构伤害、伪造付款、倒签收条**不在负触发表**，走整体停止。

## 建立工作坐标

确认：使用者与授权；本诉被告单方立场（不得同时代表本诉原被告争同一份反诉策略）；本诉原告、共同被告与保险人分列；本诉请求；程序时点（答辩期内／管辖异议未决／一审辩论终结后／二审）；己方损害与票据；已付款凭证来源与相对人；交强险垫付、救助基金、医保、第三人代付分列；不利本诉自认；法域。

口头「他也把我打伤了」「我垫过钱所以抵销」「保证准许」只登记 `S#`。微信已读不得起算答辩或异议期。用户坚持「必须反诉」「此致某院」「保险垫了当然全抵」不构成打开该格的授权。驾驶人自认不得写成保险人自认。

同时掌握双方秘密，或受害人与被告、保险人同时交材料争同一份反诉或抵销策略，或保险人与驾驶人争同一反诉策略：`整体停止`，不得以选边治愈，也不得改走负触发去出一方反诉状。提出虚构己方伤害、伪造或变造付款凭证、倒签收条或付款日、伪造伤情、要求从草稿删除不利本诉自认：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 本诉状、己方票据、付款凭证、监控分列；`R#` 应诉材料、异议裁定；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`CC#` 反请求；`Set#` 抵销或已付款抗辩；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。稿件状态只用 `草案`、`评估闸关闭`、`提交前待核`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。本任务默认 `草案`，不代提交。禁止「保证准许」「此致某院」「必须反诉」「人身损害金钱当然可抵销」。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：被告有权提起反诉；反诉当事人限于本诉当事人；与本诉基于相同法律关系、请求间有因果关系或基于相同事实的可合并审理；专属管辖或无关联则不予受理告知另诉；一审法庭辩论结束前提出；未提出管辖异议并应诉答辩或提出反诉的，视为受诉人民法院有管辖权，违反级别管辖和专属管辖除外；民法典第五百六十八条法定抵销与第五百六十九条合意抵销。合同编通则解释关于侵权人主张抵销人身权益损害赔偿债务不予支持的条文，运行时核验。技能正文条号不是 `L#`。噪声：已失效《侵权责任法》、已失效《合同法》第九十九条／第一百条、2017 年民诉旧条号、人身损害金钱当然可抵销、保险垫付当然抵销全部、保证反诉准许、选定某院、已读即期间起算。不可用则反诉受理条件、应诉管辖效力、抵销适状和期限字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变反诉期间、牵连、应诉管辖或抵销效果的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补已付款多为清偿抗辩、提出反诉可能成就应诉管辖、辩论终结后难再提、保险垫付不能当然冲销全部、还手非必须反诉、侵权人主张抵销人身损害债务通常不受支持的实务反例。
- `search_template` 只借反诉状栏目，不把范本当法定格式、已提交文本、发送版或指定唯一受诉法院。

工具不可用时继续 `CC#`／`Set#` 编目、本诉文书与付款相对人事实；准许效果、应诉管辖效力、抵销开闭和期限字段停止。不得凭记忆写成保证准许、选定法院、保险垫付当然抵销或辩论终结后仍可提交。

## 判断节点

执行顺序和停止条件以 [反诉抵销方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、评估闸与不关窗

工伤三段分流，民事反诉可留。双方秘密、虚构伤害、伪造付款第一次停。终稿、保证准许、选定某院、保险垫付当然抵销、还手必须反诉、辩论终结后保证准许不关窗。只要答辩终稿负触发。不得把终稿请求踢回答辩窗。

### 2. 定性：反诉、清偿抗辩、抵销

已付款在原告请求范围内优先标清偿抗辩，不是反诉，也不当然是抵销。互殴己方独立伤害才是反诉候选。不得为冲医疗费提返还垫付反诉以免做成应诉管辖。

### 3. 反请求 `CC#`

本诉被告对向本诉原告。对保险人当然提人身反诉该格不支持，不关窗。牵连待核。辩论终结后、二审不保证准许。异议未决则提交稿停止。

### 4. 抵销与已付 `Set#`

568 互负、种类品质相同、到期；通知到达生效，不得附条件期限。侵权人主张抵销人身损害债务该格通常不支持或待核。保险／基金／第三人代付相对人不同，不得当然写成被告对原告抵销。未知不写零。重复抵销该格不支持，不关窗。

### 5. 应诉管辖、风险与草案要点

提出反诉可能视为应诉。草案要点非终稿。不代提交。不保证准许。不选定法院。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；受害人与被告或保险人同时交材料；保险人与驾驶人争同一反诉策略；提出虚构己方伤害、伪造付款凭证、倒签收条、伪造伤情、要求删除不利本诉自认。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：反诉牵连、准许时点、应诉管辖效力、568/569 开闭未核验。评估闸未开则提交稿停止，窗口不关。用户要保证准许、选定某院、保险垫付当然抵销、还手必须反诉、辩论终结后仍保证准许、未知写零则该格停止，窗口不关。
- `目标停止`：主目标变为答辩终稿、管辖异议书、打架总路径、主动起诉状或保险分账终稿。要反诉状终稿、保证准许不在目标停止。

禁止指导虚构伤害、伪造付款或代提交。不给胜诉率。不选定法院。不代提交。不编唯一截止日。不把未知写成零。不定残。不保证准许或受理。不定罪。

严格按 [输出合同](references/output-contract.md) 交付。评估闸未打开时不得交付反诉状终稿或保证准许。节点 0 整案转出或整体停止时不得填满十节实体。边界见 [路由](references/routing.md)。
