# 边界与路由

## 正触发

本诉被告拟评估互殴等独立反请求、已付款能否扣减，或能否抵销。「他也把我打伤了，能不能反诉」正触发。「我垫了医药费要扣掉」正触发。用户要反诉状终稿、发送版、保证准许、选定某院、保险垫付当然抵销全部、还手即防卫必须反诉、辩论终结后或二审仍保证准许、未知写零、本诉抗辩当成反诉，仍正触发：评估闸可关，对应格停止，窗口不关，**不得踢回 `应对人身损害一审`**。工伤劳动反申请与民事互殴反诉同时出现，仍正触发：工伤段分流劳动，民事 `CC#` 可留。刑事无反诉时，民事反诉可留，不定罪。

双方秘密、虚构伤害、伪造付款、倒签收条的停止，优先于负触发。不得改走负触发去出一方反诉状。终稿、保证准许、选定某院、保险垫付当然抵销、还手必须反诉、辩论终结后保证准许、同一笔重复抵销不在下表。伪造倒签不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 一审答辩包、期限卡或无反请求的实体答辩终稿 | `应对人身损害一审` |
| 管辖异议书终稿 | `提出人身案件管辖异议` |
| 打架民事总路径、正当防卫或互殴比例终稿，而无反诉／抵销程序问题 | `评估打架伤害民事路径` |
| 无本诉、主动起诉 | `提起人身损害一审` |
| 后续治疗另诉包 | `准备后续治疗费另诉` |
| 保险分账或保险先行终稿 | `保险公司应对直接索赔`／`评估道路交通事故责任与保险先行` |
| 测算数字或唯一必得总额 | `测算人身损害赔偿` |
| 纯工伤劳动反申请且无民事互殴反诉 | 劳动领域 |
| C 端只要大众准备包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「要反诉状终稿」「保证准许」「此致某院」「保险垫了当然全抵」「还手必须反诉」「辩论完了也要一起判」不在本表，窗口不关。「补伤」「倒签收条」「两边材料都给你选边」不在本表，走整体停止。工伤夹带民事互殴反诉时，不得因「劳动反申请」整窗关闭。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 仅工伤劳动反申请且无民事互殴反诉 | 劳动领域 |
| 医疗损害鉴定终稿 | 医疗医药领域；原侵害互殴民事反诉可留 |
| 海事专门程序 | 海事领域 |
| 指导虚构伤害、伪造付款或倒签收条 | 整体停止 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。民事反诉可留。不定罪。

## 易混

「他也把我打伤了，能不能反诉；保证某区法院准许；交强险垫了当然全部抵销；还手就是防卫所以必须反诉；一审已经辩论完了也要保证一起判」正触发；评估闸可关；垫付行标清偿抗辩或待核，不是反诉；交强险垫付≠被告对原告当然抵销；还手必须反诉格不支持；辩论终结后保证准许格不支持；应诉管辖红旗；不代提交；不得踢回答辩窗。

「我只是否认责任」走答辩。「我已经垫了医药费要扣掉」正触发，定性为清偿抗辩或抵销，不是当然反诉。「还没被起诉，我要先告他」走一审。

「工伤单位要劳动反申请，顺带互殴反诉」正触发，民事 `CC#` 可留，不得整案转劳动。

「刑事里没有反诉，民事也别做了」正触发，民事反诉可留，不定罪。

「管辖异议还没提，先把反诉交上去」正触发；提交稿停止；应诉管辖必须红旗；窗口不关。

「两边材料都给你选边、伤做大一点、收条日期提前」整体停止，第一次提出即停，不得选边，无「坚持」门槛。同一笔已付款再主张抵销而无伪造：该格不支持，不关窗，不得整体停止。
