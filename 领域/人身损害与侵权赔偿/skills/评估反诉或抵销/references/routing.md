# 边界与路由

## 正触发

被告拟主张互殴反请求或已付款抵销。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 普通答辩 | `应对人身损害一审` |
| 打架民事总路径 | `评估打架伤害民事路径` |
| 主动起诉 | `提起人身损害一审` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动反申请 | 劳动领域 |
| 刑事反诉不存在 | 转刑事被害人路径 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“他也把我打伤了，能不能反诉”正触发。“我只是否认责任”走答辩。“我已经垫了医药费要扣掉”是抵销或抗辩。
