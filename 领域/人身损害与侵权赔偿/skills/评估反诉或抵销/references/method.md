# 反诉抵销方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。稿件状态只用 `草案`、`评估闸关闭`、`提交前待核`、`停止`。禁止胜诉率、必然责任比例、唯一必得总额、唯一截止日、选定法院、自行宣布伤残等级、保证准许、保证受理、代提交。未知金额不写零。本任务不代提交。不定罪。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、已失效《合同法》第九十九条／第一百条、2017 年民事诉讼法旧条号、把人身损害金钱写成当然可抵销、把保险垫付写成当然抵销全部、把保证准许或选定某院写成可执行、把已读写成期间起算时记为噪声，不得写入 `L#`。禁止指导虚构伤害、伪造付款、倒签收条或作伪证。

`CC#` 固定列：`编号｜反诉人（须本诉被告）｜反诉相对人（须本诉原告）｜保险人是否被列为反诉被告（默认不打开）｜请求项目与金额状态（未知不写零）｜牵连（同一法律关系／法律上牵连／不足／待核）｜分型（互殴独立伤害候选／返还垫付／其他）｜程序时点（答辩期内／异议未决／辩论终结后／二审）｜受诉法院可管（是／否／待核）｜另交费红旗｜应诉管辖红旗｜准许风险（可不准许另诉／二审调解或另诉／双方同意一并除外／待核）｜本诉撤回后反诉是否独立（待核）｜判断三值｜待核｜来源回链`。一行一反请求。禁止合成「他也受伤所以必须反诉」。对保险人当然提人身反诉该行不打开可提交。返还垫付默认不打开反诉，转 `Set#` 清偿抗辩。

`Set#` 固定列：`编号｜形态（诉讼中主张／诉讼外通知／清偿抗辩）｜主动债权｜被动债权｜相对人是否同一（被告↔原告／保险人／交强险垫付／救助基金／医保／第三人代付）｜种类品质是否相同｜是否到期且金额确定｜路径（568 法定／569 合意／清偿抗辩不按抵销开闸）｜通知是否到达（到达生效；不得附条件期限）｜性质或约定或法定不得抵销｜重复使用同一凭证（该格不支持／未显示）｜判断三值｜待核｜来源回链`。一行一笔。禁止把未确定人身金当然抵销已确定医疗费。禁止把保险／基金／第三人代付当然写成被告对原告抵销。

口头「垫过钱所以抵销」「保证一起判」只进 `S#`，不得升格 `R#` 已准许或 `Set#` 已生效。

## 节点 0　分流、立场、评估闸与不关窗

整案转出或闸关闭只交付第 1、2、10 节或标注停止的 `CC#`／`Set#`，不得交付反诉状终稿，不得标保证准许。闸部分打开时：仅对可回链的独立反请求或已付款抗辩给出草案要点，其余行停止或不打开。

| 信号 | 处理 |
| --- | --- |
| 只要一审答辩包、期限卡或无反请求的实体答辩终稿 | 负触发 `应对人身损害一审` |
| 只要管辖异议书终稿 | 负触发 `提出人身案件管辖异议` |
| 只要打架民事总路径、正当防卫或互殴比例终稿，而无反诉／抵销程序问题 | 负触发 `评估打架伤害民事路径` |
| 无本诉、主动起诉 | 负触发 `提起人身损害一审` |
| 只要后续治疗另诉包 | 负触发 `准备后续治疗费另诉` |
| 只要保险分账或保险先行终稿 | 负触发 `保险公司应对直接索赔`／`评估道路交通事故责任与保险先行` |
| 只要测算数字或唯一必得总额 | 负触发 `测算人身损害赔偿` |
| 纯工伤劳动反申请且无民事互殴反诉 | 整案转劳动；夹带民事互殴反诉则本窗正触发，工伤段分流，`CC#` 可留并转介 `评估工伤与第三人侵权竞合` |
| 刑事控告或定罪出罪 | 转刑事；民事反诉可留，不定罪，不得整案转刑事被害人路径顶替 |
| 诊疗过错医疗损害主轴 | 转医疗；原侵害互殴民事反诉可留 |
| 海事专门程序 | 转海事 |
| 未成争只要改合同 | 审查起草本窗搁置 |

评估闸打开（可出 `CC#`／`Set#` 与草案要点，仍不代提交、不保证准许／受理）须同时满足：单方无冲突本诉被告立场与授权；本诉表面存在；主成果是反诉或抵销条件评估，不是答辩终稿、不是管辖异议书、不是打架总路径、不是主动起诉状、不是保险分账终稿；至少一行可回链为对**本诉原告**的独立反请求，或相对人同一的已付款清偿抗辩／抵销候选；拟交付不含保证准许、发送版、代提交、选定某院、反诉状终稿、辩论终结后仍可提交的保证。

闸关闭（仍正触发）：要终稿／发送版／代提交；保证准许或保证受理；选定某院或预填此致某院；对保险人当然提人身反诉；返还垫付必须反诉；管辖异议未决仍要可提交反诉；一审辩论终结后或二审仍保证准许；保险垫付当然抵销全部；还手即防卫必须反诉；未确定人身金当然抵销已确定医疗费；人身损害金钱当然可抵销；未知写零。闸未开则仍只交 1、2、10 节或停止的表。

「要反诉状终稿」「保证准许」「选定某院」「保险垫付当然抵销全部」「还手即防卫必须反诉」「辩论终结后仍保证准许」**不关窗**，也**不得改走负触发踢回 `应对人身损害一审`**。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或受害人与被告、保险人同时交材料争同一份反诉或抵销策略，或保险人与驾驶人争同一反诉策略且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出虚构己方伤害、伪造或变造付款凭证、倒签收条或付款日、伪造伤情、要求从草稿删除不利本诉自认，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　定性：反诉、清偿抗辩、抵销

三概念必须分列，禁止合成「有钱或有伤就是反诉」。

| 形态 | 本窗 | 禁止写法 |
| --- | --- | --- |
| 己方亦因同一互殴事实受独立伤害，要对**本诉原告**主张赔偿 | 反诉候选，进 `CC#`；牵连待核 | 必须反诉；还手即防卫所以必须反诉；对保险人当然列反诉被告 |
| 已向原告支付医疗费、赔偿款，请求在本诉请求内扣减 | **清偿抗辩**优先；进 `Set#` 路径标清偿抗辩 | 为冲医疗费提返还垫付反诉；已付款＝抵销＝反诉 |
| 主张互负确定金钱债务按 568/569 消灭 | 抵销候选，进 `Set#`；须核相对人、种类、到期、性质不得抵销 | 未确定人身金当然抵销已确定医疗费；侵权人主张抵销人身损害债务当然成立 |
| 否认本诉请求、过错或金额，无独立请求 | 答辩，负触发或只留接口 | 把本诉抗辩写成反诉 |

检索锚点：被告可以承认或者反驳诉讼请求，有权提起反诉。条号不是 `L#`。反诉是独立之诉；反驳不是独立之诉。不得为冲医疗费而提起返还垫付反诉，以免单独成就应诉管辖。

## 节点 2　反请求 `CC#`

检索锚点：反诉的当事人应当限于本诉的当事人的范围。反诉与本诉的诉讼请求基于相同法律关系、诉讼请求之间具有因果关系，或者反诉与本诉的诉讼请求基于相同事实的，可以合并审理；反诉应由其他人民法院专属管辖，或者与本诉无关联的，裁定不予受理，告知另行起诉。在案件受理后、法庭辩论结束前提出的，可以合并审理的，人民法院应当合并审理。条号运行时核验，不是 `L#`。

一审法庭辩论终结后提出反诉：法院**可以不准许**并告知另行起诉，禁止保证准许。二审提出反诉：可以根据当事人自愿原则调解；调解不成告知另行起诉；双方同意由二审一并审理的除外，禁止保证二审准许或默认一并审理。本诉撤诉后反诉是否继续审理待核，禁止写成当然消灭或当然继续。反诉可能另交费、可能另受管辖约束。

对保险人当然提人身损害赔偿反诉当作本诉反诉：该格 `现有依据不支持` 或待核，窗口不关；保险分账转介保险窗。互殴伤害可为牵连**候选**，不是闭集。还手不是当然防卫，不得升格必须反诉；防卫接口转 `评估打架伤害民事路径`。先动手不是全赔。互殴不是各打五十。

管辖异议期间或异议未决：提出反诉可能视为受诉人民法院有管辖权（违反级别管辖和专属管辖除外）。检索锚点：现行民事诉讼法关于未提出管辖异议并应诉答辩**或者提出反诉**视为有管辖权的条款（2023 修正增加「或者提出反诉」，条号须核验）。异议未决则反诉**提交稿**停止，评估表可留并打应诉管辖红旗，窗口不关。异议书终稿转 `提出人身案件管辖异议`。期限截止日本窗只红旗，终稿转 `应对人身损害一审`。已读不得起算。

## 节点 3　抵销与已付 `Set#`

检索锚点：民法典第五百六十八条。当事人互负债务，该债务的标的物种类、品质相同的，任何一方可以将自己的债务与对方的到期债务抵销；但是，根据债务性质、按照当事人约定或者依照法律规定不得抵销的除外。当事人主张抵销的，应当通知对方。通知自到达对方时生效。抵销不得附条件或者附期限。第五百六十九条：种类品质不相同的，经协商一致也可以抵销。条号不是 `L#`。已失效《合同法》第九十九条、第一百条不得写入 `L#`。

合同编通则解释关于因侵害自然人人身权益，或者故意、重大过失侵害他人财产权益产生的损害赔偿债务，**侵权人主张抵销的，人民法院不予支持**的条文，运行时核验，条号不是 `L#`。侵权人主张抵销原告人身损害债务：该格通常 `现有依据不支持` 或待核，窗口不关。被侵权人主动抵销另核。禁止把「人身损害金钱赔偿一般可抵销」写成闭集。未确定的精神损害或未核定人身金，禁止当然抵销已确定医疗费。

已付款在原告请求范围内优先按**清偿抗辩（债务消灭）**，不是抵销，更不是反诉。交强险垫付、道路救助基金、医保已付、保险人赔付、第三人代付：相对人不同，不得当然写成被告对原告的抵销；分列待核，转介 `申请道路救助基金或垫付`／保险窗。诉讼中主张与诉讼外通知分列。诉讼外未通知不得主张 568 已生效。

同一笔付款凭证重复抵销：该格 `现有依据不支持`，**窗口不关**，不是整体停止（伪造除外）。未知不写零。过失相抵不是债的抵销，转 `评估过错与原因力`／打架窗，禁止拿一方殴打抵销另一方殴打。

## 节点 4　风险、草案要点与转介

应诉管辖风险必须在草案要点前明示。拟提管辖异议或异议未决：反诉提交稿停止或标明不得在异议裁定前提交。草稿状态默认 `草案`。不利本诉自认、已付款、重复报销必须入表，删除视为隐匿，该部分停止。不代提交。不保证准许或受理。不选定法院，不得预填此致某院。闸未开不得标反诉状终稿 `已形成`。

| 接口 | 本窗 | 转介 |
| --- | --- | --- |
| 答辩期限卡、实体答辩终稿 | 不写 | `应对人身损害一审` |
| 管辖异议书 | 只红旗 | `提出人身案件管辖异议` |
| 正当防卫、互殴比例 | 只接口 | `评估打架伤害民事路径` |
| 分项金额 | 不得已核实未知 | `测算人身损害赔偿` |
| 保险分账、垫付追偿 | 只红旗 | `保险公司应对直接索赔`／`评估道路交通事故责任与保险先行` |
| 救助基金／抢救垫付 | 相对人分列 | `申请道路救助基金或垫付` |
| 无本诉主动起诉 | 负触发 | `提起人身损害一审` |
| 二审程序中的答辩 | 准许风险可留 | `应对人身损害二审` |
| 工伤待遇与第三人 | 工伤段分流；民事 `CC#` 可留 | `评估工伤与第三人侵权竞合` |
| 刑附民 | 不定罪；民事反诉可留 | `评估刑附民与另行起诉` |
