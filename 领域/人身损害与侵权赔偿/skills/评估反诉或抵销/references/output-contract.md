# 输出合同

按触发结果选择交付形状。评估闸未打开不得交付反诉状终稿或保证准许。禁止选定唯一法院或预填「此致某院」。禁止已读当期间起算。禁止把已付款写成反诉。禁止把保险垫付、救助基金、医保或第三人代付写成被告对原告当然抵销。禁止侵权人主张抵销人身损害债务写成当然成立。禁止未确定人身金抵销已确定医疗费。禁止还手即防卫必须反诉。禁止辩论终结后或二审保证准许。禁止发送版、代提交。禁止胜诉率。禁止选边治愈。未知不写零。不定残。不定罪。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 评估闸关闭或节点 0 整案转出 | 第 1、2、10 节：关闭理由、程序时点和最小补证。可附停止的 `CC#`／`Set#`。禁止反诉状终稿、保证准许、保证受理、唯一截止日、选定某院。对民事反诉可留时不得因工伤或刑事整案转出 |

| 用户要终稿、保证准许、选定某院、保险垫付当然抵销全部、还手必须反诉、辩论终结后仍保证准许、未知写零、同一笔重复抵销（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；闸未开则仍只交 1、2、10；不得改走负触发踢回答辩窗；不得标反诉状终稿 `已形成` |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入反诉状终稿已形成。双方秘密未解不得进入「部分形成」。每个 `CC#`／`Set#` 必须带来源和三值判断。`L#` 不得直接抄技能内条号。人身损害金钱当然可抵销、保证准许若返回则记噪声。稿件状态默认 `草案`。

## 1. 触发、单方立场、授权与成果状态

评估闸开、部分开或关。程序时点必须标明。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。稿件默认 `草案`。不代提交。不保证准许或受理。

## 2. 来源登记与 MCP 调用表

`S/D/R/L/I/G/CC/Set/V`。口头垫付、已读只登记 `S#`／`V#`。MCP 未调用也留一行。噪声命中须登记。不利本诉自认必须入表。

## 3. 定性三分型

反诉／清偿抗辩／抵销分列。已付款优先清偿抗辩。本诉抗辩不是反诉。不得为冲医疗费提返还垫付反诉。

## 4. 反请求 `CC#`

本诉被告对向本诉原告。对保险人当然提人身反诉该格不支持。牵连、程序时点、应诉管辖红旗、准许风险分列。辩论终结后、二审不保证准许。异议未决提交稿停止。

## 5. 抵销与已付 `Set#`

相对人、种类、到期、568/569 或清偿抗辩路径分列。侵权人主张抵销人身损害债务该格通常不支持或待核。保险／基金／代付不得当然写成对原告抵销。重复抵销该格不支持，不关窗。未知不写零。

## 6. 应诉管辖与程序风险

提出反诉可能视为应诉。管辖异议须先处理。另交费、管辖约束红旗。本诉撤诉后反诉独立性待核。期限只红旗，不编唯一截止日。

## 7. 草案要点

当事人地位互换、请求、牵连事实、证据。非终稿。不利事实不得删除。闸未开则本节停止。不代提交。不预填此致某院。

## 8. 打架、保险与邻接分流

还手不是当然防卫，不得升格必须反诉。互殴不是各打五十。保险分账、垫付追偿只标接口。工伤段分流，民事 `CC#` 可留。不定罪。

## 9. 下一步与转介

转介答辩窗、管辖异议、打架路径、测算、保险窗、二审应对、工伤竞合只点名。不写成发送版指令。不代提交。不保证立案或准许。

## 10. 缺口、停止项与提示

须列对方最强解释：已付款必须反诉返还、交强险垫了当然全部抵销、人身损害金钱一般可抵销、不确定精神损害把医疗费抵掉、还手就是防卫所以必须反诉、保证某区法院准许、一审辩论完了也必须一起判、二审当然一并审理、对保险公司一并反诉人身损害、管辖异议还没提先把反诉交上去、同一笔收条再抵一次、未知先写零、两边材料都给你选边、伤做大一点、收条日期提前。

本成果不是答辩终稿、不是管辖异议书、不是打架总路径、不是主动起诉状、不是保险分账、不是反诉状终稿、不是发送版、不保证准许或受理、不是唯一截止日、不是选定法院。不代提交。
