# 起草人身损害和解协议

## 任务目标

在明确、无利益冲突的单方立场下，于合意闸打开后形成不代签署的人身损害和解协议草稿包：合意闸、`Agr#` 分项与付款、`W#` 弃权边界、后续治疗保留、单独和解无强制执行力明示。讨论稿不等于可签终稿。口头「差不多了」、微信「行／已读」不是已合意。保险人限额内付款不当然消灭对侵权人其余请求。未知伤残、未知手术、后续治疗默认保留；覆盖未知损害的概括弃权不得因用户书面明示风险而写入可签主文。司法确认、诉讼调解书、公证赋强另项。保险人印好的了结或权益转让文本审查另项。不定残。不输出唯一必得总额。未知金额不写零。

`depends-on` 为空。只要让步档和底线转 `谈判人身损害和解`。保险了结文本转 `审查保险一次性了结弃权`。司法确认或赋强转 `办理人身和解执行力补强`。测算终稿转 `测算人身损害赔偿`。

## 工作边界

正触发：用户要和解协议正文或草稿。自称谈拢但分项金额、付款人、弃权项目／期间／相对人、后续治疗是否保留四项未闭合，或要写入「永不追究一切未知伤残」、保证有强制执行力、协议等同判决、未稳定却写死伤残确定额，仍正触发：合意闸可关，对应格填 `现有依据不支持` 或停止，只出讨论稿或第 1、2、10 节，窗口不关，不得踢回谈判，不得标可签终稿已形成。工伤待遇与对第三人民事和解同时出现：本窗正触发，工伤段分流劳动，对第三人的 `Agr#` 可留。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是让步档、底线或未闭合报价方案（转 `谈判人身损害和解`）；
- 主成果是审查保险人一次性了结或权益转让文本（转 `审查保险一次性了结弃权`）；
- 主成果是司法确认、诉讼调解书或公证赋强手续（转 `办理人身和解执行力补强`）；
- 主成果是比较法院／人民调解方案效力（转 `评估人身调解方案与效力`）；
- 只要测算终稿或唯一必得总额（转 `测算人身损害赔偿`）；
- 只要先予执行申请（转 `申请先予执行医疗费`）；
- 执行程序中的分期或以物抵债（转 `准备人身执行和解`）；
- 只要起诉状或答辩（转 `提起人身损害一审`／`应对人身损害一审`）；
- 纯工伤待遇一次性了结且无第三人民事和解（转劳动）；
- C 端只要大众准备包（只分流）；
- 未成争改合同（审查起草搁置）。

概括弃权未知伤残、保证执行力、口头已成交**不在负触发表**，窗口不关。倒签、骗保、掩盖犯罪、双方秘密、要求产出含「永不追究一切未知损害」的可签终稿**不在负触发表**，走整体停止。

## 建立工作坐标

确认：使用者与授权；单方立场；已报价与书面确认；分项金额；付款人（交强险／商业三者／侵权人／用人者）；弃权项目、期间、相对人；后续治疗是否保留；治疗是否相对稳定、鉴定状态；权利人适格（法定代理人、近亲属逐名）；已收款与基金已付；法域。

口头报价、微信「行／已读／差不多了」只登记 `V#`／`S#`，不得升格为已合意。用户口述唯一总额或指定十级，不构成把未知写成确定额或概括弃权的授权。

同时掌握双方秘密，或受害人与侵权人、保险人同时交材料争同一份可签稿：`整体停止`，不得以选边治愈，也不得改走负触发去出一方协议。受害人已开口且委托范围就是协议草稿、且未掌握对方秘密时，可推定单方立场。只要同时掌握双方秘密，无例外整体停止。提出倒签、指导骗保、隐瞒伤情、用和解掩盖犯罪、刑事报案逼签民事弃权、要求把覆盖未知伤残或「永不追究一切」写入可签终稿：第一次提出即整体停止，不以「坚持」或「书面明示风险」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 谈判记录、报价；`A#`／`Agr#` 已一致条款；`C#` 保单或了结文本；`R#` 立案或调解组织；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`W#` 弃权；`V#` 协议版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。稿件状态只用 `讨论稿`、`合意闸关闭`、`待签待核`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。不准许率。本任务默认 `讨论稿`，不代签署、不代发送。可签终稿仅在合意闸打开且无停止的 `W#` 时使用 `待签待核`，不得标已签字生效。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民事法律行为成立与意思表示真实；欺诈、胁迫、重大误解、显失公平可撤销接口；造成对方人身损害的免责条款无效接口；诉讼时效中断须分相对人；私下和解仅合同拘束力，不能直接强制执行；司法确认须依法设立的调解组织主持且双方共同申请。技能正文条号不是 `L#`。噪声：已失效《侵权责任法》、已失效《合同法》、口头差不多了即已成立、概括放弃未知伤残当然有效、保险人付款消灭对侵权人全部请求、协议等同判决、私下微信和解可司法确认、唯一截止日、选定法院、代签署。不可用则弃权效力、执行力、时效、可撤销字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变弃权范围、执行力或可撤销结论的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补未稳定概括弃权、私下和解不能强制执行、司法确认不受理、保险了结与侵权和解混淆的实务反例。
- `search_template` 只借和解协议栏目，不把范本当法定格式、已签署文本、发送版或保证有执行力，不得把范本概括弃权带进主文。

工具不可用时继续 `Agr#`／`W#` 编目和讨论稿栏目；弃权效力、执行力、时效、可撤销字段停止。不得凭记忆写成协议等同判决或概括弃权有效。

## 判断节点

执行顺序和停止条件以 [和解协议起草方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、合意闸与不关窗

工伤三段分流，对第三人民事协议可留。双方秘密或倒签骗保第一次停。自称谈拢未闭合、概括弃权、保证执行力不关窗。只要谈判方案负触发。

### 2. 当事人与付款 `Agr#`

侵权人、保险人、权利人分列。谁付哪一笔必须可见。未知不写零。禁止一行打包总额。

### 3. 弃权边界 `W#`

列明放弃的项目、期间、相对人。未知伤残、后续手术默认保留。概括弃权停止，用户明示不能治愈。未成年人、死亡近亲属不得代弃权。

### 4. 履行与解除

不写「签了就视为已履行」。不代签署。可撤销只作接口，不鼓励无理由反悔。

### 5. 执行力与草稿

单独和解无强制执行力必须明示。司法确认另项。讨论稿不等于待签。不保证法院确认。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；隐瞒已收款以提高要价；倒签落款或出险日；指导骗保、伪造伤情、隐瞒伤情；以和解掩盖犯罪；用刑事报案逼签民事弃权；要求把覆盖未知伤残、未知手术或「永不追究一切」写入可签终稿。整体停止优先于负触发。不以「坚持」或「书面明示风险」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：弃权效力、履行效力、执行力条件、司法确认期限、时效中断未核验。合意闸未开则可签终稿停止，窗口不关。用户要概括弃权、保证执行力或协议等同判决则该格停止，窗口不关。
- `目标停止`：主目标变为谈判方案、保险弃权审查终稿、司法确认手续、测算终稿、起诉或答辩。概括弃权、保证执行力不在目标停止。

禁止指导伪造伤情、倒签或骗保。不给胜诉率。不选定法院。不代签署。不编唯一截止日。不把未知写成零。不定残。
