# 边界与路由

## 正触发

用户要和解协议正文或草稿。自称谈拢但分项、付款人、弃权或后续治疗保留未闭合，或要写入永不追究未知伤残、保证有执行力、协议等同判决，仍正触发：合意闸可关，对应格停止，窗口不关，不得踢回谈判。工伤待遇与对第三人民事和解同时出现，仍正触发：工伤段分流劳动，对第三人 `Agr#` 可留。

双方秘密、倒签、骗保、掩盖犯罪、要求产出含未知损害概括弃权可签终稿的停止，优先于负触发。不得改走负触发去出一方协议。概括弃权、保证执行力不在下表。倒签骗保不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 让步档、底线或未闭合报价方案 | `谈判人身损害和解` |
| 保险人了结或权益转让文本审查 | `审查保险一次性了结弃权` |
| 司法确认、诉讼调解书或公证赋强手续 | `办理人身和解执行力补强` |
| 法院／人民调解方案效力比较 | `评估人身调解方案与效力` |
| 保险先行还是诉讼调解的路径选择 | `选择诉讼调解或保险先行` |
| 分项测算终稿 | `测算人身损害赔偿` |
| 先予执行申请 | `申请先予执行医疗费` |
| 执行中和解 | `准备人身执行和解` |
| 起诉状 | `提起人身损害一审` |
| 答辩 | `应对人身损害一审` |
| 纯工伤待遇了结且无第三人民事和解 | 劳动领域 |
| C 端只要大众准备包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「按出险日倒签」「指导隐瞒伤情骗保」「用协议把案子压下去」不在本表，走整体停止。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 仅工伤待遇一次性了结且无第三人民事和解 | 劳动领域 |
| 诊疗过错或医疗鉴定终稿 | 医疗医药领域；对医疗机构的民事和解可留 |
| 海事专门和解 | 海事领域 |
| 指导骗保或以和解掩盖犯罪 | 整体停止；刑事只打红旗，不得用来出协议 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。对第三人民事和解可留。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 条件未谈只要档位底线 | `谈判人身损害和解` |
| 保险人印好了结书 | `审查保险一次性了结弃权` |
| 需要强制执行力 | `办理人身和解执行力补强` |
| 伤残未鉴定且鉴定闸已打开 | `准备伤残鉴定材料`；闸关闭禁止转介启动，本窗伤残档保留另行主张 |
| 未发生后续治疗 | `评估后续治疗费另行主张` |
| 死亡近亲属争议 | `评估死亡赔偿权利人与分配` |
| 未成年人代理 | `评估未成年或无行为能力受害人代理` |
| 工作中第三人 | `评估工伤与第三人侵权竞合` |
| 时效 | `评估人身损害诉讼时效` |
| 交强险分账 | `评估道路交通事故责任与保险先行` |
| 金额接口 | `测算人身损害赔偿` |
| 刑事在侦或报案施压 | `分流刑民交叉` |

## 易混

「数字谈好了，写协议」正触发。「还在谈底线」走谈判。「保险公司拿来一份了结书」走弃权审查。「八万差不多了，一次性了结，残了也不再赔，保证能强制执行」仍正触发；合意闸可关；概括弃权、保证执行力格停止；只出讨论稿，后续治疗默认保留。「工伤也要认，和肇事司机的民事和解要落纸」正触发，民事草稿可留，工伤段分流。「两边材料都给你，选边出可签协议，出险日改到保单期内」整体停止。
