# 输出合同

按触发结果选择交付形状。合意闸未打开不得交付可签终稿。禁止把口头报价写成协议已成立。禁止把未知伤残、未知手术或「永不追究一切」写入可签主文。禁止保证强制执行力或协议等同判决。禁止选定唯一法院。禁止自行定残。禁止未知金额写零。禁止代签署、发送版。禁止选边治愈。禁止倒签、骗保或掩盖犯罪。不定残。不保证法院确认。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 合意闸关闭或节点 0 整案转出 | 第 1、2、10 节，可附标注缺口的讨论稿。禁止可签终稿、概括弃权主文、保证执行力。对第三人民事协议可留时不得因工伤整案转出 |
| 整体停止 | 第 1、10 节。禁止 `Agr#` 可签主文、弃权文本、付款安排、选边、倒签方法。双方秘密、倒签、骗保、掩盖犯罪、要求产出含未知损害概括弃权的可签终稿第一次即停，优先于负触发；无选边治愈，无「坚持」或「明示风险」门槛 |
| 用户要概括弃权、保证执行力、口头已成交或协议等同判决（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或停止；闸未开则仍只交讨论稿或 1、2、10；不得改走负触发关窗；成果不得标可签终稿 `已形成` |
| 正触发且闸开（可部分开） | 下列十节表头均出现；弃权效力、执行力、时效未核验的单元格填 `依据不足，无法形成结论` 或 `待核`；分项分列；禁止为填满而写入概括弃权、等同判决或预填已签署 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入可签终稿已形成。双方秘密未解不得进入「部分形成」。每个 `Agr#`／`W#` 必须带来源和状态。`L#` 不得直接抄技能内条号。口头已成立、概括弃权当然有效、协议等同判决若返回则记噪声。稿件状态默认 `讨论稿`。

## 1. 触发、单方立场、授权与成果状态

合意闸开、部分开或关。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。稿件默认 `讨论稿`。不代签署。

## 2. 来源登记与 MCP 调用表

`S/D/A/Agr/C/R/L/I/G/W/V`。口头报价、微信已读只登记 `S#`／`V#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 合意闸与已一致／未一致清单

四项分列。缺一不得可签。不得擅补弃权。口头差不多了不是已合意。

## 4. 当事人与付款 `Agr#`

分笔。保险人付款默认不消灭对侵权人余额。未知不写零。已付扣减可见。

## 5. 弃权边界 `W#`

未知伤残、后续治疗默认保留。概括弃权停止，明示不能治愈。近亲属、未成年人不得代弃权。

## 6. 协议草稿

讨论稿或待签待核，状态必须标明。不得把讨论稿标成可签终稿。不利事实不删除。

## 7. 执行力提示

单独和解无强制执行力必须明示。司法确认、诉讼调解书、公证赋强只点转介。私下和解不能司法确认。不保证确认。

## 8. 未成年人或死亡案件特别提示

法定代理人签署。一人不得代全体近亲属弃权。缺授权则该 `W#` 停止。

## 9. 履行、可撤销接口与下一步

不写签了即已履行。可撤销只作接口。转介谈判、保险审查、执行力补强、测算、鉴定只点名。不选定法院。不代签署。

## 10. 缺口、停止项与提示

须列对方最强解释：口头差不多了就是已签、永不追究未知伤残当然有效、保险先付消灭对司机全部请求、本协议可直接强制执行、私下签完再补司法确认、一人签字代表全体近亲属、未稳定也可以一次性了结、签了就视为已履行、选边即可出稿、倒签到出险日、后续费先写零。

本成果不是已签字协议、不是判决、不是保险了结审查、不是司法确认、不保证执行力、不是唯一截止日。不代签署。
