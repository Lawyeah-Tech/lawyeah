# 和解协议起草方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。稿件状态只用 `讨论稿`、`合意闸关闭`、`待签待核`、`停止`。禁止胜诉率、必然成交、唯一必得总额、选定法院、自行宣布伤残等级。未知金额不写零。本任务不代签署、不代发送。讨论稿不等于可签终稿。口头报价不得写成已合意。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、已失效《合同法》、把口头差不多了写成已成立、把概括放弃未知伤残写成当然有效、把保险人付款写成消灭对侵权人全部请求、把协议写成等同判决、把私下微信和解写成可司法确认时记为噪声，不得写入 `L#`。禁止指导倒签、骗保或以和解掩盖犯罪。

`Agr#` 固定列：`编号｜分项（医疗／误工／护理／伤残或死亡／精神损害／后续治疗／已付扣减；伤残未鉴定填不打开或保留另行主张）｜金额状态（已合意确定额／未知不写零／保留另行主张）｜付款人（交强险／商业三者／侵权人／用人者分列）｜付款时间或分期｜权利人｜相对人｜后续治疗是否保留｜鉴定或治疗稳定闸｜状态（已一致／未闭合／闸关／停止）｜来源回链`。禁止一行打包总额。

`W#` 固定列：`编号｜相对人｜项目｜期间｜已知伤情｜治疗稳定｜鉴定状态｜授权（本人／法定代理人／近亲属逐名）｜是否覆盖未知伤残或未知手术（默认否；覆盖则停止）｜保险人付款是否消灭其余请求（默认否）｜状态（可写入主文／默认保留／停止）｜来源回链`。一行一相对人×一项目×一期间。

口头报价、微信「行／已读／差不多了」只进 `V#`／`S#`，不得升格 `Agr#`／`W#`。

## 节点 0　分流、立场、合意闸与不关窗

整案转出或闸关闭只交付第 1、2、10 节或标注缺口的讨论稿，不得交付可签终稿，不得标 `待签待核` 已形成。闸部分打开时：仅对已闭合分项给出草案，伤残未鉴定行、概括弃权行停止或保留。

| 信号 | 处理 |
| --- | --- |
| 主成果是让步档、底线或未闭合报价方案 | 负触发 `谈判人身损害和解` |
| 主成果是保险人了结或权益转让文本审查 | 负触发 `审查保险一次性了结弃权`；本窗不改写了结书 |
| 主成果是司法确认、诉讼调解书或公证赋强手续 | 负触发 `办理人身和解执行力补强` |
| 主成果是调解方案效力比较 | 负触发 `评估人身调解方案与效力` |
| 只要测算终稿 | 负触发 `测算人身损害赔偿` |
| 只要先予执行申请 | 负触发 `申请先予执行医疗费` |
| 执行中分期或以物抵债 | 负触发 `准备人身执行和解` |
| 只要起诉状或答辩 | 负触发对应一审原子 |
| 纯工伤待遇一次性了结且无第三人民事和解 | 整案转劳动；夹带对第三人民事和解则本窗正触发，工伤段分流，`Agr#` 可留并转介 `评估工伤与第三人侵权竞合` |
| 诊疗过错或医疗鉴定终稿 | 转医疗；对医疗机构的民事和解可留 |
| 海事专门和解 | 转海事 |
| 未成争只要改合同 | 审查起草本窗搁置 |

合意闸打开（可签档 `待签待核`，须同时满足）：单方无冲突立场与授权；主成果是协议草稿；分项金额闭合；付款人分列闭合；弃权项目／期间／相对人具体；后续治疗是否保留已明示。口头「差不多了」不得打开可签档。

闸关闭（仍正触发）：自称谈拢但四项缺一；要写入覆盖未知伤残、未知手术或「永不追究一切」；要保证有强制执行力或协议等同判决；未稳定或未鉴定却要写死伤残确定额。「保证有执行力」「一次性了结永不追究」本身不得开闸写成可签终稿。

「概括弃权」「保证执行力」「口头已成交」「协议等同判决」**不关窗**。闸未开则仍只交讨论稿或 1、2、10 节。

鉴定闸（与谈判、伤残鉴定材料同一信号）：急救未结束、骨折未固定、内固定未取、计划内二次手术未做、烧伤未拆痂、伤残未鉴定 → 伤残赔偿金、护理依赖、后续治疗相关 `W#` 只能保留另行主张，禁止写进可签终稿，禁止「先签了结再评残」无风险路径。鉴定闸关闭不关窗。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或受害人与侵权人、保险人同时交材料争同一份可签稿且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出倒签、指导骗保、隐瞒伤情、伪造票据、以和解掩盖犯罪、刑事逼签、要求把覆盖未知伤残或「永不追究一切」写入可签终稿，then 整体停止；第一次提出即停，不以「坚持」或「书面明示风险」为门槛。

## 节点 1　当事人与付款

权利人、侵权人、用人者、交强险保险人、商业三者保险人分列。谁付哪一笔必须可见。保险人限额内付款默认不消灭对侵权人、用人者及其他义务人的余额请求，除非对应 `W#` 项目、期间、相对人具体且鉴定闸已开。

已收款、医保、工伤基金、垫付必须入账扣减。隐瞒已收款以提高要价：整体停止。未知金额不写零。测算数字只作接口，本窗不定残、不输出唯一必得总额。

分期须写明时间、凭证；违约恢复或加速到期效果待核。不写「签了就视为已履行」。

未成年人须法定代理人签署，不得由侵权人一方的监护人单方放弃。死亡案件近亲属独立请求须逐名授权，一人不得代全体弃权；漏列转 `评估死亡赔偿权利人与分配`，该 `W#` 停止。

---

## 节点 2　弃权边界

只把已一致且允许写入的条款写入主文。未一致项保持空白并列为缺口，不得擅补对用户不利的概括弃权。

未知伤残、未知二次手术、未知护理依赖、未知后续治疗、近亲属独立请求、「永不追究一切人身损害」：该 `W#` 状态只能是 `停止` 或 `默认保留`。用户书面明示风险 **不能治愈**。要求产出含上述概括弃权的可签终稿：整体停止。

要对某相对人放弃已知项目：必须项目、期间、已知伤情、相对人具体，且治疗相对稳定、该项目已可确定。否则该弃权停止。

造成对方人身损害的免责条款无效接口、格式条款接口：运行时核验，未核验则效力字段停止，不得写成「自愿放弃一切」当然有效。

---

## 节点 3　履行与解除

付款凭证、票据移交、保险理赔配合分列。不代签署、不代发送、不编已签字生效文本。

撤销、重大误解、欺诈、胁迫、显失公平只作提示接口，不鼓励无理由反悔，不承诺必然可撤。检索锚点：民事法律行为可撤销。条号不是 `L#`。

诉讼时效中断或重新起算须分相对人。对保险人的到达或付款不当然中断对侵权人的时效。不得写死唯一届满日。转介 `评估人身损害诉讼时效`。

---

## 节点 4　执行力与草稿

单独民事和解原则上仅合同拘束力，必须明示不能直接申请强制执行。不得写成协议等同判决、签完即可执行。诉讼调解书、司法确认、公证赋强只点转介 `办理人身和解执行力补强`。私下微信或当面和解不能走司法确认。不保证法院确认或赋强成功。有效仲裁条款不得写成谈不拢就去选定某法院。

草稿栏目只借范本结构。状态默认 `讨论稿`。合意闸打开且无停止的 `W#` 才得标 `待签待核`。不利事实不删除。不发送版。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过合意闸直接给可签终稿或概括弃权主文。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if C 端只要大众准备包，then 只分流不回改。

判断状态只许三值。口头转述、截图和「已读」不得写成协议已成立、已签署、已送达或期限已起算。事故认定书、调解记录不得单独写成民事终局比例。

## 本任务回链纪律

本任务成果是「不代签署的人身损害和解协议草稿」。不包含：谈判让步表、保险了结审查终稿、司法确认手续、测算终稿、概括弃权可签主文。禁止口头报价写成已合意。禁止未知伤残概括弃权因明示写入。禁止协议等同判决。禁止选边治愈。禁止倒签骗保。禁止未知写零。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标可签终稿已形成。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接。
风险档 A：不可逆弃权或倒签字段必须单独标可逆性。
