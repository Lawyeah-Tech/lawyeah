# 输出合同

按触发结果选择交付形状。禁止唯一责任百分比。禁止把替代写成连带或各一半。禁止必须先劳动仲裁。禁止编造被告。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出（主成果仅工伤三段且无需对外替代；诊疗主轴；海事） | 第 1、2、10 节。禁止替代表和追偿条件。个人劳务走负触发一句，不走本行 |
| 整体停止 | 第 1、10 节。禁止替代表、50%、被告清单和倒签方案。双方秘密、虚构职务、伪造出车单、倒签合同时，整体停止优先于负触发 |
| 正触发且可判断替代 | 下列十节表头均出现；用户要各 50% 时第 5、6 节数字格填 `待核` 或 `依据不足，无法形成结论`；用户要把替代改写连带时第 5 节连带格填 `现有依据不支持`，不关窗；第三人受害时第 7 节填 `不打开`；禁止省略后改填各一半 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。双方秘密未解不得进入「部分形成」。每个 `Q#` 必须带证明负担方和判断三值。

## 1. 触发、单方立场、授权与成果状态

写明受害人是第三人还是工作人员、是否夹带工伤请求、受限字段。双方秘密未解不得进入「部分形成」。

## 2. 来源登记与 MCP 调用表

工牌、劳动合同、调度、出车单分列编号。口头「他是公司的」只登记 `S#`。`L#` 不得直接抄技能内条号。MCP 未调用也留一行。

## 3. 单位与行为人关系

派遣、挂靠、承揽、个人劳务冲突并列，不选有利版本。挂靠、承揽、1192 不打开则填 `不打开`。

## 4. 执行工作任务判断

仅工牌依据不足。执行中违规不等于偏离任务。内部禁止不当然对外免责。公车私用等不利事实不得删除。

## 5. 对外替代主体

用人单位替代打开。工作人员不当然对外连带、不当然必须共同被告。派遣：用工单位全部，派遣单位过错范围内共同承担，补充责任不打开。禁止各一半。禁止编造全体员工。

## 6. 对内追偿接口

故意或重大过失待核。一般过失不当然追偿。金额不与对外自动等额。不附追偿状。不得升格为对外连带。

## 7. 工伤入口

第三人受害默认 `不打开`。工作人员受害只红旗转劳动或竞合，不代办、不填待遇。禁止必须先仲裁才能告单位。

## 8. 证据缺口

出车单、岗位职责、监控控制方。不得因对方控制考勤推定在岗。保存通知不等于保全。认定书不写成用人者终局。

## 9. 下一步

只转介：主体评估、交通专项、共同侵权、过错、工伤竞合、劳务受害、起诉。禁止在此写起诉状、追偿状或保险分账。不选定法院。

## 10. 缺口、停止项与提示

须列对方最强解释（工牌即执行任务、口头即公司的、认定书即用人者终局、必须先劳动仲裁、内部禁止即免责、超速即偏离任务、单位与司机当然连带或各一半、派遣公司只负补充责任、犯罪则单位免责、考勤在对方即已证明、要某区法院就必须出诉状、要正式工就必须倒签）与证据缺口。

本成果不是劳动关系确认书、工伤待遇、交强险分账、共同侵权判决、追偿状或起诉状。
