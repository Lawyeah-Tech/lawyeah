# 用人者责任方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。对外形态只用 `替代` / `不打开` / `过错范围内共同承担` / `待核`。禁止唯一责任百分比、单位与员工各一半、工作人员当然对外连带。未知金额不写零。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》第三十四条（派遣单位相应补充责任）、第三十五条，或 2003 年人身损害赔偿解释第九条（雇员故意或重大过失与雇主对外连带）时记为噪声，不得写入 `L#`。对外替代不得写成连带。

`Q#` 交付列：`主体｜关系假设｜执行工作任务｜对外形态｜证明负担方｜对内追偿接口｜来源｜判断`。工牌、劳动合同、调度、出车单必须分列，不得合成一行。

---

## 节点 0　关系分流

整案转出只交付第 1、2、10 节。

若 if 主成果仅是确认劳动关系、工伤认定、劳鉴或待遇，且无需对外替代，then 负触发至劳动。
若 if 用户同时要工伤认定和对外告单位，then 本窗正触发：工伤三段转劳动，对外替代留本窗。禁止写成必须先劳动仲裁或先确认劳动关系才能起诉用人单位。检索锚点：侵权责任编解释（一）第十五条。
若 if 个人之间提供劳务或无偿帮工，含致第三人损害，then 负触发至 `评估提供劳务受害`，不得写成第一千一百九十一条。
若 if 材料表面是承揽、定作，then 并行「可能用人者 / 可能承揽」，承揽终稿转介主体评估，本窗不写第一千一百九十三条。
若 if 受害人是工作人员且因用人单位以外的第三人受害，需要分账，then 民事第三人段可留接口，分账转 `评估工伤与第三人侵权竞合`，对单位工伤请求转劳动。同事执行任务致害：默认用人者路径，不是当然第三人。
若 if 劳务派遣三方争议主轴且无人身损害对外赔偿，then 负触发。

口头「他是公司的」「配送途中」只登记 `S#`。认定书上的「某公司司机 / 执行公务」只作 `R#`，不写成用人者替代已核验。

## 节点 1　执行工作任务

检索锚点：民法典第一千一百九十一条第一款。主张用人者责任的一方证明：行为人属于工作人员或执行工作任务的其他人员，且行为与执行任务有内在联系。个体工商户从业人员适用同一款。检索锚点：解释（一）第十五条。不以劳动仲裁确认劳动关系为前置。

若 if 仅有工牌而无任务指令、调度或出车单，then 执行工作任务 `依据不足，无法形成结论`。
时间、地点不是唯一标准。依据用人单位指示在职权范围内的行为、为完成职权范围内事务的辅助行为、为用人单位利益的合理行为，均可作为内在关联候选，须回链材料。
执行中违规（配送中超速、执勤中冲突）不等于偏离任务，不得据此对外免责。
若 if 单位主张内部「禁止此类操作」，then 内部规定不当然对外免责，是否仍属执行任务另核。
若 if 公车私用或明显偏离任务，then 标不利事实，不得为用户删去，该行待核。
不得因对方控制考勤或监控而推定在岗、在途。保存通知不等于保全。

## 节点 2　对外责任主体

现有依据支持用人者对外责任时，由用人单位承担侵权责任。工作人员一般不当然对外连带，不当然必须列为共同被告。另有共同实施事实才转介 `评估共同侵权与连带按份`。禁止把故意或重大过失升格为对外连带。禁止单位与员工各一半。

劳务派遣：检索锚点民法典第一千一百九十一条第二款、解释（一）第十六条。接受劳务派遣的用工单位承担侵权人应承担的全部责任；劳务派遣单位在不当选派工作人员、未依法履行培训义务等过错范围内，与用工单位共同承担责任，总额不超过被侵权人应受偿损失。禁止写成《侵权责任法》第三十四条的相应补充责任。禁止写成两家当然全额连带。派遣协议与劳动合同冲突并列，不选有利版本。用工单位与派遣单位内部约定不得对抗受害人。

工作人员执行任务中违法并构成犯罪：检索锚点解释（一）第十七条。刑事责任不影响用人单位依法承担民事责任。刑民交叉只标接口。

挂靠机动车：实际使用人、被挂靠人、保险人分列，转介 `评估道路交通事故责任与保险先行` 和 `评估责任主体与保险覆盖`。禁止车主当然连带。本窗不写交强险分账终稿。
不得把无法指明的「某公司全体员工」写成被告。编造全体员工：整体停止。

## 节点 3　对内追偿

检索锚点：民法典第一千一百九十一条第一款追偿句。用人单位承担侵权责任后，可以向有故意或者重大过失的工作人员追偿。一般过失不当然追偿。主张追偿的用人单位证明故意或重大过失。
追偿是对内接口，不得写成受害人必须先告员工。追偿金额不得写成与对外赔偿自动等额。本任务不制作追偿起诉状。
单位已付工伤待遇与民事追偿关系转劳动或 `评估工伤与第三人侵权竞合`。

---

## 节点 4　邻接与输出纪律

第三人受害的行人案：工伤入口填 `不打开`。
交强险、商业三者顺序转入交通专项。该列谁转入主体评估。
用户要各 50% 或唯一比例：数字格字段停止，比较表仍交付。
用户要把替代改写连带：连带格 `现有依据不支持`，不关窗。
用户要必须先劳动仲裁：前置格 `现有依据不支持`。

三行必须可见：对受害人的对外替代、对工作人员的追偿接口、对劳动包的分流。禁止把用人者责任写成「单位和员工各一半」。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过专项分流直接给连带或各一半。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密且未获冲突豁免，then 整体停止，不得选边治愈。
若 if 用户提出虚构职务、伪造出车单或调度、倒签劳动合同、把兼职改写成正式工、编造全体员工被告、伪造伤情或隐匿既往，then 整体停止；第一次提出即停。
若 if 日期、送达或动态规则未核验，then 期限字段停止，不编造唯一截止日，不选定法院。
若 if 金额或份额参数不足，then 该行标未知或 `待核`，禁止写零或各一半冒充已核定。

口头转述、截图和「已读」不得写成已受理、已送达或执行任务已证明。事故认定书、调解记录不得单独写成民事用人者终局。判断状态只许三值。禁止胜诉率。

## 本任务回链纪律

本任务成果是「用人者对外替代责任表」。不包含：劳动关系确认、工伤待遇、提供劳务受害终稿、共同侵权终稿、交强险分账、挂靠连带终稿、承揽终稿、追偿状、起诉状。禁止工作人员当然对外连带；禁止派遣两家当然连带或旧补充责任；禁止必须先确认劳动关系。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接。
风险档 A：不可逆文书或期限字段必须单独标可逆性。
