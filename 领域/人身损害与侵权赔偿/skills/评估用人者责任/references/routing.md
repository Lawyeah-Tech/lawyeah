# 边界与路由

## 正触发

执行工作任务致害，或工作人员受害并可能牵出单位对外或对内责任，需要单独判断用人者路径。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 工伤认定待遇 | 劳动领域 |
| 个人劳务或帮工 | `评估提供劳务受害` |
| 第三人与工伤分账 | `评估工伤与第三人侵权竞合` |
| 总体总图 | `评估人身侵权责任` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 工伤认定、劳动能力鉴定、工伤待遇 | 劳动领域 |
| 诊疗过错 | 医疗医药领域 |
| 海事船员 | 海事领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“公司司机撞人，告公司还是司机”正触发。“员工要认工伤”转劳动。“私人叫邻居帮忙搬家具受伤”走提供劳务受害。
