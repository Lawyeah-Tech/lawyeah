# 边界与路由

## 正触发

工作人员因执行工作任务造成他人损害，需要单独判断用人者替代、执行任务与追偿接口。己方或对方主张均可。用户要唯一百分比或要把替代改写成连带，仍正触发，该格字段停止。同事执行任务致害默认走本窗。

用户同时要工伤认定和对外告单位：本窗正触发，工伤段转劳动，对外留本窗。双方秘密、虚构职务或伪造出车单的停止，优先于负触发。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 主成果仅工伤三段且无需对外替代 | 劳动领域 |
| 个人劳务或帮工（含致第三人） | `评估提供劳务受害` |
| 只要总体责任总图 | `评估人身侵权责任` |
| 只要工伤与第三人分账 | `评估工伤与第三人侵权竞合` |
| 只要交强险或商业三者分账 | `评估道路交通事故责任与保险先行` |
| 只要主体名单或挂靠连带终稿 | `评估责任主体与保险覆盖` |
| 只要共同侵权形态终稿 | `评估共同侵权与连带按份` |
| 只要承揽定作人过错终稿 | `评估责任主体与保险覆盖` |
| 只要过错原因力终稿 | `评估过错与原因力` |
| 只要起诉状或追偿状 | `提起人身损害一审` |

「要各 50%」「要派遣补充责任」「必须先劳动仲裁」不在本表。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 机动车、交强险、挂靠 | `评估道路交通事故责任与保险先行`、`评估责任主体与保险覆盖` |
| 另有共同实施事实 | `评估共同侵权与连带按份` |
| 过失相抵、原因力序位 | `评估过错与原因力` |
| 工作人员因第三人受害、分账 | `评估工伤与第三人侵权竞合` |
| 个人劳务或帮工 | `评估提供劳务受害` |
| 承揽、定作人过错 | `评估责任主体与保险覆盖` |
| 场所内第三人、商场补充 | `评估场所安全保障义务` |
| 已选定后起诉 | `提起人身损害一审` |
| 追加单位或派遣单位 | `追加变更责任主体` |
| 监控、考勤在对方控制 | `准备监控保存通知` |

## 易混

「公司司机撞人，告公司还是司机」正触发；「各赔 50%」仍正触发，数字格停止。「员工要认工伤」转劳动；同时要告肇事方或告单位对外，对外段留本窗。「私人叫邻居帮忙搬家具受伤」走提供劳务受害，不写 1191。「保安是派遣来的，只告派遣公司补充责任」正触发，补充格 `现有依据不支持`。「必须先劳动仲裁」前置格不支持。「把兼职改成正式工再告」整体停止。
