# 评估用人者责任

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成「用人者对外替代责任表」：执行工作任务是否成立、用人单位对外责任、工作人员是否共同被告单独待核、对内故意或重大过失追偿接口。不认定劳动关系，不计算工伤待遇，不把提供劳务与用人者责任混写成一条。不把替代改写成共同侵权或各一半。

`depends-on` 为空。接受等价事实、工牌、调度、出车单和证据清单。

## 工作边界

正触发：工作人员因执行工作任务造成他人损害，需要单独判断用人者替代、执行任务与追偿接口。己方或对方主张均可。用户要唯一百分比或要把替代改写成连带，仍正触发，该格字段停止。同事执行任务致害默认走本窗，不是当然第三人。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果仅是劳动关系确认、工伤认定、劳鉴或待遇，且无需对外替代（转劳动）；
- 个人之间劳务或无偿帮工，含致第三人损害（转 `评估提供劳务受害`，不写第一千一百九十一条）；
- 只要总体责任总图（转 `评估人身侵权责任`）；
- 只要工伤与第三人分账（转 `评估工伤与第三人侵权竞合`）；
- 只要交强险或商业三者分账终稿（转 `评估道路交通事故责任与保险先行`）；
- 只要主体名单或挂靠连带终稿（转 `评估责任主体与保险覆盖`）；
- 只要共同侵权形态终稿（转 `评估共同侵权与连带按份`）；
- 只要承揽定作人过错终稿（接口转主体评估，本窗不写第一千一百九十三条终稿）；
- 只要起诉状或追偿状（转 `提起人身损害一审`）。

用户同时要工伤认定和对外告单位：本窗正触发，工伤段转劳动，对外留本窗。禁止写成必须先劳动仲裁才能起诉用人单位。

本任务不选定法院，不写唯一截止日，不代提交追偿状或起诉状，不给胜诉率。

## 建立工作坐标

确认：使用者与授权；单方立场；单位名称；行为人职务或岗位；行为是否与执行任务有内在联系；是否存在劳务派遣、挂靠或承揽候选；受害人是第三人还是工作人员；法域。口头「他是公司的」不得写成工作人员身份已证明。仅有工牌无任务指令，执行工作任务依据不足。

同时掌握双方秘密或未解利益冲突：`整体停止`，不得以选边治愈，也不得改走负触发去出连带或各一半。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 劳动合同、工牌、调度、出车单分列；`R#` 认定书或机关文书；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 责任行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。对外形态只用 `替代` / `不打开` / `过错范围内共同承担` / `待核`。禁止填连带、各一半。技能正文中的条号是检索锚点，不是已核验 `L#`。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验用人单位责任、派遣相应责任、追偿故意或重大过失等将被写入 `L#` 的现行规则；不可用则这些字段停止，且不得填各一半或必须先仲裁。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变对外替代或派遣形态的条文正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补执行工作任务内在关联、内部禁止不当然对外免责、工作人员不当然连带的实务反例。

工具不可用时继续职务、调度、出车编目。不得凭记忆写单位与司机连带、派遣两家连带，或 2003 年解释第九条雇员连带。

## 判断节点

执行顺序和停止条件以 [用人者责任方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 关系分流

工伤三段转劳动。个人劳务转另项。承揽、挂靠只标接口。夹带对外请求不得整案关掉本窗。

### 2. 执行工作任务

时间地点不是唯一标准。执行中违规不等于偏离任务。内部禁止不当然对外免责。

### 3. 对外替代主体

用人单位对外承担责任。工作人员不当然对外连带。派遣：用工单位全部，派遣单位过错范围内共同承担，不是补充责任。

### 4. 对内追偿接口

故意或重大过失待核。一般过失不当然追偿。不得升格为对外连带。

### 5. 邻接与输出纪律

工伤入口、交强险、共同侵权只标转介。用户要各一半则数字格停止。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；虚构职务；伪造出车单、调度或工牌；倒签劳动合同；把兼职改写成正式工以制造请求权；编造「某公司全体员工」为被告。整体停止优先于负触发。第一次提出即停，不以「坚持」为门槛。
- `字段停止`：执行工作任务、派遣关系、追偿故意重大过失标准未核验；用户要唯一百分比的数字格；用户要把替代改写连带的连带格；必须先劳动仲裁的前置格。
- `目标停止`：主目标变为工伤认定、提供劳务受害终稿、交强险分账、共同侵权终稿或起诉状。

禁止指导伪造出车单或倒签合同。不给胜诉率。
