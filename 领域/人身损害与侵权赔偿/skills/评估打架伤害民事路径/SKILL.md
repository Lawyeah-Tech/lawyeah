# 评估打架伤害民事路径

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“打架伤害民事请求、正当防卫接口、刑附民或另行起诉分流”。不定罪。刑事控告辩护转刑事。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算、鉴定和证据清单。

## 工作边界

正触发：互殴或被打造成人身损害，需要民事请求判断并与刑事程序分流。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 要求定罪或代写刑事控告、辩护（转刑事）；
- 只要刑附民与另行起诉的专项比较且刑事程序已启动（转 `评估刑附民与另行起诉`）；
- 场所因未制止互殴的补充责任为主成果（转场所专项）。

本任务不定罪，不判断刑事责任。正当防卫民事效果须核验，不得写成“先动手的一定全赔”。

## 建立工作坐标

确认：使用者与授权；单方立场；互殴还是单方殴打；伤情；是否已出警、行政拘留或刑事立案；正当防卫主张；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 监控、验伤；`R#` 受案回执、鉴定；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 民事请求；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典正当防卫、互殴过失相抵和刑附民范围接口。不虚构案件系统。

工具不可用时继续事实、主体、程序文书状态和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [打架民事方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　刑民分流

不定罪。刑事程序权利转刑事。

### 节点 2　民事请求与互殴

各自伤害分别建 `Q#`。互殴可能过失相抵，不是当然各打五十。

### 节点 3　正当防卫接口

民事上因正当防卫造成损害不承担责任，超过必要限度承担适当责任。

### 节点 4　场所与共同侵权接口

酒吧KTV未制止：场所补充。多人共同实施：连带专项。

### 节点 5　输出纪律

不指导继续斗殴。伤情鉴定转鉴定原子。

## 停止与安全

- `整体停止`：立场不明；用户坚持报复伤害或伪造伤情。
- `字段停止`：正当防卫民事效果、刑附民范围未核验。
- `目标停止`：主目标变为刑事控告辩护或刑附民专项终稿。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
