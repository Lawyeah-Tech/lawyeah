# 评估打架伤害民事路径

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成互殴或单方殴打的民事请求表（双方损害分列 `Q#`）、第一百八十一条正当防卫与过当接口、第一千一百七十三条过失相抵接口，以及与治安或刑事程序并行的提示。不定罪。先动手不是全赔。还手不是当然防卫。互殴不是第一千一百八十六条各打五十。不是必须先刑后民。不写分流刑民交叉终稿、刑附民终稿、1198 场所补充终稿、1168 连带终稿、1199–1201 教育机构终稿、1176、测算或起诉状。

`depends-on` 为空。刑民边界总图转 `分流刑民交叉`。已立案且主成果是附民与另诉比较转 `评估刑附民与另行起诉`。场所未制止转 `评估场所安全保障义务`。校园学校职责转 `评估教育机构责任`。过错百分比转 `评估过错与原因力`。

## 工作边界

正触发：互殴或被打造成人身损害，需要民事请求判断并与治安、刑事程序分流。用户要「先动手一定全赔」「还手即正当防卫」「互殴各打五十」「必须先刑后民」仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 要求定罪或代写刑事控告、辩护（转刑事）；
- 只要刑民边界总图（转 `分流刑民交叉`）；
- 刑事已启动且主成果是附民与另诉比较（转 `评估刑附民与另行起诉`）；
- 场所因未制止互殴的补充责任为主成果（转 `评估场所安全保障义务`）；
- 多人共同实施形态终稿（转 `评估共同侵权与连带按份`）；
- 在园在校学校职责终稿（转 `评估教育机构责任`）；
- 只要自甘风险或公平分担终稿（转 `评估自甘风险与公平分担`）；
- 只要过错百分比（转 `评估过错与原因力`）；
- 反诉终稿（转 `评估反诉或抵销`）；
- 只要测算或伤残（转 `测算人身损害赔偿` 或 `准备伤残鉴定材料`）；
- 只要起诉状（转 `提起人身损害一审`）；
- 只要监控保存通知发送稿（转 `准备监控保存通知`）；
- 只要唯一时效截止日（转 `评估人身损害诉讼时效`）；
- 只要选定法院（转 `评估人身损害管辖`）；
- C 端只要大众准备包（只分流）；
- 未成争改合同（审查起草搁置）。

已刑事立案而用户仍要打架民事请求表：本窗正触发，刑附民只标接口，不写刑附民终稿。主目标是控告仍负触发刑事，不保留请求表硬填。

## 建立工作坐标

确认：使用者与授权；单方立场；互殴还是单方殴打；伤情材料表面；是否已出警、治安处罚或刑事立案（文书表面）；正当防卫主张；场所或校园是否介入；法域。

口头「他先动手」「我是正当防卫」「已经立案」「批捕了」只登记 `S#`。

同时掌握双方秘密或互殴双方利益冲突未解：`整体停止`，不得以选边治愈，也不得改走负触发去出请求或抗辩方案。提出报复伤害、继续斗殴、约架取证、伪造或夸大伤情入罪或出罪、威胁证人、倒签谅解或违法取证：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 监控、验伤表面；`R#` 受案回执、处罚决定、调解书、人体损伤程度鉴定表面；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 民事请求行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。接口状态只用 `打开`、`不打开`、`待核`。技能正文中的条号是检索锚点，不是已核验 `L#`。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民法典第一百八十一条正当防卫与过当适当责任；第一千一百六十五条过错责任；第一千一百七十三条过失相抵（只作接口，禁止唯一比例）；第一千一百八十三条精神损害接口。不可用则防卫效果、相抵开闭、精神损害接口字段停止。禁止把第一千一百八十条（多人死亡相同数额死亡赔偿金）当防卫。禁止把刑法第二十条写入民事 `L#` 或据此定罪出罪。已失效《侵权责任法》第三十条、第二十四条不得写入 `L#`。禁止把 1198、1168、1199、1176、1186 当本窗 `L#` 终稿。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变 181 开闭、过当、相抵或刑民并行结论的条文正文再写入 `L#`。不得编造 `regulation_id`，也不得把摘要条号写成已核验 `L#`。
- `search_practiced` 补互殴与防卫分型、先动手非当然全责、治安未结可诉民事、场所未制止是补充不是连带的实务反例。

工具不可用时继续互殴或单方殴打、伤情、出警立案表面编目；法律效果字段停止。不得凭记忆写先动手全赔、还手即防卫、各打五十或必须先刑后民。

## 判断节点

执行顺序和停止条件以 [打架民事方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场与不关窗

刑民并行提示，不定罪。双方秘密或报复、伪造提出即停。错误主张不关窗。

### 2. 民事请求分列与第一千一百七十三条

双方损害分列 `Q#`。互殴不是当然各打五十。过错百分比转过错窗。

### 3. 第一百八十一条正当防卫

检索锚点是第一百八十一条，不是第一千一百八十条。还手不是当然防卫。本窗不定罪。

### 4. 邻接红旗

1198、1168、1199、1176、1186、刑附民、分流刑民交叉只标接口。

### 5. 证据与禁止报复

不指导继续斗殴。人体损伤程度鉴定不是伤残等级。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；提出报复伤害、继续斗殴、约架取证、伪造或夸大伤情、威胁证人、倒签谅解或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。
- `字段停止`：正当防卫民事效果、互殴事实、刑民是否中止未核验。用户要先动手全赔、还手即防卫、各打五十或必须先刑后民则该格停止，窗口不关。
- `目标停止`：主目标变为刑事控告辩护、刑附民终稿、1198、1168、1199、1176、测算或起诉状。

禁止指导继续斗殴或伪造伤情。不给胜诉率。不选定法院。不保证必得。不代提交、不代报案。
