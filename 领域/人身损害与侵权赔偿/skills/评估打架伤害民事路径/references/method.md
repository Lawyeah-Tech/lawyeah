# 打架民事方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。接口状态只用 `打开`、`不打开`、`待核`。禁止胜诉率、唯一责任比例、必得总额、选定法院、伤残等级。未知金额不写零。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》第三十条、第二十四条，已失效《民法通则》第一百二十八条、第一百三十二条，或把刑法第二十条、民法典第一千一百八十条当作正当防卫时记为噪声，不得写入 `L#`。禁止用第一千一百八十六条各打五十替代第一千一百七十三条。禁止把紧急避险第一百八十二条、见义勇为第一百八十三条与正当防卫揉成一条。禁止写必须先刑后民。

`Q#` 固定列：`编号｜主张人｜相对人｜分型（单方殴打/互殴/防卫候选）｜损害表面｜1165 接口｜181 防卫｜过当适当责任｜1173 相抵接口｜1198/1168/1199 接口｜证明负担方｜判断｜待核`。一行一伤害。互殴双方不得合成「各打五十」一行。

## 节点 0　分流、立场与不关窗

整案转出只交付第 1、2、10 节。

| 信号 | 处理 |
| --- | --- |
| 执行职务被打且主轴是工伤认定、劳鉴或待遇 | 转劳动；民事接口可留 |
| 诊疗过错或医疗损害鉴定主轴 | 转医疗医药 |
| 海事 | 转海事 |
| 未成争只要改合同 | 审查起草本窗搁置 |

「先动手一定全赔」「还手即正当防卫」「互殴各打五十」「必须先刑后民」**不关窗**。

治安案件：民事可独立进行。已刑事立案：本窗保留当事人之间 `Q#`；刑附民或另行起诉只标接口，展开转 `评估刑附民与另行起诉`；刑民边界总图转 `分流刑民交叉`。本窗不定罪、不写控告状、不代报案、不写刑附民终稿。民事是否必须中止：仅当基本事实必须以刑事案件审理结果为依据时待核，不得默写必须先刑后民。口头立案、口头批捕只登记 `S#`。

群体伤害策略属范围外，输出 `unavailable`，本任务只处理单方或有限人数互殴。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出报复伤害、继续斗殴、约架取证、伪造或夸大伤情、威胁证人、倒签谅解或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　证明负担

一般打架走第一千一百六十五条过错责任，不是过错推定。不得因场所控制监控而倒置。

| 路径 | 主张方须证 | 相对方须证 | 禁止写法 |
| --- | --- | --- | --- |
| 单方殴打请求 | **主张被打的一方**：殴打行为、损害、因果 | 未实施、无因果、互殴或防卫另负担 | 口头「他打的」升格已证；轻伤鉴定=责任已成立 |
| 互殴相抵或各自侵权 | **主张相抵或对方也加害的一方**证明对方实施加害及因果 | 不得把双方都受伤写成互殴已证 | 各打五十；先动手即全赔 |
| 正当防卫（第一百八十一条第一款） | **主张防卫的一方**证明正在进行的不法侵害、针对侵害人、为制止侵害、未超过必要限度 | 相对方可反证不存在侵害、已停止、互殴或过当 | 还手=防卫；口头先动手=防卫已成立；刑法第二十条当民事 `L#` |
| 防卫过当（第一百八十一条第二款） | **主张过当的一方**证明超过必要限度及不应有之损害 | 防卫基础不足则过当格 `依据不足` | 有还手即过当全赔；过当=互殴同一比例 |

口头「他先动手」「我是正当防卫」只登记 `S#`，判断填 `依据不足，无法形成结论`。互殴与防卫互斥待核：材料支持相互攻击的，防卫格不得标 `现有依据支持`；一方停止后另一方继续攻击，分时段建行。

治安调解书、行政处罚决定、受案回执、人体损伤程度鉴定只进 `R#` 表面，不得单独写成民事终局比例、已定罪或防卫已构成。人体损伤程度（轻微伤、轻伤、重伤）不是伤残等级，不得写成评残已完成。

## 节点 2　民事请求分列与第一千一百七十三条

单方殴打：受害人医疗、误工、伤残、精神损害分列接口；金额终稿转测算窗；精神损害转 `评估精神损害赔偿`（第一千一百八十三条只标接口）。

互殴：双方损害各建 `Q#`，禁止合成一笔净额再对半。过错形态与原因力转 `评估过错与原因力`，不输出唯一比例。反请求转 `评估反诉或抵销`，本窗不写反诉终稿。1186 默认 `不打开`。用户要各打五十或先动手全赔：该格 `现有依据不支持`，窗口不关。未成年人加害：1188 监护人只标接口，转主体窗。

## 节点 3　第一百八十一条正当防卫

检索锚点：因正当防卫造成损害的，不承担民事责任。正当防卫超过必要的限度，造成不应有的损害的，正当防卫人应当承担适当的民事责任。

不是第一千一百八十条。不是刑法第二十条。本窗不认定构成犯罪或阻却犯罪。不得仅因还手写成防卫。挑拨对方侵害后反击，防卫格不得标支持。用户要还手即防卫：该格 `现有依据不支持` 或待核，窗口不关。未核验则防卫法律效果字段停止。

## 节点 4　邻接红旗

酒吧、KTV 未制止：1198 接口打开，转 `评估场所安全保障义务`。禁止写成场所与打人者连带、禁止补充即全额、禁止同一执行顺序。未制止不等于共同实施。

多人共同实施伤害：转 `评估共同侵权与连带按份`。在场但无伤害故意或行为的，不得默认连带。教唆帮助另列。

校园互殴：当事人之间民事请求留本窗；学校 1199/1200/1201 转 `评估教育机构责任`。同学不得写成 1201 第三人与学校连带。

1176 对互殴默认 `不打开`。已立案选附民或另诉：只标转介，不展开范围比较。

## 节点 5　证据、管辖与输出纪律

监控多为场所控制：不能因对方控制推定内容有利，也不得因口述「已删」即全责。不办调取，只转介 `准备监控保存通知`。禁止指导私下约架、继续斗殴固定证据。

不选定法院。侵权行为地（实施地与结果发生地分列）、各被告住所地并列待核。住院地不得写成必有权。口头转述、截图和「已读」不得写成已受理、已送达或期限已起算。不写唯一时效截止日。普通打架不得套第一百九十一条。

禁止指导继续斗殴。本任务不制作刑事文书。
