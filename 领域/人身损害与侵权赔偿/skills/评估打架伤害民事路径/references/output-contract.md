# 输出合同

按触发结果选择交付形状。禁止先动手一定全赔。禁止还手即正当防卫。禁止互殴各打五十。禁止必须先刑后民。禁止把第一百八十一条写成第一千一百八十条。禁止把刑法第二十条当民事 `L#`。禁止场所与打人者连带。禁止把人体损伤程度鉴定写成伤残等级。禁止选定法院、必得总额。禁止指导继续斗殴或伪造伤情。禁止代报案、代提交。本窗不定罪。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出（执行职务被打工伤待遇或劳鉴主轴；诊疗过错主轴；海事；未成争改合同） | 第 1、2、10 节。禁止互殴比例、防卫成立、刑附民选择、必得额 |
| 整体停止 | 第 1、10 节。禁止请求、抗辩、金额、选边方案、被告清单、取证步骤。双方秘密、报复伤害、约架、伪造伤情、威胁证人或倒签谅解时，整体停止优先于负触发；第一次提出即停，无选边治愈，无「坚持」门槛 |
| 用户要「先动手一定全赔」或「还手即正当防卫」或「互殴各打五十」或「必须先刑后民」（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；不得改走负触发关窗；成果不得标 `已形成` |
| 正触发且可评估 | 下列十节表头均出现；防卫要件、互殴事实、刑民是否中止未核验的单元格填 `依据不足，无法形成结论` 或 `待核`；禁止为填满而编造全赔、防卫成立或各 50% |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。双方秘密未解不得进入「部分形成」。每个 `Q#` 必须带判断三值和证明负担方。`L#` 不得直接抄技能内条号。

## 1. 触发、单方立场、授权与成果状态

互殴或单方殴打。双方秘密未解不得进入「部分形成」。

## 2. 来源登记与 MCP 调用表

监控、验伤、受案回执分列。口述先动手、口头立案只登记 `S#`。MCP 未调用也留一行。刑法第二十条、侵权责任法第三十条、第一千一百八十条当防卫若返回则记噪声。

## 3. 刑民边界

不定罪。不代报案。不写控告状。治安可与民事并行。已立案只标刑附民或分流接口，不写附民范围终稿。口头立案不得写成民事必须中止。必须先刑后民格填 `现有依据不支持` 或待核。

## 4. 民事请求表

双方损害分列 `Q#`。未知金额不写零。禁止合成一笔各一半。过错百分比转过错窗。精神损害只标 1183 接口。

## 5. 第一百八十一条正当防卫

检索锚点第一百八十一条。还手即防卫格填 `现有依据不支持` 或待核。过当是适当责任，不是全额也不是零。禁止 1180。禁止刑法第二十条当民事成立。

## 6. 第一千一百七十三条与第一千一百八十六条

相抵接口打开则转过错窗，不输出唯一比例。1186 默认不打开。各打五十格填 `现有依据不支持`。先动手全赔格填 `现有依据不支持`。

## 7. 邻接红旗与行政刑事文书

1198、1168、1199、1176、刑附民、分流刑民交叉：打开、不打开或待核。调解书、处罚决定、受案回执、人体损伤程度鉴定 ≠ 民事终局、已定罪或防卫已构成。

## 8. 证据与禁止事项

监控只转介保存通知，不办调取。不能因场所控制推定内容有利。禁止继续斗殴、约架、伪造伤情。轻伤不是伤残等级。

## 9. 下一步

转介鉴定材料、发函、起诉、管辖、时效、场所窗、教育机构窗、刑附民、分流刑民交叉。不定残。不选定法院。侵权行为地与被告住所地并列待核。住院地不得写成必有权。不写诉状。不写唯一时效截止日。

## 10. 缺口、停止项与提示

须列对方最强解释（先动手所以全赔、还手就是正当防卫、互殴各打五十、必须等刑事或治安结案才能告、已经立案就必须中止、治安调解已经了断、轻伤就是十级、监控在酒吧就拍到或已删即全责、场所与打人者当然连带、学校在校全责、刑法第二十条直接免民事、1180 就是防卫条、选边即可继续）与证据缺口。

本成果不是刑事意见、不是分流刑民交叉终稿、不是刑附民终稿、不是诉状、不是必得总额。
