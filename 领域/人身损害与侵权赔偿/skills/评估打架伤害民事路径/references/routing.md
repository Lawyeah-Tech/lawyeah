# 边界与路由

## 正触发

互殴或被打造成人身损害，需要民事请求判断并与治安、刑事程序分流。用户要「先动手一定全赔」「还手即正当防卫」「互殴各打五十」「必须先刑后民」仍正触发。已刑事立案而用户仍要民事请求表，仍正触发。

双方秘密、报复伤害、伪造伤情或约架取证的停止，优先于负触发。不得改走负触发去出请求或抗辩方案。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 定罪、控告状或辩护 | 刑事领域 |
| 刑民边界总图 | `分流刑民交叉` |
| 刑附民与另行起诉比较终稿 | `评估刑附民与另行起诉` |
| 场所未制止主成果 | `评估场所安全保障义务` |
| 1168–1172 形态终稿 | `评估共同侵权与连带按份` |
| 在园在校学校职责终稿 | `评估教育机构责任` |
| 自甘风险或公平分担终稿 | `评估自甘风险与公平分担` |
| 过错百分比终稿 | `评估过错与原因力` |
| 反诉终稿 | `评估反诉或抵销` |
| 测算或伤残 | `测算人身损害赔偿` / `准备伤残鉴定材料` |
| 起诉状 | `提起人身损害一审` |
| 监控保存通知发送稿 | `准备监控保存通知` |
| 唯一时效截止日 | `评估人身损害诉讼时效` |
| 选定法院 | `评估人身损害管辖` |
| C 端只要大众准备包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「先动手全赔」不在本表。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 刑事控告辩护定罪 | 刑事领域 |
| 执行职务被打且工伤待遇或劳鉴主轴 | 劳动领域并标民事 |
| 医疗伤情鉴定中的诊疗过错 | 医疗医药领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

「被人打了怎么民事索赔」正触发。「帮我告他故意伤害罪」转刑事。「案子已经批捕了选附民还是另诉」走刑附民专项。「酒吧没拉架要酒吧赔」走 1198。「幼儿园同学互抓」学校职责走教育机构，当事人之间请求可留本窗。「互殴各打五十」仍正触发，1186 格不支持。「必须等刑事判完才能起诉」仍正触发，先刑后民格不支持或待核。「还手就是正当防卫」仍正触发，防卫格不支持或待核。「再打回去把伤做大」第一次提出即整体停止。
