# 边界与路由

## 正触发

互殴或被打造成人身损害，需要民事请求判断并与刑事程序分流。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 定罪控告辩护 | 刑事领域 |
| 刑附民路径终稿 | `评估刑附民与另行起诉` |
| 场所未制止主成果 | `评估场所安全保障义务` |
| 反诉终稿 | `评估反诉或抵销` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 刑事控告辩护定罪 | 刑事领域 |
| 工伤（执行职务被打） | 劳动领域并标民事 |
| 医疗伤情鉴定中的诊疗过错 | 医疗医药领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“被人打了怎么民事索赔”正触发。“帮我告他故意伤害罪”转刑事。“案子已经批捕了选附民还是另诉”走刑附民专项。
