# 保全申请方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。稿件状态只用 `草案`、`申请闸关闭`、`提交前待核`、`停止`。禁止准许率、胜诉率、必然准许、唯一截止日、选定法院、自行宣布伤残等级。未知金额不写零。本任务不代提交，不保证裁定，先予执行不得写入保全主文。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、把保存通知或现场步骤写成保全裁定、把先予执行写成保全、把三十日写成未核验日历截止、把四十八小时写成申请人今晚截止、把一律免担保或一律百分之三十、把保证准许、把查封一切写入结论时记为噪声，不得写入 `L#`。禁止指导虚构转移或查封生活必需。

`App-证#` 与 `App-财#` 必须分表，禁止合成「查封一切」。固定列：`编号｜分型｜时机（诉前／诉中／仲裁前）｜申请人｜被申请人（与案外人分列）｜对象（具体账户／车牌／不动产／具体证据；猜测标S#）｜控制方或登记名义｜线索来源｜紧急或难以执行／灭失事实（回链）｜条件判断（三值）｜请求范围与金额（未知不写零、不写无限）｜拟采取措施｜管辖连结点并列（不选唯一）｜担保（诉前应当／诉中可以责令，额度待核）｜错误赔偿明示｜范围红旗（超请求／案外人／生活必需）｜诉前三十日红旗（只写期间长度）｜四十八小时红旗（对法院期间）｜状态｜来源回链`。一行一类对象。

## 节点 0　分流、立场、申请闸与不关窗

整案转出或闸关闭只交付第 1、2、10 节，不交申请书终稿。闸部分打开时：仅对已有具体线索的行给出草案，另一行标 `依据不足` 或 `不打开`。

| 信号 | 处理 |
| --- | --- |
| 尚未决定是否申请 | 负触发 `评估证据或财产保全必要性` |
| 只要先予执行医疗费或生活费 | 负触发 `申请先予执行医疗费`；给付不得改写成查封，也不得写入保全主文 |
| 只要保存通知正文 | 负触发 `准备监控保存通知` |
| 只要现场合法固定步骤 | 负触发 `保全现场监控与电子证据` |
| 只要调查令或公证事项终稿 | 负触发对应原子 |
| 已被保全只要复议或担保置换 | 负触发 `应对人身案件保全裁定`；申请方续封可留，标明不是复议 |
| 只要起诉状 | 负触发 `提起人身损害一审` |
| 主轴仅工伤待遇且无对第三人财产或易失证据 | 整案转劳动；夹带第三人车辆／账户／场所监控则本窗正触发，工伤段分流，`App#` 可留并转介 `评估工伤与第三人侵权竞合` |
| 诊疗过错或医疗鉴定终稿 | 转医疗；对医疗机构财产或场所监控的申请可留 |
| 海事扣船或海事保全 | 转海事 |
| 工程款工期质量造价 | 转建设工程；工地人身对第三人保全不得误转 |
| 未成争只要改合同 | 审查起草本窗搁置 |

申请闸打开条件（对某一行，同时满足）：单方无冲突立场与授权；已决定申请；该行对象有具体线索（账户、车牌、坐落、证据名称加保管人或机位时段），可标 `S#` 或更强；主成果是申请草稿而非必要性评估、先予执行、保存函或现场步骤。

闸关闭（仍正触发）：完全无线索；目的是「查封一切并保证准许」而无具体对象。「今天必须交」「必须冻结」本身不得开闸写成应当准许。仅有担心无回链事实：该行 `依据不足`，不关窗。

「保证准许」「查封一切」「写死三十日」「一律百分之三十担保」「四十八小时今晚必须交」「保险保函法院必须接受」**不关窗**。闸未开则仍只交 1、2、10 节。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或受害人与被申请人同时交材料争同一份申请且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出虚构转移、倒签紧急事实、查封无关案外人生活必需且拒绝限缩、以保全骚扰、违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　管辖与当事人

申请人、被申请人、案外人分列。不得把案外人写成被申请人。

管辖连结点并列，材料不足则并列待核，**任何情况下不选定唯一法院**，申请书不得预填「此致某院」：

- 财产保全：被保全财产所在地、被申请人住所地、对案件有管辖权的人民法院；
- 证据保全：证据所在地、被申请人住所地、对案件有管辖权的人民法院。

住院地不得单独打开管辖。用户指定唯一法院：该格 `现有依据不支持` 或待核，窗口不关。条号不是 `L#`。

## 节点 2　请求与线索

财产与证据分表。账户、车牌、不动产登记信息、证据名称与保管人分列来源。禁止「查封对方一切财产」。无线索则闸关闭，不得为填满而编造对象。

请求范围限于请求的范围或与本案有关的财物。金额不超过已支持请求或合理区间，未知不写零也不写无限。超标的红旗必须可见。

证据保全须写明：证据基本情况、待证事实、灭失或以后难以取得的风险、拟采取措施（封存、拍照、录像、复制、提取等，栏目待核）。不得要求打包全部硬盘或无关第三人全时段画面。

先予执行（紧急医疗费、必要生活费）不进保全主文。用户把「先让医院有钱」写入冻结请求：该给付行 `现有依据不支持`，转介 `申请先予执行医疗费`，保全行窗口不关。

不能因对方控制推定监控存在或内容有利。口述转移只登记 `S#`。

## 节点 3　担保、错误赔偿与范围红旗

诉前财产保全申请人应当提供担保，不提供则裁定驳回申请——检索锚点，未核验不得写成人身损害一律免担保。诉中保全人民法院可以责令担保。证据保全参照保全章，应当或可以待核。额度、形式待核，**禁止默写唯一比例（含百分之三十）**。诉讼保全担保实践常见上限与诉前「相当于请求保全数额」分档，一律待核，不得把其中一档写成全国唯一。

保险保函只作候选，是否接受由法院决定。用户要「保函法院必须收」：该格 `现有依据不支持` 或待核，窗口不关。

申请有错误的，申请人应当赔偿被申请人因保全所遭受的损失。必须写入自检，不得写成「无风险」。

范围红旗：超请求、案外人财产、生活所必需物品（执行规范待核）。线索指向生活必需且用户拒绝限缩仍要求「应当查封」：整体停止。

保险人认责或交强险在案可以降低财产保全必要性，但不改担保法定分档，不关闭证据行，也不等于本窗应当免担保。

## 节点 4　申请书草案与诉前三十日

草稿栏目：当事人基本情况、请求事项、事实与理由、保全对象明确信息或具体线索、拟采取措施、担保材料、是否已提出其他保全。状态 `草案` 或 `提交前待核`。不代提交，不得写成已提交或已裁定。不利事实不删除。

诉前保全后三十日内不依法提起诉讼或者申请仲裁的，人民法院应当解除保全。三十日是期间长度锚点，不是未核验的唯一日历截止日。起算点未核验则截止日字段停止。微信已读、裁定作出日、口头告知不得单独起算。

人民法院对情况紧急的申请须在四十八小时内作出裁定，是对法院的期间，不是申请人「今晚必须交」的截止日。非紧急财产保全的五日等期间同样待核，不得写入用户唯一期限。

输出纪律：不保证准许。不选定法院。不代提交。申请书不得写「依法应当准许」「保证四十八小时内裁定」。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过申请闸直接给可提交终稿或必然准许。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if C 端只要大众准备包，then 只分流不回改。

判断状态只许三值。口头转述、截图和「已读」不得写成已受理、已送达、已保全或期限已起算。事故认定书不得单独写成民事终局比例并据此必须保全。

## 本任务回链纪律

本任务成果是「不代提交的财产或证据保全申请草稿」。不包含：必要性评估终稿、先予执行、保存函、现场步骤、调查令、公证事项、应对裁定、起诉状。禁止保证准许。禁止选定唯一法院。禁止写死三十日。禁止查封一切。禁止默写百分之三十。禁止选边治愈。禁止虚构转移。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标申请终稿已形成。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接：已固定分型、线索缺口和稿件状态。
风险档 A：不可逆申请或期限字段必须单独标可逆性。
