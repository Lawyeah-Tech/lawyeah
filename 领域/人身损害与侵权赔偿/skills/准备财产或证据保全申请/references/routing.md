# 边界与路由

## 正触发

已决定申请诉前或诉中财产保全或证据保全。无线索、用户要保证准许、查封一切、写死三十日、一律百分之三十担保或四十八小时今晚必须交仍正触发：申请闸可关，对应格停止，窗口不关。工伤待遇与对第三人财产或易失证据同时出现，仍正触发：工伤段分流劳动，对第三人 `App#` 可留。申请方续封可留，标明不是复议。

双方秘密、同时交材料、虚构转移、查封案外人生活必需、以保全骚扰的停止，优先于负触发。不得改走负触发去出申请书。保证准许不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 尚未决定是否申请 | `评估证据或财产保全必要性` |
| 先予执行医疗费或生活费 | `申请先予执行医疗费` |
| 只要保存通知正文 | `准备监控保存通知` |
| 现场、聊天或行车记录仪合法固定步骤 | `保全现场监控与电子证据` |
| 调查令终稿 | `申请人身案件调查令或取证` |
| 公证保全事项终稿 | `准备人身案件公证保全` |
| 已被保全只要复议或担保置换 | `应对人身案件保全裁定` |
| 起诉状 | `提起人身损害一审` |
| 送达渠道专项 | `设计人身案件通知送达` |
| 建卷矩阵 | `建立人身损害证据案卷` |
| C 端只要大众准备包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「把岳父房子一起封了吓他」「先做一份假过户记录」不在本表，走整体停止。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 仅工伤待遇且无对第三人财产或易失证据 | 劳动领域 |
| 劳动仲裁保全且无民事第三人对象 | 劳动领域 |
| 病历封存或医疗鉴定终稿 | 医疗医药领域；对医疗机构财产或场所监控可留 |
| 海事扣船或海事保全 | 海事领域 |
| 工程造价主轴 | 建设工程；人身对第三人保全不得误转 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。对第三人财产或易失证据可留。

| 信号 | 转介 |

## 易混

「决定冻账户，写申请」正触发。「到底要不要冻」走必要性。「先让对方付医疗费」走先予执行，不得写入保全主文。「不知道有没有房子，必须全部冻结并保证准许，担保百分之三十，今晚交，写死三十日，此致某区法院」仍正触发；闸可关或对象格依据不足；保证准许、百分之三十、今晚截止、日历三十日、唯一法院各格不支持或待核。「工伤还在认，对方要卖车，申请冻这辆车」正触发，财产行可留，工伤段分流。「两边材料都给你，选边写申请」整体停止。「监控函和现场拷贝一并写进申请书」保存函与现场步骤转介，本窗不附那些终稿。
