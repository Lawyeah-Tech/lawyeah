# 边界与路由

## 正触发

已决定申请诉前或诉中财产保全或证据保全。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 尚未决定 | `评估证据或财产保全必要性` |
| 先予执行 | `申请先予执行医疗费` |
| 应对已被保全 | `应对人身案件保全裁定` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 海事扣船 | 海事领域 |
| 劳动仲裁保全 | 劳动领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“决定冻账户，写申请”正触发。“到底要不要冻”走必要性。“先让对方付医疗费”走先予执行。
