# 输出合同

按触发结果选择交付形状。申请闸未打开不得交付申请书终稿。禁止保证准许或准许率。禁止选定唯一法院或预填「此致某院」。禁止写死三十日日历截止。禁止把四十八小时写成申请人今晚截止。禁止默写一律免担保或一律百分之三十。禁止查封一切。禁止把先予执行写入保全主文。禁止把保存通知、现场步骤、公证或调查令写成法院保全裁定。禁止选边治愈。禁止虚构转移或查封生活必需步骤。不代提交。不定残。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 申请闸关闭或节点 0 整案转出 | 第 1、2、10 节：关闭理由和最小补证。禁止申请书终稿、唯一法院、截止日。对第三人申请可留时不得因工伤整案转出 |
| 整体停止 | 第 1、10 节。禁止 `App#`、申请书、选边、虚构转移方法。双方秘密、同时交材料、查封案外人生活必需、虚构转移、骚扰第一次即停，优先于负触发；无选边治愈，无「坚持」门槛 |
| 用户要保证准许、查封一切、写死三十日、一律百分之三十或今晚必须交（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；闸未开则仍只交 1、2、10；不得改走负触发关窗；成果不得标申请终稿 `已形成` 为应当准许 |
| 正触发且闸开（可部分开） | 下列十节表头均出现；条件、担保、期限、管辖未核验的单元格填 `依据不足，无法形成结论` 或 `待核`；证据表与财产表分列；禁止为填满而宣布应当准许、查封一切或预填唯一法院 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入申请终稿已形成。双方秘密未解不得进入「部分形成」。每个 `App-证#`／`App-财#` 必须带来源和三值判断。`L#` 不得直接抄技能内条号。保证准许、三十日日历截止、百分之三十默写、四十八小时申请人截止若返回则记噪声。稿件状态默认 `草案`。

## 1. 触发、单方立场、授权与成果状态

申请闸开、部分开或关。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。已决定申请。稿件默认 `草案`。

## 2. 来源登记与 MCP 调用表

`S/D/R/C/L/I/G/App/V`。口述转移、口头认责、已读截图只登记 `S#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 申请闸、时机与分型

诉前、诉中、仲裁前分列。证据保全与财产保全分表。先予执行不进主文。「查封一切」不得开闸。

## 4. 管辖与当事人

连结点并列。财产行与证据行分别列。不选定唯一法院。被申请人与案外人分列。申请书不得预填受诉法院。

## 5. 请求与线索 `App#`

具体账户、车牌、坐落或证据名称加保管人。未知不写零不写无限。禁止查封一切。无线索则该行依据不足。

## 6. 担保方案

诉前应当，诉中可以责令。额度待核。禁止默写百分之三十或一律免担保。保险保函只是候选。

## 7. 错误赔偿与范围红旗

申请错误应赔偿。超请求、案外人、生活必需单列。拒绝限缩生活必需则整体停止。

## 8. 申请书草稿

当事人、请求、事实理由、对象线索、措施、担保。草案，不代提交。不得写依法应当准许。不利事实不删除。

## 9. 时机红旗与下一步

三十日只作期间长度。已读、作出日不得起算。四十八小时是对法院的期间。转介起诉准备、必要性补证或先予执行。不写那些终稿。

## 10. 缺口、停止项与提示

须列对方最强解释：保证准许、查封一切、百分之三十担保、三十日写死截止、四十八小时今晚必须交、保险保函法院必须收、先予执行就是查封、选边即可继续、口述转移即已支持、保存函即已保全、选定唯一法院。

本成果不是已提交申请、不是裁定、不是先予执行、不是保存函、不保证准许、不是唯一截止日。不代提交。
