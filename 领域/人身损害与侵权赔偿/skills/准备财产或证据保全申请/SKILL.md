# 准备财产或证据保全申请

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的申请方立场下，形成不代提交的保全申请包：申请闸、财产行 `App-财#` 与证据行 `App-证#` 分表、管辖连结点并列、担保与错误赔偿自检、申请书草案。已决定诉前或诉中申请。不保证准许。不选定唯一法院。不计算唯一截止日。先予执行不是保全，不得写入申请主文。保存通知、现场合法固定、公证、调查令不等于法院保全裁定。保险保函只是担保候选，是否接受由法院决定。

`depends-on` 为空。尚未决定转 `评估证据或财产保全必要性`。紧急医疗费转 `申请先予执行医疗费`。已被裁定转 `应对人身案件保全裁定`。保存函转 `准备监控保存通知`。现场步骤转 `保全现场监控与电子证据`。

## 工作边界

正触发：已决定申请诉前或诉中财产保全或证据保全。无线索、用户要「保证准许」「查封一切」「写死三十日」「一律百分之三十担保」「四十八小时今晚必须交」仍正触发：申请闸可关，对应格填 `现有依据不支持` 或字段停止，窗口不关。工伤待遇与对第三人财产或易失证据同时出现：本窗正触发，工伤段分流劳动，对第三人的 `App#` 可留。申请方续封可留本窗，须标明不是复议。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未决定是否申请（转 `评估证据或财产保全必要性`）；
- 只要先予执行医疗费或生活费（转 `申请先予执行医疗费`）；
- 只要保存通知正文（转 `准备监控保存通知`）；
- 只要现场、聊天或行车记录仪合法固定步骤（转 `保全现场监控与电子证据`）；
- 只要调查令终稿（转 `申请人身案件调查令或取证`）；
- 只要公证事项终稿（转 `准备人身案件公证保全`）；
- 已被保全且只要复议或担保置换（转 `应对人身案件保全裁定`）；
- 只要起诉状（转 `提起人身损害一审`）；
- C 端只要大众准备包（只分流）；
- 未成争改合同（审查起草搁置）。

保证准许、查封一切、写死三十日**不在负触发表**，窗口不关。虚构转移、查封生活必需拒绝限缩、双方秘密**不在负触发表**，走整体停止。

## 建立工作坐标

确认：使用者与授权；申请方；诉前或诉中或仲裁前；具体财产线索或具体证据对象；被申请人与案外人分列；担保准备；保险覆盖材料；法域。

口头「查封一切」「保证准许」「今晚必须交」「担保就百分之三十」只登记 `S#`。不得预填唯一法院，不得写死唯一日历截止日，不得把口述转移写成已支持。

同时掌握双方秘密，或受害人与被申请人同时交材料争同一份申请：`整体停止`，不得以选边治愈，也不得改走负触发去出一方申请。受害人已开口且委托范围就是申请草稿、且未掌握对方秘密时，可推定申请方立场。只要同时掌握双方秘密，无例外整体停止。提出虚构转移、倒签紧急事实、查封无关案外人生活必需且拒绝限缩、以保全骚扰：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 线索、权属、保单；`R#` 立案或机关文书；`C#` 担保或保险材料；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`App-证#`／`App-财#` 申请行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。稿件状态只用 `草案`、`申请闸关闭`、`提交前待核`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。不准许率。本任务默认 `草案`，不代提交。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：财产保全以可能使判决难以执行或造成其他损害为条件；诉前财产保全另须情况紧急、不立即申请将使合法权益受到难以弥补的损害，申请人应当提供担保，向被保全财产所在地、被申请人住所地或对案件有管辖权的人民法院申请；采取保全措施后三十日内不依法起诉或申请仲裁应解除（三十日是期间长度）；情况紧急时人民法院须在四十八小时内作出裁定（对法院的期间，不是申请人今晚截止）；证据保全以证据可能灭失或以后难以取得为条件，诉前须情况紧急，向证据所在地、被申请人住所地或对案件有管辖权的人民法院申请；申请有错误应赔偿被申请人因保全所遭受的损失；诉中保全可以责令担保；保全限于请求的范围或与本案有关的财物。技能正文条号不是 `L#`。噪声：已失效《侵权责任法》、保证准许、写死三十日、选定唯一法院、一律免担保或一律百分之三十、查封一切、先予执行等于保全、保存通知或现场步骤等于裁定、四十八小时写成申请人截止、生活必需当然可查封、保险保函法院必须接受。不可用则条件、担保、期限、管辖效力字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变条件、担保、诉前期间或错误赔偿的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补无线索难准许、超范围错误赔偿、诉前三十日实践差异、保险保函是否接受由法院决定、免担保非人身损害一律的实务反例。
- `search_template` 只借保全申请书栏目，不把范本当法定格式、已提交文本或指定唯一法院。

工具不可用时继续当事人、线索和 `App#` 编目；条件、担保、期限、管辖效力字段停止。不得凭记忆写三十日截止、必然准许或唯一法院。

## 判断节点

执行顺序和停止条件以 [保全申请方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、申请闸与不关窗

工伤三段分流，对第三人申请可留。双方秘密或虚构转移第一次停。保证准许不关窗。尚未决定负触发。

### 2. 管辖与当事人

财产与证据连结点分别并列。不选定唯一法院。被申请人与案外人分列。申请书不得预填「此致某院」。

### 3. 请求与线索 `App#`

财产与证据分表。禁止查封一切。未知金额不写零也不写无限。先予执行不进主文。

### 4. 担保、错误赔偿与范围红旗

诉前应当担保，诉中可以责令。禁止默写百分之三十。申请错误应赔偿。生活必需拒绝限缩第一次停。

### 5. 申请书草案与诉前三十日

草案不代提交。不保证裁定。三十日只作期间长度。四十八小时不是申请人今晚截止。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；受害人与被申请人同时交材料；提出虚构转移或倒签紧急事实、查封无关案外人生活必需且拒绝限缩、以保全骚扰、违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：管辖连结点、担保应当或可以、诉前期间起算、条件未核验。用户要保证准许、查封一切、写死三十日、一律百分之三十或今晚必须交则该格停止，窗口不关；闸未开仍不出申请书终稿。
- `目标停止`：主目标变为必要性评估、先予执行、保存函、现场步骤、调查令、公证、应对裁定或起诉状终稿。保证准许不在目标停止。

禁止指导虚构转移或查封生活必需。不给准许率。不选定法院。不代提交。不编唯一截止日。
