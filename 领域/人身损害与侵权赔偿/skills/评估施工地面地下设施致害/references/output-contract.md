# 输出合同

按触发结果选择交付形状。禁止绝对全责。禁止有坑即全责。禁止有锥桶即免责。禁止发包人当然施工人连带。禁止盗盖即免责、全责或场所补充必然。禁止把「没看到牌子」写成已证明未设置。禁止写 1252/1255/1256/1198/1240 终稿。禁止选定法院、伤残等级、必得总额。禁止工伤认定或造价鉴定。禁止代提交。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出（施工人员工伤待遇或劳鉴主轴；诊疗过错主轴；港口或海事施工；未成争改施工合同） | 第 1、2、10 节。禁止路径成立结论、全责方案、施工人认定终局 |
| 整体停止 | 第 1、10 节。禁止请求、抗辩、金额、选边方案、被告清单、取证步骤。双方秘密、破坏现场、挪锥桶再拍、伪造标志缺失、擅闯工地、倒签巡检或伪造伤情时，整体停止优先于负触发；第一次提出即停，无选边治愈，无「坚持」门槛 |
| 用户要「有坑即全责」或「有锥桶即免责」或「绝对全责」或「发包人当然施工人连带」或「盗盖即免责/全责/场所补充必然」（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；不得改走负触发关窗；成果不得标 `已形成` |
| 正触发且可评估 | 下列十节表头均出现；分型、施工人、标志措施是否足够、管理人、盗盖形态未核验的单元格填 `依据不足，无法形成结论` 或 `待核`；禁止为填满而编造全责、免责、伤残或必得额 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。双方秘密未解不得进入「部分形成」。每个 `Q#` 必须带判断三值和证明负担方。`L#` 不得直接抄技能内条号。

## 1. 触发、单方立场、授权与成果状态

行人、相邻居民还是作业人员。双方秘密未解不得进入「部分形成」。

## 2. 来源登记与 MCP 调用表

现场、告示、合同、井盖标识分列。口述没护栏、没看到牌子只登记 `S#`。`L#` 不得抄技能内条号。MCP 未调用也留一行。侵权责任法第九十一条若返回则记噪声。

## 3. 工伤与工程分流

作业人员自身受害应转出则停止 1258 实体结论。对第三人车辆只标民事接口，禁止「必须先工伤才能起诉」。工程款转出。

## 4. 地面施工第一千二百五十八条第一款

施工人识别。原告负担施工事实、损害、因果；施工人负担已经设置明显标志并且采取安全措施。有坑即全责格、有锥桶即免责格、绝对全责格填 `现有依据不支持`。标志是否明显、措施是否足以未核验则效果待核。

## 5. 地下设施第一千二百五十八条第二款

市政、权属、养护、物业冲突并列。伤害不等于定责。盗盖与管理职责分列；补充或直接或范围待核。禁止套 1198 第二款场所补充必然。

## 6. 发包分包转包挂靠分列

一行一主体。禁止发包人当然施工人连带。禁止选定唯一责任人。不写 1168 终稿。不替代主体窗。

## 7. 第三人与邻接红旗

盗盖人、路过车辆分列。1252/1255/1256/1198/1240：打开、不打开或待核。倒塌不在此终稿。地下挖掘高度危险不在此终稿。

## 8. 证据与禁止事项

不擅闯工地。不破坏、摆拍现场，不挪锥桶再拍，不倒签巡检。不能因对方控制许可证、巡检或监控推定内容有利。转介保全或保存通知，不办调取。非法取证画面不得指导使用。

## 9. 下一步

转介主体名单、过错窗、工伤竞合、劳动包、物件窗、高度危险、测算、发函、起诉、管辖、时效。不定伤残。不选定法院。施工地、医院所在地、各被告住所地并列待核。不写诉状。不写唯一时效截止日。

## 10. 缺口、停止项与提示

须列对方最强解释（有坑就是全责、有锥桶就免责、推定即绝对责任、没看到牌子就是没设、旧第九十一条由原告证明无标志、发包人当然赔、选定唯一施工方、盗盖物业免责或全责或按 1198 补充、工人摔了走民事全额、楼塌了按 1258 找路面施工人、工地走 1198、渣土遗撒按挖坑、爆破按 1258、必须先工伤才能起诉、选边即可继续）与证据缺口。

本成果不是造价鉴定、不是工伤认定、不是 1252 终稿、不是诉状、不是必得总额。
