# 边界与路由

## 正触发

施工、地面施工或地下设施造成通行人或第三人人身损害，需要判断施工人和公共设施管理人。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 工程款工期质量造价 | 建设工程领域 |
| 施工人员工伤 | 劳动领域 |
| 高空抛物或外墙脱落 | `评估物件脱落坠落与高空抛物` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 工伤认定待遇 | 劳动领域 |
| 工程价款工期质量 | 建设工程领域 |
| 港口施工 | 海事或工程，按主轴 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“人行道开挖没护栏摔了”正触发。“要工程进度款”转建设工程。“工人从脚手架掉下”转劳动工伤。
