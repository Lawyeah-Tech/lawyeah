# 边界与路由

## 正触发

在公共场所或者道路上挖掘、修缮安装地下设施等，或窨井等地下设施，造成通行人、相邻居民或第三人人身损害，需要判断施工人或地下设施管理人。塔吊、脚手架、施工围挡致场外通行人且用户要标志措施或施工现场安全路径，仍正触发。用户要「有坑即全责」「有锥桶即免责」「过错推定即绝对责任」「发包人当然施工人连带」「盗盖即管理人免责或全责或场所补充必然」仍正触发。

双方秘密、破坏现场、伪造标志缺失、擅闯工地或倒签巡检的停止，优先于负触发。不得改走负触发去出全责或免责方案。

## 易混

「人行道开挖没护栏摔了」正触发。「楼房盖到一半塌了」负触发走物件 1252，不得以施工现场为由留在本窗写倒塌终稿。「挖坑震到邻房倒塌，行人另在坑边摔了」：倒塌段转物件，摔人段可留本窗，分表。「要工程进度款」转建设工程。「工人从脚手架掉下」转劳动，不对第三人保留民事接口时不得把工人留在 1258。「塔吊砸到路人」本窗正触发，1252/1253 只标接口。「仓库货垛倒塌」不是本窗（1255）。「路上渣土遗撒绊倒、没有开挖」不是本窗（1256）。「商场地滑」走 1198。「工地护栏缺失路人摔」走本窗。「爆破伤人」走高度危险。「隧道盾构地下挖掘」走 1240，不按 1258 地面施工。「没护栏所以绝对全责」不关窗。「现场有个锥桶所以免责」不关窗。「发包人肯定连带」不关窗。「把护栏拆了拍照再告」第一次提出即整体停止。
