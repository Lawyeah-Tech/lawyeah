# 评估施工地面地下设施致害

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成民法典第一千二百五十八条两款分路径：地面施工施工人不能证明已经设置明显标志和采取安全措施则担责；窨井等地下设施管理人不能证明尽到管理职责则担责。不定伤残，不保证必得，不选定法院，不办工伤认定、劳动能力鉴定、工伤待遇或工程价款工期质量造价。不把过错推定写成绝对全责或无过错全责，不因有坑即全责、有锥桶即免责，不把发包人写成当然施工人连带，不把盗盖写成管理人当然免责、当然全责或场所补充必然。不写第一千二百五十二条倒塌终稿、第一千二百五十五条堆放终稿、第一千二百五十六条道路遗撒终稿、第一千一百九十八条场所终稿、第一千二百四十条地下挖掘高度危险终稿、1168–1172 形态终稿、测算或起诉状。

`depends-on` 为空。倒塌 1252 转 `评估物件脱落坠落与高空抛物`。场所 1198 转 `评估场所安全保障义务`。高度危险（含 1240 高空、高压、地下挖掘活动）转 `评估高度危险作业致害`。1168–1172 转 `评估共同侵权与连带按份`。施工人员工伤主轴转劳动 / `评估工伤与第三人侵权竞合`。工程款转建设工程领域。

## 工作边界

正触发：在公共场所或者道路上挖掘、修缮安装地下设施等，或窨井等地下设施，造成通行人、相邻居民或第三人人身损害，需要判断施工人或地下设施管理人。塔吊、脚手架、施工围挡致**场外通行人**且用户要标志措施或施工现场安全路径：正触发（1252/1253/1255 只标接口）。用户要「有坑即全责」「有锥桶即免责」「过错推定即绝对责任」「发包人当然施工人连带」「盗盖即管理人免责或全责或场所补充必然」仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要总体责任总图（转 `评估人身侵权责任`）；
- 只要主体名单终稿（转 `评估责任主体与保险覆盖`）；
- 只要 1168–1172 形态终稿（转 `评估共同侵权与连带按份`）；
- 只要过错百分比（转 `评估过错与原因力`）；
- 建筑物、构筑物倒塌塌陷主轴，或只要 1252 建设/施工单位连带展开（转 `评估物件脱落坠落与高空抛物`）；
- 外墙脱落、花盆、高空抛物主轴（转物件窗）；
- 非道路开挖的堆放物滚落滑落主轴（1255 不在本窗终稿）；
- 公共道路堆放、倾倒、遗撒且无挖掘作业（1256 不在本窗终稿）；
- 经营或公共场所一般摔伤、未制止互殴，且不是地面开挖或地下设施（转 `评估场所安全保障义务`）；
- 高压、爆破、放射性、高速轨道、1240 高空或地下挖掘活动主轴（转 `评估高度危险作业致害`）；
- 施工人员自身受害、工伤认定、劳动能力鉴定或工伤待遇主轴（转劳动；第三人车辆民事可另开竞合窗）；
- 工程价款、工期、质量、造价鉴定（转建设工程）；
- 只要测算或伤残（转 `测算人身损害赔偿` 或 `准备伤残鉴定材料`）；
- 只要起诉状（转 `提起人身损害一审`）；
- 只要唯一时效截止日（转 `评估人身损害诉讼时效`）；
- 只要监控保存通知发送稿（转 `准备监控保存通知`）；
- 港口或通海水域施工（转海事或工程，按主轴）；
- 未成争改施工或设施管护合同（审查起草搁置）；
- C 端只要大众准备包（只分流）。

开挖致邻房损坏：邻房倒塌质量/建设施工连带主轴负触发至物件 1252；路面挖坑未设标志致行人摔伤正触发。二者并行时分表，禁止合成一笔 1252+1258 必得。

## 建立工作坐标

确认：使用者与授权；单方立场；受害人是行人、相邻居民还是作业人员；地面施工与地下设施分型；施工人与发包、分包、转包、挂靠名称变体；标志与安全措施表面；窨井管理人（市政、权属、养护、物业）冲突并列；是否盗盖或第三人车辆；法域。

口头「没护栏」「井盖是物业的」「没看到牌子」只登记 `S#`。施工告示、围挡企业名、井盖标识不得写成已确定唯一责任人。

同时掌握双方秘密或受害人与施工方、发包人、市政、物业利益冲突未解：`整体停止`，不得以选边治愈，也不得改走负触发去出全责或免责方案。提出破坏施工现场、挪走锥桶再拍照、摆拍无标志、伪造标志缺失、擅闯工地、倒签巡检或伪造伤情：第一次提出即整体停止，不以「坚持」为门槛。

编号：`S#` 单方陈述；`D#` 告示、合同、现场照片表面；`R#` 文书；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 责任行；`V#` 版本。

## 判断节点

执行顺序和停止条件以 [施工致害方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、身份与分型

工伤待遇或工程款主轴整案转出。倒塌主轴负触发至物件窗。双方秘密或破坏现场提出即停。行人摔坑正触发；作业人员自身受害不写 1258 终稿。

### 2. 第一千二百五十八条第一款地面施工

过错推定，不是无过错全责。施工人证明已经设置明显标志并采取安全措施。有坑不等于全责，有锥桶不等于免责。

### 3. 第一千二百五十八条第二款地下设施

管理人证明尽到管理职责。市政、权属、养护、物业冲突并列。盗盖与管理职责分列，不得套 1198 补充必然。

### 4. 施工人、发包分包挂靠与第三人

一行一主体。禁止发包人当然施工人连带。禁止选定唯一责任人。不写 1168 终稿。

### 5. 邻接红旗与输出纪律

1252/1255/1256/1198/1240 只标接口。不定伤残，不选定法院，不保证必得。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；提出破坏现场、挪锥桶再拍、伪造标志缺失、擅闯工地、倒签巡检或伪造伤情。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。
- `字段停止`：分型、施工人、标志措施是否足够、管理人、盗盖形态未核验。用户要绝对全责、有坑即全责、有锥桶即免责、发包人当然连带或盗盖即免责/全责/场所补充必然则该格停止，窗口不关。
- `目标停止`：主目标变为 1252 倒塌、1255 堆放、1256 遗撒、1198 场所、高度危险、工伤认定、工程款、1168 形态、测算或起诉状。

禁止指导破坏现场、伪造标志缺失或擅闯工地。不给胜诉率。不选定法院。不保证必得。不代提交。
