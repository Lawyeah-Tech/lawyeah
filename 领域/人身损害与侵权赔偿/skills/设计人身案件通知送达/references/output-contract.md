# 输出合同

按触发结果选择交付形状。设计闸未打开不得交付 `E#` 发送前终稿。禁止写通知实体内容。禁止执行发送。禁止补造回证。禁止把已读、发送成功或口头转述写成已到达。禁止计算唯一截止日。禁止把诉讼电子送达须同意套到诉讼外否则到达停止。禁止诉讼外任意公告或留置。禁止对保险人到达即中断对侵权人。禁止选边治愈。禁止伪造签收或倒签邮戳步骤。不选定法院。不保证中断时效。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 设计闸关闭或节点 0 整案转出 | 第 1、2、10 节：关闭理由和最小补证。禁止 `E#` 发送前终稿。第三人催告送达可留时不得因工伤整案转出 |
| 整体停止 | 第 1、10 节。禁止渠道表、回证方案、倒签或伪造步骤。双方秘密、同时交材料、伪造签收、倒签邮戳第一次即停，优先于负触发；无选边治愈，无「坚持」门槛 |
| 用户要把已读写成已到达、写死截止日或今天必须发出（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；闸未开则仍只交 1、2、10；不得改走负触发关窗；到达状态最高 `已发送待证明到达`；成果不得标已到达且已中断 `已形成` |
| 正触发且闸开 | 下列十节表头均出现；到达、中断、公告／留置未核验的单元格填 `依据不足，无法形成结论` 或 `待核`；禁止为填满而宣布已送达、已中断或诉讼外公告已完成 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入发送前终稿已形成。双方秘密未解不得进入「部分形成」。每个 `E#` 必须带来源和到达状态。`L#` 不得直接抄技能内条号。已读即到达、诉讼内外规则互套、公告任意可用若返回则记噪声。到达状态默认 `草案` 或 `待发送`。

## 1. 触发、单方立场、授权与成果状态

设计闸开或关。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。到达状态默认 `草案` 或 `待发送`。

## 2. 来源登记与 MCP 调用表

`S/C/D/L/I/G/E/V`。约定条款、工商地址、邮箱报文头分列。口述已读、后天截止只登记 `S#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 设计闸、文书类型与诉讼内外

文书类型只作标签，不写正文。诉讼外与诉讼送达分列。已立案法院送达不在本窗实施。「今天必须发出」不得开闸。

## 4. 收件人与已知地址

一行一个。侵权人与保险人分列。无线索则闸关闭。不选定唯一义务人。同事、门卫不得写成当然有权签收。

## 5. 约定渠道与备份渠道 `E#` 前半

条款必须定位。变更地址未通知待核。备份写失败升级。不得共用一个地址冒充全部到达。

## 6. 回证与到达状态

已读不等于到达。无回证不得写成依法未中断。本任务不执行发送、不补造回证。用户回报送达事实后再升状态。最高在仅有已读时为 `已发送待证明到达`。

## 7. 失败升级与禁止事项

拒绝签收记录经过。公告、留置条件未核验不得建议。伪造签收第一次停。公证实施、法院送达只点转介名。

## 8. 时效中断接口

分相对人。对保险人到达不当然中断对侵权人。保存函不当然中断。本窗不计算截止日。未核验则中断格待核。

## 9. 风险与下一步

不执行发送。转介正文原子、时效评估、公证保全、主体保险或起诉。不选定法院。不写那些终稿。

## 10. 缺口、停止项与提示

须列对方最强解释：已读即到达、发送成功即中断、对保险公司寄到了就对司机也中断、没约定电子送达所以微信一律无效、直接公告或留置、选边即可继续、倒签邮戳补中断、口述截止日必须写入。

本成果不是通知正文、不是已送达回证、不是法院送达、不是公证实施、不保证中断时效、不是唯一截止日。不执行发送。
