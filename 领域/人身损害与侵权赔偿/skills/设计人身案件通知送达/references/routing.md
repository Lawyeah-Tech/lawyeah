# 边界与路由

## 正触发

发函前需要单独设计送达渠道和到达证据，不写或暂不写通知实体内容。收件人地址不全、约定条款未定位、用户要把已读写成已到达、写死截止日或今天必须发出仍正触发：设计闸可关，对应格停止，窗口不关。工伤待遇与对第三人催告送达同时出现，仍正触发：工伤段分流劳动，催告送达可留。

双方秘密、同时交材料、伪造签收、倒签邮戳的停止，优先于负触发。不得改走负触发去出渠道表。伪造签收不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 索赔通知正文或项目表 | `准备侵权索赔通知` |
| 保存通知正文 | `准备监控保存通知` |
| 保险理赔申请材料包 | `准备交强险商业险索赔材料` |
| 公证送达或公证保全实施 | `准备人身案件公证保全` |
| 已立案且只要法院诉讼送达 | 由法院实施；本窗不写诉讼送达方案 |
| 时效截止日或剩余天数终稿 | `评估人身损害诉讼时效` |
| 起诉状 | `提起人身损害一审` |
| 应诉 | `应对人身损害一审` |
| 现场监控合法保全步骤 | `保全现场监控与电子证据` |
| 收件人完全不明且主问谁是侵权人 | `评估侵权人不明路径`；设计闸可并行关闭 |
| C 端只要大众准备包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「伪造签收」「倒签邮戳」「补一张回执」不在本表，走整体停止。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 仅工伤待遇且无对第三人催告送达 | 劳动领域 |
| 医疗损害鉴定终稿 | 医疗医药领域；对医疗机构或保险人的诉讼外催告送达可留 |
| 海事专门程序 | 海事领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。第三人催告送达可留。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 索赔正文 | `准备侵权索赔通知` |
| 保存正文 | `准备监控保存通知` |
| 中断能否成立、截止日 | `评估人身损害诉讼时效`；本窗不计算截止日 |
| 公证实施 | `准备人身案件公证保全` |
| 收件人、借用、未投保形态 | `评估责任主体与保险覆盖` |
| 向保险公司交材料 | `准备交强险商业险索赔材料` |
| 工伤与第三人 | `评估工伤与第三人侵权竞合` |
| 已立案后的送达实施 | 法院实施；起诉或应诉原子 |
| 易失监控步骤 | `保全现场监控与电子证据` |

## 易混

「函怎么送才能留下到达证据」正触发。「函里写什么赔偿项目」走索赔通知。「要公证处出证」走公证专项，本窗只把公证列为备份渠道名。「已经立案了，问法院怎么送」负触发，由法院实施。「微信已读就算送到，按今天中断，写死截止日」仍正触发；已读不得单独到达，截止日停止。「两边材料都给你，签收栏空着就填一填」整体停止。「工伤也要认，对肇事方的催告还没设计怎么送」正触发，催告送达可留，工伤段分流。
