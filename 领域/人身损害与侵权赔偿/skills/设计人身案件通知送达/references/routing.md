# 边界与路由

## 正触发

发函前需要单独设计送达渠道和到达证据。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 索赔通知正文 | `准备侵权索赔通知` |
| 保存通知正文 | `准备监控保存通知` |
| 公证送达实施 | `准备人身案件公证保全` |
| 伪造签收 | 整体停止 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 法院诉讼送达 | 程序内由法院实施 |
| 跨境送达 | 涉外领域红旗 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“函怎么送才能算送到”正触发。“函里写什么赔偿项目”走索赔通知。“要公证处出证”走公证专项。
