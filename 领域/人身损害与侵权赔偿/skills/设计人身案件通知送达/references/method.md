# 送达设计方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。到达状态只用 `草案`、`待发送`、`已发送待证明到达`、`已到达`、`停止`。禁止胜诉率、必然中断、唯一截止日、选定法院、把已读写成已到达。未知金额不写零。本任务不写通知实体内容，不执行发送，不补造回证。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文、已失效《合同法》、把微信已读写成到达、把诉讼电子送达须同意套到诉讼外否则到达停止、把公告或留置任意用于诉讼外催告、把对保险人到达写成当然中断对侵权人时记为噪声，不得写入 `L#`。禁止指导伪造签收或倒签邮戳。

`E#` 固定列：`收件人｜文书类型｜诉讼内外｜约定渠道｜备份渠道｜回证｜失败升级｜到达状态｜时效中断接口待核｜来源回链`。一行一个收件人。禁止合成「一次寄出即对全体义务人到达」。禁止把诉讼送达规则填进诉讼外行，也禁止把诉讼外数据电文规则填进已立案法院送达行。

拟制日＝本次形成本任务成果之日。函面、落款、寄出、拟制、邮戳四类日期均不得早于本次形成日。

## 节点 0　分流、立场、禁止与不关窗

整案转出或闸关闭只交付第 1、2、10 节，不交 `E#` 发送前终稿。

| 信号 | 处理 |
| --- | --- |
| 只要索赔通知正文或项目表 | 负触发 `准备侵权索赔通知` |
| 只要保存通知正文 | 负触发 `准备监控保存通知` |
| 只要保险理赔材料包 | 负触发 `准备交强险商业险索赔材料` |
| 只要公证实施终稿 | 负触发 `准备人身案件公证保全`；本窗可将公证列为备份渠道名，不写实施步骤 |
| 已立案且只要法院诉讼送达 | 负触发；由法院实施，本窗不写诉讼送达方案 |
| 只要时效截止日或剩余天数 | 负触发 `评估人身损害诉讼时效` |
| 只要起诉状或应诉 | 负触发 `提起人身损害一审`／`应对人身损害一审` |
| 主轴仅工伤认定、劳鉴或待遇，且无对第三人催告送达 | 整案转劳动；夹带对第三人／保险人催告送达则本窗正触发，工伤段分流，催告送达可留并转介 `评估工伤与第三人侵权竞合` |
| 诊疗过错或医疗鉴定终稿 | 转医疗；对医疗机构或保险人的诉讼外催告送达可留 |
| 海事专门程序 | 转海事 |
| 未成争只要改合同 | 审查起草本窗搁置 |

设计闸打开条件（同时满足）：单方无冲突立场与授权；至少一名收件人有名称或地址／邮箱／电话线索；拟发送文书类型可标（索赔、保存、和解催告等）；主成果是送达设计而非正文、公证实施或法院送达。

闸关闭（仍正触发）：收件人无线索；约定与备份渠道均无法列出；目的是威慑或「今晚必须发出」而无最小地址线索。「今天必须发出」本身不得开闸。合法二次催告（已寄过一次、补送达或换渠道）不受「对方未回复不得打开闸」误关。

「已读即到达」「写死截止日」「今天必须发出」「诉讼外直接公告」**不关窗**。闸未开则仍只交 1、2、10 节。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或受害人与侵权人、保险人同时交材料争同一份送达方案且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出伪造签收、倒签邮戳、补造回证、把本稿写成此前已发出、威胁或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　文书类型与诉讼内外分列

本任务不写正文。文书类型只作 `E#` 标签：索赔通知、保存通知、和解催告、其他诉讼外主张。正文转对应原子。用户同时要正文：列出独立成果，先完成本任务或按其指定优先；本窗仍不写正文。

诉讼外意思表示到达与诉讼送达必须分列，检索锚点分别核验，不得互套：

- **诉讼外**：非对话意思表示到达相对人时生效；数据电文进入相对人指定系统，或相对人知道／应当知道进入其系统时视为到达；另有约定按约定。诉讼外主张信件或数据电文到达或应当到达，即可作为对该收件人的中断候选，**不要求**事先约定电子送达。发送前不得把未经核验的电子渠道写成已经到达。
- **诉讼送达**：人民法院电子送达须受送达人同意。公告送达以受送达人下落不明或用其他方式无法送达为前提。留置是诉讼送达规则。已立案且只要法院送达：负触发，本窗不写实施方案。

禁止：把「须约定否则到达停止」写成诉讼外数据电文的关门条件；把民诉公告、留置直接填进诉讼外行并标 `已到达`。

## 节点 2　收件人、约定渠道与备份渠道

收件人分列：行为人、用人者、场所、教育机构、交强险保险人、商业三者保险人。不选定唯一义务人。收件人无线索：闸关闭，依据不足。对保险人与对侵权人必须分行；对保险人的到达不当然中断对侵权人的时效，反之亦然。

约定渠道必须定位到合同、保单、客运条款的条款位置，写入 `C#`。变更地址未通知的风险待核，不得把过期地址写成当然有效。约定邮箱或即时通讯：保留完整报文头、账号与发送记录设计，不得只写「发微信」。

备份渠道候选：工商或户籍地址、工作场所、EMS 法律文书专递、当面签收、公证送达过程。公证实施转 `准备人身案件公证保全`，本窗只点转介名。每条写失败升级。不得共用一个地址冒充全部到达。

签收人范围须运行时核验：法人可为法定代表人、主要负责人、收发部门或被授权人；自然人可为本人、同住完全行为能力亲属或被授权人。无核验不得把同事、门卫、无关第三人写成当然有权签收。

## 节点 3　回证、到达状态与失败升级

每次尝试预列：实施人、文本版本、渠道、地址、回证、失败升级。本任务不执行发送，不补造回证。发送后用户回报送达事实，状态才可改为 `已发送待证明到达` 或 `已到达`。

微信已读、发送成功、邮件打开、孤立截图、口头转述最多升到 `已发送待证明到达`，不得升 `已到达`，也不得据此起算时效或写成中断已成立。「应当到达」不得靠已读拟制。无回证不得写成「依法未中断」，只标中断待核。

拒绝签收：记录经过，升级书面可核验渠道或公证过程；不得把诉讼留置规则直接写成诉讼外已留置到达。

失败升级：

- 地址错误或无人签收：核对工商／户籍／约定变更，换备份渠道；
- 电子渠道无到达凭证：改书面专递或当面，保留报文头；
- 公告：诉讼外不得任意建议；诉讼公告条件未核验不得写入 `E#` 作为已可用升级；
- 法院送达：只在已立案后由法院实施，不是本任务的失败升级终稿。

用户要「发公告就算送到」「留置到门上就算到」：该格 `现有依据不支持` 或待核，窗口不关。

## 节点 4　时效中断接口与不可逆

到达可能构成向**该收件人**主张权利，从而成为对该相对人的时效中断候选。检索锚点：权利人向义务人提出履行请求且到达。须在成果中明示：

- 未保留回证则中断可能无法证明；
- 发错主体不当然中断对真正义务人的时效；
- 对保险人的到达不当然中断对侵权人的时效；
- 保存函不当然中断时效，中断主要是索赔通知争点；
- 本任务不计算截止日、剩余天数或唯一届满日；截止日转 `评估人身损害诉讼时效`，该格停止。

用户要把已读写成已到达并中断时效、写死截止日：到达状态最高 `已发送待证明到达`，中断与截止日字段停止或 `现有依据不支持`，窗口不关，成果不得标发送前终稿 `已形成` 为「已到达且已中断」。

拟制日＝本次形成日。用户要求倒签邮戳、把本稿写成此前已发出或补历史回证：整体停止。

工作中第三人伤害且民事催告送达可留：必须转介 `评估工伤与第三人侵权竞合`；工伤认定、劳动能力鉴定、工伤待遇不进本窗结论。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过设计闸直接给 `E#` 发送前终稿或已到达结论。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if C 端只要大众准备包，then 只分流不回改。

判断状态只许三值。口头转述、截图和「已读」不得写成已受理、已送达、已到达或期限已起算。事故认定书、调解记录不得单独写成民事终局比例。

## 本任务回链纪律

本任务成果是「人身损害通知的分相对人送达设计」。不包含：通知实体内容、法院诉讼送达实施、公证实施终稿、时效截止日、起诉状、保存或索赔正文。禁止已读单独到达。禁止诉讼内外规则互套。禁止选边治愈。禁止伪造签收。禁止倒签。禁止把对保险人到达写成对侵权人已中断。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标发送前终稿已形成。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接：已固定收件人线索、渠道缺口和到达状态。
风险档 A：不可逆文书或期限字段必须单独标可逆性。
