# 先予执行方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。稿件状态只用 `草案`、`申请闸关闭`、`提交前待核`、`停止`。禁止准许率、必然准许、唯一截止日、选定法院、自行宣布伤残等级、必得总额。未知金额不写零。本任务不代提交，不保证裁定，给付不得写成查封冻结。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、把先予执行写成保全、把尚未起诉写成应当裁定、把伤残金精神损害写入先予执行必得、把紧急裁定期间写成申请人今晚截止、把基金已付写成已经先予执行、把未知金额写零时记为噪声，不得写入 `L#`。禁止指导虚构紧急手术或伪造病历。

`Adv#` 固定列：`编号｜分型（紧急医疗费／必要生活费；伤残金、精神损害、全案标的填不打开）｜时机（诉中可开闸／尚未起诉闸关）｜申请人｜被申请人｜立案或受理回链｜紧急事实（回链病历费用；口述只S#）｜权利义务关系是否明确（三值）｜不先予执行将严重影响生活或生产经营（三值）｜被申请人履行能力（三值）｜请求金额（未知不写零、不写无限）｜已付互斥（医保／工伤基金／交强险或救助基金垫付分列）｜措施红旗（给付≠冻结）｜担保（可以责令，额度待核）｜败诉赔偿明示｜管辖连结点并列（不选唯一）｜紧急裁定期间红旗（对法院期间）｜复议接口（转应对人身案件保全裁定）｜状态｜来源回链`。一行一类给付。禁止一行混入伤残金、精神损害或全案标的。

## 节点 0　分流、立场、申请闸与不关窗

整案转出或闸关闭只交付第 1、2、10 节，不交申请书终稿、唯一截止日或应当裁定。闸部分打开时：仅对已有费用回链的医疗费或生活费行给出草案，伤残金行标 `不打开`。

| 信号 | 处理 |
| --- | --- |
| 只要财产或证据保全申请书 | 负触发 `准备财产或证据保全申请`；用户同时要冻和付：本窗只做给付行，保全另开，禁止并主文 |
| 尚未决定是否保全 | 负触发 `评估证据或财产保全必要性` |
| 只要对先予执行或保全裁定复议 | 负触发 `应对人身案件保全裁定`；本窗不写复议终稿，不得把给付改写成解冻 |
| 只要救助基金或交强险抢救垫付终稿 | 负触发 `申请道路救助基金或垫付`；并行不等于已经先予执行 |
| 只要交强险或商业三者材料包 | 负触发 `准备交强险商业险索赔材料` |
| 只要起诉状终稿 | 负触发 `提起人身损害一审`；尚未起诉时本窗闸关并转介起诉，窗口不关 |
| 只要测算终稿 | 负触发 `测算人身损害赔偿` |
| 纯劳动报酬先予执行且无人身紧急医疗费 | 整案转劳动；夹带人身紧急医疗费则医疗费行可留，报酬段分流 |
| 主轴仅工伤待遇且无对第三人给付 | 整案转劳动；夹带对第三人紧急医疗费则本窗正触发，工伤段分流，`Adv#` 可留并转介 `评估工伤与第三人侵权竞合` |
| 诊疗过错或医疗鉴定终稿 | 转医疗；对医疗机构的紧急医疗费给付可留 |
| 海事先予执行 | 转海事 |
| 未成争只要改合同 | 审查起草本窗搁置 |

申请闸打开条件（对某一行，同时满足）：单方无冲突申请方立场与授权；主成果是给付申请草稿而非保全、基金、诉状或测算；该行有紧急医疗费或必要生活费对象，可标 `S#` 或更强；材料能指称已进入诉讼或法律允许的阶段（已有立案或受理 `R#`）。

闸关闭（仍正触发）：尚未起诉、无受理 `R#`；完全无紧急事实却要「保证今晚裁定」；主文只要查封账户。「今晚必须裁」「保证准许」本身不得开闸写成应当裁定。尚未起诉转介 `提起人身损害一审`，可与起诉草稿并行，本窗不代写诉状终稿。

「保证裁定」「尚未起诉仍要终稿」「今晚必须裁」「伤残金精神损害进先予执行」「一律免担保」「基金已付等于已经先予执行」**不关窗**。闸未开则仍只交 1、2、10 节。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或受害人与被申请人同时交材料争同一份给付稿且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出虚构紧急手术、伪造病历或费用、倒签入院或手术时间、威胁或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　与保全区分和程序前提

先予执行是给付，保全是冻结或固定。两者可并行，文书必须分开。写入查封、冻结、扣划到法院账户即结案：该给付行 `现有依据不支持`，转介保全原子，窗口不关。

检索锚点：先予执行适用于受理案件后终审判决作出前，限于当事人诉讼请求范围。诉前紧急控制财产通常走保全，不得把诉前写成先予执行终稿已打开。尚未起诉：闸关闭，窗口不关。条号不是 `L#`。

情况紧急时人民法院作出裁定的期间（常见四十八小时）是对法院的期间，不是申请人「今晚必须交」的截止日。

## 节点 2　条件对照

三项条件分列三值，检索锚点，未核验则该格停止：

1. 当事人之间权利义务关系明确；
2. 不先予执行将严重影响申请人的生活或者生产经营；
3. 被申请人有履行能力。

责任争议巨大：关系明确格 `依据不足，无法形成结论`，申请仍可准备但风险高，不关窗，不得写成关系当然明确。无治疗紧急或生活困难事实：急需格 `现有依据不支持`，该行闸可关。履行能力无线索：该格依据不足，不得编造对方一定有钱或一定没钱。

劳动报酬、赡养、扶养、抚养、抚恤金另列，不与人身紧急医疗费同一行。

## 节点 3　范围、金额与已付互斥

仅紧急医疗费或必要生活费。残疾赔偿金、精神损害、误工截止、后续未知手术、全案标的写入申请主文：该格 `现有依据不支持` 或 `不打开`，窗口不关。未知后续手术标未知，禁止写进必得额，禁止写零。已发生未结以票据或费用清单回链。

医保已付、工伤基金已付、交强险或商业险垫付、救助基金已拨，必须分列扣减。禁止同一笔医疗费双领。已申请基金或保险公司口头垫付 **不等于** 已经先予执行，不得关窗，也不得标终稿 `已形成`。救助基金、交强险垫付只点转介名。

金额不超过已支持的急需范围，未知不写零也不写无限。

## 节点 4　担保返还与申请草稿

人民法院可以责令申请人提供担保，申请人不提供担保的，裁定驳回申请。未核验不得写成人身损害一律免担保，禁止默写唯一比例（含百分之三十）。申请人败诉的，应当赔偿被申请人因先予执行遭受的财产损失。必须写入自检，不得写成无风险。

对先予执行裁定不服可申请复议一次，复议期间不停止执行。复议终稿转 `应对人身案件保全裁定`。本窗不写复议稿，不得写成复议期间停止给付。

草稿栏目：当事人、请求给付项目与金额、事实与理由、三项条件对照、已付扣减、担保材料、费用清单与病历附件。状态 `草案` 或 `提交前待核`。不代提交。不得预填「此致某院」或依法应当准许。不利事实不删除。管辖连结点并列，不选定唯一法院。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过申请闸直接给可提交终稿或应当裁定。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if C 端只要大众准备包，then 只分流不回改。

判断状态只许三值。口头转述、截图和「已读」不得写成已受理、已裁定或期限已起算。事故认定书不得单独写成民事终局并据此必须先予执行。
