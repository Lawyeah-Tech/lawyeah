# 输出合同

按触发结果选择交付形状。申请闸未打开不得交付申请书终稿。禁止保证裁定或准许率。禁止选定唯一法院或预填「此致某院」。禁止写死唯一日历截止。禁止把四十八小时写成申请人今晚截止。禁止把先予执行写成查封冻结。禁止把伤残金、精神损害、后续未知手术或全案标的写入先予执行必得。禁止未知金额写零。禁止默写一律免担保。禁止选边治愈。禁止虚构手术步骤。不代提交。不定残。不保证裁定。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 申请闸关闭或节点 0 整案转出 | 第 1、2、10 节：关闭理由、程序前提待核和最小补证。禁止申请书终稿、应当裁定、唯一截止日。对第三人给付可留时不得因工伤整案转出 |
| 整体停止 | 第 1、10 节。禁止 `Adv#`、申请书、选边、虚构手术方法。双方秘密、同时交材料、虚构紧急手术、伪造病历第一次即停，优先于负触发；无选边治愈，无「坚持」门槛 |
| 用户要保证裁定、尚未起诉出终稿、今晚必须裁、伤残精神损害进先予执行（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；闸未开则仍只交 1、2、10；不得改走负触发关窗；成果不得标申请终稿 `已形成` 为应当裁定 |
| 正触发且闸开（可部分开） | 下列十节表头均出现；条件、担保、期间未核验的单元格填 `依据不足，无法形成结论` 或 `待核`；医疗费与生活费分列；禁止为填满而宣布应当裁定、写入全案标的或预填唯一法院 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入申请终稿已形成。双方秘密未解不得进入「部分形成」。每个 `Adv#` 必须带来源和三值判断。`L#` 不得直接抄技能内条号。保证裁定、先予执行等于保全、未知写零若返回则记噪声。稿件状态默认 `草案`。

## 1. 触发、单方立场、授权与成果状态

申请闸开、部分开或关。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。稿件默认 `草案`。

## 2. 来源登记与 MCP 调用表

`S/D/R/C/L/I/G/Adv/V`。口述紧急、保证今晚裁只登记 `S#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 申请闸、程序前提与保全区分

诉中可开闸。尚未起诉闸关并转介起诉。给付不是冻结。同时要冻账户只点保全名。

## 4. 条件对照

关系明确、急需、履行能力三值分列。责任争议巨大则明确性格依据不足，不关窗。

## 5. 范围与金额 `Adv#`

仅紧急医疗费或必要生活费。伤残金精神损害不打开。未知不写零。不是全案标的。

## 6. 已付互斥与并行垫付

医保、工伤基金、交强险、救助基金分列扣减。禁止双领。已申请基金不等于已经先予执行。

## 7. 担保与败诉返还

可以责令担保。禁止默写免担保或百分之三十。败诉须赔偿因先予执行所受损失。

## 8. 申请书草稿

当事人、给付项目、事实理由、条件对照、已付扣减、附件。草案，不代提交。不得写依法应当准许。不得预填唯一法院。

## 9. 复议接口与下一步

不服转 `应对人身案件保全裁定`。复议期间不停止执行。转介起诉、保全、基金、测算只点名。不选定法院。

## 10. 缺口、停止项与提示

须列对方最强解释：保证裁定、尚未起诉也能今晚裁、先予执行就是冻账户、伤残金精神损害必须先付、未知手术写零或写八十万、基金已申请等于已经先予执行、医保已付仍全额双领、一律免担保、选边即可继续、编一台急诊就能过。

本成果不是已提交申请、不是裁定、不是保全、不是救助基金、不是起诉状、不保证裁定、不是唯一截止日。不代提交。
