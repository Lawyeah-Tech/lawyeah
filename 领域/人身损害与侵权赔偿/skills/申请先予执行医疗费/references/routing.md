# 边界与路由

## 正触发

情况紧急，需要先行给付医疗费或生活费。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 财产或证据保全 | 保全原子 |
| 尚未符合程序前提 | 先评估起诉入口 |
| 全案一次性给付 | 判决或和解 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动报酬先予执行 | 劳动领域 |
| 海事先予执行 | 海事领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“手术费等不起，求法院先让对方付”正触发。“先冻他房子”走保全。“判决后再执行”走执行原子。
