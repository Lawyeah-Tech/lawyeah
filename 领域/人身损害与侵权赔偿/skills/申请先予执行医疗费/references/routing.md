# 边界与路由

## 正触发

情况紧急，需要先行给付医疗费或必要生活费。尚未起诉、用户要保证裁定、今晚必须裁、把伤残金精神损害写入先予执行或一律免担保仍正触发：申请闸可关，对应格停止，窗口不关。工伤待遇与对第三人紧急医疗费同时出现，仍正触发：工伤段分流劳动，对第三人 `Adv#` 可留。劳动报酬夹带人身医疗费，医疗费行可留。

双方秘密、同时交材料、虚构紧急手术、伪造病历的停止，优先于负触发。不得改走负触发去出申请书。保证裁定、尚未起诉不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 财产或证据保全申请书 | `准备财产或证据保全申请` |
| 尚未决定是否保全 | `评估证据或财产保全必要性` |
| 对先予执行或保全裁定复议、担保置换 | `应对人身案件保全裁定` |
| 救助基金或交强险抢救垫付申请终稿 | `申请道路救助基金或垫付` |
| 交强险或商业三者索赔材料包 | `准备交强险商业险索赔材料` |
| 起诉状终稿 | `提起人身损害一审` |
| 分项测算终稿 | `测算人身损害赔偿` |
| 后续治疗费另诉终稿 | `评估后续治疗费另行主张` |
| 纯劳动报酬先予执行且无人身紧急医疗费 | 劳动领域 |
| C 端只要大众准备包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「编一台今晚必须开的急诊」「伪造住院发票」不在本表，走整体停止。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 仅工伤待遇且无对第三人给付 | 劳动领域 |
| 劳动报酬先予执行且无人身紧急医疗费 | 劳动领域 |
| 海事先予执行 | 海事领域 |
| 指导虚构手术或伪造病历 | 整体停止 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。对第三人紧急医疗费可留。

## 易混

「手术费等不起，求法院先让对方付」正触发。「先冻他房子」走保全，本窗不写冻结。「还没起诉，保证今晚裁，把残疾金精神损害一共八十万写进去」仍正触发；闸关并转介起诉；保证裁定、全案标的、伤残精神损害各格不支持。「工伤还在认，对司机的抢救费要先付」正触发，给付行可留，工伤段分流。「救助基金已经申请了等于法院已经先予执行」仍正触发；基金≠先予执行。「两边材料都给你，选边写先予执行」整体停止。「二次手术还没做先写成零」该格不支持，未知不得写零。
