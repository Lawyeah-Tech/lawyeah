# 申请先予执行医疗费

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的申请方立场下，形成不代提交的先予执行申请包：申请闸、`Adv#` 紧急医疗费与必要生活费分表、三项条件对照、已付互斥、担保与败诉返还、申请书草案。先予执行是给付，不是查封或冻结。不保证裁定。不选定法院。不计算唯一截止日。未知金额不写零。不是全案标的。医保、工伤基金、交强险或救助基金已付须扣减提示，垫付并行不等于已经先予执行。

`depends-on` 为空。冻账户转 `准备财产或证据保全申请`。尚未决定是否保全转 `评估证据或财产保全必要性`。对先予执行裁定不服转 `应对人身案件保全裁定`。尚未起诉转介 `提起人身损害一审`。基金垫付转 `申请道路救助基金或垫付`。保险理赔材料转 `准备交强险商业险索赔材料`。

## 工作边界

正触发：情况紧急，需要先行给付医疗费或必要生活费。尚未起诉、送达不明、用户要「保证裁定」「今晚必须裁」「把伤残金精神损害写入先予执行」「一律免担保」仍正触发：申请闸可关，对应格填 `现有依据不支持` 或字段停止，窗口不关。工伤待遇与对第三人紧急医疗费同时出现：本窗正触发，工伤段分流劳动，对第三人的 `Adv#` 可留。劳动报酬夹带人身医疗费：医疗费行可留，报酬段分流劳动。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要财产或证据保全申请书（转 `准备财产或证据保全申请`）；
- 尚未决定是否保全（转 `评估证据或财产保全必要性`）；
- 只要对先予执行或保全裁定复议、担保置换（转 `应对人身案件保全裁定`）；
- 只要救助基金或交强险抢救垫付申请终稿（转 `申请道路救助基金或垫付`）；
- 只要交强险或商业三者索赔材料包（转 `准备交强险商业险索赔材料`）；
- 只要起诉状终稿（转 `提起人身损害一审`）；
- 只要分项测算终稿（转 `测算人身损害赔偿`）；
- 只要后续治疗费另诉终稿（转 `评估后续治疗费另行主张`）；
- 纯劳动报酬先予执行且无人身紧急医疗费（转劳动领域）；
- C 端只要大众准备包（只分流）；
- 未成争改合同（审查起草搁置）。

保证裁定、尚未起诉、全案标的、今晚必须裁**不在负触发表**，窗口不关。虚构紧急手术、伪造病历、双方秘密**不在负触发表**，走整体停止。

## 建立工作坐标

确认：使用者与授权；申请方；是否已立案或受理；治疗紧急程度与病历费用；对方给付能力线索；医保／工伤／保险／基金已付；请求项目；法域。

口头「保证今晚裁」「手术还没做先写八十万」「基金已经等于先予执行了」只登记 `S#`。不得写入应当裁定或必得总额。

同时掌握双方秘密，或受害人与被申请人同时交材料争同一份给付稿：`整体停止`，不得以选边治愈，也不得改走负触发去出一方申请。受害人已开口且委托范围就是先予执行申请、且未掌握对方秘密时，可推定申请方立场。只要同时掌握双方秘密，无例外整体停止。提出虚构紧急手术、伪造病历或费用、倒签入院或手术时间：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 病历、费用清单、收入；`R#` 立案或受理；`C#` 担保或保险、基金材料；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Adv#` 给付行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。稿件状态只用 `草案`、`申请闸关闭`、`提交前待核`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。不准许率。本任务默认 `草案`，不代提交。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：追索医疗费用、因情况紧急需要先予执行等可裁定先予执行；须当事人之间权利义务关系明确、不先予执行将严重影响申请人生活或生产经营、被申请人有履行能力；人民法院可以责令申请人提供担保，不提供担保的裁定驳回申请；申请人败诉应当赔偿被申请人因先予执行遭受的财产损失；对先予执行裁定不服可申请复议一次，复议期间不停止执行。技能正文条号不是 `L#`。噪声：已失效《侵权责任法》、先予执行等于保全、尚未起诉即可保证裁定、保证今晚裁定、把伤残金精神损害写入先予执行必得、紧急裁定期间写成申请人今晚截止、选定唯一法院、一律免担保、基金已付等于已经先予执行、未知金额写零。不可用则条件、担保、期间、管辖效力字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变程序前提、条件、担保或复议效果的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补诉中前提、关系不明确时难准许、超范围写入伤残精神损害被限缩、担保责令实践差异、不保证裁定的实务反例。
- `search_template` 只借先予执行申请书栏目，不把范本当法定格式、已提交文本或指定唯一法院。

工具不可用时继续当事人、费用和 `Adv#` 编目；条件、担保、期间、管辖效力字段停止。不得凭记忆写应当裁定、唯一截止日或唯一法院。

## 判断节点

执行顺序和停止条件以 [先予执行方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、申请闸与不关窗

工伤三段分流，对第三人给付可留。双方秘密或虚构手术第一次停。保证裁定、尚未起诉不关窗。保全负触发。

### 2. 与保全区分和程序前提

给付不是冻结。文书分开。尚未起诉闸关，转介起诉，窗口不关。

### 3. 条件对照

权利义务关系明确、急需、被申请人有履行能力，三值分列。责任争议巨大则明确性格依据不足，不关窗。

### 4. 范围、金额与已付互斥

仅紧急医疗费或必要生活费。未知不写零。伤残金精神损害不打开。医保工伤垫付分列扣减。

### 5. 担保返还与申请草稿

可以责令担保。败诉须赔偿。草案不代提交。不保证裁定。复议终稿转应对裁定窗。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；受害人与被申请人同时交材料；提出虚构紧急手术、伪造病历或费用、倒签入院或手术时间、威胁或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：三项条件、担保、期间、管辖未核验。尚未起诉则申请书终稿停止，窗口不关。用户要保证裁定、今晚必须裁、全案标的或伤残精神损害进先予执行则该格停止，窗口不关。
- `目标停止`：主目标变为保全申请、必要性评估、复议终稿、救助基金、交强险材料、起诉状或测算终稿。保证裁定、尚未起诉不在目标停止。

禁止指导虚构手术或伪造病历。不给准许率。不选定法院。不代提交。不编唯一截止日。不把未知写成零或必得总额。
