# 直接起诉保险公司

## 任务目标

在明确、无利益冲突的原告立场下，形成保险人诉讼地位与分项请求包：起诉闸、`Def#`（交强险应当共同被告／商业三者条款与直接请求核验后可列）、`P#` 分袋（交强险限额内／商业三者约定内／侵权人其余）、精神损害优先开闭（须被侵权人或近亲属提出）、管辖连结点并列、不代提交诉状草案。垫付医疗费不等于可不列交强险。不保证限额内全额。不选定法院。拒赔不是起诉前提。交强险索赔、直接请求与对侵权人诉讼原则上可并行。同时起诉时按交强险→商业三者→侵权人分项，检索锚点民法典第一千二百一十三条，条号不是 `L#`。

`depends-on` 为空。只诉侵权人且不要保险人地位的完整一审包转 `提起人身损害一审`。路径比较转 `选择诉讼调解或保险先行`。分账转 `评估道路交通事故责任与保险先行`。材料包转 `准备交强险商业险索赔材料`。保险人应诉转 `保险公司应对直接索赔`。已立案追加转 `追加变更责任主体`。

## 工作边界

正触发：已决定同时或单独起诉交强险或商业三者保险人（可与侵权人并列）。「司机和保险公司一起告」且主成果含保险人地位或分项请求，正触发。保证限额内全额、只列某院、商业三者当然可列或当然不列、交强险未赔不能起诉、精神损害当然进交强险、垫付后可不列交强险，仍正触发：起诉闸可关，对应格填 `现有依据不支持` 或字段停止，窗口不关，不得改走负触发，不得标诉状终稿已形成。工伤待遇与对第三人保险人请求同时出现：本窗正触发，工伤段分流劳动，对第三人的 `Def#`／`P#` 可留。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果已是不含保险人、只诉侵权人的一审完整起诉包（转 `提起人身损害一审`）；
- 主成果是保险人应诉或答辩（转 `保险公司应对直接索赔`）；
- 只要索赔材料包（转 `准备交强险商业险索赔材料`）；
- 只要交强险分账或第七十六条对照（转 `评估道路交通事故责任与保险先行`）；
- 只要主体名单或保险能否进入（转 `评估责任主体与保险覆盖`）；
- 只要路径比较（转 `选择诉讼调解或保险先行`）；
- 只要拒赔减赔拆解（转 `应对保险拒赔减赔`）；
- 只要印好了结审查（转 `审查保险一次性了结弃权`）；
- 只要先予执行申请（转 `申请先予执行医疗费`）；
- 只要救助基金申请（转 `申请道路救助基金或垫付`）；
- 已立案只要追加变更被告（转 `追加变更责任主体`）；
- 只要测算终稿（转 `测算人身损害赔偿`）；
- 纯工伤待遇且无第三人保险人请求（转劳动）；
- C 端只要大众准备包（只分流）；
- 未成争改合同（审查起草搁置）。

保证限额内全额、选定法院、商业三者当然可列、未赔不能起诉、精神损害当然优先、垫付后可不列**不在负触发表**，窗口不关。伪造保单、倒签出险、骗保、双方秘密、编造保险人**不在负触发表**，走整体停止。

## 建立工作坐标

确认：使用者与授权；原告及近亲属；交强险与商业三者分袋；保险人名称是否足以与他人相区别；是否列侵权人；当事人是否请求加入商业三者；精神损害是否已提出；已赔、垫付、基金；治疗是否相对稳定、鉴定状态；管辖材料；是否已有案号；法域。

口头「限额内全拿」、微信保单截图、已读只登记 `S#`／`V#`。不得升格为已承保、已赔清、已受理或时效已中断。用户坚持「就去某区法院」「垫过就别列保险公司」不构成选定法院或删除交强险被告的授权。

同时掌握双方秘密，或受害人与侵权人、保险人同时交材料争同一份诉保稿：`整体停止`，不得以选边治愈，也不得改走负触发去出一方诉状。受害人已开口且委托范围就是起诉保险人、且未掌握对方秘密时，可推定原告立场。只要同时掌握双方秘密，无例外整体停止。提出伪造或编造保单、保险人名称或保单号，倒签出险日，顶包骗保，逃逸未知名仍虚构保险人，要求产出含未知伤残概括弃权的诉请：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 保单、认定书、票据；`C#` 保险索赔或赔付凭证；`R#` 立案或案号；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Def#` 被告；`P#` 请求；`J#` 管辖连结点；`V#` 诉状版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。稿件状态只用 `草案`、`起诉闸关闭`、`提交前待核`、`停止`。金额状态只用 `已核实金额`、`情景金额`、`无法估计`。技能正文中的条号是检索锚点，不是已核验 `L#`。不准许率。本任务默认 `草案`，不代提交。禁止「限额内全额」「此致某院」「商业三者当然可列」。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：交强险被侵权人直接请求；道路交通事故损害赔偿中承保交强险的保险公司应当列为共同被告（已在限额内实际赔付且当事人无异议除外，垫付不等于除外）；同时起诉侵权人与保险人时的赔偿顺序；商业三者诉讼地位须核验条款和法律，当事人请求加入与第三者直接请求分列，未核验不得当然列或当然不列；精神损害在交强险内优先须被侵权人或近亲属提出；管辖连结点分列。技能正文条号不是 `L#`。噪声：已失效《侵权责任法》、已失效《合同法》、交强险未赔不能起诉、保证限额内全额、商业三者当然可列、精神损害当然进交强险、只列保险公司所在地某院、垫付后可不列交强险、营业部当然有管辖权、口头或已读即已受理、已废止交强险旧限额。不可用则直接请求、共同被告、商业三者地位、精神损害优先、管辖效力字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变保险人被告地位、直接请求、精神损害优先或管辖结论的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补垫付后仍应列交强险、商业三者直接列因条款被驳、精神损害未提出不得优先、保险人住所地不当然唯一管辖的实务反例。
- `search_template` 只借起诉状栏目，不把范本当法定格式、已提交文本或指定唯一法院。

工具不可用时继续 `Def#`／`P#` 编目与事实；直接请求、共同被告、商业三者地位、精神损害优先、管辖字段停止。不得凭记忆写成保证限额内全额、商业三者当然可列、选定法院或交强险未赔不能起诉。

## 判断节点

执行顺序和停止条件以 [直接起诉保险人方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、起诉闸与不关窗

工伤三段分流，对第三人保险人可留。双方秘密、伪造保单第一次停。保证限额内全额、选定法院、未赔不能起诉不关窗。只要不含保险人的一审包负触发。

### 2. 被告结构 `Def#`

交强险应当共同被告，垫付不得除外。商业三者请求加入与直接请求分列待核。不得编造保险人。只列保险人须有直接请求回链。

### 3. 分项请求 `P#`

交强险限额内、商业三者约定内、侵权人其余分袋。精神损害优先须提出。未知不写零。不保证限额内全额。

### 4. 管辖连结点

侵权地、各被告住所地、保险人住所地并列。营业部不当然打开管辖。不选定法院。不预填「此致某院」。

### 5. 诉状草案、已赔扣减与并行

草案不代提交。已赔、垫付、基金分列扣减。理赔与起诉可并行。已有案号停止起诉入口。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；受害人与侵权人、保险人同时交材料；伪造或编造保单、保险人名称或保单号；倒签出险日；顶包、隐瞒伤情骗保；逃逸未知名仍虚构保险人；要求产出含未知伤残或「永不追究一切」的诉请。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：直接请求、共同被告、商业三者地位、精神损害优先、管辖、限额未核验。起诉闸未开则诉状终稿停止，窗口不关。用户要保证限额内全额、选定法院、商业三者当然可列、未赔不能起诉、精神损害当然优先或垫付后可不列则该格停止，窗口不关。
- `目标停止`：主目标变为只诉侵权人完整一审包、保险人应诉、材料包、分账、路径比较、拒赔拆解、了结审查、先予执行、基金或追加终稿。保证限额内全额、选定法院不在目标停止。

禁止指导伪造保单、倒签或骗保。不给胜诉率。不选定法院。不代提交。不编唯一截止日。不把未知写成零。不定残。不保证限额内全额。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。起诉闸未打开时不得交付诉状终稿或保证限额内全额。节点 0 整案转出或整体停止时不得填满十节实体。边界见 [路由](references/routing.md)。
