# 直接起诉保险人方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。稿件状态只用 `草案`、`起诉闸关闭`、`提交前待核`、`停止`。金额状态只用 `已核实金额`、`情景金额`、`无法估计`。禁止胜诉率、必然责任比例、唯一必得总额、唯一截止日、选定法院、自行宣布伤残等级、保证限额内全额。未知金额不写零。本任务不代提交。拒赔不是起诉前提。商业三者不得写成全国一律可直接列或一律不能列。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》、已失效《合同法》、把交强险未赔写成不能起诉、把商业三者写成当然可列、把垫付写成可不列交强险、把精神损害写成无需提出即优先、把营业部写成当然管辖、把旧十一万／一万写成现行限额时记为噪声，不得写入 `L#`。禁止指导伪造保单、倒签出险或骗保。

`Def#` 固定列：`编号｜主体类型（交强险保险人／商业三者保险人／侵权人／投保义务人）｜名称可识别性｜列法（交强险应当共同被告／商业三者当事人请求加入待核／保险法直接请求待核／不打开／逃逸不得编造）｜直接请求权（打开／待核／不打开）｜保单或分支机构表面｜已赔例外（限额内实际赔清且无异议才可不列交强险；垫付≠除外）｜是否营业部或营销服务部｜状态｜来源回链`。一行一主体。禁止一行打包「保险公司们」。禁止编造保单号或保险人名称。

`P#` 固定列：`编号｜责任层（交强险限额内／商业三者约定内／侵权人其余；检索锚点民法典第一千二百一十三条）｜项目｜金额状态（已核实／情景／无法估计；未知不写零）｜精神损害优先（已提出才打开／未提出不打开）｜已赔、垫付、基金扣减｜互斥（被扶养人生活费计入残疾或死亡赔偿金，禁止双计）｜状态｜来源回链`。一行一层一项。禁止合成「限额内全额」。鉴定闸关闭则残疾金、护理依赖 `无法估计`，禁止十级折现。

口头「限额内全拿」、微信截图、已读只进 `S#`／`V#`，不得升格已承保、已赔清、已受理或时效已中断。

## 节点 0　分流、立场、起诉闸与不关窗

整案转出或闸关闭只交付第 1、2、10 节或标注停止的 `Def#`／`P#`，不得交付诉状终稿，不得标限额内全额或选定某院。闸部分打开时：仅对名称可识别且列法可回链的主体给出草案，其余行停止或不打开。

| 信号 | 处理 |
| --- | --- |
| 主成果已是不含保险人、只诉侵权人的一审完整起诉包 | 负触发 `提起人身损害一审`；「司机和保险公司一起告」且含保险人地位仍留本窗 |
| 主成果是保险人应诉或答辩 | 负触发 `保险公司应对直接索赔` |

| 只要分账或第七十六条对照 | 负触发 `评估道路交通事故责任与保险先行` |
| 只要主体名单或保险能否进入 | 负触发 `评估责任主体与保险覆盖` |
| 只要路径比较 | 负触发 `选择诉讼调解或保险先行` |
| 只要拒赔减赔拆解 | 负触发 `应对保险拒赔减赔` |
| 只要印好了结审查 | 负触发 `审查保险一次性了结弃权` |

起诉闸打开（可出 `Def#`／`P#` 与诉状草案，仍不代提交、不保证受理或限额内全额）须同时满足：单方无冲突原告立场与授权；主成果是保险人地位与分项请求（可含诉状草案栏目），不是只诉侵权人完整一审包、不是材料包、不是应诉、不是分账终稿；人身损害已发生或声称已发生；至少一名保险人名称足以与他人相区别，或交强险应当共同被告接口可回链；不得用编造保单补齐。

闸关闭（仍正触发）：只列某区法院；保证限额内全额；商业三者当然可列或当然不列；交强险未赔就不能起诉；精神损害当然进交强险；垫付后可不列交强险；已读起算；未稳定写确定残疾金。闸未开则仍只交 1、2、10 节。

「保证限额内全额」「选定法院」「商业三者当然可列」「未赔不能起诉」「精神损害当然优先」「垫付后可不列」**不关窗**。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密，或受害人与侵权人、保险人同时交材料争同一份诉保稿且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出伪造或编造保单、保险人名称或保单号，倒签出险日，顶包骗保，逃逸未知名仍虚构保险人，或要求产出含未知伤残或「永不追究一切」的诉请，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　被告结构 `Def#`

**交强险。** 被侵权人可直接请求保险人。道路交通事故损害赔偿中，承保交强险的保险公司通常**应当**列为共同被告。除外仅当：已在交强险责任限额范围内**实际赔偿完毕**且当事人无异议，并有赔付凭证。垫付医疗费、预付、抢救费垫付 **不能** 打开除外。用户坚持不列：该 `Def#` 仍保留并字段停止，**不得删除**。检索锚点：交强险被侵权人直接请求；道交损害赔偿交强险共同被告。条号不是 `L#`。

**商业三者。** 两条路径分列，未核验不得当然列、也不得当然不列：
1. 道路交通事故中当事人**请求**将其列为共同被告，法院应予准许——须用户请求回链；
2. 责任保险第三者直接请求：被保险人对第三者应负赔偿责任已确定，且被保险人怠于请求时，第三者有权直接向保险人请求——须运行时核验保险法责任保险条款。道交解释「请求加入」≠保险法单独直接请求。未核验该行待核。

**只列保险人、不列侵权人。** 须有直接请求权回链，否则依据不足，窗口不关。逃逸、机动车或保险人未知名：停止该保险人行，**不得编造**；转介 `评估侵权人不明路径`、`申请道路救助基金或垫付`。

**分支机构。** 依法设立并领取营业执照的保险公司分支机构可作为当事人。营业部、营销服务部不当然等于有当事人能力的分公司，该行待核。保单仲裁条款原则上不当然阻断受害人对交强险的法定共同被告诉讼，效果待核。

## 节点 2　分项请求 `P#`

同时起诉侵权人与保险人时，按交强险限额内 → 商业三者约定内 → 侵权人其余分袋。检索锚点：民法典第一千二百一十三条。条号不是 `L#`。禁止打包「保险公司全赔」。禁止按民事比例扣交强险。

精神损害优先在交强险死亡伤残限额内排序，**须被侵权人或近亲属提出**；未提出不得自动优先；只改排序、不增加限额。未投保无此接口。本窗只标开闭，酌定转 `评估精神损害赔偿`。

被扶养人生活费计入残疾或死亡赔偿金，禁止双计。未知不写零。鉴定闸：急救未结束、内固定未取、伤残未鉴定 → 残疾金、护理依赖 `无法估计`，禁止评残申请或预估等级写入诉状。打开接口 ≠ 限额内必得。无责档、分项用尽、本车人员除外、免责待核。用户要限额内全额：该格 `现有依据不支持`，窗口不关。已废止旧限额不得默写。

## 节点 3　管辖连结点

侵权行为实施地、结果发生地、各被告住所地、保险人住所地分列回链。**任何情况下都不选定唯一法院**，起诉状不得预填「此致某院」。用户指定某院只登记 `S#`，该格停止，窗口不关。保险公司所在地不当然唯一有权。营业部住所不当然打开对驾驶人的管辖。展开转 `评估人身损害管辖`。时效只打红旗，已读、口头报案不得起算或中断，对保险人主张不当然覆盖对侵权人，转 `评估人身损害诉讼时效`。

---

## 节点 4　诉状草案、已赔扣减与并行

草稿栏目只借范本结构。状态默认 `草案`。闸打开且无停止的 `Def#`／`P#` 才得标 `提交前待核`。不代提交、不代签署、不代立案。不利事实不删除。保全和先予执行只做红旗，终稿转对应原子。

已赔、垫付、基金、医保必须分列扣减，禁止双计。限额内付款不当然消灭对侵权人其余请求。交强险索赔、直接请求、起诉侵权人默认可并行。拒赔不是起诉条件。「未赔就不能起诉」该格不支持。已有案号停止起诉入口，追加转 `追加变更责任主体`。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过起诉闸直接给限额内全额、选定法院或商业三者当然可列。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if C 端只要大众准备包，then 只分流不回改。

判断状态只许三值。口头转述、截图和「已读」不得写成已受理、已承保、已赔清或期限已起算。事故认定书不得单独写成民事终局比例并据此只告或不告保险人。

## 本任务回链纪律

本任务成果是「不代提交的保险人诉讼地位与分项请求草案」。必须包含：交强险应当共同被告、商业三者待核、精神损害优先须提出。不包含：只诉侵权人完整一审包、保险人应诉、材料包、分账终稿、路径选择终稿。禁止保证限额内全额。禁止选定法院。禁止垫付后可不列交强险。禁止未赔不能起诉。禁止选边治愈。禁止编造保险人。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标诉状终稿已形成。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接。
风险档 A：不可逆起诉或概括弃权诉请必须单独标可逆性。
