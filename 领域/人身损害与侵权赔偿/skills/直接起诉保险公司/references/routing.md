# 边界与路由

## 正触发

决定同时或单独起诉交强险或商业三者保险人。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只诉侵权人 | `提起人身损害一审` |
| 保险人应诉 | `保险公司应对直接索赔` |
| 理赔材料 | `准备交强险商业险索赔材料` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 工伤保险待遇之诉 | 劳动领域 |
| 医疗责任保险主轴 | 医疗医药领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“把保险公司和司机一起告”正触发。“只告司机”走普通起诉。“我是保险公司被告了”走保险人应诉。
