# 边界与路由

## 正触发

已决定同时或单独起诉交强险或商业三者保险人（可与侵权人并列）。「司机和保险公司一起告」且主成果含保险人地位或分项请求，正触发。保证限额内全额、只列某院、商业三者当然可列、交强险未赔不能起诉、精神损害当然进交强险、垫付后可不列交强险，仍正触发：起诉闸可关，对应格停止，窗口不关。工伤待遇与对第三人保险人请求同时出现，仍正触发：工伤段分流劳动，对第三人 `Def#`／`P#` 可留。

双方秘密、伪造保单、倒签出险、编造保险人的停止，优先于负触发。不得改走负触发去出一方诉状。保证限额内全额、选定法院不在下表。伪造骗保不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 不含保险人、只诉侵权人的一审完整起诉包 | `提起人身损害一审` |
| 保险人应诉或答辩 | `保险公司应对直接索赔` |
| 交强险或商业三者索赔材料包 | `准备交强险商业险索赔材料` |
| 交强险分账或第七十六条对照 | `评估道路交通事故责任与保险先行` |
| 主体名单或保险能否进入 | `评估责任主体与保险覆盖` |
| 保险理赔、调解、起诉哪条更适配 | `选择诉讼调解或保险先行` |
| 拒赔减赔拆解 | `应对保险拒赔减赔` |
| 保险人了结或权益转让审查 | `审查保险一次性了结弃权` |
| 先予执行申请书 | `申请先予执行医疗费` |
| 救助基金或垫付申请 | `申请道路救助基金或垫付` |
| 已立案后追加变更被告 | `追加变更责任主体` |
| 分项测算终稿 | `测算人身损害赔偿` |
| 纯工伤待遇且无第三人保险人请求 | 劳动领域 |
| C 端只要大众准备包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「编一个保单号先立案」「倒签出险日」「两边材料都给你选边」不在本表，走整体停止。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 仅工伤待遇且无第三人保险人请求 | 劳动领域 |
| 诊疗过错或医疗鉴定终稿 | 医疗医药领域；对医疗机构责任险的民事请求可留待核 |
| 海事专门程序 | 海事领域 |
| 指导伪造保单、倒签出险、骗保或编造保险人 | 整体停止 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。对第三人保险人诉讼可留。

| 信号 | 转介 |

| 先赔还是先告 | `选择诉讼调解或保险先行` |

| 时效中断展开 | `评估人身损害诉讼时效` |

## 易混

「把保险公司和司机一起告，保险公司怎么列、商业三者能不能列」正触发。「只告司机、不要保险公司」走一审窗。「我是保险公司被告了」走保险人应诉。「交强险限额怎么分」走分账。「先找保险公司还是先起诉」走路径选择。「垫过抢救费就别列交强险、就去保险公司注册地某区法院、限额内全拿、精神损害不用写也优先、商业三者当然可列、没赔完不能告」仍正触发；起诉闸关；交强险共同被告保留；商业三者待核；保证全额、选定法院、未赔不能起诉、精神损害未提出各格不支持。「工伤还在认，要告对方交强险」正触发，第三人行可留，工伤段分流。「逃逸先写一家保险公司顶上」或「两边材料都给你选边」整体停止。
