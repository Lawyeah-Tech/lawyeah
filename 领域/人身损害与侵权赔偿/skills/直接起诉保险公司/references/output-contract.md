# 输出合同

按触发结果选择交付形状。起诉闸未打开不得交付诉状终稿或保证限额内全额。禁止选定唯一法院或预填「此致某院」。禁止商业三者全国一律可直接列或一律不能列。禁止交强险未赔就不能起诉。禁止精神损害未提出即自动优先。禁止垫付后可不列交强险。禁止保证限额内全额。禁止未知金额写零。禁止胜诉率。禁止选边治愈。禁止编造保单或保险人。不代提交。不定残。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 起诉闸关闭或节点 0 整案转出 | 第 1、2、10 节：关闭理由、被告待核和最小补证。可附标注停止的 `Def#`／`P#`。禁止诉状终稿、限额内全额、选定某院。对第三人保险人可留时不得因工伤整案转出 |
| 整体停止 | 第 1、10 节。禁止 `Def#`／`P#` 诉状包、选边、伪造保单或倒签方法。双方秘密、伪造保单、倒签出险、编造保险人第一次即停，优先于负触发；无选边治愈，无「坚持」门槛 |
| 用户要保证限额内全额、只列某院、商业三者当然可列、未赔不能起诉、精神损害当然优先、垫付后可不列（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；闸未开则仍只交 1、2、10；不得改走负触发关窗；成果不得标诉状终稿 `已形成` 或限额内全额 |
| 正触发且闸开（可部分开） | 下列十节表头均出现；直接请求、商业三者地位、精神损害优先、管辖未核验的单元格填 `依据不足，无法形成结论` 或 `待核`；交强险与商业三者分列；禁止为填满而宣布限额内全额、选定法院或商业三者当然可列 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入诉状终稿已形成。双方秘密未解不得进入「部分形成」。每个 `Def#`／`P#` 必须带来源和三值判断。`L#` 不得直接抄技能内条号。未赔不能起诉、商业三者当然可列、保证限额内全额若返回则记噪声。稿件状态默认 `草案`。

## 1. 触发、单方立场、授权与成果状态

起诉闸开、部分开或关。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。稿件默认 `草案`。不代提交。

## 2. 来源登记与 MCP 调用表

`S/D/C/R/L/I/G/Def/P/J/V`。口头限额内全拿、已读、保单截图只登记 `S#`／`V#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 被告结构 `Def#`

交强险应当共同被告；垫付不得除外。商业三者请求加入与直接请求分列待核。不得编造。只列保险人须有直接请求回链。

## 4. 分项请求 `P#`

交强险限额内、商业三者约定内、侵权人其余分袋。未知不写零。鉴定闸关闭则残疾金无法估计。不保证限额内全额。

## 5. 精神损害优先开闭

须被侵权人或近亲属提出。未提出不打开。只改排序、不增加限额。

## 6. 管辖连结点 `J#`

侵权地、各被告住所地、保险人住所地并列。营业部不当然打开。不选定法院。不预填「此致某院」。

## 7. 诉状与证据目录草稿

当事人、诉讼请求、事实理由、证据目录。草案，不代提交。不利事实不删除。不得写依法应当全额支持。

## 8. 已赔扣减与并行

交强险、商业险、侵权人、基金、医保分列扣减。禁止双计。理赔与起诉可并行。拒赔不是起诉前提。

## 9. 红旗与下一步

保全、先予执行只点名。已有案号转追加。转介一审、分账、材料包、管辖、时效、精神损害、工伤竞合只点名。不选定法院。

## 10. 缺口、停止项与提示

须列对方最强解释：交强险没赔完就不能告、必须先理赔拒了再起诉、限额内肯定全拿、商业三者当然可列或当然不能列、精神损害不用写也进交强险、垫过抢救费就别列交强险、就去保险公司注册地某区法院、营业部当然有管辖权、微信已读时效已经中断、认定书全责所以只告或不告保险公司、工伤还在认所以不能告对方保险公司、编一个保单号先立案、选边即可继续、倒签出险日就能进保单期间。

本成果不是已提交诉状、不是限额内必得、不是材料包、不是分账终稿、不是应诉、不是追加申请、不保证受理、不是唯一截止日。不代提交。
