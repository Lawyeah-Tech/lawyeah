# 边界与路由

## 正触发

立案后发现应追加或变更用人者、场所、保险人或其他义务人。「立案了才发现有交强险」正触发。尚未起诉也要追加、保证准许、选定某院、辩论终结后保证能追加、漏列交强险不用追加、商业三者当然可列、垫付后可不列交强险、无新主体事实仍要随意追加，仍正触发：追加闸可关，对应格停止，窗口不关。工伤待遇与对第三人追加同时出现，仍正触发：工伤段分流劳动，对第三人 `Add#` 可留。

双方秘密、编造新被告、伪造劳动关系或保单的停止，优先于负触发。不得改走负触发去出一方申请。尚未起诉、保证准许不在下表。编造伪造不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 诉前完整一审起诉状 | `提起人身损害一审` |
| 诉前保险人诉讼地位起诉入口 | `直接起诉保险公司` |
| 主体名单或保险能否进入 | `评估责任主体与保险覆盖` |
| 被告反诉或抵销 | `评估反诉或抵销` |
| 执行阶段变更或追加被执行人 | `执行人身损害生效文书`／`应对人身损害执行` |
| 管辖或时效终稿 | `评估人身损害管辖`／`评估人身损害诉讼时效` |
| 连带按份形态终稿 | `评估共同侵权与连带按份` |
| 刑附民应否列或另行民事 | `评估刑附民与另行起诉` |
| 纯工伤待遇或劳动被申请人追加且无第三人 | 劳动领域 |
| C 端只要大众准备包 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「编一个物业名先追加」「倒签劳动合同」「两边材料都给你选边」不在本表，走整体停止。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 仅工伤待遇或劳动被申请人且无第三人 | 劳动领域 |
| 诊疗过错或医疗鉴定终稿 | 医疗医药领域；对医疗机构的民事追加可留 |
| 海事专门程序 | 海事领域 |
| 指导编造被告、伪造保单或倒签 | 整体停止 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。对第三人追加可留。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 尚未起诉、无案号 | `提起人身损害一审`／`评估责任主体与保险覆盖`／`直接起诉保险公司`（闸关不关窗） |
| 该列谁、保险能不能进 | `评估责任主体与保险覆盖` |
| 逃逸未知名、不能指明 | `评估侵权人不明路径` |
| 用人者地位展开 | `评估用人者责任` |
| 场所补充责任展开 | `评估场所安全保障义务` |
| 连带按份展开 | `评估共同侵权与连带按份` |
| 管辖连结点展开 | `评估人身损害管辖` |
| 对新被告时效展开 | `评估人身损害诉讼时效` |
| 工作中第三人 | `评估工伤与第三人侵权竞合` |
| 被告要反诉 | `评估反诉或抵销` |
| 执行里追加 | `执行人身损害生效文书`／`应对人身损害执行` |
| 刑事在侦 | `分流刑民交叉`／`评估刑附民与另行起诉` |

## 易混

「立案了才发现有交强险」正触发。「还没立案列谁」：窗口不关，追加闸关，转介起诉或主体评估，不得写成负触发踢走。「被告要反诉」走反诉。「执行里追加保险人」走执行。「垫过抢救费别追加交强险、保证准许、就追加到某区法院、庭辩完了也能追加」仍正触发；交强险行保留；保证准许、选定法院、辩论终结后必准各格不支持。「工伤还在认，要追加对方保险公司和用人单位」正触发，第三人行可留，工伤段分流。「编个物业名先追加、两边材料都给你选边」整体停止。
