# 边界与路由

## 正触发

立案后发现应追加用人者、场所、保险人或其他义务人。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 尚未起诉 | `提起人身损害一审` 或主体评估 |
| 反诉 | `评估反诉或抵销` |
| 执行追加 | 执行原子或程序法待核 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动被申请人追加 | 劳动领域 |
| 医疗共同被告主轴 | 医疗医药领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“立案了才发现有交强险”正触发。“还没立案列谁”走主体评估或起诉。“被告要反诉”走反诉。
