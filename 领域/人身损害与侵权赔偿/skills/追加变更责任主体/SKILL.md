# 追加变更责任主体

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的原告立场下，形成不代提交的追加或变更申请包：追加闸、`Add#`（用人者／场所／交强险应当共同被告／商业三者待核／共同侵权人）、必要共同与普通追加分列、请求调整（不整状重写除非必要）、管辖与时效红旗并列、申请草案。不保证准许。不选定法院。不编造被告。一审辩论终结后、二审限制更严，不得写成与一审相同。执行阶段追加被执行人不是本任务。

`depends-on` 为空。尚未起诉转介 `提起人身损害一审`／`评估责任主体与保险覆盖`／`直接起诉保险公司`，本窗不写起诉状终稿。反诉转 `评估反诉或抵销`。执行追加转 `执行人身损害生效文书`／`应对人身损害执行`。主体总评估转 `评估责任主体与保险覆盖`。不明主体转 `评估侵权人不明路径`。

## 工作边界

正触发：立案后发现应追加或变更用人者、场所、保险人或其他义务人。「立案了才发现有交强险」正触发。尚未起诉也要追加、保证准许、选定某院、辩论终结后保证能追加、漏列交强险不用追加、商业三者当然可列、垫付后可不列交强险、无新主体事实仍要随意追加，仍正触发：追加闸可关，对应格填 `现有依据不支持` 或字段停止，窗口不关，不得改走负触发，不得标申请终稿已形成。工伤待遇与对第三人追加同时出现：本窗正触发，工伤段分流劳动，对第三人的 `Add#` 可留。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果已是诉前完整一审起诉状（转 `提起人身损害一审`）；
- 主成果是诉前保险人诉讼地位起诉入口（转 `直接起诉保险公司`）；
- 只要主体名单或保险能否进入（转 `评估责任主体与保险覆盖`）；
- 被告侧反诉或抵销（转 `评估反诉或抵销`）；
- 执行阶段变更或追加被执行人（转 `执行人身损害生效文书`／`应对人身损害执行`）；
- 只要管辖或时效终稿（转 `评估人身损害管辖`／`评估人身损害诉讼时效`）；
- 只要连带按份形态终稿（转 `评估共同侵权与连带按份`）；
- 刑附民应否列共同被告或另行民事（转 `评估刑附民与另行起诉`）；
- 纯工伤待遇或劳动被申请人追加且无第三人主体（转劳动）；
- C 端只要大众准备包（只分流）；
- 未成争改合同（审查起草搁置）。

尚未起诉、保证准许、选定法院、辩论终结后必准、漏列交强险不用追加、无新事实仍要追加**不在负触发表**，窗口不关。编造被告、伪造保单或劳动关系、双方秘密**不在负触发表**，走整体停止。

## 建立工作坐标

确认：使用者与授权；案号或受理凭证 `R#`；现有被告；拟追加主体及名称是否足以与他人相区别；新主体事实（保单、用工、场所）；审理阶段（一审辩论终结前／后、二审、执行误入）；是否列交强险／商业三者；法域。

口头「立案了」、截图、「已读」只登记 `S#`／`V#`。不得升格为已受理、已送达新被告、答辩期已起算或审限已变。用户坚持「保证准许」「就追加到某院」不构成准许或选定法院的授权。

同时掌握双方秘密，或受害人与拟追加的用人单位、保险人、场所同时交材料争同一份追加稿：`整体停止`，不得以选边治愈，也不得改走负触发。受害人已开口且委托范围就是追加申请、且未掌握对方秘密时，可推定原告立场。只要同时掌握双方秘密，无例外整体停止。提出编造被告、单位、保险人名称或保单号，伪造劳动关系或保单，倒签入职或出险日，逃逸未知名仍虚构主体，「先随便列一个再补」：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 新证据、保单、劳动关系材料；`R#` 立案受理；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Add#` 追加行；`P#` 因追加必须改的请求行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。稿件状态只用 `草案`、`追加闸关闭`、`提交前待核`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。不准许率。本任务默认 `草案`，不代提交。禁止「法院应当准许」「此致某院」「漏列交强险不用追加」。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：必须共同进行诉讼的当事人未参加，人民法院应当通知其参加，当事人也可申请追加；理由不成立裁定驳回；受理后法庭辩论结束前增加诉讼请求可合并；道路交通事故中承保交强险的保险公司应当列为共同被告（限额内实际赔清且无异议除外，垫付不等于除外）；商业三者须当事人请求加入；二审必须参加诉讼的当事人一审未参加的，可调解，调解不成发回，不得写成与一审相同。技能正文条号不是 `L#`。噪声：已失效《侵权责任法》、已失效《合同法》、尚未起诉即可出追加终稿、保证准许、选定某院、辩论终结后必能追加、漏列交强险不用追加、垫付后可不列交强险、把执行变更追加被执行人写成诉讼追加、口头或已读即已受理或已送达。不可用则追加条件、必要共同、辩论终结效果、保险人地位、管辖时效字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变追加条件、必要共同、辩论终结效果或保险人被告地位的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补辩论终结后难准许、二审追加更严、垫付后仍应列交强险、必要共同与普通追加被驳的实务反例。
- `search_template` 只借追加或变更申请栏目，不把范本当法定格式、已提交文本或指定唯一法院。

工具不可用时继续 `Add#` 编目与事实；追加条件、必要共同、辩论终结效果、保险人地位、管辖时效字段停止。不得凭记忆写成保证准许、选定法院、尚未起诉也能出追加终稿或漏列交强险不用追加。

## 判断节点

执行顺序和停止条件以 [追加主体方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、追加闸与不关窗

工伤三段分流，对第三人追加可留。双方秘密、编造被告第一次停。尚未起诉、保证准许不关窗。只要起诉状终稿负触发。

### 2. 拟追加主体 `Add#`

一行一主体。交强险应当追加，垫付不得除外。商业三者待核。不能指明则不打开，转不明路径。

### 3. 必要共同与普通追加、阶段

必要共同应当追加 ≠ 保证准许。普通追加可以不准许。一审辩论终结后、二审闸收紧。执行误入转出。

### 4. 请求调整、时效管辖红旗

不当然重写整状。对新被告时效、管辖分列，不写死截止日，不选定法院。

### 5. 申请草稿、送达与审限

草案不代提交。已读不得起算。不保证准许。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；受害人与拟追加单位、保险人同时交材料；编造被告、单位、保险人名称或保单号；伪造劳动关系或保单；倒签入职或出险日；逃逸未知名仍虚构主体；先随便列一个再补。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：追加条件、必要共同、辩论终结效果、保险人地位、管辖时效未核验。追加闸未开则申请终稿停止，窗口不关。用户要保证准许、选定法院、尚未起诉出追加终稿、辩论终结后必准、漏列交强险不用追加则该格停止，窗口不关。
- `目标停止`：主目标变为起诉状终稿、主体总评估、直接起诉保险人入口、反诉、执行追加。尚未起诉、保证准许不在目标停止。

禁止指导编造被告、伪造保单或倒签。不给胜诉率。不选定法院。不代提交。不编唯一截止日。不把未知写成零。不定残。不保证准许。
