# 边界与路由

## 正触发

饲养或管理的动物造成人身损害，需要判断饲养人、管理人责任和受害人过错。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 野生动物行政补偿 | 行政或其他专项 |
| 总体总图 | `评估人身侵权责任` |
| 物业安保主成果 | `评估场所安全保障义务` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 饲养场职工工伤 | 劳动领域 |
| 动物致伤后的诊疗过错 | 医疗医药领域 |
| 海生养殖或船舶 | 海事领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“邻居的狗咬了”正触发。“野猪下山伤人”转行政补偿。“小区没管流浪狗”可能同时打开物业安保接口。
