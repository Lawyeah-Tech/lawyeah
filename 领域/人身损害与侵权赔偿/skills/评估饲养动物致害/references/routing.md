# 边界与路由

## 正触发

饲养或管理的动物造成人身损害，需要判断饲养人、管理人责任和分则减免接口。用户要「一般过失免责」「烈性犬按一般过错」「物业和全体业主连带必得」仍正触发。

双方秘密、伤害动物取证、伪造养犬证或伪造伤情的停止，优先于负触发。不得改走负触发去出请求或抗辩。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 野生动物行政补偿 | 行政或其他专项 |
| 总体责任总图 | `评估人身侵权责任` |
| 主体名单终稿 | `评估责任主体与保险覆盖` |
| 过错百分比终稿 | `评估过错与原因力` |
| 物业安保主成果 | `评估场所安全保障义务` |
| 1168–1172 形态终稿 | `评估共同侵权与连带按份` |
| 测算或伤残 | `测算人身损害赔偿` / `准备伤残鉴定材料` |
| 起诉状 | `提起人身损害一审` |
| 唯一时效截止日 | `评估人身损害诉讼时效` |
| 捕杀或养犬行政处罚 | 行政或其他专项 |
| 未成争改养犬合同 | 审查起草搁置 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 饲养场职工工伤 | 劳动领域 |
| 动物致伤后的诊疗过错 | 医疗医药领域 |
| 海生养殖或船舶 | 海事领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 该列谁可能是饲养人或管理人 | `评估责任主体与保险覆盖` |
| 受害人过错形态、过失相抵百分比 | `评估过错与原因力`；本窗只走分则减免格 |
| 物业未管流浪狗、小区安保 | `评估场所安全保障义务` |
| 要把 1250 写成 1168 连带 | `评估共同侵权与连带按份` 禁令 |
| 监控保存 | `准备监控保存通知` |
| 测算、评残、发函、起诉、时效、管辖 | 对应原子 |

## 易混

「邻居的狗咬了」正触发。「野猪下山伤人」转行政补偿。「小区没管流浪狗」本窗可留动物路径，物业只开场所接口，不得写成全体业主是饲养人。「逗狗所以饲主免责」仍正触发，一般过失免责格现有依据不支持；未拴绳走 1246，故意才可能减轻、不能免除。「看起来是烈性犬所以按一般过错」不关窗，名录未核则定性停止。「立刻告物业和全体业主连带并算出必得」不关窗，连带格与总额格不支持或停止。
