# 输出合同

按触发结果选择交付形状。禁止一般过失免责。禁止把烈性犬写成一般过错。禁止把物业和全体业主写成饲养人连带。禁止选定法院、伤残等级、必得总额。禁止捕杀决定或行政补偿终稿。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出（饲养场工伤或劳鉴主轴；动物致伤后诊疗过错主轴；海生养殖或船舶；未成争改养犬合同） | 第 1、2、10 节。禁止路径成立结论、减免策略、追偿方案、名录终局 |
| 整体停止 | 第 1、10 节。禁止请求、抗辩、金额、选边方案。双方秘密、伤害动物取证、伪造养犬证或伪造伤情时，整体停止优先于负触发；第一次提出即停，无选边治愈，无「坚持」门槛 |
| 用户要「一般过失免责」或「烈性犬按一般过错」或「物业和全体业主连带必得」（不关窗） | 十节表头可出现；减免格、过错形态格或连带格填 `现有依据不支持` 或字段停止；不得改走负触发关窗；成果不得标 `已形成` |
| 正触发且可评估 | 下列十节表头均出现；路径开闭、名录、动物园免责、遗弃归属、追偿未核验的单元格填 `依据不足，无法形成结论` 或 `待核`；禁止为填满而编造减免、连带、伤残或必得额；第一千二百五十一条不是独立必赔行 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。双方秘密未解不得进入「部分形成」。每个 `Q#` 必须带判断三值和证明负担方。`L#` 不得直接抄技能内条号。

## 1. 触发、单方立场、授权与成果状态

动物种类与场景。双方秘密未解不得进入「部分形成」。

## 2. 来源登记与 MCP 调用表

登记、名录、监控分列。口述禁养不得写成名录已核验。`L#` 不得抄技能内条号。MCP 未调用也留一行。

## 3. 饲养、野生、流浪分流与饲养人管理人识别

登记人、实际饲养人、临时帮喂人冲突并列。不得指定社区或全体业主为饲养人。野生动物停止民事饲养人结论。

## 4. 一般饲养路径

检索锚点第一千二百四十五条。无过错成立。一般过失免责格 `现有依据不支持`。主张减免方举证。

## 5. 未采取安全措施路径

检索锚点第一千二百四十六条，与第 4 节分列。仅故意可以减轻，不能免除。重大过失、一般过失不打开本条减免。未拴绳只建候选。

## 6. 禁止饲养烈性犬路径

检索锚点第一千二百四十七条。不得改写一般过错。名录待核。主张减免须核验解释（一）第二十三条，未核验则该格停止。

## 7. 动物园过错推定与遗弃逃逸

第一千二百四十八条与第一千二百四十九条分格。伤害不等于定责。门票不等于免责。遗弃逃逸与无主流浪分列。

## 8. 第三人对外请求与追偿

第一千二百五十条：可向饲养人或第三人请求，不是必须两边都告，不是真正连带。物业只标场所接口。全体业主连带格 `现有依据不支持`。

## 9. 下一步

过错窗只转介分则减免。场所窗写物业安保。主体窗只列谁。转介发函、鉴定、测算或起诉。不定伤残。不选定法院。不办捕杀。

## 10. 缺口、停止项与提示

须列对方最强解释（一般过失免责、烈性犬按一般过错、物业和全体业主连带必得、流浪即社区饲养、逗狗即全责、未拴绳可用 1245 写成饲主零责、动物园有门票即免责或有伤害即全责、必须两边都告、选边即可继续）与证据缺口。

本成果不是捕杀决定、不是行政补偿、不是评残、不是诉状、不是必得总额。
