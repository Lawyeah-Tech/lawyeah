# 自甘风险方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。1176 与 1186 状态只用 `打开` / `不打开` / `待核`。禁止唯一 50%、全免数字、胜诉率。未知金额不写零。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》第二十四条（根据实际情况分担）、民法通则第一百三十二条时记为噪声，不得写入 `L#`。自甘风险是对其他参加者的法定抗辩，不是活动组织者免于安保，也不是合同弃权。

民法典第一千一百七十六条第一款：自愿参加具有一定风险的文体活动，因其他参加者的行为受到损害的，受害人不得请求其他参加者承担侵权责任；但是，其他参加者对损害的发生有故意或者重大过失的除外。第二款：活动组织者的责任适用第一千一百九十八条至第一千二百零一条。

`Q#` 交付列：`活动类型｜文体活动｜自愿｜其他参加者行为｜固有风险｜但书｜1176｜组织者接口｜1186｜声明效力｜证明负担方｜来源｜判断`。报名、告知书、规则、监控必须分列。

## 节点 0　分流与活动定性

整案转出只交付第 1、2、10 节。

主张 1176 免责的一方证明：文体活动、自愿参加、损害因其他参加者的行为、属于固有风险、非故意或重大过失。
是否文体活动依据不足则 1176 字段停止。不得扩张到团建、广场舞、庙会、单位年会、公园散步等一切集体活动。条文未使用「等」，适用范围封闭。
若 if 商场摔伤、公园台阶、道路交通事故、动物咬伤，then 1176 `不打开`。主成果是场所设施则负触发至 `评估场所安全保障义务`。若用户同时点名公平分担，1186 另判，禁止用台阶案灌 1176。
若 if 单人举重、体操独自失误、无人其他参加者，then 1176 `不打开`（无其他参加者的行为）。
若 if 个人劳务或无偿帮工，then 1176 `不打开`，负触发或转介 `评估提供劳务受害`。
若 if 高度危险经营、高压、高速轨道，then 1176 `不打开`。问「自愿进入是不是自甘风险」可留窗写不打开；减免限额转介 `评估高度危险作业致害`，禁止用 1176 套 1236 至 1244。
若 if 学校课间体育，then 对其他学生的 1176 可留本窗；教育机构 1199 至 1201 填 `不打开` 并转介，禁止并行写学校终稿。
若 if 主成果仅工伤三段，then 整案转劳动。

口头「打球都是自愿的」只登记 `S#`。

## 节点 1　自愿参加与固有风险

两要件分列，不得捆成一句「参加了就免」。
若 if 被强制参加或不知情被拉入，then 自愿 `依据不足` 或 `现有依据不支持`。
无民事行为能力人或限制民事行为能力人的报名、家长代签：自愿字段停止，转介 `评估未成年或无行为能力受害人代理`。
固有风险指文体活动正常范围内难以避免的危险。若 if 损害来自场地缺陷、器材故障或组织者未告知的额外危险，then 不是固有风险，1176 不成立；场所或组织者路径只标转介，本窗不写 1198 终稿。
竞技中的合理冲撞可标固有风险候选，不是 1176 已成立。

报名表「自愿承担一切后果」不得单独写成第一千一百七十六条已满足。检索锚点：民法典第五百零六条，造成对方人身损害的免责条款无效。1176 是法定抗辩，不是合同弃权。

---

## 节点 2　但书与对其他参加者

检索锚点：第一千一百七十六条第一款但书。其他参加者故意或重大过失：不得请求免责，1176 对参加者 `不打开` 或该格不支持。
一般过失不是当然全免；四要件未齐备不得写成全免。形态判断转介 `评估过错与原因力`，本任务只标接口。不得因存在保险而跳过该判断。
互殴、故意伤害转介 `评估打架伤害民事路径`，不把互殴写成 1176 但书终稿。

---

## 节点 3　组织者接口

自甘风险抗辩成功不等于组织者无责。第二款指向 1198 至 1201，本窗只标 `打开` 或 `不打开`，禁止另建场所或学校终稿 `Q#`。
社会赛事、场馆经营者：打开则转介 `评估场所安全保障义务`。
学校组织者：打开则转介 `评估教育机构责任`。无行为能力与限制行为能力举证结构不得在本窗混写。
组织者主张已尽安保：由组织者证明；未尽义务的损害与场所或组织关系由受害人初步证明。用户要组织者一并免：组织者免责格 `现有依据不支持`，窗口仍开。

---

## 节点 4　公平责任接口

检索锚点：民法典第一千一百八十六条。受害人和行为人对损害的发生都没有过错的，依照法律的规定由双方分担损失。主张 1186 的一方必须指出具体法律。无法定依据则 1186 `不打开`。
禁止凭「双方都可怜」或公平观念各打五十。《侵权责任法》第二十四条、《民法通则》第一百三十二条为噪声。
1176 不成立不得自动打开 1186。法定依据未核验：金额字段停止，禁止填 50%。用户要各一半：仍正触发，数字格停止。
紧急避险适当补偿、高空抛物可能加害人补偿等是其他条文的补偿或分担，不是本窗用 1186 发明 50%；只标转介。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过专项分流直接给全免或各一半。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密且未获冲突豁免，then 整体停止，不得选边治愈。
若 if 用户提出用免责声明覆盖故意或重大过失、倒签免责声明、伪造报名、伪造伤情或隐匿既往，then 整体停止；第一次提出即停。
若 if 日期、送达或动态规则未核验，then 期限字段停止，不编造唯一截止日，不选定法院。
若 if 金额或份额参数不足，then 该行标未知或 `待核`，禁止写零或各一半冒充已核定。

口头转述、截图和「已读」不得写成已受理、已送达或自愿已成立。事故认定书、调解记录不得单独写成民事终局比例。判断状态只许三值。禁止胜诉率。

## 本任务回链纪律

本任务成果是「自甘风险与法定公平接口表」。不包含：过错终稿、场所安保终稿、教育机构终稿、高度危险减免终稿、劳务受害、唯一 50%、起诉状。禁止把自愿参加写成当然免责；禁止把 1176 成功写成组织者无责；禁止无法定依据各打五十。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接。
风险档 A：不可逆文书或期限字段必须单独标可逆性。
