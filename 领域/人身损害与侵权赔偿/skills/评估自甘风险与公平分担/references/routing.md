# 边界与路由

## 正触发

损害发生在文体活动中，或双方主张均无过错要求公平分担，需要单独判断自甘风险与法定公平责任。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 一般过失相抵 | `评估过错与原因力` |
| 教育机构责任主成果 | `评估教育机构责任` |
| 场所安保主成果 | `评估场所安全保障义务` |
| 高度危险作业 | `评估高度危险作业致害` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 单位文体活动构成工伤 | 劳动领域 |
| 学校医疗事故 | 医疗医药领域 |
| 海上体育或船舶 | 海事领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“打球撞伤是不是自己认了”正触发。“公园台阶摔了”不是自甘风险。“学校没人看管”主成果可能是教育机构责任。
