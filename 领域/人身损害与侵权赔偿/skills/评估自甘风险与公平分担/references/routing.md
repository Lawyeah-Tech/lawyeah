# 边界与路由

## 正触发

需要单独判断对其他参加者的自甘风险是否成立；或材料、主张已指向法定公平分担是否打开。己方或对方主张均可。用户要当然免责、组织者一并免或各一半，仍正触发，该格字段停止。

用免责声明覆盖故意或重大过失、倒签声明、伪造报名：整体停止，优先于负触发。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要过错或过失相抵终稿 | `评估过错与原因力` |
| 只要教育机构责任终稿 | `评估教育机构责任` |
| 只要场所安保终稿（公园台阶、商场摔伤、场地缺陷） | `评估场所安全保障义务` |
| 只要高度危险减免或限额终稿 | `评估高度危险作业致害` |
| 只要个人劳务或帮工受害终稿 | `评估提供劳务受害` |
| 只要总体责任总图 | `评估人身侵权责任` |
| 只要起诉状 | `提起人身损害一审` |

「要当然免责」「要各一半」不在本表。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 故意或重大过失形态、过失相抵 | `评估过错与原因力` |
| 场地缺陷、器材故障、场馆经营者 | `评估场所安全保障义务` |
| 学校课间、无或限制行为能力人在校 | `评估教育机构责任` |
| 高压、高速轨道、危险作业 | `评估高度危险作业致害` |
| 个人帮忙修缮、无偿帮工 | `评估提供劳务受害` |
| 未成年人报名或家长代签 | `评估未成年或无行为能力受害人代理` |
| 互殴、故意伤害 | `评估打架伤害民事路径` |
| 单位文体活动构成工伤 | 劳动或 `评估工伤与第三人侵权竞合` |
| 分项数字 | `测算人身损害赔偿` |
| 已选定后起诉 | `提起人身损害一审` |

## 易混

「打球撞伤是不是自己认了」正触发；「报名了就全免」仍正触发，免责格停止。「公园台阶摔了、大家都没过错、各一半」负触发场所安保，1186 不打开。「学校没人看管」主成果是教育机构；课间合理冲撞问自甘风险时，本窗可写对同学的 1176，学校职责不打开。「自愿上屋顶帮忙」走劳务受害，不是 1176。「高压区域自愿进入」1176 不打开，高度危险减免不写终稿。
