# 输出合同

按触发结果选择交付形状。禁止当然免责。禁止无法定依据各打五十。禁止把 1176 写成组织者无责。禁止编造自愿或倒签声明。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出（主成果仅工伤三段且无 1176 空间；诊疗主轴；海事） | 第 1、2、10 节。禁止 1176 成立表、组织者安保表、1186 分担表。公园台阶、商场摔伤、教育机构主成果走负触发一句，不走本行 |
| 整体停止 | 第 1、10 节。禁止成立表、全免方案、各一半、倒签声明。双方秘密、用免责声明覆盖故意或重大过失、伪造报名时，整体停止优先于负触发 |
| 正触发且可判断 | 下列十节表头均出现；组织者、教育机构、过错、高危、劳务不打开则填 `不打开`；用户要当然免责时该格 `现有依据不支持`；用户要各一半时数字格 `待核` 或 `现有依据不支持`；禁止省略后改填全免或各一半 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。双方秘密未解不得进入「部分形成」。每个 `Q#` 必须带证明负担方和判断三值。

## 1. 触发、单方立场、授权与成果状态

写明问的是对其他参加者还是公平分担、是否夹带组织者或学校、受限字段。双方秘密未解不得进入「部分形成」。

## 2. 来源登记与 MCP 调用表

报名、告知书、规则、监控、免责声明分列编号。口头「自愿」只登记 `S#`。`L#` 不得直接抄技能内条号。MCP 未调用也留一行。

## 3. 活动定性与 1176 是否打开

不是文体活动、不是其他参加者行为 → 1176 `不打开`。不得扩张到一切集体活动。单人活动不打开。

## 4. 自愿参加与固有风险

两要件分列。场地缺陷、器材故障、未告知额外危险不是固有风险。报名表不得单独满足 1176。未成年人自愿字段停止。

## 5. 对其他参加者：1176 是否成立与但书

故意或重大过失不免。一般过失不是当然全免。四要件未齐则待核。形态转介过错专项。

## 6. 组织者 1198 至 1201

不打开则填 `不打开`。打开也只转介场所或教育机构，不写安保或学校终稿。用户要组织者一并免：该格不支持。

## 7. 1186 法定公平

须有法律明文。无法定依据则 `不打开`。禁止《侵权责任法》第二十四条。禁止各一半。1176 不成立不得自动打开本行。

## 8. 免责声明效力

不覆盖故意或重大过失。造成人身损害的免责条款无效。不得单独写成 1176 已满足。倒签则不得进入本节实体。

## 9. 下一步

只转介过错、场所、教育机构、高危、劳务、未成年代理、测算、管辖、起诉。禁止在此写诉状或总额。不选定法院。

## 10. 缺口、停止项与提示

须列对方最强解释（口头即自愿、报名即 1176、免责声明覆盖恶意犯规、参加了就免、组织者因 1176 无责、学校课间也免、双方可怜各一半、公园台阶走 1186、高压自愿即 1176、要全免就必须关窗、要某区法院就必须出诉状）与证据缺口。

本成果不是过错终稿、教育机构终稿、场所安保终稿、高度危险减免终稿、劳务受害、唯一 50% 或起诉状。
