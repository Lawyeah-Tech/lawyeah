# 评估自甘风险与公平分担

## 任务目标

在明确、无利益冲突的单方立场下，形成「自甘风险与法定公平接口表」：文体活动中因其他参加者行为受害时第一千一百七十六条是否成立；活动组织者第一千一百九十八条至第一千二百零一条只标接口；第一千一百八十六条仅在有法律明文时打开。不把自愿参加写成当然免责，不因自甘风险消灭组织者义务，不在法无明文时各打五十。

`depends-on` 为空。接受等价事实、报名、规则、告知书和证据清单。

## 工作边界

正触发：需要单独判断对其他参加者的自甘风险是否成立；或材料、主张已指向法定公平分担是否打开。己方或对方主张均可。用户要当然免责、组织者一并免或各一半，仍正触发，该格字段停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要一般过错或过失相抵终稿（转 `评估过错与原因力`）；
- 只要教育机构责任终稿（转 `评估教育机构责任`）；
- 只要场所安保终稿，含公园台阶、商场摔伤、场地缺陷（转 `评估场所安全保障义务`）；
- 只要高度危险减免或限额终稿（转 `评估高度危险作业致害`）；
- 只要个人劳务或无偿帮工受害终稿（转 `评估提供劳务受害`）；
- 只要总体责任总图（转 `评估人身侵权责任`）；
- 只要起诉状（转 `提起人身损害一审`）。

「要当然免责」「要各一半」不在负触发表。用免责声明覆盖故意或重大过失：整体停止，不走负触发。

本任务不选定法院，不写唯一截止日，不代提交起诉状，不输出唯一分担比例，不给胜诉率。

## 建立工作坐标

确认：使用者与授权；单方立场；活动类型是否文体活动；损害是否因其他参加者的行为；受害人是否自愿参加；损害是否该活动固有风险；其他参加者是否故意或重大过失；组织者身份；是否学校课间；法域。口头「打球都是自愿的」不得写成自愿已成立。报名表「自愿承担一切后果」不得单独写成第一千一百七十六条已满足。

同时掌握双方秘密或未解利益冲突：`整体停止`，不得以选边治愈，也不得改走负触发去出全免或各一半。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 报名、告知书、规则、监控分列；`R#` 文书；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 抗辩行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。1176 与 1186 状态只用 `打开` / `不打开` / `待核`。禁止唯一 50%。技能正文中的条号是检索锚点，不是已核验 `L#`。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验自甘风险、法定公平分担、人身损害免责条款等将被写入 `L#` 的现行规则；1198 至 1201 只核验组织者是接口。不可用则法律效果字段停止，且不得填全免或各一半。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变 1176 成立、但书或 1186 是否打开的条文正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补报名概括弃权不当然免责、固有风险与场地缺陷区分、1186 须具体法定依据的实务反例。

工具不可用时继续活动类型、报名、规则编目。不得凭记忆写当然免责、各一半，或把《侵权责任法》第二十四条当现行。

## 判断节点

执行顺序和停止条件以 [自甘风险方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流与活动定性

仅文体活动且因其他参加者行为才打开 1176。商场摔伤、公园台阶、道路交通、单人活动、个人劳务帮忙：1176 不打开。

### 2. 自愿参加与固有风险

两要件分列。被强制或不知情拉入则自愿不足。场地缺陷、器材故障、未告知额外危险不是固有风险。

### 3. 但书与对其他参加者的成立判断

故意或重大过失不免。一般过失不是当然全免。形态转介过错专项。

### 4. 组织者与公平接口

组织者 1198 至 1201 不打开则填 `不打开`，不写安保或学校终稿。1186 须法律明文，无法定依据则不打开。

### 5. 邻接与输出纪律

用户要当然免责或各一半则该格停止。免责声明不得单独满足 1176，不覆盖故意或重大过失。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；用免责声明覆盖故意或重大过失；倒签免责声明或伪造报名；伪造伤情。整体停止优先于负触发。第一次提出即停，不以「坚持」为门槛。
- `字段停止`：是否文体活动、自愿、固有风险、其他参加者行为、公平责任法定依据未核验；用户要全免或各一半的数字格。
- `目标停止`：主目标变为过错终稿、教育机构终稿、场所安保终稿、高度危险减免终稿或起诉状。

禁止指导倒签免责声明。不给胜诉率。
