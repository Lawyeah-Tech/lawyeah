# 评估道路交通事故责任与保险先行

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《侵权责任法》、2003 年人身损害赔偿解释已删除条文或已失效《合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“道路交通事故民事赔偿与保险先行表”：事故认定复核接口、交强险先行、商业三者、未投保、精神损害优先接口。不替代总体评估或精算，不办交警认定本身。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算、鉴定和证据清单。

## 工作边界

正触发：机动车道路交通事故已发生，需要单独判断民事赔偿路径和交强险、商业三者顺序。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要总体责任总图或精算终稿；
- 只要复核事故认定书（转 `复核交通事故认定`）；
- 铁路航空承运人（转 `评估铁路航空等非海事承运人人身损害`）；
- 海事船舶（转海事）；
- C 端交通事故测算只要大众测算（只分流）。

本任务不替代总体评估或精算，不办交警认定，不保证在限额内全额受偿。C 端 006 只分流。

## 建立工作坐标

确认：使用者与授权；单方立场；机动车方与非机动车或行人；事故认定书版本；交强险和商业三者保单；是否逃逸或未投保；精神损害是否拟优先在交强险内主张；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 保单、行驶证；`R#` 事故认定书；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 分账行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典第一千二百零八条至第一千二百一十三条、交强险条例和侵权责任编解释关于未投保的规则。不虚构案件系统。

工具不可用时继续事实、主体、程序文书状态和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [交通事故保险方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　场景分流

仅道路机动车事故。铁路航空海事转出。

### 节点 2　事故认定与复核接口

认定书只作 `R#`。不服走复核专项。

### 节点 3　交强险先行

先交强险分项限额，再商业三者，仍不足由侵权人。

### 节点 4　未投保、盗抢、挂靠

投保义务人在交强险限额范围内的责任须核验解释。

### 节点 5　商业三者与输出纪律

商业险受合同条款约束，不保证全额。

## 停止与安全

- `整体停止`：立场不明；用户坚持伪造保单或顶包。
- `字段停止`：交强险限额、未投保规则、精神损害优先规则未核验。
- `目标停止`：主目标变为认定书复核终稿、总体评估或精算终稿。
