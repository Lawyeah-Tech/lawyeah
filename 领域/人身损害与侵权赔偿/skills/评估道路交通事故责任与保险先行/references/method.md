# 交通事故保险方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。接口状态只用 `打开`、`不打开`、`待核`。禁止胜诉率、唯一责任百分比、限额内必得总额、选定法院、伤残等级。未知金额不写零。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《侵权责任法》第四十八条至第五十三条、2003 年人身损害赔偿解释已删除条文、已失效《合同法》，或把已废止交强险死亡伤残 11 万／医疗 1 万旧限额写成现行标准时记为噪声。把未投保写成「限额内连带」、把道路交通安全法第七十六条「不超过百分之十」写成默认减轻或三七开，同样记为噪声。

`Q#` 固定列：`编号｜车辆或保单身份｜险种层｜交强险分项｜限额档有责或无责｜受害人是否第三人｜精神损害优先｜主体路径条｜未投保结构｜已付扣减｜判断｜待核`。一行一袋。多车、多份保单不得合并。民事对照与交强险应赔额分表，禁止把认定书比例写入交强险格。

## 节点 0　分流、立场与禁止事项

整案转出只交付第 1、2、10 节。

| 信号 | 处理 |
| --- | --- |
| 工伤待遇或劳动能力鉴定主轴 | 转劳动；第三人车辆分账可留本窗接口 |
| 诊疗过错医疗损害主轴 | 转医疗医药 |
| 船舶、海上人身伤亡 | 转海事 |
| 未成争只要改合同或出稿 | 审查起草本窗搁置 |

铁路、航空旅客伤害：负触发至 `评估铁路航空等非海事承运人人身损害`，不是本节点整案转出。只要总图、主体名单、过错百分比、连带终稿、测算、认定复核、诉状、索赔稿、拒赔、救助基金申请：负触发至对应原子。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握双方秘密且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发去出分账、诉状或复核稿。
若 if 保险人与驾驶人共同委托而利益冲突未解，then 整体停止。
若 if 提出伪造保单、顶包、改写认定书、伪造伤情或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

一般陆上机动车事故夹带工伤或就医背景时，专项段只分流，民事分账可留；医疗费禁止双领，转介 `评估工伤与第三人侵权竞合`。

## 节点 1　场景、交强险接口与认定书

机动车事故（含道路以外通行、停车场低速碰撞）**一律打开交强险接口**，不因认定书无责、次责或「不是道路上」而关闭。道路以外通行比照交强险条例第四十三条（条号须核验）。解释（二）第五条针对起重、升降等工程专项作业车：交通事故造成损害则交强险打开；作业时非因交通事故造成损害则交强险不打开；该车在道路以外通行发生事故比照条例第四十三条。停车场争的是「是否道路交通事故认定」与「交强险比照是否打开」必须分列，禁止合成「交强险停止」。

非机动车之间事故：先核是否夹带机动车。交强险可能 `不打开`。一般过错转 `评估过错与原因力`，本窗不填总图终稿。非机动车商业三者合并审理只标接口，检索锚点解释（二）第十一条。

交强险受害人为本车人员、被保险人以外的人。检索锚点：交强险条例第三条。乘客、驾驶人本人是否落入须按座位、时空位置和保单核验，依据不足该 `Q#` 停止。开门杀致车外第三人与本车人员受害分两行。开门杀：乘车人责任属于该机动车一方；保险人不得以乘车人不是被保险人或其允许的驾驶人为由拒赔交强险或商业三者。检索锚点：解释（二）第二条。驾驶人离开本车后因自身过错被本车碰撞碾压：请求本车交强险、商业三者，现有依据支持不打开，须核验解释（一）第二十二条。

认定书事实与责任分列，只作 `R#`。人民法院依法审查证明力，相反证据可以推翻；检索锚点为道交解释认定书条款（条号须核验）。主责、次责、同等、全部**不得**自动映射三七开、二八开或民事份额。口头「交警说全责」只登记 `S#`，不得写入 `R#`。无认定书无监控：对照格 `依据不足，无法形成结论`。

用户不服认定：标复核红旗，转介 `复核交通事故认定`。复核**不是**民事起诉前置；复核期内仍可起诉；起诉后复核是否终止标 `待核`。本窗不重写交警结论，不定唯一责任百分比。用户要顶包改认定：回节点 0 整体停止，不转复核去完成改认定。逃逸、酒驾、无证：只标保险免责或追偿红旗，展开转 `应对保险拒赔减赔`。

好意同乘：检索锚点民法典第一千二百一十七条、解释（二）第三条。交警全责或主责**不当然**等于使用人对搭乘人的故意或重大过失。本窗不写减轻比例终稿，转过错专项。

## 节点 2　两套时际与第七十六条对照

两套时际必须分列，禁止混用：

| 规范 | 时际 | 本窗用法 |
| --- | --- | --- |
| 道交解释（二）法释〔2026〕9 号 | 2026-06-30 施行；**施行后尚未终审的案件适用**；施行前已终审再审不适用（第十二条）。事故日早于施行日但未终审，**不得以事故日排除** | 开门杀、1209 共同承担、工程作业车、基金已付、驾驶证过期 |
| 人身损害赔偿解释法释〔2022〕14 号 | **侵权行为发生日**（第二十四条） | 城乡口径、残疾赔偿金项目。本窗不写测算终稿 |

道路交通安全法第七十六条检索锚点（条号须核验）：

- 先由交强险在责任限额范围内赔偿；不足部分再按下列规则。
- 机动车之间：有过错的一方承担；双方都有过错的，按过错比例分担。本窗仍不填唯一数字。
- 机动车与非机动车驾驶人、行人：行人没有过错的，由机动车一方承担；有证据证明行人有过错的，根据过错程度**适当减轻**；机动车一方**没有过错**的，承担不超过百分之十的赔偿责任。
- 百分之十是机动车没有过错时的法定上限接口，不是全案默认比例，不是机动车次责时的地板。次责机动车不得套用百分之十。
- 损失由非机动车驾驶人、行人**故意碰撞**机动车造成的，机动车一方不承担赔偿责任。闯红灯、未系安全带不当然等于故意碰撞。

民事减轻**不得**写入交强险应赔额。交强险限额内不得按本窗或认定书比例扣减。第七十六条民事对照转介 `评估过错与原因力` 展开，本窗只钉禁令与保险层效果。

## 节点 3　交强险先行分账

检索锚点：民法典第一千二百一十三条。属于该机动车一方责任的，先由承保交强险的保险人在强制保险责任限额范围内赔偿；不足部分由承保商业三者的保险人按照保险合同约定赔偿；仍然不足或没有投保商业保险的，由侵权人赔偿。

分项：死亡伤残／医疗费用／财产损失 × 有责／无责。未核验现行标准则金额格停止。禁止已废止 11 万／1 万（及医疗 1 万／1 千）旧档。禁止把记忆中的 18 万／1.8 万／0.2 万写成已核验必得。禁止把医疗费写入死亡伤残限额。微信保单截图、口头「保了交强险」只登记 `D#` 表面，限额格停止。

多车多份分列，不得简单相加冒充必得，也不得因次责丢掉该车交强险。部分车辆未投保时「先由已承保交强险赔偿」另核道交解释相关条款，不得写成受害人只能拿一份。

精神损害请求交强险优先：须被侵权人或近亲属**提出**。检索锚点：道交解释关于精神损害优先的条款（2020 修正后常见为第十三条第二款，条号须核验）。未提出不得自动优先。只改变死亡伤残限额内排序，不增加总额。未投保无此接口。本窗不分配唯一数字，转介 `评估精神损害赔偿`。

承保交强险的保险公司在道路交通事故损害赔偿中**应当列为共同被告**（已在责任限额范围内实际赔付且当事人无异议除外）。检索锚点：道交解释保险人共同被告条款（条号须核验）。应当共同被告 **≠** 连带。本窗只标红旗，不写起诉状。商业三者仅在当事人请求时加入。转介 `直接起诉保险公司`、`评估责任主体与保险覆盖`。

医保基金、工伤保险基金已付医疗费和救助基金垫付的抢救费、丧葬费，不得再向侵权人重复主张该部分。检索锚点：解释（二）第十条。禁止写成「基金已付则全部民事责任消灭」。已发生抢救费用且逃逸、未投保或超医疗限额：转介 `申请道路救助基金或垫付`。未就医、无抢救费不得把基金申请写成默认下一步。

打开接口 ≠ 限额内必得。用户要立刻算出交强险必得总额：数字格停止，窗口不关，成果不得标 `已形成`。

## 节点 4　未投保限额层、商业三者与转介

主体名单终稿转 `评估责任主体与保险覆盖`。本窗只保留保险层效果。路径必须**单选一条**，禁止混写。

| 路径 | 保险层口径 | 禁止 |
| --- | --- | --- |
| 未投保且投保义务人与事故责任人不是同一人 | 责任人承担全部；投保义务人在交强险限额内**共同承担**。检索锚点：解释（一）第二十一条 | 连带、限额内连带、无限连带 |
| 未投保且为同一人 | 另核道交解释第十六条第一款（条号须核验） | 用 21 条第二款吞掉第一款 |
| 借用、租赁（1209） | 使用人承担该机动车一方应承担的全部责任；所有人、管理人仅在**有过错范围内共同承担**。检索锚点：解释（二）第一条 | 登记车主当然连带；无过错仍写共同被告终局 |
| 挂靠（1211） | 挂靠人与被挂靠人连带**候选** | 与借用混行 |
| 转让交付未登记（1210） | 最后一次转让并交付的受让人 | 登记车主当然责任 |
| 擅自驾驶（1212） | 使用人承担；所有人、管理人有过错的相应责任 | 与盗抢、借用混成一条 |
| 拼装或报废（1214） | 转让人与受让人连带候选 | 当成普通未过户 |
| 盗抢（1215） | 盗窃人、抢劫人或抢夺人承担；与使用人不是同一人时二人连带候选 | 原所有人因被盗抢当然担责；租赁分离套盗抢；因盗抢直接删除交强险公司 |

数人侵权连带或按份终稿转 `评估共同侵权与连带按份`。本窗不得把补充改成连带，也不得把未投保共同承担改成连带。

商业三者：免责、不计免赔、医保外用药、酒驾、无证、逃逸须回链条款原文，不得概括一定赔或一定不赔。驾驶证过期尚未注销，保险人不得仅以此拒赔。检索锚点：解释（二）第四条。展开转 `应对保险拒赔减赔`。材料包转 `准备交强险商业险索赔材料`。C 端 006 只分流。

本任务不定责已终局，不输出唯一必得总额，不定伤残等级，不选定法院，不写诉状。

## 证据与禁止

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口。不能因对方控制而推定材料存在或内容有利。地点、保单号、车牌冲突并列。禁止伪造保单、顶包、改认定、伪造伤情。第一次提出即停。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过专项分流直接给限额内必得或车主连带。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if 金额参数不足，then 该行标未知，禁止写零。

口头转述、截图和「已读」不得写成已受理、已送达、已承保或限额已确定。事故认定书、调解记录不得单独写成民事终局比例。判断状态只许三值。

## 本任务回链纪律

本任务成果是「交强险／商业三者先行分账表」。不包含：责任主体名单终稿、过错百分比终稿、连带按份终稿、测算终稿、认定复核终稿、起诉状、索赔发送稿、拒赔终稿、救助基金申请终稿、唯一受诉法院、伤残等级。禁止限额内必得；禁止按民事比例扣交强险；禁止未投保写成连带；禁止车主当然连带。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接。
