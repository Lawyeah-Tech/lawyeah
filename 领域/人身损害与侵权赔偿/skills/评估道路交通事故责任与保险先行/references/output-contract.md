# 输出合同

按触发结果选择交付形状。禁止把认定书写成民事终局。禁止限额内必得。禁止按民事比例扣交强险。禁止未投保写成连带。禁止车主当然连带。禁止把百分之十写成默认减轻或三七开。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出（工伤待遇或劳鉴主轴；诊疗过错主轴；海事；未成争改合同） | 第 1、2、10 节。禁止分账数字、第七十六条比例、保险人必担额 |
| 整体停止 | 第 1、10 节。禁止分账表、选边、策略。双方秘密、伪造保单、顶包、改写认定书时，整体停止优先于负触发；第一次提出即停，无选边治愈，无「坚持」门槛 |
| 用户要限额内必得或唯一分账款（不关窗） | 十节表头可出现；必得额与唯一数字格字段停止；不得改走负触发关窗 |
| 正触发且可分账 | 下列十节表头均出现；限额、第七十六条效果、多车分摊未核验的单元格填 `依据不足，无法形成结论` 或 `待核`；禁止省略后改填限额内必得或按民事比例扣交强险 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。双方秘密未解不得进入「部分形成」。每个 `Q#` 必须带判断三值。用户催必得总额或车主连带时，成果不得标 `已形成`。

## 1. 触发、单方立场、授权与成果状态

写明是否道路机动车事故、冲突筛查、受限字段。双方秘密未解不得进入「部分形成」。

## 2. 来源登记与 MCP 调用表

认定书、行驶证、保单分列编号。微信截图、口头保单只登记 `D#` 或 `S#` 表面。`L#` 不得直接抄技能内条号。MCP 未调用也留一行。

## 3. 事故认定对照

事实与责任分列。主次责不得映射三七开。口头全责不得写入 `R#`。不服转 `复核交通事故认定`。本窗不重写交警结论。复核不是民事起诉前置。

## 4. 第七十六条民事对照

机动车之间／机动车与行人适当减轻／无过错不超过百分之十，分列接口。只对照，不填唯一百分比。次责不得套百分之十。故意碰撞才可能全免。解释（二）与 2022 人身损害解释两套时际分列。

## 5. 交强险先行与分项限额

死亡伤残／医疗／财产 × 有责／无责。不得串项。不得按第 4 节比例扣减。次责、无责不关闭该车交强险。道路以外或停车场不得关闭接口。未核验则金额停止。禁止旧 11 万／1 万。多车多份分列，不得相加冒充必得。打开接口不等于限额内必得。应当共同被告只标红旗，不等于连带。

## 6. 精神损害优先接口

须被侵权人或近亲属提出。未提出填 `不打开`。只改变死亡伤残限额内排序，不增加总额。未投保无此接口。不分配唯一数字。

## 7. 商业三者与免责红旗

不保证全额。免责、医保外用药、不计免赔、驾驶证过期只标接口。展开转 `应对保险拒赔减赔`。不得概括一定赔或一定不赔。

## 8. 未投保或主体特殊路径的限额层

未投保：限额内共同承担，禁止连带。借用：使用人全部，所有人仅过错范围内共同承担，禁止车主当然连带。挂靠、转让、盗抢、擅自驾驶分列，禁止混条。原车主不因被盗抢当然列入。名单终稿转 `评估责任主体与保险覆盖`。

## 9. 下一步

转介复核、过错、主体、共同侵权、测算、直接起诉保险人、索赔材料、救助基金、工伤竞合。已发生抢救费且逃逸／未投保／超医疗限额才打开救助基金接口。不写诉状、索赔发送稿或拒赔终稿。不选定法院。

## 10. 缺口、停止项与提示

须列对方最强解释（认定书即民事终局、主次责即三七开、次责只赔百分之十、截图即可算出必得、未投保车主连带、借用即登记车主连带、不是道路上就没有交强险、选边即可继续、顶包改认定就能过、基金已付则全部免责）与证据缺口。

本成果不是认定书、精算终稿、主体名单终稿、过错百分比、诉状或限额内必得意见。
