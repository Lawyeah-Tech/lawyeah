# 边界与路由

## 正触发

机动车道路交通事故已发生，需要单独判断民事赔偿路径和交强险、商业三者顺序。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 总体评估或精算 | `评估人身侵权责任` 或 `测算人身损害赔偿` |
| 复核认定书 | `复核交通事故认定` |
| 铁路航空 | `评估铁路航空等非海事承运人人身损害` |
| 海事 | 海事领域 |
| C 端交通事故测算 | 大众专项，只分流 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 上下班第三人事故的工伤三段 | 劳动领域 |
| 交通事故后诊疗过错主轴 | 医疗医药领域 |
| 船舶事故 | 海事领域 |

一般陆上人身侵权夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 易混

“撞了人，交强险怎么先赔”正触发。“认定书写错了要复核”走复核专项。“火车上受伤”走承运人专项。
