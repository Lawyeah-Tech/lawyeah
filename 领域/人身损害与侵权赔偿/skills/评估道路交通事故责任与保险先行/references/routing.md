# 边界与路由

## 正触发

机动车道路交通事故已发生，需要单独判断民事赔偿路径和交强险、商业三者顺序。停车场或道路以外通行争认定或交强险比照，仍可正触发：接口打开，赔付条件待核。

双方秘密、伪造保单、顶包或改写认定书的停止，优先于负触发。不得改走负触发去出分账、诉状或复核稿。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 总体责任总图 | `评估人身侵权责任` |
| 主体名单或保险能否进入 | `评估责任主体与保险覆盖` |
| 过错形态或唯一责任百分比 | `评估过错与原因力` |
| 连带、按份或补充终稿 | `评估共同侵权与连带按份` |
| 精算或分项测算终稿 | `测算人身损害赔偿` |
| 复核认定书终稿 | `复核交通事故认定` |
| 直接起诉保险人诉状 | `直接起诉保险公司` |
| 索赔材料包 | `准备交强险商业险索赔材料` |
| 拒赔减赔终稿 | `应对保险拒赔减赔` |
| 救助基金申请终稿 | `申请道路救助基金或垫付` |
| 铁路航空承运人 | `评估铁路航空等非海事承运人人身损害` |
| 海事船舶 | 海事领域 |
| C 端交通事故测算 | 大众专项，只分流 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 上下班第三人事故的工伤三段 | 劳动领域；民事分账接口可留，转介 `评估工伤与第三人侵权竞合` |
| 交通事故后诊疗过错主轴 | 医疗医药领域 |
| 船舶事故 | 海事领域 |

一般陆上机动车事故夹带工伤或就医背景时，专项段只分流，不把专项规则写入本任务结论。审查起草领域本窗搁置：未成争只要改合同或出稿，只说明不实施。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 该列谁、保险能不能进、应当共同被告 | `评估责任主体与保险覆盖` |
| 三七开、形态、百分之十上限展开 | `评估过错与原因力` |
| 认定书不服、要复核稿 | `复核交通事故认定` |
| 项目金额、伤残、误工 | `测算人身损害赔偿` |
| 精神损害如何入账数字 | `评估精神损害赔偿` |
| 索赔材料 | `准备交强险商业险索赔材料` |
| 免责、减赔、定损争议 | `应对保险拒赔减赔` |
| 同时或单独诉保险人 | `直接起诉保险公司` |
| 已发生抢救费且逃逸、未投保或超医疗限额 | `申请道路救助基金或垫付` |
| 第三人侵权夹工伤 | `评估工伤与第三人侵权竞合` |

## 易混

「撞了人，交强险怎么先赔」正触发。「认定书写错了要复核」走复核专项。「该告车主还是司机」走主体窗。「是不是三七开」走过错窗。「能拿到多少钱」走测算窗。「火车上受伤」走承运人专项。「微信保单截图，立刻算出交强险必得，车主要连带」正触发，但限额格停止、车主连带格现有依据不支持。「未投保加借车，两边材料都在，想顶包改认定」整体停止，不关窗成负触发，也不转复核去改认定。保险人营业部所在地不等于对司机有管辖，管辖不在本窗选定。
