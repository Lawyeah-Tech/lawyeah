# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变解除权成立、催告必要、除斥或通知效力结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然解除或唯一除斥截止日。构成违约不等于当然解除。

节点法律结论必须运行时 `search_law` 核验现行民法典第 562、563、564、565、199 条和《最高人民法院关于适用〈中华人民共和国民法典〉合同编通则若干问题的解释》（法释〔2023〕13 号）第 53 条后再写入 `L#`。核验失败则本节点法律结论字段停止，事实与问题清单继续。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。

## Q# 路径矩阵

固定列：`编号｜路径类型｜提出方｜相对方｜法律效果｜成立条件｜支持事实｜不利事实｜催告是否必要｜除斥情景｜控制方｜最强反方｜主备位｜判断｜待核`。

至少分列：`Q-约` 约定解除；`Q-协` 协商一致解除；`Q-法-迟` 迟延主要债务＋催告；`Q-法-目` 违约致使目的不能实现；`Q-法-期` 预期拒绝；`Q-法-不` 不可抗力致目的不能实现；`Q-不定期` 不定期持续合同的随时解除；`Q-抗` 无解除权、催告未完成、除斥届满、通知未到达。

`Q-约`／`Q-法-*` 与继续履行不得同时写成均已成立。违约金、赔偿另标接口，不在本任务做金额终局。

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定、实际施工人 | 建设工程领域 |
| 金融借贷、保证、抵押质押、保理、融资租赁主轴 | 金融借贷担保领域 |
| 商品房买卖、开发合作、物业服务主轴 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、劳动报酬、解除劳动合同、工伤待遇 | 劳动领域 |
| 尚未成争，只要改解除条款或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

若：用户只要争议总图 → 负触发，转 `assess-contract`。  
若：已决定发函且只要发送前解除稿 → 负触发，转 `prepare-termination-notice`。  
若：本次主成果是催告履行 → 负触发，转 `prepare-demand-notice`。

## 节点 1　文本版本、合同目的和通知状态

1. 固定合同、附件、订单和补充协议版本。约定解除条款、合同目的条款、催告期、自动解除期必须定位到 `C#`。冲突并列，不选对用户有利的一版。
2. 主体表记录解除权人、相对方和实际发出／接收通知的主体。无权代理人发出的通知不自动写成有效行使。
3. 通知状态表逐件记录催告、解除通知、异议：文本 `V#` 或对方来函、发出日、渠道、到达证据、对方是否否认。微信“已读”不等于到达。
4. 已经发出或已经到达的通知必须如实登记，不得按“尚未行动”评估。
5. 同时掌握双方秘密或立场不明：整体停止策略输出。

## 节点 2　约定解除与协商一致

运行时核验第 562 条现行文本后再落判断。

| 条件 | 判断 | 禁止写成 |
| --- | --- | --- |
| 双方已就解除达成一致且意思表示可回链 | `Q-协` 现有依据支持解除合意；是否已发生解除效果仍看协议生效条件 | 单方通知已解除 |
| 合同约定解除条件，该当事实可回链已成就，通知尚未有效发出 | 解除权现有依据支持（或 `依据不足` 若事实有缺口）；**未行使** | 合同已解除 |
| 约定条件未成就，仅有用户情绪或商业不便 | 约定解除现有依据不支持 | 视为已成就 |
| 条件成就但除斥可能届满 | 建并行情景，解除权存续 `依据不足` | 唯一截止日后必然仍可解 |
| 条款写“对方违约即可解除”但未界定违约范围 | 条件是否该当 `依据不足` | 任何迟延均可解除 |

成就不等于已经发出有效通知。未通知而直接起诉或申请仲裁主张解除：仅在确认该主张后，自起诉状或仲裁申请书副本送达时解除（第 565 条）。评估阶段不得把“准备起诉”写成已经解除。

## 节点 3　法定解除与催告是否必要

运行时核验第 563 条现行文本。五项分列，禁止合成“已经违约所以可以解除”。

### 3.1 先分账

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 对方迟延或质量不符 | 已构成法定解除 |
| 用户想今天发函 | 解除权已行使或合同已解除 |
| 约定了违约金 | 合同目的不能实现 |
| 对方未在异议期内异议 | 即使无解除权也已解除 |
| 轻微迟延、可补救瑕疵 | 可以跳过催告 |

### 3.2 分项规则

1. **不可抗力致目的不能实现**  
   若：事件可回链，但仅造成成本上升或商业困难 → 现有依据不支持法律上的不能，不得跳到解除。  
   若：事件、通知义务、减损措施分列后仍不能证明目的不能实现 → `依据不足`。

2. **预期拒绝主要债务**  
   若：拒绝表示的主体、权限、原文和到达均可回链 → 可不经催告的法定解除候选。  
   若：仅凭迟到几天、态度不好或停止回复 → 默示拒绝现有依据不支持。

3. **迟延主要债务**  
   **原则上先催告，并指定合理期限。**  
   若：迟延的是主要债务 **并且** 尚未催告 **并且** 无目的不能实现的可回链事实 → 催告必要＝现有依据支持；**不得写解除已成立**。  
   若：已催告且指定期限届满仍未履行 → 法定解除候选；期限是否合理标待核，不编造“一律 15 日”。  
   若：催告文本无法定位或未到达 → 催告完成 `依据不足`，不写解除已成立。

4. **迟延或其他违约致使目的不能实现**  
   目的来自合同目的条款、标的性质和磋商记录，不来自用户事后情绪。  
   若：通用货物轻微迟延、瑕疵可修理更换、价款争议不影响标的用途 → 跳过催告现有依据不支持。  
   若：特定目的、季节性、期限本质或对方明确拒绝补救可回链 → 才讨论第 563 条第四项候选。

5. **其他法律规定的解除**  
   必须指出具体法律名称并 `search_law`；不能用已失效《合同法》条号填空。

持续履行的不定期合同随时解除候选，须另列合理期限通知义务，不与违约解除混写。

### 3.3 催告必要输出

| 条件 | 催告是否必要 | 本任务对解除权的判断 |
| --- | --- | --- |
| 迟延主要债务，目的不能实现依据不足 | 必要 | 未催告则解除已成立＝现有依据不支持 |
| 预期拒绝或目的不能实现现有依据支持 | 可能不必要 | 仍须核验事实和除斥，不自动写成已解除 |
| 约定解除条件已成就 | 视条款是否另要求催告 | 成就≠已行使 |
| 依法须催告且未催告 | 必要 | **不写解除已成立** |

## 节点 4　除斥、到达与无解除权通知

运行时核验第 564、565、199 条和通则解释第 53 条。

### 4.1 除斥并行情景

- 解除权存续：约定期间或法律规定的期间。  
- 无约定且无法定期间：知道或应当知道解除事由之日起一年；或经对方催告后的合理期限。  
- 除斥不适用诉讼时效的中止、中断、延长（第 199 条）。禁止用三年诉讼时效去算解除权。  
- 知悉日、应当知悉日、对方催告日、约定除斥起算日冲突时，建立并行情景，**不给唯一除斥截止日**。  
- 日期不明或送达不明：字段停止，不选对用户最有利的一天。

### 4.2 到达与效力

| 条件 | 判断 | 禁止 |
| --- | --- | --- |
| 有解除权的通知已到达对方 | 到达时发生解除效力（第 565 条） | 把发出日写成解除日；把“已读”写成到达 |
| 附自动解除期限，期限届满且未履行 | 期限届满时解除候选 | 忽略“未履行”这一条件 |
| 未通知而直接起诉或申请仲裁主张解除 | 仅在确认后，自副本送达时解除 | 把“准备起诉”写成已解除 |
| 通知已发出但无到达证据，对方否认收到 | 到达 `依据不足` | 合同已解除 |
| 仅有微信已读、未读或表情回复 | 不得写成到达 | 已读＝送达＝已解除 |

### 4.3 无解除权则通知不生效

若：解除权成立判断为现有依据不支持或依据不足，即使对方未提异议 → 通知不发生解除效力（通则解释第 53 条）。对方沉默不能补正解除权的缺失。

没有送达事实和规则引文，禁止写“合同已解除”。

## 节点 5　异议后确认之诉分流与转出

| 条件 | 本任务输出 | 转介 |
| --- | --- | --- |
| 仍希望对方履行或补救，催告必要或有用 | 催告必要、合理期限待核、风险 | `prepare-demand-notice` |
| 解除路径条件尚未闭合 | 缺口、最强反方、不可逆提示 | 不转介发函 |
| 用户已决定发出解除终稿，且解除权评估可闭合 | 最小交接，目标停止 | `prepare-termination-notice`，不在本包出稿 |
| 依法须催告且未催告，用户仍要解除函 | 解除已成立＝现有依据不支持；停止解除终稿 | 先 `prepare-demand-notice` |
| 对方已异议或拟请求确认未解除 | 分流确认之诉／仲裁，列请求方向和期限待核 | `file-first-instance` 或仲裁确认；`object-to-termination` 承接异议函。本任务不写诉状 |
| 拟解除方需确认解除效力 | 同上，只给分流 | 不写确认之诉诉状 |
| 只要总图 | 负触发 | `assess-contract` |
