# 边界与路由

## 正触发

拟解除，或已收到对方解除通知，需要判断约定或法定解除权、催告是否必要、除斥和通知效力。从零、碎片、催告未核验、无书面评估授权仍正触发：有可编号合同、催告、解除通知或履行碎片则闸开或半开，出 `JC#` 草案，保持草案。本次不写发送版解除函、不给胜诉率是交付禁令，不是开窗条件。构成违约即解除、须催告未催告即已成立、已读即到达，仍正触发。

双方秘密、伪造催告、倒签解除通知、伪造送达、隐匿证据、违法取证的停止，优先于负触发。上述信号不在下表。不写发送版解除函不是负触发。「构成违约即已解除」「须催告未催告即已成立」「已读即已到达」「准备起诉即已解除」「未异议即已解除」不在下表。伪造倒签不在下表，走整体停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 争议总图 | `评估合同争议` |
| 发送版催告 | `准备催告履行或补救通知` |
| 发送版解除通知 | `准备解除通知` |
| 异议函终稿 | `准备对合同解除通知的异议` |
| 确认解除或未解除起诉包 | `提起合同纠纷一审` |
| 情势变更变更或解除之诉 | `提起情势变更变更或解除之诉` |
| 尚未成争，改解除条款 | 审查起草领域（本窗搁置，只说明） |
| 工程／金融／房产／海事／劳动主轴 | 对应领域 |

不得因「不写发送版解除函」关窗。拟解除权评估仍正触发，不得写成已解除。

| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |

## 易混

本窗闸名只能是解除闸，不是争议闸，不是催告闸，不是发送闸。`JC#` 不是催告，不是解除函，不是诉状。主路径是 `Q-除`，不是 `Q-解`，不是 `Q-催`。构成违约不是当然解除。催告不是已解除。准备起诉不是已解除。未异议不能补正解除权缺失。除斥不是诉讼时效。已读不是已送达。已失效《合同法》不是现行规则。商品房催告后三个月不是一般买卖当然规则。「把催告函倒签」整体停止。本窗不执行发送，不代提交。
