# 边界与路由

## 正触发

拟解除，或已收到解除通知，单方需要判断约定／法定解除权是否成立、催告是否必要、除斥是否可能届满，以及已发通知是否发生解除效力。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要争议总图 | `评估合同争议` |
| 已决定发解除通知 | `准备解除通知` |
| 仍要对方履行或补救，主成果是催告 | `准备催告履行或补救通知` |
| 已收到解除通知，只要异议函 | `准备对合同解除通知的异议` |
| 只要确认解除效力或未解除的诉状 | `提起合同纠纷一审`（或仲裁确认） |
| 未成争，改解除条款或出稿 | 审查起草领域（本窗搁置，只说明） |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，不回改 |
