# 评估解除权是否成立

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“解除权是否成立”的专项评估：约定／法定路径表、催告是否必要、合理期限待核、除斥并行情景、到达与通知效力、异议后确认之诉分流。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价合同文本、催告／解除通知和争点表。

## 工作边界

正触发：拟解除，或已收到对方解除通知，需要判断约定解除、法定解除、催告是否必要、除斥是否可能届满，以及通知是否发生解除效力。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 已决定发出解除通知，只要发送前稿（转 `prepare-termination-notice`）；
- 只要争议总图，不要解除权专项结论（转 `assess-contract`）；
- 本次主成果是催告履行或补救（转 `prepare-demand-notice`）；
- 只要确认解除效力或未解除的起诉状；
- 建设工程、金融借贷担保、房地产物业、海事、劳动专项争议；
- 尚未成争，只要改解除条款或出稿（审查起草领域，本生产线搁置，只说明不实施）。

本任务不生成发送版解除函、催告终稿或确认之诉诉状，不给胜诉率。构成违约不等于当然解除。依法须催告且尚未催告时，不得写解除已成立。

## 建立评估坐标

确认：使用者与授权；单方立场（拟解除方或被解除方）；相对方；合同及附件版本；争议事项和合同目的条款；已发生迟延、拒绝、质量不符或不可抗力事实；已发出或已收到的催告、解除通知；法域；当前协商、仲裁、诉讼状态。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 解除路径假设；`V#` 评估版本；`E#` 发送／送达／履行凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典第 562–565、199 条和合同编通则解释第 53 条等现行文本；`search_practiced` 补催告必要、目的不能实现和除斥起算争点；特殊事实用 `search_case_by_fact`，明确筛选用 `search_case_by_filter`。不虚构案件系统。

`search_law` 对法律结论、除斥和通知效力为 required。工具不可用时继续事实、通知文本和问题清单；解除是否成立、除斥截止和“已解除”字段停止。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 专项分流、文本版本和通知状态

先做专项整案转出。再固定合同版本、约定解除条款和合同目的条款。程序表记录催告、解除通知、异议、起诉或仲裁：作出日、发出日、收到日、送达方式和效力凭证。微信“已读”不写成到达。口头转述不写成已经解除。

### 2. 约定解除路径

核对该当条件是否已成就。成就不等于已经发出有效通知，也不等于合同已解除。协商一致解除与约定条件解除分列。用户事后情绪或“没法合作了”不得补写成约定条件。

### 3. 法定解除路径与催告是否必要

按民法典第 563 条分项：不可抗力致目的不能实现；预期拒绝主要债务；迟延主要债务经催告后合理期限仍未履行；迟延或其他违约致使目的不能实现。迟延主要债务原则上先催告；只有目的不能实现的事实可回链时才讨论跳过催告。依法须催告且未催告，不得写解除已成立。

### 4. 除斥并行情景与到达效力

约定或法定除斥期间、知悉日起一年、对方催告后的合理期限并行，不混入诉讼时效，不适用中止、中断、延长（第 199 条）。通知到达对方时解除；无解除权的通知不因对方未异议而生效（通则解释第 53 条）。没有送达事实和规则引文，禁止写“合同已解除”。

### 5. 异议后确认之诉分流与转出

对方已异议或拟异议时，分流确认解除效力或未解除之诉／仲裁，本任务不写诉状。先核验仲裁协议是否覆盖本争议：表面有效则确认路径主位为仲裁，不得直接写应起诉；未核验则程序入口字段停止。解除路径未闭合只列缺口；用户已决定发函且条件可闭合则转介解除通知原子，不在本任务出稿。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或文本无法建立；用户坚持伪造催告、倒签解除通知或伪造送达。
- `字段停止`：法域、知悉日、送达日、动态规则未核验。
- `目标停止`：主目标已变为发送版解除函、催告终稿、确认之诉诉状或总体评估。
