# 评估解除权是否成立

## 任务目标

在明确、无利益冲突的单方立场下（拟解除方、被解除方或其受托律师，互斥），形成解除权专项评估草案：解除闸、主体与强制接口、`Q#` 路径、`JC#` 解除权行（路径切片／约定或法定该当／催告必要与合理期限／除斥并行情景／到达与通知效力／`E#` 回链）。本窗 `JC#` 是解除权行草案，不是已解除，不是催告发送版，不是解除函，不是诉状。本窗闸名只能是解除闸，禁止复用争议闸、论坛闸、催告闸、发送闸、精算闸、管辖闸、起诉闸。预留不得占用：立案闸、催告闸、发送闸、精算闸、论坛闸。本窗主行只能是 `JC#`，禁止 `ZT#`、`LT#`、`A#`。主路径只用 `Q-除`，禁止用 `Q-解`、`Q-催`、`Q-告`、`Q-函`、`Q-总`、`Q-坛`、`Q-诉` 作主路径。邻窗 `评估合同争议` 的 `Q-除` 只作转介进本窗；本窗打开为主路径。本窗 `Q-签` 只作「评估即已解除或已发送」不关窗码。解除闸打开不等于已违约不等于解除权已成立不等于已行使不等于催告已完成不等于已到达不等于除斥未届满不等于可发函。构成违约不是当然解除。催告不是已解除。解除通知草稿不是已到达解除。对方未异议不能补正解除权缺失。准备起诉不是已解除。除斥不是诉讼时效。口头或已读不是已送达。未知不写零。不写发送版催告或解除函。不写确认之诉诉状。不选定法院。不写唯一截止日。不定罪。不保证胜诉。不代提交。伤残等级与本窗无关，禁止折入。

`depends-on` 为空。主成果是争议总图转 `评估合同争议`。主成果是发送版催告转 `准备催告履行或补救通知`。主成果是发送版解除通知转 `准备解除通知`。主成果是异议函转 `准备对合同解除通知的异议`。主成果是确认解除或未解除起诉包转 `提起合同纠纷一审`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：拟解除，或已收到对方解除通知，需要判断约定解除、法定解除、催告是否必要、除斥是否可能届满，以及通知是否发生解除效力。「已经违约了」「今天发函就算解除」仍正触发，成果状态 `草案`。催告、送达、除斥未核验仍正触发：有可编号合同、催告、解除通知或履行碎片则解除闸打开或半开，第 6 节出 `JC#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出已解除终稿」才关闸，仍交十节，第 6 节不出 `JC#` 终稿，第 7 节不得出催告、解除函或诉状，窗口不关。用户要把构成违约写成当然解除、把须催告未催告写成已成立、把已读写成已到达、把准备起诉写成已解除、把未异议写成已解除、把未知写成零或唯一截止日，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `JC#` 草案。不得因「不写发送版解除函」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是争议总图（转 `评估合同争议`）；
- 主成果是发送版催告（转 `准备催告履行或补救通知`）；
- 主成果是发送版解除通知（转 `准备解除通知`）；
- 主成果是异议函终稿（转 `准备对合同解除通知的异议`）；
- 主成果是确认解除或未解除起诉包（转 `提起合同纠纷一审`）；
- 主成果是情势变更变更或解除之诉（转 `提起情势变更变更或解除之诉`）；
- 尚未成争，只要改解除条款或出稿（审查起草领域，本窗搁置，只说明不实施）；
- 建设工程、金融借贷担保、房地产物业、海事、劳动专项争议主轴。

双方秘密、伪造催告、倒签解除通知、伪造送达、隐匿证据、违法取证**不在负触发表**，走整体停止。「构成违约即已解除」「须催告未催告即已成立」「已读即已到达」「准备起诉即已解除」「未异议即已解除」「保证已解除」「未知写零」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不写发送版解除函」「不给胜诉率」是交付禁令，不是负触发。主成果才转；出现「解除」「催告」一词不是转出。

## 建立工作坐标

确认：评估授权；单方立场（拟解除方或被解除方或其受托律师，互斥）；合同及附件版本；已发生迟延、拒绝、质量不符或不可抗力事实；已发出或已收到的催告、解除通知；法域。

口头「已经违约了」「今天发函就算解除」只登记 `S#`／`V#`。不得升格已解除或已到达，**不得单独算作开闸材料**。可编号合同、催告、解除通知或履行碎片可开闸。已读不等于到达。本窗不执行发送，不代提交，不写催告或解除函。

立场只许拟解除方、被解除方或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：解除闸关闭，仍交十节，不是整体停止。无书面评估授权但单方立场已闭合、且已有碎片：解除闸部分打开，仍交十节，不是整体停止。提出伪造催告、倒签解除通知、伪造送达、隐匿证据或违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`JC#` 解除权行；`V#` 版本；`E#` 证据形态回链（合同版本、催告或解除通知、送达形态，不是发送闸，不是已解除证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`ZT#`、`LT#`。技能正文中的条号是检索锚点，不是已核验 `L#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。未知不写零。构成违约 ≠ 当然解除。催告 ≠ 已解除。草稿 ≠ 已到达。未异议 ≠ 已解除。准备起诉 ≠ 已解除。除斥 ≠ 诉讼时效。已读 ≠ 到达。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或裁判案例检索。本窗是解除权评估，**不要**用 `search_template` 生成催告、解除函、诉状或「已解除」证明。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现构成违约即解除、须催告未催告即已成立、已读即到达、未异议即已解除、准备起诉即已解除的反例；案例只比较事实差异与翻转条件，不写成必然结果。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把商品房解释催告后三个月套一般买卖当然适用。不得把合理期限写成一律十五日。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的解除是否成立、除斥或到达效力保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民法典第五百六十二条协议解除与约定解除。第五百六十三条法定解除分项；迟延主要债务原则上经催告后合理期限仍未履行。第五百六十四条解除权除斥；第一百九十九条不适用诉讼时效中止、中断、延长。第五百六十五条通知到达对方时解除；未通知而起诉或申请仲裁主张解除，确认该主张后自起诉状或仲裁申请书副本送达对方时解除。合同编通则解释第五十三条无解除权的通知不因对方未异议而生效。噪声：已失效《合同法》及其解释；商品房催告后三个月套一般买卖；一律十五日；唯一除斥截止日。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变解除成立、催告必要、除斥或到达效力的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补构成违约不是法定解除、须催告未催告不得写已成立、已读不是到达、未异议不能补正解除权缺失、成就不是已行使、准备起诉不是已解除的实务反例。
- `search_case_by_fact` 只比较事实差异与翻转条件：违约不是解除；未催告不是已成立；已读不是到达；未异议不是已解除；准备起诉不是已解除。无类案不得写成已解除。评估类禁止用 `search_template` 生成催告、解除函、诉状或「已解除」证明。

工具不可用时继续主体、文本版本和 `JC#` 编目；解除是否成立、除斥、「已解除」字段停止。不得拒跑，不得凭记忆写成已解除。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、解除闸与不关窗

主成果才整案转出。双方秘密、伪造催告、倒签第一次停。构成违约即解除不关窗。闸关仍交十节，第 6 节不出 `JC#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

约定解除／法定解除／协议解除分列。催告必要／可跳过催告分列。本节禁止出 `JC#` 终稿。

### 3. 解除闸与路径 `Q#`

本节禁止出 `JC#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-除`。

### 4. 解除权行 `JC#`

路径切片、该当、催告必要、除斥并行、到达效力。状态 `草案`。禁止升格已解除、已到达、已行使。无 `E#` 不得写已解除。

### 5. 催告、发函、确认之诉接口

催告转催告窗。发函转发送窗。第 7 节不得夹带 `JC#` 终稿或发送版函绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造催告、倒签解除通知、伪造送达、隐匿证据或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：解除闸关闭，仍交十节，不是整体停止。无书面评估授权但有碎片：解除闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：催告必要、合理期限、除斥起算、送达、施行日未核验。构成违约即解除、须催告未催告即已成立、已读即到达、准备起诉即已解除、未异议即已解除、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `JC#` 草案。
- `目标停止`：主目标变为发送版函、催告终稿、确认之诉诉状或争议总图。禁止把「构成违约即已解除」当作用户错误主张时的目标停止；那是不关窗。

禁止指导伪造催告或倒签解除日。不给胜诉率。不定罪。不选定法院。不代提交。未知不写零。不写唯一截止日。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。解除闸关闭仍交十节，第 6 节不出 `JC#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `JC#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。解除闸未打开时不得交付「已解除」。边界见 [路由](references/routing.md)。
