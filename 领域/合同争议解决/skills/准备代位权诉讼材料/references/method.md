# 准备代位权诉讼材料方法

本文件是可执行判断节点。草稿不是已提交。评估不是已代位成立。未列债务人不是可交终稿。此致某院不是管辖已定。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已提交、已立案、已代位成立、选定法院、代提交、未知写零。本任务不定罪，不写发送版起诉状，不把草稿写成已提交。本窗闸名只能是位诉闸，禁止复用起诉闸、代权闸、诉材闸、立案闸。预留不得占用：立案闸、催告闸、解除闸、发送闸。本窗 `WQ#` 是位诉行。主路径只用 `Q-位诉`，禁止用 `Q-位`、`Q-代`、`Q-诉`、`Q-签` 作主路径。本窗 `Q-签` 只作「草稿即已提交或已立案」不关窗码。英文 id 禁止使用，一律用中文技能名 `准备代位权诉讼材料`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991 年民诉第一百二十二条开庭通知、2017 年第一百十九条、已失效合同法第七十三条、解释（一）第十一条至第二十二条、把「次债务人」或第四十四条撤销权列法当本窗规则时记为噪声。禁止指导伪造次债权或虚假诉讼。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现请求碎片扫描，不是默认闭集。
`WQ#` 固定列：`编号｜请求切片｜原告适格与被告第三人列法｜次债权管辖与仲裁中止｜范围费用与从权利｜证据目录通知债务人与保全红旗｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已提交」或「已立案」。无 `E#` 不得写已提交。列法或管辖未闭合不得标 `待提交`。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-位诉`。禁止 `DQ#`、`CQ#`、`QT#`、`QS#`、`SC#`、`DW#`、`A#`、`N#`。

口头「今晚交出去」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：被告是相对人，债务人是第三人。管辖是被告住所地，专属除外。次债权管辖协议异议不予支持。

## 节点 0　分流、立场、位诉闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造次债权、倒签、虚假诉讼不进负表。利益冲突未解不进整体停止。不代提交、不选定法院不是负触发。把草稿写成已提交、把评估写成已代位成立不是负触发。

整案转出只交付第 1、2、10 节，不出 `WQ#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是代位条件评估终稿 | 负触发 `评估债权人代位权` |
| 主成果是普通给付诉状 | 负触发 `提起合同纠纷一审` |
| 主成果是撤销权诉状 | 负触发 `准备债权人撤销权诉讼` |
| 主成果是保险代位求偿诉状 | 整案转金融借贷担保或保险 |
| 主成果是实际施工人工程代位 | 整案转建设工程 |
| 主成果是股东代表诉讼 | 整案转公司治理 |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 尚未评估代位条件，只要策略 | 负触发 `评估债权人代位权` |
| 「不代提交」「不选定法院」 | 交付禁令，不是负触发 |

出现「代位」「起诉」一词不是转出。

位诉闸打开（可出 `WQ#` 草案，仍不得标「已提交／已立案／已代位成立」）须同时满足：单方无冲突立场已闭合；主成果是代位起诉材料草稿，不是发送版终稿；至少一行可编号两层债权、相对人或起诉决定碎片。口头「今晚交出去」不算单独开闸材料。

位诉闸部分打开：已有碎片，但列法、管辖或范围未闭合；对应格待核；仍交十节。无书面授权但单方立场已闭合且已有碎片：位诉闸部分打开，仍交十节，不是整体停止。

位诉闸关闭（仍正触发）：无一可编号碎片。「今天必须出已提交／已立案终稿」而无最小碎片不得开闸。不出 `WQ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `WQ#` 终稿，**第 7 节不得出发送版起诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已提交」「评估即已代位成立」「催告即怠于」「专属即可代位」「一揽子全部对外债权」「次债权仲裁即应起诉或当然不受理」「未列第三人仍可交终稿」「此致某院即管辖已定」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `WQ#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 位诉闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造次债权或怠于证据、倒签、隐匿责任财产、虚假诉讼或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个请求切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `WQ#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 列法 | 原告债权人、被告相对人、第三人债务人分列 | 债务人当唯一被告；「次债务人」称谓 |
| 管辖 | 被告住所地、专属除外分列 | 次债权管辖协议升格；此致某院 |
| 仲裁 | 异议原则上不支持、首次开庭前申请可中止分列 | 当然应起诉或当然不受理 |
| 范围 | 以债权人到期债权为限分列 | 一揽子全部对外债权 |
| 怠于 | 诉讼或仲裁主张缺口分列 | 催告升格怠于 |

检索锚点（写入 `L#` 前须核验）：见技能正文 MCP 节。噪声：1991 年民诉第一百二十二条；2017 年第一百十九条；解释（一）第十一条至第二十二条。

## 节点 3　位诉行 `WQ#`

按已出现请求碎片扫描，不是默认闭集。每条须能指向列法、管辖、范围或证据目录之一。

无 `E#` 不得写已提交。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止唯一截止日。列法或管辖未闭合不得标 `待提交`。

热冲突强制处理：

- 草稿即已提交／评估即已代位成立／催告即怠于／一揽子全部对外债权／此致某院即管辖已定／未知写零 → 该格不支持或字段停止；仍出其他 `WQ#`。
- 无一碎片 → 关闸，不出 `WQ#` 终稿，窗口不关。
- 指导伪造次债权、虚假诉讼 → 整体停止，不是该格不支持。

## 节点 4　评估、普通起诉、撤销、保全接口

第 7 节只开接口，不得夹带 `WQ#` 终稿或发送版起诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待列法编号」，不得补写已提交。不选定法院。不代提交。不写发送版起诉状。

下一步只转介：`评估债权人代位权`、`评估债权人撤销权`、`准备债权人撤销权诉讼`、`评估债权转让与债务承担争议`、`评估合同争议`、`评估合同管辖与仲裁协议`、`提起合同纠纷一审`、`应对合同纠纷一审`、`建立合同争议证据案卷`、`评估争议期间`、`评估合同财产保全必要性`、`准备合同财产保全申请`、`申请律师调查令或法院调查取证`、`评估抵销留置与扣款抗辩`、`选择诉讼仲裁或督促程序`、`提起合同仲裁`。禁止此致某院。

若 if 用户催促「今晚交出去／此致某院先填上／把全部对外债权都写上／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

每个节点结束后回写：来源、判断、最强反方、是否字段停止。不得跳过位诉闸直接给已提交或已立案。

若 if 列法、管辖、仲裁中止、范围、施行日未核验，then 该强制项字段停止，窗口不关。

## 本任务回链纪律

本任务成果是「位诉闸与位诉行草案」。本窗不执行发送。不包含：已提交、已立案、已代位成立、发送版起诉状。禁止选边治愈。禁止草稿即已提交。禁止列债务人为唯一被告。禁止指导伪造。位诉闸打开 ≠ 已提交 ≠ 已立案 ≠ 已代位成立。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标位诉终稿已形成。
风险档 A：伪造次债权、倒签、虚假诉讼必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：债权人已决定代位起诉，草稿把债务人列为唯一被告，请求写上债务人全部对外债权，催告函当怠于证据，此致某院先填某中院，主张今晚交出去就算已提交、评估过就算已代位成立、不清楚先写零。次债权订有仲裁。位诉闸打开或半开。`Q-签`、`Q-状`、`Q-揽`、`Q-列`、`Q-院`、`Q-次`、`Q-零` 不打开为可靠路径。第 6 节不得把已提交、已代位成立、一揽子请求、0 写入可执行 `WQ#`；对应格 `现有依据不支持` 或字段停止；仍出列法分列、被告住所地缺口、范围以到期债权为限、仲裁中止接口等其他 `WQ#`。不关窗。不代提交。不写发送版。

场景②：用户同时交出己方「把怠于证明倒签到一年前、次债权确认书用空白章补一份」与对方「债务人已起诉相对人」口径，并要「先立案再说」。命中双方秘密＋倒签＋伪造。第一次整体停止。只交第 1、10 节。不出 `WQ#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代违法方案。
