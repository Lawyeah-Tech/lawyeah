# 边界与路由

## 正触发

已决定以自己的名义代位起诉债务人的相对人，需要起诉材料草稿。从零、碎片、列法未核验、无书面授权仍正触发：有可编号两层债权、相对人或起诉决定碎片则闸开或半开，出 `WQ#` 草案，保持草案。本次不代提交、不选定法院是交付禁令，不是开窗条件。草稿即已提交、评估即已代位成立、未列第三人仍可交终稿，仍正触发。把此致某院写成管辖已定，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造次债权、倒签、虚假诉讼的停止，优先于负触发。上述信号不在下表。不代提交不是负触发。「草稿即已提交」「评估即已代位成立」「催告即怠于」「专属即可代位」「一揽子全部对外债权」「次债权仲裁即应起诉或当然不受理」「未列第三人仍可交终稿」「此致某院即管辖已定」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 代位条件评估终稿 | `评估债权人代位权` |
| 普通给付诉状 | `提起合同纠纷一审` |
| 撤销权诉状 | `准备债权人撤销权诉讼` |
| 保险代位求偿诉状 | 金融借贷担保或保险 |
| 实际施工人工程代位 | 建设工程领域 |
| 股东代表诉讼 | 公司治理 |
| 争议总图 | `评估合同争议` |

不得因「不代提交」或「不选定法院」关窗。拟位诉草稿仍正触发，不得写成已提交或已立案。

## 易混

本窗闸名只能是位诉闸，不是起诉闸，不是代权闸，不是诉材闸，不是立案闸。`WQ#` 不是 `DQ#`，不是 `QT#`，不是 `CQ#`。主路径是 `Q-位诉`，不是 `Q-位`，不是 `Q-诉`，不是 `Q-代`。`起诉闸`／`Q-诉` 是提起合同纠纷一审。`代权闸`／`Q-位` 是评估债权人代位权。`诉材闸` 是合规追偿诉材。草稿不是已提交。评估不是已代位成立。被告是相对人，债务人是第三人。管辖是被告住所地，次债权管辖协议异议不予支持。MCP 查询第一百二十二条可能先返回 1991 年开庭通知条，须核 2023 修正起诉条件。2017 年第一百十九条不是现行。已失效合同法第七十三条及解释（一）第十一条至第二十二条不是现行。「次债务人」不是现行称谓。第四十四条是撤销权诉讼。「今晚交出去」「怠于证明倒签」整体停止。本窗不执行发送，不代提交。不选定法院。不写发送版起诉状。
