# 边界与路由

## 正触发

一般合同已成争，解除权评估或等价材料支持发出解除通知，单方需要发送前稿、到达设计和异议应对。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |
| 只要总体争议总图 | `评估合同争议` |
| 只判断能否解除 | `评估解除权是否成立` |
| 依法须催告且催告未完成；或只要催告履行／补救 | `准备催告履行或补救通知` |
| 只要单独设计送达渠道、不写通知实体 | `设计合同案件通知送达` |
| 已收到解除通知，要异议或确认未解除 | `准备对合同解除通知的异议` |
| 精算违约金或损失 | `测算违约金与损害赔偿` |
| 完整证据卷 | `建立合同争议证据案卷` |
| 和解条件 | `谈判合同和解方案` |
| 以起诉或仲裁主张解除，要诉状／申请 | `提起合同纠纷一审` 或仲裁申请项 |
| 确认解除效力或未解除之诉 | `提起合同纠纷一审` |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，只分流，不回改 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

用户说“今天发函解除”，但材料只证明迟延或质量不符、催告未完成：负触发或目标停止，转催告或解除权评估，不把解除通知改写成催告。用户要把“逾期即已解除”写进催告：不在本包出稿，转催告项并禁止该表述，除非解除权条件已核验闭合。用户准备起诉主张解除：本任务可说明起诉／仲裁是另一路径，但不写诉状。微信已读、对方未异议，不得写成合同已解除。
