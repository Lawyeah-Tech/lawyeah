# 边界与路由

## 正触发

一般合同已成争，用户需要发送前解除通知。从零、碎片、催告未核验、无书面发函授权仍正触发：有可编号路径切片、等价解除权材料或催告闭合碎片则闸开或半开，出 `HF#` 草案，保持草案。依法须催告且催告未完成、主成果仍是解除通知，仍正触发：闸关或半开，仍交十节，不出终稿。本次不执行发送、不保证到达、不代提交、不写已解除是交付禁令，不是开窗条件。发出即已解除、已读即已到达、草稿即已发送，仍正触发。

双方秘密、伪造催告或解除函、倒签发出日、伪造送达、隐匿证据、违法取证的停止，优先于负触发。上述信号不在下表。不执行发送不是负触发。「发出即已解除」「须催告未催告即已解除」「已读即已到达」「草稿即已发送」「未异议即已解除」「准备起诉即已解除」不在下表。伪造倒签不在下表，走整体停止。依法须催告且催告未完成不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 争议总图 | `评估合同争议` |
| 解除权评估（不发函） | `评估解除权是否成立` |
| 发送版催告 | `准备催告履行或补救通知` |
| 异议函 | `准备对合同解除通知的异议` |
| 索赔通知 | `准备索赔或违约金主张通知` |
| 精算工作表 | `测算违约金与损害赔偿` |
| 独立复杂送达方案 | `设计合同案件通知送达` |
| 完整证据卷 | `建立合同争议证据案卷` |
| 清理返还终稿 | `处理解除后返还与清理` |
| 起诉包或确认之诉 | `提起合同纠纷一审` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |
| 工程／金融／房产／海事／劳动主轴 | 对应领域 |

不得因「不执行发送」或「不写已解除」关窗。拟解除通知草稿仍正触发，不得写成已发送或已解除。不得因「须催告未完成」改走负触发。

## 易混

本窗闸名只能是发送闸，不是解除闸，不是催告闸，不是争议闸。`HF#` 不是催告，不是诉状，不是 `FS#`。主路径是 `Q-函`，不是 `Q-解`，不是 `Q-告`，不是 `Q-除`。邻窗 `Q-函` 只转介发送前解除通知草稿，不是已发出。解除通知草稿不是已发送。已读不是已到达。草稿不是已解除。无解除权通知不因未异议而生效。须催告未催告不是已解除。已失效《合同法》不是现行规则。破产或劳动合同解除范本不是本窗。依法须催告未完成不是负触发。「把解除通知倒签」整体停止。本窗不执行发送，不代提交。不保证到达。
