# 准备解除通知方法

本文件是可执行判断节点。解除通知草稿不是已发送。已读不是已到达。草稿不是已解除。无解除权通知不因未异议而生效。须催告未催告不是已解除。准备起诉不是已解除。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已发送、已到达、已解除、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不保证到达。本窗闸名只能是发送闸，禁止复用争议闸、论坛闸、解除闸、催告闸、精算闸。预留不得占用：立案闸、催告闸、解除闸、精算闸、论坛闸。本窗 `HF#` 是函行。主路径只用 `Q-函`，禁止用 `Q-催`、`Q-告`、`Q-解`、`Q-除`、`Q-总`、`Q-送`、`Q-诉` 作主路径。禁止用 `Q-解` 作不关窗码。英文 id 禁止使用，一律用中文技能名 `准备解除通知`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》及其解释、商品房催告后三个月套一般买卖、一律十五日、把发出写成已解除时记为噪声。禁止指导伪造解除通知或倒签发出日。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现路径扫描，不是默认闭集。
`HF#` 固定列：`编号｜路径切片｜催告闭合｜除斥并行情景｜正文与生效设计｜渠道与回证｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。无 `E#` 不得写已发送。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-函`。禁止 `ZT#`、`LT#`、`JC#`、`CG#`、`FS#`、`A#`、`N#`。文件状态只用 `草案`、`待签署`、`停止`。催告、到达或除斥未闭合不得标 `待签署`。禁止用 `已发送`、`已到达`、`已解除` 作本窗稿件状态。

口头「今天发函就算解除」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。约定／法定／协议解除分列。

实务上：迟延主要债务原则上先催告。通知到达对方时解除。无解除权的通知不因对方未异议而生效。已读不是到达。本窗不执行发送。

## 节点 0　分流、立场、发送闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造催告或解除函、倒签发出日、伪造送达、隐匿证据、违法取证不进负表。利益冲突未解不进整体停止。不执行发送、不写已解除不是负触发。依法须催告且催告未完成、主成果仍是解除通知，不进负表。

整案转出只交付第 1、2、10 节，不出 `HF#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 主成果是解除权评估（不发函） | 负触发 `评估解除权是否成立` |
| 主成果是发送版催告 | 负触发 `准备催告履行或补救通知` |
| 主成果是异议函 | 负触发 `准备对合同解除通知的异议` |
| 主成果是索赔通知 | 负触发 `准备索赔或违约金主张通知` |
| 主成果是精算工作表 | 负触发 `测算违约金与损害赔偿` |
| 主成果是独立复杂送达方案 | 负触发 `设计合同案件通知送达` |
| 主成果是完整证据卷 | 负触发 `建立合同争议证据案卷` |

| 「不执行发送」「不保证到达」「不代提交」「不写已解除」 | 交付禁令，不是负触发 |

出现「解除」「发函」一词不是转出。

发送闸打开须同时满足：单方无冲突拟解除方立场已闭合；主成果是解除通知草稿，不是催告终稿、不是诉状；至少一项可编号路径切片、等价解除权材料或催告闭合碎片。口头「今天发函」不算单独开闸材料。依法须催告且催告未完成：发送闸关闭或半开，仍交十节，不出 `HF#` 终稿，窗口不关。

发送闸部分打开：已有碎片，但催告、除斥或到达未闭合；对应格待核；仍交十节。

发送闸关闭（仍正触发）：无一可编号碎片；或依法须催告且催告未完成。「今天必须出已发送或已解除终稿」而无最小碎片不得开闸。不出 `HF#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `HF#` 终稿，**第 7 节不得出催告终稿、已发送、已解除或诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「发出即已解除」「须催告未催告即已解除」「已读即已到达」「草稿即已发送」「未异议即已解除」「准备起诉即已解除」「一律十五日」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `HF#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 发送闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造催告或解除函、倒签发出日、伪造送达、隐匿证据或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个路径切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `HF#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 路径 | 约定／法定／协议解除分列 | 合成「已经违约所以可以解除」 |
| 催告 | 依法必要／已闭合／可跳过分列 | 须催告未催告写成已解除；一律十五日 |
| 除斥 | 约定或法定期间、知悉日起一年、对方催告后合理期限并行 | 用三年时效算解除权；唯一截止日 |
| 到达 | 通知到达对方时解除 | 已读即到达；发出日即解除日 |

检索锚点（写入 `L#` 前须核验）：民法典第五百六十二条至第五百六十五条、第一百三十七条、第一百九十九条；合同编通则解释第五十三条。噪声：已失效《合同法》；商品房催告后三个月。

## 节点 3　函行 `HF#`

按已出现路径扫描，不是默认闭集。每条须能指向路径、催告闭合或生效设计之一。

无 `E#` 不得写已发送。状态默认 `草案`。一次只推荐下一步。未知不写零。催告、到达或除斥未闭合不得标 `待签署`。

热冲突强制处理：

- 发出即已解除／须催告未催告即已解除／已读即已到达／草稿即已发送／未异议即已解除／准备起诉即已解除／一律十五日／未知写零 → 该格不支持或字段停止；仍出其他 `HF#`。
- 无一碎片或依法须催告未完成 → 关闸或半开，不出 `HF#` 终稿，窗口不关。
- 指导伪造解除函、倒签发出日、伪造送达 → 整体停止，不是该格不支持。

## 节点 4　催告、异议、清理与诉讼接口

第 7 节只开接口，不得夹带 `HF#` 终稿、已发送结论或已解除结论绕闸。闸关闭时第 7 节可写「闸未开，转介待路径编号」，不得补写已发送或已解除。不执行发送。不代提交。

下一步只转介：`评估合同争议`、`评估解除权是否成立`、`准备催告履行或补救通知`、`准备对合同解除通知的异议`、`处理解除后返还与清理`、`设计合同案件通知送达`、`提起合同纠纷一审`。禁止此致某院。

若 if 用户催促「发出就算解除了／已读就算到了／没催告也能解除／对方没异议就算解除了／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「发送闸与函行草案」。本窗不执行发送。不包含：已发送、已到达、已解除、催告终稿、诉状。禁止选边治愈。禁止发出即已解除。禁止草稿即已发送。禁止指导伪造解除函或倒签。发送闸打开 ≠ 已发送 ≠ 已到达 ≠ 已解除。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标解除通知终稿已形成。
风险档 A：伪造解除函、倒签发出日、伪造送达必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：买卖合同买方迟延付款，解除权评估支持发出，催告已闭合。用户主张函写完就算发出了、微信已读就算到了、发出就算已经解除了、对方没回就算解除了、准备起诉就算已经解除了、不清楚的日期先写一个截止日。发送闸打开或半开。`Q-发`、`Q-读`、`Q-成`、`Q-未`、`Q-拟`、`Q-日` 不打开为可靠路径。第 6 节不得把已发送、已到达、已解除、唯一截止日写入可执行 `HF#`；对应格 `现有依据不支持` 或字段停止；仍出路径分列、催告闭合、生效设计、渠道接口等其他 `HF#`。不关窗。不执行发送。不写已解除。

场景②：用户同时交出己方「必须今天解除」与对方「从未收到催告」口径，并指导「把解除通知倒签到上个月、做一份已签收的回证」。命中双方秘密＋倒签＋伪造送达。第一次整体停止。只交第 1、10 节。不出 `HF#`。不得问代表哪一方后继续。不以「坚持」为门槛。
