# 申请撤销仲裁裁决

## 任务目标

在明确、无利益冲突的单方立场下（拟申请撤销的裁决当事人或其受托律师，互斥），形成发送前撤销申请草稿：撤裁闸、主体与强制接口、`Q#` 路径、`HC#` 撤裁行（裁决切片／送达与撤销期／法定事由对照／中院管辖与重新仲裁接口／申请接口／`E#` 回链）。本窗 `HC#` 是撤裁行草案，不是已提交，不是已裁定撤销，不是不予执行终稿，不是上诉状，不是再审。本窗闸名只能是撤裁闸，禁止复用撤销闸、撤权闸、撤诉闸、仲裁闸、起诉闸、上诉闸、开庭闸、支付闸、申请闸、执行闸。预留不得占用：立案闸、保全闸、应裁闸、不执闸。本窗主行只能是 `HC#`，禁止 `CC#`、`CX#`、`CQ#`、`XQ#`、`ZC#`、`ZX#`、`HS#`、`LF#`、`KT#`、`SS#`、`A#`。主路径只用 `Q-撤裁`，禁止用 `Q-撤`、`Q-撤诉`、`Q-申`、`Q-金令`、`Q-开庭`、`Q-上`、`Q-裁`、`Q-仲`、`Q-仲异`、`Q-签` 作主路径。邻窗 `Q-撤裁` 只作转介进本窗；本窗打开为主路径，不是已撤销、不是已提交。本窗 `Q-不执` 只转介 `申请不予执行仲裁裁决`。本窗 `Q-撤` 不打开（撤权窗）。本窗 `Q-签` 只作「草稿即已提交或已撤销」不关窗码。撤裁闸打开不等于已提交不等于已撤销不等于待提交终稿。草稿不是已撤销。网交不是已提交。三个月除斥不是时效，不得中断或延长。已读或作出日不是收到起算。实体不服通常不足。未获通知不是国内闭集（涉外清单只开接口）。撤销不是不予执行。驳回后再以相同事由交叉提通常不支持。可上诉裁定或判决不是撤裁对象。劳动终局单位撤裁不是本窗。未知不写零。不代提交。不选定中院。不定罪。不保证撤销。伤残等级与本窗无关，禁止折入。

`depends-on` 为空。主成果是不予执行终稿转 `申请不予执行仲裁裁决`。主成果是上诉状转 `提起合同案件上诉`。主成果是执行申请转 `执行合同生效文书`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：一般合同商事仲裁裁决已作出，拟申请撤销草稿。「裁决不公今晚交出去」「按六个月还有时间」仍正触发，成果状态 `草案`，不代提交。收到日、事由、管辖未核验仍正触发：有可编号裁决书或收到日碎片则撤裁闸打开或半开，第 6 节出 `HC#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出已撤销终稿」才关闸，仍交十节，第 6 节不出 `HC#` 终稿，第 7 节不得出发送版申请，窗口不关。用户要把草稿写成已撤销、把三个月写成六个月现行、把实体不服写成应撤销、把逾期写成仍可提交终稿、把撤销写成不予执行终稿、把未知写成零、把此致某中院写成管辖已定，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `HC#` 草案。不得因「不保证撤销」「不代提交」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是不予执行终稿（转 `申请不予执行仲裁裁决`）；
- 主成果是上诉状（转 `提起合同案件上诉`）；
- 主成果是执行申请（转 `执行合同生效文书`）；
- 主成果是应裁实体（转 `应对合同仲裁`）；
- 主成果是仲异或效力确认（转 `准备合同仲裁协议异议材料`）；
- 主成果是仲裁申请（转 `提起合同仲裁`）；
- 尚未成争，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）。

双方秘密、伪造裁决或程序材料、倒签收到日、虚假仲裁、违法取证**不在负触发表**，走整体停止。STUB 把「期限届满仍要求可提交终稿」放进负触发，必须改不关窗：该格不支持，不出可提交终稿，窗口不关。STUB 把「与不予执行混用同一主成果」放进负触发：主成果才转；混写该格不支持，不出两份主位终稿。STUB 把「对法院判决撤销」放进负触发：主成果才转上诉窗；把判决当裁决撤该格不支持，窗口不关。「草稿即已撤销」「六个月仍现行」「实体不服即应撤销」「未知写零」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不保证撤销」「不代提交」是交付禁令，不是负触发。主成果才转；出现「撤销」「裁决」一词不是转出。

## 建立工作坐标

确认：申请授权；单方立场；裁决切片；收到日；法定事由；机构所在地；法域；当前执行或另诉状态。

口头「裁决不公今晚交出去」只登记 `S#`／`V#`。不得升格已提交、已撤销或收到日起算，**不得单独算作开闸材料**。可编号裁决书或收到日碎片可开闸。本窗不执行发送，不代提交。

立场只许拟申请撤销的裁决当事人或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：撤裁闸关闭，仍交十节，不是整体停止。无书面授权但单方立场已闭合、且已有碎片：撤裁闸部分打开，仍交十节，不是整体停止。提出伪造裁决或程序材料、倒签收到日、虚假仲裁或违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 合同或仲裁条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`HC#` 撤裁行；`V#` 版本；`E#` 证据形态回链（裁决书、收到日、程序记录，不是发送闸，不是已撤销证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`CC#`、`ZC#`、`HS#`、`XQ#`、`CQ#`。技能正文中的条号是检索锚点，不是已核验 `L#`。文件状态只用 `草案`、`停止`。期限或事由未闭合不得标待提交。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。未知不写零。草稿 ≠ 已撤销。三个月 ≠ 六个月现行。实体不服 ≠ 应撤销。撤销 ≠ 不予执行。已读 ≠ 收到起算。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或文书范本检索。本窗是申请草稿准备，范本只借撤销仲裁裁决申请书栏目，**不要**升格「已提交／已裁定撤销／管辖已定」。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现草稿即已撤销、六个月仍现行、实体不服即应撤销、与不予执行混同一终稿的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把 1994 年或 2017 年第五十八条、第五十九条六个月当作现行。不得把 1994 年第七十二条外国承认执行当作三个月除斥。不得把「未获通知」写入国内闭集。不得把劳动争议调解仲裁法第四十九条单位撤终局套商事。仲裁法 2025 修订施行日 2026-03-01 已施行，MCP 标尚未施行时以施行日为准。解释仍引第五十八条须核对应第七十一条。MCP 效力字段与公布施行日冲突时，以施行日为准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的收到日、三个月、事由、管辖或施行日保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：仲裁法（2025 修订，施行日 2026-03-01）第七十一条当事人提出证据证明裁决有下列情形之一的，可以向仲裁机构所在地的中级人民法院申请撤销：没有仲裁协议；事项不属于协议范围或机构无权仲裁；组成或程序违反法定程序；证据伪造；隐瞒足以影响公正裁决的证据；仲裁员索贿受贿、徇私舞弊、枉法裁决。合议庭审查核实应当裁定撤销；违背公共利益的应当裁定撤销。噪声：1994 年或 2017 年第五十八条；「仲裁委员会所在地」未核验即定院。第七十二条应当自收到裁决书之日起三个月内提出。噪声：2017 年第五十九条六个月；1994 年第七十二条外国承认执行。第七十三条受理之日起两个月内作出撤销或驳回裁定。第七十四条认为可以重新仲裁的，通知仲裁庭并裁定中止撤销程序；仲裁庭开始重新仲裁的应当裁定终结撤销程序；拒绝的应当恢复。噪声：2017 年第六十一条未核「开始则终结」。第七十六条不予执行国内裁决事由与第七十一条衔接。第七十七条一方申请执行、另一方申请撤销的应当中止执行；裁定撤销则终结执行，驳回则恢复。噪声：2017 年第六十四条。解释第二十六条撤裁被驳回后以相同理由申请不予执行的，人民法院不予支持；条号运行时核验。解释第二十一条伪造或隐瞒证据可以通知重新仲裁，所引第六十一条须核第七十四条。解释第二十三条重新仲裁裁决不服的期间，所引第五十八条及六个月须核第七十一条、第七十二条三个月。执行规定（2018）第七条受理撤裁应当中止执行；第二十条相同事由交叉提通常不支持。民诉（2023）第二百四十八条不予执行只开接口。噪声：2017 年第二百三十七条。技能正文条号不是 `L#`。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、撤裁闸与不关窗

主成果才整案转出。双方秘密、伪造、倒签收到日第一次停。草稿即已撤销、六个月仍现行不关窗。闸关仍交十节，第 6 节不出 `HC#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

裁决／收到日／法定事由／中院管辖／不予执行分流分列。实体不服关可提交该格。本节禁止出 `HC#` 终稿。

### 3. 撤裁闸与路径 `Q#`

本节禁止出 `HC#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-撤裁`。

### 4. 撤裁行 `HC#`

切片、期限、事由、管辖与重新仲裁、申请接口。状态 `草案`。禁止升格已提交、已撤销。无 `E#` 不得写已撤销。

### 5. 不予执行、执行、上诉与仲裁接口

不予执行转不执窗。执行只开中止接口。第 7 节不得夹带 `HC#` 终稿或发送版绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造裁决或程序材料、倒签收到日、虚假仲裁或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：撤裁闸关闭，仍交十节，不是整体停止。无书面授权但有碎片：撤裁闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：收到日、三个月、第七十一条逐项、管辖、施行日未核验。草稿即已撤销、六个月仍现行、实体不服即应撤销、逾期仍可提交终稿、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `HC#` 草案。
- `目标停止`：主目标变为不予执行终稿、上诉状或执行申请。禁止把「期限届满仍要可提交终稿」当作用户错误主张时的目标停止；那是不关窗。

禁止指导伪造裁决或倒签收到日。不给撤销率。不定罪。不选定中院。不代提交。未知不写零。不写发送版。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。撤裁闸关闭仍交十节，第 6 节不出 `HC#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `HC#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。撤裁闸未打开时不得交付「已撤销」或「已提交」。边界见 [路由](references/routing.md)。
