# 申请撤销仲裁裁决方法

本文件是可执行判断节点。草稿不是已撤销。三个月除斥不是时效。已读不是收到起算。实体不服通常不足。撤销不是不予执行。未知不写零。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止撤销率、已撤销、已提交、选定中院、代提交、未知写零。本任务不定罪，不执行发送，不保证撤销。本窗闸名只能是撤裁闸，禁止复用撤销闸、撤权闸、撤诉闸、仲裁闸、上诉闸。预留不得占用：立案闸、保全闸、不执闸。本窗 `HC#` 是撤裁行。主路径只用 `Q-撤裁`，禁止用 `Q-撤`、`Q-撤诉`、`Q-申`、`Q-上`、`Q-裁`、`Q-签` 作主路径。本窗 `Q-签` 只作「草稿即已提交或已撤销」不关窗码。英文 id 禁止使用，一律用中文技能名 `申请撤销仲裁裁决`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1994 年或 2017 年第五十八条、第五十九条六个月、1994 年第七十二条外国承认执行、把未获通知写入国内闭集、MCP 标 2025 尚未施行时记为噪声。禁止指导伪造裁决或倒签收到日。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现裁决切片扫描，不是默认闭集。
`HC#` 固定列：`编号｜裁决切片｜送达与撤销期｜法定事由对照｜中院管辖与重新仲裁接口｜申请接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已撤销」或「已提交」。无 `E#` 不得写已撤销。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-撤裁`。禁止 `CC#`、`ZC#`、`HS#`、`XQ#`、`CQ#`、`A#`、`N#`。文件状态只用 `草案`、`停止`。

口头「裁决不公今晚交出去」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。不写死唯一日历截止日。

实务上：国内事由限于第七十一条六项加公共利益，实体不服通常不足。期间自收到日起三个月。管辖是仲裁机构所在地中院。撤裁被驳回后相同事由不予执行通常不支持。开始重新仲裁可能终结本窗。

## 节点 0　分流、立场、撤裁闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造、倒签收到日、虚假仲裁、违法取证不进负表。利益冲突未解不进整体停止。不保证撤销、不代提交不是负触发。

整案转出只交付第 1、2、10 节，不出 `HC#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是不予执行终稿 | 负触发 `申请不予执行仲裁裁决` |
| 主成果是上诉状 | 负触发 `提起合同案件上诉` |
| 主成果是执行申请 | 负触发 `执行合同生效文书` |
| 主成果是应裁实体 | 负触发 `应对合同仲裁` |
| 主成果是仲异或效力确认 | 负触发 `准备合同仲裁协议异议材料` |
| 主成果是仲裁申请 | 负触发 `提起合同仲裁` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程／金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不保证撤销」「不代提交」 | 交付禁令，不是负触发 |

出现「撤销」「裁决」一词不是转出。

撤裁闸打开须同时满足：单方无冲突立场已闭合；主成果是撤销申请草稿，不是不予执行终稿、不是上诉状、不是发送版；至少一项可编号裁决书或收到日碎片。口头「裁决不公」不算单独开闸材料。

撤裁闸部分打开：已有碎片，但收到日、事由或管辖未闭合；仍交十节。

撤裁闸关闭（仍正触发）：无一可编号碎片。不出 `HC#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `HC#` 终稿，**第 7 节不得出发送版申请**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已撤销」「六个月仍现行」「实体不服即应撤销」「逾期仍可提交终稿」「未知写零」**不关窗**。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 撤裁闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造裁决或程序材料、倒签收到日、虚假仲裁或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个裁决切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `HC#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 切片 | 国内商事裁决分列 | 劳动终局、体育、涉外未分卡 |
| 收到日 | 签收或送达回证 | 已读、作出日、网站公布起算 |

## 节点 3　撤裁行 `HC#`

按已出现裁决切片扫描，不是默认闭集。每条须能指向裁决、收到日或法定事由之一。

无 `E#` 不得写已提交或已撤销。状态默认 `草案`。一次只推荐下一步。未知不写零。期限或事由未闭合不得标待提交。

热冲突强制处理：

- 草稿即已撤销／六个月仍现行／实体不服即应撤销／逾期仍可提交终稿／未知写零 → 该格不支持或字段停止；仍出其他 `HC#`。
- 无一碎片 → 关闸，不出 `HC#` 终稿，窗口不关。
- 指导伪造、倒签收到日 → 整体停止，不是该格不支持。

## 节点 4　不予执行、执行、上诉与仲裁接口

第 7 节只开接口，不得夹带 `HC#` 终稿或发送版绕闸。闸关闭时第 7 节可写「闸未开，转介待事项编号」，不得补写已撤销。不选定中院。不代提交。一方执行一方撤裁只开中止执行接口，不保证停止处分。开始重新仲裁可能终结本窗。

下一步只转介：`申请不予执行仲裁裁决`、`提起合同仲裁`、`应对合同仲裁`、`准备合同仲裁协议异议材料`、`评估合同管辖与仲裁协议`、`提起合同案件上诉`、`执行合同生效文书`、`应对合同案件执行`、`准备合同案件庭审`、`建立合同争议证据案卷`、`评估合同争议`、`选择诉讼仲裁或督促程序`、`谈判合同和解方案`、`准备合同财产保全申请`、`测算违约金与损害赔偿`、`规划举证期限与证据交换`、`评估合同调解方案与效力`。禁止此致某中院。

若 if 用户催促「按六个月算／实体赔多了也撤／网交了就算撤销／过期今晚仍交／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止；倒签收到日第一次整体停止。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「撤裁闸与撤裁行草案」。本窗不代提交。不包含：已撤销、已提交终稿、不予执行终稿、上诉状。禁止选边治愈。禁止草稿即已撤销。禁止指导倒签收到日。撤裁闸打开 ≠ 已提交 ≠ 已撤销。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标申请终稿已形成。
风险档 A：伪造裁决、倒签收到日必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：2026 年 4 月签收国内商事裁决。用户主张按六个月算到十月、实体赔多了也撤、微信已读起算、此致某中院、网交了就算撤销、顺便写一份不予执行。撤裁闸打开或半开。`Q-六`、`Q-体`、`Q-签`、`Q-院`、`Q-混` 不打开为可靠路径。第 6 节不得把已撤销、六个月现行、实体事由、0 写入可执行 `HC#`；对应格 `现有依据不支持` 或字段停止；仍出裁决分列、收到日、第七十一条分列待核。不代提交。

场景②：用户同时交出己方「把签收日改到上周、证据先造一份隐瞒」与对方「根本没收到」。命中双方秘密＋倒签收到日＋伪造。第一次整体停止。只交第 1、10 节。不出 `HC#`。不得问代表哪一方后继续。不以「坚持」为门槛。
