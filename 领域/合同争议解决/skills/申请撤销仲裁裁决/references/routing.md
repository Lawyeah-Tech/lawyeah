# 边界与路由

## 正触发

一般合同商事仲裁裁决已作出，拟申请撤销草稿。从零、碎片、收到日未核验仍正触发：有可编号裁决书或收到日碎片则闸开或半开，出 `HC#` 草案，保持草案。本次不保证撤销、不代提交是交付禁令，不是开窗条件。草稿即已撤销、六个月仍现行，仍正触发。把实体不服写成应撤销、把逾期写成仍可提交终稿，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造、倒签收到日的停止，优先于负触发。上述信号不在下表。不保证撤销不是负触发。「草稿即已撤销」「六个月仍现行」「实体不服即应撤销」「逾期仍可提交终稿」「保证撤销」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 不予执行终稿 | `申请不予执行仲裁裁决` |
| 上诉状 | `提起合同案件上诉` |
| 执行申请 | `执行合同生效文书` |
| 应裁实体 | `应对合同仲裁` |
| 仲异或效力确认 | `准备合同仲裁协议异议材料` |
| 仲裁申请 | `提起合同仲裁` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不保证撤销」或「不代提交」关窗。拟申请草稿仍正触发，不得写成已撤销或已提交。

## 易混

本窗闸名只能是撤裁闸，不是撤销闸，不是撤权闸，不是撤诉闸，不是仲裁闸，不是上诉闸。`HC#` 不是 `CC#`，不是 `ZC#`，不是 `HS#`，不是 `XQ#`。主路径是 `Q-撤裁`，不是 `Q-撤`，不是 `Q-撤诉`，不是 `Q-申`，不是 `Q-上`。`撤销闸`／`Q-撤` 是评估债权人撤销权。`撤诉闸`／`XQ#`／`Q-撤诉` 是准备债权人撤销权诉讼。`仲裁闸`／`ZC#`／`Q-申` 是提起合同仲裁。`上诉闸`／`HS#`／`Q-上` 是提起合同案件上诉。1994 年或 2017 年第五十八条、第五十九条六个月不是现行。1994 年第七十二条外国承认执行不是三个月除斥。未获通知不是国内闭集。劳动终局单位撤裁不是本窗。提出「把签收日改到上周」整体停止。本窗不代提交。不选定中院。不保证撤销。
