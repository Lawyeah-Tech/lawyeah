# 管辖异议方法

本文件是可执行判断节点，不是栏目说明书。每个会改变结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然结果或唯一必得总额。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。实务检索若出现“违约金不超过合同标的百分之三十”，记为噪声。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

应诉答辩或提出反诉，不等于当然放弃仲裁协议。解除通知到达对方时解除；未通知而起诉或申请仲裁主张解除的，仅在该主张获确认后，自起诉状或仲裁申请书副本送达时解除，不得把立案日写成解除时点。第 585 条“过分高于”对照违约造成的损失，不对照合同总价。

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填本任务实体结论。

## 节点 1　期限闸

1. 当事人对管辖权有异议，应当在提交答辩状期间提出。
2. 答辩期间通常自收到起诉状副本之日起十五日，涉外住所另核。
3. 作出日不等于送达日。微信已读、邮寄跟踪、电子送达回证必须分列。
4. 送达日不明：期限字段停止，不编截止日，不输出可提交终稿。
5. 已过期间仍要求“赶一份异议书提交”：目标停止。

若：用户尚未收到起诉状副本，只有立案短信 → 不得起算异议期。
若：劳动、海事专属 → 整案转出。

## 节点 2　管辖依据

运行时核验现行民事诉讼法地域管辖、协议管辖、专属管辖和级别管辖。不得沿用记忆条号。

1. 无协议时，通常由被告住所地或合同履行地人民法院管辖。履行地有约定从约定；无约定按争议标的特征履行地规则核验。
2. 协议管辖须书面，且不得违反级别管辖和专属管辖。
3. 不动产、港口作业、继承等专属管辖命中则本任务可能负触发并转出。
4. 仲裁协议表面有效：法院管辖异议可能不是正确主位，应并行评估是否应提仲裁协议。
5. 不得直接写“应向某法院起诉对方”，本任务是异议而非选法院立案。

## 节点 3　应诉与仲裁

1. 未提管辖异议并应诉答辩或反诉，视为接受受诉法院管辖，级别和专属除外。
2. 在答辩状期间提出管辖异议，又对起诉状内容答辩的，法院仍应审查异议。
3. 应诉管辖不等于放弃仲裁协议。仲裁放弃须按仲裁法运行时核验的异议节点判断，不得用“已经来法院了”概括。
4. 需要仲裁协议异议：转 `准备合同仲裁协议异议材料`。
5. 需要实体答辩：可与本任务并行，终稿走 `应对合同纠纷一审`。

## 节点 4　异议书

1. 当事人、案号、受诉法院、异议请求、事实与理由、连结证据、送达信息。
2. 事实只服务于管辖，不把质量、价款实体写成异议理由。
3. 范本只借栏目结构。
4. 不保证裁定移送。
5. 禁止伪造送达地址或连结点证据。

## 节点 5　失败分流

1. 异议被驳回：评估上诉或复议接口（裁定上诉规则运行时核验），同时准备实体应诉。
2. 异议成立移送：交接新法院期限和材料。
3. 期间已过：只输出风险和应诉接口。

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。

下一步按期限灭失、易失证据、改变本任务结论、可逆性排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。

禁止指导伪造、隐匿、威胁或违法取证。未知金额不写零。不把应诉写成放弃仲裁。不把立案日写成解除时点。
