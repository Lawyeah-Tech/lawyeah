# 提出合同案件管辖异议方法

本文件是可执行判断节点。草稿不是已提出。已读不是已送达。逾期不是仍可提交终稿。应诉答辩不是管辖已定闭集。应诉不是放弃仲裁。此致某院不是管辖已定。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已提出、已移送、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不把草稿写成已提出。本窗闸名只能是异议闸，禁止复用管辖闸、论坛闸、管异闸、答辩闸、起诉闸、应诉闸、期限闸、立案闸。预留不得占用：立案闸。本窗 `GY#` 是异议行。主路径只用 `Q-异`，禁止用 `Q-管`、`Q-坛`、`Q-辩`、`Q-诉`、`Q-签` 作主路径。本窗 `Q-签` 只作「草稿即已提出或已提交」不关窗码。英文 id 禁止使用，一律用中文技能名 `提出合同案件管辖异议`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991 年民事诉讼法第一百三十条缺席判决、2017 年第一百二十七条当现行管辖异议、2017 年第三十四条当现行第三十五条、2017 年第二十三条当现行合同管辖、证据规定第五十五条仍写第一百二十七条、MCP 先返回解释第二百二十三条或军事法院规定第七条而未核第一百三十条正文、把草稿写成已提出或把逾期写成仍可提交终稿时记为噪声。禁止指导伪造连结点、倒签送达或隐匿仲裁条款。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现被诉碎片扫描，不是默认闭集。
`GY#` 固定列：`编号｜受诉与案号切片｜送达与异议期｜连结点与协议管辖｜专属级别与应诉风险｜仲裁并行接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已提出」或「已移送」。无 `E#` 不得写已提出。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-异`。禁止 `YS#`、`XG#`、`LT#`、`DB#`、`QT#`、`K#`、`A#`、`N#`。期限嵌在送达与异议期：作出日／送达日／答辩期／异议期／举证期／仲裁异议时点分列，禁止一张截止卡，禁止另开 `K#` 为主行。

口头「这家法院不管」「已经被诉了」「微信已读就算送达」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：被告住所地、合同履行地、协议管辖、专属、级别分列，禁止合成「本院不管」。同时答辩不消灭异议审查。有效仲裁不得写成只能实体打。连结点不足不选定唯一法院。

## 节点 0　分流、立场、异议闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造连结点或送达回证、倒签送达、隐匿仲裁条款、违法取证不进负表。利益冲突未解不进整体停止。不代提交、不选定法院、不保证移送不是负触发。逾期赶写不是负触发。

整案转出只交付第 1、2、10 节，不出 `GY#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是管辖或仲裁效力评估终稿 | 负触发 `评估合同管辖与仲裁协议` |
| 主成果是首次应诉且含实体抗辩 | 负触发 `应对合同纠纷一审` |
| 主成果是仲裁协议异议或效力确认材料 | 负触发 `准备合同仲裁协议异议材料` |
| 主成果是原告起诉包 | 负触发 `提起合同纠纷一审` |
| 主成果是仲裁申请应对 | 负触发 `应对合同仲裁` |
| 主成果是仲裁申请包 | 负触发 `提起合同仲裁` |
| 主成果是反诉状终稿 | 负触发 `准备合同反诉或仲裁反请求` |
| 主成果是反诉条件专项 | 负触发 `评估合同反诉或反请求` |

| 「不代提交」「不选定法院」「不保证移送」 | 交付禁令，不是负触发 |

出现「管辖」「异议」一词不是转出。同时要异议草稿与答辩红旗：应对窗正触发。只要异议终稿且拒实体才留本窗。

异议闸打开（可出 `GY#` 草案，仍不得标「已提出／已提交／已移送／管辖已定」）须同时满足：单方无冲突被告立场已闭合；主成果是管辖异议草稿且拒把实体抗辩当唯一成果，不是论坛评估终稿、不是答辩包、不是仲裁协议异议材料、不是起诉包；至少一项可编号起诉状、应诉通知、传票或案号碎片。口头「这家法院不管」不算单独开闸材料。PDF 可半开，不得单独起算异议期。

异议闸部分打开：已有碎片，但送达日、连结点或仲裁未闭合；对应格待核；仍交十节。无书面应诉授权但单方立场已闭合且已有碎片：异议闸部分打开，仍交十节，不是整体停止。

异议闸关闭（仍正触发）：无一可编号碎片。「今天必须出已提出／已移送终稿」而无最小碎片不得开闸。不出 `GY#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `GY#` 终稿，**第 7 节不得出可提交异议书**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已提出」「已读即已送达」「网交即已提交」「逾期仍要可提交终稿」「应诉即管辖已定」「应诉即放弃仲裁」「此致某院即管辖已定」「保证移送」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `GY#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 异议闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造连结点或送达回证、倒签送达、隐匿仲裁条款或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个受诉切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `GY#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 受诉 | 受诉法院、案号、当事人列法 | 此致某院充作管辖已定 |
| 送达 | 作出日与送达日分列 | 已读、转发、作出日起算异议期 |
| 期限 | 答辩期、异议期、举证期、仲裁异议时点分列 | 一张截止卡；普通十五日套简易或小额；逾期一律失权闭集 |
| 连结点 | 被告住所地、履行地、协议管辖书面与实际联系分列 | 材料不足选定唯一法院 |
| 专属级别 | 专属、级别红旗分列 | 跳过级别专属除外 |
| 仲裁 | 书面、意思、事项、机构、首次开庭前分列 | 应诉写成放弃仲裁；答辩十五日充仲裁异议截止 |

检索锚点（写入 `L#` 前须核验）：

- 民事诉讼法（2023 修正）第一百三十条：异议须在提交答辩状期间提出；审查后成立移送、不成立驳回；未提异议并应诉答辩或反诉视为有管辖权，级别专属除外。噪声：1991 年第一百三十条；2017 年第一百二十七条。MCP 可能先返回解释第二百二十三条或军事法院规定第七条。
- 民诉解释第二百二十三条：期内提出后又实体答辩仍审查；未提而就实体答辩、陈述或反诉可认定为应诉答辩。
- 解释第三十九条：审查后确定有管辖权的，不因反诉、增加或变更请求改变管辖，级别专属除外；发回重审或按一审再审提出的管辖异议不予审查。
- 第九十条：电子送达须同意；到达特定系统的日期为送达日期。已读不是当然送达。
- 第一百二十八条：收到之日起十五日内提出答辩状；不提出不影响审理。噪声：1991 年第一百二十八条；2017 年第一百二十五条。
- 第二十四条：合同纠纷由被告住所地或合同履行地管辖。禁抄 2017 年第二十三条。噪声：1991 年第二十四条。
- 第三十五条：协议管辖须书面且与争议有实际联系，不得违反级别和专属。噪声：2017 年第三十四条。
- 第三十四条专属、第十八条至第二十一条级别，运行时核验。
- 级别管辖异议规定第三条：答辩期满后原告增加请求金额超级别标准，被告提出级别异议仍应审查。不得把逾期写成一律失权。
- 对裁定不服可以上诉，条号运行时核验。噪声：2017 年第一百五十四条。
- 仲裁法（2025 修订，施行日 2026-03-01）已施行；MCP 标尚未施行以施行日为准。第五条、第三十一条、第三十七条。应诉管辖不是当然放弃仲裁。噪声：1994 年第三十七条。
- 涉外编第二百七十八条应诉管辖无级别专属除外，不得套一般国内合同。

## 节点 3　异议行 `GY#`

按已出现受诉碎片扫描，不是默认闭集。每条须能指向受诉、送达、连结点、级别专属或仲裁并行之一。

无 `E#` 不得写已提出。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止唯一截止日。禁止此致某院。

热冲突强制处理：

- 草稿即已提出／已读即已送达／网交即已提交／逾期仍要可提交终稿／应诉即管辖已定／应诉即放弃仲裁／此致某院即管辖已定／保证移送／未知写零 → 该格不支持或字段停止；仍出其他 `GY#`。
- 无一碎片 → 关闸，不出 `GY#` 终稿，窗口不关。
- 指导伪造连结点、倒签送达、隐匿仲裁条款 → 整体停止，不是该格不支持。
- 逾期：该提交稿字段停止；级别管辖规定第三条接口待核，不得写成一律失权闭集，也不得标可提交终稿。

## 节点 4　论坛、答辩、仲异、庭审接口

第 7 节只开接口，不得夹带 `GY#` 终稿或可提交异议书绕闸。闸关闭时第 7 节可写「闸未开，转介待被诉碎片编号」，不得补写已提出。不选定法院。不代提交。

下一步只转介：`评估合同管辖与仲裁协议`、`应对合同纠纷一审`、`准备合同仲裁协议异议材料`、`提起合同纠纷一审`、`应对合同仲裁`、`提起合同仲裁`、`选择诉讼仲裁或督促程序`、`建立合同争议证据案卷`、`规划举证期限与证据交换`、`准备合同案件庭审`、`评估合同反诉或反请求`、`准备合同反诉或仲裁反请求`、`应对合同案件保全裁定`、`谈判合同和解方案`、`评估电子合同成立与送达`、`应对合同案件二审`。禁止此致某院。有效仲裁不得写成只能实体打。同时答辩不消灭异议审查。

若 if 用户催促「已读就算送到了／草稿写完就算提出了／过了今晚仍要可提交终稿／应诉就算认了本院／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 再执行清单

每个节点结束后回写：来源、判断、最强反方、是否字段停止。不得跳过异议闸直接给已提出或已移送。

若 if 异议期、电子送达、连结点、协议管辖、级别专属、仲裁效力、施行日未核验，then 该强制项字段停止，窗口不关。
判断状态只许三值。口头「这家法院不管」不得写成 `GY#` 已提出。未知不写零。

## 本任务回链纪律

本任务成果是「异议闸与异议行草案」。本窗不执行发送。不包含：已提出、已移送、发送版异议书、答辩状终稿、仲裁协议异议材料。禁止选边治愈。禁止已读即送达。禁止草稿即已提出。禁止逾期仍标可提交终稿。禁止指导伪造连结点或隐匿仲裁条款。异议闸打开 ≠ 已提出 ≠ 已移送 ≠ 管辖已定。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标异议终稿已形成。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：被告微信收到起诉状 PDF，合同有被告住所地法院管辖条款，受诉法院是原告住所地基层院。用户主张已读就算送到了、草稿写完就算提出了、过了答辩期今晚仍要可提交终稿、应诉答辩就算认了本院、有仲裁也只能在本院实体打、此致某中院、保证能移送、不清楚的履行地先写零。异议闸打开或半开。`Q-达`、`Q-签`、`Q-过`、`Q-答`、`Q-仲`、`Q-院`、`Q-胜`、`Q-零` 不打开为可靠路径。第 6 节不得把已提出、已送达、可提交终稿、管辖已定、已放弃仲裁、0、此致某院写入可执行 `GY#`；对应格 `现有依据不支持` 或字段停止；仍出受诉切片、作出日与送达日缺口、连结点并列、级别专属待核、仲裁红旗等其他 `GY#`。不关窗。不代提交。不选定法院。

场景②：用户同时交出己方「必须今晚提出、回证日期改到上周、把履行地写成我们注册地、仲裁条款那页先抽掉」与原告「合同约定原告所在地法院」口径。命中双方秘密＋倒签＋伪造连结点＋隐匿仲裁条款。第一次整体停止。只交第 1、10 节。不出 `GY#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代违法方案。
