# 边界与路由

## 正触发

一般合同被告已收到一审起诉状、应诉通知或等价被诉碎片，需要在提交答辩状期间准备人民法院管辖异议草稿。从零、碎片、送达未核验、无书面应诉授权仍正触发：有可编号起诉状、应诉通知或案号碎片则闸开或半开，出 `GY#` 草案，保持草案。逾期仍要赶写终稿仍正触发：该提交稿字段停止，窗口不关。本次不代提交、不选定法院、不保证移送是交付禁令，不是开窗条件。草稿即已提出、已读即送达、应诉即管辖已定，仍正触发。

双方秘密、伪造连结点或送达回证、倒签送达、隐匿仲裁条款、违法取证的停止，优先于负触发。上述信号不在下表。不代提交不是负触发。「草稿即已提出」「已读即已送达」「网交即已提交」「逾期仍要可提交终稿」「应诉即管辖已定」「应诉即放弃仲裁」「此致某院即管辖已定」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 管辖或仲裁效力评估终稿 | `评估合同管辖与仲裁协议` |
| 首次应诉且含实体抗辩 | `应对合同纠纷一审` |
| 仲裁协议异议或效力确认材料 | `准备合同仲裁协议异议材料` |
| 原告起诉包 | `提起合同纠纷一审` |
| 仲裁申请应对 | `应对合同仲裁` |
| 仲裁申请包 | `提起合同仲裁` |
| 反诉状终稿 | `准备合同反诉或仲裁反请求` |
| 反诉条件专项 | `评估合同反诉或反请求` |
| 证据案卷终稿 | `建立合同争议证据案卷` |
| 举证期限计划 | `规划举证期限与证据交换` |
| 已过首次应诉的庭审提纲 | `准备合同案件庭审` |
| 保全复议或担保置换 | `应对合同案件保全裁定` |
| 和解方案 | `谈判合同和解方案` |
| 二审答辩或二审异议 | `应对合同案件二审` |
| 尚未成争，改管辖条款 | 审查起草领域（本窗搁置，只说明） |
| 工程／金融／房产／海事／劳动主轴 | 对应领域 |

不得因「不代提交」或「不保证移送」关窗。拟异议草稿仍正触发，不得写成已提出或已移送。同时要草稿和实体抗辩：应对窗正触发。只要异议终稿且拒实体才留本窗。

## 易混

本窗闸名只能是异议闸，不是管辖闸，不是论坛闸，不是答辩闸，不是起诉闸，不是立案闸。`GY#` 不是 `YS#`，不是 `XG#`，不是 `LT#`，不是 `DB#`，不是 `QT#`，不是 `K#`。主路径是 `Q-异`，不是 `Q-管`，不是 `Q-坛`，不是 `Q-辩`。`Q-管` 是公司治理管辖窗主路径；应对窗 `Q-管` 只开接口进本窗，进窗改走 `Q-异`。邻窗 `Q-异` 只转介进本窗，本窗打开为主路径，不是已提出。同时要草稿和实体抗辩：应对窗正触发。只要异议终稿且拒实体才留本窗。法院管辖异议不是仲裁协议异议。草稿不是已提出。已读不是已送达。逾期不是仍可提交终稿。应诉答辩不是管辖已定闭集。应诉不是放弃仲裁。此致某院不是管辖已定。1991 年第一百三十条不是现行管辖异议。2017 年第一百二十七条、第三十四条、第二十三条不是现行。证据规定第五十五条仍写第一百二十七条不是现行条号。MCP 先返回解释第二百二十三条或军事法院规定第七条不是现行第一百三十条正文。涉外编第二百七十八条不得套一般国内合同。仲裁法 1994 年第三十七条不是现行起诉未声明规则。已失效《合同法》不是现行。范本引用 2017 年第一百二十七条是噪声。「回证日期改到上周」「履行地改成我们注册地」「仲裁条款那页先抽掉」整体停止。本窗不执行发送，不代提交。不选定法院。不保证移送。
