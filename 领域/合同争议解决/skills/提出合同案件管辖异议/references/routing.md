# 边界与路由

## 正触发

已被起诉或被申请，需在提交答辩状期间提出人民法院管辖异议。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 仲裁协议异议 | `准备合同仲裁协议异议材料` |
| 完整一审答辩 | `应对合同纠纷一审` |
| 评估管辖或仲裁条款本身 | `评估合同管辖与仲裁协议` |
| 异议期已过仍要终稿 | 停止终稿，只交逾期风险 |
| 海事专属 | 海事领域 |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，只分流不回改 |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

已被法院起诉、争的是哪家法院管时正触发。争的是根本不该进法院而应仲裁时，转仲裁协议异议。只要实体答辩时转应诉原子。
