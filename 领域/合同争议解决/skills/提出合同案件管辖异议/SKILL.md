# 提出合同案件管辖异议

## 任务目标

在明确、无利益冲突的单方立场下（被诉守约方、被指违约方或其受托律师，互斥），形成法院管辖异议草稿：异议闸、主体与强制接口、`Q#` 路径、`GY#` 异议行（受诉与案号切片／送达与异议期／连结点与协议管辖／专属级别与应诉风险／仲裁并行接口／`E#` 回链）。本窗 `GY#` 是异议行草案，不是已提出证明，不是已移送，不是发送版异议书，不是答辩状终稿，不是仲裁协议异议材料。本窗闸名只能是异议闸，禁止复用管辖闸、论坛闸、管异闸、答辩闸、起诉闸、应诉闸、期限闸、争议闸、立案闸。预留不得占用：立案闸。本窗主行只能是 `GY#`，禁止 `YS#`、`XG#`、`LT#`、`DB#`、`QT#`、`K#`、`A#`。主路径只用 `Q-异`，禁止用 `Q-管`、`Q-坛`、`Q-辩`、`Q-诉`、`Q-签` 作主路径。邻窗 `Q-异` 只作转介进本窗；本窗打开为主路径，不是已提出、不是已移送。应对窗 `Q-管` 只开接口进本窗，进窗改走 `Q-异`，本窗不打开 `Q-管`。本窗 `Q-签` 只作「草稿即已提出或已提交」不关窗码。异议闸打开不等于已提出不等于已提交不等于已送达不等于已移送不等于应诉管辖已排除不等于管辖已定不等于保证裁定移送。草稿不是已提出。已读不是已送达。微信转发不是法定送达。网交不是已提交。逾期只停该提交稿，不关窗。同时答辩不消灭异议审查。应诉答辩不是管辖已定闭集。应诉不是放弃仲裁。有效仲裁不是本案必审。此致某院不是管辖已定。连结点不足不得选定「我方指定法院」。未知不写零。不代提交。不选定法院。不定罪。不保证移送。伤残等级与本窗无关，禁止折入。

`depends-on` 为空。主成果是论坛评估终稿转 `评估合同管辖与仲裁协议`。主成果是首次应诉且含实体抗辩转 `应对合同纠纷一审`。主成果是仲裁协议异议材料转 `准备合同仲裁协议异议材料`。主成果是原告起诉包转 `提起合同纠纷一审`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：一般合同被告已收到一审起诉状、应诉通知或等价被诉碎片，需要在提交答辩状期间准备人民法院管辖异议草稿。「给我异议书」「过了答辩期今晚仍要可提交终稿」仍正触发，成果状态 `草案`；逾期该提交稿字段停止，窗口不关。送达、连结点、协议管辖、仲裁未核验仍正触发：有可编号起诉状、应诉通知或案号碎片则异议闸打开或半开，第 6 节出 `GY#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出已提出／已移送终稿」才关闸，仍交十节，第 6 节不出 `GY#` 终稿，第 7 节不得出可提交异议书，窗口不关。用户要把草稿写成已提出、把已读写成已送达、把网交写成已提交、把逾期写成仍可提交终稿、把应诉写成管辖已定闭集、把应诉写成放弃仲裁、把有效仲裁写成本案必审、把此致某院写成管辖已定、把保证移送、把未知写成零，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `GY#` 草案。不得因「不代提交」「不选定法院」「不保证移送」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是管辖或仲裁效力评估终稿（转 `评估合同管辖与仲裁协议`）；
- 主成果是首次应诉且含实体抗辩（转 `应对合同纠纷一审`）；
- 主成果是仲裁协议异议或效力确认材料（转 `准备合同仲裁协议异议材料`）；
- 主成果是原告起诉包（转 `提起合同纠纷一审`）；
- 主成果是仲裁申请应对（转 `应对合同仲裁`）；
- 主成果是仲裁申请包（转 `提起合同仲裁`）；
- 主成果是反诉状终稿（转 `准备合同反诉或仲裁反请求`）；
- 主成果是反诉条件专项（转 `评估合同反诉或反请求`）；
- 主成果是证据案卷终稿（转 `建立合同争议证据案卷`）；
- 主成果是举证期限计划（转 `规划举证期限与证据交换`）；
- 主成果是已过首次应诉的庭审提纲（转 `准备合同案件庭审`）；
- 主成果是保全复议或担保置换（转 `应对合同案件保全裁定`）；
- 主成果是和解方案（转 `谈判合同和解方案`）；
- 主成果是二审答辩或二审异议（转 `应对合同案件二审`）；
- 尚未成争，只要改管辖条款（审查起草领域，本窗搁置，只说明不实施）；
- 建设工程、金融借贷担保、房地产物业、海事、劳动专项管辖主轴。

双方秘密、伪造连结点或送达回证、倒签送达、隐匿仲裁条款、违法取证**不在负触发表**，走整体停止。「草稿即已提出」「已读即已送达」「网交即已提交」「逾期仍要可提交终稿」「应诉即管辖已定」「应诉即放弃仲裁」「此致某院即管辖已定」「保证移送」「未知写零」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不代提交」「不选定法院」「不保证移送」是交付禁令，不是负触发。主成果才转；出现「管辖」「异议」一词不是转出。同时要异议草稿与答辩红旗：应对窗正触发；**只要异议终稿且拒实体**才留本窗。

## 建立工作坐标

确认：应诉授权；单方立场；受诉法院与案号；起诉状、应诉通知、送达凭证；每份文书作出日与送达日；合同及附件版本；协议管辖或仲裁条款；法域。

口头「这家法院不管」「已经被诉了」「微信已读就算送达」「已经提出了」只登记 `S#`／`V#`。不得升格已送达、已提出或已移送，**不得单独算作开闸材料**。可编号起诉状、应诉通知、传票或案号碎片可开闸。微信或邮箱收到的起诉状 PDF 可作被诉碎片开闸或半开，**不得**单独起算异议期。本窗不执行发送，不代提交，不选定法院。

立场只许被诉一方或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号被诉碎片：异议闸关闭，仍交十节，不是整体停止。无书面应诉授权但单方立场已闭合、且已有碎片：异议闸部分打开，仍交十节，不是整体停止。提出伪造连结点或送达回证、倒签送达、隐匿仲裁条款或违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`GY#` 异议行；`V#` 版本；`E#` 证据形态回链（应诉授权、起诉状或应诉通知、送达凭证、连结点材料，不是发送闸，不是已提出证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`K#`、`YS#`、`XG#`、`LT#`、`DB#`、`QT#`。技能正文中的条号是检索锚点，不是已核验 `L#`。期限不得另开 `K#` 为主行。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。未知不写零。草稿 ≠ 已提出。已读 ≠ 已送达。网交 ≠ 已提交。逾期 ≠ 仍可提交终稿。应诉答辩 ≠ 管辖已定闭集。应诉 ≠ 放弃仲裁。有效仲裁 ≠ 本案必审。此致某院 ≠ 管辖已定。

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或文书范本检索。本窗是管辖异议草稿，范本只借管辖权异议申请书栏目，**不要**升格「已提出／已提交／已移送／管辖已定／保证移送」，**不要**用类案写成必然移送。

- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1991 年民事诉讼法第一百三十条缺席判决当作现行管辖异议。不得把 2017 年第一百二十七条、第三十四条当作现行第一百三十条、第三十五条。不得把证据规定第五十五条仍写的「民事诉讼法第一百二十七条」当作现行条号。MCP 先返回解释第二百二十三条、军事法院规定第七条或未返回第一百三十条正文时，不得把解释或特别规定写成现行异议主条。涉外编第二百七十八条应诉管辖无级别专属除外，不得套一般国内合同。仲裁法 2025 修订施行日 2026-03-01，当前已过施行日；MCP 标尚未施行时以施行日为准。MCP 效力字段与公布施行日冲突时，以施行日为准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的异议期、连结点、应诉管辖、仲裁效力保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民事诉讼法（2023 修正，施行日 2024-01-01）第一百三十条人民法院受理案件后，当事人对管辖权有异议的，应当在提交答辩状期间提出；人民法院对异议应当审查，成立的裁定移送，不成立的裁定驳回；未提出管辖异议并应诉答辩或提出反诉的，视为受诉人民法院有管辖权，但违反级别管辖和专属管辖规定的除外。噪声：1991 年第一百三十条缺席判决；2017 年第一百二十七条。MCP 可能先返回解释第二百二十三条或军事法院规定第七条，不得把它们写成现行第一百三十条。民诉解释第二百二十三条：答辩期内提出管辖异议后又针对起诉状内容答辩的，仍审查异议；未提异议而就实体答辩、陈述或反诉的，可认定为应诉答辩。解释第三十九条：管辖异议审查后确定有管辖权的，不因反诉、增加或变更诉讼请求改变管辖，级别专属除外；发回重审或按一审再审提出的管辖异议不予审查。第九十条电子送达须经受送达人同意，采用能够确认其收悉的电子方式；以送达信息到达特定系统的日期为送达日期。已读、微信转发不是当然法定送达。第一百二十八条被告应当在收到之日起十五日内提出答辩状；不提出不影响审理。噪声：1991 年第一百二十八条；2017 年第一百二十五条。简易程序、小额诉讼答辩期运行时核验解释，不得把普通程序十五日一律套简易或小额。第二十四条合同纠纷由被告住所地或者合同履行地人民法院管辖。禁抄 2017 年第二十三条。噪声：MCP 可能先返回 1991 年第二十四条。第三十五条协议管辖须书面且与争议有实际联系，不得违反级别和专属。噪声：2017 年第三十四条。第三十四条专属、第十八条至第二十一条级别，运行时核验。级别管辖异议规定第三条：答辩期满后原告增加诉讼请求金额致使超过级别管辖标准的，被告提出级别异议仍应审查；不得把逾期写成一律失权闭集。对管辖异议裁定不服可以上诉，条号运行时核验；噪声：2017 年第一百五十四条。仲裁法（2025 修订，施行日 2026-03-01）已施行；MCP 标尚未施行以施行日为准。第五条有协议起诉原则上不予受理。第三十一条效力异议首次开庭前提出。起诉未声明有协议、另一方首次开庭前提交应驳回，否则视为放弃，条号运行时核验第三十七条。不得用答辩十五日充仲裁异议截止。应诉管辖不是当然放弃仲裁。噪声：1994 年第三十七条；2017 年第二十条、第二十六条。技能正文条号不是 `L#`。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、异议闸与不关窗

主成果才整案转出。双方秘密、伪造连结点、倒签送达第一次停。草稿即已提出、逾期仍要可提交终稿不关窗。闸关仍交十节，第 6 节不出 `GY#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

受诉与案号、送达与异议期、连结点分列。作出日与送达日分列。本节禁止出 `GY#` 终稿。

### 3. 异议闸与路径 `Q#`

本节禁止出 `GY#` 终稿。有可编号被诉碎片：闸打开或半开。主路径只用 `Q-异`。

### 4. 异议行 `GY#`

受诉与案号切片、送达与异议期、连结点与协议管辖、专属级别与应诉风险、仲裁并行接口。状态 `草案`。禁止升格已提出、已送达、已提交、已移送、管辖已定。无 `E#` 不得写已提出。

### 5. 论坛、答辩、仲异、庭审接口

论坛评估转论坛窗。含实体抗辩转答辩窗。仲裁协议异议转仲异窗。第 7 节不得夹带 `GY#` 终稿或可提交异议书绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造连结点或送达回证、倒签送达、隐匿仲裁条款或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：异议闸关闭，仍交十节，不是整体停止。无书面应诉授权但有碎片：异议闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：异议期、电子送达同意、连结点、协议管辖、级别专属、仲裁协议效力、施行日未核验。草稿即已提出、已读即已送达、网交即已提交、逾期仍要可提交终稿、应诉即管辖已定、应诉即放弃仲裁、此致某院即管辖已定、保证移送、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `GY#` 草案。
- `目标停止`：主目标变为论坛评估终稿、含实体抗辩的答辩包、仲裁协议异议材料或起诉包。禁止把「逾期仍要可提交终稿」当作用户错误主张时的目标停止；那是不关窗。

禁止指导伪造连结点、倒签送达或隐匿仲裁条款。不给胜诉率。不定罪。不选定法院。不代提交。未知不写零。不写唯一截止日。不写发送版异议书。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。异议闸关闭仍交十节，第 6 节不出 `GY#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `GY#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。异议闸未打开时不得交付「已提出」或「已移送」。边界见 [路由](references/routing.md)。
