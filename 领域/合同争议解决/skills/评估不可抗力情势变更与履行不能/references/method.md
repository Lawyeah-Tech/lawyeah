# 不可抗力情势变更与履行不能评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然结果或唯一必得总额。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。实务检索若出现“违约金不超过合同标的百分之三十”，记为噪声。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

应诉答辩或提出反诉，不等于当然放弃仲裁协议。解除通知到达对方时解除；未通知而起诉或申请仲裁主张解除的，仅在该主张获确认后，自起诉状或仲裁申请书副本送达时解除，不得把立案日写成解除时点。第 585 条“过分高于”对照违约造成的损失，不对照合同总价。

## 节点 1　事件事实

1. 事件名称、开始与持续、影响的是哪一项义务、是否金钱债务。
2. 通知：是否及时、到达凭证、减损措施。未通知不当然消灭不可抗力，但扩大损失部分不得免责。
3. 合同中的不可抗力条款：约定范围可细于或宽于法定，但不得与效力强制性规定冲突。
4. 建设工程停工、金融停贷、商品房政策限购：专项转出。

若：只有“行情不好”“成本涨了” → 不足支持不可抗力或情势变更。
若：用户要求今天发解除通知且路径是情势变更 → 停止，情势变更不能单方通知解除。

## 节点 2　不可抗力

运行时核验第 180、590 条。

1. 三不能：预见、避免、克服。市场涨价、融资失败、自身经营困难通常不支持。
2. 部分不能：仅免除不能履行部分。
3. 迟延后发生不可抗力：不得免除迟延责任。
4. 金钱债务原则上仍须支付，不可抗力抗辩极窄，须有特别依据才讨论。
5. `search_law` 返回已失效合同法不可抗力条记为噪声。

## 节点 3　情势变更

运行时核验第 533 条和通则解释第 32 条。

1. 时间：合同成立后。订立时已存在的风险不构成。
2. 无法预见且不属于商业风险。政策调整或供求异常导致价格剧烈涨跌，可能构成重大变化；市场属性活跃、长期波动大的大宗商品、股票、期货除外。
3. 继续履行对一方明显不公平。
4. 先重新协商。无再交涉记录：变更或解除请求风险升高，列入缺口。
5. 当事人请求变更的，法院不得径行解除；一方变更一方解除时按公平原则判决。事先排除第 533 条适用的约定无效。
6. 裁判应明确变更或解除时间，不得把起诉当日当然写成解除日。

## 节点 4　第 580 条

1. 适用于非金钱债务的继续履行除外情形。
2. 法律上不能、事实上不能、不适于强制履行或费用过高、债权人未在合理期限请求。
3. 有除外情形且目的不能实现：当事人可请求终止权利义务关系。此终止不是通知解除，须裁判或另行合意。
4. 商业上不愿意继续，不等于费用过高。
5. 继续履行专项终局转 `评估继续履行是否可能`。
