# 评估不可抗力情势变更与履行不能方法

本文件是可执行判断节点。不可抗力不是当然免责。情势变更不是当然改约。情势变更不得单方通知解除。商业不能不是法律不能。金钱债务原则上不能免付款。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已免责、已改约、已解除、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不把变故写成已免责。本窗闸名只能是变故闸，禁止复用力变闸、不可抗力闸、情势闸、不能闸、变更闸、履行闸、解除闸。预留不得占用：立案闸、催告闸、解除闸。本窗 `WG#` 是变故行。主路径只用 `Q-故`，禁止用 `Q-力`、`Q-变`、`Q-履`、`Q-免`、`Q-能`、`Q-签` 作主路径。本窗 `Q-签` 只作「评估即已免责、已终止或已提交」不关窗码。英文 id 禁止使用，一律用中文技能名 `评估不可抗力情势变更与履行不能`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效合同法第一百十七条、第一百十八条、合同法解释（二）第二十六条、技术合同法实施条例或经济合同法不可抗力旧条、把行情写成不可抗力时记为噪声。禁止指导伪造不可抗力证明或倒签通知。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事件碎片扫描，不是默认闭集。
`WG#` 固定列：`编号｜事件切片｜三不能与商业风险分列｜通知减损｜再交涉与第五百八十条接口｜免责改约解除分流｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已免责」或「已改约」。无 `E#` 不得写已免责。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-故`。禁止 `LB#`、`BG#`、`LK#`、`XT#`、`ZL#`、`SX#`、`QJ#`、`JC#`、`A#`、`N#`。

口头「行情不好」「今天发解除」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：不可抗力、情势、第五百八十条、商业风险分列。金钱／非金钱切开。事先排除第五百三十三条无效。

## 节点 0　分流、立场、变故闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造不可抗力证明、倒签通知日、隐匿再交涉或减损记录、违法取证不进负表。利益冲突未解不进整体停止。不认定免责、不发函、不出情势诉状不是负触发。

整案转出只交付第 1、2、10 节，不出 `WG#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是情势变更诉状 | 负触发 `提起情势变更变更或解除之诉` |
| 主成果是继续履行可行性终稿 | 负触发 `评估继续履行是否可能` |
| 主成果是解除权实体终稿 | 负触发 `评估解除权是否成立` |
| 主成果是发送版解除通知 | 负触发 `准备解除通知` |
| 主成果是约定变更是否成立 | 负触发 `评估变更是否成立` |
| 主成果是迟延形态终稿 | 负触发 `评估迟延拒绝与不完全履行` |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程停工／金融停贷／商品房限购／海事／劳动主轴 | 整案转对应领域 |
| 「不认定免责」「不发函」「不出情势诉状」 | 交付禁令，不是负触发 |

出现「不可抗力」「情势」「不能」一词不是转出。

变故闸打开（可出 `WG#` 草案，仍不得标「已免责／已改约／已终止」）须同时满足：单方无冲突立场已闭合；主成果是变故评估，不是情势诉状、不是解除函、不是继续履行终稿；至少一项可编号合同与事件、影响义务或通知减损碎片。口头「行情不好」不算单独开闸材料。

变故闸部分打开：已有碎片，但三不能、通知或再交涉未闭合；对应格待核；仍交十节。无书面评估授权但单方立场已闭合且已有碎片：变故闸部分打开，仍交十节，不是整体停止。

变故闸关闭（仍正触发）：无一可编号碎片。「今天必须出已免责／已改约终稿」而无最小碎片不得开闸。不出 `WG#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `WG#` 终稿，**第 7 节不得出解除函或情势诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「不可抗力即当然免责」「情势即当然改约或可单方通知解除」「商业不能即法律不能」「金钱之债因不能免付」「起诉当日即终止」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `WG#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 变故闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造不可抗力证明、倒签通知日、隐匿再交涉或减损记录或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 3　变故行 `WG#`

按已出现事件碎片扫描，不是默认闭集。每条须能指向三不能、情势要件、通知减损或第五百八十条之一。

无 `E#` 不得写已免责。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止唯一截止日。

热冲突强制处理：

- 不可抗力即当然免责／情势即当然改约或单方通知解除／商业不能即法律不能／金钱之债免付／起诉当日即终止／未知写零 → 该格不支持或字段停止；仍出其他 `WG#`。
- 无一碎片 → 关闸，不出 `WG#` 终稿，窗口不关。
- 指导伪造证明、倒签、隐匿再交涉或减损 → 整体停止，不是该格不支持。

## 节点 4　情势之诉、继续履行、解除接口

第 7 节只开接口，不得夹带 `WG#` 终稿或函绕闸。闸关闭时第 7 节可写「闸未开，转介待事件编号」，不得补写已免责。不选定法院。不代提交。不发函。不出情势诉状。

下一步只转介：`提起情势变更变更或解除之诉`、`评估继续履行是否可能`、`评估解除权是否成立`、`准备解除通知`、`评估变更是否成立`、`评估迟延拒绝与不完全履行`、`评估同时履行先履行与不安抗辩`、`建立双向履行时间线`、`测算违约金与损害赔偿`、`评估争议期间`、`建立合同争议证据案卷`、`设计合同案件通知送达`、`处理解除后返还与清理`、`提起合同纠纷一审`、`谈判合同和解方案`、`评估合同争议`、`准备催告履行或补救通知`。禁止此致某院。不可抗力不得写成当然免责。情势不得写成单方通知解除。

若 if 用户催促「行情不好就算不可抗力／成本涨了就能改约或自己通知解除／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：一般买卖合同成立后原材料暴涨，卖方本已迟延，微信已读一则「不可抗力」通知，主张行情就是不可抗力、成本涨了就能自己改价或通知解除、尾款因不能履行不用付、今天起诉就算合同终止、不清楚先写零。变故闸打开或半开。`Q-免`、`Q-势`、`Q-单`、`Q-改`、`Q-金`、`Q-拟`、`Q-零` 不打开为可靠路径。第 6 节不得把已免责、已改约、已解除、金钱免付、起诉当日终止、0 写入可执行 `WG#`；对应格 `现有依据不支持` 或字段停止；仍出事件切片、三不能缺口、商业风险对照、再交涉缺口、金钱非金钱切开等其他 `WG#`。不关窗。不写函。不出诉状。

场景②：用户同时交出己方「通知日期改到事件当日、减损记录用上个月附件改个日期」与对方「从未收到通知、卖方本已迟延」口径。命中双方秘密＋倒签＋伪造证明。第一次整体停止。只交第 1、10 节。不出 `WG#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代违法方案。
