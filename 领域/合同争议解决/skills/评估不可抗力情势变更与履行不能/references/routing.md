# 边界与路由

## 正触发

一般合同已成争，出现外部变故、成本剧变或履行不能，需要区分不可抗力、情势变更、商业风险与第五百八十条终止接口。从零、碎片、通知未核验、无书面评估授权仍正触发：有可编号合同与事件、影响义务或通知减损碎片则闸开或半开，出 `WG#` 草案，保持草案。本次不认定免责、不发函、不出情势诉状是交付禁令，不是开窗条件。不可抗力即当然免责、情势即当然改约，仍正触发。

双方秘密、伪造不可抗力证明、倒签通知日、隐匿再交涉或减损记录、违法取证的停止，优先于负触发。上述信号不在下表。不认定免责不是负触发。「不可抗力即当然免责」「情势即当然改约或可单方通知解除」「商业不能即法律不能」「金钱之债因不能免付」「起诉当日即终止」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 情势变更诉状 | `提起情势变更变更或解除之诉` |
| 继续履行可行性终稿 | `评估继续履行是否可能` |
| 解除权实体终稿 | `评估解除权是否成立` |
| 发送版解除通知 | `准备解除通知` |
| 约定变更是否成立 | `评估变更是否成立` |
| 迟延形态终稿 | `评估迟延拒绝与不完全履行` |
| 争议总图 | `评估合同争议` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |
| 工程停工／金融停贷／商品房限购／海事／劳动主轴 | 对应领域 |

不得因「不认定免责」或「不出情势诉状」关窗。拟变故评估仍正触发，不得写成已免责或已改约。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工停工、分包、工程造价 | 建设工程领域 |
| 停贷、保证、抵押质押 | 金融借贷担保领域 |
| 商品房限购、开发合作 | 房地产物业领域 |
| 海上货物、船舶 | 海事领域 |
| 劳动关系、工资 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流。出现「不可抗力」「情势」「不能」一词不是转出。C 端只要大众免责填空页时只分流，不把本包降成填空式免责，不回改。

## 易混

本窗闸名只能是变故闸，不是力变闸，不是情势闸，不是不能闸，不是变更闸，不是解除闸。`WG#` 不是 `LB#`，不是 `BG#`，不是 `JC#`，不是 `XT#`。主路径是 `Q-故`，不是 `Q-力`，不是 `Q-变`，不是 `Q-履`。`Q-力` 是和解窗执行力补强转介。`Q-变` 留给 `评估变更是否成立`。`Q-履` 留给继续履行窗。不可抗力不是当然免责。情势变更不是当然改约，不得单方通知解除。商业不能不是法律不能。金钱债务原则上不能免付款。第五百八十条终止不是通知解除，终止时点不是立案日。已失效合同法第一百十七条、第一百十八条及解释（二）第二十六条不是现行。MCP 可能先返回技术合同法实施条例或通则解释第五十九条而漏第五百九十条、第五百八十条正文。「通知日期改到事件当日」「减损记录改个日期」整体停止。本窗不执行发送，不代提交。不选定法院。不认定免责。不发函。不出情势诉状。
