# 边界与路由

## 正触发

一般合同已成争，出现外部变故、履行不能或成本剧变，需要区分不可抗力、情势变更与商业风险。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 提起情势变更之诉 | `提起情势变更变更或解除之诉` |
| 继续履行是否可能 | `评估继续履行是否可能` |
| 法定或约定解除 | `评估解除权是否成立` |
| 发解除通知 | `准备解除通知` |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，只分流不回改 |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

外部变故要定性时正触发。已决定按第 533 条起诉时转起诉原子。用户把亏损说成不可抗力且拒绝再交涉时，不得写成已成立。
