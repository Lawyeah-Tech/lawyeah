# 准备索赔或违约金主张通知

## 任务目标

在明确、无利益冲突的单方立场下（主张金钱的守约方或其受托律师，互斥），形成发送前索赔或违约金主张通知草稿：索赔闸、主体与强制接口、`Q#` 路径、`SH#` 索函行（项目切片／性质与请求／金额与假设／互斥与调整接口／渠道与回证／`E#` 回链）。本窗 `SH#` 是索函行草案，不是已发送证明，不是已到达，不是必得总额，不是精算终稿，不是起诉状，不是发送版。本窗闸名只能是索赔闸，禁止复用催告闸、发送闸、精算闸、测算闸、解除闸、起诉闸、解异闸、通知闸、主张闸。预留不得占用：立案闸、和解闸。本窗主行只能是 `SH#`，禁止 `SJ#`、`JS#`、`DJ#`、`CG#`、`HF#`、`QT#`、`SP#`、`YY#`、`A#`。主路径只用 `Q-索`，禁止用 `Q-测`、`Q-告`、`Q-函`、`Q-除`、`Q-诉`、`Q-金`、`Q-额`、`Q-签` 作主路径。邻窗 `Q-索` 只作转介进本窗；本窗打开为主路径，不是已发出、不是必得、不是已违约、不是已立案。本窗 `Q-测` 只转介 `测算违约金与损害赔偿`。本窗 `Q-告` 只转介 `准备催告履行或补救通知`。本窗 `Q-诉` 只转介 `提起合同纠纷一审`。本窗 `Q-签` 只作「稿即已发送、已中断或已提交」不关窗码。索赔闸打开不等于已发送不等于已到达不等于已违约不等于约定金必得不等于时效已中断不等于待发送终稿。约定数字不是必得。过分高于对照损失不是合同总价。增减须当事人请求。草稿不是已发送。口头或已读不是已到达。发出不是当然已中断时效。定金与违约金选用不明两项待核，不双计。服务合同不得直接套买卖解释第二十条。未知不写零。不执行发送。不代提交。不写精算终稿。不写起诉状。不选定法院。不定罪。伤残等级与本窗无关，禁止折入。

`depends-on` 为空。主成果是精算工作表转 `测算违约金与损害赔偿`。主成果是催告履行转 `准备催告履行或补救通知`。主成果是解除通知转 `准备解除通知`。主成果是起诉包转 `提起合同纠纷一审`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：不解除或已解除，需书面主张金钱。「今晚发索赔」「约定多少就得多少」仍正触发，成果状态 `草案`。金额、到达、选用未核验仍正触发：有可编号金钱请求切片、条款数字或已付款碎片则索赔闸打开或半开，第 6 节出 `SH#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出已发送／必得／已违约终稿」才关闸，仍交十节，第 6 节不出 `SH#` 终稿，第 7 节不得出精算终稿、发送版或起诉状，窗口不关。用户要把约定数字写成必得、把过分高于对照合同总价、把草稿写成已发送、把已读写成到达、把索赔写成违约已成立、把发出写成已中断时效、把定金与违约金双计、把未知写成零，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `SH#` 草案。不得因「不执行发送」「不写精算终稿」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是精算工作表或必得核算（转 `测算违约金与损害赔偿`）；
- 主成果仍要对方履行或补救（转 `准备催告履行或补救通知`）；
- 主成果是发送版解除通知（转 `准备解除通知`）；
- 主成果是起诉包（转 `提起合同纠纷一审`）；
- 主成果是定金罚则专项终稿（转 `评估定金罚则争议`）；
- 主成果是争议总图（转 `评估合同争议`）；
- 尚未成争，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）；
- 尚未形成金钱请求切片，只要策略。

双方秘密、伪造流水或索赔函、虚增损失、倒签发出日、伪造送达、违法取证**不在负触发表**，走整体停止。「约定数字即必得」「总价百分之三十即过分高于」「草稿即已发送」「已读即到达」「索赔即违约已成立」「发出即已中断时效」「定金违约金双计」「未知写零」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不执行发送」「不写精算终稿」「不写起诉状」是交付禁令，不是负触发。主成果才转；出现「索赔」「违约金」一词不是转出。

## 建立工作坐标

确认：发送授权；单方立场；金钱请求切片；条款数字或损失碎片；定金选用；渠道；法域。

口头「今晚发索赔」「约定多少就得多少」只登记 `S#`／`V#`。不得升格已发送、已到达、必得或已违约，**不得单独算作开闸材料**。可编号金钱请求切片、条款数字或已付款碎片可开闸。本窗不执行发送，不代提交，不写精算终稿，不写起诉状，不选定法院。

立场只许主张金钱的守约方或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：索赔闸关闭，仍交十节，不是整体停止。无书面授权但单方立场已闭合、且已有碎片：索赔闸部分打开，仍交十节，不是整体停止。提出伪造流水或索赔函、虚增损失、倒签发出日、伪造送达或违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`SH#` 索函行；`V#` 版本；`E#` 证据形态回链（条款数字、损失碎片、授权、旧函，不是发送闸，不是已发送证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`SJ#`、`JS#`、`DJ#`、`CG#`、`HF#`、`QT#`、`SP#`。技能正文中的条号是检索锚点，不是已核验 `L#`。文件状态只用 `草案`、`待提交`、`停止`。金额、到达或选用未闭合不得标 `待提交`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。未知不写零。约定数字 ≠ 必得。过分高于 ≠ 对照合同总价。草稿 ≠ 已发送。已读 ≠ 到达。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或文书范本检索。本窗是索赔通知草稿，范本只借索赔函栏目，**不要**升格「已发送／已到达／必得／已违约／已中断」，**不要**改写成起诉状。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现约定金即必得、总价百分之三十即过分高于、草稿即已发送、已读即到达的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效合同法第一百十四条、解释（二）标的额百分之三十、把买卖解释第二十条套服务合同当作现行。MCP 效力字段与公布施行日冲突时，以施行日为准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的调整、到达、中断、必得保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民法典第五百八十五条约定金可增减，增减须当事人请求，过分高于对照违约造成的损失不是合同总价。第五百八十四条损失相当于因违约所造成的损失，受可预见限制。通则解释第六十五条以第五百八十四条损失为基，超过损失百分之三十一般可认定过分高于，不是总价上限。第六十四条调整须请求，约定不得调整不排除。第一百三十七条已读不是到达。第一百九十五条中断须到达且请求内容可识别，草稿不是已中断。第五百八十六条至第五百八十八条、通则解释第六十七条至第六十八条定金与违约金选用不明两项待核，不双计。噪声：已失效合同法第一百十四条及解释（二）；买卖解释第二十条套服务合同。技能正文条号不是 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变到达、第五百八十五条调整、定金选用或中断效果的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补约定金不是必得、过分高于不对照总价、无请求不得写已调、草稿不是已发送、已读不是到达、索赔不是违约已成立、发出不是当然已中断的实务反例。
- `search_template` 只借索赔函或催款函栏目（当事人／请求项目／事实与理由／付款期限与账户／证据名称／渠道回证）。范本总额栏、逾期即解除句、此致某院、落款日、送达回证不得升格已发送、已到达、必得、已违约、已解除或待发送终稿。禁止改写成起诉状。禁止用催告、解除通知或民事起诉状改头换面。禁止用范本生成发送版。

工具不可用时继续项目碎片和 `SH#` 编目；到达、调整、必得、中断字段停止。不得拒跑，不得凭记忆写成已发送、必得或已违约。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、索赔闸与不关窗

主成果才整案转出。双方秘密、伪造流水、虚增损失、倒签第一次停。约定金即必得、草稿即已发送不关窗。闸关仍交十节，第 6 节不出 `SH#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

项目切片、性质、金额假设、定金选用、渠道分列。本节禁止出 `SH#` 终稿。

### 3. 索赔闸与路径 `Q#`

本节禁止出 `SH#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-索`。

### 4. 索函行 `SH#`

项目切片、性质与请求、金额与假设、互斥与调整、渠道与回证。状态 `草案`。禁止升格已发送、已到达、必得、已违约。无 `E#` 不得写已发送。金额或到达未闭合不得标 `待提交`。

### 5. 精算、催告、起诉、送达接口

精算转测算窗。仍要履行转催告窗。起诉包转一审窗。第 7 节不得夹带 `SH#` 终稿、精算终稿、发送版或起诉状绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造流水或索赔函、虚增损失、倒签发出日、伪造送达或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：索赔闸关闭，仍交十节，不是整体停止。无书面授权但有碎片：索赔闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：金额、到达、调整、选用、施行日未核验。约定数字即必得、总价百分之三十即过分高于、草稿即已发送、已读即到达、索赔即违约已成立、发出即已中断时效、定金违约金双计、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `SH#` 草案。
- `目标停止`：主目标变为精算终稿、催告履行、解除通知或起诉包。禁止把「约定数字即必得」或「草稿即已发送」当作用户错误主张时的目标停止；那是不关窗。

禁止指导伪造流水或虚增损失。不给胜诉率。不定罪。不选定法院。不执行发送。不代提交。未知不写零。不写精算终稿。不写起诉状。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。索赔闸关闭仍交十节，第 6 节不出 `SH#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `SH#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。索赔闸未打开时不得交付「已发送」或「必得」。边界见 [路由](references/routing.md)。
