# 边界与路由

## 正触发

不解除或已解除，需要书面主张违约金、损失或其他金钱。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 精算终稿 | `测算违约金与损害赔偿` |
| 催告履行 | `准备催告履行或补救通知` |
| 解除通知 | `准备解除通知` |
| 起诉 | `提起合同纠纷一审` |
| 定金定性 | `评估定金罚则争议` |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，只分流不回改 |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

要一封要钱的函、还不是精算表或诉状时正触发。要可复核工作表时转测算。还想让对方继续交货时转催告。
