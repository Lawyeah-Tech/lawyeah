# 边界与路由

## 正触发

不解除或已解除，需书面主张金钱。从零、碎片、金额未核验、无书面授权仍正触发：有可编号金钱请求切片、条款数字或已付款碎片则闸开或半开，出 `SH#` 草案，保持草案。本次不执行发送、不写精算终稿、不写起诉状是交付禁令，不是开窗条件。约定数字即必得、草稿即已发送，仍正触发。把过分高于对照合同总价、把已读写成到达，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造流水、虚增损失、倒签发出日的停止，优先于负触发。上述信号不在下表。不执行发送不是负触发。「约定数字即必得」「总价百分之三十即过分高于」「草稿即已发送」「已读即到达」「索赔即违约已成立」「发出即已中断时效」「定金违约金双计」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 精算工作表或必得核算 | `测算违约金与损害赔偿` |
| 仍要对方履行或补救 | `准备催告履行或补救通知` |
| 发送版解除通知 | `准备解除通知` |
| 起诉包 | `提起合同纠纷一审` |
| 定金罚则专项终稿 | `评估定金罚则争议` |
| 争议总图 | `评估合同争议` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |
| 尚未形成金钱请求切片，只要策略 | `测算违约金与损害赔偿` |

不得因「不执行发送」或「不写精算终稿」关窗。拟索赔草稿仍正触发，不得写成已发送或必得。

## 易混

本窗闸名只能是索赔闸，不是催告闸，不是发送闸，不是精算闸，不是起诉闸。`SH#` 不是 `SJ#`，不是 `CG#`，不是 `HF#`，不是 `QT#`，不是 `JS#`，不是 `DJ#`，不是 `SP#`。主路径是 `Q-索`，不是 `Q-测`，不是 `Q-告`，不是 `Q-函`，不是 `Q-诉`。`精算闸`／`Q-测` 是测算违约金与损害赔偿。`催告闸`／`Q-告` 是准备催告履行或补救通知。`发送闸`／`Q-函` 是准备解除通知。`SP#` 是合规评价行。约定数字不是必得。过分高于对照损失不是合同总价。草稿不是已发送。已读不是到达。已失效合同法第一百十四条、解释（二）标的额百分之三十不是现行。买卖解释第二十条不得套服务合同。「今晚发索赔」「损失先按合同总价写满」整体停止。本窗不执行发送，不代提交。不选定法院。不写精算终稿。不写起诉状。
