# 准备索赔或违约金主张通知方法

本文件是可执行判断节点。约定数字不是必得。过分高于对照损失不是合同总价。增减须当事人请求。草稿不是已发送。口头或已读不是已到达。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已发送、必得、已违约、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不写精算终稿，不写起诉状。本窗闸名只能是索赔闸，禁止复用催告闸、发送闸、精算闸、解除闸、起诉闸。预留不得占用：立案闸、和解闸。本窗 `SH#` 是索函行。主路径只用 `Q-索`，禁止用 `Q-测`、`Q-告`、`Q-函`、`Q-诉`、`Q-签` 作主路径。本窗 `Q-签` 只作「稿即已发送、已中断或已提交」不关窗码。英文 id 禁止使用，一律用中文技能名 `准备索赔或违约金主张通知`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效合同法第一百十四条、解释（二）标的额百分之三十、把买卖解释第二十条套服务合同时记为噪声。禁止指导伪造流水或虚增损失。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现项目碎片扫描，不是默认闭集。
`SH#` 固定列：`编号｜项目切片｜性质与请求｜金额与假设｜互斥与调整接口｜渠道与回证｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已发送」或「必得」。无 `E#` 不得写已发送。金额或到达未闭合不得标 `待提交`。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-索`。禁止 `SJ#`、`JS#`、`DJ#`、`CG#`、`HF#`、`QT#`、`SP#`、`A#`、`N#`。

口头「今晚发索赔」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：函面主张不等于已违约成立。调整须请求。中断须到达且请求内容可识别。

## 节点 0　分流、立场、索赔闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造流水、虚增损失、倒签发出日不进负表。利益冲突未解不进整体停止。不执行发送、不写精算终稿不是负触发。把约定数字写成必得、把草稿写成已发送不是负触发。

整案转出只交付第 1、2、10 节，不出 `SH#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是精算工作表或必得核算 | 负触发 `测算违约金与损害赔偿` |
| 主成果仍要对方履行或补救 | 负触发 `准备催告履行或补救通知` |
| 主成果是发送版解除通知 | 负触发 `准备解除通知` |
| 主成果是起诉包 | 负触发 `提起合同纠纷一审` |
| 主成果是定金罚则专项终稿 | 负触发 `评估定金罚则争议` |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 尚未形成金钱请求切片，只要策略 | 负触发 `测算违约金与损害赔偿` |
| 建设工程／金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不执行发送」「不写精算终稿」「不写起诉状」 | 交付禁令，不是负触发 |

出现「索赔」「违约金」一词不是转出。

索赔闸打开（可出 `SH#` 草案，仍不得标「已发送／必得／已违约」）须同时满足：单方无冲突立场已闭合；主成果是索赔或违约金主张通知草稿，不是精算终稿、不是发送版、不是起诉状；至少一行可编号金钱请求切片、条款数字或已付款碎片。口头「今晚发索赔」不算单独开闸材料。

索赔闸部分打开：已有碎片，但金额、到达或选用未闭合；对应格待核；仍交十节。无书面授权但单方立场已闭合且已有碎片：索赔闸部分打开，仍交十节，不是整体停止。

索赔闸关闭（仍正触发）：无一可编号碎片。「今天必须出已发送／必得终稿」而无最小碎片不得开闸。不出 `SH#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `SH#` 终稿，**第 7 节不得出精算终稿、发送版或起诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「约定数字即必得」「总价百分之三十即过分高于」「草稿即已发送」「已读即到达」「索赔即违约已成立」「发出即已中断时效」「定金违约金双计」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `SH#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 索赔闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造流水或索赔函、虚增损失、倒签发出日、伪造送达或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个项目切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `SH#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 项目 | 约定金／损失／定金／已付款返还分列 | 合成应赔总额；函内已解除 |
| 金额 | 条款数字或损失假设分列 | 未知写零；未舍入公式当本窗终稿 |
| 调整 | 过分高于对照损失、须请求分列 | 对照合同总价；无请求写已调 |
| 选用 | 定金与违约金分列 | 双计相加 |
| 到达 | 渠道、回证栏目分列 | 已读即到达；草稿即已发送 |

检索锚点（写入 `L#` 前须核验）：见技能正文 MCP 节。噪声：合同法第一百十四条；解释（二）标的额百分之三十。

## 节点 3　索函行 `SH#`

按已出现项目碎片扫描，不是默认闭集。每条须能指向性质、金额假设、互斥调整或渠道回证之一。

无 `E#` 不得写已发送。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止唯一必得总额。金额或到达未闭合不得标 `待提交`。

热冲突强制处理：

- 约定数字即必得／总价百分之三十即过分高于／草稿即已发送／已读即到达／索赔即违约已成立／发出即已中断／定金违约金双计／未知写零 → 该格不支持或字段停止；仍出其他 `SH#`。
- 无一碎片 → 关闸，不出 `SH#` 终稿，窗口不关。
- 指导伪造流水、虚增损失、倒签、伪造送达 → 整体停止，不是该格不支持。

## 节点 4　精算、催告、起诉、送达接口

第 7 节只开接口，不得夹带 `SH#` 终稿、精算终稿、发送版或起诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待项目编号」，不得补写已发送。不选定法院。不执行发送。不写精算终稿。不写起诉状。

下一步只转介：`测算违约金与损害赔偿`、`准备催告履行或补救通知`、`准备解除通知`、`设计合同案件通知送达`、`评估定金罚则争议`、`评估价款结算与发票争议`、`评估迟延拒绝与不完全履行`、`评估质量瑕疵与检验期间`、`处理解除后返还与清理`、`评估继续履行是否可能`、`选择合同违约与侵权竞合路径`、`准备质量或损失鉴定申请`、`评估争议期间`、`建立合同争议证据案卷`、`谈判合同和解方案`、`提起合同纠纷一审`、`评估电子合同成立与送达`、`评估合同管辖与仲裁协议`、`评估合同争议`。禁止此致某院。

若 if 用户催促「今晚发索赔／约定多少就得多少／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「索赔闸与索函行草案」。本窗不执行发送。不包含：已发送、必得、已违约、精算终稿、起诉状。禁止选边治愈。禁止约定金即必得。禁止草稿即已发送。禁止指导伪造。索赔闸打开 ≠ 已发送 ≠ 必得 ≠ 已违约。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标索赔终稿已形成。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：买卖尾款未付，合同写违约金为总价百分之二十，用户主张约定多少就得多少、总价百分之三十就是上限、今晚发出去就算已发送、已读就算到达、发出去时效就中断了、不清楚先写零。索赔闸打开或半开。`Q-必`、`Q-三`、`Q-签`、`Q-读`、`Q-零` 不打开为可靠路径。第 6 节不得把必得、总价百分之三十上限、已发送、已到达、0 写入可执行 `SH#`；对应格 `现有依据不支持` 或字段停止；仍出项目分列、损失对照缺口、调整须请求、渠道回证待核等其他 `SH#`。不关窗。不执行发送。不写精算终稿。不写起诉状。

场景②：用户同时交出己方「损失金额先按合同总价写满、发出日改到上周」与对方「质量根本不合格」口径，并要「先发出去再说」。命中双方秘密＋虚增损失＋倒签。第一次整体停止。只交第 1、10 节。不出 `SH#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代违法方案。
