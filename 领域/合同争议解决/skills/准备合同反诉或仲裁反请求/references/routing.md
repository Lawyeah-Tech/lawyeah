# 边界与路由

## 正触发

一般合同已决定提出反诉或仲裁反请求，需要状稿草稿。从零、碎片、牵连未核验仍正触发：有可编号拟反请求切片、本诉或仲裁碎片则闸开或半开，出 `FT#` 草案，保持草案。本次不代提交、不保证准许是交付禁令，不是开窗条件。草稿即已提起、无牵连仍要可提交，仍正触发。把评估写成已提起、把答辩和反诉混成一份，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造牵连、塞无关债拒限缩的停止，优先于负触发。上述信号不在下表。不代提交不是负触发。「草稿即已提起」「评估即已提起」「无牵连仍要可提交终稿」「答辩期满即失权」「二审当然一并」「混成一份答辩终稿」「保证准许」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 条件评估 | `评估合同反诉或反请求` |
| 一审答辩 | `应对合同纠纷一审` |
| 应裁实体 | `应对合同仲裁` |
| 二审答辩 | `应对合同案件二审` |
| 无关另诉 | `提起合同纠纷一审` 或 `提起合同仲裁` |
| 抵销抗辩不必反诉 | `评估抵销留置与扣款抗辩` |
| 证据案卷终稿 | `建立合同争议证据案卷` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不代提交」或「不保证准许」关窗。拟状稿草稿仍正触发，不得写成已提起或已受理。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤、劳动反申请 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流。出现「反诉」「反请求」一词不是转出。C 端只要大众填空页时只分流，不把本包降成填空式结论，不回改。

## 易混

本窗闸名只能是反状闸，不是反诉闸，不是反请求闸，不是答辩闸，不是应裁闸，不是起诉闸，不是决定闸。`FT#` 不是 `FQ#`，不是 `FS#`，不是 `DB#`，不是 `YC#`，不是 `QT#`。主路径是 `Q-反请`，不是 `Q-反`，不是 `Q-状`，不是 `Q-辩`，不是 `Q-应裁`。`反诉闸`／`FQ#`／`Q-反` 是评估合同反诉或反请求。`FS#` 是公司治理分配诉行。1991 年或 2017 年第一百四十三条不是现行合并条。2015 年解释第三百二十八条须核 2022 年第三百二十六条。2022 年第三百二十七条不是二审反诉。1994 年第三十八条不是反请求。提出「把无关债写进去、落款改到上周」整体停止。本窗不代提交。不选定法院。不写发送版。不保证准许。
