# 准备合同反诉或仲裁反请求方法

本文件是可执行判断节点。草稿不是已提起。评估不是已提起。无牵连不是可提交终稿。答辩期满不是当然失权。二审反诉不是当然一并。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止准许率、已提起、已受理、选定法院、代提交、未知写零。本任务不定罪，不写发送版，不把草稿写成已提起。本窗闸名只能是反状闸，禁止复用反诉闸、反请求闸、答辩闸、应裁闸、起诉闸、决定闸。预留不得占用：立案闸、保全闸、反诉闸。本窗 `FT#` 是反状行。主路径只用 `Q-反请`，禁止用 `Q-反`、`Q-状`、`Q-辩`、`Q-应裁`、`Q-签` 作主路径。本窗 `Q-签` 只作「草稿即已提起、已提交或已受理」不关窗码。本窗 `Q-反` 只转介评估窗。英文 id 禁止使用，一律用中文技能名 `准备合同反诉或仲裁反请求`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991 年或 2017 年第一百四十三条、2015 年解释第三百二十八条、1994 年第三十八条除名、把草稿写成已提起时记为噪声。禁止指导伪造牵连或隐匿证据。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现拟反请求切片扫描，不是默认闭集。
`FT#` 固定列：`编号｜反诉或反请求切片｜当事人与本诉对应｜牵连覆盖｜期间与规则期限｜证据目录接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已提起」或「已受理」。无 `E#` 不得写已提起。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-反请`。禁止 `FQ#`、`FS#`、`DB#`、`YC#`、`QT#`、`A#`、`N#`。牵连或覆盖未闭合不得标待提交。答辩与反诉分列成稿。

口头「已经决定反了」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：无牵连关可提交该格，仍出其他切片草案。二审钉解释第三百二十六条。仲裁反请求期看该机构规则。

## 节点 0　分流、立场、反状闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造牵连、倒签、把无关债塞进状稿且拒限缩、隐匿证据、违法取证不进负表。利益冲突未解不进整体停止。不代提交、不保证准许不是负触发。

整案转出只交付第 1、2、10 节，不出 `FT#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是条件评估 | 负触发 `评估合同反诉或反请求` |
| 主成果是一审答辩 | 负触发 `应对合同纠纷一审` |
| 主成果是应裁实体 | 负触发 `应对合同仲裁` |
| 主成果是二审答辩 | 负触发 `应对合同案件二审` |
| 主成果是无关另诉 | 负触发 `提起合同纠纷一审` 或 `提起合同仲裁` |
| 主成果是抵销抗辩不必反诉 | 负触发 `评估抵销留置与扣款抗辩` |
| 主成果是证据案卷终稿 | 负触发 `建立合同争议证据案卷` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程／金融借贷担保／房地产物业／海事／劳动反申请主轴 | 整案转对应领域 |
| 「不代提交」「不保证准许」 | 交付禁令，不是负触发 |

出现「反诉」「反请求」一词不是转出。同时要状稿和评估红旗：本窗正触发。只要评估终稿且拒状稿才负触发。

反状闸打开（可出 `FT#` 草案，仍不得标「已提起／已受理／已提交」）须同时满足：单方无冲突反诉原告或反请求申请人立场已闭合；主成果是状稿草稿，不是评估终稿、不是一审答辩、不是发送版；至少一项可编号拟反请求切片、本诉或仲裁碎片。口头「已经决定反了」不算单独开闸材料。

反状闸部分打开：已有碎片，但牵连、覆盖或期间未闭合；对应格待核；仍交十节。无书面授权但单方立场已闭合且已有碎片：反状闸部分打开，仍交十节，不是整体停止。

反状闸关闭（仍正触发）：无一可编号碎片。「今天必须出已提起终稿」而无最小碎片不得开闸。不出 `FT#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `FT#` 终稿，**第 7 节不得出发送版状稿**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已提起」「评估即已提起」「无牵连仍要可提交终稿」「答辩期满即失权」「二审当然一并」「混成一份答辩终稿」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `FT#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 反状闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造牵连、倒签、把无关债塞进状稿且拒限缩、隐匿证据或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个拟反请求切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `FT#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 主体 | 反诉原告＝本诉被告；被反诉人＝本诉原告 | 第三人当然列为被反诉人 |
| 请求 | 给付／确认／解除分列 | 与答辩混成一份终稿 |
| 牵连 | 同法律关系／因果／同事实／不足 | 无关债写入可提交终稿 |
| 论坛 | 法院／仲裁、专属、协议覆盖 | 此致某院升格已定 |
| 期间 | 辩论结束前／该机构规则／二审 326 | 答辩期当失权；民诉十五日充反请求截止 |
| 证据 | 独立目录，可引用本诉编号 | 隐匿不利证据 |

检索锚点（写入 `L#` 前须核验）：见技能正文 MCP 节。噪声：1991 年或 2017 年第一百四十三条；2015 年第三百二十八条；1994 年第三十八条。

## 节点 3　反状行 `FT#`

按已出现拟反请求切片扫描，不是默认闭集。每条须能指向请求、当事人对应、牵连或期间之一。

无 `E#` 不得写已提起。状态默认 `草案`。一次只推荐下一步。未知不写零。牵连或覆盖未闭合不得标待提交。禁止写入已受理或当然合并。

热冲突强制处理：

- 草稿即已提起／评估即已提起／无牵连仍要可提交／答辩期满即失权／二审当然一并／混成一份答辩终稿／未知写零 → 该格不支持或字段停止；仍出其他 `FT#`。
- 无一碎片 → 关闸，不出 `FT#` 终稿，窗口不关。
- 指导伪造牵连、塞无关债拒限缩、隐匿 → 整体停止，不是该格不支持。

## 节点 4　评估、答辩、应裁、另诉与庭审接口

第 7 节只开接口，不得夹带 `FT#` 终稿或发送版绕闸。闸关闭时第 7 节可写「闸未开，转介待拟反请求切片编号」，不得补写已提起。不选定法院。不代提交。不写发送版。答辩与反诉必须分开。

下一步只转介：`评估合同反诉或反请求`、`应对合同纠纷一审`、`应对合同仲裁`、`应对合同案件二审`、`提起合同纠纷一审`、`提起合同仲裁`、`提出合同案件管辖异议`、`评估合同管辖与仲裁协议`、`准备合同仲裁协议异议材料`、`评估抵销留置与扣款抗辩`、`测算违约金与损害赔偿`、`建立合同争议证据案卷`、`规划举证期限与证据交换`、`准备合同案件庭审`、`评估合同争议`、`谈判合同和解方案`、`评估合同调解方案与效力`。禁止此致某院。草稿不得写成已提起。无牵连不得写成可提交终稿。

若 if 用户催促「状写完就算交了／评估过了就算提起了／没有牵连也先交／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

若 if 牵连、辩论结束前或该机构反请求期、覆盖、施行日未核验，then 该强制项字段停止，窗口不关。

## 本任务回链纪律

本任务成果是「反状闸与反状行草案」。本窗不代提交。不包含：已提起、已受理、发送版状稿、一审答辩终稿。禁止选边治愈。禁止草稿即已提起。禁止指导塞无关债。反状闸打开 ≠ 已提起 ≠ 已受理 ≠ 已提交。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标状稿终稿已形成。
风险档 A：伪造牵连、倒签、塞无关债必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：买卖尾款本诉，被告要质量违约金反诉状，并要把无关借款写进同一份。用户主张状写完就算交了、评估过了就算提起了、过了答辩期也必须收、二审必须一并、和答辩写在同一份、不清楚金额先写零。反状闸打开或半开。`Q-签`、`Q-连`、`Q-失`、`Q-二`、`Q-混`、`Q-零` 不打开为可靠路径。第 6 节不得把已提起、无关借款可提交、当然失权、当然一并、混稿、0 写入可执行 `FT#`；对应格 `现有依据不支持` 或字段停止；仍出质量给付切片、牵连待核、分开成稿接口。不关窗。不代提交。

场景②：用户同时交出己方「必须把无关债写进去、落款改到上周」与原告「从未违约」口径。命中双方秘密＋倒签＋塞无关债拒限缩。第一次整体停止。只交第 1、10 节。不出 `FT#`。不得问代表哪一方后继续。不以「坚持」为门槛。
