# 应对合同案件保全裁定

## 任务目标

在明确、无利益冲突的单方立场下（被保全方或其受托律师，互斥），形成发送前保全复议或担保置换草稿：应保闸、主体与强制接口、`Q#` 路径、`NS#` 应保行（文书切片／措施与范围／复议／五日／担保置换／超范围／错误赔偿接口／`E#` 回链）。本窗 `NS#` 是应保行草案，不是已解除，不是已解冻，不是已排除，不是发送版复议，不是进攻性保全申请。本窗闸名只能是应保闸，禁止复用冻结闸、保全闸、申保闸、要保闸、现证闸、应对闸、应诉闸、复议闸、换保闸、解封闸、答辩闸。预留不得占用：立案闸、和解闸、保全闸、冻结闸、申保闸、要保闸。本窗主行只能是 `NS#`，禁止 `FZ#`、`BQ#`、`SB#`、`YB#`、`XZ#`、`CB#`、`FC#`、`DB#`、`A#`。主路径只用 `Q-应保`，禁止用 `Q-冻`、`Q-保`、`Q-申保`、`Q-要`、`Q-现`、`Q-议`、`Q-额`、`Q-应`、`Q-辩`、`Q-签` 作主路径。邻窗 `Q-应保` 只作转介进本窗；本窗打开为主路径，不是已解除、不是已解冻、不是已提交。本窗 `Q-申保` 只转介 `准备合同财产保全申请`。本窗 `Q-要` 只转介 `评估合同财产保全必要性`。本窗 `Q-签` 只作「草稿即已提交或已解除」不关窗码。本窗 `Q-议` 只作「复议草稿即已解除」不关窗码。本窗 `Q-额` 只作「交保即已解冻」不关窗码。应保闸打开不等于已解除不等于已解冻不等于复议期间停止执行不等于等额担保已足额不等于行为保全应当解除不等于待提交终稿。复议草稿不是已解除。交保不是已解冻。复议期间不是停止执行。财产纠纷交保应当解除不是行为保全当然解除。等值担保可以变更不是应当解除。口头传说不是已冻结。未知不写零。不保证解除。不代提交。不选定法院。不定罪。伤残等级与本窗无关，禁止折入。先予执行、行为保全应对、案外人执行异议之诉属本包未安装能力，主成果命中则负触发 `unavailable`。

`depends-on` 为空。主成果是必要性评估转 `评估合同财产保全必要性`。主成果是进攻性财产保全申请转 `准备合同财产保全申请`。主成果是一审应诉转 `应对合同纠纷一审`。主成果是股权冻结或行为保全治理轴转 `应对股权冻结或行为保全`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：一般合同已成争，财产已被保全，需复议或提供担保解封。「给我解冻申请」「交保就能解」「复议期间先当没冻」仍正触发，成果状态 `草案`，不代提交。五日、担保、财产／行为对照未核验仍正触发：有可编号已作出保全文书碎片则应保闸打开或半开，第 6 节出 `NS#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出已解除终稿」才关闸，仍交十节，第 6 节不出 `NS#` 终稿，第 7 节不得出已解冻或发送版复议，窗口不关。用户要把复议写成已解除、把交保写成已解冻、把复议期间写成停止执行、把可以变更写成应当解除、把行为保全交保写成应当解除、把未知写成零，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `NS#` 草案。不得因「不保证解除」「不代提交」「不提供转移方案」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是必要性评估（转 `评估合同财产保全必要性`）；
- 主成果是进攻性财产保全申请书（转 `准备合同财产保全申请`）；
- 主成果是一审应诉而无复议或换保（转 `应对合同纠纷一审`）；
- 主成果是先予执行（`unavailable`，本包未安装）；
- 主成果是行为保全应对（`unavailable`，本包未安装）；
- 主成果是案外人执行异议之诉（`unavailable`，本包未安装）；
- 主成果是股权冻结或禁开会治理轴（转 `应对股权冻结或行为保全`）；
- 主成果是争议总图（转 `评估合同争议`）；
- 尚未成争，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）。

双方秘密、转移隐匿或毁损被保全财产、违反裁定处分、串通解冻、抽逃作置换担保、伪造权属、倒签复议日、违法取证**不在负触发表**，走整体停止。「复议即已解除」「交保即已解冻」「复议期间停止执行」「可以变更即应当解除」「行为保全交保即应当解除」「保证解除」「未知写零」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不保证解除」「不代提交」「不提供转移隐匿方案」是交付禁令，不是负触发。STUB 把「提供转移隐匿财产方案」放进负触发，必须改整体停止。转移隐匿**不是负触发**，第一次整体停止。主成果才转；出现「保全」「冻结」「复议」「解冻」「担保」一词不是转出。

## 建立工作坐标

确认：应对授权；单方立场；保全裁定或协助执行、冻结查封扣押通知；送达日；措施与范围；担保置换方案；法域；当前诉讼或仲裁状态。

口头「听说冻了」「交保就能解」只登记 `S#`／`V#`。不得升格已解除、已解冻或已提交，**不得单独算作开闸材料**。可编号已作出保全文书碎片可开闸。本窗不执行发送，不代提交，不写发送版复议。

立场只许被保全方或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：应保闸关闭，仍交十节，不是整体停止。无书面授权但单方立场已闭合、且已有碎片：应保闸部分打开，仍交十节，不是整体停止。提出转移隐匿或毁损被保全财产、违反裁定处分、串通解冻、抽逃作置换担保、伪造权属、倒签复议日或违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`NS#` 应保行；`V#` 版本；`E#` 证据形态回链（裁定、协助执行通知、送达回证、担保栏目，不是发送闸，不是已解除证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`FZ#`、`BQ#`、`SB#`、`YB#`、`XZ#`、`CB#`。技能正文中的条号是检索锚点，不是已核验 `L#`。文件状态只用 `草案`、`停止`。五日、担保或财产／行为对照未闭合不得标待提交。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。未知不写零。复议草稿 ≠ 已解除。交保 ≠ 已解冻。复议期间 ≠ 停止执行。可以变更 ≠ 应当解除。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或文书范本检索。本窗是复议或换保草稿，范本只借保全复议申请书、解除保全申请书、变更保全标的物申请书、担保置换栏目，**不要**升格「已解除／已解冻／已提交」。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现复议即已解除、交保即已解冻、复议期间停止执行的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把 1991 年民事诉讼法第一百一十一条起诉条件当作现行复议条。不得把 2017 年第一百零八条未核验对应现行第一百一十一条。不得把解释第一百七十二条仍引旧第一百零八条未核对应现行第一百一十一条。不得把财产保全规定仍引旧第二百二十五条、第二百二十七条未核对应现行执行异议条。MCP 可能先返回 1991 年第一百一十一条。MCP 效力字段与公布施行日冲突时，以施行日为准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的五日、解除条件、行为对照或施行日保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民事诉讼法（2023 修正，施行日 2024-01-01）第一百一十一条对保全或先予执行裁定不服可以申请复议一次，复议期间不停止裁定的执行；正文没有五日、十日。第一百零七条财产纠纷案件，被申请人提供担保的，应当裁定解除保全，不是交保即已解冻，不是行为保全当然交保即解除。第一百零八条申请有错误应当赔偿。民诉解释第一百七十一条自收到裁定书之日起五日内向作出裁定的人民法院申请复议，法院收到后十日内审查；五日是申请期限，十日是审查期限，不得写入第一百一十一条正文。第一百六十七条等值担保且有利于执行的，可以裁定变更保全标的物，可以不是应当，变更不是解除。财产保全规定第二十二条充分有效担保请求解除，财产纠纷应当准许；对作为争议标的的财产请求解除须经申请保全人同意。第二十五条送达之日起五日复议一次、法院十日审查。噪声：1991 年第一百一十一条起诉条件；2017 年第一百零八条、第一百零四条、第一百零五条；解释第一百七十二条仍引旧第一百零八条；财产保全规定仍引旧第二百二十五条、第二百二十七条须核对应现行执行异议条；知产行为保全规定第十二条不得写成一般合同默认路径。技能正文条号不是 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变五日、解除条件或行为对照的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补复议不是已解除、交保不是已解冻、复议期间不停止执行、财产纠纷交保应当解除、行为保全一般不因交保解除、可以变更不是应当解除的实务反例。
- `search_template` 只借保全复议申请书、解除保全申请书、变更保全标的物申请书、担保置换栏目。范本解除栏、此致某院、落款日不得升格已解除、已解冻或已提交。禁止用执行复议申请书冒充保全复议。禁止用诉讼保全申请书或行为保全申请书改头换面。禁止用范本生成发送版复议或转移隐匿步骤。

工具不可用时继续文书碎片和 `NS#` 编目；五日、解除条件、已解除字段停止。不得拒跑，不得凭记忆写成已解除或指导转移。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、应保闸与不关窗

主成果才整案转出。双方秘密、转移隐匿、违反裁定第一次停。复议即已解除、交保即已解冻不关窗。闸关仍交十节，第 6 节不出 `NS#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

财产／行为分列，行为列 `unavailable`。诉前／诉中／执行分列。本节禁止出 `NS#` 终稿。

### 3. 应保闸与路径 `Q#`

本节禁止出 `NS#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-应保`。

### 4. 应保行 `NS#`

文书、措施与范围、复议五日、担保置换、超范围与错误赔偿接口。状态 `草案`。禁止升格已解除、已解冻、已提交。无 `E#` 不得写已解除。

### 5. 申保、应诉、执行与案外人接口

申请转申保窗。实体应诉转一审。案外人路径 `unavailable`。第 7 节不得夹带 `NS#` 终稿或已解冻绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出转移隐匿或毁损被保全财产、违反裁定处分、串通解冻、抽逃作置换担保、伪造权属、倒签复议日或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：应保闸关闭，仍交十节，不是整体停止。无书面授权但有碎片：应保闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：五日、解除条件、财产／行为对照、施行日未核验。复议即已解除、交保即已解冻、复议期间停止执行、可以变更即应当解除、行为保全交保即应当解除、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `NS#` 草案。
- `目标停止`：主目标变为进攻性申请终稿、一审答辩终稿、案外人异议之诉、转移隐匿方案。禁止把「复议即已解除」或「交保即已解冻」当作用户错误主张时的目标停止；那是不关窗。

禁止指导转移隐匿或违反裁定。不给解除率。不定罪。不选定法院。不代提交。未知不写零。不写发送版复议。不保证解除。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。应保闸关闭仍交十节，第 6 节不出 `NS#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `NS#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。应保闸未打开时不得交付「已解除」或「已解冻」。边界见 [路由](references/routing.md)。
