# 边界与路由

## 正触发

财产已被保全，需复议或提供担保解封。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 尚未保全 | `评估合同财产保全必要性` |
| 申请保全 | `准备合同财产保全申请` |
| 实体应诉 | `应对合同纠纷一审` |
| 仲裁应诉 | `应对合同仲裁` |
| 案外人异议之诉 | unavailable（P2） |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，只分流不回改 |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

## 易混
