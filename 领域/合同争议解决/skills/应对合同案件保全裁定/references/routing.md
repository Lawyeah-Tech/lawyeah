# 边界与路由

## 正触发

一般合同已成争，财产已被保全，需复议或提供担保解封。从零、碎片、五日未核验、无书面授权仍正触发：有可编号已作出保全文书碎片则闸开或半开，出 `NS#` 草案，保持草案。本次不保证解除、不代提交、不提供转移方案是交付禁令，不是开窗条件。复议即已解除、交保即已解冻，仍正触发。把复议期间写成停止执行、把可以变更写成应当解除，仍正触发：该格不支持，不改负触发关窗。

双方秘密、转移隐匿、违反裁定的停止，优先于负触发。上述信号不在下表。不保证解除不是负触发。「复议即已解除」「交保即已解冻」「复议期间停止执行」「可以变更即应当解除」「行为保全交保即应当解除」「保证解除」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 必要性评估 | `评估合同财产保全必要性` |
| 进攻性财产保全申请 | `准备合同财产保全申请` |
| 一审应诉而无复议或换保 | `应对合同纠纷一审` |
| 先予执行 | `unavailable` |
| 行为保全应对 | `unavailable` |
| 案外人执行异议之诉 | `unavailable` |
| 股权冻结或禁开会治理轴 | `应对股权冻结或行为保全` |
| 争议总图 | `评估合同争议` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不保证解除」或「不提供转移方案」关窗。拟复议或换保仍正触发，不得写成已解除或已解冻。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |

| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流。出现「保全」「冻结」「复议」一词不是转出。C 端只要大众填空页时只分流，不把本包降成填空式结论，不回改。

## 易混

本窗闸名只能是应保闸，不是冻结闸，不是保全闸，不是申保闸，不是要保闸，不是应对闸，不是复议闸。`NS#` 不是 `FZ#`，不是 `SB#`，不是 `YB#`，不是 `BQ#`。主路径是 `Q-应保`，不是 `Q-冻`，不是 `Q-保`，不是 `Q-申保`，不是 `Q-要`，不是 `Q-议`。`冻结闸`／`FZ#`／`Q-冻` 是公司治理应对股权冻结或行为保全。`申保闸`／`SB#`／`Q-申保` 是准备合同财产保全申请。`要保闸`／`YB#`／`Q-要` 是评估合同财产保全必要性。复议草稿不是已解除。交保不是已解冻。复议期间不是停止执行。1991 年民事诉讼法第一百一十一条起诉条件不是现行复议条。2017 年第一百零八条须核对应现行第一百一十一条。五日和十日在解释第一百七十一条，不得写入第一百一十一条正文。提出「今晚把冻结账户的钱转走」整体停止。本窗不执行发送，不代提交。不选定法院。不写发送版。不保证解除。不提供转移隐匿方案。
