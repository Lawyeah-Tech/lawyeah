# 应对合同案件保全裁定方法

本文件是可执行判断节点。复议草稿不是已解除。交保不是已解冻。复议期间不是停止执行。财产纠纷交保应当解除不是行为保全当然解除。等值担保可以变更不是应当解除。未知不写零。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已解除、已解冻、选定法院、代提交、未知写零。本任务不定罪，不写发送版复议，不保证解除，不提供转移隐匿方案。本窗闸名只能是应保闸，禁止复用冻结闸、保全闸、申保闸、要保闸、应对闸、复议闸、换保闸。预留不得占用：立案闸、和解闸、保全闸、冻结闸、申保闸、要保闸。本窗 `NS#` 是应保行。主路径只用 `Q-应保`，禁止用 `Q-冻`、`Q-保`、`Q-申保`、`Q-要`、`Q-议`、`Q-额`、`Q-应`、`Q-辩`、`Q-签` 作主路径。本窗 `Q-签` 只作「草稿即已提交或已解除」不关窗码。本窗 `Q-议` 只作「复议草稿即已解除」不关窗码。本窗 `Q-额` 只作「交保即已解冻」不关窗码。英文 id 禁止使用，一律用中文技能名 `应对合同案件保全裁定`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991 年民事诉讼法第一百一十一条起诉条件、2017 年第一百零八条、把复议写成已解除时记为噪声。禁止指导转移隐匿或违反裁定。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现文书切片扫描，不是默认闭集。
`NS#` 固定列：`编号｜文书切片｜措施与范围｜复议／五日｜担保置换｜超范围／错误赔偿接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已解除」或「已解冻」。无 `E#` 不得写已解除。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-应保`。禁止 `FZ#`、`BQ#`、`SB#`、`YB#`、`XZ#`、`CB#`、`A#`、`N#`。文件状态只用 `草案`、`停止`。

口头「听说冻了」「交保就能解」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：复议向作出裁定的法院提出，不是向上一级。复议期间不停止执行。财产纠纷交保应当解除须裁定，不是自行解封。行为保全主成果 `unavailable`。案外人异议之诉 `unavailable`。

## 节点 0　分流、立场、应保闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、转移隐匿、违反裁定、串通解冻、抽逃作置换担保、伪造权属、倒签复议日、违法取证不进负表。利益冲突未解不进整体停止。不保证解除、不代提交、不提供转移方案不是负触发。

整案转出只交付第 1、2、10 节，不出 `NS#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是必要性评估 | 负触发 `评估合同财产保全必要性` |
| 主成果是进攻性财产保全申请 | 负触发 `准备合同财产保全申请` |
| 主成果是一审应诉而无复议或换保 | 负触发 `应对合同纠纷一审` |
| 主成果是先予执行 | 负触发 `unavailable` |
| 主成果是行为保全应对 | 负触发 `unavailable` |
| 主成果是案外人执行异议之诉 | 负触发 `unavailable` |
| 主成果是股权冻结或禁开会治理轴 | 负触发 `应对股权冻结或行为保全` |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程／金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不保证解除」「不代提交」「不提供转移方案」 | 交付禁令，不是负触发 |

出现「保全」「冻结」「复议」「解冻」一词不是转出。

应保闸打开（可出 `NS#` 草案，仍不得标「已解除／已解冻／已提交」）须同时满足：单方无冲突立场已闭合；主成果是复议或担保置换草稿，不是进攻申请、不是一审答辩、不是案外人异议之诉；至少一项可编号已作出保全文书碎片。口头「听说冻了」不算单独开闸材料。

应保闸部分打开：已有碎片，但五日、担保或财产／行为对照未闭合；对应格待核；仍交十节。无书面授权但单方立场已闭合且已有碎片：应保闸部分打开，仍交十节，不是整体停止。

应保闸关闭（仍正触发）：无一可编号碎片。「今天必须出已解除终稿」而无最小碎片不得开闸。不出 `NS#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `NS#` 终稿，**第 7 节不得出已解冻或发送版复议**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「复议即已解除」「交保即已解冻」「复议期间停止执行」「可以变更即应当解除」「行为保全交保即应当解除」「保证解除」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `NS#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 应保闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出转移隐匿或毁损被保全财产、违反裁定处分、串通解冻、抽逃作置换担保、伪造权属、倒签复议日或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个文书切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `NS#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 文书 | 裁定／协助执行／冻结查封扣押通知／送达回证分列 | 口头传说升格已冻结 |
| 措施 | 查封／扣押／冻结与范围分列 | 混成已全部解冻 |
| 制度 | 财产保全／行为保全／先予执行分列 | 把行为或先予写入财产行终稿 |
| 复议 | 五日申请期限、十日审查期限、不停止执行分列 | 五日写入第一百一十一条正文；向上一级复议 |
| 担保 | 财产纠纷应当解除／争议标的须同意／可以变更分列 | 交保即已解冻；可以变更即应当解除 |

检索锚点（写入 `L#` 前须核验）：见技能正文 MCP 节。噪声：1991 年第一百一十一条；2017 年第一百零八条。

## 节点 3　应保行 `NS#`

按已出现文书切片扫描，不是默认闭集。每条须能指向措施与范围、复议五日、担保置换或超范围错误赔偿接口之一。

无 `E#` 不得写已解除或已解冻。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止唯一日历截止日。五日或担保未闭合不得标待提交。

热冲突强制处理：

- 复议即已解除／交保即已解冻／复议期间停止执行／可以变更即应当解除／行为保全交保即应当解除／未知写零 → 该格不支持或字段停止；仍出其他 `NS#`。
- 无一碎片 → 关闸，不出 `NS#` 终稿，窗口不关。
- 指导转移隐匿、违反裁定、串通解冻 → 整体停止，不是该格不支持。

## 节点 4　申保、应诉、执行与案外人接口

第 7 节只开接口，不得夹带 `NS#` 终稿或已解冻绕闸。闸关闭时第 7 节可写「闸未开，转介待文书编号」，不得补写已解除。不选定法院。不代提交。不保证解除。

下一步只转介：`评估合同财产保全必要性`、`准备合同财产保全申请`、`评估合同争议`、`评估合同管辖与仲裁协议`、`提起合同纠纷一审`、`应对合同纠纷一审`、`提出合同案件管辖异议`、`提起合同仲裁`、`选择诉讼仲裁或督促程序`、`建立合同争议证据案卷`、`申请律师调查令或法院调查取证`、`测算违约金与损害赔偿`、`评估债权人撤销权`、`准备债权人撤销权诉讼`、`评估债权人代位权`、`准备代位权诉讼材料`、`准备合同案件公证保全`、`保全质量现场与电子证据`。禁止此致某院。

若 if 用户催促「交保就能解／复议期间先当没冻／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 用户要求转移隐匿或违反裁定，then 第一次整体停止。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「应保闸与应保行草案」。本窗不执行发送。不包含：已解除、已解冻、已提交终稿、发送版复议、转移步骤。禁止选边治愈。禁止复议即已解除。禁止交保即已解冻。禁止指导转移隐匿。应保闸打开 ≠ 已解除 ≠ 已解冻 ≠ 复议期间停止执行。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标应对终稿已形成。
风险档 A：转移隐匿、违反裁定、串通解冻必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：买方账户被冻，主张交了担保就算已经解冻、复议期间先当没冻、复议申请交了就算已经撤销、此致某中院、不清楚的损失先写零。应保闸打开或半开。`Q-额`、`Q-停`、`Q-议`、`Q-院`、`Q-零` 不打开为可靠路径。第 6 节不得把已解冻、停止执行、已解除、0 写入可执行 `NS#`；对应格 `现有依据不支持` 或字段停止；仍出文书分列、措施范围、五日待核、财产纠纷交保应当解除须裁定、错误赔偿接口等其他 `NS#`。不关窗。不代提交。不保证解除。

场景②：用户同时交出己方「已经解冻」与申请保全人「仍在冻结」口径，并要「今晚把冻结账户的钱转走、置换担保用抽逃资金」。命中双方秘密＋违反裁定＋抽逃作保。第一次整体停止。只交第 1、10 节。不出 `NS#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给转移方案。
