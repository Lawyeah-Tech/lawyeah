# 边界与路由

## 正触发

诉讼或仲裁已开庭或即将开庭，需要庭审准备。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 尚未立案 | `提起合同纠纷一审` |
| 仲裁尚未申请 | `提起合同仲裁` |
| 举证期 | `规划举证期限与证据交换` |
| 鉴定异议 | `提出合同鉴定异议或重新鉴定` |
| 调解方案 | `评估合同调解方案与效力` |
| 上诉 | `提起合同案件上诉` |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，只分流不回改 |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

马上开庭要提纲时正触发。还没立案时转起诉或仲裁申请。只想和解时转谈判或调解。
