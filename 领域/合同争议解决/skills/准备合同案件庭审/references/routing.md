# 边界与路由

## 正触发

一般合同诉讼或仲裁已开庭或即将开庭，需要争点、举证质证、询问或代理提纲。从零、碎片、尚未立案或尚未组庭仍要提纲仍正触发：有可编号开庭碎片则闸开或半开，出 `KT#` 草案；无碎片则闸可关，仍交十节，不改负触发踢走。本次不代开庭、不给胜诉率是交付禁令，不是开窗条件。提纲即已开庭、口头即已质证，仍正触发。把缺席写成当然胜诉、把逾期写成当然可提交，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造证据、诱导作伪证的停止，优先于负触发。上述信号不在下表。不代开庭不是负触发。「提纲即已开庭」「口头即已质证」「网交即已提交」「逾期即当然可提交」「缺席即当然胜诉」「保证胜诉」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 尚未立案的起诉包 | `提起合同纠纷一审` |
| 仲裁申请包 | `提起合同仲裁` |
| 首次答辩 | `应对合同纠纷一审` |
| 应裁实体 | `应对合同仲裁` |
| 案卷编目终稿 | `建立合同争议证据案卷` |
| 举证期限与交换计划 | `规划举证期限与证据交换` |
| 可签和解或调解方案终稿 | `谈判合同和解方案` 或 `评估合同调解方案与效力` |
| 上诉状 | `提起合同案件上诉` |
| 鉴定申请或鉴异终稿 | 对应鉴定窗；庭上问鉴定人留本窗 |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不代开庭」或「不给胜诉率」关窗。拟提纲仍正触发，不得写成已开庭或已质证。

## 易混

本窗闸名只能是开庭闸，不是庭审闸，不是举证闸，不是证据闸，不是起诉闸，不是质证闸。`KT#` 不是 `TS#`，不是 `JQ#`，不是 `JE#`，不是 `QT#`。主路径是 `Q-开庭`，不是 `Q-审`，不是 `Q-庭`，不是 `Q-举证`，不是 `Q-据`。`庭审闸`／`TS#`／`Q-审` 是准备股东与公司治理案件庭审，本窗分列开庭闸，不得抄名册章证照列。`举证闸`／`JQ#`／`Q-举证` 是规划举证期限与证据交换。`证据闸`／`JE#`／`Q-据` 是建立合同争议证据案卷。1991 年民事诉讼法第一百三十九条先行判决不是开庭通知。1991 年第一百四十七条上诉期不是被告缺席。1991 年第七十一条当事人陈述不是出示质证。2017 年开庭与缺席旧条须核现行。仲裁开庭通知按该机构规则，不得一律三日。提出「对账单藏起来、证人按我写的答、倒签质证笔录」整体停止。本窗不代开庭。不代提交。不选定法院。不给胜诉率。
