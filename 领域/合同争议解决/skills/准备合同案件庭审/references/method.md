# 准备合同案件庭审方法

本文件是可执行判断节点。提纲不是已开庭。口头已质证不是已质证。网交不是已提交。逾期证据不是当然可提交。缺席不是当然胜诉。不利证据必须入列。未知不写零。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已开庭、已质证、已胜诉、选定法院、代开庭、代提交、未知写零。本任务不定罪，不执行发送，不保证结果。本窗闸名只能是开庭闸，禁止复用庭审闸、举证闸、证据闸、起诉闸。预留不得占用：立案闸、举证闸、庭审闸。本窗 `KT#` 是开庭行。主路径只用 `Q-开庭`，禁止用 `Q-审`、`Q-庭`、`Q-举证`、`Q-据`、`Q-诉`、`Q-签` 作主路径。本窗 `Q-签` 只作「提纲即已提交或已开庭」不关窗码。本窗 `Q-证` 只作「口头即已质证」不关窗码。英文 id 禁止使用，一律用中文技能名 `准备合同案件庭审`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991 年民事诉讼法第一百三十九条先行判决、第一百四十七条上诉期、第七十一条当事人陈述、2017 年开庭与缺席旧条、把劳动办案规则套商事庭审时记为噪声。禁止指导伪造证据或诱导作伪证。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现争点切片扫描，不是默认闭集。
`KT#` 固定列：`编号｜争点切片｜本证反证｜质证三性｜询问与承认风险｜调解权限接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已开庭」或「已质证」。无 `E#` 不得写已开庭。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-开庭`。禁止 `TS#`、`JQ#`、`JE#`、`QT#`、`A#`、`N#`。文件状态只用 `草案`、`停止`。

口头「明天开庭一定赢」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：有传票、开庭通知、组庭或排期才可能开闸。诉讼与仲裁规则分列。不利证据必须入列。鉴定人拒不出庭只击该意见，不是全案必败。缺席「可以」不是请求当然成立。

## 节点 0　分流、立场、开庭闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造证据、诱导作伪证、倒签笔录、隐匿已知材料、违法取证不进负表。利益冲突未解不进整体停止。不代开庭、不给胜诉率不是负触发。

整案转出只交付第 1、2、10 节，不出 `KT#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是尚未立案的起诉包 | 负触发 `提起合同纠纷一审` |
| 主成果是仲裁申请包 | 负触发 `提起合同仲裁` |
| 主成果是首次答辩 | 负触发 `应对合同纠纷一审` |
| 主成果是应裁实体 | 负触发 `应对合同仲裁` |
| 主成果是案卷编目终稿 | 负触发 `建立合同争议证据案卷` |
| 主成果是举证期限计划 | 负触发 `规划举证期限与证据交换` |
| 主成果是可签和解或调解方案终稿 | 负触发 `谈判合同和解方案` 或 `评估合同调解方案与效力` |
| 主成果是上诉状 | 负触发 `提起合同案件上诉` |
| 主成果是鉴定申请或鉴异终稿 | 负触发对应鉴定窗；庭上问鉴定人留本窗 |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程／金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不代开庭」「不给胜诉率」 | 交付禁令，不是负触发 |

出现「庭审」「开庭」「质证」一词不是转出。

开庭闸打开须同时满足：单方无冲突立场已闭合；主成果是争点／质证／询问／代理提纲，不是起诉包、不是案卷终稿、不是发送版代理词；至少一项可编号案号、传票、开庭通知、组庭或争点碎片。口头「明天开庭一定赢」不算单独开闸材料。

开庭闸部分打开：已有碎片，但举证期、出庭或争点未闭合；仍交十节。

开庭闸关闭（仍正触发）：无一可编号碎片。尚未立案或尚未组庭只要庭审提纲：闸可关，**仍交十节**，第 6 节不出 `KT#` 终稿，第 7 节转介起诉或仲裁接口。禁止改走负触发踢走。

「提纲即已开庭」「口头已质证即已质证」「网交即已提交」「逾期即当然可提交」「缺席即当然胜诉」「未知写零」**不关窗**。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 开庭闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造证据或笔录、诱导作伪证、指导隐匿已知不利材料或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个争点切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `KT#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 切片 | 成立／履行／质量／解除／金钱分列 | 合成「全案必赢」 |
| 程序 | 诉讼一审／二审／仲裁分列 | 仲裁套法院三日 |
| 本证反证 | 支持与不利分列 | 藏匿已知对账单 |
| 出庭 | 传票、三日或规则期限、缺席接口 | 缺席升格当然胜 |
| 鉴定 | 到庭效果只开接口 | 不到庭写成全案必败 |

检索锚点（写入 `L#` 前须核验）：见技能正文 MCP 节。噪声：1991 年第一百三十九条、第一百四十七条；2017 年开庭与缺席旧条。

## 节点 3　开庭行 `KT#`

按已出现争点切片扫描，不是默认闭集。每条须能指向争点、本证反证或质证三性之一。不利证据必须入列。

无 `E#` 不得写已开庭或已质证。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止写入已开庭笔录。举证期或出庭未闭合不得标待提交。

热冲突强制处理：

- 提纲即已开庭／口头即已质证／网交即已提交／逾期即当然可提交／缺席即当然胜诉／未知写零 → 该格不支持或字段停止；仍出其他 `KT#`。
- 建议否认已知真实的不利证据 → 该格不支持；若升级为隐匿或诱导作伪证 → 整体停止。
- 无一碎片 → 关闸，不出 `KT#` 终稿，窗口不关。
- 指导伪造、诱导作伪证、隐匿已知材料 → 整体停止，不是该格不支持。

## 节点 4　起诉、答辩、案卷、举证、和解、上诉与鉴定接口

第 7 节只开接口，不得夹带 `KT#` 终稿或已开庭笔录绕闸。闸关闭时第 7 节可写「闸未开，转介待事项编号」，不得补写已开庭。不选定法院。不代开庭。不写发送版代理词。

下一步只转介：`提起合同纠纷一审`、`应对合同纠纷一审`、`规划举证期限与证据交换`、`建立合同争议证据案卷`、`提起合同仲裁`、`应对合同仲裁`、`提起合同案件上诉`、`应对合同案件二审`、`提出合同鉴定异议或重新鉴定`、`准备质量或损失鉴定申请`、`申请律师调查令或法院调查取证`、`谈判合同和解方案`、`评估合同调解方案与效力`、`评估合同管辖与仲裁协议`、`评估合同争议`、`准备合同反诉或仲裁反请求`、`保全质量现场与电子证据`、`测算违约金与损害赔偿`。禁止此致某院。

若 if 用户催促「提纲写完就算开完／微信质证完了／对方不到一定赢／对账单庭上说没这回事／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止；隐匿或诱导作伪证第一次整体停止。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 再执行清单

每个节点结束后回写：来源、判断、最强反方、是否字段停止。不得跳过开庭闸直接给已开庭或保证结果。

若 if 举证期、出庭、缺席效果、鉴定到庭、施行日未核验，then 该强制项字段停止，窗口不关。

## 本任务回链纪律

本任务成果是「开庭闸与开庭行草案」。本窗不代开庭。不包含：已开庭、已质证、已胜诉终稿、发送版代理词、起诉状。禁止选边治愈。禁止提纲即已开庭。禁止指导伪证。开庭闸打开 ≠ 已开庭 ≠ 已质证 ≠ 已胜诉。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标提纲终稿已形成。
风险档 A：伪造证据、诱导作伪证、隐匿已知材料必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：有案号和开庭通知，货款与质量争点。用户主张提纲写完就算开完、微信质证完了、逾期当然能用、一定赢、不清楚先写零。开庭闸打开或半开。`Q-纲`、`Q-证`、`Q-新`、`Q-胜`、`Q-零` 不打开为可靠路径。第 6 节不得把已开庭、已质证、0 写入可执行 `KT#`；对应格 `现有依据不支持` 或字段停止；仍出争点分列、本证反证、三性缺口。不代开庭。

场景②：用户同时交出己方「对账单藏起来、庭上说没签过、证人按我写的答」与对方「对账单已发过」。命中双方秘密＋隐匿＋诱导作伪证。第一次整体停止。只交第 1、10 节。不出 `KT#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代伪证方案。
