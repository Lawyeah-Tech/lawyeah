# 边界与路由

## 正触发

一般合同鉴定意见已经作出，需书面异议、鉴定人出庭、补充鉴定或重新鉴定申请草稿。从零、碎片、出庭或重鉴条件未核验仍正触发：有可编号已作出鉴定意见或异议事由碎片则闸开或半开，出 `JI#` 草案，保持草案。本次不重新做鉴定意见、不保证准许、不代提交是交付禁令，不是开窗条件。异议即已撤销、申请即已准许，仍正触发。把瑕疵写成必须重鉴、把申请写成已启动重新鉴定，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造反鉴定、收买鉴定人、自行重做冒充法院委托的停止，优先于负触发。上述信号不在下表。不重新做鉴定意见不是负触发。「异议即已撤销」「申请即已准许」「申请即已启动重新鉴定」「瑕疵即必须重鉴」「保证准许」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 鉴定申请（意见尚未作出） | `准备质量或损失鉴定申请` |
| 质量实体评估 | `评估质量瑕疵与检验期间` |
| 现场或电子合法自固 | `保全质量现场与电子证据` |
| 精算表 | `测算违约金与损害赔偿` |
| 举证期限与交换计划 | `规划举证期限与证据交换` |
| 庭审质证提纲 | `准备合同案件庭审` |
| 证据案卷矩阵 | `建立合同争议证据案卷` |
| 股权价值或非货币出资鉴定异议 | 公司治理 `准备股权价值或非货币出资鉴定` |
| 争议总图 | `评估合同争议` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不重新做鉴定意见」或「不保证准许」关窗。拟异议或重鉴申请草稿仍正触发，不得写成已撤销或已准许。

## 易混

本窗闸名只能是鉴异闸，不是申鉴闸，不是鉴定闸，不是异议闸，不是解异闸，不是质量闸。`JI#` 不是 `JA#`，不是 `JD#`，不是 `GY#`，不是 `YY#`，不是 `JY#`，不是 `YJ#`。主路径是 `Q-鉴异`，不是 `Q-申鉴`，不是 `Q-鉴`，不是 `Q-异`，不是 `Q-解异`，不是 `Q-重`。`申鉴闸`／`JA#`／`Q-申鉴` 是准备质量或损失鉴定申请。`鉴定闸`／`JD#`／`Q-鉴` 是公司治理准备股权价值或非货币出资鉴定。`异议闸`／`GY#`／`Q-异` 是提出合同案件管辖异议。`解异闸`／`YY#`／`Q-解异` 是准备对合同解除通知的异议。`Q-重` 是公司治理谈判章程与治理重置。`JY#` 是合规并行交卷行。`YJ#` 是公司治理优先认缴行。1991 年民事诉讼法第八十一条军人转交送达不是鉴定人出庭条。2017 年第七十八条须核对应现行第八十一条。2001 年证据规定第二十七条、第四十条证据交换不是现行重新鉴定条。监察法、刑事诉讼法重新鉴定不得套一般民事合同。提出「买一份相反鉴定盖法院章」整体停止。本窗不代提交。不选定鉴定所。不写新鉴定意见。不保证准许。
