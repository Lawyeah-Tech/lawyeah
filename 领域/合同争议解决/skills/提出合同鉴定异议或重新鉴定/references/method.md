# 提出合同鉴定异议或重新鉴定方法

本文件是可执行判断节点。异议草稿不是已撤销鉴定意见。重新鉴定申请不是已启动新鉴定。有缺陷可补正不是必须重新鉴定。拒不出庭不得作为认定根据。未知不写零。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已撤销、已准许、选定鉴定所、代提交、未知写零。本任务不定罪，不写新鉴定意见，不指导伪造反鉴定。本窗闸名只能是鉴异闸，禁止复用申鉴闸、鉴定闸、异议闸、解异闸、质量闸。预留不得占用：立案闸、和解闸、鉴定闸、申鉴闸。本窗 `JI#` 是鉴异行。主路径只用 `Q-鉴异`，禁止用 `Q-申鉴`、`Q-鉴`、`Q-异`、`Q-解异`、`Q-疵`、`Q-重`、`Q-签` 作主路径。本窗 `Q-签` 只作「草稿即已提交或已提出」不关窗码。本窗 `Q-见` 只作「异议即已撤销意见」不关窗码。本窗 `Q-重鉴` 只作「申请即已启动重新鉴定」不关窗码。英文 id 禁止使用，一律用中文技能名 `提出合同鉴定异议或重新鉴定`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991 年民事诉讼法第八十一条军人转交送达、2001 年证据规定第四十条证据交换、监察法或刑事诉讼法重新鉴定、把异议写成已撤销时记为噪声。禁止指导伪造反鉴定或收买鉴定人。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现意见切片扫描，不是默认闭集。
`JI#` 固定列：`编号｜意见切片｜异议事由｜出庭或补正｜重新鉴定条件｜申请接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已撤销」或「已重新鉴定」。无 `E#` 不得写已提出或已准许。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-鉴异`。禁止 `JA#`、`JD#`、`GY#`、`YY#`、`JY#`、`YJ#`、`A#`、`N#`。文件状态只用 `草案`、`停止`。

口头「这份鉴定废了」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：书面异议后先解释、说明或补充。仍有异议才预交出庭费用并通知出庭。不预交视为放弃异议。拒不出庭不得作为认定根据，当事人可申请退费或重新鉴定，仍不保证已准许。重新鉴定四项应当准许；瑕疵可补正、补充鉴定或补充质证的，不予准许重新鉴定。重新鉴定后原意见不得作为认定根据，不是本窗已经重鉴。

## 节点 0　分流、立场、鉴异闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造反鉴定、收买鉴定人、调包、倒签异议日、隐匿不利意见、未授权破坏性取样、违法取证、自行重做冒充法院委托不进负表。利益冲突未解不进整体停止。不重新做鉴定意见、不保证准许、不代提交不是负触发。

整案转出只交付第 1、2、10 节，不出 `JI#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是鉴定申请（意见尚未作出） | 负触发 `准备质量或损失鉴定申请` |
| 主成果是质量实体评估 | 负触发 `评估质量瑕疵与检验期间` |
| 主成果是现场或电子合法自固 | 负触发 `保全质量现场与电子证据` |
| 主成果是精算表 | 负触发 `测算违约金与损害赔偿` |
| 主成果是举证期限与交换计划 | 负触发 `规划举证期限与证据交换` |
| 主成果是庭审质证提纲 | 负触发 `准备合同案件庭审` |
| 主成果是证据案卷矩阵 | 负触发 `建立合同争议证据案卷` |
| 主成果是股权价值或非货币出资鉴定异议 | 负触发公司治理 `准备股权价值或非货币出资鉴定` |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程造价／竣工验收／施工质量主轴 | 整案转建设工程领域 |
| 金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不重新做鉴定意见」「不保证准许」「不代提交」 | 交付禁令，不是负触发 |

出现「鉴定」「异议」一词不是转出。

鉴异闸打开（可出 `JI#` 草案，仍不得标「已提出／已准许／已撤销」）须同时满足：单方无冲突立场已闭合；主成果是异议或重新鉴定申请草稿，不是质量实体终稿、不是新鉴定意见、不是申鉴申请终稿；至少一项可编号已作出鉴定意见或异议事由碎片。口头「这份鉴定废了」不算单独开闸材料。尚未作出不得开本窗闸。

鉴异闸部分打开：已有碎片，但出庭、补正可能或重鉴四项未闭合；对应格待核；仍交十节。无书面授权但单方立场已闭合且已有碎片：鉴异闸部分打开，仍交十节，不是整体停止。

鉴异闸关闭（仍正触发）：无一可编号碎片。「今天必须出已撤销意见终稿」而无最小碎片不得开闸。不出 `JI#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `JI#` 终稿，**第 7 节不得出已撤销、已准许或新鉴定意见**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「异议即已撤销」「申请即已准许」「申请即已启动重新鉴定」「瑕疵即必须重鉴」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `JI#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 鉴异闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造反鉴定、收买鉴定人、调包检材、倒签异议日、隐匿不利意见、未授权破坏性取样、违法取证，或自行重做一份鉴定意见冒充法院委托，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 3　鉴异行 `JI#`

按已出现意见切片扫描，不是默认闭集。每条须能指向已作出意见、异议事由或重鉴条件之一。

无 `E#` 不得写已提出或已准许。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止写入已撤销或已重新鉴定。事由或意见未闭合不得标待提交。

热冲突强制处理：

- 异议即已撤销／申请即已准许／申请即已启动重新鉴定／瑕疵即必须重鉴／未知写零 → 该格不支持或字段停止；仍出其他 `JI#`。
- 无一碎片 → 关闸，不出 `JI#` 终稿，窗口不关。
- 指导伪造反鉴定、收买鉴定人、自行重做冒充法院委托 → 整体停止，不是该格不支持。

## 节点 4　申鉴、质量、庭审与举证接口

第 7 节只开接口，不得夹带 `JI#` 终稿或新鉴定意见绕闸。闸关闭时第 7 节可写「闸未开，转介待事项编号」，不得补写已撤销。不选定鉴定所。不代提交。不写新鉴定意见。

下一步只转介：`准备质量或损失鉴定申请`、`评估质量瑕疵与检验期间`、`规划举证期限与证据交换`、`准备合同案件庭审`、`保全质量现场与电子证据`、`建立合同争议证据案卷`、`测算违约金与损害赔偿`、`申请律师调查令或法院调查取证`、`准备合同案件公证保全`、`提起合同纠纷一审`、`应对合同纠纷一审`、`评估电子合同成立与送达`、`建立双向履行时间线`、`评估合同争议`、`评估迟延拒绝与不完全履行`、`准备索赔或违约金主张通知`、`评估继续履行是否可能`。禁止此致某鉴定所。

若 if 用户催促「这份鉴定废了／申请了就一定重做／不清楚先写零／今晚重做一份冒充法院的」，then 该格 `现有依据不支持` 或字段停止；冒充法院委托第一次整体停止。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「鉴异闸与鉴异行草案」。本窗不代提交。不包含：已撤销、已准许、已重新鉴定终稿、新鉴定意见。禁止选边治愈。禁止异议即已撤销。禁止指导伪造反鉴定。鉴异闸打开 ≠ 已提出 ≠ 已准许 ≠ 已撤销。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标申请终稿已形成。
风险档 A：伪造反鉴定、收买鉴定人、自行重做冒充法院委托必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：设备质量鉴定意见已作出，买方主张这份鉴定废了、申请了就一定重做、计算差两块也必须重鉴、不预交出庭费也算出庭、不清楚先写零。鉴异闸打开或半开。`Q-见`、`Q-准`、`Q-重鉴`、`Q-零` 不打开为可靠路径。第 6 节不得把已撤销、已准许、已重鉴、0 写入可执行 `JI#`；对应格 `现有依据不支持` 或字段停止；仍出意见分列、书面异议、补正与重鉴四项分列。不代提交。

场景②：用户同时交出己方「必须把鉴定作废」与对方「从未收到副本」口径，并要「买一份相反鉴定盖法院章、把不合格件换成送检件」。命中双方秘密＋伪造反鉴定＋冒充法院委托＋调包。第一次整体停止。只交第 1、10 节。不出 `JI#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代伪造方案。
