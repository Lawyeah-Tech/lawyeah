# 评估合同反诉或反请求方法

本文件是可执行判断节点。评估不是已提起。草稿不是已受理。无牵连不是可反诉。答辩期满不是当然失权。二审反诉不是当然一并。反诉不是放弃仲裁。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已提起、已受理、选定法院、代提交、未知写零。本任务不定罪，不写反诉状终稿，不把评估写成已提起。本窗闸名只能是反诉闸，禁止复用评估闸、反请求闸、答辩闸、应裁闸、起诉闸、抵留闸。预留不得占用：立案闸、保全闸。本窗 `FQ#` 是反请行。主路径只用 `Q-反`，禁止用 `Q-反请`、`Q-辩`、`Q-应裁`、`Q-诉`、`Q-签` 作主路径。本窗 `Q-签` 只作「评估即已反诉、已受理反请求或已提交」不关窗码。本窗 `Q-反请` 只转介准备窗。英文 id 禁止使用，一律用中文技能名 `评估合同反诉或反请求`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991 年第一百四十三条口头起诉简易程序、2017 年第一百四十三条原告不到按撤诉、2015 年解释第三百二十八条未核 2022 年第三百二十六条、1994 年第三十八条除名、把评估写成已提起时记为噪声。禁止指导伪造牵连或隐匿证据。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现本诉或拟反请求切片扫描，不是默认闭集。
`FQ#` 固定列：`编号｜本诉或仲裁请求切片｜牵连或另诉｜论坛与应诉风险｜期间与规则期限｜利弊与请求草案接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已提起」或「已受理」。无 `E#` 不得写已提起。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-反`。禁止 `FS#`、`DB#`、`YC#`、`QT#`、`DX#`、`A#`、`N#`。一审合并窗口嵌期间列：法庭辩论结束前，不是答辩期。仲裁反请求期嵌该机构规则。二审嵌解释第三百二十六条。

口头「要反诉」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：质量减价、未付款抗辩优先标抗辩；独立修复费、违约金、确认未解除才是反诉候选。抵销抗辩不必反诉。无关另一合同应另诉或另案仲裁。

## 节点 0　分流、立场、反诉闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造牵连、倒签、把无关债塞进反诉且拒限缩、隐匿证据、违法取证不进负表。利益冲突未解不进整体停止。不出反诉状终稿、不代提交不是负触发。

整案转出只交付第 1、2、10 节，不出 `FQ#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是反诉状或反请求文书终稿 | 负触发 `准备合同反诉或仲裁反请求` |
| 主成果是一审答辩 | 负触发 `应对合同纠纷一审` |
| 主成果是应裁实体 | 负触发 `应对合同仲裁` |
| 主成果是二审答辩 | 负触发 `应对合同案件二审` |
| 主成果是无关另诉 | 负触发 `提起合同纠纷一审` 或 `提起合同仲裁` |
| 主成果是管辖或仲裁效力评估终稿 | 负触发 `评估合同管辖与仲裁协议` |
| 主成果是抵销抗辩不必反诉 | 负触发 `评估抵销留置与扣款抗辩` |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程／金融借贷担保／房地产物业／海事／劳动反申请主轴 | 整案转对应领域 |
| 「不出反诉状终稿」「不代提交」「不保证准许」 | 交付禁令，不是负触发 |

出现「反诉」「反请求」一词不是转出。同时要评估和状稿接口：本窗正触发。只要状稿终稿才负触发。

反诉闸打开（可出 `FQ#` 草案，仍不得标「已提起／已受理／已合并」）须同时满足：单方无冲突被告或被申请立场已闭合；主成果是条件评估，不是状稿终稿、不是一审答辩、不是应裁；至少一项可编号本诉起诉状、应诉通知、仲裁申请书副本、案号或拟反请求切片。口头「要反诉」不算单独开闸材料。

反诉闸部分打开：已有碎片，但牵连、覆盖或期间未闭合；对应格待核；仍交十节。无书面授权但单方立场已闭合且已有碎片：反诉闸部分打开，仍交十节，不是整体停止。

反诉闸关闭（仍正触发）：无一可编号碎片。「今天必须出已提起终稿」而无最小碎片不得开闸。不出 `FQ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `FQ#` 终稿，**第 7 节不得出可提交反诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「评估即已提起」「草稿即已受理」「无关债当然牵连」「答辩期满即失权」「二审当然一并」「反诉即放弃仲裁」「民诉十五日即反请求截止」「抵销必须反诉」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `FQ#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 反诉闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造牵连、倒签反诉日、把无关债塞进反诉且拒限缩、隐匿证据或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个拟反诉或反请求切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `FQ#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 主体 | 本诉被告对向本诉原告；被申请人对申请人 | 第三人、担保人当然列为反诉被告 |
| 本诉 | 给付／确认／解除分列 | 合成「对方全错」 |
| 拟反 | 减价抗辩与独立给付分列 | 抗辩升格必须反诉 |
| 牵连 | 同法律关系／因果／同事实／不足 | 无关另一合同当然牵连 |
| 论坛 | 法院／仲裁、专属、协议覆盖 | 反诉即放弃仲裁 |
| 期间 | 辩论结束前／该机构规则／二审 326 | 答辩期当一审失权；民诉十五日充反请求截止 |

检索锚点（写入 `L#` 前须核验）：见技能正文 MCP 节。噪声：1991 年或 2017 年第一百四十三条；2015 年第三百二十八条；1994 年第三十八条。

## 节点 3　反请行 `FQ#`

按已出现拟反请求切片扫描，不是默认闭集。每条须能指向本诉、牵连、论坛或期间之一。

无 `E#` 不得写已提起或牵连已证成。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止写入已受理或当然合并。

热冲突强制处理：

- 评估即已提起／无关债当然牵连／答辩期满即失权／二审当然一并／反诉即放弃仲裁／未知写零 → 该格不支持或字段停止；仍出其他 `FQ#`。
- 无一碎片 → 关闸，不出 `FQ#` 终稿，窗口不关。
- 指导伪造牵连、塞无关债拒限缩、隐匿 → 整体停止，不是该格不支持。

## 节点 4　答辩、应裁、准备、另诉与抵销接口

第 7 节只开接口，不得夹带 `FQ#` 终稿或可提交反诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待本诉碎片编号」，不得补写已提起。不选定法院。不代提交。不写发送版。

下一步只转介：`准备合同反诉或仲裁反请求`、`应对合同纠纷一审`、`应对合同仲裁`、`应对合同案件二审`、`提起合同纠纷一审`、`提起合同仲裁`、`提出合同案件管辖异议`、`评估合同管辖与仲裁协议`、`准备合同仲裁协议异议材料`、`评估抵销留置与扣款抗辩`、`测算违约金与损害赔偿`、`建立合同争议证据案卷`、`规划举证期限与证据交换`、`准备合同案件庭审`、`评估合同争议`、`谈判合同和解方案`、`评估合同调解方案与效力`。禁止此致某院。评估不得写成已提起。二审不得写成当然一并。

若 if 用户催促「评估完就算提起了／过了答辩期就不能反／二审必须一并判／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「反诉闸与反请行草案」。本窗不出反诉状终稿。不包含：已提起、已受理、已合并、发送版反诉状。禁止选边治愈。禁止评估即已提起。禁止指导塞无关债。反诉闸打开 ≠ 已提起 ≠ 牵连已闭合 ≠ 应诉管辖已成立。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标评估终稿已形成。
风险档 A：伪造牵连、倒签、塞无关债必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：买卖尾款本诉，被告主张质量违约金反诉，另夹一笔无关借款。用户主张评估完就算提起了、过了答辩期就不能反、二审必须一并、民诉十五天就是反请求截止、不清楚金额先写零。反诉闸打开或半开。`Q-签`、`Q-失`、`Q-二`、`Q-连`、`Q-零` 不打开为可靠路径。第 6 节不得把已提起、当然失权、当然一并、无关借款牵连、0 写入可执行 `FQ#`；对应格 `现有依据不支持` 或字段停止；仍出质量给付切片、牵连待核、辩论结束前窗口、无关借款另诉接口。不关窗。不代提交。不出反诉状终稿。

场景②：用户同时交出己方「必须把那笔无关债写进去拖时间、反诉日改到上周」与原告「从未违约」口径。命中双方秘密＋倒签＋塞无关债拒限缩。第一次整体停止。只交第 1、10 节。不出 `FQ#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代违法方案。
