# 边界与路由

## 正触发

一般合同被告或被申请人拟反诉或提出仲裁反请求，需要牵连、论坛、期间与利弊评估。从零、碎片、牵连未核验仍正触发：有可编号本诉起诉状、应诉通知、仲裁申请书副本、案号或拟反请求切片则闸开或半开，出 `FQ#` 草案，保持草案。本次不出反诉状终稿、不代提交是交付禁令，不是开窗条件。评估即已提起、无关债当然牵连，仍正触发。把答辩期满写成当然失权、把二审写成当然一并，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造牵连、塞无关债拒限缩的停止，优先于负触发。上述信号不在下表。不出反诉状终稿不是负触发。「评估即已提起」「草稿即已受理」「无关债当然牵连」「答辩期满即失权」「二审当然一并」「反诉即放弃仲裁」「保证准许」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 反诉状或反请求文书终稿 | `准备合同反诉或仲裁反请求` |
| 一审答辩 | `应对合同纠纷一审` |
| 应裁实体 | `应对合同仲裁` |
| 二审答辩 | `应对合同案件二审` |
| 无关另诉 | `提起合同纠纷一审` 或 `提起合同仲裁` |
| 管辖或仲裁效力评估终稿 | `评估合同管辖与仲裁协议` |
| 抵销抗辩不必反诉 | `评估抵销留置与扣款抗辩` |
| 争议总图 | `评估合同争议` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不出反诉状终稿」或「不代提交」关窗。拟条件评估仍正触发，不得写成已提起或已受理。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤、劳动反申请 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流。出现「反诉」「反请求」一词不是转出。C 端只要大众填空页时只分流，不把本包降成填空式结论，不回改。

## 易混

本窗闸名只能是反诉闸，不是评估闸，不是反请求闸，不是答辩闸，不是应裁闸，不是起诉闸，不是抵留闸。`FQ#` 不是 `FS#`，不是 `DB#`，不是 `YC#`，不是 `QT#`，不是 `DX#`。主路径是 `Q-反`，不是 `Q-反请`，不是 `Q-辩`，不是 `Q-应裁`，不是 `Q-诉`。`FS#` 是公司治理分配诉行。`答辩闸`／`DB#`／`Q-辩` 是应对合同纠纷一审。`应裁闸`／`YC#`／`Q-应裁` 是应对合同仲裁。准备窗后续自锁 `Q-反请`，本窗不打开为主路径。1991 年或 2017 年第一百四十三条不是现行合并条。2015 年解释第三百二十八条须核 2022 年第三百二十六条。2022 年第三百二十七条不是二审反诉。1994 年第三十八条不是反请求。提出「把无关债写进去拖时间、反诉日改到上周」整体停止。本窗不出反诉状终稿。不代提交。不选定法院。不保证准许。
