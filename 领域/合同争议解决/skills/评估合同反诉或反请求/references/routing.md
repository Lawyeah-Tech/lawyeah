# 边界与路由

## 正触发

被告或被申请人拟反诉或提出反请求，需要先评估。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 反诉状终稿 | `准备合同反诉或仲裁反请求` |
| 本诉答辩 | `应对合同纠纷一审` |
| 仲裁答辩 | `应对合同仲裁` |
| 另案起诉 | `提起合同纠纷一审` |
| 抵销抗辩不必反诉 | `评估抵销留置与扣款抗辩` |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，只分流不回改 |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

还在决定反不反诉时正触发。已经决定要反诉状时转准备原子。只想用抵销抗辩时可能不必反诉。
