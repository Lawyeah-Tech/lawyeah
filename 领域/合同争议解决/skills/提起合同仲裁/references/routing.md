# 边界与路由

## 正触发

一般合同已成争，拟递交商事仲裁申请包草稿。从零、碎片、协议或机构未核验仍正触发：有可编号请求、书面条款或机构碎片则闸开或半开，出 `ZC#` 草案，保持草案。本次不保证受理、不代提交是交付禁令，不是开窗条件。草稿即已受理、口头即书面，仍正触发。把或裁或诉写成当然有效、把机构不明写成已可申请、把有效仲裁写成应起诉，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造协议、虚假仲裁的停止，优先于负触发。上述信号不在下表。不保证受理不是负触发。「草稿即已受理」「口头即书面」「或裁或诉当然有效」「机构不明仍可申请」「有效仲裁应起诉」「保证受理」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 管辖或仲裁条款专项 | `评估合同管辖与仲裁协议` |
| 起诉包 | `提起合同纠纷一审` |
| 程序比较 | `选择诉讼仲裁或督促程序` |
| 仲异或效力确认材料 | `准备合同仲裁协议异议材料` |
| 应裁实体 | `应对合同仲裁` |
| 保全申请终稿 | `准备合同财产保全申请` |
| 庭审提纲 | `准备合同案件庭审` |
| 反请求终稿 | `准备合同反诉或仲裁反请求` |
| 支付令申请 | `申请合同金钱支付令` |
| 争议总图 | `评估合同争议` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不保证受理」或「不代提交」关窗。拟申请草稿仍正触发，不得写成已受理或已提交。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流。出现「仲裁」「申请」一词不是转出。C 端只要大众填空页时只分流，不把本包降成填空式结论，不回改。

## 易混

本窗闸名只能是仲裁闸，不是仲异闸，不是论坛闸，不是起诉闸，不是择径闸，不是立案闸。`ZC#` 不是 `ZX#`，不是 `QT#`，不是 `LT#`，不是 `XH#`，不是 `ZS#`。主路径是 `Q-申`，不是 `Q-仲`，不是 `Q-裁`，不是 `Q-仲异`，不是 `Q-诉`，不是 `Q-坛`。`仲异闸`／`ZX#`／`Q-仲异` 是准备合同仲裁协议异议材料。`论坛闸`／`LT#`／`Q-坛` 是评估合同管辖与仲裁协议。`起诉闸`／`QT#`／`Q-诉` 是提起合同纠纷一审。`择径闸`／`XH#`／`Q-督` 是选择诉讼仲裁或督促程序。`ZS#` 是公司治理忠实行。1994 年仲裁法第四条、第五条须核 2025 修订。1994 年或 2017 年第十六条至第十九条不是 2025 年书面三要素与独立性。1994 年第三十七条重新选定仲裁员不是起诉未声明协议。MCP 标尚未施行时以施行日 2026-03-01 为准。劳动人事争议仲裁申请书不是本窗。提出「把或裁或诉那句抽掉、落款改到上周」整体停止。本窗不代提交。不选定法院。不写发送版。不保证受理。
