# 提起合同仲裁方法

本文件是可执行判断节点。草稿不是已受理。口头约定不是书面仲裁协议。或裁或诉不是当然有效。机构不明不是已可申请。有效仲裁不是应起诉。合同无效不是仲裁协议消灭。构成违约不是当然解除。未知不写零。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已受理、已提交、已组庭、选定法院、代提交、未知写零。本任务不定罪，不写发送版申请，不指导伪造协议。本窗闸名只能是仲裁闸，禁止复用仲异闸、论坛闸、起诉闸、择径闸。预留不得占用：立案闸、保全闸、应裁闸。本窗 `ZC#` 是申请行。主路径只用 `Q-申`，禁止用 `Q-仲`、`Q-裁`、`Q-仲异`、`Q-诉`、`Q-坛`、`Q-督`、`Q-签` 作主路径。本窗 `Q-签` 只作「草稿即已提交或已受理」不关窗码。本窗 `Q-仲` 只作「有效仲裁仍应直接起诉」或「无协议仍要可提交终稿」不关窗码。英文 id 禁止使用，一律用中文技能名 `提起合同仲裁`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1994 年仲裁法第四条或第五条未核 2025、把 1994 年或 2017 年第十六条至第十九条当成现行书面三要素、把 1994 年第三十七条重新选定仲裁员当成起诉未声明规则、MCP 标 2025 修订尚未施行时记为噪声。禁止指导伪造协议或隐匿条款。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现请求切片扫描，不是默认闭集。
`ZC#` 固定列：`编号｜请求切片｜申请人适格与被申请人明确｜书面协议与机构可确定｜规则组庭与保全转交｜证据目录与保全红旗｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已受理」或「已组庭」。无 `E#` 不得写已提交或已受理。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-申`。禁止 `ZX#`、`QT#`、`LT#`、`XH#`、`ZS#`、`P#`、`A#`、`N#`。文件状态只用 `草案`、`停止`。

口头「已经受理了」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：书面三要素闭合且机构可确定才可能交申请包。或裁或诉、两机构待选、仅约定规则待核，不得写成已可申请。默示协议发生在程序中，不能当申请当日已有书面协议。合同无效不消灭已达成的仲裁协议。组庭、受理、保全裁定只开接口。

## 节点 0　分流、立场、仲裁闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造协议、倒签、隐匿不利条款、虚假仲裁、违法取证不进负表。利益冲突未解不进整体停止。不保证受理、不代提交不是负触发。

整案转出只交付第 1、2、10 节，不出 `ZC#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是管辖或仲裁条款专项 | 负触发 `评估合同管辖与仲裁协议` |
| 主成果是起诉包 | 负触发 `提起合同纠纷一审` |
| 主成果是程序比较 | 负触发 `选择诉讼仲裁或督促程序` |
| 主成果是仲异或效力确认材料 | 负触发 `准备合同仲裁协议异议材料` |
| 主成果是应裁实体 | 负触发 `应对合同仲裁` |
| 主成果是保全申请终稿 | 负触发 `准备合同财产保全申请` |
| 主成果是庭审提纲 | 负触发 `准备合同案件庭审` |
| 主成果是反请求终稿 | 负触发 `准备合同反诉或仲裁反请求` |
| 主成果是支付令申请 | 负触发 `申请合同金钱支付令` |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程／金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不保证受理」「不代提交」 | 交付禁令，不是负触发 |

出现「仲裁」「申请」一词不是转出。

仲裁闸打开（可出 `ZC#` 草案，仍不得标「已提交／已受理／已组庭」）须同时满足：单方无冲突立场已闭合；主成果是仲裁申请包草稿，不是起诉包、不是应裁、不是发送版；至少一项可编号请求、书面条款或机构碎片。口头「已经受理了」不算单独开闸材料。

仲裁闸部分打开：已有碎片，但三要素、机构或规则未闭合；对应格待核；仍交十节。无书面授权但单方立场已闭合且已有碎片：仲裁闸部分打开，仍交十节，不是整体停止。

仲裁闸关闭（仍正触发）：无一可编号碎片。「今天必须出已受理终稿」而无最小碎片不得开闸。不出 `ZC#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `ZC#` 终稿，**第 7 节不得出发送版申请书**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已受理」「口头即书面」「或裁或诉当然有效」「机构不明仍可申请」「有效仲裁应起诉」「合同无效即仲裁消灭」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `ZC#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 仲裁闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造协议或签署页、倒签、隐匿不利条款、虚假仲裁、指导隐匿证据或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个请求切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `ZC#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 切片 | 付款／违约金／继续履行／确认解除分列 | 合成「合同权益」；继续履行与确认解除两份主位终局 |
| 主体 | 申请人适格、被申请人明确 | 匿名被申请人仍交终稿 |
| 协议 | 书面三要素原文＋签署页 | 口头升格书面；默示当申请当日已有 |
| 机构 | 名称能否确定、或裁或诉另格 | 两机构待选仍打开已可申请 |
| 申请 | 递交协议＋申请书＋副本＋目录 | 此致某会升格已受理 |

检索锚点（写入 `L#` 前须核验）：见技能正文 MCP 节。噪声：1994 年第四条、第五条；1994 年或 2017 年第十六条至第十九条。

## 节点 3　申请行 `ZC#`

按已出现请求切片扫描，不是默认闭集。每条须能指向请求、协议覆盖或机构可确定之一。

无 `E#` 不得写已提交或已受理。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止写入已组庭或已保全。协议或机构未闭合不得标待提交。

热冲突强制处理：

- 草稿即已受理／口头即书面／或裁或诉当然有效／机构不明仍可申请／有效仲裁应起诉／合同无效即仲裁消灭／未知写零 → 该格不支持或字段停止；仍出其他 `ZC#`。
- 无一碎片 → 关闸，不出 `ZC#` 终稿，窗口不关。
- 指导伪造协议、隐匿条款、虚假仲裁 → 整体停止，不是该格不支持。

## 节点 4　论坛、起诉、应裁、保全与庭审接口

第 7 节只开接口，不得夹带 `ZC#` 终稿或发送版绕闸。闸关闭时第 7 节可写「闸未开，转介待事项编号」，不得补写已受理。不选定法院。不代提交。不写发送版。保全只开机构转交法院接口，本窗不出保全终稿，不占用保全闸。组庭只开规则接口，不得写已组庭。

下一步只转介：`评估合同管辖与仲裁协议`、`选择诉讼仲裁或督促程序`、`提起合同纠纷一审`、`应对合同仲裁`、`准备合同仲裁协议异议材料`、`评估解除权是否成立`、`准备催告履行或补救通知`、`准备解除通知`、`测算违约金与损害赔偿`、`建立合同争议证据案卷`、`谈判合同和解方案`、`准备合同财产保全申请`、`提起合同成立或效力确认之诉`、`准备合同案件庭审`、`规划举证期限与证据交换`、`准备合同反诉或仲裁反请求`、`评估合同争议`、`申请合同金钱支付令`。禁止此致某院。禁止此致某会升格已受理。

若 if 用户催促「提交了就算受理／口头约定就算协议／有仲裁也一起出起诉状／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止；伪造协议第一次整体停止。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 再执行清单

每个节点结束后回写：来源、判断、最强反方、是否字段停止。不得跳过仲裁闸直接给已受理或发送版终稿。

若 if 书面三要素、机构可确定、现行规则、五日、解除时点、施行日未核验，then 该强制项字段停止，窗口不关。
判断状态只许三值。口头「已经受理了」不得写成 `ZC#` 已受理。未知不写零。

## 本任务回链纪律

本任务成果是「仲裁闸与申请行草案」。本窗不代提交。不包含：已受理、已提交、已组庭终稿、发送版申请书、起诉状、保全申请。禁止选边治愈。禁止草稿即已受理。禁止指导伪造协议。仲裁闸打开 ≠ 已提交 ≠ 已受理 ≠ 已组庭。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标申请终稿已形成。
风险档 A：伪造协议、倒签、隐匿条款、虚假仲裁必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：买卖尾款，合同写可诉讼可仲裁、机构写某地仲裁委。用户主张口头说过去仲裁就算数、今晚网交就算受理、有仲裁也把起诉状一起交、此致某会、不清楚违约金先写零。仲裁闸打开或半开。`Q-口`、`Q-交`、`Q-签`、`Q-裁`、`Q-仲`、`Q-院`、`Q-零` 不打开为可靠路径。第 6 节不得把已受理、已提交、书面已闭合、0 写入可执行 `ZC#`；对应格 `现有依据不支持` 或字段停止；仍出请求分列、或裁或诉待核、机构名称待核。不代提交。

场景②：用户同时交出己方「从未签过仲裁」与对方「合同有仲裁页」口径，并要「把或裁或诉那句抽掉、落款改到上周」。命中双方秘密＋隐匿条款＋倒签。第一次整体停止。只交第 1、10 节。不出 `ZC#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代隐匿方案。
