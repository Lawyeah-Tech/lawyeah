# 评估同时履行先履行与不安抗辩方法

本文件是可执行判断节点。停给不是已违约。无确切证据中止不是合法不安。抗辩不是解除。相应不是全部停付。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、抗辩已成立终稿、已解除、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不把抗辩写成已解除。本窗闸名只能是履抗闸，禁止复用抗辩闸、顺序闸、履行闸、不安闸、答辩闸、形态闸、解除闸。预留不得占用：立案闸、催告闸、解除闸。本窗 `LK#` 是抗辩行。主路径只用 `Q-抗`，禁止用 `Q-辩`、`Q-履`、`Q-序`、`Q-态`、`Q-除`、`Q-签` 作主路径。本窗 `Q-签` 只作「评估即已抗辩成立、已解除或已提交」不关窗码。英文 id 禁止使用，一律用中文技能名 `评估同时履行先履行与不安抗辩`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效合同法第六十六条至第六十九条、把停给写成已违约或把抗辩写成已解除时记为噪声。禁止指导伪造不安证据或倒签中止通知。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现对待给付碎片扫描，不是默认闭集。
`LK#` 固定列：`编号｜对待给付与约定顺序切片｜同时或先履行相应性｜不安情形与确切证据｜通知担保与恢复｜解除／迟延／抵销接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「抗辩已成立」或「已解除」。无 `E#` 不得写抗辩已成立。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-抗`。禁止 `XT#`、`ZL#`、`SX#`、`QJ#`、`JC#`、`ZT#`、`DB#`、`A#`、`N#`。

口头「可以停了」「没有证据也能不安」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：同时、先履行、不安分列。相应不是全部。不安主体必须是应当先履行的一方。无确切证据中止可能构成违约。

## 节点 0　分流、立场、履抗闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造不安证据或中止通知、倒签中止日、隐匿担保或对账单、违法取证不进负表。利益冲突未解不进整体停止。不把抗辩写成解除、不发函不是负触发。

整案转出只交付第 1、2、10 节，不出 `LK#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是迟延形态终稿 | 负触发 `评估迟延拒绝与不完全履行` |
| 主成果是解除权实体终稿 | 负触发 `评估解除权是否成立` |
| 主成果是发送版解除通知 | 负触发 `准备解除通知` |
| 主成果是继续履行可行性终稿 | 负触发 `评估继续履行是否可能` |
| 主成果是抵销留置终稿 | 负触发 `评估抵销留置与扣款抗辩` |
| 主成果是完整时间线 | 负触发 `建立双向履行时间线` |
| 主成果是质量瑕疵终稿 | 负触发 `评估质量瑕疵与检验期间` |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程进度款／金融借贷停贷／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不把抗辩写成解除」「不发函」 | 交付禁令，不是负触发 |

出现「同时履行」「不安」「停给」一词不是转出。

履抗闸打开（可出 `LK#` 草案，仍不得标「抗辩已成立／已中止合法／已解除」）须同时满足：单方无冲突立场已闭合；主成果是履行抗辩评估，不是迟延终稿、不是解除终稿、不是停给方案终稿；至少一项可编号对待给付、约定先后、停给行为或中止通知碎片。口头「可以停了」不算单独开闸材料。

履抗闸部分打开：已有碎片，但顺序、相应性或确切证据未闭合；对应格待核；仍交十节。无书面评估授权但单方立场已闭合且已有碎片：履抗闸部分打开，仍交十节，不是整体停止。

履抗闸关闭（仍正触发）：无一可编号碎片。「今天必须出抗辩已成立／已解除终稿」而无最小碎片不得开闸。不出 `LK#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `LK#` 终稿，**第 7 节不得出停给函、解除函或诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「停给即已违约」「无确切证据中止即合法不安」「抗辩即已解除」「部分不符即全部停付」「传闻即确切证据」「已读即到达」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `LK#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 履抗闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造不安证据或中止通知、倒签中止日、隐匿担保或对账单或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 3　抗辩行 `LK#`

按已出现对待给付碎片扫描，不是默认闭集。每条须能指向顺序、相应性、确切证据或通知之一。

无 `E#` 不得写抗辩已成立。状态默认 `草案`。一次只推荐下一步。未知不写零。先履行抗辩成立不得写对方已迟延。

热冲突强制处理：

- 停给即已违约／无确切证据中止即合法不安／抗辩即已解除／部分不符即全部停付／传闻即确切证据／已读即到达／未知写零 → 该格不支持或字段停止；仍出其他 `LK#`。
- 无一碎片 → 关闸，不出 `LK#` 终稿，窗口不关。
- 指导伪造不安证据、倒签、隐匿担保或对账单 → 整体停止，不是该格不支持。

## 节点 4　形态、解除、时线、抵销接口

第 7 节只开接口，不得夹带 `LK#` 终稿或停给函绕闸。闸关闭时第 7 节可写「闸未开，转介对待给付编号」，不得补写抗辩已成立。不选定法院。不代提交。不发函。

下一步只转介：`评估迟延拒绝与不完全履行`、`评估解除权是否成立`、`准备解除通知`、`评估继续履行是否可能`、`评估抵销留置与扣款抗辩`、`建立双向履行时间线`、`评估质量瑕疵与检验期间`、`评估不可抗力情势变更与履行不能`、`评估价款结算与发票争议`、`建立合同争议证据案卷`、`测算违约金与损害赔偿`、`评估争议期间`、`设计合同案件通知送达`、`提起合同纠纷一审`、`评估合同争议`、`评估合同成立与效力`、`准备催告履行或补救通知`。禁止此致某院。抗辩不得写成已解除。先履行抗辩成立不得写成已迟延。

若 if 用户催促「可以停了／没有证据也能不安／抗辩了就算解除／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：买卖合同约定先货后款。卖方第三批规格轻微偏差，买方要停付全部价款，并凭一条行业传闻主张卖方要垮了可以不安中止，微信已读中止通知就算到达，保证函一出就算应当恢复，抗辩了就算已经解除。履抗闸打开或半开。`Q-全`、`Q-空`、`Q-闻`、`Q-读`、`Q-除`、`Q-签` 不打开为可靠路径。第 6 节不得把全部停付已成立、不安已合法、已到达、已解除写入可执行 `LK#`；对应格 `现有依据不支持` 或字段停止；仍出批次对应、相应性待核、确切证据缺口、通知到达缺口等其他 `LK#`。不关窗。不写函。不认定解除。

场景②：用户同时交出己方「中止通知日期改到上周、把对方正常往来写成抽逃」与对方「从未恶化」口径。命中双方秘密＋倒签＋伪造不安证据。第一次整体停止。只交第 1、10 节。不出 `LK#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代违法方案。
