# 履行顺序与抗辩评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然结果或唯一必得总额。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。实务检索若出现“违约金不超过合同标的百分之三十”，记为噪声。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

应诉答辩或提出反诉，不等于当然放弃仲裁协议。解除通知到达对方时解除；未通知而起诉或申请仲裁主张解除的，仅在该主张获确认后，自起诉状或仲裁申请书副本送达时解除，不得把立案日写成解除时点。第 585 条“过分高于”对照违约造成的损失，不对照合同总价。


## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填本任务实体结论。

| 信号 | 转出 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定、实际施工人 | 建设工程领域 |
| 金融借贷、保证、抵押质押、保理、融资租赁主轴 | 金融借贷担保领域 |
| 商品房买卖、开发合作、物业服务主轴 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、劳动报酬、解除劳动合同、工伤待遇 | 劳动领域 |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

混合信号：一般买卖或服务主轴可留本任务；专项只作为背景时在缺口标明，不把专项规则硬套进一般合同结论。


## 节点 1　对待给付

1. 画出双方主给付是否构成对待给付。单向赠与或已履行完毕的一侧，不能再主张同时履行。
2. 金钱与货物、服务分期：按期匹配，不得用后期款项抗辩已到期的对应批次。
3. 约定预付款、进度款、验收后尾款：按约定顺序，不按“行业惯例必须先货后款”改写。
4. 建设工程进度款、金融借款提款停贷：整案转出。

若：文本对顺序沉默且无法从交易类型确定 → 顺序字段 `依据不足`。

## 节点 2　同时履行与先履行

运行时核验第 525、526 条。

1. 同时履行：对方未履行或履行不符合约定时，可拒绝其相应履行请求。
2. “相应”意味着部分瑕疵只能拒绝对应部分，不能拒付全部，除非不可分或目的受影响。
3. 先履行抗辩：后履行方在先履行方未完成前有权拒绝。
4. 先履行方轻微不符是否足以拒绝：回链是否影响后履行方义务的对应性。
5. 不得把质量争议直接升级为全部停付而不作相应性说明。

## 节点 3　不安抗辩

运行时核验第 527、528 条。

1. 主体必须是应当先履行的一方。
2. 法定情形逐项核对，必须有确切证据。传闻、行业谣言、单条负面新闻通常不足。
3. 转移财产或抽逃资金须指向逃避债务，正常经营往来不当然符合。
4. 没有确切证据中止履行：现有依据不支持抗辩，可能构成违约。
5. 中止后的解除权是另一条路径，本任务只标接口，不发解除通知。

## 节点 4　通知

1. 中止履行应当及时通知。未通知不当然消灭抗辩，但增加违约风险，须写入最强反方。
2. 通知到达按约定渠道和数据电文规则，已读不等于到达。
3. 对方提供适当担保：适当性标待核，不把任何保证函写成已经足够。
4. 恢复履行的时点和范围写清楚，避免被指继续违约。

## 节点 5　禁止自动解除

1. 抗辩 ≠ 解除。用户要求把停给写成合同已解除：目标停止。
2. 合理期限未恢复且未提供担保：转 `评估解除权是否成立`。
3. 对方指控己方迟延：并行 `评估迟延拒绝与不完全履行`。
4. 金钱抗辩涉及抵销或留置：转抵销留置原子。

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。

下一步按期限灭失、易失证据、改变本任务结论、可逆性排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。

禁止指导伪造、隐匿、威胁或违法取证。未知金额不写零。不把应诉写成放弃仲裁。不把立案日写成解除时点。
