# 边界与路由

## 正触发

一般合同已成争，一方拟停给停付或被指责停给，需要评估同时履行、先履行或不安抗辩。从零、碎片、确切证据未核验、无书面评估授权仍正触发：有可编号对待给付、约定先后、停给行为或中止通知碎片则闸开或半开，出 `LK#` 草案，保持草案。本次不把抗辩写成解除、不发函是交付禁令，不是开窗条件。停给即已违约、无确切证据中止即合法不安，仍正触发。

双方秘密、伪造不安证据或中止通知、倒签中止日、隐匿担保或对账单、违法取证的停止，优先于负触发。上述信号不在下表。不把抗辩写成解除不是负触发。「停给即已违约」「无确切证据中止即合法不安」「抗辩即已解除」「部分不符即全部停付」「传闻即确切证据」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 迟延形态终稿 | `评估迟延拒绝与不完全履行` |
| 解除权实体终稿 | `评估解除权是否成立` |
| 发送版解除通知 | `准备解除通知` |
| 继续履行可行性终稿 | `评估继续履行是否可能` |
| 抵销留置终稿 | `评估抵销留置与扣款抗辩` |
| 完整时间线 | `建立双向履行时间线` |
| 质量瑕疵终稿 | `评估质量瑕疵与检验期间` |
| 争议总图 | `评估合同争议` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |
| 工程进度款／金融停贷／房产／海事／劳动主轴 | 对应领域 |

不得因「不把抗辩写成解除」或「不发函」关窗。拟抗辩评估仍正触发，不得写成抗辩已成立或已解除。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工进度款、分包、优先受偿 | 建设工程领域 |
| 停贷、保证、抵押质押、保理 | 金融借贷担保领域 |

一般买卖或服务夹带专项背景时，专项段只分流。出现「同时履行」「不安」「停给」一词不是转出。C 端只要大众停给填空页时只分流，不把本包降成填空式停给方案，不回改。

## 易混

本窗闸名只能是履抗闸，不是抗辩闸，不是顺序闸，不是答辩闸，不是形态闸，不是解除闸。`LK#` 不是 `XT#`，不是 `DB#`，不是 `JC#`，不是 `SX#`。主路径是 `Q-抗`，不是 `Q-辩`，不是 `Q-履`，不是 `Q-序`。`Q-辩` 是一审答辩窗。`Q-履` 留给继续履行窗。停给不是已违约。无确切证据中止不是合法不安。抗辩不是解除。相应不是全部停付。已失效合同法第六十六条至第六十九条不是现行。MCP 可能先返回第五百二十五条、第五百二十八条而漏第五百二十六条。「中止日期改到上周」「把正常往来写成抽逃」整体停止。本窗不执行发送，不代提交。不选定法院。不把抗辩写成解除。不发函。
