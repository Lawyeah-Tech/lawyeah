# 边界与路由

## 正触发

一方拟停给停付或被指责停给，需要评估同时履行、先履行或不安抗辩。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 要把抗辩写成解除 | `评估解除权是否成立` |
| 迟延或拒绝形态 | `评估迟延拒绝与不完全履行` |
| 抵销留置扣款 | `评估抵销留置与扣款抗辩` |
| 发催告 | `准备催告履行或补救通知` |
| 金融担保实现 | 金融借贷担保领域 |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，只分流不回改 |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

核心是能不能停、停了要不要通知时正触发。核心是对方已经构成解除事由时，转解除权。核心是质量本身时，转质量原子。
