# 评估迟延拒绝与不完全履行

## 任务目标

在明确、无利益冲突的单方立场下（主张请求或抗辩一方或其受托律师，互斥），形成违约形态评估草案：形态闸、主体与强制接口、`Q#` 路径、`XT#` 形态行（义务切片／形态分列（迟延／预期拒绝／拒绝受领／不完全）／催告必要与合理期限／目的能否实现／补救继续履行赔偿接口／`E#` 回链）。本窗 `XT#` 是形态行草案，不是已违约终稿，不是已催告届满，不是目的不能实现证明，不是已解除，不是催告函或解除函。本窗闸名只能是形态闸，禁止复用违约闸、履行闸、迟延闸、拒绝闸、质量闸、时线闸、期间闸、解除闸、催告闸、争议闸、发送闸。预留不得占用：立案闸、催告闸、解除闸。本窗主行只能是 `XT#`，禁止 `ZL#`、`SX#`、`QJ#`、`JC#`、`ZT#`、`CG#`、`HF#`、`SJ#`、`A#`。主路径只用 `Q-态`，禁止用 `Q-违`、`Q-迟`、`Q-履`、`Q-历`、`Q-疵`、`Q-期`、`Q-除`、`Q-总`、`Q-告`、`Q-形`、`Q-签` 作主路径。邻窗 `Q-态` 只作转介进本窗；本窗打开为主路径，不是已违约、不是已解除。本窗 `Q-签` 只作「评估即已违约、已解除或已提交」不关窗码。本窗 `Q-违` 只作「构成违约即当然解除」不关窗码。本窗 `Q-迟` 只作「迟延即当然解除」不关窗码。形态闸打开不等于已违约不等于已催告届满不等于目的不能实现不等于当然解除不等于待发函终稿。构成违约不是当然解除。迟延主要债务原则上须催告并给合理期限。须催告未催告不是已成立。合理期限不是一律十五日或三个月。已读不是到达。约定不明不是已逾期。「尽快」不是确定到期。先履行抗辩成立不是已迟延。从给付迟延不是当然解除。轻微迟延可补救不是目的不能实现。未知不写零。不写唯一截止日。不写发送版催告或解除函。不写诉状。不选定法院。不代提交。不定罪。伤残等级与本窗无关，禁止折入。

`depends-on` 为空。主成果是完整时间线转 `建立双向履行时间线`。主成果是质量瑕疵终稿转 `评估质量瑕疵与检验期间`。主成果是解除权实体终稿转 `评估解除权是否成立`。主成果是发送版催告转 `准备催告履行或补救通知`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：一般合同已成争，存在逾期、拒绝履行、拒绝受领或履行不符合约定，需要分列形态并判断催告是否必要、补救是否可能、目的能否实现。「对方违约了就能解除」「不催告也能解除」仍正触发，成果状态 `草案`。催告、到达、目的未核验仍正触发：有可编号义务、履行期或拒绝／不符碎片则形态闸打开或半开，第 6 节出 `XT#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出已违约／已解除终稿」才关闸，仍交十节，第 6 节不出 `XT#` 终稿，第 7 节不得出催告函、解除函或诉状，窗口不关。用户要把构成违约写成当然解除、把迟延写成当然解除、把须催告写成未催告已成立、把合理期限写成一律十五日、把已读写成到达、把未知写成零，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `XT#` 草案。不得因「不认定解除」「不发函」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是完整时间线（转 `建立双向履行时间线`）；
- 主成果是质量瑕疵终稿（转 `评估质量瑕疵与检验期间`）；
- 主成果是履行顺序或不安抗辩终稿（转 `评估同时履行先履行与不安抗辩`）；
- 主成果是解除权实体终稿（转 `评估解除权是否成立`）；
- 主成果是发送版催告（转 `准备催告履行或补救通知`）；
- 主成果是发送版解除通知（转 `准备解除通知`）；
- 主成果是继续履行可行性终稿（转 `评估继续履行是否可能`）；
- 主成果是精算工作表（转 `测算违约金与损害赔偿`）；
- 主成果是争议总图（转 `评估合同争议`）；
- 尚未成争，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）；
- 建设工程、金融借贷担保、房地产物业、海事、劳动专项履行主轴。

双方秘密、伪造履行记录、倒签催告或到达日、隐匿对账单、违法取证**不在负触发表**，走整体停止。「构成违约即当然解除」「迟延即当然解除」「须催告未催告即已成立」「合理期限一律十五日」「已读即到达」「未知写零」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不认定解除」「不发函」「不写唯一截止日」是交付禁令，不是负触发。主成果才转；出现「迟延」「拒绝」「不完全」一词不是转出。

## 建立工作坐标

确认：评估授权；单方立场；合同及订单版本；义务切片与履行期；催告或拒绝碎片；法域。

口头「对方违约了」「可以解除了」「不催告也能解除」只登记 `S#`／`V#`。不得升格已违约、已解除或目的不能实现，**不得单独算作开闸材料**。可编号义务、履行期或拒绝／不符碎片可开闸。本窗不执行发送，不代提交，不写函或诉状。

立场只许主张请求或抗辩一方或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：形态闸关闭，仍交十节，不是整体停止。无书面评估授权但单方立场已闭合、且已有碎片：形态闸部分打开，仍交十节，不是整体停止。提出伪造履行记录、倒签催告或到达日、隐匿对账单或违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`XT#` 形态行；`V#` 版本；`E#` 证据形态回链（合同版本、履行期、催告或拒绝到达形态，不是发送闸，不是已违约证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`ZL#`、`SX#`、`QJ#`、`JC#`、`ZT#`、`CG#`。技能正文中的条号是检索锚点，不是已核验 `L#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。未知不写零。构成违约 ≠ 当然解除。迟延 ≠ 当然解除。须催告未催告 ≠ 已成立。已读 ≠ 到达。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或裁判案例检索。本窗是评估，**不要**用 `search_template` 生成催告函、解除函、诉状或已违约证明。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现构成违约即当然解除、迟延即当然解除、须催告未催告即已成立、合理期限一律十五日的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效合同法第一百零七条、第九十四条、第六十七条、第六十一条、第六十二条当作现行规则。不得把商品房催告后三个月、技术合同催告后三十日套一般买卖。MCP 可能先返回第五百二十五条、第五百二十七条、第五百二十八条或通则解释第三十一条而未返回第五百二十六条、第五百六十三条正文，不得把抗辩或不安条文写成迟延解除主条。MCP 效力字段与公布施行日冲突时，以施行日为准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的形态、催告或目的结论保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民法典第五百七十七条不履行或履行不符合约定，应当承担继续履行、采取补救措施或者赔偿损失等违约责任；不是当然解除。第五百六十三条第三项迟延履行主要债务，经催告后在合理期限内仍未履行；第四项目的不能实现可讨论跳过催告；第二项预期拒绝分列。合理期限不写一律十五日；商品房三个月、技术合同三十日不得套一般买卖。第五百七十八条期限届满前明确表示或以行为表明不履行，对方可请求承担违约责任，不是当然解除。第五百二十六条先履行一方未履行或不符合约定，后履行一方有权拒绝相应请求；抗辩成立不得写已迟延违约。第五百一十条约定不明可协议补充。第五百一十一条仍不能确定时分项；「尽快」不是确定到期。第五百八十二条补救只开接口。第五百二十五条、第五百二十七条、第五百二十八条、通则解释第三十一条只开抗辩窗接口。噪声：已失效合同法第一百零七条、第九十四条、第六十七条、第六十一条、第六十二条；涉外经济合同法第二十九条。技能正文条号不是 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变催告必要、合理期限或目的不能的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补构成违约不是解除、迟延主要债务原则上须催告、轻微迟延不是目的不能、已读不是到达的实务反例。实务把催告后三个月写成一般买卖规则时记为噪声。
- `search_case_by_fact` 只比较事实差异与翻转条件：构成违约不是解除；须催告未催告不是已成立；已读不是到达；先履行抗辩成立不是已迟延；约定不明不是已逾期；尽快不是确定到期；从给付迟延不是当然解除；短迟延可补救不是目的不能。无类案不得写成已违约、已解除或目的不能终稿。评估类禁止用 `search_template` 生成催告、解除函或已违约证明。

工具不可用时继续义务碎片和 `XT#` 编目；形态、催告、目的结论字段停止。不得拒跑，不得凭记忆写成已违约、已解除或当然解除。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、形态闸与不关窗

主成果才整案转出。双方秘密、伪造履行记录、倒签第一次停。构成违约即当然解除、迟延即当然解除不关窗。闸关仍交十节，第 6 节不出 `XT#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

迟延、预期拒绝、拒绝受领、不完全分列。本节禁止出 `XT#` 终稿。

### 3. 形态闸与路径 `Q#`

本节禁止出 `XT#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-态`。

### 4. 形态行 `XT#`

义务切片、形态分列、催告必要与合理期限、目的能否实现、补救接口。状态 `草案`。禁止升格已违约、已解除、目的不能闭集。无 `E#` 不得写已催告届满。

### 5. 时线、质量、催告、解除接口

完整时间线转时线窗。质量转质量窗。发送版催告转催告窗。解除实体转解除窗。第 7 节不得夹带 `XT#` 终稿或函绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造履行记录、倒签催告或到达日、隐匿对账单或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：形态闸关闭，仍交十节，不是整体停止。无书面评估授权但有碎片：形态闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：履行期、催告到达、合理期限、目的、抗辩、施行日未核验。构成违约即当然解除、迟延即当然解除、须催告未催告即已成立、合理期限一律十五日、已读即到达、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `XT#` 草案。
- `目标停止`：主目标变为发送版解除函、完整时间线终稿或质量瑕疵终稿。禁止把「构成违约即当然解除」当作用户错误主张时的目标停止；那是不关窗。

禁止指导伪造履行记录或倒签催告。不给胜诉率。不定罪。不选定法院。不代提交。未知不写零。不写唯一截止日。不发函。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。形态闸关闭仍交十节，第 6 节不出 `XT#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `XT#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。形态闸未打开时不得交付「已违约」或「已解除」。边界见 [路由](references/routing.md)。
