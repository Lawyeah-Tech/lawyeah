# 迟延拒绝与不完全履行评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然结果或唯一必得总额。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。实务检索若出现“违约金不超过合同标的百分之三十”，记为噪声。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

应诉答辩或提出反诉，不等于当然放弃仲裁协议。解除通知到达对方时解除；未通知而起诉或申请仲裁主张解除的，仅在该主张获确认后，自起诉状或仲裁申请书副本送达时解除，不得把立案日写成解除时点。第 585 条“过分高于”对照违约造成的损失，不对照合同总价。

## 节点 1　形态识别

1. 迟延：期限届满未履行，且无合法抗辩。
2. 预期拒绝：期限届满前明确表示或以行为表明不履行主要债务。默示拒绝不得单凭迟到几天认定。
3. 不完全履行：有履行但数量、质量、地点或方式不符。
4. 受领迟延：债权人无正当理由拒绝受领或未提供必要协助。
5. 合法抗辩（同时履行、先履行、不安、不可抗力）成立时，不得写成违约。

若：停给停付主轴是履行顺序 → 先转或并行 `评估同时履行先履行与不安抗辩`。
若：质量主轴 → 质量原子出瑕疵结论，本任务只接形态。

## 节点 2　主要债务与催告

1. 区分主要债务与从给付。从给付迟延通常不当然解除。
2. 迟延主要债务：原则上催告 + 合理期限仍未履行，才进入第 563 条第三项。
3. 合理期限按标的性质、准备周期和合同约定判断，标待核，不编统一日数。
4. 已有符合要求的催告：记录发出、到达和期限届满事实。已读不等于到达。
5. 依法须催告且未催告：不得写解除已成立。

## 节点 3　目的能否实现

1. 目的不能实现须回链合同目的、时间敏感性、季节性或特定项目窗口。
2. 可补救的短迟延、可更换的轻微瑕疵，不得跳到解除。
3. 不可抗力造成不能履行：按第 180、590 条部分或全部免责接口，转情势或不可抗力原子，不直接写违约。
4. 商业亏损不等于目的不能实现。

## 节点 4　法律效果

1. 继续履行、补救措施、赔偿损失分列。
2. 违约金按第 585 条，对照损失而非总价。
3. 解除只作为接口：条件未闭合不转介发函。
4. 拒绝履行的意思须主体有权、原文和到达可回链。
