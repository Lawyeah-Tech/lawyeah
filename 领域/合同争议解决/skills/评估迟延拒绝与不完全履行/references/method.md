# 评估迟延拒绝与不完全履行方法

本文件是可执行判断节点。构成违约不是当然解除。迟延主要债务原则上须催告。须催告未催告不是已成立。合理期限不是一律十五日。已读不是到达。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已违约终稿、已解除、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不把形态写成已解除。本窗闸名只能是形态闸，禁止复用违约闸、履行闸、迟延闸、质量闸、时线闸、期间闸、解除闸、催告闸。预留不得占用：立案闸、催告闸、解除闸。本窗 `XT#` 是形态行。主路径只用 `Q-态`，禁止用 `Q-违`、`Q-迟`、`Q-履`、`Q-历`、`Q-疵`、`Q-除`、`Q-形`、`Q-签` 作主路径。本窗 `Q-签` 只作「评估即已违约、已解除或已提交」不关窗码。本窗 `Q-违` 只作「构成违约即当然解除」不关窗码。本窗 `Q-迟` 只作「迟延即当然解除」不关窗码。英文 id 禁止使用，一律用中文技能名 `评估迟延拒绝与不完全履行`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效合同法第一百零七条、第九十四条、第六十七条、第六十一条、第六十二条、商品房催告后三个月、把构成违约写成当然解除时记为噪声。禁止指导伪造履行记录或倒签催告。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现义务碎片扫描，不是默认闭集。
`XT#` 固定列：`编号｜义务切片｜形态分列（迟延／预期拒绝／拒绝受领／不完全）｜催告必要与合理期限｜目的能否实现｜补救继续履行赔偿接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已违约」或「已解除」。无 `E#` 不得写已催告届满。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-态`。禁止 `ZL#`、`SX#`、`QJ#`、`JC#`、`ZT#`、`CG#`、`A#`、`N#`。

口头「对方违约了」「可以解除了」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：迟延、预期拒绝、拒绝受领、不完全分列。迟延主要债务原则上催告＋合理期限。定期行为目的不能才讨论跳过催告。不编造一律十五日。

## 节点 0　分流、立场、形态闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造履行记录、倒签催告或到达日、隐匿对账单、违法取证不进负表。利益冲突未解不进整体停止。不认定解除、不发函不是负触发。

整案转出只交付第 1、2、10 节，不出 `XT#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是完整时间线 | 负触发 `建立双向履行时间线` |
| 主成果是质量瑕疵终稿 | 负触发 `评估质量瑕疵与检验期间` |
| 主成果是履行顺序或不安抗辩终稿 | 负触发 `评估同时履行先履行与不安抗辩` |
| 主成果是解除权实体终稿 | 负触发 `评估解除权是否成立` |
| 主成果是发送版催告 | 负触发 `准备催告履行或补救通知` |
| 主成果是发送版解除通知 | 负触发 `准备解除通知` |
| 主成果是继续履行可行性终稿 | 负触发 `评估继续履行是否可能` |
| 主成果是精算工作表 | 负触发 `测算违约金与损害赔偿` |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程／金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不认定解除」「不发函」「不写唯一截止日」 | 交付禁令，不是负触发 |

出现「迟延」「拒绝」「不完全」一词不是转出。

形态闸打开（可出 `XT#` 草案，仍不得标「已违约／已解除／目的不能闭集」）须同时满足：单方无冲突立场已闭合；主成果是形态评估，不是时间线终稿、不是质量终稿、不是解除终稿、不是发函；至少一项可编号义务、履行期或拒绝／不符碎片。口头「对方违约了」不算单独开闸材料。

形态闸部分打开：已有碎片，但催告、到达或目的未闭合；对应格待核；仍交十节。无书面评估授权但单方立场已闭合且已有碎片：形态闸部分打开，仍交十节，不是整体停止。

形态闸关闭（仍正触发）：无一可编号碎片。「今天必须出已违约／已解除终稿」而无最小碎片不得开闸。不出 `XT#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `XT#` 终稿，**第 7 节不得出催告函、解除函或诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「构成违约即当然解除」「迟延即当然解除」「须催告未催告即已成立」「合理期限一律十五日」「已读即到达」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `XT#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 形态闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造履行记录、倒签催告或到达日、隐匿对账单或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 3　形态行 `XT#`

按已出现义务碎片扫描，不是默认闭集。每条须能指向形态、催告必要或目的之一。

无 `E#` 不得写已催告届满。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止唯一截止日。

热冲突强制处理：

- 构成违约即当然解除／迟延即当然解除／须催告未催告即已成立／合理期限一律十五日／已读即到达／未知写零 → 该格不支持或字段停止；仍出其他 `XT#`。
- 无一碎片 → 关闸，不出 `XT#` 终稿，窗口不关。
- 指导伪造履行记录、倒签、隐匿对账单 → 整体停止，不是该格不支持。

## 节点 4　时线、质量、催告、解除接口

第 7 节只开接口，不得夹带 `XT#` 终稿或函绕闸。闸关闭时第 7 节可写「闸未开，转介待义务编号」，不得补写已违约。不选定法院。不代提交。不发函。

下一步只转介：`建立双向履行时间线`、`评估质量瑕疵与检验期间`、`评估同时履行先履行与不安抗辩`、`评估不可抗力情势变更与履行不能`、`评估继续履行是否可能`、`评估解除权是否成立`、`准备催告履行或补救通知`、`准备解除通知`、`测算违约金与损害赔偿`、`评估争议期间`、`建立合同争议证据案卷`、`评估价款结算与发票争议`、`处理解除后返还与清理`、`设计合同案件通知送达`、`准备索赔或违约金主张通知`、`提起合同纠纷一审`、`评估合同争议`。禁止此致某院。构成违约不得写成当然解除。

## 场景对抗（运行时自检，不写入用户可见闭集）
