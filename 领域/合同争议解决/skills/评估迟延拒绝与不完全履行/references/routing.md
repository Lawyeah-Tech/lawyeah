# 边界与路由

## 正触发

一般合同已成争，存在逾期、拒绝履行或履行不符合约定，需要定性并决定催告或补救路径。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 发解除通知 | `准备解除通知` |
| 发催告 | `准备催告履行或补救通知` |
| 解除权是否成立 | `评估解除权是否成立` |
| 履行顺序或不安 | `评估同时履行先履行与不安抗辩` |
| 质量专项 | `评估质量瑕疵与检验期间` |
| 时间线 | `建立双向履行时间线` |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，只分流不回改 |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

要定性迟延或拒绝、还不必发解除函时正触发。用户开口就要解除终稿时负触发。停给理由是同时履行或不安时，履行顺序原子更合适。
