# 边界与路由

## 正触发

一般合同已成争，存在逾期、拒绝履行、拒绝受领或履行不符合约定，需要分列形态并判断催告是否必要、补救是否可能、目的能否实现。从零、碎片、催告未核验、无书面评估授权仍正触发：有可编号义务、履行期或拒绝／不符碎片则闸开或半开，出 `XT#` 草案，保持草案。本次不认定解除、不发函、不写唯一截止日是交付禁令，不是开窗条件。构成违约即当然解除、迟延即当然解除，仍正触发。

双方秘密、伪造履行记录、倒签催告或到达日、隐匿对账单、违法取证的停止，优先于负触发。上述信号不在下表。不认定解除不是负触发。「构成违约即当然解除」「迟延即当然解除」「须催告未催告即已成立」「合理期限一律十五日」「已读即到达」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 完整时间线 | `建立双向履行时间线` |
| 质量瑕疵终稿 | `评估质量瑕疵与检验期间` |
| 履行顺序或不安抗辩终稿 | `评估同时履行先履行与不安抗辩` |
| 解除权实体终稿 | `评估解除权是否成立` |
| 发送版催告 | `准备催告履行或补救通知` |
| 发送版解除通知 | `准备解除通知` |
| 继续履行可行性终稿 | `评估继续履行是否可能` |
| 精算工作表 | `测算违约金与损害赔偿` |
| 争议总图 | `评估合同争议` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |
| 工程／金融／房产／海事／劳动主轴 | 对应领域 |

不得因「不认定解除」或「不发函」关窗。拟形态评估仍正触发，不得写成已违约或已解除。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流。出现「迟延」「拒绝」「不完全」一词不是转出。C 端只要大众违约填空页时只分流，不把本包降成填空式违约认定，不回改。

## 易混

本窗闸名只能是形态闸，不是违约闸，不是履行闸，不是质量闸，不是时线闸，不是解除闸，不是催告闸。`XT#` 不是 `ZL#`，不是 `SX#`，不是 `JC#`，不是 `CG#`。主路径是 `Q-态`，不是 `Q-违`，不是 `Q-迟`，不是 `Q-履`，不是 `Q-形`。`Q-形` 是公司治理形式变更主路径。`Q-履` 留给继续履行窗。构成违约不是当然解除。迟延主要债务原则上须催告。合理期限不是一律十五日。商品房催告后三个月、技术合同三十日不得套一般买卖。已失效合同法第一百零七条、第九十四条、第六十七条不是现行。MCP 可能先返回第五百二十五条、第五百二十八条而不是第五百二十六条、第五百六十三条。「催告日期改到上周」「对账单先藏起来」整体停止。本窗不执行发送，不代提交。不选定法院。不认定解除。不写唯一截止日。不发函。
