# 应对合同纠纷一审

## 任务目标

在明确、无利益冲突的被告立场下，形成首次应诉答辩包：答辩期限卡（作出日与送达日分列）、原告请求拆解、答辩草稿、管辖／仲裁抗辩红旗、反诉评估接口和证据意见。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价起诉材料、评估、测算和证据清单。原告侧材料不得直接当作被告已掌握或已授权使用的秘密。

## 工作边界

正触发：一般合同被告已收到起诉状或应诉通知，需要答辩、请求拆解、期限判断和抗辩红旗，而不是只要一份管辖异议终稿、也不是只要大众答辩包。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未成争，只要改合同或出稿（审查起草领域，本生产线搁置，只说明不实施）；
- 用户实为原告、只要起诉状；
- 只要管辖异议终稿且无实体答辩（转 `提出合同案件管辖异议`，可注明与本任务并行）；
- 劳动应诉（整案转劳动领域）；
- 建设工程、金融借贷担保、房地产物业、海事专项应诉；
- 已决定只谈和解、只要谈判方案。

C 端 012 只分流：普通民事被告只要大众答辩包时提及 012，不回改，不把本技能降成大众答辩包。本任务仍负责专业请求拆解、除斥／时效分列和管辖／仲裁红旗。

本任务不自动生成反诉状终稿，不保证免于缺席或胜诉，不指导隐匿证据或虚假陈述。

## 建立应诉坐标

确认：使用者与授权；被告立场；原告及共同诉讼人；收到的起诉状、应诉通知、举证通知及其他机关文书；每份文书的作出日、送达日、送达方式和效力凭证；合同及附件版本；法域；是否已有仲裁条款；材料来源与使用权限；关键材料及缺失。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。口头转述、截图、“已读”不得写成已送达或期限已起算。作出日与送达日不明时，期限字段停止，不编唯一截止日。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`K#` 期限卡；`H#` 抗辩；`V#` 稿件版本；`E#` 发送／送达／履行凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验答辩期间、管辖异议期间、仲裁协议抗辩时点、应诉管辖、反诉条件和期间起算；`search_template` 只借答辩状栏目结构；`search_practiced` 补路径与反例；特殊事实用 `search_case_by_fact`，明确筛选用 `search_case_by_filter`。不虚构案件系统。

工具不可用时继续文书登记、请求拆解、事实和问题清单；期限截止日、管辖／仲裁抗辩成立与否、反诉法律结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [应诉方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 专项分流、被告立场和材料权限

先做专项整案转出。劳动应诉不得留在本任务。固定被告立场和授权。原告材料、对方律师函和己方内部文件分权登记；不得用原告未向被告披露的秘密撰写答辩。用户只要管辖异议终稿且无实体：负触发至管辖异议原子，可注明并行。

### 2. 答辩期限卡

每份机关文书单独一行：作出日、送达日、送达方式、效力凭证、起算事件、期间类型、程序种类。普通程序以收到起诉状副本之日起算答辩期间，不得用应诉通知作出日代替送达日。送达不明则期限字段停止。已读不等于送达。

### 3. 请求拆解与管辖／仲裁抗辩红旗

逐项拆解原告请求：承认、否认、不知、抗辩分列。出现仲裁条款或管辖连结点冲突时先做红旗，不得径直只写实体认诺。未提管辖异议并应诉答辩或反诉，可能被视为接受受诉法院管辖，但不自动消灭仲裁协议争点。有效仲裁不得写成“反正已经进法院就只能实体打”。

### 4. 答辩草稿与反诉评估接口

按拆解结果组织答辩草稿。反诉只评估条件、牵连、管辖、时效和风险，不自动生成反诉状终稿。需要反诉状时转评估反诉或准备反诉原子。

### 5. 证据与禁止事项

证据按抗辩绑定，标控制方和合法性。拒绝隐匿、伪造、虚假陈述指导。不利证据必须进入最强反方，不得从草稿中删除。C 端 012 只分流，不把本节改成大众填空答辩。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或起诉材料无法建立；用户坚持隐匿证据、虚假陈述、伪造或违法取证。
- `字段停止`：作出日或送达日不明、法域、动态规则、仲裁／管辖关键事实未核验。
- `目标停止`：主目标已变为管辖异议终稿、反诉状终稿、二审答辩或和解协议正文。
