# 应对合同纠纷一审

## 任务目标

在明确、无利益冲突的单方立场下（被诉守约方、被指违约方或其受托律师，互斥），形成合同纠纷一审首次答辩草稿：答辩闸、主体与强制接口、`Q#` 路径、`DB#` 答辩行（请求切片／送达与期限接口／程序抗辩／实体抗辩／反诉接口／`E#` 回链）。本窗 `DB#` 是答辩行草案，不是已答辩证明，不是发送版答辩状，不是反诉状终稿，不是管辖异议唯一成果。本窗闸名只能是答辩闸，禁止复用应诉闸、应对闸、起诉闸、立案闸、管辖闸、证据闸、方案闸、争议闸、论坛闸、保全闸、提交闸。预留不得占用：立案闸、起诉闸。本窗主行只能是 `DB#`，禁止 `QT#`、`K#`、`H#`、`SZ#`、`YS#`、`Ans#`、`A#`。主路径只用 `Q-辩`，禁止 `Q-应`、`Q-诉`、`Q-管`、`Q-坛` 作主路径。邻窗 `Q-辩` 只作转介进本窗；本窗打开为主路径，不是已提交、不是已答辩。本窗 `Q-应裁` 只转介 `应对合同仲裁`。本窗 `Q-应上` 只转介 `应对合同案件二审`。本窗 `Q-签` 只作「草稿即已提交答辩」不关窗码。答辩闸打开不等于已答辩不等于已提交不等于已送达不等于抗辩已成立不等于应诉管辖已成立不等于保证驳回。草稿不是已答辩。已读不是已送达。微信转发不是法定送达。网交不是已提交。不提出答辩状不是当然败诉。逾期只停该提交稿，不关窗。有效仲裁协议不是本案必审。构成违约不是当然解除。选定某院不是管辖已定。未知不写零。不写反诉状终稿。不写保全复议终稿。不代提交。不选定法院。不定罪。不保证胜诉。伤残等级与本窗无关，禁止折入。

`depends-on` 为空。主成果是原告起诉包转 `提起合同纠纷一审`。主成果是管辖或仲裁效力评估终稿、或只要管辖异议终稿且拒绝任何实体抗辩转 `评估合同管辖与仲裁协议` 或 `提出合同案件管辖异议`。主成果是仲裁申请应对转 `应对合同仲裁`。主成果是反诉状终稿转 `准备合同反诉或仲裁反请求`。主成果是已过首次应诉的庭审提纲转 `准备合同案件庭审`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：一般合同被告已收到一审起诉状、应诉通知或等价被诉碎片，需要请求拆解、送达与期限、程序和实体抗辩接口及答辩草稿。「给我答辩状」仍正触发，成果状态 `草案`，不代提交。送达、仲裁、管辖未核验仍正触发：有可编号起诉状或应诉通知碎片则答辩闸打开或半开，第 6 节出 `DB#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出已答辩／保证驳回终稿」才关闸，仍交十节，第 6 节不出 `DB#` 终稿，第 7 节不得出可提交答辩状，窗口不关。用户要把已读写成已送达、把网交写成已答辩、把不答辩写成当然败诉、把过期仍要可提交终稿、把有效仲裁写成应直接实体答辩当本案必审、把应诉写成管辖已定闭集、把构成违约写成当然解除、把选定某院、把保证驳回、把未知写成零，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `DB#` 草案。不得因「不代提交」「不选定法院」「不出反诉终稿」「管辖异议不是唯一成果」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是原告起诉包（转 `提起合同纠纷一审`）；
- 主成果是管辖或仲裁效力评估终稿（转 `评估合同管辖与仲裁协议`）；
- 只要管辖异议终稿且拒绝任何实体抗辩（转 `提出合同案件管辖异议`）；
- 主成果是仲裁协议异议材料终稿（转 `准备合同仲裁协议异议材料`）；
- 主成果是仲裁申请应对（转 `应对合同仲裁`）；
- 主成果是反诉状终稿（转 `准备合同反诉或仲裁反请求`）；
- 主成果是反诉条件专项（转 `评估合同反诉或反请求`）；
- 主成果是证据案卷终稿（转 `建立合同争议证据案卷`）；
- 主成果是举证期限计划（转 `规划举证期限与证据交换`）；
- 主成果是已过首次应诉的庭审提纲（转 `准备合同案件庭审`）；
- 主成果是保全复议或担保置换（转 `应对合同案件保全裁定`）；
- 主成果是和解方案（转 `谈判合同和解方案`）；
- 主成果是可签和解协议（转 `起草合同和解协议`）；
- 主成果是二审答辩（转 `应对合同案件二审`）；
- 尚未成争，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）；
- 建设工程、金融借贷担保、房地产物业、海事、劳动专项应诉。

双方秘密、伪造或倒签答辩或送达回证、隐匿证据、虚假陈述、违法取证**不在负触发表**，走整体停止。「草稿即已答辩」「已读即已送达」「网交即已提交」「不答辩即败诉」「过期仍要可提交」「有效仲裁仍当本案必审」「应诉即管辖已定」「保证驳回」「选定某院」「未知写零」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不代提交」「不选定法院」「不出反诉终稿」是交付禁令，不是负触发。主成果才转；出现「应诉」「答辩」「管辖」「仲裁」一词不是转出。C 端 012 只分流，不回改、不降成大众答辩包。

## 建立工作坐标

确认：应诉授权；单方立场；原告及共同诉讼人；收到的起诉状、应诉通知、举证通知；每份文书作出日与送达日；合同及附件版本；法域；是否已有仲裁条款。

口头「已经被诉了」「微信已读就算送达」「已经答辩了」「不答辩就败了」只登记 `S#`／`V#`。不得升格已送达、已答辩或当然败诉，**不得单独算作开闸材料**。可编号起诉状、应诉通知、传票、举证通知或案号碎片可开闸。微信或邮箱收到的起诉状 PDF 可作被诉碎片开闸或半开，**不得**单独起算答辩期。已排期且主成果只要庭审提纲：目标停止，转庭审原子。本窗不执行发送，不代提交，不选定法院。

立场只许被诉一方或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。原告侧材料不得直接当作被告已掌握或已授权使用的秘密。无一可编号被诉碎片：答辩闸关闭，仍交十节，不是整体停止。无书面应诉授权但单方立场已闭合、且已有碎片：答辩闸部分打开，仍交十节，不是整体停止。提出伪造或倒签答辩或送达回证、隐匿证据、虚假陈述或违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`DB#` 答辩行；`V#` 版本；`E#` 证据形态回链（应诉授权、起诉状或应诉通知、送达凭证，不是发送闸，不是已答辩证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`K#`、`H#`、`QT#`、`SZ#`。技能正文中的条号是检索锚点，不是已核验 `L#`。期限不得另开 `K#` 为主行。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。未知不写零。草稿 ≠ 已答辩。已读 ≠ 已送达。网交 ≠ 已提交。不答辩 ≠ 当然败诉。有效仲裁 ≠ 本案必审。应诉答辩 ≠ 管辖已定闭集。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或文书范本检索。本窗是首次答辩草稿，范本只借民事答辩状栏目，**不要**升格「已答辩／已提交／已送达／保证驳回」，**不要**用类案写成必然驳回。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现已读即送达、网交即已答辩、不答辩即败诉、有效仲裁仍当本案必审、应诉即管辖已定的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1991 年民事诉讼法第一百二十八条调解判决、第一百三十条缺席判决当作现行。不得把 2017 年第一百二十五条、第一百二十七条当作现行第一百二十八条、第一百三十条。MCP 效力字段与公布施行日冲突时，以施行日为准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的答辩期、管辖异议、仲裁效力保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民事诉讼法（2023 修正，施行日 2024-01-01）第一百二十八条人民法院应当在立案之日起五日内将起诉状副本发送被告，被告应当在收到之日起十五日内提出答辩状；被告不提出答辩状的，不影响人民法院审理。噪声：1991 年第一百二十八条调解判决；2017 年第一百二十五条。第九十条电子送达须经受送达人同意，采用能够确认其收悉的电子方式；以送达信息到达特定系统的日期为送达日期。已读、微信转发不是当然法定送达。第一百三十条对管辖权有异议的，应当在提交答辩状期间提出；未提出管辖异议并应诉答辩或提出反诉的，视为受诉人民法院有管辖权，但违反级别管辖和专属管辖规定的除外。噪声：1991 年第一百三十条缺席判决；2017 年第一百二十七条。民诉解释第二百二十三条：答辩期内提出管辖异议后又实体答辩的，仍审查异议；未提异议而就实体答辩或反诉的，可认定为应诉答辩。简易程序、小额诉讼答辩期运行时核验解释，不得把普通程序十五日一律套简易或小额。仲裁法（2025 修订，施行日 2026-03-01）已施行；MCP 标尚未施行以施行日为准。第五条有协议起诉原则上不予受理。第三十一条效力异议首次开庭前提出。起诉未声明有协议、另一方首次开庭前提交应驳回，否则视为放弃，条号运行时核验第三十七条。不得用答辩十五日充仲裁异议截止。应诉管辖不是当然放弃仲裁。噪声：1994 年第三十七条；2017 年第二十条、第二十六条。民法典第五百七十七条不是当然解除。第五百八十五条约定金不是必得。技能正文条号不是 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变答辩期、管辖异议时点、电子送达或仲裁异议的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补已读不是送达、网交回执不是已答辩、不提出答辩状不影响审理、管辖异议须在提交答辩状期间、应诉答辩可能视为接受管辖但不自动消灭仲裁争点、有效仲裁首次开庭前提交应驳回起诉的实务反例。
- `search_template` 只借民事答辩状栏目（当事人／答辩事项／事实理由／证据名称／证明对象）。范本落款、此致某院、「请驳回全部诉讼请求」不得升格已答辩、已提交、保证驳回或管辖已定。禁止用范本生成发送版答辩状或反诉状终稿。仲裁答辩书不得套法院一审。

工具不可用时继续请求拆解和 `DB#` 编目；答辩期、管辖异议期、仲裁效力、施行日字段停止。不得拒跑，不得凭记忆写成已答辩、已送达、当然败诉或保证驳回。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、答辩闸与不关窗

主成果才整案转出。双方秘密、隐匿证据、倒签答辩第一次停。已读即送达、不答辩即败诉不关窗。闸关仍交十节，第 6 节不出 `DB#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

被告列法、对方请求类型分列。作出日与送达日分列。本节禁止出 `DB#` 终稿。

### 3. 答辩闸与路径 `Q#`

本节禁止出 `DB#` 终稿。有可编号被诉碎片：闸打开或半开。主路径只用 `Q-辩`。

### 4. 答辩行 `DB#`

请求切片、送达与期限、程序抗辩、实体抗辩、反诉接口。状态 `草案`。禁止升格已答辩、已送达、已提交、当然败诉。无 `E#` 不得写已答辩。

### 5. 管辖仲裁、反诉、庭审接口

论坛评估转论坛窗。异议终稿转异议窗。反诉只开接口。已排期只要庭审转庭审窗。第 7 节不得夹带 `DB#` 终稿或可提交答辩状绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造或倒签答辩或送达回证、隐匿证据、虚假陈述或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：答辩闸关闭，仍交十节，不是整体停止。无书面应诉授权但有碎片：答辩闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：答辩期、管辖异议期、电子送达同意、仲裁协议效力、施行日未核验。已读即送达、不答辩即败诉、网交即已提交、有效仲裁仍当本案必审、应诉即管辖已定、过期仍要可提交、保证驳回、选定某院、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `DB#` 草案。
- `目标停止`：主目标变为起诉包、管辖异议唯一成果、反诉状终稿、保全复议终稿或庭审提纲。禁止把「不答辩即败诉」当作用户错误主张时的目标停止；那是不关窗。

禁止指导隐匿证据、伪造答辩或倒签送达。不给胜诉率。不定罪。不选定法院。不代提交。未知不写零。不写唯一截止日。不写反诉状终稿。不写发送版答辩状。
