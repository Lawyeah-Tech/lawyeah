# 边界与路由

## 正触发

一般合同被告已收到起诉状或应诉通知，需要期限卡、请求拆解、答辩草稿、管辖／仲裁红旗、反诉评估接口和证据意见。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 用户为原告，只要起诉状 | `提起合同纠纷一审` |
| 只要总体评估 | `评估合同争议` |
| 只要管辖或仲裁协议评估 | `评估合同管辖与仲裁协议` |
| 只要管辖异议终稿且无实体答辩 | `提出合同案件管辖异议`（可与本任务并行说明） |
| 只要仲裁协议异议材料 | `准备合同仲裁协议异议材料` |
| 已决定反诉并只要反诉状 | `准备合同反诉或仲裁反请求` |
| 只要是否反诉的专项评估 | `评估合同反诉或反请求` |
| 收到的是仲裁申请 | `应对合同仲裁` |
| 只要和解方案 | `谈判合同和解方案` |
| 劳动应诉 | 劳动领域整案转出 |
| 工程／金融／房产／海事 | 对应领域整案转出 |
| 只要通用民事答辩状、不需要合同请求拆解／期限卡／仲裁红旗／反诉评估 | C 端 `只要通用民事答辩状不需要合同请求拆解／期限卡／仲裁红旗／反诉评估`（012），只分流 |
| C 端 012 只要大众答辩包 | 只分流，不回改，不把本任务降成大众包 |
| C 端 032／011 | 大众专项，只分流，不回改、不实施 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全、港口作业 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

已收到起诉状但仍要谈和解：主目标是方案则转谈判原子；主目标是按期答辩则留本任务，和解只作并行提示。只要管辖异议终稿、明确不做实体：负触发至异议原子，可注明答辩草稿可并行准备以免异议被驳回后失期。C 端 012 与本任务冲突时先澄清成果，不两边各出一份终稿。有效仲裁条款出现时先做红旗，不得因案件已经进法院就写成只能实体答辩。
