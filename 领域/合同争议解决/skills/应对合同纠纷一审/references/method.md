# 应对合同纠纷一审方法

本文件是可执行判断节点。草稿不是已答辩。已读不是已送达。不提出答辩状不是当然败诉。有效仲裁不是本案必审。应诉答辩不是管辖已定闭集。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已答辩、当然败诉、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不把草稿写成已答辩。本窗闸名只能是答辩闸，禁止复用应诉闸、应对闸、起诉闸、立案闸、管辖闸。预留不得占用：立案闸、起诉闸。本窗 `DB#` 是答辩行。主路径只用 `Q-辩`，禁止用 `Q-应`、`Q-诉`、`Q-管`、`Q-签` 作主路径。本窗 `Q-签` 只作「草稿即已提交答辩」不关窗码。英文 id 禁止使用，一律用中文技能名 `应对合同纠纷一审`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991 年民事诉讼法第一百二十八条调解判决、第一百三十条缺席判决、2017 年第一百二十五条当现行答辩期、2017 年第一百二十七条当现行管辖异议、仲裁法 1994 年第三十七条、把草稿写成已答辩或把不答辩写成当然败诉时记为噪声。禁止指导隐匿证据、伪造答辩或倒签送达。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现被诉碎片扫描，不是默认闭集。
`DB#` 固定列：`编号｜请求切片｜送达与期限接口｜程序抗辩｜实体抗辩｜反诉接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已答辩」或「当然败诉」。无 `E#` 不得写已答辩。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-辩`。禁止 `QT#`、`K#`、`H#`、`A#`、`N#`。期限嵌在送达与期限接口：作出日／送达日／答辩期／管辖异议期／举证期／仲裁异议时点分列，禁止一张截止卡，禁止另开 `K#` 为主行。

口头「已经被诉了」「微信已读就算送达」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：承认、否认、不知、抗辩分列。管辖异议与实体抗辩可并列。有效仲裁不得写成只能实体打。不利证据必须进入最强反方，不得从草稿中删除。

## 节点 0　分流、立场、答辩闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造或倒签答辩或送达回证、隐匿证据、虚假陈述、违法取证不进负表。利益冲突未解不进整体停止。不代提交、不出反诉终稿不是负触发。

整案转出只交付第 1、2、10 节，不出 `DB#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是原告起诉包 | 负触发 `提起合同纠纷一审` |
| 主成果是管辖或仲裁效力评估终稿 | 负触发 `评估合同管辖与仲裁协议` |
| 只要管辖异议终稿且拒绝任何实体抗辩 | 负触发 `提出合同案件管辖异议` |
| 主成果是仲裁协议异议材料终稿 | 负触发 `准备合同仲裁协议异议材料` |
| 主成果是仲裁申请应对 | 负触发 `应对合同仲裁` |
| 主成果是反诉状终稿 | 负触发 `准备合同反诉或仲裁反请求` |
| 主成果是反诉条件专项 | 负触发 `评估合同反诉或反请求` |

| 主成果是已过首次应诉的庭审提纲 | 负触发 `准备合同案件庭审` |
| 主成果是保全复议或担保置换 | 负触发 `应对合同案件保全裁定` |
| 主成果是和解方案 | 负触发 `谈判合同和解方案` |
| 主成果是可签和解协议 | 负触发 `起草合同和解协议` |

| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程／金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不代提交」「不出反诉终稿」「不选定法院」 | 交付禁令，不是负触发 |

出现「应诉」「答辩」「管辖」「仲裁」一词不是转出。同时要答辩草稿和管辖红旗：本窗正触发。只要异议终稿且拒实体才负触发。

答辩闸打开（可出 `DB#` 草案，仍不得标「已答辩／已提交／已送达」）须同时满足：单方无冲突被告立场已闭合；主成果是一审首次答辩草稿，不是起诉包、不是异议唯一成果、不是反诉终稿、不是庭审提纲；至少一项可编号起诉状、应诉通知、传票、举证通知或案号碎片。口头「已经被诉了」不算单独开闸材料。PDF 可半开，不得单独起算答辩期。

答辩闸部分打开：已有碎片，但送达日、仲裁或管辖未闭合；对应格待核；仍交十节。无书面应诉授权但单方立场已闭合且已有碎片：答辩闸部分打开，仍交十节，不是整体停止。

答辩闸关闭（仍正触发）：无一可编号碎片。「今天必须出已答辩终稿」而无最小碎片不得开闸。不出 `DB#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `DB#` 终稿，**第 7 节不得出可提交答辩状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已答辩」「已读即已送达」「网交即已提交」「不答辩即败诉」「过期仍要可提交」「有效仲裁仍当本案必审」「应诉即管辖已定」「保证驳回」「选定某院」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `DB#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 答辩闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造或倒签答辩或送达回证、隐匿证据、虚假陈述或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个请求切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `DB#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 被告 | 被诉主体与授权 | 用原告未向被告披露的秘密撰写答辩 |
| 请求 | 承认／否认／不知／抗辩分列 | 合成「全部不认」而无切片 |
| 送达 | 作出日与送达日分列 | 已读、转发、作出日起算答辩期 |
| 期限 | 答辩期、管辖异议期、举证期、仲裁异议时点分列 | 一张截止卡；普通十五日套简易或小额 |
| 程序抗辩 | 管辖、仲裁、主体不适格红旗 | 有效仲裁写成只能实体打 |
| 实体抗辩 | 履行、质量、解除、金额、时效分列 | 构成违约写成当然解除 |
| 反诉 | 只开接口 | 本窗出反诉状终稿 |

检索锚点（写入 `L#` 前须核验）：

- 民事诉讼法（2023 修正）第一百二十八条：立案之日起五日内发送起诉状副本；被告自收到之日起十五日内提出答辩状；不提出不影响审理。噪声：1991 年第一百二十八条；2017 年第一百二十五条。
- 第九十条：电子送达须经受送达人同意；到达特定系统的日期为送达日期。已读不是当然送达。
- 第一百三十条：管辖异议在提交答辩状期间提出；应诉答辩或反诉视为有管辖权，级别专属除外。噪声：1991 年第一百三十条；2017 年第一百二十七条。民诉解释第二百二十三条。
- 简易、小额答辩期运行时核验解释，不得一律套普通十五日。
- 仲裁法（2025 修订，施行日 2026-03-01）已施行；MCP 标尚未施行以施行日为准。第五条、第三十一条、第三十七条。不得用答辩十五日充仲裁异议截止。应诉管辖不是当然放弃仲裁。噪声：1994 年第三十七条；2017 年第二十条、第二十六条。
- 民法典第五百七十七条不是当然解除。第五百八十五条约定金不是必得。

## 节点 3　答辩行 `DB#`

按已出现请求切片扫描，不是默认闭集。每条须能指向请求、送达、程序抗辩或实体抗辩之一。

无 `E#` 不得写已答辩。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止唯一截止日。

热冲突强制处理：

- 草稿即已答辩／已读即已送达／网交即已提交／不答辩即败诉／过期仍要可提交／有效仲裁仍当本案必审／应诉即管辖已定／保证驳回／未知写零 → 该格不支持或字段停止；仍出其他 `DB#`。
- 无一碎片 → 关闸，不出 `DB#` 终稿，窗口不关。
- 指导隐匿、伪造答辩、倒签送达 → 整体停止，不是该格不支持。

## 节点 4　管辖仲裁、反诉、庭审接口

第 7 节只开接口，不得夹带 `DB#` 终稿或可提交答辩状绕闸。闸关闭时第 7 节可写「闸未开，转介待被诉碎片编号」，不得补写已答辩。不选定法院。不代提交。

下一步只转介：`提起合同纠纷一审`、`评估合同管辖与仲裁协议`、`提出合同案件管辖异议`、`准备合同仲裁协议异议材料`、`应对合同仲裁`、`评估合同反诉或反请求`、`准备合同反诉或仲裁反请求`、`建立合同争议证据案卷`、`规划举证期限与证据交换`、`准备合同案件庭审`、`应对合同案件保全裁定`、`谈判合同和解方案`、`测算违约金与损害赔偿`、`选择诉讼仲裁或督促程序`。禁止此致某院。有效仲裁不得写成只能实体打。反诉只开接口。

若 if 用户催促「已读就算送到了／不答辩就败了／有仲裁也只能在本院实体打／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「答辩闸与答辩行草案」。本窗不执行发送。不包含：已答辩、发送版答辩状、反诉状终稿、管辖异议唯一成果。禁止选边治愈。禁止已读即送达。禁止不答辩即败诉。禁止指导隐匿或倒签。答辩闸打开 ≠ 已答辩 ≠ 应诉管辖已成立。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：被告微信收到起诉状 PDF，合同有仲裁条款。用户主张已读就算送到了、不答辩就败了、有仲裁也只能在某区法院实体打、草稿写完就算交了、不清楚的金额先写零。答辩闸打开或半开。`Q-达`、`Q-败`、`Q-仲`、`Q-签`、`Q-零` 不打开为可靠路径。第 6 节不得把已送达、当然败诉、本案必审、已提交、0 写入可执行 `DB#`；对应格 `现有依据不支持` 或字段停止；仍出请求分列、作出日与送达日缺口、仲裁红旗等其他 `DB#`。不关窗。不代提交。不选定法院。
