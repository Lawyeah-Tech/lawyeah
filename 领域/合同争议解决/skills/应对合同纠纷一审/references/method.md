# 应诉方法

本文件是可执行判断节点，不是栏目说明书。每个会改变期限、抗辩成立、管辖／仲裁红旗或答辩表述的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然驳回起诉、必然免于缺席或唯一免赔总额。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## 抗辩矩阵

固定列：`编号H#｜对应原告请求Q#｜抗辩类型｜法律效果｜成立条件｜支持事实｜不利事实｜控制方｜最强反方｜与管辖／仲裁红旗关系｜判断｜待核`。

对原告每项请求分别回答承认、否认、不知或抗辩。继续履行、解除确认、违约金、赔偿、定金不得合成一句“不同意全部诉讼请求”。构成违约不等于当然解除，被告亦不得把“未造成损失”直接写成合同必须继续。

## 节点 0　专项分流

先于答辩草稿。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节应诉包。

| 信号 | 转出 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定、实际施工人 | 建设工程领域 |
| 金融借贷、保证、抵押质押、保理、融资租赁主轴 | 金融借贷担保领域 |
| 商品房买卖、开发合作、物业服务主轴 | 房地产物业领域 |
| 海上货物、船舶、海事保全、港口作业 | 海事领域 |
| 劳动关系、劳动报酬、解除劳动合同、工伤待遇 | 劳动领域 |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

混合信号：一般买卖／服务主轴可留本任务；专项只作为背景时在缺口标明，不把专项规则硬套进一般合同答辩结论。

## 节点 1　被告立场、授权和材料权限

1. 确认用户为被告或共同被告，已收到起诉状或应诉通知。用户实为原告：负触发至起诉原子。尚未收到任何机关文书、只是听说“要被起诉”：程序状态标未到达，期限字段停止，可整理已知争点但不作出答辩截止判断。
2. 固定授权范围。承认、放弃、反诉、和解须有特别授权才写入可提交表述；无特别授权时只保留意见接口。
3. 同时掌握双方秘密或立场不明：整体停止策略输出。
4. 材料权限分账：原告起诉材料、法院送达材料、被告自有材料、第三人材料。不得把原告未向被告出示、或己方因利益冲突持有的对方秘密写入答辩策略。来源不明的聊天截图不升级为 `A#`。
5. 用户只要管辖异议终稿且明确不做实体答辩：负触发至 `object-to-jurisdiction`。可在分流说明中提示：异议被驳回后答辩期可能已过或即将届满，是否并行准备实体答辩由用户决定，本任务不自动改写异议书。

## 节点 2　答辩期限卡

每份文书单独建 `K#`。禁止用一张“答辩截止日”吞并作出、送达、程序种类和期间类型。

### 2.1 强制分列

固定列：`文书｜作出日｜送达日｜送达方式｜签收人｜效力凭证｜起算事件｜期间类型｜程序种类｜截止情景｜判断｜待核`。

| 不得写成 | 正确处理 |
| --- | --- |
| 应诉通知落款日＝答辩起算日 | 起算看起诉状副本是否送达及送达凭证 |
| 短信／微信已读＝送达 | 已读不等于到达；电子送达须符合法定同意和到达特定系统规则（民事诉讼法第 90 条，运行时核验） |
| 口头说“法院打电话了”＝已送达 | 记录为转述，期限字段停止 |
| 作出日缺失就用今天倒推 | 字段停止，并列可能情景 |
| 简易／小额／普通混用十五日 | 先核验程序种类和应诉通知指定期间 |

### 2.2 普通程序锚点

运行时核验现行文本后再落判断。核验失败则期限字段停止，请求拆解可继续。

民事诉讼法第 128 条：人民法院应当在立案之日起五日内将起诉状副本发送被告，被告应当在收到之日起十五日内提出答辩状。期间开始的时和日不计算在内；届满日为法定休假日的顺延；期满前交邮不算过期（第 85 条）。

第 130 条：当事人对管辖权有异议的，应当在提交答辩状期间提出。未提出管辖异议并应诉答辩或者提出反诉的，视为受诉人民法院有管辖权，但违反级别管辖和专属管辖规定的除外。本条用于红旗，不得在送达不明时计算“最后异议日”。

被告不提出答辩状，不影响人民法院审理（第 128 条第二款）。不得把“可以不答辩”写成“不答辩没有风险”；缺席可能按现有材料裁判（第 147 条）。

### 2.3 简易、小额、涉外

应诉通知或立案文书载明简易程序或小额程序时，答辩期间以该文书指定和现行解释为准，不得直接套用普通程序十五日。指定期间不明：字段停止。涉外期间另行核验，不套用国内十五日。

举证期限与答辩期限分列。证据规定中的举证期间不得拿来充作答辩截止日。

### 2.4 仲裁协议异议时点

仲裁协议抗辩的提出时点按现行《仲裁法》和司法解释核验，通常不得晚于首次开庭前；条号不得沿用 2017 年记忆。法院已经立案，不消灭该红旗。核验失败则仲裁抗辩时点字段停止，红旗仍须列出。

## 节点 3　请求拆解与管辖／仲裁红旗

### 3.1 逐项拆解

对起诉状每一项诉讼请求建立 `Q#`，被告侧对应 `H#`：

- 承认：仅限用户明示且有材料支持的事实或请求；承认诉讼请求须标不可逆风险；
- 否认：写明否认的事实点，不得空洞否认；
- 不知：限于被告客观上无法核对的事项，不得用于逃避已知事实；
- 抗辩：同时履行、先履行、不安、质量异议、检验期间、时效、未达解除条件、违约金调整、减损、双方违约、主体不适格等，分项列条件。

原告主张解除或确认解除效力：核验催告、除斥、通知是否到达、有无解除权。对方未异议不能补正解除权的缺失。已读不等于解除通知到达。原告未通知而直接起诉主张解除的，即使请求可能成立，解除时点也不是立案日；若裁判确认解除，通常自起诉状副本送达对方时解除，须核验送达事实，不得写成立案即解除。

违约金请求：约定数字不是必得；调整须经当事人请求（第 585 条）。被告拟请求减少的，在抗辩中单列接口，对照损失而非合同总价。不得指导被告虚报损失。

### 3.2 管辖红旗

分列：被告住所地、合同履行地、协议管辖、专属管辖、级别管辖、应诉管辖风险。连结点冲突标红，不在本任务输出管辖异议书终稿。

用户明确只要异议终稿、无实体：负触发。用户需要实体答辩同时保留异议：本任务做答辩草稿，异议书转介，并提示第 130 条应诉管辖风险——在答辩状期间提出异议后又对实体答辩的，法院仍应审查异议；未提异议并应诉答辩或反诉，可能视为受诉法院有管辖权。

### 3.3 仲裁红旗

合同或事后协议出现仲裁条款时：

1. 不得写“既然已经进法院，就只能实体答辩”。
2. 分列书面性、事项覆盖、机构、或裁或诉、是否已应诉答辩、是否已过异议时点。
3. 表面有效：红旗主位写成应提出仲裁协议抗辩或转介 `object-to-arbitration-agreement`。
4. 合同无效、被撤销或终止，不当然消灭仲裁协议。独立性运行时核验现行《仲裁法》，不得沿用记忆条号。无法核验则仲裁抗辩字段停止。
5. 有效仲裁不得直接写成“应继续在本院实体应诉”。

### 3.4 C 端 012

普通民事被告只要大众答辩包：只分流至 012，不回改，不把本任务降成填空式答辩。本任务继续的专业工作是请求拆解、期间分列和管辖／仲裁红旗。冲突时字段停止，先澄清成果，不两边各做一份终稿。

## 节点 4　答辩草稿与反诉评估接口

### 4.1 答辩草稿

按第 128 条答辩状应当记明的事项和范本栏目组织：当事人信息；对诉讼请求的逐项意见；事实与理由；证据。范本只借结构。

事实部分区分 `A#` 与 `S#`。已知不利事实必须保留在最强反方和草稿风险段，不得按“对被告好看”删除。发送前复核标记为必填。不代提交。

诚信原则和处分原则（第 13 条）用于约束虚假认诺和虚假否认，不写成道德说教。

### 4.2 反诉只留接口

民事诉讼法第 54 条：被告有权提起反诉。第 143 条：被告提出反诉可以合并审理。本任务只评估：

- 是否与本诉基于同一合同或有牵连；
- 是否应由本诉法院管辖，或是否受仲裁协议约束；
- 是否已过诉讼时效或其他期间；
- 提起反诉对应诉管辖、小额程序转换、审理周期的影响；
- 与本诉请求是否互斥或可抵销。

判断为 `现有依据支持` 考虑反诉时，输出最小交接，转 `assess-counterclaim` 或 `prepare-counterclaim`。不自动生成反诉状终稿。用户尚未决定反诉，不得把反诉请求写入答辩状当作已经提起。

## 节点 5　证据与禁止事项

1. 证据按 `H#` 绑定待证事实、证明目的、原件状态、控制方、取得方式和合法性。
2. 不能因原告控制而推定材料存在或内容有利于被告；也不能因被告持有不利材料就建议不提交或销毁。
3. 当事人对自己的主张有责任提供证据（第 67 条）。逾期举证后果只标接口。完整建卷转 `build-evidence-record`。
4. 禁止并整体停止的请求：隐匿、销毁、伪造证据；指使作伪证；虚假陈述或虚假自认；非法获取对方通讯、账号或个人信息；威胁证人。首次提出毁证或作伪时立即拒绝，要求保留完整材料；坚持则整体停止，不提供规避方法。
5. 妨害民事诉讼的强制措施和刑事责任风险（第 114、115 条等，运行时核验）只作停止理由，不展开“如何不被发现”。

## 期限卡表

每行只对应一份文书、一种期间类型、一个起算事件。作出日与送达日必须分列。关键日期冲突则并行情景，不选对被告最有利的一天。已读不等于送达。

## 答辩与反诉接口表

固定列：原告请求、被告意见类型、抗辩、依据、不利事实、管辖／仲裁红旗、反诉接口、判断、待核。参数不足不输出唯一免赔额。

## 证据、反方和下一步

下一步按期限灭失、管辖／仲裁异议窗口、易失证据、改变 `H#`、可逆性排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。

管辖异议书、反诉状、仲裁应诉、和解协议只写转介条件和最小交接，不在本方法生成那些终稿。禁止指导伪造、隐匿、威胁或违法取证。不保证免于缺席或胜诉。
