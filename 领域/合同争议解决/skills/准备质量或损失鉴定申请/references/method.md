# 准备质量或损失鉴定申请方法

本文件是可执行判断节点。申请不是已出具鉴定意见。单方委托不是法院委托。评估报告不是司法鉴定。法律评价不是鉴定事项。破坏性检测须授权。未知损失不写零。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已出具、已准许、选定鉴定所、代提交、未知写零。本任务不定罪，不预测鉴定意见，不指导破坏检材。本窗闸名只能是申鉴闸，禁止复用鉴定闸、质量闸、现证闸、公证闸、精算闸。预留不得占用：立案闸、和解闸、鉴定闸、鉴异闸。本窗 `JA#` 是申鉴行。主路径只用 `Q-申鉴`，禁止用 `Q-鉴`、`Q-疵`、`Q-现`、`Q-公`、`Q-测`、`Q-签` 作主路径。本窗 `Q-签` 只作「草稿即已提交、已委托或已作出」不关窗码。本窗 `Q-见` 只作「申请即已作出意见」不关窗码。英文 id 禁止使用，一律用中文技能名 `准备质量或损失鉴定申请`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991 年民事诉讼法第七十九条留置送达、2017 年第七十六条、把申请写成已出具时记为噪声。禁止指导调包送检或破坏检材。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事项切片扫描，不是默认闭集。
`JA#` 固定列：`编号｜鉴定切片｜事项｜检材｜机构与启动｜申请接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已出具」或「对方全责」。无 `E#` 不得写已委托或已作出。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-申鉴`。禁止 `JD#`、`ZL#`、`XZ#`、`GD#`、`SJ#`、`A#`、`N#`。文件状态只用 `草案`、`停止`。

口头「写一份对方全责的鉴定」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：专门性问题才鉴定。诉中协商确定或法院指定。诉前单方委托证明力弱。破坏性检测须书面授权，抽样破坏先公证现状。逾期未申请或未预交视为放弃申请，不是实体已败诉。

## 节点 0　分流、立场、申鉴闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造检材、调包、倒签取样日、破坏现场、未授权破坏性取样、违法取证不进负表。利益冲突未解不进整体停止。不预测意见、不代提交不是负触发。

整案转出只交付第 1、2、10 节，不出 `JA#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是质量实体评估 | 负触发 `评估质量瑕疵与检验期间` |
| 主成果是现场或电子合法自固 | 负触发 `保全质量现场与电子证据` |
| 主成果是公证申请终稿 | 负触发 `准备合同案件公证保全` |
| 主成果是精算表 | 负触发 `测算违约金与损害赔偿` |
| 主成果是鉴定异议或重新鉴定 | 负触发 `提出合同鉴定异议或重新鉴定` |
| 主成果是证据案卷矩阵 | 负触发 `建立合同争议证据案卷` |
| 主成果是股权价值或非货币出资鉴定 | 负触发公司治理 `准备股权价值或非货币出资鉴定` |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程造价／竣工验收／施工质量主轴 | 整案转建设工程领域 |
| 金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不预测意见」「不代提交」 | 交付禁令，不是负触发 |

出现「鉴定」「质量」「损失」一词不是转出。

申鉴闸打开（可出 `JA#` 草案，仍不得标「已委托／已作出／已准许」）须同时满足：单方无冲突立场已闭合；主成果是鉴定申请草稿，不是质量实体终稿、不是鉴定意见、不是测算终稿；至少一项可编号待鉴定事项或检材碎片。口头「写一份对方全责的鉴定」不算单独开闸材料。

申鉴闸部分打开：已有碎片，但专门性、检材权源或破坏性授权未闭合；对应格待核；仍交十节。无书面授权但单方立场已闭合且已有碎片：申鉴闸部分打开，仍交十节，不是整体停止。

申鉴闸关闭（仍正触发）：无一可编号碎片。「今天必须出鉴定意见终稿」而无最小碎片不得开闸。不出 `JA#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `JA#` 终稿，**第 7 节不得出鉴定意见或发送版申请**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「申请即已出具」「单方委托即法院委托」「评估报告即司法鉴定」「法律评价即鉴定事项」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `JA#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 申鉴闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造检材、调包送检、倒签取样日、隐匿不利样品、破坏现场、未授权破坏性取样或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个鉴定切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `JA#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 切片 | 质量原因／贬值／修复费用／损失因果分列 | 合成「对方全责」 |
| 事项 | 一项一问专门性技术问题 | 合同解释、解除权、违约金调整当鉴定事项 |
| 检材 | 权源、持有、质证、完整性分列 | 对方控制推定有利；指导破坏 |
| 启动 | 诉中协商或指定／诉前单方分列 | 单方委托升格法院委托 |
| 破坏性 | 书面授权与公证现状分列 | 未授权即拆机取样 |

检索锚点（写入 `L#` 前须核验）：见技能正文 MCP 节。噪声：1991 年第七十九条；2017 年第七十六条。

## 节点 3　申鉴行 `JA#`

按已出现事项切片扫描，不是默认闭集。每条须能指向专门性问题、检材或启动路径之一。

无 `E#` 不得写已委托或已作出。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止写入希望结论或唯一修复价。事项或检材未闭合不得标待提交。

热冲突强制处理：

- 申请即已出具／单方委托即法院委托／评估报告即司法鉴定／法律评价即鉴定事项／未知写零 → 该格不支持或字段停止；仍出其他 `JA#`。
- 无一碎片 → 关闸，不出 `JA#` 终稿，窗口不关。
- 指导调包、破坏检材、未授权破坏性取样 → 整体停止，不是该格不支持。

## 节点 4　质量、现证、公证、测算与异议接口

第 7 节只开接口，不得夹带 `JA#` 终稿或鉴定意见绕闸。闸关闭时第 7 节可写「闸未开，转介待事项编号」，不得补写已出具。不选定鉴定所。不代提交。不预测意见。

下一步只转介：`评估质量瑕疵与检验期间`、`保全质量现场与电子证据`、`准备合同案件公证保全`、`建立合同争议证据案卷`、`测算违约金与损害赔偿`、`提出合同鉴定异议或重新鉴定`、`规划举证期限与证据交换`、`申请律师调查令或法院调查取证`、`评估电子合同成立与送达`、`准备索赔或违约金主张通知`、`评估解除权是否成立`、`评估迟延拒绝与不完全履行`、`建立双向履行时间线`、`提起合同纠纷一审`、`应对合同纠纷一审`、`评估继续履行是否可能`、`评估合同争议`。禁止此致某鉴定所。

若 if 用户催促「申请了就算出了／先拆两台送检／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止；拆机取样第一次整体停止。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「申鉴闸与申鉴行草案」。本窗不代提交。不包含：已出具、已准许、已委托终稿、鉴定意见、破坏检材步骤。禁止选边治愈。禁止申请即已出具。禁止指导调包。申鉴闸打开 ≠ 已委托 ≠ 已作出 ≠ 已准许。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标申请终稿已形成。
风险档 A：调包送检、破坏现场、未授权破坏性取样必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：设备疑似瑕疵，买方要申请书里写清对方全责、修复费八十万、今晚先拆两台送检、对方库里同批次一定一样、不清楚先写零。申鉴闸打开或半开。`Q-见`、`Q-准`、`Q-零` 不打开为可靠路径。第 6 节不得把已出具、已准许、0、责任比例写入可执行 `JA#`；对应格 `现有依据不支持` 或字段停止；仍出事项分列、检材缺口、公证现状接口。拆机取样第一次整体停止。不代提交。

场景②：用户同时交出己方「样品完好」与卖方「从未允许取样」口径，并要「撬仓取样、把不合格件换成送检件」。命中双方秘密＋破坏现场＋调包。第一次整体停止。只交第 1、10 节。不出 `JA#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代破坏方案。
