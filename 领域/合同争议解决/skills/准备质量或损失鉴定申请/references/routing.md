# 边界与路由

## 正触发

一般合同已成争，需鉴定机构回答专门性问题，要发送前申请草稿。从零、碎片、检材未核验、无书面授权仍正触发：有可编号待鉴定事项或检材碎片则闸开或半开，出 `JA#` 草案，保持草案。本次不预测意见、不代提交是交付禁令，不是开窗条件。申请即已出具、单方委托即法院委托，仍正触发。把评估报告写成司法鉴定、把法律评价当鉴定事项，仍正触发：该格不支持，不改负触发关窗。

双方秘密、调包送检、破坏现场的停止，优先于负触发。上述信号不在下表。不预测意见不是负触发。「申请即已出具」「单方委托即法院委托」「评估报告即司法鉴定」「法律评价即鉴定事项」「保证鉴定结论」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 质量实体评估 | `评估质量瑕疵与检验期间` |
| 现场或电子合法自固 | `保全质量现场与电子证据` |
| 公证申请终稿 | `准备合同案件公证保全` |
| 精算表 | `测算违约金与损害赔偿` |
| 鉴定异议或重新鉴定 | `提出合同鉴定异议或重新鉴定` |
| 证据案卷矩阵 | `建立合同争议证据案卷` |
| 股权价值或非货币出资鉴定 | 公司治理 `准备股权价值或非货币出资鉴定` |
| 争议总图 | `评估合同争议` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不预测意见」或「不代提交」关窗。拟鉴定申请草稿仍正触发，不得写成已出具或已准许。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤、伤残 | 劳动或人身损害领域 |

一般买卖或服务夹带专项背景时，专项段只分流。出现「鉴定」「质量」「损失」一词不是转出。C 端只要大众填空页时只分流，不把本包降成填空式结论，不回改。

## 易混

本窗闸名只能是申鉴闸，不是鉴定闸，不是质量闸，不是现证闸，不是公证闸，不是精算闸。`JA#` 不是 `JD#`，不是 `ZL#`，不是 `XZ#`，不是 `GD#`，不是 `SJ#`。主路径是 `Q-申鉴`，不是 `Q-鉴`，不是 `Q-疵`，不是 `Q-现`，不是 `Q-公`，不是 `Q-测`。`鉴定闸`／`JD#`／`Q-鉴` 是公司治理准备股权价值或非货币出资鉴定。电约窗 `Q-鉴` 是评估即鉴定意见不关窗码。邻窗 `Q-鉴` 只转介进本窗，本窗改走 `Q-申鉴`。申请不是已出具。单方委托不是法院委托。评估报告不是司法鉴定。1991 年民事诉讼法第七十九条留置送达不是鉴定条。2017 年第七十六条须核对应现行第七十九条。提出「撬仓取样、把不合格件换成送检件」整体停止。本窗不代提交。不选定鉴定所。不写鉴定意见。不保证准许。
