# 抵销留置与扣款评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然结果或唯一必得总额。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。实务检索若出现“违约金不超过合同标的百分之三十”，记为噪声。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

应诉答辩或提出反诉，不等于当然放弃仲裁协议。解除通知到达对方时解除；未通知而起诉或申请仲裁主张解除的，仅在该主张获确认后，自起诉状或仲裁申请书副本送达时解除，不得把立案日写成解除时点。第 585 条“过分高于”对照违约造成的损失，不对照合同总价。

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填本任务实体结论。

| 信号 | 转出 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定、实际施工人 | 建设工程领域 |
| 金融借贷、保证、抵押质押、保理、融资租赁主轴 | 金融借贷担保领域 |
| 商品房买卖、开发合作、物业服务主轴 | 房地产物业领域 |

## 节点 1　两债对照

固定列：`债#｜债权人｜债务人｜发生原因｜种类品质｜到期日｜金额来源｜抗辩｜禁止抵销红旗`。

1. 主体必须对应。债权转让后抵销，按第 549 条接口，本任务只标相对人。
2. 金额未知不写零。质保金、违约金未结算不得填已确定主动债权。
3. 第 585 条调整未完成时，违约金不得按约定数字直接抵销完毕。
4. 借贷保证主轴转金融。

若：只有“我们互有往来”无具体债 → `依据不足`。

## 节点 2　法定抵销

运行时核验第 568 条。

1. 种类品质相同，通常为金钱之债最常见。
2. 主动债权到期。被动债权即使未到期，抵销效果须谨慎，标待核。
3. 通知到达对方时发生抵销。未通知不得写已经抵销。
4. 已读不等于到达。送达设计转送达原子。
5. 抵销不得附条件或期限。

## 节点 3　约定抵销与扣款

1. 合同允许以质量扣款、逾期扣款、对账余额抵销：核条款是否成为合同内容。
2. 格式扣款条款可能不成为内容或无效，转格式条款原子。
3. 扣款须对应已发生且可回链的事件，不得预扣未发生违约。
4. 约定抵销仍受效力强制性规范和禁止抵销规则约束。

## 节点 4　禁止抵销

运行时核验通则解释第 57 条和第 569 条。

1. 侵害自然人人身权益之债，侵权人不得主张抵销。
2. 故意或重大过失侵害财产权益之债，侵权人不得主张抵销。
3. 按性质不得抵销：抚养、工资生活必需、社会保险待遇等。劳动报酬主轴转劳动。
4. 约定不得抵销：有效约定应尊重。
5. `search_law` 返回已失效合同法解释（二）抵销条时，核验是否已被现行规则吸收，失效文本不得单独作为 `L#`。

## 节点 5　留置

1. 占有必须合法且持续。因侵权取得占有不得留置。
2. 同一法律关系：保管、运输、承揽常见。企业之间留置放宽规则须运行时核验。
3. 留置后应通知并给履行宽限期，实现方式不得私自处分隐瞒。
4. 不动产通常不成立留置。建设工程优先受偿转工程。
5. 抵押质押实现转金融，不在本任务设计拍卖方案。

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。

下一步按期限灭失、易失证据、改变本任务结论、可逆性排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。

禁止指导伪造、隐匿、威胁或违法取证。未知金额不写零。不把应诉写成放弃仲裁。不把立案日写成解除时点。
