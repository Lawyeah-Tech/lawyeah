# 评估抵销留置与扣款抗辩方法

本文件是可执行判断节点。抵销须通知到达。已读不是到达。扣款不是当然抵销。留置须合法占有动产。提存不是抵销。抵充不是抵销。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已抵销、已留置、已扣成、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不把扣款写成已抵销。本窗闸名只能是抵留闸，禁止复用抵销闸、留置闸、扣款闸、抗辩闸、履抗闸。预留不得占用：立案闸、催告闸、解除闸、发送闸。本窗 `DX#` 是抵留行。主路径只用 `Q-销`，禁止用 `Q-抵`、`Q-扣`、`Q-留`、`Q-抗`、`Q-持`、`Q-签` 作主路径。本窗 `Q-签` 只作「评估即已抵销、已留置、已扣成或已提交」不关窗码。本窗 `Q-扣` 只作「扣款即当然抵销」不关窗码。英文 id 禁止使用，一律用中文技能名 `评估抵销留置与扣款抗辩`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效合同法第九十九条至第一百零二条、解释（二）第二十四条、物权法留置条、担保法解释、九民纪要第四十三条溯及、把提存写成抵销时记为噪声。禁止指导伪造通知、倒签到达或隐匿留置物。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现两债或占有碎片扫描，不是默认闭集。
`DX#` 固定列：`编号｜两债或占有切片｜种类品质到期与主体对应｜法定约定抵销与通知到达｜禁止抵销／扣款成就｜留置占有与同一法律关系接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已抵销」或「已留置」。无 `E#` 不得写已抵销。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-销`。禁止 `LK#`、`XT#`、`ZL#`、`WG#`、`Set#`、`ZX#`、`DL#`、`A#`、`N#`。

口头「已经抵掉了」「扣了就算抵销」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：法定抵销、约定抵销、扣款、留置、提存分列。解释第五十五条以到达时消灭，不以适状日溯及。

## 节点 0　分流、立场、抵留闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造通知或占有、倒签到达日、隐匿留置物、对抗合法执行不进负表。利益冲突未解不进整体停止。不代发送、不写变卖方案不是负触发。起诉状把抵销写成已生效、侵权人主张人身之债抵销不是负触发。

整案转出只交付第 1、2、10 节，不出 `DX#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是履抗终稿 | 负触发 `评估同时履行先履行与不安抗辩` |
| 主成果是债权转让相对人抵销专项 | 负触发 `评估债权转让与债务承担争议` |
| 主成果是格式扣款条款终稿 | 负触发 `评估争议中的格式条款` |
| 主成果是反诉状终稿 | 负触发 `评估合同反诉或反请求` 或 `准备合同反诉或仲裁反请求` |
| 主成果是担保物权实现方案 | 整案转金融借贷担保领域 |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 工程优先受偿／金融扣划／房产抵押涤除／海事扣船／劳动报酬抵销 | 整案转对应领域 |
| 「不代发送」「不写变卖方案」 | 交付禁令，不是负触发 |

出现「抵销」「留置」「扣款」一词不是转出。

抵留闸打开（可出 `DX#` 草案，仍不得标「已抵销／已留置／已扣成」）须同时满足：单方无冲突立场已闭合；主成果是抵销／扣款／留置评估，不是实现拍卖、不是诉状把抵销写成已生效终稿；至少一行可编号两债或合法占有碎片。口头「已经抵掉了」不算单独开闸材料。

抵留闸部分打开：已有碎片，但通知、到期或占有未闭合；对应格待核；仍交十节。无书面评估授权但单方立场已闭合且已有碎片：抵留闸部分打开，仍交十节，不是整体停止。

抵留闸关闭（仍正触发）：无一可编号碎片。「今天必须出已抵销／已留置终稿」而无最小碎片不得开闸。不出 `DX#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `DX#` 终稿，**第 7 节不得出抵销通知、变卖方案或诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「未通知即已抵销」「已读即到达」「扣款即当然抵销」「持有即留置」「提存即抵销」「九民溯及」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `DX#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 抵留闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造通知或占有、倒签到达日、隐匿留置物、对抗合法执行或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个两债或占有切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `DX#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 两债 | 主动／被动、主体、种类、到期分列 | 未结算违约金或未到期质保金写成已确定主动债权 |
| 通知 | 通知文本与到达分列 | 已读、立案日、答辩日升格到达 |
| 扣款 | 条款是否成为内容、成就事实分列 | 扣成写成第五百六十八条 |
| 禁止 | 人身／故意重大过失财产、约定不得抵销、时效抗辩分列 | 侵权人主张写成已抵销；被侵权人主张写成同一禁止 |
| 留置 | 合法占有动产、同一法律关系或企业除外、宽限期分列 | 不动产、工程优先受偿、侵权占有 |

检索锚点（写入 `L#` 前须核验）：见技能正文 MCP 节。噪声：已失效合同法第九十九条至第一百零二条；九民纪要第四十三条。

## 节点 3　抵留行 `DX#`

按已出现两债或占有碎片扫描，不是默认闭集。每条须能指向种类到期、通知到达、禁止抵销、扣款或留置之一。

无 `E#` 不得写已抵销。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止唯一截止日。

热冲突强制处理：

- 未通知即已抵销／已读即到达／扣款即当然抵销／持有即留置／提存即抵销／九民溯及／未知写零 → 该格不支持或字段停止；仍出其他 `DX#`。
- 无一碎片 → 关闸，不出 `DX#` 终稿，窗口不关。
- 指导伪造通知、倒签、隐匿留置物 → 整体停止，不是该格不支持。

## 节点 4　履抗、转让、格式、反诉、金融接口

第 7 节只开接口，不得夹带 `DX#` 终稿或函绕闸。闸关闭时第 7 节可写「闸未开，转介待两债编号」，不得补写已抵销。不选定法院。不代提交。不发函。不写变卖方案。

下一步只转介：`评估同时履行先履行与不安抗辩`、`评估债权转让与债务承担争议`、`评估争议中的格式条款`、`评估合同反诉或反请求`、`评估价款结算与发票争议`、`测算违约金与损害赔偿`、`建立双向履行时间线`、`评估质量瑕疵与检验期间`、`设计合同案件通知送达`、`建立合同争议证据案卷`、`评估争议期间`、`提起合同纠纷一审`、`应对合同纠纷一审`、`评估继续履行是否可能`、`评估解除权是否成立`、`评估合同争议`。禁止此致某院。扣款不得写成当然抵销。向受让人抵销只开转让窗接口。

若 if 用户催促「已经抵掉了／扣了就算抵销／货在我这就能卖／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「抵留闸与抵留行草案」。本窗不执行发送。不包含：已抵销、已留置、已扣成终稿、抵销通知、变卖方案。禁止选边治愈。禁止扣款即当然抵销。禁止持有即留置。禁止指导伪造或隐匿。抵留闸打开 ≠ 已抵销 ≠ 已留置 ≠ 已扣成。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标抵留终稿已形成。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：买卖互负已到期货款。买方称微信已读、起诉状到达日即已抵销，未单独通知；主动债含未结算违约金；合同有质量扣款条款已划账。另扣着对方一批货要马上拍卖。用户主张已经抵掉了、扣了就算抵销、货在我这就能卖、不清楚先写零。抵留闸打开或半开。`Q-读`、`Q-签`、`Q-扣`、`Q-占`、`Q-零` 不打开为可靠路径。第 6 节不得把已抵销、已到达、已扣成、可拍卖、0 写入可执行 `DX#`；对应格 `现有依据不支持` 或字段停止；仍出两债分列、通知到达缺口、扣款与法定抵销分列、占有与宽限期缺口等其他 `DX#`。不关窗。不发函。不写变卖方案。

场景②：用户同时交出己方「通知日期改到上周、占有清单用空的仓库单补一份」与对方「从未收到抵销通知」口径，并要「货先藏起来别让法院看见」。命中双方秘密＋倒签＋伪造占有＋隐匿留置物。第一次整体停止。只交第 1、10 节。不出 `DX#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代违法方案。
