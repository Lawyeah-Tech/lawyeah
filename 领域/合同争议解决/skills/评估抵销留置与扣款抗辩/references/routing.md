# 边界与路由

## 正触发

一般合同一方主张抵销、扣款或留置，需要评估能否成立。从零、碎片、通知未核验、无书面评估授权仍正触发：有可编号两债或合法占有碎片则闸开或半开，出 `DX#` 草案，保持草案。本次不代发送、不写变卖方案是交付禁令，不是开窗条件。未通知即已抵销、扣款即当然抵销、持有即留置，仍正触发。起诉状把抵销写成已生效、侵权人主张人身之债抵销，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造通知或占有、倒签到达日、隐匿留置物、对抗合法执行的停止，优先于负触发。上述信号不在下表。不代发送不是负触发。「未通知即已抵销」「已读即到达」「扣款即当然抵销」「持有即留置」「提存即抵销」「九民溯及」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 履抗终稿 | `评估同时履行先履行与不安抗辩` |
| 债权转让相对人抵销专项 | `评估债权转让与债务承担争议` |
| 格式扣款条款终稿 | `评估争议中的格式条款` |
| 反诉状终稿 | `评估合同反诉或反请求` 或 `准备合同反诉或仲裁反请求` |
| 担保物权实现方案 | 金融借贷担保领域 |
| 争议总图 | `评估合同争议` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |
| 工程优先受偿／金融扣划／房产抵押涤除／海事扣船／劳动报酬抵销 | 对应领域 |

不得因「不代发送」或「不写变卖方案」关窗。拟抵留评估仍正触发，不得写成已抵销或已留置。

## 易混

本窗闸名只能是抵留闸，不是抵销闸，不是留置闸，不是扣款闸，不是抗辩闸，不是履抗闸。`DX#` 不是 `LK#`，不是 `Set#`，不是 `DL#`。主路径是 `Q-销`，不是 `Q-抵`，不是 `Q-扣`，不是 `Q-留`，不是 `Q-持`。`Q-抵` 是房地产抵押／抵扣分列码。`Q-持` 是代持窗主路径。`Q-抗` 是履抗窗主路径。抵销须通知到达。扣款不是当然抵销。留置须合法占有动产。提存不是抵销。抵充不是抵销。解释第五十五条以到达时消灭，九民纪要第四十三条溯及是噪声。已失效合同法第九十九条至第一百零二条不是现行。解释（二）第二十四条三个月异议已废。MCP 可能先返回担保法解释或担保制度解释第六十二条而漏第四百四十八条、第四百五十三条。「通知日期改到上周」「货先藏起来」整体停止。本窗不执行发送，不代提交。不选定法院。不发函。不写变卖方案。
