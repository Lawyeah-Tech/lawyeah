# 边界与路由

## 正触发

一般合同一方主张抵销、扣款或留置，需要评估能否成立。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 担保物权实现 | 金融借贷担保领域 |
| 债权转让后的抵销相对人 | `评估债权转让与债务承担争议` |
| 格式扣款条款效力 | `评估争议中的格式条款` |
| 价款结算总表 | `评估价款结算与发票争议` |
| 送达设计 | `设计合同案件通知送达` |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，只分流不回改 |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

一方要用另一笔债或扣住货物对抗付款时正触发。要把货卖掉实现担保物权时转金融。劳动工资抵销转劳动。
