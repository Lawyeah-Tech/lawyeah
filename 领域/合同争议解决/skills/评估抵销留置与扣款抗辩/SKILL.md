# 评估抵销留置与扣款抗辩

## 任务目标

在明确、无利益冲突的单方立场下（主张请求或抗辩一方或其受托律师，互斥），形成抵留评估草案：抵留闸、主体与强制接口、`Q#` 路径、`DX#` 抵留行（两债或占有切片／种类品质到期与主体对应／法定约定抵销与通知到达／禁止抵销或扣款成就／留置占有与同一法律关系接口／`E#` 回链）。本窗 `DX#` 是抵留行草案，不是已抵销证明，不是通知已到达，不是留置已成立，不是扣款已合法，不是变卖方案。本窗闸名只能是抵留闸，禁止复用抵销闸、留置闸、扣款闸、抗辩闸、履抗闸、形态闸、变故闸、结算闸、反诉闸、担保闸。预留不得占用：立案闸、催告闸、解除闸、发送闸。本窗主行只能是 `DX#`，禁止 `LK#`、`XT#`、`ZL#`、`WG#`、`Set#`、`ZX#`、`DL#`、`A#`。主路径只用 `Q-销`，禁止用 `Q-抵`、`Q-扣`、`Q-留`、`Q-抗`、`Q-辩`、`Q-持`、`Q-签` 作主路径。邻窗 `Q-销` 只作转介进本窗；本窗打开为主路径，不是已抵销、不是已留置、不是已扣成。本窗 `Q-签` 只作「评估即已抵销、已留置、已扣成或已提交」不关窗码。本窗 `Q-扣` 只作「扣款即当然抵销」不关窗码。抵留闸打开不等于已抵销不等于通知已到达不等于留置已成立不等于扣款已合法不等于可拍卖。抵销须通知到达。已读不是到达。立案日或答辩日不是到达日。诉讼中主张不是诉讼外通知已到达。扣款不是当然抵销。种类不同未经协商不是法定抵销。主动债权未到期不是可抵销。抵销不得附条件或期限。侵权人就其侵害自然人人身或故意重大过失侵害财产之债主张抵销，不予支持；被侵权人主张不是同一禁止。提存不是抵销。抵充不是抵销。留置须合法占有动产。侵权占有不是可留置。不动产不是留置。非企业无同一法律关系不是可商事留置。宽限期未满不是可实现。丧失占有不是仍可留置。工程优先受偿不是留置。未知不写零。不写发送版抵销通知。不写变卖方案。不选定法院。不代提交。不定罪。伤残等级与本窗无关，禁止折入。

`depends-on` 为空。主成果是履抗终稿转 `评估同时履行先履行与不安抗辩`。主成果是债权转让相对人抵销终稿转 `评估债权转让与债务承担争议`。主成果是格式扣款条款终稿转 `评估争议中的格式条款`。主成果是担保物权实现转金融借贷担保领域。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：一般合同一方主张抵销、扣款或留置，需要评估能否成立。「已经抵掉了」「扣了就算抵销」「扣着货就能卖」仍正触发，成果状态 `草案`。通知、到期、占有未核验仍正触发：有可编号两债或合法占有碎片则抵留闸打开或半开，第 6 节出 `DX#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出已抵销／已留置终稿」才关闸，仍交十节，第 6 节不出 `DX#` 终稿，第 7 节不得出抵销通知、变卖方案或诉状，窗口不关。用户要把未通知写成已抵销、把已读写成到达、把扣款写成当然抵销、把持有写成留置、把侵权占有写成可留置、把九民纪要溯及写成到达日前消灭、把未知写成零，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `DX#` 草案。人身侵权之债由侵权人主张抵销、起诉状把抵销写成已生效，仍正触发：该格不支持，不改负触发关窗。不得因「不代发送」「不写变卖方案」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是履抗终稿（转 `评估同时履行先履行与不安抗辩`）；
- 主成果是债权转让相对人抵销专项（转 `评估债权转让与债务承担争议`）；
- 主成果是格式扣款条款终稿（转 `评估争议中的格式条款`）；
- 主成果是反诉状终稿（转 `评估合同反诉或反请求` 或 `准备合同反诉或仲裁反请求`）；
- 主成果是担保物权实现、抵押权或质权变卖方案（金融借贷担保领域）；
- 主成果是争议总图（转 `评估合同争议`）；
- 尚未成争，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）；
- 建设工程优先受偿、金融扣划停贷、房地产抵押涤除、海事扣船、劳动报酬抵销专项主轴。

双方秘密、伪造抵销通知或扣款凭证或占有、倒签到达日、教唆隐匿留置物或对抗合法执行、违法取证**不在负触发表**，走整体停止。「未通知即已抵销」「已读即到达」「扣款即当然抵销」「持有即留置」「提存即抵销」「九民溯及」「未知写零」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不代发送」「不写变卖方案」是交付禁令，不是负触发。主成果才转；出现「抵销」「留置」「扣款」一词不是转出。

## 建立工作坐标

确认：评估授权；单方立场；两债主体种类到期金额来源；通知或占有碎片；法域。

口头「已经抵掉了」「扣了就算抵销」「货在我这就能卖」只登记 `S#`／`V#`。不得升格已抵销、已留置或已扣成，**不得单独算作开闸材料**。可编号两债或合法占有碎片可开闸。本窗不执行发送，不代提交，不写函或变卖方案。

立场只许主张请求或抗辩一方或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：抵留闸关闭，仍交十节，不是整体停止。无书面评估授权但单方立场已闭合、且已有碎片：抵留闸部分打开，仍交十节，不是整体停止。提出伪造抵销通知或扣款凭证或占有、倒签到达日、教唆隐匿留置物或对抗合法执行或违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`DX#` 抵留行；`V#` 版本；`E#` 证据形态回链（两债文本、通知到达形态、占有凭证，不是发送闸，不是已抵销证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`LK#`、`XT#`、`ZL#`、`WG#`、`Set#`、`ZX#`、`DL#`。技能正文中的条号是检索锚点，不是已核验 `L#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。未知不写零。未通知 ≠ 已抵销。已读 ≠ 到达。扣款 ≠ 当然抵销。持有 ≠ 留置。提存 ≠ 抵销。抵充 ≠ 抵销。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或裁判案例检索。本窗是评估，**不要**用 `search_template` 生成抵销通知、扣款函、留置变卖方案或诉状。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现未通知即已抵销、已读即到达、扣款即抵销、持有即留置、提存即抵销、九民纪要溯及的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效合同法第九十九条至第一百零二条、合同法解释（二）第二十三条、第二十四条三个月异议、物权法留置条、担保法及其解释、九民纪要第四十三条溯及至适状当作现行规则。第五百七十条至第五百七十四条提存不是抵销。MCP 可能先返回担保法解释或担保制度解释第六十二条而漏第四百四十八条、第四百五十三条，不得把失效解释或实现程序写成留置已成立。MCP 效力字段与公布施行日冲突时，以施行日为准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的已抵销、已留置或已扣成结论保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民法典第五百六十八条互负债务、种类品质相同，任何一方可以将自己的债务与对方的到期债务抵销，性质、约定或法定不得抵销除外；主张抵销应当通知对方，通知自到达对方时生效；抵销不得附条件或附期限。第五百六十九条种类品质不同经协商一致也可以抵销；扣款不是当然约定抵销。通则解释第五十五条抵销权成立的，认定通知到达对方时主债务、利息、违约金或损害赔偿金在同等数额内消灭，不以适状日溯及。噪声：九民纪要第四十三条溯及。解释第五十六条不足额抵销顺序参照第五百六十条、第五百六十一条；未知金额不写零；抵充不是抵销。解释第五十七条因侵害自然人人身权益，或故意、重大过失侵害他人财产权益产生的损害赔偿债务，侵权人主张抵销的，人民法院不予支持；被侵权人主张不是同一禁止。解释第五十八条以诉讼时效期间已经届满的债权通知抵销，对方提出时效抗辩的，对该抗辩应予支持；一方债权时效届满、对方主张抵销的，应予支持。第五百四十九条向受让人抵销只开债权转让窗接口。第四百四十七条债务人不履行到期债务，债权人可以留置已经合法占有的债务人的动产。第四百四十八条应当与债权属于同一法律关系，企业之间留置除外。第四百四十九条法定或约定不得留置的不得留置。第四百五十条可分物仅留与债务相当部分。第四百五十三条宽限期没有约定或约定不明确的，应当给债务人六十日以上履行期限，鲜活易腐除外；未满宽限期不得写可拍卖。噪声：物权法两个月。第四百五十五条实现转金融，本窗只红旗。第四百五十七条丧失占有或接受另行担保则消灭。第五百七十条至第五百七十四条提存是噪声，不是抵销。噪声：已失效合同法第九十九条至第一百零二条；解释（二）第二十四条。技能正文条号不是 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变通知到达、禁止抵销、同一法律关系或宽限期的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补未通知不是已抵销、已读不是到达、扣款不是法定抵销、非法占有不是留置、提存不是抵销的实务反例。实务把九民纪要第四十三条溯及或解释（二）三个月异议写成现行时记为噪声。
- `search_case_by_fact` 只比较事实差异与翻转条件：未通知不是已抵销；已读不是到达；扣款不是抵销；种类不同未经协商不是法定抵销；侵权占有不是可留置；非企业无同一关系不是可留置；宽限期未满不是可实现；提存不是抵销；九民溯及不是到达日前消灭。无类案不得写成已抵销、已留置或已扣成终稿。评估类禁止用 `search_template` 生成抵销通知、扣款函、变卖方案或诉状。

工具不可用时继续两债或占有碎片和 `DX#` 编目；已抵销、已留置、已扣成结论字段停止。不得拒跑，不得凭记忆写成已抵销或已留置。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、抵留闸与不关窗

主成果才整案转出。双方秘密、伪造通知、倒签、隐匿留置物第一次停。未通知即已抵销、扣款即当然抵销不关窗。闸关仍交十节，第 6 节不出 `DX#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

法定抵销、约定抵销、扣款、留置分列。本节禁止出 `DX#` 终稿。

### 3. 抵留闸与路径 `Q#`

本节禁止出 `DX#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-销`。

### 4. 抵留行 `DX#`

两债或占有切片、种类到期、通知到达、禁止抵销或扣款、留置占有。状态 `草案`。禁止升格已抵销、已留置、已扣成。无 `E#` 不得写已抵销。

### 5. 履抗、转让、格式、反诉、金融接口

履抗转履抗窗。向受让人抵销转债权转让窗。格式扣款转格式窗。实现变卖转金融。第 7 节不得夹带 `DX#` 终稿或函绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造抵销通知或扣款凭证或占有、倒签到达日、教唆隐匿留置物或对抗合法执行或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：抵留闸关闭，仍交十节，不是整体停止。无书面评估授权但有碎片：抵留闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：种类到期、通知到达、禁止抵销、同一法律关系、宽限期、施行日未核验。未通知即已抵销、已读即到达、扣款即当然抵销、持有即留置、提存即抵销、九民溯及、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `DX#` 草案。
- `目标停止`：主目标变为担保物权实现方案、发送版抵销通知或反诉状终稿。禁止把「扣款即当然抵销」当作用户错误主张时的目标停止；那是不关窗。

禁止指导伪造通知、倒签到达或隐匿留置物。不给胜诉率。不定罪。不选定法院。不代提交。未知不写零。不发函。不写变卖方案。

## 交付
