# 提起合同案件上诉方法

本文件是可执行判断节点。草稿不是已提起。口头不服不是已上诉。逾期不是当然仍可普通上诉。已生效不是可普通上诉。判决十五日与裁定十日不得混卡。已读不是送达起算。调解书不是普通上诉。对仲裁裁决不是普通上诉。未知不写零。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止改判率、已提起、已提交、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不保证改判。本窗闸名只能是上诉闸，禁止复用起诉闸、开庭闸、庭审闸、支付闸、仲裁闸。预留不得占用：立案闸、保全闸。本窗 `HS#` 是上诉行。主路径只用 `Q-上`，禁止用 `Q-诉`、`Q-辩`、`Q-开庭`、`Q-审`、`Q-申`、`Q-签` 作主路径。本窗 `Q-签` 只作「草稿即已提交」不关窗码。英文 id 禁止使用，一律用中文技能名 `提起合同案件上诉`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991 年第一百四十七条上诉期（现行第一百四十七条是被告缺席）、1991 年第一百七十一条认定无民事行为能力鉴定、2017 年第一百六十四条、把现行第一百四十七条缺席写成上诉期时记为噪声。禁止指导伪造上诉材料或倒签送达。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现裁判碎片扫描，不是默认闭集。
`HS#` 固定列：`编号｜范围切片｜送达与上诉期｜事实法律程序理由｜新证据接口｜一审请求边界｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已提起」或「已改判」。无 `E#` 不得写已提起。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-上`。禁止 `SS#`、`QT#`、`KT#`、`LF#`、`ZC#`、`A#`、`N#`。文件状态只用 `草案`、`停止`。

口头「判决刚到不服」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。一行一项主文。不写死唯一日历截止日。

实务上：口头表示上诉须在期限内递交上诉状，未递交视为未提起。未交上诉费可能按自动撤回。未上诉判项可能生效。超出一审请求不当然允许。可上诉裁定通常限于不予受理、管辖权异议、驳回起诉。

## 节点 0　分流、立场、上诉闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造上诉材料、倒签送达、虚假诉讼、违法取证不进负表。利益冲突未解不进整体停止。不代提交、不保证改判、不选定二审法院不是负触发。

整案转出只交付第 1、2、10 节，不出 `HS#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是庭审提纲 | 负触发 `准备合同案件庭审` |
| 主成果是一审起诉包 | 负触发 `提起合同纠纷一审` |
| 主成果是首次答辩 | 负触发 `应对合同纠纷一审` |
| 主成果是二审答辩 | 负触发 `应对合同案件二审` |
| 主成果是案卷编目终稿 | 负触发 `建立合同争议证据案卷` |
| 主成果是撤销裁决或不予执行终稿 | 负触发 `申请撤销仲裁裁决` |
| 主成果是再审整案 | 只开接口，本窗不出再审终稿 |
| 主成果是执行整案 | 负触发 `执行合同生效文书` 接口 |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程／金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不代提交」「不保证改判」「不选定二审法院」 | 交付禁令，不是负触发 |

出现「上诉」「不服」「二审」一词不是转出。

上诉闸打开须同时满足：单方无冲突上诉方立场已闭合；主成果是上诉状、范围、期限或理由，不是庭审提纲、不是一审起诉、不是再审、不是执行；至少一项可编号一审裁判或上诉期碎片。口头「不服」不算单独开闸材料。

上诉闸部分打开：已有碎片，但送达、期间或范围未闭合；仍交十节。

上诉闸关闭（仍正触发）：无一可编号碎片。不出 `HS#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `HS#` 终稿，**第 7 节不得出可提交上诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已提起」「口头不服即已上诉」「逾期当然仍可普通上诉」「已生效仍可普通上诉」「保证改判」「选定二审法院」「未知写零」**不关窗**。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 上诉闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造上诉材料、倒签送达、虚假诉讼或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个范围切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `HS#` 终稿。

| 受送达人 | 各当事人送达日分列 | 共用一个截止日 |

| 新证据 | 一审结束后新发现条件待核 | 逾期当然能用或当然失权 |

## 节点 3　上诉行 `HS#`

按已出现主文扫描，不是默认闭集。每条须能指向不服判项或上诉期之一。

无 `E#` 不得写已提起。状态默认 `草案`。一次只推荐下一步。未知不写零，不给改判率。送达、期间或范围未闭合不得标待提交。

热冲突强制处理：

- 草稿即已提起／口头不服即已上诉／逾期当然仍可／已生效仍可普通上诉／保证改判／选定二审法院／未知写零 → 该格不支持或字段停止；仍出其他 `HS#`。
- 无一碎片 → 关闸，不出 `HS#` 终稿，窗口不关。
- 指导伪造上诉材料、倒签送达 → 整体停止，不是该格不支持。

## 节点 4　庭审、一审、二审答辩、再审、撤销与执行接口

第 7 节只开接口，不得夹带 `HS#` 终稿或发送版上诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待上诉碎片编号」，不得补写已提起。不选定法院。不代提交。不保证改判。通过原审提出，不预填此致某中院。

下一步只转介：`准备合同案件庭审`、`应对合同案件二审`、`提起合同纠纷一审`、`应对合同纠纷一审`、`建立合同争议证据案卷`、`规划举证期限与证据交换`、`评估合同管辖与仲裁协议`、`评估合同争议`、`执行合同生效文书`、`申请撤销仲裁裁决`、`提起合同仲裁`、`谈判合同和解方案`、`提出合同案件管辖异议`、`准备合同财产保全申请`、`测算违约金与损害赔偿`、`评估合同调解方案与效力`、`准备合同反诉或仲裁反请求`。禁止此致某中院为已上诉。

若 if 用户催促「草稿写完就算提起了／嘴上说了就算上诉了／过期也能交／一定改判／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「上诉闸与上诉行草案」。本窗不执行发送。不包含：已提起终稿、已改判、一审起诉状、庭审提纲、再审、执行。禁止选边治愈。禁止草稿即已提起。禁止保证改判。禁止指导倒签送达。上诉闸打开 ≠ 已上诉 ≠ 已提交 ≠ 已改判。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标上诉终稿已形成。
风险档 A：伪造上诉材料、倒签送达必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：有一审判决书和送达回证碎片。用户主张草稿写完就算提起了、嘴上说了就算上诉了、微信已读那天开始算十五日、按 1991 年第一百四十七条、裁定也按十五日、一定改判、不清楚先写零。上诉闸打开或半开。`Q-签`、`Q-口`、`Q-达`、`Q-胜`、`Q-零` 不打开为可靠路径。第 6 节不得把已提起、已改判、0、此致某中院写入可执行 `HS#`；对应格 `现有依据不支持` 或字段停止；仍出范围分列、期间接口、理由缺口等其他 `HS#`。不关窗。不代提交。不保证改判。

场景②：用户同时交出上诉人「送达回证日期改到上周」与对方「根本没收到」口径。命中双方秘密＋倒签送达＋伪造上诉材料。第一次整体停止。只交第 1、10 节。不出 `HS#`。不得问代表哪一方后继续。不以「坚持」为门槛。
