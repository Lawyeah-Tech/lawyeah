# 边界与路由

## 正触发

不服尚未生效的一般合同裁判，需要上诉状、范围、期限或理由草稿。从零、碎片、送达未核验仍正触发：有可编号一审裁判或上诉期碎片则闸开或半开，出 `HS#` 草案，保持草案。本次不代提交、不保证改判、不选定二审法院是交付禁令，不是开窗条件。草稿即已提起、口头不服即已上诉，仍正触发。把逾期写成当然仍可、把已生效写成可普通上诉、把仲裁裁决写成可普通上诉，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造上诉材料、倒签送达的停止，优先于负触发。上述信号不在下表。不代提交不是负触发。「草稿即已提起」「口头不服即已上诉」「逾期当然仍可普通上诉」「已生效仍可普通上诉」「保证改判」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 庭审提纲 | `准备合同案件庭审` |
| 一审起诉包 | `提起合同纠纷一审` |
| 首次答辩 | `应对合同纠纷一审` |
| 二审答辩 | `应对合同案件二审` |
| 案卷编目终稿 | `建立合同争议证据案卷` |
| 撤销裁决或不予执行终稿 | `申请撤销仲裁裁决` |
| 再审整案 | 只开接口，本窗不出再审终稿 |
| 执行整案 | `执行合同生效文书` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不代提交」或「不保证改判」关窗。拟上诉草稿仍正触发，不得写成已提起或已改判。

## 易混

本窗闸名只能是上诉闸，不是起诉闸，不是开庭闸，不是庭审闸，不是立案闸。`HS#` 不是 `SS#`，不是 `QT#`，不是 `KT#`。主路径是 `Q-上`，不是 `Q-诉`，不是 `Q-开庭`，不是 `Q-审`。`SS#` 是公司治理上诉行，本窗分列 `HS#`。`开庭闸`／`KT#`／`Q-开庭` 是准备合同案件庭审。`起诉闸`／`QT#`／`Q-诉` 是提起合同纠纷一审。1991 年民事诉讼法第一百四十七条上诉期不是现行；现行第一百四十七条是被告缺席。1991 年第一百七十一条、第一百七十二条不是上诉状条。2017 年第一百六十四条须核对应现行第一百七十一条。1985 年涉外上诉期批复已失效。提出「把签收日改到上周」整体停止。本窗不代提交。不选定二审法院。不保证改判。
