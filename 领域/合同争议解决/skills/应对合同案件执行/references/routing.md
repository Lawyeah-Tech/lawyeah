# 边界与路由

## 正触发

一般合同被执行人已收到执行通知、执行裁定或等价执行碎片，需要执行行为异议、超标的或豁免主张、报告财产与合法履行安排草稿。从零、碎片、期限或豁免未核验仍正触发：有可编号执行通知、执行裁定、查封扣押冻结扣划通知、报告财产令、执行案号或协助执行碎片则闸开或半开，出 `YE#` 草案，保持草案。本次不代提交、不出执和终稿、不保证停止执行、不提供隐匿转移方案是交付禁令，不是开窗条件。草稿即已提出、申请异议即已停止执行，仍正触发。把实体不服写成执行异议、把生活住房写成当然豁免，仍正触发：该格不支持，不改负触发关窗。

双方秘密、隐匿转移、虚假报告的停止，优先于负触发。上述信号不在下表。不代提交不是负触发。「草稿即已提出」「申请异议即已停止执行」「实体不服即执行异议」「超标的即当然全部解除」「生活住房当然豁免」「未报告即当然拒执刑责」「执和违约不可恢复」「保证停止执行」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 申请执行包 | `执行合同生效文书` |
| 执行中和解协议终稿 | `准备合同执行和解` |
| 不予执行申请 | `申请不予执行仲裁裁决` |
| 撤裁申请 | `申请撤销仲裁裁决` |
| 保全复议或担保置换 | `应对合同案件保全裁定` |
| 私下和解要执行力 | `办理合同和解执行力补强` |
| 上诉状 | `提起合同案件上诉` |
| 案外人执行异议之诉 | `unavailable` |
| 复杂追加被执行人或拒执刑责终稿 | `unavailable` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不代提交」或「不提供隐匿转移方案」关窗。拟应执草稿仍正触发，不得写成已提出或已停止执行。

## 易混

本窗闸名只能是应执闸，不是执行闸，不是执申闸，不是不执闸，不是执和闸，不是保全闸，不是冻结闸，不是应保闸，不是应对闸，不是异议闸。`YE#` 不是 `ZE#`，不是 `BZ#`，不是 `TH#`，不是 `NS#`，不是 `FZ#`，不是 `ZX#`。主路径是 `Q-应执`，不是 `Q-执`，不是 `Q-执申`，不是 `Q-不执`，不是 `Q-冻`，不是 `Q-保`。`执行闸`／`ZE#`／`Q-执申` 是执行合同生效文书。`不执闸`／`BZ#`／`Q-不执` 是申请不予执行仲裁裁决。`执和闸`／`TH#`／`Q-执和` 预留给准备合同执行和解。`应保闸`／`NS#`／`Q-应保` 是应对合同案件保全裁定。`冻结闸`／`FZ#`／`Q-冻` 是公司治理应对股权冻结或行为保全。`Q-执` 是不关窗码。1991 年第二百三十六条不是行为异议。2017 年第二百二十五条不是现行第二百三十六条。2017 年第二百二十七条不是现行第二百三十八条。2017 年第二百四十一条不是现行报告财产条。现行第二百三十七条不是行为异议条。提出「把房子今晚过户给亲戚、财产申报先写没有」整体停止。本窗不代提交。不选定法院。不写发送版。不保证停止执行。不提供隐匿转移方案。
