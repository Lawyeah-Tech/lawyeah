# 应对合同案件执行方法

本文件是可执行判断节点。草稿不是已提出。申请异议不是已停止执行。实体不服不是执行异议。超标的不是当然全部解除。生活住房不是当然豁免。未报告不是当然拒执刑责。执和违约一般可恢复。未知不写零。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已提出、已停止执行、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不把草稿写成已提出，不提供隐匿转移方案。本窗闸名只能是应执闸，禁止复用执行闸、执申闸、不执闸、执和闸、保全闸、冻结闸、应保闸、答辩闸、应对闸。预留不得占用：立案闸、保全闸、执行闸、执和闸、不执闸。本窗 `YE#` 是应执行。主路径只用 `Q-应执`，禁止用 `Q-执`、`Q-执申`、`Q-不执`、`Q-冻`、`Q-保`、`Q-应`、`Q-辩`、`Q-签` 作主路径。本窗 `Q-执` 只作「草稿即已可强制执行、已立案、已控制财产或申请异议即已停止执行」不关窗码。本窗 `Q-签` 只作「草稿即已提出或已提交」不关窗码。本窗 `Q-停` 只作「申请异议即已停止执行」不关窗码。本窗 `Q-体` 只作「实体不服即执行异议」不关窗码。英文 id 禁止使用，一律用中文技能名 `应对合同案件执行`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991 年第二百三十六条中止终结裁定送达立即生效、1991 年第二百三十八条国际条约、1991 年第二百五十一条财产保全申请、1991 年第二百五十二条诉前保全三十日、2017 年第二百二十五条旧行为异议、2017 年第二百二十七条旧案外人异议、2017 年第二百三十条旧和解、2017 年第二百四十一条旧报告财产、把现行第二百三十七条超六个月未执行当成行为异议、把草稿写成已提出或把申请异议写成已停止执行时记为噪声。禁止指导隐匿转移、虚假报告或拒执。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现执行碎片扫描，不是默认闭集。
`YE#` 固定列：`编号｜名义与执行案切片｜送达与措施｜适格异议（行为违法／超标的／豁免）｜履行或分期接口｜不执／案外人／执和接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已提出」或「已停止执行」。无 `E#` 不得写已提出。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-应执`。禁止 `ZE#`、`ZX#`、`FZ#`、`BZ#`、`YC#`、`NS#`、`TH#`、`A#`、`N#`。期限嵌在行为异议／书面与期限：作出日／送达日／书面提出／十五日审查／十日复议分列，禁止一张截止卡，禁止另开 `K#` 为主行。豁免嵌查封规定第三条至第五条、第十九条与异议复议规定第二十条，禁止扩成一律不得执行。

口头「收到执行了」「异议交了就算停了」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：行为异议向负责执行的人民法院书面提出，不是保全复议五日。审查期间原则上不停止执行。案外人路径只开接口，之诉终稿 `unavailable`。对判决对错不服不是本窗异议闭集。不利证据必须进入最强反方，不得从草稿中删除。未知财产写 `未知`／`G#`，禁止编造没有或写零。

## 节点 0　分流、立场、应执闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、隐匿转移、虚假报告、伪造异议、倒签提出日、违法取证、指导拒执不进负表。利益冲突未解不进整体停止。不代提交、不出执和终稿、不保证停止执行、不提供隐匿转移方案不是负触发。

整案转出只交付第 1、2、10 节，不出 `YE#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是申请执行包 | 负触发 `执行合同生效文书` |
| 主成果是执行中和解协议终稿 | 负触发 `准备合同执行和解` |
| 主成果是不予执行申请 | 负触发 `申请不予执行仲裁裁决` |
| 主成果是撤裁申请 | 负触发 `申请撤销仲裁裁决` |
| 主成果是保全复议或担保置换 | 负触发 `应对合同案件保全裁定` |
| 主成果是私下和解要执行力 | 负触发 `办理合同和解执行力补强` |
| 主成果是上诉状 | 负触发 `提起合同案件上诉` |
| 主成果是案外人执行异议之诉 | 负触发 `unavailable` |
| 主成果是复杂追加被执行人或拒执刑责终稿 | 负触发 `unavailable` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程／金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不代提交」「不出执和终稿」「不保证停止执行」「不提供隐匿转移方案」 | 交付禁令，不是负触发 |

出现「执行」「异议」「查封」「报告财产」一词不是转出。同时要行为异议和履行安排：本窗正触发。只要执和终稿才负触发。

应执闸打开（可出 `YE#` 草案，仍不得标「已提出／已提交／已停止执行／豁免已准许」）须同时满足：单方无冲突被执行立场已闭合；主成果是执行应对草稿，不是申请执行包、不是执和终稿、不是不执终稿、不是案外人异议之诉、不是隐匿方案；至少一项可编号执行通知、执行裁定、查封扣押冻结扣划通知、报告财产令、执行案号或协助执行碎片。口头「收到执行了」不算单独开闸材料。PDF 可半开，不得单独起算异议审查或报告期。

应执闸部分打开：已有碎片，但送达日、异议期限、豁免条件或报告义务未闭合；对应格待核；仍交十节。无书面应执授权但单方立场已闭合且已有碎片：应执闸部分打开，仍交十节，不是整体停止。

应执闸关闭（仍正触发）：无一可编号碎片。「今天必须出已提出／已停止执行终稿」而无最小碎片不得开闸。不出 `YE#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `YE#` 终稿，**第 7 节不得出可提交异议书或已停止执行**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已提出」「已读即已送达」「网交即已提交」「申请异议即已停止执行」「实体不服即执行异议」「超标的即当然全部解除」「生活住房当然豁免」「未报告即当然拒执刑责」「执和违约不可恢复」「保证停止执行」「选定某院」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `YE#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 应执闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出隐匿转移或毁损被查封财产、虚假报告财产、伪造异议或送达回证、倒签提出日、违法取证或指导拒执，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

- 第二百三十六条：书面异议、十五日审查、十日复议。不是已停止执行。噪声：1991 年第二百三十六条；2017 年第二百二十五条；司法解释仍引第二百二十五条。

- 第二百三十七条：超六个月未执行，不是本窗异议条。
- 第二百四十一条：执行和解记入笔录；不履行可恢复。噪声：2017 年第二百三十条。
- 第二百五十一条：发出执行通知，并可以立即采取强制执行措施。噪声：1991 年第二百五十一条；2017 年第二百四十条。
- 第二百五十二条：报告财产；拒绝或虚假报告可以罚款、拘留。噪声：1991 年第二百五十二条；2017 年第二百四十一条。
- 查封规定第三条至第五条、第十九条。异议复议规定第七条、第二十条。审查期间原则上不停止执行，条号运行时核验。

## 节点 3　应执行 `YE#`

按已出现措施切片扫描，不是默认闭集。每条须能指向措施、名义与已履行、行为异议、超标的或豁免、报告财产或履行接口之一。

无 `E#` 不得写已提出或已停止执行。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止唯一截止日。禁止写入已停止执行或豁免已准许。实体不服未转接口不得标可提交异议闭集。

热冲突强制处理：

- 草稿即已提出／已读即已送达／网交即已提交／申请异议即已停止执行／实体不服即执行异议／超标的即当然全部解除／生活住房当然豁免／未报告即当然拒执刑责／执和违约不可恢复／保证停止执行／未知写零 → 该格不支持或字段停止；仍出其他 `YE#`。
- 无一碎片 → 关闸，不出 `YE#` 终稿，窗口不关。
- 指导隐匿转移、虚假报告、伪造异议、倒签、拒执 → 整体停止，不是该格不支持。

## 节点 4　执申、执和、不执、保全、案外人与上诉接口

第 7 节只开接口，不得夹带 `YE#` 终稿或可提交异议书绕闸。闸关闭时第 7 节可写「闸未开，转介待执行碎片编号」，不得补写已提出或已停止执行。不选定法院。不代提交。不写发送版。执和只开接口，本窗不出执和协议终稿。案外人异议之诉标 `unavailable`。不执只开 `申请不予执行仲裁裁决`。保全复议只开 `应对合同案件保全裁定`。

下一步只转介：`执行合同生效文书`、`准备合同执行和解`、`申请不予执行仲裁裁决`、`申请撤销仲裁裁决`、`办理合同和解执行力补强`、`应对合同案件保全裁定`、`评估合同调解方案与效力`、`起草合同和解协议`、`谈判合同和解方案`、`提起合同案件上诉`、`应对合同案件二审`、`评估合同争议`、`建立合同争议证据案卷`、`准备合同财产保全申请`、`申请合同金钱支付令`、`应对合同纠纷一审`、`评估债权人撤销权`、`准备债权人撤销权诉讼`。禁止此致某院升格管辖已定。申请异议不得写成已停止执行。实体不服不得写成执行异议闭集。执和只开接口。

若 if 用户催促「异议交了就算停了／唯一住房一律不能卖／不清楚先写零／今晚把账户转空」，then 该格 `现有依据不支持` 或字段停止；转空命中隐匿则整体停止，窗口在错误主张时不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「应执闸与应执行草案」。本窗不执行发送。不包含：已提出、发送版异议书、执和协议终稿、不予执行终稿、案外人异议之诉终稿、隐匿方案。禁止选边治愈。禁止申请异议即已停止执行。禁止实体不服即执行异议。禁止指导隐匿或虚假报告。应执闸打开 ≠ 已提出 ≠ 已停止执行。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标应执终稿已形成。
风险档 A：隐匿转移、虚假报告、伪造异议、倒签、指导拒执必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：买卖尾款判决进入执行，被执行人微信收到执行通知 PDF 和账户冻结裁定。用户主张异议交了就算停了、对判决金额不服就当执行异议、唯一住房一律不能卖、没报财产也不算拒执、不清楚的金额先写零、此致某中院保证停止执行。应执闸打开或半开。`Q-停`、`Q-体`、`Q-豁`、`Q-报`、`Q-签`、`Q-院`、`Q-胜`、`Q-零` 不打开为可靠路径。第 6 节不得把已停止执行、实体不服闭集、当然豁免、已提出、0 写入可执行 `YE#`；对应格 `现有依据不支持` 或字段停止；仍出措施分列、作出日与送达日缺口、第二百三十六条书面异议红旗、查封规定第四条可以查封不得拍卖、第二百五十二条报告义务等其他 `YE#`。不关窗。不代提交。不选定法院。

场景②：用户同时交出己方「必须认下来、异议日改到上周、把房子今晚过户给亲戚、财产申报先写没有」与申请执行人「从未收到履行」口径。命中双方秘密＋倒签＋隐匿转移＋虚假报告。第一次整体停止。只交第 1、10 节。不出 `YE#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代违法方案。
