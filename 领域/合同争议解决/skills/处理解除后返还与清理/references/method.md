# 处理解除后返还与清理方法

本文件是可执行判断节点。返还不是当然已返还。折价不是唯一必得价。保管费用不是当然由对方承担。结算清理条款不因终止失效。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已返还、已折价必得、已结清、选定法院、代提交、未知写零。本任务不定罪，不重判解除，不写发送版函，不写诉状。本窗闸名只能是清理闸，禁止复用返还闸、折价闸、结算闸、解除闸、发送闸。预留不得占用：立案闸、和解闸。本窗 `QL#` 是清理行。主路径只用 `Q-理`，禁止用 `Q-清`、`Q-票`、`Q-除`、`Q-函`、`Q-还`、`Q-签` 作主路径。本窗 `Q-签` 只作「处理即已返还、已结清或已提交」不关窗码。英文 id 禁止使用，一律用中文技能名 `处理解除后返还与清理`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效合同法第九十七条、第九十八条、把第五百八十五条顶替第五百八十四条时记为噪声。禁止指导毁损藏匿或伪造交接。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现标的碎片扫描，不是默认闭集。
`QL#` 固定列：`编号｜标的切片｜解除或终止假设｜返还或折价｜结算清理条款效力｜保管减损与金钱接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已返还」或「已折价必得」。无 `E#` 不得写已返还。返还或折价未闭合不得标 `待提交`。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-理`。禁止 `ZP#`、`JC#`、`HF#`、`FH#`、`JS#`、`DJ#`、`SJ#`、`A#`、`N#`。

口头「东西已经还了」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。解除是否成立只作输入假设。

实务上：尚未履行终止履行。已履行按履行情况和合同性质恢复原状或其他补救。不能返还则折价，不是写零。结算清理条款不因终止失效。

## 节点 0　分流、立场、清理闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造交接、指导毁损、倒签不进负表。利益冲突未解不进整体停止。不重判解除、不写发送版不是负触发。把返还写成已返还、把终止写成清理条款失效不是负触发。

整案转出只交付第 1、2、10 节，不出 `QL#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是解除权是否成立 | 负触发 `评估解除权是否成立` |
| 主成果是发送版解除通知 | 负触发 `准备解除通知` |
| 主成果是对解除通知的异议 | 负触发 `准备对合同解除通知的异议` |
| 主成果是价款发票结算 | 负触发 `评估价款结算与发票争议` |
| 主成果是精算工作表 | 负触发 `测算违约金与损害赔偿` |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 建设工程拆除或造价清理主轴 | 整案转建设工程领域 |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 「不重判解除」「不写发送版」「不写诉状」 | 交付禁令，不是负触发 |

出现「返还」「清理」一词不是转出。

清理闸打开（可出 `QL#` 草案，仍不得标「已返还／已折价必得／已结清」）须同时满足：单方无冲突立场已闭合；主成果是清理方案草案，不是发送版、不是诉状；至少一行可编号标的切片、占有或履行碎片。口头「东西已经还了」不算单独开闸材料。

清理闸部分打开：已有碎片，但返还、折价或清理条款未闭合；对应格待核；仍交十节。无书面授权但单方立场已闭合且已有碎片：清理闸部分打开，仍交十节，不是整体停止。

清理闸关闭（仍正触发）：无一可编号碎片。「今天必须出已返还／已折价终稿」而无最小碎片不得开闸。不出 `QL#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `QL#` 终稿，**第 7 节不得出发送版函或诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「返还即已返还」「折价即唯一必得」「保管费当然对方承担」「终止即清理条款失效」「口头即已返还」「不能原物返还即写零」「立案日即解除时点」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `QL#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 清理闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造返还或折价凭证、倒签解除或返还日、隐匿标的或已付款、指导毁损藏匿或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

一行一个标的切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `QL#` 终稿。不重判解除。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 假设 | 解除或终止来源、到达或副本送达分列 | 立案日即解除；本窗重判解除权 |
| 返还 | 原物能否返还、占有现状分列 | 口头升格已返还；占有即已返还 |
| 折价 | 不能返还时的折价情景分列 | 唯一必得价；不能返还写零 |

## 节点 3　清理行 `QL#`

按已出现标的碎片扫描，不是默认闭集。每条须能指向解除假设、返还或折价、结算清理条款或保管减损之一。

无 `E#` 不得写已返还。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止唯一必得清理总额。返还或折价未闭合不得标 `待提交`。

热冲突强制处理：

- 返还即已返还／折价即唯一必得／保管费当然对方／终止即清理条款失效／口头即已返还／不能原物返还即写零／立案日即解除／未知写零 → 该格不支持或字段停止；仍出其他 `QL#`。
- 无一碎片 → 关闸，不出 `QL#` 终稿，窗口不关。
- 指导毁损藏匿、伪造交接、倒签 → 整体停止，不是该格不支持。

## 节点 4　解除、结算、测算、保管接口

第 7 节只开接口，不得夹带 `QL#` 终稿、发送版函或诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待标的编号」，不得补写已返还。不选定法院。不代提交。不写发送版函。不写诉状。不重判解除。

下一步只转介：`评估合同争议`、`评估解除权是否成立`、`准备解除通知`、`准备对合同解除通知的异议`、`评估价款结算与发票争议`、`测算违约金与损害赔偿`、`评估定金罚则争议`、`评估抵销留置与扣款抗辩`、`评估同时履行先履行与不安抗辩`、`评估继续履行是否可能`、`评估质量瑕疵与检验期间`、`评估不可抗力情势变更与履行不能`、`建立双向履行时间线`、`建立合同争议证据案卷`、`谈判合同和解方案`、`提起合同纠纷一审`、`评估争议期间`、`准备催告履行或补救通知`。禁止此致某院。

若 if 用户催促「东西已经还了／终止了清理条款就没了／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「清理闸与清理行草案」。本窗不执行发送。不包含：已返还、已折价必得、已结清、发送版函、诉状。禁止选边治愈。禁止返还即已返还。禁止终止即清理条款失效。禁止指导毁损。清理闸打开 ≠ 已返还 ≠ 已折价 ≠ 已结清。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标清理终稿已形成。
风险档 A：伪造交接、倒签、指导毁损必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：买卖已交货，买方主张合同已解除要退货，口头说货已经还了，不能退的部分先写零，终止了违约金条款也没了，保管费全算卖方的，今天立案就算解除日。清理闸打开或半开。`Q-口`、`Q-原`、`Q-终`、`Q-费`、`Q-拟`、`Q-零` 不打开为可靠路径。第 6 节不得把已返还、0、条款失效、立案日解除写入可执行 `QL#`；对应格 `现有依据不支持` 或字段停止；仍出标的分列、解除假设待核、折价情景、567 条款效力、保管减损缺口等其他 `QL#`。不关窗。不重判解除。不写发送版。不写诉状。

场景②：用户同时交出己方「返还日改到上周、货先藏起来再说」与对方「货还在买方仓库」口径，并要「先按已返还写」。命中双方秘密＋倒签＋指导隐匿。第一次整体停止。只交第 1、10 节。不出 `QL#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代违法方案。
