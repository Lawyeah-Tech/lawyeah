# 边界与路由

## 正触发

解除或终止后需要返还、折价、保管或结算清理。从零、碎片、解除假设未核验、无书面授权仍正触发：有可编号标的切片、占有或履行碎片则闸开或半开，出 `QL#` 草案，保持草案。本次不重判解除、不写发送版是交付禁令，不是开窗条件。返还即已返还、终止即清理条款失效，仍正触发。把折价写成唯一必得、把不能原物返还写成零，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造交接、指导毁损、倒签的停止，优先于负触发。上述信号不在下表。不重判解除不是负触发。「返还即已返还」「折价即唯一必得」「保管费当然对方承担」「终止即清理条款失效」「口头即已返还」「不能原物返还即写零」「立案日即解除时点」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 解除权是否成立 | `评估解除权是否成立` |
| 发送版解除通知 | `准备解除通知` |
| 对解除通知的异议 | `准备对合同解除通知的异议` |
| 价款发票结算 | `评估价款结算与发票争议` |
| 精算工作表 | `测算违约金与损害赔偿` |
| 争议总图 | `评估合同争议` |
| 建设工程拆除或造价清理 | 建设工程领域 |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不重判解除」或「不写发送版」关窗。拟清理方案仍正触发，不得写成已返还或已折价。

| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |

一般买卖或服务夹带专项背景时，专项段只分流。出现「返还」「清理」一词不是转出。C 端只要大众退货填空页时只分流，不把本包降成填空式结论，不回改。

## 易混

本窗闸名只能是清理闸，不是返还闸，不是折价闸，不是结算闸，不是解除闸，不是发送闸。`QL#` 不是 `ZP#`，不是 `JC#`，不是 `HF#`，不是 `FH#`，不是 `SJ#`。主路径是 `Q-理`，不是 `Q-清`，不是 `Q-还`，不是 `Q-票`，不是 `Q-除`。`Q-清` 在争议窗、结算窗禁作主路径，邻窗只转介进本窗。`Q-还` 是公司治理代持还原主路径。`FH#` 是合规返还行。`结算闸`／`Q-票` 是评估价款结算与发票争议。`解除闸`／`Q-除` 是评估解除权是否成立。返还不是当然已返还。折价不是唯一必得价。结算清理条款不因终止失效。已失效合同法第九十七条、第九十八条不是现行。「返还日改到上周」「货先藏起来再说」整体停止。本窗不执行发送，不代提交。不选定法院。不写发送版函。不写诉状。不重判解除。
