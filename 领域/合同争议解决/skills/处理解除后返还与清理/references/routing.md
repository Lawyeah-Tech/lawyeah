# 边界与路由

## 正触发

解除或终止后需要返还、折价、保管或结算清理。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 重判解除 | `评估解除权是否成立` |
| 异议 | `准备对合同解除通知的异议` |
| 测算 | `测算违约金与损害赔偿` |
| 结算价款 | `评估价款结算与发票争议` |
| 继续履行可能 | `评估继续履行是否可能` |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，只分流不回改 |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

解除或终止之后怎么还东西、怎么算账时正触发。还在吵能不能解除时转解除权或异议。
