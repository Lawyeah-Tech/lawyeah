# 处理解除后返还与清理

## 任务目标

在明确、无利益冲突的单方立场下（主张返还或清理一方、占有标的一方或其受托律师，互斥），形成清理方案草案：清理闸、主体与强制接口、`Q#` 路径、`QL#` 清理行（标的切片／解除或终止假设／返还或折价／结算清理条款效力／保管减损与金钱接口／`E#` 回链）。本窗 `QL#` 是清理行草案，不是已返还证明，不是已折价必得，不是保管费已转嫁，不是发送版函，不是诉状，不是精算终稿。本窗闸名只能是清理闸，禁止复用返还闸、折价闸、结算闸、解除闸、发送闸、保管闸、精算闸。预留不得占用：立案闸、和解闸。本窗主行只能是 `QL#`，禁止 `ZP#`、`JC#`、`HF#`、`FH#`、`JS#`、`DJ#`、`SJ#`、`A#`。主路径只用 `Q-理`，禁止用 `Q-清`、`Q-票`、`Q-除`、`Q-函`、`Q-还`、`Q-结`、`Q-签` 作主路径。邻窗 `Q-清` 只作转介进本窗；本窗打开为主路径，不是已返还、不是已折价、不是已结清。本窗 `Q-除` 只转介 `评估解除权是否成立`。本窗 `Q-函` 只转介 `准备解除通知`。本窗 `Q-票` 只转介 `评估价款结算与发票争议`。本窗 `Q-签` 只作「处理即已返还、已结清或已提交」不关窗码。清理闸打开不等于已解除不等于已返还不等于已折价不等于已结清不等于结算清理条款已失效不等于待提交终稿。返还不是当然已返还。折价不是唯一必得价。保管费用不是当然由对方承担。终止不是结算清理条款失效。口头不是已返还。不能返还原物不是写零。立案日不是解除时点。本窗不重判解除是否成立。未知不写零。不执行发送。不写发送版函。不写诉状。不选定法院。不代提交。不定罪。伤残等级与本窗无关，禁止折入。

`depends-on` 为空。主成果是解除权评估终稿转 `评估解除权是否成立`。主成果是发送版解除通知转 `准备解除通知`。主成果是价款发票结算转 `评估价款结算与发票争议`。主成果是精算工作表转 `测算违约金与损害赔偿`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：解除或终止后需要返还、折价、保管或结算清理。「东西已经还了」「终止了清理条款就没了」仍正触发，成果状态 `草案`。解除假设、标的、折价未核验仍正触发：有可编号标的切片、占有或履行碎片则清理闸打开或半开，第 6 节出 `QL#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出已返还／已折价终稿」才关闸，仍交十节，第 6 节不出 `QL#` 终稿，第 7 节不得出发送版函或诉状，窗口不关。用户要把返还写成已返还、把折价写成唯一必得、把保管费写成当然对方承担、把终止写成清理条款失效、把口头写成已返还、把不能原物返还写成零、把立案日写成解除时点、把未知写成零，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `QL#` 草案。不得因「不重判解除」「不写发送版」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是解除权是否成立（转 `评估解除权是否成立`）；
- 主成果是发送版解除通知（转 `准备解除通知`）；
- 主成果是对解除通知的异议（转 `准备对合同解除通知的异议`）；
- 主成果是价款发票结算（转 `评估价款结算与发票争议`）；
- 主成果是精算工作表（转 `测算违约金与损害赔偿`）；
- 主成果是争议总图（转 `评估合同争议`）；
- 建设工程拆除或造价清理主轴（转建设工程领域）；
- 尚未成争，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）。

双方秘密、伪造返还或折价凭证、倒签解除或返还日、隐匿标的或已付款、指导毁损藏匿、违法取证**不在负触发表**，走整体停止。「返还即已返还」「折价即唯一必得」「保管费当然对方承担」「终止即清理条款失效」「口头即已返还」「不能原物返还即写零」「立案日即解除时点」「未知写零」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不重判解除」「不写发送版」「不写诉状」是交付禁令，不是负触发。主成果才转；出现「返还」「清理」一词不是转出。

## 建立工作坐标

确认：清理授权；单方立场；解除或终止假设来源；标的占有与履行情况；结算清理条款；保管现状；法域。

口头「东西已经还了」「终止了清理条款就没了」只登记 `S#`／`V#`。不得升格已返还、已折价、已结清或已解除，**不得单独算作开闸材料**。可编号标的切片、占有或履行碎片可开闸。本窗不执行发送，不代提交，不写发送版函，不写诉状，不选定法院。不重判解除。

立场只许主张返还或清理一方、占有标的一方或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：清理闸关闭，仍交十节，不是整体停止。无书面授权但单方立场已闭合、且已有碎片：清理闸部分打开，仍交十节，不是整体停止。提出伪造返还或折价凭证、倒签解除或返还日、隐匿标的或已付款、指导毁损藏匿或违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`QL#` 清理行；`V#` 版本；`E#` 证据形态回链（标的、占有、交接、结算清理条款、授权，不是发送闸，不是已返还证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`ZP#`、`JC#`、`HF#`、`FH#`、`JS#`、`DJ#`、`SJ#`。技能正文中的条号是检索锚点，不是已核验 `L#`。文件状态只用 `草案`、`待提交`、`停止`。返还或折价未闭合不得标 `待提交`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。未知不写零。返还 ≠ 已返还。折价 ≠ 唯一必得。终止 ≠ 清理条款失效。立案日 ≠ 解除时点。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或文书范本检索。本窗是清理方案草稿，范本只借返还清单、结算清理表或保管交接栏目，**不要**升格「已返还／已折价／已结清／已解除」，**不要**改写成发送版解除函或诉状。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现返还即已返还、折价即必得、保管费当然对方、终止即清理条款失效、不能原物返还即写零的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效合同法第九十七条、第九十八条当作现行。不得把第五百八十五条顶替第五百八十四条损失接口。买卖解释第二十条仅买卖因违约解除后可继续主张违约金条款，服务合同不得直接套。MCP 效力字段与公布施行日冲突时，以施行日为准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的返还、折价、结算清理或保管减损保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民法典第五百六十六条合同解除后尚未履行的终止履行；已经履行的根据履行情况和合同性质可以请求恢复原状或其他补救，并有权请求赔偿损失；因违约解除的，解除权人可以请求违约责任，另有约定除外。第五百六十七条终止不影响结算和清理条款。第五百五十八条终止后通知、协助、保密、旧物回收。第五百八十四条损失分列，不得把第五百八十五条过分高于顶替损失计算。第五百五十七条合同解除亦为终止。噪声：已失效合同法第九十七条、第九十八条；立案日即解除时点；终止即清理条款失效。技能正文条号不是 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变返还、折价、结算清理或保管减损的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补口头不是已返还、终止不是清理条款失效、不能原物返还不是写零、折价不是唯一必得、保管费不是当然对方承担、立案日不是解除时点的实务反例。
- `search_template` 只借返还清单、结算清理表或保管交接栏目（项目／性质／假设解除生效／凭证／未知／互斥）。范本落款、此致某院、已结清句、返还完毕栏、金额栏不得升格已返还、已折价、已结清或已解除。禁止用发送版解除函、催告函或诉状改头换面。禁止用范本生成发送版或诉状。禁止用法院执行发还清单改头换面。

工具不可用时继续标的碎片和 `QL#` 编目；已返还、已折价、已结清字段停止。不得拒跑，不得凭记忆写成已返还或必得折价。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、清理闸与不关窗

主成果才整案转出。双方秘密、伪造交接、指导毁损第一次停。返还即已返还、终止即清理条款失效不关窗。闸关仍交十节，第 6 节不出 `QL#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

解除或终止假设、标的占有、返还或折价、结算清理条款、保管减损分列。本节禁止出 `QL#` 终稿。不重判解除。

### 3. 清理闸与路径 `Q#`

本节禁止出 `QL#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-理`。

### 4. 清理行 `QL#`

标的切片、解除或终止假设、返还或折价、结算清理条款效力、保管减损与金钱接口。状态 `草案`。禁止升格已返还、已折价、已结清。无 `E#` 不得写已返还。返还或折价未闭合不得标 `待提交`。

### 5. 解除、结算、测算、保管接口

解除权转解除窗。价款结算转结算窗。精算转测算窗。第 7 节不得夹带 `QL#` 终稿、发送版函或诉状绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造返还或折价凭证、倒签解除或返还日、隐匿标的或已付款、指导毁损藏匿或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：清理闸关闭，仍交十节，不是整体停止。无书面授权但有碎片：清理闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：解除假设、返还、折价、结算清理、保管减损、施行日未核验。返还即已返还、折价即唯一必得、保管费当然对方承担、终止即清理条款失效、口头即已返还、不能原物返还即写零、立案日即解除时点、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `QL#` 草案。
- `目标停止`：主目标变为重判解除、发送版解除通知或精算终稿。禁止把「返还即已返还」或「终止即清理条款失效」当作用户错误主张时的目标停止；那是不关窗。

禁止指导毁损、藏匿或伪造交接。不给胜诉率。不定罪。不选定法院。不代提交。未知不写零。不写发送版函。不写诉状。不输出唯一必得清理总额。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。清理闸关闭仍交十节，第 6 节不出 `QL#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `QL#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。清理闸未打开时不得交付「已返还」或「已折价」。边界见 [路由](references/routing.md)。
