# 规划举证期限与证据交换方法

本文件是可执行判断节点。逾期不是当然失权。协商期限须法院准许。不得一律十五日或三十日。作出日不是送达日。已读不是送达起算。网交回执不是已交换。目录不是已质证。延长须届满前书面。未知不写零。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已交换、已失权、选定法院、代提交、未知写零。本任务不定罪，不保证采纳，不指导伪造逾期理由。本窗闸名只能是举证闸，禁止复用期间闸、证据闸、时线闸、交换闸、举期闸。预留不得占用：立案闸、和解闸、期间闸、证据闸、时线闸、鉴异闸。本窗 `JQ#` 是举证行。主路径只用 `Q-举证`，禁止用 `Q-举`、`Q-期`、`Q-据`、`Q-历`、`Q-换`、`Q-交`、`Q-证`、`Q-签` 作主路径。本窗 `Q-签` 只作「计划即已交换、已提交或已失权」不关窗码。本窗 `Q-失` 只作「逾期即当然失权」不关窗码。本窗 `Q-日` 只作「唯一截止日」不关窗码。英文 id 禁止使用，一律用中文技能名 `规划举证期限与证据交换`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991 年民事诉讼法第一百三十六条中止诉讼、2017 年第六十五条、2015 年解释第九十九条、2001 年证据规定第三十三条不少于三十日或第五十一条质证顺序、把逾期写成当然失权时记为噪声。禁止指导伪造逾期理由或隐匿证据。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现通知切片扫描，不是默认闭集。
`JQ#` 固定列：`编号｜通知切片｜指定期限与起算｜目录与待证绑定｜逾期与补证｜交换方式与回证｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已交换」或「已失权」。无 `E#` 不得写已交换或已提交。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-举证`。禁止 `JE#`、`QJ#`、`SX#`、`JZ#`、`A#`、`N#`。文件状态只用 `草案`、`停止`。

口头「逾期了也必须全收」「过期一律作废」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：普通程序指定不得少于十五日，不是一律十五日也不是旧三十日。简易不得超过十五日，小额一般不超过七日。协商须法院准许。延长须届满前书面。逾期分层：客观原因或对方未异议视为未逾期；非故意重大过失应采纳可训诫；故意重大过失一般不采纳，但与基本事实有关仍应采纳并训诫、罚款。证据交换之日举证期限届满。仲裁按该机构规则，不得套法院十五日。

## 节点 0　分流、立场、举证闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造逾期理由、伪造新发现、隐匿证据、倒签提交日、违法取证不进负表。利益冲突未解不进整体停止。不代提交、不保证采纳不是负触发。

整案转出只交付第 1、2、10 节，不出 `JQ#` 终稿。

出现「举证」「交换」一词不是转出。

举证闸打开（可出 `JQ#` 草案，仍不得标「已交换／已提交／已失权」）须同时满足：单方无冲突立场已闭合；主成果是举证期限与交换计划，不是案卷终稿、不是庭审提纲、不是已失权裁定；至少一项可编号举证通知、指定期限、待交换目录或逾期风险碎片。口头「逾期了也必须全收」不算单独开闸材料。尚未立案不得开本窗闸。

举证闸部分打开：已有碎片，但送达起算、程序类型或交换渠道未闭合；对应格待核；仍交十节。无书面授权但单方立场已闭合且已有碎片：举证闸部分打开，仍交十节，不是整体停止。

举证闸关闭（仍正触发）：无一可编号碎片。「今天必须出已交换终稿」而无最小碎片不得开闸。不出 `JQ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `JQ#` 终稿，**第 7 节不得出已交换、已失权或已质证**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「逾期即当然失权」「口头协商即已改期」「一律十五日或三十日」「作出日即送达起算」「已读或网交即已交换」「目录即已质证」「计划即已提交」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `JQ#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 举证闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造逾期理由、伪造新发现、隐匿证据、倒签提交日或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 3　举证行 `JQ#`

按已出现通知切片扫描，不是默认闭集。每条须能指向通知、期限、目录或逾期风险之一。

无 `E#` 不得写已交换或已提交。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止写入已失权或唯一截止日。期限或送达未闭合不得标待提交。

热冲突强制处理：

- 逾期即当然失权／口头协商即已改期／一律十五日或三十日／作出日即送达起算／已读或网交即已交换／目录即已质证／未知写零 → 该格不支持或字段停止；仍出其他 `JQ#`。
- 无一碎片 → 关闸，不出 `JQ#` 终稿，窗口不关。
- 指导伪造逾期理由、隐匿证据、倒签提交日 → 整体停止，不是该格不支持。

## 节点 4　案卷、庭审、鉴定与调查接口

第 7 节只开接口，不得夹带 `JQ#` 终稿或已失权绕闸。闸关闭时第 7 节可写「闸未开，转介待事项编号」，不得补写已交换。不选定法院。不代提交。不写质证提纲。鉴定、调查、证据保全申请原则上举证期限届满前只开接口，本窗不出申请终稿。

下一步只转介：`建立合同争议证据案卷`、`准备合同案件庭审`、`申请律师调查令或法院调查取证`、`准备质量或损失鉴定申请`、`提出合同鉴定异议或重新鉴定`、`保全质量现场与电子证据`、`准备合同案件公证保全`、`评估争议期间`、`建立双向履行时间线`、`评估电子合同成立与送达`、`提起合同纠纷一审`、`应对合同纠纷一审`、`评估合同反诉或反请求`、`准备合同反诉或仲裁反请求`、`评估合同管辖与仲裁协议`、`提起合同仲裁`、`应对合同仲裁`、`评估合同争议`。禁止此致某院。

若 if 用户催促「逾期一律作废／口头商量过就算改期／不清楚先写十五日／网交了就算交换完」，then 该格 `现有依据不支持` 或字段停止。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「举证闸与举证行草案」。本窗不代提交。不包含：已交换、已失权、已质证终稿、案卷终稿、庭审提纲。禁止选边治愈。禁止逾期即当然失权。禁止指导伪造逾期理由。举证闸打开 ≠ 已交换 ≠ 已提交 ≠ 已失权。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：买卖合同已立案，法院指定举证期。原告部分证据逾期提交，主张必须一律采纳；被告主张逾期一律失权。双方曾口头商量延长但未经法院准许。原告把网上办案平台上传回执当成已经完成证据交换，把证据目录当成已经质证，把通知作出日当成起算，不清楚就写十五日或旧三十日。举证闸打开或半开。`Q-失`、`Q-口`、`Q-律`、`Q-读`、`Q-交`、`Q-证`、`Q-零` 不打开为可靠路径。第 6 节不得把已失权、已准许改期、已交换、已质证、0、唯一十五日写入可执行 `JQ#`；对应格 `现有依据不支持` 或字段停止；仍出通知分列、送达与作出分列、逾期分层、交换回证缺口等其他 `JQ#`。不关窗。不代提交。

场景②：用户同时交出己方「必须把不利合同藏起来」与对方「从未收到举证通知」口径，并要「倒签提交日、编一套新发现理由」。命中双方秘密＋隐匿＋伪造逾期理由＋倒签。第一次整体停止。只交第 1、10 节。不出 `JQ#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代隐匿方案。
