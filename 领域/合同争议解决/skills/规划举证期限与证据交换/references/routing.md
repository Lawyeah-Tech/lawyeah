# 边界与路由

## 正触发

一般合同诉讼或仲裁已立案，需规划举证期限、目录绑定、逾期分层与交换回证。从零、碎片、送达未核验仍正触发：有可编号举证通知、指定期限、待交换目录或逾期风险碎片则闸开或半开，出 `JQ#` 草案，保持草案。本次不代提交、不保证采纳是交付禁令，不是开窗条件。逾期即当然失权、口头协商即已改期，仍正触发。把网交回执写成已交换、把目录写成已质证，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造逾期理由、隐匿证据的停止，优先于负触发。上述信号不在下表。不代提交不是负触发。「逾期即当然失权」「口头协商即已改期」「一律十五日或三十日」「作出日即送达起算」「已读或网交即已交换」「目录即已质证」「保证采纳」不在下表。

| 主要目标 | 路由 |

| 整本案卷矩阵 | `建立合同争议证据案卷` |

| 调查令或法院调查 | `申请律师调查令或法院调查取证` |

| 时效或除斥评估 | `评估争议期间` |

不得因「不代提交」或「不保证采纳」关窗。拟期限与交换计划仍正触发，不得写成已交换或已失权。

## 易混

本窗闸名只能是举证闸，不是期间闸，不是证据闸，不是时线闸，不是交换闸，不是举期闸。`JQ#` 不是 `JE#`，不是 `QJ#`，不是 `SX#`，不是 `JZ#`。主路径是 `Q-举证`，不是 `Q-举`，不是 `Q-期`，不是 `Q-据`，不是 `Q-历`，不是 `Q-交`。`期间闸`／`QJ#`／`Q-期` 是评估争议期间。`证据闸`／`JE#`／`Q-据` 是建立合同争议证据案卷。`时线闸`／`SX#`／`Q-历` 是建立双向履行时间线。`JZ#` 是公司治理减资行。`Q-举` 是设立窗已选举。邻窗 `Q-举证` 只转介进本窗。逾期不是当然失权。协商期限须法院准许。不得一律十五日或三十日。1991 年民事诉讼法第一百三十六条中止诉讼不是审理前准备。2017 年第六十五条须核对应现行第六十八条。2001 年证据规定第三十四条视为放弃举证权利不是现行规则。提出「把不利合同藏起来、编一套新发现理由」整体停止。本窗不代提交。不选定法院。不写已失权。不保证采纳。
