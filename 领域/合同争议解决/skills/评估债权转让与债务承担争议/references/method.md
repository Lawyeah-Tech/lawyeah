# 债权转让与债务承担评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然结果或唯一必得总额。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。实务检索若出现“违约金不超过合同标的百分之三十”，记为噪声。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

应诉答辩或提出反诉，不等于当然放弃仲裁协议。解除通知到达对方时解除；未通知而起诉或申请仲裁主张解除的，仅在该主张获确认后，自起诉状或仲裁申请书副本送达时解除，不得把立案日写成解除时点。第 585 条“过分高于”对照违约造成的损失，不对照合同总价。

## 节点 1　交易定性

1. 债权转让、债务免责承担、债务加入、权利义务一并转让分列。
2. 保理、资产证券化、银行出让信贷资产：金融专项转出。
3. 名称是“对账单确认给第三方”但无转让意思：定性 `依据不足`。
4. 公司合并分立导致承继：标接口，不做公司治理方案。

## 节点 2　可转让性

运行时核验第 545 条。

1. 人身属性、特定服务请求权可能不得转让。
2. 禁止转让特约：区分金钱与非金钱、是否善意第三人。
3. 从权利一并转让，专属于债权人自身的除外。
4. 部分转让须可分，并明确通知范围。

## 节点 3　通知

运行时核验第 546 条。

1. 对债务人生效以通知到达为准，不是转让合同签订日，也不是立案日。
2. 让与人或受让人均可通知，但受让人通知时通常需证明转让事实。
3. 通知内容应足以识别债权。金额不明不写零。
4. 重复转让：先到达的通知优先对抗债务人履行，内部效力另判。
5. 禁止指导倒签通知或伪造签收。

## 节点 4　债务承担

运行时核验第 551–554 条。

1. 免责的债务承担：债务人将债务转移，须债权人同意。未同意不发生免责效果。
2. 债务加入：第三人表示加入，债权人可在其愿意承担范围内请求连带。
3. 新债务人可主张原债务人对债权人的抗辩。
4. 未经债权人同意的“内部转包债务”只在内部有效。

## 节点 5　抗辩、抵销、争议解决

1. 债务人接到通知后，向受让人主张对让与人的抗辩。
2. 抵销：债务人的债权先于转让或同时到期等条件按第 549 条核验。
3. 仲裁或管辖条款是否随同约束受让人：运行时核验，不得凭记忆一概而论。
4. 应诉新诉讼不等于放弃对仲裁条款的异议。
5. 需要起诉受让人或新债务人：转一审或仲裁申请原子，本任务不出诉状。

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。

下一步按期限灭失、易失证据、改变本任务结论、可逆性排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。

禁止指导伪造、隐匿、威胁或违法取证。未知金额不写零。不把应诉写成放弃仲裁。不把立案日写成解除时点。
