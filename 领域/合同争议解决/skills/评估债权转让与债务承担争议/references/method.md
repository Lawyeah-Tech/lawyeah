# 评估债权转让与债务承担争议方法

本文件是可执行判断节点。转让须通知到达。已读不是到达。未通知不是对债务人生效，也不是让与合同无效。免责须债权人同意，未表示视为不同意。加入不是免责承担。内部转债不是对债权人免责。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已对债务人生效、已免责、已加入、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不把加入写成免责。本窗闸名只能是转承闸，禁止复用转让闸、承担闸、加入闸、抵留闸、变更闸。预留不得占用：立案闸、催告闸、解除闸、发送闸、变更闸。本窗 `RY#` 是转承行。主路径只用 `Q-与`，禁止用 `Q-转`、`Q-让`、`Q-承`、`Q-移`、`Q-签` 作主路径。本窗 `Q-签` 只作「评估即已对债务人生效、已免责承担或已提交」不关窗码。本窗 `Q-知` 只作「未通知即对债务人生效」不关窗码。本窗 `Q-入` 只作「加入即免责承担」不关窗码。英文 id 禁止使用，一律用中文技能名 `评估债权转让与债务承担争议`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效合同法第七十九条至第八十六条、合同法解释（一）第二十七条至第二十九条、法释〔2001〕12 号报纸公告、把加入写成免责、把通则解释第五十二条当让与条时记为噪声。禁止指导伪造通知、倒签到达或隐匿通知。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现关系碎片扫描，不是默认闭集。
`RY#` 固定列：`编号｜关系切片（转让／加入／免责承担）｜可转让性或同意要件｜通知到达或债权人同意｜抗辩抵销延续｜相对人与论坛接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已对债务人生效」或「已免责」。无 `E#` 不得写已对债务人生效。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-与`。禁止 `CR#`、`TC#`、`ZR#`、`ZC#`、`DX#`、`LK#`、`A#`、`N#`。

口头「已经转给你了」「内部已经换人」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：转让、加入、免责承担分列。解释第四十八条以起诉状副本送达且确认转让事实为对债务人生效时点，不是立案日。

## 节点 0　分流、立场、转承闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造通知或同意、倒签到达日、隐匿通知、对抗合法执行不进负表。利益冲突未解不进整体停止。不代发送、不写通知函不是负触发。起诉状把转让写成已对债务人生效、把加入写成免责不是负触发。

整案转出只交付第 1、2、10 节，不出 `RY#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是向受让人抵销终稿 | 负触发 `评估抵销留置与扣款抗辩` |
| 主成果是管辖或仲裁条款是否约束新主体 | 负触发 `评估合同管辖与仲裁协议` |
| 主成果是起诉新相对人诉状 | 负触发 `提起合同纠纷一审` 或 `提起合同仲裁` |
| 主成果是保理或不良资产批量转让 | 整案转金融借贷担保领域 |
| 主成果是股权内部转让终稿 | 负触发 `准备有限公司股权内部转让` |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 工程分包转债／金融保理／土地出让／提单背书／劳动报酬债权 | 整案转对应领域 |
| 「不代发送」「不写通知函」 | 交付禁令，不是负触发 |

出现「转让」「承担」「加入」一词不是转出。

转承闸打开（可出 `RY#` 草案，仍不得标「已对债务人生效／已免责／已加入」）须同时满足：单方无冲突立场已闭合；主成果是转让／加入／免责评估，不是发送函、不是诉状把转让写成已生效终稿；至少一行可编号基础债权、让与或承担或加入文本、通知或同意碎片。口头「已经转给你了」不算单独开闸材料。

转承闸部分打开：已有碎片，但通知、同意或到达未闭合；对应格待核；仍交十节。无书面评估授权但单方立场已闭合且已有碎片：转承闸部分打开，仍交十节，不是整体停止。

转承闸关闭（仍正触发）：无一可编号碎片。「今天必须出已对债务人生效／已免责终稿」而无最小碎片不得开闸。不出 `RY#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `RY#` 终稿，**第 7 节不得出转让通知、同意函或诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「未通知即对债务人生效」「已读即到达」「内部转债即免责」「加入即免责」「未通知即让与合同无效」「立案日即到达」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `RY#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 转承闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造通知或同意、倒签到达日、隐匿通知、对抗合法执行或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个关系切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `RY#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 转让 | 基础债权、让与文本、通知与到达分列 | 签约日升格对债务人生效；未通知写成让与合同无效 |
| 特约 | 金钱／非金钱、善意分列 | 金钱特约对抗第三人；特约写成合同当然无效 |
| 免责 | 债权人同意与未表示分列 | 内部转债写成对债权人免责；沉默写成同意 |
| 加入 | 加入意思、通知或未拒绝、愿意范围分列 | 加入写成免责；未拒绝写成已免责换人 |
| 诉讼通知 | 起诉状副本送达与确认转让事实分列 | 立案日、起诉当日升格到达 |

检索锚点（写入 `L#` 前须核验）：见技能正文 MCP 节。噪声：已失效合同法第七十九条至第八十六条；法释〔2001〕12 号。

## 节点 3　转承行 `RY#`

按已出现关系碎片扫描，不是默认闭集。每条须能指向可转让性、通知到达、债权人同意、加入或抗辩之一。

无 `E#` 不得写已对债务人生效。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止唯一截止日。

热冲突强制处理：

- 未通知即对债务人生效／已读即到达／内部转债即免责／加入即免责／未通知即让与合同无效／立案日即到达／未知写零 → 该格不支持或字段停止；仍出其他 `RY#`。
- 无一碎片 → 关闸，不出 `RY#` 终稿，窗口不关。
- 指导伪造通知、倒签、隐匿 → 整体停止，不是该格不支持。

## 节点 4　抵留、管辖、起诉、保理、代位接口

第 7 节只开接口，不得夹带 `RY#` 终稿或函绕闸。闸关闭时第 7 节可写「闸未开，转介待关系编号」，不得补写已对债务人生效。不选定法院。不代提交。不发函。不写诉状。

下一步只转介：`评估抵销留置与扣款抗辩`、`评估合同管辖与仲裁协议`、`准备合同仲裁协议异议材料`、`提起合同纠纷一审`、`应对合同纠纷一审`、`提起合同仲裁`、`设计合同案件通知送达`、`评估电子合同成立与送达`、`评估合同成立与效力`、`评估变更是否成立`、`评估债权人代位权`、`评估债权人撤销权`、`建立合同争议证据案卷`、`评估框架协议与订单冲突`、`评估同时履行先履行与不安抗辩`、`评估争议期间`、`评估合同争议`。禁止此致某院。向受让人抵销只开抵留窗接口。保证通知只开金融或保证接口，不展开第六百九十六条。

若 if 用户催促「已经转给你了／内部已经换人／他答应加入就算免责／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「转承闸与转承行草案」。本窗不执行发送。不包含：已对债务人生效、已免责、已加入终稿、转让通知、同意函、诉状。禁止选边治愈。禁止加入即免责。禁止内部转债即免责。禁止指导伪造或隐匿。转承闸打开 ≠ 已对债务人生效 ≠ 已免责 ≠ 已加入。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标转承终稿已形成。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：买卖货款让与协议已签，债务人未收到书面通知，受让人发微信债务人已读未回复，主张已对债务人生效并要立即付款。基础合同有金钱债权禁止转让特约。债务人内部把债务转给关联公司，债权人未书面同意。关联公司曾表示愿意还，债权人主张加入连带，关联公司主张免责换人。用户主张已经转给你了、已读就算到了、内部已经换人、他答应加入就算免责、不清楚先写零。转承闸打开或半开。`Q-知`、`Q-读`、`Q-内`、`Q-入`、`Q-签`、`Q-零` 不打开为可靠路径。第 6 节不得把已对债务人生效、已到达、已免责、已加入、0 写入可执行 `RY#`；对应格 `现有依据不支持` 或字段停止；仍出关系分列、通知到达缺口、同意缺口、加入与免责分列等其他 `RY#`。不关窗。不发函。不写诉状。

场景②：用户同时交出己方「通知日期改到上周、同意函用空白章补一份」与对方「从未收到转让通知」口径，并要「先把倒签通知发出去」。命中双方秘密＋倒签＋伪造同意。第一次整体停止。只交第 1、10 节。不出 `RY#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代违法方案。
