# 边界与路由

## 正触发

一般合同一方主张债权转让对债务人生效、免责债务承担或债务加入，需要评估能否成立。从零、碎片、通知未核验、无书面评估授权仍正触发：有可编号基础债权、让与或承担或加入文本、通知或同意碎片则闸开或半开，出 `RY#` 草案，保持草案。本次不代发送、不写通知函是交付禁令，不是开窗条件。未通知即对债务人生效、加入即免责、内部转债即免责，仍正触发。起诉状把转让写成已对债务人生效、把加入写成免责，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造通知或同意、倒签到达日、隐匿通知、对抗合法执行的停止，优先于负触发。上述信号不在下表。不代发送不是负触发。「未通知即对债务人生效」「已读即到达」「内部转债即免责」「加入即免责」「未通知即让与合同无效」「立案日即到达」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 向受让人抵销终稿 | `评估抵销留置与扣款抗辩` |
| 管辖或仲裁条款是否约束新主体 | `评估合同管辖与仲裁协议` |
| 起诉新相对人诉状 | `提起合同纠纷一审` 或 `提起合同仲裁` |
| 保理或不良资产批量转让 | 金融借贷担保领域 |
| 股权内部转让终稿 | `准备有限公司股权内部转让` |
| 争议总图 | `评估合同争议` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |
| 工程分包转债／金融保理／土地出让／提单背书／劳动报酬债权 | 对应领域 |

不得因「不代发送」或「不写通知函」关窗。拟转承评估仍正触发，不得写成已对债务人生效或已免责。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 分包转债、实际施工人债权让与 | 建设工程领域 |
| 保理、不良资产、银行出让信贷资产 | 金融借贷担保领域 |
| 土地出让、商品房预售债权批量 | 房地产物业领域 |
| 提单背书、海商货物债权 | 海事领域 |
| 劳动报酬债权让与 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流。出现「转让」「承担」「加入」一词不是转出。C 端只要大众转让填空页时只分流，不把本包降成填空式转让，不回改。

## 易混

本窗闸名只能是转承闸，不是转让闸，不是承担闸，不是加入闸，不是抵留闸，不是变更闸。`RY#` 不是 `CR#`，不是 `TC#`，不是 `ZR#`，不是 `DX#`。主路径是 `Q-与`，不是 `Q-转`，不是 `Q-让`，不是 `Q-承`，不是 `Q-移`。`Q-转` 是股权转让闸主路径。`Q-让` 是方案窗让步。`Q-承` 是人身承揽分列码。`Q-移` 是环境移送红旗。`CR#` 是税务扣税凭证行。`TC#` 是退出谈判行。转让须通知到达。未通知不是对债务人生效，也不是让与合同无效。加入不是免责。内部转债不是对债权人免责。解释第四十八条以起诉状副本送达且确认转让事实为对债务人生效时点，不是立案日。已失效合同法第七十九条至第八十六条不是现行。法释〔2001〕12 号报纸公告不是一般合同已通知。MCP 可能先返回合同法第八十条或法释〔2001〕12 号而漏第五百四十五条第二款、第五百五十二条、通则解释第四十八条。「通知日期改到上周」「同意函补一份」整体停止。本窗不执行发送，不代提交。不选定法院。不发函。不写诉状。
