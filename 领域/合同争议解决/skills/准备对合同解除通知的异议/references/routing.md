# 边界与路由

## 正触发

已收到解除通知，需异议或请求确认合同未解除。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 解除权专项评估 | `评估解除权是否成立` |
| 确认未解除诉状 | `提起合同纠纷一审` |
| 自己发解除 | `准备解除通知` |
| 送达设计 | `设计合同案件通知送达` |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，只分流不回改 |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

已经收到对方解除通知、要书面反对时正触发。要告确认未解除的诉状时转起诉原子。自己要解除时转解除通知。
