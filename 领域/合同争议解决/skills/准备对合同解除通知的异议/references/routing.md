# 边界与路由

## 正触发

已收到解除通知，需异议或请求确认合同未解除。从零、碎片、到达未核验、无书面授权仍正触发：有可编号解除通知文本或到达碎片则闸开或半开，出 `YY#` 草案，保持草案。本次不执行发送、不写诉状是交付禁令，不是开窗条件。收到通知即已解除、未异议即已解除，仍正触发。把已读写成到达、把口头异议写成已提出、把草稿写成已发送，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造异议函、倒签发出日、伪造送达的停止，优先于负触发。上述信号不在下表。不执行发送不是负触发。「收到通知即已解除」「已读即到达」「口头异议即已提出」「未异议即已解除」「草稿即已发送」「约定异议期补正解除权」「立案日即解除时点」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 解除权评估终稿 | `评估解除权是否成立` |
| 自己发解除通知 | `准备解除通知` |
| 确认未解除起诉包 | `提起合同纠纷一审` |
| 成立、无效或撤销确认 | `提起合同成立或效力确认之诉` |
| 催告履行 | `准备催告履行或补救通知` |
| 争议总图 | `评估合同争议` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |
| 尚未收到通知，只要预防性策略 | `评估解除权是否成立` |

不得因「不执行发送」或「不写诉状」关窗。拟异议草稿仍正触发，不得写成已提出、已发送或已解除。

一般买卖或服务夹带专项背景时，专项段只分流。出现「异议」「解除」一词不是转出。C 端只要大众异议填空页时只分流，不把本包降成填空式函件，不回改。

## 易混

本窗闸名只能是解异闸，不是解除闸，不是发送闸，不是异议闸，不是催告闸，不是确诉闸。`YY#` 不是 `JC#`，不是 `HF#`，不是 `GY#`，不是 `QR#`，不是 `YJ#`，不是 `JY#`。主路径是 `Q-解异`，不是 `Q-除`，不是 `Q-函`，不是 `Q-异`。`解除闸`／`Q-除` 是评估解除权是否成立。`发送闸`／`Q-函` 是准备解除通知。`异议闸`／`Q-异` 是提出合同案件管辖异议。`YJ#` 是公司治理优先认缴行。`JY#` 是质量窗禁码／合规并行交卷。收到通知不是已解除。已读不是到达。口头异议不是已提出。未异议不是已解除。已失效合同法第九十六条、解释（二）第二十四条三个月异议不是现行。「今晚发出去」「异议发出日改到通知当天」整体停止。本窗不执行发送，不代提交。不选定法院。不写诉状。
