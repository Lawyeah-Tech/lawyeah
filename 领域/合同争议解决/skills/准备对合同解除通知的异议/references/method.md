# 准备对合同解除通知的异议方法

本文件是可执行判断节点。收到通知不是已解除。已读不是到达。口头异议不是已提出。未异议不能补正解除权缺失。草稿不是已发送。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已提出、已发送、已解除、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不写诉状，不把收到通知写成已解除。本窗闸名只能是解异闸，禁止复用解除闸、发送闸、异议闸、催告闸。预留不得占用：立案闸、和解闸。本窗 `YY#` 是解异行。主路径只用 `Q-解异`，禁止用 `Q-除`、`Q-函`、`Q-异`、`Q-签` 作主路径。本窗 `Q-签` 只作「异议稿即已发送或已提交」不关窗码。英文 id 禁止使用，一律用中文技能名 `准备对合同解除通知的异议`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效合同法第九十六条、解释（二）第二十四条三个月异议、把立案日写成解除时点时记为噪声。实务检索若仍写三个月异议期，记为噪声。禁止指导伪造异议函或倒签发出日。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现通知碎片扫描，不是默认闭集。
`YY#` 固定列：`编号｜通知切片｜到达与异议期｜解除权缺口｜异议要点与继续履行｜渠道与回证｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已提出」或「已发送」。无 `E#` 不得写已提出。到达或解除权未闭合不得标 `待提交`。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-解异`。禁止 `JC#`、`CG#`、`HF#`、`GY#`、`ZX#`、`QR#`、`YJ#`、`JY#`、`A#`、`N#`。

口头「今晚发出去就算提出了」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：无解除权的通知不因未异议而生效。约定异议期不是解除权补正。确认未解除之诉不在本窗写诉状。

## 节点 0　分流、立场、解异闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造异议函、倒签发出日、伪造送达不进负表。利益冲突未解不进整体停止。不执行发送、不写诉状不是负触发。把收到通知写成已解除、把未异议写成已解除不是负触发。

整案转出只交付第 1、2、10 节，不出 `YY#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是解除权评估终稿 | 负触发 `评估解除权是否成立` |
| 主成果是自己发解除通知 | 负触发 `准备解除通知` |
| 主成果是确认未解除起诉包 | 负触发 `提起合同纠纷一审` |
| 主成果是成立、无效或撤销确认 | 负触发 `提起合同成立或效力确认之诉` |
| 主成果是催告履行 | 负触发 `准备催告履行或补救通知` |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 尚未收到通知，只要预防性策略 | 负触发 `评估解除权是否成立` |
| 建设工程／金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不执行发送」「不写诉状」 | 交付禁令，不是负触发 |

出现「异议」「解除」一词不是转出。

解异闸打开（可出 `YY#` 草案，仍不得标「已提出／已发送／已解除／已未解除」）须同时满足：单方无冲突立场已闭合；主成果是相对方异议函草稿，不是发送版终稿、不是诉状；至少一行可编号解除通知文本或到达碎片。口头「今晚发出去」不算单独开闸材料。

解异闸部分打开：已有碎片，但到达、解除权或异议期未闭合；对应格待核；仍交十节。无书面授权但单方立场已闭合且已有碎片：解异闸部分打开，仍交十节，不是整体停止。

解异闸关闭（仍正触发）：无一可编号碎片。「今天必须出已提出／已发送终稿」而无最小碎片不得开闸。不出 `YY#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `YY#` 终稿，**第 7 节不得出发送版或诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「收到通知即已解除」「已读即到达」「口头异议即已提出」「未异议即已解除」「草稿即已发送」「约定异议期补正解除权」「立案日即解除时点」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `YY#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 解异闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造异议函、倒签发出日、伪造送达或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个通知切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `YY#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 通知 | 解除通知文本、发出渠道分列 | 口头升格已提出；空白页当通知 |
| 到达 | 到达凭证与时点分列 | 已读即到达；发出即到达 |
| 权源 | 对方解除权最小核验接口 | 未异议补正权源；收到即已解除 |
| 异议期 | 约定异议期／合理期限分列 | 解释（二）第二十四条三个月；异议期当除斥补正 |
| 时点 | 通知到达、副本送达分列 | 立案日或起诉当日写成解除 |

检索锚点（写入 `L#` 前须核验）：见技能正文 MCP 节。噪声：合同法第九十六条；解释（二）第二十四条。

## 节点 3　解异行 `YY#`

按已出现通知碎片扫描，不是默认闭集。每条须能指向到达、解除权缺口、异议要点或渠道回证之一。

无 `E#` 不得写已提出。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止唯一截止日。到达或解除权未闭合不得标 `待提交`。

热冲突强制处理：

- 收到通知即已解除／已读即到达／口头异议即已提出／未异议即已解除／草稿即已发送／约定异议期补正解除权／立案日即解除／未知写零 → 该格不支持或字段停止；仍出其他 `YY#`。
- 无一碎片 → 关闸，不出 `YY#` 终稿，窗口不关。
- 指导伪造异议函、倒签发出日、伪造送达 → 整体停止，不是该格不支持。

## 节点 4　解除评估、发送、起诉、送达接口

第 7 节只开接口，不得夹带 `YY#` 终稿、发送版或诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待通知编号」，不得补写已提出。不选定法院。不执行发送。不写诉状。

下一步只转介：`评估解除权是否成立`、`准备解除通知`、`准备催告履行或补救通知`、`设计合同案件通知送达`、`评估电子合同成立与送达`、`处理解除后返还与清理`、`评估继续履行是否可能`、`评估迟延拒绝与不完全履行`、`评估同时履行先履行与不安抗辩`、`评估质量瑕疵与检验期间`、`评估争议期间`、`建立双向履行时间线`、`建立合同争议证据案卷`、`评估合同管辖与仲裁协议`、`提起合同纠纷一审`、`提起合同成立或效力确认之诉`、`提起合同仲裁`、`选择诉讼仲裁或督促程序`、`应对合同纠纷一审`、`评估合同争议`。禁止此致某院。

若 if 用户催促「今晚发出去就算提出了／没回就是认了／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「解异闸与解异行草案」。本窗不执行发送。不包含：已提出、已发送、已解除、确认未解除诉状。禁止选边治愈。禁止收到通知即已解除。禁止未异议即已解除。禁止指导伪造。解异闸打开 ≠ 已提出 ≠ 已发送 ≠ 已解除。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：相对方收到微信解除通知已读，约定异议期三天已过，用户主张没回就是认了、已读就算到达、今晚把异议发出去就算已提出、对方没解除权也因过期而解除、今天立案就算已经解除、不清楚先写零。解异闸打开或半开。`Q-收`、`Q-读`、`Q-签`、`Q-未`、`Q-期`、`Q-拟`、`Q-零` 不打开为可靠路径。第 6 节不得把已解除、已到达、已提出、未异议即生效、立案日时点、0 写入可执行 `YY#`；对应格 `现有依据不支持` 或字段停止；仍出通知文本分列、到达缺口、解除权最小核验、异议要点等其他 `YY#`。不关窗。不执行发送。不写诉状。

场景②：用户同时交出己方「异议发出日改到通知当天、回证先补一份」与对方「从来没收到异议」口径，并要「先承认已经解除再说」。命中双方秘密＋倒签＋伪造。第一次整体停止。只交第 1、10 节。不出 `YY#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代违法方案。
