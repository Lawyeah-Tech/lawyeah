# 准备对合同解除通知的异议

## 任务目标

在明确、无利益冲突的单方立场下（被通知解除的相对方或其受托律师，互斥），形成异议函草稿：解异闸、主体与强制接口、`Q#` 路径、`YY#` 解异行（通知切片／到达与异议期／解除权缺口／异议要点与继续履行／渠道与回证／`E#` 回链）。本窗 `YY#` 是解异行草案，不是已提出证明，不是已发送，不是已到达，不是已未解除裁判，不是发送版异议函，不是确认未解除诉状。本窗闸名只能是解异闸，禁止复用解除闸、催告闸、发送闸、异议闸、仲异闸、确诉闸、起诉闸、情诉闸、答辩闸。预留不得占用：立案闸、和解闸。本窗主行只能是 `YY#`，禁止 `JC#`、`CG#`、`HF#`、`GY#`、`ZX#`、`QR#`、`QT#`、`QY#`、`YJ#`、`JY#`、`A#`。主路径只用 `Q-解异`，禁止用 `Q-除`、`Q-告`、`Q-函`、`Q-异`、`Q-仲异`、`Q-确诉`、`Q-诉`、`Q-情诉`、`Q-履`、`Q-签` 作主路径。邻窗 `Q-解异` 只作转介进本窗；本窗打开为主路径，不是已提出、不是已发送、不是已解除、不是已未解除。本窗 `Q-除` 只转介 `评估解除权是否成立`。本窗 `Q-函` 只转介 `准备解除通知`。本窗 `Q-诉` 只转介 `提起合同纠纷一审`。本窗 `Q-签` 只作「异议稿即已发送或已提交」不关窗码。解异闸打开不等于已提出不等于已发送不等于已到达不等于已解除不等于已未解除不等于待发送终稿。收到通知不是已解除。已读不是到达。口头异议不是已提出。未异议不是已解除。约定异议期不是解除权补正。立案日不是解除时点。继续付款不是已认可解除。未知不写零。不执行发送。不代提交。不写诉状。不选定法院。不定罪。伤残等级与本窗无关，禁止折入。

`depends-on` 为空。主成果是解除权评估终稿转 `评估解除权是否成立`。主成果是自己发解除通知转 `准备解除通知`。主成果是确认未解除起诉包转 `提起合同纠纷一审`。主成果是成立、无效或撤销确认转 `提起合同成立或效力确认之诉`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：已收到解除通知，需异议或请求确认合同未解除。「今晚发出去就算提出了」「没回就是认了」仍正触发，成果状态 `草案`。到达、解除权、异议期未核验仍正触发：有可编号解除通知文本或到达碎片则解异闸打开或半开，第 6 节出 `YY#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出已提出／已发送／已未解除终稿」才关闸，仍交十节，第 6 节不出 `YY#` 终稿，第 7 节不得出发送版或诉状，窗口不关。用户要把收到通知写成已解除、把已读写成到达、把口头异议写成已提出、把未异议写成已解除、把草稿写成已发送、把约定异议期写成补正解除权、把立案日写成解除时点、把未知写成零，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `YY#` 草案。不得因「不执行发送」「不写诉状」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是解除权评估终稿（转 `评估解除权是否成立`）；
- 主成果是自己发解除通知（转 `准备解除通知`）；
- 主成果是确认未解除起诉包（转 `提起合同纠纷一审`）；
- 主成果是成立、无效或撤销确认（转 `提起合同成立或效力确认之诉`）；
- 主成果是催告履行（转 `准备催告履行或补救通知`）；
- 主成果是争议总图（转 `评估合同争议`）；
- 尚未成争，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）；
- 尚未收到通知，只要预防性策略。

双方秘密、伪造异议函、倒签发出日、伪造送达、违法取证**不在负触发表**，走整体停止。「收到通知即已解除」「已读即到达」「口头异议即已提出」「未异议即已解除」「草稿即已发送」「约定异议期补正解除权」「立案日即解除时点」「未知写零」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不执行发送」「不写诉状」是交付禁令，不是负触发。主成果才转；出现「异议」「解除」一词不是转出。

## 建立工作坐标

确认：异议授权；单方立场；解除通知文本；到达碎片；约定异议期；解除权最小核验；法域。

口头「今晚发出去就算提出了」「没回就是认了」只登记 `S#`／`V#`。不得升格已提出、已发送、已到达或已解除，**不得单独算作开闸材料**。可编号解除通知文本或到达碎片可开闸。本窗不执行发送，不代提交，不写诉状，不选定法院。

立场只许被通知解除的相对方或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：解异闸关闭，仍交十节，不是整体停止。无书面授权但单方立场已闭合、且已有碎片：解异闸部分打开，仍交十节，不是整体停止。提出伪造异议函、倒签发出日、伪造送达或违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`YY#` 解异行；`V#` 版本；`E#` 证据形态回链（通知文本、到达凭证、异议稿、授权，不是发送闸，不是已提出证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`JC#`、`CG#`、`HF#`、`GY#`、`ZX#`、`QR#`、`YJ#`、`JY#`。技能正文中的条号是检索锚点，不是已核验 `L#`。文件状态只用 `草案`、`待提交`、`停止`。到达或解除权未闭合不得标 `待提交`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。未知不写零。收到通知 ≠ 已解除。已读 ≠ 到达。口头异议 ≠ 已提出。未异议 ≠ 已解除。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或文书范本检索。本窗是异议函草稿，范本只借异议函栏目，**不要**升格「已提出／已发送／已到达／已解除／已未解除」，**不要**改写成起诉状。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现收到通知即已解除、已读即到达、口头异议即已提出、未异议即已解除、草稿即已发送的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效合同法第九十六条、解释（二）第二十四条三个月异议当作现行。实务检索若仍写三个月异议期，记为噪声。MCP 查询第一百二十二条可能先返回 1991 年开庭通知条，本窗不写诉状，该条只作分流噪声。MCP 效力字段与公布施行日冲突时，以施行日为准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的到达、解除权、异议效力保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民法典第五百六十五条通知到达对方时解除；未通知而起诉或申请仲裁主张解除，该主张获确认后自起诉状或仲裁申请书副本送达时解除，立案日不是解除时点。第一百三十七条到达，已读不是到达。通则解释第五十三条：以未在约定或合理异议期内提出异议主张已解除的，须审查是否享有解除权；不享有则不发生解除效力。第五十四条撤诉后再诉，以再次起诉状副本送达为准。噪声：已失效合同法第九十六条、解释（二）第二十四条三个月异议。技能正文条号不是 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变到达、解除权有无或异议效力的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补收到通知不是已解除、已读不是到达、口头异议不是已提出、草稿不是已发送、未异议不能补正解除权缺失、约定异议期届满不是无解除权通知生效、立案日不是解除时点的实务反例。
- `search_template` 只借异议函栏目（当事人／异议事项／事实与理由／证据名称）。范本逾期即解除句、落款、送达回证、此致某院不得升格已提出、已发送、已到达、已解除或已未解除。禁止改写成起诉状或确认之诉诉状。禁止用解除通知、管辖异议书、支付令异议或仲裁协议异议范本改头换面。禁止用范本生成发送版。

工具不可用时继续通知碎片和 `YY#` 编目；到达、解除权、施行日字段停止。不得拒跑，不得凭记忆写成已提出、已发送或已解除。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、解异闸与不关窗

主成果才整案转出。双方秘密、伪造异议函、倒签发出日第一次停。收到通知即已解除、未异议即已解除不关窗。闸关仍交十节，第 6 节不出 `YY#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

通知文本、到达、解除权最小核验、异议期分列。本节禁止出 `YY#` 终稿。

### 3. 解异闸与路径 `Q#`

本节禁止出 `YY#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-解异`。

### 4. 解异行 `YY#`

通知切片、到达与异议期、解除权缺口、异议要点与继续履行、渠道与回证。状态 `草案`。禁止升格已提出、已发送、已到达、已解除。无 `E#` 不得写已提出。到达或解除权未闭合不得标 `待提交`。

### 5. 解除评估、发送、起诉、送达接口

解除权评估转解除窗。自己发解除转发送窗。确认未解除起诉包转一审窗。第 7 节不得夹带 `YY#` 终稿、发送版或诉状绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造异议函、倒签发出日、伪造送达或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：解异闸关闭，仍交十节，不是整体停止。无书面授权但有碎片：解异闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：到达、解除权、异议期、施行日未核验。收到通知即已解除、已读即到达、口头异议即已提出、未异议即已解除、草稿即已发送、约定异议期补正解除权、立案日即解除时点、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `YY#` 草案。
- `目标停止`：主目标变为确认未解除起诉包、自己发解除通知或解除权评估终稿。禁止把「未异议即已解除」或「收到通知即已解除」当作用户错误主张时的目标停止；那是不关窗。

禁止指导伪造异议函或倒签发出日。不给胜诉率。不定罪。不选定法院。不执行发送。不代提交。未知不写零。不写诉状。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。解异闸关闭仍交十节，第 6 节不出 `YY#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `YY#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。解异闸未打开时不得交付「已提出」或「已发送」。边界见 [路由](references/routing.md)。
