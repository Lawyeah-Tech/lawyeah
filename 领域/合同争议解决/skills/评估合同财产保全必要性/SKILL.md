# 评估合同财产保全必要性

## 任务目标

在明确、无利益冲突的单方立场下（拟申请财产保全的请求权人或其受托律师，互斥），形成财产保全必要性评估草案：要保闸、主体与强制接口、`Q#` 路径、`YB#` 要保行（请求切片／难以执行或损害迹象／担保与错误赔偿／诉前诉中与三十日／申请／复议／先予／行为接口／`E#` 回链）。本窗 `YB#` 是要保行草案，不是已必要证明，不是已裁定，不是已申请，不是申请书终稿，不是已冻结。本窗闸名只能是要保闸，禁止复用保全闸、冻结闸、现证闸、封存闸、必要闸、担保闸、起诉闸、评估闸。预留不得占用：立案闸、和解闸、保全闸。本窗主行只能是 `YB#`，禁止 `BQ#`、`FZ#`、`XZ#`、`FC#`、`CB#`、`NS#`、`A#`。主路径只用 `Q-要`，禁止用 `Q-保`、`Q-冻`、`Q-账`、`Q-现`、`Q-必`、`Q-急`、`Q-诉`、`Q-签` 作主路径。邻窗 `Q-要` 只作转介进本窗；本窗打开为主路径，不是已裁定、不是已决定申请。本窗 `Q-保` 只转介 `准备合同财产保全申请`（申请窗打开 `Q-申保`，本窗不打开 `Q-保` 为主路径，也不出 `BQ#`）。本窗 `Q-签` 只作「评估即已裁定、已申请、已冻结或已提交」不关窗码。本窗 `Q-忧` 只作「单纯担心即难以执行已证成」不关窗码。本窗 `Q-急` 只作「口头紧急即四十八小时已裁」不关窗码。要保闸打开不等于已必要不等于已裁定不等于已申请不等于已冻结不等于担保已足额不等于诉前三十日已起算不等于待提交终稿。单纯担心不是难以执行。申请草稿不是已裁定。担保不是已保全。诉前三十日不是已起诉。口头紧急不是四十八小时已裁。未知金额不写零。不代写申请。不保证裁定。不选定法院。不代提交。不定罪。伤残等级与本窗无关，禁止折入。先予执行与行为保全申请属本包未安装能力，主成果命中则负触发 `unavailable`。

`depends-on` 为空。主成果是财产保全申请书终稿转 `准备合同财产保全申请`。主成果是复议或换保终稿转 `应对合同案件保全裁定`。主成果是现场或电子自固转 `保全质量现场与电子证据`。主成果是争议总图转 `评估合同争议`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：一般合同已成争，担心转移财产，尚未决定申请诉前或诉中财产保全。「他肯定在转钱」「必须今晚冻」仍正触发，成果状态 `草案`，不代提交。请求、对象、迹象、担保未核验仍正触发：有可编号给付请求碎片或拟保全对象、可回链转移迹象碎片则要保闸打开或半开，第 6 节出 `YB#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出已裁定／应保全终稿」才关闸，仍交十节，第 6 节不出 `YB#` 终稿，第 7 节不得出申请书或已冻结，窗口不关。用户要把单纯担心写成难以执行已证成、把申请写成已裁定、把担保写成已保全、把三十日写成已起诉、把口头紧急写成四十八小时已裁、把未知写成零，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `YB#` 草案。不得因「不代写申请」「不保证裁定」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是财产保全申请书终稿（转 `准备合同财产保全申请`）；
- 主成果是复议或换保终稿（转 `应对合同案件保全裁定`）；
- 主成果是先予执行（`unavailable`，本包未安装）；
- 主成果是行为保全申请（`unavailable`，本包未安装）；
- 主成果是现场或电子自固（转 `保全质量现场与电子证据`）；
- 主成果是争议总图（转 `评估合同争议`）；
- 尚未成争，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）。

双方秘密、虚构紧急、伪造转移迹象、倒签申请日、伪造担保、指导隐匿或转移对方财产、违法取证**不在负触发表**，走整体停止。「单纯担心即难以执行」「申请即已裁定」「担保即已保全」「三十日即已起诉」「口头紧急即四十八小时已裁」「未知写零」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不代写申请」「不保证裁定」「不选定法院」是交付禁令，不是负触发。虚构紧急**不是负触发**，第一次整体停止。主成果才转；出现「保全」「冻结」「担保」一词不是转出。财产评估为主、顺口问行为或先予：本窗正触发可留，行为／先予段标 `unavailable` 接口，不整案转出。

## 建立工作坐标

确认：评估授权；单方立场；给付请求；拟保全对象；转移或难以执行迹象；诉前或诉中；担保能力；法域；仲裁协议；当前诉讼或仲裁状态。

口头「他肯定在转钱」「必须今晚冻」只登记 `S#`／`V#`。不得升格已必要、已裁定或已申请，**不得单独算作开闸材料**。可编号给付请求或对象、迹象碎片可开闸。本窗不执行发送，不代提交，不写申请书。

立场只许拟申请财产保全的请求权人或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：要保闸关闭，仍交十节，不是整体停止。无书面授权但单方立场已闭合、且已有碎片：要保闸部分打开，仍交十节，不是整体停止。提出虚构紧急、伪造转移迹象、倒签申请日、伪造担保、指导隐匿或转移对方财产或违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`YB#` 要保行；`V#` 版本；`E#` 证据形态回链（请求、对象、迹象、担保栏目，不是发送闸，不是已裁定证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`BQ#`、`FZ#`、`XZ#`、`FC#`。技能正文中的条号是检索锚点，不是已核验 `L#`。文件状态只用 `草案`、`停止`。请求、担保或三十日未闭合不得标待提交。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。未知不写零。担心 ≠ 难以执行。申请 ≠ 已裁定。担保 ≠ 已保全。三十日 ≠ 已起诉。口头紧急 ≠ 四十八小时已裁。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或裁判案例检索。本窗是评估，**不要**用 `search_template` 生成申请书、担保书、已裁定证明或诉状，**不要**用类案写成必然已必要或已裁定。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现单纯担心即难以执行、申请即已裁定、担保即已保全、三十日即已起诉、口头紧急即四十八小时已裁的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把 1991 年民事诉讼法第一百零三条协助执行罚款当作现行保全条。不得把 2017 年第一百条、第一百零一条未核验对应现行第一百零三条、第一百零四条。不得把财产保全规定或知产行为保全规定仍引旧第一百条、第一百零一条、第一百零五条未核对应现行条。MCP 可能先返回 1991 年第一百零三条。MCP 效力字段与公布施行日冲突时，以施行日为准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的保全条件、担保、三十日、四十八小时或施行日保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民事诉讼法（2023 修正，施行日 2024-01-01）第一百零三条诉讼中保全：可能因一方行为或其他原因使判决难以执行或造成其他损害，可裁定财产保全、责令作出或禁止一定行为；可以责令提供担保；紧急须四十八小时内裁定。本窗只评估财产保全必要性，行为段 `unavailable`。第一百零四条诉前：情况紧急、不立即申请将使合法权益受到难以弥补的损害；应当提供担保；采取后三十日内不依法起诉或申请仲裁的应当解除。第一百零五条限于请求范围或与本案有关的财物。第一百零六条查封、扣押、冻结或其他法定方法，不得重复查封、冻结。第一百零七条被申请人提供担保的，应当裁定解除财产保全。第一百零八条申请有错误的，应当赔偿被申请人因保全所遭受的损失。民诉解释第一百五十二条诉前财产保全应当提供相当于请求保全数额的担保，情况特殊可以酌情；诉讼中是否责令担保及数额由法院根据情况决定。财产保全规定第十七条诉前采取后三十日内起诉或申请仲裁的自动转化。仲裁法（2025 修订，施行日 2026-03-01）第三十九条财产或行为保全由法院处理，申请错误应当赔偿；MCP 标尚未施行时以施行日为准。噪声：1991 年第一百零三条协助执行罚款；2017 年第一百条、第一百零一条；财产保全规定或知产行为保全规定仍引旧第一百条、第一百零一条、第一百零五条；担保一律百分之三十；保证准许。技能正文条号不是 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变保全条件、担保、三十日、四十八小时或错误赔偿的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补单纯担心不是难以执行、正常经营不是转移、担保不是已保全、三十日不是已起诉、口头紧急不是四十八小时已裁、有仲裁协议仍可向法院保全、超范围可能错误赔偿的实务反例。
- `search_case_by_fact` 只比较事实差异与翻转条件：无迹象不是应保全；超范围不是当然合法；错误申请可能赔偿；诉前未诉应解除。无类案不得写成已必要、已裁定或应申请终稿。评估类禁止用 `search_template` 生成申请书、担保书或已裁定证明。

工具不可用时继续请求碎片和 `YB#` 编目；已必要、已裁定、担保已足额、三十日字段停止。不得拒跑，不得凭记忆写成已裁定或指导隐匿。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、要保闸与不关窗

主成果才整案转出。双方秘密、虚构紧急、指导隐匿第一次停。单纯担心即难以执行不关窗。闸关仍交十节，第 6 节不出 `YB#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

诉前／诉中切开。财产／行为／先予分列，后两列 `unavailable`。本节禁止出 `YB#` 终稿。

### 3. 要保闸与路径 `Q#`

本节禁止出 `YB#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-要`。

### 4. 要保行 `YB#`

请求、迹象、担保与错误赔偿、诉前诉中与三十日、申请接口。状态 `草案`。禁止升格已必要、已裁定、已申请。无 `E#` 不得写难以执行已证成。

### 5. 申请、应对、现证与调查令接口

申请转申请窗。第 7 节不得夹带 `YB#` 终稿或申请书绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出虚构紧急、伪造转移迹象、倒签申请日、伪造担保、指导隐匿或转移对方财产、查封无关生活必需且拒绝限缩或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：要保闸关闭，仍交十节，不是整体停止。无书面授权但有碎片：要保闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：保全条件、担保、三十日、四十八小时、保全法院连结点、施行日未核验。单纯担心即难以执行、申请即已裁定、担保即已保全、三十日即已起诉、口头紧急即四十八小时已裁、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `YB#` 草案。
- `目标停止`：主目标变为申请书终稿、已裁定终稿、先予执行或隐匿对攻方案。禁止把「单纯担心即难以执行」当作用户错误主张时的目标停止；那是不关窗。

禁止指导虚构紧急或隐匿对方财产。不给准许率。不定罪。不选定法院。不代提交。未知不写零。不写申请书。不保证裁定。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。要保闸关闭仍交十节，第 6 节不出 `YB#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `YB#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。要保闸未打开时不得交付「已必要」或「已裁定」。边界见 [路由](references/routing.md)。
