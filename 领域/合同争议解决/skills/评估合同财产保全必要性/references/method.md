# 评估合同财产保全必要性方法

本文件是可执行判断节点。单纯担心不是难以执行。申请草稿不是已裁定。担保不是已保全。诉前三十日不是已起诉。口头紧急不是四十八小时已裁。未知金额不写零。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已必要、已裁定、选定法院、代提交、未知写零。本任务不定罪，不写申请书，不保证裁定。本窗闸名只能是要保闸，禁止复用保全闸、冻结闸、现证闸、封存闸、必要闸。预留不得占用：立案闸、和解闸、保全闸。本窗 `YB#` 是要保行。主路径只用 `Q-要`，禁止用 `Q-保`、`Q-冻`、`Q-账`、`Q-现`、`Q-必`、`Q-急`、`Q-签` 作主路径。本窗 `Q-签` 只作「评估即已裁定、已申请、已冻结或已提交」不关窗码。本窗 `Q-忧` 只作「单纯担心即难以执行已证成」不关窗码。英文 id 禁止使用，一律用中文技能名 `评估合同财产保全必要性`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991 年民事诉讼法第一百零三条协助执行罚款、2017 年第一百条或第一百零一条、把单纯担心写成难以执行时记为噪声。禁止指导虚构紧急或隐匿对方财产。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现请求或迹象碎片扫描，不是默认闭集。
`YB#` 固定列：`编号｜请求切片｜难以执行或损害迹象｜担保与错误赔偿｜诉前诉中与三十日｜申请／复议／先予／行为接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已必要」或「已裁定」。无 `E#` 不得写难以执行已证成。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-要`。禁止 `BQ#`、`FZ#`、`XZ#`、`FC#`、`A#`、`N#`。文件状态只用 `草案`、`停止`。

口头「他肯定在转钱」「必须今晚冻」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：诉前应当担保，诉中可以责令。三十日是采取后起诉或申请仲裁的期间长度，不是已立案。有仲裁协议仍可向法院申请财产保全。错误申请可能赔偿。行为保全与先予执行主成果 `unavailable`。

## 节点 0　分流、立场、要保闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、虚构紧急、伪造转移迹象、倒签申请日、伪造担保、指导隐匿或转移对方财产、违法取证不进负表。利益冲突未解不进整体停止。不代写申请、不保证裁定不是负触发。

整案转出只交付第 1、2、10 节，不出 `YB#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是财产保全申请书终稿 | 负触发 `准备合同财产保全申请` |
| 主成果是复议或换保终稿 | 负触发 `应对合同案件保全裁定` |
| 主成果是先予执行 | 负触发 `unavailable` |
| 主成果是行为保全申请 | 负触发 `unavailable` |
| 主成果是现场或电子自固 | 负触发 `保全质量现场与电子证据` |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程／金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不代写申请」「不保证裁定」「不选定法院」 | 交付禁令，不是负触发 |

出现「保全」「冻结」「担保」一词不是转出。

要保闸打开（可出 `YB#` 草案，仍不得标「已必要／已裁定／已申请」）须同时满足：单方无冲突立场已闭合；主成果是必要性评估，不是申请书、不是已裁定、不是先予或行为保全终稿；至少一项可编号给付请求或对象、迹象碎片。口头「他肯定在转钱」不算单独开闸材料。

要保闸部分打开：已有碎片，但迹象、担保或诉前诉中未闭合；对应格待核；仍交十节。无书面授权但单方立场已闭合且已有碎片：要保闸部分打开，仍交十节，不是整体停止。

要保闸关闭（仍正触发）：无一可编号碎片。「今天必须出已裁定终稿」而无最小碎片不得开闸。不出 `YB#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `YB#` 终稿，**第 7 节不得出申请书或已冻结**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「单纯担心即难以执行」「申请即已裁定」「担保即已保全」「三十日即已起诉」「口头紧急即四十八小时已裁」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `YB#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 要保闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出虚构紧急、伪造转移迹象、倒签申请日、伪造担保、指导隐匿或转移对方财产或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个请求或对象切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `YB#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 时机 | 诉前／诉中切开 | 未立案写成诉中；已立案套诉前三十日 |
| 对象 | 账户／不动产／动产／股权／其他分列 | 混成一包已冻结；查封生活必需且拒绝限缩 |
| 制度 | 财产保全／行为保全／先予执行分列 | 把行为或先予写入财产行终稿 |

| 三十日 | 诉前采取后起诉或申请仲裁期间 | 写成已起诉；写死唯一日历截止 |

检索锚点（写入 `L#` 前须核验）：见技能正文 MCP 节。噪声：1991 年第一百零三条；2017 年第一百条、第一百零一条。

## 节点 3　要保行 `YB#`

按已出现请求或迹象碎片扫描，不是默认闭集。每条须能指向难以执行迹象、担保与错误赔偿或诉前诉中与三十日之一。

无 `E#` 不得写难以执行已证成。状态默认 `草案`。一次只推荐下一步。未知金额不写零。禁止唯一日历截止日。请求、担保或三十日未闭合不得标待提交。

热冲突强制处理：

- 单纯担心即难以执行／申请即已裁定／担保即已保全／三十日即已起诉／口头紧急即四十八小时已裁／未知写零 → 该格不支持或字段停止；仍出其他 `YB#`。
- 无一碎片 → 关闸，不出 `YB#` 终稿，窗口不关。
- 指导虚构紧急、伪造迹象、隐匿转移 → 整体停止，不是该格不支持。

## 节点 4　申请、应对、现证与调查令接口

第 7 节只开接口，不得夹带 `YB#` 终稿或申请书绕闸。闸关闭时第 7 节可写「闸未开，转介待请求编号」，不得补写已裁定。不选定法院。不代提交。不保证裁定。

下一步只转介：`准备合同财产保全申请`、`应对合同案件保全裁定`、`评估合同争议`、`评估合同管辖与仲裁协议`、`提起合同纠纷一审`、`应对合同纠纷一审`、`测算违约金与损害赔偿`、`建立合同争议证据案卷`、`申请律师调查令或法院调查取证`、`保全质量现场与电子证据`、`准备合同案件公证保全`、`评估债权人撤销权`、`评估债权人代位权`、`选择诉讼仲裁或督促程序`。禁止此致某院。

若 if 用户催促「他肯定在转钱所以必须冻／交保就算保上了／三十天内算已经起诉／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 用户要求虚构紧急或隐匿对方财产，then 第一次整体停止。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「要保闸与要保行草案」。本窗不执行发送。不包含：已必要、已裁定、已申请终稿、申请书、隐匿步骤。禁止选边治愈。禁止单纯担心即难以执行。禁止申请即已裁定。禁止指导虚构紧急。要保闸打开 ≠ 已必要 ≠ 已裁定 ≠ 已申请。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标评估终稿已形成。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：卖方担心买方转走货款，主张肯定会转所以必须冻、交了担保就算已经保全、申请了法院四十八小时一定会准、诉前冻了三十天内就算已经起诉、不清楚的金额先写零。要保闸打开或半开。`Q-忧`、`Q-担`、`Q-急`、`Q-前`、`Q-零` 不打开为可靠路径。第 6 节不得把已必要、已保全、已裁定、已起诉、0 写入可执行 `YB#`；对应格 `现有依据不支持` 或字段停止；仍出请求分列、迹象缺口、诉前应当担保、错误赔偿接口、三十日期间长度等其他 `YB#`。不关窗。不写申请书。不保证裁定。

场景②：用户同时交出己方「对方正在转移」与对方「账户正常经营」口径，并要「紧急日改到昨天、把案外人住房也先封上」。命中双方秘密＋倒签＋超范围查封生活必需。第一次整体停止。只交第 1、10 节。不出 `YB#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给隐匿或超范围方案。
