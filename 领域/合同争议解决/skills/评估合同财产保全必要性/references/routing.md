# 边界与路由

## 正触发

一般合同已成争，担心转移财产，尚未决定申请诉前或诉中财产保全。从零、碎片、迹象未核验、无书面授权仍正触发：有可编号给付请求或对象、迹象碎片则闸开或半开，出 `YB#` 草案，保持草案。本次不代写申请、不保证裁定是交付禁令，不是开窗条件。单纯担心即难以执行、申请即已裁定，仍正触发。把担保写成已保全、把三十日写成已起诉，仍正触发：该格不支持，不改负触发关窗。

双方秘密、虚构紧急、指导隐匿的停止，优先于负触发。上述信号不在下表。不代写申请不是负触发。「单纯担心即难以执行」「申请即已裁定」「担保即已保全」「三十日即已起诉」「口头紧急即四十八小时已裁」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 财产保全申请书终稿 | `准备合同财产保全申请` |
| 复议或换保终稿 | `应对合同案件保全裁定` |
| 先予执行 | `unavailable` |
| 行为保全申请 | `unavailable` |
| 现场或电子自固 | `保全质量现场与电子证据` |
| 争议总图 | `评估合同争议` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不代写申请」或「不保证裁定」关窗。拟必要性评估仍正触发，不得写成已裁定或应申请终稿。

## 易混

本窗闸名只能是要保闸，不是保全闸，不是冻结闸，不是现证闸，不是封存闸，不是必要闸。`YB#` 不是 `BQ#`，不是 `FZ#`，不是 `XZ#`，不是 `FC#`。主路径是 `Q-要`，不是 `Q-保`，不是 `Q-冻`，不是 `Q-账`，不是 `Q-现`，不是 `Q-必`。`保全闸`／`BQ#`／`Q-保` 是公司治理准备股权或公司财产保全，合同包留给 `准备合同财产保全申请`。`冻结闸`／`FZ#`／`Q-冻` 是应对股权冻结或行为保全。`Q-必` 是约定金即必得，本窗担心即必要走 `Q-忧`。单纯担心不是难以执行。申请不是已裁定。担保不是已保全。诉前三十日不是已起诉。1991 年民事诉讼法第一百零三条协助执行罚款不是现行保全条。2017 年第一百条、第一百零一条须核对应现行第一百零三条、第一百零四条。仲裁法第三十九条 MCP 标尚未施行时以施行日为准。提出「紧急日改到昨天」「把案外人住房也先封上」整体停止。本窗不执行发送，不代提交。不选定法院。不写申请书。不保证裁定。
