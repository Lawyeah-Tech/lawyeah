# 边界与路由

## 正触发

框架、订单、送货单、对账单不一致，需要确定哪一层构成约束及缺口。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 条款歧义 | `解释争议条款与填补漏洞` |
| 是否已变更 | `评估变更是否成立` |
| 电子订单到达 | `评估电子合同成立与送达` |
| 结算发票 | `评估价款结算与发票争议` |
| 仲裁条款冲突 | `评估合同管辖与仲裁协议` |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，只分流不回改 |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

多份交易文件打架时正触发。只有一份合同内部不会读时转解释。要按每一张订单各开一个新方法时拒绝拆分。
