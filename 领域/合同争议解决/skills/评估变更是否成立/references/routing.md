# 边界与路由

## 正触发

一般合同口头变更、会议纪要或长期实际履行与书面合同冲突，需要评估变更是否成立。从零、碎片、合意未核验、无书面评估授权仍正触发：有可编号书面合同与冲突文本或履行碎片则闸开或半开，出 `BY#` 草案，保持草案。本次不代签署、不写补充协议是交付禁令，不是开窗条件。口头即已改约、纪要即当然变更、填补即已改约，仍正触发。把口头写成已改约、把一次让步写成全面弃权，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造补充协议或纪要、倒签变更日、隐匿原合同、对抗合法执行的停止，优先于负触发。上述信号不在下表。不代签署不是负触发。「口头即已改约」「纪要即当然变更」「内容不明仍已变更」「填补即已改约」「一次让步即全面弃权」「长期履行即整份作废」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 条款解释或填补终稿 | `解释争议条款与填补漏洞` |
| 框架与订单效力层级 | `评估框架协议与订单冲突` |
| 情势变更终稿 | `评估不可抗力情势变更与履行不能` 或 `提起情势变更变更或解除之诉` |
| 成立或代理权限 | `评估合同成立与效力` |
| 电子记录到达 | `评估电子合同成立与送达` |
| 争议总图 | `评估合同争议` |
| 尚未成争，改合同或补签 | 审查起草领域（本窗搁置，只说明） |
| 工程签证／金融批准变更／商品房更名／海事航次书面／劳动一个月口头变更 | 对应领域 |

不得因「不代签署」或「不写补充协议」关窗。拟变约评估仍正触发，不得写成已改约或全面弃权。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 工程签证、设计变更、现场指令 | 建设工程领域 |
| 金融合同变更批准、借款展期专项 | 金融借贷担保领域 |
| 商品房认购更名、预售变更 | 房地产物业领域 |
| 航次租船书面、提单批注 | 海事领域 |
| 劳动合同一个月口头变更 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流。出现「变更」「纪要」「口头」一词不是转出。C 端只要大众改约填空页时只分流，不把本包降成填空式变更，不回改。

## 易混

本窗闸名只能是变约闸，不是变更闸，不是变故闸，不是解释闸，不是成立闸。`BY#` 不是 `BG#`，不是 `GY#`，不是 `WG#`，不是 `JX#`。主路径是 `Q-变`，不是 `Q-改`，不是 `Q-形`，不是 `Q-故`，不是 `Q-释`。`变更闸`／`BG#`／`Q-形` 是公司治理形式变更。`Q-改` 是变故／解释「已改约」不关窗。`GY#` 是管辖异议行。口头不是已改约。纪要不是当然变更。内容不明推定未变更。填补不是已改约。一次让步不是全面弃权。第四百九十条、通则解释第三条是成立形式补正，不是变更已成立。已失效合同法第七十七条、第七十八条不是现行。劳动争议解释（一）第四十三条一个月不得套一般合同。MCP 可能先返回合同法第七十七条或劳动一个月而漏第五百四十四条、通则解释第十四条。「补充协议日期改到上周」「纪要用空白章补一份」整体停止。本窗不执行发送，不代提交，不代签署。不选定法院。不写补充协议。不写诉状。
