# 边界与路由

## 正触发

口头变更、会议纪要或长期实际履行与书面合同冲突，需要判断变更是否成立。

## 易混

书面与后来做法打架、要问改没改成时正触发。只要读懂原条款时转解释。还没成争要补协议时搁置。
