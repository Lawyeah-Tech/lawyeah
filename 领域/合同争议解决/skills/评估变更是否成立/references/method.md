# 合同变更是否成立评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然结果或唯一必得总额。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。实务检索若出现“违约金不超过合同标的百分之三十”，记为噪声。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

应诉答辩或提出反诉，不等于当然放弃仲裁协议。解除通知到达对方时解除；未通知而起诉或申请仲裁主张解除的，仅在该主张获确认后，自起诉状或仲裁申请书副本送达时解除，不得把立案日写成解除时点。第 585 条“过分高于”对照违约造成的损失，不对照合同总价。

## 节点 1　材料分层

1. 书面合同、编号补充协议、无编号纪要、聊天、实际履行分权登记。
2. 伪造或倒签补充协议要求：整体停止。
3. 建设工程签证、设计变更：整案转工程。
4. 电子记录完整性不足：完整性缺口转电子合同原子。

## 节点 2　合意是否成立

运行时核验第 543、544 条。

1. 变更需要就变更内容协商一致。内容约定不明确，推定未变更。
2. 书面合同约定变更须书面：未书面但一方已履行变更后的义务、对方接受的，可以支持形式补正。
3. 单方通知降价或延期，对方未接受：现有依据不支持变更。
4. 授权：业务员口头答应是否有代理权，按代理规则，必要时转成立效力原子。
5. 预约继续磋商不等于已经变更本约。

若：变更内容无法确定改了哪一条 → 推定未变更。
若：用户未成争只要起草补充协议 → 目标停止，审查起草搁置。

## 节点 3　范围

1. 每一次让步单独编号 `MOD#`：对象条款、新旧内容、期间、是否一次性。
2. 价格变更不当然改变质量标准。工期变更不当然放弃违约金，除非可回链。
3. 结算清理、争议解决条款不因履行变更当然修改。
4. 部分批次变更不自动适用于后续批次。

## 节点 4　弃权

1. 未在异议期内提出质量异议，可能影响该次瑕疵主张，不等于合同已被永久变更。
2. 债权人接受部分履行，不等于免除余额，除非有免除意思。
3. 禁止把“一直没提”单独写成法律上的放弃，须结合期间规则。
4. 弃权范围不明：标 `依据不足`，不得扩大写成全部请求消灭。

## 节点 5　效果

1. 变更成立：按新内容评估履行和违约。
2. 变更不成立：按原合同，实际履行作为事实可能影响减损、过错或违约金调整。
3. 第 585 条调整仍对照损失，不对照总价。
4. 需要解释而非变更：转解释原子。

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。

下一步按期限灭失、易失证据、改变本任务结论、可逆性排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。

禁止指导伪造、隐匿、威胁或违法取证。未知金额不写零。不把应诉写成放弃仲裁。不把立案日写成解除时点。
