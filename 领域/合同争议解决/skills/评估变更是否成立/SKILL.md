# 评估变更是否成立

## 任务目标

在明确、无利益冲突的单方立场下（主张变更成立或不成立一方或其受托律师，互斥），形成变约评估草案：变约闸、主体与强制接口、`Q#` 路径、`BY#` 变约行（文本切片／协商一致或内容明确／书面特约与形式补正／变更范围／弃权或禁止反言接口／`E#` 回链）。本窗 `BY#` 是变约行草案，不是已改约证明，不是形式已补正，不是整份合同作废，不是全面弃权，不是待签补充协议终稿。本窗闸名只能是变约闸，禁止复用变更闸、变故闸、成立闸、解释闸、形态闸、履抗闸、转承闸、抵留闸、合意闸、填补闸、情势闸、修约闸、改约闸。预留不得占用：立案闸、催告闸、解除闸、发送闸。本窗主行只能是 `BY#`，禁止 `BG#`、`GY#`、`MOD#`、`WG#`、`JX#`、`CL#`、`XD#`、`A#`。主路径只用 `Q-变`，禁止用 `Q-改`、`Q-形`、`Q-故`、`Q-契`、`Q-释`、`Q-填`、`Q-履`、`Q-签` 作主路径。邻窗 `Q-变` 只作转介进本窗；本窗打开为主路径，不是已改约、不是形式已补正。本窗 `Q-签` 只作「评估即已改约或已提交」不关窗码。本窗 `Q-口` 只作「口头即已变更」不关窗码。变约闸打开不等于已改约不等于形式已补正不等于整份作废不等于全面弃权不等于余额已免不等于待签补充协议终稿。当事人协商一致可以变更。内容约定不明确推定未变更。口头变更不是已改约。会议纪要不是当然变更。长期实际履行可能构成变更，不是当然整份合同作废。约定书面变更但一方已履行变更后义务且对方接受，可能形式补正，不是口头当然已改约。第四百九十条、通则解释第三条是成立形式补正，不是变更已成立。填补漏洞不是已改约。一次让步不是全面弃权。接受部分履行不是免除余额。情势变更不是本窗合意改约。劳动一个月口头变更不得套一般合同。未知不写零。不写补充协议终稿。不代签署。不选定法院。不代提交。不定罪。伤残等级与本窗无关，禁止折入。

`depends-on` 为空。主成果是条款解释或填补终稿转 `解释争议条款与填补漏洞`。主成果是框架与订单效力层级转 `评估框架协议与订单冲突`。主成果是情势变更终稿转 `评估不可抗力情势变更与履行不能`。主成果是未成争补签补充协议转审查起草（本窗搁置）。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：一般合同口头变更、会议纪要或长期实际履行与书面合同冲突，需要评估变更是否成立。「已经改了」「纪要上写了就算改了」「一直这么做整份作废」仍正触发，成果状态 `草案`。书面、合意、范围未核验仍正触发：有可编号书面合同与冲突文本或履行碎片则变约闸打开或半开，第 6 节出 `BY#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出已改约终稿」才关闸，仍交十节，第 6 节不出 `BY#` 终稿，第 7 节不得出补充协议或诉状，窗口不关。用户要把口头写成已改约、把纪要写成当然变更、把内容不明写成已变更、把填补写成已改约、把一次让步写成全面弃权、把接受部分履行写成免除余额、把长期履行写成整份作废、把情势写成合意改约、把未知写成零，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `BY#` 草案。不得因「不代签署」「不写补充协议」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是条款解释或填补终稿（转 `解释争议条款与填补漏洞`）；
- 主成果是框架与订单效力层级（转 `评估框架协议与订单冲突`）；
- 主成果是情势变更终稿（转 `评估不可抗力情势变更与履行不能` 或 `提起情势变更变更或解除之诉`）；
- 主成果是成立或代理权限终稿（转 `评估合同成立与效力`）；
- 主成果是电子记录到达终稿（转 `评估电子合同成立与送达`）；
- 主成果是争议总图（转 `评估合同争议`）；
- 尚未成争，只要改合同或补签补充协议（审查起草领域，本窗搁置，只说明不实施）；
- 建设工程签证设计变更、金融合同变更批准、商品房认购更名、海事航次书面、劳动合同一个月口头变更专项主轴。

双方秘密、伪造补充协议或纪要或聊天、倒签变更日、教唆隐匿原合同或对抗合法执行、违法取证**不在负触发表**，走整体停止。「口头即已改约」「纪要即当然变更」「内容不明仍已变更」「填补即已改约」「一次让步即全面弃权」「长期履行即整份作废」「未知写零」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不代签署」「不写补充协议」是交付禁令，不是负触发。主成果才转；出现「变更」「纪要」「口头」一词不是转出。

## 建立工作坐标

确认：评估授权；单方立场；书面合同版本；冲突的口头、纪要或履行碎片；法域。

口头「已经改了」「纪要上写了就算改了」「一直这么做整份作废」只登记 `S#`／`V#`。不得升格已改约、形式已补正或全面弃权，**不得单独算作开闸材料**。可编号书面合同与冲突文本或履行碎片可开闸。本窗不执行发送，不代签署，不代提交，不写补充协议或诉状。

立场只许主张变更成立或不成立一方或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：变约闸关闭，仍交十节，不是整体停止。无书面评估授权但单方立场已闭合、且已有碎片：变约闸部分打开，仍交十节，不是整体停止。提出伪造补充协议或纪要或聊天、倒签变更日、教唆隐匿原合同或对抗合法执行或违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`BY#` 变约行；`V#` 版本；`E#` 证据形态回链（书面合同、纪要或聊天、实际履行凭证，不是发送闸，不是已改约证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`BG#`、`GY#`、`MOD#`、`WG#`、`JX#`、`CL#`。技能正文中的条号是检索锚点，不是已核验 `L#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。未知不写零。口头 ≠ 已改约。纪要 ≠ 当然变更。内容不明 ≠ 已变更。填补 ≠ 已改约。一次让步 ≠ 全面弃权。接受部分履行 ≠ 免除余额。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或裁判案例检索。本窗是评估，**不要**用 `search_template` 生成补充协议、已改约证明或诉状。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现口头即已改约、纪要即当然变更、填补即已改约、一次让步即全面弃权、劳动一个月套一般合同的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效合同法第七十七条、第七十八条、第三十六条、合同法解释（二）、把第五百三十三条情势当合意改约、把第四百九十条或通则解释第三条成立形式补正当变更已成立、把劳动争议解释（一）第四十三条一个月口头变更套一般合同当作现行规则。MCP 可能先返回合同法第七十七条或劳动争议解释（一）第四十三条而漏第五百四十四条、通则解释第十四条，不得把失效条文或劳动规则写成一般合同已改约。MCP 效力字段与公布施行日冲突时，以施行日为准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的已改约、形式已补正或全面弃权结论保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民法典第五百四十三条当事人协商一致，可以变更合同。第五百四十四条当事人对合同变更的内容约定不明确的，推定为未变更。第五百零九条应当全面履行，不得擅自变更或解除，不是已改约主条。第四百六十九条书面、口头或其他形式，数据电文可视为书面，是形式能力不是已改约。第四百九十条应书面未书面、一方已履行主要义务且对方接受时合同成立，是成立形式补正，不是变更已成立。通则解释第三条未书面或未签章但能确定已履行主要义务的可认定合同成立，只对照成立。通则解释第十四条多份合同均系真实意思表示的，应当在查明成立先后和实际履行情况的基础上认定内容是否发生变更；法律、行政法规禁止变更的，相应变更无效。通则解释第一条履行行为可作解释因素，不是已改约。第五百一十条、第五百一十一条约定不明走协议补充、相关条款或习惯、分项填补，只开解释窗，填补不是已改约。第五百三十三条、通则解释第三十二条情势变更只开变故窗，不得单方通知解除，不是本窗合意改约。噪声：已失效合同法第七十七条、第七十八条、第三十六条及解释（二）；劳动争议解释（一）第四十三条一个月口头变更不得套一般合同。技能正文条号不是 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变协商一致、内容明确、书面特约或形式补正的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补口头不是已改约、纪要不是当然变更、内容不明不是已变更、填补不是已改约、一次让步不是全面弃权、劳动一个月不是一般合同规则的实务反例。实务把合同法第七十七条或劳动一个月写成现行一般规则时记为噪声。
- `search_case_by_fact` 只比较事实差异与翻转条件：口头不是已改约；纪要不是当然变更；内容不明不是已变更；未书面且无履行接受不是形式已补正；一方履行对方未接受不是已变更；一次让步不是全面弃权；接受部分履行不是免除余额；填补不是已改约；长期履行不是整份作废；情势不是合意改约；成立形式补正不是变更已成立。无类案不得写成已改约终稿。评估类禁止用 `search_template` 生成补充协议、已改约证明或诉状。

工具不可用时继续书面合同、冲突文本或履行碎片和 `BY#` 编目；已改约、形式已补正、全面弃权结论字段停止。不得拒跑，不得凭记忆写成已改约。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、变约闸与不关窗

主成果才整案转出。双方秘密、伪造补充协议或纪要、倒签变更日第一次停。口头即已改约、填补即已改约不关窗。闸关仍交十节，第 6 节不出 `BY#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

口头、纪要、实际履行、书面补充分列。本节禁止出 `BY#` 终稿。

### 3. 变约闸与路径 `Q#`

本节禁止出 `BY#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-变`。

### 4. 变约行 `BY#`

文本切片、合意与内容明确、书面特约与形式补正、范围、弃权接口。状态 `草案`。禁止升格已改约、整份作废、全面弃权。无 `E#` 不得写已改约。

### 5. 解释、框架、情势、成立、电子接口

解释填补转解释窗。框架订单转框架窗。情势转变故窗。成立代理转成立窗。电子到达转电子窗。第 7 节不得夹带 `BY#` 终稿或补充协议绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造补充协议或纪要或聊天、倒签变更日、教唆隐匿原合同或对抗合法执行或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：变约闸关闭，仍交十节，不是整体停止。无书面评估授权但有碎片：变约闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：协商一致、内容明确、书面特约、形式补正、变更范围、施行日未核验。口头即已改约、纪要即当然变更、内容不明仍已变更、填补即已改约、一次让步即全面弃权、长期履行即整份作废、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `BY#` 草案。
- `目标停止`：主目标变为未成争补签补充协议或情势诉状终稿。禁止把「口头即已改约」当作用户错误主张时的目标停止；那是不关窗。

禁止指导伪造补充协议、倒签纪要或隐匿原合同。不给胜诉率。不定罪。不选定法院。不代提交。不代签署。未知不写零。不写补充协议。不写诉状。

## 交付
