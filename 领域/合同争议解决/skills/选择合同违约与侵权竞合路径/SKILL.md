# 选择合同违约与侵权竞合路径

## 任务目标

在明确、无利益冲突的单方立场下（受损害方或其受托律师，互斥），形成竞合路径草案：竞合闸、主体与强制接口、`Q#` 路径、`JH#` 竞合行（损害切片／择一范围与并行分界／违约路径成立与效果／侵权路径成立与效果／时效管辖仲裁与填平接口／`E#` 回链）。本窗 `JH#` 是竞合行草案，不是已选定证明，不是已胜诉，不是已立案，不是双份全额方案，不是诉状。本窗闸名只能是竞合闸，禁止复用选择闸、请求闸、侵权闸、违约闸、路径闸、框约闸、争议闸、精算闸、形态闸、起诉闸、论坛闸。预留不得占用：立案闸、催告闸、解除闸、发送闸。本窗主行只能是 `JH#`，禁止 `KY#`、`DY#`、`BY#`、`CL#`、`JJ#`、`SJ#`、`ZT#`、`A#`。主路径只用 `Q-择`，禁止用 `Q-合`、`Q-竞`、`Q-违`、`Q-侵`、`Q-架`、`Q-签`、`Q-测`、`Q-诉` 作主路径。邻窗 `Q-择` 只作转介进本窗；本窗打开为主路径，不是已选定、不是已胜诉。本窗 `Q-签` 只作「比较即已选定、已胜诉或已提交」不关窗码。`Q-违`、`Q-侵` 不得升主路径。竞合闸打开不等于已选定不等于已胜诉不等于已立案不等于双份可赔不等于待提交终稿。因一方违约损害对方人身或财产权益的，受损害方有权选择请求承担违约责任或者侵权责任。择一只约束该相对方该行为，不得就同一损失双份重复填补。选违约且损害人格权并造成严重精神损害的，不影响请求精神损害赔偿；未核验人格权与严重性则待核，不是违约当然可赔，也不是当然不可赔。选侵权不是当然避开仲裁。纯金钱迟延不是当然独立侵权竞合。不同被告并行不是第一百八十六条全球互斥。人身伤害主轴负触发转侵权领域。比较表不是已选定。未知不写零。不写诉状。不选定法院。不代提交。不定罪。伤残等级与本窗无关，禁止折入。

`depends-on` 为空。主成果是人身伤害竞合终稿转 `选择人身损害违约侵权竞合路径`。主成果是测算终稿转 `测算违约金与损害赔偿`。主成果是管辖仲裁终稿转 `评估合同管辖与仲裁协议`。主成果是起诉状转 `提起合同纠纷一审`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：同一事实可主张违约或侵权，需要比较时效、管辖、赔偿并择一。「两份都要拿」「选了就算赢了」「选侵权就不用管仲裁」仍正触发，成果状态 `草案`。时效、管辖、精神损害未核验仍正触发：有可编号同一事实与相对方碎片则竞合闸打开或半开，第 6 节出 `JH#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出已选定／已胜诉终稿」才关闸，仍交十节，第 6 节不出 `JH#` 终稿，第 7 节不得出诉状或双份方案，窗口不关。用户要把双份全额写成可执行、把选择写成已胜诉、把选侵权写成当然避开仲裁、把违约写成当然不赔精神损害、把纯金钱迟延写成独立侵权、把比较表写成已选定、把未知写成零，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `JH#` 草案。不得因「不写诉状」「不双份索赔」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是人身伤害竞合终稿（转侵权领域 `选择人身损害违约侵权竞合路径`）；
- 主成果是测算终稿（转 `测算违约金与损害赔偿`）；
- 主成果是管辖或仲裁条款终稿（转 `评估合同管辖与仲裁协议`）；
- 主成果是起诉状终稿（转 `提起合同纠纷一审` 或 `提起合同仲裁`）；
- 主成果是争议总图（转 `评估合同争议`）；
- 尚未成争，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）；
- 要求同时按违约和侵权拿两份重复赔偿作为主目标且拒绝比较表（仍先按不关窗处理双份格；仅当用户把「双份方案终稿」当唯一主成果才目标停止）；
- 产品责任群体或刑民交叉主目标；建设工程、金融、房产、海事、劳动专项主轴。

双方秘密、伪造合同或损失、倒签、隐匿路径、违法取证**不在负触发表**，走整体停止。「双份全额」「选择即已胜诉」「选侵权当然避开仲裁」「违约当然不赔精神损害」「未知写零」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不写诉状」「不双份索赔」是交付禁令，不是负触发。主成果才转；出现「竞合」「侵权」「违约」一词不是转出。

## 建立工作坐标

确认：评估授权；单方立场；同一事实与相对方；合同与损害碎片；法域。

口头「两份都要拿」「选了就算赢了」「选侵权就不用管仲裁」只登记 `S#`／`V#`。不得升格已选定、已胜诉或双份可赔，**不得单独算作开闸材料**。可编号同一事实与相对方碎片可开闸。本窗不执行发送，不代提交，不写诉状。

立场只许受损害方或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：竞合闸关闭，仍交十节，不是整体停止。无书面评估授权但单方立场已闭合、且已有碎片：竞合闸部分打开，仍交十节，不是整体停止。提出伪造合同或损失、倒签、隐匿路径或违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`JH#` 竞合行；`V#` 版本；`E#` 证据形态回链（同一事实、合同、损害形态，不是发送闸，不是已选定证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`KY#`、`JJ#`、`SJ#`、`ZT#`、`CL#`。技能正文中的条号是检索锚点，不是已核验 `L#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。未知不写零。择一 ≠ 已胜诉。双份 ≠ 可执行。选侵权 ≠ 当然避开仲裁。选违约 ≠ 当然不赔精神损害。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或裁判案例检索。本窗是评估，**不要**用 `search_template` 生成诉状、已选定证明或双份索赔方案。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现双份全额、选择即已胜诉、选侵权当然避开仲裁、违约当然不赔精神损害的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效合同法第一百二十二条、合同法解释（一）第三十条、2010 年旅游纠纷规定第二十一条「违约之诉不支持精神损害」、已失效侵权责任法当作现行规则。MCP 可能先返回合同法第一百二十二条或公司法第一百八十六条归入而漏民法典第一百八十六条、第九百九十六条，不得把失效竞合条或公司归入条写成已择一。MCP 效力字段与公布施行日冲突时，以施行日为准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的已选定、双份可赔或精神损害结论保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民法典第一百八十六条因一方违约损害对方人身或财产权益，受损害方有权选择请求承担违约责任或者侵权责任。第一百八十七条因同一行为应当承担民事、行政和刑事责任的，行政或刑事责任不影响民事责任；财产不足以支付的，优先用于民事责任。第九百九十六条因违约损害人格权并造成严重精神损害，选违约责任的，不影响请求精神损害赔偿。第五百八十四条违约损失赔偿以可预见为限。第五百八十五条约定金对照损失，不是必得。第五百零六条造成对方人身损害的免责条款无效。第一千一百六十五条过错侵权。第一千一百八十二条、第一千一百八十三条侵权财产与人身精神损害，人身伤害主轴只开接口。第一百八十八条时效分列。仲裁事项是否覆盖基于该合同的侵权之诉运行时核验，不得凭记忆写成当然覆盖或当然不覆盖。噪声：已失效合同法第一百二十二条；解释（一）第三十条；2010 年旅游纠纷规定第二十一条。技能正文条号不是 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变择一、双赔互斥、精神损害或仲裁覆盖的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补仲裁是否约束基于该合同的侵权之诉、预备合并与禁止双赔、选违约仍可主张精神损害的实务反例。实务把旅游纠纷规定第二十一条或合同法第一百二十二条写成现行时记为噪声。
- `search_case_by_fact` 只比较事实差异与翻转条件：选择不是已胜诉；同一相对方择一不是双份全额；人身伤害主轴不是本窗终稿；精神损害不是当然写入违约路径，也不是当然不可赔；选侵权不是当然避开仲裁；纯金钱迟延不是独立侵权竞合；不同被告并行不是第一百八十六条全球互斥。无类案不得写成已选定、已胜诉或双份可赔终稿。评估类禁止用 `search_template` 生成诉状、已选定证明或双份索赔方案。

工具不可用时继续同一事实、相对方碎片和 `JH#` 编目；已选定、已胜诉、双份可赔结论字段停止。不得拒跑，不得凭记忆写成已选定或双份可赔。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、竞合闸与不关窗

主成果才整案转出。双方秘密、伪造合同或损失、倒签第一次停。双份全额、选择即已胜诉不关窗。闸关仍交十节，第 6 节不出 `JH#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

同一事实、相对方、违约构成、侵权构成分列。本节禁止出 `JH#` 终稿。

### 3. 竞合闸与路径 `Q#`

本节禁止出 `JH#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-择`。

### 4. 竞合行 `JH#`

损害切片、择一范围、违约与侵权效果、时效管辖仲裁。状态 `草案`。禁止升格已选定、已胜诉、双份可赔。无 `E#` 不得写已选定。

### 5. 测算、管辖、起诉、人身、期间接口

测算转测算窗。管辖仲裁转管辖窗。起诉转起诉窗。人身伤害转侵权竞合窗。期间转期间窗。第 7 节不得夹带 `JH#` 终稿或诉状绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造合同或损失、倒签、隐匿路径或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：竞合闸关闭，仍交十节，不是整体停止。无书面评估授权但有碎片：竞合闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：择一范围、时效、管辖连结点、仲裁覆盖、人格权与严重精神损害、施行日未核验。双份全额、选择即已胜诉、选侵权当然避开仲裁、违约当然不赔精神损害、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `JH#` 草案。
- `目标停止`：主目标变为人身侵权整案或双份重复索赔方案终稿。禁止把「双份全额」当作用户错误主张时的目标停止；那是不关窗。

禁止指导伪造合同或损失。不给胜诉率。不定罪。不选定法院。不代提交。未知不写零。不写诉状。不输出双份全额方案。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。竞合闸关闭仍交十节，第 6 节不出 `JH#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `JH#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。竞合闸未打开时不得交付「已选定」或「已胜诉」。边界见 [路由](references/routing.md)。
