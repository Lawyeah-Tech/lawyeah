# 边界与路由

## 正触发

同一事实可主张违约或侵权，需要比较时效、管辖、赔偿并择一。从零、碎片、时效未核验、无书面评估授权仍正触发：有可编号同一事实与相对方碎片则闸开或半开，出 `JH#` 草案，保持草案。本次不写诉状、不双份索赔是交付禁令，不是开窗条件。双份全额、选择即已胜诉、选侵权当然避开仲裁，仍正触发。把比较表写成已选定，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造合同或损失、倒签、隐匿路径的停止，优先于负触发。上述信号不在下表。不写诉状不是负触发。「双份全额」「选择即已胜诉」「选侵权当然避开仲裁」「违约当然不赔精神损害」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 人身伤害竞合终稿 | `选择人身损害违约侵权竞合路径` |
| 测算终稿 | `测算违约金与损害赔偿` |
| 管辖或仲裁条款终稿 | `评估合同管辖与仲裁协议` |
| 起诉状终稿 | `提起合同纠纷一审` 或 `提起合同仲裁` |
| 争议总图 | `评估合同争议` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |
| 产品责任群体／刑民交叉／工程／金融／房产／海事／劳动 | 对应领域 |

不得因「不写诉状」或「不双份索赔」关窗。拟竞合比较仍正触发，不得写成已选定或已胜诉。

## 易混

本窗闸名只能是竞合闸，不是选择闸，不是侵权闸，不是精算闸，不是争议闸。`JH#` 不是 `SJ#`，不是 `ZT#`，不是 `JJ#`。主路径是 `Q-择`，不是 `Q-合`，不是 `Q-竞`，不是 `Q-违`，不是 `Q-侵`。`Q-违` 是形态窗「构成违约即当然解除」不关窗码。`Q-侵` 是抵留窗不关窗码。`JJ#` 是僵局行。择一不是已胜诉。同一损失不得双份重复索赔。选违约不是当然不得精神损害。选侵权不是当然避开仲裁。已失效合同法第一百二十二条不是现行。2010 年旅游纠纷规定第二十一条不是现行一般规则。MCP 可能先返回合同法第一百二十二条或公司法第一百八十六条归入而漏第一百八十六条、第九百九十六条。「损失清单改到签约前」整体停止。本窗不执行发送，不代提交。不选定法院。不写诉状。不输出双份全额方案。
