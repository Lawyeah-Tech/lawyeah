# 选择合同违约与侵权竞合路径方法

本文件是可执行判断节点。择一不是已胜诉。同一损失不得双份重复索赔。选违约不是当然不得精神损害。选侵权不是当然避开仲裁。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已选定、已胜诉、双份全额、选定法院、代提交、未知写零。本任务不定罪，不写诉状，不把比较表写成已选定。本窗闸名只能是竞合闸，禁止复用选择闸、侵权闸、违约闸、精算闸。预留不得占用：立案闸、催告闸、解除闸、发送闸。本窗 `JH#` 是竞合行。主路径只用 `Q-择`，禁止用 `Q-合`、`Q-竞`、`Q-违`、`Q-侵`、`Q-签` 作主路径。本窗 `Q-签` 只作「比较即已选定、已胜诉或已提交」不关窗码。英文 id 禁止使用，一律用中文技能名 `选择合同违约与侵权竞合路径`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效合同法第一百二十二条、解释（一）第三十条、2010 年旅游纠纷规定第二十一条、把公司法第一百八十六条归入写成竞合时记为噪声。禁止指导伪造合同或损失。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现损害碎片扫描，不是默认闭集。
`JH#` 固定列：`编号｜损害切片（同一事实／相对方／不同被告）｜择一范围与并行分界｜违约路径成立与效果｜侵权路径成立与效果｜时效管辖仲裁与填平接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已选定」或「双份可赔」。无 `E#` 不得写已选定。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-择`。禁止 `KY#`、`JJ#`、`SJ#`、`ZT#`、`A#`、`N#`。

口头「两份都要拿」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：违约与侵权分列比较。第九百九十六条选违约不影响精神损害赔偿，前提是人格权加严重精神损害。

## 节点 0　分流、立场、竞合闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造合同或损失、倒签、隐匿路径不进负表。利益冲突未解不进整体停止。不写诉状、不双份索赔不是负触发。把双份全额写成可执行、把选择写成已胜诉不是负触发。

整案转出只交付第 1、2、10 节，不出 `JH#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是人身伤害竞合终稿 | 负触发 `选择人身损害违约侵权竞合路径` |
| 主成果是测算终稿 | 负触发 `测算违约金与损害赔偿` |
| 主成果是管辖或仲裁条款终稿 | 负触发 `评估合同管辖与仲裁协议` |
| 主成果是起诉状终稿 | 负触发 `提起合同纠纷一审` 或 `提起合同仲裁` |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 产品责任群体／刑民交叉主目标／工程／金融／房产／海事／劳动 | 整案转对应领域 |
| 「不写诉状」「不双份索赔」 | 交付禁令，不是负触发 |

出现「竞合」「侵权」「违约」一词不是转出。

竞合闸打开（可出 `JH#` 草案，仍不得标「已选定／已胜诉／双份可赔」）须同时满足：单方无冲突立场已闭合；主成果是竞合路径比较，不是诉状、不是双份方案终稿；至少一行可编号同一事实与相对方碎片。口头「两份都要拿」不算单独开闸材料。

竞合闸部分打开：已有碎片，但时效、管辖或精神损害未闭合；对应格待核；仍交十节。无书面评估授权但单方立场已闭合且已有碎片：竞合闸部分打开，仍交十节，不是整体停止。

竞合闸关闭（仍正触发）：无一可编号碎片。「今天必须出已选定／已胜诉终稿」而无最小碎片不得开闸。不出 `JH#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `JH#` 终稿，**第 7 节不得出诉状或双份方案**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「双份全额」「选择即已胜诉」「选侵权当然避开仲裁」「违约当然不赔精神损害」「纯金钱迟延即独立侵权」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `JH#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 竞合闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造合同或损失、倒签、隐匿路径或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个损害切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `JH#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 同一事实 | 相对方、行为、损害分列 | 不同被告套第一百八十六条全球互斥 |
| 违约 | 可预见、减损、违约金、继续履行分列 | 比较表升格已选定 |
| 侵权 | 过错、因果、人身或财产分列 | 纯金钱迟延升格独立侵权 |
| 精神损害 | 人格权、严重性分列 | 当然写入或不写入违约路径 |
| 仲裁 | 事项是否覆盖侵权分列 | 选侵权升格当然避开 |

检索锚点（写入 `L#` 前须核验）：见技能正文 MCP 节。噪声：已失效合同法第一百二十二条；旅游纠纷规定第二十一条。

## 节点 3　竞合行 `JH#`

按已出现损害碎片扫描，不是默认闭集。每条须能指向择一范围、违约效果、侵权效果或时效管辖之一。

无 `E#` 不得写已选定。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止唯一截止日。禁止双份全额。

热冲突强制处理：

- 双份全额／选择即已胜诉／选侵权当然避开仲裁／违约当然不赔精神损害／纯金钱迟延即独立侵权／未知写零 → 该格不支持或字段停止；仍出其他 `JH#`。
- 无一碎片 → 关闸，不出 `JH#` 终稿，窗口不关。
- 指导伪造合同或损失、倒签、隐匿 → 整体停止，不是该格不支持。

## 节点 4　测算、管辖、起诉、人身、期间接口

第 7 节只开接口，不得夹带 `JH#` 终稿或诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待事实编号」，不得补写已选定。不选定法院。不代提交。不写诉状。不输出双份全额。

下一步只转介：`测算违约金与损害赔偿`、`评估合同管辖与仲裁协议`、`评估争议期间`、`提起合同纠纷一审`、`提起合同仲裁`、`应对合同纠纷一审`、`选择诉讼仲裁或督促程序`、`准备索赔或违约金主张通知`、`评估质量瑕疵与检验期间`、`评估迟延拒绝与不完全履行`、`建立合同争议证据案卷`、`评估解除权是否成立`、`评估定金罚则争议`、`评估继续履行是否可能`、`评估争议中的格式条款`、`评估合同争议`。人身伤害转 `选择人身损害违约侵权竞合路径`。禁止此致某院。

若 if 用户催促「两份都要拿／选了就算赢了／选侵权就不用管仲裁／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「竞合闸与竞合行草案」。本窗不执行发送。不包含：已选定、已胜诉、双份全额终稿、诉状。禁止选边治愈。禁止双份重复索赔。禁止选择即已胜诉。禁止指导伪造。竞合闸打开 ≠ 已选定 ≠ 已胜诉 ≠ 双份可赔。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标竞合终稿已形成。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：设备买卖质量争议，买方要违约金加侵权全额再加精神损害，主张两份都要拿、选了就算赢了、选侵权就不用管合同仲裁。损害主要是修理费和停工损失，人格权未核验。用户不清楚先写零。竞合闸打开或半开。`Q-双`、`Q-胜`、`Q-仲`、`Q-精`、`Q-签`、`Q-零` 不打开为可靠路径。第 6 节不得把已选定、已胜诉、双份全额、0 写入可执行 `JH#`；对应格 `现有依据不支持` 或字段停止；仍出同一事实分列、违约与侵权效果比较、仲裁覆盖待核、第九百九十六条待核等其他 `JH#`。不关窗。不写诉状。不输出双份方案。

场景②：用户同时交出己方「把损失清单改到签约前、鉴定先补一份假的」与对方「从未收到质量异议」口径，并要「两份判决都去要」。命中双方秘密＋伪造损失。第一次整体停止。只交第 1、10 节。不出 `JH#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代违法方案。
