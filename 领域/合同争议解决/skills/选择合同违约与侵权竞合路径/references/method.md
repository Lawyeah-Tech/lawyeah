# 违约与侵权竞合选择方法

本文件是可执行判断节点，不是栏目说明书。每个会改变结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然结果或唯一必得总额。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。实务检索若出现“违约金不超过合同标的百分之三十”，记为噪声。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

应诉答辩或提出反诉，不等于当然放弃仲裁协议。解除通知到达对方时解除；未通知而起诉或申请仲裁主张解除的，仅在该主张获确认后，自起诉状或仲裁申请书副本送达时解除，不得把立案日写成解除时点。第 585 条“过分高于”对照违约造成的损失，不对照合同总价。

## 节点 1　是否竞合

1. 须有合同关系且同一行为同时符合违约和侵权构成。
2. 纯金钱给付迟延通常只有违约路径，没有独立侵权利益时不制造竞合。
3. 产品缺陷致人身损害：主轴转侵权，合同路径只作备位说明。
4. 诈骗、伪造资金逃匿：刑民交叉 P2，`unavailable`，只标红旗。

若：用户要两份重复赔偿 → 停止该方案，说明禁止重复填补同一损失。

## 节点 2　实体比较

1. 违约赔偿：第 584 条可预见；违约金第 585 条对照损失不对照总价。
2. 侵权：过错、违法、因果、损害。故意或重大过失可能影响约定限制责任条款。
3. 精神损害赔偿通常不属于违约，人身伤害主轴已转出。
4. 惩罚性赔偿仅在特别法有规定时讨论，一般合同不得发明。
5. 继续履行、修理更换是违约特有，侵权路径通常是金钱或停止侵害。

## 节点 3　程序比较

1. 诉讼时效：合同债权一般为三年；侵权同样三年但起算可能不同。须分列，不混算。
2. 管辖：合同履行地或协议管辖；侵权行为地或被告住所地。
3. 仲裁协议：合同请求常被覆盖。侵权请求是否属于仲裁事项标待核，不得因已应诉写成放弃。
4. 应诉不等于放弃仲裁。

## 节点 4　选择

运行时核验第 186 条。

1. 记录用户选定或给出比较后由用户选。未选前不指定唯一路径。
2. 选择侵权则合同违约金请求通常不能并行就同一损失主张。
3. 选择违约则侵权精神抚慰金通常不能并行。
4. 与第三人侵权并存时，不在本任务分配最终份额。

## 节点 5　交接

1. 选定违约诉讼：`提起合同纠纷一审`。
2. 选定仲裁：`提起合同仲裁`。
3. 质量或鉴定仍按原接口。
4. 不写胜诉率。

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。

下一步按期限灭失、易失证据、改变本任务结论、可逆性排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。

禁止指导伪造、隐匿、威胁或违法取证。未知金额不写零。不把应诉写成放弃仲裁。不把立案日写成解除时点。
