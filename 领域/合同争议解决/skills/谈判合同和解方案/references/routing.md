# 边界与路由

## 正触发

一般合同已成争，协商渠道尚未切断，单方需要底线、让步、弃权范围、付款清理和执行力提示，而不是可签协议正文。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 条件已谈拢，只要协议正文 | `起草合同和解协议` |
| 只要司法确认、仲裁调解书或公证赋强 | `办理合同和解执行力补强` |
| 只要诉讼或仲裁调解利弊 | `评估合同调解方案与效力` |
| 执行阶段分期或以物抵债 | `准备合同执行和解` |
| 只要总体评估 | `评估合同争议` |
| 只要答辩 | `应对合同纠纷一审` |
| 已决定起诉且只要诉状 | `提起合同纠纷一审` |
| 只要发送版催告或解除函 | `准备催告履行或补救通知` 或 `准备解除通知` |
| 工程／金融／房产／海事／劳动 | 对应领域整案转出 |
| C 端 032／012／011 | 大众专项，只分流，不回改、不实施 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

已起诉或已仲裁但用户仍要谈条件：正触发，程序状态写入方案约束。用户只要答辩：负触发，不把本任务改写成答辩包。报价要点已闭合、只要合同条款和签章页：负触发至起草和解。有效仲裁协议下谈不拢：论坛主位仍是仲裁，不得直接写应起诉。
