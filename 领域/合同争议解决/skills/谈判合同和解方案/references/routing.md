# 边界与路由

## 正触发

一般合同已成争，协商渠道尚未切断，单方需要底线、让步、弃权范围和执行力提示，而不是可签协议正文。从零、碎片、弃权未核验、无书面谈判授权仍正触发：有可编号争点或报价碎片则闸开或半开，出 `FA#` 草案，保持草案。已起诉、已仲裁或已保全，只要仍可自行和解，仍正触发。本次不写已签署、不代签署、不保证执行是交付禁令，不是开窗条件。要点即已签署、口头谈拢即已生效、单独和解即已可执行、永不追究覆盖未知，仍正触发。

双方秘密、伪造协议或签章、倒签签署日、伪造流水、以和解掩盖犯罪或逃废债务、违法取证的停止，优先于负触发。上述信号不在下表。不代签署不是负触发。「要点即已签署」「口头谈拢即已生效」「单独和解即已可执行」「永不追究覆盖未知」「约定金即必得」「谈不拢即应起诉」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 已谈拢可签和解协议正文 | `起草合同和解协议` |
| 司法确认、仲裁调解书或公证赋强手续 | `办理合同和解执行力补强` |
| 诉讼、仲裁或人民调解利弊与效力 | `评估合同调解方案与效力` |
| 执行阶段分期或以物抵债 | `准备合同执行和解` |
| 争议总图 | `评估合同争议` |
| 起诉包 | `提起合同纠纷一审` |
| 答辩包 | `应对合同纠纷一审` |
| 发送版催告 | `准备催告履行或补救通知` |
| 发送版解除通知 | `准备解除通知` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |
| 工程／金融／房产／海事／劳动主轴 | 对应领域 |

不得因「不写已签署」或「不代签署」关窗。拟和解方案仍正触发，不得写成已签署或已可执行。

## 易混

本窗闸名只能是方案闸，不是和解闸，不是谈判闸，不是让步闸，不是谈拢闸，不是争议闸，不是精算闸。`FA#` 不是 `HJ#`，不是 `TP#`，不是 `RB#`，不是 `N#`。主路径是 `Q-方`，不是 `Q-和`，不是 `Q-谈`，不是 `Q-让`。`Q-和` 留给 `起草合同和解协议`，本窗只开接口。`Q-谈` 是公司治理退出谈判窗主路径，本窗不打开。`Q-执` 只作「单独和解即已可执行」不关窗码。要点不是已签署。口头谈拢不是已生效。单独和解不是已可强制执行。永不追究不是覆盖未知。约定金不是必得。已读不是到达。报价不是已中断时效。1991 年民事诉讼法第五十三条不是现行自行和解。2012 年第一百九十四条不是现行第二百零五条。已失效 2002 年人民调解协议规定不是现行。破产法和解不是本合同和解。已失效《合同法》不是现行。「签署日改到上周」「流水先做一版」整体停止。本窗不执行发送，不代签署，不代提交。不选定法院。不保证司法确认。
