# 谈判合同和解方案方法

本文件是可执行判断节点。要点不是已签署。口头谈拢不是已生效。单独和解不是已可强制执行。永不追究不得覆盖未知。约定数字不是必得。构成违约不是必须以解除为成交条件。已读不是已到达。报价不是已中断时效。打包了结不是分项已闭合。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已签署、已可执行、选定法院、代签署、代提交、未知写零。本任务不定罪，不执行发送，不把要点写成已签署。本窗闸名只能是方案闸，禁止复用和解闸、谈判闸、让步闸、谈拢闸、争议闸、论坛闸、解除闸、催告闸、发送闸、精算闸、证据闸、管辖闸。预留不得占用：立案闸、和解闸。本窗 `FA#` 是方案行。主路径只用 `Q-方`，禁止用 `Q-和`、`Q-谈`、`Q-让`、`Q-总`、`Q-诉`、`Q-签` 作主路径。本窗 `Q-签` 只作「要点即已签署」不关窗码。英文 id 禁止使用，一律用中文技能名 `谈判合同和解方案`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991 年民事诉讼法第五十三条共同诉讼当现行第五十三条自行和解、2012 年第一百九十四条当现行第二百零五条、已失效 2002 年人民调解协议规定、破产法和解、已失效《合同法》、把要点写成已签署或把单独和解写成已可执行时记为噪声。禁止指导伪造协议、倒签签署日或掩盖犯罪。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现争点碎片扫描，不是默认闭集。
`FA#` 固定列：`编号｜争点切片｜底线｜让步至｜弃权范围｜执行力路径｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已签署」或「已可强制执行」。无 `E#` 不得写已签署。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-方`。禁止 `HJ#`、`TP#`、`RB#`、`N#`、`W#`、`A#`。文件状态只用 `草案`、`停止`。禁止标 `待签署`。

口头「已经谈拢」「微信说没问题」「已读就算到了」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：继续履行／解除／违约金／赔偿／定金／返还清理分列，禁止合成「一笔了结且已可强制执行」。单独和解必须明示无强制执行力。未获用户就具体范围的明示确认，不得把现有请求写成已放弃。

## 节点 0　分流、立场、方案闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造协议或签章、倒签签署日、伪造流水、以和解掩盖犯罪或逃废债务、违法取证不进负表。利益冲突未解不进整体停止。不写已签署、不代签署、不保证执行不是负触发。

整案转出只交付第 1、2、10 节，不出 `FA#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是已谈拢可签和解协议正文 | 负触发 `起草合同和解协议` |
| 主成果是司法确认、仲裁调解书或公证赋强手续 | 负触发 `办理合同和解执行力补强` |
| 主成果是诉讼、仲裁或人民调解利弊与效力 | 负触发 `评估合同调解方案与效力` |
| 主成果是执行阶段分期或以物抵债 | 负触发 `准备合同执行和解` |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 主成果是起诉包 | 负触发 `提起合同纠纷一审` |
| 主成果是答辩包 | 负触发 `应对合同纠纷一审` |
| 主成果是发送版催告 | 负触发 `准备催告履行或补救通知` |
| 主成果是发送版解除通知 | 负触发 `准备解除通知` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程／金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不写已签署」「不代签署」「不保证执行」 | 交付禁令，不是负触发 |

出现「谈判」「和解」「方案」一词不是转出。

方案闸打开（可出 `FA#` 草案，仍不得标「已签署／已生效／已可强制执行」）须同时满足：单方无冲突立场已闭合；主成果是和解方案要点，不是可签协议、不是赋强手续、不是调解终稿、不是起诉状、不是答辩状；至少一项可编号争点切片、报价档位或弃权碎片。口头「已经谈拢」不算单独开闸材料。已起诉、已仲裁或已保全，只要协商渠道未切断，仍可开闸。

方案闸部分打开：已有碎片，但弃权范围、执行力路径或论坛未闭合；对应格待核；仍交十节。无书面谈判授权但单方立场已闭合且已有碎片：方案闸部分打开，仍交十节，不是整体停止。

方案闸关闭（仍正触发）：无一可编号碎片。「今天必须出已签署终稿」而无最小碎片不得开闸。不出 `FA#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `FA#` 终稿，**第 7 节不得出已签署协议或已可执行**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「要点即已签署」「口头谈拢即已生效」「单独和解即已可执行」「永不追究覆盖未知」「约定金即必得」「打包了结即分项已闭合」「已读即已到达」「报价即已中断时效」「谈不拢即应起诉」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `FA#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 方案闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造协议或签章、倒签签署日、伪造流水、以和解掩盖犯罪或逃废债务、违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个争点切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `FA#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 争点 | 继续履行、解除、违约金、赔偿、定金、返还清理、程序对价分列 | 合成「打包了结」；构成违约写成必须以解除成交 |
| 底线 | 金钱／非金钱／期限／程序分列 | 未测算项目写成零；输出唯一必得总额 |
| 让步至 | 开价、可谈、底线对应具体对价 | 只写「各让一步」 |
| 弃权 | 已确认范围逐项；未知、第三人、未发生事实单列 | 永不追究覆盖未知；未明示写成已放弃 |
| 执行力 | 单独和解无执行力；赋强只开接口 | 聊天一致、律师见证、已读写成可强制执行 |
| 论坛 | 有效仲裁不得写应起诉 | 谈不拢即此致某院 |

检索锚点（写入 `L#` 前须核验）：

- 民法典第一百三十七条：非对话到达相对人时生效；数据电文进入指定系统时生效。已读不是到达。
- 第一百九十五条：时效中断须法定事由。报价草稿或已读不是当然中断。时效规定（2020 修正）第八条须到达；第十四条义务人同意履行才构成中断。
- 第一百九十七条：时效期间约定无效；预先放弃时效利益无效。
- 第四百八十三条：承诺生效时合同成立。口头谈拢不是当然成立。
- 第五百零七条：合同不生效、无效、被撤销或终止，不影响争议解决条款。
- 第五百五十七条：债权因履行、抵销、提存、免除等终止。概括了结不是自动覆盖未知请求。
- 第五百六十六条：解除后返还清理与违约责任分列，不得因一揽子了结省略。
- 第五百六十七条：终止不影响结算和清理条款。
- 第五百七十五条：免除由债权人作出，债务人合理期限内可拒绝。未明示确认不得写成已放弃。
- 第五百七十七条：继续履行、补救或赔偿不是当然解除。
- 第五百八十五条：约定金不是必得。增减须当事人请求。
- 民事诉讼法（2023 修正）第五十三条：双方可以自行和解。噪声：1991 年第五十三条共同诉讼。
- 第一百零一条：即时履行等可不制作调解书。诉讼调解书签收生效须运行时核验现行调解章条号，禁抄 2017 年第九十七条。
- 第二百零五条：依法设立的调解组织调解后，双方自生效之日起三十日内共同申请司法确认。私下和解不得直接写成可司法确认。
- 第二百零六条：确认有效可申请执行；驳回可再调解或起诉，不是丧失实体权利。噪声：2012 年第一百九十四条、第一百九十五条；民诉解释第三百五十一条仍引第二百零一条。
- 民事调解工作规定（2020 修正）第二条：诉讼中自行和解可申请制作调解书。不是诉讼外单独和解已有执行力。
- 民诉解释第一百零七条：调解或和解妥协认可的事实原则上不得在后续诉讼作为不利根据。
- 公证法第三十七条、公证程序规则第三十九条、民诉第二百四十九条：赋强须给付明确、债权无疑义并载明接受强制执行承诺。质量或解除争点未闭合不得承诺可办公证赋强。噪声：公证法 2005 文本标已被修改，以 2017 修正为准；2002 年人民调解协议规定已失效；破产法和解不是本合同和解。

## 节点 3　方案行 `FA#`

按已出现争点碎片扫描，不是默认闭集。每条须能指向争点、底线、让步至、弃权或执行力路径之一。

无 `E#` 不得写已签署。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止标 `待签署`。

热冲突强制处理：

- 要点即已签署／口头即已生效／单独和解即已可执行／永不追究覆盖未知／约定金即必得／打包了结／已读即到达／报价即已中断时效／谈不拢即应起诉／未知写零 → 该格不支持或字段停止；仍出其他 `FA#`。
- 无一碎片 → 关闸，不出 `FA#` 终稿，窗口不关。
- 指导伪造协议、倒签签署日、掩盖犯罪 → 整体停止，不是该格不支持。
- 有效仲裁协议下写应起诉 → 该格不支持，论坛字段停止。

## 本任务回链纪律

本任务成果是「方案闸与方案行草案」。本窗不执行发送。不包含：已签署和解协议、已可强制执行、调解书、司法确认裁定、起诉状。禁止选边治愈。禁止要点即已签署。禁止口头即已生效。禁止单独和解即已可执行。禁止指导伪造或倒签。方案闸打开 ≠ 已签署 ≠ 已生效 ≠ 已可强制执行。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标方案终稿已形成。

## 场景对抗（运行时自检，不写入用户可见闭集）
