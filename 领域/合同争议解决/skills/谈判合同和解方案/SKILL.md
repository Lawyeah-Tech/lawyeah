# 谈判合同和解方案

## 任务目标

在明确、无利益冲突的单方立场下，形成仍可协商的“合同和解方案表”：争点与让步档位、谈判底线、弃权范围、付款／交付／解除与清理安排、单独和解无执行力的明示，以及司法确认、仲裁调解书、公证赋强的转介条件。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价评估、测算、证据清单和谈判记录。

## 工作边界

正触发：一般合同已成争，相对方或程序尚未切断协商可能，用户需要条件和让步方案，而不是已谈拢后的可签协议正文。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未成争，只要改合同或出稿（审查起草领域，本生产线搁置，只说明不实施）；
- 对方已起诉或已发应诉通知，用户只要答辩；
- 条件已谈拢，只要和解协议正文（转 `起草合同和解协议`，不在本包出签章终稿）；
- 要求写“永不追究”且覆盖未知损害、未知第三人权利或未发生事实；
- 建设工程、金融借贷担保、房地产物业、海事、劳动专项争议。

本任务不生成可签署的和解协议终稿，不代办司法确认、仲裁调解或公证赋强，不保证对方履行或法院确认，不放弃用户现有请求，除非用户就具体弃权范围作出明示确认。

## 建立谈判坐标

确认：使用者与授权；单方立场；相对方及可能加入和解的第三人、担保人；合同及附件版本；已形成争点；法域；当前协商、催告、仲裁、诉讼或执行状态；机关文书作出与送达；对方已知报价和已拒绝事项；关键材料及缺失。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。口头报价、聊天“已读”不得写成协议已成立、义务已到达或期限已起算。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 争点／请求；`N#` 让步档位；`W#` 弃权范围；`V#` 方案版本；`E#` 发送／送达／履行凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验弃权与债务消灭、解除后结算清理、诉讼时效中断、调解书／司法确认／公证赋强的效力条件；`search_practiced` 补谈判路径与反例；特殊事实用 `search_case_by_fact`，明确筛选用 `search_case_by_filter`。范本只借鉴方案栏目，不生成签章协议。不虚构案件系统。

工具不可用时继续事实、报价记录、争点表和问题清单；弃权效力、执行力路径和期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [谈判方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 专项分流、立场和仍可谈状态

先做专项整案转出，再固定单方立场、授权和程序阶段。已起诉、已仲裁或已保全，只要协商渠道未切断，仍可正触发；用户只要答辩则负触发。未成争改合同只说明审查起草搁置，不实施。

### 2. 争点让步表与主备位

每个 `Q#` 独立对应让步档 `N#`：主位主张、可让档、对价、互斥和最强反方。继续履行、解除、违约金、赔偿、定金、返还清理不得合成一笔“打包了结”。构成违约不等于必须以解除为成交条件。

### 3. 底线、弃权范围与明示确认

底线按金钱、非金钱、期限和程序动作分列。未获用户就具体范围的明示确认，不得把现有请求写成已放弃。覆盖未知损害、未知第三人权利或“永不追究”的概括弃权：字段停止或负触发。

### 4. 付款、交付、解除与清理

写明主体、对象、时间、条件、凭证和未履行后果。解除是否作为成交条件单列；解除后结算清理条款仍可能有效，不因“一揽子了结”而省略返还、折价、保管和发票。分期、以物抵债、第三方代付单独标风险。

### 5. 执行力路径与转介

单独和解协议仅有合同拘束力、无强制执行力，必须在成果中明示。司法确认、仲裁调解书、公证赋强、诉讼调解书只写转介条件和最小交接，不代办、不保证获准。有效仲裁协议不得写成“谈不拢就去法院起诉”。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或文本无法建立；用户坚持伪造、隐匿、威胁、违法取证，或要求指导以和解掩盖犯罪、逃废债务。
- `字段停止`：法域、弃权范围、执行力条件、文书送达、动态规则未核验。
- `目标停止`：主目标已变为可签协议正文、答辩状、起诉状或发送版解除函。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
