# 定金罚则评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然结果或唯一必得总额。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。实务检索若出现“违约金不超过合同标的百分之三十”，记为噪声。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

应诉答辩或提出反诉，不等于当然放弃仲裁协议。解除通知到达对方时解除；未通知而起诉或申请仲裁主张解除的，仅在该主张获确认后，自起诉状或仲裁申请书副本送达时解除，不得把立案日写成解除时点。第 585 条“过分高于”对照违约造成的损失，不对照合同总价。

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填本任务实体结论。

| 信号 | 转出 |

| 建设工程施工、分包、优先受偿、工程造价鉴定、实际施工人 | 建设工程领域 |
| 金融借贷、保证、抵押质押、保理、融资租赁主轴 | 金融借贷担保领域 |

## 节点 1　定性

运行时核验第 586 条和通则解释第 67 条。

1. 名称不是决定因素。须有定金性质约定或可认定的违约定金意思。
2. 订金、预付款通常按预付款处理，不适用罚则。
3. 立约定金：拒绝订立或违背诚信导致未订立，可适用罚则。
4. 成约定金：未交付但主要义务已履行完毕并为对方接受，合同仍可成立或生效。
5. 解约定金：以丧失或双倍返还为代价解除，须有该类约定。

若：只有付款没有定金意思 → 现有依据不支持罚则。
若：商品房认购书定金 → 房地产领域。

## 节点 2　交付与上限

1. 未实际交付：定金合同不成立。
2. 少交付：按实际交付数额。
3. 超过主合同标的额百分之二十的部分不产生定金效力，该部分可按预付款。
4. 标的额不明：上限字段停止，不写零。

## 节点 3　罚则

运行时核验第 587 条。

1. 须有违约且通常达到不能实现合同目的或符合约定罚则条件。轻微瑕疵不得当然没收。
2. 双方都有过错：不得简单双倍或没收，标依据不足或按过错接口。
3. 不可抗力导致不能履行：罚则通常不支持。
4. `search_law` 返回已失效担保法定金条：噪声。

## 节点 4　选用

运行时核验第 588 条。

1. 违约金与定金选择适用，不得并用填补同一违约。
2. 选择后仍可主张其他损失超过部分，须核验并转测算。
3. 第 585 条调整与定金选用分开写。
4. 解除后结算清理不当然消灭已合法成立的定金请求，但条件须再核。

## 节点 5　输出

性质、交付、上限、罚则条件、选用、最强反方、测算接口。不输出必得双倍。

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。

下一步按期限灭失、易失证据、改变本任务结论、可逆性排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。

禁止指导伪造、隐匿、威胁或违法取证。未知金额不写零。不把应诉写成放弃仲裁。不把立案日写成解除时点。
