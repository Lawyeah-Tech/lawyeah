# 评估定金罚则争议方法

本文件是可执行判断节点。订金不是定金。未实际交付不是定金合同已成立。超过标的额百分之二十的超过部分不产生定金效力。轻微违约不是当然没收或双倍。定金与违约金不是当然双计。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已双倍、已没收、已适用罚则、选定法院、代提交、未知写零。本任务不定罪，不写索赔函，不写精算终稿。本窗闸名只能是金罚闸，禁止复用定金闸、罚金闸、订金闸、精算闸、索赔闸。预留不得占用：立案闸、和解闸。本窗 `DN#` 是罚则行。主路径只用 `Q-则`，禁止用 `Q-测`、`Q-索`、`Q-订`、`Q-双`、`Q-签` 作主路径。本窗 `Q-签` 只作「评估即罚则已适用、已提交或已立案」不关窗码。本窗 `Q-双` 只作「定金与违约金双计」不关窗码。英文 id 禁止使用，一律用中文技能名 `评估定金罚则争议`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效合同法第一百十五条、第一百十六条、担保法及其解释、把订金写成定金时记为噪声。类案先引担保法记为噪声。禁止指导伪造交付凭证。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现款项碎片扫描，不是默认闭集。
`DN#` 固定列：`编号｜款项切片｜名称与性质｜交付与百分之二十上限｜罚则条件｜选用与互斥接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已双倍」或「已适用罚则」。无 `E#` 不得写已交付或已双倍。性质或交付未闭合不得标 `待提交`。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-则`。禁止 `DJ#`、`JS#`、`SJ#`、`SH#`、`FJ#`、`A#`、`N#`。

口头「收据写了订金就算定金」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：名称不是性质。超过部分不产生定金效力，不是整笔无效。罚则须不能实现合同目的。选用不明两项待核。

## 节点 0　分流、立场、金罚闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造交付、倒签交付日、虚增标的额不进负表。利益冲突未解不进整体停止。不定罚则已适用、不给必得双倍不是负触发。把订金写成定金、把未交付写成已成立不是负触发。

整案转出只交付第 1、2、10 节，不出 `DN#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是精算工作表或必得核算 | 负触发 `测算违约金与损害赔偿` |
| 主成果是索赔或违约金主张通知 | 负触发 `准备索赔或违约金主张通知` |
| 主成果是价款、发票或质保金结算 | 负触发 `评估价款结算与发票争议` |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 商品房认购定金主轴 | 整案转房地产领域 |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 签前定金条款审查或改稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程／金融借贷担保／海事／劳动主轴 | 整案转对应领域 |
| 「不定罚则已适用」「不给必得双倍」 | 交付禁令，不是负触发 |

出现「定金」「订金」一词不是转出。

金罚闸打开（可出 `DN#` 草案，仍不得标「已双倍／已没收／已适用罚则」）须同时满足：单方无冲突立场已闭合；主成果是定金定性与罚则评估，不是精算终稿、不是索赔函；至少一行可编号款项切片、收据或交付碎片。口头「收据写了订金就算定金」不算单独开闸材料。

金罚闸部分打开：已有碎片，但性质、交付或上限未闭合；对应格待核；仍交十节。无书面授权但单方立场已闭合且已有碎片：金罚闸部分打开，仍交十节，不是整体停止。

金罚闸关闭（仍正触发）：无一可编号碎片。「今天必须出已双倍／已适用罚则终稿」而无最小碎片不得开闸。不出 `DN#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `DN#` 终稿，**第 7 节不得出索赔函或精算终稿**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「订金即定金」「未交付即已成立」「超百分之二十全部产生定金效力」「轻微违约即没收或双倍」「定金与违约金双计」「评估即已双倍」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `DN#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 金罚闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造交付凭证、倒签交付日、隐匿已返还、虚增标的额凑百分之二十或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个款项切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `DN#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 名称 | 定金／订金／预付款／保证金／押金分列 | 名称即性质；订金升格定金 |
| 交付 | 实际交付凭证、时点、数额分列 | 未交付升格已成立；口头交付 |
| 上限 | 主合同标的额、百分之二十、超过部分分列 | 超百分之二十整笔无效或整笔有效 |
| 罚则 | 给付方／收受方、能否实现目的、轻微／部分履行分列 | 轻微即没收；双方根本违约仍适用；整笔套部分履行 |
| 选用 | 定金与违约金分列 | 双计相加 |

检索锚点（写入 `L#` 前须核验）：见技能正文 MCP 节。噪声：合同法第一百十五条、第一百十六条；担保法及其解释第一百十八条、第一百二十条、第一百二十一条、第一百二十二条。

## 节点 3　罚则行 `DN#`

按已出现款项碎片扫描，不是默认闭集。每条须能指向名称与性质、交付与上限、罚则条件或选用之一。

无 `E#` 不得写已交付或已双倍。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止唯一必得双倍。性质或交付未闭合不得标 `待提交`。

热冲突强制处理：

- 订金即定金／未交付即已成立／超百分之二十全部有效／轻微违约即没收或双倍／定金与违约金双计／评估即已双倍／未知写零 → 该格不支持或字段停止；仍出其他 `DN#`。
- 无一碎片 → 关闸，不出 `DN#` 终稿，窗口不关。
- 指导伪造交付、倒签、虚增标的额 → 整体停止，不是该格不支持。

## 节点 4　测算、索赔、返还、起诉接口

第 7 节只开接口，不得夹带 `DN#` 终稿、索赔函或精算终稿绕闸。闸关闭时第 7 节可写「闸未开，转介待款项编号」，不得补写已双倍。不选定法院。不代提交。不写索赔函。不写精算终稿。

下一步只转介：`测算违约金与损害赔偿`、`准备索赔或违约金主张通知`、`评估价款结算与发票争议`、`评估合同争议`、`评估合同成立与效力`、`处理解除后返还与清理`、`评估解除权是否成立`、`评估迟延拒绝与不完全履行`、`评估不可抗力情势变更与履行不能`、`评估继续履行是否可能`、`评估争议中的格式条款`、`评估框架协议与订单冲突`、`建立合同争议证据案卷`、`准备催告履行或补救通知`、`谈判合同和解方案`、`提起合同纠纷一审`、`评估合同管辖与仲裁协议`。禁止此致某院。

若 if 用户催促「收据写了订金就算定金／没给也算成立／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：买卖收据写「订金两万元」，尚未交货，用户主张订金就是定金、没给也算成立、超百分之二十全算定金、晚一天也要双倍、违约金再加一份、评估完就算已双倍、不清楚先写零。金罚闸打开或半开。`Q-订`、`Q-给`、`Q-超`、`Q-轻`、`Q-双`、`Q-倍`、`Q-零` 不打开为可靠路径。第 6 节不得把已适用罚则、已双倍、整笔有效、双计、0 写入可执行 `DN#`；对应格 `现有依据不支持` 或字段停止；仍出名称与性质分列、交付缺口、百分之二十上限、选用待核等其他 `DN#`。不关窗。不写索赔函。不写精算终稿。

场景②：用户同时交出己方「交付日改到上周、标的额先按低价凑百分之二十」与对方「这就是预付款」口径，并要「先按双倍写」。命中双方秘密＋倒签＋虚增。第一次整体停止。只交第 1、10 节。不出 `DN#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代违法方案。
