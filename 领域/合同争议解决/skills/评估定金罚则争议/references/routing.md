# 边界与路由

## 正触发

定金、订金、预付款性质及双倍返还或没收发生争议。从零、碎片、性质未核验、无书面授权仍正触发：有可编号款项切片、收据或交付碎片则闸开或半开，出 `DN#` 草案，保持草案。本次不定罚则已适用、不给必得双倍是交付禁令，不是开窗条件。订金即定金、未交付即已成立，仍正触发。把超百分之二十全部写成定金、把轻微违约写成当然没收或双倍，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造交付、倒签交付日、虚增标的额的停止，优先于负触发。上述信号不在下表。不定罚则已适用不是负触发。「订金即定金」「未交付即已成立」「超百分之二十全部产生定金效力」「轻微违约即没收或双倍」「定金与违约金双计」「评估即已双倍」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 精算工作表或必得核算 | `测算违约金与损害赔偿` |
| 索赔或违约金主张通知 | `准备索赔或违约金主张通知` |
| 价款、发票或质保金结算 | `评估价款结算与发票争议` |
| 争议总图 | `评估合同争议` |
| 商品房认购定金主轴 | 房地产领域 |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |
| 签前定金条款审查或改稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不定罚则已适用」或「不给必得双倍」关窗。拟定金评估仍正触发，不得写成已双倍或已适用罚则。

## 易混

本窗闸名只能是金罚闸，不是定金闸，不是罚金闸，不是订金闸，不是精算闸，不是索赔闸。`DN#` 不是 `DJ#`，不是 `SJ#`，不是 `SH#`，不是 `JS#`，不是 `FJ#`。主路径是 `Q-则`，不是 `Q-测`，不是 `Q-索`，不是 `Q-订`，不是 `Q-定`，不是 `Q-双`。`DJ#` 是公司治理测算行。`Q-定` 是房地产「评估定金订金与首付款性质」。`精算闸`／`Q-测` 是测算违约金与损害赔偿。`索赔闸`／`Q-索` 是准备索赔或违约金主张通知。订金不是定金。未交付不是已成立。超过部分不产生定金效力，不是整笔无效。已失效合同法第一百十五条、第一百十六条、担保法及其解释不是现行。类案先引担保法不是现行依据。「收据写了订金就算定金」「标的额先按低价凑百分之二十」整体停止。本窗不执行发送，不代提交。不选定法院。不写索赔函。不写精算终稿。
