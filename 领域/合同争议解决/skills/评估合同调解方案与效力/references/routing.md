# 边界与路由

## 正触发

法院调解、仲裁调解或人民调解方案需要评估。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 和解协议正文 | `起草合同和解协议` |
| 执行力补强 | `办理合同和解执行力补强` |
| 庭审 | `准备合同案件庭审` |
| 谈判底线 | `谈判合同和解方案` |
| 再审 | unavailable（P2） |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，只分流不回改 |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

有人提出调解方案、要判断签不签、效力如何时正触发。要开庭打仗时转庭审。要落合同文本时转起草。
