# 边界与路由

## 正触发

一般合同已成争，法院调解、仲裁调解或人民调解方案需要评估利弊、效力和反悔窗口。从零、碎片、签收未核验仍正触发：有可编号调解类型、方案对照或效力碎片则闸开或半开，出 `TJ#` 草案，保持草案。本次不代替庭审、不保证出调解书是交付禁令，不是开窗条件。评估即已出调解书、拒收即已可执行，仍正触发。把口头写成已生效、把反悔窗口未核写成已确定，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造调解书、倒签签收日、掩盖犯罪的停止，优先于负触发。上述信号不在下表。不代替庭审不是负触发。「评估即已出调解书」「拒收即已可执行」「口头即已调解」「反悔未核即已确定」「保证出调解书」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 谈判方案要点 | `谈判合同和解方案` |
| 可签和解正文 | `起草合同和解协议` |
| 司法确认、赋强或申请制作调解书 | `办理合同和解执行力补强` |
| 执行中分期或以物抵债 | `准备合同执行和解` |
| 庭审质证提纲 | `准备合同案件庭审` |
| 争议总图 | `评估合同争议` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不代替庭审」或「不保证出调解书」关窗。拟利弊与效力评估仍正触发，不得写成已出调解书或已可执行。

## 易混

本窗闸名只能是调解闸，不是方案闸，不是和解闸，不是力补闸，不是媒效闸。`TJ#` 不是 `FA#`，不是 `HJ#`，不是 `QF#`，不是 `MD#`。主路径是 `Q-媒`，不是 `Q-方`，不是 `Q-和`，不是 `Q-力`，不是 `Q-调`。`方案闸`／`FA#`／`Q-方` 是谈判合同和解方案。`和解闸`／`HJ#`／`Q-和` 是起草合同和解协议。`力补闸`／`QF#`／`Q-力` 是办理合同和解执行力补强。`Q-调` 是认缴期限调整主路径。`Q-媒` 在合规是媒体必须公告不关窗。1991 年民事诉讼法第一百条拘传不是调解书。2017 年第九十七条须核对应现行第一百条。2017 年第一百条、第一百零一条是保全，不是现行调解条。提出「倒签上周已签收、把逃废写成调解」整体停止。本窗不代签收。不选定法院。不代替庭审。
