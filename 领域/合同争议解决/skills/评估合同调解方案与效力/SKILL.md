# 评估合同调解方案与效力

## 任务目标

在明确、无利益冲突的单方立场下（拟接受或拒绝调解一方或其受托律师，互斥），形成调解评估草案：调解闸、主体与强制接口、`Q#` 路径、`TJ#` 调解行（方案切片／程序前提／签收或生效／反悔或无效接口／与确认赋强分流／`E#` 回链）。本窗 `TJ#` 是调解行草案，不是已出调解书，不是已签收生效，不是已可强制执行，不是和解协议正文，不是司法确认申请。本窗闸名只能是调解闸，禁止复用方案闸、和解闸、力补闸、公证闸、效力闸、媒效闸、争议闸。预留不得占用：立案闸、和解闸、方案闸、力补闸。本窗主行只能是 `TJ#`，禁止 `FA#`、`HJ#`、`QF#`、`MD#`、`A#`。主路径只用 `Q-媒`，禁止用 `Q-方`、`Q-和`、`Q-力`、`Q-公`、`Q-调`、`Q-签` 作主路径。邻窗 `Q-媒` 只作转介进本窗；本窗打开为主路径，不是已出调解书、不是已签收、不是已可执行。合规窗 `Q-媒` 是媒体必须公告不关窗，本窗不得抄。本窗 `Q-方` 只转介 `谈判合同和解方案`。本窗 `Q-和` 只转介 `起草合同和解协议`。本窗 `Q-力` 只转介 `办理合同和解执行力补强`。本窗 `Q-签` 只作「评估即已出调解书」不关窗码。本窗 `Q-执` 只作「拒收即已可强制执行」不关窗码。本窗 `Q-口` 只作「口头即已调解」不关窗码。本窗 `Q-悔` 只作「反悔窗口未核即已确定」不关窗码。调解闸打开不等于已签收不等于已出调解书不等于已可强制执行不等于待提交终稿。调解书双方签收才生效。拒收不是已可执行。评估不是已出调解书。口头同意不是已生效。人民调解未确认不是已可强制执行。调解妥协原则上不得作后续不利自认。未知不写零。不代签收。不选定法院。不定罪。不保证法院出调解书。不代替庭审策略。伤残等级与本窗无关，禁止折入。

`depends-on` 为空。主成果是谈判方案要点转 `谈判合同和解方案`。主成果是可签和解正文转 `起草合同和解协议`。主成果是司法确认、赋强或申请制作调解书转 `办理合同和解执行力补强`。主成果是执行中分期或以物抵债转 `准备合同执行和解`。主成果是庭审提纲转 `准备合同案件庭审`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：一般合同已成争，法院调解、仲裁调解或人民调解方案需要评估利弊、效力和反悔窗口。「签了就能执行」「拒收也算生效」仍正触发，成果状态 `草案`。类型、签收、反悔窗口未核验仍正触发：有可编号调解类型、方案对照或效力碎片则调解闸打开或半开，第 6 节出 `TJ#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出已生效终稿」才关闸，仍交十节，第 6 节不出 `TJ#` 终稿，第 7 节不得出已出调解书或已可执行，窗口不关。用户要把评估写成已出调解书、把拒收写成已可执行、把口头写成已生效、把反悔窗口未核写成已确定、把未知写成零，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `TJ#` 草案。不得因「不代替庭审」「不保证出调解书」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是谈判方案要点（转 `谈判合同和解方案`）；
- 主成果是可签和解正文（转 `起草合同和解协议`）；
- 主成果是司法确认、赋强或申请制作调解书（转 `办理合同和解执行力补强`）；
- 主成果是执行中分期或以物抵债（转 `准备合同执行和解`）；
- 主成果是庭审质证提纲（转 `准备合同案件庭审`）；
- 主成果是争议总图（转 `评估合同争议`）；
- 尚未成争，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）。

双方秘密、伪造调解书或签章、倒签签收日、以调解掩盖犯罪或逃废债务、违法取证**不在负触发表**，走整体停止。STUB 把「代替庭审策略」放进负触发，必须改交付禁令。「评估即已出调解书」「拒收即已可执行」「口头即已调解」「反悔未核即已确定」「未知写零」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不代替庭审」「不保证出调解书」是交付禁令，不是负触发。STUB 把「隐瞒调解效力」放进目标停止，必须改不关窗。主成果才转；出现「调解」一词不是转出。

## 建立工作坐标

确认：评估授权；单方立场；调解类型；方案对照请求；签收或笔录；反悔窗口；法域；当前诉讼或仲裁状态。

口头「已经调成了」只登记 `S#`／`V#`。不得升格已出调解书、已签收或已可执行，**不得单独算作开闸材料**。可编号调解类型、方案对照或效力碎片可开闸。本窗不执行发送，不代签收。

立场只许拟接受或拒绝调解一方或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：调解闸关闭，仍交十节，不是整体停止。无书面授权但单方立场已闭合、且已有碎片：调解闸部分打开，仍交十节，不是整体停止。提出伪造调解书或签章、倒签签收日、以调解掩盖犯罪或逃废债务、违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`TJ#` 调解行；`V#` 版本；`E#` 证据形态回链（方案、送达回证、签收或笔录，不是发送闸，不是已生效证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`FA#`、`HJ#`、`QF#`、`MD#`。技能正文中的条号是检索锚点，不是已核验 `L#`。文件状态只用 `草案`、`停止`。不得标已出调解书、已签收或待提交。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。未知不写零。评估 ≠ 已出调解书。拒收 ≠ 已可执行。口头 ≠ 已生效。未确认 ≠ 已可强制执行。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或类案检索。本窗是评估类，**禁止**用 `search_template` 顶第四槽，**不要**升格「已出调解书／已签收／已可执行」。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现拒收即已可执行、评估即已出调解书、口头即已生效、调解妥协即不利自认的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把 2017 年民事诉讼法第九十七条未核验对应现行第一百条。不得把 2017 年第一百条、第一百零一条保全条与现行调解条撞号。不得把 1991 年第一百条拘传当作调解书。MCP 效力字段与公布施行日冲突时，以施行日为准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的签收、反悔、自认或施行日保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民事诉讼法（2023 修正，施行日 2024-01-01）第九十六条至第九十九条调解自愿、主持、协助、协议不得违法。第一百条调解达成协议应当制作调解书，经双方当事人签收后即具有法律效力。噪声：1991 年第一百条拘传；2017 年第九十七条。第一百零一条即时履行等可以不制作调解书，记入笔录由双方、审判人员、书记员签名或盖章后即具有法律效力。噪声：2017 年第一百条保全。第一百零二条未达成协议或送达前一方反悔的，应当及时判决。噪声：2017 年第一百零一条诉前保全。民诉解释第一百三十三条调解书直接送达本人，不适用留置送达。第一百四十九条以最后签收日为生效日期。第一百五十一条各方同意签章即生效时，拒收调解书不影响该协议效力，不得把普通拒收升格已可执行。第一百零七条为达成调解或和解作出的妥协，原则上不得作为后续不利根据。第一百四十八条请求按调解协议制作判决书不予准许。人民调解法第三十一条至第三十三条有约束力，争议可起诉，确认须双方三十日内共同申请，手续转力补窗。仲裁法 2025 修订施行日 2026-03-01 已施行，MCP 标尚未施行时以施行日为准；调解书签收生效、签收前反悔及时裁决，条号运行时核验。噪声：1994 年、2017 年仲裁法第四十九条至第五十二条；2002 年人民调解协议规定；破产和解；劳动调解；刑诉和解。技能正文条号不是 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变签收、反悔或自认的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补签收才生效、拒收不是已可执行、最后签收日为生效日、调解妥协原则上不得作不利自认、人民调解未确认不是已可强制执行的实务反例。噪声：把解释第一百五十一条例外写成普通拒收仍生效。
- `search_case_by_fact` 只比较事实差异与翻转条件：未签收不是已生效；送达前反悔应及时判决。无类案不得写成已出调解书或已可执行终稿。评估类禁止用 `search_template` 生成调解书或已可执行证明。

工具不可用时继续方案碎片和 `TJ#` 编目；已签收、已可执行、反悔窗口、施行日字段停止。不得拒跑，不得凭记忆写成已生效或指导伪造调解书。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、调解闸与不关窗

主成果才整案转出。双方秘密、伪造调解书、倒签签收日第一次停。评估即已出调解书、拒收即已可执行不关窗。闸关仍交十节，第 6 节不出 `TJ#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

诉讼调解／仲裁调解／人民调解分列。对照请求。签收与笔录分列。本节禁止出 `TJ#` 终稿。

### 3. 调解闸与路径 `Q#`

本节禁止出 `TJ#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-媒`。

### 4. 调解行 `TJ#`

切片、程序前提、签收或生效、反悔接口、确认赋强分流。状态 `草案`。禁止升格已出调解书、已签收、已可执行。无 `E#` 不得写已签收。

### 5. 方案、起草、力补与庭审接口

未谈拢转谈判窗。要正文转起草窗。要手续转力补窗。要开庭转庭审窗。第 7 节不得夹带 `TJ#` 终稿或已可执行绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造调解书或签章、倒签签收日、以调解掩盖犯罪或逃废债务、违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：调解闸关闭，仍交十节，不是整体停止。无书面授权但有碎片：调解闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：签收、反悔窗口、自认例外、施行日未核验。评估即已出调解书、拒收即已可执行、口头即已调解、反悔未核即已确定、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `TJ#` 草案。
- `目标停止`：主目标变为庭审提纲终稿、已出调解书终稿或手续终稿。禁止把「评估即已出调解书」当作用户错误主张时的目标停止；那是不关窗。

禁止指导伪造调解书或倒签。不给确认率。不定罪。不选定法院。不代签收。未知不写零。不代替庭审。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。调解闸关闭仍交十节，第 6 节不出 `TJ#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `TJ#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。调解闸未打开时不得交付「已出调解书」或「已可执行」。边界见 [路由](references/routing.md)。
