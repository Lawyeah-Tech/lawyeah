# 边界与路由

## 正触发

一般合同已成争，核心条款歧义、冲突或漏洞决定请求或抗辩能否成立。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 争成立或效力 | `评估合同成立与效力` |
| 格式条款提示说明或无效 | `评估争议中的格式条款` |
| 框架与订单冲突 | `评估框架协议与订单冲突` |
| 实际履行是否构成变更 | `评估变更是否成立` |
| 总体评估 | `评估合同争议` |
| 未成争改条款 | 审查起草领域（本窗搁置，只说明） |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，只分流不回改 |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

条款意思决定请求能否成立时正触发。用户其实要否定合同存在或宣告无效时，转成立效力原子。用户要出一版新合同文本时负触发。
