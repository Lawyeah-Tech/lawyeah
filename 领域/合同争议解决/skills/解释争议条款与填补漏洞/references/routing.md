# 边界与路由

## 正触发

一般合同已成争，核心条款歧义、冲突或漏洞决定请求或抗辩能否成立。从零、碎片、习惯未核验、无书面解释授权仍正触发：有可编号争议条款、冲突文本或约定不明碎片则闸开或半开，出 `JX#` 草案，保持草案。本次不重写合同、不把解释写成已改约是交付禁令，不是开窗条件。填补即已改约、有歧义即不利提供方、单方惯例即双方习惯，仍正触发。

双方秘密、伪造合同或修订、倒签修订日、隐匿文本、违法取证的停止，优先于负触发。上述信号不在下表。不重写合同不是负触发。「填补即已改约」「有歧义即不利提供方」「单方惯例即双方习惯」「对我方有利即唯一解释」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 争议总图 | `评估合同争议` |
| 成立或效力专项 | `评估合同成立与效力` |
| 格式条款提示说明与效力 | `评估争议中的格式条款` |
| 框架与订单冲突 | `评估框架协议与订单冲突` |
| 变更是否成立 | `评估变更是否成立` |
| 电子到达或电子签名专项 | `评估电子合同成立与送达` |
| 确认之诉诉状 | `提起合同成立或效力确认之诉` |
| 尚未成争，改条款或重写合同 | 审查起草领域（本窗搁置，只说明） |
| 工程／金融／房产／海事／劳动主轴 | 对应领域 |

不得因「不重写合同」或「不把解释写成已改约」关窗。拟条款解释仍正触发，不得写成已改约或唯一有利解释。

## 易混

本窗闸名只能是解释闸，不是条款闸，不是格式闸，不是成立闸，不是争议闸。`JX#` 不是 `SY#`，不是 `CL#`，不是 `ZT#`。公司治理授予窗占用 `SY#`，本窗不打开。主路径是 `Q-释`，不是 `Q-契`，不是 `Q-格`，不是 `Q-条`。填补漏洞不是已经改约。有歧义不是当然不利格式提供方。单方惯例不是双方习惯。对我方有利不是唯一解释。第四百九十八条只开格式窗，协商条款不得套不利解释。已失效合同法第一百二十五条、第四十一条、第六十一条、第六十二条不是现行。预付式消费解释第八条不是一般商事合同解释规则。「修订日改到上周」「把对我有利那一版当唯一文本」整体停止。本窗不执行发送，不代提交。不选定法院。不重写整份合同。不写诉状。
