# 解释争议条款与填补漏洞方法

本文件是可执行判断节点。填补漏洞不是已经改约。有歧义不是当然不利格式提供方。单方惯例不是双方习惯。对我方有利不是唯一解释。目的不是推翻清晰文义。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已改约、唯一有利解释、选定法院、代提交、未知写零。本任务不定罪，不重写整份合同，不写确认之诉诉状。本窗闸名只能是解释闸，禁止复用条款闸、格式闸、填补闸、成立闸、争议闸。预留不得占用：立案闸。本窗 `JX#` 是解释行。主路径只用 `Q-释`，禁止用 `Q-契`、`Q-条`、`Q-漏`、`Q-补`、`Q-格`、`Q-签` 作主路径。本窗 `Q-签` 只作「解释即已确认或已改约」不关窗码。英文 id 禁止使用，一律用中文技能名 `解释争议条款与填补漏洞`。公司治理授予窗占用 `SY#`，本窗不打开 `SY#`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》第一百二十五条、第四十一条、第六十一条、第六十二条、合同法解释二第一条仍引上述条文、预付式消费解释第八条套一般商事、把填补写成已改约时记为噪声。禁止指导伪造合同或倒签修订。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现条款碎片扫描，不是默认闭集。
`JX#` 固定列：`编号｜条款切片｜文义与体系｜目的习惯诚信｜格式／不利解释接口｜漏洞填补候选｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已改约」或「唯一有利解释」。无 `E#` 不得写已改约。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-释`。禁止 `SY#`、`CL#`、`ZT#`、`TK#`、`A#`、`N#`。

口头「按对我们有利的意思」「行业都这么做」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：冲突文本并列，不选对用户有利的一版冒充唯一。填补顺序：协议补充 → 相关条款或习惯 → 第五百一十一条分项。第四百九十八条只开格式窗接口。

## 节点 0　分流、立场、解释闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造合同或修订、倒签修订日、隐匿文本、违法取证不进负表。利益冲突未解不进整体停止。不重写合同、不把解释写成已改约不是负触发。

整案转出只交付第 1、2、10 节，不出 `JX#` 终稿。

解释闸打开（可出 `JX#` 草案，仍不得标「已改约／唯一有利解释／习惯已证成」）须同时满足：单方无冲突立场已闭合；主成果是条款解释或填补，不是总图、不是成立效力终稿、不是格式专项、不是新合同；至少一项可编号争议条款原文、冲突文本或约定不明碎片。口头「按对我们有利的意思」不算单独开闸材料。

解释闸部分打开：已有碎片，但习惯、共同理解或第五百一十一条分项未闭合；对应格待核；仍交十节。无书面解释授权但单方立场已闭合且已有碎片：解释闸部分打开，仍交十节，不是整体停止。

解释闸关闭（仍正触发）：无一可编号碎片。「今天必须出已改约终稿」而无最小碎片不得开闸。不出 `JX#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `JX#` 终稿，**第 7 节不得出新合同或已改约**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「填补即已改约」「有歧义即不利提供方」「单方惯例即双方习惯」「对我方有利即唯一解释」「目的推翻清晰文义」「选有利文本冒充唯一」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `JX#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 解释闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。

## 节点 1　主体与强制接口

一行一个条款切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `JX#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 文本 | 冲突版本、手写与打印、修订记录并列 | 选有利一版冒充唯一 |
| 文义与体系 | 词句通常含义、相关条款、标题、定义、附件 | 目的直接推翻清晰文义 |
| 目的习惯诚信 | 目的条款、标的性质、磋商；习惯须举证 | 单方内部惯例写成双方习惯；事后情绪当目的 |
| 格式接口 | 是否格式、是否已完成提示说明只开接口 | 协商条款套第四百九十八条不利解释 |
| 填补 | 协议补充 → 相关条款或习惯 → 第五百一十一条分项 | 填补写成已改约或已补签 |

检索锚点（写入 `L#` 前须核验）：

- 第一百四十二条：有相对人按词句结合相关条款、性质目的、习惯、诚信。
- 第四百六十六条：条款争议依第一百四十二条第一款；多文本同等效力词句推定相同。
- 合同编通则解释第一条：通常含义为基础；共同理解优先于通常含义；影响效力时选择有利于有效的解释；无偿合同选择对债务人负担较轻。
- 第五百零九条：全面履行与诚信附随，不是填补主条。
- 第五百一十条：约定不明可协议补充；不能达成则按相关条款或交易习惯。
- 第五百一十一条：仍不能确定时质量、价款、履行地、期限、方式、费用分项。
- 第四百九十八条只开格式窗。噪声：已失效合同法第一百二十五条、第四十一条、第六十一条、第六十二条；解释二第一条；预付式消费解释第八条。

## 节点 3　解释行 `JX#`

按已出现条款碎片扫描，不是默认闭集。每条须能指向条款原文、冲突文本或约定不明之一。

无 `E#` 不得写已改约。状态默认 `草案`。一次只推荐下一步。未知不写零。第五百一十一条分项一行一项。

热冲突强制处理：

- 填补即已改约／有歧义即不利提供方／单方惯例即双方习惯／对我方有利即唯一解释／目的推翻清晰文义／选有利文本冒充唯一／未知写零 → 该格不支持或字段停止；仍出其他 `JX#`。

- 指导伪造合同、倒签修订 → 整体停止，不是该格不支持。
- 协商条款套第四百九十八条 → 该格不支持，只开格式窗接口。
