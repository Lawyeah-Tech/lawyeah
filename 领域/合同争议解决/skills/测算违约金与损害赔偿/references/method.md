# 测算方法

本文件是可执行判断节点，不是栏目说明书。每个会改变项目能否计入、互斥或调整结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然违约或唯一必得总额。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。实务检索若出现“违约金不超过合同标的百分之三十”，记为噪声，不得写入结论。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突。

本任务**不认定违约已经成立**。测算行建立在明示假设上：若某 `Q#` 成立，则对应 `M#` 如何计算。假设不成立时该行不得当成已核实金额。

## 节点 0　专项分流

先于数字展开。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体测算。

| 信号 | 转出 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定、实际施工人 | 建设工程领域 |
| 金融借贷、保证、抵押质押、保理、融资租赁主轴 | 金融借贷担保领域 |
| 商品房买卖、开发合作、物业服务主轴 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、劳动报酬、解除劳动合同、工伤待遇 | 劳动领域 |
| 保险理赔或侵权损害赔偿主轴 | 保险／侵权领域 |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 只要定性总图，不要分项测算 | `评估合同争议` |

混合信号：一般买卖／服务主轴可留本任务；专项只作为背景时在缺口标明，不把专项费率或优先受偿规则硬套进一般合同测算。

## 节点 1　范围、假设和事件编号

1. 固定单方立场、合同版本、待算项目和排除项。用户只要策略地图：负触发。
2. 每个金钱主张先挂到独立的 `Q#` 假设：违约金、损害赔偿、定金、减价、返还已付款、扣留质保金。构成违约不等于当然解除；解除后结算清理条款仍可能有效，须另列，不把解除本身折算成一笔“合同权益”。
3. 为每个独立经济事件分配 `EVT#`。同一事件可以并列不同性质项目，但须标明互斥或选用。禁止重复计入的是同一损失、同一利益或同一价差，不是“一个事件只能占一行”。约定违约金不是必得。
4. 未知值写 `unknown`。真实零必须有肯定来源。禁止把查不到的运费、停工损失或可得利益写成零后加总。
5. 已付款、发票、质保金、定金、订金、预付款名称以资金流向和约定性质为准，不按用户口头标签合并。

## 节点 2　分项建账

每个 `M#` 固定列：

`编号｜项目｜性质｜EVT#｜Q# 假设｜参数｜未舍入公式｜已付／扣减｜互斥／抵扣｜金额状态｜判断｜待核｜来源`

默认分项，不得预先合成“应赔总额”：

| 项目 | 性质 | 计入规则 |
| --- | --- | --- |
| 约定违约金 | 金钱给付 | 按条款计算，进入调整接口，不是必得 |
| 迟延违约金 | 金钱给付 | 与继续履行可能并存；支付后债务仍可能要继续履行 |
| 直接损失 | 赔偿 | 因违约造成的实际减少，须回链凭证 |
| 可得利益 | 赔偿 | 合同履行后可以获得的利益，受可预见约束 |
| 定金 | 担保／罚则 | 先定性，再与违约金选用 |
| 已付款 | 返还或抵扣 | 按资金流向和合同阶段，不自动等于损失 |
| 质保金 | 扣留或返还 | 先核质保条件，不把扣留写成当然赔偿 |
| 减价 | 价金调整 | 与赔偿、违约金的关系必须写互斥或抵扣 |

顺序：先写假设和事件，再取参数和公式，再匹配已付和扣减，最后标金额状态。无法代入得数的行用 `无法估计`，保留公式。只有数值足以复算时才用 `情景金额` 或 `已核实金额`。

鉴定、评估未完成：相关行保持 `无法估计`，转介鉴定原子，不编造市场差价。

## 节点 3　第五百八十五条调整接口

运行时核验现行《中华人民共和国民法典》第五百八十五条和《最高人民法院关于适用〈中华人民共和国民法典〉合同编通则若干问题的解释》（法释〔2023〕13号）第六十四条、第六十五条后再落调整字段。核验失败则调整结论停止，分项公式继续。

1. 当事人可以约定违约金或损失赔偿额的计算方法。**约定数字不是必得金额。**
2. 约定违约金低于造成的损失，或过分高于造成的损失，人民法院或者仲裁机构**可以根据当事人的请求**予以增加或适当减少。本任务只建接口：有无请求、由谁请求、对照损失是多少。没有请求事实，不得把调整后的数字写成已经确定。
3. “过分高于”对照的是**违约造成的损失**，不是合同总价，也不是未付价款本身。
4. 通则解释第六十五条：应当以第五百八十四条规定的损失为基础，兼顾合同主体、交易类型、履行情况、过错程度、履约背景等，遵循公平原则和诚信原则衡量。约定的违约金**超过造成损失的百分之三十**的，一般可以认定为过分高于造成的损失。**恶意违约的当事人一方请求减少违约金的，一般不予支持。**
5. 通则解释第六十四条：通过反诉或者抗辩请求调整的，依法应予支持。违约方主张过分高于的，承担举证责任；非违约方主张约定合理的，也应当提供相应证据。**当事人仅以合同约定不得对违约金进行调整为由主张不予调整的，不予支持。**
6. 迟延履行违约金支付后，债务仍应当履行。继续履行是否可能另列非金钱后果，不折算进本表总额。
7. **买卖合同解释（2020修正）第二十条**：买卖合同因违约而解除后，守约方主张继续适用违约金条款的，应予支持；但约定违约金过分高于造成的损失的，仍参照第五百八十五条第二款处理。该条适用于**买卖合同**。服务、承揽、合作等合同不得直接套用，相应字段标待核，并在缺口写明须核验有无其他现行依据。
8. 合同权利义务终止，不影响结算和清理条款的效力。结算清理条款有效不等于违约金数字必得。

不得把“合同总价百分之三十”或“不超过标的额百分之三十”写成现行标准。

## 节点 4　可预见、减损、双方违约和获益扣减

运行时核验第五百八十四条、第五百九十一条、第五百九十二条和通则解释第六十三条。各项分列，禁止合成一笔“应赔”。

1. **损失范围**：相当于因违约所造成的损失，包括合同履行后可以获得的利益；但不得超过违约一方订立合同时预见到或者应当预见到的因违约可能造成的损失。
2. **可预见的判断**：根据订立合同的目的，综合考虑合同主体、合同内容、交易类型、交易习惯、磋商过程，按照与违约方处于相同或者类似情况的民事主体在订立合同时预见到或者应当预见到的损失确定。向第三人承担违约责任应当支出的额外费用等其他损失，须单独判断是否可预见。
3. **减损**：一方违约后，对方应当采取适当措施防止损失扩大；没有采取适当措施致使损失扩大的，不得就扩大的损失请求赔偿。防止损失扩大的合理费用，由违约方负担，另列一行，不与扩大损失对冲成零后消失。
4. **双方违约与过错相抵**：当事人都违反合同的，应当各自承担相应的责任。一方违约造成对方损失，对方对损失的发生有过错的，可以减少相应的损失赔偿额。减少额另列，不直接改写原始损失行。
5. **获益扣减**：确定赔偿额时，扣除非违约方未采取适当措施导致的扩大损失、非违约方过错造成的相应损失、非违约方因违约获得的额外利益或者减少的必要支出。各扣减项独立成行，回链 `EVT#`，避免同一利益被扣两次。

替代交易价格、市场价格差、持续履行合同的合理寻找替代期限，只在事实足够时建情景；事实不足标 `无法估计`。不得把用户事后报价当成唯一市场价格。

## 节点 5　互斥、选用、情景和汇总

### 5.1 定金与违约金

运行时核验第五百八十六条至第五百八十八条、通则解释第六十七条、第六十八条。

- 当事人既约定违约金又约定定金的，一方违约时，对方可以选择适用违约金或者定金条款。定金不足以弥补损失的，可以请求赔偿超过定金数额的损失；该“超过部分”与违约金选用必须分列，不得把定金罚则和全部违约金相加。
- **选用不明时，定金行与违约金行都标待核，不双计，不输出相加总额。**
- 留置金、担保金、保证金、订约金、押金或订金等，没有约定定金性质的，不得适用定金罚则。先定性，再决定是否进入罚则行。
- 定金超过主合同标的额百分之二十的部分不产生定金效力。超过部分另标，不计入罚则。
- 双方都构成致使不能实现合同目的的违约时，适用定金罚则的请求一般不予支持。轻微违约对抗目的不能实现的违约，另按解释第六十八条处理，不在本表直接写“定金必得”。

### 5.2 减价、已付款、质保金

- 减价以符合约定标的与实际交付标的的价值差为候选，不与就同一价值差额计算的赔偿重复计入。
- 已付款按返还、抵作价款或抵作违约金／定金分别记账，禁止同一笔资金在返还和赔偿中各算一次。
- 质保金扣留先核质量异议、质保期和扣留条件。条件未核验时扣留额标待核，不得写成已实现的赔偿。

### 5.3 情景与质量门

情景只改变明确列出的未知变量，例如损失是否被认定为可预见、对方是否请求减少违约金、定金与违约金选用哪一项。每个情景保存假设、受影响 `M#` 和结果，不改写原始事实。

总表分为：已核实金额、各情景金额、无法估计项目。**禁止输出唯一必得总额。** 任一展示合计都必须由行级明细重新聚合，并剔除互斥未选项。

用户要求“给一个法院一定支持的数”：拒绝该表述，改给区间和条件。用户要求把未知当零以做出整洁总额：字段停止；坚持伪造或隐匿已收款：整体停止。

禁止指导伪造流水、虚增损失、隐匿减损机会或重复索赔技巧。
