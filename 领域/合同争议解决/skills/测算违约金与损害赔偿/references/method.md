# 测算违约金与损害赔偿方法

本文件是可执行判断节点。约定数字不是必得。过分高于对照损失不是合同总价。增减须当事人请求。未知不写零。定金与违约金选用不明不双计。测算不是违约已成立。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必得总额、选定法院、代提交、未知写零。本任务不定罪，不定违约已成立，不写诉状或索赔函。本窗闸名只能是精算闸，禁止复用争议闸、论坛闸、解除闸、催告闸、发送闸、测算闸。预留不得占用：立案闸。本窗 `SJ#` 是测算行。主路径只用 `Q-测`，禁止用 `Q-总`、`Q-告`、`Q-函`、`Q-除`、`Q-坛`、`Q-诉` 作主路径。英文 id 禁止使用，一律用中文技能名 `测算违约金与损害赔偿`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》及其解释、合同法解释二「标的额百分之三十」、把过分高于对照合同总价时记为噪声。禁止指导伪造流水或虚增损失。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现项目扫描，不是默认闭集。
`SJ#` 固定列：`编号｜项目切片｜性质与事件｜参数与未舍入公式｜已付／扣减｜互斥／调整接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。金额旁注只用 `已核实`、`情景`、`无法估计`。无 `E#` 不得写已核实。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-测`。禁止 `JS#`、`DJ#`、`M#`、`A#`、`N#`。

口头「必须赔多少」「今天必须出一个数」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。约定金、迟延违约金、直接损失、可得利益、定金、已付款、质保金、减价分列。

实务上：增减须当事人请求。过分高于对照损失。超过损失百分之三十一般可认定过分高于。不得以约定不得调整排除。定金与违约金选用不明则并列待核，不双计。服务合同不得直接套买卖解释第二十条。

## 节点 0　分流、立场、精算闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造流水、虚增损失、隐匿已收款、倒签基准日、违法取证凑测算不进负表。利益冲突未解不进整体停止。不定违约已成立、不给必得总额不是负触发。

整案转出只交付第 1、2、10 节，不出 `SJ#` 终稿。

出现「违约金」「损失」一词不是转出。

精算闸打开须同时满足：单方无冲突立场已闭合；主成果是分项测算，不是总图、不是函、不是诉状；至少一项可编号条款数字、付款、损失或可编号缺口。口头「必须赔多少」不算单独开闸材料。

精算闸部分打开：已有碎片，但参数、调整或互斥未闭合；对应格待核；仍交十节。

精算闸关闭（仍正触发）：无一可编号碎片。「今天必须出一个数」而无最小碎片不得开闸。不出 `SJ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `SJ#` 终稿，**第 7 节不得出诉状、索赔函或必得额**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「约定金即必得」「总价百分之三十即过分高于」「未知写零」「测算即违约已成立」「定金违约金双计」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `SJ#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 精算闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造流水、虚增损失、隐匿已收款、倒签基准日或违法取证凑测算，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 3　测算行 `SJ#`

按已出现项目扫描，不是默认闭集。每条须能指向项目、参数或互斥之一。

无 `E#` 不得写已核实。状态默认 `草案`。一次只推荐下一步。未知不写零。不输出唯一必得总额。

热冲突强制处理：

- 约定金即必得／总价百分之三十／未知写零／测算即违约已成立／定金违约金双计 → 该格不支持或字段停止；仍出其他 `SJ#`。
- 无一碎片 → 关闸，不出 `SJ#` 终稿，窗口不关。
- 指导伪造流水、虚增损失、隐匿已收款 → 整体停止，不是该格不支持。

## 节点 4　索赔、鉴定、起诉接口

第 7 节只开接口，不得夹带 `SJ#` 终稿或必得额绕闸。闸关闭时第 7 节可写「闸未开，转介待项目编号」，不得补写必得或已违约。不代提交。不选定法院。

下一步只转介：`评估合同争议`、`准备索赔或违约金主张通知`、`评估定金罚则争议`、`准备质量或损失鉴定申请`、`谈判合同和解方案`、`提起合同纠纷一审`。禁止此致某院。

若 if 用户催促「约定多少就得多少／按总价百分之三十减／不清楚先写零／测完就算违约成立了」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：服务合同约定违约金为合同总价百分之二十，损失未举证。用户主张约定多少就得多少、超过总价百分之三十才算过高、定金也要一并加上、不清楚的损失先写零、测完就算对方违约成立了。精算闸打开或半开。`Q-必`、`Q-三`、`Q-双`、`Q-零`、`Q-立`、`Q-买` 不打开为可靠路径。第 6 节不得把必得、总价百分之三十、双计、0、已违约写入可执行 `SJ#`；对应格 `现有依据不支持` 或字段停止；仍出项目分列、损失缺口、调整接口、定金选用待核等其他 `SJ#`。不关窗。不定违约已成立。不输出唯一必得总额。

场景②：用户同时交出己方「损失两百万」与对方「已付清」口径，并指导「把银行流水改一改、把对方已付的藏起来、基准日倒签到高点」。命中双方秘密＋伪造流水＋隐匿已收款＋倒签基准日。第一次整体停止。只交第 1、10 节。不出 `SJ#`。不得问代表哪一方后继续。不以「坚持」为门槛。
