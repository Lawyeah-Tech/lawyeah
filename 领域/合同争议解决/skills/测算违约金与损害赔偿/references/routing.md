# 边界与路由

## 正触发

一般合同已成争，单方需要违约金、损失、定金、已付款、质保金或减价的可复核数字工作表。本任务不认定违约已经成立。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |
| 只要定性总图或策略地图 | `评估合同争议` |
| 只要定金／订金定性，不要分项测算 | `评估定金罚则争议` |
| 只要价款结算、发票或对账争点 | `评估价款结算与发票争议` |
| 发催告履行 | `准备催告履行或补救通知` |
| 发解除通知 | `准备解除通知` |
| 准备索赔通知但不做精算 | `准备索赔或违约金主张通知` |
| 完整证据卷 | `建立合同争议证据案卷` |
| 质量或损失鉴定申请 | `准备质量或损失鉴定申请` |
| 和解条件 | `谈判合同和解方案` |
| 起诉 | `提起合同纠纷一审` |
| 应诉 | `应对合同纠纷一审` |
| 保险或侵权主轴 | 保险／侵权领域 |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，只分流，不回改 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

用户说“先算对方必须赔多少”：正触发，但必须分项、标情景，并写明不定违约已成立、约定数字不是必得。用户只要“能不能解除、去哪打”：负触发，转评估。定金与违约金都约定且选用不明：两项并列待核，禁止相加。买卖解除后继续主张违约金：买卖合同可引用买卖解释第二十条并仍受第五百八十五条约束；服务合同标待核，不得直接套用。
