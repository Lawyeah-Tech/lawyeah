# 边界与路由

## 正触发

一般合同已成争，单方需要违约金、损失、定金、已付款、质保金或减价的可复核分项测算。从零、碎片、参数未核验、无书面测算授权仍正触发：有可编号条款数字、付款、损失或缺口则闸开或半开，出 `SJ#` 草案，保持草案。本次不定违约已成立、不给必得总额、不写诉状是交付禁令，不是开窗条件。约定金即必得、总价百分之三十、未知写零，仍正触发。

双方秘密、伪造流水、虚增损失、隐匿已收款、倒签基准日、违法取证凑测算的停止，优先于负触发。上述信号不在下表。不定违约已成立不是负触发。「约定金即必得」「总价百分之三十即过分高于」「未知写零」「测算即违约已成立」「定金违约金双计」不在下表。伪造流水不在下表，走整体停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 争议总图 | `评估合同争议` |
| 定金定性不要分项测算 | `评估定金罚则争议` |
| 价款结算或发票争点 | `评估价款结算与发票争议` |
| 发送版催告 | `准备催告履行或补救通知` |
| 发送版解除通知 | `准备解除通知` |
| 索赔通知且不做精算 | `准备索赔或违约金主张通知` |
| 完整证据卷 | `建立合同争议证据案卷` |
| 质量或损失鉴定申请 | `准备质量或损失鉴定申请` |
| 和解条件 | `谈判合同和解方案` |
| 可提交一审起诉包 | `提起合同纠纷一审` |
| 首次应诉答辩 | `应对合同纠纷一审` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |
| 保险或侵权主轴 | 保险／侵权领域 |
| 工程／金融／房产／海事／劳动主轴 | 对应领域 |

不得因「不定违约已成立」或「不给必得总额」关窗。拟分项测算仍正触发，不得写成必得或已违约。

## 易混

本窗闸名只能是精算闸，不是测算闸，不是争议闸，不是发送闸。`SJ#` 不是 `JS#`，不是 `DJ#`，不是 `M#`。主路径是 `Q-测`，不是 `Q-总`，不是 `Q-索`。约定数字不是必得。过分高于对照损失不是合同总价。未知不写零。定金与违约金不得双计。测算不是违约已成立。已失效《合同法》不是现行规则。合同法解释二「标的额百分之三十」不是现行对照。买卖解释第二十条不是服务合同当然规则。「把流水改一改」整体停止。本窗不执行发送，不代提交。不定违约已成立。不输出唯一必得总额。
