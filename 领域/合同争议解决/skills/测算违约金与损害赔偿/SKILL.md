# 测算违约金与损害赔偿

## 任务目标

在明确、无利益冲突的单方立场下（守约方、被指违约方或其受托律师，互斥），形成分项测算草案：精算闸、主体与强制接口、`Q#` 路径、`SJ#` 测算行（项目切片／性质与事件／参数与未舍入公式／已付／扣减／互斥／调整接口／`E#` 回链）。本窗 `SJ#` 是测算行草案，不是必得总额，不是已确定给付，不是索赔函，不是诉状。本窗闸名只能是精算闸，禁止复用争议闸、论坛闸、解除闸、催告闸、发送闸、管辖闸、起诉闸、测算闸、索赔闸、鉴定闸。预留不得占用：立案闸、发送闸、催告闸、解除闸、论坛闸、争议闸。本窗主行只能是 `SJ#`，禁止 `JS#`、`DJ#`、`M#`、`ZT#`、`LT#`、`JC#`、`CG#`、`HF#`、`A#`。主路径只用 `Q-测`，禁止用 `Q-总`、`Q-告`、`Q-函`、`Q-除`、`Q-坛`、`Q-诉`、`Q-索`、`Q-金`、`Q-额`、`Q-解`、`Q-催` 作主路径。邻窗 `Q-测` 只作转介进本窗；本窗打开为主路径，不是已核实、不是必得、不是已立案。本窗 `Q-则` 只转介 `评估定金罚则争议`。本窗 `Q-签` 只作「测算即已提交或已立案」不关窗码。精算闸打开不等于已违约不等于约定金必得不等于调整已确定不等于定金罚则已选用不等于待提交终稿已闭合。约定数字不是必得。过分高于对照损失不是合同总价。增减须当事人请求。未知不写零。定金与违约金选用不明两项待核，不双计。服务合同不得直接套买卖解释第二十条。本任务不认定违约已经成立。不输出唯一必得总额。不写发送版催告、解除或索赔函。不写诉状。不选定法院。不代提交。不定罪。不保证胜诉。伤残等级与本窗无关，禁止折入。

`depends-on` 为空。主成果是争议总图转 `评估合同争议`。主成果是定金定性转 `评估定金罚则争议`。主成果是价款结算转 `评估价款结算与发票争议`。主成果是发送版催告转 `准备催告履行或补救通知`。主成果是发送版解除通知转 `准备解除通知`。主成果是索赔通知转 `准备索赔或违约金主张通知`。主成果是起诉包转 `提起合同纠纷一审`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：一般合同已成争，单方需要违约金、损失、定金、已付款、质保金或减价的可复核分项测算。「必须赔多少」「今天必须出一个数」仍正触发，成果状态 `草案`。参数、调整、互斥未核验仍正触发：有可编号条款数字、付款、损失或可编号缺口则精算闸打开或半开，第 6 节出 `SJ#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出一个法院支持的数」才关闸，仍交十节，第 6 节不出 `SJ#` 终稿，第 7 节不得出诉状、索赔函或必得额，窗口不关。用户要把约定数字写成必得、把过分高于对照合同总价、把未知写成零、把定金与违约金双计、把测算写成违约已成立，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `SJ#` 草案。不得因「不定违约已成立」「不给必得总额」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是争议总图或策略地图（转 `评估合同争议`）；
- 主成果是定金或订金定性且不要分项测算（转 `评估定金罚则争议`）；
- 主成果是价款结算、发票或对账争点（转 `评估价款结算与发票争议`）；
- 主成果是发送版催告（转 `准备催告履行或补救通知`）；
- 主成果是发送版解除通知（转 `准备解除通知`）；
- 主成果是索赔通知且不做精算（转 `准备索赔或违约金主张通知`）；
- 主成果是完整证据卷（转 `建立合同争议证据案卷`）；
- 主成果是质量或损失鉴定申请（转 `准备质量或损失鉴定申请`）；
- 主成果是和解条件（转 `谈判合同和解方案`）；
- 主成果是可提交一审起诉包（转 `提起合同纠纷一审`）；
- 主成果是首次应诉答辩（转 `应对合同纠纷一审`）；
- 尚未成争，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）；
- 保险或侵权主轴；
- 建设工程、金融借贷担保、房地产物业、海事、劳动专项争议主轴。

双方秘密、伪造流水、虚增损失、隐匿已收款、倒签基准日、违法取证凑测算**不在负触发表**，走整体停止。「约定金即必得」「总价百分之三十即过分高于」「未知写零」「测算即违约已成立」「定金违约金双计」「今天必须出一个数」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不定违约已成立」「不给必得总额」「不写诉状」是交付禁令，不是负触发。主成果才转；出现「违约金」「损失」一词不是转出。

## 建立工作坐标

确认：测算授权；单方立场；合同及附件版本；拟测算项目与排除项；已付款、定金、质保金、减价；损失构成；法域。

口头「必须赔多少」「今天必须出一个数」只登记 `S#`／`V#`。不得升格必得或已核实，**不得单独算作开闸材料**。可编号条款数字、付款、损失或可编号缺口可开闸。本窗不执行发送，不代提交，不定违约已成立。

立场只许守约方、被指违约方或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：精算闸关闭，仍交十节，不是整体停止。无书面测算授权但单方立场已闭合、且已有碎片：精算闸部分打开，仍交十节，不是整体停止。提出伪造流水、虚增损失、隐匿已收款、倒签基准日或违法取证凑测算：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`SJ#` 测算行；`V#` 版本；`E#` 证据形态回链（条款、付款、损失凭证，不是发送闸，不是已核实证明，不是已违约证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`M#`、`DJ#`、`JS#`。技能正文中的条号是检索锚点，不是已核验 `L#`。金额旁注只用 `已核实`、`情景`、`无法估计`。未知不写零。真实零必须有肯定来源。不输出唯一必得总额。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。约定数字 ≠ 必得。过分高于对照损失 ≠ 合同总价。无请求 ≠ 已调整。定金与违约金选用不明 ≠ 可双计。测算 ≠ 违约已成立。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或裁判案例检索。本窗是分项测算，**不要**用 `search_template` 生成精算终稿、必得总额、索赔函或诉状。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现约定金即必得、过分高于对照总价、标的额百分之三十、定金违约金双计、未知写零的反例；案例只比较事实差异与翻转条件，不写成必然结果。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把合同法解释二「标的额百分之三十」写成已核验。不得把买卖解释第二十条直接套服务或承揽。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的调整结论、买卖解释适用范围或法定上限保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民法典第五百八十四条损失与可预见。第五百八十五条约定金不是必得；增减须当事人请求；过分高于对照违约造成的损失，不是合同总价。第五百九十一条减损及合理费用另列。第五百九十二条双方违约或过错相抵另列。第五百八十六条至第五百八十八条定金定性与选用；超过主合同标的额百分之二十的部分不产生定金效力。合同编通则解释第六十三条获益扣减分列。第六十四条反诉或抗辩请求调整，不得以约定不得调整排除。第六十五条超过损失百分之三十一般可认定过分高于；恶意违约请求减少一般不予支持。第六十七条、第六十八条定金与违约金选用。买卖解释（2020 修正）第二十条仅买卖因违约解除后可继续主张违约金条款，仍受第五百八十五条约束；服务或承揽不得直接套用。噪声：已失效《合同法》及其解释；合同法解释二「标的额百分之三十」；过分高于对照合同总价；约定金即必得；定金违约金相加；未知写零。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变计入、互斥、第五百八十五条调整、定金选用或买卖解释第二十条适用范围的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补约定金不是必得、过分高于对照损失不是总价、无请求不得写已调减、定金与违约金不得双计、订金不是定金、服务合同不得套买卖解释第二十条、未知不得写零的实务反例。
- `search_case_by_fact` 只比较事实差异与翻转条件：约定金不是必得；百分之三十对照损失不是标的额；选用不明不得相加；无请求不是已调整。无类案不得写成必得或已核实终稿。测算类禁止用 `search_template` 生成精算终稿、必得总额、索赔函或诉状。

工具不可用时继续项目碎片和 `SJ#` 编目；调整结论、买卖解释适用范围、法定上限字段停止。不得拒跑，不得凭记忆写成必得或违约已成立。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、精算闸与不关窗

主成果才整案转出。双方秘密、伪造流水、虚增损失第一次停。约定金即必得不关窗。闸关仍交十节，第 6 节不出 `SJ#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

约定金／迟延违约金／直接损失／可得利益／定金／已付款／质保金／减价分列。本节禁止出 `SJ#` 终稿。

### 3. 精算闸与路径 `Q#`

本节禁止出 `SJ#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-测`。

### 4. 测算行 `SJ#`

项目切片、参数与未舍入公式、已付／扣减、互斥／调整接口。状态 `草案`。禁止升格必得、已核实终稿、违约已成立。无 `E#` 不得写已核实。

### 5. 索赔、鉴定、起诉接口

索赔转索赔窗。第 7 节不得夹带 `SJ#` 终稿或必得额绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造流水、虚增损失、隐匿已收款、倒签基准日或违法取证凑测算。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：精算闸关闭，仍交十节，不是整体停止。无书面测算授权但有碎片：精算闸部分打开，不是整体停止。利益冲突未解：不是整体停止。把未知写成零：该格字段停止，窗口不关，不是整体停止。
- `字段停止`：调整规则、买卖解释适用范围、利率或鉴定参数、施行日未核验。约定金即必得、总价百分之三十、未知写零、测算即违约已成立、定金违约金双计：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `SJ#` 草案。
- `目标停止`：主目标变为总图、发函、建卷、起诉包或必得总额终稿。禁止把「约定金即必得」当作用户错误主张时的目标停止；那是不关窗。

禁止指导伪造流水或虚增损失。不给胜诉率。不定罪。不选定法院。不代提交。未知不写零。不输出唯一必得总额。不定违约已成立。伤残等级禁止折入。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。精算闸关闭仍交十节，第 6 节不出 `SJ#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `SJ#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。精算闸未打开时不得交付「必得总额」或「违约已成立」。边界见 [路由](references/routing.md)。
