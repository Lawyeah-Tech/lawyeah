# 评估管辖与仲裁协议

## 任务目标

在明确、无利益冲突的单方立场下，形成“管辖与仲裁协议评估”：协议文本回链、书面形式、仲裁意思、事项覆盖、机构是否选定或存在、或裁或诉、独立性、诉讼连结点、异议期限待核和主位论坛。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价合同文本、程序文书和争点表。

## 工作边界

正触发：一般合同已成争，需要选择法院还是仲裁；或对方已提出管辖／仲裁协议异议，用户仍需评估该异议是否绊住诉讼或仲裁，而不是只要可提交异议书终稿。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 海事专属管辖、海上货物、船舶或海事保全；
- 劳动关系、劳动报酬、解除劳动合同、工伤待遇等须先劳动仲裁的事项；
- 只要起诉状、仲裁申请书或完整立案包；
- 异议期已过且用户唯一目标是赶写管辖／仲裁协议异议书；若仍需判断论坛或协议效力，本任务继续并标逾期风险；
- 建设工程、金融借贷担保、房地产物业专项争议整案；
- 尚未成争，只要改管辖／仲裁条款或出稿（审查起草领域，本生产线搁置，只说明不实施）。

本任务不生成管辖异议书终稿、仲裁协议异议／效力确认申请终稿、起诉状或仲裁申请书，不给胜诉率，不选定唯一法院。

## 建立评估坐标

确认：使用者与授权；单方立场；相对方及未签字可能约束主体；合同、补充协议、订单和事后书面协议版本；争议事项是否落入仲裁或协议管辖范围；法域；当前协商、催告、立案、应诉或开庭状态；起诉状／仲裁申请／应诉通知的作出与送达；对方已知管辖或仲裁主张。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 论坛假设；`V#` 评估版本；`E#` 发送／送达／应诉凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验仲裁协议要件、独立性、或裁或诉、协议管辖、专属管辖、应诉管辖和异议期限；`search_practiced` 补机构名称瑕疵、格式条款提示说明和失权路径；特殊事实用 `search_case_by_fact`，明确筛选用 `search_case_by_filter`。不虚构案件系统。

`search_law` 对法律结论和期限为 required。工具不可用时继续文本回链、程序文书状态和问题清单；效力、主位论坛法律结论及异议期限字段停止。

《仲裁法》版本与施行日运行时核验后写入 `L#`。效力字段与公布施行日冲突时记录冲突；无法核验则效力、论坛和期限字段停止。不得沿用记忆条号。`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。本任务不判断违约或解除是否成立，不输出发送版催告或解除函。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 专项分流、主体和程序状态

先做工程／金融／房产／海事／劳动整案转出。再固定合同版本和仲裁／管辖条款冲突，并列未签字主体。程序表记录起诉、仲裁申请、应诉通知、首次开庭和已提出的异议：机关／机构、案号、文书、作出日、收到日、送达方式和效力凭证。口头转述、截图、微信“已读”不写成已受理、已送达或异议期限已起算。

### 2. 协议文本回链与书面形式

每个仲裁条款和管辖条款必须回链到可定位文本。分列：载体（主合同／补充协议／事后协议／订单／格式条款）、书面形式、形成时点、签署或确认方式。仅口头“以后仲裁”或无法定位的转述，不得写成已存在书面仲裁协议。

### 3. 仲裁意思、事项覆盖和机构选定

分别判断：是否有请求仲裁的意思；仲裁事项是否覆盖本案请求；是否选定机构；机构是否存在或可确定。机构不明、已撤销且无承继、两个机构未选定，效力标 `依据不足`，不选定唯一论坛。

### 4. 或裁或诉、独立性与主位论坛

或裁或诉不得直接写成有效或无效，须运行时核验现行规则；在核验完成前主位论坛标未选定。合同无效、被撤销或终止，不当然消灭仲裁协议。书面形式、仲裁意思、事项覆盖、机构可确定且无或裁或诉冲突均获支持时，主位写成仲裁，禁止写“应向法院起诉”。任一要件未核验则主位未选定。

### 5. 诉讼连结点、异议期限待核和转出

无仲裁协议或现有依据不支持其适用时，才把一审诉讼列为可行入口。连结点、级别管辖、专属管辖、协议管辖只列待核，不选定唯一法院。已进入程序时标异议期限红旗，不编造截止日期，不写异议书终稿。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或文本无法建立；用户坚持伪造管辖连结点、伪造送达或隐匿仲裁条款。
- `字段停止`：法域、条款原文、机构存续、送达日期、动态规则未核验。
- `目标停止`：主目标已变为起诉状、仲裁申请、管辖异议书终稿或过期赶写异议书。
