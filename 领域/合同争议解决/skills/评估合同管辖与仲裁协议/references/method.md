# 评估合同管辖与仲裁协议方法

本文件是可执行判断节点。评估不是已选定法院。仲裁条款不是当然有效。或裁或诉不是当然有效。口头不是书面协议。已读不是已送达。合同无效不当然消灭仲裁协议。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已选定法院、应起诉、选定唯一法院、代提交、未知写零。本任务不定罪，不写异议书、起诉状或仲裁申请。本窗闸名只能是论坛闸，禁止复用管辖闸、争议闸、起诉闸、答辩闸、催告闸、解除闸、精算闸。预留不得占用：立案闸、催告闸、解除闸、精算闸。本窗 `LT#` 是论坛行。主路径只用 `Q-坛`，禁止用 `Q-管`、`Q-总`、`Q-诉`、`Q-催`、`Q-解`、`Q-裁` 作主路径。英文 id 禁止使用，一律用中文技能名 `评估合同管辖与仲裁协议`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991 年第一百三十条缺席判决、2017 年第三十四条或第一百二十七条未核对应、2017 年仲裁法第十六条至第二十六条未核对应、MCP 把已施行 2025 仲裁法标尚未施行而未以施行日为准、把评估写成已选定法院时记为噪声。禁止指导伪造连结点、伪造送达或隐匿仲裁条款。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现条款扫描，不是默认闭集。
`LT#` 固定列：`编号｜条款切片｜书面形式与仲裁意思｜事项覆盖与机构｜或裁或诉与独立性｜连结点与异议期｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。无 `E#` 不得写已选定、条款已有效或异议期已起算。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-坛`。禁止 `XG#`、`ZT#`、`A#`、`N#`。

口头「就在某地打」「某院一定管」「以后仲裁」只进 `S#`／`V#`，**不得单独算作开闸材料**。已读不得升格已送达。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：书面形式、请求仲裁意思、事项覆盖、选定机构四项未全支持或有或裁或诉冲突时主位未选定。合同无效不当然消灭仲裁协议。首次开庭前未异议视为放弃须核验 2025 文本。不选定唯一法院。

## 节点 0　分流、立场、论坛闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造连结点、伪造送达、隐匿仲裁条款、倒签签署日、伪造仲裁协议、违法取证不进负表。利益冲突未解不进整体停止。不选定法院、不写异议书不是负触发。

整案转出只交付第 1、2、10 节，不出 `LT#` 终稿。

| 主成果是仲裁申请 | 负触发 `提起合同仲裁` |

出现「管辖」「仲裁」一词不是转出。

论坛闸打开（可出 `LT#` 草案，仍不得标「已选定法院／应起诉／条款当然有效」）须同时满足：单方无冲突立场已闭合；主成果是论坛评估，不是起诉包、不是异议书；至少一项可编号条款或连结点碎片。口头「去某院告」不算单独开闸材料。

论坛闸部分打开：已有碎片，但书面形式、机构或连结点未闭合；对应格待核；仍交十节。

论坛闸关闭（仍正触发）：无一可编号碎片。「今天必须出此致某院终稿」而无最小碎片不得开闸。不出 `LT#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `LT#` 终稿，**第 7 节不得出此致某院、起诉状、异议书或仲裁申请**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「评估即已选定法院」「仲裁条款当然有效」「或裁或诉当然有效」「未签署人已受约束」「有效仲裁仍应直接起诉」「已读即异议期起算」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `LT#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 论坛闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造管辖连结点、伪造送达、隐匿仲裁条款、倒签签署日、伪造仲裁协议或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 3　论坛行 `LT#`

按已出现条款扫描，不是默认闭集。每条须能指向条款、书面形式或连结点之一。

无 `E#` 不得写已选定、条款已有效或异议期已起算。状态 `草案`。一次只推荐下一步。未知不写零。不选定唯一法院。

热冲突强制处理：

- 评估即已选定法院／条款当然有效／或裁或诉当然有效／未签署人已受约束／有效仲裁仍应起诉／已读即异议期起算／未知写零 → 该格不支持或字段停止；仍出其他 `LT#`。
- 无一碎片 → 关闸，不出 `LT#` 终稿，窗口不关。
- 指导伪造连结点、隐匿仲裁条款、倒签 → 整体停止，不是该格不支持。

## 节点 4　起诉、仲裁、异议接口

第 7 节只开接口，不得夹带 `LT#` 终稿或此致某院绕闸。闸关闭时第 7 节可写「闸未开，转介待条款编号」，不得补写已选定法院。不选定法院。不代提交。

下一步只转介：`评估合同争议`、`提起合同纠纷一审`、`提起合同仲裁`、`提出合同案件管辖异议`、`准备合同仲裁协议异议材料`、`应对合同纠纷一审`、`应对合同仲裁`、`选择诉讼仲裁或督促程序`。禁止此致某院。

若 if 用户催促「某院一定管／写了仲裁就能裁／有仲裁也直接起诉／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）
