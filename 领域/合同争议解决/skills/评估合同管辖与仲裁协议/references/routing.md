# 边界与路由

## 正触发

一般合同已成争，单方需要选择法院还是仲裁；或对方已提出管辖／仲裁协议异议，用户仍需评估协议效力和主位论坛，而不是只要可提交异议书终稿。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争，改管辖或仲裁条款 | 审查起草领域（本窗搁置，只说明） |
| 只要争议总图 | `评估合同争议` |
| 只要起诉状 | `提起合同纠纷一审` |
| 有效仲裁且决定申请 | `提起合同仲裁` |
| 已被起诉，只要管辖异议书终稿 | `提出合同案件管辖异议` |
| 只要仲裁协议异议或效力确认材料 | `准备合同仲裁协议异议材料` |
| 异议期已过，只要赶写异议书 | 对应 object 项并标逾期；本任务不写终稿 |
| 已进入实体应诉 | `应对合同纠纷一审` 或 `应对合同仲裁` |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，不回改 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全、海事专属 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项管辖规则写入本任务结论。

## 易混

有仲裁条款仍要求“直接起诉”时，先完成本任务论坛闸，不改写成立案原子。对方已提异议但用户要的是效力评估而非异议书，正触发。只要起诉状、只要过期赶写异议书，负触发。海事专属和劳动仲裁不是本任务的“仲裁条款评估”变体。
