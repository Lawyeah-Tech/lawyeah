# 边界与路由

## 正触发

一般合同已成争，需要选择法院还是仲裁；或对方已提出管辖／仲裁协议异议，用户仍需评估效力，而不是只要可提交异议书终稿。从零、碎片、条款未核验、无书面评估授权仍正触发：有可编号条款或连结点碎片则闸开或半开，出 `LT#` 草案，保持草案。本次不选定法院、不写异议书、不给胜诉率是交付禁令，不是开窗条件。评估即已选定法院、仲裁条款当然有效、或裁或诉当然有效，仍正触发。

双方秘密、伪造管辖连结点、伪造送达、隐匿仲裁条款、倒签签署日、伪造仲裁协议、违法取证的停止，优先于负触发。上述信号不在下表。不选定法院不是负触发。「评估即已选定法院」「仲裁条款当然有效」「或裁或诉当然有效」「未签署人已受约束」「有效仲裁仍应直接起诉」「已读即异议期起算」不在下表。伪造隐匿不在下表，走整体停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 争议总图 | `评估合同争议` |
| 起诉包 | `提起合同纠纷一审` |
| 仲裁申请 | `提起合同仲裁` |
| 管辖异议书终稿 | `提出合同案件管辖异议` |
| 仲裁协议异议或效力确认材料 | `准备合同仲裁协议异议材料` |
| 首次应诉答辩 | `应对合同纠纷一审` 或 `应对合同仲裁` |
| 程序选择闭集 | `选择诉讼仲裁或督促程序` |
| 异议期已过且唯一目标赶写异议书 | 对应异议原子，标逾期，不代写终稿 |
| 尚未成争，改管辖／仲裁条款 | 审查起草领域（本窗搁置，只说明） |
| 工程／金融／房产／海事／劳动主轴 | 对应领域 |

不得因「不选定法院」或「不写异议书」关窗。拟论坛评估仍正触发，不得写成已选定法院或应起诉。

## 易混

本窗闸名只能是论坛闸，不是管辖闸，不是争议闸，不是起诉闸。`LT#` 不是 `XG#`，不是 `ZT#`。主路径是 `Q-坛`，不是 `Q-管`，不是 `Q-总`，不是 `Q-裁`。邻窗 `Q-管` 只转介进本窗，本窗不打开 `Q-管`。评估不是已选定法院。仲裁条款不是当然有效。或裁或诉不是当然有效。口头不是书面协议。已读不是已送达。合同无效不当然消灭仲裁协议。1991 年第一百三十条不是现行第一百三十条。2017 年仲裁法条号不是 2025 现行条。仲裁法 2025 修订施行日 2026-03-01 已施行。「把仲裁条款那页藏起来」整体停止。本窗不执行发送，不代提交。不选定法院。
