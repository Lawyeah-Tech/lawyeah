# 争议期间评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然结果或唯一必得总额。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。实务检索若出现“违约金不超过合同标的百分之三十”，记为噪声。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

应诉答辩或提出反诉，不等于当然放弃仲裁协议。解除通知到达对方时解除；未通知而起诉或申请仲裁主张解除的，仅在该主张获确认后，自起诉状或仲裁申请书副本送达时解除，不得把立案日写成解除时点。第 585 条“过分高于”对照违约造成的损失，不对照合同总价。

## 节点 1　分账

每种期间单独一行。禁止用三年诉讼时效去算解除权，也禁止用除斥去挡普通金钱请求。

| 类型 | 规则锚点 | 允许输出 | 禁止 |
| --- | --- | --- | --- |
| 诉讼时效 | 第 188、189 条 | 起算事件、备选起算、中断候选、条件公式 | 唯一截止日；法院主动审查时效 |
| 解除权除斥 | 第 564、199 条 | 知悉日或催告日并行情景 | 与时效混算；适用中止中断 |
| 质量异议或检验期间 | 第 621、622 条；买卖解释：二年为最长合理期限且为不变期间 | 约定检验期、合理期限、质保期、明知例外 | 签收=验收；付款或使用=放弃异议（另有约定除外） |
| 约定催告期或自动解除期 | 合同条款 | 条款原文定位、是否已起算 | 把约定期写成法定除斥 |
| 可撤销除斥 | 第 152、199 条 | 一年、九十日、五年并行 | 并入诉讼时效 |
| 仲裁或管辖异议期 | 程序法，运行时核验 | 已进入程序时标红旗 | 在本任务写出异议书充作法律意见 |

## 节点 2　诉讼时效

1. 普通债权请求权适用三年时效，法律另有规定除外。
2. 起算：知道或应当知道权利受损和义务人。分期履行自最后一期履行期限届满。
3. 中断：请求、同意履行、提起诉讼或申请仲裁等，须有可回链事实。
4. 最长二十年自权利受损害之日起算，有特殊情况可申请延长，须运行时核验。
5. 对方未主张时效抗辩时，不得写成法院将主动驳回。

若：起算日有两种以上证据 → 并行情景，不选对用户有利的一天。
若：用户要求“告诉我最晚哪天起诉”且事实冲突 → 字段停止。

## 节点 3　解除权除斥

1. 解除权存续期间是除斥，不适用诉讼时效中止、中断、延长。
2. 约定行使期限优先核验。
3. 无约定：知道或应当知道解除事由之日起一年；或对方催告后合理期限。
4. 解除是否成立不在本任务终局，只判断期间是否可能届满。
5. 解除时点按通知到达或起诉状副本送达，不是立案日。

若：用户把“过了三年”说成解除权消灭 → 纠正类型错误，分列时效与除斥。

## 节点 4　质量异议与约定催告

1. 约定检验期间过短且不足以完成通常检验的，视为未约定。
2. 未约定检验期：及时检验，在发现或应当发现瑕疵的合理期间内通知。
3. 买卖标的数量或外观瑕疵的合理期间最长二年为不变期间，须核验是否适用本案合同类型。
4. 出卖人知道或应当知道标的不符合约定的，买受人不受通知时间限制。
5. 质量是否构成瑕疵转质量原子，本任务只判断通知是否可能逾期。

## 节点 5　输出纪律

1. 每行只对应一种期间类型和一个起算事件。
2. 禁止输出“本案权利已过期”这种跨类型总括句。
3. 仲裁时效或申请期限与诉讼时效分列。
4. 管辖或仲裁异议期限只做红旗，异议书走相应原子。

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。

下一步按期限灭失、易失证据、改变本任务结论、可逆性排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。

禁止指导伪造、隐匿、威胁或违法取证。未知金额不写零。不把应诉写成放弃仲裁。不把立案日写成解除时点。
