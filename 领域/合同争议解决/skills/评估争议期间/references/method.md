# 评估争议期间方法

本文件是可执行判断节点。除斥不是诉讼时效。已读不是起算。签收不是验收。约定催告期不是法定除斥。质保期不是检验异议期。法院不主动审查时效。禁止唯一截止日。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已届满总括、选定法院、代提交、未知写零。本任务不定罪，不写函，不写诉状。本窗闸名只能是期间闸，禁止复用时效闸、期限闸、除斥闸、争议闸、解除闸。预留不得占用：立案闸。本窗 `QJ#` 是期间行。主路径只用 `Q-期`，禁止用 `Q-时`、`Q-日`、`Q-总`、`Q-除`、`Q-签` 作主路径。本窗 `Q-时` 只作「除斥当诉讼时效或混算」不关窗码。本窗 `Q-日` 只作「唯一截止日」不关窗码。英文 id 禁止使用，一律用中文技能名 `评估争议期间`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回民法通则二年时效、已失效合同法第一百二十九条、民法总则诉讼时效解释、把除斥写成时效或输出唯一截止日时记为噪声。禁止指导伪造期间材料或倒签催告检验日。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现期间碎片扫描，不是默认闭集。
`QJ#` 固定列：`编号｜期间类型切片｜起算事件｜中断中止或除斥并行｜届满风险｜效力接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「本案权利已过期」或「唯一截止日」。无 `E#` 不得写已届满。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-期`。禁止 `ZT#`、`JC#`、`A#`、`N#`。诉讼时效、解除除斥、质量异议或检验、约定催告各占一行。

口头「已经过了」「最晚哪天起诉」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：日期冲突建并行情景。没有送达或知悉事实则字段停止。仲裁申请期限与诉讼时效分列。管辖或仲裁异议期只开红旗。

## 节点 0　分流、立场、期间闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造催告或检验通知、倒签期间起算日、隐匿送达、违法取证不进负表。利益冲突未解不进整体停止。不写唯一截止日、不给胜诉率不是负触发。

整案转出只交付第 1、2、10 节，不出 `QJ#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 主成果是解除权实体终稿 | 负触发 `评估解除权是否成立` |
| 主成果是质量瑕疵终稿 | 负触发 `评估质量瑕疵与检验期间` |
| 主成果是管辖异议书终稿 | 负触发 `提出合同案件管辖异议` |
| 主成果是发送版催告 | 负触发 `准备催告履行或补救通知` |
| 主成果是发送版解除通知 | 负触发 `准备解除通知` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程／金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不写唯一截止日」「不给胜诉率」 | 交付禁令，不是负触发 |

出现「期间」「时效」「除斥」一词不是转出。

期间闸打开（可出 `QJ#` 草案，仍不得标「已届满／唯一截止日」）须同时满足：单方无冲突立场已闭合；主成果是分类型期间表，不是解除实体、不是质量瑕疵终稿、不是唯一截止日意见；至少一项可编号请求、解除事由、检验或催告碎片。口头「已经过了」不算单独开闸材料。

期间闸部分打开：已有碎片，但起算、送达或中断未闭合；对应格待核；仍交十节。无书面评估授权但单方立场已闭合且已有碎片：期间闸部分打开，仍交十节，不是整体停止。

期间闸关闭（仍正触发）：无一可编号碎片。「今天必须出唯一截止日终稿」而无最小碎片不得开闸。不出 `QJ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `QJ#` 终稿，**第 7 节不得出唯一截止日或诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「除斥当时效」「唯一截止日」「已读即起算」「签收即验收」「催告期即法定除斥」「法院主动审查时效」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `QJ#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 期间闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造催告或检验通知、倒签期间起算日、隐匿送达或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 3　期间行 `QJ#`

按已出现期间类型扫描，不是默认闭集。每条须能指向时效、除斥、检验或催告之一。

无 `E#` 不得写已届满。状态默认 `草案`。一次只推荐下一步。未知不写零。日期冲突并行情景。

热冲突强制处理：

- 除斥当时效／唯一截止日／已读即起算／签收即验收／催告期即法定除斥／法院主动审查时效／未知写零 → 该格不支持或字段停止；仍出其他 `QJ#`。
- 无一碎片 → 关闸，不出 `QJ#` 终稿，窗口不关。
- 指导伪造期间材料、倒签催告检验日 → 整体停止，不是该格不支持。

## 节点 4　解除、质量、总图、异议接口

第 7 节只开接口，不得夹带 `QJ#` 终稿或唯一截止日绕闸。闸关闭时第 7 节可写「闸未开，转介待期间类型编号」，不得补写已届满。不选定法院。不代提交。

下一步只转介：`评估合同争议`、`评估解除权是否成立`、`评估质量瑕疵与检验期间`、`准备催告履行或补救通知`、`准备解除通知`、`准备对合同解除通知的异议`、`提出合同案件管辖异议`、`评估合同管辖与仲裁协议`、`应对合同纠纷一审`、`提起合同纠纷一审`、`建立合同争议证据案卷`、`评估合同成立与效力`、`评估债权人撤销权`、`评估迟延拒绝与不完全履行`、`建立双向履行时间线`、`选择合同违约与侵权竞合路径`、`提起合同成立或效力确认之诉`。禁止此致某院。禁止「本案权利已过期」跨类型句。

若 if 用户催促「过了三年解除权没了／已读就算起算／签收就算验收／催告十五天除斥到了／告诉我最晚哪天起诉／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：买方主张过了三年解除权没了、已读就算起算、签收就算验收、催告十五天除斥到了、告诉我最晚哪天起诉、不清楚先写零。期间闸打开或半开。`Q-时`、`Q-读`、`Q-收`、`Q-限`、`Q-日`、`Q-零` 不打开为可靠路径。第 6 节不得把已届满、唯一截止日、0 写入可执行 `QJ#`；对应格 `现有依据不支持` 或字段停止；仍出时效／除斥／检验／催告分列等其他 `QJ#`。不关窗。不写诉状。
