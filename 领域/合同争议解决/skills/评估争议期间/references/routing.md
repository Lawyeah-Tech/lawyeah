# 边界与路由

## 正触发

一般合同已成争，单独委托核验各类期间是否可能届满。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 解除权实体结论 | `评估解除权是否成立` |
| 质量是否构成瑕疵 | `评估质量瑕疵与检验期间` |
| 总体评估 | `评估合同争议` |
| 管辖异议书 | `提出合同案件管辖异议` |
| 要求唯一截止日 | 停止并分列期间，不输出唯一截止日 |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，只分流不回改 |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

用户只要核期间、且接受分类型表时正触发。用户要顺便认定能解除或有质量问题时，把实体转给对应原子。要求给出一个最后日期时停止。
