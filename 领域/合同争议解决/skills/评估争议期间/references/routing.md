# 边界与路由

## 正触发

一般合同已成争，单独委托核验诉讼时效、解除权除斥、质量异议或检验期间、约定催告期是否可能届满。从零、碎片、起算未核验、无书面评估授权仍正触发：有可编号请求、解除事由、检验或催告碎片则闸开或半开，出 `QJ#` 草案，保持草案。本次不写唯一截止日、不给胜诉率是交付禁令，不是开窗条件。除斥当时效、唯一截止日、已读即起算，仍正触发。

双方秘密、伪造催告或检验通知、倒签期间起算日、隐匿送达、违法取证的停止，优先于负触发。上述信号不在下表。不写唯一截止日不是负触发。「除斥当时效」「唯一截止日」「已读即起算」「签收即验收」「催告期即法定除斥」「法院主动审查时效」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 争议总图 | `评估合同争议` |
| 解除权实体终稿 | `评估解除权是否成立` |
| 质量瑕疵终稿 | `评估质量瑕疵与检验期间` |
| 管辖异议书终稿 | `提出合同案件管辖异议` |
| 发送版催告 | `准备催告履行或补救通知` |
| 发送版解除通知 | `准备解除通知` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |
| 工程／金融／房产／海事／劳动主轴 | 对应领域 |

不得因「不写唯一截止日」或「不给胜诉率」关窗。拟分类型期间表仍正触发，不得写成已届满或唯一截止日。

## 易混

本窗闸名只能是期间闸，不是时效闸，不是期限闸，不是解除闸，不是争议闸。`QJ#` 不是 `JC#`，不是 `ZT#`。主路径是 `Q-期`，不是 `Q-时`，不是 `Q-日`，不是 `Q-除`。除斥不是诉讼时效。已读不是起算。签收不是验收。约定催告期不是法定除斥。质保期不是检验异议期。法院不主动审查时效。民法通则二年不是现行三年。已失效合同法第一百二十九条不是一般合同时效。「催告日改到上周」整体停止。本窗不执行发送，不代提交。不选定法院。不写唯一截止日。不写诉状。
