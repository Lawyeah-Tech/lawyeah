# 建立合同争议证据案卷

## 任务目标

在明确、无利益冲突的单方立场下（守约方、被指违约方或其受托律师，互斥），形成合同争议证据案卷草案：证据闸、主体与强制接口、`Q#` 路径、`JE#` 证据行（待证要件／材料形态／支持／不利／控制方／合法取得／`E#` 回链）。本窗 `JE#` 是证据行草案，不是诉状，不是保全终稿，不是已质证，不是已入卷。本窗闸名只能是证据闸，禁止复用案卷闸、争议闸、论坛闸、解除闸、催告闸、发送闸、精算闸、管辖闸、起诉闸、保全闸。预留不得占用：立案闸、发送闸、催告闸、解除闸、论坛闸、精算闸、案卷闸。本窗主行只能是 `JE#`，禁止 `AJ#`、`ZM#`、`ZH#`、`EV#`、`SJ#`、`ZT#`、`LT#`、`JC#`、`CG#`、`HF#`、`A#`。主路径只用 `Q-据`，禁止用 `Q-卷`、`Q-总`、`Q-告`、`Q-函`、`Q-测`、`Q-诉`、`Q-辩`、`Q-现`、`Q-举证`、`Q-调令` 作主路径。邻窗 `Q-卷` 只作转介进本窗；本窗不打开 `Q-卷` 为主路径（公司治理案卷窗占用），改走 `Q-据`。本窗 `Q-现` 只转介 `保全质量现场与电子证据`。本窗 `Q-举证` 只转介 `规划举证期限与证据交换`。本窗 `Q-调令` 只转介 `申请律师调查令或法院调查取证`。本窗 `Q-签` 只作「案卷即已提交或已立案」不关窗码。证据闸打开不等于已入卷不等于已质证不等于已提交不等于已立案不等于已保全不等于已公证。对方控制材料不得推定内容有利。材料缺失不是事件未发生。复制不是已固定。哈希不是已公证。已读不是已到达。红旗不是保全已完成。案卷不是诉状。未知不写零。不写诉状。不写保全申请终稿。不指导违法取证。不选定法院。不代提交。不定罪。不保证采信。不保证胜诉。伤残等级与本窗无关，禁止折入。

`depends-on` 为空。主成果是争议总图转 `评估合同争议`。主成果是发送版催告转 `准备催告履行或补救通知`。主成果是发送版解除通知转 `准备解除通知`。主成果是精算工作表转 `测算违约金与损害赔偿`。主成果是现场或电子保全步骤转 `保全质量现场与电子证据`。主成果是公证保全转 `准备合同案件公证保全`。主成果是鉴定申请转 `准备质量或损失鉴定申请`。主成果是起诉包转 `提起合同纠纷一审`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：一般合同已成争，单独委托建卷，或评估后需要把要件、举证和材料做成可回链案卷。「把证据理一理」「对方电脑里一定有」仍正触发，成果状态 `草案`。材料、控制方、合法性未核验仍正触发：有可编号待证要件、材料碎片、控制方线索或缺口则证据闸打开或半开，第 6 节出 `JE#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须齐证／已质证终稿」才关闸，仍交十节，第 6 节不出 `JE#` 终稿，第 7 节不得出诉状、保全终稿或已质证，窗口不关。用户要把对方控制写成内容有利、把复制写成已固定、把哈希写成已公证、把已读写成已到达、把未知写成零、把案卷写成已提交，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `JE#` 草案。不得因「不写诉状」「不指导违法取证」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是争议总图（转 `评估合同争议`）；
- 主成果是发送版催告（转 `准备催告履行或补救通知`）；
- 主成果是发送版解除通知（转 `准备解除通知`）；
- 主成果是精算工作表（转 `测算违约金与损害赔偿`）；
- 主成果是现场或电子保全步骤（转 `保全质量现场与电子证据`）；
- 主成果是公证保全（转 `准备合同案件公证保全`）；
- 主成果是鉴定申请（转 `准备质量或损失鉴定申请`）；
- 主成果是调查令或法院调查（转 `申请律师调查令或法院调查取证`）；
- 主成果是举证期限与交换计划（转 `规划举证期限与证据交换`）；
- 主成果是起诉包（转 `提起合同纠纷一审`）；
- 主成果是答辩包（转 `应对合同纠纷一审`）；
- 尚未成争，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）；
- 建设工程、金融借贷担保、房地产物业、海事、劳动专项争议主轴。

双方秘密、伪造证据、隐匿、倒签、偷拷电脑、非法侵入、违法取证**不在负触发表**，走整体停止。「对方控制即内容有利」「复制即已固定」「哈希即已公证」「已读即已到达」「案卷即已质证或已立案」「红旗即保全已完成」「未知写零」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不写诉状」「不指导违法取证」「不代提交」「不保证采信」是交付禁令，不是负触发。主成果才转；出现「证据」「案卷」一词不是转出。

## 建立工作坐标

确认：编目授权；单方立场；合同及附件版本；待证争点；已持有材料；对方或第三人控制线索；法域；当前协商、催告、解除、仲裁或诉讼状态。

口头「已经备份」「对方电脑里一定有」「今天必须齐证」只登记 `S#`／`V#`。不得升格已入卷、已固定、已质证或已公证，**不得单独算作开闸材料**。可编号待证要件或材料碎片可开闸。本窗不执行发送，不代提交，不写诉状。

立场只许守约方、被指违约方或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：证据闸关闭，仍交十节，不是整体停止。无书面编目授权但单方立场已闭合、且已有碎片：证据闸部分打开，仍交十节，不是整体停止。提出伪造证据、隐匿、倒签、偷拷电脑、非法侵入或违法取证：第一次提出即整体停止，不以「坚持」为门槛，不得给替代违法方案。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`JE#` 证据行；`V#` 版本；`E#` 证据形态回链（载体、控制方、原件或复制、提取人，不是发送闸，不是已固定证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`EV#`、`AJ#`、`ZM#`、`ZH#`。技能正文中的条号是检索锚点，不是已核验 `L#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。未知不写零。对方控制 ≠ 内容有利。复制 ≠ 已固定。哈希 ≠ 已公证。已读 ≠ 已到达。红旗 ≠ 保全已完成。案卷 ≠ 诉状。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或文书范本检索。本窗是证据编目，范本只借证据目录／编目栏目，**不要**升格「已入卷／已质证／已立案」，**不要**用类案补造对账单内容。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现对方控制即有利、复制即已固定、已读即到达、案卷即诉状的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的举证责任、举证期限或非法排除保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民事诉讼法及民事诉讼证据规定中的举证责任、书证提出、电子数据、举证期限、非法证据排除。民法典到达、履行、解除要件只开接口，不得写成已到达、已解除或当然解除。噪声：已失效《合同法》及其解释；对方控制即存在或有利；缺失即未发生；已读即到达；案卷即诉状或已立案。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变举证责任、书证提出、电子数据、举证期限或非法排除的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补对方控制不是内容有利、缺失不是未发生、已读不是到达、复印件不是原件、案卷不是诉状／已质证／已立案、红旗不是保全已完成的实务反例。
- `search_template` 只借证据目录／编目栏目。范本质证结论、装订日、此致某院、回证栏不得升格已入卷、已质证、已可提交、已立案或待提交终稿。禁止用诉状、答辩、保全申请或催告／解除函模板改头换面。禁止用范本生成伪造证据。

工具不可用时继续要件、材料碎片和 `JE#` 编目；分配、期限、排除字段停止。不得拒跑，不得凭记忆写成已入卷、已质证或内容有利。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、证据闸与不关窗

主成果才整案转出。双方秘密、伪造证据、违法取证第一次停。对方控制即有利、复制即已固定不关窗。闸关仍交十节，第 6 节不出 `JE#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

待证要件分列。支持材料与不利材料并列。本节禁止出 `JE#` 终稿。

### 3. 证据闸与路径 `Q#`

本节禁止出 `JE#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-据`。

### 4. 证据行 `JE#`

待证要件、材料形态、支持／不利、控制方、合法取得。状态 `草案`。禁止升格已入卷、已质证、已固定。无 `E#` 不得写已入卷。

### 5. 保全、鉴定、起诉接口

保全、公证、鉴定、调查令、举证期只开接口。第 7 节不得夹带 `JE#` 终稿或诉状绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造证据、隐匿、倒签、偷拷电脑、非法侵入或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。不得「该部分停后继续编其余目录」。无一可编号碎片：证据闸关闭，仍交十节，不是整体停止。无书面编目授权但有碎片：证据闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：举证责任、举证期限、非法排除、施行日未核验。对方控制即有利、复制即已固定、哈希即已公证、已读即已到达、案卷即已质证或已立案、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `JE#` 草案。
- `目标停止`：主目标变为诉状、保全终稿、催告函、精算终稿或违法取证方案。禁止把「对方控制即有利」当作用户错误主张时的目标停止；那是不关窗。

禁止指导伪造证据或违法取证。不给胜诉率。不定罪。不选定法院。不代提交。未知不写零。不写诉状。不保证采信。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。证据闸关闭仍交十节，第 6 节不出 `JE#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `JE#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。证据闸未打开时不得交付「已入卷」或「已质证」。边界见 [路由](references/routing.md)。
