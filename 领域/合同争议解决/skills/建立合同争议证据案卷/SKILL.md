# 建立合同争议证据案卷

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“合同争议证据案卷矩阵”：争点要件、举证责任、支持材料、不利材料、控制方、合法取得、缺口、补证步骤和最晚时点。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价争点表、请求抗辩和材料清单。本任务不是策略备忘，也不是起诉状或答辩状。

## 工作边界

正触发：一般合同已成争，单独委托建卷，或评估后需要把要件、举证和材料做成可回链案卷。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未成争，只要改合同或出稿（审查起草领域，本生产线搁置，只说明不实施）；
- 只要策略总图或请求抗辩决策，不要证据矩阵；
- 只要发送版催告、解除或索赔函；
- 只要精算工作表；
- 已决定起诉／仲裁申请／答辩／开庭并只要相应文书；
- 建设工程、金融借贷担保、房地产物业、海事、劳动专项争议。

本任务不生成诉状、答辩、代理词或胜诉率，不指导伪造、隐匿、偷拷电脑或违法取证。

## 建立案卷坐标

确认：使用者与授权；单方立场；相对方；合同及附件版本；待证争点和请求／抗辩假设；法域；当前协商、催告、解除、仲裁、诉讼或举证期限状态；已持有材料及来源；对方或第三人控制的材料线索；关键缺失。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`EV#` 证据条目；`V#` 案卷版本；`E#` 发送／送达／履行凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

不能因对方控制而推定材料存在，更不能推定内容有利于己方。材料缺失不证明事件未发生。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验举证责任、书证提出、电子数据、举证期限和非法证据排除的现行条件；`search_practiced` 补举证路径与反例；特殊事实用 `search_case_by_fact`。不虚构调查令或鉴定工具。

工具不可用时继续材料编目、控制方和缺口清单；举证责任分配、举证期限截止、非法证据排除的法律结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [建卷方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 专项分流、立场和争点要件

先做专项分流。只要策略总图或只要诉状则负触发。把每个 `Q#` 拆成待证要件，不把违约写成当然解除，不把已读写成到达。

### 2. 举证责任分配

逐要件写谁主张、谁举证、转移条件和反证对象。运行时核验现行程序规则。规范未核验则分配字段停止，材料编目继续。

### 3. 支持、不利、控制方和合法取得

每个要件并列支持材料和不利材料。记录形成主体、取得方式、控制方和合法取得判断。对方控制的文书不得推定存在或有利。首次要求伪造、隐匿、偷拷电脑或违法取证：该部分整体停止。

### 4. 缺口、补证和最晚时点

缺口写成合法补证步骤、责任人或控制方、最晚时点。期限分类型，不混算诉讼时效、解除权除斥、质量异议期和举证期。不能合法取得的，标停止，不给规避方案。

### 5. 保全红旗、禁止动作和转介

质量现场、电子易失列出保全红旗和合法步骤，转介保全原子。本任务不指导违法取证，不代申请调查令或保全，不把案卷改写成诉状。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或文本无法建立。
- `该部分整体停止`：用户就某一争点或材料坚持伪造、隐匿、偷拷电脑、窃听、非法侵入系统或违法取证。第一次提出即停止该部分，不提供方法。
- `字段停止`：法域、举证责任、举证期限或非法证据排除规则未核验。
- `目标停止`：主目标已变为策略总图、发函、精算、诉状或违法取证方案。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
