# 建立合同争议证据案卷方法

本文件是可执行判断节点。对方控制材料不得推定内容有利。复制不是已固定。哈希不是已公证。已读不是已到达。材料缺失不是事件未发生。案卷不是诉状。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已质证、已入卷、选定法院、代提交、未知写零。本任务不定罪，不写诉状，不指导违法取证。本窗闸名只能是证据闸，禁止复用案卷闸、争议闸、论坛闸、精算闸。预留不得占用：立案闸、案卷闸。本窗 `JE#` 是证据行。主路径只用 `Q-据`，禁止用 `Q-卷`、`Q-总`、`Q-告`、`Q-函`、`Q-测`、`Q-诉` 作主路径。英文 id 禁止使用，一律用中文技能名 `建立合同争议证据案卷`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》及其解释、把对方控制写成内容有利时记为噪声。禁止指导伪造证据、偷拷或违法取证。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现要件扫描，不是默认闭集。
`JE#` 固定列：`编号｜待证要件｜材料形态｜支持／不利｜控制方｜合法取得｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。无 `E#` 不得写已入卷。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-据`。禁止 `AJ#`、`EV#`、`ZM#`、`ZH#`、`A#`、`N#`。

口头「已经备份」「对方电脑里一定有」「今天必须齐证」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。支持材料与不利材料并列。

实务上：对方控制不得推定存在或有利。复印件与原件分列。已读不是到达。红旗只转介保全窗。拒不提交不是主张已成立。

## 节点 0　分流、立场、证据闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造证据、隐匿、倒签、偷拷电脑、非法侵入、违法取证不进负表。利益冲突未解不进整体停止。不写诉状、不指导违法取证不是负触发。

整案转出只交付第 1、2、10 节，不出 `JE#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 主成果是发送版催告 | 负触发 `准备催告履行或补救通知` |
| 主成果是发送版解除通知 | 负触发 `准备解除通知` |
| 主成果是精算工作表 | 负触发 `测算违约金与损害赔偿` |
| 主成果是现场或电子保全步骤 | 负触发 `保全质量现场与电子证据` |
| 主成果是公证保全 | 负触发 `准备合同案件公证保全` |
| 主成果是鉴定申请 | 负触发 `准备质量或损失鉴定申请` |
| 主成果是调查令或法院调查 | 负触发 `申请律师调查令或法院调查取证` |
| 主成果是举证期限与交换计划 | 负触发 `规划举证期限与证据交换` |
| 主成果是起诉包 | 负触发 `提起合同纠纷一审` |
| 主成果是答辩包 | 负触发 `应对合同纠纷一审` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程／金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不写诉状」「不指导违法取证」「不代提交」 | 交付禁令，不是负触发 |

出现「证据」「案卷」一词不是转出。

证据闸打开须同时满足：单方无冲突立场已闭合；主成果是证据矩阵，不是诉状、不是函、不是精算；至少一项可编号待证要件或材料碎片。口头「已经备份」不算单独开闸材料。

证据闸部分打开：已有碎片，但控制方、合法性或原件未闭合；对应格待核；仍交十节。

证据闸关闭（仍正触发）：无一可编号碎片。「今天必须齐证」而无最小碎片不得开闸。不出 `JE#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `JE#` 终稿，**第 7 节不得出诉状、保全终稿或已质证**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「对方控制即内容有利」「复制即已固定」「哈希即已公证」「已读即已到达」「案卷即已质证或已立案」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `JE#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 证据闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造证据、隐匿、倒签、偷拷电脑、非法侵入或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛，不得给替代违法方案。

## 节点 1　主体与强制接口

一行一个待证要件。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `JE#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 要件 | 成立、履行、质量、解除、金额、送达分列 | 合成「合同权益」；违约写成当然解除 |
| 材料 | 原件／复制／电子／口头分列 | 复制升格已固定；哈希升格已公证 |
| 控制方 | 己方／对方／第三人 | 对方控制推定存在或有利 |
| 合法取得 | 取得方式、合法性判断 | 指导偷拷、侵入、隐匿 |

检索锚点（写入 `L#` 前须核验）：民事诉讼法及民事诉讼证据规定中的举证责任、书证提出、电子数据、举证期限、非法证据排除。噪声：已失效《合同法》；对方控制即有利。

## 节点 3　证据行 `JE#`

按已出现要件扫描，不是默认闭集。每条须能指向要件、材料或控制方之一。

无 `E#` 不得写已入卷。状态默认 `草案`。一次只推荐下一步。未知不写零。

热冲突强制处理：

- 对方控制即有利／复制即已固定／已读即到达／案卷即已质证／未知写零 → 该格不支持或字段停止；仍出其他 `JE#`。
- 无一碎片 → 关闸，不出 `JE#` 终稿，窗口不关。
- 指导伪造、偷拷、违法取证 → 整体停止，不是该格不支持。

## 节点 4　保全、鉴定、起诉接口

第 7 节只开接口，不得夹带 `JE#` 终稿或诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待要件编号」，不得补写已入卷。不代提交。不选定法院。

下一步只转介：`评估合同争议`、`保全质量现场与电子证据`、`准备合同案件公证保全`、`准备质量或损失鉴定申请`、`申请律师调查令或法院调查取证`、`规划举证期限与证据交换`、`提起合同纠纷一审`、`应对合同纠纷一审`。禁止此致某院。

若 if 用户催促「对方电脑里一定有／截图就算固定／不清楚先写零／编完就算已提交」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 再执行清单

每个节点结束后回写：来源、判断、最强反方、是否字段停止。不得跳过证据闸直接给已入卷或已质证。

若 if 举证责任、举证期限、非法排除未核验，then 该强制项字段停止，窗口不关。
判断状态只许三值。口头「已经备份」不得写成 `JE#` 已入卷。未知不写零。

## 本任务回链纪律

本任务成果是「证据闸与证据行草案」。本窗不执行发送。不包含：已入卷、已质证、诉状、保全终稿。禁止选边治愈。禁止对方控制即有利。禁止复制即已固定。禁止指导伪造或违法取证。证据闸打开 ≠ 已入卷 ≠ 已质证。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标案卷终稿已形成。
风险档 A：伪造证据、偷拷、违法取证必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：买方主张对账单在对方财务电脑里、微信截图已经备份、不清楚的货款先写零、编完目录就算已提交。证据闸打开或半开。`Q-控`、`Q-复`、`Q-零`、`Q-签` 不打开为可靠路径。第 6 节不得把内容有利、已固定、0、已提交写入可执行 `JE#`；对应格 `现有依据不支持` 或字段停止；仍出要件分列、控制方、原件缺口等其他 `JE#`。不关窗。不写诉状。

场景②：用户同时交出己方「必须连夜齐证」与对方「从未违约」口径，并指导「今晚把对方邮箱拷下来补进卷」。命中双方秘密＋偷拷／违法取证。第一次整体停止。只交第 1、10 节。不出 `JE#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代违法方案。
