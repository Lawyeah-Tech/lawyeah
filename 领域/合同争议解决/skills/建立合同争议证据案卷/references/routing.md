# 边界与路由

## 正触发

一般合同已成争，单独委托建卷，或评估后需要把要件、举证和材料做成可回链案卷。从零、碎片、材料未核验、无书面编目授权仍正触发：有可编号待证要件或材料碎片则闸开或半开，出 `JE#` 草案，保持草案。本次不写诉状、不指导违法取证、不代提交是交付禁令，不是开窗条件。对方控制即有利、复制即已固定、未知写零，仍正触发。

双方秘密、伪造证据、隐匿、倒签、偷拷电脑、非法侵入、违法取证的停止，优先于负触发。上述信号不在下表。不写诉状不是负触发。「对方控制即内容有利」「复制即已固定」「哈希即已公证」「已读即已到达」「案卷即已质证或已立案」不在下表。伪造偷拷不在下表，走整体停止。

## 易混

本窗闸名只能是证据闸，不是案卷闸，不是争议闸，不是精算闸。`JE#` 不是 `AJ#`，不是 `EV#`。主路径是 `Q-据`，不是 `Q-卷`，不是 `Q-总`。邻窗 `Q-卷` 只转介进本窗，本窗不打开 `Q-卷`。对方控制不是内容有利。复制不是已固定。哈希不是已公证。已读不是已到达。案卷不是诉状。红旗不是保全已完成。未知不写零。已失效《合同法》不是现行规则。「今晚把对方邮箱拷下来」整体停止。本窗不执行发送，不代提交。不写诉状。不保证采信。
