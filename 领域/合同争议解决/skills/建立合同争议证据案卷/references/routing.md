# 边界与路由

## 正触发

一般合同已成争，单独委托盘点举证责任和补证，或评估后需要把要件、材料和缺口做成可回链案卷。本任务不是策略备忘，也不是起诉状。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |
| 只要策略总图或请求抗辩决策 | `评估合同争议` |
| 质量现场、聊天或邮件可能灭失，要保全步骤 | `保全质量现场与电子证据` |
| 只要公证送达或证据保全公证 | `准备合同案件公证保全` |
| 要质量或损失鉴定申请 | `准备质量或损失鉴定申请` |
| 关键证据在第三方，要调查令或法院调查 | `申请律师调查令或法院调查取证` |
| 已立案，只要举证期限与交换计划 | `规划举证期限与证据交换` |
| 发催告或解除通知 | `准备催告履行或补救通知` 或 `准备解除通知` |
| 精算违约金或损失 | `测算违约金与损害赔偿` |
| 和解条件 | `谈判合同和解方案` |
| 只要诉状 | `提起合同纠纷一审` |
| 只要答辩 | `应对合同纠纷一审` |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，只分流，不回改 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项鉴定或优先受偿规则写入本任务结论。

## 易混

用户说“把证据理一理，顺便写起诉思路”：本任务只建矩阵，策略总图和诉状分别转介。用户说对方电脑里一定有对账单且内容有利：不得推定存在或有利，只列控制方、合法调取路径和缺口。用户要求偷拷电脑、私装录音、侵入邮箱：该部分整体停止。质量现场或电子易失：列保全红旗后转介保全原子，本任务不展开违法取证步骤。
