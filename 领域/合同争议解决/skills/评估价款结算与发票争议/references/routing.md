# 边界与路由

## 正触发

对账、结算、发票、质保金扣留发生争议，且存在履行抗辩或结算缺口。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 纯欠款催收交叉 | 可交催收交叉，有抗辩留本领域 |
| 支付令 | `申请合同金钱支付令` |
| 工程结算 | 建设工程领域 |
| 定金 | `评估定金罚则争议` |
| 抵销扣款 | `评估抵销留置与扣款抗辩` |
| 测算 | `测算违约金与损害赔偿` |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，只分流不回改 |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

对不上账、票和款缠在一起时正触发。钱数清楚且无抗辩时可以分流催收。工程审计定案转工程。
