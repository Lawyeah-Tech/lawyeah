# 边界与路由

## 正触发

对账、结算、发票、质保金扣留发生争议，且存在履行抗辩或结算缺口。从零、碎片、对账未核验、无书面授权仍正触发：有可编号价款、对账、发票、质保金或付款碎片则闸开或半开，出 `ZP#` 草案，保持草案。本次不定已结清、不写催收函是交付禁令，不是开窗条件。对账单即改约、发票即已付款，仍正触发。把质保金扣留写成抵销、把未开票写成拒付全部，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造对账或发票、虚开、倒签的停止，优先于负触发。上述信号不在下表。不定已结清不是负触发。「对账单即改约」「发票即已结算或已付款」「质保金扣留即抵销」「未开票即拒付全部」「沉默即确认」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 精算工作表或必得核算 | `测算违约金与损害赔偿` |
| 抵销、留置或扣款终稿 | `评估抵销留置与扣款抗辩` |
| 框架与订单冲突 | `评估框架协议与订单冲突` |
| 定金定性 | `评估定金罚则争议` |
| 纯无争议到期欠款催收或支付令 | `申请合同金钱支付令` |
| 工程造价或竣工结算 | 建设工程领域 |
| 争议总图 | `评估合同争议` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |
| 只要开票税务筹划 | 税务领域 |

不得因「不定已结清」或「不写催收函」关窗。拟结算评估仍正触发，不得写成已结算或已付款。

## 易混

本窗闸名只能是结算闸，不是对账闸，不是发票闸，不是抵留闸，不是精算闸。`ZP#` 不是 `SJ#`，不是 `DX#`，不是 `DN#`，不是 `JS#`，不是 `DJ#`。主路径是 `Q-票`，不是 `Q-对`，不是 `Q-结`，不是 `Q-测`，不是 `Q-销`。`Q-对` 是框约窗「对账单即改约」不关窗码，本窗同样只作不关窗。`Q-票` 在公司治理、合规是表决或有发票即真实的不关窗，本窗打开为主路径不是已付款。`抵留闸`／`Q-销` 是评估抵销留置与扣款抗辩。`精算闸`／`Q-测` 是测算违约金与损害赔偿。对账单不是当然改约。发票不是当然结算。已失效合同法第一百五十九条至第一百六十一条不是现行。MCP 查通则解释第三十一条可能先返回买卖解释第三十一条。「对账日改到上周」「空白发票先补一张」整体停止。本窗不执行发送，不代提交。不选定法院。不写催收函。不写精算终稿。
