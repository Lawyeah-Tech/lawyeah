# 评估价款结算与发票争议

## 任务目标

在明确、无利益冲突的单方立场下（主张价款请求或结算抗辩一方或其受托律师，互斥），形成结算评估草案：结算闸、主体与强制接口、`Q#` 路径、`ZP#` 账票行（批次切片／约定价与已付／付款条件与发票牵连／对账确认效力／质保金／扣款／抗辩接口／`E#` 回链）。本窗 `ZP#` 是账票行草案，不是已结算证明，不是已付款，不是已改约，不是已抵销，不是催收函，不是精算终稿。本窗闸名只能是结算闸，禁止复用对账闸、发票闸、价款闸、质保闸、抵留闸、精算闸、金罚闸、索赔闸、框约闸。预留不得占用：立案闸、和解闸。本窗主行只能是 `ZP#`，禁止 `JS#`、`DJ#`、`SJ#`、`DN#`、`SH#`、`DX#`、`KY#`、`JP#`、`A#`。主路径只用 `Q-票`，禁止用 `Q-对`、`Q-结`、`Q-账`、`Q-清`、`Q-测`、`Q-索`、`Q-则`、`Q-销`、`Q-架`、`Q-签` 作主路径。邻窗 `Q-票` 只作转介进本窗；本窗打开为主路径，不是已结清、不是已确认、不是已付款、不是必得。本窗 `Q-对` 只作「对账单即改约或即已结算」不关窗码。本窗 `Q-测` 只转介 `测算违约金与损害赔偿`。本窗 `Q-销` 只转介 `评估抵销留置与扣款抗辩`。本窗 `Q-清` 只转介 `处理解除后返还与清理`。本窗 `Q-签` 只作「评估即已结清、已提交或已立案」不关窗码。结算闸打开不等于已结算不等于已付款不等于已改约不等于已抵销不等于待提交终稿。对账单不是当然改约。单方对账沉默不是当然确认。发票不是当然结算也不是当然已付款。增值税专用发票及抵扣资料不是已交付。未开票不是当然拒付全部价款。质保金扣留不是当然抵销也不是当然赔偿。未知不写零。不写催收函。不写精算终稿。不写诉状。不选定法院。不代提交。不定罪。伤残等级与本窗无关，禁止折入。

`depends-on` 为空。主成果是精算工作表转 `测算违约金与损害赔偿`。主成果是抵销扣款终稿转 `评估抵销留置与扣款抗辩`。主成果是框架与订单冲突转 `评估框架协议与订单冲突`。主成果是纯无争议到期欠款催收转 `申请合同金钱支付令`。主成果是工程造价或竣工结算转建设工程领域。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：对账、结算、发票、质保金扣留发生争议，且存在履行抗辩或结算缺口。「对过账就算结了」「开了票就算付了」仍正触发，成果状态 `草案`。对账、发票、已付未核验仍正触发：有可编号价款、对账、发票、质保金或付款碎片则结算闸打开或半开，第 6 节出 `ZP#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出已结算／已付款终稿」才关闸，仍交十节，第 6 节不出 `ZP#` 终稿，第 7 节不得出催收函或精算终稿，窗口不关。用户要把对账单写成已改约、把发票写成已结算或已付款、把质保金扣留写成抵销、把未开票写成拒付全部、把沉默写成确认、把未知写成零，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `ZP#` 草案。不得因「不定已结清」「不给必得总额」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是精算工作表或必得核算（转 `测算违约金与损害赔偿`）；
- 主成果是抵销、留置或扣款终稿（转 `评估抵销留置与扣款抗辩`）；
- 主成果是框架与订单冲突（转 `评估框架协议与订单冲突`）；
- 主成果是定金定性（转 `评估定金罚则争议`）；
- 主成果是纯无争议到期欠款催收或支付令（转 `申请合同金钱支付令`）；
- 主成果是工程造价或竣工结算（转建设工程领域）；
- 主成果是争议总图（转 `评估合同争议`）；
- 尚未成争，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）；
- 只要开票税务筹划（转税务领域）。

双方秘密、伪造对账单或发票或流水、虚开、隐匿已付款或已开票、倒签对账日或开票日、违法取证**不在负触发表**，走整体停止。「对账单即改约」「发票即已结算或已付款」「质保金扣留即抵销」「未开票即拒付全部」「沉默即确认」「未知写零」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不定已结清」「不给必得总额」「不写催收函」是交付禁令，不是负触发。主成果才转；出现「结算」「发票」「对账」一词不是转出。

## 建立工作坐标

确认：评估授权；单方立场；约定价与已付；对账单或结算函；发票与开票约定；质保金条款；法域。

口头「对过账就算结了」「开了票就算付了」只登记 `S#`／`V#`。不得升格已结算、已付款、已改约或已抵销，**不得单独算作开闸材料**。可编号价款、对账、发票、质保金或付款碎片可开闸。本窗不执行发送，不代提交，不写催收函，不写精算终稿，不选定法院。

立场只许主张价款请求或结算抗辩一方或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：结算闸关闭，仍交十节，不是整体停止。无书面授权但单方立场已闭合、且已有碎片：结算闸部分打开，仍交十节，不是整体停止。提出伪造对账单或发票或流水、虚开、隐匿已付款或已开票、倒签对账日或开票日或违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`ZP#` 账票行；`V#` 版本；`E#` 证据形态回链（合同价、对账单、发票、付款凭证、授权，不是发送闸，不是已结算证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`JS#`、`DJ#`、`SJ#`、`DN#`、`SH#`、`DX#`。技能正文中的条号是检索锚点，不是已核验 `L#`。文件状态只用 `草案`、`待提交`、`停止`。对账、发票或已付未闭合不得标 `待提交`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。未知不写零。对账单 ≠ 已改约。发票 ≠ 已结算。质保金扣留 ≠ 抵销。未开票 ≠ 拒付全部。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或裁判案例检索。本窗是评估，**不要**用 `search_template` 生成对账确认书、结算协议、开票函或诉状，**不要**用类案写成必然已结算。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现对账单即改约、发票即结算、质保金扣留即抵销、未开票即拒付全部、沉默即确认的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效合同法第一百五十九条至第一百六十一条及其解释当作现行。不得把发票管理办法 2019 年第十九条当现行开票条。MCP 查询通则解释第三十一条可能先返回买卖解释第三十一条抗辩反诉分界，须核通则解释第三十一条从给付与主要债务。MCP 效力字段与公布施行日冲突时，以施行日为准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的对账效力、发票先决、质保金返还保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民法典第五百零九条全面履行。第五百一十条、第五百一十一条填补不是已改约，价格漏洞不编单价。第五百二十五条、第五百二十六条同时履行与先履行，发票是否先决待核。第六百二十六条、第六百二十八条买卖价款支付。通则解释第二十六条开具发票等非主要债务，原则上不因此解除。第三十一条以未履行非主要债务拒付主要债务一般不支持，另有约定或致目的不能除外。买卖解释（2020 修正）第一条送货单、结算单、发票、对账确认函须结合交易方式与习惯，不是当然成立、不是当然结算、不是当然改约。第五条仅专票及抵扣资料不能单证已交付；普通发票仅约定或习惯可证付款，相反证据可推翻。噪声：已失效合同法及其解释；2012 年买卖解释未改码文本；发票管理办法 2019 年第十九条。技能正文条号不是 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变对账效力、发票先决或质保金返还的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补对账单不是改约、发票不是结算、质保金扣留不是抵销、未开票不是当然先履行抗辩、沉默不是确认、有票不是已付款的实务反例。
- `search_case_by_fact` 只比较事实差异与翻转条件：对账单不是当然改约；单方对账沉默不是确认；发票不是当然结算或已付款；专票不是已交付；未开票不是拒付全部；质保金扣留不是法定抵销。无类案不得写成已结算、已付款或已改约终稿。评估类禁止用 `search_template` 生成对账确认书、结算协议、开票函或诉状。

工具不可用时继续价款碎片和 `ZP#` 编目；对账效力、发票先决、质保金字段停止。不得拒跑，不得凭记忆写成已结算或已付款。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、结算闸与不关窗

主成果才整案转出。双方秘密、伪造对账或发票、虚开第一次停。对账单即改约、发票即已付款不关窗。闸关仍交十节，第 6 节不出 `ZP#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

约定价、已付、发票、对账、质保金分列。本节禁止出 `ZP#` 终稿。

### 3. 结算闸与路径 `Q#`

本节禁止出 `ZP#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-票`。

### 4. 账票行 `ZP#`

批次切片、约定价与已付、付款条件与发票牵连、对账确认效力、质保金／扣款／抗辩接口。状态 `草案`。禁止升格已结算、已付款、已改约。无 `E#` 不得写已结清。对账或已付未闭合不得标 `待提交`。

### 5. 测算、抵留、履抗、支付令接口

精算转测算窗。扣款抵销转抵留窗。先履行抗辩转履抗窗。纯欠款转支付令。第 7 节不得夹带 `ZP#` 终稿、催收函或必得额绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造对账单或发票或流水、虚开、隐匿已付款或已开票、倒签对账日或开票日或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：结算闸关闭，仍交十节，不是整体停止。无书面授权但有碎片：结算闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：对账效力、发票先决、质保金、已付、施行日未核验。对账单即改约、发票即已结算或已付款、质保金扣留即抵销、未开票即拒付全部、沉默即确认、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `ZP#` 草案。
- `目标停止`：主目标变为精算终稿、催收函、税务筹划或工程造价鉴定。禁止把「对账单即改约」或「发票即已付款」当作用户错误主张时的目标停止；那是不关窗。

禁止指导伪造对账单或虚开。不给胜诉率。不定罪。不选定法院。不代提交。未知不写零。不写催收函。不写精算终稿。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。结算闸关闭仍交十节，第 6 节不出 `ZP#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `ZP#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。结算闸未打开时不得交付「已结算」或「已付款」。边界见 [路由](references/routing.md)。
