# 边界与路由

## 正触发

一般合同已成争，核心争点是合同是否成立、是否有效、是否可撤销或效力待定，或是否构成无权代理／表见代理。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要总体评估 | `评估合同争议` |
| 只要解释条款 | `解释争议条款与填补漏洞` |
| 只要格式条款效力 | `评估争议中的格式条款` |
| 电子成立或送达主争点 | `评估电子合同成立与送达` |
| 提起确认之诉 | `提起合同成立或效力确认之诉` |
| 框架与订单冲突 | `评估框架协议与订单冲突` |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，只分流不回改 |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

争的是“有没有合同、管不管用”时正触发。争的是条款什么意思但不否定合同存在时，转解释原子。已决定打确认之诉且只要诉状时负触发。
