# 边界与路由

## 正触发

一般合同已成争，核心争点是成立、无权代理、无效、可撤销或效力待定。从零、碎片、到达未核验、无书面评估授权仍正触发：有可编号合同、要约承诺、印章或履行碎片则闸开或半开，出 `CL#` 草案，保持草案。本次不写诉状、不把口头写成已成立是交付禁令，不是开窗条件。口头即已成立、无权代理当然有效或无效、未追认即已追认，仍正触发。

双方秘密、伪造合同、倒签签署日、伪造印章、隐匿文本、违法取证的停止，优先于负触发。上述信号不在下表。不写诉状不是负触发。「口头即已成立」「已读即已到达」「无权代理当然有效或当然无效」「未追认即已追认」「无效即未成立」「可撤销即当然无效」「盖章即表见」「假章一律无效」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 争议总图 | `评估合同争议` |
| 条款解释且不争成立效力 | `解释争议条款与填补漏洞` |
| 格式条款提示说明专项 | `评估争议中的格式条款` |
| 电子到达或电子签名专项 | `评估电子合同成立与送达` |
| 框架与订单冲突 | `评估框架协议与订单冲突` |
| 变更是否成立 | `评估变更是否成立` |
| 确认之诉诉状 | `提起合同成立或效力确认之诉` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |
| 工程／金融／房产／海事／劳动主轴 | 对应领域 |

不得因「不写诉状」或「不把口头写成已成立」关窗。拟成立效力专项仍正触发，不得写成已成立或当然无效。

## 易混

本窗闸名只能是成立闸，不是效力闸，不是评估闸，不是争议闸。`CL#` 不是 `ZT#`，不是 `XL#`。主路径是 `Q-契`，不是 `Q-立`，不是 `Q-成`，不是 `Q-效`。口头不是已成立。已读不是到达。无权代理不是当然有效或当然无效。未追认不是已追认。无效不是未成立。可撤销不是当然无效。盖章不是表见。假章不是一律无效。未生效不是无效。已失效合同法第五十一条不是现行。民法通则不是现行。「签署日改到上周」「印章先刻一版」整体停止。本窗不执行发送，不代提交。不选定法院。不写诉状。
