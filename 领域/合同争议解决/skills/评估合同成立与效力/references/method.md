# 成立与效力评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然结果或唯一必得总额。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。实务检索若出现“违约金不超过合同标的百分之三十”，记为噪声。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

应诉答辩或提出反诉，不等于当然放弃仲裁协议。解除通知到达对方时解除；未通知而起诉或申请仲裁主张解除的，仅在该主张获确认后，自起诉状或仲裁申请书副本送达时解除，不得把立案日写成解除时点。第 585 条“过分高于”对照违约造成的损失，不对照合同总价。

## 节点 1　成立争点

1. 先固定要约与承诺文本、到达凭证、是否要求书面或批准、是否已实际履行。
2. 若只有意向书、框架或预约：判断是否具备本约主要条款并有受约束意思。材料不足则成立字段标 `依据不足，无法形成结论`。
3. 一方已履行主要义务且对方接受的，可以支持合同成立，但仍须核验法定批准或登记是否影响生效。
4. 电子承诺、点击确认走电子合同原子接口，本任务只留到达与意思表示缺口。
5. 禁止把“已经合作很久”写成成立，除非能回链具体意思表示或履行接受事实。

若：当事人主张从未签字且无履行接受 → 不得写合同已成立。
若：有签字或盖章但主体名称冲突 → 并列主体，不选对用户有利的一版。
若：法定批准未完成 → 成立与生效分列，不把未生效写成无效。

## 节点 2　代理与代表

1. 无权代理：相对人可催告被代理人追认；被代理人已履行或接受履行，视为追认。
2. 表见代理：须有代理权外观，且相对人善意无过失。内部授权限制不得当然对抗善意相对人，但须核验外观事实。
3. 法定代表人或负责人越权：不得对抗善意相对人。相对人是否知道或应当知道越权必须单独判断。
4. 假章、私刻、盗用：不自动等于合同不成立或不生效，须结合履行、表见和鉴定接口。
5. 若用户要求按“假章一律无效”出结论且无鉴定或履行事实：该字段停止。

## 节点 3　无效路径

运行时核验民法典第一编第六章和合同编效力条文后再落判断。核验失败则效力字段停止。

1. 虚假意思表示无效，隐藏行为依其效力规则处理。
2. 违反法律、行政法规的强制性规定：区分效力性与管理性；仅管理性违法不得径直写合同全部无效。
3. 违背公序良俗无效。不得把商业上不道德直接写成公序良俗。
4. 恶意串通损害他人合法权益无效。须有通谋和损害事实，不得凭价格偏低单独认定。
5. 免责条款：造成对方人身损害或因故意或重大过失造成财产损失的免责条款无效。

`search_law` 返回已失效《合同法》第五十二条清单时记为噪声，改核现行民法典条文。

## 节点 4　可撤销与效力待定

1. 重大误解、欺诈、胁迫、显失公平分列要件和除斥。
2. 除斥：知道或应当知道撤销事由之日起一年；重大误解九十日；胁迫终止之日起一年；行为发生之日起五年不行使则消灭。
3. 日期冲突建并行情景，不给唯一截止日。
4. 限制民事行为能力人实施的合同效力待定，纯获利益或与年龄智力相适应的除外。
5. 无权处分不再当然按效力待定处理；处分权缺失主要影响物权变动，合同效力另判。

若：撤销权除斥可能届满 → 可撤销路径标红旗，不把合同写成已经有效终局。
若：用户只要改条款让合同有效 → 目标停止，转审查起草（搁置）。

## 节点 5　后果与程序接口

1. 无效或被撤销自始没有法律约束力；已履行的返还或折价，有过错的赔偿损失。
2. 部分无效不影响其他部分，但核心给付不可分时不得强行切割。
3. 争议解决条款继续评估，不因主合同效力争点当然消灭。
4. 需要法院或仲裁确认成立、不成立、无效或撤销：转 `提起合同成立或效力确认之诉`。
5. 金钱后果只建接口，不替代 `测算违约金与损害赔偿`。

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。

下一步按期限灭失、易失证据、改变本任务结论、可逆性排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。

禁止指导伪造、隐匿、威胁或违法取证。未知金额不写零。不把应诉写成放弃仲裁。不把立案日写成解除时点。
