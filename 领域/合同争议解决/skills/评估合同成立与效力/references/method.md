# 评估合同成立与效力方法

本文件是可执行判断节点。口头或已读不是已成立。无权代理不是当然有效或当然无效。未追认不是已追认。无效不是未成立。可撤销不是当然无效。盖章不是表见。假章不是一律无效。未生效不是无效。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已成立终局、选定法院、代提交、未知写零。本任务不定罪，不写确认之诉诉状。本窗闸名只能是成立闸，禁止复用效力闸、评估闸、争议闸。预留不得占用：立案闸。本窗 `CL#` 是成立效力行。主路径只用 `Q-契`，禁止用 `Q-立`、`Q-成`、`Q-效`、`Q-总`、`Q-签` 作主路径。本窗 `Q-签` 只作「评估即已确认成立或已提交」不关窗码。英文 id 禁止使用，一律用中文技能名 `评估合同成立与效力`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》第五十一条、第五十二条、民法通则、民法总则、把口头写成已成立或把无权代理写成当然有效时记为噪声。禁止指导伪造合同或倒签签署日。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现文本碎片扫描，不是默认闭集。
`CL#` 固定列：`编号｜文本切片｜要约承诺或履行成立｜代理代表与追认｜无效／可撤销／待定｜除斥与后果／独立性｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已成立」或「当然无效」。无 `E#` 不得写已成立。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-契`。禁止 `ZT#`、`XL#`、`A#`、`N#`。

口头「早就成立了」「盖了章就算数」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：成立与生效分列。无效、可撤销、效力待定分列。代理与代表分列。除斥并行情景，不写唯一截止日。

## 节点 0　分流、立场、成立闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造合同、倒签签署日、伪造印章、隐匿文本、违法取证不进负表。利益冲突未解不进整体停止。不写诉状、不把口头写成已成立不是负触发。

整案转出只交付第 1、2、10 节，不出 `CL#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 主成果是条款解释且不争成立效力 | 负触发 `解释争议条款与填补漏洞` |
| 主成果是格式条款提示说明专项 | 负触发 `评估争议中的格式条款` |
| 主成果是电子到达或电子签名专项 | 负触发 `评估电子合同成立与送达` |
| 主成果是框架与订单冲突 | 负触发 `评估框架协议与订单冲突` |
| 主成果是变更是否成立 | 负触发 `评估变更是否成立` |
| 主成果是确认之诉诉状 | 负触发 `提起合同成立或效力确认之诉` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程／金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不写诉状」「不把口头写成已成立」 | 交付禁令，不是负触发 |

出现「成立」「无效」一词不是转出。

成立闸打开（可出 `CL#` 草案，仍不得标「已成立／已无效／已追认」）须同时满足：单方无冲突立场已闭合；主成果是成立效力专项，不是总图、不是诉状、不是格式专项；至少一项可编号合同、要约承诺、印章或履行碎片。口头「早就成立了」不算单独开闸材料。

成立闸部分打开：已有碎片，但到达、追认或除斥未闭合；对应格待核；仍交十节。无书面评估授权但单方立场已闭合且已有碎片：成立闸部分打开，仍交十节，不是整体停止。

成立闸关闭（仍正触发）：无一可编号碎片。「今天必须出已成立终稿」而无最小碎片不得开闸。不出 `CL#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `CL#` 终稿，**第 7 节不得出诉状或已成立终局**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「口头即已成立」「已读即已到达」「无权代理当然有效或当然无效」「未追认即已追认」「无效即未成立」「可撤销即当然无效」「盖章即表见」「假章一律无效」「未生效即无效」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `CL#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 成立闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造合同、倒签签署日、伪造印章、隐匿文本或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 3　成立效力行 `CL#`

按已出现文本碎片扫描，不是默认闭集。每条须能指向成立、代理、无效可撤销待定或除斥之一。

无 `E#` 不得写已成立。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止唯一除斥截止日。

热冲突强制处理：

- 口头即已成立／已读即到达／无权代理当然有效或无效／未追认即已追认／无效即未成立／可撤销即当然无效／盖章即表见／假章一律无效／未生效即无效／未知写零 → 该格不支持或字段停止；仍出其他 `CL#`。
- 无一碎片 → 关闸，不出 `CL#` 终稿，窗口不关。
- 指导伪造合同、倒签签署日、伪造印章 → 整体停止，不是该格不支持。

## 节点 4　电子、格式、确认之诉、返还接口

第 7 节只开接口，不得夹带 `CL#` 终稿或诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待文本编号」，不得补写已成立。不选定法院。不代提交。

下一步只转介：`评估合同争议`、`解释争议条款与填补漏洞`、`评估争议中的格式条款`、`评估电子合同成立与送达`、`评估框架协议与订单冲突`、`评估变更是否成立`、`提起合同成立或效力确认之诉`、`评估合同管辖与仲裁协议`、`处理解除后返还与清理`、`测算违约金与损害赔偿`、`建立合同争议证据案卷`、`提起合同纠纷一审`、`应对合同纠纷一审`、`评估争议期间`、`评估解除权是否成立`、`选择诉讼仲裁或督促程序`。禁止此致某院。

若 if 用户催促「口头就算成立了／盖了章就算数／假章一律无效／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。
