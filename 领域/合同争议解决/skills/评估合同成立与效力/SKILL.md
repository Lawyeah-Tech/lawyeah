# 评估合同成立与效力

## 任务目标

在明确、无利益冲突的单方立场下（主张成立或有效一方、主张不成立或无效一方或其受托律师，互斥），形成成立与效力评估草案：成立闸、主体与强制接口、`Q#` 路径、`CL#` 成立效力行（文本切片／要约承诺或履行成立／代理代表与追认／无效／可撤销／待定／除斥与后果／独立性／`E#` 回链）。本窗 `CL#` 是成立效力行草案，不是已成立证明，不是已无效终局，不是确认之诉诉状。本窗闸名只能是成立闸，禁止复用效力闸、评估闸、争议闸、论坛闸、解除闸、催告闸、发送闸、精算闸、起诉闸、答辩闸、证据闸、方案闸。预留不得占用：立案闸。本窗主行只能是 `CL#`，禁止 `ZT#`、`XL#`、`HT#`、`QT#`、`A#`。主路径只用 `Q-契`，禁止用 `Q-立`、`Q-成`、`Q-效`、`Q-总`、`Q-诉`、`Q-签` 作主路径。邻窗 `Q-契` 只作转介进本窗；本窗打开为主路径，不是已成立、不是已确认。本窗 `Q-签` 只作「评估即已确认成立或已提交」不关窗码。成立闸打开不等于已成立不等于已生效不等于已无效不等于已撤销不等于表见已成立不等于除斥未届满不等于应起诉。口头或已读不是已成立。无权代理不是当然有效或当然无效。未追认不是已追认。无效不是未成立。可撤销不是当然无效。盖章不是表见。假章不是一律无效。未生效不是无效。意向书不是本约。未知不写零。不写确认之诉诉状。不选定法院。不代提交。不定罪。不保证胜诉。伤残等级与本窗无关，禁止折入。

`depends-on` 为空。主成果是争议总图转 `评估合同争议`。主成果是确认之诉诉状转 `提起合同成立或效力确认之诉`。主成果是条款解释且不争成立效力转 `解释争议条款与填补漏洞`。主成果是电子到达专项转 `评估电子合同成立与送达`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：一般合同已成争，核心争点是合同是否成立、是否有效、是否可撤销或效力待定，或是否构成无权代理／表见代理。「合同算不算成立」「盖了章有没有效」仍正触发，成果状态 `草案`。到达、追认、除斥未核验仍正触发：有可编号合同、要约承诺、印章或履行碎片则成立闸打开或半开，第 6 节出 `CL#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出已成立／已无效终稿」才关闸，仍交十节，第 6 节不出 `CL#` 终稿，第 7 节不得出诉状或已成立终局，窗口不关。用户要把口头写成已成立、把已读写成已到达、把无权代理写成当然有效或当然无效、把未追认写成已追认、把无效写成未成立、把可撤销写成当然无效、把盖章写成表见、把假章写成一律无效、把未生效写成无效、把未知写成零，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `CL#` 草案。不得因「不写诉状」「不把口头写成已成立」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是争议总图（转 `评估合同争议`）；
- 主成果是条款解释且不争成立效力（转 `解释争议条款与填补漏洞`）；
- 主成果是格式条款提示说明专项（转 `评估争议中的格式条款`）；
- 主成果是电子到达或电子签名专项（转 `评估电子合同成立与送达`）；
- 主成果是框架与订单冲突（转 `评估框架协议与订单冲突`）；
- 主成果是变更是否成立（转 `评估变更是否成立`）；
- 主成果是确认之诉诉状（转 `提起合同成立或效力确认之诉`）；
- 尚未成争，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）；
- 建设工程、金融借贷担保、房地产物业、海事、劳动专项争议主轴。

双方秘密、伪造合同、倒签签署日、伪造印章、隐匿文本、违法取证**不在负触发表**，走整体停止。「口头即已成立」「已读即已到达」「无权代理当然有效或当然无效」「未追认即已追认」「无效即未成立」「可撤销即当然无效」「盖章即表见」「假章一律无效」「未生效即无效」「未知写零」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不写诉状」「不把口头写成已成立」是交付禁令，不是负触发。主成果才转；出现「成立」「无效」一词不是转出。

## 建立工作坐标

确认：评估授权；单方立场；相对方；合同、要约、承诺、附件、订单、实际履行和印章版本；法域；当前协商、催告、仲裁或诉讼状态。

口头「早就成立了」「盖了章就算数」「假章一律无效」只登记 `S#`／`V#`。不得升格已成立、已有效或已追认，**不得单独算作开闸材料**。可编号合同、要约承诺、印章或履行碎片可开闸。本窗不执行发送，不代提交，不写诉状。

立场只许主张成立或有效一方、主张不成立或无效一方或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：成立闸关闭，仍交十节，不是整体停止。无书面评估授权但单方立场已闭合、且已有碎片：成立闸部分打开，仍交十节，不是整体停止。提出伪造合同、倒签签署日、伪造印章、隐匿文本或违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`CL#` 成立效力行；`V#` 版本；`E#` 证据形态回链（文本版本、到达凭证、印章、履行，不是发送闸，不是已成立证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`ZT#`、`XL#`。技能正文中的条号是检索锚点，不是已核验 `L#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。未知不写零。口头 ≠ 已成立。已读 ≠ 到达。无权代理 ≠ 当然有效或当然无效。未追认 ≠ 已追认。无效 ≠ 未成立。可撤销 ≠ 当然无效。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或裁判案例检索。本窗是评估，**不要**用 `search_template` 生成已成立证明或确认之诉诉状，**不要**用类案写成必然有效或无效。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现口头即已成立、已读即到达、无权代理当然有效或无效、未追认即已追认、无效即未成立、可撤销即当然无效的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、《民法通则》《民法总则》当作现行规则。不得把合同法第五十一条无权处分效力待定、第五十二条无效清单当作现行。MCP 效力字段与公布施行日冲突时，以施行日为准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的成立、追认、除斥或无效结论保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民法典第一百三十七条非对话到达相对人时生效，数据电文进入指定系统时生效，已读不是到达。第一百三十六条民事法律行为自成立时生效，法律另有规定或当事人另有约定除外。第一百四十三条有效要件：行为能力、意思表示真实、不违反法律行政法规强制性规定、不违背公序良俗，不得写成已核验「已成立」。第一百四十六条通谋虚伪无效，隐藏行为另依规定。第一百四十七条至第一百五十一条欺诈、胁迫、重大误解、显失公平可撤销，分列不得合成当然无效。第一百五十二条撤销权除斥：自知道或应当知道之日起一年，重大误解九十日，胁迫行为终止之日起一年，最长五年；并行情景，不写唯一截止日。第一百九十九条除斥不适用诉讼时效中止、中断、延长。第一百五十三条违反法律行政法规强制性规定的民事法律行为无效，但该强制性规定不导致无效的除外；违背公序良俗无效。仅管理性规定不是当然全部无效。第一百七十一条无权代理：未经追认对被代理人不发生效力，相对人可催告、善意相对人可撤销；不是当然有效也不是当然无效。第一百七十二条表见代理须相对人有理由相信有代理权，盖章不是当然表见。第四百八十三条承诺生效时合同成立，法律另有规定或另有约定除外。第五百零二条依法成立的合同自成立时生效；未办理批准等手续影响生效的，不影响报批义务条款；未生效不是无效。第五百零三条无权代理人订立合同，被代理人已经开始履行或接受履行的，视为追认；未履行不是已追认。第五百零四条越权代表，除相对人知道或应当知道外，该代表行为有效。第五百零七条合同不生效、无效、被撤销或终止，不影响争议解决条款。噪声：已失效合同法第五十一条无权处分效力待定、第五十二条无效清单；民法通则第五十八条；民法总则。技能正文条号不是 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变成立、追认、除斥或无效入口的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补口头不是已成立、已读不是到达、无权代理不是当然有效或无效、未追认不是已追认、无效不是未成立、可撤销不是当然无效、盖章不是表见、假章不是一律无效的实务反例。
- `search_case_by_fact` 只比较事实差异与翻转条件：口头不是成立；已读不是到达；无权代理不是当然有效或无效；未追认不是已追认；无效不是未成立；可撤销不是当然无效。无类案不得写成已成立或已无效终稿。评估类禁止用 `search_template` 生成确认之诉诉状或已成立证明。

工具不可用时继续文本碎片和 `CL#` 编目；成立、追认、除斥、无效结论字段停止。不得拒跑，不得凭记忆写成已成立或当然无效。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、成立闸与不关窗

主成果才整案转出。双方秘密、伪造合同、倒签签署日第一次停。口头即已成立、无权代理当然有效不关窗。闸关仍交十节，第 6 节不出 `CL#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

要约承诺、到达、形式、代理、无效可撤销待定分列。本节禁止出 `CL#` 终稿。

### 3. 成立闸与路径 `Q#`

本节禁止出 `CL#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-契`。

### 4. 成立效力行 `CL#`

文本切片、成立、代理追认、无效可撤销待定、除斥与后果。状态 `草案`。禁止升格已成立、已追认、已无效终局。无 `E#` 不得写已成立。

### 5. 电子、格式、确认之诉、返还接口

电子到达转电子窗。格式条款转格式窗。确认之诉转确认之诉窗。第 7 节不得夹带 `CL#` 终稿或诉状绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造合同、倒签签署日、伪造印章、隐匿文本或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：成立闸关闭，仍交十节，不是整体停止。无书面评估授权但有碎片：成立闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：到达、追认、除斥、强制性规定效力、施行日未核验。口头即已成立、已读即到达、无权代理当然有效或无效、未追认即已追认、无效即未成立、可撤销即当然无效、盖章即表见、假章一律无效、未生效即无效、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `CL#` 草案。
- `目标停止`：主目标变为确认之诉诉状、争议总图、未成争改稿或发送版解除函。禁止把「口头即已成立」当作用户错误主张时的目标停止；那是不关窗。

禁止指导伪造合同或倒签签署日。不给胜诉率。不定罪。不选定法院。不代提交。未知不写零。不写诉状。不写唯一除斥截止日。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。成立闸关闭仍交十节，第 6 节不出 `CL#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `CL#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。成立闸未打开时不得交付「已成立」或「已无效」。边界见 [路由](references/routing.md)。
