# 保全质量现场与电子证据

## 任务目标

给出保全步骤、公证或鉴定分流和禁止动作。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算、通知和证据清单。

## 工作边界

正触发：瑕疵、现场、聊天或邮件可能灭失，需要合法固定。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未成争，只要改合同或出稿（审查起草领域，本生产线搁置，只说明不实施）;
- 建设工程、金融借贷担保、房地产物业、海事、劳动专项争议;
- 指导违法取证或侵入系统;
- 建设工程现场主轴（转工程）;
- 只要鉴定申请终稿;

不指导违法取证。工程现场转工程。不给胜诉率。

## 建立评估坐标

确认：使用者与授权；单方立场；相对方及可能责任主体；合同及附件版本；争议事项；法域；当前协商、催告、仲裁、诉讼或执行状态；机关文书作出与送达；对方已知主张；关键材料及缺失。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩或本任务假设；`V#` 评估或稿件版本；`E#` 发送／送达／履行凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民事诉讼法证据保全和电子数据规则的现行文本；`search_practiced` 补路径与反例；特殊事实用 `search_case_by_fact`，明确筛选用 `search_case_by_filter`。不虚构案件系统。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。工具不可用时继续事实、主体、程序文书状态和问题清单；法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　对象与灭失风险

实物、现场状态、网页、邮箱、聊天、后台日志分列。无灭失风险则说明普通取证即可。

### 节点 2　合法手段

自行固定、公证、法院证据保全、鉴定抽样。手段与对象匹配。

### 节点 3　禁止

禁止侵入、窃听、盗号、破坏现场、伪造时间戳、威胁保管人。

### 节点 4　分流

公证转公证原子。鉴定抽样转鉴定原子。诉前保全转财产或行为保全接口，行为保全属 P2 则 unavailable。

### 节点 5　记录

操作人、时间、哈希或封存、见证人。单方事后补拍证明力弱。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或文本无法建立；用户坚持伪造、隐匿、威胁或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为违法取证方案或工程现场专属操作。
