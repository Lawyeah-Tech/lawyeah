# 边界与路由

## 正触发

瑕疵、现场、聊天或邮件可能灭失，需要合法固定。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 工程现场 | 建设工程领域 |
| 公证 | `准备合同案件公证保全` |
| 鉴定 | `准备质量或损失鉴定申请` |
| 调查令 | `申请律师调查令或法院调查取证` |
| 质量实体评估 | `评估质量瑕疵与检验期间` |
| 行为保全 | unavailable（P2） |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，只分流不回改 |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

东西或聊天马上没了、要合法固定时正触发。要鉴定意见时转鉴定。工程工地转工程。要违法手段时停止。
