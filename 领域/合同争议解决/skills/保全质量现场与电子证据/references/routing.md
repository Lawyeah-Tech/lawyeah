# 边界与路由

## 正触发

瑕疵实物、现场状态、网页、邮箱、聊天或后台日志可能灭失，需要合法自固、公证分流或法院证据保全接口。从零、碎片、持有未核验、无书面授权仍正触发：有可编号对象或灭失风险碎片则闸开或半开，出 `XZ#` 草案，保持草案。本次不代提交、不写已保全、不指导违法取证是交付禁令，不是开窗条件。截图即原件、哈希即已公证、申请即已准许，仍正触发。把草稿写成已保全、把口头或已读写成已固定，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造聊天、破坏现场、侵入的停止，优先于负触发。上述信号不在下表。不代提交不是负触发。「草稿即已保全」「口头或已读即已固定」「截图即原件」「哈希即已公证」「申请即已准许」「红旗即已保全」「对方控制即内容有利」不在下表。

## 易混

本窗闸名只能是现证闸，不是固证闸，不是证据闸，不是质量闸，不是时线闸，不是保全闸，不是封存闸。`XZ#` 不是 `JE#`，不是 `ZL#`，不是 `SX#`，不是 `FC#`，不是 `GD#`。主路径是 `Q-现`，不是 `Q-据`，不是 `Q-疵`，不是 `Q-保`，不是 `Q-账`，不是 `Q-固`。`证据闸`／`Q-据` 是建立合同争议证据案卷。`质量闸`／`Q-疵` 是评估质量瑕疵与检验期间。`保全闸`／`Q-保` 预留给财产保全窗。`封存闸`／`Q-账` 是公司治理账簿封存窗。`Q-固` 只作「口头或已读即已固定」不关窗码，不是主路径。草稿不是已保全。截图不是原件。哈希不是已公证。申请不是已准许。1991 年民事诉讼法第八十四条公告送达不是现行证据保全条。2017 年第八十一条须核对应现行第八十四条。证据规定第二十五条仍可能引旧第八十一条。仲裁法第五十八条 MCP 标尚未施行时以施行日为准。提出「今晚去把货拆了取样」「把对方邮箱拷下来」整体停止。本窗不执行发送，不代提交。不选定法院。不写申请书终稿。不指导违法取证。
