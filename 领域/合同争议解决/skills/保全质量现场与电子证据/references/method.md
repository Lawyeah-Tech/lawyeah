# 保全质量现场与电子证据方法

本文件是可执行判断节点。草稿不是已保全。口头或已读不是已固定。截图不是原件。哈希不是已公证。申请不是已准许。红旗不是已保全。对方控制不是内容有利。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已保全、已公证、已准许、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不写保全申请终稿，不指导违法取证。本窗闸名只能是现证闸，禁止复用固证闸、证据闸、质量闸、时线闸、保全闸、封存闸、案卷闸、鉴定闸、公证闸。预留不得占用：立案闸、和解闸、保全闸。本窗 `XZ#` 是现证行。主路径只用 `Q-现`，禁止用 `Q-据`、`Q-疵`、`Q-历`、`Q-保`、`Q-账`、`Q-卷`、`Q-固`、`Q-签` 作主路径。本窗 `Q-签` 只作「草稿即已保全、已公证或已提交」不关窗码。本窗 `Q-固` 只作「口头或已读即已固定」不关窗码。英文 id 禁止使用，一律用中文技能名 `保全质量现场与电子证据`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991 年民事诉讼法第八十四条公告送达、2017 年第八十一条旧号、2001 年证据规定第十四条分类编号、把截图写成原件或把申请写成已准许时记为噪声。禁止指导违法取证、破坏现场或伪造聊天。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现对象切片扫描，不是默认闭集。
`XZ#` 固定列：`编号｜对象切片｜灭失风险｜合法自固步骤｜公证／鉴定／法院证据保全分流｜禁止动作红旗｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已保全」或「已准许」。无 `E#` 不得写已保全或已公证。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-现`。禁止 `JE#`、`ZL#`、`SX#`、`FC#`、`AJ#`、`GD#`、`GZ#`、`BQ#`、`A#`、`N#`。文件状态只用 `草案`、`停止`。

口头「已经截过图了」「哈希就算公证了」「今晚去把货拆了取样」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：仅对己方合法持有或已同意接触的材料做拍照、录像、复制、哈希、见证人。对方控制场所强行进入、拆封或拷贝是违法取证。公证机构只证明提取过程，不保证必然可采。区块链上链前仍是普通证据。单方事后补拍证明力弱。财产保全申请书终稿转财产保全窗。

「草稿即已保全」「口头或已读即已固定」「截图即原件」「哈希即已公证」「申请即已准许」「红旗即已保全」「对方控制即内容有利」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `XZ#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 现证闸关闭，仍交十节，不是整体停止。

## 节点 3　现证行 `XZ#`

按已出现对象切片扫描，不是默认闭集。每条须能指向灭失风险、合法自固、公证鉴定法院保全分流或禁止动作红旗之一。

无 `E#` 不得写已保全或已公证。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止把红旗写成已保全。持有范围未闭合不得标 `待提交`。

热冲突强制处理：

- 草稿即已保全／口头或已读即已固定／截图即原件／哈希即已公证／申请即已准许／红旗即已保全／对方控制即内容有利／未知写零 → 该格不支持或字段停止；仍出其他 `XZ#`。
- 无一碎片 → 关闸，不出 `XZ#` 终稿，窗口不关。
- 指导违法取证、破坏现场、伪造聊天、侵入 → 整体停止，不是该格不支持。
