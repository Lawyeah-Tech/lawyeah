# 准备催告履行或补救通知

## 任务目标

在明确、无利益冲突的单方立场下（催告方债权人或其受托律师，互斥），形成发送前催告草稿：催告闸、主体与强制接口、`Q#` 路径、`CG#` 催告行（请求切片／义务与原履行期／现状与补救请求／期限依据／渠道与回证／`E#` 回链）。本窗 `CG#` 是催告行草案，不是已发送，不是已到达，不是已解除，不是解除函，不是诉状。本窗闸名只能是催告闸，禁止复用争议闸、论坛闸、解除闸、发送闸、精算闸、管辖闸、起诉闸、送达闸、案卷闸。预留不得占用：立案闸、发送闸、精算闸、论坛闸、解除闸。本窗主行只能是 `CG#`，禁止 `ZT#`、`LT#`、`JC#`、`A#`。主路径只用 `Q-告`，禁止用 `Q-催`、`Q-函`、`Q-解`、`Q-总`、`Q-除`、`Q-送`、`Q-道` 作主路径。邻窗 `Q-告` 只作转介进本窗；本窗打开为主路径，不是已发出。本窗 `Q-道` 只转介 `设计合同案件通知送达`。本窗 `Q-签` 只作「催告稿即已发送或已提交」不关窗码。催告闸打开不等于已发送不等于已到达不等于催告期已起算不等于已解除不等于待发送终稿已闭合。催告草稿不是已发送。已读不是已到达。催告不是已解除。构成违约不是当然解除。合理期限不是一律十五日。微信已读不是合法送达。未知不写零。不执行发送。不代提交。不代签收。不选定法院。不写逾期即已解除。不定罪。不保证到达。不保证胜诉。伤残等级与本窗无关，禁止折入。

`depends-on` 为空。主成果是争议总图转 `评估合同争议`。主成果是解除权评估转 `评估解除权是否成立`。主成果是发送版解除通知转 `准备解除通知`。主成果是索赔通知转 `准备索赔或违约金主张通知`。主成果是精算工作表转 `测算违约金与损害赔偿`。主成果是独立复杂送达方案转 `设计合同案件通知送达`。主成果是起诉包转 `提起合同纠纷一审`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：一般合同已成争，用户仍希望对方履行、修理、更换、重作、补足或付款，本次主成果是催告而不是解除。「尽快催一下」「逾期即解除」「一律十五日」仍正触发，成果状态 `草案`，不执行发送。义务、期限、渠道未核验仍正触发：有可编号义务、迟延或瑕疵事实、既有催告或请求切片则催告闸打开或半开，第 6 节出 `CG#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出已发送终稿」才关闸，仍交十节，第 6 节不出 `CG#` 终稿，第 7 节不得出已发送、逾期已解除或解除函，窗口不关。用户要把草稿写成已发送、把已读写成已到达、把催告写成已解除、把合理期限写成一律十五日、把未知写成零，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `CG#` 草案。不得因「不执行发送」「禁止逾期即已解除」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是争议总图（转 `评估合同争议`）；
- 主成果是解除权评估且不发函（转 `评估解除权是否成立`）；
- 主成果是发送版解除通知（转 `准备解除通知`）；
- 主成果是索赔通知（转 `准备索赔或违约金主张通知`）；
- 主成果是精算工作表（转 `测算违约金与损害赔偿`）；
- 主成果是独立复杂送达方案为唯一成果（转 `设计合同案件通知送达`）；
- 主成果是完整证据卷（转 `建立合同争议证据案卷`）；
- 主成果是起诉包（转 `提起合同纠纷一审`）；
- 尚未成争，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）；
- 建设工程、金融借贷担保、房地产物业、海事、劳动专项争议主轴。

双方秘密、伪造履行、倒签催告、伪造送达、隐匿证据、违法取证**不在负触发表**，走整体停止。「催告即已解除」「逾期即已解除」「已读即已到达」「草稿即已发送」「一律十五日」「保证到达」「未知写零」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不执行发送」「不保证到达」「不代提交」是交付禁令，不是负触发。主成果才转；出现「催告」「履行」一词不是转出。

## 建立工作坐标

确认：催告授权；单方立场；相对方及通知接收主体；合同及附件版本；被催告的具体义务和原履行期；已发生迟延或瑕疵事实；已发出过的催告；约定送达渠道；法域。

口头「尽快催一下」「逾期即解除」「一律十五日」只登记 `S#`／`V#`。不得升格已发送、已到达或已解除，**不得单独算作开闸材料**。可编号义务、迟延或瑕疵事实、既有催告或请求切片可开闸。已读不等于到达。本窗不执行发送，不代提交，不代签收。已发出的催告如实登记，不把旧函改写成未发送。

立场只许催告方债权人或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：催告闸关闭，仍交十节，不是整体停止。无书面催告授权但单方立场已闭合、且已有碎片：催告闸部分打开，仍交十节，不是整体停止。提出伪造履行、倒签催告、伪造送达、隐匿证据或违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`CG#` 催告行；`V#` 版本；`E#` 证据形态回链（合同义务、迟延事实、渠道栏目、授权，不是发送闸，不是已发送证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`ZT#`、`LT#`、`JC#`。技能正文中的条号是检索锚点，不是已核验 `L#`。文件状态只用 `草案`、`待签署`、`停止`。期限或到达未闭合不得标 `待签署`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。未知不写零。催告草稿 ≠ 已发送。已读 ≠ 已到达。催告 ≠ 已解除。构成违约 ≠ 当然解除。合理期限 ≠ 一律十五日。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或文书范本检索。本窗是催告草稿准备，范本只借催告／履行通知函栏目，**不要**升格「已发送／已到达／已解除」。催款函里的解除合同、仲裁诉讼栏不得升格已解除或已起诉。逾期贷款催收是金融窗，破产管理人回复是破产窗。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现催告即已解除、已读即到达、一律十五日、草稿即已发送、只发微信即合法送达的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把商品房催告后三个月套一般买卖当然适用。不得把合理期限写成一律十五日。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的期限是否合理、到达或逾期即解除保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民法典第五百零九条应当按照约定全面履行。第五百七十七条继续履行、补救或赔偿，不是当然解除。第五百八十二条修理、重作、更换、退货、减少价款或报酬。第五百六十三条迟延主要债务原则上经催告后合理期限仍未履行；合理期限不得写成一律十五日；催告是解除前提，不是本函已解除。第一百三十七条非对话意思表示到达相对人时生效；数据电文进入指定系统时生效；已读不是到达。第五百六十五条通知到达对方时解除，不得把本催告稿写成已经解除。噪声：已失效《合同法》及其解释；商品房催告后三个月套一般买卖；法定十五日；逾期即已解除；催告稿即已发送。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变催告必要、合理期限、到达效力或补救方式的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补催告不是已解除、已读不是到达、一律十五日不是法定、只发微信不是约定渠道、催告稿不是已发送、构成违约不是函内已解除的实务反例。
- `search_template` 只借催告／履行通知函栏目。范本解除栏、逾期即解除句、此致某院、落款日、送达回证栏不得升格已发送、已到达、已解除或待发送终稿。禁止用解除通知模板改头换面。禁止用范本生成发送版解除函或伪造送达步骤。

工具不可用时继续义务碎片和 `CG#` 编目；期限是否合理、到达、逾期即解除字段停止。不得拒跑，不得凭记忆写成已发送、已到达、已解除或一律十五日。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、催告闸与不关窗

主成果才整案转出。双方秘密、伪造催告、倒签第一次停。催告即已解除不关窗。闸关仍交十节，第 6 节不出 `CG#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

继续履行／修理／更换／重作／补足／付款分列。约定期限／合理期限待核分列。本节禁止出 `CG#` 终稿。

### 3. 催告闸与路径 `Q#`

本节禁止出 `CG#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-告`。

### 4. 催告行 `CG#`

请求切片、义务与原履行期、现状与补救请求、期限依据、渠道与回证。状态 `草案`。禁止升格已发送、已到达、已解除。无 `E#` 不得写已发送。

### 5. 解除、发送、精算与送达接口

解除转解除权或发送窗。第 7 节不得夹带 `CG#` 终稿或已发送结论绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造履行、倒签催告、伪造送达、隐匿证据或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：催告闸关闭，仍交十节，不是整体停止。无书面催告授权但有碎片：催告闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：期限是否合理、到达、渠道、施行日未核验。催告即已解除、逾期即已解除、已读即已到达、草稿即已发送、一律十五日、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `CG#` 草案。
- `目标停止`：主目标变为解除函、精算终稿、起诉包、已发送终稿。禁止把「催告即已解除」当作用户错误主张时的目标停止；那是不关窗。

禁止指导伪造催告或倒签发出日。不给胜诉率。不定罪。不选定法院。不代提交。不执行发送。未知不写零。不写逾期即已解除。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。催告闸关闭仍交十节，第 6 节不出 `CG#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `CG#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。催告闸未打开时不得交付「已发送」或「已解除」。边界见 [路由](references/routing.md)。
