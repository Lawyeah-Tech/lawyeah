# 准备催告履行或补救通知方法

本文件是可执行判断节点。催告草稿不是已发送。已读不是已到达。催告不是已解除。构成违约不是当然解除。合理期限不是一律十五日。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已发送、已到达、已解除、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不保证到达。本窗闸名只能是催告闸，禁止复用争议闸、论坛闸、解除闸、发送闸、精算闸、管辖闸、起诉闸。预留不得占用：立案闸、发送闸、精算闸、论坛闸、解除闸。本窗 `CG#` 是催告行。主路径只用 `Q-告`，禁止用 `Q-催`、`Q-函`、`Q-解`、`Q-总`、`Q-除`、`Q-送` 作主路径。英文 id 禁止使用，一律用中文技能名 `准备催告履行或补救通知`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》及其解释、商品房催告后三个月套一般买卖、一律十五日、把催告写成已解除时记为噪声。禁止指导伪造催告或倒签发出日。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现义务扫描，不是默认闭集。
`CG#` 固定列：`编号｜请求切片｜义务与原履行期｜现状与补救请求｜期限依据｜渠道与回证｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。无 `E#` 不得写已发送。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-告`。禁止 `ZT#`、`LT#`、`JC#`、`A#`、`N#`。文件状态只用 `草案`、`待签署`、`停止`。期限或到达未闭合不得标 `待签署`。

口头「尽快催一下」「逾期即解除」「一律十五日」只进 `S#`／`V#`，**不得单独算作开闸材料**。已发出的催告如实登记，不把旧函改写成未发送。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。继续履行、修理、更换、重作、补足、付款分列。

实务上：迟延主要债务原则上先催告。合理期限不得写成一律十五日。已读不是到达。催告是解除前提，不是本函已解除。本窗不执行发送。

## 节点 0　分流、立场、催告闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造履行、倒签催告、伪造送达、隐匿证据、违法取证不进负表。利益冲突未解不进整体停止。不执行发送、不保证到达不是负触发。

整案转出只交付第 1、2、10 节，不出 `CG#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 主成果是解除权评估（不发函） | 负触发 `评估解除权是否成立` |
| 主成果是发送版解除通知 | 负触发 `准备解除通知` |
| 主成果是索赔通知 | 负触发 `准备索赔或违约金主张通知` |
| 主成果是精算工作表 | 负触发 `测算违约金与损害赔偿` |
| 主成果是独立复杂送达方案 | 负触发 `设计合同案件通知送达` |
| 主成果是完整证据卷 | 负触发 `建立合同争议证据案卷` |
| 主成果是起诉包 | 负触发 `提起合同纠纷一审` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程／金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不执行发送」「不保证到达」「不代提交」 | 交付禁令，不是负触发 |

出现「催告」「履行」一词不是转出。

催告闸打开须同时满足：单方无冲突催告方立场已闭合；主成果是催告草稿，不是解除函、不是诉状；至少一项可编号义务、迟延或瑕疵事实、既有催告或请求切片。口头「尽快催一下」不算单独开闸材料。

催告闸部分打开：已有碎片，但期限、渠道或请求未闭合；对应格待核；仍交十节。

催告闸关闭（仍正触发）：无一可编号碎片。「今天必须出已发送终稿」而无最小碎片不得开闸。不出 `CG#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `CG#` 终稿，**第 7 节不得出已发送、逾期已解除或解除函**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「催告即已解除」「逾期即已解除」「已读即已到达」「草稿即已发送」「一律十五日」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `CG#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 催告闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造履行、倒签催告、伪造送达、隐匿证据或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个请求切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `CG#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 请求 | 继续履行／修理／更换／重作／补足／付款分列 | 合成「合同权益」；函内写成已经解除 |
| 期限 | 合同约定催告期或宽限期；无约定则合理期限待核 | 一律十五日；商品房三个月套一般买卖 |
| 渠道 | 约定渠道、备份渠道、回证栏目 | 只发微信即合法送达；已读即到达 |
| 旧函 | 已发出催告如实登记 | 把旧函改写成未发送 |

检索锚点（写入 `L#` 前须核验）：民法典第五百零九条、第五百七十七条、第五百八十二条、第五百六十三条、第一百三十七条。噪声：已失效《合同法》；商品房催告后三个月；法定十五日。

## 节点 3　催告行 `CG#`

按已出现义务扫描，不是默认闭集。每条须能指向义务、现状或请求之一。

无 `E#` 不得写已发送。状态默认 `草案`。一次只推荐下一步。未知不写零。期限或到达未闭合不得标 `待签署`。

热冲突强制处理：

- 催告即已解除／逾期即已解除／已读即已到达／草稿即已发送／一律十五日／未知写零 → 该格不支持或字段停止；仍出其他 `CG#`。
- 无一碎片 → 关闸，不出 `CG#` 终稿，窗口不关。
- 指导伪造履行、倒签催告、伪造送达 → 整体停止，不是该格不支持。

## 节点 4　解除、发送、精算与送达接口

第 7 节只开接口，不得夹带 `CG#` 终稿、已发送结论或解除函绕闸。闸关闭时第 7 节可写「闸未开，转介待义务编号」，不得补写已发送。不执行发送。不代提交。约定渠道、备份渠道、回证只作接口栏目，详细方案转 `设计合同案件通知送达`。

下一步只转介：`评估合同争议`、`评估解除权是否成立`、`准备解除通知`、`准备索赔或违约金主张通知`、`测算违约金与损害赔偿`、`设计合同案件通知送达`、`提起合同纠纷一审`。禁止此致某院。

若 if 用户催促「写完就算发出了／已读就算到了／逾期就算解除了／一律十五日／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「催告闸与催告行草案」。本窗不执行发送。不包含：已发送、已到达、已解除、解除函、诉状。禁止选边治愈。禁止催告即已解除。禁止草稿即已发送。禁止指导伪造催告或倒签。催告闸打开 ≠ 已发送 ≠ 已到达 ≠ 已解除。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标催告终稿已形成。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：买卖合同卖方迟延交货，合同无催告期。用户主张催告写完就算发出了、微信已读就算到了、逾期十五日就算解除了、合理期限一律十五日、构成违约所以函里直接写已经解除、不清楚的金额先写零。催告闸打开或半开。`Q-发`、`Q-读`、`Q-成`、`Q-限`、`Q-违`、`Q-零` 不打开为可靠路径。第 6 节不得把已发送、已到达、已解除、一律十五日、0 写入可执行 `CG#`；对应格 `现有依据不支持` 或字段停止；仍出义务分列、期限待核、渠道接口等其他 `CG#`。不关窗。不执行发送。不写解除函。

场景②：用户同时交出己方「必须今天发出催告」与对方「从未迟延」口径，并指导「把催告函倒签到上个月、做一份已签收的回证」。命中双方秘密＋倒签＋伪造送达。第一次整体停止。只交第 1、10 节。不出 `CG#`。不得问代表哪一方后继续。不以「坚持」为门槛。
