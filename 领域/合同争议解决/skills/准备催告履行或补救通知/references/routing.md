# 边界与路由

## 正触发

一般合同已成争，用户仍希望对方履行或补救，本次主成果是催告而不是解除。从零、碎片、期限未核验、无书面催告授权仍正触发：有可编号义务、迟延或瑕疵事实、既有催告或请求切片则闸开或半开，出 `CG#` 草案，保持草案。本次不执行发送、不保证到达、不代提交是交付禁令，不是开窗条件。催告即已解除、已读即已到达、草稿即已发送，仍正触发。

双方秘密、伪造履行、倒签催告、伪造送达、隐匿证据、违法取证的停止，优先于负触发。上述信号不在下表。不执行发送不是负触发。「催告即已解除」「逾期即已解除」「已读即已到达」「草稿即已发送」「一律十五日」不在下表。伪造倒签不在下表，走整体停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 争议总图 | `评估合同争议` |
| 解除权评估（不发函） | `评估解除权是否成立` |
| 发送版解除通知 | `准备解除通知` |
| 索赔通知 | `准备索赔或违约金主张通知` |
| 精算工作表 | `测算违约金与损害赔偿` |
| 独立复杂送达方案 | `设计合同案件通知送达` |
| 完整证据卷 | `建立合同争议证据案卷` |
| 起诉包 | `提起合同纠纷一审` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |
| 工程／金融／房产／海事／劳动主轴 | 对应领域 |

不得因「不执行发送」或「禁止逾期即已解除」关窗。拟催告草稿仍正触发，不得写成已发送或已解除。

## 易混

本窗闸名只能是催告闸，不是解除闸，不是发送闸，不是争议闸。`CG#` 不是解除函，不是诉状。主路径是 `Q-告`，不是 `Q-催`，不是 `Q-函`，不是 `Q-解`。邻窗 `Q-告` 只转介发送前催告草稿，不是已发出。催告草稿不是已发送。已读不是已到达。催告不是已解除。合理期限不是一律十五日。已失效《合同法》不是现行规则。催款函范本里的解除栏不是本窗已解除。「把催告函倒签」整体停止。本窗不执行发送，不代提交。不保证到达。
