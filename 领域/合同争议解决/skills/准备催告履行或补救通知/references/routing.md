# 边界与路由

## 正触发

一般合同已成争，单方仍希望对方履行或补救，本次主成果是发送前催告，而不是解除通知。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 本次主成果是解除通知 | `准备解除通知` |
| 还不能判断能否解除 | `评估解除权是否成立` |
| 只要争议总图 | `评估合同争议` |
| 只要索赔通知或精算 | `准备索赔或违约金主张通知` 或 `测算违约金与损害赔偿` |
| 只要独立、复杂的送达方案 | `设计合同案件通知送达`（本任务仍须填约定渠道＋备份＋回证） |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |
| 已决定起诉或仲裁申请 | `提起合同纠纷一审` 或 `提起合同仲裁` |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，不回改 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项催告规则写入本任务函稿。

## 易混

仍要对方履行或补救时正触发。把催告当解除函、或要求写“逾期即已解除”且解除条件未核验，负触发或删除该句。未成争只改合同，走审查起草并搁置。通知正文在本技能；只做渠道公证和失败升级的独立方案走送达原子，但最低三字段仍在本任务交付。
