# 提起合同成立或效力确认之诉方法

本文件是可执行判断节点。草稿不是已提交。确认之诉不是给付之诉。确认成立不是已生效履行。可撤销不是当然无效。除斥不是时效。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已提交、已立案、已确认成立、已生效履行、选定法院、代提交、未知写零。本任务不定罪，不写发送版起诉状，不把草稿写成已提交。本窗闸名只能是确诉闸，禁止复用起诉闸、成立闸、效力闸、位诉闸、撤诉闸。预留不得占用：立案闸。本窗 `QR#` 是确诉行。主路径只用 `Q-确诉`，禁止用 `Q-诉`、`Q-契`、`Q-签`、`Q-位诉`、`Q-撤诉` 作主路径。本窗 `Q-签` 只作「草稿即已提交或已立案」不关窗码。英文 id 禁止使用，一律用中文技能名 `提起合同成立或效力确认之诉`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991 年民诉第一百二十二条开庭通知、2017 年第一百十九条、已失效合同法第五十二条、把第五百四十一条债权人撤销除斥套本窗第一百五十二条、把人民调解司法确认套本窗时记为噪声。仲裁法（2025 修订）第三十条 MCP 标尚未施行时，以施行日 2026-03-01 为准。禁止指导伪造合同或诉状。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现请求碎片扫描，不是默认闭集。
`QR#` 固定列：`编号｜请求切片｜原告适格与被告明确｜确认利益与给付吸收｜管辖与仲裁独立性｜除斥互斥与证据目录保全红旗｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已提交」或「已立案」。无 `E#` 不得写已提交。确认利益或除斥未闭合不得标 `待提交`。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-确诉`。禁止 `QT#`、`CL#`、`WQ#`、`XQ#`、`QS#`、`A#`、`N#`。

口头「今晚交出去」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：确认对象是法律关系，不是单纯事实关系。给付能吸收则无独立确认必要。撤销是形成之诉，须核第一百五十二条除斥。无效确认不受该除斥限制，但不得把可撤销硬改无效以规避除斥。主合同效力争点不当然消灭仲裁条款。

## 节点 0　分流、立场、确诉闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造合同或诉状、倒签、虚假诉讼不进负表。利益冲突未解不进整体停止。不代提交、不选定法院不是负触发。把草稿写成已提交、把确认之诉写成给付、把可撤销写成当然无效不是负触发。

整案转出只交付第 1、2、10 节，不出 `QR#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是成立效力评估终稿 | 负触发 `评估合同成立与效力` |
| 主成果是普通给付诉状且确认可被吸收 | 负触发 `提起合同纠纷一审` |
| 主成果是债权人撤销起诉材料 | 负触发 `准备债权人撤销权诉讼` |
| 主成果是情势变更变更或解除之诉 | 负触发 `提起情势变更变更或解除之诉` |
| 主成果是确认解除或未解除 | 负触发 `提起合同纠纷一审` 或 `准备对合同解除通知的异议` |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 尚未评估成立效力，只要策略 | 负触发 `评估合同成立与效力` |
| 建设工程／金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不代提交」「不选定法院」 | 交付禁令，不是负触发 |

出现「确认」「无效」「撤销」一词不是转出。

确诉闸打开（可出 `QR#` 草案，仍不得标「已提交／已立案／已确认成立／已生效履行」）须同时满足：单方无冲突立场已闭合；主成果是确认成立、不成立、无效或请求撤销的材料草稿，不是发送版终稿；至少一行可编号原告适格、请求类型或合同碎片。口头「今晚交出去」不算单独开闸材料。

确诉闸部分打开：已有碎片，但确认利益、除斥、仲裁独立性或列法未闭合；对应格待核；仍交十节。无书面授权但单方立场已闭合且已有碎片：确诉闸部分打开，仍交十节，不是整体停止。

确诉闸关闭（仍正触发）：无一可编号碎片。「今天必须出已提交／已立案／已确认终稿」而无最小碎片不得开闸。不出 `QR#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `QR#` 终稿，**第 7 节不得出发送版起诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已提交」「确认之诉即给付之诉」「确认成立即已生效履行」「可撤销即当然无效」「除斥即时效」「除斥届满仍要撤销确认终稿」「有效仲裁仍应直接起诉」「此致某院即管辖已定」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `QR#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 确诉闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造合同或诉状、倒签落款或签署日、虚假诉讼或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个请求切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `QR#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 请求 | 成立／不成立／无效／撤销分列，互斥主位不得叠加 | 确认成立写成已生效履行；可撤销写成当然无效；确认对象写成单纯事实关系 |

## 节点 3　确诉行 `QR#`

按已出现请求碎片扫描，不是默认闭集。每条须能指向确认利益、列法、仲裁独立性、除斥互斥或证据目录之一。

无 `E#` 不得写已提交。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止唯一截止日。确认利益或除斥未闭合不得标 `待提交`。除斥可能届满的撤销请求不得标 `待提交`。成立、不成立、无效、撤销互斥主位不得合成一条已可执行终稿。

热冲突强制处理：

- 草稿即已提交／确认之诉即给付／确认成立即已生效履行／可撤销即当然无效／除斥即时效／除斥届满仍要撤销确认终稿／有效仲裁仍应直接起诉／此致某院即管辖已定／未知写零 → 该格不支持或字段停止；仍出其他 `QR#`。
- 无一碎片 → 关闸，不出 `QR#` 终稿，窗口不关。
- 指导伪造合同、诉状、倒签、虚假诉讼 → 整体停止，不是该格不支持。

## 节点 4　评估、给付、撤诉、保全接口

第 7 节只开接口，不得夹带 `QR#` 终稿或发送版起诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待请求编号」，不得补写已提交。不选定法院。不代提交。不写发送版起诉状。

下一步只转介：`评估合同成立与效力`、`评估合同争议`、`提起合同纠纷一审`、`应对合同纠纷一审`、`评估合同管辖与仲裁协议`、`提起合同仲裁`、`选择诉讼仲裁或督促程序`、`准备债权人撤销权诉讼`、`准备对合同解除通知的异议`、`提起情势变更变更或解除之诉`、`处理解除后返还与清理`、`评估电子合同成立与送达`、`评估争议中的格式条款`、`评估框架协议与订单冲突`、`评估变更是否成立`、`解释争议条款与填补漏洞`、`建立合同争议证据案卷`、`评估争议期间`、`评估合同财产保全必要性`、`准备合同财产保全申请`。禁止此致某院。

若 if 用户催促「今晚交出去／先确认有效再要钱／过了一年还能中断／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「确诉闸与确诉行草案」。本窗不执行发送。不包含：已提交、已立案、已确认成立、已生效履行、发送版起诉状。禁止选边治愈。禁止草稿即已提交。禁止确认之诉即给付。禁止指导伪造。确诉闸打开 ≠ 已提交 ≠ 已立案 ≠ 已确认成立 ≠ 已生效履行。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标确诉终稿已形成。
风险档 A：伪造合同或诉状、倒签、虚假诉讼必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：买卖双方对合同是否成立有争议，用户只要确认有效再另行要货款，草稿此致某中院，主张今晚交出去就算已提交、确认了就算已生效履行、可撤销的也先按无效写、过了一年还能中断、合同无效仲裁就没了、不清楚先写零。确诉闸打开或半开。`Q-签`、`Q-给`、`Q-效`、`Q-撤`、`Q-时`、`Q-仲`、`Q-独`、`Q-院`、`Q-零` 不打开为可靠路径。第 6 节不得把已提交、已生效履行、当然无效、除斥可中断、0、此致某院写入可执行 `QR#`；对应格 `现有依据不支持` 或字段停止；仍出请求分列、确认利益与给付吸收缺口、仲裁独立性待核、除斥一年九十日五年并行等其他 `QR#`。不关窗。不代提交。不写发送版。

场景②：用户同时交出己方「签署日改到上周、空白页先补一章」与对方「从未成立」口径，并要「先立案再说」。命中双方秘密＋倒签＋伪造。第一次整体停止。只交第 1、10 节。不出 `QR#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代违法方案。
