# 边界与路由

## 正触发

需法院或仲裁确认合同成立、不成立、无效或撤销。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 成立效力评估 | `评估合同成立与效力` |
| 普通给付一审 | `提起合同纠纷一审` |
| 情势变更之诉 | `提起情势变更变更或解除之诉` |
| 撤销权诉讼 | `准备债权人撤销权诉讼` |
| 仲裁申请 | `提起合同仲裁` |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，只分流不回改 |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

需要单独确认有没有合同、是否无效或撤销时正触发。只要要钱且确认可吸收时转普通起诉。情势变更改合同转情势之诉。
