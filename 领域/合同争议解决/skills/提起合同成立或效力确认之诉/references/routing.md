# 边界与路由

## 正触发

需法院或仲裁确认合同成立、不成立、无效或请求撤销，需要材料草稿。从零、碎片、确认利益未核验、无书面授权仍正触发：有可编号原告适格、请求类型或合同碎片则闸开或半开，出 `QR#` 草案，保持草案。本次不代提交、不选定法院是交付禁令，不是开窗条件。草稿即已提交、确认之诉即给付之诉、确认成立即已生效履行，仍正触发。把可撤销写成当然无效、把除斥写成时效、把除斥届满仍写成可提交撤销终稿，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造合同或诉状、倒签、虚假诉讼的停止，优先于负触发。上述信号不在下表。不代提交不是负触发。「草稿即已提交」「确认之诉即给付之诉」「确认成立即已生效履行」「可撤销即当然无效」「除斥即时效」「除斥届满仍要撤销确认终稿」「有效仲裁仍应直接起诉」「此致某院即管辖已定」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 成立效力评估终稿 | `评估合同成立与效力` |
| 普通给付诉状且确认可被吸收 | `提起合同纠纷一审` |
| 债权人撤销起诉材料 | `准备债权人撤销权诉讼` |
| 情势变更变更或解除之诉 | `提起情势变更变更或解除之诉` |
| 确认解除或未解除 | `提起合同纠纷一审` 或 `准备对合同解除通知的异议` |
| 争议总图 | `评估合同争议` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |
| 尚未评估成立效力，只要策略 | `评估合同成立与效力` |

不得因「不代提交」或「不选定法院」关窗。拟确认草稿仍正触发，不得写成已提交或已立案。

## 易混

本窗闸名只能是确诉闸，不是起诉闸，不是成立闸，不是效力闸，不是位诉闸，不是撤诉闸。`QR#` 不是 `QT#`，不是 `CL#`，不是 `WQ#`，不是 `XQ#`，不是 `QS#`。主路径是 `Q-确诉`，不是 `Q-诉`，不是 `Q-契`，不是 `Q-认`，不是 `Q-确`。`成立闸`／`Q-契` 是评估合同成立与效力。`起诉闸`／`QT#`／`Q-诉` 是提起合同纠纷一审。`撤诉闸`／`XQ#`／`Q-撤诉` 是准备债权人撤销权诉讼。`QS#` 是企业合规诉材行。草稿不是已提交。确认之诉不是给付之诉。确认成立不是已生效履行。可撤销不是当然无效。除斥不是时效。主合同无效不是仲裁条款消灭。MCP 查询第一百二十二条可能先返回 1991 年开庭通知条，须核 2023 修正起诉条件。2017 年第一百十九条不是现行。已失效合同法第五十二条不是现行。第五百四十一条不是本窗除斥。仲裁法（2025 修订）第三十条施行日 2026-03-01，MCP 标尚未施行时以施行日为准。「今晚交出去」「签署日改到上周」整体停止。本窗不执行发送，不代提交。不选定法院。不写发送版起诉状。
