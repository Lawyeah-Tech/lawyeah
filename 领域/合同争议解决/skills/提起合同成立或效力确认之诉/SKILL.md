# 提起合同成立或效力确认之诉

## 任务目标

在明确、无利益冲突的单方立场下（主张成立或不成立一方、主张有效或无效一方、请求撤销一方或其受托律师，互斥），形成确认之诉或撤销形成之诉材料草稿：确诉闸、主体与强制接口、`Q#` 路径、`QR#` 确诉行（请求切片／原告适格与被告明确／确认利益与给付吸收／管辖与仲裁独立性／除斥互斥与证据目录保全红旗／`E#` 回链）。本窗 `QR#` 是确诉行草案，不是已提交证明，不是已立案，不是已确认成立，不是已生效履行，不是发送版起诉状。本窗闸名只能是确诉闸，禁止复用起诉闸、立案闸、成立闸、效力闸、诉材闸、位诉闸、撤诉闸、答辩闸。预留不得占用：立案闸。本窗主行只能是 `QR#`，禁止 `QT#`、`CL#`、`WQ#`、`XQ#`、`QS#`、`XL#`、`A#`。主路径只用 `Q-确诉`，禁止用 `Q-诉`、`Q-契`、`Q-立`、`Q-成`、`Q-效`、`Q-认`、`Q-确`、`Q-签`、`Q-位诉`、`Q-撤诉` 作主路径。邻窗 `Q-确诉` 只作转介进本窗；本窗打开为主路径，不是已提交、不是已立案、不是已确认、不是应起诉。本窗 `Q-契` 只转介 `评估合同成立与效力`。本窗 `Q-诉` 只转介 `提起合同纠纷一审`。本窗 `Q-签` 只作「草稿即已提交或已立案」不关窗码。确诉闸打开不等于已提交不等于已立案不等于已确认成立不等于已生效履行不等于应起诉不等于管辖已定不等于待提交终稿。草稿不是已提交。网交不是已提交。确认之诉不是给付之诉。确认成立不是已生效履行。可撤销不是当然无效。除斥不是时效。有效仲裁协议不是应起诉。主合同无效不是仲裁条款消灭。给付可吸收不是仍须独立确认终稿。此致某院不是管辖已定。未知不写零。不代提交。不选定法院。不定罪。不保证受理。伤残等级与本窗无关，禁止折入。

`depends-on` 为空。主成果是成立效力评估终稿转 `评估合同成立与效力`。主成果是普通给付诉状转 `提起合同纠纷一审`。主成果是债权人撤销起诉材料转 `准备债权人撤销权诉讼`。主成果是情势变更之诉转 `提起情势变更变更或解除之诉`。主成果是确认解除或未解除转 `提起合同纠纷一审` 或 `准备对合同解除通知的异议`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：需法院或仲裁确认合同成立、不成立、无效或请求撤销，需要材料草稿。「今晚交出去」「先确认有效再要钱」「过了一年还能中断」仍正触发，成果状态 `草案`。确认利益、除斥、仲裁独立性未核验仍正触发：有可编号原告适格、请求类型或合同碎片则确诉闸打开或半开，第 6 节出 `QR#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出已提交／已立案／已确认终稿」才关闸，仍交十节，第 6 节不出 `QR#` 终稿，第 7 节不得出发送版起诉状，窗口不关。用户要把草稿写成已提交、把确认之诉写成给付之诉、把确认成立写成已生效履行、把可撤销写成当然无效、把除斥写成时效、把除斥可能届满仍写成可提交撤销终稿、把有效仲裁写成仍应直接起诉、把此致某院写成管辖已定、把未知写成零，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `QR#` 草案。不得因「不代提交」「不选定法院」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是成立效力评估终稿（转 `评估合同成立与效力`）；
- 主成果是普通给付诉状且确认可被吸收（转 `提起合同纠纷一审`）；
- 主成果是债权人撤销起诉材料（转 `准备债权人撤销权诉讼`）；
- 主成果是情势变更变更或解除之诉（转 `提起情势变更变更或解除之诉`）；
- 主成果是确认解除或未解除（转 `提起合同纠纷一审` 或 `准备对合同解除通知的异议`）；
- 主成果是争议总图（转 `评估合同争议`）；
- 尚未成争，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）；
- 尚未评估成立效力、只要策略。

双方秘密、伪造合同或诉状、倒签落款或签署日、虚假诉讼、违法取证**不在负触发表**，走整体停止。「草稿即已提交」「确认之诉即给付之诉」「确认成立即已生效履行」「可撤销即当然无效」「除斥即时效」「除斥届满仍要撤销确认终稿」「有效仲裁仍应直接起诉」「此致某院即管辖已定」「未知写零」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不代提交」「不选定法院」是交付禁令，不是负触发。主成果才转；出现「确认」「无效」「撤销」一词不是转出。

## 建立工作坐标

确认：起诉或申请仲裁授权；单方立场；合同文本或成立过程碎片；请求类型（成立／不成立／无效／撤销）；确认利益或给付吸收；仲裁条款；除斥碎片；法域。

口头「今晚交出去」「先确认有效再要钱」「过了一年还能中断」只登记 `S#`／`V#`。不得升格已提交、已立案、已确认成立或已生效履行，**不得单独算作开闸材料**。可编号原告适格、请求类型或合同碎片可开闸。本窗不执行发送，不代提交，不选定法院。

立场只许主张成立或不成立一方、主张有效或无效一方、请求撤销一方或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：确诉闸关闭，仍交十节，不是整体停止。无书面授权但单方立场已闭合、且已有碎片：确诉闸部分打开，仍交十节，不是整体停止。提出伪造合同或诉状、倒签落款或签署日、虚假诉讼或违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`QR#` 确诉行；`V#` 版本；`E#` 证据形态回链（合同文本、成立过程、授权、除斥起算，不是发送闸，不是已提交证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`QT#`、`CL#`、`WQ#`、`XQ#`、`QS#`。技能正文中的条号是检索锚点，不是已核验 `L#`。文件状态只用 `草案`、`待提交`、`停止`。确认利益、列法、除斥或仲裁独立性未闭合不得标 `待提交`。除斥可能届满的撤销请求不得标 `待提交`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。未知不写零。草稿 ≠ 已提交。确认之诉 ≠ 给付之诉。确认成立 ≠ 已生效履行。可撤销 ≠ 当然无效。除斥 ≠ 时效。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或文书范本检索。本窗是确认之诉或撤销形成之诉材料草稿，范本只借民事起诉状栏目，**不要**升格「已提交／已立案／已确认成立／已生效履行／管辖已定」，**不要**用类案写成必然受理。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现草稿即已提交、确认之诉即给付之诉、确认成立即已生效履行、可撤销即当然无效、除斥即时效、有效仲裁仍应直接起诉、此致某院即管辖已定的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效合同法第五十二条、解释（一）、2017 年民诉第一百十九条、1991 年第一百二十二条开庭通知当作现行。不得把第五百四十一条债权人撤销除斥套本窗意思表示撤销。MCP 查询第一百二十二条可能先返回 1991 年开庭通知条，须核 2023 修正起诉条件。仲裁法（2025 修订）第三十条 MCP 可能标尚未施行，施行日 2026-03-01，今日已施行，以施行日为准。MCP 效力字段与公布施行日冲突时，以施行日为准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的确认利益、除斥、管辖、仲裁独立性保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变确认利益、除斥、互斥或仲裁独立性的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补草稿不是已提交、确认之诉不是给付之诉、确认成立不是已生效履行、可撤销不是当然无效、除斥不是时效、有效仲裁不是应起诉、主合同无效不是仲裁消灭、此致某院不是管辖已定的实务反例。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、确诉闸与不关窗

主成果才整案转出。双方秘密、伪造合同或诉状、倒签、虚假诉讼第一次停。草稿即已提交、确认之诉即给付、可撤销即当然无效不关窗。闸关仍交十节，第 6 节不出 `QR#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

原告适格、明确被告、确认利益或给付吸收、仲裁独立性、除斥与请求互斥分列。本节禁止出 `QR#` 终稿。

### 3. 确诉闸与路径 `Q#`

本节禁止出 `QR#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-确诉`。

### 4. 确诉行 `QR#`

请求切片、原告适格与被告明确、确认利益与给付吸收、管辖与仲裁独立性、除斥互斥与证据目录。状态 `草案`。禁止升格已提交、已立案、已确认成立、已生效履行。无 `E#` 不得写已提交。确认利益或除斥未闭合不得标 `待提交`。

### 5. 评估、给付、撤诉、保全接口

成立效力评估转成立闸窗。给付可吸收转一审窗。债权人撤销转撤诉窗。保全只开接口。第 7 节不得夹带 `QR#` 终稿或发送版起诉状绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造合同或诉状、倒签落款或签署日、虚假诉讼或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：确诉闸关闭，仍交十节，不是整体停止。无书面授权但有碎片：确诉闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：确认利益、管辖、除斥、仲裁独立性、施行日未核验。草稿即已提交、确认之诉即给付之诉、确认成立即已生效履行、可撤销即当然无效、除斥即时效、除斥届满仍要撤销确认终稿、有效仲裁仍应直接起诉、此致某院即管辖已定、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `QR#` 草案。
- `目标停止`：主目标变为普通给付诉状、债权人撤销起诉材料、情势变更之诉或成立效力评估终稿。禁止把「除斥届满仍要撤销确认终稿」或「确认之诉即给付之诉」当作用户错误主张时的目标停止；那是不关窗。

禁止指导伪造合同或诉状。不给胜诉率。不定罪。不选定法院。不代提交。未知不写零。不写发送版起诉状。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。确诉闸关闭仍交十节，第 6 节不出 `QR#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `QR#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。确诉闸未打开时不得交付「已提交」或「已立案」。边界见 [路由](references/routing.md)。
