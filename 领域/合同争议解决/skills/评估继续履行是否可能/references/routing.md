# 边界与路由

## 正触发

请求继续履行或主张法律上、事实上不能继续履行。从零、碎片、切开未核验、无书面授权仍正触发：有可编号义务切片或履行障碍碎片则闸开或半开，出 `LN#` 草案，保持草案。本次不强制实际履行、不写执行方案是交付禁令，不是开窗条件。金钱之债免付、商业不愿即费用过高，仍正触发。把除外写成当然免赔偿、把起诉当日写成终止时点，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造不能证明、倒签的停止，优先于负触发。上述信号不在下表。不强制实际履行不是负触发。「金钱之债因不能免付」「商业不愿即费用过高」「除外即免赔偿」「起诉当日或立案日即终止」「评估即已可强制」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 变故评估终稿 | `评估不可抗力情势变更与履行不能` |
| 解除权实体终稿 | `评估解除权是否成立` |
| 清理方案 | `处理解除后返还与清理` |
| 催告履行 | `准备催告履行或补救通知` |
| 发送版解除通知 | `准备解除通知` |
| 争议总图 | `评估合同争议` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不强制实际履行」或「不写执行方案」关窗。拟续履行评估仍正触发，不得写成已可强制或免付款。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流。出现「继续履行」「不能履行」一词不是转出。C 端只要大众履行填空页时只分流，不把本包降成填空式结论，不回改。

## 易混

本窗闸名只能是履能闸，不是不能闸，不是续履闸，不是履行闸，不是履抗闸，不是变故闸，不是清理闸。`LN#` 不是 `WG#`，不是 `QL#`，不是 `LK#`，不是 `JC#`，不是 `NL#`。主路径是 `Q-履`，不是 `Q-故`，不是 `Q-理`，不是 `Q-抗`，不是 `Q-力`。`变故闸`／`Q-故` 是评估不可抗力情势变更与履行不能。`履抗闸`／`Q-抗` 是评估同时履行先履行与不安抗辩。`Q-力` 是和解窗执行力补强。金钱债务原则上不能因履行不能免付款。商业不愿继续不是履行费用过高。第五百八十条终止不是通知解除。已失效合同法第一百十条、第一百十一条不是现行。MCP 可能先返回通则解释第五十九条而漏第五百八十条正文。「请求履行日改到去年」「替代报价先造一份」整体停止。本窗不执行发送，不代提交。不选定法院。不写强制执行方案。不写解除函。不写诉状。
