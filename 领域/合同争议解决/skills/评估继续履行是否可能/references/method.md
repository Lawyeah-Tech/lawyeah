# 评估继续履行是否可能方法

本文件是可执行判断节点。金钱债务原则上不能因履行不能免付款。商业不愿继续不是履行费用过高。除外成立不当然免赔偿。第五百八十条终止不是通知解除。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已可强制、已终止、已免付、选定法院、代提交、未知写零。本任务不定罪，不写强制执行方案，不写解除函。本窗闸名只能是履能闸，禁止复用不能闸、续履闸、履行闸、履抗闸、变故闸、清理闸。预留不得占用：立案闸、和解闸。本窗 `LN#` 是履能行。主路径只用 `Q-履`，禁止用 `Q-故`、`Q-理`、`Q-抗`、`Q-除`、`Q-力`、`Q-签` 作主路径。本窗 `Q-签` 只作「评估即已可强制、已终止或已提交」不关窗码。英文 id 禁止使用，一律用中文技能名 `评估继续履行是否可能`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效合同法第一百十条、第一百十一条、把通则解释第五十九条当主条而漏第五百八十条时记为噪声。禁止指导伪造不能证明。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现义务碎片扫描，不是默认闭集。
`LN#` 固定列：`编号｜义务切片｜金钱非金钱与债务性质｜法律上或事实上不能｜不适于强制费用过高与合理期限｜替代履行与终止解除赔偿分流｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已可强制」或「已终止」。无 `E#` 不得写已可强制。切开或除外未闭合不得标 `待提交`。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-履`。禁止 `WG#`、`QL#`、`LK#`、`JC#`、`JS#`、`DJ#`、`A#`、`N#`。

口头「尾款因不能履行不用付」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：金钱债务走第五百七十九条，原则上可请求支付。非金钱才进第五百八十条除外。除外致目的不能才可请求终止，不影响违约责任。终止一般以起诉状副本送达为准。

## 节点 0　分流、立场、履能闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造不能证明、倒签不进负表。利益冲突未解不进整体停止。不强制实际履行、不写执行方案不是负触发。把金钱债务写成免付款、把商业不愿写成费用过高不是负触发。

整案转出只交付第 1、2、10 节，不出 `LN#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是变故评估终稿 | 负触发 `评估不可抗力情势变更与履行不能` |
| 主成果是解除权实体终稿 | 负触发 `评估解除权是否成立` |
| 主成果是清理方案 | 负触发 `处理解除后返还与清理` |
| 主成果是催告履行 | 负触发 `准备催告履行或补救通知` |
| 主成果是发送版解除通知 | 负触发 `准备解除通知` |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 要求强制对方立即实际履行的实施方案 | 交付禁令，不是负触发；不写执行方案 |
| 建设工程／金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不强制实际履行」「不写执行方案」「不发函」 | 交付禁令，不是负触发 |

出现「继续履行」「不能履行」一词不是转出。

履能闸打开（可出 `LN#` 草案，仍不得标「已可强制／已终止／已免付」）须同时满足：单方无冲突立场已闭合；主成果是续履行评估，不是执行方案、不是解除函；至少一行可编号义务切片或履行障碍碎片。口头「尾款因不能履行不用付」不算单独开闸材料。

履能闸部分打开：已有碎片，但切开或除外未闭合；对应格待核；仍交十节。无书面授权但单方立场已闭合且已有碎片：履能闸部分打开，仍交十节，不是整体停止。

履能闸关闭（仍正触发）：无一可编号碎片。「今天必须出已可强制／免付款终稿」而无最小碎片不得开闸。不出 `LN#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `LN#` 终稿，**第 7 节不得出强制实施方案、解除函或诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「金钱之债因不能免付」「商业不愿即费用过高」「除外即免赔偿」「起诉当日或立案日即终止」「评估即已可强制」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `LN#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 履能闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造不能证明、倒签请求履行日或终止时点、隐匿可替代履行或费用对照或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 3　履能行 `LN#`

按已出现义务碎片扫描，不是默认闭集。每条须能指向金钱非金钱切开、除外三项、替代履行或终止分流之一。

无 `E#` 不得写已可强制。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止唯一必得替代费用。切开或除外未闭合不得标 `待提交`。

热冲突强制处理：

- 金钱之债免付／商业不愿即费用过高／除外即免赔偿／起诉当日即终止／评估即已可强制／未知写零 → 该格不支持或字段停止；仍出其他 `LN#`。
- 无一碎片 → 关闸，不出 `LN#` 终稿，窗口不关。
- 指导伪造不能证明、倒签、隐匿替代 → 整体停止，不是该格不支持。

## 节点 4　变故、解除、催告、测算、清理接口

第 7 节只开接口，不得夹带 `LN#` 终稿或强制执行方案绕闸。闸关闭时第 7 节可写「闸未开，转介待义务编号」，不得补写已可强制。不选定法院。不代提交。不写执行方案。不写解除函。

下一步只转介：`评估合同争议`、`评估不可抗力情势变更与履行不能`、`评估同时履行先履行与不安抗辩`、`评估迟延拒绝与不完全履行`、`评估解除权是否成立`、`评估质量瑕疵与检验期间`、`准备催告履行或补救通知`、`准备解除通知`、`建立双向履行时间线`、`测算违约金与损害赔偿`、`评估争议期间`、`建立合同争议证据案卷`、`处理解除后返还与清理`、`提起情势变更变更或解除之诉`、`提起合同纠纷一审`、`谈判合同和解方案`、`设计合同案件通知送达`。禁止此致某院。

若 if 用户催促「尾款因不能履行不用付／亏本就算费用过高／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「履能闸与履能行草案」。本窗不执行发送。不包含：已可强制、已终止、已免付、强制执行方案、解除函。禁止选边治愈。禁止金钱之债免付。禁止商业不愿即费用过高。禁止指导伪造。履能闸打开 ≠ 已可强制 ≠ 已终止 ≠ 已免赔偿。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标评估终稿已形成。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：卖方交付设备，买方主张尾款因履行不能不用付，亏本就是费用过高，除外成立就不用赔，今天起诉就算合同终止，不清楚先写零。履能闸打开或半开。`Q-金`、`Q-商`、`Q-免`、`Q-拟`、`Q-零` 不打开为可靠路径。第 6 节不得把免付款、费用过高已成立、免赔偿、起诉当日终止、0 写入可执行 `LN#`；对应格 `现有依据不支持` 或字段停止；仍出金钱非金钱切开、除外三项分列、终止时点待核、赔偿并存等其他 `LN#`。不关窗。不写执行方案。不写解除函。

场景②：用户同时交出己方「请求履行日改到去年、替代报价先造一份」与对方「随时可以交货」口径，并要「先按已不能履行写」。命中双方秘密＋倒签＋伪造。第一次整体停止。只交第 1、10 节。不出 `LN#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代违法方案。
