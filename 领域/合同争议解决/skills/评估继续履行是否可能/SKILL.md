# 评估继续履行是否可能

## 任务目标

在明确、无利益冲突的单方立场下（请求继续履行或主张法律上、事实上不能一方或其受托律师，互斥），形成续履行评估草案：履能闸、主体与强制接口、`Q#` 路径、`LN#` 履能行（义务切片／金钱非金钱与债务性质／法律上或事实上不能／不适于强制费用过高与合理期限／替代履行与终止解除赔偿分流／`E#` 回链）。本窗 `LN#` 是履能行草案，不是已可强制证明，不是已终止，不是已免赔偿，不是强制执行方案，不是解除函，不是诉状。本窗闸名只能是履能闸，禁止复用不能闸、续履闸、履行闸、履抗闸、变故闸、清理闸、解除闸、强制闸。预留不得占用：立案闸、和解闸。本窗主行只能是 `LN#`，禁止 `WG#`、`QL#`、`LK#`、`JC#`、`NL#`、`JS#`、`DJ#`、`A#`。主路径只用 `Q-履`，禁止用 `Q-故`、`Q-理`、`Q-抗`、`Q-除`、`Q-力`、`Q-能`、`Q-签` 作主路径。邻窗 `Q-履` 只作转介进本窗；本窗打开为主路径，不是已可强制、不是已终止、不是已免责。本窗 `Q-故` 只转介 `评估不可抗力情势变更与履行不能`。本窗 `Q-除` 只转介 `评估解除权是否成立`。本窗 `Q-理` 只转介 `处理解除后返还与清理`。本窗 `Q-签` 只作「评估即已可强制、已终止或已提交」不关窗码。履能闸打开不等于已可强制继续履行不等于法律不能终局不等于第五百八十条已终止不等于已免赔偿不等于替代费用已确定不等于待提交终稿。金钱债务原则上不能因履行不能免付款。商业不愿继续不是履行费用过高。除外一项成立排除强制继续履行，不当然免赔偿。第五百八十条终止不是通知解除。终止时点不是立案日、不是起诉当日。未知不写零。不强制对方实际履行。不写强制执行实施方案。不写解除函。不写诉状。不选定法院。不代提交。不定罪。伤残等级与本窗无关，禁止折入。

`depends-on` 为空。主成果是变故评估终稿转 `评估不可抗力情势变更与履行不能`。主成果是解除权实体终稿转 `评估解除权是否成立`。主成果是清理方案转 `处理解除后返还与清理`。主成果是催告履行转 `准备催告履行或补救通知`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：请求继续履行或主张法律上、事实上不能继续履行。「尾款因不能履行不用付」「亏本就算费用过高」仍正触发，成果状态 `草案`。金钱非金钱切开、除外三项未核验仍正触发：有可编号义务切片或履行障碍碎片则履能闸打开或半开，第 6 节出 `LN#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出已可强制／已终止／免付款终稿」才关闸，仍交十节，第 6 节不出 `LN#` 终稿，第 7 节不得出强制实施方案、解除函或诉状，窗口不关。用户要把金钱债务写成免付款、把商业不愿继续写成费用过高、把除外写成当然免赔偿、把起诉当日写成终止时点、把评估写成已可强制或已出执行方案、把未知写成零，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `LN#` 草案。不得因「不强制实际履行」「不写执行方案」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是变故评估终稿（转 `评估不可抗力情势变更与履行不能`）；
- 主成果是解除权实体终稿（转 `评估解除权是否成立`）；
- 主成果是清理方案（转 `处理解除后返还与清理`）；
- 主成果是催告履行（转 `准备催告履行或补救通知`）；
- 主成果是发送版解除通知（转 `准备解除通知`）；
- 主成果是争议总图（转 `评估合同争议`）；
- 尚未成争，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）；
- 要求强制对方立即实际履行的实施方案。

双方秘密、伪造不能证明、倒签请求履行日或终止时点、隐匿可替代履行或费用对照、违法取证**不在负触发表**，走整体停止。「金钱之债因不能免付」「商业不愿即费用过高」「除外即免赔偿」「起诉当日或立案日即终止」「评估即已可强制」「未知写零」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不强制对方实际履行」「不写执行方案」「不发函」是交付禁令，不是负触发。主成果才转；出现「继续履行」「不能履行」一词不是转出。

## 建立工作坐标

确认：评估授权；单方立场；义务性质（金钱／非金钱）；除外三项碎片；替代履行费用；终止请求；法域。

口头「尾款因不能履行不用付」「亏本就算费用过高」只登记 `S#`／`V#`。不得升格已可强制、已终止、已免付或法律不能终局，**不得单独算作开闸材料**。可编号义务切片或履行障碍碎片可开闸。本窗不执行发送，不代提交，不写强制执行方案，不写解除函，不选定法院。

立场只许请求继续履行或主张法律上、事实上不能一方或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：履能闸关闭，仍交十节，不是整体停止。无书面授权但单方立场已闭合、且已有碎片：履能闸部分打开，仍交十节，不是整体停止。提出伪造不能证明、倒签请求履行日或终止时点、隐匿可替代履行或费用对照或违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`LN#` 履能行；`V#` 版本；`E#` 证据形态回链（义务文本、不能证明、费用对照、请求履行日、授权，不是发送闸，不是已可强制证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`WG#`、`QL#`、`LK#`、`JC#`、`JS#`、`DJ#`。技能正文中的条号是检索锚点，不是已核验 `L#`。文件状态只用 `草案`、`待提交`、`停止`。金钱非金钱切开或除外未闭合不得标 `待提交`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。未知不写零。金钱之债 ≠ 免付款。商业不愿 ≠ 费用过高。除外 ≠ 免赔偿。起诉当日 ≠ 终止时点。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或裁判案例检索。本窗是评估，**不要**用 `search_template` 生成强制执行方案、终止证明、替代报价或诉状，**不要**用类案写成必然已可强制或已终止。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现金钱之债免付、商业不愿即费用过高、除外即免赔偿、起诉当日即终止的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效合同法第一百十条、第一百十一条、第一百零七条当作现行。MCP 可能先返回通则解释第五十九条或第五百九十条而漏第五百八十条、第五百八十一条正文，须核主条。MCP 效力字段与公布施行日冲突时，以施行日为准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的金钱非金钱切开、除外三项、终止时点或替代费用保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民法典第五百七十九条金钱债务可请求支付。第五百七十七条继续履行、补救、赔偿并存，不是当然解除。第五百八十条非金钱债务可请求履行，除外：法律上或者事实上不能履行、标的不适于强制履行或者履行费用过高、债权人在合理期限内未请求履行；有除外致使不能实现合同目的的，可请求人民法院或仲裁机构终止权利义务关系，不影响违约责任。第五百八十一条依性质不得强制履行的，可请求负担第三人替代履行的费用。第五百八十五条第三款迟延违约金支付后仍应当履行债务。通则解释第五十九条终止一般以起诉状副本送达对方的时间为准，不是立案日、不是起诉当日。噪声：已失效合同法第一百十条、第一百十一条；金钱之债免付；商业不愿即费用过高；除外即免赔偿。技能正文条号不是 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变金钱非金钱切开、除外三项、终止时点或替代费用的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补金钱债务原则上不能免付款、商业不愿继续不是费用过高、人身性服务通常不适于强制、除外不是当然免赔偿、终止不是通知解除、起诉当日不是终止时点的实务反例。
- `search_case_by_fact` 只比较事实差异与翻转条件：金钱之债不是免付款；亏本不是费用过高；除外不是免责；合理期限未请求不是当然消灭全部救济；起诉当日不是终止。无类案不得写成已可强制、已终止或已替代终稿。评估类禁止用 `search_template` 生成强制执行方案、解除函、终止证明或诉状。

工具不可用时继续义务碎片和 `LN#` 编目；已可强制、已终止、免付款字段停止。不得拒跑，不得凭记忆写成已可强制或免付款。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、履能闸与不关窗

主成果才整案转出。双方秘密、伪造不能证明、倒签第一次停。金钱之债免付、商业不愿即费用过高不关窗。闸关仍交十节，第 6 节不出 `LN#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

金钱／非金钱切开。除外三项、替代费用、终止时点分列。本节禁止出 `LN#` 终稿。

### 3. 履能闸与路径 `Q#`

本节禁止出 `LN#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-履`。

### 4. 履能行 `LN#`

义务切片、金钱非金钱、除外三项、替代履行与终止分流。状态 `草案`。禁止升格已可强制、已终止、已免付。无 `E#` 不得写已可强制。切开或除外未闭合不得标 `待提交`。

### 5. 变故、解除、催告、测算、清理接口

变故转变故窗。解除转解除窗。催告转催告窗。第 7 节不得夹带 `LN#` 终稿或强制执行方案绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造不能证明、倒签请求履行日或终止时点、隐匿可替代履行或费用对照或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：履能闸关闭，仍交十节，不是整体停止。无书面授权但有碎片：履能闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：金钱非金钱切开、除外三项、终止时点、替代费用、施行日未核验。金钱之债免付、商业不愿即费用过高、除外即免赔偿、起诉当日或立案日即终止、评估即已可强制、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `LN#` 草案。
- `目标停止`：主目标变为强制执行实施方案、变故评估终稿或解除函。禁止把「金钱之债免付」或「商业不愿即费用过高」当作用户错误主张时的目标停止；那是不关窗。

禁止指导伪造不能证明。不给胜诉率。不定罪。不选定法院。不代提交。未知不写零。不写强制执行方案。不写解除函。不写诉状。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。履能闸关闭仍交十节，第 6 节不出 `LN#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `LN#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。履能闸未打开时不得交付「已可强制」或「已终止」。边界见 [路由](references/routing.md)。
