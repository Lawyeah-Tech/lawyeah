# 应对合同仲裁方法

本文件是可执行判断节点。草稿不是已答辩。已读不是已送达。未提交答辩书不是当然败诉。应裁不是放弃协议异议。民诉十五日不是本窗截止。第三十七条不是仲裁庭异议截止。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已答辩、已放弃、当然败诉、选定机构、代提交、未知写零。本任务不定罪，不执行发送，不把草稿写成已答辩。本窗闸名只能是应裁闸，禁止复用答辩闸、应诉闸、应对闸、仲裁闸、仲异闸、开庭闸、撤裁闸、不执闸。预留不得占用：立案闸、保全闸。本窗 `YC#` 是应裁行。主路径只用 `Q-应裁`，禁止用 `Q-辩`、`Q-应`、`Q-申`、`Q-开庭`、`Q-仲异`、`Q-签` 作主路径。本窗 `Q-签` 只作「草稿即已提交或已答辩」不关窗码。本窗 `Q-弃` 只作「应裁或实体答辩即已放弃协议异议」不关窗码。英文 id 禁止使用，一律用中文技能名 `应对合同仲裁`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1994 年第三十一条选定仲裁员、第三十六条回避决定、第三十七条重新选定仲裁员、第三十八条除名、1994 年或 2017 年第二十条／第二十五条／第二十六条／第二十七条未核对应、民诉第一百二十八条十五日或第一百三十条应诉管辖套本窗、MCP 标 2025 修订尚未施行而未以施行日为准、把草稿写成已答辩或把应裁写成放弃异议时记为噪声。禁止指导隐匿证据、伪造答辩或倒签送达。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现被申请碎片扫描，不是默认闭集。
`YC#` 固定列：`编号｜请求切片｜送达与期限接口｜协议异议接口｜实体抗辩｜反请求接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已答辩」或「已放弃」。无 `E#` 不得写已答辩。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-应裁`。禁止 `DB#`、`ZC#`、`ZX#`、`KT#`、`HC#`、`BZ#`、`A#`、`N#`。期限嵌在送达与期限接口：作出日／送达日／该机构规则答辩期／反请求期／组庭与开庭通知分列，禁止一张截止卡，禁止另开 `K#` 为主行。协议异议嵌首次开庭前／单独递交／第三十一条，禁止把第三十七条写成仲裁庭截止。

口头「已经被裁了」「微信已读就算送达」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：承认、否认、不知、抗辩分列。协议异议与实体抗辩可并列，异议须单独递交。应裁本身不等于放弃。不利证据必须进入最强反方，不得从草稿中删除。答辩期、反请求期按该机构现行规则核验，禁止用民诉十五日或某一会规则写成全国唯一截止。

## 节点 0　分流、立场、应裁闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、用申请方未授权秘密、伪造或倒签答辩或送达回证、隐匿证据、虚假陈述、违法取证不进负表。利益冲突未解不进整体停止。不代提交、不出反请求终稿、不出仲异终稿不是负触发。

整案转出只交付第 1、2、10 节，不出 `YC#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是申请包 | 负触发 `提起合同仲裁` |
| 主成果是一审应诉 | 负触发 `应对合同纠纷一审` |
| 主成果是管辖或仲裁效力评估终稿 | 负触发 `评估合同管辖与仲裁协议` |
| 只要协议异议终稿且拒绝任何实体抗辩 | 负触发 `准备合同仲裁协议异议材料` |
| 主成果是反请求条件专项 | 负触发 `评估合同反诉或反请求` |
| 主成果是反请求文书终稿 | 负触发 `准备合同反诉或仲裁反请求` |
| 主成果是已过首次应裁的庭审提纲 | 负触发 `准备合同案件庭审` |
| 主成果是保全复议或担保置换 | 负触发 `应对合同案件保全裁定` |
| 主成果是证据案卷终稿 | 负触发 `建立合同争议证据案卷` |
| 主成果是举证期限计划 | 负触发 `规划举证期限与证据交换` |
| 主成果是和解方案 | 负触发 `谈判合同和解方案` |
| 主成果是撤裁申请 | 负触发 `申请撤销仲裁裁决` |
| 主成果是不予执行申请 | 负触发 `申请不予执行仲裁裁决` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程／金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不代提交」「不出反请求终稿」「不出仲异终稿」 | 交付禁令，不是负触发 |

出现「应裁」「答辩」「异议」「仲裁」一词不是转出。同时要应裁草稿和异议红旗：本窗正触发。只要仲异终稿且拒实体才负触发。

应裁闸打开（可出 `YC#` 草案，仍不得标「已答辩／已提交／已送达／已放弃」）须同时满足：单方无冲突被申请立场已闭合；主成果是首次应裁草稿，不是申请包、不是一审答辩、不是仲异唯一成果、不是反请求终稿、不是庭审提纲；至少一项可编号申请书副本、受理或答辩通知、组庭或开庭通知或案号碎片。口头「已经被裁了」不算单独开闸材料。PDF 可半开，不得单独起算答辩期或首次开庭前。

应裁闸部分打开：已有碎片，但送达日、该机构规则或首次开庭前未闭合；对应格待核；仍交十节。无书面应裁授权但单方立场已闭合且已有碎片：应裁闸部分打开，仍交十节，不是整体停止。

应裁闸关闭（仍正触发）：无一可编号碎片。「今天必须出已答辩终稿」而无最小碎片不得开闸。不出 `YC#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `YC#` 终稿，**第 7 节不得出可提交答辩书**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已答辩」「已读即已送达」「网交即已提交」「不答辩即败诉」「应裁即放弃异议」「民诉十五日即本窗截止」「第三十七条即仲裁庭异议截止」「过期仍要可提交有效异议终稿」「保证驳回」「选定某会」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `YC#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 应裁闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造或倒签答辩或送达回证、隐匿证据、虚假陈述、用申请方未授权秘密撰写应裁或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 3　应裁行 `YC#`

按已出现请求切片扫描，不是默认闭集。每条须能指向请求、送达、协议异议或实体抗辩之一。

无 `E#` 不得写已答辩或已提出异议。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止唯一截止日。禁止写入已放弃或当然败诉。协议异议未单独递交不得标已放弃闭集。

热冲突强制处理：

- 草稿即已答辩／已读即已送达／网交即已提交／不答辩即败诉／应裁即放弃异议／民诉十五日即本窗截止／第三十七条即仲裁庭异议截止／过期仍要可提交有效异议终稿／保证驳回／未知写零 → 该格不支持或字段停止；仍出其他 `YC#`。
- 无一碎片 → 关闸，不出 `YC#` 终稿，窗口不关。
- 指导隐匿、伪造答辩、倒签送达、用申请方未授权秘密 → 整体停止，不是该格不支持。

## 节点 4　仲异、反请求、庭审、一审与保全接口

第 7 节只开接口，不得夹带 `YC#` 终稿或可提交答辩书绕闸。闸关闭时第 7 节可写「闸未开，转介待被申请碎片编号」，不得补写已答辩。不选定机构或法院。不代提交。不写发送版。反请求只开接口，本窗不出反请求终稿。组庭只开规则指定或选定接口，选定仲裁员不得写成已放弃异议。保全应对只开 `应对合同案件保全裁定`。

下一步只转介：`提起合同仲裁`、`应对合同纠纷一审`、`评估合同管辖与仲裁协议`、`准备合同仲裁协议异议材料`、`评估合同反诉或反请求`、`准备合同反诉或仲裁反请求`、`准备合同案件庭审`、`建立合同争议证据案卷`、`规划举证期限与证据交换`、`选择诉讼仲裁或督促程序`、`谈判合同和解方案`、`准备合同财产保全申请`、`应对合同案件保全裁定`、`申请撤销仲裁裁决`、`申请不予执行仲裁裁决`、`测算违约金与损害赔偿`、`评估合同争议`。禁止此致某院。禁止此致某会升格规则已定。应裁不得写成放弃异议。民诉十五日不得充本窗截止。反请求只开接口。

若 if 用户催促「已读就算送到了／不答辩就败了／交了答辩就算放弃异议／过了今晚仍要可提交有效异议终稿／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「应裁闸与应裁行草案」。本窗不执行发送。不包含：已答辩、发送版答辩书、反请求终稿、仲异唯一成果。禁止选边治愈。禁止已读即送达。禁止不答辩即败诉。禁止应裁即放弃。禁止指导隐匿或倒签。应裁闸打开 ≠ 已答辩 ≠ 已放弃协议异议。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标应裁终稿已形成。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：买卖尾款，被申请人微信收到贸仲申请书 PDF，合同有仲裁条款。用户主张已读就算送到了、不答辩就败了、交了答辩就算放弃异议、民诉十五天就是截止、把法院答辩状改头换面当仲裁答辩、草稿写完就算交了、不清楚的金额先写零、此致某会保证驳回。应裁闸打开或半开。`Q-达`、`Q-败`、`Q-弃`、`Q-签`、`Q-院`、`Q-胜`、`Q-零` 不打开为可靠路径。第 6 节不得把已送达、当然败诉、已放弃、已提交、0 写入可执行 `YC#`；对应格 `现有依据不支持` 或字段停止；仍出请求分列、作出日与送达日缺口、该机构规则待核、第三十一条异议红旗等其他 `YC#`。不关窗。不代提交。不选定机构。

场景②：用户同时交出己方「必须认下来、回证日期改到上周、对方那份对账单先藏起来」与申请人「从未违约」口径。命中双方秘密＋倒签＋隐匿。第一次整体停止。只交第 1、10 节。不出 `YC#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代违法方案。
