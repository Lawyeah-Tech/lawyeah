# 边界与路由

## 正触发

一般合同被申请人已收到商事仲裁申请书副本、受理或答辩通知或等价被申请碎片，需要首次应裁草稿。从零、碎片、规则或异议未核验仍正触发：有可编号申请书副本、受理或答辩通知、组庭或开庭通知或案号碎片则闸开或半开，出 `YC#` 草案，保持草案。本次不代提交、不出反请求终稿是交付禁令，不是开窗条件。草稿即已答辩、应裁即放弃异议，仍正触发。把不答辩写成当然败诉、把民诉十五日写成本窗截止、把第三十七条写成仲裁庭异议截止，仍正触发：该格不支持，不改负触发关窗。

双方秘密、用申请方未授权秘密、伪造答辩、隐匿证据的停止，优先于负触发。上述信号不在下表。不代提交不是负触发。「草稿即已答辩」「已读即已送达」「不答辩即败诉」「应裁即放弃异议」「过期仍要可提交有效异议终稿」「保证驳回」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 申请包 | `提起合同仲裁` |
| 一审应诉 | `应对合同纠纷一审` |
| 管辖或仲裁效力评估终稿 | `评估合同管辖与仲裁协议` |
| 只要协议异议终稿且拒绝任何实体抗辩 | `准备合同仲裁协议异议材料` |
| 反请求条件专项 | `评估合同反诉或反请求` |
| 反请求文书终稿 | `准备合同反诉或仲裁反请求` |
| 已过首次应裁的庭审提纲 | `准备合同案件庭审` |
| 保全复议或担保置换 | `应对合同案件保全裁定` |
| 证据案卷终稿 | `建立合同争议证据案卷` |
| 举证期限计划 | `规划举证期限与证据交换` |
| 和解方案 | `谈判合同和解方案` |
| 撤裁申请 | `申请撤销仲裁裁决` |
| 不予执行申请 | `申请不予执行仲裁裁决` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不代提交」或「不出反请求终稿」关窗。拟应裁草稿仍正触发，不得写成已答辩或已放弃。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流。出现「应裁」「答辩」「异议」「仲裁」一词不是转出。C 端只要大众填空页时只分流，不把本包降成填空式结论，不回改。

| 信号 | 转介 |

| 只要一审应诉 | `应对合同纠纷一审` |

## 易混

本窗闸名只能是应裁闸，不是答辩闸，不是仲裁闸，不是仲异闸，不是开庭闸，不是应诉闸，不是应对闸。`YC#` 不是 `DB#`，不是 `ZC#`，不是 `ZX#`，不是 `KT#`，不是 `HC#`，不是 `BZ#`。主路径是 `Q-应裁`，不是 `Q-辩`，不是 `Q-应`，不是 `Q-申`，不是 `Q-开庭`，不是 `Q-仲异`。`答辩闸`／`DB#`／`Q-辩` 是应对合同纠纷一审。`仲裁闸`／`ZC#`／`Q-申` 是提起合同仲裁。`仲异闸`／`ZX#`／`Q-仲异` 是准备合同仲裁协议异议材料。`开庭闸`／`KT#`／`Q-开庭` 是准备合同案件庭审。`一人窗`禁止 `YC#` 不是本窗占用。1994 年第三十一条不是效力异议。1994 年第三十六条不是答辩。1994 年第三十七条不是起诉未声明。1994 年第三十八条不是反请求。民诉第一百二十八条十五日不是本窗截止。第三十七条是法院应诉条，不是仲裁庭异议截止。MCP 标尚未施行时以施行日 2026-03-01 为准。劳动人事争议仲裁答辩不是本窗。提出「回证日期改到上周、对账单先藏起来」整体停止。本窗不代提交。不选定机构或法院。不写发送版。不保证驳回。
