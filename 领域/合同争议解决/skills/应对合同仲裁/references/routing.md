# 边界与路由

## 正触发

收到仲裁申请，被申请方需要应裁。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 一审应诉 | `应对合同纠纷一审` |
| 协议异议专项 | `准备合同仲裁协议异议材料` |
| 反请求评估 | `评估合同反诉或反请求` |
| 反请求文书 | `准备合同反诉或仲裁反请求` |
| 庭审 | `准备合同案件庭审` |
| 申请方立案 | `提起合同仲裁` |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，只分流不回改 |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

已经收到仲裁申请要应裁时正触发。收到的是法院传票时转一审应诉。只要打协议、不要实体时转协议异议。
