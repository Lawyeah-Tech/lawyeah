# 边界与路由

## 正触发

一般合同已成争，需司法确认、公证赋强或申请制作诉讼／仲裁调解书。从零、碎片、路径前提未核验仍正触发：有可编号给付和解碎片或路径前提则闸开或半开，出 `QF#` 草案，保持草案。本次不代申请、不保证确认是交付禁令，不是开窗条件。单独和解即已可强制执行、申请即已裁定，仍正触发。把赋强写成证据保全公证、把私下微信写成人民调解，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造调解组织、倒签、掩盖犯罪的停止，优先于负触发。上述信号不在下表。不代申请不是负触发。「单独和解即已可强制执行」「申请即已裁定」「赋强即证据保全公证」「私下微信即人民调解」「保证确认」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 可签和解正文 | `起草合同和解协议` |
| 谈判方案要点 | `谈判合同和解方案` |
| 调解方案利弊 | `评估合同调解方案与效力` |
| 执行中分期或以物抵债 | `准备合同执行和解` |
| 证据保全公证 | `准备合同案件公证保全` |
| 已生效名义强制执行 | `执行合同生效文书` |
| 争议总图 | `评估合同争议` |

不得因「不代申请」或「不保证确认」关窗。拟手续草稿仍正触发，不得写成已裁定或已可执行。

## 易混

本窗闸名只能是力补闸，不是和解闸，不是方案闸，不是公证闸，不是补强闸。`QF#` 不是 `HJ#`，不是 `FA#`，不是 `GD#`，不是 `Pth#`。主路径是 `Q-力`，不是 `Q-和`，不是 `Q-方`，不是 `Q-公`，不是 `Q-执`。`和解闸`／`HJ#`／`Q-和` 是起草合同和解协议。`公证闸`／`GD#`／`Q-公` 是准备合同案件公证保全。`补强闸` 是人身损害办理人身和解执行力补强。1991 年民事诉讼法第二百零五条破产管辖不是司法确认。2012 年第一百九十四条、2021 年第二百零一条须核对应现行第二百零五条。公证法 2005 年第三十七条须核 2017 修正。第三十六条证据效力不是执行名义。提出「倒签人民调解、把逃废债务写成已确认」整体停止。本窗不代申请。不选定法院或公证处。不保证确认。
