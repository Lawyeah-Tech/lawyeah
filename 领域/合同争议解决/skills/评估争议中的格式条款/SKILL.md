# 评估争议中的格式条款

## 任务目标

在明确、无利益冲突的单方立场下（格式提供方、相对方或其受托律师，互斥），形成格式条款评估草案：格式闸、主体与强制接口、`Q#` 路径、`GS#` 格式条款行（条款切片／格式定性／重大利害／异常／提示说明与是否成为内容／无效／不利解释接口／`E#` 回链）。本窗 `GS#` 是格式条款行草案，不是已提示证明，不是条款已无效终局，不是改稿，不是诉状。本窗闸名只能是格式闸，禁止复用解释闸、提示闸、条款闸、效力闸、评估闸、争议闸、成立闸。预留不得占用：立案闸。本窗主行只能是 `GS#`，禁止 `JX#`、`SY#`、`CL#`、`ZT#`、`A#`。主路径只用 `Q-格`，禁止用 `Q-释`、`Q-契`、`Q-总`、`Q-式`、`Q-签` 作主路径。邻窗 `Q-格` 只作转介进本窗；本窗打开为主路径，不是已提示、不是已无效。本窗 `Q-签` 只作「评估即已确认或已提交」不关窗码。格式闸打开不等于已构成格式不等于已提示说明不等于不成为内容不等于条款已无效不等于不利解释已适用不等于整份无效不等于应起诉。未提示说明不是当然无效。有歧义不是一律不利提供方。非格式条款优先不是非格式当然有效。签名或勾选不是已经提示说明。政府示范不是当然非格式。已协商修改不是仍当然格式。对我们不利不是当然第四百九十七条无效。未知不写零。不重写格式文本。不写诉状。不选定法院。不代提交。不定罪。不保证胜诉。伤残等级与本窗无关，禁止折入。

`depends-on` 为空。主成果是争议总图转 `评估合同争议`。主成果是解释且不争提示、成为内容或第四百九十七条无效转 `解释争议条款与填补漏洞`。主成果是成立效力专项转 `评估合同成立与效力`。主成果是管辖或仲裁协议本身转 `评估合同管辖与仲裁协议`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：一般合同已成争，对方以格式条款免责、限责或限制主要权利，需要判断提示说明与效力。「这是不是格式条款」「勾了就算提示了吧」仍正触发，成果状态 `草案`。提示、说明、无效未核验仍正触发：有可编号争议条款碎片则格式闸打开或半开，第 6 节出 `GS#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出已无效／已提示终稿」才关闸，仍交十节，第 6 节不出 `GS#` 终稿，第 7 节不得出改稿或已无效终局，窗口不关。用户要把未提示写成当然无效或整份无效、把有歧义写成一律不利提供方、把勾选写成已提示、把示范文本写成非格式、把已协商修改写成仍当然格式、把对我们不利写成当然无效、把未知写成零，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `GS#` 草案。不得因「不重写格式文本」「不给胜诉率」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是争议总图（转 `评估合同争议`）；
- 主成果是解释且不争提示、成为内容或第四百九十七条无效（转 `解释争议条款与填补漏洞`）；
- 主成果是成立效力专项（转 `评估合同成立与效力`）；
- 主成果是电子到达或电子签名专项（转 `评估电子合同成立与送达`）；
- 主成果是管辖或仲裁协议本身（转 `评估合同管辖与仲裁协议`）；
- 主成果是框架与订单冲突（转 `评估框架协议与订单冲突`）；
- 主成果是变更是否成立（转 `评估变更是否成立`）；
- 主成果是确认之诉诉状（转 `提起合同成立或效力确认之诉`）；
- 尚未成争，只要改模板或签前审查（审查起草领域，本窗搁置，只说明不实施）；
- 建设工程、金融借贷担保、房地产物业、海事、劳动专项争议主轴；
- 消费公益诉讼或群体策略主目标（P2，输出 unavailable）。

双方秘密、伪造提示记录、倒签勾选、隐匿文本、违法取证**不在负触发表**，走整体停止。「未提示即当然无效」「有歧义即一律不利提供方」「勾选即已提示」「示范即非格式」「已协商修改仍当然格式」「对我们不利即当然无效」「未知写零」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不重写格式文本」「不给胜诉率」是交付禁令，不是负触发。主成果才转；出现「格式」「无效」一词不是转出。

## 建立工作坐标

确认：评估授权；单方立场；提供方与相对方；合同及附件版本；争议条款原文；订立时是否协商；提示说明材料；法域。

口头「签了就算提示」「示范文本不是格式」只登记 `S#`／`V#`。不得升格已提示、已无效或非格式，**不得单独算作开闸材料**。可编号争议条款碎片可开闸。本窗不执行发送，不代提交，不重写格式文本。

立场只许格式提供方、相对方或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：格式闸关闭，仍交十节，不是整体停止。无书面评估授权但单方立场已闭合、且已有碎片：格式闸部分打开，仍交十节，不是整体停止。提出伪造提示记录、倒签勾选、隐匿文本或违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`GS#` 格式条款行；`V#` 版本；`E#` 证据形态回链（条款原文、提示标识、勾选记录、协商痕迹，不是发送闸，不是已提示证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`JX#`、`SY#`、`CL#`。技能正文中的条号是检索锚点，不是已核验 `L#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。未知不写零。未提示 ≠ 当然无效。有歧义 ≠ 一律不利提供方。勾选 ≠ 已提示。示范 ≠ 非格式。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或裁判案例检索。本窗是评估，**不要**用 `search_template` 生成改稿或已提示证明，**不要**用类案写成必然无效。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现未提示即当然无效、勾选即已提示、有歧义即一律不利提供方、示范即非格式的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》第三十九条至第四十一条及其解释当作现行规则。MCP 效力字段与公布施行日冲突时，以施行日为准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的提示、成为内容或无效结论保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民法典第四百九十六条格式条款是为重复使用而预先拟定、订立时未与对方协商的条款；提供方应当采取合理方式提示对方注意免除或减轻其责任等与对方有重大利害关系的条款，并按要求说明；未履行提示或说明义务致使对方没有注意或理解的，对方可以主张该条款不成为合同内容，不是当然无效，不是整份合同无效。合同编通则解释第十条：通常足以引起注意的明显标识可认定提示义务；按要求作出通常能够理解的解释说明可认定说明义务；提供方对提示或说明承担举证责任；电子合同仅以勾选、弹窗主张已履行的，人民法院不予支持，但举证符合前两款的除外。第四百九十七条格式条款无效：具有第一编第六章第三节和第五百零六条规定的无效情形；不合理地免除或减轻其责任、加重对方责任、限制对方主要权利；排除对方主要权利。限制与排除分列，对我们不利不是当然无效。第五百零六条造成对方人身损害或因故意、重大过失造成对方财产损失的免责条款无效。第四百九十八条对格式条款的理解发生争议，应当按照通常理解予以解释；有两种以上解释的，应当作出不利于提供格式条款一方的解释；格式条款和非格式条款不一致的，应当采用非格式条款。非格式优先不是非格式当然有效。噪声：已失效合同法第三十九条至第四十一条。技能正文条号不是 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变提示、成为内容或无效入口的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补未提示不是当然无效、勾选不是已提示、有歧义须先通常理解、示范文本仍可能是格式、仅未重复使用不能否定格式定性的实务反例。
- `search_case_by_fact` 只比较事实差异与翻转条件：未提示不是当然无效；勾选不是已提示；有歧义不是一律不利提供方；示范不是非格式。无类案不得写成已无效或已提示终稿。评估类禁止用 `search_template` 生成改稿或已提示证明。

工具不可用时继续条款碎片和 `GS#` 编目；提示、成为内容、无效结论字段停止。不得拒跑，不得凭记忆写成已提示或当然无效。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、格式闸与不关窗

主成果才整案转出。双方秘密、伪造提示、倒签勾选第一次停。未提示即当然无效、勾选即已提示不关窗。闸关仍交十节，第 6 节不出 `GS#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

格式定性、重大利害、提示说明、无效、不利解释分列。本节禁止出 `GS#` 终稿。

### 3. 格式闸与路径 `Q#`

本节禁止出 `GS#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-格`。

### 4. 格式条款行 `GS#`

条款切片、格式定性、提示与是否成为内容、无效与不利解释接口。状态 `草案`。禁止升格已提示、不成为内容、已无效。无 `E#` 不得写已提示。

### 5. 解释、论坛、电子、测算接口

一般解释转解释窗。管辖仲裁格式效力转论坛窗。第 7 节不得夹带 `GS#` 终稿或改稿绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造提示记录、倒签勾选、隐匿文本或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：格式闸关闭，仍交十节，不是整体停止。无书面评估授权但有碎片：格式闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：提示说明、成为内容、第四百九十七条不合理、施行日未核验。未提示即当然无效、有歧义即一律不利提供方、勾选即已提示、示范即非格式、已协商修改仍当然格式、对我们不利即当然无效、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `GS#` 草案。
- `目标停止`：主目标变为签前审查意见、整份合同改稿或群体诉讼策略。禁止把「未提示即当然无效」当作用户错误主张时的目标停止；那是不关窗。

禁止指导伪造提示或倒签勾选。不给胜诉率。不定罪。不选定法院。不代提交。未知不写零。不重写格式文本。不写诉状。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。格式闸关闭仍交十节，第 6 节不出 `GS#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `GS#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。格式闸未打开时不得交付「已提示」或「已无效」。边界见 [路由](references/routing.md)。
