# 边界与路由

## 正触发

一般合同已成争，对方以格式条款免责、限责或限制主要权利，需要判断提示说明与效力。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 签前审查格式文本 | 审查起草领域（本窗搁置，只说明） |
| 非格式条款歧义 | `解释争议条款与填补漏洞` |
| 管辖或仲裁协议本身 | `评估合同管辖与仲裁协议` |
| 成立或效力总表 | `评估合同成立与效力` |
| 群体格式合同策略 | unavailable（P2） |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，只分流不回改 |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

已成争且对方拿格式条款挡请求或抗辩时正触发。签约前要改模板时负触发。只解释双方协商过的条款时转解释原子。
