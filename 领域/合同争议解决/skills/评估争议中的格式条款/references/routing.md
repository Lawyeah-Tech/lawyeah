# 边界与路由

## 正触发

一般合同已成争，对方以格式条款免责、限责或限制主要权利，需要判断提示说明与效力。从零、碎片、提示未核验、无书面评估授权仍正触发：有可编号争议条款碎片则闸开或半开，出 `GS#` 草案，保持草案。本次不重写格式文本、不给胜诉率是交付禁令，不是开窗条件。未提示即当然无效、勾选即已提示、有歧义即一律不利提供方，仍正触发。

双方秘密、伪造提示记录、倒签勾选、隐匿文本、违法取证的停止，优先于负触发。上述信号不在下表。不重写格式文本不是负触发。「未提示即当然无效」「勾选即已提示」「有歧义即一律不利提供方」「示范即非格式」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 争议总图 | `评估合同争议` |
| 解释且不争提示、成为内容或第四百九十七条无效 | `解释争议条款与填补漏洞` |
| 成立效力专项 | `评估合同成立与效力` |
| 电子到达或电子签名专项 | `评估电子合同成立与送达` |
| 管辖或仲裁协议本身 | `评估合同管辖与仲裁协议` |
| 框架与订单冲突 | `评估框架协议与订单冲突` |
| 变更是否成立 | `评估变更是否成立` |
| 确认之诉诉状 | `提起合同成立或效力确认之诉` |
| 尚未成争，改模板或签前审查 | 审查起草领域（本窗搁置，只说明） |
| 工程／金融／房产／海事／劳动主轴 | 对应领域 |
| 消费公益诉讼或群体策略 | P2 unavailable |

不得因「不重写格式文本」或「不给胜诉率」关窗。拟格式评估仍正触发，不得写成已提示或当然无效。

## 易混

本窗闸名只能是格式闸，不是解释闸，不是提示闸，不是成立闸，不是争议闸。`GS#` 不是 `JX#`，不是 `SY#`，不是 `CL#`。主路径是 `Q-格`，不是 `Q-释`，不是 `Q-契`。邻窗 `Q-格` 只转介进本窗。未提示说明不是当然无效。有歧义不是一律不利提供方。签名勾选不是已经提示说明。政府示范不是当然非格式。第四百九十六条不成为内容不是第四百九十七条无效。已失效合同法第三十九条至第四十一条不是现行。「勾选时间改到上周」「提示页先补一版」整体停止。本窗不执行发送，不代提交。不选定法院。不重写格式文本。不写诉状。
