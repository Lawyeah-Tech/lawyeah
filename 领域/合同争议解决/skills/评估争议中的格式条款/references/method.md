# 格式条款争议评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然结果或唯一必得总额。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。实务检索若出现“违约金不超过合同标的百分之三十”，记为噪声。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

应诉答辩或提出反诉，不等于当然放弃仲裁协议。解除通知到达对方时解除；未通知而起诉或申请仲裁主张解除的，仅在该主张获确认后，自起诉状或仲裁申请书副本送达时解除，不得把立案日写成解除时点。第 585 条“过分高于”对照违约造成的损失，不对照合同总价。


## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填本任务实体结论。

| 信号 | 转出 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定、实际施工人 | 建设工程领域 |
| 金融借贷、保证、抵押质押、保理、融资租赁主轴 | 金融借贷担保领域 |
| 商品房买卖、开发合作、物业服务主轴 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、劳动报酬、解除劳动合同、工伤待遇 | 劳动领域 |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

混合信号：一般买卖或服务主轴可留本任务；专项只作为背景时在缺口标明，不把专项规则硬套进一般合同结论。


## 节点 1　是否构成格式条款

1. 预先拟定、重复使用、订立时未与对方协商，三者均需核对。
2. 双方来回修改过的条款：记录修改痕迹，相应段落退出格式条款通道。
3. 监管示范文本被一方单方采用：仍可能构成格式条款，不得因“政府示范”跳过提示说明。
4. 建设工程、金融、商品房、海事、劳动示范文本若构成那些专项主轴：整案转出。

若：无法判断是否预先拟定 → 格式条款定性标 `依据不足`。
若：用户要在签约前改模板 → 目标停止，审查起草搁置。

## 节点 2　提示与说明

运行时核验第 496 条。民法典施行前订立、涉及提示说明的，时间效力规定指向第 496 条，仍按现行规则核验。

1. 提示须针对免除或减轻提供方责任等重大利害关系条款，且方式合理：显著字体、单独告知、弹窗停留等，须有证据。
2. 说明以对方要求或条款复杂到通常无法理解为准。专业术语未解释列入缺口。
3. 电子勾选“我已阅读”不单独等于已经提示说明。
4. 未尽义务的法律效果是对方可主张该条款不成为合同内容，不是整份合同当然无效。
5. 提供方主张已提示：由其控制的页面、录音、签收栏必须可回链。

## 节点 3　无效

运行时核验第 497 条、第 506 条。

1. 具有民事法律行为无效情形的，条款无效。
2. 不合理免除或减轻提供方责任、加重对方责任、限制对方主要权利：无效。
3. 排除对方主要权利：无效。
4. 造成人身损害的免责，或因故意、重大过失造成财产损失的免责：无效。
5. 不得用已失效《合同法》第四十条作为现行依据。

若：条款仅分配商业风险且对价清楚 → 不得仅因“对我们不利”写无效。
若：人身伤害主轴 → 转侵权领域，本任务只处理合同条款接口。

## 节点 4　解释

1. 通常理解解释格式条款。
2. 两种以上解释：不利于提供格式条款一方。
3. 非格式条款优先于格式条款。
4. 不利解释不得用来发明合同中不存在的给付。

## 节点 5　程序接口

1. 格式仲裁或管辖条款：效力争点移交 `评估合同管辖与仲裁协议`。
2. 格式违约金：效力按本任务；金额调整按第 585 条对照损失，不对照总价。
3. 群体同一格式合同策略属 P2，输出 `unavailable`。

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。

下一步按期限灭失、易失证据、改变本任务结论、可逆性排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。

禁止指导伪造、隐匿、威胁或违法取证。未知金额不写零。不把应诉写成放弃仲裁。不把立案日写成解除时点。
