# 评估争议中的格式条款方法

本文件是可执行判断节点。未提示说明不是当然无效。有歧义不是一律不利提供方。非格式条款优先不是非格式当然有效。签名或勾选不是已经提示说明。政府示范不是当然非格式。已协商修改不是仍当然格式。对我们不利不是当然第四百九十七条无效。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已提示、已无效终局、选定法院、代提交、未知写零。本任务不定罪，不重写格式文本，不写诉状。本窗闸名只能是格式闸，禁止复用解释闸、提示闸、条款闸、成立闸、争议闸。预留不得占用：立案闸。本窗 `GS#` 是格式条款行。主路径只用 `Q-格`，禁止用 `Q-释`、`Q-契`、`Q-总`、`Q-签` 作主路径。本窗 `Q-签` 只作「评估即已确认或已提交」不关窗码。英文 id 禁止使用，一律用中文技能名 `评估争议中的格式条款`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》第三十九条至第四十一条、把未提示写成当然无效或把勾选写成已提示时记为噪声。禁止指导伪造提示记录或倒签勾选。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现条款碎片扫描，不是默认闭集。
`GS#` 固定列：`编号｜条款切片｜格式定性｜重大利害／异常｜提示说明与是否成为内容｜无效／不利解释接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已提示」或「当然无效」。无 `E#` 不得写已提示。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-格`。禁止 `JX#`、`SY#`、`CL#`、`A#`、`N#`。

口头「签了就算提示」「示范文本不是格式」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：格式定性（预拟＋重复使用＋订时未协商）与提示说明、成为内容、第四百九十七条无效、第五百零六条免责无效、第四百九十八条解释分列。限制与排除分列。

## 节点 0　分流、立场、格式闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造提示记录、倒签勾选、隐匿文本、违法取证不进负表。利益冲突未解不进整体停止。不重写格式文本、不给胜诉率不是负触发。

整案转出只交付第 1、2、10 节，不出 `GS#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 主成果是解释且不争提示、成为内容或第四百九十七条无效 | 负触发 `解释争议条款与填补漏洞` |
| 主成果是成立效力专项 | 负触发 `评估合同成立与效力` |
| 主成果是电子到达或电子签名专项 | 负触发 `评估电子合同成立与送达` |
| 主成果是管辖或仲裁协议本身 | 负触发 `评估合同管辖与仲裁协议` |
| 主成果是框架与订单冲突 | 负触发 `评估框架协议与订单冲突` |
| 主成果是变更是否成立 | 负触发 `评估变更是否成立` |
| 主成果是确认之诉诉状 | 负触发 `提起合同成立或效力确认之诉` |
| 尚未成争，只要改模板或签前审查 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程／金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 消费公益诉讼或群体策略主目标 | P2 unavailable |
| 「不重写格式文本」「不给胜诉率」 | 交付禁令，不是负触发 |

出现「格式」「无效」一词不是转出。

格式闸打开（可出 `GS#` 草案，仍不得标「已提示／已无效／整份无效」）须同时满足：单方无冲突立场已闭合；主成果是格式提示说明与效力，不是总图、不是一般解释终稿、不是改稿；至少一项可编号争议条款碎片。口头「签了就算提示」不算单独开闸材料。

格式闸部分打开：已有碎片，但提示、说明或无效要件未闭合；对应格待核；仍交十节。无书面评估授权但单方立场已闭合且已有碎片：格式闸部分打开，仍交十节，不是整体停止。

格式闸关闭（仍正触发）：无一可编号碎片。「今天必须出已无效终稿」而无最小碎片不得开闸。不出 `GS#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `GS#` 终稿，**第 7 节不得出改稿或已无效终局**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「未提示即当然无效」「有歧义即一律不利提供方」「勾选即已提示」「示范即非格式」「已协商修改仍当然格式」「对我们不利即当然无效」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `GS#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 格式闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造提示记录、倒签勾选、隐匿文本或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个条款切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `GS#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 格式定性 | 预拟、重复使用、订立时未协商分列 | 示范即非格式；未实际重复使用即非格式 |
| 重大利害／异常 | 免责、限责、期限、管辖仲裁、单方解约分列 | 合成「对我们不利」 |
| 提示说明 | 标识、说明内容、时间、举证责任 | 勾选、弹窗单独升格已提示 |
| 成为内容 | 第四百九十六条不成为内容 | 写成当然无效或整份无效 |
| 无效 | 第四百九十七条与第五百零六条分列 | 限制与排除合成一律无效；不利即无效 |
| 解释 | 先通常理解，两种以上才不利提供方 | 有歧义一律不利；协商条款套不利解释 |

检索锚点（写入 `L#` 前须核验）：第四百九十六条、合同编通则解释第十条、第四百九十七条、第五百零六条、第四百九十八条。噪声：已失效合同法第三十九条至第四十一条。

## 节点 3　格式条款行 `GS#`

按已出现条款碎片扫描，不是默认闭集。每条须能指向条款原文、提示材料或协商痕迹之一。

无 `E#` 不得写已提示。状态默认 `草案`。一次只推荐下一步。未知不写零。

热冲突强制处理：

- 未提示即当然无效／有歧义即一律不利提供方／勾选即已提示／示范即非格式／已协商修改仍当然格式／对我们不利即当然无效／未知写零 → 该格不支持或字段停止；仍出其他 `GS#`。
- 无一碎片 → 关闸，不出 `GS#` 终稿，窗口不关。
- 指导伪造提示、倒签勾选 → 整体停止，不是该格不支持。

## 节点 4　解释、论坛、电子、测算接口

第 7 节只开接口，不得夹带 `GS#` 终稿或改稿绕闸。闸关闭时第 7 节可写「闸未开，转介待条款编号」，不得补写已提示或已无效。不选定法院。不代提交。

下一步只转介：`评估合同争议`、`解释争议条款与填补漏洞`、`评估合同成立与效力`、`评估电子合同成立与送达`、`评估框架协议与订单冲突`、`评估变更是否成立`、`评估合同管辖与仲裁协议`、`测算违约金与损害赔偿`、`评估解除权是否成立`、`建立合同争议证据案卷`、`提起合同纠纷一审`、`应对合同纠纷一审`、`提起合同仲裁`、`选择诉讼仲裁或督促程序`、`提起合同成立或效力确认之诉`、`处理解除后返还与清理`。禁止此致某院。禁止出改稿。

若 if 用户催促「勾了就算提示了／没提示整份都无效／有歧义都按对我们有利／示范文本不是格式／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：服务合同网上勾选，有免责条款碎片。用户主张勾了就算提示了、没提示整份都无效、有歧义都按对我们有利、这是政府示范所以不是格式、不清楚先写零。格式闸打开或半开。`Q-勾`、`Q-份`、`Q-歧`、`Q-范`、`Q-零` 不打开为可靠路径。第 6 节不得把已提示、整份无效、一律不利、非格式、0 写入可执行 `GS#`；对应格 `现有依据不支持` 或字段停止；仍出格式定性、提示标识缺口、第四百九十六条与第四百九十七条分列等其他 `GS#`。不关窗。不重写文本。

场景②：用户同时交出己方「勾选时间改到上周、提示页先补一版」与对方「从未见过弹窗」口径。命中双方秘密＋倒签＋伪造提示。第一次整体停止。只交第 1、10 节。不出 `GS#`。不得问代表哪一方后继续。不以「坚持」为门槛。
