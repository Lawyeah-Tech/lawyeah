# 边界与路由

## 正触发

数据电文、平台下单或电子章引发成立或到达争议。从零、碎片、系统未核验、无书面评估授权仍正触发：有可编号电文、订单、电子章或日志碎片则闸开或半开，出 `DY#` 草案，保持草案。本次不代鉴定、不写已到达是交付禁令，不是开窗条件。已读即到达、截图即原件、电子章即可靠签名，仍正触发。把已读写成到达、把点击写成已成立，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造时间戳或电子章、倒签到达日、违法侵入取证的停止，优先于负触发。上述信号不在下表。不代鉴定不是负触发。「已读即到达」「截图即原件」「点击即成立」「电子章即可靠签名」「进入垃圾箱即到达」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 总体成立效力而不涉及电子到达 | `评估合同成立与效力` |
| 格式勾选提示终稿 | `评估争议中的格式条款` |
| 电子认证鉴定意见 | 鉴定接口或 `保全质量现场与电子证据`／`准备合同案件公证保全` |
| 诉讼文书电子送达 | `设计合同案件通知送达` |
| 框架与订单效力层级 | `评估框架协议与订单冲突` |
| 争议总图 | `评估合同争议` |
| 尚未成争，改合同或设计电子签约 | 审查起草领域（本窗搁置，只说明） |
| 工程电子签证／金融电子签章／商品房网签／海事电子提单／劳动电子送达 | 对应领域 |

不得因「不代鉴定」或「不写已到达」关窗。拟电约评估仍正触发，不得写成已到达或已成立。

## 易混

本窗闸名只能是电约闸，不是成立闸，不是发送闸，不是送达闸，不是电文闸。`DY#` 不是 `CL#`，不是 `HF#`，不是 `SD#`。主路径是 `Q-电`，不是 `Q-契`，不是 `Q-函`，不是 `Q-送`，不是 `Q-达`。`Q-送`／`SD#`／送达闸是公司治理通知送达窗。`Q-达` 被该窗禁作主路径。`Q-契` 是成立窗主路径。决议窗 `Q-电` 是「视频开会即未召开」不关窗码，不是本窗主路径的同一含义。已读不是到达。截图不是原件。电子章不是当然可靠电子签名。第一百三十七条未指定系统以知道或应当知道进入为准，合同法第十六条首次进入是噪声。电子签名法第十一条接收时间不是第一百三十七条生效。民诉第九十条不得套民事到达。电子签名法 2019 年 4 月 23 日第二次修正施行。「已读截图P成回证」「时间戳改到昨天」整体停止。本窗不执行发送，不代提交，不代鉴定。不选定法院。不写诉状。
