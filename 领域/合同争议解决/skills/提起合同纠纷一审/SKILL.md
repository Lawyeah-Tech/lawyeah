# 提起合同纠纷一审

## 任务目标

在明确、无利益冲突的原告立场下，形成可复核、不代提交的“合同纠纷一审起诉包”：起诉状草稿、分项诉讼请求（可含确认解除效力或确认未解除）、管辖连结点、证据目录和保全红旗。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价评估、测算、证据清单和仲裁排除材料。

## 工作边界

正触发：一般合同已成争，用户已决定向人民法院提起一审，且无表面有效的仲裁协议阻挡诉讼，或阻挡已被可回链证据排除。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未成争，只要改合同或出稿（审查起草领域，本生产线搁置，只说明不实施）；
- 只要总体评估、只要和解方案、只要发送版催告或解除函；
- 仲裁条款表面有效且未被排除，用户仍要求“直接起诉”；
- 已决定申请仲裁（转 `提起合同仲裁`）；
- 已收到起诉状或应诉通知、用户实为被告；
- 建设工程、金融借贷担保、房地产物业、海事专属、劳动专项争议。

C 端 011 只分流：用户只要大众网上立案材料包、且主体请求论坛已闭合时，可提及 011；本技能仍负责专业请求判断，不得降成大众立案包，不回改 011。

本任务不代提交、不保证受理或胜诉，不写保全申请终稿，不把有效仲裁写成应起诉。

## 建立起诉坐标

确认：使用者与授权；原告立场；被告及可能共同被告；合同及附件版本；拟提出的请求；法域；当前协商、催告、解除、仲裁或诉讼状态；是否已有案号或受理凭证；管辖连结点材料；仲裁条款及排除证据；关键材料及缺失。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。口头转述和“已读”不写成已受理、已送达或期限已起算。已有受理凭证、案号或立案通知时，停止生成起诉入口材料。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`P#` 诉讼请求；`J#` 管辖连结点；`V#` 稿件版本；`E#` 发送／送达／履行凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验起诉条件、管辖、仲裁协议阻却、确认解除效果、期间和保全接口；`search_template` 只借起诉状栏目结构；`search_practiced` 补路径与反例；特殊事实用 `search_case_by_fact`，明确筛选用 `search_case_by_filter`。不虚构案件系统。

工具不可用时继续主体、事实、证据目录和问题清单；请求的法律结论、管辖选定、期限和机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [起诉方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 专项分流、起诉决定和仲裁阻却闸

先做专项整案转出。劳动、工程、海事专属不得留在本任务做起诉包。仲裁条款出现时不得直接写应起诉；表面有效且未排除则负触发，转论坛评估或仲裁申请。排除必须有可回链证据。

### 2. 主体适格与分项诉讼请求

原告须与本案有直接利害关系，被告须明确。继续履行、确认解除效力、确认未解除、付款、违约金、赔偿、定金、返还清理分列，禁止合成“合同权益”。构成违约不等于当然请求解除。确认解除未事先通知的，解除时点按起诉状副本送达处理，不得写成起诉当日已解除。

### 3. 管辖连结点

分列被告住所地、合同履行地、协议管辖、专属管辖和级别管辖。连结点材料不足时不选定唯一法院。协议管辖不得违反级别管辖和专属管辖。有效仲裁未被排除时，本节点不展开法院清单冒充可选论坛。

### 4. 证据目录与保全红旗

证据按待证事实绑定请求，标明原件／复制件、控制方和合法性。保全只做红旗：转移财产迹象、紧急减损、诉前保全后法定期限内须起诉。不写保全申请终稿，不保证裁定。

### 5. 起诉状草稿与提交核验

按起诉状法定事项组织草稿。只交付草案和核验清单，不代提交，不保证七日内立案或实体胜诉。网上立案渠道信息可提示，但不把本包改写成 C 端 011 成果。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或文本无法建立；用户坚持伪造、隐匿、虚假陈述或违法取证。
- `字段停止`：法域、仲裁排除、管辖连结点、送达、动态规则未核验。
- `目标停止`：主目标已变为仲裁申请、保全申请终稿、答辩或执行申请。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
