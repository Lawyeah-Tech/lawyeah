# 提起合同纠纷一审方法

本文件是可执行判断节点。草稿不是已立案。网交不是已受理。有效仲裁不是应起诉。构成违约不是当然解除。未通知而起诉主张解除，解除时点不是起诉当日。口头或已读不是已送达。此致某院不是管辖已定。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已立案、应起诉、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不把草稿写成已立案。本窗闸名只能是起诉闸，禁止复用立案闸、管辖闸、仲裁阻却闸、诉材闸、争议闸、论坛闸、证据闸、方案闸。预留不得占用：立案闸。本窗 `QT#` 是诉状行。主路径只用 `Q-诉`，禁止用 `Q-管`、`Q-坛`、`Q-总`、`Q-据`、`Q-测`、`Q-方`、`Q-辩`、`Q-签` 作主路径。本窗 `Q-签` 只作「草稿即已提交或已立案」不关窗码。英文 id 禁止使用，一律用中文技能名 `提起合同纠纷一审`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991 年民事诉讼法第一百二十二条开庭公告、第一百三十条缺席判决、2017 年第一百十九条当现行起诉条件、2017 年第二十三条当现行合同管辖、2017 年第三十四条当现行第三十五条、2017 年第一百二十七条当现行管辖异议、仲裁法 1994 年第三十七条重新选定仲裁员、已失效《合同法》、把草稿写成已立案或把有效仲裁写成应起诉时记为噪声。禁止指导伪造诉状、倒签落款或虚假诉讼。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现请求碎片扫描，不是默认闭集。
`QT#` 固定列：`编号｜请求切片｜原告适格与被告明确｜仲裁阻却与排除｜管辖连结点｜证据目录与保全红旗｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已立案」或「应起诉」。无 `E#` 不得写已立案。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-诉`。禁止 `SZ#`、`P#`、`J#`、`LA#`、`A#`、`N#`。文件状态只用 `草案`、`停止`。禁止标 `待提交` 为已立案。

口头「已经立案了」「仲裁不影响起诉」「某院一定管」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：继续履行／确认解除／确认未解除／违约金／赔偿／定金／返还清理分列，禁止合成「合同权益」。有效仲裁未排除不得写应起诉。材料不足不选定唯一法院。保全只做红旗。

## 节点 0　分流、立场、起诉闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造诉状或连结点、倒签落款、隐匿仲裁条款、虚假诉讼、伪造送达、违法取证不进负表。利益冲突未解不进整体停止。不代提交、不选定法院、不保证立案不是负触发。

整案转出只交付第 1、2、10 节，不出 `QT#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 主成果是管辖或仲裁协议评估终稿 | 负触发 `评估合同管辖与仲裁协议` |
| 主成果是仲裁申请包 | 负触发 `提起合同仲裁` |
| 主成果是发送版催告 | 负触发 `准备催告履行或补救通知` |
| 主成果是发送版解除通知 | 负触发 `准备解除通知` |
| 主成果是证据案卷终稿 | 负触发 `建立合同争议证据案卷` |
| 主成果是精算工作表 | 负触发 `测算违约金与损害赔偿` |
| 主成果是保全申请终稿 | 负触发 `准备合同财产保全申请` |
| 主成果是答辩包，用户为被告 | 负触发 `应对合同纠纷一审` |
| 主成果是和解方案 | 负触发 `谈判合同和解方案` |
| 主成果是成立、无效或撤销确认之诉终稿 | 负触发 `提起合同成立或效力确认之诉` |
| 主成果是情势变更之诉终稿 | 负触发 `提起情势变更变更或解除之诉` |
| 主成果是支付令申请 | 负触发 `申请合同金钱支付令` |
| 主成果是已立案后庭审 | 负触发 `准备合同案件庭审` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程／金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不代提交」「不选定法院」「不保证立案」 | 交付禁令，不是负触发 |

出现「起诉」「立案」「管辖」一词不是转出。确认解除效力或确认未解除由本窗 `QT#` 承接，不要求先转效力确认之诉，除非成立、无效、撤销本身才是主请求。

起诉闸打开（可出 `QT#` 草案，仍不得标「已立案／已提交／应起诉」）须同时满足：单方无冲突立场已闭合；主成果是一审起诉包，不是仲裁申请、不是答辩、不是保全终稿、不是总图；至少一项可编号原告适格、请求类型或合同碎片。口头「已经立案了」不算单独开闸材料。表面有效仲裁未排除仍可开或半开，对应格不支持，不出起诉状终稿。

起诉闸部分打开：已有碎片，但仲裁排除、管辖连结点或主体未闭合；对应格待核；仍交十节。无书面起诉授权但单方立场已闭合且已有碎片：起诉闸部分打开，仍交十节，不是整体停止。

起诉闸关闭（仍正触发）：无一可编号碎片。「今天必须出已立案终稿」而无最小碎片不得开闸。不出 `QT#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `QT#` 终稿，**第 7 节不得出发送版起诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已立案」「网交即已受理」「有效仲裁仍应直接起诉」「构成违约即当然解除」「起诉当日即已解除」「此致某院即管辖已定」「约定金即必得」「未知写零」「七日立案已保证」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `QT#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 起诉闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造诉状或连结点、倒签落款、隐匿仲裁条款、虚假诉讼、伪造送达或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。
若 if 已有受理凭证或案号，then 目标停止，转 `准备合同案件庭审`，不得继续生成起诉入口终稿。

## 节点 1　主体与强制接口

一行一个请求切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `QT#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 原告 | 与本案有直接利害关系；签约名／履行名／付款名并列 | 合并未核验主体 |
| 被告 | 能够识别的姓名或名称、住所或其他足以送达的信息 | 「某某公司（待查）」充作明确被告 |
| 请求 | 继续履行、确认解除、确认未解除、违约金、赔偿、定金、返还清理分列 | 合成「合同权益」；构成违约写成当然解除 |
| 互斥 | 继续履行与确认解除主备位可见 | 两项均写成已成立主位终局 |
| 仲裁 | 书面、意思、事项、机构、或裁或诉、排除证据分列 | 口头同意去法院单独排除；有效仲裁写成应起诉 |
| 管辖 | 被告住所地、履行地、协议管辖、专属、级别并列 | 材料不足选定唯一法院；此致某院 |

检索锚点（写入 `L#` 前须核验）：

- 民事诉讼法（2023 修正）第一百二十二条：起诉四要件。噪声：1991 年第一百二十二条；2017 年第一百十九条。
- 第一百二十三条：递交起诉状并按被告人数提出副本。
- 第一百二十四条：起诉状应当记明当事人、诉讼请求和事实理由、证据和证据来源。
- 第一百二十六条：符合条件七日立案。只开接口，不保证。
- 第一百二十七条第二项：书面仲裁协议告知申请仲裁。噪声：2017 年第一百二十七条管辖异议。
- 合同纠纷法定管辖：被告住所地或合同履行地，条号运行时核验现行第二十四条。禁抄 2017 年第二十三条。噪声：MCP 先返回 1991 年第二十四条。
- 第三十五条：协议管辖须书面且与争议有实际联系，不得违反级别和专属。噪声：2017 年第三十四条。
- 第一百三十条：管辖异议在提交答辩状期间提出；应诉答辩或反诉视为有管辖权，级别专属除外。噪声：1991 年第一百三十条缺席判决。民诉解释第二百二十三条。
- 第三十四条专属、第十八条至第二十一条级别、第三十六条共同管辖／最先立案。
- 保全红旗：第一百零三条至第一百零八条，运行时核验，不写保全终稿。
- 仲裁法（2025 修订，施行日 2026-03-01）已施行；MCP 标尚未施行以施行日为准。第四条无协议不受理。第五条有协议起诉原则上不受理。第二十七条书面三要素。第三十条独立性。第三十一条首次开庭前异议。起诉未声明有协议的效果运行时核验第三十七条。噪声：1994 年第三十七条；2017 年第十六条至第十九条、第二十六条。
- 民法典第五百六十五条：未通知而起诉主张解除，确认后自副本送达时解除。第五百六十七条结算清理。第五百七十七条不是当然解除。第五百八十五条约定金不是必得。

## 节点 3　诉状行 `QT#`

按已出现请求碎片扫描，不是默认闭集。每条须能指向请求、主体、仲裁、管辖或证据目录之一。

无 `E#` 不得写已立案。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止此致某院。

热冲突强制处理：

- 草稿即已立案／网交即已受理／有效仲裁仍应起诉／构成违约即当然解除／起诉当日即已解除／此致某院／约定金即必得／未知写零／七日立案已保证 → 该格不支持或字段停止；仍出其他 `QT#`。
- 无一碎片 → 关闸，不出 `QT#` 终稿，窗口不关。
- 指导伪造诉状、倒签、虚假诉讼、隐匿仲裁条款 → 整体停止，不是该格不支持。
- 有效仲裁未排除 → 该格不支持，不出起诉状终稿，窗口不关。

## 节点 4　论坛、保全、庭审接口

第 7 节只开接口，不得夹带 `QT#` 终稿或发送版起诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待请求编号」，不得补写已立案。不选定法院。不代提交。

下一步只转介：`评估合同争议`、`评估合同管辖与仲裁协议`、`提起合同仲裁`、`选择诉讼仲裁或督促程序`、`应对合同纠纷一审`、`谈判合同和解方案`、`建立合同争议证据案卷`、`测算违约金与损害赔偿`、`评估解除权是否成立`、`准备催告履行或补救通知`、`准备解除通知`、`准备合同财产保全申请`、`提起合同成立或效力确认之诉`、`准备合同案件庭审`、`申请合同金钱支付令`、`规划举证期限与证据交换`。禁止此致某院。有效仲裁不得写成应起诉。保全只列红旗。

若 if 用户催促「草稿写完就算立案了／网交回执就算受理／有仲裁也直接去某区法院／已经违约所以请求解除／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「起诉闸与诉状行草案」。本窗不执行发送。不包含：已立案、已受理、发送版起诉状、保全终稿、仲裁申请。禁止选边治愈。禁止草稿即已立案。禁止有效仲裁即应起诉。禁止指导伪造或虚假诉讼。起诉闸打开 ≠ 已立案 ≠ 应起诉 ≠ 管辖已定。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标起诉终稿已形成。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：买卖合同货款迟延，有合同和催告碎片，合同另有仲裁条款。用户主张草稿写完就算立案了、网交回执就算受理、有仲裁也直接去某区法院、已经违约所以请求解除且今天起诉就算解除、违约金按合同数字必得、不清楚的利息先写零。起诉闸打开或半开。`Q-签`、`Q-交`、`Q-仲`、`Q-违`、`Q-拟`、`Q-院`、`Q-必`、`Q-零` 不打开为可靠路径。第 6 节不得把已立案、已受理、应起诉、已解除、必得、0、此致某院写入可执行 `QT#`；对应格 `现有依据不支持` 或字段停止；仍出请求分列、主体、仲裁缺口、连结点并列等其他 `QT#`。不关窗。不代提交。不选定法院。

场景②：用户同时交出己方「必须今晚立案、落款改到上周、仲裁条款那页先抽掉」与对方「从未违约、有仲裁」口径。命中双方秘密＋倒签＋隐匿仲裁条款。第一次整体停止。只交第 1、10 节。不出 `QT#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代违法方案。
