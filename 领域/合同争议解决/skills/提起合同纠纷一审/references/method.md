# 起诉方法

本文件是可执行判断节点，不是栏目说明书。每个会改变诉讼请求、论坛入口、管辖连结点或起诉状表述的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然解除或唯一必得总额。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## 请求矩阵

固定列：`编号P#｜关系假设｜原告｜被告｜法律效果｜成立条件｜支持事实｜不利事实｜控制方｜最强反方｜主备位｜判断｜待核`。

解除确认、继续履行、违约金、赔偿、定金、返还清理分列。同一事实支持多项时分别说明效果，不重复金额。构成违约不等于当然解除。

## 节点 0　专项分流

先于起诉草稿。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节起诉包。

| 信号 | 转出 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定、实际施工人 | 建设工程领域 |
| 金融借贷、保证、抵押质押、保理、融资租赁主轴 | 金融借贷担保领域 |
| 商品房买卖、开发合作、物业服务主轴 | 房地产物业领域 |
| 海上货物、船舶、海事保全、港口作业 | 海事领域 |
| 劳动关系、劳动报酬、解除劳动合同、工伤待遇 | 劳动领域 |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

混合信号：一般买卖／服务主轴可留本任务；专项只作为背景时在缺口标明，不把专项规则硬套进一般合同起诉结论。

## 节点 1　起诉决定和仲裁阻却闸

1. 确认用户已决定起诉，而不是仍在比较催告、和解或仲裁。未决定则目标停止，转评估或相应原子。
2. 确认原告立场和授权。用户实际为被告：负触发至应诉原子。已有受理凭证、案号、立案通知：停止生成起诉入口，转审理阶段原子。
3. 同时掌握双方秘密或立场不明：整体停止策略输出。

### 1.1 仲裁协议优先闸

合同、补充协议或事后书面协议中出现仲裁条款时：

1. 不得直接写“应向法院起诉”。
2. 分列：是否书面；是否有请求仲裁的意思；仲裁事项是否覆盖本案；是否选定机构；是否或裁或诉；机构是否存在或可确定。
3. 或裁或诉、机构约定不明、未签字主体、格式仲裁条款提示说明不足：效力标 `依据不足`，转介 `assess-forum-and-arbitration`，本任务不出起诉状终稿。
4. 表面有效且无排除证据：负触发。论坛主位写成仲裁，转 `file-arbitration` 或论坛评估。
5. 排除必须可回链，例如：协议无效或失效的核验结论；双方已以应诉答辩等方式变更救济且符合现行规则；仲裁机构不予受理或撤销案件后依法可诉；法律另有规定。口头“对方同意去法院”或聊天已读，不得单独写成排除。
6. 合同无效、被撤销或终止，不当然消灭仲裁协议。独立性规则须运行时核验现行《仲裁法》文本，不得凭记忆写 2017 年第 16–19 条。

### 1.2 仲裁法版本

《仲裁法》版本与施行日运行时核验。无法核验或冲突时，仲裁效力、法院入口和起诉状终稿字段停止，转论坛评估。当事人达成仲裁协议后向法院起诉的效果，以核验后的现行文本为准，不得用内嵌日期代替 `L#`。

民事诉讼法第 127 条第二项：依照法律规定双方达成书面仲裁协议申请仲裁、不得向人民法院起诉的，告知原告向仲裁机构申请仲裁。本任务不得用立案登记制绕过该闸。

## 节点 2　主体适格与分项诉讼请求

运行时核验民事诉讼法第 122、124 条后再落判断。核验失败则请求法律结论字段停止，事实与证据清单继续。

### 2.1 主体

1. 原告须是与本案有直接利害关系的公民、法人或其他组织。签约名、履行名、付款名、发票名不一致不自动合并，并列主体假设。
2. 被告须明确：能够识别其身份的姓名或名称、住所或其他足以送达的信息。不知注册地址不等于可以写“某某公司（待查）”充作明确被告。
3. 共同被告、担保人、债务加入人分别判断是否具备请求基础，不把方便送达的主体写成责任主体。

### 2.2 请求分列

默认主位候选按事实分别建立，不得预先锁定解除：

- `P-履` 继续履行或补救（修理、更换、重作、减价）
- `P-解确` 确认合同已解除或解除行为有效
- `P-未解` 确认合同未解除或解除不发生效力
- `P-金` 违约金
- `P-损` 损害赔偿
- `P-定` 定金罚则（与违约金选用，不得双计）
- `P-清` 返还、折价、价款、质保金、发票配合
- `P-费` 诉讼费、保全担保损失等程序费用，仅在有依据时单列

成立、无效、撤销本身成为主请求时，转介 `file-validity-action` 可并行说明；确认解除效力或确认未解除由本任务列入 `P-解确`／`P-未解`，不要求先转效力确认之诉。

### 2.3 解除请求的时点

未通知对方而直接起诉主张解除：仅在裁判确认该主张后，合同自起诉状副本送达对方时解除（民法典第 565 条）。评估或起草阶段不得写“今日起诉即已解除”。没有送达事实和规则引文，禁止写“合同已解除”。微信已读不等于到达。

构成违约不等于当然解除。迟延主要债务原则上先核验催告与合理期限；无解除权的通知不因对方未异议而生效。解除后结算清理条款仍可能有效（第 567 条）。买卖合同解除后守约方主张继续适用违约金条款的，仍受第 585 条约束，不得把约定数字写成必得金额。

### 2.4 互斥

`P-履` 与 `P-解确` 不得同时写成均已成立的主位终局请求；可以主位／备位并列并写明选择关系。定金与违约金选用不明时两项都标待核，不输出相加总额。未知金额不写零。

## 节点 3　管辖连结点

本任务列连结点和风险，不在材料不足时指定唯一受诉法院，不保证该院受理。

### 3.1 法定连结

运行时核验现行民事诉讼法后再落判断。

| 连结点 | 规则锚点 | 本任务允许 | 禁止 |
| --- | --- | --- | --- |
| 被告住所地／经常居住地 | 运行时核验现行民诉法 | 自然人：住所与经常居住地分列；法人或其他组织：主要办事机构或登记住所，不把经常收货点写成住所 | 把临时收货点写成住所 |
| 合同履行地 | 运行时核验 | 约定履行地原文；无约定按标的性质列待核情景；合同未实际履行且双方住所地均不在约定履行地时单列回退规则待核 | 为挑法院把付款地和交货地同时写成唯一履行地 |
| 协议管辖 | 第 35 条 | 书面协议、实际联系、是否违反级别和专属 | 格式条款未提示却写成已排他选定 |
| 专属管辖 | 第 34 条 | 不动产、港口作业命中则整段停止或转出 | 用协议管辖覆盖专属 |
| 级别管辖 | 第 18–21 条及当地标准 | 标的额、是否重大涉外待核 | 为“好打”指定中院或基层 |

两个以上法院都有管辖权时，列出可选项和最先立案规则（第 36 条），由用户选定后写入起诉状抬头；用户未选定则草稿抬头留空并字段停止。

### 3.2 与仲裁闸的关系

有效仲裁未被排除时，本节点不把法院连结点展开成“可以去这些法院”，以免把负触发改写成起诉建议。

### 3.3 C 端 011

主体、请求、论坛均已闭合，用户只要大众网上立案材料包：可提及 C 端 011，但 `P#` 判断、互斥和仲裁闸仍由本任务完成。不得回改 011，不得把本包降成填空式立案页。冲突或无法判断走哪一端时字段停止，先澄清成果，不两边各做一份终稿。

## 节点 4　证据目录与保全红旗

### 4.1 证据目录

按待证事实绑定 `P#`。每份材料写：名称、证明目的、页数或电子标识、原件或复制件、取得方式、控制方、合法性、是否涉及商业秘密。

不能因对方控制而推定材料存在或内容有利。逾期举证风险只标接口，不在本任务制作完整证据卷（转 `build-evidence-record`）。禁止指导伪造、隐匿、违法取证。

起诉状法定事项包括证据和证据来源、证人姓名和住所（第 124 条）。目录可以简于专项案卷，但不得只有“合同一份”而无证明目的。

### 4.2 保全只做红旗

出现转移财产、抽逃出资、紧急毁损标的等迹象时，在红旗栏写：可能符合诉前或诉中保全的表面条件、担保和错误赔偿风险、诉前保全后须在法定期限内起诉（第 103–108 条，运行时核验）。

不写保全申请书终稿，不选定保全法院，不保证裁定。需要申请书时转 `prepare-preservation-application`。先予执行另项，不在本包展开。

## 节点 5　起诉状草稿与提交核验

1. 按第 123–124 条组织：当事人身份信息；诉讼请求和所根据的事实与理由；证据和证据来源。范本只借栏目，不复制与本案无关的请求。
2. 事实部分按时间线，区分 `A#` 一致事实与 `S#` 单方主张。理由部分逐项回链 `P#` 和 `L#`。不得把未核验规则写成已成立。
3. 请求栏使用可执行表述：给付写金额和期间；确认解除写确认对象和时点假设；继续履行写具体行为。禁止“判令被告承担全部法律责任”一类空请求。
4. 只交付草稿和提交核验清单：身份证明、主体资格、授权委托、证据副本份数、是否需要网上立案或现场提交。不代提交，不填写法院内部系统，不预测七日立案结果。
5. 符合起诉条件的，人民法院应当受理并在七日内立案（第 126 条）。该规则用于核验材料完备性，不得改写成“本院包提交后必然立案”。对书面仲裁协议、不属于受诉法院管辖等第 127 条情形，须在核验清单中预先标红。

登记立案不等于请求成立。任何稿件均须由用户或合格中国大陆法律专业人员复核后实施。

## 程序与期限表

程序动作记录机关、案号、文书、作出、收到、送达、效力。期限每行只对应一种期间类型和一个起算事件：诉讼时效、解除权除斥、质量异议期、约定催告期分列。日期冲突、送达不明：并行情景＋字段停止，不选对用户最有利的一天。已读不等于到达。

## 管辖连结点表

固定列：连结点类型、事实、条款定位、证据、是否违反级别或专属、与仲裁闸关系、判断、待核。

## 证据、反方和下一步

最强反方至少覆盖：仲裁协议、管辖、主体不适格、请求互斥、解除权不成立、违约金调整、减损和双方违约。下一步按期限灭失、易失证据、改变 `P#`、可逆性排序。

保全申请、仲裁申请、应诉、精算、完整证据卷只写转介条件和最小交接。禁止指导伪造、隐匿、威胁或违法取证。不保证受理或胜诉。
