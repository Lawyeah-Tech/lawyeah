# 边界与路由

## 正触发

一般合同已成争，用户已决定提起一审，无表面有效仲裁阻挡或阻挡已被可回链证据排除，需要起诉状、请求、管辖连结点、证据目录和保全红旗。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 尚未决定是否起诉，只要总图 | `评估合同争议` |
| 仲裁条款效力或或裁或诉未闭合 | `评估合同管辖与仲裁协议` |
| 仲裁条款表面有效且未排除，已决定走仲裁 | `提起合同仲裁` |
| 只要发送版催告或解除函 | `准备催告履行或补救通知` 或 `准备解除通知` |
| 只要确认之诉且成立效力本身是主轴 | `提起合同成立或效力确认之诉` 可并行说明；解除效力确认由本任务承接 |
| 只要保全申请终稿 | `准备合同财产保全申请` |
| 已收到起诉状，用户为被告 | `应对合同纠纷一审` |
| 只要和解方案 | `谈判合同和解方案` |
| 工程／金融／房产／海事／劳动 | 对应领域整案转出 |
| C 端 011 只要大众网上立案包 | 只分流，不回改；本任务仍可保留专业请求判断 |
| C 端 032／012 | 大众专项，只分流，不回改、不实施 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全、港口作业专属 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

请求尚未闭合、仍在比较催告、解除或和解时负触发至评估或相应原子。仲裁条款存在且未被排除时，即使当事人情绪上要“直接去法院”，本任务负触发，不得改写成立案原子。确认解除效力或确认未解除由本任务列入请求，不要求先转效力确认之诉，除非成立、无效、撤销本身才是主请求。用户只要 011 材料包且请求论坛已闭合：提及 011，但请求判断仍由本任务完成。
