# 边界与路由

## 正触发

一般合同已成争，用户已决定向人民法院提起一审，需要起诉状草稿、分项请求、仲裁接口、管辖连结点和证据目录。从零、碎片、仲裁未核验、无书面起诉授权仍正触发：有可编号原告适格、请求类型或合同碎片则闸开或半开，出 `QT#` 草案，保持草案。表面有效仲裁未排除仍正触发：该格不支持，不出起诉状终稿，窗口不关。本次不代提交、不选定法院、不保证立案是交付禁令，不是开窗条件。草稿即已立案、有效仲裁仍应直接起诉、构成违约即当然解除，仍正触发。

双方秘密、伪造诉状或连结点、倒签落款、隐匿仲裁条款、虚假诉讼、伪造送达、违法取证的停止，优先于负触发。上述信号不在下表。不代提交不是负触发。「草稿即已立案」「网交即已受理」「有效仲裁仍应直接起诉」「构成违约即当然解除」「起诉当日即已解除」「此致某院即管辖已定」不在下表。

| 主要目标 | 路由 |
| --- | --- |
| 争议总图 | `评估合同争议` |
| 管辖或仲裁协议评估终稿 | `评估合同管辖与仲裁协议` |
| 仲裁申请包 | `提起合同仲裁` |
| 发送版催告 | `准备催告履行或补救通知` |
| 发送版解除通知 | `准备解除通知` |
| 证据案卷终稿 | `建立合同争议证据案卷` |
| 精算工作表 | `测算违约金与损害赔偿` |
| 保全申请终稿 | `准备合同财产保全申请` |
| 答辩包，用户为被告 | `应对合同纠纷一审` |
| 和解方案 | `谈判合同和解方案` |
| 成立、无效或撤销确认之诉终稿 | `提起合同成立或效力确认之诉` |
| 情势变更之诉终稿 | `提起情势变更变更或解除之诉` |
| 支付令申请 | `申请合同金钱支付令` |

不得因「不代提交」或「不保证立案」关窗。拟起诉包仍正触发，不得写成已立案或应起诉。确认解除或确认未解除由本窗承接，不要求先转效力确认之诉。

## 易混

本窗闸名只能是起诉闸，不是立案闸，不是管辖闸，不是论坛闸，不是证据闸。`QT#` 不是 `SZ#`，不是 `P#`，不是 `J#`，不是 `LA#`。主路径是 `Q-诉`，不是 `Q-管`，不是 `Q-坛`，不是 `Q-辩`。`Q-管` 是公司治理管辖窗主路径，本窗不打开。有效仲裁未排除：该格不支持，不出起诉状终稿，不是负触发关窗；主成果才转论坛或仲裁窗。草稿不是已立案。网交不是已受理。构成违约不是当然解除。起诉当日不是已解除。此致某院不是管辖已定。1991 年第一百二十二条不是现行起诉条件。1991 年第一百三十条不是现行管辖异议。2017 年第一百十九条、第二十三条、第三十四条、第一百二十七条不是现行。仲裁法 1994 年第三十七条不是现行起诉未声明规则。已失效《合同法》不是现行。「落款改到上周」「仲裁条款那页先抽掉」整体停止。本窗不执行发送，不代提交。不选定法院。不保证七日立案。
