# 边界与路由

## 正触发

一般买卖、服务或承揽已成争，争质量、隐蔽瑕疵或验收异议。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 建设工程质量 | 建设工程领域 |
| 产品伤人 | 侵权领域 |
| 期间是否逾期的精算表 | `评估争议期间` |
| 鉴定申请 | `准备质量或损失鉴定申请` |
| 现场或电子保全 | `保全质量现场与电子证据` |
| 解除权 | `评估解除权是否成立` |
| 竞合选择 | `选择合同违约与侵权竞合路径` |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，只分流不回改 |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

已成争、要判断检验通知和瑕疵因果时正触发。工程验收或造价鉴定负触发。只要鉴定文书时转鉴定原子。
