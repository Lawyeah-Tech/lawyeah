# 边界与路由

## 正触发

一般合同已成争，需要核验标的质量是否可能构成瑕疵、检验或异议期间是否可能届满。从零、碎片、通知未核验、无书面评估授权仍正触发：有可编号标的、批次、标准、交付或检验异议碎片则闸开或半开，出 `ZL#` 草案，保持草案。本次不写唯一截止日、不认定解除、不发函是交付禁令，不是开窗条件。签收即验收、构成瑕疵即当然解除，仍正触发。

双方秘密、伪造检验记录、倒签检验或异议日、隐匿通知、违法取证的停止，优先于负触发。上述信号不在下表。不认定解除不是负触发。「签收即验收」「质保期即检验异议期」「付款或使用即放弃异议」「构成瑕疵即当然解除」「唯一截止日」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 期间精算表 | `评估争议期间` |
| 解除权实体终稿 | `评估解除权是否成立` |
| 鉴定申请 | `准备质量或损失鉴定申请` |
| 现场或电子保全 | `保全质量现场与电子证据` |
| 争议总图 | `评估合同争议` |
| 完整时间线 | `建立双向履行时间线` |
| 迟延拒绝或不完全履行形态终稿 | `评估迟延拒绝与不完全履行` |
| 发送版催告 | `准备催告履行或补救通知` |
| 发送版解除通知 | `准备解除通知` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |
| 工程竣工验收或造价／产品伤人／海事货损 | 对应领域 |

不得因「不写唯一截止日」或「不认定解除」关窗。拟质量评估仍正触发，不得写成已构成瑕疵或已解除。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、竣工验收、工程造价鉴定 | 建设工程领域 |
| 产品责任伤人 | 人身损害与侵权赔偿领域 |

一般买卖或服务夹带专项背景时，专项段只分流。出现「质量」「验收」「检验」一词不是转出。C 端只要大众验收填空页时只分流，不把本包降成填空式验收，不回改。

## 易混

本窗闸名只能是质量闸，不是瑕疵闸，不是验收闸，不是期间闸，不是时线闸，不是解除闸。`ZL#` 不是 `SX#`，不是 `QJ#`，不是 `JE#`，不是 `JC#`。主路径是 `Q-疵`，不是 `Q-质`，不是 `Q-历`，不是 `Q-期`，不是 `Q-除`。`Q-质` 是公司治理出质窗主路径，本窗不打开。签收不是验收。质保期不是检验异议期。付款或使用不是当然放弃异议。构成瑕疵不是当然解除。已失效合同法第一百五十七条、第一百五十八条不是现行。商品房催告后三个月不是一般买卖检验异议期。买卖解释 2012 年未改码文本不是现行第十二条至第十四条。「检验报告日期改到签收当日」整体停止。本窗不执行发送，不代提交。不选定法院。不认定解除。不写唯一截止日。不预测鉴定意见。
