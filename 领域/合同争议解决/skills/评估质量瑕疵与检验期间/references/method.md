# 质量瑕疵评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然结果或唯一必得总额。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。实务检索若出现“违约金不超过合同标的百分之三十”，记为噪声。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

应诉答辩或提出反诉，不等于当然放弃仲裁协议。解除通知到达对方时解除；未通知而起诉或申请仲裁主张解除的，仅在该主张获确认后，自起诉状或仲裁申请书副本送达时解除，不得把立案日写成解除时点。第 585 条“过分高于”对照违约造成的损失，不对照合同总价。

## 节点 1　标准和标的

1. 先固定标的描述、批次、序列号、交付日和验收文件。
2. 质量标准冲突：约定标准、强制标准、样品并行，不选对用户有利的一版。
3. 服务或承揽：成果与过程标准分列，不得套用买卖检验二年规则而不核验。
4. 建设工程、商品房质量、海事货损：整案转出。

若：无人伤但产品缺陷同时可走侵权 → 竞合接口转 `选择合同违约与侵权竞合路径`。
若：用户只要改验收条款 → 审查起草搁置。

## 节点 2　检验与通知

运行时核验第 621、622 条和买卖解释相关条文。

1. 约定检验期间过短，根据标的性质和交易习惯不足以完成通常检验的，视为没有约定。
2. 未约定：及时检验，在发现或应当发现的合理期间内通知。
3. 买卖数量或外观瑕疵，买受人自收到之日起二年未通知，视为符合约定；有质保期的按质保期。该二年为不变期间，须确认是否适用于本案合同类型。
4. 出卖人知道或应当知道不符合约定的，买受人不受通知时间限制。
5. 签收单“外观完好”不覆盖隐蔽瑕疵。付款或投入使用不当然放弃异议，另有约定除外。

日期冲突建并行情景，不输出唯一异议截止日。期间精算可转期间原子。

## 节点 3　瑕疵判断

1. 待证：不符合约定或通常标准的具体表现、检测方法、是否影响合同目的。
2. 轻微不影响使用的偏差，不得直接写成根本违约。
3. 因果：交付时已存在，还是使用、保管、改造导致。不明则 `依据不足`。
4. 对方最强反方必须写入：超期通知、使用不当、未按说明书、第三方损坏。
5. 禁止编造检测数据。

## 节点 4　效果

1. 违约责任首先是修理、更换、重作、退货、减少价款或报酬。
2. 损失赔偿受可预见、减损约束，金额转测算原子。
3. 第 585 条违约金对照损失，不对照合同总价。
4. 解除：只有目的不能实现或符合约定解除时才接口到解除权原子。本任务不发解除通知。

## 节点 5　鉴定与保全

1. 现场可能灭失：转 `保全质量现场与电子证据`。
2. 需要机构确认瑕疵或贬值：转 `准备质量或损失鉴定申请`。
3. 不预测鉴定意见，不写“鉴定后一定能赢”。

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。

下一步按期限灭失、易失证据、改变本任务结论、可逆性排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。

禁止指导伪造、隐匿、威胁或违法取证。未知金额不写零。不把应诉写成放弃仲裁。不把立案日写成解除时点。
