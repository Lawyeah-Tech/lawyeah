# 评估质量瑕疵与检验期间方法

本文件是可执行判断节点。签收不是验收。质保期不是检验异议期。付款或使用不是当然放弃异议。构成瑕疵不是当然解除。过短约定检验期不是全面闭集。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已构成瑕疵、已解除、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不预测鉴定意见。本窗闸名只能是质量闸，禁止复用瑕疵闸、验收闸、检验闸、期间闸、时线闸、解除闸、争议闸。预留不得占用：立案闸、鉴定闸、保全闸。本窗 `ZL#` 是质量行。主路径只用 `Q-疵`，禁止用 `Q-质`、`Q-历`、`Q-期`、`Q-除`、`Q-收`、`Q-签` 作主路径。本窗 `Q-签` 只作「评估即已构成瑕疵、已解除或已提交」不关窗码。本窗 `Q-收` 只作「签收即验收」不关窗码。英文 id 禁止使用，一律用中文技能名 `评估质量瑕疵与检验期间`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效合同法第一百五十七条、第一百五十八条、商品房催告后三个月、买卖解释 2012 年未改码文本、把签收写成验收或把构成瑕疵写成当然解除时记为噪声。禁止指导伪造检验记录或倒签异议日。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现标的碎片扫描，不是默认闭集。
`ZL#` 固定列：`编号｜标的与标准切片｜检验期间与通知｜外观隐蔽与因果｜补救减价赔偿接口｜解除与鉴定分流｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已构成瑕疵」或「已解除」。无 `E#` 不得写已构成瑕疵或已逾期视为合格。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-疵`。禁止 `SX#`、`QJ#`、`JE#`、`JC#`、`ZT#`、`A#`、`N#`。

口头「已经不合格了」「签收了就算验收」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：外观与隐蔽分列。约定检验期、合理期限、二年、质保期、明知例外分列。修理更换重作减价在解除之前可见。

## 节点 0　分流、立场、质量闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造检验记录、倒签检验或异议日、隐匿通知、违法取证不进负表。利益冲突未解不进整体停止。不写唯一截止日、不认定解除、不发函不是负触发。

整案转出只交付第 1、2、10 节，不出 `ZL#` 终稿。

| 主成果是鉴定申请 | 负触发 `准备质量或损失鉴定申请` |

| 主成果是争议总图 | 负触发 `评估合同争议` |

| 主成果是迟延拒绝或不完全履行形态终稿 | 负触发 `评估迟延拒绝与不完全履行` |

出现「质量」「验收」「检验」一词不是转出。

质量闸打开（可出 `ZL#` 草案，仍不得标「已构成瑕疵／已验收／已解除」）须同时满足：单方无冲突立场已闭合；主成果是质量瑕疵评估，不是期间精算、不是解除终稿、不是鉴定申请；至少一项可编号标的、批次、标准、交付或检验异议碎片。口头「已经不合格了」不算单独开闸材料。

质量闸部分打开：已有碎片，但标准、通知或外观隐蔽未闭合；对应格待核；仍交十节。无书面评估授权但单方立场已闭合且已有碎片：质量闸部分打开，仍交十节，不是整体停止。

质量闸关闭（仍正触发）：无一可编号碎片。「今天必须出已构成瑕疵／已解除终稿」而无最小碎片不得开闸。不出 `ZL#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `ZL#` 终稿，**第 7 节不得出鉴定意见、函或诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「签收即验收」「质保期即检验异议期」「付款或使用即放弃异议」「构成瑕疵即当然解除」「唯一截止日」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `ZL#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 质量闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造检验记录、倒签检验或异议日、隐匿通知或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 3　质量行 `ZL#`

按已出现标的碎片扫描，不是默认闭集。每条须能指向标准、检验期间、外观隐蔽或补救接口之一。

无 `E#` 不得写已构成瑕疵。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止唯一截止日。

热冲突强制处理：

- 签收即验收／质保期即检验异议期／付款或使用即弃权／构成瑕疵即当然解除／唯一截止日／未知写零 → 该格不支持或字段停止；仍出其他 `ZL#`。
- 无一碎片 → 关闸，不出 `ZL#` 终稿，窗口不关。
- 指导伪造检验记录、倒签、隐匿通知 → 整体停止，不是该格不支持。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：设备买卖，买方签收送货单载明型号规格，三周后发现隐蔽故障，合同有三十日检验期和一年质保。用户主张签收就算验收、过了三十天没权了、质保期就是检验期、已经付了款就不能再异议、不合格就能解除、最晚哪天通知写死、不清楚先写零。质量闸打开或半开。`Q-收`、`Q-质期`、`Q-用`、`Q-根`、`Q-日`、`Q-零` 不打开为可靠路径。第 6 节不得把已验收、已逾期闭集、已弃权、已解除、0、唯一截止日写入可执行 `ZL#`；对应格 `现有依据不支持` 或字段停止；仍出外观与隐蔽分列、过短约定仅管外观待核、质保与检验分列、明知例外缺口等其他 `ZL#`。不关窗。不写函。不认定解除。
