# 评估质量瑕疵与检验期间

## 任务目标

在明确、无利益冲突的单方立场下（主张请求或抗辩一方或其受托律师，互斥），形成质量瑕疵评估草案：质量闸、主体与强制接口、`Q#` 路径、`ZL#` 质量行（标的与标准切片／检验期间与通知／外观隐蔽与因果／补救减价赔偿接口／解除与鉴定分流／`E#` 回链）。本窗 `ZL#` 是质量行草案，不是已构成瑕疵证明，不是已验收，不是已解除，不是鉴定意见，不是唯一截止日。本窗闸名只能是质量闸，禁止复用瑕疵闸、验收闸、检验闸、鉴定闸、期间闸、时线闸、争议闸、解除闸、催告闸、证据闸、异议闸。预留不得占用：立案闸、鉴定闸、保全闸。本窗主行只能是 `ZL#`，禁止 `SX#`、`QJ#`、`JE#`、`CG#`、`JC#`、`ZT#`、`XC#`、`JY#`、`A#`。主路径只用 `Q-疵`，禁止用 `Q-质`、`Q-历`、`Q-期`、`Q-据`、`Q-告`、`Q-除`、`Q-总`、`Q-收`、`Q-签`、`Q-日`、`Q-现`、`Q-申鉴` 作主路径。邻窗 `Q-疵` 只作转介进本窗；本窗打开为主路径，不是已构成瑕疵、不是已解除。本窗 `Q-签` 只作「评估即已构成瑕疵、已解除或已提交」不关窗码。本窗 `Q-收` 只作「签收即验收」不关窗码。本窗 `Q-现` 只转介 `保全质量现场与电子证据`。本窗 `Q-申鉴` 只转介 `准备质量或损失鉴定申请`。质量闸打开不等于已构成瑕疵不等于已逾期视为合格不等于已解除不等于鉴定已成立不等于待提交终稿。签收不是验收。质保期不是检验异议期。付款或使用不是当然放弃异议。过短约定检验期不是全面闭集。构成瑕疵不是当然解除。二年不变期间不是诉讼时效。合理期限不是一律十五日或三个月。未知不写零。不写唯一截止日。不写发送版催告或解除函。不写诉状。不选定法院。不代提交。不定罪。不预测鉴定意见。伤残等级与本窗无关，禁止折入。

`depends-on` 为空。主成果是期间精算表转 `评估争议期间`。主成果是解除权实体终稿转 `评估解除权是否成立`。主成果是鉴定申请转 `准备质量或损失鉴定申请`。主成果是现场或电子保全转 `保全质量现场与电子证据`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：一般合同已成争，需要核验标的质量是否可能构成瑕疵、检验或异议期间是否可能届满。「已经不合格了」「过了就没权了」仍正触发，成果状态 `草案`。标准、交付、通知未核验仍正触发：有可编号标的、批次、标准、交付或检验异议碎片则质量闸打开或半开，第 6 节出 `ZL#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出已构成瑕疵／已解除终稿」才关闸，仍交十节，第 6 节不出 `ZL#` 终稿，第 7 节不得出鉴定意见、函或诉状，窗口不关。用户要把签收写成验收、把质保期写成检验异议期、把付款或使用写成放弃异议、把构成瑕疵写成当然解除、把未知写成零或唯一截止日，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `ZL#` 草案。不得因「不写唯一截止日」「不认定解除」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是期间精算表（转 `评估争议期间`）；
- 主成果是解除权实体终稿（转 `评估解除权是否成立`）；
- 主成果是鉴定申请（转 `准备质量或损失鉴定申请`）；
- 主成果是现场或电子保全（转 `保全质量现场与电子证据`）；
- 主成果是争议总图（转 `评估合同争议`）；
- 主成果是完整时间线（转 `建立双向履行时间线`）；
- 主成果是迟延拒绝或不完全履行形态终稿（转 `评估迟延拒绝与不完全履行`）；
- 主成果是发送版催告（转 `准备催告履行或补救通知`）；
- 主成果是发送版解除通知（转 `准备解除通知`）；
- 尚未成争，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）；
- 建设工程竣工验收或造价、产品责任伤人、海事货损专项主轴。

双方秘密、伪造检验记录、倒签检验或异议日、隐匿通知、违法取证**不在负触发表**，走整体停止。「签收即验收」「质保期即检验异议期」「付款或使用即放弃异议」「构成瑕疵即当然解除」「唯一截止日」「未知写零」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不写唯一截止日」「不给胜诉率」「不发解除函」是交付禁令，不是负触发。主成果才转；出现「质量」「验收」「检验」一词不是转出。

## 建立工作坐标

确认：评估授权；单方立场；合同及订单版本；标的批次与标准；交付签收；检验或异议通知；法域。

口头「已经不合格了」「签收了就算验收」「过了就没权了」只登记 `S#`／`V#`。不得升格已构成瑕疵、已验收或唯一截止日，**不得单独算作开闸材料**。可编号标的、批次、标准、交付或检验异议碎片可开闸。本窗不执行发送，不代提交，不写函或诉状，不预测鉴定意见。

立场只许主张请求或抗辩一方或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：质量闸关闭，仍交十节，不是整体停止。无书面评估授权但单方立场已闭合、且已有碎片：质量闸部分打开，仍交十节，不是整体停止。提出伪造检验记录、倒签检验或异议日、隐匿通知或违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`ZL#` 质量行；`V#` 版本；`E#` 证据形态回链（合同标准、交付签收、检验或异议通知形态，不是发送闸，不是已构成瑕疵证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`SX#`、`QJ#`、`JE#`、`JC#`、`ZT#`。技能正文中的条号是检索锚点，不是已核验 `L#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。未知不写零。签收 ≠ 验收。质保期 ≠ 检验异议期。付款或使用 ≠ 放弃异议。构成瑕疵 ≠ 当然解除。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或裁判案例检索。本窗是评估，**不要**用 `search_template` 生成验收证明、异议函、解除函或诉状。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现签收即验收、质保期即检验异议期、付款即弃权、构成瑕疵即当然解除的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效合同法第一百五十七条、第一百五十八条当作现行规则。不得把商品房买卖合同解释催告后三个月套一般买卖检验异议期。不得把买卖解释 2012 年未改码文本第十五条至第二十条当现行。MCP 效力字段与公布施行日冲突时，以施行日为准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的瑕疵、期间或解除结论保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民法典第六百二十条买受人收到标的物时应当在约定的检验期限内检验；没有约定的应当及时检验。第六百二十一条约定检验期限内通知；未约定则发现或应当发现的合理期限内通知；自收到之日起二年内未通知视为符合约定；有质量保证期的适用质量保证期，不适用该二年；出卖人知道或应当知道不符合约定的，买受人不受通知时间限制。约定、合理期限、二年、质保期、明知例外分列，不写唯一截止日。第六百二十二条约定过短难以完成全面检验的，该期限仅视为外观瑕疵异议期限；短于法律行政法规规定期限的以规定为准。第六百二十三条未约定检验期限、签收单载明数量型号规格的，推定已对数量和外观瑕疵检验，相反证据可推翻；不是隐蔽瑕疵已验，不是放弃质量异议。第五百八十二条质量不符合约定，对方可请求修理、重作、更换、退货、减少价款；构成瑕疵不是当然解除。买卖解释（2020 修正）第十二条合理期限综合判断；二年是最长合理期限且为不变期间，不适用诉讼时效中止中断延长。第十三条合理期限内异议后，付款、确认欠款、使用不当然弃权，另有约定除外。第十四条检验、合理或二年期限经过后主张不符原则上不予支持；自愿承担后不得以经过翻悔。承揽第七百八十一条只开接口，不得直接套买卖二年。噪声：已失效合同法第一百五十七条、第一百五十八条；商品房催告后三个月；合理期限一律十五日；工矿产品购销合同条例已失效。技能正文条号不是 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变检验期间、外观隐蔽切开或弃权的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补签收不是验收、质保期不是检验异议期、付款或使用不是当然弃权、过短约定不是全面届满、构成瑕疵不是当然解除的实务反例。
- `search_case_by_fact` 只比较事实差异与翻转条件：签收不是验收；付款使用不是弃权；过短约定不是全面检验届满；逾期通知不是当然失权（明知例外）；瑕疵不是当然解除。无类案不得写成已构成瑕疵、已逾期或唯一截止日。评估类禁止用 `search_template` 生成验收证明、异议函或解除函。

工具不可用时继续标的碎片和 `ZL#` 编目；瑕疵、期间、解除结论字段停止。不得拒跑，不得凭记忆写成已构成瑕疵、已验收或唯一截止日。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、质量闸与不关窗

主成果才整案转出。双方秘密、伪造检验记录、倒签第一次停。签收即验收、构成瑕疵即解除不关窗。闸关仍交十节，第 6 节不出 `ZL#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

标的批次、标准、外观与隐蔽分列。本节禁止出 `ZL#` 终稿。

### 3. 质量闸与路径 `Q#`

本节禁止出 `ZL#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-疵`。

### 4. 质量行 `ZL#`

标的与标准、检验期间与通知、外观隐蔽与因果、补救接口。状态 `草案`。禁止升格已构成瑕疵、已验收、已解除、唯一截止日。无 `E#` 不得写已构成瑕疵。

### 5. 期间、解除、鉴定、时线接口

期间精算转期间窗。解除实体转解除窗。鉴定转鉴定窗。第 7 节不得夹带 `ZL#` 终稿或解除函绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造检验记录、倒签检验或异议日、隐匿通知或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：质量闸关闭，仍交十节，不是整体停止。无书面评估授权但有碎片：质量闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：标准、检验期间、通知到达、明知例外、施行日未核验。签收即验收、质保期即检验异议期、付款或使用即弃权、构成瑕疵即当然解除、唯一截止日、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `ZL#` 草案。
- `目标停止`：主目标变为期间精算表、解除权实体终稿、鉴定申请或保全终稿。禁止把「签收即验收」当作用户错误主张时的目标停止；那是不关窗。

禁止指导伪造检验记录或倒签异议日。不给胜诉率。不定罪。不选定法院。不代提交。未知不写零。不写唯一截止日。不预测鉴定意见。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。质量闸关闭仍交十节，第 6 节不出 `ZL#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `ZL#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。质量闸未打开时不得交付「已构成瑕疵」或「已解除」。边界见 [路由](references/routing.md)。
