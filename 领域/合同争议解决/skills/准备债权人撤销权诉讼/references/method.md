# 准备债权人撤销权诉讼方法

本文件是可执行判断节点。草稿不是已提交。评估不是已撤销成立。共同被告是债务人和相对人。除斥不是时效。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已提交、已立案、已撤销成立、选定法院、代提交、未知写零。本任务不定罪，不写发送版起诉状，不把草稿写成已提交。本窗闸名只能是撤诉闸，禁止复用起诉闸、撤权闸、位诉闸、撤销闸。预留不得占用：立案闸、催告闸、解除闸、发送闸。本窗 `XQ#` 是撤诉行。主路径只用 `Q-撤诉`，禁止用 `Q-撤`、`Q-位诉`、`Q-诉`、`Q-签` 作主路径。本窗 `Q-签` 只作「草稿即已提交或已立案」不关窗码。英文 id 禁止使用，一律用中文技能名 `准备债权人撤销权诉讼`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991 年民诉第一百二十二条开庭通知、2017 年第一百十九条、已失效合同法第七十四条、第七十五条、解释（一）第二十四条、把代位节第三十五条至第三十七条套本窗列法时记为噪声。禁止指导伪造低价或无偿证据。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现请求碎片扫描，不是默认闭集。
`XQ#` 固定列：`编号｜请求切片｜原告适格与债务人相对人共同被告列法｜管辖与仲裁接口｜除斥一年五年与范围费用返还｜证据目录处分对价明知与保全红旗｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已提交」或「已立案」。无 `E#` 不得写已提交。列法或除斥未闭合不得标 `待提交`。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-撤诉`。禁止 `CQ#`、`WQ#`、`DQ#`、`QT#`、`CX#`、`A#`、`N#`。

口头「今晚交出去」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：共同被告是债务人和相对人。管辖是被告住所地，专属除外。除斥不适用中止中断。

## 节点 0　分流、立场、撤诉闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造低价或无偿、倒签、虚假诉讼不进负表。利益冲突未解不进整体停止。不代提交、不选定法院不是负触发。把草稿写成已提交、把除斥写成时效不是负触发。

整案转出只交付第 1、2、10 节，不出 `XQ#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是撤销条件评估终稿 | 负触发 `评估债权人撤销权` |
| 主成果是代位起诉材料 | 负触发 `准备代位权诉讼材料` |
| 主成果是无效确认诉状 | 负触发 `提起合同成立或效力确认之诉` |
| 主成果是普通给付诉状 | 负触发 `提起合同纠纷一审` |
| 主成果是破产撤销 | 整案转破产领域 |
| 主成果是家事赠与析产 | 整案转婚姻家事 |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 尚未评估撤销条件，只要策略 | 负触发 `评估债权人撤销权` |
| 「不代提交」「不选定法院」 | 交付禁令，不是负触发 |

出现「撤销」「起诉」一词不是转出。

撤诉闸打开（可出 `XQ#` 草案，仍不得标「已提交／已立案／已撤销成立」）须同时满足：单方无冲突立场已闭合；主成果是撤销起诉材料草稿，不是发送版终稿；至少一行可编号债权人债权、处分行为或起诉决定碎片。口头「今晚交出去」不算单独开闸材料。

撤诉闸部分打开：已有碎片，但列法、除斥或范围未闭合；对应格待核；仍交十节。无书面授权但单方立场已闭合且已有碎片：撤诉闸部分打开，仍交十节，不是整体停止。

撤诉闸关闭（仍正触发）：无一可编号碎片。「今天必须出已提交／已立案终稿」而无最小碎片不得开闸。不出 `XQ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `XQ#` 终稿，**第 7 节不得出发送版起诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已提交」「评估即已撤销成立」「除斥即时效」「只列一方仍可交终稿」「此致某院即管辖已定」「除斥届满仍要可提交终稿」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `XQ#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 撤诉闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造低价或无偿证据、倒签处分或除斥起算、隐匿责任财产、虚假诉讼或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个请求切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `XQ#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 列法 | 原告债权人、共同被告债务人与相对人分列 | 只列一方；套代位「相对人被告、债务人第三人」；解释（一）第二十四条 |
| 管辖 | 债务人或者相对人住所地、专属除外分列 | 此致某院；套代位第三十五条 |
| 除斥 | 知悉一年、行为发生五年分列 | 除斥当时效中止中断；已读当知悉起算 |
| 范围 | 可分／不可分、返还向债务人分列 | 可分标的全部撤销；返还当优先受偿 |
| 对价 | 市价或指导价、明知分列 | 七十％当唯一；无偿须相对人恶意 |

检索锚点（写入 `L#` 前须核验）：见技能正文 MCP 节。噪声：1991 年民诉第一百二十二条；2017 年第一百十九条；解释（一）第二十四条；代位节第三十五条至第三十七条。

## 节点 3　撤诉行 `XQ#`

按已出现请求碎片扫描，不是默认闭集。每条须能指向列法、除斥、范围或证据目录之一。

无 `E#` 不得写已提交。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止唯一截止日。列法或除斥未闭合不得标 `待提交`。除斥可能届满不得标 `待提交`。

热冲突强制处理：

- 草稿即已提交／评估即已撤销成立／除斥即时效／只列一方仍可交终稿／此致某院即管辖已定／未知写零 → 该格不支持或字段停止；仍出其他 `XQ#`。
- 无一碎片 → 关闸，不出 `XQ#` 终稿，窗口不关。
- 指导伪造低价、无偿、倒签、虚假诉讼 → 整体停止，不是该格不支持。

## 节点 4　评估、代位诉材、无效确认、保全接口

第 7 节只开接口，不得夹带 `XQ#` 终稿或发送版起诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待列法编号」，不得补写已提交。不选定法院。不代提交。不写发送版起诉状。

下一步只转介：`评估债权人撤销权`、`评估债权人代位权`、`准备代位权诉讼材料`、`评估债权转让与债务承担争议`、`评估合同争议`、`评估合同成立与效力`、`评估合同管辖与仲裁协议`、`提起合同纠纷一审`、`应对合同纠纷一审`、`建立合同争议证据案卷`、`评估争议期间`、`评估合同财产保全必要性`、`准备合同财产保全申请`、`申请律师调查令或法院调查取证`、`选择诉讼仲裁或督促程序`、`提起合同仲裁`。禁止此致某院。

若 if 用户催促「今晚交出去／只告相对人／过了一年还能中断／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「撤诉闸与撤诉行草案」。本窗不执行发送。不包含：已提交、已立案、已撤销成立、发送版起诉状。禁止选边治愈。禁止草稿即已提交。禁止只列一方。禁止指导伪造。撤诉闸打开 ≠ 已提交 ≠ 已立案 ≠ 已撤销成立。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标撤诉终稿已形成。
风险档 A：伪造低价或无偿、倒签、虚假诉讼必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：债权人已决定起诉撤销低价转让，草稿只列相对人为被告，除斥一年可能届满仍要可提交终稿，此致某院先填某中院，主张今晚交出去就算已提交、评估过就算已撤销成立、过了一年还能中断、不清楚先写零。撤诉闸打开或半开。`Q-签`、`Q-状`、`Q-时`、`Q-列`、`Q-院`、`Q-零` 不打开为可靠路径。第 6 节不得把已提交、已撤销成立、除斥可中断、0 写入可执行 `XQ#`；对应格 `现有依据不支持` 或字段停止；仍出共同被告分列、除斥一年五年并行、范围可分缺口等其他 `XQ#`。不关窗。不代提交。不写发送版。

场景②：用户同时交出己方「把转让日改到五年内、评估报告用空白章补一份」与对方「市价就是这个价」口径，并要「先立案再说」。命中双方秘密＋倒签＋伪造。第一次整体停止。只交第 1、10 节。不出 `XQ#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代违法方案。
