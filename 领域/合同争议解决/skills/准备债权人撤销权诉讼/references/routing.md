# 边界与路由

## 正触发

已决定起诉请求撤销债务人无偿或明显不合理处分。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 尚未评估 | `评估债权人撤销权` |
| 合同无效确认 | `提起合同成立或效力确认之诉` |
| 代位诉讼 | `准备代位权诉讼材料` |
| 破产撤销 | 破产领域 |
| 保全 | `准备合同财产保全申请` |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，只分流不回改 |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

已决定打撤销权之诉时正触发。要确认合同自始无效时转效力确认之诉。破产撤销转破产。
