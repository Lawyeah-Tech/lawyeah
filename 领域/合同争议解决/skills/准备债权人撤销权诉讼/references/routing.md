# 边界与路由

## 正触发

已决定起诉请求撤销债务人无偿或明显不合理处分，需要起诉材料草稿。从零、碎片、列法未核验、无书面授权仍正触发：有可编号债权人债权、处分行为或起诉决定碎片则闸开或半开，出 `XQ#` 草案，保持草案。本次不代提交、不选定法院是交付禁令，不是开窗条件。草稿即已提交、评估即已撤销成立、只列一方仍可交终稿，仍正触发。把除斥写成时效、把除斥届满仍写成可提交终稿，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造低价或无偿、倒签、虚假诉讼的停止，优先于负触发。上述信号不在下表。不代提交不是负触发。「草稿即已提交」「评估即已撤销成立」「除斥即时效」「只列一方仍可交终稿」「此致某院即管辖已定」「除斥届满仍要可提交终稿」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 撤销条件评估终稿 | `评估债权人撤销权` |
| 代位起诉材料 | `准备代位权诉讼材料` |
| 无效确认诉状 | `提起合同成立或效力确认之诉` |
| 普通给付诉状 | `提起合同纠纷一审` |
| 破产撤销 | 破产领域 |
| 家事赠与析产 | 婚姻家事 |
| 争议总图 | `评估合同争议` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |
| 尚未评估撤销条件，只要策略 | `评估债权人撤销权` |

不得因「不代提交」或「不选定法院」关窗。拟撤诉草稿仍正触发，不得写成已提交或已立案。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 破产法撤销、偏颇清偿 | 破产领域 |
| 夫妻赠与、父母子女赠与主轴 | 婚姻家事 |
| 意思表示欺诈胁迫重大误解撤销 | `评估合同成立与效力` 或 `提起合同成立或效力确认之诉` |

一般买卖或服务夹带专项背景时，专项段只分流。出现「撤销」「起诉」一词不是转出。C 端只要大众撤销填空页时只分流，不把本包降成填空式起诉，不回改。

## 易混

本窗闸名只能是撤诉闸，不是起诉闸，不是撤权闸，不是位诉闸，不是撤销闸。`XQ#` 不是 `CQ#`，不是 `WQ#`，不是 `CX#`。主路径是 `Q-撤诉`，不是 `Q-撤`，不是 `Q-位诉`，不是 `Q-诉`。`撤权闸`／`Q-撤` 是评估债权人撤销权。`位诉闸`／`WQ#`／`Q-位诉` 是准备代位权诉讼材料。`CX#` 是公司治理程序行。草稿不是已提交。评估不是已撤销成立。共同被告是债务人和相对人，禁止套代位「相对人被告、债务人第三人」。除斥不是时效。MCP 查询第一百二十二条可能先返回 1991 年开庭通知条，须核 2023 修正起诉条件。2017 年第一百十九条不是现行。已失效合同法第七十四条、第七十五条及解释（一）第二十四条不是现行。代位节第三十五条至第三十七条不是本窗列法。「今晚交出去」「转让日改到五年内」整体停止。本窗不执行发送，不代提交。不选定法院。不写发送版起诉状。
