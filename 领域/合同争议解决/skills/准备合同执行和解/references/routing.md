# 边界与路由

## 正触发

一般合同已进入执行，拟分期、以物抵债或第三人代履行，需要执行和解要点或协议草稿。从零、碎片、笔录或弃权未核验仍正触发：有可编号执行案号、执行通知或裁定、已生效名义碎片则闸开或半开，出 `TH#` 草案，保持草案。本次不代提交、不保证中止、不提供隐匿转移方案是交付禁令，不是开窗条件。草稿即已中止、私下即已可强制执行，仍正触发。把不履行写成不可恢复、把沉默写成弃权，仍正触发：该格不支持，不改负触发关窗。

双方秘密、隐匿转移、伪造笔录的停止，优先于负触发。上述信号不在下表。不代提交不是负触发。「草稿即已记入笔录」「私下即已可强制执行」「口头即已执和」「不履行不可恢复」「沉默即弃权」「分期即消灭名义」「以物抵债即裁定或已过户」「保证中止」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 申请执行包 | `执行合同生效文书` |
| 被执行应对终稿 | `应对合同案件执行` |
| 诉前或诉中普通和解正文 | `起草合同和解协议` |
| 谈判方案要点 | `谈判合同和解方案` |
| 赋强公证或司法确认手续 | `办理合同和解执行力补强` |
| 调解利弊 | `评估合同调解方案与效力` |
| 不予执行申请 | `申请不予执行仲裁裁决` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不代提交」或「不提供隐匿转移方案」关窗。拟执和草稿仍正触发，不得写成已记入笔录或已中止。

## 易混

本窗闸名只能是执和闸，不是和解闸，不是执行闸，不是应执闸，不是力补闸，不是调解闸，不是方案闸。`TH#` 不是 `HJ#`，不是 `ZE#`，不是 `YE#`，不是 `QF#`，不是 `FA#`，不是 `TJ#`。主路径是 `Q-执和`，不是 `Q-执`，不是 `Q-执申`，不是 `Q-应执`，不是 `Q-和`，不是 `Q-力`。`和解闸`／`HJ#`／`Q-和` 是起草合同和解协议。`执行闸`／`ZE#`／`Q-执申` 是执行合同生效文书。`应执闸`／`YE#`／`Q-应执` 是应对合同案件执行。`力补闸`／`QF#`／`Q-力` 是办理合同和解执行力补强。`Q-执` 是不关窗码。1991 年第二百四十一条不是执行和解。2017 年第二百四十一条不是现行第二百四十一条。2017 年第二百三十条不是现行。解释第四百六十六条仍引第二百四十六条须核第二百五十条。规定第六条不得依以物抵债协议作出以物抵债裁定。提出「把房子今晚过户给亲戚、和解日改到上周」整体停止。本窗不代提交。不选定法院。不写发送版。不保证中止或终结。不提供隐匿转移方案。
