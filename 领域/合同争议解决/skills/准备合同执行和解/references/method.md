# 准备合同执行和解方法

本文件是可执行判断节点。草稿不是已记入笔录。私下和解不是已可强制执行。不履行可申请恢复原生效文书。沉默不是弃权。以物抵债不是已裁定。未知不写零。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止到位率、已中止、已终结、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不把草稿写成已记入笔录，不提供隐匿转移方案。本窗闸名只能是执和闸，禁止复用和解闸、执行闸、应执闸、力补闸、调解闸、方案闸。预留不得占用：立案闸、保全闸、执行闸、应执闸。本窗 `TH#` 是执和行。主路径只用 `Q-执和`，禁止用 `Q-执`、`Q-执申`、`Q-应执`、`Q-和`、`Q-力`、`Q-签` 作主路径。本窗 `Q-执` 只作「私下和解即已可强制执行、执和即新执行名义或已恢复」不关窗码。本窗 `Q-签` 只作「草稿即已记入笔录、已提交、已中止或已终结」不关窗码。英文 id 禁止使用，一律用中文技能名 `准备合同执行和解`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991 年第二百四十一条外国人委托中国律师、2017 年第二百四十一条旧报告财产、2017 年第二百三十条旧和解、1991 年第二百一十一条、解释第四百六十六条仍引第二百四十六条未核第二百五十条、把草稿写成已中止时记为噪声。禁止指导隐匿转移、伪造笔录或逃废。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现执行碎片扫描，不是默认闭集。
`TH#` 固定列：`编号｜执行案与名义切片｜分期或抵债方案｜弃权边界（本金／迟延利息／迟延履行金）｜违约恢复执行｜抵债物权属与负担｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已记入笔录」或「已中止」。无 `E#` 不得写已记入笔录。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-执和`。禁止 `HJ#`、`ZE#`、`YE#`、`QF#`、`FA#`、`A#`、`N#`。期限与弃权嵌在十一列，禁止另开 `K#` 为主行。

口头「今晚签了就能停执行」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：记入笔录并由双方签名或盖章才是民诉意义上的执行和解。法院可以裁定中止，不是当然中止。不履行一般可申请恢复原文书。以物抵债不得依据该协议作出以物抵债裁定。不利证据必须进入最强反方。未知金额写 `未知`／`G#`，禁止写零。

## 节点 0　分流、立场、执和闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、隐匿转移、伪造笔录、倒签、逃废不进负表。利益冲突未解不进整体停止。不代提交、不保证中止、不提供隐匿转移方案不是负触发。

整案转出只交付第 1、2、10 节，不出 `TH#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是申请执行包 | 负触发 `执行合同生效文书` |
| 主成果是被执行应对终稿 | 负触发 `应对合同案件执行` |
| 主成果是诉前或诉中普通和解正文 | 负触发 `起草合同和解协议` |
| 主成果是谈判方案要点 | 负触发 `谈判合同和解方案` |
| 主成果是赋强公证或司法确认手续 | 负触发 `办理合同和解执行力补强` |
| 主成果是调解利弊 | 负触发 `评估合同调解方案与效力` |
| 主成果是不予执行申请 | 负触发 `申请不予执行仲裁裁决` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程／金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不代提交」「不保证中止或终结」「不提供隐匿转移方案」 | 交付禁令，不是负触发 |

出现「和解」「执行」「分期」「抵债」一词不是转出。

执和闸打开（可出 `TH#` 草案，仍不得标「已签署／已记入笔录／已中止／已终结」）须同时满足：单方无冲突立场已闭合；主成果是执行中和解草稿，不是执申包、不是应执终稿、不是诉前和解正文、不是力补手续；至少一项可编号执行案号、执行通知或裁定、已生效名义碎片。口头「已经和解了」不算单独开闸材料。

执和闸部分打开：已有碎片，但笔录形式、弃权或抵债物权属未闭合；对应格待核；仍交十节。无书面授权但单方立场已闭合且已有碎片：执和闸部分打开，仍交十节，不是整体停止。

执和闸关闭（仍正触发）：无一可编号碎片。「今天必须出已中止终稿」而无最小碎片不得开闸。不出 `TH#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `TH#` 终稿，**第 7 节不得出已中止或发送版**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已记入笔录」「私下即已可强制执行」「口头即已执和」「不履行不可恢复」「沉默即弃权」「分期即消灭名义」「以物抵债即裁定或已过户」「保证中止」「选定某院」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `TH#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 执和闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出隐匿转移、以执和逃废、伪造笔录或签章、倒签和解日或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 3　执和行 `TH#`

按已出现方案切片扫描，不是默认闭集。每条须能指向名义、分期或抵债、弃权、恢复或权属之一。

无 `E#` 不得写已记入笔录或已中止。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止唯一截止日。禁止写入已终结或新执行名义。

热冲突强制处理：

- 草稿即已记入笔录／私下即已可强制执行／口头即已执和／不履行不可恢复／沉默即弃权／分期即消灭名义／以物抵债即裁定或已过户／保证中止／未知写零 → 该格不支持或字段停止；仍出其他 `TH#`。
- 无一碎片 → 关闸，不出 `TH#` 终稿，窗口不关。
- 指导隐匿转移、伪造笔录、倒签、逃废 → 整体停止，不是该格不支持。

## 本任务回链纪律

本任务成果是「执和闸与执和行草案」。本窗不执行发送。不包含：已记入笔录、已中止、已终结、发送版、赋强终稿。禁止选边治愈。禁止私下即已可强制执行。禁止草稿即已中止。禁止指导隐匿。执和闸打开 ≠ 已记入笔录 ≠ 已中止 ≠ 已可强制执行。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：买卖尾款判决已立案执行，双方拟六期还款并口头说利息全免。用户主张微信签了就算停执行、私下协议就能当执行名义、没写利息就是放弃迟延利息、对方晚一期也不能恢复、不清楚的金额先写零、此致某中院保证中止。执和闸打开或半开。`Q-执`、`Q-签`、`Q-口`、`Q-弃`、`Q-复`、`Q-止`、`Q-院`、`Q-零` 不打开为可靠路径。第 6 节不得把已中止、已可强制执行、已弃权、0 写入可执行 `TH#`；对应格 `现有依据不支持` 或字段停止；仍出案号分列、第二百四十一条笔录红旗、弃权须明示、不履行可申请恢复等其他 `TH#`。不关窗。不代提交。不选定法院。

场景②：用户同时交出申请执行人「必须全额」与被执行人「今晚把房子过户给亲戚、和解日改到上周、笔录先按已签」口径。命中双方秘密＋隐匿转移＋倒签＋伪造。第一次整体停止。只交第 1、10 节。不出 `TH#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代违法方案。
