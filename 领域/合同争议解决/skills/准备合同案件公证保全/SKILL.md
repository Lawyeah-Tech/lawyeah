# 准备合同案件公证保全

## 任务目标

在明确、无利益冲突的单方立场下（拟申请保全证据公证一方或其受托律师，互斥），形成发送前公证申请与提纲草稿：公证闸、主体与强制接口、`Q#` 路径、`GD#` 公证行（公证切片／事项／机构与预约／检材／操作提纲／鉴定／法院证据保全／送达分流／`E#` 回链）。本窗 `GD#` 是公证行草案，不是已公证，不是已出证，不是鉴定意见，不是法院证据保全裁定，不是赋强执行证书。本窗闸名只能是公证闸，禁止复用现证闸、固证闸、申保闸、应保闸、要保闸、保全闸、封存闸、鉴定闸、证据闸、达证闸、公保闸、检材闸。预留不得占用：立案闸、和解闸、保全闸、鉴定闸。本窗主行只能是 `GD#`，禁止 `XZ#`、`SB#`、`NS#`、`YB#`、`BQ#`、`FC#`、`GZ#`、`GN#`、`JE#`、`CD#`、`A#`。主路径只用 `Q-公`，禁止用 `Q-现`、`Q-申保`、`Q-应保`、`Q-要`、`Q-保`、`Q-账`、`Q-据`、`Q-证`、`Q-道`、`Q-固`、`Q-签` 作主路径。邻窗 `Q-公` 只作转介进本窗；本窗打开为主路径，不是已公证、不是已出证、不是必然可采。本窗 `Q-现` 只转介 `保全质量现场与电子证据`。本窗 `Q-道` 只转介 `设计合同案件通知送达`。本窗 `Q-签` 只作「草稿即已公证、已出证或已提交」不关窗码。本窗 `Q-固` 只作「口头或已读即已固定」不关窗码。公证闸打开不等于已公证不等于已出证不等于已质证不等于必然可采不等于待提交终稿。草稿不是已公证。哈希不是已公证。截图不是原件。检材不是公证效力。申请不是已出证。口头或已读不是已固定。公证不是必然可采。送达过程公证不是已到达。鉴定性判断不属公证。赋强公证不是本窗。未知不写零。不代替鉴定。不代办理。不代提交。不选定唯一公证处。不定罪。不保证效力。不指导违法取证。伤残等级与本窗无关，禁止折入。

`depends-on` 为空。主成果是现场或电子合法自固转 `保全质量现场与电子证据`。主成果是鉴定申请终稿转 `准备质量或损失鉴定申请`。主成果是送达渠道设计且不要公证过程转 `设计合同案件通知送达`。主成果是赋强公证或执行证书转 `办理合同和解执行力补强`。主成果是证据案卷矩阵转 `建立合同争议证据案卷`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：一般合同已成争，需公证处固定发送过程或网页、聊天、物体现状。「怎么做网页公证」「催告寄出过程要公证」「哈希就算公证了」仍正触发，成果状态 `草案`，不代办理。事项、检材、机构未核验仍正触发：有可编号待公证事项或检材碎片则公证闸打开或半开，第 6 节出 `GD#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出已公证终稿」才关闸，仍交十节，第 6 节不出 `GD#` 终稿，第 7 节不得出公证书终稿或违法取证步骤，窗口不关。用户要把草稿写成已公证、把哈希写成已公证、把截图写成原件、把检材写成公证效力、把申请写成已出证、把公证写成必然可采或不可推翻、把未知写成零，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `GD#` 草案。不得因「不代替鉴定」「不保证效力」「不代办理」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是现场或电子合法自固步骤（转 `保全质量现场与电子证据`）；
- 主成果是鉴定申请终稿（转 `准备质量或损失鉴定申请`）；
- 主成果是送达渠道设计且不要公证过程（转 `设计合同案件通知送达`）；
- 主成果是赋强公证或执行证书（转 `办理合同和解执行力补强`）；
- 主成果是证据案卷矩阵（转 `建立合同争议证据案卷`）；
- 主成果是财产保全申请（转 `准备合同财产保全申请`）；
- 主成果是争议总图（转 `评估合同争议`）；
- 尚未成争，只要改合同、出稿或合同签字公证（审查起草领域，本窗搁置，只说明不实施）。

双方秘密、伪造聊天或时间戳、倒签提取日或公证日、对未发生过程作假、预先打开污染现场、补拍不存在页面、盗号侵入、购买非法数据、违法取证**不在负触发表**，走整体停止。「草稿即已公证」「哈希即已公证」「截图即原件」「检材即公证效力」「申请即已出证」「公证即必然可采或不可推翻」「未知写零」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不代替鉴定」「不保证效力」「不代办理」是交付禁令，不是负触发。STUB 把「要求保证公证效力不可推翻」放进负触发，必须改不关窗。违法取证**不是负触发**，第一次整体停止。主成果才转；出现「公证」「保全」一词不是转出。

## 建立工作坐标

确认：公证申请授权；单方立场；待证事项切片；检材与持有范围；拟预约机构；法域；当前诉讼、仲裁或发送状态。

口头「已经截过图了」「哈希就算公证了」「约了公证处就算出证」只登记 `S#`／`V#`。不得升格已公证、已出证或已固定，**不得单独算作开闸材料**。可编号待公证事项或检材碎片可开闸。本窗不执行发送，不代办理，不代提交。仅对己方合法持有或已同意接触的材料做公证提纲；对方控制场所强行进入或预先打开污染现场是违法取证。

立场只许拟申请保全证据公证一方或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：公证闸关闭，仍交十节，不是整体停止。无书面授权但单方立场已闭合、且已有碎片：公证闸部分打开，仍交十节，不是整体停止。提出伪造聊天或时间戳、倒签提取日或公证日、对未发生过程作假、预先打开污染现场、补拍不存在页面、盗号侵入、购买非法数据或违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`GD#` 公证行；`V#` 版本；`E#` 证据形态回链（事项、检材目录、预约栏目、操作提纲，不是发送闸，不是已公证证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`XZ#`、`SB#`、`NS#`、`YB#`、`GZ#`、`GN#`、`JE#`、`CD#`。技能正文中的条号是检索锚点，不是已核验 `L#`。文件状态只用 `草案`、`停止`。不得标已公证或待提交。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。未知不写零。草稿 ≠ 已公证。哈希 ≠ 已公证。截图 ≠ 原件。检材 ≠ 公证效力。申请 ≠ 已出证。公证 ≠ 必然可采。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或文书范本检索。本窗是公证申请与提纲准备，范本只借保全证据公证申请、送达过程公证申请、检材目录、操作提纲栏目，**不要**升格「已公证／已出证／必然可采」。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现哈希即已公证、截图即原件、公证即不可推翻、送达过程即已到达的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把 2005 年公证法文本未核 2017 修正当作现行。不得把 2017 年民事诉讼法第六十九条未核验对应现行第七十二条。不得把 1991 年民事诉讼法第八十四条公告送达当作证据保全或公证条。不得把知识产权民事诉讼证据规定第三十条或行政诉讼证据规定第六十四条套一般合同。MCP 可能先返回 2005 年公证法第三十六条「已被修改」。MCP 效力字段与公布施行日冲突时，以施行日为准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的可推翻、鉴定排除或施行日保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：公证法（2017 修正）第十一条第九项保全证据。第三十一条专业技术鉴定、评估不予办理；虚假材料或不真实不合法不予办理。第三十六条经公证的民事法律行为、有法律意义的事实和文书应当作为认定事实的根据，但有相反证据足以推翻该项公证的除外。第三十七条赋强债权文书只开接口，禁止把证据保全公证写成执行名义。噪声：2005 年文本未核 2017 修正。民事诉讼法（2023 修正，施行日 2024-01-01）第七十二条经过法定程序公证证明的法律事实和文书，人民法院应当作为认定事实的根据，但有相反证据足以推翻公证证明的除外。噪声：2017 年第六十九条旧号。民事诉讼证据规定（2019 修正，施行日 2020-05-01）第九十三条电子数据真实性综合判断，未公证不得写成虚假。第九十四条第一款五项可以确认真实性但有足以反驳的相反证据除外；第二款电子数据内容经公证机关公证的，人民法院应当确认其真实性，但有相反证据足以推翻的除外。禁止把第一款「可以」写成第二款「应当」，禁止把第九十四条写成不可推翻。第十五条电子数据应提供原件，截图不是原件。噪声：知识产权证据规定第十一条、第十五条、第三十条；监察或刑事电子数据提取规则；2002 年失效公证程序规则。技能正文条号不是 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变可推翻、鉴定排除或禁止取证方式的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补哈希不是已公证、截图不是原件、预先打开被质疑、公证只证提取过程不保证采信、送达公证不是到达、程序违法可能不予采信的实务反例。
- `search_template` 只借保全证据公证申请、送达过程公证申请、网页或电子证据保全操作记录、检材目录、询问或操作提纲栏目。范本出证栏、生效栏、落款日、此致某公证处不得升格已公证、已出证或已提交。禁止用鉴定申请书、法院证据保全申请书、赋强公证书、执行证书或起诉状改头换面。禁止用范本生成盗号、补拍不存在页面或已出证证明。

工具不可用时继续事项碎片和 `GD#` 编目；已公证、可推翻、受理、施行日字段停止。不得拒跑，不得凭记忆写成已公证或指导违法取证。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、公证闸与不关窗

主成果才整案转出。双方秘密、伪造过程、违法取证第一次停。哈希即已公证、公证即不可推翻不关窗。闸关仍交十节，第 6 节不出 `GD#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

发送过程／网页或聊天现状／物体现状分列。鉴定性判断关该事项，窗口不关。本节禁止出 `GD#` 终稿。

### 3. 公证闸与路径 `Q#`

本节禁止出 `GD#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-公`。

### 4. 公证行 `GD#`

切片、事项、机构与预约、检材与提纲、分流。状态 `草案`。禁止升格已公证、已出证、必然可采。无 `E#` 不得写已公证。

### 5. 现证、鉴定、达证、赋强与案卷接口

自固转现证窗。鉴定转鉴定窗。赋强转补强窗。第 7 节不得夹带 `GD#` 终稿或违法取证步骤绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造聊天或时间戳、倒签提取日或公证日、对未发生过程作假、预先打开污染现场、补拍不存在页面、盗号侵入、购买非法数据或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：公证闸关闭，仍交十节，不是整体停止。无书面授权但有碎片：公证闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：可推翻、鉴定排除、管辖预约、施行日未核验。草稿即已公证、哈希即已公证、截图即原件、检材即公证效力、申请即已出证、公证即必然可采、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `GD#` 草案。
- `目标停止`：主目标变为自固终稿、鉴定终稿、赋强终稿、已公证终稿或违法取证方案。禁止把「哈希即已公证」或「保证不可推翻」当作用户错误主张时的目标停止；那是不关窗。

禁止指导伪造过程或违法取证。不给胜诉率。不定罪。不选定唯一公证处。不代提交。未知不写零。不写已公证。不保证效力。不代替鉴定。
