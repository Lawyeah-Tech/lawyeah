# 准备合同案件公证保全方法

本文件是可执行判断节点。草稿不是已公证。哈希不是已公证。截图不是原件。检材不是公证效力。申请不是已出证。公证不是必然可采。送达过程公证不是已到达。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已公证、已出证、选定唯一公证处、代提交、未知写零。本任务不定罪，不代办理，不代替鉴定，不保证效力。本窗闸名只能是公证闸，禁止复用现证闸、固证闸、申保闸、鉴定闸、公保闸、检材闸。预留不得占用：立案闸、和解闸、保全闸、鉴定闸。本窗 `GD#` 是公证行。主路径只用 `Q-公`，禁止用 `Q-现`、`Q-据`、`Q-证`、`Q-道`、`Q-固`、`Q-签` 作主路径。本窗 `Q-签` 只作「草稿即已公证、已出证或已提交」不关窗码。本窗 `Q-固` 只作「口头或已读即已固定」不关窗码。英文 id 禁止使用，一律用中文技能名 `准备合同案件公证保全`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 2005 年公证法未核 2017 修正、2017 年民事诉讼法第六十九条、1991 年第八十四条公告送达、把哈希写成已公证时记为噪声。禁止指导伪造过程或违法取证。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事项切片扫描，不是默认闭集。
`GD#` 固定列：`编号｜公证切片｜事项｜机构与预约｜检材／操作提纲｜鉴定／法院证据保全／送达分流｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已公证」或「已出证」。无 `E#` 不得写已公证。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-公`。禁止 `XZ#`、`GZ#`、`GN#`、`JE#`、`SB#`、`CD#`、`A#`、`N#`。文件状态只用 `草案`、`停止`。

口头「已经截过图了」「哈希就算公证了」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：公证处只证明提取或发送过程，不保证必然可采。第九十四条第二款可被相反证据推翻。鉴定性判断不予办理公证。赋强债权文书不是本窗。提纲只允许己方合法持有或已同意接触。

## 节点 0　分流、立场、公证闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造过程、倒签、预先打开、补拍不存在页面、盗号侵入、违法取证不进负表。利益冲突未解不进整体停止。不代替鉴定、不保证效力、不代办理不是负触发。

整案转出只交付第 1、2、10 节，不出 `GD#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是现场或电子合法自固 | 负触发 `保全质量现场与电子证据` |
| 主成果是鉴定申请终稿 | 负触发 `准备质量或损失鉴定申请` |
| 主成果是送达渠道设计且不要公证过程 | 负触发 `设计合同案件通知送达` |
| 主成果是赋强公证或执行证书 | 负触发 `办理合同和解执行力补强` |
| 主成果是证据案卷矩阵 | 负触发 `建立合同争议证据案卷` |
| 主成果是财产保全申请 | 负触发 `准备合同财产保全申请` |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 尚未成争，只要改合同、出稿或合同签字公证 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程／金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不代替鉴定」「不保证效力」「不代办理」 | 交付禁令，不是负触发 |

出现「公证」「保全」一词不是转出。

公证闸打开（可出 `GD#` 草案，仍不得标「已公证／已出证／必然可采」）须同时满足：单方无冲突立场已闭合；主成果是公证申请与提纲，不是自固终稿、不是鉴定终稿、不是赋强、不是违法取证方案；至少一项可编号待公证事项或检材碎片。口头「哈希就算公证了」不算单独开闸材料。

公证闸部分打开：已有碎片，但机构、检材或可推翻未闭合；对应格待核；仍交十节。无书面授权但单方立场已闭合且已有碎片：公证闸部分打开，仍交十节，不是整体停止。

公证闸关闭（仍正触发）：无一可编号碎片。「今天必须出已公证终稿」而无最小碎片不得开闸。不出 `GD#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `GD#` 终稿，**第 7 节不得出公证书终稿或违法取证步骤**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已公证」「哈希即已公证」「截图即原件」「检材即公证效力」「申请即已出证」「公证即必然可采」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `GD#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 公证闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造过程、倒签、预先打开、补拍不存在页面、盗号侵入或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 3　公证行 `GD#`

按已出现事项切片扫描，不是默认闭集。每条须能指向事项、检材与提纲或分流之一。

无 `E#` 不得写已公证或已出证。状态默认 `草案`。一次只推荐下一步。未知不写零。哈希记录只作检材描述，不得写入已公证格。事项或机构未闭合不得标待提交。

热冲突强制处理：

- 草稿即已公证／哈希即已公证／截图即原件／检材即公证效力／申请即已出证／公证即必然可采／未知写零 → 该格不支持或字段停止；仍出其他 `GD#`。
- 无一碎片 → 关闸，不出 `GD#` 终稿，窗口不关。
- 指导伪造过程、预先打开、违法取证 → 整体停止，不是该格不支持。
