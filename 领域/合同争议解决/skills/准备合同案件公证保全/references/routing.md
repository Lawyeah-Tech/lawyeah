# 边界与路由

## 正触发

一般合同已成争，需公证处固定发送过程或网页、聊天、物体现状。从零、碎片、机构未核验、无书面授权仍正触发：有可编号待公证事项或检材碎片则闸开或半开，出 `GD#` 草案，保持草案。本次不代替鉴定、不保证效力、不代办理是交付禁令，不是开窗条件。哈希即已公证、公证即不可推翻，仍正触发。把草稿写成已公证、把截图写成原件，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造过程、违法取证的停止，优先于负触发。上述信号不在下表。不代替鉴定不是负触发。「草稿即已公证」「哈希即已公证」「截图即原件」「检材即公证效力」「申请即已出证」「公证即必然可采」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 现场或电子合法自固 | `保全质量现场与电子证据` |
| 鉴定申请终稿 | `准备质量或损失鉴定申请` |
| 送达渠道设计且不要公证过程 | `设计合同案件通知送达` |
| 赋强公证或执行证书 | `办理合同和解执行力补强` |
| 证据案卷矩阵 | `建立合同争议证据案卷` |
| 财产保全申请 | `准备合同财产保全申请` |
| 争议总图 | `评估合同争议` |
| 尚未成争，改合同、出稿或合同签字公证 | 审查起草领域（本窗搁置，只说明） |

不得因「不代替鉴定」或「不保证效力」关窗。拟公证申请与提纲仍正触发，不得写成已公证或必然可采。
