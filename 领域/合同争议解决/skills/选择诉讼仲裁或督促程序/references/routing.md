# 边界与路由

## 正触发

一般合同已成争，债权条件需要比较起诉、仲裁或支付令。从零、碎片、条款未核验仍正触发：有可编号请求、仲裁条款或金钱债权碎片则闸开或半开，出 `XH#` 草案，保持草案。本次不写完整申请书、不选定法院是交付禁令，不是开窗条件。有效仲裁仍应起诉、比较即已选定，仍正触发。把支付令写成已可执行、把或裁或诉写成当然有效，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造条款、隐匿仲裁、虚假诉讼的停止，优先于负触发。上述信号不在下表。不写完整申请书不是负触发。「有效仲裁仍应起诉」「比较即已选定」「支付令即已可执行」「保证更快」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 管辖或仲裁条款专项 | `评估合同管辖与仲裁协议` |
| 起诉包 | `提起合同纠纷一审` |
| 仲裁申请 | `提起合同仲裁` |
| 支付令申请书 | `申请合同金钱支付令` |
| 首次答辩 | `应对合同纠纷一审` 或 `应对合同仲裁` |
| 违约与侵权竞合择一 | `选择合同违约与侵权竞合路径` |
| 争议总图 | `评估合同争议` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不写完整申请书」或「不选定法院」关窗。拟路径比较仍正触发，不得写成已选定或应起诉。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤、劳动仲裁前置 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流。出现「仲裁」「起诉」「支付令」一词不是转出。C 端只要大众填空页时只分流，不把本包降成填空式结论，不回改。

## 易混

本窗闸名只能是择径闸，不是论坛闸，不是起诉闸，不是竞合闸，不是程序闸，不是路径闸。`XH#` 不是 `LT#`，不是 `QT#`，不是 `JH#`，不是 `CX#`。主路径是 `Q-督`，不是 `Q-坛`，不是 `Q-诉`，不是 `Q-择`，不是 `Q-径`。`论坛闸`／`LT#`／`Q-坛` 是评估合同管辖与仲裁协议。`起诉闸`／`QT#`／`Q-诉` 是提起合同纠纷一审。`竞合闸`／`JH#`／`Q-择` 是选择合同违约与侵权竞合路径。`程序闸`／`CX#` 是公司治理召集程序瑕疵。1991 年民事诉讼法第二百二十五条执行保管不是支付令。2017 年第二百一十四条须核对应现行第二百二十五条。1994 年仲裁法第五条须核 2025 修订；MCP 标尚未施行时以施行日 2026-03-01 为准。提出「把仲裁页撕掉再起诉」整体停止。本窗不写完整申请书。不选定法院。不保证更快。
