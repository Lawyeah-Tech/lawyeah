# 选择诉讼仲裁或督促程序方法

本文件是可执行判断节点。有效仲裁不是应起诉。比较不是已选定法院。支付令不是已可执行。有实质对待给付争议不是支付令适格。未知不写零。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已选定、应起诉、已发支付令、选定法院、代提交、未知写零。本任务不定罪，不写完整申请书。本窗闸名只能是择径闸，禁止复用论坛闸、起诉闸、答辩闸、竞合闸、程序闸。预留不得占用：立案闸、论坛闸、起诉闸。本窗 `XH#` 是择径行。主路径只用 `Q-督`，禁止用 `Q-坛`、`Q-诉`、`Q-辩`、`Q-择`、`Q-径`、`Q-选`、`Q-签`、`Q-金令` 作主路径。本窗 `Q-签` 只作「比较即已选定或已立案」不关窗码。本窗 `Q-仲` 只作「有效仲裁仍应直接起诉」不关窗码。本窗 `Q-执` 只作「支付令即已可执行」不关窗码。英文 id 禁止使用，一律用中文技能名 `选择诉讼仲裁或督促程序`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991 年民事诉讼法第二百二十五条执行保管、2017 年第二百一十四条、1994 年仲裁法第五条未核 2025、把有效仲裁写成应起诉时记为噪声。禁止指导伪造条款或隐匿仲裁。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现请求切片扫描，不是默认闭集。
`XH#` 固定列：`编号｜请求切片｜仲裁条款接口｜诉讼接口｜督促支付令接口｜互斥与失败分流｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「应起诉」或「已发支付令」。无 `E#` 不得写已选定。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-督`。禁止 `LT#`、`QT#`、`DB#`、`JH#`、`CX#`、`A#`、`N#`。文件状态只用 `草案`、`停止`。

口头「直接去法院更快」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：有效书面仲裁协议，起诉原则上不予受理。或裁或诉、机构不明待核。支付令限于金钱或有价证券、无其他债务纠纷、能够送达；有实质履行抗辩不得包装。异议成立则支付令失效，原则上转入诉讼。比较表不是已选定。

## 节点 0　分流、立场、择径闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造条款、隐匿仲裁、倒签、虚假诉讼、违法取证不进负表。利益冲突未解不进整体停止。不写完整申请书、不选定法院不是负触发。

整案转出只交付第 1、2、10 节，不出 `XH#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是管辖或仲裁条款专项 | 负触发 `评估合同管辖与仲裁协议` |
| 主成果是起诉包 | 负触发 `提起合同纠纷一审` |
| 主成果是仲裁申请 | 负触发 `提起合同仲裁` |
| 主成果是支付令申请书 | 负触发 `申请合同金钱支付令` |
| 主成果是首次答辩 | 负触发 `应对合同纠纷一审` 或 `应对合同仲裁` |
| 主成果是违约与侵权竞合择一 | 负触发 `选择合同违约与侵权竞合路径` |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程／金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不写完整申请书」「不选定法院」 | 交付禁令，不是负触发 |

出现「仲裁」「起诉」「支付令」一词不是转出。

择径闸打开须同时满足：单方无冲突立场已闭合；主成果是路径比较，不是起诉包、不是支付令终稿、不是仲裁申请；至少一项可编号请求、条款或金钱债权碎片。口头「直接去法院更快」不算单独开闸材料。

择径闸部分打开：已有碎片，但仲裁效力、送达可能或对待给付未闭合；仍交十节。

择径闸关闭（仍正触发）：无一可编号碎片。不出 `XH#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `XH#` 终稿，**第 7 节不得出起诉状、仲裁申请或支付令终稿**。

「有效仲裁仍应起诉」「比较即已选定」「支付令即已可执行」「未知写零」**不关窗**。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 择径闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造仲裁条款或连结点、隐匿仲裁协议、倒签、虚假诉讼、违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 3　择径行 `XH#`

按已出现请求切片扫描，不是默认闭集。每条须能指向请求、仲裁覆盖或支付令适格之一。

无 `E#` 不得写已选定或应起诉。状态默认 `草案`。一次只推荐下一步。未知不写零。仲裁效力或送达未闭合不得标待提交。

热冲突强制处理：

- 有效仲裁仍应起诉／比较即已选定／支付令即已可执行／未知写零 → 该格不支持或字段停止；仍出其他 `XH#`。
- 无一碎片 → 关闸，不出 `XH#` 终稿，窗口不关。
- 指导伪造条款、隐匿仲裁、虚假诉讼 → 整体停止，不是该格不支持。

第 7 节只开接口，不得夹带 `XH#` 终稿或起诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待事项编号」，不得补写应起诉。不选定法院。不写完整申请书。

下一步只转介：`评估合同管辖与仲裁协议`、`提起合同纠纷一审`、`申请合同金钱支付令`、`提起合同仲裁`、`应对合同纠纷一审`、`应对合同仲裁`、`提出合同案件管辖异议`、`准备合同仲裁协议异议材料`、`谈判合同和解方案`、`建立合同争议证据案卷`、`测算违约金与损害赔偿`、`准备合同财产保全申请`、`准备合同案件庭审`、`选择合同违约与侵权竞合路径`、`评估合同成立与效力`、`评估解除权是否成立`、`评估合同争议`。禁止此致某院。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：买卖尾款，合同写可仲裁也可诉讼、机构写某地仲裁委。用户主张直接去法院更快、支付令今晚就能发、有仲裁也可以先起诉、此致某中院、不清楚先写零。择径闸打开或半开。`Q-仲`、`Q-执`、`Q-院`、`Q-必`、`Q-零` 不打开为可靠路径。第 6 节不得把应起诉、已发令、已选定、0 写入可执行 `XH#`；对应格 `现有依据不支持` 或字段停止；仍出请求分列、或裁或诉待核、支付令对待给付缺口。不写申请书。

场景②：用户同时交出己方「从未签过仲裁」与对方「合同有仲裁条款」口径，并要「把仲裁页撕掉再起诉」。命中双方秘密＋隐匿仲裁。第一次整体停止。只交第 1、10 节。不出 `XH#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代隐匿方案。
