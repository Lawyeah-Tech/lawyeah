# 建立双向履行时间线

## 任务目标

在明确、无利益冲突的单方立场下（主张请求或抗辩一方或其受托律师，互斥），形成履行时间线草案：时线闸、主体与强制接口、`Q#` 路径、`SX#` 时线行（义务切片／义务人与文本来源／约定日与先决／实际行为日／异常与冲突日／`E#` 回链）。本窗 `SX#` 是时线行草案，不是已履行证明，不是已违约终稿，不是已解除，不是唯一截止日，不是催告函或诉状。本窗闸名只能是时线闸，禁止复用期间闸、期限闸、履行闸、时序闸、日历闸、争议闸、解除闸、催告闸、证据闸、精算闸、立案闸。预留不得占用：立案闸、和解闸。本窗主行只能是 `SX#`，禁止 `OB#`、`XL#`、`QJ#`、`JE#`、`ZT#`、`SJ#`、`YS#`、`A#`。主路径只用 `Q-历`，禁止用 `Q-期`、`Q-时`、`Q-日`、`Q-据`、`Q-总`、`Q-测`、`Q-履`、`Q-线`、`Q-签` 作主路径。邻窗 `Q-历` 只作转介进本窗；本窗打开为主路径，不是已履行、不是已违约。本窗 `Q-签` 只作「时间线即已履行、已违约、已解除或已提交」不关窗码。本窗 `Q-日` 只作「唯一截止日」不关窗码。时线闸打开不等于已履行不等于已到达不等于已验收不等于已违约不等于已解除不等于抗辩已成立不等于待提交终稿。口头不是已履行。已读不是到达。签收不是验收。发出不是到达。部分履行不是全部完成。多单不是一直在供货。先决未成就不是已到期。「尽快」不是确定到期。异常不是已违约终局。异常不是已解除。未知不写零。不写唯一截止日。不写发送版催告或解除函。不写诉状。不选定法院。不代提交。不定罪。伤残等级与本窗无关，禁止折入。

`depends-on` 为空。主成果是争议总图转 `评估合同争议`。主成果是完整证据卷转 `建立合同争议证据案卷`。主成果是迟延拒绝或不完全履行形态转 `评估迟延拒绝与不完全履行`。主成果是质量瑕疵终稿转 `评估质量瑕疵与检验期间`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：一般合同已成争，需要单独把双方义务、约定日、实际履行和异常做成可回链时间线。「画完就算齐」「已经给了你列出来」仍正触发，成果状态 `草案`。约定日、到达、先决未核验仍正触发：有可编号义务切片、约定日或实际行为碎片则时线闸打开或半开，第 6 节出 `SX#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出已履行／已违约终稿」才关闸，仍交十节，第 6 节不出 `SX#` 终稿，第 7 节不得出违约终局、函或诉状，窗口不关。用户要把口头写成已履行、把已读写成到达、把签收写成验收、把部分写成全部、把异常写成已违约或已解除、把未知写成零或唯一截止日，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `SX#` 草案。不得因「不认定违约」「不写唯一截止日」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是争议总图（转 `评估合同争议`）；
- 主成果是完整证据卷（转 `建立合同争议证据案卷`）；
- 主成果是迟延拒绝或不完全履行形态终稿（转 `评估迟延拒绝与不完全履行`）；
- 主成果是质量瑕疵终稿（转 `评估质量瑕疵与检验期间`）；
- 主成果是履行顺序或不安抗辩终稿（转 `评估同时履行先履行与不安抗辩`）；
- 主成果是变更是否成立（转 `评估变更是否成立`）；
- 主成果是解除权实体终稿（转 `评估解除权是否成立`）；
- 主成果是发送版催告（转 `准备催告履行或补救通知`）；
- 主成果是发送版解除通知（转 `准备解除通知`）；
- 主成果是期间届满评估（转 `评估争议期间`）；
- 主成果是精算工作表（转 `测算违约金与损害赔偿`）；
- 尚未成争，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）；
- 建设工程、金融借贷担保、房地产物业、海事、劳动专项履行主轴。

双方秘密、伪造履行记录、倒签节点或物流回单或签收日、隐匿对账单、违法取证**不在负触发表**，走整体停止。「口头即已履行」「已读即到达」「签收即验收」「异常即已违约或已解除」「唯一截止日」「未知写零」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不认定违约」「不写唯一截止日」「不发函」是交付禁令，不是负触发。主成果才转；出现「时间线」「履行」一词不是转出。

## 建立工作坐标

确认：评估授权；单方立场；合同及订单版本；双方义务切片；约定日与先决；实际履行行为；法域。

口头「已经给了」「早就违约了」「最晚哪天起诉」「画完就算齐」只登记 `S#`／`V#`。不得升格已履行、已违约或唯一截止日，**不得单独算作开闸材料**。可编号义务切片、约定日或实际行为碎片可开闸。本窗不执行发送，不代提交，不写函或诉状。

立场只许主张请求或抗辩一方或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：时线闸关闭，仍交十节，不是整体停止。无书面评估授权但单方立场已闭合、且已有碎片：时线闸部分打开，仍交十节，不是整体停止。提出伪造履行记录、倒签节点或物流回单或签收日、隐匿对账单或违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`SX#` 时线行；`V#` 版本；`E#` 证据形态回链（合同版本、物流回单、签收、系统日志、付款凭证，不是发送闸，不是已履行证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`OB#`、`XL#`、`QJ#`、`JE#`、`ZT#`。技能正文中的条号是检索锚点，不是已核验 `L#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。未知不写零。口头 ≠ 已履行。已读 ≠ 到达。签收 ≠ 验收。部分 ≠ 全部。异常 ≠ 已违约终局。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或文书范本检索。本窗是建立时间线，范本只借履行对照表栏目，**不要**升格「已履行／已违约／已解除／唯一截止日」，**不要**用类案写成已违约终稿。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现口头即已履行、已读即到达、签收即验收、发出即到达、异常即已违约的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》第六十条至第六十二条、第六十六条至第六十九条、第一百五十七条、第一百五十八条及其解释当作现行规则。MCP 可能先返回失效合同法或第五百六十三条解除清单；解除只开接口，不得写入本窗已解除。MCP 效力字段与公布施行日冲突时，以施行日为准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的届期、到达或同时履行结论保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民法典第五百零九条全面履行与诚信，不得擅自变更解除。第五百一十条约定不明协议补充，不能达成则按相关条款或习惯。第五百一十一条质量、价款、履行地、期限、方式、费用分项，一行一项；「尽快」「验收后付款」无补充则约定期标依据不足。第五百一十二条电子合同交付：物流以签收时间为交付时间，只记日历，不写风险已移转或已履行终局；服务以凭证载明或实际提供服务时间；在线传输以进入指定系统且能够检索识别的时间为交付时间。第五百二十五条同时履行。第五百二十六条先履行。第五百二十七条不安中止须确切证据。第五百二十八条中止应及时通知，本窗只记通知到达日，不写已解除。第一百三十七条非对话到达相对人时生效；指定系统的数据电文进入该系统时生效。已读不是到达。发出日、律师函落款日、立案日不是到达日或履行完成日。第六百二十一条检验通知，签收不是验收。第六百二十三条签收单载明数量型号规格的推定外观检验，可推翻。合同编通则解释第三十一条不得以对方未履行非主要债务拒自己的主要债务。噪声：已失效合同法第六十条至第六十二条、第六十六条至第六十九条、第一百五十七条、第一百五十八条；商品房催告后三个月套一般买卖；合理期限一律十五日。技能正文条号不是 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变届期、到达、检验或同时履行的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补口头不是已履行、已读不是到达、签收不是验收、发票不是当然交付、部分不是全部的实务反例。
- `search_template` 只借履行对照表或工作底稿栏目（义务人／约定日／先决／实际日／异常／证据）。范本落款日、此致某院、违约金或解除栏不得升格已履行、已违约、已解除或唯一截止日。禁止用催告函、解除函、诉状或证据目录改头换面。禁止用范本生成伪造履行记录。建立类禁止用 `search_case_by_fact` 写成已违约终稿。

工具不可用时继续义务碎片和 `SX#` 编目；届期、到达、同时履行结论字段停止。不得拒跑，不得凭记忆写成已履行、已违约或唯一截止日。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、时线闸与不关窗

主成果才整案转出。双方秘密、伪造履行记录、倒签第一次停。口头即已履行、签收即验收不关窗。闸关仍交十节，第 6 节不出 `SX#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

双方义务、约定日与先决分列。本节禁止出 `SX#` 终稿。

### 3. 时线闸与路径 `Q#`

本节禁止出 `SX#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-历`。

### 4. 时线行 `SX#`

义务切片、约定日与先决、实际行为日、异常与冲突日。状态 `草案`。禁止升格已履行、已违约、已解除、唯一截止日。无 `E#` 不得写已履行。双方同日冲突并行两行，不得选边合并。

### 5. 迟延、质量、顺序、解除接口

迟延形态转迟延窗。质量转质量窗。顺序转抗辩窗。解除转解除窗。第 7 节不得夹带 `SX#` 终稿或违约终局绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造履行记录、倒签节点或物流回单或签收日、隐匿对账单或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：时线闸关闭，仍交十节，不是整体停止。无书面评估授权但有碎片：时线闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：约定日、到达、先决、检验期间、施行日未核验。口头即已履行、已读即到达、签收即验收、异常即已违约或已解除、唯一截止日、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `SX#` 草案。
- `目标停止`：主目标变为违约终局、质量瑕疵终稿、发送版函或诉状。禁止把「口头即已履行」当作用户错误主张时的目标停止；那是不关窗。

禁止指导伪造履行记录或倒签节点。不给胜诉率。不定罪。不选定法院。不代提交。未知不写零。不写唯一截止日。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。时线闸关闭仍交十节，第 6 节不出 `SX#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `SX#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。时线闸未打开时不得交付「已履行」或「已违约」。边界见 [路由](references/routing.md)。
