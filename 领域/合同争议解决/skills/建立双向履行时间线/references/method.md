# 建立双向履行时间线方法

本文件是可执行判断节点。口头不是已履行。已读不是到达。签收不是验收。发出不是到达。部分不是全部。异常不是已违约终局。异常不是已解除。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已履行、已违约终稿、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不把时间线写成已违约。本窗闸名只能是时线闸，禁止复用期间闸、期限闸、履行闸、争议闸、解除闸、催告闸、证据闸。预留不得占用：立案闸、和解闸。本窗 `SX#` 是时线行。主路径只用 `Q-历`，禁止用 `Q-期`、`Q-时`、`Q-日`、`Q-据`、`Q-总`、`Q-签` 作主路径。本窗 `Q-签` 只作「时间线即已履行、已违约、已解除或已提交」不关窗码。本窗 `Q-日` 只作「唯一截止日」不关窗码。英文 id 禁止使用，一律用中文技能名 `建立双向履行时间线`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效合同法第六十条至第六十二条、第六十六条至第六十九条、第一百五十七条、第一百五十八条、把口头写成已履行或把签收写成验收时记为噪声。禁止指导伪造履行记录或倒签节点。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现义务碎片扫描，不是默认闭集。
`SX#` 固定列：`编号｜义务切片｜义务人与文本来源｜约定日与先决｜实际行为日｜异常与冲突日｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已履行」或「已违约」。无 `E#` 不得写已履行。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-历`。禁止 `OB#`、`XL#`、`QJ#`、`JE#`、`ZT#`、`A#`、`N#`。双方同日冲突并行两行，不得选边合并。

口头「已经给了」「早就违约了」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：双方义务分列，禁止只画己方有利段。日期冲突并列。先决未成就不得写成已到期。

## 节点 0　分流、立场、时线闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造履行记录、倒签节点或物流回单或签收日、隐匿对账单、违法取证不进负表。利益冲突未解不进整体停止。不认定违约、不写唯一截止日、不发函不是负触发。

整案转出只交付第 1、2、10 节，不出 `SX#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 主成果是完整证据卷 | 负触发 `建立合同争议证据案卷` |
| 主成果是迟延拒绝或不完全履行形态终稿 | 负触发 `评估迟延拒绝与不完全履行` |
| 主成果是质量瑕疵终稿 | 负触发 `评估质量瑕疵与检验期间` |
| 主成果是履行顺序或不安抗辩终稿 | 负触发 `评估同时履行先履行与不安抗辩` |
| 主成果是变更是否成立 | 负触发 `评估变更是否成立` |
| 主成果是解除权实体终稿 | 负触发 `评估解除权是否成立` |
| 主成果是发送版催告 | 负触发 `准备催告履行或补救通知` |
| 主成果是发送版解除通知 | 负触发 `准备解除通知` |
| 主成果是期间届满评估 | 负触发 `评估争议期间` |
| 主成果是精算工作表 | 负触发 `测算违约金与损害赔偿` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程／金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不认定违约」「不写唯一截止日」「不发函」 | 交付禁令，不是负触发 |

出现「时间线」「履行」一词不是转出。

时线闸打开（可出 `SX#` 草案，仍不得标「已履行／已违约／已解除」）须同时满足：单方无冲突立场已闭合；主成果是时间线草案，不是总图、不是证据卷、不是违约形态终稿；至少一项可编号义务切片、约定日或实际行为碎片。口头「已经给了」不算单独开闸材料。

时线闸部分打开：已有碎片，但约定日、到达或先决未闭合；对应格待核；仍交十节。无书面评估授权但单方立场已闭合且已有碎片：时线闸部分打开，仍交十节，不是整体停止。

时线闸关闭（仍正触发）：无一可编号碎片。「今天必须出已履行／已违约终稿」而无最小碎片不得开闸。不出 `SX#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `SX#` 终稿，**第 7 节不得出违约终局、函或诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「口头即已履行」「已读即到达」「签收即验收」「发出即到达」「异常即已违约或已解除」「唯一截止日」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `SX#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 时线闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造履行记录、倒签节点或物流回单或签收日、隐匿对账单或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个义务切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `SX#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 义务人 | 双方分列 | 只画己方有利段 |
| 文本 | 主合同／订单／变更分列 | 选对用户有利的一版冒充唯一 |
| 约定日 | 履行日、宽限、先决分列 | 「尽快」写成确定到期；先决未成就写成已到期 |
| 实际 | 发出／到达／签收／付款分列 | 口头升格已履行；已读升格到达 |
| 异常 | 迟延、短少、拒收、暂停只记事件 | 写成已违约终局或已解除 |

## 节点 3　时线行 `SX#`

按已出现义务碎片扫描，不是默认闭集。每条须能指向义务、约定日、实际行为或异常之一。

无 `E#` 不得写已履行。状态默认 `草案`。一次只推荐下一步。未知不写零。双方同日冲突并行两行。

热冲突强制处理：

- 口头即已履行／已读即到达／签收即验收／发出即到达／异常即已违约或已解除／唯一截止日／未知写零 → 该格不支持或字段停止；仍出其他 `SX#`。
- 无一碎片 → 关闸，不出 `SX#` 终稿，窗口不关。
- 指导伪造履行记录、倒签、隐匿对账单 → 整体停止，不是该格不支持。

## 节点 4　迟延、质量、顺序、解除接口

第 7 节只开接口，不得夹带 `SX#` 终稿或违约终局绕闸。闸关闭时第 7 节可写「闸未开，转介待义务编号」，不得补写已履行。不选定法院。不代提交。

下一步只转介：`评估合同争议`、`建立合同争议证据案卷`、`评估迟延拒绝与不完全履行`、`评估质量瑕疵与检验期间`、`评估同时履行先履行与不安抗辩`、`评估变更是否成立`、`评估解除权是否成立`、`准备催告履行或补救通知`、`准备解除通知`、`评估争议期间`、`测算违约金与损害赔偿`、`评估框架协议与订单冲突`、`评估电子合同成立与送达`、`评估不可抗力情势变更与履行不能`、`评估价款结算与发票争议`、`保全质量现场与电子证据`、`设计合同案件通知送达`。禁止此致某院。异常不得写成已违约或已解除。

若 if 用户催促「已经给了就算履行了／已读就算到达／签收就算验收／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「时线闸与时线行草案」。本窗不执行发送。不包含：已履行、已违约终稿、已解除、唯一截止日、发送版函。禁止选边治愈。禁止口头即已履行。禁止签收即验收。禁止指导伪造或倒签。时线闸打开 ≠ 已履行 ≠ 已违约 ≠ 已解除。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标时线终稿已形成。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：买卖合同分三批发货，买方微信已读物流短信，第三批签收但未验收。用户主张已经给了就算履行完了、已读就算到达、签收就算验收合格、部分交货就算全部、异常就是根本违约可以解除、最晚哪天起诉写死、不清楚的日期先写零。时线闸打开或半开。`Q-口`、`Q-读`、`Q-收`、`Q-违`、`Q-除`、`Q-日`、`Q-零` 不打开为可靠路径。第 6 节不得把已履行、已到达、已验收、已违约、已解除、0、唯一截止日写入可执行 `SX#`；对应格 `现有依据不支持` 或字段停止；仍出批次分列、发出与到达分列、签收与验收分列、冲突日并行等其他 `SX#`。不关窗。不写函。不认定违约。

场景②：用户同时交出己方「上周已经送到、回单日期改到验收日前」与对方「从未收到第三批」口径，并指导「对账单那页先藏起来」。命中双方秘密＋倒签＋隐匿。第一次整体停止。只交第 1、10 节。不出 `SX#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代违法方案。
