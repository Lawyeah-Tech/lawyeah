# 边界与路由

## 正触发

一般合同已成争，需要单独把双方义务、节点、实际履行做成可回链时间线。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 判断迟延或拒绝 | `评估迟延拒绝与不完全履行` |
| 质量瑕疵 | `评估质量瑕疵与检验期间` |
| 履行顺序或不安抗辩 | `评估同时履行先履行与不安抗辩` |
| 是否构成变更 | `评估变更是否成立` |
| 总体评估 | `评估合同争议` |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，只分流不回改 |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

需要可回链日历、还不下违约或解除结论时正触发。用户要立刻认定违约或发解除函时负触发。
