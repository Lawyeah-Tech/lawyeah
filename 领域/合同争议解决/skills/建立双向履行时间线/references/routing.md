# 边界与路由

## 正触发

一般合同已成争，需要单独把双方义务、约定日、实际履行和异常做成可回链时间线。从零、碎片、到达未核验、无书面评估授权仍正触发：有可编号义务切片、约定日或实际行为碎片则闸开或半开，出 `SX#` 草案，保持草案。本次不认定违约、不写唯一截止日、不发函是交付禁令，不是开窗条件。口头即已履行、签收即验收、异常即已违约，仍正触发。

双方秘密、伪造履行记录、倒签节点或物流回单或签收日、隐匿对账单、违法取证的停止，优先于负触发。上述信号不在下表。不认定违约不是负触发。「口头即已履行」「已读即到达」「签收即验收」「异常即已违约或已解除」「唯一截止日」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 争议总图 | `评估合同争议` |
| 完整证据卷 | `建立合同争议证据案卷` |
| 迟延拒绝或不完全履行形态终稿 | `评估迟延拒绝与不完全履行` |
| 质量瑕疵终稿 | `评估质量瑕疵与检验期间` |
| 履行顺序或不安抗辩终稿 | `评估同时履行先履行与不安抗辩` |
| 变更是否成立 | `评估变更是否成立` |
| 解除权实体终稿 | `评估解除权是否成立` |
| 发送版催告 | `准备催告履行或补救通知` |
| 发送版解除通知 | `准备解除通知` |
| 期间届满评估 | `评估争议期间` |
| 精算工作表 | `测算违约金与损害赔偿` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |
| 工程／金融／房产／海事／劳动主轴 | 对应领域 |

不得因「不认定违约」或「不写唯一截止日」关窗。拟时间线仍正触发，不得写成已履行或已违约。

## 易混

本窗闸名只能是时线闸，不是期间闸，不是争议闸，不是证据闸，不是催告闸，不是解除闸。`SX#` 不是 `OB#`，不是 `XL#`，不是 `QJ#`，不是 `JE#`，不是 `ZT#`。主路径是 `Q-历`，不是 `Q-期`，不是 `Q-据`，不是 `Q-总`。口头不是已履行。已读不是到达。签收不是验收。发出不是到达。部分不是全部。异常不是已违约终局。异常不是已解除。已失效合同法第六十条至第六十二条、第六十六条至第六十九条、第一百五十七条、第一百五十八条不是现行。「回单日期改到上周」「对账单先藏起来」整体停止。本窗不执行发送，不代提交。不选定法院。不认定违约。不写唯一截止日。
