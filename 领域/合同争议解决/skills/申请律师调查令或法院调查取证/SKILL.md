# 申请律师调查令或法院调查取证

## 任务目标

在明确、无利益冲突的单方立场下（拟合法调取第三方材料一方或其受托律师，互斥），形成发送前调查令或法院调查取证申请草稿：调令闸、主体与强制接口、`Q#` 路径、`DC#` 调令行（对象切片／不能自行收集原因／律师调查令或法院调查分流／范围与禁止动作／申请接口／`E#` 回链）。本窗 `DC#` 是调令行草案，不是令文，不是已准许，不是已签发，不是已调取，不是案卷终稿，不是搜查证。本窗闸名只能是调令闸，禁止复用调查闸、证据闸、现证闸、举证闸、申鉴闸、公证闸、保全闸、取证闸、申请闸。预留不得占用：立案闸、和解闸、调查闸、保全闸。本窗主行只能是 `DC#`，禁止 `JE#`、`XZ#`、`JQ#`、`JA#`、`GD#`、`DL#`、`LT#`、`DY#`、`A#`。主路径只用 `Q-调令`，禁止用 `Q-据`、`Q-现`、`Q-举证`、`Q-申鉴`、`Q-公`、`Q-保`、`Q-调`、`Q-令`、`Q-取`、`Q-查`、`Q-交`、`Q-签` 作主路径。邻窗 `Q-调令` 只作转介进本窗；本窗打开为主路径，不是已准许、不是已签发、不是已调取。本窗 `Q-据` 只转介 `建立合同争议证据案卷`。本窗 `Q-现` 只转介 `保全质量现场与电子证据`。本窗 `Q-举证` 只转介 `规划举证期限与证据交换`。本窗 `Q-签` 只作「草稿即已提交或已签发」不关窗码。本窗 `Q-调取` 只作「草稿即已调取」不关窗码。调令闸打开不等于已准许不等于已签发不等于已调取不等于待提交终稿。申请不是已准许。草稿不是已调取。律师调查令不是搜查证。律师有权调查收集不是全国已立法调查令。对方控制不是内容有利。对方控制的普通书证不是当然改走调查令。范围最小化。未知不写零。不代提交。不选定法院。不定罪。不保证签发。不指导购买数据、侵入系统或偷拷。伤残等级与本窗无关，禁止折入。

`depends-on` 为空。主成果是整本案卷矩阵转 `建立合同争议证据案卷`。主成果是现场自固转 `保全质量现场与电子证据`。主成果是举证期限计划转 `规划举证期限与证据交换`。主成果是鉴定申请转 `准备质量或损失鉴定申请`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：一般合同已成争，关键证据由银行、登记机关、平台等第三方掌握，因客观原因不能自行收集，要律师调查令或法院调查取证申请草稿。「今晚把对方账户全掏出来」「申请了就一定发出令」仍正触发，成果状态 `草案`，不代提交。对象、原因、范围未核验仍正触发：有可编号第三方对象或不能自行收集碎片则调令闸打开或半开，第 6 节出 `DC#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出已调取终稿」才关闸，仍交十节，第 6 节不出 `DC#` 终稿，第 7 节不得出令文或已调取，窗口不关。用户要把申请写成已准许、把草稿写成已调取、把对方控制写成内容有利、把调查令写成搜查证、把未知写成零、把此致某院写成管辖已定，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `DC#` 草案。不得因「不保证签发」「不代提交」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是整本案卷矩阵（转 `建立合同争议证据案卷`）；
- 主成果是现场或电子合法自固（转 `保全质量现场与电子证据`）；
- 主成果是公证申请终稿（转 `准备合同案件公证保全`）；
- 主成果是举证期限与交换计划（转 `规划举证期限与证据交换`）；
- 主成果是鉴定申请（转 `准备质量或损失鉴定申请`）；
- 主成果是庭审质证提纲（转 `准备合同案件庭审`）；
- 主成果是财产保全申请（转 `准备合同财产保全申请`）；
- 主成果是争议总图（转 `评估合同争议`）；
- 尚未成争，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）。

双方秘密、购买数据、侵入系统、偷拷、变造令文、违法调取个人信息、违法取证**不在负触发表**，走整体停止。STUB 把「违法调取个人信息或购买数据」放进负触发，必须改整体停止。「申请即已准许」「草稿即已调取」「对方控制即内容有利」「调查令即搜查证」「未知写零」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。STUB 把「对方控制的普通书证却要求打探无关隐私」放进负触发，必须改不关窗：超范围关该格，窗口不关。「不保证签发」「不代提交」是交付禁令，不是负触发。主成果才转；出现「调查令」「调取」一词不是转出。

## 建立工作坐标

确认：申请授权；单方立场；第三方对象切片；不能自行收集原因；律师调查令或法院调查分流；范围与禁止字段；法域；当前诉讼或仲裁状态。

口头「今晚把对方账户全掏出来」只登记 `S#`／`V#`。不得升格已准许、已签发或已调取，**不得单独算作开闸材料**。可编号第三方对象或不能自行收集碎片可开闸。本窗不执行发送，不代提交，不持令取证。

立场只许拟合法调取一方或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：调令闸关闭，仍交十节，不是整体停止。无书面授权但单方立场已闭合、且已有碎片：调令闸部分打开，仍交十节，不是整体停止。提出购买数据、侵入系统、偷拷、变造令文、违法调取个人信息或违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`DC#` 调令行；`V#` 版本；`E#` 证据形态回链（对象、自行收集受阻、范围、授权，不是发送闸，不是已调取证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`JE#`、`XZ#`、`DL#`、`DY#`。技能正文中的条号是检索锚点，不是已核验 `L#`。文件状态只用 `草案`、`停止`。不得标已准许、已签发或待提交。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。未知不写零。申请 ≠ 已准许。草稿 ≠ 已调取。调查令 ≠ 搜查证。对方控制 ≠ 内容有利。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或文书范本检索。本窗是申请草稿准备，范本只借调查令申请书、法院调查取证申请书、拟调查事项清单栏目，**不要**升格「已准许／已签发／已调取」。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现申请即已准许、草稿即已调取、调查令即搜查证、对方控制即有利的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把 2017 年民事诉讼法第六十四条未核验对应现行第六十七条。不得把 2017 年第六十七条有权向单位调查取证未核验对应现行第七十条。律师调查令无全国统一立法，各地高院指引运行时核验，不得写成全国已立法。不得把执行调查令、监察调查或内部合规调查套本案。MCP 效力字段与公布施行日冲突时，以施行日为准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的客观原因、申请期间、准许或施行日保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民事诉讼法（2023 修正，施行日 2024-01-01）第六十四条代理诉讼的律师和其他诉讼代理人有权调查收集证据，可以查阅本案有关材料；这不是全国调查令立法。第六十七条当事人对自己提出的主张有责任提供证据；因客观原因不能自行收集或人民法院认为审理案件需要的，人民法院应当调查收集。噪声：2017 年第六十四条。第七十条人民法院有权向有关单位和个人调查取证，有关单位和个人不得拒绝。噪声：2017 年第六十七条与现行第六十七条举证责任撞号。第一百三十三条派出人员调查应当出示证件。民诉解释第九十四条客观原因包括国家有关部门保存无权查阅调取、涉及国家秘密商业秘密或个人隐私、其他客观原因；可以在举证期限届满前书面申请。若仍引旧第六十四条第二款须核对应现行第六十七条第二款。第九十五条与待证事实无关联、无意义或其他无必要的，不予准许。第九十六条依职权调查范围；除此应当依照当事人的申请进行。第九十七条调查收集应当由两人以上共同进行。民事诉讼证据规定（2019 修正）第二条当事人因客观原因不能自行收集的，可申请人民法院调查收集。第二十条举证期限届满前提交书面申请，载明被调查人、证据名称或内容、原因、待证事实以及明确线索。书证提出命令只开接口，不得写成调查令已签发。噪声：2001 年证据规定第十五条至第十九条；执行程序调查令指引套诉讼；合规内部调查授权。技能正文条号不是 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变客观原因、申请期间、依职权范围或两人调查的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补申请不是已准许、草稿不是已调取、调查令不是搜查证、不是全国统一立法、对方控制不是内容有利、范围须最小化、立案后才可能发令的实务反例。噪声：执行完毕前申请调查令；对方控制即责令提交的书证提出命令推定套调查令。
- `search_template` 只借律师调查令申请书、法院调查取证申请书、拟调查事项清单栏目。范本准许栏、令文栏、落款日、此致某院不得升格已准许、已签发、已调取或已提交。禁止用保全申请、鉴定申请、起诉状、内部调查授权书或搜查证改头换面。禁止用范本生成侵入、购买数据或超范围隐私清单。

工具不可用时继续对象碎片和 `DC#` 编目；已准许、已签发、已调取、申请期间、施行日字段停止。不得拒跑，不得凭记忆写成已调取或指导违法取证。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、调令闸与不关窗

主成果才整案转出。双方秘密、购买数据、侵入系统第一次停。申请即已准许、草稿即已调取不关窗。闸关仍交十节，第 6 节不出 `DC#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

对象／原因／令或法院调查／范围／禁止动作分列。一揽子隐私关该格。本节禁止出 `DC#` 终稿。

### 3. 调令闸与路径 `Q#`

本节禁止出 `DC#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-调令`。

### 4. 调令行 `DC#`

切片、原因、分流、范围、申请接口。状态 `草案`。禁止升格已准许、已签发、已调取。无 `E#` 不得写已调取。

### 5. 案卷、现证、举证与书证提出接口

案卷转证据窗。自固转现证窗。书证提出命令只开接口。第 7 节不得夹带 `DC#` 终稿或令文绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出购买数据、侵入系统、偷拷、变造令文、违法调取个人信息或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：调令闸关闭，仍交十节，不是整体停止。无书面授权但有碎片：调令闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：客观原因、申请期间、地方调查令规则、施行日未核验。申请即已准许、草稿即已调取、对方控制即内容有利、调查令即搜查证、超范围隐私、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `DC#` 草案。
- `目标停止`：主目标变为案卷终稿、令文已签发或违法取证方案。禁止把「申请即已准许」当作用户错误主张时的目标停止；那是不关窗。

禁止指导购买数据或侵入系统。不给签发率。不定罪。不选定法院。不代提交。未知不写零。不写令文。不保证签发。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。调令闸关闭仍交十节，第 6 节不出 `DC#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `DC#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。调令闸未打开时不得交付「已准许」或「已调取」。边界见 [路由](references/routing.md)。
