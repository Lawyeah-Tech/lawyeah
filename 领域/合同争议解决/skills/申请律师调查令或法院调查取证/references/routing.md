# 边界与路由

## 正触发

关键证据由银行、登记机关、平台等第三方掌握，需合法调取。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 电子自行保全 | `保全质量现场与电子证据` |
| 公证 | `准备合同案件公证保全` |
| 举证期规划 | `规划举证期限与证据交换` |
| 财产线索用于保全 | `准备合同财产保全申请` |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，只分流不回改 |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

## 易混

第三方手里有关键账或登记、自己拿不到时正触发。要买黑客数据时停止。只要自己卷宗整理时转建卷。
