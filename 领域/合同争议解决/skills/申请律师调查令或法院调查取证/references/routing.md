# 边界与路由

## 正触发

一般合同已成争，关键证据由第三方掌握，因客观原因不能自行收集，要律师调查令或法院调查取证申请草稿。从零、碎片、地方令规则未核验仍正触发：有可编号第三方对象或不能自行收集碎片则闸开或半开，出 `DC#` 草案，保持草案。本次不保证签发、不代提交是交付禁令，不是开窗条件。申请即已准许、草稿即已调取，仍正触发。把调查令写成搜查证、把对方控制写成内容有利，仍正触发：该格不支持，不改负触发关窗。

双方秘密、购买数据、侵入系统的停止，优先于负触发。上述信号不在下表。不保证签发不是负触发。「申请即已准许」「草稿即已调取」「对方控制即内容有利」「调查令即搜查证」「保证签发」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 整本案卷矩阵 | `建立合同争议证据案卷` |
| 现场或电子合法自固 | `保全质量现场与电子证据` |
| 公证申请终稿 | `准备合同案件公证保全` |
| 举证期限与交换计划 | `规划举证期限与证据交换` |
| 鉴定申请 | `准备质量或损失鉴定申请` |
| 庭审质证提纲 | `准备合同案件庭审` |
| 财产保全申请 | `准备合同财产保全申请` |
| 争议总图 | `评估合同争议` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不保证签发」或「不代提交」关窗。拟申请草稿仍正触发，不得写成已准许或已调取。

## 易混

本窗闸名只能是调令闸，不是调查闸，不是证据闸，不是现证闸，不是举证闸。`DC#` 不是 `JE#`，不是 `XZ#`，不是 `JQ#`，不是 `DL#`。主路径是 `Q-调令`，不是 `Q-调`，不是 `Q-令`，不是 `Q-取`，不是 `Q-查`，不是 `Q-据`。`调查闸` 是合规内部调查路由。`Q-调` 是认缴期限调整主路径。`Q-查` 是查阅权诉讼主路径。`Q-令` 是合规责令改正或不关窗「法院调查令即内部授权」。`Q-取` 是合规「授权稿即已合法取证」。2017 年民事诉讼法第六十四条须核对应现行第六十七条。2017 年第六十七条有权向单位调查须核对应现行第七十条。律师有权调查收集不是全国调查令立法。执行调查令不是本窗。提出「买一份银行内部数据、黑进对方邮箱」整体停止。本窗不代提交。不选定法院。不写令文。不保证签发。
