# 申请律师调查令或法院调查取证方法

本文件是可执行判断节点。申请不是已准许。草稿不是已调取。律师调查令不是搜查证。律师有权调查收集不是全国已立法调查令。对方控制不是内容有利。未知不写零。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已签发、已调取、选定法院、代提交、未知写零。本任务不定罪，不持令取证，不指导违法取证。本窗闸名只能是调令闸，禁止复用调查闸、证据闸、现证闸、举证闸。预留不得占用：立案闸、和解闸、调查闸。本窗 `DC#` 是调令行。主路径只用 `Q-调令`，禁止用 `Q-据`、`Q-现`、`Q-调`、`Q-令`、`Q-取`、`Q-查`、`Q-签` 作主路径。本窗 `Q-签` 只作「草稿即已提交或已签发」不关窗码。本窗 `Q-调取` 只作「草稿即已调取」不关窗码。英文 id 禁止使用，一律用中文技能名 `申请律师调查令或法院调查取证`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 2017 年民事诉讼法第六十四条、把 2017 年第六十七条有权向单位调查写成现行第六十七条举证责任、把调查令写成全国立法或搜查证时记为噪声。禁止指导购买数据或侵入系统。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现对象切片扫描，不是默认闭集。
`DC#` 固定列：`编号｜对象切片｜不能自行收集原因｜律师调查令或法院调查分流｜范围与禁止动作｜申请接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已调取」或「已签发」。无 `E#` 不得写已调取或已签发。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-调令`。禁止 `JE#`、`XZ#`、`DL#`、`DY#`、`A#`、`N#`。文件状态只用 `草案`、`停止`。

口头「今晚把对方账户全掏出来」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：客观原因不能自行收集才申请。举证期限届满前书面。无关联无意义无必要不予准许。律师调查令是地方实践，通常立案后、限于本案、范围最小化，被调查单位可核验令文。对方控制的普通书证优先考虑书证提出命令接口，不是当然调查令。执行调查令不是本窗。

## 节点 0　分流、立场、调令闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、购买数据、侵入、偷拷、变造令文、违法调取个人信息、违法取证不进负表。利益冲突未解不进整体停止。不保证签发、不代提交不是负触发。

整案转出只交付第 1、2、10 节，不出 `DC#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是整本案卷矩阵 | 负触发 `建立合同争议证据案卷` |
| 主成果是现场或电子合法自固 | 负触发 `保全质量现场与电子证据` |
| 主成果是公证申请终稿 | 负触发 `准备合同案件公证保全` |
| 主成果是举证期限与交换计划 | 负触发 `规划举证期限与证据交换` |
| 主成果是鉴定申请 | 负触发 `准备质量或损失鉴定申请` |
| 主成果是庭审质证提纲 | 负触发 `准备合同案件庭审` |
| 主成果是财产保全申请 | 负触发 `准备合同财产保全申请` |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程／金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不保证签发」「不代提交」 | 交付禁令，不是负触发 |

出现「调查令」「调取」一词不是转出。

调令闸打开（可出 `DC#` 草案，仍不得标「已准许／已签发／已调取」）须同时满足：单方无冲突立场已闭合；主成果是调查令或法院调查申请草稿，不是案卷终稿、不是令文、不是违法取证方案；至少一项可编号第三方对象或不能自行收集碎片。口头「今晚全掏出来」不算单独开闸材料。

调令闸部分打开：已有碎片，但客观原因、地方令规则或范围未闭合；对应格待核；仍交十节。无书面授权但单方立场已闭合且已有碎片：调令闸部分打开，仍交十节，不是整体停止。

调令闸关闭（仍正触发）：无一可编号碎片。「今天必须出已调取终稿」而无最小碎片不得开闸。不出 `DC#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `DC#` 终稿，**第 7 节不得出令文或已调取**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「申请即已准许」「草稿即已调取」「对方控制即内容有利」「调查令即搜查证」「超范围隐私」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `DC#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 调令闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出购买数据、侵入系统、偷拷、变造令文、违法调取个人信息或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个对象切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `DC#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 切片 | 银行流水／登记／平台订单分列 | 合成「把对方底都调出来」 |
| 原因 | 部门保存无权查阅／隐私／自行受阻分列 | 对方控制推定有利 |
| 分流 | 地方调查令／法院调查／书证提出命令 | 调查令升格搜查证 |
| 范围 | 期间、字段最小化 | 一揽子通讯、配偶隐私 |

检索锚点（写入 `L#` 前须核验）：见技能正文 MCP 节。噪声：2017 年第六十四条；2017 年第六十七条撞号；执行调查令。

## 节点 3　调令行 `DC#`

按已出现对象切片扫描，不是默认闭集。每条须能指向第三方对象、不能自行收集原因或范围之一。

无 `E#` 不得写已调取或已签发。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止写入已准许或搜查步骤。范围或原因未闭合不得标待提交。

热冲突强制处理：

- 申请即已准许／草稿即已调取／对方控制即有利／调查令即搜查证／超范围隐私／未知写零 → 该格不支持或字段停止；仍出其他 `DC#`。
- 无一碎片 → 关闸，不出 `DC#` 终稿，窗口不关。
- 指导购买数据、侵入、偷拷、变造令文 → 整体停止，不是该格不支持。

## 节点 4　案卷、现证、举证与书证提出接口

第 7 节只开接口，不得夹带 `DC#` 终稿或令文绕闸。闸关闭时第 7 节可写「闸未开，转介待事项编号」，不得补写已调取。不选定法院。不代提交。不写令文。书证提出命令只开接口，本窗不出责令提交终稿。

下一步只转介：`建立合同争议证据案卷`、`规划举证期限与证据交换`、`保全质量现场与电子证据`、`准备合同案件庭审`、`准备合同案件公证保全`、`准备质量或损失鉴定申请`、`提出合同鉴定异议或重新鉴定`、`评估合同争议`、`提起合同纠纷一审`、`应对合同纠纷一审`、`评估合同财产保全必要性`、`准备合同财产保全申请`、`建立双向履行时间线`、`评估电子合同成立与送达`、`评估争议期间`、`评估债权人代位权`、`提起合同仲裁`。禁止此致某院。

若 if 用户催促「申请了就发出令／账户全掏出来／不清楚先写零／买一份银行内部数据」，then 该格 `现有依据不支持` 或字段停止；购买数据第一次整体停止。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 再执行清单

每个节点结束后回写：来源、判断、最强反方、是否字段停止。不得跳过调令闸直接给已签发或已调取终稿。

若 if 客观原因、申请期间、地方调查令规则、施行日未核验，then 该强制项字段停止，窗口不关。
判断状态只许三值。口头「今晚全掏出来」不得写成 `DC#` 已调取。未知不写零。

## 本任务回链纪律

本任务成果是「调令闸与调令行草案」。本窗不代提交。不包含：已准许、已签发、已调取终稿、令文、搜查步骤。禁止选边治愈。禁止申请即已准许。禁止指导违法取证。调令闸打开 ≠ 已准许 ≠ 已签发 ≠ 已调取。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标申请终稿已形成。
风险档 A：购买数据、侵入系统、变造令文必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：买卖合同已立案，买方要调对方三年全部银行流水、微信聊天和配偶账户，主张对方电脑里一定有、申请了就发出令、调查令就是搜查证、网交了就算提交、不清楚先写零。调令闸打开或半开。`Q-准`、`Q-调取`、`Q-控`、`Q-签`、`Q-零` 不打开为可靠路径。第 6 节不得把已准许、已调取、内容有利、0、一揽子隐私写入可执行 `DC#`；对应格 `现有依据不支持` 或字段停止；仍出对象分列、客观原因、范围最小化、地方令规则待核。不代提交。

场景②：用户同时交出己方「必须拿到内部对账单」与对方「从未拒绝提供」口径，并要「买一份银行内部数据、黑进对方邮箱」。命中双方秘密＋购买数据＋侵入。第一次整体停止。只交第 1、10 节。不出 `DC#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代违法方案。
