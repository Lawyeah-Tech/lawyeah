# 提起情势变更变更或解除之诉

## 任务目标

在明确、无利益冲突的单方立场下（受不利影响的当事人或其受托律师，互斥），形成情势变更形成之诉材料草稿：情诉闸、主体与强制接口、`Q#` 路径、`QY#` 情诉行（请求切片／原告适格与被告明确／管辖与仲裁接口／再交涉与变更解除互斥时点／证据目录重大变化商业风险排除与保全红旗／`E#` 回链）。本窗 `QY#` 是情诉行草案，不是已提交证明，不是已立案，不是已改约，不是已解除，不是发送版起诉状。本窗闸名只能是情诉闸，禁止复用起诉闸、立案闸、解除闸、变约闸、变故闸、确诉闸、情势闸、变更闸、力变闸。预留不得占用：立案闸、和解闸、发送闸、催告闸。本窗主行只能是 `QY#`，禁止 `QT#`、`WG#`、`BY#`、`JC#`、`QR#`、`QS#`、`A#`。主路径只用 `Q-情诉`，禁止用 `Q-诉`、`Q-故`、`Q-变`、`Q-除`、`Q-确诉`、`Q-力`、`Q-履`、`Q-势`、`Q-签` 作主路径。邻窗 `Q-情诉` 只作转介进本窗；本窗打开为主路径，不是已提交、不是已改约、不是已解除、不是已立案。本窗 `Q-故` 只转介 `评估不可抗力情势变更与履行不能`。本窗 `Q-变` 只转介 `评估变更是否成立`。本窗 `Q-诉` 只转介 `提起合同纠纷一审`。本窗 `Q-除` 只转介 `评估解除权是否成立`。本窗 `Q-签` 只作「草稿即已提交或已立案」不关窗码。情诉闸打开不等于已提交不等于已立案不等于已改约不等于已解除不等于应起诉不等于管辖已定不等于待提交终稿。草稿不是已提交。网交不是已提交。通知不是解除。商业风险不是情势。情势不是不可抗力。请求变更不是法院可径行解除。立案日或起诉当日不是变更或解除时点。排除第五百三十三条的事先约定不是有效。有效仲裁协议不是应起诉。此致某院不是管辖已定。未知不写零。不代提交。不选定法院。不定罪。不保证受理。伤残等级与本窗无关，禁止折入。

`depends-on` 为空。主成果是变故评估终稿转 `评估不可抗力情势变更与履行不能`。主成果是合意改约是否成立转 `评估变更是否成立`。主成果是通知解除路径转 `评估解除权是否成立` 或 `准备解除通知`。主成果是普通给付诉状转 `提起合同纠纷一审`。主成果是成立效力确认转 `提起合同成立或效力确认之诉`。主成果是继续履行可行性终稿转 `评估继续履行是否可能`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：已判断可能适用情势变更，需请求人民法院或仲裁机构变更或解除，需要材料草稿。「今晚交出去」「发个通知就算解除」「行情不好就算情势」仍正触发，成果状态 `草案`。再交涉、请求互斥、时点未核验仍正触发：有可编号原告适格、重大变化碎片或起诉决定碎片则情诉闸打开或半开，第 6 节出 `QY#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出已提交／已立案／已改约／已解除终稿」才关闸，仍交十节，第 6 节不出 `QY#` 终稿，第 7 节不得出发送版起诉状，窗口不关。用户要把草稿写成已提交、把通知写成已解除、把商业风险写成情势、把请求变更写成法院可径行解除、把立案日写成变更或解除时点、把排除特约写成有效、把此致某院写成管辖已定、把未知写成零，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `QY#` 草案。不得因「不代提交」「不选定法院」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是变故评估终稿（转 `评估不可抗力情势变更与履行不能`）；
- 主成果是合意改约是否成立（转 `评估变更是否成立`）；
- 主成果是通知解除路径（转 `评估解除权是否成立` 或 `准备解除通知`）；
- 主成果是普通给付诉状（转 `提起合同纠纷一审`）；
- 主成果是成立、无效或撤销确认（转 `提起合同成立或效力确认之诉`）；
- 主成果是继续履行可行性终稿（转 `评估继续履行是否可能`）；
- 主成果是争议总图（转 `评估合同争议`）；
- 尚未成争，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）；
- 尚未评估变故定性、只要策略。

双方秘密、伪造指数或疫情政策证明、倒签再交涉或落款、虚假诉讼、违法取证**不在负触发表**，走整体停止。「草稿即已提交」「通知即解除」「商业风险即情势」「请求变更即法院可径行解除」「立案日即变更或解除时点」「排除特约有效」「此致某院即管辖已定」「未知写零」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不代提交」「不选定法院」是交付禁令，不是负触发。主成果才转；出现「情势」「变更」「解除」一词不是转出。

## 建立工作坐标

确认：起诉或申请仲裁授权；单方立场；合同文本；基础条件变化碎片；再交涉记录；请求类型（变更／解除）；仲裁条款；法域。

口头「今晚交出去」「发个通知就算解除」「行情不好就算情势」只登记 `S#`／`V#`。不得升格已提交、已立案、已改约或已解除，**不得单独算作开闸材料**。可编号原告适格、重大变化碎片或起诉决定碎片可开闸。本窗不执行发送，不代提交，不选定法院。

立场只许受不利影响的当事人或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：情诉闸关闭，仍交十节，不是整体停止。无书面授权但单方立场已闭合、且已有碎片：情诉闸部分打开，仍交十节，不是整体停止。提出伪造指数或疫情政策证明、倒签再交涉或落款、虚假诉讼或违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`QY#` 情诉行；`V#` 版本；`E#` 证据形态回链（合同文本、重大变化对照、再交涉、授权，不是发送闸，不是已提交证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`QT#`、`WG#`、`BY#`、`JC#`、`QR#`、`QS#`。技能正文中的条号是检索锚点，不是已核验 `L#`。文件状态只用 `草案`、`待提交`、`停止`。再交涉、请求互斥或仲裁未闭合不得标 `待提交`。商业风险未切开不得标 `待提交`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。未知不写零。草稿 ≠ 已提交。通知 ≠ 解除。商业风险 ≠ 情势。请求变更 ≠ 法院可径行解除。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或文书范本检索。本窗是形成之诉材料草稿，范本只借民事起诉状栏目，**不要**升格「已提交／已立案／已改约／已解除／管辖已定」，**不要**用类案写成必然改约或必然解除。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现通知即解除、商业风险即情势、请求变更即径行解除、无再交涉即可交终稿、草稿即已提交、此致某院即管辖已定的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效合同法解释（二）第二十六条、把情势写成不可抗力第一百八十条或第五百九十条、把裁判变更写成协商一致第五百四十三条、把情势解除写成第五百六十五条通知解除当作现行。MCP 查询第一百二十二条可能先返回 1991 年开庭通知条，须核 2023 修正起诉条件。实务检索若仍写「非不可抗力」或「不能实现合同目的」作为情势要件，记为噪声。MCP 效力字段与公布施行日冲突时，以施行日为准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的再交涉、请求互斥、管辖、仲裁保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民法典第五百三十三条——合同成立后基础条件发生订立时无法预见、不属于商业风险的重大变化，继续履行明显不公平的，受不利影响的当事人可以重新协商；合理期限内协商不成的，请求人民法院或仲裁机构变更或解除，不是通知即解除。合同编通则解释第三十二条：政策调整或供求异常导致无法预见且非商业风险的价格涨跌可认定重大变化，大宗商品、股票、期货等活跃价格波动除外；当事人请求变更的，人民法院不得解除；一方变更对方解除或一方解除对方变更的，按公平原则判决；裁判应明确变更或解除时间；事先约定排除第五百三十三条的，无效。民事诉讼法（2023 修正）第一百二十二条起诉条件。噪声：MCP 可能先返回 1991 年第一百二十二条开庭三日前通知；2017 年第一百十九条。第一百二十四条起诉状应记事项。噪声：已失效合同法解释（二）第二十六条；第一百八十条、第五百九十条不可抗力；第五百四十三条协商一致变更；第五百六十五条通知解除。技能正文条号不是 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变再交涉、变更／解除互斥、裁判时点或起诉条件的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补通知不是解除、商业风险不是情势、请求变更不是法院可径行解除、无再交涉不是可交终稿、草稿不是已提交、有效仲裁不是应直接起诉、此致某院不是管辖已定的实务反例。
- `search_template` 只借民事起诉状栏目（当事人／诉讼请求／事实与理由／证据名称／证明对象／原件复印件）。范本落款、此致某院、立案结论、变更或解除结论不得升格已提交、已立案、已改约、已解除或管辖已定。禁止把情势之诉改写成给付之诉或确认之诉。禁止用普通给付、无效确认、撤销权、代位权、不可抗力通知或解除通知范本改头换面。禁止用范本生成发送版起诉状。

工具不可用时继续再交涉、请求互斥、重大变化碎片和 `QY#` 编目；管辖、仲裁、施行日字段停止。不得拒跑，不得凭记忆写成已提交、已改约或通知已解除。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、情诉闸与不关窗

主成果才整案转出。双方秘密、伪造指数、倒签再交涉、虚假诉讼第一次停。通知即解除、商业风险即情势不关窗。闸关仍交十节，第 6 节不出 `QY#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

原告适格、明确被告、再交涉、变更或解除互斥、仲裁独立性分列。本节禁止出 `QY#` 终稿。

### 3. 情诉闸与路径 `Q#`

本节禁止出 `QY#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-情诉`。

### 4. 情诉行 `QY#`

请求切片、原告适格与被告明确、管辖与仲裁、再交涉与变更解除互斥时点、证据目录。状态 `草案`。禁止升格已提交、已立案、已改约、已解除。无 `E#` 不得写已提交。再交涉或请求互斥未闭合不得标 `待提交`。

### 5. 变故、合意变更、解除、保全接口

变故评估转变故窗。合意改约转变约窗。通知解除转解除窗。保全只开接口。第 7 节不得夹带 `QY#` 终稿或发送版起诉状绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造指数或疫情政策证明、倒签再交涉或落款、虚假诉讼或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：情诉闸关闭，仍交十节，不是整体停止。无书面授权但有碎片：情诉闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：再交涉、管辖、请求互斥、时点、施行日未核验。草稿即已提交、通知即解除、商业风险即情势、请求变更即法院可径行解除、立案日即变更或解除时点、排除特约有效、此致某院即管辖已定、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `QY#` 草案。
- `目标停止`：主目标变为变故评估终稿、通知解除函、合意改约评估或普通给付诉状。禁止把「通知即解除」或「商业风险即情势」当作用户错误主张时的目标停止；那是不关窗。

禁止指导伪造指数或倒签再交涉。不给胜诉率。不定罪。不选定法院。不代提交。未知不写零。不写发送版起诉状。

## 交付
