# 边界与路由

## 正触发

已判断可能适用情势变更，需请求人民法院或仲裁机构变更或解除，需要材料草稿。从零、碎片、再交涉未核验、无书面授权仍正触发：有可编号原告适格、重大变化碎片或起诉决定碎片则闸开或半开，出 `QY#` 草案，保持草案。本次不代提交、不选定法院是交付禁令，不是开窗条件。草稿即已提交、通知即解除、商业风险即情势，仍正触发。把请求变更写成法院可径行解除、把立案日写成变更或解除时点，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造指数、倒签再交涉、虚假诉讼的停止，优先于负触发。上述信号不在下表。不代提交不是负触发。「草稿即已提交」「通知即解除」「商业风险即情势」「请求变更即法院可径行解除」「立案日即变更或解除时点」「排除特约有效」「此致某院即管辖已定」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 变故评估终稿 | `评估不可抗力情势变更与履行不能` |
| 合意改约是否成立 | `评估变更是否成立` |
| 通知解除路径 | `评估解除权是否成立` 或 `准备解除通知` |
| 普通给付诉状 | `提起合同纠纷一审` |
| 成立、无效或撤销确认 | `提起合同成立或效力确认之诉` |
| 继续履行可行性终稿 | `评估继续履行是否可能` |
| 争议总图 | `评估合同争议` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |
| 尚未评估变故定性，只要策略 | `评估不可抗力情势变更与履行不能` |

不得因「不代提交」或「不选定法院」关窗。拟情势草稿仍正触发，不得写成已提交、已改约或已解除。

## 易混

本窗闸名只能是情诉闸，不是起诉闸，不是变故闸，不是变约闸，不是解除闸，不是确诉闸，不是情势闸。`QY#` 不是 `QT#`，不是 `WG#`，不是 `BY#`，不是 `JC#`，不是 `QR#`，不是 `QS#`。主路径是 `Q-情诉`，不是 `Q-诉`，不是 `Q-故`，不是 `Q-变`，不是 `Q-除`，不是 `Q-势`。`变故闸`／`Q-故` 是评估不可抗力情势变更与履行不能。`变约闸`／`Q-变` 是评估变更是否成立。`解除闸`／`Q-除` 是评估解除权是否成立。`起诉闸`／`Q-诉` 是提起合同纠纷一审。`确诉闸`／`Q-确诉` 是提起合同成立或效力确认之诉。`QS#` 是企业合规诉材行。`Q-势` 是变故窗「亏损即情势」不关窗码。草稿不是已提交。通知不是解除。商业风险不是情势。请求变更不是法院可径行解除。MCP 查询第一百二十二条可能先返回 1991 年开庭通知条，须核 2023 修正起诉条件。2017 年第一百十九条不是现行。已失效合同法解释（二）第二十六条不是现行。第一百八十条、第五百九十条不是本窗主条。第五百四十三条不是裁判变更。第五百六十五条不是情势解除。「今晚交出去」「再交涉日期改到涨价当日」整体停止。本窗不执行发送，不代提交。不选定法院。不写发送版起诉状。
