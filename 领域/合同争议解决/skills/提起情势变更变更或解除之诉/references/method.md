# 提起情势变更变更或解除之诉方法

本文件是可执行判断节点。通知不是解除。商业风险不是情势。请求变更不是法院可径行解除。草稿不是已提交。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已提交、已立案、已改约、已解除、选定法院、代提交、未知写零。本任务不定罪，不写发送版起诉状，不把通知写成已解除。本窗闸名只能是情诉闸，禁止复用起诉闸、解除闸、变故闸、变约闸、确诉闸、情势闸。预留不得占用：立案闸、和解闸、发送闸、催告闸。本窗 `QY#` 是情诉行。主路径只用 `Q-情诉`，禁止用 `Q-诉`、`Q-故`、`Q-变`、`Q-除`、`Q-签` 作主路径。本窗 `Q-签` 只作「草稿即已提交或已立案」不关窗码。英文 id 禁止使用，一律用中文技能名 `提起情势变更变更或解除之诉`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991 年民诉第一百二十二条开庭通知、2017 年第一百十九条、已失效合同法解释（二）第二十六条、把情势写成不可抗力第一百八十条或第五百九十条、把裁判变更写成第五百四十三条、把情势解除写成第五百六十五条时记为噪声。实务检索若仍写「非不可抗力」或「不能实现合同目的」作为情势要件，记为噪声。禁止指导伪造指数或倒签再交涉。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现请求碎片扫描，不是默认闭集。
`QY#` 固定列：`编号｜请求切片｜原告适格与被告明确｜管辖与仲裁接口｜再交涉与变更解除互斥时点｜证据目录重大变化商业风险排除与保全红旗｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已提交」或「已立案」。无 `E#` 不得写已提交。再交涉或请求互斥未闭合不得标 `待提交`。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-情诉`。禁止 `QT#`、`WG#`、`BY#`、`JC#`、`QR#`、`QS#`、`A#`、`N#`。

口头「今晚交出去」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：情势变更是形成之诉，须裁判变更或解除。先再交涉，协商不成才请求裁判。请求变更则裁判不得径行解除。时点不是立案日、不是起诉当日。大宗商品、股票、期货活跃波动通常除外。

## 节点 0　分流、立场、情诉闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造指数、倒签再交涉、虚假诉讼不进负表。利益冲突未解不进整体停止。不代提交、不选定法院不是负触发。把通知写成已解除、把商业风险写成情势不是负触发。

整案转出只交付第 1、2、10 节，不出 `QY#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是变故评估终稿 | 负触发 `评估不可抗力情势变更与履行不能` |
| 主成果是合意改约是否成立 | 负触发 `评估变更是否成立` |
| 主成果是通知解除路径 | 负触发 `评估解除权是否成立` 或 `准备解除通知` |
| 主成果是普通给付诉状 | 负触发 `提起合同纠纷一审` |
| 主成果是成立、无效或撤销确认 | 负触发 `提起合同成立或效力确认之诉` |
| 主成果是继续履行可行性终稿 | 负触发 `评估继续履行是否可能` |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 尚未评估变故定性，只要策略 | 负触发 `评估不可抗力情势变更与履行不能` |
| 建设工程／金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不代提交」「不选定法院」 | 交付禁令，不是负触发 |

出现「情势」「变更」「解除」一词不是转出。

情诉闸打开（可出 `QY#` 草案，仍不得标「已提交／已立案／已改约／已解除」）须同时满足：单方无冲突立场已闭合；主成果是请求裁判变更或解除的材料草稿，不是发送版终稿；至少一行可编号原告适格、重大变化碎片或起诉决定碎片。口头「今晚交出去」不算单独开闸材料。

情诉闸部分打开：已有碎片，但再交涉、请求互斥、时点或仲裁未闭合；对应格待核；仍交十节。无书面授权但单方立场已闭合且已有碎片：情诉闸部分打开，仍交十节，不是整体停止。

情诉闸关闭（仍正触发）：无一可编号碎片。「今天必须出已提交／已立案／已改约终稿」而无最小碎片不得开闸。不出 `QY#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `QY#` 终稿，**第 7 节不得出发送版起诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已提交」「通知即解除」「商业风险即情势」「请求变更即法院可径行解除」「立案日即变更或解除时点」「排除特约有效」「此致某院即管辖已定」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `QY#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 情诉闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造指数或疫情政策证明、倒签再交涉或落款、虚假诉讼或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 3　情诉行 `QY#`

按已出现请求碎片扫描，不是默认闭集。每条须能指向再交涉、重大变化、商业风险排除、变更解除互斥或证据目录之一。

无 `E#` 不得写已提交。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止唯一截止日。再交涉或请求互斥未闭合不得标 `待提交`。商业风险未切开不得标 `待提交`。请求变更与请求解除不得合成一条已可执行终稿。

热冲突强制处理：

- 草稿即已提交／通知即解除／商业风险即情势／请求变更即径行解除／立案日即变更或解除时点／排除特约有效／此致某院即管辖已定／未知写零 → 该格不支持或字段停止；仍出其他 `QY#`。
- 无一碎片 → 关闸，不出 `QY#` 终稿，窗口不关。
- 指导伪造指数、倒签再交涉、虚假诉讼 → 整体停止，不是该格不支持。

## 节点 4　变故、合意变更、解除、保全接口

第 7 节只开接口，不得夹带 `QY#` 终稿或发送版起诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待请求编号」，不得补写已提交。不选定法院。不代提交。不写发送版起诉状。

下一步只转介：`评估不可抗力情势变更与履行不能`、`评估变更是否成立`、`评估解除权是否成立`、`准备解除通知`、`评估继续履行是否可能`、`提起合同纠纷一审`、`应对合同纠纷一审`、`评估合同管辖与仲裁协议`、`提起合同仲裁`、`选择诉讼仲裁或督促程序`、`提起合同成立或效力确认之诉`、`处理解除后返还与清理`、`测算违约金与损害赔偿`、`建立合同争议证据案卷`、`谈判合同和解方案`、`评估合同争议`、`评估合同财产保全必要性`、`准备合同财产保全申请`、`准备对合同解除通知的异议`。禁止此致某院。

若 if 用户催促「今晚交出去／发个通知就算解除／行情不好就算情势／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「情诉闸与情诉行草案」。本窗不执行发送。不包含：已提交、已立案、已改约、已解除、发送版起诉状。禁止选边治愈。禁止通知即解除。禁止商业风险即情势。禁止指导伪造。情诉闸打开 ≠ 已提交 ≠ 已立案 ≠ 已改约 ≠ 已解除。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标情诉终稿已形成。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：买卖合同成立后原材料暴涨，用户主张发个微信就算解除、行情不好就是情势、只要改价法院也可以直接解约、今天立案就算已经变更、合同里写了不适用情势变更所以更能打、此致某中院、不清楚先写零。情诉闸打开或半开。`Q-签`、`Q-通`、`Q-险`、`Q-径`、`Q-拟`、`Q-排`、`Q-院`、`Q-零` 不打开为可靠路径。第 6 节不得把已提交、已解除、已改约、径行解除、立案日时点、0、此致某院写入可执行 `QY#`；对应格 `现有依据不支持` 或字段停止；仍出请求分列、再交涉缺口、商业风险对照、变更解除互斥、裁判时点待核等其他 `QY#`。不关窗。不代提交。不写发送版。

场景②：用户同时交出己方「再交涉日期改到涨价当日、指数用空白章补一份」与对方「这就是正常行情」口径，并要「先立案再说」。命中双方秘密＋倒签＋伪造。第一次整体停止。只交第 1、10 节。不出 `QY#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代违法方案。
