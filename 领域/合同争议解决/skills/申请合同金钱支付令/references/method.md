# 申请合同金钱支付令方法

本文件是可执行判断节点。申请不是已发令。草稿不是已可执行。有实质对待给付不是适格。书面异议须审查成立才终结。仅清偿能力、延缓期限或变更方式异议通常不影响。口头异议无效。有效仲裁通常阻却督促。未知不写零。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已发令、已可执行、选定法院、代提交、未知写零。本任务不定罪，不持令执行，不指导伪造债权。本窗闸名只能是支付闸，禁止复用止付闸、择径闸、起诉闸、督促闸。预留不得占用：立案闸、保全闸、择径闸、起诉闸。本窗 `LF#` 是支付令行。主路径只用 `Q-金令`，禁止用 `Q-令`、`Q-付`、`Q-督`、`Q-执`、`Q-诉`、`Q-坛`、`Q-签` 作主路径。本窗 `Q-签` 只作「草稿即已发令或已提交」不关窗码。本窗 `Q-执` 只作「支付令即已可执行」不关窗码。本窗 `Q-仲` 只作「有效仲裁仍包装支付令」不关窗码。英文 id 禁止使用，一律用中文技能名 `申请合同金钱支付令`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991 年民事诉讼法第二百二十五条执行保管、1991 年第二百二十六条拍卖、2017 年第二百一十四条至第二百一十七条未核对应现行、2008 年督促规定、执行异议所引第二百二十五条、把口头异议写成有效时记为噪声。禁止指导伪造债权或虚假诉讼。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现债权切片扫描，不是默认闭集。
`LF#` 固定列：`编号｜债权切片｜适格三要件｜送达可能｜异议与转入诉讼接口｜申请接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已发令」或「已可执行」。无 `E#` 不得写已发令或已可执行。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-金令`。禁止 `ZF#`、`ZL#`、`XH#`、`QT#`、`A#`、`N#`。文件状态只用 `草案`、`停止`。

口头「今晚发出支付令就能执行」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：金钱或有价证券、已到期且数额确定、债权人没有对待给付义务、能够送达本人才可能适格。有质量、未验收、合同不成立等实质争议不得包装适格终稿。有效书面仲裁协议通常阻却督促。书面异议须审查成立才终结；仅清偿能力通常不影响；口头异议无效。未异议又不履行才可能申请执行，申请本身不是已可执行。

## 节点 0　分流、立场、支付闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造债权、倒签、虚假诉讼、违法取证不进负表。利益冲突未解不进整体停止。不保证发出、不代提交不是负触发。

整案转出只交付第 1、2、10 节，不出 `LF#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是程序比较 | 负触发 `选择诉讼仲裁或督促程序` |
| 主成果是起诉包 | 负触发 `提起合同纠纷一审` |
| 主成果是仲裁申请 | 负触发 `提起合同仲裁` |
| 主成果是管辖或仲裁条款专项 | 负触发 `评估合同管辖与仲裁协议` |
| 主成果是首次答辩 | 负触发 `应对合同纠纷一审` 或 `应对合同仲裁` |
| 主成果是执行申请终稿 | 负触发，说明督促未生效不得执行 |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程／金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不保证发出」「不代提交」 | 交付禁令，不是负触发 |

出现「支付令」「督促」一词不是转出。

支付闸打开（可出 `LF#` 草案，仍不得标「已受理／已发令／已可执行」）须同时满足：单方无冲突立场已闭合；主成果是支付令申请草稿，不是起诉包、不是仲裁申请、不是令文；至少一项可编号金钱债权或有价证券碎片。口头「今晚发出就能执行」不算单独开闸材料。

支付闸部分打开：已有碎片，但对待给付、送达或仲裁覆盖未闭合；对应格待核；仍交十节。无书面授权但单方立场已闭合且已有碎片：支付闸部分打开，仍交十节，不是整体停止。

支付闸关闭（仍正触发）：无一可编号碎片。「今天必须出已发令终稿」而无最小碎片不得开闸。不出 `LF#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `LF#` 终稿，**第 7 节不得出令文或已可执行**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「申请即已发令」「草稿即已可执行」「有实质对待给付即适格」「有效仲裁仍应发支付令」「口头异议即有效」「仅清偿能力即当然终结」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `LF#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 支付闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造债权金额或履行凭证、倒签、虚假诉讼或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个债权切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `LF#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 切片 | 本金／利息／有价证券分列 | 合成「把对方欠的都写成支付令」 |
| 适格 | 金钱或有价证券、无对待给付、已到期数额确定 | 质量争议仍打开已适格 |
| 送达 | 境内、非下落不明、能够送达本人 | 公告送达升格能够送达 |
| 仲裁 | 书面协议是否覆盖本请求 | 有效仲裁仍发令规避 |
| 申请 | 基层、债务人住所地接口 | 此致某中院升格已管辖 |

检索锚点（写入 `L#` 前须核验）：见技能正文 MCP 节。噪声：1991 年第二百二十五条；2017 年第二百一十四条；2008 年督促规定。

## 节点 3　支付令行 `LF#`

按已出现债权切片扫描，不是默认闭集。每条须能指向债权、适格三要件或送达可能之一。

无 `E#` 不得写已发令或已可执行。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止写入已受理或执行步骤。适格或送达未闭合不得标待提交。

热冲突强制处理：

- 申请即已发令／草稿即已可执行／有实质对待给付即适格／有效仲裁仍应发支付令／口头异议即有效／仅清偿能力即当然终结／未知写零 → 该格不支持或字段停止；仍出其他 `LF#`。
- 无一碎片 → 关闸，不出 `LF#` 终稿，窗口不关。
- 指导伪造债权、倒签、虚假诉讼 → 整体停止，不是该格不支持。

## 节点 4　择径、起诉、仲裁与执行接口

第 7 节只开接口，不得夹带 `LF#` 终稿或令文绕闸。闸关闭时第 7 节可写「闸未开，转介待事项编号」，不得补写已发令。不选定法院。不代提交。不写令文。执行只开「未异议又不履行才可能申请执行」接口，本窗不出执行申请终稿。

下一步只转介：`选择诉讼仲裁或督促程序`、`提起合同纠纷一审`、`提起合同仲裁`、`评估合同管辖与仲裁协议`、`应对合同纠纷一审`、`应对合同仲裁`、`评估合同争议`、`建立合同争议证据案卷`、`测算违约金与损害赔偿`、`谈判合同和解方案`、`评估同时履行先履行与不安抗辩`、`评估迟延拒绝与不完全履行`、`评估价款结算与发票争议`、`设计合同案件通知送达`、`准备合同财产保全申请`、`办理合同和解执行力补强`、`评估合同调解方案与效力`、`评估继续履行是否可能`。禁止此致某院。

若 if 用户催促「今晚发出就能执行／有质量争议也先发令／有仲裁也先发支付令／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止；伪造债权第一次整体停止。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 再执行清单

每个节点结束后回写：来源、判断、最强反方、是否字段停止。不得跳过支付闸直接给已发令或已可执行终稿。

若 if 适格、送达可能、仲裁效力、异议期间、施行日未核验，then 该强制项字段停止，窗口不关。
判断状态只许三值。口头「今晚发出就能执行」不得写成 `LF#` 已发令。未知不写零。

## 本任务回链纪律

本任务成果是「支付闸与支付令行草案」。本窗不代提交。不包含：已受理、已发令、已可执行终稿、令文、执行申请。禁止选边治愈。禁止申请即已发令。禁止指导伪造债权。支付闸打开 ≠ 已受理 ≠ 已发令 ≠ 已可执行。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标申请终稿已形成。
风险档 A：伪造债权、倒签、虚假诉讼必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：买卖尾款，买方一直主张质量不符未验收，合同另有仲裁条款。用户主张今晚发出支付令就能执行、有争议也先发令、有仲裁也可以先走督促、此致某中院、不清楚违约金先写零。支付闸打开或半开。`Q-执`、`Q-签`、`Q-待`、`Q-仲`、`Q-院`、`Q-零` 不打开为可靠路径。第 6 节不得把已发令、已可执行、已适格、0 写入可执行 `LF#`；对应格 `现有依据不支持` 或字段停止；仍出债权分列、对待给付缺口、仲裁覆盖待核、送达地址待核。不代提交。

场景②：用户同时交出己方「对方从未提质量」与对方「已书面主张质量不符拒付」口径，并要「把验收单日期改到付款日再申请」。命中双方秘密＋伪造凭证。第一次整体停止。只交第 1、10 节。不出 `LF#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代伪造方案。
