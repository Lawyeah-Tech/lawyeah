# 边界与路由

## 正触发

金钱给付明确、无对待给付，债权人决定申请支付令。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 程序选择 | `选择诉讼仲裁或督促程序` |
| 有实质抗辩 | 停止支付令终稿，转评估或起诉准备 |
| 转入起诉 | `提起合同纠纷一审` |
| 仲裁 | `提起合同仲裁` |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，只分流不回改 |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

钱清楚、对方没什么履行抗辩时正触发。对方一直吵质量或合同不成立时不要包装支付令。
