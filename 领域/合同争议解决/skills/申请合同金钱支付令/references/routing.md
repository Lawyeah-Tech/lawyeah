# 边界与路由

## 正触发

一般合同已成争，债权人拟就到期、数额确定的金钱或有价证券申请支付令草稿。从零、碎片、对待给付或送达未核验仍正触发：有可编号金钱债权或有价证券碎片则闸开或半开，出 `LF#` 草案，保持草案。本次不保证发出、不代提交是交付禁令，不是开窗条件。申请即已发令、草稿即已可执行，仍正触发。把有实质对待给付写成适格、把有效仲裁写成仍应发支付令、把口头异议写成有效，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造债权、虚假诉讼的停止，优先于负触发。上述信号不在下表。不保证发出不是负触发。「申请即已发令」「草稿即已可执行」「有实质对待给付即适格」「有效仲裁仍应发支付令」「口头异议即有效」「仅清偿能力即当然终结」「保证发出」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 程序比较 | `选择诉讼仲裁或督促程序` |
| 起诉包 | `提起合同纠纷一审` |
| 仲裁申请 | `提起合同仲裁` |
| 管辖或仲裁条款专项 | `评估合同管辖与仲裁协议` |
| 首次答辩 | `应对合同纠纷一审` 或 `应对合同仲裁` |
| 执行申请终稿 | 督促未生效不得执行，本窗不出执行终稿 |
| 争议总图 | `评估合同争议` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不保证发出」或「不代提交」关窗。拟申请草稿仍正触发，不得写成已发令或已可执行。

## 易混

本窗闸名只能是支付闸，不是止付闸，不是择径闸，不是起诉闸，不是督促闸，不是立案闸。`LF#` 不是 `ZF#`，不是 `XH#`，不是 `QT#`，不是 `ZL#`。主路径是 `Q-金令`，不是 `Q-令`，不是 `Q-付`，不是 `Q-督`，不是 `Q-执`，不是 `Q-诉`。`止付闸`／`ZF#` 是合规内部账户止付。`择径闸`／`XH#`／`Q-督` 是选择诉讼仲裁或督促程序。`起诉闸`／`QT#`／`Q-诉` 是提起合同纠纷一审。`论坛闸`／`LT#`／`Q-坛` 是评估合同管辖与仲裁协议。`Q-令` 是合规责令改正。`Q-付` 是解异窗不关窗。1991 年民事诉讼法第二百二十五条执行保管不是支付令。1991 年第二百二十六条拍卖不是五日受理。2017 年第二百一十四条须核对应现行第二百二十五条。2008 年督促规定已失效。执行异议复议规定所引第二百二十五条、第二百二十七条不是督促。督促执行令不是支付令申请书。台湾支付命令二十日期限不是中国大陆十五日。提出「把验收单日期改到付款日再申请」整体停止。本窗不代提交。不选定法院。不写令文。不保证发出。
