# 边界与路由

## 正触发

已决定申请诉前或诉中财产保全。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 尚未决定 | `评估合同财产保全必要性` |
| 应对保全 | `应对合同案件保全裁定` |
| 先予执行 | unavailable（P2） |
| 调查令补线索 | `申请律师调查令或法院调查取证` |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，只分流不回改 |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

已决定冻结财产、要申请包时正触发。还在评估要不要保时转评估。已被保全时转应对。
