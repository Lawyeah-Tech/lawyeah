# 边界与路由

## 正触发

一般合同已成争，已决定申请诉前或诉中财产保全。从零、碎片、担保未核验、无书面授权仍正触发：有可编号拟保全对象碎片则闸开或半开，出 `SB#` 草案，保持草案。本次不保证裁定、不代提交是交付禁令，不是开窗条件。草稿即已裁定、担保即已保全、保证准许，仍正触发。把线索写成已冻结、把三十日写成已起诉，仍正触发：该格不支持，不改负触发关窗。

双方秘密、虚构紧急、指导隐匿的停止，优先于负触发。上述信号不在下表。不保证裁定不是负触发。「草稿即已裁定」「担保即已保全」「线索即已冻结」「口头紧急即四十八小时已裁」「三十日即已起诉」「此致某院即管辖已定」「保证准许」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 必要性评估 | `评估合同财产保全必要性` |
| 复议或换保终稿 | `应对合同案件保全裁定` |
| 先予执行 | `unavailable` |
| 行为保全申请 | `unavailable` |
| 现场或电子自固 | `保全质量现场与电子证据` |
| 起诉包 | `提起合同纠纷一审` |
| 仲裁申请包 | `提起合同仲裁` |
| 争议总图 | `评估合同争议` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不保证裁定」或「不代提交」关窗。拟申请草稿仍正触发，不得写成已裁定或已冻结。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |

| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流。出现「保全」「冻结」一词不是转出。C 端只要大众填空页时只分流，不把本包降成填空式结论，不回改。股东争议、冻结股权表决或禁开会主轴转公司治理，不抢保全闸。

## 易混

本窗闸名只能是申保闸，不是保全闸，不是要保闸，不是冻结闸，不是现证闸，不是封存闸。`SB#` 不是 `BQ#`，不是 `YB#`，不是 `FZ#`，不是 `XZ#`。主路径是 `Q-申保`，不是 `Q-保`，不是 `Q-要`，不是 `Q-冻`，不是 `Q-账`，不是 `Q-现`，不是 `Q-申`。`保全闸`／`BQ#`／`Q-保` 是公司治理准备股权或公司财产保全；邻窗 `Q-保` 只转介进本窗，本窗改走 `Q-申保`。`要保闸`／`YB#`／`Q-要` 是评估合同财产保全必要性。`冻结闸`／`FZ#`／`Q-冻` 是应对股权冻结或行为保全。草稿不是已裁定。担保不是已保全。线索不是已冻结。诉前三十日不是已起诉。1991 年民事诉讼法第一百零三条协助执行罚款不是现行保全条。2017 年第一百条、第一百零一条须核对应现行第一百零三条、第一百零四条。仲裁法第三十九条 MCP 标尚未施行时以施行日为准。提出「申请日改到昨天」「把案外人住房也先封上」整体停止。本窗不执行发送，不代提交。不选定法院。不写发送版。不保证裁定。
