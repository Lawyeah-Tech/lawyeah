# 边界与路由

## 正触发

一般合同权利人持判决、调解书、裁决、支付令或赋强文书，需要强制执行申请草稿。从零、碎片、生效或二年未核验仍正触发：有可编号名义碎片则闸开或半开，出 `ZE#` 草案，保持草案。本次不代提交、不保证控制财产是交付禁令，不是开窗条件。申请即已立案、未签收即已可执行，仍正触发。把单独和解写成已可强制执行、把过期写成当然不受理，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造线索、指导隐匿转移的停止，优先于负触发。上述信号不在下表。不代提交不是负触发。「申请即已立案」「草稿即已查控」「未签收即已可执行」「单独和解即已可强制执行」「已读即起算」「过期仍要可提交普通终稿」「保证控制财产」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 被执行应对 | `应对合同案件执行` |
| 执行中和解 | `准备合同执行和解` |
| 不予执行申请 | `申请不予执行仲裁裁决` |
| 撤裁申请 | `申请撤销仲裁裁决` |
| 私下和解要执行力 | `办理合同和解执行力补强` |
| 上诉状 | `提起合同案件上诉` |
| 保全申请终稿 | `准备合同财产保全申请` |
| 支付令申请 | `申请合同金钱支付令` |
| 复杂追加或拒执刑责终稿 | `unavailable` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不代提交」或「不保证控制财产」关窗。拟执行申请草稿仍正触发，不得写成已立案或已查控。

## 易混

本窗闸名只能是执行闸，不是申请闸，不是执申闸，不是不执闸，不是支付闸，不是保全闸，不是强制闸。`ZE#` 不是 `ZX#`，不是 `BZ#`，不是 `LF#`，不是 `QF#`，不是 `Enf#`。主路径是 `Q-执申`，不是 `Q-执`，不是 `Q-申`，不是 `Q-金令`，不是 `Q-不执`。`仲异闸`／`ZX#`／`Q-仲异` 是准备合同仲裁协议异议材料。`不执闸`／`BZ#`／`Q-不执` 是申请不予执行仲裁裁决。`Q-执` 是不关窗码。邻窗应对窗预留应执闸／`NZ#`／`Q-应执`。邻窗执和窗预留执和闸／`TH#`／`Q-执和`。1991 年第二百一十九条不是现行二年。2017 年第二百三十九条每次分别起算不是现行最后一期。2017 年第二百三十七条不是现行超六个月未执行条。1991 年第一百条不是调解书签收。解释仍引第二百四十六条须核第二百五十条。提出「签收日改到上周、把账户今晚转空」整体停止。本窗不代提交。不选定法院。不写发送版。不保证控制财产。不重审实体。
