# 执行合同生效文书方法

本文件是可执行判断节点。申请不是已立案执行。草稿不是已采取强制措施。调解书签收才生效。单独和解不是已可强制执行。分期从最后一期届满起算，不是每次分别起算。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止到位率、已立案、已查控、选定法院、代提交、未知写零。本任务不定罪，不写发送版，不指导隐匿转移，不重审实体。本窗闸名只能是执行闸，禁止复用不执闸、支付闸、申请闸、保全闸、强制闸。预留不得占用：立案闸、保全闸、应执闸、执和闸。本窗 `ZE#` 是执申行。主路径只用 `Q-执申`，禁止用 `Q-执`、`Q-申`、`Q-金令`、`Q-不执`、`Q-签` 作主路径。本窗 `Q-执` 只作「草稿即已可强制执行、已立案或已控制财产」不关窗码。本窗 `Q-签` 只作「草稿即已提交、已立案或已采取强制措施」不关窗码。英文 id 禁止使用，一律用中文技能名 `执行合同生效文书`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991 年第二百一十九条一年或六月、2017 年第二百三十九条每次分别起算、2017 年第二百三十七条仲裁裁决执行、1991 年第一百条拘传、把申请写成已立案时记为噪声。禁止指导隐匿转移或伪造线索。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现名义切片扫描，不是默认闭集。
`ZE#` 固定列：`编号｜名义切片｜生效与申请期间｜金额（本金／迟延／已履行）｜管辖连结点与财产线索｜申请接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已立案执行」或「已查控」。无 `E#` 不得写已立案。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-执申`。禁止 `ZX#`、`BZ#`、`LF#`、`ZC#`、`QF#`、`Enf#`、`A#`、`N#`。生效或二年未闭合不得标待提交。一行一个名义切片。金额未知写 `未知`／`G#`，禁止写 `0`。

口头「对方不给钱今晚去查封」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：调解书最后签收日才生效。私下和解不是执行名义。超期仍应受理，异议成立才可能不予执行。仲裁裁决管辖不得套一审法院。

## 节点 0　分流、立场、执行闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造文书或线索、倒签签收、指导隐匿转移、违法查人不进负表。利益冲突未解不进整体停止。不代提交、不保证控制财产、不重审实体不是负触发。

整案转出只交付第 1、2、10 节，不出 `ZE#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是被执行应对 | 负触发 `应对合同案件执行` |
| 主成果是执行中和解 | 负触发 `准备合同执行和解` |
| 主成果是不予执行申请 | 负触发 `申请不予执行仲裁裁决` |
| 主成果是撤裁申请 | 负触发 `申请撤销仲裁裁决` |
| 主成果是私下和解要执行力 | 负触发 `办理合同和解执行力补强` |
| 主成果是上诉状 | 负触发 `提起合同案件上诉` |
| 主成果是保全申请终稿 | 负触发 `准备合同财产保全申请` |
| 主成果是支付令申请 | 负触发 `申请合同金钱支付令` |
| 主成果是复杂追加或拒执刑责终稿 | 负触发 `unavailable` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程／金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不代提交」「不保证控制财产」「不重审实体」 | 交付禁令，不是负触发 |

出现「执行」一词不是转出。未生效仍要执行申请：本窗正触发，该格不支持，窗口不关。

执行闸打开（可出 `ZE#` 草案，仍不得标「已立案／已提交／已查控」）须同时满足：单方无冲突权利人立场已闭合；主成果是发送前执行申请草稿，不是被执行应对、不是执行和解、不是发送版；至少一项可编号名义碎片。口头「今晚去查封」不算单独开闸材料。

执行闸部分打开：已有碎片，但签收、二年、金额或线索未闭合；对应格待核；仍交十节。无书面授权但单方立场已闭合且已有碎片：执行闸部分打开，仍交十节，不是整体停止。

执行闸关闭（仍正触发）：无一可编号碎片。「今天必须出已立案终稿」而无最小碎片不得开闸。不出 `ZE#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `ZE#` 终稿，**第 7 节不得出发送版或已查控**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「申请即已立案」「草稿即已查控」「未签收即已可执行」「单独和解即已可强制执行」「已读即起算」「过期仍要可提交普通终稿」「未知写零」「执行中重审实体」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `ZE#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 执行闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造文书或线索、倒签签收、指导隐匿转移、违法查人或非法讨债，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个名义切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `ZE#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 名义 | 判决／调解书／裁决／支付令／赋强分列 | 私下和解当执行名义 |
| 生效 | 签收日与送达日分列 | 已读、作出日、拒收升格生效 |
| 期间 | 二年、履行届满、最后一期分列 | 2017 每次分别起算；已读起算 |
| 金额 | 本金／迟延／已履行分列 | 未知写零；执行中改判实体 |
| 管辖 | 判决一审或同级财产地；裁决住所地或财产地 | 裁决套一审法院；此致某院 |
| 线索 | 合法来源、控制方 | 伪造线索；指导转移 |

检索锚点（写入 `L#` 前须核验）：见技能正文 MCP 节。噪声：1991 年第二百一十九条；2017 年第二百三十九条；2017 年第二百三十七条；1991 年第一百条。

## 节点 3　执申行 `ZE#`

按已出现名义切片扫描，不是默认闭集。每条须能指向名义、生效、期间、金额或管辖线索之一。

无 `E#` 不得写已立案。状态默认 `草案`。一次只推荐下一步。未知不写零。未生效或私下和解不得标待提交。禁止写入已查控。

热冲突强制处理：

- 申请即已立案／草稿即已查控／未签收即已可执行／单独和解即已可强制执行／已读即起算／过期仍要可提交／未知写零／执行中重审实体 → 该格不支持或字段停止；仍出其他 `ZE#`。
- 无一碎片 → 关闸，不出 `ZE#` 终稿，窗口不关。
- 指导隐匿转移、伪造线索、倒签签收 → 整体停止，不是该格不支持。

## 节点 4　应对、和解、不执、力补与上诉接口

第 7 节只开接口，不得夹带 `ZE#` 终稿或已查控绕闸。闸关闭时第 7 节可写「闸未开，转介待名义编号」，不得补写已立案。不选定法院。不代提交。不写发送版。不保证控制财产。

下一步只转介：`应对合同案件执行`、`准备合同执行和解`、`申请不予执行仲裁裁决`、`申请撤销仲裁裁决`、`办理合同和解执行力补强`、`提起合同案件上诉`、`应对合同案件二审`、`申请合同金钱支付令`、`评估合同调解方案与效力`、`起草合同和解协议`、`谈判合同和解方案`、`准备合同财产保全申请`、`评估合同争议`、`建立合同争议证据案卷`、`提起合同纠纷一审`、`提起合同仲裁`、`选择诉讼仲裁或督促程序`。禁止此致某院。申请不得写成已立案。调解书未签收不得写成已可执行。

若 if 用户催促「申请了就算立案了／未签收也能执行／私下和解就能强制／不清楚利息先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 再执行清单

每个节点结束后回写：来源、判断、最强反方、是否字段停止。不得跳过执行闸直接给已立案或已查控。

若 if 生效或签收、二年、管辖、迟延利息、施行日未核验，then 该强制项字段停止，窗口不关。

## 本任务回链纪律

本任务成果是「执行闸与执申行草案」。本窗不代提交。不包含：已立案、已查控、发送版申请、不予执行终稿、被执行应对。禁止选边治愈。禁止申请即已立案。禁止指导隐匿转移。执行闸打开 ≠ 已提交 ≠ 已立案 ≠ 已控制财产。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标申请终稿已形成。
风险档 A：伪造线索、倒签签收、指导隐匿转移必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：2023 年调解书一方拒收，用户凭微信已读主张已生效、两年从作出日起算、去一审基层院执行仲裁裁决、过期也关窗、不清楚利息先写零、今晚网交就算立案。执行闸打开或半开。`Q-媒`、`Q-执`、`Q-期`、`Q-院`、`Q-零`、`Q-签` 不打开为可靠路径。第 6 节不得把已生效、已立案、0、此致某院写入可执行 `ZE#`；对应格 `现有依据不支持` 或字段停止；仍出名义分列、签收缺口、二年待核、裁决管辖待核。不关窗。不代提交。

场景②：用户同时交出权利人「签收日改到上周、把对方账户今晚转空」与被执行人「从未收到调解书」口径。命中双方秘密＋倒签＋指导转移。第一次整体停止。只交第 1、10 节。不出 `ZE#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代转移方案。
