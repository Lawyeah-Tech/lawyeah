# 执行合同生效文书

## 任务目标

在明确、无利益冲突的单方立场下（申请执行的权利人或其受托律师，互斥），形成发送前强制执行申请草稿：执行闸、主体与强制接口、`Q#` 路径、`ZE#` 执申行（名义切片／生效与申请期间／金额本金迟延已履行／管辖连结点与财产线索／申请接口／`E#` 回链）。本窗 `ZE#` 是执申行草案，不是已提交，不是已立案执行，不是已采取强制措施，不是已查封冻结扣划，不是不予执行终稿，不是被执行应对终稿。本窗闸名只能是执行闸，禁止复用申请闸、执申闸、不执闸、支付闸、仲裁闸、保全闸、冻结闸、力补闸、强制闸。预留不得占用：立案闸、保全闸、应执闸、执和闸。本窗主行只能是 `ZE#`，禁止 `ZX#`、`BZ#`、`LF#`、`ZC#`、`QF#`、`BQ#`、`FZ#`、`ZS#`、`SQ#`、`Enf#`、`A#`。主路径只用 `Q-执申`，禁止用 `Q-执`、`Q-申`、`Q-金令`、`Q-不执`、`Q-保`、`Q-力`、`Q-强`、`Q-签` 作主路径。邻窗 `Q-执申` 只作转介进本窗；本窗打开为主路径，不是已立案执行、不是已控制财产。本窗 `Q-执` 只作「草稿即已可强制执行、已立案或已控制财产」不关窗码。本窗 `Q-签` 只作「草稿即已提交、已立案或已采取强制措施」不关窗码。本窗 `Q-不执` 只转介 `申请不予执行仲裁裁决`。本窗 `Q-应执` 只转介 `应对合同案件执行`。本窗 `Q-执和` 只转介 `准备合同执行和解`。本窗 `Q-力` 只转介 `办理合同和解执行力补强`。执行闸打开不等于已提交不等于已立案执行不等于已控制财产不等于待提交终稿。申请不是已立案执行。草稿不是已采取强制措施。网交不是已立案。财产线索不是已查封冻结扣划。调解书双方签收才生效。已读不是签收。拒收不是已可执行。单独和解不是已可强制执行。履行期未满不是已可强制。申请执行期间一般为二年，分期从最后一期届满起算，不是每次分别起算。已读不是二年起算。过期只停该提交稿，不关窗；超期仍应受理，异议成立才可能不予执行。判决、裁定、调解书走第一审法院或同级财产所在地；仲裁裁决、赋强公证走被执行人住所地或财产所在地，不得一律套一审法院。此致某院不是管辖已定。未知利息不写零。不重审实体。不代提交。不选定法院。不定罪。不保证查明或控制财产。伤残等级与本窗无关，禁止折入。复杂追加、拒执刑责、案外人异议之诉主成果命中则负触发 `unavailable` 或只开升级接口。

`depends-on` 为空。主成果是被执行应对转 `应对合同案件执行`。主成果是执行中和解转 `准备合同执行和解`。主成果是不予执行转 `申请不予执行仲裁裁决`。主成果是私下和解要执行力转 `办理合同和解执行力补强`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：一般合同权利人持判决、调解书、裁决、支付令或赋强文书，需要强制执行申请、金额与合法线索草稿。「给我执行申请书」「对方不给钱去查封」仍正触发，成果状态 `草案`，不代提交。生效、二年、管辖未核验仍正触发：有可编号名义碎片则执行闸打开或半开，第 6 节出 `ZE#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出已立案／已查控终稿」才关闸，仍交十节，第 6 节不出 `ZE#` 终稿，第 7 节不得出发送版或已查控，窗口不关。用户要把申请写成已立案、把草稿写成已查封、把未签收调解书写成已可执行、把单独和解写成已可强制执行、把已读写成签收或二年起算、把过期写成当然不受理或仍要可提交普通终稿、把未知利息写成零、把执行中重审实体，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `ZE#` 草案。不得因「不代提交」「不保证控制财产」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是被执行应对（转 `应对合同案件执行`）；
- 主成果是执行中和解（转 `准备合同执行和解`）；
- 主成果是不予执行申请（转 `申请不予执行仲裁裁决`）；
- 主成果是撤裁申请（转 `申请撤销仲裁裁决`）；
- 主成果是私下和解要执行力（转 `办理合同和解执行力补强`）；
- 主成果是上诉状（转 `提起合同案件上诉`）；
- 主成果是保全申请终稿（转 `准备合同财产保全申请`）；
- 主成果是支付令申请（转 `申请合同金钱支付令`）；
- 主成果是复杂追加被执行人或拒执刑责终稿（本包未安装，`unavailable`）；
- 尚未成争，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）；
- 建设工程、金融借贷担保、房地产物业、海事、劳动专项执行。

双方秘密、伪造文书或线索、倒签签收、指导隐匿转移、违法查人**不在负触发表**，走整体停止。「申请即已立案」「草稿即已查控」「未签收即已可执行」「单独和解即已可强制执行」「已读即起算」「过期当然不受理或仍要可提交普通终稿」「未知写零」「执行中重审实体」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不代提交」「不保证控制财产」「不重审实体」是交付禁令，不是负触发。主成果才转；出现「执行」一词不是转出。C 端 012 只分流，不回改。

## 建立工作坐标

确认：申请执行授权；单方立场；名义种类；生效或签收事件；履行期间；金额与已受偿；管辖连结点；合法财产线索；法域。

口头「对方不给钱今晚去查封」「判决刚到已经生效」只登记 `S#`／`V#`。不得升格已立案、已查控或已生效，**不得单独算作开闸材料**。可编号判决书、调解书、裁决书、支付令、赋强文书或案号碎片可开闸。本窗不执行发送，不代提交，不代查控。

立场只许申请执行的权利人或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号名义碎片：执行闸关闭，仍交十节，不是整体停止。无书面授权但单方立场已闭合、且已有碎片：执行闸部分打开，仍交十节，不是整体停止。提出伪造文书或线索、倒签签收、指导隐匿转移、违法查询个人信息或非法讨债：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 合同或仲裁条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`ZE#` 执申行；`V#` 版本；`E#` 证据形态回链（文书、签收回证、履行凭证、合法线索，不是发送闸，不是已立案证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`K#`、`ZX#`、`BZ#`、`Enf#`、`Clue#`。技能正文中的条号是检索锚点，不是已核验 `L#`。文件状态只用 `草案`、`停止`。生效或二年未闭合不得标待提交。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。未知不写零。申请 ≠ 已立案执行。草稿 ≠ 已查控。调解书签收 ≠ 送达。单独和解 ≠ 已可强制执行。已读 ≠ 二年起算。过期 ≠ 当然不受理。构成违约 ≠ 当然解除。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或文书范本检索。本窗是执行申请草稿，范本只借强制执行申请书、财产线索表栏目，**不要**升格「已立案／已提交／已查控」。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现申请即已立案、草稿即已查控、未签收即已可执行、单独和解即已可强制执行、已读即起算的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把 1991 年第二百一十九条自然人一年法人六月当成现行二年。不得把 2017 年第二百三十九条「每次分别起算」当成现行最后一期。不得把 2017 年第二百三十七条仲裁裁决执行当成现行第二百三十七条（现行是超六个月未执行）。不得把 2017 年第二百五十三条当成现行迟延履行条。不得把 1991 年第一百条拘传当成调解书签收。解释仍引民事诉讼法第二百四十六条申请执行期间时记噪声并核现行第二百五十条。MCP 效力字段与公布施行日冲突时，以施行日为准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的生效、二年、管辖、迟延利息、施行日保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民事诉讼法（2023 修正，施行日 2024-01-01）第一百条调解书经双方当事人签收后即具有法律效力。噪声：1991 年第一百条拘传。解释第一百四十九条以最后签收日为生效日。第二百三十五条发生法律效力的民事判决、裁定以及刑事判决、裁定中的财产部分，由第一审人民法院或者与第一审人民法院同级的被执行的财产所在地人民法院执行；法律规定由人民法院执行的其他法律文书，由被执行人住所地或者被执行的财产所在地人民法院执行。仲裁裁决、赋强公证不得一律套一审法院。噪声：1991 年第二百零七条；2017 年第二百二十四条。第二百四十七条发生法律效力的民事判决、裁定，当事人必须履行；一方拒绝履行的，对方可以向人民法院申请执行，也可以由审判员移送执行。调解书和其他应当由人民法院执行的法律文书，一方拒绝履行的，对方可以申请执行。噪声：1991 年第二百四十七条涉外送达。第二百五十条申请执行的期间为二年；中止、中断适用诉讼时效规定；有履行期间的从最后一日起算；分期履行的从最后一期履行期限届满之日起算；未规定履行期间的从生效之日起算。噪声：1991 年第二百一十九条；2017 年第二百三十九条每次分别起算；把现行第二百四十六条检察监督或 2017 年第二百四十六条强制迁出当成二年条。解释第四百六十六条仍引第二百四十六条须核第二百五十条。解释超期申请仍应受理、被执行人异议成立才可能不予执行，条号运行时核验约第四百八十一条。第二百四十八条国内仲裁裁决不予执行事由只开风险接口，本窗不出不执终稿。噪声：2017 年第二百三十七条。迟延履行利息或迟延履行金条号运行时核验现行约第二百六十四条。噪声：2017 年第二百五十三条。仲裁法（2025 修订，施行日 2026-03-01）第七十五条一方不履行裁决的，另一方可依民诉向人民法院申请执行。技能正文条号不是 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变生效、二年、管辖或迟延利息的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补申请不是已立案、草稿不是已查控、调解书签收才生效、单独和解不是已可强制执行、超期仍应受理但异议可阻却、线索须合法来源、不保证控制财产的实务反例。

工具不可用时继续名义碎片和 `ZE#` 编目；生效、二年、管辖、迟延利息、施行日字段停止。不得拒跑，不得凭记忆写成已立案或指导转移财产。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、执行闸与不关窗

主成果才整案转出。双方秘密、伪造线索、指导隐匿转移第一次停。申请即已立案、未签收即已可执行不关窗。闸关仍交十节，第 6 节不出 `ZE#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

名义种类分列。签收日与送达日分列。判决管辖与裁决管辖分列。本节禁止出 `ZE#` 终稿。

### 3. 执行闸与路径 `Q#`

本节禁止出 `ZE#` 终稿。有可编号名义碎片：闸打开或半开。主路径只用 `Q-执申`。

### 4. 执申行 `ZE#`

名义切片、生效与二年、金额、管辖线索、申请接口。状态 `草案`。禁止升格已立案、已查控、已可强制执行。无 `E#` 不得写已立案。未生效或无牵连名义不得标待提交。

### 5. 应对、和解、不执、力补与上诉接口

被执行应对转应对窗。执行中和解转执和窗。第 7 节不得夹带 `ZE#` 终稿或已查控绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造文书或线索、倒签签收、指导隐匿转移、违法查询个人信息或非法讨债。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：执行闸关闭，仍交十节，不是整体停止。无书面授权但有碎片：执行闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：生效或签收、二年起算、管辖连结点、迟延利息、施行日未核验。申请即已立案、草稿即已查控、未签收即已可执行、单独和解即已可强制执行、已读即起算、过期仍要可提交普通终稿、未知写零、执行中重审实体：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `ZE#` 草案。
- `目标停止`：主目标变为被执行应对终稿、执行和解终稿、不予执行终稿或上诉状。禁止把「未生效仍要执行」当作用户错误主张时的目标停止；那是不关窗。

禁止指导隐匿转移、伪造线索或非法讨债。不给到位率。不定罪。不选定法院。不代提交。未知不写零。不写发送版。不保证控制财产。不重审实体。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。执行闸关闭仍交十节，第 6 节不出 `ZE#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `ZE#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。执行闸未打开时不得交付「已立案执行」或「已查控」。边界见 [路由](references/routing.md)。
