# 原子 Skill 选择方法

## 一、先识别成果

先问这一次要拿到什么可独立验收的成果，而不是按买卖、服务或法条名称匹配：

- 争议总图；
- 管辖或仲裁协议判断；
- 成立效力、条款解释、格式条款、期间分列；
- 解除权是否成立、催告、解除通知、对解除异议；
- 履行时间线、质量、迟延拒绝、履行顺序、情势变更；
- 金钱测算、索赔通知、定金、结算、解除后清理；
- 证据案卷、保全、公证、鉴定、举证交换、调查令；
- 和解谈判、和解协议、执行力补强、调解评估；
- 程序选择、支付令、仲裁申请或应裁、一审起诉或应诉、庭审、上诉；
- 撤销或不予执行裁决、反诉评估或准备、执行申请、执行应对、执行和解。

先予执行、行为保全、再审、检察监督、案外人执行异议之诉、群体策略、刑民交叉专项、简易小额专项、第三人撤销之诉属 P2，输出 `unavailable`。

## 二、再确认上下文

只确认会改变入口的最小信息：

1. 单方立场与授权；
2. 争议是否已经形成；
3. 是否已有仲裁条款、起诉状或解除通知；
4. 本次要分析、发函、测算、建卷、谈判还是程序文书；
5. 是否属于工程、金融、房产、海事或劳动专项。

## 三、处理混合请求

1. 列出每项可独立验收的成果及对应入口；
2. 只问：`这次要先取得哪一项成果？`；
3. 回答前不指定主要 Skill，不暗示必须先评估再发函；
4. 用户确认后只启动所选入口；等价评估、测算或证据可由用户或律师提供。

## 四、停止

立场冲突、专项主轴或未成争改合同时，说明边界并转出，不代做。信息不足时每轮只追问一个最能改变入口的问题。
