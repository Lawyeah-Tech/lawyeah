# 合同争议领域边界

本表只说明归属。当前安装包是。每次路由先核对 [当前能力地图](capability-map.md)；未安装的 P2 入口输出 `unavailable`。

| 相邻 | 本包入口 | 转出 |
| --- | --- | --- |
| 合同审查与起草 | 无。未成争只要改合同或出稿：本窗搁置，只说明不实施 | 审查起草领域（用户单独策略） |
| 建设工程 | 无 | 施工、分包、优先受偿、工程造价鉴定、实际施工人 |
| 金融借贷担保 | 无 | 借贷、保证、抵押质押、保理、融资租赁主轴 |
| 房地产物业 | 无 | 商品房、开发合作、物业服务主轴 |
| 海事 | 无 | 海上货物、船舶、海事保全 |
| 劳动 | 无 | 劳动关系、工资、解除劳动合同、工伤 |
| 刑事 | 评估中的刑民交叉只标红旗 | 定罪、控告、辩护 |
| C 端 032 | 专业评估或通知，不降成止损清单 | 大众第一轮止损 |
| C 端 011 | 专业起诉包 | 大众网上立案材料且请求论坛已闭合 |
| C 端 012 | 专业应诉包 | 大众民事答辩 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本包结论。
