# 评估债权人代位权

## 任务目标

在明确、无利益冲突的单方立场下（债权人或其受托律师，互斥），形成代权评估草案：代权闸、主体与强制接口、`Q#` 路径、`DQ#` 代权行（债权切片／到期合法确定与影响实现／怠于行使与专属排除／范围费用与从权利／相对人抗辩保全破产与仲裁接口／`E#` 回链）。本窗 `DQ#` 是代权行草案，不是已代位成立证明，不是已胜诉，不是已立案，不是诉状。本窗闸名只能是代权闸，禁止复用代位闸、竞合闸、转承闸、起诉闸、诉材闸、代表诉讼闸、撤销闸。预留不得占用：立案闸、催告闸、解除闸、发送闸、撤销闸。本窗主行只能是 `DQ#`，禁止 `DW#`、`WQ#`、`DL#`、`DS#`、`DX#`、`DY#`、`JH#`、`RY#`、`A#`。主路径只用 `Q-位`，禁止用 `Q-代`、`Q-择`、`Q-与`、`Q-诉`、`Q-撤`、`Q-签` 作主路径。邻窗 `Q-位` 只作转介进本窗；本窗打开为主路径，不是已代位成立、不是已胜诉。本窗 `Q-签` 只作「评估即已代位成立、已胜诉或已提交」不关窗码。代权闸打开不等于已代位成立不等于已胜诉不等于已立案不等于相对人应直接履行不等于待提交终稿。代位须债务人怠于行使到期债权或从权利、影响债权人到期债权实现。怠于＝应行使且能行使而不以诉讼或仲裁主张。催告发函不是怠于。专属权利不可代位。劳动报酬超过生活必需部分不是当然专属。范围以债权人到期债权为限，不是一揽子全部对外债权。相对人抗辩可向债权人主张，不是代位已切断。认定成立后相对人向债权人履行。第五百三十六条保存行为是请求相对人向债务人履行或申报，不是第五百三十七条直接受领。未到期不是当然可代位。次债权仲裁协议原则上不阻却代位诉讼，首次开庭前申请仲裁可中止，不是当然应起诉也不是当然不受理。应诉不是放弃仲裁。未经生效文书确认不是阻却。责任财产充足不是影响实现。保险代位求偿不是本窗。股东代表诉讼不是本窗。实际施工人工程代位转建设工程。未知不写零。不写诉状。不选定法院。不代提交。不定罪。伤残等级与本窗无关，禁止折入。

`depends-on` 为空。主成果是代位权诉状转 `准备代位权诉讼材料`。主成果是撤销权终稿转 `评估债权人撤销权`。主成果是破产管理人职责转破产领域。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：债务人怠于行使对第三人的债权或从权利，影响债权人到期债权实现，需要评估代位能否成立。「已经催过就算怠于」「专属也能代位」「起诉状交了就算成立」仍正触发，成果状态 `草案`。到期、怠于、专属未核验仍正触发：有可编号两层债权与相对人碎片则代权闸打开或半开，第 6 节出 `DQ#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出已代位成立终稿」才关闸，仍交十节，第 6 节不出 `DQ#` 终稿，第 7 节不得出诉状，窗口不关。用户要把催告写成怠于、把专属写成可代位、把未到期写成当然可代位、把一揽子对外债权写成范围、把起诉状写成已代位成立、把次债权仲裁写成当然应起诉或当然不受理、把保险赔付写成本窗代位、把未知写成零，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `DQ#` 草案。不得因「不写诉状」「不代提交」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是代位权诉状终稿（转 `准备代位权诉讼材料`）；
- 主成果是撤销权终稿（转 `评估债权人撤销权` 或 `准备债权人撤销权诉讼`）；
- 主成果是破产管理人权利或破产撤销（转破产领域）；
- 主成果是保险代位求偿（转金融借贷担保或保险）；
- 主成果是股东代表诉讼（转公司治理 `评估股东代表诉讼条件`）；
- 主成果是实际施工人工程代位（转建设工程）；
- 主成果是争议总图（转 `评估合同争议`）；
- 尚未成争，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）；
- 要管理债务人公司治理或股东责任。

双方秘密、伪造次债权或怠于证据、倒签到期或催告、隐匿责任财产、违法取证**不在负触发表**，走整体停止。「催告即怠于」「专属即可代位」「起诉状即已代位成立」「未到期即当然可代位」「未知写零」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不写诉状」「不代提交」是交付禁令，不是负触发。主成果才转；出现「代位」一词不是转出。

## 建立工作坐标

确认：评估授权；单方立场；债权人到期债权、次债权、相对人；怠于与专属碎片；法域。

口头「已经催过就算怠于」「专属也能代位」「起诉状交了就算成立」只登记 `S#`／`V#`。不得升格已代位成立、已怠于或已胜诉，**不得单独算作开闸材料**。可编号两层债权与相对人碎片可开闸。本窗不执行发送，不代提交，不写诉状。

立场只许债权人或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：代权闸关闭，仍交十节，不是整体停止。无书面评估授权但单方立场已闭合、且已有碎片：代权闸部分打开，仍交十节，不是整体停止。提出伪造次债权或怠于证据、倒签到期或催告、隐匿责任财产或违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`DQ#` 代权行；`V#` 版本；`E#` 证据形态回链（两层债权、怠于形态、专属或责任财产碎片，不是发送闸，不是已代位成立证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`DW#`、`WQ#`、`JH#`、`RY#`、`DX#`。技能正文中的条号是检索锚点，不是已核验 `L#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。未知不写零。催告 ≠ 怠于。专属 ≠ 可代位。起诉状 ≠ 已代位成立。未到期 ≠ 当然可代位。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或裁判案例检索。本窗是评估，**不要**用 `search_template` 生成代位诉状或已代位成立证明。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现催告即怠于、专属即可代位、未到期当然可代位、次债权仲裁当然阻却的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效合同法第七十三条、合同法解释（一）第十一条至第二十二条、把通则解释第四十二条至第四十三条撤销权节当代位条、把建工解释（一）第四十四条实际施工人代位、把保险法解释（四）第七条保险代位求偿当作本窗现行规则。MCP 可能先返回合同法第七十三条或保险代位而漏第五百三十五条、通则解释第三十三条，不得把失效金钱债权限定或保险代位写成已代位成立。MCP 效力字段与公布施行日冲突时，以施行日为准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的已代位成立、已怠于或已胜诉结论保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民法典第五百三十五条因债务人怠于行使其债权或从权利，影响债权人到期债权实现的，债权人可以向人民法院请求以自己的名义代位行使，专属于债务人自身的除外；范围以债权人到期债权为限；必要费用由债务人负担；相对人抗辩可向债权人主张。第五百三十六条债权到期前，次债权时效即将届满或未及时申报破产债权等，可代位请求相对人向债务人履行、申报或作其他必要保存行为，不是第五百三十七条直接受领。第五百三十七条认定成立后相对人向债权人履行，接受后相应权利义务终止；次债权被保全执行或债务人破产的，依照相关法律处理。通则解释第三十三条怠于＝不履行到期债务又不以诉讼或仲裁向相对人主张，致使到期债权未能实现。第三十四条专属：抚养赡养扶养、人身损害赔偿、生活必需范围内的劳动报酬、基本养老失业最低生活保障等。第三十六条次债权仲裁协议异议原则上不支持，首次开庭前申请仲裁可中止。第四十一条无正当理由减免或延长期限不得对抗债权人。噪声：已失效合同法第七十三条及解释（一）第十一条至第二十二条（金钱到期债权、「造成损害」、次债务人、诉讼费由次债务人负担）；通则解释第四十二条至第四十三条已是撤销权节。技能正文条号不是 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变怠于、专属、范围或履行效果的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补口头催告不是怠于、未到期不是当然代位、责任财产充足不是可代位、专属不是可代位、一揽子对外债权不是范围、次债权仲裁不是当然可诉或当然不受理、通知相对人不是代位已成立的实务反例。实务把合同法第七十三条或保险代位写成现行本窗规则时记为噪声。
- `search_case_by_fact` 只比较事实差异与翻转条件：催告发函不是已诉讼或仲裁主张；专属不是可代位；责任财产充足不是影响实现；一揽子全部对外债权不是范围；未到期不是当然可代位（保存不是直接受领）；次债权仲裁不是当然应起诉也不是当然不受理；起诉状不是已代位成立；未经生效确认不是阻却。无类案不得写成已代位成立或应起诉终稿。评估类禁止用 `search_template` 生成代位诉状或已代位成立证明。

工具不可用时继续两层债权、相对人碎片和 `DQ#` 编目；已代位成立、已怠于、已胜诉结论字段停止。不得拒跑，不得凭记忆写成已代位成立。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、代权闸与不关窗

主成果才整案转出。双方秘密、伪造次债权或怠于证据、倒签第一次停。催告即怠于、起诉状即已代位成立不关窗。闸关仍交十节，第 6 节不出 `DQ#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

债权人债权、次债权、相对人分列。本节禁止出 `DQ#` 终稿。

### 3. 代权闸与路径 `Q#`

本节禁止出 `DQ#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-位`。

### 4. 代权行 `DQ#`

债权切片、到期与影响实现、怠于与专属、范围费用、抗辩保全破产仲裁。状态 `草案`。禁止升格已代位成立、已怠于、已胜诉。无 `E#` 不得写已代位成立。

### 5. 诉材、撤销、保全、破产、仲裁接口

诉状转 `准备代位权诉讼材料`。撤销转撤销窗。保全转保全窗。破产转破产领域。次债权仲裁只开接口。第 7 节不得夹带 `DQ#` 终稿或诉状绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造次债权或怠于证据、倒签到期或催告、隐匿责任财产或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：代权闸关闭，仍交十节，不是整体停止。无书面评估授权但有碎片：代权闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：到期、怠于、专属、影响实现、范围、次债权仲裁、施行日未核验。催告即怠于、专属即可代位、未到期即当然可代位、起诉状即已代位成立、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `DQ#` 草案。
- `目标停止`：主目标变为代位权诉状终稿或债务人内部治理方案。禁止把「催告即怠于」当作用户错误主张时的目标停止；那是不关窗。

禁止指导伪造次债权或怠于证据。不给胜诉率。不定罪。不选定法院。不代提交。未知不写零。不写诉状。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。代权闸关闭仍交十节，第 6 节不出 `DQ#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `DQ#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。代权闸未打开时不得交付「已代位成立」或「已胜诉」。边界见 [路由](references/routing.md)。
