# 边界与路由

## 正触发

债务人怠于行使对第三人的债权或从权利，影响债权人到期债权实现，需要评估代位能否成立。从零、碎片、怠于未核验、无书面评估授权仍正触发：有可编号两层债权与相对人碎片则闸开或半开，出 `DQ#` 草案，保持草案。本次不写诉状、不代提交是交付禁令，不是开窗条件。催告即怠于、专属即可代位、起诉状即已代位成立，仍正触发。把未到期写成当然可代位，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造次债权或怠于证据、倒签、隐匿责任财产的停止，优先于负触发。上述信号不在下表。不写诉状不是负触发。「催告即怠于」「专属即可代位」「起诉状即已代位成立」「未到期即当然可代位」「一揽子全部对外债权」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 代位权诉状终稿 | `准备代位权诉讼材料` |
| 撤销权终稿 | `评估债权人撤销权` 或 `准备债权人撤销权诉讼` |
| 破产管理人权利 | 破产领域 |
| 保险代位求偿 | 金融借贷担保或保险 |
| 股东代表诉讼 | `评估股东代表诉讼条件` |
| 实际施工人工程代位 | 建设工程领域 |
| 争议总图 | `评估合同争议` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |
| 要管理债务人公司治理 | 公司治理领域 |

不得因「不写诉状」或「不代提交」关窗。拟代权评估仍正触发，不得写成已代位成立或已胜诉。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 实际施工人代位发包人 | 建设工程领域 |
| 保险代位求偿 | 金融借贷担保或保险 |
| 破产撤销、管理人职责 | 破产领域 |
| 股东代表诉讼 | 公司治理 |

一般买卖或服务夹带专项背景时，专项段只分流。出现「代位」一词不是转出。C 端只要大众代位填空页时只分流，不把本包降成填空式代位，不回改。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 只要诉状 | `准备代位权诉讼材料` |
| 只要撤销 | `评估债权人撤销权` |

## 易混

本窗闸名只能是代权闸，不是代位闸，不是撤销闸，不是起诉闸。`DQ#` 不是 `DW#`，不是 `WQ#`。主路径是 `Q-位`，不是 `Q-代`，不是 `Q-撤`。`代位闸` 是保险代位求偿窗。`Q-代` 是股东代表诉讼主路径。催告不是怠于。专属不是可代位。起诉状不是已代位成立。未到期保存不是直接受领。已失效合同法第七十三条不是现行。解释（一）第十一条至第二十二条金钱限定不是现行。通则解释第四十二条至第四十三条是撤销权节。建工解释（一）第四十四条、保险法解释（四）第七条不是本窗。MCP 可能先返回合同法第七十三条或保险代位而漏第五百三十五条、通则解释第三十三条。「催告日改到一年前」「责任财产清单藏起来」整体停止。本窗不执行发送，不代提交。不选定法院。不写诉状。
