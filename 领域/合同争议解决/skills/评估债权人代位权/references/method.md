# 评估债权人代位权方法

本文件是可执行判断节点。催告不是怠于。专属不是可代位。起诉状不是已代位成立。未到期不是当然可代位。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已代位成立、已胜诉、选定法院、代提交、未知写零。本任务不定罪，不写诉状，不把催告写成怠于。本窗闸名只能是代权闸，禁止复用代位闸、撤销闸、起诉闸。预留不得占用：立案闸、催告闸、解除闸、发送闸、撤销闸。本窗 `DQ#` 是代权行。主路径只用 `Q-位`，禁止用 `Q-代`、`Q-撤`、`Q-诉`、`Q-签` 作主路径。本窗 `Q-签` 只作「评估即已代位成立、已胜诉或已提交」不关窗码。英文 id 禁止使用，一律用中文技能名 `评估债权人代位权`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效合同法第七十三条、解释（一）第十一条至第二十二条、把通则解释第四十二条至第四十三条当撤销权节、把保险代位或建工实际施工人代位写成现行本窗规则时记为噪声。禁止指导伪造次债权或怠于证据。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现两层债权碎片扫描，不是默认闭集。
`DQ#` 固定列：`编号｜债权切片（债权人债权／次债权／相对人）｜到期合法确定与影响实现｜怠于行使与专属排除｜范围费用与从权利｜相对人抗辩保全破产与仲裁接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已代位成立」或「已怠于」。无 `E#` 不得写已代位成立。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-位`。禁止 `DW#`、`WQ#`、`JH#`、`RY#`、`A#`、`N#`。

口头「已经催过就算怠于」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：怠于以诉讼或仲裁主张为准。第五百三十六条保存不是第五百三十七条直接受领。

## 节点 0　分流、立场、代权闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造次债权或怠于证据、倒签、隐匿责任财产不进负表。利益冲突未解不进整体停止。不写诉状、不代提交不是负触发。把催告写成怠于、把起诉状写成已代位成立不是负触发。

整案转出只交付第 1、2、10 节，不出 `DQ#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是代位权诉状终稿 | 负触发 `准备代位权诉讼材料` |
| 主成果是撤销权终稿 | 负触发 `评估债权人撤销权` 或 `准备债权人撤销权诉讼` |
| 主成果是破产管理人权利 | 整案转破产领域 |
| 主成果是保险代位求偿 | 整案转金融借贷担保或保险 |
| 主成果是股东代表诉讼 | 负触发 `评估股东代表诉讼条件` |
| 主成果是实际施工人工程代位 | 整案转建设工程 |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 要管理债务人公司治理 | 整案转公司治理 |
| 「不写诉状」「不代提交」 | 交付禁令，不是负触发 |

出现「代位」一词不是转出。

代权闸打开（可出 `DQ#` 草案，仍不得标「已代位成立／已怠于／已胜诉」）须同时满足：单方无冲突立场已闭合；主成果是代位评估，不是诉状终稿；至少一行可编号两层债权与相对人碎片。口头「已经催过就算怠于」不算单独开闸材料。

代权闸部分打开：已有碎片，但到期、怠于或专属未闭合；对应格待核；仍交十节。无书面评估授权但单方立场已闭合且已有碎片：代权闸部分打开，仍交十节，不是整体停止。

代权闸关闭（仍正触发）：无一可编号碎片。「今天必须出已代位成立终稿」而无最小碎片不得开闸。不出 `DQ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `DQ#` 终稿，**第 7 节不得出诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「催告即怠于」「专属即可代位」「起诉状即已代位成立」「未到期即当然可代位」「一揽子全部对外债权」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `DQ#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 代权闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造次债权或怠于证据、倒签到期或催告、隐匿责任财产或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个债权切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `DQ#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 债权人债权 | 到期、合法、确定分列 | 未到期升格第五百三十七条直接受领 |
| 次债权 | 相对人、从权利分列 | 金钱限定写成现行 |
| 怠于 | 诉讼或仲裁主张分列 | 催告、发函升格怠于 |
| 专属 | 抚养赡养、人身损害、生活必需劳动报酬分列 | 专属升格可代位；超过生活必需仍写专属 |
| 范围 | 以债权人到期债权为限 | 一揽子全部对外债权 |

检索锚点（写入 `L#` 前须核验）：见技能正文 MCP 节。噪声：已失效合同法第七十三条；解释（一）第十一条至第二十二条。

## 节点 3　代权行 `DQ#`

按已出现两层债权碎片扫描，不是默认闭集。每条须能指向到期、怠于、专属、范围或抗辩之一。

无 `E#` 不得写已代位成立。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止唯一截止日。

热冲突强制处理：

- 催告即怠于／专属即可代位／未到期即当然可代位／一揽子全部对外债权／起诉状即已代位成立／未知写零 → 该格不支持或字段停止；仍出其他 `DQ#`。
- 无一碎片 → 关闸，不出 `DQ#` 终稿，窗口不关。
- 指导伪造次债权、怠于、倒签、隐匿 → 整体停止，不是该格不支持。

## 节点 4　诉材、撤销、保全、破产、仲裁接口

第 7 节只开接口，不得夹带 `DQ#` 终稿或诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待债权编号」，不得补写已代位成立。不选定法院。不代提交。不写诉状。

下一步只转介：`准备代位权诉讼材料`、`评估债权人撤销权`、`准备债权人撤销权诉讼`、`评估债权转让与债务承担争议`、`评估合同管辖与仲裁协议`、`提起合同纠纷一审`、`应对合同纠纷一审`、`提起合同仲裁`、`评估争议期间`、`建立合同争议证据案卷`、`评估合同财产保全必要性`、`准备合同财产保全申请`、`申请律师调查令或法院调查取证`、`评估抵销留置与扣款抗辩`、`选择诉讼仲裁或督促程序`、`评估合同争议`。禁止此致某院。第五百三十六条保存只开接口，不得写成直接受领。

若 if 用户催促「已经催过就算怠于／专属也能代位／起诉状交了就算成立／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「代权闸与代权行草案」。本窗不执行发送。不包含：已代位成立、已胜诉、诉状。禁止选边治愈。禁止催告即怠于。禁止专属即可代位。禁止指导伪造。代权闸打开 ≠ 已代位成立 ≠ 已胜诉。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标代权终稿已形成。
风险档 A：伪造次债权或怠于、倒签、隐匿责任财产必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：买卖货款已到期，债务人另有对丙的货款未起诉。债权人发过催告函，主张已经催过就算怠于，要把债务人全部对外债权一揽子代位，含劳动报酬，起诉状交了就算成立。次债权订有仲裁。用户不清楚先写零。代权闸打开或半开。`Q-怠`、`Q-揽`、`Q-专`、`Q-状`、`Q-次`、`Q-零` 不打开为可靠路径。第 6 节不得把已怠于、已代位成立、一揽子范围、0 写入可执行 `DQ#`；对应格 `现有依据不支持` 或字段停止；仍出两层债权分列、诉讼或仲裁主张缺口、专属分列、范围以到期债权为限、仲裁中止接口等其他 `DQ#`。不关窗。不写诉状。

场景②：用户同时交出己方「把催告日改到一年前、次债权确认书用空白章补一份」与对方「债务人已起诉相对人」口径，并要「把责任财产清单藏起来」。命中双方秘密＋倒签＋伪造＋隐匿。第一次整体停止。只交第 1、10 节。不出 `DQ#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代违法方案。
