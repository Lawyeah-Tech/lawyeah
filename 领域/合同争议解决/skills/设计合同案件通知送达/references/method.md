# 设计合同案件通知送达方法

本文件是可执行判断节点。已读不是到达。发出不是到达。微信转发不是发出。草稿不是已送达。拒收或退件不是当然已到达。民诉电子送达未经同意不得套民事到达。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已发出、已送达、已到达、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不写通知正文，不写法院送达方案。本窗闸名只能是达证闸，禁止复用送达闸、到达闸、通知闸、发送闸、催告闸、电约闸、渠道闸。预留不得占用：立案闸、和解闸。本窗 `CD#` 是达证行。主路径只用 `Q-道`，禁止用 `Q-送`、`Q-达`、`Q-函`、`Q-告`、`Q-电`、`Q-渠`、`Q-址`、`Q-签` 作主路径。本窗 `Q-签` 只作「设计即已发出、已送达、已到达或已提交」不关窗码。本窗 `Q-读` 只作「已读即到达」不关窗码。本窗 `Q-址` 只作「虚假地址或无约定即已到达」不关窗码。英文 id 禁止使用，一律用中文技能名 `设计合同案件通知送达`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效合同法第十条、第十六条、第二十六条、第九十六条、1991 年民事诉讼法第八十四条公告送达、把民诉第九十条未同意写成民事到达时记为噪声。禁止指导伪造回证或倒签交寄。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现文书或地址碎片扫描，不是默认闭集。
`CD#` 固定列：`编号｜文书种类接口｜地址权源｜渠道组合｜回证形态｜失败升级｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已发出」或「已到达」。无 `E#` 不得写已发出或已送达。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-道`。禁止 `SD#`、`HF#`、`CG#`、`DY#`、`DZ#`、`HZ#`、`A#`、`N#`。文件状态只用 `草案`、`停止`。

口头「微信已读就算到了」「发出去了就算到了」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：约定主渠道加备份。已读截图只作弱辅助。拒收与退件分列待核，约定「拒收视为送达」须核条款和格式提示。下落不明不编民事公告送达。诉讼文书送达转应诉窗。电子签名法第十一条接收时间不是第一百三十七条生效。

## 节点 0　分流、立场、达证闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造回证、已读截图充到达、倒签交寄或签收、隐匿退件、伪造物流、违法取证不进负表。利益冲突未解不进整体停止。不执行发送、不写通知正文不是负触发。

整案转出只交付第 1、2、10 节，不出 `CD#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是催告正文 | 负触发 `准备催告履行或补救通知` |
| 主成果是解除函正文 | 负触发 `准备解除通知` |
| 主成果是索赔通知正文 | 负触发 `准备索赔或违约金主张通知` |
| 主成果是异议函正文 | 负触发 `准备对合同解除通知的异议` |
| 主成果是电文成立或到达实体评估 | 负触发 `评估电子合同成立与送达` |
| 主成果是公证申请终稿 | 负触发 `准备合同案件公证保全` |
| 主成果是诉讼文书或法院／仲裁送达方案 | 负触发 `应对合同纠纷一审` 或对应仲裁窗 |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 尚未成争，只要改合同送达条款或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程／金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不执行发送」「不写通知正文」「不写已送达」 | 交付禁令，不是负触发 |

出现「送达」「已读」「邮寄」一词不是转出。邻窗把诉讼文书电子送达丢进本窗时，本窗仍负触发应诉窗，不开闸。

达证闸打开（可出 `CD#` 草案，仍不得标「已发出／已送达／已到达」）须同时满足：单方无冲突立场已闭合；主成果是渠道与回证设计，不是通知正文、不是已到达证明、不是法院送达方案；至少一项可编号拟送文书种类或相对方、约定地址或系统碎片。口头「微信已读就算到了」不算单独开闸材料。

达证闸部分打开：已有碎片，但地址权源或渠道未闭合；对应格待核；仍交十节。无书面授权但单方立场已闭合且已有碎片：达证闸部分打开，仍交十节，不是整体停止。

达证闸关闭（仍正触发）：无一可编号碎片。「今天必须出已送达终稿」而无最小碎片不得开闸。不出 `CD#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `CD#` 终稿，**第 7 节不得出通知正文或已到达证明**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「已读即到达」「发出即到达」「微信转发即发出」「草稿即已送达」「拒收或退件即当然已到达」「民诉电子送达未同意即民事到达」「未知写零」「唯一到达日」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `CD#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 达证闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造回证、已读截图充到达、倒签交寄或签收、隐匿退件、伪造物流或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 3　达证行 `CD#`

按已出现文书或地址碎片扫描，不是默认闭集。每条须能指向地址权源、渠道组合、回证形态或失败升级之一。

无 `E#` 不得写已发出或已到达。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止唯一到达日。地址或渠道未闭合不得标待发送。

热冲突强制处理：

- 已读即到达／发出即到达／微信转发即发出／草稿即已送达／拒收或退件即当然已到达／民诉电子送达未同意即民事到达／未知写零／唯一到达日 → 该格不支持或字段停止；仍出其他 `CD#`。
- 无一碎片 → 关闸，不出 `CD#` 终稿，窗口不关。
- 指导伪造回证、已读截图充到达、倒签交寄 → 整体停止，不是该格不支持。

## 节点 4　正文、电约、公证与法院送达接口

第 7 节只开接口，不得夹带 `CD#` 终稿、通知正文或已到达结论绕闸。闸关闭时第 7 节可写「闸未开，转介待渠证编号」，不得补写已到达。不选定法院。不代提交。不保证到达。

下一步只转介：`准备催告履行或补救通知`、`准备解除通知`、`准备索赔或违约金主张通知`、`准备对合同解除通知的异议`、`评估电子合同成立与送达`、`评估解除权是否成立`、`评估合同争议`、`建立合同争议证据案卷`、`保全质量现场与电子证据`、`准备合同案件公证保全`、`评估债权转让与债务承担争议`、`评估抵销留置与扣款抗辩`、`评估同时履行先履行与不安抗辩`、`评估迟延拒绝与不完全履行`、`建立双向履行时间线`、`提起合同纠纷一审`、`应对合同纠纷一审`、`评估争议期间`、`评估争议中的格式条款`。禁止此致某院。

若 if 用户催促「已读就算到了／发出去了就算到了／拒收也算送到／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 用户要求伪造回证或倒签交寄，then 第一次整体停止。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。
