# 边界与路由

## 正触发

发诉讼外民事通知前需单独设计约定渠道、备份送达、回证和失败升级。从零、碎片、地址未核验、无书面授权仍正触发：有可编号拟送文书种类或相对方、约定地址或系统碎片则闸开或半开，出 `CD#` 草案，保持草案。本次不执行发送、不写通知正文、不写已送达是交付禁令，不是开窗条件。已读即到达、发出即到达、拒收即当然送达，仍正触发。把已读写成到达、把发出写成到达，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造回证、已读截图充到达、倒签的停止，优先于负触发。上述信号不在下表。不执行发送不是负触发。「已读即到达」「发出即到达」「微信转发即发出」「草稿即已送达」「拒收或退件即当然已到达」「民诉电子送达未同意即民事到达」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 催告正文 | `准备催告履行或补救通知` |
| 解除函正文 | `准备解除通知` |
| 索赔通知正文 | `准备索赔或违约金主张通知` |
| 异议函正文 | `准备对合同解除通知的异议` |
| 电文成立或到达实体评估 | `评估电子合同成立与送达` |
| 公证申请终稿 | `准备合同案件公证保全` |
| 诉讼文书或法院／仲裁送达方案 | `应对合同纠纷一审` 或对应仲裁窗 |
| 争议总图 | `评估合同争议` |
| 尚未成争，改合同送达条款或出稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不执行发送」或「不写通知正文」关窗。拟渠道设计仍正触发，不得写成已发出或已到达。

## 易混

本窗闸名只能是达证闸，不是送达闸，不是到达闸，不是通知闸，不是发送闸，不是催告闸，不是电约闸。`CD#` 不是 `SD#`，不是 `HF#`，不是 `CG#`，不是 `DY#`，不是 `DZ#`。主路径是 `Q-道`，不是 `Q-送`，不是 `Q-达`，不是 `Q-函`，不是 `Q-告`，不是 `Q-电`，不是 `Q-渠`。`送达闸`／`SD#`／`Q-送` 是公司治理催缴召集优先购买通知送达。`发送闸`／`HF#`／`Q-函` 是准备解除通知。`电约闸`／`DY#`／`Q-电` 是评估电子合同成立与送达。`Q-渠` 是合规举报渠道窗。催告窗 `Q-道` 只转介进本窗。已读不是到达。发出不是到达。微信转发不是发出。拒收不是当然已到达。1991 年民事诉讼法第八十四条公告送达不是民事通知到达。合同法第十条、第十六条首次进入任何系统是噪声。民诉第九十条未经同意不得套第一百三十七条。电子签名法第十一条接收时间不是第一百三十七条生效。提出「回证日期改到上周」「已读截图P成签收」整体停止。本窗不执行发送，不代提交。不选定法院。不写通知正文。不写法院送达方案。
