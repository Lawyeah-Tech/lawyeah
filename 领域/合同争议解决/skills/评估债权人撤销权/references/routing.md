# 边界与路由

## 正触发

债务人无偿或明显不合理低价高价处分、为他人担保或恶意延长期限，影响债权人债权实现，需要评估撤销能否成立。从零、碎片、对价未核验、无书面评估授权仍正触发：有可编号债权人债权与处分行为碎片则闸开或半开，出 `CQ#` 草案，保持草案。本次不写诉状、不代提交是交付禁令，不是开窗条件。无偿即当然已撤销、除斥即时效、起诉状即已撤销成立，仍正触发。把七十％写成唯一标准，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造低价或无偿证据、倒签、隐匿责任财产的停止，优先于负触发。上述信号不在下表。不写诉状不是负触发。「无偿即当然已撤销」「除斥即时效」「起诉状即已撤销成立」「责任财产充足仍可撤」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 撤销权诉状终稿 | `准备债权人撤销权诉讼` |
| 代位权终稿 | `评估债权人代位权` |
| 破产撤销 | 破产领域 |
| 家事赠与析产 | 婚姻家事 |
| 意思表示瑕疵撤销 | `评估合同成立与效力` |
| 争议总图 | `评估合同争议` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不写诉状」或「不代提交」关窗。拟撤权评估仍正触发，不得写成已撤销成立或已胜诉。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 破产法撤销、偏颇清偿 | 破产领域 |
| 夫妻赠与、父母子女赠与主轴 | 婚姻家事 |
| 意思表示欺诈胁迫重大误解撤销 | `评估合同成立与效力` |

一般买卖或服务夹带专项背景时，专项段只分流。出现「撤销」一词不是转出。C 端只要大众撤销填空页时只分流，不把本包降成填空式撤销，不回改。

## 易混

本窗闸名只能是撤权闸，不是撤销闸，不是代权闸，不是起诉闸。`CQ#` 不是 `DQ#`，不是 `WQ#`。主路径是 `Q-撤`，不是 `Q-位`，不是 `Q-代`。代位窗 `Q-撤` 只作转介进本窗。无偿不是当然已撤销。除斥不是时效。起诉状不是已撤销成立。七十％不是唯一标准。已失效合同法第七十四条、第七十五条不是现行。第一百五十二条是意思表示瑕疵撤销。代位节第三十三条至第四十一条不是撤销条。MCP 可能先返回第一百五十二条或合同法第七十四条而漏第五百三十八条、第五百四十一条。「转让日改到五年前」「评估报告补一份」整体停止。本窗不执行发送，不代提交。不选定法院。不写诉状。
