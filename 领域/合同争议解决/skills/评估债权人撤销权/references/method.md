# 评估债权人撤销权方法

本文件是可执行判断节点。无偿不是当然已撤销。除斥不是时效。起诉状不是已撤销成立。七十％不是唯一标准。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已撤销成立、已胜诉、选定法院、代提交、未知写零。本任务不定罪，不写诉状，不把除斥写成时效。本窗闸名只能是撤权闸，禁止复用撤销闸、代权闸、起诉闸。预留不得占用：立案闸、催告闸、解除闸、发送闸。本窗 `CQ#` 是撤权行。主路径只用 `Q-撤`，禁止用 `Q-位`、`Q-代`、`Q-诉`、`Q-签` 作主路径。本窗 `Q-签` 只作「评估即已撤销成立、已胜诉或已提交」不关窗码。英文 id 禁止使用，一律用中文技能名 `评估债权人撤销权`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效合同法第七十四条、第七十五条、解释（一）撤销节、第一百五十二条意思表示瑕疵撤销、代位节第三十三条至第四十一条、破产撤销条时记为噪声。禁止指导伪造低价或无偿证据。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现处分碎片扫描，不是默认闭集。
`CQ#` 固定列：`编号｜处分切片（债权人债权／处分行为／相对人）｜到期合法确定与影响实现｜无偿或明显不合理对价与相对人明知｜除斥一年五年与范围费用返还｜代位保全破产家事仲裁接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已撤销成立」。无 `E#` 不得写已撤销成立。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-撤`。禁止 `DQ#`、`WQ#`、`DW#`、`A#`、`N#`。

口头「无偿就算能撤」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：无偿通常不要求相对人恶意。第五百三十九条不合理对价须相对人知道或应当知道。除斥不适用中止中断。

## 节点 0　分流、立场、撤权闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造低价或无偿证据、倒签、隐匿责任财产不进负表。利益冲突未解不进整体停止。不写诉状不是负触发。把无偿写成当然已撤销、把除斥写成时效不是负触发。

整案转出只交付第 1、2、10 节，不出 `CQ#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是撤销权诉状终稿 | 负触发 `准备债权人撤销权诉讼` |
| 主成果是代位权终稿 | 负触发 `评估债权人代位权` |
| 主成果是破产撤销 | 整案转破产领域 |
| 主成果是家事赠与析产 | 整案转婚姻家事 |
| 主成果是意思表示瑕疵撤销 | 负触发 `评估合同成立与效力` |
| 主成果是争议总图 | 负触发 `评估合同争议` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 「不写诉状」「不代提交」 | 交付禁令，不是负触发 |

出现「撤销」一词不是转出。

撤权闸打开（可出 `CQ#` 草案，仍不得标「已撤销成立／已胜诉」）须同时满足：单方无冲突立场已闭合；主成果是撤销评估，不是诉状终稿；至少一行可编号债权人债权与处分行为碎片。口头「无偿就算能撤」不算单独开闸材料。

撤权闸部分打开：已有碎片，但对价、明知或除斥未闭合；对应格待核；仍交十节。无书面评估授权但单方立场已闭合且已有碎片：撤权闸部分打开，仍交十节，不是整体停止。

撤权闸关闭（仍正触发）：无一可编号碎片。「今天必须出已撤销成立终稿」而无最小碎片不得开闸。不出 `CQ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `CQ#` 终稿，**第 7 节不得出诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「无偿即当然已撤销」「除斥即时效」「起诉状即已撤销成立」「责任财产充足仍可撤」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `CQ#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 撤权闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造低价或无偿证据、倒签处分或除斥起算、隐匿责任财产或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个处分切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `CQ#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 无偿 | 放弃债权、放弃担保、无偿转让、恶意延长分列 | 无偿升格须相对人恶意；为他人担保当第五百三十八条 |
| 对价 | 市价或指导价、交易类型分列 | 七十％／三十％升格唯一标准 |
| 明知 | 第五百三十九条知道或应当知道分列 | 知情升格恶意终稿 |
| 除斥 | 知悉一年、行为发生五年分列 | 除斥当时效中止中断；已读当知悉起算 |
| 范围 | 可分／不可分、必要费用分列 | 可分标的全部撤销；返还当优先受偿 |

检索锚点（写入 `L#` 前须核验）：见技能正文 MCP 节。噪声：已失效合同法第七十四条、第七十五条；第一百五十二条。

## 节点 3　撤权行 `CQ#`

按已出现处分碎片扫描，不是默认闭集。每条须能指向无偿或对价、明知、除斥或范围之一。

无 `E#` 不得写已撤销成立。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止唯一截止日。

热冲突强制处理：

- 无偿即当然已撤销／除斥即时效／起诉状即已撤销成立／责任财产充足仍可撤／未知写零 → 该格不支持或字段停止；仍出其他 `CQ#`。
- 无一碎片 → 关闸，不出 `CQ#` 终稿，窗口不关。
- 指导伪造低价、无偿、倒签、隐匿 → 整体停止，不是该格不支持。

## 节点 4　诉材、代位、保全、破产、家事接口

第 7 节只开接口，不得夹带 `CQ#` 终稿或诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待处分编号」，不得补写已撤销成立。不选定法院。不代提交。不写诉状。

下一步只转介：`准备债权人撤销权诉讼`、`评估债权人代位权`、`准备代位权诉讼材料`、`评估债权转让与债务承担争议`、`评估合同争议`、`评估合同成立与效力`、`评估合同管辖与仲裁协议`、`提起合同纠纷一审`、`应对合同纠纷一审`、`建立合同争议证据案卷`、`评估争议期间`、`评估合同财产保全必要性`、`准备合同财产保全申请`、`申请律师调查令或法院调查取证`、`选择诉讼仲裁或督促程序`、`提起合同仲裁`。禁止此致某院。

若 if 用户催促「无偿就算能撤／过了一年还能中断／起诉状交了就算撤了／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 再执行清单

每个节点结束后回写：来源、判断、最强反方、是否字段停止。不得跳过撤权闸直接给已撤销成立。

若 if 影响实现、对价、相对人明知、除斥起算、范围、施行日未核验，then 该强制项字段停止，窗口不关。
判断状态只许三值。口头「无偿就算能撤」不得写成 `CQ#` 已撤销成立。未知不写零。

## 本任务回链纪律

本任务成果是「撤权闸与撤权行草案」。本窗不执行发送。不包含：已撤销成立、已胜诉、诉状。禁止选边治愈。禁止无偿即当然已撤销。禁止除斥即时效。禁止指导伪造。撤权闸打开 ≠ 已撤销成立 ≠ 已胜诉。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标撤权终稿已形成。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：债务人把设备以记忆中市价七成卖给关联公司，债权人主张无偿就算能撤、百分之七十就是唯一标准、过了一年还能中断、起诉状交了就算撤了，要把全部财产一揽子撤销，不清楚先写零。相对人是否知道未核验。撤权闸打开或半开。`Q-无`、`Q-价`、`Q-时`、`Q-状`、`Q-揽`、`Q-零` 不打开为可靠路径。第 6 节不得把已撤销成立、除斥可中断、0 写入可执行 `CQ#`；对应格 `现有依据不支持` 或字段停止；仍出处分分列、对价与明知缺口、一年五年并行、可分范围等其他 `CQ#`。不关窗。不写诉状。

场景②：用户同时交出己方「把转让日改到五年前刚过一点、评估报告用空白章补一份」与对方「市价就是这个价」口径，并要「把责任财产清单藏起来」。命中双方秘密＋倒签＋伪造＋隐匿。第一次整体停止。只交第 1、10 节。不出 `CQ#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代违法方案。
