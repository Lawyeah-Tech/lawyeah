# 准备合同仲裁协议异议材料方法

本文件是可执行判断节点。草稿不是已提出。已读不是已开庭。应诉不是放弃仲裁。答辩十五日不是仲裁异议截止。合同无效不是仲裁消灭。或裁或诉不是当然有效或当然无效。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已提出、协议已无效、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不把草稿写成已提出。本窗闸名只能是仲异闸，禁止复用异议闸、论坛闸、管辖闸、协议闸、效力闸、答辩闸、起诉闸、应诉闸、立案闸。预留不得占用：立案闸、和解闸。本窗 `ZX#` 是仲异行。主路径只用 `Q-仲异`，禁止用 `Q-异`、`Q-坛`、`Q-辩`、`Q-诉`、`Q-仲`、`Q-裁`、`Q-签` 作主路径。本窗 `Q-签` 只作「草稿即已提出或已提交」不关窗码。英文 id 禁止使用，一律用中文技能名 `准备合同仲裁协议异议材料`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1994 年第二十七条请求变动、1994 年或 2017 年第三十七条重新选定仲裁员、2017 年第十六条至第二十条未核对应、MCP 把已施行 2025 仲裁法标尚未施行而未以施行日为准、民诉 2017 年第一百二十七条当现行书面仲裁告知、把草稿写成已提出或把应诉写成放弃仲裁时记为噪声。禁止指导伪造仲裁条款、倒签或隐匿条款。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现条款或程序碎片扫描，不是默认闭集。
`ZX#` 固定列：`编号｜协议切片｜书面形式与仲裁意思｜事项覆盖与机构｜效力或不适用与独立性｜时点与机关路径｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已提出」或「协议已无效」。无 `E#` 不得写已提出。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-仲异`。禁止 `GY#`、`YS#`、`LT#`、`DB#`、`QT#`、`ZY#`、`XY#`、`K#`、`A#`、`N#`。期限嵌在时点与机关路径：作出日／送达日／答辩期／首次开庭前／管辖异议期分列，禁止一张截止卡，禁止另开 `K#` 为主行。

口头「条款无效」「已读就算开庭」「已经提出了」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：书面形式、请求仲裁意思、事项覆盖、选定机构分列，禁止合成「条款无效」。应诉本身不等于放弃。放弃须回链法定首次开庭前节点。合同无效不当然消灭仲裁协议。

## 节点 0　分流、立场、仲异闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造仲裁条款、倒签签署日或异议日或开庭日、隐匿条款、伪造送达、违法取证不进负表。利益冲突未解不进整体停止。不代提交、不保证无效、不写管辖异议书不是负触发。逾期赶写不是负触发。

整案转出只交付第 1、2、10 节，不出 `ZX#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是管辖或仲裁效力评估终稿 | 负触发 `评估合同管辖与仲裁协议` |
| 主成果是法院管辖异议书 | 负触发 `提出合同案件管辖异议` |
| 主成果是含实体抗辩的一审答辩 | 负触发 `应对合同纠纷一审` |
| 主成果是仲裁应裁实体 | 负触发 `应对合同仲裁` |
| 主成果是原告起诉包 | 负触发 `提起合同纠纷一审` |
| 主成果是仲裁申请包 | 负触发 `提起合同仲裁` |
| 主成果是程序选择闭集 | 负触发 `选择诉讼仲裁或督促程序` |
| 主成果是撤销仲裁裁决申请 | 负触发 `申请撤销仲裁裁决` |
| 主成果是不予执行申请 | 负触发 `申请不予执行仲裁裁决` |
| 尚未成争，只要改仲裁条款 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程／金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不代提交」「不保证无效」「不写管辖异议书」 | 交付禁令，不是负触发 |

出现「仲裁」「异议」一词不是转出。

仲异闸打开（可出 `ZX#` 草案，仍不得标「已提出／已提交／协议已无效」）须同时满足：单方无冲突被诉或被申请立场已闭合；主成果是仲裁协议异议或效力确认材料，不是论坛评估终稿、不是法院管辖异议书、不是实体答辩、不是仲裁申请；至少一项可编号仲裁条款、起诉状、仲裁申请或开庭通知碎片。口头「条款无效」不算单独开闸材料。PDF 可半开，不得单独起算首次开庭前时点。

仲异闸部分打开：已有碎片，但书面三要素、机构或首次开庭前时点未闭合；对应格待核；仍交十节。无书面授权但单方立场已闭合且已有碎片：仲异闸部分打开，仍交十节，不是整体停止。

仲异闸关闭（仍正触发）：无一可编号碎片。「今天必须出已提出／已无效终稿」而无最小碎片不得开闸。不出 `ZX#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `ZX#` 终稿，**第 7 节不得出可提交异议书**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已提出」「已读即已开庭或异议期已起算」「应诉即放弃仲裁」「答辩十五日即仲裁异议截止」「合同无效即仲裁消灭」「或裁或诉当然有效或当然无效」「逾期仍要可提交终稿」「此致某院即论坛已定」「保证无效或驳回」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `ZX#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 仲异闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造仲裁条款、倒签签署日或异议日或开庭日、隐匿条款、伪造送达或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

- 仲裁法（2025 修订，施行日 2026-03-01）已施行；MCP 标尚未施行以施行日为准。

## 节点 3　仲异行 `ZX#`

按已出现条款或程序碎片扫描，不是默认闭集。每条须能指向协议、书面三要素、独立性或时点机关之一。

无 `E#` 不得写已提出。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止唯一截止日。禁止此致某院。

热冲突强制处理：

- 草稿即已提出／已读即已开庭／应诉即放弃／答辩十五日即截止／合同无效即消灭／或裁或诉当然有效或当然无效／逾期仍要可提交终稿／保证无效／未知写零 → 该格不支持或字段停止；仍出其他 `ZX#`。
- 无一碎片 → 关闸，不出 `ZX#` 终稿，窗口不关。
- 指导伪造条款、倒签、隐匿 → 整体停止，不是该格不支持。
- 首次开庭前未异议：该提交稿字段停止；不得写成仍可提交有效异议终稿，也不得改走负触发关窗。

## 节点 4　论坛、管辖异议、应裁、起诉接口

第 7 节只开接口，不得夹带 `ZX#` 终稿或可提交异议书绕闸。闸关闭时第 7 节可写「闸未开，转介待条款编号」，不得补写已提出。不选定法院。不代提交。

下一步只转介：`评估合同管辖与仲裁协议`、`提出合同案件管辖异议`、`应对合同纠纷一审`、`应对合同仲裁`、`提起合同纠纷一审`、`提起合同仲裁`、`选择诉讼仲裁或督促程序`、`评估合同成立与效力`、`评估争议中的格式条款`、`申请撤销仲裁裁决`、`申请不予执行仲裁裁决`、`建立合同争议证据案卷`、`准备合同案件庭审`。禁止此致某院。应诉不得写成放弃仲裁。答辩十五日不得充首次开庭前。

若 if 用户催促「已读就算开庭了／草稿写完就算提出了／应诉就算放弃仲裁／过了今晚仍要可提交终稿／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「仲异闸与仲异行草案」。本窗不执行发送。不包含：已提出、协议已无效、发送版异议书、管辖异议书、实体答辩终稿。禁止选边治愈。禁止已读即开庭。禁止草稿即已提出。禁止应诉即放弃。禁止指导伪造条款或隐匿。仲异闸打开 ≠ 已提出 ≠ 协议已无效 ≠ 法院必驳回。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标仲异终稿已形成。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：买卖合同有「可仲裁也可诉讼、机构写某地仲裁委」条款，对方已向某区法院起诉，被告微信已读起诉状 PDF。用户主张条款当然无效、合同一无效仲裁就没了、已读就算首次开庭过了、应诉答辩就算放弃仲裁、答辩十五天就是异议截止、草稿写完就算提出了、此致某中院保证确认无效、不清楚先写零。仲异闸打开或半开。`Q-裁`、`Q-独`、`Q-达`、`Q-仲`、`Q-签`、`Q-院`、`Q-胜`、`Q-零` 不打开为可靠路径。第 6 节不得把已提出、已无效、已放弃、已开庭、0、此致某院写入可执行 `ZX#`；对应格 `现有依据不支持` 或字段停止；仍出条款分列、书面三要素待核、或裁或诉待核、首次开庭前缺口等其他 `ZX#`。不关窗。不代提交。不选定法院。

场景②：用户同时交出己方「必须确认无效、签署日改到上周、把或裁或诉那句藏起来」与对方「条款有效、已过首次开庭」口径。命中双方秘密＋倒签＋隐匿条款。第一次整体停止。只交第 1、10 节。不出 `ZX#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代违法方案。
