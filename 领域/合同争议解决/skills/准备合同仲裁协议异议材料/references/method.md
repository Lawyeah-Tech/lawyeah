# 仲裁协议异议方法

本文件是可执行判断节点，不是栏目说明书。每个会改变结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然结果或唯一必得总额。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。实务检索若出现“违约金不超过合同标的百分之三十”，记为噪声。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

应诉答辩或提出反诉，不等于当然放弃仲裁协议。解除通知到达对方时解除；未通知而起诉或申请仲裁主张解除的，仅在该主张获确认后，自起诉状或仲裁申请书副本送达时解除，不得把立案日写成解除时点。第 585 条“过分高于”对照违约造成的损失，不对照合同总价。


## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填本任务实体结论。

| 信号 | 转出 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定、实际施工人 | 建设工程领域 |
| 金融借贷、保证、抵押质押、保理、融资租赁主轴 | 金融借贷担保领域 |
| 商品房买卖、开发合作、物业服务主轴 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、劳动报酬、解除劳动合同、工伤待遇 | 劳动领域 |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

混合信号：一般买卖或服务主轴可留本任务；专项只作为背景时在缺口标明，不把专项规则硬套进一般合同结论。


## 节点 1　程序位置

1. 登记：仲裁申请、法院起诉、应诉通知、首次开庭日、已提出的异议。
2. 对仲裁协议效力有异议，应当在仲裁庭首次开庭前提出。具体条号运行时核验现行仲裁法。
3. 一方向法院起诉未声明有仲裁协议，另一方在首次开庭前提交仲裁协议的，法院应驳回起诉，协议无效或法律另有规定除外；首次开庭前未异议的，视为放弃仲裁协议。
4. 应诉提交实体答辩，不等于当然视为放弃仲裁。放弃必须回链法定节点事实。
5. 首次开庭前未提异议，后又申请法院确认无效：按司法解释通常不予受理。不得指导补做虚假开庭前异议。

若：程序位置不明 → 时点字段停止。
若：用户只想评估条款、尚未决定提出 → 转 `评估合同管辖与仲裁协议`。

## 节点 2　协议要件

1. 书面形式：合同条款、补充协议、往来数据电文。
2. 请求仲裁的意思必须清楚。或裁或诉、既可起诉也可仲裁：效力标待核。
3. 仲裁事项须覆盖本案请求。超范围事项单列。
4. 选定机构或可确定机构。机构更名、合并、不存在须核验。
5. 独立性：合同不生效、无效、被撤销或终止，不影响争议解决条款。不得因主合同效力争点直接写仲裁条款无效。

## 节点 3　无效或不适用

运行时核验现行仲裁法和民法典民事行为能力、意思表示规则。

1. 无民事行为能力人订立的仲裁协议。
2. 胁迫订立。
3. 约定事项超出可仲裁范围。
4. 约定的仲裁机构不存在或无法确定，且依法导致协议无效或不明确。
5. 未签字主体、债权受让后仲裁条款是否约束受让人：单独判断，不概括。

`search_law` 返回已失效合同法或旧条号记忆时记为噪声。

## 节点 4　材料

1. 异议或确认申请、协议文本、主体资格、程序时点证据、覆盖范围对照表。
2. 不把质量、价款实体抗辩写入效力申请主文。
3. 不保证法院或机构支持无效。
4. 与法院地域管辖异议互斥主成果：用户只要移送其他法院，走管辖异议原子。

## 节点 5　失败与并行

1. 效力被维持：转仲裁应诉或仲裁申请原子。
2. 效力被否定：转诉讼入口，不在本任务写起诉状。
3. 已过异议节点：只输出放弃风险，停止有效异议终稿。

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。

下一步按期限灭失、易失证据、改变本任务结论、可逆性排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。

禁止指导伪造、隐匿、威胁或违法取证。未知金额不写零。不把应诉写成放弃仲裁。不把立案日写成解除时点。
