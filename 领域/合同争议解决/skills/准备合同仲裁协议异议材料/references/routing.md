# 边界与路由

## 正触发

一般合同对方依仲裁条款推进诉讼或仲裁，己方主张仲裁协议无效、未成立或不适用，需要异议或效力确认材料草稿。从零、碎片、时点未核验、无书面授权仍正触发：有可编号仲裁条款、起诉状、仲裁申请或开庭通知碎片则闸开或半开，出 `ZX#` 草案，保持草案。逾期仍要赶写终稿仍正触发：该提交稿字段停止，窗口不关。本次不代提交、不保证无效、不写管辖异议书是交付禁令，不是开窗条件。草稿即已提出、已读即已开庭、应诉即放弃仲裁，仍正触发。

双方秘密、伪造仲裁条款、倒签签署日或异议日或开庭日、隐匿条款、伪造送达、违法取证的停止，优先于负触发。上述信号不在下表。不代提交不是负触发。「草稿即已提出」「已读即已开庭」「应诉即放弃仲裁」「答辩十五日即仲裁异议截止」「合同无效即仲裁消灭」「或裁或诉当然有效或当然无效」「逾期仍要可提交终稿」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 管辖或仲裁效力评估终稿 | `评估合同管辖与仲裁协议` |
| 法院管辖异议书 | `提出合同案件管辖异议` |
| 含实体抗辩的一审答辩 | `应对合同纠纷一审` |
| 仲裁应裁实体 | `应对合同仲裁` |
| 原告起诉包 | `提起合同纠纷一审` |
| 仲裁申请包 | `提起合同仲裁` |
| 程序选择闭集 | `选择诉讼仲裁或督促程序` |
| 撤销仲裁裁决申请 | `申请撤销仲裁裁决` |
| 不予执行申请 | `申请不予执行仲裁裁决` |
| 尚未成争，改仲裁条款 | 审查起草领域（本窗搁置，只说明） |
| 工程／金融／房产／海事／劳动主轴 | 对应领域 |

不得因「不代提交」或「不保证无效」关窗。拟异议材料仍正触发，不得写成已提出或已无效。
