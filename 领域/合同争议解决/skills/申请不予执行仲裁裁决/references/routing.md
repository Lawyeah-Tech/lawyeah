# 边界与路由

## 正触发

一般合同商事仲裁裁决已进入执行，被执行方拟申请不予执行草稿。从零、碎片、尚未执行仍要本窗草稿仍正触发：有可编号裁决且有执行开始碎片则闸开或半开；执行未开始则闸可关，该格不支持，窗口不关。本次不保证不予执行、不代提交是交付禁令，不是开窗条件。草稿即已裁定、实体不服即应不予执行，仍正触发。把相同事由交叉提写成可提交、把逾期写成仍可提交终稿，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造、倒签执行通知日、转移财产的停止，优先于负触发。上述信号不在下表。不保证不予执行不是负触发。「草稿即已裁定」「实体不服即应不予执行」「相同事由交叉提」「逾期仍可提交终稿」「保证停止执行」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 撤裁终稿 | `申请撤销仲裁裁决` |
| 执行申请 | `执行合同生效文书` |
| 普通执行行为异议或履行安排 | `应对合同案件执行` |
| 执行和解 | `准备合同执行和解` |
| 上诉状 | `提起合同案件上诉` |
| 应裁实体 | `应对合同仲裁` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不保证不予执行」或「不代提交」关窗。拟申请草稿仍正触发，不得写成已裁定或已停止执行。

## 专项整案转出

| 主轴信号 | 路由 |

| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |

一般买卖或服务夹带专项背景时，专项段只分流。出现「不予执行」「执行」一词不是转出。C 端只要大众填空页时只分流，不把本包降成填空式结论，不回改。

## 易混

本窗闸名只能是不执闸，不是执行闸，不是撤裁闸，不是申请闸，不是异议闸。`BZ#` 不是 `HC#`，不是 `ZC#`，不是 `HS#`。主路径是 `Q-不执`，不是 `Q-撤裁`，不是 `Q-执`。`撤裁闸`／`HC#`／`Q-撤裁` 是申请撤销仲裁裁决；邻窗 `Q-不执` 只转介进本窗。`Q-执` 是单独和解即已可执行不关窗码。2017 年民事诉讼法第二百三十七条不是现行不予执行。现行第二百四十四条是执行回转不是不予执行。执行规定仍引第二百三十七条须核对应现行第二百四十八条。1994 年第七十六条仲裁费用不是不予执行。劳动终局不是本窗。提出「把执行通知日改到上周」整体停止。本窗不代提交。不选定中院。不保证停止处分。
