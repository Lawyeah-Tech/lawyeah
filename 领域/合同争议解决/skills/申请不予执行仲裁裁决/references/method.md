# 申请不予执行仲裁裁决方法

本文件是可执行判断节点。草稿不是已裁定不予执行。执行开始后才可能。相同事由交叉提通常不支持。实体不服通常不足。未知不写零。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止不予执行率、已裁定、已停止执行、选定中院、代提交、未知写零。本任务不定罪，不执行发送，不保证停止处分。本窗闸名只能是不执闸，禁止复用执行闸、撤裁闸、申请闸。预留不得占用：立案闸、保全闸、执行闸、撤裁闸。本窗 `BZ#` 是不执行。主路径只用 `Q-不执`，禁止用 `Q-撤裁`、`Q-执`、`Q-签` 作主路径。本窗 `Q-签` 只作「草稿即已提交或已裁定不予执行」不关窗码。本窗 `Q-执禁` 只作「申请即已停止执行」不关窗码。英文 id 禁止使用，一律用中文技能名 `申请不予执行仲裁裁决`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 2017 年民事诉讼法第二百三十七条、现行第二百四十四条执行回转、1994 年第七十六条仲裁费用、把尚未执行写成可提交终稿时记为噪声。禁止指导伪造材料、倒签执行通知日或转移执行财产。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现裁决切片扫描，不是默认闭集。
`BZ#` 固定列：`编号｜裁决切片｜执行案与管辖接口｜法定事由对照｜交叉提禁令与中止接口｜申请接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已裁定不予执行」或「已停止执行」。无 `E#` 不得写已裁定。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-不执`。禁止 `HC#`、`ZC#`、`HS#`、`A#`、`N#`。文件状态只用 `草案`、`停止`。

口头「今晚卡住执行」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。不写死唯一日历截止日。

实务上：被申请人举证。执行通知送达起十五日。多个事由一并。撤裁被驳回后相同事由通常不支持。调解书原则上不支持。不执须担保才应当中止执行。

## 节点 0　分流、立场、不执闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造、倒签执行通知日、转移隐匿财产、虚假仲裁、违法取证不进负表。利益冲突未解不进整体停止。不保证不予执行、不代提交不是负触发。

整案转出只交付第 1、2、10 节，不出 `BZ#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是撤裁终稿 | 负触发 `申请撤销仲裁裁决` |
| 主成果是执行申请 | 负触发 `执行合同生效文书` |
| 主成果是普通执行行为异议 | 负触发 `应对合同案件执行` |
| 主成果是执行和解 | 负触发 `准备合同执行和解` |
| 主成果是上诉状 | 负触发 `提起合同案件上诉` |
| 主成果是应裁实体 | 负触发 `应对合同仲裁` |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程／金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不保证不予执行」「不代提交」 | 交付禁令，不是负触发 |

出现「不予执行」「执行」一词不是转出。

不执闸打开须同时满足：单方无冲突被执行立场已闭合；主成果是不予执行申请草稿，不是撤裁终稿、不是执行异议终稿、不是发送版；至少一项可编号裁决碎片 **且** 执行开始碎片。口头「卡住执行」不算单独开闸材料。

不执闸部分打开：已有裁决或执行碎片之一，通知日、事由或交叉禁令未闭合；仍交十节。

不执闸关闭（仍正触发）：无一可编号碎片，或仅有裁决、执行未开始又要已裁定终稿。不出 `BZ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `BZ#` 终稿，**第 7 节不得出发送版**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已裁定」「实体不服即应不予执行」「相同事由交叉提」「逾期仍可提交终稿」「未知写零」**不关窗**。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 不执闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造材料、倒签执行通知日、转移隐匿财产、虚假仲裁或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 3　不执行 `BZ#`

按已出现裁决切片扫描，不是默认闭集。每条须能指向裁决、执行开始或法定事由之一。

无 `E#` 不得写已提交或已裁定。状态默认 `草案`。一次只推荐下一步。未知不写零。执行开始或事由未闭合不得标待提交。

热冲突强制处理：

- 草稿即已裁定／实体不服即应不予执行／相同事由交叉提／逾期仍可提交终稿／未知写零 → 该格不支持或字段停止；仍出其他 `BZ#`。
- 无一碎片或执行未开始要已裁定终稿 → 关闸，不出 `BZ#` 终稿，窗口不关。
- 指导伪造、倒签执行通知日、转移财产 → 整体停止，不是该格不支持。

## 节点 4　撤裁、执行异议、和解与中止接口

第 7 节只开接口，不得夹带 `BZ#` 终稿或发送版绕闸。闸关闭时第 7 节可写「闸未开，转介待事项编号」，不得补写已裁定。不选定中院。不代提交。撤裁受理应当中止执行只开接口。不执须适当担保才应当中止执行，不保证停止处分。

下一步只转介：`申请撤销仲裁裁决`、`提起合同仲裁`、`应对合同仲裁`、`准备合同仲裁协议异议材料`、`评估合同管辖与仲裁协议`、`提起合同案件上诉`、`执行合同生效文书`、`应对合同案件执行`、`准备合同执行和解`、`准备合同案件庭审`、`建立合同争议证据案卷`、`评估合同争议`、`选择诉讼仲裁或督促程序`、`谈判合同和解方案`、`准备合同财产保全申请`、`测算违约金与损害赔偿`、`评估合同调解方案与效力`。禁止此致某中院。

若 if 用户催促「赔多了也要停／撤裁刚驳回同一套事由再提／草稿写完就算已经裁定／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止；倒签执行通知日第一次整体停止。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「不执闸与不执行草案」。本窗不代提交。不包含：已裁定不予执行、已停止执行、撤裁终稿、执行异议终稿。禁止选边治愈。禁止草稿即已裁定。禁止指导倒签或转移财产。不执闸打开 ≠ 已提交 ≠ 已裁定 ≠ 已停止执行。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标申请终稿已形成。
风险档 A：伪造材料、倒签执行通知日、转移财产必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：执行通知已送达。用户主张赔多了也要不予执行、撤裁刚被驳回用同一套程序事由再提、草稿写完就算已经裁定、此致某中院、不清楚先写零、顺便再写一份撤裁。不执闸打开或半开。`Q-体`、`Q-同`、`Q-签`、`Q-混`、`Q-院`、`Q-零` 不打开为可靠路径。第 6 节对应格不支持；仍出裁决分列、通知日、第二百四十八条分列待核。不代提交。不保证中止。

场景②：双方秘密＋倒签执行通知日＋伪造程序材料。第一次整体停止。只交第 1、10 节。不出 `BZ#`。不得问代表哪一方后继续。不以「坚持」为门槛。
