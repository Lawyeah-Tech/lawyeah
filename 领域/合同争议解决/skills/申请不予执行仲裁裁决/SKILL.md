# 申请不予执行仲裁裁决

## 任务目标

在明确、无利益冲突的单方立场下（被执行人或其受托律师，互斥），形成发送前不予执行申请草稿：不执闸、主体与强制接口、`Q#` 路径、`BZ#` 不执行（裁决切片／执行案与管辖接口／法定事由对照／交叉提禁令与中止接口／申请接口／`E#` 回链）。本窗 `BZ#` 是不执行草案，不是已提交，不是已裁定不予执行，不是已停止执行，不是撤裁终稿，不是执行异议终稿。本窗闸名只能是不执闸，禁止复用执行闸、申请闸、撤裁闸、撤销闸、仲裁闸、异议闸、支付闸、上诉闸、开庭闸、起诉闸。预留不得占用：立案闸、保全闸、应裁闸、执行闸、撤裁闸。本窗主行只能是 `BZ#`，禁止 `HC#`、`ZC#`、`ZX#`、`HS#`、`LF#`、`QF#`、`KT#`、`A#`。主路径只用 `Q-不执`，禁止用 `Q-撤裁`、`Q-执`、`Q-执禁`、`Q-签`、`Q-申`、`Q-上`、`Q-裁`、`Q-仲`、`Q-金令` 作主路径。邻窗 `Q-不执` 只作转介进本窗；本窗打开为主路径，不是已裁定不予执行、不是已停止执行。本窗 `Q-撤裁` 只转介 `申请撤销仲裁裁决`。本窗 `Q-执申` 只转介 `执行合同生效文书`。本窗 `Q-执` 不打开为主路径。本窗 `Q-执禁` 只作「申请即已停止执行或草稿即已裁定不予执行」不关窗码。本窗 `Q-签` 只作「草稿即已提交或已裁定不予执行」不关窗码。不执闸打开不等于已提交不等于已裁定不予执行不等于已中止处分不等于待提交终稿。草稿不是已裁定不予执行。网交不是已提交。执行开始后才可能。执行通知送达起十五日书面申请。已读不是送达起算。实体不服通常不足。撤销不是不予执行。相同事由交叉提通常不支持。仲裁调解书或依和解协议作出的裁决原则上不支持，公共利益除外。不执须适当担保才应当中止执行，不保证停止处分。行为违法走执行行为异议，不是不予执行。案外人虚假仲裁不是本窗主线。未知不写零。不代提交。不选定中院。不定罪。不保证不予执行。伤残等级与本窗无关，禁止折入。

`depends-on` 为空。主成果是撤裁终稿转 `申请撤销仲裁裁决`。主成果是执行申请转 `执行合同生效文书`。主成果是普通执行异议转 `应对合同案件执行`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：一般合同商事仲裁裁决已进入执行，被执行方拟申请不予执行草稿。「今晚卡住执行」「赔多了也要停」仍正触发，成果状态 `草案`，不代提交。执行案、通知日、事由未核验仍正触发：有可编号裁决碎片且有执行开始碎片则不执闸打开或半开，第 6 节出 `BZ#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出已裁定不予执行终稿」才关闸，仍交十节，第 6 节不出 `BZ#` 终稿，第 7 节不得出发送版，窗口不关。尚未进入执行仍要本窗草稿：仍正触发，闸可关或半开，该格不支持，窗口不关。用户要把草稿写成已裁定、把实体不服写成应不予执行、把相同事由交叉提写成可提交、把逾期写成仍可提交终稿、把未知写成零、把此致某中院写成管辖已定，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `BZ#` 草案。不得因「不保证不予执行」「不代提交」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是撤裁终稿（转 `申请撤销仲裁裁决`）；
- 主成果是执行申请（转 `执行合同生效文书`）；
- 主成果是普通执行行为异议或履行安排（转 `应对合同案件执行`）；
- 主成果是执行和解（转 `准备合同执行和解`）；
- 主成果是上诉状（转 `提起合同案件上诉`）；
- 主成果是应裁实体（转 `应对合同仲裁`）；
- 尚未成争，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）。

双方秘密、伪造申请材料、倒签执行通知日、转移隐匿财产、虚假仲裁、违法取证**不在负触发表**，走整体停止。STUB 把「与撤销混用同一终稿」放进负触发，必须改：主成果才转；混写该格不支持，不出两份主位终稿，窗口不关。STUB 把「撤销已被驳回仍以相同事由再提」放进负触发或目标停止，必须改不关窗。STUB 把「对法院判决不予执行」放进负触发：主成果才转；把判决当裁决该格不支持，窗口不关。「草稿即已裁定」「实体不服即应不予执行」「逾期仍可提交终稿」「未知写零」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不保证不予执行」「不代提交」是交付禁令，不是负触发。主成果才转；出现「不予执行」「执行」一词不是转出。

## 建立工作坐标

确认：申请授权；单方被执行立场；裁决切片；执行案与通知日；法定事由；交叉提禁令；法域；当前撤裁或担保状态。

口头「今晚卡住执行」只登记 `S#`／`V#`。不得升格已提交、已裁定或不予执行已停止处分，**不得单独算作开闸材料**。可编号裁决碎片且有执行开始碎片可开闸。本窗不执行发送，不代提交。

立场只许被执行人或其受托律师，互斥。同时掌握对立双方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：不执闸关闭，仍交十节，不是整体停止。无书面授权但单方立场已闭合、且已有碎片：不执闸部分打开，仍交十节，不是整体停止。提出伪造申请材料、倒签执行通知日、转移隐匿财产、虚假仲裁或违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 合同或仲裁条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`BZ#` 不执行；`V#` 版本；`E#` 证据形态回链（裁决书、执行通知、程序记录，不是发送闸，不是已裁定不予执行证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`HC#`、`HS#`、`ZC#`、`ZX#`。技能正文中的条号是检索锚点，不是已核验 `L#`。文件状态只用 `草案`、`停止`。执行开始或事由未闭合不得标待提交。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。未知不写零。草稿 ≠ 已裁定不予执行。申请 ≠ 已停止执行。实体不服 ≠ 应不予执行。撤销 ≠ 不予执行。已读 ≠ 送达起算。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或文书范本检索。本窗是申请草稿准备，范本只借不予执行仲裁裁决申请书栏目，**不要**升格「已提交／已裁定不予执行／已停止执行」。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现草稿即已裁定、实体不服即应不予执行、相同事由交叉提、尚未执行也可提交终稿的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把 2017 年民事诉讼法第二百三十七条当作现行不予执行。不得把现行第二百四十四条执行回转当作不予执行。不得把 2017 年仲裁法第六十三条所引第二百一十三条未核验对应现行第二百四十八条。执行规定仍引第二百三十七条第四、六项须核对应现行第二百四十八条第二款第四、六项。仲裁法 2025 修订施行日 2026-03-01 已施行，MCP 标尚未施行时以施行日为准。不得把 1994 年第七十六条仲裁费用当作不予执行。MCP 效力字段与公布施行日冲突时，以施行日为准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的十五日、事由、管辖或施行日保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民事诉讼法（2023 修正，施行日 2024-01-01）第二百四十八条一方不履行可申请执行；被申请人提出证据证明有下列情形之一的，合议庭审查核实裁定不予执行：没有仲裁条款或书面协议；事项不属于协议范围或机构无权仲裁；组成或程序违反法定程序；证据伪造；向机构隐瞒足以影响公正裁决的证据；仲裁员贪污受贿、徇私舞弊、枉法裁决。违背社会公共利益的裁定不予执行。不予执行后可重新仲裁或起诉。噪声：2017 年第二百三十七条；现行第二百四十四条执行回转；现行第二百三十七条超六个月未执行。仲裁法（2025 修订，施行日 2026-03-01）第七十六条被申请人证明有第七十一条第一款情形的，裁定不予执行；违背公共利益应当不予执行。噪声：2017 年第六十三条；1994 年第七十六条仲裁费用。第七十七条一方执行一方撤销应当中止执行。执行规定（2018）第二条由被执行人住所地或财产所在地中院管辖。第七条撤裁已受理应当中止执行；不予执行申请并提供适当担保应当中止执行，申请执行人提供充分担保可请求继续执行。第八条执行通知书送达之日起十五日内书面申请；有民诉第二百三十七条第二款第四、六项情形且执行未终结的，自知道或应当知道之日起十五日，所引条号须核对应现行第二百四十八条。期限届满前撤裁已受理的，自驳回撤裁裁判生效日起重新计算。第十条多个事由应当一并提出；驳回后再次提出原则上不予审查，第四、六项新证据除外。第十一条合议庭围绕已申请事由审查，未申请事由原则上不审，公共利益除外。第十七条对仲裁调解书或依和解、调解协议作出的裁决申请不予执行，原则上不予支持，公共利益除外。第十九条逾期不予受理或驳回。第二十条撤裁被驳回后相同事由不予执行不予支持；对称反向同样；不予执行审查中撤裁受理则中止对该申请的审查。解释第四百七十九条应在执行终结前向执行法院提出。技能正文条号不是 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变期限、事由或管辖的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补草稿不是已裁定、执行未开始不是可提交终稿、相同事由交叉通常不支持、实体不服通常不足、担保不是当然停止处分、调解书原则上不支持的实务反例。噪声：实务仍写第二百三十七条或六个月。
- `search_template` 只借不予执行仲裁裁决申请书栏目。范本落款、此致某中院、请予不予执行不得升格已提交、已裁定、管辖已定或已停止执行。禁止用撤裁申请书、起诉状、上诉状、执行异议书、支付令、公证债权文书或劳动终局材料改头换面。禁止用范本生成发送版或伪造证据清单。

工具不可用时继续裁决、执行碎片和 `BZ#` 编目；已裁定、已提交、十五日、事由、管辖字段停止。不得拒跑，不得凭记忆写成已裁定或尚未执行也可提交终稿。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、不执闸与不关窗

主成果才整案转出。双方秘密、伪造、倒签执行通知日第一次停。草稿即已裁定、相同事由交叉提不关窗。闸关仍交十节，第 6 节不出 `BZ#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

裁决／执行开始／法定事由／交叉禁令／执行中院分列。实体不服关可提交该格。本节禁止出 `BZ#` 终稿。

### 3. 不执闸与路径 `Q#`

本节禁止出 `BZ#` 终稿。有可编号裁决且有执行开始碎片：闸打开或半开。主路径只用 `Q-不执`。

### 4. 不执行 `BZ#`

切片、执行案与管辖、事由、交叉与中止、申请接口。状态 `草案`。禁止升格已提交、已裁定。无 `E#` 不得写已裁定不予执行。

### 5. 撤裁、执行异议、和解与中止接口

撤裁转撤裁窗。执行异议转应对执行窗。第 7 节不得夹带 `BZ#` 终稿或发送版绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造申请材料、倒签执行通知日、转移隐匿财产、虚假仲裁或违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：不执闸关闭，仍交十节，不是整体停止。无书面授权但有碎片：不执闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：执行通知送达日、十五日、第二百四十八条逐项、相同事由、施行日未核验。草稿即已裁定、实体不服即应不予执行、相同事由交叉提、逾期仍可提交终稿、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `BZ#` 草案。
- `目标停止`：主目标变为撤裁终稿、执行申请或普通执行异议终稿。禁止把「相同事由再提」当作用户错误主张时的目标停止；那是不关窗。

禁止指导伪造材料、倒签执行通知日或转移执行财产。不给不予执行率。不定罪。不选定中院。不代提交。未知不写零。不写发送版。不保证停止处分。

## 交付
