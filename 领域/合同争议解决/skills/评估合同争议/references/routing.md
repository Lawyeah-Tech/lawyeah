# 边界与路由

## 正触发

一般合同已成争，单方需要总体决定请求、抗辩、论坛、证据优先级和下一步。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |
| 评估管辖或仲裁条款本身 | `评估合同管辖与仲裁协议` |
| 只判断能否解除 | `评估解除权是否成立` |
| 发催告履行 | `准备催告履行或补救通知` |
| 发解除通知 | `准备解除通知` |
| 精算违约金或损失 | `测算违约金与损害赔偿` |
| 完整证据卷 | `建立合同争议证据案卷` |
| 和解条件 | `谈判合同和解方案` |
| 起诉 | `提起合同纠纷一审` |
| 应诉 | `应对合同纠纷一审` |
| 工程／金融／房产／海事／劳动 | 对应领域 |
| C 端 032／012／011 | 大众专项，只分流不回改 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融借贷担保领域 |
| 商品房、开发合作、物业服务 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、工资、解除劳动合同、工伤 | 劳动领域 |

一般买卖或服务夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

请求尚未闭合、需比较是否提出解除或先催告时正触发。主体、请求、论坛均确认且只要诉状时负触发。有仲裁条款仍要求“直接起诉”时，先完成论坛闸，不改写成立案原子。
