# 边界与路由

## 正触发

一般合同已成争，需要总图再决定催告、解除、测算或诉讼。从零、碎片、文本未核验、无书面评估授权仍正触发：有可编号合同或履行／程序碎片则闸开或半开，出 `ZT#` 草案，保持草案。本次不写发送版催告或诉状、不给胜诉率、不选定法院是交付禁令，不是开窗条件。构成违约即解除、约定金即必得、仲裁即应起诉，仍正触发。

双方秘密、伪造合同、倒签签署或解除日、隐匿证据、违法取证的停止，优先于负触发。上述信号不在下表。不写发送版催告不是负触发。「构成违约即已解除」「约定数字即必得」「仲裁即应起诉」「已读即已送达」「准备起诉即已解除」「未异议即已解除」「保证胜诉」不在下表。伪造倒签不在下表，走整体停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 管辖或仲裁条款评估终稿 | `评估合同管辖与仲裁协议` |
| 解除权是否成立终稿（不发函） | `评估解除权是否成立` |
| 发送版催告 | `准备催告履行或补救通知` |
| 发送版解除通知 | `准备解除通知` |
| 精算工作表 | `测算违约金与损害赔偿` |
| 完整证据卷 | `建立合同争议证据案卷` |
| 和解谈判要点 | `谈判合同和解方案` |
| 可提交一审起诉包 | `提起合同纠纷一审` |
| 首次应诉答辩 | `应对合同纠纷一审` |
| 成立或效力专项终稿 | `评估合同成立与效力` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |
| 工程／金融／房产／海事／劳动主轴 | 对应领域 |

不得因「不写发送版催告」或「不写诉状」关窗。拟争议总图仍正触发，不得写成已解除或应起诉。

## 易混

本窗闸名只能是争议闸，不是催告闸，不是解除闸，不是论坛闸，不是精算闸。`ZT#` 不是催告，不是解除函，不是诉状。主路径是 `Q-总`，不是 `Q-催`，不是 `Q-解`，不是 `Q-管`。构成违约不是当然解除。约定违约金不是必得。仲裁条款不是应起诉。口头或已读不是已送达。准备起诉不是已解除。未异议不能补正解除权缺失。已失效《合同法》不是现行规则。「过分高于」对照损失不是合同总价。仲裁法 2025 修订施行日 2026-03-01 已施行。「把解除通知倒签」整体停止。本窗不执行发送，不代提交。不选定法院。
