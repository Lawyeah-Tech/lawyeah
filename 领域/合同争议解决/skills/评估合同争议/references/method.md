# 评估合同争议方法

本文件是可执行判断节点。构成违约不是当然解除。约定违约金不是必得。仲裁条款不是应起诉。口头或已读不是已送达。准备起诉不是已解除。未异议不能补正解除权缺失。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已解除、应起诉、唯一必得总额、选定法院、代提交、未知写零。本任务不定罪，不写发送版催告、解除函或诉状。本窗闸名只能是争议闸，禁止复用评估闸、催告闸、解除闸、论坛闸、精算闸、管辖闸、起诉闸、答辩闸、案卷闸、和解闸、谈判闸、保全闸、冻结闸、关系闸。预留不得占用：立案闸、催告闸、解除闸、论坛闸、精算闸。本窗 `ZT#` 是总图行。主路径只用 `Q-总`，禁止用 `Q-催`、`Q-解`、`Q-清`、`Q-争`、`Q-管`、`Q-诉`、`Q-约` 作主路径。英文 id 禁止使用，一律用中文技能名 `评估合同争议`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》及其解释、把「过分高于」对照合同总价、把「标的额百分之三十」当已核验、把构成违约写成当然解除时记为噪声。禁止指导伪造合同或倒签。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现合同或履行碎片扫描，不是默认闭集。
`ZT#` 固定列：`编号｜合同切片｜请求抗辩｜论坛期限｜金额区间｜打开接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「合同权益」一笔。无 `E#` 不得写已解除、已到达或应起诉。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-总`。禁止 `GX#`、`FZ#`、`BQ#`、`HT#`、`A#`、`N#`。

口头「已经违约了」「今天发函就算解除」「有仲裁也直接起诉」只进 `S#`／`V#`，**不得单独算作开闸材料**。已读不得升格已送达。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：迟延主要债务原则上先催告。无解除权的通知不因对方未异议而生效。约定数字不是必得，增减须当事人请求；过分高于对照损失不是合同总价。仲裁条款出现不得写应起诉。

## 节点 0　分流、立场、争议闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造合同、倒签签署或解除日、隐匿证据、违法取证不进负表。利益冲突未解不进整体停止。不写发送版催告或诉状、不给胜诉率不是负触发。

整案转出只交付第 1、2、10 节，不出 `ZT#` 终稿。

| 主成果是和解谈判要点 | 负触发 `谈判合同和解方案` |

混合信号：一般买卖或服务主轴可留本任务。出现「解除」「仲裁」「违约金」一词不是转出。

争议闸打开（可出 `ZT#` 草案，仍不得标「已解除／应起诉／必得总额」）须同时满足：单方无冲突立场已闭合；主成果是争议总图，不是催告函、不是解除函、不是诉状；至少一项可编号合同或履行／程序碎片。口头「已经违约了」不算单独开闸材料。

争议闸部分打开：已有碎片，但文本版本、送达或金额未闭合；对应格待核；仍交十节。无书面评估授权但单方立场已闭合且已有碎片：争议闸部分打开，仍交十节，不是整体停止。

争议闸关闭（仍正触发）：无一可编号碎片。「今天必须出已解除／应起诉终稿」而无最小碎片不得开闸。不出 `ZT#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `ZT#` 终稿，**第 7 节不得出催告、解除函或诉状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「构成违约即已解除」「约定数字即必得」「仲裁即应起诉」「已读即已送达」「准备起诉即已解除」「未异议即已解除」「保证胜诉」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `ZT#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 争议闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造合同、倒签签署或解除日、隐匿证据或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体、文本版本与程序状态

一行一个合同切片或主体。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `ZT#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 主体 | 签约名、履行名、付款名、发票名分列 | 名称不一致自动合并 |
| 文本版本 | 合同、附件、订单、对账单、会议纪要、聊天变更冲突并列 | 选对用户有利的一版冒充唯一文本 |
| 程序 | 协商、催告、解除通知、仲裁、诉讼：机关、文书、作出日、收到日、送达方式 | 口头转述、截图、已读升格已受理、已送达或期限已起算 |

检索锚点（写入 `L#` 前须核验）：

- 民法典第五百六十三条法定解除；迟延主要债务原则上先催告。噪声：商品房解释三个月合理期限不得套一般买卖当然适用。
- 第五百六十四条解除权除斥；第一百九十九条不适用诉讼时效中止、中断、延长。
- 第五百六十五条通知到达时解除；未通知而起诉或仲裁主张解除，确认后自副本送达时解除。噪声：合同法第九十六条。
- 合同编通则解释第五十三条无解除权不因未异议而生效。第五十四条撤诉后再诉以再次起诉副本送达为准。
- 第五百七十七条违约责任不是当然解除。第五百八十五条过分高于对照损失。解释第六十四条、第六十五条。噪声：合同法解释二；「标的额百分之三十」。

名称不一致不自动合并。口头变更与书面冲突并列，不选边。

## 节点 3　总图行 `ZT#`

按已出现合同切片扫描，不是默认闭集。每条须能指向文本、请求抗辩或论坛接口之一。

无 `E#` 不得写已解除、已到达或应起诉。状态 `草案`。一次只推荐下一步。未知金额不写零，不输出唯一必得总额。

热冲突强制处理：

- 构成违约即解除／约定金即必得／仲裁即应起诉／已读即到达／准备起诉即已解除／未异议即已解除／未知写零 → 该格不支持或字段停止；仍出其他 `ZT#`。
- 无一碎片 → 关闸，不出 `ZT#` 终稿，窗口不关。
- 指导伪造合同、倒签、隐匿证据 → 整体停止，不是该格不支持。

## 节点 4　催告、解除、管辖与诉讼接口

第 7 节只开接口，不得夹带 `ZT#` 终稿、催告、解除函或诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待合同编号」，不得补写已解除或应起诉。期限分列，不混算，不写唯一截止日。不选定法院。不代提交。

下一步只转介：`评估合同管辖与仲裁协议`、`评估解除权是否成立`、`准备催告履行或补救通知`、`准备解除通知`、`测算违约金与损害赔偿`、`建立合同争议证据案卷`、`提起合同纠纷一审`、`应对合同纠纷一审`。禁止此致某院。

若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：有买卖合同和迟延交货聊天记录。用户主张已经违约所以合同已经解除、条款写了违约金就是必得、有仲裁条款也直接去某区法院、微信已读就算通知到了、准备起诉就算已经解除、不清楚的损失先写零。争议闸打开或半开。`Q-违`、`Q-必`、`Q-仲`、`Q-读`、`Q-拟`、`Q-院`、`Q-零` 不打开为可靠路径。第 6 节不得把已解除、应起诉、必得、0 写入可执行 `ZT#`；对应格 `现有依据不支持` 或字段停止；仍出文本分列、催告缺口、论坛待核、金额接口等其他 `ZT#`。不关窗。不写诉状。不选定法院。
