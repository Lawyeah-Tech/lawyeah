# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然解除、必然受理或唯一必得总额。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜关系假设｜提出方｜相对方｜法律效果｜成立条件｜支持事实｜不利事实｜控制方｜最强反方｜主备位｜判断｜待核`。

解除、继续履行、违约金、赔偿、定金分列。同一事实支持多项时分别说明效果，不重复金额。构成违约不等于当然解除。

---

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填总体评估十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定、实际施工人 | 建设工程领域 |
| 金融借贷、保证、抵押质押、保理、融资租赁主轴 | 金融借贷担保领域 |
| 商品房买卖、开发合作、物业服务主轴 | 房地产物业领域 |
| 海上货物、船舶、海事保全 | 海事领域 |
| 劳动关系、劳动报酬、解除劳动合同、工伤待遇 | 劳动领域 |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

混合信号：一般买卖/服务主轴可留本任务；专项只作为背景时在缺口标明，不把专项规则硬套进一般合同结论。

## 节点 1　主体、文本版本和程序状态

1. 固定合同、附件、订单、对账单、会议纪要、聊天变更的版本层级。冲突并列，不选对用户有利的一版冒充唯一文本。
2. 主体表记录签约名、履行名、付款名、发票名和可能责任主体。名称不一致不自动合并。
3. 程序表逐动作记录协商、催告、解除通知、仲裁、诉讼或执行：机关/机构、案号、文书、作出日、收到日、送达方式和效力凭证。口头转述、截图、“已读”不得写成已受理、已送达或期限已起算。
4. 同时掌握双方秘密或立场不明：整体停止策略输出。

## 节点 2　请求与抗辩假设

每个 `Q#` 先写法律效果，再写成立条件。禁止合成“合同权益”一笔。

默认主位候选按事实分别建立，不得预先锁定解除：

- `Q-履` 继续履行或补救（修理、更换、重作、减价）
- `Q-催` 催告履行或指定合理期限（本身不是解除）
- `Q-解` 约定解除或法定解除
- `Q-清` 解除后返还、折价、结算清理（接口，不替代专项清理原子）
- `Q-金` 违约金
- `Q-损` 损害赔偿（含可得利益，受可预见、减损、过错相抵约束）
- `Q-定` 定金罚则（与违约金选用，不得双计）
- `Q-抗` 同时履行、先履行、不安、质量异议、时效、仲裁/管辖异议

单位或被指违约方立场：逐项回应对方已知主张，并列己方最强抗辩，不把反诉写成已经提起。

主备位和互斥必须可见。`Q-解` 与 `Q-履` 不得同时写成均已成立。定金与违约金选用不明时两项都标待核，不输出相加总额。

专项评估（成立效力、质量、履行顺序、期限精算）可在矩阵中留接口，不在本任务做专项终局。

## 节点 3　催告还是解除

本节点只判断路径，不生成发送版催告或解除通知。

### 3.1 先分账

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 对方迟延或质量不符 | 已构成法定解除 |
| 用户想今天发函 | 解除权已行使或合同已解除 |
| 约定了违约金 | 合同目的不能实现 |
| 对方未在异议期内异议 | 即使无解除权也已解除 |

### 3.2 法定解除分流（民法典第 563 条）

运行时核验现行文本后再落判断。核验失败则本节点字段停止，事实与问题清单继续。

1. **不可抗力致目的不能实现**：事件、通知、减损分列；商业困难不等于法律上的不能。
2. **预期拒绝主要债务**：表示主体、权限、原文和到达必须可回链；默示拒绝不得单凭迟到几天认定。
3. **迟延主要债务**：原则上先走催告 + 合理期限；期限是否合理标待核，不编造“一律 15 日”。
4. **迟延或其他违约致使目的不能实现**：目的来自合同目的条款、标的性质和磋商，不来自用户事后情绪。轻微迟延、可补救瑕疵不得直接跳到解除。
5. **约定解除**：核对该当条件是否已成就；成就不等于已经发出有效通知。

持续履行的不定期合同随时解除候选，须另列合理期限通知义务，不与违约解除混写。

### 3.3 除斥与到达

- 解除权存续：约定或法定期间；无约定且无法定期间时，知道或应当知道解除事由之日起一年，或经对方催告后的合理期限（第 564 条）。除斥不适用诉讼时效中止、中断、延长（第 199 条）。
- 关键日期冲突建并行情景，不给唯一除斥截止日。
- 通知到达对方时解除；附自动解除期限的，期限届满且未履行时解除（第 565 条）。
- 未通知而直接起诉或申请仲裁主张解除：仅在确认该主张后，自起诉状或仲裁申请书副本送达时解除。评估阶段不得把“准备起诉”写成已经解除。
- 对方未提异议，不能补正解除权的缺失（合同编通则解释第 53 条）。无解除权的通知不发生解除效力。
- 没有送达事实和规则引文，禁止写“合同已解除”。微信已读不等于到达。

### 3.4 输出

| 条件 | 本任务输出 | 转介 |
| --- | --- | --- |
| 仍希望对方履行或补救，催告必要或有用 | 催告是否必要、合理期限待核、风险 | `prepare-demand-notice` |
| 解除路径条件尚未闭合 | 缺口、最强反方、不可逆提示 | 不转介发函 |
| 解除权评估本身成为主目标 | 最小交接 | `assess-termination-right` |
| 用户坚持今天发出解除终稿 | 目标停止 | `prepare-termination-notice`，不在本包出稿 |

## 节点 4　论坛、仲裁与程序入口

分别判断：协商、催告、仲裁、诉讼、确认解除效力、保全红旗、执行。本任务不写立案包或管辖异议书。

### 4.1 仲裁协议优先闸

合同、补充协议或事后书面协议中出现仲裁条款时：

1. 不得直接写“应向法院起诉”。
2. 分列：是否书面；是否有请求仲裁的意思；仲裁事项是否覆盖本案；是否选定机构；是否或裁或诉；机构是否存在或可确定。
3. 或裁或诉、机构约定不明、未签字主体、格式仲裁条款提示说明不足：效力标 `依据不足`，转介 `assess-forum-and-arbitration`。
4. 书面形式、仲裁意思、事项覆盖、机构可确定且无或裁或诉冲突均获支持时，论坛主位写成仲裁，诉讼入口标负触发。仅在已核验的无效、不覆盖，或依法未在规定节点提出异议并因此视为放弃且事实可回链时，才评估诉讼入口。不得用“双方应诉”概括放弃。任一要件未核验则主位未选定。
5. 合同无效、被撤销或终止，不当然消灭仲裁协议。独立性规则须运行时核验现行《仲裁法》文本，不得凭记忆写条号。

### 4.2 仲裁法版本

《仲裁法》版本、条号和施行日一律运行时核验后写入 `L#`。MCP 效力字段与公布施行日冲突时记录冲突，以有权机关施行日为准；无法核验则仲裁效力、论坛和相关期限字段停止。不得沿用记忆条号，不得把内嵌日期写成已核验。

### 4.3 诉讼入口

无仲裁协议或仲裁协议现有依据不支持其适用时，才把一审诉讼列为可行入口。管辖连结点、专属管辖、协议管辖只列待核，不选定唯一法院。已收到起诉状或仲裁申请：目标停止，转 `defend-first-instance` 或仲裁应诉，不把本任务改写成答辩状。

保全只做红旗（转移财产迹象、紧急减损），不写保全申请。

## 节点 5　期限分类型

每种期间单独一行。禁止用三年诉讼时效去算解除权，也禁止用除斥去挡普通金钱请求。

| 类型 | 规则锚点 | 本任务允许的输出 | 禁止 |
| --- | --- | --- | --- |
| 诉讼时效 | 第 188 条一般为三年；分期履行自最后一期届满（第 189 条）；中断中止须有具体事实 | 起算事件、备选起算、中断候选、条件公式 | 唯一截止日；法院主动审查时效的表述 |
| 解除权除斥 | 第 564、199 条 | 知悉日/催告日并行情景 | 与时效混算；适用中止中断 |
| 质量异议 / 检验期间 | 第 621、622 条；买卖解释第 12 条：二年为最长合理期限且为不变期间 | 约定检验期、合理期限、质保期、出卖人明知例外 | 签收=验收；付款或使用=放弃异议（另有约定除外） |
| 约定催告期 / 自动解除期 | 合同条款 | 条款原文定位、是否已起算 | 把约定期写成法定除斥 |
| 仲裁请求时效／申请期限 | 运行时核验 | 与诉讼时效分列 | 用三年诉讼时效冒充仲裁期限 |
| 仲裁/管辖异议期 | 程序法，运行时核验 | 已进入程序时标红旗 | 在评估里写出异议书截止日期充作法律意见 |

日期冲突、送达不明、知悉日不明：并行情景 + 字段停止，不选对用户最有利的一天。

## 节点 6　金额区间与第 585 条接口

本任务只建区间和接口，不替代 `calculate-damages`。

1. 分项：约定违约金、迟延违约金、损失（直接 / 可得利益）、定金、已付款、质保金、减价。未知不写零，不输出唯一必得总额。
2. 约定数字不是必得金额。增减须经当事人请求，由法院或仲裁机构调整（第 585 条）。
3. “过分高于”对照的是**违约造成的损失**，不是合同总价。合同编通则解释第 65 条：超过损失百分之三十一般可认定过分高于；恶意违约方请求减少一般不予支持。实务检索若出现“不超过合同标的 30%”，记为噪声，不得写入结论。
4. 不得以“合同约定不得调整”排除调整（解释第 64 条）。反诉或抗辩提出调整，依法应予审查。
5. 买卖合同因违约解除后，守约方可主张继续适用违约金条款，但仍受第 585 条第二款约束（买卖解释第 20 条，2020 修正）。结算清理条款不因终止当然失效（第 567 条）。
6. 损失受可预见（第 584 条、解释第 63 条）、减损（第 591 条）、双方违约与过错相抵（第 592 条）、因违约获益扣减约束。不得合成一笔“应赔”。
7. 迟延违约金支付后，债务仍可能要继续履行（第 585 条第三款）。继续履行是否可能（第 580 条）单列非金钱后果，不折算进违约金。

参数不足：只列已知参数、未知参数和专项测算接口。

## 程序与期限表

程序动作记录机关、案号、文书、作出、收到、送达、效力。期限每行只对应一种期间类型和一个起算事件。关键日期冲突则并行情景。

## 金额区间表

固定列：项目、性质、期间、参数、来源、已付、未知、互斥／抵扣、范围、专项测算接口。参数不足不输出唯一总额。

## 证据与下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。

下一步按期限灭失、易失证据、改变请求抗辩、可逆性排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。

解除通知、起诉、应诉、精算、完整证据卷只写转介条件和最小交接，不在本方法生成那些终稿。禁止指导伪造、隐匿、威胁或违法取证。
