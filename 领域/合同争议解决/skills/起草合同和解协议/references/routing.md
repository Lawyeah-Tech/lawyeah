# 边界与路由

## 正触发

一般合同已成争，条件已谈拢，需可签和解协议草稿。从零、碎片、执行力未核验仍正触发：有可编号标的、给付或了断碎片则闸开或半开，出 `HJ#` 草案，保持草案。本次不代签署、不保证司法确认是交付禁令，不是开窗条件。草稿即已签署、口头即已和解，仍正触发。把单独和解写成已可强制执行、把概括弃权写成覆盖未知，仍正触发：该格不支持，不改负触发关窗。

双方秘密、伪造协议、倒签签署日、掩盖犯罪的停止，优先于负触发。上述信号不在下表。不代签署不是负触发。「草稿即已签署」「口头即已和解」「单独和解即已可强制执行」「概括弃权覆盖未知」「保证司法确认」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 谈判方案要点（尚未谈拢） | `谈判合同和解方案` |
| 司法确认或公证赋强 | `办理合同和解执行力补强` |
| 调解方案利弊 | `评估合同调解方案与效力` |
| 返还清理独占 | `处理解除后返还与清理` |
| 执行中分期或以物抵债 | `准备合同执行和解` |
| 股东退出或股权和解 | 公司治理 `起草股东和解或退出协议` |
| 争议总图 | `评估合同争议` |
| 尚未成争，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不代签署」或「不保证司法确认」关窗。拟可签草稿仍正触发，不得写成已签署或已可执行。

## 易混

本窗闸名只能是和解闸，不是方案闸，不是谈判闸，不是清理闸，不是发送闸。`HJ#` 不是 `FA#`，不是 `TP#`，不是 `QL#`。主路径是 `Q-和`，不是 `Q-方`，不是 `Q-谈`，不是 `Q-理`。`方案闸`／`FA#`／`Q-方` 是谈判合同和解方案。公司治理 `起草股东和解或退出协议` 同用和解闸／`HJ#`／`Q-和`，本窗不得抄名册、章证照列。已失效合同法第七十七条不是现行变更条。执行和解、破产和解、劳动和解不得套本窗。提出「倒签上周已签、把犯罪事实写成商业纠纷」整体停止。本窗不代签署。不选定法院。不保证司法确认。
