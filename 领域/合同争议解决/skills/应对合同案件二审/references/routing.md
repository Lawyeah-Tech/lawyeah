# 边界与路由

## 正触发

一般合同被上诉人已收到上诉状副本、二审应诉或答辩通知或等价被上诉碎片，需要二审答辩草稿。从零、碎片、送达或范围未核验仍正触发：有可编号上诉状副本、二审应诉或答辩通知、案号或一审裁判加对方已上诉碎片则闸开或半开，出 `BS#` 草案，保持草案。本次不代提交、不出上诉状终稿是交付禁令，不是开窗条件。草稿即已答辩、答辩即独立上诉，仍正触发。把不答辩写成当然败诉、把未上诉部分写成当然全改、把已生效写成仍可普通二审答辩，仍正触发：该格不支持，不改负触发关窗。

双方秘密、用上诉人未授权秘密、伪造答辩、隐匿证据的停止，优先于负触发。上述信号不在下表。不代提交不是负触发。「草稿即已答辩」「已读即已送达」「不答辩即败诉」「答辩即独立上诉」「过期仍要可提交有效终稿」「保证维持」不在下表。

## 易混

本窗闸名只能是应上闸，不是上诉闸，不是答辩闸，不是应裁闸，不是开庭闸，不是应诉闸，不是应对闸，不是被上闸，不是二审闸。`BS#` 不是 `HS#`，不是 `SS#`，不是 `DB#`，不是 `YC#`，不是 `KT#`，不是 `YS#`，不是 `ES#`。主路径是 `Q-应上`，不是 `Q-上`，不是 `Q-辩`，不是 `Q-应`，不是 `Q-开庭`。`上诉闸`／`HS#`／`Q-上` 是提起合同案件上诉。`答辩闸`／`DB#`／`Q-辩` 是应对合同纠纷一审。`开庭闸`／`KT#`／`Q-开庭` 是准备合同案件庭审。`应裁闸`／`YC#`／`Q-应裁` 是应对合同仲裁。`YS#` 是合规监测行。`ES#` 是工程执行和解要点。1991 年第一百七十四条不是二审答辩。2017 年第一百六十七条须核对应现行第一百七十四条。第一百七十一条十五日／十日不是本窗答辩截止。刑诉全面审查不是民事二审范围。提出「回证日期改到上周、对账单先藏起来」整体停止。本窗不代提交。不选定法院。不写发送版。不保证维持。
