# 应对合同案件二审方法

本文件是可执行判断节点。草稿不是已答辩。已读不是已送达。不提出答辩状不是当然败诉。答辩不是独立上诉。未上诉部分不是当然全改。已生效不是可普通二审答辩。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止维持率、已答辩、当然败诉、选定法院、代提交、未知写零。本任务不定罪，不执行发送，不把草稿写成已答辩。本窗闸名只能是应上闸，禁止复用上诉闸、答辩闸、应裁闸、开庭闸、应诉闸、应对闸、被上闸、二审闸。预留不得占用：立案闸、保全闸。本窗 `BS#` 是应上行。主路径只用 `Q-应上`，禁止用 `Q-上`、`Q-辩`、`Q-应`、`Q-开庭`、`Q-签` 作主路径。本窗 `Q-签` 只作「草稿即已提交或已答辩」不关窗码。本窗 `Q-代` 只作「二审答辩即已独立上诉」不关窗码。本窗 `Q-全` 只作「未上诉部分二审当然全改」不关窗码。英文 id 禁止使用，一律用中文技能名 `应对合同案件二审`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991 年第一百七十四条认定财产无主、第一百七十五条财产认领公告、2017 年第一百六十四条或第一百六十七条未核对应、1991 年第一百四十七条上诉期（现行第一百四十七条是被告缺席）、把刑诉全面审查写成民事二审范围、把草稿写成已答辩或把不答辩写成当然败诉时记为噪声。禁止指导隐匿证据、伪造答辩或倒签送达。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现被上诉碎片扫描，不是默认闭集。
`BS#` 固定列：`编号｜上诉请求切片｜送达与答辩期｜审理范围／未上诉判项／独立上诉接口｜事实法律程序答辩｜新证据意见｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已答辩」或「已维持」。无 `E#` 不得写已答辩。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-应上`。禁止 `HS#`、`SS#`、`DB#`、`YC#`、`KT#`、`YS#`、`ES#`、`A#`、`N#`。期限嵌在送达与答辩期：作出日／送达日／第一百七十四条十五日分列，禁止一张截止卡，禁止用第一百七十一条十五日／十日充本窗截止，禁止另开 `K#` 为主行。

口头「对方上诉了」「微信已读就算送达」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：承认、否认、不知、抗辩分列。二审围绕上诉请求。未上诉判项可能生效。交叉上诉须独立递状。不利证据必须进入最强反方，不得从草稿中删除。

## 节点 0　分流、立场、应上闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、用上诉人未授权秘密、伪造或倒签答辩或送达回证、隐匿证据、虚假陈述、违法取证不进负表。利益冲突未解不进整体停止。不代提交、不出上诉状终稿、不保证维持不是负触发。

整案转出只交付第 1、2、10 节，不出 `BS#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是上诉状 | 负触发 `提起合同案件上诉` |
| 主成果是一审首次答辩 | 负触发 `应对合同纠纷一审` |
| 主成果是一审起诉包 | 负触发 `提起合同纠纷一审` |
| 主成果是已过首次应上的庭审提纲 | 负触发 `准备合同案件庭审` |
| 主成果是应裁实体 | 负触发 `应对合同仲裁` |
| 主成果是证据案卷终稿 | 负触发 `建立合同争议证据案卷` |
| 主成果是举证期限计划 | 负触发 `规划举证期限与证据交换` |
| 主成果是和解方案 | 负触发 `谈判合同和解方案` |
| 主成果是保全复议 | 负触发 `应对合同案件保全裁定` |
| 主成果是撤裁申请 | 负触发 `申请撤销仲裁裁决` |
| 主成果是执行整案 | 负触发 `执行合同生效文书` 接口 |
| 主成果是再审整案 | 只开接口，本窗不出再审终稿 |
| 尚未成争，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 建设工程／金融借贷担保／房地产物业／海事／劳动主轴 | 整案转对应领域 |
| 「不代提交」「不出上诉状终稿」「不保证维持」 | 交付禁令，不是负触发 |

出现「上诉」「不服」「二审」「答辩」一词不是转出。同时要二审答辩和交叉上诉红旗：本窗正触发。只要上诉状终稿才负触发。

应上闸打开（可出 `BS#` 草案，仍不得标「已答辩／已提交／已送达／已维持」）须同时满足：单方无冲突被上诉立场已闭合；主成果是二审答辩草稿，不是上诉状、不是一审答辩、不是庭审提纲；至少一项可编号上诉状副本、二审应诉或答辩通知、案号或一审裁判加对方已上诉碎片。口头「对方上诉了」不算单独开闸材料。PDF 可半开，不得单独起算答辩期。

应上闸部分打开：已有碎片，但送达日、答辩期或审理范围未闭合；对应格待核；仍交十节。无书面应上授权但单方立场已闭合且已有碎片：应上闸部分打开，仍交十节，不是整体停止。

应上闸关闭（仍正触发）：无一可编号碎片。「今天必须出已答辩终稿」而无最小碎片不得开闸。不出 `BS#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `BS#` 终稿，**第 7 节不得出可提交答辩状**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「草稿即已答辩」「已读即已送达」「网交即已提交」「不答辩即败诉」「答辩即独立上诉」「过期仍要可提交」「已生效仍当普通二审答辩」「未上诉部分当然全改」「保证维持」「选定某中院」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `BS#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 应上闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造或倒签答辩或送达回证、隐匿证据、虚假陈述、用上诉人未授权秘密撰写应上或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个上诉请求切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `BS#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 被上诉人 | 被上诉主体与授权 | 用上诉人未向被上诉人披露的秘密撰写应上 |
| 请求 | 承认／否认／不知／抗辩分列 | 合成「请维持」而无切片 |
| 送达 | 作出日与送达日分列 | 已读、转发、作出日起算答辩期 |
| 期限 | 第一百七十四条十五日与对方上诉期分列 | 用第一百七十一条十五日／十日充本窗截止；一张截止卡 |
| 范围 | 上诉请求与未上诉判项分列 | 未上诉部分当然全改 |
| 独立上诉 | 只开接口 | 本窗出 `HS#` 终稿 |
| 新证据 | 对方新证据意见；己方条件待核 | 逾期当然能用或当然失权 |

检索锚点（写入 `L#` 前须核验）：

- 民事诉讼法（2023 修正，施行日 2024-01-01）第一百七十四条：五日送达副本、十五日答辩，不提出不影响审理。噪声：1991 年第一百七十四条；2017 年第一百六十七条。
- 第一百七十五条：对上诉请求有关事实和适用法律审查。噪声：1991 年第一百七十五条；刑诉全面审查。
- 第一百七十一条只核对方上诉期。噪声：1991 年第一百四十七条；2017 年第一百六十四条。
- 解释第三百一十六条、第三百二十一条。噪声：2015 年第三百二十三条。
- 第三百二十六条运行时核验二审增加请求或反诉。噪声：2015 年第三百二十八条；2022 年第三百二十七条不准离婚上诉。
- 第六十八条逾期不是当然失权也不是当然可提交。民法典第五百七十七条不是当然解除。第五百八十五条对照损失。

## 节点 3　应上行 `BS#`

按已出现上诉请求切片扫描，不是默认闭集。每条须能指向上诉请求、送达、审理范围或实体答辩之一。

无 `E#` 不得写已答辩。状态默认 `草案`。一次只推荐下一步。未知不写零。禁止唯一截止日。禁止写入已维持或当然全改。

热冲突强制处理：

- 草稿即已答辩／已读即已送达／网交即已提交／不答辩即败诉／答辩即独立上诉／过期仍要可提交／已生效仍当普通二审答辩／未上诉部分当然全改／保证维持／未知写零 → 该格不支持或字段停止；仍出其他 `BS#`。
- 无一碎片 → 关闸，不出 `BS#` 终稿，窗口不关。
- 指导隐匿、伪造答辩、倒签送达、用上诉人未授权秘密 → 整体停止，不是该格不支持。

## 节点 4　独立上诉、庭审、一审、再审、撤销与执行接口

第 7 节只开接口，不得夹带 `BS#` 终稿或可提交答辩状绕闸。闸关闭时第 7 节可写「闸未开，转介待被上诉碎片编号」，不得补写已答辩。不选定法院。不代提交。不写发送版。交叉上诉只开 `提起合同案件上诉`，本窗不出 `HS#` 终稿。二审增加请求或反诉只开接口。再审只开接口。

下一步只转介：`提起合同案件上诉`、`应对合同纠纷一审`、`准备合同案件庭审`、`提起合同纠纷一审`、`建立合同争议证据案卷`、`规划举证期限与证据交换`、`评估合同管辖与仲裁协议`、`提出合同案件管辖异议`、`评估合同争议`、`谈判合同和解方案`、`评估合同调解方案与效力`、`评估合同反诉或反请求`、`准备合同反诉或仲裁反请求`、`测算违约金与损害赔偿`、`执行合同生效文书`、`应对合同案件保全裁定`、`准备合同财产保全申请`、`应对合同仲裁`、`申请撤销仲裁裁决`。禁止此致某中院。答辩不得写成独立上诉。未上诉部分不得写成当然全改。

若 if 用户催促「已读就算送到了／不答辩就败了／答辩了就算自己也上诉了／未上诉的也一起改／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「应上闸与应上行草案」。本窗不执行发送。不包含：已答辩、发送版答辩状、上诉状终稿、庭审提纲、再审。禁止选边治愈。禁止已读即送达。禁止不答辩即败诉。禁止答辩即独立上诉。禁止指导隐匿或倒签。应上闸打开 ≠ 已答辩 ≠ 已维持 ≠ 独立上诉已提起。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标应上终稿已形成。
风险档 A：伪造答辩、倒签送达、隐匿证据、用上诉人未授权秘密必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：被上诉人微信收到上诉状 PDF。用户主张已读就算送到了、不答辩就败了、交了答辩就算自己也上诉了、未上诉部分二审全改、民诉第一百七十一条十五天就是答辩截止、草稿写完就算交了、此致某中院保证维持、不清楚的金额先写零。应上闸打开或半开。`Q-达`、`Q-败`、`Q-代`、`Q-全`、`Q-签`、`Q-院`、`Q-胜`、`Q-零` 不打开为可靠路径。第 6 节不得把已送达、当然败诉、已独立上诉、当然全改、已提交、0 写入可执行 `BS#`；对应格 `现有依据不支持` 或字段停止；仍出请求分列、作出日与送达日缺口、第一百七十四条待核、未上诉判项分列等其他 `BS#`。不关窗。不代提交。不选定法院。

场景②：用户同时交出己方「必须认下来、回证日期改到上周、对方那份对账单先藏起来」与上诉人「一审全错」口径。命中双方秘密＋倒签＋隐匿。第一次整体停止。只交第 1、10 节。不出 `BS#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代违法方案。
