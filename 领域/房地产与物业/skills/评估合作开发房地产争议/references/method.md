# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然结果或唯一必得总额。未知金额不写零。建设工程施工、分包、优先受偿、造价鉴定、工期索赔或实际施工人主轴整案转出。一般买卖、服务、承揽、动产租赁等非不动产主轴只分流到合同争议，不把本任务规则写入一般合同结论。

`search_law` 返回已失效《合同法》《物权法》及其解释，或 2020 年已删除的商品房解释原第 7、8、9、14 条时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。



至少分列：`Q-合` 合作开发继续履行或分配；`Q-借` 名为合作实为借贷返还；`Q-租` 名为合作实为租赁；`Q-资` 资质障碍；`Q-房` 面积或房屋分配；`Q-损` 赔偿。

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定、工期索赔、实际施工人 | 建设工程领域 |
| 一般买卖、服务、承揽、动产租赁等非不动产主轴 | 合同争议解决领域 |
| 金融借贷、保证、抵押实现、保理、融资租赁主轴 | 金融借贷担保领域 |
| 婚姻析产、继承过户、夫妻房产归属 | 婚家领域 |
| 征收决定、补偿决定复议诉讼 | 行政争议领域 |
| 矿业权、农地承包、能源环境监管 | 环境能源领域 |
| 劳动关系、工资、工伤 | 劳动领域 |
| 尚未成争，只要改合同、出稿或做签前审查 | 审查起草领域（本窗搁置，只说明不实施） |
| 刑事定罪、控告、辩护 | 刑事领域 |

C 端相邻只分流不回改。未成争只要改合同、出稿或做签前审查：审查起草领域本窗搁置，只说明不实施。

若 `search_law` 不可用：继续整理主体、文本、程序文书和问题清单；依赖未核验规则的法律结论、期限、效力、管辖选定字段停止，不拒绝执行。


## 节点 1　定性三叉

1. 若双方共同投资、共享利润、共担风险，且分配房屋或利润以项目经营结果为条件：主位可评估 `Q-合`。
2. 若一方只提供资金、不承担经营风险、收取固定回报或固定面积且与盈亏无关：主位评估 `Q-借`，不得因合同标题是“合作开发”而写成合作。
3. 若一方提供土地或房屋供对方建设经营、收取固定租金或管理费：评估 `Q-租` 或转租赁专项。
4. 若争议材料主要是施工进度款、签证、竣工结算：整案转建设工程。
5. 若主轴是还款、保证、抵押物处置：整案转金融。

## 节点 2　资质与主体

1. 若出地方或项目公司不具备房地产开发经营资质，而相对方请求分配房屋：分配请求不得当然写成现有依据支持；运行时核验解释现行条文后落判断。
2. 若实际施工人以合作开发为名主张房屋：先转工程领域的实际施工人规则，不在本任务认定工程价款。
3. 项目公司股东会决议、股权转让与合作合同冲突时并列，不审理公司治理内部决议本身作为终局。

## 节点 3　出资与保底

1. 把现金、土地估价、垫资建安、管理输出资分项，未评估的土地作价不得写成已核实金额。
2. 保底条款、最低回报、逾期翻倍：作为借贷定性的支持事实，同时标效力待核，不得写成合法利息必得。
3. 分配条件（取得预售许可、竣工、可售面积确认）未成就：`Q-房` 依据不足。

## 节点 4　土地、查封与施工交叉

1. 土地仍登记在出地方名下：过户义务与分配请求分列。
2. 在建工程或土地被查封：保全或执行障碍列入最强反方。
3. 总包主张建设工程价款优先受偿：本任务只标记冲突，整段工程请求转建设工程，不在合作利润里抵销未审工程款。

## 节点 5　输出

`Q-合` 与 `Q-借` 不得同时写成均已成立。用户只要改合作协议：目标停止。用户要起诉：转 `file-first-instance` 并移交定性结论。


## 通用输出纪律

1. 若立场或授权不明，或同时掌握双方秘密未解：整体停止策略输出。
2. 若用户坚持伪造、倒签、隐匿查封抵押、暴力清场、停水停电催费或违法取证：整体停止。
3. 若主目标已变为相邻原子的成果：目标停止并分流，不代做。
4. 判断结论必须带回链；不得用失效《合同法》填空。
