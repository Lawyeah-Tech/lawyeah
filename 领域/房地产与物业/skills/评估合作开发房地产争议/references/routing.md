# 边界与路由

## 正触发

联合建房、以地出资、利润或房屋分配，或名为合作实为借贷已成争。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 施工价款工期质量 | 建设工程领域 |
| 纯借款或抵押权实现 | 金融借贷担保领域 |
| 土地使用权一地数转 | `评估土地使用权取得与转让争议` |
| 改合作协议 | 审查起草（本窗搁置） |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

合同标题是合作开发不等于共担风险。固定回报优先按借贷评估。施工结算不能当合作利润。
