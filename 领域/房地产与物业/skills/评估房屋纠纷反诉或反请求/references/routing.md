# 边界与路由

## 正触发

被告或被申请人拟反诉或反请求，需要决策评估。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 反诉状终稿 | `准备房屋纠纷反诉或仲裁反请求` |
| 本诉答辩 | `应对房地产与物业纠纷一审` 或仲裁应诉 |
| 主动起诉 | `提起房地产与物业纠纷一审` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

有牵连才能反诉。反诉逃不掉仲裁协议。评估不是状纸。
