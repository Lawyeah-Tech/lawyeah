# 评估物业费与物业服务争议

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，判断物业费请求或质价不符抗辩能否成立：前期合同约束力、催告、违规收费、期间金额区间和下一步。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：物业服务合同或前期物业安排已成争，业主或物业服务人需要请求／抗辩判断和金额区间。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要发送版催缴函；
- 要求设计停水、停电、停电梯催费；
- 只要业主大会决议撤销之诉终稿；
- 施工质量、工程造价主轴；
- 一般服务合同非物业。

C 端物业争议只分流。本任务不生成停水电方案，不保证胜诉。

## 建立坐标

确认：业主或物业服务人立场；前期合同或业主大会选聘合同；收费依据和政府指导价；催告记录；服务瑕疵事实；使用人还是业主。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。口头转述和“已读”不写成已受理、已送达或期限已起算。

## 来源和判断状态

编号：`S#`；`D#`；`A#`；`R#`；`C#`；`L#`；`I#`；`G#`；`Q#`；`M#` 期间金额；`V#`；`E#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典第 939、944、946、950 条及物业服务解释；工具不可用时继续期间和事实表；请求成立与否、催告闭合字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 主体与合同约束力

前期物业合同及业主大会选聘合同对业主有约束力（第 939 条）。未实际入住不是拒付已提供服务期间物业费的充分理由。

### 2. 催告闸与禁止手段

物业服务人起诉或申请仲裁前应催告合理期限（第 944 条第二款）。不得采取停止供电、供水、供热、供燃气等方式催交。

### 3. 请求与抗辩分列

`Q-费` 物业费；`Q-滞` 滞纳金（受第 585 条调整）；`Q-违` 违规收费返还；`Q-减` 质价不符扣减；`Q-退` 预收未服务期间退还。质价不符须对应期间和事实，不得写成全部免除。

### 4. 期间、时效与使用人

分期间测算。使用人实施违规行为可参照业主。诉讼时效单独一行，不与催告期混算。

### 5. 解聘与后合同

共同决定解聘须提前六十日书面通知（第 946 条）。合同终止后至新物业接管前，原物业可请求期间物业费（第 950 条）。

## 停止与安全

- `整体停止`：立场不明；用户坚持停水电催费或伪造服务记录。
- `字段停止`：收费依据、催告到达、指导价规则未核验。
- `目标停止`：主目标变为催缴函终稿、决议撤销诉状或停水电方案。
