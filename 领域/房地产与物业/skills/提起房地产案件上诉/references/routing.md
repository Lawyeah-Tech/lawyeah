# 边界与路由

## 正触发

不服尚未生效的房地产或物业一审裁判，要上诉。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 已生效再审 | 另案，本任务负触发 |
| 重做一审 | 拒绝 |
| 仲裁裁决 | 撤销或不予执行路径，非上诉 |
| 一审起诉 | `提起房地产与物业纠纷一审` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

上诉有法定期限。不能把一审没要的请求整棵重栽。仲裁走不上上诉通道。
