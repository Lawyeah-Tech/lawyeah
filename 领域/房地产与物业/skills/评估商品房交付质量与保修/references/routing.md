# 边界与路由

## 正触发

商品房交付质量、保修或严重影响居住，买受方要修复或解除分流。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 施工质量或造价 | 建设工程领域 |
| C 端质量退房 | 大众专项，只分流 |
| 人身伤害 | 人身损害与侵权领域 |
| 发解除通知 | `准备房屋买卖解除或退房通知` |
| 交房后隐蔽瑕疵细项且已过户入住 | `评估交房后隐蔽瑕疵` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

保修期内不修不等于当然解除。买卖保修与施工质量索赔是两条轨道。
