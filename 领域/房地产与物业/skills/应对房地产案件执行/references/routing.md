# 边界与路由

## 正触发

被执行人收到房地产或物业案件执行，要适格异议或履行安排。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 隐匿转移房产 | 整体停止 |
| 重审实体 | 上诉或再审另案 |
| 案外人异议 | P2 unavailable |
| 权利人申请执行 | `执行房地产生效文书` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

执行异议不是二审。唯一住房不是绝对豁免。禁止任何转移隐匿方案。
