# 边界与路由

## 正触发

补偿协议履行、安置房交付或补偿款已成民事或协议履行之争。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 征收或补偿决定复议诉讼 | 行政争议领域 |
| C 端拆迁材料 | 大众专项，只分流 |
| 安置房权属细项 | `评估安置房交付与权属` |
| 征收合法性 | 行政争议领域 |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

有协议不等于能在民事庭告征收决定。补偿决定与补偿协议是两条救济。C 端包不能替代论坛判断。
