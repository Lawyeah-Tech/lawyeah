# 边界与路由

## 正触发

中介隐瞒重要事实或争居间报酬。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 房屋质量本体 | 质量专项 |
| 存量房总图 | `评估存量房买卖争议` |
| 改居间合同 | 审查起草（本窗搁置） |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

成交了不等于中介无责。中介有责不等于房屋质量当然成立。跳单不是当然免佣也不是当然全赔。
