# 边界与路由

## 正触发

车位车库、外墙、会所或共有收益归属有争议。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 规划许可诉讼 | 行政争议领域 |
| 物业费 | `评估物业费与物业服务争议` |
| 专有部分改建 | `评估专有部分擅自改建` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

有产权证的车位仍受首先满足业主约束。占共有道路的车位不能当开发商专有。收益扣除须有合理成本。
