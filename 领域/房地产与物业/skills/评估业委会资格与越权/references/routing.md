# 边界与路由

## 正触发

业委会任期、备案、越权签约或起诉资格有争议。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 街道办行政行为 | 行政争议领域 |
| 大会决议内容 | `评估业主大会决议效力` |
| 物业费实体 | `评估物业费与物业服务争议` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

未备案不等于必然无原告资格。任期届满效果必须核验。越权对外和对内不同。
