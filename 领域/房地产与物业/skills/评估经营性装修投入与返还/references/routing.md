# 边界与路由

## 正触发

商铺装修附合、提前解约或到期拆除争费用分担。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 违法建设处罚 | 行政争议领域 |
| 装修工程款 | 建设工程领域 |
| 租赁解除权 | `评估租赁解除权是否成立` |
| 住宅押金 | `评估租金押金与抵扣` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

同意装修不是同意违法扩建。附合补偿看谁违约。工程款另案。
