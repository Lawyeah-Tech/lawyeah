# 边界与路由

## 正触发

物业费或租金金钱明确、无对待给付，债权人要申请支付令。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 有实质服务抗辩 | `提起房地产与物业纠纷一审` 或仲裁 |
| 复杂购房争议 | 起诉或仲裁 |
| 催告未做 | `准备物业费催缴通知` 或租赁催告 |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

支付令怕书面异议。有质价争议就不要包装。异议后不是继续执行。
