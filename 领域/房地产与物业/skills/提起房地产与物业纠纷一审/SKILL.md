# 提起房地产与物业纠纷一审

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的原告立场下，形成可复核、不代提交的一审起诉包：起诉状草稿、分项诉讼请求、管辖连结点、证据目录和保全红旗。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：房地产或物业争议已决定向人民法院提起一审，且无表面有效仲裁阻挡，或阻挡已被可回链证据排除。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 仲裁条款表面有效且未被排除，仍要求直接起诉；
- 已决定申请仲裁；
- 用户实为被告；
- 建设工程价款工期质量整案；
- 只要大众网上立案材料且请求论坛已闭合（可提及 C 端 011，不回改）。

本任务不代提交，不保证受理或胜诉，不写保全申请终稿。

## 建立坐标

确认：原告立场；被告及共同被告（开发商、项目公司、保证人、物业服务人）；仲裁条款及排除证据；不动产坐落；拟提出的请求。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。口头转述和“已读”不写成已受理、已送达或期限已起算。

## 来源和判断状态

编号：`S#`；`D#`；`A#`；`R#`；`C#`；`L#`；`I#`；`G#`；`Q#`；`P#` 诉讼请求；`J#` 管辖；`V#`；`E#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验起诉条件、第 28 条专属、仲裁阻却、确认解除效果；`search_template` 只借起诉状栏目。工具不可用时继续主体和证据目录；请求法律结论、管辖选定和期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 专项分流、起诉决定和仲裁阻却

劳动、工程整案转出。仲裁条款出现时不得直接写应起诉。

### 2. 主体适格与分项请求

继续履行、确认解除、返还购房款、违约金、办证协助、物业费、腾退分列。禁止合成“房产权益”。未事先通知而请求确认解除的，解除时点按起诉状副本送达处理。

### 3. 管辖连结点

先做第 28 条定性。普通商品房买卖、物业费不是当然专属。连结点不足不选定唯一法院。

### 4. 证据目录与保全红旗

证据按待证事实绑定请求。保全只做红旗，不写申请终稿。

### 5. 起诉状草稿与提交核验

只交付草案和核验清单，不代提交。不把本包改写成 C 端 011。

## 停止与安全

- `整体停止`：立场不明；用户坚持虚假陈述或隐瞒仲裁条款。
- `字段停止`：仲裁排除、管辖连结点、送达未核验。
- `目标停止`：主目标变为仲裁申请、保全申请终稿或答辩。

## 交付
