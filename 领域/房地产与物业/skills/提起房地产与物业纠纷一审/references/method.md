# 起诉方法

不得把有效仲裁写成应起诉。不得把普通商品房买卖写成当然专属。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

`search_law` 返回已失效《合同法》《物权法》及其解释，或 2020 年已删除的商品房解释原第 7、8、9、14 条时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

---

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定、工期索赔、实际施工人 | 建设工程领域 |
| 一般买卖、服务、承揽、动产租赁等非不动产主轴 | 合同争议解决领域 |
| 金融借贷、保证、抵押实现、保理、融资租赁主轴 | 金融借贷担保领域 |

| 征收决定、补偿决定复议诉讼 | 行政争议领域 |
| 矿业权、农地承包、能源环境监管 | 环境能源领域 |
| 劳动关系、工资、工伤 | 劳动领域 |

## 节点 1　起诉决定和仲裁闸

表面有效仲裁未排除 → 负触发。排除必须有可回链证据（无效、不覆盖、未在规定节点提出异议并视为放弃等，规则运行时核验）。

---

## 节点 2　请求

`P-履` 交房／过户／协助登记；`P-解` 确认解除；`P-款` 返还购房款及利息；`P-金` 违约金；`P-证` 协助办证；`P-物` 物业费；`P-腾` 腾退。确认解除未事先通知：不得写起诉当日已解除。已删一倍惩罚不得作为独立诉讼请求必得项。

物业费请求须有催告闭合接口（第 944 条）。

---

## 节点 3　管辖

适用 `assess-forum-and-arbitration` 同一套第 28 条闸。协议管辖不得违反专属和级别管辖。材料不足：列连结点，不选定唯一法院。

---

## 节点 4　证据与保全

证据目录绑定 `P#`。房屋可能被二次出售或预售资金转移：保全红旗。不写保全申请终稿。

---

## 节点 5　草稿

按起诉状法定事项组织。不代提交。已有案号或立案通知：停止生成起诉入口材料。
