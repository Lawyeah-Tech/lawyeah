# 边界与路由

## 正触发

已被起诉，需在法定期限内提出管辖异议。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 异议期已过 | 停止终稿，转 `应对房地产与物业纠纷一审` |
| 仲裁协议异议 | `准备房屋仲裁协议异议材料` |
| 原告评估管辖 | `评估不动产管辖与仲裁协议` |
| 实体答辩 | `应对房地产与物业纠纷一审` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

管辖异议与仲裁协议异议不同。楼盘所在地不是商品房买卖的当然专属。过期不能靠未开庭补救。
