# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然结果或唯一必得总额。未知金额不写零。建设工程施工、分包、优先受偿、造价鉴定、工期索赔或实际施工人主轴整案转出。一般买卖、服务、承揽、动产租赁等非不动产主轴只分流到合同争议，不把本任务规则写入一般合同结论。

`search_law` 返回已失效《合同法》《物权法》及其解释，或 2020 年已删除的商品房解释原第 7、8、9、14 条时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。



分列：`Q-期` 异议期；`Q-专` 专属；`Q-协` 协议管辖；`Q-地` 地域连结点；`Q-级` 级别管辖。

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定、工期索赔、实际施工人 | 建设工程领域 |
| 一般买卖、服务、承揽、动产租赁等非不动产主轴 | 合同争议解决领域 |
| 金融借贷、保证、抵押实现、保理、融资租赁主轴 | 金融借贷担保领域 |
| 婚姻析产、继承过户、夫妻房产归属 | 婚家领域 |
| 征收决定、补偿决定复议诉讼 | 行政争议领域 |
| 矿业权、农地承包、能源环境监管 | 环境能源领域 |
| 劳动关系、工资、工伤 | 劳动领域 |
| 尚未成争，只要改合同、出稿或做签前审查 | 审查起草领域（本窗搁置，只说明不实施） |
| 刑事定罪、控告、辩护 | 刑事领域 |


本任务额外分流：

| 信号 | 转出 |
| --- | --- |
| 仲裁协议效力或不适用 | `object-to-arbitration-agreement` |
| 原告选择管辖或评估论坛 | `assess-forum-and-arbitration` |


C 端相邻只分流不回改。未成争只要改合同、出稿或做签前审查：审查起草领域本窗搁置，只说明不实施。

若 `search_law` 不可用：继续整理主体、文本、程序文书和问题清单；依赖未核验规则的法律结论、期限、效力、管辖选定字段停止，不拒绝执行。


## 节点 1　期限闸

1. 逐份起诉状记录：作出日、送达日、送达方式、签收人。电子送达须有约定或同意的证据。
2. 若无法确定送达日：异议期字段停止，不得按立案日起算。
3. 若已超过法定异议期：负触发，停止终稿，转 `defend-first-instance`。
4. 若已提出实体答辩或反诉：应诉管辖红旗，异议成功依据不足，须明示风险后才能出草稿。
5. 口头“还没开庭所以还能提异议”不能代替法定期限。

## 节点 2　专属闸

1. 若诉讼标的是房屋所有权确认、共有分割、相邻关系：不动产所在地专属可评估。
2. 若是房屋租赁：按不动产纠纷确定管辖，不是一般合同任意选择。
3. 若是普通商品房买卖金钱给付、逾期交房、办证、退房：不得写成当然由楼盘所在地专属。
4. 若是物业服务合同欠费：不得写成当然专属。
5. 建设工程施工合同管辖整案转建设工程，本任务不代写。

## 节点 3　连结点

协议管辖须有书面且不违反专属和级别。连结点材料不足：不选定“唯一正确法院”，只列原告选择的缺陷和被告主张的连结点。

## 节点 4　异议书

正文结构：当事人、案号、异议请求、事实与理由、证据目录。不写实体胜诉理由。不保证异议成立或移送。

## 节点 5　转介

仲裁条款表面有效：管辖异议不能替代仲裁协议异议。用户实为原告：负触发。


## 通用输出纪律

1. 若立场或授权不明，或同时掌握双方秘密未解：整体停止策略输出。
2. 若用户坚持伪造、倒签、隐匿查封抵押、暴力清场、停水停电催费或违法取证：整体停止。
3. 若主目标已变为相邻原子的成果：目标停止并分流，不代做。
4. 判断结论必须带回链；不得用失效《合同法》填空。
