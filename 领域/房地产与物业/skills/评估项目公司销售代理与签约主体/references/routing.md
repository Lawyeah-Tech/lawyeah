# 边界与路由

## 正触发

项目公司、销售代理、印章或无权代理导致签约效力争议。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 公司决议效力主轴 | 公司治理与股权领域 |
| 预售许可有无 | `评估预售许可与销售资格` |
| 施工总包签约 | 建设工程领域 |
| 总体评估 | `评估房地产与物业争议` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

在售楼处签字不等于表见代理当然成立。收款也不当然追认全部越权条款。
