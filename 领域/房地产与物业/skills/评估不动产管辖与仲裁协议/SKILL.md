# 评估管辖与仲裁协议

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成论坛评估：专属管辖是否真正适用、仲裁协议是否绊住诉讼、协议管辖与法定连结点、异议期限待核。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：房地产或物业争议需要选择法院或仲裁，或对方已提出管辖／仲裁异议，用户需要效力与连结点判断而不是立案包。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未成争，只要改管辖或仲裁条款（审查起草领域，本窗搁置）；
- 只要完整起诉状或仲裁申请；
- 异议期已过且唯一目标是赶写异议书；
- 建设工程施工合同专属整案、劳动仲裁、海事专属；
- 普通商品房买卖被用户要求写成“当然专属”且拒绝分列。

本任务不代写完整立案包，不保证受理，不把普通商品房买卖或物业服务合同写成当然专属。

## 建立坐标

确认：使用者与授权；单方立场；合同及补充协议中的管辖／仲裁条款；不动产坐落；登记与否；争议类型（物权确认／租赁／商品房买卖／物业费／开发合作）；是否已起诉或申请仲裁。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。口头转述和“已读”不写成已受理、已送达或期限已起算。

## 来源和判断状态

编号：`S#`；`D#`；`A#`；`R#`；`C#` 条款定位；`L#`；`I#`；`G#`；`Q#` 论坛假设；`J#` 连结点；`V#`；`E#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民诉法第 34 条、民诉法解释第 28 条、仲裁法现行文本；工具不可用时继续条款对照和连结点事实；效力、选定法院和期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 专项分流、争议定性与专属闸

先定性：物权确认／分割／相邻、房屋租赁、政策性房屋买卖、普通商品房买卖、物业服务、开发合作。只有解释第 28 条列明类型才按不动产纠纷确定管辖。

### 2. 仲裁协议文本

书面形式、仲裁意思、事项覆盖、机构是否选定分列。或裁或诉、机构不明标依据不足。合同无效不当然消灭仲裁协议。

### 3. 诉讼连结点

分列被告住所地、合同履行地、协议管辖、不动产所在地、级别管辖。材料不足不选定唯一法院。协议管辖不得违反专属和级别管辖。

### 4. 异议期限与应诉管辖

已进入程序时标红旗。口头转述不得起算异议期。未提异议并应诉答辩可能视为接受管辖，但不自动消灭仲裁争点。

### 5. 主位论坛与转介

主位只在条件闭合后选定。表面有效仲裁未排除则诉讼入口负触发。需要立案包转起诉或仲裁申请原子。

## 停止与安全

- `整体停止`：立场不明；用户坚持伪造管辖连结点或隐瞒仲裁条款。
- `字段停止`：仲裁法文本、专属规则、送达日未核验。
- `目标停止`：主目标变为立案包或过期异议书终稿。
