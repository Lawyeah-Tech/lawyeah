# 评估方法

每个会改变主位论坛、效力或异议期限结论的节点必须回链来源。不得输出唯一有管辖权法院，或在表面有效仲裁下写“应起诉”。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

`search_law` 返回已失效《合同法》《物权法》及其解释，或 2020 年已删除的商品房解释原第 7、8、9、14 条时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

《仲裁法》版本、条号和施行日一律运行时核验后写入 `L#`。

## Q# 论坛假设

固定列：`编号｜论坛类型｜提出方｜相对方｜文本定位｜成立条件｜支持事实｜不利事实｜控制方｜最强反方｜主备位｜判断｜待核`。

至少分列：`Q-专` 专属管辖；`Q-仲` 仲裁；`Q-诉` 一审诉讼；`Q-协管` 协议管辖；`Q-法定` 法定地域／级别；`Q-异` 异议。

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定、工期索赔、实际施工人 | 建设工程领域 |
| 一般买卖、服务、承揽、动产租赁等非不动产主轴 | 合同争议解决领域 |
| 金融借贷、保证、抵押实现、保理、融资租赁主轴 | 金融借贷担保领域 |
| 婚姻析产、继承过户、夫妻房产归属 | 婚家领域 |
| 征收决定、补偿决定复议诉讼 | 行政争议领域 |
| 矿业权、农地承包、能源环境监管 | 环境能源领域 |
| 劳动关系、工资、工伤 | 劳动领域 |
| 尚未成争，只要改合同、出稿或做签前审查 | 审查起草领域（本窗搁置，只说明不实施） |

劳动争议走劳动仲裁，不走本任务。建设工程施工合同按不动产纠纷确定管辖，但整案转建设工程领域。

## 节点 1　争议定性与第 28 条闸

1. 先问诉讼标的是什么，而不是房屋在哪。
2. 若：物权归属确认、共有分割、相邻关系 → `Q-专` 现有依据支持不动产所在地专属。
3. 若：房屋租赁合同纠纷 → 按不动产纠纷确定管辖。
4. 若：政策性房屋买卖 → 按不动产纠纷确定管辖。
5. 若：普通商品房买卖逾期交房、办证、返还购房款 → **不得**写成当然专属；走一般合同地域管辖。
6. 若：物业服务合同欠费或服务品质 → **不得**写成当然专属。
7. 若：开发合作利润分配金钱给付 → 一般合同管辖，标待核；涉及土地使用权权属确认则专属接口单列。
8. 不动产已登记以登记簿记载所在地为准；未登记以实际所在地为准。两地冲突并列。

---

## 节点 2　仲裁协议

1. 主合同、补充协议、单独仲裁协议、网签文本冲突并列。
2. 仅有“协商不成依法解决／可诉讼可仲裁” → 仲裁意思 `依据不足`。
3. 事项是否覆盖退房、办证、物业费分别判断。
4. 机构是否存在、是否唯一。或裁或诉标依据不足。
5. 未签字主体、销售代理代签、格式条款未提示说明：约束力 `依据不足`。
6. 合同无效、被撤销或终止，不当然消灭仲裁协议。独立性规则须核验现行仲裁法。

---

## 节点 3　诉讼连结点

无仲裁或仲裁现有依据不支持适用时，才展开法院清单。协议管辖不得对抗真正的专属管辖，也不得对抗级别管辖。连结点材料不足：不选定唯一法院。

---

## 节点 4　异议与应诉

每份起诉状／应诉通知单独一行：作出日、送达日、送达方式。已读不等于送达。异议期已过且只要赶写异议书：负触发。未提异议并实体答辩或反诉：应诉管辖红旗，但仲裁协议争点不自动消灭。
