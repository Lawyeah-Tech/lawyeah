# 应对房地产与物业纠纷一审

## 任务目标

在明确、无利益冲突的被告立场下，形成首次应诉答辩包：答辩期限卡、原告请求拆解、答辩草稿、管辖／仲裁红旗、反诉评估接口和证据意见。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：房地产或物业被告已收到起诉状或应诉通知，需要答辩而不是只要管辖异议终稿或只要大众答辩包。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 用户实为原告、只要起诉状；
- 只要管辖异议终稿且无实体答辩；
- 建设工程应诉整案；
- 已决定只谈和解。

C 端 012 只分流。本任务不自动生成反诉状终稿，不指导隐匿证据。

## 建立坐标

确认：被告立场；每份文书的作出日、送达日、送达方式；材料来源与使用权限；仲裁条款。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。口头转述和“已读”不写成已受理、已送达或期限已起算。

## 来源和判断状态

编号：`S#`；`D#`；`A#`；`R#`；`C#`；`L#`；`I#`；`G#`；`Q#`；`K#` 期限卡；`H#` 抗辩；`V#`；`E#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验答辩期间、管辖异议期间、应诉管辖、反诉条件。作出日或送达日不明则期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 被告立场和材料权限

原告材料不得直接当作被告已掌握的秘密。只要管辖异议终稿且无实体：负触发。

### 2. 答辩期限卡

每份文书单独一行。普通程序以收到起诉状副本之日起算。已读不等于送达。

### 3. 请求拆解与红旗

承认、否认、不知、抗辩分列。普通商品房买卖被原告写成专属管辖时提出红旗。未提管辖异议并应诉可能视为接受管辖，但不自动消灭仲裁争点。

### 4. 答辩草稿与反诉接口

反诉只评估条件、牵连、管辖、时效，不自动生成反诉状终稿。

### 5. 证据与禁止事项

不利证据必须进入最强反方。拒绝隐匿、伪造指导。

## 停止与安全

- `整体停止`：用户坚持隐匿证据、虚假陈述或伪造交付记录。
- `字段停止`：作出日或送达日不明。
- `目标停止`：主目标变为管辖异议终稿、反诉状终稿或和解协议正文。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
