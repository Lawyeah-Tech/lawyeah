# 边界与路由

## 正触发

物业服务人拟催告欠费后再起诉或仲裁。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 停水停电方案 | 整体停止 |
| 业主抗辩评估 | `评估物业费与物业服务争议` |
| 起诉状 | `提起房地产与物业纠纷一审` |
| 支付令 | `申请物业费或租金支付令` |
| 租金催告 | `准备租赁催告或解除通知` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

催告不是判决。未入住不是函里能消灭的抗辩。停水电违法。
