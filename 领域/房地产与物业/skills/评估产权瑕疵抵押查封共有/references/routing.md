# 边界与路由

## 正触发

共有、抵押、查封、租赁或登记错误阻碍过户。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 婚姻析产 | 婚家领域 |
| 抵押权实现 | 金融借贷担保领域 |
| 登记行政诉讼 | 行政争议领域 |
| 一房二卖 | `评估一房二卖与隐瞒抵押查封` |
| 预告异议操作细项 | `评估转移预告异议登记路径` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

有抵押不等于买卖无效。共有未同意是处分权问题，不一定先离婚。查封房产不得指导转移。
