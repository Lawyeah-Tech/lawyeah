# 边界与路由

## 正触发

担心转移房产或预售资金，尚未决定是否申请保全。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 代写申请 | 不实施 |
| 现场证据保全 | `保全房屋现场与质量证据` |
| 预售资金查封对抗实体 | `评估预售资金监管与查封风险` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

保全必要性不是胜诉率。证据保全与财产保全不同。无担保会卡诉前保全。
