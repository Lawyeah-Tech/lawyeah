# 边界与路由

## 正触发

欠租催告、限期腾退或解除租赁需要发送前稿。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 一函充作催告和解除均完成 | 拒绝，拆项 |
| 解除权未闭合 | `评估租赁解除权是否成立` |
| 买卖解除通知 | `准备房屋买卖解除或退房通知` |
| 物业费催缴 | `准备物业费催缴通知` |
| 只设计送达不写正文 | `设计房屋案件通知送达` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

催告预告解除不等于已经解除。一函双用不能当作两步完成。腾退不得靠停水电。
