# 边界与路由

## 正触发

对方依仲裁条款推进，己方主张无效或不适用。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 法院管辖异议 | `提出不动产管辖异议` |
| 实体答辩 | `应对房地产仲裁` 或 `应对房地产与物业纠纷一审` |
| 评估应否仲裁 | `评估不动产管辖与仲裁协议` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

否定仲裁协议不是实体无理由。管辖异议书不能当仲裁协议异议用。
