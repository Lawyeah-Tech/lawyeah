# 边界与路由

## 正触发

一房数卖或隐瞒抵押查封、已出卖，买受方要判断效力和归属。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 已删一倍必得 | 拒绝写入现行必得 |
| 定罪 | 刑事领域 |
| 抵押权实现 | 金融借贷担保领域 |
| 产权瑕疵但非二卖 | `评估产权瑕疵抵押查封共有` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

一房二卖合同多半有效，争的是履行和物权。已删一倍不是现行法。后签约不等于没有权利。
