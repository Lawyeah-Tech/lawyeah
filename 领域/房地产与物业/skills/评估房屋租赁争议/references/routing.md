# 边界与路由

## 正触发

房屋租赁租金、维修、转租或提前解约已成争。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| C 端租赁解约 | 大众专项，只分流 |
| 动产租赁 | 合同争议解决领域 |
| 解除权细项 | `评估租赁解除权是否成立` |
| 发催告或解除通知 | `准备租赁催告或解除通知` |
| 押金租金精算 | `测算租金物业费及抵扣` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

未备案不是当然无效。欠租不是当然立即解除。C 端包不能替代专业解除矩阵。
