# 边界与路由

## 正触发

拆承重、占公共通道或改变用途，业主或物业要停止侵害或恢复原状。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 拆除决定复议诉讼 | 行政争议领域 |
| 工程质量鉴定 | 建设工程领域 |
| 物业费 | `评估物业费与物业服务争议` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

有专有权不等于能拆承重。住改商要利害关系业主同意。行政拆除是另一条线。
