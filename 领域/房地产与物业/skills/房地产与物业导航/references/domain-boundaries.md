# 房地产与物业领域边界

本表只说明归属。每次路由先核对 [当前能力地图](capability-map.md)；未安装入口输出 `unavailable`。

| 相邻 | 本包入口 | 转出 |
| --- | --- | --- |
| 合同审查与起草 | 无。未成争只要改合同、出稿或二手房签前审查：本窗搁置，只说明不实施 | 审查起草领域（用户单独策略） |
| 合同争议解决 | 不动产交易、开发、租赁、物业专门争议 | 一般买卖、服务、承揽、动产租赁等非不动产主轴 |
| 建设工程 | 商品房交付质量与保修的买卖成果 | 施工价款、工期、质量鉴定、实际施工人 |
| 金融借贷担保 | 按揭不能导致买卖合同解除的后果 | 贷款合同、保证、抵押权实现 |
| 婚家 | 无 | 夫妻房产分割、继承过户 |
| 行政争议 | 征收补偿协议民事履行 | 征收决定、补偿决定复议诉讼 |
| 环境能源 | 无 | 矿业权、农地承包、环境监管 |
| 劳动 | 无 | 劳动关系、工资、工伤 |
| 刑事 | 评估中的刑民交叉只标红旗 | 定罪、控告、辩护 |
| C 端退房／物业／租赁／认购／二手房审查／拆迁 | 专业评估或通知，不降成大众行动清单 | 大众第一轮材料或行动包 |
| C 端 011／012 | 专业起诉或应诉包 | 大众网上立案或民事答辩 |

一般买卖夹带房产背景时，房产段只分流，不把专项规则写入一般合同结论；反之亦然。
