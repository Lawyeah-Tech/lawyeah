# 边界与路由

## 正触发

交房后不迁户口、第三人占有或承租人拒腾。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 户籍行政诉讼 | 行政争议领域 |
| 租赁备案与优先细项 | `评估租赁备案与买卖不破租赁` |
| 存量房总图 | `评估存量房买卖争议` |
| 暴力清场 | 整体停止 |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

过户完成不等于占有交付。户口未迁主要是合同问题，不是自动否定过户。承租人可能受买卖不破租赁保护。
