# 边界与路由

## 正触发

不动产取得、开发、交易、租赁或物业已成争，单方需要总体决定请求、抗辩、论坛、证据优先级和下一步。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争，改合同或签前审查 | 审查起草领域（本窗搁置，只说明） |
| 评估管辖或仲裁条款本身 | `评估不动产管辖与仲裁协议` |
| 只判断商品房能否解除退房 | `评估商品房解除退房路径` |
| 只判断物业费或质价不符 | `评估物业费与物业服务争议` |
| 发催告交房或办证 | `准备催告交房或办证通知` |
| 发解除或退房通知 | `准备房屋买卖解除或退房通知` |
| 精算购房款或违约金 | `测算购房款返还违约金与赔偿` |
| 完整证据卷 | `建立房地产争议证据案卷` |
| 和解条件 | `谈判房地产与物业和解方案` |
| 起诉 | `提起房地产与物业纠纷一审` |
| 应诉 | `应对房地产与物业纠纷一审` |
| 工程价款工期质量 | 建设工程领域 |
| 一般合同主轴 | 合同争议解决领域 |
| C 端退房／物业／租赁／认购／二手房审查／拆迁 | 大众专项，只分流不回改 |

## 易混

请求尚未闭合、需比较退房还是先催告交房办证时正触发。主体、请求、论坛均确认且只要诉状时负触发。普通商品房买卖要求“必须在楼盘所在地起诉”时，先完成专属管辖闸。
