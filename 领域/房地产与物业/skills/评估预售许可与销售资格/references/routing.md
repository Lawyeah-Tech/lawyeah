# 边界与路由

## 正触发

无证预售、假证、起诉前补证或销售主体不适格已成争，需要效力与补正判断。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 总体评估 | `评估房地产与物业争议` |
| 行政处罚复议 | 行政争议领域 |
| 项目公司或代理签约效力细项 | `评估项目公司销售代理与签约主体` |
| 存量房 | `评估存量房买卖争议` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

起诉前补证与“正在办证”不是一回事。无证预售无效风险不等于当然获得惩罚性赔偿。
