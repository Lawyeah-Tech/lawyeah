# 评估预售许可与销售资格

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

判断预售许可取得时点、起诉前补证、销售主体是否适格，以及对合同效力和后续解除或继续履行的接口，不写行政处罚文书。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：无证预售、假证、起诉前补证或销售主体不适格已经成争，需要效力判断。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要总体争议总图;
- 要写行政处罚、责令停售或复议申请书;
- 施工许可证或竣工验收备案的工程质量主轴;
- 存量房买卖无预售许可问题;

起诉前取得预售许可的效力必须运行时核验现行解释，不得用失效条文填空。

## 建立坐标

确认：签约日、网签日、预售许可编号与发证日、补证日、起诉日；销售主体是开发商还是项目公司或代理；许可范围是否覆盖该栋该层。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。口头转述和“已读”不写成已受理、已送达或期限已起算。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`V#` 评估版本；`E#` 发送／送达／履行凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验商品房买卖合同解释关于预售许可的现行条文（2003 年第 2 条未被 2020 决定删除，条号须核验）及城市房地产开发经营管理条例相关条款。工具不可用时效力字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　专项分流与许可对象

存量房、施工许可主轴转出。核对许可是否覆盖争议房屋。

### 节点 2　无证、假证、超范围

无证签约与伪造证件分列。假证另标刑民交叉红旗，不定罪。

### 节点 3　起诉前补证窗口

补证日与起诉日比较。补证事实必须有发证机关材料，口头“已经在办”不得写成已补正。

### 节点 4　销售主体适格

项目公司、分公司、销售代理盖章签约：主体与代理权限分列，转项目公司专项接口。

### 节点 5　效力后果与转介

无效、有效或待核分列。有效不等于不能解除；无效不等于当然获得已删一倍惩罚。

## 停止与安全

- `整体停止`：用户坚持伪造预售许可或倒签补证日。
- `字段停止`：预售许可效力条文、补证窗口未核验。
- `目标停止`：主目标变为行政处罚复议或总体评估。
