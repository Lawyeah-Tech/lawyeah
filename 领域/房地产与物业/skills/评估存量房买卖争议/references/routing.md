# 边界与路由

## 正触发

二手房已成争，买受人或出卖人要请求抗辩总图。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 签前审查 | 审查起草（本窗搁置） |
| C 端二手房审查 | 大众专项，只分流 |
| 商品房预售 | `评估房地产与物业争议` 或相应商品房专项 |
| 婚姻析产 | 婚家领域 |
| 户口占有细项 | `评估户口腾退与占有交付` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

签前审查与已成争评估不同。户口未迁不等于不能过户。限购不是自动无效也不是自动免责。
