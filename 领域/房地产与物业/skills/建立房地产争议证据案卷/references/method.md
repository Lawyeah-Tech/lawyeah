# 建卷方法

不能因对方控制而推定材料存在或内容有利。构成逾期与解除、已读与到达分列。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

`search_law` 返回已失效《合同法》《物权法》及其解释，或 2020 年已删除的商品房解释原第 7、8、9、14 条时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定、工期索赔、实际施工人 | 建设工程领域 |
| 一般买卖、服务、承揽、动产租赁等非不动产主轴 | 合同争议解决领域 |
| 金融借贷、保证、抵押实现、保理、融资租赁主轴 | 金融借贷担保领域 |
| 婚姻析产、继承过户、夫妻房产归属 | 婚家领域 |
| 征收决定、补偿决定复议诉讼 | 行政争议领域 |
| 矿业权、农地承包、能源环境监管 | 环境能源领域 |
| 劳动关系、工资、工伤 | 劳动领域 |
| 尚未成争，只要改合同、出稿或做签前审查 | 审查起草领域（本窗搁置，只说明不实施） |
| 刑事定罪、控告、辩护 | 刑事领域 |

## 节点 1　要件

按 `Q#` 拆待证要件。商品房解除至少分列：合同成立、预售许可、逾期事实、催告到达、除斥未满、出卖人原因。物业费至少分列：合同约束力、服务已提供、期间、催告。

---

## 节点 2　证据矩阵

固定列：`EV#｜对应要件｜材料名称｜支持／不利｜形成主体｜形成时间｜控制方｜取得方式｜合法取得｜完整性／冲突｜判断｜来源`。

典型材料：预售许可证、网签、不动产登记簿、交付确认书、验收备案、维修记录、物业费账单、业主大会决议、催告邮寄回证。复印件不能核对原件的，完整性标待核。

---

## 节点 3　冲突

同一面积的预测绘与实测、同一交房日的通知与拒收记录、同一收费标准的备案与实际加收，必须并列。

---

## 节点 4　补证

合法步骤：登记中心查询、政府公示、公证处保全现状、鉴定机构、法院调查令。禁止：伪造预售许可、倒签网签、偷拷物业监控不经合法程序、收买证人作伪证。

---

## 节点 5　红旗与转介

现场易灭失 → `preserve-site-or-quality-evidence`（未安装则最小交接）。需要鉴定 → `prepare-appraisal`（未安装则 unavailable）。需要起诉 → `file-first-instance`。
