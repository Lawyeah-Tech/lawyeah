# 边界与路由

## 正触发

已收到解除或退房通知，相对方要异议或主张未解除。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 确认之诉诉状 | `提起房地产与物业纠纷一审` |
| 己方发送解除 | 对应 `prepare-sale-termination-notice` 或租赁通知 |
| 管辖异议 | `提出不动产管辖异议` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

异议不是确认之诉。无解除权的通知不因未异议而变有效，但沉默会增加证明成本。
