# 边界与路由

## 正触发

欠租、押金扣留或占有使用费需要定性与抵扣规则。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| C 端押金退还 | 大众专项，只分流 |
| 精算 | `测算租金物业费及抵扣` |
| 物业费 | `评估物业费与物业服务争议` |
| 租赁总图 | `评估房屋租赁争议` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

押金不是定金。解除后继续占有不是当然按原租约延期。全部没收押金常常过苛。
