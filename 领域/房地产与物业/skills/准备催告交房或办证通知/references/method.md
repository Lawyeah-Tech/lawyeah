# 发函方法

通知状态只用 `草案`、`待发送`、`已发送待证明到达`、`已到达`、`停止`。没有送达事实不得写已到达。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

`search_law` 返回已失效《合同法》《物权法》及其解释，或 2020 年已删除的商品房解释原第 7、8、9、14 条时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

---

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定、工期索赔、实际施工人 | 建设工程领域 |
| 一般买卖、服务、承揽、动产租赁等非不动产主轴 | 合同争议解决领域 |
| 金融借贷、保证、抵押实现、保理、融资租赁主轴 | 金融借贷担保领域 |
| 婚姻析产、继承过户、夫妻房产归属 | 婚家领域 |
| 征收决定、补偿决定复议诉讼 | 行政争议领域 |
| 矿业权、农地承包、能源环境监管 | 环境能源领域 |
| 劳动关系、工资、工伤 | 劳动领域 |
| 尚未成争，只要改合同、出稿或做签前审查 | 审查起草领域（本窗搁置，只说明不实施） |
| 刑事定罪、控告、辩护 | 刑事领域 |

## 节点 1　催告闸

若：用户主成果是解除／退房 → 负触发至 `prepare-sale-termination-notice`。  
若：无法识别仍要对方履行的具体事项 → 字段停止。  
若：解除权评估已闭合且用户只要解除稿 → 本任务负触发。

---

## 节点 2　事项和期限

1. 交房：对照约定交房日和交付条件。不具备交付条件的，催告对象是“具备条件并交付”，不是“签收不合格房屋”。
2. 办证：对照约定办证日或解释第 14 条九十日档。催告协助提供材料、缴税配合、申请登记。
3. 付款：买受人迟延付款时出卖人可催告。
4. 期限：解释第 11 条将三个月表述为合理期限，另有约定除外。约定期限优先。未核验不得写“法定就是 15 日”或“法定必须 3 个月否则无效”。
5. 期限是否合理标待核。

---

## 节点 3　正文约束

逐句回链。禁止：倒签；把催告写成解除；把违约金写成必得；威胁停水电或限制人身；要求对方自认犯罪。

---

## 节点 4　到达设计

约定送达地址、电子渠道、公证送达、备份邮寄分列。每次尝试预列实施人、版本、回证、失败升级。不补造回证。

---

## 节点 5　状态

成果保持 `待发送`。不得写“催告期满合同已解除”。下一步可转介解除评估或解除通知，但须另行确认催告已闭合。
