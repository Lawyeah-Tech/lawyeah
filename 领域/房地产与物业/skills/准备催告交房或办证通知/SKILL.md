# 准备催告交房或办证通知

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成仍要对方交房、协助办理不动产登记或支付购房款的发送前催告包：催告稿、期限依据、送达留痕。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：房屋买卖已成争，用户仍希望对方履行或补救，需要催告而不是解除。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 本次主成果是解除或退房通知；
- 只要总体评估或精算；
- 依法路径已是直接解除且用户明确只要解除稿；
- 工程进度款催告。

本任务不执行发送，不把催告写成逾期即已解除，不倒签日期。

## 建立坐标

确认：主张方立场；相对人；交房日或办证日；拟指定的合理期限；约定送达渠道；是否已有催告。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。口头转述和“已读”不写成已受理、已送达或期限已起算。

## 来源和判断状态

编号：`S#`；`D#`；`A#`；`R#`；`C#`；`L#`；`I#`；`G#`；`Q#`；`V#` 通知版本；`E#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验解释第 11、14 条和民法典催告规则；`search_template` 只借通知栏目。工具不可用时继续事实和稿件结构；三月期限是否“法定唯一”字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 发送闸：催告而非解除

主成果必须是催告履行。用户改口要解除：目标停止，转解除通知原子。

### 2. 催告事项与期限

交房、协助办证、支付购房款分列。解释第 11 条三个月是解除前合理期限接口，不得编造“一律 15 日”，也不得把三个月写成已经解除。

### 3. 发送前正文

只写已支持的主体、合同版本、履行事项、指定期限、送达后继续保留解除权的提示。不宣称合同已解除，不写必得违约金数字。

### 4. 到达设计

按约定渠道、网签地址、备份送达设计。已读不等于到达。本任务不执行发送。

### 5. 与解除的衔接

催告稿不得含“逾期本合同自动解除”除非合同有可回链的自动解除条款且已核验。自动解除条款不得用来规避尚未成就的法定催告。

## 停止与安全

- `整体停止`：立场不明；用户坚持倒签催告或伪造送达。
- `字段停止`：合理期限规则、送达规则未核验。
- `目标停止`：主目标变为解除通知或起诉状。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
