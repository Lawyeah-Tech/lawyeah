# 边界与路由

## 正触发

逾期交房、不具备交付条件或拒收已成争，需要判断而不发函。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 发解除通知 | `准备房屋买卖解除或退房通知` |
| 发催告交房 | `准备催告交房或办证通知` |
| 施工工期 | 建设工程领域 |
| 办证逾期 | `评估办证不能与权属障碍` |
| 商品房解除总表 | `评估商品房解除退房路径` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

通知收房不等于合法交付。逾期不等于当然解除。拒收可能是正当的。
