# 边界与路由

## 正触发

和解条件已谈拢，需要可签的房地产或物业和解协议。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 条件未谈拢 | `谈判房地产与物业和解方案` |
| 司法确认或赋强 | `办理房屋和解执行力补强` |
| 未成争补充协议 | 审查起草（本窗搁置） |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

谈拢才能起草原稿。单独和解没有执行力。概括弃权会吞掉未知请求。
