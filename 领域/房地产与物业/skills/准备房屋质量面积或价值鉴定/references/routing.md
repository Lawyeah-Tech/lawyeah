# 边界与路由

## 正触发

需要鉴定机构确认房屋质量、面积或价值。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 预测意见 | 拒绝 |
| 工程造价 | 建设工程领域 |
| 现场保全 | `保全房屋现场与质量证据` |
| 财产保全 | `评估房屋财产保全必要性` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

鉴定不回答法律问题。单方委托不是法院鉴定。造价属工程。
