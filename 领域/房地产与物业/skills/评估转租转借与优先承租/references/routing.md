# 边界与路由

## 正触发

擅自转租、优先承租或数份租赁争履行。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 写成物权优先 | 拒绝该表述 |
| 解除通知 | `准备租赁催告或解除通知` |
| 买卖不破租赁 | `评估租赁备案与买卖不破租赁` |
| 租赁总图 | `评估房屋租赁争议` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

履行顺序不是物权。优先承租要同等条件。知道转租后长期不反对会丧失解除权。
