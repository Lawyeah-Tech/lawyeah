# 边界与路由

## 正触发

逾期办证或因出卖人原因无法登记，买受方要判断违约与解除。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 登记行政诉讼 | 行政争议领域 |
| 抵押权实现 | 金融借贷担保领域 |
| 交房逾期 | `评估逾期交房与接房条件` |
| 发解除通知 | `准备房屋买卖解除或退房通知` |
| 商品房解除总表 | `评估商品房解除退房路径` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

办证九十日不是解除除斥。超一年解除必须因出卖人原因。告登记机构是行政路径。
