# 边界与路由

## 正触发

拟解除或已收到解除，需判断房屋租赁解除权。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 发通知 | `准备租赁催告或解除通知` |
| 租赁总图 | `评估房屋租赁争议` |
| 装修投入 | `评估经营性装修投入与返还` |
| 动产租赁 | 合同争议解决领域 |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

欠租不是当然当天解除。不定期终止要提前通知。知道转租后六个月不提不得再解除。
