# 边界与路由

## 正触发

持判决、调解书或裁决未获过户或付款，权利人要执行。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 重审实体 | 拒绝 |
| 文书未生效 | 上诉或等待生效 |
| 无执行力和解 | `办理房屋和解执行力补强` |
| 案外人异议 | P2 未安装则 unavailable |
| 被执行人应对 | `应对房地产案件执行` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

没有执行名义不能强制过户。执行不重审对错。案外人是另一原子且本包为 P2。
