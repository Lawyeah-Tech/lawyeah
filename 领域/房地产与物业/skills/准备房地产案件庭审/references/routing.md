# 边界与路由

## 正触发

诉讼或仲裁即将开庭，单方需要庭审提纲。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 尚未立案 | `提起房地产与物业纠纷一审` 或 `提起房地产仲裁` |
| 只和解 | `谈判房地产与物业和解方案` |
| 上诉 | `提起房地产案件上诉` |
| 工程鉴定庭主轴 | 建设工程领域 |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

庭审提纲不是起诉状。鉴定人不是法律裁判者。和解准备不能省略质证。
