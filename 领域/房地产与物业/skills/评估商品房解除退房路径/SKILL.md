# 评估商品房解除退房路径

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，判断商品房买卖合同约定或法定解除权是否成立：催告必要、三月合理期限、一年除斥、办证超一年、质量严重影响居住、规划变更或按揭不能，不发函。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：商品房预售或现售已成争，用户拟退房或已收到退房主张，需要解除路径判断而不是发送通知。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未成争或只要改合同；
- 只要总体争议总图；
- 材料已支持发送且用户只要解除通知终稿；
- 施工合同质量、造价鉴定、工期索赔；
- 存量房、租赁、物业主轴（转对应评估）。

本任务不生成发送版解除函或诉状，不把逾期几天写成当然解除，不把已删一倍惩罚写成解除条件。

## 建立坐标

确认：买受人或出卖人立场；预售许可；合同约定交房日、办证日、解除条款；是否已催告及催告到达；质量描述；贷款合同是否订立；查封抵押。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。口头转述和“已读”不写成已受理、已送达或期限已起算。

## 来源和判断状态

编号：`S#`；`D#`；`A#`；`R#`；`C#`；`L#`；`I#`；`G#`；`Q#` 解除路径；`K#` 除斥情景；`V#`；`E#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

宿主可调用时：`search_law` 核验商品房解释第 10、11、14、15、19 条及民法典第 563、564、565 条；工具不可用时继续事实和催告时间线；解除效果与除斥截止字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 专项分流、立场和发送闸关闭

本任务只评估，打开发送闸属于通知原子。施工质量主轴转工程。

### 2. 路径分列

分别建立：约定解除、迟延交房／付款＋催告三月、目的不能实现、办证超一年、质量严重影响居住、按揭不能、无预售许可效力。不得合成“可以退房”。

### 3. 催告闭合与除斥情景

解释第 11 条催告后三个月；对方未催告则知悉后一年。日期冲突建并行情景，不给唯一截止日。

### 4. 质量、办证、贷款接口

质量解除须“严重影响正常居住使用”，轻微瑕疵走修复。办证违约金与办证超一年解除分列。按揭不能区分可归责／不可归责双方。

### 5. 通知到达效果与转介

评估不得写合同已解除。条件闭合且用户要发函 → 转解除通知；依法须催告未完成 → 转催告通知。

## 停止与安全

- `整体停止`：立场不明；用户坚持倒签催告或伪造交付不合格。
- `字段停止`：催告到达日、知悉日、解释条文未核验。
- `目标停止`：主目标变为发送版解除函或起诉状。
