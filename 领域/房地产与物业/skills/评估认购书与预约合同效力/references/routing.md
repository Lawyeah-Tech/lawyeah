# 边界与路由

## 正触发

认购、意向、排号后争能否转本约或解除返还。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 起草本约 | 审查起草（本窗搁置） |
| C 端认购 | 大众专项，只分流 |
| 本约已成立要退房 | `评估商品房解除退房路径` |
| 定金与首付款纯定性且本约已签 | `评估定金订金与首付款性质` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

交了认筹金不等于房子已经买到。预约违约不等于本约解除。
