# 边界与路由

## 正触发

单独核验房地产或物业争议的期间是否届满。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 要求唯一截止日 | 拒绝该输出，保持分类型表 |
| 工程优先受偿期限 | 建设工程领域 |
| 行政起诉期限 | 行政争议领域 |
| 总体评估 | `评估房地产与物业争议` |
| 发解除通知 | `准备房屋买卖解除或退房通知` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

时效与除斥不是同一口钟。物业费不能从第一期欠费起算全部三年。办证九十日不是解除除斥。
