# 边界与路由

## 正触发

容积率、楼间距、户型等规划设计变更，买受方要判断退房或补偿。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 规划许可行政诉讼 | 行政争议领域 |
| 施工签证 | 建设工程领域 |
| 广告不符未变规划 | `评估宣传与合同不符` |
| 发解除通知 | `准备房屋买卖解除或退房通知` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

规划变更的民事后果与许可合法性是两条线。轻微景观变化不是当然退房。
