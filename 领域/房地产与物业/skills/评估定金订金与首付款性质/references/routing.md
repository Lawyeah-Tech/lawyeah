# 边界与路由

## 正触发

定金、订金、意向金或首付款性质及罚则有争议。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 签前改条款 | 审查起草（本窗搁置） |
| 租赁押金 | `评估租金押金与抵扣` |
| 精算 | `测算购房款返还违约金与赔偿` |
| 认购预约 | `评估认购书与预约合同效力` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

订金不是定金。首付不能整体按双倍。定金与违约金通常选用而非叠加。
