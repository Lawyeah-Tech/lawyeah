# 边界与路由

## 正触发

所有权变动后承租人要求继续履行，或受让人要求腾退。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 抵押权实现 | 金融借贷担保领域 |
| 优先承租 | `评估转租转借与优先承租` |
| 户口占有总图 | `评估户口腾退与占有交付` |
| 倒签租约对抗执行 | 整体停止 |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

未备案不等于买卖破租赁。先抵押后租可能例外。倒签租约不能对抗查封。
