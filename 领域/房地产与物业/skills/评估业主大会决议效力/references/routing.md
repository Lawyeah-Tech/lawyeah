# 边界与路由

## 正触发

业主大会表决程序、人数面积或决议内容被挑战。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 代开大会 | 不实施 |
| 物业费该不该交 | `评估物业费与物业服务争议` |
| 业委会资格 | `评估业委会资格与越权` |
| 维修资金使用 | `评估专项维修资金使用争议` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

表决比例必须核验现行第 278 条，不得凭记忆。程序瑕疵不等于当然无效。撤销有窗口。
