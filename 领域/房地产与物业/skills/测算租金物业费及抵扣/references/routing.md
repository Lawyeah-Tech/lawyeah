# 边界与路由

## 正触发

需要可复核的租金、占有使用费、物业费或押金抵扣数字。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 认定欠费成立 | 对应评估原子 |
| 购房款测算 | `测算购房款返还违约金与赔偿` |
| 工程造价 | 建设工程领域 |
| 物业费定性 | `评估物业费与物业服务争议` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

测算不是判决。空置不是整表免除。滞纳金不是必得。
