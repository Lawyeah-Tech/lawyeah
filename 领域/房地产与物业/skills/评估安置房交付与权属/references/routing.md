# 边界与路由

## 正触发

安置房逾期交付、面积或权属有争议。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 征收合法性 | 行政争议领域 |
| 补偿协议论坛总界 | `评估房屋征收补偿民事请求` |
| 普通商品房买卖 | 商品房专项 |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

安置房不是自动适用全部商品房解释。没有安置协议很难主张特定房屋。另卖要看登记和占有。
