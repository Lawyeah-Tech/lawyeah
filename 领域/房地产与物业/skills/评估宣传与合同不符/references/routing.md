# 边界与路由

## 正触发

广告、沙盘、样板间与合同或交付现状冲突，买受方要判断是否订入及后果。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 自动三倍 | 拒绝默认，保持待核 |
| 当然解除并发函 | `评估商品房解除退房路径` 或解除通知 |
| 规划变更专项 | `评估规划设计变更退房` |
| 工程索赔 | 建设工程领域 |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

宣传不符首先是违约问题。排除条款不自动消灭解释第 3 条。三倍不是默认。
