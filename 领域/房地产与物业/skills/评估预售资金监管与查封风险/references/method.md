# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然结果或唯一必得总额。未知金额不写零。建设工程施工、分包、优先受偿、造价鉴定、工期索赔或实际施工人主轴整案转出。一般买卖、服务、承揽、动产租赁等非不动产主轴只分流到合同争议，不把本任务规则写入一般合同结论。

`search_law` 返回已失效《合同法》《物权法》及其解释，或 2020 年已删除的商品房解释原第 7、8、9、14 条时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。



分列：`Q-监` 监管义务；`Q-查` 查封对抗；`Q-保` 保全红旗；`Q-刑` 刑民交叉；`Q-破` 破产分流。

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定、工期索赔、实际施工人 | 建设工程领域 |
| 一般买卖、服务、承揽、动产租赁等非不动产主轴 | 合同争议解决领域 |
| 金融借贷、保证、抵押实现、保理、融资租赁主轴 | 金融借贷担保领域 |

| 征收决定、补偿决定复议诉讼 | 行政争议领域 |

若 `search_law` 不可用：继续整理主体、文本、程序文书和问题清单；依赖未核验规则的法律结论、期限、效力、管辖选定字段停止，不拒绝执行。


## 节点 1　监管资金

1. 合同或监管协议指定账户与实际收款账户不一致：监管义务违反支持事实。
2. 地方预售资金监管办法多为规章或规范性文件，层级必须标明，不得写成法律当然无效买卖合同。
3. 已入监管账户被违法拨付：责任主体可能是开发商、监管银行，银行责任依据待核，不当然成立。

## 节点 2　查封

1. 查封在网签或预告登记之前：买受人对抗依据弱。
2. 已预告登记：处分不发生物权效力接口（第 221 条）。
3. 消费者交付购买商品房的对抗执行：属于执行异议或执行异议之诉，本包 P2 未安装则标 `unavailable`，只给红旗。
4. 不得指导隐匿或转移被查封房屋。

## 节点 3　保全

资金仍可转出或剩余房屋可能再卖：保全必要性红旗，转 `assess-preservation-need`。本任务不写担保和申请书。

## 节点 4　刑民

伪造预售许可、携款逃匿、非法吸收公众存款：提示可能影响民事中止或证据，不定罪，不写报案书作为主成果。

## 节点 5　破产

法院已受理破产：返还购房款可能变为破产债权，整段转破产。尚未受理不得按破产规则减免债务。


## 通用输出纪律

1. 若立场或授权不明，或同时掌握双方秘密未解：整体停止策略输出。
2. 若用户坚持伪造、倒签、隐匿查封抵押、暴力清场、停水停电催费或违法取证：整体停止。
3. 若主目标已变为相邻原子的成果：目标停止并分流，不代做。
4. 判断结论必须带回链；不得用失效《合同法》填空。
