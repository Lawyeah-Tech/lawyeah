# 边界与路由

## 正触发

预售资金挪用、监管账户或房屋被查封，买受方要判断对抗与风险。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 定罪或控告 | 刑事领域 |
| 破产债权 | 破产重整与清算领域 |
| 保全申请终稿 | `评估房屋财产保全必要性` |
| 一房二卖隐瞒抵押 | `评估一房二卖与隐瞒抵押查封` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

入监管账户不等于资金安全。查封对抗不是唯一结论。刑民交叉只标红旗。
