# 谈判方法

口头报价、聊天已读不得写成协议已成立。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

`search_law` 返回已失效《合同法》《物权法》及其解释，或 2020 年已删除的商品房解释原第 7、8、9、14 条时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

---

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定、工期索赔、实际施工人 | 建设工程领域 |
| 一般买卖、服务、承揽、动产租赁等非不动产主轴 | 合同争议解决领域 |
| 金融借贷、保证、抵押实现、保理、融资租赁主轴 | 金融借贷担保领域 |
| 婚姻析产、继承过户、夫妻房产归属 | 婚家领域 |
| 征收决定、补偿决定复议诉讼 | 行政争议领域 |
| 矿业权、农地承包、能源环境监管 | 环境能源领域 |
| 劳动关系、工资、工伤 | 劳动领域 |
| 尚未成争，只要改合同、出稿或做签前审查 | 审查起草领域（本窗搁置，只说明不实施） |
| 刑事定罪、控告、辩护 | 刑事领域 |

## 节点 1　可谈性

对方已明确拒绝协商且已进入庭审且用户只要代理提纲 → 转 `prepare-hearing`（未安装则 unavailable）。其余已诉案件只要仍想谈，正触发。

---

## 节点 2　让步档

每个 `Q#` 对应 `N#`：主位、可让档、对价、互斥。商品房案件至少分列：是否继续要房、退房返还时点、违约金是否放弃、贷款如何结清。物业案件分列：欠费期间、滞纳金是否减免、服务整改。

---

## 节点 3　弃权

`W#` 必须写对象、请求类型、是否含未知质量损害、是否含贷款银行和承租人。覆盖未知第三人权利：字段停止。

---

## 节点 4　履行安排

过户：缴税、预约、领证责任人。腾退：户口、物品、钥匙。金钱：监管账户或公证提存接口。未履行是恢复原请求还是违约金单列。

---

## 节点 5　执行力

明示：私下和解通常不能直接申请执行。转介 `draft-settlement-agreement`、`confirm-settlement-enforceability`（未安装则 unavailable）。
