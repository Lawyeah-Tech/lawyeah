# 谈判房地产与物业和解方案

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成仍可协商的和解方案表：争点与让步、过户／腾退／缴费条件、弃权范围、单独和解无执行力的明示。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：房地产或物业争议仍可谈，用户需要条件和让步，而不是已谈拢后的可签协议正文。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 未成争只要改合同；
- 只要答辩或起诉状；
- 条件已谈拢只要协议正文；
- 要求写覆盖未知损害的“永不追究”。

本任务不生成可签署终稿，不代办司法确认。

## 建立坐标

确认：已形成争点；对方已知报价；是否已立案；贷款银行、承租人、共有人是否必须加入。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。口头转述和“已读”不写成已受理、已送达或期限已起算。

## 来源和判断状态

编号：`S#`；`D#`；`A#`；`R#`；`C#`；`L#`；`I#`；`G#`；`Q#`；`N#` 让步档；`W#` 弃权；`V#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验弃权、债务消灭、调解书／司法确认／公证赋强条件。工具不可用时继续报价表；弃权效力和执行力路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 仍可谈状态

已起诉或已保全，只要协商渠道未切断，仍可正触发。用户只要答辩则负触发。

### 2. 争点让步表

继续履行、解除退房、购房款、违约金、物业费、腾退、过户、贷款结清不得合成“打包了结”。

### 3. 底线与弃权

未获用户就具体范围的明示确认，不得把现有请求写成已放弃。概括“永不追究”停止。

### 4. 过户、腾退、缴费、贷款

写明主体、时间、条件、凭证和未履行后果。银行解除抵押、承租人腾退、共有人签字单列。第三方代付标风险。

### 5. 执行力

单独和解无强制执行力必须明示。司法确认、调解书、公证赋强只写转介。有效仲裁不得写成谈不拢就起诉。

## 停止与安全

- `整体停止`：用户要求以和解掩盖犯罪、逃废贷款或伪造网签。
- `字段停止`：弃权范围、执行力条件未核验。
- `目标停止`：主目标变为可签协议正文或答辩状。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
