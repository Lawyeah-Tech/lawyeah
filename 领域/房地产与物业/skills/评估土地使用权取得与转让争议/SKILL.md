# 评估土地使用权取得与转让争议

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成土地使用权争议评估矩阵：出让或转让定性、数份合同履行顺序、登记与占有、无效或解除分流、金额区间接口和下一步。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：国有建设用地使用权出让、转让、一地数转或变更登记不能已经成争，用户需要定性、履行顺序和后果分流，而不是施工结算或征收决定合法性审查。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 矿业权、探矿权或农地承包经营权主轴;
- 征收决定、补偿决定复议或诉讼;
- 建设工程价款、工期、质量鉴定或实际施工人主轴;
- 只要改出让或转让合同文本（审查起草本窗搁置）;
- 只要起诉状或解除通知终稿;

本任务不给胜诉率，不把未登记写成合同当然无效，未知金额不写零。

## 建立坐标

确认：单方立场；出让人、受让人、转受让人；出让合同与转让合同版本；土地坐落与用途；是否已缴纳出让金；是否已办理出让或变更登记；占有使用现状；查封抵押；一地数转的各份文本签约日。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。口头转述和“已读”不写成已受理、已送达或期限已起算。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`V#` 评估版本；`E#` 发送／送达／履行凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典第 209、215 条、国有土地使用权合同解释（2020 修正）关于出让、转让、一地数转和合作开发的现行条文。工具不可用时继续主体、文本和占有事实；效力、履行顺序与期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　专项分流、主体和文本版本

先转出矿业权、农地承包、征收决定合法性和施工主轴。固定出让合同、转让合同、补充协议和登记簿冲突并列，名称不一致不自动合并。

### 节点 2　出让／转让／无效／解除分列

每个 Q# 独立列法律效果。未办理物权登记不影响合同效力（第 215 条）。无批准或未缴清出让金的效力必须运行时核验解释现行条文，不得用失效合同法填空。

### 节点 3　一地数转履行顺序

若数份转让合同均有效：先看是否已变更登记，再看合法占有使用，再看付款履行，最后看签约在先。不得按用户先接触的一份写成唯一物权归属。

### 节点 4　登记、占有与金额接口

登记不能的原因分列：出让人未协助、查封抵押、规划用途不符、受让人材料不全。金额只列已付出让金／转让价款区间，未知不写零。

### 节点 5　证据、反方和下一步

最强反方通常是：名为转让实为抵押、未缴清出让金、无权处分、一地数转中的善意登记方。发送解除或立案只作转介。

## 停止与安全

- `整体停止`：立场或授权不明；用户坚持伪造出让金票据、倒签转让合同或隐匿一地数转。
- `字段停止`：出让批准、登记规则、一地数转履行顺序条文未核验。
- `目标停止`：主目标变为施工结算、征收行政诉讼、改合同或起诉状。
