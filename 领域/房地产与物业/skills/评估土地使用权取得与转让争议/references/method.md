# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然结果或唯一必得总额。未知金额不写零。建设工程施工、分包、优先受偿、造价鉴定、工期索赔或实际施工人主轴整案转出。一般买卖、服务、承揽、动产租赁等非不动产主轴只分流到合同争议，不把本任务规则写入一般合同结论。

`search_law` 返回已失效《合同法》《物权法》及其解释，或 2020 年已删除的商品房解释原第 7、8、9、14 条时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

不得把“没过户”写成合同当然无效。不得把土地使用权争议改写成施工合同结算。

固定列：`编号｜关系假设｜提出方｜法律效果｜成立条件｜支持事实｜不利事实｜控制方｜最强反方｜主备位｜判断｜待核`。至少分列：`Q-让` 出让合同效力与继续履行；`Q-转` 转让合同效力；`Q-登` 协助变更登记；`Q-占` 占有保护；`Q-解` 解除或无效返还；`Q-序` 数份合同履行顺序。

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定、工期索赔、实际施工人 | 建设工程领域 |
| 一般买卖、服务、承揽、动产租赁等非不动产主轴 | 合同争议解决领域 |
| 金融借贷、保证、抵押实现、保理、融资租赁主轴 | 金融借贷担保领域 |
| 婚姻析产、继承过户、夫妻房产归属 | 婚家领域 |
| 征收决定、补偿决定复议诉讼 | 行政争议领域 |
| 矿业权、农地承包、能源环境监管 | 环境能源领域 |
| 劳动关系、工资、工伤 | 劳动领域 |
| 尚未成争，只要改合同、出稿或做签前审查 | 审查起草领域（本窗搁置，只说明不实施） |
| 刑事定罪、控告、辩护 | 刑事领域 |


本任务额外分流：

| 信号 | 转出 |
| --- | --- |
| 矿业权、探矿权、农地承包 | 环境能源或相应农地规则，本包不实施 |
| 征收决定或补偿决定合法性 | 行政争议领域 |
| 施工价款工期质量 | 建设工程领域 |


C 端相邻只分流不回改。未成争只要改合同、出稿或做签前审查：审查起草领域本窗搁置，只说明不实施。

若 `search_law` 不可用：继续整理主体、文本、程序文书和问题清单；依赖未核验规则的法律结论、期限、效力、管辖选定字段停止，不拒绝执行。


## 节点 1　主体、批准和文本

1. 若土地为集体土地承包或宅基地：整案转出，不套用国有建设用地出让规则。
2. 若争议实为探矿权、采矿权：整案转环境能源。
3. 固定出让批准文件、出让合同、转让合同、付款凭证、交付或交地纪要、不动产登记簿。冲突并列。
4. 若主体是项目公司、母公司或管委会代签：名称不自动合并，代理权限另列待核。
5. 若同时存在合作开发合同：先判断主轴是土地转让还是共同投资共担风险；后者转 `assess-development-cooperation`。

## 节点 2　效力与第 215 条

1. 若仅因未办理变更登记主张合同无效：判断为 `现有依据不支持`（民法典第 215 条），除非另有导致无效的法定事由。
2. 若主张未缴清出让金即当然无效：不得直接写成无效；运行时核验国有土地使用权合同解释现行条文和出让合同关于付款与解除的约定，结论字段在未核验时停止。
3. 若转让未经出让人同意：把同意、通知、登记条件分列，不把管理性规定一律写成效力性强制规定。
4. 若无权处分：合同效力与能否发生物权变动分列，不得合成“合同无效所以不用过户”。
5. 若用户要改出让或转让条款：目标停止，转审查起草（本窗搁置）。

## 节点 3　一地数转

若同一地块存在两份以上转让合同：

1. 先判断各份合同是否成立及是否有无效、可撤销事由，不得预先认定先签约者当然取得使用权。
2. 若其中一份已办理变更登记：登记权利人作为物权归属的现有依据支持项，但恶意串通或虚假登记另列 `Q-恶`。
3. 若均未登记、一方已合法占有使用：占有方列入履行顺序候选，占有合法性必须有交地或进场证据。
4. 若均未登记亦未占有：比较付款履行和签约顺序，两项都标情景，不输出唯一权利人。
5. 金钱返还与物权归属分列，不得把未取得土地使用权的价款请求写成已经取得物权。

## 节点 4　登记不能、解除与金额

1. 若登记不能可归责于出让人或转让人未协助：`Q-登` 可评估继续履行或赔偿接口。
2. 若土地已被查封、抵押或规划用途变更：把障碍原因和能否涤除分列；抵押权实现转金融。
3. 解除或无效后的返还：已付价款、占用费、利息分项，未知不写零。
4. 不得把已删商品房惩罚性条款套用到土地使用权。

## 节点 5　输出与转介

| 条件 | 本任务 | 转介 |
| --- | --- | --- |
| 主轴是联合建房或利润分配 | 最小交接 | `assess-development-cooperation` |
| 主轴是施工结算 | 整案转出 | 建设工程领域 |
| 用户要发解除通知 | 效力判断保留 | 房屋买卖解除通知不套用；土地合同通知按本评估接口另案 |
| 只要起诉包 | 最小交接 | `file-first-instance` |


## 通用输出纪律

1. 若立场或授权不明，或同时掌握双方秘密未解：整体停止策略输出。
2. 若用户坚持伪造、倒签、隐匿查封抵押、暴力清场、停水停电催费或违法取证：整体停止。
3. 若主目标已变为相邻原子的成果：目标停止并分流，不代做。
4. 判断结论必须带回链；不得用失效《合同法》填空。
