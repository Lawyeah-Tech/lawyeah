# 边界与路由

## 正触发

国有建设用地使用权出让、转让、一地数转或变更登记不能已成争，单方需要定性、履行顺序和无效或解除分流。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 矿业权或农地承包 | 环境能源或相应领域 |
| 征收决定合法性 | 行政争议领域 |
| 施工价款工期质量 | 建设工程领域 |
| 名为合作实为共同开发 | `评估合作开发房地产争议` |
| 改出让合同文本 | 审查起草（本窗搁置） |
| 总体争议总图 | `评估房地产与物业争议` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

未过户不等于合同无效。一地数转不得按先接触的合同写成唯一物权。施工总包进场不是土地使用权转让履行完毕。
