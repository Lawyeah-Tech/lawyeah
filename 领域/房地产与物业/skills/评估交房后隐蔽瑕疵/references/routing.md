# 边界与路由

## 正触发

过户或入住后发现隐蔽质量或权利瑕疵。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 施工鉴定 | 建设工程领域 |
| 人身伤害 | 人身损害与侵权领域 |
| 交付当时质量 | `评估商品房交付质量与保修` |
| 现场保全 | `保全房屋现场与质量证据` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

入住后才发现不等于都能解除。怠于通知会削弱请求。权利瑕疵和质量瑕疵期间不同。
