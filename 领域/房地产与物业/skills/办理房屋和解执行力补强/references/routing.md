# 边界与路由

## 正触发

需要司法确认、仲裁调解书或公证赋强来补强和解执行力。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 宣称普通和解可执行 | 拒绝，必须明示无执行力 |
| 尚无和解文本 | `起草房屋和解协议` |
| 已有生效文书要执行 | `执行房地产生效文书` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

和解签字不等于能强制过户。赋强公证不当然覆盖腾退过户。调解书才是执行名义之一。
