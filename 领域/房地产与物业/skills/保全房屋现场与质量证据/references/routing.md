# 边界与路由

## 正触发

房屋现场或质量现状可能灭失，需要合法保全步骤。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 违法取证 | 整体停止 |
| 工程现场造价 | 建设工程领域 |
| 完整证据卷 | `建立房地产争议证据案卷` |
| 鉴定申请稿 | `准备房屋质量面积或价值鉴定` |
| 财产保全必要性 | `评估房屋财产保全必要性` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

现场保全不是财产保全。公证不是鉴定意见。不能为取证而违法。
