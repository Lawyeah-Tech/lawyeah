# 边界与路由

## 正触发

不动产合同争成立、认购转本约、无权处分、预售无效或可撤销。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 总体评估 | `评估房地产与物业争议` |
| 签前改稿 | 审查起草（本窗搁置） |
| 认购专项 | `评估认购书与预约合同效力` |
| 预售许可专项 | `评估预售许可与销售资格` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

未过户不是无效。成立失败与无效后果不同。撤销除斥不是诉讼时效。
