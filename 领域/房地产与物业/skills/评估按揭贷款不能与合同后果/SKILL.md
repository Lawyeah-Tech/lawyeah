# 评估按揭贷款不能与合同后果

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

判断担保贷款合同未订成时买卖合同能否继续、谁可归责、解除与返还，贷款、保证和抵押权实现转金融。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：买受人未能获得商品房担保贷款，双方争买卖合同是否解除及责任。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 贷款合同、保证责任或抵押权实现主轴;
- 只要总体评估;
- 要发解除通知;
- 民间借贷购房资金主轴;

本任务不给胜诉率，未知金额不写零。

## 建立坐标

确认：买卖合同按揭条款；是否已签贷款合同；拒贷理由；买受人是否提供虚假资料；出卖人是否配合；已付首付和定金。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。口头转述和“已读”不写成已受理、已送达或期限已起算。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`V#` 评估版本；`E#` 发送／送达／履行凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验商品房解释第 19、21 条。贷款合同效力与保证规则不在本任务展开。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　贷款合同是否订成

未批准、已批准未放款、已放款后提前收回分列，法律效果不同。

### 节点 2　可归责买受人

虚假收入、征信、拒不提供资料、改变贷款银行：买受人原因。

### 节点 3　可归责出卖人

房屋被查封、无预售许可、不配合抵押登记。

### 节点 4　不可归责双方

政策限贷、银行内部额度：可评估解除并返还已付款及利息或定金，不当然赔偿。

### 节点 5　金融分流

贷款合同纠纷、保证、抵押权实现整段转金融。解释第 21 条返还贷款人接口只标记。

## 停止与安全

- `整体停止`：用户坚持伪造收入流水继续骗贷。
- `字段停止`：解释第 19 条未核验。
- `目标停止`：主目标变为贷款诉讼或发送解除函。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
