# 边界与路由

## 正触发

担保贷款合同未订成，买卖双方要判断合同能否继续及责任。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 贷款保证抵押权实现 | 金融借贷担保领域 |
| 发解除通知 | `准备房屋买卖解除或退房通知` |
| 商品房解除总表 | `评估商品房解除退房路径` |
| 测算返还数字 | `测算购房款返还违约金与赔偿` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

拒贷不等于买受人必然违约。已放款断供不是本任务。返还可能要分账给银行。
