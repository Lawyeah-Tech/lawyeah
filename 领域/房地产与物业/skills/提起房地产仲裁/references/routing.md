# 边界与路由

## 正触发

有效仲裁协议且决定申请房地产或物业仲裁。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 起诉 | `提起房地产与物业纠纷一审` |
| 协议无效异议 | `准备房屋仲裁协议异议材料` |
| 被申请方材料 | `应对房地产仲裁` |
| 工程整案 | 建设工程领域 |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

有仲裁协议就不应出起诉终稿。申请仲裁不是应诉。机构名称错误会受理失败。
