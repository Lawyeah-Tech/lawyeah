# 边界与路由

## 正触发

实测或产权面积与约定不符，需要补退或退房分流。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 把已删第十四条当现行解释 | 拒绝写入必得，保持噪声处理 |
| 工程造价面积 | 建设工程领域 |
| 精算终稿 | `测算购房款返还违约金与赔偿` |
| 租赁面积 | `评估房屋租赁争议` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

管理办法第 20 条是规章参照，不是现行司法解释。已删解释第十四条不得复活。
