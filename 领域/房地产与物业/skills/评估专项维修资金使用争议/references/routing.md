# 边界与路由

## 正触发

维修资金列支、表决或挪用有争议。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 维修技术方案 | 不实施，可转鉴定机构 |
| 大会一般决议 | `评估业主大会决议效力` |
| 物业移交账目 | `评估物业承接查验与移交` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

紧急抢修不是自动合法列支。保修期内应找保修义务人。本任务不替代工程师方案。
