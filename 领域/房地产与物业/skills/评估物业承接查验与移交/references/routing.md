# 边界与路由

## 正触发

前期物业交接、资料或共有部位移交不能。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 工程质量鉴定 | 建设工程领域 |
| 业委会资格 | `评估业委会资格与越权` |
| 维修资金使用实体 | `评估专项维修资金使用争议` |
| 物业费 | `评估物业费与物业服务争议` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

移交不能不是工程鉴定。开发商和前期物业义务不同。不得以抢场代替移交请求。
