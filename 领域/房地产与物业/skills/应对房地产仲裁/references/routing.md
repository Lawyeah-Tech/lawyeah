# 边界与路由

## 正触发

收到房地产或物业仲裁申请，被申请方要答辩。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 申请仲裁 | `提起房地产仲裁` |
| 法院应诉 | `应对房地产与物业纠纷一审` |
| 协议异议专项 | `准备房屋仲裁协议异议材料` |
| 反请求终稿 | `准备房屋纠纷反诉或仲裁反请求` |

## 专项转出

建设工程价款、工期、质量鉴定或实际施工人整案转建设工程。一般买卖、服务、承揽、动产租赁等非不动产主轴转合同争议。未成争改合同或签前审查：审查起草领域（本窗搁置，只说明不实施）。C 端 109 相邻商品只分流，不回改。

## 易混

仲裁答辩期不是民诉答辩期。协议抗辩和实体抗辩要分开写。不要用起诉状模板硬套。
