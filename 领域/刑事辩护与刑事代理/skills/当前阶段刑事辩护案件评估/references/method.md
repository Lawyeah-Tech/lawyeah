# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变路径、机关、期限或请求范围的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然结果、机关必然受理或确定刑期。

`search_law` 返回已废止文本或已失效《合同法》及其解释时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。现行《刑事诉讼法》及有效司法解释未核验前，不得把记忆条号写成已核验。

禁止指导伪造、隐匿、串供、威胁证人、违法接触证人和违法取证。用户坚持上述行为时整体停止策略输出。

入口状态：已确认侦查机关、措施状态与当前权限。
主管机关或论坛：承办侦查机关或监督检察机关。
期限输入：措施采取日、期限与羁押状态。
最小证据：当前阶段与权限表、材料可靠性与缺口表。

---

## 节点 1　立场、阶段与权限闭合

先固定单一客户立场和可由文书支持的当前阶段，再决定评估深度。未闭合则整案字段停止。

| 条件 | 则 |
| --- | --- |
| 若 委托人、被追诉人与授权文书不能回链到同一主体 | 整体停止策略输出，只列身份和授权缺口 |
| 若 同时掌握同案其他被追诉人或被害方秘密且冲突未解 | 整体停止，不形成对任何一方有利的评估 |
| 若 阶段只能写成侦查、审查逮捕、审查起诉、审判或其他之一且有文书支持 | 在该阶段权限内评估；跨阶段合并评估标依据不足 |
| 若 当前阶段律师阅卷、会见或调查权限规则未核验 | 权限字段停止，不把无权取得的材料写成已核实 |
| 若 用户要的是接案或冲突筛查本身 | 负触发，转 `刑事接案资格与冲突筛查`（`Q-接`），不启动本评估 |

禁止写成：
- 把家属转述写成已核实的措施状态
- 在无权阅卷阶段假设完整案卷

---

## 节点 2　材料范围与可靠性

评估深度不得超过已提供材料。每份材料记来源、完整性、相反材料和核验状态。

| 条件 | 则 |
| --- | --- |
| 若 仅有口头案情而无文书或会见记录 | 只形成缺口清单，不写实体强弱 |
| 若 材料互相冲突且无法判断哪一方为机关记录 | 并列冲突，判断标依据不足 |
| 若 关键日期、案由或强制措施文书缺失 | 对应期限和措施字段停止 |
| 若 第三人传闻或媒体报道 | 不得升为已核实事实 |
| 若 用户要求补造缺失供述或书证 | 拒绝并停止相关结论 |

---

## 节点 3　程序、事实与责任争点分列

在材料范围内分列程序争点、事实争点和可能的责任争点，不合成一份定罪意见。

| 条件 | 则 |
| --- | --- |
| 若 材料只支持程序违法或期限问题 | 只评估程序路径，不写构成要件成立 |
| 若 指控事实在材料中存在替代解释 | 并列替代解释和最强反方，不选定唯一故事 |
| 若 责任形态、共同犯罪或单位犯罪信号出现但授权只覆盖一人 | 他人责任字段停止并提示冲突风险 |
| 若 用户要求直接给出无罪或罪名成立 | 目标停止；完整实体辩护转相应专项 |

禁止写成：
- 按罪名名称机械生成构成要件结论
- 输出胜诉率或量刑预测数字

---

## 节点 4　下一步选择而不固定组合

列出可改变现状的独立下一步，不规定强制顺序，不把本评估当作其他原子的技术依赖。

| 条件 | 则 |
| --- | --- |
| 若 强制措施仍在且取保或羁押必要性条件可核验 | 标为可转介的独立申请，不在本任务出具申请书 |
| 若 非法取证线索待核验且仍在侦查 | 转介线索保全，不写正式排除申请 |
| 若 已在审查起诉且不起诉路径成为主目标 | 目标停止，转不起诉专项 |
| 若 材料不足以支持任何改变现状的动作 | 只交付缺口和停止条件 |

---

## 节点 5　评估意见的条件性与停止

意见必须标明材料边界。规则未核验则法律字段停止。

| 条件 | 则 |
| --- | --- |
| 若 现行刑事诉讼法或有效解释未核验 | 法律结论和期限字段停止，事实索引可继续 |
| 若 评估将影响供述策略且会见尚未完成 | 不得指导如何陈述未发生的事实 |
| 若 用户要求承诺撤销案件、不起诉或改判 | 拒绝承诺，意见保持条件性 |

---

## 程序与期限表

程序动作记录机关、案号、文书、作出、收到、送达、效力。期限每行只对应一种期间类型和一个起算事件。关键日期冲突则并行情景，不选对用户最有利的一天。未知日期不得计算截止日。

## 证据与下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。下一步按期限灭失、易失证据、能否改变本成果争点、可逆性排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。

相邻专项申请、完整实体辩护、审查起草或未安装能力只写转介条件和最小交接，不在本方法生成那些终稿。
