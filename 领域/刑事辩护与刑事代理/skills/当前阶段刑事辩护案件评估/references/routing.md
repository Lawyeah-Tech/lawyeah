# 边界与路由

## 正触发

在已确认单一客户立场和当前程序阶段后，形成受材料范围限制的案件评估与下一步选择意见。

未确认授权时允许仅说明安全和停止事项；完成单一立场、授权、阶段和机关核验后，才进入本成果的条件性工作。本技能不评价是否接案或执业准入。`depends-on` 为空。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 接案授权或利益冲突筛查 | `刑事接案资格与冲突筛查` |
| 完整实体辩护意见 | `罪名与刑事责任辩护意见` |
| 审查逮捕专项 | `审查逮捕辩护意见` |
| 不起诉专项 | `审查起诉不起诉辩护意见` |
| 尚未成争或只要改合同、出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端 109 大众刑事问答 | 大众专项，只分流不回改 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 简易或速裁程序选择成为主目标 | P2 `assess-summary-expedited-procedure`，输出 unavailable |
| 监视居住合法性成为主目标 | P2，输出 unavailable |
| 以预防整改为目标的企业内部调查或合规项目 | 企业合规领域，只分流 |
| 行政处罚、许可、行政强制及其复议诉讼 | 行政争议领域，只分流 |
| 劳动调查、停职、处分、解除及其他用工后果 | 劳动领域，只分流 |
| 脱离刑事程序的一般侵权赔偿完整诉讼 | 人身损害或民事领域，只分流 |
| 境外当地刑事法、引渡或跨法域监管 | 涉外领域，只分流 |

## 易混

已确认单一立场和当前阶段、需要受材料限制的总体判断时正触发。只要接案筛查、或已决定做完整实体/不起诉/排非专项时负触发。不得把本评估写成全案胜诉判断。

## 最近邻边界

- `简易速裁程序选择评估`：独立触发，不自动调用或固定组合。
- `审查起诉认罪认罚决策评估`：独立触发，不自动调用或固定组合。
- `刑事附带民事请求评估`：独立触发，不自动调用或固定组合。

本技能不自动调用或固定组合相邻技能。目标成果未安装时输出 `unavailable`，不得由名称相近的已安装技能代做。
