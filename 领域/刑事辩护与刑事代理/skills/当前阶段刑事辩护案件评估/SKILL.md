# 当前阶段刑事辩护案件评估

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。刑事判断以现行《刑事诉讼法》及有效司法解释、规范性文件为准，废止文本不得写入结论。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在已确认单一客户立场和当前程序阶段后，形成受材料范围限制的案件评估与下一步选择意见。

仅服务于单一用户目标和独立成果：当前阶段与权限表；材料可靠性与缺口表；受限案件评估意见。不替代接案资格筛查，不扩展为相邻专项包，不承诺机关决定或裁判结果。`depends-on` 为空。接受用户、律师、机关或其他来源的合格等价事实、测算和证据清单。

## 工作边界

正触发：在已确认单一客户立场和当前程序阶段后，形成受材料范围限制的案件评估与下一步选择意见。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 接案授权或利益冲突筛查；
- 完整实体辩护意见；
- 审查起草或合同出稿（审查起草领域，本生产线搁置，只说明不实施）；
- C 端 109 大众刑事专项（只分流，不回改）。

本任务不给胜诉率，不指导伪造、隐匿、串供或违法取证。

## 建立评估坐标

确认：使用者与授权；单一客户立场；相对方及可能共同诉讼或同案主体；当前程序阶段与承办机关；关键文书作出与送达；已有材料范围及缺失；利益冲突筛查状态。同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 本成果范围内的争点或请求。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然排除或确定刑期。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验现行《刑事诉讼法》及有效解释中的条件、机关和期限；`search_practiced` 补路径与反例；特殊事实可用案例检索比较差异。不虚构案件系统。不得把已失效《合同法》当作现行规则。

工具不可用时继续事实、主体、程序文书状态和问题清单；法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　立场、阶段与权限闭合

先固定单一客户立场和可由文书支持的当前阶段，再决定评估深度。未闭合则整案字段停止。
### 节点 2　材料范围与可靠性

评估深度不得超过已提供材料。每份材料记来源、完整性、相反材料和核验状态。
### 节点 3　程序、事实与责任争点分列

在材料范围内分列程序争点、事实争点和可能的责任争点，不合成一份定罪意见。
### 节点 4　下一步选择而不固定组合

列出可改变现状的独立下一步，不规定强制顺序，不把本评估当作其他原子的技术依赖。
### 节点 5　评估意见的条件性与停止

意见必须标明材料边界。规则未核验则法律字段停止。


## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体、阶段或机关无法建立；用户坚持伪造、隐匿、串供、威胁证人或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为相邻专项成果、审查起草或未安装能力。

禁止指导伪造、隐匿、串供、威胁证人、违法取证或规避强制措施。合法部分仍按输出合同交付或停止。不给胜诉率，不承诺机关决定或裁判结果。未知金额不写零。
