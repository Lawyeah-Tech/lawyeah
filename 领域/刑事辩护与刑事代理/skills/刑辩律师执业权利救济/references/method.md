# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变路径、机关、期限或请求范围的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然结果、机关必然受理或确定刑期。

`search_law` 返回已废止文本或已失效《合同法》及其解释时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。现行《刑事诉讼法》及有效司法解释未核验前，不得把记忆条号写成已核验。

禁止指导伪造、隐匿、串供、威胁证人、违法接触证人和违法取证。用户坚持上述行为时整体停止策略输出。

入口状态：已确认侦查机关、措施状态与当前权限。
主管机关或论坛：承办侦查机关或监督检察机关。
期限输入：措施采取日、期限与羁押状态。
最小证据：受阻事实记录、救济路径意见。

---

## 节点 1　受阻事实与权利类型

先固定受阻的具体执业权利、时间、场所、相对机关和在场记录，不把一般不便写成侵权。

| 条件 | 则 |
| --- | --- |
| 若 无法指出被拒绝的会见、阅卷、调查或庭审动作 | 依据不足，不启动救济材料 |
| 若 受阻发生在依法尚不可会见或尚不可阅卷的阶段 | 先核验阶段权限；权限不支持则不写侵权成立 |
| 若 仅有律师单方陈述、无《拒绝理由说明书》或其他回链记录 | 事实标单方主张，不得写成已核实侵权 |
| 若 争议是律师与当事人之间的收费或纪律 | 负触发，转一般执业纪律，不走本任务 |

---

## 节点 2　法定救济机关与顺序

运行时核验现行刑事诉讼法及律师法、保障律师执业权利规定后再选机关。

| 条件 | 则 |
| --- | --- |
| 若 侦查阶段会见被无合法理由拒绝 | 评估向承办机关、驻所检察或依法有权机关提出的路径，不代提交 |
| 若 阅卷被拒绝或限缩超出法定范围 | 评估向承办检察机关或受理法院提出的路径 |
| 若 庭审中剥夺辩护或质证机会 | 记录当庭异议和庭后书面异议接口，不补造庭审笔录 |
| 若 机关路径或级别规则未核验 | 机关字段停止 |

禁止写成：
- 同时向全部可能机关群发同一指控并保证受理

---

## 节点 3　与实体辩护、排非、侦查违法的分界

执业权利救济不等于当事人实体意见，也不等于非法证据排除。

| 条件 | 则 |
| --- | --- |
| 若 真正目标是排除某份口供或物证 | 负触发或并行转介排非专项，本任务只保留执业受阻事实 |
| 若 真正目标是控告刑讯或超期羁押本身 | 转侦查违法申诉，本任务只处理律师履职受阻 |
| 若 需要同时形成被告人无罪意见 | 实体部分停止，转罪名责任专项 |

---

## 节点 4　材料与安全

救济材料只使用可回链的受阻记录，不泄露会见秘密和案卷原文。

| 条件 | 则 |
| --- | --- |
| 若 材料将复制讯问笔录或同步录音录像全文 | 只摘必要标识，不整卷外传 |
| 若 存在对律师或在押人员的即时人身危险 | 先安全分流，再写救济 |
| 若 用户要求伪造《拒绝会见通知》或改写时间 | 整体停止 |

---

## 节点 5　条件性救济方案

只形成可复核的投诉、申诉或控告草案索引，不承诺查处结果。

| 条件 | 则 |
| --- | --- |
| 若 受阻事实现有依据支持且机关可核验 | 形成条件性救济方案和材料目录 |
| 若 受阻事实依据不足 | 只交付补证清单 |
| 若 规则未核验 | 法律路径字段停止 |

---

## 程序与期限表

程序动作记录机关、案号、文书、作出、收到、送达、效力。期限每行只对应一种期间类型和一个起算事件。关键日期冲突则并行情景，不选对用户最有利的一天。未知日期不得计算截止日。

## 证据与下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。下一步按期限灭失、易失证据、能否改变本成果争点、可逆性排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。

相邻专项申请、完整实体辩护、审查起草或未安装能力只写转介条件和最小交接，不在本方法生成那些终稿。
