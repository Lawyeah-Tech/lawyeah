# 边界与路由

## 正触发

在会见、阅卷、调查取证或庭审履职受阻时，形成可提交的律师执业权利救济方案与材料。

未确认授权时允许仅说明安全和停止事项；完成单一立场、授权、阶段和机关核验后，才进入本成果的条件性工作。本技能不评价是否接案或执业准入。`depends-on` 为空。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 一般律师执业纪律或收费争议 | 律师行业管理或民事路径，只分流 |
| 为当事人形成实体辩护意见 | `罪名与刑事责任辩护意见` |
| 正式非法证据排除 | 按阶段转起诉或法院排非原子 |
| 处理一般律师执业纪律争议 | 负触发，不启动本任务 |
| 尚未成争或只要改合同、出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端 109 大众刑事问答 | 大众专项，只分流不回改 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查违法本身而非律师履职受阻 | `侦查违法申诉控告` |
| 以预防整改为目标的企业内部调查或合规项目 | 企业合规领域，只分流 |
| 行政处罚、许可、行政强制及其复议诉讼 | 行政争议领域，只分流 |
| 劳动调查、停职、处分、解除及其他用工后果 | 劳动领域，只分流 |
| 脱离刑事程序的一般侵权赔偿完整诉讼 | 人身损害或民事领域，只分流 |
| 境外当地刑事法、引渡或跨法域监管 | 涉外领域，只分流 |

## 易混

会见、阅卷、调查或庭审履职被具体拒绝或限缩时正触发。只要纪律处分、实体辩护或排非时负触发。不要把看守所安检耗时单独写成剥夺会见权。

## 最近邻边界

- `侦查阶段非法取证线索保全与监督材料`：独立触发，不自动调用或固定组合。
- `审查起诉阶段正式非法证据排除申请`：独立触发，不自动调用或固定组合。
- `侦查违法申诉控告`：独立触发，不自动调用或固定组合。

本技能不自动调用或固定组合相邻技能。目标成果未安装时输出 `unavailable`，不得由名称相近的已安装技能代做。
