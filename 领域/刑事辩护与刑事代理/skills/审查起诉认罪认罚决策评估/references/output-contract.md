# 输出合同

## 事实与证据链

每条事实记录固定包含：`factId`、主体/阶段/机关/措施、事实或主张、事实来源类别、具体材料/页码或记录标识、取得方式与日期、证明对象、核验状态、相反材料、限制和下一步。法律结论另有固定元数据：`jurisdiction`、`lawVersionOrEffectiveDate`、`citation`、`applicability`、`checkedAt`、`ruleStatus`。事实来源类别仅可使用原件/可回链副本、机关正式电子记录、当事人本人陈述、第三方转述、现场观察；不得以转述升级为已核实事实。

## 正常输出

每项成果给出结论、依据、反向事实、未闭合事项和限制。

1. **证据标准与自愿性核验表**
2. **法律帮助、量刑建议、意见期和录像核验表**
3. **具结/反悔/程序转换决策意见**
4. **风险、限制和停止条件**

## 每项成果的固定字段

每个正常成果都必须依次包含：`scopeAndStage`、`stageConfirmation`、`actorAndAuthority`、`factRows`、`evidenceRows`、`ruleRows`、`issueMap`、`counterMaterials`、`actionRows`、`deadlineRows`、`uncertainties`、`privacyRedactions`、`dataHandling`、`humanReviewRequired`。`stageConfirmation`记录当前/拟进入阶段、明确肯定回复、时间、会话标识和披露范围；`evidenceRows`记录证据类型、原件/复制件及载体、真实性/完整性、取得与保管转移链、取证合法性/可采性、保存风险、链条断点和反向材料；关键字段或法源引文缺失时仅待核验/停止。`dataHandling`记录输入、工具参数、日志/缓存、输出和导出的脱敏、访问、保留、删除限制；原始卷宗、特权材料、第三方个人信息不得原样进入工具、日志、缓存或非必要输出。`issueMap`仅映射本成果范围内的程序问题或明确的待核验实体问题，不代表事实或犯罪成立。结论只能使用条件性状态（已核实/支持/不支持/冲突/待核验/停止），不得作事实真伪、犯罪成立、机关必然受理或裁判结果保证。

## 期限与动作字段

任何期限或程序动作必须记录：`procedureStage`、`status`、`deadlineType`、动作主体、受理机关、启动事件、起算日期/时刻/时区、自然日或工作日口径、期间、届满时间、节假日/送达瑕疵/延长或补救条件、所需授权和材料、提交方式与回执、逾期后果、失败升级路径及核验人；每条记录仅对应一个阶段、一个启动事件和一种期限类型，关键字段不明时不计算截止日。

## 停止输出

按‘停止原因 → 成果状态：因停止条件未形成 → 最小补充事项’输出，不开始相邻 Skill 的实体工作，不承诺机关或法院结果。

## 安全输出

拒绝串供、毁证、伪造、冒充、威胁证人、非法取证、泄露他人秘密和规避期限；合法部分仍按本合同交付或停止。
