# 边界与路由

## 正触发

在审查起诉拟具结前核验认罪认罚的证据标准、自愿真实性、法律帮助、量刑建议、意见期及录音录像条件，形成是否具结的决策意见。 未确认授权时允许仅启动 A 阶段安全三分流和停止/升级输出；完成安全三分流、最小输入及主体身份、权限、授权与冲突状态的可回链确认后，才进入 B 阶段文书核验和 C 阶段法源核验及条件性成果。本 Skill 不评价是否接案、是否建立代理关系或执业准入资格。

## 路由键

- 入口状态：A 阶段仅需安全风险、最小身份和程序状态；B 阶段再确认法域、当前日期/时区、主体及特殊身份、阶段、措施、机关、文书日期和授权/冲突；C 阶段还需逐项法源引文。缺失时停留在对应阶段，不输出确定法律结论。
- 主管机关或法院：按文书和阶段核验，不凭常识推定。
- 期限输入：送达日、措施采取日、申请或开庭节点；未知则不得给确定期限。
- 最小证据：审查起诉阶段与指控范围、证据和供述材料、具结书、量刑建议和意见期通知。

## 最近邻边界

`审查起诉不起诉辩护意见`、`首次在押会见与权利处置`、`简易速裁程序选择评估`；本 Skill 不自动调用或固定组合相邻 Skill。

## 负触发与停止

接案身份、法域、阶段、机关、期限、授权、证据或冲突未闭合时停止；即时安全风险先转紧急服务和合格律师；纯负触发只说明不启动本成果和安全路由，不生成相邻成果。

目标成果未安装时输出 `unavailable`，不得由本 Skill 代做，也不得把未安装原子的标识当成已安装入口。
