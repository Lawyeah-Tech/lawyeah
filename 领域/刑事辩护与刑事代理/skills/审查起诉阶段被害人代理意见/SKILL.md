# 审查起诉阶段被害人代理意见

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是运行本技能的强制依赖。

## 任务与边界

在审查起诉阶段为被害人形成事实证据、罪名责任、追赃退赔和量刑方面的代理意见。

仅服务于单一用户目标和独立成果：被害人代理争点表；审查起诉代理意见；证据、损失和退赔附件目录；安全、风险和后续路由。不替代接案资格筛查，不扩展为完整案件代理，不承诺机关决定或裁判结果。`dependsOn: []`。

## 不处理范围

- 被告人不起诉辩护
- 不服不起诉决定后的申诉

## 最小输入

- 被害人身份和代理授权
- 审查起诉阶段与承办检察机关
- 起诉意见或指控范围
- 损失、退赔、谅解和安全材料
- 被害人程序参与需求
- 适用法域、当前日期和时区、适用法律版本或待核验状态
- 主体身份（犯罪嫌疑人、被告人、被害人、证人或第三人）、年龄及未成年人/身心障碍/语言等特殊状态
- 诉讼阶段、措施类型、承办机关、关键文书、采取/送达时间及其原件或可回链副本
- 官方案由/指控罪名或待核验条文（仅在确实影响本成果路径时收集去标识化摘要）
- 委托与授权证明、利益冲突筛查状态、允许采取的动作范围
- 仅收集完成本成果所需的最小个人信息；第三方信息脱敏，无法安全处理时停止

## 适用前置与安全分流

1. 未授权 A0 阶段仅允许不含案件事实的通用安全三分流、停止原因和最小非案件问题；先验证当前用户身份/关系及授权证明的可回链状态，验证前不确认人员是否被传唤、拘留、搜查或失联及其程序状态。身份或授权无法验证时停止并提示由本人、已核验的法定代理人或合格律师重新发起。
2. 完成身份/关系/授权门禁后进入授权后 A 阶段，再做安全三分流（即时危险/医疗或失踪风险/无即时危险），再询问最小缺失信息；前一阶段不收集完整卷宗、无关身份或第三方秘密。
3. A 阶段只收集安全风险、最小身份和程序状态，固定输出安全状态、停止/升级原因和下一步最小问题；B 阶段在 A 通过后才收集可回链文书、法域、日期和授权，固定输出缺失/冲突字段、文书回链状态、授权/冲突状态和进入 C 阶段门槛；C 阶段在 B 通过后输出：有法源引文时写条件性法律成果；无法源引文时法律字段停止，仍交付已核验的非法律事实、缺口和最小补充事项。每次阶段转换前要求用户确认，禁止复制不必要的原文。
4. 法域、阶段、主体、机关、措施、官方案由、日期或适用规则缺失/冲突时，不输出确定的权利、期限、机关或法律结论，只输出待核验事项。
5. 出现即时人身危险、医疗急症、自伤风险、疑似非法限制自由、失踪或脆弱人员风险时，先提示联系当地紧急服务、医疗机构或合格律师；仅在确认安全、必要且获适格授权时联系家属，不得把失联推定为刑事措施。
6. 仅在授权和冲突边界闭合后生成本成果范围内的条件性草案、核验表或路径意见；不得代提交、联系机关、冒充用户/律师，完整实体辩护或相邻救济文书一律停止。
7. 任何法律结论必须逐项绑定法域、法源名称/版本或生效日、条文引文、适用前提、核验时间、相反材料和条件性结论；法源工具无结果时法律结论字段停止，不中断主流程。

## 执行方法

1. 先核验被害人代理主体、阶段、检察机关和授权范围
2. 分开定罪责任意见、证据意见、损失退赔意见和量刑意见
3. 对每项主张标明卷内证据、被害人陈述、相反材料和可申请核实事项
4. 处理谅解、退赔、和解和安全风险时不得施压或承诺刑事结果
5. 按审查起诉节点形成可提交意见和附件目录，区分后续庭审代理

## 阶段与主体门禁

- 主体角色只从：犯罪嫌疑人、被告人、被害人、控告人、自诉人、证人、第三人、近亲属、保证人、法定代理人、辩护人、诉讼代理人、机关工作人员中选择，并记录关系和权限；不明则停止。
- 程序状态只从：未受案、已受案未决定、立案侦查、审查起诉、审判中、判决/裁定后未生效—上诉准备期、上诉中、决定后救济中选择；记录具体审级、当前节点、状态变更事件和文书依据，禁止跨状态合并期限或动作。
- 只有当本成果目标明确要求实体定性时，才把官方案由/罪名作为待核验问题映射；其他成果仅核验影响本阶段动作的程序前提，禁止形成犯罪成立、实体抗辩或完整罪名意见。
- 任何代理、申请或提交成果均须记录申请主体资格、授权范围、受理机关、提交方式和“不代提交、不联系机关、不冒充用户或律师”的外部动作边界。
- `search_law` 仅接受指定法域内可回链的官方或批准标准法源；必须返回规范名称、发布机关、版本/生效日、逐项原文引文、适用前提、检索时间和来源标识。实践、模板、类案或权威性不明的结果不满足法源门禁，法律字段停止。
- 含法律规则、期限、机关路径、申请或权利处置的 C 阶段成果必须标记 `humanReviewRequired: true`；合格刑事法律专业人员确认前只能输出草案、核验表、缺口和停止事项，不得作为最终意见、提交文件或外部行动依据。


## 高风险停止

- 被害人身份、授权或阶段不明
- 损失或责任主张只有推测且无证据链
- 要求威胁、诱导谅解或泄露被追诉方秘密
- 把被告侧不起诉辩护或不服不起诉救济混入
- 法域、阶段、主体、机关、文书日期或授权缺失且会改变结论
- 需要写法律结论、期限或机关路径，但工具不可用、法源冲突或无法获得逐项引文（只停止这些字段，不拒绝执行）
- 任何即时安全风险未先完成合法紧急升级


## 输出

1. 被害人代理争点表
2. 审查起诉代理意见
3. 证据、损失和退赔附件目录
4. 安全、风险和后续路由

输出必须逐字段保留材料来源、核验状态、反向材料和限制；采用三阶段渐进披露：A 安全与最小身份/状态，B 文书/授权/法域核验，C 法源核验后的条件性成果；未通过前一阶段不得展开下一阶段或复制敏感材料。每次阶段转换必须记录明确肯定回复、时间、会话标识和披露范围；没有可审计确认时停留在当前阶段。关键事实缺失或冲突时只交付停止形状，不补造事实。法源工具不可用、无结果或冲突时不拒绝执行、不中断主流程：交付 A/B 已核验的非法律事实索引、缺口和最小补充事项；法律结论、期限、机关路径、申请或质证建议字段停止，不得编造法源。
