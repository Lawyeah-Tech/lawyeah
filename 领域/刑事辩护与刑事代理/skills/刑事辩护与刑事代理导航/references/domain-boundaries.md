# 刑事领域边界

本表只说明成果归属。每次路由先核对[当前能力地图](capability-map.md)；刑事侧入口未安装时输出 `unavailable`，不得由相邻 Skill 或名称相近的刑事 Skill 代替。

| 相邻领域 | 刑事侧成果 | 转交相邻领域的独立成果 |
| --- | --- | --- |
| 企业合规 | 具体刑事案件的控告、辩护、被害人代理和刑事责任意见 | 以预防、整改、制度建设或企业治理为目标的内部调查与合规项目 |
| 行政争议 | 刑事强制措施、侦查行为和刑事责任相关程序成果 | 行政处罚、许可、行政强制及其复议诉讼成果 |
| 劳动用工 | 员工涉嫌犯罪后的刑事控告、辩护和刑事责任 | 劳动调查、停职、处分、解除及其他用工后果 |
| 人身损害 | 被害人刑事程序权利及依法属于刑事程序的附带民事成果 | 脱离刑事程序的一般侵权责任和完整民事赔偿诉讼 |
| 数据隐私 | 具体刑事案件中的电子数据证据审查和程序申请 | 数据处理合法性、个人信息影响评估、跨境和网络安全治理 |
| 涉外 | 中国大陆刑事案件的辩护和代理 | 境外当地刑事法、引渡司法协助、制裁出口管制及跨法域准入专项成果 |
| 合同与一般民商事 | 行为是否具有刑事可追诉性以及刑事程序成果 | 合同履行、违约、解除、民事请求与商事争议解决成果 |

同一事实可能同时产生多个领域的独立成果。刑事 Skill 只处理其明确声明的刑事目标，不以刑事风险为由接管企业治理、劳动处分、行政诉讼、侵权赔偿、数据治理或一般民商事方案。

医学诊断、电子数据鉴定、会计审计、资产评估、精神状态鉴定和其他需要法定或专业资质的技术结论，应由适格机构或专业人员提供。刑事 Skill 可以核验其程序地位和证据限制，不补造技术结论。
