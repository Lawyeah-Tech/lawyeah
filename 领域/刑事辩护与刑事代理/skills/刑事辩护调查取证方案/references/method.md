# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变路径、机关、期限或请求范围的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然结果、机关必然受理或确定刑期。

`search_law` 返回已废止文本或已失效《合同法》及其解释时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。现行《刑事诉讼法》及有效司法解释未核验前，不得把记忆条号写成已核验。

禁止指导伪造、隐匿、串供、威胁证人、违法接触证人和违法取证。用户坚持上述行为时整体停止策略输出。

入口状态：案件已进入审查起诉或收到相应决定。
主管机关或论坛：承办案件检察机关。
期限输入：移送日、决定或具结拟定日、送达日。
最小证据：调查目标表、取证路径与权限矩阵。

---

## 节点 1　争点与缺口对齐

每项调查目标必须对应一个已识别争点和缺口，禁止无目标摸底。

| 条件 | 则 |
| --- | --- |
| 若 没有争点或缺口，只要求“全面调查” | 依据不足，不形成方案 |
| 若 缺口可通过已有阅卷解决 | 先转或提示阅卷原子，不重复调查 |
| 若 目标是寻找可以威胁证人改口的材料 | 整体停止 |

---

## 节点 2　路径与权限矩阵

自行收集、申请检察院或法院调取、申请证人出庭，分列资格和风险。

| 条件 | 则 |
| --- | --- |
| 若 对象是被害人或者控方证人 | 禁止指导私下会见；只写申请机关通知或出庭 |
| 若 对象是不反对接受律师访问的知情者且无妨害诉讼迹象 | 可列入自行访问方案，并写明告知身份、禁止诱导 |
| 若 需要查询通讯、行踪或银行明细 | 只写向有权机关申请 |
| 若 律师在侦查阶段调查权限规则未核验 | 该路径字段停止 |

禁止写成：
- 设计陪同作伪证或统一口径
- 指导隐匿对委托人不利的物证

---

## 节点 3　合法性与安全控制

方案必须含利益冲突、保密、人身安全和违法红线。

| 条件 | 则 |
| --- | --- |
| 若 调查可能暴露在押人员与案外人员的串通渠道 | 删除该动作 |
| 若 存在打击报复风险 | 改走机关调取并作安全提示 |
| 若 需要录音录像 | 只在合法知情同意和当地规则核验后列入 |

---

## 节点 4　与保全、调取申请、出庭方案的分界

本任务出总方案，不代替具体申请书或出庭提纲。

| 条件 | 则 |
| --- | --- |
| 若 主目标已收缩为向检察院或法院提交调取申请 | 转 `apply-evidence-collection` |
| 若 主目标是侦查阶段灭失风险 | 转保全方案 |
| 若 主目标是证人鉴定人出庭 | 转出庭询问方案 |

---

## 节点 5　不实施

明确本技能不代打电话、不代见面、不代取证。

| 条件 | 则 |
| --- | --- |
| 若 用户要求现在就联系证人 | 目标停止，只保留书面方案 |
| 若 规则未核验 | 权限字段停止 |

---

## 程序与期限表

程序动作记录机关、案号、文书、作出、收到、送达、效力。期限每行只对应一种期间类型和一个起算事件。关键日期冲突则并行情景，不选对用户最有利的一天。未知日期不得计算截止日。

## 证据与下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。下一步按期限灭失、易失证据、能否改变本成果争点、可逆性排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。

相邻专项申请、完整实体辩护、审查起草或未安装能力只写转介条件和最小交接，不在本方法生成那些终稿。
