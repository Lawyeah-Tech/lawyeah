# 边界与路由

## 正触发

围绕指控事实、构成要件、责任形态和排除责任事由形成实体辩护意见。

未确认授权时允许仅说明安全和停止事项；完成单一立场、授权、阶段和机关核验后，才进入本成果的条件性工作。本技能不评价是否接案或执业准入。`depends-on` 为空。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 仅形成量刑情节意见 | `量刑辩护意见` |
| 按罪名机械生成结论 | 拒绝 |
| 审查起诉不起诉专项 | `审查起诉不起诉辩护意见` |
| 尚未成争或只要改合同、出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端 109 大众刑事问答 | 大众专项，只分流不回改 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 单位主体资格或单位意志成为主轴 | 转单位犯罪专项 |
| 以预防整改为目标的企业内部调查或合规项目 | 企业合规领域，只分流 |
| 行政处罚、许可、行政强制及其复议诉讼 | 行政争议领域，只分流 |
| 劳动调查、停职、处分、解除及其他用工后果 | 劳动领域，只分流 |
| 脱离刑事程序的一般侵权赔偿完整诉讼 | 人身损害或民事领域，只分流 |
| 境外当地刑事法、引渡或跨法域监管 | 涉外领域，只分流 |

## 易混

需要围绕指控要件和责任形成实体辩护时正触发。只要量刑数字、或按罪名名套结论时负触发。

## 最近邻边界

- `量刑辩护意见`：独立触发，不自动调用或固定组合。
- `审查起诉不起诉辩护意见`：独立触发，不自动调用或固定组合。
- `单位犯罪责任人员专项辩护意见`：独立触发，不自动调用或固定组合。

本技能不自动调用或固定组合相邻技能。目标成果未安装时输出 `unavailable`，不得由名称相近的已安装技能代做。
