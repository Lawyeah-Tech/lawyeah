# 刑事接案资格与冲突筛查方法

本文件是可执行判断节点。家属不是客户。付款人不是委托人。口头同意不是授权。值班安排不是本案辩护人。筛查结论不是已接受委托。信息隔离不是冲突已治愈。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已接案、无冲突终稿、选定机关、代提交、未知写零。本任务不定罪，不保证可接，不代会见，不执行发送。本窗闸名只能是接案闸，禁止复用冲突闸、筛查闸、资格闸、评估闸、会见闸。预留不得占用：立案闸、调查闸。本窗 `JB#` 是接案行。主路径只用 `Q-接`，禁止用 `Q-筛`、`Q-冲`、`Q-总`、`Q-诉`、`Q-辩`、`Q-签` 作主路径。英文 id 禁止使用，一律用中文技能名 `刑事接案资格与冲突筛查`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 2012 年刑事诉讼法第三十三条当现行在押代委托、第三十七条当现行会见、把律师法第三十九条写成可口头豁免、把值班安排写成已有辩护人时记为噪声。禁止指导伪造授权、规避冲突、泄密或选边。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。
`JB#` 固定列：`编号｜主体切片（客户/委托人/付款人/单位）｜授权路径｜冲突｜打开接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。一行一切片。无 `E#` 不得写已核实、已接受、无冲突。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-接`。禁止 `A#`、`N#`、`JS#`、`SC#` 作主行。

口头「家属就是客户」「付了就能接」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：律所统一接受委托并做冲突审查。同案或关联被告人不得由同一辩护人辩护。同所不得同时担任被告辩护人与被害人代理人。在押代委托成立后须在首次可能联系时确认本人意愿。

## 节点 0　分流、立场、接案闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造授权、规避已确定冲突、泄密、冒充、违法取证不进负表。利益冲突未解不进整体停止。不定罪、不保证可接、不代提交不是负触发。禁止把会见闸、紧急闸、评估闸写进本窗节点 0。

整案转出只交付第 1、2、10 节，不出 `JB#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是紧急行动方案 | 负触发 `刑事紧急响应方案` |
| 主成果是首次会见提纲 | 负触发 `首次在押会见与权利处置` |
| 主成果是阶段案件评估 | 负触发 `当前阶段刑事辩护案件评估` |
| 主成果是控告可追诉性 | 负触发 `刑事控告可行性评估` |
| 主成果是自诉入口可行性 | 负触发 `刑事自诉可行性评估` |
| 主成果是单位侧意见 | 负触发 `单位犯罪被追诉单位专项辩护意见` |
| 主成果是责任人员侧意见 | 负触发 `单位犯罪责任人员专项辩护意见` |
| 主成果是速裁／简易程序选择 | `unavailable`，本窗不代评 |
| 「不定罪」「不保证可接」「不代提交」 | 交付禁令，不是负触发 |

出现「接案」「冲突」一词不是转出。

接案闸打开（可出 `JB#` 草案，仍不得标「已接受／已接案」）须同时满足：单方无冲突立场已闭合且互斥；主成果是接案筛查，不是紧急方案、会见或实体意见；至少一项可编号主体或路径碎片。口头「家属就是客户」「付了就能接」不算单独开闸材料。

接案闸部分打开：已有碎片，但授权链、本人意愿、阶段或冲突记录未闭合；对应格待核；仍交十节。无书面筛查授权但单方立场已闭合且已有碎片：接案闸部分打开，仍交十节，不是整体停止。两阶段路径（在押代委托或本案法援决定／指派其他门闭合、本人客观暂不可联系）：部分打开，第 6 节只出受限初始承接草案，范围锁在首次会见及确认本人意愿。

接案闸关闭（仍正触发）：无一可编号碎片。「今天必须出已接案终稿」而无最小碎片不得开闸。不出 `JB#` 终稿。**仍交十节**，第 5 节只交闸／`Q-接`，第 6 节不出 `JB#` 终稿，**第 7 节不得出会见方案、紧急行动或委托合同**。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「没有冲突」或「已经接了」。

「保证今晚必须接案」「家属就是客户」「口头即授权」「付款即已接」「值班即辩护人」「先接再补手续」「信息隔离即无冲突」「法援口头通知即本案指派」「单位授权即个人辩护」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `JB#` 草案。冲突未闭合不得写限定范围接受，窗口不关。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 接案闸关闭，仍交十节，不是整体停止。
若 if 同时掌握对立双方相互冲突的秘密，或两造争同一份接案结论，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造授权、规避已确定冲突、泄密、冒充或违法取证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体切片与资格路径

一行一个主体或路径切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `JB#` 终稿。

| 路径 | 允许 | 禁止 |
| --- | --- | --- |
| 本人委托 | 本人意愿、书面委托、律所受理 | 付款人决定范围 |
| 在押代委托 | 在押、关系、书面代委托；其余门闭合且本人暂不可联系时仅受限初始承接 | 代办人决定实体策略 |
| 被害人等代理 | 主体、阶段、代理委托 | 套用被追诉人辩护路径 |
| 单位与责任人员 | 单位授权只覆盖单位；个人须独立委托 | 一方替另一方决定 |
| 法援决定／指派 | 本案决定与指派文书 | 一般资格或口头通知替代 |
| 值班法律帮助 | 仅法律帮助范围 | 升格本案辩护人 |

检索锚点（写入 `L#` 前须核验）：刑事诉讼法 2018 第三十三条、第三十四条；噪声 2012 年第三十三条、第三十七条。刑诉解释 2021 第四十三条。律师法第二十五条、第三十三条、第三十九条。律师事务所管理办法第四十六条。法律援助法第十四条、第二十四条、第二十五条、第二十七条。办理法律援助案件程序规定 2023 第二十八条。法释〔2025〕9 号。

## 节点 3　接案行 `JB#`

按已出现主体或路径扫描，不是默认闭集。每一行须能指向客户切片、授权路径或冲突之一。

无 `E#` 不得写已核实、已接受或无冲突。状态默认 `草案`。一次只推荐下一步。未知不写零。冲突记录未调取不得写成无冲突。禁止性冲突已核验：出拒绝／转介草案，不是整体停止。

热冲突强制处理：

- 保证今晚必须接／家属即客户／口头即授权／付款即已接／值班即辩护人／隔离即无冲突／未知写零 → 该格不支持或字段停止；仍出其他 `JB#`。
- 无一碎片 → 关闸，不出 `JB#` 终稿，窗口不关。
- 冲突未闭合 → 不得写限定范围接受；仍出角色与冲突缺口行。
- 伪造授权、规避已确定冲突、双方秘密 → 整体停止。

两阶段路径：范围只能是首次会见及确认本人意愿。本人已可联系却拒绝确认、明确拒绝或另有辩护人：停止／调整／退出该承接。

## 节点 4　紧急、会见与案件评估接口

第 7 节只开接口，不得夹带 `JB#` 终稿、委托合同或会见提纲绕闸。闸关闭时第 7 节可写「闸未开，转介待主体编号」，不得补写已接受。不选定机关。不代提交。不定罪。不保证可接。

下一步只转介：`刑事紧急响应方案`、`首次在押会见与权利处置`、`当前阶段刑事辩护案件评估`、`取保候审申请`、`审查逮捕辩护意见`、`刑事阅卷与证据体系审查`、`审查起诉不起诉辩护意见`、`审查起诉认罪认罚决策评估`、`刑事控告可行性评估`、`刑事控告材料包`、`审查起诉阶段被害人代理意见`、`刑事判决或裁定上诉评估`、`不予立案或逾期未立案救济`、`刑事自诉可行性评估`、`刑辩律师执业权利救济`、`侦查阶段辩护意见`、`单位犯罪被追诉单位专项辩护意见`、`单位犯罪责任人员专项辩护意见`。禁止此致某局某院。禁止转介本窗完成规避冲突。

若 if 用户催促「家属就是客户／付了就能接／今晚必须接／不清楚先写没冲突」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 再执行清单

每个节点结束后回写：来源、判断、最强反方、是否字段停止。不得跳过接案闸直接给已接受或无冲突。

若 if 资格路径、授权、法援规则、冲突可继续性、施行日未核验，then 该强制项字段停止，窗口不关。
判断状态只许三值。口头「付了就能接」不得写成 `JB#` 已接受。未知不写零。

## 本任务回链纪律

本任务成果是「接案闸与接案行草案」。本窗不执行发送。不包含：已接受证明、委托合同终稿、会见提纲、紧急行动、实体意见、无冲突证明。禁止选边治愈。禁止家属即客户。禁止口头即授权。禁止值班即辩护人。接案闸打开 ≠ 已接受 ≠ 无冲突 ≠ 已会见。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标接案终稿已形成。
风险档 A：伪造授权、规避冲突、泄密必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：丈夫在押，妻子付款并口头说「你们先接，冲突以后再说」，同时要接同案另一被告人。用户主张家属就是客户、付了就能接、隔离墙就能两边都接、今晚必须有人进去。接案闸打开或半开。`Q-家`、`Q-付`、`Q-口`、`Q-隔`、`Q-签` 不打开为可靠路径。第 6 节不得把已接受、无冲突、两边都接写入可执行 `JB#`；对应格 `现有依据不支持`；仍出主体分列、在押代委托两阶段、同案冲突拒绝／转介等其他 `JB#`。不关窗。不代会见。不定罪。

场景②：用户同时交出被追诉人家属委托草稿与被害人代理意向，要求选对所里有利的一版，并指导「授权书日期改到上周」。命中双方秘密＋伪造授权。第一次整体停止。只交第 1、10 节。不出 `JB#`。不得问代表哪一方后继续。不以「坚持」为门槛。
