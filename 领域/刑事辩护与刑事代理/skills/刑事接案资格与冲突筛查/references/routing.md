# 边界与路由

## 正触发

实质刑事工作开始前，主成果是客户、资格路径、授权与冲突筛查。授权、本人意愿或冲突记录未闭合仍正触发：有可编号碎片则闸开或半开，出 `JB#` 草案，保持草案。本次不定罪、不保证可接、不代提交是交付禁令，不是开窗条件。保证今晚必须接案、家属即客户、口头即授权、付款即已接、值班即辩护人、先接再补手续，仍正触发。

双方秘密、伪造授权、规避已确定冲突、泄密、冒充、违法取证的停止，优先于负触发。上述信号不在下表。不定罪不是负触发。「保证今晚必须接案」「家属就是客户」不在下表。伪造授权不在下表，走整体停止。

## 易混
