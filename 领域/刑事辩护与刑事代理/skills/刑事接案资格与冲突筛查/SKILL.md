# 刑事接案资格与冲突筛查

## 任务目标

在明确、无利益冲突的单方立场下（被追诉人辩护、被害人等代理、单位或责任人员，互斥），形成接案筛查草案：接案闸、`Q#` 路径、`JB#` 接案行（主体切片（客户／委托人／付款人／单位）／授权路径／冲突／打开接口／`E#` 回链）。本窗 `JB#` 是接案行草案，不是已接受委托，不是已发送，不是已会见，不是已采取程序行动，不是已取得机关结果，不是实体意见。本窗闸名只能是接案闸，禁止复用冲突闸、筛查闸、资格闸、评估闸、授权闸、会见闸、紧急闸、起诉闸。预留不得占用：立案闸、调查闸。本窗主行只能是 `JB#`，禁止 `JS#`、`CX#`、`SC#`、`IC#`、`AZ#`、`A#`、`N#`、`P#`、`K#`。主路径只用 `Q-接`，禁止用 `Q-筛`、`Q-冲`、`Q-总`、`Q-诉`、`Q-辩`、`Q-风`、`Q-启`、`Q-签` 作主路径。邻窗 `Q-接` 只作转介进本窗；本窗打开为主路径，不是已接受、不是可行动。接案闸打开不等于已接受不等于家属即客户不等于付款人即委托人不等于值班即本案辩护人不等于法援一般资格即本案指派不等于单位授权即个人辩护不等于已隔离即无冲突不等于待提交终稿。家属不是客户。付款人不是委托人。口头同意不是授权。付款记录不赋权。书面代委托不是本人已确认策略。值班安排不是本案委托或法律援助决定／指派。法援口头通知不是本案决定／指派。单位授权不是责任人员本人辩护。信息隔离不是冲突已治愈。筛查结论不是已立案、不是已会见、不是实体意见。会见三证不是已完成会见。侦查期间只能委托律师。一名辩护人不得同时为两名以上同案或关联被告人辩护。未知不写零。不定罪。不保证可接。不执行发送。不代提交。不联系机关。不选定机关。不写唯一截止日。

`depends-on` 为空。紧急行动转 `刑事紧急响应方案`。首次会见提纲转 `首次在押会见与权利处置`。阶段总评估转 `当前阶段刑事辩护案件评估`。控告可行性转 `刑事控告可行性评估`。自诉可行性转 `刑事自诉可行性评估`。单位侧意见转 `单位犯罪被追诉单位专项辩护意见`。责任人员侧意见转 `单位犯罪责任人员专项辩护意见`。简易速裁选择未安装则 `unavailable`，本窗不代评。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：实质刑事工作开始前，主成果是客户、资格路径、授权与冲突筛查。授权、本人意愿或冲突记录未闭合仍正触发：有可编号主体或路径碎片则接案闸打开或半开，第 6 节出 `JB#` 草案，缺项记 `G#`。无一可编号碎片才关闸，仍交十节，第 6 节不出 `JB#` 终稿，第 7 节不得出会见方案、紧急行动或委托合同终稿，窗口不关。用户要保证今晚必须接案、把家属写成客户、口头当书面、付款即已接、值班即辩护人、先接再补手续、信息隔离即无冲突，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `JB#` 草案。冲突未闭合不得形成限定范围接受，但窗口不关，仍交角色与冲突草案。不得因「不定罪」「不保证可接」「不代提交」改走负触发关窗。利益冲突未解不是整体停止。无书面筛查授权但单方立场已闭合且已有可编号碎片：接案闸部分打开，仍交十节，不是整体停止。口头「家属就是客户」「付了就能接」不得单独算作开闸材料。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是紧急状态、权利保护或期限行动方案（转 `刑事紧急响应方案`）；
- 主成果是首次在押会见提纲或会后权利处置（转 `首次在押会见与权利处置`）；
- 主成果是已确认立场后的阶段案件评估（转 `当前阶段刑事辩护案件评估`）；
- 主成果是刑事控告可追诉性（转 `刑事控告可行性评估`）；
- 主成果是自诉入口可行性（转 `刑事自诉可行性评估`）；
- 主成果是单位犯罪单位侧意见（转 `单位犯罪被追诉单位专项辩护意见`）；
- 主成果是责任人员侧意见（转 `单位犯罪责任人员专项辩护意见`）；
- 主成果是速裁／简易程序选择（`unavailable`，本窗不代评）。

双方秘密、两造争同一份接案结论、伪造授权、泄密、规避已确定冲突、冒充、违法取证**不在负触发表**，走整体停止。「保证今晚必须接案」「家属就是客户」「口头即授权」**不在负触发表**。「不定罪」「不保证可接」「不代提交」是交付禁令，不是负触发。主成果才转；出现「接案」「冲突」一词不是转出。

## 建立工作坐标

确认：客户、拟委托人、付款／联络人、授权代表、单位与责任人员、真正受益立场；程序身份；程序阶段与承办机关类型（不选定某局某院）；在押／强制措施；委托或指派路径；同案／关联与既有客户。

口头「家属就是客户」「付了就能接」「微信已同意」、已读只登记 `S#`／`V#`。不得升格已接受、已授权或冲突已治愈，**不得单独算作开闸材料**。身份材料、书面委托／授权、律所受理、法援决定／指派、值班安排、机关文书、羁押材料、既有冲突记录可开闸。本窗不执行发送，不代提交，不定罪，不保证可接。

立场只许互斥的一方出稿。同时掌握被追诉人与被害人、或同案对立被告人相互冲突的秘密，或两造争同一份接案结论：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：接案闸关闭，仍交十节，不是整体停止。提出伪造授权、规避已确定冲突、泄密、冒充、违法取证：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止；不得写成限定范围接受。开口不等于立场闭合。无机关 `R#` 不得写机关名称，只写类型。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 制度或律所记录；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`JB#` 接案行；`V#` 版本；`E#` 证据形态回链（不是已接受证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`P#`、`JS#` 作主行。技能正文中的条号是检索锚点，不是已核验 `L#`。稿件状态默认 `草案`。无 `E#` 不得写已核实、已接受、无冲突。未知不写零。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。家属 ≠ 客户。口头 ≠ 授权。值班 ≠ 辩护人。筛查 ≠ 已接案。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或类案检索。本窗是评估筛查，`search_case_by_fact` 只比较事实差异与翻转条件，**不要**把无类案写成可接受或已接案；禁止 `search_template` 生成委托合同、无冲突声明或已接案证明。
- 法规用于核验中国大陆现行委托、代委托、法援／值班与冲突规则；实务用于发现家属即客户、付款即授权、值班即辩护人、隔离即无冲突的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把 2012 年刑事诉讼法第三十三条当现行在押代委托、第三十七条当现行会见。现行在押代委托是 2018 修正第三十四条。律师法第三十九条同案双方代理不是可口头豁免。法释〔2025〕9 号施行日 2025-06-27。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的资格、指派或冲突可继续性保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：刑事诉讼法（2018 修正）第三十三条委托一至二人及辩护人范围；第三十四条第一次讯问或采取强制措施之日起有权委托，侦查期间只能委托律师，在押可由监护人、近亲属代为委托。噪声：2012 年第三十三条、第三十七条。刑诉解释（2021）第四十三条一名辩护人不得为两名以上同案或关联被告人辩护。律师法（2017）第二十五条律所统一接受委托；第三十三条持三证会见不是已会见；第三十九条不得在同一案件为双方担任代理人。律师事务所管理办法第四十六条受理须利益冲突审查。法律援助法第十四条值班律师为没有辩护人者提供法律帮助；第二十四条、第二十五条申请或通知指派；第二十七条不得限制委托辩护人权利。办理法律援助案件程序规定（2023）第二十八条法援后近亲属代委托、本人接受委托辩护的报告义务。法释〔2025〕9 号：法援指派后近亲属代委托的受委托辩护人仍有权会见；本人选择代委托辩护人的，应通知法律援助机构终止法律援助。技能正文条号不是 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变资格、指派覆盖或冲突可继续性的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补家属即客户、付款即授权、值班即辩护人、隔离即无冲突、同所同时担任被告辩护与被害人代理的反例。
- `search_case_by_fact` 只比较事实差异与翻转条件。无类案不得写成可接受或已接案。禁止范本升格。

工具不可用时继续 `JB#` 与缺口；资格、指派、冲突可继续性字段停止。不得拒跑，不得凭记忆写已接受或无冲突。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、接案闸与不关窗

主成果才整案转出。双方秘密、伪造授权第一次停。保证今晚必须接、家属即客户不关窗。闸关仍交十节，第 6 节不出 `JB#` 终稿。利益冲突未解不是整体停止。禁止把会见闸、紧急闸、评估闸写进本窗节点 0。

### 2. 主体切片与资格路径

客户、委托人、付款人、单位分列。本人委托、在押代委托、被害人代理、单位与责任人员、法援指派、值班帮助分列。本节禁止出 `JB#` 终稿。

### 3. 接案闸与路径 `Q#`

本节禁止出 `JB#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-接`。`Q-筛`、`Q-签` 不得升主路径。

### 4. 接案行 `JB#`

每一行须能指向主体、授权路径或冲突之一。无 `E#` 不得写已接受或无冲突。状态 `草案`。冲突未闭合不得写限定范围接受。

### 5. 紧急、会见与案件评估接口

紧急、会见、阶段评估、控告、自诉只开接口。第 7 节不得夹带 `JB#` 终稿或委托合同绕闸。两阶段路径下一步只开会见窗接口。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；两造争同一份接案结论；伪造授权；泄密；规避已确定冲突；冒充；违法取证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：接案闸关闭，仍交十节，不是整体停止。无书面筛查授权但有碎片：接案闸部分打开，不是整体停止。利益冲突未解：不是整体停止；不得写成限定范围接受。已核验禁止性冲突：出拒绝／转介草案，不是整体停止；要规避该冲突才整体停止。
- `字段停止`：资格路径、授权／指派、阶段机关、冲突记录、法援规则、施行日未核验。保证今晚必须接、家属即客户、口头即授权、付款即已接、值班即辩护人、先接再补手续：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `JB#` 草案。
- `目标停止`：主目标变为紧急方案、会见提纲、实体意见、自诉或控告材料包。禁止把「保证今晚必须接」当作用户错误主张时的目标停止；那是不关窗。

禁止指导伪造授权、规避冲突、泄密或选边。不给胜诉率。不保证可接。不定罪。不选定机关。不代提交。未知不写零。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。接案闸关闭仍交十节，第 6 节不出 `JB#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `JB#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。接案闸未打开时不得交付已接受或无冲突终稿。边界见 [路由](references/routing.md)。
