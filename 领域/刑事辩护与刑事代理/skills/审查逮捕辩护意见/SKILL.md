# 审查逮捕辩护意见

## 任务与边界

仅在中国大陆辩护方场景中，于公安机关已经提请批准逮捕、检察机关正在审查逮捕且入口可核验时，形成唯一成果“审查逮捕辩护意见包”：审查逮捕辩护意见正文、社会危险性反证目录、听取律师意见要点。它不代表已发送、提交或获采纳，也不代替机关决定。

事实、来源、规则适用和限制已充分回链时，可以在辩护立场内建议或请求依法不批准逮捕；不代表机关已作出不批准逮捕决定。材料不足、冲突或待核验时，只写核验问题与受限结论，不把缺口写成不批准逮捕结论。

`dependsOn: []`

负触发优先于成果状态。先读取 [边界与路由](references/routing.md) 判断是否尚未提请、已经逮捕或主目标属于相邻事项；一经判定负触发，只路由，不使用三种成果状态，也不交付三个组成件。只有已经进入本候选判断后，才处理入口冲突或安全停止。

## 入口硬门

逐项记录并核对：辩护立场、执业与授权、利益冲突、涉嫌事项、拘留起算、提请日期、承办机关、当前节点及其材料来源。

入口硬门先于规则检索、规则降级和实体分析；规则来源不完整或用户要求跳过核验，均不得绕过入口硬门。

- 公安机关尚未提请，或检察机关尚未进入审查：路由，不形成意见包。
- 已作出逮捕决定，或主目标已转为羁押必要性、一般取保、不起诉、撤案、量刑辩护或完整代理：路由，不代做相邻文书。量刑辩护指出 `量刑辩护意见`；该原子未安装时输出 `unavailable`，不得在本任务内写成量刑意见。
- 已进入本候选判断，但执业身份、授权、辩护立场、利益冲突任一缺失、冲突或无法核验：必须使用“因停止条件未形成”的最小输出，不得交付三个组成件。
- 关键日期、机关或阶段存在会改变入口的缺失、冲突或无法核验：必须使用“因停止条件未形成”的最小输出。
- 出现伪造、毁灭或补造证据，串供、干扰证人、规避侦查、违法取得受限数据、代替机关决定，或将未证实事实包装为定论的请求：安全停止并给最小输出，不强制写成果状态。

## 工作流

1. 读取 [审查方法](references/method.md)，依次完成入口坐标、听取意见、双层逮捕条件、社会危险性、替代措施、来源与程序线索、成果状态与路由七个节点。犯罪事实证据、可能判处徒刑以上刑罚、法定具体社会危险性、取保候审或其他非羁押措施不足必须分别判断、分别回链且不得互相替代。
2. 每项事实同时标注来源和核验状态；保留有利、不利、冲突、缺失与待核验内容。材料不全时降低结论强度，不把缺口写成实体结论。
3. 仅在外部信息会改变判断时，按最小必要范围使用运行时工具：`search_law` 核对规则、权限与期限；`search_practiced` 补充实务视角；`search_case_by_fact` 或 `search_case_by_filter` 处理相似案例；`get_case_detail` 核对已确认案例全文；`search_template` 核对文书结构。核查相关性、现行性、层级和完整性后再使用结果。
4. 只有用户输入明确报告或本次实际调用返回工具状态时才记录，并同时记录状态来源；两者均无时，不得推断或声称工具不可用、无结果、冲突或其他状态。工具确有事件时按 [审查方法](references/method.md) 降级。
5. 仅对正触发、全部入口硬门闭合且进入本候选判断的任务，按 [输出合同](references/output-contract.md) 固定交付三个组成件。成果状态为“已形成”或“部分形成并明确受限字段”；只有此后实体证据、风险或替代措施材料受限时，才可使用后者。入口硬门未闭合时只能使用“因停止条件未形成”。

## 提交前检查

确认：入口仍闭合；辩护请求均有充分回链且未写成机关决定；社会危险性逐项有证据矩阵；替代措施逐项回应具体风险；不利事实未省略；每项限制可定位；负触发与安全停止没有被继续处理。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是运行本技能的强制依赖。
