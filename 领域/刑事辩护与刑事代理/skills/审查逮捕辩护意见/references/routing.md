# 边界与路由

## 正触发

公安机关已经提请批准逮捕，检察机关正在审查逮捕；辩护立场、授权、拘留起算、提请日期、承办机关和当前节点均可核验。此时才形成审查逮捕辩护意见包。

## 负触发

负触发优先于成果状态。一经命中下列场景，只路由，不使用成果状态，不交付三个组成件。

| 主目标或阶段 | 路由方向 | 本任务只做什么 |
| --- | --- | --- |
| 尚未提请批准逮捕 | 等待入口闭合或对应侦查阶段事项 | 只说明尚未进入本节点，不预写意见包 |
| 已逮捕，目标为羁押必要性 | `羁押必要性审查申请` | 只说明逮捕后羁押必要性与本任务的阶段差异 |
| 一般取保申请 | `取保候审申请` | 只说明独立取保申请与条件化替代分析的差异 |
| 审查起诉不起诉意见 | `审查起诉不起诉辩护意见` | 只说明审查起诉阶段与审查逮捕阶段的差异 |
| 侦查阶段撤案意见 | `侦查撤案辩护意见` | 只说明撤案目标与审查逮捕意见包的差异 |
| 量刑辩护 | `量刑辩护意见` | 只说明刑罚裁量与审查逮捕四项条件的差异，不扩张为量刑意见 |
| 完整刑事辩护代理 | 对应完整代理事项 | 只说明本任务不覆盖持续代理工作 |

负触发时只路由，不代做相邻成果，也不形成该成果的正文、申请或代理方案。

## 易混场景

用户虽提到取保、居所、保证或工作安排，但主目标仍是检察机关审查逮捕前的辩护意见时，可在正文内进行风险—替代措施的条件化分析；不得改写为一般取保申请。

阶段、日期、机关、身份、授权或立场存在会改变入口的重大冲突时，不静默猜测或改换任务，使用停止状态并列出最小补充事项。

目标成果未安装时输出 `unavailable`，不得由本 Skill 代做，也不得把未安装原子的标识当成已安装入口。
