# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变路径、机关、期限或请求范围的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然结果、机关必然受理或确定刑期。

`search_law` 返回已废止文本或已失效《合同法》及其解释时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。现行《刑事诉讼法》及有效司法解释未核验前，不得把记忆条号写成已核验。

禁止指导伪造、隐匿、串供、威胁证人、违法接触证人和违法取证。用户坚持上述行为时整体停止策略输出。

入口状态：已确认侦查机关、措施状态与当前权限。
主管机关或论坛：承办侦查机关或监督检察机关。
期限输入：措施采取日、期限与羁押状态。
最小证据：侦查阶段辩护意见、事实与依据附件目录。

---

## 节点 1　阶段与提交对象

本意见只提交侦查机关或其依法听取意见的节点，不改写成审查逮捕或审查起诉文书。

| 条件 | 则 |
| --- | --- |
| 若 案件已移送审查起诉 | 目标停止，转不起诉或实体辩护专项 |
| 若 当前节点是审查逮捕 | 负触发，转审查逮捕意见 |
| 若 侦查机关、案号或承办单位不明 | 机关字段停止，不出具意见正文 |
| 若 用户只要撤销案件专项结论 | 负触发，转撤案专项 |

---

## 节点 2　事实与依据范围

意见只能使用会见记录、已依法取得的材料和公开程序文书。

| 条件 | 则 |
| --- | --- |
| 若 关键事实只有传闻 | 标单方主张，不得写成已核实 |
| 若 存在同步录音录像或体检材料但未取得 | 记缺口，不补造内容 |
| 若 意见将引用无权阅卷阶段的“全卷” | 停止相关事实判断 |

---

## 节点 3　程序、责任与排除事由分列

分别写强制措施、取证程序、事实不清和责任阻却，不合成定罪意见。

| 条件 | 则 |
| --- | --- |
| 若 材料支持程序违法但不支持事实不存在 | 只写程序问题，不写无罪成立 |
| 若 责任年龄、精神状态或正当防卫信号出现 | 单列待核，不自行作医学或年龄鉴定结论 |
| 若 单位犯罪与个人责任混写 | 按授权只写本客户，他人责任停止 |

禁止写成：
- 按罪名名称套用构成要件并宣布不构成犯罪

---

## 节点 4　意见结构与附件

意见分请求、事实、依据、附件目录和停止项。不得承诺侦查机关接受。

| 条件 | 则 |
| --- | --- |
| 若 请求包括变更强制措施 | 只作接口，完整取保或羁押必要性转相应原子 |
| 若 请求包括排除非法证据 | 侦查阶段只保留线索接口，正式排除按阶段转出 |
| 若 附件含原始卷宗或可识别第三人信息 | 脱敏或停止导出 |

---

## 节点 5　现行法核验

涉及律师在侦查阶段提出意见、强制措施和追诉条件的规则必须运行时核验。

| 条件 | 则 |
| --- | --- |
| 若 规则未核验 | 法律结论字段停止 |
| 若 用户要求指导串供或统一口径 | 整体停止 |

---

## 程序与期限表

程序动作记录机关、案号、文书、作出、收到、送达、效力。期限每行只对应一种期间类型和一个起算事件。关键日期冲突则并行情景，不选对用户最有利的一天。未知日期不得计算截止日。

## 证据与下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。下一步按期限灭失、易失证据、能否改变本成果争点、可逆性排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。

相邻专项申请、完整实体辩护、审查起草或未安装能力只写转介条件和最小交接，不在本方法生成那些终稿。
