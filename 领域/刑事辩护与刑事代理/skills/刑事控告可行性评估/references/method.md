# 执行方法

## 共同事实与来源链

案件事实记录与法律规则记录分开。事实来源白名单为：原件/可回链副本、机关正式电子记录、当事人本人陈述、第三方转述、现场观察；法律来源单独记录法域、规范名称、版本/生效日、逐项引文、适用前提、检索时间和工具返回标识。事实状态只使用已核实、单方主张、冲突、尚未提供/无法取得；规则来源不证明案件事实，缺失且会改变结论时停止。

## 本 Skill 方法节点

每个节点必须回链到对应输入、法源引文、反向材料和输出字段。

1. **节点 1**：先确认主体、被控行为、时空范围和可能管辖，不把纠纷标签当作犯罪事实。
2. **节点 2**：分别检验刑事可追诉性、民事/行政替代路径、主观要素、损害、因果和证据门槛。
3. **节点 3**：建立最强反解释、报案风险、证据缺口和安全控制表。
4. **节点 4**：根据材料选择控告、补证、先行民事/行政处理或不启动路径。
5. **节点 5**：只交付决策意见，不承诺立案或直接写完整控告材料。

## 现行性与反向核验

每次改变结论的规则、期限、机关或特殊主体均需调用允许的法源工具并保存法域、版本/生效日和引文；经验信息只能补充，不能替代规范依据。对最强不利事实、相反来源和最近邻成果至少各做一次区分。工具不可用、无结果或结果冲突时，禁止输出确定法律结论、期限或机关路径。

## 工具与降级

允许的稳定工具：`search_law`、`search_case_by_fact`、`search_case_by_filter`。只有 `search_law` 的法源引文可作为法律结论的必要核验；本 Skill 声明的其他工具（`search_case_by_fact`、`search_case_by_filter`）仅为可选的去标识化公开实践/模板辅助，不能证明本案事实、罪名、期限或结果。不得上传姓名、联系方式、完整文书、卷宗、可识别事实或特权材料。所有工具调用前执行脱敏检查，返回须带来源标识；法源工具不可用、无结果或冲突时不拒绝执行，法律字段留空并停止。
