# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变路径、机关、期限或请求范围的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然结果、机关必然受理或确定刑期。

`search_law` 返回已废止文本或已失效《合同法》及其解释时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。现行《刑事诉讼法》及有效司法解释未核验前，不得把记忆条号写成已核验。

禁止指导伪造、隐匿、串供、威胁证人、违法接触证人和违法取证。用户坚持上述行为时整体停止策略输出。

入口状态：犯罪嫌疑人或被告人已被逮捕，当前诉讼阶段及承办或监督机关已核验。
主管机关或论坛：侦查阶段：承办侦查机关或有管辖权人民检察院；审查起诉阶段：有管辖权人民检察院；审判阶段：有管辖权人民法院。
期限输入：措施采取日、期限与羁押状态。
最小证据：羁押必要性评估、审查申请书。

---

## 节点 1　逮捕后时点与机关

本任务只在逮捕后启动。决定或审查机关按阶段核验，不与审查逮捕混写。

| 条件 | 则 |
| --- | --- |
| 若 尚未逮捕，仅刑事拘留或取保 | 负触发；审查逮捕转相应原子，取保转取保原子 |
| 若 逮捕文书、执行日或羁押场所不明 | 措施字段停止，不写继续羁押不必要 |
| 若 侦查、审查起诉或审判阶段不明 | 机关字段停止 |
| 若 用户把本申请改名为取保申请且事实未增加情势变化 | 负触发，不机械改名 |

---

## 节点 2　继续羁押因素建模

分列社会危险性、妨碍诉讼、可能判处刑罚、案件进展、身体状况和看护条件。每项独立判断。

| 条件 | 则 |
| --- | --- |
| 若 社会危险性材料只有保证“不会再犯”的口头承诺 | 依据不足 |
| 若 出现不适宜羁押的疾病或怀孕等法定情形信号 | 记待核医学或身份材料，不自行诊断 |
| 若 案件证据已固定且无毁灭证据具体迹象 | 作为有利因素记录，不得写成必然释放 |
| 若 存在新的毁灭证据、干扰证人或再犯迹象 | 作为最强反方列出，不得隐瞒 |

禁止写成：
- 承诺批准变更强制措施
- 把家属付款写成法定释放条件

---

## 节点 3　情势变化与既有申请

必须说明逮捕后的新事实，避免重复提交同一理由。

| 条件 | 则 |
| --- | --- |
| 若 与审查逮捕意见使用完全相同事实且无新进展 | 标重复风险，依据不足支持新的必要性审查 |
| 若 量刑情节、和解、退赃或案件管辖变化可回链 | 作为情势变化列入 |
| 若 和解材料以威胁取得 | 排除该材料并停止相关从宽主张 |

---

## 节点 4　申请书与证明目录

申请写明对象机关、逮捕后事实、法律依据待核、附件和反馈后分支。

| 条件 | 则 |
| --- | --- |
| 若 保证人或社会调查材料来源不明 | 该附件不进入目录 |
| 若 需要调查未成年人成长经历 | 只列合法调取路径，不自行接触在校师生 |

---

## 节点 5　与取保、监视居住的关系

变更措施种类是可能结果，不是本申请的改名。监视居住合法性是未安装能力。

| 条件 | 则 |
| --- | --- |
| 若 主目标是监视居住地点或执行合法性 | P2，输出 unavailable |
| 若 主目标仍是一般取保条件评估 | 转取保原子 |
| 若 规则未核验 | 期限和机关字段停止 |

---

## 程序与期限表

程序动作记录机关、案号、文书、作出、收到、送达、效力。期限每行只对应一种期间类型和一个起算事件。关键日期冲突则并行情景，不选对用户最有利的一天。未知日期不得计算截止日。

## 证据与下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。下一步按期限灭失、易失证据、能否改变本成果争点、可逆性排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。

相邻专项申请、完整实体辩护、审查起草或未安装能力只写转介条件和最小交接，不在本方法生成那些终稿。
