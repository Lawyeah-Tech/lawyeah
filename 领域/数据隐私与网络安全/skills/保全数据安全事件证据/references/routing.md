# 边界与路由

## 正触发

日志、镜像、通知记录可能灭失，需要合法保全。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 事件处置总图 | `应对数据与网络安全事件` |
| 对外报告稿 | `准备安全事件报告与告知` |
| 暴露范围测算 | `测算事件影响范围与通知对象` |
| 刑事 | 刑事领域 |
| 行为保全停止处理 | `申请停止处理或删除的行为保全` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

## 易混

怕日志镜像没了要合法固化时正触发。不入侵、不隐匿。处置和发文另项。
