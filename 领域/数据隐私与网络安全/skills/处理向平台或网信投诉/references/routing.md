# 边界与路由

## 正触发

个人要向平台投诉或向网信等部门举报个人信息问题。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 起诉 | `提起个人信息民事索赔` |
| 处理者答复权利请求 | `处理个人信息主体权利请求` |
| 处理者应对监管 | `应对网信约谈与监督检查` |
| C 端个信投诉 | 大众专项，只分流不回改 |
| 和解 | `谈判个人信息侵权和解` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

## 易混

个人要投诉平台或向网信举报时正触发。要打官司走起诉。处理者答复走另一原子。C 端商品不回改。
