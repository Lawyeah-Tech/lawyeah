# 边界与路由

## 正触发

训练语料、用户输入或生成内容含个人信息或重要数据。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 算法备案深度合成 | `算法备案深度合成`（未安装则 `unavailable`） |
| 自动化推荐 | `评估自动化决策与个性化推荐` |
| 重要数据 | `识别重要数据` |
| 匿名化 | `评估匿名化去标识化与再识别风险` |
| 内容审查整案 | 相应内容监管，不整案吞并 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

## 易混

训练语料、用户输入、模型输出里的个人信息和重要数据正触发。备案走 P2。内容审核整案不吞并。
