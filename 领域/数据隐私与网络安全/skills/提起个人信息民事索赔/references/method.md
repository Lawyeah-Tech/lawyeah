# 起诉方法

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不给胜诉率。

## 节点 0　分流

C 端投诉只分流。名誉、肖像走对应商品或人格权专项。劳动、医疗、刑事转出。公益诉讼转 P2（未安装则 `unavailable`）。被告立场转应诉原子。

## 节点 1　主体与行为

原告须是个人信息主体或依法可主张的近亲属。被告须是处理者或共同处理者，名称以营业执照或 App 运营者为准，冲突并列。

## 节点 2　请求

- `P-停` 停止处理或排除妨碍
- `P-删` 删除或更正
- `P-歉` 赔礼道歉、消除影响
- `P-财` 财产损失
- `P-精` 精神损害

民法典第 995 条：停止侵害、排除妨碍、消除危险、消除影响、恢复名誉、赔礼道歉请求权不适用诉讼时效。金钱请求适用普通时效，起算未核验则字段停止。

赔偿按第 69 条：损失或处理者获益；难以确定则根据实际情况。不得写唯一必得金额；精算可转测算原子。

## 节点 3　管辖

连结点材料不足不选唯一法院。协议管辖不得违反级别和专属管辖。

## 节点 4　证据

原告证明：处理行为、与本人相关、损害或人格请求基础。处理者无过错由被告负担，但起诉包仍要预列对方最强合法基础抗辩。

## 节点 5　文书

按起诉状法定事项组织。不代提交。网上立案渠道可提示，但不改写成 C 端投诉成果。
