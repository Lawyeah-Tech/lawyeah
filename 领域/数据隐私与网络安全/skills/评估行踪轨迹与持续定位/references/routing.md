# 边界与路由

## 正触发

App 或其他终端持续定位、后台定位或轨迹画像。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 车端数据 | `评估汽车数据与车外图像` |
| 敏感信息一般认定 | `评估敏感个人信息处理` |
| 工作场所监测 | `评估工作场所监测合法性` |
| 合法性总评 | `评估个人信息处理合法性` |
| 最小必要 | `评估最小必要与过度收集` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

## 易混

持续定位或轨迹画像正触发。车端走车辆原子。一次性前台导航通常不是本任务主轴。
