# 边界与路由

## 正触发

关基或达到数量门槛的个人信息、重要数据是否必须境内存储。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 出境路径 | `评估数据出境路径` |
| 远程运维是否出境 | `评估境外远程运维访问是否出境` |
| 云驻留选型 | `评估云与SaaS数据驻留` |
| 关基义务 | `评估关键信息基础设施运营者义务` |
| 重要数据识别 | `识别重要数据` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

## 易混

问必须不要境内存、镜像算不算出境时正触发。选哪条出境路径走出境评估。云怎么买走云驻留。
