# 影响评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变合法性、路径、时限或对外含义的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然免罚、必然合法或唯一处罚金额。未知人数或金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜活动｜触发项｜合法性候选｜必要性｜影响路径｜风险｜措施｜落实证据｜可否继续｜最强反方｜判断｜待核`。委托、对外提供、公开、出境分列，不得合成“数据共享”。

---

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填本任务实体结论。

| 信号 | 转出 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

混合信号：本任务主轴可留；专项只作为背景时在缺口标明，不把专项规则硬套进本任务结论。

## 节点 1　触发闭合

运行时核验个保法第 55 条后再落触发。

- 若 处理敏感个人信息：则 本活动进入评估主位，并同时打开单独同意与第 30 条告知接口
- 若 利用个人信息进行自动化决策：则 进入评估主位，并打开透明度、拒绝个性化和重大影响人工复核接口
- 若 委托处理、向其他处理者提供或公开个人信息：则 进入评估主位；角色按委托／对外提供／公开分账，不得写成同一项
- 若 向境外提供个人信息：则 进入评估主位，但出境路径选择转 `评估数据出境路径`，本任务只评估影响与措施
- 若 其他对个人权益有重大影响的处理：则 必须写明影响机制；写不出机制则触发项标 `依据不足`，不得为交差虚构重大影响
- 若 以上均不支持且无其他重大影响事实：则 结论为现有依据不支持必须开展本项评估；可停止本任务或转总体评估

禁止：
- 把日常日志备份写成必须 PIPIA
- 把未发生的出境写成已评估通过

## 节点 2　处理活动与合法性

- 若 同一产品存在多种目的：则 按目的拆行，禁止合成“用户运营”一笔
- 若 合法基础候选只有同意：则 核知情自愿明确；预勾选或捆绑标现有依据不支持该同意
- 若 主张第 13 条第 2–7 项：则 逐项写成立条件；多项都弱时主位标依据不足，不挑选最有利项冒充已成立
- 若 去标识或哈希后仍可识别个人：则 仍按个人信息评估，不得写成已退出个保法

禁止：
- 把已发布隐私政策写成合法基础已闭合

## 节点 3　影响路径

- 若 涉及生物识别或行踪轨迹：则 必须评估再识别、持续监控和滥用路径
- 若 自动化决策影响交易条件或待遇：则 必须评估歧视、不透明和无法拒绝的影响
- 若 对外提供或公开后接收方不受本处理者控制：则 影响按“不可撤回扩散”评估，不得写成内部风险
- 若 影响人数未知：则 写区间或未知，禁止写零

## 节点 4　风险与措施

- 若 措施仅有制度标题没有落实证据：则 措施判断为依据不足，不得写风险已消除
- 若 受托人或境外接收方安全能力无材料：则 对应 `Q#` 标缺口；可否继续处理不得写成现有依据支持
- 若 用户要求把计划中的加密写成已经部署：则 整体停止该项美化，计划与落实分列
- 若 存在可降低风险的替代方案未被评估：则 列入最强反方：为何不采用更小侵害手段

## 节点 5　继续处理接口与状态词

- 若 风险可控、措施可核验、触发项与合法性已闭合：则 可继续处理，残留风险和下一次复评条件必须可见
- 若 合法性不支持或措施明显不足：则 现有依据不支持继续处理，列停止或限缩项
- 若 出境路径、重要数据识别或人数累计未核验：则 可否继续字段停止，不得写成已通过网信评估
- 若 用户要求本记录代替出境安全评估申报：则 目标停止，转出境申报原子

禁止：
- 把 PIPIA 写成网信部门已通过的安全评估
- 保证评估后不会被处罚

## 金额与规模

已知处理人数、事件波及人数、上一年度营业额只作区间参数。未知不写零。个保法第 66 条处罚上限只标接口，不输出唯一罚款预测。

下一步按期限灭失、易失证据、能否改变 `Q#`、可逆性排序。相邻原子只写转介和最小交接，不代做。禁止指导伪造同意、补造日志、瞒报或违法取证。
