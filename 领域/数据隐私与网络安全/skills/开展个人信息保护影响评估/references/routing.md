# 边界与路由

## 正触发

敏感个人信息、自动化决策、委托处理、向他人提供、公开、出境或对个人权益有重大影响的处理活动即将开展或重大变更，处理者需要影响评估记录。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要合规总图 | `评估数据与隐私合规` |
| 只要某一活动合法基础 | `评估个人信息处理合法性` |
| 只要出境路径 | `评估数据出境路径` |
| 路径已定、要安全评估申报包 | `准备数据出境安全评估申报` |
| 只要告知终稿 | `准备隐私政策与告知` |
| 只要处理活动台账 | `建立个人信息处理活动记录` |
| 企业综合合规体系 | 企业合规领域 |
| 一般采购或交易合同审查 | 审查起草领域（本窗搁置） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

## 易混

第 55 条触发且需要可归档评估记录时正触发。已决定出境路径并只要申报书时负触发。PIPIA 通过不等于网信安全评估通过，不得互相替代。
