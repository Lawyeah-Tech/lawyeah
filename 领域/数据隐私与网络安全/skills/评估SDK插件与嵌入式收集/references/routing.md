# 边界与路由

## 正触发

App、小程序或网站嵌入第三方 SDK、插件或像素。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| C 端 App 审查 | 大众专项，只分流不回改 |
| 下架整改 | `应对App下架通报与整改` |
| 对外提供 | `评估向第三方提供个人信息` |
| 委托 | `准备委托处理安排` |
| 告知文本 | `准备隐私政策与告知` |
| 出境 | `评估数据出境路径` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

## 易混

要盘嵌入式 SDK 收集和同意时正触发。大众 App 审查只分流。已被下架走下架原子。
