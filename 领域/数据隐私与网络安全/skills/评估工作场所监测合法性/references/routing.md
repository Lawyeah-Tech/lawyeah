# 边界与路由

## 正触发

考勤、邮件、定位、屏幕或摄像头监测员工。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 解除处分民主程序 | 劳动领域 |
| 公共场所摄像头 | `评估公共场所图像采集` |
| 员工信息合法性总评 | `评估员工个人信息处理合法性` |
| 人脸专项 | `评估人脸识别与生物识别` |
| 舞弊调查 | 企业合规领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

## 易混

监测手段本身的个保合法性正触发。处分解除走劳动。无雇佣关系的楼宇监控走公共摄像头。
