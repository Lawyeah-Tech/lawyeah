# 边界与路由

## 正触发

车端个人信息、车外图像、座舱数据或汽车领域重要数据。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 行踪 App 定位 | `评估行踪轨迹与持续定位` |
| 公共摄像头非车端 | `评估公共场所图像采集` |
| 匿名化 | `评估匿名化去标识化与再识别风险` |
| 重要数据识别 | `识别重要数据` |
| 出境 | `评估数据出境路径` |
| 交通事故赔偿 | 侵权领域 |
| 缺陷召回整案 | 产品监管，不整案吞并 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

## 易混

车端个人、车外图像、汽车重要数据怎么处理和出境时正触发。撞车赔钱走侵权。手机定位走行踪原子。
