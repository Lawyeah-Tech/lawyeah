# 评估汽车数据与车外图像

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

形成告知同意、匿名化、出境和评估接口。交通事故赔偿转侵权。产品缺陷监管不整案吞并。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、处理记录和证据清单。

## 工作边界

正触发：车端个人信息、车外图像、座舱数据或汽车领域重要数据。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 交通事故赔偿或保险理赔主轴；
- 产品缺陷、召回监管整案；
- 只要普通行踪轨迹 App 定位；
- 只要公共场所摄像头非车端；

本任务不给胜诉率或免罚承诺。审查起草本窗搁置。企业合规整案与知识产权只分流。

## 建立坐标

确认：车型与数据处理者；座舱个人；车外图像；是否匿名化；出境与远程升级；是否被识别为重要数据。

同时掌握处理者与权利人双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 制度或合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 义务／风险项；`V#` 评估版本；`E#` 告知／同意／报告凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然免罚、必然合法或唯一处罚金额。未知人数或金额不写零。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验汽车数据安全管理若干规定及个保法、出境规则。不虚构案件系统。

工具不可用时继续主体、场景、系统和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [汽车数据方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　主体

汽车数据处理者，含制造商、零部件、软件、经销、维修、出行平台。

### 节点 2　车外图像与匿名

车外图像、车内非驾驶人。默认匿名化要求运行时核验。未匿名按个人信息。

### 节点 3　告知同意

驾驶人与乘客告知。生物识别另核。

### 节点 4　出境与重要数据

汽车领域重要数据识别状态。出境打开路径原子。

### 节点 5　分账

事故赔偿转侵权。缺陷召回不整案吞并。手机 App 定位走行踪原子。

## 停止与安全

- `整体停止`：把未匿名车外图像写成可任意用；事故责任认定。
- `字段停止`：汽车数据规定条款未核验。
- `目标停止`：主目标变为交通事故或缺陷召回整案。

## 交付

严格按 [输出合同](references/output-contract.md) 八节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
