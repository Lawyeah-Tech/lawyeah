# 边界与路由

## 正触发

路径已指向订立并备案个人信息出境标准合同。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 路径未选 | `评估数据出境路径` |
| 安全评估申报 | `准备数据出境安全评估申报` |
| 认证 | `评估个人信息保护认证出境路径` |
| 豁免 | `评估跨境流动便利化与豁免` |
| PIPIA | `开展个人信息保护影响评估` |
| 一般合同审查 | 审查起草领域（本窗搁置） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

## 易混

已确定走标准合同、要填充和备案材料时正触发。改法定文本对抗个人一律停止。商务合同审查搁置。
