# 负责人指定方法

本文件是可执行判断节点，不是栏目说明书。每个会改变合法性、路径、时限或对外含义的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然免罚、必然合法或唯一处罚金额。未知人数或金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜主体｜处理规模｜门槛核验｜人选｜职责｜公开联系方式｜独立性｜判断｜待核`。

---

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填本任务实体结论。

| 信号 | 转出 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

混合信号：本任务主轴可留；专项只作为背景时在缺口标明，不把专项规则硬套进本任务结论。

## 节点 1　分流

- 若 要建企业级合规体系或任命首席合规官统管贿赂舞弊：则 企业合规领域整案转出
- 若 只要告知文本里的联系方式句子：则 转告知原子
- 若 关基安全负责人且无个保问题：则 打开关基原子，不在本任务宣布关基

## 节点 2　门槛

- 若 处理量材料不足：则 门槛字段停止，不得写“一定要指定”或“一定不用指定”
- 若 运行时核验后达到应当指定：则 指定义务主位
- 若 未达法定门槛但对外需要接口：则 可建议指定，义务判断为现有依据不支持“应当”

## 节点 3　人选与职责

- 若 人选无权限查看处理活动：则 监督职责不支持
- 若 人选同时是主要营销指标负责人且无制衡：则 独立性红旗，依据不足
- 若 职责文件只写“配合业务”：则 第 52 条职责不支持

## 节点 4　公开

- 若 联系方式未出现在告知或易找到位置：则 公开不支持
- 若 联系方式无人值守：则 履职依据不足

## 节点 5　输出

- 若 门槛已核验且人选职责公开均支持：则 指定安排可成立
- 若 用户要董事会决议文本：则 目标停止，不输出治理文件终稿

## 金额与规模

已知处理人数、事件波及人数、上一年度营业额只作区间参数。未知不写零。个保法第 66 条处罚上限只标接口，不输出唯一罚款预测。
