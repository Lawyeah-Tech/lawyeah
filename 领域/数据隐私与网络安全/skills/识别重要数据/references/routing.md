# 边界与路由

## 正触发

要判断某类数据是否属于重要数据、要不要按重要数据处理。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 分类分级目录 | `开展数据分类分级` |
| 核心数据 | `评估核心数据保护义务` |
| 出境路径 | `评估数据出境路径` |
| 出境安全评估申报 | `准备数据出境安全评估申报` |
| 出口管制 | 涉外／管制领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

## 易混

问是不是重要数据、按什么状态处理时正触发。未告知未公布不得写成已确定并强制评估，也不得写成已排除。
