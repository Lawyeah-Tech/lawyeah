# 重要数据识别方法

本文件是可执行判断节点，不是栏目说明书。每个会改变合法性、路径、时限或对外含义的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然免罚、必然合法或唯一处罚金额。未知人数或金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜数据｜识别状态｜依据｜告知／公布事实｜出境接口｜年报红旗｜判断｜待核`。

---

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填本任务实体结论。

| 信号 | 转出 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

混合信号：本任务主轴可留；专项只作为背景时在缺口标明，不把专项规则硬套进本任务结论。

## 节点 1　分流

- 若 只要分级目录：则 转分类分级原子
- 若 明显关系国家安全命脉且要核心数据义务：则 转核心数据原子
- 若 出口管制物项：则 涉外／管制领域

## 节点 2　四态

- 若 地区或部门已公布目录且该数据在列：则 已公布，按重要数据处理
- 若 主管部门已书面告知：则 已告知，按重要数据处理
- 若 已按规定申报识别但未告知未公布：则 不得强制按重要数据做出境评估，也不得写成不是重要数据
- 若 尚未识别：则 识别状态为未识别，出境与年报字段停止或标待核

## 节点 3　出境

运行时核验条例第 37 条。

- 若 已申报未告知未公布：则 不需要作为重要数据申报出境安全评估；个人信息出境仍走个人信息路径
- 若 已告知或公布：则 打开出境评估原子，重要数据出境主位
- 若 用户要求在未告知时强制评估：则 停止该强制表述

## 节点 4　年报

- 若 已确定重要数据处理者：则 标风险评估与年报接口，不代写
- 若 未确定：则 年报义务不写成已触发

## 节点 5　输出

- 若 四态已标明：则 交付识别状态和接口
- 若 事实不足：则 依据不足，无法形成是或不是的结论

## 金额与规模

已知处理人数、事件波及人数、上一年度营业额只作区间参数。未知不写零。个保法第 66 条处罚上限只标接口，不输出唯一罚款预测。
