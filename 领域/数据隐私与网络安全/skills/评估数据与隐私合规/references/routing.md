# 边界与路由

## 正触发

需要数据、个人信息或网络安全合规总图，单方尚未要求本任务直接产出对外终稿、申报包或诉状。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 判断某一处理活动合法基础 | `评估个人信息处理合法性` |
| 判断出境路径 | `评估数据出境路径` |
| 发布或更新告知 | `准备隐私政策与告知` |
| 事件处置总图已够、只要对外报告稿 | `准备安全事件报告与告知` |
| 只要事件处置方案 | `应对数据与网络安全事件` |
| 完整处理活动台账 | `建立个人信息处理活动记录` |
| 起诉 | `提起个人信息民事索赔` |
| 应诉 | `应对个人信息民事索赔` |
| 精算损害 | `测算个人信息侵权损害` |
| PIPIA 正文 | `开展个人信息保护影响评估`（未安装则 `unavailable`） |
| 知识产权 / 综合合规 / 医疗业务 / 劳动程序 / 刑事 | 对应领域 |
| C 端 App 审查 / 网站协议隐私 | 大众专项，只分流不回改 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、舞弊调查 | 企业合规领域 |
| 诊疗、器械、医院执业监管 | 医疗医药领域 |
| 解除处分、加班工资、工伤 | 劳动领域 |
| 个信刑事犯罪 | 刑事领域 |

## 易混

要先看清能不能做、做出境还是先改告知时正触发。主体、场景、路径均确认且只要申报书或政策终稿时负触发。有境外访问仍要求“直接写未出境”时，先完成出境闸，不改写出境申报原子。
