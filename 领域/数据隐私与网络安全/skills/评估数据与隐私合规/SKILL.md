# 评估数据与隐私合规

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“数据与隐私合规总体评估矩阵”：主体与角色、处理场景、合法性红旗、出境与本地化、分类分级与关基、事件与监管状态、证据缺口、对方或监管最强解释和下一步。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、处理记录和证据清单。

## 工作边界

正触发：中国大陆个人信息、重要数据或网络安全治理需要总图，用户仍需决定整改、出境、发告知、事件响应或下一步。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要对外发布的隐私政策或告知终稿；
- 只要出境安全评估申报包或标准合同备案终稿；
- 只要发送版事件报告或对个人告知；
- 只要完整处理活动台账或精算终稿；
- 已决定起诉／应诉／监管申辩并只要相应文书；
- 知识产权确权维权、企业综合合规体系、医疗业务监管、劳动程序后果或刑事个信犯罪为主要成果。

本任务不生成对外告知终稿、出境申报、事件报告、诉状或答辩，不给胜诉率或免罚承诺。

## 建立评估坐标

确认：使用者与授权；单方立场；处理者／受托人／共同处理者；产品与系统；处理目的与种类；是否出境或境外访问；是否已发生事件或收到监管文书；法域；关键材料及缺失。

同时掌握处理者与权利人双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 制度或合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 义务／风险项；`V#` 评估版本；`E#` 告知／同意／报告凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验个保法、数安法、网安法、网络数据安全管理条例、跨境流动规定的现行条件和效力时点；`search_practiced` 补路径与反例。不虚构案件系统。

工具不可用时继续主体、场景、系统和问题清单；合法性、出境路径、报告时限字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 专项分流、主体角色和系统范围

先做专项分流，再固定处理者、受托人、共同处理者和系统边界。名称不一致不自动合并。口头“已经合规”不写成已评估、已备案或已报告。

### 2. 处理场景与合法性红旗

每个场景独立列目的、种类、来源、合法基础候选、告知、单独同意、保存。同意不是唯一基础。不得把已发布隐私政策写成已合法。

### 3. 出境、重要数据和关基闸

境外存储、境外账号、远程运维、集团同步都先判断是否构成向境外提供。重要数据未被告知或公布时，不得既写成“已确定重要数据必须评估”，也不得写成“一定不是重要数据”。关基不得自行宣布。

### 4. 事件、监管和期限待核

已发生或可能发生泄露篡改丢失：只标报告/告知时钟和转介，不写发送稿。约谈、检查、下架只列程序状态。时限未核验则字段停止，不编造一律 24 小时。

### 5. 证据、反方和下一步

记录矩阵列待证事实、控制方、合法取得、缺口。下一步按事件时钟、出境累计、易失日志、能否改变 `Q#`、可逆性排序。发告知、出境申报、事件报告、起诉标为转介。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或系统无法建立；用户坚持伪造同意、瞒报、毁日志或向外国执法擅自提供境内个人信息。
- `字段停止`：法域、日期、数量累计、重要数据识别状态、动态规则未核验。
- `目标停止`：主目标已变为发告知、出境申报、事件报告、建完整台账、起诉或应诉。
