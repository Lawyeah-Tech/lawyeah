# 边界与路由

## 正触发

向其他个人信息处理者提供个人信息，而非委托其处理。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 委托 | `准备委托处理安排` |
| 共同处理 | `评估共同处理安排` |
| 公开 | `评估公开个人信息` |
| 出境 | `评估数据出境路径` |
| 并购转移 | `处理合并分立破产中的个人信息转移` |
| SDK | `评估SDK插件与嵌入式收集` |
| PIPIA | `开展个人信息保护影响评估` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

## 易混

把个人信息给另一个独立处理者时正触发。听命处理走委托。发出境走出境。发网上走公开。
