# 应对个人信息民事索赔

## 任务目标

在明确、无利益冲突的被告处理者立场下，形成首次应诉包：答辩期限卡、过错举证结构、合法性抗辩、请求逐项回应、答辩草稿。

`depends-on` 为空。

## 工作边界

正触发：已收到起诉状、应诉通知或进入民事索赔应对，主成果是答辩而非监管申辩。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 用户实为原告要起诉；
- 劳动仲裁应诉；
- 只要网信处罚陈述申辩；
- 要求伪造同意或隐匿日志。

## 建立应诉坐标

确认：送达日与答辩期限；案号；原告主张；己方处理活动；同意与告知版本；是否共同被告。口头转述不得写成已送达。

## 来源和判断状态

编号：`S/D/A/R/C/L/I/G/Q/V/E`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

`search_law` 核验答辩期限、第 13、69 条、人格请求时效。不可用则期限和法律结论字段停止。

## 五个判断节点

以 [应诉方法](references/method.md) 为准。

### 1. 期限与程序闸

答辩、管辖异议期限分列。过期字段停止，不编造仍可当然延期。

### 2. 第 69 条举证

处理者不能证明自己没有过错则承担损害赔偿。必须列能证明无过错或过错不成立的材料，不能只重复“我们有隐私政策”。

### 3. 合法性抗辩

逐项回应对方请求。第 2–7 项基础可抗辩“不需同意”，但须有事实。超范围、未单独同意不得用概括同意硬抗。

### 4. 请求拆解

停止处理、删除、道歉、金钱分列。能满足的权利请求与须抗辩的金钱请求不得绑在一起拒绝。

### 5. 答辩草稿

只交草案。反诉评估只留接口。不保证胜诉。

## 停止与安全

- `整体停止`：伪造同意；毁证；立场不明。
- `字段停止`：送达日或规则未核验。
- `目标停止`：主目标变为起诉、监管申辩或和解协议终稿。
