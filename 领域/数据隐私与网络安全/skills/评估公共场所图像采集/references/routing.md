# 边界与路由

## 正触发

楼宇、商场、社区、园区安装或使用图像采集设备。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 人脸识别专项 | `评估人脸识别与生物识别` |
| 工作场所员工监测 | `评估工作场所监测合法性` |
| 肖像商用 | 人格权／C 端肖像，只分流 |
| 公安依法安装 | 另核法定职权 |
| 出境 | `评估数据出境路径` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

## 易混

楼宇商场社区摄像头的提示和目的限制正触发。刷脸比对走人脸。拍广告用肖像走人格权。
