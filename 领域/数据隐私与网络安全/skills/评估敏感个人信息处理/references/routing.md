# 边界与路由

## 正触发

拟处理或已处理生物识别、医疗健康、金融账户、行踪轨迹、特定身份等敏感个人信息。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 儿童个人信息 | `处理不满十四周岁未成年人个人信息` |
| 人脸识别场所与替代方案 | `评估人脸识别与生物识别` |
| 行踪持续定位 | `评估行踪轨迹与持续定位` |
| 医疗健康专项治理 | `评估医疗健康个人信息专项治理` |
| 诊疗监管 | 医疗医药领域 |
| PIPIA 正文 | `开展个人信息保护影响评估` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

## 易混

要判断是不是敏感、能不能处理、单独同意和告知是否够时正触发。儿童、刷脸场所、持续定位有更专项的原子。
