# 儿童个人信息方法

本文件是可执行判断节点，不是栏目说明书。每个会改变合法性、路径、时限或对外含义的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然免罚、必然合法或唯一处罚金额。未知人数或金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜场景｜是否可能儿童｜年龄闸｜监护人验证｜专门规则｜种类必要｜判断｜待核`。

---

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填本任务实体结论。

| 信号 | 转出 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

混合信号：本任务主轴可留；专项只作为背景时在缺口标明，不把专项规则硬套进本任务结论。

## 节点 1　分流

- 若 主轴是防沉迷、内容生态或校园管理监管：则 不整案吞并，只保留个保切片
- 若 对象明确已满十四周岁：则 不适用本任务儿童规则，转敏感或普通合法性
- 若 监护权归属争议：则 婚家领域

## 节点 2　年龄闸

- 若 产品定位儿童且无年龄核验：则 年龄闸不支持
- 若 仅自报年龄且面向儿童的设计明显：则 合理措施依据不足
- 若 无法判断是否有儿童用户：则 字段停止，不得写成一定没有儿童

## 节点 3　监护人同意

运行时核验第 31 条。

- 若 只有儿童点击同意：则 监护人同意不支持
- 若 监护人验证与风险不匹配（高敏感仅短信验证码且号码由儿童填写）：则 验证依据不足
- 若 监护人拒绝后仍处理：则 处理不支持

## 节点 4　专门规则与必要

- 若 无专门规则或与成人政策完全同一且无儿童段落：则 专门规则不支持
- 若 收集超出服务必要的行踪或生物识别：则 必要不支持
- 若 向儿童作个性化广告：则 红旗，规则待核后通常不支持

## 节点 5　输出

- 若 年龄闸、监护人同意、专门规则、必要均支持：则 可在该范围内处理
- 若 任一项不支持：则 应停止或限缩儿童信息处理

## 金额与规模

已知处理人数、事件波及人数、上一年度营业额只作区间参数。未知不写零。个保法第 66 条处罚上限只标接口，不输出唯一罚款预测。
