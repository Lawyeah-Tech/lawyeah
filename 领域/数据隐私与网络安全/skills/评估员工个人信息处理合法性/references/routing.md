# 边界与路由

## 正触发

招聘、入职、背景调查、在职档案中的员工个人信息。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 解除处分民主程序 | 劳动领域 |
| 工作场所监测手段 | `评估工作场所监测合法性` |
| 健康信息专项 | `评估医疗健康个人信息专项治理` |
| 保存期限 | `评估保存期限与删除义务` |
| 舞弊调查 | 企业合规领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

## 易混

招聘背调在职档案的个保合法性正触发。能不能开除走劳动。摄像头怎么装走监测原子。
