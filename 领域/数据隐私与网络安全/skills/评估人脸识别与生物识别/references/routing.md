# 边界与路由

## 正触发

门禁、核验、考勤或营销使用人脸或其他生物识别。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 敏感信息一般认定 | `评估敏感个人信息处理` |
| 工作场所监测总评 | `评估工作场所监测合法性` |
| 公共场所摄像头非人脸专项 | `评估公共场所图像采集` |
| 刑侦履职 | 另核法定职权，不指导对抗 |
| PIPIA | `开展个人信息保护影响评估` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

## 易混

刷脸或生物识别作门禁核验营销时正触发。普通摄像头无生物比对走公共摄像头原子。不指导规避核验。
