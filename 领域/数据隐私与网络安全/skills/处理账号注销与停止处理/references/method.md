# 注销与停止处理方法

本文件是可执行判断节点，不是栏目说明书。每个会改变合法性、路径、时限或对外含义的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然免罚、必然合法或唯一处罚金额。未知人数或金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜系统／副本｜是否停止处理｜删除或匿名化｜保存例外依据｜期限｜完成标志｜判断｜待核`。

---

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填本任务实体结论。

| 信号 | 转出 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

混合信号：本任务主轴可留；专项只作为背景时在缺口标明，不把专项规则硬套进本任务结论。

## 节点 1　定性

- 若 请求仅删除某条内容且账号继续使用：则 转权利请求原子
- 若 企业账号下有其他授权用户：则 先核管理员权限与他人数据边界，不得一把删除他人合法账号
- 若 未成年人账号：则 打开儿童原子接口，监护人同意与注销一并核验

## 节点 2　路径

- 若 注销需人工审核而注册可自动完成，且无风险核验必要：则 路径便利性现有依据不支持
- 若 要求先放弃法定权利或先好评才能注销：则 不合理条件，现有依据不支持
- 若 未完成订单或余额：则 可提示清算，但不得把无关授权或新的个人信息处理作为注销前提

## 节点 3　范围

- 若 主库停止但画像或推荐特征仍用：则 停止处理不完整，现有依据不支持已完成
- 若 已向第三方提供：则 列接收方、是否通知、能否停处理；不能召回的标缺口，不得写成全部已删
- 若 境外副本或集团同步：则 打开出境与再转移接口，不得只改境内开关

## 节点 4　例外

- 若 主张财务或监管保存：则 指出条文、种类、期限；超范围部分仍应删或停处理
- 若 技术上难以删除：则 停止除存储和采取必要安全保护措施之外的处理，并说明原因
- 若 例外种类写成“全部用户数据”：则 例外不支持

## 节点 5　完成与答复

- 若 仅有申请单号：则 状态为处理中，不得写已注销
- 若 用户要求保证即时销号：则 不承诺即时；写合理处理周期待核
- 若 注销后仍发营销短信：则 停止处理不支持，打开营销原子

## 金额与规模

已知处理人数、事件波及人数、上一年度营业额只作区间参数。未知不写零。个保法第 66 条处罚上限只标接口，不输出唯一罚款预测。

下一步按期限灭失、易失证据、能否改变 `Q#`、可逆性排序。相邻原子只写转介和最小交接，不代做。禁止指导伪造同意、补造日志、瞒报或违法取证。
