# 边界与路由

## 正触发

个人要求注销，或服务停止、合同终止后处理者要停止处理并处理账号内个人信息。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 普通删除、查阅、更正 | `处理个人信息主体权利请求` |
| 保存期限总评 | `评估保存期限与删除义务` |
| 劳动解除档案与程序 | 劳动领域 |
| 起诉 | `提起个人信息民事索赔` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

## 易混

账号级停用或服务结束后停处理正触发。只删一条内容走权利请求。不得承诺即时无残留销号。
