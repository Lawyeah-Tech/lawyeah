# 处理账号注销与停止处理

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

形成注销与停止处理方案：路径是否便利、停止处理范围、最短保存例外、证明与答复接口。不保证即时销号。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、处理记录和证据清单。

## 工作边界

正触发：个人要求注销，或服务停止、合同终止后处理者要停止处理并处理账号内个人信息。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只是普通删除某几条信息，账号继续使用；
- 要求保证即时、不可逆销号且无任何保存；
- 劳动解除后的档案与竞业主轴；
- 只要民事起诉包；

本任务不给胜诉率或免罚承诺。审查起草本窗搁置。企业合规整案与知识产权只分流。

## 建立坐标

确认：账号类型；注销入口；未完成交易或余额；法定保存项目；备份与日志；是否涉及未成年人或企业账号多人使用。

同时掌握处理者与权利人双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 制度或合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 义务／风险项；`V#` 评估版本；`E#` 告知／同意／报告凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然免罚、必然合法或唯一处罚金额。未知人数或金额不写零。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验第 15、16、47 条、条例第 23 条及 App 告知同意指南关于注销的现行要求。不虚构案件系统。

工具不可用时继续主体、场景、系统和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [注销与停止处理方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　与普通删除分账

删除单条信息走权利请求原子。本任务处理账号级停止服务与停处理。

### 节点 2　路径便利

注销不得比注册明显更难。不得设置不合理条件或人工障碍。

### 节点 3　停止处理范围

主库、备份、日志、画像、对外已提供副本分列。已提供给第三方的，须通知或说明无法召回的部分。

### 节点 4　最短保存例外

发票、交易、监管报送等例外必须指出条文和期限。例外不得吞并营销库或画像。技术难以删除的转为停止处理。

### 节点 5　完成标志

列可核验完成项。不得把“已提交注销申请”写成已完成。不保证即时销号。

## 停止与安全

- `整体停止`：设置虚假障碍阻挠注销；伪造已删除；借注销勒索未结费用以外的无关授权。
- `字段停止`：法定保存条文与期限未核验；备份是否可召回未知。
- `目标停止`：主目标变为单条删除答复或起诉。
