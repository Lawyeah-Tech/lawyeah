# 边界与路由

## 正触发

数据可能关系国家安全、国民经济命脉、重要民生、重大公共利益。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 重要数据识别 | `识别重要数据` |
| 分类分级 | `开展数据分类分级` |
| 关基义务 | `评估关键信息基础设施运营者义务` |
| 出口管制 | 涉外／管制领域 |
| 刑事 | 刑事领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

## 易混

可能关系国家安全命脉民生、要更严保护接口时正触发。自行宣布或定罪一律停止。出口管制另转。
