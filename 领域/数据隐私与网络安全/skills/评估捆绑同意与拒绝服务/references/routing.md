# 边界与路由

## 正触发

不授权就无法使用基本功能，或多个处理目的捆在一个同意里，或拒绝后频繁弹窗。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 最小必要种类 | `评估最小必要与过度收集` |
| 同意效力 | `评估同意与单独同意` |
| App 下架整改 | `应对App下架通报与整改` |
| C 端 App 审查 | 大众专项，只分流不回改 |
| 告知文本 | `准备隐私政策与告知` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

## 易混

争交互上是否强迫授权或捆在一起时正触发。只问某权限是否必要走最小必要。已被下架要复测走下架原子。
