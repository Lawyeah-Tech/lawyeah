# 边界与路由

## 正触发

要按重要程度和对国家安全、公共利益或个人的危害建立数据目录。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 重要数据识别 | `识别重要数据` |
| 核心数据义务 | `评估核心数据保护义务` |
| 综合合规体系 | 企业合规领域 |
| 处理活动台账 | `建立个人信息处理活动记录` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

## 易混

要建一版可追溯的分类分级目录时正触发。是否已被公布为重要数据走识别原子。不得冒充法定唯一目录。
