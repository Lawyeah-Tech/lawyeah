# 边界与路由

## 正触发

个信侵权争议仍可谈判删除、道歉、赔偿和弃权。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 起诉 | `提起个人信息民事索赔` |
| 应诉 | `应对个人信息民事索赔` |
| 损害测算 | `测算个人信息侵权损害` |
| 行为保全 | `申请停止处理或删除的行为保全` |
| 和解协议审查起草 | 审查起草领域（本窗搁置） |
| 劳动和解 | 劳动领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

## 易混

还能谈删除道歉给钱和弃权范围时正触发。不写已签协议。要打官司走起诉应诉。
