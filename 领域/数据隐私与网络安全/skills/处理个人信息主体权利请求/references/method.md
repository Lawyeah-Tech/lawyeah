# 主体权利请求方法

本文件是可执行判断节点，不是栏目说明书。每个会改变合法性、路径、时限或对外含义的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然免罚、必然合法或唯一处罚金额。未知人数或金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜请求类型｜接收时点｜核验状态｜范围｜准驳依据｜例外｜答复时限｜已执行动作｜判断｜待核`。

---

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填本任务实体结论。

| 信号 | 转出 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

混合信号：本任务主轴可留；专项只作为背景时在缺口标明，不把专项规则硬套进本任务结论。

## 节点 1　分流与受理

- 若 请求实质是注销账号或停止服务后全量停处理：则 转 `处理账号注销与停止处理`
- 若 已进入应诉且用户只要答辩状：则 转 `应对个人信息民事索赔`
- 若 请求人是死者近亲属：则 标 P2 `死者近亲属请求`；未安装则 `unavailable`
- 若 无法确认接收时间：则 时限起算字段停止，不得编造“已超时”或“仍在期限内”

## 节点 2　核验

- 若 核验材料超出确认身份所必要：则 超收红旗，核验范围应限缩
- 若 代理人提出请求：则 核代理权限；权限不明则字段停止
- 若 核验失败一次：则 可一次性说明补正，不得直接写成永久无权请求
- 若 处理者以“系统复杂”拒绝定位：则 现有依据不支持该拒绝，除非能指出合法例外

## 节点 3　分类型判断

运行时核验第 45–48 条。

- 若 查阅复制：则 提供处理种类、来源或副本；商业秘密抗辩不得吞并全部个人信息
- 若 更正补充：则 不准确或不完整的现有依据支持时应当更正；争议事实标争议，不得擅自改写对个人更不利的记录冒充更正
- 若 删除且目的已实现、同意已撤回、违法处理或法律要求删除：则 删除主位；技术难以删除的转为停止处理并标接口
- 若 转移：则 核提供方式、条件和国家网信部门规定；条件未核验则字段停止，不得保证可携出全部数据
- 若 解释说明处理规则：则 解释自动化决策或处理规则，不得用隐私政策链接代替具体说明

禁止：
- 设置积分、付费或到店才能行使权利
- 把法定期限内保存写成可以拒绝查阅

## 节点 4　例外与限制

- 若 主张法律行政法规规定的保存期限未届满：则 必须指出条文和保存范围；超范围部分仍应删除或停处理
- 若 主张删除将损害他人合法权益：则 写明谁的何种权益；写不出则例外依据不足
- 若 限制处理请求：则 核争议期间或法定情形，不得把限制写成永久冻结全部账号功能

## 节点 5　答复状态

- 若 决定准许：则 答复稿接口写执行范围和完成标志，状态保持待发出
- 若 决定拒绝：则 必须写理由和救济途径，不得只写“无法办理”
- 若 部分准许：则 准许与拒绝分列，禁止用“已处理完毕”覆盖未完成部分
- 若 用户要求把草稿写成已送达：则 目标停止该项美化

## 金额与规模

已知处理人数、事件波及人数、上一年度营业额只作区间参数。未知不写零。个保法第 66 条处罚上限只标接口，不输出唯一罚款预测。
