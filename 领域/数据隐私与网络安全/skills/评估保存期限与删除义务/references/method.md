# 保存与删除方法

本文件是可执行判断节点，不是栏目说明书。每个会改变合法性、路径、时限或对外含义的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然免罚、必然合法或唯一处罚金额。未知人数或金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜种类｜目的｜现保存期｜最短必要依据｜法定／约定例外｜到期动作｜技术障碍｜判断｜待核`。

---

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填本任务实体结论。

| 信号 | 转出 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

混合信号：本任务主轴可留；专项只作为背景时在缺口标明，不把专项规则硬套进本任务结论。

## 节点 1　分流

- 若 用户要全公司档案制度或综合合规体系：则 综合合规转出
- 若 已收到删除请求只要准驳：则 转权利请求原子
- 若 账号注销：则 转销号原子，本任务只评保存例外

## 节点 2　最短必要

运行时核验第 19 条。

- 若 告知写“永久保存”且无确定方法：则 期限依据不支持
- 若 目的已实现仍用于新的营销或画像：则 超期兼目的外使用红旗
- 若 同一库混合交易凭证与营销标签且共用十年：则 营销标签期限不支持，须拆分

## 节点 3　法定与约定

- 若 存在会计或监管保存：则 只覆盖该种类；列出条文；未核验则字段停止
- 若 合同约定长于最短必要：则 约定不能对抗个保法最短必要，除非另有合法基础
- 若 为潜在诉讼无限保存全量用户：则 现有依据不支持该无限保存；诉讼保全另案处理

## 节点 4　到期动作

- 若 可删除：则 主位删除并写完成标志
- 若 主张已匿名：则 转匿名化原子；未通过前仍按个人信息保存
- 若 技术难以删除：则 停处理 + 安全保护 + 原因；不得继续使用、提供或公开

## 节点 5　清理优先级

- 若 敏感信息超期：则 优先于普通日志
- 若 已对外提供的超期副本：则 列召回或通知缺口
- 若 人数或容量未知：则 不写零，写待核区间

## 金额与规模

已知处理人数、事件波及人数、上一年度营业额只作区间参数。未知不写零。个保法第 66 条处罚上限只标接口，不输出唯一罚款预测。
