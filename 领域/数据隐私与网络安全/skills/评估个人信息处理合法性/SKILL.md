# 评估个人信息处理合法性

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，对一项或一组已圈定的个人信息处理活动，形成合法性判断：第 13 条基础逐项、告知是否必要、单独同意或书面同意接口、最小必要、最强反方和下一步。

`depends-on` 为空。接受用户或其他来源提供的场景说明、告知文本、同意记录和制度摘录。

## 工作边界

正触发：需要判断特定处理活动能不能做、依据哪一项基础、要不要告知或单独同意。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要总体合规总图或多场景体检；
- 只要对外发布的隐私政策终稿；
- 主问题是出境路径而非境内合法基础；
- 只要起诉状、答辩或事件报告；
- 知识产权、综合合规、医疗业务监管、劳动程序后果为主。

本任务不生成对外告知终稿，不给胜诉率。

## 建立评估坐标

确认：使用者与授权；单方立场；处理活动边界；个人种类是否敏感；是否不满十四周岁；是否自动化决策、对外提供、公开或出境；现有告知和同意材料。

同时掌握双方秘密时先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关文书；`C#` 制度或合同条款；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 基础候选；`V#` 评估版本；`E#` 告知／同意凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验个保法第 13、17、29、31 条及网络数据安全管理条例第 22 条现行文本。工具不可用时继续事实比对；法律结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。

### 1. 圈定活动与个人种类

未圈定活动不得做全产品合法化。敏感信息、儿童信息单独标记。

### 2. 第 13 条逐项

七项独立判断。第 2–7 项支持时不得要求必须再同意。合同必要或人力资源管理必要必须“确属必要”，不得用概括授权冒充。

### 3. 告知与单独同意

告知事项对照第 17 条。依法可不告知的才停告知。敏感信息、对外提供、公开、出境另标单独同意，不在本任务写政策终稿。

### 4. 最小必要与拒绝后果

种类、频率、保存是否为实现目的最短必要。拒绝处理是否导致无法使用基本功能。

### 5. 反方与下一步

最强反方通常是：基础选错、同意无效、超范围、未单独同意。需要政策文本、PIPIA 或出境评估时转介。

## 停止与安全

- `整体停止`：立场不明；伪造同意；活动无法识别。
- `字段停止`：法域或条文未核验。
- `目标停止`：主目标变为总图、告知终稿、出境申报或诉状。
