# 边界与路由

## 正触发

达到定期审计门槛或被要求开展个人信息保护合规审计。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 重要数据识别与年报红旗 | `识别重要数据` |
| 处理活动台账 | `建立个人信息处理活动记录` |
| 综合合规审计 | 企业合规领域 |
| 整改报告 | `准备监管整改报告` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

## 易混

要准备个保合规审计、看触发和找谁审时正触发。不代替审计意见。重要数据年报另衔接。
