# 准备隐私政策与告知

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的处理者立场下，形成“发送前告知包”：告知事项对照、清单化处理规则、单独同意接口、变更告知设计、发布前稿。

`depends-on` 为空。本任务只形成待发布材料，不执行上线，不把发布写成已合法。

## 工作边界

正触发：需要对外告知或更新个人信息处理规则。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 一般用户协议、会员条款或交易合同审查起草（本窗搁置）；
- 只要合法性判断或总体合规总图；
- 只要出境申报或事件报告；
- 用户只要 C 端网站协议与隐私政策商品。

本任务不实施审查起草领域，不回改 C 端商品。

## 建立发文坐标

确认：处理者名称与联系方式；产品范围；处理目的方式种类；敏感信息；儿童；自动化决策；对外提供与出境；保存；权利行使路径；拟发布渠道。

## 来源和判断状态

编号：`S/D/A/R/C/L/I/G/Q/V/E`。文本状态只用 `草案`、`待发布`、`已发布待证明到达`、`停止`。没有发布事实不得写 `已告知全体用户`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

`search_law` 核验第 17、30、39、48 条及条例第 22–23 条、审计办法告知要点。`search_template` 只借栏目结构。

## 五个判断节点

以 [告知方法](references/method.md) 为准。

### 1. 发布闸

活动清单或等价材料必须能支持拟告知的种类和接收方。未知种类不得写“等”来假装穷尽。

### 2. 法定告知事项

对照第 17 条逐项。敏感信息补必要性与影响。出境补接收方信息。

### 3. 发送前正文

显著方式、清晰易懂。清单列明收集的个人信息及处理方式种类。基本功能与附加功能分列。不得预勾选同意。

### 4. 权利路径与变更

查阅复制更正删除限制转移、撤回同意、注销、解释说明的途径。变更须及时告知并标重新同意接口。

### 5. 状态词与不可逆提示

成果保持 `待发布`。发布后难以撤回已读用户的告知效果，上线前必须复核。

## 停止与安全

- `整体停止`：伪造处理规则；隐瞒对外提供或出境；立场不明。
- `字段停止`：接收方、保存期限、出境路径未核验。
- `目标停止`：主目标变为用户协议、合法性总评或出境申报。
