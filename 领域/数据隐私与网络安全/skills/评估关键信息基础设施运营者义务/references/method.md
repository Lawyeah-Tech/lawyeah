# 关基义务方法

本文件是可执行判断节点，不是栏目说明书。每个会改变合法性、路径、时限或对外含义的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然免罚、必然合法或唯一处罚金额。未知人数或金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜设施｜认定状态｜等保之上义务｜采购审查｜境内存储｜事件报告｜判断｜待核`。

---

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填本任务实体结论。

| 信号 | 转出 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

混合信号：本任务主轴可留；专项只作为背景时在缺口标明，不把专项规则硬套进本任务结论。

## 节点 1　认定

- 若 已收到保护工作部门认定通知：则 已认定，按关基义务评估
- 若 仅内部认为“可能是”：则 可能被认定红旗，不得对外写成已是关基
- 若 用户要求自行公告关基身份：则 停止该宣布

## 节点 2　义务

运行时核验关基保护条例。

- 若 已认定：则 列安全保护机构、负责人、检测评估、演练等接口，不代替测评机构结论
- 若 只要等保材料：则 转等保原子

## 节点 3　采购与审查

- 若 采购可能影响安全的网络产品服务：则 打开网络安全审查原子
- 若 产品来自境外且可能影响国家安全：则 审查红旗，不保证结果

## 节点 4　存储出境事件

- 若 关基运营者向境外提供个人信息或重要数据：则 出境评估主位
- 若 发生安全事件：则 打开事件原子，关基报告义务待核

## 节点 5　行业部门

- 若 保护工作部门已启动专项检查程序：则 可分流行业专项，本任务只留义务接口

## 金额与规模

已知处理人数、事件波及人数、上一年度营业额只作区间参数。未知不写零。个保法第 66 条处罚上限只标接口，不输出唯一罚款预测。

下一步按期限灭失、易失证据、能否改变 `Q#`、可逆性排序。相邻原子只写转介和最小交接，不代做。禁止指导伪造同意、补造日志、瞒报或违法取证。
