# 边界与路由

## 正触发

主张合同履行、跨境人事、紧急情况、低量或自贸区负面清单外，免予评估／标准合同／认证。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 路径总评 | `评估数据出境路径` |
| 安全评估申报 | `准备数据出境安全评估申报` |
| 标准合同 | `准备个人信息出境标准合同备案` |
| 重要数据识别 | `识别重要数据` |
| 远程运维是否出境 | `评估境外远程运维访问是否出境` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

## 易混

主张某一项便利化豁免是否成立时正触发。豁免不免告知和安全。含重要数据或拆数量一律挡住。
