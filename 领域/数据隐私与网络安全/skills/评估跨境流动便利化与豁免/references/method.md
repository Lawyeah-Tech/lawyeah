# 出境豁免方法

本文件是可执行判断节点，不是栏目说明书。每个会改变合法性、路径、时限或对外含义的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然免罚、必然合法或唯一处罚金额。未知人数或金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜主张条款｜确需事实｜是否含重要数据｜累计人数｜自贸区清单｜残留义务｜判断｜待核`。

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填本任务实体结论。

| 信号 | 转出 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

混合信号：本任务主轴可留；专项只作为背景时在缺口标明，不把专项规则硬套进本任务结论。

## 节点 1　分流

- 若 用户尚未选定要主张哪一项豁免且只要总路径：则 转路径原子
- 若 用户要拆分主体以压低累计：则 整体停止规避方案

## 节点 2　第 3 条

- 若 国际贸易跨境运输学术合作跨国生产制造市场营销中收集产生且不含个人信息也不含重要数据：则 第 3 条候选
- 若 含个人信息或重要数据：则 第 3 条不支持

## 节点 3　第 5 条确需

- 若 订立履行个人为一方的合同所确需：则 写明哪份合同哪类信息确需；整包营销库不支持
- 若 跨境人事所确需：则 须有合法劳动规章制度或集体合同，范围限于人事
- 若 紧急保护生命健康财产所确需：则 须有紧急事实，日常风控不支持
- 若 关基以外且累计不满规定人数且不含敏感个人信息：则 低量候选；人数未知不写零；阈值运行时核验

## 节点 4　重要数据与自贸区

- 若 重要数据已告知或公布：则 不得主张第 5 条低量豁免
- 若 主张自贸区负面清单外：则 须有清单文本及适用主体事实，否则依据不足

## 节点 5　残留义务

- 若 豁免成立：则 仍须告知、合法基础、安全、第 39 条（依法除外）
- 若 用户把豁免写成可以不告知：则 停止该表述

## 金额与规模

已知处理人数、事件波及人数、上一年度营业额只作区间参数。未知不写零。个保法第 66 条处罚上限只标接口，不输出唯一罚款预测。
