# 并购破产转移方法

本文件是可执行判断节点，不是栏目说明书。每个会改变合法性、路径、时限或对外含义的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然免罚、必然合法或唯一处罚金额。未知人数或金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜程序类型｜移交范围｜接收方｜告知｜异议｜义务承继｜判断｜待核`。

---

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填本任务实体结论。

| 信号 | 转出 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

混合信号：本任务主轴可留；专项只作为背景时在缺口标明，不把专项规则硬套进本任务结论。

## 节点 1　分流

- 若 用户要交易结构或交割清单统筹：则 投资并购领域
- 若 用户要破产申请或管理人职责：则 破产领域
- 若 并非合并分立解散破产等原因：则 按对外提供或委托评估

## 节点 2　告知

运行时核验第 22 条。

- 若 未告知接收方名称联系方式：则 告知不支持
- 若 接收方变更后未再告知：则 告知不支持

## 节点 3　承继与异议

- 若 接收方改变原处理目的方式：则 应重新取得同意或其他合法基础，不得只靠转移条款
- 若 个人提出异议：则 列停止移交或限缩范围接口，不得无视

## 节点 4　范围与安全

- 若 移交范围含无关系统：则 必要不支持
- 若 接收方无安全措施证据：则 安全保障依据不足

## 节点 5　输出

- 若 告知、承继、范围、安全支持：则 可按该范围转移
- 若 实为出售数据包：则 不支持按第 22 条豁免单独同意

## 金额与规模

已知处理人数、事件波及人数、上一年度营业额只作区间参数。未知不写零。个保法第 66 条处罚上限只标接口，不输出唯一罚款预测。

下一步按期限灭失、易失证据、能否改变 `Q#`、可逆性排序。相邻原子只写转介和最小交接，不代做。禁止指导伪造同意、补造日志、瞒报或违法取证。

## 补强：移交范围与交割时点

- 若 股权转让未导致处理者变更，仅股东变化：则 不当然适用第 22 条转移，按日常处理评估。
- 若 资产包交割日与告知日不一致：则 告知必须覆盖实际接收方，交割前未告知则该时点转移依据不足。
- 若 接收方拟把人事档案用于新营销：则 改变目的，须重新取得同意或其他基础，不得只靠并购条款。
- 若 破产管理人要求移交全量备份：则 范围仍受必要原则约束，与破产程序交接分列。
