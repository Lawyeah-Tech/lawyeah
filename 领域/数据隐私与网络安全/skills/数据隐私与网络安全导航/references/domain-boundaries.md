# 数据隐私领域边界

本表只说明归属。每次路由先核对 [当前能力地图](capability-map.md)；未安装入口输出 `unavailable`。

| 相邻 | 本包入口 | 转出 |
| --- | --- | --- |
| 合同审查与起草 | 隐私政策、告知、委托处理要点、出境标准合同属于本领域制度/出境文件 | 一般交易合同签前审查起草：本窗搁置，只说明不实施 |
| 知识产权 | 个人信息与数据治理 | 商标专利著作权确权、商业秘密权利基础与侵权损失 |
| 企业合规 | 数据和网络安全专项体系 | 企业级制度体系、反商业贿赂、舞弊调查 |
| 医疗医药 | 医疗健康个人信息专项治理 | 诊疗过错、病历鉴定、药品器械和医疗机构监管 |
| 劳动 | 员工信息的个保合法性 | 用工目的、处分解除、民主程序和劳动法后果 |
| 刑事 | 评估中的刑民交叉只标红旗 | 侵犯公民个人信息罪的控告与辩护 |
| 行政争议 | 处罚事实与申辩要点接口 | 行政复议诉讼文书和通用程序代理 |
| 投资并购 / 破产 | 合并分立破产中的个人信息转移接口 | 交易结构、交割统筹、破产程序 |
| 竞争法 | 自动化决策中的个信规则 | 以市场排除或反爬虫竞争秩序为主要成果 |
| C 端 App 审查 | 专业合规总图或 SDK 记录 | 大众第一轮对照清单 |
| C 端个信投诉 | 专业起诉包 | 大众投诉材料 |
| C 端网站协议隐私 | 专业告知原子 | 大众网站协议套件 |
| C 端网络名誉 / 肖像 | 处理合法性切片 | 名誉诽谤或肖像商业使用主轴 |

行业场景只作为上下文参数。专项段只分流，不把相邻领域规则写入本包结论。
