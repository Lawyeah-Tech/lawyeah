# 边界与路由

## 正触发

要定级备案测评，或要把等保与数据安全防护衔接。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 关基义务 | `评估关键信息基础设施运营者义务` |
| 密评 | `评估商用密码与关键系统密码应用` |
| 网络安全审查 | `评估是否触发网络安全审查` |
| 分类分级 | `开展数据分类分级` |
| 综合合规 | 企业合规领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

## 易混

要定级备案测评或和数据安全怎么衔接时正触发。不代替测评机构。关基、密评另项。
