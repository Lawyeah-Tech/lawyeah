# 边界与路由

## 正触发

要把个人信息处理委托给供应商、云或外包。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 共同处理 | `评估共同处理安排` |
| 向第三方提供 | `评估向第三方提供个人信息` |
| 供应商角色盘点 | `评估处理者与供应商数据义务` |
| 一般采购合同审查 | 审查起草领域（本窗搁置） |
| C 端供应商尽调 | 大众专项，只分流 |
| PIPIA | `开展个人信息保护影响评估` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

## 易混

处理者指示供应商按其约定处理时正触发。对方自己决定目的走共同处理或对外提供。不审查整份采购合同。
