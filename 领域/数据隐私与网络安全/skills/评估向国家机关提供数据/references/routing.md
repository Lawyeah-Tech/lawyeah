# 边界与路由

## 正触发

公安、国安、法院、监察或外国执法索取数据。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 刑事辩护控告 | 刑事领域 |
| 出境路径 | `评估数据出境路径` |
| 监管约谈 | `应对网信约谈与监督检查` |
| 民事调查令文书 | 相应民事程序，不在本任务实施 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

## 易混

谁来要数据、能不能给、外国执法要不要批准时正触发。国内合法调取不对抗。外国执法擅给是禁止项。
