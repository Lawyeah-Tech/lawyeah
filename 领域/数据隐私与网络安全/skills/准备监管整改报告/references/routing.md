# 边界与路由

## 正触发

约谈或处罚后要书面整改报告。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 处罚申辩 | `应对数据网络安全行政处罚` |
| 约谈答复 | `应对网信约谈与监督检查` |
| App 下架复测 | `应对App下架通报与整改` |
| 综合合规 | 企业合规领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

## 易混

监管要一份书面整改时正触发。别把计划写成已经做完。申辩和 App 复测另项。
