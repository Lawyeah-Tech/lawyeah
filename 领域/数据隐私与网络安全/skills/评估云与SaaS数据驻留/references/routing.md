# 边界与路由

## 正触发

上云、多可用区、境外 Region 或 SaaS。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 远程运维出境认定 | `评估境外远程运维访问是否出境` |
| 境内存储义务 | `评估境内存储与本地化` |
| 出境路径 | `评估数据出境路径` |
| 供应商盘点 | `评估处理者与供应商数据义务` |
| 云采购合同审查 | 审查起草领域（本窗搁置） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

## 易混

上云或选 Region、要驻留和子处理器表时正触发。运维算不算出境走远程访问。合同怎么改搁置。
