# 网络安全审查方法

本文件是可执行判断节点，不是栏目说明书。每个会改变合法性、路径、时限或对外含义的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然免罚、必然合法或唯一处罚金额。未知人数或金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜场景｜触发类型｜门槛核验｜是否已申报｜暂停风险｜判断｜待核`。

---

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填本任务实体结论。

| 信号 | 转出 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

混合信号：本任务主轴可留；专项只作为背景时在缺口标明，不把专项规则硬套进本任务结论。

## 节点 1　分流

- 若 证券发行文件或估值：则 证券／投行领域
- 若 只要关基日常义务：则 转关基原子

## 节点 2　采购触发

- 若 关基采购且可能影响国家安全：则 审查触发候选
- 若 是否影响国家安全依据不足：则 触发字段停止，不得写成一定不审

## 节点 3　上市触发

运行时核验审查办法关于国外上市的数量门槛。

- 若 赴国外上市且处理个人信息：则 核数量；未核验不得写一定触发或一定不触发
- 若 赴香港上市：则 对照现行办法是否纳入，未核验字段停止
- 若 国内上市：则 通常不是本触发，证券义务另转

## 节点 4　暂停与抢跑

- 若 应申报尚未申报却计划交割或挂牌：则 暂停风险红旗，不指导抢跑
- 若 用户要保证通过：则 停止保证

## 节点 5　输出

- 若 触发支持：则 列申报红旗和暂停风险
- 若 触发不支持：则 写明理由，仍可能有其他国家安全审查

## 金额与规模

已知处理人数、事件波及人数、上一年度营业额只作区间参数。未知不写零。个保法第 66 条处罚上限只标接口，不输出唯一罚款预测。

下一步按期限灭失、易失证据、能否改变 `Q#`、可逆性排序。相邻原子只写转介和最小交接，不代做。禁止指导伪造同意、补造日志、瞒报或违法取证。

## 补强：上市与采购时点

- 若 赴国外上市辅导已开始但人数门槛未核验：则 触发字段停止，不得写成一定不申报。
- 若 关基采购合同已签约尚未到货：则 标暂停履行风险，不指导抢先上线造成既成事实。
- 若 数据处理者赴香港或国外上市口径冲突：则 对照现行办法文本，未核验则字段停止。
- 若 用户要保证“报了就能过”：则 停止保证。
