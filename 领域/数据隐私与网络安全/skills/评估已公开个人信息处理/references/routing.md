# 边界与路由

## 正触发

拟抓取、汇集或二次使用个人自行公开或已合法公开的个人信息。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 处理者自己公开个人信息 | `评估公开个人信息` |
| 合法性总评 | `评估个人信息处理合法性` |
| 肖像商用或名誉 | 人格权／C 端专项，只分流 |
| 反爬虫或数据产权 | 竞争法或知识产权领域 |
| 新闻舆论监督合法基础总评 | `评估个人信息处理合法性` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

## 易混

二次使用已经公开的个人信息时正触发。自己把未公开信息发上网走公开原子。不得写成公开即可任意用。
