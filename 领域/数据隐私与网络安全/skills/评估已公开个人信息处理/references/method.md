# 已公开信息处理方法

本文件是可执行判断节点，不是栏目说明书。每个会改变合法性、路径、时限或对外含义的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然免罚、必然合法或唯一处罚金额。未知人数或金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜来源｜是否合法公开｜原范围｜拟用途｜是否超出合理范围｜个人拒绝｜重大影响｜判断｜待核`。

---

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填本任务实体结论。

| 信号 | 转出 |
| --- | --- |
| 商业秘密、专利商标著作权权利本身 | 知识产权领域 |
| 企业级合规体系、反商业贿赂、舞弊内部调查 | 企业合规领域 |
| 诊疗过错、病历鉴定、药品器械或医疗机构监管本身 | 医疗医药领域 |
| 解除、处分、民主程序等劳动法后果为主 | 劳动领域 |
| 侵犯公民个人信息罪控告或辩护 | 刑事领域 |
| 一般交易合同签前审查起草 | 审查起草领域（本窗搁置，只说明不实施） |

混合信号：本任务主轴可留；专项只作为背景时在缺口标明，不把专项规则硬套进本任务结论。

## 节点 1　分流

- 若 处理者拟主动公开尚未公开的个人信息：则 转 `评估公开个人信息`
- 若 主轴是肖像商用或名誉：则 转人格权或 C 端肖像／名誉，只分流
- 若 主轴是反爬虫或竞争秩序：则 转竞争法或知识产权
- 若 新闻舆论监督：则 第 13 条第 5 项另核，本任务不自动写成已合法

## 节点 2　来源

- 若 来源是官方公布、判决书依法公开或个人主动展示：则 合法公开候选，仍须核原范围
- 若 来源是泄露库、暗网或来源不明数据包：则 合法公开不支持
- 若 来源是超robots或突破访问控制的爬取：则 不得写成合法公开；竞争法问题另转

## 节点 3　合理范围

运行时核验第 27 条。

- 若 用途与原公开目的一致且未汇聚：则 合理范围可支持
- 若 用于用户画像、评分或差异定价：则 通常超出合理范围，须同意或其他基础
- 若 与其他来源拼接再识别：则 超出合理范围候选，并打开匿名化／再识别原子

## 节点 4　拒绝与重大影响

- 若 个人已明确拒绝：则 不得处理
- 若 对个人权益有重大影响：则 应取得同意；影响机制必须可写
- 若 敏感个人信息：则 不得仅凭曾经公开就降低敏感规则

## 节点 5　输出

- 若 来源合法、未超范围、未拒绝、无重大影响：则 可在该范围内处理，仍要安全保护
- 若 任一项不支持：则 不得继续该用途，或转同意／合法性原子
- 若 用户要求写成“公开即可任意用”：则 整体停止该表述

## 金额与规模

已知处理人数、事件波及人数、上一年度营业额只作区间参数。未知不写零。个保法第 66 条处罚上限只标接口，不输出唯一罚款预测。

下一步按期限灭失、易失证据、能否改变 `Q#`、可逆性排序。相邻原子只写转介和最小交接，不代做。禁止指导伪造同意、补造日志、瞒报或违法取证。
