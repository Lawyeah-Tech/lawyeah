# 边界与路由

## 正触发

监管约谈或补贴结算仍可谈。

立场：单方。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 处罚申辩 | 准备环境行政处罚陈述申辩 |
| 补贴资格评估 | 评估可再生能源消纳补贴与绿证 |
| 已签字审查 | 审查起草（本窗搁置） |
| 虚假承诺骗补 | 整体停止 |
| 并网条件评估 | 评估电力市场交易与并网接入 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 反垄断承诺 | 竞争领域 |
| 上市公司监管承诺 | 证券接口 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

监管约谈承诺不是陈述申辩。放弃诉讼请求不能写成行政机关已经撤销决定。
