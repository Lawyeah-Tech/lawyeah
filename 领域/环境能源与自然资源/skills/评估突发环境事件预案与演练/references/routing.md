# 边界与路由

## 正触发

预案未备案、未演练、风险评估缺失或专项预案过期，单位需要义务缺口判断。

立场：生产经营单位。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 已发生事件要报告 | 准备突发环境事件报告与应急 |
| 倒签备案或假演练 | 整体停止 |
| 总图 | 评估环境能源与资源事项 |
| 现场检查即将开始 | 应对环境现场检查与调查询问 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 安全生产应急预案主轴 | 可标安监接口，环境预案仍可留 |
| 核事故应急 | P2 核能 unavailable |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

预案备案不是事故报告。补做演练不能消灭已经发生的未备案违法。事故发生后本任务不再写报告终稿。
