# 边界与路由

## 正触发

处罚或命令已送达，需要实体复议理由，而不是复议程序方法。

立场：当事人。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 复议管辖格式期限程序 | 行政救济领域 |
| 决定前申辩 | 准备环境行政处罚陈述申辩 |
| 实体诉讼理由 | 准备环境处罚实体诉讼理由 |
| 时效精算 | 评估环境违法追责时效 |
| 一般行政诉讼程序 | 行政救济领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 行政赔偿程序 | 行政救济领域 |
| 矿业股权并购中的处罚包袱 | 投资并购整案转出，处罚实体可留接口 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

实体理由清单不是复议申请书。起诉期限和复议期限计算属于行政领域。本任务不填申请书格式栏目。
