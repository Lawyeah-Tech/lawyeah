# 边界与路由

## 正触发

屋顶光伏、储能、氢能项目接入或备案受阻。

立场：投资人。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 屋顶租赁主轴 | 合同争议或房地产领域 |
| 集中式核准 | 评估能源项目核准备案与节能审查 |
| 电力市场交易 | 评估电力市场交易与并网接入 |
| 违规并网 | 整体停止 |
| 补贴绿证 | 评估可再生能源消纳补贴与绿证 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 建筑光伏一体化规划许可 | 房地产接口 |
| 危化品氢能生产 | 安监接口，不替代 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

备案不是并网调度协议。屋顶租赁合同有效不是已经取得并网。氢能项目不能只按光伏备案规则处理。
