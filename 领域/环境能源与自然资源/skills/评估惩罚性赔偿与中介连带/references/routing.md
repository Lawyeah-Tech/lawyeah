# 边界与路由

## 正触发

拟主张或抗辩惩罚性赔偿，或环评、监测、运维机构连带。

立场：单方。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 普通私益路径 | 评估环境污染侵权请求或抗辩 |
| 环评造假专项 | 评估环评文件失实与中介责任 |
| 第三方运维 | 评估第三方治理与设施运维责任 |
| 编造故意 | 整体停止 |
| 定罪 | 刑事领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 消费惩罚性 | 不在本包 |
| 公益中的惩罚性 | 须单独核验适用 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

无过错责任成立不等于惩罚性成立。中介一般质量瑕疵不是第 65 条故意失实。倍数不是谈判口号。
