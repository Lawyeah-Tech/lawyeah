# 边界与路由

## 正触发

占用林地草地湿地、采伐或流转需要权利与许可判断。

立场：使用权人或建设单位（强制单方）。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 农村承包流转 | 只分流 |
| 房地开发主轴 | 房地产物业领域 |
| 保护地红线 | 评估野生动植物与保护地红线 |
| 毁林填湿操作 | 整体停止 |
| 工程造价 | 建设工程领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 征地拆迁补偿包 | C 端拆迁／房地产或行政，只分流 |
| 碳汇交易 | 碳配额原子接口 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

林地使用许可不是建设用地规划许可。缴纳植被恢复费不是已经完成生态修复。承包经营权流转不改变林地用途管制。
