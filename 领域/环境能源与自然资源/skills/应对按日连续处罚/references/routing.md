# 边界与路由

## 正触发

因拒不改正被按日计罚或面临计罚，当事人需要起点和程序判断。

立场：当事人。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 普通罚款申辩 | 准备环境行政处罚陈述申辩 |
| 责令改正履行 | 应对责令改正限制生产停产 |
| 承诺当已改正 | 不支持该等同 |
| 复议程序方法 | 行政救济领域 |
| 时效主成果 | 评估环境违法追责时效 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 行政强制执行 | 行政救济领域 |
| 信用修复 | 评估重点排污单位与环境信用 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

提交整改方案不是改正完成。计罚日数不能从责令改正作出日起算，须按复查拒不改正的规则核验。
