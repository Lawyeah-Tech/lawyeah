# 边界与路由

## 正触发

委托运营、监测运维或第三方治理后仍超标，委托人或运营人需要法定与合同责任分账。

立场：委托人或第三方运营人（强制单方）。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 价款工期质量主轴 | 建设工程或合同争议领域 |
| 运维合同改稿 | 审查起草（本窗搁置） |
| 处罚申辩 | 准备环境行政处罚陈述申辩 |
| 中介连带精算 | 评估惩罚性赔偿与中介连带 |
| 故意停运设施 | 整体停止指导 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 一般合同解除程序 | 合同争议领域 |
| PPP 特许经营整案 | 可留环境法定责任，特许主轴标投资接口 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

第三方治理合同不能消灭排污许可主体责任。运维费未付不是合法停运环保设施的理由。
