# 边界与路由

## 正触发

对核查报告或配额分配不服。

立场：控排单位。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 配额履约总评 | 评估碳配额履约与交易 |
| 伪造数据 | 整体停止 |
| 行政诉讼程序 | 行政救济领域 |
| 监测数据行政违法 | 评估自行监测与排污数据合规 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 上市公司环境信息披露 | 信息公开原子接口 |
| 第三方核查机构责任 | 中介连带接口 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

核查异议不是可以改历史排放以逃避清缴。配额分配政策调整不是个案数据错误。
