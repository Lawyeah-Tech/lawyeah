# 边界与路由

## 正触发

检查、处罚或督察后需要可核验整改方案，排污单位尚未要求本任务写申辩终稿。

立场：排污单位。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 陈述申辩主成果 | 准备环境行政处罚陈述申辩 |
| 督察拆解主成果 | 应对环保督察反馈与整改 |
| 虚假整改 | 整体停止 |
| 修复施工图造价 | 建设工程领域 |
| 责令停产履行边界 | 应对责令改正限制生产停产 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 信用修复决定 | 评估重点排污单位与环境信用 |
| 一般履职程序 | 行政救济领域 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

整改方案不是申辩。承诺整改不等于已经改正，不能对抗按日计罚的“已改正”要件。
