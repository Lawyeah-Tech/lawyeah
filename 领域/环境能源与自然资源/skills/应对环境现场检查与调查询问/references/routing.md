# 边界与路由

## 正触发

执法检查、采样或询问笔录即将或正在发生，被检查人需要合法配合边界。

立场：被检查人。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 阻碍或调样 | 整体停止 |
| 申辩终稿 | 准备环境行政处罚陈述申辩 |
| 事故报告 | 准备突发环境事件报告与应急 |
| 刑事讯问 | 刑事领域 |
| 查封停产履行 | 应对责令改正限制生产停产 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 一般行政检查程序方法整案 | 行政救济领域，本任务只留环境现场实体 |
| 海关或海南海事登临 | 海事或海关接口 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

拒绝在错误笔录上签字不是阻碍执法。销毁台账不是“整理材料”。采样见证不能事后补拍。
