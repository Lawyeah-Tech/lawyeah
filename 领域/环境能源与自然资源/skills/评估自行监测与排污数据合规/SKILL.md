# 评估自行监测与排污数据合规

## 任务目标

在明确、无利益冲突的排污单位立场下，形成“自行监测与排污数据合规矩阵”：监测义务范围、自动与手工监测分账、执行报告、数据有效性争点、逃避监管红旗、补证和下一步。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：自动监测、手工监测、执行报告或排污数据有效性已被检查、约谈、处罚告知或民事对方质疑，单方需要合规判断和补证路径。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要总体事项总图，不要监测专项；
- 用户要求改数、关停或遮挡监控、调换样品；
- 主目标已是发送版陈述申辩或应急报告；
- 涉嫌伪造监测数据且用户只要刑事辩护或控告（转刑事）；
- 工程施工价款或房地交易主轴；

本任务不给胜诉率，未知金额不写零。

## 建立工作坐标

确认：使用者与授权；单方立场（排污单位）；相对方、主管机关及可能责任主体；关键文本版本；法域；当前检查、处罚、协商、诉讼或执行状态；机关文书作出与送达；对方已知主张；关键材料及缺失。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 许可、标准或合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩或义务假设；`V#` 版本；`E#` 送达／监测／履行凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。

## 使用 Lawyeah MCP

宿主可调用时：search_law 核验排污许可管理条例、自行监测指南、生态环境监测条例接口、逃避监管排放罚则；search_practiced 补自动监测有效性与执行报告争点。禁止检索或输出改数方法。 不虚构案件系统。核验重点：排污许可管理条例及 2024 年管理办法、环境保护法监测义务、刑法伪造监测数据红旗（不定罪）。

工具不可用时继续事实、主体、程序文书状态和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　专项分流与监测身份

先分流再固定许可证、排放口、监测点位和数据期间。

### 节点 2　监测义务与覆盖范围

义务来自许可、标准和名录，不来自口头习惯。

### 节点 3　数据真实性与有效性

有效性审核、标记、修约和缺失分列。

### 节点 4　逃避监管红旗

红旗不是定罪，也不等于行政处罚已成立。

### 节点 5　补证、申辩接口和下一步

本任务不出发送版申辩或报告。


## 停止与安全

- `整体停止`：立场或授权不明；用户坚持伪造、删改或关停监控；利益冲突未解；基础主体无法建立。
- `字段停止`：许可证身份、监测标准、有效性规则、期限未核验；法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标变为改数、申辩终稿、应急报告或刑事辩护。
