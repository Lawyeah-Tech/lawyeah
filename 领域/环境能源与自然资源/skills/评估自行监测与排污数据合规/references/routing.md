# 边界与路由

## 正触发

自动监测、手工监测、执行报告或排污数据有效性已被检查、约谈、处罚告知或民事对方质疑，单方需要合规判断和补证路径。

立场：排污单位。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要总图 | 评估环境能源与资源事项 |
| 只要许可是否闭合 | 评估环评与排污许可缺口 |
| 发送处罚申辩 | 准备环境行政处罚陈述申辩 |
| 伪造数据刑事辩护或控告 | 刑事领域 |
| 改数或关停监控 | 整体停止，不实施 |
| 完整证据卷 | 建立环境污染与生态损害证据案卷 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 施工造价鉴定 | 建设工程领域 |
| 一般复议格式或起诉期限计算 | 行政救济领域 |
| 船舶监测或海上溢油数据 | 海事领域 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

执行报告填报错误不等于伪造监测数据。自动监测故障有报修记录时，不得直接写成逃避监管。数据被质疑时本任务评估争点，不代写申辩终稿。
