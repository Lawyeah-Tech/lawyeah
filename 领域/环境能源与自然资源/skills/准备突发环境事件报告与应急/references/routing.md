# 边界与路由

## 正触发

已经发生或可能发生突发环境事件，需要发送前依法报告稿和应急边界。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要预案备案演练评估 | `评估突发环境事件预案与演练`（未安装则 `unavailable`） |
| 只要事项总图 | `评估环境能源与资源事项` |
| 处罚申辩 | `准备环境行政处罚陈述申辩` |
| 保全现场证据且不要报告 | `保全污染现场与监测证据`（未安装则 `unavailable`） |
| 船舶海上溢油 | 海事领域 |
| 要求瞒报或倒签 | 整体停止，不提供替代话术 |

## 易混

厂内异常尚未定性时，正触发按可能事件处理，不得写成“等第三方监测出来再报”。日常超标排污未达事件标准时，说明报告闸未打开，转许可或处罚路径，仍不得建议销毁数据。
