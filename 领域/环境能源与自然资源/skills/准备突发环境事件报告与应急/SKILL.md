# 准备突发环境事件报告与应急

## 任务目标

在明确、无利益冲突的单方立场下，于现有依据支持依法报告时，形成“发送前突发环境事件报告与应急包”：事件定性闸、报告时限与对象、发送前报告稿、通报与应急动作、禁止项和到达设计。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实和监测材料。

本任务只形成待发送材料，不执行发送，不伪造送达，不把内部便签写成已经依法报告。

## 工作边界

正触发：中国大陆企业事业单位已经发生或可能发生突发环境事件，需要依法报告并采取应急措施。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要预案备案或演练评估，不要报告稿；
- 只要事项总图；
- 用户要求迟报、谎报、瞒报或倒签；
- 船舶碰撞、海上溢油主轴（海事领域）；
- 只要处罚申辩或民事诉状。

本任务不指导进入危险区、破坏现场或调换样品，不给“可以先不报”的合法化结论，除非现行规则核验后支持不属于报告范围。

## 建立发函坐标

确认：使用者与授权；单方立场；事件发现时间、地点、污染物或风险物质、已采取措施；预案及备案；拟报告机关；法域；是否已有人员伤亡或环境敏感目标；关键材料及缺失。

同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关文书；`C#` 预案或许可定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 报告义务假设；`V#` 报告版本；`E#` 发送／送达凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

报告状态只用 `草案`、`待发送`、`已发送待证明到达`、`已到达`、`停止`。没有送达事实和规则引文，禁止写 `已依法报告`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验突发环境事件应急管理办法、环保法和地方报告时限；`search_template` 只借报告栏目。工具不可用时继续事实和时间线；时限和法律定性字段停止，仍须提示不得瞒报。

## 五个判断节点

执行顺序和停止条件以 [报告方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 专项分流和报告闸

船舶海事转出。用户要求瞒报或倒签：整体停止。先判断是否属于或可能属于突发环境事件；依据不足时按可能事件处理，不写成可以等待监测完成再决定是否报告。

### 2. 时限、对象和初报续报

核验发现后初次报告时限、续报和终报。对象含生态环境主管部门和可能受影响地区。时限未核验则字段停止，仍列出已知发现时刻。

### 3. 发送前报告正文

只写已支持的时间、地点、排放或泄漏物质、已知影响、已采取措施和请求支援。未知标未知，不编造已控制。不倒签。

### 4. 应急动作与禁止项

启动预案、切断源、通知下游、保护人员。禁止破坏现场、冲洗灭迹、关闭监控或阻挠采样。

### 5. 到达设计与不可逆提示

预列渠道、实施人、回证。成果保持 `待发送`。内部群消息不等于依法报告。

## 停止与安全

- `整体停止`：立场不明；用户坚持瞒报、倒签、毁证。
- `字段停止`：报告时限、分级标准未核验。
- `目标停止`：主目标变为申辩、起诉或预案修订。

本任务不执行发送，不伪造送达。
