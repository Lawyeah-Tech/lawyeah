# 边界与路由

## 正触发

农用地或建设用地土壤污染调查、风险管控或修复责任不明，土地使用权人或责任人需要识别义务。

立场：土地使用权人或土壤污染责任人（强制单方）。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 地块交易主轴 | 房地产物业领域 |
| 修复施工结算 | 建设工程领域 |
| 修复费用精算 | 测算生态环境损害与修复费用 |
| 农村承包流转 | 只分流 |
| 矿区修复主成果 | 评估矿区生态修复义务 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 征地供地程序 | 房地产或行政，只分流 |
| 一般行政诉讼程序 | 行政救济领域 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

土壤污染状况调查报告不是修复验收。土地使用权人配合调查不等于已被认定为责任人。建设用地名录与农用地分类不得混用。
