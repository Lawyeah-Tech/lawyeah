# 边界与路由

## 正触发

已决定就矿业权、取水权等起诉。

立场：原告。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 房地或承包 | 房地产或农村土地领域 |
| 污染侵权起诉 | 提起环境污染侵权诉讼 |
| 行政程序方法 | 行政救济领域 |
| 股权并购整案 | 投资并购领域 |
| 应诉该权利诉讼 | 应对自然资源权利诉讼 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 海事海域权属 | 可能转海事或留海域原子接口 |
| 执行 | 胜诉后转执行接口 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

矿业权民事起诉不是环境侵权起诉。不服吊销许可证主要是行政诉讼，不能只写民事确认之诉了事。
