# 边界与路由

## 正触发

已决定提起环境污染或生态破坏私益侵权一审。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 尚未决定，只要总图 | `评估环境能源与资源事项` |
| 被告应诉 | `应对环境污染侵权诉讼` |
| 公益诉讼 | `提起环境民事公益诉讼`（未安装则 `unavailable`） |
| 政府生态损害赔偿诉讼 | `提起生态环境损害赔偿诉讼`（未安装则 `unavailable`） |
| 工伤 | 劳动领域 |
| 施工质量 | 建设工程领域 |
| 大众网上立案材料且请求已闭合 | C 端 011，只分流 |

## 易混

渔民索赔是私益。检察院起诉是公益。市政府指定部门起诉是生态损害赔偿。三类不得混用一份诉状。
