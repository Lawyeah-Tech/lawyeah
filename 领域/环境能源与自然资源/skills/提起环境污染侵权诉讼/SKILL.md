# 提起环境污染侵权诉讼

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的原告立场下，形成可复核、不代提交的“环境污染私益侵权起诉包”：起诉状草稿、分项诉讼请求、管辖连结点、证据目录和保全红旗。

`depends-on` 为空。接受用户、律师或其他来源的等价评估、测算和证据清单。

## 工作边界

正触发：中国大陆污染环境或破坏生态造成人身、财产损害，用户已决定向人民法院提起私益侵权一审。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要总体评估或证据目录，尚未决定起诉；
- 社会组织或检察机关提起公益诉讼；
- 政府指定部门提起生态环境损害赔偿诉讼；
- 已收到起诉状、用户实为被告；
- 工程施工质量或工伤主轴。

C 端 011 只分流：主体请求已闭合且只要大众立案材料时可提及；本技能仍做专业请求判断，不回改 011。

本任务不代提交，不保证受理或胜诉，不写保全申请终稿。

## 建立起诉坐标

确认：使用者与授权；原告；被告及可能共同被告（含帮助人或中介机构）；损害事实；法域；是否已有案号；管辖连结点；关键材料。

已有受理凭证时停止生成起诉入口材料。

## 来源和判断状态

编号：`S#` 陈述；`D#` 材料；`A#` 承认；`R#` 文书；`C#` 标准或许可；`L#` 已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求假设；`P#` 诉讼请求；`J#` 管辖；`V#` 稿件版本；`E#` 送达凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典第 1229–1235 条、侵权解释、证据规定、管辖；`search_template` 只借起诉状栏目。

工具不可用时继续主体、事实和证据目录；请求法律结论、管辖选定、期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [起诉方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、起诉决定和请求类型闸

公益或政府索赔转出。工伤转劳动。施工质量转工程。

### 2. 主体与分项请求

人身、财产、预防费用、行为禁令、惩罚性分列。不得同时主张第 1235 条生态损害。

### 3. 管辖连结点

侵权行为地、被告住所地、环境资源审判专门管辖待核。材料不足不选定唯一法院。

### 4. 证据目录与保全红旗

关联性证据必须可见。保全只做红旗。

### 5. 起诉状草稿与提交核验

只交付草案，不代提交。

## 停止与安全

- `整体停止`：立场不明；用户坚持虚假陈述。
- `字段停止`：管辖、时效、请求权基础未核验。
- `目标停止`：主目标变为公益或政府索赔诉讼。
