# 边界与路由

## 正触发

保护地、红线、禁猎或栖息地破坏被查或选址触及。

立场：建设单位或被查处人（强制单方）。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 刑事辩护或控告 | 刑事领域 |
| 选址限批总评 | 评估规划环评选址与区域限批 |
| 偷猎毁栖息地 | 整体停止 |
| 林草湿占用许可 | 评估林草湿占用与资源权利 |
| 房地开发 | 房地产物业领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 海关野生动植物进出口 | 海关／濒危公约接口 |
| 动物防疫 | 不在本包 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

在保护地外围作业不等于当然合法。特许猎捕不是普通狩猎。行政没收不是刑事判决。
