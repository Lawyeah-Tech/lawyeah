# 边界与路由

## 正触发

许可证到期、责令改正未改或拟被吊销。

立场：权利人。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 抢采 | 整体停止 |
| 延续申请材料 | 准备探矿权采矿权申请材料 |
| 矿区修复专项 | 评估矿区生态修复义务 |
| 行政诉讼程序 | 行政救济领域 |
| 职工安置 | 劳动领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 闭坑地质报告 | 只标技术接口 |
| 破产清算中的矿权 | 破产接口 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

许可证过期不是自动注销完结。吊销决定送达前不得写成已经没有矿业权，也不得继续开采。
