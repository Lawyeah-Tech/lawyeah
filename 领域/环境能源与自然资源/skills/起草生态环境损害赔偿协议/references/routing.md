# 边界与路由

## 正触发

磋商条件已谈拢，需要可签的生态环境损害赔偿协议。

立场：赔偿义务人或权利人一方（强制单方）。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 尚未谈拢 | 谈判生态环境损害赔偿磋商 |
| 司法确认 | 办理生态损害赔偿协议司法确认 |
| 商业合同改稿 | 审查起草（本窗搁置） |
| 把纪要当判决 | 禁止 |
| 磋商策略 | 谈判生态环境损害赔偿磋商 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 矿业股权并购整案中的生态或有负债条款 | 并购整案转投资并购，本任务只写法定赔偿协议 |
| 公证 | 只标接口 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

生态环境损害赔偿协议不是普通民事和解。未司法确认不得写成可直接强制执行。商业项目合同审查不在本窗实施。
