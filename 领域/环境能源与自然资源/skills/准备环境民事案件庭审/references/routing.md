# 边界与路由

## 正触发

侵权、公益或生态损害赔偿已开庭或即将开庭。

立场：单方代理。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 尚未立案 | 对应 file 原子 |
| 行政庭审程序 | 行政救济领域 |
| 鉴定异议材料 | 提出环境鉴定异议或重新鉴定 |
| 伪证 | 整体停止 |
| 刑事庭审 | 刑事领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 二审或再审程序方法 | 只留环境争点，程序转民事程序接口 |
| 执行听证 | 执行原子 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

庭审提纲不是立案包。行政执法文书不是当然免证事实。鉴定询问不是当庭重做鉴定。
