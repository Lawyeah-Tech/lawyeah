# 边界与路由

## 正触发

节能监察、限额或考核问责。

立场：用能单位。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 项目核准主成果 | 评估能源项目核准备案与节能审查 |
| 篡改能耗 | 整体停止 |
| 合同能源管理价款 | 合同争议领域 |
| 处罚申辩 | 准备环境行政处罚陈述申辩 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 碳排放强度 | 碳配额原子接口 |
| 工业节能监察地方细则 | 须核验地区 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

双控考核约谈不是行政处罚。节能审查批复不是开工许可的全部。重点用能单位名录不是重点排污单位名录。
