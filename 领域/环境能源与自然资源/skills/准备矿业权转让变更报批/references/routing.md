# 边界与路由

## 正触发

已决定报批变更登记。

立场：单方。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 效力评估 | 评估矿业权转让合同与报批 |
| 股权工商变更 | 公司股权／投资并购 |
| 合同改稿 | 审查起草（本窗搁置） |
| 写成已变更 | 禁止 |
| 新设申请 | 准备探矿权采矿权申请材料 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 一般行政许可时限计算 | 行政救济领域 |
| 矿区修复义务承继 | 评估矿区生态修复义务 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

报批受理回执不是变更登记完成。受让人名称出现在合同抬头不是矿业权人已经变更。
