# 评估规划环评选址与区域限批

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的建设单位立场下，形成“规划环评、选址与区域限批矩阵”：规划环评结论、三线一单、保护地和岸线约束、区域限批、选址否决风险和补正路径。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：选址可能落入保护地、生态保护红线、岸线或区域限批，建设单位需要否决风险判断。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 土地出让、建设用地规划许可或商品房开发交易主轴（转房地产）；
- 施工图、造价、工期主轴（转工程）；
- 只要项目环评报告书代做；
- 农村土地承包或征地拆迁材料包；

本任务不给胜诉率，未知金额不写零。

## 建立工作坐标

确认：使用者与授权；单方立场（建设单位）；相对方、主管机关及可能责任主体；关键文本版本；法域；当前检查、处罚、协商、诉讼或执行状态；机关文书作出与送达；对方已知主张；关键材料及缺失。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 许可、标准或合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩或义务假设；`V#` 版本；`E#` 送达／监测／履行凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：search_law 核验环评法规划环评专章、生态保护红线、长江保护法／黄河保护法岸线接口、区域限批条款；不虚构控制单元。 不虚构案件系统。核验重点：环境影响评价法规划环评、环境保护法、生态保护红线、地方三线一单（须核验地区）。

工具不可用时继续事实、主体、程序文书状态和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　分流与选址身份

土地出让和规划许可不是本任务主成果。

### 节点 2　规划环评与项目环评分账

二者不互相替代。

### 节点 3　三线一单、红线与岸线

控制单元、优先／重点／一般管控分列。

### 节点 4　区域限批

限批对象、范围、解除条件分列。

### 节点 5　否决风险与下一步

本任务不代做规划环评。


## 停止与安全

- `整体停止`：立场不明；用户坚持在禁建区开工或伪造坐标；利益冲突未解；基础主体无法建立。
- `字段停止`：三线一单、红线、限批范围未核验；法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标变为土地出让或项目环评代做。
