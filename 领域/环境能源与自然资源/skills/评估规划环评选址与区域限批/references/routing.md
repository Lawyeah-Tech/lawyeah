# 边界与路由

## 正触发

选址可能落入保护地、生态保护红线、岸线或区域限批，建设单位需要否决风险判断。

立场：建设单位。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 项目环评排污许可缺口 | 评估环评与排污许可缺口 |
| 土地出让或规划许可主轴 | 房地产物业领域 |
| 施工图或造价 | 建设工程领域 |
| 保护地野生动植物处罚主成果 | 评估野生动植物与保护地红线 |
| 代做规划环评报告 | 负触发 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 征地拆迁补偿 | C 端拆迁／房地产或行政，只分流 |
| 农村承包流转 | 只分流 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

规划环评通过不等于项目可以未批先建。三线一单符合性查询不能替代项目环评审批。
