# 边界与路由

## 正触发

产生、收集、贮存、转移、利用或处置危险废物被查或拟安排，产废或经营单位需要全链条判断。

立场：产废单位或危废经营单位（强制单方）。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 刑民交叉主成果 | 分流污染环境罪刑民交叉 |
| 处罚申辩 | 准备环境行政处罚陈述申辩 |
| 无证或伪造联单操作 | 整体停止 |
| 船舶污染物 | 海事领域 |
| 清运合同改稿 | 审查起草（本窗搁置） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 一般行政许可程序 | 行政救济领域 |
| 医疗废物医院主轴 | 可留危废链条，医疗损害转医疗 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

危险废物与一般工业固体废物不得凭合同名称认定。转移联单填写错误不等于已经合法处置。经营许可类别必须覆盖该废物代码。
