# 边界与路由

## 正触发

需鉴定机构确认污染、因果或修复费用。

立场：单方。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 已有意见异议 | 提出环境鉴定异议或重新鉴定 |
| 工程造价鉴定 | 建设工程领域 |
| 现场保全 | 保全污染现场与监测证据 |
| 污染检材 | 整体停止 |
| 生态费用假设 | 测算生态环境损害与修复费用 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 医疗鉴定 | 医疗领域 |
| 海事检验 | 海事领域 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

鉴定事项不能写成“请认定被告构成环境污染侵权”。修复费用鉴定不是工程竣工结算审价。
