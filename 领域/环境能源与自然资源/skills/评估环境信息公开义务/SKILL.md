# 评估环境信息公开义务

## 任务目标

在明确、无利益冲突的披露义务人立场下，形成“环境信息公开义务矩阵”：是否属于重点排污单位或依申请公开对象、公开范围、时点、渠道、违法后果和补正路径。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：重点排污单位环境信息或依申请公开被投诉、被约谈或可能被处罚，披露义务人需要范围和时点判断。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是上市公司定期报告或临时公告全文（可标证券接口）；
- 只要总体事项总图；
- 用户要求隐瞒超标或伪造公开数据；
- 纯证券虚假陈述赔偿主轴（转证券／侵权接口）；

本任务不给胜诉率，未知金额不写零。

## 建立工作坐标

确认：使用者与授权；单方立场（披露义务人）；相对方、主管机关及可能责任主体；关键文本版本；法域；当前检查、处罚、协商、诉讼或执行状态；机关文书作出与送达；对方已知主张；关键材料及缺失。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 许可、标准或合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩或义务假设；`V#` 版本；`E#` 送达／监测／履行凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：search_law 核验环境保护法公开条款、企业环境信息依法披露管理办法、清洁生产审核公开接口；上市公司公告只标接口不替代。 不虚构案件系统。核验重点：环境保护法、企业环境信息依法披露管理办法、清洁生产促进法公开接口。

工具不可用时继续事实、主体、程序文书状态和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　分流与义务人身份

先确认是环境法上的披露还是证券法上的公告。

### 节点 2　公开范围

法定事项与自愿事项分列。

### 节点 3　时点与渠道

逾期与渠道错误分列。

### 节点 4　违法后果与信用接口

处罚、信用、民事索赔分列。

### 节点 5　补正与反方

补正不保证免罚。


## 停止与安全

- `整体停止`：立场不明；用户坚持隐瞒超标或伪造披露；利益冲突未解；基础主体无法建立。
- `字段停止`：名录身份、披露办法、答复期限未核验；法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标变为上市公告终稿或处罚申辩。
