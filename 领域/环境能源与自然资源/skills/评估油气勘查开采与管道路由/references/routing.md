# 边界与路由

## 正触发

油气矿业权、管线路由或保护发生争议。

立场：权利人或沿线权利人（强制单方）。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 管道施工结算 | 建设工程领域 |
| 征地拆迁 | 房地产或征收，只分流 |
| 矿业权总评 | 评估矿业权取得变更与争议 |
| 破坏管道 | 整体停止；刑事接口 |
| 并购整案 | 投资并购领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 海事海底管道 | 海事接口 |
| 危险化学品安全生产许可 | 不替代本任务保护范围判断 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

管道保护法上的保护范围不是征收红线。油气矿业权争议不是管道施工质量争议。
