# 边界与路由

## 正触发

并网、市场交易、电费结算或强制收购发生争议。

立场：发电或售电主体。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 无监管争点的购售电合同 | 合同争议领域 |
| 补贴绿证 | 评估可再生能源消纳补贴与绿证 |
| 能源监管谈判 | 谈判能源监管与补贴结算争议 |
| 电网施工 | 建设工程领域 |
| 合同改稿 | 审查起草（本窗搁置） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 反垄断电力市场 | 竞争领域接口 |
| 分布式接入 | 评估分布式光伏储能氢能接入 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

并网意见不是购售电合同。保障性收购不是财政补贴。电力业务许可证不是发电项目核准。
