# 边界与路由

## 正触发

岸上排污、入海排污口或向海倾废被追究，陆源排污者需要责任和分界判断。

立场：陆源排污者。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 船舶油污或海上运输 | 海事领域 |
| 海域使用权或采砂 | 评估海域使用权与采砂 |
| 生态修复精算 | 测算生态环境损害与修复费用 |
| 渔损私益测算 | 测算污染人身财产损失 |
| 继续偷排 | 整体停止 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 海事保全 | 海事领域 |
| 海岸工程规划许可 | 可留陆源责任，规划许可转规划／房地产接口 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

岸上工厂经管道入海是陆源。油轮泄漏是船舶污染。二者证据、主管机关和公约接口都不同。
