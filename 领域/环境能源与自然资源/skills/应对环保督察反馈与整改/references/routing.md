# 边界与路由

## 正触发

中央或省级环保督察点名、交办或书面反馈已到达或有等价材料，被督察对象需要拆解和合法整改边界。

立场：被督察对象。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 发送应急报告 | 准备突发环境事件报告与应急 |
| 处罚申辩 | 准备环境行政处罚陈述申辩 |
| 可核验整改方案正文 | 准备环境合规整改方案 |
| 虚假整改或毁证 | 整体停止 |
| 刑事辩护 | 刑事领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 党政问责程序 | 只标接口，不代做政务处分 |
| 一般行政程序方法 | 行政救济领域 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

督察整改报告不是处罚申辩。销号不等于免罚或免刑。地方政府汇报口径不能替代企业法律义务。
