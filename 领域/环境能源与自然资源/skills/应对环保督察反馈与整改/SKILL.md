# 应对环保督察反馈与整改

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的被督察对象立场下，形成“督察反馈应对包”：反馈事项拆解、整改方案法律边界、报送口径风险、与处罚／刑事接口和下一步。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：中央或省级环保督察点名、交办或书面反馈已到达或有等价材料，被督察对象需要拆解和合法整改边界。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 指导虚假整改、表面整改或毁证；
- 只要突发环境事件发送稿；
- 只要处罚陈述申辩终稿；
- 一般政务督查与环保督察无关的材料；

本任务不给胜诉率，未知金额不写零。

## 建立工作坐标

确认：使用者与授权；单方立场（被督察对象）；相对方、主管机关及可能责任主体；关键文本版本；法域；当前检查、处罚、协商、诉讼或执行状态；机关文书作出与送达；对方已知主张；关键材料及缺失。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 许可、标准或合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩或义务假设；`V#` 版本；`E#` 送达／监测／履行凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：search_law 核验中央环保督察工作规定接口、环境保护法、处罚与移送衔接；不检索毁证方法。 不虚构案件系统。核验重点：中央环保督察工作规定接口、环境保护法、行政处罚与刑事移送衔接。

工具不可用时继续事实、主体、程序文书状态和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 停止与安全

- `整体停止`：立场不明；用户坚持虚假整改或毁证；利益冲突未解；基础主体无法建立。
- `字段停止`：督察依据、整改时限、移送标准未核验；法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标变为假整改、应急报告或刑事辩护。
