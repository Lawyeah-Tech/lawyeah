# 边界与路由

## 正触发

水质、土壤、大气或现场可能灭失，单方需要保全步骤。

立场：单方。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 完整证据卷 | 建立环境污染与生态损害证据案卷 |
| 鉴定申请 | 准备环境损害司法鉴定申请 |
| 行为禁令 | 准备环境行为保全或禁止令 |
| 伪造背景或破坏现场 | 整体停止 |
| 危险区冒险取样 | 拒绝指导 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 海事溢油取样 | 海事领域 |
| 刑事现场 | 转刑事，不破坏公安现场 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

公证拍照不是司法鉴定。法院行为保全不是证据保全。冲洗现场“便于检查”是毁证风险。
