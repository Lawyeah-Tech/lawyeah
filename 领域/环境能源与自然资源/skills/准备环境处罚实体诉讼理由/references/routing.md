# 边界与路由

## 正触发

已决定就环境处罚或许可提起行政诉讼，只要实体理由。

立场：原告（被处罚人或许可申请人等）。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 起诉期限管辖庭审程序 | 行政救济领域 |
| 民事污染起诉 | 提起环境污染侵权诉讼 |
| 实体复议理由 | 准备环境处罚实体复议理由 |
| 矿业股权并购整案 | 投资并购／公司股权领域 |
| 决定前申辩 | 准备环境行政处罚陈述申辩 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 行政许可听证程序方法 | 行政救济领域 |
| 国家赔偿程序 | 行政救济领域 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

环境实体理由不是行政起诉状全文。起诉期限起算必须由行政领域核验，本任务不得填写“最后起诉日”。
