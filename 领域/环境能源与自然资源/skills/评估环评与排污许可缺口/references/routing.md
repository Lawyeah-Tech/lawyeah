# 边界与路由

## 正触发

拟建、在建或已排污，单方需要环评、三同时、排污许可或登记是否闭合的缺口清单。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要事项总图 | `评估环境能源与资源事项` |
| 代做环评或验收报告 | 技术服务，本包不实施 |
| 发送处罚申辩 | `准备环境行政处罚陈述申辩` |
| 监测数据真实性本身 | `评估自行监测与排污数据合规`（未安装则 `unavailable`） |
| 施工价款工期质量 | 建设工程领域 |
| 土地出让或商品房 | 房地产领域 |

## 易混

已开工但未投产：先做未批先建，不写成无证排污。已投产未验收：三同时与排污许可分列。用户说“补个环评就行”时，必须核验现行环评法第 31 条，不得写限期补办。
