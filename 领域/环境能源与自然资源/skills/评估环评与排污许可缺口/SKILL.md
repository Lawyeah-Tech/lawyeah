# 评估环评与排污许可缺口

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的建设单位或排污单位立场下，形成“环评与排污许可缺口矩阵”：项目分类、环评文件与批复、三同时与自主验收、排污许可或登记、未批先建与无证排污分账、变更重新报批、补正路径和最强反方。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价评估和证照材料。

## 工作边界

正触发：中国大陆拟建、在建或已排污项目，单方需要判断环评、三同时、排污许可或登记是否闭合。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要总体事项总图，不要许可缺口清单；
- 只要代做环境影响报告书或验收报告；
- 只要发送版陈述申辩或应急报告；
- 施工价款、工期、质量鉴定主轴；
- 建设用地出让或商品房开发交易主轴。

本任务不把 2002 年环评法“限期补办手续”写成现行默认，不保证补证后免罚。

## 建立评估坐标

确认：使用者与授权；单方立场；项目名称与建设地点；行业类别；开工与投产时点；现有环评、验收、许可证或登记；法域；检查或处罚状态；关键材料及缺失。

同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关文书；`C#` 许可证或环评批复定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 义务／违法假设；`V#` 评估版本；`E#` 证照或监测凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验环评法（2018 修正）、环保法、排污许可管理条例及 2024 年管理办法、分类管理名录；`search_practiced` 补未批先建与三同时分算反例。不虚构名录条目。

工具不可用时继续证照对照和事实缺口；违法定性、罚款幅度、时效字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 专项分流和项目身份

先分流工程价款和房地交易。固定项目、地点、行业、实际建设内容与环评申报内容是否一致。

### 2. 环评分类与未批先建

报告书、报告表、登记表分列。未依法审批不得开工（环评法第 25 条）。重大变动是否须重新报批单列。禁止用 2002 年限期补办作为现行路径。

### 3. 三同时与自主验收

环保设施须与主体工程同时设计、施工、投产。未验收或验收不合格投入生产与未批先建分账，不得混成一条时效。

### 4. 排污许可或登记

重点管理、简化管理、登记管理分列。未取得排污许可证不得排污。不按证排污、无组织排放、特殊时段限制单列。2019 年试行办法失效，不得引用。

### 5. 补正路径、处罚接口和反方

补正申请、停止建设或停止排污、申辩转介分别写。最强反方包括：实际未开工、属于登记管理、建设内容未变、已持证。用户要申辩终稿则目标停止。

## 停止与安全

- `整体停止`：立场不明；用户坚持伪造环评或倒签开工日。
- `字段停止`：分类名录、现行罚则、时效未核验。
- `目标停止`：主目标变为代做环评、申辩终稿或施工结算。
