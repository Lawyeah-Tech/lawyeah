# 边界与路由

## 正触发

单独委托核验处罚是否超过追责时效或是否属于继续状态。

立场：当事人。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 申辩全文 | 准备环境行政处罚陈述申辩 |
| 复议起诉期限怎么算 | 行政救济领域 |
| 1996 调查条款当时效 | 噪声，拒绝采用 |
| 按日计罚起点 | 应对按日连续处罚 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 民事诉讼时效 | 私益路径原子，与处罚时效分列 |
| 刑事追诉时效 | 刑事领域 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

处罚追责时效不是复议期限，也不是民事时效。未批先建完工后，三同时未验收可能仍在继续，必须分算。
