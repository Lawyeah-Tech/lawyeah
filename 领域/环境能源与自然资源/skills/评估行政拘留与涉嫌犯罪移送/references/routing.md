# 边界与路由

## 正触发

暗管、伪造数据、无证排污拒不停止等可能行政拘留或移送公安机关，当事人或负责人需要红旗判断。

立场：当事人或负责人（强制单方）。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 辩护或控告 | 刑事领域 |
| 刑民交叉并行策略 | 分流污染环境罪刑民交叉 |
| 普通申辩 | 准备环境行政处罚陈述申辩 |
| 继续暗管毁证 | 整体停止 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 治安拘留一般程序 | 公安／行政接口 |
| 监察调查 | 只标接口 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

行政拘留不是刑事拘留。移送公安机关不是已经定罪。单位违法拘留责任人须核验具体情形，不得随意指定法定代表人。
