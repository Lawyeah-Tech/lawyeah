# 边界与路由

## 正触发

在产、转让后或历史遗留矿区修复责任需要判断。

立场：采矿权人或政府接口（强制单方）。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 修复施工结算 | 建设工程领域 |
| 生态费用精算 | 测算生态环境损害与修复费用 |
| 土壤地块责任 | 评估土壤污染责任与风险管控 |
| 假覆绿 | 整体停止 |
| 矿业权状态 | 评估矿业权取得变更与争议 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 土地复垦验收登记 | 自然资源／房地产接口 |
| 破产后的修复债权 | 破产接口 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

缴纳矿山环境治理恢复基金不是已经修复。采矿权转让合同把义务推给对方，不当然消灭法定义务。
