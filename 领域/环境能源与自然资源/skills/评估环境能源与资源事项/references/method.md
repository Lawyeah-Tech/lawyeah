# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变路径、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然免罚、必然受理或唯一必得总额。

`search_law` 返回已失效《合同法》、民法通则、2002 年环评法“限期补办”、2010 年环境行政处罚办法或 2019 年排污许可管理办法（试行）时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜关系假设｜提出方｜相对方｜法律效果｜成立条件｜支持事实｜不利事实｜控制方｜最强反方｜主备位｜判断｜待核`。

监管罚则、责令改正、私益赔偿、生态修复、公益诉讼、资源权利确认分列。同一事实支持多项时分别说明效果，不重复金额。无过错不等于当然赔偿。构成行政违法不等于当然民事赔偿或刑事移送。

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填总体评估十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定、实际施工人 | 建设工程领域 |
| 商品房买卖、开发合作、物业服务、建设用地使用权交易主轴 | 房地产物业领域 |
| 只要复议申请书格式、起诉期限怎么算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上货物、海事保全 | 海事领域 |
| 农村土地承包经营权流转 | C 端承包／相关领域 |
| 征地拆迁补偿材料包 | C 端拆迁／房地产或行政 |
| 劳动关系、工伤待遇 | 劳动领域 |
| 尚未形成监管或争议，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

混合信号：排污或项目监管主轴可留本任务；专项只作为背景时在缺口标明，不把施工造价或售房规则硬套进环境结论。

## 节点 1　主体、文本版本和程序状态

1. 固定环境影响评价文件、排污许可证或登记、监测报告、矿业权或取水许可证、督察反馈、处罚文书的版本层级。冲突并列，不选对用户有利的一版冒充唯一文本。
2. 主体表记录项目业主、排污单位、实际控制人、运营方、环评或监测机构、受害人和主管机关。名称不一致不自动合并。
3. 程序表逐动作记录检查、采样、事先告知、听证、处罚、磋商、诉讼或执行：机关、文号、作出日、收到日、送达方式和效力凭证。口头转述、截图、“已读”不得写成已立案、已送达或期限已起算。
4. 同时掌握双方秘密或立场不明：整体停止策略输出。

## 节点 2　事项定性与请求抗辩假设

每个 `Q#` 先写法律效果，再写成立条件。禁止合成“环境权益”一笔。

默认主位候选按事实分别建立，不得预先锁定处罚或起诉：

- `Q-许` 环评、三同时、排污许可或登记是否闭合（接口，不替代许可专项终局）
- `Q-监` 检查、责令改正、限制生产、停产、查封
- `Q-罚` 罚款、按日计罚、拘留、吊销
- `Q-报` 突发环境事件是否须报告（本身不是申辩）
- `Q-私` 私益人身财产损害赔偿（民法典第 1229–1233 条）
- `Q-生` 生态环境修复或损害赔偿（第 1234–1235 条；政府磋商或诉讼）
- `Q-公` 环境民事公益诉讼
- `Q-惩` 惩罚性赔偿（须故意、违法、严重后果，法释〔2022〕1 号）
- `Q-权` 矿业权、取水权等资源权利确认或争议
- `Q-刑` 污染环境罪或伪造监测数据移送红旗（不定罪）

单位或被指侵权／被处罚立场：逐项回应对方已知主张，并列己方最强抗辩，不把复议或反诉写成已经提起。

主备位和互斥必须可见。`Q-私` 与 `Q-生` 不得写成同一权利人可重复主张同一生态损害（法释〔2023〕5 号第 22 条）。私益被侵权人同时请求第 1235 条生态环境损害赔偿的，该项标不支持或待核，不得与人身财产损失加总。

专项评估（许可缺口、时效精算、矿业权）可在矩阵中留接口，不在本任务做专项终局。

## 节点 3　报告、申辩还是诉讼／磋商

本节点只判断路径，不生成发送版报告、申辩或诉状。

### 3.1 先分账

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 出现异常排放或投诉 | 已构成突发环境事件且可合法不报 |
| 超标一次 | 已构成按日计罚 |
| 未批先建 | 当然无证排污、当然三同时未验收 |
| 监测超标 | 因果关系已成立、私益必赔 |
| 对方未异议 | 无处罚权或无请求权也已确定 |

### 3.2 民事构成（须核验现行文本）

核验失败则本节点字段停止，事实与问题清单继续。

1. **无过错**：污染环境、破坏生态造成他人损害，行为人不论有无过错都应当承担侵权责任（第 1229 条；解释第 4 条）。
2. **关联性与因果**：原告提供行为与损害的关联性证据；法院综合行为方式、污染物、介质、时间顺序、空间距离判断（证据规定第 5 条）。行为人就法律规定的免责减责及行为与损害不存在因果关系举证（第 1230 条）。不得把“举证责任倒置”写成原告无需证明关联性。
3. **第三人**：第三人过错不免除污染者责任；污染者赔偿后可追偿（第 1233 条）。帮助提供场地或运输可连带（解释第 10 条）。
4. **中介连带**：环评、监测或防治设施运维机构故意失实、隐瞒超标或故意不运行设施，可与污染者连带（环保法第 65 条；解释第 21 条）。
5. **惩罚性**：违反法律规定 + 故意 + 严重后果（第 1232 条；惩罚性解释第 4、7、8 条）。不得编造倍数。

### 3.3 监管与期限

- 未批先建、无证排污、不按证排污、三同时未验收、逃避监管排放分列。
- 处罚追责时效核验现行《行政处罚法》；禁止引用 1996 年调查条款当时效；禁止默认“生态环境一律五年”；继续状态从行为终了日起算，未批先建与三同时未验收不得混算一条。
- 民事时效：知道或应当知道权利受损及责任人之日起算；侵权行为仍持续的，自行为结束之日起算（解释第 27 条）。与处罚时效分列。
- 没有送达事实和规则引文，禁止写“已过时效”或“处罚已生效”。

### 3.4 输出

| 条件 | 本任务输出 | 转介 |
| --- | --- | --- |
| 可能构成或已构成突发环境事件 | 是否须报、时限待核、瞒报风险 | `prepare-incident-report` |
| 已有事先告知或听证告知 | 申辩窗口、争点 | `prepare-penalty-defense` |
| 许可缺口本身成为主目标 | 最小交接 | `assess-eia-and-permit` |
| 用户坚持今天发出报告或申辩终稿 | 目标停止 | 对应文书原子，不在本包出稿 |

## 节点 4　论坛与程序入口

分别判断：整改、申辩、复议实体接口、磋商、私益诉讼、公益诉讼、生态损害赔偿诉讼、刑事移送。本任务不写立案包或复议申请书。

出现检察机关或社会组织公益诉讼信号时，不得直接写成普通侵权起诉。出现省级或设区的市级政府指定部门磋商时，不得跳过磋商写成私益给付。

仲裁条款若出现在资源权利或治理合同中：不得直接写应起诉；或裁或诉和机构不明标待核。

## 节点 5　金额、证据、反方和下一步

1. 罚款、按日计罚、私益损失、修复费用、事务性费用、惩罚性各自成行。未知不写零。真实零必须有肯定来源。
2. 证据矩阵：待证事实、支持、不利、控制方、合法取得、行政执法数据转化资格、缺口、最晚时点。禁止建议调换样品、关停监控或伪造联单。
3. 最强反方至少覆盖：不是责任主体、行为与损害无关联、不可抗力或受害人故意、监测不合法、继续状态不成立、请求权主体不适格。
4. 下一步按：人身与环境安全、报告或听证期限、易失证据、可逆性排序。发送报告、申辩、立案只转介。
