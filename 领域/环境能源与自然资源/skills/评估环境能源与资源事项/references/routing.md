# 边界与路由

## 正触发

已出现环境监管、污染损害、能源项目监管或自然资源权利问题，单方需要总体决定路径、证据优先级和下一步。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成监管事项，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |
| 只判断环评或排污许可是否闭合 | `评估环评与排污许可缺口` |
| 发突发环境事件报告 | `准备突发环境事件报告与应急` |
| 写处罚陈述申辩 | `准备环境行政处罚陈述申辩` |
| 精算修复费用 | `测算生态环境损害与修复费用` |
| 完整证据卷 | `建立环境污染与生态损害证据案卷` |
| 生态损害赔偿磋商条件 | `谈判生态环境损害赔偿磋商` |
| 私益侵权起诉 | `提起环境污染侵权诉讼` |
| 私益侵权应诉 | `应对环境污染侵权诉讼` |
| 只判断矿业权状态 | `评估矿业权取得变更与争议` |
| 工程施工／房地交易／一般行政程序／海事船舶 | 对应领域 |
| C 端拆迁／承包／处罚救济／011／012 | 大众专项，只分流不回改 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审方法 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | C 端承包／相关领域 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政 |
| 定罪、控告、辩护 | 刑事领域 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

事项尚未闭合、需比较监管应对还是民事索赔时正触发。主体、请求、论坛均确认且只要诉状或申辩终稿时负触发。已出现暗管、伪造数据或拒不停止排污时，先标刑事红旗，不在本任务做辩护。
