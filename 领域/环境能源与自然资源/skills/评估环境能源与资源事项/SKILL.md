# 评估环境能源与资源事项

## 任务目标

在明确、无利益冲突的单方立场下，形成“环境能源与资源事项总体评估矩阵”：事项定性、主体和程序状态、事实时间线、逐项监管／民事／公益／资源请求或抗辩、期限待核、金额区间与非金钱后果、证据缺口、对方最强解释和下一步。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：中国大陆已出现环境保护监管、污染或生态损害、能源项目监管或自然资源权利法律问题，用户仍需决定路径或下一步。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未形成监管事项或争议，只要改项目合同或出稿（审查起草领域，本生产线搁置，只说明不实施）；
- 只要发送版突发环境事件报告或处罚陈述申辩；
- 只要精算工作表或完整证据卷；
- 已决定起诉／答辩／磋商协议／许可申请并只要相应文书；
- 工程施工价款工期质量鉴定、房地产交易开发运营、一般行政复议诉讼程序方法、船舶海上污染、农村土地承包或征地拆迁主轴。

本任务不生成发送版报告、申辩、可提交诉状或答辩，不给胜诉率。

## 建立评估坐标

确认：使用者与授权；单方立场；相对方、主管机关及可能责任主体；项目或权利文本版本；事项类型；法域；当前检查、处罚、协商、诉讼或执行状态；机关文书作出与送达；对方已知主张；关键材料及缺失。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 许可或合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`V#` 评估版本；`E#` 送达／监测／履行凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验环保、环评、排污许可、侵权、矿法、能源和期限；`search_practiced` 补路径与反例；特殊事实用 `search_case_by_fact`。不虚构案件系统。

工具不可用时继续事实、主体、程序文书状态和问题清单；请求／抗辩的法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 专项分流、主体和程序状态

先做工程、房地、一般行政程序、海事、承包拆迁分流，再固定项目、许可、监测和权利文本版本，并列主体和程序表。口头转述不得写成已立案、已送达或期限已起算。

### 2. 事项定性与请求抗辩假设

监管、私益侵权、公益诉讼、生态环境损害赔偿、资源权利争议分列，禁止合成“环境权益”。无过错不等于必然赔偿。未批先建、无证排污、三同时未验收不得混成一条违法。

### 3. 论坛、报告／申辩和期限

处罚事先告知、听证、复议、诉讼、磋商、刑事移送分列。期限分列报告时限、听证期、处罚追责时效、民事时效、复议起诉期限，不混算。

### 4. 金额区间与非金钱后果

分项列罚款区间、按日计罚、私益损失、修复费用、惩罚性接口。未知不写零。停产、限产、吊销、修复、恢复原状等非金钱结果单列。

### 5. 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。下一步按期限灭失、易失证据、能否改变 `Q#`、可逆性排序。发送报告、申辩、立案标为转介。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或项目无法建立；用户坚持伪造监测、隐匿危废、威胁或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为发报告、申辩、精算、建卷、磋商协议或程序文书。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
