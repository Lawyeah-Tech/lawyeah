# 原子 Skill 选择方法

## 一、先识别成果

先问这一次要拿到什么可独立验收的成果，而不是按水气声渣、许可证名称或法条名称匹配。

P0 成果簇：事项总图；环评与排污许可缺口；突发环境事件报告；处罚陈述申辩；生态损害与修复测算；证据案卷；生态环境损害赔偿磋商方案；环境污染侵权起诉包；环境污染侵权应诉包；矿业权状态与争议判断。

P1 成果簇：自行监测与数据；环境信息公开；重点排污单位与信用；规划选址与限批；环评文件失实；督察整改；土壤；危废；噪声恶臭光；辐射安全；陆源污染海洋；第三方治理；合规整改方案；预案演练；现场检查应对；追责时效；责令停产；按日计罚；实体复议理由；实体诉讼理由；拘留与移送；私益侵权路径；私益损失测算；现场保全；鉴定申请；鉴定异议；公益起诉；公益应诉；生态协议草稿；司法确认；生态损害赔偿起诉；生态损害赔偿应诉；惩罚性与中介连带；行为保全；私益和解；民事庭审；矿权申请；矿权转让评估；矿权转让报批；矿权延续吊销；取水权；取水许可申请；林草湿；保护地野生动植物；海域与采砂；矿区修复；资源权利起诉；资源权利应诉；能源项目核准；电力市场并网；补贴绿证；碳配额；碳核查异议；节能双控；油气管道；分布式能源；能源监管谈判；刑民交叉分流；生态文书执行；应对执行。

P2 成果簇（本包 `unavailable`）：新污染物终局；生态补偿转移支付终局；核能与核设施许可终局。

## 二、再确认上下文

只确认会改变入口的最小信息：

1. 单方立场与授权；
2. 当前是监管检查、突发事件、民事索赔、政府磋商、资源权利还是能源监管；
3. 是否已有事先告知书、起诉状、监测报告或许可证；
4. 本次要分析、发报告、申辩、测算、建卷、谈判还是程序文书；
5. 是否属于工程施工、房地交易、一般行政程序、矿业股权并购、海事船舶或农村承包征地专项。

## 三、处理混合请求

1. 列出每项可独立验收的成果及对应入口；
2. 只问：`这次要先取得哪一项成果？`；
3. 回答前不指定主要 Skill，不暗示必须先评估再发报告；
4. 用户确认后只启动所选入口；等价评估、测算或证据可由用户或律师提供。

## 四、停止

立场冲突、专项主轴或未成监管事项改合同时，说明边界并转出，不代做。信息不足时每轮只追问一个最能改变入口的问题。一般行政诉讼程序与矿业股权并购整案只分流。
