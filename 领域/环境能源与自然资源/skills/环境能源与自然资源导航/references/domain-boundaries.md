# 环境能源领域边界

本表只说明归属。每次路由先核对 [当前能力地图](capability-map.md)；未安装入口输出 `unavailable`。当前安装包是（P0+P1）。

| 相邻 | 本包入口 | 转出 |
| --- | --- | --- |
| 合同审查与起草 | 无。未成监管事项只要改项目合同或出稿：本窗搁置，只说明不实施。已谈拢的生态环境损害赔偿协议按 P1 起草原子处理，不是商业合同审查 | 审查起草领域（用户单独策略） |
| 建设工程 | 环评排污许可、应急、污染责任、矿区修复义务可留 | 施工、分包、优先受偿、工程造价鉴定、实际施工人 |
| 房地产物业 | 矿业权、林草湿、土壤修复责任可留 | 商品房、开发合作、物业、建设用地买卖主轴 |
| 行政复议与行政诉讼 | 环境处罚实体申辩、实体理由可留 | 复议申请书格式、起诉期限计算、行政庭审程序方法 |
| 投资并购／公司股权 | 矿业权转让报批、证照状态可留 | 矿业公司股权并购、对赌交割整案 |
| 海事 | 陆源污染海洋、海域使用权可留 | 船舶油污、海上运输、海事保全 |
| 刑事 | 评估中的刑民交叉、拘留移送只标红旗 | 定罪、控告、辩护 |
| 劳动 | 无 | 工伤待遇、劳动关系、矿山关闭安置 |
| C 端拆迁 / 承包 | 无 | 征地拆迁材料、农村土地承包流转 |
| C 端处罚救济 | 专业环境实体申辩 | 大众一般处罚救济包 |
| C 端 011 / 012 | 专业起诉或应诉包 | 大众网上立案或民事答辩 |

工程、房地、并购或行政程序夹带环境监管背景时，专项段只分流，不把施工造价、售房、股权交割或一般行政程序规则写入本包结论。
