# 当前能力地图

当前安装包是，包含全部 P0 与全部 P1 原子 Skill。只推荐实际安装在本包中的 Skill。未列入的 P2 及其他未安装能力必须输出 `unavailable`，不得由名称相近的 Skill 代做。

## P0

| 用户当前目标 | 原子 Skill | 独立成果 | 不包含 |
| --- | --- | --- | --- |
| 已出现监管、污染、资源权利或能源法律问题，要总图再决定报告、申辩、磋商或立案 | `评估环境能源与资源事项` | 事项定性、请求抗辩、期限、金额区间、缺口和下一步 | 发送版报告或申辩、诉状、精算终稿 |
| 判断环评、三同时、排污许可或登记是否闭合 | `评估环评与排污许可缺口` | 分类管理、未批先建与无证排污分账、补正路径 | 代做环评报告、限期补办默认 |
| 已发生或可能发生突发环境事件，要依法报告 | `准备突发环境事件报告与应急` | 发送前报告稿、时限、通报对象、禁止项 | 倒签瞒报、破坏现场 |
| 已收到处罚事先告知或听证告知，要决定前申辩 | `准备环境行政处罚陈述申辩` | 陈述申辩或听证意见、事实争点、裁量时效 | 一般复议申请书主成果、保证免罚 |
| 要可复核的修复费用或生态损害数字 | `测算生态环境损害与修复费用` | 分项测算、鉴定接口、互斥、情景区间 | 认定责任已成立、唯一必得总额 |
| 单独盘点举证责任和补证 | `建立环境污染与生态损害证据案卷` | 要件、举证、监测鉴定和行政执法证据矩阵 | 策略总图、诉状、违法取样 |
| 政府或指定部门已启动或拟启动生态损害赔偿磋商 | `谈判生态环境损害赔偿磋商` | 争点、修复边界、让步、协议效力提示 | 已签字协议、把纪要写成判决 |
| 决定提起环境污染私益侵权诉讼 | `提起环境污染侵权诉讼` | 起诉状、请求、管辖、证据目录 | 代提交；公益或政府索赔诉讼 |
| 已收到环境污染侵权起诉状，要首次应诉 | `应对环境污染侵权诉讼` | 期限卡、答辩草稿、因果抗辩 | 主动起诉、劳动应诉 |
| 探矿权采矿权出让、权属、转让或吊销争议总评 | `评估矿业权取得变更与争议` | 权利状态、报批、重叠、争议路径 | 土地使用权买卖、矿山施工合同 |
