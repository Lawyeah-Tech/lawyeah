# 边界与路由

## 正触发

污染已致人身或财产损害，需判断请求或抗辩能否立住。

立场：受害人或被指侵权人（强制单方）。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 起诉状 | 提起环境污染侵权诉讼 |
| 答辩 | 应对环境污染侵权诉讼 |
| 私益损失数字 | 测算污染人身财产损失 |
| 惩罚性精算 | 评估惩罚性赔偿与中介连带 |
| 工伤 | 劳动领域 |
| 公益诉讼 | 提起环境民事公益诉讼 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 医疗损害 | 医疗领域 |
| 一般相邻关系无排污 | 房地产或侵权接口 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

无过错不是必然赔偿。举证责任倒置不是免除原告关联性举证。私益受害人不是生态环境损害赔偿权利人。
