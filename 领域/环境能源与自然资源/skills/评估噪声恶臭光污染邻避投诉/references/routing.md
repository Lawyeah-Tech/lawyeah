# 边界与路由

## 正触发

厂界、施工或邻避投诉需要定性，排污单位或居民需要标准、监测和责任分流。

立场：排污单位或居民（强制单方）。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 施工合同主轴 | 建设工程领域 |
| 物业或装修相邻主轴 | 房地产物业领域 |
| 选址红线主成果 | 评估规划环评选址与区域限批 |
| 私益起诉 | 提起环境污染侵权诉讼 |
| 伪造本底 | 整体停止 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 一般治安噪声 | 可标公安接口，不改环境实体 |
| 劳动场所职业噪声 | 劳动或职业卫生接口 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

厂界达标不等于敏感点室内一定合法。居民投诉不是公益诉讼。施工噪声合同索赔与环境侵权请求不得写在同一 Q#。
