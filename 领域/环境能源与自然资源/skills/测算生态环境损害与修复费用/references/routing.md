# 边界与路由

## 正触发

需要生态环境修复费用、期间损失、永久损害或事务性费用的可复核数字。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要总图 | `评估环境能源与资源事项` |
| 只要渔损作物或健康损失 | `测算污染人身财产损失`（未安装则 `unavailable`） |
| 磋商方案 | `谈判生态环境损害赔偿磋商` |
| 工程造价鉴定 | 建设工程领域 |
| 认定责任并起诉 | `提起环境污染侵权诉讼` 或生态损害赔偿诉讼（未安装则 `unavailable`） |

## 易混

评估报告给出一个“总损失”时，必须拆回第 1235 条项目。不能修复时用永久损害，不得同时按完全修复计费。
