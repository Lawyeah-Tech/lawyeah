# 测算生态环境损害与修复费用

## 任务目标

在明确、无利益冲突的单方立场下，形成“生态环境损害与修复费用可复核测算包”：事件编号、分项工作表、修复／期间损失／永久损害／事务性费用、私益损失互斥、鉴定接口、情景区间和缺口。

`depends-on` 为空。接受用户、律师、鉴定或其他来源的等价参数。本任务**不认定生态环境损害赔偿责任已经成立**。

## 工作边界

正触发：中国大陆污染环境或破坏生态事项需要修复费用、生态环境损害或相关事务性费用的分项数字工作表。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要策略总图；
- 只要私人人身健康或财产损失精算终稿（转私益测算，未安装则 `unavailable`）；
- 只要诉状、磋商协议或申辩；
- 工程造价鉴定主轴。

本任务不输出唯一必得总额，不把私益损失与生态损害加总冒充一笔。

## 建立测算坐标

确认：使用者与授权；单方立场；损害事实期间；拟测算项目与排除项；是否已有鉴定或评估报告；法域；磋商或诉讼状态。用户希望唯一金额，不构成把未知写成零的授权。

## 来源和判断状态

编号：`S#` 陈述；`D#` 材料；`A#` 承认；`R#` 机关或鉴定；`C#` 标准或方案定位；`L#` 已核验规则；`I#` 判断；`G#` 缺口；`Q#` 责任假设；`EVT#` 同一生态事件；`M#` 测算行；`V#` 工作表版本；`E#` 支付或修复凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

金额状态只用 `已核实金额`、`情景金额`、`无法估计`。未知不写零。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典第 1234、1235 条、生态环境损害赔偿规定、侵权解释第 22 条；`search_practiced` 补磋商鉴定转化。不虚构鉴定单价。

工具不可用时继续分项建账；法定项目范围和鉴定方法字段停止。

## 五个判断节点

执行顺序和停止条件以 [测算方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场和测算范围

工程造价主轴转出。私益人身财产另表，不得并入本表总额。本任务展开数字，不把责任写成已经成立。

### 2. 事件编号与分项建账

按民法典第 1235 条项目分列。同一修复工程不得重复计入替代修复与自行修复。

### 3. 修复路径与鉴定接口

能修复与不能修复、自行修复与替代修复、期间损失与永久损害分列。无鉴定参数标无法估计，保留公式。

### 4. 互斥、减损和已支付

私益被侵权人不得同时主张第 1235 条生态损害。政府索赔与私益清理费用可能重叠时标互斥待核。已支付修复费用扣减须有凭证。

### 5. 情景区间和缺口

情景只改变列明未知变量。禁止唯一必得总额。

## 停止与安全

- `整体停止`：立场不明；用户坚持把未知当零或伪造鉴定。
- `字段停止`：法定项目、鉴定方法未核验。
- `目标停止`：主目标变为总图、诉状或磋商协议正文。
