# 边界与路由

## 正触发

控排企业配额缺口、清缴或交易发生争议。

立场：控排单位。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 核查异议 | 准备碳排放报告核查异议 |
| 绿证补贴 | 评估可再生能源消纳补贴与绿证 |
| 预测碳价 | 拒绝 |
| 伪造排放 | 整体停止 |
| 交易合同改稿 | 审查起草（本窗搁置） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 地方试点与全国市场衔接 | 须核验 |
| 碳汇项目方法学 | 不在本任务展开 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

配额账户余额不是已经清缴。绿证不能默认抵销碳配额。买卖合同签字不是登记交割。
