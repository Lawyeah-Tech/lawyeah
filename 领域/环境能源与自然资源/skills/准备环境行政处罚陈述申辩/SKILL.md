# 准备环境行政处罚陈述申辩

## 任务目标

在明确、无利益冲突的当事人立场下，于处罚事先告知或听证告知已经到达或有等价材料时，形成“发送前环境行政处罚陈述申辩包”：告知送达与期限闸、违法事实争点、法律适用与裁量、追责时效、听证意见和附件清单。

`depends-on` 为空。接受用户、律师或机关提供的等价告知书、监测和许可材料。

本任务只形成待发送材料，不执行发送，不保证免罚或减轻。

## 工作边界

正触发：生态环境主管部门已作出处罚事先告知或听证告知，或等价材料证明决定前申辩窗口仍在，用户需要陈述申辩或听证意见。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要总体评估或许可缺口，不要申辩稿；
- 处罚决定已送达，主成果是复议申请书格式或起诉期限计算（行政领域）；
- 只要应急报告；
- 用户要求伪造监测、隐匿危废或虚假整改材料；
- 工程施工或房地交易主轴。

C 端行政处罚救济准备只分流：大众只要一般处罚包时提及该商品；本技能仍做环境实体争点，不回改。

## 建立申辩坐标

确认：使用者与授权；当事人；告知书文号、作出日、收到日；拟认定的违法行为；拟处罚种类和幅度；听证权利是否告知；法域；许可证和监测材料；关键缺失。

口头说“要罚我们”不得写成事先告知已送达。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 承认；`R#` 告知或检查文书；`C#` 许可证或环评定位；`L#` 已核验规则；`I#` 判断；`G#` 缺口；`Q#` 申辩点；`V#` 稿件版本；`E#` 送达凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验环保法、环评法、排污许可条例、生态环境行政处罚办法（2023）、现行行政处罚法时效与听证；`search_template` 只借申辩栏目。2010 年环境行政处罚办法失效。

工具不可用时继续事实争点和附件清单；法律适用、裁量基准、时效结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [申辩方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、告知送达和窗口

先分流工程、房地和一般复议程序。无告知书且无法证明决定前窗口：负触发或字段停止。已作出处罚决定且只要复议程序：转行政。

### 2. 违法事实与监测证据

逐项拆解告知书事实。未批先建、无证排污、三同时、超标、逃避监管分列。监测方法、采样、鉴定资质可质疑，不得建议改数。

### 3. 法律适用与裁量

核验现行罚则和生态环境行政处罚办法第 41 条裁量情节。不得用失效“限期补办”作为唯一请求。同类情节相当则幅度应相当。

### 4. 追责时效与继续状态

核验现行行政处罚法。禁止把 1996 年第 36 条调查条款当时效。禁止默认生态环境一律五年。未批先建与三同时分算。

### 5. 申辩正文、听证和不可逆

正文只写已支持争点。听证权利已告知且符合听证条件则准备听证意见。成果保持待发送。不保证机关采纳。

## 停止与安全

- `整体停止`：立场不明；用户坚持伪造证据。
- `字段停止`：送达日、罚则、时效未核验。
- `目标停止`：主目标变为复议程序文书或应急报告。
