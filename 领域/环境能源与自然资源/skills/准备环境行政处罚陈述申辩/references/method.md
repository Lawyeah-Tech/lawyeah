# 申辩方法

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不保证免罚。

## 节点 0　分流

工程施工或房地交易主轴转出。用户只要复议怎么立案、期限怎么算：转行政领域。用户要求提供假验收、假监测：整体停止。

## 节点 1　告知窗口

1. 固定事先告知书或听证告知书文号、作出日、送达方式、当事人签收或拒收记录。
2. 无送达证据不得起算申辩或听证期限。口头约谈不是告知。
3. 核验陈述申辩期和听证申请期。未核验则期限字段停止，仍列出已知收到日。
4. 处罚决定书已送达：本任务不再产出发送前申辩终稿；说明窗口关闭，转介实体复议理由（未安装则 `unavailable`）和行政程序。

## 节点 2　事实争点

按告知书逐项建立 `Q#`：

- 主体是否适格（分公司、承包方、实际排污人）；
- 行为是否发生、持续区间；
- 未批先建 / 无证排污 / 三同时 / 超标或超量 / 逃避监管，禁止合并；
- 监测点位、方法、气象或水文条件、是否超标；
- 改正是否已经完成（承诺改正不等于已经改正）。

承认不利事实。不得为争点而否认已签字的现场笔录，除非指出具体违法取证情形。

## 节点 3　法律适用与裁量

1. 核验告知书引用条文是否现行有效。引用 2010 年环境行政处罚办法或 2002 年环评法限期补办：指出噪声并请求适用现行法。
2. 生态环境行政处罚办法（2023）第 41 条：危害后果、主观过错、手段、持续时间、危害对象、初犯再犯、改正态度与效果。逐项对照，不编造从轻档。
3. 同类违法行为情节相当的，种类和幅度应当相当。无比较样本则该项待核。
4. 按日计罚须另行核验责令改正和拒不改正的告知程序，不在普通罚款申辩里直接改写计罚公式。

## 节点 4　时效

1. 核验现行《行政处罚法》追责时效条文。1996 年文本第 36 条为调查取证条款，不得当作二年／五年时效依据。
2. 不得默认“涉及生态环境一律五年”。五年延长以现行条文列举的情形且有危害后果为准；条文未核验则五年主张字段停止。
3. 期限从违法行为发生之日起算；有连续或继续状态从终了之日起算。未批先建（建设行为是否终了）与三同时未验收（投入生产期间是否继续）分列。
4. 关键日期冲突建并行情景，不给唯一“已过时效”截止日。

## 节点 5　正文与听证

正文结构：当事人与告知书；事实异议；证据异议；法律适用；裁量；时效；请求（不予处罚／减轻／改正后从轻等，须有依据）。逐句回链。

符合听证条件且当事人要求听证：另附听证请求和质证提纲。本任务不保证举行听证。

成果状态 `待发送`。不执行提交，不伪造签收。
