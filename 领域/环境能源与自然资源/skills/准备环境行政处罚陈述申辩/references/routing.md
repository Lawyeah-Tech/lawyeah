# 边界与路由

## 正触发

已有处罚事先告知或听证告知，需要决定前陈述申辩或听证意见。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要许可缺口 | `评估环评与排污许可缺口` |
| 只要事项总图 | `评估环境能源与资源事项` |
| 决定已送达，只要复议格式和期限计算 | 行政救济领域 |
| 决定已送达，只要环境实体复议理由 | `准备环境处罚实体复议理由`（未安装则 `unavailable`） |
| 突发环境事件报告 | `准备突发环境事件报告与应急` |
| 按日计罚专项 | `应对按日连续处罚`（未安装则 `unavailable`） |
| C 端一般处罚救济 | 只分流不回改 |

## 易混

告知书与决定书名称混淆时，先核文本。决定书已送达仍要“申辩”：决定前窗口关闭，转实体复议理由或行政程序，不把申辩稿冒充复议申请。
