# 边界与路由

## 正触发

已收到矿业权、取水权等权利诉讼起诉状。

立场：被告。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 侵权应诉 | 应对环境污染侵权诉讼 |
| 行政应诉程序 | 行政救济领域 |
| 权利起诉 | 提起自然资源权利诉讼 |
| 并购应诉整案 | 投资并购领域 |
| 转移矿产品 | 整体停止 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 反诉报批 | 可列接口 |
| 财产保全矿权 | 财产保全接口 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

资源权利应诉不是排污侵权应诉。持有土地使用权不是当然抗辩采矿权归属。
