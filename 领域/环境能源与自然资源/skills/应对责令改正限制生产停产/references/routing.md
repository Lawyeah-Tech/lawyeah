# 边界与路由

## 正触发

已被责令改正、限制生产、停产整治或关闭，当事人需要定性与履行边界。

立场：当事人。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 复议格式或起诉期限 | 行政救济领域 |
| 按日计罚主成果 | 应对按日连续处罚 |
| 拒不执行 | 整体停止指导 |
| 实体复议理由 | 准备环境处罚实体复议理由 |
| 整改方案正文 | 准备环境合规整改方案 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 行政强制执行程序整案 | 行政救济领域 |
| 矿业权吊销 | 评估矿业权延续注销吊销 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

责令改正不是罚款。停产整治不是关闭。未履行责令改正才可能启动按日计罚，不能把责令文书当日当作计罚起点。
