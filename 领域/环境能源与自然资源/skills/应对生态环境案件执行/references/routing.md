# 边界与路由

## 正触发

被执行修复或巨额赔偿。

立场：被执行人。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 隐匿破坏 | 整体停止 |
| 申请执行 | 执行生态环境生效文书 |
| 重审实体 | 再审或原实体原子，不在执行中展开 |
| 破产整案 | 破产领域接口 |
| 拒执刑事 | 刑事领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 执行和解 | 可写入分期方案 |
| 信用惩戒 | 只标接口 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

执行异议不是二审。分期修复申请不是已经批准。停运防治设施应付划扣会造成新的违法。
