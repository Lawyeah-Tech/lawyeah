# 边界与路由

## 正触发

需立即停止排污或破坏。

立场：申请方。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 财产保全 | 民事程序／财产保全接口，不混写 |
| 起诉状 | 提起环境污染侵权诉讼 或公益／生态起诉原子 |
| 现场证据保全 | 保全污染现场与监测证据 |
| 自行危险封堵 | 拒绝 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 行政责令停产 | 应对责令改正限制生产停产 |
| 海事禁令 | 海事领域 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

行为保全不是财产保全。行政责令停产不是法院禁止令。申请稿不能写成已经裁定。
