# 边界与路由

## 正触发

磋商不成或依法可诉，权利人指定部门拟起诉。

立场：原告代理人（赔偿权利人指定部门）。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 公益诉讼 | 提起环境民事公益诉讼 |
| 私益起诉 | 提起环境污染侵权诉讼 |
| 磋商未结束 | 谈判生态环境损害赔偿磋商 |
| 应诉该诉 | 应对生态环境损害赔偿诉讼 |
| 冒充指定部门 | 整体停止 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 一般行政诉讼 | 若误把民事索赔写成行政诉讼则纠正 |
| 执行 | 胜诉后转执行原子 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

政府生态损害赔偿诉讼不是公益诉讼，也不是普通侵权。磋商纪要不是起诉的可选附件，而是前置核验对象。
