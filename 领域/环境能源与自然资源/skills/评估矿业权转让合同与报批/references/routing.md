# 边界与路由

## 正触发

转让已签或拟签，报批未定。

立场：转让人或受让人（强制单方）。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 股权并购整案 | 投资并购／公司股权领域 |
| 合同改稿 | 审查起草（本窗搁置） |
| 报批材料主成果 | 准备矿业权转让变更报批 |
| 权利状态总评 | 评估矿业权取得变更与争议 |
| 抢先开采 | 整体停止指导 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 一般行政诉讼撤销登记 | 行政救济领域 |
| 上市公司矿权收购披露 | 证券接口 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

转让合同有约束力不等于已经变更矿业权。股权交割不等于采矿权主体变更。未经批准不是当然无效。
