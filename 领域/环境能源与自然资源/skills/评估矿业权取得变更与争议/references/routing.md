# 边界与路由

## 正触发

探矿权或采矿权取得、权属、转让、延续或吊销需要状态判断和路径。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 矿区土地或房屋买卖 | 房地产领域 |
| 矿山施工价款工期 | 建设工程领域 |
| 只要申请材料包 | `准备探矿权采矿权申请材料`（未安装则 `unavailable`） |
| 只要转让报批材料 | `准备矿业权转让变更报批`（未安装则 `unavailable`） |
| 只要修复义务专项 | `评估矿区生态修复义务`（未安装则 `unavailable`） |
| 未成争改转让合同 | 审查起草（本窗搁置） |
| 征地拆迁或土地承包 | C 端／对应领域 |

## 易混

股权转让控制矿山不等于矿业权已经变更登记。海域采砂可能同时触及海域使用权，专项未安装则标接口。
