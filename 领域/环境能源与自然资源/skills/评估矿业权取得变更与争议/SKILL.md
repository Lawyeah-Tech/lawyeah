# 评估矿业权取得变更与争议

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“矿业权状态与争议评估矩阵”：探矿权或采矿权主体、许可证与出让合同、重叠、转让报批、延续吊销、修复义务接口、民事或行政路径和下一步。

`depends-on` 为空。接受用户、律师或机关提供的等价证照和合同。

## 工作边界

正触发：中国大陆探矿权、采矿权的取得、权属、重叠、转让、延续、注销或吊销发生或可能发生争议，单方需要状态判断和路径。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 矿区土地使用权、房屋或地面附着物买卖主轴（房地产）；
- 矿山基建施工价款工期质量（工程）；
- 只要代写申请或报批材料包；
- 农村土地承包流转或征地拆迁材料；
- 未成争只要改转让合同文本（审查起草，本窗搁置）。

不得把民法通则第 81 条或与 2024 年矿产资源法冲突的旧条款写成现行规则。

## 建立评估坐标

确认：使用者与授权；单方立场；矿种、矿区范围、许可证号与有效期；出让或转让合同；报批状态；修复义务；法域；诉讼或处罚状态。

## 来源和判断状态

编号：`S#` 陈述；`D#` 材料；`A#` 承认；`R#` 许可证或登记；`C#` 出让或转让合同；`L#` 已核验规则；`I#` 判断；`G#` 缺口；`Q#` 权利／争议假设；`V#` 评估版本；`E#` 登记或缴费凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验矿产资源法（2024 修订，2025-07-01 施行）、民法典第 329 条、矿业权纠纷解释（2020 修正）、转让管理办法与新法是否冲突；`search_practiced` 补报批和合同效力反例。

工具不可用时继续证照对照；效力、批准和路径法律结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流和权利文本

土地使用权、施工合同转出。许可证、出让合同、转让合同、实际控制人分列。

### 2. 取得与效力

勘查、开采原则上分别取得探矿权、采矿权。出让合同依法成立的效力按解释第 2 条核验。

### 3. 转让、报批与变更登记

转让合同成立即有约束力；未经批准不得请求变更登记。不得仅以未经批准主张合同无效。

### 4. 重叠、延续、吊销与修复

矿区重叠、保护地冲突、延续条件、吊销事由。修复义务不因采矿权消灭而免除；转让后原则上由受让人履行。

### 5. 争议路径和下一步

民事诉讼、行政诉讼或复议实体接口、行政查处分列。一般复议程序转行政。不保证颁发或维持许可证。

## 停止与安全

- `整体停止`：立场不明；用户坚持无证开采或抢采。
- `字段停止`：新矿法与旧转让办法冲突未核验。
- `目标停止`：主目标变为报批材料或施工结算。
