# 边界与路由

## 正触发

渔损、作物、健康或清理费用需要分项数字，受害人或抗辩方需要可复核工作表。

立场：受害人或抗辩方（强制单方）。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 生态修复精算 | 测算生态环境损害与修复费用 |
| 侵权能否立住 | 评估环境污染侵权请求或抗辩 |
| 一般伤残鉴定 | 侵权或鉴定领域接口 |
| 起诉状 | 提起环境污染侵权诉讼 |
| 未知当零 | 拒绝 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 渔业互保或农业保险理赔 | 只标接口 |
| 工伤 | 劳动领域 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

渔损不是海洋生态损害。清理费用可能与政府索赔重叠，必须标互斥，不得加总冒充一笔环境权益。
