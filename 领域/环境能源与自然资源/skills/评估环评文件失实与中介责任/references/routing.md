# 边界与路由

## 正触发

环境影响报告书（表）被指造假、隐瞒超标或总量，或环评机构被追责，建设单位或环评机构需要争点判断。

立场：建设单位或环评机构（强制单方）。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 许可是否闭合 | 评估环评与排污许可缺口 |
| 处罚申辩终稿 | 准备环境行政处罚陈述申辩 |
| 中介民事连带精算 | 评估惩罚性赔偿与中介连带 |
| 刑事辩护或控告 | 刑事领域 |
| 代做环评报告 | 负触发 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 一般行政许可撤销程序方法 | 行政救济领域 |
| 建设工程设计质量主轴 | 建设工程领域 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

环评技术争议不是必然造假。批复被撤销不等于建设单位与机构当然连带赔偿全部生态损害。
