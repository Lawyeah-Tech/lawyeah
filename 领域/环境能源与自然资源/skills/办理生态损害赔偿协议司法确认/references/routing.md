# 边界与路由

## 正触发

需司法确认增强生态环境损害赔偿协议执行力。

立场：单方。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 尚无协议 | 起草生态环境损害赔偿协议 |
| 已有生效文书要执行 | 执行生态环境生效文书 |
| 把未确认当执行依据 | 禁止 |
| 磋商未谈拢 | 谈判生态环境损害赔偿磋商 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 一般民事调解确认程序 | 民事程序接口 |
| 行政复议 | 不适用于协议确认 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

司法确认不是重新判决实体责任。确认裁定前不得向法院执行机构申请强制执行该协议。
