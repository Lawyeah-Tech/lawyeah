# 谈判生态环境损害赔偿磋商

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“生态环境损害赔偿磋商方案”：主体资格、争点、修复或赔偿边界、让步表、弃权范围、协议效力与司法确认提示、磋商不成转诉讼接口。

`depends-on` 为空。接受用户、律师或机关提供的等价调查评估和测算。

本任务不代行赔偿权利人的调查权，不把磋商纪要写成生效判决。

## 工作边界

正触发：省级或设区的市级人民政府及其指定部门、机构已启动或拟启动生态环境损害赔偿磋商，或赔偿义务人需要应对磋商。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要测算工作表或总图；
- 条件已谈拢，只要协议正文（未安装则 `unavailable`）；
- 磋商已结束并已决定起诉，只要诉状；
- 私益和解主轴；
- 用户要求隐匿排放或威胁评估机构。

## 建立磋商坐标

确认：使用者与授权；单方是权利人指定部门还是义务人；启动文书；调查评估报告；拟修复方案；法域；已开会次数和期限；是否并行公益诉讼或刑事案件。

## 来源和判断状态

编号：`S#` 陈述；`D#` 材料；`A#` 承认；`R#` 启动或评估文书；`C#` 方案条款；`L#` 已核验规则；`I#` 判断；`G#` 缺口；`Q#` 争点；`V#` 方案版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验生态环境损害赔偿规定、民法典第 1234–1235 条、固废法第 122 条；`search_practiced` 补磋商不成情形和司法确认。

工具不可用时继续争点和让步表；协议效力和诉讼前置字段停止。

## 五个判断节点

执行顺序和停止条件以 [磋商方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、主体和启动

确认权利人层级和指定文件。本包不冒充检察机关或政府。

### 2. 争点和评估材料

行为、损害、数额、关联性、修复可行性分列。义务人可异议评估并保留重新鉴定。

### 3. 让步、弃权和互斥

修复方式、期限、分期、担保、弃权范围。不得放弃尚未查明的其他介质损害除非明示。私益受害人权利不得被义务人与政府协议处分。

### 4. 协议效力与司法确认

磋商协议具有民事合同性质。无司法确认或公证赋强则执行力受限，必须明示。

### 5. 不成转诉讼

拒绝磋商、无故缺席、多次会议或超期未达成：标诉讼接口，不在本任务写诉状。

## 停止与安全

- `整体停止`：立场不明；用户坚持伪造评估或威胁。
- `字段停止`：权利人资格、协议效力未核验。
- `目标停止`：主目标变为协议正文或起诉包。
