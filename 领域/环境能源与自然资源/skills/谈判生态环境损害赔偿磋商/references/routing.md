# 边界与路由

## 正触发

生态损害赔偿磋商已启动或即将启动，需要单方底线和效力提示。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要测算 | `测算生态环境损害与修复费用` |
| 已谈拢要协议正文 | `起草生态环境损害赔偿协议`（未安装则 `unavailable`） |
| 司法确认 | `办理生态损害赔偿协议司法确认`（未安装则 `unavailable`） |
| 磋商不成要起诉 | `提起生态环境损害赔偿诉讼`（未安装则 `unavailable`） |
| 私益和解 | `谈判污染侵权和解方案`（未安装则 `unavailable`） |

## 易混

环保行政处罚结案不等于生态损害赔偿已经放弃。公益诉讼与政府索赔可能并行，弃权条款必须限定主体。
