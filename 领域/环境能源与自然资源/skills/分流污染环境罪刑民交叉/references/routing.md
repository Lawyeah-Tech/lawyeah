# 边界与路由

## 正触发

出现污染环境罪、非法处置危废、伪造监测数据迹象。

立场：单方。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 辩护或控告 | 刑事领域 |
| 拘留移送专项 | 评估行政拘留与涉嫌犯罪移送 |
| 危废合规 | 评估危险废物全链条合规 |
| 监测数据 | 评估自行监测与排污数据合规 |
| 毁证串供 | 整体停止 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 监察调查 | 只标接口 |
| 单位犯罪与责任人 | 转刑事展开 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

行政罚款已缴不是刑事免责。民事调解不是刑事撤案。红旗清单不是起诉意见书。
