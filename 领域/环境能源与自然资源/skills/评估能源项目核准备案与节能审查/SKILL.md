# 评估能源项目核准备案与节能审查

## 任务目标

在明确、无利益冲突的投资人立场下，形成“能源项目核准备案与节能审查矩阵”：项目性质、核准目录、节能审查、与环评分账。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：火电、风光、水电、储能等项目核准、备案或节能审查受阻。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 施工总承包价款工期（转工程）；
- 用地出让或征地主轴（转房地产／征收分流）；
- 只要项目环评缺口终稿；
- 改购电或EPC合同（审查起草搁置）；

本任务不给胜诉率，未知金额不写零。

## 建立工作坐标

确认：使用者与授权；单方立场（投资人）；相对方、主管机关及可能责任主体；关键文本版本；法域；当前检查、处罚、协商、诉讼或执行状态；机关文书作出与送达；对方已知主张；关键材料及缺失。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 许可、标准或合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩或义务假设；`V#` 版本；`E#` 送达／监测／履行凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 停止与安全

- `整体停止`：指导未批先建或伪造节能报告；利益冲突未解；基础主体无法建立。
- `字段停止`：核准目录、节能审查范围未核验；法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标变为EPC结算或环评代做。
