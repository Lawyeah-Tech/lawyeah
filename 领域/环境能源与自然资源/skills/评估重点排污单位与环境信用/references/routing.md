# 边界与路由

## 正触发

名录、环境信用评价、区域或企业限批、绿色信贷或融资因环境信用受阻，生产经营者需要要件和修复判断。

立场：生产经营者。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要总图 | 评估环境能源与资源事项 |
| 信息公开范围主成果 | 评估环境信息公开义务 |
| 虚假整改换修复 | 整体停止 |
| 融资合同改稿 | 审查起草（本窗搁置） |
| 发放修复决定 | 负触发，无权作出 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 一般行政行为复议程序 | 行政救济领域 |
| 银行贷款担保主轴 | 金融或合同争议接口 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

重点排污单位名录不是失信惩戒名单。限批不是关闭决定。信用修复决定只能由有权机关作出。
