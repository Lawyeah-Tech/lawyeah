# 边界与路由

## 正触发

海域使用权取得、变更或违法采砂被查。

立场：权利人或被查处人（强制单方）。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 船舶事故 | 海事领域 |
| 陆源污染 | 评估陆源污染海洋责任 |
| 矿业权评估 | 评估矿业权取得变更与争议 |
| 无证采砂操作 | 整体停止 |
| 海岸施工结算 | 建设工程领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 河湖采砂许可 | 水法／河长制接口，可类比双闸 |
| 填海造地供地 | 房地产接口 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

海域使用权证不是采矿许可证。航道疏浚出土不等于可以对外销售海砂。船舶采砂作业事故走海事。
