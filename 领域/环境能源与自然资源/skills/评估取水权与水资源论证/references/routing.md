# 边界与路由

## 正触发

取水许可、水量、退水或转让发生争议。

立场：取水人或相对人（强制单方）。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 供水合同价款 | 合同争议领域 |
| 取水许可申请 | 准备取水许可申请或变更 |
| 农村承包用水 | 只分流 |
| 合同改稿 | 审查起草（本窗搁置） |
| 河湖采砂 | 评估海域使用权与采砂 或地方河湖采砂接口 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 水污染排放许可 | 评估环评与排污许可缺口 |
| 抗旱应急取水 | 须核验特别规定 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

取水许可不是排污许可。水资源论证不是项目环评。缴纳水费不是当然取得取水权。
