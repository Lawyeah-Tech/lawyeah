# 边界与路由

## 正触发

持修复或赔偿生效文书未获履行。

立场：权利人。强制单方。同时掌握双方策略时停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未确认协议 | 办理生态损害赔偿协议司法确认 |
| 被执行人立场 | 应对生态环境案件执行 |
| 重审实体 | 拒绝；实体原子另选 |
| 文书未生效 | 负触发 |
| 非法讨债 | 整体停止 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 建设工程施工、分包、优先受偿、工程造价鉴定 | 建设工程领域 |
| 商品房、开发合作、物业、建设用地买卖 | 房地产物业领域 |
| 只要复议格式、起诉期限计算、行政庭审程序 | 行政救济领域 |
| 船舶油污、海上运输、海事保全 | 海事领域 |
| 农村土地承包流转 | 只分流 |
| 征地拆迁补偿材料 | C 端拆迁／房地产或行政，只分流 |
| 定罪、控告、辩护 | 刑事领域 |
| 未成监管事项只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 矿业公司股权并购整案 | 投资并购／公司股权领域 |
| 行政非诉执行 | 行政救济领域 |
| 破产分配 | 破产接口 |

一般排污或项目夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

司法确认前的磋商协议不是执行依据。修复行为执行不是简单的划扣银行存款。执行不能重写鉴定结论。
