# 边界与路由

## 正触发

需要环境污染或生态损害的要件、举证分配和合法补证矩阵。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要总图 | `评估环境能源与资源事项` |
| 只要诉状 | `提起环境污染侵权诉讼` |
| 只要鉴定申请稿 | `准备环境损害司法鉴定申请`（未安装则 `unavailable`） |
| 现场可能灭失且只要保全步骤 | `保全污染现场与监测证据`（未安装则 `unavailable`） |
| 工程造价鉴定 | 建设工程领域 |
| 违法取样或关停监控 | 整体停止 |

## 易混

一份超标报告不等于关联性已成立。执法卷不等于不可质证的定案依据。
