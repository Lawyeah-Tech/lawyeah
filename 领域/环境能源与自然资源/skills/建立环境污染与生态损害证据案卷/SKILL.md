# 建立环境污染与生态损害证据案卷

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“环境污染与生态损害证据案卷”：要件、举证责任分配、监测与鉴定、行政执法证据转化、合法补证和禁止项。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价评估和材料清单。

## 工作边界

正触发：中国大陆环境污染、生态破坏或生态环境损害赔偿事项，单方需要单独盘点举证责任和补证。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要策略总图或诉状；
- 要求进入危险区、调换样品、关闭监控或伪造背景值；
- 工程造价鉴定主轴；
- 一般民事证据三性科普而无环境要件。

本任务不替代总体策略，不保证法院采信。

## 建立案卷坐标

确认：使用者与授权；单方立场；请求或抗辩假设；介质与时段；已有监测、鉴定、执法卷；法域；诉讼或磋商状态。

## 来源和判断状态

编号：`S#` 陈述；`D#` 材料；`A#` 承认；`R#` 执法或鉴定；`C#` 标准定位；`L#` 已核验规则；`I#` 判断；`G#` 缺口；`Q#` 待证事实；`EV#` 证据；`V#` 案卷版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验法释〔2023〕6 号、民法典第 1230 条、行政执法证据转化规则；`search_practiced` 补磋商材料入诉。

工具不可用时继续材料编目；举证分配法律结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [建卷方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流和待证事实

按私益、公益或生态损害赔偿分别列要件。禁止一套证据冒充三类请求。

### 2. 举证责任分配

原告证明行为和关联性；行为人对免责减责和无因果关系举证。不得写成原告无需举证。

### 3. 监测、鉴定和执法转化

行政执法调查报告、检测、评估在符合标准并经质证后可作为证据。磋商阶段材料可转化，对方可申请重新鉴定。

### 4. 合法补证

公证、申请调查令、申请鉴定、申请证据保全。禁止违法取样和破坏现场。

### 5. 缺口时点和案卷目录

按易失性和期限排序补证。输出目录，不写诉状。

## 停止与安全

- `整体停止`：立场不明；用户坚持违法取证。
- `字段停止`：举证规则未核验。
- `目标停止`：主目标变为起诉或鉴定意见本身。
