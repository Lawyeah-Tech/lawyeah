# 起草方法

本文件是可执行判断节点，不是栏目说明书。每个会改变通知时限、调整项或附件接口结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

调价通知把测算争议送入合同程序，不代替测算，也不等于赔偿通知。

---

## Q# 调整项表

固定列：`编号｜项目｜条款｜数字状态｜附件｜是否写入通知`。

净债务、营运资金、泄漏、错误分列。未知留空。

---

## 节点 0　闸

1. 机制未定 → `评估锁箱与交割账机制`。
2. 数字工作表 → 测算原子。

## 节点 1　时限

1. 逾期通知可能不得调整，揭示风险。

## 节点 2　正文

1. 指向附件，不在通知里发明新口径。

## 节点 3　与赔偿

1. 同一事实可能两套请求，标互斥。

## 节点 4　到达

1. 约定渠道。

## 节点 5　安全

1. 禁止编造数字。

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 发出通知 | 调整金额已经确定应付 |
| 测算没做 | 可以写一个整数充数 |
| R&W 通知 | 本任务主成果 |
| 机制还在选 | 本任务主成果 |

---

## 条件句

if 无数字基础还要写确定额 → 金额字段停止或负触发回测算
if 编造 → 整体停止
if 机制未选 → 负触发
if R&W 赔偿主成果 → 负触发

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 不代替测算终稿。 |
| 2 | 不写已确定应付。 |
| 3 | 时限逾期标失权风险。 |
| 4 | 与赔偿互斥须揭示。 |

---

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按编造、时限、与赔偿分工排序。测算、机制评估、赔偿通知只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

状态保持待发送。
---

## 补充条件句与停止

if 锁箱或交割账机制尚未选择 → 负触发，转机制评估原子。  
if 没有任何测算基础却要写确定应付额 → 金额字段停止，或转测算原子。  
if 主成果是陈述保证赔偿通知 → 负触发。  
if 通知时限可能已过 → 揭示失权风险，不得写成调整权已保全。  
禁止编造数字。通知不是调整金额已确定的裁判。
