# 准备价格调整通知

## 任务目标

在明确、无利益冲突的单方立场下，形成“发送前价格调整通知”：发送前通知、计算附件接口

`depends-on` 为空。接受用户、律师、财务顾问或其他来源的等价事实、估值、清单和文本。本任务不把未核验规则写成已闭合结论。

## 工作边界

正触发：交割账或锁箱泄漏需书面提出调整；主张方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 代替测算终稿；
- 投后 R&W 赔偿通知；
- 机制尚未选择；
- 写成调整金额已确定应付；

本任务不代替测算终稿，不给成交率或胜诉率。

## 建立出稿坐标

确认：使用者与授权；单方立场；机制条款；测算草稿或等价数字；通知时限；拟发送日；法域；当前磋商、文本、审批或交割状态；关键材料及缺失。

同时掌握买卖双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 陈述；`D#` 测算／报表；`C#` 调价条款；`L#` 已核验规则；`I#` 判断；`Q#` 调整项；`E#` 送达；`V#` 版本

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验通知时限和价款确定；不虚构审批系统、案号或登记回执。

工具不可用时继续按已有测算接口出受限通知，终局数字字段停止；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [起草方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　闸

机制未选转机制原子。无任何数字基础不得写确定应付额。

### 节点 2　时限

交割账提交期、异议期。逾期可能失权，标红旗。

### 节点 3　正文

调整项、依据、附件接口。不代替测算终稿。

### 节点 4　专家程序

会计师程序接口。

### 节点 5　到达

待发送。不写金额已确定。

## 停止与安全

- `整体停止`：编造数字；倒签通知日。
- `字段停止`：时限未核验。
- `目标停止`：主目标变为测算终稿或 R&W 通知。

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `草案、待发送、停止`。边界见 [路由](references/routing.md)。
