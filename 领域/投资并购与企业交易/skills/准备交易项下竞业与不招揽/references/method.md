# 起草方法

本文件是可执行判断节点，不是栏目说明书。每个会改变范围、期限、对价或效力红旗结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

交易项下竞业保护的是买方取得的商誉和业务，不是用工管理。劳动竞业的期限、补偿、范围转劳动。不保证条款有效。

---

## Q# 限制矩阵

固定列：`编号｜主体｜业务｜地域｜期限｜对价接口｜劳动交叉｜效力红旗｜状态`。

卖方、创始人、控股股东分列。

---

## 节点 0　分流

1. 劳动合同竞业、补偿、经济补偿金 → 劳动。
2. 横向市场分割 → 竞争法红旗。

## 节点 1　范围

1. 必须对应所售业务。全国全行业无期限标高风险。

## 节点 2　对价

1. 未另付对价不自动无效，但须揭示争议。不得写成当然有效。

## 节点 3　不招揽

1. 主动挖角 vs 员工自主求职分列。

## 节点 4　双重文件

1. 同时有劳动竞业：揭示可能适用劳动强制规范。

## 节点 5　安全

1. 禁止用交易文件规避劳动保护。

---

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 写了竞业 | 一定有效可执行 |
| 创始人也是员工 | 只需交易文件不必看劳动法 |
| 劳动竞业协议 | 本任务主成果 |
| 范围越宽越好 | 法律支持 |

---

## 条件句

if 劳动竞业主成果 → 负触发
if 规避劳动补偿 → 整体停止
if 范围覆盖无关市场 → 效力红旗，可能删减
if 保证有效 → 不得输出该保证

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按劳动规避、范围过宽、垄断红旗排序。劳动、竞争法、SPA 只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

文本状态保持待签署。不保证有效。
---

## 补充条件句与停止

if 主成果是劳动合同竞业限制、补偿金或经济补偿 → 负触发，转劳动领域。  
if 用交易竞业规避劳动法定补偿 → 整体停止。  
if 范围覆盖所售业务以外的全国全行业且无期限 → 效力红旗，不得保证可执行。  
if 出现横向分割市场线索 → 竞争法红旗，本任务不写垄断分析终局。  
不保证条款有效。不得输出“签了就能禁止对方从业”。
