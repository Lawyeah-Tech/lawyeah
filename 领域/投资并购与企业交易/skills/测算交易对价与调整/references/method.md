# 测算方法

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。金额状态：`已核实金额`、`情景金额`、`无法估计`。未知不写零。真实零必须有肯定来源。不输出唯一必得总额。不认定调整权或对赌已成立。

失效合同法不得写入 `L#`。

---

## 节点 0　分流

if 主成果是税负 → 税务领域。  
if 主成果是对赌效力 → 效力字段停止并转出，数字接口可留。  
if 无任何价格条款、报价或参数 → 不出工作表终稿。

---

## 节点 1　机制识别

读取条款原文：
- 锁箱：锁箱日权益价值 − 泄漏 +/− 其他约定。锁箱日后普通经营流出不当然是泄漏。
- 交割账：权益价值 − 净债务 +/−（实际营运资金 − 目标营运资金）。
- 固定价：无调整则工作表只列基础价和已付，不编调整。
- 混合：按条款拆行，不把两套机制的减项加两次。

if 机制冲突或条款无法定位公式 → 并列情景，主位 `依据不足`。

---

## 节点 2　分项建账

为同一经济事件分配 `EVT#`。分项：`M-基础` `M-现金` `M-金融债` `M-类债` `M-营运资金` `M-泄漏` `M-已付定金` `M-留扣` `M-或有`。

规则：
- 现金与债务定义以条款为准，不以用户口头“就是贷款”。
- 关联方借款、未宣告股利、资本开支承诺是否计入净债务：条款沉默则 `无法估计`，不按“行业惯例”填数。
- 营运资金目标值缺失：不编造历史平均数冒充约定目标。
- 已付订金／定金与分手费互斥时两项都列，标选用，不双计。

---

## 节点 3　或有对价接口

业绩补偿、回购价款、奖励对价只列公式参数和已知输入。  
if 义务主体是目标公司 → 标注资本维持／减资闸待核，不把公式结果写成可强制执行金额。  
if 上市对赌 → 标证券监管红旗，不算入已核实应付。

---

## 节点 4　情景与汇总

情景只改变列明变量（例如营运资金 ±X、是否计入某笔关联借款）。汇总分三栏：已核实、情景、无法估计。禁止把三栏加总成“应付人民币 Y 元整”。用户索要唯一总额：拒绝并保持部分形成。

---

## 节点 5　安全

禁止按用户要求把收入做高或把债务藏掉。禁止指导阴阳价。测算不是付款指令，资金流向转交割原子。
