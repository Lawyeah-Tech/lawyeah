# 测算交易对价与调整

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“交易对价可复核测算包”：机制识别、分项工作表、情景区间、互斥和缺口。本任务**不认定调整权已经成立**，不输出唯一必得总价。

`depends-on` 为空。接受用户、财务顾问或审计的等价参数。

## 工作边界

正触发：单方需要对基础价、净债务、营运资金、锁箱泄漏、交割账或或有对价做可复核数字工作表。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要对赌效力判断；
- 只要税负测算；
- 只要结构总图或 SPA 正文；
- 融资成本测算主轴（转金融）。

## 建立测算坐标

确认：使用者与授权；单方立场；价格条款版本；锁箱日或交割账日；已付；单位和币种；法域。

用户希望唯一金额，不构成把未知写成零的授权。

## 来源和判断状态

编号：`S#` 陈述；`D#` 报表或流水；`C#` 价格条款；`L#` 已核验规则；`I#` 判断；`G#` 缺口；`EVT#` 经济事件；`M#` 测算行；`V#` 工作表版本。

金额状态只用 `已核实金额`、`情景金额`、`无法估计`。未知不写零。真实零必须有肯定来源。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验违约金或定金与交易分手费交叉时的调整规则。工具不可用时继续分项建账，法定上限字段停止。

## 五个判断节点

执行顺序和停止条件以 [测算方法](references/method.md) 为准。

### 1. 机制识别

锁箱与交割账互斥主位，除非条款明确组合。

### 2. 分项建账

基础价、净债务、现金、营运资金、泄漏、或有对价分列。同一 EVT 不得重复计入。

### 3. 或有对价接口

对赌只建数字接口，不判与目标公司约定的效力。

### 4. 互斥和情景

情景只改变列明变量。禁止唯一必得总额。

### 5. 缺口和下一步

转介效力评估、索赔通知或交割，不在本任务出通知。

## 停止与安全

- `整体停止`：立场冲突；伪造流水；把未知当零。
- `字段停止`：会计定义或条款公式未核验。
- `目标停止`：主目标变为效力判断或出 SPA。
