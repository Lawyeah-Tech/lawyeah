# 起草方法

本文件是可执行判断节点，不是栏目说明书。每个会改变协议条款、通知安排或债务承继结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

已定路径是发送闸。评估原子或其他来源的等价路径结论均可。文本状态保持待签署、待发送。不得把草案写成合并已经发生。

---

## Q# 文件块矩阵

固定列：`编号｜文件｜必要事项｜事实支持｜待核规则｜与债权人关系｜状态`。

协议、决议、资产负债表／财产清单、通知、公告安排、债务承继表分列。

---

## 节点 0　发送闸

1. 路径未在吸收／新设／分立中闭合 → 负触发，回 `评估合并分立重组路径`。
2. 破产程序内 → 转破产。
3. 用户只要申报集中 → 转竞争法。

## 节点 1　协议与决议

1. 协议写明各方、类型、份额或对价、交割或生效日机制、员工接口、违约。
2. 决议按特别决议草案准备，回避按关联原子接口。
3. 对价未知写确定机制，不写零。

## 节点 2　债权人程序安排

1. 已知债权人书面通知与公告并行设计。
2. 期间起算依赖送达和公告规则，未核验则起算字段停止。
3. 本任务不执行发送，不写“已公告”。

## 节点 3　债务承继表

1. 金融债务、经营债务、担保、诉讼标的分列对应主体。
2. 内部分担协议不能对抗提出请求的债权人。
3. 未知债务标或有，不写成零。

## 节点 4　登记与安全

1. 当地登记书式一律待核。
2. 禁止倒签决议日、公告日。禁止指导隐匿债权人。

## 节点 5　下一步

1. 债权人提出清偿或担保 → `应对合并分立债权人清偿或担保请求`。
2. 集中申报红旗转竞争法。

---

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 路径还在讨论 | 可以出发送前终稿 |
| 通知稿已写 | 已经公告并起算 |
| 内部约定债务归甲方 | 债权人必须找甲方 |
| 登记材料未交 | 合并已经生效 |

---

## 条件句

if 路径未定 → 负触发
if 债权人名单明显不全且用户拒绝补 → 通知安排可出受限稿，起算和对抗字段停止
if 用户要求倒签公告日 → 整体停止
if 破产程序内 → 负触发，转破产

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 债权人通知与公告安排必须设计，本任务不代发。 |
| 2 | 内部分担不得写成已对抗债权人。 |
| 3 | 草案不得写成已生效或已登记。 |
| 4 | 集中申报不在本任务撰写。 |

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按路径闸、债权人名单、通知期限、登记书式排序。代发公告、申报、破产文件只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

文本状态保持待签署、待发送。
