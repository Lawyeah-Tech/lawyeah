# 边界与路由

## 正触发

已定合并或分立路径，需协议、决议、资产负债表和债权人通知公告。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 路径未定 | 评估合并分立重组路径 |
| 债权人已提出清偿或担保 | 应对合并分立债权人清偿或担保请求 |
| 代发公告或代登记 | 不实施 |
| 经营者集中申报 | 竞争法领域 |
| 破产程序文件 | 破产领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 经营者集中申报、竞争限制专项 | 竞争法领域 |
| 借贷、保证、抵押质押、保理、融资租赁主轴 | 金融领域 |
| 日常章程、股东会、董事会或一般股东争议 | 公司治理领域 |
| 劳动尽调、员工转移、安置方案本身 | 劳动领域 |
| 环境许可、资源权利、能源监管专项尽调 | 环境能源领域 |
| 境外法适用、ODI、制裁、跨法域准入整体 | 涉外领域 |
| 税负测算、税务架构或稽查应对 | 税务领域 |
| 破产、重整、清算程序内投资 | 破产领域 |
| 一般买卖服务合作签前审查起草 | 审查起草领域（本窗搁置） |
| 证券发行、持续信息披露正文或重组报告书 | 证券监管专项，未核验则字段停止或 `unavailable` |

## 易混

路径已定、要协议和通知安排时正触发。还在选吸收还是分立，或已经要发公告回执时负触发。
