# 准备合并分立实施文件与债权人通知

## 任务目标

在明确、无利益冲突的单方立场下，形成“发送前合并／分立实施文件包”：发送前合并／分立协议、债权人通知与公告安排、债务承继表

`depends-on` 为空。接受用户、律师、财务顾问或其他来源的等价事实、估值、清单和文本。本任务不把未核验规则写成已闭合结论。

## 工作边界

正触发：已定合并或分立路径，需协议、决议、资产负债表和债权人通知公告。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 路径未定，先要评估；
- 只要代发公告或代提交登记；
- 只要经营者集中申报；
- 破产程序内重整文件；

本任务不代发公告；集中申报转竞争法；破产程序转破产，不给成交率或胜诉率。

## 建立出稿坐标

确认：使用者与授权；单方立场；已定类型；各方授权；资产负债表基准日；已知债权人名单；法域；当前磋商、文本、审批或交割状态；关键材料及缺失。

同时掌握买卖双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 陈述；`D#` 财报／债权人名单；`C#` 路径结论／章程；`L#` 已核验规则；`I#` 判断；`G#` 缺口；`Q#` 条款块；`V#` 文本版本

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验合并分立协议必要事项、通知公告和登记；`search_template` 只借栏目；不虚构审批系统、案号或登记回执。

工具不可用时继续按已定路径出受限草案，通知期限和法律效果字段停止；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [起草方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　发送闸和路径闭合

路径未定负触发回评估原子。破产或集中申报主成果转出。

### 节点 2　协议和决议结构

合并／分立协议必要事项、对价或份额、职工安置接口、生效条件分列。草案不得写成已生效。

### 节点 3　债权人通知与公告安排

通知对象、渠道、公告媒体、期间起算待核。本任务不代发。

### 节点 4　债务承继表

已知债务逐笔对应承继主体。约定内部分担不得写成已对抗债权人。

### 节点 5　登记和不可逆提示

四节点分列。文本保持待签署。禁止倒签公告日。

## 停止与安全

- `整体停止`：立场冲突；倒签；伪造债权人名单或已通知记录。
- `字段停止`：通知公告期限、登记书式、简易合并未核验。
- `目标停止`：路径未定；主目标变为代发公告或集中申报。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `草案、待签署、停止`。边界见 [路由](references/routing.md)。
