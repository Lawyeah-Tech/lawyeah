# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变或有事项分级或交割条件结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

或有负债评估服务交易决策，不代替审判。禁止输出胜诉率。未知金额不写零。

---

## Q# 或有事项矩阵

固定列：`编号｜类型｜相对方｜程序阶段｜请求／处罚｜金额区间｜担保／保全｜交易影响｜判断｜待核`。

诉讼、仲裁、处罚、担保、承诺分列。金额给区间或标未知。

---

## 节点 0　分流

1. 写诉状或代理策略 → 合同争议或其他诉讼领域。
2. 完整报告 → 报告原子。

## 节点 1　清单

1. 检索与卖方披露对照。未检索不得写“无诉讼”。

## 节点 2　定性

1. 公司为被告、原告、第三人、担保人分列。
2. 行政处罚与民事请求分账。

## 节点 3　接口

1. 价格调整、留扣、专项赔偿、交割条件、披露。
2. 测算数字转测算原子。

## 节点 4　反方

1. 卖方“无关紧要”不得直接采信。
2. 重复赔偿与保险回收不得重复计入已确定应付。

## 节点 5　下一步

1. 否决级转红旗原子。发索赔通知是投后事项。

---

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 没给案卷 | 没有或有负债 |
| 卖方说能赢 | 风险为零 |
| 本任务表格 | 案件已经胜诉或败诉 |
| 金额未知 | 记为零 |

---

## 条件句

if 用户要应诉状 → 负触发
if 未做任何检索且无披露 → 无诉讼结论不得输出
if 隐匿已知诉讼 → 整体停止
if 金额未知 → 写未知，不写零

---

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 不定案、不写诉状、不给胜诉率。 |
| 2 | 未知金额不写零。 |
| 3 | 未检索不得写无诉讼。 |
| 4 | 普通诉讼代理转出。 |

---

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按隐匿、未检索、金额缺口、期限排序。应诉、报告、测算只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

本成果不是裁判，也不是准备金会计意见。
