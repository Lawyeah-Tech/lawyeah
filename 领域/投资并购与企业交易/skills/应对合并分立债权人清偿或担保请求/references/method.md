# 应对方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求是否成立、清偿担保选项或进程影响结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

公司方立场。债权人请求不是普通催收模板。未核验公司法债权人保护条文前，不得输出“请求不成立、合并不受影响”。

---

## Q# 请求矩阵

固定列：`编号｜债权人｜债权依据｜金额待核｜是否到期｜期间内｜请求内容｜成立判断｜选项｜对进程影响`。

金额未知不写零。多项债权不得合成一笔“供应商货款”。

---

## 节点 0　分流

1. 与合并分立无关的日常催收 → 合同争议或金融。
2. 破产程序内 → 破产。
3. 路径未定 → 先回路径评估。

## 节点 1　期间与送达

1. 通知是否发出、是否到达、公告是否完成、期间是否起算分列。
2. 已读微信不等于到达。无送达事实不得写期间已过。

## 节点 2　成立性

1. 债权是否存在、金额、抗辩、是否已过诉讼时效分列。
2. 未到期债权请求提供担保与请求立即清偿分账。
3. 或有债权、担保债权单独标待核。

## 节点 3　选项

1. 清偿、保证、抵押质押、银行保函、提存分列可行性和对公司流动性影响。
2. 金融担保文件转金融，本任务只留接口。
3. 禁止指导抽逃或偏颇清偿损害其他债权人。

## 节点 4　进程

1. 依法应清偿或担保而未履行时，合并分立推进的法律障碍待核。
2. 不得写“债权人未起诉就可以交割登记”。

## 节点 5　下一步

1. 需要书面答复稿可在本任务列要点；发送状态不得写成已消除请求。
2. 争议诉讼转合同争议。

---

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 债权人只是普通供应商 | 没有合并法上的请求权 |
| 公司现金流紧 | 可以一律拒绝担保 |
| 期间是否起算不清 | 期间已过 |
| 一般讨债 | 本任务主成果 |

---

## 条件句

if 请求与合并分立程序无关 → 负触发
if 通知期间事实不足 → 成立性和进程字段停止或部分形成
if 用户要求否认账上已知债务 → 整体停止
if 破产已受理 → 负触发，转破产

---

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 合并分立中债权人请求清偿或担保是法定保护接口，不是普通商务谈判。 |
| 2 | 未到期债权与已到期债权的选项不同，必须分账。 |
| 3 | 期间起算依赖送达和公告事实。 |
| 4 | 一般催收和金融清收转出。 |

---

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按期间、债权真实性、违法推进风险、担保文件排序。路径重判、普通诉讼、金融担保正文只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

本成果不是判决，也不构成已清偿收据。
