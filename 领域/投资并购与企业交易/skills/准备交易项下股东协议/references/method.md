# 起草方法

本文件是可执行判断节点，不是栏目说明书。每个会改变保护性权利、转让限制或退出机制结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

交易项下 SHA 服务交割后投资人与创始人安排，不接管日常公司治理生产线。劳动股权激励方案转劳动。

---

## Q# 条款块矩阵

固定列：`编号｜权利｜主体｜触发｜与章程关系｜资本维持｜可执行性待核｜状态`。

治理、信息、转让、退出、清算优先分列。

---

## 节点 0　分流

1. 日常章程修订 → 公司治理。
2. 期权／限制性股权用工后果 → 劳动。
3. 认购额与缴付 → 认购原子。

## 节点 1　保护性权利

1. 否决清单必须特定。概括否决全部经营标风险。

## 节点 2　转让

1. 拖售对未签署股东的效力待核。
2. 优先购买与法定程序衔接。

## 节点 3　章程

1. 建议同步修改的条款只列接口，不在本任务完成登记章程修订流程。

## 节点 4　回购

1. 目标公司回购或补偿：资本维持、减资闸。不得写成当然有效。

## 节点 5　安全

1. 不得用 SHA 剥夺职工董事法定席位或法定公示义务。

---

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| SHA 已起草 | 已经替代章程并对抗第三人 |
| 拖售条款 | 未签约小股东一定被拖售 |
| 劳动期权 | 本任务主成果 |
| 日常董事会怎么开会 | 本任务主成果 |

---

## 条件句

if 日常治理主成果 → 负触发
if 劳动激励主成果 → 负触发
if 对公司回购未核验资本维持 → 效力字段停止
if 架空法定机关 → 整体停止或该条款删除

---

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | SHA 不当然对抗第三人。 |
| 2 | 拖售对未签署方效力待核。 |
| 3 | 对公司回购不当然有效。 |
| 4 | 日常治理和劳动激励转出。 |

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按章程冲突、资本维持、未签署方、劳动交叉排序。认购协议、章程修订流程、劳动方案只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

文本状态保持待签署。
