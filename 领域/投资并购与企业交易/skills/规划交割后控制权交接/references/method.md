# 规划方法

本文件是可执行判断节点，不是栏目说明书。每个会改变交接步骤、决议接口或停止项结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

交接计划把交易文件里的控制权变成可执行步骤，但不接管公司治理生产线，不写抢章脚本。

---

## P# 步骤矩阵

固定列：`编号｜步骤｜前置｜文件｜责任人｜失败回退｜停止项`。

改选、印鉴、银行、系统、信息权分列。

---

## 节点 0　分流

1. 开会通知制度 → 公司治理。
2. 印鉴清单细节 → 印鉴原子。

## 节点 1　改选

1. 股东会／董事会职权。职工董事不得随意取消。

## 节点 2　顺序

1. 先有权机关决议，再改印鉴和银行。

## 节点 3　不配合

1. 协议义务、诉讼接口。禁止抢章。

## 节点 4　信息权

1. 报表、查阅。过度查阅转公司治理边界。

## 节点 5　状态

1. 计划≠已改选完成。

---

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 写了计划 | 董事已经改选完成 |
| 对方不交章 | 可以去抢 |
| 怎么开例会 | 本任务主成果 |
| 印鉴清单 | 可以代替本计划 |

---

## 条件句

if 日常治理主成果 → 负触发
if 抢章 → 整体停止
if 罢免门槛未核验 → 改选有效性字段停止
if 只要印鉴清单 → 转印鉴原子

---

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 不接管日常治理。 |
| 2 | 不指导抢章。 |
| 3 | 计划不是已完成。 |
| 4 | 职工董事等法定安排不得随意取消。 |

---

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按抢章、治理边界、罢免门槛排序。公司治理、印鉴清单、登记只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

本成果不是已完成改选的证明。
---

## 补充条件句与停止

if 主成果是日常如何召集股东会或董事会 → 负触发，转公司治理。  
if 用户要求抢章或不经决议更换法定代表人对抗第三人 → 整体停止。  
if 职工董事或法定职工安排被要求随意取消 → 该步骤停止。  
if 任期未满罢免门槛未核验 → 改选有效性字段停止。  
计划不是已完成改选或已完成银行预留印鉴变更的证明。
