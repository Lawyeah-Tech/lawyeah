# 当前能力地图

本包包含下表全部原子技能。未列入的 P2 必须输出 `unavailable`，不得由名称相近的 Skill 代做。

## P0

| 用户当前目标 | 原子 Skill | 独立成果 | 不包含 |
| --- | --- | --- | --- |
| 拟投、拟买、拟卖或拟重组，要先定路径和监管闸 | `评估投资并购交易结构` | 路径比较、主体、控制权、监管红旗、关键条件和下一步 | SPA、交割包、集中申报 |
| 已定或拟定路径，先定尽调范围和资料清单 | `规划法律尽调范围与红旗` | 范围、清单、红旗类别、专项转出 | 尽调报告终稿 |
| 已收材料，要可决策的法律尽调报告 | `形成法律尽调报告` | 分模块发现、影响分级、条件／价格／披露接口 | 把缺失写成清洁 |
| 要把结构、对价、条件写成条款清单或意向书 | `准备投资并购条款清单` | 发送前条款清单、拘束力分账 | SPA；非约束力=零责任 |
| 已定股权路径，要发送前股权收购协议 | `准备股权收购协议` | 发送前 SPA、条件、R&W、赔偿接口 | 小微无争议转让包；已签署 |
| 收到对方交易文件，要问题清单和改法 | `审查对方交易文件` | 严重度分级问题单、接受／改写／退出 | 己方首稿 |
| 要可复核的基础价、净债务、营运资金或锁箱／交割账数字 | `测算交易对价与调整` | 分项测算、情景区间、互斥 | 唯一必得总价；对赌效力终局 |
| 条件将闭合，要交割清单和交割文件 | `准备交割文件包` | 条件表、文件、资金流向、名册登记印章 | 代提交；登记=权属终局 |
| 已支持发出交易终止，要发送前稿 | `准备交易终止通知` | 发送前终止通知、到达、异议应对 | 把发送写成已终止 |
| 交割后发现违反陈述、价格调整或对赌，先判断能否主张 | `评估投后赔偿与或有对价请求` | 请求矩阵、篮子／上限／期限、下一步 | 发送版索赔通知 |

| 债权人在通知期内要求清偿或担保 | `应对合并分立债权人清偿或担保请求` | 请求是否成立、清偿／担保选项、对进程影响 | 重判路径；一般催收 |
| 必须或选择产权交易所挂牌 | `评估产权交易所挂牌路径` | 挂牌条件、信息披露、优先权与摘牌接口 | 代挂牌；国资批准本身 |
| 对外转股或增资的优先购买、同意和章程限制 | `评估优先购买权同意权与章程限制` | 通知四要素、期间、章程另有规定、是否闭合 | 旧法第 71 条默认；C 端小微 |
| 交易依赖特许或牌照能否随转 | `评估交割前后许可资质承继` | 许可清单、可否承继、先批后交割红旗 | 行业申报正文；环境许可 |
| 交割前要显名、还原或解除代持 | `评估交易中的代持清理` | 清理路径、其他股东同意、登记对抗风险 | 权属终局；C 端 034 |
