# 投资并购领域边界

本表只说明归属。当前安装包是。每次路由先核对 [当前能力地图](capability-map.md)；未安装入口（含全部 P2）输出 `unavailable`。

| 相邻 | 本包入口 | 转出 |
| --- | --- | --- |
| 合同审查与起草 | 投资并购交易文件、交割和投后安排 | 一般买卖服务合作的签前审查起草（本窗搁置，只说明不实施） |
| 公司治理与股权 | 交易必需的决议、名册、印鉴交接接口 | 日常章程运行、股东会董事会、一般股东争议 |
| 竞争法与反垄断 | 只识别经营者集中红旗 | 经营者集中申报、竞争限制专项判断 |
| 金融借贷担保 | 交易对价和交割资金流向 | 贷款、保证、抵押质押、保理、融资租赁主轴 |
| 劳动 | 交易结构、交割统筹 | 劳动尽调、员工转移和人员安置 |
| 环境能源 | 交易执行 | 能源资源权利和环境监管专项尽调 |
| 涉外 | 境内交易主体工作 | 跨法域准入、境外法、ODI、制裁 |
| 税务 | 交易结构中的税负红旗 | 税负测算、申报、稽查和税务争议 |
| 破产 | 程序外普通投资并购 | 破产、重整、清算程序内投资 |
| 合同争议 | 仍服务交易完成或投后契约履行 | 已脱离交易完成目标的普通诉讼仲裁 |
| C 端股权转让／代持／创业股权／供应商尽调 | 专业并购成果 | 大众专项，只分流不回改 |
