# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变是否触安全审查红旗或应停止交割结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

安全审查与经营者集中是不同闸。本任务主成果只能是红旗和停止交割提示，不能写成申报书。范围条文未核验时只保留红旗，不写“不必申报”。

---

## P# 红旗矩阵

固定列：`编号｜敏感线索｜控制权变化｜可能申报义务人｜对交割影响｜与集中申报关系｜支持事实｜不利事实｜判断｜待核`。

军工、农产品、能源资源、重大装备、基础设施、运输服务、信息技术和互联网、金融、文化、数据分列线索，不得用“普通制造业”一句话排除全部。

---

## 节点 0　专项分流

1. 主成果是安全审查申报表或代理申报 → 不实施。
2. 主成果是经营者集中申报 → 竞争法；本任务只可在缺口提一句交叉。
3. 主成果是制裁、出口管制 → 涉外。

## 节点 1　控制权

1. 股权、表决权、董事会席位、协议控制、经营权均可能构成实际控制。
2. 未取得控制但取得重要影响力：仍标待核，不得写成绝对不触发。

## 节点 2　敏感领域

1. 按现行安全审查范围核对行业、产品、设施和数据。
2. 重要数据、关键信息基础设施、军工配套即使收入占比低也可能触审。
3. 范围未核验：红旗保留，结论字段停止。

## 节点 3　申报与停止实施

1. 可能触审：交割条件写“完成安全审查或确认不属于审查范围”，不得写可以先交割后补审，除非现行规则明确允许且已核验。
2. 申报主体、申报时机、工作机制只标待核。

## 节点 4　与集中申报互斥主成果

1. 两闸可能并行。本任务不计算营业额、不写竞争分析。
2. 用户只要一份“反垄断+安审”申报包：拆分并转出集中申报。

## 节点 5　下一步

1. 准入清单问题转外资准入原子。
2. 申报正文：`unavailable` 或不实施。

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 看起来不像军工 | 不必安全审查 |
| 营业额很小 | 安全审查与集中申报都不触发 |
| 双方愿先交割 | 可以先交割后补审 |
| 本任务红旗表 | 已经完成申报 |

---

## 条件句

if 存在重要数据、关键设施或军工配套线索 → 必须保留红旗，不得排除
if 范围条文未核验 → “不必申报”不得输出
if 主成果是集中申报 → 负触发，转竞争法
if 用户要求在触审可能下强行交割 → 整体停止

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 安全审查看控制权和敏感领域，不是只看营业额。 |
| 2 | 与经营者集中申报互斥主成果，可并行红旗。 |
| 3 | 未核验范围不得写不必申报。 |
| 4 | 不代申报、不编造工作机制内部时限。 |

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按敏感领域、控制权、停止交割、申报主体排序。申报正文不在本包。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

本成果不是安全审查申报书。
