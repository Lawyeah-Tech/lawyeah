# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变排除是否闭合或补披露风险结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

披露函评估看是否闭合，不重写 SPA，也不制作卖方披露表。资料室存在某文件不等于已披露，除非约定如此且能回链。

---

## Q# 对照矩阵

固定列：`编号｜R&W｜披露条目｜附件／索引｜是否特定｜排除判断｜补披露风险｜最强反方`。

不得把整份资料室写成一条已闭合披露。

---

## 节点 0　分流

1. 制作披露附件 → `准备披露函与披露附件`。
2. R&W 条款设计 → `准备陈述保证与披露附件`。
3. 整份 SPA → 股权或资产协议原子。

## 节点 1　版本

1. 签署版、更新版、交割补披露分列。

## 节点 2　对照

1. 特定披露必须能让合理买方理解例外范围。
2. 仅文件夹名称通常不足。

## 节点 3　效力

1. 约定排除 vs 欺诈／故意／权利瑕疵法定限制分列。
2. 未核验不得写“披露了就绝对免责”。

## 节点 4　补披露

1. 允许补披露的，买方救济必须可见。
2. 卖方不得把补披露写成已经消灭买方终止权，除非条文如此且已核验。

## 节点 5　下一步

1. 投后请求转赔偿评估原子，不在本任务发通知。

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 资料室有这份合同 | 对应 R&W 已被排除 |
| 披露函很厚 | 全部 R&W 已闭合 |
| 本任务对照表 | SPA 已经重写 |
| 补披露发出 | 买方终止权已消灭 |

---

## 条件句

if 没有 R&W 文本 → 排除效力字段停止
if 用户要用含混一句覆盖已知造假 → 整体停止
if 主成果是整份 SPA → 负触发
if 主成果是卖方披露表制作 → 转准备原子

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 资料室投放不等于披露，除非约定且可回链。 |
| 2 | 欺诈或故意不披露待核，不得写成已排除。 |
| 3 | 不重写整份 SPA。 |
| 4 | 补披露不自动消灭买方救济。 |

---

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按故意隐瞒、对照缺口、补披露窗口排序。SPA、披露表制作、索赔通知只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

本成果不是披露函终稿，也不是索赔通知。
