# 起草方法

本文件是可执行判断节点，不是栏目说明书。每个会改变排他范围、期限或违反后果结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

排他不是已经获得独占。上市公司卖方可能有信义义务出口，本包 P2 未安装则该字段 `unavailable`，不得凭记忆写可以无出口锁死董事会。

---

## Q# 条款块矩阵

固定列：`编号｜义务｜覆盖主体｜例外｜期限｜后果｜上市接口｜状态`。

排他与冻结分列。不得写成已生效。

---

## 节点 0　分流

1. 整份 TS → `准备投资并购条款清单`。
2. 去商店／信义出口 → P2 `unavailable`。
3. 拘束力评估 → 评估原子。

## 节点 1　范围

1. 卖方集团、财务顾问、实际控制人是否覆盖必须写明。

## 节点 2　冻结

1. 处分股权、资产、分红、关联交易。
2. 依法必须的披露、进场或监管要求列为例外。

## 节点 3　后果

1. 约定违约金或分手费转评估原子接口。
2. 不写法院必支持数额。

## 节点 4　上市

1. 信义义务出口未核验则字段停止或 `unavailable`。

## 节点 5　安全

1. 未签署不得对外宣称已锁定。

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 发出排他稿 | 已经锁定 |
| 上市公司卖方 | 可以无出口锁死董事会 |
| 整份 TS | 本任务主成果 |
| 法定进场 | 排他可以改写进场规则 |

---

## 条件句

if 上市信义出口是主成果 → P2 unavailable
if 用户要用未签文本阻击第三方 → 整体停止
if 法定进场与排他冲突 → 法定进场优先，排他不得改写
if 主成果是整份 TS → 负触发

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 草案不得写成已锁定。 |
| 2 | 法定进场和强制披露不得用排他改写。 |

| 4 | 后果金额不写必得。 |

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按未成立却对外宣称、法定程序冲突、上市出口排序。TS、拘束力评估、P2、分手费只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

文本状态保持待签署。
