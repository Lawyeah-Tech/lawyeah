# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变口径、调整或是否成就结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

成就评估看口径和证据，不代替审计，不重写对赌效力，除非公司作为义务人需要闸口。

---

## Q# 指标矩阵

固定列：`编号｜指标｜条款口径｜卖方数｜买方数｜调整项｜判断｜待核`。

多指标分别判断，不得合成“差不多完成”。

---

## 节点 0　分流

1. 效力／资本维持 → `评估或有对价与对赌`。
2. 行权通知 → 行权原子。
3. 审计报告 → 不实施。

## 节点 1　口径

1. 会计政策锁定。一次性收益是否计入必须回链。

## 节点 2　操纵红旗

1. 交割后压费用或提前确认收入标红旗，不写已构成犯罪。

## 节点 3　判断

1. 三种判断语。数字给区间或待核。

## 节点 4　专家

1. 条款中的会计师程序优先于另行诉讼，待核。

## 节点 5　安全

1. 禁止指导做假账。

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 卖方说完成了 | 已经成就 |
| 本任务判断 | 审计已经完成 |
| 效力没评 | 必须先出当然有效结论 |
| 利润分配争议 | 本任务主成果 |

---

## 条件句

if 要代做审计 → 负触发
if 指导假账 → 整体停止
if 数据两套且无条款优先级 → 判断依据不足
if 主成果是行权通知 → 负触发

---

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 不代做审计。 |
| 2 | 条款沉默不编造口径。 |
| 3 | 未知不写零。 |
| 4 | 效力闸需要时另项。 |

---

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按假账、口径冲突、审计边界排序。审计、效力评估、行权通知只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

本成果不是审计报告。
---

## 补充条件句与停止

if 用户要求代编审计报告或指导提前确认收入 → 整体停止或不实施审计。  
if 两套账且条款未规定优先级 → 成就判断为依据不足。  
if 主成果是行权通知 → 负触发。  
if 对公司付款而资本维持未评 → 可履行性字段停止，口径比较可继续。  
条款沉默时不得编造一次性项目是否计入的口径。
