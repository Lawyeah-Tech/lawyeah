# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变义务主体、资本维持闸或期间结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

与目标公司对赌不得写成当然有效或当然无效。九民纪要不得代替对现行公司法资本维持和回购规则的核验。

---

## Q# 义务矩阵

固定列：`编号｜类型｜义务人｜权利人｜触发｜期间｜资本维持闸｜可履行性｜效力判断｜待核`。

现金补偿、股权回购、earnout 付款、估值调整分列。

---

## 节点 0　分流

1. 数字工作表 → `测算交易对价与调整`。
2. 业绩期结束争口径 → `评估或有对价是否成就`。

## 节点 1　主体

1. 股东之间通常较易支持但仍须核意思表示和条件。
2. 公司作为补偿或回购义务人必须单列闸。

## 节点 2　闸

1. 减资决议与公告、回购情形、利润可分配性。未核验不得写可强制公司付款。

## 节点 3　期间

1. 起算、届满、提前触发。日期冲突建并行情景。

## 节点 4　与赔偿互斥

1. 可能选用，不得直接相加为已确定应付。

## 节点 5　安全

1. 禁止抽逃。禁止把公司资金用于规避资本维持。

---

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 对公司对赌 | 当然无效 |
| 对公司对赌 | 当然有效 |
| 九民纪要一句话 | 现行唯一规则 |
| 测算未做 | 本任务已给出应付总额 |

---

## 条件句

if 用户要当然有效或当然无效的口号 → 拒绝该表述，改为分列效力与可履行
if 抽逃式安排 → 整体停止
if 主成果是数字表 → 负触发
if 主成果是业绩是否达成 → 转业绩评估

---

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 不把与公司对赌写成当然有效或当然无效。 |
| 2 | 资本维持和回购闸必须单独判断。 |
| 3 | 不代替测算或审计。 |
| 4 | 不用口诀代替现行核验。 |

---

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按抽逃、公司义务闸、期间、与赔偿互斥排序。测算、业绩成就、行权通知只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

本成果不是应付总额，也不是当然有效意见。
