# 报告方法

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。禁止“未发现即不存在”。禁止把卖方口头否认写成已核实无诉讼。

失效合同法、旧公司法第 71 条默认程序、失效公司登记管理条例不得写入 `L#`。

---

## 节点 0　分流与报告资格

if 没有可引用的文件、公示或可核对陈述 → 不得出报告终稿，转规划原子。  
if 主成果是劳动／环境／税专项 → 整段转出。  
if 用户要求删除已看到的不利事实 → 整体停止。

---

## 节点 1　范围与限制

1. 写资料截止日。截止日后事件一律 `无法核实`。
2. 列出已打开的文件夹／文件号和未提供清单。未提供 ≠ 不存在。
3. 依赖管理层问卷时，问卷答案标 `S#`，不得升为 `D#`。
4. 登记公示与内部名册、章程冲突时并列，不选对买方有利的一版。

---

## 节点 2　分模块发现

每条 `F#` 固定列：模块｜事实｜来源｜与交易路径的关系｜支持继续的事实｜不利事实｜判断｜影响级｜待核。

必写模块：公司存续与机关、股权权属与负担、出资（认缴／实缴／期限／第 88 条时点）、重大合同 CoC／终止、许可、诉讼处罚、关联交易。劳动、环境、税仅摘交易相关事实并转出。

出资：
- if 转让发生在 2024-07-01 后且为未届期出资 → 适用第 88 条第一款框架：受让人缴纳，转让人补充责任；规则未核验则字段停止。
- if 转让发生在 2024-07-01 前 → 不得直接套用第 88 条第一款（法释〔2024〕15 号），判断标待核。
- 瑕疵出资适用第 88 条第二款时，受让人善意抗辩必须单列。

权属：质押、冻结、查封、代持、一股二卖分列。未变更登记不得写成无权属风险；亦不得写成登记完成即无争议。

---

## 节点 3　影响分级

| 级 | 进入条件 | 禁止 |
| --- | --- | --- |
| 否决 | 许可无法迁转且路径依赖该许可；权属无法建立；法定禁止转让未解除 | 把可补救瑕疵写成否决 |
| 价格 | 可用留扣、调价或或有对价吸收 | 编造调整额 |
| 条件 | 可用交割条件或先批后交 | 写成已经满足 |
| 披露 | 可用披露排除 R&W | 写成已经排除 |

同一诉讼既可能是价格也可能是条件，两条都写，不合成“有风险”。

---

## 节点 4　接口，不出稿

把否决项映射为停买或路径重选；价格项映射测算原子；条件项映射交割包；披露项映射 R&W／披露函。本任务不起草 SPA 条款正文，不写终止通知。

经营者集中、融资、劳动安置只保留红旗一句并转出。

---

## 节点 5　反方与安全

每条否决或价格级发现必须写卖方最强解释。禁止指导伪造清洁函、补造已签署的优先购买放弃或隐匿诉讼。
