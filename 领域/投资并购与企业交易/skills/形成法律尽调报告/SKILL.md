# 形成法律尽调报告

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“法律尽调报告”：范围与限制、分模块发现、交易影响分级、条件／价格／披露接口、最强反方和缺口。

`depends-on` 为空。接受用户提供的资料室、清单或口头补充。本任务**不把缺失写成清洁**，不认定交易应当成交。

## 工作边界

正触发：已收到全部或部分交易资料，单方需要可决策的法律尽调发现和影响分级。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 还没有材料，只要范围和清单；
- 只要劳动、环境或税务专项报告；
- 只要 SPA 或交割包；
- 卖方只要组织资料室；
- 一般合同审查起草（本窗搁置）。

## 建立报告坐标

确认：使用者与授权；单方立场；路径；资料截止日；已查／未查模块；已知卖方披露；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 资料室文件表面；`A#` 卖方确认；`R#` 公示或机关文书；`C#` 章程合同条款；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`F#` 发现；`V#` 报告版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。发现状态只用 `已核实`、`部分核实`、`无法核实`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验出资、股权负担、对外转让、许可存续；`search_practiced` 补影响分级反例。工具不可用时继续事实摘录，法律定性字段停止。

## 五个判断节点

执行顺序和停止条件以 [报告方法](references/method.md) 为准。

### 1. 范围、截止日和限制

写明看过什么、没看什么、依赖谁的陈述。未查模块不得给清洁意见。

### 2. 分模块发现

每条 `F#` 回链文件。冲突并列。

### 3. 交易影响分级

否决／价格／条件／披露。同一事实可多级，但金额不得重复计算为已确定调整。

### 4. 接口

价格、交割条件、R&W、披露函。不写 SPA 正文。

### 5. 反方、缺口和下一步

卖方最强解释必须可见。下一步转介出稿或停买，不在本任务发终止通知。

## 停止与安全

- `整体停止`：立场冲突；用户要求删除已知不利发现或伪造清洁函。
- `字段停止`：规则、登记或许可效力未核验。
- `目标停止`：主目标变为出 SPA 或只要范围规划。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。边界见 [路由](references/routing.md)。
