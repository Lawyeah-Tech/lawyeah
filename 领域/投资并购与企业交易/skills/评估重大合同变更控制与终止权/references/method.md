# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变CoC、同意或终止风险结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

重大合同评估不是合同审查起草生产线。不得改写客户或供应商合同作为本任务主成果。未看到文本不得写成无 CoC。

---

## Q# 合同影响矩阵

固定列：`编号｜合同｜相对方｜到期｜CoC／转让限制｜同意｜终止权｜交易影响｜判断｜待核`。

收入前十大、独家、许可、融资、租赁分列。融资主轴整行转金融。

---

## 节点 0　分流

1. 一般签前审查起草 → 本窗搁置。
2. 贷款担保本身 → 金融。
3. 劳动合同 → 劳动。

## 节点 1　清单

1. 缺失文本标缺口，不得用管理层口述代替条款。

## 节点 2　CoC

1. 看控制权定义是否含股权变化、董事会变化、资产出售。
2. “不得转让本合同”不等于无 CoC，也不等于有 CoC，必须读条文。

## 节点 3　同意

1. 同意是否可不合理拒绝、时限、默示同意待核。
2. 不得指导倒签同意函。

## 节点 4　终止

1. 已发生违约是否已触发终止或加速。
2. 交割后整合可能构成违约的条款标红旗。

## 节点 5　下一步

1. 否决级转红旗原子。需要改那些合同：标明审查起草搁置或由对方改稿谈判。

---

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 没给合同 | 没有 CoC 风险 |
| 股权收购 | 资产合同当然不受影响 |
| 本任务清单 | 已经重写了那些合同 |
| 融资合同主轴 | 本任务终局 |

---

## 条件句

if 用户要重写客户合同 → 负触发，审查起草搁置
if 关键合同文本缺失 → CoC 结论字段停止
if 融资文件是主成果 → 转金融
if 伪造同意 → 整体停止

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 未见文本不得写无 CoC。 |
| 2 | 一般合同审查起草本窗搁置。 |
| 3 | 融资、劳动主轴转出。 |
| 4 | 不得倒签对方同意。 |

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按关键合同缺失、已触发终止、同意不可得排序。重写合同、完整报告、融资文件只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

本成果不是那些合同的修订稿。
