# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变合并类型、债权人程序或债务承继结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

运行时核验公司法现行合并分立条文后再落程序判断。核验失败则法律效果字段停止，类型比较继续。简易合并（持股百分之九十以上）不得凭记忆写成程序已豁免。

---

## P# 合并分立矩阵

固定列：`编号｜类型｜存续／新设主体｜决议闸｜债权人程序｜债务效果｜登记｜集中申报红旗｜判断｜待核`。

吸收与新设、派生与新设分立必须分开。不得写成“重组已经生效”。

---

## 节点 0　专项分流

1. 破产、重整、清算程序内 → 破产领域。
2. 主成果是合并协议、通知公告稿 → `准备合并分立实施文件与债权人通知`。
3. 主成果是集中申报 → 竞争法。
4. 主成果是日常减资 → 公司治理。

## 节点 1　类型

1. 吸收合并：一方存续。新设合并：各方解散、新公司设立。
2. 分立后债务承担约定不得对抗债权人，除非债权人同意。
3. 三角合并、跨境合并未核验则字段停止，跨境整案转涉外。

## 节点 2　决议与债权人

1. 合并分立通常属股东会特别决议事项，章程更高比例从其规定。
2. 通知已知债权人和公告程序必须设计，不得用“没有大债权人”省略。
3. 债权人请求清偿或担保的应对转 `应对合并分立债权人清偿或担保请求`。

## 节点 3　简易合并待核

1. 持股百分之九十以上公司合并的简化程序必须运行时核验。
2. 未核验不得写“子公司合并不必通知债权人或不必决议”。
3. 少数股东收购请求权只标接口。

## 节点 4　登记与集中

1. 登记完成前主体资格变化不得对第三人主张已经完成。
2. 控制权集中红旗转竞争法，本任务不写申报。

## 节点 5　下一步

1. 路径闭合后转实施文件原子。
2. 国资合并另核国资原子。

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 双方同意合并 | 债权人程序已经可以省略 |
| 母公司持有子公司全部股权 | 简易合并程序已自动豁免 |
| 签了重组意向 | 合并已经生效 |
| 破产管理人在谈投资 | 本任务可代替破产重整 |

---

## 条件句

if 路径未在吸收／新设／分立之间闭合 → 不得转实施文件原子出终稿
if 公司法条文未核验 → 通知期限、决议比例、简易合并字段停止
if 用户要求不通知债权人 → 整体停止
if 程序在破产内 → 负触发，转破产

---

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 合并各方的债权债务由合并后存续或新设公司承继。 |
| 2 | 分立后债务分担约定原则上不能对抗债权人。 |
| 3 | 债权人通知与公告是程序闸，不是可选公关。 |
| 4 | 简易合并效力待核，禁止凭记忆豁免。 |

---

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按类型未定、债权人程序、决议、集中申报、登记排序。实施文件、债权人应对、破产、集中申报只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

本成果不是合并协议、公告或登记申请。
