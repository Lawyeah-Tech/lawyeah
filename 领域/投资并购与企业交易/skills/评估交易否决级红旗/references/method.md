# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变四级分流或停止交易建议的依据结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

四级是分流不是情绪。不得输出成交率。未知损失不写零。不得把完整报告压缩成本任务唯一成果。

---

## P# 红旗分流矩阵

固定列：`编号｜红旗｜事实依据｜强制规范待核｜四级｜可逆性｜支持调价／条件的接口｜判断`。

否决、价格、条件、披露必须单选主位，可并列备位。

---

## 节点 0　分流

1. 完整报告 → 报告原子。
2. 发终止 → `准备交易终止通知`，须先评估能否走。
3. 能否走 → `评估交割失败与退出交易`。

## 节点 1　否决级

1. 法律上不能实施、权属无法建立、关键许可确定灭失且不可补。
2. 依据不足时标依据不足，不装否决。

## 节点 2　价格／条件

1. 可量化或可隔离的风险。数字转测算原子。

## 节点 3　披露

1. 仅当不阻碍合法交割且买方知情后仍可决策。

## 节点 4　禁止降级

1. 伪造、行贿、规避监管不得写成披露级。

## 节点 5　下一步

1. 停买后的终止权评估另项，本任务不发通知。

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 有一些尽调问题 | 必须停买 |
| 卖方愿意披露 | 否决级已消除 |
| 本任务四级表 | 尽调报告已经完成 |
| 想停买 | 终止通知已经可发 |

---

## 条件句

if 红旗事实未建立 → 不得输出否决终局
if 用户要把违法行为降成披露 → 整体停止
if 只要报告 → 负触发
if 只要终止通知且终止权未评估 → 转评估或通知原子

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按违法实施、权属灭失、许可灭失、可隔离风险排序。报告、测算、终止通知只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

本成果不是终止通知，也不是完整报告。
