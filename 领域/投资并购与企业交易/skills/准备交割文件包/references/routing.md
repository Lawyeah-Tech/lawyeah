# 边界与路由

## 正触发

条件将闭合或已签约待交割，需要交割清单、资金流向和交接文件。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 起草 SPA | `准备股权收购协议` |
| 判断能否终止或退出 | `评估交割失败与退出交易`（未安装则 `unavailable`），不得转终止通知 |
| 经营者集中申报 | 竞争法领域 |
| 小微无争议变更材料 | C 端股权转让协议与变更准备 |
| 融资放款文件 | 金融领域 |

## 易混

“先交割再补批准”且批准是法定前置时负触发并停止。只要判断能否终止或退出时负触发，不得进入终止通知。材料待核但仍要交割准备时正触发，状态为部分形成。
