# 交割方法

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。条件状态：`已满足`、`未满足`、`放弃待授权`、`依据不足`。不得把登记完成写成权属终局。不得引用已失效《公司登记管理条例》。不得撰写经营者集中申报。

运行时核验公司法第 34、86 条及市场主体登记规则。核验失败则期限和书式字段停止，清单继续。

---

## 节点 0　交割闸

if 法定或约定的强制性先批条件未满足（国资批准、外资不准入、集中申报未完成且条款要求完成）→ 不得输出“可以交割”确认，只输出缺口和停止。  
if 用户要求先交割再补法定批准 → 整体停止该确认，不提供规避步骤。  
if 主成果是申报本身 → 转竞争法或对应监管领域。

---

## 节点 1　条件矩阵

每条 `CP#`：条款定位｜义务方｜证据｜状态｜放弃权人｜交割影响。  
口头“都办好了”不得写成 `已满足`。放弃必须有授权人；无权放弃的法定条件不能标放弃。集中申报条款：本包只写“未完成则不得交割，专项转竞争法”。

---

## 节点 2　文件与资金

1. 文件按交割桌分组：生效文本、批准、辞任／任命、名册、印鉴、银行、交接备忘。缺失标 `G#`。
2. 资金流向：付款人、账户、币种、时点、提存或留扣、失败回退。账户与签约主体不一致不自动合并。
3. 同时履行：付款、文件、印鉴应能互锁。禁止“先全额付款再谈交印鉴”而不写违约与资金保全。
4. 禁止阴阳价、拆分账户逃税或为不明第三方付款。

---

## 节点 3　名册与登记

1. 书面通知公司变更股东名册。受让人自记载于股东名册时起可向公司主张股东权利。
2. 需要办理变更登记的，请求公司向登记机关申请。未经变更登记不得对抗善意相对人。
3. 申请期限、书式、份数、是否必须决议：运行时核验现行登记规则和当地指南，全部标待核。不得把失效条例的三十日条款不经核验写成已核实期限。
4. C 端小微无争议材料包不在本任务实施。

---

## 节点 4　印章与控制

交接清单：公章、财务章、合同章、发票章、证照、U 盾、账册、域名和系统管理员。监交人和现场照片／签收预列。禁止指导抢章、更换印鉴而不作交接记录。

---

## 节点 5　备忘与安全

交割备忘只确认当日互交和保留项，不得把未完成登记写成已完成。下一步可转登记原子（未安装则 `unavailable`）或投后跟踪。
