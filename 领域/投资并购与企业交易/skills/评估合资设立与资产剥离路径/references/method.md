# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变合资、剥离或交割顺序结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

合资与剥离是路径参数，不是行业模板。资产范围未闭合前不得出可签署合资或剥离协议终稿。人员安置不是本任务主成果。

---

## P# 路径矩阵

固定列：`编号｜路径｜注入／剥离标的｜债务处理｜许可／合同｜人员接口｜顺序｜支持事实｜不利事实｜判断｜待核`。

`P-新设` `P-增资合资` `P-剥后股` `P-剥后资` 分列。两步走必须写中间主体和失败回退。

---

## 节点 0　专项分流

1. 员工转移、经济补偿、集体协商 → 劳动领域。
2. 土地使用权、在建工程、施工合同主轴 → 房地产或建设工程领域。
3. 破产重整投资 → 破产领域。
4. 一般买卖合同审查起草 → 本窗搁置。

## 节点 1　路径

1. 新设合资：出资形式、评估、缴付期限、控制权安排分列。
2. 剥离：是营业转让、资产买卖还是分立，法律效果不同，不得混称“剥离”。
3. 分立路径转合并分立原子，本任务只比较是否应改走分立。

## 节点 2　范围

1. 资产清单、排除负债、或有负债、担保释放分列。
2. 不得写成“项目相关的都走”。
3. 合同转让需对方同意；许可可能需重新申请。

## 节点 3　顺序

1. 先设立后注资、先剥离后卖股、同一交割日同步，必须写失败回退。
2. 中间日谁承担经营损益和事故责任必须可见。
3. 不得把尚未完成的剥离写成已可对第三方主张。

## 节点 4　人员与监管

1. 人员只列是否随业务走的接口，方案转劳动。
2. 外资合资另核准入原子。国资剥离另核国资原子。

## 节点 5　下一步

1. 资产协议转 `准备资产收购协议`。
2. 合并分立转相应原子。许可承继转许可原子。

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 买方要团队和客户 | 必须做股权收购且债务自动留下 |
| 口头说剥离完成 | 债务和许可已经切割 |
| 设立合资公司 | 员工已自动转入合资公司 |
| 房地产项目公司 | 本任务可代替房地产权属专项 |

---

## 条件句

if 劳动转移是主成果 → 负触发，转劳动
if 剥离范围未列出资产和排除负债 → 路径可比较，主位标依据不足
if 许可不能随转且交易依赖许可 → 先批后交割红旗
if 用户要把债务留在空壳坑债权人 → 整体停止

---

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 债务转移须债权人同意；不得写成随资产自动走。 |
| 2 | 合同和许可需逐项转让或重申，不随合资自动承继。 |
| 3 | 人员安置转劳动，本任务只留接口。 |
| 4 | 房地产或工程主轴转出。 |

---

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按范围不明、债务未切割、许可、顺序失败回退排序。劳动、房地产、资产协议、分立只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

本成果不是合资合同终稿、资产清单公证或安置方案。
