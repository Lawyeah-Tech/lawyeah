# 起草方法

本文件是可执行判断节点，不是栏目说明书。每个会改变R&W 范围、限定或附件结构结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

R&W 模块可独立谈判，但不能代替主协议交割和价格条款。卖方完成披露表另项。

---

## Q# R&W 矩阵

固定列：`编号｜主题｜买方要｜卖方抗｜知识／重大性｜附件号｜生存期接口｜状态`。

不得用一条“不存在任何风险”覆盖全部。

---

## 节点 0　分流

1. 整份 SPA → 股权或资产协议原子。
2. 评估已出披露函 → `评估披露函是否闭合陈述保证`。
3. 卖方填表 → `准备披露函与披露附件`。

## 节点 1　清单

1. 按路径增减：资产交易加重权属交付；增资加重出资用途。

## 节点 2　限定

1. 知识主体必须点名。
2. 重大性定量或定性待核，不编市场惯例百分比冒充法律。

## 节点 3　附件

1. 只建结构与索引规则。

## 节点 4　劳动环境税

1. 只留接口，不写专项保证终局。

## 节点 5　安全

1. 禁止设计与已知事实相反的保证。

---

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| R&W 清单 | SPA 已经齐 |
| 资料室在 | 披露附件已经完成 |
| 市场惯例百分之十篮子 | 法律强制 |
| 已出披露函要评估 | 本任务主成果 |

---

## 条件句

if 主成果是整份 SPA → 负触发
if 已知虚假仍作出保证 → 整体停止
if 评估已出披露函 → 负触发
if 卖方要填完表 → 转披露表原子

---

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 不代替整份 SPA。 |
| 2 | 知识限定必须点名主体。 |
| 3 | 不编造惯例百分比当法律。 |
| 4 | 不填完卖方披露内容。 |

---

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按虚假保证、路径不匹配、专项接口排序。SPA、披露评估、卖方填表只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

文本状态保持待纳入主协议。
