# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变条款拘束力或本约是否成立结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

不得把无拘束力标题写成全部条款零责任。不得把已列主要条款的意向书未经分析写成已成立股权转让本约。失效合同法不得写入 L#。

---

## Q# 条款分账矩阵

固定列：`编号｜条款｜文本用语｜是否单独签署／履行｜预约／本约／无拘束判断｜责任接口｜待核`。

保密、排他、费用、锁定期、交易主要条款必须分行。

---

## 节点 0　分流

1. 重写 TS → `准备投资并购条款清单`。
2. 出发送 SPA → 相应起草原子。

## 节点 1　文本

1. 整份声明 vs 个别条款保留拘束力。冲突并列。

## 节点 2　本约

1. 标的、数量、价款、履行是否确定。
2. 已过户、已付款、已改名册是履行事实，可能影响成立判断，但不自动等于本约。

## 节点 3　预约

1. 须诚信磋商、在约定期间谈本约。违反可能承担预约违约或缔约过失，二者分列待核。

## 节点 4　金额

1. 分手费、费用承担只标接口，转分手费原子或测算。

## 节点 5　下一步

1. 已支持发出终止 → 终止通知原子。

---

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 写了非约束力 | 全部条款零责任 |
| 主要条款都写了 | 本约已经成立 |
| 本任务分账 | TS 已经重写 |
| 想签 SPA | 本任务可出发送前 SPA |

---

## 条件句

if 文本与签署事实冲突 → 成立字段停止或并行情景
if 用户要倒签已成立本约 → 整体停止
if 主成果是重写 TS → 负触发
if 主成果是 SPA → 负触发

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 标题无拘束力不覆盖全部条款。 |
| 2 | 无拘束力不是零责任。 |
| 3 | 本约成立须单独判断。 |
| 4 | 不用失效合同法。 |

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按伪造签署、本约争议、预约期间、排他违反排序。重写 TS、出 SPA、终止通知只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

本成果不是 TS 修订稿或本约。
