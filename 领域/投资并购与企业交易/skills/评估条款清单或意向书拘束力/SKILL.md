# 评估条款清单或意向书拘束力

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“条款清单拘束力分账”：条款分账、预约责任、本约是否已成立

`depends-on` 为空。接受用户、律师、财务顾问或其他来源的等价事实、估值、清单和文本。本任务不把未核验规则写成已闭合结论。

## 工作边界

正触发：已签或拟签 TS／LOI，需判断预约／本约／无拘束。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 重写 TS；
- 已决出发送 SPA；
- 把无拘束力写成零责任而不评估诚信磋商；
- 一般合同审查起草（本窗搁置）；

本任务不重写 TS；已决出发送 SPA 走起草原子，不给成交率或胜诉率。

## 建立评估坐标

确认：使用者与授权；单方立场；TS／LOI 文本与签署事实；后续履行；是否已开始起草本约；法域；当前磋商、文本、审批或交割状态；关键材料及缺失。

同时掌握买卖双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 陈述；`D#` TS／往来；`C#` 拘束力条款；`L#` 已核验民法典；`I#` 判断；`Q#` 条款；`V#` 版本

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验预约合同、本约成立和缔约过失；不虚构审批系统、案号或登记回执。

工具不可用时继续文本分账和签署履行事实整理；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　分流

重写 TS 转条款清单原子。出 SPA 转协议原子。先固定文本版本和签署／履行事实。

### 节点 2　条款分账

排他、保密、费用、准据法、本约主要条款分列。标题“无法律约束力”不自动覆盖全部条款。

### 节点 3　预约与本约

主要条款是否已确定到可履行。已开始履行标红旗。依据不足不得写本约已成立或一定未成立。

### 节点 4　预约责任与缔约过失

无正当理由中断磋商、违反排他或保密的责任接口。不写必得金额。

### 节点 5　下一步

要改 TS 转准备原子。要出本约转 SPA／认购／资产协议。终止另项。

## 停止与安全

- `整体停止`：立场冲突；伪造签署页或倒签。
- `字段停止`：预约与本约界限、签署事实未核验。
- `目标停止`：主目标变为重写 TS 或出 SPA。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成、部分形成并明确受限字段、因停止条件未形成`。边界见 [路由](references/routing.md)。
