# 规划方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得把未提供的文件写成无风险，不得输出“标准尽调包已覆盖全部风险”。

`search_law` 返回失效合同法或旧公司法默认程序时记为噪声。

---

## 节点 0　专项分流

| 信号 | 转出 |
| --- | --- |
| 主成果是劳动负债、员工转移或安置 | 劳动领域 |
| 主成果是排污许可、矿权、环评 | 环境能源领域 |
| 主成果是税负或税务架构 | 税务领域 |
| 主成果是集中申报 | 竞争法领域 |
| 普通供应商准入，不是投资交易 | C 端供应商尽调清单 |
| 材料已齐只要报告 | `形成法律尽调报告` |

## 节点 1　路径假设决定模块

1. 固定单方立场。买方尽调与卖方组织资料室目标不同：本任务默认为调查方规划；卖方建室转卖方资料室原子（未安装则 `unavailable`，本任务只给出买方请求侧）。
2. 路径假设写入每个模块。
   - 股权／增资：公司存续、出资、股权负担、重大合同 CoC、许可是否因控制权变化而撤销。
   - 资产：权属、抵押、资产能否单独转让、合同需否对方同意、许可能否迁转。
   - 合并：债权人通知、债务承继、简易合并条件待核。
3. 路径未定：并列两套模块，标互斥，不合并成一份“通用尽调”。

---

## 节点 2　模块与必查门槛

默认模块：`M-公司` `M-权属负担` `M-出资` `M-重大合同` `M-许可` `M-诉讼处罚` `M-关联` `M-不动产接口` `M-知识产权接口` `M-数据接口` `M-劳动接口` `M-环境接口` `M-税务接口`。

if 模块会改变是否买、价格、条件或能否交割 → 必查。  
if 模块仅背景 → 标选查。  
if 模块属于他域专项方法 → 只留转出接口，不写专项检查表。

不得因“时间紧”删除权属、出资、诉讼和许可四个必查模块，除非用户书面限缩范围；限缩必须写入成果并标残缺。

---

## 节点 3　资料请求与合法边界

1. 每项请求写：目的、对应模块、控制方、格式、最晚时点。禁止“请提供全部公司文件”这种不可执行请求。
2. 个人信息、身份证影像、与交易无关的员工医疗或通讯记录：不列入，除非劳动接口且有合法必要性；否则停止该项。
3. 特权文件（律师意见、诉讼策略）单独列，标注不得强迫放弃特权。
4. 清洁团队：竞争敏感的客户单价、未来定价，仅在存在竞争者买方时启用；本任务不评估经营者集中，只避免资料室泄密。

## 节点 4　红旗四级

| 级 | 含义 | 不得写成 |
| --- | --- | --- |
| 否决 | 未经清除不得继续出价 | 口头否认=已清除 |
| 价格 | 应用对价或留扣吸收 | 已确定调整额 |
| 条件 | 应交割条件或先决批准 | 已经满足 |
| 披露 | 应用披露排除 R&W | 已经排除 |

“尚未提供”只能进缺口，不能进“无红旗”。卖方陈述无诉讼，在无检索和文书支持时判断为 `依据不足`。

## 节点 5　时间盒和下一步

按签署／交割时点倒排请求批次。下一步只转介报告、结构评估或出稿，不在本任务写发现章节。禁止指导黑客、收买员工或隐匿已知不利材料。
