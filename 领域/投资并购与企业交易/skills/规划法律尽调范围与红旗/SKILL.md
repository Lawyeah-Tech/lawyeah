# 规划法律尽调范围与红旗

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“法律尽调规划包”：交易路径假设、调查范围、资料请求、红旗类别、特权／清洁团队、专项转出和下一步。

`depends-on` 为空。接受用户或其他来源的等价结构评估。本任务不写尽调报告终稿，不把未收到的材料写成清洁。

## 工作边界

正触发：已定或拟定投资并购路径，单方需要先确定法律尽调范围、清单和红旗，而不是立即出具报告。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 材料已齐，只要尽调报告终稿；
- 只要劳动、环境、税务专项尽调成果；
- 普通供应商准入清单（C 端分流）；
- 只要 SPA、交割包或集中申报；
- 一般合同审查起草（本窗搁置）。

## 建立规划坐标

确认：使用者与授权；单方立场；路径假设（股权／资产／增资／合并）；行业；时间盒；资料室是否存在；已知红旗；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 已有清单或资料室；`A#` 双方已确认范围；`C#` 章程或意向书对尽调的约定；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`M#` 模块；`V#` 规划版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验与路径相关的权属、许可、对外转让和合并程序，用于决定模块是否必查；`search_practiced` 补常见遗漏模块。工具不可用时继续按路径建模块，监管结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [规划方法](references/method.md) 为准。

### 1. 分流、立场和路径假设

路径未定时可并列假设，但每个模块必须标明对应哪条路径。专项尽调整段转出。

### 2. 模块与重要性

公司、权属、重大合同、许可、诉讼、关联、劳动接口、数据接口分列。劳动、环境、税只留接口，不展开专项方法。

### 3. 资料请求与资料室规则

请求必须可执行。清洁团队、特权文件和禁止钓鱼式要无关个人数据。

### 4. 红旗分类

否决／价格／条件／披露四级。不得把“尚未提供”写成“无风险”。

### 5. 时间盒和下一步

按交割时点倒排。报告、出稿、专项转介分列。

## 停止与安全

- `整体停止`：立场冲突；用户要求违法调取个人信息、黑客进入资料室或隐匿已知红旗。
- `字段停止`：路径、行业许可清单未核验。
- `目标停止`：主目标已变为报告终稿或出 SPA。
