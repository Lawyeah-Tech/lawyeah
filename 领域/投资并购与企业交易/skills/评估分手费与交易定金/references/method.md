# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变定性、调整接口或与损害赔偿关系结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

名称叫分手费不等于法律定性。不得输出法院必支持的数字。未知已付金额不写零。

---

## Q# 定性矩阵

固定列：`编号｜用语｜付款事实｜触发｜可能定性｜调整接口｜与损害赔偿｜判断`。

买方分手费、卖方反向分手费、定金、订金、意向金分列。

---

## 节点 0　分流

1. 退出路径总图 → 退出评估原子。
2. 一般买卖定金诉讼 → 合同争议。

## 节点 1　定性

1. 定金须有定金意思；“订金”“意向金”不当然是定金。

## 节点 2　触发

1. 己方违约通常不能主张对方支付分手费。

## 节点 3　调整

1. 违约金过高过低调整只标接口，对照损失而非合同总价口诀。

## 节点 4　互斥

1. 定金罚则与损害赔偿择一主张待核。

## 节点 5　安全

1. 禁止把行贿或非法安排写成费用。

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 写了分手费 | 法院一定按该数支持 |
| 付过意向金 | 当然适用定金罚则 |
| 本任务评估 | 金额已经确定应付 |
| 融资承诺费 | 本任务终局 |

---

## 条件句

if 要必得数额 → 拒绝该输出
if 非法对价 → 整体停止
if 退出路径未问只要钱 → 可做本任务但须揭示路径依赖
if 一般定金诉讼无交易 → 转争议

---

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 不定法院必支持数额。 |
| 2 | 名称不等于定性。 |
| 3 | 定金与损害赔偿可能互斥。 |
| 4 | 调整只标接口。 |

---

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按非法对价、定性、互斥、调整排序。退出评估、索赔通知、一般定金诉讼只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

本成果不是给付判决。
---

## 补充条件句与停止

if 用户要求输出法院必支持的固定数额 → 拒绝该输出，只给定性与调整接口。  
if 名称为订金或意向金 → 不得直接适用定金罚则。  
if 己方违约却主张对方支付分手费 → 判断现有依据不支持，除非条款明确反向安排并已核验。  
if 付款具有行贿、抽逃或非法对价外观 → 整体停止。  
定金与损害赔偿可能互斥，两项都标待核时不输出相加总额。
