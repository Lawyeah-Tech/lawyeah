# 准备尽调资料清单与资料室规则

## 任务目标

在明确、无利益冲突的单方立场下，形成“买方尽调请求与资料室规则包”：资料请求、批次、保密／清洁团队规则

`depends-on` 为空。接受用户、律师、财务顾问或其他来源的等价事实、估值、清单和文本。本任务不把未核验规则写成已闭合结论。

## 工作边界

正触发：需向卖方发 RFI 或建买方资料室规则；买方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要卖方建室、脱敏和披露边界；
- 只要尽调报告终稿；
- 只要规划范围而不要请求清单；
- 一般 NDA 签前审查（审查起草领域，本窗搁置）；

本任务不代替卖方建室，不写尽调报告，不给成交率或胜诉率。

## 建立出稿坐标

确认：使用者与授权；单方立场；已定或拟定路径；行业；清洁团队需求；已有保密安排；法域；当前磋商、文本、审批或交割状态；关键材料及缺失。

同时掌握买卖双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 陈述；`D#` 已收清单／TS；`C#` 保密条款；`L#` 已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求项；`V#` 版本

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_practiced` 补资料室和清洁团队失败模式；法规只核验保密与特权边界；不虚构审批系统、案号或登记回执。

工具不可用时继续按路径和行业出受限请求清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [起草方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　分流和立场

卖方建室另项。尽调报告另项。范围规划已完成或等价提供即可。买方立场。

### 节点 2　请求与批次

公司、股权、合同、诉讼、许可、劳动／环境／税只留接口。批次按红旗优先，不得一次要“全部经营秘密”。

### 节点 3　保密与清洁团队

竞品买方必须设计清洁团队和信息隔离。不得指导套取依法不应获取的信息。

### 节点 4　特权与违法材料

律师特权、个人信息、国家秘密分列。要求对方违法提供则停止该项。

### 节点 5　发送闸

请求清单保持待发送。不把未提供写成对方已经违约，除非已有约束力条款支持。

## 停止与安全

- `整体停止`：立场冲突；要求对方提供国家秘密或违法获取个人信息。
- `字段停止`：特权范围、跨境传输、清洁团队规则未核验。
- `目标停止`：主目标变为卖方建室或尽调报告。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `草案、待发送、停止`。边界见 [路由](references/routing.md)。
