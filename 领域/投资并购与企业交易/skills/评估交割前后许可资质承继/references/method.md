# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变许可能否承继或须先批后交割结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

许可是交易可行性闸。不同许可对股权变更、实际控制人变更、资产转让的敏感度不同，禁止一套结论套全部证书。

---

## P# 许可矩阵

固定列：`编号｜许可｜发证机关｜有效期｜路径敏感点｜可否承继｜先批后交割｜对收入依赖｜判断｜待核`。

特许、普通许可、备案、人员执业资格分列。环境类整行转出。

---

## 节点 0　分流

1. 排污、环评、能源消耗、资源权利 → 环境能源。
2. 行业申报正文或代办 → 不实施。
3. 许可过期超范围的尽调发现主成果 → `评估许可合规尽调发现`。

## 节点 1　清单

1. 证书、附件范围、年报或检查记录、是否在有效期。
2. 缺失不得写成“没有许可问题”。

## 节点 2　承继

1. 股权收购：核实际控制人变更、主要人员变更是否触发重新核准。
2. 资产收购：通常需重新申请或合同转让，不得写自动承继。
3. 合并分立：承继规则按该许可领域待核。

## 节点 3　先批

1. 关键许可可能中断 → 交割条件或分步交割。
2. 过渡期无证经营风险必须明示，不得设计无证继续经营方案。

## 节点 4　人员绑定

1. 建造师、医师、驾驶员等人员资质随人走。劳动接口转劳动，不在本任务写用工方案。

## 节点 5　下一步

1. 尽调深度转许可尽调原子。结构影响转结构原子。

---

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 做股权收购 | 所有牌照自动稳定 |
| 做资产收购 | 买方自动取得卖方全部许可 |
| 证书还在墙上 | 许可仍在有效范围 |
| 环境排污许可 | 本任务可终局 |

---

## 条件句

if 环境类许可是主轴 → 负触发，转环境能源
if 行业规则未核验 → 承继和先批字段停止
if 用户要求无证过渡经营方案 → 整体停止
if 只要代办延续 → 负触发，不实施

---

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 股权路径不等于许可不敏感；资产路径不等于全部不能做。 |
| 2 | 人员资质随人，不随公司自动保留。 |
| 3 | 环境许可专项转出。 |
| 4 | 未核验行业规则不得写可以交割后补证。 |

---

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按无证风险、关键许可、规则核验、人员绑定排序。代办、环境专项、尽调报告只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

本成果不是许可申请，也不保证交割后可经营。
