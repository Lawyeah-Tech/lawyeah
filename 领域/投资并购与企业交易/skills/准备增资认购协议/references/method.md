# 起草方法

本文件是可执行判断节点，不是栏目说明书。每个会改变增资额、用途、交割或章程接口结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

增资认购协议解决钱进公司和股权形成，不解决交割后全部治理。完整 SHA 另项。对公司对赌不得写成当然有效或当然无效。

---

## Q# 条款块矩阵

固定列：`编号｜块｜数字／机制｜决议接口｜用途｜对赌主体｜状态`。

认购、估值、缴付、条件、R&W、对赌接口、登记分列。

---

## 节点 0　闸

1. 老股 → `准备股权收购协议`。
2. 日常增资运行 → 公司治理。
3. 登记全套 → `准备交易项下增资扩股文件`。

## 节点 1　数字

1. 认缴、实缴、溢价。非货币出资评估待核。

## 节点 2　优先认缴

1. 未放弃不得写成可排除老股东。

## 节点 3　对赌

1. 主体是股东还是目标公司。资本维持闸待核。

## 节点 4　交割

1. 缴付到公司账户。不得写成付给老股东还叫增资。

## 节点 5　安全

1. 禁止抽逃循环。禁止阴阳估值文件。

---

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 钱付给老股东 | 这是增资 |
| 对公司对赌 | 当然有效 |
| 认购协议 | 完整 SHA 已包含 |
| 日常增资登记 | 本任务主成果 |

---

## 条件句

if 路径是老股 → 负触发
if 对赌相对方是公司且规则未核验 → 效力字段停止
if 抽逃循环 → 整体停止
if 只要完整 SHA → 负触发

---

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 增资资金必须进入公司。 |
| 2 | 优先认缴未闭合不得排除老股东。 |
| 3 | 对公司对赌不当然有效或无效。 |
| 4 | 不出完整 SHA。 |

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按路径闸、优先认缴、对赌主体、出资真实性排序。SPA、SHA、登记包、日常治理只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。
