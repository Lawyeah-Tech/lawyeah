# 准备交易内部决议与批准包

## 任务目标

在明确、无利益冲突的单方立场下，形成“交易内部决议与批准包”：决议草稿、回避、批准层级、授权

`depends-on` 为空。接受用户、律师、财务顾问或其他来源的等价事实、估值、清单和文本。本任务不把未核验规则写成已闭合结论。

## 工作边界

正触发：签约或交割需股东会／董事会／投资人批准。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 日常董事会运行或会议组织；
- 国资批准请示本身；
- 把草稿写成已通过；
- 证券发行核准正文；

本任务日常董事会运行转公司治理；国资批准另项，不给成交率或胜诉率。

## 建立出稿坐标

确认：使用者与授权；单方立场；需批准的行为；机关和人数；关联回避；章程更高比例；法域；当前磋商、文本、审批或交割状态；关键材料及缺失。

同时掌握买卖双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 陈述；`D#` 章程／名册；`C#` 交易文件；`L#` 已核验规则；`I#` 判断；`Q#` 决议项；`V#` 版本

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验股东会董事会职权、表决比例和回避；不虚构审批系统、案号或登记回执。

工具不可用时继续按章程和交易行为出受限草案，有效性字段停止；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [起草方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　分流

日常会议运行转公司治理。国资批准另项。上市股东大会披露转上市原子或证券专项。

### 节点 2　层级

董事会、股东会、投资人同意、章程特别比例分列。控制权交易不得默认董事长一人决定。

### 节点 3　回避

关联董事／股东回避。回避后人数不足标待核。

### 节点 4　授权

签署授权必须覆盖文件清单和价格区间。概括授权标风险。

### 节点 5　状态

待召开。不得写成已通过或已备案。

## 停止与安全

- `整体停止`：立场冲突；伪造已召开或倒签决议。
- `字段停止`：表决比例、回避、授权范围未核验。
- `目标停止`：主目标变为日常治理或国资请示。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `草案、待召开、停止`。边界见 [路由](references/routing.md)。
