# 边界与路由

## 正触发

签约或交割需股东会／董事会／投资人批准。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 日常董事会或股东会运行 | 公司治理领域 |
| 国资批准路径 | 评估国资交易进场与审批路径 |
| 关联冲突识别 | 评估交易关联关系与利益冲突 |
| 上市股东大会披露 | 评估上市公司收购与重组路径 或证券专项 |
| 交割包 | 准备交割文件包 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 经营者集中申报、竞争限制专项 | 竞争法领域 |
| 借贷、保证、抵押质押、保理、融资租赁主轴 | 金融领域 |
| 日常章程、股东会、董事会或一般股东争议 | 公司治理领域 |
| 劳动尽调、员工转移、安置方案本身 | 劳动领域 |
| 环境许可、资源权利、能源监管专项尽调 | 环境能源领域 |
| 境外法适用、ODI、制裁、跨法域准入整体 | 涉外领域 |
| 税负测算、税务架构或稽查应对 | 税务领域 |
| 破产、重整、清算程序内投资 | 破产领域 |
| 一般买卖服务合作签前审查起草 | 审查起草领域（本窗搁置） |
| 证券发行、持续信息披露正文或重组报告书 | 证券监管专项，未核验则字段停止或 `unavailable` |

## 易混

这笔交易要出决议和授权书时正触发。要公司怎么开例会或要国资批复本身时负触发。
