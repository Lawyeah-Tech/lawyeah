# 起草方法

本文件是可执行判断节点，不是栏目说明书。每个会改变批准层级、回避或授权范围结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

交易决议包只服务本笔签约或交割。日常董事会怎么开会、通知期如何计算的制度设计转公司治理。

---

## Q# 决议矩阵

固定列：`编号｜机关｜事项｜比例｜回避｜授权范围｜文件清单｜状态`。

签约批准与交割批准可分两次，不得混成一次已完成。

---

## 节点 0　分流

1. 会议怎么通知、表决器、年度董事会 → 公司治理。
2. 国资出资人批准 → 国资原子。

## 节点 1　层级

1. 出售全部或主要资产、对外担保、增资、合并按现行公司法及章程。未核验则字段停止。

## 节点 2　回避

1. 关联识别可引用冲突原子结论。

## 节点 3　授权

1. 授权签署人、价格上限、文本版本。超出授权的签署标效力待核。

## 节点 4　一人公司／外方

1. 唯一股东书面决定、外资内部批准文件分列。

## 节点 5　安全

1. 禁止倒签。禁止伪造出席。

---

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 决议草稿 | 已经合法召开并通过 |
| 日常董事会制度 | 本任务主成果 |
| 国资进场批准 | 本任务已覆盖 |
| 董事长签字 | 控制权交易已获充分授权 |

---

## 条件句

if 日常治理主成果 → 负触发
if 倒签或伪造 → 整体停止
if 国资批准主成果 → 负触发
if 比例未核验 → 有效性字段停止

---

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 草稿不是已通过。 |
| 2 | 日常治理转出。 |
| 3 | 国资批准另项。 |
| 4 | 控制权交易不得默认一人决定。 |

---

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按伪造、层级错误、回避、授权过宽排序。公司治理、国资、上市披露只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

文本状态保持待召开。
---

## 补充条件句与停止

if 用户要求倒签召开日或伪造出席签名 → 整体停止。  
if 控制权交易仅有董事长签字而无股东会或董事会依据 → 批准有效性字段停止。  
if 主成果是日常会议通知期限或表决器制度 → 负触发，转公司治理。  
if 国资出资人批准是主成果 → 负触发，转国资路径原子。  
回避后不足法定人数：不得写成可以强行通过。文本状态保持待召开。
