# 审查对方交易文件

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“对方交易文件审查包”：文本版本、严重度分级问题单、接受／改写／退出建议、监管和程序红旗、最强反方。

`depends-on` 为空。本任务不把问题清单改写成己方首份 SPA，不把批注写成双方已同意。

## 工作边界

正触发：已收到对方投资并购交易文件草稿，单方需要风险审查和改法建议。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 还没有对方文本，只要己方首稿；
- 一般买卖服务合同签前审查（本窗搁置）；
- 只要集中申报或融资文件；
- 只要交割清单且文本风险已闭合。

## 建立审查坐标

确认：使用者与授权；审查立场；对方文本版本和对照 TS／尽调；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 对方文本表面；`C#` 己方 TS 或章程；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`K#` 问题；`V#` 审查版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验被审查条款是否与现行公司法、民法典冲突。工具不可用时继续文本对照，效力结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。

### 1. 分流、立场和文本版本

多份红线并列。不得只审格式。

### 2. 交易经济与控制权

对价机制、或有对价、控制权交割是否被文本掏空。

### 3. 条件和退出

先决条件是否单边；MAC、终止、分手费是否可操作。

### 4. R&W、披露和赔偿

知识、披露排除、篮子、上限、生存期。卖方稿与买方稿方向相反时按审查立场评估。

### 5. 程序合法性和下一步

优先购买、国资、外资、集中申报红旗。给出接受／改写／退出，不代发送改稿为已同意文本。

## 停止与安全

- `整体停止`：立场冲突；用户要求隐瞒已审出的致命条款。
- `字段停止`：效力规则未核验。
- `目标停止`：主目标变为起草己方首稿或交割。
