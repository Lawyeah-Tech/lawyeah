# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变退出路径、责任或分手费接口结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

先判断有没有走的权利，再谈通知。不发通知。强制交割是否可能属 P2，未安装则 `unavailable`。

---

## P# 退出矩阵

固定列：`编号｜原因｜是否有终止权｜通知前置｜分手费接口｜损害赔偿接口｜最强反方｜判断`。

监管失败、对方违约、我方违约、协商分列。

---

## 节点 0　分流

1. 发通知 → 终止通知原子。
2. 强制交割 → P2 unavailable。
3. 一般买卖解除 → 合同争议。

## 节点 1　原因

1. 我方融资失败若未约定融资条件，可能构成我方违约。

## 节点 2　路径

1. 须催告而未催告：目标停止发通知。

## 节点 3　费用

1. 分手费与损害赔偿可能互斥，转专项。

## 节点 4　部分履行

1. 已付款、已改名册的回退单独列。

## 节点 5　安全

1. 禁止捏造违约事实。

---

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 不想买了 | 已经有终止权 |
| 本任务评估 | 交易已经终止 |
| 强制交割 | 本包可终局 |
| 分手费条款 | 金额必得 |

---

## 条件句

if 主成果是发通知 → 负触发
if 捏造违约 → 整体停止
if 强制交割主成果 → P2 unavailable
if 终止权依据不足 → 判断依据不足，不得转通知终稿

---

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 不发终止通知。 |
| 2 | 不想买不等于有终止权。 |
| 3 | 强制交割 P2 unavailable。 |
| 4 | 分手费不写必得。 |

---

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按捏造、终止权、通知前置、P2排序。终止通知、分手费、异议、P2 只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

本成果不是终止通知。
---

## 补充条件句与停止

if 用户只是不想买且条款未给单方退出权 → 不得写成现有依据支持终止。  
if 须催告或补正而未完成 → 不得转到终止通知原子出终稿。  
if 主成果是发送终止通知 → 负触发。  
if 主成果是请求强制交割 → 输出 `unavailable`（P2 未安装）。  
捏造对方违约以退出：整体停止。分手费数额转专项，不写必得。
