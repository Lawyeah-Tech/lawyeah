# 起草方法

本文件是可执行判断节点，不是栏目说明书。每个会改变披露表完整性、排除主张或补披露窗口结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

卖方填表是制作披露，不是判断 R&W 客观为真。隐匿已知否决级事实整体停止。

---

## Q# 披露行矩阵

固定列：`编号｜R&W｜披露事实｜附件｜拟排除范围｜是否特定｜补披露｜状态`。

空行必须标缺口，不得用总括句填满。

---

## 节点 0　分流

1. 买方评估排除效力 → `评估披露函是否闭合陈述保证`。
2. R&W 条款设计 → R&W 原子。

## 节点 1　填表

1. 事实要特定到合同名称、案号、证书号或期间。

## 节点 2　排除

1. 卖方不得把“可能存在的一切风险”写成已披露。

## 节点 3　资料室

1. 索引可作附件，但本表仍要指向。

## 节点 4　补披露

1. 机制和买方救济并列。

## 节点 5　安全

1. 禁止隐匿。

---

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 资料室很全 | 披露表已经闭合 |
| 买方评估 | 本任务主成果 |
| 总括一句 | 已特定披露 |
| 草稿 | 排除效力已经成立 |

---

## 条件句

if 隐匿已知重大不利 → 整体停止
if 主成果是买方评估 → 负触发
if R&W 文本缺失 → 无法填表，字段停止
if 主成果是 SPA → 负触发

---

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 不重判 R&W 真假。 |
| 2 | 禁止隐匿。 |
| 3 | 禁止仅写见资料室。 |
| 4 | 资料室不等于本表完成。 |

---

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按隐匿、不特定、补披露排序。买方评估、R&W 设计、SPA 只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

文本状态保持待签署。
---

## 补充条件句与停止

if 已知重大诉讼、许可灭失或权利负担而要求不披露也不登记保留 → 整体停止。  
if 每一行只写“见资料室”而无具体事实或索引 → 不得主张已特定披露。  
if 主成果是买方评估排除效力 → 负触发，转披露函评估原子。  
if R&W 文本缺失 → 无法填表，成果状态为因停止条件未形成。  
补披露不得写成已经消灭买方终止或调价权，除非条文支持且已核验。
