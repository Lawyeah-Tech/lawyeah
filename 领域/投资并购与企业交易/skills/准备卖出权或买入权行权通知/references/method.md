# 起草方法

本文件是可执行判断节点，不是栏目说明书。每个会改变行权条件、通知正文或价格机制结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

行权通知以条件闭合为前提。对公司回购不得绕过资本维持。通知不是过户。

---

## Q# 行权矩阵

固定列：`编号｜权利类型｜条件｜是否闭合｜价格机制｜相对方｜到达设计｜状态`。

put、call、强制回购分列。

---

## 节点 0　闸

1. 条件未闭合 → 停止终稿。
2. 公司义务未评资本维持 → 字段停止或先转对赌原子。

## 节点 1　价格

1. 公式回链。评估机构选任争议标红旗。

## 节点 2　通知

1. 到达渠道。禁止倒签行权日。

## 节点 3　程序

1. 优先购买、国资、外资闸仍可能适用。

## 节点 4　效果

1. 不得写已过户或已登记。

## 节点 5　安全

1. 禁止抽逃式行权。

---

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 发出行权通知 | 股权已经过户 |
| 条件还没成就 | 可以出终稿 |
| 公司没钱也要回购 | 可以不顾资本维持 |
| 日常转股 | 本任务主成果 |

---

## 条件句

if 条件未闭合 → 停止终稿
if 抽逃式回购 → 整体停止
if 倒签行权日 → 整体停止
if 日常无期权转股 → 负触发

---

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 条件未闭合不得出终稿。 |
| 2 | 通知≠过户。 |
| 3 | 公司回购须过资本维持闸。 |
| 4 | 禁止倒签。 |

---

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按条件闸、资本维持、过户错写排序。效力评估、优先购买、登记只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

状态保持待发送。
---

## 补充条件句与停止

if 行权条件未闭合 → 停止出终稿。  
if 义务主体是目标公司且资本维持或回购闸未核验 → 效力与可履行字段停止。  
if 用户要求倒签行权日 → 整体停止。  
if 把发出通知写成已经过户或已登记 → 纠正该表述。  
优先购买、国资进场或外资限制仍可能阻却履行，必须留接口。
