# 边界与路由

## 正触发

拟进行境内投资、收购、出售或重组，单方需要决定路径、主体、监管闸或关键条件。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 规划尽调范围 | `规划法律尽调范围与红旗` |
| 写尽调报告 | `形成法律尽调报告` |
| 出条款清单 | `准备投资并购条款清单` |
| 出股权收购协议 | `准备股权收购协议` |
| 审查对方文本 | `审查对方交易文件` |
| 测算对价 | `测算交易对价与调整` |
| 交割包 | `准备交割文件包` |
| 经营者集中申报 | 竞争法领域 |
| 贷款担保文件 | 金融领域 |
| 日常治理或股东争议 | 公司治理领域 |
| 劳动尽调或安置 | 劳动领域 |
| 一般合同审查起草 | 审查起草领域（本窗搁置） |
| 普通有限公司无争议转让材料 | C 端股权转让协议与变更准备，只分流 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 经营者集中申报、竞争限制专项 | 竞争法领域 |
| 借贷、保证、抵押质押、保理、融资租赁 | 金融领域 |
| 境外法、ODI、制裁、跨法域准入整体 | 涉外领域 |
| 税负测算或税务架构 | 税务领域 |
| 破产重整投资 | 破产领域 |
| 环境能源资源专项权利 | 环境能源领域 |

## 易混

“想买这家公司”而路径、标的和监管闸未定时正触发。主体、路径、对价机制均确认且只要 SPA 时负触发。出现营业额或控制权集中信号时只做红旗，不改写成本任务的申报成果。
