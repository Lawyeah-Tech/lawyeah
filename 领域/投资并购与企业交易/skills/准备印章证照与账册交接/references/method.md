# 起草方法

本文件是可执行判断节点，不是栏目说明书。每个会改变交接清单、监交或风险结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

印鉴交接服务合法交割，不服务控制权争夺战。拒绝提供印鉴时提示协议救济或诉讼，不写抢章脚本。

---

## Q# 交接矩阵

固定列：`编号｜物品／权限｜控制人｜交接动作｜监交｜未交后果｜状态`。

印章、证照、密钥、账册、系统分列。

---

## 节点 0　禁止

1. 抢章、围堵、限制人身 → 整体停止。
2. 日常用印 SOP → 公司治理。

## 节点 1　清单

1. 遗漏财务章或 U 盾标重大缺口。

## 节点 2　监交

1. 双方授权代表签字。

## 节点 3　银行

1. 预留印鉴、网银管理员变更与交接同日或先后顺序必须写。

## 节点 4　拒绝

1. 合同违约、诉讼要印鉴、变更法定代表人接口。不写强制夺取。

## 节点 5　效果

1. 持有印章不等于股东权利已取得。

---

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 拿到公章 | 已经合法控制公司并可对抗第三人 |
| 对方不交章 | 可以去抢 |
| 用印制度 | 本任务主成果 |
| 交接清单 | 登记已经完成 |

---

## 条件句

if 用户要抢章方案 → 整体停止
if 日常用印制度 → 负触发
if 银行变更手续不明 → 银行控制字段停止
if 未监交 → 不得写已完成

---

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 不指导抢章。 |
| 2 | 日常用印转公司治理。 |
| 3 | 持章≠已对抗第三人。 |
| 4 | 拒绝交接走协议或诉讼，不写夺取。 |

---

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按抢章违法、清单遗漏、银行印鉴排序。登记、交割总包、公司治理、诉讼只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

状态保持待交接。
---

## 补充条件句与停止

if 用户要求抢章、撬门、扣押人员或切断对方通行 → 整体停止。  
if 主成果是日常用印审批流程 → 负触发，转公司治理。  
if 未安排监交和回执 → 不得写交接已完成。  
if 银行预留印鉴变更手续不明 → 银行控制字段停止。  
持有印章不等于已取得股东权利，也不等于已对抗善意相对人。
