# 起草方法

本文件是可执行判断节点，不是栏目说明书。每个会改变确认范围、未完成项或保留结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

交割备忘记录当日互交和保留，不创造登记效力。强制条件未满足不得确认交割完成。

---

## Q# 确认矩阵

固定列：`编号｜项目｜当日状态｜证据｜保留｜是否写入已完成｜判断`。

条件、文件、资金、印章、名册、登记分列。

---

## 节点 0　闸

1. 强制监管未完成 → 不得确认交割。
2. 满足性判断另项。

## 节点 1　清单

1. 原件、复印件、电子件分列。

## 节点 2　资金

1. 指令已发≠到账。到账须凭证。

## 节点 3　登记

1. 不得写已完成，除非有登记回执。

## 节点 4　保留

1. 未完成项、补交期限、违约后果接口。

## 节点 5　安全

1. 禁止倒签和伪称。

---

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 备忘签署 | 登记已经完成并可对抗第三人 |
| 钱已指令 | 已经到账 |
| 条件还没评估 | 可以确认交割完成 |
| 倒签一天 | 可以 |

---

## 条件句

if 强制条件未满足 → 不得出完成确认
if 伪称登记完成 → 整体停止
if 倒签 → 整体停止
if 到账无凭证 → 资金完成字段停止

---

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 不伪称登记已完成。 |
| 2 | 指令≠到账。 |
| 3 | 强制条件未满足不得确认。 |
| 4 | 禁止倒签。 |

---

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按伪称、倒签、强制条件排序。条件评估、资金指令、登记只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

文本状态保持待签署。
---

## 补充条件句与停止

if 强制监管条件未满足（集中申报、安全审查、禁止类外资） → 不得出交割完成确认。  
if 用户要求伪称登记或批准已完成 → 整体停止。  
if 要求倒签交割日 → 整体停止。  
if 资金仅有付款指令而无到账凭证 → 资金完成字段停止。  
备忘只记录当日互交和保留，不创造登记对抗效力。
