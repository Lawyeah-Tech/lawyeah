# 准备交易终止通知

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，于终止权评估或等价材料已经支持发出终止通知时，形成“发送前交易终止通知包”：发送闸、通知路径、发送前正文、到达设计和异议应对。

`depends-on` 为空。本任务只形成待发送材料，不执行发送，不把准备发送写成交易已经终止。

## 工作边界

正触发：条款清单、SPA 或其他交易文件下的终止权材料支持发送，用户需要发送前稿和到达设计。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要评估能不能走，材料不支持发送；
- 只要 SPA 或交割包；
- 一般合同解除通知（合同争议领域）；
- 依法或依约须先催告／补正且尚未完成。

## 建立发函坐标

确认：使用者与授权；单方立场；交易文件版本；拟主张的终止路径；催告或补正是否必要；拟发送日和约定送达渠道。

同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 陈述；`D#` 材料；`C#` 终止条款；`L#` 已核验规则；`I#` 判断；`G#` 缺口；`E#` 送达设计；`V#` 通知版本。

通知状态只用 `草案`、`待发送`、`已发送待证明到达`、`已到达`、`停止`。没有送达事实和规则引文，禁止写 `交易已终止`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验通知到达、约定解除、预约责任。工具不可用时继续事实和正文结构，终止效果字段停止。

## 五个判断节点

执行顺序和停止条件以 [发函方法](references/method.md) 为准。

### 1. 发送闸

材料必须支持发出。想今天发函或对方未异议，打不开闸。

### 2. 路径和催告闭合

约定终止、条件失败、MAC、预约退出分账。须催告未完成则目标停止。

### 3. 发送前正文

只写已支持的事实和条款。不倒签。不宣称已经终止。

### 4. 到达设计

按约定渠道。已读不等于到达。本任务不执行发送。

### 5. 异议和分手费接口

预列对方最强异议。金额不写成必得。

## 停止与安全

- `整体停止`：立场冲突；伪造送达；倒签。
- `字段停止`：终止效果、期限未核验。
- `目标停止`：发送闸未打开；主目标变为评估或起诉。
