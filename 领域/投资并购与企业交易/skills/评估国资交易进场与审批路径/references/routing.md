# 边界与路由

## 正触发

标的或转让方含国有、应进场或应评估审批。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 代办进场或摘牌 | 不实施；挂牌评估见 评估产权交易所挂牌路径 |
| 产权交易所挂牌条件本身 | 评估产权交易所挂牌路径 |
| 交易结构总图 | 评估投资并购交易结构 |
| 经营者集中申报 | 竞争法领域 |
| 一般合同审查起草 | 审查起草领域（本窗搁置） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 经营者集中申报、竞争限制专项 | 竞争法领域 |
| 借贷、保证、抵押质押、保理、融资租赁主轴 | 金融领域 |
| 日常章程、股东会、董事会或一般股东争议 | 公司治理领域 |
| 劳动尽调、员工转移、安置方案本身 | 劳动领域 |
| 环境许可、资源权利、能源监管专项尽调 | 环境能源领域 |
| 境外法适用、ODI、制裁、跨法域准入整体 | 涉外领域 |
| 税负测算、税务架构或稽查应对 | 税务领域 |
| 破产、重整、清算程序内投资 | 破产领域 |
| 一般买卖服务合作签前审查起草 | 审查起草领域（本窗搁置） |
| 证券发行、持续信息披露正文或重组报告书 | 证券监管专项，未核验则字段停止或 `unavailable` |
| 金融文化等特别国资规则未核验 | 字段停止，不套一般企业口诀 |

## 易混

“能不能协议转让、要不要进场”正触发。只要填写挂牌表格或只要证券披露正文时负触发。
