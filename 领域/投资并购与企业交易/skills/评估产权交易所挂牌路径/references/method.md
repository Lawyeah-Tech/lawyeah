# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变挂牌条件、信息披露或摘牌接口结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

产权交易所规则因地而异，一律待核。国资法定进场不得用流程函或附属函改写。竞价流程函属 P2，未安装则 `unavailable`。

---

## P# 挂牌矩阵

固定列：`编号｜交易所｜进场原因｜资格条件｜披露期｜优先权接口｜成交方式｜失败回退｜判断｜待核`。

法定进场与自愿挂牌分列。不得把某产权交易所习惯写成全国规则。

---

## 节点 0　分流

1. 国资应否进场、批准层级 → `评估国资交易进场与审批路径`。
2. 上市公司股份集中竞价或大宗 → 证券专项。
3. 代提交挂牌材料 → 不实施。

## 节点 1　条件与披露

1. 受让方资格不得量身定做到排除潜在竞买人，除非规则允许且已核验。
2. 信息披露期、披露内容、重大事项补充披露分列。
3. 商业秘密与法定披露冲突时标红旗，不得指导隐瞒。

## 节点 2　优先权

1. 章程或公司法上的优先购买与挂牌“同等条件”如何对接必须待核。
2. 未通知其他股东不得写成可以挂牌成交。
3. 两个以上股东行使优先权的处理回优先购买原子。

## 节点 3　成交与失败

1. 一次挂牌未成交是否允许延期、降价再挂，按该所规则待核。
2. 摘牌前签署的私下成交文件不得写成已可履行。

## 节点 4　与交易文件关系

1. 挂牌成交确认书与后续 SPA 的关系必须可见。
2. 不得用 side letter 改法定资格或价格限制。

## 节点 5　下一步

1. 优先购买细节转 `评估优先购买权同意权与章程限制`。
2. 竞价流程函 P2 `unavailable`。

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 已选定意向受让方 | 可以按该方条件锁定挂牌结果 |
| 国资批准未做 | 本任务已替代批准 |
| 某所口头习惯 | 全国统一挂牌程序 |
| 私函约定不披露负债 | 可以不披露 |

---

## 条件句

if 法定进场且用户要用私函改资格或价格 → 整体停止
if 该所规则未取得 → 条件、期间、成交方式字段停止
if 主成果是国资批准请示 → 负触发，转国资原子
if 证券二级市场交易 → 负触发

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 法定进场规则不得用私函改写。 |
| 2 | 交易所规则当地待核，不得全国一套口诀。 |
| 3 | 优先购买与挂牌同等条件的衔接必须单独判断。 |
| 4 | 不代挂牌、不代摘牌。 |

---

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按法定规则冲突、该所规则、优先权、披露排序。国资批准、代挂牌、证券竞价只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

本成果不是挂牌申请或成交确认。
