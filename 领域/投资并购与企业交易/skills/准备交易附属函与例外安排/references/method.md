# 起草方法

本文件是可执行判断节点，不是栏目说明书。每个会改变例外安排或与主协议冲突结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

附属函是例外工具，不是第二套主协议，更不是规避工具。与主协议冲突必须可见。

---

## Q# 冲突矩阵

固定列：`编号｜附属安排｜主协议条款｜章程／SHA｜法定程序｜谁受益｜冲突处理｜状态`。

付款、优先、治理、竞业、披露分列。

---

## 节点 0　禁止绕开

1. 应进场、应披露、应申报集中、禁止类外资：整体停止出规避稿。

## 节点 1　范围

1. 一次性宽限 vs 持续修改主协议。后者应走主协议修订。

## 节点 2　冲突

1. 效力优先条款、修改程序、通知其他当事方。

## 节点 3　其他股东

1. 可能构成对其他股东的损害或触发反稀释／最惠。待核。

## 节点 4　上市／国资

1. 未披露的附属安排标红旗。

## 节点 5　状态

1. 待签署。不得写主协议已被修改。

---

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 签一封函 | 法定进场已经可以不做 |
| 个别股东口头答应 | 其他股东已受约束 |
| 附属函草稿 | 主协议已经修订 |
| 日常股东安排 | 本任务主成果 |

---

## 条件句

if 目的是绕开进场或披露 → 整体停止
if 冲突未列表 → 不得出发送终稿
if 无交易背景的日常安排 → 转公司治理
if 主成果是 SPA → 负触发

---

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 不得用附属函绕开法定进场或强制披露。 |
| 2 | 与主协议冲突必须列表。 |
| 3 | 对其他股东效力待核。 |
| 4 | 草案不得写成已修改主协议。 |

---

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按规避法定程序、未揭示冲突、其他股东排序。主协议、国资、上市披露只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

文本状态保持待签署。
---

## 补充条件句与停止

if 附属安排改变法定进场资格、价格限制或信息披露范围 → 整体停止，不得出发送前终稿。  
if 只给个别股东优惠且未对照最惠国或反稀释条款 → 冲突表必须列出，效力字段停止。  
if 附属函实际是对主协议的全面修订 → 负触发，转主协议起草原子。  
if 上市主体未披露的持续附属安排 → 披露字段停止或转上市路径原子。  
禁止用附属函倒签主协议生效日。文本状态保持待签署。
