# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变准入、不准入或信息报告结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

2019 年外商投资法实施后，准入前国民待遇加负面清单是默认框架。不得把 2009 年《关于外国投资者并购境内企业的规定》的审批写成现行全国默认。该规定与现行规则冲突时，以现行有效规则和施行日为准。

---

## P# 准入矩阵

固定列：`编号｜外方路径｜行业｜清单结果｜股比／高管限制｜信息报告｜与安全审查关系｜支持事实｜不利事实｜判断｜待核`。

直接并购、间接收购、增资、协议控制分列。协议控制不得写成已经自动合法。

---

## 节点 0　专项分流

1. 主成果是境外法意见、ODI、制裁或出口管制 → 涉外领域。
2. 主成果是安全审查申报 → `评估外商投资安全审查红旗` 只做红旗，申报不在本包。
3. 主成果是经营者集中申报 → 竞争法。

## 节点 1　外方与控制链

1. 外方包括外国投资者、外商投资企业再投资等需按现行定义核验。
2. 名义境内买方若受外方控制，按外资路径继续，不得因登记在境内就写成内资。
3. 多层境外架构只画到足以判断控制，境外公司效力转涉外。

## 节点 2　负面清单

1. 核验现行全国清单和适用的自贸试验区或自由贸易港清单，二者冲突时说明适用哪一份及理由。
2. 禁止类：该路径判断 `现有依据不支持` 继续，或整体停止出稿。
3. 限制类：股比、投资方式、高管国籍等条件未满足不得写成可以交割。
4. 清单未核验：准入字段停止，事实比较可继续。

## 节点 3　信息报告

1. 初始、变更、年度报告义务只标接口和责任主体待核。
2. 不得把“已办商务审批”写成现行必经默认，也不得把信息报告写成已经取得准入许可。
3. 市场主体登记与外资报告的衔接按当地待核。

## 节点 4　协议控制与规避

1. VIE 或协议控制出现时标红旗，不写成当然有效或当然无效。
2. 用户要求境内代持规避负面清单或制裁：整体停止。

## 节点 5　下一步

1. 安全审查红旗转相应原子。集中申报转竞争法。
2. 不准入则停止出可交割稿。

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 买方是境外主体 | 必须先拿商务部并购审批 |
| 境内公司出面签约 | 当然属于内资交易 |
| 做过信息报告 | 已经取得准入许可 |
| 2009 并购规定仍印在旧模板 | 现行默认程序 |

---

## 条件句

if 控制链显示外方直接或间接控制 → 按外资路径判断，不得写成纯内资
if 行业可能落入禁止或限制类且清单未核验 → 准入和交割字段停止
if 用户要用代持规避清单 → 整体停止
if 主成果是制裁或 ODI → 负触发，转涉外

---

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 现行默认是准入前国民待遇加负面清单和信息报告，不是 2009 并购审批。 |
| 2 | 禁止类不得写成可交割；限制类条件未满足不得写成可交割。 |
| 3 | 信息报告不能替代安全审查或经营者集中。 |
| 4 | 境外法、ODI、制裁整案转涉外。 |

---

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按禁止类、限制未满足、控制链不明、安全审查、集中申报排序。申报正文、境外法意见只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

本成果不是批准证书、信息报告代填或境外法律意见。
