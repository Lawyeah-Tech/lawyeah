# 评估优先购买权同意权与章程限制

## 任务目标

在明确、无利益冲突的单方立场下，形成“优先购买与章程限制评估矩阵”：通知四要素、期间、章程另有规定、同意／优先权闭合

`depends-on` 为空。接受用户、律师、财务顾问或其他来源的等价事实、估值、清单和文本。本任务不把未核验规则写成已闭合结论。

## 工作边界

正触发：对外转股或增资，需判断章程、股东协议限制。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 把 2018 年公司法第 71 条过半数同意当现行默认；
- 权属清楚的普通小微无争议转让材料（C 端分流）；
- 只要日常股东争议诉讼策略；
- 只要发送前 SPA 且限制已闭合；

本任务不把旧法第 71 条当现行默认；C 端小微转让只分流，不给成交率或胜诉率。

## 建立评估坐标

确认：使用者与授权；单方立场；转让是对内或对外；章程和股东协议文本；拟通知内容；是否增资；法域；当前磋商、文本、审批或交割状态；关键材料及缺失。

同时掌握买卖双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 陈述；`D#` 章程／SHA／通知；`C#` 条款定位；`L#` 已核验公司法；`I#` 判断；`G#` 缺口；`E#` 送达；`V#` 版本

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　分流和对内对外

C 端小微转让只分流。日常股东争议转公司治理。先区分对内转让、对外转让、增资稀释。

### 节点 2　章程与股东协议

章程另有规定、SHA 同意权、禁售、ROFR／ROFO 分列。冲突并列，不自动选对公司或对转让方有利的一版。

### 节点 3　通知四要素和期间

现行默认是书面通知数量、价格、支付方式和期限；三十日未答复视为放弃。章程另有规定从其规定。无送达不得写已放弃。

### 节点 4　多人行使与增资例外

两个以上股东行使时先协商，不成按转让时出资比例。增资是否适用优先认缴按章程和现行法待核。

### 节点 5　闭合和下一步

未闭合不得写出可签署对外转让终稿。SPA 转介。

## 停止与安全

- `整体停止`：立场冲突；伪造放弃声明或倒签通知。
- `字段停止`：章程另有规定、期间、增资优先认缴未核验。
- `目标停止`：主目标变为 C 端小微包或日常股东诉讼。
