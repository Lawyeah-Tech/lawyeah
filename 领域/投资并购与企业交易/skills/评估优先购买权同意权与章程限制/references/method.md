# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变通知要件、期间或优先权是否闭合结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

禁止把“其他股东过半数同意”写成现行全国默认。2024-07-01 后对外转让默认是书面通知数量、价格、支付方式和期限。章程另有规定仍可能约束。SHA 可能严于法律。

---

## Q# 限制矩阵

固定列：`编号｜限制来源｜对内／对外／增资｜通知要件｜期间｜同意／优先｜是否已闭合｜支持事实｜不利事实｜判断`。

公司法默认、章程、股东协议、一致行动、国资／上市特别规则分列。

---

## 节点 0　分流

1. 普通有限公司、权属清楚、无对赌国资上市跨境控制权争夺，只要协议和工商材料 → C 端分流。
2. 日常股东资格或知情争议 → 公司治理。
3. 挂牌程序中的优先权衔接 → 同时保留挂牌原子接口。

## 节点 1　文本

1. 取得现行章程、全部修正案、SHA、一致行动。缺一不得写“只有法定默认”。
2. 章程禁止对外转让或要求全体同意：标有效性待核，不得直接写作废或直接写有效。

## 节点 2　通知

1. 四要素缺一：不得写已触发放弃拟制。
2. 价格或支付方式事后变更：可能需重新通知，标待核。
3. 送达按约定或可验证渠道。已读不等于到达。

## 节点 3　行使与多人

1. 部分行使是否允许按章程和交易条件判断。
2. 两个以上股东行使：先协商，不成按转让时出资比例。不得写成由转让方指定。

## 节点 4　增资

1. 股东优先认缴与对外转股优先购买不是同一制度，必须分账。
2. 排除优先认缴须回链决议和章程，未核验则增资闭合字段停止。

## 节点 5　下一步

1. 闭合后转 SPA 或认购协议原子。
2. 未闭合不得指导强行登记。

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 其他股东没开会 | 对外转让无效（以旧法第 71 条为唯一理由） |
| 发过一封未写价格的邮件 | 三十日已过视为放弃 |
| 章程写全体同意 | 新法后当然作废 |
| 小微内部转让填空 | 本任务主成果 |

---

## 条件句

if 材料引用 2018 年公司法第 71 条作为现行默认 → 记为噪声，改核第 84 条和章程
if 通知缺四要素之一 → 不得写优先权已放弃
if C 端小微无争议转让 → 负触发
if 用户要求伪造放弃声明 → 整体停止

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 对外转让现行默认：书面通知数量、价格、支付方式和期限；三十日未答复视为放弃。 |
| 2 | 章程另有规定从其规定；SHA 可能另设同意权。 |
| 3 | 不得把过半数同意写成现行全国默认。 |
| 4 | 无送达事实不得写已放弃。 |

---

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按伪造风险、四要素、章程冲突、增资例外排序。SPA、挂牌、C 端包只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

本成果不是放弃声明，也不是已闭合证明。
