# 起草方法

本文件是可执行判断节点，不是栏目说明书。每个会改变名册请求、材料清单或三十日提示结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

四节点：协议生效、名册记载、章程记载、登记变更。本任务落地后两到三项材料，不保证对抗第三人。

---

## Q# 材料矩阵

固定列：`编号｜文件｜法律作用｜当地书式｜与交割条件关系｜状态`。

名册、章程、决议、转让／增资证明、申请表分列。

---

## 节点 0　分流

1. 无交易小微转让 → C 端。
2. 日常变更 → 公司治理。
3. 交割总包 → `准备交割文件包`。

## 节点 1　名册

1. 记载事项、签收、拒绝时的救济接口。

## 节点 2　登记

1. 书式、预约、电子化当地待核。

## 节点 3　期间

1. 三十日提示，起算日分列交割日／决议日／记载日。

## 节点 4　对抗

1. 未登记不得对抗善意相对人。

## 节点 5　安全

1. 禁止伪造名册。

---

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 材料备好 | 已经对抗第三人 |
| C 端模板 | 本任务主成果 |
| 外省表格 | 本登记机关可用终局 |
| 登记将受理 | 权属无争议 |

---

## 条件句

if C 端小微无交易复杂度 → 只分流
if 伪造记载日 → 整体停止
if 书式未核 → 提交字段停止
if 代提交要求 → 不实施

---

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 当地书式一律待核。 |
| 2 | 不代提交。 |
| 3 | C 端只分流。 |
| 4 | 登记完成≠权属无争议。 |

---

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按伪造、书式、期间、C 端边界排序。交割总包、增资包、C 端、诉讼只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

状态保持待提交。
---

## 补充条件句与停止

if 权属清楚的普通小微无争议变更且只要填表 → 负触发，C 端只分流。  
if 用户要求伪造名册记载日 → 整体停止。  
if 当地书式未核验 → 一律待核，不得用外省表格写成终局。  
if 公司拒绝变更名册 → 提示可依法起诉，本任务不写诉状。  
三十日起算日有冲突时建并行情景，不选对用户最有利的一天。
