# 起草方法

本文件是可执行判断节点，不是栏目说明书。每个会改变文件包完整性、出资或登记接口结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

本项覆盖增资交割落地文件，认购协议原子覆盖商业条款。二者可先后或由用户提供等价认购条款。

---

## Q# 文件包矩阵

固定列：`编号｜文件｜依据｜当地书式｜与认购协议关系｜状态`。

决议、章程、出资、名册、登记分列。

---

## 节点 0　闸

1. 只要估值和权利 → 认购原子。
2. 无交易日常增资 → 公司治理。
3. C 端小微 → 分流。

## 节点 1　章程

1. 股东及出资额记载修改；依法不需再表决的范围待核，当地仍要决议的标待核。

## 节点 2　出资

1. 入资凭证。非货币评估。

## 节点 3　登记

1. 变更登记申请不代交。三十日提示。

## 节点 4　对抗

1. 名册与登记四节点分列。

## 节点 5　安全

1. 禁止虚假出资和倒签。

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 文件包草稿 | 登记已经完成 |
| 认购协议 | 本任务重复出商业条款终稿即可 |
| 当地表格未核 | 可以用外省表格终局 |
| C 端小微 | 本任务主成果 |

---

## 条件句

if 只要商业条款 → 负触发
if 日常无交易增资 → 转公司治理
if 倒签出资 → 整体停止
if 当地书式未核 → 提交字段停止

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按虚假出资、书式、与认购分工排序。认购协议、公司治理、C 端只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

状态保持待提交。
---

## 补充条件句与停止

if 只要估值、优先权和商业条款 → 负触发，转认购协议原子。  
if 无交易背景的日常增资跑登记 → 负触发，转公司治理。  
if 用户要求倒签出资日或循环打款制造实缴外观 → 整体停止。  
if 当地登记书式未核验 → 提交字段停止，文件清单可继续。  
登记材料待提交，不得写成变更已经完成或已对抗第三人。
