# 起草方法

本文件是可执行判断节点，不是栏目说明书。每个会改变赔偿范围、限额或留扣接口结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

赔偿条款是结构，不是胜诉支票。未知不写零。融资担保、独立保函转金融。

---

## Q# 赔偿矩阵

固定列：`编号｜类型｜触发｜除外｜篮子｜上限｜生存期｜留扣接口｜判断`。

一般赔偿与专项赔偿分列。金额未知留空。

---

## 节点 0　分流

1. 保函、抵押、保证主轴 → 金融。
2. 提存合同操作 → `准备对价提存或尾款留扣安排`。
3. 整份 SPA → 相应原子。

## 节点 1　范围

1. 不得用唯一救济条款消灭法定撤销或欺诈救济而不标风险。

## 节点 2　限额

1. 数字来源必须回链用户或文件，禁止编造。

## 节点 3　留扣

1. 与提存原子分工：本任务建接口，操作条款可另项。

## 节点 4　程序

1. 通知时限过短标买方风险。

## 节点 5　安全

1. 禁止脱离交易的资金空转。

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 写了上限 | 买方最多只能拿到该金额且已确定 |
| 市场惯例 | 法律强制篮子 |
| 融资保证 | 本任务主成果 |
| 赔偿矩阵 | 索赔通知已可发 |

---

## 条件句

if 融资担保是主成果 → 负触发，转金融
if 数字无来源 → 留空待核，不编造
if 主成果是整份 SPA → 负触发
if 要必得金额 → 负触发

---

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 不算出必得金额。 |
| 2 | 不编造惯例百分比当法律。 |
| 3 | 融资担保转金融。 |
| 4 | 欺诈例外待核。 |

---

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按编造数字、融资主轴、唯一救济过宽排序。SPA、提存细则、索赔通知、金融只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

文本状态保持待纳入主协议。
---

## 补充条件句与停止

if 用户要求编造篮子或上限百分比冒充法律强制 → 数字留空待核，并书面排除该惯例。  
if 唯一救济条款试图消灭欺诈或法定撤销 → 必须标买方审查风险，不得写成已合法排除。  
if 主成果是保函、抵押或保证合同 → 负触发，转金融领域。  
if 损失数字未知 → 不写零，不输出必得金额。  
生存期、通知时限未核验则索赔程序字段停止，条款结构可继续。
