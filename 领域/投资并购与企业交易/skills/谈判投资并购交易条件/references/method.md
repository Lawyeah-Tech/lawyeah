# 谈判方法

本文件是可执行判断节点，不是栏目说明书。每个会改变让步、不可让项或弃权范围结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

谈判方案强制单方立场。不可让项包括：法定进场、禁止类外资、安全审查、集中申报实施禁令、伪造文件。价格数字未知不编。

---

## Q# 争点让步矩阵

固定列：`编号｜争点｜我方现立场｜对方现立场｜可让步｜交换｜底线｜不可让理由｜状态`。

不得把全部争点合成“差不多就行”。

---

## 节点 0　分流

1. 已谈拢出稿 → SPA／资产／认购／SHA 原子。
2. 对方文本问题单 → `审查对方交易文件`。

## 节点 1　强制规范

1. 监管闸、法定程序不得列入可让。

## 节点 2　阶梯

1. 每让一步写换回什么。空让标风险。

## 节点 3　弃权

1. 授权不明不得建议弃权。
2. 弃权范围必须特定。

## 节点 4　披露

1. 谈判中的披露不得构成内幕交易或虚假陈述。上市字段停止或转上市原子。

## 节点 5　下一步

1. 谈崩 → `评估交割失败与退出交易`。

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 还能谈 | SPA 已经定稿 |
| 双方都想成交 | 可以同时给出双方最优策略 |
| 法定进场麻烦 | 可以谈掉 |
| 审查问题单 | 本任务主成果 |

---

## 条件句

if 同时代表双方 → 整体停止
if 把应进场或禁止类当可让 → 整体停止
if 已谈拢只要正文 → 负触发
if 授权底线不明 → 弃权字段停止

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按违法让步、双边策略、授权排序。出稿、审查、退出评估只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

本成果不是协议正文。
