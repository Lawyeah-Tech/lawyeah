# 谈判投资并购交易条件

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“交易条件谈判让步表”：争点让步表、条件、弃权范围

`depends-on` 为空。接受用户、律师、财务顾问或其他来源的等价事实、估值、清单和文本。本任务不把未核验规则写成已闭合结论。

## 工作边界

正触发：仍可谈，要底线、让步和不可让条款。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 代替已谈拢的 SPA 正文；
- 同时为双方出谈判策略；
- 只要审查问题清单而不要让步策略；
- 一般合同审查起草（本窗搁置）；

本任务不代替已谈拢的 SPA 正文，不给成交率或胜诉率。

## 建立谈判坐标

确认：使用者与授权；单方立场；争点清单；已有 TS／SPA 草稿；授权底线；监管闸；法域；当前磋商、文本、审批或交割状态；关键材料及缺失。

同时掌握买卖双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 陈述；`D#` 对方文本／会议纪要；`C#` 已谈拢条款；`L#` 已核验规则；`I#` 判断；`Q#` 争点；`V#` 版本

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_practiced` 补争点失败模式；法规用于核验不可让的强制规范；不虚构审批系统、案号或登记回执。

工具不可用时继续按争点表出受限让步矩阵；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [谈判方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　分流和单方

已谈拢只要出稿转起草原子。审查问题清单另项。双方策略整体停止。

### 节点 2　争点分账

价格、条件、R&W、赔偿、排他、监管分列。强制规范不可让。

### 节点 3　让步阶梯

每项设底线、可让步、交换条件。不得把违法事项列入可让。

### 节点 4　弃权范围

弃权必须书面、特定、有授权。不得概括放弃法定进场、优先购买程序或安全审查。

### 节点 5　下一步

谈拢后转相应起草原子。谈崩转退出评估。

## 停止与安全

- `整体停止`：立场冲突或同时服务双方；把强制监管当可让条款。
- `字段停止`：授权范围、强制规范未核验。
- `目标停止`：主目标变为已谈拢 SPA 正文。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成、部分形成并明确受限字段、因停止条件未形成`。边界见 [路由](references/routing.md)。
