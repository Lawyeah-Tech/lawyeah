# 识别经营者集中红旗并转出

## 任务目标

在明确、无利益冲突的单方立场下，形成“经营者集中红旗与转出交接”：红旗、营业额／控制权待核、转竞争法最小交接

`depends-on` 为空。接受用户、律师、财务顾问或其他来源的等价事实、估值、清单和文本。本任务不把未核验规则写成已闭合结论。

## 工作边界

正触发：交易可能导致控制权集中，需判断是否触申报闸。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要撰写或提交经营者集中申报；
- 只要竞争限制专项分析终局；
- 只要安全审查申报正文；
- 一般合同审查起草（本窗搁置）；

本任务不撰写、不提交经营者集中申报，不给成交率或胜诉率。

## 建立识别坐标

确认：使用者与授权；单方立场；交易是否取得控制；参与集中的经营者；已有营业额线索；法域；当前磋商、文本、审批或交割状态；关键材料及缺失。

同时掌握买卖双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 陈述；`D#` 结构／财务线索；`L#` 已核验规则；`I#` 判断；`G#` 缺口；`P#` 红旗；`V#` 版本

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验经营者集中申报标准和控制权定义，只用于红旗，不用于撰写申报；不虚构审批系统、案号或登记回执。

工具不可用时继续控制权变化和已有营业额线索整理；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [识别方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　专项分流

申报正文、竞争评估、代理申报一律转竞争法。本任务只做红旗和最小交接。

### 节点 2　控制权变化

单独控制、共同控制、从共同到单独控制分列。少数否决权也可能构成控制，未核验不得排除。

### 节点 3　营业额和其他标准待核

只列待核事实和材料清单，不计算申报标准终局，不写“未达门槛故不必报”。

### 节点 4　停止实施提示

可能触报则交割条件保留获准或不实施。不得指导抢跑。

### 节点 5　最小交接

向竞争法领域交接：交易结构、控制权假设、已有财务线索、时间表。不附申报草稿。

## 停止与安全

- `整体停止`：立场冲突；用户坚持在可能触报时交割或拆单规避申报。
- `字段停止`：控制权定义、申报标准未核验时不得输出不必申报。
- `目标停止`：主目标变为撰写或提交申报。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成、部分形成并明确受限字段、因停止条件未形成`。边界见 [路由](references/routing.md)。
