# 识别方法

本文件是可执行判断节点，不是栏目说明书。每个会改变是否触申报红旗或应转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

本包明确不收录经营者集中申报原子。任何申报标准计算终局、竞争影响分析、申报表或代理策略都属于竞争法领域。本任务最多输出红旗和交接清单。

---

## P# 红旗矩阵

固定列：`编号｜控制权假设｜参与集中经营者｜营业额线索｜其他标准线索｜对交割影响｜交接材料｜判断｜待核`。

不得输出“经测算未达门槛、可以交割”作为本任务结论。

---

## 节点 0　专项分流

1. 用户要申报表、委托书、竞争分析、救济方案 → 整案转竞争法，本任务只交红旗。
2. 安全审查主成果 → 安全审查原子。
3. 拆分交易规避申报 → 整体停止。

## 节点 1　控制权

1. 取得控制包括决定高级管理人员、财务预算、经营计划等。
2. 共同控制、否决权、一致行动均可能构成集中。无材料不得写成“只是财务投资故不报”。

## 节点 2　标准只待核

1. 营业额口径、归属、汇率、上一会计年度只列待核。
2. 即便用户已提供数字，本任务也不做申报标准终局计算。
3. 未达门槛的主张一律标 `依据不足，无法形成结论` 或转竞争法。

## 节点 3　停止实施

1. 可能触报：不得实施集中，包括过户、委派关键人员、实质整合。
2. 不得指导交割后补报来正当化抢跑。

## 节点 4　最小交接

1. 交接包：交易步骤、各方控制关系图、已有合并报表或审计线索、交割时间表、是否已发生部分实施。
2. 不附申报草稿、不写市场份额。

## 节点 5　下一步

1. 明确写出：经营者集中申报由竞争法领域完成，未完成前本包交割原子不得写成可交割。

---

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 财务投资人自称不参与经营 | 当然不构成控制 |
| 营业额看起来不大 | 不必申报 |
| 本任务红旗表 | 申报已经完成 |
| 先交割再看 | 可以抢跑 |

---

## 条件句

if 出现控制权变化或共同控制线索 → 必须输出红旗并转竞争法
if 用户要申报书 → 负触发，整案转竞争法
if 用户要拆单规避 → 整体停止
if 标准条文未核验 → 不得写不必申报

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按抢跑风险、控制权、交接完整性排序。申报正文只转竞争法。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

本成果不是申报表，也不是“已排除申报义务”的意见。
