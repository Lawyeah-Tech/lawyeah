# 准备资产收购协议

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“发送前资产收购协议”：资产范围、负债排除、许可／合同转让、交割

`depends-on` 为空。接受用户、律师、财务顾问或其他来源的等价事实、估值、清单和文本。本任务不把未核验规则写成已闭合结论。

## 工作边界

正触发：已定资产路径，需发送前资产购买协议；起草方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 房地产买卖主轴；
- 把资产协议写成股权协议；
- 路径未定仍要比较股权或资产；
- 一般买卖合同起草（本窗搁置）；

本任务不把资产协议写成股权协议；房地产买卖主轴转房地产，不给成交率或胜诉率。

## 建立出稿坐标

确认：使用者与授权；单方立场；资产清单；排除负债；许可与合同；起草立场；法域；当前磋商、文本、审批或交割状态；关键材料及缺失。

同时掌握买卖双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 陈述；`D#` 资产／合同清单；`C#` TS；`L#` 已核验规则；`I#` 判断；`Q#` 条款块；`V#` 版本

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验买卖合同、债务转移、权利瑕疵；`search_template` 只借栏目；不虚构审批系统、案号或登记回执。

工具不可用时继续按清单出受限草案，承继和登记字段停止；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [起草方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　发送闸和路径

未定资产路径负触发回结构原子。房地产主轴转出。不得写成股权转让。

### 节点 2　范围与排除负债

列入资产逐项。排除负债必须明示。不得写“与业务有关的债务随资产走”。

### 节点 3　合同、许可、人员接口

合同转让需对方同意。许可重办接口。人员转劳动。

### 节点 4　对价、交割与风险负担

交付、权属转移、风险负担、同时履行。未知对价写机制不写零。

### 节点 5　不可逆提示

待签署。交付不等于全部许可已承继。

## 停止与安全

- `整体停止`：立场冲突；阴阳价；把已知负债写成已排除却让买方默示承担。
- `字段停止`：债务转移、物权变动、许可承继未核验。
- `目标停止`：主目标变为股权 SPA 或房地产买卖。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `草案、待签署、停止`。边界见 [路由](references/routing.md)。
