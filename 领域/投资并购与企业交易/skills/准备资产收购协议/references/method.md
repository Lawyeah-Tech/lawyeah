# 起草方法

本文件是可执行判断节点，不是栏目说明书。每个会改变资产范围、负债排除或转让交割结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

资产收购协议的核心是范围和负债切割，不是把股权 SPA 改个标题。一般买卖合同审查起草搁置，但交易项下资产购买协议留在本领域。

## Q# 条款块矩阵

固定列：`编号｜块｜列入／排除｜同意／重办｜交割动作｜风险｜状态`。

有形资产、知识产权、合同、债权、排除负债、或有负债分列。

---

## 节点 0　闸

1. 路径不是资产 → 负触发。
2. 土地房屋主轴 → 房地产。
3. 一般商品买卖审查 → 搁置。

## 节点 1　范围

1. 清单附件。盘点差异机制。
2. 在途存货、发票、票据分列。

## 节点 2　负债

1. 明示承担的负债白名单。其余排除。
2. 法定随附义务待核，不得一口排除劳动法或税法强制债务。劳动方案仍转劳动。

## 节点 3　转让

1. 合同同意、通知、许可重办作为条件。

## 节点 4　物权

1. 动产交付、登记财产登记。未核验物权变动规则则字段停止。

## 节点 5　安全

1. 禁止阴阳价。禁止无证经营过渡。

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 标题改成资产收购 | 公司全部债务已留下 |
| 房地产项目 | 本任务可代替房地产专项 |
| 草案 | 已经交付并取得权属 |
| 一般买卖审查 | 本任务主成果 |

---

## 条件句

if 路径未定 → 负触发
if 房地产主轴 → 负触发
if 负债排除与强制债务冲突未核验 → 排除字段停止
if 阴阳价 → 整体停止

---

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 债务不随资产自动走。 |
| 2 | 合同和许可需逐项转让或重办。 |
| 3 | 房地产主轴转出。 |
| 4 | 草案不得写成已交付。 |

---

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按路径闸、负债切割、许可、物权变动排序。股权 SPA、房地产、劳动、一般审查只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。
