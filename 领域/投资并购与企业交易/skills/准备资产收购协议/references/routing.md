# 边界与路由

## 正触发

已定资产路径，需发送前资产购买协议；起草方。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 路径未定 | 评估投资并购交易结构 |
| 合资或剥离路径 | 评估合资设立与资产剥离路径 |
| 股权收购协议 | 准备股权收购协议 |
| 房地产买卖主轴 | 房地产领域 |
| 一般买卖审查起草 | 审查起草领域（本窗搁置） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 经营者集中申报、竞争限制专项 | 竞争法领域 |
| 借贷、保证、抵押质押、保理、融资租赁主轴 | 金融领域 |
| 日常章程、股东会、董事会或一般股东争议 | 公司治理领域 |
| 劳动尽调、员工转移、安置方案本身 | 劳动领域 |
| 环境许可、资源权利、能源监管专项尽调 | 环境能源领域 |
| 境外法适用、ODI、制裁、跨法域准入整体 | 涉外领域 |
| 税负测算、税务架构或稽查应对 | 税务领域 |
| 破产、重整、清算程序内投资 | 破产领域 |
| 一般买卖服务合作签前审查起草 | 审查起草领域（本窗搁置） |
| 证券发行、持续信息披露正文或重组报告书 | 证券监管专项，未核验则字段停止或 `unavailable` |

## 易混

已定买资产／业务、要发送前协议时正触发。其实是买股权，或土地房屋是主标的时负触发。
