# 起草方法

本文件是可执行判断节点，不是栏目说明书。每个会改变保密范围、例外或归还销毁结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

交易专项保密不是一般商务 NDA 审查生产线。审查起草领域本窗搁置。C 端保密协议只分流。

---

## Q# 条款块矩阵

固定列：`编号｜条款｜目的限制｜范围｜例外｜期间｜救济｜状态`。

单方披露与互相披露分列。不得写成已签署。

---

## 节点 0　分流

1. 一般签前 NDA 审查 → 审查起草搁置。
2. C 端大众保密协议 → 只分流。
3. 资料室权限 → 买方或卖方资料室原子。

## 节点 1　范围

1. 信息定义过宽至公共领域：标买方／接收方风险。
2. 个人信息单独最小化。

## 节点 2　例外

1. 强制披露应尽量预先通知并争取保密处理。
2. 不得用例外掏空保密义务，也不得写零例外。

## 节点 3　非锁定

1. 保密安排不构成必须成交。排他另项。

## 节点 4　救济

1. 停止侵害、销毁、损害赔偿接口。金额未知不写。

## 节点 5　安全

1. 禁止用于内幕交易或套取无关商业秘密。

---

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 发出保密稿 | 已经生效 |
| 一般 NDA 审查 | 本任务主成果 |
| C 端模板 | 可直接当并购保密安排 |
| 保密条款 | 已经排他锁定交易 |

---

## 条件句

if 主成果是一般 NDA 审查 → 负触发，搁置
if C 端无交易背景 → 只分流
if 用于内幕或套取无关秘密 → 整体停止
if 草案当已生效 → 文本状态纠回待签署

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按违法使用、范围过宽、成立事实排序。一般审查、C 端、资料室、排他只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

文本状态保持待签署。
