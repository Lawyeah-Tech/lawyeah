# 边界与路由

## 正触发

接触资料前需交易专项保密。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 一般 NDA 审查起草 | 审查起草领域（本窗搁置） |
| C 端保密协议 | C 端专项只分流 |
| 买方资料室规则 | 准备尽调资料清单与资料室规则 |
| 卖方资料室 | 准备卖方资料室与披露控制 |
| 排他谈判 | 准备排他谈判与冻结安排 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 经营者集中申报、竞争限制专项 | 竞争法领域 |
| 借贷、保证、抵押质押、保理、融资租赁主轴 | 金融领域 |
| 日常章程、股东会、董事会或一般股东争议 | 公司治理领域 |
| 劳动尽调、员工转移、安置方案本身 | 劳动领域 |
| 环境许可、资源权利、能源监管专项尽调 | 环境能源领域 |
| 境外法适用、ODI、制裁、跨法域准入整体 | 涉外领域 |
| 税负测算、税务架构或稽查应对 | 税务领域 |
| 破产、重整、清算程序内投资 | 破产领域 |
| 一般买卖服务合作签前审查起草 | 审查起草领域（本窗搁置） |
| 证券发行、持续信息披露正文或重组报告书 | 证券监管专项，未核验则字段停止或 `unavailable` |

## 易混

接触并购资料前要一份交易专项保密稿时正触发。要审查对方普通 NDA 或只要 C 端模板时负触发。
