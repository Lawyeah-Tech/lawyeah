# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变权属链、负担或对抗效力结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

不能因卖方未提供查询结果而推定清洁。房地产、在建工程、建设用地使用权主轴转房地产。

---

## P# 权属负担矩阵

固定列：`编号｜标的｜取得依据｜名册／登记｜负担类型｜权利人｜对抗效力待核｜解除路径｜判断`。

股权与资产分行。多项负担不得合成“有点瑕疵”。

---

## 节点 0　分流

1. 土地使用权、房屋、在建工程主轴 → 房地产。
2. 完整报告 → `形成法律尽调报告`。
3. 一般买卖合同审查 → 本窗搁置。

## 节点 1　权属链

1. 每一手取得：协议、入股、继承、司法裁定、增资。
2. 名册与登记冲突并列。
3. 代持只标红旗，转清理原子，不裁定权属。

## 节点 2　负担

1. 股权出质看登记；账户或股权冻结看司法协助通知。
2. 资产抵押、动产融资、所有权保留、融资租赁分列。
3. 未检索不得写“未见负担”。

## 节点 3　对抗

1. 未经登记不得对抗善意第三人是接口，不是过户保证。
2. 不得写本任务完成后一定能解押或解封。

## 节点 4　解除路径

1. 解押、执行和解、提存、交割条件分列，金融担保文件转金融。

## 节点 5　下一步

1. 否决级负担转 `评估交易否决级红旗`。

---

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 未做查询 | 权属清洁 |
| 房地产证未核 | 本任务已替代房地产专项 |
| 有质押 | 一定不能做交易 |
| 登记将提交 | 已经可以对抗第三人 |

---

## 条件句

if 房地产权利是主轴 → 负触发
if 查询未完成 → 无负担结论不得输出
if 用户要求隐瞒冻结 → 整体停止
if 只要报告终稿 → 负触发

---

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 缺失查询不得写成清洁。 |
| 2 | 对抗效力待核，不保证过户。 |
| 3 | 房地产专项转出。 |
| 4 | 代持不在本任务裁定。 |

---

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按断链、冻结、未查询、解押可行性排序。报告、房地产、金融解押文件只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

本成果不是他项权利注销保证。
