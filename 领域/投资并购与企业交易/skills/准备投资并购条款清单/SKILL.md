# 准备投资并购条款清单

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“发送前条款清单／意向书包”：交易要点、拘束力分账、排他／保密／费用条款、预约或本约风险和发送前状态。

`depends-on` 为空。本任务只形成待发送材料，不执行发送，不把签署条款清单写成 SPA 已成立。

## 工作边界

正触发：路径已有初步共识或需要把关键商业和法律条件写成条款清单或意向书。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 已决定出 SPA 或只要 SPA 正文；
- 只要评估拘束力、不出稿；
- 只要交割包或集中申报；
- 一般合同审查起草（本窗搁置）；
- C 端无争议小微转让材料。

## 建立出稿坐标

确认：使用者与授权；单方立场；路径；拟约束条款；拟发送日；相对方；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 既有 TS／纪要；`C#` 拟写入条款；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`B#` 拘束力分类；`V#` 文本版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。文本状态只用 `草案`、`待发送`、`停止`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典第 495 条、合同编通则解释第 6 条及公司路径规则；`search_template` 只借栏目。工具不可用时继续分账，预约／本约结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [出稿方法](references/method.md) 为准。

### 1. 分流、立场和发送闸

路径完全空白且用户拒绝任何假设时，不得把商业愿景写成已合意条款。

### 2. 拘束力分账

保密、排他、费用、准据法、终止权与商业条款分开。禁止“标题写非约束力即无责任”。

### 3. 交易要点正文

结构、对价机制、条件、交割、对赌接口。未知数字不写零。

### 4. 预约或本约风险

主体、标的、价款是否已足以构成本约或预约。已构成本约则目标停止，转 SPA 或效力评估。

### 5. 发送前状态和不可逆提示

成果保持 `待发送`。签署可能锁定排他和费用。

## 停止与安全

- `整体停止`：立场冲突；用户要求倒签或用条款清单规避国资进场。
- `字段停止`：拘束力规则未核验。
- `目标停止`：主目标已变为 SPA 或本约已成立。
