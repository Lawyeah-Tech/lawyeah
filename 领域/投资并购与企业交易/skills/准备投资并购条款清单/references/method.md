# 出稿方法

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得把“非约束力”标题写成零责任。不得把条款清单写成已签署 SPA。

运行时核验民法典第 495 条和合同编通则解释第 6 条。核验失败则拘束力结论字段停止，条款分账继续。失效合同法不得写入 `L#`。

---

## 节点 0　分流

if 用户只要 SPA → 转 `准备股权收购协议`。  
if 一般买卖服务意向、与投资并购无关 → 审查起草搁置。  
if 国资必须进场，用户要用私签 TS 锁定成交价规避公开交易 → 整体停止。

---

## 节点 1　发送闸

1. 固定单方立场和授权。无授权不得标 `待发送`。
2. 至少能写出：当事方称呼、标的方向（股权／资产／增资）、交易意向。三者全缺则不出终稿。
3. 对价数字未知：写确定机制，不写零，不编估值。

---

## 节点 2　拘束力分账

对每一条拟写条款判定 `B#`：

| 条款类型 | 默认处理 |
| --- | --- |
| 保密、资料归还 | 通常应标有拘束力 |
| 排他／冻结谈判 | 通常应标有拘束力，并写期限和例外 |
| 费用分担、分手费意向 | 写明是否现在即有拘束力；含糊则 `依据不足` |
| 准据法、争议解决、通知 | 程序条款可单独有拘束力 |
| 结构、对价、R&W、赔偿 | 默认为商业意向，除非已具备本约要素 |
| “善意协商” | 不得写成可强制成交 |

if 文本已写明将来一定期限内订立本约，且主体、标的可确定 → 预约风险必须明示（第 495 条）。  
if 标的、数量、价款等主要内容已合意，且未保留另行订立本约，或已有履行被接受 → 本约风险，目标停止出“无拘束力 TS”，转 SPA 或效力评估。

禁止用“本意向书不构成合同”一句覆盖已经具备本约要素的条款。冲突必须并列给用户。

---

## 节点 3　交易要点

必须覆盖：路径、标的范围、对价机制（固定／锁箱／交割账／或有）、拟交割条件家族、先签后交与否、排他期限、资料使用、终止。对赌只写主体是股东还是公司及“效力待核”，不写成当然有效。

经营者集中、外资、国资只做红旗，不把“双方负责办完所有批准”写成已满足。

对外转让不得把过半数同意写成现行默认。

---

## 节点 4　发送前正文规则

逐句回链来源。不倒签。不把草案写成已签署。范本只借栏目。数字与机制冲突时并列，不取平均。

---

## 节点 5　不可逆提示

签署有拘束力的排他或费用条款后，再谈其他买方或无故退出可能触发预约违约或约定责任。本任务不执行发送。禁止伪造对方已同意排他。
