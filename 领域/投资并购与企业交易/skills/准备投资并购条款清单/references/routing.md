# 边界与路由

## 正触发

需要把投资并购的结构、对价、条件和拘束力条款写成发送前条款清单或意向书。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 股权收购协议 | `准备股权收购协议` |
| 只判断已签 TS 的拘束力 | 未安装则 `unavailable`，本任务可做分账但不改写成效力鉴定终局 |
| 交易结构总图 | `评估投资并购交易结构` |
| 审查对方已拟 TS | `审查对方交易文件` |
| 一般买卖意向书审查 | 审查起草领域（搁置） |

## 易混

商业条款未齐但仍要锁排他和保密时正触发。主体、标的、价款已闭合且未保留“另行订立本约”时，应停止本约化出稿并转 SPA。
