# 谈判方法

本文件是可执行判断节点，不是栏目说明书。每个会改变底线、弃权范围或执行力结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

投后和解服务交易契约收口。已谈拢文本、普通诉讼和解分别转出。不写必得金额。

---

## Q# 方案矩阵

固定列：`编号｜争点｜我方底线｜可让步｜交换｜弃权范围｜执行力红旗`。

赔偿、调价、对赌、提存分列。

---

## 节点 0　分流

1. 已谈拢正文 → 另项（本任务停止出稿）。
2. 无交易背景的和解 → 合同争议。

## 节点 1　底线

1. 授权不明不得建议让步。

## 节点 2　弃权

1. 已知请求可弃。未知欺诈、人身侵权、监管责任不得概括弃。

## 节点 3　公司付款

1. 资本维持闸。分期加担保接口。

## 节点 4　保密与不贬损

1. 不得阻碍依法举报。

## 节点 5　安全

1. 禁止用和解转移赃款或抽逃。

---

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 谈得拢 | 已经和解并已履行 |
| 双方都烦了 | 可以同时给两边方案 |
| 普通买卖和解 | 本任务主成果 |
| 公司没利润也一次付清对赌 | 当然可执行 |

---

## 条件句

if 同时服务双方 → 整体停止
if 已要正文终稿 → 负触发
if 一般和解无交易 → 转争议
if 概括放弃欺诈或监管责任 → 删除该弃权

---

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 强制单方。 |
| 2 | 弃权必须特定。 |
| 3 | 不写已谈拢正文。 |
| 4 | 公司付款须过资本维持。 |

---

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按双边策略、概括弃权、抽逃、正文边界排序。正文另项、一般和解、金融担保只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

本成果不是和解协议终稿，也不是已履行证明。
---

## 补充条件句与停止

if 同时为双方输出谈判策略 → 整体停止。  
if 已谈拢只要和解协议正文 → 负触发，本任务不出终稿。  
if 无交易投后背景的普通诉讼和解 → 负触发，转合同争议领域。  
if 弃权条款概括放弃未知欺诈、人身损害或监管责任 → 删除该弃权。  
if 以公司资金履行对赌或赔偿而资本维持未核验 → 执行力字段停止。  
禁止用和解设计抽逃或转移违法资金。
