# 起草方法

本文件是可执行判断节点，不是栏目说明书。每个会改变流向、同时履行或回退结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

资金流向必须可追溯到交易对价和合法债务。禁止阴阳价。融资提款通知转金融。

---

## Q# 流向矩阵

固定列：`编号｜金额机制｜付款人｜收款人／账户｜时点｜对应交付｜失败回退｜状态`。

未知金额留空，不写零。

---

## 节点 0　禁止

1. 阴阳价、拆分私人账户逃税逃汇逃执行 → 整体停止。

## 节点 1　主体

1. 账户名称必须匹配收款主体或经书面指定且合法。

## 节点 2　同时履行

1. 见文件付款、见付款交章分列风险。

## 节点 3　提存

1. 与提存原子接口。

## 节点 4　跨境

1. 外汇登记待核，未核验则跨境字段停止。

## 节点 5　状态

1. 指令不是到账证明。

---

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 指令写完 | 钱已经到账 |
| 两套价格 | 可以做 |
| 贷款放款通知 | 本任务主成果 |
| 账户是法定代表人私人 | 当然可以 |

---

## 条件句

if 阴阳价或洗钱 → 整体停止
if 融资文件主成果 → 负触发
if 账户与主体不符且无合法指定 → 该笔停止
if 金额未知 → 留空不写零

---

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 禁止阴阳价和洗钱。 |
| 2 | 融资放款转金融。 |
| 3 | 指令不等于到账。 |
| 4 | 账户须匹配主体或合法指定。 |

---

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按违法资金、账户权属、同时履行排序。金融、提存、交割确认只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

状态保持待执行。
---

## 补充条件句与停止

if 出现两套价格、拆分私人账户逃税逃汇或逃避执行 → 整体停止。  
if 主成果是贷款提款通知或担保放款 → 负触发，转金融领域。  
if 收款账户名称与主体不符且无合法书面指定 → 该笔流向停止。  
if 金额未知 → 留空，不写零。  
指令已发出不等于资金已到账；到账必须另有凭证。
