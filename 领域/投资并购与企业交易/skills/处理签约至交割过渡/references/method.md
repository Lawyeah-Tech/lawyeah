# 处理方法

本文件是可执行判断节点，不是栏目说明书。每个会改变过渡契约、信息权或禁止事项结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

空档期卖方通常仍控制公司。买方保护靠契约和信息，不靠提前接收印鉴对抗第三人。

---

## Q# 过渡契约矩阵

固定列：`编号｜义务｜主体｜例外｜监控｜违反后果｜与锁箱关系｜判断`。

经营、处置、分配、人事、合同、许可分列。

---

## 节点 0　定性

1. 签署日、交割日分列。不得写已交割。

## 节点 1　经营

1. 普通过程须定义。超出须买方同意。

## 节点 2　泄漏

1. 与锁箱定义对照。无锁箱仍可设禁止清单。

## 节点 3　信息

1. 定期报表、重大事项通知。上市内幕红旗。

## 节点 4　监管

1. 卖方须继续推进批准申请。不正当阻却接口。

## 节点 5　安全

1. 禁止提前抢章。

---

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 已经签约 | 已经是股东并可对抗第三人 |
| 空档很长 | 买方可以先接管印章 |
| 交割后 TSA | 本任务主成果 |
| 日常经营制度 | 本任务主成果 |

---

## 条件句

if 把签署当交割 → 纠正并字段停止相关结论
if 抢章 → 整体停止
if 主成果是交割后 TSA → 负触发
if 上市内幕风险 → 信息权字段限制

---

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 签署≠交割。 |
| 2 | 不指导提前抢章。 |
| 3 | 泄漏保护与锁箱对齐。 |
| 4 | 交割后 TSA 另项。 |

---

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按抢权、泄漏、监管申请、内幕排序。交割包、TSA、终止通知只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

本成果不是交割完成证明。
---

## 补充条件句与停止

if 把签署日写成已交割或已取得股东权利 → 纠正该表述，相关结论停止。  
if 用户要求空档期内先接管印章对抗第三人 → 整体停止。  
if 主成果是交割后 TSA → 负触发，转过渡服务原子。  
if 目标或买方为上市公司 → 信息权须避开内幕滥用，披露字段停止或转上市原子。  
泄漏清单应与锁箱定义对照；无锁箱仍须列出禁止分红、掏空和异常负债。
