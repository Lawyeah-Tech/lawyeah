# 准备过渡服务安排

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“发送前过渡服务安排”：发送前 TSA 范围、期限、收费、退出

`depends-on` 为空。接受用户、律师、财务顾问或其他来源的等价事实、估值、清单和文本。本任务不把未核验规则写成已闭合结论。

## 工作边界

正触发：交割后仍需卖方提供系统、人员或采购过渡。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 劳动派遣或用工方案；
- 把 TSA 写成长期经营承包而无交易背景；
- 一般服务合同审查起草（本窗搁置）；
- 代替交割包；

本任务劳动派遣／用工转劳动，不给成交率或胜诉率。

## 建立出稿坐标

确认：使用者与授权；单方立场；依赖的系统、采购、场所；拟定期限；收费机制；退出迁移；法域；当前磋商、文本、审批或交割状态；关键材料及缺失。

同时掌握买卖双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 陈述；`D#` 依赖清单；`C#` SPA；`L#` 已核验规则；`I#` 判断；`Q#` 服务项；`V#` 版本

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验服务合同和数据／个人信息接口；劳动条款只标转出；不虚构审批系统、案号或登记回执。

工具不可用时继续按依赖清单出受限草案；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [起草方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　分流

用工、派遣、社保转劳动。一般服务合同审查搁置。本任务仅交易过渡。

### 节点 2　范围

系统、财务、采购、仓储、品牌过渡分列。不得写成无限兜底。

### 节点 3　服务水准与收费

水准、故障、收费、税务发票。未知收费写机制不写零。

### 节点 4　数据、许可、退出

数据迁移、分许可、期限、提前终止、迁移协助。

### 节点 5　人员接口

卖方员工继续提供服务的用工关系转劳动，本任务只写服务界面。

## 停止与安全

- `整体停止`：立场冲突；用 TSA 掩盖无证经营或劳动派遣规避。
- `字段停止`：数据出境、分许可、用工定性未核验。
- `目标停止`：主目标变为劳动方案或一般服务审查。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `草案、待签署、停止`。边界见 [路由](references/routing.md)。
