# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变清理路径、其他股东同意或登记对抗结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

本任务服务交易交割前的清理可行性，不裁定隐名与显名之间的权属。C 端 034 只分流。不得把代持清理写成已经完成过户。

---

## P# 清理路径矩阵

固定列：`编号｜路径｜前提｜其他股东｜优先购买｜登记节点｜对交割顺序｜支持事实｜不利事实｜判断`。

`P-显` 实际出资人显名；`P-还` 还原后转让；`P-直` 显名股东直接转并披露。不得合成“把代持处理一下”。

---

## 节点 0　分流

1. 只要确权判决 → 不实施，C 端 034 只分流或转争议。
2. 日常股东资格之诉 → 公司治理。
3. 代持为规避负面清单、限售或国资 → 整体停止。

## 节点 1　事实

1. 协议、转账、税务、表决授权、知情股东范围分列。
2. 公司和其他股东是否同意实际出资人显名，是独立事实。

## 节点 2　路径

1. 显名通常需要公司其他股东过半数同意等现行要件，必须核验，不得用旧司法解释口诀代替。
2. 还原后转让仍走优先购买。
3. 显名股东直接转让：买方知情代持的风险必须写入，不认定善意。

## 节点 3　对抗

1. 名册记载与登记分列。
2. 不得写清理协议一签就对抗质押权人或后续买受人。

## 节点 4　与交易文件

1. 清理完成应否作为交割条件必须可见。
2. 不得把未清理的代持写成无权利负担。

## 节点 5　下一步

1. 股权图转 `梳理目标公司股权与组织`。
2. 优先购买转相应原子。出 SPA 转介。

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 有代持协议 | 实际出资人已经是股东并可直接卖给买方 |
| C 端 034 名称相近 | 本任务可实施其成果 |
| 其他股东尚不知情 | 可以先过户再告知 |
| 代持为规避外资限制 | 可以设计更隐蔽的代持 |

---

## 条件句

if 代持用于规避准入、国资或限售 → 整体停止
if 用户只要权属判决 → 负触发
if 其他股东同意事实缺失 → 显名路径判断依据不足
if C 端大众代持咨询且无交易交割目标 → 只分流

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 不裁定隐名股东权属终局。 |
| 2 | 显名、还原、直接转三条路径分账。 |
| 3 | 登记对抗和善意不得在本任务认定。 |
| 4 | 规避型代持整体停止。 |

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按规避违法、权属冲突、其他股东、优先购买排序。确权诉讼、C 端 034、日常治理只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

本成果不是确权判决或过户保证。
