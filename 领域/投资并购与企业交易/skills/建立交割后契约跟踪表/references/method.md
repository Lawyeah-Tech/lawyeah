# 起草方法

本文件是可执行判断节点，不是栏目说明书。每个会改变日历项、责任人或逾期后果结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

跟踪表是管理工具，不改变实体权利。日常股东会／董事会运行转公司治理。

## Q# 契约日历

固定列：`编号｜义务｜条款｜起算｜届满｜责任人｜证据｜逾期后果｜状态`。

法定期间与约定期间分列。

---

## 节点 0　分流

1. 日常会议年历 → 公司治理。
2. 能否索赔 → 投后赔偿评估。
3. 控制权交接计划 → 交接规划原子。

## 节点 1　列入

1. 交割备忘保留项必须转入。

## 节点 2　起算

1. 交割日、通知日、发现日分列，冲突建并行。

## 节点 3　后果

1. 通知逾期可能失权：标红旗，不擅自宣布已失权。

## 节点 4　劳动环境税

1. 只留节点，专项转出。

## 节点 5　安全

1. 禁止伪造履行勾选。

---

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 做了跟踪表 | 义务已经履行 |
| 日常董事会年历 | 本任务主成果 |
| 通知时限可能过了 | 请求权已经消灭（无核验） |
| 赔偿评估 | 本任务主成果 |

---

## 条件句

if 日常治理主成果 → 负触发
if 无凭证勾已完成 → 整体停止或删除该勾
if 起算不清 → 届满字段停止
if 主成果是赔偿终局 → 负触发

---

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 不接管日常治理。 |
| 2 | 跟踪≠已履行。 |
| 3 | 起算不清不得宣布失权。 |
| 4 | 专项只留节点。 |

---

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按伪造履行、起算、治理边界排序。治理、赔偿评估、交接计划只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

本成果不是履行完毕证明。
---

## 补充条件句与停止

if 主成果是日常股东会或董事会年历 → 负触发，转公司治理。  
if 无凭证将义务勾成已履行 → 删除该勾选或整体停止。  
if 通知时限起算日冲突 → 建并行情景，不得宣布请求权已消灭。  
if 主成果是赔偿能否成立的终局判断 → 负触发，转投后赔偿评估。  
跟踪表是管理工具，不改变实体权利，也不构成履行完毕证明。
