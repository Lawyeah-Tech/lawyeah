# 起草方法

本文件是可执行判断节点，不是栏目说明书。每个会改变通知正文、时限或提存抵扣接口结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

投后赔偿通知以评估闭合为前提。depends-on 为空，用户可提供等价评估。未闭合则目标停止。

---

## Q# 通知请求矩阵

固定列：`编号｜被违反条款｜事实｜损失状态｜时限｜提存／抵扣｜是否写入`。

与价格调整、对赌请求分列，避免重复计算。

---

## 节点 0　闸

1. 无评估且材料明显不足 → 转 `评估投后赔偿与或有对价请求`。

## 节点 1　时限

1. 发现日、交割日、生存期并行情景。

## 节点 2　正文

1. 特定化。禁止“一切损失请赔偿”。

## 节点 3　程序

1. 第三人索赔控制、抗辩参与权按条款列入。

## 节点 4　到达

1. 约定渠道。

## 节点 5　安全

1. 禁止虚构。

---

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 发出通知 | 已经获得赔偿 |
| 评估还在进行 | 可以出终稿 |
| 对方来通知要抗辩 | 本任务主成果 |
| 起诉状 | 本任务主成果 |

---

## 条件句

if 评估未闭合 → 不得出终稿
if 虚构损失 → 整体停止
if 主成果是抗辩 → 负触发
if 交割失败索赔 → 负触发

---

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 评估未闭合不得出终稿。 |
| 2 | 不写必得金额。 |
| 3 | 发送≠已获赔。 |
| 4 | 与调价／对赌分列。 |

---

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按发送闸、时限、虚构排序。评估、抗辩、起诉、调价通知只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

## 补充条件句与停止

if 投后赔偿评估或等价材料未支持发出 → 目标停止，不得出终稿。  
if 生存期或通知期可能届满 → 揭示失权风险，不得把准备发送写成已保全。  
if 主成果是应对方通知 → 负触发，转应对原子。  
if 同一事实同时构成调价和对赌 → 分列，禁止重复计入已确定应付。  
禁止虚构损失。文本状态保持待发送。
