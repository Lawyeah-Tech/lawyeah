# 准备股权收购协议

## 任务目标

在明确、无利益冲突的单方立场下，形成“发送前股权收购／转让协议包”：主体与标的、对价与支付、先决条件、陈述保证与披露接口、赔偿与留扣、交割和名册／登记配合。

`depends-on` 为空。本任务只形成待签署草案，不执行签署或登记，不把草案写成已生效。

## 工作边界

正触发：已定或可支持股权路径，单方需要发送前股权收购或股权转让协议。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 资产收购主路径；
- 只要审查对方已拟文本；
- 权属清楚、无对赌国资上市跨境控制权争夺的普通有限公司转让材料（C 端分流）；
- 只要交割包或集中申报；
- 一般买卖合同起草（本窗搁置）。

## 建立出稿坐标

确认：使用者与授权；起草立场；目标公司类型；标的股权（认缴／实缴／比例）；对价机制；章程和股东协议限制；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 尽调或名册材料；`C#` 章程／股东协议／TS；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 条款块；`V#` 协议版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。文本状态只用 `草案`、`待签署`、`停止`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验公司法第 84、86、88 条及登记对抗规则；`search_template` 只借栏目。工具不可用时继续按事实出受限草案，对外转让程序和法律效果字段停止。

## 五个判断节点

执行顺序和停止条件以 [起草方法](references/method.md) 为准。

### 1. 分流、路径和发送闸

资产路径、C 端小微转让、对方文本审查负触发。股权路径未闭合不得出可签署终稿。

### 2. 标的、出资和优先购买

认缴与实缴分列。对外转让按第 84 条和章程，不用旧法第 71 条默认。第 88 条时点必须可见。

### 3. 对价、条件和交割

锁箱／交割账／或有对价分账。签约不等于交割。

### 4. 陈述保证、披露和赔偿

R&W 与披露接口。赔偿篮子、上限、期限只建结构，不写必得金额。

### 5. 名册、登记和不可逆提示

四节点分列。草案不得写成已生效或已对抗第三人。

## 停止与安全

- `整体停止`：立场冲突；阴阳价格；伪造优先购买放弃；绕过冻结质押或国资进场。
- `字段停止`：章程限制、第 88 条时点、登记规则未核验。
- `目标停止`：主目标变为资产协议、交割包或对方文本审查。
