# 边界与路由

## 正触发

已定股权路径，单方需要发送前股权收购或转让协议。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 审查对方文本 | `审查对方交易文件` |
| 条款清单 | `准备投资并购条款清单` |
| 交割包 | `准备交割文件包` |
| 资产收购协议 | 未安装则 `unavailable` |
| 普通无争议小微转让 | C 端股权转让协议与变更准备 |
| 日常增资或章程修订 | 公司治理领域 |
| 经营者集中申报 | 竞争法领域 |

## 易混

控制权交易、对赌、分期交割、先决条件未齐时正触发。只要把姓名金额填进万能模板的小微内部转让负触发。
