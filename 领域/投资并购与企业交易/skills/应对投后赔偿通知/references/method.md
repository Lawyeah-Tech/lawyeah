# 应对方法

本文件是可执行判断节点，不是栏目说明书。每个会改变抗辩、排除或反请求红旗结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

被请求方立场。不自动承认。披露排除须回链披露函，资料室存在不等于已排除，除非约定如此。

---

## Q# 抗辩矩阵

固定列：`编号｜对方请求｜抗辩类型｜依据｜判断｜是否影响提存释放`。

程序抗辩与实体抗辩分列。

---

## 节点 0　收到

1. 通知是否符合形式和时限。

## 节点 1　排除

1. 对照披露函评估或当场对照。

## 节点 2　限额

1. 篮子、免赔、上限、已付。

## 节点 3　损失

1. 因果关系、减损、保险回收。不代精算。

## 节点 4　反请求

1. 只标红旗。

## 节点 5　安全

1. 禁止隐匿相反文件。禁止自动承认。

---

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 收到通知 | 已经责任成立 |
| 资料室有文件 | 当然已排除 |
| 答辩状 | 本任务主成果 |
| 部分可解释 | 必须全部承认或全部否认 |

---

## 条件句

if 未收到 → 负触发
if 用户要一律承认以免麻烦且未授权 → 停止承认策略
if 隐匿文件 → 整体停止
if 主成果是诉状 → 负触发

---

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 不自动承认责任。 |
| 2 | 披露排除须可回链。 |
| 3 | 不写答辩状。 |
| 4 | 反请求只标红旗。 |

---

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按承认越权、隐匿、时限排序。己方发通知、起诉、披露评估只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

本成果不是免责决定。
---

## 补充条件句与停止

if 尚未收到赔偿通知 → 负触发。  
if 用户要求一律承认以免麻烦且无明确授权 → 停止承认策略。  
if 资料室存在某文件但条款未规定资料室即披露 → 不得写成当然排除。  
if 主成果是民事答辩状 → 负触发，转合同争议。  
部分事实可承认，责任不自动成立。金额未知不写零。
