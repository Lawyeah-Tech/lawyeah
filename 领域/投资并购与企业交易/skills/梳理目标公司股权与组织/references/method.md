# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变股权图、出资状态或机关缺口结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

本任务只形成可回链的股权与组织图。名册记载不等于权属终局，登记完成不等于无负担，代持协议不等于可对抗公司和其他股东。

---

## P# 架构矩阵

固定列：`编号｜层｜主体｜持有标的｜比例｜认缴｜实缴｜机关｜负担｜代持疑点｜支持事实｜不利事实｜判断｜待核`。

目标公司、中间层、实际控制人分列。不得合成“老板持股百分之百”一笔。

---

## 节点 0　专项分流

1. 主成果是日常股东会／董事会运行或一般股东争议 → 公司治理领域。
2. 权属清楚的普通有限公司、无对赌国资上市跨境控制权争夺，只要协议和工商材料 → C 端股权转让协议与变更准备。
3. 主成果是裁定代持权属或隐名股东确权之诉 → 不在本任务实施，C 端 034 只分流或转公司治理／争议。
4. 混合信号：交易需要股权图时本任务可留；权属终局和日常治理只作缺口。

## 节点 1　立场、一层与多层

1. 固定单方立场。同时掌握双方秘密或立场不明：整体停止策略输出。
2. 主体名称、统一社会信用代码、登记住所不一致不自动合并。
3. 一层不够时逐层画到标的。持股平台、有限合伙、契约型主体必须单列，不得把执行事务合伙人或普通合伙人写成目标股东本身，除非名册或登记如此记载且已核验。
4. 境外上层只标存在和信息缺口，境外法／ODI 整案转涉外，不在本任务写境外效力。

## 节点 2　认缴、实缴与瑕疵

1. 认缴额、实缴额、出资期限、非货币出资评估状态分列。
2. 实缴凭证、验资或审计、银行回单冲突并列，不选对用户有利的一版。
3. 未届期出资标红旗，不在本任务认定第 88 条责任已经成立。
4. 抽逃、虚假出资线索只标证据缺口和交易影响，不写刑事结论。

## 节点 3　代持、负担和机关

1. 代持协议、资金来源、分红流向、表决权委托并列。没有书面代持不得写成已确认代持，也不得写成已排除代持。
2. 质押、冻结、司法协助、限售只按材料表面列负担表，对抗效力待核。
3. 机关：股东会／董事会人数、任期、是否到期未改选、法定代表人与印鉴控制人是否同一。章程与公司法冲突不自动选章程或选法律，标冲突和待核。
4. 一人公司、职工董事、国有独资董事会特别规则未核验则该机关字段停止。

## 节点 4　冲突处理

1. 名册、章程记载、登记信息和实际表决人不一致时，四套事实并列，不合并为“以登记为准即可交割”。
2. 受让人向公司主张股东权利看名册记载；未经变更登记不得对抗善意相对人。本任务不写过户保证。

## 节点 5　缺口和下一步

1. 按权属不明、负担未解除、代持未清理、机关缺位、登记冲突排序。
2. 代持清理转 `评估交易中的代持清理`；结构总图转 `评估投资并购交易结构`；优先购买转相应原子。

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 名册记载某人为股东 | 隐名股东权属已经裁定 |
| 登记持股百分之百 | 不存在代持或一致行动 |
| 实缴数字未知 | 出资已缴清或出资为零 |
| 有董事会 | 日常治理方案已经设计完成 |

---

## 条件句

if 只有口头股权结构而无名册、章程或登记材料 → 交付待核图，权属和比例字段停止
if 出现代持或资金代付线索 → 标红旗，不裁定权属，提示清理原子
if 多层架构未画到标的 → 不得输出“目标股权清晰”
if 机关任期届满未改选且交易依赖该机关批准 → 批准有效性字段停止
if 用户要求把代持直接写成登记股东 → 整体停止

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 受让人自记载于股东名册时起可向公司主张股东权利；未经变更登记不得对抗善意相对人。 |
| 2 | 认缴与实缴必须分列；未知实缴不得写成已缴清。 |
| 3 | 不得把 2018 年公司法第 71 条过半数同意写成现行对外转让默认。 |
| 4 | 一人公司财产独立、国有独资机关设置未核验则相应字段停止。 |
| 5 | C 端 034 代持专项只分流，不回改、不在本任务实施其成果。 |

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按权属冲突、负担、代持、机关缺位、可逆性排序。出 SPA、确权诉讼、日常治理只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

本成果不是权属判决、治理方案或交易文件。
