# 边界与路由

## 正触发

单独要把目标公司股权、出资、一层／多层架构和机关做成可回链图。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 裁定代持权属 | C 端 034 只分流或不实施 |
| 日常治理或股东争议 | 公司治理领域 |
| 交易结构总图 | 评估投资并购交易结构 |
| 代持清理路径 | 评估交易中的代持清理 |
| 普通无争议小微转让材料 | C 端股权转让协议与变更准备 |
| 一般合同审查起草 | 审查起草领域（本窗搁置） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 经营者集中申报、竞争限制专项 | 竞争法领域 |
| 借贷、保证、抵押质押、保理、融资租赁主轴 | 金融领域 |
| 日常章程、股东会、董事会或一般股东争议 | 公司治理领域 |
| 劳动尽调、员工转移、安置方案本身 | 劳动领域 |
| 环境许可、资源权利、能源监管专项尽调 | 环境能源领域 |
| 境外法适用、ODI、制裁、跨法域准入整体 | 涉外领域 |
| 税负测算、税务架构或稽查应对 | 税务领域 |
| 破产、重整、清算程序内投资 | 破产领域 |
| 一般买卖服务合作签前审查起草 | 审查起草领域（本窗搁置） |
| 证券发行、持续信息披露正文或重组报告书 | 证券监管专项，未核验则字段停止或 `unavailable` |

## 易混

“先画清这家公司谁持股”而权属、代持和机关未闭合时正触发。只要确权判决或只要日常董事会运行时负触发。出现集中申报信号只标红旗，不改写成本任务申报成果。
