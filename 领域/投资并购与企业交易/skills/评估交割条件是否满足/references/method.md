# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变条件满足、放弃或未满足结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出成交率、胜诉率、必然过会、必然交割或唯一必得金额。未知金额不写零。`search_law` 返回已失效《合同法》、2018 年公司法文本或已失效《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

每项 CP 独立判断。集中申报、安全审查、国资批准未完成不得写成可交割，除非该条件已被有权放弃且非强制。

---

## Q# 条件矩阵

固定列：`编号｜条件｜类型｜证据｜满足判断｜可否放弃｜放弃权人｜最强反方`。

监管类、同意类、自身承诺类、融资类分列。融资文件转金融。

---

## 节点 0　分流

1. 交割文件清单 → `准备交割文件包`。
2. 交割日备忘 → `准备交割确认与完成备忘`。
3. 终止 → 终止通知原子。

## 节点 1　证据

1. 口头“批了”不等于满足。须书面或可验证状态。

## 节点 2　强制条件

1. 法律禁止实施的集中或禁止类外资：不可放弃。

## 节点 3　放弃

1. 弃权范围特定。概括放弃全部 CP 标风险。

## 节点 4　阻却

1. 故意不提交申请可能构成不正当阻却，待核。

## 节点 5　安全

1. 禁止伪造批文。

## 分账禁令

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 想交割 | 条件已经满足 |
| 对方没反对 | 未满足的条件已被放弃 |
| 集中申报未获准 | 可以放弃后交割 |
| 本任务表格 | 交割确认已经发出 |

---

## 条件句

if 监管强制条件未完成 → 不得写已满足或可放弃交割
if 伪造批文 → 整体停止
if 主成果是发通知 → 负触发
if 证据不足 → 判断依据不足

## 核验规则

| 序号 | 可执行规则 |
| --- | --- |
| 1 | 未完成不得写已满足。 |
| 2 | 强制监管条件不可放弃。 |
| 3 | 不发交割或终止通知。 |
| 4 | 口头不等于批准。 |

## 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因相对方未提供材料而推定清洁、已放弃、已批准或已到达。

下一步按强制监管、伪造、放弃权限排序。交割包、确认、终止通知、退出评估只写转介。禁止指导抢章、伪造放弃优先购买、阴阳价格、倒签或绕过冻结质押与法定进场。

本成果不是交割确认或终止通知。
