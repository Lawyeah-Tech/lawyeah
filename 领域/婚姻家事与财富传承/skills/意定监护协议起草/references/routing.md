# 边界与路由

## 正触发

成年人当前有完整意思能力并拟预先指定监护人。目标是：为具有完全民事行为能力的成年人形成尊重本人意愿、职责、监督和财产边界清晰的意定监护协议。。

## 入口键

- 入口状态：成年人当前有完整意思能力并拟预先指定监护人
- 最低证据：本人真实意愿、监护人同意、职责和财产边界
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录
- `depends-on` 为空；等价前置成果可以由用户、律师、机构或其他 Skill 提供

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 代替本人作出未经授权的医疗或财产决定 | 负触发，说明排除理由和正确入口 |
| 当事人已丧失或部分丧失民事行为能力 | 最近邻排除 |
| 一般民商事合同审查或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端 109 大众专项同题 | 只分流，不回改 C 端包 |
| 刑事控告、辩护或刑事代理 | 刑事领域 |
| 税务测算、投资产品、公司治理、境外法 | 相应专业领域 |

| 已无能力要认定 | 行为能力认定与恢复特别程序材料 |
| 财富工具选择 | 家庭传承法律问题与转交边界图 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 脱离家庭身份的合同、物权或商事争议 | 一般争议或相应商事领域 |
| 独立人身损害赔偿且非家事保护入口 | 人身损害领域 |

## 易混

意定监护不是现在就把财产交给监护人处分的授权。公证是否必要须核验，不是口头常识。

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
