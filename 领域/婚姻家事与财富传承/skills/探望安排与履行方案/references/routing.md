# 边界与路由

## 正触发

亲子与直接抚养基本确定，争议是探望。目标是：形成兼顾子女安全、稳定和真实意愿的探望时间、交接、监督及履行救济方案。。

## 入口键

- 入口状态：亲子与直接抚养基本确定，争议是探望
- 最低证据：子女状态、既有安排、阻碍或风险事实
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录
- `depends-on` 为空；等价前置成果可以由用户、律师、机构或其他 Skill 提供

## 负触发

| 主要目标 | 路由 |
| --- | --- |

| 争议核心是变更直接抚养 | 最近邻排除 |
| 一般民商事合同审查或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

| 变更抚养 | 变更直接抚养关系方案 |
| 抢夺藏匿 | 抢夺藏匿未成年子女紧急处置 |

## 易混

探望权不是对子女的强制执行标的。不配合探望不等于自动改判抚养。

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
