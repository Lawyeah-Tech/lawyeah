# 边界与路由

## 正触发

已收到配偶扶养请求、起诉材料或明确履行主张，需从义务方立场应对。目标是：由被请求履行配偶扶养义务的一方形成义务基础、实际需要、履行能力和给付范围的答辩材料。。

## 入口键

- 入口状态：已收到配偶扶养请求、起诉材料或明确履行主张，需从义务方立场应对
- 最低证据：婚姻状态、对方实际需要、己方履行能力、既有给付和送达期限
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录
- `depends-on` 为空；等价前置成果可以由用户、律师、机构或其他 Skill 提供

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 作为请求方主张配偶扶养，或处理子女抚养、老年人赡养 | 负触发，说明排除理由和正确入口 |
| 作为请求方提出扶养，或义务基础为子女抚养、老年人赡养 | 最近邻排除 |
| 一般民商事合同审查或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端 109 大众专项同题 | 只分流，不回改 C 端包 |
| 刑事控告、辩护或刑事代理 | 刑事领域 |
| 税务测算、投资产品、公司治理、境外法 | 相应专业领域 |

| 请求方 | 配偶扶养请求方案 |
| 赡养答辩 | 老年人与成年亲属赡养请求答辩方案 |

## 最近邻边界

| Skill | 名称 | 规则 |

| `老年人与成年亲属赡养请求答辩方案` | 老年人与成年亲属赡养请求答辩方案 | 识别到用户核心目标符合该最近邻入口时停止相邻实体扩展并转介；不自动调用。 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 脱离家庭身份的合同、物权或商事争议 | 一般争议或相应商事领域 |
| 独立人身损害赔偿且非家事保护入口 | 人身损害领域 |
| 家庭成员犯罪后的控告、被害人代理或辩护 | 刑事领域 |
| 投资、税务、金融产品、信托公司承做 | 相应财富或税务领域 |
| 境外法、冲突规范、境外资产和跨境执行 | 涉外专项 |
| 审查起草一般合同 | 审查起草领域（本窗搁置） |

## 易混

有收入不等于应承担对方主张的全部金额。分居不是当然免责。

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
