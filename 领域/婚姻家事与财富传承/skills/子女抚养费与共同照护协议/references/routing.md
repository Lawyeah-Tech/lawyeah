# 边界与路由

## 正触发

父母可协商子女给付和照护事项。目标是：为父母形成抚养费项目、支付调整、重大支出、共同决策和履行机制明确的协议。。

## 入口键

- 入口状态：父母可协商子女给付和照护事项
- 最低证据：子女需求、父母负担能力和照护安排
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录
- `depends-on` 为空；等价前置成果可以由用户、律师、机构或其他 Skill 提供

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 排除子女依法请求合理费用的权利 | 负触发，说明排除理由和正确入口 |
| 已经存在拒付或变更争议需诉讼 | 最近邻排除 |
| 一般民商事合同审查或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端 109 大众专项同题 | 只分流，不回改 C 端包 |
| 刑事控告、辩护或刑事代理 | 刑事领域 |
| 税务测算、投资产品、公司治理、境外法 | 相应专业领域 |

| 拒付或调整诉讼 | 抚养费请求与调整材料 |
| 探望为主 | 探望安排与履行方案 |

## 易混

协议不能买断子女未来合理需要。约定比例不是法定上限。

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
