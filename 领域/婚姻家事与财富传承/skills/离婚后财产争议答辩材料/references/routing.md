# 边界与路由

## 正触发

已收到对方起诉、申请或明确请求并需以被告或相对方立场应对。目标是：被告围绕漏分、隐藏、转移或离婚协议财产条款争议形成答辩材料。。

## 入口键

- 入口状态：已收到对方起诉、申请或明确请求并需以被告或相对方立场应对
- 最低证据：离婚依据、争议财产、发现时间和处分线索、对方诉讼材料
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录
- `depends-on` 为空；等价前置成果可以由用户、律师、机构或其他 Skill 提供

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 用户作为原告提起离婚后财产诉讼 | 负触发，说明排除理由和正确入口 |
| 用户作为原告提起离婚后财产诉讼 | 最近邻排除 |
| 一般民商事合同审查或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

| 税务测算、投资产品、公司治理、境外法 | 相应专业领域 |

| 用户作为原告起诉 | 离婚后财产争议诉讼材料 |
| 执行旧义务 | 离婚约定与裁判履行救济 |

## 易混

协议已写“各自名下归各自”不自动覆盖隐藏财产。时效抗辩须有知悉事实。

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
