# 遗嘱起草与订立方案

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是运行本技能的强制依赖。

## 任务与边界

为具备遗嘱能力的自然人形成处分范围、形式、见证、执行和更新机制清晰的遗嘱。

本 Skill 只形成自身约定的成果，不自动调用、组合或替代相邻 Skill，不承诺受理、裁判、登记或执行结果。`dependsOn: []`。

## 渐进式工作

1. **入口核验**：先确认用户身份、代表主体、授权依据、信息披露范围、利益冲突、目标、角色、法域与紧急安全。身份或权限未核验时，只输出通用清单、停止原因和最小补充事项。
2. **事实与程序建模**：入口成立后再读取最小必要材料，分别记录案件事实、相反材料、证据缺口、机关、案号、阶段、送达和期限触发事件。
3. **法律核验与交付**：有 `search_law` 可回链现行法源时形成条件性法律结论；工具未安装、不可用、无结果或冲突时不中断主流程，继续事实与缺口整理，法律结论、期限和机关路径标停止或待核。按需再读取[执行方法](references/method.md)、[输出合同](references/output-contract.md)和[边界与路由](references/routing.md)。

## 最小输入

- 遗嘱人身份、当前能力、沟通和自由真实意愿
- 婚姻亲属、受扶养人和必要份额风险
- 逐项个人财产权属、共有和负担
- 继承人受遗赠人、替代安排和附义务
- 遗嘱执行人、保管和通知意愿
- 既有遗嘱赠与协议、保险信托和跨专业事项
- 用户身份、代表主体、授权依据或未核验状态、信息披露范围和利益冲突状态
- 适用法域、当前日期与时区、案件机关、案号或无案号状态、程序阶段、关键文书和送达期限材料
- 所有材料的可回链位置、来源类别、取得方式、日期及核验状态

只处理完成本成果必要的去标识化摘要。完整文书、未成年人及第三人个人信息不得无目的上传工具。

## 适用前置

1. 先核验入口状态：遗嘱人当前能够表达真实意愿并拟处分个人财产。
2. 最低证据为：身份能力、家庭关系、财产权属、受益安排和既有文书。不足时不得用推测补足。
3. 每项事实区分已核实、单方主张、冲突、尚未提供和无法取得；规则来源不能证明案件事实。
4. 法域、规则版本或关键法源缺失时，只保留事实证据矩阵、待核验问题和停止输出，不给确定法律结论、截止日、机关路径或结果概率。
5. 文书、证据和程序动作均须由用户或合格中国大陆法律专业人员复核后实施。
6. 缺失输入时，每轮只追问一个最可能改变入口、角色、安全分流或成果类型的最小问题；不得一次索取整套材料。

## 执行方法

1. 在订立时点核验遗嘱能力、真实意思、无胁迫欺诈和安全沟通。
2. 逐一核验法定继承人中是否存在缺乏劳动能力且无生活来源者及其必要遗产份额事实，并通过 search_law 核验规则。
3. 必要遗产份额事实不足、冲突或规则未核验时标记待核验／停止，不生成排除或耗尽该份额的确定性处分条款。
4. 逐项确认仅处分遗嘱人的个人财产并标记共有、公司、保险、信托或境外边界。
5. 设计受益、替代受益、附义务和遗嘱执行安排，避免自相矛盾。
6. 根据用户条件选择法定遗嘱形式并核验签名日期、见证资格、过程留痕。
7. 形成文本、订立见证、保管告知和更新撤回清单，不代签或保证绝对有效。

## 高风险停止

- 遗嘱能力、真实意思或无胁迫状态无法核验
- 财产权属不明或要求处分他人财产
- 见证人资格、法定形式或过程留痕无法满足
- 要求隐瞒胁迫、伪造签名日期、代签或替代税务境外法意见
- 要求伪造、篡改、隐匿材料，非法获取信息，规避法定义务或承诺结果
- 身份、授权、利益冲突、法域或会改变结论的程序状态未核验

## 输出

1. 能力意愿和家庭利益核验
2. 处分财产与受益安排表
3. 遗嘱文本草案
4. 订立见证保管与更新清单

所有法律结论只用「现有依据支持」「现有依据不支持」「依据不足，无法形成结论」，逐项绑定事实、相反材料、适用前提、法域、规则版本或生效日、引文与核验时间。没有法源引文时，法律结论字段留空并停止；主流程继续交付事实矩阵、缺口和可处理部分。未知金额不写零。
