# 边界与路由

## 正触发

已经识别一笔或多笔具体债务及主张主体，需要区分债务真实性、对外共同或个人责任、夫妻内部承担、第三人效力、抗辩和证据缺口。

## 入口键

- 立场：债权人、举债配偶、非举债配偶；未明确时先确认。
- 债务颗粒度：每笔具有可区分的主体、金额、形成和交付事实。
- 婚姻与程序状态：形成债务时和当前的婚姻、分居、离婚、诉讼或执行状态。
- 最低证据：债务形成、用途、意思表示和资金流材料；只存在标签时停留在待核验。

## 最近邻边界

- `夫妻财产与债务证据图谱`：没有具体债务，目标是全面寻找、盘点和固定夫妻财产债务线索。
- `复杂夫妻财产分割方案`：债务性质和主要资产已经明确，目标是形成整体财产分割方案。
- 本 Skill 不自动调用或固定组合最近邻；等价前置成果可以由用户、律师、机构或其他 Skill 提供。

## 跨领域停止

公司债务、股东责任、担保效力、破产、执行异议、虚假诉讼刑事风险、税务或境外法需要独立专业判断时，只记录它们对夫妻债务问题的待核验影响和转介对象，不补造相邻领域结论。

## 负触发

没有具体债务、只要求查找全部资产负债、只要求整体离婚分割、只问公司是否承担债务，或要求虚构隐匿债务时，不启动本成果。负触发只说明排除理由和正确入口，不生成相邻成果。
