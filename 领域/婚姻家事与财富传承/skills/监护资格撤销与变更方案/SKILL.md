# 监护资格撤销与变更方案

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是运行本技能的强制依赖。

## 任务与边界

针对怠于履职、侵害、冲突或监护能力变化形成撤销、变更和临时保护材料。

本 Skill 只形成自身约定的成果，不自动调用、组合或替代相邻 Skill，不承诺受理、裁判、登记或执行结果。`dependsOn: []`。

## 渐进式工作

1. **入口核验**：先确认用户身份、代表主体、授权依据、信息披露范围、利益冲突、目标、角色、法域与紧急安全。身份或权限未核验时，只输出通用清单、停止原因和最小补充事项。
2. **事实与程序建模**：入口成立后再读取最小必要材料，分别记录案件事实、相反材料、证据缺口、机关、案号、阶段、送达和期限触发事件。
3. **法律核验与交付**：有 `search_law` 可回链现行法源时形成条件性法律结论；工具未安装、不可用、无结果或冲突时不中断主流程，继续事实与缺口整理，法律结论、期限和机关路径标停止或待核。按需再读取[执行方法](references/method.md)、[输出合同](references/output-contract.md)和[边界与路由](references/routing.md)。

## 最小输入

- 被监护人年龄或出生日期、未成年人／成年人身份、能力状态和真实意愿
- 行为能力认定文书或无文书状态、成年监护或法定监护依据
- 现任监护关系及确定依据
- 申请主体资格与代理授权
- 侵害、失职、能力变化或利益冲突事实
- 即时人身财产风险和临时保护需要
- 替代监护候选、住所、可能受理主体和程序材料
- 用户身份、代表主体、授权依据或未核验状态、信息披露范围和利益冲突状态
- 适用法域、当前日期与时区、案件机关、案号或无案号状态、程序阶段、关键文书和送达期限材料
- 所有材料的可回链位置、来源类别、取得方式、日期及核验状态

只处理完成本成果必要的去标识化摘要。完整文书、未成年人及第三人个人信息不得无目的上传工具。

## 适用前置

1. 先核验入口状态：现有监护人涉嫌侵害、失职或无法履职。
2. 最低证据为：监护关系、风险事实和可行保护或替代方案；被监护人意愿在能够安全取得的范围内记录，无法取得时记录原因和替代证据。不足时不得用推测补足。
3. 每项事实区分已核实、单方主张、冲突、尚未提供和无法取得；规则来源不能证明案件事实。
4. 法域、规则版本或关键法源缺失时，只保留事实证据矩阵、待核验问题和停止输出，不给确定法律结论、截止日、机关路径或结果概率。
5. 文书、证据和程序动作均须由用户或合格中国大陆法律专业人员复核后实施。
6. 缺失输入时，每轮只追问一个最可能改变入口、角色、安全分流或成果类型的最小问题；不得一次索取整套材料。

## 执行方法

1. 先分流撤销监护资格、争议变更、协商或指定变更、临时监护和其他紧急保护，不预设法院为唯一入口。
2. 核验申请主体、受理主体、监护依据、年龄和行为能力认定状态，分别绑定请求、材料与程序。
3. 对撤销监护资格逐项核验现行法定事由：严重损害身心健康；怠于履职；无法履职且拒绝将职责部分或全部委托他人并导致被监护人处于危困状态；同时记录连接条件、相反材料和撤销后监护人确定路径。
4. 现实危险只作为即时安全、临时监护和其他保护分流事实，不单独替代撤销监护资格的法定事由。
5. 即时危险下不得停止安全分流：先提示报警、急救、就医、临时安置，并条件性提示向公安、民政、基层组织、妇联或其他有权机关询问临时保护和人身安全保护令入口。
6. 按未成年人／成年人分流意见：未成年人仅在年龄成熟程度和安全条件允许范围内记录自由表达；成年人记录可安全取得的真实意愿、支持性决策和能力事实来源，不作医疗诊断或能力鉴定。
7. 无法取得意愿、表达受控制或取得本身增加风险时，记录原因、替代性证据和人工复核，不将意愿作为所有分支的绝对前置条件。
8. 意见与安全或法定职责冲突时记录冲突并人工复核，不机械服从或压制。
9. 形成对应分支的撤销或变更申请材料和保护清单，不把财产利益当作监护目的。

## 高风险停止

- 被监护人存在即时危险却未先采取保护
- 申请主体、现任监护依据或受理入口未核验时停止确定性的实体、程序和期限结论，但即时危险下不得停止安全分流
- 目标实际为首次指定监护、行为能力认定或相对方答辩
- 要求控制、处分被监护人财产或压制其真实意愿
- 要求伪造、篡改、隐匿材料，非法获取信息，规避法定义务或承诺结果
- 身份、授权、利益冲突、法域或会改变结论的程序状态未核验

## 输出

1. 监护关系、主体与程序核验
2. 侵害失职和证据矩阵
3. 临时保护与替代监护方案
4. 撤销变更申请材料草案

所有法律结论只用「现有依据支持」「现有依据不支持」「依据不足，无法形成结论」，逐项绑定事实、相反材料、适用前提、法域、规则版本或生效日、引文与核验时间。没有法源引文时，法律结论字段留空并停止；主流程继续交付事实矩阵、缺口和可处理部分。未知金额不写零。
