# 边界与路由

## 正触发

现有监护人涉嫌侵害、失职或无法履职，目标是针对怠于履职、侵害、冲突或监护能力变化形成撤销、变更和临时保护材料。

## 入口键

- 入口状态：现有监护人涉嫌侵害、失职或无法履职
- 最低证据：监护关系、风险事实和可行保护或替代方案；被监护人意愿在能够安全取得的范围内记录，无法取得时记录原因和替代证据
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录

## 最近邻边界

- `行为能力认定与恢复特别程序材料`：识别到用户核心目标符合该最近邻 Skill 的入口条件时停止相邻实体扩展并转介；不自动调用。
- `被监护人财产保护方案`：识别到用户核心目标符合该最近邻 Skill 的入口条件时停止相邻实体扩展并转介；不自动调用。
- 最近邻排除：尚未首次确定行为能力和监护人。
- 本 Skill 独立发展，`dependsOn: []`；等价前置成果可以由用户、律师、机构或其他 Skill 提供。


## 跨领域停止

发现刑事、公司、担保、破产、执行、税务、行政、医疗或境外法等独立专业问题时，只记录其对本成果的影响、待核验事项和转介对象，不补造相邻领域结论。

## 负触发

- 以财产利益替代被监护人最佳利益

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
