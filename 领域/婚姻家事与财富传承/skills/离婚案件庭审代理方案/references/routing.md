# 边界与路由

## 正触发

离婚案件已立案并进入庭前或开庭阶段。目标是：针对已立案离婚案件形成争点、举证质证、询问、辩论和调解响应方案。。

## 入口键

- 入口状态：离婚案件已立案并进入庭前或开庭阶段
- 最低证据：诉辩主张、证据、法院通知和争议焦点
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录
- `depends-on` 为空；等价前置成果可以由用户、律师、机构或其他 Skill 提供

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 代替法院认定事实 | 负触发，说明排除理由和正确入口 |
| 尚未形成诉讼请求和立案材料 | 最近邻排除 |
| 一般民商事合同审查或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端 109 大众专项同题 | 只分流，不回改 C 端包 |
| 刑事控告、辩护或刑事代理 | 刑事领域 |
| 税务测算、投资产品、公司治理、境外法 | 相应专业领域 |

| 尚未立案 | 离婚诉讼原告起诉材料 |
| 安全协商为主 | 离婚谈判与调解方案 |
| 一审已判决 | 家事裁判上诉与审级救济 |

## 最近邻边界

| Skill | 名称 | 规则 |
| --- | --- | --- |
| `离婚诉讼原告起诉材料` | 离婚诉讼原告起诉材料 | 识别到用户核心目标符合该最近邻入口时停止相邻实体扩展并转介；不自动调用。 |
| `离婚谈判与调解方案` | 离婚谈判与调解方案 | 识别到用户核心目标符合该最近邻入口时停止相邻实体扩展并转介；不自动调用。 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 脱离家庭身份的合同、物权或商事争议 | 一般争议或相应商事领域 |
| 独立人身损害赔偿且非家事保护入口 | 人身损害领域 |
| 家庭成员犯罪后的控告、被害人代理或辩护 | 刑事领域 |
| 投资、税务、金融产品、信托公司承做 | 相应财富或税务领域 |
| 境外法、冲突规范、境外资产和跨境执行 | 涉外专项 |
| 审查起草一般合同 | 审查起草领域（本窗搁置） |

## 易混

庭审方案不是判决书。举证期限届满不等于证据必然失权，须运行时核验。

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
