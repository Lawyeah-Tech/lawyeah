# 执行方法

本文件是可执行判断节点，不是栏目说明书。每个会改变效力、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然无效或唯一必得金额。未知金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

入口状态：存在特定婚姻事实或登记状态疑问。
最低证据：身份、登记及共同生活材料。不足时不得用推测补足。
每项事实区分已核实、单方主张、冲突、尚未提供和无法取得；规则来源不能证明案件事实。

## 事实、规则与程序分账

案件事实只从原件或可回链副本、机关正式记录、当事人本人陈述、第三方转述和现场观察取得，并标记核验状态。法律规则另行记录法域、规范名称、版本或生效日、逐项引文、适用前提、核验时间和工具返回标识。程序事实另行记录机关、案号、阶段、关键文书、送达和期限触发事件。三类信息不得互相替代。

## Q# 矩阵

固定列：`编号｜关系假设｜提出方｜相对方｜法律效果｜成立条件｜支持事实｜不利事实｜控制方｜最强反方｜主备位｜判断｜待核`。同一事实支持多项时分别说明效果，不重复金额。

---

### 判断节点 1　主体、登记与成立事实

- If 双方身份、行为能力或登记主体无法核验, then 整体停止效力结论，只保留身份缺口。
- If 存在结婚登记证书或档案摘录, then 把登记日、登记机关、证书编号记为 D#，口头“已经领证”不得写成已登记。
- If 登记材料冲突, then 并列各版本，不选对用户有利的一版冒充唯一登记。
- If 仅有仪式或共同生活而无登记, then 进入事实婚姻或同居边界节点，不得写成有效法律婚姻。
- If 用户同时要求办理结婚登记, then 目标停止，转结婚登记办理原子（P2，本升级包输出 unavailable）。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然无效或唯一必得金额。未知金额不写零。

### 判断节点 2　无效事由核验

- 运行时核验现行民法典婚姻家庭编后再落判断，不得凭记忆写条号当作已核验。
- If 主张重婚, then 分别核验前一婚姻是否仍有效、后一结合是否以夫妻名义、以及是否仅同居。
- If 主张禁婚亲或未达法定婚龄, then 核验亲属计算、出生日期和登记时点；登记后已达婚龄的后果标待核，不直接写成自始有效。
- If 无效事由现有依据不支持, then 不得为追求解除效果改写成可撤销或离婚。
- If 无效事由依据不足, then 效力字段停止，事实时间线继续。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然无效或唯一必得金额。未知金额不写零。

### 判断节点 3　可撤销事由与除斥

- If 主张胁迫结婚, then 核验胁迫行为、意思不自由、结婚与胁迫的因果，以及撤销权人、除斥起算事件。
- If 主张婚前重大疾病未如实告知, then 分列疾病性质、告知义务、对方知悉日和是否仍请求撤销。
- If 知悉日、送达日或除斥起算冲突, then 建并行情景，不给唯一截止日。
- If 除斥可能届满, then 只写条件公式和待核日期，不宣布权利已消灭。
- If 用户要求直接起诉撤销, then 本任务可形成效力评估交接，诉状转婚姻效力诉讼原子。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然无效或唯一必得金额。未知金额不写零。

### 判断节点 4　事实婚姻与同居边界

- If 双方在婚姻登记办法施行前即以夫妻名义共同生活, then 核验当时共同生活、对外名义和截止日期，运行时核验现行衔接规则。
- If 登记办法施行后未登记, then 不得写成事实婚姻，按同居关系记录财产和子女接口。
- If 一方或双方已有有效婚姻, then 后一结合不得评估为有效婚姻。
- If 核心目标是同居财产析产, then 负触发并转同居析产原子。
- If 核心目标是普通离婚, then 先完成本效力闸，有效婚姻才转离婚路径原子。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然无效或唯一必得金额。未知金额不写零。

### 判断节点 5　后果接口与停止

- If 效力判断为现有依据支持无效或可撤销, then 只列子女抚养、财产返还、彩礼、损害赔偿的接口，不在本任务做分割终局。
- If 存在家暴或胁迫仍持续, then 先安全分流，不要求双方共同到场核验。
- If 用户要起草离婚诉状, then 负触发。
- If search_law 不可用, then 效力、期限和机关路径字段停止。
- 禁止承诺法院必然宣告无效或撤销。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然无效或唯一必得金额。未知金额不写零。


## 程序与期限表

程序动作记录机关、案号、文书、作出、收到、送达、效力。期限每行只对应一种期间类型和一个起算事件。关键日期冲突则并行情景，不计算唯一截止日。

## 金额区间表

固定列：项目、性质、期间、参数、来源、已付、未知、互斥／抵扣、范围、专项测算接口。参数不足不输出唯一总额。未知不写零。

## 证据与下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。

下一步按期限灭失、易失证据、改变请求抗辩、可逆性排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。

相邻起诉、答辩、审查起草、税务、刑事或境外法只写转介条件和最小交接。禁止指导伪造、隐匿、威胁或违法取证。一般民商事合同审查起草转介审查起草领域（本窗搁置，只说明不实施）。C 端 109 大众专项只分流、不回改。刑事控告或辩护、税务测算、公司治理、投资金融产品、境外法或跨境执行只记录对本成果的影响并转介，不补造相邻领域结论。

## 工具与降级

- `search_law`：按任务按需核验，不可用时不拒绝执行。
- `search_practiced`：按任务按需核验，不可用时不拒绝执行。
- `search_case_by_filter`：按任务按需核验，不可用时不拒绝执行。

所有工具调用前删除姓名、联系方式、住址、账户、完整文书、可识别家庭关系和第三人秘密。`search_law` 不可用、无结果或冲突时，事实矩阵可以继续，法律结论、期限和机关路径必须停止。
