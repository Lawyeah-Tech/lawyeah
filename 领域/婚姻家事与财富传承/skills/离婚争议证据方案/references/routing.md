# 边界与路由

## 正触发

已识别离婚诉讼争点。目标是：围绕感情、子女、财产债务、过错和救济请求形成事实—证据—证明责任图谱。。

## 入口键

- 入口状态：已识别离婚诉讼争点
- 最低证据：争点、现有材料、证据持有人和时间线
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录
- `depends-on` 为空；等价前置成果可以由用户、律师、机构或其他 Skill 提供

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 指导窃取账户或非法监听 | 负触发，说明排除理由和正确入口 |
| 仅需把既有材料整理进诉状 | 最近邻排除 |
| 一般民商事合同审查或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端 109 大众专项同题 | 只分流，不回改 C 端包 |
| 刑事控告、辩护或刑事代理 | 刑事领域 |
| 税务测算、投资产品、公司治理、境外法 | 相应专业领域 |

| 只要起诉状 | 离婚诉讼原告起诉材料 |
| 家暴证据固定为主 | 家庭暴力证据固定方案 |
| 尚未决定路径 | 离婚路径与请求评估 |

## 易混

证据方案不是诉状。出警记录不是当然的感情破裂唯一证据。非法取得的材料不得写成可用。

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
