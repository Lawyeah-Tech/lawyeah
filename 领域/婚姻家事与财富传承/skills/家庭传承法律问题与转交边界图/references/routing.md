# 边界与路由

## 正触发

用户目标跨越多个家庭身份或传承法律工具且尚未确定单一成果。目标是：识别家庭关系、财产权属、监护与继承目标中的法律问题、冲突、单一工具候选及专业转交边界。。

## 入口键

- 入口状态：用户目标跨越多个家庭身份或传承法律工具且尚未确定单一成果
- 最低证据：家庭关系、目标、资产债务、既有文书、法域和专业约束
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录
- `depends-on` 为空；等价前置成果可以由用户、律师、机构或其他 Skill 提供
