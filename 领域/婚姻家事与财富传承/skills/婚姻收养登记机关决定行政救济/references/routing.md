# 边界与路由

## 正触发

已取得或可识别登记机关的拒绝、错误记载、不予更正等具体处理决定。目标是：针对婚姻或必要收养登记的拒绝、错误记载、不予更正等登记机关决定，识别行政救济入口、期限和材料。。

## 入口键

- 入口状态：已取得或可识别登记机关的拒绝、错误记载、不予更正等具体处理决定
- 最低证据：申请登记材料、登记机关决定或记录、送达时间、身份关系和拟救济事项
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录
- `depends-on` 为空；等价前置成果可以由用户、律师、机构或其他 Skill 提供

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 脱离家庭身份的合同、物权或商事争议 | 一般争议或相应商事领域 |
| 独立人身损害赔偿且非家事保护入口 | 人身损害领域 |

## 易混

登记机关拒绝不是法院宣告婚姻无效。补正档案不是重新结婚。

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
