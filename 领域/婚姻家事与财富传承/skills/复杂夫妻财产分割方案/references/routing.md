# 边界与路由

## 正触发

已知主要财产且目标是形成分割方案。目标是：对房产、股权及其他资产形成家庭法上的财产性质、权属争议和分割请求情景方案。。

## 入口键

- 入口状态：已知主要财产且目标是形成分割方案
- 最低证据：权属、来源、价值、贡献和负担材料
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录
- `depends-on` 为空；等价前置成果可以由用户、律师、机构或其他 Skill 提供

## 易混

财产性质判断不是过户指令。股权家庭法分割不是股权交易。照顾因素不是自动百分比。

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
