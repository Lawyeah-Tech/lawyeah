# 边界与路由

## 正触发

已收到人身安全保护令申请、裁定或送达通知，需依法答辩、复议或请求调整措施。目标是：被申请人围绕保护令事实、措施范围、证据和复议形成程序应对，不接触或报复申请人。。

## 入口键

- 入口状态：已收到人身安全保护令申请、裁定或送达通知，需依法答辩、复议或请求调整措施
- 最低证据：申请书、裁定或送达材料，争议事实，拟提交证据和措施调整主张
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录
- `depends-on` 为空；等价前置成果可以由用户、律师、机构或其他 Skill 提供

| 申请保护令、主张违反保护令，或任何联系报复受保护人的请求 | 最近邻排除 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 脱离家庭身份的合同、物权或商事争议 | 一般争议或相应商事领域 |
| 独立人身损害赔偿且非家事保护入口 | 人身损害领域 |

## 易混

复议保护令不是离婚反诉。否认家暴不是允许继续接触。

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
