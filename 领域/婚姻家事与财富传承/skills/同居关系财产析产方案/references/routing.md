# 边界与路由

## 正触发

共同生活但婚姻效力缺失或不成立。目标是：对未形成有效婚姻的共同生活财产形成权属、贡献、债务与析产方案。。

## 入口键

- 入口状态：共同生活但婚姻效力缺失或不成立
- 最低证据：财产来源、出资、登记和共同生活材料
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录
- `depends-on` 为空；等价前置成果可以由用户、律师、机构或其他 Skill 提供

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 按夫妻共同财产当然平均分割 | 负触发，说明排除理由和正确入口 |
| 双方存在有效婚姻且处理夫妻共同财产 | 最近邻排除 |
| 一般民商事合同审查或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端 109 大众专项同题 | 只分流，不回改 C 端包 |
| 刑事控告、辩护或刑事代理 | 刑事领域 |
| 税务测算、投资产品、公司治理、境外法 | 相应专业领域 |

| 存在有效婚姻 | 复杂夫妻财产分割方案 |
| 婚姻效力不明 | 婚姻成立与效力评估 |
| 只要彩礼返还 | 彩礼返还争议方案 |

## 易混

同居财产不是夫妻共同财产的简化版。登记名不等于出资归零。子女安排不随财产对半分。

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
