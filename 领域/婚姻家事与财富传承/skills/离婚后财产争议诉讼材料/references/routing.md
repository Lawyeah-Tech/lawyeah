# 边界与路由

## 正触发

离婚已完成且存在独立财产争议。目标是：对漏分、隐藏、转移或离婚协议财产条款争议形成起诉和证据材料。。

## 入口键

- 入口状态：离婚已完成且存在独立财产争议
- 最低证据：离婚依据、争议财产、发现时间和处分线索
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录
- `depends-on` 为空；等价前置成果可以由用户、律师、机构或其他 Skill 提供

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 执行已明确的生效给付义务；为被告或相对方形成答辩材料 | 负触发，说明排除理由和正确入口 |
| 仅需执行已明确财产义务 | 最近邻排除 |
| 一般民商事合同审查或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端 109 大众专项同题 | 只分流，不回改 C 端包 |
| 刑事控告、辩护或刑事代理 | 刑事领域 |
| 税务测算、投资产品、公司治理、境外法 | 相应专业领域 |

| 被告应诉 | 离婚后财产争议答辩材料 |
| 执行已明确义务 | 离婚约定与裁判履行救济 |
| 婚姻存续中追回 | 夫妻共同财产不当处分追回起诉 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |

## 易混

离婚后财产诉讼不是执行实施。发现新财产不是自动改判旧判决。

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
