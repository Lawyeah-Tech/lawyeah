# 边界与路由

## 正触发

财产所有人拟在生前向特定家庭成员转移特定财产。目标是：围绕家庭成员间特定财产的赠与、附义务或附条件安排、登记交付、撤销和第三人效力形成法律文书。。

## 入口键

- 入口状态：财产所有人拟在生前向特定家庭成员转移特定财产
- 最低证据：身份能力、财产权属、夫妻共有、债务第三人、条件义务和登记交付材料
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录
- `depends-on` 为空；等价前置成果可以由用户、律师、机构或其他 Skill 提供

## 易混

赠与合同成立不等于物权变动。父母出资购房可能是赠与、借款或共同所有，须分假设。

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
