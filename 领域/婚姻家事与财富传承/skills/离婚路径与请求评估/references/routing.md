# 边界与路由

## 正触发

一方已提出结束婚姻的明确目标，目标是在单一当事人立场下形成协议登记或诉讼路径、请求范围、风险和行动顺序。

## 入口键

- 入口状态：一方已提出结束婚姻的明确目标
- 最低证据：婚姻、子女、财产债务和安全状态概览
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录

## 最近邻边界

- `离婚协议起草`：识别到用户核心目标符合该最近邻 Skill 的入口条件时停止相邻实体扩展并转介；不自动调用。
- `离婚诉讼原告起诉材料`：只有用户要求起草诉状、填写或提交立案材料、代理办理诉讼时转介；仅识别诉讼可能性、评估管辖、请求范围或行动顺序时继续本 Skill。；不自动调用。
- 最近邻排除：双方已达成完整共识仅需起草协议。
- 本 Skill 独立发展，`dependsOn: []`；等价前置成果可以由用户、律师、机构或其他 Skill 提供。

- 仅识别诉讼可能性、评估管辖、请求范围或行动顺序时继续完成本 Skill；只有用户要求起草诉状、填写或提交立案材料、代理办理诉讼时，才转离婚诉讼原告起诉材料。

## 跨领域停止

发现刑事、公司、担保、破产、执行、税务、行政、医疗或境外法等独立专业问题时，只记录其对本成果的影响、待核验事项和转介对象，不补造相邻领域结论。

## 负触发

- 替代具体协议或诉状

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
