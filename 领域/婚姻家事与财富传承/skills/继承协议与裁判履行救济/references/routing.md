# 边界与路由

## 正触发

已有可识别的分割依据且出现未履行。目标是：针对遗产分割协议、调解书或生效裁判未履行形成催告、执行、处分协助和后续救济材料。。

## 入口键

- 入口状态：已有可识别的分割依据且出现未履行
- 最低证据：依据文件、履行记录、到期事实和遗产线索
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录
- `depends-on` 为空；等价前置成果可以由用户、律师、机构或其他 Skill 提供

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 把普通分割协议当然作为强制执行依据 | 负触发，说明排除理由和正确入口 |
| 继承权或遗产归属尚未确定 | 最近邻排除 |
| 一般民商事合同审查或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端 109 大众专项同题 | 只分流，不回改 C 端包 |
| 刑事控告、辩护或刑事代理 | 刑事领域 |
| 税务测算、投资产品、公司治理、境外法 | 相应专业领域 |

| 资格效力未定 | 继承权与遗嘱遗赠争议起诉材料 |
| 协商分割 | 遗产分割协商与调解方案 |
| 执行程序异议 | 家事执行程序异议与复议 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 脱离家庭身份的合同、物权或商事争议 | 一般争议或相应商事领域 |
| 独立人身损害赔偿且非家事保护入口 | 人身损害领域 |

## 易混

遗产分割协议的合同请求与强制执行不是同一条路。协助执行不是重新分割。

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
