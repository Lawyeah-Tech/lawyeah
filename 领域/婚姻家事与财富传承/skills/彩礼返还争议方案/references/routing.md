# 边界与路由

## 正触发

争议核心是以婚姻为目的的财物给付。目标是：围绕特定彩礼给付和共同生活事实形成返还范围、主体、证据与诉讼方案。。

## 入口键

- 入口状态：争议核心是以婚姻为目的的财物给付
- 最低证据：给付、接收、共同生活和登记材料
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录
- `depends-on` 为空；等价前置成果可以由用户、律师、机构或其他 Skill 提供

## 负触发

| 主要目标 | 路由 |

| 争议核心是婚后共同财产分割 | 最近邻排除 |
| 一般民商事合同审查或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端 109 大众专项同题 | 只分流，不回改 C 端包 |
| 刑事控告、辩护或刑事代理 | 刑事领域 |
| 税务测算、投资产品、公司治理、境外法 | 相应专业领域 |

| 被告或接收方应对 | 彩礼返还争议答辩 |
| 核心是婚后共同财产 | 复杂夫妻财产分割方案 |

| 一般合同审查起草 | 审查起草领域（本窗搁置） |

## 易混

结婚登记完成不等于彩礼当然不必还。未登记也不等于当然全额返还。父母给付不等于父母必然是适格原告。

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
