# 执行方法

本文件是可执行判断节点，不是栏目说明书。每个会改变效力、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然无效或唯一必得金额。未知金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

入口状态：争议核心是以婚姻为目的的财物给付。
最低证据：给付、接收、共同生活和登记材料。不足时不得用推测补足。
每项事实区分已核实、单方主张、冲突、尚未提供和无法取得；规则来源不能证明案件事实。

## 事实、规则与程序分账

案件事实只从原件或可回链副本、机关正式记录、当事人本人陈述、第三方转述和现场观察取得，并标记核验状态。法律规则另行记录法域、规范名称、版本或生效日、逐项引文、适用前提、核验时间和工具返回标识。程序事实另行记录机关、案号、阶段、关键文书、送达和期限触发事件。三类信息不得互相替代。

## Q# 矩阵

固定列：`编号｜关系假设｜提出方｜相对方｜法律效果｜成立条件｜支持事实｜不利事实｜控制方｜最强反方｜主备位｜判断｜待核`。同一事实支持多项时分别说明效果，不重复金额。

---

### 判断节点 1　立场、主体与彩礼范围

- If 用户实际为接收方或被告, then 负触发，转答辩原子。
- If 给付主体是父母或其他近亲属, then 分别记录给付人、接收人和可能的诉讼主体，不自动合并。
- If 款项性质不明, then 分列彩礼、恋爱赠与、婚房出资、日常消费，不得合成一笔“彩礼”。
- If 金额未知, then 金额字段留空，不写零。
- If 争议核心是婚后共同财产, then 负触发。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然无效或唯一必得金额。未知金额不写零。

### 判断节点 2　婚姻目的与共同生活

- 运行时核验现行彩礼返还规则和司法解释后再落判断。
- If 双方已登记并长期共同生活, then 全额返还主张标严格审查，分别评估共同生活时间、孕育、过错和用途。
- If 未登记且未共同生活, then 返还路径作为主位候选，仍须核验给付性质。
- If 共同生活短暂或因给付人原因未登记, then 建并行情景，不给唯一比例。
- If “共同生活”只有单方叙述, then 依据不足，不得写成已共同生活。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然无效或唯一必得金额。未知金额不写零。

### 判断节点 3　返还范围、折价与消耗

- If 财物已用于共同生活或已消耗, then 逐项标记现状、残值和举证责任，不得把消耗当然写成无需返还。
- If 存在黄金、车辆、转账、三金混同, then 分项评估，禁止打包一个总数冒充已核验。
- If 对方主张已返还或部分抵销, then 列入最强反方，不直接否认。
- If 夹带房产首付或父母出资, then 只标接口，转财产或赠与原子，不在本任务定房屋权属。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然无效或唯一必得金额。未知金额不写零。

### 判断节点 4　管辖、期限与当事人

- If 离婚诉讼已受理且彩礼只是附带请求, then 记录是否应并入离婚案件，不自动另诉。
- If 尚未起诉, then 列可能被告、管辖连结点和时效待核，不选定唯一法院。
- If 诉讼时效起算日冲突, then 并行情景，不给唯一截止日。
- If 存在家暴或人身危险, then 先安全分流，不要求当面索要。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然无效或唯一必得金额。未知金额不写零。

### 判断节点 5　起诉材料边界

- If 返还请求现有依据支持形成材料, then 输出条件性起诉状要点和证据目录，不代提交。
- If 依据不足, then 只交缺口和取证方案。
- 禁止承诺必然返还或固定比例。
- 审查起草一般合同转介本窗搁置。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然无效或唯一必得金额。未知金额不写零。


## 程序与期限表

程序动作记录机关、案号、文书、作出、收到、送达、效力。期限每行只对应一种期间类型和一个起算事件。关键日期冲突则并行情景，不计算唯一截止日。

## 金额区间表

固定列：项目、性质、期间、参数、来源、已付、未知、互斥／抵扣、范围、专项测算接口。参数不足不输出唯一总额。未知不写零。

## 证据与下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。

下一步按期限灭失、易失证据、改变请求抗辩、可逆性排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。

相邻起诉、答辩、审查起草、税务、刑事或境外法只写转介条件和最小交接。禁止指导伪造、隐匿、威胁或违法取证。一般民商事合同审查起草转介审查起草领域（本窗搁置，只说明不实施）。C 端 109 大众专项只分流、不回改。刑事控告或辩护、税务测算、公司治理、投资金融产品、境外法或跨境执行只记录对本成果的影响并转介，不补造相邻领域结论。
