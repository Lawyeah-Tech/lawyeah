# 边界与路由

## 正触发

设立人拟以遗嘱方式建立持续财产管理和受益安排。目标是：为明确家庭目的形成遗嘱信托的财产、受托人、受益、治理、终止和执行法律文书方案。。

## 入口键

- 入口状态：设立人拟以遗嘱方式建立持续财产管理和受益安排
- 最低证据：目的、财产权属、受托受益主体、期限治理和监管边界
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录
- `depends-on` 为空；等价前置成果可以由用户、律师、机构或其他 Skill 提供

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 承诺金融机构承接、税务结果或投资收益 | 负触发，说明排除理由和正确入口 |
| 只需一次性遗嘱处分而无持续管理 | 最近邻排除 |
| 一般民商事合同审查或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端 109 大众专项同题 | 只分流，不回改 C 端包 |
| 刑事控告、辩护或刑事代理 | 刑事领域 |
| 税务测算、投资产品、公司治理、境外法 | 相应专业领域 |

| 一次性遗嘱 | 遗嘱起草与订立方案 |
| 工具选择总图 | 家庭传承法律问题与转交边界图 |

## 易混

遗嘱信托条款不是银行产品说明书。写了受托人姓名不等于信托已设立。

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
