# 边界与路由

## 正触发

继承资格和主要依据可识别，核心争议是遗产范围或分割。目标是：在继承资格和主要继承依据可识别时，围绕遗产范围、债务、份额和实物分割形成诉讼材料。。

## 入口键

- 入口状态：继承资格和主要依据可识别，核心争议是遗产范围或分割
- 最低证据：身份依据、财产权属、债务、价值和处分材料
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录
- `depends-on` 为空；等价前置成果可以由用户、律师、机构或其他 Skill 提供

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 继承人资格或遗嘱遗赠效力为核心的争议；为被告或相对方形成答辩材料 | 负触发，说明排除理由和正确入口 |
| 核心争议是继承权或遗嘱遗赠效力 | 最近邻排除 |
| 一般民商事合同审查或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端 109 大众专项同题 | 只分流，不回改 C 端包 |
| 刑事控告、辩护或刑事代理 | 刑事领域 |
| 税务测算、投资产品、公司治理、境外法 | 相应专业领域 |

| 被告应诉 | 遗产范围与分割争议答辩材料 |
| 资格效力为核心 | 继承权与遗嘱遗赠争议起诉材料 |
| 先识别 | 继承人及遗产范围识别 |

## 专项整案转出

## 易混

分割之诉不是确权遗嘱之诉。未清偿债务前不输出净分配为已确定。

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
