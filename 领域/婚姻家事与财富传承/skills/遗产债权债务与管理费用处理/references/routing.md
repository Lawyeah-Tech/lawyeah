# 边界与路由

## 正触发

已有遗产清册基础，管理主体需处理债权通知申报、债务核查争议、清偿顺序或管理费用。目标是：为已确定的遗产管理主体形成债权通知核查、债务清偿顺序、争议债权和管理费用方案。。

## 入口键

- 入口状态：已有遗产清册基础，管理主体需处理债权通知申报、债务核查争议、清偿顺序或管理费用
- 最低证据：遗产清册、债权申报、债务税费与管理费用、通知送达和争议材料
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录
- `depends-on` 为空；等价前置成果可以由用户、律师、机构或其他 Skill 提供

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 制作初始遗产清册或实施最终遗产分配 | 负触发，说明排除理由和正确入口 |
| 尚需制作初始清册或采取保全措施；遗产已可直接实施最终分配 | 最近邻排除 |
| 一般民商事合同审查或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端 109 大众专项同题 | 只分流，不回改 C 端包 |
| 刑事控告、辩护或刑事代理 | 刑事领域 |
| 税务测算、投资产品、公司治理、境外法 | 相应专业领域 |

| 初始清册保全 | 遗产清册与保全方案 |
| 最终分配 | 遗产分配实施方案 |

## 最近邻边界

| Skill | 名称 | 规则 |
| --- | --- | --- |
| `遗产清册与保全方案` | 遗产清册与保全方案 | 识别到用户核心目标符合该最近邻入口时停止相邻实体扩展并转介；不自动调用。 |
| `遗产分配实施方案` | 遗产分配实施方案 | 识别到用户核心目标符合该最近邻入口时停止相邻实体扩展并转介；不自动调用。 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 脱离家庭身份的合同、物权或商事争议 | 一般争议或相应商事领域 |
| 独立人身损害赔偿且非家事保护入口 | 人身损害领域 |
| 家庭成员犯罪后的控告、被害人代理或辩护 | 刑事领域 |
| 投资、税务、金融产品、信托公司承做 | 相应财富或税务领域 |
| 境外法、冲突规范、境外资产和跨境执行 | 涉外专项 |
| 审查起草一般合同 | 审查起草领域（本窗搁置） |

## 易混

申报期满不是未申报债权绝对消灭，须核验规则。管理费用不是管理人私款。

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
