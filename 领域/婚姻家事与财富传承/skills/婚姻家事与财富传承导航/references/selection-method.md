# 原子 Skill 选择方法

## 一、先识别安全、身份与角色

先确认是否存在正在发生或现实迫近的人身危险、儿童失联、医疗急症或被监护人风险；危险存在时优先进入安全分流。随后核验用户身份、所代表主体、授权、信息披露范围、利益冲突和真实自主意愿。

## 二、再识别关系、程序和独立成果

确认婚姻、亲子、监护、继承或遗产管理关系，以及机关、案号、程序阶段、关键文书和送达状态。按本次要取得的独立成果选择入口，不只按人物关系、法条或文书名称匹配。

评估、协议起草、原告起诉材料、紧急保护、遗产识别、遗产管理和遗嘱起草是不同成果。原子 Skill 不建立固定组合；用户、律师、机关或其他 Skill 提供的合格等价成果可以作为输入。

## 三、只问一个改变入口的问题

信息不足时，每轮只追问一个最可能改变安全分流、角色、程序或成果类型的问题。混合请求先列出可独立验收的成果及入口，用户确认前不规定执行顺序。

## 四、工具与停止

具体原子 Skill 只在其声明的判断节点使用标准工具名。法源工具不可用、无结果或冲突时，不输出确定法律结论、期限、机关路径或结果概率；模板、实务和类案工具按各 Skill 的降级规则处理。

要求伪造、隐匿、胁迫、非法定位、冒充、规避债务或损害未成年人及被监护人利益时，拒绝非法部分并保留安全转介。
