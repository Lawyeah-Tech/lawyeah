# 边界与路由

## 正触发

遗产清册、债务处理、管理权限和分配依据均达到可执行状态。目标是：在遗产范围、债务、管理权限和分配依据达到可分配状态后形成分配、交付、登记和留痕方案。。

## 入口键

- 入口状态：遗产清册、债务处理、管理权限和分配依据均达到可执行状态
- 最低证据：最终清册、债务处理、分配依据、同意裁判和登记交付要求
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录
- `depends-on` 为空；等价前置成果可以由用户、律师、机构或其他 Skill 提供

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 遗产范围、债务或权限尚未关闭时不可逆处分核心遗产 | 负触发，说明排除理由和正确入口 |
| 遗产仍需清理保全或债权债务尚未处理 | 最近邻排除 |
| 一般民商事合同审查或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端 109 大众专项同题 | 只分流，不回改 C 端包 |
| 刑事控告、辩护或刑事代理 | 刑事领域 |
| 税务测算、投资产品、公司治理、境外法 | 相应专业领域 |

| 仍需清册 | 遗产清册与保全方案 |
| 仍需协商份额 | 遗产分割协商与调解方案 |
| 债务未处理 | 遗产债权债务与管理费用处理 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 脱离家庭身份的合同、物权或商事争议 | 一般争议或相应商事领域 |
| 独立人身损害赔偿且非家事保护入口 | 人身损害领域 |
| 家庭成员犯罪后的控告、被害人代理或辩护 | 刑事领域 |
| 投资、税务、金融产品、信托公司承做 | 相应财富或税务领域 |
| 境外法、冲突规范、境外资产和跨境执行 | 涉外专项 |
| 审查起草一般合同 | 审查起草领域（本窗搁置） |

## 易混

可分配不是继承人口头同意即可过户。提存和直接交付不同。

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
