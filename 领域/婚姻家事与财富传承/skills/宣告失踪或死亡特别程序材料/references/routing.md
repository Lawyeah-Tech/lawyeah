# 边界与路由

## 正触发

特定自然人下落不明事实和法定期间需要核验，并拟启动宣告失踪或死亡特别程序。目标是：围绕特定自然人的宣告失踪或宣告死亡条件形成利害关系人、事实期限和特别程序申请材料。。

## 入口键

- 入口状态：特定自然人下落不明事实和法定期间需要核验，并拟启动宣告失踪或死亡特别程序
- 最低证据：失联事实与起止时间、寻找经过、最后住所、利害关系和已知财产家庭情况
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录
- `depends-on` 为空；等价前置成果可以由用户、律师、机构或其他 Skill 提供

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 直接实施监护、婚姻身份、继承、债务或遗产处分后果 | 负触发，说明排除理由和正确入口 |
| 已有生效宣告且目标是评估家事继承后果，或尚无启动宣告程序的具体目标 | 最近邻排除 |
| 一般民商事合同审查或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端 109 大众专项同题 | 只分流，不回改 C 端包 |
| 刑事控告、辩护或刑事代理 | 刑事领域 |
| 税务测算、投资产品、公司治理、境外法 | 相应专业领域 |

| 评估家事后果 | 失踪死亡宣告家事后果评估 |
| 管辖期限总表 | 家事主体管辖与期限评估 |

## 最近邻边界

| Skill | 名称 | 规则 |
| --- | --- | --- |
| `失踪死亡宣告家事后果评估` | 失踪死亡宣告家事后果评估 | 识别到用户核心目标符合该最近邻入口时停止相邻实体扩展并转介；不自动调用。 |
| `家事主体管辖与期限评估` | 家事主体管辖与期限评估 | 识别到用户核心目标符合该最近邻入口时停止相邻实体扩展并转介；不自动调用。 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 脱离家庭身份的合同、物权或商事争议 | 一般争议或相应商事领域 |
| 独立人身损害赔偿且非家事保护入口 | 人身损害领域 |
| 家庭成员犯罪后的控告、被害人代理或辩护 | 刑事领域 |
| 投资、税务、金融产品、信托公司承做 | 相应财富或税务领域 |
| 境外法、冲突规范、境外资产和跨境执行 | 涉外专项 |
| 审查起草一般合同 | 审查起草领域（本窗搁置） |

## 易混

宣告死亡时间不是任意指定的遗产起算游戏。利害关系人不是任何亲友。

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
