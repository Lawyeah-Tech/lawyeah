# 边界与路由

## 正触发

已存在收养事实且成立、效力或身份后果发生争议。目标是：围绕收养主体、同意、登记、成立或无效及其亲子监护扶养继承后果形成评估和起诉材料。。

## 入口键

- 入口状态：已存在收养事实且成立、效力或身份后果发生争议
- 最低证据：各方身份同意、登记、共同生活和被收养人利益材料
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录
- `depends-on` 为空；等价前置成果可以由用户、律师、机构或其他 Skill 提供

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 一般亲子关系确认或单纯收养登记办理；为被告或相对方形成答辩材料 | 负触发，说明排除理由和正确入口 |
| 目标是首次办理收养登记或解除有效收养 | 最近邻排除 |
| 一般民商事合同审查或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端 109 大众专项同题 | 只分流，不回改 C 端包 |
| 刑事控告、辩护或刑事代理 | 刑事领域 |
| 税务测算、投资产品、公司治理、境外法 | 相应专业领域 |

| 相对方答辩 | 收养成立与效力争议答辩材料 |
| 首次登记 | 境内收养条件与登记方案 |
| 解除 | 解除收养原子（P2，unavailable） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 脱离家庭身份的合同、物权或商事争议 | 一般争议或相应商事领域 |
| 独立人身损害赔偿且非家事保护入口 | 人身损害领域 |

## 易混

收养无效与解除有效收养不是同一请求。长期共同生活不是登记的替代。

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
