# 边界与路由

## 正触发

存在需由法院处理的婚姻无效、撤销或身份争议。目标是：围绕婚姻无效、撤销或身份确认争议形成主体、请求、期限、证据和诉讼材料。。

## 入口键

- 入口状态：存在需由法院处理的婚姻无效、撤销或身份争议
- 最低证据：身份登记、效力事由、知悉时间和基础证据
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录
- `depends-on` 为空；等价前置成果可以由用户、律师、机构或其他 Skill 提供

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 行政婚姻登记办理或普通离婚诉讼；为被告或相对方形成答辩材料 | 负触发，说明排除理由和正确入口 |
| 目标只是办理登记或解除有效婚姻 | 最近邻排除 |
| 一般民商事合同审查或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端 109 大众专项同题 | 只分流，不回改 C 端包 |
| 刑事控告、辩护或刑事代理 | 刑事领域 |
| 税务测算、投资产品、公司治理、境外法 | 相应专业领域 |

| 被告应诉 | 婚姻效力与撤销争议答辩材料 |
| 只要效力评估 | 婚姻成立与效力评估 |
| 解除有效婚姻 | 离婚诉讼原告起诉材料 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |

## 易混

撤销婚姻不是离婚。登记错误的行政救济不是民事效力之诉。

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
