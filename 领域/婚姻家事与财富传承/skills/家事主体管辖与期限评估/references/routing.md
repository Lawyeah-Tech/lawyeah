# 边界与路由

## 正触发

用户已选定一个具体的单一家事原子候选，但该事项的机关、主体资格、管辖或期限信息仍不明确。目标是：针对一个已明确的单一家事目标形成程序入口、主体资格、受理机关、管辖、期限和失权风险分流表。。

## 入口键

- 入口状态：用户已选定一个具体的单一家事原子候选，但该事项的机关、主体资格、管辖或期限信息仍不明确
- 最低证据：已选定候选、身份关系、当前程序、送达时间、拟请求事项及已知机关信息
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录
- `depends-on` 为空；等价前置成果可以由用户、律师、机构或其他 Skill 提供

| 税务测算、投资产品、公司治理、境外法 | 相应专业领域 |

| 尚未选目标 | 婚姻家事与财富传承导航 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 脱离家庭身份的合同、物权或商事争议 | 一般争议或相应商事领域 |
| 独立人身损害赔偿且非家事保护入口 | 人身损害领域 |

## 易混

管辖评估不是立案。期限公式不是截止日期。导航 Guide 才处理未选目标。

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
