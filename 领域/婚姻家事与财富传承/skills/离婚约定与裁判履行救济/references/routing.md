# 边界与路由

## 正触发

已有离婚协议或生效法律文书且出现未履行。目标是：针对离婚协议、调解书或判决的未履行事项形成催告、诉讼或执行方案。。

## 入口键

- 入口状态：已有离婚协议或生效法律文书且出现未履行
- 最低证据：依据文件、履行记录、到期事实和财产线索
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录
- `depends-on` 为空；等价前置成果可以由用户、律师、机构或其他 Skill 提供

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 把未登记离婚协议当然作为执行依据 | 负触发，说明排除理由和正确入口 |
| 离婚后发现尚未处理的新财产 | 最近邻排除 |
| 一般民商事合同审查或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端 109 大众专项同题 | 只分流，不回改 C 端包 |
| 刑事控告、辩护或刑事代理 | 刑事领域 |
| 税务测算、投资产品、公司治理、境外法 | 相应专业领域 |

| 漏分隐藏新财产 | 离婚后财产争议诉讼材料 |
| 抚养费请求调整而非执行 | 抚养费请求与调整材料 |

## 最近邻边界

| Skill | 名称 | 规则 |
| --- | --- | --- |
| `离婚后财产争议诉讼材料` | 离婚后财产争议诉讼材料 | 识别到用户核心目标符合该最近邻入口时停止相邻实体扩展并转介；不自动调用。 |
| `抚养费请求与调整材料` | 抚养费请求与调整材料 | 识别到用户核心目标符合该最近邻入口时停止相邻实体扩展并转介；不自动调用。 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 脱离家庭身份的合同、物权或商事争议 | 一般争议或相应商事领域 |
| 独立人身损害赔偿且非家事保护入口 | 人身损害领域 |
| 家庭成员犯罪后的控告、被害人代理或辩护 | 刑事领域 |
| 投资、税务、金融产品、信托公司承做 | 相应财富或税务领域 |
| 境外法、冲突规范、境外资产和跨境执行 | 涉外专项 |
| 审查起草一般合同 | 审查起草领域（本窗搁置） |

## 易混

离婚协议登记离婚后仍可能只是合同依据。执行和另诉不是同一入口。

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
