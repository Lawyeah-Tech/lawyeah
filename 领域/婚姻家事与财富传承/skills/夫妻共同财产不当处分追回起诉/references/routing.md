# 边界与路由

## 正触发

已经发生具体共同财产处分。目标是：针对赠与、低价转让、恶意串通或隐藏共同财产形成效力、返还评估与起诉材料。。

## 入口键

- 入口状态：已经发生具体共同财产处分
- 最低证据：财产来源、处分、对价、受让人知情和损害材料
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录
- `depends-on` 为空；等价前置成果可以由用户、律师、机构或其他 Skill 提供

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 当然否定所有未经配偶同意的交易；为被告或受让人形成答辩材料 | 负触发，说明排除理由和正确入口 |
| 仅存在未来处分风险，或用户立场是被告或受让人 | 最近邻排除 |
| 一般民商事合同审查或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端 109 大众专项同题 | 只分流，不回改 C 端包 |
| 刑事控告、辩护或刑事代理 | 刑事领域 |
| 税务测算、投资产品、公司治理、境外法 | 相应专业领域 |

| 被告或受让人 | 夫妻共同财产不当处分答辩 |
| 仅未来风险 | 夫妻财产紧急保全方案 |
| 离婚后漏分 | 离婚后财产争议诉讼材料 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 脱离家庭身份的合同、物权或商事争议 | 一般争议或相应商事领域 |
| 独立人身损害赔偿且非家事保护入口 | 人身损害领域 |

## 易混

未同意处分不是自动无效。离婚分割中的少分请求与对第三人的返还请求不是同一 Q#。

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
