# 边界与路由

## 正触发

拟在中国境内建立特定收养关系。目标是：对中国境内收养形成收养人、被收养人、送养人条件、同意、评估和登记材料方案。。

## 入口键

- 入口状态：拟在中国境内建立特定收养关系
- 最低证据：各方身份、条件、同意和被收养人利益材料
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录
- `depends-on` 为空；等价前置成果可以由用户、律师、机构或其他 Skill 提供

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 规避收养登记或买卖儿童 | 负触发，说明排除理由和正确入口 |
| 收养已成立且目标是解除 | 最近邻排除 |
| 一般民商事合同审查或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端 109 大众专项同题 | 只分流，不回改 C 端包 |
| 刑事控告、辩护或刑事代理 | 刑事领域 |
| 税务测算、投资产品、公司治理、境外法 | 相应专业领域 |

| 效力争议 | 收养成立与效力争议方案 |
| 解除已成立收养 | 解除收养原子（P2，unavailable） |
| 亲子确认 | 亲子关系确认与否认诉讼材料 |

## 易混

事实抚养不是收养。送养同意不是买卖对价。登记不是可跳过的手续。

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
