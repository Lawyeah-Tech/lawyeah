# 遗产清册与保全方案

## 任务与边界

为已确定的遗产管理主体形成通知、清册、占有控制、保全和管理日志。

本 Skill 只形成自身约定的成果，不自动调用、组合或替代相邻 Skill，不承诺受理、裁判、登记或执行结果。`dependsOn: []`。

## 渐进式工作

1. **入口核验**：先确认用户身份、代表主体、授权依据、信息披露范围、利益冲突、目标、角色、法域与紧急安全。身份或权限未核验时，只输出通用清单、停止原因和最小补充事项。
2. **事实与程序建模**：入口成立后再读取最小必要材料，分别记录案件事实、相反材料、证据缺口、机关、案号、阶段、送达和期限触发事件。
3. **法律核验与交付**：有 `search_law` 可回链现行法源时形成条件性法律结论；工具未安装、不可用、无结果或冲突时不中断主流程，继续事实与缺口整理，法律结论、期限和机关路径标停止或待核。按需再读取[执行方法](references/method.md)、[输出合同](references/output-contract.md)和[边界与路由](references/routing.md)。

## 最小输入

- 遗产管理主体、权限依据和利益冲突
- 死亡、继承人受遗赠人和通知信息
- 逐项遗产线索、权属和占有控制状态
- 易损灭失、转移侵占和价值波动风险
- 保管账户文件钥匙印章和数字访问状态
- 既有清册、操作日志和第三人财产主张
- 用户身份、代表主体、授权依据或未核验状态、信息披露范围和利益冲突状态
- 适用法域、当前日期与时区、案件机关、案号或无案号状态、程序阶段、关键文书和送达期限材料
- 所有材料的可回链位置、来源类别、取得方式、日期及核验状态

只处理完成本成果必要的去标识化摘要。完整文书、未成年人及第三人个人信息不得无目的上传工具。

## 适用前置

1. 先核验入口状态：遗产管理主体已确定，现需识别遗产、形成清册、通知利害关系人并采取占有控制或保全措施。
2. 最低证据为：管理权限依据、遗产线索、占有控制状态、利害关系人和保全风险材料。不足时不得用推测补足。
3. 每项事实区分已核实、单方主张、冲突、尚未提供和无法取得；规则来源不能证明案件事实。
4. 法域、规则版本或关键法源缺失时，只保留事实证据矩阵、待核验问题和停止输出，不给确定法律结论、截止日、机关路径或结果概率。
5. 文书、证据和程序动作均须由用户或合格中国大陆法律专业人员复核后实施。
6. 缺失输入时，每轮只追问一个最可能改变入口、角色、安全分流或成果类型的最小问题；不得一次索取整套材料。

## 执行方法

1. 确认遗产管理主体已经依法或有效文书确定，不代替指定管理人程序。
2. 先分离他人财产并建立逐资产线索、权属、位置、占有和价值状态。
3. 向继承人受遗赠人等利害关系人形成可回执通知台账，只使用经核验且必要知悉的安全地址与渠道。
4. 涉及未成年人、无民事行为能力人、家暴风险人员或实际居住房屋时，先核验居住照护和反报复风险；不得以清册或保全为由擅自换锁、驱离、断供生活必需品或限制依法应有的进入。
5. 优先采用不改变居住照护现状的最小保全措施，并把儿童最佳利益、隐私和人身安全列为独立复核项。
6. 记录每项管理动作的权限、目的、时间、经手人、凭证和利益冲突。
7. 只处理初始清册通知保全，不进入债权核查清偿、管理费用或最终分配。

## 高风险停止

- 遗产管理主体或权限尚未确定
- 财产可能属于配偶、共有人、公司或第三人但未分离
- 要求私自转移处分、侵占账户或规避通知
- 目标实际为债权债务处理、管理费用或最终分配
- 要求伪造、篡改、隐匿材料，非法获取信息，规避法定义务或承诺结果
- 身份、授权、利益冲突、法域或会改变结论的程序状态未核验

## 输出

1. 遗产管理权限与利害关系人表
2. 逐资产清册和他人财产标记
3. 通知、占有控制与保全方案
4. 管理日志、冲突和停止事项

所有法律结论只用「现有依据支持」「现有依据不支持」「依据不足，无法形成结论」，逐项绑定事实、相反材料、适用前提、法域、规则版本或生效日、引文与核验时间。没有法源引文时，法律结论字段留空并停止；主流程继续交付事实矩阵、缺口和可处理部分。未知金额不写零。
