# 边界与路由

## 正触发

已收到对方起诉、申请或明确请求并需以被告或相对方立场应对。目标是：被告围绕子女需要、负担能力、既有给付和调整事由形成答辩材料。。

## 入口键

- 入口状态：已收到对方起诉、申请或明确请求并需以被告或相对方立场应对
- 最低证据：子女实际需要、父母负担能力和既有安排、对方诉讼材料
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录
- `depends-on` 为空；等价前置成果可以由用户、律师、机构或其他 Skill 提供

## 易混

负担能力抗辩不是拒绝一切给付。已付现金须有凭证。
