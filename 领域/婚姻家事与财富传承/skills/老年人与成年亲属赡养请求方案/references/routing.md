# 边界与路由

## 正触发

老年人或其他被赡养人存在需要和未履行事实。目标是：针对成年子女或其他法定义务人的赡养责任形成项目、测算、证据和协商诉讼材料。。

## 入口键

- 入口状态：老年人或其他被赡养人存在需要和未履行事实
- 最低证据：身份关系、实际需要、履行能力和既有给付
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录
- `depends-on` 为空；等价前置成果可以由用户、律师、机构或其他 Skill 提供

## 负触发

| 主要目标 | 路由 |
| --- | --- |

| 义务基础是配偶扶养或未成年子女抚养 | 最近邻排除 |
| 一般民商事合同审查或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

| 税务测算、投资产品、公司治理、境外法 | 相应专业领域 |

| 配偶扶养 | 配偶扶养请求方案 |
| 义务方答辩 | 老年人与成年亲属赡养请求答辩方案 |

## 易混

赡养不是遗产预分配。轮养约定不当然消灭法定责任。

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
