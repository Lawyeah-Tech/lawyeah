# 边界与路由

## 正触发

家事裁判、调解书或其他执行依据已进入执行且出现程序或标的异议。目标是：案外人针对家事执行标的主张实体权利时形成异议、复议或案外人诉讼分流材料。。

## 入口键

- 入口状态：家事裁判、调解书或其他执行依据已进入执行且出现程序或标的异议
- 最低证据：执行依据、执行通知措施、标的权属、主体和送达期限材料
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录
- `depends-on` 为空；等价前置成果可以由用户、律师、机构或其他 Skill 提供

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 申请执行人或被执行人的一般执行程序异议 | 负触发，说明排除理由和正确入口 |
| 仅存在到期未履行但尚未进入执行程序 | 最近邻排除 |
| 一般民商事合同审查或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端 109 大众专项同题 | 只分流，不回改 C 端包 |
| 刑事控告、辩护或刑事代理 | 刑事领域 |
| 税务测算、投资产品、公司治理、境外法 | 相应专业领域 |

| 当事人程序异议 | 家事执行程序异议与复议 |
| 遗产范围诉讼 | 遗产范围与分割争议诉讼材料 |

## 最近邻边界

| Skill | 名称 | 规则 |
| --- | --- | --- |
| `家事执行程序异议与复议` | 家事执行程序异议与复议 | 识别到用户核心目标符合该最近邻入口时停止相邻实体扩展并转介；不自动调用。 |
| `遗产范围与分割争议诉讼材料` | 遗产范围与分割争议诉讼材料 | 识别到用户核心目标符合该最近邻入口时停止相邻实体扩展并转介；不自动调用。 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 脱离家庭身份的合同、物权或商事争议 | 一般争议或相应商事领域 |
| 独立人身损害赔偿且非家事保护入口 | 人身损害领域 |
| 家庭成员犯罪后的控告、被害人代理或辩护 | 刑事领域 |
| 投资、税务、金融产品、信托公司承做 | 相应财富或税务领域 |
| 境外法、冲突规范、境外资产和跨境执行 | 涉外专项 |
| 审查起草一般合同 | 审查起草领域（本窗搁置） |

## 易混

案外人异议之诉不是执行复议的别名。共有份额不等于排除全部执行。

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
