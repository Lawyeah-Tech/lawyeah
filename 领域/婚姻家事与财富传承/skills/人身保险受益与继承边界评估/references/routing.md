# 边界与路由

## 正触发

存在特定人身保险合同及家庭传承目标或身故事件。目标是：对特定人身保险的投保人、被保险人、受益人指定变更与保险金是否进入遗产形成法律评估。。

## 入口键

- 入口状态：存在特定人身保险合同及家庭传承目标或身故事件
- 最低证据：保险合同、主体、受益指定变更、保费来源和婚姻状态
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录
- `depends-on` 为空；等价前置成果可以由用户、律师、机构或其他 Skill 提供

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 推荐保险产品或承诺税务结果 | 负触发，说明排除理由和正确入口 |
| 目标是选择或配置保险产品 | 最近邻排除 |
| 一般民商事合同审查或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端 109 大众专项同题 | 只分流，不回改 C 端包 |
| 刑事控告、辩护或刑事代理 | 刑事领域 |
| 税务测算、投资产品、公司治理、境外法 | 相应专业领域 |

| 遗产识别 | 继承人及遗产范围识别 |
| 综合工具图 | 家庭传承法律问题与转交边界图 |

## 易混

受益人指定不是遗嘱。离婚判决分割保单不等于已完成受益人变更。

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
