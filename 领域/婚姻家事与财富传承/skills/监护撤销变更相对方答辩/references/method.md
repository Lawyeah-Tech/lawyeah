# 执行方法

本文件是可执行判断节点，不是栏目说明书。每个会改变效力、请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然无效或唯一必得金额。未知金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

入口状态：现任监护人、其他被申请人或利害关系人已收到撤销、变更或临时保护申请、裁定或送达通知，需要依法答辩、复议或请求调整措施。
最低证据：申请书或裁定、送达时间、监护履职记录、风险争点、被监护人意愿和替代监护方案。不足时不得用推测补足。
每项事实区分已核实、单方主张、冲突、尚未提供和无法取得；规则来源不能证明案件事实。

## 事实、规则与程序分账

案件事实只从原件或可回链副本、机关正式记录、当事人本人陈述、第三方转述和现场观察取得，并标记核验状态。法律规则另行记录法域、规范名称、版本或生效日、逐项引文、适用前提、核验时间和工具返回标识。程序事实另行记录机关、案号、阶段、关键文书、送达和期限触发事件。三类信息不得互相替代。

## Q# 矩阵

固定列：`编号｜关系假设｜提出方｜相对方｜法律效果｜成立条件｜支持事实｜不利事实｜控制方｜最强反方｜主备位｜判断｜待核`。同一事实支持多项时分别说明效果，不重复金额。

### 判断节点 1　相对方与安全闸

- If 用户是申请人要撤销, then 负触发。
- If 答辩会妨害被监护人即时安全, then 停止对抗性策略，先保护。

- 照顾、医疗、财产、报告记录分列；缺失标依据不足。
- 不得伪造履职日志。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然受理、必然无效或唯一必得金额。未知金额不写零。

## 程序与期限表

程序动作记录机关、案号、文书、作出、收到、送达、效力。期限每行只对应一种期间类型和一个起算事件。关键日期冲突则并行情景，不计算唯一截止日。

## 金额区间表

固定列：项目、性质、期间、参数、来源、已付、未知、互斥／抵扣、范围、专项测算接口。参数不足不输出唯一总额。未知不写零。

## 证据与下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。

下一步按期限灭失、易失证据、改变请求抗辩、可逆性排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。

相邻起诉、答辩、审查起草、税务、刑事或境外法只写转介条件和最小交接。禁止指导伪造、隐匿、威胁或违法取证。一般民商事合同审查起草转介审查起草领域（本窗搁置，只说明不实施）。C 端 109 大众专项只分流、不回改。刑事控告或辩护、税务测算、公司治理、投资金融产品、境外法或跨境执行只记录对本成果的影响并转介，不补造相邻领域结论。
