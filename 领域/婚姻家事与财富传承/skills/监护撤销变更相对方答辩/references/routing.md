# 边界与路由

## 正触发

现任监护人、其他被申请人或利害关系人已收到撤销、变更或临时保护申请、裁定或送达通知，需要依法答辩、复议或请求调整措施。目标是：现任监护人或利害关系人针对撤销、变更或临时保护请求形成答辩材料。。

## 入口键

- 入口状态：现任监护人、其他被申请人或利害关系人已收到撤销、变更或临时保护申请、裁定或送达通知，需要依法答辩、复议或请求调整措施
- 最低证据：申请书或裁定、送达时间、监护履职记录、风险争点、被监护人意愿和替代监护方案
- 角色与授权：用户立场、代表主体、授权依据、信息披露范围和利益冲突均已核验
- 法域与程序：适用法域、机关、案号或无案号、阶段、送达和期限触发事实已记录
- `depends-on` 为空；等价前置成果可以由用户、律师、机构或其他 Skill 提供

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 作为申请人提出撤销或变更监护；以答辩妨害被监护人的即时安全或最佳利益 | 负触发，说明排除理由和正确入口 |
| 申请人提出撤销或变更监护，或尚需首次设立指定监护 | 最近邻排除 |
| 一般民商事合同审查或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端 109 大众专项同题 | 只分流，不回改 C 端包 |
| 刑事控告、辩护或刑事代理 | 刑事领域 |
| 税务测算、投资产品、公司治理、境外法 | 相应专业领域 |

| 申请人撤销 | 监护资格撤销与变更方案 |
| 首次指定 | 监护设立指定与临时监护方案 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 脱离家庭身份的合同、物权或商事争议 | 一般争议或相应商事领域 |
| 独立人身损害赔偿且非家事保护入口 | 人身损害领域 |
| 家庭成员犯罪后的控告、被害人代理或辩护 | 刑事领域 |
| 投资、税务、金融产品、信托公司承做 | 相应财富或税务领域 |
| 境外法、冲突规范、境外资产和跨境执行 | 涉外专项 |

## 易混

维持监护资格不是否定临时保护。财产控制记录可能是不利证据。

负触发只说明排除理由、停止状态和正确入口，不生成相邻成果。
