# 继承权与遗嘱遗赠争议起诉材料

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是运行本技能的强制依赖。

## 任务与边界

围绕继承人资格、继承权、遗嘱或遗赠效力形成原告请求和起诉材料。

本 Skill 只形成自身约定的成果，不自动调用、组合或替代相邻 Skill，不承诺受理、裁判、登记或执行结果。`dependsOn: []`。

## 渐进式工作

1. **入口核验**：先确认用户身份、代表主体、授权依据、信息披露范围、利益冲突、目标、角色、法域与紧急安全。身份或权限未核验时，只输出通用清单、停止原因和最小补充事项。
2. **事实与程序建模**：入口成立后再读取最小必要材料，分别记录案件事实、相反材料、证据缺口、机关、案号、阶段、送达和期限触发事件。
3. **法律核验与交付**：有 `search_law` 可回链现行法源时形成条件性法律结论；工具未安装、不可用、无结果或冲突时不中断主流程，继续事实与缺口整理，法律结论、期限和机关路径标停止或待核。按需再读取[执行方法](references/method.md)、[输出合同](references/output-contract.md)和[边界与路由](references/routing.md)。

## 最小输入

- 原告身份、继承或受遗赠立场和授权
- 被继承人死亡及继承开始材料
- 争议的继承资格、继承权、遗嘱、遗赠或遗赠扶养协议
- 胎儿、未成年人、无或限制民事行为能力人和必要遗产份额相关事实
- 拟受理法院、管辖、当事人、法定代理与利益冲突、送达信息
- 遗嘱能力、真实意思、形式见证和多份文书证据
- 请求、保全、鉴定调查和相反材料
- 用户身份、代表主体、授权依据或未核验状态、信息披露范围和利益冲突状态
- 适用法域、当前日期与时区、案件机关、案号或无案号状态、程序阶段、关键文书和送达期限材料
- 所有材料的可回链位置、来源类别、取得方式、日期及核验状态

只处理完成本成果必要的去标识化摘要。完整文书、未成年人及第三人个人信息不得无目的上传工具。

## 适用前置

1. 先核验入口状态：继承已开始且核心争议是继承资格、继承权或遗嘱遗赠效力。
2. 最低证据为：死亡、身份、继承依据和争议事实材料。不足时不得用推测补足。
3. 每项事实区分已核实、单方主张、冲突、尚未提供和无法取得；规则来源不能证明案件事实。
4. 法域、规则版本或关键法源缺失时，只保留事实证据矩阵、待核验问题和停止输出，不给确定法律结论、截止日、机关路径或结果概率。
5. 文书、证据和程序动作均须由用户或合格中国大陆法律专业人员复核后实施。
6. 缺失输入时，每轮只追问一个最可能改变入口、角色、安全分流或成果类型的最小问题；不得一次索取整套材料。

## 执行方法

1. 锁定原告立场、继承开始、法院管辖和争议属于身份效力而非单纯分割。
2. 把继承资格、丧失宽恕、遗嘱继承、遗赠、遗赠扶养协议、能力、意思和形式分别列为争点。
3. 强制核验胎儿利益、缺乏劳动能力且无生活来源继承人的必要遗产份额，以及未成年人或被监护人与法定代理人的利益冲突。
4. 识别所有必要当事人、放弃状态、特别代理或独立代表需求和不得遗漏的权利主体。
5. 如已识别或无法排除法定代理人与未成年人、被监护人或其他必要权利主体存在利益冲突，在特别代理人或独立代表确定并核验权限前，停止代表该主体形成实体请求、起诉状和程序申请。
6. 逐请求建立事实—证据—证明责任—法源矩阵，保留最强反向解释。
7. 核验鉴定、调查取证、保全和送达等程序入口。
8. 形成原告起诉材料，不混入被告答辩、遗产管理或分割实施。

## 高风险停止

- 用户实际为被告或相对方
- 死亡、原告资格、法院管辖或核心争议未核验
- 法定代理人与未成年人、被监护人或必要权利主体的利益冲突未排除，特别代理人或独立代表尚未确定并核验权限
- 身份效力无争议而只需遗产范围分割
- 要求伪造遗嘱、隐瞒继承人或未经复核直接提交
- 要求伪造、篡改、隐匿材料，非法获取信息，规避法定义务或承诺结果
- 身份、授权、利益冲突、法域或会改变结论的程序状态未核验

## 输出

1. 主体管辖与争议类型表
2. 身份效力争点与证明责任矩阵
3. 诉讼请求和起诉状草案
4. 证据目录与程序申请清单

所有法律结论只用「现有依据支持」「现有依据不支持」「依据不足，无法形成结论」，逐项绑定事实、相反材料、适用前提、法域、规则版本或生效日、引文与核验时间。没有法源引文时，法律结论字段留空并停止；主流程继续交付事实矩阵、缺口和可处理部分。未知金额不写零。
