# 评估告知同意争议

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把已失效《侵权责任法》医疗专章同号旧义当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。


## 任务目标

在明确、无利益冲突的单方立场下，形成“告知同意专项评估矩阵：说明义务范围、明确同意证据、紧急情况例外、人身损害要件、反方和下一步”。

`depends-on` 为空。接受用户、律师、医学专家、机关或其他来源的等价事实、病历、鉴定、许可和费用清单。

## 工作边界

正触发：争点集中在病情、医疗措施、风险、替代方案未说明或签字效力，用户仍需决定该项请求或抗辩是否单独成立。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 用户要的是医疗损害总体评估而非告知专项；
- 紧急批准路径是主轴且不要普通告知检验；
- 未出现人身损害，只要把签字瑕疵写成必赔；
- 只要鉴定申请、诉状或精算终稿；
- 未成争只要改知情同意书文本（审查起草本窗搁置）。

本任务不把未造成人身损害的单纯告知瑕疵写成必赔，不替代总体过错评估，不写鉴定或起诉终稿，不给胜诉率，不指导伪造、抢夺、威胁、隐匿病历或中断救治取证。

## 建立坐标

确认：使用者与授权；单方立场；患者、近亲属、签字人、手术或特殊检查项目、知情同意书版本、紧急情况线索、损害后果；法域；当前投诉、封存、鉴定、调解、监管或诉讼状态；机关文书作出与送达；对方已知主张；关键材料及缺失。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关、鉴定或生效文书；`M#` 病历、实物或许可台账；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩／合规项；`V#` 评估或稿件版本；`E#` 封存／送达／提交凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典第一千二百一十九条、第一千二百二十条，医疗损害责任解释（2020修正）第五条、第十七条，医疗机构管理条例第三十二条；`search_practiced` 补路径与反例；特殊事实用 `search_case_by_fact`。不虚构鉴定、许可或案件系统。

工具不可用时继续事实、主体、材料和问题清单；说明义务、紧急例外和法律结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　说明范围与对象

区分一般说明与手术、特殊检查、特殊治疗的具体说明。不能或不宜向患者说明的，核验是否向近亲属说明。
### 节点 2　明确同意证据

机构提交明确同意证据时，可以初步认定尽到说明义务，但患方相反证据足以反驳的除外。
### 节点 3　紧急例外

抢救生命垂危等紧急情况、不能取得患者或近亲属意见的，经负责人或授权负责人批准可立即实施。
### 节点 4　人身损害要件

解释第十七条：违反说明义务但未造成人身损害的，损害赔偿请求不予支持。
### 节点 5　反方、竞合并下一步

告知专项不得替代总体过错评估。紧急批准、产品缺陷、合同路径分列转介。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；用户坚持伪造签字或倒签同意书。
- `字段停止`：法域、签署时点、紧急批准规则未核验。
- `目标停止`：主目标已变为总体评估、鉴定申请、起诉或改同意书文本。

严格按 [输出合同](references/output-contract.md) 交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
