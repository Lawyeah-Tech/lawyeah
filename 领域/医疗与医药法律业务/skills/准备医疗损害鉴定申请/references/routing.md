# 边界与路由

## 正触发

已决定申请医疗损害专门性问题鉴定，需要事项、检材和发送前申请稿。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只选鉴定类型 | `选择医疗损害鉴定与事故技术鉴定`（未安装则 `unavailable`） |
| 异议或重新鉴定 | `提出医疗鉴定异议或重新鉴定`（未安装则 `unavailable`） |
| 专家咨询出庭 | `准备医学专家咨询与出庭`（未安装则 `unavailable`） |
| 过错总图 | `评估医疗损害争议` |
| 一般伤残测算 | 人身损害领域 |
| 起诉状 | `提起医疗损害诉讼` |

## 易混

可以边诉边鉴定。未鉴定不是起诉障碍。事故鉴定与司法鉴定不是同一文书。
