# 申请方法

不得预测鉴定意见。不得把医疗事故技术鉴定“不属于事故”写成民事不赔。

## 节点 0　类型闸

| 用户目标 | 处理 |
| --- | --- |
| 只比较鉴定类型 | 负触发，转 `select-appraisal-type`（未安装则 `unavailable`） |
| 已有意见要异议 | 负触发，转 `object-to-appraisal`（未安装则 `unavailable`） |
| 无诊疗／产品争点的交通或场所伤残 | 转人身损害领域 |
| 已决定申请医疗损害专门性问题鉴定 | 进入本方法 |

民事案件主位优先考虑司法鉴定事项（解释第 8、11 条）。医学会事故鉴定如用户坚持，必须书面声明：即使不构成事故，仍可能依民法典承担过错责任。未核验地方委托细则则委托路径字段停止。

## 节点 1　事项拆分

每项 `APP#` 固定列：事项原文｜对应 `Q#`｜待证事实｜检材｜是否专门性问题｜判断｜待核。

解释第 11 条允许的事项分别建行，禁止一行写完“责任和赔多少”。伤残和三期可以申请，但其赔偿标准测算转人身损害领域。说明义务事项须同时保留“未造成人身损害则解释第 17 条不支持赔偿”的反方。

产品／血液案件：患者先提交使用和损害证据；缺陷与因果可作为鉴定事项；不存在缺陷或血液合格由被告举证（解释第 7 条），申请稿不得写成患方必须先证明缺陷。

## 节点 2　检材

1. 已封存病历优先列封存编号；未封存标灭失风险，转介封存原子而不是在本申请里改写封存稿。
2. 影像原始数据、病理蜡块、植入物、输液残液分列控制方。不能因对方控制推定检材有利。
3. 缺关键检材：申请仍可起草，但须标鉴定不能或无法出具意见的风险，不补造检材。
4. 回避：列与机构存在利害关系的线索。禁止调查鉴定人隐私或威胁。

## 节点 3　程序位置

- 诉前自行委托：效力和对方案异议风险更高，必须明示。
- 诉中申请：法院应予准许专门性问题；未申请时法院认为需要可依职权委托。不得写“不鉴定就不能起诉”。
- 医调委咨询专家不是鉴定意见，不得写入申请事项冒充已鉴定。

## 节点 4　申请稿与禁止

稿件包含：申请人、被申请人、鉴定机构待定或候选、事项清单、检材目录、鉴定要求（资质、组成、程序、期限名称）。状态 `待提交`。禁止：指定必须的过错比例；要求鉴定人按己方陈述改意见；隐瞒不利病历。
