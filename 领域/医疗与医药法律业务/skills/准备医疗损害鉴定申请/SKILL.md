# 准备医疗损害鉴定申请

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把“不属于医疗事故就不赔偿”写成现行民事前提。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，于已决定申请医疗损害鉴定时，形成“发送前鉴定申请包”：鉴定类型澄清、事项与要求、检材清单、回避、申请稿和不可预测声明。

`depends-on` 为空。接受用户、律师、法院或其他来源的等价评估、病历和争点表。本任务不预测鉴定意见，不代选定鉴定人结论。

## 工作边界

正触发：医疗损害或医疗产品／血液争议需要申请对专门性问题鉴定，用户要申请稿和事项清单。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要在司法鉴定与医疗事故技术鉴定之间做路径比较，不要申请稿；
- 鉴定意见已作出，只要异议或重新鉴定；
- 只要总体评估或只要伤残标准测算；
- 一般交通事故或场所伤害伤残鉴定、无诊疗过错争点；
- 用户要求保证鉴定结论或指定虚假事项。

本任务不生成诉状终稿，不保证法院准许或鉴定意见有利。

## 建立申请坐标

确认：使用者与授权；单方立场；患者与机构及产品主体；是否已立案；拟鉴定事项；已有病历和实物；回避线索；法域；缴费和检材控制方。

同时掌握双方秘密时停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`M#` 检材；`R#` 机关文书；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 争点；`APP#` 鉴定事项；`V#` 申请版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验解释第 8、11 条及鉴定程序规则；`search_template` 只借申请书栏目。工具不可用时继续事项拆分和检材表；准许条件和期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [申请方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 类型澄清与分流

司法鉴定与医疗事故技术鉴定分列。民事赔偿不以构成医疗事故为前提。一般伤残鉴定无诊疗争点则转出。

### 2. 事项拆分

按解释第 11 条逐项：过错；因果及原因力；说明义务与同意；产品缺陷及原因力；伤残；三期。禁止合成“请鉴定医院有没有责任”。

### 3. 检材与回避

列病历、影像、实物、封存状态、缺件风险。回避只列线索，不指导威胁鉴定人。

### 4. 申请稿

发送前稿回链争点。不预测意见，不倒签。未立案时标明诉前委托与诉中申请的差异待核。

### 5. 费用、不预判和转介

鉴定费负担只标接口。需要异议、重新鉴定或起诉时转介，不在本申请写结论。

## 停止与安全

- `整体停止`：立场不明；用户要求伪造检材、买通或威胁鉴定人、保证结论。
- `字段停止`：鉴定程序规则未核验。
- `目标停止`：主目标变为类型选择、异议、总图或诉状。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
