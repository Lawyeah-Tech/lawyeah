# 边界与路由

## 正触发

需要合法查阅、复制或双方在场封存病历，且不要过错结论或鉴定申请。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 大众第一轮应急 | C 端医疗争议材料准备 |
| 已持有病历要审查 | `审查病历真实性完整性` |
| 输液输血注射用药实物 | `封存输液输血注射用药现场实物`（未安装则 `unavailable`） |
| 影像原始数据或切片 | `调取影像病理切片与原始数据`（未安装则 `unavailable`） |
| 公证保全 | 本任务失败升级中的合法公证在场；未安装专项则 `unavailable` |
| 过错总图 | `评估医疗损害争议` |
| 机构并行报告接待 | `规划医疗机构纠纷初期应对` |
| 抢夺、撕封条、改病程 | 整体停止 |

## 易混

封存不等于鉴定，也不等于已经证明隐匿。复制件加盖印记不等于病历真实完整。
