# 准备病历查阅复制与封存

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得用已失效或较窄旧清单否定现行复制范围。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取医院信息系统账号、完整未脱敏第三人病历或密钥。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“病历查阅复制与封存发送前包”：申请主体资格、复制范围、在场要求、封存目录草稿、机构保管安排、禁止动作和到达留痕。

`depends-on` 为空。接受用户、律师或机构提供的等价身份、就诊和已有材料信息。本任务不执行闯窗、不代提交、不把准备写成已经封存。

## 工作边界

正触发：需要依法查阅、复制或双方在场封存病历，且救治不是当前唯一目标。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 生命危险未脱离，用户要以取证中断救治；
- 只要大众第一轮应急清单且不要专业申请稿（C 端只分流）；
- 已持有病历只要真实性审查；
- 只要现场实物（输液输血注射用药）封存，不要病历；
- 只要鉴定申请、诉状或过错结论；
- 用户要求抢夺原件、撕封条、改病程或私自带走封存物。

本任务不认定过错或医疗事故，不保证机构当场交付，不执行发送。

## 建立文书坐标

确认：使用者与授权；患者或近亲属资格；机构全称与病案窗口；门诊／住院／死亡；已复制或已封存部分；拟封存原件或复制件；法域；当前纠纷状态。

机构立场：确认接待部门、保管责任和不得拒绝合法复制。同时掌握双方秘密时停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`B#` 主体资格；`M#` 病历或封存项；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`V#` 文书版本；`E#` 提交／在场凭证。

文书状态只用 `草案`、`待提交`、`已提交待证明`、`已封存`、`停止`。没有在场清单和双方签章，禁止写 `已封存`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典第 1225 条、条例第 16、23、24 条、解释第 6 条范围；`search_template` 只借申请书栏目。工具不可用时继续资格、目录和禁止动作；拒绝复制的法律后果字段停止。

## 五个判断节点

执行顺序和停止条件以 [保全方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 救治闸、资格和立场

救治优先。复制请求人须是患者或死亡患者近亲属等适格主体。资格材料不足则文书终稿停止。

### 2. 复制范围

以条例第十六条和民法典第一千二百二十五条为准，列明类别。不得用较窄旧清单砍掉费用或护理记录。

### 3. 封存闸与目录

封存、启封须双方在场；可为原件或复制件，由机构保管；未完成病历先封已完成部分。目录必须具体，禁止只写“全部病历”。

### 4. 发送前文书和在场清单

申请稿、在场人员、签章、各执一份清单。不倒签日期。不把提交写成已封存。

### 5. 禁止动作与失败升级

拒绝复制标合法催告和诉讼中提交接口。禁止抢夺、撕封条、私自启封。机构不得隐匿。

## 停止与安全

- `整体停止`：立场或资格不明；用户坚持抢夺、撕封条、改病程或中断救治取证。
- `字段停止`：复制范围或封存规则未核验。
- `目标停止`：主目标变为真实性审查、实物封存、鉴定或起诉。

本任务不执行提交，不伪造在场签章。
