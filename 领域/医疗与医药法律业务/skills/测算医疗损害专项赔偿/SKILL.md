# 测算医疗损害专项赔偿

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把已失效《侵权责任法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“医疗损害专项测算包”：事件编号、原发病与扩大损害分账、原因力接口、已付费用核验、一般人身项目转介、情景区间和缺口。

`depends-on` 为空。接受用户、律师、鉴定或其他来源的等价过错假设、原因力和票据。本任务**不认定过错已经成立**。

## 工作边界

正触发：医疗损害或医疗产品／血液争议需要把费用和损失按过错假设与原因力拆开。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要定性总图；
- 主导是交通事故或一般人身侵权项目精算；
- 工伤待遇测算；
- 只要诉状或和解协议正文；
- 用户要求把未知写成零或输出唯一必得总额。

本任务不生成诉状，不给胜诉率，不输出唯一必得总额，不套用地区残疾／死亡赔偿金标准表。

## 建立测算坐标

确认：使用者与授权；单方立场；患者与责任主体；拟测算项目与排除项；过错／原因力假设来源；已付票据；后续治疗假设；法域。

用户希望唯一金额，不构成把未知写成零的授权。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 票据表面；`R#` 鉴定或文书；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`EVT#` 同一经济事件；`M#` 测算行；`V#` 工作表版本。

金额状态只用 `已核实金额`、`情景金额`、`无法估计`、`转介人身损害领域`。未知不写零。真实零必须有肯定来源。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典医疗损害及人身损害赔偿一般规定中与医疗费、护理费相关的现行条件；不把一般标准表引入本包终稿。工具不可用时继续分项建账；原因力乘法和法定标准字段停止。

## 五个判断节点

执行顺序和停止条件以 [测算方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流和测算范围

交通事故项目、一般人身精算、工伤待遇整案转出。本任务展开医疗专项分账，不把过错写成已经成立。

### 2. 事件编号与原发病／扩大损害

同一损害事件分配 `EVT#`。原发病必然发生的费用与争议诊疗扩大的费用分列。无法区分则标 `无法估计`，不平均拆分冒充精确。

### 3. 原因力接口

鉴定或等价材料给出的原因力只作乘法接口。无原因力时输出未乘区间，不编造 25%／50%／75%。实务五档只作说明，不是法定唯一分档。

### 4. 一般人身项目转介

残疾赔偿金、死亡赔偿金、被扶养人生活费、按标准计算的误工和残疾辅助器具：标转介，不套上一年度统计表。

### 5. 互斥、情景和缺口

后续治疗费与已发生医疗费不双计同一服务。情景只改变列明变量。禁止唯一必得总额。

## 停止与安全

- `整体停止`：立场不明；用户坚持伪造票据、隐匿医保已报销或把未知当零。
- `字段停止`：原因力或项目规则未核验。
- `目标停止`：主目标变为总图、诉状或一般人身测算。
