# 边界与路由

## 正触发

机构刚发生不良事件或现场纠纷，需要并行救治、告知、封存、接待和报告。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 患方总图 | `评估医疗损害争议` |
| 患方复制封存稿 | `准备病历查阅复制与封存` |
| 应诉 | `应对医疗损害诉讼` |
| 投诉信访专办 | `处理医疗投诉与信访`（未安装则 `unavailable`） |
| 医闹刑民分流 | `分流医闹治安与刑事交叉`（未安装则 `unavailable`） |
| 卫健处罚申辩 | `应对卫生健康行政处罚`（未安装则 `unavailable`） |
| 通用内部调查 | 企业合规领域 |
| 隐匿或改病程 | 整体停止 |

## 易混

初期应对不是认责声明，也不是答辩状。告知尸检不是鉴定申请。
