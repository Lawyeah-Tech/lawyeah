# 边界与路由

## 正触发

输血适应证、交叉配血或血袋管理出现检查或不良后果，需要用血合规评估。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 实物封存 | 封存输液输血注射用药现场实物 |
| 路径选择 | 选择诊疗过错与药品器械缺陷路径 |
| 产品诉讼 | 提起药品器械产品责任诉讼 |
| 不良反应报告 | 应对药品器械不良反应或不良事件报告 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 生命危险未脱离、仍需急救或手术决策 | 只交付急救与安全交接，不展开本任务策略 |
| 交通事故、场所跌伤、殴打等非诊疗主导 | 人身损害领域 |
| 工伤认定、劳动能力鉴定、工伤待遇 | 劳动领域 |
| 只要大众第一轮应急清单 | C 端医疗争议材料准备（只分流，不回改） |
| 通用企业合规体系或内部舞弊调查全案 | 企业合规领域 |
| 个人信息影响评估、数据跨境、网安体系整案 | 数据隐私领域 |
| 尚未成争，只要改医疗服务合同或未争议服务协议 | 审查起草领域（本窗搁置，只说明不实施） |
| 定罪、控告、辩护或非法行医刑责策略 | 刑事领域（本任务只标红旗） |
| 产品责任诉讼 | 提起药品器械产品责任诉讼 或 defend-product-liability-action |
| 现场血袋封存 | 封存输液输血注射用药现场实物 |

院内诊疗或本领域监管夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

用血管理看核查和制度，不是产品诉讼，也不写输血医嘱。
