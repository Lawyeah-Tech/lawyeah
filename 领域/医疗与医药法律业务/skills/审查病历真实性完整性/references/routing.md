# 边界与路由

## 正触发

已持有病历复制件或封存件，需要完整性、一致性和推定过错接口，而不是复制操作或鉴定意见。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 尚未持有病历，要复制或封存 | `准备病历查阅复制与封存` |
| 调取影像原始数据或病理切片 | `调取影像病理切片与原始数据`（未安装则 `unavailable`） |
| 过错总图 | `评估医疗损害争议` |
| 鉴定申请 | `准备医疗损害鉴定申请` |
| 建卷 | `建立医疗损害证据案卷` |
| 大众应急清单 | C 端医疗争议材料准备 |
| 认定伪造犯罪 | 刑事领域（只标红旗） |

## 易混

病历缺页是完整性争点，不是当然推定过错。抢救补记不是伪造。审查已持有文本时正触发；还没有文本时负触发。
