# 选择医疗服务合同与侵权竞合

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把已失效《侵权责任法》医疗专章同号旧义当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。


## 任务目标

在明确、无利益冲突的单方立场下，形成“请求权选择、时效、管辖、赔偿范围比较，禁止双份重复索赔”。

`depends-on` 为空。接受用户、律师、医学专家、机关或其他来源的等价事实、病历、鉴定、许可和费用清单。

## 工作边界

正触发：同一事实可主张医疗服务合同或侵权，用户需要选择或明确主备位。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要侵权总体评估，合同只是背景；
- 未成争只要改服务合同；
- 用户要求同时全额主张合同和侵权并双计；
- 已决定起诉路径并只要诉状。

本任务不把医疗服务合同解释成适用医疗损害解释，不双份重复索赔，不给胜诉率，不指导伪造、抢夺、威胁、隐匿病历或中断救治取证。

## 建立坐标

确认：使用者与授权；单方立场；服务协议、知情同意、收费、损害、仲裁条款、已主张路径；法域；当前投诉、封存、鉴定、调解、监管或诉讼状态；机关文书作出与送达；对方已知主张；关键材料及缺失。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关、鉴定或生效文书；`M#` 病历、实物或许可台账；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩／合规项；`V#` 评估或稿件版本；`E#` 封存／送达／提交凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典侵权责任与合同编现行规则、医疗损害责任解释第一条第三款、民事诉讼法与仲裁条款；`search_practiced` 补路径与反例；特殊事实用 `search_case_by_fact`。不虚构鉴定、许可或案件系统。

工具不可用时继续事实、主体、材料和问题清单；竞合选择、解释适用范围和论坛法律结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　是否构成竞合

须有同一事实可能产生合同请求和侵权请求。
### 节点 2　解释与规则差异

合同纠纷不适用医疗损害解释。推定过错、病历推定等不得写入合同请求结论。
### 节点 3　时效与论坛

时效、管辖、仲裁按路径分列。
### 节点 4　赔偿范围

合同与侵权的赔偿项目、精神损害、惩罚性接口不同。
### 节点 5　选择与交接

给出主备位，不代替起诉。

## 停止与安全

- `整体停止`：立场不明；用户坚持双份全额重复索赔并要求写成合法。
- `字段停止`：竞合、仲裁或时效规则未核验。
- `目标停止`：主目标变为诉状或合同审查。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
