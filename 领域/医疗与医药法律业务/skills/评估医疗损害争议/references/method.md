# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、论坛、期限或金额接口的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然医疗事故、必然受理或唯一必得总额。

`search_law` 返回已失效《侵权责任法》医疗专章或已失效《合同法》时记为噪声，不得写入 `L#`。不得把《医疗事故处理条例》第四十九条写成现行民事赔偿前提。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜关系假设｜提出方｜相对方｜法律效果｜成立条件｜支持事实｜不利事实｜控制方｜最强反方｜主备位｜判断｜待核`。

诊疗过错、告知同意、产品／血液、合同竞合、不必要检查分列。同一事实支持多项时分别说明效果，不重复金额。不良后果不等于过错。有过错不等于原因力百分之百。

## 节点 0　救治优先与专项分流

先于实体判断。

1. 生命危险未脱离或仍需急救、转诊、手术决策：停止普通策略输出，只交付急救和安全交接。
2. 命中任一项则整案转出，本任务只交付分流理由和最小交接，不填总体评估十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 交通事故、场所跌伤、殴打等非诊疗主导 | 人身损害领域 |
| 工伤认定、劳动能力鉴定、工伤待遇 | 劳动领域 |
| 生活美容、非诊疗纹绣美甲美发 | 人身损害领域 |
| 只要大众第一轮应急清单 | C 端医疗争议材料准备（只分流，不回改） |
| 通用企业合规体系或内部舞弊调查 | 企业合规领域 |
| 个人信息影响评估、数据跨境、网安体系 | 数据隐私领域 |
| 尚未成争，只要改医疗服务合同 | 审查起草领域（本窗搁置，只说明不实施） |
| 刑事非法行医、伪造病历定罪或伤害医务人员刑责 | 刑事领域（本任务只标红旗） |

混合信号：院内诊疗主轴可留本任务；交通事故入院后的诊疗过错段可并列，但交通赔偿项目不在本任务测算。

## 节点 1　主体、病历版本和程序状态

1. 固定患者身份、授权人、医疗机构登记名称、实际科室、执业许可范围、会诊或转诊链条、可能的药品器械持有人／生产者／血液提供机构。名称不一致不自动合并。
2. 病历表记录已复制、已封存、未取得、冲突版本。电子病历与纸质打印件冲突并列，不选对用户有利的一版冒充唯一文本。
3. 程序表逐动作记录投诉、封存、尸检告知、鉴定、医调委、诉讼：机关／机构、案号、文书、作出日、收到日、送达方式和效力凭证。口头转述、截图、“已读”不得写成已受理、已封存或期限已起算。
4. 同时掌握双方秘密或立场不明：整体停止策略输出。

## 节点 2　请求与抗辩假设

每个 `Q#` 先写法律效果，再写成立条件。禁止合成“医院责任”一笔。

默认主位候选按事实分别建立，不得预先锁定必赔：

- `Q-诊` 诊疗过错（民法典第 1218、1221 条；解释第 4、16 条）
- `Q-告` 未尽说明义务且造成人身损害（第 1219 条；解释第 5、17 条：未造成人身损害不予支持）
- `Q-急` 紧急救治／不能取得意见的批准路径（第 1220 条）
- `Q-推` 推定过错红旗（第 1222 条；解释第 6 条病历范围与逾期不提交）
- `Q-产` 药品、消毒产品、器械缺陷或不合格血液（第 1223 条；解释第 3、7 条）
- `Q-合` 医疗服务合同路径（解释第 1 条第三款：合同纠纷不适用该解释）
- `Q-抗` 不配合符合规范的诊疗、紧急情况已尽合理诊疗、限于当时医疗水平难以诊疗（第 1224 条）；医方自身过错仍担相应责任

患者立场：不得把并发症、疾病自然转归或知情同意书签字单独写成医疗机构必无责。机构立场：不得把患方情绪或网络评价写成已构成扰乱秩序并据此免责。

主备位和互斥必须可见。`Q-诊` 与 `Q-产` 可并列，但赔偿事件须编号，避免双计同一损失。原因力未知时金额接口标待核。

## 节点 3　推定过错、鉴定入口和期限

### 3.1 推定过错只做红旗

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 病历缺页、字迹潦草、补记 | 已构成伪造或第 1222 条推定 |
| 机构暂未在窗口交付全部复制件 | 已经拒绝提供并推定过错 |
| 违反某科室习惯 | 已违反法律行政法规规章及诊疗规范 |
| 医学会认为不构成医疗事故 | 民事上必然无责 |

运行时核验第 1222 条和解释第 6 条后再落判断。核验失败则本节点字段停止。

### 3.2 鉴定

专门性问题（解释第 11 条）：诊疗有无过错；因果及原因力；说明义务与明确同意；产品缺陷及原因力；伤残；三期。本任务只判断是否需要鉴定、事项清单接口和最强反方，不写申请终稿，不预测意见。

未申请鉴定不等于请求不成立；法院认为需要可依职权委托（解释第 8 条）。评估阶段不得把“尚未鉴定”写成必然败诉。

### 3.3 期限分类型

| 类型 | 本任务允许的输出 | 禁止 |
| --- | --- | --- |
| 诉讼时效 | 起算事件、备选起算、中断候选 | 唯一截止日 |
| 尸检期间名称 | 摘录四十八小时／七日／冻存条件名称 | 死亡时间加 48 小时写成唯一截止日 |
| 封存满三年机构可自行启封 | 期间名称和起算待核 | 与时效混算 |
| 医调委办理期 | 三十个工作日名称；鉴定时间不计入 | 写成起诉障碍 |
| 答辩期／举证期 | 已进入诉讼时标红旗 | 在评估里写出唯一答辩截止日充作法律意见 |

日期冲突、送达不明、知悉日不明：并行情景 + 字段停止。

## 节点 4　金额接口

本任务只建接口，不替代 `calculate-medical-damage`，更不替代一般人身侵权测算。

1. 分项：与争议诊疗相关的已付医疗费、可区分的原发病费用、后续治疗费假设、住院伙食和护理中与扩大损害相关的部分、鉴定费、交通费中已有票据的部分。
2. 残疾赔偿金、死亡赔偿金、被扶养人生活费、一般误工标准表：只写 `转介人身损害领域`，不套地区标准计算。
3. 原因力未知不得输出乘过后的唯一总额。未知不写零。
4. 精神损害只标是否出现严重人身后果的接口，不定必得。

## 程序与期限表

程序动作记录机关、案号、文书、作出、收到、送达、效力。期限每行只对应一种期间类型和一个起算事件。

## 证据与下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定病历内容有利。

下一步按救治、易失病历实物、期限灭失、改变请求抗辩、可逆性排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。

封存稿、鉴定申请、起诉、应诉、专项精算、完整证据卷只写转介条件和最小交接。禁止指导伪造、抢夺、威胁或违法取证。
