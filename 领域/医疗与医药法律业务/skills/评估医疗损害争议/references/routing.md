# 边界与路由

## 正触发

诊疗活动中已出现不良后果或被指诊疗过错，单方需要总体决定请求、抗辩、鉴定、证据优先级和下一步。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 生命危险未脱离 | 急救与安全交接，不展开本任务 |
| 大众第一轮应急清单 | C 端 `大众第一轮应急清单`（只分流） |
| 审查已持有病历的真实性完整性 | `审查病历真实性完整性` |
| 复制或封存病历 | `准备病历查阅复制与封存` |
| 鉴定申请终稿 | `准备医疗损害鉴定申请` |
| 专项精算 | `测算医疗损害专项赔偿` |
| 完整证据卷 | `建立医疗损害证据案卷` |
| 和解条件 | `谈判医疗和解方案` |
| 起诉 | `提起医疗损害诉讼` |
| 应诉 | `应对医疗损害诉讼` |
| 机构刚发生纠纷要并行封存报告 | `规划医疗机构纠纷初期应对` |
| 一般人身侵权／交通事故项目／工伤 | 人身损害或劳动领域 |
| 未成争改合同 | 审查起草领域（本窗搁置，只说明） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 交通事故、场所跌伤、殴打，诊疗不是责任主轴 | 人身损害领域 |
| 工伤认定、鉴定、待遇 | 劳动领域 |
| 生活美容、非诊疗服务 | 人身损害领域 |
| 企业通用合规、舞弊调查 | 企业合规领域 |
| 个人信息治理、跨境、网安体系 | 数据隐私领域 |
| 定罪、控告、辩护 | 刑事领域 |

院内诊疗夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

请求尚未闭合、需比较过错／产品／告知路径时正触发。主体、请求、鉴定事项均确认且只要申请书或诉状时负触发。医学会“不属于医疗事故”不能单独写成民事无责。
