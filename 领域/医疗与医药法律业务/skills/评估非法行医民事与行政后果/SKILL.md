# 评估非法行医民事与行政后果

## 任务目标

在明确、无利益冲突的单方立场下，形成“民事效力、行政责任、刑民红旗”。

`depends-on` 为空。接受用户、律师、医学专家、机关或其他来源的等价事实、病历、鉴定、许可和费用清单。

## 工作边界

正触发：无证行医或超范围已构成非法行医嫌疑，需要民事和行政层评估。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 要定罪或刑事辩护策略；
- 已进入刑事诉讼；
- 只是轻微超范围注册评估无非法行医嫌疑；
- 生活美容无诊疗内容。

本任务不定罪、不做出辩护策略，刑事转刑事，不给胜诉率，不指导伪造、抢夺、威胁、隐匿病历或中断救治取证。

## 建立坐标

确认：使用者与授权；单方立场；有无医师或机构许可、行为内容、收费、损害、行政机关或公安介入；法域；当前投诉、封存、鉴定、调解、监管或诉讼状态；机关文书作出与送达；对方已知主张；关键材料及缺失。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关、鉴定或生效文书；`M#` 病历、实物或许可台账；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩／合规项；`V#` 评估或稿件版本；`E#` 封存／送达／提交凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验医师法、医疗机构管理条例、民法典合同与侵权效力接口；刑法只作红旗不展开；`search_practiced` 补路径与反例；特殊事实用 `search_case_by_fact`。不虚构鉴定、许可或案件系统。

工具不可用时继续事实、主体、材料和问题清单；民事效力和行政责任法律结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　行为定性（民行层）

只判断有无合法执业资格和是否诊疗行为。
### 节点 2　民事效力

合同可能无效或存在返还、侵权请求，须核验。
### 节点 3　行政责任

取缔、没收、罚款接口。
### 节点 4　刑民红旗

严重情节只标红旗。
### 节点 5　停止项

立即停止无证执业。

## 停止与安全

- `整体停止`：立场不明；要求辩护策略或继续无证执业。
- `字段停止`：民事效力或行政罚则未核验。
- `目标停止`：主目标变为刑事辩护或单纯注册评估。
