# 医疗与医药领域边界

本表只说明归属。每次路由先核对 [当前能力地图](capability-map.md)；未安装入口输出 `unavailable`。

| 相邻 | 本包入口 | 转出 |
| --- | --- | --- |
| 合同审查与起草 | 无。未成争只要改医疗服务合同：本窗搁置，只说明不实施 | 审查起草领域（用户单独策略） |
| 人身损害 | 诊疗过错、病历、鉴定、原因力专项测算 | 一般人身侵权、交通事故项目、场所伤害；残疾／死亡赔偿金标准表 |
| 劳动 | 无 | 工伤认定、劳动能力鉴定、工伤待遇 |
| 企业合规 | 卫健／药监／医保／麻精／院感等行业专项 | 企业通用合规体系和内部舞弊调查 |
| 数据隐私 | 诊疗中病历隐私的行业责任接口（`评估诊疗中病历隐私泄露行业后果`，已安装） | 个人信息影响评估、跨境、网络安全专项治理 |
| 行政争议 | 卫健／药监行业申辩接口（`respond-health-admin-penalty`、`respond-nmpa-penalty`，已安装） | 通用行政复议诉讼文书 |
| 刑事 | 评估中的刑民交叉只标红旗 | 定罪、控告、辩护 |
| C 端医疗争议材料准备 | 专业评估、封存稿、鉴定或诉讼 | 大众第一轮急救分流和保全清单 |
| C 端 011／012 | 专业起诉／应诉包 | 大众网上立案或普通民事答辩 |

院内诊疗夹带交通、工伤或产品背景时，专项段只分流，不把专项规则写入本包结论。
