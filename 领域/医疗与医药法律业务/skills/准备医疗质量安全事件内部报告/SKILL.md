# 准备医疗质量安全事件内部报告

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把已失效《侵权责任法》医疗专章同号旧义当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。


## 任务目标

在明确、无利益冲突的机构方立场下，形成“报告口径、时限名称、对外披露边界”。

`depends-on` 为空。接受用户、律师、医学专家、机关或其他来源的等价事实、病历、鉴定、许可和费用清单。

## 工作边界

正触发：需按院感或不良事件制度上报医疗质量安全事件。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主轴是卫健处罚申辩；
- 用户要求补造报告消灭不利证据；
- 只要对患方的投诉答复；
- 药品器械不良反应报告主轴。

本任务不代替监管申辩，禁止补造报告消灭证据，不给胜诉率，不指导伪造、抢夺、威胁、隐匿病历或中断救治取证。

## 建立坐标

确认：使用者与授权；单方立场；事件分级线索、发现时间、已采取措施、报告对象、对外新闻口径；法域；当前投诉、封存、鉴定、调解、监管或诉讼状态；机关文书作出与送达；对方已知主张；关键材料及缺失。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关、鉴定或生效文书；`M#` 病历、实物或许可台账；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩／合规项；`V#` 评估或稿件版本；`E#` 封存／送达／提交凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验医疗质量安全事件报告相关现行规范、医院感染管理办法、医疗纠纷预防和处理条例报告条款；`search_practiced` 补路径与反例；特殊事实用 `search_case_by_fact`。不虚构鉴定、许可或案件系统。

工具不可用时继续事实、主体、材料和问题清单；报告时限和分级法律结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　是否属于报告事件

对照质量安全事件和院感暴发定义，不认定医学感染源。
### 节点 2　时限名称

分列发现后报告时限名称，不写唯一截止日。
### 节点 3　口径

只写已核实事实、已采取措施和未知项。
### 节点 4　对外披露边界

内部报告不等于新闻稿，也不是对患方的责任承认。
### 节点 5　与申辩分卷

不代替监管申辩。

## 停止与安全

- `整体停止`：立场不明；补造报告消灭证据。
- `字段停止`：报告分级或时限规则未核验。
- `目标停止`：主目标变为处罚申辩或对外危机公关整案。
