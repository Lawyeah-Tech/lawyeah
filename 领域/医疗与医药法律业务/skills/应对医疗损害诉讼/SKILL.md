# 应对医疗损害诉讼

## 任务目标

在明确、无利益冲突的被告立场下，形成首次应诉答辩包：答辩期限卡、原告请求拆解、第 1224 条抗辩、推定过错回应、鉴定意见、证据和禁止隐匿病历声明。

`depends-on` 为空。接受用户、律师或机关提供的起诉材料和病历。原告侧未向被告披露的秘密不得写入答辩。

## 工作边界

正触发：医疗机构、医务人员所在单位或药品器械／血液主体已收到起诉状或应诉通知，需要专业答辩。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 用户实为原告；
- 劳动应诉；
- 只要大众民事答辩包（C 端 012 只分流）；
- 只要管辖异议终稿且无实体；
- 只要和解方案；
- 用户要求隐匿、抽页或补造病历。

本任务不自动生成反诉状终稿，不保证免于缺席或胜诉。

## 建立应诉坐标

确认：使用者与授权；被告立场；收到的每份文书作出日、送达日、送达方式；病历是否已封存或已提交法院；鉴定状态；仲裁或管辖争点。口头转述不得写成已送达。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关文书；`M#` 病历；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`K#` 期限卡；`H#` 抗辩；`V#` 稿件版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把已失效《侵权责任法》当作现行规则。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验答辩期间、管辖异议期间、解释第 4–7、16、17 条、第 1224 条。工具不可用时继续文书登记和请求拆解；截止日和法律结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [应诉方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、被告立场和材料权限

劳动应诉转出。固定授权。不得用未向被告披露的患方秘密。

### 2. 答辩期限卡

每份文书单独一行。作出日与送达日分列。已读不等于送达。

### 3. 请求拆解与推定／管辖红旗

承认、否认、不知、抗辩分列。逾期不提交病历的推定风险必须写入。

### 4. 答辩草稿与鉴定接口

第 1224 条抗辩须有事实。反诉只评估接口。

### 5. 证据与禁止事项

不利病历必须进入最强反方。拒绝隐匿或补造。

## 停止与安全

- `整体停止`：立场不明；用户坚持隐匿病历、虚假陈述或伪造。
- `字段停止`：送达日不明或规则未核验。
- `目标停止`：主目标变为管辖异议终稿、反诉状或和解协议正文。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
