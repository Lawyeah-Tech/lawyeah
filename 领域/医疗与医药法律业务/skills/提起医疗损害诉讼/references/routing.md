# 边界与路由

## 正触发

已决定起诉医疗损害或产品／血液责任主体，需要专业起诉包。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 总图、鉴定、测算、建卷 | 相应原子 |
| 被告应诉 | `应对医疗损害诉讼` |
| 产品责任主轴且只要产品两造文书 | `提起药品器械产品责任诉讼`（未安装则 `unavailable`，可用本任务并限定产品请求） |
| 一般人身侵权起诉 | 人身损害领域 |
| 大众网上立案 | C 端 011，只分流 |
| 有效仲裁未排除 | 论坛评估，不写应起诉 |

## 易混

可以未鉴定先起诉。不属于医疗事故不是不受理理由。
