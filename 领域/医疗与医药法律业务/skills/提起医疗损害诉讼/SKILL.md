# 提起医疗损害诉讼

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把已失效《侵权责任法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的原告立场下，形成可复核、不代提交的“医疗损害一审起诉包”：起诉状草稿、分项诉讼请求、被告与追加接口、管辖连结点、鉴定申请接口、证据目录和保全／先予执行红旗。

`depends-on` 为空。接受用户、律师或其他来源的等价评估、测算、病历和鉴定材料。

## 工作边界

正触发：用户已决定向人民法院提起医疗损害或医疗产品／血液侵权之诉。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要总体评估、和解或鉴定申请；
- 用户实为被告；
- 一般人身侵权或交通事故主轴，诊疗不是责任基础；
- 工伤待遇或劳动仲裁；
- 表面有效仲裁协议未被排除仍要求“直接起诉”；
- 只要大众网上立案材料且请求论坛已闭合（C 端 011 只分流）。

本任务不代提交，不保证受理或胜诉，不写保全申请终稿，不要求必须先构成医疗事故。

## 建立起诉坐标

确认：使用者与授权；原告资格；被告及产品／血液主体；拟请求；病历与鉴定状态；仲裁条款；管辖连结点；是否已有案号。已有受理凭证则停止生成起诉入口材料。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或鉴定；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#`／`P#` 请求；`J#` 管辖；`V#` 稿件版本；`E#` 送达凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验起诉条件、管辖、解释第 1、3 条追加、期间；`search_template` 只借起诉状栏目。工具不可用时继续主体、事实和证据目录；管辖选定和期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [起诉方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、起诉决定和仲裁闸

专项整案转出。仲裁条款表面有效且未排除则负触发。

### 2. 主体与分项请求

诊疗过错、告知、产品／血液、费用、鉴定费分列。禁止合成“医院责任”。不要求先鉴定才能诉。

### 3. 管辖连结点

侵权行为地、被告住所地、产品主体所在地分列。材料不足不选定唯一法院。

### 4. 证据目录与鉴定接口

证据绑定请求。鉴定事项只留接口或引用已有申请，不在起诉包预测意见。

### 5. 起诉状草稿与提交核验

只交付草案。不代提交。不降成 C 端 011。

## 停止与安全

- `整体停止`：立场不明；用户坚持虚假陈述或伪造病历。
- `字段停止`：管辖、仲裁排除、动态规则未核验。
- `目标停止`：主目标变为保全终稿、鉴定申请或答辩。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
