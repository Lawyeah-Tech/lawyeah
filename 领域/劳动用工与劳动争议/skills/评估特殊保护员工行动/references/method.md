# 评估特殊保护员工行动方法

本文件是可执行判断节点，不是栏目说明书。每个会改变路径、请求、金额、期限或可提交状态的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不给胜诉率、必然受理、必然有效或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。劳动、社保、工伤、仲裁和执行规则一律运行时核验现行文本后再落判断。

一般商事合同、采购外包主合同、股权交易文件的审查与起草转交审查起草领域；本窗搁置，只说明不实施，不回改该领域或 C 端 109 专项。

## 节点 1　保护事实

保护状态必须可回链。

- if 孕产或医疗期状态只有口头怀疑
  then 保护字段依据不足，不得按无保护处理
- if 用户要求本任务作出流产或伤残等级结论
  then 拒绝，转医疗机构或鉴定
- if 多类保护重叠
  then 分别列期限，取更严格的停止条件

## 节点 2　措施定性

每项措施单独判断。

- if 拟解除或终止
  then 先核验法定禁止情形，不支持则停止该路径
- if 拟调岗但缺少岗位必要性
  then 单方调岗依据不足
- if 实为绩效改善或处分
  then 拆出对应原子

## 节点 3　禁止与例外

例外必须有明确法定或事实支持。

- if 处于孕产哺乳或医疗期仍拟过失性以外解除
  then 现有依据通常不支持，路径停止
- if 合同期满但保护期未结束
  then 续延字段进入核验，不得按普通终止
- if 未成年工拟安排禁忌岗位
  then 现有依据不支持

## 节点 4　安置

安置不是医学适岗。

- if 需要职业禁忌或劳动能力结论
  then 只接受合格鉴定，本任务不预测等级
- if 无适当岗位
  then 安置不能字段依据不足，不得径行解除
- if 批量保护人员处理
  then 筛查是否构成裁员

## 节点 5　停止

不得提供规避保护的方案。

- if 用户要求以协商或调岗名义逼退保护期员工
  then 整体停止
- if 保护截止日期冲突
  then 并行情景，不选最早解禁日
- if 已发出解除通知
  then 目标停止，路由实施补救或争议

## 证据、金额与下一步

- if 关键事实仅有单方陈述且对方控制原始材料:
  then 不得因对方控制而推定材料存在或内容有利；只列控制方、补证路径和最晚时点。
- if 金额参数不足或地方基数未核验:
  then 只列公式、已知参数、未知参数和区间接口，未知不写零，不输出唯一必得总额。
- if 期限起算日、送达日或知悉日冲突:
  then 建立并行情景并字段停止，不选对用户最有利的一天冒充唯一截止日。
- if 用户要求预测胜诉率或保证机关支持:
  then 拒绝该字段，继续交付可复核事实、条件和缺口。
- if 用户要求倒签、补造程序、伪造送达、隐匿财产或违法取证:
  then 整体停止，只输出拒绝、保全真实材料和按真实日期恢复的条件。

下一步按期限灭失、易失证据、能否改变本任务结论、不可逆性和成本排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。不代用户向机关或对方实际提交。
