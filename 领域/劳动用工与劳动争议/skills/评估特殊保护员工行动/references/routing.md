# 边界与路由

## 正触发

管理方拟对受特殊保护人员采取措施，需要可行性、期限和停止条件。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 医学或职业危害技术结论 | 有资质机构 | 不作诊断或检测 |
| 已选解除只要实施 | 实施单位解除终止 | 不写通知 |
| 绩效改善方案 | 设计绩效改善 | 不写 PIP |
| 工伤待遇测算 | 测算工伤待遇 | 不测算待遇 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 职业病诊断与危害评价 | 有资质职业卫生机构 |
| 劳动能力鉴定 | P2 unavailable |
| 歧视的行政或公益诉讼 | 行政或其他专业 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

保护期内能否调整或必须停止是正触发；用户只要一份解除通知，或要你下医学结论时负触发。保护期冲突必须并行情景。
