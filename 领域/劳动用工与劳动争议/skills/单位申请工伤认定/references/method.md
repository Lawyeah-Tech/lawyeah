# 单位申请工伤认定方法

本文件是可执行判断节点，不是栏目说明书。每个会改变路径、请求、金额、期限或可提交状态的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不给胜诉率、必然受理、必然有效或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。劳动、社保、工伤、仲裁和执行规则一律运行时核验现行文本后再落判断。

一般商事合同、采购外包主合同、股权交易文件的审查与起草转交审查起草领域；本窗搁置，只说明不实施，不回改该领域或 C 端 109 专项。

## 节点 1　谁申请

单位申请与职工申请互斥为主成果。

- if 实际申请人是职工或近亲属
  then 负触发，路由职工申请
- if 单位期限可能已过
  then 字段停止可提交，必须提示职工路径
- if 事故刚发生尚未整理申请
  then 若主目标是响应则负触发

## 节点 2　事实

申请叙述不是认定结论。

- if 时间地点原因缺失
  then 对应事实受限
- if 存在醉酒或犯罪等排除嫌疑
  then 必须列入，不得删除
- if 要求写成必然认定工伤
  then 拒绝

## 节点 3　材料

单位不得隐瞒不利材料。

- if 考勤与外出记录冲突
  then 并列
- if 要求伪造劳动合同或考勤
  then 整体停止
- if 未参保
  then 如实写，不编造参保

## 节点 4　提交

草案不是已受理。

- if 管辖地未核验
  then 机关字段停止
- if 用户要求代为提交
  then 拒绝
- if 已收到补正或调查通知
  then 目标停止，路由调查应对

## 节点 5　分界

第三人侵权不在本申请解决。

- if 主诉求是第三人赔偿
  then 转人身损害
- if 需要复议文书
  then 转行政领域
- if 只要待遇测算
  then 路由待遇测算

## 证据、金额与下一步

- if 关键事实仅有单方陈述且对方控制原始材料:
  then 不得因对方控制而推定材料存在或内容有利；只列控制方、补证路径和最晚时点。
- if 金额参数不足或地方基数未核验:
  then 只列公式、已知参数、未知参数和区间接口，未知不写零，不输出唯一必得总额。
- if 期限起算日、送达日或知悉日冲突:
  then 建立并行情景并字段停止，不选对用户最有利的一天冒充唯一截止日。
- if 用户要求预测胜诉率或保证机关支持:
  then 拒绝该字段，继续交付可复核事实、条件和缺口。
- if 用户要求倒签、补造程序、伪造送达、隐匿财产或违法取证:
  then 整体停止，只输出拒绝、保全真实材料和按真实日期恢复的条件。

下一步按期限灭失、易失证据、能否改变本任务结论、不可逆性和成本排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。不代用户向机关或对方实际提交。
