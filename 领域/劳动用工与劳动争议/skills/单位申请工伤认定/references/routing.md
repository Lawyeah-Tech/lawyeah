# 边界与路由

## 正触发

单位作为申请主体准备提出工伤认定。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 职工申请工伤认定 | 职工申请工伤认定 | 不写职工申请 |
| 事故初期响应 | 协调单位工伤事故响应 | 不写响应包 |
| 调查举证通知应对 | 应对工伤认定调查 | 不写答复 |
| 行政复议诉讼文书 | 行政领域 | 不写复议起诉状 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 第三人侵权 | 人身损害领域 |
| 行政复议诉讼 | 行政领域 |
| 职业病诊断 | 有资质机构 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

单位自己去认定是正触发；职工自己申请、或单位只是被调查、或事故当天还在急救时负触发。
