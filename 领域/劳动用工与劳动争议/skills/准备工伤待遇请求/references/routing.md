# 边界与路由

## 正触发

职工方已有认定或鉴定，待遇未付，需要请求方案而不是立案文书本身。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 程序立案文书 | 提起劳动仲裁 等 | 不写可提交申请 |
| 单纯测算 | 测算工伤待遇 | 不把测算当请求方案 |
| 尚无认定的申请 | 职工或单位认定申请 | 不写认定申请 |
| 第三人侵权 | 人身损害领域 | 不写侵权请求 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 第三人侵权 | 人身损害领域 |
| 基金行政决定不服 | 行政分流或行政领域 |
| 执行未支付的生效文书 | 执行原子 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

认定鉴定已有、待遇没给、要请求结构是正触发；直接要仲裁申请书，或还没认定就主张伤残补助时拆分。
