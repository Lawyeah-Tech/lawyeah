# 边界与路由

## 正触发

企业要求检查限定组织、期间和样本的综合用工合规，管理方需要差距、分级和整改顺序。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 重写全部规章制度 | 建立劳动规章制度 | 不输出制度定稿 |
| 交易或上市劳动尽调 | 开展劳动专项尽调 | 不写尽调报告 |
| 仅薪酬工时休假样本审计 | 审计薪酬工时休假 | 不形成精算表 |
| 判断既有事实关系 | 识别劳动关系与责任主体 | 不做关系终局 |
| 个案处分或调查 | 调查或处分原子 | 不写处分通知 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 企业级舞弊、反贿赂或综合合规体系 | 企业合规领域 |
| 完整个人信息影响评估或跨境传输 | 数据隐私领域 |
| 交易结构、交割和估值 | 投资并购领域 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

限定范围的综合差距表是正触发；用户只要薪酬工时一张精算表或只要尽调报告时负触发。样本审计发现疑似派遣或外包，只建风险单元，不把本任务改写成关系识别。
