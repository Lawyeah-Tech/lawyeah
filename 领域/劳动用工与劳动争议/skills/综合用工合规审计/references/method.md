# 综合用工合规审计方法

本文件是可执行判断节点，不是栏目说明书。每个会改变路径、请求、金额、期限或可提交状态的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不给胜诉率、必然受理、必然有效或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。劳动、社保、工伤、仲裁和执行规则一律运行时核验现行文本后再落判断。

一般商事合同、采购外包主合同、股权交易文件的审查与起草转交审查起草领域；本窗搁置，只说明不实施，不回改该领域或 C 端 109 专项。

## 节点 1　范围与样本

审计结论不得超出已闭合的组织、期间和样本。

- if 组织、期间或样本未由委托确认
  then 只建立受限坐标，不把样本缺口写成全员违法或全员合规
- if 用户要求覆盖未抽样历史全员并给出确定总额
  then 金额字段停止，只给外推条件和禁止外推声明
- if 同时掌握劳动者投诉秘密且未获该方授权
  then 停止使用该秘密，澄清只代表管理方

## 节点 2　关系形态

标签不能替代实际用工测试。

- if 合同写外包或合作但单位直接管理考勤奖惩和报酬
  then 列为疑似劳动关系或派遣风险单元，不在本任务做关系终局
- if 派遣比例或岗位限制未核验
  then 比例和岗位字段停止，不写成已经合法或已经违法
- if 平台或个体户安排缺少履行材料
  then 依据不足，并列合作与用工两套假设

## 节点 3　制度与薪酬接口

综合审计记录差距，不重写制度，不做精算。

- if 制度未经民主或公示材料不可读
  then 该制度不得作为处分或调岗依据接口，路由制度建设
- if 主要目标变成重写全部手册
  then 负触发，停止本任务制度正文
- if 工资工时需要逐人逐期间精算
  then 只留接口给薪酬工时审计或个体测算，不吞并精算成果

## 节点 4　社保公积金分轨

两轨分开，互不替代。

- if 出现住房公积金未缴少缴
  then 将住房公积金缺口转出到规划住房公积金整改，本任务只记分轨接口，不把公积金缺口并入社保总额
- if 用户要求把纯补缴包装为劳动仲裁请求
  then 拒绝该包装，分流到劳动者征缴申请或行政路径，不把纯补缴写入仲裁请求
- if 未向机关核实缴费记录
  then 缴费缺口标为依据不足，不得写成无需整改或不存在历史责任

## 节点 5　分级与整改

按不可逆性、人数和行政暴露排序整改。

- if 差距可能触发批量解除或裁员
  then 停止按个体解除复制，路由裁员安置
- if 用户要求伪造覆盖率或倒签民主程序
  then 整体停止，只输出拒绝和按真实日期恢复的条件
- if 整改需要行政许可或机关确认
  then 不冒充机关办结，只列办理接口和材料

## 证据、金额与下一步

- if 关键事实仅有单方陈述且对方控制原始材料:
  then 不得因对方控制而推定材料存在或内容有利；只列控制方、补证路径和最晚时点。
- if 金额参数不足或地方基数未核验:
  then 只列公式、已知参数、未知参数和区间接口，未知不写零，不输出唯一必得总额。
- if 期限起算日、送达日或知悉日冲突:
  then 建立并行情景并字段停止，不选对用户最有利的一天冒充唯一截止日。
- if 用户要求预测胜诉率或保证机关支持:
  then 拒绝该字段，继续交付可复核事实、条件和缺口。
- if 用户要求倒签、补造程序、伪造送达、隐匿财产或违法取证:
  then 整体停止，只输出拒绝、保全真实材料和按真实日期恢复的条件。

下一步按期限灭失、易失证据、能否改变本任务结论、不可逆性和成本排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。不代用户向机关或对方实际提交。
