# 设计绩效改善方法

本文件是可执行判断节点，不是栏目说明书。每个会改变路径、请求、金额、期限或可提交状态的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不给胜诉率、必然受理、必然有效或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。劳动、社保、工伤、仲裁和执行规则一律运行时核验现行文本后再落判断。

一般商事合同、采购外包主合同、股权交易文件的审查与起草转交审查起草领域；本窗搁置，只说明不实施，不回改该领域或 C 端 109 专项。

## 节点 1　定性

绩效不是违纪。

- if 主要事实是违纪或骚扰
  then 负触发，路由调查或处分
- if 处于医疗期或孕产期
  then 先转特殊保护评估
- if 只有主观评价无事实
  then 不能胜任依据不足

## 节点 2　标准

标准必须事先存在并可核验。

- if 考核制度未民主公示
  then 不得以该制度作为不能胜任依据
- if 标准在启动改善后才编写
  then 事后标准不支持
- if 同类人员适用明显不一致
  then 记录不利事实

## 节点 3　培训或调岗

非过失解除前的法定前置不得虚构。

- if 方案不含真实培训或调岗选项
  then 不得把本方案写成已经满足法定前置
- if 调岗具有侮辱性或显著降薪
  then 合理性依据不足
- if 用户明确要求走完形式立即解除
  then 目标停止，不提供走过场方案

## 节点 4　证据

记录必须真实。

- if 要求补造以往辅导记录
  then 整体停止
- if 不给员工陈述机会
  then 程序缺口列入
- if 周期短到无法完成既定任务
  then 方案有效性依据不足

## 节点 5　出口

改善不等于解除决定。

- if 用户已选定解除只要通知
  then 负触发，路由退出评估或实施
- if 改善期未结束就拟按严重违纪解除
  then 禁止混用路径
- if 需要变更劳动条件
  then 变更部分转条件变更原子

## 证据、金额与下一步

- if 关键事实仅有单方陈述且对方控制原始材料:
  then 不得因对方控制而推定材料存在或内容有利；只列控制方、补证路径和最晚时点。
- if 金额参数不足或地方基数未核验:
  then 只列公式、已知参数、未知参数和区间接口，未知不写零，不输出唯一必得总额。
- if 期限起算日、送达日或知悉日冲突:
  then 建立并行情景并字段停止，不选对用户最有利的一天冒充唯一截止日。
- if 用户要求预测胜诉率或保证机关支持:
  then 拒绝该字段，继续交付可复核事实、条件和缺口。
- if 用户要求倒签、补造程序、伪造送达、隐匿财产或违法取证:
  then 整体停止，只输出拒绝、保全真实材料和按真实日期恢复的条件。

下一步按期限灭失、易失证据、能否改变本任务结论、不可逆性和成本排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。不代用户向机关或对方实际提交。
