# 边界与路由

## 正触发

管理方要对绩效或能力问题实施改善期，目标是方案和证据，而不是处分或解除。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 预设解除实施 | 退出评估或解除实施 | 不写解除通知 |
| 违纪处分 | 决定劳动纪律处分 | 不写处分决定 |
| 工作场所调查 | 调查工作场所投诉 | 不写调查报告 |
| 已形成争议 | 评估劳动争议 | 不写争议矩阵 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 企业级绩效体系咨询 | 非法律专项 |
| 医学不能上班 | 医疗机构或特殊保护 |
| 集体合同考核条款 | P2 集体协商 unavailable |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

要一份可执行的改善期方案是正触发；心里已经决定解除只差走形式，或把迟到旷工当绩效时负触发。
