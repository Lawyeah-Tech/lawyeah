# 边界与路由

## 正触发

管理方要对特定人员落地调岗、调薪、地点、借调或派驻。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 期满续订 | 评估劳动合同续订 | 不做续订决策 |
| 绩效改善 | 设计绩效改善 | 不写 PIP |
| 并购或主体变更批量转移 | 实施员工转移 | 不做批量转移 |
| 解除终止实施 | 实施单位解除终止 | 不发解除通知 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 一般商事借调或服务协议 | 审查起草领域（本窗搁置） |
| 医学适岗结论 | 有资质医疗机构 |
| 交易结构 | 投资并购领域 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

对在职人员落地单项条件变更是正触发；借变更实施解除、借续订改条件或多人组织迁移应拆出。单方“通知调岗”在缺少依据时不得写成已经生效。
