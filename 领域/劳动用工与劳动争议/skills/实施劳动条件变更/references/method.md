# 实施劳动条件变更方法

本文件是可执行判断节点，不是栏目说明书。每个会改变路径、请求、金额、期限或可提交状态的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不给胜诉率、必然受理、必然有效或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。劳动、社保、工伤、仲裁和执行规则一律运行时核验现行文本后再落判断。

一般商事合同、采购外包主合同、股权交易文件的审查与起草转交审查起草领域；本窗搁置，只说明不实施，不回改该领域或 C 端 109 专项。

## 节点 1　是否条件变更

期满续订、PIP、批量转移和退出不是本任务。

- if 主轴是合同到期续订
  then 负触发，路由续订评估
- if 主轴是不能胜任的改善期
  then 负触发，路由绩效改善
- if 同一组织调整驱动多人转移
  then 先筛查批量转移或裁员

## 节点 2　合意与合理调整

单方调整必须有合同制度依据和合理性。

- if 合同未约定调整权且无协商一致
  then 不得写成已经有权单方变更
- if 调岗明显降薪、地点显著不便或具有侮辱性
  then 合理性依据不足或不支持
- if 借调或派驻改变用人单位主体
  then 可能构成转移或借调，主体字段单独核验

## 节点 3　保护与禁止

特殊保护可阻断变更。

- if 孕产哺乳或医疗期状态未知
  then 受影响变更字段停止
- if 职业禁忌或工伤后调岗缺少医学意见
  then 不作医学结论，变更停止
- if 变更疑似报复举报或歧视
  then 整体停止实施稿

## 节点 4　文件生效

通知到达和签署是不同状态。

- if 协议未签且通知未发
  then 保持草案，不写已变更
- if 电子送达渠道未确认
  then 送达字段停止
- if 用户要求倒签变更日
  then 整体停止

## 节点 5　拒绝后路径

拒绝变更不等于已选择解除。

- if 劳动者明确拒绝且单位拟解除
  then 本任务停止实施，路由退出评估
- if 单位拟按旷工处理但变更本身未闭合
  then 不得补造旷工事实
- if 需要一般商事借调协议
  then 商事正文转审查起草领域，本窗搁置

## 证据、金额与下一步

- if 关键事实仅有单方陈述且对方控制原始材料:
  then 不得因对方控制而推定材料存在或内容有利；只列控制方、补证路径和最晚时点。
- if 金额参数不足或地方基数未核验:
  then 只列公式、已知参数、未知参数和区间接口，未知不写零，不输出唯一必得总额。
- if 期限起算日、送达日或知悉日冲突:
  then 建立并行情景并字段停止，不选对用户最有利的一天冒充唯一截止日。
- if 用户要求预测胜诉率或保证机关支持:
  then 拒绝该字段，继续交付可复核事实、条件和缺口。
- if 用户要求倒签、补造程序、伪造送达、隐匿财产或违法取证:
  then 整体停止，只输出拒绝、保全真实材料和按真实日期恢复的条件。

下一步按期限灭失、易失证据、能否改变本任务结论、不可逆性和成本排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。不代用户向机关或对方实际提交。
