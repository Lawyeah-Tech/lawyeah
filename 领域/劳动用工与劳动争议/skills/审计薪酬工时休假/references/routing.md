# 边界与路由

## 正触发

单位侧需要对明确总体或可界定样本开展薪酬、工时、加班、调休和休假专项审计，并形成风险、差额、整改和复测成果。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 单个劳动者的工资工时休假金额 | 个体权益测算 | 不代算最终请求金额 |
| 离职补偿赔偿和结算 | 离职款项测算 | 不扩张到退出款项 |
| 直接发薪、扣款或会计入账 | 工资核算操作 | 不执行付款和账务 |
| 社保、公积金或税务专项 | 相应专项任务 | 不把相邻参数并入本报告 |
| 仲裁诉讼请求或抗辩 | 争议或程序任务 | 不生成可提交文书 |
| 新建规章制度 | 制度建设 | 只记录整改接口，不代写完整制度 |

## 易混场景

对一批人员逐人计算仍可属于审计，但必须有单位侧总体、抽样、控制和整改目标；仅服务一个人的款项主张则负触发。规则包未覆盖地方参数时审计结构继续、地方金额和总体结论停止。整改清单形成不等于批准、支付或复测完成。
