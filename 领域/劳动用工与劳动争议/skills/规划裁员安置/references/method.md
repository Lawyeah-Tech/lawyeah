# 规划裁员安置方法

本文件是可执行判断节点，不是栏目说明书。每个会改变路径、请求、金额、期限或可提交状态的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不给胜诉率、必然受理、必然有效或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。劳动、社保、工伤、仲裁和执行规则一律运行时核验现行文本后再落判断。

一般商事合同、采购外包主合同、股权交易文件的审查与起草转交审查起草领域；本窗搁置，只说明不实施，不回改该领域或 C 端 109 专项。

## 节点 1　批量闸

同一组织调整驱动的多人退出先按批量测试。

- if 人数或比例达到法定裁员标准
  then 不得拆成多个体过失或不能胜任来规避
- if 只有个别人员且无组织原因
  then 负触发，路由个体退出评估
- if 实为并购交割人员去留决策但无减员
  then 可能转员工转移

## 节点 2　事由

经营困难必须有可核材料。

- if 只有口头说活不下去
  then 法定事由依据不足
- if 未说明情况或未听取工会职工意见
  then 程序未完成，停止可实施
- if 地方报告口径未核验
  then 报告字段停止

## 节点 3　选择

禁止清单优先。

- if 拟裁孕产医疗期或工伤人员
  then 现有依据不支持
- if 按举报人或工会委员名单淘汰
  then 报复风险，停止该选择
- if 优先留用条件未核验
  then 选择字段受限

## 节点 4　程序

报告不是批准，但缺少报告不得假装已完成。

- if 报告材料未形成
  then 不得写成已经合法裁员
- if 要求倒签听取意见记录
  then 整体停止
- if 部分人员走协商部分走裁员
  then 分册，不混用通知模板

## 节点 5　成本与交易

本任务不设计交易。

- if 补偿参数不足
  then 只给公式和区间，未知不写零
- if 用户要交易对价或交割统筹
  then 负触发交易部分，转并购领域
- if 用户要求保证不会发生群体事件
  then 拒绝保证

## 证据、金额与下一步

- if 关键事实仅有单方陈述且对方控制原始材料:
  then 不得因对方控制而推定材料存在或内容有利；只列控制方、补证路径和最晚时点。
- if 金额参数不足或地方基数未核验:
  then 只列公式、已知参数、未知参数和区间接口，未知不写零，不输出唯一必得总额。
- if 期限起算日、送达日或知悉日冲突:
  then 建立并行情景并字段停止，不选对用户最有利的一天冒充唯一截止日。
- if 用户要求预测胜诉率或保证机关支持:
  then 拒绝该字段，继续交付可复核事实、条件和缺口。
- if 用户要求倒签、补造程序、伪造送达、隐匿财产或违法取证:
  then 整体停止，只输出拒绝、保全真实材料和按真实日期恢复的条件。

下一步按期限灭失、易失证据、能否改变本任务结论、不可逆性和成本排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。不代用户向机关或对方实际提交。
