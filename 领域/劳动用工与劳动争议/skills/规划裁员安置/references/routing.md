# 边界与路由

## 正触发

管理方面对批量减员或重组，需要按群体程序而不是复制多个体解除。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 复制多个体解除 | 实施单位解除终止 | 不按个体通知批量套用 |
| 交易结构与交割 | 投资并购领域 | 不写交易文件 |
| 个体协商解除 | 准备协商解除 | 协商人员另册 |
| 员工转移而非减员 | 实施员工转移 | 不写裁员方案 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 交易结构、对价和交割 | 投资并购领域 |
| 破产重整职工安置债权 | 破产领域 |
| 群体事件公共安全 | 相邻公共安全或刑事 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

组织原因驱动的批量减员是正触发；把二十人拆成二十份过失解除，或把并购人员转移写成裁员时必须纠正入口。
