# 边界与路由

## 正触发

已决定向劳动人事争议仲裁机构提出具体申请，需要可提交的立案材料。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 被申请方答辩 | 应对劳动仲裁 | 不写答辩 |
| 完整庭审准备 | 准备劳动仲裁庭审 | 不写庭审提纲 |
| 争议评估尚未决定仲裁 | 评估劳动争议 | 不写申请书 |
| 一审起诉 | 提起劳动争议一审 | 不写起诉状 |
| 单位撤裁 | 单位申请撤销终局裁决 | 不按起诉处理 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 集体劳动争议代表程序 | P2 unavailable |
| 行政复议 | 行政领域 |
| C 端仲裁申请消费包 | 只分流不回改 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

申请方要立案材料是正触发；收到申请要答辩、或还在评估该不该告、或已经要开庭提纲时负触发。
