# 边界与路由

## 正触发

单位侧针对终局裁决寻求撤销，而不是普通起诉。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 普通一审起诉 | 提起劳动争议一审 | 不写起诉状 |
| 劳动者不服终局 | 提起劳动争议一审 | 劳动者走起诉 |
| 仲裁申请或答辩 | 仲裁原子 | 不写仲裁文书 |
| 执行异议 | 应对劳动执行 | 不写执行异议 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 普通商事仲裁撤裁 | 争议解决其他领域 |
| 再审 | P2 unavailable |
| 行政起诉 | 行政领域 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

单位拿终局裁决要撤是正触发；劳动者不服终局去基层法院起诉，或非终局裁决去一审，都不能写成撤裁。
