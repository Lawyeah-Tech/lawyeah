# 决定劳动纪律处分方法

本文件是可执行判断节点，不是栏目说明书。每个会改变路径、请求、金额、期限或可提交状态的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不给胜诉率、必然受理、必然有效或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。劳动、社保、工伤、仲裁和执行规则一律运行时核验现行文本后再落判断。

一般商事合同、采购外包主合同、股权交易文件的审查与起草转交审查起草领域；本窗搁置，只说明不实施，不回改该领域或 C 端 109 专项。

## 节点 1　材料闸

没有调查材料就不要处分。

- if 关键事实没有已读取材料
  then 处分依据不足，停止可发送通知
- if 用户要求先处分再补调查
  then 拒绝
- if 材料明显不完整且用户拒绝补证
  then 只输出不处分或受限意见

## 节点 2　制度

无有效制度不得随意重罚。

- if 制度未经民主或未公示
  then 不得以该条款作为严重违纪解除依据
- if 适用版本不是行为发生时版本
  then 依据不足
- if 条款未覆盖该行为
  then 不得类推为严重违纪

## 节点 3　相当性

同类人员应同等处理。

- if 拟解除但事实只支持警告
  then 现有依据不支持解除级处分
- if 同类行为他人仅口头提醒
  then 一致性抗辩列入最强反方
- if 保护期或残疾状态未筛查
  then 受影响处分停止

## 节点 4　程序

陈述和送达必须真实。

- if 要求补造昨天的谈话记录
  then 整体停止
- if 工会程序依法需要但未开始
  then 解除级处分程序停止
- if 员工未获陈述机会
  then 程序缺口，不得写已完成

## 节点 5　出口

处分决定不是解除实施包。

- if 已决定过失性解除并要发送
  then 目标停止，路由解除实施
- if 实为绩效问题
  then 负触发，路由绩效改善
- if 已进入仲裁
  then 负触发，路由应诉或争议

## 证据、金额与下一步

- if 关键事实仅有单方陈述且对方控制原始材料:
  then 不得因对方控制而推定材料存在或内容有利；只列控制方、补证路径和最晚时点。
- if 金额参数不足或地方基数未核验:
  then 只列公式、已知参数、未知参数和区间接口，未知不写零，不输出唯一必得总额。
- if 期限起算日、送达日或知悉日冲突:
  then 建立并行情景并字段停止，不选对用户最有利的一天冒充唯一截止日。
- if 用户要求预测胜诉率或保证机关支持:
  then 拒绝该字段，继续交付可复核事实、条件和缺口。
- if 用户要求倒签、补造程序、伪造送达、隐匿财产或违法取证:
  then 整体停止，只输出拒绝、保全真实材料和按真实日期恢复的条件。

下一步按期限灭失、易失证据、能否改变本任务结论、不可逆性和成本排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。不代用户向机关或对方实际提交。
