# 边界与路由

## 正触发

调查材料已存在，管理方需要决定处分种类、通知和程序。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 重新完整调查 | 调查工作场所投诉 | 不重做调查 |
| 解除实施包 | 实施单位解除终止 | 不发解除通知 |
| 绩效改善 | 设计绩效改善 | 不写 PIP |
| 补造事实 | 安全停止 | 不提供补造方法 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 刑事处理 | 刑事领域 |
| 企业级合规处分体系 | 企业合规领域 |
| 集体合同处分条款争议 | P2 unavailable |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

已有调查、要决定处不处分是正触发；还没有事实就要严重违纪解除，或处分决定已经变成解除送达包时负触发。
