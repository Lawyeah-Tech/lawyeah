# 实施方法

## 前提和证据

将既定路径每个构成条件转为一行：条件、决定时已有事实、支持材料、不利材料／劳动者解释、控制方、取得合法性、制度版本、判断状态和停止结果。后来发现的事实不得倒填进原通知理由。

## 动作状态机

顺序：`草案 → 待授权／审批 → 待工会程序 → 待发送 → 已发送待证明到达 → 已送达 → 结算处理中 → 已结算有凭证 → 已归档`。任何阻断可转 `停止`；状态推进必须回链 `E#`。发送证据不是到达证据，付款指令不是到账凭证。

## 通知和版本

通知字段固定：用人单位与劳动者、唯一路径、决定日和生效表达、逐项事实及日期、合同／制度条款、规则来源、离职交接和权利提示、签发主体、真实签发日。每句理由回链证据。正文、附件、签发页和送达件组成唯一 `V#`，每项保存哈希。

## 工会与送达

工会表记录单位工会状态、适用程序、发送内容与 `V#`、真实时间、到达、意见、单位研究和书面回复。送达表记录地址来源、渠道、执行人、时间、内容哈希、签收／拒收／退回和原始凭证。不能用计划或同事口头转告推进状态。

## 结算和离职后动作

每项列项目、人员期间、参数、公式、应付、已付、差额、审批、付款和到账 `E#`。交接、证明、档案社保转移、财物账号、竞业和归档分别建行，不以一项完成代表全部完成。
