# 边界与路由

## 正触发

管理方要查明公积金缺口并规划向管理中心办理的整改。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 社会保险整改 | 规划社会保险整改 | 不混入社保 |
| 劳动者追缴申请 | 准备住房公积金追缴申请 | 不写申请书 |
| 行政复议诉讼文书 | 行政领域 | 不写复议起诉状 |
| 综合用工审计吞并本项 | 综合审计只留接口 | 不互相替代 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 行政复议诉讼代理 | 行政领域 |
| 个人住房贷款审批 | 非本领域 |
| 税务处理 | 税务领域 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

单位侧公积金整改是正触发；劳动者要中心处理，或把社保和公积金合成一张补缴表时必须拆分。
