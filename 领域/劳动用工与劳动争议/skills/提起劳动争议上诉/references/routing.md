# 边界与路由

## 正触发

已有一审裁判并在上诉期内，上诉方需要上诉材料。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 二审答辩 | 应对劳动争议二审 | 不写被上诉答辩 |
| 对仲裁裁决起诉 | 提起劳动争议一审 | 不写一审起诉 |
| 重做一审 | 一审原子 | 不重写一审全套 |
| 再审 | P2 unavailable | 不写再审申请 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 普通民事上诉非劳动 | 争议解决其他领域 |
| 再审检察监督 | P2 unavailable |
| 执行 | 执行原子 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

一审出来、要上诉是正触发；对方上诉你要答辩、或拿着仲裁裁决当一审判决时负触发。
