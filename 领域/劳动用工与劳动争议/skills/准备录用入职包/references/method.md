# 准备录用入职包方法

本文件是可执行判断节点，不是栏目说明书。每个会改变路径、请求、金额、期限或可提交状态的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不给胜诉率、必然受理、必然有效或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。劳动、社保、工伤、仲裁和执行规则一律运行时核验现行文本后再落判断。

一般商事合同、采购外包主合同、股权交易文件的审查与起草转交审查起草领域；本窗搁置，只说明不实施，不回改该领域或 C 端 109 专项。

## 节点 1　录用是否已决定

本任务以已决定录用为前提。

- if 仍在比较候选人、背调或录用条件
  then 负触发，路由招聘流程审查
- if 劳动者询问是否接受 offer
  then 负触发，不代表劳动者做接受决策
- if 主体、到岗日或岗位未定
  then 不得形成可签署终稿

## 节点 2　offer 与合同接口

offer 不是劳动合同本身。

- if 用户要求本任务输出完整劳动合同定稿
  then 负触发完整合同部分，路由起草劳动合同
- if offer 与拟签合同工资、地点或期限冲突
  then 列入冲突表，不静默改写
- if 需要一般商事服务协议
  then 转审查起草领域，本窗搁置

## 节点 3　表单与告知

表单只处理入职必要信息。

- if 收集与入职无关的敏感信息
  then 删除或停止该字段
- if 制度尚未完成民主公示
  then 签收页不得写成已经依法可执行
- if 特殊人员许可或体检未核验
  then 到岗字段停止

## 节点 4　版本与签署

草案不是已签署。

- if 纸质与电子文本不一致
  then 不得发出，先锁定唯一版本
- if 签署尚未发生
  then 动作状态保持待发送或草案
- if 要求劳动者预签空白页
  then 整体停止

## 节点 5　已用工与倒签

不得用入职包掩盖既成用工。

- if 人员已经实际用工仍要求倒签入职日
  then 整体停止
- if 用户接受如实补签
  then 区分真实签署日和既往期间，不写既往无争议
- if 已发生工资或解除争议
  then 负触发，路由争议或测算

## 证据、金额与下一步

- if 关键事实仅有单方陈述且对方控制原始材料:
  then 不得因对方控制而推定材料存在或内容有利；只列控制方、补证路径和最晚时点。
- if 金额参数不足或地方基数未核验:
  then 只列公式、已知参数、未知参数和区间接口，未知不写零，不输出唯一必得总额。
- if 期限起算日、送达日或知悉日冲突:
  then 建立并行情景并字段停止，不选对用户最有利的一天冒充唯一截止日。
- if 用户要求预测胜诉率或保证机关支持:
  then 拒绝该字段，继续交付可复核事实、条件和缺口。
- if 用户要求倒签、补造程序、伪造送达、隐匿财产或违法取证:
  then 整体停止，只输出拒绝、保全真实材料和按真实日期恢复的条件。

下一步按期限灭失、易失证据、能否改变本任务结论、不可逆性和成本排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。不代用户向机关或对方实际提交。
