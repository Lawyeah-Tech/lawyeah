# 边界与路由

## 正触发

管理方已决定录用特定人员，需要 offer、入职表单和签署留痕。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 完整劳动合同起草 | 起草劳动合同 | 不输出合同定稿 |
| 招聘流程审查 | 审查招聘流程 | 不改广告或背调 |
| 劳动者是否接受 | 劳动者决策，不代理 | 不写出接受建议 |
| 已发生履行争议 | 评估劳动争议 | 不写争议矩阵 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 一般商事合同审查起草 | 审查起草领域（本窗搁置） |
| 外国人工作许可专项 | P2 unavailable |
| 完整个保影响评估 | 数据隐私领域 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

已决定录用、需要 offer 和表单是正触发；用户主要目标是劳动合同正文或仍在审查招聘条件时负触发。offer 与劳动合同冲突必须显式列出。
