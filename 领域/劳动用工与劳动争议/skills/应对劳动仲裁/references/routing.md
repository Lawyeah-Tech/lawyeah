# 边界与路由

## 正触发

被申请方已收到申请、受理或答辩举证通知，需要答辩和必要反请求。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 主动申请仲裁 | 提起劳动仲裁 | 不写申请书 |
| 完整庭审准备 | 准备劳动仲裁庭审 | 不写庭审提纲 |
| 一审答辩 | 应对劳动争议一审 | 不写民事答辩状 |
| 单位撤裁 | 单位申请撤销终局裁决 | 不写撤裁申请 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 劳动监察应对 | P2 unavailable |
| 刑事并行 | 刑事领域 |
| C 端单位应诉消费包 | 只分流不回改 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

被申请方要交答辩是正触发；自己要立案、或开庭在即只要庭审提纲、或已经拿到裁决要去法院时负触发。
