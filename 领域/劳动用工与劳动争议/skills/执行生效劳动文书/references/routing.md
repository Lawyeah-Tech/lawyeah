# 边界与路由

## 正触发

文书已生效未履行，权利人要申请执行。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 重新处理实体 | 争议或上诉再审入口 | 不重审对错 |
| 被执行人应对 | 应对劳动执行 | 不写异议 |
| 财产保全或先予执行 | P2 unavailable | 不写保全申请 |
| 尚未生效 | 上诉或起诉原子 | 不写执行申请 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 普通民事执行非劳动 | 执行综合或争议领域 |
| 破产分配 | 破产领域 |
| 拒不执行刑事 | 刑事领域 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

手里有生效文书对方不给钱是正触发；还在上诉、或想借执行再打一遍实体、或自己是被执行人时负触发。
