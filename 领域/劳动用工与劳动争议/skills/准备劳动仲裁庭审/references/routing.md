# 边界与路由

## 正触发

已经开庭或确定开庭，需要一次庭审的争点、举证质证和提纲。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 立案申请 | 提起劳动仲裁 | 不写申请书 |
| 答辩提交 | 应对劳动仲裁 | 不写答辩书终稿 |
| 仅补证建卷 | 建立劳动争议证据案卷 | 不把建卷当庭审 |
| 裁决后起诉或撤裁 | 一审或撤裁原子 | 不写起诉或撤裁 |
| 庭外和解 | 谈判劳动争议和解 | 不写和解协议 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 鉴定机构程序 | 有资质机构 |
| 刑事诉讼并行 | 刑事领域 |
| 一审开庭准备 | 若已到法院则走一审原子而非本项 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

通知开庭、双方材料已来、要一次庭审作战包是正触发；还在写申请或答辩，或裁决出来了要去法院时负触发。
