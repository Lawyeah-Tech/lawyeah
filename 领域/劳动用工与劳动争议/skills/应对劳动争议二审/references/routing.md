# 边界与路由

## 正触发

被上诉方已收到上诉状或二审应诉材料，需要答辩。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 主动上诉 | 提起劳动争议上诉 | 不写上诉状 |
| 一审答辩 | 应对劳动争议一审 | 不写一审答辩 |
| 再审 | P2 unavailable | 不写再审 |
| 执行 | 执行生效劳动文书 | 不写执行申请 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 普通民事二审非劳动 | 争议解决其他领域 |
| 再审检察 | P2 unavailable |
| 调解 | 和解原子接口 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

对方上诉了要答辩是正触发；自己还要上诉必须另案。不要把一审答辩原样当二审答辩。
