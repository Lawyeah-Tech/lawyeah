# 边界与路由

## 正触发

已有认定或不予认定决定，需要劳动实体争点，而不是复议起诉状。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 行政复议诉讼文书 | 行政领域 | 不写复议起诉状 |
| 认定申请或调查应对 | 对应申请或调查原子 | 不写申请或答复 |
| 待遇测算或请求 | 测算或请求原子 | 不写测算终局 |
| 行政救济入口总分流 | 分流劳动行政救济 | 若只要入口不问实体则走分流 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 行政复议诉讼代理 | 行政领域 |
| 职业病诊断争议 | 有资质机构 |
| 第三人侵权 | 人身损害领域 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

已有决定、要劳动实体争点是正触发；只要一份复议申请书，或还没有决定时负触发。
