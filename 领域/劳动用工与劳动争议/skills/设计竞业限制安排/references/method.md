# 设计竞业限制安排方法

本文件是可执行判断节点，不是栏目说明书。每个会改变路径、请求、金额、期限或可提交状态的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不给胜诉率、必然受理、必然有效或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。劳动、社保、工伤、仲裁和执行规则一律运行时核验现行文本后再落判断。

一般商事合同、采购外包主合同、股权交易文件的审查与起草转交审查起草领域；本窗搁置，只说明不实施，不回改该领域或 C 端 109 专项。

## 节点 1　对象

竞业不是全员条款。

- if 拟覆盖无保密义务的普通岗位
  then 现有依据不支持
- if 对象是否高管或高技未核验
  then 对象字段停止
- if 已发现在职创业或入职竞争对手
  then 负触发设计主位，路由追究或调查

## 节点 2　范围

范围必须可执行且不过宽。

- if 行业范围覆盖全部国民经济门类
  then 过宽，依据不足或不支持
- if 期限超过法定上限或未核验
  then 期限字段停止或改到上限待核
- if 地域与实际业务无关联
  then 地域依据不足

## 节点 3　补偿

无补偿安排的竞业高风险。

- if 未约定补偿且地方标准未核验
  then 补偿字段停止，不得写成免费竞业有效
- if 把在职工资当作竞业补偿
  then 现有依据通常不支持
- if 补偿金额未知
  then 不写零，只列公式和待核标准

## 节点 4　协议

方案不是商业秘密诉讼。

- if 用户要商业秘密侵权诉状
  then 转知识产权领域
- if 一般商事 NDA 审查起草
  then 转审查起草领域，本窗搁置
- if 履行规则要求违法监控
  then 删除该监控手段

## 节点 5　停止

不得设计规避补偿的结构。

- if 要求写永不支付也能约束终身
  then 整体停止该条款
- if 需要入职包或劳动合同主文
  then 只留接口
- if 已进入违约争议
  then 负触发，路由追究或挑战

## 证据、金额与下一步

- if 关键事实仅有单方陈述且对方控制原始材料:
  then 不得因对方控制而推定材料存在或内容有利；只列控制方、补证路径和最晚时点。
- if 金额参数不足或地方基数未核验:
  then 只列公式、已知参数、未知参数和区间接口，未知不写零，不输出唯一必得总额。
- if 期限起算日、送达日或知悉日冲突:
  then 建立并行情景并字段停止，不选对用户最有利的一天冒充唯一截止日。
- if 用户要求预测胜诉率或保证机关支持:
  then 拒绝该字段，继续交付可复核事实、条件和缺口。
- if 用户要求倒签、补造程序、伪造送达、隐匿财产或违法取证:
  then 整体停止，只输出拒绝、保全真实材料和按真实日期恢复的条件。

下一步按期限灭失、易失证据、能否改变本任务结论、不可逆性和成本排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。不代用户向机关或对方实际提交。
