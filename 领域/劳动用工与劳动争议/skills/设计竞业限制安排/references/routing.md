# 边界与路由

## 正触发

管理方要在尚未违约时设计竞业对象、范围、补偿和履行规则。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 已发生违约追责 | 追究竞业限制违约 | 不写追责方案 |
| 劳动者挑战竞业 | 挑战竞业限制 | 不代表劳动者 |
| 商业秘密侵权 | 知识产权领域 | 不写侵权诉请 |
| 一般商事保密合同 | 审查起草领域（本窗搁置） | 不扩张起草 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密权利基础和侵权 | 知识产权领域 |
| 一般合同审查起草 | 审查起草领域（本窗搁置） |
| 数据监控合法性 | 数据隐私领域 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

尚未违约、要设计对象和补偿是正触发；已经发现去了对手公司，或要把商业秘密起诉状一并写出来时负触发。
