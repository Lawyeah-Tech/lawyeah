# 边界与路由

## 正触发

事故刚刚发生，单位需要在法定期限内报告、救治和固定证据。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 职工初期行动方案 | 规划职工工伤初期行动 | 不写职工方案 |
| 单位认定申请包 | 单位申请工伤认定 | 不写申请书 |
| 工伤认定结论 | 社会保险行政部门 | 不作认定 |
| 事故技术或医学结论 | 有资质机构 | 不作鉴定 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 第三人侵权赔偿 | 人身损害领域 |
| 安全生产事故调查处理 | 安全监管或行政 |
| 刑事安全责任 | 刑事领域 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

事故刚发生、单位要抢期限和证据是正触发；已经要递申请书，或职工要自己的行动清单，或要你定工伤时负触发。
