# 边界与路由

## 正触发

交易或上市委托方需要目标公司用工负债识别，而不是综合合规审计或交易统筹。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 交易结构与交割统筹 | 投资并购领域 | 不写交易文件 |
| 日常综合用工审计 | 综合用工合规审计 | 不写内部整改路线图为主成果 |
| 员工转移实施 | 实施员工转移 | 不写签署包 |
| 一般合同审查起草 | 审查起草领域（本窗搁置） | 不写股权协议 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 交易文件和交割 | 投资并购领域 |
| 证券信息披露统筹 | 证券或并购专业 |
| 税务和社保滞纳精算终局 | 税务或精算接口 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

为交易识别用工负债是正触发；把尽调写成日常整改，或要求你把股权协议一并起草时负触发。未开门的资料室不能写成干净。
