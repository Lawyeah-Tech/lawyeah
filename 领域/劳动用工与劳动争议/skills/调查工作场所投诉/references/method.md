# 调查工作场所投诉方法

本文件是可执行判断节点，不是栏目说明书。每个会改变路径、请求、金额、期限或可提交状态的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不给胜诉率、必然受理、必然有效或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。劳动、社保、工伤、仲裁和执行规则一律运行时核验现行文本后再落判断。

一般商事合同、采购外包主合同、股权交易文件的审查与起草转交审查起草领域；本窗搁置，只说明不实施，不回改该领域或 C 端 109 专项。

## 节点 1　授权与冲突

无授权或不独立则不能调查。

- if 委托范围或授权不明
  then 整体停止调查方案
- if 调查人与当事人存在利益冲突
  then 回避，停止由该人继续
- if 企业级财务舞弊主轴
  then 负触发，转企业合规领域

## 节点 2　争点

先事实后评价。

- if 用户要求先定严重违纪再找证据
  then 拒绝预定结论
- if 可能构成犯罪的线索
  then 只标刑事接口，不作罪名认定
- if 投诉人只要辅导方案
  then 负触发，P2 投诉人辅导 unavailable

## 节点 3　取证

合法取得优先于完整。

- if 拟秘密侵入个人设备或胁迫取证
  then 整体停止
- if 监控用于调查但劳动程序未评估
  then 使用风险列入，完整合法性转数据领域
- if 访谈未告知身份与记录方式
  then 该份陈述证明力受限

## 节点 4　事实认定

无法核实必须写明。

- if 只有传闻无原始来源
  then 依据不足
- if 双方陈述冲突且无旁证
  then 并列，不选对委托方有利版本
- if 要求删除不利证据
  then 拒绝，整体停止策略

## 节点 5　移交

报告不是处分决定。

- if 用户只要处分通知
  then 负触发，路由处分决定
- if 需要启动解除
  then 只留接口，不写解除实施
- if 需要刑事控告文书
  then 转刑事领域

## 证据、金额与下一步

- if 关键事实仅有单方陈述且对方控制原始材料:
  then 不得因对方控制而推定材料存在或内容有利；只列控制方、补证路径和最晚时点。
- if 金额参数不足或地方基数未核验:
  then 只列公式、已知参数、未知参数和区间接口，未知不写零，不输出唯一必得总额。
- if 期限起算日、送达日或知悉日冲突:
  then 建立并行情景并字段停止，不选对用户最有利的一天冒充唯一截止日。
- if 用户要求预测胜诉率或保证机关支持:
  then 拒绝该字段，继续交付可复核事实、条件和缺口。
- if 用户要求倒签、补造程序、伪造送达、隐匿财产或违法取证:
  then 整体停止，只输出拒绝、保全真实材料和按真实日期恢复的条件。

下一步按期限灭失、易失证据、能否改变本任务结论、不可逆性和成本排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。不代用户向机关或对方实际提交。
