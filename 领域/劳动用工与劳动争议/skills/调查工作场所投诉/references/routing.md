# 边界与路由

## 正触发

已有投诉或线索，受托方需要独立事实调查和证据清单。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 最终处分决定 | 决定劳动纪律处分 | 不写处分通知 |
| 企业级舞弊调查 | 企业合规领域 | 不写合规整改 |
| 刑事定性或控告 | 刑事领域 | 不定罪名 |
| 已形成劳动争议总体策略 | 评估劳动争议 | 不写争议矩阵 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 企业合规反舞弊 | 企业合规领域 |
| 刑事控告辩护 | 刑事领域 |
| 个人信息监控合法性 | 数据隐私领域 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

受托查清事实是正触发；用户已写好处分理由只要补证据，或要你定强奸罪、职务侵占罪时负触发。
