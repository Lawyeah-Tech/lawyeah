# 边界与路由

## 正触发

争议相关证据需要单独建卷，总体策略或立案文书不是主目标。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 争议总体策略 | 评估劳动争议 | 不写总矩阵终局 |
| 仲裁申请或答辩 | 立案或应诉原子 | 不写文书 |
| 庭审准备 | 准备劳动仲裁庭审 | 不写庭审提纲 |
| 违法取证方案 | 安全停止 | 不提供方法 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 电子证据鉴定 | 有资质机构 |
| 刑事非法证据 | 刑事领域 |
| 个保取证合法性 | 数据隐私领域 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

单独把证据账理清是正触发；其实要告谁告什么，或已经要写申请书、开庭提纲时负触发。
