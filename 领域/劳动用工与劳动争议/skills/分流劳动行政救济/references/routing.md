# 边界与路由

## 正触发

已有或即将面对行政决定，需要判断走哪扇门，而不是写复议起诉状。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 行政复议诉讼文书 | 行政领域 | 不写复议起诉状 |
| 劳动争议总体评估 | 评估劳动争议 | 不写争议矩阵 |
| 工伤实体争点展开 | 评估工伤行政救济实体问题 | 若主目标是实体则转出 |
| 监察投诉或应对 | P2 unavailable | 不写监察文书 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 行政复议诉讼代理 | 行政领域 |
| C 端行政救济消费包 | 只分流不回改 |
| 刑事处罚衔接 | 刑事领域 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

拿着一份人社或监察文书问走哪条救济是正触发；已经决定写起诉状，或其实是普通劳动仲裁实体时负触发。
