# 应对劳动执行

## 任务目标

被执行人收到执行材料后，形成执行应对和适格异议材料。

`depends-on` 为空。接受用户、律师、机关或其他合格来源的等价事实、测算、关系意见和证据清单，不要求先运行其他 Skill。

## 工作边界

正触发：被执行人已收到执行通知、裁定或查控，需要合法应对。

负触发并输出 `触发判定：负触发，未启动本任务`：隐匿转移财产；权利人申请执行；借执行重审实体。

本任务不给胜诉率，未知金额不写零，不把未发生的提交、送达、缴费或签署写成已完成。一般商事合同、采购外包主合同、股权交易文件的审查与起草转交审查起草领域；本窗搁置，只说明不实施，不回改该领域或 C 端 109 专项。

## 建立坐标

确认使用者与授权；单方立场；相对方及可能责任主体；中国大陆工作地、单位所在地和目标时点；当前协商、行政、仲裁、诉讼或执行状态；对方已知主张；关键材料及缺失。同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 已实际读取的材料表面；`A#` 当前一致／承认；`R#` 机关、鉴定或裁判状态；`L#` 运行时已核验规则；`P#` 已读取并准入的等价包；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩或行动项；`V#` 已形成并可定位的文本版本；`E#` 已实际取得的提交、送达、缴费、签署或履行证据。用户只声称存在但未读取的材料仍是 `S#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不给胜诉率、必然受理、必然有效或唯一必得总额。未知金额不写零。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。劳动合同、社会保险、工伤、竞业和仲裁程序分别核验现行文本，不得用失效合同规则替代劳动专项规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主实际注册且可调用时，使用 `search_law` 核验现行实体和程序规则，使用 `search_practiced` 补充路径与反例，特殊事实用 `search_case_by_fact`，明确地区年份案由用 `search_case_by_filter`，文书结构可用 `search_template` 只借鉴栏目。本任务不声明正式依赖，也不虚构机关提交、查询或支付能力。

实际调用状态只用 `not-registered`、`permission-denied`、`error`、`no-result`、`partial`、`conflict`、`verified-result`。工具不可用时继续事实、主体、材料和问题清单；依赖未核规则的法律结论、期限或机关路径字段停止。`no-result` 不证明没有规则或请求不存在。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　执行依据是否可对抗

未生效、已履行、主体错误或超出主文。
### 节点 2　异议类型

执行行为异议、执行异议之诉或案外人异议分列，不得乱用。
### 节点 3　已履行与抵销

必须有凭证。未知已付不写零。
### 节点 4　程序权利

听证、复议。不提供逃避执行方案。
### 节点 5　安全停止

隐匿、转移、虚假诉讼或暴力抗法整体停止。

## 停止与安全

- `整体停止`：单方立场或授权不明；利益冲突未解；基础主体、法域或对象无法建立；用户坚持伪造、隐匿、威胁、违法取证或隐匿财产。
- `字段停止`：法域、日期、文书送达、动态参数、医学鉴定或机关路径未核验。
- `目标停止`：主目标已变为相邻原子成果、一般商事审查起草、行政复议诉讼文书或 C 端大众专项。
