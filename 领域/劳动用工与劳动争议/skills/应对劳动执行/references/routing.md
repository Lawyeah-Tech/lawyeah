# 边界与路由

## 正触发

被执行人已收到执行通知、裁定或查控，需要合法应对。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 权利人申请执行 | 执行生效劳动文书 | 不写执行申请 |
| 隐匿转移财产 | 安全停止 | 不提供方法 |
| 重审实体 | 上诉或再审入口 | 不把异议当上诉 |
| 再审检察 | P2 unavailable | 不写再审 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 拒不执行刑事风险 | 刑事领域 |
| 破产中的执行中止 | 破产领域 |
| 案外人异议之诉复杂程序 | 按民诉核验，超出则标缺口 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

被执行人收到执行文书要合法异议是正触发；问怎么把钱藏起来必须拒绝。对判决不服应走上诉再审，不是执行异议。
