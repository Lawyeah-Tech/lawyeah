# 边界与路由

## 正触发

单位处于被动应对认定调查或举证通知的阶段。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 单位主动申请 | 单位申请工伤认定 | 不写申请书 |
| 行政复议诉讼文书 | 行政领域 | 不写复议起诉状 |
| 职工申请包 | 职工申请工伤认定 | 不写职工申请 |
| 工伤行政实体争点评估 | 评估工伤行政救济实体问题 | 不写实体评估终局 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 行政复议诉讼代理 | 行政领域 |
| 事故技术鉴定 | 有资质机构 |
| 刑事伪证或安全责任 | 刑事领域 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

单位被通知来举证是正触发；自己去申请、或已经要告人社局时负触发。笼统否认不等于有依据。
