# 边界与路由

## 正触发

管理方要在限定主体、人员和期间内查明社保缺口并规划整改。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 住房公积金整改 | 规划住房公积金整改 | 不混入公积金 |
| 劳动者征缴申请 | 准备社保补缴征缴申请 | 不写申请书 |
| 已无法补办的待遇损失 | 评估社保待遇损失 | 不替换为损失请求 |
| 行政复议诉讼文书 | 行政领域 | 不写复议起诉状 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 行政复议诉讼代理 | 行政领域 |
| 税前扣除或税务稽查 | 税务领域 |
| 破产清算中的社保债权 | 破产领域 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

单位侧查缺口和整改顺序是正触发；劳动者要告单位赔偿，或主目标是公积金，或已经要写复议书时负触发。
