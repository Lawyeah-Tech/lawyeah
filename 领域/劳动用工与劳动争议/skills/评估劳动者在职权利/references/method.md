# 评估劳动者在职权利方法

本文件是可执行判断节点，不是栏目说明书。每个会改变路径、请求、金额、期限或可提交状态的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不给胜诉率、必然受理、必然有效或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。劳动、社保、工伤、仲裁和执行规则一律运行时核验现行文本后再落判断。

一般商事合同、采购外包主合同、股权交易文件的审查与起草转交审查起草领域；本窗搁置，只说明不实施，不回改该领域或 C 端 109 专项。

## 节点 1　阶段

在职未成争是本任务的门。

- if 已经申请仲裁或起诉
  then 负触发，路由争议评估或程序原子
- if 劳动者主要目标是辞职或被迫解除
  then 负触发，路由劳动者退出
- if 只要审合同红线
  then 负触发，路由合同审查

## 节点 2　影响

措施必须具体。

- if 只有情绪不满无具体措施
  then 影响依据不足，给观察清单
- if 降薪或调岗已书面化
  then 条件变更影响进入核验
- if 可能性骚扰或报复
  then 安全优先，调查接口标出但不代替企业调查

## 节点 3　沟通

沟通不等于认可违法措施。

- if 拟书面确认降低劳动报酬
  then 必须提示可能被当作合意
- if 要求教唆同事作伪证
  then 整体停止
- if 集体停工策划
  then 本任务不组织集体行动，P2 unavailable

## 节点 4　留证

合法保存优先。

- if 拟盗用公司账号或偷拍隐私
  then 停止该手段
- if 工资和考勤在单位系统
  then 列合法导出或申请开具路径
- if 只要精算加班费
  then 负触发测算部分，路由工时测算

## 节点 5　升级

不把本任务写成仲裁请求。

- if 用户已决定仲裁
  then 目标停止，路由争议评估或立案
- if 用户已决定走退出
  then 路由劳动者退出
- if 纯金额测算
  then 路由测算

## 证据、金额与下一步

- if 关键事实仅有单方陈述且对方控制原始材料:
  then 不得因对方控制而推定材料存在或内容有利；只列控制方、补证路径和最晚时点。
- if 金额参数不足或地方基数未核验:
  then 只列公式、已知参数、未知参数和区间接口，未知不写零，不输出唯一必得总额。
- if 期限起算日、送达日或知悉日冲突:
  then 建立并行情景并字段停止，不选对用户最有利的一天冒充唯一截止日。
- if 用户要求预测胜诉率或保证机关支持:
  then 拒绝该字段，继续交付可复核事实、条件和缺口。
- if 用户要求倒签、补造程序、伪造送达、隐匿财产或违法取证:
  then 整体停止，只输出拒绝、保全真实材料和按真实日期恢复的条件。

下一步按期限灭失、易失证据、能否改变本任务结论、不可逆性和成本排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。不代用户向机关或对方实际提交。
