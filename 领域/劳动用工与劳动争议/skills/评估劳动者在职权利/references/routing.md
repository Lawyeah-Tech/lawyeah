# 边界与路由

## 正触发

劳动者在职，争议未形成，需要诊断管理措施并决定沟通、留证或观察。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 纯合同审阅 | 审查劳动合同 | 不写红线稿 |
| 纯金额测算 | 测算工资工时休假权益 | 不写精算表 |
| 退出选择 | 评估劳动者退出应对 | 不写退出方案 |
| 已形成争议 | 评估劳动争议 | 不写争议矩阵 |
| 投诉调查 | 调查或 P2 投诉人辅导 | 不写调查报告 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 个保与监控合法性 | 数据隐私领域 |
| 刑事控告 | 刑事领域 |
| C 端在职消费包 | 只分流不回改 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

还在职、还没撕破脸、要知道这件事伤不伤权利和怎么留证是正触发；已经要告、已经要走、或只要算加班费时负触发。
