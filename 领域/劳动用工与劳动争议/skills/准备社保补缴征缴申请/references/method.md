# 准备社保补缴征缴申请方法

本文件是可执行判断节点，不是栏目说明书。每个会改变路径、请求、金额、期限或可提交状态的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不给胜诉率、必然受理、必然有效或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。劳动、社保、工伤、仲裁和执行规则一律运行时核验现行文本后再落判断。

一般商事合同、采购外包主合同、股权交易文件的审查与起草转交审查起草领域；本窗搁置，只说明不实施，不回改该领域或 C 端 109 专项。

## 节点 1　入口

征缴申请不是仲裁申请。

- if 用户要求把纯补缴写成劳动仲裁请求
  then 负触发该包装，说明行政入口
- if 主目标是单位整改
  then 负触发，路由单位社保整改
- if 已无法补办且只要损失赔偿
  then 负触发，路由待遇损失评估

## 节点 2　主体

缴费主体与签约主体可能不同。

- if 实际用工与参保主体不一致
  then 并列责任主体候选，不擅自唯一化
- if 申请人身份或授权不明
  then 停止可提交状态
- if 单位已进入破产
  then 标破产债权接口，不在本任务申报

## 节点 3　事实

未提供的期间不得补写。

- if 工作期间或工资未知
  then 对应请求期间停止或受限
- if 仅有口头陈述无任何旁证
  then 可形成受限申请，不得写成事实已确认
- if 地方征缴受理范围未核验
  then 机关路径字段停止

## 节点 4　文书

申请包不是复议书。

- if 经办机构已作出拒绝决定且用户要复议
  then 负触发文书部分，转行政领域
- if 材料份数和窗口要求未核验
  then 提交格式字段停止
- if 用户要求本任务实际提交
  then 拒绝代提交

## 节点 5　停止

真实材料优先。

- if 要求伪造工资或入职
  then 整体停止
- if 同时要求住房公积金追缴
  then 公积金另案，不混入社保申请
- if 已有生效处理结果重复申请
  then 程序风险字段停止

## 证据、金额与下一步

- if 关键事实仅有单方陈述且对方控制原始材料:
  then 不得因对方控制而推定材料存在或内容有利；只列控制方、补证路径和最晚时点。
- if 金额参数不足或地方基数未核验:
  then 只列公式、已知参数、未知参数和区间接口，未知不写零，不输出唯一必得总额。
- if 期限起算日、送达日或知悉日冲突:
  then 建立并行情景并字段停止，不选对用户最有利的一天冒充唯一截止日。
- if 用户要求预测胜诉率或保证机关支持:
  then 拒绝该字段，继续交付可复核事实、条件和缺口。
- if 用户要求倒签、补造程序、伪造送达、隐匿财产或违法取证:
  then 整体停止，只输出拒绝、保全真实材料和按真实日期恢复的条件。

下一步按期限灭失、易失证据、能否改变本任务结论、不可逆性和成本排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。不代用户向机关或对方实际提交。
