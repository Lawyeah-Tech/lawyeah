# 边界与路由

## 正触发

劳动者要向社保主管或经办机关请求追缴，而不是把纯补缴写成仲裁请求。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 把纯补缴写成劳动仲裁 | 提起劳动仲裁 不适用纯补缴 | 不写仲裁申请 |
| 单位整改方案 | 规划社会保险整改 | 不写单位路线图 |
| 待遇损失赔偿 | 评估社保待遇损失 | 不替换为损失 |
| 行政复议诉讼文书 | 行政领域 | 不写复议起诉状 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 行政复议诉讼代理 | 行政领域 |
| 住房公积金追缴 | 准备住房公积金追缴申请 |
| 破产债权申报 | 破产领域 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

劳动者向机关追缴社保是正触发；把同一事实改成仲裁请求或单位整改方案时负触发。能补办时不要改写成损失之诉。
