# 边界与路由

## 正触发

单位侧已发现疑似竞争行为，需要决定启动、解除或追责。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 商业秘密侵权诉讼 | 知识产权领域 | 不写侵权诉请 |
| 劳动者挑战竞业 | 挑战竞业限制 | 不代表劳动者 |
| 设计尚未签署的竞业 | 设计竞业限制安排 | 不写设计方案 |
| 仲裁立案文书 | 提起劳动仲裁 | 不写申请书 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密侵权和保密措施 | 知识产权领域 |
| 不正当竞争 | 竞争法领域 |
| 刑事侵犯商业秘密 | 刑事领域 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

单位要追究已出现的竞争行为是正触发；还在设计条款，或主诉求是商业秘密赔偿时拆分。未付补偿时不得写成违约金已稳获。
