# 边界与路由

## 正触发

单位未申请或职工选择自行申请，申请主体是职工、近亲属或工会。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 单位申请工伤认定 | 单位申请工伤认定 | 不写单位申请 |
| 职工初期行动 | 规划职工工伤初期行动 | 不写初期方案 |
| 第三人侵权赔偿 | 人身损害领域 | 不写侵权诉请 |
| 工伤待遇请求 | 准备工伤待遇请求 | 不写待遇请求 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 第三人侵权 | 人身损害领域 |
| 职业病诊断 | 有资质机构 |
| 行政复议诉讼 | 行政领域 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

职工自己去认定是正触发；单位去申请、或还在住院只要初期行动、或主诉是交通肇事赔偿时负触发。
