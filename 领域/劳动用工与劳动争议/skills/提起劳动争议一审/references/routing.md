# 边界与路由

## 正触发

已有仲裁处理结果或依法可诉，原告需要起诉材料。劳动者不服终局裁决走本项，单位撤裁不走本项。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 单位撤销终局裁决 | 单位申请撤销终局裁决 | 不按普通起诉 |
| 仲裁申请或答辩 | 仲裁原子 | 不写仲裁文书 |
| 一审应诉 | 应对劳动争议一审 | 不写答辩 |
| 上诉 | 提起劳动争议上诉 | 不写上诉状 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 普通民事一审非劳动 | 争议解决其他领域 |
| 行政起诉人社局 | 行政领域 |
| C 端诉讼消费包 | 只分流不回改 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

仲裁后原告去法院是正触发；单位拿着终局裁决要撤裁必须另走；还没仲裁就直接起诉通常负触发。
