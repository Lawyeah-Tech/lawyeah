# 边界与路由

## 正触发

劳动者要挑战范围、解除限制或追索竞业补偿。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 商业秘密侵权抗辩 | 知识产权领域 | 不写侵权抗辩 |
| 单位追究竞业 | 追究竞业限制违约 | 不代表单位 |
| 设计竞业安排 | 设计竞业限制安排 | 不写单位方案 |
| 仲裁立案文书 | 提起劳动仲裁 | 不写申请书 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密侵权诉讼 | 知识产权领域 |
| 不正当竞争应诉 | 竞争法领域 |
| C 端竞业消费包 | 只分流不回改 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

劳动者要松绑或追补偿是正触发；实际是商业秘密被告、或要一份“保证去某公司没事”时负触发或拒绝保证。
