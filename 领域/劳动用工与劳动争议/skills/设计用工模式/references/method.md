# 设计用工模式方法

本文件是可执行判断节点，不是栏目说明书。每个会改变路径、请求、金额、期限或可提交状态的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不给胜诉率、必然受理、必然有效或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。劳动、社保、工伤、仲裁和执行规则一律运行时核验现行文本后再落判断。

一般商事合同、采购外包主合同、股权交易文件的审查与起草转交审查起草领域；本窗搁置，只说明不实施，不回改该领域或 C 端 109 专项。

## 节点 1　前瞻还是既有事实

本任务只设计尚未实施的模式。

- if 用工已经发生且需要定性
  then 负触发，路由关系识别，不把本任务改写成关系结论
- if 用户只要一份商业外包主合同正文
  then 负触发，转审查起草领域，本窗搁置
- if 立场或授权不明
  then 整体停止策略输出

## 节点 2　控制与独立性

实际控制决定风险，不决定于合同名称。

- if 单位将直接安排工时、考勤、奖惩和报酬
  then 直营或派遣主位，外包仅作高风险备位
- if 承揽方有独立生产组织、自有人员和经营风险
  then 外包可列为可行，仍需安全与工伤接口
- if 平台仅提供信息撮合且无劳动管理迹象
  then 依据不足时并列合作与用工两套假设，不选定唯一

## 节点 3　派遣与法定限制

派遣不是普通外包的替代标签。

- if 拟用派遣但岗位不属于临时、辅助或替代性且未核验
  then 派遣字段停止，不写成已经合法
- if 派遣比例或许可未核验
  then 比例和许可字段停止
- if 将同一批人员在外包与派遣之间来回改名
  then 记录规避风险，不提供改名方案

## 节点 4　责任与文件

模式方案不是商事合同定稿。

- if 需要一般采购或外包主合同条款
  then 只列劳动法责任接口，正文转审查起草领域
- if 工伤或安全责任拟全部转嫁且无独立承揽事实
  then 现有依据不支持转嫁结论
- if 商业秘密或竞业需要独立安排
  then 只留接口，不代做竞业或保密专项

## 节点 5　落地与停止

落地不得倒签已经发生的用工。

- if 拟对已经在岗人员补签外包协议掩盖管理
  then 整体停止，不提供规避措辞
- if 转换将导致批量减员
  then 停止按模式设计处理，路由裁员安置
- if 外国人或未成年工未分流
  then 相关模式字段停止，P2 专项标 unavailable

## 证据、金额与下一步

- if 关键事实仅有单方陈述且对方控制原始材料:
  then 不得因对方控制而推定材料存在或内容有利；只列控制方、补证路径和最晚时点。
- if 金额参数不足或地方基数未核验:
  then 只列公式、已知参数、未知参数和区间接口，未知不写零，不输出唯一必得总额。
- if 期限起算日、送达日或知悉日冲突:
  then 建立并行情景并字段停止，不选对用户最有利的一天冒充唯一截止日。
- if 用户要求预测胜诉率或保证机关支持:
  then 拒绝该字段，继续交付可复核事实、条件和缺口。
- if 用户要求倒签、补造程序、伪造送达、隐匿财产或违法取证:
  then 整体停止，只输出拒绝、保全真实材料和按真实日期恢复的条件。

下一步按期限灭失、易失证据、能否改变本任务结论、不可逆性和成本排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。不代用户向机关或对方实际提交。
