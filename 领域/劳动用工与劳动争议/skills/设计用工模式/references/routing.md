# 边界与路由

## 正触发

管理方尚未落地，需要比较多种用工模式并配置责任。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 判断既有事实关系 | 识别劳动关系与责任主体 | 不做关系终局 |
| 起草一般商业外包合同 | 审查起草领域（本窗搁置） | 不输出商事合同定稿 |
| 已发生履行或解除争议 | 评估劳动争议 | 不写争议矩阵 |
| 综合历史合规审计 | 综合用工合规审计 | 不写历史差距表 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 商业秘密侵权或权利基础 | 知识产权领域 |
| 交易结构或交割 | 投资并购领域 |
| 境外当地劳动法 | 涉外领域 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

尚未落地的模式比较是正触发；已经在岗只是要一份外包合同或要关系结论时负触发。派遣与外包必须分列，不得写成一种“灵活用工”。
