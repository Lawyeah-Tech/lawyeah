# 边界与路由

## 正触发

管理方面对合同期满，需要决定续订、不续订或无固定期限。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 在职调岗调薪或地点变更 | 实施劳动条件变更 | 不做变更实施 |
| 非期满单方解除 | 退出评估或实施原子 | 不写解除通知 |
| 批量减员 | 规划裁员安置 | 不按个体不续订复制 |
| 已形成争议 | 评估劳动争议 | 不写争议矩阵 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 事业单位人事关系 | P2 unavailable |
| 破产安置 | 破产领域 |
| 交易导致主体变更 | 员工转移原子 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

到期决定续或不续是正触发；把期满当过失解除，或借续订做调岗降薪，应拆分而不是混在一个期满结论里。
