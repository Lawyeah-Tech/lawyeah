# 评估劳动合同续订方法

本文件是可执行判断节点，不是栏目说明书。每个会改变路径、请求、金额、期限或可提交状态的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不给胜诉率、必然受理、必然有效或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。劳动、社保、工伤、仲裁和执行规则一律运行时核验现行文本后再落判断。

一般商事合同、采购外包主合同、股权交易文件的审查与起草转交审查起草领域；本窗搁置，只说明不实施，不回改该领域或 C 端 109 专项。

## 节点 1　是否期满决策

本任务以合同期限届满为轴。

- if 合同仍在履行中且目标是调岗调薪
  then 负触发，路由劳动条件变更
- if 单位要以过失或不能胜任立即解除
  then 负触发，路由退出评估或实施
- if 到期日冲突
  then 并行情景，不给唯一截止日

## 节点 2　次数与十年

二次固定期限和十年是不同闸。

- if 已连续订立二次固定期限且劳动者提出续订
  then 无固定期限义务字段进入核验，不得径行改签固定期限
- if 工龄是否满十年未核验
  then 十年闸字段停止
- if 中断是否足够切断连续订立有争议
  then 依据不足，并列两套情景

## 节点 3　不续订

不续订不是过失性解除。

- if 单位拒绝续订但符合应订无固定期限情形
  then 现有依据不支持按普通终止处理
- if 需要支付终止补偿但工资基数未知
  then 只列公式和参数缺口，不写零
- if 不续订实为批量减员
  then 负触发，路由裁员安置

## 节点 4　续订文本

续订可沿用或调整，调整有边界。

- if 续订同时大幅降薪或改地
  then 超出期满决策，条件变更部分转专项
- if 用户要求从零审查一般商事合同
  then 转审查起草领域，本窗搁置
- if 需要完整新合同起草
  then 文本接口给起草原子，本任务保留决策

## 节点 5　通知与停止

通知期和地方规则必须核验。

- if 地方提前通知期未核验
  then 通知字段停止
- if 用户要求倒签到期日或隐瞒第二次固定期限
  then 整体停止
- if 通知已经发出且目标变为撤回或争议
  then 目标停止，路由争议或实施补救

## 证据、金额与下一步

- if 关键事实仅有单方陈述且对方控制原始材料:
  then 不得因对方控制而推定材料存在或内容有利；只列控制方、补证路径和最晚时点。
- if 金额参数不足或地方基数未核验:
  then 只列公式、已知参数、未知参数和区间接口，未知不写零，不输出唯一必得总额。
- if 期限起算日、送达日或知悉日冲突:
  then 建立并行情景并字段停止，不选对用户最有利的一天冒充唯一截止日。
- if 用户要求预测胜诉率或保证机关支持:
  then 拒绝该字段，继续交付可复核事实、条件和缺口。
- if 用户要求倒签、补造程序、伪造送达、隐匿财产或违法取证:
  then 整体停止，只输出拒绝、保全真实材料和按真实日期恢复的条件。

下一步按期限灭失、易失证据、能否改变本任务结论、不可逆性和成本排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。不代用户向机关或对方实际提交。
