# 边界与路由

## 正触发

已有合同或模板，单方需要风险清单和修改稿或红线稿，履行争议尚未作为主目标。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 已发生履行争议 | 评估劳动争议 | 不写争议矩阵 |
| 从零起草劳动合同 | 起草劳动合同 | 不输出新签定稿 |
| 一般商事合同审查 | 审查起草领域（本窗搁置） | 不扩张审查范围 |
| 续订或不续订决策 | 评估劳动合同续订 | 不做续订决定 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 一般合同审查起草 | 审查起草领域（本窗搁置） |
| 商业秘密侵权 | 知识产权领域 |
| 股权激励文件 | 公司治理或P2 unavailable |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

对已有劳动文本做红线是正触发；用户主要目标是打官司或从零起草时负触发。劳动强制规则审查不是一般合同审查。
