# 审查劳动合同方法

本文件是可执行判断节点，不是栏目说明书。每个会改变路径、请求、金额、期限或可提交状态的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不给胜诉率、必然受理、必然有效或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。劳动、社保、工伤、仲裁和执行规则一律运行时核验现行文本后再落判断。

一般商事合同、采购外包主合同、股权交易文件的审查与起草转交审查起草领域；本窗搁置，只说明不实施，不回改该领域或 C 端 109 专项。

## 节点 1　对象与立场

只审查劳动合同或劳动模板。

- if 文本是采购、外包或股权交易合同
  then 负触发，转审查起草领域，本窗搁置
- if 主目标是已发生工资、解除或社保争议
  then 负触发，路由争议评估
- if 立场不明或利益冲突
  then 整体停止

## 节点 2　强制规则

劳动强制规则优先于约定。

- if 试用期超过法定期限或重复约定
  then 现有依据不支持该条款按约定执行
- if 排除社会保险或低于最低工资
  then 现有依据不支持，列入必须改写
- if 规则未核验
  then 对应字段停止，不写成有效或无效

## 节点 3　可约定条款

可约定不等于任意约定。

- if 约定提前三十日不得辞职或高额辞职罚金
  then 现有依据通常不支持限制法定辞职权，列入红线
- if 加班费包干但工时制度未核验
  then 依据不足，不得写成已经合法
- if 竞业或服务期条款事实不足
  then 主合同只标接口，不代做专项方案

## 节点 4　红线稿

修改稿必须回链风险。

- if 用户要求保留明显违反强制标准的条款并保证有效
  then 拒绝保证，字段保持不支持
- if 需要从零起草而非改已有文本
  then 负触发，路由起草劳动合同
- if 模板适用于多地但地方规则未核
  then 地方字段停止

## 节点 5　转介

审查不等于争议或续订。

- if 合同即将到期需要续订决策
  then 负触发，路由续订评估
- if 已在仲裁或诉讼中攻击该条款
  then 负触发，路由争议或证据任务
- if 一般商事条款夹杂其中
  then 商事段转审查起草领域，劳动段继续

## 证据、金额与下一步

- if 关键事实仅有单方陈述且对方控制原始材料:
  then 不得因对方控制而推定材料存在或内容有利；只列控制方、补证路径和最晚时点。
- if 金额参数不足或地方基数未核验:
  then 只列公式、已知参数、未知参数和区间接口，未知不写零，不输出唯一必得总额。
- if 期限起算日、送达日或知悉日冲突:
  then 建立并行情景并字段停止，不选对用户最有利的一天冒充唯一截止日。
- if 用户要求预测胜诉率或保证机关支持:
  then 拒绝该字段，继续交付可复核事实、条件和缺口。
- if 用户要求倒签、补造程序、伪造送达、隐匿财产或违法取证:
  then 整体停止，只输出拒绝、保全真实材料和按真实日期恢复的条件。

下一步按期限灭失、易失证据、能否改变本任务结论、不可逆性和成本排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。不代用户向机关或对方实际提交。
