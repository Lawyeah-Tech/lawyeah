# 边界与路由

## 正触发

任一方需要测算离职相关款项，路径合法性不是本任务主目标。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 判断退出路径是否合法 | 单位或劳动者退出评估 | 不选路径 |
| 工伤待遇测算 | 测算工伤待遇 | 不并入工伤项目 |
| 在职工资工时精算 | 测算工资工时休假权益 | 不吞并在职精算 |
| 实施解除通知 | 实施单位解除终止 | 不发通知 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 第三人侵权赔偿 | 人身损害领域 |
| 股权激励兑现 | 公司治理或税务领域 |
| 破产职工债权 | 破产领域 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

路径已作为假设、只要把账算清是正触发；用户还在问能不能解除，或要把工伤和离职补偿合成一笔时负触发或拆分。
