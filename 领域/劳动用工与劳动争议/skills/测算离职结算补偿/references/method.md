# 测算离职结算补偿方法

本文件是可执行判断节点，不是栏目说明书。每个会改变路径、请求、金额、期限或可提交状态的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不给胜诉率、必然受理、必然有效或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。劳动、社保、工伤、仲裁和执行规则一律运行时核验现行文本后再落判断。

一般商事合同、采购外包主合同、股权交易文件的审查与起草转交审查起草领域；本窗搁置，只说明不实施，不回改该领域或 C 端 109 专项。

## 节点 1　测算而非定性

本任务不决定解除是否合法。

- if 用户主要目标是选择解除路径
  then 负触发，路由单位或劳动者退出评估
- if 用户主要目标是工伤待遇
  then 负触发，路由工伤待遇测算
- if 路径假设未声明
  then 并列多种互斥情景，不选一笔总额

## 节点 2　N 与 2N

经济补偿与赔偿金互斥。

- if 同时把 N 和 2N 加总
  then 禁止，分列互斥情景
- if 代通知金与提前通知事实冲突
  then 依据不足，不计入确定应付
- if 地方月工资上限未核验
  then 上限字段停止，不编造数字

## 节点 3　基数与工龄

参数不足不得写零。

- if 平均工资构成未知
  then 只列口径和缺口，不把未知写成零
- if 入职日或连续工龄冲突
  then 并行情景
- if 不满六个月或分段封顶规则未核验
  then 对应段字段停止

## 节点 4　其他款项

分项不得合成一笔离职权益。

- if 未休年假或奖金缺少期间参数
  then 该项无法估计，不写零
- if 已付款无凭证
  then 列入待匹配，不擅自抵扣
- if 竞业补偿或工伤待遇混入
  then 转出对应专项，本表删除该加总

## 节点 5　输出纪律

可复核优于好看的整数。

- if 用户要求唯一法定金额
  then 拒绝，只给情景区间
- if 用户要求按胜诉率打折
  then 拒绝胜诉率字段
- if 用户要求伪造工资条做基数
  then 整体停止

## 证据、金额与下一步

- if 关键事实仅有单方陈述且对方控制原始材料:
  then 不得因对方控制而推定材料存在或内容有利；只列控制方、补证路径和最晚时点。
- if 金额参数不足或地方基数未核验:
  then 只列公式、已知参数、未知参数和区间接口，未知不写零，不输出唯一必得总额。
- if 期限起算日、送达日或知悉日冲突:
  then 建立并行情景并字段停止，不选对用户最有利的一天冒充唯一截止日。
- if 用户要求预测胜诉率或保证机关支持:
  then 拒绝该字段，继续交付可复核事实、条件和缺口。
- if 用户要求倒签、补造程序、伪造送达、隐匿财产或违法取证:
  then 整体停止，只输出拒绝、保全真实材料和按真实日期恢复的条件。

下一步按期限灭失、易失证据、能否改变本任务结论、不可逆性和成本排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。不代用户向机关或对方实际提交。
