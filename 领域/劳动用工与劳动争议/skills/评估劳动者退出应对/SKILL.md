# 评估劳动者退出应对

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是运行本技能的强制依赖。

## 任务目标

为劳动者侧形成“退出行动、通知、证据、权益、谈判与停止条件方案”，在不可逆行动前比较继续履行、普通辞职、条件化解除、协商离开、回应单位通知和暂缓行动；已发生行动则如实转为后果管理。

`depends-on` 为空。接受用户、律师、单位或机关形成的等价材料，不要求先运行其他 Skill。

## 工作边界

正触发限于劳动者单方立场且主要目标仍是退出行动选择或回应。单位设计退出、只要精确金额、只起草仲裁申请、只审查协议红线或已确认程序请求均负触发。固定输出 `触发判定：负触发，未启动本任务`，只说明路由和最小输入，不代做相邻成果，不填写成果状态。

本任务不替用户实际发送通知、签署协议、停工离岗、提交机关材料或决定放弃和解底线。

## 建立当前状态

确认劳动者、实际用人单位、地区、合同和履行；当前目标与不可接受风险；单位行为、工资社保、工作安排和通知；已准备、已发送、已到达、已签署、已履行、停工、退出群聊、交接、收款、账号门禁变化及时间；现有合法证据和即将发生期限；安全、医疗、工伤或报复风险。

事件表固定列时间、行为人、文件／行为、内容与理由、接收主体、渠道、到达证据、签署／履行、争议和可逆性。发送不自动等于到达，未回复不自动等于拒绝或同意。

## 来源和行动状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或裁判状态；`L#` 运行时已核验规则；`P#` 实际读取并准入的等价来源包；`I#` 判断；`G#` 缺口；`V#` 行动方案／通知草案版本；`E#` 真实到达、签署、交接或付款证据。

可逆性字段只允许逐字使用 `尚未行动`、`已准备未发送/未签署`、`已通知/已到达`、`已签署未履行`、`已履行或关系终止`，不得使用 `可逆`、`待核`、`已履行`、`核验后决定` 或其他近义词；未知时按真实已发生动作选取上述五态，并把疑点写入争议或缺口字段。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。建议级别只用 `可立即执行的低风险保全`、`核验后决定`、`需专业人员审阅后行动`、`禁止/停止`。

## 使用 Lawyeah MCP

宿主实际注册且可调用时，使用 `search_law` 核验路径、通知和期限，使用 `search_practiced` 补充劳动者行动实务，特殊事实用 `search_case_by_fact`，明确筛选条件用 `search_case_by_filter`。本候选不声明正式依赖，不虚构企业取数、发送或提交工具。

实际调用状态只用 `not-registered`、`permission-denied`、`error`、`no-result`、`partial`、`conflict`、`verified-result`，记录工具、时间、最小查询、请求标识、来源审查、覆盖和恢复条件。无结果不证明理由成立或不成立。不可用时继续真实状态、低风险保全和条件矩阵；依赖未核规则的不可逆行动字段停止。来源包只有实际读取并完成准入核验才使用。

## 五个判断节点

### 1. 当前状态和可逆性

先锁定是否仍在职、是否正常提供劳动、单位是否安排工作、双方通知、协议、交接、款项和账号变化。已经停工、退出群聊或通知到达时不得按“尚未行动”设计；先给澄清、留痕、减少旷工或默示接受风险的合法低风险动作。

### 2. 路径条件

并列继续履行、普通辞职、条件化劳动者解除、协商解除、回应单位解除／终止和暂缓。每条列事实条件、规则、主要证据、不利解释、可逆性、权益影响、替代路径和停止点。详见 [行动方法](references/method.md)。

一般不满、关系恶化或领导态度不能自动写成条件化解除理由；普通辞职不是等待单位批准；已到达通知不得保证可单方撤回。

### 3. 权益影响

路径合法性与金额分开。逐项列工资、加班、休假、补偿赔偿候选、社保、奖金提成股权、竞业及补偿、培训服务期、保密、离职证明、档案社保转移和交接，记录成立条件、材料、已付／处分、待测算及程序。协商草案不是已合意，结清条款需核权利范围和意思表示。

### 4. 合法证据与沟通

只保存劳动者有权接触的本人文件、工资社保、工作安排、本人沟通、单位交付和公共记录；保留原始导出、元数据、时间和来源。不侵入系统、不绕过权限、不复制商业秘密或无关个人信息、不删记录、不诱导证言。

沟通计划列目的、发送人、接收主体及权限、核心事实、明确请求／立场、不承认事项、渠道、到达证据、最晚时点、备选渠道和停止条件。模板必须由已核事实驱动，不替用户决定和解底线。

### 5. 时序、安全和停止

优先级：人身安全／急迫医疗 → 固定已发生状态与到达 → 保存合法证据 → 核验法域规则和期限 → 比较可逆路径 → 决定不可逆通知／签署 → 交接和权益跟踪。威胁、暴力、危险作业或严重报复时，不要求为证据回到危险环境，给出合格保护和专业渠道。

具体期限必须绑定请求类型、事实日、关系终止、到达及中止／中断证据；一般沟通不自动产生时效效果。

## 停止与安全

- `整体停止`：劳动者立场、对象、法域或基础状态无法建立；用户坚持侵入系统、绕过权限、删除记录、窃取秘密、诱导证言、伪造理由或以材料要挟。
- `行动停止`：解除理由、通知对象、到达、规则、保护、已签协议或后果未核，停止不可逆通知／签署，低风险保全继续。
- `安全优先`：人身危险、医疗、工伤或急迫报复风险先路由合格渠道。

首次非法取证、删除记录、诱导证言或要挟要求立即拒绝、整体停止退出路径设计并给合法替代入口；在用户明确接受合法边界前，不得仅暂停不可逆部分后继续比较路径。用户明确接受后恢复，使用有权材料和正式渠道；坚持时维持整体停止，不提供绕过日志或反取证方法。

## 交付

严格按 [输出合同](references/output-contract.md) 固定十节交付。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`；负触发不填写。

提交前检查：立场单一；已行动如实；普通辞职、条件化解除和协商分开；每条建议有前提、证据、可逆性和替代；到达证据明确；不伪精确金额；不侵权取证；安全医疗和期限优先；不保证补偿、单位接受或争议结果。路由见 [边界](references/routing.md)。
