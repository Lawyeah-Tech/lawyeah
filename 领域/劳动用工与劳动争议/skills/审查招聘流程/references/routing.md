# 边界与路由

## 正触发

管理方需要审查招聘流程或录用条件、背景调查、offer 撤回。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 完整个人信息影响评估 | 数据隐私领域 | 不写 DPIA |
| 生成全套入职文件 | 准备录用入职包 | 不输出入职包 |
| 起草劳动合同 | 起草劳动合同 | 不起草合同 |
| 已发生录用争议总体评估 | 评估劳动争议 | 不写争议矩阵 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 个人信息合法性、跨境和安全 | 数据隐私领域 |
| 一般商事服务合同审查起草 | 审查起草领域（本窗搁置） |
| 刑事背景的控告或辩护 | 刑事领域 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

审查广告、背调和撤回条件是正触发；用户已决定录用只要签署包，或只要数据影响评估时负触发。撤回 offer 不自动等于解除劳动合同。
