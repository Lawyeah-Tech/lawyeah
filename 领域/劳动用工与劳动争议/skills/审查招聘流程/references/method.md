# 审查招聘流程方法

本文件是可执行判断节点，不是栏目说明书。每个会改变路径、请求、金额、期限或可提交状态的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不给胜诉率、必然受理、必然有效或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。劳动、社保、工伤、仲裁和执行规则一律运行时核验现行文本后再落判断。

一般商事合同、采购外包主合同、股权交易文件的审查与起草转交审查起草领域；本窗搁置，只说明不实施，不回改该领域或 C 端 109 专项。

## 节点 1　广告与筛选

招聘条件必须与岗位相关且不构成法定歧视。

- if 限定性别、婚育、民族或残疾且无职业禁忌依据
  then 现有依据不支持该条件，列入必须删除或改写
- if 传染病排除未区分职业禁忌与法律禁止歧视
  then 字段停止，不得写成可以一律排除
- if 主要目标是完整个保影响评估
  then 负触发，转数据领域

## 节点 2　背景调查

调查必须有授权、范围和必要。

- if 拟查询与岗位无关的通讯、行踪或生物识别
  then 现有依据不支持扩大调查
- if 第三方背调合同需要商事审查起草
  then 劳动法意见可写范围，合同正文转审查起草领域本窗搁置
- if 授权文本不可读或未取得
  then 调查启动字段停止

## 节点 3　录用条件

录用条件必须事先明确并可核验。

- if 录用条件仅在拒绝时事后补充
  then 不得将该条件写成已合法设立
- if 条件与岗位无关联
  then 依据不足或不支持
- if 用户只要全套入职包
  then 负触发，路由准备录用入职包

## 节点 4　撤回录用

撤回不等于已经解除劳动关系。

- if 尚未用工且书面录用未形成信赖
  then 可评估撤回风险，不写成已建立劳动关系
- if 对方已辞职或已到岗
  then 可能进入关系识别或退出评估，本任务只标接口
- if 撤回理由与已公布条件矛盾
  then 记录不利事实，不得补造新的录用条件

## 节点 5　修改与停止

修改清单必须可执行。

- if 用户坚持以婚检或孕检作为录用门槛
  then 整体停止，不提供规避措辞
- if 地方招聘监管规则未核验
  then 对应字段停止
- if 已进入劳动争议
  then 负触发，路由争议评估

## 证据、金额与下一步

- if 关键事实仅有单方陈述且对方控制原始材料:
  then 不得因对方控制而推定材料存在或内容有利；只列控制方、补证路径和最晚时点。
- if 金额参数不足或地方基数未核验:
  then 只列公式、已知参数、未知参数和区间接口，未知不写零，不输出唯一必得总额。
- if 期限起算日、送达日或知悉日冲突:
  then 建立并行情景并字段停止，不选对用户最有利的一天冒充唯一截止日。
- if 用户要求预测胜诉率或保证机关支持:
  then 拒绝该字段，继续交付可复核事实、条件和缺口。
- if 用户要求倒签、补造程序、伪造送达、隐匿财产或违法取证:
  then 整体停止，只输出拒绝、保全真实材料和按真实日期恢复的条件。

下一步按期限灭失、易失证据、能否改变本任务结论、不可逆性和成本排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。不代用户向机关或对方实际提交。
