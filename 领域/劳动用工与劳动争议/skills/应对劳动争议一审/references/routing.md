# 边界与路由

## 正触发

被告或互诉方已收到起诉状或应诉通知，需要法院一审答辩。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 仲裁答辩 | 应对劳动仲裁 | 不写仲裁答辩 |
| 主动起诉 | 提起劳动争议一审 | 不写起诉状 |
| 二审答辩 | 应对劳动争议二审 | 不写二审答辩 |
| 单位撤裁 | 单位申请撤销终局裁决 | 不写撤裁 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 普通民事答辩非劳动 | 争议解决其他领域 |
| 财产保全应对 | P2 unavailable |
| 刑事并行 | 刑事领域 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

法院起诉材料到了要答辩是正触发；仲裁通知当法院传票，或自己要当原告，或已经判决要上诉时负触发。
