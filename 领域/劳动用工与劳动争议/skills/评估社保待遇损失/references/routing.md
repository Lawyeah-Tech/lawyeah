# 边界与路由

## 正触发

补办路径已关闭或依据支持无法补办，且待遇损失已经发生，劳动者拟向单位主张。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 仍能补办 | 征缴申请或单位整改 | 不替换为损失 |
| 工伤待遇测算 | 测算工伤待遇 | 不并入工伤 |
| 仲裁立案文书 | 提起劳动仲裁 | 不写申请书 |
| 单位整改 | 规划社会保险整改 | 不写单位方案 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 第三人侵权医疗费 | 人身损害领域 |
| 行政复议诉讼文书 | 行政领域 |
| 养老金行政核定争议 | P2 unavailable 或行政领域 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

不能补办且损失已发生是正触发；还没问过能不能补缴就要求按赔偿总额起诉时，先停在补办闸。
