# 评估社保待遇损失方法

本文件是可执行判断节点，不是栏目说明书。每个会改变路径、请求、金额、期限或可提交状态的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不给胜诉率、必然受理、必然有效或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。劳动、社保、工伤、仲裁和执行规则一律运行时核验现行文本后再落判断。

一般商事合同、采购外包主合同、股权交易文件的审查与起草转交审查起草领域；本窗搁置，只说明不实施，不回改该领域或 C 端 109 专项。

## 节点 1　补办闸

能补办则不改写成损失。

- if 现有依据支持仍可补办
  then 负触发损失主位，路由征缴或单位整改
- if 尚未询问经办机构
  then 不能补办字段停止，不得形成损失终局
- if 部分险种可补办部分不可
  then 分项处理，不整案替换

## 节点 2　损失发生

未发生的损失不能当已发生。

- if 只是担心将来养老金减少
  then 已发生损失依据不足
- if 医疗费已发生但报销材料缺失
  then 项目受限，不写零
- if 失业金因未缴无法领取且事实可回链
  then 可作为损失候选继续

## 节点 3　因果与减损

单位未缴不等于全部损失当然成立。

- if 损失另有第三人侵权或自身原因
  then 分摊字段依据不足或不支持全部归责
- if 劳动者拒绝配合补办
  then 减损抗辩列入最强反方
- if 责任主体不明
  then 并列候选，不唯一化

## 节点 4　测算

分项且未知不写零。

- if 参数不足
  then 只给公式和无法估计
- if 把工伤待遇并入社保损失
  then 转出工伤测算
- if 用户要求唯一必得总额
  then 拒绝

## 节点 5　程序

评估不是立案。

- if 用户已决定仲裁立案
  then 目标停止，路由提起劳动仲裁
- if 需要复议诉讼文书
  then 转行政领域
- if 要求伪造不能补办的机关答复
  then 整体停止

## 证据、金额与下一步

- if 关键事实仅有单方陈述且对方控制原始材料:
  then 不得因对方控制而推定材料存在或内容有利；只列控制方、补证路径和最晚时点。
- if 金额参数不足或地方基数未核验:
  then 只列公式、已知参数、未知参数和区间接口，未知不写零，不输出唯一必得总额。
- if 期限起算日、送达日或知悉日冲突:
  then 建立并行情景并字段停止，不选对用户最有利的一天冒充唯一截止日。
- if 用户要求预测胜诉率或保证机关支持:
  then 拒绝该字段，继续交付可复核事实、条件和缺口。
- if 用户要求倒签、补造程序、伪造送达、隐匿财产或违法取证:
  then 整体停止，只输出拒绝、保全真实材料和按真实日期恢复的条件。

下一步按期限灭失、易失证据、能否改变本任务结论、不可逆性和成本排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。不代用户向机关或对方实际提交。
