# 边界与路由

## 正触发

劳动者要向管理中心请求处理单位未缴少缴。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 社保征缴申请 | 准备社保补缴征缴申请 | 不混入社保 |
| 劳动仲裁请求 | 提起劳动仲裁 | 不写仲裁申请 |
| 单位整改 | 规划住房公积金整改 | 不写单位方案 |
| 行政复议诉讼文书 | 行政领域 | 不写复议起诉状 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 行政复议诉讼代理 | 行政领域 |
| 个人住房贷款审批 | 非本领域 |
| C 端消费包 | 只分流不回改 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

向中心追缴公积金是正触发；写成仲裁或并入社保征缴时必须拆开。不代用户提交。
