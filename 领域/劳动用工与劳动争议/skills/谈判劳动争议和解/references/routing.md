# 边界与路由

## 正触发

争议已形成，需要底线、条款和协议，而不是未成争的协商解除。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 未争议的协商解除 | 准备协商解除 | 不写预离职协议冒充和解 |
| 立案或应诉文书 | 仲裁或一审程序原子 | 不写申请答辩 |
| 执行阶段隐匿财产 | 安全停止 | 不提供方法 |
| 总体争议评估 | 评估劳动争议 | 若尚未决定和解则先评估 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 一般商事和解审查起草 | 审查起草领域（本窗搁置） |
| 税务处理 | 税务领域 |
| 刑事谅解 | 刑事领域 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

已经吵起来或已经立案、要谈和解是正触发；还在职友好地谈离职补偿走协商解除。庭外协议不能写成已经有强制执行力。
