# 实施员工转移方法

本文件是可执行判断节点，不是栏目说明书。每个会改变路径、请求、金额、期限或可提交状态的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不给胜诉率、必然受理、必然有效或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。劳动、社保、工伤、仲裁和执行规则一律运行时核验现行文本后再落判断。

一般商事合同、采购外包主合同、股权交易文件的审查与起草转交审查起草领域；本窗搁置，只说明不实施，不回改该领域或 C 端 109 专项。

## 节点 1　不是裁员也不是交易

转移保留关系，裁员消灭关系。

- if 真实目标是减员
  then 负触发，路由裁员安置
- if 用户要设计股权结构
  then 负触发，转并购领域
- if 只是个体调岗仍在原主体
  then 负触发，路由条件变更

## 节点 2　承继

合并分立与资产收购不同。

- if 公司合并或分立
  then 劳动关系承继候选，仍需核验通知和社保主体
- if 仅资产或业务转让
  then 通常需要协商转签，不得写成自动承继
- if 主体变更事实不清
  then 路径字段停止

## 节点 3　同意

强制转签依据必须可回链。

- if 路径依法需要同意但未设计征求
  then 停止可发送终稿
- if 拒绝人员拟按旷工或过失解除
  then 禁止在转移包中夹带该理由
- if 保护期人员未单列
  then 受影响路径停止

## 节点 4　文件

批量文本必须分类。

- if 承继通知与协商解除模板混用
  then 拆分，不得一套打天下
- if 需要股权或资产协议条款
  then 转审查起草或并购，本窗搁置
- if 倒签转移日
  then 整体停止

## 节点 5　工龄

工龄处理影响补偿。

- if 新签拟重置工龄
  then 必须明示法律风险，不得保证有效
- if 补偿或工龄参数未知
  then 不写零
- if 社保公积金转移窗口未核验
  then 办理字段停止

## 证据、金额与下一步

- if 关键事实仅有单方陈述且对方控制原始材料:
  then 不得因对方控制而推定材料存在或内容有利；只列控制方、补证路径和最晚时点。
- if 金额参数不足或地方基数未核验:
  then 只列公式、已知参数、未知参数和区间接口，未知不写零，不输出唯一必得总额。
- if 期限起算日、送达日或知悉日冲突:
  then 建立并行情景并字段停止，不选对用户最有利的一天冒充唯一截止日。
- if 用户要求预测胜诉率或保证机关支持:
  then 拒绝该字段，继续交付可复核事实、条件和缺口。
- if 用户要求倒签、补造程序、伪造送达、隐匿财产或违法取证:
  then 整体停止，只输出拒绝、保全真实材料和按真实日期恢复的条件。

下一步按期限灭失、易失证据、能否改变本任务结论、不可逆性和成本排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。不代用户向机关或对方实际提交。
