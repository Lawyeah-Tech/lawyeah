# 边界与路由

## 正触发

管理方要因主体或集团调整转移员工，而不是裁员或个体调岗。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 交易结构与交割统筹 | 投资并购领域 | 不写交易文件 |
| 裁员安置 | 规划裁员安置 | 不写裁员方案 |
| 个体调岗调薪 | 实施劳动条件变更 | 不做个体变更 |
| 劳动尽调 | 开展劳动专项尽调 | 不写尽调报告 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 交易文件 | 投资并购或审查起草（本窗搁置） |
| 破产重整安置 | 破产领域 |
| 跨境派遣 | 涉外或 P2 unavailable |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

主体变化下保留或转签劳动关系是正触发；实际要裁员，或只要把资产协议写完时负触发。资产收购不能写成自动承继。
