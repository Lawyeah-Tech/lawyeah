# 边界与路由

## 正触发

认定、鉴定或等价材料已经存在，需要按项目和支付主体测算。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 第三人侵权赔偿 | 人身损害领域 | 不写侵权项目 |
| 普通离职补偿 | 测算离职结算补偿 | 不并入 N 或 2N |
| 待遇请求文书 | 准备工伤待遇请求 | 不写请求方案主文 |
| 劳动能力鉴定申请 | P2 unavailable | 不预测等级 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 第三人侵权损害赔偿 | 人身损害领域 |
| 医学停工留薪期鉴定 | 有资质机构 |
| 基金支付争议行政文书 | 行政领域 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

已有认定或鉴定、要把账分项算清是正触发；没有等级就要一次性伤残补助确定额，或把车祸侵权和工伤合成一笔时负触发。
