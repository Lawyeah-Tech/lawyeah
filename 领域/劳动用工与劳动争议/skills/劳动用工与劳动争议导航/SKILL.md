# 劳动用工与劳动争议能力导航

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是运行本技能的强制依赖。

## 定位

说明本包的能力、边界和原子 Skill 全貌，并根据用户当前主要目标与预期成果定位入口。具体法律任务可以直接使用相应原子 Skill，无须先经过本 Guide。

本 Guide 不完成关系识别、合同起草、审计、测算、退出实施、工伤行动、争议评估或任何 P1 专项成果，也不建立固定组合方案。当前安装包是，覆盖 P0 与 P1。

## 选择方法

读取 [选择方法](references/selection-method.md)，按“用户目标 + 独立专业成果 + 当前立场与阶段”选择一个主要原子 Skill。只有某项任务确实需要另一项已形成成果时，才按具体 Skill 声明的依赖处理；律师、机关、用户材料或其他来源提供的等价成果均可作为输入。

混合请求先列出各自可独立验收的成果和对应入口，再只问一个问题：用户这次要先取得哪一项成果。用户回答前不指定主要 Skill，也不暗示执行顺序；用户只询问是否必须按某顺序调用时，先明确回答“不必须”，再询问当前要启动哪一项。

## 当前原子能力

当前安装包是。读取 [能力地图](references/capability-map.md) 查找已安装的全部 P0 与 P1 原子 Skill。只推荐实际安装在本包中的 Skill。未列入的 P2 输出 `unavailable`，不声称路线图中的未发布能力已经可用。

## 领域边界

读取 [领域边界](references/domain-boundaries.md) 处理合同、人身损害、知识产权、数据隐私、企业合规、行政争议、并购、破产、公司治理、税务、涉外、刑事和建设工程等相邻成果。

当劳动专项成果与相邻领域成果同时存在时，将它们拆成各自独立任务；不要在劳动 Skill 内补造相邻领域结论。

## MCP 边界

本包与全家族一样支持 Lawyeah MCP 按需增强。导航通常不必调用工具；是否调用由执行 Agent 按当前任务决定。原子 Skill 按各自判断节点使用已登记工具，工具不可用时只停止依赖该规则的字段。本 Guide 不代替原子 Skill 决定调用，也不得因 MCP 未安装或不可用而拒绝完成本 Guide 的入口定位。

不得声称 MCP 已连接，不要求用户提供密钥或令牌，也不得因工具未注册、不可用或无结果推断没有法律依据。

## 输出

单一成果请求只输出：当前目标与成果、推荐的已安装原子 Skill、选择理由与排除项，以及启动所需的最小输入。

混合请求且用户尚未明确本次优先成果时，只输出：独立成果与入口清单、各自边界，以及“这次先取得哪一项成果”的一个问题；此时不指定主要 Skill，不规定固定执行顺序。
