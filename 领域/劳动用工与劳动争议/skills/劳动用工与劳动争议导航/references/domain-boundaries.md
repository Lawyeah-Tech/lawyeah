# 劳动领域边界

本表只说明领域归属。每次路由先核对 [当前能力地图](capability-map.md)。当前安装包是。P2 或表中写明未安装时，输出 `unavailable`，不得用邻近 Skill 代替。

| 相邻领域 | 当前升级包入口 | 尚未安装（P2，unavailable） | 转交相邻领域的独立成果 |
| --- | --- | --- | --- |
| 合同 | `起草劳动合同` 处理劳动合同起草；`审查劳动合同` 处理劳动合同审查 | 集体合同起草 | 一般商业外包、采购及其他商事合同（审查起草领域，本窗搁置） |
| 人身损害 | 工伤初期、认定申请、待遇测算与请求等已安装工伤原子 | 劳动能力鉴定、复工安置 | 第三人侵权责任及侵权损害赔偿 |
| 知识产权 | `设计竞业限制安排`、`追究竞业限制违约`、`挑战竞业限制` | 劳动关系内保密安排 | 商业秘密权利基础、侵权和损失 |
| 数据隐私 | 招聘流程中的背景调查劳动合规接口 | 员工监控劳动后果 | 个人信息合法性、影响评估、跨境和安全专项 |
| 企业合规 | 制度建设、场所调查、纪律处分 | 员工申诉机制、群体事件预案 | 企业级舞弊、反商业贿赂和综合整改 |
| 行政争议 | `分流劳动行政救济` 只做分流；工伤行政实体争点有专项原子 | 社保经办争议、公积金处理决定、劳动监察投诉与应对 | 行政复议、行政诉讼的通用代理成果 |
| 投资并购 | `开展劳动专项尽调`、`实施员工转移`、`规划裁员安置` | 无 | 交易结构、交割和项目统筹 |
| 破产 | 未安装专门破产安置原子 | 职工债权申报接口 | 职工债权申报、确认和破产分配 |
| 公司治理 | 未安装 | 高管劳动身份、激励劳动后果 | 公司职务、股权和股东权利 |
| 税务 | 未安装 | 薪酬激励税负劳动交叉 | 税负、申报和税务争议 |
| 涉外 | 关系识别仅作中国大陆受限识别 | 外国人在华用工专项 | 境外当地劳动法和跨法域准入监管 |
| 刑事 | 调查原子不作刑事定性 | 无 | 刑事控告、辩护和刑事责任 |
| 建设工程 | 关系识别、测算或工伤原子仅按各自范围使用 | 农民工工资专项治理 | 工程合同、工程价款和施工责任 |

职业危害技术评价、安全生产工程结论和医学诊断需要有资质的专业机构完成。没有已安装入口时输出 `unavailable`。
