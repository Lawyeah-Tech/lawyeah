# 边界与路由

## 正触发

双方或单方已选择走协商解除，需要谈判和协议，争议诉讼尚未成为主轴。

## 负触发

| 主要目标 | 路由方向 | 本任务不得继续 |
| --- | --- | --- |
| 已形成争议的和解 | 谈判劳动争议和解 | 不写诉讼和解 |
| 仍在比较单方解除 | 评估单位个体退出 | 不选路径 |
| 劳动者总体退出应对 | 评估劳动者退出应对 | 不改写成劳动者总方案 |
| 解除通知实施 | 实施单位解除终止 | 不发单方通知 |

## 专项转出

| 主轴信号 | 路由 |
| --- | --- |
| 诉讼和解协议审查起草扩张 | 审查起草领域（本窗搁置） |
| 税务处理 | 税务领域 |
| 股权激励退出 | 公司治理 |
| 一般商事合同审查或起草 | 审查起草领域（本窗搁置，只说明不实施） |
| C 端大众劳动专项 | 只分流，不回改 109 或消费包正文 |

## 易混场景

已经决定走协商、要协议和履行清单是正触发；还在问能不能开除，或案子已经立案要庭上和解时负触发。
