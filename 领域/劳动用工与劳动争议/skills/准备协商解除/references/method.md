# 准备协商解除方法

本文件是可执行判断节点，不是栏目说明书。每个会改变路径、请求、金额、期限或可提交状态的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不给胜诉率、必然受理、必然有效或唯一必得总额。未知金额不写零。

`search_law` 返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。劳动、社保、工伤、仲裁和执行规则一律运行时核验现行文本后再落判断。

一般商事合同、采购外包主合同、股权交易文件的审查与起草转交审查起草领域；本窗搁置，只说明不实施，不回改该领域或 C 端 109 专项。

## 节点 1　路径闸

协商必须是已选路径。

- if 单位还在比较过失或裁员
  then 负触发，路由退出评估
- if 已有仲裁或诉讼且目标是和解
  then 负触发，路由争议和解
- if 劳动者尚未决定是否协商
  then 负触发，路由劳动者退出评估

## 节点 2　授权

无授权不签字。

- if 签署权限或款项审批不明
  then 停止可签署终稿
- if 同时掌握双方谈判底线
  then 整体停止，澄清一方
- if 对方法定代表人未确认
  then 对方签署字段停止

## 节点 3　条款

协议不能消灭全部法定权利。

- if 要求劳动者放弃尚未发生的工伤或社会保险权利
  then 该弃权现有依据不支持
- if 款项与离职测算参数冲突
  then 列入冲突，不静默改小
- if 需要一般商事和解合同审查
  then 劳动协议继续，商事扩张转审查起草领域本窗搁置

## 节点 4　履行

签字不是已付款。

- if 支付安排无账户或审批
  then 履行字段停止
- if 要求先签空白协议再填金额
  then 整体停止
- if 离职证明或档案转移未列入
  then 补入清单，不以付款代替

## 节点 5　破裂

协商破裂回到决策，不自动解除。

- if 对方拒绝且单位要立即单方解除
  then 本任务停止，路由退出评估或实施
- if 谈判中承认的事实被要求隐瞒
  then 拒绝隐瞒
- if 倒签解除日
  then 整体停止

## 证据、金额与下一步

- if 关键事实仅有单方陈述且对方控制原始材料:
  then 不得因对方控制而推定材料存在或内容有利；只列控制方、补证路径和最晚时点。
- if 金额参数不足或地方基数未核验:
  then 只列公式、已知参数、未知参数和区间接口，未知不写零，不输出唯一必得总额。
- if 期限起算日、送达日或知悉日冲突:
  then 建立并行情景并字段停止，不选对用户最有利的一天冒充唯一截止日。
- if 用户要求预测胜诉率或保证机关支持:
  then 拒绝该字段，继续交付可复核事实、条件和缺口。
- if 用户要求倒签、补造程序、伪造送达、隐匿财产或违法取证:
  then 整体停止，只输出拒绝、保全真实材料和按真实日期恢复的条件。

下一步按期限灭失、易失证据、能否改变本任务结论、不可逆性和成本排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。不代用户向机关或对方实际提交。
