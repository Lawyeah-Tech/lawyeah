# 测算方法

本任务**不认定少缴、偷税或虚开已经成立**。测算行建立在明示假设上。

`search_law` 返回 1992 年《税收征收管理法》同号旧义、已失效《税务行政复议规则（暂行）》或已废止《增值税暂行条例》充当 2026-01-01 之后现行法时，记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 主目标是遗嘱、夫妻财产协议、继承分配、代际架构或婚家传承方案本身 | 婚家领域 |
| 主目标是非税务机关作出的一般行政行为复议或诉讼程序 | 行政争议领域 |
| 主目标是跨境交易、贸易管制、境外投资整体 | 涉外领域 |
| 主目标是薪酬、解除、社保等劳动权利本身 | 劳动领域 |
| 公安、监察已介入，或主目标是会见、取保、辩护、定罪 | 刑事领域 |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 海关代征、缉私主导 | 海关／涉外，不按国内税务检查清单放行 |

混合信号：税务主轴可留本任务；专项只作为背景时在缺口标明。C 端 054／055／014 只分流，不回改。

若主目标只要定性总图：负触发，转 `assess-tax-matter`。

## 节点 1　假设和事件

1. 为每个独立经济事件分配 `EVT#`：未开票收入、进项转出、费用不得税前扣除、优惠追回、视同销售等。
2. 每个 `M#` 必须挂 `HYP#`：若某 `Q#` 成立，则如何计算。
3. 税种不得混行。增值税、企业所得税、个人所得税、土地增值税、印花各行。
4. 2026-01-01 之后的增值税计算须按《增值税法》核验，不得继续套用已废止暂行条例条文充当 `L#`。所属期跨越施行日：分属期，不混用。

---

## 节点 2　分项建账

每个 `M#` 固定列：

`编号｜项目｜税种｜所属期｜EVT#｜HYP#／Q#｜参数｜未舍入公式｜已缴／扣减｜互斥｜金额状态｜判断｜待核｜来源`

金额状态只用：`无法估计`、`情景金额`、`已核实金额`。只有数值足以复算时才用后两档。

默认分项：

| 项目 | 计入规则 |
| --- | --- |
| 税款 | 计税依据 × 税率或征收率，按现行法 |
| 进项转出 | 不得抵扣或虚开风险下的转出，挂假设 |
| 滞纳金 | 税款 × 日万分之五 × 天数情景，封顶与停止加收待核 |
| 罚款 | 法定幅度区间，须有处罚接口 |
| 加处罚款 | 与罚款分列 |
| 优惠追回 | 与原税款分列，不重复加总税基 |

---

## 节点 3　滞纳金

运行时核验征管法第三十二条及现行滞纳金规则。

1. 因税务机关责任未缴少缴：不得加收滞纳金（第五十二条第一款）。
2. 起算：应缴未缴或少缴之日起算须核验细则第八十三条，不得用检查通知日冒充。
3. 停止加收：缴纳日、复议诉讼中停止执行是否停止加收，运行时核验，不得凭记忆写“起诉就停”。
4. 本金未知：滞纳金行 `无法估计`，禁止用零本金算出零滞纳金。

---

## 节点 4　罚款

1. 无告知书或决定书：罚款不是已核实金额。
2. 幅度须核验行为对应条文（例如第六十三条）。不得用“一般百分之五十到五倍”套所有行为。
3. 五年处罚时效可能挡住罚款但挡不住偷税追征：分列，不把时效写成税款也消失。
4. 不得输出“认罚就能按最低档”。

---

## 节点 5　加总和披露

可以给情景合计，但必须：

- 标明假设组合；
- 分项可见；
- 互斥项不得相加（例如同一进项既当转出又当不得抵扣重复）；
- 明确“不是机关确定税额，不是申报数”。

首次逃税补缴免刑条件不在本表折算成折扣。
