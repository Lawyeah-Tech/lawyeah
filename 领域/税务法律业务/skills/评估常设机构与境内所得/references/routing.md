# 边界与路由

## 正触发

境外主体境内活动是否构成机构场所或常设机构。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 跨境交易或投资整体 | 涉外领域 |
| 居民身份 | `评估居民身份与纳税地点` |
| 对外付汇扣缴 | `评估对外付汇扣缴` |
| 保证不构成 PE | 不实施 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

境外公司派人长期在客户现场交付，合同写成“技术咨询”。正触发：服务 PE 与机构场所分表，未知天数不写零，整体投资方案转涉外。
