# 边界与路由

## 正触发

账户、商品或财产已被税收保全。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 转移隐匿 | 不实施 |
| 强制执行 | `应对税收强制执行` |
| 准备担保 | `准备纳税担保` |
| 调取账簿 | `应对调账检查与资料调取` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

保全后客户要把货连夜转走“免得被拍卖”。整体停止。拍卖属强制阶段，本任务只做条件、解除和救济。
