# 边界与路由

## 正触发

账套、邮件或进销存可能灭失或已被调取，需要只读备份。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 格式化或改系统时间 | 不实施 |
| 调取程序权利 | `应对调账检查与资料调取` |
| 证据评价建卷 | `建立税务证据案卷` |
| 刑事毁灭证据 | 刑事领域／整体停止 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

IT 建议重装系统“清干净再配合检查”。整体停止。只输出只读镜像和禁止清单。
