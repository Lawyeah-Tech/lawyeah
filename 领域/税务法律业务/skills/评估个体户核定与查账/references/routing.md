# 边界与路由

## 正触发

个体户或个人经营征收方式、定额偏离，经营者需要争点与建账义务。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 大众预防体检 | C 端 054，只分流 |
| 已进入检查 | `评估税务检查应对` |
| 企业核定征收 | `评估查账与核定征收` |
| 合伙穿透 | `评估合伙穿透课税` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

平台销售收入远超定额，客户问“还按定额缴是不是就行”。正触发：列偏离调整接口，禁止隐瞒流水。只要 054 对照则分流。
