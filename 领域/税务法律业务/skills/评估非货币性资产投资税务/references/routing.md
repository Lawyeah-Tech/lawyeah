# 边界与路由

## 正触发

以股权、不动产或知识产权出资，需要递延和评估接口。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 撰写出资协议 | 审查起草本窗搁置 |
| 公司设立整体 | 公司治理 |
| 特殊重组 | `评估重组特殊性税务处理` |
| 不动产过户方案 | 房地产／`评估不动产交易税负` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

个人用股权作价出资，要求“递延五年一定批”。正触发：列条件与备案缺口，不保证批准，不写出资协议。
