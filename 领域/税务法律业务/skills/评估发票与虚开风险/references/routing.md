# 边界与路由

## 正触发

受票、开票、走逃或协查，需要虚开与善意取得边界。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 定罪或刑事辩护 | 刑事领域 |
| 异常失控作废操作 | `处理异常失控作废发票` |
| 协查回函 | `准备发票协查应对` |
| 进项抵扣专项 | `评估进项抵扣能否成立` |
| 指导补票改账 | 不实施 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

上游走逃，受票方说“我们有合同就是善意”。正触发：对照善意取得条件，不定罪，不指导补假票。公安已介入则刑行分流。
