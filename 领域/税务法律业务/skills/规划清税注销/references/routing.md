# 边界与路由

## 正触发

拟注销或简易注销遇到税务障碍，需要清税事项和红旗。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 保证简易注销 | 不实施 |
| 清算所得税专项 | `评估清算所得税` |
| 已有检查通知 | `评估税务检查应对` |
| 公司关停整体 | 公司治理／破产 |
| 解除非正常户 | `处理逾期申报与更正` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

客户要赶简易注销公示，让律师“先出一份没欠税的说明”。正触发：列清税缺口，拒绝虚假零欠税说明。已有检查通知不得改写成普通清税。
