# 边界与路由

## 正触发

已收强制执行决定或即将扣缴、拍卖。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 对抗执行或转移财产 | 不实施 |
| 税收保全 | `应对税收保全` |
| 申请停止执行 | `申请停止执行或暂缓` |
| 补税谈判 | `谈判补税整改方案` |
| 破产税务债权 | 破产领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

账户即将被扣，客户要先把钱转到亲属卡。整体停止转移。本任务只做程序抗辩、缴纳停止和救济分流。
