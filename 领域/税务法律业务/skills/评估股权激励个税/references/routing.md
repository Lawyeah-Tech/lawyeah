# 边界与路由

## 正触发

期权、限制性股票或分红激励需要个税口径。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 劳动权利或行权安排本身 | 劳动领域 |
| 撰写激励计划 | 审查起草本窗搁置 |
| 股权转让一般税负 | `评估股权转让税负` |
| 解除补偿个税 | `测算解除补偿个税` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

员工离职未行权，公司问“能不能按补偿金免税”。正触发：激励所得与解除补偿分账，补偿专项另项，不写计划，劳动权利转劳动。
