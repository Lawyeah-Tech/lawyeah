# 边界与路由

## 正触发

合并、分立、划转或股权／资产收购拟适用特殊重组。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 保证适用 | 不实施 |
| 并购交易整体 | 投资并购领域 |
| 普通股权转让税负 | `评估股权转让税负` |
| 撰写重组协议 | 审查起草本窗搁置 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

收购比例未达线，客户要求按特殊重组出意见以便融资。正触发：逐条对照并标失败后果，不保证适用，不写交易文件。
