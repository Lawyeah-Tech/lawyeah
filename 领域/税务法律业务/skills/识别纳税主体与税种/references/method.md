# 主体税种识别方法

本文件是可执行判断节点，不是栏目说明书。每个会改变争点、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然补税、必然免罚或唯一必得总额。

`search_law` 返回 1992 年《税收征收管理法》同号旧义、已失效《税务行政复议规则（暂行）》或已废止《增值税暂行条例》充当 2026-01-01 之后现行法时，记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 主目标是遗嘱、夫妻财产协议、继承分配、代际架构或婚家传承方案本身 | 婚家领域 |
| 主目标是非税务机关作出的一般行政行为复议或诉讼程序 | 行政争议领域 |
| 主目标是跨境交易、贸易管制、境外投资整体 | 涉外领域 |
| 主目标是薪酬、解除、社保等劳动权利本身 | 劳动领域 |
| 公安、监察已介入，或主目标是会见、取保、辩护、定罪 | 刑事领域 |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 海关代征、缉私主导 | 海关／涉外，不按国内税务检查清单放行 |

混合信号：税务主轴可留本任务；专项只作为背景时在缺口标明。C 端 054／055／014 只分流，不回改。

## 节点 1　名称冲突

1. 为每个出现过的名称建立 `TP#`：营业执照、税务登记、开户许可、发票抬头、合同相对方、实际收款人。
2. 若现有依据支持两名称指向同一法律主体（统一社会信用代码一致）：可合并，并在来源标注。
3. 若只有简称、曾用名或口头指称：`依据不足，无法形成结论`，不得合并。
4. 总分机构：总部与分支机构各建一行。跨区经营未经核验不得写成只由总部纳税。
5. 合伙、契约型基金、个人独资：不得直接写成公司企业所得税纳税人，除非运行时核验支持。

## 节点 2　角色

| 已能支持的事实 | 可写 | 不得写成 |
| --- | --- | --- |
| 发生应税行为或取得应税所得 | 纳税人候选 | 已确定唯一纳税人并排除扣缴 |
| 支付所得且依法应扣 | 扣缴义务人候选 | 被支付方无申报义务 |
| 机关委托代征协议 | 代征角色 | 代征人就是纳税人 |
| 实际控制人指挥开票收款 | 控制关系待核 | 当然的纳税主体 |

若用户要求把空壳公司或自然人从纳税人表删除：整体停止，不得配合隐匿。

## 节点 3　税种税目

每个独立经济事件 `EVT#` 对应至少一个 `TX#`。

- 销售货物、服务、无形资产、不动产：增值税候选；所属期在 2026-01-01 之后按《增值税法》，不得引用已废止暂行条例充当 `L#`。
- 生产销售应税消费品：消费税另行一行，不并入增值税。
- 企业所得：居民企业与非居民分列。
- 个人所得：综合所得、经营所得、财产转让、利息股息红利分目。
- 转让土地使用权或房地产：土地增值税、契税、印花各行。
- 书立应税凭证：印花税。

税目不明：只列候选和待核事实，不选对用户有利的低税率充当结论。

## 节点 4　属地属人

运行时核验征管法实施细则及增值税法、企业所得税法纳税地点条款。核验失败则本节点字段停止。

1. 固定业户与非固定业户分列。
2. 不动产所在地、机构所在地、劳务发生地冲突时并行情景，不输出唯一主管机关。
3. 居民身份争议转介 `assess-tax-resident`，本任务只留接口。
4. 海关代征进口增值税、消费税：整案转海关／涉外。

## 节点 5　输出与转介

| 条件 | 本任务输出 | 转介 |
| --- | --- | --- |
| 主体税种仍乱，用户只要总图 | 负触发 | `assess-tax-matter` |
| 要办设立变更注销 | 最小交接 | `plan-registration-change` 或 `plan-tax-deregistration` |
| 扣缴范围和时点是主目标 | 角色表 | `assess-withholding-duty` |
| 对外付汇 | 角色接口 | `assess-outbound-withholding` |

不得因名称相近就把个人经营者写成企业所得税纳税人。未知金额不写零。


## 证据、金额与下一步

不能因机关控制材料而推定内容有利。禁止指导伪造、隐匿、虚开、拒检、改账或违法取证。未知金额不写零，不输出唯一必得总额或胜诉率。

若现有依据支持某一法律效果：写入对应 `Q#` 并回链来源。若现有依据不支持：明确排除该效果，不得改用更有利的相邻效果顶替。若依据不足：字段停止，并列待核事实，不选对用户有利的默认值。

发送申辩、听证、复议、起诉、登记、备案或对外文书，只写转介条件和最小交接。规则未核验的法律结论、期限或机关路径字段停止。C 端 054／055／014 只分流。
