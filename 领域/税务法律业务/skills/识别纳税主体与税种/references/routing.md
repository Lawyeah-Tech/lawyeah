# 边界与路由

## 正触发

主体混同、总分机构、扣缴代征或税种定性不明，单方需要可复核的主体与税种表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 总体评估总图 | `评估税务事项` |
| 代办税务登记或变更 | `规划税务登记变更` |
| 清税注销 | `规划清税注销` |
| 扣缴范围与时点专项 | `评估扣缴义务` |
| 居民身份专项 | `评估居民身份与纳税地点` |
| 精算税额 | `测算调整滞纳金罚款` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

总公司与分公司共用发票抬头时，用户说“都是我们公司”。正触发：先拆 `TP#`，不因抬头相同合并纳税主体。用户只要“整个案子怎么打”则负触发，转总体评估。
