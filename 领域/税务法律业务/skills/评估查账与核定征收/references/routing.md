# 边界与路由

## 正触发

拟核定、已被核定或争议可否查账。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 个体户定额 | `评估个体户核定与查账` |
| 唯一税额 | `测算调整滞纳金罚款` |
| 已进入检查只要应对 | `评估税务检查应对` |
| 指导假账转核定 | 不实施 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

企业成本票缺失，顾问建议“申请核定更省税”。正触发：对照第三十五条，拒绝毁账或假乱账建议，不定唯一税额。
