# 边界与路由

## 正触发

房产或股权赠与、继承过户需要税负，或已成税务争议。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 遗嘱、财产协议、代际架构 | 婚家领域 |
| 不动产买卖税负 | `评估不动产交易税负` |
| 股权转让税负 | `评估股权转让税负` |
| 过户手续方案 | 不实施 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

父母把房产过户给子女并收取部分房款，要求按继承免税出意见。正触发：关系与对价并行，可能转买卖税负，拒绝写遗嘱或财产协议。
