# 边界与路由

## 正触发

账簿、凭证或电子数据已被或即将被调取。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 藏账或改系统时间 | 不实施 |
| 税收保全 | `应对税收保全` |
| 强制执行 | `应对税收强制执行` |
| 只读备份专项 | `保全账簿与电子数据` |
| 刑事扣押 | 刑事领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |
