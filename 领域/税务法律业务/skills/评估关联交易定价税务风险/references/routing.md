# 边界与路由

## 正触发

关联购销、服务或资金占用被问定价，需要风险与资料接口。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 特别纳税调整评估 | `评估转让定价调整` |
| 准备同期资料 | `准备同期资料` |
| 一般反避税调查 | `应对反避税调查` |
| 跨境架构整体 | 涉外领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

母公司长期无偿占用资金，财务问“内部往来是不是不用管”。正触发：列独立交易风险，不认定避税已成立，不替代调整评估。
