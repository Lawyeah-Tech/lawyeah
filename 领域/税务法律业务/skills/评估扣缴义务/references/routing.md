# 边界与路由

## 正触发

支付方被指应扣未扣，或被扣方争议代扣，需要扣缴专项。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 劳动报酬或解除权利本身 | 劳动领域 |
| 对外付汇扣缴 | `评估对外付汇扣缴` |
| 总体评估 | `评估税务事项` |
| 精算终稿 | `测算调整滞纳金罚款` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

公司把年终奖改成报销，财务问“是不是就不用扣了”。正触发：按所得实质列扣缴候选，不得指导改名规避。劳动请求本身转劳动。
