# 边界与路由

## 正触发

风险提示或自查通知已到，尚未立案稽查。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 已立案检查 | `评估税务检查应对` |
| 普通更正（无自查通知） | `处理逾期申报与更正` |
| 补税谈判 | `谈判补税整改方案` |
| 保证补了就没事 | 不实施 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

自查通知与检查通知同一天送达。必须分文书：检查已启动则本任务负触发，不得再出“自查关闭案件”方案。
