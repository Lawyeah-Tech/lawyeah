# 边界与路由

## 正触发

房产土地买卖、投资或抵债，需要税负争点而不是过户方案。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 网签或过户方案 | 不实施／房地产领域 |
| 开发销售争议 | 房地产领域 |
| 赠与继承涉税 | `评估赠与继承涉税后果` |
| 土地增值税清算 | `测算土地增值税清算` |
| 撰写买卖合同 | 审查起草本窗搁置 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

卖房客户说“按网签低价报税”。正触发：按实质对价列计税接口，拒绝阴阳合同，不写过户方案。
