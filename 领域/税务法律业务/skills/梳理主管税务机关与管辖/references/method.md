# 税务管辖梳理方法

本文件是可执行判断节点，不是栏目说明书。每个会改变争点、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然补税、必然免罚或唯一必得总额。

`search_law` 返回 1992 年《税收征收管理法》同号旧义、已失效《税务行政复议规则（暂行）》或已废止《增值税暂行条例》充当 2026-01-01 之后现行法时，记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## 节点 1　文书上的机关

1. 摘录全称、印章、文号前缀。简称“市局”“稽查”单独建 `ORG#`，判断为依据不足。
2. 检查通知、处理决定、处罚决定、保全、强制可能由不同机关作出：逐份列表，不合并。
3. 风险评估或协查函的发文机关不等于处理决定机关。

## 节点 2　稽查局与税务所

运行时核验税务行政复议规则第十六条、第十七条。核验失败则复议机关字段停止。

- 若现有依据支持作出机关是税务所、稽查局：复议机关候选为所属税务局，而不是当然上一级省局。
- 若现有依据支持作出机关是税务局：复议机关候选为上一级税务局。
- 计划单列市税务局、税务总局派出机构：单独核验，不得套用地级市规则。
- 国地税合并前的旧文书：标明历史机关，不得用已撤销机关当作现行复议被申请人而不加说明。

## 节点 3　跨区经营

1. 注册地主管与经营地、项目地、不动产所在地分列。
2. 汇总纳税、跨区税源分配未核验：属地字段停止。
3. 共同作出的行政行为：列出全部作出机关，复议被申请人按核验规则并列，不擅自选一个。
4. 上级交办或指定管辖：需要交办文书，口头指定无效。

## 节点 4　不得写成

| 事实 | 不得写成 |
| --- | --- |
| 已能列出复议机关候选 | 法院已确定 |
| 稽查局已检查 | 处理权、处罚权、复议机关已当然归属同一局 |
| 两地都曾收过税 | 两地都有权处理同一所属期全部税种 |
| 海关进口增值税 | 国内主管税务局当然管辖 |

## 证据、金额与下一步

不能因机关控制材料而推定内容有利。禁止指导伪造、隐匿、虚开、拒检、改账或违法取证。未知金额不写零，不输出唯一必得总额或胜诉率。

若现有依据支持某一法律效果：写入对应 `Q#` 并回链来源。若现有依据不支持：明确排除该效果，不得改用更有利的相邻效果顶替。若依据不足：字段停止，并列待核事实，不选对用户有利的默认值。

发送申辩、听证、复议、起诉、登记、备案或对外文书，只写转介条件和最小交接。规则未核验的法律结论、期限或机关路径字段停止。C 端 054／055／014 只分流。
