# 边界与路由

## 正触发

多机关、稽查局、跨区经营或共同行为，需要主管与复议机关图。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 选定管辖法院 | `提起税务行政诉讼` |
| 复议申请终稿 | `申请税务行政复议` |
| 海关代征 | 海关／涉外 |
| 一般行政机关管辖 | 行政争议领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

稽查局作出处理决定，客户说“找市局复议还是找省局”。正触发：按所属关系列候选并核验第十六条、第十七条，不凭国地税旧习惯指定。
