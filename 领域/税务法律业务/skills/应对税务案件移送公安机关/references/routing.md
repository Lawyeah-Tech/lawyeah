# 边界与路由

## 正触发

税务案件已决定或可能移送公安机关。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 会见取保辩护 | 刑事领域 |
| 首次免刑条件 | `评估首次逃税不予追究刑事责任条件` |
| 刑行边界判断 | `分流逃税骗税虚开刑行交叉` |
| 海关缉私 | 海关／涉外／刑事 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

移送函已出，客户要律师去看守所会见并在本技能写取保理由。负触发刑事部分：会见取保转刑事，本任务只做移送节点和行政衔接。
