# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变争点、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然补税、必然免罚或唯一必得总额。

`search_law` 返回 1992 年《税收征收管理法》同号旧义、已失效《税务行政复议规则（暂行）》或已废止《增值税暂行条例》充当 2026-01-01 之后现行法时，记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜关系假设｜提出方｜相对方｜法律效果｜成立条件｜支持事实｜不利事实｜控制方｜最强反方｜主备位｜判断｜待核`。

补税、滞纳金、罚款、优惠追回、虚开进项转出分列。同一事实支持多项时分别说明效果，不重复金额。构成少缴不等于当然偷税，也不等于当然刑事移送。

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 主目标是遗嘱、夫妻财产协议、继承分配、代际架构或婚家传承方案本身 | 婚家领域 |
| 主目标是非税务机关作出的一般行政行为复议或诉讼程序 | 行政争议领域 |
| 主目标是跨境交易、贸易管制、境外投资整体 | 涉外领域 |
| 主目标是薪酬、解除、社保等劳动权利本身 | 劳动领域 |
| 公安、监察已介入，或主目标是会见、取保、辩护、定罪 | 刑事领域 |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 海关代征、缉私主导 | 海关／涉外，不按国内税务检查清单放行 |

混合信号：税务主轴可留本任务；专项只作为背景时在缺口标明。C 端 054／055／014 只分流，不回改。

## 节点 1　主体、税种和程序状态

1. 固定纳税主体、扣缴义务人、担保人、实际控制人和发票抬头。名称不一致不自动合并。
2. 税种与所属期按申报表、缴款书、检查通知、处理决定分列。不得把多期合成“近几年”。
3. 程序表逐动作记录自查、评估约谈、检查、稽查立案、告知、听证、处理、处罚、保全、强制、复议、诉讼：机关、文号、作出日、收到日、送达方式和效力凭证。口头数字不得写成已确定税额。
4. 同时掌握征纳双方秘密或立场不明：整体停止策略输出。

## 节点 2　争点假设

每个 `Q#` 先写法律效果，再写成立条件。禁止合成“税务责任”一笔。

默认主位候选按事实分别建立：

- `Q-纳` 纳税义务是否成立及税目税率
- `Q-扣` 扣缴义务
- `Q-优` 优惠、减免、加计是否被追回
- `Q-票` 发票与进项
- `Q-补` 补税
- `Q-滞` 滞纳金
- `Q-罚` 行政处罚
- `Q-刑` 刑行交叉红旗（只分流，不定罪）
- `Q-救` 陈述、听证、复议、诉讼入口

单位或被查方立场：逐项回应对方已知主张，并列己方最强抗辩，不把复议写成已经提起。

## 节点 3　程序入口

本节点只判断路径，不生成发送版文书。

### 3.1 先分账

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 少缴或申报差异 | 已构成偷税或逃税罪 |
| 已收检查通知 | 处理决定已作出或税额已确定 |
| 已收处理决定 | 处罚决定已可忽略或已可直接起诉 |
| 对方未在某期内异议 | 即使未送达也已生效 |

### 3.2 征税行为与其他行为

运行时核验征管法第八十八条、实施细则第一百条、税务行政复议规则第十四条后再落判断。核验失败则本节点字段停止。

1. **征税行为**：确认纳税主体、征税对象、范围、减免退抵、税率、计税依据、环节、期限、地点、征收方式、征税款、加收滞纳金、代扣代收代征。主位写成先缴或担保 → 复议 → 诉讼，转介 `assess-collection-gate`。
2. **处罚、保全、强制**：可复议也可诉讼，不得写成必须先复议，除非运行时核验出相反现行规则。
3. **加处罚款**：规则第三十四条第二款须先缴纳罚款和加处罚款再复议；运行时核验。

### 3.3 输出

| 条件 | 本任务输出 | 转介 |
| --- | --- | --- |
| 仍在检查、告知前 | 阶段、权利、禁止动作 | `assess-inspection-path` |
| 要提交申辩 | 最小交接 | `prepare-statement` |
| 要申请听证 | 申请期限红旗 | `prepare-hearing` |
| 要打开纳税争议复议 | 先缴闸红旗 | `assess-collection-gate` |
| 用户坚持今天出复议或起诉终稿 | 目标停止 | 对应原子，不在本包出稿 |

## 节点 4　期限分类型

每种期间单独一行。禁止用五年处罚时效去算补税，也禁止用三年追征去挡偷税追征。

| 类型 | 规则锚点 | 本任务允许的输出 | 禁止 |
| --- | --- | --- | --- |
| 追征 | 征管法第五十二条 | 机关责任／失误／偷抗骗分列情景 | 唯一截止日 |
| 处罚时效 | 第八十六条五年 | 发现日待核 | 用追征替代处罚时效 |
| 复议 | 规则第三十二条六十日 | 知道日／送达日并行 | 把检查通知日当成复议起算 |
| 听证申请 | 行政处罚法与税务听证办法，运行时核验 | 告知书送达日原文、三日／五日并行情景 | 通知送达日加固定天数充作听证截止 |
| 起诉 | 行政诉讼法，运行时核验 | 复议前置是否挡住 | 纳税争议写成应直接起诉 |

日期冲突、送达不明：并行情景 + 字段停止。

## 节点 5　金额区间

本任务只建区间和接口，不替代 `calculate-exposure`。

1. 分项：税款、滞纳金、罚款、加处罚款、进项转出、优惠追回。未知不写零，不输出唯一必得总额。
2. 检查人员口头数、内部测算、用户“大概八十万”一律标陈述，不得写入已核实金额。
3. 滞纳金每日万分之五须运行时核验现行文本；起算和停止加收分列。
4. 罚款倍数只标接口，不选对用户最有利的一档当成结论。
5. 首次逃税补缴免刑只标红旗和转介，不定“补了就没事”。

参数不足：只列已知参数、未知参数和专项测算接口。
