# 边界与路由

路由表中的原子 Skill 若未安装在当前包，输出 `unavailable`，不得由本任务代做。

## 正触发

税务事项已出现，单方需要总体决定争点、程序入口、证据优先级和下一步。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 婚家传承方案、遗嘱、财产协议本身 | 婚家领域 |
| 一般行政复议或非税务行政诉讼 | 行政争议领域 |
| 评估检查阶段与权限 | `评估税务检查应对` |
| 判断先缴或担保 | `评估纳税争议先缴或担保` |
| 精算补税滞纳金罚款 | `测算调整滞纳金罚款` |
| 完整证据卷 | `建立税务证据案卷` |
| 发陈述申辩 | `准备检查陈述申辩` |
| 申请听证 | `准备税务听证材料` |
| 申请税务复议 | `申请税务行政复议` |
| 提起税务行政诉讼 | `提起税务行政诉讼` |
| 补税整改谈判 | `谈判补税整改方案` |
| 大众预防体检 | C 端 054，只分流 |
| 大众检查应急清单 | C 端 055，只分流 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

检查通知已到、用户要“先看看严重不严重”时正触发。主体、文书、请求均确认且只要申辩稿时负触发。已收处理决定仍要求“直接去法院告征税”时，先完成先缴闸，不改写成诉讼原子。
