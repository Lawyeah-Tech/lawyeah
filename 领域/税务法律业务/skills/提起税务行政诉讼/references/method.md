# 起诉方法

纳税争议未经过复议程序（含不受理或逾期未答复的法定出口）不得包装成可提交起诉包。

`search_law` 返回 1992 年《税收征收管理法》同号旧义、已失效《税务行政复议规则（暂行）》或已废止《增值税暂行条例》充当 2026-01-01 之后现行法时，记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 主目标是遗嘱、夫妻财产协议、继承分配、代际架构或婚家传承方案本身 | 婚家领域 |
| 主目标是非税务机关作出的一般行政行为复议或诉讼程序 | 行政争议领域 |
| 主目标是跨境交易、贸易管制、境外投资整体 | 涉外领域 |
| 主目标是薪酬、解除、社保等劳动权利本身 | 劳动领域 |
| 公安、监察已介入，或主目标是会见、取保、辩护、定罪 | 刑事领域 |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 海关代征、缉私主导 | 海关／涉外，不按国内税务检查清单放行 |

混合信号：税务主轴可留本任务；专项只作为背景时在缺口标明。C 端 054／055／014 只分流，不回改。

## 节点 1　前置

1. 行为定性复用先缴闸标准。
2. 征税行为：必须具备下列之一且可回链：复议决定；不予受理决定；复议机关逾期不作答复。仅有“我们不想复议”：负触发。
3. 处罚、保全、强制：可直接起诉。用户仍想先复议：转复议原子，不在本包出诉状。
4. 一般行政行为：整案转行政领域。

---

## 节点 2　被告与请求

运行时核验行政诉讼法被告规则。复议维持与改变的被告确定不得凭记忆写死。

请求分列：撤销处理／处罚、确认违法、判令返还、停止执行接口。不得合成“解决税务问题”。不请求法院代为定税种立法。

---

## 节点 3　管辖

分列被告所在地、复议机关所在地、专属管辖和级别管辖。材料不足不选定唯一法院。海关处理的纳税争议不按本包国内税务局口径。

---

## 节点 4　期限

复议决定送达后起诉期限、直接起诉期限、不知行政行为时的最长期限，运行时核验现行行政诉讼法，不得用六十日复议期限冒充起诉期限。冲突并行情景。

---

## 节点 5　起诉状

原告、被告、诉讼请求、事实理由、证据目录、管辖连结点、是否经过复议。只交付草案。不保证七日立案。停止执行或保全只红旗，转介对应原子。
