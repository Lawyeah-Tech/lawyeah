# 边界与路由

## 正触发

拟或已进入重大税务案件审理，需要节点和陈述机会。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 预测审理结论 | 不实施 |
| 普通陈述申辩 | `准备检查陈述申辩` |
| 听证申请 | `准备税务听证材料` |
| 一般复议程序 | 行政争议领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

检查科说案子要上审委会，客户问“是不是已经定了百分之八十会罚”。正触发：只做节点和权利，不预测结论，不把口头当成已进入。
