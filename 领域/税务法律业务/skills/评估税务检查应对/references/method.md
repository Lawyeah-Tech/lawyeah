# 检查评估方法

本文件是可执行判断节点。判断只用三类用语。不得输出“这样应对一定没事”或确定税额。

`search_law` 返回 1992 年《税收征收管理法》同号旧义、已失效《税务行政复议规则（暂行）》或已废止《增值税暂行条例》充当 2026-01-01 之后现行法时，记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 主目标是遗嘱、夫妻财产协议、继承分配、代际架构或婚家传承方案本身 | 婚家领域 |
| 主目标是非税务机关作出的一般行政行为复议或诉讼程序 | 行政争议领域 |
| 主目标是跨境交易、贸易管制、境外投资整体 | 涉外领域 |
| 主目标是薪酬、解除、社保等劳动权利本身 | 劳动领域 |
| 公安、监察已介入，或主目标是会见、取保、辩护、定罪 | 刑事领域 |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 海关代征、缉私主导 | 海关／涉外，不按国内税务检查清单放行 |

混合信号：税务主轴可留本任务；专项只作为背景时在缺口标明。C 端 054／055／014 只分流，不回改。

## 节点 1　文书定性

按表面效力由低到高并列，不选对用户有利的定性冒充唯一：

1. 风险提示、提示提醒、自查通知；
2. 纳税评估约谈、询问；
3. 发票协查、核查；
4. 税务检查通知、立案稽查；
5. 税务行政处罚事项告知书、听证告知；
6. 税务处理决定书、处罚决定书、保全或强制文书。

口头“来查账了”不得写成已立案。多份文书并列，不合成一份。

若主目标是自查补报且尚未立案：转介 `prepare-self-inspection`，本任务只保留阶段判断。
若已到处理或处罚决定且主目标是救济：转介先缴闸或复议／诉讼，不把本任务改写成复议申请。

## 节点 2　权限与调取

运行时核验征管法第五十四条至第五十七条、稽查程序规定后再落判断。

1. 检查人员是否出示税务检查证和检查通知书。两证不能从用户“他们来了”推定。
2. 调取账簿须有调取通知书和清单。以前年度规范上三个月内退还，当年三十日内退还：这是机关义务，不是扣留或改账的理由。退还期限须运行时核验现行文本。
3. 电子系统可提供与原始数据一致的复制件。不得建议格式化、卸载聊天或改系统时间。
4. 集贸市场及集中经营业户可以使用统一检查通知书：须核验是否属于该情形，不得普遍写成可以拒绝。

## 节点 3　期限摘录

| 条件 | 输出 | 禁止 |

## 节点 4　权利义务

- 依法出示后：接受检查、如实反映、提供资料，不得拒绝、隐瞒。
- 笔录：阅读后再签；有误要求当场更正。本任务不写统一口径，不替多人排练同一套说法。
- 陈述申辩权在告知后存在，但不在本包出稿。
- 阻挠检查可单独处罚：必须写入最强反方。

会计／税务师／律师分工只做红旗：会计清点只读备份；税务师核政策与进度；律师管程序、听证、刑行。本包不替代任何一方。

---

## 节点 5　升级

出现任一情形，停止普通评估并升级：

- 公安、监察介入或用户称刑事立案；
- 隐匿、擅自销毁账簿凭证，或要求指导这样做；
- 伪造、虚开、买票；
- 已过陈述申辩或听证申请期仍要“拖一拖别回”；
- 出口退税或海关缉私主导。

不定罪名。最小交接给刑事领域或对应原子。
