# 边界与路由

路由表中的原子 Skill 若未安装在当前包，输出 `unavailable`，不得由本任务代做。

## 正触发

已有检查类文书或依法出示的现场检查，需要阶段、权限和下一步，不要申辩终稿。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 尚未被查的预防对照 | `体检申报合规缺口` 或 C 端 054 |
| 大众应急清单 | C 端 055，只分流 |
| 发送版陈述申辩 | `准备检查陈述申辩` |
| 听证申请 | `准备税务听证材料` |
| 确定税额 | `测算调整滞纳金罚款` |
| 已到处理决定要争征税 | `评估纳税争议先缴或担保` |
| 刑事辩护 | 刑事领域 |

## 易混

检查通知已到、用户要专业判断阶段时正触发。用户只要“今天先别让他们进门”且拒绝出示证件核验时，只输出拒绝权条件，不写成可以关门一定没事。
