# 评估税务检查应对

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。引用税收征收管理法时使用 2015 年修正文本，不得采用 1992 年文本同号旧义。《增值税法》自 2026-01-01 施行；MCP 如仍标“尚未施行”，以有权机关公布的施行日为准，不得把已施行法律写成未生效。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌、电子税务局完整凭证或未脱敏客户名单。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的被查方立场下，形成“税务检查应对评估”：文书定性、检查权限与证件、所属期与资料范围、程序节点、原文期限、权利义务、刑事红旗和下一步转介。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：已收到或当面出示税务检查、稽查、协查、评估约谈类文书，用户需要判断阶段和下一步，而不是只要大众应急清单。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未被查，只要预防体检（054 或 `audit-filing-compliance`）；
- 只要发送版陈述申辩或听证申请；
- 只要确定税额或补税测算终稿；
- 公安、监察已介入且主目标是刑事辩护；
- 用户只要 C 端 055 八节应急清单且不要专业争点。

本任务不生成申辩终稿，不定税额，不保证不被查或“配合就没事”。

## 建立评估坐标

确认：使用者与授权；被查方立场；文书全称、文号、作出机关；送达或出示日期原文；检查所属期；资料范围；检查人员证件；账簿和电子数据现在在哪；是否已有告知书、笔录或调取清单。

同时掌握征纳双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同或交易文本定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 争点／请求／抗辩；`V#` 评估或稿件版本；`E#` 发送／送达／履行凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。
另用 `N#` 文书摘录；`H#` 分工与交接。
## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验检查权、出示证件、调账退还、陈述申辩、阻挠检查；`search_practiced` 补节点。不虚构案件系统。

工具不可用时继续事实、主体、程序文书状态和问题清单；法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [检查评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 专项分流和文书定性

先分流婚家、一般行政、海关缉私、刑事。再判断是提示提醒、纳税评估、协查、立案稽查还是已到告知／决定。收据不升级为处理决定。

### 2. 权限、证件与资料范围

无税务检查证且无检查通知书的，告知有权拒绝检查；已经依法出示的，必须接受检查、如实反映、提供资料。不得写成“可以关门一定没事”。

### 3. 期限只摘录原文

只抄通知、告知书或回证上的原文。原文没有期限：写未见，不推算。不得把检查通知送达日加减日历日当成听证截止日。

### 4. 权利、义务和禁止动作

陈述申辩、听证、调账退还、阅读笔录后签字分列。禁止改账、藏账、统一口径、拒检。

### 5. 升级红旗和下一步

刑事、虚开、隐匿、重大案件审理、告知书已到：转介对应原子或刑事领域。C 端 055 只作为大众应急清单分流，不替代本评估。

## 停止与安全

- `整体停止`：立场不明；用户坚持改账、藏账、拒检或保证没事；刑事主目标。
- `字段停止`：文书未见全文、送达不明、条号未核验。
- `目标停止`：主目标已变为申辩稿、听证申请或税额终稿。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
