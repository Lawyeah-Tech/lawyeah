# 边界与路由

## 正触发

不服尚未生效的税务行政判决或裁定，需要上诉范围和期限。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 重做一审 | `提起税务行政诉讼` 或 `应对税务行政诉讼` |
| 已生效再审 | 不在本任务展开 |
| 一般行政上诉 | 行政争议领域 |
| 刑事上诉 | 刑事领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

判决已过上诉期，客户要按未送达重做上诉。送达冲突只并行情景，不得伪造未送达。已生效不走本任务。
