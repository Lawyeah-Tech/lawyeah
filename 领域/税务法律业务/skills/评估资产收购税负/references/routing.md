# 边界与路由

## 正触发

资产包转让或剥离，需要增值税、土增、企税、契税接口。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 撰写买卖合同 | 审查起草本窗搁置 |
| 房地产开发销售争议 | 房地产领域 |
| 股权转让税负 | `评估股权转让税负` |
| 特殊重组 | `评估重组特殊性税务处理` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

客户把股权交易改叫“资产包”，要求按存货低税率测算。正触发：先定性标的，禁止为低税伪装交易，不写合同。
