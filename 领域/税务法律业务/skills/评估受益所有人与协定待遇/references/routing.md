# 边界与路由

## 正触发

对外付汇拟适用协定税率，需要受益所有人要件。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 保证协定适用 | 不实施 |
| 对外付汇扣缴手续 | `评估对外付汇扣缴` |
| 跨境交易整体 | 涉外领域 |
| 间接转让 | `评估受控外国企业与间接转让` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

香港控股公司无员工，客户要按百分之五股息税率出函。正触发：导管与受益所有人因素并列，不保证适用，付汇手续另项。
