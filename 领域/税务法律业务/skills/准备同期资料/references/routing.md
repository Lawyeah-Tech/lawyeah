# 边界与路由

## 正触发

达到准备门槛或被要求提供同期资料。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 保证免调整 | 不实施 |
| 特别纳税调整评估 | `评估转让定价调整` |
| 关联定价风险 | `评估关联交易定价税务风险` |
| 伪造可比 | 不实施 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

企业刚过门槛，顾问说“做一套模板就能挡调整”。正触发：列法定章节缺口，不保证免调整，不套用他案可比。
