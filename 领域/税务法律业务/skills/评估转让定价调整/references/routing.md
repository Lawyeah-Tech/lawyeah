# 边界与路由

## 正触发

已收到特别纳税调整或预约定价，需要方法争点和补税接口。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 关联定价风险（尚未调整） | `评估关联交易定价税务风险` |
| 同期资料正文 | `准备同期资料` |
| 一般反避税调查 | `应对反避税调查` |
| 先缴闸 | `评估纳税争议先缴或担保` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

初步调整约谈给出一个数字，客户要“按这个数认了并写避税不成立”。正触发：方法争点和金额接口分列，不定避税成立，口头数不是已核实金额。
