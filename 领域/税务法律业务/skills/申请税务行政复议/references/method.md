# 复议方法

本任务是**税务**行政复议，不是一般行政复议程序。一般行政行为转行政争议领域。

`search_law` 返回 1992 年《税收征收管理法》同号旧义、已失效《税务行政复议规则（暂行）》或已废止《增值税暂行条例》充当 2026-01-01 之后现行法时，记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 主目标是遗嘱、夫妻财产协议、继承分配、代际架构或婚家传承方案本身 | 婚家领域 |
| 主目标是非税务机关作出的一般行政行为复议或诉讼程序 | 行政争议领域 |
| 主目标是跨境交易、贸易管制、境外投资整体 | 涉外领域 |
| 主目标是薪酬、解除、社保等劳动权利本身 | 劳动领域 |
| 公安、监察已介入，或主目标是会见、取保、辩护、定罪 | 刑事领域 |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 海关代征、缉私主导 | 海关／涉外，不按国内税务检查清单放行 |

混合信号：税务主轴可留本任务；专项只作为背景时在缺口标明。C 端 054／055／014 只分流，不回改。

## 节点 1　受案和闸

1. 行为是否属于复议规则第十四条所列税务具体行政行为。不是：整案转出。
2. 第十四条第（一）项征税行为：必须完成先缴或担保闭合核验。未闭合：目标停止，转 `assess-collection-gate` 或 `prepare-tax-guarantee`，本包不出终稿。
3. 其他项：可复议。加处罚款须先缴罚款和加处罚款。
4. 已向人民法院起诉且已受理：复议不予受理，停止本包终稿。
5. 不得引用 2004 年暂行规则。

---

## 节点 2　复议机关

运行时核验 2018 修正文本：

- 对各级税务局：上一级税务局；
- 对计划单列市税务局：国家税务总局；
- 对税务所（分局）、稽查局：所属税务局；
- 共同行为、被撤销机关、加处罚款的特殊机关规则按第十九条核验。

国地税合并前的“向国税／地税／本级政府”旧口径不得直接写成现行规则。

---

## 节点 3　请求

每个 `APP#`：行为文号、请求类型、事实、理由、依据待核。补税请求与罚款请求分开。不得请求抽象撤销某税种立法。

附带审查：规则第十五条，针对规定不含规章。提出时点：申请时或决定作出前。

---

## 节点 4　期限

申请人可以在知道具体行政行为之日起六十日内提出。不可抗力或被申请人设障耽误的，扣除被耽误时间。缴清或担保确认与六十日起算的关系运行时核验第三十三条，不引用失效暂行规则。送达冲突并行情景。

---

## 节点 5　申请书和发送

法定事项：申请人、被申请人、复议请求、事实理由、日期。附件：决定书、送达证明、缴税或担保确认、身份与授权、证据目录。

不代提交。不保证五日审查后受理。复议期间具体行政行为不停止执行，除非依法停止；停止执行转介 `apply-stay-enforcement`。
