# 边界与路由

路由表中的原子 Skill 若未安装在当前包，输出 `unavailable`，不得由本任务代做。

## 正触发

已决定申请税务复议，且征税闸已闭合或不适用。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 一般行政行为复议程序 | 行政争议领域 |
| 先缴或担保是否必要 | `评估纳税争议先缴或担保` |
| 准备担保 | `准备纳税担保` |
| 税务行政诉讼 | `提起税务行政诉讼` |
| 谈判整改 | `谈判补税整改方案` |
| 一般处罚大众包 | C 端 014，税务不走 014 全案 |

## 易混

用户说“按普通复议写一份”。本包必须先做税务受案和第八十八条闸，不得改写成一般复议教程。
