# 边界与路由

## 正触发

收到协查、核查或风险提示，需要回函要点和资料目录。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 已立案稽查 | `评估税务检查应对` |
| 虚开定性 | `评估发票与虚开风险` |
| 统一口径 | 不实施 |
| 刑事询话 | 刑事领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

协查函要求三日内说明，销售要求全员统一说“货都送到了”。正触发：回函只写有来源的事实；统一口径整体停止。已立案则负触发。
