# 先缴闸方法

本文件是可执行判断节点。不得把处罚决定写成必须先缴税款才能告，也不得把征税行为写成可以直接起诉。

`search_law` 返回 1992 年《税收征收管理法》同号旧义、已失效《税务行政复议规则（暂行）》或已废止《增值税暂行条例》充当 2026-01-01 之后现行法时，记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## 节点 1　行为定性

运行时核验实施细则第一百条和复议规则第十四条。

| 表面主文 | 征税行为候选 | 其他行为候选 |
| --- | --- | --- |
| 确认纳税主体、税目、税率、计税依据、征收方式 | 是 | 否 |
| 征税款、加收滞纳金、代扣代收代征 | 是 | 否 |
| 罚款、没收、停止出口退税权 | 否 | 处罚 |
| 税收保全、强制执行 | 否 | 保全／强制 |
| 发票发售收缴代开 | 否 | 发票管理 |
| 纳税信用、阻止出境 | 否 | 其他 |

同一决定书既有补税滞纳金又有罚款：拆成两行。补税行走本闸；罚款行走选择复议或诉讼，不套先缴税款条件。

无法定性：`依据不足`，不打开任何救济终稿。

## 节点 2　法律闸

1. 核验征管法第八十八条第一款：纳税人、扣缴义务人、纳税担保人同税务机关在纳税上发生争议时，必须先依照纳税决定缴纳或解缴税款及滞纳金或者提供相应担保，然后可以依法申请行政复议；对复议决定不服的，可以起诉。
2. 核验第八十八条第二款：对处罚、强制执行、税收保全不服，可以申请复议，也可以起诉。
3. 核验复议规则第三十四条：第十四条第（一）项以外可选择；加处罚款须先缴罚款和加处罚款再复议。
4. 核验 2023 年行政复议法与上述条款的适用关系。不得凭记忆写成第八十八条已废止或已确认保留。冲突时记录冲突，字段停止。
5. 2004 年复议规则（暂行）第十四条不得写入 `L#`。

## 节点 3　缴清或担保闭合

若现有依据支持须先缴或担保：

1. `PAY#`：税种、所属期、税额、滞纳金、缴款书号、缴纳日、是否足额。口头“已经交了”不升级为已缴清。
2. `GTE#`：保证／抵押／质押、保证人资格、抵押物权属、是否提交作出机关、是否已确认。未确认 = 闸未打开。
3. 提供担保不得写成已经缴清。缴清不得写成担保已被接受。
4. 无力缴纳又无法提供有效担保：输出闸未打开、救济受限，以及担保原子转介。不得建议虚假担保或转移财产后再谈担保。

若行为是处罚／保全／强制：本节点标注“先缴税款闸不适用”，仍须核验加处罚款是否另有先缴罚款条件。

## 节点 4　打开哪一扇门

| 定性 | 缴清或担保 | 本任务结论 | 不得写成 |
| --- | --- | --- | --- |
| 征税行为 | 已闭合 | 复议入口可评估，起诉仍受复议前置约束 | 应直接起诉 |
| 征税行为 | 未闭合 | 复议申请终稿停止 | 先把申请交上去再说 |
| 处罚／保全／强制 | 不依赖税款闸 | 复议或诉讼均可评估 | 必须先复议 |
| 加处罚款 | 罚款和加处罚款未缴 | 复议停止 | 与征税先缴混用 |

---

## 节点 5　期限

复议申请期限与“缴清之日或担保确认之日”的起算关系必须运行时核验现行规则第三十二条、第三十三条，不引用 2004 年暂行规则。送达日冲突建并行情景。本任务不计算唯一截止日。
