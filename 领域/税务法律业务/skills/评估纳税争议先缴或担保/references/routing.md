# 边界与路由

路由表中的原子 Skill 若未安装在当前包，输出 `unavailable`，不得由本任务代做。

## 正触发

要对征税行为寻求救济，或处理决定与处罚决定缠在一起，需要先分清是否须先缴或担保。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 复议申请书 | `申请税务行政复议` |
| 准备担保材料 | `准备纳税担保` |
| 税务行政诉讼状 | `提起税务行政诉讼` |
| 只要检查阶段判断 | `评估税务检查应对` |
| 一般行政行为复议 | 行政争议领域 |

## 易混

“先别缴、直接告”在征税行为上不得放行。处罚决定“先别缴罚款就复议”须单独核验，不与税款闸混写。
