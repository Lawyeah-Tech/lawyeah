# 小规模与一般纳税人路径方法

本文件是可执行判断节点，不是栏目说明书。每个会改变争点、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然补税、必然免罚或唯一必得总额。

`search_law` 返回 1992 年《税收征收管理法》同号旧义、已失效《税务行政复议规则（暂行）》或已废止《增值税暂行条例》充当 2026-01-01 之后现行法时，记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |

| 主目标是非税务机关作出的一般行政行为复议或诉讼程序 | 行政争议领域 |

## 节点 1　资格事实

固定：当前资格、取得日期、是否辅导期、是否转登记而来。系统截图与证件冲突时并行，不选对用户有利的一种。

## 节点 2　标准

运行时核验《增值税法》及配套销售额标准、年应税销售额计算口径。核验失败则标准字段停止，不得写入记忆中的五百万元或其他数字充当 `L#`。

1. 连续12个月或四个季度的计算窗口按核验文本。
2. 应税销售额是否含免税、是否含纳税义务发生但未开票：待核，不得自行取低。
3. 超过标准是否必须登记：按现行强制规则，不得写成“可以一直选择小规模”。
4. 未超标准是否可选择登记：单独一行。

## 节点 3　税负与进项

本任务只给路径后果，不输出唯一税负结论。

- 一般纳税人：销项与进项接口，进项能否成立转 `assess-input-credit`。
- 小规模：征收率接口，不得抵扣进项的后果。
- 转登记或转回：存量进项转出、控制期间待核。

不得输出“转一般纳税人一定节税”或“留在小规模一定更安全”。

## 节点 4　禁止筹划动作

| 用户请求 | 处理 |
| --- | --- |
| 把销售额拆到关联公司以保持小规模 | 整体停止 |
| 拖延开票压低窗口销售额 | 整体停止 |
| 虚假转回小规模 | 整体停止 |
| 合法评估是否登记 | 继续 |

## 节点 5　转介

办理登记或变更：`plan-registration-change`。发票与虚开：`assess-invoice-risk`。总体税负：`assess-tax-matter`。


## 证据、金额与下一步

不能因机关控制材料而推定内容有利。禁止指导伪造、隐匿、虚开、拒检、改账或违法取证。未知金额不写零，不输出唯一必得总额或胜诉率。

若现有依据支持某一法律效果：写入对应 `Q#` 并回链来源。若现有依据不支持：明确排除该效果，不得改用更有利的相邻效果顶替。若依据不足：字段停止，并列待核事实，不选对用户有利的默认值。

发送申辩、听证、复议、起诉、登记、备案或对外文书，只写转介条件和最小交接。规则未核验的法律结论、期限或机关路径字段停止。C 端 054／055／014 只分流。
