# 边界与路由

## 正触发

销售额接近标准或拟登记／转回，管理方需要资格与进项后果。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 代办登记 | `规划税务登记变更` |
| 进项抵扣专项 | `评估进项抵扣能否成立` |
| 虚开评估 | `评估发票与虚开风险` |
| 保证税负更低 | 不实施 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

销售额刚过线，客户问“先别开票是不是还能当小规模”。正触发：核验强制登记，并停止任何延迟开票建议。
