# 边界与路由

## 正触发

复议或诉讼进行中，需要暂缓或停止税收执行。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 保证准许 | 不实施 |
| 先缴闸未开 | `评估纳税争议先缴或担保` |
| 强制执行应对 | `应对税收强制执行` |
| 一般行政停止执行 | 行政争议领域 |
| 拖延缴税 | 不实施 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

客户想用停止执行申请拖过拍卖日并把货转走。整体停止转移。申请只评估法定例外，不保证准许，不能代替先缴闸。
