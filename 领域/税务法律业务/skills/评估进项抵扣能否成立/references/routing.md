# 边界与路由

## 正触发

扣税凭证被否或拟抵扣，需要要件和转出时点。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 虚开定性 | `评估发票与虚开风险` |
| 异常失控发票 | `处理异常失控作废发票` |
| 小规模资格路径 | `评估小规模与一般纳税人路径` |
| 保证必然抵扣 | 不实施 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

财务称“有专票就能抵”。正触发：必须核验增值税法凭证种类和用途，集体福利或免税项目不得写成已抵扣成立。
