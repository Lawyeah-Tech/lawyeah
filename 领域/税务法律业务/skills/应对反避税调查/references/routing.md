# 边界与路由

## 正触发

一般反避税或受控交易调查已启动，需要实质抗辩和程序节点。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 日常检查评估 | `评估税务检查应对` |
| 转让定价调整 | `评估转让定价调整` |
| 刑事辩护 | 刑事领域 |
| 设计避税安排 | 不实施 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

稽查通知同时引用虚开和一般反避税。先分账：虚开走发票／刑行；反避税安排走本任务；不得用一套申辩覆盖全部。
