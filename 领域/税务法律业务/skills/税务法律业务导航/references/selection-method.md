# 原子 Skill 选择方法

当前安装包是。先识别可独立验收的成果，再在已安装的 P0 与 P1 中选一个主要 Skill。未列入能力地图的 P2 输出 `unavailable`。

## 一、先识别成果

先问这一次要拿到什么可独立验收的成果，而不是按增值税、企税或文书名称匹配。

P0 成果：税务事项总图；检查阶段与权限；先缴或担保闸；分项测算；证据案卷；陈述申辩；听证申请；税务复议申请；税务行政诉讼起诉包；补税整改谈判方案。

P1 成果按轨道：

- 入口：纳税主体与税种表；追征与处罚时效分表；主管与复议机关图；居民与纳税地点；扣缴义务。
- 日常合规：申报缺口体检；优惠要件；小规模／一般纳税人路径；登记变更；清税注销；逾期更正；个体户征收方式；合伙穿透；查账与核定。
- 交易结构：股权／资产／重组／不动产税负；关联定价风险；股权激励个税；解除补偿个税；赠与继承涉税；非货币出资；清算所得税。
- 发票抵扣：虚开边界；异常失控发票；进项抵扣；协查回函。
- 反避税：转让定价调整；同期资料；CFC 与间接转让；受益所有人；反避税调查。
- 检查应对：自查补报；评估约谈；调账调取；重大案件审理。
- 测算：滞纳金区间；退抵；土地增值税清算；出口退税风险额。
- 证据与强制：账簿数据保全；纳税担保；保全；强制执行；停止执行。
- 复议诉讼深化：机关应诉；规范性文件附带审查；税务上诉。
- 刑行交叉：逃税骗税虚开分流；首次逃税免刑条件；移送公安。
- 跨境税务专项：常设机构；对外付汇扣缴。

## 二、再确认上下文

只确认会改变入口的最小信息：

1. 单方立场与授权；
2. 是否已有检查、告知、处理、处罚、保全、强制或移送文书；
3. 争议对象是征税行为还是处罚／保全／强制；
4. 本次要识别、评估、测算、建卷、出稿、谈判还是程序文书；
5. 是否属于婚家传承方案、一般行政救济、跨境交易整体、劳动权利或刑事案件。

## 三、处理混合请求

1. 列出每项可独立验收的成果及对应入口；
2. 只问：`这次要先取得哪一项成果？`；
3. 回答前不指定主要 Skill，不暗示必须先评估再出稿；
4. 用户确认后只启动所选入口；等价评估、测算或证据可由用户或律师提供。

## 四、停止

立场冲突、专项主轴或未成争改合同时，说明边界并转出，不代做。信息不足时每轮只追问一个最能改变入口的问题。P2 能力不得由相邻 P0／P1 代做。
