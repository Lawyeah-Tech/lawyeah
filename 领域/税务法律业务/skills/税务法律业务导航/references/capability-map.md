# 当前能力地图

本包包含下表全部原子技能。未列入的 P2 必须输出 `unavailable`，不得由名称相近的 Skill 代做。

| 仍可与机关谈补税整改 | `谈判补税整改方案` | 让步表、底线、禁止承诺 | 保证免罚免刑；复议申请 |
