# 税务法律业务领域边界

当前安装包是。本表只说明归属。每次路由先核对 [当前能力地图](capability-map.md)；未安装入口输出 `unavailable`。

| 相邻 | 本包入口 | 转出 |
| --- | --- | --- |
| 婚家传承 | 赠与继承税负、申报或已成税务争议 | 遗嘱、财产协议、继承分配、代际架构本身 |
| 行政争议 | 税务处理实体、税务复议诉讼、先缴闸、保全强制、机关应诉、附带审查、税务上诉 | 一般行政复议诉讼程序和方法 |
| 涉外 | 跨境税务专项：居民、PE、对外扣缴、CFC／间接转让、受益所有人、出口退税风险 | 跨境交易、管制、投资整体 |
| 劳动 | 扣缴、解除补偿个税、股权激励税务后果 | 薪酬、解除、社保劳动权利 |
| 刑事 | 刑行分流、首次逃税免刑条件、移送交接 | 会见、取保、辩护、定罪 |
| 合同审查与起草 | 无 | 未成争只要改合同或出稿：本窗搁置，只说明不实施 |
| 公司治理／并购 | 股权转让、非货币出资、清算所得税、特殊重组税务 | 章程、交割、交易整体 |
| 房地产 | 不动产交易税负、土地增值税清算接口 | 开发销售、网签过户方案本身 |
| 破产 | 清税注销与清算所得税衔接 | 破产分配、债权申报 |
| C 端 054 | 专业申报体检或个体户征收评估，不降成预防对照 | 大众个体户预防体检 |
| C 端 055 | 专业检查评估或申辩，不降成应急清单 | 大众检查应急清单 |
| C 端 014 | 税务复议诉讼留本包 | 非税务一般处罚救济 |

一般经营夹带专项背景时，专项段只分流，不把婚家方案或一般复议方法写入本包结论。P2（信用修复、债务重组税务、兼营混合销售、红字规划、资本弱化、举报检查、计税评估鉴定、行政赔偿、信息交换）输出 `unavailable`。
