# 边界与路由

## 正触发

开发项目达到清算或核定条件，需要项目、扣除和预征差。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 唯一清算额 | 不实施 |
| 开发销售争议 | 房地产领域 |
| 普通不动产买卖 | `评估不动产交易税负` |
| 虚增扣除 | 不实施 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

销售未达线，客户要把相邻高成本项目并进来降低增值率。正触发：按清算单位规则拒绝随意合并，不定唯一额。
