# 边界与路由

## 正触发

多缴、减免、留抵或结算退税，需要条件和证据。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 出口退税风险 | `测算出口退税风险额` |
| 保证退还 | 不实施 |
| 优惠资格 | `评估税收优惠适用` |
| 税务行政赔偿 | 未安装则 `unavailable`／行政领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

留抵很大，客户要“这个月一定退到账”。正触发：对照条件与信用接口，不保证退还。函调异常的出口退税另项。
