# 评估追征期与处罚时效

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。引用税收征收管理法时使用 2015 年修正文本，不得采用 1992 年文本同号旧义。《增值税法》自 2026-01-01 施行；MCP 如仍标“尚未施行”，以有权机关公布的施行日为准，不得把已施行法律写成未生效。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌、电子税务局完整凭证或未脱敏客户名单。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成分类型期间表：机关责任、计算失误、偷抗骗等追征情景，以及五年处罚时效，各占一行，并标出未知起算日。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：单独委托核验能否追征、加收滞纳金或处罚，用户需要分类型期间而不是唯一截止日。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 要求输出唯一追征截止日或“过了三年就没事”；
- 主目标是偷税定性或刑事辩护；
- 只要总体评估或税额终稿；
- 一般行政处罚时效教学且非税务。

本任务禁止混算期间，不定偷税已经成立。

## 建立评估坐标

确认：授权；税种与所属期；申报或应申报日；检查发现日候选；处理决定和处罚决定是否已作；用户主张的定性（失误／偷税／抗税／骗税）。

同时掌握征纳双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 合同或交易文本定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 争点／请求／抗辩；`V#` 评估或稿件版本；`E#` 发送／送达／履行凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。
另用 `LIM#` 期间情景；`DISC#` 发现日候选。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验征管法第五十二条、第八十六条及实施细则追征条款现行文本；不得用 1992 年同号旧义。

工具不可用时继续事实、主体、程序文书状态和问题清单；法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [追征与处罚时效方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　分账对象

税款追征、滞纳金加收、行政处罚时效分列。处理决定与处罚决定各挂期间，不得合成“税务时效”。

### 节点 2　追征类型

机关责任、计算失误与偷税、抗税、骗税分情景。未核验定性前，不得选用无限期追征充当结论。

### 节点 3　处罚时效

五年处罚时效单独一行。发现日、连续状态和立案日并行待核，不得用追征三年去挡罚款或用五年去挡偷税追征。

### 节点 4　起算与送达

应缴日、申报日、检查通知日、处理决定送达日不得混为同一起算。口头“已过时效”不写入已核实。

### 节点 5　输出纪律

每种期间单独一行。禁止唯一截止日。偷税定性不足时该行判断为依据不足。

## 停止与安全

- `整体停止`：用户要求把偷税写成失误以缩短追征；伪造申报日。
- `字段停止`：第五十二条、第八十六条、发现日、定性未核验。
- `目标停止`：主目标变为偷税定罪或总体评估。
