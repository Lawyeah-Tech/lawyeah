# 边界与路由

## 正触发

单独委托核验追征、滞纳金或处罚是否仍可能发生，需要分类型期间表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 总体评估 | `评估税务事项` |
| 偷税或虚开定罪 | `分流逃税骗税虚开刑行交叉` 或刑事领域 |
| 滞纳金金额测算 | `测算滞纳金区间` |
| 补税罚款精算 | `测算调整滞纳金罚款` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

客户说“这事都五年了肯定罚不了也补不了”。正触发：分列处罚时效与追征，不输出唯一截止日。机关已主张偷税时，无限期追征只作条件情景，不定性已成立。
