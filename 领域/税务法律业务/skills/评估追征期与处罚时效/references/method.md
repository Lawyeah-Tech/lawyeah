# 追征与处罚时效方法

本文件是可执行判断节点，不是栏目说明书。每个会改变争点、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然补税、必然免罚或唯一必得总额。

`search_law` 返回 1992 年《税收征收管理法》同号旧义、已失效《税务行政复议规则（暂行）》或已废止《增值税暂行条例》充当 2026-01-01 之后现行法时，记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## 节点 1　对象分账

先建立三张期间表，互不替代：

1. `LIM-征` 税款追征；
2. `LIM-滞` 滞纳金是否仍可加收；
3. `LIM-罚` 行政处罚时效。

若只有检查人员口头说“过了三年”：记为 `S#`，不得写成期间已届满。

## 节点 2　追征情景

运行时核验征管法第五十二条及实施细则。核验失败则本节点全部字段停止。

| 情景 | 允许输出 | 禁止 |
| --- | --- | --- |
| 因税务机关责任未缴少缴 | 不得追征该笔税款的情景接口 | 据此宣称全部税种都过期 |
| 计算失误等非责任情形 | 三年追征情景，起算待核 | 写成绝对截止日 |
| 有偷税、抗税、骗税主张 | 无限期追征只作为条件情景 | 在定性成立前选定无限期为唯一结论 |
| 定性不明 | 三行并行，判断均为依据不足 | 选对用户有利的三年挡全部追征 |

构成少缴不等于当然偷税。偷税要件转总体评估或刑行分流，本任务只挂条件。

## 节点 3　处罚时效

运行时核验征管法第八十六条五年时效及行政处罚法衔接。

1. 若现有依据支持违法行为发生日或连续状态终了日：列入 `DISC#` 候选，不直接起算。
2. 若只有检查通知日：不得把它写成处罚时效起算日。
3. 追征仍可能进行时，罚款行仍可能因时效停止；两行同时保留。
4. 加处罚款不另造一套追征规则，除非核验出独立期间。

## 节点 4　起算日冲突

对每个 `LIM#` 列出全部日期候选：应缴日、申报日、缴款书日、检查立案日、告知日、决定送达日。

- 日期冲突：并行情景 + 字段停止。
- 文书未见全文：不推算届满日。
- 滞纳金是否随税款追征届满而停止：运行时核验，不得凭记忆写“税过了滞纳金也过了”。

## 节点 5　与相邻原子

| 条件 | 本任务 | 转介 |
| --- | --- | --- |
| 用户要唯一截止日 | 拒绝并保持分表 | 无 |
| 要认定偷税已成立 | 目标停止 | `assess-tax-matter` 或 `screen-criminal-overlap` |
| 要算滞纳金金额 | 只留起算接口 | `calculate-surcharge` |
| 要总体策略 | 负触发 | `assess-tax-matter` |

禁止把未知本金写成零后再宣称滞纳金为零。


## 证据、金额与下一步

不能因机关控制材料而推定内容有利。禁止指导伪造、隐匿、虚开、拒检、改账或违法取证。未知金额不写零，不输出唯一必得总额或胜诉率。

若现有依据支持某一法律效果：写入对应 `Q#` 并回链来源。若现有依据不支持：明确排除该效果，不得改用更有利的相邻效果顶替。若依据不足：字段停止，并列待核事实，不选对用户有利的默认值。

发送申辩、听证、复议、起诉、登记、备案或对外文书，只写转介条件和最小交接。规则未核验的法律结论、期限或机关路径字段停止。C 端 054／055／014 只分流。
