# 边界与路由

## 正触发

被指逃税，拟主张补缴后不予追究刑事责任。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 保证补了就没事 | 不实施 |
| 已刑事立案辩护 | 刑事领域 |
| 虚开或骗税 | `分流逃税骗税虚开刑行交叉` |
| 移送应对 | `应对税务案件移送公安机关` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

未见追缴通知时，先对照法释〔2024〕4 号第三条第二款是否支持不予追究刑事责任，不得写成“没通知就谈不上免刑”。客户要把罚款改成“自愿认罚”以求凑齐第一款：仍须分列通知形式、补缴凭证和五年记录，不保证免刑。虚开不得套用。公安约谈尚未立案：留在本任务核验立案时点，不整案转刑事。
