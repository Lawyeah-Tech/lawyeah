# 边界与路由

## 正触发

个人或企业居民、机构场所或经营地争议，需要税务专项识别。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 跨境交易或境外投资整体 | 涉外领域 |
| 常设机构专项 | `评估常设机构与境内所得` |
| 对外付汇扣缴 | `评估对外付汇扣缴` |
| 总体评估 | `评估税务事项` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

外籍高管一年多次入境，人力资源说“没满183天所以不用缴”。正触发：停留证据与住所并行核验，不满183天仍可能就境内所得纳税，不得写成零税负。
