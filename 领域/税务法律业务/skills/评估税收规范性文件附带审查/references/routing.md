# 边界与路由

## 正触发

认为税务处理依据不合法，拟在复议或诉讼中附带审查。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 抽象审查规章或法律 | 不实施 |
| 无具体行政行为 | 不实施 |
| 应诉说明 | `应对税务行政诉讼` |
| 一般行政文件 | 行政争议领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

客户要把财政部规章和税务总局公告一起“附带告无效”。规章部分停止；公告是否属于可审查规定须核验层级，不得抽象审查。
