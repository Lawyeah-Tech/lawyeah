# 边界与路由

## 正触发

高新、小微、加计扣除、减免备案或事后核查，需要要件与追回风险。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 代为备案 | 不实施 |
| 确定税额 | `测算调整滞纳金罚款` |
| 已立案检查 | `评估税务检查应对` |
| 总体评估 | `评估税务事项` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

高新复审在即，客户要“出一份一定能过的意见”。正触发：只做要件对照和资料缺口，不保证通过，不补造指标。
