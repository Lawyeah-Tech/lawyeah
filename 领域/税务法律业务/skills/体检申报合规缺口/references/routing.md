# 边界与路由

## 正触发

尚未被查，管理方要对照所属期申报、开票、收款找缺口。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 已进入检查 | `评估税务检查应对` |
| 评估约谈 | `应对纳税评估约谈` |
| 大众预防体检 | C 端 054，只分流 |
| 确定税额 | `测算调整滞纳金罚款` |
| 逾期更正专项 | `处理逾期申报与更正` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

风险提示刚到，财务要“先做个体检别让检查组来”。正触发：可做缺口表，但必须标明可能升级，不得保证体检完就没事。已收检查通知则负触发。
