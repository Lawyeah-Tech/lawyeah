# 边界与路由

## 正触发

发票异常、失控、作废或红冲争议，需要进项处理和证明责任。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 虚开定性 | `评估发票与虚开风险` |
| 协查回函 | `准备发票协查应对` |
| 进项一般要件 | `评估进项抵扣能否成立` |
| 虚假红冲 | 不实施 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

为调减销项要求对无退货发票全额红冲。整体停止虚假红冲。仅真实退货或开票有误才继续补救路径。
