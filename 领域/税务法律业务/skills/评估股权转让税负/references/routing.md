# 边界与路由

## 正触发

拟转或已转股权，转让方或受让方需要税种与计税基础。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 撰写股权协议 | 审查起草本窗搁置 |
| 公司治理与交割整体 | 公司治理／投资并购 |
| 间接转让 | `评估受控外国企业与间接转让` |
| 非货币出资 | `评估非货币性资产投资税务` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

股东一元转股给亲属，要律师写“正当理由一定成立”。正触发：并列价格情景和证据缺口，不保证正当理由，不写协议。
