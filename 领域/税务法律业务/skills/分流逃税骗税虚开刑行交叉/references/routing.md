# 边界与路由

## 正触发

出现逃税、骗税、虚开或隐匿账簿线索，需要行政与刑事边界。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 定罪或辩护会见 | 刑事领域 |
| 首次逃税免刑条件 | `评估首次逃税不予追究刑事责任条件` |
| 已决定移送 | `应对税务案件移送公安机关` |
| 虚开行政边界 | `评估发票与虚开风险` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

客户问“补八十万是不是就不会进公安”。本任务只标红旗和转介首次免刑评估，不定罪，不保证不移送。
