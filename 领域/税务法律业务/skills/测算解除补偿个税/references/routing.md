# 边界与路由

## 正触发

已有或拟支付解除补偿，需要免税额接口和与工资拆分。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 补偿合法性或 N／N+1 | 劳动领域 |
| 股权激励个税 | `评估股权激励个税` |
| 未知金额写成零 | 不实施 |
| 总体评估 | `评估税务事项` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

协议把年终奖和补偿写在一笔“打包补偿”里。正触发：必须拆分，缺社平工资不得写免税额为零或已确定。合法性转劳动。
