# 边界与路由

## 正触发

对外支付股息、利息、特许权或服务费，需要税目和扣缴报告。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 外汇与贸易监管整体 | 涉外领域 |
| 受益所有人实体 | `评估受益所有人与协定待遇` |
| 常设机构 | `评估常设机构与境内所得` |
| 境内工资扣缴 | `评估扣缴义务` |
| 保证免税 | 不实施 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

把股息改成咨询费以便付汇。整体停止改名规避。外汇手续转涉外，本任务只做税目、扣缴和税务报告接口。
