# 边界与路由

## 正触发

单独委托核验滞纳金起算、费率或停止加收。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未知本金写零 | 不实施 |
| 补税罚款完整精算 | `测算调整滞纳金罚款` |
| 特别纳税调整利息 | `评估转让定价调整` |
| 追征期 | `评估追征期与处罚时效` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

本金未定，客户要一份“滞纳金最多零”的函。整体停止写零。只列未知参数和公式接口。
