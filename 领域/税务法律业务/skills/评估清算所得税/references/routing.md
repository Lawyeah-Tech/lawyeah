# 边界与路由

## 正触发

公司清算或视同清算，需要剩余财产和股东所得税务接口。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 撰写清算分配方案 | 不实施 |
| 破产分配 | 破产领域 |
| 清税注销手续 | `规划清税注销` |
| 合伙穿透 | `评估合伙穿透课税` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

账面亏损，股东要求“清算所得写零好注销”。正触发：可变现价值未知不得写零，不写分配方案。破产分配转破产。
