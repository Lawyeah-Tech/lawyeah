# 边界与路由

## 正触发

为打开纳税争议复议或解除保全需要提供担保。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 保证机关确认 | 不实施 |
| 先缴闸判断 | `评估纳税争议先缴或担保` |
| 复议申请终稿 | `申请税务行政复议` |
| 民事担保合同出稿 | 审查起草本窗搁置 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

股东个人签字保证，尚未经税务机关确认，客户要直接交复议申请。本任务必须标明闸未打开，不保证确认。
