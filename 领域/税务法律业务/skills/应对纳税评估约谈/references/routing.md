# 边界与路由

## 正触发

评估约谈、询问或提示提醒，需要要点和升级红旗。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 立案稽查 | `评估税务检查应对` |
| 大众应急清单 | C 端 055，只分流 |
| 确定税额 | `测算调整滞纳金罚款` |
| 自查通知方案 | `准备自查补报方案` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

约谈通知与检查通知一起到。必须先看是否已检查：已检查走检查评估；仅评估约谈才走本任务，不得在约谈提纲里承认偷税。
