# 边界与路由

## 正触发

漏报、错报、更正申报或解除非正常，且尚未把检查案件伪装成更正。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 已立案检查 | `评估税务检查应对` |
| 自查通知未立案 | `准备自查补报方案` |
| 补税终值 | `测算调整滞纳金罚款` |
| 滞纳金精算 | `测算滞纳金区间` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

检查组已进场，财务问“我们连夜更正是不是就不算偷税”。负触发或停止：已检查不得包装成普通更正。仅内部发现差错才正触发。
