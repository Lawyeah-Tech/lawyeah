# 边界与路由

## 正触发

出口退税被疑骗税或函调异常，需要金额区间和刑行分流。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 海关缉私主导 | 海关／涉外／刑事 |
| 普通留抵退税 | `测算退税与抵缴` |
| 认定骗税成立 | 不实施 |
| 刑事辩护 | 刑事领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

函调未回，客户要律师代境外供应商写确认函。禁止代写虚假回函。海关缉私已接手则本任务停止实体。
