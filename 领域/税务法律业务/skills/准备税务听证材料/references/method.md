# 听证方法

逾期不提出视为放弃听证权利。本任务把期限当作不可逆闸。

`search_law` 返回 1992 年《税收征收管理法》同号旧义、已失效《税务行政复议规则（暂行）》或已废止《增值税暂行条例》充当 2026-01-01 之后现行法时，记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 主目标是遗嘱、夫妻财产协议、继承分配、代际架构或婚家传承方案本身 | 婚家领域 |
| 主目标是非税务机关作出的一般行政行为复议或诉讼程序 | 行政争议领域 |
| 主目标是跨境交易、贸易管制、境外投资整体 | 涉外领域 |
| 主目标是薪酬、解除、社保等劳动权利本身 | 劳动领域 |
| 公安、监察已介入，或主目标是会见、取保、辩护、定罪 | 刑事领域 |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 海关代征、缉私主导 | 海关／涉外，不按国内税务检查清单放行 |

混合信号：税务主轴可留本任务；专项只作为背景时在缺口标明。C 端 054／055／014 只分流，不回改。

若主目标是普通申辩：负触发，转 `prepare-statement`。

## 节点 1　听证范围

运行时核验：

- 《行政处罚法》关于听证的情形；
- 《税务行政处罚听证程序实施办法（试行）》适用范围；
- 稽查程序规定第四十一条。

个人与单位罚款门槛、是否仍适用 1996 年办法中的数额，一律待核，不得把记忆中的“个人二千、单位一万”写成已核验现行标准。不在听证范围：说明现有依据不支持听证申请作为权利，可转申辩。

---

## 节点 2　申请期限闸

1. 起算事件：告知书送达。检查通知书送达不是起算。
2. 申请方式：书面。口头要求不写成已申请。
3. 天数：运行时核验《行政处罚法》告知后五日提出的一般规则，以及《税务行政处罚听证程序实施办法（试行）》第四条三日规则。冲突时并列情景，字段停止，不得选对用户更宽或更严的一天充作唯一截止日。
4. 逾期：可能视为放弃。本任务可说明仍可陈述申辩或事后救济，但不得把逾期申请写成仍有效。
5. 日期冲突：并行情景 + 字段停止。

---

## 节点 3　申请书要素

申请人、告知书文号、要求听证的明确意思、联系人、日期、签章。代理人须授权。向作出告知的税务机关提出。

---

## 节点 4　提纲

按拟处罚事实逐项：承认／否认、证据、法律、程序、量罚。拟向检查人员提出的问题单列。不得排练虚假口径。

---

## 节点 5　衔接

听证组织期间不计入部分办案期限（稽查程序规定第四十七条）：只作说明，不写成可以借听证无限拖延。听证后仍可能作出处罚。对处罚不服走复议或诉讼，不在本包出那些文书。
