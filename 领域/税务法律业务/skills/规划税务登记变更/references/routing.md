# 边界与路由

## 正触发

地址、名称、扣缴或跨区经营需要税务登记变更。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 代为提交 | 不实施 |
| 清税注销 | `规划清税注销` |
| 股权架构或章程 | 公司治理 |
| 主管机关争议 | `梳理主管税务机关与管辖` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

公司搬迁尚未办工商，财务要先改发票地址。正触发：分列工商与税务时序和票面名称风险，不代提交，不建议虚假住所。
