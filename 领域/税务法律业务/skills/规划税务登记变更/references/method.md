# 税务登记变更方法

本文件是可执行判断节点，不是栏目说明书。每个会改变争点、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然补税、必然免罚或唯一必得总额。

`search_law` 返回 1992 年《税收征收管理法》同号旧义、已失效《税务行政复议规则（暂行）》或已废止《增值税暂行条例》充当 2026-01-01 之后现行法时，记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 主目标是遗嘱、夫妻财产协议、继承分配、代际架构或婚家传承方案本身 | 婚家领域 |
| 主目标是非税务机关作出的一般行政行为复议或诉讼程序 | 行政争议领域 |
| 主目标是跨境交易、贸易管制、境外投资整体 | 涉外领域 |
| 主目标是薪酬、解除、社保等劳动权利本身 | 劳动领域 |
| 公安、监察已介入，或主目标是会见、取保、辩护、定罪 | 刑事领域 |
| 尚未成争，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 海关代征、缉私主导 | 海关／涉外，不按国内税务检查清单放行 |

混合信号：税务主轴可留本任务；专项只作为背景时在缺口标明。C 端 054／055／014 只分流，不回改。

## 节点 1　事项识别

只处理税务登记和扣缴登记、跨区报验事项。公司增资、股权转让协议、治理安排转公司治理或投资并购。

每个 `CHG#` 写：现状、拟变更为、法律依据待核、是否已在市场监管部门完成。

## 节点 2　期限

运行时核验征管法第十六条及实施细则办理变更的日数。核验失败则期限字段停止，不得写死“30日”或其他记忆数字充当结论。

工商已变税务未变：标逾期风险，仍不代提交。

## 节点 3　材料

列法定材料与控制方。住所证明、租赁合同真伪由用户负责。本任务不得建议使用挂靠地址或虚假房东。

## 节点 4　申报与发票衔接

1. 名称变更前后发票开具名称。
2. 地址变更后主管机关是否可能调整：转介 `map-tax-authority`，本任务不选定新机关。
3. 扣缴义务登记增减与工资发放所属期。
4. 跨区经营报验与预缴。

## 节点 5　转介

| 条件 | 转介 |
| --- | --- |
| 要清税注销 | `plan-tax-deregistration` |
| 主管机关争议 | `map-tax-authority` |
| 股权架构方案 | 公司治理／投资并购 |
| 用户要本窗提交 | 目标停止，不实施 |

不得把变更规划写成已经办结。


## 证据、金额与下一步

不能因机关控制材料而推定内容有利。禁止指导伪造、隐匿、虚开、拒检、改账或违法取证。未知金额不写零，不输出唯一必得总额或胜诉率。

若现有依据支持某一法律效果：写入对应 `Q#` 并回链来源。若现有依据不支持：明确排除该效果，不得改用更有利的相邻效果顶替。若依据不足：字段停止，并列待核事实，不选对用户有利的默认值。

发送申辩、听证、复议、起诉、登记、备案或对外文书，只写转介条件和最小交接。规则未核验的法律结论、期限或机关路径字段停止。C 端 054／055／014 只分流。
