# 边界与路由

## 正触发

境外架构利润不分配，或间接转让中国权益，需要税务专项。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 跨境交易或境外投资整体 | 涉外领域 |
| 受益所有人 | `评估受益所有人与协定待遇` |
| 常设机构 | `评估常设机构与境内所得` |
| 设计避税架构 | 不实施 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

境外控股公司转让，客户称“境外交易中国管不着”。正触发：间接转让报告与合理商业目的并列待核，不设计新架构，整体跨境方案转涉外。
