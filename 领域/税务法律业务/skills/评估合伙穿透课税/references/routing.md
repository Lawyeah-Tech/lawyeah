# 边界与路由

## 正触发

合伙企业或契约型安排谁纳税、所得性质或分配时点不明。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 退伙或合伙协议起草 | 审查起草本窗搁置／民事／公司 |
| 公司居民身份 | `评估居民身份与纳税地点` |
| 清算所得税 | `评估清算所得税` |
| 精算税额 | `测算调整滞纳金罚款` |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

有限合伙把股权转让收益留在账上不分配，合伙人说“没拿到钱就没税”。正触发：分配时点与所得性质并列待核，不得写成零税。不写退伙协议。
