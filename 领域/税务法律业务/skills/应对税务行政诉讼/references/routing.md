# 边界与路由

## 正触发

税务机关或第三人应诉税务行政诉讼。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 纳税人起诉 | `提起税务行政诉讼` |
| 重做处理决定 | 不实施 |
| 规范性文件范围 | `评估税收规范性文件附带审查` |
| 上诉 | `提起税务行政上诉` |
| 一般行政应诉 | 行政争议领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 遗嘱、夫妻财产、继承分配、代际架构 | 婚家领域 |
| 非税务一般行政行为救济 | 行政争议领域 |
| 跨境交易、管制、境外投资整体 | 涉外领域 |
| 劳动报酬、解除、工伤、社保权利 | 劳动领域 |
| 会见、取保、辩护、定罪 | 刑事领域 |

## 易混

应诉机关想补一份新的处理决定替换原决定再交法院。本任务停止重做决定，只评估原行为举证和程序。
