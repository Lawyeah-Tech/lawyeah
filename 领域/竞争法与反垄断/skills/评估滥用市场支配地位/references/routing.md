# 边界与路由

## 正触发

不公平价格、拒绝交易、限定交易、搭售或差别待遇被质疑。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 相关市场终局界定 | 界定相关市场 |
| 拒绝或搭售专项 | 评估拒绝交易限定交易或搭售 |
| 价格或差别待遇专项 | 评估不公平价格与差别待遇 |
| 知识产权权属或侵权比对 | 知识产权 |
| 消费者三倍赔偿主路径 | 消保或 C 端 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| SEP 或拒绝许可主轴 | 评估知识产权行使的竞争法面向 |
| 必要设施深挖 | 评估拒绝交易限定交易或搭售 |

一般商业做法夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。知识产权侵权主轴、投并购交易文件只分流。

## 易混

对方是不是垄断企业在乱收费是正触发。先把相关市场做成鉴定意见是市场界定原子。
