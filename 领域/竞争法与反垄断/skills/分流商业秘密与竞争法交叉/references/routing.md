# 边界与路由

## 正触发

同时出现保密措施和竞争秩序主张。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 商业秘密构成要件终局 | 知识产权 |
| 无秘密点的仿冒或诋毁 | 相应不正当竞争专项 |
| 劳动保密处分 | 劳动 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 秘密点鉴定 | 知识产权 |
| 竞业限制劳动争议 | 劳动 |

一般商业做法夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。知识产权侵权主轴、投并购交易文件只分流。

## 易混

既说泄密又说仿冒是正触发。请直接认定构成商业秘密是负触发。
