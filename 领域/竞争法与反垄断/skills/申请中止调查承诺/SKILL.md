# 申请中止调查承诺

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 2008 年申报门槛或 2007 年反垄断法条号当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的被调查人立场下，形成“中止调查承诺申请包”：承诺措施、履行监督、恢复调查风险。

`depends-on` 为空。接受用户或律师提供的等价谈判方案和调查文书。

## 工作边界

正触发：已决定走承诺程序，需正式申请。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 谈判方案尚未谈拢（转 P0 谈判中止调查承诺或和解方案）；
- 保证中止调查；
- 宽恕申请（转 申请垄断协议宽恕）；
- 已签字民事和解（转 起草竞争争议和解协议）；

本任务不保证中止，不替代谈判原子，不代提交。

## 建立评估坐标

确认：被调查人；案号；已谈措施；是否排除承诺适用的严重情形。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` `D#` `A#` `R#` `C#` `L#` `I#` `G#` `Q#` `COM#` 措施；`V#` `E#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

`search_law` 核验反垄断法中止调查、恢复调查和不得承诺的情形。工具不可用时继续措施清单；中止效果字段停止。

工具不可用时继续事实、主体、程序文书状态和问题清单；法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [申请方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　适用闸

已决定申请。严重违法可能不得承诺，须核验。

### 节点 2　措施可核验

停止行为、开放、整改须可监督。

### 节点 3　申请书草稿

事实承认边界。不得写成已认定违法。

### 节点 4　监督与恢复

不履行将恢复调查。

### 节点 5　与谈判民事交叉

谈判方案另项。民事和解另项。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或做法无法建立；用户坚持伪造、隐匿、威胁、违法取证或指导规避执法。
- `字段停止`：法域、日期、文书送达、申报标准、动态规则未核验。
- `目标停止`：主目标已变为相邻原子或相邻领域的终稿。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
