# 准备向反垄断执法机构举报

## 任务目标

在明确、无利益冲突的举报人立场下，形成发送前行政举报材料：被举报行为轨道、事实回链、管辖建议、保密请求、证据目录和不得发送项。

`depends-on` 为空。接受等价评估和证据清单。

## 工作边界

正触发：拟向市场监管总局或依法承担反垄断/反不正当竞争执法职责的省级或地方市场监督管理部门举报，主成果是行政举报而非民事起诉。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要民事起诉状（转 `file-civil-claim`）；
- 只要停止侵权律师函（未安装则 `unavailable`）；
- 普通消费者只要消保投诉；
- 用户要求保证立案或指示伪造证据。

文稿状态只用 `草案`、`发送前复核`、`不得发送`。一律视为未发送。

## 建立举报坐标

确认：举报人资格与授权；被举报经营者；行为时间与持续；已知主管机关；是否请求保密；是否同时准备民事诉讼。

## 来源和判断状态

编号：`S#` `D#` `A#` `R#` `C#` `L#` `I#` `G#` `Q#` `V#` `E#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 2007 年反垄断法条号或误标未施行的 2025 年反不正当竞争法当作障碍而拒绝执行。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

`search_law` 核验举报受理、管辖和保密；`search_template` 只借举报信栏目。机关名称和授权范围未核验则管辖字段停止。

## 五个判断节点

以 [举报方法](references/method.md) 为准。

### 1. 资格与轨道

举报人与事实的关系、行为属于垄断协议/滥用/集中/不正当竞争哪一条轨道。消费者纯消保负触发。

### 2. 事实回链

每个行为主张必须回链到日期、主体、原文或数据。传闻标 `S#`，不得写成已核实。

### 3. 管辖建议

总局与省级授权分列待核。跨省或全国重大影响标红旗，不选定唯一机关冒充已指定。

### 4. 发送前稿与保密

锁定 `V#`。可请求对举报人信息保密。不得诬告或把推测写成“已构成垄断”。

### 5. 证据目录与并行民事

证据列原件控制方和合法性。行政举报不阻断民事，但不得承诺“先行政必赢民事”。

## 停止与安全

- `整体停止`：立场不明；用户坚持诬告、伪造或违法取证。
- `字段停止`：管辖、条号、保密规则未核验。
- `目标停止`：主目标变为起诉状。
