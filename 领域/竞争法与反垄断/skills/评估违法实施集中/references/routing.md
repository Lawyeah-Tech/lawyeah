# 边界与路由

## 正触发

交割前整合、委派高管、交换敏感信息，或已交割未申报或未获批准。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 判断是否必须申报且无实施行为 | 评估经营者集中申报义务 |
| 准备自我报告材料 | 准备未依法申报自我报告 |
| 指导完成交割 | 整体停止；交易执行归投资并购 |
| 附加限制性条件履行 | 执行限制性条件监督报告 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 交割清单、付款、工商变更操作 | 投资并购 |

一般商业做法夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。知识产权侵权主轴、投并购交易文件只分流。

## 易混

已签 SPA 但未交割、已派驻财务负责人是正触发。用户要怎么把交割做完是负触发并停止。
