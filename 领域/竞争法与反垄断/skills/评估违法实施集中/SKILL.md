# 评估违法实施集中

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 2008 年申报门槛或 2007 年反垄断法条号当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“违法实施集中识别包”：实施行为识别、恢复原状风险、处罚接口、停止项和下一步。

`depends-on` 为空。接受用户或律师提供的等价申报义务判断、交易时间线和整合记录。

## 工作边界

正触发：交割前已整合、委派高管、交换敏感信息，或已交割但未依法申报或未获批准。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 指导如何补做交割或把已整合伪装成未实施（整体停止）；
- 只要自我报告材料包（转 准备未依法申报自我报告）；
- 还在判断是否必须申报且无实施行为（转 评估经营者集中申报义务）；
- 只要交易对价或交割清单（投资并购）；

本任务不指导补做交割，不生成自我报告终稿，不定罪，不输出唯一罚款。

## 建立评估坐标

确认：使用者与授权；单方立场；交易步骤与签署或交割日；申报或批准状态；已发生的人事、信息、业务、资产动作。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` `D#` `A#` `R#` `C#` `L#` `I#` `G#` `Q#` `ACT#` 实施行为；`V#` `E#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

`search_law` 核验反垄断法关于禁止实施集中、未申报调查和罚款档位（2022 修正，条号运行时核验）；`search_practiced` 补抢跑识别。工具不可用时继续行为时间线；处罚法律效果字段停止。

工具不可用时继续事实、主体、程序文书状态和问题清单；法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　申报与批准状态

固定是否构成集中、是否达到标准或被要求申报、是否已申报、是否已批准。口头法务说没问题不写成已批准。

### 节点 2　实施行为识别

交割、资产或客户转移、关键人员委派、采购或定价整合、超出尽调必要的敏感信息交换分列 ACT#。

### 节点 3　恢复原状与停止项

已实施的，列出可逆动作和必须立即停止的动作。不指导继续完成交割。

### 节点 4　处罚与调查接口

只建罚款、恢复原状、限制再次申报的接口，不输出唯一必罚总额。

### 节点 5　自我报告与下一步

是否值得转入自我报告专项。禁止伪造时间线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或做法无法建立；用户坚持伪造、隐匿、威胁、违法取证或指导规避执法。
- `字段停止`：法域、日期、文书送达、申报标准、动态规则未核验。
- `目标停止`：主目标已变为相邻原子或相邻领域的终稿。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
