# 提起竞争法民事诉讼

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的原告立场下，形成可复核、不代提交的“竞争法民事起诉包”：起诉状草稿、分项诉讼请求、管辖连结点、证据目录和保全红旗。

`depends-on` 为空。

## 工作边界

正触发：已决定向人民法院提起垄断或不正当竞争民事诉讼。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要行政举报（转 `prepare-samr-complaint`）；
- 只要知识产权权属或侵权比对终局（知识产权）；
- 已收到起诉状、用户实为被告；
- 普通消费者只要消保三倍赔偿主路径；
- 劳动争议。

C 端网上立案只分流：本技能仍负责专业请求判断，不降成大众立案包。

本任务不代提交，不保证受理或胜诉，不写保全申请终稿。

## 建立起诉坐标

确认：原告适格；被告；行为轨道；拟请求；法域；是否已有行政认定；管辖连结点；仲裁条款是否出现。

已有受理凭证或案号时，停止生成起诉入口材料。

## 来源和判断状态

编号：`S#` `D#` `A#` `R#` `C#` `L#` `I#` `G#` `Q#` `P#` 诉讼请求；`J#` 管辖；`V#` `E#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

`search_law` 核验起诉条件、垄断民事解释管辖与举证责任、反不正当竞争法请求权；`search_template` 只借起诉状栏目。工具不可用时继续事实和证据目录；请求法律结论、管辖选定、期限字段停止。

## 五个判断节点

以 [起诉方法](references/method.md) 为准。

### 1. 分流、起诉决定和仲裁闸

IP 权属、消保、劳动整案转出。仲裁条款出现时不得直接写应起诉。

### 2. 适格与分项请求

停止侵害、赔偿、消除影响分列。禁止合成“竞争法权益”。行政认定不是自动赔偿额。

### 3. 管辖连结点

知识产权法院、中院集中管辖、侵权行为地、被告住所地分列待核，材料不足不选唯一法院。

### 4. 证据目录与保全红旗

按待证事实绑定请求。保全只做红旗。

### 5. 起诉状草稿与提交核验

只交付草案。不代提交。

## 停止与安全

- `整体停止`：立场冲突；伪造；违法取证。
- `字段停止`：管辖、仲裁排除、条号未核验。
- `目标停止`：主目标变为举报或应诉。
