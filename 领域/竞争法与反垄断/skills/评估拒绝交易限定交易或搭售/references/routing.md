# 边界与路由

## 正触发

必要设施、二选一、捆绑被质疑。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 强制缔约 | 不实施 |
| 滥用总览 | 评估滥用市场支配地位 |
| 平台规则总览 | 评估平台竞争限制 |
| 许可合同权利本身 | 知识产权 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| SEP 拒绝许可 | 评估知识产权行使的竞争法面向 |

一般商业做法夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。知识产权侵权主轴、投并购交易文件只分流。
