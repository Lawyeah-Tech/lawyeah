# 评估拒绝交易、限定交易或搭售

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 2008 年申报门槛或 2007 年反垄断法条号当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“拒绝交易、限定交易或搭售评估包”：正当理由、交易必要性、替代供应。

`depends-on` 为空。接受用户提供的交易条件、替代供应商和设施描述。

## 工作边界

正触发：必要设施、二选一、捆绑被质疑。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 强制缔约或直接下命令交易；
- 滥用总览且行为未聚焦（转 评估滥用市场支配地位）；
- 平台二选一总览（转 评估平台竞争限制）；
- 知识产权许可权利谈判本身（知识产权；竞争面向转 ip-antitrust-interface）；

本任务不强制缔约，不保证必获供应。

## 建立评估坐标

确认：被指支配或相对优势方；被拒或被搭售方；设施或商品；替代供应；正当理由主张。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` `D#` `A#` `R#` `C#` `L#` `I#` `G#` `Q#` `V#` `E#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

`search_law` 核验拒绝交易、限定交易、搭售条款和正当理由。工具不可用时继续替代供应事实；滥用成立字段停止。

工具不可用时继续事实、主体、程序文书状态和问题清单；法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　市场与支配接口

无市场最低事实不得写拒绝交易当然成立。

### 节点 2　拒绝或限定

中断既有交易与拒绝新开交易分列。二选一实质限定单列。

### 节点 3　搭售

独立商品、强制、正当理由。

### 节点 4　替代供应与必要性

存在可行替代则必要设施难以成立。

### 节点 5　救济接口

停止侵害、恢复交易方向。不强制写必须签约。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或做法无法建立；用户坚持伪造、隐匿、威胁、违法取证或指导规避执法。
- `字段停止`：法域、日期、文书送达、申报标准、动态规则未核验。
- `目标停止`：主目标已变为相邻原子或相邻领域的终稿。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
