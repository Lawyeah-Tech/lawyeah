# 边界与路由

## 正触发

新设或改建合营，争是否取得控制权或决定性影响，以及营业额如何归属。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 起草合资合同或章程 | 审查起草领域（本窗搁置） |
| 选定是否必须申报 | 评估经营者集中申报义务 |
| 单独核验控制权与营业额口径且无合营争点 | 评估控制权与营业额 |
| 母公司协同定价或划分市场 | 评估垄断协议 |
| 对价与交割 | 投资并购 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 合资合同、SHA、章程出稿 | 审查起草搁置 |
| 交易结构与交割 | 投资并购 |

一般商业做法夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。知识产权侵权主轴、投并购交易文件只分流。

## 易混

50/50 合营是否申报是正触发。用户要一份可签署合资合同是负触发。
