# 边界与路由

## 正触发

拟实施或已接近交割的控制权变化，单方需要判断中国大陆是否必须事先申报以及批准前能否实施。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 交易结构、尽调、对价、交割清单 | 投资并购领域 |
| 申报表和附件 | `准备经营者集中申报` |
| 已违法实施，要自我报告 | `准备未依法申报自我报告`（未安装则 `unavailable`） |
| 境外当地申报 | 涉外领域 |
| 竞争法总图而非申报义务 | `评估竞争法事项` |
| 改 SPA 文本且无申报判断 | 审查起草（本窗搁置） |

## 易混

“帮我看看这个收购要不要报”正触发。“把申报表填好”负触发。“这个收购怎么定价和交割”转投资并购。
