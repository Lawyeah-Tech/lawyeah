# 评估经营者集中申报义务

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 2008 年申报门槛或商务部旧申报办法当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“经营者集中申报义务判断包”：交易步骤是否构成集中、控制权与营业额情景、2024 申报标准是否可能达到、未达标准被要求申报红旗、批准前实施禁止、申报义务人建议和下一步。

`depends-on` 为空。接受用户、律师、财务或其他来源的等价股权结构、营业额和交易文件。

## 工作边界

正触发：拟实施或已接近交割的合并、股权或资产取得、合营或其他控制权变化，用户需要判断中国大陆是否必须事先申报以及交割是否被禁止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要交易结构、对价、交割清单或投后治理（投资并购）；
- 只要申报表终稿或附件清单（转 `prepare-merger-filing`）；
- 只要境外当地申报（涉外）；
- 尚未形成竞争法任务，只要改 SPA/SHA（审查起草搁置）；
- 主目标是垄断协议、滥用或不正当竞争总图。

本任务不生成申报表，不设计交易对价，不批准交割。

## 建立评估坐标

确认：使用者与授权；单方立场；参与集中的各方及所属集团；交易步骤和时间表；上一会计年度营业额材料；已发生的整合或信息交换；法域；是否已向市场监管总局递交材料。

同时掌握买卖双方秘密且未获双方豁免时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关文书；`C#` 交易文件条款；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 义务假设；`V#` 评估版本；`E#` 申报或交割凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验反垄断法集中定义、2024 申报标准第三条和第四条、经营者集中审查规定营业额口径；`search_practiced` 补控制权与抢跑识别。

`search_law` 对门槛和实施禁止为 required。返回 2008 年 100 亿/20 亿/4 亿时记为噪声。第三条现行数额未返回则门槛字段停止。

工具不可用时继续控制权事实和问题清单；能否交割、是否必须申报字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 交易步骤是否构成集中

合并、取得股权或资产、通过合同或其他方式取得控制权或决定性影响分别检验。新设合营看共同控制。不构成集中则申报义务主位不成立，仍检查已发生协同是否落入垄断协议轨道。

### 2. 控制权与营业额口径

集团内直接和间接控制一并计入。目标仅部分营业被取得时，只计入该部分。金融业走专门口径接口。口头估算不得写成已核实营业额。

### 3. 2024 申报标准与第四条

并列全球加境内双经营者、境内合计加双经营者两条。禁止回填 2008 数额。未达标准保留被要求申报红旗。任一门槛未核验则“无须申报”不得成立。

### 4. 实施禁止与抢跑红旗

达到标准或被要求申报：批准前不得实施。人事委派、业务整合、敏感信息交换、提前付款交割分列红旗，不在本任务做抢跑处罚终局。

### 5. 申报义务人与下一步

合并由各方申报；其他情形原则上由取得控制权的经营者申报，其他方配合。下一步只转介申报稿、自我报告或交易领域，不把本包改写成申报表。

## 停止与安全

- `整体停止`：立场或授权不明；双方冲突未解；用户坚持隐瞒控制关系、伪造营业额或在禁止期内交割。
- `字段停止`：会计年度、营业额口径、2024 第三条数额、金融业算法未核验。
- `目标停止`：主目标已变为申报表、交易文件或交割清单。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
