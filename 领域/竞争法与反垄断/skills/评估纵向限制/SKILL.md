# 评估纵向限制

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 2008 年申报门槛或 2007 年反垄断法条号当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的品牌方或经销商立场下，形成“纵向限制评估包”：第十八条路径、排除限制竞争效果、安全港接口。

`depends-on` 为空。接受用户或律师提供的等价经销政策、协议文本和市场份额材料。

## 工作边界

正触发：转售价格、独家、最惠或地域限制被质疑，需要竞争法判断。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 重写经销合同正文或出可签署文本（审查起草搁置）；
- 横向竞争者协议为主（转 评估垄断协议）；
- 整套经销体系条款表（转 审查经销体系竞争限制）；
- 平台二选一主轴（转 评估平台竞争限制）；

本任务不重写经销合同正文，不写成必然合法或必然违法。

## 建立评估坐标

确认：品牌方或经销商立场；渠道层级；被指限制类型；协议版本；市场份额材料；是否已有投诉或调查。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` `D#` `A#` `R#` `C#` 经销条款；`L#` `I#` `G#` `Q#` `V#` `E#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

`search_law` 核验反垄断法第十八条及第二三款、纵向垄断协议规定和安全港份额条件（份额数字必须运行时核验，不得凭记忆）。工具不可用时继续条款识别；合法或违法结论字段停止。

工具不可用时继续事实、主体、程序文书状态和问题清单；法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　限制类型识别

转售价格固定或限定最低价、独家、最惠客户、地域或客户限制分列，不得合成纵向风险一笔。

### 节点 2　第十八条路径

先问是否属于禁止的纵向协议，再问第二三款抗辩和安全港。不得跳过效果分析直接写当然违法，除非现行规则核验支持该类型的特殊对待。

### 节点 3　排除限制竞争效果

品牌内竞争、品牌间竞争、抗衡买方力量、新进入。数据不足则效果字段停止。

### 节点 4　安全港与豁免接口

份额条件未核验不得主张已进入安全港。转介豁免专项可深挖。

### 节点 5　停止项与合同接口

须停、须改、可保留只出竞争法判断，不出可签署合同。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或做法无法建立；用户坚持伪造、隐匿、威胁、违法取证或指导规避执法。
- `字段停止`：法域、日期、文书送达、申报标准、动态规则未核验。
- `目标停止`：主目标已变为相邻原子或相邻领域的终稿。
