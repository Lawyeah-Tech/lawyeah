# 边界与路由

## 正触发

转售价格、独家、最惠或地域限制被质疑。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 重写经销合同 | 审查起草搁置 |
| 横向协议 | 评估垄断协议 |
| 整套经销政策条款表 | 审查经销体系竞争限制 |
| 平台二选一 | 评估平台竞争限制 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 经销合同出稿 | 审查起草搁置 |
| 商标许可权利本身 | 知识产权 |

一般商业做法夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。知识产权侵权主轴、投并购交易文件只分流。

## 易混

这个最低零售价能不能留是正触发。把经销合同改到可以签是负触发。
