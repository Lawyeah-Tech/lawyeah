# 边界与路由

## 正触发

交易方自我判断未达 2024 第三条，仍需评估被要求申报、被叫停或主动沟通。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 判断是否构成集中或是否达到第三条 | 评估经营者集中申报义务 |
| 出申报稿 | 准备经营者集中申报 |
| 已实施或抢跑处罚评估 | 评估违法实施集中 |
| 交易结构、对价、交割 | 投资并购领域 |
| 境外当地申报 | 涉外领域 |
| 改 SPA/SHA 文本 | 审查起草领域（本窗搁置） |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| SPA/SHA 谈判、交割条件、融资 | 投资并购 |
| 境外反垄断申报 | 涉外 |

一般商业做法夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。知识产权侵权主轴、投并购交易文件只分流。

## 易混

未达门槛是否绝对安全是正触发。用户要确认可以交割且第四条未核验时，交割字段停止，不改写为实施许可。
