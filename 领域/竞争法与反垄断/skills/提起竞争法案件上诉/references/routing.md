# 边界与路由

## 正触发

不服未生效竞争法裁判，决定上诉。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 重做一审 | prepare-hearing 或起诉应诉 |
| 已生效再审 | 超出本任务，只标接口 |
| 执行 | 执行竞争法生效文书 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 再审程序通论 | 按民事诉讼法，本任务不实施 |

一般商业做法夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。知识产权侵权主轴、投并购交易文件只分流。

## 易混

判决刚到要上诉是正触发。把一审从头再打一遍是负触发。
