# 谈判中止调查承诺或和解方案

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成谈判方案：争点让步表、可接受的行政承诺措施或民事和解条件、弃权范围、执行力、恢复调查或再诉风险。

`depends-on` 为空。

## 工作边界

正触发：行政调查仍可能中止，或民事/举报争议仍可谈，本次主成果是方案而不是已签字协议或正式承诺申请。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 条件已谈拢，只要可签和解协议正文（未安装则 `unavailable`）；
- 只要正式中止调查申请（未安装则 `unavailable`）；
- 只要答辩状或举报函；
- 用户要求以和解掩盖正在实施的垄断协议并继续实施。

## 建立谈判坐标

确认：立场；对方是执法机构还是私主体；已查明或被指的行为；不可接受的自认表述；履行监督能力；是否并行民事和行政。

## 来源和判断状态

编号：`S#` `D#` `A#` `R#` `C#` `L#` `I#` `G#` `Q#` `T#` 条件项；`V#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

`search_law` 核验中止调查、恢复调查、民事和解效力。工具不可用时继续让步表；中止法律效果字段停止。

## 五个判断节点

以 [谈判方法](references/method.md) 为准。

### 1. 可谈性闸

核心卡特尔仍在实施：不得设计“边违法边和解”。执法机构已进入处罚告知且规则不允许中止：中止路径字段停止。

### 2. 争点与让步表

事实、行为改正、金钱、表述、期限分列。

### 3. 行政承诺措施

措施须可执行、可监督、能消除后果。不保证中止。

### 4. 民事和解与弃权

弃权范围不得暗含放弃未知人身损害或强制放弃举报权。执行力提示：普通和解可能无强制执行力。

### 5. 恢复调查与再诉风险

写明违约、隐瞒、新证据的恢复或再诉情景。

## 停止与安全

- `整体停止`：继续实施违法行为的交易；伪造履行。
- `字段停止`：中止条件、和解执行力未核验。
- `目标停止`：主目标变为正式申请或协议正文。
