# 边界与路由

## 正触发

交易在境外签署或交割，需判断中国申报。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 境外当地申报 | 涉外 |
| 中国申报稿 | 准备经营者集中申报 |
| 对价与境外交割执行 | 投资并购 |
| 未达门槛叫停专项 | 评估未达标准被要求申报 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 外国监管申报清单 | 涉外 |

一般商业做法夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。知识产权侵权主轴、投并购交易文件只分流。

## 易混

这个美国交易要不要报中国是正触发。顺便把欧盟申报表做了是负触发。
