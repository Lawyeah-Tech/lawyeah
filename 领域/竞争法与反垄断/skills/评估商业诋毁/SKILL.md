# 评估商业诋毁

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 2008 年申报门槛或 2007 年反垄断法条号当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的主张方或被指方立场下，形成“商业诋毁评估包”：信息真伪、传播主体、损害。

`depends-on` 为空。接受用户提供的传播文本、发布账号和销售影响材料。

## 工作边界

正触发：编造传播虚假或误导信息损害商誉。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 名誉权个人主轴（侵权领域）；
- 经营者虚假宣传专项（转 评估经营者间虚假宣传）；
- 消费者评价纠纷主轴（消保或平台规则）；

本任务不审理自然人名誉权终局，不把发送函件写成已构成诋毁。

## 建立评估坐标

确认：主张方或被指方；信息内容；发布和转发主体；知悉真实性的材料；经营损害迹象。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` `D#` `A#` `R#` `C#` `L#` `I#` `G#` `Q#` `V#` `E#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

`search_law` 核验反不正当竞争法商业诋毁条款。工具不可用时继续文本和传播事实；诋毁成立字段停止。

工具不可用时继续事实、主体、程序文书状态和问题清单；法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　主体

经营者编造或传播。自媒体受经营者指示视同。个人泄愤主轴转侵权。

### 节点 2　信息真伪与误导

虚假或误导。真实但片面可能仍误导，须论证。

### 节点 3　针对性与损害

指向特定经营者商誉；销售、合作或融资受损。

### 节点 4　抗辩

合理评论、转述来源、及时更正。

### 节点 5　救济

停止传播、删除、澄清、赔偿接口。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或做法无法建立；用户坚持伪造、隐匿、威胁、违法取证或指导规避执法。
- `字段停止`：法域、日期、文书送达、申报标准、动态规则未核验。
- `目标停止`：主目标已变为相邻原子或相邻领域的终稿。
