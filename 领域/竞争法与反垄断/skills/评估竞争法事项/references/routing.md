# 边界与路由

## 正触发

已出现经营者集中、垄断行为、不正当竞争、平台限制或竞争调查信号，单方需要总体决定轨道、请求或风险、机关、证据优先级和下一步。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 交易结构、尽调全文、对价、交割 | 投资并购领域 |
| 商标权属、专利比对、商业秘密构成要件终局 | 知识产权领域 |
| 企业综合合规或内部调查治理 | 企业合规领域 |
| 未形成竞争法任务，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |
| 只判断是否必须申报 | `评估经营者集中申报义务` |
| 出申报稿 | `准备经营者集中申报` |
| 向执法机构举报 | `准备向反垄断执法机构举报` |
| 精算罚款或赔偿 | `测算罚款违法所得与损害赔偿` |
| 完整证据卷 | `建立竞争法证据案卷` |
| 已立案调查的书面应对 | `应对反垄断调查` |
| 承诺或和解条件 | `谈判中止调查承诺或和解方案` |
| 起诉 | `提起竞争法民事诉讼` |
| 应诉 | `应对竞争法民事诉讼` |
| 普通消费者消保索赔 | C 端虚假宣传消费者索赔，只分流 |
| 串通投标定罪或行贿辩护 | 刑事领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| SPA/SHA 谈判、交割条件、融资安排 | 投资并购 |
| 权利证书、近似比对、秘密点鉴定 | 知识产权 |
| 合规手册、举报热线、舞弊调查章程 | 企业合规 |
| 复议申请格式、行政诉讼举证期限通论 | 行政争议 |
| 劳动关系内竞业或保密处分 | 劳动 |

一般商业做法夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

轨道尚未闭合、需比较申报、举报、调查或民事诉讼时正触发。主体、请求、论坛均确认且只要诉状或申报表时负触发。营业额未核验仍要求“确认可以交割”时，先完成申报义务闸，不改写为实施许可。
