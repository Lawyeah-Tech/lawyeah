# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变轨道、实施禁止、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然立案、必然批准或唯一必罚总额。

`search_law` 返回已失效《合同法》、2007 年反垄断法旧条号或 2008 年申报门槛时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜轨道｜提出方｜相对方｜法律效果｜成立条件｜支持事实｜不利事实｜控制方｜最强反方｜主备位｜判断｜待核`。

经营者集中、垄断协议、滥用支配地位、不正当竞争、行政垄断分列。同一事实支持多项时分别说明效果，不重复金额。构成竞争法风险不等于已经可以交割、已经构成垄断或当然胜诉。

---

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填总体评估十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 交易结构、尽调全文、对价调整、交割清单、投后治理为主目标 | 投资并购领域 |
| 商标近似比对、专利权属、商业秘密构成要件终局、许可合同权利 | 知识产权领域 |
| 企业合规手册、举报热线、舞弊调查章程、反贿赂体系 | 企业合规领域 |
| 复议申请格式、行政诉讼举证期限通论，无竞争法实体争点 | 行政争议领域 |
| 串通投标定罪、行贿或损害商誉犯罪辩护 | 刑事领域 |
| 普通消费者三倍赔偿或预付费主请求 | 消保 / C 端 |
| 尚未形成竞争法任务，只要改合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

混合信号：竞争法轨道可留本任务；相邻领域只作为背景时在缺口标明，不把相邻规则硬套进竞争法结论。

---

## 节点 1　主体、集团关系和程序状态

1. 固定经营者、关联方、行业协会、平台规则版本。名称不一致不自动合并。
2. 控制权表记录直接控制、间接控制和共同控制。不能仅因持股比例写“已取得控制权”。
3. 程序表逐动作记录协商、申报、补正、调查、约谈、处罚、诉讼：机关、案号、文书、作出日、收到日、送达方式和效力凭证。口头转述、“法务说没问题”、微信已读不得写成已批准、已立案或期限已起算。
4. 同时掌握双方秘密或立场不明：整体停止策略输出。

## 节点 2　轨道与请求／风险假设

每个 `Q#` 先写法律效果，再写成立条件。禁止合成“竞争法风险”一笔。

默认主位候选按事实分别建立，不得预先锁定某一轨道：

- `Q-集` 经营者集中：是否构成集中、是否达到申报标准、批准前不得实施
- `Q-未达` 未达标准被要求申报（2024 规定第四条）
- `Q-横` 横向垄断协议或协同行为
- `Q-纵` 纵向限制（转售价格、独家、最惠）
- `Q-滥` 滥用市场支配地位
- `Q-不` 不正当竞争（混淆、虚假宣传、诋毁、网络干扰、商业贿赂）
- `Q-行` 滥用行政权力排除限制竞争 / 公平竞争审查
- `Q-民` 民事停止侵害、赔偿
- `Q-行罚` 行政调查、罚款、没收违法所得
- `Q-抗` 豁免、安全港、正当理由、时效、管辖异议

单位或被指违法方立场：逐项回应对方已知主张，并列己方最强抗辩，不把反诉或举报写成已经提起。

主备位和互斥必须可见。`Q-集` 未核验不得与“可以交割”同时成立。消费者请求与竞争关系请求不得写成同一原告资格。

专项评估（申报义务、相关市场、纵向限制）可在矩阵中留接口，不在本任务做专项终局。

## 节点 3　实施禁止、机关与论坛

本节点只判断路径，不生成申报稿、举报函或诉状。

### 3.1 先分账

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 已签署交易协议 | 已可交割或已批准 |
| 管理层估算未达门槛 | 依法无须申报 |
| 收到约谈或问询 | 已认定垄断 |
| 行政处罚事先告知 | 民事必然胜诉 |
| 对方未异议 | 行为当然合法或当然违法 |

### 3.2 经营者集中闸

运行时核验反垄断法关于集中的定义和 2024 申报标准后再落判断。核验失败则实施禁止与门槛字段停止，事实与问题清单继续。

1. 是否取得控制权或能够施加决定性影响：股权、协议、人事、财务、业务分列。
2. 营业额是否可能达到 2024 标准：禁止回填 2008 年 100 亿/20 亿/4 亿。第三条数额未核验则门槛判断 `依据不足`。
3. 未达标准：保留第四条被要求申报红旗，不得写成绝对安全。
4. 达到标准或被要求申报：主位写成批准前不得实施集中。已发生人事整合、敏感信息交换、提前交割标 `Q-抢跑` 接口，转介申报义务或自我报告，不在本任务定性终局。

### 3.3 行为轨道

- 垄断协议：先分横向/纵向/组织或实质性帮助。第十八条第二三款抗辩和安全港只标接口。
- 滥用：先问相关市场与支配地位是否有最低事实，再问行为类型和正当理由。不得跳过市场界定直接写滥用成立。
- 不正当竞争：先确认经营者间竞争关系或扰乱竞争秩序事实，再匹配行为类型。2025 年反不正当竞争法条号运行时核验；事件日在 2025-10-15 前改核 2019 文本。
- 行政垄断与公平竞争审查：主体须是行政机关或法律法规授权组织，或起草单位的政策措施。

### 3.4 论坛

分别判断：自行整改、行政举报、反垄断调查应对、民事诉讼、公平竞争审查投诉。本任务不写立案包或举报终稿。

民事诉讼与行政举报可并行，但须分列请求和证据负担，不得承诺“先行政必赢民事”。

## 节点 4　期限分类型

每种期间单独一行。禁止用民事诉讼时效去算申报审查期，也禁止用审查期去挡民事请求。

| 类型 | 规则锚点 | 本任务允许的输出 | 禁止 |
| --- | --- | --- | --- |
| 民事诉讼时效 | 民法典一般时效；垄断民事解释运行时核验 | 起算事件、备选起算、中断候选 | 唯一截止日 |
| 行政处罚追究时效 | 运行时核验现行行政处罚法及反垄断法 | 连续或继续状态是否可能中断起算 | 把民事时效写成行政时效 |
| 申报审查期限 | 经营者集中审查规定；停钟事由 | 立案、初步审查、进一步审查、中止 | 预测批准日 |
| 异议 / 听证 / 复议期 | 处罚告知或决定载明 + 运行时核验 | 已进入程序时标红旗 | 在评估里写出异议书截止日期充作法律意见 |

日期冲突、送达不明、知悉日不明：并行情景 + 字段停止，不选对用户最有利的一天。

---

## 节点 5　金额区间与罚款接口

本任务只建区间和接口，不替代 `calculate-exposure`。

1. 分项：上一年度销售额百分比罚款、无销售额固定档、个人罚款、违法所得、民事赔偿、惩罚性赔偿候选。未知不写零，不输出唯一必罚或必得总额。
2. 反垄断法第五十六条、第五十七条、第五十八条、第六十三条须运行时核验现行文本后再写档位。MCP 若返回 2007 年条号，记为噪声。
3. 情节特别严重可二倍以上五倍以下加重只标接口，不得默认适用。
4. 民事赔偿受损害、因果、减损约束。行政罚款不是民事赔偿的自动数额。
5. 停止行为、剥离、恢复原状、附加限制性条件单列非金钱后果。

参数不足：只列已知参数、未知参数和专项测算接口。

---

## 程序与期限表

程序动作记录机关、案号、文书、作出、收到、送达、效力。期限每行只对应一种期间类型和一个起算事件。关键日期冲突则并行情景。

## 金额区间表

固定列：项目、性质、期间、参数、来源、已付、未知、互斥／抵扣、范围、专项测算接口。参数不足不输出唯一总额。

## 证据与下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。

下一步按实施禁止、期限灭失、易失证据、改变请求或风险、可逆性排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。

申报、举报、起诉、应诉、精算、完整证据卷只写转介条件和最小交接，不在本方法生成那些终稿。禁止指导伪造、隐匿、威胁、抢跑交割伪装或违法取证。
