# 评估竞争法事项

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 2008 年申报门槛或 2007 年反垄断法条号当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“竞争法事项总体评估矩阵”：主体和程序状态、轨道分流、逐项请求或风险假设、主管机关与期限待核、金额区间与非金钱后果、证据缺口、对方最强解释和下一步。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：已出现经营者集中、垄断协议、滥用支配地位、不正当竞争、平台限制或竞争调查信号，用户仍需决定轨道、请求、抗辩或下一步。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要交易结构、尽调全文、对价或交割清单（投资并购）；
- 只要商标权属、专利比对或商业秘密构成要件终局（知识产权）；
- 只要企业综合合规体系或内部调查治理（企业合规）；
- 尚未形成竞争法任务，只要改合同或出稿（审查起草领域，本生产线搁置，只说明不实施）；
- 只要申报终稿、举报函、诉状、答辩或罚款精算工作表；
- 普通消费者只要消保索赔。

本任务不生成申报表、发送版举报函、可提交诉状或答辩，不给胜诉率，不批准交割。

## 建立评估坐标

确认：使用者与授权；单方立场；相对方及可能责任主体；商业做法或交易步骤；法域；当前协商、申报、调查、诉讼状态；机关文书作出与送达；对方已知主张；关键材料及缺失。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 协议或规则定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／风险假设；`V#` 评估版本；`E#` 发送／送达／申报凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验反垄断法 2022 修正、2024 申报标准、2025 反不正当竞争法、垄断民事解释；`search_practiced` 补路径与反例；特殊事实用 `search_case_by_fact`。不虚构案件系统。

`search_law` 返回 2007 年反垄断法旧条号、2008 年申报门槛或失效合同法时记为噪声，不得写入 `L#`。反不正当竞争法 2025 修订若被标“尚未施行”，以 2025-10-15 施行日为准并记录冲突。

工具不可用时继续事实、主体、程序文书状态和问题清单；法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 专项分流、主体和程序状态

先做并购整体、IP 权利、综合合规、刑事、消保、审查起草分流。再固定主体、集团控制关系和程序表。口头“法务说没问题”不写成已批准、已立案或期限已起算。

### 2. 轨道与请求／风险假设

每个 `Q#` 独立列法律效果、成立条件、支持及不利事实、控制方、最强反方、主备位和互斥。集中申报、垄断协议、滥用、不正当竞争、行政垄断不得合成一笔“竞争法风险”。

### 3. 机关、实施禁止和期限

申报标准未核验不得写可以交割。未达门槛仍保留被要求申报接口。期限分列民事诉讼时效、行政处罚追究时效、申报审查期限，不混算。

### 4. 金额区间与非金钱后果

分项列行政罚款、违法所得、民事赔偿、停止行为、恢复原状。未知不写零。销售额百分比只标接口，不输出唯一必罚总额。

### 5. 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。下一步按实施禁止、期限灭失、易失证据、可逆性排序。申报、举报、起诉、精算标为转介，不在本包做出发送或提交终稿。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或做法无法建立；用户坚持伪造营业额、抢跑交割伪装、藏匿材料或违法取证。
- `字段停止`：法域、日期、文书送达、申报标准、动态规则未核验。
- `目标停止`：主目标已变为申报稿、举报函、建卷、和解协议或程序文书。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
