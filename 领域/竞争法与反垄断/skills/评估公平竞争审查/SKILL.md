# 评估公平竞争审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 2008 年申报门槛或 2007 年反垄断法条号当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的起草单位或受影响经营者立场下，形成“公平竞争审查评估包”：是否属于应审文件、禁令清单命中、不得出台风险。

`depends-on` 为空。接受用户提供的政策措施草案或已出台文件及起草说明。

## 工作边界

正触发：政策措施草案或已出台文件被指排除限制竞争。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 出具正式审查意见书（转 准备公平竞争审查意见）；
- 滥用行政权力排除限制竞争行为评估为主（转 评估滥用行政权力排除限制竞争）；
- 替代立法起草本身；
- 一般抽象行政行为诉讼通论（行政争议）；

本任务不替代正式审查意见书，不代替立法起草，不保证文件被撤销。

## 建立评估坐标

确认：起草单位或受影响经营者立场；文件名称与文号；是否已出台；措施内容；涉及的商品、要素或经营主体。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` `D#` `A#` `R#` `C#` 政策文本；`L#` `I#` `G#` `Q#` `V#` `E#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

`search_law` 核验公平竞争审查条例及配套规定关于审查范围、禁令和例外。工具不可用时继续文件识别；应审和不得出台的法律结论字段停止。

工具不可用时继续事实、主体、程序文书状态和问题清单；法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　是否应审文件

行政机关或法律法规授权组织起草的涉及经营主体经济活动的政策措施。内部人事或党建文件通常不入。

### 节点 2　禁令清单命中

市场准入和退出、商品要素自由流动、影响生产经营成本、影响生产经营行为四类分列。

### 节点 3　例外适用

维护国家安全、社会保障等例外须满足规定条件，不得空泛套用。

### 节点 4　不得出台或应修订风险

已出台的评估清理或纠正接口，不代替对行政机关的一般诉讼。

### 节点 5　与行政垄断的交叉

强制垄断协议、指定交易可并行行政垄断评估。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或做法无法建立；用户坚持伪造、隐匿、威胁、违法取证或指导规避执法。
- `字段停止`：法域、日期、文书送达、申报标准、动态规则未核验。
- `目标停止`：主目标已变为相邻原子或相邻领域的终稿。
