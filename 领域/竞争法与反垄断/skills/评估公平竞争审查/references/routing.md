# 边界与路由

## 正触发

政策措施草案或已出台文件被指排除限制竞争。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 正式审查意见书 | 准备公平竞争审查意见 |
| 行政垄断行为评估为主 | 评估滥用行政权力排除限制竞争 |
| 立法起草本身 | 不实施；非本包 |
| 一般行政诉讼程序 | 行政争议 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 抽象行政行为诉讼通论 | 行政争议 |

一般商业做法夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。知识产权侵权主轴、投并购交易文件只分流。
