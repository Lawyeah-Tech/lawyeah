# 边界与路由

## 正触发

片面对比或虚假交易评价伤害竞争者。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 普通消费者索赔 | 消保或 C 端虚假宣传包 |
| 商业诋毁主轴 | 评估商业诋毁 |
| 无竞争关系的广告处罚通论 | 广告监管或行政 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| C 端虚假宣传消费者索赔 | 只分流，不回改 |

一般商业做法夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。知识产权侵权主轴、投并购交易文件只分流。
