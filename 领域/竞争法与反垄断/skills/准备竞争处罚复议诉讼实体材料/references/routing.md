# 边界与路由

## 正触发

已决定寻求行政救济，需竞争法实体争点包。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 通用复议诉讼文书 | 行政领域 |
| 尚未决定是否救济 | 评估行政处罚决定 |
| 民事后继 | 评估行政认定后的后继民事诉讼 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 复议诉讼通用程序 | 行政争议 |

一般商业做法夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。知识产权侵权主轴、投并购交易文件只分流。

## 易混

决定告市监局，需要竞争法打哪几枪是正触发。复议申请书格式走行政。
