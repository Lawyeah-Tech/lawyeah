# 准备经营者集中申报

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 2008 年申报门槛当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的申报义务人立场下，形成可复核、不代提交的“经营者集中申报包”：简易或普通程序建议、文件清单、申报表草稿、保密标注、批准前实施禁止提示。

`depends-on` 为空。接受用户或律师提供的等价申报义务判断、营业额和交易文件。

## 工作边界

正触发：已判断应申报，或执法机构已要求申报，本次主成果是提交前申报材料。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 还在判断是否必须申报（转 `assess-merger-notification`）；
- 只要交易对价、交割或融资（投资并购）；
- 只要答复已立案后的问题清单（未安装则 `unavailable`）；
- 用户要求代为提交或保证批准。

文稿状态只用 `草案`、`提交前复核`、`不得提交`。本任务形成的文本一律视为未提交。

## 建立申报坐标

确认：申报义务人；其他参与方；交易文件版本；营业额材料；相关市场初步描述；是否主张简易案件；已发生整合；联系人与授权委托。

## 来源和判断状态

编号：`S#` `D#` `A#` `R#` `C#` `L#` `I#` `G#` `Q#` `V#` 稿件版本；`E#` 递交凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验审查规定关于申报文件、简易案件和实施禁止；`search_template` 只借申报表栏目。工具不可用时继续文件清单和草稿结构；简易案件适用和法律效果字段停止。

## 五个判断节点

执行顺序和停止条件以 [申报方法](references/method.md) 为准。

### 1. 义务闭合闸

无等价申报义务判断且营业额、控制权无法建立：字段停止或负触发回申报义务评估。已被要求申报的，即使未达第三条也进入本任务。

### 2. 简易或普通

只给出建议和条件，不保证总局接受简易。横向重叠、纵向关系、相邻市场事实不足时不得主张简易。

### 3. 文件清单与事实回链

主体证明、交易文件、营业额、股权结构图、相关市场描述、协同效应材料分列。缺失标 `G#`，不得用估算填报为已审计数。

### 4. 申报表草稿与保密

锁定唯一 `V#`。正文只写已支持事实。商业秘密和未公开交易信息标保密。不得把交割日期写成已获批准。

### 5. 实施禁止与提交核验

提交不等于批准。批准前不得实施。本任务不代提交，不预测审限届满日。

## 停止与安全

- `整体停止`：立场冲突；用户坚持虚报营业额、隐瞒重叠或在禁止期交割。
- `字段停止`：简易条件、文件真实性、动态规则未核验。
- `目标停止`：主目标变为交易文件或交割。
