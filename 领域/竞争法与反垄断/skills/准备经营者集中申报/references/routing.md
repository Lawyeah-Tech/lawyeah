# 边界与路由

## 正触发

申报义务已判断成立或已被要求申报，本次要提交前申报包。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 是否必须申报尚未判断 | `评估经营者集中申报义务` |
| 交易对价、交割、融资 | 投资并购 |
| 审查问题清单答复 | `应对申报补正与审查问题`（未安装则 `unavailable`） |
| 附加限制性条件方案 | `准备附加限制性条件方案`（未安装则 `unavailable`） |
| 代提交或保证批准 | 停止，不实施 |

## 易混

“先出一套申报草稿，交割先进行”负触发并字段停止。实施禁止未解除前不得把草稿标为可交割依据。
