# 边界与路由

## 正触发

需立即停止仿冒、封禁或搭售。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 保证裁定 | 不提供 |
| 财产保全终局 | 另评，不在本任务 |
| 只发函 | 准备停止不正当竞争通知 |
| IP 行为保全主轴 | 知识产权 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 知识产权行为保全 | 知识产权 |
| 财产保全 | 另评 |

一般商业做法夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。知识产权侵权主轴、投并购交易文件只分流。

## 易混

求法院先下令停用仿冒包装是正触发。先把对方账户冻了是财产保全另评。
