# 申请停止侵害或行为保全

## 任务目标

在明确、无利益冲突的申请方立场下，形成“停止侵害或行为保全申请包”：行为保全或停止侵害申请、紧迫性、担保。

`depends-on` 为空。接受用户提供的等价侵权或限制事实、诉讼或仲裁进度和拟担保财产。

## 工作边界

正触发：需立即停止仿冒、封禁或搭售。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 保证裁定；
- 财产保全另评（提示转相关程序，本任务不做财产保全终局）；
- 尚未决定起诉且只要发函（转 准备停止不正当竞争通知）；
- 知识产权行为保全且权属侵权比对为主（知识产权）；

本任务不保证裁定，不做财产保全终局，不代提交。

## 建立评估坐标

确认：申请方；被申请行为；本案或将案；紧迫损害；担保能力。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` `D#` `A#` `R#` `C#` `L#` `I#` `G#` `Q#` `V#` `E#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 2008 年申报门槛或 2007 年反垄断法条号当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

`search_law` 核验民事诉讼法行为保全和反不正当竞争法或反垄断法停止侵害。工具不可用时继续紧迫事实；裁定可能性字段停止。

工具不可用时继续事实、主体、程序文书状态和问题清单；法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [申请方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　本案基础

已诉或即将起诉。权属主轴转知识产权。

### 节点 2　行为特定

停止的具体行为必须可执行，不得笼统停止不正当竞争。

### 节点 3　紧迫性

持续混淆、下架窗口、证据或市场份额不可逆损失。

### 节点 4　担保

提供担保方向。金额未知不写零。

### 节点 5　与财产保全分账

查封账户另评。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或做法无法建立；用户坚持伪造、隐匿、威胁、违法取证或指导规避执法。
- `字段停止`：法域、日期、文书送达、申报标准、动态规则未核验。
- `目标停止`：主目标已变为相邻原子或相邻领域的终稿。

严格按 [输出合同](references/output-contract.md) 交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
