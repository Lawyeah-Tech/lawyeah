# 边界与路由

## 正触发

SEP、拒绝许可、过期权利继续收费被指排除限制竞争。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 权属、侵权比对、许可权利本身 | 知识产权 |
| 相关市场终局 | 界定相关市场 |
| 起草许可协议 | 审查起草搁置 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 专利侵权比对、权属 | 知识产权 |
| 许可合同出稿 | 审查起草搁置 |

一般商业做法夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。知识产权侵权主轴、投并购交易文件只分流。

## 易混

过期专利还在收许可费是不是垄断是正触发。这专利是不是我的、构不构成侵权是知识产权。
