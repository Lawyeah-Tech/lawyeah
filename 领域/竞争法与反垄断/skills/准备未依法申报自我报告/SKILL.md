# 准备未依法申报自我报告

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 2008 年申报门槛或 2007 年反垄断法条号当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的义务人立场下，形成“未依法申报自我报告包”：事实陈述边界、停止实施建议、材料包。

`depends-on` 为空。接受用户或律师提供的等价交易时间线、营业额和控制权材料。

## 工作边界

正触发：已实施或即将被查，拟主动向执法机构报告未依法申报或批准前实施。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 指导伪造补申报时间线或伪装未实施（整体停止）；
- 抢跑行为识别尚未做且用户只要定性（转 评估违法实施集中）；
- 正常申报稿且尚未实施（转 准备经营者集中申报）；
- 交割操作（投资并购）；

本任务不指导伪造时间线，不保证减免，不代提交。

## 建立评估坐标

确认：义务人；交易与实施时间线；是否已被问询；拟报告范围；已停止实施与否。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` `D#` `A#` `R#` `C#` `L#` `I#` `G#` `Q#` `V#` 稿件；`E#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

`search_law` 核验未申报调查程序、罚款和配合情节。工具不可用时继续事实时间线；减免效果字段停止。

工具不可用时继续事实、主体、程序文书状态和问题清单；法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [报告方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　报告决定与范围

确认已决定主动报告。范围覆盖集中步骤和实施行为，不得选择性遗漏。

### 节点 2　事实陈述边界

只写已支持事实。不知道就写不知道。禁止倒签。

### 节点 3　停止实施

报告前必须列出已停止和无法立即恢复的事项。

### 节点 4　材料包

交易文件、营业额、股权图、实施行为清单、授权委托。

### 节点 5　提交与减免接口

不保证从轻。后续调查转调查应对。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或做法无法建立；用户坚持伪造、隐匿、威胁、违法取证或指导规避执法。
- `字段停止`：法域、日期、文书送达、申报标准、动态规则未核验。
- `目标停止`：主目标已变为相邻原子或相邻领域的终稿。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
