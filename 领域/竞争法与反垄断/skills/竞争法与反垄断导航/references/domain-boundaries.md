# 竞争法领域边界

本表只说明归属。当前安装包是（P0+P1）。每次路由先核对 [当前能力地图](capability-map.md)；未列入的 P2 及其他未安装入口输出 `unavailable`。

| 相邻 | 本包入口 | 转出 |
| --- | --- | --- |
| 投资并购 | 经营者集中申报义务、申报稿、附加限制性条件竞争专项 | 交易结构、尽调整体、对价、交割清单、投后治理 |
| 知识产权 | 以市场排除和竞争秩序为主要成果的评估、诉讼 | 权属、侵权比对、商业秘密构成要件终局、许可合同权利 |
| 企业合规 | 针对特定竞争做法的风险控制、调查应对 | 综合合规机制、内部调查治理、反贿赂体系整包 |
| 行政争议 | 竞争处罚实体争点、举报、调查程序状态 | 复议申请书格式、行政诉讼通用程序代理 |
| 合同审查与起草 | 无。未形成竞争法任务只要改合同或出稿：本窗搁置，只说明不实施 | 审查起草领域（用户单独策略） |
| 刑事 | 评估中的刑行交叉只标红旗 | 定罪、控告、辩护 |
| 涉外 | 境外交易的中国申报连结 | 境外当地申报、外国监管 |
| 劳动 | 无 | 劳动关系内保密、竞业限制劳动后果 |
| C 端虚假宣传消费者索赔 | 经营者间虚假宣传的竞争法路径 | 普通消费者消保索赔 |
| C 端侵权下架 | 竞争法停止通知或平台投诉且要件未闭合 | 大众下架材料且权利基础已闭合 |
| C 端行政处罚救济 | 竞争处罚实体评估 | 通用复议诉讼材料且实体已闭合 |

一般交易或宣传夹带竞争法背景时，竞争法段留本包；交易执行、权利本身或综合合规段只分流，不把相邻规则写入本包结论。
