# 原子 Skill 选择方法

## 一、先识别成果

先问这一次要拿到什么可独立验收的成果，而不是按行业、法条或案由名称匹配：

- 竞争法总图；
- 申报义务判断、未达门槛叫停、抢跑、合营、控制权与营业额、境外交易中国申报；
- 经营者集中申报包、补正答复、救济方案、撤回、自我报告、条件履行、审限停钟；
- 垄断协议、纵向限制、协会组织、轴辐算法、豁免安全港、宽恕；
- 滥用、相关市场、拒绝或搭售、价格差别待遇；
- 不正当竞争总览及混淆、诋毁、虚假宣传、商业贿赂、网络干扰；
- 平台竞争限制、商业秘密交叉分流；
- 停止通知、平台投诉下架；
- 行政举报材料、现场检查、调查答复、初步核实、承诺申请、听证、处罚评估、复议诉讼实体；
- 行政垄断、公平竞争审查评估与审查意见；
- 民事起诉、应诉、行为保全、庭审、上诉、后继诉讼、执行、管辖异议；
- 罚款或赔偿测算、证据案卷、电子证据保全、经济学委托提纲；
- 承诺谈判、已成争和解；
- 期限与主管机关、现场检查手册、特定做法控制点、协会文件审查、知识产权行使的竞争法面向。

## 二、再确认上下文

只确认会改变入口的最小信息：

1. 单方立场与授权；
2. 是交易申报、行为评估、已被调查还是已涉诉；
3. 是否已有申报回执、调查通知或起诉状；
4. 本次要分析、出申报/举报稿、测算、建卷、谈判还是程序文书；
5. 是否属于并购交易整体、知识产权权利本身、综合合规或一般行政程序。

## 三、处理混合请求

1. 列出每项可独立验收的成果及对应入口；
2. 只问：`这次要先取得哪一项成果？`；
3. 回答前不指定主要 Skill，不暗示必须先评估再申报；
4. 用户确认后只启动所选入口；等价评估、测算或证据可由用户或律师提供。

## 四、停止

立场冲突、相邻领域主轴或未形成竞争法任务只要改合同时，说明边界并转出，不代做。信息不足时每轮只追问一个最能改变入口的问题。
