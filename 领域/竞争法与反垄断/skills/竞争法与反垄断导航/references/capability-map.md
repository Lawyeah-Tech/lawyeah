# 当前能力地图

当前安装包是，覆盖下列 10 个 P0 与 55 个 P1 原子 Skill。只推荐表中已安装入口。未列入的 P2 及其他路线图能力必须输出 `unavailable`，不得由名称相近的 Skill 代做。

## P0

| 用户当前目标 | 原子 Skill | 独立成果 | 不包含 |
| --- | --- | --- | --- |
| 已出现申报、垄断、不正当竞争或调查信号，要总图再决定路径 | `评估竞争法事项` | 轨道分流、请求或风险、期限机关、金额区间、缺口和下一步 | 申报终稿、举报函、诉状、精算终稿 |
| 拟交割或已接近交割，要判断是否必须申报 | `评估经营者集中申报义务` | 集中是否成立、门槛情景、实施禁止 | 申报表、交易结构 |
| 已判断应申报或被要求申报，要提交前申报包 | `准备经营者集中申报` | 申报类型建议、文件清单、申报表草稿 | 代提交；把签署写成已可交割 |
| 要向市场监管总局或授权机关举报 | `准备向反垄断执法机构举报` | 发送前举报材料、管辖建议、证据目录 | 保证立案；民事起诉状 |
| 要可复核的罚款、违法所得或损害赔偿数字 | `测算罚款违法所得与损害赔偿` | 分项测算、裁量接口、互斥抵扣 | 认定违法已成立、唯一必得总额 |
| 单独盘点举证责任和补证 | `建立竞争法证据案卷` | 要件、举证、材料矩阵、合法补证 | 策略总图、诉状、违法取证 |
| 已立案调查或收到调查通知，要书面应对 | `应对反垄断调查` | 程序状态、答复边界、承诺/宽恕接口 | 到场指挥终稿、保证中止 |
| 决定提起垄断或不正当竞争民事诉讼 | `提起竞争法民事诉讼` | 起诉状、请求、管辖、证据目录 | 代提交；行政举报终稿 |
| 已收到起诉状，要首次应诉 | `应对竞争法民事诉讼` | 期限卡、答辩草稿、反诉评估接口 | 主动起诉、劳动应诉 |
| 仍可谈行政承诺或民事和解 | `谈判中止调查承诺或和解方案` | 让步表、承诺措施、弃权、恢复调查风险 | 已签字和解协议、正式承诺申请 |

## P1

| 用户当前目标 | 原子 Skill | 独立成果 | 不包含 |
| --- | --- | --- | --- |
| 未达门槛仍担心被叫停或被要求申报 | `评估未达标准被要求申报` | 第四条风险情景、证据信号、主动沟通接口 | 不替代申报义务总评估；不写申报终稿 |
| 交割前已整合、委派高管、交换敏感信息或已交割未申报 | `评估违法实施集中` | 实施行为识别、恢复原状风险、处罚接口、停止项 | 不指导补做交割；自我报告另项 |
| 新设或改建合营，争是否取得控制权或决定性影响 | `评估合营是否构成集中` | 共同控制、全功能合营、营业额归属 | 不起草合资合同（审查起草搁置） |
| 单独委托核验控制权变化和营业额口径 | `评估控制权与营业额` | 控制权表、集团营业额口径、金融业特殊算法接口 | 不选定是否必须申报 |
| 价格、产量、市场划分、联合抵制或协同行为被质疑 | `评估垄断协议` | 协议或协同要件、横向纵向分流、豁免接口、个人责任红旗 | 不定罪；协会、轴辐另项可深挖 |
| 转售价格、独家、最惠、地域限制被质疑 | `评估纵向限制` | 第十八条路径、排除限制竞争效果、安全港接口 | 不重写经销合同正文 |
| 不公平价格、拒绝交易、限定交易、搭售、差别待遇被质疑 | `评估滥用市场支配地位` | 相关市场接口、支配地位假设、滥用类型、正当理由 | 不替代相关市场专项界定 |
| 仿冒、虚假宣传、诋毁、网络干扰等经营者间争议 | `评估不正当竞争行为` | 行为类型、竞争关系、混淆或误导、停止与赔偿接口 | 普通消费者转消保或 C 端；商业秘密权利转知识产权 |
| 二选一、自我优待、数据封禁、算法协同、平台内规则被质疑 | `评估平台竞争限制` | 反垄断与反不正当竞争双轨、必要设施或相对优势接口 | 不建平台综合合规；数据跨境转数据隐私 |
| 政策措施草案或已出台文件被指排除限制竞争 | `评估公平竞争审查` | 是否应审、禁令清单命中、不得出台风险 | 不替代正式审查意见书 |
| 已立案审查，收到补正或问题清单 | `应对申报补正与审查问题` | 逐问答复、保密标注、停钟影响 | 不改写交易整体；不承诺审查结果 |
| 审查认为可能排除限制竞争，需提出救济 | `准备附加限制性条件方案` | 结构性或行为性条件比较、可执行性、监督接口 | 不保证附加批准；不吞并购重组方案 |
| 拟撤回申报或为竞争审查调整控制权安排 | `准备撤回申报或竞争专项结构调整` | 撤回后果、再申报风险、竞争专项调整意见 | 交易整体、融资交割归投资并购 |
| 交易在境外签署或交割，需判断中国申报 | `评估境外交易中国申报` | 中国营业额连结、控制权、实施地 | 境外当地申报转涉外 |
| 已实施或即将被查，拟主动报告 | `准备未依法申报自我报告` | 事实陈述边界、停止实施建议、材料包 | 不指导伪造补申报时间线 |
| 已附加批准，需按期报告履行 | `执行限制性条件监督报告` | 履行对照表、受托人接口、违约红旗 | 不重开交易谈判 |
| 单独核验立案、初步审查、进一步审查和中止 | `评估申报审查期限与停钟` | 期限表、停钟事由、交割窗口 | 不预测批准日 |
| 协会章程、会议纪要或自律公约被指组织协同 | `评估行业协会组织垄断协议` | 组织或帮助要件、会员责任分流、删除条款建议 | 不定罪；不建协会综合治理 |
| 平台或上游传递价格、算法跟价被指协同 | `评估轴辐协议或算法协同` | 意思联络替代路径、实质性帮助、算法抗辩 | 不鉴定算法源码 |
| 已决定争取减免处罚，需排队和材料 | `申请垄断协议宽恕` | 申请时点、顺位风险、陈述边界、配合义务 | 不保证第一顺位；不指导甩锅伪造 |
| 主张效率、中小企业或市场份额安全港 | `评估豁免或安全港` | 第二十条或第十八条第二三款接口、举证责任 | 不写成必然不予禁止 |
| 已有或拟执行经销政策，需竞争法判断 | `审查经销体系竞争限制` | 风险条款表、可保留或须改或须停项 | 不出可签署经销合同 |
| 单独委托商品市场和地域市场界定 | `界定相关市场` | 替代分析、假设、数据缺口、经济学委托接口 | 不输出市场份额唯一数字冒充已证实 |
| 必要设施、二选一、捆绑被质疑 | `评估拒绝交易限定交易或搭售` | 正当理由、交易必要性、替代供应 | 不强制缔约 |
| 过高过低价、大数据杀熟的竞争法路径 | `评估不公平价格与差别待遇` | 价格比较基准、条件是否相同、消费者法分流 | 纯消保路径转出；不定价监管结论 |
| 名称、包装、装潢、搜索关键词被指仿冒 | `评估混淆与仿冒` | 有一定影响、混淆可能性、停止与赔偿接口 | 商标权属与授权本身转知识产权 |
| 编造传播虚假或误导信息损害商誉 | `评估商业诋毁` | 信息真伪、传播主体、损害 | 名誉权个人主轴转侵权 |
| 片面对比、虚假交易评价伤害竞争者 | `评估经营者间虚假宣传` | 引人误解、组织虚假交易、竞争关系损失 | 普通消费者索赔转消保或 C 端 |
| 账外暗中利益输送争夺交易机会 | `评估商业贿赂竞争法路径` | 不正当利益、账簿、相对方身份 | 不定受贿罪；刑事转刑事领域 |
| 流量劫持、恶意不兼容、干扰、虚假数据 | `评估网络不正当竞争` | 第十三条路径、技术手段、妨碍后果 | 不替代平台规则仲裁；数据合规转数据隐私 |
| 同时出现保密措施和竞争秩序主张 | `分流商业秘密与竞争法交叉` | 权利基础归知识产权、竞争秩序接口、不得双份主成果 | 不审理商业秘密构成要件终局 |
| 已决定发函要求停止仿冒、诋毁或网络干扰 | `准备停止不正当竞争通知` | 发送前停止通知、事实回链、送达留痕 | 不把发送写成已构成侵权；举报函另项 |
| 向电商或应用商店投诉下架仿冒或虚假宣传 | `准备平台内竞争投诉下架` | 平台投诉包、证据链、保全提示 | C 端侵权下架包只分流；不保证下架 |
| 执法人员已到场或即将到场 | `应对反垄断现场检查` | 到场权利义务卡、封存配合、陈述边界、律师在场 | 不指导藏匿销毁；不替代后续调查应对 |
| 接到初步核实或约谈，尚未正式立案 | `作为被举报人应对初步核实` | 事实澄清边界、补证、升级风险 | 不写成已经结案 |
| 已决定走承诺程序，需正式申请 | `申请中止调查承诺` | 承诺措施、履行监督、恢复调查风险 | 谈判方案走承诺谈判原子；不保证中止 |
| 已收到处罚告知或听证通知 | `准备行政处罚听证陈述` | 听证陈述、证据质证要点、裁量情节 | 一般行政听证方法转行政领域 |
| 已收到处罚决定书，需判断履行、复议或诉讼 | `评估行政处罚决定` | 事实理由裁量表、期限、后续接口 | 不代写复议申请书通用格式 |
| 已决定寻求行政救济，需竞争法实体争点包 | `准备竞争处罚复议诉讼实体材料` | 实体违法或裁量争点、证据、期限红旗 | 复议诉讼通用程序文书转行政领域 |
| 地方保护、指定交易、强制垄断协议 | `评估滥用行政权力排除限制竞争` | 主体、行为类型、公平竞争审查交叉 | 不替代对行政机关的一般行政诉讼 |
| 需立即停止仿冒、封禁或搭售 | `申请停止侵害或行为保全` | 行为保全或停止侵害申请、紧迫性、担保 | 不保证裁定；财产保全另评 |
| 诉讼已排期开庭 | `准备竞争法案件庭审` | 争点、举证质证、经济学专家接口、代理提纲 | 不代替立案或仅和解 |
| 不服未生效裁判 | `提起竞争法案件上诉` | 上诉状、范围、期限、理由 | 不重做一审 |
| 已有行政处罚或认定，拟跟进民事赔偿 | `评估行政认定后的后继民事诉讼` | 预决力范围、另证事项、时效 | 不把行政认定写成必然胜诉 |
| 停止侵害或金钱判决未获履行 | `执行竞争法生效文书` | 执行申请、行为履行监督、金额 | 不重审实体 |
| 已被起诉，需在法定期限提管辖异议 | `提出竞争法案件管辖异议` | 异议书、连结点、知识产权法院或中院集中管辖待核 | 过期停止；与实体答辩分开 |
| 聊天、算法日志、网页可能灭失 | `保全协同或仿冒电子证据` | 保全步骤、公证或时间戳分流、禁止动作 | 不指导侵入系统或非法爬取 |
| 需外部经济学家做相关市场或损害分析 | `准备经济学分析委托提纲` | 委托问题、数据清单、假设边界 | 不冒充已完成经济学鉴定 |
| 条件已谈拢，需可签的竞争争议和解协议 | `起草竞争争议和解协议` | 和解草稿、停止行为、弃权边界 | 与未争议的经销补充协议不同 |
| 单独核验时效、执法时效、管辖法院和执法机构 | `评估竞争法期限与主管机关` | 分类型期间表、级别管辖、授权省级机关 | 禁止混算或输出唯一截止日 |
| 尚未被查，需预置反垄断现场检查手册 | `准备现场检查应急手册` | 到场分工、文件范围、陈述纪律 | 不是企业综合合规或内控手册 |
| 某一经销、定价或平台规则需要可执行控制点 | `针对特定商业做法设计竞争风险控制` | 针对该做法的禁止项、审批点、记录 | 不建反贿赂、数据、出口管制综合合规 |
| 协会拟发布或已发布自律公约 | `审查协会章程与行业自律文件` | 竞争风险条款、删除或保留建议 | 不出新的协会治理体系 |
| 起草单位需出具政策措施审查意见 | `准备公平竞争审查意见` | 审查表、例外适用、不得出台结论接口 | 不替代立法起草本身 |
| SEP、拒绝许可、过期权利继续收费被指排除限制竞争 | `评估知识产权行使的竞争法面向` | 权利行使是否构成垄断或不正当竞争、FRAND 接口 | 权属、侵权比对、许可合同权利本身转知识产权 |
