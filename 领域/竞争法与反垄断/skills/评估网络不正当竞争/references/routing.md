# 边界与路由

## 正触发

流量劫持、恶意不兼容、干扰或虚假数据。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 平台内部仲裁终局 | 不替代 |
| 数据合规跨境 | 数据隐私 |
| 非法爬取 | 禁止 |
| 总览未聚焦网络 | 评估不正当竞争行为 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 数据出境与个信 | 数据隐私 |

一般商业做法夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。知识产权侵权主轴、投并购交易文件只分流。
