# 边界与路由

## 正触发

已有行政处罚或认定，拟跟进民事赔偿。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 写成必然胜诉 | 禁止该写法 |
| 无行政文书的起诉 | 提起竞争法民事诉讼 |
| 挑战处罚本身 | assess-penalty-decision 或 prepare-admin-challenge-materials |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 行政文书效力通论 | 行政争议只分流 |

一般商业做法夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。知识产权侵权主轴、投并购交易文件只分流。

## 易混

罚了他们我们能不能跟着赔是正触发。罚了就稳赢是错误写法。
