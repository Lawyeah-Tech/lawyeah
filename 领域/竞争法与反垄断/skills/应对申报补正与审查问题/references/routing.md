# 边界与路由

## 正触发

已立案审查并收到补正或问题清单。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 尚未申报 | 准备经营者集中申报 |
| 附加限制性条件方案 | 准备附加限制性条件方案 |
| 撤回申报 | 准备撤回申报或竞争专项结构调整 |
| 改交易对价或交割 | 投资并购 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 交易重组方案 | 投资并购 |

一般商业做法夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。知识产权侵权主轴、投并购交易文件只分流。

## 易混

总局来了一串问题怎么回是正触发。顺便把交易对价改了再报是负触发。
