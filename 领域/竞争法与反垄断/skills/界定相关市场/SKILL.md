# 界定相关市场

## 任务目标

在明确、无利益冲突的单方立场下，形成“相关市场界定包”：替代分析、假设、数据缺口、经济学委托接口。

`depends-on` 为空。接受用户提供的商品描述、价格数据、客户和竞争对手名单。

## 工作边界

正触发：单独委托商品市场和地域市场界定。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 输出市场份额唯一数字冒充已证实；
- 冒充已完成经济学鉴定（转 准备经济学分析委托提纲 仅委托提纲）；
- 滥用或集中总评估尚未需要市场终局（可回总图或滥用评估）；

本任务不输出唯一份额数字冒充已证实，不冒充经济学鉴定。

## 建立评估坐标

确认：目标商品或服务；客户类型；地域；可用价格和转移数据；对立市场主张。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` `D#` `A#` `R#` `C#` `L#` `I#` `G#` `Q#` `MKT#`；`V#` `E#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 2008 年申报门槛或 2007 年反垄断法条号当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

`search_law` 核验相关市场界定指南或现行规则；案例只比较事实差异。工具不可用时继续替代事实；唯一市场结论字段停止。

工具不可用时继续事实、主体、程序文书状态和问题清单；法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [界定方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　商品替代

需求替代为主，供给替代为辅。功能、价格、转换成本。

### 节点 2　地域替代

运输、监管、语言、交货时间。进出口是否同一市场待核。

### 节点 3　假设与反证

窄市场与宽市场并行，不选对用户有利的唯一市场。

### 节点 4　数据缺口

SSNIP、转移率缺失则标经济学接口。

### 节点 5　份额禁令

不得把单一份额写成已证实。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或做法无法建立；用户坚持伪造、隐匿、威胁、违法取证或指导规避执法。
- `字段停止`：法域、日期、文书送达、申报标准、动态规则未核验。
- `目标停止`：主目标已变为相邻原子或相邻领域的终稿。
