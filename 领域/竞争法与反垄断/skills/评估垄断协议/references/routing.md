# 边界与路由

## 正触发

价格、产量、市场划分、联合抵制或协同行为被质疑。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 行业协会组织深挖 | 评估行业协会组织垄断协议 |
| 轴辐或算法协同深挖 | 评估轴辐协议或算法协同 |
| 纵向限制专项 | 评估纵向限制 |
| 申请宽恕 | 申请垄断协议宽恕 |
| 定罪或串通投标辩护 | 刑事领域 |
| 改经销或协同合同 | 审查起草搁置 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 串通投标刑事 | 刑事 |
| 商业秘密窃取主轴 | 知识产权 |

一般商业做法夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。知识产权侵权主轴、投并购交易文件只分流。

## 易混

我们一起调了价算不算垄断是正触发。帮我写一份不会被查的价格备忘录是负触发并停止。
