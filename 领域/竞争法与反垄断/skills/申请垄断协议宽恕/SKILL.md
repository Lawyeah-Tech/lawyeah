# 申请垄断协议宽恕

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 2008 年申报门槛或 2007 年反垄断法条号当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的参与方立场下，形成“宽恕申请包”：申请时点、顺位风险、陈述边界、配合义务。

`depends-on` 为空。接受用户或律师提供的等价参与事实和已知调查进度。

## 工作边界

正触发：已决定争取减免处罚，需要排队和材料。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 保证第一顺位或保证免罚；
- 指导甩锅或伪造他人主谋（整体停止）；
- 尚未决定是否承认参与（先转 评估垄断协议 或调查应对）；
- 中止调查承诺申请（转 申请中止调查承诺）；

本任务不保证第一顺位，不指导甩锅伪造，不代提交。

## 建立评估坐标

确认：申请人；已知其他参与方是否已报告；调查阶段；拟陈述范围；证据控制方。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` `D#` `A#` `R#` `C#` `L#` `I#` `G#` `Q#` `V#` `E#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

`search_law` 核验垄断协议宽大制度或宽恕规定关于申请顺序、材料完整性和减免幅度接口。幅度未核验不得写具体免罚比例。

工具不可用时继续事实、主体、程序文书状态和问题清单；法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [申请方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　申请时点

立案前、调查中、处罚告知前分列。越晚顺位风险越高，但不保证第一。

### 节点 2　顺位风险

未知他人是否已申请时不得声称第一。

### 节点 3　陈述边界

完整、持续、真实。不得扩大指控第三人。

### 节点 4　配合义务

继续提供证据、不得销毁。违反可能失去宽恕。

### 节点 5　与承诺、民事的关系

宽恕不自动消灭民事责任。承诺程序另项。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或做法无法建立；用户坚持伪造、隐匿、威胁、违法取证或指导规避执法。
- `字段停止`：法域、日期、文书送达、申报标准、动态规则未核验。
- `目标停止`：主目标已变为相邻原子或相邻领域的终稿。
