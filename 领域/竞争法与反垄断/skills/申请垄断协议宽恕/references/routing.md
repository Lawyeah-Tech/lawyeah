# 边界与路由

## 正触发

已决定争取垄断协议减免处罚，需排队和材料。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 保证第一顺位 | 不提供 |
| 甩锅伪造 | 整体停止 |
| 中止调查承诺申请 | 申请中止调查承诺 |
| 尚未决定是否承认 | 评估垄断协议 或 respond-investigation |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 刑事自首或立功 | 刑事 |

一般商业做法夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。知识产权侵权主轴、投并购交易文件只分流。

## 易混

我们想争取宽大是正触发。帮我把责任全推给前同事是负触发并停止。
