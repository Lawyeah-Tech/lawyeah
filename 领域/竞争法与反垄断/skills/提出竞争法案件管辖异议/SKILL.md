# 提出竞争法案件管辖异议

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 2008 年申报门槛或 2007 年反垄断法条号当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的被告立场下，形成“竞争法管辖异议包”：异议书、连结点、知识产权法院或中院集中管辖待核。

`depends-on` 为空。接受用户提供的起诉状、送达凭证和连结事实。

## 工作边界

正触发：已被起诉，需在法定期限提管辖异议。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 过期仍要提异议（停止）；
- 与实体答辩混写且用户只要实体（转 P0 defend-civil-claim）；
- 仲裁条款排除诉讼的终局尚未核验且主目标是实体；

本任务过期停止，与实体答辩分开，不保证移送。

## 建立评估坐标

确认：被告；受诉法院；送达日；答辩期；侵权行为地、被告住所地、协议管辖或仲裁条款。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` `D#` `A#` `R#` `C#` `L#` `I#` `G#` `Q#` `J#`；`V#` `E#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

`search_law` 核验垄断民事解释管辖、反不正当竞争管辖和知识产权法院或中院集中管辖规则。未核验不得选定唯一法院。

工具不可用时继续事实、主体、程序文书状态和问题清单；法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [异议方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　异议期限

答辩期满前提。过期停止。

### 节点 2　连结点

被告住所地、侵权行为实施地、结果地。

### 节点 3　集中管辖待核

知识产权法院、中院集中管辖必须运行时核验。

### 节点 4　仲裁

有效仲裁条款则诉讼管辖可能不成立。

### 节点 5　与实体分开

异议书不写实体胜负。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或做法无法建立；用户坚持伪造、隐匿、威胁、违法取证或指导规避执法。
- `字段停止`：法域、日期、文书送达、申报标准、动态规则未核验。
- `目标停止`：主目标已变为相邻原子或相邻领域的终稿。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
