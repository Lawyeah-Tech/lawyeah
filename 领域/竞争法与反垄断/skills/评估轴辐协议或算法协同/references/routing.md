# 边界与路由

## 正触发

平台或上游传递价格，或算法跟价被指协同。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 鉴定源码或侵入系统 | 禁止；整体停止 |
| 普通横向会议 | 评估垄断协议 |
| 二选一或自我优待 | 评估平台竞争限制 |
| 数据跨境 | 数据隐私 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 算法源码鉴定 | 不实施 |
| 个信与跨境 | 数据隐私 |

一般商业做法夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。知识产权侵权主轴、投并购交易文件只分流。

## 易混

平台把同行价格推给我要我跟是正触发。把对方算法脱下来分析是负触发并停止。
