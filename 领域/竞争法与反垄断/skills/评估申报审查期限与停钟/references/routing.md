# 边界与路由

## 正触发

单独核验立案、初步审查、进一步审查和中止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 预测批准日 | 字段停止；本任务不提供 |
| 写补正答复 | 应对申报补正与审查问题 |
| 出申报稿 | 准备经营者集中申报 |
| 交割执行 | 投资并购 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 交割日谈判 | 投资并购 |

一般商业做法夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。知识产权侵权主轴、投并购交易文件只分流。

## 易混

审限还剩多少、能不能先交割是正触发中的期限部分；交割许可字段停止。
