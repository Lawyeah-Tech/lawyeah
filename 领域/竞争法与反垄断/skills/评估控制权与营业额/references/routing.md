# 边界与路由

## 正触发

单独委托核验控制权变化和营业额口径。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 选定是否必须申报或能否交割 | 评估经营者集中申报义务 |
| 合营全功能与共同控制争点为主 | 评估合营是否构成集中 |
| 出申报表 | 准备经营者集中申报 |
| 对价与交割 | 投资并购 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 合并报表审计调整本身 | 财务顾问；本任务只用法条口径 |

一般商业做法夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。知识产权侵权主轴、投并购交易文件只分流。

## 易混

帮我算一下营业额再告诉我能不能交割是混合请求，先交付口径表，交割意见转申报义务评估。
