# 测算罚款违法所得与损害赔偿

## 任务目标

在明确、无利益冲突的单方立场下，形成“罚款、违法所得与损害赔偿可复核测算包”：事件编号、分项工作表、销售额百分比与固定档接口、二至五倍加重接口、民事损害项目、互斥和缺口。

`depends-on` 为空。本任务**不认定违法已经成立**。

## 工作边界

正触发：单方需要行政罚款区间、违法所得或民事赔偿的可复核数字工作表。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要定性总图；
- 只要申报稿、举报函或诉状；
- 用户要求把未知销售额写成零或输出唯一必罚总额。

## 建立测算坐标

确认：立场；轨道（协议/滥用/集中/不正当竞争）；上一年度销售额材料；违法所得候选；民事损失构成；已处罚或已赔偿。

## 来源和判断状态

编号：`S#` `D#` `A#` `R#` `C#` `L#` `I#` `G#` `Q#` `EVT#` `M#` `V#` `E#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

金额状态只用 `已核实金额`、`情景金额`、`无法估计`。未知不写零。真实零必须有肯定来源。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 2007 年反垄断法罚款条文当作现行条文。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

`search_law` 核验反垄断法第五十六条至第五十八条、第六十三条，反不正当竞争法罚款档，垄断民事解释损害赔偿规则。工具不可用时继续分项建账；档位和加重字段停止。

## 五个判断节点

以 [测算方法](references/method.md) 为准。

### 1. 轨道与测算范围

行政罚款、违法所得、民事赔偿分账。不把行政罚款自动写入民事请求。

### 2. 事件编号与分项建账

同一经济事件 `EVT#`。销售额基数、百分比、固定档、个人罚款、违法所得、实际损失、所失利益分列。

### 3. 法定档位与加重接口

运行时核验现行条号。情节特别严重的二至五倍只标接口，不默认适用。2007 条号是噪声。

### 4. 民事损害与减损

损害、因果、减损、行政认定预决力分列。不得把罚款数额当作赔偿数额。

### 5. 互斥、情景区间和缺口

汇总区分已核实、情景和无法估计。禁止唯一必罚或必得总额。

## 停止与安全

- `整体停止`：立场不明；用户坚持伪造流水或把未知当零。
- `字段停止`：销售额口径、条号、加重条件未核验。
- `目标停止`：主目标变为总图或文书。
