# 边界与路由

## 正触发

协会章程、会议或自律公约被指组织协同。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 无协会角色的横向协议 | 评估垄断协议 |
| 协会文件全面条款审查 | 审查协会章程与行业自律文件 |
| 定罪 | 刑事 |
| 协会综合治理 | 非本包 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 刑事串通 | 刑事 |

一般商业做法夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。知识产权侵权主轴、投并购交易文件只分流。

## 易混

协会让大家统一报价是正触发。帮协会做全套治理手册是负触发。
