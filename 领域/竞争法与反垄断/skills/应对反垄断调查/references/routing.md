# 边界与路由

## 正触发

已有调查通知、立案文书或书面问询，需要答复边界和程序状态。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 现场检查到场指挥 | `应对反垄断现场检查`（未安装则只给最低纪律） |
| 正式承诺申请 | `申请中止调查承诺`（未安装则 `unavailable`） |
| 宽恕申请材料 | `申请垄断协议宽恕`（未安装则 `unavailable`） |
| 民事应诉 | `应对竞争法民事诉讼` |
| 谈判方案而非书面答复 | `谈判中止调查承诺或和解方案` |
| 藏匿销毁 | 整体停止 |

## 易混

约谈或初步核实尚未立案：可部分使用本方法，但不得把约谈写成已立案调查。
