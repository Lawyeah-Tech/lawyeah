# 应对反垄断调查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的被调查人立场下，形成“反垄断调查应对包”：程序状态、问询逐项答复边界、配合与拒绝合法边界、宽恕/承诺接口、停止项和下一步。

`depends-on` 为空。

## 工作边界

正触发：已立案调查、收到调查通知、问询函或要求报送材料，本次主成果是书面应对策略和答复边界。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 执法人员正在现场或即将到场，只要到场指挥卡（未安装 dawn-raid 则只给最低到场纪律，不把本包改写成现场手册）；
- 只要正式中止调查申请终稿（未安装则 `unavailable`）；
- 只要民事答辩；
- 用户要求藏匿、销毁或伪造材料。

## 建立应对坐标

确认：被调查主体；调查机关与文书；案号或通知文号；作出与收到日；要求报送期限；已知调查事项；是否已有律师在场记录。

口头转述不写成已立案或期限已起算。

## 来源和判断状态

编号：`S#` `D#` `A#` `R#` `C#` `L#` `I#` `G#` `Q#` `ANS#` 答复项；`V#` `E#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

`search_law` 核验调查权、配合义务、妨碍调查处罚（2022 修正第六十二条一带）、中止调查与宽恕。工具不可用时继续程序文书状态；答复法律效果和期限字段停止。

## 五个判断节点

以 [应对方法](references/method.md) 为准。

### 1. 文书与程序状态

固定机关、文书种类、送达和期限。未申报集中调查的三十日答辩（审查规定第五十九条）须对号。

### 2. 调查事项与答复边界

逐问区分事实、法律评价和不知道。不得扩大自认。

### 3. 配合与合法拒绝

配合提供账簿、文件、说明。不得拒绝依法检查。与调查无关的个人隐私、律师权利运行时核验，不得编造“一律拒绝”。

### 4. 宽恕与承诺接口

只判断是否值得转入专项，不保证顺位或中止。

### 5. 停止项与下一步

禁止毁证。听证、处罚评估、民事并行只转介。

## 停止与安全

- `整体停止`：用户坚持销毁、藏匿、威胁员工作伪证。
- `字段停止`：送达日、答复期限、宽恕规则未核验。
- `目标停止`：主目标变为现场手册、起诉或正式承诺申请。
