# 边界与路由

## 正触发

审查认为可能排除限制竞争，需提出救济。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 已附加批准后的履行报告 | 执行限制性条件监督报告 |
| 补正问题答复 | 应对申报补正与审查问题 |
| 并购重组、对价、融资 | 投资并购 |
| 撤回申报 | 准备撤回申报或竞争专项结构调整 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 剥离资产的交易文件 | 投资并购 |
| 剥离所涉知识产权许可权利 | 知识产权 |

一般商业做法夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。知识产权侵权主轴、投并购交易文件只分流。

## 易混

总局担心重叠，我们能承诺什么是正触发。顺便把整个重组方案做了是负触发。
