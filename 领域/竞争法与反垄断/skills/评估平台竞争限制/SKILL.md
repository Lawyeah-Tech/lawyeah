# 评估平台竞争限制

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 2008 年申报门槛或 2007 年反垄断法条号当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的平台或商家立场下，形成“平台竞争限制评估包”：反垄断与反不正当竞争双轨、必要设施或相对优势接口。

`depends-on` 为空。接受用户或律师提供的等价平台规则版本、协议和流量或佣金数据。

## 工作边界

正触发：二选一、自我优待、数据封禁、算法协同或平台内规则被质疑。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 建设平台综合合规体系（企业合规）；
- 数据跨境或个人信息合规主轴（数据隐私）；
- 轴辐或算法协同专项深挖（转 评估轴辐协议或算法协同）；
- 拒绝交易或必要设施专项（转 评估拒绝交易限定交易或搭售）；
- 改平台用户协议正文且未形成竞争法任务（审查起草搁置）；

本任务不建平台综合合规体系，不鉴定算法源码，不处理数据跨境。

## 建立评估坐标

确认：平台或商家立场；规则版本；被指限制；是否具有支配或相对优势材料；是否已有约谈或处罚。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` `D#` `A#` `R#` `C#` 平台规则；`L#` `I#` `G#` `Q#` `V#` `E#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

`search_law` 核验反垄断法滥用和垄断协议、反不正当竞争法网络条款和平台责任（按事件日选文本）；`search_practiced` 补二选一与自我优待路径。工具不可用时继续规则事实；支配或违法结论字段停止。

工具不可用时继续事实、主体、程序文书状态和问题清单；法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　双轨分流

具有支配地位嫌疑走滥用；无支配但利用规则或数据妨碍走反不正当竞争；横向或轴辐走协议。不得合成平台风险一笔。

### 节点 2　二选一与限定交易

合同强制、流量惩罚、保证金或算法降权是否实质限定。正当理由单列。

### 节点 3　自我优待与数据封禁

自营或关联商家优待、接口关闭、数据拒绝。必要设施或相对优势只标接口。

### 节点 4　算法协同

跟价或统一佣金是否构成意思联络替代。源码鉴定不在本任务。

### 节点 5　规则修改与下一步

竞争法须停或须改项。不出新的平台治理体系。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或做法无法建立；用户坚持伪造、隐匿、威胁、违法取证或指导规避执法。
- `字段停止`：法域、日期、文书送达、申报标准、动态规则未核验。
- `目标停止`：主目标已变为相邻原子或相邻领域的终稿。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
