# 边界与路由

## 正触发

二选一、自我优待、数据封禁、算法协同或平台内规则被质疑。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 平台综合合规体系 | 企业合规 |
| 数据跨境或个信合规 | 数据隐私 |
| 轴辐或算法专项 | 评估轴辐协议或算法协同 |
| 必要设施或拒绝交易专项 | 评估拒绝交易限定交易或搭售 |
| 改用户协议且未成争 | 审查起草搁置 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 数据出境 | 数据隐私 |
| 平台劳动用工 | 劳动 |

一般商业做法夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。知识产权侵权主轴、投并购交易文件只分流。

## 易混

平台逼我二选一是正触发。帮我做一套平台合规体系是负触发。
