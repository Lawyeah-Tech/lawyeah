# 边界与路由

## 正触发

仿冒、虚假宣传、诋毁、网络干扰等经营者间争议需要总览。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 普通消费者索赔 | 消保或 C 端 |
| 商业秘密权利本身 | 知识产权 |
| 混淆专项 | 评估混淆与仿冒 |
| 诋毁专项 | 评估商业诋毁 |
| 经营者虚假宣传专项 | 评估经营者间虚假宣传 |
| 网络不正当竞争专项 | 评估网络不正当竞争 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 商标近似比对、权属 | 知识产权 |
| 消费者预付费或三倍赔偿 | 消保或 C 端 |

一般商业做法夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。知识产权侵权主轴、投并购交易文件只分流。

## 易混

同行抄了包装怎么告是正触发。我作为消费者要退一赔三是负触发。
