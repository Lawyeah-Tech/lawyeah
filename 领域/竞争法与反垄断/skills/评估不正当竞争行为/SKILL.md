# 评估不正当竞争行为

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 2008 年申报门槛或 2007 年反垄断法条号当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的主张方或被指方立场下，形成“不正当竞争行为评估包”：行为类型、竞争关系、混淆或误导、停止与赔偿接口。

`depends-on` 为空。接受用户或律师提供的等价网页、包装、宣传和交易记录。

## 工作边界

正触发：仿冒、虚假宣传、诋毁、网络干扰等经营者间争议，需要定性、竞争关系和救济接口。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 普通消费者主请求（消保或 C 端虚假宣传包）；
- 商业秘密权利本身或构成要件终局（知识产权）；
- 混淆仿冒专项深挖（转 评估混淆与仿冒）；
- 商业诋毁专项（转 评估商业诋毁）；
- 经营者间虚假宣传专项（转 评估经营者间虚假宣传）；
- 网络不正当竞争专项（转 评估网络不正当竞争）；
- 商标权属或近似比对终局（知识产权）；

本任务不替代各专项终局，不把发送律师函写成已构成侵权，不定罪。

## 建立评估坐标

确认：主张方或被指方；双方经营者身份；被指行为；商品或服务重叠；事件日（决定 2019 或 2025 反不正当竞争法文本）。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` `D#` `A#` `R#` `C#` `L#` `I#` `G#` `Q#` `V#` `E#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

`search_law` 核验反不正当竞争法现行文本。事件日在 2025-10-15 前改核 2019 文本；之后核验 2025 修订。工具不可用时继续行为事实；条文效果字段停止。

工具不可用时继续事实、主体、程序文书状态和问题清单；法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　竞争关系与适用文本

先确认经营者间竞争关系或扰乱竞争秩序事实。按事件日锁定 2019 或 2025 文本。

### 节点 2　行为类型分流

混淆、虚假宣传、诋毁、商业贿赂、网络干扰分列。专项可转出深挖。

### 节点 3　混淆或误导检验

有一定影响、混淆可能性或引人误解只做总览，不代替专项。

### 节点 4　停止与赔偿接口

停止、消除影响、赔偿分列。未知损失不写零。

### 节点 5　知识产权与消保分流

权属和侵权比对转知识产权。普通消费者转 C 端。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或做法无法建立；用户坚持伪造、隐匿、威胁、违法取证或指导规避执法。
- `字段停止`：法域、日期、文书送达、申报标准、动态规则未核验。
- `目标停止`：主目标已变为相邻原子或相邻领域的终稿。
