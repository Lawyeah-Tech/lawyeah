# 边界与路由

## 正触发

拟撤回申报或为竞争审查调整控制权安排。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 交易整体、融资、交割 | 投资并购 |
| 救济方案 | 准备附加限制性条件方案 |
| 已实施抢跑 | 评估违法实施集中 |
| 改 SPA 全文 | 审查起草搁置 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 融资与交割 | 投资并购 |

一般商业做法夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。知识产权侵权主轴、投并购交易文件只分流。

## 易混

先撤申报再改控制权是正触发。把整轮融资文件重做是负触发。
