# 准备撤回申报或竞争专项结构调整

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 2008 年申报门槛或 2007 年反垄断法条号当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的申报方立场下，形成“撤回或竞争专项结构调整意见”：撤回后果、再申报风险、竞争专项调整意见。

`depends-on` 为空。接受用户或律师提供的等价申报状态和拟调整的控制权安排。

## 工作边界

正触发：拟撤回申报，或仅为竞争审查调整控制权安排。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 交易整体、融资、交割清单（投资并购）；
- 附加限制性条件方案为主（转 准备附加限制性条件方案）；
- 改写 SPA/SHA 全文（审查起草搁置）；
- 已交割后的抢跑评估（转 评估违法实施集中）；

本任务不设计融资交割，不出可签署交易文件，不保证撤回后不再被查。

## 建立评估坐标

确认：申报状态；拟撤回原因；拟调整的控制权或交易步骤；是否已实施集中；再交割时间表。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` `D#` `A#` `R#` `C#` `L#` `I#` `G#` `Q#` `V#` `E#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

`search_law` 核验审查规定关于撤回申报、重新申报和实施禁止。工具不可用时继续事实；撤回法律效果字段停止。

工具不可用时继续事实、主体、程序文书状态和问题清单；法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [撤回方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　申报与实施状态

已立案、已进一步审查、已实施分列。已实施不得把撤回写成洗白。

### 节点 2　撤回后果

审限结束、材料效力、是否视为未申报。不得预测再报必过。

### 节点 3　再申报风险

事实变化、控制权是否仍构成集中、第四条残留。

### 节点 4　竞争专项调整

只评论控制权是否仍构成集中或是否降低排除限制竞争效果。股权对价和融资归投资并购。

### 节点 5　下一步

撤回函草案边界。交易文件不实施。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或做法无法建立；用户坚持伪造、隐匿、威胁、违法取证或指导规避执法。
- `字段停止`：法域、日期、文书送达、申报标准、动态规则未核验。
- `目标停止`：主目标已变为相邻原子或相邻领域的终稿。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
