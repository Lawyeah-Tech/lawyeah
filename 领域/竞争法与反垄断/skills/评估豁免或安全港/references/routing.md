# 边界与路由

## 正触发

主张效率、中小企业或市场份额安全港。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 协议要件未识别 | 评估垄断协议 或 assess-vertical-restraint |
| 写成必然不予禁止 | 本任务拒绝该写法 |
| 中止调查承诺 | 申请中止调查承诺 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 国家产业政策文件本身 | 公平竞争审查或行政垄断，视主体 |

一般商业做法夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。知识产权侵权主轴、投并购交易文件只分流。
