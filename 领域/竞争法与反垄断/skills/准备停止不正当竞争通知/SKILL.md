# 准备停止不正当竞争通知

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 2008 年申报门槛或 2007 年反垄断法条号当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的主张方立场下，形成“停止不正当竞争通知包”：发送前停止通知、事实回链、送达留痕。

`depends-on` 为空。接受用户提供的等价行为评估、证据和相对方地址。

## 工作边界

正触发：已决定发函要求停止仿冒、诋毁或网络干扰。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 把发送写成已构成侵权；
- 行政举报函（转 P0 准备向反垄断执法机构举报）；
- C 端大众下架通知且权利已闭合（C 端侵权下架，只分流）；
- 尚未决定主张、只要总评（转评估原子）；

本任务不把发送写成已构成侵权，不保证对方停止，不代发送。

## 建立评估坐标

确认：主张方授权；相对方；行为类型；拟请求停止的具体行为；送达地址。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` `D#` `A#` `R#` `C#` `L#` `I#` `G#` `Q#` `V#` 函稿；`E#` 送达。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

`search_law` 核验停止侵害请求基础；`search_template` 只借律师函栏目。工具不可用时继续事实回链；侵权成立措辞停止。

工具不可用时继续事实、主体、程序文书状态和问题清单；法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [通知方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　发送决定

已决定发函。未闭合的权属争议须在函中保持主张而非认定。

### 节点 2　事实回链

每项被要求停止的行为对应证据编号。无证据的指控删除。

### 节点 3　措辞边界

使用被指、现有材料显示，禁止写成法院已认定。

### 节点 4　送达留痕

地址、方式、拟留存凭证。不代发送。

### 节点 5　与举报起诉接口

函件不是举报也不是起诉。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或做法无法建立；用户坚持伪造、隐匿、威胁、违法取证或指导规避执法。
- `字段停止`：法域、日期、文书送达、申报标准、动态规则未核验。
- `目标停止`：主目标已变为相邻原子或相邻领域的终稿。

## 交付
