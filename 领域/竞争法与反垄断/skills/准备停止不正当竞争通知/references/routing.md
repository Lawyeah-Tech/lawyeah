# 边界与路由

## 正触发

已决定发函要求停止仿冒、诋毁或网络干扰。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 行政举报 | 准备向反垄断执法机构举报 |
| C 端已闭合下架 | C 端侵权下架，只分流 |
| 尚未评估 | 相应评估原子 |
| 把发送写成已侵权 | 禁止该写法 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 商标停止侵权函权利已闭合 | 知识产权或 C 端，视用户 |

一般商业做法夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。知识产权侵权主轴、投并购交易文件只分流。

## 易混

先发函叫停是正触发。这封函一发对方就已侵权是错误写法。
