# 准备平台内竞争投诉下架

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 2008 年申报门槛或 2007 年反垄断法条号当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的主张方立场下，形成“平台内竞争投诉下架包”：平台投诉包、证据链、保全提示。

`depends-on` 为空。接受用户提供的商品链接、侵权对比材料和平台规则。

## 工作边界

正触发：需向电商或应用商店投诉下架仿冒或虚假宣传。

负触发并输出 `触发判定：负触发，未启动本任务`：

- C 端侵权下架包且权利基础已闭合（只分流）；
- 保证下架或保证平台赔偿；
- 行政举报（转 P0 举报原子）；
- 非法登录对方商家后台取证（禁止）；

本任务不保证下架，不替代 C 端已闭合权利包，不代提交。

## 建立评估坐标

确认：平台名称；商品或应用链接；主张的竞争法或权利基础；平台投诉入口规则。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` `D#` `A#` `R#` `C#` 平台规则；`L#` `I#` `G#` `Q#` `V#` `E#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

`search_law` 核验电商法通知删除接口和反不正当竞争停止请求。平台内部细则以用户提供的规则版本为准，不编造。

工具不可用时继续事实、主体、程序文书状态和问题清单；法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [投诉方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　权利或竞争基础

仿冒、虚假宣传、诋毁。权属未闭合须标明主张而非权属终局。

### 节点 2　平台规则匹配

按用户提供的投诉类目，不编造类目。

### 节点 3　证据链

链接、截图时间、对比。易失页面转保全。

### 节点 4　通知删除接口

电商法路径与竞争法请求分列。

### 节点 5　C 端分流

大众消费者下架且权利已闭合只分流。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或做法无法建立；用户坚持伪造、隐匿、威胁、违法取证或指导规避执法。
- `字段停止`：法域、日期、文书送达、申报标准、动态规则未核验。
- `目标停止`：主目标已变为相邻原子或相邻领域的终稿。
