# 边界与路由

## 正触发

向电商或应用商店投诉下架仿冒或虚假宣传。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| C 端已闭合下架 | C 端侵权下架，只分流 |
| 行政举报 | 准备向反垄断执法机构举报 |
| 保证下架 | 不提供 |
| 侵入后台 | 禁止 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| C 端侵权下架 | 只分流 |

一般商业做法夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。知识产权侵权主轴、投并购交易文件只分流。
