# 劳动行政分流方法

判断只用三态。劳动仲裁不是行政诉讼。不重做工伤认定实体。不写劳动仲裁申请。

## 节点 0　先排除仲裁

| 对象 | 处理 |
| --- | --- |
| 劳动仲裁申请、仲裁裁决、仲裁逾期 | 转劳动领域；明确不是行政诉讼 |
| 对仲裁裁决不服 | 民事诉讼，不是本领域 |
| 工伤认定决定 | 行政救济入口留本领域；是否工伤的实体转劳动 |
| 社保经办核定、待遇核定 | 同上 |
| 劳动监察限期改正、处罚 | 程序留本领域；用工违法实体转劳动 |

---

## 节点 1　实体转出

伤害是否因工作、上下班路线、职业病诊断、缴费基数、视同工伤情形：全部转劳动领域。本任务不写认定标准分析，不替代劳动能力鉴定。

---

## 节点 2　程序保留

工伤认定决定、不予认定、社保经办行为，属于行政复议行政诉讼对象。复议机关、被告、起诉期限按本领域期间和资格原子。认为未履行法定职责的，可能复议前置。

---

## 节点 3　监察与处罚

劳动监察责令改正不一定是处罚。处罚走一般处罚程序接口。监察决定的事实证据仍归劳动实体。

---

## 节点 4　禁止

禁止撰写劳动仲裁申请书。禁止告诉用户“对仲裁不服就告人社局行政诉讼”。禁止把用人单位与劳动者的合同争议写成行政不作为。

---

## 节点 5　交接

劳动包：实体要件、证据、仲裁时效。
本包：复议诉讼文书和程序闸。
C 端劳动或处罚救济只分流不回改。

## 节点补强：仲裁排除

1. 劳动仲裁申请、仲裁裁决、对裁决不服：转劳动或民事。劳动仲裁不是行政诉讼。
2. 禁止告诉用户对仲裁不服就告人社局。
3. 工伤认定决定、社保经办行为：复议诉讼入口留本领域；是否工伤、缴费基数转劳动。
4. 劳动监察责令改正不一定是处罚。用工违法实体仍归劳动。
5. 不写劳动仲裁申请，不重做工伤认定实体。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（分流劳动工伤社保行政事项）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（劳动实体材料归劳动、复议诉讼入口归本领域）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：不重做工伤认定实体；不写劳动仲裁申请。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
