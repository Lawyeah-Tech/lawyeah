# 二审应对方法

判断只用三态。不代替主动上诉。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 用户要上诉 | 转 `appeal-judgment` |
| 裁判已生效 | 再审 `unavailable` |
| 一审应诉尚未判决 | 转一审应诉 |
| 第三人二审参加 | 可并行第三人规则 |

---

## 节点 1　窗口

收到上诉状时自身上诉期可能尚未届满。对一审也不服：优先提示上诉原子。只答辩可能无法获得改判利益。

---

## 节点 2　答辩

逐条回应上诉理由。维持一审的事实和法律要点。承认一审笔误与承认实体错误必须分开。

---

## 节点 3　新证据

二审新证据法定条件核验。对对方逾期或违法证据请求不予接纳。己方一审已持有无正当理由未交的，不利。

---

## 节点 4　审理方式

开庭或询问。准备提纲接口转庭审原子，本任务主成果是答辩。

---

## 节点 5　输出

答辩草稿、新证据意见、自身上诉红旗。不保证维持。

## 节点补强：自身窗口

1. 用户要上诉：转上诉原子。裁判已生效：再审 unavailable。
2. 收到上诉状时自身上诉期可能未满，必须红旗，避免只答辩失去请求。
3. 针对上诉请求答辩，不重做一审答辩全文。
4. 对对方新证据发表是否符合二审条件的意见。
5. 不保证维持。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（应对行政诉讼二审）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（二审答辩和补充证据意见）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：不代替主动上诉。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
