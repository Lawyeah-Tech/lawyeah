# 税务分流方法

判断只用三态。整案税务主轴转税务。不作法条税负或稽查实体方案。

## 节点 0　先定性

| 文书 | 处理 |
| --- | --- |
| 税务处理决定、税额核定、纳税调整 | 整案转税务 |
| 纳税担保、税收保全、税收强制 | 整案转税务 |
| 与税款绑定的处罚 | 实体转税务；一般处罚程序可留接口 |
| 市场监管、应急、城管等一般处罚仅提及发票 | 不转税务，除非税局文书为主轴 |

---

## 节点 1　前置提示

纳税争议申请复议往往以缴清税款滞纳金或提供担保为条件。具体条件、例外、可否直接诉讼，一律转税务领域核验，本任务只写“存在前置，本领域不展开”。

---

## 节点 2　可保留

本领域可保留：一般处罚告知、听证申请形式、送达、起诉状格式、共同被告程序。不得在这些接口中写入税率、税基或稽查约谈策略。

---

## 节点 3　禁止

禁止计算应纳税额。禁止设计账外账应对。禁止把缴清写成“先认税再告”。禁止用已失效《合同法》解释税收协议。

---

## 节点 4　交接清单

文书名称文号、税款期间、是否已缴或担保、处罚是否分离、当事人联系人。交给税务领域原子，不在本包继续实体。

---

## 节点 5　输出

分流表、保留接口、禁止展开声明。不写税务复议申请实体理由。

## 节点补强：主轴与禁止展开

1. 税务处理、核定、纳税担保、税收保全强制：整案转税务。
2. 与税款绑定的处罚：实体转税务，一般处罚程序可留接口。
3. 市监等一般处罚仅提及发票：不转税务。
4. 禁止计算税基税率，禁止设计稽查约谈，禁止把缴清写成先认税。
5. 纳税争议前置条件由税务包判断，本领域只提示存在前置。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（分流税务实体争议）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（纳税争议前置与实体转出、一般处罚程序接口）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：不作法条税负或稽查实体方案；整案转税务。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
