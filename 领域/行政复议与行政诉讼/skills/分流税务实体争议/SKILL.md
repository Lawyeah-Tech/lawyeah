# 分流税务实体争议

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1989 年行政诉讼法、1996 年行政处罚法或 1999／2017 年行政复议法当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成纳税争议前置与实体转出说明，以及本领域可保留的一般处罚程序接口。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：处理决定、税额核定、纳税担保、税务处罚混在一起，需要分流。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 作法条税负或稽查实体方案；
- 在本领域写税务复议申请实体理由；
- 把一般市监处罚整案转税务；

不作法条税负或稽查实体方案。整案税务主轴转税务。劳动仲裁不是本分流对象。

## 建立税务分流坐标

确认：使用者与授权；文书种类（处理／处罚／核定／担保）；是否缴清或提供担保；一般程序争点是否独立。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 税务文书；`C#` 规范定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`H#` 分流行；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 仅核验纳税争议复议前置的程序接口条文，不展开税负计算。

工具不可用时继续文书种类和缴清或担保事实登记；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [税务分流方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1 主轴识别

税额核定、处理决定、纳税担保、缴清后复议是税务主轴。
### 节点 2 前置

纳税争议通常须缴清或提供担保后复议，细节整案转税务。
### 节点 3 可保留接口

与税负无涉的一般处罚程序、听证程序可留本领域接口。
### 节点 4 禁止展开

不做法条适用、进项销项、转让定价或稽查应对方案。
### 节点 5 交接

最小交接清单交给税务领域。

## 停止与安全

- `整体停止`：在本领域展开税基计算或稽查实体方案。
- `字段停止`：文书种类不足以判断主轴。
- `目标停止`：主目标已变为税务实体或一般非税处罚评估。

## 交付

严格按 [输出合同](references/output-contract.md) 10节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
