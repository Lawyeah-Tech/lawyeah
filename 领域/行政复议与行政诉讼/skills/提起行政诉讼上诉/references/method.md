# 上诉方法

判断只用三态。不重做一审。不保证改判。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 裁判已生效要再审 | 输出 `unavailable`（P2） |
| 收到对方上诉状 | 转 `respond-appeal` |
| 一审尚未判决 | 转庭审或一审原子 |
| 送达不明却要唯一截止日 | 期限字段停止 |

---

## 节点 1　期限

运行时核验：对判决提起上诉的期限、对裁定提起上诉的期限。作出日不得代替送达日。邮寄提交以邮戳等规则核验。

---

## 节点 2　范围

列一审判项，逐项标服或不服。部分上诉时写明。未上诉判项可能先行生效的风险提示并核验。

---

## 节点 3　理由

事实认定错误、适用依据错误、程序违法、遗漏诉讼请求。每项回链一审材料和法规。禁止仅写“不服，请求改判”。

---

## 节点 4　新证据

二审提交新证据的条件运行时核验。一审已持有而无正当理由未交的，标不利。

---

## 节点 5　草稿

上诉人、被上诉人、一审法院案号、请求、理由。只交草案。不代提交。

## 节点补强：未生效与范围

1. 裁判已生效：普通上诉负触发，再审输出 unavailable。
2. 判决与裁定上诉期限分列。送达不明则截止日停止。
3. 禁止仅写“不服，请求改判”。未上诉判项可能生效。
4. 不把一审起诉状改个标题当上诉状。
5. 收到对方上诉状：转二审应对。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（提起行政诉讼上诉）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（上诉状、范围、期限、理由）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：不重做一审。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
