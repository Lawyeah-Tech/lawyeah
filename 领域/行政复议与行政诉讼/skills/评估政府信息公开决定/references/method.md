# 公开决定方法

判断只用三态。不编造国家秘密。不代替提出公开申请。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 尚未提出申请，只要写申请 | 负触发，转 `apply-information-disclosure` |
| 用户要求认定某文件不是国家秘密 | 该结论字段停止；不编造 |
| 档案法、保密法专门程序主导 | 标转出，本任务只留救济接口 |
| 税务内部计税底稿实体 | 转税务 |

---

## 节点 1　对象匹配

1. 申请是否明确到政府信息。要求机关“给个说法”或“解释政策”可能不属于政府信息。
2. 答复是否逐项对应。告知已主动公开的，须核验链接或获取途径是否可用。
3. 信息不存在：审查检索说明是否可回链，不得仅因申请人怀疑就写成机关藏匿。

---

## 节点 2　范围与例外

运行时核验政府信息公开条例第十四条至第十八条等。

| 例外 | 处理 |
| --- | --- |
| 国家秘密 | 不编造解密或定密对错；只评是否书面说明和救济 |
| 商业秘密或个人隐私 | 第三方征求意见程序是否履行 |
| 过程性信息 | 是否仍在讨论、研究或审查中 |
| 内部事务信息 | 是否纯内部管理 |
| 危及国家安全、公共安全、经济安全、社会稳定 | 须有说明，不能空泛套用 |

例外部分成立时，能区分处理的必须区分，不得整份拒绝。

---

## 节点 3　期限

答复期限及延期必须核验。期限届满无答复：不作为路径，并命中复议前置。

---

## 节点 4　救济

2023 年复议法第二十三条：申请政府信息公开，行政机关不予公开的，先复议。复议未完成不得写成应直接起诉。

---

## 节点 5　安全

禁止指导套取国家秘密或他人隐私。禁止把公开申请写成替代卷宗阅卷的唯一合法手段而不提示诉讼中的阅卷权。

## 节点补强：答复形态与前置

1. 尚未提出申请：负触发，转申请原子。
2. 不予公开：主位先复议，不得写成应直接起诉。
3. 国家秘密：不编造解密或定密对错，只评是否书面说明和救济。
4. 信息不存在须有检索说明；仅怀疑藏匿：`依据不足，无法形成结论`。
5. 能区分处理却整份拒绝：程序或适用争点候选。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。
