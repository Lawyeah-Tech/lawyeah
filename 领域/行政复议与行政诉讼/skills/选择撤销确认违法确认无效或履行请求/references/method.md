# 请求选择方法

判断只用三态。确认无效与撤销不得混写为同一效果。不写完整起诉状。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 只要总体评估 | 转总体评估 |
| 请求已选定只要起诉状 | 转 `file-first-instance` |
| 只要赔偿路径 | 转赔偿路径原子 |
| 不作为且未判断前置 | 转不作为或路径原子 |

---

## 节点 1　状态

| 状态 | 主位候选 |
| --- | --- |
| 行为仍有效且有内容可撤销 | `Q-撤` |
| 已执行完毕或不具可撤销内容，仍须评价合法性 | `Q-违` |
| 实施主体不具资格或没有依据等重大且明显违法 | `Q-无` |
| 不履行法定职责 | `Q-履` |
| 处罚明显不当 | `Q-变` 可备位 |

---

## 节点 2　效果差异

撤销：溯及消灭或使行为失去效力，可责令重作。
确认违法：行为效力处理不同，常用于已执行完毕并衔接赔偿。
确认无效：自始无效，标准高于一般违法，不得用一般程序瑕疵冒充。
责令履行：针对不作为或拒绝履行。

---

## 节点 3　互斥与主备

主位一项，备位一项。不得写“请求撤销即确认无效”。法院释明变更请求的风险单独一行。

---

## 节点 4　期限

普通撤销、确认违法受起诉期限约束。确认无效是否不受普通期限约束必须运行时核验，未核验字段停止，不得写成“无效就没有期限”。

---

## 节点 5　输出

比较表、主备位、期限影响。不写起诉状全文。

## 节点补强：状态决定主位

1. 仍有可撤销内容：主位撤销。已执行完毕：主位确认违法。
2. 确认无效标准是重大且明显违法，一般程序瑕疵不得冒充。
3. 确认无效与撤销不得写成同一效果。可主备位。
4. 确认无效是否受普通起诉期限约束必须核验，未核验不得写成没有期限。
5. 不写完整起诉状。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（选择撤销确认违法确认无效或履行请求）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（请求比较、互斥、期限影响、释明风险）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：不写完整起诉状；确认无效与撤销不得混写为同一效果。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
