# 选择撤销确认违法确认无效或履行请求

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1989 年行政诉讼法、1996 年行政处罚法或 1999／2017 年行政复议法当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的主张方立场下，形成请求比较、互斥、期限影响和释明风险。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：已决定走复议或诉讼，需要选定请求类型。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 写完整起诉状；
- 把确认无效与撤销写成同一效果；
- 只要总体评估；

不写完整起诉状。确认无效与撤销不得混写为同一效果。

## 建立请求选择坐标

确认：使用者与授权；行为是否仍可撤销；是否已执行完毕；主体资格或依据是否明显缺失；是否不作为；期限状态。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 文书；`C#` 规范定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验行政诉讼法第七十条至第七十八条请求类型和确认无效的重大明显违法标准。

工具不可用时继续行为状态、执行情况和期限事实登记；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [请求选择方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1 行为状态

仍存在可撤销内容、已执行完毕、自始明显无效、不履行职责分列。
### 节点 2 请求比较

撤销、确认违法、确认无效、责令履行、变更分列效果。
### 节点 3 互斥

确认无效与撤销不得写成同一效果。可主备位。
### 节点 4 期限影响

确认无效是否受普通起诉期限约束必须核验。
### 节点 5 释明风险

请求选错可能被释明或驳回，本任务不写诉状。

## 停止与安全

- `整体停止`：把一般违法写成确认无效并拒绝分列。
- `字段停止`：确认无效标准或期限规则未核验。
- `目标停止`：主目标已变为完整起诉状。

## 交付

严格按 [输出合同](references/output-contract.md) 10节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
