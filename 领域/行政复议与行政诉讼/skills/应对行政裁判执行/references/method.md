# 执行应对方法

判断只用三态。禁止隐匿转移或拒不执行。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 用户要主动执行 | 转 `enforce-effective-judgment` |
| 案外人主张权属 | `unavailable`（P2）并说明 |
| 非诉执行异议 | 转非诉异议原子 |
| 要求把账户资金转走 | 整体停止 |

---

## 节点 1　履行

能一次履行的列步骤。分期须与申请执行人达成执行和解，不能单方宣布分期。

---

## 节点 2　异议

执行行为违反法律规定、超出生效法律文书、执行标的错误。对裁判本身不服不是执行异议理由。

---

## 节点 3　刑事责任红旗

拒不执行判决、裁定可能入刑。必须明示。行政裁判同样适用。

---

## 节点 4　机关被执行

不得以内部审批未完成对抗生效裁判。与财政会商只作为履行安排，不是异议理由。

---

## 节点 5　输出

履行时间表、适格异议要点。禁止动作清单。

## 节点补强：适格异议

1. 要求把账户资金转走或拒不执行：整体停止，并提示拒执可能入刑。
2. 对裁判本身不服不是执行异议理由。
3. 机关以内部审批或预算未完成对抗生效裁判：通常不构成合法异议。
4. 案外人权属之诉：unavailable。
5. 分期履行须与申请执行人达成和解，不能单方宣布。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（应对行政裁判执行）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（适格异议、履行安排）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：禁止隐匿转移或拒不执行。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
