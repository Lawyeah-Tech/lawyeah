# 强制评估方法

判断只用三态。不保证停止执行或解除查封。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 刑事搜查、扣押、冻结 | 转刑事 |
| 税收保全、税收强制执行实体 | 转税务 |
| 机关要向法院申请非诉执行 | 转 `apply-non-litigation-enforcement` |
| 用户只要停止执行申请书 | 转 `apply-stay-of-execution` |

---

## 节点 1　定性

1. 行政强制措施：暂时性限制，目的是制止、防止证据损毁或控制危险。
2. 行政强制执行：对已生效行政决定的履行强制。
3. 行政处罚的暂扣许可证不是查封。扣押财物清单必须单独登记。
4. 即时强制须有法律依据，不得用一般调查权冒充。

---

## 节点 2　措施程序

运行时核验行政强制法第十八条至第三十三条。

| 要件 | 缺失效果 |
| --- | --- |
| 实施前报告批准 | 程序争点 |
| 两名以上执法人员并出示证件 | 程序争点 |
| 通知当事人到场、告知理由权利 | 程序争点 |
| 制作现场笔录和财物清单 | 财物范围待核 |
| 通知家属或所在单位（限制人身） | 独立争点 |

查封扣押冻结期限一般为三十日，延长须依法批准，上限须核验。超期未办理解除：现有依据支持违法候选。

---

## 节点 3　执行程序

1. 须有已生效且具有可执行内容的行政决定。处罚起诉期限未满，不得把自行强制写成已合法。
2. 催告、听取陈述申辩、强制执行决定、实施分列。
3. 加处罚款或滞纳金是否以本金为上限，运行时核验。
4. 行政机关没有自行强制执行权的，应申请法院执行，不得写成可以自行拍卖。

---

## 节点 4　权利与停止

1. 陈述、复议、诉讼、赔偿接口分列。
2. 复议或诉讼期间原则上不停止执行。停止执行须另评难以弥补损失和公共利益。
3. 不得指导转移被查封财物或破坏封条。

---

## 节点 5　输出

种类、程序、期限、催告、停止执行接口。不写非诉执行申请，不写停止执行终稿。

## 节点补强：措施与执行不得混写

1. 查封扣押冻结是措施，划拨拍卖是执行。混写则种类行停止重分。
2. 措施期限及延长未核验：超期结论停止，仍列已知起止日。
3. 机关无法律赋予的自行强制权却准备自行拍卖：现有依据不支持已合法执行。
4. 刑事名义搜查扣押：整案转刑事。
5. 用户要停止执行申请书或非诉执行申请：目标停止，转对应原子。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。
