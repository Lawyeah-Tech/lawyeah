# 应对行政复议被申请

## 任务目标

在明确、无利益冲突的被申请人立场下，形成答复书、证据依据和不得事后取证红旗。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：机关收到复议申请需要依法答复和举证。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 申请人侧复议申请；
- 行政诉讼一审答辩（转 `应对行政诉讼一审`）；
- 事后自行收集证据补卷；

与原告侧复议申请权限不同。被申请人不得事后自行取证。

## 建立复议答复坐标

确认：使用者与授权；复议机关通知；答复期限；原行为卷宗是否完整；是否共同被申请人。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 复议通知与原卷；`C#` 规范定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`H#` 答复点；`K#` 期限；`V#` 稿件版本；`E#` 送达凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1989 年行政诉讼法、1996 年行政处罚法或 1999／2017 年行政复议法当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验 2023 年复议法被申请人答复期限和不得自行取证条款。

工具不可用时继续通知送达日、原卷目录和申请人请求登记；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [复议答复方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1 答复期限

自收到申请书副本之日起的答复期运行时核验。送达不明则截止日停止。
### 节点 2 卷宗

提交当初作出行为的证据和依据。不得现补现场笔录。
### 节点 3 答复结构

承认、否认、法律依据、程序说明。不攻击申请人人格。
### 节点 4 取证禁令

被申请人不得自行向申请人和其他有关单位收集证据。
### 节点 5 与诉讼应诉区分

本任务不写行政诉讼答辩状。

## 停止与安全

- `整体停止`：设计事后取证或隐匿卷宗。
- `字段停止`：答复期限未核验；送达不明。
- `目标停止`：主目标已变为诉讼应诉或申请人侧申请。
