# 复议答复方法

判断只用三态。不得事后自行取证。不保证维持。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 用户是申请人只要申请书 | 转 `file-reconsideration` |
| 已进入诉讼 | 转 `defend-first-instance` |
| 要求现在补做检查笔录入卷 | 拒绝并红旗 |
| 纳税争议复议答复实体 | 转税务 |

---

## 节点 1　期限

运行时核验 2023 年复议法被申请人提交书面答复和作出行为的证据、依据的期限。以收到副本之日起算。逾期不答复的后果（可能被视为没有证据）必须写明。

---

## 节点 2　材料范围

当初收集的证据、依据文本、程序文书。作出之后新取证不得作为维持原行为的依据。复议程序中补充的说明不是新证据。

---

## 节点 3　答复书

申请人请求逐项回应。主体、事实、依据、程序、裁量分列。发现原行为确有问题：依法自我纠正接口，不指导隐瞒。

---

## 节点 4　禁令

不得自行向申请人、第三人取证。不得隐匿不利卷宗。不得伪造签字。

---

## 节点 5　输出

答复草稿、证据目录、红旗。不代提交。不写诉讼答辩。

## 节点补强：答复与禁令

1. 用户是申请人：转复议申请原子。
2. 以收到申请书副本之日起算答复期。逾期可能视为没有证据。
3. 不得自行向申请人或其他单位收集证据。不得补做现场笔录入卷。
4. 发现原行为确有问题：自我纠正接口，不指导隐瞒。
5. 本任务不写行政诉讼答辩状。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（应对行政复议被申请）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（答复书、证据依据、不得事后取证红旗）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：与原告侧复议申请权限不同。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
