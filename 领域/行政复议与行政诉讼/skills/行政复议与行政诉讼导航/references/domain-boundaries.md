# 行政复议与行政诉讼领域边界

本表只说明归属。每次路由先核对 [当前能力地图](capability-map.md)；未安装入口输出 `unavailable`。

| 相邻 | 本包入口 | 转出 |
| --- | --- | --- |
| 合同审查与起草 | 无。未成争只要许可申请或出稿：本窗搁置，只说明不实施 | 审查起草领域（用户单独策略） |
| 刑事 | 行政处罚、行政强制措施的救济 | 刑事拘留、逮捕、侦查措施、定罪与辩护 |
| 税务 | 一般处罚程序和救济方法接口 | 税务处理、税额核定、纳税担保、纳税争议实体 |
| 竞争法 | 行政救济程序接口 | 经营者集中申报、垄断协议、滥用支配地位调查实体 |
| 环境能源 | 行政复议诉讼程序接口 | 环评、排污许可、资源权利实体设计 |
| 劳动 | 工伤、社保、劳动监察决定的复议诉讼文书 | 工伤认定、社保待遇、劳动监察的劳动实体条件和证据；劳动仲裁申请和仲裁裁决救济不是行政诉讼 |
| 知识产权 | 一般处罚或许可的救济程序 | 商标评审、专利复审无效 |
| 房地产 | 征收程序违法的救济入口 | 补偿标准实体、安置方案、C 端征地材料整理 |
| 合同争议 | 行政协议的行政路径 | 一般民事合同履行解除 |
| C 端处罚救济 | 专业评估或陈述 | 大众第一轮止损标签 |
| C 端网上立案／民事答辩 | 专业行政起诉或应诉 | 普通民事立案或答辩 |

一般处罚夹带专项背景时，专项段只分流，不把专项实体规则写入本包结论。
