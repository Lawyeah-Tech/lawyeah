# 当前能力地图

当前安装包是（P0 + P1）。只推荐下表已安装原子 Skill。未列入的 P2 必须输出 `unavailable`，不得由名称相近的 Skill 代做。

## P0 主干

| 用户当前目标 | 原子 Skill | 独立成果 | 不包含 |
| --- | --- | --- | --- |
| 已成争，要总图再决定陈述、复议或起诉 | `评估行政行为争议` | 行为定性、请求抗辩、论坛期限、金额区间、缺口和下一步 | 发送版陈述申辩、复议申请、诉状、精算终稿 |
| 要选先复议还是直接起诉，或判断是否前置 | `评估复议或诉讼路径` | 前置命中、受理互斥、复议机关层级、失败后起诉接口 | 完整复议申请包、完整起诉包 |
| 利害关系不明，或复议维持后不知告谁 | `评估原告资格与被告` | 资格、被申请人／被告、共同被告、追加风险 | 起诉状终稿 |
| 已收到告知，要在决定作出前交陈述申辩 | `准备陈述申辩` | 发送前陈述申辩、权利清单、不得因申辩加重 | 听证材料终稿、把陈述写成已减轻 |
| 已决定申请复议 | `申请行政复议` | 复议申请书、复议机关、请求、证据目录 | 代提交；法院已受理同一行为 |
| 要可复核的罚款、没收或行政赔偿数字 | `测算罚款没收与行政赔偿` | 分项测算、法定幅度接口、互斥抵扣 | 认定处罚或赔偿已成立、唯一必得总额 |
| 单独盘点举证责任和补证 | `建立行政争议证据案卷` | 要件、被告举证、材料矩阵、合法补证 | 策略总图、诉状、违法取证 |
| 仍可谈，要底线和法定可调范围 | `谈判行政争议协调方案` | 让步表、可协调事项、执行力提示 | 已签字协议、就处罚合法性违法调解 |
| 决定起诉且前置已完成或依法可不前置 | `提起行政诉讼一审` | 起诉状、请求、被告、管辖、证据目录 | 代提交；前置未完成 |
| 已收到起诉状，要首次应诉 | `应对行政诉讼一审` | 十五日举证卡、答辩草稿、共同被告分工 | 民事答辩包、主动起诉、隐匿卷宗 |
