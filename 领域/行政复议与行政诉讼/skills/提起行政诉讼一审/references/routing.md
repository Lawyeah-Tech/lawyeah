# 边界与路由

## 正触发

已决定起诉，前置已完成或不适用，复议未挡住诉讼。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 前置未完成 | `评估复议或诉讼路径` 或 `file-reconsideration` |
| 复议申请 | `申请行政复议` |
| 应诉 | `应对行政诉讼一审` |
| 资格或被告专项 | `评估原告资格与被告` |
| 民事网上立案 | C 端 011，只分流 |
| 单独赔偿诉讼 | `单独提起行政赔偿诉讼`（未安装则本任务可列一并赔偿接口） |

## 易混

复议维持后只想告原机关：本任务仍可正触发，但必须把复议机关列为共同被告或写明追加后果。
