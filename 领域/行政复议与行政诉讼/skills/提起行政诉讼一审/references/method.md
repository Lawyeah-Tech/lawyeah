# 起诉方法

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然立案或必然停止执行。

## 节点 0　前置、互斥和分流

1. 2023 年复议法第二十三条情形命中，且复议未作出决定、未被不予受理或驳回、期限未届满：负触发，转路径或复议申请原子。
2. 复议已依法受理：负触发。
3. 刑事、税务实体、竞争环境实体、劳动实体：整案转出。
4. 已有立案通知或案号：停止生成起诉入口材料。

前置不适用或已完成（复议决定送达、不予受理、驳回、超期不答）须有可回链证据。

## 节点 1　当事人和请求

原告须有利害关系。被告按行政诉讼法第二十六条和行诉解释第一百三十四条确定。复议维持：原机关与复议机关共同被告；只列一个必须写追加风险。

请求分列：

- `P-撤` 撤销或部分撤销；
- `P-违` 确认违法；
- `P-无` 确认无效；
- `P-履` 责令履行；
- `P-变` 变更明显不当处罚；
- `P-赔` 一并赔偿；
- `P-审` 一并审查规范性文件。

确认无效与撤销不得写成同一效果。未确认违法的赔偿按一并请求处理，不得假装已可单独提起赔偿诉讼。

## 节点 2　管辖

分列：最初作出机关所在地、复议机关所在地、不动产所在地、专属管辖、级别管辖、跨行政区划或集中管辖待核。连结点不足不选定唯一法院。协议管辖对行政诉讼原则上不适用，不得照搬民事协议管辖。

## 节点 3　期限

起诉一般期限、复议决定送达后期限、前置失败十五日、未告知起诉期限最长一年、不作为履行期满后六月、不动产二十年或其他最长保护期分列。运行时核验现行条号。送达不明则期限字段停止。不输出未核验的唯一截止日。

## 节点 4　证据和红旗

证据按请求绑定。停止执行、财产保全只做红旗。诉讼期间原则上不停止执行。

## 节点 5　草稿

按起诉状法定事项组织。只交付草案和核验清单。网上立案渠道可提示，但不得改写成 C 端民事网上立案成果。不代提交。
