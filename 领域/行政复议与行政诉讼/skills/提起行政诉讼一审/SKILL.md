# 提起行政诉讼一审

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1989 年行政诉讼法、1996 年行政处罚法或 1999／2017 年行政复议法当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的原告立场下，形成可复核、不代提交的“行政诉讼一审起诉包”：起诉状草稿、分项诉讼请求、被告和共同被告、管辖连结点、证据目录和保全或停止执行红旗。

`depends-on` 为空。

## 工作边界

正触发：已决定向人民法院提起行政诉讼一审，且复议前置已完成或不适用，复议亦未被依法受理挡住起诉。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 复议前置命中且复议未结束、未被依法排除；
- 复议已依法受理同一行为；
- 只要总体评估、陈述申辩或复议申请；
- 用户实为被告；
- 普通民事网上立案。

C 端网上立案只分流：行政诉讼不走民事立案包，不回改 011。

本任务不代提交，不保证立案或胜诉，不把起诉写成已停止执行。

## 建立起诉坐标

确认：原告；被告；复议经过及结果；文书送达；拟请求；法域；是否已有案号。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关文书；`C#` 规范定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`P#` 诉讼请求；`J#` 管辖连结点；`V#` 稿件版本；`E#` 送达／受理凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验起诉条件、前置、被告、管辖和起诉期限；`search_template` 只借起诉状栏目。工具不可用时继续主体、事实和目录；请求法律结论、管辖选定和期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [起诉方法](references/method.md) 为准。

### 1. 前置和互斥闸

前置未完成或复议已受理：负触发。

### 2. 原告、被告和请求

撤销、确认违法、确认无效、履行、变更、赔偿分列。复议维持必须评估共同被告。

### 3. 管辖连结点

被告所在地、复议机关所在地、不动产所在地、级别管辖分列。材料不足不选定唯一法院。

### 4. 证据目录与停止执行红旗

不写停止执行或保全申请终稿。

### 5. 起诉状草稿与提交核验

不代提交。不改写成民事网上立案包。

## 停止与安全

- `整体停止`：伪造文书；前置未完成仍要求包装成可诉。
- `字段停止`：前置、被告、管辖、送达未核验。
- `目标停止`：主目标已变为复议申请或应诉。
