# 边界与路由

## 正触发

已确认违法且义务机关已处理或逾期，要单独提起行政赔偿诉讼。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未确认违法 | `评估行政赔偿路径` 或一并请求 |
| 义务机关申请 | `向赔偿义务机关申请赔偿` |
| 刑事赔偿 | 刑事领域 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 刑事拘留、逮捕、搜查扣押、定罪或辩护 | 刑事领域 |
| 税务处理、税额核定、纳税担保、缴清或提供担保后复议 | 税务领域 |
| 经营者集中、垄断协议、滥用市场支配地位调查实体 | 竞争法领域 |
| 环评批复实体、排污许可实体、资源权利设计 | 环境能源领域 |
| 工伤认定条件、劳动能力鉴定、社保待遇核定、劳动监察实体证据 | 劳动领域 |
| 商标评审、专利复审无效宣告 | 知识产权领域 |
| 尚未成争，只要代办许可或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

一般处罚或一般强制夹带专项背景时，专项段只分流，不把专项实体规则写入本任务结论。劳动仲裁不是行政诉讼，不得把劳动仲裁申请改写成行政起诉。

## 易混

单独赔偿诉讼不是重新打一场撤销之诉。没有先行处理不要硬写可立案。
