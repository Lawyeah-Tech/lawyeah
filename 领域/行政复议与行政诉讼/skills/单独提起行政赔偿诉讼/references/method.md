# 单独赔偿诉讼方法

判断只用三态。未确认违法不得包装成可单独提起。未知不写零。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 未确认违法 | 转路径原子或一并请求；本任务负触发 |
| 尚未向义务机关请求且依法应先行 | 转 `apply-agency-compensation` |
| 刑事赔偿 | 转刑事 |
| 只要精算 | 转测算原子 |

---

## 节点 1　核验

确认文书（判决、复议决定、义务机关确认）必须可回链。处理决定或逾期期满事实必须可回链。缺一则入口不打开。

---

## 节点 2　诉状结构

原告、被告义务机关、请求分项、事实、证据、管辖。确认无效或撤销主诉已结束的，只写赔偿，不重审行为合法性全部争点，但可引用确认理由。

---

## 节点 3　金额

人身自由、医疗、误工、财产直接损失分列。标准核验。禁止输出唯一必赔总额。

---

## 节点 4　管辖期限

赔偿诉讼管辖和起诉期限运行时核验。未核验字段停止。

---

## 节点 5　输出

材料包草案。不代提交。不保证获赔。

## 节点补强：入口闭合

1. 未确认违法：负触发，转路径或一并请求。
2. 依法应先行处理且尚未申请：转义务机关申请原子。
3. 确认文书和处理或逾期事实必须可回链，缺一则入口不打开。
4. 分项请求，禁止唯一必赔总额。刑事赔偿转刑事。
5. 不代提交，不保证获赔。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（单独提起行政赔偿诉讼）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（赔偿起诉材料、先行处理核验）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：未确认违法应视为一并提起；刑事赔偿转刑事。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
