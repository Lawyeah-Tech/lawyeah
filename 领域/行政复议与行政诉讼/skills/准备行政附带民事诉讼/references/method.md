# 附带民事方法

判断只用三态。与单独民事起诉不同。劳动仲裁不是行政诉讼。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 无行政行为，只要民事 | 转合同或相应民事领域 |
| 工伤赔偿、劳动关系 | 劳动领域；应仲裁的不得附带 |
| 只要行政起诉 | 转 `file-first-instance` |
| 刑事附带民事 | 转刑事 |

---

## 节点 1　条件

运行时核验行政诉讼法第六十一条：涉及行政许可、登记、征收、征用和行政机关对民事争议所作裁决的行政诉讼，当事人可申请一并解决相关民事争议。

不在列举且无司法解释扩展的，附带入口待核，不硬写可一并。

---

## 节点 2　牵连

民事争议须由被诉行政行为引出。许可颁给第三人导致权属纠纷，是典型牵连。无关的借款纠纷不能搭车。

---

## 节点 3　请求与当事人

行政被告是机关。民事被告可能是第三人。两套请求分列，证据分列。不得把民事违约金写成行政赔偿。

---

## 节点 4　管辖与时效

附带民事一般由受理行政案件的法院一并审理。民事时效与行政起诉期限分列，不混算。已有生效民事裁判的，标既判力缺口。

---

## 节点 5　输出

附带请求、牵连、管辖。不把劳动仲裁请求改写进来。不代提交。

## 节点补强：牵连与排除

1. 无行政行为只要民事：转民事领域。
2. 工伤劳动报酬等应仲裁事项：不得改写成行政附带民事。劳动仲裁不是行政诉讼。
3. 牵连须由被诉行政行为引出。无关借款不能搭车。
4. 行政被告是机关，民事被告可能是第三人。两套请求分列。
5. 民事时效与行政起诉期限不混算。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（准备行政附带民事诉讼）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（附带民事请求、牵连、管辖）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：与单独民事起诉不同。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
