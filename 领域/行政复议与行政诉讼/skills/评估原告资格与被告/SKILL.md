# 评估原告资格与被告

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1989 年行政诉讼法、1996 年行政处罚法或 1999／2017 年行政复议法当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“资格与被告矩阵”：利害关系、申请人／原告适格、被申请人／被告、共同被告、追加风险和第三人接口。

`depends-on` 为空。

## 工作边界

正触发：行政争议已形成，利害关系不明，或复议决定作出后不知告谁。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要起诉状或复议申请终稿；
- 只要总体合法性或只要路径选择；
- 刑事被告人身份或辩护策略；
- 民事原告适格判断。

本任务不写起诉状终稿，不保证受理。

## 建立资格坐标

确认：使用者与授权；拟主张权利的主体；行政行为相对人与其他利害关系人；作出机关、内设或派出机构名义、授权或委托；是否经过复议及复议结果；法域。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 规范定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 资格或被告假设；`V#` 评估版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验行政诉讼法第二十五条、第二十六条及行诉解释第一百三十四条。工具不可用时继续主体表；适格与共同被告结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [资格方法](references/method.md) 为准。

### 1. 专项分流和主体表

刑事身份转出。相对人、相邻权人、公平竞争权人、债权人分列，不自动合并。

### 2. 申请人或原告资格

必须与被诉行为有利害关系。主观不满或公益热情不等于原告资格。公益诉讼转出。

### 3. 被申请人或被告

直接起诉告作出机关。内设机构、派出机构、授权组织、委托机关分列。职权变更后继续行使职权的机关为被告。

### 4. 复议后的被告

维持：原机关与复议机关共同被告。改变：复议机关为被告。复议不作为：可选告原行为或复议不作为。漏列时法院应告知追加。

### 5. 第三人与追加风险

权利受影响的未列主体标第三人接口。不同意追加共同被告的后果必须写明。

## 停止与安全

- `整体停止`：立场不明；冒用他人名义起诉。
- `字段停止`：复议结果、机关职权、利害关系事实未核验。
- `目标停止`：主目标已变为起诉状或复议申请。
