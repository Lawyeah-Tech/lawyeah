# 资格与被告方法

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然受理。不得把刑事被告人规则写入本任务。

## 节点 0　分流

刑事强制措施中的犯罪嫌疑人身份转刑事。民事合同相对人资格转合同争议。行政公益诉讼转出为 `unavailable` 或公益诉讼原子。

## 节点 1　主体表

固定列：`主体｜角色假设｜文书记载名称｜实际作出名义｜利害关系事实｜来源｜判断｜待核`。

相对人、相邻权人、公平竞争权人、受害人、权利承受人分列。名称不一致不合并。未成年人、破产管理人、清算组须标法定代理或代表权限缺口。

## 节点 2　资格

1. 原告须是行政行为的相对人或其他与行政行为有利害关系的公民、法人或其他组织。
2. “有利害关系”需要可回链的权利义务增减事实，不得用情绪或新闻关注代替。
3. 债权人一般不因债务人被处罚而当然取得原告资格；有特定法律保护的除外，须核验。
4. 复议申请人资格与原告资格分列，通常同步但复议法另有规定时运行时核验。
5. 冒用他人名义或未经授权以公司名义：整体停止。

## 节点 3　直接起诉的被告

核验行政诉讼法第二十六条。

| 作出名义 | 被告候选 | 禁止 |
| --- | --- | --- |
| 行政机关 | 该机关 | 告内设科室 |
| 法律、法规、规章授权组织 | 该组织 | 无授权依据仍写成授权 |
| 受委托组织 | 委托的行政机关 | 告受托组织 |
| 两个以上机关共同作出 | 共同被告 | 只告其中一个且不标追加风险 |
| 机关被撤销或职权变更 | 继续行使职权的机关 | 告已撤销印章 |

派出机构以自己名义作出：是否有法律、法规、规章授权必须核验。无授权时被告多为设立该派出机构的机关。

## 节点 4　复议后的被告

| 复议结果 | 被告 | 级别管辖提示 |
| --- | --- | --- |
| 维持原行为 | 原机关 + 复议机关共同被告 | 以原机关确定级别管辖 |
| 改变原行为 | 复议机关 | 以复议机关确定 |
| 既有维持又有改变或不予受理 | 原机关 + 复议机关 | 待核 |
| 逾期未作决定，诉原行为 | 原机关 | — |
| 逾期未作决定，诉复议不作为 | 复议机关 | — |

原告只起诉其中一个共同被告：记录法院应告知追加；不同意追加的，法院应依职权将另一机关列为共同被告。本任务不代替追加申请原子。

“维持”以复议决定主文为准，不得用口头“差不多维持”认定。

## 节点 5　第三人

与被诉行为有利害关系、未列为原被告的主体，标第三人接口。不在本任务制作参加诉讼申请终稿。
