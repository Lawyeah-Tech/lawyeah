# 应对保全方法

判断只用三态。禁止教唆违反裁定。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 用户要主动保全 | 转 `apply-preservation` |
| 用户要主动停止执行 | 转 `apply-stay-of-execution` |
| 要求把钱转走或继续拆除 | 整体停止 |
| 执行阶段查封 | 转执行应对原子 |

---

## 节点 1　遵守

裁定主文逐句拆解。立即停止的行为、不得处分的财产列清单。告知违反后果。

---

## 节点 2　救济

保全裁定复议期限运行时核验。停止执行裁定的复议或复议途径核验。逾期字段停止。

---

## 节点 3　担保

财产保全可用担保置换。担保形式、额度、法院审查。不把提供担保写成必然解除。

---

## 节点 4　错误保全

超范围、重复保全、与本案无关财产：异议理由。申请错误导致损失的索赔接口另列，不在本任务写独立侵权诉状。

---

## 节点 5　输出

遵守清单、复议或担保方案。禁止违反裁定的明示。

## 节点补强：先遵守

1. 要求转移被保全财产或继续被停止行为：整体停止。
2. 先拆裁定主文，列出必须立即停止或不得处分的对象。
3. 担保置换针对财产保全，不一定能推翻停止执行。
4. 复议期限未核验则截止日停止。
5. 主动保全或主动停止执行：负触发。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（应对保全或停止执行裁定）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（复议／担保置换方案）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：禁止教唆违反裁定。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
