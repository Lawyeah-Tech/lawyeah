# 听证申请方法

判断只用三态。申请不是听证材料包。不保证举行。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 已决定出席并要质证提纲 | 转 `prepare-hearing-materials` |
| 复议中申请听证 | 转 `apply-reconsideration-hearing` |
| 决定已送达，听证期已过 | 目标停止，转复议或诉讼入口 |
| 税务听证申请且实体主导 | 转税务 |

---

## 节点 1　权利

告知书明确告知听证权：正触发。未告知但种类可能属于听证范围：申请稿可准备，并红旗机关未告知的程序争点。门槛条文运行时核验。

---

## 节点 2　期限

1. 告知书载明的五日或其他期限，须核验是工作日还是自然日。未核验则截止日停止。
2. 送达日与作出日分列。已读不等于送达。
3. 逾期申请：写明视为放弃听证的风险，不把逾期申请写成必然受理。

---

## 节点 3　申请稿

必备：申请人身份、告知书文号、明确请求举行听证、联系人、日期。不要把完整事实申辩和证据质证塞进申请书。委托手续另附。

---

## 节点 4　放弃与并行

放弃听证不等于放弃书面陈述，也不停止复议或起诉期限。用户误以为“申请听证就不用复议”必须纠正。

---

## 节点 5　提交

按告知书指定渠道。只交付草案和回证设计。不代提交。不写成听证已安排。

## 节点补强：申请期与放弃

1. 告知书送达日与作出日分列。已读不等于送达。工作日或自然日未核验则截止日停止。
2. 逾期申请：写明视为放弃听证，不写成必然受理。
3. 申请书只表达举行听证的意思，不塞完整质证。
4. 放弃听证不停止陈述、复议、起诉期限。
5. 复议听证或诉讼庭审：负触发。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（申请举行听证）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（听证申请稿、期限情景、放弃风险）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：申请本身不是听证材料包。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
