# 不作为方法

判断只用三态。不把民事拖延写成行政不作为。劳动仲裁逾期不是行政诉讼对象。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 对方是民事主体不履行合同 | 转合同争议 |
| 劳动仲裁委逾期未裁 | 劳动领域；劳动仲裁不是行政诉讼 |
| 信息公开申请逾期 | 可转 `assess-information-disclosure`，本任务可留职责接口 |
| 税务审批或退税实体 | 转税务 |
| 刑事控告机关不立案 | 转刑事 |

---

## 节点 1　申请事实

1. 申请送达：提交回执、登记号、邮寄妥投。口头申请须有笔录或可回链事实。
2. 申请事项必须具体。仅有信访或领导信箱投诉，是否构成履职申请待核，不得直接写成已申请。
3. 向无权限机关提交：职责行可能不支持，另列指引义务是否存在。

---

## 节点 2　法定职责

| 来源 | 处理 |
| --- | --- |
| 法律、法规、规章明确职责 | 主位职责候选 |
| 三定方案、权力清单 | 待核，不得单独写成已闭合 |
| 行政协议约定的行政义务 | 转行政协议评估接口 |
| 民事合同、商业承诺 | 现有依据不支持行政不作为 |
| 法定救助或保护职责（依职权） | 须有危险或请求保护事实 |

保护性职责可以不经格式化申请，但须有机关已知或应当知道危险的事实。

---

## 节点 3　期限与形态

1. 法定期限优先。法律未规定的，合理期限须说明计算依据，不能随意写成十五日或六十日。
2. 期限未满：不作为不成立，可准备催告。
3. 明确拒绝：定性为作为，请求可能是撤销拒绝并责令履行，不是单纯确认不作为。
4. 答非所问或仅告知“已转办”：是否构成履行待核。

---

## 节点 4　复议前置与起诉

运行时核验 2023 年复议法第二十三条。认为行政机关未履行法定职责，主位先复议。复议未完成不得写成应直接起诉。起诉期限从履行期限届满之日起算，另转期间原子。

---

## 节点 5　输出

职责、期限、催告、前置命中、请求类型接口。不写复议申请或起诉状。不把信访不答复当然写成可诉不作为。

## 节点补强：申请、职责、沉默

1. 无申请事实且非保护性依职权职责：不作为通常 `现有依据不支持`。
2. 信访或领导信箱是否构成履职申请：待核，不得直接写成已申请。
3. 明确拒绝是作为，请求可能是撤销拒绝并责令履行，不是单纯确认不作为。
4. 认为未履行法定职责：主位先复议。前置未完成不得写成应直接起诉。
5. 劳动仲裁委逾期：劳动仲裁不是行政诉讼，整项转劳动。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。
