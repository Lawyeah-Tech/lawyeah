# 行政协议方法

判断只用三态。不得把已失效《合同法》当作现行规则。一般民事合同整案转出。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 普通买卖、借款、租赁，无行政职权因素 | 转合同争议 |
| 尚未成争只要改协议条款 | 审查起草本窗搁置 |
| 征收补偿协议但主问征收决定程序 | 转征收程序评估 |
| 矿业权、特许的产业准入实体设计 | 相应领域实体转出，本任务留协议救济 |

---

## 节点 1　定性

行政协议典型：政府特许经营协议；土地、房屋等征收征用补偿协议；矿业权等国有自然资源使用权出让协议；其他因行政管理需要与公民、法人订立的协议。

缺行政管理目标和行政职责要素的，现有依据不支持行政协议定性。

---

## 节点 2　路径

1. 对协议提起行政诉讼，适用行政诉讼法和行政协议司法解释。
2. 当事人起诉要求解决的是纯民事权利且协议未被定性为行政协议：转民事。
3. 仲裁协议：行政协议能否仲裁必须运行时核验，未核验不得写成应仲裁或应起诉。
4. 不得建议劳动仲裁解决行政协议。

---

## 节点 3　优益权与违约

| 行为 | 若 | 则 |
| --- | --- | --- |
| 单方变更解除 | 有法律或协议依据且为公共利益 | 合法优益权候选，补偿接口 |
| 单方变更解除 | 无依据或非公共利益 | 违法或违约候选 |
| 相对人不履行 | 协议约定义务明确 | 违约或非诉执行接口待核 |
| 协议本身违法 | 重大且明显违法 | 无效候选 |

现行合同编规则可用于参照的，必须核验后写，禁止引用 1999 年《合同法》作为现行法。

---

## 节点 4　请求

继续履行、解除、确认无效、赔偿或补偿、撤销单方变更决定分列。确认无效与解除不得写成同一效果。

---

## 节点 5　输出

定性、路径、无效或违约分流。不按特许、补偿、矿业权拆三个成果。不写起诉状。

## 节点补强：定性与路径

1. 缺行政管理目标和行政职责：转合同争议，不硬写成行政协议。
2. 征收补偿协议、特许经营、矿业权出让：行政协议候选。
3. 单方变更解除有法律或协议依据且为公共利益：优益权候选加补偿接口；否则违法或违约候选。
4. 仲裁条款对行政协议的效力必须运行时核验，未核验不得写成应裁或应诉。
5. 禁止引用 1999 年《合同法》作为现行依据。劳动仲裁解决不了行政协议。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。
