# 申请行政复议

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1989 年行政诉讼法、1996 年行政处罚法或 1999／2017 年行政复议法当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的申请人立场下，形成可复核、不代提交的“行政复议申请包”：申请书草稿、被申请人、复议机关候选、复议请求、事实理由、证据目录和受理互斥核验。

`depends-on` 为空。

## 工作边界

正触发：已决定申请行政复议，法院尚未依法受理同一行政行为。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要路径判断或只要总体评估；
- 人民法院已依法受理同一行政行为；
- 只要起诉状；
- 纳税争议实体方案；
- 刑事申诉或控告。

本任务不代提交，不保证受理，不把申请写成已中止执行。

## 建立申请坐标

确认：使用者与授权；申请人；被申请人；行政行为文书；是否已起诉；复议机关候选；法域；送达与知悉事实。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关文书；`C#` 规范定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 复议请求；`V#` 稿件版本；`E#` 送达／受理凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验 2023 年复议法第二十条、第二十四条、第二十九条、第三十条；`search_template` 只借申请书栏目。工具不可用时继续主体、事实和目录；复议机关选定、期限和受理结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [复议申请方法](references/method.md) 为准。

### 1. 互斥受理和专项分流

法院已受理则负触发。纳税争议实体转税务。

### 2. 申请人、被申请人和复议机关

资格与层级未闭合时并列候选，不编唯一复议机关。

### 3. 复议请求

撤销、确认违法、确认无效、责令履行、变更、赔偿、附带审查规范性文件分列。

### 4. 期限情景

六十日、未告知最长一年、不可抗力继续计算分列。不输出未核验的唯一截止日。

### 5. 申请书草稿与提交核验

只交付草案和核验清单，不代提交。申请复议不当然停止执行。

## 停止与安全

- `整体停止`：立场不明；伪造文书；法院已受理仍坚持申请。
- `字段停止`：复议机关、期限、送达未核验。
- `目标停止`：主目标已变为起诉或陈述申辩。
