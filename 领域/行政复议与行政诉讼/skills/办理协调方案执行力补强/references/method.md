# 执行力补强方法

判断只用三态。单独谅解无执行力必须明示。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 尚无文本 | 转起草或谈判原子 |
| 已进入执行阶段要执行和解 | 转 `prepare-enforcement-settlement` |
| 劳动争议司法确认 | 劳动领域 |
| 用户坚持私下协议可直接强制执行 | 纠正 |

---

## 节点 1　诊断

`P-谅解`：双方签字，无执行名义。
`P-复议调解`：复议机关主持，效力核验。
`P-诉讼调解书`：法院出具，可执行。
`P-司法确认`：是否适用于本案行政和解须运行时核验，未核验则该路径停止。

---

## 节点 2　比较

每条路径：受理机关、双方同意、可写入的给付内容、对行政行为合法性的处理限度、耗时、失败后能否再诉。

---

## 节点 3　材料

身份证明、授权、和解文本、案件受理证明、履行条款具体到可执行。金额不明不得写零冒充可执行。

---

## 节点 4　失败

对方拒绝确认：保留原复议或诉讼。已撤诉且禁止再诉的风险必须对照撤回原子。

---

## 节点 5　封面强制句

成果必须出现：单独谅解协议通常不具有强制执行力，不能直接申请法院执行。

## 节点补强：路径诊断

1. 成果封面必须出现：单独谅解协议通常不具有强制执行力。
2. 司法确认是否适用于本案行政和解必须核验，未核验该路径停止。
3. 已撤诉再诉限制对照撤回原子。
4. 执行阶段和解转执行和解原子。
5. 金额不明不得写零冒充可执行。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（办理协调方案执行力补强）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（路径比较、材料、失败分流）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：单独谅解无执行力必须明示。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
