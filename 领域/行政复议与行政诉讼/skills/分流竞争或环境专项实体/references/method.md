# 竞争环境分流方法

判断只用三态。不设计竞争申报或环境合规体系。

## 节点 0　竞争

| 信号 | 处理 |
| --- | --- |
| 经营者集中申报、附加限制性条件 | 转竞争法 |
| 垄断协议、滥用市场支配地位调查实体 | 转竞争法 |
| 市监普通广告或质量处罚 | 留本领域处罚评估 |
| 公平竞争审查政策设计 | 转竞争法，本领域不设计 |

---

## 节点 1　环境

| 信号 | 处理 |
| --- | --- |
| 环评批复合法性实体、替代方案 | 转环境能源 |
| 排污许可核发条件、总量、标准设计 | 转环境能源 |
| 普通环境行政处罚程序、听证、复议起诉 | 本领域可保留 |
| 矿业权出让条件设计 | 转环境能源；协议救济可留行政协议接口 |

---

## 节点 2　可保留程序

受案、期限、管辖、被告、复议申请格式、起诉状格式、停止执行、庭审程序。实体构成要件、申报文件、监测方案不写。

---

## 节点 3　禁止

禁止撰写经营者集中申报表。禁止设计环境监测或应急预案体系。禁止用本领域替代专项合规。

---

## 节点 4　混合

同一案件既有普通处罚程序又有专项实体：程序段留，实体段转出，两份交接。

---

## 节点 5　输出

转出理由、保留接口、交接清单。

## 节点补强：专项与普通处罚

1. 经营者集中申报、垄断协议、滥用支配地位调查实体：转竞争法。
2. 环评批复实体、排污许可条件、资源权利设计：转环境能源。
3. 普通环保或广告质量处罚程序：留本领域，不因提及环境或市场整案转出。
4. 禁止撰写申报表或监测应急体系。
5. 混合案件程序段留、实体段转，两份交接。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（分流竞争或环境专项实体）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（实体转出理由、本领域可保留的救济程序接口）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：不设计竞争申报或环境合规体系。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
