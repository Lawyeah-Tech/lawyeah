# 应对行政诉讼一审

## 任务目标

在明确、无利益冲突的被告立场下，形成首次应诉答辩包：答辩兼举证期限卡（作出日与送达日分列）、原告请求拆解、答辩草稿、共同被告分工、规范性文件清单和不得事后补证红旗。

`depends-on` 为空。原告侧材料不得直接当作被告已掌握或已授权使用的秘密。

## 工作边界

正触发：行政机关或共同被告已收到起诉状或应诉通知，需要答辩和十五日举证。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 用户实为原告、只要起诉状；
- 只要管辖异议终稿且无实体答辩；
- 普通民事被告只要大众答辩包；
- 复议被申请人答复（转复议应诉原子，未安装则 `unavailable`）；
- 已决定只谈协调、只要谈判方案。

C 端 012 民事答辩只分流，不回改，不把本技能降成民事答辩包。

本任务不指导隐匿卷宗或事后伪造执法记录，不保证免于缺席或胜诉。行政诉讼原则上无民事式反诉。

## 建立应诉坐标

确认：被告机关；是否复议共同被告；收到的起诉状和应诉通知；每份文书作出日、送达日、送达方式；行政案卷是否完整；法域。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关文书；`C#` 规范定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`K#` 期限卡；`H#` 抗辩；`V#` 稿件版本；`E#` 送达凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1989 年行政诉讼法、1996 年行政处罚法或 1999／2017 年行政复议法当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验行政诉讼法第六十七条十五日举证、共同被告举证分工和补充证据限制。工具不可用时继续文书登记和请求拆解；截止日和合法性结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [应诉方法](references/method.md) 为准。

### 1. 被告立场和材料权限

固定授权。不得隐匿已存在的不利卷宗。

### 2. 十五日举证卡

以收到起诉状副本之日起算。作出日不得代替送达日。送达不明则期限字段停止。

### 3. 请求拆解与管辖红旗

承认、否认、不知、抗辩分列。管辖异议红旗不得吞并本任务，除非用户只要异议终稿。

### 4. 答辩草稿与共同被告分工

原机关与复议机关对原行为合法性共同举证；复议机关对复议决定合法性自行举证。

### 5. 案卷与禁止事项

拒绝隐匿、伪造、事后补做现场笔录。不利证据必须进入最强反方。

## 停止与安全

- `整体停止`：隐匿卷宗；伪造执法记录。
- `字段停止`：送达日不明；举证规则未核验。
- `目标停止`：主目标已变为管辖异议终稿、二审或协调协议。
