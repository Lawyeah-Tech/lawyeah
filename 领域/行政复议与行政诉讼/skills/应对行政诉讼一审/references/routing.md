# 边界与路由

## 正触发

被告已收到起诉状或应诉通知，需要答辩和十五日举证。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 主动起诉 | `提起行政诉讼一审` |
| 只要管辖异议终稿 | `提出行政诉讼管辖异议`（未安装则 `unavailable`，可与本任务并行注明） |
| 复议答复 | `应对行政复议被申请`（未安装则 `unavailable`） |
| 民事答辩 | C 端 012 或合同争议应诉 |
| 只要协调方案 | `谈判行政争议协调方案` |
| 隐匿或伪造卷宗 | 整体停止 |

## 易混

复议共同被告只想让原机关出卷：本任务仍正触发，必须写明共同举证和复议决定合法性由复议机关承担。
