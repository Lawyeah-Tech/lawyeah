# 公开申请方法

判断只用三态。不保证公开。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 已有答复要评估 | 转 `assess-information-disclosure` |
| 要套取国家秘密或他人隐私 | 整体停止 |
| 只要诉讼阅卷 | 提示诉讼权利，不把公开申请当作唯一手段 |
| 税务内部计税过程 | 转税务 |

---

## 节点 1　描述

每项 `Q#` 具体到文件名称、文号、时间段或事项。过宽申请容易被要求补正或被拒。补正次数和期限待核。

---

## 节点 2　机关

制作机关优先。保存机关可并列。向无信息机关提出：可能告知获取途径，不写成违法。

---

## 节点 3　草稿

申请人、身份、信息描述、获取方式、联系方式。用途不是法定拒绝理由，但涉及商业秘密申请须谨慎。只交草案。

---

## 节点 4　期限

答复期限及延期运行时核验。未核验不写唯一到期日。

---

## 节点 5　后续

不予公开、逾期、内容不符：评估原子加复议前置。本任务不写复议申请。

## 节点补强：可识别与后续

1. 已有答复要评估：负触发。
2. 描述须使机关能够识别，禁止“全套卷宗交出来”。
3. 指导套取国家秘密或他人隐私：整体停止。
4. 答复期限未核验不写唯一到期日。
5. 不予公开或逾期：复议前置接口，本任务不写复议申请。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（申请政府信息公开）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（公开申请、范围、答复期限待核）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：不保证公开；后续复议诉讼另项。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
