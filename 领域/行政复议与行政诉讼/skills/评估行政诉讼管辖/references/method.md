# 管辖方法

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。连结点不足不选定唯一法院。不得输出必然立案。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 海事行政、船舶碰撞等海事专属 | 转海事领域 |
| 刑事附带民事 | 转刑事 |
| 只要完整起诉状 | 负触发，转 `file-first-instance` |
| 只要复议机关是谁 | 负触发，转路径或资格原子 |
| 纳税争议该告谁、向哪一级税务复议 | 转税务 |

---

## 节点 1　固定被告结构

1. 未复议：被告一般为作出机关。
2. 复议改变：被告一般为复议机关；级别和地域随复议机关。
3. 复议维持：原机关与复议机关共同被告。级别管辖一般以作出原行为的机关确定；地域可由原机关所在地或复议机关所在地法院管辖。
4. 只列一个共同被告：管辖结论必须附追加风险，不得假装列全。
5. 职权变更、撤销或授权组织：被告待核，管辖连结点随被告待核。

---

## 节点 2　级别

运行时核验行政诉讼法第十四条至第十六条及专门规定。

| 若 | 则 |
| --- | --- |
| 国务院部门作被告 | 中级候选；条号须核验 |
| 县级以上地方政府作被告 | 中级候选；派出机关或部门名义不得直接写成政府 |
| 海关处理或处罚 | 中级候选 |
| 本辖区重大复杂 | 标待核，不因标的额大就写成中级已成立 |
| 复议维持、原机关为县级部门 | 通常基层，复议机关为上级政府不当然升至中级 |

未核验专门规定（专利、反垄断等）时，该专门级别行停止。

---

## 节点 3　地域

1. 原则：最初作出行政行为的行政机关所在地。
2. 经复议：也可由复议机关所在地法院管辖。
3. 限制人身自由：原告所在地与被告所在地可并列候选。行政拘留与刑事拘留必须先分流。
4. 不动产：由不动产所在地法院管辖。土地、房屋征收决定或补偿决定涉及不动产的，按不动产专属处理，不另选原告住所地。
5. 行政诉讼原则上不适用民事协议管辖。管辖协议或合同约定法院不得直接写成已确定。

---

## 节点 4　集中管辖与专门法院

1. 跨行政区划法院、铁路法院集中管辖行政案件：必须核验受案法院所在地的现行指定文件。未核验则 `F-集中` 标待核，并列普通地域候选。
2. 知识产权法院、互联网法院是否管辖本案行政争议，运行时核验，不得默认。
3. 海事法院管辖的海事行政案件整案转海事，本任务不选普通行政庭冒充。

---

## 节点 5　输出与异议接口

| 条件 | 输出 | 禁止 |
| --- | --- | --- |
| 单一连结点已核验 | 主位法院类型＋所在地 | 编具体派出法庭名称冒充已指定 |
| 多个合法连结点 | 并列候选和利弊 | 替用户抢管辖 |
| 对方已提异议 | 连结点反证和期限红旗 | 在本任务写异议书终稿 |
| 用户只要立案包 | 目标停止 | 把管辖表改写成起诉状 |

管辖异议期限运行时核验。过期提出异议的风险必须写明，但不在本任务代替 `object-to-jurisdiction`。
