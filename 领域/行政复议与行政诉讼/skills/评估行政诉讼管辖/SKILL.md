# 评估行政诉讼管辖

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1989 年行政诉讼法、1996 年行政处罚法或 1999／2017 年行政复议法当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成行政诉讼管辖矩阵：级别管辖、地域管辖、复议共同被告情形下的级别与地域、不动产或限制人身自由连结点、跨行政区划或集中管辖待核。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：要选受诉法院，或对方已提出管辖异议，需要可复核的连结点和级别判断。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要完整立案包（转 `提起行政诉讼一审`）；
- 海事行政或海事赔偿专属（转海事）；
- 刑事附带民事；
- 只要复议机关层级（转路径原子）；

不代写完整立案包。海事、刑事附带排除。协议管辖对行政诉讼原则上不适用。

## 建立管辖坐标

确认：使用者与授权；原告所在地；作出机关所在地；复议机关所在地；不动产所在地；是否限制人身自由；是否海关、专利或县级以上政府作被告；法域和可能的集中管辖文件。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或法院文书；`C#` 规范定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`F#` 连结点；`V#` 评估版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验行政诉讼法第十四条至第二十四条、行诉解释关于复议共同被告管辖和跨行政区划法院的条文。

工具不可用时继续机关所在地、复议结果和连结点清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [管辖方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1 被告与复议结果

先固定被告候选和复议是维持、改变还是未复议。复议维持共同被告时，级别一般按原机关确定，地域可为原机关或复议机关所在地。
### 节点 2 级别管辖

基层为原则。国务院部门、县级以上地方政府、海关等中级情形运行时核验。材料不足并列中级与基层候选。
### 节点 3 地域管辖

最初作出机关所在地为原则。限制人身自由可加原告所在地。不动产专属不动产所在地。协议管辖不得照搬民事。
### 节点 4 集中管辖与排除

跨行政区划或集中管辖文件必须当地核验，未核验标待核。海事、刑事附带整案转出。
### 节点 5 异议接口

被告要提管辖异议时只给连结点和期限红旗，不在本任务写异议书终稿。连结点不足不选定唯一法院。

## 停止与安全

- `整体停止`：立场不明；用户坚持用伪造住所地抢管辖。
- `字段停止`：被告未定；所在地不明；集中管辖文件未核验。
- `目标停止`：主目标已变为起诉状或管辖异议书。
