# 提出行政诉讼管辖异议

## 任务目标

在明确、无利益冲突的被告立场下，形成管辖异议书、连结点证据和逾期风险。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：已被起诉，需在法定期限提出管辖异议。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 与实体答辩混写为一份主成果；
- 期限已过仍要求写成必然移送；
- 只要管辖评估不要异议书；

与实体答辩分开。过期停止。

## 建立管辖异议坐标

确认：使用者与授权；应诉通知和起诉状送达日；受诉法院；被告所在地；复议结果；不动产或人身自由连结点。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 应诉文书；`C#` 规范定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`F#` 连结点；`K#` 期限；`V#` 稿件版本；`E#` 送达凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1989 年行政诉讼法、1996 年行政处罚法或 1999／2017 年行政复议法当作现行文本。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验管辖异议提出期限和行政诉讼管辖条文。

工具不可用时继续送达日、受诉法院和连结点登记；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [管辖异议方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1 期限闸

在提交答辩状期间提出。送达不明则期限字段停止。过期则目标停止。
### 节点 2 连结点

级别、地域、专属、集中管辖分列。
### 节点 3 与答辩分离

异议书不写实体合法。实体另转应诉原子。
### 节点 4 异议稿

请求移送或驳回起诉。不保证成立。
### 节点 5 应诉风险

应诉行为是否视为接受管辖须核验。

## 停止与安全

- `整体停止`：期限已过仍伪造未送达以重启异议期。
- `字段停止`：异议期限或管辖规则未核验；送达不明。
- `目标停止`：主目标已变为实体答辩或管辖评估。

## 交付
