# 管辖异议方法

判断只用三态。过期停止。与实体答辩分开。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 只要管辖评估、尚未被诉 | 转 `assess-jurisdiction` |
| 只要实体答辩 | 转 `defend-first-instance` |
| 海事专属 | 转海事 |
| 期限已过仍要“一定能移送” | 目标停止，说明逾期风险 |

---

## 节点 1　期限

运行时核验在提交答辩状期间提出。答辩期以收到起诉状副本之日起算，通常十五日，须核验。逾期提出：异议权消灭情景，本任务不把异议写成仍必然审理。

---

## 节点 2　理由

级别错误、地域错误、违反专属、违反集中管辖指定。复议共同被告的地域选择是法定选择，不得仅因原告选了复议机关所在地就当然异议成立。

---

## 节点 3　与实体分离

异议书只写管辖。承认或否认违法、过罚相当等放入答辩原子。混写导致法院视为已应诉的风险必须提示并核验。

---

## 节点 4　草稿

受诉法院、案号、异议请求、连结点证据、法条待核。只交草案。

---

## 节点 5　输出

异议稿、期限情景、逾期则停止。不保证移送。

## 节点补强：期限与分离

1. 须在提交答辩状期间提出。逾期：目标停止，不写成仍必然审理。
2. 异议书不写实体合法。混写可能视为已应诉，规则核验。
3. 复议共同被告时原告选择复议机关所在地往往合法，不得仅因此主张管辖错误已成立。
4. 送达不明则期限字段停止。
5. 海事专属转海事。只要评估尚未被诉：转管辖评估。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（提出行政诉讼管辖异议）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（异议书、连结点证据、逾期风险）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：与实体答辩分开；过期停止。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
