# 准备陈述申辩

## 任务目标

在明确、无利益冲突的相对人立场下，于决定作出前形成“发送前陈述申辩包”：发送闸、权利清单、陈述申辩稿、不得因申辩加重提示、送达留痕设计。

`depends-on` 为空。本任务只形成待发送材料，不执行发送。

## 工作边界

正触发：已收到行政处罚事先告知或拟处理告知，决定尚未作出，用户需要发送前陈述申辩。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 决定已经作出，本次主成果是复议或起诉；
- 只要听证材料或只要提出听证申请；
- 只要总体评估；
- 刑事讯问或刑事辩护；
- 税务稽查陈述的纳税调整实体方案。

C 端处罚救济只分流：大众只要第一轮止损标签时提及该商品，不回改，不把本技能降成止损清单。

本任务不保证减轻处罚，不把草稿写成已提交或已采纳。

## 建立发函坐标

确认：使用者与授权；告知书文号、拟处罚内容、事实理由依据；告知送达日；陈述窗口；拟签发主体；法域。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关文书；`C#` 规范定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 申辩点；`V#` 稿件版本；`E#` 送达凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。通知状态只用 `草案`、`待发送`、`已发送待证明到达`、`已到达`、`停止`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1989 年行政诉讼法、1996 年行政处罚法或 1999／2017 年行政复议法当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验 2021 年行政处罚法告知、陈述申辩和不得因申辩加重条文；部门程序规定只作窗口线索，与上位法冲突时以上位法为准。工具不可用时继续事实与稿件结构；窗口截止和法律效果字段停止。

## 五个判断节点

执行顺序和停止条件以 [陈述方法](references/method.md) 为准。

### 1. 发送闸

决定已经作出则目标停止。告知未送达或窗口不明则期限字段停止，仍可形成草案。

### 2. 权利清单

陈述申辩权、听证权、申请回避分列。符合听证范围的，不得用本任务吞并听证申请。

### 3. 申辩正文

逐点回应对拟认定事实、证据、依据和裁量。不利事实必须保留。不得教唆否认已知真实事实。

### 4. 不得因申辩加重

正文和封面提示：机关不得因当事人陈述申辩给予更重处罚。不得把该规则写成“申辩后必然减轻”。

### 5. 送达设计与状态词

成果保持 `待发送`。不执行发送，不伪造回证。

## 停止与安全

- `整体停止`：立场不明；用户坚持虚假陈述或伪造证据。
- `字段停止`：告知送达日、窗口规则未核验。
- `目标停止`：主目标已变为听证、复议或起诉。
