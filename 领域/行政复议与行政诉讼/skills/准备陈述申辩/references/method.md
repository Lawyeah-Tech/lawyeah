# 陈述申辩方法

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然减轻或必然不处罚。不得因用户催促把未知写成已提交。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 决定书已送达，本次要复议 | 目标停止，转 `file-reconsideration` |
| 用户只要听证材料或听证申请 | 负触发，转听证原子（未安装则 `unavailable`） |
| 刑事讯问 | 转刑事 |
| 税务纳税调整实体 | 转税务；一般处罚告知可留本任务但实体段停止 |
| 大众只要止损标签 | 分流 C 端处罚救济，不降级本任务 |

## 节点 1　发送闸

1. 必须存在事先告知或等价告知事实。仅有检查通知、询问通知，不是本任务正触发。
2. 决定书已作出并送达：不得再产出发送前陈述终稿。
3. 告知书载明的陈述期限、部门规章的工作日口径必须运行时核验。未核验则截止日字段停止，草案仍可写。
4. 口头告知须有笔录或可回链事实；否则送达标待核。

## 节点 2　权利清单

分列：陈述权、申辩权、听证权、申请回避、委托代理人。听证门槛（较大数额罚款、没收较大数额违法所得或非法财物、降低资质、吊销许可证件、责令停产停业、责令关闭、限制从业等）运行时核验 2021 年处罚法第六十三条。命中听证且用户主成果是听证：目标停止。命中听证但用户只要书面陈述：本任务继续，并红旗告知听证窗口可能并行经过。

## 节点 3　申辩点矩阵

固定列：`Q#｜针对拟认定事实／证据／依据／裁量｜支持材料｜不利事实｜最强反方｜判断｜是否写入正文`。

默认检查：

- 主体是否适格、委托或授权是否可见；
- 事实是否清到可回链的时间、地点、行为、后果；
- 证据是否在告知前形成，有无逼供诱供或单方隐匿；
- 依据是否公布、是否适用于本案；
- 过罚相当、首违不罚、从轻减轻、超过追责时效。

禁止：教唆虚假陈述；删除已知不利事实；把“态度好”写成法定从轻已成立。

## 节点 4　正文与加重禁止

正文只写已支持的主体、告知文号、申辩点、证据清单和请求（不予处罚、从轻、减轻或继续调查）。逐句回链。不得倒签。必须写明：行政机关不得因当事人陈述申辩而给予更重的处罚。该句是程序权利，不是减轻承诺。

## 节点 5　送达设计

按告知书指定渠道、登记地址、备份送达设计。每次尝试预列实施人、版本、渠道、回证。本任务不执行发送。状态保持 `待发送`。已读不等于到达。
