# 调解范围方法

判断只用三态。不代替庭审策略。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 条件已谈拢要文本 | 转起草原子 |
| 只要谈判底线 | 转 `negotiate-settlement` |
| 税务和解或重大税务案件协调实体 | 转税务 |
| 劳动调解或劳动仲裁调解 | 劳动领域；不是行政诉讼调解 |

---

## 节点 1　法定范围

运行时核验行政诉讼法第六十条：人民法院审理行政案件不适用调解。但是，行政赔偿、补偿以及行政机关行使法律、法规规定的自由裁量权的案件可以调解。

自由裁量权案件可调的是裁量结果，不是把无权处罚调成有权。赔偿、补偿、行政协议是明确可调类型。

---

## 节点 2　禁止事项

| 事项 | 判断 |
| --- | --- |
| 处罚是否成立、主体是否适格 | 不可调成合意合法 |
| 许可是否依法应准予 | 不可用和解赋予法定之外的许可 |
| 刑事责任 | 不可调 |
| 国家秘密事项 | 不可调公开 |

---

## 节点 3　效力

法院主持并出具调解书：生效后可执行。
当事人庭外和解后撤诉：执行力弱，转执行力补强原子。
复议调解：核验复议法。

---

## 节点 4　策略边界

本任务只划范围。开庭顺序、证人、质证仍归庭审原子。不同意调解不得写成态度恶劣。

---

## 节点 5　输出

可调表、禁止表、效力。不写协议正文。

## 节点补强：法定范围

1. 行政案件原则上不适用调解。赔偿、补偿、行政协议及法定裁量案件可以调解，条文须核验。
2. 处罚是否成立、主体是否适格，不可调成合意合法。
3. 劳动仲裁调解不是行政诉讼调解。
4. 不同意调解不得写成态度恶劣。
5. 本任务不写协议正文，不代替庭审提纲。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（评估行政诉讼调解范围）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（可调事项、禁止事项、效力）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：不代替庭审策略。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
