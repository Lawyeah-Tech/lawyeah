# 评估行政诉讼调解范围

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1989 年行政诉讼法、1996 年行政处罚法或 1999／2017 年行政复议法当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成可调事项、禁止事项和效力说明。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：法院建议调解，或复议中考虑协调，需要判断能否调、调什么。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 代替庭审策略；
- 条件已谈拢只要协议正文；
- 就处罚合法性本身设计让步；

不代替庭审策略。行政诉讼调解限于法定范围。

## 建立调解范围坐标

确认：使用者与授权；诉讼或复议阶段；争议类型（处罚／赔偿／协议／补偿）；法院或复议机关是否建议调解。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 文书；`C#` 规范定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`M#` 可调项；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验行政诉讼法第六十条调解范围。

工具不可用时继续案件类型和请求登记；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [调解范围方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1 法定可调

行政赔偿、补偿、行政协议等。条文运行时核验。
### 节点 2 禁止

行政处罚合法性、许可赋权合法性原则上不可调成“双方同意合法”。
### 节点 3 附带民事

附带民事请求可调，但不把行政请求一并购销合法性。
### 节点 4 效力

调解书效力与庭外和解分列。
### 节点 5 与庭审关系

评估范围不代替举证质证提纲。

## 停止与安全

- `整体停止`：设计就处罚合法性本身达成“合法确认”的调解。
- `字段停止`：行政诉讼法调解范围条文未核验。
- `目标停止`：主目标已变为协议正文或庭审提纲。
