# 路径方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然受理或唯一复议机关。

`search_law` 返回 1999／2017 年复议法或 1989 年诉讼法时记为噪声。2007 年实施条例与 2023 年复议法冲突的条文记噪声。

## 节点 0　专项分流

| 信号 | 转出 |
| --- | --- |
| 税务处理、税额核定、纳税担保、须缴清或提供担保后复议 | 税务领域，本任务只交最小分流 |
| 刑事拘留、逮捕、侦查措施 | 刑事领域 |
| 竞争调查或环境许可实体方案 | 对应领域 |

当场处罚中的税务当场处罚仍先标税务转出，不在本任务用一般当场处罚规则覆盖纳税争议。

## 节点 1　文书和行为定性

1. 固定文书名称：当场处罚决定、普通处罚决定、许可决定、强制措施通知、履职申请与答复、信息公开答复、征收决定、复议决定。
2. “当场”必须有文书或笔录支持。口头说“当时就罚了”不得写成当场处罚前置已命中。
3. 不作为必须有申请事实或法定保护职责事实。单纯不满监管力度不是不作为。
4. 信息公开“不予公开”与逾期未答复分列；逾期未答复是否落入第二十三条第四项，运行时核验后落判断。

## 节点 2　复议前置

运行时核验 2023 年复议法第二十三条。

| 情形 | 主位路径 | 禁止 |
| --- | --- | --- |
| 当场行政处罚 | 先复议 | 写成可直接起诉 |
| 侵犯已依法取得的自然资源所有权或使用权决定 | 先复议 | 把权属未核验写成已依法取得 |
| 未履行法定职责 | 先复议 | 把民事请求包装成履职 |
| 政府信息公开不予公开 | 先复议 | 把申请公开本身写成复议 |
| 法律、行政法规其他前置 | 先复议或转出 | 用部门规章自创前置 |
| 以上均不命中 | 复议与直接起诉并列 | 强迫先复议 |

前置命中且复议尚未结束：诉讼入口 `现有依据不支持`。前置命中且复议不予受理、驳回或超期不答：打开十五日起诉接口，不自动写成已经可诉，须核验送达日或届满日。

## 节点 3　互斥受理

核验 2023 年复议法第二十九条。

- 复议机关已依法受理：诉讼主位关闭。
- 人民法院已依法受理：复议主位关闭。
- 仅有邮寄底单、窗口照片或口头转述：两条路径都标 `依据不足`，不得写成已受理。
- 重复申请同一行政行为：记录复议法第三十条第七项风险，不指导规避。

## 节点 4　复议机关层级

核验 2023 年复议法第二十四条及国务院部门、垂直管理机关的特别规则。

1. 地方政府工作部门作出的：本级人民政府为默认候选。
2. 下级人民政府作出的：上一级人民政府。
3. 派出机构以自己名义作出的：原则上本级人民政府；直辖市、设区的市部门按区划设立的派出机构，也可由所在地政府管辖。
4. 国务院部门、垂直管理机构：运行时核验特别管辖，不凭记忆写成“一律本级政府”。
5. 材料不足以确定层级：并列候选，不选定唯一机关。

## 节点 5　期限接口与转介

复议申请期、起诉一般期限、复议后起诉期、前置失败十五日分列。本任务不计算唯一截止日。

| 用户下一步 | 转介 |
| --- | --- |
| 写复议申请 | `申请行政复议` |
| 写起诉状且前置已排除或不适用 | `提起行政诉讼一审` |
| 只要合法性总图 | `评估行政行为争议` |
| 不知告谁 | `评估原告资格与被告` |

禁止指导伪造未申请记录以规避互斥受理。
