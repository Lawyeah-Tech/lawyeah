# 评估复议或诉讼路径

## 任务目标

在明确、无利益冲突的单方立场下，形成“复议或诉讼路径矩阵”：行为类型与前置命中、复议机关层级、复议与诉讼互斥受理、期限接口、失败后十五日起诉接口和下一步。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价评估和文书。

## 工作边界

正触发：行政争议已形成，用户需要选择先复议、直接起诉或判断前置是否绊住诉讼。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要总体合法性总图，不要路径判断；
- 只要复议申请书或起诉状终稿；
- 纳税争议实体、缴清税款或提供担保条件（转税务）；
- 刑事强制措施或刑事责任；
- 已决定只交陈述申辩。

本任务不生成可提交复议申请或诉状，不给胜诉率，不选定唯一法院。

## 建立路径坐标

确认：使用者与授权；单方立场；文书种类（当场处罚、资源权属、不作为、信息公开、其他）；作出机关层级；是否已申请复议或已起诉；受理凭证；法域；关键材料及缺失。

同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 规范定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径假设；`V#` 评估版本；`E#` 送达／受理凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验 2023 年复议法第二十三条、第二十九条、第三十四条和行政诉讼法第四十四条；`search_practiced` 补前置反例。工具不可用时继续文书定性与受理状态；前置结论和复议机关字段停止。

## 五个判断节点

执行顺序和停止条件以 [路径方法](references/method.md) 为准。

### 1. 专项分流和文书定性

税务纳税争议、刑事措施先转出。当场处罚、资源权属、不作为、信息公开必须单独标记，不得用“普通处罚”概括。

### 2. 复议前置命中

逐项核验法定前置情形。命中则直接起诉现有依据不支持。未核验则主位未选定。

### 3. 互斥受理

复议已受理不得起诉；法院已受理不得复议。口头声称“已经交了”无受理凭证时，两条路径都标待核。

### 4. 复议机关层级与失败接口

按 2023 年复议法政府管辖规则列候选复议机关，不编唯一机关。前置失败的不予受理、驳回或超期不答，列十五日起诉接口。

### 5. 期限接口和下一步

复议六十日与起诉一般期限分列。路径选定后只转介文书原子，不在本包出稿。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；用户坚持伪造受理凭证。
- `字段停止`：前置规则、复议机关、送达未核验。
- `目标停止`：主目标已变为复议申请或起诉状。
