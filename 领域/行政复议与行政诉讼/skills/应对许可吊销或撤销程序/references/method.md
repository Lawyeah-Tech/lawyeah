# 许可撤销应对方法

判断只用三态。不保证保留许可。不重做申请。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 尚未启动程序，只要评估决定 | 转 `assess-license-decision` |
| 用户要重新申领许可材料 | 审查起草搁置或许可代办转出 |
| 商标专利无效 | 转知识产权 |
| 吊销同时有大额罚款，主成果是处罚陈述 | 转陈述原子，本任务留许可抗辩接口 |

---

## 节点 1　定性

吊销是处罚。撤销针对违法准予。撤回针对合法许可的情势变更。注销是记载事项消灭。用错种类可请求纠正程序。

---

## 节点 2　程序

1. 事先告知事实、理由、依据和权利。
2. 吊销：听证门槛按处罚法核验。
3. 撤销：听取意见。欺骗贿赂事实须有证据，不得仅凭怀疑。
4. 送达不明则期限字段停止。

---

## 节点 3　抗辩矩阵

`Q-主体` `Q-事实` `Q-程序` `Q-种类` `Q-信赖` `Q-过罚` 分列。持证人无过错而机关违法准予：撤销须权衡公共利益，补偿接口打开。持证人欺骗取得：信赖弱。

---

## 节点 4　经营持续

许可证被暂扣或可能立即失效时，不得指导继续无证从事许可事项。过渡安排只列合法选项：暂停、申请临时措施、等待决定。

---

## 节点 5　输出

程序权利清单、抗辩、听证或陈述接口、信赖利益。不保证证件保留。不重做申请卷。

## 节点补强：程序内应对

1. 尚未启动程序只要评估：转许可决定评估。
2. 吊销按处罚听证规则核验；撤销听取意见；注销不是处罚。
3. 不得指导在许可证失效后继续无证经营。
4. 无过错信赖打开补偿接口，不保证保留证件。
5. 用户要重新申领材料：审查起草搁置。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（应对许可吊销或撤销程序）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（程序权利、陈述听证、信赖利益抗辩）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：不重做许可申请；不保证保留许可。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
