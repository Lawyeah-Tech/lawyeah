# 阅卷并拆解行政案卷

## 任务目标

在明确、无利益冲突的单方立场下，形成卷宗目录、缺失项和事后补证红旗。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：已取得或可申请查阅处罚卷、复议卷或诉讼交换的行政案卷。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 完整证据策略（转 `建立行政争议证据案卷`）；
- 庭审质证终稿（转 `质证行政机关证据`）；
- 被申请人要事后自行取证补卷；

不代替完整证据策略。被申请人不得事后自行取证。

## 建立阅卷坐标

确认：使用者与授权；卷宗来源（处罚卷／复议卷／诉讼交换）；已取得页范围；阅卷手续；立场。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 卷面；`A#` 当前一致／承认；`R#` 文书；`C#` 规范定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`F#` 卷宗件；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1989 年行政诉讼法、1996 年行政处罚法或 1999／2017 年行政复议法当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验复议被申请人不得自行取证、被告举证期限和阅卷权利条文。

工具不可用时继续卷宗目录和页码登记；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [阅卷方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1 权限与范围

固定谁有权阅、已阅页码、是否保密卷。不得指导违法复制国家秘密。
### 节点 2 目录还原

按时间还原立案、调查、告知、听证、决定、送达。缺页单独成行。
### 节点 3 形成时间

每份证据形成日与决定日比较。决定后形成的标事后补证红旗。
### 节点 4 被申请人取证禁令

复议中被申请人不得自行取证。诉讼中被告原则上不得自行收集。
### 节点 5 交接

只交目录和红旗。完整举证策略或质证意见另项。

## 停止与安全

- `整体停止`：指导隐匿卷宗或事后伪造入卷。
- `字段停止`：阅卷范围不明；取证禁令条文未核验。
- `目标停止`：主目标已变为完整证据策略或庭审质证。
