# 阅卷方法

判断只用三态。不代替完整证据策略。禁止指导隐匿或销毁卷内不利材料。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 尚未有卷，只要举证责任总表 | 转 `build-evidence-record` |
| 已交换且只要逐份质证 | 转 `challenge-agency-evidence` |
| 被申请人要求“现在补做现场笔录入卷” | 红旗并拒绝设计事后取证 |
| 刑事侦查卷 | 转刑事 |

---

## 节点 1　目录

每件 `F#`：名称、页码、形成时间、制作人、是否签名、与待证事实。无法辨认的影印件标缺口。

---

## 节点 2　完整性

典型缺失：立案审批、检查通知、现场笔录、抽样、鉴定、事先告知、听证、集体讨论、送达回证。缺失不等于必然撤销，但必须列入红旗。

---

## 节点 3　时间红旗

| 若 | 则 |
| --- | --- |
| 证据落款晚于决定日 | 事后补证红旗 |
| 复议期间被申请人新取证 | 不得作为维持依据的候选 |
| 诉讼举证期后提交 | 逾期举证后果接口 |
| 一份笔录多种笔迹倒签 | 真实性争点 |

---

## 节点 4　禁令

复议被申请人不得自行向申请人和其他组织收集证据。被告在诉讼中自行收集的，原则上不得作为认定行为合法的依据。本任务不设计补证方案去规避禁令。

---

## 节点 5　输出

目录、缺失、红旗、最小交接。不写质证终稿，不写举证策略全文。

## 节点补强：目录与时间红旗

1. 看不到的页不得推定内容有利于任何一方。
2. 证据落款晚于决定日：事后补证红旗。
3. 复议期间被申请人新取证：不得作为维持依据的候选。
4. 拒绝设计补做现场笔录入卷。
5. 本任务交目录和红旗，不交质证终稿或完整策略。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（阅卷并拆解行政案卷）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（卷宗目录、缺失、事后补证红旗）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：不代替完整证据策略；被申请人不得事后自行取证。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
