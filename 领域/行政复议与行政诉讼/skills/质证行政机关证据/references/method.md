# 质证方法

判断只用三态。不重做鉴定。不得把原告未反证写成行为合法。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 尚未建证据矩阵 | 可先转 `build-evidence-record`，已有清单则继续 |
| 用户要新的鉴定报告正文 | 负触发 |
| 只要阅卷目录 | 转阅卷原子 |

---

## 节点 1　三性模板

每份 `H#`：名称｜待证事实｜真实性｜合法性｜关联性｜最强反方｜是否申请排除或补证。

“全部不认”无具体理由：意见行 `依据不足`。

---

## 节点 2　排除接口

运行时核验行政诉讼法第四十三条及司法解释。严重违反法定程序收集、以利诱胁迫欺诈等手段、侵害他人合法权益等，分别建排除行。轻微瑕疵不等于必须排除。

---

## 节点 3　鉴定

质证鉴定人资格、检材、方法、是否通知到场。申请重新鉴定只标条件接口。本任务不撰写鉴定意见替代件。

---

## 节点 4　听证与复议材料

处罚听证笔录、复议答复证据须单独质证。复议中不得自行收集的证据，诉讼中仍可攻击。

---

## 节点 5　输出

逐份意见和排除接口。不代替庭审代理提纲全文。禁止指导伪造反证。

## 节点补强：三性与排除

1. “全部不认”无具体理由：意见行 `依据不足，无法形成结论`。
2. 严重违反法定程序收集的进入排除接口；轻微瑕疵不等于必须排除。
3. 不重做鉴定，只列重新鉴定申请条件。
4. 被告未举证不得写成原告必须证明行为违法。
5. 复议中不得自行收集的证据，诉讼中仍可攻击。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（质证行政机关证据）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（三性意见、听证笔录、非法证据排除接口）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：不重做鉴定意见。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
