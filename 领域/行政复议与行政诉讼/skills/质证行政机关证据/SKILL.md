# 质证行政机关证据

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1989 年行政诉讼法、1996 年行政处罚法或 1999／2017 年行政复议法当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成三性意见、听证或庭审笔录接口和非法证据排除接口。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：已交换证据或开庭在即，需要逐份质证。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 重做鉴定意见；
- 完整建卷策略（转 `建立行政争议证据案卷`）；
- 阅卷目录尚未做（可先转阅卷）；

不重做鉴定意见。被告对合法性举证，不得把原告未反证写成行为合法。

## 建立质证坐标

确认：使用者与授权；证据交换清单；庭审或听证期日；鉴定意见；立场。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 证据表面；`A#` 当前一致／承认；`R#` 文书；`C#` 规范定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`H#` 质证意见；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验行政诉讼法非法证据排除和被告举证规则。

工具不可用时继续证据清单和形成时间登记；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [质证方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1 逐份三性

真实性、合法性、关联性分列，不得只写“不认可”。
### 节点 2 合法性来源

偷拍、刑讯、未表明身份、严重违反法定程序收集的，进入排除接口。
### 节点 3 鉴定

鉴定机构和程序可质证。不重做鉴定，只列重新鉴定申请接口。
### 节点 4 听证笔录

处罚听证笔录在诉讼中的位置单独评。未质证不得当庭突然作为唯一依据。
### 节点 5 证明妨碍

机关持有而不提交，不得据此推定相对人败诉。

## 停止与安全

- `整体停止`：指导伪造反证或威胁鉴定人。
- `字段停止`：排除规则未核验；证据原件未见。
- `目标停止`：主目标已变为重新鉴定或整本案卷策略。

## 交付

严格按 [输出合同](references/output-contract.md) 10节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
