# 评估行政行为争议

## 任务目标

在明确、无利益冲突的单方立场下，形成“行政行为争议总体评估矩阵”：行为定性、主体和程序状态、事实时间线、逐项请求／抗辩、复议与诉讼入口、期限待核、金额区间与非金钱后果、证据缺口、对方最强解释和下一步。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：行政处罚、许可、强制、征收程序、信息公开、行政协议或不作为已形成争议，用户仍需决定请求、抗辩、路线或下一步。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未形成行政争议，只要代办许可申请或出稿（审查起草领域，本生产线搁置，只说明不实施）；
- 只要发送版陈述申辩、听证或复议申请；
- 只要精算工作表或完整证据卷；
- 已决定起诉／应诉／开庭／执行并只要相应文书；
- 刑事强制措施或刑事责任；税务机关作出的专业税务处理或纳税争议实体；竞争申报调查或环境能源资源监管实体设计。

本任务不生成发送版陈述申辩、可提交复议申请或诉状，不给胜诉率。

## 建立评估坐标

确认：使用者与授权；单方立场；作出机关、复议机关和可能共同被告；文书名称与文号；争议事项；法域；当前告知、听证、复议、诉讼或执行状态；文书作出与送达；对方已知主张；关键材料及缺失。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 规范或决定定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 请求／抗辩；`V#` 评估版本；`E#` 发送／送达凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1989 年行政诉讼法、1996 年行政处罚法或 1999／2017 年行政复议法当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验受案范围、复议前置、期限、被告、过罚相当；`search_practiced` 补路径与反例；特殊事实用 `search_case_by_fact`，明确筛选用 `search_case_by_filter`。不虚构案件系统。

工具不可用时继续事实、主体、程序文书状态和问题清单；请求／抗辩的法律结论及期限字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 专项分流、行为定性和程序状态

先做刑事、税务实体、竞争环境实体、劳动实体分流，再固定文书版本、作出机关和送达。口头转述和“已读”不写成已送达或期限已起算。内部行为、过程行为、刑事措施不得直接写成可诉行政行为。

### 2. 请求与抗辩假设

每个 `Q#` 独立列法律效果、成立条件、支持及不利事实、控制方、最强反方、主备位和互斥。撤销、确认违法、确认无效、责令履行、变更、赔偿不得合成一笔“行政权益”。过罚相当不等于当然撤销。

### 3. 复议、诉讼和期限

复议前置命中时不得直接写成应起诉。复议已受理与诉讼已受理互斥。期限分列复议申请期、未告知最长一年、起诉六月、复议后十五日、不作为期限，不混算。

### 4. 金额区间与非金钱后果

分项列罚款、没收、滞纳金、停产停业、吊销许可、行政赔偿。未知不写零。法定幅度不是必处或必赔金额。

### 5. 证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。被告对合法性承担举证责任，不得把原告未能自证违法写成行为合法。下一步按期限灭失、易失证据、能否改变 `Q#`、可逆性排序。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体或文书无法建立；用户坚持伪造、隐匿、威胁或违法取证。
- `字段停止`：法域、日期、文书送达、动态规则未核验。
- `目标停止`：主目标已变为陈述申辩、复议申请、精算、建卷、协调协议或诉讼文书。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
