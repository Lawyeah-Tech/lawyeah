# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变请求、论坛、期限或金额结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然撤销、必然受理或唯一必处／必赔总额。

`search_law` 返回 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。2007 年复议法实施条例与 2023 年复议法冲突的条文记噪声。

## Q# 矩阵

固定列：`编号｜关系假设｜提出方｜相对方｜法律效果｜成立条件｜支持事实｜不利事实｜控制方｜最强反方｜主备位｜判断｜待核`。

撤销、确认违法、确认无效、责令履行、变更、停止执行、赔偿分列。同一事实支持多项时分别说明效果，不重复金额。程序违法不等于当然无效。

## 节点 0　专项分流

先于实体判断。命中任一项则整案转出，本任务只交付分流理由和最小交接，不填总体评估十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 刑事拘留、逮捕、搜查扣押、定罪或辩护 | 刑事领域 |
| 税务处理、税额核定、纳税担保、缴清或提供担保后复议 | 税务领域 |
| 经营者集中、垄断协议、滥用市场支配地位调查实体 | 竞争法领域 |
| 环评批复实体、排污许可实体、资源权利设计 | 环境能源领域 |
| 工伤认定条件、劳动能力鉴定、社保待遇核定、劳动监察实体证据 | 劳动领域 |
| 商标评审、专利复审无效宣告 | 知识产权领域 |
| 尚未成争，只要代办许可或出稿 | 审查起草领域（本窗搁置，只说明不实施） |

混合信号：一般处罚或一般强制主轴可留本任务；专项只作为背景时在缺口标明，不把专项实体规则硬套进一般行政结论。

## 节点 1　行为定性、主体和程序状态

1. 固定告知书、决定书、复议决定、送达回证、公告的版本和文号。冲突并列，不选对用户有利的一版冒充唯一文书。
2. 主体表记录作出机关、内设机构或派出机构名义、授权组织、委托机关、复议机关。名称不一致不自动合并。内设机构以自己名义作出的，被告／被申请人须标待核。
3. 程序表逐动作记录调查、告知、听证、决定、复议、诉讼或执行：机关、案号或文号、文书、作出日、收到日、送达方式和效力凭证。口头转述、截图、“已读”、网站公示不得单独写成已送达或期限已起算。
4. 定性候选分列：行政处罚、行政许可、行政强制措施、行政强制执行、征收决定或补偿决定、政府信息公开、行政协议、不履行法定职责、内部行为、过程行为、刑事措施。过程行为和内部行为不得直接写成可诉。
5. 同时掌握双方秘密或立场不明：整体停止策略输出。

## 节点 2　请求与抗辩假设

每个 `Q#` 先写法律效果，再写成立条件。禁止合成“行政权益”一笔。

默认主位候选按事实分别建立，不得预先锁定撤销：

- `Q-撤` 撤销或部分撤销
- `Q-违` 确认违法（行为已执行完毕或不具可撤销内容）
- `Q-无` 确认无效（重大且明显违法：实施主体不具行政主体资格或没有依据等）
- `Q-履` 责令履行法定职责
- `Q-变` 变更明显不当的处罚
- `Q-停` 停止执行（例外，不是默认）
- `Q-赔` 行政赔偿（一并接口，不替代专项赔偿原子）
- `Q-抗` 主体越权、事实不清、程序违法、适用依据错误、明显不当、超过追责时效、复议或起诉期限

机关或被告立场：逐项回应对方已知主张，并列己方最强抗辩，不把反诉写成已经提起。行政诉讼原则上无民事式反诉。

主备位和互斥必须可见。`Q-无` 与 `Q-撤` 不得写成同一效果。确认无效不受普通起诉期限约束的主张必须运行时核验后才能落判断，未核验则字段停止。

## 节点 3　复议还是诉讼

本节点只判断路径，不生成复议申请或起诉状。

### 3.1 先分账

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 用户不满处罚结果 | 已构成应予撤销 |
| 用户想今天起诉 | 复议前置已完成或不必前置 |
| 对方未在异议期内异议 | 行为已不可争议 |
| 复议机关维持 | 只需告原机关 |

### 3.2 复议前置分流

运行时核验 2023 年复议法第二十三条及行政诉讼法第四十四条后再落判断。核验失败则本节点字段停止，事实与问题清单继续。

1. **当场作出的行政处罚**：主位写成先复议。
2. **侵犯已经依法取得的自然资源所有权或使用权的决定**：主位写成先复议。土地权属争议未核验“已经依法取得”时标待核。
3. **认为行政机关未履行法定职责**：主位写成先复议。
4. **申请政府信息公开，行政机关不予公开**：主位写成先复议。
5. **法律、行政法规规定的其他前置**：纳税争议等整案转税务，不在本任务展开缴清或担保条件。

非前置案件：复议与直接起诉并列可选，说明互斥受理。复议已依法受理：诉讼入口负触发。法院已依法受理：复议入口负触发。

### 3.3 期限分类型

每种期间单独一行。禁止用起诉六月去算复议六十日，也禁止用复议期去挡赔偿一并请求。

| 类型 | 规则锚点 | 本任务允许的输出 | 禁止 |
| --- | --- | --- | --- |
| 复议申请期 | 2023 年复议法第二十条：知道或应当知道之日起六十日；法律可更长 | 起算事件、备选起算、不可抗力继续计算 | 唯一截止日 |
| 未告知复议权利 | 同条：自知道权利、机关和期限之日起算，但自知道内容之日起最长一年 | 并行情景 | 用六十日冒充最长一年 |
| 起诉期 | 行政诉讼法现行起诉期限条文，运行时核验 | 知道或应当知道之日起的一般期限 | 用 1989 年第四十六条合议庭条文冒充起诉期限 |
| 复议后起诉 | 复议决定送达后法定期限；前置失败十五日 | 送达日与作出日分列 | 用复议决定作出日代替送达日 |
| 不作为 | 履行期限届满之日起算 | 申请日、履行期限、届满日 | 把民事拖延写成行政不作为 |
| 未告知起诉期限 | 行诉解释第六十四条：最长一年 | 与起诉一般期限分列 | 混成一个截止日 |

日期冲突、送达不明、知悉日不明：并行情景 + 字段停止，不选对用户最有利的一天。

### 3.4 输出

| 条件 | 本任务输出 | 转介 |
| --- | --- | --- |
| 告知后决定前，陈述窗口未过 | 陈述是否必要、放弃风险 | `prepare-statement-and-defense` |
| 路径条件尚未闭合 | 缺口、最强反方、不可逆提示 | 不转介发文书 |
| 路径选择本身成为主目标 | 最小交接 | `assess-reconsideration-or-litigation` |
| 用户坚持今天提交复议或起诉终稿 | 目标停止 | 对应文书原子，不在本包出稿 |

## 节点 4　金额区间与非金钱后果

本任务只建区间和接口，不替代 `calculate-penalty-or-compensation`。

1. 分项：罚款、没收违法所得、没收非法财物、滞纳金、加处罚款、吊销或暂扣许可、责令停产停业、限制从业、行政赔偿。未知不写零，不输出唯一必处或必赔总额。
2. 法定幅度或裁量基准不是必处金额。过罚相当、首违不罚、从轻减轻只标接口。
3. 行政赔偿项目分列人身自由、生命健康、财产直接损失。标准须运行时核验，不得把未知写成零。
4. 征收补偿标准实体转出，不在本任务给出唯一补偿额。

参数不足：只列已知参数、未知参数和专项测算接口。

## 节点 5　证据、反方和下一步

1. 被告对行政行为合法性承担举证责任。原告未能提供相反证据，不得写成行为合法。
2. 原告仍须对起诉条件、赔偿损失事实、不作为的申请事实提供初步材料。
3. 证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因机关控制卷宗而推定内容有利于相对人，也不得推定内容不利于相对人。
4. 下一步按期限灭失、易失证据、改变请求抗辩、可逆性排序。每项写执行人、前置、最晚时点、预期改变、备选、可逆性和停止条件。

陈述申辩、复议申请、起诉、应诉、精算、完整证据卷只写转介条件和最小交接，不在本方法生成那些终稿。禁止指导伪造、隐匿、威胁或违法取证。
