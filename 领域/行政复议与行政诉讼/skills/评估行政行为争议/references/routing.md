# 边界与路由

## 正触发

行政处罚、许可、强制、征收程序、信息公开、行政协议或不作为已成争，单方需要总体决定请求、抗辩、论坛、证据优先级和下一步。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 未成争，代办许可或出稿 | 审查起草领域（本窗搁置，只说明） |
| 只判断先复议还是起诉 | `评估复议或诉讼路径` |
| 只判断告谁或有无原告资格 | `评估原告资格与被告` |
| 交陈述申辩 | `准备陈述申辩` |
| 申请复议 | `申请行政复议` |
| 精算罚款或赔偿 | `测算罚款没收与行政赔偿` |
| 完整证据卷 | `建立行政争议证据案卷` |
| 协调条件 | `谈判行政争议协调方案` |
| 起诉 | `提起行政诉讼一审` |
| 应诉 | `应对行政诉讼一审` |
| 刑事强制措施 | 刑事领域 |
| 税务处理或纳税争议实体 | 税务领域 |
| 竞争或环境专项实体 | 对应领域 |
| 工伤社保劳动监察实体 | 劳动领域 |
| C 端处罚救济／征地材料／税务检查 | 大众专项，只分流不回改 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 刑事拘留、逮捕、搜查、定罪 | 刑事领域 |
| 税务处理、税额核定、纳税担保、缴清后复议 | 税务领域 |
| 经营者集中、垄断协议、滥用支配地位调查实体 | 竞争法领域 |
| 环评、排污许可、资源权利实体设计 | 环境能源领域 |
| 工伤认定条件、社保待遇核定、劳动监察实体证据 | 劳动领域 |
| 商标评审、专利复审无效 | 知识产权领域 |

一般处罚夹带专项背景时，专项段只分流，不把专项规则写入本任务结论。

## 易混

请求尚未闭合、需比较陈述、复议或起诉时正触发。主体、请求、论坛均确认且只要文书时负触发。复议前置命中仍要求“直接起诉”时，先完成路径闸，不改写成立案原子。
