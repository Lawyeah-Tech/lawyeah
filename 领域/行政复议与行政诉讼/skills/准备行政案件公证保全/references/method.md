# 公证准备方法

判断只用三态。不代替鉴定或法院保全。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 需要鉴定意见 | 负触发 |
| 需要进入对方控制场所 | 转法院证据保全 |
| 只要保全策略未选定公证 | 转 `preserve-evidence` |
| 用户要公证员在申请书上写“行为违法” | 拒绝；公证不认定行政行为合法性 |

---

## 节点 1　事项

`N-网页` `N-现场` `N-送达` `N-电子载体` 分列。一项一证思路，不把无关事实塞进同一公证书。

---

## 节点 2　材料

身份证件、主体资格、网址或地址、清洁电脑或现场条件、拟操作脚本。送达公证须有受送达人地址来源，不得虚构地址。

---

## 节点 3　询问提纲

来源是否合法持有、是否修改过、操作人是谁、时间是否同步。虚假陈述将导致公证书被否定，必须写明。

---

## 节点 4　限度

公证固定的是过程和现状。行政行为是否合法、损失金额、鉴定结论，公证不能替代。

---

## 节点 5　输出

事项、材料、提纲。不代办公证。不保证受理。

## 节点补强：公证限度

1. 需要鉴定意见或强制进入对方场所：负触发。
2. 公证证明过程和现状，不认定行政行为合法性。
3. 送达公证不得虚构地址。向公证员虚假陈述将导致证书被否定。
4. 一项一证，不把无关事实塞进同一公证书。
5. 不代办公证，不保证受理。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（准备公证送达或证据保全公证）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（公证事项、材料、询问提纲）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：不代替鉴定或法院保全。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
