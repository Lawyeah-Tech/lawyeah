# 调解协议起草方法

判断只用三态。不得就处罚合法性本身违法调解。不得把已失效《合同法》当作现行规则。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 条件未谈拢 | 转 `negotiate-settlement` |
| 只要判断能否调 | 转 `assess-mediation-scope` |
| 只要司法确认或调解书路径 | 转 `confirm-settlement-enforceability` |
| 用户要把“处罚改为合法”写进协议 | 删除该条款并说明禁止 |

---

## 节点 1　范围

可写：赔偿或补偿数额与支付；行政协议的履行变更；诉讼费；行为的后续安排（在法定权限内）。
不可写：约定处罚行为合法且不得再争；约定放弃对第三人刑事责任的追究；处分依法不能处分的公共职权。

---

## 节点 2　条款

当事人、案件索引、履行、保密、通知、生效、份数。弃权条款必须写清放弃的是何种请求、针对何行为、是否保留国家赔偿。

---

## 节点 3　执行力提示

诉讼中调解且法院出调解书：具有强制执行力。
复议调解：按复议法核验效力。
仅双方签字的谅解：通常无直接强制执行力，必须在文本封面提示。

---

## 节点 4　金钱

分项列，未知不写零。不得引用 1999 年《合同法》违约金条款作为现行依据；需要合同编规则时运行时核验。

---

## 节点 5　安全

不代签字。不把草稿写成已生效。一方为行政机关时，签署权限须核验。

## 节点补强：可写与不可写

1. 条件未谈拢：转谈判原子。
2. 不可写：约定处罚合法且不得再争；放弃对第三人刑事责任的追究。
3. 单独谅解无强制执行力必须在封面明示。
4. 行政机关签署权限须核验。不代签字。
5. 禁止引用 1999 年《合同法》作为现行依据。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（起草行政调解或和解协议）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（协议草稿、弃权边界、履行与反悔）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：不得就处罚合法性本身违法调解。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
