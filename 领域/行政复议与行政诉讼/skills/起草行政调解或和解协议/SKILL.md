# 起草行政调解或和解协议

## 任务目标

在明确、无利益冲突的单方立场下，形成协议草稿、弃权边界、履行与反悔安排。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：条件已谈拢，需要可签署的行政调解或和解文本。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 就处罚合法性本身违法调解；
- 条件尚未谈拢只要谈判方案（转 `谈判行政争议协调方案`）；
- 只要评估能否调；

不得就处罚合法性本身违法调解。单独谅解的执行力必须明示。

## 建立协议起草坐标

确认：使用者与授权；已谈拢条件；案件阶段（复议／诉讼／诉讼外）；是否需要法院或复议机关出具调解书；弃权范围。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 文书；`C#` 规范定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`C条款#` 条款；`V#` 稿件版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1989 年行政诉讼法、1996 年行政处罚法或 1999／2017 年行政复议法当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验行政诉讼法调解范围；范本只借栏目。不得把已失效《合同法》当作现行规则。

工具不可用时继续已谈拢条件和案件阶段登记；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [调解协议起草方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1 可调范围闸

赔偿、补偿、行政协议等可调。处罚合法性本身不得写成双方同意合法或违法。
### 节点 2 弃权边界

放弃复议、起诉或赔偿必须明示范围和是否可逆。
### 节点 3 履行

金额、期限、账户、非金钱义务分列。未知不写零。
### 节点 4 执行力

法院调解书、复议调解与私下谅解分列。私下谅解无强制执行力必须明示。
### 节点 5 反悔

签字前可撤回谈判。生效后反悔条件待核。

## 停止与安全

- `整体停止`：把处罚合法性写成可约定事项；伪造对方已同意的条款。
- `字段停止`：调解范围或调解书效力未核验。
- `目标停止`：主目标已变为谈判方案或执行力路径比较。

## 交付

严格按 [输出合同](references/output-contract.md) 10节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
