# 征收程序方法

判断只用三态。不测算唯一补偿额。实体补偿转出。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 用户只要补偿单价、安置房设计 | 转房地产或 C 端征地材料整理 |
| 民事腾退、租赁纠纷为主 | 转合同或房地产民事 |
| 税务土地增值税实体 | 转税务 |
| 只要总体行政评估 | 可转总体评估，本任务只做程序层 |

---

## 节点 1　分层

1. 集体土地征收与国有土地上房屋征收规则不同，必须先定性。
2. 征收决定、补偿方案、补偿决定、征收补偿协议分列。
3. 协议履行争议转行政协议评估。本任务管决定和程序。

---

## 节点 2　程序清单

运行时核验土地管理法、国有土地上房屋征收与补偿条例等现行程序。

| 步骤 | 缺失 |
| --- | --- |
| 公共利益和规划条件 | 征收决定合法性争点 |
| 公告与征求意见 | 程序争点 |
| 旧城区改造等应当听证而未听证 | 程序争点 |
| 评估机构选定程序 | 程序争点 |
| 补偿决定作出前的调解或协商 | 待核 |

不得把“我不同意补偿”写成程序违法已成立。

---

## 节点 3　实体转出

评估报告数值、类似房地产比较、停产停业损失标准、安置面积：列出转出，不给唯一补偿额。未知不写零。

---

## 节点 4　强制与赔偿

补偿决定生效后申请法院强制执行，是非诉执行接口。未取得合法决定的拆除，进入确认违法和赔偿路径，不在本任务写赔偿起诉状。

---

## 节点 5　救济

征收决定、补偿决定可复议可诉。自然资源权属已依法取得被侵犯的，可能复议前置，运行时核验。C 端征地材料整理只分流不回改。

## 节点补强：决定分层与实体转出

1. 先分集体土地征收与国有土地上房屋征收，规则不同。
2. 征收决定、补偿决定、补偿协议必须分对象。协议履行转行政协议评估。
3. 未公告或依法应听证未听证：程序争点候选。不同意补偿数额本身不是程序违法。
4. 评估数值、安置面积、停产停业标准：转房地产或 C 端征地材料，不给唯一补偿额。
5. 无合法决定的拆除：确认违法和赔偿接口，不在本任务写赔偿诉状。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。
