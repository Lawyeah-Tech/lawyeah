# 评估征收征用程序救济

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1989 年行政诉讼法、1996 年行政处罚法或 1999／2017 年行政复议法当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的被征收人立场下，形成征收或征用程序违法争点、救济入口，以及实体补偿转出说明。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：对征收决定、补偿决定或未公告未听证等程序有争议，需要救济入口。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 补偿标准实体和安置方案设计（转房地产或 C 端征地材料整理）；
- 要求测算唯一补偿额；
- 只要民事腾退诉讼；

补偿标准实体和安置方案设计转房地产或 C 端征地材料整理。不测算唯一补偿额。

## 建立征收程序坐标

确认：使用者与授权；征收决定和补偿决定文号；公告、听证、评估、签约事实；房屋或土地权属；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 征收文书；`C#` 规范定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 程序争点；`V#` 评估版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验土地管理法、国有土地上房屋征收与补偿条例中的公告、听证、评估和决定程序。

工具不可用时继续决定文书、公告和听证事实登记；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [征收程序方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1 对象与决定分层

征收决定与补偿决定分开。征收决定解决公共利益和范围；补偿决定解决未签约时的补偿。
### 节点 2 公告与参与

征收公告、补偿方案征求意见、听证、评估机构选定分列。未公告不得写成程序已完成。
### 节点 3 评估与签约

评估程序违法可作程序争点。评估数值实体转出，不在本任务改写成唯一补偿额。
### 节点 4 强制搬迁接口

申请法院强制执行与自行拆除分列。违法强拆进入赔偿接口。
### 节点 5 救济与转出

复议诉讼入口留本领域。补偿标准、安置方案、C 端材料整理转出。

## 停止与安全

- `整体停止`：立场不明；用户只要唯一补偿额并拒绝转出。
- `字段停止`：征收类型或听证条件未核验。
- `目标停止`：主目标已变为安置方案设计或协议起草。
