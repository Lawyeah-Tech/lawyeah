# 赔偿路径方法

判断只用三态。不写赔偿起诉状。不给必赔金额。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 刑事拘留、逮捕、无罪羁押 | 转刑事赔偿 |
| 只要精算表 | 转 `calculate-penalty-or-compensation` |
| 只要申请书 | 转 `apply-agency-compensation` |
| 已确认且已处理或逾期，只要起诉状 | 转 `file-state-compensation` |
| 征收补偿标准 | 转房地产，不是国家赔偿 |

---

## 节点 1　确认状态

1. 复议决定、判决或义务机关书面确认违法：确认行支持。
2. 正在对行政行为诉讼：主位一并请求。
3. 未确认且未起诉行为：单独赔偿诉讼入口通常未打开。
4. 行为被维持但当事人仍要赔：现有依据不支持，除非另有确认。

---

## 节点 2　先行处理

运行时核验国家赔偿法关于行政赔偿程序的条文。

| 若 | 则 |
| --- | --- |
| 拟单独提起 | 主位先向义务机关申请 |
| 机关逾期未决定 | 单独诉讼入口候选 |
| 机关已决定但请求人不服 | 单独诉讼入口候选 |
| 在对行为之诉中一并请求 | 通常不必先行处理，规则须核验 |

---

## 节点 3　路径比较

`P-一并`：依附行为之诉，请求类型随主诉。
`P-申请`：向义务机关提出，形成处理或逾期事实。
`P-单独诉`：确认加先行处理条件闭合后才打开。

互斥可见。不得把三种写成同一张状。

---

## 节点 4　义务机关与项目

义务机关一般为实施机关。复议加重部分由复议机关负责。项目只列人身自由、健康、财产直接损失接口，未知不写零。

---

## 节点 5　输出

路径表、条件缺口、转介。不保证获赔。时效规则未核验则时效字段停止。

## 节点补强：确认与先行

1. 刑事羁押赔偿：转刑事。征收补偿标准：转房地产，不是国家赔偿。
2. 未确认违法：单独赔偿诉讼入口通常未打开，主位一并请求或先确认。
3. 拟单独提起：主位先向义务机关申请。
4. 三种路径不得写成同一张状。
5. 未知损失不写零。时效未核验则时效字段停止。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。
