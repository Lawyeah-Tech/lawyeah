# 执行和解方法

判断只用三态。不放弃已生效判项除非明示。不得把已失效《合同法》当作现行规则。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 尚未进入执行 | 转诉讼调解或执行力补强 |
| 用户要减免判项却不写明 | 必须明示或拒绝写入放弃 |
| 劳动仲裁执行和解 | 劳动领域 |
| 假和解真转移财产 | 整体停止 |

---

## 节点 1　范围

可写：履行期限、分期、替代履行、担保。
须明示才可写：减免金额、放弃部分判项。
不可写：约定原行政行为改为合法；约定不再履行法院判令重作的法定职责。

---

## 节点 2　恢复执行

一方不履行和解：对方可申请恢复对原生效法律文书的执行，已履行部分扣除。规则运行时核验。不得写成只能另行起诉。

---

## 节点 3　文本要点

当事人、执行案号、原判项完整引用、变更仅限履行方式、分期表、违约即恢复、担保、签署日期。金额未知不写零。

---

## 节点 4　机关限制

行政机关不得通过和解放弃法定职责或处分无权处分的公共资源。相对人是被执行人时，和解不消灭拒执风险，除非已履行或获准。

---

## 节点 5　输出

要点或草稿。不代签署。不保证法院认可。

## 节点补强：不默示放弃

1. 减免金额或放弃判项必须明示，否则不得写入。
2. 不得约定原行政行为改为合法，不得和解掉法定重作职责。
3. 一方不履行：申请恢复对原生效文书的执行，已履行部分扣除。
4. 假和解转移财产：整体停止。
5. 尚未进入执行：转诉讼调解或执行力补强。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（准备执行和解）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（执行和解要点、违约恢复执行）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：不放弃已生效判项除非明示。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
