# 复议决定履行方法

判断只用三态。不重开实体复议。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 已有法院判决要执行 | 转 `enforce-effective-judgment` |
| 机关要执行原处罚 | 转非诉执行 |
| 对复议决定不服要起诉 | 转起诉原子 |
| 纳税争议复议决定履行实体 | 转税务 |

---

## 节点 1　可履行性

撤销并责令重作、变更、确认并赔偿、限期履行职责：有可执行内容。
单纯维持：申请人通常不能据此强制被申请人“再做一次”，除非决定另有履行项。

---

## 节点 2　责令履行

运行时核验 2023 年复议法被申请人不履行复议决定时，复议机关或有权机关责令履行、对责任人员处理的规则。申请书列决定文号、主文、不履行事实。

---

## 节点 3　申请法院执行

复议决定作为执行名义的条件和管辖须核验。未核验则法院执行路径字段停止，责令履行路径可继续。

---

## 节点 4　期限

被申请人履行复议决定的期限，决定有载明的从其载明，否则合理期限须说明。未届满不得写成拒不履行已成立。

---

## 节点 5　输出

责令履行申请、法院执行接口。不重写复议申请，不重审实体。

## 节点补强：可履行内容

1. 单纯维持决定：通常无可供申请人强制的给付。
2. 履行期限未届满：不得写成拒不履行已成立。
3. 已有行政判决：转判决执行原子。
4. 对复议决定不服要起诉：转起诉原子，不走本任务。
5. 法院执行路径条件未核验则该路径停止，责令履行可继续。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（申请履行复议决定）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（责令履行或申请法院执行材料）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：不重开实体复议。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
