# 申请履行复议决定

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1989 年行政诉讼法、1996 年行政处罚法或 1999／2017 年行政复议法当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的申请人立场下，形成责令履行或申请法院执行复议决定的材料。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：被申请人拒不履行复议决定，申请人要责令履行或申请法院执行。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 重开实体复议；
- 执行行政诉讼判决（转判决执行原子）；
- 非诉执行原处罚决定；

不重开实体复议。

## 建立复议履行坐标

确认：使用者与授权；复议决定主文；送达日；被申请人；履行期限；是否已起诉原行为。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 复议决定；`C#` 规范定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`P#` 履行项；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验 2023 年复议法关于复议决定履行和责令履行、申请法院强制执行的条文。

工具不可用时继续复议决定主文、送达和履行期限登记；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [复议决定履行方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1 决定效力

复议决定已生效且有可履行内容。维持决定通常无可供申请人申请强制的给付。
### 节点 2 责令履行

向复议机关申请责令被申请人履行。
### 节点 3 法院执行

依法可申请法院强制执行复议决定的条件核验。
### 节点 4 不重开

不重新审理原行为全部实体。
### 节点 5 与判决执行区分

已有行政判决的，走判决执行原子。

## 停止与安全

- `整体停止`：把维持决定包装成可强制执行的给付；重审实体。
- `字段停止`：责令履行或法院执行条件未核验。
- `目标停止`：主目标已变为起诉或判决执行。

## 交付

严格按 [输出合同](references/output-contract.md) 10节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
