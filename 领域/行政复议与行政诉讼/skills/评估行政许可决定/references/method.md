# 许可决定方法

判断只用三态。不保证保留许可。不代办申请材料。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 商标评审、专利复审无效宣告 | 转知识产权 |
| 排污许可、采矿权出让实体设计 | 转环境能源或相应领域 |
| 尚未成争只要填申请表 | 审查起草本窗搁置 |
| 机关已启动吊销或撤销程序，用户只要应对文书 | 转 `respond-to-license-revocation-process` |
| 吊销作为处罚且主问过罚相当 | 可并行 `assess-administrative-penalty` |

---

## 节点 1　定性

1. 不予受理不是实体不准予，程序效果不同。
2. 不予许可须说明理由。理由缺失标程序争点。
3. 变更、延续、撤回、撤销、注销、吊销分列，不得都写成“被取消”。
4. 吊销许可证件属于处罚种类时，必须挂处罚程序接口。

---

## 节点 2　程序

运行时核验行政许可法第三十二条、第四十二条至第四十八条等。

| 若 | 则 |
| --- | --- |
| 申请材料齐全未受理 | 不作为或程序违法候选 |
| 要求补正但范围不清或反复补正 | 争点；不写成已拒绝 |
| 法定期限届满未决定 | 转入不作为评估接口 |
| 依法应听证未听证 | 程序争点 |
| 直接关系他人重大利益未听取意见 | 第三人程序争点 |

---

## 节点 3　撤回、撤销、注销

| 种类 | 成立方向 | 禁止 |
| --- | --- | --- |
| 撤回 | 许可所依据的法律或客观情况重大变化，为公共利益 | 把违法许可当成撤回以逃避撤销程序 |
| 撤销 | 机关违法准予，或欺骗贿赂等 | 把无过错合法许可写成可任意撤销 |
| 注销 | 许可有效期届满、主体终止等 | 用注销代替吊销或撤销 |
| 吊销 | 处罚程序 | 写成行政管理内部调整 |

欺骗、贿赂取得许可：撤销方向强，信赖保护弱。机关自身违法但相对人无过错：撤销须权衡公共利益和信赖。

---

## 节点 4　信赖利益

1. 投入事实、批准行为、善意无过错、公共利益分列。
2. 补偿只标接口，不测算唯一数额。
3. 相对人违法取得的，不得把停业损失写成应补偿。

---

## 节点 5　输出

不重做申请材料。不保证许可恢复。救济入口分列陈述、听证、复议、诉讼。

## 节点补强：种类锁死再评程序

1. 若用户只说“证没了”：先分不予、撤回、撤销、注销、吊销，未定性则结论字段停止。
2. 若吊销：并行处罚程序接口，不得只按许可法评过。
3. 若欺骗贿赂取得许可：信赖保护弱，撤销方向强，仍须程序权利。
4. 若机关自身违法但相对人无过错：撤销须权衡公共利益，补偿接口打开，不测算唯一额。
5. 若尚未成争只要填申请表：负触发，审查起草本窗搁置。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。
