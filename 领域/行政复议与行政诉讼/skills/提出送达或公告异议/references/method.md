# 送达异议方法

判断只用三态。不编造未收到。已读不等于送达。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 只要评估送达、不对外提异议 | 转 `assess-delivery-and-service` |
| 只要期间表 | 转期间原子 |
| 用户要求按未收到写但材料有本人签收 | 整体停止或该事实按材料写 |
| 诉讼文书送达异议已进入法院程序 | 按诉讼送达规则核验 |

---

## 节点 1　冲突表

列：地址是否正确、签收人是否适格、邮单是否妥投、公告前是否尝试其他方式、电子同意是否存在。每项三态。

---

## 节点 2　渠道

决定作出阶段：向机关书面异议并保留复议权。
复议阶段：在复议理由中攻击送达。
诉讼阶段：在起诉条件或实体中主张期限未起算。
本任务给要点和草稿段落，不代替复议申请或起诉状全文。

---

## 节点 3　效果

异议不自动推翻文书。即使送达违法，实际知悉后的期间可能另起情景。两行并列。

---

## 节点 4　草稿

事实、证据、请求（重新送达、期限未起算、撤销公告送达）。不保证支持。

---

## 节点 5　安全

禁止指导作伪证。已读只能作为知悉线索，不能单独写成合法电子送达，也不能单独写成未送达。

## 节点补强：冲突表与安全

1. 材料有本人签收仍要求按未收到写：停止或按材料写。
2. 已读只作知悉线索，不能单独写成合法电子送达，也不能单独写成未送达。
3. 公告前未穷尽其他方式：公告合法性争点。
4. 异议不自动推翻文书。实际知悉后的期间另列情景。
5. 禁止伪造未收到或隐匿回证。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（提出送达或公告异议）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（异议要点、送达证据冲突、期限情景）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：不编造未收到；已读不等于送达。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
