# 庭审准备方法

判断只用三态。不代替立案。不给胜诉率。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 尚未起诉 | 转起诉原子 |
| 只要逐份质证表 | 可引用质证原子成果 |
| 二审开庭且用户只要应对上诉 | 转 `respond-appeal` 或上诉原子 |
| 复议听证 | 转复议听证 |

---

## 节点 1　争点

按法庭可能归纳的争议焦点预列，每点：我方主张、依据、证据、最强反方、让步限度（调解范围内）。处罚合法性不得设计违法让步。

---

## 节点 2　共同被告庭审

原告漏列复议机关：准备释明和追加接口。原机关与复议机关发言分工预先写清，避免互相推诿被记入笔录。

---

## 节点 3　举证质证

被告对行为合法性举证。原告准备起诉条件、不作为申请、赔偿损失的证据。质证引用已有三性意见，不在庭审提纲重做全部鉴定。

---

## 节点 4　询问与最后陈述

问题必须有证明目的。禁止指导伪证。最后陈述控制在争点结论，不宣读长文。

---

## 节点 5　输出

提纲。不代出庭。不保证结果。

## 节点补强：庭审组织

1. 尚未起诉：转立案原子。复议听证：转复议听证。
2. 被告先就合法性举证。原告准备起诉条件、不作为申请、赔偿损失证据。
3. 共同被告预先分工，避免互相推诿记入笔录。
4. 处罚合法性不得设计违法让步。禁止指导伪证。
5. 不给胜诉率，不代出庭。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（准备行政诉讼庭审）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（争点、举证质证、询问、代理提纲）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：覆盖复议共同被告庭审；不代替立案。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
