# 建立行政争议证据案卷

## 任务目标

在明确、无利益冲突的单方立场下，形成“行政争议证据案卷”：要件、被告举证责任、原告或第三人补证、合法性、缺口和合法补证计划。

`depends-on` 为空。

## 工作边界

正触发：单独委托盘点行政争议举证责任和补证。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要策略总图或只要诉状；
- 要求设计偷拍、侵入执法场所、伪造或隐匿卷宗；
- 劳动仲裁证据整卷（转劳动）。

本任务不代替总体评估或起诉状。

## 建立案卷坐标

确认：立场；被诉或拟复议行为；已持有材料及来源权限；是否已阅卷；法域。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关文书；`C#` 规范定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`EV#` 证据；`V#` 案卷版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1989 年行政诉讼法、1996 年行政处罚法或 1999／2017 年行政复议法当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验行政诉讼法第三十四条、行政诉讼证据规定和复议程序中不得事后取证规则。工具不可用时继续材料编目；举证分配结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [证据方法](references/method.md) 为准。

### 1. 分流和材料权限

原告侧材料与机关卷宗分权登记。不得使用对方未披露秘密。

### 2. 要件与举证责任

合法性要件归被告。起诉条件、申请履职事实、赔偿损失事实归原告初步证明。

### 3. 证据矩阵

每份材料绑定待证事实、三性、控制方、形成时间（决定前／后）。

### 4. 事后补证红旗

复议中被申请人不得自行向申请人和其他组织个人收集证据。诉讼中被告补充证据受法定限制。

### 5. 合法补证计划

只列合法调取、申请法院调取、公证保全。禁止违法取证。

## 停止与安全

- `整体停止`：要求违法取证或隐匿卷宗。
- `字段停止`：举证规则未核验。
- `目标停止`：主目标已变为诉状或质证提纲终稿。
