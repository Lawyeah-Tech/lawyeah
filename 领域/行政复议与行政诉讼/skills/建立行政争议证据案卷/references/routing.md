# 边界与路由

## 正触发

需要单独的行政争议证据矩阵和合法补证计划。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 策略总图 | `评估行政行为争议` |
| 阅卷拆解 | `阅卷并拆解行政案卷`（未安装则本任务可列阅卷接口） |
| 诉状 | `提起行政诉讼一审` |
| 庭审质证提纲 | `质证行政机关证据` 或 `prepare-hearing`（未安装则 `unavailable`） |
| 违法取证方案 | 整体停止 |
| 劳动仲裁证据 | 劳动领域 |

## 易混

用户说“帮我做证据”但其实只要起诉状：负触发。没有材料也可正触发，输出缺口案卷。
