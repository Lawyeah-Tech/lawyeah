# 准备行政处罚听证材料

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1989 年行政诉讼法、1996 年行政处罚法或 1999／2017 年行政复议法当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的相对人立场下，形成听证申请或出席材料、质证提纲和笔录核对要点。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：已决定举行听证或依法应听证，相对人需要听证陈述和质证提纲。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要书面陈述申辩（转 `准备陈述申辩`）；
- 只要在法定期限提交听证申请（转 `申请举行听证`）；
- 税务听证实体方案（转税务）；

不替代陈述申辩。较大数额等门槛运行时核验。不把材料写成听证已胜。

## 建立听证材料坐标

确认：使用者与授权；告知书或听证通知；听证时间地点主持人；拟处罚种类；已交换的证据；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 告知与通知；`C#` 规范定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`H#` 质证点；`V#` 稿件版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验 2021 年处罚法第六十三条至第六十四条及部门听证规则；`search_template` 只借栏目。

工具不可用时继续听证通知、拟处罚种类和证据清单登记；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [听证材料方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1 听证门槛与通知

较大数额等门槛运行时核验。已通知听证则门槛争议不阻挡准备出席材料。
### 节点 2 与陈述申辩互斥主成果

主成果是听证提纲，不产发送版陈述终稿。陈述窗口若并行经过必须红旗。
### 节点 3 质证提纲

对拟认定事实和证据逐份三性意见。不得教唆毁灭证据。
### 节点 4 回避与程序权利

主持人、记录人、调查人员不得同一。回避申请要点列入。
### 节点 5 笔录核对

核对签名、补正、拒绝签名的后果。本任务不代出席。

## 停止与安全

- `整体停止`：立场不明；教唆伪造证据或扰乱听证。
- `字段停止`：听证门槛或部门听证规则未核验。
- `目标停止`：主目标已变为书面陈述或仅提交申请。

## 交付
