# 听证材料方法

判断只用三态。不替代陈述申辩。不保证改变拟处罚。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 只要书面陈述、尚未进入听证 | 负触发，转陈述原子 |
| 只要提交听证申请、材料未准备 | 转 `apply-for-hearing` |
| 税务听证且税负实体主导 | 转税务 |
| 复议听证 | 转 `apply-reconsideration-hearing` |
| 许可听证且非处罚 | 可留程序提纲，实体转许可评估 |

---

## 节点 1　门槛与通知

运行时核验 2021 年处罚法第六十三条。未核验不得写成无权听证或必须听证。机关已发出听证通知：按出席准备，门槛争点另列。

---

## 节点 2　材料结构

1. 听证参加人、委托手续、证据目录、陈述提纲、质证提纲、请求。
2. 请求限于不予处罚、从轻减轻、补充调查、排除非法证据，不得写成已获准。
3. 与发送版陈述互斥为主成果：可引用已有陈述，不重写一份对外陈述终稿。

---

## 节点 3　质证

固定列：`证据｜来源｜形成时间｜三性意见｜最强反方｜是否写入提纲`。

事后补证、单方隐匿、未告知的鉴定，标排除或补证接口。禁止指导伪造或威胁证人。

---

## 节点 4　程序权利

主持人回避、申请公开或不公开、最后陈述、核对笔录。调查人员不得主持。未告知这些权利，列入程序争点。

---

## 节点 5　笔录

核对要点：时间地点、参加人、证据出示、陈述原意、修改处按手印。拒绝签名须注明理由。本任务不代为签字。

## 节点补强：门槛、互斥、笔录

1. 只要书面陈述：负触发。只要提交申请：转申请原子。
2. 门槛未核验不得写成无权听证或必须听证。已发听证通知则按出席准备。
3. 调查人员不得主持。回避未告知列入程序争点。
4. 质证须逐份三性，禁止“全部不认”无理由。
5. 笔录核对后本任务不代签名。放弃听证不等于放弃陈述和复议。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（准备行政处罚听证材料）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（听证申请或出席材料、质证提纲、笔录核对要点）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：不替代陈述申辩；较大数额等门槛运行时核验。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
