# 证据保全方法

判断只用三态。禁止违法取证。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 主要是财产或行为保全 | 转 `apply-preservation` |
| 主要是停止执行 | 转 `apply-stay-of-execution` |
| 证据在机关手中要法院调取 | 转 `apply-investigation-order` |
| 已选定公证处只要事项清单 | 转 `prepare-notarial-evidence` |
| 用户要潜入现场偷拍 | 整体停止 |

---

## 节点 1　风险

每项 `P#`：对象、控制方、灭失机制（覆盖、拆除、到期自动删除）、最晚时点。无风险的普通书证走普通举证。

---

## 节点 2　合法自助

可做：在公共区域拍摄可见外立面；保存已合法持有的电子数据原始载体；书面催告对方保存。
不可做：翻越围挡、破坏查封、侵入办公区、破解系统、违法安装录音。

---

## 节点 3　公证与法院

网页、微信对话、现场现状：公证优先候选。
需要进入对方控制场所或强制提取：法院证据保全。诉前保全须情况紧急，担保规则核验。

---

## 节点 4　与其他保全区分

证据保全固定事实。财产保全控制履行。停止执行暂停行政行为。三者不得写成同一申请。

---

## 节点 5　输出

步骤、分流、禁止动作。不保证裁定。不指导违法拍摄。

## 节点补强：合法固定

1. 无灭失风险的普通书证走普通举证，不启动保全。
2. 禁止翻越围挡、破坏封条、侵入办公区、破解系统。
3. 网页或现状优先公证；须进入对方控制场所则法院证据保全。
4. 证据保全、财产保全、停止执行不得写成同一申请。
5. 用户要潜入偷拍：整体停止。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（保全行政争议证据）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（保全步骤、公证／法院保全分流、禁止动作）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：不指导偷拍违法或侵入执法场所。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
