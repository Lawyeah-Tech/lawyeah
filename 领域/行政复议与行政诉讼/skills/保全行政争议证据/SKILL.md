# 保全行政争议证据

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1989 年行政诉讼法、1996 年行政处罚法或 1999／2017 年行政复议法当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成保全步骤、公证或法院保全分流和禁止动作清单。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：现场、电子数据或执法记录可能灭失，需要合法固定。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 指导偷拍违法或侵入执法场所；
- 只要法院调取申请（转 `申请法院调取证据`）；
- 只要公证事项清单且已选定公证（转公证原子）；

不指导偷拍违法或侵入执法场所。

## 建立保全坐标

确认：使用者与授权；可能灭失的对象；控制方；是否已立案；公证处或法院保全意向；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 文书；`C#` 规范定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`P#` 保全项；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验行政诉讼法证据保全和公证保全相关规则。

工具不可用时继续灭失风险对象和控制方登记；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [证据保全方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1 对象与灭失风险

现场状态、监控、执法记录仪、网页、账册分列。无灭失风险则负触发。
### 节点 2 合法自助固定

自行拍照须在合法场所。禁止侵入、破坏封条或违法窃听。
### 节点 3 公证分流

网页、送达、现状适合公证的，转公证原子接口。
### 节点 4 法院保全

诉前或诉中证据保全条件、担保。与财产保全、停止执行区分。
### 节点 5 禁止动作

偷拍他人住宅、贿赂获取卷宗、攻击机关信息系统一律停止。

## 停止与安全

- `整体停止`：指导偷拍、侵入、破坏封条或攻击信息系统。
- `字段停止`：诉前保全或公证受理条件未核验。
- `目标停止`：主目标已变为财产保全、调取申请或公证终稿。

## 交付

严格按 [输出合同](references/output-contract.md) 10节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
