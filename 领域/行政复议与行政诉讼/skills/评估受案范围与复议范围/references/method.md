# 可诉性方法

判断只用三态。不得输出必然受理、必然驳回或胜诉率。本任务不选定复议机关或受诉法院。

`search_law` 返回 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》时记为噪声，不得写入 `L#`。

## 节点 0　专项分流

先于可诉性判断。命中任一项则整案转出，只交付分流理由。

| 信号 | 转出 |
| --- | --- |
| 刑事拘留、逮捕、搜查扣押、定罪或辩护 | 刑事领域 |
| 税务处理、税额核定、纳税担保、缴清或提供担保后复议 | 税务领域 |
| 经营者集中、垄断协议、滥用支配地位调查实体 | 竞争法领域 |
| 环评、排污许可、资源权利实体设计 | 环境能源领域 |
| 工伤认定条件、社保待遇核定、劳动监察实体 | 劳动领域；劳动仲裁申请不是行政诉讼 |
| 商标评审、专利复审无效 | 知识产权领域 |

混合信号：一般处罚或一般强制主轴可留本任务；专项只作背景时在缺口标明。

---

## 节点 1　固定对象

1. 固定文书名称、文号、作出名义、主送对象和是否对外发生法律效果。多份文书冲突并列，不选对用户有利的一版冒充唯一对象。
2. 口头答复、会议纪要、内部请示批复、执法过程中的告知或催告，先标文书类型，不得直接写成可复议或可诉行政行为。
3. 不作为对象必须先有申请履职或保护的事实；没有申请事实不得把民事拖延写成行政不作为。
4. 同时掌握双方秘密或立场不明：整体停止。

---

## 节点 2　复议范围

运行时核验 2023 年复议法第十一条、第十二条后再落判断。核验失败则 `J-复` 字段停止，事实清单继续。

1. **正列候选**：对行政处罚、行政许可、行政强制、征收征用及其补偿、不履行法定职责、政府信息公开、行政协议等不服，分别建 `J-复` 行。
2. **排除候选**：国防外交等国家行为；行政法规、规章或行政机关制定、发布的具有普遍约束力的决定命令；对行政机关工作人员的奖惩任免等决定；法律规定的行政终局裁决。命中则 `现有依据不支持` 写入复议范围。
3. **调解与指导**：行政调解、行政指导等不具强制力的行为，原则上 `现有依据不支持` 进入复议范围，除非材料证明已转化为设定义务的决定。
4. 材料只证明“不满意”而不能对应到具体行为：`依据不足，无法形成结论`。

---

## 节点 3　诉讼受案

运行时核验行政诉讼法第十二条、第十三条及行诉解释相关条文。不得把 1989 年文本当作现行受案清单。

1. 受案正列与复议范围对照，但两者不是同一集合：复议维持后的共同被告诉讼、复议前置未完成的诉讼入口，必须分开标注。
2. 排除：国防外交；行政法规、规章或具有普遍约束力的决定命令；奖惩任免等内部行为；法律规定由行政机关最终裁决的行为。
3. 最终裁决必须有法律明文。国务院作出的裁决是否终局，须核验现行复议法后再写，未核验则该行停止。不得把普通复议决定写成终局。
4. 抽象规定不得单独起诉。对规定不服只能标附带审查接口，不在本任务展开。

---

## 节点 4　内部行为、过程行为

| 类型 | 若 | 则 |
| --- | --- | --- |
| 内部人事 | 奖惩、任免、考核、调岗仅约束机关内部人事关系 | `J-诉` `J-复` 均为现有依据不支持 |
| 内部请示批复 | 未对外发生法律效果 | 不得写成可诉行政行为 |
| 过程行为 | 告知、调查通知、听证通知、内部审核意见 | 默认不可诉；仅当已独立设定权利义务或产生强制效果时进入可诉候选 |
| 重复处理 | 对同一事实作出的重复告知或重复答复 | 审查是否产生新的法律效果；无新效果则不得另开可诉对象 |
| 刑事措施 | 搜查、扣押、拘留以刑事名义实施 | 整案转刑事，本任务停止 |

过程行为“可能影响权利”本身不等于独立法律效果。用户主张告知书已限权时，必须指出具体义务或处分内容，否则 `依据不足，无法形成结论`。

---

## 节点 5　输出闸

| 条件 | 本任务输出 | 不得输出 |
| --- | --- | --- |
| 可复议且可诉 | 两行均支持，并提示路径互斥与前置待核 | 选定复议机关或法院 |
| 仅可复议 | 诉讼行不支持或须先复议 | 直接写成应起诉 |
| 仅可诉 | 复议排除或复议窗口已过且诉讼仍可 | 编造仍可复议 |
| 两者皆不可 | 排除理由和最强反方 | 改写成民事起诉或劳动仲裁 |
| 对象不明 | 缺口清单 | 用用户感受补一个可诉行为 |

劳动争议应走仲裁或民事诉讼的，明确写：劳动仲裁不是行政诉讼。用户要总体策略、管辖或文书时目标停止。
