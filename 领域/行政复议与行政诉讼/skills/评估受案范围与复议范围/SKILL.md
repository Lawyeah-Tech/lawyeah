# 评估受案范围与复议范围

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1989 年行政诉讼法、1996 年行政处罚法或 1999／2017 年行政复议法当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“复议范围与诉讼受案分流表”：行为是否属于复议范围、是否属于行政诉讼受案范围、内部行为／过程行为／最终裁决／抽象规定分流，以及不得包装成可诉的情形。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：单独委托判断该行为或相应不作为能否申请复议或提起行政诉讼，尚未要求选定复议机关、受诉法院或形成总体策略。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要总体评估矩阵（转 `评估行政行为争议`）；
- 只要选定复议机关或受诉法院（转路径或管辖原子）；
- 只要复议申请或起诉状终稿；
- 刑事强制措施或刑事责任；
- 纳税争议实体方案（转税务）；

本任务不替代总体评估，不选定复议机关或法院，不给胜诉率或必然受理结论。

## 建立可诉性坐标

确认：使用者与授权；单方立场；文书名称与文号；作出机关；行为或相应不作为的内容；是否内部人事或过程性文书；是否声称国务院终局或法律终局；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关文书；`C#` 规范定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`J#` 可诉性行；`V#` 评估版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验 2023 年复议法第十一条、第十二条，行政诉讼法第十二条、第十三条及行诉解释关于过程行为、内部行为的条文；`search_practiced` 补过程行为独立法律效果的反例。

工具不可用时继续文书定性、主体名义和排除清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [可诉性方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1 专项分流和文书固定

先做刑事、税务实体、竞争环境实体、劳动实体分流。再固定文书版本、作出名义和是否对外发生法律效果。口头转述不得单独写成已对外发生效果。
### 节点 2 复议范围行

对照现行复议范围与排除清单逐项落 `J-复`。内部人事处理、行政调解、行政指导、国家行为分别建行。材料不足则该行 `依据不足，无法形成结论`。
### 节点 3 诉讼受案行

对照行政诉讼法受案与排除清单落 `J-诉`。国防外交、最终裁决、内部奖惩任免、法律规定行政终局不得写成可诉。规范性文件本身不得单独起诉。
### 节点 4 内部、过程、终局过滤器

内部行为、过程行为、最终裁决分列。过程行为仅在产生独立法律效果时才可进入可诉候选，否则负向。最终裁决须有法律明文，不得把复议决定本身写成终局。
### 节点 5 分流而不选定论坛

可复议／可诉／两者皆不可／须先复议只出分流，不选定复议机关或法院。用户坚持要法院名称或申请书时目标停止。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；对象文书无法建立；用户坚持把内部人事或刑事措施包装成行政诉讼。
- `字段停止`：规范未核验；文书是否对外发生效果不明；最终裁决依据不明。
- `目标停止`：主目标已变为总体评估、选定法院、复议申请或起诉状。
