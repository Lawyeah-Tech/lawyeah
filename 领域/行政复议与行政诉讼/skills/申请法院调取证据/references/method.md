# 调取申请方法

判断只用三态。禁止违法调取个人信息。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 被告要补卷 | 负触发；提示自行取证禁令 |
| 只要财产保全 | 转保全原子 |
| 用户要一份空白调查令去银行随便查 | 整体停止 |
| 未立案只要律师调查 | 本任务不签发调查令 |

---

## 节点 1　条件

运行时核验行政诉讼法第四十一条。三项情形分列，至少一项有事实支持，否则申请必要性 `依据不足`。

---

## 节点 2　范围

每项 `T#` 必须具体到文件名称、时间段、保管单位。禁止“该局全部执法记录”“某自然人三年通话”。涉及个人信息须说明与本案直接关联和最小必要。

---

## 节点 3　申请稿

法院名称、案号、申请人、调取对象、线索、证明目的、不能自行收集的原因、附件。只交草案。不保证准许。

---

## 节点 4　与举证期

调取申请应在举证期限内提出，规则核验。逾期须说明正当理由，否则风险写入。

---

## 节点 5　安全

不指导伪造法院文书。不指导买卖个人信息。国家秘密材料只请求由法院依法调取和查阅，不要求复制给当事人。

## 节点补强：主体、范围、期限

1. 被告申请调取补合法性：负触发。
2. 对象必须具体。禁止“该局全部执法记录”或打捞无关通话。
3. 申请应在举证期限内提出，逾期须正当理由。
4. 国家秘密只请求法院依法调取查阅，不要求复制给当事人。
5. 伪造调查令或买卖个人信息：整体停止。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（申请法院调取证据）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（调取申请、范围、必要性）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：禁止违法调取个人信息。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
