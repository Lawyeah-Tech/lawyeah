# 申请法院调取证据

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1989 年行政诉讼法、1996 年行政处罚法或 1999／2017 年行政复议法当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的原告或第三人立场下，形成调取申请、范围和必要性说明。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：关键证据由行政机关或第三人掌握，原告或第三人需要申请法院调取。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 违法调取个人信息；
- 被告要法院替自己补合法性证据；
- 只要普通举证期限规划；

禁止违法调取个人信息。被告对合法性举证，不得把调取写成替被告补卷。

## 建立调取坐标

确认：使用者与授权；待调取对象；控制方；与请求的关联；是否已自行收集不能；立案状态。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 文书；`C#` 规范定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`T#` 调取项；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验行政诉讼法第四十一条及行诉解释原告申请调取的条件。

工具不可用时继续控制方、对象和自行收集不能的事实登记；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [调取申请方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1 申请主体

原告或第三人。被告申请调取补合法性通常负触发。
### 节点 2 法定情形

由国家有关部门保存须法院调取、涉及秘密、确因客观原因不能自行收集。
### 节点 3 范围必要

对象具体，禁止概括调取全部个人信息或无关通信。
### 节点 4 申请稿

证据名称、线索、证明目的、不能自行收集的原因。
### 节点 5 安全

拒绝设计爬取、收买内部人员或伪造调查令。

## 停止与安全

- `整体停止`：设计违法调取个人信息或伪造调查令。
- `字段停止`：调取条件和期限规则未核验。
- `目标停止`：主目标已变为普通举证规划或违法调查。

## 交付

严格按 [输出合同](references/output-contract.md) 10节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
