# 停止执行方法

判断只用三态。不保证裁定。原则上不停止执行。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 要查封对方财产或行为保全 | 转 `apply-preservation` |
| 非诉执行审查中的异议 | 转 `object-to-non-litigation-enforcement` |
| 尚未复议或起诉且只要评估强制 | 转强制评估 |
| 税务强制执行停止实体 | 转税务 |

---

## 节点 1　原则

运行时核验复议法和行政诉讼法停止执行条款。默认输出必须写：申请不等于停止，裁定前行为仍可能被执行。

---

## 节点 2　例外

典型例外：被告认为需要停止；原告或利害关系人申请且不停止会造成难以弥补损失、停止不损害国家或社会公共利益；法律、法规规定停止。每项独立判断。

难以弥补：房屋即将拆除、许可证即将注销且无法恢复、不可逆的信息公开。单纯罚款、可回转金钱给付，通常难证明难以弥补。

---

## 节点 3　申请对象

复议阶段向复议机关。诉讼阶段向法院。须有已受理的复议或诉讼，否则入口待核。

---

## 节点 4　草稿

请求停止的具体行为、损失证据、公共利益权衡、担保是否需要（规则核验）。不把申请写成裁定。

---

## 节点 5　安全

禁止指导对抗已生效强制措施或破坏现场。裁定前的执行风险必须明示。

## 节点补强：原则不停止

1. 申请不等于停止。裁定前行为仍可能被执行，必须明示。
2. 单纯可回转金钱给付，难以弥补通常偏弱。
3. 拆除、吊销后无法恢复、不可逆公开：难以弥补候选。
4. 财产保全或非诉异议：负触发。
5. 禁止指导对抗已生效强制或破坏现场。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（申请停止执行行政行为）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（停止执行申请、损失与公共利益权衡）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：不保证裁定；诉讼期间原则上不停止执行。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
