# 规划举证期限与补充证据

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1989 年行政诉讼法、1996 年行政处罚法或 1999／2017 年行政复议法当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成举证期限卡、被告逾期举证后果和原告补证申请要点。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：已立案，需要在举证期内完成举证或提出补证、延期。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 完整案卷策略；
- 庭审质证终稿；
- 尚未立案只要起诉证据目录；

不替代整本案卷或庭审质证。被告十五日举证以送达日起算。

## 建立举证期限坐标

确认：使用者与授权；立案和应诉通知送达日；举证期限指定；已提交清单；是否共同被告；立场。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 应诉或举证通知；`C#` 规范定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`K#` 期限卡；`V#` 版本；`E#` 送达凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验行政诉讼法第六十七条十五日举证和补证、延期规则。

工具不可用时继续应诉通知送达日和已提交清单登记；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [举证期限方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1 期限卡

被告收到起诉状副本之日起十五日。作出日不得代替送达日。法院指定期另列。
### 节点 2 被告逾期后果

无正当理由逾期提供的，视为没有证据，规则须核验例外。
### 节点 3 原告补证

起诉条件、不作为申请事实、赔偿损失等由原告提供。补证申请须说明理由。
### 节点 4 共同被告分工

原机关与复议机关对原行为共同举证；复议决定由复议机关举证。
### 节点 5 延期与排除

延期申请、逾期说明。不在本任务写质证终稿。

## 停止与安全

- `整体停止`：设计事后伪造执法记录以规避逾期。
- `字段停止`：送达日不明；十五日或指定期规则未核验。
- `目标停止`：主目标已变为质证或完整建卷。
