# 调查应对方法

判断只用三态。禁止教唆毁灭证据、威胁执法人员或伪造材料。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 刑事立案、监察调查、留置讯问 | 转刑事 |
| 税务稽查底稿和税负实体 | 转税务；一般检查程序可留 |
| 已到处罚告知阶段只要陈述 | 转陈述原子 |
| 用户要求“把资料毁了” | 整体停止 |

---

## 节点 1　权限核验

1. 执法证件、两人以上、检查范围与事项管辖。
2. 无证件或明显越权：记录异议、最小化配合、即时固定执法者信息。不得指导锁门对抗或抢夺执法记录仪。
3. 抽样取证、先行登记保存须有手续。

---

## 节点 2　配合边界

| 若 | 则 |
| --- | --- |
| 要求与本案相关的账簿、许可证、现场 | 依法配合，列清单 |
| 要求与本案无关的个人通信或全体员工隐私 | 标超出范围，要求书面说明 |
| 要求当场出具认错书 | 不写成必须签署；可核对事实后签字 |
| 涉及商业秘密 | 申请保密，提交最小必要副本 |

---

## 节点 3　询问笔录

有权核对、补正。笔录与陈述不一致必须指出。不得教唆统一口径作伪。当事人有权进行陈述申辩，调查阶段不等于已放弃听证。

---

## 节点 4　材料提交

每项 `M#`：名称、原件或复制件、控制方、是否提交、保留证据、法律风险。无法提供须真实说明，不得虚构丢失。

---

## 节点 5　安全

禁止毁灭、隐匿、篡改。出现刑事信号立即转出。C 端税务检查应对只分流，不降级本任务。

## 节点补强：配合与禁止

1. 刑事立案、监察留置：转刑事，不得按行政策略隐匿。
2. 无证件或明显越权：记录异议、最小化配合，禁止锁门对抗或抢夺执法记录仪。
3. 要求与本案无关的全体员工通信：标超出范围，要求书面说明。
4. 用户要求毁资料或统一作伪：整体停止。
5. 笔录与事实不符必须指出补正。配合不等于自认违法。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（应对行政调查询问）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（配合边界、权利告知核验、材料提交清单）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：禁止教唆毁灭证据或妨碍执法；刑事立案转刑事。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
