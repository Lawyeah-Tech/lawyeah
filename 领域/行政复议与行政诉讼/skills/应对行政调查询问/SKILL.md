# 应对行政调查询问

## 任务目标

在明确、无利益冲突的相对人立场下，形成配合边界、权利告知核验和材料提交清单。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：被检查、询问或要求提供材料，需要合法配合边界。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 刑事讯问或搜查（转刑事）；
- 教唆毁灭证据或妨碍执法；
- 只要陈述申辩终稿；

禁止教唆毁灭证据或妨碍执法。刑事立案转刑事。

## 建立调查应对坐标

确认：使用者与授权；检查或询问通知；执法人员身份；要求提供的材料范围；是否已立案处罚；有无刑事信号；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 通知与笔录；`C#` 规范定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`M#` 材料项；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1989 年行政诉讼法、1996 年行政处罚法或 1999／2017 年行政复议法当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验处罚法、强制法关于表明身份、抽样和复制材料的条文。

工具不可用时继续通知文书、身份出示和材料范围登记；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [调查应对方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1 行刑分流

限制人身自由的讯问、刑事立案或监察调查转出。行政检查不得按刑事辩护策略隐匿。
### 节点 2 身份与权限

两名以上执法人员、证件、检查通知。越权检查标异议，但不指导暴力抗拒。
### 节点 3 配合边界

依法提供材料与超出范围的捕捞式调取分列。商业秘密标最小必要。
### 节点 4 笔录与签字

核对笔录、补正、拒绝在失实处签字的要点。不得教唆作虚假陈述。
### 节点 5 材料清单

逐项列提交、保留副本、无法提供的理由。禁止毁灭。

## 停止与安全

- `整体停止`：教唆毁灭证据、伪造材料或暴力抗法；刑事程序已启动仍按行政策略隐匿。
- `字段停止`：检查权限或材料范围规范未核验。
- `目标停止`：主目标已变为陈述申辩或刑事辩护。

## 交付

严格按 [输出合同](references/output-contract.md) 10节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
