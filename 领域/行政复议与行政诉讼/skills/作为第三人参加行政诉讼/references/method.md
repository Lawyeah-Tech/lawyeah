# 第三人参加方法

判断只用三态。与被告答辩不同。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 用户其实是被告 | 转应诉原子 |
| 没有行政案件 | 转相应民事或劳动领域 |
| 劳动仲裁第三人 | 劳动领域 |
| 只要证人出庭 | 不是第三人参加 |

---

## 节点 1　资格

同业竞争者、相邻权人、许可争议的另一方、征收中的共有权人等可能具备。仅有情感关注或新闻兴趣：现有依据不支持。

---

## 节点 2　参加

申请书：案号、利害关系、请求（参加诉讼）、证据。法院可通知必须参加的第三人。被通知而不参加的后果核验。

---

## 节点 3　独立请求

对诉讼标的有独立请求：可提出自己的请求，注意期限。无独立请求：陈述事实和意见，防止被告处分损害自己。

---

## 节点 4　与被告边界

不得在未授权时代被告承认违法或承诺履行。利益冲突时整体停止双方策略。

---

## 节点 5　输出

参加申请或陈述提纲、独立请求评估。不写被告答辩状。

## 节点补强：利害关系

1. 用户其实是被告：转应诉。劳动仲裁第三人：转劳动。
2. 仅有新闻兴趣：现有依据不支持参加。
3. 有独立请求与辅助一方分列。未授权不得代被告承认违法。
4. 利益冲突时代理双方：整体停止。
5. 被通知而不参加的后果须核验。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（作为第三人参加行政诉讼）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（参加申请或陈述、独立请求评估）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：与被告答辩不同。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
