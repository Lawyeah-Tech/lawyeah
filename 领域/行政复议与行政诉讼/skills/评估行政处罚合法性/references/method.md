# 处罚合法性方法

判断只用三态。不得输出必然撤销、必然不罚或唯一必处金额。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 税务处罚与税额核定、滞纳金绑在一起 | 整案转税务 |
| 垄断协议、滥用支配地位处罚实体 | 转竞争法 |
| 环境违法处罚的排污许可或环评实体 | 转环境能源；一般程序争点可留接口 |
| 已刑事立案同一事实 | 转刑事；不得建议以罚代刑 |
| 只要陈述或听证终稿 | 目标停止 |

---

## 节点 1　种类与主体

1. 处罚种类分列，不得把责令改正当然写成处罚，也不得把强制措施写成处罚。
2. 主体：法律、法规、规章授权；委托须书面且不得再委托。内设机构以自己名义作出的，主体行 `现有依据不支持` 或待核。
3. 相对人是否自然人、法人或不具法人资格的组织，影响听证申请人和救济资格，分列。

---

## 节点 2　事实与依据

1. 构成要件逐项回链。只有“存在违法行为”的结论句，事实行 `依据不足，无法形成结论`。
2. 证据须在告知前形成。事后补做的现场笔录标红旗。
3. 依据必须公布且现行有效。内部红头文件不得单独作为处罚依据；可进入附带审查接口。
4. 新法旧法适用必须核验从旧兼从轻等现行规则，未核验则依据行停止。

---

## 节点 3　程序

运行时核验 2021 年处罚法第四十四条至第六十三条等条文。

| 步骤 | 若缺失 | 则 |
| --- | --- | --- |
| 立案或调查表明身份 | 无执法证件或无立案痕迹 | 程序争点成立候选 |
| 事先告知 | 决定前未告知事实理由和权利 | 不得写成轻微瑕疵当然可忽略 |
| 陈述申辩 | 拒绝听取 | 程序违法争点 |
| 听证 | 命中听证范围未告知或拒绝 | 独立争点，不并入陈述 |
| 集体讨论 | 情节复杂或重大，依法应集体讨论 | 待核 |
| 送达 | 送达不明 | 期限字段停止，另转送达原子 |

简易程序当场处罚须符合现行条件，不得把普通程序案件改写成已合法当场处罚。

---

## 节点 4　听证、时效、过罚相当

1. 听证范围：较大数额罚款、没收较大数额违法所得或非法财物、降低资质等级、吊销许可证件、责令停产停业、责令关闭、限制从业等，门槛运行时核验。
2. 追责时效：违法行为发生日起算；连续或继续状态从终了日起算。年限必须核验，未核验停止。
3. 过罚相当、首违不罚、从轻减轻、减轻到幅度以下分别建接口，不自动改写拟处结果。
4. 必须提示：行政机关不得因当事人陈述申辩而给予更重处罚。该句不是已减轻。

---

## 节点 5　输出闸

不产出发送版陈述、听证提纲或复议申请。金额只给幅度接口，未知不写零。用户要“保证能撤”时拒绝。

## 节点补强：拟处种类与权利窗口

1. 先锁定文书是告知还是决定。告知阶段主成果是争点表，不是复议申请。决定已送达则陈述窗口关闭，救济转复议或诉讼接口。
2. 若种类命中听证范围但告知未载明听证权：程序争点成立候选，同时红旗申请期可能已起算。
3. 若同一事实已刑事立案：停止把本案写成“只是罚款”，转刑事并禁止以罚代刑建议。
4. 若相对人只要发送版陈述：目标停止，争点表可作为交接，不在本任务出稿。
5. 首违不罚、从轻减轻必须各建一行接口。材料只有“态度好”：从轻行 `依据不足，无法形成结论`。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。
