# 评估行政处罚合法性

## 任务目标

在明确、无利益冲突的相对人立场下，形成行政处罚合法性争点表：主体、事实、依据、程序、过罚相当、听证权利、首违不罚或从轻接口，以及不得因申辩加重的提示。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：拟处罚或已决定，相对人需要判断主体、事实、依据、程序和过罚相当，但尚不要发送版陈述或听证终稿。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要发送版陈述申辩（转 `准备陈述申辩`）；
- 只要听证材料或听证申请；
- 税务处罚税额或滞纳金实体（转税务）；
- 反垄断或环境监管处罚实体方案；

不输出陈述申辩终稿。税务处罚实体转税务。竞争环境专项实体转出。不给必然撤销或必然不罚。

## 建立处罚评估坐标

确认：使用者与授权；相对人；作出或拟作出机关；告知书或决定书文号；拟认定事实；拟适用依据；是否已听证；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关文书；`C#` 规范定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 合法性争点；`V#` 评估版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1989 年行政诉讼法、1996 年行政处罚法或 1999／2017 年行政复议法当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验 2021 年行政处罚法关于主体、程序、听证、首违不罚、追责时效和过罚相当的条文。

工具不可用时继续文书、主体、告知和拟处种类登记；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [处罚合法性方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1 专项分流和处罚种类

税务处罚实体、竞争或环境专项实体、刑事立案转出。固定警告、罚款、没收、暂扣或吊销许可、限制从业、行政拘留等种类，不得合成一笔“处罚权益”。
### 节点 2 主体与管辖

作出名义、委托、授权、内设机构以自己名义作出的，分别判断。地域和事项管辖冲突标待核。
### 节点 3 事实、证据与依据

时间、地点、行为、后果必须可回链。依据是否公布、是否适用于本案。未经公布的不得作为处罚依据。
### 节点 4 程序、听证与时效

立案、调查、告知、听证、决定、送达分列。较大数额等听证门槛运行时核验。追责时效未核验则该行停止。
### 节点 5 过罚相当与从轻接口

首违不罚、从轻减轻、不予处罚只标接口，不写成已减轻。不得因申辩加重必须提示。

## 停止与安全

- `整体停止`：立场不明；教唆虚假陈述；把刑事案包装成仅行政处罚。
- `字段停止`：听证门槛、追责时效或依据效力未核验。
- `目标停止`：主目标已变为陈述、听证或复议申请。
