# 谈判行政争议协调方案

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1989 年行政诉讼法、1996 年行政处罚法或 1999／2017 年行政复议法当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“行政争议协调方案”：争点让步表、法定可调事项、底线、弃权范围和执行力提示。

`depends-on` 为空。

## 工作边界

正触发：行政争议仍可与机关或第三人谈，需要底线和可调范围。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要已谈拢的协议正文；
- 要求就处罚合法性本身做违法交易或花钱买不处罚且无法律依据；
- 只要答辩状；
- 刑事和解冒充行政协调。

本任务不保证对方接受，不把谅解书写成已具执行力。

## 建立谈判坐标

确认：立场；授权处分范围；是否已复议或诉讼；争议事项是否属于赔偿、补偿、行政协议等可调范围；法域。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关文书；`C#` 规范定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 争点；`N#` 让步档；`W#` 弃权；`V#` 方案版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验行政诉讼调解范围和复议调解规则。工具不可用时继续争点表；可调范围结论字段停止。

## 五个判断节点

执行顺序和停止条件以 [协调方法](references/method.md) 为准。

### 1. 仍可谈和授权

已起诉仍可能协调。授权不明不得处分权利。

### 2. 法定可调范围

赔偿、补偿、行政协议等可调；处罚合法性本身不得违法调解。范围未核验则字段停止。

### 3. 让步表

开价、可谈、底线三档。不把多项折成一笔了结款。

### 4. 弃权闸

未获明示确认不得写已放弃复议或起诉。

### 5. 执行力

单独谅解无执行力必须明示。调解书或复议调解另项转介。

## 停止与安全

- `整体停止`：行贿买销案；伪造和解。
- `字段停止`：调解范围未核验。
- `目标停止`：主目标已变为协议正文或答辩。
