# 协调方法

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出对方必接受、法院必出具调解书或花钱即可撤销处罚。

## 节点 0　分流

刑事和解转刑事。税务和解或事先裁定转税务。要求向执法人员输送利益以换取不处罚：整体停止。

## 节点 1　仍可谈与授权

1. 固定使用者、代表主体、授权范围。超越授权的让步不得写入底线以下。
2. 已复议或已诉讼，只要依法仍可协调，本任务仍可正触发。用户只要答辩：负触发。
3. 报价记录分列提出人、渠道、是否到达、是否附期限。聊天已读不等于承诺。

## 节点 2　法定可调范围

运行时核验行政诉讼法关于调解的规定：人民法院审理行政案件一般不适用调解，但行政赔偿、补偿以及行政机关行使法律、法规规定的自由裁量权的案件可以调解。复议调解规则另行核验。

| 事项 | 本任务 |
| --- | --- |
| 赔偿金额、支付时间 | 可建让步档 |
| 征收补偿金额（程序救济背景下的谈判接口） | 可建档，实体标准转出 |
| 行政协议变更解除履行 | 可建档 |
| 裁量权范围内的处罚种类或幅度 | 仅在有法律依据的裁量内建档，并标机关内部审批风险 |
| 处罚合法性本身、虚构不违法 | 禁止作为成交条件 |
| 损害公共利益、第三人合法权益 | 禁止 |

范围未核验：可调结论字段停止，争点表可继续。

## 节点 3　让步矩阵

固定列：`Q#｜争点｜主位主张｜开价｜可谈｜底线｜对价｜互斥｜弃权接口｜最强反方｜判断`。

撤销请求与赔偿请求分列。不得把“不再告了”写成唯一对价而不写保留项。金额引用已有测算或用户材料，不替代测算原子。

## 节点 4　弃权闸

`W#` 必须逐项：是否放弃复议、起诉、赔偿、公开请求。未获用户对具体范围的明示确认，不得写成已放弃。撤回后再申请或再诉的风险转撤回原子（未安装则提示 `unavailable`）。

## 节点 5　执行力

单独谅解、会议纪要、调解书、复议调解书分列效力。单独谅解无强制执行力必须明示。需要补强时转介执行力原子（未安装则 `unavailable`）。
