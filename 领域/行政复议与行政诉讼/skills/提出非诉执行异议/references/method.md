# 非诉执行异议方法

判断只用三态。与诉讼应诉不同。禁止拒不执行。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 起诉期限未满且用户可以起诉 | 强烈提示诉讼入口，异议不是替代 |
| 已在诉讼中 | 转应诉；非诉应停止 |
| 执行的是法院判决 | 转 `resist-enforcement` |
| 藏匿财产 | 整体停止 |

---

## 节点 1　审查标准

法院对非诉执行做适度审查：明显缺乏事实根据、明显缺乏法律依据、其他明显违法并损害被执行人合法权益。一般争议不等于明显违法，但期限未满、未送达、无依据属于强争点。

---

## 节点 2　意见稿

请求不准予执行或撤销准予裁定、事实、明显违法点、证据。不写成全面行政诉讼起诉状，除非用户改走诉讼且期限允许。

---

## 节点 3　期限

提出书面意见或异议的期限核验。送达审查通知不明则字段停止。

---

## 节点 4　效果

不准予则机关不能依靠该裁定执行。已执行部分的回转接口另列。

---

## 节点 5　输出

异议要点。提示：能起诉时不要只用异议放弃诉权。

## 节点补强：明显违法与诉权

1. 起诉期限未满且仍可起诉：必须提示诉讼入口，异议不是替代。
2. 已在诉讼中：转应诉，非诉应停止。
3. 未送达、无依据、期限未满是强争点。一般争议不等于明显违法。
4. 禁止指导藏匿财产。
5. 执行的是法院判决：转裁判执行应对。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（提出非诉执行异议）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（异议／审查意见、明显违法争点）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：与诉讼应诉不同。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
