# 提出非诉执行异议

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1989 年行政诉讼法、1996 年行政处罚法或 1999／2017 年行政复议法当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的相对人立场下，形成异议或审查意见和明显违法争点。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：法院审查非诉执行或已裁定准予，相对人要提出异议。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 诉讼应诉；
- 起诉期限未过却只想异议而不行使诉权（须提示）；
- 教唆拒不执行；

与诉讼应诉不同。

## 建立非诉异议坐标

确认：使用者与授权；行政决定；法院审查通知或准予裁定；送达和起诉期限事实；明显违法争点。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 决定与执行裁定；`C#` 规范定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`O#` 异议点；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验非诉执行审查标准和相对人权利。

工具不可用时继续审查通知、决定和期限事实登记；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [非诉执行异议方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1 阶段

审查中发表意见与裁定后异议分列。
### 节点 2 明显违法

明显缺乏事实、法律依据，或损害被执行人合法权益。
### 节点 3 期限未满

起诉期未满是不准予执行的强理由。
### 节点 4 与诉讼不同

不按全面合法性审查写诉状，但明显违法必须展开。
### 节点 5 禁止拒执

异议期间仍须依法应对，不指导藏匿财产。

## 停止与安全

- `整体停止`：教唆拒执或在可起诉时故意隐瞒诉讼入口。
- `字段停止`：非诉审查标准或异议期限未核验。
- `目标停止`：主目标已变为普通应诉或判决执行异议。
