# 义务机关申请方法

判断只用三态。不写赔偿诉讼状。未知不写零。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 刑事赔偿 | 转刑事 |
| 只要选路径 | 转 `assess-state-compensation-path` |
| 已处理或逾期只要起诉状 | 转 `file-state-compensation` |
| 征收补偿协商 | 转房地产，不是国家赔偿 |

---

## 节点 1　义务机关

作出违法行政行为的机关。两个以上机关共同：可向其中任何一个请求，规则核验。复议机关加重损害：加重部分由复议机关履行。

---

## 节点 2　申请事项

申请人、具体请求、事实理由、证据。项目分列，禁止合成“行政赔偿一笔”。人身自由赔偿金年度标准未核验则该行 `无法估计`。

---

## 节点 3　处理期限

义务机关处理期限运行时核验。未核验则逾期起算字段停止。申请不当然停止对原行为的复议起诉期限。

---

## 节点 4　草稿

只交付草案。不代提交。不把申请写成已获赔。

---

## 节点 5　失败分流

全部或部分不予赔偿、逾期不处理：单独提起行政赔偿诉讼接口。未确认违法且未走行为之诉：提示路径风险。

## 节点补强：申请与逾期

1. 刑事赔偿或征收补偿：转出。只要路径比较：转路径原子。
2. 项目分列，禁止合成一笔。年度标准未核验则该行无法估计。
3. 申请不停止对原行为的复议起诉期限。
4. 机关逾期或处理不服：单独赔偿诉讼接口。
5. 不把申请写成已获赔，不写起诉状。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（向赔偿义务机关申请赔偿）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（赔偿申请、项目、义务机关）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：不写赔偿诉讼状；刑事赔偿转刑事。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
