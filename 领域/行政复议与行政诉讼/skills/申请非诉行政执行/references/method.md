# 非诉执行申请方法

判断只用三态。起诉期限未满不得包装成可执行。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 相对人已起诉或复议未结 | 负触发 |
| 起诉期限未满 | 负触发 |
| 权利人执行法院判决 | 转生效裁判执行 |
| 税务强制执行实体 | 转税务 |

---

## 节点 1　届满

必须同时支持：决定已生效、已依法送达、复议和起诉期限届满或未申请、相对人未履行。任一项不明：停止申请结论。

---

## 节点 2　催告

申请法院强制执行前依法催告，催告期核验。未催告列入缺口，不假装已可受理。

---

## 节点 3　材料

行政决定、送达凭证、催告书、相对人身份财产线索、申请书。决定明显缺乏事实或法律依据：应自我纠正，不指导强行申请。

---

## 节点 4　管辖期限

申请法院执行的期限和管辖运行时核验。逾期申请风险必须写。

---

## 节点 5　输出

申请包。不保证准予。不隐瞒已起诉事实。

## 节点补强：届满闸

1. 起诉或复议期限未满：负触发，不得包装成可执行。
2. 相对人已起诉或复议未结：负触发。
3. 送达不明：期限字段停止，不得申请。
4. 申请前依法催告，未催告列入缺口。
5. 决定明显缺乏事实或法律依据：应自我纠正，不指导强行申请。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（申请非诉行政执行）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（非诉执行申请、起诉期限届满核验）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：起诉期限未满不得包装成可执行。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
