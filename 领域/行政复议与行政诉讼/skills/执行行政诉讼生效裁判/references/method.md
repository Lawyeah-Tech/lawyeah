# 生效裁判执行方法

判断只用三态。不重审实体。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 裁判未生效 | 转上诉或等待生效 |
| 机关要执行自己的处罚决定 | 转非诉执行 |
| 复议决定未履行 | 转 `apply-enforcement-of-reconsideration` |
| 要再审 | `unavailable` |

---

## 节点 1　名义与内容

生效证明、主文可执行性。仅确认违法而无给付或重作内容：执行入口可能打不开，转赔偿或另诉接口。

---

## 节点 2　申请

执行管辖一般为第一审法院。申请执行期限运行时核验。被执行人是行政机关时写明账户或应履行的行为。

---

## 节点 3　升级

行政机关拒绝履行：法院可通知银行划拨、对机关负责人罚款、将信息纳入信用、向监察或上级提出司法建议、情节严重拘留负责人。每项条件核验，不写成必然拘留。

---

## 节点 4　和解接口

执行中和解转执行和解原子。不在本任务放弃判项。

---

## 节点 5　输出

申请草稿、履行内容、升级清单。不重审。不保证执行到位。

## 节点补强：名义与升级

1. 裁判未生效：负触发。机关执行自己的处罚：转非诉执行。
2. 仅确认违法无可执行内容：执行入口可能打不开。
3. 机关拒不履行：划拨、罚款、司法建议、拘留负责人等须逐项核验，不写成必然拘留。
4. 不重审实体。再审 unavailable。
5. 申请执行期限未核验则该行停止。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（执行行政诉讼生效裁判）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（执行申请、履行内容、机关拒不履行升级）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：不重审实体。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
