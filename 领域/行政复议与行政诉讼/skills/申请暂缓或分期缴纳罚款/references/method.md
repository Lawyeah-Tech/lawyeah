# 缓缴申请方法

判断只用三态。不把申请写成已获准。不停止复议起诉期限。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 税款、滞纳金、纳税担保 | 转税务 |
| 只要复议或起诉 | 转对应原子，并提示可并行申请缓缴 |
| 加处罚款是否超上限精算 | 转测算原子 |
| 用户要“申请了就不用交也不用告” | 纠正并继续或目标停止 |

---

## 节点 1　适用范围

运行时核验 2021 年处罚法第六十六条。当事人确有经济困难，可申请延期或分期缴纳。对象是罚款，不是没收财物。

---

## 节点 2　困难证据

收入、负债、重大疾病、停产、银行流水。企业须区分股东财产与企业财产。证据不足则困难行 `依据不足`，草稿可写但封面标风险。

---

## 节点 3　方案

暂缓截止日期或分期期数、每期金额。方案应可执行，不得写“等有钱再交”。批准权在行政机关，本任务不代批。

---

## 节点 4　期限红旗

复议六十日、起诉六月等照常计算。缓缴申请不是时效中止。加处罚款是否继续计算须核验，未核验则该行停止。

---

## 节点 5　风险

不申请又不缴纳：强制执行或加处罚款。获准后违约：恢复执行。不得指导转移财产规避执行。

## 节点补强：缓缴不等于停救济

1. 对象限于罚款。税款滞纳金转税务。没收不是本任务。
2. 空泛“没钱”：困难行依据不足。
3. 申请不停止复议起诉期限，必须明示。
4. 不把申请写成已获准。获准后违约恢复执行。
5. 禁止指导转移财产规避罚款。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（申请暂缓或分期缴纳罚款）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（申请稿、困难证据、不履行风险）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：不把申请写成已获准；不停止复议起诉期限。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
