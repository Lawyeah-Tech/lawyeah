# 测算罚款没收与行政赔偿

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1989 年行政诉讼法、1996 年行政处罚法或 1999／2017 年行政复议法当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“罚款没收与行政赔偿可复核测算包”：事件编号、分项工作表、法定幅度接口、从轻减轻或首违不罚接口、赔偿项目、情景区间和缺口。

`depends-on` 为空。本任务**不认定处罚或赔偿责任已经成立**。

## 工作边界

正触发：行政争议已形成，单方需要罚款、没收、滞纳金、加处罚款或行政赔偿的可复核数字工作表。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要定性总图；
- 税务税额核定或税负测算；
- 征收补偿标准实体终值；
- 只要起诉状或复议申请。

本任务不输出唯一必处或必赔总额。未知不写零。真实零必须有肯定来源。

## 建立测算坐标

确认：使用者与授权；拟测算项目；告知或决定记载的幅度；已缴金额；损害事实；法域。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关文书；`C#` 规范定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`EVT#` 同一经济事件；`M#` 测算行；`V#` 工作表版本。

金额状态只用 `已核实金额`、`情景金额`、`无法估计`。
判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验处罚幅度、过罚相当、国家赔偿项目与标准。工具不可用时继续分项建账；法定上限、赔偿日标准和利息字段停止。

## 五个判断节点

执行顺序和停止条件以 [测算方法](references/method.md) 为准。

### 1. 分流和测算范围

税务核定、征收补偿实体转出。不把处罚写成已经成立。

### 2. 事件编号与分项建账

罚款、没收、滞纳金、加处罚款、赔偿项目分列。同一损失不得重复计入。

### 3. 法定幅度与裁量接口

幅度不是必处。从轻减轻、首违不罚、过罚相当只标接口。

### 4. 行政赔偿项目

人身自由、健康、财产直接损失分列。标准运行时核验。

### 5. 情景区间和缺口

汇总区分已核实、情景和无法估计。禁止唯一必得总额。

## 停止与安全

- `整体停止`：把未知当零；伪造流水。
- `字段停止`：幅度、赔偿标准未核验。
- `目标停止`：主目标已变为总图或文书。
