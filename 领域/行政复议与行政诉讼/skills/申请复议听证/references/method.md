# 复议听证申请方法

判断只用三态。不替代复议申请。不保证举行。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 尚未提交复议申请 | 转 `file-reconsideration` |
| 处罚决定前的听证 | 转处罚听证原子 |
| 诉讼开庭提纲 | 转 `prepare-hearing` |
| 纳税争议复议听证实体 | 转税务 |

---

## 节点 1　条件

运行时核验 2023 年复议法听证条款。申请人有权申请，是否举行由复议机关依法决定。重大复杂的事实争点、需要当面质证的，申请理由更具体。

---

## 节点 2　参加人

列申请人、代理人、被申请人、第三人。要求调查人员到场须说明必要。不得把无关群众列为必须参加人。

---

## 节点 3　焦点

`H-事实` `H-依据` `H-程序` `H-裁量` 各写一句争点，不粘贴整份复议申请书。

---

## 节点 4　草稿

案号、申请听证的意思、理由、参加人、焦点、联系方式。只交草案。

---

## 节点 5　效果

听证不是重新处罚听证。复议听证笔录影响复议决定，不当然停止执行。

## 节点补强：复议已形成

1. 无复议申请或未被受理：不能代替立案，转复议申请原子。
2. 处罚决定前听证或诉讼开庭：负触发。
3. 申请人有权申请，是否举行由复议机关依法决定，不保证举行。
4. 焦点分事实、依据、程序、裁量各一句，不粘贴整份复议申请。
5. 复议听证不当然停止执行。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（申请复议听证）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（听证申请、参加人、焦点）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：不替代复议申请本身。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
