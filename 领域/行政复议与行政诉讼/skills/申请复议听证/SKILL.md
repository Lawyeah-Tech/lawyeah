# 申请复议听证

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1989 年行政诉讼法、1996 年行政处罚法或 1999／2017 年行政复议法当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的申请人立场下，形成复议听证申请、参加人和焦点。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：重大复杂或依法应听证的复议案件，申请人要申请复议听证。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 替代复议申请本身；
- 处罚听证材料；
- 诉讼庭审提纲；

不替代复议申请本身。不保证举行听证。

## 建立复议听证坐标

确认：使用者与授权；复议案号或申请状态；案件是否重大复杂；申请人参加人；争议焦点。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 复议文书；`C#` 规范定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`H#` 焦点；`V#` 稿件版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验 2023 年复议法关于听证的条文。

工具不可用时继续复议案号、案件复杂性和参加人登记；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [复议听证申请方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1 复议是否已形成

无复议申请或未被受理，本任务不能代替立案。
### 节点 2 听证条件

重大、疑难、复杂或申请人提出且复议机关认为必要等，运行时核验。
### 节点 3 参加人

申请人、被申请人、第三人。证人不是当然参加人。
### 节点 4 焦点

事实、依据、程序分列，供听证使用，不重写复议申请。
### 节点 5 申请稿

只请求举行听证并列出焦点。不保证举行。

## 停止与安全

- `整体停止`：无复议案件仍制作听证申请冒充已受理。
- `字段停止`：复议听证条件未核验。
- `目标停止`：主目标已变为复议申请或诉讼庭审。
