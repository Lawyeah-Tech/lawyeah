# 评估复议起诉期限

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1989 年行政诉讼法、1996 年行政处罚法或 1999／2017 年行政复议法当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成分类型期间表：复议六十日、未告知复议权利最长一年、起诉六月、复议后十五日、不作为履行期满后期限、未告知起诉期限最长一年、不动产或其他最长保护期各占一行，并标起算事件与停止条件。

`depends-on` 为空。接受用户、律师、机关或其他来源的等价事实、测算和证据清单。

## 工作边界

正触发：单独委托核验复议申请期或起诉期是否届满，或需要把多种期间分开列清。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要总体评估或只要路径选择本身；
- 要求输出未核验的唯一截止日；
- 只要复议申请或起诉状；
- 纳税争议缴清或担保后的税务期限实体（转税务）；

禁止混算或输出唯一截止日。送达不明则期限字段停止。本任务不给胜诉率。

## 建立期间坐标

确认：使用者与授权；单方立场；文书作出日、送达日、送达方式；告知权利内容；申请履职日与履行期限；复议决定送达日；法域。

同时掌握双方秘密或潜在冲突时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关文书；`C#` 规范定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`K#` 期间行；`E#` 送达凭证；`V#` 评估版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验 2023 年复议法第二十条，行政诉讼法起诉期限现行条文，行诉解释未告知起诉期限与最长保护期条文。

工具不可用时继续作出日、送达事实和期间类型分列；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [期间方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1 送达与知悉事实

作出日与送达日分列。口头转述、截图、“已读”不得单独写成已送达或期限已起算。送达不明则全部截止日字段停止。
### 节点 2 复议期间行

知道或应当知道之日起六十日与未告知权利最长一年分列。法律另有更长期限的运行时核验。不可抗力是继续计算，不是重新起算。
### 节点 3 起诉期间行

一般六月、复议决定送达后十五日、复议逾期不答十五日、不作为履行期满后期限分列。不得用起诉六月去算复议六十日。
### 节点 4 未告知与最长保护期

未告知起诉期限最长一年与不动产二十年或其他最长保护期分列。起算点不同，禁止合成一个截止日。
### 节点 5 届满判断与禁止混算

每行独立给三态判断。日期冲突并列情景。用户要“就一天”时拒绝合成，只给已核验行。

## 停止与安全

- `整体停止`：立场不明；用户坚持伪造送达日或倒签知悉日。
- `字段停止`：送达不明；告知权利文句不明；动态期限条文未核验。
- `目标停止`：主目标已变为送达异议终稿、复议申请或起诉状。
