# 期间方法

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。禁止把多种期间混算成一个截止日。送达不明则期限字段停止，事实清单继续。

`search_law` 返回 1989 年行政诉讼法合议庭条文、1999／2017 年复议法或已失效《合同法》时记为噪声。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 纳税争议缴清、担保、复议前置期限实体 | 整案转税务 |
| 刑事强制措施羁押期限 | 转刑事 |
| 只要送达是否合法，不要期间表 | 负触发，转 `assess-delivery-and-service` |
| 只要申请书或诉状 | 目标停止 |

---

## 节点 1　起算事实

1. 每份文书登记：作出日、送达日、送达方式、回证、告知的权利与期限文句。
2. 作出日不得代替送达日。公告送达须另核公告条件，未核验不得用公告日强行起算。
3. 微信已读、短信回执、网站公示不得单独写成已送达。
4. 知悉日有冲突：并列 `K#` 情景，不选对用户最有利的一天。

---

## 节点 2　复议期间

运行时核验 2023 年复议法第二十条。

| 类型 | 规则锚点 | 允许输出 | 禁止 |
| --- | --- | --- | --- |
| 复议申请期 | 知道或应当知道之日起六十日；法律可更长 | 起算事件、备选起算、继续计算 | 唯一截止日 |
| 未告知复议权利、机关或期限 | 自知道该等内容之日起算，但自知道行为内容之日起最长一年 | 并行情景 | 用六十日冒充最长一年 |
| 不可抗力或其他正当理由 | 障碍消除后继续计算 | 障碍起止事实 | 重新起算全部六十日 |

法律另有更长期限必须指出法名和条号并核验。未核验则该行停止。

---

## 节点 3　起诉期间

运行时核验行政诉讼法现行起诉期限条文，不得用 1989 年第四十六条合议庭规定冒充起诉期限。

| 类型 | 允许输出 | 禁止 |
| --- | --- | --- |
| 一般起诉期 | 知道或应当知道之日起的六月情景 | 用六月去挡复议六十日 |
| 复议后起诉 | 复议决定送达后法定期限 | 用复议决定作出日代替送达日 |
| 复议逾期不答 | 复议期满之日起十五日情景 | 把申请日当成期满日 |
| 不作为 | 履行期限届满之日起算 | 把民事拖延写成行政不作为 |

复议前置未完成：起诉期间行标“入口未打开”，不得写成已经逾期。

---

## 节点 4　未告知起诉期限与最长保护期

运行时核验行诉解释第六十四条等现行条文。

1. 未告知起诉期限或复议决定未告知起诉期限：自知道或应当知道起诉期限之日起算，但自知道或应当知道行为内容之日起最长一年。
2. 涉及不动产的最长保护期与其他行为的最长保护期分列。未核验条号和年限则该行停止。
3. 最长保护期从行为作出之日起算，与知道之日起算的一般期限不是同一行。
4. 确认无效是否受普通起诉期限约束，必须运行时核验后才能落判断；未核验则该主张字段停止。

---

## 节点 5　届满判断

每条 `K#` 独立输出：起算事件、期间类型、已知日期、冲突情景、判断、待核。

| 若 | 则 |
| --- | --- |
| 送达和知悉均不明 | 全部截止日字段停止 |
| 仅一份文书日期清楚 | 只给该行情景，其他行停止 |
| 用户要求“就告诉我哪天截止” | 拒绝合成；列出已核验行和停止行 |
| 已能支持逾期 | 写明最强反方（未告知、不可抗力、继续计算） |
| 已能支持尚未起算 | 写明尚缺的送达或告知事实 |

不输出未核验的唯一截止日。不把申请暂缓缴纳罚款写成期限中止。
