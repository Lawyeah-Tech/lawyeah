# 追加变更被告方法

判断只用三态。法院可依职权列共同被告。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 尚未起诉，只要资格评估 | 转 `assess-standing-and-defendant` |
| 被告要异议管辖 | 转管辖异议 |
| 第三人要参加 | 转第三人原子 |

---

## 节点 1　类型

复议维持未列复议机关：追加共同被告。
复议改变却告了原机关：变更被告。
机构改革职权划转：变更或追加继受机关。
授权组织与委托机关混淆：按名义和授权文件判断。

---

## 节点 2　释明

法院告知应追加复议机关，原告不同意：法院可以依职权追加，也可以按司法解释处理，规则核验。本任务必须写明：不同意追加不等于能维持只告一个。

---

## 节点 3　申请稿

案号、现被告、拟追加或变更对象、事实理由、送达地址。只交草案。

---

## 节点 4　效果

追加后举证期限可能重新指定。漏列且未追加可能导致驳回起诉。

---

## 节点 5　输出

申请、释明应对、风险。不重写整份起诉状，除非用户目标已变为重做起诉。

## 节点补强：共同被告

1. 复议维持未列复议机关：追加共同被告。
2. 原告不同意追加：法院可依职权列，不同意不等于能只告一个。
3. 复议改变却告原机关：变更被告。
4. 告内设机构或政府办公室：按名义和授权判断变更。
5. 漏列且未追加可能导致驳回起诉。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（申请追加或变更被告）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（追加／变更申请、共同被告释明应对）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：不同意追加时法院可依职权列共同被告。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
