# 诉讼保全方法

判断只用三态。不保证裁定。与停止执行不同。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 停止行政行为本身的效力 | 转 `apply-stay-of-execution` |
| 只要公证固定网页 | 转公证原子 |
| 对方已保全，要复议或担保置换 | 转 `respond-to-preservation` |
| 非诉执行 | 转非诉执行原子 |

---

## 节点 1　种类

财产保全：账户、不动产、车辆。
行为保全：禁止或责令一定行为，须具体。
证据保全：固定证据，对象是证据不是责任财产。

停止拆除决定的执行，优先停止执行原子，而不是用行为保全混写。

---

## 节点 2　诉前

情况紧急、不立即保全会使判决难以执行或造成损害。诉前保全后须在法定期限起诉，期限运行时核验。未核验则该行停止。

---

## 节点 3　担保与范围

担保形式、额度按法院要求，未核验不编具体金额。保全范围限于请求或与本案有关财产。超范围风险必须写。

---

## 节点 4　草稿

法院、申请人被申请人、请求、事实、线索、担保。只交草案。不代提交。

---

## 节点 5　错误保全

申请错误造成损失可能赔偿。禁止故意超标的查封整垮对方以迫使调解。

## 节点补强：种类与诉前

1. 停止行政行为效力：转停止执行原子。
2. 诉前须情况紧急，并在法定期限起诉，未核验则该行停止。
3. 保全范围限于请求或与本案有关财产。超范围风险必须写。
4. 申请错误可能赔偿。禁止故意超标的查封逼迫调解。
5. 不保证裁定。担保额度未核验不编具体金额。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（准备行政诉讼保全申请）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（申请书、担保、财产或行为线索）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：不保证裁定；与停止执行不同。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
