# 附带审查请求方法

判断只用三态。不单独起诉抽象文件。

## 节点 0　分流

| 信号 | 处理 |
| --- | --- |
| 只要能否审查 | 转 `assess-normative-document-review` |
| 对象是规章以上 | 停止对该文件的审查请求 |
| 没有具体行为 | 负触发 |
| 税务文件税负实体 | 转税务 |

---

## 节点 1　对象

写明文件全称、文号、条款。无法提供文本：请求行待核，不编造条文。

---

## 节点 2　时点

复议申请书或起诉状中专节提出。一审法庭调查中补充须说明正当理由。二审新提通常受限。

---

## 节点 3　表述

正确：请求审查该规定合法性，不作为认定被诉行为合法的依据。
错误：请求撤销该通知对全市失效；以制定机关为被告单独起诉文件。

---

## 节点 4　理由结构

上位法条号（须核验）、冲突点、对本案适用关系。空泛“不合理”不够。

---

## 节点 5　输出

请求段落、时点、风险。不保证文件被否定。

## 节点补强：请求表述

1. 规章以上：停止对该文件的审查请求。
2. 正确表述是不作为认定依据，错误表述是请求普遍废止或单独起诉文件。
3. 无文件文本不得编造条文，请求行待核。
4. 应嵌入复议申请或起诉状，不另立抽象诉讼。
5. 空泛“不合理”不够，须对照上位法条号（核验后写）。

## 执行闸（必须逐条走过）

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率。未知金额不写零。不得把 1989 年行政诉讼法、1996 年行政处罚法、1999／2017 年行政复议法或已失效《合同法》当作现行文本。

| 若 | 则 |
| --- | --- |
| 立场或授权不明，或同时掌握双方秘密 | 整体停止策略输出 |
| 税务处理、税额核定、纳税担保、缴清后复议为主轴 | 整案转税务，本任务只交分流 |
| 劳动仲裁申请或对仲裁裁决不服 | 转劳动或民事；劳动仲裁不是行政诉讼 |
| 刑事拘留、搜查、定罪 | 转刑事 |
| 动态规则未核验 | 对应法律结论或期限字段停止 |
| 用户要求伪造、隐匿、威胁或违法取证 | 整体停止 |

`depends-on` 为空。MCP 不可用时不拒跑，继续事实和清单。

## 交付前自检（一并提出规范性文件审查）

完成本任务前逐项打勾。任一未闭合则对应字段停止，不假装已形成结论。

1. 单方立场和授权已固定，利益冲突已排除。
2. 文书名称、文号、作出日与送达日已分列；口头转述和已读未写成已送达。
3. 本技能独立成果（审查请求、文件层级、提出时点）已按输出合同各节落盘，未改写成相邻原子终稿。
4. 排除项已检查：不单独起诉抽象文件。
5. 税务主轴已转税务；劳动仲裁未写成行政诉讼；刑事措施已转刑事。
6. 法律结论与期限仅在规则核验后落判断；未核验则字段停止。
7. 未知金额未写零。未输出胜诉率或必然受理、必然撤销。
8. 禁止动作已明示。未指导伪造、隐匿、威胁或违法取证。
