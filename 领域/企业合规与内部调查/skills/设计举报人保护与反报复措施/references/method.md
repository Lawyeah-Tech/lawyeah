# 评估方法

本文件是可执行判断节点。保护方案不是已实施保护。纸面制度不是已有效。调岗隔离不是当然合法保护。公开表彰可能二次暴露。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、范本填满、唯一截止日、选定机关、代提交、未知写零。本任务不写劳动解除或处分决定，不写报复是否已发生终稿，不定罪，不代提交。本窗 `PT#` 是保护措施行，不是可查性行，不是渠道行。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1985 年会计法第五条、2018 年监察法文本当现行第十八条、把 42 号令第二十四条或劳动法第一百零一条套成民企内部廉洁举报一般法定义务、把调岗写成当然保护时记为噪声。禁止指导伪造保护日志、追踪匿名举报人或删除会计资料。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`PT#` 固定列：`编号｜保护对象／暴露等级｜知悉范围｜禁止动作｜监测点／基线｜E#回链｜判断三值｜缺口G#｜最强反方｜待核`。禁止合成「已实施保护闭环」一笔。无法判断则该条待核，**不得默认保留调岗隔离或公开表彰**。热冲突不得保留。`E#` 只作证据形态回链。缺项记 `G#`。扫描不是闭集。

口头「已经保护了」「制度写了不得报复」「调岗就是隔离」「群已读」只进 `S#`／`V#`，**不得算作开闸材料**。已读、揽收不得升格 `R#` 已送达，不得升格已实施。`A#` 是承认，不是已保护。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

## 节点 0　分流、立场、保护闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。伪造保护日志、倒签知悉名单、以保护为名打击被举报人、指导删除、平行灭证、指导追踪匿名、打击报复、阻挠合法检查、双方秘密不进负表。

整案转出只交付第 1、2、10 节，不出 `PT#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是报复是否已发生 | 负触发 `评估打击报复风险` |
| 主成果是单件可查性 | 负触发 `评估单件举报可查性` |
| 主成果是建渠道且没有保护对象 | 负触发 `建设内部举报渠道与受理规则` |
| 主成果是完整启动闸 | 负触发 `评估是否启动内部调查` |
| 主成果是劳动解除、处分或劳动争议程序文书 | 整案转劳动；保护建议若仍是主轴则留本窗、文书转劳动 |
| 主成果是职场性骚扰或日常违纪调查终稿 | 整案转劳动 |
| 主成果是回避名单终稿 | 负触发 `处理利益冲突与调查回避` |
| 主成果是全员或对外通报正文 | 负触发 `准备对内通报与对外口径` |
| 确为中央企业且主成果是 42 号令对照终稿 | 负触发 `评估国企合规管理办法差距` |
| 侦查、起诉、辩护为主成果 | 整案转刑事 |

审查起诉、监管检查只作程序背景。主成果才整案转。出现「保护」「报复」一词不是转出。已形成劳动争议：保护建议可继续，不得负触发关窗。

保护闸打开（可出 `PT#` 草案，仍不得标「已实施／已有效／绝对不泄露」）须同时满足：单方无冲突公司立场已闭合；主成果是保护与反报复措施草案，不是报复迹象表、可查性或劳动解除；至少一名可编号保护对象或拟设措施行。从零：有对象碎片或拟设即可开或半开，缺项记 `G#`。口头已保护、群已读、纸面制度不算开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

保护闸部分打开：知悉名单、监测基线或主体未核验，但已有可编号范围；或无书面保护授权但已有拟设行或对象碎片；对应格待核；仍交十节；不得标终稿 `已形成`。

保护闸关闭（仍正触发）：无一可编号对象且无一拟设行。「今天必须出已实施保护终稿」而无最小事实不得开闸。不出 `PT#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `PT#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「已经保护」或「没有报复风险」。

「纸面即已保护」「调岗即保护」「公开表彰即激励」「绝对不泄露已保证」「民企必须按 42 号令第二十四条建保护上报」「劳动法第一百零一条覆盖全部内部举报」「渠道即免责」「群已读即已公布」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `PT#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合、无书面保护授权但已有拟设行或对象碎片，then 保护闸部分打开，仍交十节，不是整体停止。
若 if 公司立场已闭合但无一拟设且无一对象，then 保护闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被指向人或举报人相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造保护日志、倒签知悉名单、以保护为名打击被举报人、指导追踪匿名、指导删除会计资料、借保护稿平行灭证、打击报复或阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

中央企业／地方国企／参股／民企／是否上市分列。保护对象分列：实名举报人、可识别匿名人、证人、拒绝参与违规的员工。不编造无法识别的匿名对象。

检索锚点（写入 `L#` 前须核验）：

- 42 号令第二条、第二十四条、第四十条：第 24 条保密与不得打击报复只约束中央企业。奖励属实举报人 ≠ 全员公开表彰。民企硬套：该格不支持，不关窗，不得建议上报国资委。
- 公司法第一百六十八条、第一百七十七条：不套民企必须建保护上报。
- 劳动法（2018 修正）第一百零一条：阻挠劳动行政部门监督检查或报复向劳动行政机关举报的人员。噪声：1994 年文本。不是全部内部廉洁举报的一般法定义务。
- 劳动合同法第四条：构成劳动规章的保护纪律只开民主程序接口。
- 会计法（2024 修正）第五条、第四十三条：会计人员报复与恢复名誉职务。噪声：1985 年第五条。不得写成全体举报人当然恢复原职。
- 个保法第六条、第十三条、第二十五条：知悉范围最小化 ≠ 全员通报身份。
- 监察法（2024 修正）第十八条：不得伪造、隐匿、毁灭。
- 刑法第三百零八条、第三百零七条、第一百六十二条之一只作红旗。

强制接口与非强制对标分列。

## 节点 3　保护措施行 `PT#`

按已出现保护对象扫描，不是默认闭集。每名对象一行。无法识别的匿名不编造对象，记渠道级保密 `G#`。

热冲突强制处理（不得保留）：

- 调岗、降薪、解除作为「保护」且未经劳动合法性评估 → 该格不支持；暂停建议只开劳动接口，不写必须恢复原职的裁决。
- 全员通报、公开表彰、点名颁奖 → 删除或改写为不暴露身份的奖励。
- 向被指向人或其直线核实身份 → 删除；构成报复方法则整体停止。
- 绝对无法泄露承诺且技术不能支持 → **删除**，改为如实披露限制。
- 被调查人及其直线进入知悉名单（除非保护对象已换调查主体）→ 删除。
- 「以保护为名」对被举报人解除、公示、扣押设备 → 整体停止，不是该格不支持。

知悉范围：最小必要。扩大须书面理由并记 `G#`。名单外知悉视为泄露事件接口，本窗不做出结论。

监测点：绩效、考勤、工作分配、奖金、培训机会、合同动作的异常窗口。无基线数据：监测字段停止，仍可列禁止动作。

无 `E#` 不得写已覆盖或已实施。状态 `草案`。

## 节点 4　劳动交叉、可逆性与转介

构成劳动规章的纪律条款：本窗不写生效稿，只开劳动合同法第四条接口。已形成劳动争议：保护建议继续，仲裁／诉讼文书转劳动。不写解除决定，不选定仲裁委或法院，不写唯一截止日。

可逆与不可逆分列。不可逆（对员工公布发生处分效力、全员点名、向被指向人出示身份、格式化旧档、对外宣称已保护）不得在草案阶段实施。禁止提交指令。不代公布、不代提交。

下一步只转介：打击报复评估、可查性、启动闸、渠道、回避、通报、劳动。禁止一次写完全部邻窗终稿。

已有监察或检查 `R#`：不得借保护稿平行灭证。刑法第一百六十二条之一只作红旗，不得指导删除。

## 本任务回链纪律

本任务成果是「保护闸与保护措施草案」。本窗不执行发送。不包含：已实施保护证明、绝对不泄露保证、劳动解除决定、报复是否已发生终稿、可查性终稿、启动闸、渠道终稿、发送版通报。禁止伪造保护日志。禁止选边治愈。禁止调岗即保护。禁止公开表彰暴露。禁止民企套第 24 条。禁止以保护为名打击被举报人。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标保护终稿已形成。
