# 评估方法

本文件是可执行判断节点。保护不是处分被举报人。公开表彰不是保护。不保证绝对不泄露。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、绝对不泄露保证、唯一截止日、选定机关、代提交、未知写零。本任务不写劳动处分，不评估报复是否已发生终稿。本窗 `PR#` 是保护措施行，不是优先受偿，不是 `P#`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、把 42 号令第二十四条套民企必须上报、把公开表彰写成保护时记为噪声。禁止指导追踪匿名或删除会计资料。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`PR#` 固定列：`编号｜对象形态（实名／可识别匿名／证人／拒绝违规）｜暴露路径｜最小知悉名单｜禁止／建议暂停动作｜监测点｜E#回链｜判断三值｜G#｜最强反方｜待核`。禁止合成「已保护闭环」。`E#` 只作证据形态回链。缺项记 `G#`。扫描不是闭集。

口头「要保护一下」「已经保护了」「群已读」只进 `S#`／`V#`，**不得算作开闸材料**。已读、揽收不得升格 `R#` 已送达，不得升格保护已生效。口头备份不等于已保全。`A#` 是承认暴露／拟议动作，不是已保护。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

## 节点 0　分流、立场、保护闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。以保护打被举报人、指导追踪匿名、伪造保护记录、倒签生效、指导删除、打击报复、双方秘密不进负表。

整案转出只交付第 1、2、10 节，不出 `PR#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是报复是否已发生／迹象表 | 负触发 `评估打击报复风险` |
| 主成果是单件可查性 | 负触发 `评估单件举报可查性` |
| 主成果是建渠道、没有保护对象 | 负触发 `建设内部举报渠道与受理规则` |
| 主成果是劳动解除、处分、恢复原职 | 整案转劳动 |
| 主成果是职场性骚扰或日常违纪调查 | 整案转劳动（可留保护接口） |
| 主成果是完整启动闸 | 负触发 `评估是否启动内部调查` |
| 主成果是调查报告 | 负触发 `形成内部调查报告` |
| 主成果是全员点名／表彰通报正文 | 负触发 `准备对内通报与对外口径` |
| 确为中央企业且对照终稿 | 负触发 `评估国企合规管理办法差距` |
| 侦查、起诉、辩护为主成果 | 整案转刑事 |

审查起诉、检查只作程序背景。主成果才整案转。

保护闸打开（可出 `PR#` 草案，仍不得标「已保护／已绝对不泄露」）须同时满足：单方无冲突公司立场已闭合；主成果是保护方案，不是可查性、渠道、已发生报复或劳动处分；至少一名可编号对象或一条暴露钩子。口头已保护、已读、公开表彰不算开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

保护闸部分打开：对象可编号但知悉／汇报线／拟议动作未闭合；或无书面授权但有拟设对象或暴露碎片；对应格待核；仍交十节；不得标终稿 `已形成`。

保护闸关闭（仍正触发）：无一可识别对象且无一暴露碎片。「今天必须出已保护终稿」而无最小事实不得开闸。不出 `PR#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `PR#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「没有报复风险」或「已经保护到位」。没有对象、只要建热线：负触发渠道窗，不是本窗关闸。

「公开表彰即保护」「绝对不泄露可承诺」「必须恢复原职裁决」「保护方案即免责」「民企必须按第二十四条上报」「未立案所以推迟保护」「群已读即已保护」「交方案即从轻」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `PR#` 草案。公开表彰／全员点名**该行删除**。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合、无书面授权但已有对象或暴露碎片，then 保护闸部分打开，仍交十节，不是整体停止。
若 if 公司立场已闭合但无一对象且无一碎片，then 保护闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与举报人或被指向人相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出以保护为名打击被举报人、指导追踪匿名、伪造保护记录或知悉名单、倒签生效、指导删除或打击报复，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　对象与暴露

实名举报人、可识别匿名、证人、拒绝参与违规的员工分列。不编造姓名或工号。身份不明且无一暴露钩子：不编造对象，只出渠道级保密接口，闸可关或半开。可识别匿名：岗位／交易／时点可反推则当暴露对象编 `PR#`，不得指导查 IP／设备／日志以「保护」为名识别。拒绝违规但未正式举报也算保护对象，不得写成「未举报故不保护」。不因尚未立案推迟保护。

## 节点 3　保护行 `PR#`

按已出现对象扫描，不是默认闭集。知悉名单：最小必要；名单外知悉视为泄露事件候选。被调查人及其直线不得进入名单，除非保护对象就是其本人且已换调查主体。

禁止动作：公开点名、全员通报点名、公开表彰、向被指向人出示原件或核实身份、调岗、降薪、解除、取消奖金、孤立、异常考勤处罚——建议暂停，本窗不写决定。公开表彰／点名行删除。

监测点：考勤、绩效、工作分配、培训机会、合同／权限动作。无基线则监测字段部分停止，仍可列禁止动作。监测点不是报复已发生终稿。

## 节点 4　可逆性与转介

可逆与不可逆分列。不可逆（全员点名、向被举报人出示身份、实施调岗、倒签生效）不得在草案阶段实施。禁止提交指令。不代处分、不代调岗、不代提交。

下一步只转介：打击报复评估、可查性、渠道、启动闸、回避、通报（禁点名）、劳动、证据保全接口。不代做迹象终稿。

已有监察或检查 `R#`：不得借保护稿平行灭证。刑法第一百六十二条之一只作红旗，不得指导删除。
