# 边界与路由

## 正触发

需要对举报人或证人采取保护措施并监测报复，而不是作出处分、打劳动官司或评估报复是否已发生。从零、暴露碎片、无书面授权仍正触发：有对象或暴露钩子则闸开或半开，出 `PR#` 草案。公开表彰即保护、绝对不泄露、民企套第 24 条、未立案推迟保护，仍正触发。

双方秘密、以保护为名打击被举报人、指导追踪匿名、伪造保护记录、倒签生效、打击报复的停止，优先于负触发。上述信号不在下表。「公开表彰即保护」「绝对不泄露可承诺」「必须恢复原职」「保护即免责」「民企套第 24 条」「未立案推迟保护」不在下表。「不作出劳动处分」「不保证绝对不泄露」是交付禁令，不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 报复是否已发生／迹象表终稿 | `评估打击报复风险` |
| 单件可查性 | `评估单件举报可查性` |
| 建渠道、没有保护对象 | `建设内部举报渠道与受理规则` |
| 劳动解除、处分、恢复原职 | 劳动领域 |
| 职场性骚扰或日常违纪调查 | 劳动领域（可留保护接口） |
| 完整启动闸 | `评估是否启动内部调查` |
| 调查报告 | `形成内部调查报告` |
| 全员点名／表彰通报正文 | `准备对内通报与对外口径` |
| 确为中央企业且对照终稿 | `评估国企合规管理办法差距` |

不得因「不保证绝对不泄露」或「要求表彰当保护」关窗。拟设仍正触发，不得写成已保护。民企硬套不得负触发到对照窗。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、解除、工伤、职场性骚扰主轴 | 劳动领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |
| 垄断、滥用支配、经营者集中 | 竞争法领域 |

综合合规保护主轴可留本任务。审查起诉或检查只作背景，主成果才转。出现「保护」「举报人」一词不是转出。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 已发生不利人事或合同动作要迹象终稿 | `评估打击报复风险` |
| 本件能不能初核 | `评估单件举报可查性` |
| 入口／开箱／分办规则 | `建设内部举报渠道与受理规则` |
| 谁查、预算 | `评估是否启动内部调查` |
| 全员口径正文 | `准备对内通报与对外口径` |
| 解除／处分合法性 | 劳动领域 |

## 易混

保护方案不是处分被举报人。公开表彰可能造成二次暴露，不是保护。全员通报点名不是保护。绝对不泄露通常无法保证，应披露限制而不是关窗。未立案不是推迟保护的理由。群已读不是保护已生效。口头「已经保护了」不是保护方案。民企套 42 号令第二十四条：该格不支持，不关窗，不转出。以保护为名打击被举报人、指导追踪匿名：第一次整体停止。报复是否已发生、劳动处分、可查性、渠道规则不在本窗做完。
