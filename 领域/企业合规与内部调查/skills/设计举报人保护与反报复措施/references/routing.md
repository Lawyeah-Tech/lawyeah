# 边界与路由

## 正触发

需要对举报人、可识别匿名人、证人或拒绝参与违规的员工设计保护与反报复措施，而不是作出处分、打劳动官司或评估报复是否已发生。从零、对象碎片、无书面保护授权仍正触发：有拟设或对象碎片则闸开或半开，出 `PT#` 草案。纸面即已保护、调岗即保护、公开表彰即激励、绝对不泄露、民企套第 24 条，仍正触发。

双方秘密、伪造保护日志、倒签知悉名单、以保护为名打击被举报人、指导删除、平行灭证、指导追踪匿名、打击报复、阻挠合法检查的停止，优先于负触发。上述信号不在下表。「纸面即已保护」「调岗即保护」「公开表彰即激励」「绝对不泄露已保证」「民企必须套第 24 条」不在下表。「不作出劳动处分」「不保证绝对不泄露」「不保证免责」是交付禁令，不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 报复是否已发生或迹象表终稿 | `评估打击报复风险` |
| 单件可查性 | `评估单件举报可查性` |
| 建渠道且没有保护对象 | `建设内部举报渠道与受理规则` |
| 完整启动闸 | `评估是否启动内部调查` |
| 劳动解除、处分决定或劳动争议程序文书 | 劳动领域 |
| 职场性骚扰或日常违纪调查终稿 | 劳动领域 |
| 回避名单终稿 | `处理利益冲突与调查回避` |
| 全员或对外通报正文 | `准备对内通报与对外口径` |
| 确为中央企业且 42 号令对照终稿 | `评估国企合规管理办法差距` |
| 交易合同改稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不保证绝对不泄露」或「夹带劳动争议」关窗。已形成劳动争议时保护建议可继续，程序文书转劳动。民企硬套不得负触发到对照窗。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、解除、工伤、职场性骚扰主轴且保护不是主成果 | 劳动领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |
| 垄断、滥用支配、经营者集中 | 竞争法领域 |

综合保护与反报复措施主轴可留本任务。审查起诉或检查只作背景，主成果才转。出现「保护」一词不是转出。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 报复迹象是否已发生 | `评估打击报复风险` |
| 这封信能否初核 | `评估单件举报可查性` |
| 谁查、查到哪、预算 | `评估是否启动内部调查` |
| 渠道级保密、无具体保护对象 | `建设内部举报渠道与受理规则` |
| 调查组回避名单终稿 | `处理利益冲突与调查回避` |
| 全员通报正文 | `准备对内通报与对外口径` |
| 调岗／解除合法性做完 | 劳动领域 |

## 易混

保护方案不是已实施保护。纸面制度不是已有效。调岗隔离不是当然合法保护，可能构成报复。公开表彰可能二次暴露。不保证身份绝对不泄露；该承诺技术不能支持则删除。保护方案不是处分被举报人。劳动法第一百零一条不是全部内部廉洁举报的一般法定义务。会计法第五条／第四十三条只约束对会计人员的报复，不是全体举报人当然恢复原职。民企套 42 号令第二十四条：该格不支持，不关窗，不转出，不得建议上报国资委。以保护为名打击被举报人整体停止。报复是否已发生不在本窗。不作出劳动处分、不保证绝对不泄露是交付禁令，不是负触发。
