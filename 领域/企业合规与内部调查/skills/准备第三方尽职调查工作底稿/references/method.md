# 评估方法

本文件是可执行判断节点。底稿完成不是已批准合作。访谈印象不是已证实。未提供不是无问题。必须写成可合作该格不支持。依据不足不得改可合作。公开检索不是已尽职。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。结论四态只用 `可合作`、`有条件合作`、`不建议`、`依据不足`。四态「可合作」不是已批准合作。禁止胜诉率、必然免责、选定法院、代提交、未知写零。本窗不定罪，不实施访谈，不发中止通知，不写并购总尽调，不写完整合同。本窗 `DW#` 是底稿行，不是筛查行 `SC#`，不是第三方行 `TD#`，不是提纲行 `IQ#`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1993 年反不正当竞争法第八条、把底稿完成写成已批准合作时记为噪声。禁止指导买黑客、伪造底稿或把访谈印象写成已证实作为方法。禁止 `search_template` 生成已批准合作底稿或可合作证明。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现问题扫描，不是默认闭集。
`DW#` 固定列：`编号｜对象｜拟证问题（受益人／公职关系／成功费去向／分包／历史调查／账簿配合）｜材料室编号／原件／矛盾点｜访谈接口｜四态结论｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已批准合作闭环」或「未提供即无问题」。无 `E#` 不得写可合作、已批准、已证实、无问题。`E#` 只作证据形态回链。缺项记 `G#`。扫描不是闭集。

口头「底稿写完就可合作」「感觉可靠」「没交就是没问题」只进 `S#`／`V#`，**不得单独算作开闸材料**。对象名称、拟证问题、材料室目录、用户合法持有材料可编号开闸。承诺书、工商截图能开闸，不能升格已尽职。`A#` 是承认该对象或该问存在，不是已批准合作。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上廉洁尽调底稿应对受益人、公职关系、成功费去向、分包、历史调查、账簿配合意愿逐问留痕，但这不是已批准合作。未提供材料标依据不足，不推定无问题。访谈只开接口，印象不得填补受益人空白。

## 节点 0　分流、立场、底稿闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、指导买黑客、指导伪造底稿、指导伪装调查、指导把访谈印象写成已证实作为方法、打击报复不进负表。利益冲突未解不进整体停止。不保证可合作、不定罪、不买违法征信、不实施访谈、不发中止通知不进负表。

整案转出只交付第 1、2、10 节，不出 `DW#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是公开信息筛查 | 负触发 `筛查经销商代理中介廉洁风险` |
| 主成果是机制草案 | 负触发 `设计第三方合规管理机制` |
| 主成果是中止或终止通知 | 负触发 `准备中止或终止高风险第三方合作通知` |
| 主成果是访谈提纲与笔录结构 | 负触发 `准备调查访谈提纲与笔录结构` |
| 主成果是收集日志 | 负触发 `合法收集书证电子证与财务痕迹` |
| 主成果是中间人费用与资金链路 | 负触发 `评估中间人费用与资金链路` |
| 主成果是是否启动内部调查 | 负触发 `评估是否启动内部调查` |
| 主成果是并购总尽调 | 整案转投资并购 |
| 主成果是完整交易合同 | 负触发，审查起草领域（本窗搁置） |
| 主成果是刑辩、控告或自首 | 整案转刑事 |
| 「不保证可合作」「不定罪」「不买违法征信」「不实施访谈」「不发中止通知」 | 交付禁令，不是负触发 |

审查起诉、监管检查只作背景。主成果才整案转。出现「尽调」「第三方」「经销商」一词不是转出。

底稿闸打开（可出 `DW#` 草案，仍不得标「已批准合作／已证实／可合作闭环」）须同时满足：单方无冲突公司立场已闭合；主成果是廉洁尽调底稿草案，不是筛查终稿、机制、中止通知、访谈提纲或并购总尽调；至少一条可编号对象或拟证问题／材料室碎片。口头「写完就可合作」不算单独开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

底稿闸部分打开：已有对象或问题／碎片，但授权、受益人、公职关系、材料室未闭合；对应格待核；仍交十节。

底稿闸关闭（仍正触发）：无一可编号对象且无一问题／碎片。「今天必须出可合作终稿」而无最小件不得开闸。不出 `DW#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `DW#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「底稿完成即已批准合作」「访谈印象即已证实」「未提供即无问题」「必须写成可合作」「依据不足改可合作」「公开检索即已尽职」「承诺书即已通过」「高风险即必须中止」「FCPA 即中国法」「民企必须按 42 号令尽调完」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `DW#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无一对象且无一问题／碎片，then 底稿闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被尽调对象或相对方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出指导买黑客、非法获取个人信息、伪造或倒签底稿、伪装调查、把访谈印象写成已证实作为方法、打击报复，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个对象或强制接口。缺项记 `G#`，不得把未知金额写成 `0`。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 主体 | 中央企业／地方国企／参股／民企；是否上市 | 把民企写成必须按 42 号令尽调完上报 |
| 对象 | 经销／代理／中介／顾问／高风险供应商 | 把 C 端勾选清单写成专业尽调 |
| 拟证问题 | 受益人／公职关系／成功费去向／分包／历史调查／账簿配合 | 访谈印象填空白 |

检索锚点（写入 `L#` 前须核验）：

- 反不正当竞争法（2025）第八条：明示折扣佣金如实入账不是贿赂。施行日 2025-10-15。
- 刑法第二百五十三条之一及法释〔2017〕10 号第四条：购买、收受、交换获取公民个人信息属于非法获取。
- 个保法第六条、第十三条、第二十五条只开合法处理接口。
- 42 号令第二条只约束中央企业。
- 行政处罚法（2021）第三十二条交底稿 ≠ 从轻。
- 刑法第一百六十三条／第一百六十四条只作红旗，不定罪。
- FCPA／英国反贿赂法不是中国法义务。

本节禁止出 `DW#` 终稿。

## 节点 3　底稿行 `DW#`

按已出现问题扫描，不是默认闭集。建议行型（出现才用，**不是闭集**）：

| 编号 | 含义 | 本窗允许 | 禁止 |
| --- | --- | --- | --- |
| `DW-问` | 拟证问题 | 受益人／公职／成功费／分包／历史／账簿分列 | 一句话结案 |
| `DW-材` | 材料室 | 编号、来源、原件、矛盾点 | 未提供写成无问题 |
| `DW-访` | 访谈接口 | 只开转介，不写提纲终稿 | 本窗出 `IQ#`；印象即已证实 |
| `DW-结` | 四态结论 | 可合作／有条件／不建议／依据不足 | 无 `E#` 写可合作；不足改可合作 |
| `DW-益` | 受益所有人 | 不明＝依据不足 | 印象填空白 |
| `DW-公` | 公职关系 | 待核红旗 | 见过官员即行贿 |
| `DW-资` | 成功费去向 | 红旗待证 | 成功费即已贿赂 |

热冲突强制处理：

- 底稿完成即已批准合作／访谈印象即已证实／未提供即无问题／必须写成可合作／依据不足改可合作／公开检索即已尽职／承诺书即已通过／高风险即必须中止／FCPA 即中国法 → 该格不支持；仍出其他 `DW#`。
- 材料未提供 → 四态 `依据不足`，不得写无问题。
- 受益人不明 → 不得写可合作。
- 指导买黑客或伪造底稿 → 整体停止，不是该格不支持。

无 `E#` 不得写可合作、已批准或已证实。状态 `草案`。一次只推荐下一步。

## 节点 4　访谈、中止、并购边界与转介

第 7 节只开接口，不得夹带 `DW#` 终稿绕闸。闸关闭时第 7 节可写「闸未开，转介待拟设编号」，不得补写可合作。

不写筛查终稿、机制全文、中止通知发送稿、访谈提纲终稿、并购总尽调、完整合同。不可逆（对外宣称已批准合作、向监管报告已尽职、补假底稿）不得在草案阶段实施。禁止提交指令。不代提交。不选定机关。不实施访谈。

筛查转 `筛查经销商代理中介廉洁风险`。机制转 `设计第三方合规管理机制`。中止转 `准备中止或终止高风险第三方合作通知`。提纲转 `准备调查访谈提纲与笔录结构`。中间人转 `评估中间人费用与资金链路`。启动调查转 `评估是否启动内部调查`。并购转投资并购。完整合同搁置。

若 if 用户催促「按零写／填满可合作终稿」，then 该格 `现有依据不支持`，窗口不关。
若 if 金额、家数未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「底稿闸与底稿草案」。本窗不执行印发，不实施访谈，不发中止。不包含：已批准合作证明、已尽职证明、筛查终稿、访谈提纲终稿、中止通知发送稿、并购总尽调、账外操作步骤。禁止选边治愈。禁止底稿完成即已批准合作。禁止访谈印象即已证实。禁止未提供即无问题。禁止必须写成可合作。禁止指导买黑客或伪造底稿。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：民企。筛查已把某经销商标高风险。材料室有工商截图、承诺书；受益人不明；访谈对象未定；对方未交分包与成功费去向。用户主张底稿填完即已批准合作、访谈感觉可靠即已证实、没交材料就是没问题、今天必须写成可合作、依据不足也改可合作、按 FCPA 写死、民企必须按 42 号令尽调完上报。底稿闸打开。`Q-合`、`Q-访`、`Q-缺`、`Q-可`、`Q-足`、`Q-美`、`Q-18` 不打开为可靠路径。第 6 节不得把已批准合作、已证实、无问题、可合作写入可执行 `DW#`；对应格 `现有依据不支持`；仍出对象、拟证问题、材料缺口、访谈接口、依据不足等其他 `DW#` 草案。受益人不明行四态＝`依据不足`。不关窗。不定罪。不发中止。不实施访谈。不得建议报国资委。

场景②：用户同时交出公司底稿草稿与被尽调经销商抗辩，要求选对公司有利的一版写成可合作，并指导「受益人先买个人征信、访谈印象先写成已证实、缺件先补假」。命中双方秘密＋指导非法获取／伪造底稿。第一次整体停止。只交第 1、10 节。不出 `DW#`。不得问代表哪一方后继续。
