# 边界与路由

## 正触发

高风险第三方需要可复核的廉洁尽调底稿，而不是批量公开筛查、建机制、发中止通知或做并购总尽调。材料、受益人未核验仍正触发：有可编号对象或拟证问题／材料室碎片则闸开或半开，出 `DW#` 草案。底稿完成即已批准合作、访谈印象即已证实、未提供即无问题、必须写成可合作、公开检索即已尽职、承诺书即已通过、高风险即必须中止、FCPA 即中国法义务、民企必须按 42 号令尽调完，仍正触发。

双方秘密、指导买黑客或非法获取个人信息、指导伪造或倒签底稿、指导伪装调查、指导把访谈印象写成已证实作为方法、打击报复的停止，优先于负触发。上述信号不在下表。「底稿完成即已批准合作」「访谈印象即已证实」「未提供即无问题」「必须写成可合作」「公开检索即已尽职」「承诺书即已通过」「高风险即必须中止」「FCPA 即中国法」「民企必须尽调完」不在下表。「不保证可合作」「不定罪」「不买违法征信」「不实施访谈」「不发中止通知」是交付禁令，不在下表。出现「尽调」「第三方」「经销商」一词不是转出。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 单家或一批公开信息筛查 | `筛查经销商代理中介廉洁风险` |
| 第三方机制草案 | `设计第三方合规管理机制` |
| 中止或终止合作通知 | `准备中止或终止高风险第三方合作通知` |
| 访谈提纲与笔录结构 | `准备调查访谈提纲与笔录结构` |
| 收集日志终稿 | `合法收集书证电子证与财务痕迹` |
| 中间人费用与资金链路终稿 | `评估中间人费用与资金链路` |
| 是否启动内部调查 | `评估是否启动内部调查` |
| 投资并购交易尽调整体 | 投资并购领域 |
| 完整交易合同审查或起草 | 审查起草领域（本窗搁置） |
| C 端小微供应商勾选清单 | 大众专项，只分流 |
| 刑事辩护、控告或自首 | 刑事领域 |
| 劳动规章或解除决定 | 劳动领域 |

不得因「不保证可合作」「不定罪」「不买违法征信」「不实施访谈」「不发中止通知」关窗。底稿完成即已批准合作、访谈印象即已证实、未提供即无问题、必须写成可合作该格不支持，窗口不关，不转出。主成果才转。民企硬套不得负触发到对照窗。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |

| 药品购销回扣行业细则为主成果 | 医疗领域 |

综合廉洁尽调底稿主轴可留本任务。检查或已立案只作背景，主成果才转。

## 易混

底稿闸打开不是已批准合作。

草案不是已尽职。底稿完成不是已批准合作。访谈印象不是已证实。未提供不是无问题。依据不足不是可合作。公开信息检索不是已尽职。承诺书不是已通过。高风险不是必须中止。C 端勾选清单不是专业尽调。明示佣金入账不是贿赂。FCPA 不是中国法义务。42 号令不套民企必须尽调完。交底稿不是从轻。不保证可合作、不定罪、不买违法征信、不实施访谈是交付禁令，不是负触发。口头「写完就可合作」不是开闸材料。可编号对象或拟证问题／材料室碎片才开闸。指导买黑客或伪造底稿是第一次整体停止，不是不关窗。本窗不出 `IQ#` 提纲终稿，不出 `SC#` 筛查终稿，不出中止通知发送稿。
