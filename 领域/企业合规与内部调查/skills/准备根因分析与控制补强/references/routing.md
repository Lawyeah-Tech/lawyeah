# 边界与路由

## 正触发

单件事件之后需要控制失效根因和可验收补强动作，而不是整包整改动作表、检察验收或只处分人。从零、碎片、控制点未核验、无书面分析授权仍正触发：有事件或控制碎片则闸开或半开，出 `YG#` 草案，保持草案。品德即根因、再培训即补强、计划即已完成、处分人即根因闭合，仍正触发。

双方秘密、虚假完成、隐瞒未改项、倒签、指导删除会计资料、打击报复的停止，优先于负触发。上述信号不在下表。「品德即根因」「再培训即补强」「计划即已完成」「处分人即根因闭合」「入账折扣即贿赂根因」「民企套第二十三条」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 整包可验收整改动作表 | `准备合规整改方案` |
| 跟踪已列动作的验收与复发 | `跟踪整改验收与复发监测` |
| 调查报告或事实认定终稿 | `形成内部调查报告` |
| 检察合规第三方验收 | `准备涉案企业合规整改与验收` |
| 劳动处分或解除决定 | 劳动领域 |
| 刑事辩护、控告或自首 | 刑事领域 |
| 有效性评价终稿 | `评估合规管理体系有效性` 或 `开展合规有效性评价` |

不得因「不把根因写成员工品德」或「不把计划写成已完成」关窗。拟分析仍正触发，不得写成已闭合或已完成。英文 id `prepare-remediation-plan` 禁止使用。

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、解除、工伤主轴 | 劳动领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |

| 税务处理决定、稽查实体 | 税务领域 |

| 出口管制、制裁名单 | 涉外领域 |
| 章程、股权、任免本身为主成果 | 公司治理领域 |

综合单件根因与控制补强主轴可留本任务。审查起诉只作背景，主成果才转。专项只作为背景时在缺口标明。出现「根因」「补强」「整改」一词不是转出。

## 易混

处分员工不是根因闭合。再培训一次不是控制补强。员工品德不是唯一根因。计划不是已完成。入账折扣不是贿赂根因。42 号令第二十三条不套民企。补强计划不是从轻。安全生产复查意见书不是企业已完成。本窗 `YG#` 不是整改窗 `RC#`／`A#`。检察合规验收不在本窗。「未改的先写成已完成」整体停止。本窗不执行发送，不代提交。审查起诉只作背景，主成果才转刑事。
