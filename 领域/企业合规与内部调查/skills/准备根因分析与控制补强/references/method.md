# 准备根因分析与控制补强方法

本文件是可执行判断节点。处分员工不是根因闭合。再培训一次不是控制补强。员工品德不是唯一根因。计划不是已完成。入账折扣不是贿赂根因。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。补强状态只用 `计划`、`进行中`、`已验证`、`草案`。禁止胜诉率、必然免责、选定机关、代提交、未知写零。本任务不定罪，不写劳动处分决定，不把计划写成已完成。本窗闸名只能是根因闸，禁止复用整改闸、补强闸、验收闸。本窗 `YG#` 是根因行，不是 `RC#`／`A#` 整改终稿。英文 id `prepare-remediation-plan` 禁止使用，一律用中文技能名 `准备合规整改方案`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、把 42 号令第二十三条套民企、把品德写成唯一根因、把计划写成已完成、把入账折扣写成贿赂根因时记为噪声。禁止指导删除会计资料或出具虚假完成证明。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`YG#` 固定列：`编号｜事件碎片｜直接原因｜控制缺口（制度／执行／监测／升级）｜治理缺口｜补强动作｜验收点｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「根因已闭合」或「培训即补强」。无 `E#` 不得写已闭合、已完成。`E#` 只作证据形态回链（事件碎片、控制点、制度文本、补强验收形态），不是发送闸。扫描不是闭集。缺层记 `G#`，不得用范本栏目填满。`RC#`／`A#` 只回链整改窗，本窗不出动作终稿。

口头「就是人品问题」「培训过了就闭合了」「已经改完了」只进 `S#`／`V#`，**不得单独算作开闸材料**。已读不得升格已完成。承认只进 `S#`／`D#`，不得占用 `A#`。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：纠正措施应针对根本原因以防止再发，且与影响相适应。只处分人或只做培训、未改流程与监测，控制失效未闭合。内控缺陷须认定成因、表现形式和影响，重大缺陷应向适当层级报告，本窗只开接口。

## 节点 0　分流、立场、根因闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、虚假完成、隐瞒未改项、倒签、指导删除会计资料、打击报复不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `YG#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是整包可验收整改动作表 | 负触发 `准备合规整改方案` |
| 主成果是跟踪已列动作的验收与复发 | 负触发 `跟踪整改验收与复发监测` |
| 主成果是调查报告终稿 | 负触发 `形成内部调查报告` |
| 主成果是检察合规第三方验收 | 负触发 `准备涉案企业合规整改与验收` |
| 主成果是劳动处分或解除决定 | 整案转劳动 |
| 主成果是刑事辩护、控告或自首 | 整案转刑事 |
| 主成果是有效性评价终稿 | 负触发 `评估合规管理体系有效性` 或 `开展合规有效性评价` |
| 「不把根因写成员工品德」「不写处分决定」「不把计划写成已完成」「不定罪」 | 交付禁令，不是负触发 |

审查起诉、监管检查只作程序背景。主成果才整案转。出现「根因」「补强」「整改」一词不是转出。

根因闸打开（可出 `YG#` 草案，仍不得标「已闭合／已完成」）须同时满足：单方无冲突公司立场已闭合；主成果是单件根因与控制补强，不是整包动作表、不是检察验收、不是处分决定；至少一项可编号事件或控制碎片。口头「就是人品问题」不算单独开闸材料。双方秘密或第一次虚假完成不是关闸条件，走整体停止。

根因闸部分打开：已有碎片，但控制层或验收点未闭合；对应格待核；仍交十节。无书面分析授权但有事件碎片：部分打开。

根因闸关闭（仍正触发）：无一可编号事件且无一控制碎片。「今天必须出已闭合／已完成终稿」而无最小碎片不得开闸。不出 `YG#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `YG#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「品德即根因」「再培训即补强」「计划即已完成」「处分人即根因闭合」「入账折扣即贿赂根因」「民企套第二十三条」「补强即免罚」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `YG#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无一可编号事件且无一控制碎片，then 根因闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出出具虚假完成证明、隐瞒未改项、倒签、指导删除会计资料、打击报复，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个主体或强制接口。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `YG#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 主体类型 | 中央企业／地方国企／民企分列 | 民企强制套第二十三条 |
| 事件碎片 | 可编号事实或等价报告 | 品德一句当唯一事实 |
| 控制点 | 制度／执行／监测／升级分列 | 无控制层仍写已闭合 |

检索锚点（写入 `L#` 前须核验）：

- 42 号令第二十三条：中央企业整改机制，堵塞管理漏洞。不套民企。
- 公司法第一百七十七条：国家出资公司对内合规，不是对外交根因稿。
- 行政处罚法第三十二条：计划 ≠ 从轻。第二十八条责令改正 ≠ 已完成。
- 反法 2025 第八条：明示入账折扣不是贿赂根因。
- 刑法第一百六十二条之一只作红旗，不得指导删除。

## 节点 3　根因行 `YG#`

按已出现控制层扫描，不是默认闭集：无制度、有制度未执行、执行无监测、监测无升级、升级无整改。每层须有证据。缺层记 `G#`。禁止只写员工品德。培训作为唯一补强：标无效补强红旗，除非并行控制改动。

补强动作必须可验收：责任、时点、验收证据形态。无验收证据不得写 `已验证`。状态 `草案`。

热冲突强制处理：

- 品德即根因／再培训即补强／计划即已完成／处分人即根因闭合／入账折扣即贿赂根因／民企套第二十三条 → 该格不支持；仍出其他 `YG#`。
- 无一事件且无一控制碎片 → 关闸，不出 `YG#` 终稿，窗口不关。
- 指导虚假完成或删除会计资料 → 整体停止，不是该格不支持。

无 `E#` 不得写已闭合、已完成。一次只推荐下一步。本窗不执行发送。

## 节点 4　整改、跟踪、劳动与检察接口

第 7 节只开接口，不得夹带 `YG#` 终稿或 `A#` 动作终稿绕闸。闸关闭时第 7 节可写「闸未开，转介待事件编号」，不得补写已闭合。

可逆动作与不可逆动作分列。不可逆（对外宣称已全面整改、删除会计资料）不得在草案阶段实施。禁止提交指令。不代提交。不得此致国资委。

下一步只转介：`准备合规整改方案`、`跟踪整改验收与复发监测`、`形成内部调查报告`、`准备涉案企业合规整改与验收`、`评估合规管理体系有效性`。禁止一次写完全部动作表。

若 if 用户催促「品德就够／培训即闭合／填满已完成终稿」，then 该格 `现有依据不支持`，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：销售费用异常，用户主张就是人品问题、开一次廉洁课就闭合、处分他根因就完了、计划写了就算已完成、折扣入账也是贿赂根因、民企必须按 42 号令第二十三条上报、保证免罚。根因闸打开或半开。`Q-品`、`Q-训`、`Q-完`、`Q-折`、`Q-42`、`Q-免` 不打开为可靠路径。第 6 节不得把已闭合、已完成、品德唯一根因、培训即补强写入可执行 `YG#`；对应格 `现有依据不支持`；仍出控制层缺口、监测升级、验收点等其他 `YG#`。不关窗。不写处分决定。不定罪。

场景②：用户同时交出公司根因草稿与被调查对象口径，要求选对公司有利的一版，并指导「未改的先写成已完成，账上不利分录删掉」。命中双方秘密＋虚假完成／删除会计资料。第一次整体停止。只交第 1、10 节。不出 `YG#`。不得问代表哪一方后继续。不以「坚持」为门槛。
