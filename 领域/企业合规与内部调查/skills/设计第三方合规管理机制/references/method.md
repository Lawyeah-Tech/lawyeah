# 设计方法

本文件是可执行判断节点。承诺书不是已覆盖。准入表不是已覆盖。印发不是生效。纸面不是有效机制。无监测则框架不支持有效机制。范本不是法定格式。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、选定法院、代提交、未知写零。本任务不写单家筛查结论，不写完整交易合同，不写中止通知终稿，不定罪。本窗 `TM#` 是机制行，不是制度行 `GP#`，不是渠道行 `CH#`，不是接触点行 `TP#`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1993 年反不正当竞争法第八条、把 MCP「尚未施行」的 2025 反法第八条在施行日 2025-10-15 之后仍当未生效、把承诺书写成已覆盖时记为噪声。禁止指导账外佣金或另开账外口径。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现条款扫描，不是默认闭集。
`TM#` 固定列：`编号｜行类（对象类型／风险级／准入／合同接口／监测复评／退出）｜对象形态｜公职接触／成功费｜准入材料｜合同接口要点｜监测周期与升级｜退出接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已覆盖闭环」或「承诺书即机制」。无 `E#` 不得写已覆盖、已生效、有效机制。`E#` 只作证据形态回链。开口径无留痕监测：该行删除或该监测字段停止。缺项记 `G#`。扫描不是闭集。

口头「签了承诺书就覆盖了」「表填了就合规」「印了就生效」「没有监测也算机制」只进 `S#`／`V#`，**不得单独算作开闸材料**。已读不得升格已生效。总部印发不对独立法人子公司当然生效。`A#` 是承认现行准入碎片，不是已覆盖。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上企业应对经销商、代理、中介、顾问和高风险供应商做分级管理，但这不是已覆盖。签廉洁承诺书不是机制。有准入表不是已覆盖。无监测、无复评、无退出接口的纸面办法，不得称有效机制。范本《第三方合规管理办法》《经销商合规承诺书》只借栏目。

## 节点 0　分流、立场、机制闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、指导账外佣金、另开账外口径、伪造账册、倒签生效、指导删除、打击报复不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `TM#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是单家或一批廉洁筛查 | 负触发 `筛查经销商代理中介廉洁风险` |
| 主成果是尽调工作底稿 | 负触发 `准备第三方尽职调查工作底稿` |
| 主成果是中止或终止通知 | 负触发 `准备中止或终止高风险第三方合作通知` |
| 主成果是中间人费用与资金链路 | 负触发 `评估中间人费用与资金链路` |
| 主成果是礼品招待制度全文 | 负触发 `设计反商业贿赂与礼品招待制度` |
| 主成果是完整交易合同审查或起草 | 负触发，审查起草领域（本窗搁置） |
| 主成果是 C 端小微供应商勾选清单 | 负触发，大众专项只分流 |
| 主成果是综合框架 | 负触发 `设计合规管理体系框架` |
| 主成果是章程级办法全文 | 负触发 `起草合规管理办法或章程级制度` |
| 主成果是药品购销回扣行业细则整案 | 整案转医疗 |
| 主成果是垄断或竞争协议审查 | 整案转竞争法或审查起草搁置 |
| 主成果是刑辩、控告或自首 | 整案转刑事 |
| 「不写完整合同」「不保证合作合法」「不筛单家」 | 交付禁令，不是负触发 |

审查起诉、监管检查只作背景。主成果才整案转。出现「经销商」「代理」「中介」「供应商」一词不是转出。

机制闸打开（可出 `TM#` 草案，仍不得标「已覆盖／已生效／有效机制」）须同时满足：单方无冲突公司立场已闭合；主成果是机制草案，不是单家筛查、尽调底稿、中止通知或完整合同；至少一条可编号拟设机制行或现行碎片。口头承诺书即覆盖不算单独开闸材料。双方秘密或第一次指导账外不是关闸条件，走整体停止。

机制闸部分打开：已有拟设或碎片，但授权、主体、监测、合同接口未闭合；对应格待核；仍交十节。

机制闸关闭（仍正触发）：无一拟设行且无一碎片。「今天必须出已覆盖终稿」而无最小拟设不得开闸。不出 `TM#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `TM#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「签承诺书即覆盖」「准入表即已覆盖」「印发即生效」「纸面即有效机制」「无监测即有效」「范本即法定格式」「民企必须按 42 号令第十八条覆盖第三方」「交机制稿即从轻或自首」「FCPA 即中国法义务」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `TM#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无一拟设且无一碎片，then 机制闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象或相对方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出指导账外佣金、另开账外口径、伪造账册、倒签生效、指导删除、打击报复，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个主体或强制接口。缺项记 `G#`，不得把未知交易额写成 `0`。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 主体 | 中央企业／地方国企／参股／民企；是否上市 | 把民企写成必须按 42 号令第十八条覆盖第三方 |
| 现行碎片 | 准入表、承诺书、监测周期、合同接口 | 口头承诺书即覆盖开闸 |
| 对象范围 | 经销／代理／中介／顾问／高风险供应商 | 把 C 端勾选清单写成专业机制 |

检索锚点（写入 `L#` 前须核验）：

- 反不正当竞争法（2025）第八条：明示折扣佣金如实入账不是贿赂；工作人员贿赂原则上认定经营者行为。施行日 2025-10-15。
- 42 号令第二条只约束中央企业。第十八条重点领域专项只约束中央企业。第四十条地方国资参照。
- 公司法第一百七十七条不套民企必须出台第三方机制。
- 行政处罚法（2021）第三十二条交机制稿 ≠ 从轻。
- 刑法第六十七条交机制稿 ≠ 自首。
- 刑法第一百六十二条之一只作红旗，不得指导删除。
- FCPA／英国反贿赂法不是中国法义务。

本节禁止出 `TM#` 终稿。

## 节点 3　机制行 `TM#`

按已出现行类扫描，不是默认闭集。建议行型（出现才用，**不是闭集**）：

| 编号 | 含义 | 本窗允许 | 禁止 |
| --- | --- | --- | --- |
| `TM-对` | 对象类型 | 经销／代理／中介／顾问／高风险供应商分列 | 把 C 端勾选清单写成专业对象 |
| `TM-级` | 风险级 | 公职接触、成功费、决策人关联、年交易额、空壳 | 分不出级仍称已覆盖 |
| `TM-准` | 准入 | 材料清单与声明接口 | 准入表即已覆盖 |
| `TM-合` | 合同接口 | 廉洁、账簿配合、转委托限制、审计权、停付与终止要点 | 写完整合同；承诺书即覆盖 |
| `TM-监` | 监测复评 | 周期、红旗升级调查接口 | 无监测称有效 |
| `TM-退` | 退出 | 中止／终止接口，不发通知 | 本窗出发送版通知 |
| `TM-账` | 中间人同一套 | 经销／代理／中介同一套 | 另开账外口径 |

热冲突强制处理：

- 签承诺书即覆盖／准入表即已覆盖／印发即生效／纸面即有效／无监测即有效／范本即法定格式／民企必须覆盖第三方／交机制稿即从轻或自首／FCPA 即中国法 → 该格不支持；仍出其他 `TM#`。
- 无监测 → 有效机制格不支持。
- 分不出风险级 → 该覆盖格不支持。
- 开口径无留痕监测 → 该行删除或字段停止。
- 指导账外佣金或另开账外 → 整体停止，不是该格不支持。

无 `E#` 不得写已覆盖、已生效或有效机制。状态 `草案`。一次只推荐下一步。

## 节点 4　监测、边界与转介

第 7 节只开接口，不得夹带 `TM#` 终稿绕闸。闸关闭时第 7 节可写「闸未开，转介待拟设编号」，不得补写已覆盖。

不写单家筛查结论、尽调底稿、中止通知终稿、完整合同、礼品制度全文、发送版印发稿。不可逆（对外印发已生效、签署概括弃权）不得在草案阶段实施。禁止提交指令。不代印发。不选定机关。

单家筛查转 `筛查经销商代理中介廉洁风险`。尽调转 `准备第三方尽职调查工作底稿`。中止通知转 `准备中止或终止高风险第三方合作通知`。中间人资金链路转 `评估中间人费用与资金链路`。礼品制度转 `设计反商业贿赂与礼品招待制度`。框架转 `设计合规管理体系框架`。办法全文转 `起草合规管理办法或章程级制度`。完整合同搁置。医药转医疗。竞争协议搁置或转竞争法。

若 if 用户催促「按零写／填满已覆盖终稿」，then 该格 `现有依据不支持`，窗口不关。
若 if 交易额、家数未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「机制闸与机制草案」。本窗不执行印发。不包含：已覆盖证明、已生效证明、单家筛查结论、尽调底稿、中止通知发送稿、完整合同、账外操作步骤。禁止选边治愈。禁止承诺书即覆盖。禁止准入表即已覆盖。禁止印发即生效。禁止无监测称有效。禁止指导账外佣金。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标机制终稿已形成。
风险档 A：指导账外佣金、另开账外、倒签必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：民企。拟设经销／代理／中介三级、高风险须承诺书加复评，但无监测周期、无退出接口。用户主张签了承诺书就已覆盖、准入表填了就算覆盖、没有监测也是有效机制、印发当天生效、范本就是法定格式、民企必须按 42 号令第十八条覆盖第三方、交机制稿就能从轻或自首、按 FCPA 写死。机制闸打开。`Q-承`、`Q-表`、`Q-监`、`Q-印`、`Q-范`、`Q-18`、`Q-免`、`Q-自`、`Q-美` 不打开为可靠路径。第 6 节不得把承诺书即覆盖、已生效或必须专项写入可执行 `TM#`；对应格 `现有依据不支持`；仍出对象类型、风险级、合同接口要点、监测缺口等其他 `TM#` 草案。无监测则有效机制格不支持。不关窗。不代印发。不得建议报国资委。

场景②：用户同时交出公司第三方机制草稿与被调查经销商抗辩，要求选对公司有利的一版，并指导「中间人佣金改走账外、经销商另开账外口径」。命中双方秘密＋指导账外佣金。第一次整体停止。只交第 1、10 节。不出 `TM#`。不得问代表哪一方后继续。
