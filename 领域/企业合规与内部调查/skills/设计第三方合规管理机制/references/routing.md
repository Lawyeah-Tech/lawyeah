# 边界与路由

## 正触发

需要经销商、代理、中介、顾问或高风险供应商的分级准入、合同接口、监测复评与退出机制草案，而不是审查单份合同、做单家筛查或写中止通知。碎片、监测未核验仍正触发：有可编号拟设机制行或现行碎片则闸开或半开，出 `TM#` 草案。签承诺书即机制或已覆盖、清单即已尽职、合同已签即已管理、分级完成即闭环、印发即生效、纸面即有效机制、无监测即有效、范本即法定格式、民企必须按 42 号令第十八条覆盖第三方、交机制稿即从轻或自首、FCPA 即中国法义务，仍正触发。

双方秘密、指导账外佣金、另开账外口径、指导虚假尽调、伪造准入、伪造账册、倒签生效、指导删除、打击报复的停止，优先于负触发。上述信号不在下表。「签承诺书即机制或已覆盖」「清单即已尽职」「准入表即已覆盖」「印发即生效」「合同已签即已管理」「分级完成即闭环」「纸面即有效机制」「无监测即有效」「范本即法定格式」「民企必须覆盖第三方」「交机制稿即从轻或自首」「FCPA 即中国法」「本表已合规」不在下表。「不写完整合同」「不保证合作合法」「不筛单家」是交付禁令，不在下表。出现「经销商」「代理」「中介」「供应商」一词不是转出。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 单家或一批廉洁筛查 | `筛查经销商代理中介廉洁风险` |
| 尽调工作底稿 | `准备第三方尽职调查工作底稿` |
| 中止或终止合作通知 | `准备中止或终止高风险第三方合作通知` |
| 中间人费用与资金链路终稿 | `评估中间人费用与资金链路` |
| 礼品招待制度全文 | `设计反商业贿赂与礼品招待制度` |
| 销售激励与渠道返点终稿 | `评估销售激励与渠道返点廉洁风险` |
| 回扣账外资金链路终稿 | `评估回扣账外暗中与资金链路` |
| 廉洁风险图 | `评估反商业贿赂风险点` |
| 完整交易合同审查或起草 | 审查起草领域（本窗搁置） |
| C 端小微供应商勾选清单 | 大众专项，只分流 |
| 综合合规框架 | `设计合规管理体系框架` |
| 章程级办法全文 | `起草合规管理办法或章程级制度` |
| 药品购销回扣行业细则整案 | 医疗领域 |
| 垄断协议、滥用支配或竞争协议审查 | 竞争法领域或审查起草搁置 |
| 任免、股权或章程决议本身 | 公司治理领域 |
| 刑事辩护、控告或自首 | 刑事领域 |
| 劳动规章或解除决定 | 劳动领域 |

不得因「不写完整合同」「不保证合作合法」「不筛单家」关窗。承诺书即机制、清单即已尽职、合同已签即已管理、分级完成即闭环、无监测即有效、印发即生效、FCPA 当中国法该格不支持，窗口不关，不转出。主成果才转。民企硬套不得负触发到对照窗。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 药品购销回扣行业细则为主成果 | 医疗领域 |
| 垄断协议、滥用支配、经营者集中为主成果 | 竞争法领域 |
| 劳动合同、解除主轴且机制草案不是主成果 | 劳动领域 |
| 投资并购整体尽调为主成果 | 投资并购领域 |

综合第三方机制草案主轴可留本任务。检查或已立案只作背景，主成果才转。

## 易混

机制闸打开不是已覆盖。

草案不是已生效。印发不是生效。总部印发不对独立法人子公司当然生效。纸面不是有效机制。签承诺书不是机制。清单不是已尽职。准入表不是已覆盖。合同已签不是已管理。分级完成不是闭环。无监测不是有效机制。范本不是法定格式。C 端勾选清单不是专业第三方管理。中间人、经销商、代理适用同一套，不得另开账外。明示佣金入账不是贿赂。FCPA 不是中国法义务。42 号令第十八条不套民企必须覆盖第三方。交机制稿不是从轻，不是自首。不写完整合同、不保证合作合法是交付禁令，不是负触发。口头「签了承诺书就覆盖了」不是开闸材料。可编号拟设行或现行碎片才开闸。指导虚假尽调、伪造准入或账外佣金是第一次整体停止，不是不关窗。
