# 评估方法

本文件是可执行判断节点。账外闸打开不等于已回扣不等于已贿赂不等于已入账合规。明示折扣佣金如实入账不是贿赂。合同写「折扣」不是双方已如实入账。账外暗中候选不是已回扣不是已贿赂。个人账户收款不是单位行贿既遂。员工个人收钱不自动等于经营者行为。四态未齐不得写回扣已成立。对方控制账户不能推定链路存在。缺流水不写零。不输出唯一回扣总额。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、刑事既遂、选定机关、代提交、未知写零。本窗不定罪，不写风险图终稿，不写中间人费用终稿，不出测算总额。本窗 `XB#` 是账外行，不是风险点 `BR#`，不是测算 `M#`，不是调查认定 `F#`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1993 年反不正当竞争法第八条「账外暗中给予回扣以行贿论处」、把折扣写成已回扣、把账外写成已贿赂时记为噪声。2019 修正第七条公开文本没有「账外暗中以行贿论处」；该句在 1993 年第八条，2017 修订已删。施行日前未持续行为适用修改前文本（通常 2019 修正第七条）须核验后再写入 `L#`。禁止指导做假账、账外暗中路径或行贿步骤。禁止 `search_template` 生成已回扣清单或已入账合法证明。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现付款碎片扫描，不是默认闭集。
`XB#` 固定列：`编号｜款项标识｜指令人｜账户或载体｜入账四态（合同明示且双方如实入账／合同明示但入账待核或单方／账外暗中候选／去向不明）｜最终受益人｜断裂点｜E#回链｜判断三值｜G#｜最强反方｜状态`。明示双方入账 ≠ 已合法闭集。账外暗中候选 ≠ 已回扣 ≠ 已贿赂。去向不明 ≠ 推定存在。四态未齐不得写回扣已成立。缺给予／收受、财物或其他手段、交易机会或竞争优势、入账任一项：该效果 `依据不足，无法形成结论`，不得写成已回扣或已贿赂。无 `E#` 不得写已覆盖、已回扣、已入账闭环。`E#` 只作证据形态回链。缺项记 `G#`。扫描不是闭集。状态默认 `草案`。禁止本窗用 `M#` 写回扣总额。

口头「都是回扣」「折扣就是回扣」「行业都这样所以合法」「账外所以已经行贿」只进 `S#`／`V#`，**不得单独算作开闸材料**。合同写「折扣」不是双方已如实入账。截图不是已入账。员工承认收款不是经营者行为已成立。付款回单不是已贿赂。`A#` 是承认给付或入账痕迹，不是已回扣。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

## 节点 0　分流、立场、账外闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造账册、指导账外暗中、指导行贿步骤、隐匿流水、指导删除会计资料、打击报复、阻挠检查不进负表。

整案转出只交付第 1、2、10 节，不出 `XB#` 终稿。

| 主成果是中间人费用终稿 | 负触发 `评估中间人费用与资金链路` |
| 主成果是账簿虚假报销终稿 | 负触发 `评估账簿记录与虚假报销` |
| 主成果是销售激励与渠道返点终稿 | 负触发 `评估销售激励与渠道返点廉洁风险` |
| 主成果是礼品招待审查终稿 | 负触发 `审查礼品招待赞助与捐赠` |
| 主成果是反贿赂制度终稿 | 负触发 `设计反商业贿赂与礼品招待制度` |
| 主成果是非调查关联交易廉洁评估 | 负触发 `评估利益冲突与关联交易廉洁面` |

| 主成果是调查报告终稿 | 负触发 `形成内部调查报告` |
| 主成果是公职接触点终稿 | 负触发 `梳理公职人员接触点与审批` |
| 主成果是税务处理或虚开实体 | 整案转税务 |
| 主成果是药品购销回扣行业细则 | 整案转医疗 |
| 主成果是刑事辩护、控告或自首 | 整案转刑事 |
| 「不定行贿罪」「不把折扣一律写成回扣」「不作出税务处理决定」 | 交付禁令，不是负触发 |

审查起诉、监管检查、已立案只作程序背景。主成果才整案转。出现「回扣」「折扣」一词不是转出。

账外闸打开（可出 `XB#` 草案，仍不得标「已回扣／已贿赂／已合法／已定罪」）须同时满足：单方无冲突公司立场已闭合；主成果是资金链路分账，不是风险图、中间人终稿、测算总额或刑辩；至少一条可编号付款碎片。合同折扣条款、发票、入账科目、银行回单、个人卡流水、微信转账、付款指令可编号开闸。口头「都是回扣」、行业惯例不算单独开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

账外闸部分打开：已有可编号付款碎片，但指令、账户、入账、受益人、施行日未闭合；或无书面评估授权但已有碎片。对应格待核；仍交十节；不得标终稿 `已形成`。

账外闸关闭（仍正触发）：无一可编号付款碎片。「今天必须出已回扣终稿」而无最小碎片不得开闸。不出 `XB#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `XB#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关写成「没有回扣」或「已合规」。

「折扣一律回扣」「入账折扣即贿赂」「账外即已回扣／已贿赂」「个人卡即单位行贿既遂」「正常佣金即回扣」「去向不明即推定存在」「合同写折扣即已入账」「交链路表即从轻／自首」「民企必须按 42 号令上报」「本表已定罪」「唯一回扣总额」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `XB#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无一可编号付款碎片，then 账外闸关闭，仍交十节，不是整体停止。
若 if 单方立场已闭合、无书面授权但已有可编号碎片，then 账外闸部分打开，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象或相对方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出指导做假账或账外暗中步骤、指导行贿步骤、伪造账册或流水、隐匿证据、指导删除会计资料、打击报复、阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体、付款碎片与强制接口

一行一个付款碎片。缺项记 `G#`，未知金额不得写 `0`。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 主体 | 经营者／工作人员；民企／国家出资公司／上市 | 民企必须按 42 号令上报 |
| 款项 | 折扣／佣金／账外候选／其他给付，分列 | 合成「都是回扣」 |
| 入账 | 四态分列 | 合同写折扣即已入账 |
| 账户 | 对公／个人卡／第三方／账外台账 | 个人卡即单位行贿 |
| 施行日 | 行为时点相对 2025-10-15 | 跨日用唯一条文 |

检索锚点（写入 `L#` 前须核验）：反不正当竞争法（2025）第八条，施行日 2025-10-15；明示折扣、向中间人支付佣金可以，双方应当如实入账；工作人员贿赂原则上认定为经营者行为，但与谋取交易机会或竞争优势无关的抗辩除外。入账不是合法闭集。噪声：1993 年第八条「账外暗中以行贿论处」。1996 暂行规定第五条「账外暗中」定义、第六条明示入账，须与 2025 文本冲突核验后再写入 `L#`，不得单独写成已回扣。刑法第一百六十三条／第一百六十四条／第三百八十五条／第三百八十九条／第三百九十三条只作红旗，不定罪。刑法第三百八十七条账外暗中收受回扣以单位受贿论，只约束所列国有单位，不套民企。行政处罚法第三十二条交链路表 ≠ 从轻。刑法第六十七条交表 ≠ 自首。监察法第十八条不得伪造隐匿。刑法第一百六十二条之一、第三百零七条、第三百零八条只作红旗，不得指导删除。42 号令只约束中央企业。FCPA 不是中国法义务。本节禁止出 `XB#` 终稿。

## 节点 3　账外行 `XB#`

按已出现付款碎片扫描，不是默认闭集。建议行型（出现才用）：

| 编号 | 含义 | 本窗允许 | 禁止 |
| --- | --- | --- | --- |
| `KB-折` | 合同折扣 | 分账草案 | 折扣一律回扣 |
| `KB-佣` | 佣金 | 委托／成果／入账可见 | 有委托入账仍写成回扣 |
| `KB-账` | 账外候选 | 四态并列 | 账外即已贿赂 |
| `KB-卡` | 个人卡／微信 | 记账户与控制方 | 个人卡即单位行贿 |
| `KB-代` | 第三方代付 | 红旗待核 | 代付即已回扣 |
| `KB-回` | 循环回流 | 断裂点可见 | 回流即既遂 |
| `KB-票` | 假发票接口 | 只开账簿／税务接口 | 吞账簿窗终稿 |

热冲突强制处理：

- 折扣一律回扣／入账折扣即贿赂／账外即已贿赂／个人卡即单位行贿／行业惯例即合法 → 该格不支持；仍出其他 `XB#`。
- 四问（合同明示？双方如实入账？进个人或账外账户？最终受益人是否交易决策人）未齐 → 该效果依据不足，不得写成回扣已成立。
- 有真实居间＋书面委托＋合理对价＋入账 → 不支持写成回扣。
- 无工作痕迹成功费 → 红旗，转中间人窗，不得写成回扣已成立。
- 资金链断裂、对方控制账户、时间错配 → 记 `G#`，不推定存在。
- 指导账外或伪造入账 → 整体停止，不是该格不支持。

无 `E#` 不得写已覆盖、已回扣或已入账闭环。状态 `草案`。一次只推荐下一步。

## 本任务回链纪律

本任务成果是「账外闸与账外行草案」。本窗不执行发送。不包含：已回扣证明、已贿赂证明、已入账合法证明、风险图终稿、中间人费用终稿、测算总额、刑事意见。禁止选边治愈。禁止折扣一律回扣。禁止账外即已贿赂。禁止个人卡即单位行贿。禁止交表即从轻或自首。禁止民企套 42 号令必须上报。禁止唯一回扣总额。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标链路终稿已形成。

## 场景对抗（运行时自检，不写入用户可见闭集）
