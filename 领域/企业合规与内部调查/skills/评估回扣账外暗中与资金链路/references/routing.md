# 边界与路由

## 正触发

需要把明示入账的折扣或佣金与账外暗中候选分账，并标出资金链断裂点，而不是出风险图、中间人对价终稿、测算总额或刑事定性。碎片、入账未核验仍正触发：有可编号付款碎片则链路闸开或半开，出 `KB#` 草案。折扣一律回扣、入账折扣即贿赂、账外即已回扣或已贿赂、个人卡即单位行贿既遂、正常佣金即回扣、去向不明即推定存在、本表已定罪、唯一回扣总额，仍正触发。

双方秘密、指导做假账或账外暗中步骤、指导行贿步骤、伪造账册、隐匿证据、打击报复、阻挠合法检查的停止，优先于负触发。上述信号不在下表。「折扣一律回扣」「入账折扣即贿赂」「账外即已回扣／已贿赂」「个人卡即单位行贿既遂」「正常佣金即回扣」「去向不明即推定存在」「本表已定罪」「唯一回扣总额」不在下表。「不定行贿罪」「不把折扣一律写成回扣」「不作出税务处理决定」是交付禁令，不在下表。出现「回扣」「折扣」一词不是转出。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 税务处理决定、稽查实体、虚开认定为主成果 | 税务领域 |
| 药品购销回扣行业细则为主成果 | 医疗领域 |
| 劳动合同、解除、工伤主轴且链路分账不是主成果 | 劳动领域 |
| 垄断协议、滥用支配、经营者集中为主成果 | 竞争法领域 |

综合资金链路分账主轴可留本任务。检查或已立案只作背景，主成果才转。已刑事立案且主成果是刑事程序：整案转刑事。已刑事立案但主成果仍是企业链路分账：留窗；指导干扰办案或隐匿整体停止。

## 易混

明示折扣佣金如实入账不是贿赂。合同写「折扣」不是双方已如实入账。账外暗中候选不是已回扣不是已贿赂。个人账户收款不是单位行贿既遂。员工个人收钱不自动等于经营者行为。四态未齐不是回扣已成立。对方控制账户不能推定链路存在。缺流水不是零损失。1993 年反不正当竞争法第八条「账外暗中以行贿论处」不是现行 `L#`。反法 2025 第八条施行日 2025-10-15；MCP 标尚未施行的以施行日为准。刑法第三百八十七条不套民企。不定行贿罪、不把折扣一律写成回扣、不作出税务处理决定是交付禁令，不是负触发。口头「都是回扣」不是开闸材料。可编号付款碎片才开闸。链路闸打开不等于已回扣不等于已贿赂。指导账外暗中或行贿步骤是第一次整体停止，不是不关窗。本窗 `KB#` 不是测算 `M#`，不是风险点 `BR#`。
