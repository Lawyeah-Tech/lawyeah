# 边界与路由

## 正触发

要对具体的单个或一批经销商、代理、中介或顾问做公开信息红旗、缺口与风险分级，而不是建整套机制、写尽调底稿或发中止通知。来源、受益人未核验仍正触发：有可编号对象则闸开或半开，出 `SC#` 草案。工商登记即廉洁、承诺书即已通过、红旗即已违法、公开处罚即定罪、不足即低风险、本批均无问题、高风险即必须中止、亲属供货即贿赂、空壳待核即已虚假、本表已合规、FCPA 即中国法义务、民企必须按 42 号令筛完，仍正触发。

双方秘密、指导买黑客或非法获取个人信息、指导伪造筛查底稿、指导伪装调查、倒签已通过、打击报复的停止，优先于负触发。上述信号不在下表。「工商登记即廉洁」「承诺书即已通过」「红旗即已违法」「公开处罚即定罪」「不足即低风险」「本批均无问题」「高风险即必须中止」「亲属供货即贿赂」「空壳待核即已虚假」「本表已合规」「FCPA 即中国法」「民企必须筛完」不在下表。「不定罪」「不买违法征信」「不保证合作合法」「不写尽调终稿」「不发中止通知」是交付禁令，不在下表。出现「经销商」「代理」「中介」「供应商」一词不是转出。

## 易混

筛查闸打开不是已通过。草案不是已廉洁。工商登记正常不是廉洁。签了廉洁承诺书不是已通过。公开信息检索不是已尽职。红旗不是已违法。公开处罚不是本窗定罪。不足不是低风险。禁止本批均无问题。高风险不是必须中止。亲属供货不是当然贿赂。空壳待核不是已虚假。C 端勾选清单不是专业筛查。明示佣金入账不是贿赂。FCPA 不是中国法义务。42 号令不套民企必须筛完。交筛查表不是从轻。不定罪、不买违法征信、不保证合作合法是交付禁令，不是负触发。口头「这批都没问题」不是开闸材料。可编号对象才开闸。指导买黑客或非法获取个人信息是第一次整体停止，不是不关窗。
