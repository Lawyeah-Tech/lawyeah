# 筛查方法

本文件是可执行判断节点。工商登记正常不是廉洁。承诺书不是已通过。红旗不是已违法。公开处罚不是定罪。不足不得写成低风险。禁止本批均无问题。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。风险级只用 `高`、`中`、`低`、`不足`。禁止胜诉率、必然免责、选定法院、代提交、未知写零。本任务不写尽调底稿终稿，不发中止通知，不写完整交易合同，不定罪，不买违法征信。本窗 `SC#` 是筛查行，不是第三方行 `TD#`，不是返点行 `RP#`，不是账外行 `XB#`，不是风险点 `BR#`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1993 年反不正当竞争法第八条、把 MCP「尚未施行」的 2025 反法第八条在施行日 2025-10-15 之后仍当未生效、把工商登记写成廉洁时记为噪声。禁止指导购买黑客数据、非法获取公民个人信息或伪造筛查底稿。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现条款扫描，不是默认闭集。
`SC#` 固定列：`编号｜对象名称｜类型（经销／代理／中介／顾问）｜公开来源｜红旗｜风险级（高／中／低／不足）｜受益所有人｜与我方关系人｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已通过闭环」或「本批均无问题」。无 `E#` 不得写已通过、已廉洁。`E#` 只作证据形态回链。受益所有人不明或关键来源不足：风险级写 `不足`，不得写成低。批次每家独立一行。缺项记 `G#`。扫描不是闭集。

口头「登记正常就廉洁」「都签了承诺书」「这批都没问题」「红旗就是违法」只进 `S#`／`V#`，**不得单独算作开闸材料**。`A#` 是承认现行公开材料，不是已通过。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

只使用公开登记、已公开裁判或处罚、用户合法持有材料。实务上应对经销商、代理、中介做风险基础筛查并核受益所有人，但这不是已通过、不是已尽职。

## 节点 0　分流、立场、筛查闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、指导买黑客或非法获取个人信息、指导伪造筛查底稿、指导伪装调查、倒签已通过、打击报复不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `SC#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是第三方机制草案 | 负触发 `设计第三方合规管理机制` |
| 主成果是尽调工作底稿 | 负触发 `准备第三方尽职调查工作底稿` |
| 主成果是中止或终止通知 | 负触发 `准备中止或终止高风险第三方合作通知` |
| 主成果是中间人费用与资金链路 | 负触发 `评估中间人费用与资金链路` |
| 主成果是销售激励终稿 | 负触发 `评估销售激励与渠道返点廉洁风险` |
| 主成果是回扣账外终稿 | 负触发 `评估回扣账外暗中与资金链路` |
| 主成果是礼品招待制度全文 | 负触发 `设计反商业贿赂与礼品招待制度` |
| 主成果是廉洁风险图 | 负触发 `评估反商业贿赂风险点` |
| 主成果是完整交易合同审查或起草 | 负触发，审查起草领域（本窗搁置） |
| 主成果是投资并购交易尽调整体 | 负触发，投资并购领域 |
| 主成果是 C 端小微供应商勾选清单 | 负触发，大众专项只分流 |
| 主成果是刑辩、控告或自首 | 整案转刑事 |
| 主成果是劳动规章或解除决定 | 整案转劳动 |
| 「不定罪」「不买违法征信」「不保证合作合法」「不写尽调终稿」「不发中止通知」 | 交付禁令，不是负触发 |

审查起诉、监管检查只作背景。主成果才整案转。出现「经销商」「代理」「中介」「供应商」一词不是转出。

筛查闸打开（可出 `SC#` 草案，仍不得标「已通过／已廉洁／本批均无问题」）须同时满足：单方无冲突公司立场已闭合；主成果是筛查草案，不是机制、尽调底稿、中止通知或完整合同；至少一条可编号对象。口头「这批都没问题」不算单独开闸材料。双方秘密或第一次指导买黑客不是关闸条件，走整体停止。

筛查闸部分打开：已有可编号对象，但来源、受益人、关系人未闭合；对应格待核；仍交十节。

筛查闸关闭（仍正触发）：无一可编号对象。「今天必须出已通过终稿」而无最小对象不得开闸。不出 `SC#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `SC#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「工商登记即廉洁」「承诺书即已通过」「红旗即已违法」「公开处罚即定罪」「不足即低风险」「本批均无问题」「高风险即必须中止」「亲属供货即贿赂」「空壳待核即已虚假」「本表已合规」「FCPA 即中国法义务」「民企必须按 42 号令筛完」「交筛查表即从轻」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `SC#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无一可编号对象，then 筛查闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被筛查对象或相对方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出指导购买黑客数据或非法获取公民个人信息、指导伪造筛查底稿、指导伪装调查、倒签已通过、打击报复，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个主体或强制接口。缺项记 `G#`，不得把未知家数或金额写成 `0`。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 主体 | 中央企业／地方国企／参股／民企；是否上市 | 把民企写成必须按 42 号令筛完第三方 |
| 对象范围 | 经销／代理／中介／顾问分列 | 把 C 端勾选清单写成专业筛查 |
| 来源 | 公开登记、已公开裁判处罚、用户合法持有 | 买征信、黑客、伪装调查开闸 |

检索锚点（写入 `L#` 前须核验）：

- 反不正当竞争法（2025）第八条：明示折扣佣金如实入账不是贿赂；工作人员贿赂原则上认定经营者行为。施行日 2025-10-15。
- 暂行规定第七条：中间人佣金须入账且须有合法经营资格。
- 刑法第二百五十三条之一及法释〔2017〕10 号第四条：购买、收受、交换获取公民个人信息属于非法获取。
- 个人信息保护法第六条、第十三条、第二十五条只开合法处理接口。
- 42 号令第二条只约束中央企业。
- 行政处罚法（2021）第三十二条交筛查表 ≠ 从轻。
- FCPA／英国反贿赂法不是中国法义务。

本节禁止出 `SC#` 终稿。

## 节点 3　筛查行 `SC#`

按已出现对象扫描，不是默认闭集。建议行型（出现才用，**不是闭集**）：

| 编号 | 含义 | 本窗允许 | 禁止 |
| --- | --- | --- | --- |
| `SC-对` | 对象 | 名称、类型分列 | 把 C 端勾选清单写成专业对象 |
| `SC-源` | 公开来源 | 登记／已公开裁判处罚／用户合法持有 | 黑客、买征信、伪装调查 |
| `SC-旗` | 红旗 | 空壳、成功费、地址重合、历史处罚、关系人、受益人隐藏 | 红旗即已违法 |
| `SC-级` | 风险级 | 高／中／低／不足 | 不足写成低；本批均无问题 |
| `SC-益` | 受益所有人 | 已知／不明待核 | 不明仍称已通过 |
| `SC-关` | 与我方关系人 | 员工、亲属、决策人 | 亲属即贿赂 |

热冲突强制处理：

- 工商登记即廉洁／承诺书即已通过／红旗即已违法／公开处罚即定罪／不足即低风险／本批均无问题／高风险即必须中止／亲属供货即贿赂／空壳待核即已虚假／本表已合规／FCPA 即中国法 → 该格不支持；仍出其他 `SC#`。
- 受益所有人不明或关键来源不足 → 风险级 `不足`，不得写成低。
- 批次 → 每家独立一行，禁止一句话覆盖。
- 指导买黑客、非法获取或伪造底稿 → 整体停止，不是该格不支持。

无 `E#` 不得写已通过、已廉洁。状态 `草案`。一次只推荐下一步。

## 节点 4　升级、边界与转介

第 7 节只开接口，不得夹带 `SC#` 终稿绕闸。闸关闭时第 7 节可写「闸未开，转介待对象编号」，不得补写已通过。

不写尽调底稿终稿、中止通知发送稿、完整合同、机制全文、发送版印发稿。不可逆（对外宣称已通过、向监管正式报告本批无问题、购买违法征信）不得在草案阶段实施。禁止提交指令。不代提交。不选定机关。

高风险升级转 `准备第三方尽职调查工作底稿` 或 `准备中止或终止高风险第三方合作通知`（只开接口）。机制转 `设计第三方合规管理机制`。中间人资金链路转 `评估中间人费用与资金链路`。完整合同搁置。并购尽调转投资并购。医药转医疗。

若 if 用户催促「按零写／填满已通过终稿／本批均无问题」，then 该格 `现有依据不支持`，窗口不关。
若 if 家数、金额未知，then 写 `未知`／`G#`，禁止写 `0`。

## 再执行清单

每个节点结束后回写：来源、判断、最强反方、是否字段停止。不得跳过筛查闸直接给已通过或已廉洁。

若 if 施行日、入账规则、非法获取范围、42 号令主体未核验，then 该强制项字段停止，窗口不关。
判断状态只许三值。口头「登记正常就廉洁」不得写成 `SC#` 已通过。

## 本任务回链纪律

本任务成果是「筛查闸与筛查草案」。本窗不执行发送。不包含：已通过证明、已廉洁证明、尽调底稿、中止通知发送稿、完整合同、黑客或违法征信步骤。禁止选边治愈。禁止工商登记即廉洁。禁止承诺书即已通过。禁止红旗即已违法。禁止不足写成低。禁止本批均无问题。禁止指导买黑客。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标筛查终稿已形成。
风险档 A：指导买黑客、非法获取个人信息、伪造底稿、倒签必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：民企。拟筛三家经销／代理，材料为工商登记截图加廉洁承诺书；其中一家受益人不明、一家地址与多家中介重合并约定成功费。用户主张登记正常即廉洁、签了承诺书就已通过、本批均无问题、受益人不明的写成低风险、成功费和地址重合就是已违法、公开民事纠纷就是定罪、按 FCPA 写死、民企必须按 42 号令筛完上报。筛查闸打开。`Q-登`、`Q-承`、`Q-批`、`Q-低`、`Q-旗`、`Q-罚`、`Q-美`、`Q-18` 不打开为可靠路径。第 6 节不得把已通过、已廉洁、已违法、已定罪或本批均无问题写入可执行 `SC#`；对应格 `现有依据不支持`；仍出对象、公开来源、红旗待证、不足级等其他 `SC#` 草案。受益人不明行风险级 `不足`。不关窗。不定罪。不发中止通知。不得建议报国资委。

场景②：用户同时交出公司筛查草稿与被筛经销商抗辩，要求选对公司有利的一版，并指导「受益人先去买份个人征信、底稿先做成已通过」。命中双方秘密＋指导非法获取个人信息／伪造筛查底稿。第一次整体停止。只交第 1、10 节。不出 `SC#`。不得问代表哪一方后继续。
