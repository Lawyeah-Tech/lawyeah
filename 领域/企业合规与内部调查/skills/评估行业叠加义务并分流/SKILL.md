# 评估行业叠加义务并分流

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“主成果归属、保留在本领域的综合段、转出清单”。同时出现数据、竞争、劳动、医药、金融、税务信号，需要决定主成果归属。

`depends-on` 为空。接受用户、律师、内审、机关或其他来源的等价事实、制度、授权、测算和证据清单，不要求先运行其他 Skill。

## 工作边界

正触发：同一事项同时出现多个行业或专项信号，需要先分流再决定本领域做什么。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 不代做专项实体结论；
- 不把数据或反垄断整案留在本包；
本任务不生成可提交刑事文书、劳动解除决定、法定信息披露正文或未进入合规机制的交易合同改稿，不给胜诉率或“合规即可免责”。

## 建立坐标

确认：使用者与授权；单方立场；已出现的专项信号清单、用户本次要的独立成果、是否已有专项卷宗；法域；当前检查、诉讼、监察或刑事状态；关键材料及缺失。

同时掌握公司与被调查对象或相对方相互冲突的秘密时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 内部制度或合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 假设；`V#` 版本；`E#` 发送／送达／履行凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 只核验用于判断归属的接口条款，不把专项构成写进本任务结论；`search_practiced` 补交叉管辖路径。不虚构监管系统或案号。

工具不可用时继续主体、事实和问题清单；法律结论、期限、机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 节点 1　识别主成果

先问这次要哪一项可验收成果。用户未选：只列入口，不指定主 Skill。

### 节点 2　强制转出

数据隐私整案、反垄断调查主轴、刑事辩护强制转出。

### 节点 3　可留综合段

治理、举报、调查程序、廉洁账簿、第三方机制可留。专项实体规则不写入。

### 节点 4　转出清单

每项转出写接收领域、已有材料、不得代做事项。

### 节点 5　禁止代做

不得为“方便”在本任务写 PIPL 合法性、垄断协议效力或税务处理决定。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体无法建立；用户坚持伪造、隐匿、威胁、打击报复或违法取证。
- `字段停止`：法域、施行日、动态规则、机关文书送达未核验。
- `目标停止`：主目标已变为本原子不得交付的文书或专项整案。
