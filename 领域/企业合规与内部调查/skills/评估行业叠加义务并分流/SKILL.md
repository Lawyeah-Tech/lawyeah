# 评估行业叠加义务并分流

## 任务目标

在明确、无利益冲突的单方立场下，形成叠加分流草案：分流闸、专项信号清单、`Q#` 路径、`HD#` 主成果归属与转出对照、本领域可留综合段、禁止代做字段。扫描不是闭集。出现数据、竞争、劳动、医药、金融、税务词汇不是整案转出。主成果才转。不代做专项实体结论。不合成跨领域法律意见。不保证一次给完全部领域结论。不代提交。

`depends-on` 为空。只要总图且无叠加争议转 `评估企业合规风险总图`。义务地图转 `建立合规义务与责任主体地图`。集团穿透转 `评估集团与子公司合规穿透`。上市公司廉洁内控转 `评估上市公司廉洁与内控交叉`。数据／竞争／劳动／医药／金融／税务／涉外／刑事专项实体结论转对应领域。

## 工作边界

正触发：同一事项同时出现多个行业或专项信号，需要先分流再决定本领域做什么。信号不齐、用户未选定本次优先成果、机关未立案仍正触发：分流闸关闭，不出 `HD#` 终稿，窗口不关。用户要一份「全面合规意见」覆盖全部专项、把出现某词写成必须整案转出、主张综合即可覆盖专项、选定某局、今天必须定主轴，仍正触发：对应格填 `现有依据不支持` 或字段停止，闸未开则不出分流终稿，窗口不关。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果已是数据隐私整案（转数据隐私领域）；
- 主成果已是反垄断调查或经营者集中（转竞争法领域）；
- 主成果已是劳动处分或解除（转劳动领域）；
- 主成果已是药品购销回扣行业细则（转医疗医药领域）；
- 主成果已是金融机构行业合规办法（转金融领域）；
- 主成果已是税务处理或稽查实体（转税务领域）；
- 主成果已是出口管制或制裁（转涉外领域）；
- 主成果已是刑事辩护（转刑事领域）；
- 只要综合风险总图且无叠加争议（转 `评估企业合规风险总图`）。

双方秘密、伪造分流表、伪造已移交记录、指导删除会计资料、打击报复**不在负触发表**，走整体停止。「出现某词即整案转」「全面意见一次给完」「综合即可覆盖专项」**不在负触发表**，只关对应格，窗口不关。

## 建立工作坐标

确认：分流授权；单方立场；已出现的专项信号；用户本次要的独立成果；是否已有专项卷宗或机关文书；当前检查、诉讼、监察或刑事状态。

口头「都是合规的事」「一个意见包打天下」只登记 `S#`／`V#`。不得升格已选定主成果或专项已覆盖。已读、快递揽收不得升格某专项机关已立案或已移交。授权复印件不能填专项立案空格。

同时掌握公司与被调查对象相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。公司已开口且委托就是分流、且未掌握对方秘密时，可推定公司立场。提出伪造分流表、伪造已移交、指导删除或打击报复：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 内部制度；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`HD#` 转出行；`V#` 版本。禁止 `N#`、`E#`、`EV#`、`M#`、`F#`、`ACT#`、`P#`、`K#`、`O#`、`H#`、`B#`、`U#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止合成「全面合规意见」一笔。扫描不是闭集。未知不写零。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例检索。本窗是评估类分流，**不要**用文书范本检索生成「已覆盖专项／全面意见」清单。
- 法规只核验用于判断归属的接口条款，**不把专项构成写入本任务结论**；实务用于发现交叉管辖与分别立案路径；案例只比较事实差异与翻转条件，不写成必然结果。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《民法通则》《民法总则》或其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 只核验归属接口：反垄断法（2022 修正）第十三条国务院反垄断执法机构负责反垄断统一执法，垄断协议实体结论转竞争法，本窗不写协议是否成立。个保法出境、合法性基础转数据隐私，本窗只开接口。反不正当竞争法（2025 修订）第八条明示折扣或佣金双方应当如实入账，不是贿赂；施行日 2025-10-15；MCP 标「尚未施行」以施行日为准并记冲突。药品管理法（2019）第一百四十二条购销收受财物只作医疗转出红旗，本窗不定性。金融机构合规管理办法与 42 号令适用范围不同，金融主轴转金融。42 号令、公司法第一百七十七条不套全部民企。行政处罚法第二十五条管辖争议由共同上一级指定；第三十二条提交分流表不等于从轻已成就。噪声：已失效《合同法》、2009 年工商查处垄断协议程序、2010 年反价格垄断程序当现行、1993 年反法第八条当现行、出现某词即整案转出、综合即可覆盖专项。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变归属或转出条件的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补同一行为分别立案、综合意见不能代替专项构成、交叉管辖的反例。
- `search_case_by_fact` 只比较事实差异与翻转条件（如约谈传闻≠反垄断立案），不写成必然转出或必然可留。

工具不可用时继续信号清单和 `HD#` 编目；归属、期限、机关路径字段停止。不得拒跑，不得凭记忆写成出现数据词即必须转数据或综合即可覆盖专项。

## 判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、分流闸与不关窗

主成果才整案转出。审查起诉只作背景。出现某词不是整案转出。全面意见不关窗。闸关仍交十节，第 6 节不出 `HD#` 终稿。

### 2. 专项信号与机关文书

信号分列，不是闭集。市监反垄断、网信、人社、药监、金监、税务、国资、检察文书分列。

### 3. 分流闸与路径 `Q#`

本节禁止出 `HD#` 终稿。用户未选定本次优先成果则闸可关，窗口不关。

### 4. 主成果与转出 `HD#`

每项信号一行：是否主成果、本领域保留或转出、接收领域、禁止代做。不得把未完成专项写成暂按合规。

### 5. 保留段与一次一项下一步

可留综合治理段。不可留专项实体。用户未选优先成果：只问一项这次先取得哪项成果。

## 停止与安全

- `整体停止`：立场或授权无法闭合；双方秘密未解；提出伪造分流表、伪造已移交、指导删除会计资料、借已有监察／检查文书平行灭证或打击报复。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：归属接口、机关文书、施行日未核验。全面意见一次给完、出现某词即整案转、综合即可覆盖专项、选定某局：该格停止，窗口不关；闸未开仍不出 `HD#` 终稿。
- `目标停止`：主目标变为专项实体结论或跨领域综合法律意见终稿。

禁止指导伪造分流或删除会计资料。不给胜诉率。不定罪。不保证免责。不选定机关。不代提交。未知不写零。不代做专项实体结论。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。分流闸关闭或不关窗信号仍交十节；第 6 节不出 `HD#` 终稿。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。分流闸未打开时不得交付分流终稿或「全面意见已覆盖」。边界见 [路由](references/routing.md)。
