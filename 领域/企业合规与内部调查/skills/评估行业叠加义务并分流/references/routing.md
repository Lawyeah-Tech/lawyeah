# 边界与路由

## 正触发

同一事项同时出现多个行业或专项信号，需要先分流再决定本领域做什么。信号不齐、用户未选定优先成果仍正触发：分流闸关闭，不出 `HD#` 终稿，窗口不关。全面意见一次给完、出现某词即整案转、综合即可覆盖专项，仍正触发。

双方秘密、伪造分流表、伪造已移交、平行灭证、打击报复的停止，优先于负触发。上述信号不在下表。「全面意见一次给完」「出现某词即整案转」「综合即可覆盖专项」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要综合风险总图且无叠加争议 | `评估企业合规风险总图` |
| 义务—主体地图 | `建立合规义务与责任主体地图` |
| 集团穿透终稿 | `评估集团与子公司合规穿透` |
| 上市公司廉洁与内控交叉终稿 | `评估上市公司廉洁与内控交叉` |
| 数据隐私整案 | 数据隐私领域 |
| 反垄断调查或经营者集中 | 竞争法领域 |
| 劳动处分、解除 | 劳动领域 |
| 药品购销回扣行业细则 | 医疗医药领域 |
| 金融机构行业合规办法 | 金融领域 |
| 税务处理、稽查实体 | 税务领域 |
| 出口管制、制裁 | 涉外领域 |
| 刑事辩护、控告 | 刑事领域 |
| 未进入合规机制的合同改稿 | 审查起草领域（本窗搁置，只说明） |

不得因「要求全面意见」或「出现数据词」关窗。专项词汇作背景、综合治理主轴可留，不得写成专项已查清。

## 专项整案转出

| 主轴信号（须主成果） | 路由 |
| --- | --- |
| 合法性基础、出境、等保、网安事件专项整案 | 数据隐私领域 |
| 垄断协议、滥用支配、集中申报、反垄断执法应对 | 竞争法领域 |
| 劳动合同、解除、工伤主轴 | 劳动领域 |
| 药品购销回扣行业细则 | 医疗医药领域 |
| 银行保险机构行业合规办法 | 金融领域 |
| 税务处理决定、稽查实体 | 税务领域 |
| 出口管制、制裁名单 | 涉外领域 |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |

审查起诉或检查只作背景，主成果才转。出现专项词汇不等于整案转出。

## 必转介接口

## 易混

出现数据或竞争词汇不等于整案转出；整案看主成果。主成果是专项实体结论则必须转出。综合排查中的红旗可留综合段，实体结论仍转出。明示折扣如实入账不是贿赂。金融机构行业办法不是 42 号令。一份全面意见不能代替专项构成。「先把专项线索删掉再分流」整体停止。
