# 评估行业叠加义务并分流方法

本文件是可执行判断节点，不是栏目说明书。每个会改变分流、范围、发送闸或下一步的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然免责、必然行政处罚、刑事既遂或唯一必得追偿总额。

`search_law` 返回已失效《合同法》《民法通则》《民法总则》或其解释时记为噪声，不得写入 `L#`。MCP 将 2025 修订《反不正当竞争法》标为尚未施行但公布施行日为 2025-10-15 的，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。民事请求与抗辩核验《民法典》合同编及相关司法解释，不得把失效合同法当现行规则。

## Q# 矩阵

固定列：`编号｜命题｜法律或政策效果｜成立条件｜支持事实｜不利事实｜控制方｜最强反方｜主备位｜判断｜待核`。

同一事实支持多项时分别说明效果，不重复金额。管理不规范不等于商业贿赂，更不等于单位犯罪。未知金额不写零。


## 节点 0　专项分流

先于实体判断。命中任一项且该专项是**主要成果**则整案转出，本任务只交付分流理由和最小交接，不填本原子十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 侦查、审查起诉、审判、取保、阅卷、辩护、刑事控告、自首材料 | 刑事领域 |
| 劳动合同、工资工时、解除劳动合同、工伤、职场性骚扰或日常违纪处分决定 | 劳动领域 |
| 个人信息合法性基础、影响评估、数据出境、等保、网安事件专项体系整案 | 数据隐私领域 |
| 垄断协议、滥用市场支配地位、经营者集中、反垄断调查主轴 | 竞争法领域 |
| 税务处理、稽查实体、偷逃税认定 | 税务领域 |
| 银行保险机构行业《合规管理办法》主轴 | 金融领域 |
| 药品购销回扣、医疗反腐行业细则主轴 | 医疗医药领域 |
| 出口管制、制裁名单、境外经营准入 | 涉外领域 |
| 尚未进入合规机制，只要改交易合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 章程、股东会、股权结构、公司决议本身 | 公司治理领域 |

数据隐私整案、反垄断调查主轴、刑事辩护只分流，不在本任务写专项实体结论。混合信号：综合合规治理或内部调查主轴可留本任务；专项只作为背景时在缺口标明。C 端小微体检、供应商清单、广告/隐私、劳动规章：负触发，只分流不回改。

## 节点 1　先拆成果再贴标签

按用户目标拆成可独立验收成果。若用户只要“全面合规意见”：拆成综合治理段 + 各专项转出，不得合成一份跨领域法律意见。

数据隐私整案（合法性基础、影响评估、出境、等保、网安事件专项）整案转出。反垄断调查主轴（垄断协议、滥用支配、集中申报、反垄断执法应对）整案转出。刑事辩护整案转出。

---

## 节点 2　主轴判定

主轴看：用户要的最终文书是什么、哪套构成要件决定对错、哪一机关正在办案。

若市监反垄断局已立案调查垄断协议：主轴是竞争法，本领域只保留内部证据持有和廉洁交叉接口。若网信或数据主管部门要出境评估：主轴是数据。若只是综合排查中发现数据或竞争红旗：红旗可留在综合段，实体结论仍转出。

---

## 节点 3　保留段白名单

可留在本领域：体系有效性、义务地图综合行、举报渠道、调查授权与程序、反商业贿赂与账簿、第三方廉洁、检查现场纪律、整改治理段。

不可留：PIPL 合法性、垄断协议效力、集中申报策略、税务处理、劳动解除决定、刑事构成。

---

## 节点 4　转出交接

每项转出必须有：信号、接收领域、已收集材料编号、本领域停止的字段。不得把未完成的专项结论写成“暂按合规”。

---

## 节点 5　一次只推一个下一步

用户未选择本次优先成果：只问一项“这次先取得哪一项成果”。回答前不指定主要 Skill。
