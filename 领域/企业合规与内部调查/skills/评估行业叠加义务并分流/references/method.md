# 评估方法

本文件是可执行判断节点。出现某词不是整案转出。本窗不代做专项实体结论。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、全面意见闭集、唯一截止日、选定机关、代提交、未知写零。本任务不定罪。扫描不是闭集。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、2009 年工商查处垄断协议程序、2010 年反价格垄断程序、1993 年反法第八条、把出现某词写成必须整案转出时记为噪声。MCP 将 2025 反法标尚未施行但施行日为 2025-10-15 的，以施行日为准并记冲突。禁止指导伪造分流或删除会计资料。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`HD#` 固定列：`编号｜信号｜是否主成果｜本领域保留／转出｜接收领域或原子｜已有材料｜禁止代做｜判断三值｜待核`。禁止合成「全面合规意见」一笔。禁止 `N#`／`E#`／`EV#`／`M#`／`F#`／`ACT#`／`P#`／`K#`／`O#`／`H#`／`B#`／`U#`。

口头「都是合规」「一个意见包打天下」只进 `S#`／`V#`。已读、快递揽收不得升格某专项机关已立案。拟制日＝本次形成本任务成果之日。

## 节点 0　分流、立场、分流闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。伪造分流、双方秘密不进负表。

整案转出只交付第 1、2、10 节，不出 `HD#` 终稿。**仅当主成果**已是下列专项终稿时整案转出：

| 信号 | 处理 |
| --- | --- |
| 主成果是数据隐私整案 | 整案转数据隐私 |
| 主成果是反垄断调查或经营者集中 | 整案转竞争法 |
| 主成果是劳动处分或解除 | 整案转劳动 |
| 主成果是药品购销回扣行业细则 | 整案转医疗医药 |
| 主成果是金融机构行业合规办法 | 整案转金融 |
| 主成果是税务处理或稽查实体 | 整案转税务 |
| 主成果是出口管制或制裁 | 整案转涉外 |
| 主成果是刑事辩护 | 整案转刑事 |
| 只要总图且无叠加争议 | 负触发 `评估企业合规风险总图` |
| 主成果是义务地图 | 负触发 `建立合规义务与责任主体地图` |
| 主成果是集团穿透 | 负触发 `评估集团与子公司合规穿透` |
| 主成果是上市公司廉洁内控 | 负触发 `评估上市公司廉洁与内控交叉` |
| 尚未进入合规机制，只要改合同 | 审查起草本窗搁置 |

审查起诉、监管检查只作程序背景。专项词汇只作背景时，综合治理主轴可留本任务。

分流闸打开（可出 `HD#` 草案，仍不得标「全面意见已覆盖／专项已查清」）须同时满足：单方无冲突立场与分流授权；主成果是叠加分流，不是专项实体结论或无争议总图；至少一项可编号专项信号或用户成果目标；无双方秘密、无第一次伪造分流信号。

分流闸部分打开：信号或机关未闭合，但已有可编号红旗；对应格待核；仍交十节；不得标终稿 `已形成`。

分流闸关闭（仍正触发）：用户未选定本次优先成果，且无一可编号信号。「今天必须定主轴」而无最小事实不得开闸。不出 `HD#` 终稿。**仍交十节**，第 5 节只交闸／`Q#` 状态，第 6 节不出 `HD#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「没有专项」或「综合已覆盖」。

「全面合规意见一次给完」「出现某词即整案转出」「综合即可覆盖专项」「选定某局」「今天必须定主轴」「民企必须按 42 号令或 177 覆盖全部行业」「提交分流表即应当从轻」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸未开仍不出 `HD#` 终稿。

若 if 立场或授权无法闭合，then 整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造分流表、伪造已移交、指导删除会计资料、借已有监察／检查文书平行灭证或打击报复，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　专项信号与机关文书

按已出现事实扫描，不是默认闭集。数据、竞争、劳动、医药、金融、税务、涉外、刑事、国资分列。未出现的条线不铺开。

机关文书必须分列：市监反垄断、网信、人社、药监、金监、税务、国资、检察。口头约谈、微信已读不得升格已立案。授权复印件不能填专项立案空格。

检索锚点（写入 `L#` 前须核验，且**不得把专项构成写入本窗结论**）：

- 反垄断法（2022 修正）第十三条：国务院反垄断执法机构负责反垄断统一执法。本窗只判归属，不写垄断协议是否成立。噪声：2009 年工商查处垄断协议程序、2010 年反价格垄断程序。
- 个保法出境、合法性基础：转数据隐私，本窗只开接口。
- 反不正当竞争法（2025 修订）第八条：明示折扣、佣金如实入账不是贿赂；施行日 2025-10-15。廉洁账簿可留综合段，不定罪。
- 药品管理法（2019）第一百四十二条：购销收受财物只作医疗转出红旗。
- 金融机构合规管理办法与 42 号令适用范围不同。金融主轴转金融，42 号令不套全部民企。
- 行政处罚法第二十五条：两个以上机关都有管辖权的，由最先立案的管辖；争议报共同上一级。本窗不选定唯一机关。

## 节点 3　主成果与转出 `HD#`

按用户目标拆成可独立验收成果。若只要「全面合规意见」：拆成综合治理段＋各专项转出，不得合成一份跨领域法律意见。

主轴看：用户要的最终文书、哪套构成要件决定对错、哪一机关正在办案。市监反垄断局已立案调查垄断协议：主轴是竞争法，本领域只保留内部证据持有和廉洁交叉接口。网信要出境评估：主轴是数据。综合排查中发现数据或竞争红旗：红旗可留综合段，实体结论仍转出。

每项转出必须有：信号、接收领域、已收集材料编号、本领域停止的字段。不得把未完成的专项结论写成「暂按合规」。

可留在本领域：体系有效性接口、义务地图综合行、举报渠道、调查授权与程序、反商业贿赂与账簿、第三方廉洁、检查现场纪律、整改治理段。

不可留：PIPL 合法性、垄断协议效力、集中申报策略、税务处理、劳动解除决定、刑事构成、药品购销回扣认定。
