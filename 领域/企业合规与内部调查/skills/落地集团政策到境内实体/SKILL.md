# 落地集团政策到境内实体

## 任务目标

在明确、无利益冲突的单方立场下，形成集团或境外模板对单一境内实体的落地对照草案：落地闸、主体与强制本地接口、`Q#` 路径、`LD#` 条款三态行（保留／改写／删除）。总部印发不是境内已生效。原则适用不是已落地。美国律师—客户特权条款不能写成中国法免交理由。禁止整份「原则适用」。境内有权机关审议前不得写已替代集团原文。不写境外当地法结论。不给出境传输方案。不写劳动规章全文。不保证免责。不代提交。

`depends-on` 为空。集团对子公司是否覆盖转 `评估集团与子公司合规穿透`。跨境调查转 `协调跨境内部调查并分流涉外`。数据出境方案转数据隐私。出口管制或制裁转涉外。劳动规章全文转劳动。办法正文转 `起草合规管理办法或章程级制度`。政策层级终稿转 `设计政策层级与例外批准`。公司章程本身转公司治理。

## 工作边界

正触发：境内实体需要把集团模板改成可在中国大陆执行的政策对照，而不是直接适用原文。模板碎片、审议机关未核验、无书面落地授权仍正触发：有可编号模板条款或拟设落地行则落地闸打开或半开，第 6 节出 `LD#` 草案，缺项记 `G#`，生效格待核。无书面落地授权但有拟设行或模板碎片：部分打开。无一可编号条款且无一拟设行、又要求「今天必须出已在境内生效终稿」才关闸，不出 `LD#` 终稿，窗口不关。用户要整份原则适用、总部盖章即境内生效、原样保留无限制调取私人设备或禁止向当地机关举报、把 FCPA 写成中国法义务、民企按 42 号令第三十九条必须落地并上报、今天必须出已替代原文终稿，仍正触发：对应格填 `现有依据不支持`，窗口不关；闸已开仍出其他 `LD#` 草案。热冲突条款不得仅标不支持后仍写入保留。不得因「全球一致」或「不要出境方案」改走负触发关窗。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是总部机制是否覆盖子公司（转 `评估集团与子公司合规穿透`）；
- 主成果是跨境调查协调（转 `协调跨境内部调查并分流涉外`）；
- 主成果是数据出境或个人信息专项体系（转数据隐私领域）；
- 主成果是出口管制、制裁或境外当地劳动法结论（转涉外领域）；
- 主成果是劳动规章或员工手册纪律全文（转劳动领域）；
- 主成果是章程级办法正文（转 `起草合规管理办法或章程级制度`）；
- 主成果是政策层级与例外方案终稿（转 `设计政策层级与例外批准`）；
- 主成果是公司章程、股东会、股权或任免本身（转公司治理）；
- 主成果是交易合同改稿（审查起草本窗搁置）；
- 确为中央企业且主成果是 42 号令对照终稿（转 `评估国企合规管理办法差距`）；民企或参股要求按第 39 条写已覆盖仍正触发，该格 `现有依据不支持`，不得建议上报国资委。

双方秘密、伪造境内审议或倒签生效、假对照表、指导删除会计资料、打击报复**不在负触发表**，走整体停止。「原则适用即已落地」「盖章即生效」「FCPA 当中国法」「特权免交」「禁止外举」「民企套第 39 条」**不在负触发表**，该格 `现有依据不支持`，窗口不关。「不给出境方案」「不写境外当地法」「不写交易合同全文」是交付禁令，不是负触发。

## 建立工作坐标

确认：书面落地授权；单方立场（集团与境内实体互斥）；模板版本、境内主体（独立法人子公司／分公司分列）；强制本地规则信号；工会或职工代表大会接口；当前检查、诉讼、监察或刑事状态。

口头「全球适用」「总部已盖章」「群已读就是境内已生效」只登记 `S#`／`V#`。不得升格已落地、已替代或已免责，**不得算作开闸材料**。已读、快递揽收不得升格 `R#` 已送达。

同时掌握集团与境内实体相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。境内实体已开口且委托就是对照表、且未掌握集团秘密时，可推定境内立场。无书面落地授权但境内立场已闭合、且已有可编号拟设行或模板碎片：落地闸部分打开，仍交十节，不是整体停止。无一拟设且无一碎片：落地闸关闭，仍交十节，不是整体停止。提出伪造境内审议、倒签生效、假对照表、指导删除或打击报复：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认（不是已落地，不是已替代）；`R#` 机关或境内有权机关生效文书；`C#` 章程或落地授权；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`LD#` 落地条款行；`V#` 模板版本；`E#` 证据形态回链（模板版本、冲突点、境内落地授权／审议职权，不是发送闸，不是已生效证明）。禁止 `N#`、`EV#`、`M#`、`F#`、`ACT#`、`P#`、`K#`、`O#`、`H#`、`B#`、`U#`、`X#`、`HD#`、`W#`、`T#`、`OR#`、`LV#`、`TR#`、`PX#`、`SP#`。技能正文中的条号是检索锚点，不是已核验 `L#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止合成「原则适用已落地」一笔。扫描不是闭集。缺项记 `G#`，不得用全球一致填满。未知不写零。稿件状态默认 `草案`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。本窗是对照类落地草案，范本只借栏目，**不要**升格「已落地／已替代集团原文／总部印发即生效」。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现总部制度直接在子公司生效、美国特权条款原样保留、禁止向当地机关举报的反例；案例只比较事实差异与翻转条件，不写成必然结果。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《民法通则》《民法总则》或其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：公司法第三条公司是企业法人，有独立的法人财产（噪声：1993 年第三条）。第十三条子公司具有法人资格、依法独立承担民事责任；分公司不具有法人资格，民事责任由公司承担。总部规章制度不能直接在独立法人子公司生效，须子公司有权机关批准；与员工切身利益有关的制度只开劳动合同法第四条民主程序接口，本窗不做完。第十七条制定重要规章制度应当听取工会和职工意见，只开接口。第二十三条人格否认不得写成集团政策即可刺破。民法典第七十四条分支机构民事责任由法人承担，与独立法人子公司分列。第一百六十八条国家出资公司不含参股。第一百七十七条仅约束国家出资公司对内合规，不套民企子公司。中央企业合规管理办法第三十九条只约束中央企业推动所属单位建立健全，不等于模板已对民企子公司生效；第四十条是地方国资参照。个保法第六条最小范围、第十三条人力资源管理所必需，不等于全员邮箱、私人微信或定位当然授权。反不正当竞争法（2025 修订）第八条明示折扣佣金如实入账不是贿赂，施行日 2025-10-15。行政处罚法第三十二条提交对照表不等于从轻情节成就。监察法第十八条如实提供，不得伪造、隐匿、毁灭。刑法第一百六十二条之一只作红旗，**不得指导删除**。不得把美国《反海外腐败法》或萨班斯程序写成中国法义务。噪声：已失效《合同法》、总部印发即生效、原则适用即已落地、美国特权当免交、FCPA 当中国法、42 号令第三十九条套民企、交落地表即从轻。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变独立法人效果、劳动民主程序接口或个保调取边界的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补总部制度须经子公司董事会或民主程序才生效、美国特权条款不能直接保留、禁止向当地机关举报应删除的反例。
- `search_template`（optional）只借冲突条款对照、保留／改写／删除栏目，不把范本当法定格式、已落地证明或已生效结论。

工具不可用时继续主体、模板版本和 `LD#` 编目；独立法人效力、强制本地接口、施行日字段停止。不得拒跑，不得凭记忆写成总部印发已在境内生效或民企必须适用 42 号令。

## 判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、落地闸与不关窗

主成果才整案转出。审查起诉或检查只作背景。伪造审议、倒签生效第一次停。原则适用、盖章即生效、FCPA 当中国法、禁止外举不关窗。闸关仍交十节，第 6 节不出 `LD#` 终稿。集团与境内实体立场互斥。

### 2. 主体与强制接口

独立法人子公司／分公司／参股／民企／中央企业分列。强制本地规则与非强制对标分列。主体不适用则对照行删除。

### 3. 落地闸与路径 `Q#`

本节禁止出 `LD#` 终稿。从零有可编号模板条款或拟设行：闸打开或半开。无书面授权但有拟设：部分打开。无一条款且无一拟设才关闸，窗口不关。口头全球适用、总部盖章、已读揽收不得开闸。

### 4. 落地条款三态行 `LD#`

每条模板条款：保留／改写／删除。无法判断则该条待核，不得默认保留。热冲突不得保留。缺项记 `G#`。状态 `草案`。

### 5. 生效程序、劳动数据接口与转介

境内有权机关审议前不得写已替代。劳动民主程序只开接口。数据出境、出口管制只开接口。不可逆动作不得在草案阶段实施。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造境内审议、倒签生效、假对照表、指导删除会计资料、借落地稿平行灭证、打击报复或阻挠合法检查。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无书面落地授权但境内立场已闭合：不是整体停止；有拟设则部分打开，无一拟设则闸关闭，仍交十节。
- `字段停止`：法域、施行日、42 号令主体、个保或劳动强制接口未核验。原则适用即已落地、盖章即生效、FCPA 当中国法、特权免交、禁止外举、无限制调设备、民企套第 39 条：该格 `现有依据不支持`，窗口不关；闸已开仍出其他 `LD#` 草案；闸未开才不出 `LD#` 终稿。
- `目标停止`：主目标变为穿透四问终稿、出境方案、境外当地法、劳动规章全文、办法全文、公司章程。

禁止指导伪造审议或删除会计资料。不给胜诉率。不定罪。不保证免责。不选定机关。不代提交。未知不写零。不给出境方案。不写境外当地法结论。不写劳动规章全文。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。落地闸关闭仍交十节，第 6 节不出 `LD#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `LD#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。落地闸未打开时不得交付落地终稿或「已替代集团原文」。边界见 [路由](references/routing.md)。
