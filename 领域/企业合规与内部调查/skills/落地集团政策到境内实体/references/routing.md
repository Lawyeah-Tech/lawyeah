# 边界与路由

## 正触发

境内实体需要把集团模板改成可在中国大陆执行的政策对照，而不是直接适用原文。模板碎片、审议机关未核验仍正触发：落地闸关闭则不出 `LD#` 终稿，窗口不关。原则适用即已落地、盖章即生效、FCPA 当中国法、特权免交、禁止外举、无限制调设备、民企套第 39 条，仍正触发。

双方秘密、伪造境内审议、倒签生效、假对照表、指导删除、平行灭证、打击报复的停止，优先于负触发。上述信号不在下表。「原则适用即已落地」「盖章即生效」「FCPA 当中国法」「特权免交」「禁止外举」不在下表。「不给出境方案」「不写境外当地法」「不写交易合同全文」是交付禁令，不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 总部机制是否覆盖子公司 | `评估集团与子公司合规穿透` |
| 跨境调查协调 | `协调跨境内部调查并分流涉外` |
| 数据出境或个保专项体系 | 数据隐私领域 |
| 出口管制、制裁或境外当地劳动法 | 涉外领域 |
| 劳动规章或员工手册纪律全文 | 劳动领域 |
| 章程级办法正文 | `起草合规管理办法或章程级制度` |

不得因「全球一致」或「不要出境方案」或「盖章视为生效」关窗。无书面授权仍正触发，不得写成已落地。

## 易混

集团模板盖章不是境内生效。原则适用不是已落地。美国律师—客户特权条款不能直接写成中国法下的免交理由。无限制调取私人设备不能用个保法第十三条正当化。禁止向当地机关举报不能保留。并表不是穿透，本窗不出 `U#`。总部印发不能直接在独立法人子公司生效。FCPA 对标不是中国法义务。民企套 42 号令第三十九条：该格不支持，不关窗。提交对照表不是从轻已成就。「先补假子公司决议再出已落地稿」整体停止。劳动规章全文和出境方案不在本窗。
