# 边界与路由

## 正触发

境内实体需要把集团或境外模板改成可在中国大陆执行的政策对照，而不是直接适用原文。从零、模板碎片、无书面落地授权仍正触发：有拟设或模板碎片则闸开或半开，出 `LD#` 草案，生效格待核。原则适用、总部印发即生效、美国特权免交、民企套第 39 条、FCPA 当中国法、群已读即已公布，仍正触发。

双方秘密、伪造境内审议、倒签生效、指导删除、平行灭证、打击报复、阻挠合法检查的停止，优先于负触发。上述信号不在下表。「原则适用即已落地」「印发即生效」「特权免交」「禁止外举」「民企套第 39 条」「FCPA 当中国法」不在下表。「不给出境方案」「不写境外当地法」「不写劳动规章全文」是交付禁令，不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 总部机制是否覆盖（四问） | `评估集团与子公司合规穿透` |
| 只要层级／例外不要落地行 | `设计政策层级与例外批准` |
| 从零章程级办法正文 | `起草合规管理办法或章程级制度` |
| 只要框架图 | `设计合规管理体系框架` |
| 确为中央企业且主成果是 42 号令对照终稿 | `评估国企合规管理办法差距` |
| 跨境调查协调 | `协调跨境内部调查并分流涉外` |
| 劳动规章全文、解除或处分决定 | 劳动领域 |
| 境外当地劳动法结论 | 涉外领域 |
| 出口管制、制裁主轴 | 涉外领域 |
| 数据出境方案或个保专项体系 | 数据隐私领域 |
| 公司章程、股东会、股权或任免本身 | 公司治理领域 |
| 交易合同改稿 | 审查起草领域（本窗搁置，只说明） |

不得因「全球一致」或「要求按第 39 条写死」或「今天视为已生效」关窗。未审议仍正触发，不得写成已生效。民企硬套不得负触发到对照窗。

## 易混

集团模板盖章不是境内生效。总部印发不是独立法人子公司已审议。原则适用不是已落地。美国律师—客户特权不能直接写成中国法下的免交理由。培训签收不是劳动合同法第四条已完成。并表不是落地。列出子公司不是已覆盖。分公司服从总部不是子公司已生效。民企套 42 号令第三十九条：该格不支持，不关窗，不转出，不得建议上报国资委。FCPA 对标不是中国法义务。穿透四问不是本窗条款三态。「先补假审议再出已生效稿」整体停止。劳动规章全文和出境方案不在本窗。审查起诉只作背景，主成果才转刑事。
