# 评估方法

本文件是可执行判断节点。总部印发不是境内已生效。原则适用不是已落地。美国特权条款不能写成中国法免交理由。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、全球一致填满、唯一截止日、选定机关、代提交、未知写零。本任务不写境外当地法结论，不给出境方案，不写劳动规章全文。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1993 年公司法第三条、把 42 号令第三十九条或 FCPA 写成中国法义务、把总部印发写成境内已生效时记为噪声。禁止指导伪造审议或删除会计资料。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`LD#` 固定列：`编号｜模板条款定位／版本｜三态（保留／改写／删除）｜与中国大陆强制规则冲突点｜拟改写要点｜强制本地规则接口｜E#回链｜判断三值｜缺口G#｜最强反方｜待核`。禁止合成「原则适用已落地」一笔。`E#` 只作证据形态回链。缺项记 `G#`。无法判断则该条待核，不得默认保留。热冲突不得保留。

口头「全球适用」「总部已盖章」「群已读就是境内已生效」只进 `S#`／`V#`，**不得算作开闸材料**。已读、揽收不得升格 `R#`。`A#` 是承认，不是已落地。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

节点 0 只做三件事：专项整案转出、立场闸、不关窗。伪造审议、倒签生效、假对照表、指导删除、平行灭证、打击报复、双方秘密不进负表。

整案转出只交付第 1、2、10 节，不出 `LD#` 终稿。

审查起诉、监管检查只作程序背景。主成果才整案转。出现「集团政策」一词不是转出。

落地闸打开（可出 `LD#` 草案，仍不得标「已落地／已替代／已免责」）须同时满足：单方无冲突立场已闭合（集团与境内实体互斥）；主成果是对照表，不是穿透四问、不是出境方案、不是办法全文；存在书面落地授权；至少一份可编号模板版本和一家可编号境内实体。口头全球适用、总部盖章、已读揽收不算开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

落地闸部分打开：有可编号条款，但审议机关或强制规则未核验；对应格待核；仍交十节；不得标终稿 `已形成`。

落地闸关闭（仍正触发）：立场已闭合但无书面落地授权；无一可编号模板条款。「今天必须已替代集团原文」而无最小事实不得开闸。不出 `LD#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `LD#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「已经落地」或「没有冲突」。

「原则适用即已落地」「总部盖章即境内生效」「FCPA 当中国法」「美国特权免交」「禁止向当地机关举报」「无限制调取私人设备」「民企套第 39 条」「交对照表即从轻」「审议前已替代原文」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `LD#` 草案。开口径热冲突：该行删除或改写，不得仅标不支持后仍保留。

若 if 立场或委托无法闭合，then 整体停止。
若 if 境内立场已闭合但无书面落地授权，then 落地闸关闭，仍交十节，不是整体停止。
若 if 同时掌握集团与境内实体相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造境内审议、倒签生效、假对照表、指导删除会计资料、借落地稿平行灭证、打击报复或阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

境内主体：独立法人子公司与分公司分列。不自动合并。名称相似不自动合并。

检索锚点（写入 `L#` 前须核验）：

- 公司法第三条：公司是企业法人，有独立的法人财产。噪声：1993 年第三条。总部规章制度不能直接在独立法人子公司生效，须子公司有权机关批准。
- 公司法第十三条：子公司具有法人资格、依法独立承担民事责任；分公司不具有法人资格。
- 民法典第七十四条：分支机构民事责任由法人承担，与独立法人子公司分列。不得把分支服从总部写成子公司已落地。
- 公司法第二十三条人格否认不得写成集团政策即可刺破。
- 42 号令第三十九条、第四十条：只约束中央企业推动所属单位建立健全，不等于模板已对民企子公司生效。民企硬套：该格 `现有依据不支持`，对照行删除，不关窗。
- 个保法第六条、第十三条：HR 所必需不等于无限制调取私人设备或全球邮箱。
- 劳动合同法第四条：劳动规章民主程序只开接口，本窗不做完。
- 反法 2025 第八条：明示折扣入账不是贿赂。
- 行政处罚法第三十二条：提交对照表不等于情节成就。
- 不得把 FCPA／SOX 写成中国法义务；可作非强制对标并标明法域。

强制本地规则与非强制对标分列，不选对总部有利的一版。

## 节点 3　落地条款三态行 `LD#`

每条模板条款：保留／改写／删除。改写必须写明与中国大陆强制规则的冲突点。无法判断：该条待核，不得默认保留。禁止整份「原则适用」。

按已出现条款扫描，不是默认闭集。热冲突出现则删除或改写，不得标保留：内部调查可无限制调取个人设备；禁止向当地机关举报；以美国特权条款替代中国保密规则；以培训替代劳动程序；要求员工放弃法定权利。

劳动规章效力：本任务不写生效稿，只开协商或公示接口。个人信息处理规则整案：转数据，本窗只对该条款做删除／改写接口。

## 节点 4　生效、可逆性与转介

境内主体未审议、未公布：状态为对照清单，不得写集团政策已在境内生效，不得写已替代集团原文。已读、揽收不得打开已生效路径。

可逆动作与不可逆动作分列。不可逆（对外宣称已落地、以对照表代审议、代提交、无限制取证）不得在草案阶段实施。禁止提交指令。不代审议、不代提交。

下一步只转介：穿透评估、办法起草、政策层级、举报渠道、跨境调查、数据隐私。禁止一次写完全部邻窗终稿。禁止出 `U#` 四问终稿。

已有监察或检查 `R#`：不得借落地稿平行灭证。刑法第一百六十二条之一只作红旗，不得指导删除。
