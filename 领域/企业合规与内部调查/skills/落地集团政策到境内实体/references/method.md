# 评估方法

本文件是可执行判断节点。总部印发不是境内已生效。原则适用不是已落地。美国特权条款不能写成中国法免交理由。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、范本填满、唯一截止日、选定机关、代提交、未知写零。本任务不写境外当地法结论，不给出境传输方案，不写劳动规章全文，不代审议、不代公布。本窗 `LD#` 是落地条款行，不是穿透单元。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1993 公司法第三条、把 42 号令第三十九条或第一百七十七条套民企、把总部印发写成已生效、把 FCPA 写成中国法义务、把美国特权写成免交权时记为噪声。MCP 将 2025 修订《反不正当竞争法》标为尚未施行但公布施行日为 2025-10-15 的，以施行日为准；无法独立核验施行日则该规则字段停止。禁止指导伪造审议或删除会计资料。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`LD#` 固定列：`编号｜模板条款定位／V#｜三态（保留／改写／删除）｜与中国大陆强制规则的冲突点｜境内拟设要点｜指向岗位／有权机关｜E#回链｜判断三值｜缺口G#｜最强反方｜待核`。禁止合成「原则适用已落地」一笔。无法判断则该条待核，**不得默认保留**。热冲突不得保留。`E#` 只作证据形态回链。缺项记 `G#`，不得用「全球一致」填满。扫描不是闭集。

口头「全球适用」「总部已盖章」「群已读就是境内已生效」只进 `S#`／`V#`，**不得算作开闸材料**。已读、快递揽收不得升格 `R#` 已送达，不得升格已在境内生效。口头备份不等于已保全。`A#` 是承认，不是已落地。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

落地闸打开（可出 `LD#` 草案，仍不得标「已在境内生效／已替代集团原文／已免责」）须同时满足：单方无冲突的**境内实体**立场已闭合；主成果是集团／境外模板改成该实体可执行对照，不是穿透四问、出境方案或劳动规章全文；至少一条可编号模板条款或拟设落地行。从零：有模板碎片或拟设行即可开或半开，缺项记 `G#`，生效格待核。口头全球适用、已读揽收、总部盖章不算开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

落地闸部分打开：主体、审议机关或强制规则未核验，但已有可编号范围；或无书面落地授权但已有拟设行或模板碎片；对应格待核；仍交十节；不得标终稿 `已形成`。不得因无授权文件关掉拟设草案。

落地闸关闭（仍正触发）：无一可编号条款且无一拟设行。「今天必须出已在境内生效终稿」而无最小事实不得开闸。不出 `LD#` 终稿。**仍交十节**，第 5 节只交闸／`Q#` 状态，第 6 节不出 `LD#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「没有冲突」或「已经落地」。

「总部印发即对独立法人子公司生效」「整份原则适用」「美国特权可免交中国机关」「无限制调取个人设备当然合法」「禁止向当地机关举报可保留」「培训替代劳动合同法第四条」「要求员工放弃法定权利」「民企必须按 42 号令第三十九条落地上报」「FCPA 或萨班斯写成中国法义务」「群已读即已公布」「落地即免责或交表即从轻」「范本即已落地」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `LD#` 草案。闸未开才不出 `LD#` 终稿。热冲突条款不得仅标不支持后仍写入保留。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合、无书面落地授权但已有拟设行或模板碎片，then 落地闸部分打开，仍交十节，不是整体停止。
若 if 公司立场已闭合但无一拟设且无一碎片，then 落地闸关闭，仍交十节，不是整体停止。
若 if 同时掌握集团与境内实体或两家境内实体相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造境内审议或公布、倒签生效、假对照表、指导删除会计资料、借落地稿平行灭证、打击报复或阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

独立法人子公司／分公司／参股／民企／中央企业／是否上市分列。不自动合并。名称相似不自动合并。

检索锚点（写入 `L#` 前须核验）：

- 公司法第三条：公司是企业法人，有独立的法人财产。总部规章制度不能直接在独立法人子公司生效，须该法人有权机关审议。噪声：1993 年第三条。
- 公司法第十三条：子公司具有法人资格、依法独立承担民事责任；分公司不具有法人资格，民事责任由公司承担。
- 民法典第七十四条：分支机构以自己名义从事民事活动，民事责任由法人承担。分公司与独立法人子公司分列，不得把分公司「服从总部」套到子公司。
- 公司法第六十七条：董事会制定公司的基本管理制度，不等于集团印发已在本实体生效。
- 公司法第二十三条：人格否认是债权人保护例外，不得写成集团政策即可刺破，也不得写成未落地即母公司当然连带。
- 公司法第一百六十八条：国家出资公司不含参股。第一百七十七条仅国家出资公司对内合规，不套民企。
- 42 号令第三十九条：中央企业推动所属单位建立健全，只约束中央企业；推动 ≠ 本实体已生效。第四十条是对地方国资机构的参照指导。民企硬套：该格 `现有依据不支持`，强制对照行删除，不关窗。不得建议民企上报国务院国资委。
- 劳动合同法第四条：劳动纪律民主程序只开接口，本窗不做完协商公示证据。
- 个保法第六条最小范围、第十三条人力资源管理所必需，不等于全员邮箱、私人微信或定位当然授权。
- 行政处罚法第三十二条：提交对照表不等于情节成就。
- 监察法第十八条：如实提供，不得伪造、隐匿、毁灭。
- 不得把美国《反海外腐败法》或萨班斯程序写成中国法定义务；可作非强制对标并标明法域。

国企适用办法条款才写入强制项。强制接口与非强制对标分列。参股只能经股东权利建议，不得写成内部政策已对其生效。

## 节点 3　落地条款三态 `LD#`

按已出现模板条款扫描，不是默认闭集。每条：保留／改写／删除。改写必须写明与中国大陆强制规则的冲突点。无法判断：该条待核，不得默认保留。无版本、无条款编号不得排进可执行 `LD#`，记 `G#`。

热冲突强制三态（不得保留）：

- 无限制调取／镜像个人设备、私人微信、定位 → 删除或改写为最小必要，个保基础待核。
- 禁止向当地机关、纪检监察、公安、劳动监察举报 → **删除**。
- 美国律师—客户特权／work product 可免交中国机关 → 删除或改写为境内保密与配合检查分列，不得写成免交权。
- 要求员工放弃法定权利（仲裁／诉讼／举报／社保／休息等） → **删除**。
- 培训、签收、e-learning 替代劳动合同法第四条 → 删除或改写，只开劳动接口。
- FCPA／SOX 写成中国法定义务 → 改写为非强制对标并标法域。
- at-will、总部可直接处分子公司员工 → 删除或改写；处分主体是当地用人单位。
- 「原则适用／全球一套不得改」作为效力条款 → 删除或改写。

无 `E#` 不得写已覆盖或已生效。状态 `草案`。禁止整份「原则适用」。禁止先落地再改冲突。

## 节点 4　生效程序、可逆性与转介

境内有权机关审议前不得写已替代集团原文。构成劳动规章的条款：本窗不写生效稿，只标须协商／公示／职代会接口。数据出境、出口管制只开接口，不写传输方案、不评物项。

可逆动作与不可逆动作分列。不可逆（对员工公布发生劳动纪律效力、对外披露、处分、格式化旧档）不得在草案阶段实施。禁止提交指令。不代审议、不代公布、不代提交。

下一步只转介：穿透、办法、层级、框架、三道、对照（仅确为中央企业）、义务地图、跨境调查、律师工作产品、举报渠道、培训、劳动、数据、涉外。禁止一次写完全部邻窗终稿。

已有监察或检查 `R#`：不得借落地稿平行灭证。刑法第一百六十二条之一只作红旗，不得指导删除。
