# 评估方法

本文件是可执行判断节点。方案不是已经调查。访谈计划不是已实施访谈。先谈话后取证不是可靠方案。统一口径不是配合监察。无授权不是全员约谈。第十四条不是方案已执行。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、范本填满、唯一截止日、选定机关、代提交、未知写零。本任务不实施访谈，不违法取证，不出授权书终稿、收集日志、提纲笔录终稿或持有通知发送稿。本窗 `PL#` 是方案行，不是 `AZ#`，不是 `PT#`，不是取证日志。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、把第十四条写成方案已执行、把个保法第十三条写成全员约谈、把先谈话后取证写成可靠方案时记为噪声。禁止指导威胁诱供、入侵、删除会计资料。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`PL#` 固定列：`编号｜步骤类型／默认序位（持有→书证电子证→财务痕迹→外围证人→核心证人→被调查人→补证）｜拟设动作（只规划）｜拟访谈对象／角色（非实施）｜授权范围回链｜禁止动作｜证人保护接口｜机关并行／接触禁令｜E#回链｜判断三值｜缺口G#｜最强反方｜待核`。禁止合成「已执行闭环」。无 `E#` 不得写已覆盖、已访谈、已取证。状态 `草案`。扫描不是闭集。禁止 `AZ#` `AU#` `PT#` `CS#` `RF#` `F#` `ACT#` `Dsc#` `ST#` `IV#`。

口头「先去聊聊」「先把人叫来谈开」「群已读」只进 `S#`／`V#`，**不得算作开闸材料**。已读、揽收不得升格 `R#` 已送达或已约谈。纸面方案草稿不是已执行。`A#` 是承认，不是已访谈。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

## 节点 0　分流、立场、方案闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。伪造或倒签方案、威胁诱供、入侵、秘密违法录音、扣留证件、向证人透露他人陈述施压、指导删除、平行灭证、阻挠检查、双方秘密不进负表。

整案转出只交付第 1、2、10 节，不出 `PL#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是授权范围与独立终稿 | 负触发 `确定调查授权范围与独立` |
| 主成果是是否启动 | 负触发 `评估是否启动内部调查` |
| 主成果是取证实施或收集日志 | 负触发 `合法收集书证电子证与财务痕迹` |
| 主成果是访谈提纲与笔录结构终稿 | 负触发 `准备调查访谈提纲与笔录结构` |
| 主成果是发送版持有／禁毁 | 负触发 `准备证据保全与禁毁通知` |
| 主成果是证人保护终稿 | 负触发 `设计举报人保护与反报复措施` |
| 主成果是回避名单终稿 | 负触发 `处理利益冲突与调查回避` |
| 主成果是调查报告 | 负触发 `形成内部调查报告` |
| 主成果是全员监控或个保专项 | 整案转数据隐私 |
| 主成果是劳动处分、解除或性骚扰调查 | 整案转劳动 |
| 侦查、起诉、辩护为主成果 | 整案转刑事 |

审查起诉、监管检查只作程序背景。主成果才整案转。出现「方案」「访谈」一词不是转出。已刑事立案：企业方案不得以干扰侦查为目的；主成果是刑事程序则整案转刑事。

方案闸打开（可出 `PL#` 草案，仍不得标「已执行／已访谈／已查清」）须同时满足：单方无冲突的公司或其调查受托律师立场已闭合；主成果是步骤、顺序和证人保护接口；已决定要查；至少一条可编号拟设步骤或访谈顺序碎片。从零：有拟设即可开或半开，缺项记 `G#`。口头指示、已读不算开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

方案闸部分打开：无完整书面授权但已决定要查且有拟设步骤；或顺序、个保、并行机关未核验。对应格待核。仍交十节。不得标终稿 `已形成`。

方案闸关闭（仍正触发）：无一拟设步骤且无一对象碎片。「今天必须出已执行方案终稿」而无最小事实不得开闸。不出 `PL#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `PL#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「先谈话后取证即合法」「方案即已执行」「无授权也可全员约谈」「个保法第十三条即全员约谈」「第十四条即方案已执行」「统一口径即配合监察」「交方案即从轻」「口头聊聊即已授权」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `PL#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 公司已开口且委托就是方案、未掌握对方秘密，then 可推定公司或其调查受托律师立场。
若 if 被调查对象代理要出方案，then 立场无法闭合，整体停止。
若 if 公司立场已闭合、无完整授权但已有拟设步骤，then 方案闸部分打开，仍交十节，不是整体停止。
若 if 公司立场已闭合但无一拟设，then 方案闸关闭，仍交十节，不是整体停止。
若 if 提出伪造或倒签方案、威胁诱供、入侵、秘密违法录音、扣留证件、向证人透露他人陈述施压、指导删除、借方案平行灭证、阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

中央企业／地方国企／参股／民企分列。方案不得大于授权。无权主体：可依赖方案字段停止。

检索锚点（写入 `L#` 前须核验）：

- 公司法第六十七条：董事会职权不等于方案已执行。
- 公司法第一百六十八条、第一百七十七条：177 不套民企必须按方案上报。
- 42 号令第二条、第四十条：只约束中央企业。
- 42 号令第十四条：组织或参与调查不等于方案已执行。
- 个保法第六条、第十三条：人力资源管理所必需 ≠ 全员约谈、私人微信、定位、生物识别。
- 监察法（2024 修正）第十八条：如实提供，不得伪造、隐匿、毁灭。统一口径不是已配合。
- 刑法第一百六十二条之一、第三百零七条、第三百零八条只作红旗，不得指导删除或威胁证人。
- 民诉非法证据排除（条号运行时核验，通常为解释第一百零六条）只开接口，不写排除裁定。
- 行政处罚法第三十二条：交方案不等于从轻情节成就。

强制接口与非强制对标分列。

## 节点 3　方案行 `PL#`

按已出现步骤扫描，不是默认闭集。默认顺序不得改写成已执行：**持有通知 → 书证电子证 → 财务痕迹 → 外围证人 → 核心证人 → 被调查人 → 补证**。

用户要求先找被调查人「谈开」再取证：该顺序格 `现有依据不支持`，闸已开仍出其他步骤行。灭失风险只允许提前该名外围证人，仍须先持有，不得把被调查人提前到持有／书证／财务之前当合法路径。

热冲突不得保留：先谈被调查人作为可靠方案；统一口径干扰侦查；平行接触被禁证人；全员约谈／定位／生物识别；入侵、黑客、秘密违法录音、扣证强迫、向证人朗读他人陈述施压。作为方法提出则整体停止。

证人保护只开接口，不出 `PT#` 终稿，不得在日程中点名举报人。回避未处理：「可依赖访谈顺序」字段停止。汇报对象不得是被调查人。无 `E#` 不得写已覆盖。状态 `草案`。

## 节点 4　禁止事项、可逆性与转介

必须写入禁止动作接口：不得威胁证人、不得承诺免责换口供、不得单人闭门、不得入侵系统、不得秘密违法录音、不得扣留证件强迫配合、不得向证人透露他人陈述施压、不得销毁或选择性删除、不得限制人身自由、不得阻挠合法检查。用户要求写规避检查或串供方法：整体停止。

已有监察或检查 `R#`：方案限缩或暂停接触证人，不得借方案平行灭证。刑法第一百六十二条之一只作红旗，不得指导删除。

可逆与不可逆分列。不可逆（已约谈、已镜像全员、已发持有、限制人身自由）不得在草案阶段实施。禁止提交指令。不代约谈、不代签发、不代提交。不实施访谈。

下一步只转介：授权、启动闸、持有通知、合法收集、提纲笔录、保护、回避、案卷、工作产品。禁止一次写完全部邻窗终稿。第 7 节不得夹带 `PL#` 终稿绕闸。
