# 评估方法

本文件是可执行判断节点。方案不是已经调查。提纲不是已访谈。计划不是完成。先谈话后取证不是可靠方案。全员监控不是调查步骤。口头授权不是可实施访谈。授权稿不是已合法取证。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、范本填满、唯一截止日、选定机关、代提交、未知写零。本任务不实施访谈，不定罪，不代提交。本窗 `PL#` 是方案行，不是授权行 `AZ#`，不是保护行 `PT#`，不是取证日志，不是提纲笔录，不是发送版持有通知。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1993 年公司法第六十七条、把第一百七十七条或 42 号令套民企、把先谈话后取证写成可靠方案、把监察法第四十五条写成内部方案已生效、把讯问笔录范本写成内部方案法定格式时记为噪声。禁止指导伪造方案、违法取证、限制人身自由或删除会计资料。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`PL#` 固定列：`编号｜步骤类型｜对象或系统范围（主体×期间×交易或账户×系统）｜拟设顺序位｜灭失／优先级｜授权／个保边界回链｜邻窗接口｜禁止事项｜E#回链｜判断三值｜缺口G#｜最强反方｜待核`。禁止合成「已调查闭环」。无法判断则该条待核，**不得默认保留先谈话后取证或全员监控步骤**。`E#` 只作证据形态回链。缺项记 `G#`。扫描不是闭集。

默认顺序（持有通知 → 书证电子证收集 → 财务痕迹 → 外围证人 → 核心证人 → 被调查人 → 补证）是方法参考，**不是闭集**，不得因缺某一段关闸。实务上访谈一般安排在调查最后阶段，以避免提前披露导致证据灭失或不实陈述；这是方法参考，不是法定唯一顺序。

口头「你们去查」「先把人叫来谈开」「群已读」只进 `S#`／`V#`，**不得单独算作开闸材料**。已读、揽收不得升格 `R#` 已送达。纸面草稿不是已执行。`A#` 是承认，不是已调查。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

## 节点 0　分流、立场、方案闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。伪造或倒签方案、倒签步骤日、指导违法取证、入侵系统、购买黑客服务、秘密违法录音、扣留证件、向证人透露他人陈述施压、限制人身自由、指导删除、阻挠合法检查、双方秘密不进负表。

整案转出只交付第 1、2、10 节，不出 `PL#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是授权范围与独立终稿 | 负触发 `确定调查授权范围与独立` |
| 主成果是取证实施或收集日志终稿 | 负触发 `合法收集书证电子证与财务痕迹` |
| 主成果是访谈提纲与笔录结构终稿 | 负触发 `准备调查访谈提纲与笔录结构` |
| 主成果是证人保护 `PT#` 终稿 | 负触发 `设计举报人保护与反报复措施` |
| 主成果是发送版持有禁毁 | 负触发 `准备证据保全与禁毁通知` |
| 主成果是是否启动 | 负触发 `评估是否启动内部调查` |
| 主成果是回避名单终稿 | 负触发 `处理利益冲突与调查回避` |
| 主成果是调查报告或事实认定 | 负触发 `形成内部调查报告` |
| 主成果是全员监控或个保专项 | 整案转数据隐私 |
| 主成果是劳动处分、解除或性骚扰调查 | 整案转劳动 |
| 侦查、起诉、辩护为主成果 | 整案转刑事 |

审查起诉、监管检查只作程序背景。主成果才整案转。出现「方案」「访谈」「刑事」一词不是转出。已刑事立案：企业调查不得以干扰侦查为目的；主成果是刑事程序则整案转刑事；本窗访谈顺序对应格不支持统一口径干扰侦查。

方案闸打开（可出 `PL#` 草案，仍不得标「已调查／已访谈／已可取证」）须同时满足：单方无冲突公司立场已闭合；主成果是步骤、优先级与访谈顺序，不是授权终稿、取证实施或提纲终稿；至少一条可编号拟设步骤或访谈对象碎片。从零：有拟设或碎片即可开或半开，缺项记 `G#`。口头指示、已读不算单独开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

方案闸部分打开：授权主体职权、个保边界或并行程序未核验，但已有可编号步骤；或无书面授权但已有拟设步骤；对应格待核；仍交十节；不得标终稿 `已形成`。授权未闭合且主成果仍是方案：半开，转介授权窗，**不负触发**。

方案闸关闭（仍正触发）：无一可编号拟设且无一对象碎片。「今天必须出已执行方案终稿」而无最小事实不得开闸。不出 `PL#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `PL#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「先谈话后取证即可靠方案」「方案即已经调查」「提纲即已访谈」「全员监控即步骤」「口头授权即可实施访谈」「授权稿即已合法取证」「统一口径即配合监察」「42 号令第十四条即方案已执行」「监察法第四十五条即内部方案已生效」「民企必须按 177／42 号令按方案上报」「交方案即从轻」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `PL#` 草案。先谈话后取证行**不得写入可执行 `PL#`**。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合、无书面授权但已有拟设步骤或对象碎片，then 方案闸部分打开，仍交十节，不是整体停止。
若 if 公司立场已闭合但无一拟设且无一碎片，then 方案闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造或倒签方案、倒签步骤日、指导违法取证、入侵系统、购买黑客服务、秘密违法录音、扣留证件强迫配合、向证人透露他人陈述以施压、限制人身自由、指导删除会计资料、借方案稿平行灭证、打击报复或阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体、授权接口与强制接口

中央企业／地方国企／参股／民企分列。授权来源分列：董事会、审计委员会、法定代表人、合规负责人、章程授权。无权主体：授权字段停止；有拟设步骤则方案闸半开，不可逆步骤不得实施。

检索锚点（写入 `L#` 前须核验）：

- 公司法（2023 修订）第六十七条：董事会决定内部管理机构设置、制定基本管理制度，不等于已签发调查授权、已可实施访谈。噪声：1993 年第六十七条。
- 公司法第一百六十八条、第一百七十七条：177 不套民企必须按内部方案上报。
- 42 号令第二条、第四十条：只约束中央企业；地方国资参照不是民企对国资委义务。
- 42 号令第十四条：合规管理部门组织或参与调查，不等于方案即已调查。
- 个保法第六条、第十三条：人力资源管理所必需 ≠ 全员邮箱、私人微信、定位、生物识别当调查步骤。
- 监察法（2024 修正）第十八条：不得伪造、隐匿、毁灭。第四十三条非法方式取证禁令约束监察机关，只作企业内部禁止动作对标，不是内部授权依据。第四十五条严格执行调查方案约束监察机关，不是民企内部方案已生效。
- 刑法第一百六十二条之一、第三百零七条、第三百零八条只作红旗。

强制接口与非强制对标分列。非法取证排除效果只作红旗，本窗不写排除裁定。

## 节点 3　方案行 `PL#`

按已出现步骤与对象扫描，不是默认闭集。范围用主体 × 期间 × 交易或账户 × 系统闭合。用户要求「先把被调查人请来谈开再调邮箱和账」：该顺序不得写入可执行 `PL#`，该格 `现有依据不支持`，仍可出持有／书证／财务／外围证人等其他草案行。用户要求「顺便查所有邮箱、定位全员」：超出部分该格不支持，不得写入可执行步骤。

建议行型（按已出现事实选用，**不是默认闭集**）：

| 编号 | 含义 | 本窗允许 | 禁止 |
| --- | --- | --- | --- |
| `PL-持` | 持有／禁毁步骤位 | 只标顺序与优先级 | 不出发送稿 `N#` |
| `PL-书`／`PL-电` | 书证／电子证步骤位 | 范围与权限接口 | 不出收集日志终稿 |
| `PL-财` | 财务痕迹步骤位 | 同上 | 同上 |
| `PL-外`／`PL-核`／`PL-被` | 外围／核心／被调查人访谈位 | 目的、告知要点、是否需保护／回避**接口** | 不出提纲／笔录结构终稿；不实施访谈 |
| `PL-补` | 补证步骤位 | 条件待核 | 不得写成已完成 |

热冲突强制处理（不得保留为可执行行）：

- 先找被调查人谈开再取证 → 该顺序不支持；仍出其他 `PL#`。
- 与线索无关的全员监控、私人设备镜像、定位、生物识别 → 删除或该格不支持。
- 向证人透露他人陈述以施压、分别询问被合并为对质会 → 禁止事项；作为方法提出则整体停止。
- 限制人身自由、扣留工牌证件不得离场 → 禁止事项强制写入；作为方法提出则整体停止。
- 入侵系统、购买黑客服务、秘密违法录音 → 作为方法提出则整体停止。
- 承诺免责换口供、威胁证人、向被调查人通风、选择性删除 → 禁止事项；作为方法提出则整体停止。
- 干扰侦查或对抗合法检查的统一口径 → 该格不支持；指导阻挠则整体停止。

未处理回避：方案可列步骤位，但「可依赖访谈对象」字段停止，转介回避原子。汇报对象不得是被调查人。证人保护只开接口，本窗不出 `PT#` 终稿。

无 `E#` 不得写已覆盖、已调查或已访谈。状态 `草案`。实务「至少两名调查人员」「告知权利」「分别询问」写入方法参考，不得写成已实施。

## 节点 4　禁止动作、邻窗接口、可逆性与转介

必须写入禁止事项接口：不得威胁证人、不得承诺免责换口供、不得入侵系统、不得购买黑客服务、不得秘密违法录音、不得扣留证件强迫配合、不得向证人透露他人陈述以施压、不得限制人身自由、不得销毁或选择性删除、不得向被调查人通风。用户要求写规避检查：整体停止。

证人保护只开 `PT#` 接口，转 `设计举报人保护与反报复措施`。具体取证日志转 `合法收集书证电子证与财务痕迹`。具体提纲与笔录结构转 `准备调查访谈提纲与笔录结构`。发送版持有通知转 `准备证据保全与禁毁通知`。授权未闭合只开授权接口，不负触发，除非主成果是授权终稿。

可逆与不可逆分列。不可逆（对外发送访谈通知、开始镜像全员邮箱、限制人身自由、格式化旧档）不得在草案阶段实施。禁止提交指令。不代签发、不代提交。不实施访谈。

下一步只转介：授权、回避、取证、提纲、保护、持有通知、启动闸（仅当启动未闭合）、工作产品。禁止一次写完全部邻窗终稿。

已有监察或检查 `R#`：不得借方案稿平行灭证。刑法第一百六十二条之一只作红旗，不得指导删除。刑事已立案：访谈计划不得以统一口径干扰侦查。
