# 边界与路由

## 正触发

已经决定调查，需要把步骤优先级、访谈顺序和禁止动作写成可执行要点，而不是立刻问话、取证或出报告。从零、步骤碎片、无书面授权仍正触发：有拟设步骤或对象碎片则闸开或半开，出 `PL#` 草案。先谈话后取证即可靠、方案即已经调查、提纲即已访谈、全员监控即步骤、口头授权即可实施访谈，仍正触发。

双方秘密、伪造或倒签方案、倒签步骤日、指导违法取证、入侵系统、购买黑客服务、秘密违法录音、扣留证件强迫配合、向证人透露他人陈述以施压、限制人身自由、指导删除、阻挠合法检查的停止，优先于负触发。上述信号不在下表。「先谈话后取证即可靠方案」「方案即已经调查」「提纲即已访谈」「全员监控即步骤」「口头授权即可实施访谈」「授权稿即已合法取证」「监察法第四十五条即内部方案已生效」「民企套 177／42」不在下表。「不实施访谈」「不违法取证」「不强迫自证其罪口径」是交付禁令，不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 授权范围与独立终稿 | `确定调查授权范围与独立` |
| 取证实施或收集日志终稿 | `合法收集书证电子证与财务痕迹` |
| 访谈提纲与笔录结构终稿 | `准备调查访谈提纲与笔录结构` |
| 证人保护 `PT#` 终稿 | `设计举报人保护与反报复措施` |
| 发送版持有禁毁通知 | `准备证据保全与禁毁通知` |
| 是否启动尚未决定 | `评估是否启动内部调查` |
| 回避名单终稿 | `处理利益冲突与调查回避` |
| 调查报告或事实认定终稿 | `形成内部调查报告` |
| 全员监控或个保／数据专项体系 | 数据隐私领域 |
| 劳动处分、解除或职场性骚扰调查 | 劳动领域 |
| 交易合同改稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不实施访谈」或「不违法取证」关窗。先谈话后取证、全员监控主张该格不支持，窗口不关。授权未闭合且主成果仍是方案：方案闸半开，只开授权接口，不负触发授权窗。民企硬套不得负触发到对照窗。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、解除、工伤、职场性骚扰主轴 | 劳动领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |
| 垄断、滥用支配、经营者集中 | 竞争法领域 |

综合内部调查方案主轴可留本任务。审查起诉或检查只作背景，主成果才转。出现「方案」「访谈」「刑事」一词不是转出。已刑事立案且主成果是刑事程序：整案转刑事。已刑事立案但主成果仍是内部步骤：留窗；统一口径干扰侦查该格不支持。

## 易混

方案不是已经调查。提纲不是已访谈。计划不是完成。先谈话后取证通常污染范围，该顺序作为可靠方案现有依据不支持，窗口不关。全员监控不是调查步骤。人力资源管理所必需不是全员邮箱、私人微信或定位。口头「你们去查」不是可实施访谈。授权稿不是已合法取证。公司法第六十七条董事会职权不是已签发调查授权。公司法第一百七十七条不是民企必须按方案上报。42 号令第十四条组织或参与调查不是方案即已调查。监察法第四十五条严格执行调查方案约束监察机关，不是内部方案已生效。调查笔录或讯问核查函栏目不是内部方案法定格式。证人保护只开接口，本窗不出 `PT#` 终稿。不实施访谈、不违法取证是交付禁令，不是负触发。
