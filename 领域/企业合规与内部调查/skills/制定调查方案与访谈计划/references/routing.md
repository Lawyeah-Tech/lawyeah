# 边界与路由

## 正触发

已经决定调查，需要把步骤优先级、访谈顺序和禁止动作写成可执行要点，而不是立刻问话、取证或出报告。从零、步骤碎片、无完整授权仍正触发：有拟设则闸开或半开，出 `PL#` 草案。先谈话后取证即合法、方案即已执行、无授权可全员约谈、统一口径即配合监察、第十四条即已执行，仍正触发。

双方秘密、伪造或倒签方案、威胁诱供、入侵、秘密违法录音、扣留证件、向证人透露他人陈述施压、指导删除、阻挠检查的停止，优先于负触发。上述信号不在下表。「先谈话后取证即合法」「方案即已执行」「无授权可全员约谈」「个保 13 即全员约谈」「第十四条即已执行」「统一口径即配合监察」「交方案即从轻」不在下表。「不实施访谈」「不违法取证」「不保证免责」是交付禁令，不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 授权范围与独立终稿 | `确定调查授权范围与独立` |
| 是否启动尚未决定 | `评估是否启动内部调查` |
| 取证实施或收集日志 | `合法收集书证电子证与财务痕迹` |
| 访谈提纲与笔录结构终稿 | `准备调查访谈提纲与笔录结构` |
| 发送版持有禁毁通知 | `准备证据保全与禁毁通知` |
| 证人保护终稿 | `设计举报人保护与反报复措施` |
| 回避名单终稿 | `处理利益冲突与调查回避` |
| 调查报告或事实认定 | `形成内部调查报告` |
| 全员监控或个保／数据专项体系 | 数据隐私领域 |
| 劳动处分、解除或职场性骚扰调查 | 劳动领域 |
| 交易合同改稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不实施访谈」或「不违法取证」关窗。先谈话后取证主张该格不支持，窗口不关。民企硬套不得负触发到对照窗。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、解除、工伤、职场性骚扰主轴 | 劳动领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |
| 垄断、滥用支配、经营者集中 | 竞争法领域 |

综合内部调查方案主轴可留本任务。审查起诉或检查只作背景，主成果才转。出现「方案」「访谈」一词不是转出。已刑事立案且主成果是刑事程序：整案转刑事。

## 易混

方案不是已经调查。访谈计划不是已实施访谈。先谈话后取证通常污染范围，不是可靠方案。默认顺序是持有→书证→财务→外围证人→核心证人→被调查人→补证。无授权不是全员约谈。个保法第十三条不是全员约谈授权。42 号令第十四条不是方案已执行。统一口径不是配合监察。口头「先去聊聊」不是开闸。群已读不是已约谈。交方案不是从轻。不实施访谈、不违法取证是交付禁令，不是负触发。
