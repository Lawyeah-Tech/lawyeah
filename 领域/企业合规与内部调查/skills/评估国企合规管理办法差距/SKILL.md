# 评估国企合规管理办法差距

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例检索。本窗是评估类对照，**不要**用文书范本检索生成「已达标／已报国资委」清单。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现主体错配和报告路径混写；案例只比较事实差异与翻转条件，不写成必然结果。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《民法通则》《民法总则》或其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成 42 号令差距草案：对照闸、主体与监管层级、`Q#` 路径、`B#` 条款对照、第二十二条报告分列、治理／举报／整改接口。不代替普通整改方案、有效性评价或检察合规验收。不保证监管认可或合规免责。不代提交。不建议民企向国务院国资委上报。

`depends-on` 为空。董监高履职缺口终稿转 `评估董监高合规职责缺口`。有效性五维转 `评估合规管理体系有效性`。普通整改动作表转 `准备合规整改方案`。检察合规转 `准备涉案企业合规整改与验收`。义务地图转 `建立合规义务与责任主体地图`。总图转 `评估企业合规风险总图`。集团穿透转 `评估集团与子公司合规穿透`。金融机构行业办法转金融领域。

## 工作边界

正触发：主体是中央企业，或地方国企需对照 42 号令及地方参照文件做差距。主体待核、地方细则未核验、条款未检索仍正触发：对照闸关闭，不出 `B#` 终稿，窗口不关。用户是民企却要按 42 号令全表达标并上报国务院国资委、把参股写成国家出资公司、把第二十二条第一款写成已向国资委报告、保证监管认可或合规免责、今天必须交对照终稿，仍正触发：对应格填 `现有依据不支持` 或字段停止，对照行对民企删除，闸未开则不出对照终稿，窗口不关。不得因「民企硬套」改走负触发关窗。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是民企内部对标、且不主张 42 号令法定义务（转 `评估合规管理体系有效性` 或 `建立合规义务与责任主体地图`）；
- 主成果是董监高履职缺口终稿（转 `评估董监高合规职责缺口`）；
- 主成果是普通整改动作表（转 `准备合规整改方案`）；
- 主成果是检察合规验收（转 `准备涉案企业合规整改与验收`）；
- 主成果是企业级风险总图（转 `评估企业合规风险总图`）；
- 主成果是集团穿透终稿（转 `评估集团与子公司合规穿透`）；
- 主成果是三道防线配置（转 `配置合规机构与三道防线`）；
- 主成果是正式有效性评价项目（转 `开展合规有效性评价` 或 `评估合规管理体系有效性`）；
- 主成果是金融机构行业合规办法（转金融领域）。

双方秘密、伪造对照表、伪造上报记录、倒签评价、打击报复举报人、指导删除会计资料**不在负触发表**，走整体停止。「民企必须按 42 号令上报」「第一款写成向国资委报告」「保证监管认可」**不在负触发表**，只关对应格，窗口不关。

## 建立工作坐标

确认：对照授权；单方立场；主体（中央企业／地方国企／参股／民企）；国资监管层级；现行内部办法与地方实施细则；党委前置与董事会授权；已知重大事件或监管函。

口头「已按 42 号令达标」「领导小组已成立」只登记 `S#`／`V#`。不得升格已对照完成、监管已认可或已向国资委报告，**不得算作开闸所需的治理安排**。已读、微信已读、电话、口头尽快、快递揽收只进 `S#`／`V#`，不得升格 `R#` 已送达或已向国资委报告，不得起算法定报告日。口头备份不等于已保全。征求意见稿「7 个工作日」不是已核验 `L#`。

同时掌握公司与被调查对象相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。公司已开口且委托就是办法差距、且未掌握对方秘密时，可推定公司立场。无书面对照授权但公司立场已闭合：对照闸关闭，仍交十节，不是整体停止。提出伪造对照表、伪造上报记录、倒签评价、打击报复或指导删除会计资料：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 内部制度或地方细则；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`B#` 对照行；`V#` 版本；`E#` 证据形态回链（任命、纪要、送达、运行记录，不是发送闸）。禁止 `N#`、`EV#`、`M#`、`F#`、`ACT#`、`P#`、`K#`、`O#`、`H#`。技能正文中的条号是检索锚点，不是已核验 `L#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止合成「国企都要」一笔。未知不写零。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：中央企业合规管理办法（国资委令第 42 号，自 2022-10-01 施行）。第二条约束国资委履行出资人职责的中央企业，不得写成全部国企或民企同一法定义务。第八条（三）董事会推动完善合规管理体系并对其有效性进行评价；第十四条（三）合规管理部门根据董事会授权开展有效性评价；第二十七条中央企业定期开展有效性评价——三条是**评价条款**，不是第二十三条整改机制。第二十三条中央企业应当建立违规问题整改机制，对民企只作方法参考。第九条经理层只约束中央企业。第十二条设立首席合规官，不新增领导岗位和职数，由总法律顾问兼任。第二十二条第一款向**本企业合规管理部门**报告；第二款重大事件内部应对；第三款中央企业重大合规风险事件向**国资委**报告。禁止用内部报告填国资委空格。征求意见稿「7 个工作日」不是已核验报告期限。第二十四条设立举报平台、保密、不得打击报复。第四十条是对**地方国资机构**的参照指导，不是地方国企或民企对国务院国资委的报告／评价义务；地方是否参照＝地方细则待核。公司法第一百六十八条国家出资公司不含参股；第一百七十七条仅约束国家出资公司对内合规，不是向国资委交稿。行政处罚法第三十二条条件成立时应当从轻或减轻，提交对照表本身不等于情节成就。监察法第十八条如实提供，不得伪造、隐匿、毁灭。噪声：已失效《合同法》、2018 年《中央企业合规管理指引（试行）》评估／报告条款当现行 42 号令、42 号令套民企、第一款当第三款、内部报告即已报国资委、对照完成即监管认可、第八条（三）／第十四条（三）／第二十七条写成第二十三条整改、第十二条写成必须新增副总级岗位、第 23 条套民企法定义务。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变适用范围、报告对象或地方参照的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补民企被写成必须报国务院国资委、内部报告与对出资人报告混写、领导小组没有记录仍标已达标的反例。
- `search_case_by_fact` 只比较事实差异与翻转条件（如地方国资委不是间接参股企业的直接出资人），不写成必然已达标、必然免责或必须上报。

工具不可用时继续主体、监管层级和 `B#` 编目；适用范围、报告对象、期限字段停止。不得拒跑，不得凭记忆写成民企必须适用 42 号令或已向国资委报告。

## 判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、对照闸与不关窗

主成果才整案转出。伪造对照第一次停。民企硬套、第一款写成向国资委报告、保证监管认可不关窗：该格不支持，闸已开仍出其他 `B#`。闸关仍交十节，第 6 节不出 `B#` 终稿。第八条（三）／第十四条（三）／第二十七条不是第二十三条。

### 2. 主体、监管层级与适用结论

中央企业／地方国企／参股／民企分列。主体不适用则对照行删除，不倒推民企违法。

### 3. 对照闸与路径 `Q#`

本节禁止出 `B#` 终稿。无一制度且无一书面治理安排则闸可关，窗口不关。口头领导小组不得开闸。民企硬套：42 号令法定义务行删除，该格不支持，不关窗。

### 4. 条款对照 `B#`

组织、职责、制度、举报、调查、评价、考核、报告分列。未核验条款字段停止。地方细则与国家办法冲突两行并列。

### 5. 第二十二条分列、治理接口与转介

第一款内部报告与第三款向国资委报告分列。董监高、有效性、整改、举报只开接口。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造对照表、伪造上报记录、倒签评价、打击报复举报人、指导删除会计资料或借已有监察／检查文书平行灭证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无书面对照授权但公司立场已闭合：不是整体停止，对照闸关闭，仍交十节。
- `字段停止`：第二条适用范围、地方细则、重大事件阈值、报告对象未核验。民企硬套、第一款写成向国资委报告、保证监管认可、第 23 条套民企、第八条（三）写成整改已完成：该格 `现有依据不支持`，窗口不关；闸已开仍出其他 `B#` 草案；闸未开才不出 `B#` 终稿。
- `目标停止`：主目标变为普通整改终稿、有效性终稿、检察验收、义务地图或董监高缺口终稿。

禁止指导伪造对照或删除会计资料。不给胜诉率。不定罪。不保证监管认可。不选定机关。不代提交。未知不写零。不建议民企向国务院国资委上报。
