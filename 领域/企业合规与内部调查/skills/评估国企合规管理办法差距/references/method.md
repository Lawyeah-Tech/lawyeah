# 评估方法

本文件是可执行判断节点。民企硬套 42 号令不关窗。第二十二条第一款不是向国资委报告。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、监管已认可、唯一截止日、选定机关、代提交、未知写零。本任务不定罪，不写任免，不建议民企向国务院国资委上报。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、把 42 号令套全部民企、把第二十二条第一款写成向国资委报告时记为噪声。第二条适用范围须运行时核验，不得把检索摘要写成已核验 `L#`。禁止指导伪造对照或删除会计资料。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`B#` 固定列：`编号｜条款簇｜办法要求（待核）｜主体是否适用｜现行安排｜证据｜判断三值｜最强反方｜待核｜转介`。禁止合成「国企都要」一笔。禁止 `N#`／`E#`／`EV#`／`M#`／`F#`／`ACT#`／`P#`／`K#`／`O#`／`H#`。

口头「已达标」「领导小组已成立」只进 `S#`／`V#`。已读、快递揽收不得升格已向国资委报告。拟制日＝本次形成本任务成果之日。

## 节点 0　分流、立场、对照闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。伪造对照、双方秘密、打击报复不进负表。

整案转出只交付第 1、2、10 节，不出 `B#` 终稿。

| 信号 | 处理 |

| 主成果是董监高履职缺口终稿 | 负触发 `评估董监高合规职责缺口` |

审查起诉、监管检查只作程序背景。主成果才整案转。民企主张必须适用 42 号令：**不负触发**，走不关窗。

对照闸打开（可出 `B#` 草案，仍不得标「已达标／已报国资委／监管认可」）须同时满足：单方无冲突立场与对照授权；主成果是 42 号令差距，不是有效性、整改、检察验收或义务地图终稿；主体为中央企业，或地方国企且已有参照文件可编号；至少一项可编号制度或治理安排；无双方秘密、无第一次伪造对照／上报信号。

对照闸部分打开：主体或地方细则未闭合，但已有可编号央企／国企身份或内部办法；对应格待核；仍交十节；不得标终稿 `已形成`。

对照闸关闭（仍正触发）：主体是民企或参股却要出对照终稿；无一制度且无一治理安排。「今天必须交对照终稿」而无最小事实不得开闸。不出 `B#` 终稿。**仍交十节**，第 5 节只交闸／`Q#` 状态，第 6 节不出 `B#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「已全部达标」或「民企必须上报」。

「民企必须按 42 号令全表达标并上报国务院国资委」「参股＝国家出资公司」「第二十二条第一款＝已向国资委报告」「地方国企自动承受中央企业同一法定义务」「第二十三条套民企法定义务」「保证监管认可或合规免责」「今天必须交对照终稿」「提交对照表即应当从轻」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸未开仍不出 `B#` 终稿。

若 if 立场或授权无法闭合，then 整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造对照表、伪造上报记录、倒签评价、打击报复举报人、指导删除会计资料或借已有监察／检查文书平行灭证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体、监管层级与适用结论

名称、统一社会信用代码、并表范围、出资人身份不一致：不自动合并。

检索锚点（写入 `L#` 前须核验）：

- 42 号令第二条（条号运行时核验）：适用于国资委履行出资人职责的中央企业，不得写成全部国企或民企同一法定义务。
- 第四条：国资委指导、监督中央企业合规管理工作。
- 第八条董事会、第九条经理层、第十四条合规管理部门：只约束中央企业。董监高缺口终稿转 `评估董监高合规职责缺口`。
- 第二十二条：第一款向本企业合规管理部门报告；第二款重大事件内部应对（首席合规官牵头）；第三款中央企业重大合规风险事件向国资委报告。三款分列，禁止混写。
- 第二十三条：中央企业建立违规问题整改机制。民企只作方法参考。动作表转 `准备合规整改方案`。
- 第二十四条：举报平台、调查处理、保密、不得打击报复。举报渠道终稿转 `建设内部举报渠道与受理规则`。
- 第二十七条：中央企业定期开展有效性评价。本窗只开接口，不吞并 `评估合规管理体系有效性`。
- 第四十条：地方国资机构参照本办法指导所出资企业。地方细则待核。不是民企对国务院国资委义务。
- 公司法第一百六十八条：国家出资公司不含参股。第一百七十七条仅国家出资公司对内合规。

民营企业或参股：对照行删除，该格 `现有依据不支持`，不得建议比照向国务院国资委上报。地方国企：须有参照文件或地方细则才打开对应行，未核验则字段停止，不得写成与中央企业同一法定义务。

## 节点 3　条款对照 `B#`

按组织、职责、制度、风险识别、举报、调查、评价、考核、报告建行。每行必须有主体是否适用。主体不适用：删除或 `现有依据不支持`，不得留「建议比照执行」冒充法定义务。

地方实施细则与国家办法冲突：两行并列，不选对用户有利的一版。未核验条款：法律效果字段停止，仍可列现行内部安排并标 `C#`。

只有「已成立领导小组」没有议事规则和记录：该职责 `依据不足`。口头达标不得写成已对照完成。

第二十七条只标评价条款是否有安排，不得输出五维有效结论。第二十三条只标整改机制是否有，不得输出 `ACT#` 动作终稿。

## 节点 4　第二十二条分列、接口与转介

报告路径必须分列：

- 向本企业合规管理部门报告（第一款）
- 重大事件内部应对（第二款）
- 中央企业向国资委报告（第三款）

阈值规则未核验或事件定性不足：报告义务字段停止，不写「建议比照上报」。已有监察或公安：只留移交红旗，不写刑事控告。已读、快递发出不得升格国资委已收到。

已有监察或检查 `R#`：不得借对照完成平行灭证。刑法第一百六十二条之一只作红旗，不得指导删除。第二十四条打击报复：第一次整体停止。

下一步只转介邻居。禁止提交指令、此致国资委。
