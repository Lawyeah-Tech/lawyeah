# 边界与路由

## 正触发

中央企业，或地方国企需对照 42 号令及地方参照文件做差距。主体待核、细则未核验仍正触发：对照闸关闭，不出 `B#` 终稿，窗口不关。民企硬套 42 号令、把第一款写成向国资委报告、保证监管认可，仍正触发。

双方秘密、伪造对照、伪造上报、倒签评价、打击报复、指导删除会计资料的停止，优先于负触发。上述信号不在下表。「民企必须按 42 号令上报」「第一款写成向国资委报告」「保证监管认可」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 民企内部对标，且不主张 42 号令法定义务 | `评估合规管理体系有效性` 或 `建立合规义务与责任主体地图` |
| 董监高履职缺口终稿 | `评估董监高合规职责缺口` |
| 普通整改动作表 | `准备合规整改方案` |
| 检察合规验收 | `准备涉案企业合规整改与验收` |
| 企业级风险总图 | `评估企业合规风险总图` |
| 集团穿透终稿 | `评估集团与子公司合规穿透` |
| 三道防线岗位配置 | `配置合规机构与三道防线` |
| 正式有效性评价项目 | `评估合规管理体系有效性` |
| 金融机构行业合规办法 | 金融领域 |
| 刑事辩护、控告 | 刑事领域 |
| 劳动处分决定 | 劳动领域 |

不得因「民企硬套」或「要求监管认可」关窗。民企主张必须适用 42 号令：留本窗不关窗，对照行删除。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、解除、工伤主轴 | 劳动领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |
| 垄断、滥用支配、经营者集中 | 竞争法领域 |
| 税务稽查实体 | 税务领域 |
| 银行保险机构行业合规办法 | 金融领域 |
| 章程、股权、任免本身为主成果 | 公司治理领域 |

综合合规治理主轴可留本任务。审查起诉或检查只作背景，主成果才转。

## 易混

国企办法差距不是调查结论，也不是对民企的强制清单。向本企业合规管理部门报告不是已向国资委报告。领导小组不是已达标。第二十七条不是有效性终稿。第二十三条不是普通整改动作表。地方国企不自动等于中央企业。「先补假上报记录」整体停止。
