# 边界与路由

## 正触发

举报或配合调查之后出现或即将发出不利人事／合同动作，需要评估报复迹象并给出暂停建议，而不是出解除决定、保护方案或原案结论。时序、知情未核验仍正触发：有可编号不利动作件则闸开或半开，出 `RF#` 草案。不利动作即当然报复、有绩效即没有报复、劳动法第一百零一条套全部内部举报、会计法第四十三条当然复职、民企套第 24 条、迹象即已构罪，仍正触发。

双方秘密、伪造或倒签绩效、指导继续报复、指导删除、指导追踪匿名、平行灭证的停止，优先于负触发。上述信号不在下表。「不利动作即当然报复」「有绩效即没有报复」「劳动法第一百零一条套全部内部举报」「会计法第四十三条当然复职」「民企套第 24 条」「迹象即已构成报复／已构罪」「交表即从轻」不在下表。「不写解除决定」「不认定原案属实」「不定罪」是交付禁令，不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 保护方案或监测点终稿 | `设计举报人保护与反报复措施` |
| 单件可查性或原举报是否属实 | `评估单件举报可查性` |
| 完整启动闸 | `评估是否启动内部调查` |
| 事实认定或调查报告 | `形成内部调查报告` |
| 劳动解除、处分决定、仲裁申请或无举报／配合钩子的纯用工动作 | 劳动领域 |
| 职场性骚扰或日常违纪调查终稿 | 劳动领域（可留报复接口） |
| 建渠道、没有不利动作件 | `建设内部举报渠道与受理规则` |
| 回避决定终稿 | `处理利益冲突与调查回避` |
| 刑事辩护、控告、自首 | 刑事领域 |

不得因「不写解除决定」或「要求按第 24 条上报」关窗。拟设仍正触发，不得写成已构成报复。民企硬套不得负触发到对照窗。已形成劳动争议时迹象评估可继续，程序文书转劳动。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、解除、工伤、职场性骚扰主轴且迹象评估不是主成果 | 劳动领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |
| 垄断、滥用支配、经营者集中 | 竞争法领域 |
| 税务处理决定、稽查实体 | 税务领域 |

综合合规报复迹象主轴可留本任务。审查起诉或检查只作背景，主成果才转。出现「报复」一词不是转出。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 保护方案终稿 | `设计举报人保护与反报复措施` |
| 这封信能否初核、原案是否属实 | `评估单件举报可查性` |
| 谁查、查到哪、预算 | `评估是否启动内部调查` |
| 调查授权书 | `确定调查授权范围与独立` |
| 回避名单终稿 | `处理利益冲突与调查回避` |
| 要逐项属实认定 | `形成内部调查报告` |
| 调岗／解除合法性做完、仲裁文书 | 劳动领域 |

## 易混

迹象不是已构成报复。不利人事或合同动作不是当然报复。事先启动且可回链的绩效考核是最强反方，有绩效记录不等于没有报复。事后补做绩效不得覆盖原始时序。暂停建议不是已暂停。调岗不是当然报复，也不是当然保护。不续签不是当然违法解除。被指向人知情不是公司知情。群已读不是已送达，送达不是已实施。劳动法第一百零一条不是全部内部廉洁举报的一般法定义务。会计法第五条／第四十三条只约束对会计人员的报复，不是全体举报人当然恢复原职。刑法第二百五十四条不套民企 HR。民企套 42 号令第二十四条：该格不支持，不关窗，不转出，不得建议上报国资委。时间接近不得单独写成支持报复迹象。指导继续报复第一次整体停止。保护方案、可查性、启动闸、解除决定不在本窗。
