# 边界与路由

## 正触发

举报或配合调查之后出现不利人事或合同动作，需要评估报复迹象并给出暂停接口，而不是写解除决定、认定原案属实或设计保护方案。从零、动作碎片、无书面评估授权仍正触发：有拟设或动作碎片则闸开或半开，出 `RT#` 草案。绩效即无报复、组织调整洗白、事后补绩效覆盖时序、要求本窗写解除决定，仍正触发。举报后解除／调岗作为迹象评估主轴时留本窗，不得因夹带解除整案转劳动。

双方秘密、伪造绩效、倒签解除、假事先程序、指导删除、继续实施报复、阻挠合法检查的停止，优先于负触发。上述信号不在下表。「绩效即无报复」「组织调整当然洗白」「事后补绩效覆盖时序」「已读即送达」「匿名即诬告可处分」「民企必须认定报复」不在下表。「不写解除决定」「不认定原案属实」「不保证免责」是交付禁令，不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 保护方案终稿 | `设计举报人保护与反报复措施` |
| 单件可查性或原举报是否属实 | `评估单件举报可查性` |
| 完整启动闸 | `评估是否启动内部调查` |
| 劳动解除、处分决定书或劳动程序文书本身 | 劳动领域 |
| 建渠道且没有不利动作 | `建设内部举报渠道与受理规则` |
| 确为中央企业且 42 号令对照终稿 | `评估国企合规管理办法差距` |
| 交易合同改稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不写解除决定」或「夹带调岗／解除」关窗。迹象评估主轴留本窗，劳动只开接口。民企硬套不得负触发到对照窗。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动争议程序文书本身为主成果 | 劳动领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |
| 垄断、滥用支配、经营者集中 | 竞争法领域 |

综合报复迹象评估主轴可留本任务。审查起诉或检查只作背景，主成果才转。出现「报复」「解除」一词不是转出。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 保护措施方案 | `设计举报人保护与反报复措施` |
| 原举报能否初核、是否属实 | `评估单件举报可查性` |
| 谁查、查到哪、预算 | `评估是否启动内部调查` |
| 解除／调岗合法性做完 | 劳动领域 |
| 渠道级保密、无不利动作 | `建设内部举报渠道与受理规则` |

## 易混

有绩效记录不等于没有报复。组织调整不自动洗白。事后补做绩效文件不得覆盖原始时序。已读不是送达。报复评估不是原案结论。坦白不等于举报。劳动法第一百零一条不是全部内部廉洁举报的一般法定义务。会计法第五条／第四十三条只约束对会计人员的报复。民企套 42 号令第二十四条必须认定报复：该格不支持，不关窗，不转出。公司与举报人代理互斥；已混密不得问边治愈。不写解除决定、不认定原案属实是交付禁令，不是负触发。
