# 评估方法

本文件是可执行判断节点。迹象不是已构成报复。不利动作不是当然报复。有绩效不是没有报复。暂停建议不是已暂停。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。迹象三态只用 `支持报复迹象`、`不支持报复迹象`、`依据不足`。禁止胜诉率、必然免责、已构成报复、必须恢复原职、唯一截止日、选定机关、代提交、未知写零。本任务不出解除决定，不写保护方案终稿，不定原案属实。本窗 `RF#` 是报复迹象行，不是 `PT#`，不是 `CS#`，不是 `F#`，不是 `RT#`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1985 年会计法第五条、把 42 号令第二十四条套民企必须上报、把劳动法第一百零一条写成全部内部廉洁举报义务、把时间接近写成已构成报复时记为噪声。禁止指导继续报复或删除会计资料。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`RF#` 固定列：`编号｜对象（举报人／可识别匿名／证人／会计人员／拒绝违规者）｜保护性活动与时点｜不利动作形态与时点｜决策人知情｜官方理由与可回链性（事先书面／事后补做／口头）｜强制接口（劳动法101／会计法5·43／42号令24／刑法红旗，分列强制与非强制）｜迹象三态｜暂停／保护接口｜E#回链｜判断三值｜G#｜最强反方｜待核`。动作文书、决策人知情、官方理由、事先绩效／调整档案四条 `E#` 分列，禁止合成一笔。禁止合成「已构成报复闭环」。`E#` 只作证据形态回链。缺项记 `G#`。扫描不是闭集。

口头「被打击了」「要开掉他」「HR 说要优化」「群已读」只进 `S#`／`V#`，**不得算作开闸材料**。已读、揽收不得升格 `R#` 已送达，不得升格已实施。截图／转发不是原文已保全。口头备份不等于已保全。`A#` 是承认有动作或承认发过文件，不是已构成报复，不是已暂停。拟制日＝本次形成本任务成果之日，不得回填为动作日。稿件状态默认 `草案`。

## 节点 0　分流、立场、迹象闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。伪造或倒签绩效、补假动作件、指导删除、平行灭证、指导继续报复、指导追踪匿名、双方秘密不进负表。

整案转出只交付第 1、2、10 节，不出 `RF#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是保护方案或监测点终稿 | 负触发 `设计举报人保护与反报复措施` |
| 主成果是单件可查性或原案是否属实 | 负触发 `评估单件举报可查性` |
| 主成果是完整启动闸 | 负触发 `评估是否启动内部调查` |
| 主成果是事实认定或调查报告 | 负触发 `形成内部调查报告` |
| 主成果是劳动解除、处分、仲裁文书，或无举报／配合钩子的纯用工动作 | 整案转劳动（迹象评估若仍是主轴则留本窗，文书转劳动） |
| 主成果是职场性骚扰或日常违纪调查终稿 | 整案转劳动（可留报复接口） |
| 主成果是建渠道、没有不利动作件 | 负触发 `建设内部举报渠道与受理规则` |
| 主成果是回避决定终稿 | 负触发 `处理利益冲突与调查回避` |
| 侦查、起诉、辩护、刑事控告为主成果 | 整案转刑事 |
| 「不写解除决定」「不定原案属实」 | 交付禁令，不是负触发 |

审查起诉、监察检查只作程序背景。主成果才整案转。出现「报复」一词不是转出。

迹象闸打开（可出 `RF#` 草案，仍不得标「已构成报复／已构罪／当然没有报复／必须恢复原职」）须同时满足：单方无冲突立场已闭合；主成果是报复迹象、暂停建议与劳动接口，不是解除决定、原案属实或保护方案终稿；至少一件可编号不利动作件。口头扬言、群已读、空白模板不算开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

迹象闸部分打开：有可编号候选件（未发出的预告稿、审批流已创建未落章、权限关闭工单待执行）或有已发件但知情／事先档案未闭合；或无书面评估授权但已有件；对应格待核；仍交十节；不得标终稿 `已形成`。

迹象闸关闭（仍正触发）：无一可编号不利动作件且无一可核验点。「今天必须出已构成报复或必须恢复原职终稿」而无最小事实不得开闸。不出 `RF#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `RF#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「没有报复」或「未发生不利动作」。没有举报或配合钩子、只要普通 PIP／调岗／解除：负触发劳动，不是本窗关闸。尚无不利动作、只要预做保护：负触发保护窗，不是本窗关闸。

「不利动作即当然报复」「有绩效即没有报复」「劳动法第一百零一条套全部内部举报」「会计法第四十三条当然恢复原职」「民企必须按第二十四条上报」「迹象即已构成报复／已构罪」「交迹象表即从轻」「群已读即已送达／已实施」「口头要开掉他即开闸」「时间接近即已构成」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `RF#` 草案。闸未开才不出 `RF#` 终稿。

若 if 立场或委托无法闭合，then 整体停止。
若 if 同时掌握公司与举报人或被指向人相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 公司已开口且委托就是本件迹象评估、且未掌握对方秘密，then 可推定公司立场。
若 if 举报人代理已开口且委托就是本件迹象评估、且未掌握公司秘密，then 可推定举报人代理立场；第 7 节只开劳动／保护请求接口，不得写成公司内部暂停令。
若 if 两造争同一份 `RF#`，then 整体停止。
若 if 单方立场已闭合、无书面评估授权但已有可编号不利动作件，then 迹象闸部分打开，仍交十节，不是整体停止。
若 if 立场已闭合但无一可编号不利动作件，then 迹象闸关闭，仍交十节，不是整体停止。
若 if 提出伪造或倒签绩效／PIP／知悉时点、补假动作件、指导继续实施打击报复、向被指向人核实身份以便报复、指导追踪匿名、指导删除、借已有监察文书平行灭证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　时序、动作件与知情

一行一个时点事件。缺项记 `G#`，不得用「大约」「不久后」填满，不得把未知日写成 `0` 或拟制日。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 举报／配合时点 | 日期；形态（实名／匿名／谈话配合／书面说明）；来源 `E#` | 把「HR 说有人举报了」升格为收件时点 |
| 知悉人 | 岗位；知悉内容（身份／事项／仅「有举报」）；途径；时点 | 把决策人「应该知道」写成已知情；群已读升格知悉 |
| 不利动作决定时点 | 会议／审批／签发时点，不是公告日 | 把实施日或补做理由日回填为决定日 |
| 实施时点 | 权限关闭时间戳、薪资账期、最后工作日、岗位变动生效日 | 把预告发出日写成已解除 |
| 书面理由作出时点 | 官方理由首次形成书面的落款或系统创建日 | 把事后补理由的落款当真决定日 |
| 绩效／调整事先启动时点 | 举报／配合**之前**已启动的 PIP、考核、组织调整、不续签、违纪立案最早可核验日 | 把举报后补做的考核表写进本字段 |

### 事后补做文件的 `V#`

- `V0`：该事件最早可核验件（元数据、审批流创建、邮件头、系统日志）。锁定。**不得改写 `V0` 的时点字段。**
- `V1`、`V2`…：后到件。每件另起一行，记录声称日期、实际形成痕迹、与 `V0` 冲突点、控制方。
- 冲突格只写 `版本冲突`，并列保留，禁止用后到件日期覆盖 `V0`。
- 声称生效日早于元数据形成日：该件不得填「事先启动」。
- 用户要求把 `V1` 当成 `V0`、删掉旧时序、倒签考核：第一次整体停止。

### 可编号不利动作件

须同时具备：可识别作出主体、可识别对象、可识别动作类型、可核验时点、原件或带元数据的衍生件。缺任一要素：只进 `S#`／`G#`，不得开闸。

**算：** 解除／终止预告或通知；书面 PIP／考核不合格通知；书面调岗／职级／地点变更通知；可核验的取消奖、停发、降薪邮件；到期不续签书面通知；账号／门禁／财务／代码库关闭的系统日志。未落章但审批流已创建、权限工单待执行：算候选件，闸最多部分打开，不得标已实施。

**不算：** 口头「要开掉他」；群已读、微信／钉钉已读、快递揽收；同事转述；无落款模板；仅「领导圈了同意」而无可核验载体。

已读 ≠ 送达 ≠ 已实施。口头备份 ≠ 已保全。被指向人或其直线既是决策人又是开箱人：知情格污染，该格不支持或字段停止，**仍出其他 `RF#` 行**。构成报复方法（向被指向人核实身份以便开掉他）：整体停止。

## 节点 3　报复迹象行 `RF#`

按本件已出现要素扫描，不是默认闭集。禁止把「时间接近」单独写成支持报复迹象。时间接近只是时序观察，最多把该行送入 `依据不足`。

- **支持报复迹象**：须同时满足 A+B，且 C 或 D 至少一项。A. 至少一件可编号不利动作件。B. 决策人知情可回链，且知悉时点 ≤ 决定时点。C. 官方理由与举报／配合前书面待遇明显断裂，且该断裂不能由 `V0` 事先程序解释；或 D. 理由或同期书面指向配合／举报行为本身。仍不得写已构成劳动法第一百零一条、已构成刑法、必须恢复原职、解除当然无效。
- **不支持报复迹象**：可编号事先启动件，`V0` 时点早于举报／配合；官方理由可回链到该事先程序；无针对配合／举报行为本身的书面指向。支持事实与不利事实必须并列；缺不利扫描不得闭合本态，改 `依据不足`。不支持 ≠ 没有法律风险。有绩效记录 ≠ 没有报复。
- **依据不足**：有动作件但知情未闭合；仅时间接近；理由仅口头或 `V#` 冲突未解；事先档案声称存在但无 `E#`。不得因不足写成「已构成」，也不得写成「没有问题」。保护／暂停接口不因不足而推迟。

PIP 后解除：事先启动且可回链的绩效考核是最强反方；不得写成「有 PIP 即无报复」或「PIP 后解除即报复」，不得把不能胜任写成已成立。
组织调整调岗：整建制、职级薪酬不降、早于举报的书面调整是最强反方；调岗不是当然报复，也不是当然保护，本窗不裁决必须恢复原职。
取消奖金：事先固定且对同类一致的计划条件是最强反方；不得把取消奖金写成已克扣工资或已构成报复，未知金额不写零。
合同终止或不续签：到期或独立履约违约的事先书面决定是最强反方；不得把不续签写成违法解除或报复已构成。
被指向人知情后的针对动作：独立于被指向人的 HR／调查主体动作是最强反方；被指向人知情不是公司知情，不是已构成报复，不是已构罪。

会计人员才开会计法第四十三条接口。不得写成全体举报人当然恢复原职。状态 `草案`。

## 节点 4　暂停、劳动接口、最强反方与转介

第 7 节只开接口，不得夹带 `RF#` 终稿绕闸。闸关闭时第 7 节可写「闸未开，暂停接口待动作件编号」，不得补写迹象终稿。

暂停建议不是已暂停，不是已发出暂停令，不是已撤回解除。公司立场：建议暂停尚未实施的解除／调岗／关权限／不续签，并转劳动核合法性。举报人代理：建议书面要求暂停并固定时序，不得代公司设计知悉名单或监测点。已实施：只开劳动接口。不可逆动作不得在草案阶段实施。禁止提交指令。不代解除、不代处分、不代提交。

劳动交叉只开接口、本窗不做完：劳动合同法第三十九条／第四十条／第四十一条／第四十四条路径合法性、第四条民主程序、奖金工资定性、调岗变更合意、经济补偿与仲裁时效提醒。接口只写「转劳动核验」，不写解除决定、不写必得恢复原职、不写胜诉率、不写唯一截止日、不选定仲裁委或法院。

最强反方按已出现事实强制扫描，即使用户未提交，缺项记 `G#`，不得默认不存在。两份打架并列，不选有利一版。

| 反方 | 最低核验 | 翻转条件 |
| --- | --- | --- |
| 事先绩效 | `V0` 考核／PIP 启动日早于举报／配合 | 启动日晚于举报，或内容指向举报本身 |
| 组织调整 | 编制／部门撤销书面决议早于举报，且同类岗位同等适用 | 仅针对配合人、无同类适用 |
| 合同到期 | 到期日、不续签政策事先可回链，且同等适用 | 到期前突击不续签且知情已闭合 |
| 违纪程序 | 立案／调查启动早于或独立于本举报 | 「先开除再补查」；程序针对配合行为 |

若 if 用户只提供支持报复的件、拒交绩效／调整档，then 不利事实列 `G#`，不得闭合 `支持报复迹象`；催交，不关窗。
若 if 用户只提供绩效档、要求写成「没有报复」、隐瞒动作件，then 支持事实列 `G#`，不得闭合 `不支持报复迹象`。
