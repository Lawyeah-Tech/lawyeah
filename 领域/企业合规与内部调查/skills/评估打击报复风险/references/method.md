# 评估方法

本文件是可执行判断节点。有绩效记录不等于没有报复。组织调整不自动洗白。事后补做绩效文件不得覆盖原始时序。不判断原举报是否属实。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。迹象三态只用 `支持报复迹象`、`不支持`、`依据不足`。禁止胜诉率、必然免责、范本填满、唯一截止日、选定机关、代提交、未知写零。本任务不写劳动解除或处分决定，不写保护方案终稿，不定罪，不代提交。本窗 `RT#` 是报复迹象行，不是保护措施行，不是可查性行。公司与举报人代理互斥。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1994 年劳动法第一百零一条、把 42 号令第二十四条或劳动法第一百零一条套成民企内部廉洁举报一般法定义务、把绩效记录写成没有报复时记为噪声。禁止指导伪造绩效、倒签解除或删除会计资料。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`RT#` 固定列：`编号｜举报或配合时点｜不利动作／决定与实施时点｜决策人知情｜官方理由版本与作出时点｜三态｜E#回链｜判断三值｜缺口G#｜最强反方｜待核`。禁止合成「已构成打击报复」或「当然不是报复」一笔。事后补文件不得覆盖原始时序。无法判断则该条待核。`E#` 只作证据形态回链。缺项记 `G#`。扫描不是闭集。

口头「早有组织调整」「绩效一直不行」「群已读」只进 `S#`／`V#`，**不得算作开闸材料**。已读、揽收不得升格 `R#` 已送达。`A#` 是承认，不是已构成报复。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

## 节点 0　分流、立场、报复闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。伪造绩效、倒签解除、假事先程序、指导删除、继续实施报复、阻挠合法检查、双方秘密不进负表。

整案转出只交付第 1、2、10 节，不出 `RT#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是保护方案终稿 | 负触发 `设计举报人保护与反报复措施` |
| 主成果是单件可查性或原案属实 | 负触发 `评估单件举报可查性` |
| 主成果是完整启动闸 | 负触发 `评估是否启动内部调查` |
| 主成果是解除／处分决定书或劳动程序文书本身 | 整案转劳动 |
| 主成果是建渠道且没有不利动作 | 负触发 `建设内部举报渠道与受理规则` |
| 确为中央企业且主成果是 42 号令对照终稿 | 负触发 `评估国企合规管理办法差距` |
| 侦查、起诉、辩护为主成果 | 整案转刑事 |

审查起诉、监管检查只作程序背景。主成果才整案转。出现「报复」「解除」一词不是转出。**举报后解除／调岗／处分作为迹象评估主轴时留本窗**，劳动合法性只开接口，不得整案转劳动。

报复闸打开（可出 `RT#` 草案，仍不得标「已构成报复／当然不是报复」）须同时满足：单方无冲突立场已闭合（公司或举报人代理，互斥）；主成果是迹象评估，不是保护方案、可查性或解除决定书；至少一项可编号不利动作或拟设迹象行。从零：有动作碎片或拟设即可开或半开，缺项记 `G#`。口头调整、已读不算开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

报复闸部分打开：知情、理由时点或主体未核验，但已有可编号范围；或无书面评估授权但已有拟设行或动作碎片；对应格待核；仍交十节；不得标终稿 `已形成`。

报复闸关闭（仍正触发）：无一可编号动作且无一拟设行。「今天必须出已构成报复／当然不是报复终稿」而无最小事实不得开闸。不出 `RT#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `RT#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「绩效记录即没有报复」「组织调整当然洗白」「事后补绩效覆盖时序」「已读即送达」「匿名即诬告可处分」「民企必须按第 24 条认定报复」「原案不实即可处分」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `RT#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合、无书面评估授权但已有拟设行或动作碎片，then 报复闸部分打开，仍交十节，不是整体停止。
若 if 单方立场已闭合但无一拟设且无一动作，then 报复闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与举报人相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造绩效、倒签解除、假事先程序、指导删除会计资料、借迹象稿继续实施报复或阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

中央企业／地方国企／参股／民企分列。立场：公司或举报人代理，互斥，不自动合并。

检索锚点（写入 `L#` 前须核验）：

- 42 号令第二条、第二十四条、第四十条：不得打击报复只约束中央企业。民企硬套必须认定报复：该格不支持，不关窗，不得建议上报国资委。
- 公司法第一百六十八条、第一百七十七条：不套民企。
- 劳动法（2018 修正）第一百零一条：阻挠劳动行政部门或报复向劳动行政机关举报。不是全部内部廉洁举报的一般法定义务。
- 劳动合同法第四条：处分程序只开接口。不胜任调岗举证本窗不做完。
- 会计法（2024 修正）第五条、第四十三条：会计人员报复与恢复名誉职务，不是全体举报人当然恢复原职。
- 个保法第六条：评估报复不等于全员公开身份。
- 监察法（2024 修正）第十八条：不得伪造、隐匿、毁灭。
- 刑法第三百零八条、第三百零七条、第一百六十二条之一只作红旗。

强制接口与非强制对标分列。

## 节点 3　迹象行 `RT#`

按已出现不利动作扫描，不是默认闭集。每项动作一行。时序强制分列：举报或配合时点、知悉人、动作决定时点、实施时点、书面理由作出时点。事后补做文件标 `V#` 冲突，不得覆盖 `D#` 原始时序。

三态规则：

- **支持报复迹象**：决策人知情、理由与既往待遇明显断裂、动作针对配合行为本身、书面理由晚于动作或倒签。仍不得写成已构成刑事打击报复或劳动违法解除已成就。
- **不支持**：有事先启动且与举报无关、可回链的书面程序，时序不断裂。仍不得写成「当然合法」或「没有问题」。
- **依据不足**：理由口头、文件日期矛盾、知情未核验。不是必须认定报复，也不是必须洗白。

不得单独作为不支持的理由：有绩效记录、口头组织调整、已读、原举报尚未查实。不得单独作为支持的理由：出现「举报」一词、民企套第 24 条。

无 `E#` 不得写已覆盖、已构成或当然不是。状态 `草案`。不判断原案属实。

## 节点 4　暂停接口、可逆性与转介

建议暂停解除、调岗或公示，只开接口。解除合法性、经济补偿、仲裁时效转劳动。不写解除决定书，不选定仲裁委，不写唯一截止日。迹象达到支持或依据不足但不可逆动作临近：转介 `设计举报人保护与反报复措施` 并标紧急接口，本窗不出保护方案终稿。

可逆与不可逆分列。不可逆（发送解除、全员公示、格式化旧档、对外宣称当然不是报复）不得在草案阶段实施。禁止提交指令。不代提交。

下一步只转介：保护方案、可查性、启动闸、劳动、案卷。禁止一次写完全部邻窗终稿。

已有监察或检查 `R#`：不得借迹象稿平行灭证或继续报复。刑法第一百六十二条之一只作红旗，不得指导删除。
