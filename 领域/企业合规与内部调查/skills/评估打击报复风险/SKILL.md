# 评估打击报复风险

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。本窗是评估类迹象草案，**不要**用文书范本检索生成「已构成报复／解除已合法／原案已属实」。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现事后补绩效覆盖时序、组织调整洗白、绩效记录冒充无报复、解除被写成当然合法的反例；案例只比较事实差异与翻转条件，不写成必然结果。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《民法通则》《民法总则》或其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的**单方**立场下，形成打击报复迹象评估草案：报复闸、主体与强制接口、`Q#` 路径、`RT#` 迹象行（时序／知情／不利动作／官方理由可回链性／三态）。立场互斥：公司或举报人代理，不得同时代理。有绩效记录不等于没有报复。组织调整不自动洗白。事后补做绩效文件不得覆盖原始时序。不判断原举报是否属实。不写劳动解除或处分决定。不写保护方案终稿。不保证免责。不代提交。

`depends-on` 为空。保护方案终稿转 `设计举报人保护与反报复措施`。原举报可查性转 `评估单件举报可查性`。完整启动闸转 `评估是否启动内部调查`。劳动解除、处分合法性、经济补偿、仲裁时效转劳动。建渠道转 `建设内部举报渠道与受理规则`。

## 工作边界

正触发：举报或配合调查之后出现调岗、降薪、解除、公示、扣奖等不利动作，需要评估报复迹象并给出暂停接口，而不是写解除决定、认定原案属实或设计保护方案。动作碎片、知情未核验、无书面评估授权仍正触发：有可编号不利动作或拟设迹象行则报复闸打开或半开，第 6 节出 `RT#` 草案，缺项记 `G#`。无书面评估授权但有拟设行：部分打开。无一动作且无一拟设、又要求「今天必须出已构成报复／当然不是报复终稿」才关闸，不出 `RT#` 终稿，窗口不关。用户要把绩效记录写成没有报复、把组织调整写成当然洗白、把事后补绩效写成覆盖时序、把群已读写成送达、把匿名即诬告写成可以处分、民企按 42 号令第二十四条必须认定报复、要求本窗写解除决定，仍正触发：对应格填 `现有依据不支持`，窗口不关；闸已开仍出其他 `RT#` 草案。不得因「不写解除决定」或「不认定原案属实」改走负触发关窗。主成果是举报后不利动作的迹象评估时，不得因夹带解除／调岗整案转劳动。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是保护方案终稿（转 `设计举报人保护与反报复措施`）；
- 主成果是单件可查性或原举报是否属实（转 `评估单件举报可查性`）；
- 主成果是完整启动闸（转 `评估是否启动内部调查`）；
- 主成果是劳动解除、处分决定书或劳动争议程序文书本身（转劳动领域）；
- 主成果是建渠道且没有不利动作（转 `建设内部举报渠道与受理规则`）；
- 确为中央企业且主成果是 42 号令对照终稿（转 `评估国企合规管理办法差距`）；民企硬套第二十四条必须认定报复仍正触发，该格 `现有依据不支持`。

双方秘密、伪造绩效或倒签解除、假事先程序、指导删除会计资料、继续实施报复、阻挠合法检查**不在负触发表**，走整体停止。「绩效即无报复」「组织调整当然洗白」「事后补绩效覆盖时序」「已读即送达」「匿名即诬告可处分」「民企必须认定报复」**不在负触发表**，该格 `现有依据不支持`，窗口不关。「不写解除决定」「不认定原案属实」「不保证免责」是交付禁令，不是负触发。

## 建立工作坐标

确认：评估授权；**单方立场（公司／举报人代理，互斥）**；原举报或配合时点、不利动作决定时点与实施时点、决策人是否知情、官方理由作出时点、保护状态；法域；当前检查、诉讼、监察或刑事状态。

口头「早有组织调整」「绩效一直不行」「群已读就是送达」只登记 `S#`／`V#`。不得升格已构成报复、当然不是报复或已送达，**不得算作开闸材料**。事后补做的绩效文件标版本冲突，不得覆盖原始时序。已读、揽收不得升格 `R#` 已送达。

同时掌握公司与举报人相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。公司已开口且委托就是迹象评估、且未掌握对方秘密时，可推定公司立场。举报人代理已开口且委托就是迹象评估、且未掌握公司秘密时，可推定代理立场。无书面评估授权但单方立场已闭合、且已有可编号拟设行或动作碎片：报复闸部分打开，仍交十节，不是整体停止。无一拟设且无一动作：报复闸关闭，仍交十节，不是整体停止。提出伪造绩效、倒签解除、假事先程序、指导删除或继续实施报复：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认（不是已构成报复，不是原案属实）；`R#` 机关或生效文书；`C#` 内部制度、考核或解除文件版本；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`RT#` 报复迹象行；`V#` 版本；`E#` 证据形态回链（举报／配合时点、知悉人、动作决定／实施、书面理由版本，不是发送闸，不是已送达或已构成报复证明）。禁止 `N#`、`EV#`、`M#`、`F#`、`ACT#`、`P#`、`K#`、`O#`、`H#`、`B#`、`U#`、`X#`、`HD#`、`W#`、`T#`、`OR#`、`LV#`、`TR#`、`PX#`、`LD#`、`SP#`、`CH#`、`CS#`、`PT#`。技能正文中的条号是检索锚点，不是已核验 `L#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。迹象三态只用 `支持报复迹象`、`不支持`、`依据不足`。禁止合成「已构成打击报复」或「当然不是报复」一笔。扫描不是闭集。未知金额不写零。稿件状态默认 `草案`。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：中央企业合规管理办法第二条只约束国资委履行出资人职责的中央企业。第二十四条不得以任何形式对举报人打击报复，只约束中央企业；不是民企必须认定报复的一般法定义务。第四十条是对地方国资机构的参照指导。公司法第一百六十八条国家出资公司不含参股。第一百七十七条不套民企。劳动法（2018 修正）第一百零一条打击报复举报人员，指向阻挠劳动行政部门监督检查或报复向劳动行政机关举报的人员，不是全部内部廉洁举报的一般法定义务，只开接口。噪声：1994 年文本。劳动合同法第四条劳动纪律民主程序只开接口；解除、不胜任调岗的合法性本窗不做完。会计法（2024 修正）第五条、第四十三条只约束对会计人员的报复与恢复名誉职务，不是全体举报人当然恢复原职。个人信息保护法第六条最小范围不等于为评估报复而全员公开身份。监察法（2024 修正）第十八条如实提供，不得伪造、隐匿、毁灭。刑法第三百零八条、第三百零七条、第一百六十二条之一只作红旗，不定罪，不得指导删除。噪声：已失效《合同法》、42 号令套民企、劳动法 101 套全部内部举报、绩效即无报复、组织调整当然洗白、已读即送达、原案不实即可处分。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变 42 号令主体、劳动法 101 范围或会计人员报复边界的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补事后补绩效覆盖时序、组织调整洗白、不胜任调岗举证、解除被写成当然合法的反例。
- `search_case_by_fact` 只比较时序、知情、理由可回链性的事实差异与翻转条件，不写成必然构成报复、必然合法解除或必然胜诉。坦白不等于举报；类案不得升格本窗三态。

工具不可用时继续时序、动作和 `RT#` 编目；主体义务、报复规则、施行日、机关路径字段停止。不得拒跑，不得凭记忆写成民企必须认定报复或绩效记录即无报复。

## 判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、报复闸与不关窗

主成果才整案转出。举报后解除／调岗主轴仍可留本窗。伪造绩效、继续报复、双方秘密第一次停。绩效即无报复、组织调整洗白、要求写解除决定不关窗。闸关仍交十节，第 6 节不出 `RT#` 终稿。公司与举报人代理互斥。

### 2. 主体与强制接口

中央企业／地方国企／参股／民企分列。第 24 条、劳动法 101、会计法第五条／第四十三条分列强制与非强制。

### 3. 报复闸与路径 `Q#`

本节禁止出 `RT#` 终稿。有可编号不利动作或拟设行：闸打开或半开。无一动作且无一拟设才关闸，窗口不关。口头调整、已读不得开闸。

### 4. 迹象行 `RT#`

时序、知情、动作、官方理由可回链性、三态分列。事后补文件不得覆盖原始时序。不判断原案属实。状态 `草案`。

### 5. 暂停接口、劳动交叉与转介

建议暂停实施只开接口。解除合法性转劳动。保护方案转保护窗。不可逆动作不得在草案阶段实施。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造绩效、倒签解除、假事先程序、指导删除会计资料、借迹象稿继续实施报复、阻挠合法检查。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无书面评估授权但单方立场已闭合：不是整体停止；有拟设则部分打开，无一拟设则闸关闭，仍交十节。
- `字段停止`：42 号令主体、劳动法 101 范围、知情、书面理由时点、施行日未核验。绩效即无报复、组织调整洗白、事后补绩效覆盖时序、已读即送达、匿名即诬告可处分、民企必须认定报复：该格 `现有依据不支持`，窗口不关；闸已开仍出其他 `RT#` 草案。
- `目标停止`：主目标变为保护方案终稿、可查性终稿、启动闸、劳动解除决定书、原案属实认定。

禁止指导伪造绩效、倒签解除或删除会计资料。不给胜诉率。不定罪。不保证免责。不选定仲裁委或法院。不代提交。未知不写零。不写解除决定。不认定原案属实。不把绩效记录写成没有报复。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。报复闸关闭仍交十节，第 6 节不出 `RT#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `RT#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。报复闸未打开时不得交付「已构成报复」或「当然不是报复」。边界见 [路由](references/routing.md)。
