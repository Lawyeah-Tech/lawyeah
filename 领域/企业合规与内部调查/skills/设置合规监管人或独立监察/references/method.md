# 设置合规监管人或独立监察方法

本文件是可执行判断节点。设置不是监管已认可。拟设不是已任命。原顾问不是独立。现任辩护律师兼监察不是已隔离。向业务线汇报不是已独立。独立监察不是国家监察机关。监管人不是检察第三方，不是 42 号令第十五条第三道，不是首席合规官。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、监管已认可、范本填满、唯一截止日、选定机关、代提交、未知写零。本任务不定罪，不写聘用合同正文，不写任免决议，不代任免。本窗闸名只能是监管闸，禁止复用监察闸。本窗 `JG#` 是监管人行，不是岗位行 `P#`，不是检察合规计划 `P#`，不是期限卡 `K#`，不是预案行 `YU#`，不是监察行 `MO#`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1990 年能源企事业单位监察工作规定当现行、把 42 号令第十五条写成民企必须设独立监察、把本窗写成国家监察或检察第三方、把 FCPA monitor 写成中国法义务、把范本当已任命或监管已认可证明时记为噪声。禁止指导伪造无冲突声明或阻挠合法检查。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`JG#` 固定列：`编号｜人选／机构｜来源（监管协议／董事会／自行，禁止国家监察或检察第三方）｜独立性（选任／考核／报告线）｜权限（调阅／抽查／访谈／列席）｜禁止项（处分／披露／阻挠）｜冲突｜任期更换｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已设即已认」或「已独立闭环」。无 `E#` 不得写已设置、已独立、监管已认可。`E#` 只作证据形态回链（选任授权、冲突声明、报告线路由），不是发送闸。扫描不是闭集。缺项记 `G#`，不得用「参照最佳实践」或范本栏目填满。

口头「已经有独立监察」「群里宣布了」「邮件已发就是报告线已生效」「监管口头点头了」只进 `S#`／`V#`，**不得单独算作开闸材料**。已读、快递揽收不得升格 `R#` 已送达，不得升格监管已认可。口头备份不等于已保全。名片、挂名不是已授权。`A#` 是承认来源或候选人碎片，不是已任命、已独立或监管已认可。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：合规职责不得与被整改业务盈亏挂钩；报告应向董事会、审计委员会、监事会或约定监管接口，不得经被整改业务负责人改稿；现任辩护律师同时担任监察须拆分；原项目顾问通常不独立；设置了不等于监管已认可。

审查起诉、监管检查只作程序背景。主成果才整案转。出现「监察」「监管人」一词不是转出。英文 id `prepare-prosecutorial-compliance` 禁止使用，一律用中文技能名 `准备涉案企业合规整改与验收`。

监管闸打开（可出 `JG#` 草案，仍不得标「已任命／已独立／监管已认可／已免责终稿」）须同时满足：单方无冲突公司立场已闭合；主成果是独立监督整改人选，不是三道岗位、不是检察第三方、不是国家监察、不是聘用合同全文；至少一项可编号来源碎片或候选人。从零设置：有来源条款或候选人即可开闸或半开，缺项记 `G#`。书面设置授权未闭合但已有候选人：部分打开，不得因无授权文件关掉人选草案。口头已有监察、已读揽收、名片挂名、监管口头点头不算开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

监管闸部分打开：来源、报告线或冲突未闭合，但已有可编号人选或来源范围；对应格待核；仍交十节；不得标终稿 `已形成`。无书面设置授权但有候选人：部分打开。原顾问或现任辩护律师是唯一候选人：部分打开，独立性格不支持，仍出其他 `JG#`，不是关闭。

监管闸关闭（仍正触发）：无一可编号人选且无一来源。「今天必须出已任命／监管已认可终稿」而无最小事实不得开闸。无书面设置授权但已有候选人：部分打开，不是关闭。不出 `JG#` 终稿。**仍交十节**，第 5 节只交闸／`Q#` 状态，第 6 节不出 `JG#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「已经独立」或「没有缺口」。

「设置即监管已认可」「原顾问即独立」「现任辩护律师兼监察即已隔离」「向业务线汇报或经业务负责人改稿即独立」「监管人即国家监察／检察第三方／第三道／CCO」「民企必须按 42 号令第十五条或公司法第一百七十七条设独立监察并上报」「FCPA monitor 当中国法义务」「范本即法定格式或已任命」「群已读或邮件已发即已任命／报告线已生效」「交人选表即从轻」「保证过关或免责」「人数未知先写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `JG#` 草案。闸未开才不出 `JG#` 终稿。民企套第十五条不得负触发到 `评估国企合规管理办法差距`，不得建议上报国务院国资委。人选冲突、原顾问、辩护律师兼任：该格不支持或闸半开，替代方案≠已独立，**不是关闸，不是整体停止**。

`Q-认`（监管是否接受该人选）本窗**不打开**。监管闸打开 ≠ 认可打开。协议要求设 monitor、董事会已通过人选、顾问合同已签，均不得写成监管已认可。无机关 `R#` 则认可字段停止或该格不支持。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无一可编号人选且无一来源，then 监管闸关闭，仍交十节，不是整体停止。
若 if 公司立场已闭合、无书面设置授权但已有候选人，then 监管闸部分打开，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象或候选人相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出指导伪造无冲突声明或独立性声明、伪造监管已认可、倒签聘用或选任、指导阻挠合法检查、擅自对外披露方法、打击报复，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个主体或强制接口。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `JG#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 机制来源 | 监管协议／和解／董事会／自行分列 | 写成国家监察委派或检察第三方已启动 |
| 主体类型 | 中央企业／地方国企／参股／民企／是否上市分列 | 民企强制套 42 号令第十五条 |
| 检察分界 | 本窗不是第三方监督评估 | 自聘内审或顾问写成已进入检察机制 |
| 国家监察分界 | 独立监察 ≠ 监察法上的监察机关 | 把留置、调查权写入本窗权限 |
| 第三道分界 | 42 号令第十五条是央企第三道 | 把本窗监管人写成第三道或 CCO |

检索锚点（写入 `L#` 前须核验）：

- 最高检涉案企业合规第三方监督评估机制指导意见：结果是依法处理案件的重要参考，不是必然不起诉，也不是本窗人选已获监管认可。未检出则适用字段停止，禁止编造条号。英文 slug 禁止使用。
- 42 号令第二条、第四十条：只约束中央企业；第四十条是对地方国资机构的参照指导。民企监管人是内部治理文本，强制对照行删除，该格 `现有依据不支持`，不关窗。不得建议民企上报国务院国资委。
- 42 号令第十二条：首席合规官，不是本窗监管人。
- 42 号令第十五条：纪检监察机构和审计、巡视巡察、监督追责等部门履行第三道监督，不是本窗独立监管人，不套民企必须设独立监察。
- 公司法第一百六十八条：国家出资公司不含参股。第一百七十七条仅国家出资公司对内合规，不是民企设监管人义务。
- 公司法第一百八十条忠实勤勉是追偿接口，不是已独立、已廉洁。第一百八十二条关联交易报告决议、第一百八十五条关联董事不得表决只开接口，不是调查已回避，不是本窗已独立。
- 监察法及实施条例：国家监察，不是企业独立监察。实施条例中国有企业管理人员 ≠ 全部国企员工。监察法第十八条如实提供，不得伪造、隐匿、毁灭；本窗权限不得写成阻挠检查。
- 律师法第三十八条、第三十九条：同时性利益冲突。现任辩护律师兼监察：该格不支持，须拆分，窗口不关。
- 劳动合同／聘用只开接口，本窗不签正文，不写任免决议。
- 行政处罚法（2021）第三十二条：交人选表 ≠ 从轻。
- 不得把美国 FCPA monitor 或 SOX 独立监察写成中国法定义务；可作非强制对标并标明法域。
- 刑法第一百六十二条之一只作红旗，不得指导删除。
- 民法典第七十四条与公司法第三条：分公司与子公司分列。总部印发不能直接在独立法人子公司生效。

国企适用办法条款才写入强制项。强制接口与非强制对标分列，不选对用户有利的一版。经营者集中监督受托人范本不得升格本窗已独立或已进入经营者集中。

民企可出内部监管人 `JG#` 草案，必须标「内部治理／非强制对标」，禁止写成 42 号令第十五条已履行。

## 节点 3　监管人行 `JG#`

本任务范围按已出现需求扫描，不是默认闭集：人选条件、机制来源、选任与考核独立性、报告线、权限、禁止项、利益冲突、任期与更换。缺项记 `G#`，不得用「参照最佳实践」或范本栏目填满。

每行必须能指向来源、独立性与权限边界。禁止「全面独立监察」无主句；无来源归属则删除或改 `G#`。无 `E#` 不得写已设置、已独立或监管已认可。

`E#` 三件套（证据形态回链，**不是发送闸**）：

| 回链 | 形态 | 不得升格 |
| --- | --- | --- |
| 选任授权 | 董事会／有权机关决议、协议条款、书面授权范围 | 口头点头、群已读、名片 ≠ 已任命 |
| 冲突声明 | 既有顾问／辩护／项目费／被整改线考核关系的书面披露 | 口述「没关系」≠ 无冲突 |
| 报告线路由 | 直报董事会、审计委员会、监事会或约定监管接口；紧急升级；禁止被整改业务负责人改稿 | 邮件已发、已读 ≠ 报告线已生效 |

热冲突强制处理：

- 原顾问／原项目所 → 独立性格 `现有依据不支持`；仍出权限、报告线、任期等其他 `JG#`；替代条件（非原顾问、预算不走被整改线、向董事会或约定接口直报）≠ 已独立。
- 现任辩护律师兼监察 → 该格不支持；须拆分；闸半开；**不整停、不关窗**。
- 被整改业务线选任或考核、报告经业务负责人改稿 → 独立性格不支持；无直报 `E#` 不得写已独立。
- 设置即监管已认可／保证过关／FCPA 当中国法／民企套第十五条 → 该格不支持；仍出其他 `JG#`。
- 无一可编号人选且无一来源 → 关闸，不出 `JG#` 终稿，窗口不关。
- 指导伪造无冲突声明、阻挠合法检查 → 整体停止，不是该格不支持。

可写权限（拟授权草案，不是已授权）：调阅整改证据、抽查、独立访谈、列席、直接向董事会或约定监管接口报告。禁止写成已授权：人事处分、解除劳动合同、对外披露、阻挠合法检查、划走账户。建议权不得升格处分权。阻挠检查写入权限清单＝该格不支持（不关窗）；要方法挡检查或隐匿＝整体停止。外包只写独立性、保密、禁止转委托条件，不签服务合同正文。

独立法人：总部一纸任命不在子公司生效。本窗可出子公司拟设 `JG#`，生效条件＝子公司有权机关决定。伪造子公司任命＝整体停止。

状态 `草案`。一次只推荐下一步。

## 节点 4　聘用、任免、检察与三道接口

已有监察或检查 `R#`：不得借监管人稿平行灭证。刑法第一百六十二条之一只作红旗，不得指导删除。文本不得写「设置完成即免除法律责任」或「监管已经认可该人选」。
