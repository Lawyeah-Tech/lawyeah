# 设置合规监管人或独立监察

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或文书范本检索。本窗是设置类人选条件草案，范本只借栏目，**不要**升格「已任命／已独立／监管已认可」，**不要**用类案或公告检索写任免终稿。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现设置即已认可、项目顾问即独立、辩护律师兼任即独立、业务线选任考核即独立、自聘当检察第三方的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《民法通则》《民法总则》或其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下（公司或其调查受托律师，互斥），形成独立监察或监管人人选条件草案：监察闸、主体与强制接口、`Q#` 路径、`MO#` 监察行（人选／独立性／权限／报告线／任期／`E#` 回链）。本窗 `MO#` 是监察行，不是岗位行 `P#`，不是回避行 `AV#`，不是履职行 `H#`，不是整改动作 `A#`，不是验收计划。监察闸打开不等于已任命不等于已独立不等于监管已认可。设置了不是监管已认可。项目顾问不是当然独立。现任辩护律师兼任不是独立。被整改业务线选任考核不是独立。监管人不是第三道，不是 CCO。企业自聘监察不是检察合规第三方。美国 FCPA monitor 不是中国法义务。42 号令不套民企必须外聘。交监察表不等于从轻。不定罪。不保证监管认可。不签聘用合同正文。不含人事处分权。不代任免。未知不写零。

`depends-on` 为空。主成果是检察合规第三方评估或验收转 `准备涉案企业合规整改与验收`。普通整改方案转 `准备合规整改方案`。三道防线岗位配置转 `配置合规机构与三道防线`。调查回避终稿转 `处理利益冲突与调查回避`。调查授权书转 `确定调查授权范围与独立`。董监高履职痕迹转 `评估董监高合规职责缺口`。聘用合同全文本窗搁置。任免决议转公司治理。劳动解除转劳动领域。刑事辩护、控告或自首转刑事领域。

## 工作边界

正触发：董事会、监管协议或整改安排需要独立监督整改的监管人或监察人选条件、权限、报告线与利益冲突，而不是检察第三方验收、整改动作表或聘用合同全文。独立性、任期、认可未核验仍正触发：有可编号整改来源或人选碎片则监察闸打开或半开，第 6 节出 `MO#` 草案，缺项记 `G#`。无一可编号来源且无一人选碎片、又要求「今天必须出已任命或已认可终稿」才关闸，仍交十节，第 6 节不出 `MO#` 终稿，窗口不关。用户要把设置写成监管已认可、把项目顾问写成已独立、把辩护律师兼任写成独立、把业务线选任考核写成独立、把自聘写成检察第三方、把监管人写成第三道或 CCO、把民企套 42 号令写成必须外聘、把 FCPA monitor 写成中国法义务，仍正触发：对应格填 `现有依据不支持`，窗口不关；闸已开仍出其他 `MO#` 草案。不得因「不保证监管认可」「不签聘用合同正文」「不含人事处分权」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是检察合规第三方评估或验收（转 `准备涉案企业合规整改与验收`）；
- 主成果是普通整改方案终稿（转 `准备合规整改方案`）；
- 主成果是三道防线岗位配置（转 `配置合规机构与三道防线`）；
- 主成果是调查回避终稿（转 `处理利益冲突与调查回避`）；
- 主成果是调查授权书终稿（转 `确定调查授权范围与独立`）；
- 主成果是董监高履职痕迹终稿（转 `评估董监高合规职责缺口`）；
- 主成果是聘用或服务合同全文（审查起草领域，本窗搁置）；
- 主成果是任免决议或通知（转公司治理领域）；
- 主成果是劳动处分或解除（转劳动领域）；
- 主成果是刑事辩护、控告或自首（转刑事领域）。

双方秘密、指导让被整改人改监察报告、伪造独立性或监管已认可、倒签选任、打击报复**不在负触发表**，走整体停止。「设置即已认可」「顾问即独立」「辩护律师兼任即独立」「业务线选任即独立」「自聘即检察第三方」「监管人即第三道或 CCO」「民企必须外聘」「FCPA monitor 即中国法」**不在负触发表**，该格 `现有依据不支持`，窗口不关。「不保证监管认可」「不签聘用合同正文」「不含人事处分权」是交付禁令，不是负触发。主成果才转；出现「监察」「独立」「监管人」一词不是转出。

## 建立工作坐标

确认：选任授权；单方立场（公司或其调查受托律师，互斥）；机制来源（董事会／监管协议／整改安排）；整改范围；候选人与既有顾问、辩护关系；报告对象；法域；当前检查、诉讼、监察或刑事状态。

口头「顾问就能当监察」「已经设了所以监管认了」「群已读」只登记 `S#`／`V#`。不得升格已任命、已独立或监管已认可，**不得单独算作开闸材料**。可编号整改来源或人选碎片可开闸。决议能开闸，不能升格已认可。本窗不执行任免，不代提交，不定罪，不签聘用合同正文。

立场只许「公司」或其调查受托律师，互斥。同时掌握公司与被整改对象或候选人相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。公司已开口且委托就是本件监察人选、且未掌握对方秘密时，可推定公司或其调查受托律师立场。无一可编号来源且无一人选碎片：监察闸关闭，仍交十节，不是整体停止。无书面选任授权但单方立场已闭合、且已有可编号碎片：监察闸部分打开，仍交十节，不是整体停止。提出指导被整改人改稿、伪造独立性或监管已认可、倒签选任或打击报复：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认（不是已独立，不是已认可）；`R#` 机关或生效文书；`C#` 董事会决议、监管协议或整改安排；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`MO#` 监察行；`V#` 版本；`E#` 证据形态回链（选任授权、候选人关系、预算挂靠、报告对象，不是发送闸，不是已认可证明，不是任免已发出）。禁止 `N#`、`EV#`、`M#`、`F#`、`ACT#`、`P#`、`K#`、`O#`、`H#`、`B#`、`U#`、`X#`、`HD#`、`W#`、`T#`、`OR#`、`LV#`、`TR#`、`PX#`、`LD#`、`SP#`、`CH#`、`CS#`、`PT#`、`RF#`、`RT#`、`AU#`、`AZ#`、`PL#`、`LG#`、`IQ#`、`WP#`、`DP#`、`CM#`、`AV#`、`BR#`、`GP#`、`GI#`、`GF#`、`IC#`、`XB#`、`BX#`、`TP#`、`VR#`、`RP#`、`TD#`、`TM#`、`SC#`、`DW#`、`DG#`、`SU#`、`SN#`、`MJ#`、`MF#`、`YU#`、`A#`、`RC#`、`IM#`、`IS#`、`JM#`、`CG#`、`IV#`、`OT#`。技能正文中的条号是检索锚点，不是已核验 `L#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。禁止合成「已独立闭环」或「设置即已认可」。扫描不是闭集。未知不写零。设置 ≠ 监管已认可。顾问 ≠ 已独立。辩护兼任 ≠ 独立。业务线选任 ≠ 独立。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：公司法第一百六十八条不含参股、第一百七十七条不套民企必须外聘独立监察。中央企业合规管理办法第二条只约束中央企业；第十二条 CCO 不新增职数、由总法律顾问兼任，不是独立监察；第十四条组织或参与调查不是已设监察；第十五条第三道不是监管人；第二十三条整改机制不是已设独立监察；第四十条地方国资参照。最高检涉案企业合规第三方监督评估机制与本窗分列：管委会选任 ≠ 企业自聘监察。律师法利益冲突：现任辩护律师兼任监察须拆分。监察法第十八条如实提供，不得伪造独立性声明。行政处罚法（2021）第三十二条交监察人选不等于从轻。刑法第六十七条设监察不等于自首。噪声：42 号令套民企必须外聘、自聘当检察第三方、顾问即独立、辩护兼任即独立、业务线选任即独立、设置即已认可、FCPA monitor 当中国法。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变主体范围或检察第三方差界的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补项目顾问冒充独立、辩护律师兼任、业务线选任考核、报告经被整改人改稿、自聘当检察第三方、设置即监管已认可的实务反例。
- `search_template` 只借人选条件、权限、报告线、利益冲突、任期栏目。检察第三方评估协议、聘用合同、劳动合同、任免通知、FCPA monitor agreement **不得**升格本窗已任命或监管已认可。禁止用范本生成已独立证明。

工具不可用时继续人选、冲突和 `MO#` 编目；主体义务、认可、施行日字段停止。不得拒跑，不得凭记忆写成已认可、顾问即独立或民企必须外聘。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、监察闸与不关窗

主成果才整案转出。双方秘密、指导被整改人改稿或伪造独立性第一次停。设置即已认可、顾问即独立、辩护兼任即独立、业务线选任即独立不关窗。闸关仍交十节，第 6 节不出 `MO#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与强制接口

中央企业／地方国企／参股／民企分列。42 号令、检察第三方机制与本窗分列。CCO／第三道不是本窗监管人。

### 3. 监察闸与路径 `Q#`

本节禁止出 `MO#` 终稿。有可编号整改来源或人选碎片：闸打开或半开。无一可编号件才关闸，窗口不关。口头「顾问就能当」不得单独开闸。

### 4. 监察行 `MO#`

人选、独立性、权限、报告线、任期分列。状态 `草案`。禁止升格已任命、已独立、已认可。无 `E#` 不得写已覆盖。

### 5. 验收、整改、配置与合同接口

检察第三方只开验收接口。整改动作只开整改接口。三道岗位只开配置接口。聘用合同只开审查起草接口。第 7 节不得夹带 `MO#` 终稿绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出指导被整改人改稿、伪造独立性或监管已认可、倒签选任、打击报复。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号来源且无一人选碎片：监察闸关闭，仍交十节，不是整体停止。无书面选任授权但有可编号碎片：监察闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：42 号令主体、检察第三方差界、施行日未核验。设置即已认可、顾问即独立、辩护兼任即独立、业务线选任即独立、自聘即检察第三方、监管人即第三道、民企必须外聘、FCPA monitor 即中国法：该格 `现有依据不支持`，窗口不关；闸已开仍出其他 `MO#` 草案。催写零不关窗。
- `目标停止`：主目标变为检察验收包、整改动作表、三道岗位、回避终稿或聘用合同全文。

禁止指导被整改人改稿、伪造独立性或倒签选任。不给胜诉率。不定罪。不保证监管认可。不选定机关。不代任免。未知不写零。不把设置写成已认可。不把顾问写成已独立。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。监察闸关闭仍交十节，第 6 节不出 `MO#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `MO#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。监察闸未打开时不得交付「已任命」或「监管已认可」。边界见 [路由](references/routing.md)。
