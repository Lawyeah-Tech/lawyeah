# 边界与路由

## 正触发

已有合规制度或其运行痕迹，需要判断是否有效运转。文本不齐、痕迹缺失仍正触发：有效性闸关闭，不出有效性终稿，窗口不关。保证体系完备、合规即可免责、把计划写成已完成、民企套 42 号令，仍正触发。

双方秘密、伪造运行记录、伪造培训签到或整改台账的停止，优先于负触发。上述信号不在下表。「保证体系完备」「合规即可免责」不在下表。

## 易混

制度齐备但无运行证据：正触发，五维多为依据不足，不得写成有效。要抽样方案和缺陷分级终稿：负触发 `开展合规有效性评价`。零举报不是无风险。「先补假签到」整体停止。
