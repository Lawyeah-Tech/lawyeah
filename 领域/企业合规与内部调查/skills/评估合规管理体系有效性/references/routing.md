# 边界与路由

## 正触发

公司已有合规管理办法、举报、礼品或第三方等制度或其运行痕迹，需要判断体系是否有效运转。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要企业级风险总图 | `评估企业合规风险总图` |
| 要从零设计体系框架 | `设计合规管理体系框架` |
| 开展正式有效性评价项目 | `开展合规有效性评价` |
| 单件线索要不要立案 | `评估是否启动内部调查` |
| 只要董事会汇报提纲 | `准备董事会合规汇报材料` |
| 刑事辩护、控告、自首 | 刑事领域 |
| 劳动处分、解除、职场违纪调查 | 劳动领域 |
| 个人信息、数据出境、网安体系整案 | 数据隐私领域 |
| 垄断、经营者集中、反垄断调查主轴 | 竞争法领域 |
| 未进入合规机制的合同改稿 | 审查起草领域（本窗搁置，只说明） |
| C 端小微体检 / 供应商清单 / 广告 / 隐私 / 劳动规章 | 大众专项，只分流不回改 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、取保、阅卷、辩护词、刑事控告、自首 | 刑事领域 |
| 劳动合同、工资、解除、工伤、职场性骚扰主轴 | 劳动领域 |
| 个人信息合法性、影响评估、出境、等保、网安事件专项整案 | 数据隐私领域 |
| 垄断协议、滥用支配地位、经营者集中、反垄断调查主轴 | 竞争法领域 |
| 税务处理决定、稽查实体 | 税务领域 |
| 银行保险机构行业合规办法 | 金融领域 |
| 药品购销回扣行业细则 | 医疗医药领域 |
| 出口管制、制裁名单 | 涉外领域 |
| 尚未进入合规机制的交易合同改稿 | 审查起草领域（本窗搁置，只说明不实施） |

综合合规或内部调查主轴可留本任务；专项只作为背景时在缺口标明，不把专项规则写入本任务结论。


## 易混

制度齐备但无运行证据时，不得写成体系有效。有效性评价项目（抽样方案、缺陷分级）走 evaluate 原子，本任务只做五维差距。
