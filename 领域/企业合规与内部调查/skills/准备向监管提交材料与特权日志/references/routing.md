# 边界与路由

## 正触发

检查文书已到或材料调取已开始，需要交卷三态清单、扣下理由、副本控制与特权日志回链，而不是现场应对、工作产品标记专项、主动披露或出境方案。从零、碎片、文书范围未核验、无书面交卷授权仍正触发：有材料或文书则闸开或半开，出 `SL#` 草案，保持草案。全面配合即全部交出、扣下即藏匿、抄送法务即特权、ACP 即免交、交清单即从轻、待核即可拖延、保证过关，仍正触发。

双方秘密、指导伪造补件、藏匿范围内材料、拖延转移、阻挠合法检查、编造特权日志对抗检查、打击报复的停止，优先于负触发。上述信号不在下表。「全面配合即全部交出」「扣下即藏匿」「抄送法务即特权」「ACP 即免交」「交清单即从轻」「待核即可拖延」「保证过关」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 现场与首轮检查应对 | `应对监管检查或突击检查` |
| 尚未被查的现场预案 | `制定突击检查现场预案` |
| 律师工作产品标记专项 | `评估律师工作产品与保密边界` |
| 主动书面披露或自查报告 | `准备主动披露或自查报告` |
| 对内持有或禁毁通知 | `准备证据保全与禁毁通知` |
| 数据出境或境外调取方案 | 数据隐私领域或 `协调跨境内部调查并分流涉外` |
| 行政复议或行政诉讼文书 | 行政争议领域 |
| 税务稽查实体 | 税务领域 |
| 反垄断调查交卷主轴 | 竞争法领域 |
| 刑事侦查、辩护或阅卷 | 刑事领域 |
| 劳动处分或解除 | 劳动领域 |

不得因「不保证从宽」或「不代提交」或「今天视为已提交」关窗。拟交仍正触发，不得写成已提交或已从宽。人选或材料冲突不得关窗。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、解除、工伤主轴 | 劳动领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |
| 垄断、滥用支配、经营者集中 | 竞争法领域 |
| 税务处理决定、稽查实体 | 税务领域 |
| 银行保险机构行业合规办法主轴 | 金融领域 |
| 药品购销回扣行业细则主轴 | 医疗医药领域 |
| 出口管制、制裁名单 | 涉外领域 |
| 章程、股权、任免本身为主成果 | 公司治理领域 |

综合交卷清单主轴可留本任务。审查起诉或检查只作背景，主成果才转。专项只作为背景时在缺口标明，不把专项规则写入本任务结论。出现「交卷」「特权」「清单」一词不是转出。

## 易混

交卷清单不是已经获得从宽。扣下不是藏匿。超范围记录异议、不擅自扩大，不等于关门藏物。抄送法务不是中国法特权。律师在场不是免交。美国 ACP 不是中国法免交理由。标记不是已免交。待核不是拖延合法检查。全面配合不是全部交出。群已读不是已提交。证据材料目录范本不是法定交卷格式，更不是已提交。律师法第三十八条是对委托人的保密，不是对抗合法调取。行政处罚法第三十二条交材料不等于从轻。本窗 `SL#` 不是期限卡，不是 `WP#` 标记行。空白特权不得扣光。阻挠写入扣下理由该格不支持；要方法藏范围内材料才整体停止。「先补假纪要再交」整体停止。本窗不执行发送，不代提交。审查起诉只作背景，主成果才转刑事。
