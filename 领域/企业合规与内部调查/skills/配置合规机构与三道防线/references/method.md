# 评估方法

本文件是可执行判断节点。拟设不是已任命，不是已到岗，不是已独立，不是已合规。挂名总监不是三道已建立。合同审核不是二道。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、监管已认可、范本填满、唯一截止日、选定机关、代提交、未知写零。本任务不定罪，不写任免决议，不写劳动合同，不代任免。本窗 `P#` 是岗位行，不是验收计划。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、2018 年《中央企业合规管理指引（试行）》当现行 42 号令、把 42 号令或第一百七十七条套民企、把第十二条写成必须新增副总、把任命总监写成已建立、把合同审核写成二道、把 FCPA 写成中国法义务、把范本当已任命证明时记为噪声。禁止指导伪造任命或删除会计资料。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`P#` 固定列：`编号｜防线（一／二／三）｜岗位／机构｜职责要点｜汇报（实线／虚线／越级）｜授权边界｜兼岗与隔离｜E#回链｜判断三值｜缺口G#｜最强反方｜待核`。禁止合成「已建立三道防线」一笔。`E#` 只作证据形态回链。缺项记 `G#`，不得用「参照最佳实践」或范本栏目填满。扫描不是闭集。禁止无防线归属的「全面合规」空岗。

口头「已经有合规总监」「群里宣布了」「邮件已发就是报告线已生效」只进 `S#`／`V#`，**不得算作开闸材料**。已读、快递揽收不得升格 `R#` 已送达，不得升格任命已生效。口头备份不等于已保全。口头知情不是已履职。名片、挂名不是已授权。`A#` 是承认，不是已任命。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

配置闸打开（可出 `P#` 草案，仍不得标「已任命／三道已建立／监管已认可／已免责终稿」）须同时满足：单方无冲突公司立场已闭合；主成果是本实体三道防线岗位配置，不是任免文书、劳动合同、框架图或办法全文；至少一项可编号拟设岗位或现有组织碎片。从零配置：有拟设岗位即可开闸或半开，缺项记 `G#`。书面配置授权未闭合但已有拟设岗位：部分打开，不得因无授权文件关掉拟设岗位草案。口头已设 CCO、已读揽收、名片挂名不算开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

配置闸部分打开：主体、报告线或编制未闭合，但已有可编号岗位范围；对应格待核；仍交十节；不得标终稿 `已形成`。无书面配置授权但有拟设岗位：部分打开。

配置闸关闭（仍正触发）：无一拟设岗位且无一组织碎片。「今天必须出已任命／已建立终稿」而无最小事实不得开闸。无书面配置授权但已有拟设岗位：部分打开，不是关闭。不出 `P#` 终稿。**仍交十节**，第 5 节只交闸／`Q#` 状态，第 6 节不出 `P#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「已经建立」或「没有缺口」。

「任命一名合规总监即三道已建立」「合同审核岗即二道」「同一人兼任一二道仍称已独立」「仅向被监督业务分管领导汇报仍称独立」「配置即免责或交表即从轻」「民企必须按 177 或 42 号令设首席合规官并上报」「第十二条必须新增副总级岗位」「把 FCPA 或萨班斯三道写成中国法义务」「范本即法定格式或已任命」「群已读或邮件已发即已任命／报告线已生效」「保证监管认可」「人数未知先写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `P#` 草案。闸未开才不出 `P#` 终稿。民企套 42 号令不得负触发到 `评估国企合规管理办法差距`，不得建议上报国务院国资委。小企业无法分设三部门：出兼岗隔离 `P#` 草案，独立性格不支持，替代方案≠已隔离，**不是关闸**。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无一拟设岗位且无一组织碎片，then 配置闸关闭，仍交十节，不是整体停止。
若 if 公司立场已闭合、无书面配置授权但已有拟设岗位，then 配置闸部分打开，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象或候选人相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造任命、组织图、隔离或汇报记录、倒签任命、伪造监管已认可、指导删除会计资料、借配置稿平行灭证、打击报复，或要方法阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

名称、规模、是否中央企业／国家出资公司／上市分列。不自动合并。独立法人子公司不与母公司自动合并。分公司与子公司分列（民法典第七十四条与公司法第三条分列，写入 `L#` 前须核验）。

检索锚点（写入 `L#` 前须核验）：

- 公司法第一百六十八条：国家出资公司不含参股。第一百七十七条仅国家出资公司对内合规，不是对外交稿或民企设岗义务。
- 42 号令第二条、第四十条：只约束中央企业；第四十条是对地方国资机构的参照指导。地方国企不自动承受第二条义务，地方细则未核＝字段停止。民企岗位是内部治理文本，强制对照行删除，该格 `现有依据不支持`，不关窗。不得建议民企上报国务院国资委。
- 42 号令第八条（四）：董事会决定合规管理部门设置及职责，只约束中央企业。
- 42 号令第十条至第十五条：主要负责人、合规委员会、首席合规官、业务及职能部门与合规管理员、合规管理部门、纪检监察／审计等监督部门。第三道不得写死成「仅内审」。
- 42 号令第十二条：设立首席合规官，不新增领导岗位和职数，由总法律顾问兼任。央企要新设副总级 CCO：该格不支持「法定必须新增副总职数」，仍可出「总法律顾问兼任、不新增职数」`P#`。民企要设副总级合规负责人：允许作为内部治理；禁止写成第十二条义务，也禁止用第十二条禁止民企新增。
- 42 号令第二十一条：重大决策合规审查意见由首席合规官签字。签字接口≠已审查、已履职。
- 42 号令第二十二条：第一款向本企业合规管理部门报告；第三款中央企业重大事件向国资委报告。禁止内报填国资委空格。
- 42 号令第三十九条：推动所属单位≠已覆盖。
- 42 号令第八条（三）／第十四条（三）／第二十七条是评价，不是第二十三条整改；本窗只开接口。
- 公司法第三条：公司有独立法人财产。总部任命不能直接在独立法人子公司生效，须子公司有权机关决定；该格不得写已任命／已覆盖。本窗仍可出子公司拟设 `P#`。主成果才转 `评估集团与子公司合规穿透` 或 `落地集团政策到境内实体`。
- 劳动合同法：岗位、解除只开接口，本窗不做完合同正文或民主程序证据。
- 不得把美国《反海外腐败法》或萨班斯三道防线写成中国法定义务；可作非强制对标并标明法域。
- 行政处罚法第三十二条：提交配置表不等于情节成就。
- 民营经济促进法第三十九条是支持引导依法合规，不是必须按 42 号令设岗上报。

国企适用办法条款才写入强制项。强制接口与非强制对标分列，不选对用户有利的一版。金融机构行业合规办法与 42 号令适用范围不同，主轴转金融领域。

民企可出类三道防线 `P#` 草案，必须标「内部治理／非强制对标」，禁止写成 42 号令已履行。

## 节点 3　岗位行 `P#`

本任务岗位范围按已出现需求扫描，不是默认闭集：合规负责人／首席合规官、合规委员会、合规管理部门、业务及职能部门合规管理员、监督部门（纪检监察／审计等）、报告线（实线／虚线／越级）、授权边界、兼岗隔离。缺项记 `G#`，不得用「参照最佳实践」或范本栏目填满。

一道：业务及职能部门风险所有权和日常控制；合规管理员接受二道指导，不是把一道写成二道。二道：合规政策、咨询、监测、调查接口；法务合同审核本身不是二道。三道：纪检监察、审计、巡视巡察、监督追责等依职权监督；合规部自己评价自己不是第三道独立。

每岗必须能指向防线、汇报对象和授权边界。禁止「全面合规」无主句；无防线归属则删除或改 `G#`。无 `E#` 不得写已配置、已任命或已独立。

挂名：有头衔无索取材料权、无升级董事会通道、无隔离 → 已建立／已授权／已履职格 `现有依据不支持`，仍出其他 `P#`（无权限、无报告线、无授权边界）。

兼岗：销售、采购、财务出纳与合规兼岗必须列出替代方案。替代方案≠已隔离。同一人兼任一二道且无隔离：独立性 `现有依据不支持`。小企业无法分设：仍出兼岗隔离草案，不是关闸。

授权清单（拟授权草案，不是已授权）：可写索取材料、建议暂停高风险交易、启动初核、向董事会或审计委员会升级。禁止写成已授权：解除劳动合同、划走账户、对外披露、阻挠合法检查、人事处分权。建议权不得升格处分权。阻挠检查写入授权清单＝该格不支持（不关窗）；要方法挡检查或隐匿＝整体停止。外包只写独立性、保密、禁止转委托条件，不签服务合同正文。
