# 评估方法

本文件是可执行判断节点。任命一人不是三道防线已建立。合同审核岗不是合规二道。挂名无授权不是已配置。列出岗位不是已运转。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、监管必然认可、范本填满、唯一截止日、选定机关、代提交、未知写零。本任务不任免、不写劳动合同、不定罪。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1993 公司法第六十七条国有资产监督管理、把 42 号令或第一百七十七条套民企、把任命写成已建立、把 FCPA／COSO 写成中国法义务时记为噪声。禁止指导伪造任命或删除会计资料。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`OR#` 固定列：`编号｜防线（一／二／三）｜岗位／委员会｜汇报对象（实／虚／越级）｜授权边界｜兼岗与隔离｜E#回链｜判断三值｜缺口G#｜最强反方｜待核`。禁止合成「三道防线已建立」一笔。`E#` 只作证据形态回链。缺项记 `G#`，不得用「参照最佳实践」或范本栏目填满。扫描不是闭集。

口头「已经有人管合规」「群已读任命」「你兼合规就行」只进 `S#`／`V#`，**不得算作开闸材料**。已读、揽收不得升格 `R#`。口头知情不是已履职。挂名不是已授权。`A#` 是承认，不是已任命。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

## 节点 0　分流、立场、配置闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。伪造任命、倒签授权、指导删除、平行灭证、打击报复、阻挠合法检查、双方秘密不进负表。

整案转出只交付第 1、2、10 节，不出 `OR#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是董监高履职缺口或追偿 | 负触发 `评估董监高合规职责缺口` |
| 主成果是任免、章程、股东会本身 | 整案转公司治理 |
| 主成果是劳动合同或岗位聘书正文 | 整案转劳动 |
| 主成果是只要框架不要岗位 | 负触发 `设计合规管理体系框架` |
| 主成果是章程级办法正文 | 负触发 `起草合规管理办法或章程级制度` |
| 主成果是已有体系是否运转 | 负触发 `评估合规管理体系有效性` |
| 主成果是调查授权书终稿 | 负触发 `确定调查授权范围与独立` |
| 主成果是回避决定终稿 | 负触发 `处理利益冲突与调查回避` |
| 主成果是监管人人选终稿 | 负触发 `设置合规监管人或独立监察` |
| 主成果是 42 号令对照终稿 | 负触发 `评估国企合规管理办法差距` |
| 银行保险行业合规办法主轴 | 整案转金融 |
| 侦查、起诉、辩护为主成果 | 整案转刑事 |

审查起诉、监管检查只作程序背景。主成果才整案转。

配置闸打开（可出 `OR#` 草案，仍不得标「已建立／已运转／监管已认可／已任命」）须同时满足：单方无冲突公司立场已闭合；主成果是机构／防线／报告线／授权边界，不是任免、劳动合同、框架或履职终稿；存在书面配置授权；至少一项可编号拟设岗位或现行组织碎片。口头任命、挂名、合同审核岗不算开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

配置闸部分打开：主体或报告线未闭合，但已有可编号范围与书面授权；对应格待核；仍交十节；不得标终稿 `已形成`。

配置闸关闭（仍正触发）：公司立场已闭合但无书面配置授权；无一拟设岗位且无一组织碎片。「今天必须出已配置证明」而无最小事实不得开闸。不出 `OR#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `OR#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「已经建立」或「没有缺口」。

「任命一名合规总监即三道已建立」「合同审核岗即二道」「口头任命即已履职」「挂名即已授权」「同一人兼任一二道仍称独立」「保证监管认可人选」「民企必须按 177 或 42 号令第 12 条设 CCO 且不新增职数并上报」「把 FCPA／COSO 写成中国法义务」「配置即免责或应当从轻」「纸面组织图即已运转」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `OR#` 草案。闸未开才不出 `OR#` 终稿。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无书面配置授权，then 配置闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造任命或组织图、倒签授权、指导删除会计资料、借配置稿平行灭证、打击报复或阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

名称、规模、是否中央企业／国家出资公司／上市分列。不自动合并。独立法人子公司不与母公司自动合并。

检索锚点（写入 `L#` 前须核验）：

- 公司法第六十七条：董事会决定内部管理机构的设置，不等于本窗已出任免或已配置完成。噪声：1993 年第六十七条国有资产监督管理。
- 公司法第一百六十八条：国家出资公司不含参股。第一百七十七条仅国家出资公司对内合规，不是民企必须设 CCO 或法定报告线。
- 42 号令第二条、第八条、第九条、第十一条、第十二条、第十三条、第十四条、第四十条：只约束中央企业。第十二条首席合规官由总法律顾问兼任、不新增领导岗位和职数。第十三条业务部门主体责任并设合规管理员。第十四条合规管理部门职责。第四十条是对地方国资机构的参照指导。民企硬套：该格 `现有依据不支持`，强制对照行删除，不关窗。不得建议民企上报国务院国资委。
- 公司法第三条：公司有独立法人财产。总部不能直接在独立法人子公司设岗生效，只开接口到 `落地集团政策到境内实体`。
- 金融机构合规管理办法与 42 号令适用范围不同。行业办法主轴转金融领域。出现「合规」一词不是转出。
- 不得把美国《反海外腐败法》或萨班斯／COSO 三道防线写成中国法定义务；可作非强制对标并标明法域。
- 行政处罚法第三十二条：提交配置草案不等于情节成就。

国企适用办法条款才写入强制项。强制接口与非强制对标分列，不选对用户有利的一版。

## 节点 3　岗位／防线行 `OR#`

一道：业务部门风险所有权和日常控制。二道：合规政策、咨询、监测、调查接口。三道：内部审计独立评价。按已出现需求扫描，不是默认闭集；缺项记 `G#`。

若「合规部」实际只做法务合同审核：二道未建立，记缺口，不把合同审核写成合规管理体系。交易合同审核属审查起草，本窗搁置。

每岗必须能指向汇报对象。仅向被监督的业务分管领导汇报：独立性 `现有依据不支持`。合规负责人向董事会或审计委员会报告重大风险：作为设计接口，不是已履职。

同一人兼任一二道且无隔离：独立性格 `现有依据不支持`，**不关窗**；可列替代方案（独立二道、向董事会／审计委员会虚线），替代 ≠ 已隔离。销售、采购、财务出纳与合规兼岗必须列出替代方案。

可描述授权：索取材料、建议暂停高风险交易、启动初核、升级董事会。不可在本任务授权：解除劳动合同、划走个人账户、对外披露、阻挠合法检查、人事处分。不得把建议权写成人事处分权。

外包调查或监测：可写独立性、保密和禁止转委托条件，不签服务合同正文。

## 节点 4　可逆性与转介

任免、劳动合同、调查授权、回避、监管人人选只开接口。劳动民主程序和任免决议证据不在本窗做完。

可逆动作与不可逆动作分列。不可逆（对外披露、处分、终止第三方、发送任免）不得在草案阶段实施。禁止提交指令。不代任免、不代签合同。

下一步只转介：框架、办法、履职缺口、42 号令对照、调查授权、回避、监管人、集团落地、董事会汇报。禁止一次写完全部邻窗终稿。

已有监察或检查 `R#`：不得借配置稿平行灭证。刑法第一百六十二条之一只作红旗，不得指导删除。
