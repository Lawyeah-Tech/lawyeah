# 边界与路由

## 正触发

公司要配置合规机构、三道防线和报告线，而不是作出任免或签署劳动合同。组织图碎片、兼岗、授权未核验仍正触发：配置闸关闭则不出 `OR#` 终稿，窗口不关。任命即已建立、合同审核即二道、保证监管认可、民企套 12 条或 177、一二道兼岗仍独立、FCPA 当中国法，仍正触发。

双方秘密、伪造任命、倒签授权、指导删除、平行灭证、打击报复、阻挠合法检查的停止，优先于负触发。上述信号不在下表。「任命即已建立」「合同审核即二道」「保证监管认可」「民企套 42 号令」「FCPA 当中国法」不在下表。「不任免」「不写劳动合同」「不保证监管认可」是交付禁令，不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 董监高履职缺口或追偿终稿 | `评估董监高合规职责缺口` |
| 任免、章程、股东会本身 | 公司治理领域 |
| 劳动合同、岗位聘书或薪酬正文 | 劳动领域 |
| 只要框架不要岗位 | `设计合规管理体系框架` |
| 章程级办法正文 | `起草合规管理办法或章程级制度` |
| 已有体系是否运转 | `评估合规管理体系有效性` |
| 调查授权书终稿 | `确定调查授权范围与独立` |
| 回避决定终稿 | `处理利益冲突与调查回避` |
| 监管人或独立监察人选终稿 | `设置合规监管人或独立监察` |
| 42 号令对照终稿 | `评估国企合规管理办法差距` |
| 银行保险行业合规办法主轴 | 金融领域 |
| 刑事辩护、控告 | 刑事领域 |

不得因「保证监管认可」或「要求按第 12 条设 CCO」或「任命即已建立」关窗。无书面授权仍正触发，不得写成已建立。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、解除、工伤主轴 | 劳动领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |
| 垄断、滥用支配、经营者集中 | 竞争法领域 |
| 章程、股权、任免本身为主成果 | 公司治理领域 |
| 银行保险机构行业合规办法主轴 | 金融领域 |
| 药品购销回扣行业细则主轴 | 医疗医药领域 |
| 税务处理决定、稽查实体 | 税务领域 |
| 出口管制、制裁名单 | 涉外领域 |

综合合规机构配置主轴可留本任务。审查起诉或检查只作背景，主成果才转。出现「合规」一词不是整案转出。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 董监高是否履职、要不要追偿 | `评估董监高合规职责缺口` |
| 只要框架图不要岗位 | `设计合规管理体系框架` |
| 章程级办法全文 | `起草合规管理办法或章程级制度` |
| 确为中央企业且主成果是 42 号令对照 | `评估国企合规管理办法差距` |
| 调查授权书 | `确定调查授权范围与独立` |
| 回避名单或替代调查主体 | `处理利益冲突与调查回避` |
| 独立监察人人选条件 | `设置合规监管人或独立监察` |
| 集团／境外模板要在境内独立法人设岗生效 | `落地集团政策到境内实体` |

## 易混

任命一名「合规总监」不是三道防线已建立。合同审核岗不是合规二道。挂名负责人无授权不是已配置。列出岗位不是已运转。口头任命不是已履职。仅向被监督业务分管领导汇报不是独立。民企套 42 号令第 12 条或第一百七十七条：该格不支持，不关窗。FCPA／COSO 对标不是中国法义务。总部印发不能直接在独立法人子公司设岗生效。「先补假任命再出已配置稿」整体停止。任免决议和劳动合同不在本窗。
