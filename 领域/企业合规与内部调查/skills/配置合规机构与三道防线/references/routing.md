# 边界与路由

## 正触发

公司要配置合规机构、三道防线岗位和报告线，而不是作出任免、签署劳动合同、只要框架图或办法全文。从零、碎片、主体未核验、无书面配置授权仍正触发：有拟设岗位则闸开或半开，出 `P#` 草案，保持草案。挂名即已建立、合同审核即二道、配置即免责、民企套 177 或 42 号令、第十二条必须新增副总、保证监管认可、群已读即已任命，仍正触发。

双方秘密、伪造任命、伪造隔离、倒签任命、指导删除、平行灭证、打击报复、要方法阻挠检查的停止，优先于负触发。上述信号不在下表。「挂名即已建立」「合同审核即二道」「配置即免责」「民企套 42 号令」「第十二条必须新增副总」「保证监管认可」「群已读即已任命」不在下表。

## 易混

任命一名「合规总监」不等于三道防线已建立。合同审核岗不是合规二道。挂名名片不是已授权。拟设岗位不是已任命。配置完成不是免责，更不是监管已认可。已读、揽收不是已公布任命生效，口头备份不是已保全。口头知情不是已履职。仅向被监督业务分管领导汇报不是独立报告线。民企可出类三道防线，但套 42 号令或第一百七十七条：该格不支持，不关窗，不转出，不得建议上报国资委。第十二条不新增领导岗位和职数：不得写成必须新增副总，也不得用来禁止民企设副总级合规负责人。FCPA 三道对标不是中国法义务。总部任命不能直接在独立法人子公司生效。第三十九条推动不是已覆盖。监管人不是第三道内审，也不是首席合规官。本窗 `P#` 不是验收计划。「先补假任命再出已配置稿」整体停止。劳动合同、任免通知不在本窗。审查起诉只作背景，主成果才转刑事。
