# 边界与路由

## 正触发

有可编号的招标、许可、执法、国企采购、验收或拨款接触碎片，需要接触点地图与批准记录规则，而不是出礼品单笔终稿、风险图、账外专项或刑事定性。身份未核验仍正触发：有可编号接触碎片则公职闸开或半开，出 `GZ#` 草案。见过官员即行贿、国企员工即监察对象或国家工作人员、口头点头即已批准、事后补纪要即已批准、本表已定罪，仍正触发。身份不足仍正触发。

双方秘密、指导向公职人员或评标人行贿或送礼、指导串供、伪造或倒签接触或批准记录、打击报复、阻挠合法检查的停止，优先于负触发。上述信号不在下表。「见过官员即行贿」「国企员工即监察对象」「口头点头即已批准」「事后补纪要即已批准」「本表已定罪」不在下表。「不辩护职务犯罪」「不定行贿罪」「身份不足则字段停止」是交付禁令，不在下表。出现「公职」「招标」「官员」一词不是转出。

## 易混

接触不是行贿。见过官员不是行贿既遂。国企员工不是监察对象，也不是当然国家工作人员。国家出资企业一般合同制工作人员不当然属于国家工作人员。评标委员会组成人员原则上按非国家工作人员路径待核，其中的国家机关代表才开受贿接口。身份不足该格停止，窗口不关，仍做高风险接触管理。事后补纪要不是已批准。口头点头不是已批准。临近招标、评标、许可或拨款不得标接触已合法。政务处分法第三十四条只开公职受礼接口，不定罪。1988 年国内公务活动礼品规定约束行政机关工作人员，不是民企可送抗辩。监察法第十五条国有企业管理人员不是全部国企员工。不辩护职务犯罪、不定行贿罪、身份不足则字段停止是交付禁令，不是负触发。口头「见过领导」不是单独开闸材料。可编号接触碎片才开闸。指导向公职行贿或串供是第一次整体停止，不是不关窗。利益冲突未解不是本窗整体停止。本窗 `GZ#` 不是礼品审查行 `GF#`，不是账外行 `XB#`。
