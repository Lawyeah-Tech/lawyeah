# 梳理方法

本文件是可执行判断节点。接触闸打开不等于已行贿不等于已穷尽不等于已批准接触。接触不是行贿。见过官员不是行贿既遂。国企员工或国企客户经办人不当然国家工作人员或监察对象。身份不足该格字段停止，窗口不关，仍可做内部高风险接触管理。事后补纪要不是已批准。口头点头不是已批准。双人在场不是已合法。正常公务接待不是一律合法。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、刑事既遂、选定机关、代提交、未知写零。本窗不定罪，不辩护职务犯罪，不写礼品允许表，不写风险图终稿。本窗 `TP#` 是接触点行，不是礼品审查行 `GF#`，不是风险点 `BR#`，不是义务行 `O#`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、已失效《行政监察法》、把见过官员写成行贿、把全部国企员工写成国家工作人员时记为噪声。禁止指导行贿、串供、倒签纪要。禁止 `search_template` 生成已合法接触清单或已行贿证明。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现接触碎片扫描，不是默认闭集。
`TP#` 固定列：`编号｜事项（招标／许可／执法／国企采购／验收／拨款／其他）｜对方身份待核（公职／监察对象／国有单位人员／利用影响力／待核）｜我方人员｜时点窗口（决策窗口／非窗口／待核）｜批准留痕（事先书面／双人在场／纪要／口头或无／事后补／待核）｜禁止利益（礼品／就业许诺／报销／特定关系人合同／中介代送／无／待核）｜E#回链｜判断三值｜G#｜最强反方｜状态`。接触 ≠ 行贿。身份不足＝该格字段停止，仍出该行其他格。批准留痕 ≠ 已合法。双人在场 ≠ 已合规。事后补纪要＝版本冲突，不得治愈。禁止利益打开＝红旗／转介，≠ 已贿赂。无 `E#` 不得写已覆盖、已穷尽、已行贿。`E#` 只作证据形态回链。缺项记 `G#`。扫描不是闭集。状态默认 `草案`。

口头「见过局长」「国企客户都是公职」「都是正常接待」只进 `S#`／`V#`，**不得单独算作开闸材料**。名片不是已核验身份。纪要能开闸，不能升格已批准。`A#` 是承认该次接触存在，不是已合法。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

## 节点 0　分流、立场、接触闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、指导行贿、指导串供、伪造或倒签纪要、打击报复、阻挠检查不进负表。

整案转出只交付第 1、2、10 节，不出 `TP#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是廉洁风险图 | 负触发 `评估反商业贿赂风险点` |
| 主成果是单笔礼品招待审查 | 负触发 `审查礼品招待赞助与捐赠` |
| 主成果是礼品招待制度终稿 | 负触发 `设计反商业贿赂与礼品招待制度` |
| 主成果是回扣账外资金链路终稿 | 负触发 `评估回扣账外暗中与资金链路` |
| 主成果是中间人费用终稿 | 负触发 `评估中间人费用与资金链路` |
| 主成果是经销商代理中介筛查终稿 | 负触发 `筛查经销商代理中介廉洁风险` |
| 主成果是义务—主体地图终稿 | 负触发 `建立合规义务与责任主体地图` |
| 主成果是是否启动内部调查 | 负触发 `评估是否启动内部调查` |
| 主成果是调查报告终稿 | 负触发 `形成内部调查报告` |
| 主成果是药品购销回扣行业细则 | 整案转医疗 |
| 主成果是垄断或反垄断调查专项 | 整案转竞争法 |
| 主成果是刑事辩护、控告或自首 | 整案转刑事 |
| 「不定行贿罪」「不辩护职务犯罪」「身份不足则字段停止」 | 交付禁令，不是负触发 |

审查起诉、监管检查、已立案只作程序背景。主成果才整案转。出现「公职」「官员」「招标」一词不是转出。已有监察或刑事：企业接触规则不得用于串供；主成果仍是接触点地图可留窗。

接触闸打开（可出 `TP#` 草案，仍不得标「已行贿／已穷尽／已合规」）须同时满足：单方无冲突公司立场已闭合；主成果是接触点与审批草案；至少一条可编号接触碎片。会议纪要（点名对方／事项／时点）、拜访记录、招标文件经办人栏、许可窗口对接记录、执法检查接待记录、项目对口机关清单、中介介绍、事先批准单可编号开闸。口头「见过局长」不算单独开闸材料。身份不足不是关闸条件。双方秘密或第一次伪造不是关闸条件，走整体停止。

接触闸部分打开：已有可编号碎片，但授权、身份、时点、批准未闭合；或无书面评估授权但已有件。对应格待核；仍交十节；不得标终稿 `已形成`。

接触闸关闭（仍正触发）：无一可编号接触碎片。「今天必须出已穷尽／已行贿终稿」而无最小件不得开闸。不出 `TP#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `TP#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关写成「没有公职接触」或「已合规」。

「见过官员即行贿」「国企员工即国家工作人员／监察对象」「接触即已穷尽」「接触闸打开即已行贿」「双人在场即已合规」「有纪要即已批准」「事后补纪要可治愈」「正常公务接待一律合法」「交接触表即从轻／自首」「民企必须按 42 号令专项」「FCPA 即中国法已允许」「本表已定罪」「身份不足故关窗」**不关窗**。对应格 `现有依据不支持` 或身份格字段停止。闸已开仍出其他 `TP#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无一可编号接触碎片，then 接触闸关闭，仍交十节，不是整体停止。
若 if 单方立场已闭合、无书面授权但已有可编号碎片，then 接触闸部分打开，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象或相对方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出指导行贿、指导串供或统一口径、指导补假批准或倒签纪要、伪造接触清单、打击报复、阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体、接触碎片与强制接口

一行一个接触碎片。缺项记 `G#`，未知金额不得写 `0`。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 事项 | 招标／许可／执法／国企采购／验收／拨款，分列 | 合成「都见过官员」 |
| 身份 | 公职／监察对象／国有单位人员／待核 | 国企经办人即国家工作人员 |
| 时点 | 决策窗口／非窗口／待核 | 窗口内标已合法 |
| 批准 | 事先书面／口头或无／事后补／待核 | 口头即已批准 |
| 施行日 | 行为时点 | 跨法用唯一条文 |

检索锚点（写入 `L#` 前须核验）：刑法第九十三条国家工作人员范围须核验「从事公务」，不得把全部国企员工写成国家工作人员。监察法第十五条监察对象含国有企业管理人员等，不等于全体国企员工即监察对象。公职人员政务处分法第三十四条只开公职受礼接口，不定罪。1988 年国内公务活动礼品规定约束行政机关工作人员，不是民企可送抗辩。反不正当竞争法（2025）第八条利用职权或影响力影响交易只开接口，接触不等于给予财物。刑法第三百八十五条、第三百八十八条、第三百八十九条、第三百九十一条、第三百九十三条只作红旗，不定罪。监察法第十八条如实提供，不得伪造、隐匿、毁灭。行政处罚法第三十二条交接触表 ≠ 从轻。刑法第六十七条交表 ≠ 自首。42 号令只约束中央企业。FCPA 不是中国法义务。本节禁止出 `TP#` 终稿。

## 节点 3　接触点行 `TP#`

按已出现接触碎片扫描，不是默认闭集。建议行型（出现才用）：

| 编号 | 含义 | 本窗允许 | 禁止 |
| --- | --- | --- | --- |
| `TP-招` | 招标评标 | 接触行草案 | 见过评委即行贿 |
| `TP-许` | 许可窗口 | 接触行草案 | 窗口宴请即已合法 |
| `TP-执` | 执法检查 | 接触行草案 | 接待即已过关 |
| `TP-采` | 国企采购 | 身份待核 | 经办人即国家工作人员 |
| `TP-验` | 验收拨款 | 窗口内允许利益路径不打开 | 验收前礼品即合法 |
| `TP-中` | 中介代接触 | 红旗，转介 | 中介在场即已行贿 |

热冲突强制处理：

- 见过官员即行贿／国企经办人即国家工作人员／接触即穷尽／双人在场即已合法／事后补纪要即已批准 → 该格不支持或身份格字段停止；仍出其他 `TP#`。
- 身份不足 → 该点公职属性字段停止，窗口不关。
- 评标窗口宴请、验收前礼品、中介代送、特定关系人就业 → 禁止利益红旗，只开礼品或第三方接口。
- 指导串供、指导行贿、倒签纪要 → 整体停止，不是该格不支持。

无 `E#` 不得写已覆盖、已穷尽或已行贿。状态 `草案`。一次只推荐下一步。

## 节点 4　礼品、中介、刑事接口与转介

第 7 节只开接口，不得夹带 `TP#` 终稿绕闸。闸关闭时第 7 节可写「闸未开，转介待接触编号」，不得补写已行贿或已批准。

不写礼品允许表、风险图终稿、中间人费用终稿、刑事文书。已有监察或刑事 `R#`：只开配合接口，不得统一口径或串供。不可逆（对外宣称已合法接触、签署虚假纪要）不得在草案阶段实施。禁止提交指令。不代提交。不代批准。不选定机关。

下一步只转介：`评估反商业贿赂风险点`、`审查礼品招待赞助与捐赠`、`设计反商业贿赂与礼品招待制度`、`评估回扣账外暗中与资金链路`、`评估中间人费用与资金链路`、`筛查经销商代理中介廉洁风险`、`评估账簿记录与虚假报销`、`评估是否启动内部调查`、`形成内部调查报告`、`应对监管检查或突击检查`、`设计第三方合规管理机制`、刑事领域。

若 if 用户催促「按零写／填满已行贿或已穷尽终稿」，then 该格 `现有依据不支持`，窗口不关。
若 if 金额未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「接触闸与接触点草案」。本窗不执行发送。不包含：已行贿证明、已批准证明、已穷尽证明、礼品允许表、风险图、刑事意见。禁止选边治愈。禁止见过官员即行贿。禁止国企经办人即国家工作人员。禁止交表即从轻或自首。禁止民企套 42 号令必须专项。禁止用接触规则串供。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标接触终稿已形成。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：民企待批许可窗口，销售带礼见过窗口经办人。用户主张见过官员就是行贿、国企窗口就是监察对象、不定行贿所以直接标已穷尽已合规。接触闸打开。`Q-见`、`Q-国`、`Q-穷` 不打开为已行贿／已穷尽。第 6 节见过即行贿格 `现有依据不支持`；身份格字段停止；仍出事项、时点、批准、禁止利益其他 `TP#` 草案。第 7 节只开礼品接口。不关窗。不定罪。不得标终稿已形成。

场景②：用户同时交公司接触清单与被调查销售抗辩，要求选边，并指导统一口径、补一纸批准、中介代送礼。命中双方秘密＋指导串供＋指导补假批准。第一次整体停止。只交第 1、10 节。不出 `TP#`。不得问代表哪一方后继续。
