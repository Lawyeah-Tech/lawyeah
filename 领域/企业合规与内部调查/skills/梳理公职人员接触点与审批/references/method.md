# 梳理方法

本文件是可执行判断节点。公职闸打开不等于已行贿不等于已批准接触不等于已合规。接触不是行贿。见过官员不是行贿既遂。国企员工不是监察对象，也不是当然国家工作人员。身份不足该格停止，窗口不关。事后补纪要不是已批准。口头点头不是已批准。临近招标、评标、许可或拨款不得标接触已合法。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。身份三态只用 `国家工作人员或监察对象`、`国有单位一般人员待核`、`非公职或依据不足`。决策窗口只用 `是`、`否`、`待核`。禁止胜诉率、必然免责、刑事既遂、选定法院、代提交、代批准、未知写零。本窗不定罪，不辩护职务犯罪，不写礼品单笔终稿，不写风险图终稿。本窗 `GZ#` 是公职行，不是礼品审查行 `GF#`，不是账外行 `XB#`，不是风险点 `BR#`，不是冲突行 `IC#`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、已失效行政监察法、把见过官员写成行贿、把国企员工写成监察对象时记为噪声。禁止指导向公职行贿、串供、伪造接触或批准记录。禁止 `search_template` 生成已批准接触清单或已合规证明。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现接触扫描，不是默认闭集。
`GZ#` 固定列：`编号｜场景（招标／许可／执法／国企采购／验收拨款／其他）｜对方身份三态（国家工作人员或监察对象／国有单位一般人员待核／非公职或依据不足）｜事项与时点｜我方接触人｜决策窗口（是／否／待核）｜批准与双人在场｜记录／纪要｜禁止利益红旗｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已行贿闭环」。无 `E#` 不得写已覆盖、已批准、已行贿。`E#` 只作证据形态回链。缺项记 `G#`。扫描不是闭集。接触 ≠ 行贿。见过官员 ≠ 行贿既遂。国企员工 ≠ 监察对象。事后补纪要 ≠ 已批准。决策窗口内 ≠ 接触已合法。

口头「见过领导」「国企客户都是公职」「接触过所以必须报行贿」「补一份纪要就算批准」只进 `S#`／`V#`，**不得单独算作开闸材料**。招标文件、许可窗口、执法检查通知、评标或验收纪要、对口人员名单、中介委托可编号开闸。`A#` 是承认该次接触存在，不是已行贿。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上国家出资企业一般合同制工作人员不属于国家工作人员；认定须看任命程序及是否代表负有管理、监督国有资产职责的组织。评标委员会组成人员原则上按非国家工作人员路径待核，其中的国家机关代表才开受贿接口。类案国有出资企业聘用人员在经国有企业批准进入领导班子前可能不是国家工作人员，身份时点分列。

## 节点 0　分流、立场、公职闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、指导向公职行贿或送礼、指导串供、伪造或倒签接触或批准记录、打击报复、阻挠检查不进负表。利益冲突未解不进整体停止。不辩护职务犯罪、不定行贿罪、身份不足则字段停止不进负表。

整案转出只交付第 1、2、10 节，不出 `GZ#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是礼品单笔审查 | 负触发 `审查礼品招待赞助与捐赠` |
| 主成果是廉洁风险图 | 负触发 `评估反商业贿赂风险点` |
| 主成果是回扣账外资金链路终稿 | 负触发 `评估回扣账外暗中与资金链路` |
| 主成果是反贿赂制度终稿 | 负触发 `设计反商业贿赂与礼品招待制度` |
| 主成果是中间人费用终稿 | 负触发 `评估中间人费用与资金链路` |
| 主成果是是否启动内部调查 | 负触发 `评估是否启动内部调查` |
| 主成果是调查报告终稿 | 负触发 `形成内部调查报告` |
| 主成果是药品购销回扣行业细则 | 整案转医疗 |
| 主成果是刑事辩护、控告或自首 | 整案转刑事 |
| 「不辩护职务犯罪」「不定行贿罪」「身份不足则字段停止」 | 交付禁令，不是负触发 |

审查起诉、监管检查、已立案只作程序背景。主成果才整案转。出现「公职」「招标」「官员」一词不是转出。

公职闸打开（可出 `GZ#` 草案，仍不得标「已行贿／已批准接触／已合规」）须同时满足：单方无冲突公司立场已闭合；主成果是接触点地图，不是礼品单笔、风险图或刑辩；至少一条可编号接触碎片。口头「见过领导」不算单独开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

公职闸部分打开：已有可编号接触碎片，但身份、窗口、批准、纪要未闭合；或无书面评估授权但已有碎片；对应格待核；仍交十节；不得标终稿 `已形成`。

公职闸关闭（仍正触发）：无一可编号接触碎片。「今天必须出已批准接触终稿」而无最小件不得开闸。不出 `GZ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `GZ#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关写成「没有公职风险」或「已合规」。

「见过官员即行贿」「国企员工即监察对象或国家工作人员」「身份不足即必然公职或必然无关」「口头点头即已批准」「事后补纪要即已批准」「交接触表即从轻或自首」「本表已定罪」「临近招标接触即已合法」「民企必须按 42 号令专项」「FCPA 即中国法已定罪」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `GZ#` 草案。上述行**不得写入可执行 `GZ#` 的已行贿或已批准结论**。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无一可编号接触碎片，then 公职闸关闭，仍交十节，不是整体停止。
若 if 单方立场已闭合、无书面授权但已有可编号碎片，then 公职闸部分打开，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象或相对方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出指导向公职人员或评标人行贿或送礼、指导串供、伪造或倒签接触或批准记录、打击报复、阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。
若 if 利益冲突未解但未要求隐瞒或伪造，then 窗口不关，不是整体停止。

## 节点 1　主体、接触碎片与强制接口

一行一个接触碎片。缺项记 `G#`，未知金额不得写 `0`。身份不足：该点身份格停止，窗口不关，仍做高风险接触管理。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 场景 | 招标／许可／执法／国企采购／验收拨款／其他 | 把清单写成闭集 |
| 对方身份 | 国家工作人员或监察对象／国有单位一般人员待核／非公职或依据不足 | 国企员工即监察对象；身份不足猜写成公职 |
| 决策窗口 | 临近招标评标许可拨款／非窗口／待核 | 窗口内标接触已合法 |
| 批准 | 书面事先／口头或无／待核 | 口头即已批准 |
| 纪要 | 当时记录／事后补／无 | 事后补即已批准 |
| 禁止利益 | 礼品宴请就业许诺特定关系人合同中介代送／无／待核 | 红旗即已行贿 |

检索锚点（写入 `L#` 前须核验）：监察法第十五条；实施条例第四十三条国有企业管理人员范围。刑法第九十三条。公职人员政务处分法第三十四条只开受礼接口。1988 礼品规定约束行政机关工作人员。反法（2025）第八条接触 ≠ 行贿。刑法第三百八十五条／第三百八十九条只作红旗。监察法第十八条不得伪造隐匿。行政处罚法第三十二条交接触表 ≠ 从轻。42 号令只约束中央企业。FCPA 不是中国法义务。本节禁止出 `GZ#` 终稿。

## 节点 3　公职行 `GZ#`

按已出现接触扫描，不是默认闭集。建议行型（出现才用，**不是闭集**）：

| 编号 | 含义 | 本窗允许 | 禁止 |
| --- | --- | --- | --- |
| `GZ-招` | 招标评标 | 决策窗口可见 | 窗口内标已合法 |
| `GZ-许` | 许可 | 决策窗口可见 | 见过经办人即行贿 |
| `GZ-执` | 执法检查 | 配合接口 | 统一口径脚本 |
| `GZ-国` | 国企采购 | 身份三态分列 | 国企员工即监察对象 |
| `GZ-验` | 验收拨款 | 决策窗口可见 | 接触即已行贿 |
| `GZ-中` | 中介在场 | 红旗可见 | 写成当然行贿 |

热冲突强制处理：

- 见过官员即行贿／国企员工即监察对象／口头即已批准／事后补纪要即已批准／窗口内标已合法 → 该格不支持；仍出其他 `GZ#`。
- 身份不足 → 该点身份格停止，窗口不关，仍做双人、事先批准、禁止利益管理。
- 就业许诺、特定关系人合同、中介代送 → 红旗；转礼品、第三方或回扣窗；本窗不定罪。
- 已有监察或刑事 `R#` → 只开配合接口；企业接触规则不得用于串供。
- 指导向公职行贿、串供、伪造纪要或双方秘密 → 整体停止，不是该格不支持。

事实不足以支持某公职行：该条 `依据不足，无法形成结论`，不关窗。无 `E#` 不得写已覆盖、已批准或已行贿。状态 `草案`。一次只推荐下一步。

## 节点 4　礼品、中介、刑事接口、禁止文书与转介

第 7 节只开接口，不得夹带 `GZ#` 终稿绕闸。闸关闭时第 7 节可写「闸未开，转介待接触编号」，不得补写已批准。

不写礼品单笔终稿、风险图终稿、账外专项终稿、刑事文书、启动闸。不可逆（对外宣称接触已合法、向监管正式报告已无公职风险、签署虚假纪要、给评标人统一口径）不得在草案阶段实施。禁止提交指令。不代提交。不代批准。不选定机关。

礼品展开转 `审查礼品招待赞助与捐赠`。账外转 `评估回扣账外暗中与资金链路`。中间人转 `评估中间人费用与资金链路`。调查转 `评估是否启动内部调查`。刑辩主成果转刑事。

若 if 用户催促「按零写／填满已批准或已行贿终稿」，then 该格 `现有依据不支持`，窗口不关。
若 if 人数、金额未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「公职闸与公职行草案」。本窗不执行发送。不包含：已行贿证明、已批准接触证明、已合规证明、礼品单笔终稿、风险图、刑事意见。禁止选边治愈。禁止见过官员即行贿。禁止国企员工即监察对象。禁止口头即已批准。禁止事后补纪要即已批准。禁止指导串供或向公职行贿。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标接触终稿已形成。
风险档 A：指导向公职行贿、串供、伪造纪要必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：民企投标。销售见过国企采购经办人，名片无编制、无委派材料；评标前三天。用户主张见过官员就是行贿、该经办人是国企员工所以当然是监察对象和国家工作人员、今天定行贿罪并出已批准接触终稿。公职闸打开。`Q-见`、`Q-国`、`Q-窗`、`Q-罪` 不打开为可靠路径。第 6 节见过即行贿格、国企员工即监察对象格 `现有依据不支持`；身份格待核或字段停止；决策窗口＝是，已合法路径不打开。仍出事项、时点、双人、禁止利益等其他 `GZ#` 草案。不关窗。不定罪。不辩护。

场景②：用户同时交出公司拜访清单与被调查销售抗辩，要求「你帮我们选边，给评标人补礼、统一口径、事后补纪要当已批准」。命中双方秘密＋指导向评标人行贿＋指导串供＋伪造批准记录。第一次整体停止。只交第 1、10 节。不出 `GZ#`。不得问代表哪一方后继续。
