# 建立内部调查证据案卷

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《民法通则》《民法总则》或其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成内部调查证据案卷矩阵：建卷闸、`Q#` 待证要件、`E#` 支持与不利编目、控制方、合法取得三值、缺口与合法补证接口、封面／目录草稿。本任务不写调查结论终稿，不是诉状，不是持有／禁毁通知，不是合法收集或镜像步骤终稿，不等于诉讼证据已质证或已保全。不执行发送，不代提交，不倒签。

`depends-on` 为空。是否启动转 `评估是否启动内部调查`。持有通知转 `准备证据保全与禁毁通知`。收集／镜像步骤转 `合法收集书证电子证与财务痕迹`。事实结论转 `形成内部调查报告`。金额转 `测算舞弊损失与追偿`。向机关交卷转 `准备向监管提交材料与特权日志` 或 `准备主动披露或自查报告`。律师工作产品转 `评估律师工作产品与保密边界`。

## 工作边界

正触发：已有或准备内部调查，主成果是把材料做成可回链案卷矩阵。授权、范围或材料未闭合仍正触发：建卷闸关闭，不出案卷矩阵终稿，窗口不关。用户要保证案卷已完整、今天必须交卷、把猜测写成已查清、把目录写成调查结论、未知金额写零、对方控制材料推定已持有或已灭失、口头清单即已入卷、私录一律可采或一律排除、企业设备一律当然可采、民企按公司法第一百七十七条或 42 号令第二十二条必须建卷上报国资委，仍正触发：对应格填 `现有依据不支持` 或字段停止，闸未开则不出案卷矩阵终稿，窗口不关。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是是否启动内部调查（转 `评估是否启动内部调查`）；
- 主成果是对内持有或禁毁通知发送稿（转 `准备证据保全与禁毁通知`）；
- 主成果是合法收集、镜像或现场取证步骤终稿（转 `合法收集书证电子证与财务痕迹`）；
- 主成果是调查报告或事实认定终稿（转 `形成内部调查报告`）；
- 主成果是金额测算终稿（转 `测算舞弊损失与追偿`）；
- 主成果是向机关主动披露或自查报告（转 `准备主动披露或自查报告`）；
- 主成果是劳动仲裁证据包、解除或日常处分决定（转劳动领域）；
- 主成果是刑事阅卷、辩护或控告（转刑事领域）；
- 主成果是个人信息、数据出境或网安专项体系（转数据隐私领域）。

入侵、购买黑客数据、秘密安装窃听、偷拷私人设备、伪造、隐匿、删除、格式化、藏匿、选择性不入卷、妨害作证、打击报复证人**不在负触发表**，走整体停止。「保证已完整」「今天必须交卷」「把目录写成结论」**不在负触发表**，只关对应格，窗口不关。

## 建立工作坐标

确认：编目授权；单方立场（公司／被调查对象，互斥）；调查范围；待证假设；已持有材料来源；对方或第三人控制的线索；是否已发持有通知；是否已有检查、诉讼、监察或公安文书。

口头「已经备份」「已经查清」「微信已读」「快递发出」只登记 `S#`／`V#`。不得升格已入卷、已查清、已保全、已送达或机关已受理。

同时掌握公司与被调查对象相互冲突的秘密，或两造争同一本案卷：`整体停止`，不得以选边治愈，也不得改走负触发。公司已开口且委托范围就是建卷、且未掌握被调查对象秘密时，可推定公司立场。提出入侵、购买黑客数据、秘密安装窃听、偷拷私人设备、伪造、隐匿、删除、格式化、藏匿、选择性不入卷、倒签、妨害作证、打击报复证人：第一次提出即整体停止，不以「坚持」为门槛，不以「该部分停止后继续编其余目录」续跑。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 制度、劳动合同或保密协议；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`N#` 封面／目录草稿；`Q#` 要件路径；`V#` 版本；`E#` 证据编目。禁止 `EV#`、`Dsc#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。案卷状态只用 `草案`、`部分形成`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。本任务默认 `草案`，不代提交。禁止「案卷已完整」「目录即结论」「内部案卷即已质证」「口头备份即已入卷」。合法取得与诉讼可采分列，禁止合并成「已可采」。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民事诉讼法谁主张谁举证、证据种类与审核；书证提出命令／拒不提交推定以诉讼中法院责令为前提，内部目录不得写成已成立。证据可能灭失时向人民法院申请保全是另一路径，本窗不写申请书、不选定法院。最高人民法院关于适用民事诉讼法的解释（2022 修正）非法证据排除：以严重侵害他人合法权益、违反法律禁止性规定或者严重违背公序良俗的方法形成或者获取的证据，不得作为认定案件事实的根据（2015 年文本为第一百零六条，条号运行时核验）；排除看方法是否达三条，不是「未经对方同意一律排除」，也不是「企业设备一律当然可采」。未经质证不得作为认定根据：诉讼外内部案卷不是法院案卷、不是已质证。民事诉讼证据规定（2019 修正）电子数据范围、原件或视为原件的输出介质、真实性综合判断；私录视听资料不是当然排除也不是当然可采。个人信息保护法第十三条「人力资源管理所必需」不是全员私人手机、私人微信、定位或生物识别授权。会计法及会计档案管理办法：会计资料真实完整并妥善保管，保管期限只待核，不得写成内部案卷法定期限。刑法第一百六十二条之一：隐匿、故意销毁依法应当保存的会计凭证、会计账簿、财务会计报告只作红旗并待核编目理由，本窗不定罪，不得指导删除，不得因「账上可能被删」整案停止。刑法第三百零七条、第三百零八条：妨害作证、帮助毁灭伪造证据、打击报复证人只作停止红旗，第一次提出即整体停止。监察法（2024 修正）第十八条，如实提供，不得伪造、隐匿或者毁灭证据；已有监察文书时不得借编目完成平行灭证或选择性不入卷。行政处罚法先行登记保存「七日」不得写成内部案卷法定期限。劳动法打击报复举报人员只作停止红旗；举报人身份不得写入可外传目录。中央企业合规管理办法第二十二条、第二十四条只约束国资委履行出资人职责的中央企业，不得写成全部民企必须向国务院国资委交卷；公司法第一百七十七条不是民企法定建卷上报义务。噪声：把内部案卷写成已质证、凡未经同意一律不得使用、凡企业设备一律当然可采、口头备份即已入卷、已读即送达、快递发出即已受理、材料缺失即事件未发生、存在材料即要件成立、对方控制即已持有或已灭失、把第一百六十二条之一写成已构成犯罪或据此拒编会计资料、拒不提交推定诉前已成立、先行登记保存七日当内部期限、未知写零。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变合法取得、排除、举证责任或档案保存结论的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补只收有利件、口头材料升格、私人设备无授权强取、对方控制推定存在、私录两端噪声的反例。
- `search_template` 只借案卷目录或证据编目栏目，不把范本当法定卷宗格式、已装订卷宗、发送版或调查结论。

工具不可用时继续 `Q#` 要件、`E#` 编目和缺口；非法证据排除、举证责任、期限、机关路径字段停止。不得拒跑，不得凭记忆写成要件已成立、事件未发生或指导违法取证。

## 判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、建卷闸与不关窗

主成果才整案转出。入侵、隐匿、伪造第一次停。保证已完整、今天必须交卷、猜测写成已查清、目录写成结论不关窗。闸关仍交十节，第 6 节不出案卷矩阵终稿。已有监察文书不得借本窗平行灭证。

### 2. 范围、待证假设与程序状态

每个假设拆成主体、行为、对价或利益、入账、授权、时间。不得把回扣写成已构成犯罪。口头不得升格已立案。

### 3. 建卷闸与路径 `Q#`

本节禁止出 `E#` 案卷矩阵终稿。无回链材料则 `Q-卷` 关闭，窗口不关。

### 4. 案卷矩阵 `E#`

闸未开不得出可外传编目终稿。支持与不利必须能并列。对方控制不得推定已持有。合法取得与诉讼可采分列。

### 5. 禁止动作与邻居接口

不得授权违法监控或强取私人设备。停职、扣私人设备转劳动。收集／镜像转 `合法收集书证电子证与财务痕迹`。持有通知转 `准备证据保全与禁毁通知`。结论转 `形成内部调查报告`。法院保全申请本包无对应原子：字段停止，不选定法院。不等于已经入卷、已质证或已保全。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；提出入侵、购买黑客数据、秘密安装窃听、偷拷私人设备、伪造、隐匿、删除、格式化、藏匿、选择性不入卷、倒签、妨害作证、打击报复证人、限制人身自由；已有监察／公安文书仍要求借编目完成平行灭证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。不得「该部分停止后继续编其余目录」。
- `字段停止`：排除规则、电子数据真实性、举证责任、会计档案期限、个保合法基础、送达未核验。保证已完整、今天必须交卷、猜测写成已查清、目录写成结论、未知写零、对方控制推定已持有、私录一律可采或一律排除、企业设备一律当然可采、民企套 177 或 42 号令第二十二条：该格停止，窗口不关；闸未开仍不出案卷矩阵终稿。
- `目标停止`：主目标变为调查报告、诉状、持有通知发送稿、收集步骤终稿、披露稿或法院保全申请书。

禁止指导入侵、隐匿、伪造或强取私人设备。不给胜诉率。不定罪。不选定机关或法院。不代提交。未知不写零。不得因「账上可能被删」整案停止。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。建卷闸关闭或不关窗信号仍交十节；第 6 节不出案卷矩阵终稿。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。建卷闸未打开时不得交付案卷矩阵终稿或「已查清」。边界见 [路由](references/routing.md)。
