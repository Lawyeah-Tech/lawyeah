# 建立内部调查证据案卷

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《民法通则》《民法总则》或其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成内部调查证据案卷矩阵：待证要件、举证责任、支持与不利材料、控制方、合法取得、缺口、合法补证接口和最晚时点。本任务不是调查结论，不是诉状，不执行发送，不指导伪造、隐匿、偷拷或违法取证。材料缺失不证明事件未发生；存在材料不等于要件成立。

`depends-on` 为空。是否启动转 `评估是否启动内部调查`。持有禁毁转 `准备证据保全与禁毁通知`。合法收集步骤转 `合法收集书证电子证与财务痕迹`。调查报告转 `形成内部调查报告`。测算转 `测算舞弊损失与追偿`。律师工作产品转 `评估律师工作产品与保密边界`。访谈笔录结构转 `准备调查访谈提纲与笔录结构`。举报人保护转 `设计举报人保护与反报复措施`。

## 工作边界

正触发：已有或准备内部调查，需要把已出现争点做成可回链的要件—举证—材料—补证矩阵。范围未闭合、材料不全仍正触发：案卷闸可部分打开，未知不写零，窗口不关。用户要把未知写成零、把缺失写成事件未发生、把行业潜规则写成商业贿赂已构成、把案卷当调查结论、选定某局、写死唯一举证截止日，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是是否启动内部调查（转 `评估是否启动内部调查`）；
- 主成果是发送版持有或禁毁通知（转 `准备证据保全与禁毁通知`）；
- 主成果是合法收集、镜像或现场取证步骤（转 `合法收集书证电子证与财务痕迹`）；
- 主成果是调查报告终稿（转 `形成内部调查报告`）；
- 主成果是测算工作表（转 `测算舞弊损失与追偿`）；
- 主成果是劳动仲裁证据卷（转劳动领域）；
- 主成果是刑事阅卷或辩护材料（转刑事领域）；
- 主成果是个人信息、数据出境或网安专项体系（转数据隐私领域）。

伪造、隐匿、偷拷私人设备、窃听、非法侵入、购买黑客数据、统一证人口径、秘密定位**不在负触发表**，走整体停止或该部分整体停止。双方秘密不在负触发表。

## 建立案卷坐标

确认：使用者与授权；单方立场（公司／被调查对象，互斥）；调查范围；待证假设；已持有材料来源；对方或第三人控制的线索；是否已发持有通知；是否已有监察／公安／检查文书。

口头「材料在对方那里对我们有利」只登记 `S#`。不能因对方控制而推定材料存在或内容有利。

同时掌握公司与被调查对象相互冲突的秘密，或两造争同一份案卷：`整体停止`，不得以选边治愈，也不得改走负触发。公司已开口且委托范围就是案卷、且未掌握被调查对象秘密时，可推定公司立场。提出全面违法取证方案：整体停止。就某材料提出伪造、隐匿、偷拷、窃听、非法侵入：该部分整体停止，第一次提出即停，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 制度或授权；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 争点要件；`EV#` 证据条目；`V#` 案卷版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。合法取得状态只用 `现有依据支持合法`、`现有依据不支持合法`、`依据不足，无法形成结论`。路径状态只用 `打开接口`、`不打开`、`待核`。技能正文中的条号是检索锚点，不是已核验 `L#`。禁止「已查实」「已构成商业贿赂」「材料没有就是没发生」。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：以严重侵害他人合法权益、违反法律禁止性规定或严重违背公序良俗的方法形成或获取的证据，不得作为认定案件事实的根据（民诉解释，2015 年为第一百零六条，2022 年修正后条号运行时核验）。电子数据应当提供原件；制作者制作的与原件一致的副本或直接来源于电子数据的打印件、其他可显示输出介质，视为原件；孤立截图不是当然原件。个人信息保护法第十三条，人力资源管理所必需不等于全员邮箱、私人微信或定位当然授权。会计资料不得隐匿、故意销毁；刑法第一百六十二条之一只作红旗。中央企业合规管理办法第二十四条，举报人身份和事项严格保密，只约束中央企业，不得写成全部民企同一法定义务，也不得写入可外传目录。监察法第十八条，已有文书不得借案卷完成平行灭证。反不正当竞争法 2025 修订第八条：入账折扣不是贿赂；工作人员归属抗辩待核。噪声：材料缺失即未发生、截图即原件、对方控制即内容有利、行业潜规则即已贿赂、把案卷当结论。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变排除、原件或合法取得结论的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补截图不是原件、私人微信不得强取、对方控制不得推定的反例。
- 特殊事实用 `search_case_by_fact`，只比较差异，不写成证据必然采信。

工具不可用时继续材料编目和控制方登记；举证责任、非法证据排除、期限和法律效果字段停止。

## 判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、案卷闸与不关窗

主成果才整案转出。违法取证第一次停。未知写零、缺失=未发生、潜规则=已贿赂不关窗。

### 2. 要件与举证责任

按已出现事实拆 `Q#`，不是默认闭集。商业贿赂候选必须指向交易机会或竞争优势的待证事实。推定或倒置未核验则字段停止。

### 3. 编目、不利材料和合法取得

支持与不利并列。截图标明副本。对方控制不得推定存在。私人设备无合法同意或机关文书不得设计强取。

### 4. 缺口与合法补证

持有通知、合法收集、访谈、保全只列接口和转介，不出申请或发送终稿。已有监察文书不得借补证完成清理。

### 5. 时点与禁止

最晚时点能确定才写日期，否则写触发事件。禁止伪造、隐匿、偷拷、统一证人口径。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；基础事实无法建立；提出全面违法取证方案；已有监察／公安文书仍要求借案卷清理设备。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `该部分整体停止`：就某材料提出伪造、隐匿、偷拷私人微信、窃听、非法侵入、购买黑客数据、统一证人口径或秘密定位。第一次提出即停，不提供方法。其余合法编目可部分形成。
- `字段停止`：举证责任、非法证据排除、个保合法基础、期限未核验。未知写零、缺失=未发生、潜规则=已贿赂、案卷当结论、选定某局、唯一截止日：该格停止，窗口不关。
- `目标停止`：主目标变为报告、诉状、持有通知发送稿或合法收集步骤终稿。

禁止指导伪造、隐匿、威胁或违法取证。不给胜诉率。不定罪。不选定机关。未知不写零。
