# 建立内部调查证据案卷

## 任务目标

在明确、无利益冲突的单方立场下（公司、被调查对象或合规负责人，互斥），形成内部调查证据案卷草案：建卷闸、待证与材料碎片、`Q#` 路径、`JW#` 建卷行（待证要件／材料形态／支持／不利／控制方／合法取得／打开接口／`E#` 回链）。本窗 `JW#` 是建卷行草案，不是调查结论，不是诉状，不是持有通知，不是收集或镜像步骤，不是已质证，不是已入卷，不是已保全，不是已查清。本窗闸名只能是建卷闸，禁止复用证据闸、案卷闸、人据闸、持有闸、保全闸、固证闸、交卷闸、评估闸、合规闸、启动闸、披露闸、检查闸、发送闸、报告闸。预留不得占用：立案闸、调查闸、检查闸、保全闸。本窗主行只能是 `JW#`，禁止 `E#`、`N#`、`A#`、`AJ#`、`JE#`、`EV#`、`RJ#`、`GT#`、`QI#`、`LH#`、`PD#`、`RF#`。主路径只用 `Q-建卷`，禁止用 `Q-卷`、`Q-据`、`Q-人据`、`Q-持有`、`Q-启`、`Q-披露`、`Q-风`、`Q-总`、`Q-合`、`Q-发` 作主路径。邻窗 `Q-建卷` 只作转介进本窗；本窗打开为主路径，不是已入卷、不是已质证。建卷闸打开不等于已入卷不等于已质证不等于已查清不等于已保全不等于待提交终稿。口头备份不是已入卷。已读不是到达。复制或哈希不是已固定、不是已公证。截图不是电子数据原件。保存通知不是证据保全。案卷不是已质证。对方控制不得推定已持有、已灭失或内容有利。材料缺失不是事件未发生。存在材料不是要件成立。私录不是当然排除，也不是当然可采。企业设备不是当然可采。个保法第十三条不等于私人设备授权。未知不写零。不定罪。不执行发送。不代提交。不选定法院。不写唯一截止日。

`depends-on` 为空。是否启动转 `评估是否启动内部调查`。持有通知转 `准备证据保全与禁毁通知`。收集／镜像步骤转 `合法收集书证电子证与财务痕迹`。事实结论转 `形成内部调查报告`。金额转 `测算舞弊损失与追偿`。向机关交卷转 `准备向监管提交材料与特权日志` 或 `准备主动披露或自查报告`。律师工作产品转 `评估律师工作产品与保密边界`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：已有或准备内部调查，主成果是把材料做成可回链案卷矩阵。授权、范围或材料未闭合仍正触发：有可编号材料或可编号缺口则建卷闸打开或半开，第 6 节出 `JW#` 草案，缺项记 `G#`。无一可编号材料且无一可编号缺口、又要求「今天必须出已完整／已质证终稿」才关闸，仍交十节，第 6 节不出 `JW#` 终稿，第 7 节不得出已齐卷封面或已质证，窗口不关。用户要保证已完整、今天必须交卷、把猜测写成已查清、把目录写成调查结论、口头清单即已入卷、复制哈希即已固定或已公证、截图即原件、保存通知即保全、对方控制即已持有／已灭失／内容有利、私录一律可采或一律排除、企业设备一律当然可采、民企按第一百七十七条或 42 号令第二十二条建卷上报、未知写零，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `JW#` 草案。不得因「不定罪」「不等于已质证」「不代提交」改走负触发关窗。利益冲突未解不是整体停止。无书面编目授权但单方立场已闭合且已有可编号材料或缺口：建卷闸部分打开，仍交十节，不是整体停止。口头「已经备份」不得单独算作开闸材料。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是是否启动内部调查（转 `评估是否启动内部调查`）；
- 主成果是对内持有或禁毁通知发送稿（转 `准备证据保全与禁毁通知`）；
- 主成果是合法收集、镜像或现场取证步骤终稿（转 `合法收集书证电子证与财务痕迹`）；
- 主成果是调查报告或事实认定终稿（转 `形成内部调查报告`）；
- 主成果是金额测算终稿（转 `测算舞弊损失与追偿`）；
- 主成果是向机关主动披露或自查报告（转 `准备主动披露或自查报告`）；
- 主成果是向监管交卷与特权日志（转 `准备向监管提交材料与特权日志`）；
- 主成果是劳动仲裁证据包、解除或日常处分决定（转劳动领域）；
- 主成果是刑事阅卷、辩护或控告（转刑事领域）；
- 主成果是个人信息、数据出境或网安专项体系（转数据隐私领域）；
- 尚未进入合规机制，只要改交易合同或出稿（审查起草领域，本窗搁置，只说明不实施）。

入侵、购买黑客数据、秘密安装窃听、偷拷私人设备、伪造、隐匿、删除、格式化、藏匿、选择性不入卷、妨害作证、打击报复证人、限制人身自由、已有监察／公安／检察文书仍借编目平行灭证、双方秘密**不在负触发表**，走整体停止。「保证已完整」「今天必须交卷」「目录即结论」「口头即已入卷」「对方控制即已持有」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不定罪」「不等于已质证」「不代提交」「不执行发送」是交付禁令，不是负触发。主成果才转；出现「案卷」「证据」一词不是转出。查不查尚未判断不负触发吞窗。

## 建立工作坐标

确认：编目授权；单方立场（公司／被调查对象／合规负责人，互斥）；调查范围；待证假设；已持有材料来源；对方或第三人控制的线索；是否已发持有通知；是否已有检查、诉讼、监察、公安或检察文书。

口头「已经备份」「已经查清」「微信已读」「快递发出」只登记 `S#`／`V#`。不得升格已入卷、已查清、已保全、已送达或机关已受理，**不得单独算作开闸材料**。可编号材料或可编号缺口可开闸。本窗不执行发送，不代提交，不出调查报告终稿，不写持有通知或镜像步骤。

立场只许公司、被调查对象或合规负责人，互斥。同时掌握公司与被调查对象相互冲突的秘密，或两造争同一本案卷：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号材料且无一可编号缺口：建卷闸关闭，仍交十节，不是整体停止。提出入侵、购买黑客数据、秘密安装窃听、偷拷私人设备、伪造、隐匿、删除、格式化、藏匿、选择性不入卷、「先拿到再合规」、倒签、妨害作证、打击报复证人、限制人身自由：第一次提出即整体停止，不以「坚持」为门槛，不以「该部分停止后继续编其余目录」续跑。已有监察／公安／检察文书仍要求借编目完成平行灭证或拿掉不利件：第一次整体停止。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 制度、劳动合同或保密协议；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`JW#` 建卷行；`V#` 版本；`E#` 证据形态回链（载体、控制方、取得方式，不是发送闸，不是已入卷证明）。承认只进 `S#`／`D#`，不得占用 `A#`。封面／目录只作第 7 节接口草稿，不得占用 `N#` 作主行。禁止 `A#`、`N#`、`AJ#`、`JE#`、`EV#`、`RJ#`、`GT#`、`QI#`、`LH#`、`PD#`、`RF#`。技能正文中的条号是检索锚点，不是已核验 `L#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。未知不写零。口头备份 ≠ 已入卷。已读 ≠ 到达。复制／哈希 ≠ 已固定 ≠ 已公证。截图 ≠ 原件。保存通知 ≠ 证据保全。内部案卷 ≠ 已质证。对方控制 ≠ 已持有 ≠ 已灭失 ≠ 内容有利。合法取得 ≠ 诉讼可采。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或文书范本检索。本窗是建立编目，`search_template` 只借栏目，**不要**把范本升格为法定卷宗、已装订、已入卷、已质证或调查结论。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现口头升格、只收有利件、对方控制推定、私录两端噪声、内部案卷写成已质证的反例；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把 1991 年民事诉讼法第一百零六条非法拘禁追债、2017 年民事诉讼法第一百零六条先予执行、2023 年民事诉讼法第一百零六条财产保全方法、1991 年民事诉讼法第八十四条公告送达、2012／2017 年民事诉讼法第八十一条证据保全、2001 年证据规定第六十八条、法复〔1995〕2 号私录一律排除、刑法第一百六十二条妨害清算当作现行排除或保全规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的排除、举证责任、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民事诉讼法（2023 修正）第七十一条证据应当在法庭上出示并由当事人互相质证。民事诉讼法解释（2022 修正）第一百零三条未经质证不得作为认定根据；第一百零六条以严重侵害他人合法权益、违反法律禁止性规定或严重违背公序良俗的方法形成或获取的证据不得作为认定根据（2015 年同条已被修改，2022 条号与三项方法保留）；第一百一十二条书证提出须诉讼中责令。噪声：1991／2017／2023 年民事诉讼法第一百零六条各为不同制度；1991 年第八十四条公告送达。民事诉讼证据规定（2019）第十五条原件或视为原件的输出介质、第九十三条真实性综合判断、第九十四条可确认真实但可推翻；2001 年第十四条不是电子数据范围，2001 年第六十八条旧排除已删除，法复〔1995〕2 号已废止。个人信息保护法第十三条人力资源管理所必需不等于私人设备授权。监察法（2024 修正，施行日 2025-06-01）第十八条如实提供，不得伪造、隐匿、毁灭。刑事诉讼法第五十四条检察／公安调取，单位和个人应当如实提供。刑法第一百六十二条之一只作会计资料编目红旗，不定罪；噪声：第一百六十二条妨害清算。第三百零七条、第三百零八条第一次停。会计法（2024）第二十三条妥善保管。行政处罚法（2021）第五十六条先行登记保存七日不是内部案卷期限；噪声：2017 年第三十七条。公司法第一百六十八条、第一百七十七条。42 号令第二条、第二十二条、第二十四条不得套全部民企。技能正文条号不是 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变合法取得、排除、举证责任或档案保存结论的正文再写入 `L#`。不得编造 `regulation_id`。细节工具不是硬依赖。
- `search_practiced` 补只收有利件、口头升格、无授权强取私人设备、对方控制推定存在或有利、私录两端噪声、内部案卷写成已质证的实务反例。
- `search_template` 只借案卷目录或证据编目栏目。不把范本当法定卷宗、已装订、发送版或调查结论。

工具不可用时继续 `Q-建卷` 与 `JW#` 编目；排除、举证责任、期限、机关路径字段停止。不得拒跑，不得凭记忆写成已入卷、已质证、已查清或指导违法取证。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、建卷闸与不关窗

主成果才整案转出。入侵、隐匿、伪造、选择性不入卷、双方秘密第一次停。保证已完整、今天必须交卷、口头即已入卷、对方控制即已持有不关窗。闸关仍交十节，第 6 节不出 `JW#` 终稿。利益冲突未解不是整体停止。禁止把检查闸、调查闸、启动闸或持有闸写进本窗节点 0。已有监察／公安／检察文书不得借本窗平行灭证，也不得转介持有或收集完成毁证。

### 2. 范围、待证假设与程序状态

每个假设拆成主体、行为、对价或利益、入账、授权、时间。不得把回扣写成已构成犯罪。口头不得升格已立案。本节禁止出 `JW#` 终稿。

### 3. 建卷闸与路径 `Q#`

本节禁止出 `JW#` 终稿。有可编号材料或缺口：闸打开或半开。主路径只用 `Q-建卷`。`Q-取`、`Q-持有` 只作扫描或转介，不得升主路径。

### 4. 建卷行 `JW#`

待证要件、材料形态、支持／不利、控制方、合法取得分列。状态 `草案`。禁止升格已入卷、已质证、已查清、已保全。无 `E#` 不得写已入卷。合法取得与诉讼可采分列。

### 5. 收集、持有、报告与披露接口

合法收集、持有、报告、披露、启动、交卷只开接口。法院保全申请本包无对应原子：字段停止，不选定法院。第 7 节不得夹带 `JW#` 终稿或已质证绕闸。闸关时第 7 节不得出已齐卷封面。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；两造争同一本案卷；提出入侵、购买黑客数据、秘密安装窃听、偷拷私人设备、伪造、隐匿、删除、格式化、藏匿、选择性不入卷、「先拿到再合规」、倒签、妨害作证、打击报复证人、限制人身自由；已有监察／公安／检察文书仍要求借编目完成平行灭证或拿掉不利件。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。不得「该部分停止后继续编其余目录」。不得转介持有或收集完成毁证。无一可编号材料且无一可编号缺口：建卷闸关闭，仍交十节，不是整体停止。无书面编目授权但有材料或缺口：建卷闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：排除规则、电子数据真实性、举证责任、会计档案期限、个保合法基础未核验。保证已完整、今天必须交卷、猜测写成已查清、目录即结论、口头即已入卷、复制哈希即已固定、截图即原件、保存通知即保全、对方控制即已持有或已灭失、私录一律可采或一律排除、企业设备一律当然可采、民企套 177 或 42 号令、未知写零：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `JW#` 草案。
- `目标停止`：主目标变为调查报告、诉状、持有通知发送稿、收集步骤终稿或披露稿。禁止把「口头即已入卷」当作用户错误主张时的目标停止；那是不关窗。

禁止指导入侵、隐匿、伪造或强取私人设备。不给胜诉率。不定罪。不选定机关或法院。不代提交。未知不写零。不得因「账上可能被删」整案停止。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。建卷闸关闭仍交十节，第 6 节不出 `JW#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `JW#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。建卷闸未打开时不得交付案卷矩阵终稿或「已查清」。边界见 [路由](references/routing.md)。
