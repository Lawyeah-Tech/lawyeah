# 建立内部调查证据案卷方法

本文件是可执行判断节点。口头备份不是已入卷。已读不是到达。复制或哈希不是已固定、不是已公证。截图不是电子数据原件。保存通知不是证据保全。内部案卷不是已质证。对方控制不得推定已持有、已灭失或内容有利。材料缺失不是事件未发生。存在材料不是要件成立。私录不是当然排除，也不是当然可采。企业设备不是当然可采。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已入卷、已质证、已查清、已保全、选定机关、代提交、未知写零。本任务不定罪，不执行发送，不出调查结论。本窗闸名只能是建卷闸，禁止复用证据闸、案卷闸、人据闸、持有闸、评估闸、合规闸、启动闸、披露闸、检查闸。预留不得占用：立案闸、调查闸、检查闸、保全闸。本窗 `JW#` 是建卷行。主路径只用 `Q-建卷`，禁止用 `Q-卷`、`Q-据`、`Q-人据`、`Q-持有`、`Q-启`、`Q-披露`、`Q-风`、`Q-总`、`Q-合` 作主路径。英文 id 禁止使用，一律用中文技能名 `建立内部调查证据案卷`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991／2017／2023 年民事诉讼法第一百零六条各为不同制度、1991 年民事诉讼法第八十四条公告送达、2012／2017 年第八十一条证据保全、2001 年证据规定第六十八条、法复〔1995〕2 号、刑法第一百六十二条妨害清算、把内部案卷写成已质证或把拒不提交推定写成诉前已成立时记为噪声。禁止指导入侵、删除、隐匿、伪造或强取私人设备。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现材料或缺口扫描，不是默认闭集。
`JW#` 固定列：`编号｜待证要件｜材料形态｜支持／不利｜控制方｜合法取得｜打开接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已入卷」或「已质证」。无 `E#` 不得写已入卷、已质证、已保全、已查清。承认只进 `S#`／`D#`，不得占用 `A#`。`E#` 只作形态回链。主路径只用 `Q-建卷`。禁止 `N#`、`A#`、`AJ#`、`JE#`、`EV#`、`RJ#` 作主行。

口头「已经备份」「已经查清」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。封面、目录、落款日期均不得早于本次形成日。稿件状态默认 `草案`。

实务上：排除看方法是否达解释第一百零六条三条，不是未经同意一律排除。合法取得与诉讼可采分列。不得只收有利件。已有监察／公安／检察文书时配合义务是如实提供，不是拿掉不利件再装订。

## 节点 0　分流、立场、建卷闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、入侵、黑客数据、偷拷、伪造、隐匿、删除、格式化、选择性不入卷、倒签、妨害作证、打击报复、平行灭证不进负表。利益冲突未解不进整体停止。不定罪、不等于已质证、不代提交、不执行发送不是负触发。禁止把检查闸、调查闸、启动闸或持有闸写进本窗节点 0。

整案转出只交付第 1、2、10 节，不出 `JW#` 终稿。

出现「案卷」「证据」一词不是转出。查不查尚未判断不负触发吞窗。

建卷闸打开（可出 `JW#` 草案，仍不得标「已入卷／已质证／已查清」）须同时满足：单方无冲突立场已闭合；主成果是案卷矩阵，不是报告、持有函、收集步骤、披露稿；至少一类可编号材料或可编号缺口。口头「已经备份」不算单独开闸材料。

建卷闸部分打开：已有材料或缺口，但授权、范围、合法取得未闭合；对应格待核；仍交十节。无书面编目授权但单方立场已闭合且已有材料或缺口：建卷闸部分打开，仍交十节，不是整体停止。部分打开不得出可外传终稿。

建卷闸关闭（仍正触发）：无一可编号材料且无一可编号缺口。「今天必须交已完整终稿」而无最小碎片不得开闸。不出 `JW#` 终稿。**仍交十节**，第 5 节只交闸／`Q-建卷`，第 6 节不出 `JW#` 终稿，**第 7 节不得出已齐卷封面或已质证**。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「没有证据」或「事件未发生」。

「保证已完整」「今天必须交卷」「猜测写成已查清」「目录即结论」「口头即已入卷」「复制哈希即已固定或已公证」「截图即原件」「保存通知即保全」「对方控制即已持有／已灭失／内容有利」「私录一律可采或一律排除」「企业设备一律当然可采」「民企套 177 或 42 号令第二十二条」「未知写零」「选定某局」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `JW#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号材料且无一可编号缺口，then 建卷闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，或两造争同一本案卷，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出入侵、购买黑客数据、秘密安装窃听、偷拷私人设备、伪造、隐匿、删除、格式化、藏匿、选择性不入卷、「先拿到再合规」、倒签、妨害作证、打击报复证人、限制人身自由，then 整体停止；第一次提出即停，不以「坚持」为门槛，不以「该部分停止后继续编其余目录」续跑。
若 if 已有监察／公安／检察 `R#` 仍要求借编目完成平行灭证或拿掉不利件，then 整体停止；不得转介持有或收集完成毁证。

## 节点 3　建卷行 `JW#`

按已出现材料或缺口扫描，不是默认闭集。每条须能指向待证要件、材料形态、控制方或合法取得之一。

无 `E#` 不得写已入卷、已质证、已保全或已查清。状态默认 `草案`。一次只推荐下一步。未知不写零。合法取得与诉讼可采分列。支持与不利必须能并列。不得只收有利件。

热冲突强制处理：

- 保证已完整／今天必须交卷／猜测写成已查清／目录即结论／口头即已入卷／复制哈希即已固定／截图即原件／保存通知即保全／对方控制即已持有／私录一律可采或一律排除／企业设备一律当然可采／民企套 177／未知写零 → 该格不支持或字段停止；仍出其他 `JW#`。
- 无一材料且无一缺口 → 关闸，不出 `JW#` 终稿，窗口不关。
- 入侵、偷拷、伪造、隐匿、选择性不入卷、平行灭证 → 整体停止，不是该格不支持后续续编。

企业邮件／办公设备：制度授权＋告知可回链且未落入排除三条，只支持**合法取得待核**，不得写成已可采或已入卷。私人设备：无同意、无文书不得推定为企业设备。私录：已形成件只编目并标合法取得待核；「去偷录」走节点 0 整体停止。无哈希、无载体：完整性格停止，不得升格已可采、已固定或已公证。会计资料：「账上可能被删」只红旗，该行待核，不整案停、不指导删除。

## 本任务回链纪律

本任务成果是「建卷闸与建卷行草案」。本窗不执行发送。不包含：调查报告、持有通知、收集步骤终稿、披露稿、已质证证明。禁止选边治愈。禁止口头备份即已入卷。禁止对方控制即已持有。禁止内部案卷即已质证。禁止指导删除或平行灭证。建卷闸打开 ≠ 已入卷 ≠ 已质证 ≠ 已查清 ≠ 已保全。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标案卷矩阵终稿已形成。
风险档 A：入侵、隐匿、伪造、妨害作证、平行灭证必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：销售总监邮箱和报销系统待编目。用户主张 IT 口头说已经备份所以已入卷、哈希一份就算公证、对方电脑里一定有对账单、私录一律可采、企业电脑一律当然可采、民企也必须按 42 号令交卷、今天必须交齐、不清楚的金额先写零。建卷闸打开或半开。`Q-齐`、`Q-复`、`Q-控`、`Q-证`、`Q-套`、`Q-签`、`Q-零` 不打开为可靠路径。第 6 节不得把已入卷、已公证、已持有、已质证、必须交卷、0 写入可执行 `JW#`；对应格 `现有依据不支持` 或字段停止；仍出待证要件、控制方分列、合法取得待核等其他 `JW#`。不关窗。不代提交。

场景②：用户同时交出公司「必须今晚交卷、私人微信先拷进来、不利邮件不要订进可外传目录」与被调查销售「从未受贿」口径，并出示检察调取通知。命中双方秘密＋偷拷＋选择性不入卷＋平行灭证。第一次整体停止。只交第 1、10 节。不出 `JW#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得该部分停后继续编其余目录。不得转介持有完成毁证。
