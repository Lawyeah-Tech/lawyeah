# 评估方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。合法取得状态只用 `现有依据支持合法`、`现有依据不支持合法`、`依据不足，无法形成结论`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、刑事既遂、唯一举证截止日、选定机关、未知写零、把材料缺失写成事件未发生。本任务不定罪，不是调查结论。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、把 2015 年民诉解释第一百零六条条号直接抄进 `L#` 而不核验 2022 年修正后条号、把截图写成电子数据原件、把 42 号令第二十四条套全部民企时记为噪声。禁止指导伪造、隐匿、偷拷、窃听或非法侵入。

`Q#` 固定列：`编号｜路径｜提出方｜相对方｜法律效果假设｜成立条件｜支持事实｜不利事实｜控制方／证明负担红旗｜最强反方｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`EV#` 固定列：`编号｜待证要件回链｜材料摘要｜支持或不利｜控制方｜取得方式｜原件或副本｜合法取得三值｜缺口｜转介｜来源回链`。

口头「在对方那里对我们有利」只进 `S#`，不得升格 `D#` 已存在或内容有利。

## 节点 0　分流、立场、案卷闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。违法取证不进负表。

整案转出只交付第 1 节分流理由、第 2 节来源、第 10 节最小交接。

| 信号 | 处理 |
| --- | --- |
| 主成果是是否启动内部调查 | 负触发 `评估是否启动内部调查` |
| 主成果是发送版持有或禁毁通知 | 负触发 `准备证据保全与禁毁通知` |
| 主成果是合法收集、镜像或现场取证步骤 | 负触发 `合法收集书证电子证与财务痕迹` |
| 主成果是调查报告终稿 | 负触发 `形成内部调查报告` |
| 主成果是测算工作表 | 负触发 `测算舞弊损失与追偿` |
| 主成果是劳动仲裁证据卷 | 整案转劳动 |
| 主成果是刑事阅卷或辩护 | 整案转刑事 |
| 主成果是个人信息或网安专项体系 | 整案转数据隐私 |
| 垄断、滥用支配、经营者集中为主成果 | 整案转竞争法；回扣线索的案卷要件可留 |

案卷闸打开（可出 `Q#`／`EV#` 草案）须同时满足：单方无冲突立场与授权；至少一项可编号争点；主成果是案卷矩阵，不是报告、诉状、持有通知或收集步骤终稿。

案卷闸部分打开：争点可编号但合法取得或举证责任未核验。仍交十节，对应格待核。

「未知写零」「缺失即未发生」「行业潜规则即已贿赂」「把案卷当结论」「选定某局」「唯一举证截止日」**不关窗**。对应格 `现有依据不支持` 或字段停止。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出全面违法取证方案，或已有监察／公安 `R#` 仍要求借案卷清理设备，then 整体停止；第一次提出即停。
若 if 就某材料提出伪造、隐匿、偷拷私人微信、窃听、非法侵入、购买黑客数据、统一证人口径、秘密定位，then 该部分整体停止，不给方法；其余合法编目可部分形成。

## 节点 1　要件与举证责任

按已出现事实拆 `Q#`。每个商业贿赂候选须能指向交易机会或竞争优势的待证事实，不得用「行业潜规则」代替。主体、行为、对价或利益、入账、授权、时间分列。

检索锚点：反不正当竞争法 2025 修订第八条。主张商业贿赂的，证明负担原则上在提出方；工作人员贿赂原则上可认定为经营者行为，但与谋取交易机会或竞争优势无关的抗辩待核。未核验不得写成举证责任倒置。入账折扣该贿赂格 `现有依据不支持`。

劳动、数据、刑事要件只开接口，主成果才整案转出。

## 节点 2　编目、合法取得与排除接口

每个 `EV#` 必须同时列支持与不利。不得只收有利件。

企业工作邮箱／办公设备：查制度授权和告知，合法基础待核。私人设备、私人微信：无合法同意或机关文书，不得设计强取；提出偷拷则该部分整体停止。会计账簿：记录保管人和完整性校验；隐匿销毁只作停止红旗。举报人身份单独加密编号，不得写入可外传目录；42 号令第二十四条只约束中央企业。

检索锚点：民诉解释，以严重侵害他人合法权益、违反法律禁止性规定或严重违背公序良俗的方法形成或获取的证据，不得作为认定案件事实的根据（条号运行时核验）。本窗只标排除接口，不写排除裁定。违法调取的通讯不得当作可查性的支持事实。

电子数据应当提供原件。制作者制作的与原件一致的副本，或直接来源于电子数据的打印件、其他可显示输出介质，视为原件。孤立截图、导出版标明副本，不得写成原件当然成立。公证真实性可反驳。

对方控制不得推定材料存在或内容有利。诉讼中无正当理由拒不提交的推定，以法院责令为前提，调查阶段案卷不得写成已成立。

已有监察／公安 `R#`：配合义务是如实提供，不得借编目完成全员清理或格式化。

## 节点 3　缺口、补证与时点

补证必须合法。不能合法取得的标停止，不给违法步骤。

| 编号 | 打开信号 | 本任务允许 | 禁止 | 转介 |
| --- | --- | --- | --- | --- |
| `Q-件` | 已出现争点 | 要件拆分 | 闭集铺开；潜规则当构罪 | 留本任务 |
| `EV-支` | 有支持材料 | 编目 | 写成已查实 | 留本任务 |
| `EV-不` | 有不利材料 | 必须并列 | 只收有利件 | 留本任务 |
| `Q-取` | 需判断合法取得 | 三值 | 私人微信当然可取 | 数据专项／合法收集 |
| `Q-证` | 材料可能灭失 | 持有接口 | 出发送稿；监察下清理 | `准备证据保全与禁毁通知` |
| `Q-集` | 需镜像或调取步骤 | 只开接口 | 本窗出收集终稿 | `合法收集书证电子证与财务痕迹` |
| `Q-访` | 需访谈 | 只开接口 | 统一证人口径 | `准备调查访谈提纲与笔录结构` |
| `Q-密` | 律师底稿／特权 | 只开接口 | 写入可外传目录 | `评估律师工作产品与保密边界` |
| `Q-报` | 举报人可识别 | 加密编号 | 写入可外传目录；报复步骤 | `设计举报人保护与反报复措施` |
| `Q-金` | 需数字 | 只开接口 | 未知写零 | `测算舞弊损失与追偿` |
| `Q-结` | 用户要事实结论 | 只转介 | 本窗出报告 | `形成内部调查报告` |
| `Q-监` | 监察／公安 `R#` | 如实提供红旗 | 借案卷平行灭证 | 提出清理则整体停止 |

持有通知未发且存在删改风险：标红旗并转介，本任务不出发送稿。最晚时点能确定才写日期，否则写触发事件，不编唯一举证截止日。期间类型一行一类：`内部制度时限`／`行政检查期限`／`监察调查措施期限`／`劳动举证期限`／`诉讼举证期限`。送达不明则截止日停止。未知不写零。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得把案卷写成调查结论。

若 if 举证责任或排除规则未核验，then 该格字段停止。
若 if 金额参数不足，then 该行标未知，禁止写零。

判断状态只许三值。口头转述、截图不得写成原件、已查实或已合法取得。

## 本任务回链纪律

本任务成果是「内部调查证据案卷矩阵」。不包含：调查报告、持有通知发送稿、合法收集步骤终稿、诉状、测算终稿。禁止违法取证步骤。禁止选边治愈。禁止把缺失写成未发生。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`。
风险档 A：伪造、隐匿、偷拷、平行灭证必须单独标可逆性；提出即停。
