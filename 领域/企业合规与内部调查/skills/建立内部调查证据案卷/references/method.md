# 评估方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。案卷状态只用 `草案`、`部分形成`、`停止`。禁止胜诉率、必然免责、刑事既遂、唯一截止日、选定机关或法院、代提交、把口头备份写成已入卷、未知写零。本任务不定罪，不执行发送，不写调查结论终稿。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、把内部案卷写成诉讼证据已质证、把非法证据排除写成「未经对方同意一律不得使用」或「企业设备一律当然可采」、把行政先行登记保存七日写成内部案卷法定期限、把拒不提交推定写成诉前已成立、把刑法第一百六十二条之一写成已构成犯罪时记为噪声。禁止指导入侵、删除、格式化、藏匿、伪造、偷拷或选择性不入卷。

`Q#` 固定列：`编号｜路径｜提出方｜相对方｜法律效果假设｜成立条件｜支持事实｜不利事实｜控制方／证明负担红旗｜最强反方｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`E#` 固定列：`编号｜对应 Q#｜名称｜种类｜支持／不利／中性｜控制方｜形成主体｜取得方式｜权限依据｜合法取得三值｜完整性／真实性校验｜入卷状态（内部／可外传／停止）｜来源回链｜转介`。一行一条。支持与不利必须能并列。合法取得与诉讼可采分列。
`N#` 固定列：`版本｜状态（草案／停止）｜编目范围｜封面记载｜禁止夹带结论／罪名／举报人身份／倒签｜来源回链`。只作案卷封面／目录草稿，默认 `草案`，不是持有通知，不是发送稿。

拟制日＝本次形成本任务成果之日。封面、目录、落款日期均不得早于本次形成日。

口头「已经备份」「已经查清」、已读、快递发出只进 `S#`／`V#`，不得升格已入卷、已查清、已保全、已送达或机关已受理。

## 节点 0　分流、立场、建卷闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。错误主张不改走负触发。入侵、伪造、隐匿、删除、偷拷不进负表。

整案转出只交付第 1 节分流理由、第 2 节来源、第 10 节最小交接，不填第 5–9 节实体、不出 `E#` 案卷矩阵终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是是否启动内部调查 | 负触发 `评估是否启动内部调查` |
| 主成果是持有或禁毁通知发送稿 | 负触发 `准备证据保全与禁毁通知` |
| 主成果是合法收集、镜像或现场取证步骤终稿 | 负触发 `合法收集书证电子证与财务痕迹` |
| 主成果是调查报告或事实认定终稿 | 负触发 `形成内部调查报告` |
| 主成果是金额测算终稿 | 负触发 `测算舞弊损失与追偿` |
| 主成果是主动披露或自查报告 | 负触发 `准备主动披露或自查报告` |
| 主成果是向监管交卷与特权日志 | 负触发 `准备向监管提交材料与特权日志` |
| 侦查、起诉、审判、阅卷、辩护、控告为主成果 | 整案转刑事；编目接口可留时刑事段只红旗 |
| 劳动处分、解除、仲裁证据包为主成果 | 整案转劳动 |
| 个人信息、数据出境、网安专项体系为主成果 | 整案转数据隐私 |
| 垄断、滥用支配、经营者集中为主成果 | 整案转竞争法 |
| 尚未进入合规机制，只要改合同 | 审查起草本窗搁置 |

建卷闸打开（可出 `E#` 矩阵草案，仍不得标「案卷已完整／已查清」，仍不代提交）须同时满足：单方无冲突立场与编目授权；主成果是要件—材料—合法取得—缺口矩阵，不是报告、持有函、收集步骤、诉状、披露；至少一类可编号材料或线索能进 `E#`，或缺口可编号；待证假设能拆成要件；无双方秘密、无第一次违法取证／第三百零七条／第三百零八条信号。

建卷闸部分打开：授权或范围未完全闭合，但已有可编号邮件／账套等；对应格待核或字段停止；仍交十节；不得标终稿 `已形成`。

建卷闸关闭（仍正触发）：无编目授权；无一可编号材料且无一可编号缺口；系统／期间／对象无法识别。「今天必须交卷」而无最小事实不得开闸。不出案卷矩阵终稿。**仍交十节**，第 5 节只交 `Q-卷`／`Q-合` 状态，第 6 节不出可外传 `E#` 终稿。禁止因闸关闭只交第 1、2、10 节。禁止因闸关闭改走负触发。禁止把闸关闭写成「没有证据」「事件未发生」或「材料已齐所以已查清」。

「保证案卷已完整」「今天必须交卷」「把猜测写成已查清」「把目录写成调查结论」「未知金额写零」「对方控制材料推定已持有或已灭失」「口头清单即已入卷」「私录一律可采或一律排除」「企业设备一律当然可采」「民企必须按公司法第一百七十七条或 42 号令第二十二条建卷上报」「选定某局／某院」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸未开仍不出案卷矩阵终稿。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续，不得改走负触发。
若 if 提出入侵、木马、购买黑客数据、秘密安装窃听、偷拷私人设备、伪造、隐匿、删除、格式化、换机、藏匿、选择性不入卷或清理、「先拿到再合规」、倒签、补造回证、妨害作证、威胁证人、打击报复证人或举报人、限制人身自由，then 整体停止；第一次提出即停，不以「坚持」为门槛，不以「该部分停止后继续编其余目录」续跑。
若 if 已有监察／公安 `R#` 仍要求借编目完成平行灭证或选择性不入卷，then 整体停止。

## 节点 1　范围、待证假设与程序状态

1. 每个已出现的待证假设拆成主体、行为、对价或利益、入账、授权、时间。商业贿赂候选必须能指向交易机会或竞争优势的待证事实，不得用「行业潜规则」代替，不得写成已构成犯罪。
2. 范围用「系统 × 期间 × 对象／账户／关键词」识别。禁止空目录仍标已形成。对方或第三人控制的线索单独列控制方，不得推定已持有或已灭失。
3. 程序表：检查、监察、公安、诉讼文书分列动作类型、机关、案号、文书、作出日、收到日、送达方式、效力凭证。口头「监察来过」、已读、截图不得写入效力凭证，不得升格已立案、已送达或期限已起算。期间类型必须点名、一行一类：`内部制度时限`（标明非法定）／`会计资料法定保存期限`（只待核）／`行政先行登记保存期限`（噪声，不得写入内部案卷）／`行政检查期限`／`监察调查措施期限`／`民事诉讼举证或证据保全期限`（只开接口，不选定法院）／`劳动解除或仲裁期限`／`刑事追诉时效`。送达不明则该行截止日停止。未知不写零，不写死唯一截止日。
4. 已有监察／公安 `R#`：配合义务是如实向该机关提供（检索锚点：监察法第十八条）。本窗不得起草选择性不入卷、清理无关设备或格式化口径。

检索锚点：民事诉讼法解释非法证据排除三条（条号运行时核验）。民事诉讼证据规定电子数据真实性与完整性。私录视听资料不是当然排除也不是当然可采。个保法第十三条不是私人设备授权。刑法第一百六十二条之一只作会计资料编目理由待核，不定罪，不得因「账上可能被删」整案停止，不得指导删除。刑法第三百零七条、第三百零八条只作停止红旗。拒不提交推定以诉讼中法院责令为前提。

## 节点 3　案卷矩阵 `E#`

闸未开不得出可外传编目终稿。一行一条，按条给合法取得三值，禁止整卷一个三值。

| 落点 | `现有依据支持` | `现有依据不支持` | `依据不足，无法形成结论` |
| --- | --- | --- | --- |
| 企业邮件／办公设备 | 制度授权＋告知可回链，提取范围未越权，未落入排除三条 | 无授权越权提取、入侵、木马、购买黑客数据 | 有设备权属陈述但授权／告知文本未出示 |
| 私人手机／私人微信 | 有合法同意或机关文书，范围可回链 | 无同意、无文书仍设计或已实施强取 | 权属（公私）争而未闭合——不得推定为企业设备 |
| 私录视听资料 | 来源可回链且未达排除三条，仅作内部目录候选，不得标已质证可采 | 已达严重侵害合法权益／违反禁止性规定／严重违背公序良俗 | 仅「未经对方同意」不得单独填不支持；也不得因企业场所录音单独填支持 |
| 电子数据完整性 | 提取主体、方法、校验值、原始载体或视为原件的输出介质可回链 | 已证明被篡改、选择性导出后销毁源文件 | 无哈希、无载体：完整性格停止，不得升格已可采 |
| 会计资料 | 保管人、档案位置、完整性可回链 | 用户要隐匿、销毁、不入卷（提出即整体停止，不走本格续编） | 「账上可能被删」只红旗，该行待核，不整案停 |
| 对方／第三人控制 | 不得因控制关系填支持「已持有」 | 不得填不支持「已灭失」 | 控制方列对方／第三人，入卷状态非已持有 |
| 口头备份／已读／快递 | 不得填支持已入卷、已送达、机关已受理 | 把口头备份写成已入卷：该格不支持，窗口不关 | 只进 `S#`／`V#` |
| 举报人身份 | 内部加密编号可存在 | 写入可外传 `E#` 正文＝不支持外传 | 身份与事项分册，外传目录空该字段 |

已形成的录音或截图只编目并标合法取得待核，不得写成当然可采或当然排除。用户要求「去偷录／去入侵／先拿到再合规」走节点 0 整体停止，不在本节点给方法。

材料缺失不证明事件未发生。存在材料不等于要件成立。不得只收有利件。

## 节点 4　补证接口、封面与邻居

`N#` 只作封面／目录草稿，状态默认 `草案`。不得把 `N#` 写成持有通知、发送稿或调查结论。不能合法取得的标停止，只转介收集原子，本窗不出收集步骤终稿。

持有通知未发且存在删改风险：标红旗并转介 `准备证据保全与禁毁通知`，本任务不出发送稿。监管已要求提交原件：转介 `准备向监管提交材料与特权日志`，本任务只列清单，不代提交。法院证据保全申请不在本包则字段停止，不选定法院。

扣押个人手机、强制交出私人账号、停职停薪：本窗不得直接实施，转劳动。批量导出通讯录或客户个人信息：转数据。停付账户：转 `评估内部账户冻结与资金保全`。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过建卷闸直接给案卷矩阵终稿。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if 已有监察／公安 `R#`，then 不得转介本窗完成清理或选择性不入卷。

判断状态只许三值。口头转述、截图和「已读」不得写成已入卷、已送达或保存义务已激活。

## 本任务回链纪律

本任务成果是「建卷闸、待证要件与证据案卷矩阵草案」。不包含：调查报告、披露稿、处分决定、持有通知发送稿、合法收集步骤终稿、法院保全裁定、诉状。禁止删除步骤。禁止倒签。禁止选边治愈。禁止把内部目录写成已质证。禁止因账上可能被删整案停止。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标案卷矩阵终稿已形成。
风险档 A：入侵、隐匿、伪造、妨害作证、平行灭证必须单独标可逆性；提出即整体停止。
