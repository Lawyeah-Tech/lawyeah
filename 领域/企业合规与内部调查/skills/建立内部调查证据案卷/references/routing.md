# 边界与路由

## 正触发

需要内部调查的证据矩阵，而不是结论。材料不全、范围未闭合仍正触发。未知写零、缺失即未发生、潜规则即已贿赂、把案卷当结论，仍正触发，只关对应格。

双方秘密、伪造、隐匿、偷拷、窃听、非法侵入、借案卷平行灭证的停止，优先于负触发。上述信号不在下表。违法取证不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 是否启动内部调查 | `评估是否启动内部调查` |
| 发送版持有或禁毁通知 | `准备证据保全与禁毁通知` |
| 合法收集、镜像或现场取证步骤 | `合法收集书证电子证与财务痕迹` |
| 调查报告终稿 | `形成内部调查报告` |
| 测算工作表 | `测算舞弊损失与追偿` |
| 劳动仲裁证据卷 | 劳动领域 |
| 刑事阅卷或辩护 | 刑事领域 |

不得因「是否调查尚未判断」吞掉本窗：主成果才是启动闸时才负触发；用户要案卷而查不查未定，本窗正触发，启动闸只转介。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、阅卷、辩护词为主成果 | 刑事领域 |
| 劳动合同、解除、工伤、职场性骚扰主轴 | 劳动领域 |
| PIPL 合法性、出境、等保、网安事件专项 | 数据隐私领域 |
| 垄断协议、滥用支配地位、经营者集中申报 | 竞争法领域 |

综合案卷主轴可留本任务；专项只作为背景时在缺口标明。渠道回扣材料不是不正当竞争整案转出信号。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 查不查 | `评估是否启动内部调查` |
| 持有禁毁 | `准备证据保全与禁毁通知` |
| 镜像／调取步骤 | `合法收集书证电子证与财务痕迹` |
| 调查报告 | `形成内部调查报告` |
| 金额 | `测算舞弊损失与追偿` |
| 律师底稿 | `评估律师工作产品与保密边界` |
| 访谈 | `准备调查访谈提纲与笔录结构` |
| 举报人保护 | `设计举报人保护与反报复措施` |
| 交卷特权 | `准备向监管提交材料与特权日志` |

## 易混

「把材料整理一下」若需要要件和举证责任，属正触发；若只要结论，负触发报告原子。「没有就是没发生」正触发不关窗，该格不支持。「先把私人微信拷出来再编目」该部分或整体停止，不是负触发。已有监察调取通知仍要「把无关电脑格式化再入卷」：整体停止。
