# 边界与路由

## 正触发

需要把内部调查材料做成可回链案卷矩阵，而不是结论。授权、范围或材料未闭合仍正触发：建卷闸关闭，不出案卷矩阵终稿，窗口不关。保证已完整、今天必须交卷、把猜测写成已查清、把目录写成结论、未知写零、对方控制推定已持有、口头清单即已入卷、私录一律可采或一律排除、民企套 42 号令第二十二条，仍正触发。

双方秘密、入侵、购买黑客数据、偷拷私人设备、伪造、隐匿、删除、格式化、藏匿、选择性不入卷、倒签、妨害作证、打击报复证人的停止，优先于负触发。上述信号不在下表。「保证已完整」「今天必须交卷」「把目录写成结论」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 是否启动内部调查 | `评估是否启动内部调查` |
| 对内持有或禁毁通知发送稿 | `准备证据保全与禁毁通知` |
| 合法收集、镜像或现场取证步骤终稿 | `合法收集书证电子证与财务痕迹` |
| 调查报告或事实认定终稿 | `形成内部调查报告` |
| 金额测算终稿 | `测算舞弊损失与追偿` |
| 向机关披露或交自查 | `准备主动披露或自查报告` |
| 向监管交卷与特权日志 | `准备向监管提交材料与特权日志` |
| 劳动处分、解除、仲裁证据包 | 劳动领域 |
| 刑事辩护、控告、阅卷 | 刑事领域 |
| 个人信息或网安专项体系 | 数据隐私领域 |

已经决定就某一线索出报告或向机关交材料时负触发。不得因「要求今天交卷」或「要求保证已完整」关窗。不得因「是否调查尚未判断」负触发吞掉本窗；查不查只转介 `评估是否启动内部调查`，案卷矩阵可留。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、阅卷、辩护词、刑事控告为主成果 | 刑事领域 |
| 劳动合同、解除、工伤、职场性骚扰或日常处分决定主轴 | 劳动领域 |
| PIPL 合法性、出境、等保、网安事件专项 | 数据隐私领域 |
| 垄断协议、滥用支配地位、经营者集中申报 | 竞争法领域 |
| 税务处理、稽查实体 | 税务领域 |

综合建卷主轴可留本任务；专项只作为背景时在缺口标明。渠道回扣线索不是不正当竞争整案转出信号。

## 易混

「把材料整理一下」若需要要件、举证责任和合法取得，属正触发；若只要结论，走报告。「IT 说已经备份」不是已入卷。「先黑进私人微信再补授权」整体停止，不是负触发。「账上可能被删」只开持有接口和编目红旗，不整案停、不指导删除。已有监察调取通知仍要「把不利件拿掉再装订」：整体停止，不是负触发。
