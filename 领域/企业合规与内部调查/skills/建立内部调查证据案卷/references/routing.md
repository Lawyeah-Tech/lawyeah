# 边界与路由

## 正触发

已有或准备内部调查，主成果是把材料做成可回链案卷矩阵。授权、范围或材料未闭合仍正触发：有可编号材料或可编号缺口则闸开或半开，出 `JW#` 草案，保持草案。本次不定罪、不等于已质证、不代提交、不执行发送是交付禁令，不是开窗条件。保证已完整、今天必须交卷、猜测写成已查清、目录即结论、口头即已入卷、复制哈希即已固定、对方控制即已持有、私录一律可采或一律排除、企业设备一律当然可采、民企套 177／42 号令、未知写零，仍正触发。

双方秘密、入侵、偷拷、伪造、隐匿、选择性不入卷、已有监察公安检察文书仍要拿掉不利件的停止，优先于负触发。上述信号不在下表。不定罪不是负触发。「口头即已入卷」「内部案卷即已质证」「对方控制即已持有」不在下表。入侵隐匿不在下表，走整体停止。
