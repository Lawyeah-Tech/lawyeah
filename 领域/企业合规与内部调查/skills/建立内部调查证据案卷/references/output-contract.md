# 输出合同

按触发结果选择交付形状。禁止在缺输入时用估计材料填满栏目。禁止把案卷写成调查结论。禁止把保存通知写成法院保全。禁止未知写零。禁止选边治愈。不定罪。不代提交。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出 | 第 1 节（触发与分流）、第 2 节（来源）、第 10 节（交接）。不填第 5–9 节 |
| 该部分整体停止（单类违法取证） | 十节表头可在；该 `EV#` 只写停止原因，不给方法。其余合法编目可部分形成 |
| 整体停止 | 第 1 节（停止原因）、第 10 节。禁止案卷矩阵、补证步骤、选边。双方秘密、全面违法取证、借案卷平行灭证第一次即停，优先于负触发；无选边治愈，无「坚持」门槛 |
| 用户要未知写零、缺失即未发生、潜规则即已贿赂、把案卷当结论、选定某局、唯一截止日（不关窗） | 十节表头均出现；对应格填 `现有依据不支持` 或字段停止；不得改走负触发关窗；不得标案卷终稿 `已形成` |
| 正触发且可建卷 | 下列十节表头均出现；未核验格填待核；禁止为填满而写已查实、已构罪或材料没有就是没发生 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。双方秘密未解不得进入「部分形成」。每个 `EV#` 必须带合法取得判断。`L#` 不得直接抄技能内条号。

分流理由只放第 1 节。第 3 节不得写专项分流。

## 1. 触发、单方立场、授权与成果状态

谁要案卷。代表公司还是被调查对象，互斥。案卷闸是否打开。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。本成果不是调查结论。

## 2. 来源登记与 MCP 调用表

`S/D/A/R/C/L/I/G/Q/EV/V`。口头有利推定只登记 `S#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 签发主体、范围和程序状态

调查授权。范围（系统×期间×对象）。检查／监察／公安程序表：机关、案号、文书、作出、收到、送达、效力。口头不得升格已立案。

## 4. 已确认、争议及缺失事实时间线

冲突并列。材料缺失单独标 `G#`，不得写成事件未发生。

## 5. 争点要件与举证责任 `Q#`

完整固定列。只拆已出现事实。禁止铺开未出现的贿赂闭集。未核验不得写倒置。

## 6. 证据编目 `EV#`

支持与不利并列。控制方、取得方式、原件或副本、合法取得必填。截图标明副本。对方控制不得推定存在。

## 7. 合法取得、排除接口与举报人保密

私人微信无授权不得设计强取。排除只标接口。举报人身份加密，不得入可外传目录。

## 8. 缺口、合法补证和最晚时点

只列合法步骤和转介。不交付持有通知、收集步骤或报告终稿。最晚时点能确定才写日期。

## 9. 风险与下一步

每项含可逆性。只转介：`评估是否启动内部调查`、`准备证据保全与禁毁通知`、`合法收集书证电子证与财务痕迹`、`形成内部调查报告`、`测算舞弊损失与追偿`、`评估律师工作产品与保密边界`、`准备调查访谈提纲与笔录结构`、`设计举报人保护与反报复措施`。禁止发送指令、违法取证指令、此致某局。

## 10. 缺口、停止项与提示

须列对方最强解释：没有材料就是没发生、截图就是原件、对方邮箱里一定对我们有利、行业潜规则就是回扣、案卷等于已查实、先把私人微信拷出来、两边材料选边。

本成果不是调查报告、不是诉状、不是持有通知、不是证据三性裁决、不给胜诉率。禁止违法取证。不定罪。

## 综合提问的强制降级

用户同时问查不查、材料全不全、能不能偷拷、哪天到期、向哪个局交时，第 5–8、9 节仍只给接口和转介；偷拷走该部分或整体停止。
