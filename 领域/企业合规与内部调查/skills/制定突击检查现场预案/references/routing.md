# 边界与路由

## 正触发

尚未被检查，需要可演练的现场角色、证件核验、封存配合与禁止动作预案，而不是现场应对、交卷清单或复议诉讼。仅电话预约、人未到场、书面通知未送达且主成果是预案，仍正触发留本窗。值班、机关类型、场所未核验仍正触发：有可编号角色或场所碎片则闸开或半开，出 `YU#` 草案。印发即已过关、演练即已有效、等律师即可拒绝配合、无证件即可关门藏物、今天必须保证过关、选定某局、口头尽快即法定截止，仍正触发。

双方秘密、指导销毁或藏匿、指导拖延转移、指导阻挠合法检查、统一虚假陈述、打击报复的停止，优先于负触发。上述信号不在下表。「印发即已过关」「演练即已有效」「等律师即可拒绝配合」「无证件即可关门藏物」「今天必须保证过关」「选定某局」不在下表。「不阻挠合法检查」「不教藏匿」「不保证过关」「不定罪」「不选定机关」是交付禁令，不在下表。销毁方法不是负触发。出现「检查」「预案」「接待」一词不是转出。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 人员已到场或书面检查通知已送达，且主成果是现场应对 | `应对监管检查或突击检查` |
| 交卷清单与特权日志 | `准备向监管提交材料与特权日志` |
| 对内持有或禁毁通知 | `准备证据保全与禁毁通知` |
| 行政复议或行政诉讼文书 | 行政争议领域 |
| 税务稽查实体 | 税务领域 |
| 反垄断调查现场主轴 | 竞争法领域 |
| 刑事侦查、辩护或阅卷 | 刑事领域 |
| 劳动处分或解除 | 劳动领域 |

不得因「不阻挠合法检查」「不教藏匿」「不保证过关」「不定罪」「不选定机关」关窗。印发即已过关、等律师即可拒绝配合、无证件即可关门藏物该格不支持，窗口不关，不转出。主成果才转。禁止英文 slug。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 税务处理决定、稽查实体为主成果 | 税务领域 |
| 垄断协议、滥用支配、经营者集中为主成果 | 竞争法领域 |
| 劳动合同、解除主轴且预案不是主成果 | 劳动领域 |

综合尚未被查的现场预案主轴可留本任务。检查或已立案只作背景，主成果才转。人员已在场则负触发转应对窗，不在本窗出应对终稿。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 检查已开始 | `应对监管检查或突击检查` |
| 交卷与特权日志 | `准备向监管提交材料与特权日志` |
| 对内禁毁或持有 | `准备证据保全与禁毁通知` |
| 主动披露或自查 | `准备主动披露或自查报告` |
| 整改方案 | `准备合规整改方案` |
| 律师工作产品 | `评估律师工作产品与保密边界` |
| 税务稽查实体 | 税务领域 |
| 反垄断现场主轴 | 竞争法领域 |
| 复议诉讼 | 行政争议领域 |

## 易混

预案闸打开不是已过关。草案不是已有效。印发预案不是已过关。演练签到不是已有效。联系律师不是拒绝配合。无证件不得视为合法检查，但不得暴力阻挠，不得关门藏物。预案不是对抗检查。等律师不是拒绝出示已在检查范围内的材料。不阻挠合法检查、不教藏匿、不保证过关、不定罪、不选定机关是交付禁令，不是负触发。口头「印了就过关」不是开闸材料。可编号角色或场所碎片才开闸。指导销毁藏匿或阻挠合法检查是第一次整体停止，不是不关窗，也不是负触发「安全停止」。
