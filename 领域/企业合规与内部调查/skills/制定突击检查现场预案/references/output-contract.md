# 输出合同

按触发结果选择交付形状。预案闸未打开不得交付「已过关」或「已有效」。禁止把印发写成已过关。禁止把演练写成已有效。禁止把等律师写成拒绝配合。禁止把无证件写成关门藏物。禁止保证过关。禁止选定某局。禁止选边治愈。不保证免责。未知不写零。不定罪。不阻挠合法检查。不教藏匿。本窗 `YU#` 是预案行草案，不是期限卡，不是现场应对终稿。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出 | 第 1 节（触发与分流）、第 2 节（来源）、第 10 节（交接）。不填第 5–9 节 |
| 整体停止 | 第 1 节（停止原因）、第 10 节。禁止 `YU#` 正文、选边、销毁藏匿步骤。双方秘密、指导销毁藏匿、拖延转移、阻挠合法检查第一次即停，优先于负触发；无选边治愈，无「坚持」门槛 |
| 预案闸关闭（仍正触发） | 十节表头均出现；第 5 节只交闸／`Q#`；第 6 节不出 `YU#` 终稿；不得改走负触发或只交 1+2+10 |
| 用户要印发即已过关、演练即已有效、等律师即可拒绝配合、无证件即可关门藏物、今天必须保证过关、选定某局（不关窗） | 十节表头均出现；对应格填 `现有依据不支持`；闸已开仍出其他 `YU#` 草案；不得标终稿 `已形成` |
| 正触发且闸开 | 下列十节表头均出现；未核验格填待核；禁止为填满而写已过关或已有效 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入预案终稿已形成。双方秘密未解不得进入「部分形成」。每个 `YU#`／`Q#` 必须带来源和判断三值。`L#` 不得直接抄技能内条号。稿件状态默认 `草案`。本窗不执行发送。不代到场。预案闸打开不等于已过关。

分流理由只放第 1 节。第 3 节不再写专项分流。第 7 节只保留应对、交卷与禁毁接口，不得把 `YU#` 终稿改放到第 7 节绕闸。

## 1. 触发、单方立场、预案闸与成果状态

谁要预案草案。立场互斥（默认公司或其调查受托律师）。预案闸是否打开。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。不定罪。不保证过关。草案不是已有效。预案闸打开不等于已过关。利益冲突未解不是整体停止。

## 2. 来源登记与 MCP 调用表

`S/D/A/R/C/L/I/G/Q/YU/V/E`。口头「印了就过关」「律师没到就能拒」只登记 `S#`／`V#`。`E#` 是证据形态回链（值班表、角色授权、场所清单），不是发送闸。MCP 未调用也留一行。噪声命中须登记：2017 年行政处罚法第三十七条、印发即已过关、现场检查笔录升格已过关。

## 3. 主体与强制接口

可能机关类型分列，不选定唯一机关。出示证件、协助不得阻挠、监察如实提供分列。本节禁止出 `YU#` 终稿。

## 4. 场所、角色碎片与值班

场所、数据中心、接待／核验／记录／IT／发言人及其 `E#`。口头不得升格已有效。无值班表记 `G#`。本节禁止出 `YU#` 终稿。

## 5. 预案闸与路径矩阵 `Q#`

本节禁止出 `YU#` 终稿。无件则 `Q-件` 关闭，窗口不关。`Q-印`／`Q-演`／`Q-律`／`Q-证`／`Q-关`／`Q-局`／`Q-限` 不得打开已过关、已有效、拒绝配合、关门藏物、保证过关或选定机关。`Q-应`／`Q-卷` 只开接口或按主成果负触发。`Q-伪` 不是可打开路径。

## 6. 预案行 `YU#`

闸未开不得出预案终稿。闸已开且仅部分格被错误主张打中：仍出其他 `YU#` 草案，被打中的格填 `现有依据不支持`。无 `E#` 不得写已过关。状态 `草案`。禁止印发即已过关。禁止演练即已有效。禁止等律师即拒绝配合。禁止无证件即关门藏物。禁止本窗出 `K#` 应对终稿或藏匿步骤。

## 7. 应对、交卷与禁毁接口

已开始只开 `应对监管检查或突击检查` 接口。交卷只开特权日志接口。禁毁只开持有通知接口。本节不得夹带 `YU#` 终稿。不代到场。闸未开时只写「转介待角色编号」，不得补写已过关。

## 8. 边界、转介与最强反方

须列印发即已过关、演练即已有效、等律师即可拒绝配合、无证件即可关门藏物、今天必须保证过关、选定某局、两边选边等最强反方。

## 9. 风险与下一步

每项含可逆性。一次只推荐下一步。只转介：`应对监管检查或突击检查`、`准备向监管提交材料与特权日志`、`准备证据保全与禁毁通知`、`准备主动披露或自查报告`、`准备合规整改方案`、`评估律师工作产品与保密边界`、行政争议领域、税务领域、竞争法领域。禁止提交指令、此致某局、选定法院。不代到场。

## 10. 缺口、停止项与对方最强解释

须列对方最强解释：预案印发了所以已经过关、演练签到了就是有效、律师没到就能拒交范围内材料、没出示证件就该关门把硬盘拿走、联系律师就是拒绝配合、两边材料选边、检查车到门口先转移材料。

本成果不是已过关证明、不是已有效证明、不是现场应对终稿、不是交卷清单、不是禁毁通知、不保证过关、不保证免责。不定罪。草案不是已有效。印发不是已过关。等律师不是拒绝配合。无证件不是关门藏物。联系律师不得写成拒绝配合。

## 综合提问的强制降级

用户同时问印发算不算已过关、律师没到能不能拒、无证件能不能关门，第 5–8、9 节仍只给接口和转介，对应格不支持，闸已开仍出其他 `YU#`。主成果是检查已开始：负触发转 `应对监管检查或突击检查`。提出指导销毁藏匿、拖延转移或双方秘密：第一次整体停止，只交第 1、10 节，不填第 5–9 节，不把藏匿口子降级为不关窗继续出表。
