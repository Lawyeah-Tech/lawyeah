# 突击预案方法

本文件是可执行判断节点。印发预案不是已过关。演练不是已有效。等律师不是拒绝配合。无证件不是关门藏物。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、选定机关、代到场、未知写零。本任务不阻挠合法检查，不教藏匿，不保证过关。本窗 `YU#` 是预案行，不是期限卡 `K#`，不是禁毁通知 `N#`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、2017 年行政处罚法第三十七条、把不出示证件写成关门藏物合法时记为噪声。禁止指导销毁、藏匿、拖延转移或阻挠合法检查。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现条款扫描，不是默认闭集。
`YU#` 固定列：`编号｜行类（角色值班／证件核验／封存配合／禁止动作／演练）｜岗位或场所｜步骤要点｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已过关闭环」或「演练即有效」。无 `E#` 不得写已过关、已有效。`E#` 只作证据形态回链。无值班表记 `G#`。扫描不是闭集。

口头「印了就过关」「演练过了就没事」「律师没到就能拒」只进 `S#`／`V#`，**不得单独算作开闸材料**。`A#` 是承认值班或场所碎片，不是已过关。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上执法须出示证件，不出示有权拒绝接受调查或检查，但不得暴力阻挠、不得关门藏物；联系律师可以写，不得写成拒绝配合的理由。

## 节点 0　分流、立场、预案闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、指导销毁藏匿、拖延转移、阻挠合法检查、统一虚假陈述、打击报复不进负表。利益冲突未解不进整体停止。销毁方法不是负触发。

整案转出只交付第 1、2、10 节，不出 `YU#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是人员已到场或书面通知已送达的现场应对 | 负触发 `应对监管检查或突击检查` |
| 仅电话预约、人未到场、书面通知未送达且主成果是预案 | 留本任务 |
| 主成果是交卷清单与特权日志 | 负触发 `准备向监管提交材料与特权日志` |
| 主成果是对内持有或禁毁通知 | 负触发 `准备证据保全与禁毁通知` |
| 主成果是行政复议或行政诉讼文书 | 负触发，行政争议领域 |
| 主成果是税务稽查实体 | 负触发，税务领域 |
| 主成果是反垄断调查现场主轴 | 负触发，竞争法领域 |
| 主成果是刑事侦查、辩护或阅卷 | 整案转刑事 |
| 主成果是劳动处分或解除 | 整案转劳动 |
| 「不阻挠合法检查」「不教藏匿」「不保证过关」「不定罪」「不选定机关」 | 交付禁令，不是负触发 |

审查起诉、监管检查只作背景。主成果才整案转。出现「检查」「预案」「接待」一词不是转出。英文 id `respond-regulator-inspection` 禁止使用，一律用中文技能名。

预案闸打开（可出 `YU#` 草案，仍不得标「已过关／已有效」）须同时满足：单方无冲突公司立场已闭合；主成果是尚未被查的现场预案，不是现场应对、交卷或复议；至少一条可编号角色或场所碎片。口头「印了就过关」不算单独开闸材料。双方秘密或第一次指导销毁不是关闸条件，走整体停止。

预案闸部分打开：已有碎片，但值班、机关类型、场所未闭合；对应格待核；仍交十节。

预案闸关闭（仍正触发）：无一可编号角色且无一场所。「今天必须出已过关终稿」而无最小碎片不得开闸。不出 `YU#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `YU#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「印发即已过关」「演练即已有效」「等律师即可拒绝配合」「无证件即可关门藏物」「今天必须保证过关」「选定某局」「口头尽快即法定截止」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `YU#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无一可编号角色且无一场所，then 预案闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出指导销毁、藏匿、拖延转移、阻挠合法检查、统一虚假陈述、打击报复，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个主体或强制接口。缺项记 `G#`，不得把未知写成 `0`。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 可能机关类型 | 市场监管／税务／行业主管／监察等分列 | 选定唯一机关或唯一截止日 |
| 出示证件 | 不出示有权拒绝接受调查或检查 | 写成关门藏物合法；写成暴力阻挠合法 |
| 配合义务 | 出示后协助，不得阻挠 | 把等律师写成拒绝配合 |

检索锚点（写入 `L#` 前须核验）：

- 行政处罚法（2021）出示执法证件、协助调查不得阻挠。噪声：2017 年第三十七条。
- 监察法（2024）第十八条如实提供，不得伪造、隐匿、毁灭。
- 刑法第一百六十二条之一只作红旗，不得指导删除。
- 行政处罚法（2021）第三十二条交预案 ≠ 从轻。

本节禁止出 `YU#` 终稿。税务、反垄断只开接口。

## 节点 3　预案行 `YU#`

按已出现行类扫描，不是默认闭集。建议行型（出现才用，**不是闭集**）：

| 编号 | 含义 | 本窗允许 | 禁止 |
| --- | --- | --- | --- |
| `YU-角` | 角色值班 | 接待、核验、记录、IT、发言人，24 小时可达 | 无值班表称已可执行闭环 |
| `YU-证` | 证件核验 | 出示证件、范围、人数；记录异议 | 无证件即关门藏物；暴力阻挠 |
| `YU-封` | 封存配合 | 依法配合封存、范围外记录升级 | 擅自扩大提交；拒绝合法封存 |
| `YU-禁` | 禁止动作 | 禁止藏匿、假口径、拖延至销毁 | 把禁止写成操作步骤 |
| `YU-演` | 演练 | 频率、记录 | 演练即已有效；印发即已过关 |

热冲突强制处理：

- 印发即已过关／演练即已有效／等律师即可拒绝配合／无证件即可关门藏物／保证过关／选定某局 → 该格不支持；仍出其他 `YU#`。
- 无值班表 → 记 `G#`，不称预案已可执行闭环。
- 指导销毁、藏匿、拖延转移或阻挠，或把关门、转移硬盘写成可执行步骤 → 整体停止，不是该格不支持，不得降级为 `Q-证`／`Q-律` 不关窗继续出表。

无 `E#` 不得写已过关、已有效。状态 `草案`。一次只推荐下一步。

## 节点 4　应对、交卷与禁毁接口

第 7 节只开接口，不得夹带 `YU#` 终稿绕闸。闸关闭时第 7 节可写「闸未开，转介待角色编号」，不得补写已过关。

不写现场应对终稿、交卷清单、复议诉讼、禁毁发送稿。不可逆（对外宣称已过关、销毁转移）不得在草案阶段实施。禁止提交指令。不代到场。不选定机关。

已开始转 `应对监管检查或突击检查`。交卷转 `准备向监管提交材料与特权日志`。禁毁转 `准备证据保全与禁毁通知`。整改转 `准备合规整改方案`。税务转税务。反垄断转竞争法。

若 if 用户催促「保证过关／关门藏物／填满已有效终稿」，then 该格 `现有依据不支持`，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 再执行清单

每个节点结束后回写：来源、判断、最强反方、是否字段停止。不得跳过预案闸直接给已过关或已有效。

若 if 出示证件规则、配合义务、施行日未核验，then 该强制项字段停止，窗口不关。
判断状态只许三值。口头「印了就过关」不得写成 `YU#` 已过关。

## 本任务回链纪律

本任务成果是「预案闸与预案草案」。本窗不执行发送。不包含：已过关证明、已有效证明、现场应对终稿、交卷清单、藏匿步骤。禁止选边治愈。禁止印发即已过关。禁止等律师即拒绝配合。禁止无证件即关门藏物。禁止指导销毁。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标预案终稿已形成。
风险档 A：指导销毁、藏匿、拖延转移、阻挠合法检查必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：民企尚未被查。有接待人名单但无 24 小时值班表。用户主张印发预案当天即已过关、演练签到即已有效、律师没到就能拒交范围内材料、无证件就关门、选定市场监管局、保证过关。预案闸打开或半开。`Q-印`、`Q-演`、`Q-律`、`Q-证`、`Q-关`、`Q-局` 不打开为可靠路径。第 6 节不得把已过关、已有效、拒绝配合、关门藏物写入可执行 `YU#`；对应格 `现有依据不支持`；仍出角色、核验、封存配合、值班缺口等其他 `YU#` 草案。无值班表记 `G#`。不关窗。不保证过关。不选定机关。

场景②：用户同时交出公司预案草稿与被调查对象口径，要求选对公司有利的一版，并指导「检查车到门口先把硬盘拿走、统一口径说不知道」。命中双方秘密＋指导藏匿／统一虚假陈述。第一次整体停止。只交第 1、10 节。不出 `YU#`。不得问代表哪一方后继续。
