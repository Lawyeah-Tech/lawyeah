# 边界与路由

## 正触发

已决定提起民事追偿之诉，需要请求权分列、管辖时效接口和证据目录，而不是谈判方案、测算终稿、刑事控告或发送版起诉状。从零、碎片、管辖未核验、无书面起诉授权仍正触发：有被告或请求权则闸开或半开，出 `QS#` 草案，保持草案。调查报告即诉状、草案即已立案、选定某院、保证胜诉、时效未核验即仍充足、先刑后民所以不能民事起诉，仍正触发。

双方秘密、指导伪造证据、虚假诉讼、夹带刑事控告方法、威胁证人、打击报复的停止，优先于负触发。上述信号不在下表。「调查报告即诉状」「草案即已立案」「选定某院」「保证胜诉」「时效未核验即仍充足」「口头返还即无损失」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 谈判方案 | `谈判民事追偿与返还方案` |
| 损失测算终稿 | `测算舞弊损失与追偿` |
| 调查后路径比较 | `评估调查后处置路径` |
| 调查报告终稿 | `形成内部调查报告` |
| 证据案卷终稿 | `建立内部调查证据案卷` |
| 合同价款、质量或交付争议 | 合同争议领域 |
| 劳动经济补偿或须仲裁前置的劳动争议 | 劳动领域 |
| 刑事控告、辩护、自首或附带民事 | 刑事领域 |
| 资金保全或冻结方案 | `评估内部账户冻结与资金保全` |

不得因「不代提交」或「不写刑事控告」或「今天视为已立案」关窗。拟诉仍正触发，不得写成已立案或已提交。

## 易混

调查报告不能直接当诉状。草案不是已立案。民事起诉不是刑事报案。口头返还不是无损失。管辖连结点并列，不是已确定某院。时效未核验不是仍充足。劳动争议可能仲裁前置，不是当然直接起诉。起诉状范本不是已立案。群已读不是已提交。本窗 `QS#` 不是谈判行，不是测算行。本窗闸名只能是诉材闸，禁止复用起诉闸。法院保全只开接口，不出终稿。内部止付转冻结窗。证据目录不是已质证。先刑后民不是当然不能起诉。「缺的转账先 P 一张」整体停止。本窗不执行发送，不代提交。审查起诉只作背景，主成果才转刑事。
