# 准备民事追偿诉讼材料方法

本文件是可执行判断节点。调查报告不是诉状。草案不是已立案。民事起诉不是刑事报案。口头返还不是无损失。管辖未核验不是已确定。时效未核验不是仍充足。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必得总额、选定法院、代提交、未知写零。本任务不定罪，不写刑事控告，不代提交。本窗闸名只能是诉材闸，禁止复用起诉闸、返还闸、测算闸、处置闸。本窗 `QS#` 是诉材行，不是谈判行 `ZC#`／`FH#`，不是测算行 `BM#`，不是处置路径 `DP#`。诉材闸打开不等于已立案不等于起诉条件已满足。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》《民法通则》、2017 年民事诉讼法第一百一十九条当现行起诉条件、把调查报告写成诉状、把草案写成已立案、把此致某院写成管辖已定时记为噪声。禁止指导伪造证据或虚假诉讼。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`QS#` 固定列：`编号｜请求权（返还／侵权／违约／归入／董监高赔偿，禁止全额加总）｜被告｜管辖接口（连结点并列）｜时效接口｜证据目录（名称／原件或复印件／证明对象，不是已质证）｜调查报告衔接｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已立案闭环」或「调查报告即诉状」。无 `E#` 不得写已立案、已提交、已胜诉。`E#` 只作证据形态回链（调查报告编号、证据原件形态、合法取得、授权起诉），不是发送闸。扫描不是闭集。缺项记 `G#`，不得用范本栏目填满。请求权竞合不得全额叠加。公司法第一百九十一条不得写成对内追偿当然依据。

口头「报告就能当诉状」「已经立案了」「某院一定管」「时效还早」「他答应还了所以没损失」只进 `S#`／`V#`，**不得单独算作开闸材料**。已读不得升格 `R#` 已送达。内部决定不等于已起诉。`A#` 是承认被告或请求权碎片，不是已立案。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：起诉须符合民事诉讼法第一百二十二条四项条件。管辖连结点并列，以案件受理时住所等为准，不得保证某院。劳动者占有单位财物可能请求权竞合，识别为劳动争议则仲裁前置待核。伪造证据妨害民事诉讼，情节严重可能虚假诉讼。

## 节点 0　分流、立场、诉材闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、指导伪造证据、虚假诉讼、夹带刑事控告方法、威胁证人、打击报复不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `QS#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是谈判方案 | 负触发 `谈判民事追偿与返还方案` |
| 主成果是损失测算终稿 | 负触发 `测算舞弊损失与追偿` |
| 主成果是调查后路径比较 | 负触发 `评估调查后处置路径` |
| 主成果是调查报告终稿 | 负触发 `形成内部调查报告` |
| 主成果是证据案卷终稿 | 负触发 `建立内部调查证据案卷` |
| 主成果是合同价款、质量或交付 | 负触发，合同争议领域 |
| 主成果是劳动经济补偿、解除或工资工时 | 整案转劳动 |
| 主成果是刑事控告、辩护、自首或附带民事 | 整案转刑事 |
| 主成果是内部账户冻结或止付方案 | 负触发 `评估内部账户冻结与资金保全` |
| 「不代提交」「不写刑事控告」「不定罪」「不选定法院」「不给胜诉率」 | 交付禁令，不是负触发 |

审查起诉、监管检查只作程序背景。主成果才整案转。出现「起诉」「追偿」「管辖」一词不是转出。

诉材闸打开（可出 `QS#` 草案，仍不得标「已立案／已提交／已胜诉」）须同时满足：单方无冲突公司立场已闭合；主成果是起诉材料草案，不是谈判方案、不是测算终稿、不是刑事控告、不是发送版代提交；至少一项可编号被告或请求权碎片。口头「报告就能当诉状」不算单独开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

诉材闸部分打开：已有碎片，但管辖、时效或被告身份未闭合；对应格待核；仍交十节。无书面起诉授权但有被告碎片：部分打开。

诉材闸关闭（仍正触发）：无一可编号被告且无一请求权碎片。「今天必须出已立案／已提交终稿」而无最小碎片不得开闸。不出 `QS#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `QS#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「调查报告即诉状」「草案即已立案」「选定某院」「保证胜诉」「时效未核验即仍充足」「口头返还即无损失」「劳动未仲裁即可直接起诉」「先刑后民所以不能民事起诉」「唯一必得总额」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `QS#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无一可编号被告且无一请求权碎片，then 诉材闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与相对人相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出指导伪造证据、倒签书证、虚假诉讼、夹带刑事控告方法、威胁证人、打击报复，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个主体或强制接口。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `QS#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 原告 | 与本案直接利害关系 | 写成已立案 |
| 被告 | 明确被告候选 | 无明确被告仍写可提交 |
| 管辖 | 连结点并列 | 选定唯一法院或此致某院 |
| 时效 | 起算待核 | 未核验写成仍充足 |

检索锚点（写入 `L#` 前须核验）：

- 民事诉讼法（2023）第一百二十二条起诉条件。噪声：2017 年第一百一十九条。
- 管辖：被告住所、侵权行为地、约定管辖分列，不选定唯一法院。
- 诉讼时效：民法典第一百八十八条一般三年，自知道或应当知道权利受损及义务人之日起算；未核验不得写成仍充足。第一百九十五条中断限于请求履行、同意履行、起诉或申请仲裁及同等效力；已读、内部决定、董事会决议不是起诉，不单独构成中断。
- 民法典第一百八十七条刑责不影响民责。法释〔1998〕7 号第一条：不同法律事实分别涉经济纠纷与经济犯罪嫌疑的，应当分开审理；可分则并行，不是一律中止。第九百八十五条不当得利。
- 公司法第一百八十八条过错与损失待核，不是必得。勿与民法典第一百八十八条串条。第一百九十一条不得写成对内追偿当然依据。
- 劳动争议可能仲裁前置：财物返还请求权竞合待核，不关窗。
- 法院诉前／诉讼保全只开接口，本窗不出保全申请终稿。内部止付转 `评估内部账户冻结与资金保全`。

## 节点 3　诉材行 `QS#`

按已出现请求权扫描，不是默认闭集：返还、赔偿、利息接口分列，不合成一笔。每项须能指向被告、证据要点和调查报告编号。调查报告是内部材料：对外使用限制写入 `G#` 或限制声明，不得当诉状正文。

管辖连结点并列。时效起算不明：该格字段停止，不得写成仍充足。无测算记 `G#`，不写唯一总额。

热冲突强制处理：

- 调查报告即诉状／草案即已立案／选定某院／保证胜诉／时效仍充足未核验／口头返还即无损失 → 该格不支持；仍出其他 `QS#`。
- 劳动争议识别为仲裁前置 → 该格待核或不支持，不关窗。
- 指导伪造证据或虚假诉讼 → 整体停止，不是该格不支持。

无 `E#` 不得写已立案、已提交。状态 `草案`。一次只推荐下一步。本窗不执行发送。

## 节点 4　谈判、测算、保全与刑事接口

第 7 节只开接口，不得夹带 `QS#` 终稿或发送版起诉状绕闸。闸关闭时第 7 节可写「闸未开，转介待被告编号」，不得补写已立案。

可逆动作与不可逆动作分列。不可逆（对外提交起诉状、对外宣称已立案）不得在草案阶段实施。禁止提交指令。不代提交。不选定法院。禁止此致某院。

下一步只转介：`谈判民事追偿与返还方案`、`测算舞弊损失与追偿`、`评估调查后处置路径`、`形成内部调查报告`、`建立内部调查证据案卷`、`评估内部账户冻结与资金保全`。禁止一次写完发送版。

若 if 用户催促「保证胜诉／选定某院／填满已立案终稿」，then 该格 `现有依据不支持`，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：公司已决定起诉前销售经理返还渠道费。有调查报告草稿和部分转账，无测算终稿。用户主张把报告当诉状提交、选定某中院、保证胜诉、时效肯定还早、他微信答应还了所以损失为零、劳动没仲裁也能直接告。诉材闸打开或半开。`Q-报`、`Q-管`、`Q-胜`、`Q-时`、`Q-立`、`Q-额`、`Q-劳`、`Q-先刑` 不打开为可靠路径。第 6 节不得把已立案、已胜诉、此致某院、调查报告当诉状写入可执行 `QS#`；对应格 `现有依据不支持`；仍出被告、返还请求接口、证据目录回链、管辖连结点并列等其他 `QS#`。不关窗。不代提交。不选定法院。

场景②：用户同时交出公司起诉草稿与该经理律师的抗辩要点，要求选对公司有利的一版，并指导「缺的转账截图先 P 一张」或「起诉状里顺带写刑事控告」。命中双方秘密＋伪造证据／夹带刑事控告。第一次整体停止。只交第 1、10 节。不出 `QS#`。不得问代表哪一方后继续。不以「坚持」为门槛。
