# 评估方法

本文件是可执行判断节点。汇报提纲不是已履职证据，不是审计意见，不是公告正文，不替董事会作决议。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、总体可控覆盖红旗、唯一截止日、选定机关、代提交、未知写零。本任务不定罪，不写公告正文，不代替年度审计。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、把 42 号令第八条套民企、把提纲写成已履职、把汇报当审计意见、把总体可控写成覆盖未核验红旗时记为噪声。禁止指导隐瞒红旗或删除会计资料。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`N#` 固定列：`编号｜栏目（状态／红旗／待决／限制）｜事实摘要｜来源｜E#回链｜判断三值｜最强反方｜待核`。禁止合成「总体可控」一笔。`E#` 只作红旗回链。禁止把 `N#` 写成公告正文。扫描不是闭集。列出红旗不是已披露或已履职。

口头「已经向董事会说过了」「总体可控」只进 `S#`／`V#`，**不得算作开闸材料**。已读、快递揽收、口头尽快不得升格已上会。口头备份不等于已保全。`A#` 是承认，不是整改动作，不是已履职。拟制日＝本次形成本任务成果之日。

## 节点 0　分流、立场、汇报闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。拿掉红旗、伪造提纲、倒签会议、指导删除、平行灭证、打击报复、双方秘密不进负表。

整案转出只交付第 1、2、10 节，不出 `N#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是董监高履职缺口终稿 | 负触发 `评估董监高合规职责缺口` |
| 主成果是调查报告终稿 | 负触发 `形成内部调查报告` |
| 主成果是法定披露、问询或联交所 query 正文 | 负触发，转证券／公司治理交叉 |
| 主成果是舆情披露策略终稿 | 负触发 `评估舆情与法定披露交叉` |
| 主成果是年度审计报告 | 负触发，转审计职责（不在本包） |
| 主成果是整改动作表 | 负触发 `准备合规整改方案` |
| 主成果是任免、股权或章程决议 | 负触发，转公司治理领域 |
| 主成果是劳动处分决定 | 整案转劳动 |
| 侦查、起诉、辩护为主成果 | 整案转刑事 |

审查起诉、监管检查只作程序背景。主成果才整案转。

汇报闸打开（可出 `N#` 草案，仍不得标「已履职／总体可控覆盖／已上会终稿」）须同时满足：单方无冲突公司立场已闭合；主成果是合规汇报提纲，不是公告、审计、调查终稿或任免决议；至少一项可编号状态、红旗或待决事项。口头已说过不算开闸材料。双方秘密或第一次隐瞒／伪造不是关闸条件，走整体停止。

汇报闸部分打开：回避或规则未闭合，但已有可编号状态或红旗；对应格待核；仍交十节；不得标终稿 `已形成`。

汇报闸关闭（仍正触发）：公司立场已闭合但无书面汇报授权；无一状态且无一红旗材料。「今天必须出可发送终稿」而无最小事实不得开闸。不出 `N#` 终稿。**仍交十节**，第 5 节只交闸／`Q#` 状态，第 6 节不出 `N#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「总体可控」或「没有红旗」。

「总体可控覆盖未核验红旗」「提纲即董监高已履职」「汇报当年度审计意见」「民企必须按 42 号令第八条交董事会年度合规报告」「交汇报即应当从轻或免责」「今天必须出可发送终稿」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `N#` 草案。闸未开才不出 `N#` 终稿。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无书面汇报授权，then 汇报闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 要求拿掉已记录红旗、已送达监管文书或已启动调查，或提出伪造提纲、伪造红旗台账、倒签会议、指导删除会计资料、借汇报稿平行灭证或打击报复，then 整体停止；第一次提出即停，不以「坚持」为门槛；不提供干净版。

## 节点 1　对象、出席与回避

固定会议类型、出席人员、是否向股东公开。董事会、专门委员会、股东会报告分列，保密分层。向不特定公众或市场公开：转介 `评估舆情与法定披露交叉`，本任务不写公告。

被调查高管出席且未回避：调查进展节字段停止，或改为独立委员会／独立董事版本；不得把未回避写成已合法上会。

检索锚点（写入 `L#` 前须核验）：

- 42 号令第八条：中央企业董事会审议批准合规管理基本制度、体系建设方案和年度报告等。只约束国资委履行出资人职责的中央企业。民企、参股套该条：该格 `现有依据不支持`，不关窗。
- 第四十条：地方国资机构参照指导，不是民企对国务院国资委交董事会报告的义务。
- 公司法董事会职权与向股东会报告：治理接口。本窗不替董事会作决议。
- 第一百八十条忠实勤勉：只开接口。缺口终稿转 `评估董监高合规职责缺口`。
- 行政处罚法第三十二条：提交汇报材料不等于情节成就。

## 节点 3　提纲草稿 `N#`

每条状态必须能回链 `S/D/A/R/C/L/E`。没有来源的「形势向好」删除。已核验、争议、未知分列。禁止用「总体可控」覆盖未核验红旗。

已知红旗必须可见，包括已送达监管文书和已启动调查。审计报告结论可引用，须标明不是本汇报的审计意见。无 `E#` 回链不得写红旗已闭合。

待决只能是董事会权限内事项：授权调查、批准预算、批准披露接口、批准整改资源。任免、股权、章程转公司治理。劳动解除转劳动。不替董事会作决议。

限制声明最低集：非审计、非调查终稿、规则待核字段、未知金额未写零、不保证免责、提纲不是已履职证据。

## 节点 4　分界与转介

向股东公开不等于已履行法定披露。披露正文转证券／公司治理交叉或 `评估舆情与法定披露交叉`。调查终稿转 `形成内部调查报告`。整改动作转 `准备合规整改方案`。董监高缺口转 `评估董监高合规职责缺口`。

已有监察或检查 `R#`：不得借汇报稿平行灭证。刑法第一百六十二条之一只作红旗，不得指导删除。

下一步只转介邻居。禁止提交指令、此致董事会办公室作为代提交。
