# 边界与路由

## 正触发

需要向董事会、专门委员会或股东提交合规状态书面提纲，而不是审计报告或公告正文。授权或红旗未闭合仍正触发：汇报闸关闭，不出 `N#` 终稿，窗口不关。总体可控覆盖红旗、提纲即已履职、汇报当审计、民企套 42 号令第八条，仍正触发。

双方秘密、拿掉已记录红旗、伪造提纲或红旗台账、倒签会议、指导删除、平行灭证、打击报复的停止，优先于负触发。上述信号不在下表。「总体可控覆盖红旗」「提纲即已履职」「汇报当审计」「民企套第八条」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 董监高履职缺口终稿 | `评估董监高合规职责缺口` |
| 调查报告终稿 | `形成内部调查报告` |
| 法定披露、问询或联交所 query 正文 | 证券／公司治理交叉 |
| 舆情披露策略终稿 | `评估舆情与法定披露交叉` |
| 年度审计报告 | 审计职责（不在本包） |
| 整改动作表 | `准备合规整改方案` |
| 任免、股权、章程决议 | 公司治理领域 |
| 劳动处分决定 | 劳动领域 |
| 刑事辩护、控告 | 刑事领域 |

不得因「要求写成总体可控」或「要求当已履职」关窗。未核验红旗仍正触发，必须可见。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、解除、工伤主轴 | 劳动领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |
| 垄断、滥用支配、经营者集中 | 竞争法领域 |
| 章程、股权、任免本身为主成果 | 公司治理领域 |

综合合规汇报主轴可留本任务。审查起诉或检查只作背景，主成果才转。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 董监高缺口终稿 | `评估董监高合规职责缺口` |
| 调查报告终稿 | `形成内部调查报告` |
| 要公告或 query 正文 | 证券／公司治理交叉 |
| 舆情披露策略 | `评估舆情与法定披露交叉` |
| 整改动作表 | `准备合规整改方案` |
| 确为中央企业且主成果是 42 号令对照 | `评估国企合规管理办法差距` |
| 要替董事会作任免或股权决议 | 公司治理领域 |

## 易混

汇报提纲不是调查报告，也不是「董事会已履职」的证据补丁。红旗必须可见。总体可控不能覆盖未核验红旗。引用审计不是本汇报的审计意见。向股东报告不是法定披露正文。口头说过不是已上会。民企套 42 号令第八条：该格不支持，不关窗。「拿掉红旗出干净版」整体停止。
