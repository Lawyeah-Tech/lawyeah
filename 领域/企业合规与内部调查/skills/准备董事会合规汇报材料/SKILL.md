# 准备董事会合规汇报材料

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。本窗是准备类提纲，范本只借栏目，**不要**升格「已上会／已履职／总体可控」。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现隐瞒红旗、未回避上会的反例；案例只比较事实差异与翻转条件，不写成必然结果。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《民法通则》《民法总则》或其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成可上会的合规汇报草案：汇报闸、汇报对象与回避、`Q#` 路径、`N#` 提纲草稿（状态三态／已知红旗／待决事项／限制声明）、`E#` 红旗回链。提纲不是已履职证据，不是年度审计意见，不是法定信息披露正文，不替董事会作决议。不保证合规免责。不代提交。不执行发送。

`depends-on` 为空。董监高履职缺口终稿转 `评估董监高合规职责缺口`。调查报告终稿转 `形成内部调查报告`。法定披露或联交所 query 正文转证券／公司治理交叉。舆情披露策略转 `评估舆情与法定披露交叉`。整改动作表转 `准备合规整改方案`。有效性五维转 `评估合规管理体系有效性`。42 号令对照终稿转 `评估国企合规管理办法差距`。任免、股权、章程转公司治理领域。

## 工作边界

正触发：需要向董事会、专门委员会或股东提交合规状态书面提纲，而不是审计报告或公告正文。授权、红旗未闭合、会期未定仍正触发：汇报闸关闭，不出 `N#` 终稿，窗口不关。用户要用「总体可控」覆盖未核验红旗、把提纲写成董监高已履职、把汇报当年度审计意见、保证交汇报即从轻或免责、民企按 42 号令第八条必须交董事会年度合规报告、今天必须出可发送终稿，仍正触发：对应格填 `现有依据不支持`，窗口不关；闸已开仍出其他 `N#` 草案。不得因「要求写成总体可控」改走负触发关窗。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是董监高履职缺口终稿（转 `评估董监高合规职责缺口`）；
- 主成果是调查报告终稿（转 `形成内部调查报告`）；
- 主成果是法定信息披露、问询答复或联交所 query 正文（转证券／公司治理交叉）；
- 主成果是舆情与法定披露策略终稿（转 `评估舆情与法定披露交叉`）；
- 主成果是年度审计报告（转审计职责，不在本包）；
- 主成果是整改动作表（转 `准备合规整改方案`）；
- 主成果是任免、股权或章程决议（转公司治理领域）；
- 主成果是劳动处分决定（转劳动领域）。

双方秘密、要求拿掉已记录红旗或已送达监管文书、伪造提纲或红旗台账、倒签会议、指导删除会计资料、打击报复**不在负触发表**，走整体停止。「总体可控覆盖红旗」「提纲即已履职」「汇报当审计意见」「民企套 42 号令第八条」**不在负触发表**，该格 `现有依据不支持`，窗口不关；闸已开仍出其他 `N#`。

## 建立工作坐标

确认：汇报授权；单方立场（公司／治理层，互斥）；会议类型（董事会／专门委员会／股东会报告，分列）；出席与回避名单；已知红旗与监管文书；待决授权；是否并行调查、检查、监察或诉讼。

口头「已经向董事会说过了」「总体可控」「微信已读」只登记 `S#`／`V#`。不得升格已上会、已履职或红旗已闭合，**不得算作开闸材料**。已读、快递揽收不得升格 `R#` 已送达或已上会。口头备份不等于已保全。

同时掌握公司与被调查对象相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。公司已开口且委托就是汇报提纲、且未掌握对方秘密时，可推定公司立场。无书面汇报授权但公司立场已闭合：汇报闸关闭，仍交十节，不是整体停止。提出拿掉已记录红旗、已送达监管文书或已启动调查、伪造提纲或红旗台账、倒签会议、指导删除或打击报复：第一次提出即整体停止，不以「坚持」为门槛，不提供「干净版」。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认（不是整改动作，不是已履职）；`R#` 机关或生效文书；`C#` 内部制度或会议授权；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`N#` 提纲草稿（不是公告正文）；`V#` 版本；`E#` 红旗回链（已知线索、监管文书、调查状态，不是发送闸）。禁止 `EV#`、`M#`、`F#`、`ACT#`、`P#`、`K#`、`O#`、`H#`、`B#`、`U#`、`X#`、`HD#`。技能正文中的条号是检索锚点，不是已核验 `L#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止合成「总体可控」一笔覆盖未核验红旗。扫描不是闭集。列出红旗不是已披露或已履职。未知不写零。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：中央企业合规管理办法第八条，中央企业董事会审议批准合规管理基本制度、体系建设方案和年度报告等，只约束国资委履行出资人职责的中央企业；民企套第八条该格 `现有依据不支持`，不关窗。第四十条是对地方国资机构的参照指导，不是民企对国务院国资委交董事会报告的义务。公司法（2023 修订）董事会职权与向股东会报告是治理接口，本窗不替董事会作决议，提纲不是已履职证据。第一百八十条忠实勤勉只开接口，缺口终稿转 `评估董监高合规职责缺口`。证券法董监高保证披露真实准确完整只开接口，本窗不写公告正文。行政处罚法第三十二条提交汇报材料本身不等于情节成就。监察法第十八条如实提供，不得伪造、隐匿、毁灭。刑法第一百六十二条之一只作红旗，**不得指导删除**。噪声：已失效《合同法》、42 号令第八条套民企、提纲即已履职、汇报当审计意见、总体可控覆盖红旗、交汇报即从轻、口头已读即已上会。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变董事会报告义务或 42 号令主体的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补隐瞒红旗、未回避上会、提纲被写成履职证据的反例。
- `search_template` 只借汇报栏目，不把范本当法定格式、已上会证明或已履职结论。

工具不可用时继续对象、红旗和 `N#` 编目；主体义务、期限字段停止。不得拒跑，不得凭记忆写成已履职、总体可控或民企必须交 42 号令年度报告。

## 判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、汇报闸与不关窗

主成果才整案转出。拿掉红旗第一次停。总体可控、提纲即已履职、民企套第八条不关窗：该格不支持，闸已开仍出其他 `N#`。闸关仍交十节，第 6 节不出 `N#` 终稿。

### 2. 对象、出席与回避

董事会／专门委员会／股东会报告分列。被调查人出席未回避：调查进展节字段停止，或改为独立委员会／独立董事版本；不得因出席而关窗。回避终稿转 `处理利益冲突与调查回避`。

### 3. 汇报闸与路径 `Q#`

本节禁止出 `N#` 终稿。无一可编号状态或红旗材料则闸可关，窗口不关。口头已说过不得开闸。

### 4. 提纲草稿 `N#`

状态三态、已知红旗、待决事项、限制声明分列。无来源的「形势向好」删除。红旗必须可见。

### 5. 分界与转介

不写公告、不写审计意见、不替董事会作决议。调查、披露、整改、董监高缺口只开接口。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；要求拿掉已记录红旗、已送达监管文书或已启动调查；伪造提纲或红旗台账；倒签会议；指导删除会计资料；借汇报稿平行灭证；打击报复。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。不提供干净版。无书面汇报授权但公司立场已闭合：不是整体停止，汇报闸关闭，仍交十节。
- `字段停止`：42 号令主体、会议权限、回避未核验。总体可控覆盖红旗、提纲即已履职、汇报当审计、民企套第八条、交汇报即从轻：该格 `现有依据不支持`，窗口不关；闸已开仍出其他 `N#` 草案；闸未开才不出 `N#` 终稿。
- `目标停止`：主目标变为公告正文、审计报告、调查终稿、任免决议或董监高缺口终稿。

禁止指导隐瞒红旗或删除会计资料。不给胜诉率。不定罪。不保证免责。不选定机关。不代提交。未知不写零。不替董事会作决议。不写公告正文。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。汇报闸关闭仍交十节，第 6 节不出 `N#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `N#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。汇报闸未打开时不得交付提纲终稿或「已履职」。边界见 [路由](references/routing.md)。
