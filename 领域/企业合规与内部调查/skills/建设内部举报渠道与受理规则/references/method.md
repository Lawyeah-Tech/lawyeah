# 评估方法

本文件是可执行判断节点。开通邮箱不是渠道有效。人力资源投诉箱不是廉洁举报渠道。受理不是查实。不得承诺绝对无法追溯匿名。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、范本填满、唯一截止日、选定机关、代提交、未知写零。本任务不调查具体线索，不写发送版回执，不写保护方案或打击报复评估终稿，不定罪，不代提交。本窗 `CH#` 是渠道／受理行，不是立案结论。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1993 公司法第一百六十八条／第一百七十七条、1996 行政处罚法第三十二条、2018 监察法文本当现行第十八条、把 42 号令第二十四条或第一百七十七条套民企、把开通邮箱写成已有效、把 FCPA 或美国吹哨人程序写成中国法义务时记为噪声。禁止指导伪造受理日志或删除会计资料。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`CH#` 固定列：`编号｜入口形态｜控制权／开箱人｜匿名／实名｜分办｜编号与回避｜知悉范围｜E#回链｜判断三值｜缺口G#｜最强反方｜待核`。禁止合成「已有效渠道闭环」一笔。无法判断则该条待核，**不得默认保留被监督人控制的唯一邮箱或绝对匿名承诺**。热冲突不得保留。`E#` 只作证据形态回链。缺项记 `G#`，不得用「最佳实践」或范本栏目填满。扫描不是闭集。

口头「早就有热线」「邮箱开了就是渠道有效」「群已读就是已公布」只进 `S#`／`V#`，**不得算作开闸材料**。已读、快递揽收、自动回复不得升格 `R#` 已送达，不得升格受理完成或已查实。`A#` 是承认，不是已有效。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

## 节点 0　分流、立场、渠道闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。伪造受理日志、倒签收件编号、假回执、指导删除、平行灭证、打击报复、阻挠合法检查、双方秘密不进负表。

整案转出只交付第 1、2、10 节，不出 `CH#` 终稿。

审查起诉、监管检查只作程序背景。主成果才整案转。出现「举报」「热线」一词不是转出。混合入口须留本窗做分办，不得因夹带一封信或一句工资投诉整案转走。P2「处理匿名举报与材料不足」「准备举报受理回执与分流说明」未安装，标 `unavailable`，本窗不得代做。

渠道闸打开（可出 `CH#` 草案，仍不得标「已有效渠道／已运行／已免责」）须同时满足：单方无冲突公司立场已闭合；主成果是建或重整廉洁合规渠道与受理规则，不是单件立案、保护方案或劳动申诉终稿；至少一条可编号入口或拟设渠道行。从零：有入口碎片或拟设行即可开或半开，缺项记 `G#`。口头已有热线、群已读、开通邮箱、人力资源投诉箱不算开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

渠道闸部分打开：开箱权、主体或知悉范围未核验，但已有可编号范围；或无书面建设授权但已有拟设行或入口碎片；对应格待核；仍交十节；不得标终稿 `已形成`。不得因无授权文件关掉拟设草案。唯一现有入口是被监督人控制邮箱或人力资源箱：不得据此开闸为已有效；有其他拟设廉洁入口则可半开。

渠道闸关闭（仍正触发）：无一可编号入口且无一拟设行。「今天必须出已有效／已运行终稿」而无最小事实不得开闸。不出 `CH#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `CH#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「没有缺口」或「渠道已经有效」。

「开通邮箱即渠道有效」「人力资源投诉箱即廉洁渠道」「绝对无法追溯匿名已保证」「受理即查实」「渠道即免责」「民企必须按 42 号令第二十四条建平台并上报」「禁止向当地机关举报可保留」「全员可见举报内容当然合法」「群已读即已公布」「范本即已运行」「交方案即从轻」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `CH#` 草案。闸未开才不出 `CH#` 终稿。热冲突条款不得仅标不支持后仍写入保留。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合、无书面建设授权但已有拟设行或入口碎片，then 渠道闸部分打开，仍交十节，不是整体停止。
若 if 公司立场已闭合但无一拟设且无一碎片，then 渠道闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象或举报人相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造受理日志、倒签收件编号、假回执、指导删除会计资料、借渠道稿平行灭证、打击报复或阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

中央企业／地方国企／参股／民企／是否上市分列。不自动合并。名称相似不自动合并。独立法人子公司不与母公司自动合并。

检索锚点（写入 `L#` 前须核验）：

- 42 号令第二条：只约束国资委履行出资人职责的中央企业。主体未核验则第 24 条强制项字段停止。
- 42 号令第二十四条：中央企业应当设立违规举报平台，公布电话、邮箱或者信箱，按职责权限受理并调查处理；对举报人身份和事项严格保密；不得打击报复。设立平台 ≠ 已有效；受理 ≠ 本窗查实。只约束中央企业。
- 42 号令第四十条：地方国资参照指导，不是民企或参股对国务院国资委义务。民企硬套第二十四条：该格 `现有依据不支持`，强制对照行删除，不关窗。不得建议民企上报国务院国资委。
- 公司法第一百六十八条：国家出资公司不含参股。噪声：1993 年第一百六十八条公司债券。
- 公司法第一百七十七条：仅国家出资公司对内合规，不套民企。噪声：1993 年第一百七十七条公积金。
- 公司法第六十七条：董事会制定基本管理制度，不等于渠道规则已生效。
- 劳动合同法第四条：构成劳动规章的渠道纪律条款只开民主程序接口，本窗不做完。法释〔2020〕26 号第五十条只开合同优先接口。
- 个保法第六条最小范围、第十三条人力资源管理所必需、第二十五条不得公开：知悉范围最小化 ≠ 全员可见举报内容，≠ 全员邮箱／微信／定位。
- 监察法（2024 修正）第十八条：如实提供，不得伪造、隐匿、毁灭。噪声：2018 年文本。
- 行政处罚法第三十二条：提交渠道方案不等于情节成就。噪声：1996 年第三十二条。
- 刑法第一百六十二条之一只作红旗，不得指导删除。
- 证券法第七十八条、第八十条只约束信息披露义务人，内部渠道不是必须公告。
- 不得把美国吹哨人奖金或 SOX 投诉程序写成中国法定义务。

强制接口与非强制对标分列。参股只能经股东权利建议，不得写成内部渠道已对其生效。

## 节点 3　渠道与受理规则行 `CH#`

按已出现入口扫描，不是默认闭集。每条：入口形态、控制权、匿名／实名、分办、编号与回避、知悉范围。无法判断：该条待核，不得默认保留被监督人控制的唯一邮箱。无版本、无入口形态不得排进可执行 `CH#`，记 `G#`。

热冲突强制处理（不得保留）：

- 被监督人（销售、采购、被常见举报岗位、被指向人）单独控制开箱权作为**唯一**渠道 → 该格不支持；须并列独立热线、外部转办或隔离开箱权。
- 人力资源投诉箱冒充廉洁渠道 → 该格不支持；薪酬、考勤、性骚扰专项只开劳动分办。
- 承诺绝对无法追溯匿名且技术不能支持（日志、IP、邮件头、外包转办、内部 IT 管理员）→ **删除**承诺，改为如实披露限制。
- 禁止向当地机关、纪检监察、公安、劳动监察举报 → **删除**。指导打击报复 → 整体停止。
- 全员邮箱／全员群可见举报内容或身份 → 删除或改写为最小知悉名单。
- 「渠道建成即免责／有报必查即已合规」作为效力条款 → 删除。
- 美国吹哨人奖金程序写成中国法定义务 → 改写为非强制对标并标法域。

受理规则只写收件、编号、回避筛查、是否进入初核**接口**、回执栏目。受理不得写成已查实。是否立案、材料是否足够转 `评估单件举报可查性`。具体匿名件不在本窗做完。状态 `草案`。无 `E#` 不得写已覆盖或已运行。

## 节点 4　回执接口、可逆性与转介

回执只开栏目、内部管理时点接口与分办去向。不写发送版回执正文。不选定唯一截止日；起算点未闭合则时限字段停止。P2 未安装：标 `unavailable`。构成劳动规章的纪律／处分条款：本窗不写生效稿，只标须协商／公示接口。个保、数据出境只开接口。法定披露只开接口。

可逆动作与不可逆动作分列。不可逆（对员工公布发生劳动纪律效力、对外宣称渠道已有效、向举报人发送属实／立案回执、格式化旧档、向被指向人核实身份）不得在草案阶段实施。禁止提交指令。不代公布、不代提交。

下一步只转介：单件可查性、保护方案、打击报复评估、启动调查、调查授权、利益冲突回避、办法、框架、三道、落地、国企对照（仅确为中央企业）、董事会汇报。禁止一次写完全部邻窗终稿。

已有监察或检查 `R#`：不得借重建渠道平行灭证。刑法第一百六十二条之一只作红旗，不得指导删除。
