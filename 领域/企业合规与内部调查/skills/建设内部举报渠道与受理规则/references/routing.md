# 边界与路由

## 正触发

公司要建立或重整廉洁与合规举报渠道和受理规则，而不是查某一封信或出保护方案。从零、入口碎片、无书面建设授权仍正触发：有拟设或入口碎片则闸开或半开，出 `CH#` 草案，生效格待核。开通邮箱即有效、人力资源箱即廉洁渠道、绝对匿名、受理即查实、渠道即免责、民企套第 24 条、禁止外举、群已读即已公布，仍正触发。

双方秘密、伪造受理日志、倒签收件编号、假回执、指导删除、平行灭证、打击报复、阻挠合法检查的停止，优先于负触发。上述信号不在下表。「开通邮箱即有效」「人力资源箱即廉洁渠道」「绝对匿名已保证」「受理即查实」「渠道即免责」「民企套第 24 条」「禁止外举可保留」不在下表。「不调查具体线索」「不保证绝对匿名」「不保证免责」「不写发送版回执」是交付禁令，不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 单件举报可查性或立案评估 | `评估单件举报可查性` |
| 举报人保护方案终稿 | `设计举报人保护与反报复措施` |
| 打击报复风险迹象表 | `评估打击报复风险` |
| 是否启动内部调查 | `评估是否启动内部调查` |
| 调查授权范围 | `确定调查授权范围与独立` |
| 劳动申诉、工资工时、解除或职场性骚扰专项 | 劳动领域 |
| 劳动处分或日常违纪决定 | 劳动领域 |
| 章程级办法正文 | `起草合规管理办法或章程级制度` |
| 集团或境外模板落地对照 | `落地集团政策到境内实体` |
| 确为中央企业且 42 号令对照终稿 | `评估国企合规管理办法差距` |
| 数据出境或个保专项体系 | 数据隐私领域 |
| 法定披露正文 | `评估舆情与法定披露交叉` 或 `准备对内通报与对外口径` |
| 交易合同改稿 | 审查起草领域（本窗搁置，只说明） |

不得因「保证绝对匿名」或「今天视为已有效」或「顺便交来一封信」关窗。混合入口仍正触发，劳动或单件只开接口。民企硬套不得负触发到对照窗。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、解除、工伤、职场性骚扰主轴 | 劳动领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |
| 垄断、滥用支配、经营者集中 | 竞争法领域 |
| 章程、股权、任免本身为主成果 | 公司治理领域 |
| 银行保险机构行业合规办法主轴 | 金融领域 |
| 税务处理决定、稽查实体 | 税务领域 |

综合合规渠道建设主轴可留本任务。审查起诉或检查只作背景，主成果才转。出现「举报」一词不是转出。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 单件材料是否可查、是否立案 | `评估单件举报可查性` |
| 保护措施方案 | `设计举报人保护与反报复措施` |
| 报复迹象评估 | `评估打击报复风险` |
| 是否启动完整调查 | `评估是否启动内部调查` |
| 调查书面授权 | `确定调查授权范围与独立` |
| 调查组成员回避名单终稿 | `处理利益冲突与调查回避` |
| 确为中央企业且对照终稿 | `评估国企合规管理办法差距` |
| 集团模板落地行 | `落地集团政策到境内实体` |
| 劳动规章民主程序做完 | 劳动领域 |
| 发送版回执或匿名件材料不足专项 | P2 未安装，`unavailable`；本窗只开接口 |

## 易混

开通邮箱不是渠道有效。被监督人控制的邮箱不得作为唯一渠道。人力资源投诉箱不是廉洁举报渠道。受理不是查实。收件编号不是初核结论。自动回复不是已送达，不是属实证明。纸面规则不是已生效。群已读不是已公布。绝对匿名承诺在技术不能支持时必须删除，改为如实披露限制；「不保证绝对匿名」不关窗。民企套 42 号令第二十四条：该格不支持，不关窗，不转出，不得建议上报国资委。禁止外举条款删除；指导打击报复整体停止。审查起诉只作背景，主成果才转刑事。「先补假受理日志再出已运行稿」整体停止。不调查具体线索、不写发送版回执是交付禁令，不是负触发。
