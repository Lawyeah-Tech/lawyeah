# 边界与路由

## 正触发

已决定或拟决定对高风险第三方停付、中止或终止，需要发送前通知草案，而不是做筛查、写尽调底稿或改合同全文。决定、解除权、地址未核验仍正触发：有可编号对象且有决定或条款碎片则闸开或半开，出 `SU#` 草案。内部决定即已送达终止、已读即已送达、通知即刑事控告、依据不足即对方已违约、无决定即已发出、条款定位即已改约、红旗即必须终止、高风险筛查即已决定终止、本表已解除、FCPA 即中国法义务，仍正触发。

双方秘密、指导倒签送达、伪造回证、指示对方销毁材料、指导删除、打击报复的停止，优先于负触发。上述信号不在下表。「内部决定即已送达终止」「已读即已送达」「通知即刑事控告」「依据不足即对方已违约」「无决定即已发出」「条款定位即已改约」「红旗即必须终止」「高风险筛查即已决定终止」「本表已解除」不在下表。「不执行发送」「不保证解除有效」「不定罪」「不写合同全文」「已读不是已送达」是交付禁令，不在下表。出现「中止」「终止」「停付」「通知」一词不是转出。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 批量公开信息筛查 | `筛查经销商代理中介廉洁风险` |
| 第三方机制草案 | `设计第三方合规管理机制` |
| 尽调工作底稿 | `准备第三方尽职调查工作底稿` |
| 中间人费用与资金链路终稿 | `评估中间人费用与资金链路` |
| 调查后处置路径终稿 | `评估调查后处置路径` |
| 对内持有或禁毁通知 | `准备证据保全与禁毁通知` |
| 完整交易合同审查或起草 | 审查起草领域（本窗搁置） |
| 合同价款、质量或交付争议 | 合同争议或审查起草领域 |
| 劳动解除或终止劳动合同通知 | 劳动领域 |
| C 端小微供应商勾选清单 | 大众专项，只分流 |
| 刑事辩护、控告或自首 | 刑事领域 |

不得因「不执行发送」「不保证解除有效」「不定罪」「不写合同全文」「已读不是已送达」关窗。内部决定即已送达、已读即已送达、依据不足即对方已违约该格不支持，窗口不关，不转出。主成果才转。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、解除主轴且发送前通知不是主成果 | 劳动领域 |
| 药品购销回扣行业细则为主成果 | 医疗领域 |
| 垄断协议、滥用支配、经营者集中为主成果 | 竞争法领域 |
| 投资并购整体尽调为主成果 | 投资并购领域 |

综合发送前中止或终止通知主轴可留本任务。检查或已立案只作背景，主成果才转。已刑事立案：通知不得干扰侦查，只开刑事接口。

## 易混

中止闸打开不是已发出。草案不是已送达。内部决定停用不是已经送达终止。已读不是已送达。内网已读不得写成已送达。通知不是刑事控告。依据不足不是对方已违约。无决定不是已发出。条款定位不是已改约。红旗不是必须终止。高风险筛查不是已决定终止。无解除权的通知不发生解除效力。解除权未核验不是已解除。劳动合同解除通知不是本窗。破产管理人解除通知不是本窗。不执行发送、不保证解除有效、不定罪、不写合同全文是交付禁令，不是负触发。口头「已经停了」不是开闸材料。可编号对象加决定或条款碎片才开闸。指导倒签回证或指示毁证是第一次整体停止，不是不关窗。
