# 中止通知方法

本文件是可执行判断节点。内部决定不是已送达终止。已读不是已送达。通知不是刑事控告。依据不足不是对方已违约。无解除权的通知不发生解除效力。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态只用 `草案`、`待发送`、`停止`。默认 `草案`。禁止胜诉率、必然免责、选定法院、代发送、未知写零。本任务不执行发送，不写完整合同，不定罪，不发劳动解除通知。本窗 `SN#` 是中止通知行，不是禁毁通知 `N#`，不是底稿行 `DW#`，不是筛查行 `SC#`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、把诉讼电子送达规则直接写成合同通知已读即到达、把无解除权通知写成已解除时记为噪声。禁止指导倒签送达、伪造回证或指示对方销毁材料。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现条款扫描，不是默认闭集。
`SN#` 固定列：`编号｜对象｜决定记录｜合同条款定位（停付／解除／廉洁违约）｜通知类型（中止／终止／停付）｜正文要点｜到达设计｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已解除闭环」或「已读即送达」。无 `E#` 不得写已发出、已送达、已解除。`E#` 只作证据形态回链。缺项记 `G#`。扫描不是闭集。

口头「已经停了」「微信已读就是送到了」「高风险就该今天发」只进 `S#`／`V#`，**不得单独算作开闸材料**。`A#` 是承认决定或条款表面，不是已送达。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上解除通知须有法定或约定解除权，到达对方时才可能发生解除效力；无解除权即使对方未异议也不解除。诉讼电子送达规则不当然等于合同通知已读即到达。

## 节点 0　分流、立场、中止闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、指导倒签送达、伪造回证、指示毁证、指导删除、打击报复不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `SN#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是批量公开信息筛查 | 负触发 `筛查经销商代理中介廉洁风险` |
| 主成果是第三方机制草案 | 负触发 `设计第三方合规管理机制` |
| 主成果是尽调工作底稿 | 负触发 `准备第三方尽职调查工作底稿` |
| 主成果是对内持有或禁毁通知 | 负触发 `准备证据保全与禁毁通知` |
| 主成果是完整交易合同审查或起草 | 负触发，审查起草领域（本窗搁置） |
| 主成果是合同价款、质量或交付争议 | 负触发，合同争议或审查起草领域 |
| 主成果是劳动解除或终止劳动合同通知 | 负触发，劳动领域 |
| 主成果是 C 端小微供应商勾选清单 | 负触发，大众专项只分流 |
| 主成果是刑辩、控告或自首 | 整案转刑事 |
| 「不执行发送」「不保证解除有效」「不定罪」「不写合同全文」「已读不是已送达」 | 交付禁令，不是负触发 |

审查起诉、监管检查只作背景。主成果才整案转。出现「中止」「终止」「停付」「通知」一词不是转出。

中止闸打开（可出 `SN#` 草案，仍不得标「已发出／已送达／已解除」）须同时满足：单方无冲突公司立场已闭合；主成果是发送前中止或终止通知，不是筛查、尽调底稿、完整合同或劳动解除；至少一条可编号对象，且有内部决定或合同条款碎片。口头「已经停了」不算单独开闸材料。双方秘密或第一次指导倒签回证不是关闸条件，走整体停止。

中止闸部分打开：已有对象与决定或条款，但解除权、地址、授权未闭合；对应格待核；仍交十节。

中止闸关闭（仍正触发）：无一可编号对象且无决定。「今天必须发出」而无最小决定不得开闸。不出 `SN#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `SN#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「内部决定即已送达终止」「已读即已送达」「通知即刑事控告」「依据不足即对方已违约」「无决定即已发出」「条款定位即已改约」「红旗即必须终止」「高风险筛查即已决定终止」「本表已解除」「FCPA 即中国法义务」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `SN#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无一可编号对象且无决定，then 中止闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与相对方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出指导倒签送达、伪造回证、指示对方销毁材料、指导删除、打击报复，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个主体或强制接口。缺项记 `G#`，不得把未知金额写成 `0`。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 决定 | 内部停付／中止／终止决定及授权 | 把口头「已经停了」写成已发出 |
| 解除权 | 约定解除／法定解除／中止履行，待核 | 无解除权写成已解除 |
| 对象 | 经销／代理／中介／顾问 | 把个人员工劳动解除写进本窗终稿 |

检索锚点（写入 `L#` 前须核验）：

- 民法典第五百六十五条：解除应当通知，合同自通知到达对方时解除。
- 合同编通则司法解释第五十三条：无解除权的通知不发生解除效力。
- 民法典第五百六十三条、第五百六十二条、第五百二十五条至第五百二十八条只开接口。
- 民诉电子送达规则不当然等于合同通知已读即到达。
- 刑法第一百六十二条之一只作红旗，不得指示销毁。
- 失效《合同法》是噪声。

本节禁止出 `SN#` 终稿。

## 节点 3　中止通知行 `SN#`

按已出现对象扫描，不是默认闭集。建议行型（出现才用，**不是闭集**）：

| 编号 | 含义 | 本窗允许 | 禁止 |
| --- | --- | --- | --- |
| `SN-对` | 对象 | 经销／代理／中介／顾问 | 把个人员工当本窗劳动解除 |
| `SN-决` | 决定记录 | 内部停付／中止／终止及授权 | 无决定写成已发出 |
| `SN-条` | 合同条款定位 | 停付／解除／廉洁违约条款号 | 改写合同全文 |
| `SN-文` | 正文要点 | 中止或终止意思、依据、留存、联系人 | 指控未核验犯罪；指示毁证 |
| `SN-达` | 到达设计 | 约定地址、方式、回执、失败升级 | 已读即送达；本窗执行发送 |

热冲突强制处理：

- 内部决定即已送达／已读即已送达／依据不足即对方已违约／无决定即已发出／红旗即必须终止／本表已解除／FCPA 即中国法 → 该格不支持；仍出其他 `SN#`。
- 解除权未核验 → 不得写已解除；正文只保留待核接口。
- 无解除权 → 到达也不发生解除效力，该格不支持。
- 指导倒签、伪造回证或指示毁证 → 整体停止，不是该格不支持。

无 `E#` 不得写已发出、已送达或已解除。状态 `草案`。一次只推荐下一步。

## 节点 4　到达、争议与转介

第 7 节只开接口，不得夹带 `SN#` 终稿绕闸。闸关闭时第 7 节可写「闸未开，转介待对象编号」，不得补写已发出。

不写完整合同、劳动解除通知、筛查终稿、尽调底稿、禁毁通知终稿。不可逆（对外宣称已解除、补造回证、指示销毁）不得在草案阶段实施。禁止提交指令。不代发送。不选定机关。

筛查转 `筛查经销商代理中介廉洁风险`。尽调转 `准备第三方尽职调查工作底稿`。机制转 `设计第三方合规管理机制`。禁毁转 `准备证据保全与禁毁通知`。完整合同搁置。劳动解除转劳动。价款质量争议转合同争议。

若 if 用户催促「今天发出／已读即送达／填满已解除终稿」，then 该格 `现有依据不支持`，窗口不关。
若 if 金额未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「中止闸与发送前通知草案」。本窗不执行发送。不包含：已发出证明、已送达证明、已解除证明、完整合同、劳动解除通知、毁证步骤。禁止选边治愈。禁止内部决定即已送达。禁止已读即已送达。禁止依据不足即对方已违约。禁止指示毁证。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标通知终稿已形成。
风险档 A：指导倒签送达、伪造回证、指示毁证必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：民企。筛查标一家代理高风险，尚无书面终止决定，合同有廉洁违约条款但解除权未核验。用户主张今天必须发出、微信已读就是送达、红旗就是对方已违约、通知里写商业贿赂既遂、用劳动合同解除通知范本填满、改经销合同全文、按 FCPA 写死。中止闸部分打开或因无决定关闭。`Q-发`、`Q-读`、`Q-违`、`Q-控`、`Q-改`、`Q-美` 不打开为可靠路径。第 6 节不得把已发出、已送达、已违约、已解除写入可执行 `SN#`；对应格 `现有依据不支持`；有决定碎片则出其他 `SN#` 草案，无决定则第 6 节不出终稿。不关窗。不执行发送。范本只借栏目。

场景②：用户同时交出公司终止草稿与代理抗辩，要求选对公司有利的一版，并指导「回证日期往前倒、通知里让对方把电脑格式化」。命中双方秘密＋指导倒签回证／指示毁证。第一次整体停止。只交第 1、10 节。不出 `SN#`。不得问代表哪一方后继续。
