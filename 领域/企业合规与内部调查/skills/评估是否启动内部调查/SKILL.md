# 评估是否启动内部调查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“内部调查启动闸”：线索可查性、独立性与回避、范围假设、刑事/劳动/数据红旗、不启动或限缩理由、下一步。本任务不发持有通知，不出调查结论。

`depends-on` 为空。接受用户、律师、内审、机关或其他来源的等价事实、授权、测算和证据清单，不要求先运行其他 Skill。

## 工作边界

正触发：已出现举报、审计发现、监管问询或舞弊红旗，公司需要决定查不查、谁查、查到哪，且尚未以报告或发函为主成果。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要发送版持有/禁毁通知或主动披露稿；
- 只要调查报告终稿或处分决定；
- 主成果是职场违纪、性骚扰或解除劳动合同；
- 主成果是刑事立案、控告或辩护；
- 只要企业级总图，没有具体线索；

本任务不给胜诉率、必然免责、刑事既遂或唯一必得总额。

## 建立坐标

确认：授权调查的主体；线索来源与时间；被指向的人与岗位；是否涉及公职人员、个人信息或劳动争议；现存制度中的调查权限；是否已有监察/公安/检察动作。

同时掌握公司与被调查对象相互冲突的秘密时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 陈述；`D#` 材料；`A#` 一致；`R#` 机关文书；`C#` 制度条款；`L#` 已核验规则；`I#` 判断；`G#` 缺口；`Q#` 启动假设；`V#` 版本。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验举报保密、禁止报复、监察移送、非法证据排除接口；`search_practiced` 补启动与回避反例。

工具不可用时继续事实、主体和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 专项分流、立场和线索来源

先分流劳动/刑事/数据/竞争。匿名、实名、审计、监管来源分列。口头传闻不升级为已查实。

### 2. 独立性与回避

被指向人为高管、亲属、业务赞助人或调查经费控制人时，必须列回避和替代主体。老板指定“自己人查自己”且拒绝回避：启动建议字段停止。

### 3. 范围假设与禁止扩权

范围只覆盖线索所指向的交易、期间和主体。不得因方便而授权全员通讯监控。涉及邮箱、定位、生物识别：数据专项字段停止并转介。

### 4. 不启动、限缩或升级

材料显著不足可限缩初核；涉及公职人员或已有监察文书标刑事红旗，不启动企业“平行灭证”。达到启动条件仍不查：记录治理风险，不强迫立案。

### 5. 下一步与不可逆提示

决定启动则转介持有通知和案卷，本任务不出发送稿。决定不启动须写复核时点。用户要求先处分再补查：目标停止。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；用户坚持打击报复或毁证。
- `字段停止`：被指向人身份、公职属性、监察文书未核验。
- `目标停止`：主目标变为发通知、出报告、劳动处分或刑事材料。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
