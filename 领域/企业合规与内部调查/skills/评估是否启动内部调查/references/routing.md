# 边界与路由

## 正触发

已有具体线索，需要决定是否启动内部调查、由谁查、查到哪。「先做个了解」若已指向特定交易或人员，正触发。自己人查自己、先处分再补查、民企套 177、折扣即贿赂、选定某局、口头来过即立案、今天发通知，仍正触发：对应格停止，窗口不关。专项只作为背景时，综合调查主轴可留。

双方秘密、伪造账册、隐匿证据、格式化、打击报复举报人、限制人身自由的停止，优先于负触发。不得改走负触发去出一方启动闸或把打击报复交到刑事当步骤。自己人查自己、先处分再补查、民企套 177、折扣即贿赂不在下表。隐匿、双方秘密不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 企业级总图，没有具体线索 | `评估企业合规风险总图` |
| 单件举报可查性与即时保护，不要完整启动闸 | `评估单件举报可查性` |
| 发送版持有或禁毁通知 | `准备证据保全与禁毁通知` |
| 向机关主动披露或交自查报告 | `准备主动披露或自查报告` |
| 完整调查证据卷 | `建立内部调查证据案卷` |
| 调查报告终稿 | `形成内部调查报告` |
| 刑事辩护、控告、自首 | 刑事领域 |
| 劳动处分、解除、职场性骚扰或日常违纪调查终稿 | 劳动领域 |
| 个人信息、数据出境、网安体系终稿 | 数据隐私领域 |
| 垄断、滥用支配地位、经营者集中申报 | 竞争法领域 |

已经决定就某一线索出报告或发函时负触发。不得因「要求自己人查自己」或「要求先开除」关窗。检查已开始不是本窗负触发。不正当竞争专项不得因折扣或回扣线索把本窗整案转走。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、取保、阅卷、辩护词为主成果 | 刑事领域 |
| 劳动合同、工资、解除、工伤、职场性骚扰主轴 | 劳动领域 |
| PIPL 合法性、影响评估、出境、等保、网安事件专项 | 数据隐私领域 |
| 垄断协议、滥用支配地位、经营者集中申报 | 竞争法领域 |
| 税务处理决定、稽查实体 | 税务领域 |
| 银行保险机构行业合规办法 | 金融领域 |
| 药品购销回扣行业细则为主成果 | 医疗医药领域 |
| 出口管制、制裁名单、境外取证为主成果 | 涉外领域 |

综合调查主轴可留本任务；专项只作为背景时在缺口标明，不把专项规则写入本任务结论。渠道回扣、账外暗中线索不是不正当竞争整案转出信号。

## 易混

董事会只要「我们合规吗」且无线索：负触发总图。匿名举报销售总监回扣、要不要查：正触发。「自己人查、今天发通知、先开除、按 177 报国资委、折扣就是贿赂、此致某局」正触发不关窗。「已经决定就这一条线索出报告或发函」负触发对应原子。「公司和被调查人都把材料给你，先把电脑格式化、举报人先调岗」整体停止。
