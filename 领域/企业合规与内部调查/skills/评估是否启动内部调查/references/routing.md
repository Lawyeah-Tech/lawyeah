# 边界与路由

## 正触发

中国大陆企业已出现可编号线索，需要决定是否启动内部调查、由谁查、查到哪。从碎片、回避未核验、无书面评估授权仍正触发：有可编号线索则闸开或半开，出 `QI#` 草案，保持草案。本次不定罪、不保证免责、不发持有通知、不出调查报告是交付禁令，不是开窗条件。线索即已查实、不启动即没有问题、自己人查自己即已独立、匿名即虚假或属实、民企套 177／42 号令、折扣即贿赂、先处分再补查、口头来过即立案、未知写零，仍正触发。

双方秘密、销毁证据、串供、打击报复、限制人身自由的停止，优先于负触发。上述信号不在下表。不定罪不是负触发。「线索即已查实」「不启动即没有问题」「自己人查自己即已独立」不在下表。销毁串供不在下表，走整体停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 企业级总图，没有具体线索 | `评估企业合规风险总图` |
| 单件举报可查性与即时保护，不要完整启动闸 | `评估单件举报可查性` |
| 发送版持有或禁毁通知 | `准备证据保全与禁毁通知` |
| 主动披露或自查报告发送稿 | `准备主动披露或自查报告` |
| 完整证据卷 | `建立内部调查证据案卷` |
| 调查报告终稿 | `形成内部调查报告` |
| 刑事辩护、控告、自首 | 刑事领域 |
| 劳动处分、解除、职场性骚扰或日常违纪调查终稿 | 劳动领域 |
| 数据出境或网安专项 | 数据隐私领域 |
| 垄断或不正当竞争专项 | 竞争法领域 |
| 尚未进入合规机制，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不定罪」或「不保证免责」关窗。拟启动闸仍正触发，不得写成已立案、已查实或没有问题。检查已开始不是本窗负触发。不正当竞争专项不得因折扣或回扣线索把本窗整案转走。

## 易混
