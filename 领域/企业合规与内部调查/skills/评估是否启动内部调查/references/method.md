# 评估是否启动内部调查方法

本文件是可执行判断节点。线索不是已查实。不启动不是没有问题。自己人查自己不是已独立。匿名不是已虚假，也不是已属实。公司法第一百七十七条只约束国家出资公司。42 号令第二十四条只约束中央企业。明示折扣佣金如实入账不是商业贿赂。口头或已读不是已立案。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已立案、已查实、已独立、已免责、选定机关、代提交、未知写零。本任务不定罪，不发持有通知，不出调查报告。本窗闸名只能是启动闸，禁止复用评估闸、合规闸、争议闸、侵权闸、调查闸、检查闸。预留不得占用：立案闸、调查闸、检查闸。本窗 `QI#` 是启动行。主路径只用 `Q-启`，禁止用 `Q-风`、`Q-总`、`Q-责`、`Q-线`、`Q-合`、`Q-图`、`Q-检` 作主路径。`Q-线` 只作线索可查性扫描，不得升主路径。英文 id 禁止使用，一律用中文技能名 `评估是否启动内部调查`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年公司法第一百六十八条记名债券、1993 年公司法第一百七十七条公积金条款、1993 年反不正当竞争法第八条、已失效《中央企业合规管理指引（试行）》、把线索写成已查实或把民企写成必须按 42 号令第二十四条立案时记为噪声。禁止指导销毁证据、串供、打击报复、限制人身自由或阻挠检查。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现线索或红旗碎片扫描，不是默认闭集。
`QI#` 固定列：`编号｜线索切片｜可查性与来源等级｜回避与独立｜范围假设（主体×期间×交易／账户×系统）｜打开接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已立案」或「没有问题」。无 `E#` 不得写已立案、已查实、已独立、已贿赂。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-启`。禁止 `GT#`、`ZT#`、`QG#`、`A#`、`N#`、`RF#`。

口头「有人来过」「已经立案」「匿名就是诬告」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：民企启动内部调查是治理安排，不得倒推必须按 42 号令第二十四条立案上报。参与调查的人员与被调查人有亲属、利害或其他可能影响公正的关系，应当回避；被调查人有权要求回避。自己人查自己不得写成已独立。调查人员不具备限制他人人身自由的权力。已有监察／公安文书不得平行灭证。折扣入账与账外暗中分列。解除前应调查核实，先处分再补查不得写成合法路径。

## 节点 0　分流、立场、启动闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造账册、隐匿证据、串供、威胁证人、打击报复举报人、限制人身自由、阻挠合法检查、指导销毁不进负表。利益冲突未解不进整体停止。不定罪、不保证免责、不发持有通知不是负触发。禁止把调查闸或检查闸写进本窗节点 0。

整案转出只交付第 1、2、10 节，不出 `QI#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是企业级总图且没有具体线索 | 负触发 `评估企业合规风险总图` |
| 主成果是单件举报可查性与即时保护，不要完整启动闸 | 负触发 `评估单件举报可查性` |
| 主成果是发送版持有或禁毁通知 | 负触发 `准备证据保全与禁毁通知` |
| 主成果是主动披露或自查报告发送稿 | 负触发 `准备主动披露或自查报告` |
| 主成果是完整证据卷 | 负触发 `建立内部调查证据案卷` |
| 主成果是调查报告终稿 | 负触发 `形成内部调查报告` |
| 主成果是刑事立案、控告或自首 | 整案转刑事 |
| 主成果是劳动处分或职场性骚扰／日常违纪调查 | 整案转劳动 |
| 主成果是数据出境或网安专项 | 整案转数据隐私 |
| 主成果是垄断或不正当竞争专项 | 整案转竞争法 |
| 尚未进入合规机制，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 「不定罪」「不保证免责」「不发持有通知」 | 交付禁令，不是负触发 |

出现「调查」「通知」「报告」一词不是转出。综合调查主轴可留，专项段只分流。检查已开始不是本窗负触发。不正当竞争专项不得因折扣或回扣线索整案转走。

启动闸打开（可出 `QI#` 草案，仍不得标「已立案／已查实／已独立」）须同时满足：单方无冲突立场已闭合；主成果是查不查、谁查、查到哪，不是调查报告、不是持有通知、不是处分终稿；至少一项可编号线索碎片。口头「已经立案」不算单独开闸材料。

启动闸部分打开：已有线索，但回避、范围、公职属性或红旗定性未闭合；对应格待核；仍交十节。无书面评估授权但单方立场已闭合且已有线索：启动闸部分打开，仍交十节，不是整体停止。

启动闸关闭（仍正触发）：无一可编号线索。「今天必须出已立案／没有问题终稿」而无最小线索不得开闸。不出 `QI#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `QI#` 终稿，**第 7 节不得出持有通知或调查报告**。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「没有问题」。

「线索即已查实」「不启动即没有问题」「自己人查自己即已独立」「匿名即虚假或属实」「民企套第一百七十七条或 42 号令」「折扣即贿赂」「先处分再补查」「口头来过即立案」「未知写零」「选定某局」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `QI#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号线索，then 启动闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，或两造争同一份启动闸，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造账册、隐匿证据、串供、威胁证人、打击报复举报人、限制人身自由、阻挠合法检查或指导销毁，then 整体停止；第一次提出即停，不以「坚持」为门槛；不得转介持有通知完成毁证。

## 节点 1　线索、来源等级与回避

一行一个线索切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `QI#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 线索 | 来源、时间、指向的人／交易／账户分列 | 匿名升格已虚假或已属实；传闻升格已查实 |
| 被指向人 | 岗位、是否能决定人选／预算／IT／处分、是否公职人员分列 | 名称不一致自动合并；自己人查自己写成已独立 |
| 程序 | 检查、监察、公安文书作出日、收到日、送达分列 | 口头来过升格已立案；已读升格已送达 |

检索锚点（写入 `L#` 前须核验）：公司法第一百六十八条、第一百七十七条。中央企业合规管理办法第二条适用范围、第二十四条举报调查保密与不得打击报复、第四十条地方国资参照。反不正当竞争法 2025 第八条；噪声 1993 年反法第八条、1993 年公司法第一百六十八条记名债券、1993 年公司法第一百七十七条公积金。个人信息保护法第十三条。监察法第十八条。刑法隐匿销毁会计资料、妨害作证、打击报复只开红旗。

来源等级：`R#` 机关文书 > `D#` 书证／系统记录 > `S#` 实名陈述 > 匿名陈述 > 传闻。匿名不推定虚假，也不单独支持对个人的不利定性。同一人反复举报：合并编号，不因次数写成已属实。公职属性未核验：该格字段停止，不写「不是监察对象」。

## 节点 3　启动行 `QI#`

按已出现线索或红旗碎片扫描，不是默认闭集。每条须能指向线索切片、可查性、回避或范围假设之一。

无 `E#` 不得写已立案、已查实、已独立或已贿赂。状态默认 `草案`。一次只推荐下一步。未知不写零。

热冲突强制处理：

- 线索即已查实／不启动即没有问题／自己人查自己即已独立／匿名即虚假或属实／民企套 177／折扣即贿赂／先处分再补查／未知写零 → 该格不支持或字段停止；仍出其他 `QI#`。
- 无一线索 → 关闸，不出 `QI#` 终稿，窗口不关。
- 指导销毁、串供、隐匿、打击报复、限制人身自由 → 整体停止，不是该格不支持。
- 已有监察／公安 `R#` → 不得转介持有通知完成平行灭证或全员禁毁。

主体或期间无法识别：不启动正式调查；`Q-初` 可打开限缩初核接口；不得写没有问题。达到启动条件治理层仍不查：记录治理风险，不强迫立案，不写成已经合规。夹带「先开除再补查」：`Q-先` 该格不支持；调查未完成不得以处分为启动替代。

## 节点 4　禁毁、案卷、方案与披露接口

第 7 节只开接口，不得夹带 `QI#` 终稿、调查报告或持有通知绕闸。闸关闭时第 7 节可写「闸未开，转介待线索编号」，不得补写已立案或没有问题。不选定机关。不代提交。不定罪。已有监察／公安／检察 `R#` 时，`Q-持有`／`Q-初` 不得转介持有通知完成清理或平行接触证人。

下一步只转介：`评估企业合规风险总图`、`评估单件举报可查性`、`准备证据保全与禁毁通知`、`确定调查授权范围与独立`、`处理利益冲突与调查回避`、`设计举报人保护与反报复措施`、`评估打击报复风险`、`制定调查方案与访谈计划`、`合法收集书证电子证与财务痕迹`、`建立内部调查证据案卷`、`形成内部调查报告`、`应对监管检查或突击检查`、`评估反商业贿赂风险点`、`评估回扣账外暗中与资金链路`、`建设内部举报渠道与受理规则`、`准备主动披露或自查报告`、`评估调查后处置路径`。禁止此致某局。禁止转介禁毁完成毁证。
