# 评估方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态只用 `草案`、`停止`。禁止胜诉率、必然免责、刑事既遂、唯一必得总额、唯一截止日、选定机关或法院、代提交、未知写零。本任务不定罪，不发通知，不出报告。不把线索写成已查实，不把不启动写成「没有问题」。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》《民法通则》《民法总则》、1993 年公司法第一百七十七条公积金条款、1993 年反不正当竞争法第八条直接当现行、把 177 或 42 号令套到全部民企时记为噪声，不得写入 `L#`。反不正当竞争法 2025 修订第八条施行日为 2025-10-15；MCP 若仍标尚未施行，以公布施行日为准并记录冲突。禁止指导伪造、隐匿、格式化、威胁证人、打击报复、限制人身自由或阻挠检查。

`Q#` 固定列：`编号｜路径｜提出方｜相对方｜法律效果假设｜成立条件｜支持事实｜不利事实｜控制方／证明负担红旗｜最强反方｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。效果必须是假设。管理不规范不等于商业贿赂，更不等于单位犯罪。匿名不推定虚假，也不单独支持对个人不利定性。

口头「有人来过」、已读只进 `S#`／`V#`，不得升格 `R#` 已立案或期限已起算。

## 节点 0　分流、立场、启动闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。错误主张不改走负触发，不抽空十节。

整案转出只交付第 1 节分流理由、第 2 节来源、第 10 节最小交接，不填第 5–9 节实体结论。专项只作为背景时综合调查主轴可留，专项段只分流。

| 信号 | 处理 |
| --- | --- |
| 主成果是企业级总图且没有具体线索 | 负触发 `评估企业合规风险总图` |
| 主成果是发送版持有或禁毁通知 | 负触发 `准备证据保全与禁毁通知` |
| 主成果是主动披露或自查报告 | 负触发 `准备主动披露或自查报告` |
| 主成果是调查报告终稿 | 负触发 `形成内部调查报告` |
| 主成果是证据卷终稿 | 负触发 `建立内部调查证据案卷` |
| 主成果是单件举报可查性与即时保护，不要完整启动闸 | 负触发 `评估单件举报可查性` |
| 侦查、审查起诉、审判、取保、阅卷、辩护、刑事控告、自首为主成果 | 整案转刑事；综合调查主轴可留时刑事段只红旗 |
| 劳动合同、工资工时、解除、工伤、职场性骚扰或日常违纪处分决定为主成果 | 整案转劳动 |
| 个人信息、数据出境、等保、网安事件专项体系为主成果 | 整案转数据隐私 |
| 垄断协议、滥用支配地位、经营者集中申报为主成果 | 整案转竞争法 |
| 税务处理、稽查实体为主成果 | 整案转税务 |
| 药品购销回扣行业细则为主成果 | 整案转医疗医药；渠道回扣线索可留本窗 `Q-贿` 接口 |
| 出口管制、制裁名单、境外取证为主成果 | 整案转涉外 |
| 尚未进入合规机制，只要改交易合同 | 审查起草本窗搁置 |

启动闸打开（可出 `Q#` 草案，仍不代提交、不保证免责）须同时满足：单方无冲突立场与授权；已出现可编号线索；主成果是查不查、谁查、查到哪，不是通知、报告、处分或刑辩终稿。

启动闸部分打开：线索可编号但回避未闭合、范围未闭合或红旗待核。仍交十节，对应格待核或字段停止。

启动闸关闭：主体或期间无法识别，不启动正式调查。仍交十节；`Q-初` 可打开限缩初核接口；`Q-线` 正式调查 `不打开`。禁止因闸关闭只交第 1、2、10 节。禁止把闸关闭写成「没有问题」。

「自己人查自己」「先处分再补查」「民企套 177」「折扣即贿赂」「选定机关」「口头来过即立案」「今天发通知」**不关窗**。对应格填 `现有依据不支持` 或字段停止，十节保留。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，或两造争同一份启动闸，then 整体停止，不得选边治愈，也不得改走负触发，不得问代表哪一方后继续。
若 if 提出伪造、隐匿、格式化、威胁证人、打击报复或调岗举报人、限制人身自由、阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛；不得转介持有通知完成毁证。

## 节点 1　线索等级、被指向人和程序状态

1. 来源等级：`R#` 机关文书 > `D#` 书证／系统记录 > `S#` 实名陈述 > 匿名陈述 > 传闻。匿名不推定虚假，也不单独支持对个人的不利定性。同一人反复举报：合并编号，不因次数写成已属实。
2. 被指向人表：姓名变体、岗位、是否高管、是否能决定调查组人选／预算／信息技术权限／处分结果、是否公职人员或监察对象。名称不一致不自动合并。公职属性未核验：该格字段停止，不写「不是监察对象」。
3. 程序表逐动作记录举报受理、审计、检查、监察、公安、检察：机关、案号、文书、作出日、收到日、送达方式和效力凭证。口头转述、截图、「已读」不得写成已受理、已送达、已立案或期限已起算。
4. 检索锚点：公司法（2023 修订）第一百六十八条，国家出资公司是国家出资的国有独资公司、国有资本控股公司，包括有限责任公司和股份有限公司，不含国有资本参股。第一百七十七条，国家出资公司应当依法建立健全内部监督管理和风险控制制度，加强内部合规管理。对民营企业，启动内部调查是治理安排，不是该条的法定义务；不得用该条倒推民企董事会违法未立案。1993 年第一百七十七条公积金条款是噪声。
5. 《中央企业合规管理办法》（国资委令第 42 号）适用于国资委履行出资人职责的中央企业。第四十条，地方国有资产监督管理机构参照本办法，指导所出资企业加强合规管理工作。这是对地方国资监管机构的参照授权，不是地方国企或民企对国务院国资委的报告义务，更不是民企必须按该办法立案调查。第二十四条仅约束中央企业：设立违规举报平台、就举报问题调查处理、对造成资产损失或严重不良后果的移交责任追究、涉嫌违纪违法的按规定移交纪检监察；对举报人身份和事项严格保密；不得打击报复。主体不适用则 42 号令对照行删除，不写「建议比照上报」或「必须有报必查」。本任务只判断是否达到移交红旗，不写移送函。

每个 `Q#` 先写法律效果假设，再写成立条件。禁止合成「应当立案」一笔。按已出现事实扫描。

扫描项（可增，不可当成必须填满的闭集）：

| 编号 | 打开信号 | 本任务允许 | 禁止 | 转介 |

### 2.1 回避

若被指向人能够决定调查组人选、预算、信息技术权限或处分结果，必须另选主体。老板指定「自己人查自己」：`Q-避` 状态 `待核` 或 `不打开` 独立性，启动建议字段停止，十节仍出，窗口不关。无法另选：只输出冲突说明，不编造独立调查组。展开转 `处理利益冲突与调查回避`、`确定调查授权范围与独立`。

实务反例：参与调查的人员与被调查人有亲属、利害或其他可能影响公正的关系，应当回避；被调查人有权要求回避。本任务不把「有报必查」写成民企法定义务。

### 2.2 范围与禁止扩权

范围用「主体 × 期间 × 交易／账户 × 系统」闭合。超出线索的全员工作邮箱、通讯监控、定位轨迹、生物识别调取：禁止，并检查是否触发 `Q-数`。线索闭合内的系统保全只转介持有通知，本窗不授权监控。检索锚点：个人信息保护法第十三条，按照依法制定的劳动规章制度和依法签订的集体合同实施人力资源管理所必需，是处理员工个人信息的合法基础之一；不等于启动闸当然授权读取个人邮箱、定位或生物识别。合法基础未核验：数据专项字段停止。

调查人员不具备限制他人人身自由的权力。扣留工作设备应基于所有权或事先约定，不得写成搜查权。违法调取的通讯、私人邮箱不得当作 `Q-线` 可查性的支持事实。检索锚点：民事诉讼法解释关于严重侵害他人合法权益、违反法律禁止性规定或严重违背公序良俗的方法形成或获取的证据不得作为认定案件事实的根据（条号运行时核验，通常为第一百零六条）。本窗只标排除接口，不写排除裁定。

### 2.3 商业贿赂分账

检索锚点：反不正当竞争法 2025 修订第八条（施行日 2025-10-15）。经营者不得采用给予财物或其他手段贿赂交易相对方工作人员、受委托办理事务者、利用职权或影响力影响交易者，以谋取交易机会或竞争优势；明示折扣、佣金应当如实入账；工作人员贿赂原则上认定为经营者行为，但经营者有证据证明与谋取交易机会或竞争优势无关的除外。施行日前未持续的行为适用修改前文本（通常为 2019 修正第七条）。行为跨越施行日：记录冲突，分别建情景。不正当竞争专项不得吞掉本行。展开转 `评估反商业贿赂风险点`。

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 存在折扣、返点或佣金且如实入账 | 已构成商业贿赂；必须立案 |
| 有礼品或招待 | 必然违法 |
| 员工个人收钱 | 必然视为经营者行为 |
| 匿名举报 | 回扣已查实 |
| 管理不规范 | 已构成单位犯罪 |

## 节点 3　不启动、限缩与机关红旗

| 条件 | 输出 |
| --- | --- |
| 主体或期间无法识别 | 不启动正式调查；`Q-初` 打开最小书证保全接口；不得写没有问题 |
| 纯劳动争议外观且无廉洁／舞弊红旗 | 转劳动，本任务不启动企业廉洁调查 |
| 已有监察／公安要求不得平行接触证人 | 企业调查范围限缩或暂停，不对抗国家机关 |
| 达到启动条件治理层仍不查 | 记录治理风险，不强迫立案，不写成已经合规 |
| 夹带「先开除再补查」 | 启动建议该格 `现有依据不支持`；调查未完成不得以处分为启动替代；主成果变为处分才转劳动 |

检查、监察、检察合规、民事、劳动、刑事分列。每种期间单独一行。类型必须标明下列之一：`行政检查期限`／`监察调查措施期限`／`检察合规考察期`／`劳动解除或仲裁期限`／`刑事追诉时效`／`内部制度时限`。送达不明则该行截止日停止。不选定某局。不写死唯一截止日。口头来过不得起算。

已有监察文书：标 `Q-监`，不启动企业「平行灭证」。配合义务是如实向监察机关提供，不是企业自行发全员禁毁或清理设备。已有监察／公安 `R#` 时，`Q-证`／`Q-初` 不得转介持有通知完成清理或平行接触证人。本任务不写移送函、不写留置、不选定检察院。

检索锚点：劳动法第一百零一条，打击报复举报人员由劳动行政部门或有关部门处理，构成犯罪的依法追究刑事责任；刑法第二百五十五条，打击报复会计、统计人员。`Q-报` 只标停，不得把调岗、停奖、解除写成调查步骤。

## 节点 4　证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定内部邮件、对账单存在或内容有利。公文书证可推定形式真实，可反驳，不等于贿赂或违纪已成立，也不转移证明负担。

下一步按以下顺序，且必须标可逆性；本窗只转介，不出发送稿：

1. 提出隐匿、格式化、报复 → 整体停止，不得转介持有通知完成毁证
2. 已有监察／公安 `R#` → `Q-证` 不打开；不得转介持有通知做全员禁毁或清理；企业调查限缩或暂停
3. 证据可能灭失、无违法请求、且无监察／公安 `R#` → `准备证据保全与禁毁通知`
4. 回避未闭合 → `处理利益冲突与调查回避`／`确定调查授权范围与独立`
5. 范围需方案 → `制定调查方案与访谈计划`
6. 决定启动 → 转介案卷与合法收集原子，本任务不写立案决定
7. 需要事实结论 → `形成内部调查报告`
8. 检查已有 `R#` → `应对监管检查或突击检查`

用户要今天发出披露或持有通知终稿：若主成果仍是启动闸，第 9 节只写转介条件；主成果已变为发送版则目标停止或负触发。第 9 节不得写成发送、立案、开除或「此致某局」指令。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过启动闸直接给立案、处分、免责或已构罪。
