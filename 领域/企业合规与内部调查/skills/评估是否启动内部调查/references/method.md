# 启动闸方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。 不得把线索写成已查实，不得把不启动写成“没有问题”。

`search_law` 返回已失效《合同法》《民法通则》《民法总则》或其解释时记为噪声，不得写入 `L#`。MCP 将 2025 修订《反不正当竞争法》标为尚未施行但公布施行日为 2025-10-15 的，以施行日为准并记录冲突。

## 启动矩阵

固定列：`编号｜线索摘要｜来源等级｜可查性｜回避｜范围假设｜红旗｜启动判断｜待核`。

---

## 节点 0　专项分流


| 信号 | 转出 |
| --- | --- |
| 侦查、审查起诉、审判、取保、阅卷、辩护、刑事控告、自首材料 | 刑事领域 |
| 劳动合同、工资工时、解除劳动合同、工伤、职场性骚扰或日常违纪处分决定 | 劳动领域 |
| 个人信息合法性、影响评估、数据出境、等保、网安事件专项体系 | 数据隐私领域 |
| 垄断协议、滥用市场支配地位、经营者集中申报、不正当竞争专项评估 | 竞争法领域 |
| 税务处理、稽查实体 | 税务领域 |
| 银行保险机构行业合规办法主轴 | 金融领域 |
| 药品购销回扣行业细则主轴 | 医疗医药领域 |
| 出口管制、制裁名单 | 涉外领域 |
| 尚未进入合规机制，只要改交易合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |


职场性骚扰、考勤违纪、绩效不胜任主轴整案转劳动，即使夹带“合规”二字。已刑事立案且用户要辩护：整案转刑事。

---

## 节点 1　线索等级

1. `R#` 机关文书 > `D#` 书证/系统记录 > `S#` 实名陈述 > 匿名陈述 > 传闻。
2. 匿名不推定虚假，也不单独支持对个人的不利定性。
3. 同一人反复举报：合并编号，不因次数写成已属实。

---

## 节点 2　回避

若被指向人能够决定调查组人选、预算、信息技术权限或处分结果，必须另选主体。无法另选：启动建议停止，只输出冲突说明。

---

## 节点 3　范围

范围用“主体 × 期间 × 交易/账户 × 系统”闭合。超出线索的全员监控、定位轨迹、通讯内容调取：禁止，并检查是否触发数据专项。

国资企业对照第 42 号令第二十四条：举报事项调查后，造成资产损失或严重后果的移交责任追究；涉嫌违纪违法的按规定移交纪检监察。本任务只判断是否达到移交红旗，不写移送函。

---

## 节点 4　不启动与限缩

| 条件 | 输出 |
| --- | --- |
| 主体或期间无法识别 | 不启动正式调查，可做最小书证保全评估并转介持有通知 |
| 纯劳动争议外观 | 转劳动，本任务不启动企业廉洁调查 |
| 已有监察/公安要求不得平行接触证人 | 企业调查范围限缩或暂停，不对抗国家机关 |

---

## 节点 5　输出闸

启动判断三态。用户要求“先开除再补材料”：目标停止。用户要求今天出报告：转介报告原子，本任务不写认定。
