# 边界与路由

## 正触发

可能向监管、交易对方或法院提交或被调取内部调查材料，需要区分可交、应扣、待核，而不是出具监管交卷总清单、出境方案或调查结论。从零、材料碎片仍正触发：有拟标记材料则闸开或半开，出 `WP#` 草案。抄送法务即特权、律师在场即免交、ACP 即中国法免交、标记即已免交，仍正触发。

双方秘密、编造特权日志、虚构免交权、指导隐匿、阻挠合法检查的停止，优先于负触发。上述信号不在下表。「抄送法务即特权」「律师在场即特权」「全球统一特权」「ACP／FCPA 即中国法免交」「标记即已免交」「交清单即从轻」「商业秘密即对抗合法检查」不在下表。「不虚构美国式特权」「不伪造扣下理由」「不给出境方案」「不代提交」是交付禁令，不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 向监管交卷总清单或发送版特权日志 | `准备向监管提交材料与特权日志` |
| 数据出境或境外调取境内数据方案 | 数据隐私领域或 `协调跨境内部调查并分流涉外` |
| 刑事阅卷、辩护、控告或自首材料 | 刑事领域 |
| 调查报告或事实认定 | `形成内部调查报告` |
| 收集日志终稿 | `合法收集书证电子证与财务痕迹` |
| 检查现场应对终稿 | `应对监管检查或突击检查` |
| 交易合同改稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不虚构美国式特权」或「不伪造扣下理由」关窗。抄送法务即特权、ACP 即免交该格不支持，窗口不关。出境主成果才转数据，出现「出境」一词不是转出。编造特权日志不进本表，走整体停止。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |
| 出口管制、制裁名单、境外经营准入 | 涉外领域 |

综合内部调查材料标记主轴可留本任务。检查或审查起诉只作背景，主成果才转。出现「特权」「律师」一词不是转出。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 向监管正式交卷、发送版特权日志 | `准备向监管提交材料与特权日志` |
| 出境或境外调取 | `协调跨境内部调查并分流涉外` 或数据隐私 |
| 调查结论 | `形成内部调查报告` |
| 邮件、财务痕迹取回 | `合法收集书证电子证与财务痕迹` |
| 检查现场应对 | `应对监管检查或突击检查` |
| 主动披露正文 | `准备主动披露或自查报告` |

## 易混

抄送法务邮箱不等于特权。律师在场不等于免交。业务记录不因抄送律师改变性质。内部法务交流不等于执业律师保密，更不等于美国式特权。律师法保密义务不是对抗监管合法调取的免交权。商业秘密标签不是三要件已闭合，更不是当然拒检。标记不是已免交。扣下清单不是已合法拒交。全球统一特权政策不是中国法义务。FCPA／ACP／SOX 不是中国法免交理由。交清单不是从轻已成就。政府信息公开中的商业秘密抗辩不等于对抗监管检查。不虚构美国式特权、不伪造扣下理由是交付禁令，不是负触发。
