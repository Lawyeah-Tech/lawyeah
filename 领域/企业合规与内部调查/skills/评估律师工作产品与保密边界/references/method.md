# 评估方法

本文件是可执行判断节点。不虚构中国法下的美国式特权。抄送法务不等于特权。律师在场不等于免交。业务记录不因抄送律师改变性质。标记不是已免交。扣下清单不是已合法拒交。全球统一特权不支持。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、范本填满、唯一截止日、选定机关、代提交、未知写零。本任务不给出境方案，不定罪，不代提交。本窗 `WP#` 是标记行，不是监管交卷总清单，不是调查认定 `F#`，不是收集日志 `LG#`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1996 年律师法第三十八条（律师协会章程）、1996 年行政处罚法第三十二条（陈述申辩）、1980 年律师暂行条例、把美国 ACP 写成中国法免交时记为噪声。禁止指导编造特权日志、虚构免交或隐匿材料。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`WP#` 固定列：`编号｜材料简述｜形成目的｜作者身份（外聘执业律师／内部法务／业务人员）｜拟提交对象｜标记类型（法律分析／事实收集／业务记录／商业秘密候选）｜可交／应扣／待核｜理由类型｜规则核验状态｜E#回链｜判断三值｜缺口G#｜最强反方｜待核`。禁止合成「已特权闭环」。无法判断则该条待核，**不得默认保留美国式免交或抄送法务即特权**。`E#` 只作证据形态回链。缺项记 `G#`。扫描不是闭集。事实附件与法律分析拆开。

口头「抄送法务了就是特权」「美国协议写了 ACP」「群已读」只进 `S#`／`V#`，**不得单独算作开闸材料**。已读不得升格 `R#` 已送达。纸面草稿不是已免交。`A#` 是承认，不是已特权。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上中国内部法务人员通常不具备执业律师身份，其交流不受美国式律师—客户特权保护；即便外聘中国执业律师，律师法保密义务也不是对抗监管合法调取的免交权。向监管提交可能影响后续主张，只作红旗，不是必然放弃。

## 节点 0　分流、立场、标记闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。编造特权日志、虚构免交权、指导隐匿、阻挠合法检查、双方秘密不进负表。

整案转出只交付第 1、2、10 节，不出 `WP#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是向监管交卷总清单或发送版特权日志 | 负触发 `准备向监管提交材料与特权日志` |
| 主成果是数据出境或境外调取方案 | 整案转数据隐私或负触发 `协调跨境内部调查并分流涉外` |
| 主成果是刑事阅卷、辩护、控告或自首 | 整案转刑事 |
| 主成果是调查报告或事实认定 | 负触发 `形成内部调查报告` |
| 主成果是收集日志终稿 | 负触发 `合法收集书证电子证与财务痕迹` |
| 主成果是检查现场应对终稿 | 负触发 `应对监管检查或突击检查` |

审查起诉、监管检查只作程序背景。主成果才整案转。出现「特权」「律师」「出境」一词不是转出。

标记闸打开（可出 `WP#` 草案，仍不得标「已特权／已免交」）须同时满足：单方无冲突公司立场已闭合；主成果是标记、可交与应扣清单，不是监管交卷总清单或出境方案；至少一条可编号拟标记材料。从零：有拟标记材料即可开或半开，缺项记 `G#`。口头特权、已读不算单独开闸材料。双方秘密或第一次编造不是关闸条件，走整体停止。

标记闸部分打开：律师身份、商业秘密三要件或检查权限未核验，但已有可编号材料；对应格待核；仍交十节；不得标终稿 `已形成`。

标记闸关闭（仍正触发）：无一可编号拟标记材料。「今天必须出已免交终稿」而无最小事实不得开闸。不出 `WP#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `WP#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「抄送法务即特权」「律师在场即特权」「全球统一特权」「ACP／FCPA 即中国法免交」「标记即已免交」「交清单即从轻」「商业秘密即对抗合法检查」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `WP#` 草案。美国式免交行**不得写入可执行 `WP#`**。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无一拟标记材料，then 标记闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象或相对方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出编造特权日志、虚构免交权、指导隐匿或选择性销毁、伪造扣下理由、阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　中国法边界与强制接口

律师保密、商业秘密、工作秘密、国家秘密、配合检查分列。不得把外国特权条款写入 `L#`。

检索锚点（写入 `L#` 前须核验）：

- 律师法（2017 修正）第三十八条：执业律师对委托人的保密义务，不是对抗监管合法调取的美国式特权。噪声：1996 年第三十八条律师协会章程；律师执业管理办法第三十八条不正当方式影响办案。
- 内部法务通常不具备中国执业律师身份，交流不因「法务」升格律师保密。
- 监察法（2024 修正）第十八条：如实提供；不得伪造、隐匿、毁灭；监察机关对知悉信息保密。配合与保密分列。
- 反不正当竞争法商业秘密三要件须逐件核验，标签不是商业秘密，更不是当然免交。
- 行政处罚法（2021 修订）第三十二条：交材料不等于从轻已成就。噪声：1996 年第三十二条陈述申辩。
- 公司法（2023 修订）第六十七条不等于已授权对外提交。
- 刑法第一百六十二条之一只作红旗。

强制接口与非强制对标分列。向监管提交可能影响后续主张只作红旗，不是必然放弃。政府信息公开中的商业秘密抗辩与本案检查调取事实不同，不得写成必然免交。

## 节点 3　标记行 `WP#`

按已出现材料扫描，不是默认闭集。法律分析、事实收集、纯粹业务记录分列。业务记录不因抄送律师或律师在场改变性质。事实附件与法律分析拆开。

作者身份分列：外聘中国执业律师、内部法务、业务人员、境外律师。境外律师意见不自动构成中国法免交。

拟提交对象分列：监管检查、交易对方、法院、内部使用。向监管合法检查：配合义务优先，扣下仅限无检查权限或涉及已核验法定秘密的部分，对应格待核，不得写成已合法拒交。向交易对方：按合同与商业秘密三要件。向法院：只做清单接口，不代提交。

建议行型（按已出现事实选用，**不是默认闭集**）：

| 编号 | 含义 | 本窗允许 | 禁止 |
| --- | --- | --- | --- |
| `WP-法` | 律师法律分析 | 标记待核；作者身份 | 升格已特权免交 |
| `WP-事` | 事实收集／访谈笔记 | 与分析拆开 | 因抄送律师改性质 |
| `WP-业` | 业务记录／邮件／账套 | 可交候选 | 抄送法务即特权 |
| `WP-商` | 商业秘密候选 | 三要件待核 | 标签即免交 |

热冲突强制处理（不得保留为可执行行）：

- 美国 ACP／全球统一特权写成免交 → 删除或该格不支持。
- 抄送法务、律师在场写成已特权 → 该格不支持。
- 无理由扣光全部材料 → 禁止；作为对抗检查方法提出则整体停止。
- 编造扣下理由、虚构特权日志 → 整体停止。

无 `E#` 不得写已覆盖、已特权或已免交。状态 `草案`。扣下每一件必须有理由类型和规则核验状态；理由未核验则待核，不得提交虚假目录。

## 节点 4　跨境、可逆性与转介

材料出境或境外律师调取境内数据：只开接口，转数据隐私或 `协调跨境内部调查并分流涉外`，本窗不给出境方案。

向监管交卷总清单转 `准备向监管提交材料与特权日志`。调查结论转报告窗。收集实施转收集窗。检查现场转检查应对窗。

可逆与不可逆分列。不可逆（对外发送材料、向监管正式交卷、删除原件）不得在草案阶段实施。禁止提交指令。不代提交。

已有检查 `R#`：不得借标记稿平行隐匿。刑法第一百六十二条之一只作红旗，不得指导删除。

## 本任务回链纪律

本任务成果是「标记闸与可交／应扣／待核清单草案」。本窗不执行发送。不包含：已特权证明、已免交、监管交卷总清单终稿、出境方案、调查结论、收集日志。禁止编造特权日志。禁止选边治愈。禁止抄送法务即特权。禁止 ACP 即中国法免交。禁止交清单即从轻。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标标记终稿已形成。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：用户要求「邮件都抄了 legal@，美国总部 ACP 政策全球适用，监管来了全部拒交。」标记闸打开。`Q-抄`、`Q-美`、`Q-全`、`Q-检` 不打开为可靠路径。第 6 节不得把免交写入可执行 `WP#`；对应格 `现有依据不支持`；仍可出法律分析／业务记录分列草案。不关窗。不代提交。

场景②：用户主成果是「把向国资委／市场监管交卷的总清单和发送版特权日志写出来。」负触发 `准备向监管提交材料与特权日志`，一句路由，不填本窗实体十节。
