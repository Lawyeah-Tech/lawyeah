# 评估律师工作产品与保密边界

## 任务目标

在明确、无利益冲突的单方立场下（公司或其调查受托律师，互斥；不允许被调查对象代理），形成律师工作产品与保密边界评估草案：标记闸、中国法边界与强制接口、`Q#` 路径、`WP#` 标记行（材料类型／形成目的／作者身份／拟提交对象／可交／应扣／待核理由）。本窗 `WP#` 是标记行，不是监管交卷总清单，不是调查认定 `F#`，不是收集日志 `LG#`。不虚构中国法下的美国式 attorney-client privilege。抄送法务邮箱不等于特权。律师在场不等于免交。业务记录不因抄送律师改变性质。标记不是已免交。扣下清单不是已合法拒交。全球统一特权不支持。FCPA／ACP／SOX 不得写成中国法免交理由。不伪造扣下理由。不给出境方案。不代提交。不保证免责。

`depends-on` 为空。向监管交卷总清单转 `准备向监管提交材料与特权日志`。数据出境或境外调取境内数据方案转数据隐私或 `协调跨境内部调查并分流涉外`。刑事阅卷、辩护主成果转刑事。收集日志转 `合法收集书证电子证与财务痕迹`。调查报告转 `形成内部调查报告`。检查现场应对转 `应对监管检查或突击检查`。

## 工作边界

正触发：可能向监管、交易对方或法院提交或被调取内部调查材料，需要区分可交、应扣、待核，而不是出具监管交卷总清单、出境方案或调查结论。材料碎片、提交对象未核验仍正触发：有可编号拟标记材料则标记闸打开或半开，第 6 节出 `WP#` 草案，缺项记 `G#`。无一拟标记材料、又要求「今天必须出已免交终稿」才关闸，不出 `WP#` 终稿，窗口不关。用户要把抄送法务写成特权、把律师在场写成免交、把美国 ACP 写成中国法免交、把标记写成已免交、把交清单写成从轻、把全球政策写成统一特权，仍正触发：对应格填 `现有依据不支持`，窗口不关；闸已开仍出其他 `WP#` 草案。不得因「不虚构美国式特权」或「不伪造扣下理由」改走负触发关窗。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是向监管交卷总清单或发送版特权日志（转 `准备向监管提交材料与特权日志`）；
- 主成果是数据出境或境外调取境内数据方案（转数据隐私领域或 `协调跨境内部调查并分流涉外`）；
- 主成果是刑事阅卷、辩护、控告或自首材料（转刑事领域）；
- 主成果是调查报告或事实认定（转 `形成内部调查报告`）；
- 主成果是收集日志终稿（转 `合法收集书证电子证与财务痕迹`）；
- 主成果是检查现场应对终稿（转 `应对监管检查或突击检查`）。

双方秘密、编造特权日志、虚构免交权、指导隐匿或选择性销毁、阻挠合法检查**不在负触发表**，走整体停止。「抄送法务即特权」「律师在场即特权」「全球统一特权」「ACP／FCPA 即中国法免交」「标记即已免交」「交清单即从轻」「商业秘密即对抗合法检查」**不在负触发表**，该格 `现有依据不支持`，窗口不关。「不虚构美国式特权」「不伪造扣下理由」「不给出境方案」「不代提交」是交付禁令，不是负触发。

## 建立工作坐标

确认：单方公司立场；材料清单、形成目的、作者身份（外聘执业律师／内部法务／业务人员）、拟提交对象、跨境因素；法域；当前检查、诉讼、监察或刑事状态。

口头「抄送法务了就是特权」「美国协议写了 ACP」「群已读」只登记 `S#`／`V#`。不得升格已特权、已免交或已提交，**不得单独算作开闸材料**。已读不得升格 `R#` 已送达。纸面标记草稿不是已免交。

同时掌握公司与被调查对象或相对方相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。公司已开口且委托就是标记清单、且未掌握对方秘密时，可推定公司或其调查受托律师立场。被调查对象代理不是本窗立场。无一拟标记材料：标记闸关闭，仍交十节，不是整体停止。提出编造特权日志、虚构免交权、指导隐匿或阻挠合法检查：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认（不是已特权，不是已免交）；`R#` 机关或生效文书；`C#` 内部制度、律师委托或保密协议；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`WP#` 标记行；`V#` 版本；`E#` 证据形态回链（形成目的、作者身份、拟提交对象，不是发送闸，不是已免交证明）。禁止 `N#`、`EV#`、`M#`、`F#`、`ACT#`、`P#`、`K#`、`O#`、`H#`、`B#`、`U#`、`X#`、`HD#`、`W#`、`T#`、`OR#`、`LV#`、`TR#`、`PX#`、`LD#`、`SP#`、`CH#`、`CS#`、`PT#`、`RF#`、`RT#`、`AU#`、`AZ#`、`PL#`、`LG#`、`IQ#`、`CG#`、`IV#`、`OT#`、`SA#`、`Dsc#`。技能正文中的条号是检索锚点，不是已核验 `L#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止合成「已特权闭环」或「已免交」一笔。扫描不是闭集。未知件数不写零。稿件状态默认 `草案`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。本窗是评估类标记草案，案例只比较事实差异，**不要**升格「已特权／已免交／美国 ACP 即中国法免交／交清单即从轻」。
- 法规用于核验中国大陆现行律师保密、商业秘密、配合检查义务；实务用于发现抄送法务冒充特权、内部法务交流冒充律师—客户特权、全球统一特权的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《民法通则》《民法总则》或其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：律师法（2017 修正）执业律师保密义务（检索锚点第三十八条：保守执业中知悉的国家秘密、商业秘密，不得泄露当事人的隐私；对委托人不愿泄露的情况和信息应当保密，危害国家安全、公共安全以及严重危害他人人身安全的犯罪事实和信息除外）。该条是律师对委托人的保密义务，**不是**对抗监管合法调取的美国式特权。噪声：1996 年律师法第三十八条律师协会章程；律师执业管理办法第三十八条不正当方式影响办案。内部法务人员通常不具备中国执业律师身份，其交流不因「法务」二字升格律师保密。监察法（2024 修正）第十八条有关单位和个人应当如实提供，不得伪造、隐匿、毁灭；监察机关对知悉的国家秘密、工作秘密、商业秘密、个人隐私和个人信息应当保密——配合义务与保密分列，不是免交。反不正当竞争法商业秘密三要件（不为公众所知悉、具有商业价值、采取保密措施）须逐件核验，不是标签即商业秘密，更不是对抗合法检查的当然免交。行政处罚法（2021 修订）第三十二条从轻减轻情形，交材料不等于从轻已成就。噪声：1996 年行政处罚法第三十二条陈述申辩。公司法（2023 修订）第六十七条不等于已授权对外提交。刑法第一百六十二条之一只作红旗，不得指导删除。噪声：已失效《合同法》、1980 年律师暂行条例、美国 ACP／FCPA／SOX 写成中国法免交。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变律师保密边界、商业秘密要件或配合检查义务的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补抄送法务冒充特权、内部法务交流不受美国式律师—客户特权保护、业务记录不因抄送律师改变性质、向监管提交可能影响后续主张的反例。
- `search_case_by_fact`（recommended）只比较事实差异与翻转条件：政府信息公开中的商业秘密抗辩、过程性信息不予公开，不等于企业内部调查材料对抗监管检查调取；不得写成必然免交或必然可采。

工具不可用时继续材料分层和 `WP#` 编目；律师保密边界、商业秘密要件、配合检查义务、施行日字段停止。不得拒跑，不得凭记忆写成美国式特权或抄送法务即免交。

## 判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、标记闸与不关窗

主成果才整案转出。编造特权日志、双方秘密第一次停。抄送法务即特权、ACP 即免交不关窗。闸关仍交十节，第 6 节不出 `WP#` 终稿。

### 2. 中国法边界与强制接口

律师保密、商业秘密、工作秘密、国家秘密、配合检查分列。美国 ACP 不写入 `L#`。内部法务与外聘执业律师分列。

### 3. 标记闸与路径 `Q#`

本节禁止出 `WP#` 终稿。有可编号拟标记材料：闸打开或半开。无一材料才关闸，窗口不关。

### 4. 标记行 `WP#`

形成目的、作者、拟提交对象、可交／应扣／待核分列。业务记录不因抄送律师升格。状态 `草案`。

### 5. 跨境接口与转介

出境只开接口，不给出境方案。向监管交卷总清单转邻窗。不代提交。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出编造特权日志、虚构免交权、指导隐匿或选择性销毁、伪造扣下理由、阻挠合法检查。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一拟标记材料：标记闸关闭，仍交十节，不是整体停止。
- `字段停止`：律师身份、商业秘密三要件、检查权限、施行日未核验。抄送法务即特权、律师在场即特权、全球统一特权、ACP 即中国法免交、标记即已免交、交清单即从轻、商业秘密即对抗合法检查：该格 `现有依据不支持`，窗口不关；闸已开仍出其他 `WP#` 草案。
- `目标停止`：主目标变为监管交卷总清单、出境方案、刑事阅卷、调查结论、收集日志。

禁止指导编造特权日志、虚构免交或隐匿材料。不给胜诉率。不定罪。不保证免责。不选定机关。不代提交。未知不写零。不虚构美国式特权。不把抄送法务写成特权。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。标记闸关闭仍交十节，第 6 节不出 `WP#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `WP#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。标记闸未打开时不得交付「已特权」或「已免交」。边界见 [路由](references/routing.md)。
