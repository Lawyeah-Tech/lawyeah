# 评估上市公司廉洁与内控交叉

## 任务目标

在明确、无利益冲突的单方立场下，形成廉洁与内控交叉草案：交叉闸、上市架构、`Q#` 路径、`X#` 交叉红旗行（廉洁面／关联方面／内控陈述冲突／披露接口）、已披露冲突、调查与披露转介。红旗不是已违规成立，不是必须公告，不是内控已失效终局。不写法定信息披露正文、问询答复或停复牌说明。不保证合规免责。不代提交。

`depends-on` 为空。公告、问询答复或联交所 query／停复牌说明正文转证券／公司治理交叉（含港股）。舆情与法定披露策略转 `评估舆情与法定披露交叉`。关联交易股东大会决议转公司治理领域。单件调查转 `评估是否启动内部调查`。账外资金链路转 `评估回扣账外暗中与资金链路`。关联交易廉洁面终稿转 `评估利益冲突与关联交易廉洁面`。董事会汇报提纲转 `准备董事会合规汇报材料`。非上市贿赂／账外主成果转 `评估反商业贿赂风险点`；非上市关联方／回避主成果转 `评估利益冲突与关联交易廉洁面`。

## 工作边界

正触发：上市主体需要把廉洁红旗与内控、关联方、披露触发点对齐，且主成果不是公告正文。红旗未核验、内控评价缺失、关联方清单冲突仍正触发：交叉闸关闭，不出 `X#` 终稿，窗口不关。用户要把未核验红旗写成无需披露、用金额不重大或偶发写成无需披露、用内控评价有效洗白未闭合红旗、把关联方写成当然利益输送、把红旗写成财务造假或单位犯罪已成立、非上市或港股-only 发行人必须按证券法公告、今天必须交披露结论，仍正触发：对应格填 `现有依据不支持`，窗口不关；闸已开仍出其他 `X#` 草案。不得因「要求写成无需披露」改走负触发关窗。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是法定信息披露、问询答复、联交所 query 或停复牌说明正文（转证券／公司治理交叉）；
- 主成果是舆情与法定披露策略终稿（转 `评估舆情与法定披露交叉`）；
- 主成果是关联交易股东大会决议（转公司治理领域）；
- 主成果是单件调查启动（转 `评估是否启动内部调查`）；
- 主成果是关联交易廉洁面终稿（转 `评估利益冲突与关联交易廉洁面`）；
- 主成果是回扣账外资金链路终稿（转 `评估回扣账外暗中与资金链路`）；
- 主成果是董事会汇报提纲（转 `准备董事会合规汇报材料`）；
- 主成果是非上市贿赂或账外风险点（转 `评估反商业贿赂风险点`）；
- 主成果是非上市关联方或回避廉洁面（转 `评估利益冲突与关联交易廉洁面`）；
- 主成果是主动披露或自查报告终稿（转 `准备主动披露或自查报告`）。

双方秘密、伪造内控评价、伪造关联方清单、伪造公告底稿、倒签回避、指导删除会计资料、隐瞒已知红旗、打击报复**不在负触发表**，走整体停止。「无需披露」「金额不重大故无需披露」「内控有效洗白」「关联方即输送」「非上市或港股-only 必须按证券法公告」**不在负触发表**，该格 `现有依据不支持`，窗口不关；闸已开仍出其他 `X#`。

## 建立工作坐标

确认：交叉评估授权；单方立场（上市公司／被调查对象，互斥）；上市地与架构（A 股／港股／红筹或 VIE／A+H）；谁是境内证券法义务人、谁是联交所发行人；控股股东与实际控制人；关联方清单版本；最近期内控评价（董事会评价与会计师审计分列）；已知廉洁线索；问询、停复牌或监察／稽查背景。

口头「内控很完善」「金额不重大不用披露」「已经公告过了」只登记 `S#`／`V#`。不得升格内控有效、无需披露或已合规，**不得算作开闸材料**。已读、微信已读、电话、口头尽快、快递揽收只进 `S#`／`V#`，不得升格 `R#` 已送达，**交易所问询已读不得起算答复期**。口头备份不等于已保全。

同时掌握公司与被调查对象相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。公司已开口且委托就是交叉红旗、且未掌握对方秘密时，可推定公司立场。无书面交叉评估授权但公司立场已闭合：交叉闸关闭，仍交十节，不是整体停止。提出伪造内控评价、伪造关联方清单、伪造公告底稿、倒签回避、指导删除会计资料、隐瞒已知红旗或打击报复：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认（不是整改动作，不是内控已补）；`R#` 机关或生效文书；`C#` 内部制度或内控评价文本；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`X#` 交叉红旗行；`V#` 版本；`E#` 证据形态回链（公告、内控评价、关联方清单、资金痕迹，不是发送闸）。禁止 `N#`（公告／问询答复正文）、`EV#`、`M#`、`F#`、`ACT#`、`P#`、`K#`、`O#`、`H#`、`B#`、`U#`、`HD#`。技能正文中的条号是检索锚点，不是已核验 `L#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止合成「内控有效故无需披露」一笔。扫描不是闭集。列出红旗不是已披露或已合规。未知不写零。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或已披露公告检索。本窗是评估类交叉，**不要**用文书范本检索生成「已披露／内控有效／无需披露」清单，也不得代写公告。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现内控评价与未闭合红旗冲突；案例与公告只比较事实差异与翻转条件，不写成必然结果。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《民法通则》《民法总则》或其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：证券法（2019 修订）第七十八条、第八十条只约束**境内证券法上的信息披露义务人**，港股-only 开曼或香港发行人该格 `现有依据不支持`，不关窗；A+H 两套披露接口并列，禁止合成「已经公告过了」。本窗只开披露**接口**，不得写成必须公告或无需披露已成立。公司法（2023 修订）第一百四十条只约束境内上市公司实际控制人披露。第一百八十二条董监高关联交易报告与回避，开曼董事不得写成当然适用；程序终稿转公司治理，本窗只评廉洁／回避／账外。第二十一条不是当然利益输送公式。企业内部控制基本规范只作内控评价接口；董事会内控评价 ≠ 会计师财务报告内控审计，不得合成一笔。行政处罚法第三十二条提交交叉表不等于情节成就。监察法第十八条如实提供，不得伪造、隐匿、毁灭。刑法第一百六十二条之一只作红旗，**不得指导删除**。噪声：已失效《合同法》、把红旗写成必须公告或无需披露已成立、内控评价有效洗白未闭合红旗、关联方即输送、港股-only 或非上市套证券法临时报告、交表即从轻。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变披露接口、关联交易回避或实际控制人披露范围的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补内控评价有效仍被问询、金额不重大抗辩未被接受、关联方程序合规仍有账外利益的反例。
- `search_announcement` 只比对已披露事实与当前红旗的差异，不代写公告，不把未检索到公告写成无需披露。

工具不可用时继续红旗、关联方和 `X#` 编目；披露判断、期限、机关路径字段停止。不得拒跑，不得凭记忆写成无需披露、内控必然有效或必须公告。

## 判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、交叉闸与不关窗

主成果才整案转出。证监会调查或审查起诉只作背景。伪造内控评价第一次停。无需披露、金额不重大、内控有效洗白、港股套证券法不关窗：该格不支持，闸已开仍出其他 `X#`。闸关仍交十节，第 6 节不出 `X#` 终稿，第 7 节不得出无需披露或必须公告终稿。

### 2. 上市架构与已披露陈述

A 股／港股／红筹或 VIE／A+H 分列。证券法 78／80 只对境内义务人开接口。港股-only 发行人该格不支持。境内经营实体不是开曼发行人。口头不得升格已披露。

### 3. 交叉闸与路径 `Q#`

本节禁止出 `X#` 终稿。无一可编号红旗且无一内控或关联方材料则闸可关，窗口不关。口头完善不得开闸。

### 4. 交叉红旗行 `X#`

一件红旗一行：廉洁面、关联方面、内控陈述冲突、披露接口分列。未核验不得写无需披露。内控有效不能洗白未闭合红旗，也不得擅自推翻审计。

### 5. 披露接口、调查转介

只开接口。不写公告、问询答复、联交所 query 或停复牌一句正文。闸关时本节不得写无需披露或必须公告终稿。调查、持有通知、舆情披露、关联交易决议只转介。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造内控评价、伪造关联方清单、伪造公告底稿、倒签回避、指导删除会计资料、隐瞒已知红旗、借已有监察／稽查文书平行灭证或打击报复。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无书面交叉评估授权但公司立场已闭合：不是整体停止，交叉闸关闭，仍交十节。
- `字段停止`：上市规则、重大事件构成、关联方范围、内控评价周期、谁是披露义务人未核验。无需披露、金额不重大故无需披露、内控有效洗白、关联方即输送、非上市或港股-only 必须按证券法公告、交表即从轻：该格 `现有依据不支持`，窗口不关；闸已开仍出其他 `X#` 草案；闸未开才不出 `X#` 终稿，第 7 节也不得出披露终稿。
- `目标停止`：主目标变为公告正文、问询答复、关联交易决议、调查结论或舆情披露策略终稿。

禁止指导伪造内控评价或删除会计资料。不给胜诉率。不定罪。不保证免责。不选定机关。不代提交。未知不写零。不写公告正文。不擅自推翻年报内控审计。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。交叉闸关闭仍交十节，第 6 节不出 `X#` 终稿，第 7 节不得出无需披露或必须公告终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `X#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。交叉闸未打开时不得交付交叉终稿或「无需披露」。边界见 [路由](references/routing.md)。
