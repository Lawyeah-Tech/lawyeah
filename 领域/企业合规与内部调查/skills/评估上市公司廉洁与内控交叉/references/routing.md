# 边界与路由

## 正触发

上市主体需要把廉洁红旗与内控、关联方、披露触发点对齐，且主成果不是公告正文。红旗未核验、内控评价缺失仍正触发：交叉闸关闭，不出 `X#` 终稿，窗口不关。无需披露、内控有效洗白、关联方即输送、非上市必须公告，仍正触发。

双方秘密、伪造内控评价、伪造关联方清单、伪造公告底稿、倒签回避、隐瞒已知红旗、指导删除会计资料、平行灭证、打击报复的停止，优先于负触发。上述信号不在下表。「无需披露」「金额不重大故无需披露」「内控有效洗白」「关联方即输送」「非上市或港股-only 必须按证券法公告」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 公告、问询答复、联交所 query 或停复牌说明正文 | 证券／公司治理交叉 |
| 舆情与法定披露策略终稿 | `评估舆情与法定披露交叉` |
| 关联交易股东大会决议 | 公司治理领域 |
| 单件调查启动 | `评估是否启动内部调查` |
| 关联交易廉洁面终稿 | `评估利益冲突与关联交易廉洁面` |
| 回扣账外资金链路终稿 | `评估回扣账外暗中与资金链路` |
| 非上市贿赂或账外风险点 | `评估反商业贿赂风险点` |
| 非上市关联方或回避廉洁面 | `评估利益冲突与关联交易廉洁面` |
| 董事会汇报提纲 | `准备董事会合规汇报材料` |
| 主动披露或自查报告终稿 | `准备主动披露或自查报告` |
| 刑事辩护、控告 | 刑事领域 |
| 劳动处分决定 | 劳动领域 |

不得因「要求写成无需披露」或「内控评价有效」关窗。未核验红旗仍正触发，不得写成无需披露。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、解除、工伤主轴 | 劳动领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |
| 垄断、滥用支配、经营者集中 | 竞争法领域 |
| 税务稽查实体 | 税务领域 |
| 章程、股权、关联交易决议本身为主成果 | 公司治理领域 |

综合廉洁与内控交叉主轴可留本任务。审查起诉、证监会调查或交易所问询只作背景，主成果才转。

## 易混

内控评价「有效」不能自动洗白未查实的廉洁红旗。未核验事实不得写「无需披露」。金额不重大不得升格无需披露终稿。关联方不是当然利益输送。红旗不是必须公告，也不是财务造假已成立。非上市或港股-only 套证券法临时报告：该格不支持，不关窗。境内经营实体不是开曼发行人。问询或联交所 query 已读不是答复期起算。「先补假内控评价再交差」整体停止。列出红旗不是已披露或已合规。
