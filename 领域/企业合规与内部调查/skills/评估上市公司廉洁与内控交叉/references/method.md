# 评估方法

本文件是可执行判断节点。红旗不是已违规成立，不是必须公告，不是内控已失效终局。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、必须公告、无需披露已成立、唯一截止日、选定机关、代提交、未知写零。本任务不定罪，不写公告正文，不替代年报内控审计。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、把红旗写成必须公告或无需披露已成立、把内控评价有效写成洗白未闭合红旗、把关联方写成当然利益输送、把非上市主体套证券法临时报告时记为噪声。禁止指导伪造内控评价或删除会计资料。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`X#` 固定列：`编号｜红旗簇｜廉洁面｜关联方面｜内控陈述冲突｜披露接口｜E#回链｜判断三值｜最强反方｜待核｜转介`。禁止合成「内控有效故无需披露」一笔。`E#` 只作证据形态回链。禁止 `N#`／`EV#`／`M#`／`F#`／`ACT#`／`P#`／`K#`／`O#`／`H#`／`B#`／`U#`／`HD#`。扫描不是闭集。列出红旗不是已披露或已合规。

口头「内控很完善」「金额不重大不用披露」只进 `S#`／`V#`，**不得算作开闸材料**。已读、快递揽收、口头尽快不得升格问询已送达或政策已生效。**交易所问询已读不得起算答复期**。口头备份不等于已保全。`A#` 是承认，不是整改动作，不是内控已补。拟制日＝本次形成本任务成果之日。

## 节点 0　分流、立场、交叉闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。伪造内控评价、伪造关联方清单、伪造公告底稿、隐瞒已知红旗、指导删除、平行灭证、打击报复、双方秘密不进负表。

整案转出只交付第 1、2、10 节，不出 `X#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是公告、问询答复或停复牌说明正文 | 负触发，转证券／公司治理交叉 |
| 主成果是舆情与法定披露策略终稿 | 负触发 `评估舆情与法定披露交叉` |
| 主成果是关联交易股东大会决议 | 负触发，转公司治理领域 |
| 主成果是单件调查启动 | 负触发 `评估是否启动内部调查` |
| 主成果是关联交易廉洁面终稿 | 负触发 `评估利益冲突与关联交易廉洁面` |
| 主成果是回扣账外资金链路终稿 | 负触发 `评估回扣账外暗中与资金链路` |
| 主成果是董事会汇报提纲 | 负触发 `准备董事会合规汇报材料` |
| 主成果是非上市廉洁风险点 | 负触发 `评估反商业贿赂风险点` |
| 主成果是主动披露或自查报告终稿 | 负触发 `准备主动披露或自查报告` |
| 侦查、起诉、辩护为主成果 | 整案转刑事 |
| 劳动处分决定为主成果 | 整案转劳动 |

审查起诉、证监会调查、交易所问询只作程序背景。主成果才整案转。

交叉闸打开（可出 `X#` 草案，仍不得标「无需披露／必须公告／内控有效洗白／已合规」）须同时满足：单方无冲突公司立场已闭合；主成果是廉洁与内控交叉，不是公告正文、问询答复、调查结论或舆情披露策略；至少一件可编号红旗、内控评价文本或关联方清单。口头完善不算开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

交叉闸部分打开：上市规则或关联方范围未闭合，但已有可编号红旗或内控／关联方材料；对应格待核；仍交十节；不得标终稿 `已形成`。

交叉闸关闭（仍正触发）：公司立场已闭合但无书面交叉评估授权；无一红旗且无一内控或关联方材料。「今天必须交披露结论」而无最小事实不得开闸。不出 `X#` 终稿。**仍交十节**，第 5 节只交闸／`Q#` 状态，第 6 节不出 `X#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「无需披露」或「没有红旗」。

「未核验红旗无需披露」「内控评价有效洗白未闭合红旗」「关联方即利益输送」「非上市主体必须按证券法公告」「红旗即财务造假或单位犯罪已成立」「保证合规免责」「今天必须交披露结论」「提交交叉表即应当从轻」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `X#` 草案，不得因错误主张扣掉整张表。闸未开才不出 `X#` 终稿。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无书面交叉评估授权，then 交叉闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造内控评价、伪造关联方清单、伪造公告底稿、倒签回避、指导删除会计资料、隐瞒已知红旗、借已有监察／稽查文书平行灭证或打击报复，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　上市架构与已披露陈述

固定上市地、境内／境外上市架构、信息披露义务人。非上市主体：证券法临时报告行删除，该格 `现有依据不支持`，不关窗；主成果确为非上市廉洁风险才负触发 `评估反商业贿赂风险点`。

检索锚点（写入 `L#` 前须核验）：

- 证券法（2019 修订）第七十八条：依法披露的信息应当真实、准确、完整。本窗只开接口，不写公告正文。
- 第八十条：重大事件临时报告。构成未核验则披露判断字段停止，不得写「必须公告」或「无需披露已成立」。
- 公司法（2023 修订）第一百四十条：上市公司依法披露实际控制人；禁止违反法律、行政法规代持上市公司股票。非上市不适用。
- 第一百八十二条：董监高关联交易报告与回避。程序终稿转公司治理；本窗只评廉洁／回避／账外。
- 第二十一条：控股股东、实际控制人不得利用关联关系损害公司利益。不是当然输送公式。
- 企业内部控制基本规范：只作评价接口。本窗不替代年报内控审计，不得擅自推翻无保留结论，也不得用该结论洗白未闭合红旗。

已披露陈述与当前红旗冲突：两行并列。`search_announcement` 未命中不得写成无需披露。

## 节点 3　交叉红旗行 `X#`

每件红旗必须分列：涉及主体是否关联方（待核）、是否出现账外利益或中间人、是否与最近期内控评价或已披露「内控有效」冲突、是否可能构成应披露事项（只开接口）。

规则或上市规则未核验：披露判断字段停止，不得写「不影响披露」。内控中介已出无保留结论但出现未闭合廉洁事件：记冲突，不擅自推翻审计，也不写成内控必然有效。金额不重大、偶发：只进最强反方，未核验不得写成无需披露。

无 `E#` 回链不得写已披露或内控已覆盖。关联方名称出现不等于利益输送已成立。

## 节点 4　披露接口、调查与转介

只标触发点与停止项。禁止公告一句正文、问询答复草稿、停复牌说明。

已出现媒体或股价异动且用户要披露策略：转介 `评估舆情与法定披露交叉`。要调查：转介 `评估是否启动内部调查`。关联交易批准程序：转公司治理。账外资金：转介 `评估回扣账外暗中与资金链路`。

已有监察或稽查 `R#`：不得借交叉表平行灭证。刑法第一百六十二条之一只作红旗，不得指导删除。隐瞒已知红旗第一次整体停止。

下一步只转介邻居。禁止提交指令、此致交易所或证监会。

## 本任务回链纪律

本任务成果是「交叉闸与廉洁／内控／关联方／披露接口草案」。不包含：公告正文、问询答复、停复牌说明、调查结论、舆情披露策略终稿、关联交易决议、内控审计意见。禁止伪造内控评价。禁止选边治愈。禁止红旗即必须公告。禁止内控有效洗白。禁止关联方即输送。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标交叉终稿已形成。
风险档 A：伪造内控评价、伪造关联方清单、隐瞒已知红旗、指导删除必须单独标可逆性；提出即整体停止。
