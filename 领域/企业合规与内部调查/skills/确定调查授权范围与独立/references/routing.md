# 边界与路由

## 正触发

已经决定调查，需要把授权来源、范围、独立性与禁止事项写成可执行要点，而不是决定查不查、做访谈或出回避名单终稿。从零、授权碎片、无书面文件仍正触发：有拟设或范围碎片则闸开或半开，出 `AU#` 草案。口头即书面、自己人查自己、全员监控即范围闭合，仍正触发。

双方秘密、伪造或倒签授权、假董事会纪要、指导违法取证、限制人身自由、指导删除、阻挠合法检查的停止，优先于负触发。上述信号不在下表。「口头即书面」「自己人查自己即独立」「全员监控即范围闭合」「民企套 177／42」「法院调查令即内部授权」不在下表。「不扩大全员监控」「不实施访谈」「不保证免责」是交付禁令，不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 是否启动尚未决定 | `评估是否启动内部调查` |
| 调查方案与访谈计划 | `制定调查方案与访谈计划` |
| 回避名单终稿 | `处理利益冲突与调查回避` |
| 取证实施 | `合法收集书证电子证与财务痕迹` |
| 工作产品终稿 | `评估律师工作产品与保密边界` |
| 发送版持有禁毁通知 | `准备证据保全与禁毁通知` |
| 全员监控或个保／数据专项体系 | 数据隐私领域 |
| 劳动处分、解除或职场性骚扰调查 | 劳动领域 |
| 确为中央企业且 42 号令对照终稿 | `评估国企合规管理办法差距` |
| 交易合同改稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不扩大全员监控」或「不实施访谈」关窗。全员监控主张该格不支持，窗口不关。民企硬套不得负触发到对照窗。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、解除、工伤、职场性骚扰主轴 | 劳动领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |
| 垄断、滥用支配、经营者集中 | 竞争法领域 |

综合内部调查授权主轴可留本任务。审查起诉或检查只作背景，主成果才转。出现「授权」「调查」一词不是转出。已刑事立案且主成果是刑事程序：整案转刑事。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 查不查、谁查、查到哪尚未闭合 | `评估是否启动内部调查` |
| 回避名单终稿 | `处理利益冲突与调查回避` |
| 步骤、顺序、访谈 | `制定调查方案与访谈计划` |
| 邮件、财务、合同痕迹取回 | `合法收集书证电子证与财务痕迹` |
| 律师工作产品标记 | `评估律师工作产品与保密边界` |
| 发送版禁毁通知 | `准备证据保全与禁毁通知` |

## 易混

老板口头「你们去查」不是书面授权。授权范围不是空白支票。书面授权不是已独立。被调查人自己签发对自己的授权不是独立。挂名无授权不是已配置。任命一人不是授权已闭环。全员监控不是范围闭合。人力资源管理所必需不是全员邮箱、私人微信或定位。法院调查令栏目不是内部授权法定格式。公司法第六十七条董事会职权不是已签发调查授权。公司法第一百七十七条不是民企必须调查上报。不扩大全员监控、不实施访谈是交付禁令，不是负触发。
