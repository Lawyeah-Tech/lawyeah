# 评估方法

本文件是可执行判断节点。口头授权不是书面授权。授权范围不是空白支票。被调查人自己签发对自己的授权不是独立。书面授权不是已独立。全员监控不是范围闭合。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、范本填满、唯一截止日、选定机关、代提交、未知写零。本任务不实施访谈，不写发送版授权书，不定罪，不代提交。本窗 `AU#` 是授权行，不是回避名单终稿，不是调查方案，不是取证实施。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1993 年公司法第六十七条、把第一百七十七条或 42 号令套民企、把口头写成书面、把法院调查令写成内部授权时记为噪声。禁止指导伪造授权、违法取证、限制人身自由或删除会计资料。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`AU#` 固定列：`编号｜授权来源／职权｜范围（主体×期间×交易或账户×系统）｜独立性与回避接口｜禁止事项｜汇报线｜E#回链｜判断三值｜缺口G#｜最强反方｜待核`。禁止合成「已书面授权闭环」。无法判断则该条待核，**不得默认保留全员监控或自签授权**。`E#` 只作证据形态回链。缺项记 `G#`。扫描不是闭集。

口头「你们去查」「老板点头了」「群已读」只进 `S#`／`V#`，**不得算作开闸材料**。已读、揽收不得升格 `R#` 已送达。纸面草稿不是已生效。`A#` 是承认，不是已授权。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

## 节点 0　分流、立场、授权闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。伪造或倒签授权、假董事会纪要、指导违法取证、限制人身自由、指导删除、阻挠合法检查、双方秘密不进负表。

整案转出只交付第 1、2、10 节，不出 `AU#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是是否启动 | 负触发 `评估是否启动内部调查` |
| 主成果是调查方案与访谈计划 | 负触发 `制定调查方案与访谈计划` |
| 主成果是回避名单终稿 | 负触发 `处理利益冲突与调查回避` |
| 主成果是取证实施 | 负触发 `合法收集书证电子证与财务痕迹` |
| 主成果是工作产品终稿 | 负触发 `评估律师工作产品与保密边界` |
| 主成果是发送版持有禁毁 | 负触发 `准备证据保全与禁毁通知` |
| 主成果是全员监控或个保专项 | 整案转数据隐私 |
| 主成果是劳动处分、解除或性骚扰调查 | 整案转劳动 |
| 侦查、起诉、辩护为主成果 | 整案转刑事 |

审查起诉、监管检查只作程序背景。主成果才整案转。出现「授权」「调查」一词不是转出。已刑事立案：企业调查不得以干扰侦查为目的，主成果是刑事程序则整案转刑事；本窗授权行对应格不支持干扰侦查的范围。

授权闸打开（可出 `AU#` 草案，仍不得标「已书面授权／已独立／已可取证」）须同时满足：单方无冲突公司立场已闭合；主成果是授权、范围与独立性要点，不是启动闸、访谈或回避终稿；至少一条可编号拟设授权行或范围碎片。从零：有拟设或碎片即可开或半开，缺项记 `G#`。口头指示、已读不算开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

授权闸部分打开：授权主体职权、独立性或个保边界未核验，但已有可编号范围；或无书面文件但已有拟设行；对应格待核；仍交十节；不得标终稿 `已形成`。

授权闸关闭（仍正触发）：无一可编号拟设且无一范围碎片。「今天必须出已生效授权终稿」而无最小事实不得开闸。不出 `AU#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `AU#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「口头即书面」「自己人查自己即独立」「全员监控即范围闭合」「民企必须按 177／42 号令授权上报」「法院调查令即内部授权」「任命一人即闭环」「交授权要点即从轻」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `AU#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合、无书面文件但已有拟设行或范围碎片，then 授权闸部分打开，仍交十节，不是整体停止。
若 if 公司立场已闭合但无一拟设且无一碎片，then 授权闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造或倒签授权、假董事会纪要、指导违法取证、限制人身自由、指导删除会计资料、借授权稿平行灭证、打击报复或阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

中央企业／地方国企／参股／民企分列。授权来源分列：董事会、审计委员会、法定代表人、合规负责人、章程授权。无权主体：授权字段停止，不得开始取证设计。

检索锚点（写入 `L#` 前须核验）：

- 公司法（2023 修订）第六十七条：董事会决定内部管理机构设置、制定基本管理制度，不等于已签发调查授权。噪声：1993 年第六十七条。
- 公司法第一百六十八条、第一百七十七条：177 不套民企必须调查上报。
- 42 号令第二条、第四十条：只约束中央企业；地方国资参照不是民企对国资委义务。
- 个保法第六条、第十三条：人力资源管理所必需 ≠ 全员邮箱、私人微信、定位、生物识别。
- 劳动合同法第四条：只开接口。
- 监察法（2024 修正）第十八条：不得伪造、隐匿、毁灭。
- 刑法第一百六十二条之一、第三百零七条、第三百零八条只作红旗。

强制接口与非强制对标分列。

## 节点 3　授权行 `AU#`

按已出现授权来源与范围扫描，不是默认闭集。范围用主体 × 期间 × 交易或账户 × 系统闭合。用户要求「顺便查所有邮箱、定位全员」：超出部分该格不支持，不得写入可执行范围。

热冲突强制处理（不得保留）：

- 被调查人控制选人、预算或自己签发对自己的授权 → 独立性不支持；仍出其他 `AU#`。
- 与线索无关的全员监控、私人设备镜像、定位、生物识别 → 删除或该格不支持。
- 限制人身自由、扣留员工不得离场 → 禁止事项强制写入；作为方法提出则整体停止。
- 承诺免责换口供、威胁证人、向被调查人通风、选择性删除 → 禁止事项；作为方法提出则整体停止。
- 干扰侦查或对抗合法检查的范围 → 该格不支持；指导阻挠则整体停止。

未处理回避：授权可列要点，但「可依赖授权」字段停止，转介回避原子。汇报对象不得是被调查人。董事会成员涉案：改向独立委员会或外部董事接口。

无 `E#` 不得写已覆盖、已书面授权或已独立。状态 `草案`。

## 节点 4　禁止事项、可逆性与转介

必须写入禁止事项接口：不得威胁证人、不得承诺免责换口供、不得入侵系统、不得秘密违法录音方案、不得销毁或选择性删除、不得向被调查人通风、不得限制人身自由。用户要求写规避检查：整体停止。

可逆与不可逆分列。不可逆（发送授权对外、开始镜像全员邮箱、限制人身自由、格式化旧档）不得在草案阶段实施。禁止提交指令。不代签发、不代提交。不实施访谈。

下一步只转介：回避、方案／访谈、取证、工作产品、持有通知、启动闸（仅当启动未闭合）。禁止一次写完全部邻窗终稿。

已有监察或检查 `R#`：不得借授权稿平行灭证。刑法第一百六十二条之一只作红旗，不得指导删除。
