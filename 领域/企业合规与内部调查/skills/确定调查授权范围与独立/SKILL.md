# 确定调查授权范围与独立

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。本窗是确定类授权草案，范本只借栏目，**不要**升格「已书面授权／已独立／已可取证／法院调查令即内部授权」。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现口头授权冒充书面、被调查人自签授权、全员监控冒充范围、挂名无授权的反例；案例只比较事实差异与翻转条件，不写成必然结果。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《民法通则》《民法总则》或其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方公司立场下，形成内部调查书面授权草案：授权闸、主体与强制接口、`Q#` 路径、`AZ#` 授权行（授权来源／范围三要素／独立性与回避接口／禁止事项／汇报线）。本窗 `AZ#` 是授权行，不是工程审计条款 `AU#`。口头「你们去查」不是书面授权。授权范围不是空白支票。被调查人自己签发对自己的授权：独立性不支持。书面授权不是已独立。授权稿不是已合法取证。挂名无授权不是已配置。任命一人不是授权已闭环。与线索无关的全员监控、定位、生物识别不是范围。不实施访谈。不写发送版授权书。不保证免责。不代提交。

`depends-on` 为空。是否启动尚未决定转 `评估是否启动内部调查`。回避名单终稿转 `处理利益冲突与调查回避`。调查方案与访谈计划转 `制定调查方案与访谈计划`。取证实施转 `合法收集书证电子证与财务痕迹`。工作产品终稿转 `评估律师工作产品与保密边界`。持有禁毁通知转 `准备证据保全与禁毁通知`。全员监控或个保专项转数据隐私。

## 工作边界

正触发：已经决定调查，需要把授权来源、范围、独立性与禁止事项写成可执行要点，而不是决定查不查、做访谈或出回避名单终稿。授权碎片、独立性未核验、无书面授权文件仍正触发：有可编号拟设授权行或范围碎片则授权闸打开或半开，第 6 节出 `AZ#` 草案，缺项记 `G#`。无书面文件但有拟设行：部分打开。无一拟设且无一范围碎片、又要求「今天必须出已生效授权终稿」才关闸，不出 `AZ#` 终稿，窗口不关。用户要把口头指示写成书面授权、把自己人查自己写成已独立、把全员邮箱／定位写成范围闭合、把授权稿写成已合法取证、把法院调查令栏目写成内部已授权、民企按公司法第一百七十七条或 42 号令必须授权上报，仍正触发：对应格填 `现有依据不支持`，窗口不关；闸已开仍出其他 `AZ#` 草案。不得因「不扩大全员监控」或「不实施访谈」改走负触发关窗。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是是否启动（转 `评估是否启动内部调查`）；
- 主成果是调查方案与访谈计划（转 `制定调查方案与访谈计划`）；
- 主成果是回避名单终稿（转 `处理利益冲突与调查回避`）；
- 主成果是取证实施（转 `合法收集书证电子证与财务痕迹`）；
- 主成果是工作产品终稿（转 `评估律师工作产品与保密边界`）；
- 主成果是发送版持有禁毁通知（转 `准备证据保全与禁毁通知`）；
- 主成果是全员监控或个保／数据专项体系（转数据隐私领域）；
- 主成果是劳动处分、解除或职场性骚扰调查（转劳动领域）；
- 确为中央企业且主成果是 42 号令对照终稿（转 `评估国企合规管理办法差距`）。

双方秘密、伪造或倒签授权、假董事会纪要、指导违法取证、限制人身自由、指导删除会计资料、阻挠合法检查**不在负触发表**，走整体停止。「口头即书面」「自己人查自己即独立」「全员监控即范围闭合」「授权稿即已合法取证」「第十四条即已签发」「第二十一条签字即已审查」「民企必须按 177／42 号令授权上报」「法院调查令即内部授权」**不在负触发表**，该格 `现有依据不支持`，窗口不关。「不扩大全员监控」「不实施访谈」「不保证免责」是交付禁令，不是负触发。

## 建立工作坐标

确认：书面或拟设授权；单方公司立场；启动决定、线索范围、拟任调查主体、经费审批人、汇报对象、已有利益冲突；法域；当前检查、诉讼、监察或刑事状态。

口头「你们去查」「老板点头了」「群已读」只登记 `S#`／`V#`。不得升格书面授权、已独立或已可取证，**不得算作开闸材料**。已读、揽收不得升格 `R#` 已送达。纸面授权草稿不是已生效。

同时掌握公司与被调查对象相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。公司已开口且委托就是授权要点、且未掌握对方秘密时，可推定公司立场。无书面授权文件但公司立场已闭合、且已有可编号拟设行或范围碎片：授权闸部分打开，仍交十节，不是整体停止。无一拟设且无一碎片：授权闸关闭，仍交十节，不是整体停止。提出伪造授权、倒签授权日、假董事会纪要、指导违法取证、限制人身自由或阻挠合法检查：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认（不是已书面授权，不是已独立）；`R#` 机关或生效文书；`C#` 章程、董事会决议或内部授权制度；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`AZ#` 授权行；`V#` 版本；`E#` 证据形态回链（授权来源文件、范围三要素、回避接口、汇报对象，不是发送闸，不是已生效授权证明）。禁止 `N#`、`EV#`、`M#`、`F#`、`ACT#`、`P#`、`K#`、`O#`、`H#`、`B#`、`U#`、`X#`、`HD#`、`W#`、`T#`、`OR#`、`LV#`、`TR#`、`PX#`、`LD#`、`SP#`、`CH#`、`CS#`、`PT#`、`RF#`、`RT#`、`AU#`、`SA#`、`Dsc#`。技能正文中的条号是检索锚点，不是已核验 `L#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止合成「已书面授权闭环」或「已独立可取证」一笔。扫描不是闭集。未知人数、系统范围不写零。稿件状态默认 `草案`。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：公司法（2023 修订）第六十七条董事会决定内部管理机构设置、制定基本管理制度，不等于已签发调查授权、已任命调查组或已独立。噪声：1993 年第六十七条国有资产监督管理。第一百六十八条国家出资公司不含参股。第一百七十七条仅约束国家出资公司对内合规，不是民企必须立案调查并上报。中央企业合规管理办法第二条只约束国资委履行出资人职责的中央企业；第四十条是地方国资参照。第十四条合规管理部门组织或参与调查，不等于已签发调查授权书。第二十一条重大决策合规审查意见由首席合规官签字，签字接口不是已审查，也不是已授权调查。个人信息保护法第六条最小范围、第十三条人力资源管理所必需，不等于授权全员工作邮箱、私人微信、定位或生物识别。劳动合同法第四条劳动纪律民主程序只开接口。监察法（2024 修正）第十八条如实提供，不得伪造、隐匿、毁灭。刑法第一百六十二条之一、第三百零七条、第三百零八条只作红旗，不定罪，不得指导删除。非法取证对后续劳动、监察或刑事的排除效果只作红旗，本窗不写排除裁定。噪声：已失效《合同法》、177 或 42 号令套民企、口头即书面、第十四条即已签发、第二十一条签字即已审查、法院调查令即内部授权、全员监控当然合法、交授权要点即从轻。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变授权主体、个保调取边界或 42 号令主体的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补口头授权冒充书面、被调查人自签授权、全员监控冒充范围、挂名无授权的反例。企业邮箱查看权即使写进手册，也不等于私人设备、定位当然授权。
- `search_template`（optional）只借授权来源、范围、禁止事项、汇报线栏目。人民法院调查令、不准许调查收集证据通知书不是内部授权法定格式，不得升格已授权。

工具不可用时继续授权来源、范围三要素和 `AZ#` 编目；主体义务、个保边界、施行日字段停止。不得拒跑，不得凭记忆写成口头已书面授权或民企必须按 177 上报。

## 判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、授权闸与不关窗

主成果才整案转出。伪造授权、违法取证、双方秘密第一次停。口头即书面、自己人查自己、全员监控不关窗。闸关仍交十节，第 6 节不出 `AZ#` 终稿。

### 2. 主体与强制接口

中央企业／地方国企／参股／民企分列。董事会／审计委员会／法定代表人／合规负责人分列。无权主体授权：授权字段停止。

### 3. 授权闸与路径 `Q#`

本节禁止出 `AZ#` 终稿。有可编号拟设行或范围碎片：闸打开或半开。无一拟设且无一碎片才关闸，窗口不关。口头指示、已读不得开闸。

### 4. 授权行 `AZ#`

授权来源、范围三要素、独立性接口、禁止事项、汇报线分列。被调查人自签：独立性不支持。全员监控行删除或该格不支持。状态 `草案`。

### 5. 回避接口、禁止事项与转介

回避未处理：「可依赖授权」字段停止，展开转回避原子。不实施访谈。不可逆取证不得在草案阶段实施。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造或倒签授权、假董事会纪要、指导违法取证、限制人身自由、指导删除会计资料、借授权稿平行灭证、打击报复或阻挠合法检查。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无书面授权文件但公司立场已闭合：不是整体停止；有拟设则部分打开，无一拟设则闸关闭，仍交十节。
- `字段停止`：授权主体职权、42 号令主体、个保调取边界、施行日未核验。口头即书面、自己人查自己即独立、全员监控即范围闭合、授权稿即已合法取证、第十四条即已签发、第二十一条签字即已审查、民企套 177／42、法院调查令即内部授权：该格 `现有依据不支持`，窗口不关；闸已开仍出其他 `AZ#` 草案。
- `目标停止`：主目标变为启动闸、回避名单终稿、调查方案／访谈、取证实施、工作产品终稿、发送版禁毁通知。

禁止指导伪造授权、违法取证、限制人身自由或删除会计资料。不给胜诉率。不定罪。不保证免责。不选定机关。不代提交。未知不写零。不实施访谈。不把口头写成书面。不把全员监控写成范围。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。授权闸关闭仍交十节，第 6 节不出 `AZ#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `AZ#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。授权闸未打开时不得交付「已书面授权」或「已独立可取证」。边界见 [路由](references/routing.md)。
