# 评估方法

本文件是可执行判断节点。框架不是已合规，不是已运转，不是制度全文。缺一段不得称闭环。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、最佳实践填满、唯一截止日、选定机关、代提交、未知写零。本任务不定罪，不写劳动规章全文，不建设数据或竞争专项体系。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、把 42 号令或第一百七十七条套民企、把框架写成已合规、把 FCPA 写成中国法义务、用最佳实践填满缺项时记为噪声。禁止指导伪造已落地或删除会计资料。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`W#` 固定列：`编号｜闭环段（预防／发现／应对／整改）｜维（组织／政策／流程／监测／资源）｜现行碎片｜拟设模块｜E#回链｜判断三值｜缺口G#｜最强反方｜待核`。禁止合成「已合规闭环」一笔。`E#` 只作证据形态回链。缺项记 `G#`，不得用「参照最佳实践」填满。扫描不是闭集。

口头「国际最佳实践就够了」「框架图就是已经合规」只进 `S#`／`V#`，**不得算作开闸材料**。已读、快递揽收不得升格制度已生效。口头备份不等于已保全。`A#` 是承认，不是已落地。拟制日＝本次形成本任务成果之日。

## 节点 0　分流、立场、框架闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。伪造已落地、倒签制度、指导删除、平行灭证、打击报复、双方秘密不进负表。

整案转出只交付第 1、2、10 节，不出 `W#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是已有体系是否运转 | 负触发 `评估合规管理体系有效性` |
| 主成果是章程级办法全文 | 负触发 `起草合规管理办法或章程级制度` |
| 主成果是三道防线岗位配置终稿 | 负触发 `配置合规机构与三道防线` |
| 主成果是正式有效性评价项目 | 负触发 `开展合规有效性评价` |
| 主成果是劳动规章或员工手册纪律全文 | 整案转劳动 |
| 主成果是数据或竞争专项体系 | 整案转相应领域 |
| 主成果是交易合同改稿 | 审查起草本窗搁置 |
| 主成果是 42 号令对照终稿 | 负触发 `评估国企合规管理办法差距` |
| 侦查、起诉、辩护为主成果 | 整案转刑事 |

审查起诉、监管检查只作程序背景。主成果才整案转。

框架闸打开（可出 `W#` 草案，仍不得标「已合规／已运转／已闭环终稿」）须同时满足：单方无冲突公司立场已闭合；主成果是综合框架，不是有效性、办法全文或专项体系；至少一项可编号现有碎片或拟设模块。口头最佳实践不算开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

框架闸部分打开：主体或资源未闭合，但已有可编号碎片或模块；对应格待核；仍交十节；不得标终稿 `已形成`。

框架闸关闭（仍正触发）：公司立场已闭合但无书面设计授权；无一模块且无一碎片。「今天必须出已落地证明」而无最小事实不得开闸。不出 `W#` 终稿。**仍交十节**，第 5 节只交闸／`Q#` 状态，第 6 节不出 `W#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「已经合规」或「没有缺口」。

「框架即已合规或已运转」「缺一段仍称闭环」「参照最佳实践填满缺项」「民企必须按 177 或 42 号令达标上报」「把 FCPA 或萨班斯程序写成中国法义务」「保证框架即免责」「今天必须出已落地证明」「提交框架即应当从轻」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `W#` 草案。闸未开才不出 `W#` 终稿。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无书面设计授权，then 框架闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造已落地运行记录、倒签制度生效、指导删除会计资料、借框架稿平行灭证或打击报复，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

名称、规模、是否中央企业／国家出资公司／上市分列。不自动合并。

检索锚点（写入 `L#` 前须核验）：

- 公司法第一百六十八条：国家出资公司不含参股。第一百七十七条仅国家出资公司对内合规，不是对外交稿或民企义务。
- 42 号令第二条、第四十条：只约束中央企业；第四十条是对地方国资机构的参照指导。民企框架是风险控制设计，强制对照行删除，该格 `现有依据不支持`，不关窗。
- 不得把美国《反海外腐败法》或萨班斯内控条款写成中国法定义务；可作非强制对标并标明法域。
- 行政处罚法第三十二条：提交框架不等于情节成就。

国企适用办法条款才写入强制项。强制接口与非强制对标分列，不选对用户有利的一版。

## 节点 3　框架模块 `W#`

预防、发现、应对、整改必须都能指到组织、流程和证据。缺一段不得称闭环。最低集接口：治理与报告线、政策层级、高风险场景、举报与反报复、调查授权、证据持有、第三方、礼品招待、监测、整改验收、培训——按已出现需求扫描，不是默认闭集；缺项记 `G#`，不得用「参照最佳实践」填满。

资源不足记缺口。外包边界可描述，不签服务合同。劳动纪律、工时、解除只留「转劳动制度」接口。交易合同只留接口要点。

## 节点 4　顺序、可逆性与转介

先职责和举报／持有接口，再专项制度。不一次写完全部全文。可逆动作与不可逆动作分列。不可逆（对外披露、处分、终止第三方）不得在框架阶段实施。

下一步只转介：办法全文、三道防线、有效性、义务地图、政策层级、举报渠道、反贿赂制度。禁止提交指令。

已有监察或检查 `R#`：不得借框架稿平行灭证。刑法第一百六十二条之一只作红旗，不得指导删除。
