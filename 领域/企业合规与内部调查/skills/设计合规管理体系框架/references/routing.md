# 边界与路由

## 正触发

公司要从零建立或重构综合合规管理体系框架，而不是评价已有体系或写专项制度全文。碎片制度、资源不足仍正触发：框架闸关闭，不出 `W#` 终稿，窗口不关。框架即合规、缺段称闭环、最佳实践填满、民企套 177 或 42 号令、FCPA 当中国法，仍正触发。

双方秘密、伪造已落地、倒签制度、指导删除、平行灭证、打击报复的停止，优先于负触发。上述信号不在下表。「框架即合规」「缺段称闭环」「最佳实践填满」「民企套 42 号令」「FCPA 当中国法」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 已有体系是否运转 | `评估合规管理体系有效性` |
| 章程级办法全文 | `起草合规管理办法或章程级制度` |
| 三道防线岗位配置终稿 | `配置合规机构与三道防线` |
| 正式有效性评价项目 | `开展合规有效性评价` |
| 劳动规章或员工手册纪律全文 | 劳动领域 |
| 数据或竞争专项体系 | 数据隐私或竞争法领域 |
| 42 号令对照终稿 | `评估国企合规管理办法差距` |
| 交易合同改稿 | 审查起草领域（本窗搁置，只说明） |
| 刑事辩护、控告 | 刑事领域 |

不得因「保证已合规」或「要求按 42 号令写死」关窗。缺段仍正触发，不得称闭环。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、解除、工伤主轴 | 劳动领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |
| 垄断、滥用支配、经营者集中 | 竞争法领域 |
| 章程、股权、任免本身为主成果 | 公司治理领域 |

综合框架主轴可留本任务。审查起诉或检查只作背景，主成果才转。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 已有体系要判断运转 | `评估合规管理体系有效性` |
| 要章程级办法全文 | `起草合规管理办法或章程级制度` |
| 三道防线岗位细节 | `配置合规机构与三道防线` |
| 正式评价项目 | `开展合规有效性评价` |
| 确为中央企业且主成果是 42 号令对照 | `评估国企合规管理办法差距` |
| 政策层级与例外批准 | `设计政策层级与例外批准` |
| 举报渠道终稿 | `建设内部举报渠道与受理规则` |

## 易混

框架不是制度全文。有框架图不能写成已经合规。缺发现或整改段不是闭环。民企套 42 号令或第一百七十七条：该格不支持，不关窗。FCPA 对标不是中国法义务。「先补假运行记录再出框架」整体停止。劳动规章全文不在本窗。
