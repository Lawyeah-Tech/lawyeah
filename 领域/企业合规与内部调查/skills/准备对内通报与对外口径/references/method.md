# 评估方法

本文件是可执行判断节点。口径草稿不是已发送、不是已披露、不是已通报。对外口径不是调查报告摘要公开。群已读不是已送达。内部口径不是必须公告。一套稿打天下禁止。未核验不得写成已查清。无验收不得写已全面整改。交口径表不是从轻，也不是自首。民企套 42 号令不是必须向国资委通报。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、选定媒体、代发送、未知写零。本窗不出可发送 `N#`，不写公告正文。本窗 `CM#` 是口径行，不是董事会提纲 `N#`，不是调查认定 `F#`，不是处置路径 `DP#`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1998 年证券法第七十八条要约收购、2005 年第六十三条、1996 年行政处罚法第三十二条、把 42 号令第二十四条写成民企必须向国资委通报、把群已读写成已送达时记为噪声。禁止指导公开攻击举报人、编造已查清对外发布或泄露身份。禁止 `search_template` 生成新闻稿或公告。`search_announcement` 只对照已披露事实，本窗仍不出公告正文。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`CM#` 固定列：`编号｜受众｜信息层级｜事实三态（已核验／仍在查／不评论）｜禁止项｜拟用句｜E#回链｜判断三值｜G#｜最强反方`。禁止合成「已通报闭环」。无 `E#` 不得写已覆盖、已发送、已披露。`E#` 只作证据形态回链。缺项记 `G#`。扫描不是闭集。

口头「已经对外说了」「群已读」「已全面整改」「无问题」「个别员工」只进 `S#`／`V#`，**不得单独算作开闸材料**。已读不得升格 `R#` 已送达或已披露。截图不等于已保全。口径草稿不等于已发送。`A#` 是承认发过内部说明，不是已通报。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

## 节点 0　分流、立场、口径闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、公开攻击举报人、编造已查清对外发布、指导泄露身份、伪造口径依据、指导隐匿、阻挠检查不进负表。

整案转出只交付第 1、2、10 节，不出 `CM#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是法定公告／问询／query 正文 | 负触发 `评估舆情与法定披露交叉` |
| 主成果是舆情披露策略终稿 | 负触发 `评估舆情与法定披露交叉` |
| 主成果是董事会正式汇报提纲且不含分层口径 | 负触发 `准备董事会合规汇报材料` |
| 主成果是调查报告终稿 | 负触发 `形成内部调查报告` |
| 主成果是主动披露发送稿 | 负触发 `准备主动披露或自查报告` |
| 主成果是保护方案终稿 | 负触发 `设计举报人保护与反报复措施` |
| 主成果是处置路径终稿 | 负触发 `评估调查后处置路径` |
| 主成果是检查现场口径终稿 | 负触发 `应对监管检查或突击检查` |
| 主成果是向监管交卷与特权日志 | 负触发 `准备向监管提交材料与特权日志` |
| 主成果是劳动解除或处分文书 | 整案转劳动 |
| 主成果是刑事控告、辩护或自首 | 整案转刑事 |
| 「不写公告正文」「不泄露举报人」「不定罪」 | 交付禁令，不是负触发 |

审查起诉、监管检查、已立案只作程序背景。主成果才整案转。出现「公告」「媒体」「董事会」一词不是转出。已刑事立案：企业口径不得以干扰办案为目的。

口径闸打开（可出 `CM#` 草案，仍不得标「已发送／已披露／已通报」）须同时满足：单方无冲突公司立场已闭合；主成果是分层口径，不是公告、上会提纲、调查终稿或监管发送稿；至少一名可编号受众，或至少一句拟设口径。口头「已经对外说了」、群已读不算单独开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

口径闸部分打开：已有可编号受众或拟设句，但授权、上市状态、检查并行、事实三态未闭合；或无书面口径授权但已有受众或拟设句；对应格待核；仍交十节；不得标终稿 `已形成`。

口径闸关闭（仍正触发）：无一可编号受众且无一拟设口径句。「今天必须出已发送终稿」而无最小事实不得开闸。不出 `CM#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `CM#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关写成「没有问题不必说」或「已经通报过了」。

「一套稿打天下」「内部口径即必须公告」「群已读即已通报」「口径稿即已披露」「未核验即已查清」「已全面整改」「无问题」「交表即从轻／即自首」「民企必须按 42 号令向国资委通报」「个别员工即不可识别」「港股必须套证券法」「红旗必须公告」「内控有效即洗白」**不关窗**。对应格 `现有依据不支持` 或该句删除。闸已开仍出其他 `CM#` 草案。禁止披露项写入可执行句：**该行删除**，窗口不关。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无一可编号受众且无一拟设句，then 口径闸关闭，仍交十节，不是整体停止。
若 if 单方立场已闭合、无书面授权但已有可编号受众或拟设句，then 口径闸部分打开，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出公开攻击或泄露举报人、编造已查清／已立案对外发布、伪造口径依据、指导隐匿、打击报复、阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　受众分层、主体与保密强制接口

每个受众一行。全员信默认无姓名、无调查细节，除非法律或制度强制且已核验。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 受众 | 董事会内部／员工／交易对方／媒体／监管接口，分列 | 一套稿打天下 |
| 主体 | 是否境内信息披露义务人；中央企业／地方国企／参股／民企；港股分列 | 港股套证券法 78／80；民企套 42 号令必须报国资委 |
| 事实三态 | 已核验／仍在查／不评论 | 未核验升格已查清 |
| 禁止项 | 举报人身份、证人住址、未成年人、未证实第三人犯罪标签、律师分析原文 | 写入可执行句而不删除 |

检索锚点（写入 `L#` 前须核验）：证券法第七十八条／第八十条；信披办法不得以新闻发布代替公告；42 号令第二十二条／第二十四条／第四十条；个保法第六条／第十三条／第二十五条；行政处罚法第三十二条；刑法第六十七条；监察法第十八条。本节禁止出 `CM#` 终稿。

## 节点 3　口径行 `CM#`

按已出现受众扫描，不是默认闭集。建议行型（出现才用）：

| 编号 | 含义 | 本窗允许 | 禁止 |
| --- | --- | --- | --- |
| `CM-董` | 董事会内部有限口径 | 最小必要；非正式 | 当已上会 `N#`；总体可控覆盖红旗 |
| `CM-员` | 员工／全员 | 最小必要 | 姓名、细节、可识别「个别员工」 |
| `CM-客` | 交易对方 | 合同通知接口 | 本窗审合同；概括弃权 |
| `CM-媒` | 媒体 | 短、可回链、不猜测动机 | 新闻发布代替公告；选定媒体 |
| `CM-监` | 监管接口 | 只开接口 | 本窗出交卷终稿或现场口径 |

热冲突强制处理：

- 未核验即已查清／无问题 → 该句删除或该格不支持；仍出其他 `CM#`。
- 无验收写已全面整改 → **该句删除**。
- 一套稿打天下 → 该格不支持；分受众重写。
- 群已读即已通报 → 该格不支持。
- 口径即已披露／必须公告 → 该格不支持；上市触发只开接口。
- 交表即从轻／即自首 → 该格不支持。
- 民企套 42 号令必须通报 → 该格不支持，不得建议上报国资委。
- 禁止披露项写入可执行句 → **该行删除**，窗口不关。
- 公开攻击／编造已立案对外发布 → 整体停止，不是该格不支持。

无 `E#` 不得写已覆盖、已发送或已披露。状态 `草案`。一次只推荐下一步。监管在查：口径不得与检查应对冲突，并行只开接口。

## 节点 4　禁止文书、可逆性与转介

第 7 节只开接口，不得夹带 `CM#` 终稿或公告一句绕闸。闸关闭时第 7 节可写「闸未开，转介待受众或拟设句编号」，不得补写已发送口径。

不写公告正文、问询答复、可发送 `N#`、起诉状、解除决定。不可逆（群发全员、对媒体发布、向国资委／监管正式报告、签署对外声明）不得在草案阶段实施。禁止提交或群发指令。不代发送。不选定媒体或机关。

下一步只转介：`评估舆情与法定披露交叉`、`准备董事会合规汇报材料`、`形成内部调查报告`、`准备主动披露或自查报告`、`评估调查后处置路径`、`应对监管检查或突击检查`、`设计举报人保护与反报复措施`、`评估打击报复风险`、`评估律师工作产品与保密边界`、`处理利益冲突与调查回避`、`准备向监管提交材料与特权日志`、`跟踪整改验收与复发监测`。

若 if 用户催促「按零写／填满已发送终稿」，then 该格 `现有依据不支持`，窗口不关。
若 if 时点、人数、金额未知，then 写 `未知`／`G#`，禁止写 `0`。

## 再执行清单

每个节点结束后回写：来源、判断、最强反方、是否字段停止。不得跳过口径闸直接给已发送或已披露。

若 if 42 号令主体、披露义务人、个保公开边界未核验，then 该强制项字段停止，窗口不关。
判断状态只许三值。口头已说过、群已读不得写成 `CM#` 已覆盖。

## 本任务回链纪律

本任务成果是「口径闸与分层口径草案」。本窗不执行发送。不包含：已发送证明、已披露、公告正文、上会提纲终稿、调查报告、监管发送稿。禁止选边治愈。禁止未核验即已查清。禁止一套稿打天下。禁止民企套第 24 条必须通报。禁止交表即从轻或自首。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标口径终稿已形成。
风险档 A：公开攻击举报人、编造已查清对外发布、指导泄露必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：民企。已有可编号员工受众＋拟设句「调查已全面结束、无问题、已全面整改」。用户同时主张未核验即已查清、已全面整改、无问题、群已读即已通报、一套稿打天下、交表即从轻即自首、民企按 42 号令必须通报、口径即已披露。口径闸打开。`Q-清`、`Q-改`、`Q-无`、`Q-读`、`Q-套`、`Q-32`、`Q-67`、`Q-24`、`Q-披` 不打开为可靠路径。第 6 节被打中的格 `现有依据不支持` 或该句删除；仍出其他 `CM#`（如董事会最小必要、媒体「不评论」）。不关窗。不写公告正文。不得建议报国资委。

场景②：用户要求公开点名举报人并编造「公安已立案」对外发布，且要在公司与被调查人之间选边。命中公开攻击＋编造对外发布＋双方秘密。第一次整体停止。只交第 1、10 节。不出 `CM#`。不得问代表哪一方后继续。
