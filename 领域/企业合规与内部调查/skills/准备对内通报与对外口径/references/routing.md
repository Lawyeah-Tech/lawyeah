# 边界与路由

## 正触发

需要分层口径，而不是法定公告正文或调查报告全文公开。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 董事会正式汇报提纲 | `准备董事会合规汇报材料` |
| 法定公告正文 | `证券披露/公司治理交叉` |
| 舆情与披露触发评估 | `评估舆情与法定披露交叉` |
| 调查报告 | `形成内部调查报告` |
| 刑事辩护、控告、自首 | 刑事领域 |
| 劳动处分、解除、职场违纪调查 | 劳动领域 |
| 个人信息、数据出境、网安体系整案 | 数据隐私领域 |
| 垄断、经营者集中、反垄断调查主轴 | 竞争法领域 |
| 未进入合规机制的合同改稿 | 审查起草领域（本窗搁置，只说明） |
| C 端小微体检 / 供应商清单 / 广告 / 隐私 / 劳动规章 | 大众专项，只分流不回改 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、取保、阅卷、辩护词、刑事控告、自首 | 刑事领域 |
| 劳动合同、工资、解除、工伤、职场性骚扰主轴 | 劳动领域 |
| 个人信息合法性、影响评估、出境、等保、网安事件专项整案 | 数据隐私领域 |
| 垄断协议、滥用支配地位、经营者集中、反垄断调查主轴 | 竞争法领域 |
| 税务处理决定、稽查实体 | 税务领域 |
| 银行保险机构行业合规办法 | 金融领域 |
| 药品购销回扣行业细则 | 医疗医药领域 |
| 出口管制、制裁名单 | 涉外领域 |
| 尚未进入合规机制的交易合同改稿 | 审查起草领域（本窗搁置，只说明不实施） |

综合合规或内部调查主轴可留本任务；专项只作为背景时在缺口标明，不把专项规则写入本任务结论。


## 易混

对外口径不是调查报告摘要公开。说“个别员工”仍可能可识别。
