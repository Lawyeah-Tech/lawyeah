# 边界与路由

## 正触发

需要对董事会、员工、客户、媒体或监管接口给有限分层口径，而不是法定公告正文、调查报告全文公开、董事会正式汇报或主动披露发送稿。授权、事实未闭合仍正触发：有可编号受众或待说事实切片则闸开或半开，出 `CM#` 草案。一套稿打天下、内部口径即必须公告、群已读即已送达、口径稿即已生效、未核验即已查清、已全面整改、交表即从轻／即自首、民企套 42 号令必须通报、红旗必须公告、内控有效即洗白、个别员工即不可识别、港股必须套证券法，仍正触发。

双方秘密、公开攻击或泄露举报人、编造已查清充开闸或对外虚假口径、伪造口径依据、指导隐匿、打击报复、阻挠合法检查的停止，优先于负触发。上述信号不在下表。「一套稿打天下」「内部口径即必须公告」「群已读即已送达」「口径稿即已生效」「未核验即已查清」「已全面整改」「交表即从轻／即自首」「民企套 42 号令必须通报」「红旗必须公告」「内控有效即洗白」「个别员工即不可识别」「港股必须套证券法」不在下表。举报人身份写入可执行口径是该行删除，不在下表。「不写上市公司公告正文」「不泄露举报人身份」「不把未核验写成已查清」「不代发送」「不选定媒体」「不保证绝对不泄露」「不出可发送 `N#`」是交付禁令，不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 上市公司公告、临时公告或法定信息披露正文 | `评估舆情与法定披露交叉` |
| 主动披露或自查发送稿 | `准备主动披露或自查报告` |
| 董事会正式汇报提纲且不含分层口径比较 | `准备董事会合规汇报材料` |
| 调查报告终稿 | `形成内部调查报告` |
| 举报人保护方案终稿 | `设计举报人保护与反报复措施` |
| 处置路径终稿 | `评估调查后处置路径` |
| 检查或突击检查现场应对口径 | `应对监管检查或突击检查` |
| 向监管交卷与特权日志 | `准备向监管提交材料与特权日志` |
| 证据案卷 | `建立内部调查证据案卷` |
| 劳动解除、处分决定或劳动争议程序文书 | 劳动领域 |
| 刑事控告、辩护、自首或阅卷 | 刑事领域 |
| 未进入合规机制的交易合同改稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不写公告正文」「不泄露举报人」「不把未核验写成已查清」关窗。一套稿、必须公告、已读即送达该格不支持，窗口不关，不转出。出现「公告」「媒体」「董事会」一词不是转出。主成果才转。港股硬套证券法不得负触发到披露评估窗。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、解除、工伤、职场性骚扰主轴且分层口径不是主成果 | 劳动领域 |
| 税务处理决定、稽查实体 | 税务领域 |
| PIPL 专项、出境、等保、网安体系整案（本窗个保第二十五条只开公开边界接口） | 数据隐私领域 |
| 垄断、滥用支配、经营者集中 | 竞争法领域 |
| 出口管制、制裁名单、境外经营准入 | 涉外领域 |

综合内部调查后分层口径主轴可留本任务。检查或已立案只作背景，主成果才转。已刑事立案且主成果是刑事程序：整案转刑事。已刑事立案但主成果仍是企业分层口径：留窗；指导干扰办案或公开攻击举报人整体停止。

## 易混

对外口径不是调查报告摘要公开。发送前稿不是已生效。群已读不是已送达。内部口径不是必须公告。一套稿打天下禁止。说「个别员工」仍可能可识别。未核验不得写成已查清。无验收不得写已全面整改。交口径表不是从轻，也不是自首。民企套 42 号令第二十四条不是必须向国资委通报。公开点名可能二次暴露。红旗不是必须公告。内控有效不能洗白。证券法 2019 第七十八条／第八十条只约束境内信息披露义务人，港股不套证券法。个保法第二十五条不得公开个人信息。不写上市公司公告正文、不泄露举报人身份、不把未核验写成已查清是交付禁令，不是负触发。主成果是公告正文才转 `评估舆情与法定披露交叉`。口头「已经对外说了」「群已读」不是开闸材料。可编号受众或拟设口径句才开闸。本窗不出可发送 `N#`。本窗载荷是 `CM#`，不是 `N#`。合同通知只开接口，不审合同。不代发送。不选定媒体。不保证绝对不泄露。不得建议民企向国务院国资委通报。
