# 评估调查后处置路径

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。本窗是评估类路径草案，案例只比较事实差异，**不要**升格「已处置／必须刑事控告／必然开除／必然胜诉」。
- 法规用于核验移送、报告、民事请求权、劳动解除接口；实务用于发现先开除再补证据、红旗必须报案、先刑后民当然、对外披露污染追偿的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《民法通则》《民法总则》或其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下（公司或其调查受托律师，互斥；不允许被调查对象代理），形成调查后处置路径评估草案：处置闸、事实前提与强制接口、`Q#` 路径、`DP#` 处置路径行（路径类型／效果假设／成立条件／互斥／可逆性／下一步接口）。本窗 `DP#` 是路径行，不是调查认定 `F#`，不是解除决定，不是刑事控告状。路径比较不是已经选择并送达。分流不是已处置。打开路径不是已胜诉、已解除或已移送。有红旗不等于必须刑事控告。先刑后民不是当然。内部消化不是已合规。先开除再补证据不是合法。公司法第一百九十一条对外赔偿不得写成对内追偿必得。不写刑事控告或劳动解除文书。不定罪。不替代调查报告。不选定法院。不写胜诉率。不代提交。不保证免责。

`depends-on` 为空。调查报告终稿转 `形成内部调查报告`。民事追偿谈判转 `谈判民事追偿与返还方案`。民事起诉材料转 `准备民事追偿诉讼材料`。整改方案转 `准备合规整改方案`。测算转 `测算舞弊损失与追偿`。口径转 `准备对内通报与对外口径`。披露交叉转 `评估舆情与法定披露交叉`。劳动解除或处分文书转劳动领域。刑事控告、辩护或自首转刑事领域。

## 工作边界

正触发：调查事实已大致清楚或有等价事实判断，需要比较处置路径的互斥、停止项和下一步，而不是写报告或出处分、控告、起诉文书。事实未闭合、路径碎片仍正触发：有可编号拟设路径则处置闸打开或半开，第 6 节出 `DP#` 草案，缺项记 `G#`，每条未闭合路径标事实未闭合。无一拟设路径、又要求「今天必须出已处置终稿」才关闸，不出 `DP#` 终稿，窗口不关。用户要把有红旗写成必须刑事控告、把先刑后民写成当然、把先开除再补证据写成合法、把内部消化写成已合规、把路径比较写成已选择送达、把对外赔偿写成对内追偿必得，仍正触发：对应格填 `现有依据不支持`，窗口不关；闸已开仍出其他 `DP#` 草案。不得因「不写控告或解除文书」或「不定罪」改走负触发关窗。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是调查报告终稿（转 `形成内部调查报告`）；
- 主成果是民事追偿谈判方案（转 `谈判民事追偿与返还方案`）；
- 主成果是民事起诉材料（转 `准备民事追偿诉讼材料`）；
- 主成果是合规整改方案终稿（转 `准备合规整改方案`）；
- 主成果是劳动解除、处分决定或劳动争议程序文书（转劳动领域）；
- 主成果是刑事控告、辩护、自首或阅卷（转刑事领域）；
- 主成果是对内通报或对外口径正文（转 `准备对内通报与对外口径`）。

双方秘密、伪造或倒签证据、指导违法取证、指导隐匿、打击报复、阻挠合法检查**不在负触发表**，走整体停止。「有红旗必须刑事控告」「先刑后民当然」「先开除再补证据即合法」「内部消化即已合规」「路径比较即已选择送达」「对外赔偿即对内追偿必得」「交路径表即从轻」**不在负触发表**，该格 `现有依据不支持`，窗口不关。「不写刑事控告或劳动解除文书」「不定罪」「不替代调查报告」是交付禁令，不是负触发。

## 建立工作坐标

确认：单方公司立场；已有事实判断或等价报告、相对人、是否上市、是否国企、机关状态；法域；当前检查、诉讼、监察或刑事状态。

口头「内部消化就行」「必须先刑后民」「群已读」只登记 `S#`／`V#`。不得升格已处置、已选择或已送达，**不得单独算作开闸材料**。已读不得升格 `R#` 已送达。纸面路径草稿不是已选择。

同时掌握公司与被调查对象相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。公司已开口且委托就是路径比较、且未掌握对方秘密时，可推定公司或其调查受托律师立场。被调查对象代理不是本窗立场。无一拟设路径：处置闸关闭，仍交十节，不是整体停止。提出伪造证据、指导违法取证、打击报复或阻挠合法检查：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认（不是已处置，不是已选择）；`R#` 机关或生效文书；`C#` 内部制度或处分规则；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`DP#` 处置路径行；`V#` 版本；`E#` 证据形态回链（事实判断版本、相对人、机关状态，不是发送闸，不是已选择证明）。禁止 `N#`、`EV#`、`M#`、`F#`、`ACT#`、`P#`、`K#`、`O#`、`H#`、`B#`、`U#`、`X#`、`HD#`、`W#`、`T#`、`OR#`、`LV#`、`TR#`、`PX#`、`LD#`、`SP#`、`CH#`、`CS#`、`PT#`、`RF#`、`RT#`、`AU#`、`AZ#`、`PL#`、`LG#`、`IQ#`、`WP#`、`CG#`、`IV#`、`OT#`、`SA#`、`Dsc#`。技能正文中的条号是检索锚点，不是已核验 `L#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止合成「已处置闭环」。扫描不是闭集。未知金额不写零。稿件状态默认 `草案`。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：公司法（2023 修订）第一百八十八条董事、监事、高级管理人员对公司损失的赔偿责任，过错与损失待核，不是必得总额。第一百九十一条检索锚点：对外赔偿不得写成对内追偿必得。噪声：1993 年第一百九十一条清算组成立。第十一条法定代表人对外损害由公司承担后可向有过错法定代表人追偿，不是调查对象当然连带。劳动合同法第三十九条严重违纪解除只开接口，本窗不写解除决定；第四条民主程序只开接口。刑法构成只作红旗，不定罪，不写必须移送。证券法信息披露只约束信息披露义务人，内部路径不是必须公告。行政处罚法（2021 修订）第三十二条交材料不等于从轻。噪声：1996 年第三十二条陈述申辩。监察法（2024 修正）第十八条如实提供，不得伪造、隐匿、毁灭。噪声：已失效《合同法》、先刑后民当然、红旗必须刑事控告。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变对内追偿、劳动解除接口或移送边界的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补刑事报案宜作最后手段、立案后不受企业控制、和解后保留控告权的敲诈勒索红旗、先开除再补证据、对外披露影响追偿的反例。
- `search_case_by_fact`（recommended）只比较事实差异：民事返还可能被识别为劳动争议须仲裁前置；仅报案回执不足以证明已追究刑事责任；调查事实不足即解除可能构成违法解除。不写成必然结果。

工具不可用时继续路径分层和 `DP#` 编目；对内追偿、劳动解除、移送、施行日字段停止。不得拒跑，不得凭记忆写成必须刑事控告或先刑后民当然。

## 判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、处置闸与不关窗

主成果才整案转出。伪造证据、双方秘密第一次停。有红旗必须刑事控告、先开除再补证据不关窗。闸关仍交十节，第 6 节不出 `DP#` 终稿。

### 2. 事实前提与强制接口

无报告或等价事实：处置闸半开，每条路径标事实未闭合。国企／民企／上市分列。对内追偿与对外赔偿分列。

### 3. 处置闸与路径 `Q#`

本节禁止出 `DP#` 终稿。有可编号拟设路径：闸打开或半开。无一路径才关闸，窗口不关。

### 4. 处置路径行 `DP#`

内部控制、民事、劳动、监管、刑事／监察分列扫描，不是闭集。互斥可见。状态 `草案`。

### 5. 禁止文书与转介

不写控告状、解除通知、起诉状。一次只推荐下一步。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造或倒签证据、指导违法取证、指导隐匿、打击报复、阻挠合法检查。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一拟设路径：处置闸关闭，仍交十节，不是整体停止。
- `字段停止`：对内追偿过错与损失、劳动解除法定条件、移送标准、施行日未核验。有红旗必须刑事控告、先刑后民当然、先开除再补证据即合法、内部消化即已合规、路径比较即已选择送达、对外赔偿即对内追偿必得：该格 `现有依据不支持`，窗口不关；闸已开仍出其他 `DP#` 草案。
- `目标停止`：主目标变为报告终稿、解除文书、刑事控告、起诉材料、整改终稿。

禁止指导伪造证据、违法取证或打击报复。不给胜诉率。不定罪。不保证免责。不选定机关。不代提交。未知不写零。不写解除决定。不把红旗写成必须刑事控告。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。处置闸关闭仍交十节，第 6 节不出 `DP#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `DP#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。处置闸未打开时不得交付「已处置」或「已选择」。边界见 [路由](references/routing.md)。
