# 边界与路由

## 正触发

调查事实已大致清楚或有等价事实判断，需要比较处置路径的互斥、停止项和下一步，而不是写报告或出处分、控告、起诉、披露发送稿。事实未闭合、授权未核验仍正触发：有可编号事实判断或等价报告片段则闸开或半开，出 `DP#` 草案。有红旗必须刑事控告、先刑后民当然、先开除再补证据即合法、内部消化即可免责、交表即从轻／即自首、民企套 42 号令必须移交，仍正触发。

双方秘密、伪造路径依据、指导隐匿、干扰办案、指导先开除再补假证据、打击报复、阻挠合法检查的停止，优先于负触发。上述信号不在下表。「有红旗必须刑事控告」「先刑后民当然」「先开除再补证据即合法」「内部消化即可免责」「路径比较即已选择送达」「交路径表即从轻／即自首」「民企套 42 号令必须移交」「对外赔偿即对内追偿必得」不在下表。「不写刑事控告或劳动解除文书」「不定罪」「不替代调查报告」是交付禁令，不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 调查报告终稿 | `形成内部调查报告` |
| 民事追偿谈判方案 | `谈判民事追偿与返还方案` |
| 民事起诉材料 | `准备民事追偿诉讼材料` |
| 合规整改方案终稿 | `准备合规整改方案` |
| 测算终稿 | `测算舞弊损失与追偿` |
| 证据案卷 | `建立内部调查证据案卷` |
| 主动披露或自查发送稿 | `准备主动披露或自查报告` |
| 对内通报或对外口径发送稿 | `准备对内通报与对外口径` |
| 董事会汇报且不含路径比较 | `准备董事会合规汇报材料` |
| 检察合规验收包 | `准备涉案企业合规整改与验收` |
| 劳动解除、处分决定或劳动争议程序文书 | 劳动领域 |
| 刑事控告、辩护、自首或阅卷 | 刑事领域 |
| 交易合同改稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不写控告或解除文书」或「不定罪」关窗。红旗必须控告、先开除再补证据、民企套 42 号令该格不支持，窗口不关，不转出。出现「刑事」「劳动」一词不是转出。主成果才转。民企硬套不得负触发到对照窗。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、解除、工伤、职场性骚扰主轴且路径比较不是主成果 | 劳动领域 |
| 税务处理决定、稽查实体 | 税务领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |
| 垄断、滥用支配、经营者集中 | 竞争法领域 |

综合内部调查后处置比较主轴可留本任务。检查或已立案只作背景，主成果才转。已刑事立案且主成果是刑事程序：整案转刑事。已刑事立案但主成果仍是企业路径比较：留窗；指导干扰办案整体停止。

## 易混

路径比较不是已经选择并送达。分流不是已处置。打开接口不是已胜诉、已解除或已移送。有红旗不等于必须刑事控告。先刑后民不是当然。民责不因刑责免除。内部消化不是免责。先开除再补证据不是合法。交路径表不是从轻，也不是自首。民企套 42 号令第二十二条不是必须向国务院国资委移交。公司法第一百九十一条对外赔偿不是对内追偿必得。第一百八十八条对公司损失不是必得总额。劳动争议可能仲裁前置，民事返还不当然直接起诉。仅报案回执不是已追究刑事责任。口头「已经查清」「够立案了」不是开闸材料。拟设路径草稿不是开闸材料。可编号事实判断才开闸。不写控告或解除文书、不定罪是交付禁令，不是负触发。
