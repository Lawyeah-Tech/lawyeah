# 边界与路由

## 正触发

调查事实已大致清楚或有等价事实判断，需要比较处置路径的互斥、停止项和下一步，而不是写报告或出处分、控告、起诉文书。从零、事实未闭合、路径碎片仍正触发：有拟设路径则闸开或半开，出 `DP#` 草案。有红旗必须刑事控告、先刑后民当然、先开除再补证据即合法，仍正触发。

双方秘密、伪造证据、指导违法取证、打击报复、阻挠合法检查的停止，优先于负触发。上述信号不在下表。「有红旗必须刑事控告」「先刑后民当然」「先开除再补证据即合法」「内部消化即已合规」「路径比较即已选择送达」「对外赔偿即对内追偿必得」不在下表。「不写刑事控告或劳动解除文书」「不定罪」「不替代调查报告」是交付禁令，不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 调查报告终稿 | `形成内部调查报告` |
| 民事追偿谈判方案 | `谈判民事追偿与返还方案` |
| 民事起诉材料 | `准备民事追偿诉讼材料` |
| 合规整改方案终稿 | `准备合规整改方案` |
| 劳动解除、处分决定或劳动争议程序文书 | 劳动领域 |
| 刑事控告、辩护、自首或阅卷 | 刑事领域 |
| 对内通报或对外口径正文 | `准备对内通报与对外口径` |
| 交易合同改稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不写控告或解除文书」或「不定罪」关窗。红旗必须控告、先开除再补证据该格不支持，窗口不关。出现「刑事」「劳动」一词不是转出。主成果才转。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、解除、工伤、职场性骚扰主轴 | 劳动领域 |
| 税务处理决定、稽查实体 | 税务领域 |

综合内部调查后处置比较主轴可留本任务。检查或已立案只作背景，主成果才转。已刑事立案且主成果是刑事程序：整案转刑事。已刑事立案但主成果仍是企业路径比较：留窗；干扰办案该格不支持。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 调查认定终稿 | `形成内部调查报告` |
| 民事返还谈判 | `谈判民事追偿与返还方案` |
| 起诉状与证据目录 | `准备民事追偿诉讼材料` |
| 整改方案 | `准备合规整改方案` |
| 损失测算 | `测算舞弊损失与追偿` |
| 口径或披露交叉 | `准备对内通报与对外口径`／`评估舆情与法定披露交叉` |
| 解除或处分文书 | 劳动领域 |
| 控告或辩护 | 刑事领域 |

## 易混

路径比较不是已经选择并送达。分流不是已处置。打开路径不是已胜诉、已解除或已移送。有红旗不等于必须刑事控告。先刑后民不是当然。内部消化不是已合规。先开除再补证据不是合法。公司法第一百九十一条对外赔偿不是对内追偿必得。第一百八十八条对公司损失不是必得总额。劳动争议可能仲裁前置，民事返还不当然直接起诉。仅报案回执不是已追究刑事责任。不写控告或解除文书、不定罪是交付禁令，不是负触发。
