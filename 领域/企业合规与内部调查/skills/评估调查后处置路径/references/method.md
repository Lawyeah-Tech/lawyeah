# 评估方法

本文件是可执行判断节点。路径比较不是已经选择并送达。分流不是已处置。打开路径不是已胜诉、已解除或已移送。有红旗不等于必须刑事控告。先刑后民不是当然。内部消化不是已合规。先开除再补证据不是合法。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、必然开除、刑事既遂、唯一必得追偿总额、选定法院、代提交、未知写零。本任务不写控告状、解除通知或起诉状，不定罪，不代提交。本窗 `DP#` 是路径行，不是调查认定 `F#`，不是测算 `M#`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1993 年公司法第一百九十一条（清算组）、1996 年行政处罚法第三十二条（陈述申辩）、把红旗写成必须刑事控告或把第一百九十一条写成对内追偿必得时记为噪声。禁止指导伪造证据、违法取证或打击报复。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`DP#` 固定列：`编号｜路径类型｜效果假设｜成立条件｜支持事实｜不利事实｜互斥／并行｜可逆性｜下一步接口｜E#回链｜判断三值｜缺口G#｜最强反方｜待核`。禁止合成「已处置闭环」。无法判断则该条待核，**不得默认保留必须刑事控告或先开除再补证据**。`E#` 只作证据形态回链。缺项记 `G#`。扫描不是闭集。五条路径类型是方法参考，不是闭集。

口头「内部消化就行」「必须先刑后民」「群已读」只进 `S#`／`V#`，**不得单独算作开闸材料**。已读不得升格 `R#` 已送达。纸面草稿不是已选择。`A#` 是承认，不是已处置。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上刑事报案宜作最后手段；一旦立案，案件不受企业控制；和解后仍保留刑事控告权有敲诈勒索红旗。民事返还可能被识别为劳动争议而须仲裁前置。仅报案回执不足以证明已被追究刑事责任。调查事实不足即解除可能构成违法解除。

## 节点 0　分流、立场、处置闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。伪造证据、指导违法取证、打击报复、阻挠合法检查、双方秘密不进负表。

整案转出只交付第 1、2、10 节，不出 `DP#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是调查报告终稿 | 负触发 `形成内部调查报告` |
| 主成果是民事追偿谈判 | 负触发 `谈判民事追偿与返还方案` |
| 主成果是民事起诉材料 | 负触发 `准备民事追偿诉讼材料` |
| 主成果是整改方案终稿 | 负触发 `准备合规整改方案` |
| 主成果是劳动解除或处分文书 | 整案转劳动 |
| 主成果是刑事控告、辩护或自首 | 整案转刑事 |
| 主成果是通报或口径正文 | 负触发 `准备对内通报与对外口径` |

审查起诉、监管检查、已刑事立案只作程序背景。主成果才整案转。出现「刑事」「劳动」「解除」一词不是转出。已刑事立案：企业路径不得以干扰办案为目的。

处置闸打开（可出 `DP#` 草案，仍不得标「已处置／已选择／已移送」）须同时满足：单方无冲突公司立场已闭合；主成果是路径比较，不是报告、解除文书或控告；至少一条可编号拟设路径。从零：有拟设路径即可开或半开，缺项记 `G#`。无报告或等价事实：半开，每条路径标事实未闭合。口头内部消化、已读不算单独开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

处置闸部分打开：事实未闭合、对内追偿或劳动解除条件未核验，但已有可编号拟设路径；对应格待核；仍交十节；不得标终稿 `已形成`。

处置闸关闭（仍正触发）：无一可编号拟设路径。「今天必须出已处置终稿」而无最小事实不得开闸。不出 `DP#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `DP#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「有红旗必须刑事控告」「先刑后民当然」「先开除再补证据即合法」「内部消化即已合规」「路径比较即已选择送达」「对外赔偿即对内追偿必得」「交路径表即从轻」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `DP#` 草案。必须刑事控告、先开除再补证据行**不得写入可执行 `DP#`**。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无一拟设路径，then 处置闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造或倒签证据、指导违法取证、指导隐匿、打击报复、阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　事实前提与强制接口

无调查报告或等价事实判断：处置闸半开，每条 `DP#` 标事实未闭合，不得写成已可处置。用户主成果是直接出刑事控告：负触发刑事或目标停止，不在本窗写控告状。

检索锚点（写入 `L#` 前须核验）：

- 公司法（2023 修订）第一百八十八条：对公司损失须过错与损失待核，不是必得。
- 公司法第一百九十一条：对外赔偿不得写成对内追偿必得。噪声：1993 年第一百九十一条清算组。
- 公司法第十一条：法定代表人对外损害由公司承担后可向有过错法定代表人追偿，不是调查对象当然连带。
- 劳动合同法第三十九条：严重违纪解除只开接口，本窗不写解除决定。
- 刑法构成只作红旗，不定罪，不写必须移送。
- 证券法信息披露只约束义务人，内部路径不是必须公告。
- 行政处罚法（2021 修订）第三十二条：交材料不等于从轻。噪声：1996 年第三十二条。
- 监察法（2024 修正）第十八条：不得伪造、隐匿、毁灭。

国企／民企／上市分列。强制接口与非强制对标分列。

## 节点 3　处置路径行 `DP#`

按已出现路径扫描，不是默认闭集。建议行型（出现才用，**不是闭集**）：

| 编号 | 含义 | 本窗允许 | 禁止 |
| --- | --- | --- | --- |
| `DP-内` | 内部控制补强 | 接口；可逆性 | 写成已合规 |
| `DP-民` | 民事返还／赔偿 | 条件与互斥 | 必得总额；选定法院 |
| `DP-劳` | 劳动程序 | 只开接口 | 解除决定；先开除再补证据 |
| `DP-监` | 监管沟通或披露 | 红旗与互斥 | 必须公告；发送版口径 |
| `DP-刑` | 刑事／监察移送 | 红旗；最后手段 | 定罪；必须控告 |

热冲突强制处理：

- 有红旗必须刑事控告 → 该格不支持；仍出其他 `DP#`。
- 先开除再补证据 → 劳动路径不支持。
- 对外披露可能影响追偿谈判 → 互斥必须可见。
- 劳动解除可能影响证人配合 → 互斥必须可见。
- 民事和解弃权可能影响后续 → 互斥必须可见。
- 刑事已启动而以干扰办案为目的的企业路径 → 该格不支持；指导阻挠则整体停止。
- 对外赔偿写成对内追偿必得 → 该格不支持。

事实不足以支持某路径：该条 `依据不足，无法形成结论`，不关窗。无 `E#` 不得写已覆盖、已选择或已移送。状态 `草案`。一次只推荐下一步，不打包全部文书。

## 节点 4　禁止文书、可逆性与转介

不写控告状、解除通知、起诉状、发送版披露。不可逆（对外报案、送达解除、签署概括弃权、对外披露）不得在草案阶段实施。禁止提交指令。不代提交。

民事谈判转 `谈判民事追偿与返还方案`。起诉转 `准备民事追偿诉讼材料`。整改转 `准备合规整改方案`。测算转 `测算舞弊损失与追偿`。口径转 `准备对内通报与对外口径`。刑事转刑事。劳动转劳动。报告转 `形成内部调查报告`。

已有检查或刑事 `R#`：不得借路径稿干扰办案。刑法只作红旗，不得指导隐匿。

## 本任务回链纪律

本任务成果是「处置闸与路径比较草案」。本窗不执行发送。不包含：已处置证明、已选择送达、调查报告终稿、解除决定、刑事控告、起诉状、整改终稿。禁止选边治愈。禁止红旗必须刑事控告。禁止先刑后民当然。禁止先开除再补证据。禁止对外赔偿即对内追偿必得。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：用户要求「有回扣红旗就必须刑事控告，先把人开除再补证据，先刑后民。」处置闸打开。`Q-红`、`Q-开`、`Q-先刑` 不打开为可靠路径。第 6 节不得把必须控告或先开除写入可执行 `DP#`；对应格 `现有依据不支持`；仍可出民事／内控草案。不关窗。不写解除决定或控告状。

场景②：用户主成果是「把调查报告终稿和解除通知一起写出来。」负触发 `形成内部调查报告` 或劳动领域（以主成果为准），一句路由，不填本窗实体十节。
