# 评估方法

本文件是可执行判断节点。路径比较不是已经选择并送达。分流不是已处置。打开接口不是已选定、已送达、已移送、已解除或已胜诉。有红旗不等于必须刑事控告。先刑后民不是当然。民责不因刑责免除。内部消化不是免责。先开除再补证据不是合法。交路径表不是从轻，也不是自首。民企套 42 号令不是必须移交。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、必然开除、刑事既遂、唯一必得追偿总额、选定法院、代提交、未知写零。本任务不写控告状、解除通知或起诉状，不定罪，不代提交。本窗 `DP#` 是路径比较行，不是调查认定 `F#`，不是测算行 `BM#`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1993 年公司法第一百七十七条公积金或第一百九十一条清算组、1996 年行政处罚法第三十二条陈述申辩、把民法典第一百八十七条写成「先刑后民所以不能追偿」、把 42 号令第二十二条套民企必须向国资委移交、把红旗写成必须刑事控告时记为噪声。禁止指导伪造证据、隐匿、干扰办案或打击报复。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`DP#` 固定列：`编号｜材料简述｜路径类型｜效果假设｜成立条件｜支持事实｜不利事实｜互斥／并行｜可逆性｜三态｜下一步接口｜E#回链｜判断三值｜G#｜最强反方`。三态只用 `打开接口`／`不打开`／`待核`。禁止合成「已处置闭环」。无法判断则该条待核，**不得默认保留必须刑事控告或先开除再补证据**。`E#` 只作证据形态回链。缺项记 `G#`。扫描不是闭集。五条路径类型是方法参考，不是闭集，不是默认全开。

口头「已经查清」「够立案了」「内部消化就行」「必须先刑后民」「群已读」只进 `S#`／`V#`，**不得单独算作开闸材料**。已读不得升格 `R#` 已送达或已立案。截图不等于已保全。内部谈话不等于庭审自认。报告草案不等于已认定。纸面草稿不是已选择。`A#` 是承认，不是已处置。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上刑事报案宜作最后手段；一旦立案，案件不受企业控制；和解后仍保留刑事控告权有敲诈勒索红旗。民事返还可能被识别为劳动争议而须仲裁前置。仅报案回执不足以证明已被追究刑事责任。调查事实不足即解除可能构成违法解除。

## 节点 0　分流、立场、处置闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。伪造路径依据、指导隐匿、干扰办案、指导先开除再补假证据、打击报复、阻挠合法检查、双方秘密不进负表。

整案转出只交付第 1、2、10 节，不出 `DP#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是调查报告终稿 | 负触发 `形成内部调查报告` |
| 主成果是民事追偿谈判 | 负触发 `谈判民事追偿与返还方案` |
| 主成果是民事起诉材料 | 负触发 `准备民事追偿诉讼材料` |
| 主成果是整改方案终稿 | 负触发 `准备合规整改方案` |
| 主成果是测算终稿 | 负触发 `测算舞弊损失与追偿` |
| 主成果是证据案卷 | 负触发 `建立内部调查证据案卷` |
| 主成果是主动披露发送稿 | 负触发 `准备主动披露或自查报告` |
| 主成果是通报或口径发送稿 | 负触发 `准备对内通报与对外口径` |
| 主成果是董事会汇报且不含路径比较 | 负触发 `准备董事会合规汇报材料` |
| 主成果是检察合规验收包 | 负触发 `准备涉案企业合规整改与验收` |
| 主成果是劳动解除或处分文书 | 整案转劳动 |
| 主成果是刑事控告、辩护或自首 | 整案转刑事 |
| 「不写控告或解除文书」「不定罪」 | 交付禁令，不是负触发 |

审查起诉、监管检查、已刑事立案只作程序背景。主成果才整案转。出现「刑事」「劳动」「解除」一词不是转出。已刑事立案：企业路径不得以干扰办案为目的。

处置闸打开（可出 `DP#` 草案，仍不得标「已处置／已选定／已送达／已移送」）须同时满足：单方无冲突公司立场已闭合；主成果是路径比较，不是报告、解除文书、控告或披露发送稿；至少一条可编号事实判断或等价报告片段。口头「已经查清」「够立案了」、拟设路径草稿、群已读不算单独开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

处置闸部分打开：已有可编号事实判断或等价报告片段，但授权、相对人、是否国企或上市、机关状态、金额未闭合；或无书面评估授权但已有件；对应格待核；仍交十节；不得标终稿 `已形成`。

处置闸关闭（仍正触发）：无一可编号事实判断且无一等价报告片段。「今天必须出已选定路径终稿」而无最小事实不得开闸。不出 `DP#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `DP#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关写成「没有路径」或「内部消化即可」。

「有红旗必须刑事控告」「先刑后民当然」「先开除再补证据即合法」「内部消化即可免责」「路径比较即已选择送达」「交路径表即从轻／即自首」「民企必须按 42 号令向国资委移交」「对外赔偿即对内追偿必得」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `DP#` 草案。上述行**不得写入可执行 `DP#`**。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无一可编号事实判断且无一等价报告片段，then 处置闸关闭，仍交十节，不是整体停止。
若 if 单方立场已闭合、无书面评估授权但已有可编号事实判断或等价报告片段，then 处置闸部分打开，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造或倒签证据、伪造路径依据、指导隐匿或选择性不报、指导先开除再补假证据、借企业路径干扰已启动侦查、打击报复、阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体、事实前提与强制接口

一行一个主体或事实前提。缺项记 `G#`，不得把未知金额或时点写成 `0`。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 主体属性 | 中央企业／地方国企／参股／民企；是否上市；是否国家出资公司 | 把参股或民企写成必须按 42 号令向国资委报告 |
| 事实判断来源 | 可编号 `I#` 或等价报告片段及其 `E#` | 把口头「已经查清」「够立案了」升格为开闸材料或 `R#` 已立案 |
| 相对人 | 可识别对象；是否在职；是否证人 | 把处分对象写成当然解除对象 |
| 机关状态 | 检查／监察／刑事 `R#` 有无 | 把报案回执写成已追究刑事责任 |
| 金额／时点 | 可核验则写；未知写 `未知`／`G#` | 写零填满 |

检索锚点（写入 `L#` 前须核验）：

- 民法典第一百八十七条：民责不因刑责／行责免除；财产不足时优先承担民责。禁止写成「先刑后民所以不能追偿」。
- 法释〔1998〕7 号第一条：不同法律事实分别涉及经济纠纷和经济犯罪嫌疑的，应当分开审理。可分则可并行，不是一律中止。同一法律关系是否驳回／移送＝待核。
- 公司法第一百六十八条：国家出资公司不含参股。第一百七十七条仅约束国家出资公司对内合规，不得套民企必须移交国资委。
- 42 号令第二条只约束中央企业。第二十二条第一款向本企业合规管理部门报告；第三款才是中央企业重大合规风险事件向国资委报告。第二十三条整改 ≠ 已选定路径。第二十四条不得打击报复。第四十条是对地方国资机构的参照指导。
- 行政处罚法（2021）第三十二条：交路径表不等于从轻情节成就。噪声：1996 年第三十二条。
- 刑法第六十七条：交路径表 ≠ 自首已成立；企业合规材料 ≠ 自首。
- 刑法第一百六十二条之一、第三百零七条、第三百零八条只作红旗，不得指导删除。
- 监察法第十八条第一款如实提供；第二款是机关保密，不是企业免交／免报。
- 劳动合同法第三十九条／第四十条／第四十一条／第四十四条只开接口。「先开除再补证据」不得写成合法路径。
- 劳动法第一百零一条不是全部内部廉洁举报的一般义务。
- 反不正当竞争法（2025）第八条：明示折扣佣金入账不是贿赂；施行日 2025-10-15。
- 公司法第一百八十八条／第一百九十一条：对公司损失不是必得；对外赔偿不是对内追偿必得。不得用 188／191 顶替 187 与 168／177。
- 证券法信息披露只约束义务人。民诉证据保全／先予执行不是本窗。

国企／民企／上市分列。强制接口与非强制对标分列。本节禁止出 `DP#` 终稿。

## 节点 3　处置路径行 `DP#`

按已出现路径扫描，不是默认闭集。建议行型（出现才用，**不是闭集**）：

| 编号 | 含义 | 本窗允许 | 禁止 |
| --- | --- | --- | --- |
| `DP-内` | 内部控制补强／内部问责 | 接口；可逆性 | 写成已合规 |
| `DP-民` | 民事返还／赔偿 | 条件与互斥 | 必得总额；选定法院；先刑所以不能追偿 |
| `DP-劳` | 劳动程序 | 只开接口 | 解除决定；先开除再补证据 |
| `DP-监` | 监管沟通、披露或整改 | 红旗与互斥 | 必须公告；发送版口径；民企必须报国资委 |
| `DP-刑` | 刑事／监察移送 | 红旗；最后手段 | 定罪；必须控告；交表即自首 |

热冲突强制处理：

- 有红旗必须刑事控告 → 该格不支持；仍出其他 `DP#`。
- 先刑后民当然／一律中止 → 该格不支持；民事／劳动／监管窗不因此关闭。
- 先开除再补证据 → 劳动路径该格不支持；一旦要求补**假**证据，整体停止。
- 内部消化即可免责 → 该格不支持。
- 交表即从轻／即自首 → 该格不支持。
- 民企套 42 号令必须移交 → 该格不支持，不得建议上报国资委。
- 对外披露可能影响追偿谈判 → 互斥必须可见；未写清范围则并行格待核或不打开。
- 劳动解除可能影响证人配合 → 互斥必须可见。
- 民事和解弃权可能封后续请求 → 概括弃权不可逆，草案阶段不得实施。
- 刑事已启动而以干扰办案为目的的企业路径 → 指导干扰＝整体停止；仅错误主张「内部消化别报」＝该格不支持。
- 对外赔偿写成对内追偿必得 → 该格不支持。

事实不足以支持某路径：该条 `依据不足，无法形成结论`，不关窗。无 `E#` 不得写已覆盖、已选择或已移送。状态 `草案`。一次只推荐下一步，不打包全部文书。可并行必须逐条写条件，禁止五条路径默认全开。

## 节点 4　禁止文书、可逆性与转介

第 7 节只开接口，不得夹带 `DP#` 终稿绕闸。闸关闭时第 7 节可写「闸未开，转介待事实判断编号」，不得补写已选定路径。

不写控告状、解除通知、起诉状、发送版披露、公告正文、保全／先予执行申请。不可逆（对外报案、送达解除、签署概括弃权、对外披露、向国资委／监管正式报告）不得在草案阶段实施。禁止提交指令。不代提交。不选定机关或截止日。

民事谈判转 `谈判民事追偿与返还方案`。起诉转 `准备民事追偿诉讼材料`。整改转 `准备合规整改方案`。测算转 `测算舞弊损失与追偿`。口径转 `准备对内通报与对外口径`。披露发送稿转 `准备主动披露或自查报告`。刑事转刑事。劳动转劳动。报告转 `形成内部调查报告`。回避转 `处理利益冲突与调查回避`。

已有检查或刑事 `R#`：不得借路径稿干扰办案。刑法第一百六十二条之一只作红旗，不得指导隐匿。

若 if 用户催促「按零写／填满已选定终稿」，then 该格 `现有依据不支持`，窗口不关。
若 if 时点、人数、金额未知，then 写 `未知`／`G#`，禁止写 `0`。
