# 评估方法

本文件是可执行判断节点。本任务忠实勤勉不是必得追偿，口头知情不是已履职。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、刑事既遂、唯一截止日、选定机关、代提交、任免决定、未知写零。本任务不定罪，不写股东会决议。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》《民法总则》、1993 年公司法第一百八十条公益金、1993 年第一百九十一条清算、把 42 号令套全部民企、把口头知情写成已履职时记为噪声。禁止指导伪造纪要或删除会计资料。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`H#` 固定列：`编号｜角色（董／监／高／实控）｜事项｜职责来源｜应上会｜实际上会｜记录／回避｜判断三值｜最强反方｜待核｜转介`。禁止合成「董监高都有责任」一笔。禁止 `N#`／`E#`／`EV#`／`M#`／`F#`／`ACT#`／`P#`／`K#`／`O#`。

口头「董事都知道」、新闻稿只进 `S#`／`V#`，不得升格已履职。事后补做纪要标 `V#` 冲突，不覆盖原始记录。拟制日＝本次形成本任务成果之日。

履职闸打开（可出 `H#` 草案，仍不得标「已履职／必得追偿／已免责」，仍不代提交）须同时满足：单方无冲突立场与评估授权；主成果是履职缺口，不是章程任免、义务地图、汇报提纲或回避终稿；至少一项可编号任职文件、会议材料或问责文书；无双方秘密、无第一次伪造纪要／回避信号。

履职闸部分打开：主体或规则未闭合，但已有可编号任职或会议材料；对应格待核；仍交十节；不得标终稿 `已形成`。

履职闸关闭（仍正触发）：无评估授权；无一任职且无一会议痕迹。「今天必须出问责结论」而无最小事实不得开闸。不出 `H#` 终稿。**仍交十节**，第 5 节只交闸／`Q#` 状态，第 6 节不出 `H#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「已经履职」或「没有缺口」。

「保证合规免责」「第一百八十条必得追偿」「第一百八十八条已成立必赔」「第一百九十一条对内追偿当然依据」「民企必须按 177 或 42 号令追究董事会」「口头知情或新闻稿＝已履职」「董监高都有责任一笔」「交了缺口表即应当从轻」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸未开仍不出 `H#` 终稿。

若 if 立场或授权无法闭合，then 整体停止。
若 if 同时掌握公司与被调查董事／高管相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造纪要、倒签会议、伪造回避、指导删除会计资料、借已有监察文书平行灭证或打击报复，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体、机关与职责来源

名称、统一社会信用代码、并表范围不一致：不自动合并。任职文件与实际签字身份冲突：两行并列，不选对用户有利的一版。项目总工、办公室主任等职务未经核验不得升格董监高。

检索锚点（写入 `L#` 前须核验）：

- 公司法（2023 修订）第一百八十条：董监高对公司负忠实义务、勤勉义务；控股股东、实际控制人实际执行公司事务的适用前两款。只开追偿接口，不是必得公式。
- 第一百八十八条：执行职务违反法律、行政法规或章程给**公司**造成损失的赔偿。须过错与损失待核，不得写成已成立必赔。
- 第一百九十一条：执行职务给**他人**造成损害的，公司应当承担赔偿责任；董事、高级管理人员故意或重大过失的，也应当承担赔偿责任。对外赔偿接口，不得写成对内追偿当然依据。噪声：1993 年第一百九十一条清算。
- 第一百七十九条：董监高应当遵守法律、行政法规和章程。
- 第一百六十八条：国家出资公司不含参股。第一百七十七条仅约束国家出资公司对内合规。
- 中央企业合规管理办法第八条董事会、第九条经理层、第十四条合规管理部门：只约束中央企业。第四十条地方国资参照，不是民企对国务院国资委义务。

民营企业：42 号令第八条／第九条不得写成法定义务被违反。中央企业：对照行可建，条号运行时核验。监事会／审计委员会监督职责与经理层执行职责分列。

## 节点 3　履职行 `H#`

每项重大合规事项建一行，角色分列。三态必须分开：应上会／实际上会／记录完整。缺通知、缺回避、缺表决：该次 `依据不足，无法形成结论`，不得用新闻稿或口头转述补成已履职。

事后补做的纪要登记 `V#` 冲突，不覆盖原始记录。倒签会议日期：整体停止，不是版本冲突。

董事或高管是被调查对象或业务赞助人：该行履职结论字段停止，转介 `处理利益冲突与调查回避`，本窗不出回避终稿。

红旗只标待核场景，不得写成某次商业贿赂或单位犯罪已成立。用户要本表认定违规：目标停止，转介 `评估是否启动内部调查`。

刑法第一百六十二条之一只作红旗，**不得指导删除**。已有监察或检查文书，不得借补履职痕迹平行灭证。
