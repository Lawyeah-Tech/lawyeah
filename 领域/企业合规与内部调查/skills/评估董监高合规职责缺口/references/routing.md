# 边界与路由

## 正触发

治理层或公司需要判断合规职责是否留痕、是否存在冲突或待补动作。任职不齐、纪要缺失、规则未核验仍正触发：履职闸关闭，不出 `H#` 终稿，窗口不关。保证免责、第一百八十条必得追偿、第一百九十一条对内追偿、民企套 177 或 42 号令、口头知情＝已履职，仍正触发。

双方秘密、伪造纪要、倒签会议、伪造回避、指导删除会计资料、打击报复的停止，优先于负触发。上述信号不在下表。「保证免责」「必得追偿」「民企套 177 或 42 号令」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 章程、股东会、股权方案、任免决定 | 公司治理领域 |
| 义务—主体地图 | `建立合规义务与责任主体地图` |
| 董事会汇报提纲 | `准备董事会合规汇报材料` |
| 三道防线岗位配置 | `配置合规机构与三道防线` |
| 调查回避终稿 | `处理利益冲突与调查回避` |
| 42 号令差距对照终稿 | `评估国企合规管理办法差距` |
| 企业级风险总图 | `评估企业合规风险总图` |
| 已有体系是否运转 | `评估合规管理体系有效性` |
| 从零设计体系框架 | `设计合规管理体系框架` |
| 单件线索或违规认定 | `评估是否启动内部调查` |
| 刑事辩护、控告 | 刑事领域 |
| 劳动处分决定 | 劳动领域 |
| 未进入合规机制的合同改稿 | 审查起草领域（本窗搁置，只说明） |

不得因「要求写成已履职」或「要求必得追偿」关窗。纪要缺失仍正触发，不得写成已履职。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、解除、工伤主轴 | 劳动领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |
| 垄断、滥用支配、经营者集中 | 竞争法领域 |
| 税务稽查实体 | 税务领域 |
| 章程、股权、公司决议、任免本身为主成果 | 公司治理领域 |

治理层合规履职主轴可留本任务。审查起诉或检查只作背景，主成果才转。

## 易混

董事会问「我们合不合规」若要的是企业总图，走 `评估企业合规风险总图`。本任务只评治理层职责痕迹。口头知情不是已履职。事后补纪要不是原始记录。项目总工不是当然董监高。民企套 42 号令第八条：该格不支持，不关窗。第一百九十一条是对外赔偿，不是对内追偿。「先倒签纪要再评估」整体停止。
