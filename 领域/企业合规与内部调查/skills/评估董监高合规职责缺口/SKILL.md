# 评估董监高合规职责缺口

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例检索。本窗是评估类履职缺口，**不要**用文书范本检索生成「已履职／必得追偿」清单。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现履职痕迹不足、身份错配和追偿条件；案例只比较事实差异与翻转条件，不写成必然结果。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《民法通则》《民法总则》或其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成董监高合规职责缺口草案：履职闸、出资属性与机关、`Q#` 路径、`H#` 履职痕迹（应上会／实际上会／记录／回避）、问责与追偿接口、待补动作。董事、监事、高级管理人员分列。忠实勤勉不是必得追偿。口头知情不是已履职。不写任免决定或股东会决议，不保证合规免责，不代提交。

`depends-on` 为空。义务—主体全表转 `建立合规义务与责任主体地图`。董事会汇报提纲转 `准备董事会合规汇报材料`。三道防线配置转 `配置合规机构与三道防线`。回避终稿转 `处理利益冲突与调查回避`。42 号令主体差距转 `评估国企合规管理办法差距`。总图转 `评估企业合规风险总图`。有效性判断转 `评估合规管理体系有效性`。从零设计框架转 `设计合规管理体系框架`。章程、股东会、股权、任免转公司治理领域。

## 工作边界

正触发：公司或单一治理层需要判断合规职责是否留痕、是否存在冲突或待补动作，而不是改章程、出股权方案或写任免。任职文件不齐、纪要缺失、规则未核验仍正触发：履职闸关闭，不出 `H#` 终稿，窗口不关。用户要保证合规免责、按公司法第一百八十条必得追偿、把第一百九十一条写成对内追偿当然依据、民企按第一百七十七条或 42 号令董事会违法、口头知情或新闻稿写成已履职、今天必须出问责结论，仍正触发：对应格填 `现有依据不支持` 或字段停止，闸未开则不出履职终稿，窗口不关。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是章程、股东会、股权方案或任免决定（转公司治理领域）；
- 主成果是义务—主体地图（转 `建立合规义务与责任主体地图`）；
- 主成果是董事会汇报提纲（转 `准备董事会合规汇报材料`）；
- 主成果是三道防线岗位配置（转 `配置合规机构与三道防线`）；
- 主成果是调查回避终稿（转 `处理利益冲突与调查回避`）；
- 主成果是 42 号令差距对照终稿（转 `评估国企合规管理办法差距`）；
- 主成果是企业级风险总图（转 `评估企业合规风险总图`）；
- 主成果是体系是否运转（转 `评估合规管理体系有效性`）；
- 主成果是从零设计体系框架（转 `设计合规管理体系框架`）；
- 主成果是单件线索或违规认定（转 `评估是否启动内部调查`）。

双方秘密、伪造纪要、倒签会议、伪造回避记录、指导删除会计资料、打击报复**不在负触发表**，走整体停止。「保证免责」「第一百八十条必得追偿」「第一百九十一条对内追偿」「民企套 177 或 42 号令」「口头知情＝已履职」**不在负触发表**，只关对应格，窗口不关。

## 建立工作坐标

确认：履职评估授权；单方立场（公司／被评估董事或高管，互斥）；被评估主体（集团／境内实体／是否国家出资公司或中央企业）；机关设置与任职文件；会议通知、议案、纪要、回避与表决记录；已知问责或监管关注。

口头「董事都知道」「新闻稿写了重视合规」只登记 `S#`／`V#`。不得升格已履职、已免责或必得追偿。

同时掌握公司与被调查董事／高管相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。公司已开口且委托就是履职缺口、且未掌握对方秘密时，可推定公司立场。提出伪造纪要、倒签会议、伪造回避、指导删除会计资料或打击报复：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 章程或内部办法；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`H#` 履职行；`V#` 版本。禁止 `N#`、`E#`、`EV#`、`M#`、`F#`、`ACT#`、`P#`、`K#`、`O#`（`O#` 是义务地图）。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止合成「董监高都有责任」一笔。未知不写零。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：公司法（2023 修订）第一百八十条忠实、勤勉；控股股东、实际控制人实际执行公司事务的适用前两款。第一百八十条是追偿**接口**，不是必得公式。第一百八十八条：执行职务违反法律、行政法规或章程给**公司**造成损失的赔偿，须运行时核验过错与损失，不得写成已成立必赔。第一百九十一条：董事、高级管理人员执行职务给**他人**造成损害的，公司应当承担赔偿责任；董事、高级管理人员存在故意或者重大过失的，也应当承担赔偿责任。这是对外赔偿接口，不得写成对内追偿当然依据。噪声：1993 年第一百八十条公益金、第一百九十一条清算。第一百六十八条国家出资公司不含参股；第一百七十七条仅约束国家出资公司对内合规，不得倒推民企董事会违法。中央企业合规管理办法第八条董事会职责、第九条经理层职责、第十四条合规管理部门职责只约束中央企业；第四十条是地方国资参照指导。行政处罚法第三十二条条件成立时应当从轻或减轻，提交履职缺口表本身不等于情节成就。噪声：已失效《合同法》《民法总则》、42 号令套民企、口头知情即已履职、新闻稿补成已履职、180 必得追偿、191 对内追偿。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变忠实勤勉效果、对外／对内赔偿分列或 42 号令主体的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补口头知情不等于已履职、身份未证成不得当董监高、追偿须过错与损失的反例。
- `search_case_by_fact` 只比较事实差异与翻转条件（如项目总工签字≠公司董监高；挂名职务≠实际授权），不写成必然已履职、必然免责或必得追偿。

工具不可用时继续任职、会议和 `H#` 编目；主体义务、追偿、期限字段停止。不得拒跑，不得凭记忆写成民企董事会必须适用 42 号令、口头知情即已履职或必得追偿。

## 判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、履职闸与不关窗

主成果才整案转出。伪造纪要第一次停。保证免责、必得追偿、民企套 177 或 42 号令不关窗。闸关仍交十节，第 6 节不出 `H#` 终稿。董、监、高分列。

### 2. 主体、机关与职责来源

集团／境内实体／国家出资公司／中央企业分列。法定、章程、授权、内部办法分列。民企不得写成与中央企业同一法定义务被违反。

### 3. 履职闸与路径 `Q#`

本节禁止出 `H#` 终稿。无一任职且无一会议痕迹则闸可关，窗口不关。

### 4. 履职行 `H#`

应上会／实际上会／记录完整分列。缺通知、缺回避、缺表决：该次 `依据不足`。事后补纪要标版本冲突，不覆盖原始记录。

### 5. 冲突、追偿接口与待补

董事或高管是被调查对象：履职结论字段停止，转介回避原子。第一百八十／一百八十八／一百九十一条只开接口。不写任免，不写答辩状。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；提出伪造纪要、倒签会议、伪造回避、指导删除会计资料、借已有监察文书平行灭证或打击报复。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：42 号令主体、追偿条件、任职身份、送达未核验。保证免责、第一百八十条必得追偿、第一百九十一条对内追偿、民企套 177 或 42 号令、口头知情＝已履职：该格停止，窗口不关；闸未开仍不出 `H#` 终稿。
- `目标停止`：主目标变为章程任免、义务地图、汇报提纲、回避终稿或违规认定。

禁止指导伪造纪要或删除会计资料。不给胜诉率。不定罪。不保证免责。不选定机关。不写任免决定。不代提交。未知不写零。
