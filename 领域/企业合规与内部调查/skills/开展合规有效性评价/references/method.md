# 评估方法

本文件是可执行判断节点。纸面不是有效。自选样本不是独立。隐瞒样本外红旗不得写成总体有效。补强建议不是已完成整改。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、访谈填满、唯一截止日、选定机关、代提交、未知写零。本任务不是审计意见，不是调查结论，不重写全部制度。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、2018 年《中央企业合规管理指引（试行）》评估条款当现行 42 号令、把第二十七条或第一百七十七条套民企、把纸面写成已有效时记为噪声。禁止指导伪造样本或删除会计资料。转出写中文技能名，禁止英文 slug。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`SP#` 固定列：`编号｜指标（可证伪定义／通过标准）｜总体与抽样框｜抽选权（独立／被评价人／待核）｜样本与E#｜测试结果｜缺陷等级（重大／重要／一般／依据不足）｜判断三值｜缺口G#｜最强反方｜补强接口（非已完成）｜待核`。禁止合成「总体有效」一笔。`E#` 只作证据形态回链。缺项记 `G#`，不得用访谈印象或「领导重视」填满。扫描不是闭集。

口头「体系很全」「年年都评」「领导重视」只进 `S#`／`V#`，**不得算作开闸材料**。被评价人自备全优包不得开闸。`A#` 是承认，不是已有效。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

## 节点 0　分流、立场、评价闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。伪造样本、抽掉不利样本、假分级、故意不纳入已知红旗、指导删除、平行灭证、打击报复、双方秘密不进负表。

整案转出只交付第 1、2、10 节，不出 `SP#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是五维快评不要抽样 | 负触发 `评估合规管理体系有效性` |
| 主成果是财务或内控审计意见 | 审计职责，不在本包 |
| 主成果是数据专项评估整案 | 整案转数据隐私 |
| 主成果是整改是否闭合 | 负触发 `跟踪整改验收与复发监测` |
| 主成果是整改动作表终稿 | 负触发 `准备合规整改方案` |
| 主成果是单件调查或调查报告 | 负触发 `评估是否启动内部调查`／`形成内部调查报告` |
| 主成果是 42 号令对照终稿 | 负触发 `评估国企合规管理办法差距` |
| 主成果是董事会汇报提纲 | 负触发 `准备董事会合规汇报材料` |
| 主成果是从零设计或重写全部制度 | 负触发框架或办法窗 |
| 侦查、起诉、辩护为主成果 | 整案转刑事 |

审查起诉、监管检查只作程序背景。主成果才整案转。出现「评价」一词不是转出。

评价闸打开（可出 `SP#` 草案，仍不得标「已有效／独立评价已完成／已免责」）须同时满足：单方无冲突公司立场已闭合；主成果是可证伪指标＋抽样＋缺陷分级，不是五维快评、不是审计意见；存在书面评价授权；期间／总体／抽样框至少一项可编号。口头完备、自选全优包不算开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

评价闸部分打开：授权与框已有，但主体、周期或独立性未闭合；对应格待核；仍交十节；不得标终稿 `已形成`。

评价闸关闭（仍正触发）：公司立场已闭合但无书面评价授权；无一抽样框且无一指标行。「今天必须出已有效终稿」而无最小事实不得开闸。不出 `SP#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `SP#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「没有缺陷」或「已有效」。

「评价即免责」「纸面即有效」「自选样本即独立」「民企必须按第二十七条评价达标上报」「访谈或领导重视填满抽样缺口」「零举报即无风险」「补强即已完成整改」「隐瞒样本外红旗仍总体有效」**不关窗**。对应格 `现有依据不支持` 或结论字段停止。闸已开仍出其他 `SP#` 草案。闸未开才不出 `SP#` 终稿。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无书面评价授权，then 评价闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被评价或被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造样本、抽掉不利样本、假缺陷分级、故意不纳入已知红旗、伪造运行记录、指导删除会计资料、借评价稿平行灭证、打击报复或阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。
若 if 已知样本外红旗未纳入且未要求隐匿，then 评价结论字段停止，不得标终稿已形成，窗口不关。

## 节点 1　主体与强制接口

名称、规模、是否中央企业／国家出资公司／上市分列。不自动合并。

检索锚点（写入 `L#` 前须核验）：

- 42 号令第二条、第八条（三）、第十四条（三）、第二十七条、第四十条：只约束中央企业。第八条（三）／第十四条（三）／第二十七条是有效性评价与定期评价，不是第二十三条整改。第四十条是对地方国资机构的参照指导，不是民企或地方国企对国务院国资委的评价义务。民企硬套：该格 `现有依据不支持`，强制对照行删除，不关窗。不得建议民企上报国务院国资委。
- 公司法第一百六十八条：国家出资公司不含参股。第一百七十七条仅国家出资公司对内合规，不得倒推民企必须开展本评价。
- 行政处罚法第三十二条：提交评价报告不等于情节成就。
- 2018 年《中央企业合规管理指引（试行）》评估条款当现行 42 号令＝噪声。

国企适用办法条款才写入强制项。强制接口与非强制对标分列，不选对用户有利的一版。

## 节点 3　指标×样本×缺陷行 `SP#`

先固定期间、总体、抽样框、排除规则。样本由被评价部门自行挑选且无复核：独立性 `现有依据不支持`，结论字段停止。

每个指标必须可证伪：定义、抽样方法、通过标准。禁止「文化良好」「领导重视」这类不可证伪指标。可用：例外批准留痕率、举报回执及时性、高风险付款抽查入账完整、整改验收证据存在性。规则未核验的法定义务指标字段停止。抽不到样本：该指标 `依据不足`，不得用访谈印象填满。未知件数不写零。

缺陷分级仅服务本窗：重大＝机制系统性失效或隐瞒监管；重要＝关键控制不可运行；一般＝文档或偶发。分级不是处罚、不是调查定性、不是整改已验证。已知样本外红旗未纳入：评价结论字段停止，不得标终稿 `已形成`。

## 节点 4　补强、可逆性与转介

补强建议须对应缺陷编号和验收点，状态只能是建议／待实施。用户要求把建议写成「已完成」：目标停止，转 `跟踪整改验收与复发监测`；若要动作表终稿，转 `准备合规整改方案`。

可逆动作与不可逆动作分列。不可逆（对外宣称已有效、以评价代审计或代调查、代提交）不得在草案阶段实施。禁止提交指令。不代提交。

下一步只转介：五维快评、整改跟踪、整改方案、42 号令对照、董事会汇报、调查。禁止一次写完全部邻窗终稿。禁止出 `K#` 五维终稿。

已有监察或检查 `R#`：不得借评价稿平行灭证。刑法第一百六十二条之一只作红旗，不得指导删除。

## 本任务回链纪律

本任务成果是「评价闸与指标×抽样×缺陷草案」。不包含：五维快评终稿、审计意见、已有效证明、免责结论、整改已完成、调查认定、42 号令对照终稿。禁止伪造样本。禁止选边治愈。禁止纸面即有效。禁止评价即免责。禁止民企套第二十七条。禁止访谈填满抽样缺口。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标评价终稿已形成。
