# 边界与路由

## 正触发

需要一次可抽样、可分级的正式有效性评价项目，而不是五维快评或财务审计。抽样框未齐、独立性未核验仍正触发：评价闸关闭则不出 `SP#` 终稿，窗口不关。评价即免责、纸面即有效、自选样本即独立、民企套第 27 条、访谈填满缺口、隐瞒红旗仍总体有效，仍正触发。

双方秘密、伪造样本、抽掉不利样本、假分级、故意不纳入已知红旗、指导删除、平行灭证、打击报复的停止，优先于负触发。上述信号不在下表。「评价即免责」「体系完备」「自选样本即独立」「民企套 42 号令」「访谈填满」不在下表。「不替代财务审计」「不重写全部制度」「不替代单件调查」是交付禁令，不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 五维快评不要抽样 | `评估合规管理体系有效性` |
| 财务或内控审计意见 | 审计职责，不在本包 |
| 数据专项评估整案 | 数据隐私领域 |
| 跟踪整改是否闭合 | `跟踪整改验收与复发监测` |
| 整改动作表终稿 | `准备合规整改方案` |
| 单件调查启动或调查报告 | `评估是否启动内部调查`／`形成内部调查报告` |
| 42 号令对照终稿 | `评估国企合规管理办法差距` |
| 董事会汇报提纲 | `准备董事会合规汇报材料` |
| 从零设计或重写全部制度 | `设计合规管理体系框架`／`起草合规管理办法或章程级制度` |
| 刑事辩护、控告 | 刑事领域 |

不得因「保证免责」或「要求按第 27 条写死」或「自选样本视为独立」关窗。无书面授权仍正触发，不得写成已有效。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、解除、工伤主轴 | 劳动领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |
| 垄断、滥用支配、经营者集中 | 竞争法领域 |
| 章程、股权、任免本身为主成果 | 公司治理领域 |
| 银行保险机构行业合规办法主轴 | 金融领域 |
| 药品购销回扣行业细则主轴 | 医疗医药领域 |
| 税务处理决定、稽查实体 | 税务领域 |
| 出口管制、制裁名单 | 涉外领域 |

综合合规正式评价主轴可留本任务。审查起诉或检查只作背景，主成果才转。出现「评价」一词不是整案转出。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 只要五维差距不要抽样 | `评估合规管理体系有效性` |
| 补强写成已完成或要验收闭合 | `跟踪整改验收与复发监测` |
| 要整改动作表终稿 | `准备合规整改方案` |
| 确为中央企业且主成果是 42 号令对照 | `评估国企合规管理办法差距` |
| 上会提纲 | `准备董事会合规汇报材料` |
| 单件线索 | `评估是否启动内部调查` |
| 财务或内控审计意见 | 审计职责，不在本包 |

## 易混

有效性评价不是审计报告，也不是调查结论。抽样缺口不能用访谈印象填满。纸面不是有效。自选样本不是独立。隐瞒样本外红旗不得写成总体有效。补强建议不是已完成整改。评价条款不是第 23 条整改。民企套 42 号令第二十七条或第一百七十七条：该格不支持，不关窗。提交评价报告不是从轻已成就。「先抽掉不利样本再出绿色结论」整体停止。五维快评不在本窗。
