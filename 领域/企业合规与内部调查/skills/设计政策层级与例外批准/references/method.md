# 评估方法

本文件是可执行判断节点。口头指示不得高于书面。无留痕例外不是已批准。例外批准不是即合法。政策层级不是合同效力判断。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、例外即合法、范本填满、唯一截止日、选定机关、代提交、未知写零。本任务不写劳动规章全文，不审查单份交易合同，不定罪。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1993 公司法第六十七条、1993 反法第八条、把 42 号令或第一百七十七条套民企、把口头写成已批准、把 FCPA 写成中国法义务时记为噪声。MCP 将 2025 修订反法标为尚未施行但公布施行日为 2025-10-15 的，以施行日为准；无法独立核验施行日则该规则字段停止。禁止指导伪造批准或删除会计资料。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`LV#` 固定列：`编号｜行类（层级／冲突／例外）｜文本或路径｜上位—下位／适用对象｜禁止项是否被下位扩大｜例外最低集｜E#回链｜判断三值｜缺口G#｜最强反方｜待核`。禁止合成「例外已合法闭环」一笔。`E#` 只作证据形态回链。缺项记 `G#`，不得用「参照最佳实践」或范本栏目填满。扫描不是闭集。

口头「领导点头就算批了」「群已读就是已公布」「先做后补」只进 `S#`／`V#`，**不得算作开闸材料**。已读、揽收不得升格 `R#`。无版本、无生效日不得排进可执行层级。`A#` 是承认，不是已批准。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

## 节点 0　分流、立场、层级闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。伪造批准、倒签例外、假废止清单、指导删除、平行灭证、打击报复、阻挠合法检查、双方秘密不进负表。

整案转出只交付第 1、2、10 节，不出 `LV#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是只要框架不要层级方案 | 负触发 `设计合规管理体系框架` |
| 主成果是章程级办法正文 | 负触发 `起草合规管理办法或章程级制度` |
| 主成果是三道防线岗位配置终稿 | 负触发 `配置合规机构与三道防线` |
| 主成果是单笔礼品是否允许 | 负触发 `审查礼品招待赞助与捐赠` |
| 主成果是反贿赂与礼品招待制度全文 | 负触发 `设计反商业贿赂与礼品招待制度` |
| 主成果是劳动规章或员工手册纪律全文 | 整案转劳动 |
| 主成果是交易合同审查或改稿 | 审查起草本窗搁置 |
| 主成果是公司章程、股东会、股权或任免本身 | 整案转公司治理 |
| 主成果是 42 号令对照终稿 | 负触发 `评估国企合规管理办法差距` |
| 侦查、起诉、辩护为主成果 | 整案转刑事 |

审查起诉、监管检查只作程序背景。主成果才整案转。

层级闸打开（可出 `LV#` 草案，仍不得标「已生效／已批准／例外即合法／冲突已闭合」）须同时满足：单方无冲突公司立场已闭合；主成果是效力层级、冲突规则、例外审批与留痕，不是办法正文、框架图、岗位或单笔礼品；存在书面设计授权；至少一项可编号现行政策或拟设层级行。口头同意、先做后补、无版本无生效日文本不算开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

层级闸部分打开：主体或上位规则未核验，但已有书面授权与可编号范围；对应格待核；仍交十节；不得标终稿 `已形成`。

层级闸关闭（仍正触发）：公司立场已闭合但无书面设计授权；无一现行文本且无一拟设行。「今天必须出已批准例外」而无最小事实不得开闸。不出 `LV#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `LV#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「没有冲突」或「例外已合法」。

「例外批准即合法或小额即合法」「口头同意或先做后补即已批准」「下位扩大上位禁止之例外」「两份打架只留有利版本」「民企必须按 177 或 42 号令达标上报」「把 FCPA 写成中国法义务」「把范本当法定层级」「提交层级方案即应当从轻」「总部印发即对子公司生效」「未废止仍称以新规为准」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `LV#` 草案。闸未开才不出 `LV#` 终稿。开口径无留痕：该行删除或该例外字段停止。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无书面设计授权，then 层级闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造批准或废止清单、倒签例外、指导删除会计资料、借层级稿平行灭证、打击报复或阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

名称、规模、是否中央企业／国家出资公司／上市分列。不自动合并。独立法人子公司不与母公司自动合并。

检索锚点（写入 `L#` 前须核验）：

- 公司法第六十七条：董事会制定基本管理制度，不等于层级方案已生效或例外已合法。
- 公司法第一百六十八条：国家出资公司不含参股。第一百七十七条仅国家出资公司对内合规，不套民企。
- 公司法第三条：独立法人财产。总部政策不能直接在独立法人子公司生效，只开接口到 `落地集团政策到境内实体`。实务中「分支服从总部否则无效」不得写成独立法人已生效。
- 42 号令第八条、第九条、第十八条、第四十条：只约束中央企业。基本制度由董事会审议、经理层拟订，具体制度或专项指南按重点领域制定。民企硬套：该格 `现有依据不支持`，强制对照行删除，不关窗。不得建议民企上报国务院国资委。
- 反法 2025 第八条：明示折扣佣金如实入账不是贿赂（施行日 2025-10-15）。不得把口头礼品例外写成「入账即合法」。账外暗中不得写成合法。
- 不得把美国《反海外腐败法》或萨班斯内控条款写成中国法定义务；可作非强制对标并标明法域。
- 行政处罚法第三十二条：提交层级方案不等于情节成就。

国企适用办法条款才写入强制项。强制接口与非强制对标分列，不选对用户有利的一版。

## 节点 3　层级／冲突／例外行 `LV#`

先登记已出现的现行政策及版本号。无版本、无生效日：该文本不得排在可执行层级，记 `G#`。默认候选层级按已出现文本扫描，不是闭集：章程或出资人规定、合规基本制度、专项政策、操作指引、邮件或口头。口头不得高于书面。下位不得扩大上位的禁止范围之例外。

每件已知冲突建行：哪两条、适用对象、若适用 A 与适用 B 的效果、最强反方。无法判断则升级有权机关。两份现行政策打架且用户要求只保留有利版本：**冲突节字段停止**，两行并列，不选边。

例外必须同时具备：书面申请、利益冲突回避、审批人高于申请人、金额或场景阈值、有效期、公开或登记、事后抽样。缺一项：该例外路径 `现有依据不支持`。「领导口头同意」「先做后补」不得写成已批准。开口径无留痕：**该行删除或该例外字段停止**。

劳动纪律、工时、解除只留「转劳动制度」接口，本窗不做完劳动合同法第四条民主程序。交易合同只留接口要点。单笔礼品只开接口到礼品审查窗。

## 节点 4　废止、可逆性与转介

新层级生效必须附旧规废止或条款失效表。用户拒绝废止又要求「以新规为准」：冲突未闭合，冲突节字段停止。已读、揽收、群转发不得打开已公布生效路径。

可逆动作与不可逆动作分列。不可逆（对外披露、处分、对员工公布发生劳动纪律效力、发送废止通知）不得在草案阶段实施。禁止提交指令。不代公布、不代废止。

下一步只转介：框架、办法、三道防线、礼品审查、反贿赂制度、集团落地、义务地图。禁止一次写完全部邻窗终稿。

已有监察或检查 `R#`：不得借层级稿平行灭证。刑法第一百六十二条之一只作红旗，不得指导删除。

## 本任务回链纪律

本任务成果是「层级闸与效力／冲突／例外草案」。不包含：办法全文、框架模块终稿、三道岗位终稿、单笔礼品允许表、劳动规章全文、交易合同效力、已批准证明、例外即合法证明。禁止伪造批准。禁止选边治愈。禁止口头即已批准。禁止例外即合法。禁止民企套 42 号令。禁止 FCPA 当中国法。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标层级终稿已形成。
