# 边界与路由

## 正触发

内部政策相互冲突或例外批准没有留痕，需要可执行的层级和例外机制，而不是写办法全文、评单笔礼品或改合同。政策碎片、批准机关未核验仍正触发：层级闸关闭则不出 `LV#` 终稿，窗口不关。例外即合法、口头即已批准、只留有利版本、民企套 177 或 42 号令、FCPA 当中国法、范本即法定层级，仍正触发。

双方秘密、伪造批准、倒签例外、假废止清单、指导删除、平行灭证、打击报复、阻挠合法检查的停止，优先于负触发。上述信号不在下表。「例外即合法」「口头即已批准」「先做后补」「只留有利版本」「民企套 42 号令」「FCPA 当中国法」不在下表。「不审查单份合同」「不写劳动规章全文」「不保证例外即合法」是交付禁令，不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要框架不要层级方案 | `设计合规管理体系框架` |
| 章程级办法正文 | `起草合规管理办法或章程级制度` |
| 三道防线岗位配置终稿 | `配置合规机构与三道防线` |
| 单笔礼品招待赞助捐赠是否允许 | `审查礼品招待赞助与捐赠` |
| 反贿赂与礼品招待制度全文 | `设计反商业贿赂与礼品招待制度` |
| 劳动规章或员工手册纪律全文 | 劳动领域 |
| 交易合同审查或改稿 | 审查起草领域（本窗搁置，只说明） |
| 公司章程、股东会、股权或任免本身 | 公司治理领域 |
| 42 号令对照终稿 | `评估国企合规管理办法差距` |
| 刑事辩护、控告 | 刑事领域 |

不得因「保证例外即合法」或「要求按 42 号令写死」或「口头视为已批准」关窗。无书面授权仍正触发，不得写成已批准。

## 易混

政策层级不是合同效力判断。例外批准不是「小额即合法」，也不是「例外即合法」。口头指示不得高于书面。无留痕例外不是已批准。先做后补不是已批准。下位不得扩大上位禁止之例外。两份打架只留有利版本不是冲突已闭合。民企套 42 号令或第一百七十七条：该格不支持，不关窗。FCPA 对标不是中国法义务。总部印发不能直接在独立法人子公司生效。「先补假批准再出已批准稿」整体停止。劳动规章全文和交易合同不在本窗。
