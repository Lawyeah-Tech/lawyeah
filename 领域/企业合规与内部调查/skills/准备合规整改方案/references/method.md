# 评估方法

本文件是可执行判断节点。本任务不把计划写成已完成，不替代检察合规验收，不作处分决定。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。动作状态只用 `计划`、`进行中`、`已验证`、`停止`。无验收证据不得写 `已验证`。禁止胜诉率、必然免责、唯一截止日、选定机关、代提交、未知写零。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》《民法通则》、1996 年行政处罚法第三十二条陈述申辩、或把 42 号令第二十三条写成全部民企法定义务时记为噪声。MCP 将 2025 修订《反不正当竞争法》标为尚未施行但公布施行日为 2025-10-15 的，以施行日为准并记录冲突。

`RC#` 固定列：`编号｜层（制度／执行／监督／激励）｜失效描述｜支持事实｜不利／未排除｜判断｜待核｜转介`。禁止只写员工品德。
`ACT#` 固定列：`编号｜对应 RC#｜动作｜责任人｜时点类型｜验收证据形态｜状态词｜外部承诺对照｜判断｜待核`。禁止用 `A#` 当动作。
`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持｜不利｜互斥／转介｜状态｜待核`。

口头「已经改完了」、已读、快递发出只进 `S#`／`V#`，不得升格已验证、机关已验收或已获从轻。拟制日＝本次形成本任务成果之日。验收日、落款不得早于本次形成日。

## 节点 0　分流、立场、整改闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。虚假完成、双方秘密不进负表。

整案转出只交付第 1、2、10 节，不出 `ACT#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是调查报告 | 负触发 `形成内部调查报告` |
| 主成果是单件根因与控制补强 | 负触发 `准备根因分析与控制补强` |
| 主成果是检察合规第三方评估或验收 | 负触发 `准备涉案企业合规整改与验收` |
| 主成果是跟踪已列动作的验收与复发 | 负触发 `跟踪整改验收与复发监测` |
| 主成果是现场检查应对 | 负触发 `应对监管检查或突击检查` |
| 主成果是主动披露或自查 | 负触发 `准备主动披露或自查报告` |
| 主成果是解除或处分决定正文 | 整案转劳动 |
| 主成果是刑事辩护、自首或保证不起诉 | 整案转刑事 |
| 数据专项体系主轴 | 整案转数据隐私 |
| 垄断／经营者集中主轴 | 整案转竞争法 |
| 税务稽查实体 | 整案转税务 |

整改闸打开（可出 `ACT#` 草案，仍不得标「已全面整改」，仍不代提交）须同时满足：单方无冲突立场与整改授权；主成果是普通内部或监管后动作表，不是检察验收、处分、报告、披露；至少一项可编号根因或动作缺口；无双方秘密、无第一次虚假完成／倒签／指导删除信号。

整改闸部分打开：授权或根因未完全闭合，但已有可编号制度缺口或责令改正文书；对应格待核；仍交十节；不得标终稿 `已形成`。

整改闸关闭（仍正触发）：无整改授权；无一可回链根因且无一可编号动作；「今天必须交验收」而无最小事实不得开闸。不出动作终稿。**仍交十节**，第 5 节只交闸／`Q#` 状态，第 6 节不出可外传 `ACT#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「已经改完」或「没有漏洞」。

「保证已全面整改」「今天必须交验收」「整改即免罚或应当从轻」「民企必须按 177 或 42 号令第二十二条／第二十三条向国资委交整改」「选定某局」「把尚未实施催写成已完成」（尚未坚持造假入表）**不关窗**。对应格 `现有依据不支持` 或字段停止。闸未开仍不出动作终稿。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 出具虚假完成证明、把尚未实施坚持写入已验证、倒签验收日、指导删除或隐匿会计资料冒充整改、妨害作证、打击报复，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　根因 `RC#`

至少打开四层，未知不删行、不写零：

| 编号 | 层 | 打开信号 | 禁止 |
| --- | --- | --- | --- |
| `RC-制` | 制度 | 无制度、冲突、过期、例外口子过大 | 用员工品德代替制度缺口 |
| `RC-执` | 执行 | 有制度不执行、授权越级、记录缺失 | 把未核实执行写成已合规 |
| `RC-监` | 监督 | 举报／审计／合规二道防线失效 | 把未设监督写成「已闭环」 |
| `RC-激` | 激励 | 考核、提成与廉洁冲突 | 把入账折扣当贿赂激励缺口 |

明示入账折扣、佣金（检索锚点：反法 2025 第八条）不得打开「贿赂必须整改」根因。账外暗中才打开廉洁根因，并转介 `评估反商业贿赂风险点`。单件事件只要控制失效解剖、不要整包动作表：负触发 `准备根因分析与控制补强`。

## 节点 3　动作 `ACT#`

闸未开不得出可外传动作终稿。每个动作必须能被第三人核验。状态词强制：`计划`／`进行中`／`已验证`。无验收证据（截图、制度发布记录、培训签到且范围可回链等）不得写 `已验证`。当场改正截图不等于危害后果已消除，也不得单独写成整包已完成。

时点必须点名类型：`内部计划时点`（标明非法定）／`责令改正期限`（须 `R#`，送达未核验则停止）／`承诺时点`（对照对外文本）。禁止输出唯一法定截止日。已向机关承诺的时点：动作完成日不得早于承诺所依据的事实日，不得把未实施写成已赶在承诺日前完成。

---

## 节点 4　接口、外部承诺与复发

劳动处分、数据改造、竞争承诺、刑事退缴只开接口，本窗不写专项终稿。复发监测点只列接口，主成果是跟踪则转 `跟踪整改验收与复发监测`。

外部承诺对照表：承诺文本、作出日、送达／到达待核、对应 `ACT#`、现状。快递发出、已读不得写成机关已验收。

---

## 再执行清单

每个节点结束后回写：来源、判断、最强反方、是否字段停止。不得跳过整改闸直接给已全面整改。

若 if 责令改正依据或从宽规则未核验，then 效果字段停止，不写已获从轻。
若 if 已有监察／公安 `R#`，then 不得借整改完成删除、隐匿或选择性不改。

## 本任务回链纪律

本任务成果是「整改闸、根因与可验收动作草案」。不包含：检察验收包、调查报告、处分决定、披露发送稿、已全面整改证明。禁止把计划写成已完成。禁止倒签。禁止选边治愈。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标动作终稿已形成。
风险档 A：虚假完成、倒签、删除账册冒充整改必须单独标可逆性；提出即整体停止。
