# 准备合规整改方案方法

本文件是可执行判断节点。整改方案不是已完成。交整改不是已免罚。计划不是已落地。42 号令不是民企上报义务。口头「已经改完了」不是已验证。责令改正不是内部计划已履行。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已全面整改、已获从轻、选定机关、代提交、未知写零。本任务不定罪，不保证免罚，不替代检察验收包。本窗闸名只能是整改闸，禁止复用验收闸、监测闸、根因闸、评估闸、报告闸、启动闸。预留不得占用：立案闸、调查闸、检查闸。本窗 `ZG#` 是整改行。`RC#` 只作根因辅行。主路径只用 `Q-整改`，禁止用 `Q-改`、`Q-风`、`Q-启`、`Q-认定`、`Q-总` 作主路径。英文 id 禁止使用，一律用中文技能名 `准备合规整改方案`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1996／2017 年行政处罚法第三十二条陈述申辩、2021 年第二十七条行刑衔接当从宽、1993 年公司法第一百七十七条公积金、已失效合规指引、把 42 号令第二十三条套民企时记为噪声。禁止指导虚假完成、隐瞒未改或删除会计资料冒充整改。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。
`ZG#` 固定列：`编号｜动作切片｜责任人与时点｜验收证据形态｜完成状态｜打开接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。完成状态只用 `计划`、`进行中`、`已验证`、`停止`。无 `E#` 不得写已验证。承认只进 `S#`／`D#`，不得占用 `A#`。`RC#` 固定列：`编号｜层（制度／执行／监督／激励）｜失效点｜禁止只写品德｜打开接口｜G#｜状态`。
主路径只用 `Q-整改`。禁止 `A#`、`N#`、`ACT#`、`F#` 作主行。

口头「已经改完了」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。验收日不得倒签。稿件状态默认 `草案`。四层根因禁止只写员工品德。入账折扣不得当贿赂根因。

实务上：责令改正看实质履行，不是看有没有交计划。检察考察材料是办案参考，不是应当不起诉。42 号令第三十七条是国资委对央企约谈责成整改，不是行政处罚责令，不是民企义务。

## 节点 0　分流、立场、整改闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、虚假完成、隐瞒未改、倒签、指导删账不进负表。利益冲突未解不进整体停止。不定罪、不保证免罚、不代提交不是负触发。禁止把验收闸、检查闸、报告闸、启动闸写进本窗节点 0。

整案转出只交付第 1、2、10 节，不出 `ZG#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是调查报告终稿 | 负触发 `形成内部调查报告` |
| 主成果是单件根因、不要整包动作表 | 负触发 `准备根因分析与控制补强` |
| 主成果是检察合规验收包，或夹带过验收／保证不起诉 | 负触发 `准备涉案企业合规整改与验收` |
| 主成果是跟踪已列动作 | 负触发 `跟踪整改验收与复发监测` |
| 主成果是检查现场应对 | 负触发 `应对监管检查或突击检查` |
| 主成果是主动披露发送稿 | 负触发 `准备主动披露或自查报告` |
| 主成果是是否启动内部调查 | 负触发 `评估是否启动内部调查` |
| 主成果是解除或处分决定正文 | 整案转劳动 |
| 主成果是刑事辩护、自首或不起诉保证 | 整案转刑事 |
| 尚未进入合规机制，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 「不定罪」「不保证免罚」「不代提交」 | 交付禁令，不是负触发 |

出现「整改」一词不是转出。检察考察期要的也是动作表：主成果含过验收／不起诉则负触发验收窗，本窗不得出验收包或保证不起诉。

整改闸打开（可出 `ZG#` 草案，仍不得标「已全面整改／已验证终稿」）须同时满足：单方无冲突公司或合规负责人立场已闭合；主成果是普通内部动作表，不是验收包、不是报告、不是检查现场；至少一项可编号根因或动作缺口。口头「已经改完了」不算单独开闸材料。

整改闸部分打开：已有碎片，但责令、从宽或主体未闭合；对应格待核；仍交十节。无书面整改授权但单方立场已闭合且已有碎片：整改闸部分打开，仍交十节，不是整体停止。

整改闸关闭（仍正触发）：无一可编号碎片。「今天必须交已全面整改终稿」而无最小碎片不得开闸。不出 `ZG#` 终稿。**仍交十节**，第 5 节只交闸／`Q-整改`，第 6 节不出 `ZG#` 终稿，**第 7 节不得出已全面整改或验收包**。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「已经改完」或「没有未改项」。

「保证已全面整改」「今天必须交验收」「把尚未实施写成已完成」「整改即免罚」「民企套 177 或 42 号令 22／23 条」「选定某局」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `ZG#` 草案。主体不适用则对照行填不支持，**不得删除该行**。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 整改闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，或两造争同一份整改稿，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出虚假完成证明、隐瞒未改项、倒签验收日、指导删除或隐匿会计资料冒充整改，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　根因辅行 `RC#`

一行一层。禁止只写员工品德。入账折扣不得当贿赂根因。本节禁止出 `ZG#` 终稿。

检索锚点（写入 `L#` 前须核验）：42 号令第二条、第二十二条、第二十三条、第三十七条、第四十条。公司法第一百六十八条、第一百七十七条。行政处罚法第二十八条、第三十二条五项、第三十三条三层。反不正当竞争法 2025 第八条。刑法第六十七条、第一百六十二条之一。噪声：1996／2017 年第三十二条陈述申辩、已失效合规指引。

## 节点 3　整改行 `ZG#`

按已出现动作或缺口扫描，不是默认闭集。每条须能指向动作切片、责任人或验收形态之一。

无 `E#` 不得写已验证。状态默认 `草案`。一次只推荐下一步。未知不写零。已向机关承诺只对照原文，不得擅自缩短事实或夸大完成。无 `R#` 不得写机关名称。不得把「优化流程」写成清理不利分录或重做账套。

热冲突强制处理：

- 保证已全面整改／今天必须交验收／尚未实施写成已完成／整改即免罚／民企套 23 条／选定某局 → 该格不支持或字段停止；仍出其他 `ZG#`。
- 无一碎片 → 关闸，不出 `ZG#` 终稿，窗口不关。
- 虚假完成、隐瞒未改、倒签、指导删账 → 整体停止。

## 节点 4　检查、验收、跟踪与披露接口

第 7 节只开接口，不得夹带 `ZG#` 终稿或已全面整改绕闸。闸关闭时第 7 节可写「闸未开，转介待动作编号」，不得补写已完成。不选定机关。不代提交。不定罪。不保证免罚。人员仍在场不得把现场配合写成已整改。复制本窗四层表贴到检察计划不打开。

下一步只转介：`形成内部调查报告`、`准备根因分析与控制补强`、`准备涉案企业合规整改与验收`、`跟踪整改验收与复发监测`、`应对监管检查或突击检查`、`准备主动披露或自查报告`、`评估调查后处置路径`、`评估国企合规管理办法差距`、`评估反商业贿赂风险点`、`评估合规管理体系有效性`、`开展合规有效性评价`、`评估企业合规风险总图`、`设置合规监管人或独立监察`、`准备向监管提交材料与特权日志`、`测算舞弊损失与追偿`、`建立内部调查证据案卷`、`评估账簿记录与虚假报销`、`准备董事会合规汇报材料`。禁止此致某局。禁止转介本窗完成虚假完成。

若 if 用户催促「已经改完／交了就能免罚／民企也必须报国资委／今天必须过验收／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「整改闸与整改行草案」。本窗不执行发送。不包含：调查认定终稿、检察验收包、已全面整改证明、已获从轻。禁止选边治愈。禁止计划即完成。禁止交方案即免罚。禁止民企套 23 条。整改闸打开 ≠ 已全面整改 ≠ 已免罚 ≠ 责令已履行。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标动作终稿已形成。
风险档 A：虚假完成、隐瞒未改、倒签、指导删账必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：检查后要出内部动作表。用户主张已经全面整改、交了应当从轻、民企也必须按 42 号令第二十三条报国资委、今天必须交验收、此致某局。整改闸打开或半开。`Q-签`、`Q-宽`、`Q-套` 不打开为可靠路径。第 6 节不得把已全面整改、已从轻、必须上报、选定机关写入可执行 `ZG#`；对应格 `现有依据不支持` 或字段停止；仍出制度／执行／监督／激励缺口与计划态动作等其他 `ZG#`。不关窗。不定罪。不保证免罚。

场景②：用户同时交出公司「必须写成已全部完成」与被调查部门「有三项还没做」口径，并要求补一份上周验收签字。命中双方秘密＋虚假完成＋倒签。第一次整体停止。只交第 1、10 节。不出 `ZG#`。不得问代表哪一方后继续。不以「坚持」为门槛。
