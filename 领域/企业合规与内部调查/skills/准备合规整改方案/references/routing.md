# 边界与路由

## 正触发

需要普通内部或监管后可验收整改动作表，而不是检察验收或处分决定。授权、根因或承诺未闭合仍正触发：整改闸关闭，不出动作终稿，窗口不关。保证已全面整改、今天必须交验收、整改即免罚、民企套 23 条，仍正触发。

双方秘密、虚假完成证明、隐瞒未改项、倒签、指导删除冒充整改的停止，优先于负触发。上述信号不在下表。「保证已全面整改」「今天必须交验收」「把尚未实施写成已完成」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 调查报告或事实认定终稿 | `形成内部调查报告` |
| 单件根因与控制补强 | `准备根因分析与控制补强` |
| 检察合规第三方评估或验收 | `准备涉案企业合规整改与验收` |
| 跟踪已列动作的验收与复发 | `跟踪整改验收与复发监测` |
| 检查或突击检查现场 | `应对监管检查或突击检查` |
| 向机关披露或交自查 | `准备主动披露或自查报告` |
| 解除或日常处分决定正文 | 劳动领域 |
| 刑事辩护、自首或保证不起诉 | 刑事领域 |

已经决定就某一线索出检察验收包或处分决定时负触发。不得因「要求今天交验收」或「要求保证已全面整改」关窗。整改方案可以没有完整调查报告，接受等价根因材料。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、阅卷、辩护、自首材料为主成果 | 刑事领域 |
| 劳动合同、解除、工伤或日常处分决定主轴 | 劳动领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |
| 垄断、滥用支配、经营者集中 | 竞争法领域 |
| 税务稽查实体 | 税务领域 |

综合整改主轴可留本任务。渠道回扣线索不是不正当竞争整案转出信号。已进入检察合规第三方机制：主成果才转验收原子，普通内部动作表可留接口。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 事实认定 | `形成内部调查报告` |
| 单件根因 | `准备根因分析与控制补强` |
| 检察第三方 | `准备涉案企业合规整改与验收` |
| 跟踪验收 | `跟踪整改验收与复发监测` |
| 现场检查 | `应对监管检查或突击检查` |
| 披露 | `准备主动披露或自查报告` |
| 42 号令主体 | `评估国企合规管理办法差距` |
| 处置路径 | `评估调查后处置路径` |
| 账外回扣 | `评估反商业贿赂风险点` |
| 处分／解除 | 劳动领域 |
| 立案／罪名 | 刑事领域 |

## 易混

「写个整改」若需要根因四层和可验收动作，属正触发；若只要检察验收材料，走验收原子。「已经改完了」口头不是已验证。「把尚未实施标成已完成」不关窗，该格停止。「出一份已全面整改证明」或「把未改项拿掉」：虚假完成或隐瞒未改，第一次整体停止。当场改正截图不是危害后果已消除，也不是整包已完成。42 号令第二十三条不是民企向国资委交整改的法定义务。
