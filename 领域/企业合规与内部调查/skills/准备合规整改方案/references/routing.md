# 边界与路由

## 正触发

调查、检查或自查之后，主成果是可验收的普通内部整改动作表。授权、根因未闭合仍正触发：有可编号根因或动作缺口则闸开或半开，出 `ZG#` 草案，保持草案。本次不定罪、不保证免罚、不代提交是交付禁令，不是开窗条件。保证已全面整改、今天必须交验收、把尚未实施写成已完成、整改即免罚、民企套 42 号令、选定某局，仍正触发。

双方秘密、虚假完成、隐瞒未改、倒签、指导删账的停止，优先于负触发。上述信号不在下表。不定罪不是负触发。「保证已全面整改」「整改即免罚」不在下表。虚假完成不在下表，走整体停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 调查报告终稿 | `形成内部调查报告` |
| 单件根因、不要整包动作表 | `准备根因分析与控制补强` |
| 检察合规验收包，或夹带过验收／保证不起诉 | `准备涉案企业合规整改与验收` |
| 跟踪已列动作 | `跟踪整改验收与复发监测` |
| 检查现场应对 | `应对监管检查或突击检查` |
| 主动披露发送稿 | `准备主动披露或自查报告` |
| 是否启动内部调查 | `评估是否启动内部调查` |
| 解除或处分决定正文 | 劳动领域 |
| 刑事辩护、自首或不起诉保证 | 刑事领域 |
| 尚未进入合规机制，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不定罪」或「不保证免罚」关窗。拟普通动作表仍正触发，不得写成已全面整改或已获从轻。出现「整改」一词不是转出。
