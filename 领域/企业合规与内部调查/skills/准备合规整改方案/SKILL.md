# 准备合规整改方案

## 任务目标

在明确、无利益冲突的单方立场下，形成普通内部或监管后整改方案：整改闸、`RC#` 根因（制度／执行／监督／激励）、`A#` 动作（责任人、时点、验收证据、完成状态词）、外部承诺对照、未闭合项。本任务不把计划写成已完成，不替代检察合规第三方验收包，不写劳动处分决定，不保证免罚、从轻或不起诉。不执行发送，不代提交，不倒签。

`depends-on` 为空。调查结论转 `形成内部调查报告`。单件根因转 `准备根因分析与控制补强`。检察合规第三方转 `准备涉案企业合规整改与验收`。跟踪验收转 `跟踪整改验收与复发监测`。现场检查转 `应对监管检查或突击检查`。披露转 `准备主动披露或自查报告`。42 号令主体展开转 `评估国企合规管理办法差距`。

## 工作边界

正触发：调查、检查或自查之后，主成果是可验收的整改动作表。授权、根因或外部承诺未闭合仍正触发：整改闸关闭，不出动作终稿，窗口不关。用户要保证已全面整改、今天必须交验收、把尚未实施写成已完成、保证整改即免罚或应当从轻、民企按公司法第一百七十七条或 42 号令第二十二条／第二十三条必须向国资委交整改、选定某局，仍正触发：对应格填 `现有依据不支持` 或字段停止，闸未开则不出动作终稿，窗口不关。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是调查报告或事实认定终稿（转 `形成内部调查报告`）；
- 主成果是单件根因与控制补强、不要整包动作表（转 `准备根因分析与控制补强`）；
- 主成果是检察合规第三方监督评估或验收材料（转 `准备涉案企业合规整改与验收`）；
- 主成果是跟踪已列动作的验收与复发监测（转 `跟踪整改验收与复发监测`）；
- 主成果是检查或突击检查现场应对（转 `应对监管检查或突击检查`）；
- 主成果是向机关主动披露或自查报告（转 `准备主动披露或自查报告`）；
- 主成果是解除劳动合同或日常处分决定正文（转劳动领域）；
- 主成果是刑事辩护、自首或不起诉保证（转刑事领域）。

双方秘密、出具虚假整改完成证明、隐瞒未改项、倒签验收日、指导隐匿或删除会计资料冒充整改**不在负触发表**，走整体停止。「保证已全面整改」「今天必须交验收」「把尚未实施写成已完成」「整改即免罚」**不在负触发表**，只关对应格，窗口不关；同时要求伪造验收则整体停止。

## 建立工作坐标

确认：使用者与授权；单方立场（公司立场；被调查对象不得用本窗出对自己有利的「已整改」稿）；触发事件；已认定或待核事实；现行制度；可调配责任部门；已向机关作出的承诺；是否并行检查、监察、检察合规或诉讼。

口头「已经改完了」「微信已读」「快递发出」只登记 `S#`／`V#`。不得升格已验证、机关已验收或已获从轻。

同时掌握公司与被调查对象相互冲突的秘密，或两造争同一份整改稿：`整体停止`，不得以选边治愈，也不得改走负触发，不得问代表哪一方后继续。公司已开口且委托范围就是整改方案、且未掌握被调查对象秘密时，可推定公司立场。提出出具虚假完成证明、隐瞒未改项、倒签验收日、指导删除或隐匿会计资料冒充整改：第一次提出即整体停止，不以「坚持」为门槛。把尚未实施写成已完成本身不关窗；同时要求伪造验收则整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 制度或承诺；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`N#` 方案封面草稿；`Q#` 路径接口；`V#` 版本；`E#` 验收证据回链；`RC#` 根因；`A#` 整改动作。禁止 `Dsc#`、`ACT#`。承认只进 `S#`／`D#`，不得另立承认编号挤占 `A#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。动作状态只用 `计划`、`进行中`、`已验证`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。无验收证据不得写 `已验证`。未知不写零。禁止「已全面整改」「整改即免罚」「此致某局」「计划即完成」。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《民法通则》《民法总则》或其解释当作现行规则。不得把 1993 年公司法第一百八十条公益金条款、1996 年行政处罚法第三十二条陈述申辩条款直接当现行从宽规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：中央企业合规管理办法第二十三条，中央企业应当建立违规问题整改机制，通过健全规章制度、优化业务流程等堵塞管理漏洞；适用于国资委履行出资人职责的中央企业。主体不适用则该对照行删除，不得写成民企法定义务，不得建议比照向国务院国资委交整改。第四十条是对地方国资机构的参照授权，不是地方国企或民企对国务院国资委的整改义务。第二十二条是重大合规风险事件报告，不是本窗交整改稿的依据。公司法第一百六十八条国家出资公司不含参股；第一百七十七条即使对国家出资公司也只是对内合规管理，不是对外交整改或上报国资委的法定义务，更不是民企义务。行政处罚法（2021 修订）第二十八条，实施处罚时应当责令改正或者限期改正；责令改正不等于内部计划已完成。第三十二条，主动消除或者减轻危害后果等**应当**从轻或减轻；**整改计划或提交方案本身不等于危害后果已消除或已有立功**，不得写成整改即免罚或必然从轻。第三十三条不予处罚须另核。1996 年行政处罚法第三十二条陈述申辩是噪声。反不正当竞争法 2025 修订第八条（施行日 2025-10-15）：明示折扣入账不是贿赂，不得把入账折扣当必须整改的贿赂根因。刑法第六十七条：内部整改稿不是自首已成立。刑法第一百六十二条之一只作红旗，不得指导删除会计资料冒充整改。噪声：把计划写成已完成、把 23 条套全部民企、整改即免罚、责令改正已履行即已获从轻、快递发出即机关已验收、未知写零。MCP 若仍标 2025 反法尚未施行，以公布施行日为准并记录冲突。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变整改义务主体、从宽条件或责令改正效果的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补虚假合规、计划不等于落实、责令改正未实质履行、内部整改不是检察第三方验收的反例。
- `search_template` 只借整改方案栏目，不把范本当法定格式、已完成证明或验收结论。

工具不可用时继续 `RC#` 根因、`A#` 动作和缺口；责令改正效果、从宽、主体范围、期限字段停止。不得拒跑，不得凭记忆写成已全面整改或已获从轻。

## 判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、整改闸与不关窗

主成果才整案转出。虚假完成、双方秘密第一次停。保证已全面整改、今天必须交验收、整改即免罚、民企套 23 条不关窗。闸关仍交十节，第 6 节不出动作终稿。

### 2. 根因 `RC#`

至少分制度、执行、监督、激励。禁止只写员工品德。入账折扣不得当贿赂根因。

### 3. 整改闸与路径 `Q#`

本节禁止出 `A#` 动作终稿。无回链根因或动作缺口则闸关闭，窗口不关。检察第三方只打红旗。

### 4. 动作 `A#` 与完成状态

闸未开不得出可外传动作终稿。每个动作须有责任人、时点、验收证据形态、状态词。无验收证据不得写已验证。已向机关承诺的时点不得擅自缩短事实或夸大完成。

### 5. 接口与邻居

处分转劳动。数据／竞争专项只开接口。跟踪验收转跟踪原子。检察合规主成果才转验收原子。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；出具虚假整改完成证明；隐瞒未改项；倒签验收日；指导删除或隐匿会计资料冒充整改；妨害作证；打击报复。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：42 号令主体、责令改正依据、从宽条件、验收标准未核验。保证已全面整改、今天必须交验收、把尚未实施写成已完成、整改即免罚、民企套 23 条、选定某局：该格停止，窗口不关；闸未开仍不出动作终稿。未知写零同时要求伪造验收则整体停止。
- `目标停止`：主目标变为检察验收包、调查报告、处分决定或披露发送稿。

禁止指导伪造完成、隐匿或删除。不给胜诉率。不保证免罚。不定罪。不选定机关。不代提交。未知不写零。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。整改闸关闭或不关窗信号仍交十节；第 6 节不出动作终稿。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。整改闸未打开时不得交付动作终稿或「已全面整改」。边界见 [路由](references/routing.md)。
