# 测算舞弊损失与追偿方法

本文件是可执行判断节点。未知不是零。明示折扣入账不是贿赂损失。侵占与回扣同一笔不得全额双计。不当得利与侵权不得就同一利益全额相加。内部测算不是刑事数额。询价差价不是全额必得。收款不是回扣。已实际发还不是民事责任消灭。机会损失默认无法估计。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、应追回确定额、刑事既遂、选定法院、代提交、未知写零。本任务不定罪，不保证追回，不出唯一必得总额。本窗闸名只能是弊测闸，禁止复用测算闸、人测闸、精算闸、鉴定闸、评估闸。预留不得占用：立案闸、起诉闸、测算闸。本窗 `BM#` 是弊测行。主路径只用 `Q-弊测`，禁止用 `Q-测`、`Q-人测`、`Q-风`、`Q-启`、`Q-总` 作主路径。英文 id 禁止使用，一律用中文技能名 `测算舞弊损失与追偿`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回民法通则第九十二条／第一百一十七条、1993 年反法第八条、1993 年公司法第一百八十条公益金、把民法典第一百八十六条写成返还与侵权法定择一、把侵权责任编解释（一）第十七条写成对内追偿一般扣减、把反法第二十二条酌定赔偿当内部侵占公式时记为噪声。禁止指导伪造流水、虚增、隐瞒已收回或把已核实改零。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现资金碎片扫描，不是默认闭集。
`BM#` 固定列：`编号｜项目切片｜请求权假设｜参数与未舍入公式｜已收回／保险／减损｜互斥｜金额状态｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。金额状态只用 `已核实`、`情景`、`无法估计`。禁止合成「应追回确定额」。无 `E#` 不得写已核实。承认只进 `S#`／`D#`，不得占用 `A#`。同一资金事件在 `BM#` 内切片，禁止 `EVT#` 作主行。主路径只用 `Q-弊测`。禁止 `M#`、`EVT#`、`EV#`、`RS#`、`A#`、`N#`。

口头「大概亏了两百万」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。测算基准日不得早于本次形成日倒签。稿件状态默认 `草案`。已核实小计是毛损失，不得乘胜诉可能。

实务上：返还与侵权功能不同，同一利益不得全额相加，不足部分才允许「补差待核」。民法典第一百八十六条只覆盖违约与侵权择一。对内董监高用公司法第一百八十六条归入权与第一百八十八条赔偿，二者不得就同一所得全额叠算。已实际发还权利人的款项按填平扣减；未执行到位的刑事判项不得当民事已付。解释（一）第十七条仅在用人单位依民法典第一千一百九十一条对外赔偿时才打开，不是对内追偿通例。

## 节点 3　弊测行 `BM#`

按已出现资金碎片扫描，不是默认闭集。每条须能指向项目切片、请求权假设或扣减之一。
