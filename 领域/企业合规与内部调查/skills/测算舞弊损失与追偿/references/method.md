# 测算方法

本文件是可执行判断节点。本任务不认定犯罪已经成立。测算行建立在明示假设上：若某 `Q#` 成立，则对应 `M#` 如何计算。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。金额状态只用 `已核实金额`、`情景金额`、`无法估计`。未知不写零。真实零必须有肯定来源。禁止胜诉率、必然免责、刑事既遂、唯一截止日、选定法院或机关、代提交、把口头估计写成已核实、唯一必得总额。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》《民法通则》《民法总则》、1993 年公司法第一百八十条公益金、1993 年反不正当竞争法第八条，或把内部测算写成刑事立案数额时记为噪声，不得写入 `L#`。MCP 将 2025 修订《反不正当竞争法》标为尚未施行但公布施行日为 2025-10-15 的，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

`已核实金额` = 可回链毛损失或已回链利益，**不得**乘胜诉可能、责任比例或「法院会支持七成」。酌定比例、限额覆盖只出现在独立情景层。

`M#` 固定列：`编号｜项目｜EVT#｜Q# 假设｜参数｜未舍入公式｜已付／扣减｜互斥｜金额状态｜判断｜待核｜来源`。
`Q#` 固定列：`编号｜路径｜提出方｜相对方｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。

口头「大概亏了两百万」、已读、快递发出只进 `S#`／`V#`，不得升格已核实、已追回、已送达或机关已认定。

## 节点 0　分流、立场、测算闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。错误主张不改走负触发。伪造、虚增、隐瞒已收回不进负表。未知写零不进负表，也不单独整案停。

整案转出只交付第 1 节分流理由、第 2 节来源、第 10 节最小交接，不填第 5–9 节实体数字、不出唯一必得总额。

| 信号 | 处理 |
| --- | --- |
| 主成果是定性总图 | 负触发 `评估企业合规风险总图` |
| 主成果是调查报告或事实认定终稿 | 负触发 `形成内部调查报告` |
| 主成果是案卷矩阵 | 负触发 `建立内部调查证据案卷` |
| 主成果是谈判返还方案或和解文本 | 负触发 `谈判民事追偿与返还方案` |
| 主成果是民事追偿起诉状 | 负触发 `准备民事追偿诉讼材料` |
| 主成果是劳动经济补偿、赔偿金或工资扣回精算 | 整案转劳动 |
| 主成果是刑事立案数额、追缴判决或罪名认定 | 整案转刑事 |
| 主成果是主动披露或自查报告 | 负触发 `准备主动披露或自查报告` |
| 药品购销回扣行业细则主轴 | 整案转医疗医药 |
| 税务处理、稽查实体主轴 | 整案转税务 |
| 尚未进入合规机制，只要改合同 | 审查起草本窗搁置 |

测算闸打开（可出 `M#` 已核实行，仍不得标「应追回 XX 元」，仍不代提交）须同时满足：单方无冲突立场与测算授权；主成果是分项测算，不是报告、诉状、披露、劳动补偿或刑事数额；至少一类可回链资金流向、票据、转账或可编号缺口；无双方秘密、无第一次伪造／虚增／隐瞒已收回信号。

测算闸部分打开：授权或资金链未完全闭合，但已有可编号流水／合同差价；对应格待核或字段停止；仍交十节；不得标终稿 `已形成`。

测算闸关闭（仍正触发）：无测算授权；无一可回链金额且无一可编号缺口；事件／账户／期间无法识别。「今天必须算出一个数」而无最小事实不得开闸。不出唯一必得总额。**仍交十节**，第 5 节只交闸／`Q#` 状态，第 6 节不出可外传测算终稿或「应追回」额。禁止因闸关闭只交第 1、2、10 节。禁止因闸关闭改走负触发。禁止把闸关闭写成「没有损失」或「事件未发生」。

「保证追回或必得总额」「今天必须算出一个数」「选定某院追偿」「把猜测写成已核实」「把未知写成零凑整数」「把明示折扣入账当贿赂计入损失」「把内部测算当刑事立案数额」「民企必须按公司法第一百七十七条或 42 号令测算上报」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸未开仍不出测算终稿。未知写零同时要求伪造凭证：走整体停止。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续，不得改走负触发。
若 if 提出伪造流水、虚增损失、隐瞒已收回、倒签票据或基准日、指导入侵／偷拷／违法取证凑测算、妨害作证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　事件、资金流向与请求权假设

1. 固定单方立场、拟算项目和排除项。
2. 为同一资金事件分组。禁止把同一笔转账同时全额写入侵占、回扣、多付中的任意两行。
3. 不当得利、侵权、违约均为假设或材料载明，不得写成已决。刑事判决认定的金额不是民事必得额；刑事未认定的转账款也不是当然不当得利。
4. 资金流向必须能指向：付款人、收款人、账户或微信／支付宝表面、时点、对应交易。缺任一列，该笔不得变 `已核实金额`。对方或第三人控制的材料单独列控制方，不得推定金额已核实或已灭失。
5. 基准日不明：市价时点字段停止，对应行不得已核实。检索锚点：民法典第一千一百八十四条——损失发生时的市场价格或者其他合理方式。咨询日市价只能作 `情景金额`。

检索锚点：民法典第九百八十五条至第九百八十八条；第一千一百六十五条；第一百八十六条择一；第一百八十七条民责优先。

## 节点 3　分项建账 `M#`

闸未开不得标测算终稿已形成，不得出「应追回」额。项目必须可被看见，未知不得从矩阵删除。

| 项目 | 计入规则（检索锚点） | 禁止 |
| --- | --- | --- |
| 侵占／挪用公司资金 | 可回链流出与控制关系；已核实是毛流出，不乘胜诉可能 | 与同一笔回扣全额双计；口头「被拿走了」升格已核实 |
| 账外回扣／账外利益 | 账外暗中且无入账外观；收款性质有争议则该行不得已核实 | 明示入账折扣当回扣；刑事未认定的转账款当然当回扣 |
| 虚高价格／多付差额 | 须有可回链比价、同期市价或合同约定价；询价差价只作情景 | 把事后询价写成采购时市价已核实；差价全额必得（类案可酌减） |
| 调查或补救必要费用 | 单独标待核；须与减损或取证必要回链 | 把日常合规预算写入已核实；把违法取证费用写入（提出违法取证即整体停止） |
| 机会损失 | 原则上 `无法估计`。仅当有可回链替代交易或书面差价才开 `情景金额` | 无合同差价编造；把中位情景当已核实 |
| 利息／资金占用 | 规则未核验则 `无法估计`；LPR 不得默写为已核定 | 把咨询日利率写成已核定；选定唯一起算日 |

**互斥纪律：**

1. 同一资金事件的侵占、回扣、多付行不得两两同时全额已核实。能证明是同一笔资金的，只保留一条已核实，其余标互斥停止。
2. `Q-返` 与 `Q-权` 可并列假设，金额取选用或「返还不足再列侵权补差待核」，禁止把两行已核实相加当必得。检索锚点：民法典第一百八十六条择一。实务上返还与赔偿功能不同，不足才补，不是授权双计全额。
3. 有劳动合同、奖金或报销制度外观时，先标是否有法律根据；依据不足不得写成应返还。检索锚点：民法典第九百八十五条例外。
4. 善意得利且利益已不存在：返还义务字段停止，不得写成当然应返还。检索锚点：第九百八十六条。

## 节点 4　已收回、保险、减损与重复受偿

逐笔分列，不得合成一行：本人退还、第三人退还、刑事追缴已发还、保险已赔、费用补偿型保险、定额给付型保险、税费。

纪律：

1. 已追回并从权利人处实际受偿的，从对应 `M#` 扣减。隐瞒已收回：整体停止，不在本节点续算。
2. 刑事案件已完成的追缴、退赔：可以在民事测算中列扣减接口。检索锚点：侵权责任编解释（一）第十七条。刑事判决尚未作出或未判令追缴：民事测算可就已核实毛损失列表，并在缺口标明执行中可能调整。禁止写成「有刑事则民事归零」，也禁止写成「民事必得不受追缴影响」。检索锚点：民法典第一百八十七条。
3. 商业保险禁止一律扣减。费用补偿型是否冲抵运行时核验；定额给付型原则上不作为已付，待核。禁止写成「保险已赔则民事责任消灭」。
4. 减损：未采取适当措施致使扩大的部分不得计入请求。合理减损费用可单列待核。检索锚点：民法典第五百九十一条。本窗不把「公司内控有漏洞」写成损失不存在；类案可将自身过失作减责情景，不得乘进已核实小计。
5. 税费是否从损失中单列或还原，规则未核验则该行 `无法估计`，不得用零填。

## 节点 5　情景与汇总

责任情景、酌定比例只使用材料载明或用户明示假设，并声明不是已决。比例**不得**写入 `已核实金额` 单元格，不得把「法院会支持七成」乘进第 8 节已核实小计。

项目情景（保守／中位／扩展）不是必填算术。参数不足则该乘积层停止，不得用情景数字填满未知行。禁止把中位情景包装成「建议诉讼请求额」或「应追回 XX 元」。禁止输出唯一必得总额。用户催促「给一个数／先凑整数／没有票据就估」时保持 `部分形成并明确受限字段`，对应格 `现有依据不支持` 或 `无法估计`，窗口不关。

汇总表必须分列：已核实小计、情景小计、无法估计项目名单。已核实小计只含毛损失已核实行，不含胜诉可能、不含限额覆盖。互斥行不得加总。

工资扣回、违法解除赔偿：只开劳动接口，本窗不输出每月扣款日程或解除赔偿金。刑事追缴／罚金／没收：只红旗，不是本窗必得额。

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过测算闸直接给必得额。

若 if 日期、市价时点或动态规则未核验，then 依赖该规则的金额和法律结论字段停止，不编造唯一截止日或唯一市价。
若 if 已有监察／公安 `R#`，then 不得把本窗测算写成立案数额，也不得指导隐匿已收回。

判断状态只许三值。口头转述、截图和「已读」不得写成已核实、已追回或保险已赔付。
