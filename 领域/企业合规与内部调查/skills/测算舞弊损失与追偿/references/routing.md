# 边界与路由

## 正触发

已有或准备内部调查／追偿，主成果是侵占、回扣、多付价款的可复核分项测算。授权、流水未闭合仍正触发：有可编号资金碎片或缺口则闸开或半开，出 `BM#` 草案，保持草案。本次不定罪、不给必得总额、不写诉状是交付禁令，不是开窗条件。保证追回、今天必须算出一个数、选定某院、猜测写成已核实、折扣入账当贿赂、内部测算当刑事数额、民企套 177、未知写零、同一笔双计，仍正触发。

双方秘密、伪造流水、虚增、隐瞒已收回、把已核实改零、倒签、违法取证的停止，优先于负触发。上述信号不在下表。不定罪不是负触发。「保证追回」「未知写零」「折扣入账即贿赂」不在下表。伪造隐瞒不在下表，走整体停止。

## 易混

本窗闸名只能是弊测闸，不是测算闸，不是人测闸，不是精算闸，不是评估闸。`BM#` 不是 `M#`，不是 `EVT#`，不是 `RS#`。主路径是 `Q-弊测`，不是 `Q-测`，不是 `Q-人测`。`Q-测` 是合同包 `测算违约金与损害赔偿`。`人测闸`／`RS#`／`Q-人测` 是人身包 `测算人身损害赔偿`。邻窗 `评估账簿记录与虚假报销`、`评估回扣账外暗中与资金链路`、`谈判民事追偿与返还方案`、`准备民事追偿诉讼材料`、`建立内部调查证据案卷` 的测算转介改挂 `Q-弊测`。未知不是零。入账折扣不是贿赂损失。内部测算不是刑事数额。民法典第一百八十六条不是返还与侵权的法定选择条。公司法第一百八十六条是归入权，不要与民法典第一百八十六条串条。提出「已退过的改成零、流水按上周重做」整体停止。本窗不代提交。不选定法院。不定罪。不保证追回。不出应追回确定额。
