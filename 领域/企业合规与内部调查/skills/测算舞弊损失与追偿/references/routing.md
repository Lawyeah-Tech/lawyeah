# 边界与路由

## 正触发

需要可复核的舞弊或廉洁金钱工作表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要调查结论 | `形成内部调查报告` |
| 谈判返还方案 | `谈判民事追偿与返还方案`（P1，未安装则 unavailable） |
| 劳动补偿 | 劳动领域 |
| 刑事数额 | 刑事领域 |

## 专项整案转出


| 信号 | 转出 |
| --- | --- |
| 侦查、审查起诉、审判、取保、阅卷、辩护、刑事控告、自首材料 | 刑事领域 |
| 劳动合同、工资工时、解除劳动合同、工伤、职场性骚扰或日常违纪处分决定 | 劳动领域 |
| 个人信息合法性、影响评估、数据出境、等保、网安事件专项体系 | 数据隐私领域 |
| 垄断协议、滥用市场支配地位、经营者集中申报、不正当竞争专项评估 | 竞争法领域 |
| 税务处理、稽查实体 | 税务领域 |
| 银行保险机构行业合规办法主轴 | 金融领域 |
| 药品购销回扣行业细则主轴 | 医疗医药领域 |
| 出口管制、制裁名单 | 涉外领域 |
| 尚未进入合规机制，只要改交易合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |


综合合规主轴可留本任务；专项只作为背景时在缺口标明，不把专项规则写入本任务结论。

## 易混

“大概损失多少”若要分项数字属正触发；若要定性，走报告。
