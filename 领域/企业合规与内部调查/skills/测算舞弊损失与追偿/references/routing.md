# 边界与路由

## 正触发

需要可复核的舞弊或廉洁金钱工作表，而不是定性结论。授权、流水或请求权未闭合仍正触发：测算闸关闭，不出唯一必得总额，窗口不关。保证追回、今天必须算出一个数、选定某院、把猜测写成已核实、把折扣入账当贿赂、把内部测算当刑事数额、民企套 177，仍正触发。

双方秘密、伪造流水、虚增损失、隐瞒已收回、倒签基准日、指导违法取证凑测算的停止，优先于负触发。上述信号不在下表。「保证追回」「今天必须算出一个数」「把未知写成零凑整数」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 定性总图或合规路径扫描 | `评估企业合规风险总图` |
| 调查报告或事实认定终稿 | `形成内部调查报告` |
| 案卷矩阵 | `建立内部调查证据案卷` |
| 谈判返还方案或和解文本 | `谈判民事追偿与返还方案` |
| 民事追偿起诉状或证据目录终稿 | `准备民事追偿诉讼材料` |
| 劳动经济补偿、赔偿金或工资扣回精算 | 劳动领域 |
| 刑事立案数额、追缴判决或罪名认定 | 刑事领域 |
| 向机关披露或交自查 | `准备主动披露或自查报告` |
| 药品购销回扣行业细则 | 医疗医药领域 |

已经决定就某一线索出报告或起诉时负触发。不得因「要求今天算出一个数」或「要求保证追回」关窗。不得因「是否调查尚未判断」负触发吞掉本窗；查不查只转介 `评估是否启动内部调查`，测算工作表可留。

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、阅卷、辩护词、刑事控告、立案数额为主成果 | 刑事领域 |

| PIPL 合法性、出境、等保、网安事件专项 | 数据隐私领域 |
| 垄断协议、滥用支配地位、经营者集中申报 | 竞争法领域 |
| 税务处理、稽查实体 | 税务领域 |
| 药品购销回扣行业细则主轴 | 医疗医药领域 |

综合测算主轴可留本任务；专项只作为背景时在缺口标明。渠道回扣线索不是不正当竞争整案转出信号；反法第八条只用于「明示入账折扣不是贿赂损失」的计入判断。

## 易混

「大概损失多少」若要分项数字属正触发；若要定性，走报告。「给一个必得数／先凑整数／把未知当零」不关窗，不出总额，对应格停止。「先造一笔流水再测算」整体停止，不是负触发。「微信转了七万就是回扣」收款不等于回扣，该格待核或现有依据不支持，窗口不关。「询价差了三十万所以必得三十万」差价只作情景，类案可酌减，不得写入已核实必得。「有刑事就不要算民事」不关窗：第一百八十七条民责不因刑责免除，追缴只作扣减接口。「明示折扣也要算贿赂损失」该格现有依据不支持，窗口不关。
