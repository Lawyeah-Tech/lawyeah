# 测算舞弊损失与追偿

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《民法通则》《民法总则》或其解释当作现行规则。不得把 1993 年公司法第一百八十条公益金条款、1993 年反不正当竞争法第八条直接当现行计入规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成舞弊／廉洁金钱可复核测算包：测算闸、`EVT#` 事件、`Q#` 请求权假设、`M#` 分项工作表（已核实／情景／无法估计）、已收回／保险／减损分列、劳动与刑事接口。本任务不认定犯罪已成立，不输出刑事立案数额，不输出唯一必得总额，不把中位情景包装成「应追回 XX 元」。不是调查报告，不是诉状，不是披露稿，不是劳动经济补偿精算。

`depends-on` 为空。事实结论转 `形成内部调查报告`。案卷转 `建立内部调查证据案卷`。谈判返还方案转 `谈判民事追偿与返还方案`。起诉材料转 `准备民事追偿诉讼材料`。账户止付转 `评估内部账户冻结与资金保全`。账外回扣链路转 `评估回扣账外暗中与资金链路`。虚假报销转 `评估账簿记录与虚假报销`。

## 工作边界

正触发：已有或准备内部调查／追偿，主成果是把侵占、回扣、多付价款、必要费用或机会损失做成可复核分项工作表。授权、流水或请求权未闭合仍正触发：测算闸关闭，不出唯一必得总额，窗口不关。用户要保证追回或必得总额、今天必须算出一个数、选定某院追偿、把猜测写成已核实、把未知凑成整数、把明示折扣入账当贿赂计入损失、把内部测算当刑事立案数额、民企按公司法第一百七十七条或 42 号令必须测算上报国资委，仍正触发：对应格填 `现有依据不支持` 或字段停止，闸未开则不出测算终稿，窗口不关。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是定性总图或合规路径扫描（转 `评估企业合规风险总图`）；
- 主成果是调查报告或事实认定终稿（转 `形成内部调查报告`）；
- 主成果是案卷矩阵（转 `建立内部调查证据案卷`）；
- 主成果是谈判返还方案或和解文本（转 `谈判民事追偿与返还方案`）；
- 主成果是民事追偿起诉状或证据目录终稿（转 `准备民事追偿诉讼材料`）；
- 主成果是劳动经济补偿、赔偿金或工资扣回精算（转劳动领域）；
- 主成果是刑事立案数额、追缴判决或罪名认定（转刑事领域）；
- 主成果是向机关主动披露或自查报告（转 `准备主动披露或自查报告`）；
- 主成果是药品购销回扣行业细则（转医疗医药领域）。

双方秘密、伪造流水、虚增损失、隐瞒已收回、倒签测算基准日、指导违法取证凑测算**不在负触发表**，走整体停止。「保证追回」「今天必须算出一个数」「把未知写成零凑整数」「把折扣入账当贿赂」**不在负触发表**，只关对应格，窗口不关；同时要求伪造凭证则整体停止。

## 建立工作坐标

确认：使用者与授权；单方立场（公司／被调查对象，互斥）；拟测算项目与排除项；资金流向；已收回、保险与税费；拟主张路径（返还／侵权／合同，只作假设）；是否并行刑事／监察／劳动。

口头「大概亏了两百万」「微信已读」「快递发出」只登记 `S#`／`V#`。不得升格已核实金额、已追回、机关已认定或保险已赔付。

同时掌握公司与被调查对象相互冲突的秘密，或两造争同一份必得表：`整体停止`，不得以选边治愈，也不得改走负触发。公司已开口且委托范围就是测算、且未掌握被调查对象秘密时，可推定公司立场。提出伪造流水、虚增损失、隐瞒已收回、倒签票据或基准日、指导入侵或偷拷私人设备来凑测算：第一次提出即整体停止，不以「坚持」为门槛。把未知写成零凑整数本身不关窗；同时要求伪造凭证则整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 制度、劳动合同、采购合同或保险单；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`N#` 测算表封面草稿；`Q#` 请求权／互斥路径；`V#` 工作表版本；`E#` 资金流向凭证；`M#` 测算行。`EVT#` 只作同一资金事件分组，不得当主编号。禁止 `EV#`、`Dsc#`、`Ntc#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。金额状态只用 `已核实金额`、`情景金额`、`无法估计`。技能正文中的条号是检索锚点，不是已核验 `L#`。未知不写零，真实零必须有肯定来源。禁止「应追回 XX 元」「刑事数额已锁定」「折扣入账即贿赂损失」「内部测算即定罪」。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民法典第九百八十五条，得利人没有法律根据取得不当利益的，受损失的人可以请求返还，但为履行道德义务、债务到期前清偿、明知无给付义务而清偿除外；第九百八十六条，善意且利益已不存在的不承担返还；第九百八十七条，知情或应当知情可请求返还并依法赔偿损失；第九百八十八条，无偿转第三人的可请求第三人相应返还。第一千一百六十五条过错侵权；第一千一百八十四条，侵害他人财产的，财产损失按照损失发生时的市场价格或者其他合理方式计算。第一百八十六条违约与侵权择一；第一百八十七条，民事责任不因行政或刑事责任免除，财产不足时优先用于民事责任。第五百九十一条减损：未采取适当措施不得就扩大部分请求赔偿，合理减损费用由违约方负担。反不正当竞争法 2025 修订第八条（公布施行日 2025-10-15）：明示折扣、佣金如实入账不是贿赂；工作人员贿赂原则上认定经营者行为，但「与谋取交易机会或竞争优势无关」抗辩待核。第二十二条损害赔偿按实际损失或侵权获利，商业秘密情节严重可一至五倍，第七条、第十条难以确定时五百万元以下由法院酌定——均不得写成法定必得额。MCP 若仍标 2025 反法尚未施行，以公布施行日为准并记录冲突。公司法 2023 第一百八十条忠实勤勉是高管追偿接口，不是必得公式；第一百九十一条是执行职务给**他人**造成损害的对外赔偿，不得写成公司向董事追偿的当然条文；第一百七十七条不是民企法定测算上报义务。工资支付暂行规定第十六条从工资扣除损失每月不超过百分之二十且不低于最低工资，只开劳动接口，本窗不精算。侵权责任编解释（一）第十七条：刑事案件已完成的追缴、退赔可以在民事判决或执行中扣减，不得写成民事责任消灭。噪声：民法通则第九十二条／第一百一十七条、1993 年反法第八条、1993 年公司法第一百八十条公益金、把内部测算写成刑事立案数额、把明示入账折扣当贿赂、把询价差价写成全额必得、未知写零。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变计入、互斥、扣减或返还范围的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补侵占与回扣双计、收款不等于回扣、机会损失难以量化、保险赔付扣减、工资扣回须约定且受百分之二十限制的反例。
- `search_case_by_fact` 只比较事实差异与翻转条件（例如询价差价经酌减不是全额必得、刑事未认定的转账款不得当然当不当得利），不写成必得总额。

工具不可用时继续 `EVT#` 建账、`M#` 分项和缺口；返还／侵权／扣减法律效果、期限、机关路径字段停止。不得拒跑，不得凭记忆写成应追回确定额或已构成犯罪。

## 判断节点

执行顺序和停止条件以 [测算方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、测算闸与不关窗

主成果才整案转出。伪造、虚增、隐瞒已收回第一次停。保证追回、今天必须算出一个数、把未知写成零凑整数、选定某院、折扣入账当贿赂、内部测算当刑事数额不关窗。闸关仍交十节，第 6 节不出测算终稿。

### 2. 事件、资金流向与请求权假设

同一笔资金一个分组。侵占、回扣、多付不得对同一笔全额两两双计。不当得利、侵权、违约只作 `Q#` 假设，材料载明路径不是已决。

### 3. 测算闸与路径 `Q#`

本节禁止出唯一必得总额。无回链资金事实则测算闸关闭，窗口不关。`Q-刑`／`Q-劳` 只打红旗。

### 4. 分项 `M#` 与已收回／保险／减损

闸未开不得标测算终稿已形成。机会损失默认 `无法估计`，除非有可回链合同差价。已追回、保险赔付、税费各自成行。禁止一律扣减商业险。

### 5. 情景汇总与邻居接口

已核实小计是毛损失，不得乘胜诉可能。工资扣回转劳动。刑事追缴只红旗。谈判与起诉只开接口。不选定法院。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；提出伪造流水、虚增损失、隐瞒已收回、倒签票据或基准日、指导入侵／偷拷／违法取证凑测算、妨害作证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：返还／侵权规则、市价时点、保险扣减、善意得利抗辩、百分之二十工资限额未核验。保证追回、今天必须算出一个数、把未知写成零凑整数、选定某院、折扣入账当贿赂、内部测算当刑事数额、民企套 177：该格停止，窗口不关；闸未开仍不出测算终稿。未知写零同时要求伪造凭证则整体停止。
- `目标停止`：主目标变为调查报告、诉状、披露稿、劳动补偿精算或刑事立案数额终稿。

禁止指导伪造、隐匿、把未知当零或违法取证。不给胜诉率。不定罪。不保证追回。不选定法院或机关。不代提交。未知不写零。
