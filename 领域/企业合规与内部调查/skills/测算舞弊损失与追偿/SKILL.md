# 测算舞弊损失与追偿

## 任务目标

在明确、无利益冲突的单方立场下（公司、被调查对象或合规负责人，互斥），形成舞弊／廉洁金钱分项测算草案：弊测闸、项目切片与参数、`Q#` 路径、`BM#` 弊测行（项目切片／请求权假设／参数与未舍入公式／已收回／保险／减损／互斥／金额状态／`E#` 回链）。本窗 `BM#` 是弊测行草案，不是必得总额，不是刑事立案数额，不是诉状，不是谈判行，不是调查结论。本窗闸名只能是弊测闸，禁止复用测算闸、人测闸、精算闸、鉴定闸、评估闸、合规闸、启动闸、持有闸、披露闸、建卷闸、返还闸、诉材闸。预留不得占用：立案闸、起诉闸、测算闸。本窗主行只能是 `BM#`，禁止 `M#`、`EVT#`、`EV#`、`RS#`、`SJ#`、`JW#`、`A#`、`N#`。主路径只用 `Q-弊测`，禁止用 `Q-测`、`Q-人测`、`Q-风`、`Q-启`、`Q-持有`、`Q-披露`、`Q-建卷`、`Q-总`、`Q-发` 作主路径。邻窗 `Q-弊测` 只作转介进本窗；本窗打开为主路径，不是已核实、不是必得、不是犯罪已成立、不是已立案。弊测闸打开不等于已核实不等于项目必得不等于应追回确定额不等于犯罪已成立不等于刑事立案数额不等于待提交终稿。未知不是零。明示折扣佣金如实入账不是贿赂损失。侵占与回扣同一笔不得全额双计。不当得利与侵权不得就同一利益全额相加。内部测算不是刑事数额。询价差价不是全额必得。收款不是回扣。已实际发还不是民事责任消灭。机会损失默认无法估计。本任务不认定犯罪已经成立。不输出唯一必得总额。不写诉状或谈判协议终稿。不选定法院。不代提交。不定罪。不保证追回。

`depends-on` 为空。事实结论转 `形成内部调查报告`。案卷转 `建立内部调查证据案卷`。谈判返还方案转 `谈判民事追偿与返还方案`。起诉材料转 `准备民事追偿诉讼材料`。账户止付转 `评估内部账户冻结与资金保全`。账外回扣链路转 `评估回扣账外暗中与资金链路`。虚假报销转 `评估账簿记录与虚假报销`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：已有或准备内部调查／追偿，主成果是把侵占、回扣、多付价款、必要费用或机会损失做成可复核分项工作表。「必须追回多少」「今天必须算出一个数」仍正触发，成果状态 `草案`。授权、流水或请求权未闭合仍正触发：有可编号资金碎片、票据或可编号缺口则弊测闸打开或半开，第 6 节出 `BM#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出应追回确定额」才关闸，仍交十节，第 6 节不出 `BM#` 终稿，第 7 节不得出应追回额、诉状或谈判协议，窗口不关。用户要保证追回或必得总额、选定某院、把猜测写成已核实、把明示折扣入账当贿赂、把内部测算当刑事数额、民企按第一百七十七条或 42 号令必须测算上报、未知写零、侵占与回扣同一笔全额双计、询价差价即全额必得，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `BM#` 草案。不得因「不定罪」「不给必得总额」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是定性总图或合规路径扫描（转 `评估企业合规风险总图`）；
- 主成果是调查报告或事实认定终稿（转 `形成内部调查报告`）；
- 主成果是案卷矩阵（转 `建立内部调查证据案卷`）；
- 主成果是谈判返还方案或和解文本（转 `谈判民事追偿与返还方案`）；
- 主成果是民事追偿起诉状或证据目录终稿（转 `准备民事追偿诉讼材料`）；
- 主成果是劳动经济补偿、赔偿金或工资扣回精算（转劳动领域）；
- 主成果是刑事立案数额、追缴判决或罪名认定（转刑事领域）；
- 主成果是向机关主动披露或自查报告（转 `准备主动披露或自查报告`）；
- 主成果是药品购销回扣行业细则（转医疗医药领域）；
- C 端大众测算包（只分流，本窗不降级实施）；
- 尚未进入合规机制，只要改合同或出稿（审查起草领域，本窗搁置，只说明不实施）。

双方秘密、伪造流水、虚增损失、隐瞒已收回、把已核实金额改写成零、倒签测算基准日、指导违法取证凑测算**不在负触发表**，走整体停止。「保证追回」「今天必须算出一个数」「折扣入账当贿赂」「未知写零」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不定罪」「不给必得总额」「不写诉状」是交付禁令，不是负触发。主成果才转；出现「测算」「追回」「必得」一词不是转出。查不查尚未判断不负触发吞窗。

## 建立工作坐标

确认：测算授权；单方立场（公司／被调查对象／合规负责人，互斥）；拟测算项目与排除项；资金流向；已收回、保险与税费；拟主张路径（返还／侵权／合同，只作假设）；是否并行刑事／监察／劳动。

口头「大概亏了两百万」「今天必须算出一个数」只登记 `S#`／`V#`。不得升格已核实金额，**不得单独算作开闸材料**。可编号资金碎片、票据或可编号缺口可开闸。本窗不执行发送，不代提交，不定罪。

立场只许公司、被调查对象或合规负责人，互斥。同时掌握公司与被调查对象相互冲突的秘密，或两造争同一份必得表：`整体停止`，不得选边，不得问代表哪一方后继续。无一可编号碎片：弊测闸关闭，仍交十节，不是整体停止。无书面测算授权但单方立场已闭合、且已有碎片：弊测闸部分打开，仍交十节，不是整体停止。提出伪造流水、虚增损失、隐瞒已收回、把已核实金额改写成零、倒签票据或基准日、指导入侵或偷拷私人设备来凑测算：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。开口不等于立场闭合。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 制度、劳动合同、采购合同或保险单；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`BM#` 弊测行；`V#` 版本；`E#` 证据形态回链（票据、流水、合同差价，不是已核实证明，不是必得证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`M#`、`EVT#`、`EV#`、`RS#`。同一资金事件在 `BM#` 内切片，禁止另立 `EVT#` 作主行。技能正文中的条号是检索锚点，不是已核验 `L#`。金额旁注只用 `已核实`、`情景`、`无法估计`。未知不写零。真实零必须有肯定来源。无 `E#` 不得写已核实。不输出唯一必得总额。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态默认 `草案`。未知 ≠ 零。入账折扣 ≠ 贿赂损失。内部测算 ≠ 刑事数额。询价差价 ≠ 全额必得。收款 ≠ 回扣。已发还 ≠ 民事责任消灭。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或裁判案例检索。本窗是分项测算，**不要**用 `search_template` 生成精算终稿、必得总额、诉状或「应追回 XX 元」。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现未知写零、折扣入账即贿赂、内部测算即定罪、询价差价即全额必得的反例；案例只比较事实差异与翻转条件，不写成必然结果。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《民法通则》《民法总则》、1993 年公司法第一百八十条公益金、1993 年反不正当竞争法第八条、把民法典第一百八十六条写成返还与侵权法定择一、把侵权责任编解释（一）第十七条写成对内追偿一般扣减当作现行计入规则。反不正当竞争法 2025 修订第八条施行日 2025-10-15；MCP 标「尚未施行」以施行日为准。施行日前未持续行为适用修改前文本（通常为 2019 修正第七条）。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的返还、侵权、扣减、市价时点或期限保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：民法典第九百八十五条至第九百八十八条不当得利（例外三项、善意利益不存在、知情可返还并赔偿、无偿转第三人）。第一千一百六十五条过错侵权。第一千一百八十四条财产损失按损失发生时市场价格或其他合理方式。第一百八十六条只覆盖违约与侵权择一，不是返还与侵权的法定选择条。第一百八十七条民事责任不因行政或刑事责任免除，财产不足优先民事责任。第五百九十一条减损只锚定合同相对方路径，侵权行不得默写成已核验公式。公司法（2023）第一百八十条忠实勤勉是义务标准不是必得公式；第一百八十六条归入权（违反第一百八十一条至第一百八十四条所得归公司）；第一百八十八条执行职务违法违规给公司造成损失应赔偿；第一百九十一条是执行职务给他人造成损害的对外结构，不得写成公司向董事追偿的当然条文；第一百七十七条不是民企测算上报义务。反不正当竞争法 2025 第八条：明示折扣、佣金如实入账不是贿赂。工资支付暂行规定第十六条从工资扣除损失每月不超过百分之二十且不低于最低工资，只开劳动接口。噪声：民法通则第九十二条／第一百一十七条、1993 年反法第八条、1993 年公司法第一百八十条公益金、把解释（一）第十七条当对内追偿一般扣减、把反法第二十二条酌定赔偿当内部侵占公式、未知写零、询价差价即全额必得、内部测算即定罪。技能正文条号不是 `L#`。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变计入、互斥、扣减或返还范围的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补侵占与回扣双计、收款不等于回扣、机会损失难以量化、保险赔付扣减、工资扣回须约定且受百分之二十限制的反例。
- `search_case_by_fact` 只比较事实差异与翻转条件（询价差价经酌减不是全额必得、刑事未认定的转账款不得当然当不当得利）。无类案不得写成项目必得或必不得。测算类禁止用 `search_template` 生成精算终稿、必得总额或诉状。

工具不可用时继续 `BM#` 分项与缺口；返还／侵权／扣减、市价时点、期限字段停止。不得拒跑，不得凭记忆写成应追回确定额或已构成犯罪。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、弊测闸与不关窗

主成果才整案转出。双方秘密、伪造流水、虚增、隐瞒已收回第一次停。保证追回、今天必须算出一个数、未知写零、折扣入账当贿赂不关窗。闸关仍交十节，第 6 节不出 `BM#` 终稿。利益冲突未解不是整体停止。禁止把测算闸、评估闸、启动闸写进本窗节点 0。

### 2. 项目切片、资金流向与请求权假设

同一笔资金一个分组。侵占、回扣、多付不得对同一笔全额双计。返还、侵权、违约只作 `Q#` 假设，材料载明路径不是已决。本节禁止出 `BM#` 终稿。

### 3. 弊测闸与路径 `Q#`

本节禁止出 `BM#` 终稿。有可编号碎片：闸打开或半开。主路径只用 `Q-弊测`。`Q-返`／`Q-权`／`Q-违` 不得升主路径。

### 4. 弊测行 `BM#`

项目切片、参数与未舍入公式、已收回／保险／减损、互斥。状态 `草案`。禁止升格必得、已核实终稿、应追回确定额。无 `E#` 不得写已核实。

### 5. 劳动、刑事、谈判与起诉接口

工资扣回转劳动。刑事追缴只红旗。谈判与起诉只开接口。第 7 节不得夹带 `BM#` 终稿或应追回额绕闸。不选定法院。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；两造争同一份必得表；提出伪造流水、虚增损失、隐瞒已收回、把已核实金额改写成零、倒签票据或基准日、指导违法取证凑测算。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：弊测闸关闭，仍交十节，不是整体停止。无书面测算授权但有碎片：弊测闸部分打开，不是整体停止。利益冲突未解：不是整体停止。把未知写成零：该格字段停止，窗口不关，不是整体停止。
- `字段停止`：返还／侵权规则、市价时点、保险扣减、善意得利抗辩、百分之二十工资限额、施行日未核验。保证追回、今天必须算出一个数、选定某院、折扣入账当贿赂、内部测算当刑事数额、民企套 177、未知写零、同一笔全额双计、询价差价即全额必得：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `BM#` 草案。
- `目标停止`：主目标变为调查报告、诉状、披露稿、劳动补偿精算或刑事立案数额终稿。禁止把「未知写零」或「保证追回」当作用户错误主张时的目标停止；那是不关窗。

禁止指导伪造、隐匿或把已核实改零。不给胜诉率。不定罪。不保证追回。不选定法院或机关。不代提交。未知不写零。不输出唯一必得总额。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。弊测闸关闭仍交十节，第 6 节不出 `BM#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `BM#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。弊测闸未打开时不得交付测算终稿或「应追回 XX 元」。边界见 [路由](references/routing.md)。
