# 准备调查访谈提纲与笔录结构

## 任务目标

在明确、无利益冲突的单方立场下（公司或其调查受托律师，互斥；不允许被调查对象代理），形成内部调查访谈提纲与笔录结构草案：提纲闸、对象分层与强制接口、`Q#` 路径、`IQ#` 提纲行（对象分层／告知事项／问题顺序／笔录结构接口／双人规则／禁止口径）。本窗 `IQ#` 是提纲行，不是 `OT#`，不是方案 `PL#`，不是收集 `LG#`，不是保护 `PT#`，不是调查认定 `F#`。提纲不是已访谈。笔录结构不是已笔录。内部访谈不是刑事讯问。笔录签名不是犯罪承认。统一口径不是配合监察。单人闭门不是可靠笔录。口头授权不是可实施访谈。不实施访谈。不强迫自证其罪口径。不实施现场审讯。不写调查结论。不保证免责。不代提交。

`depends-on` 为空。调查方案与访谈顺序转 `制定调查方案与访谈计划`。收集日志转 `合法收集书证电子证与财务痕迹`。证人保护终稿转 `设计举报人保护与反报复措施`。回避名单终稿转 `处理利益冲突与调查回避`。调查报告转 `形成内部调查报告`。授权终稿转 `确定调查授权范围与独立`。刑事讯问、辩护、控告主成果转刑事。劳动违纪问话主轴转劳动。

## 工作边界

正触发：已经决定调查，需要准备知情人或被调查人的访谈提纲、告知事项和笔录结构，而不是已经在问话、出调查结论或做刑事讯问。对象碎片、授权未核验、无书面提纲仍正触发：有可编号拟访谈对象或提纲碎片则提纲闸打开或半开，第 6 节出 `IQ#` 草案，缺项记 `G#`。无书面授权但有拟访谈对象：部分打开。无一拟访谈对象且无一提纲碎片、又要求「今天必须出已访谈终稿」才关闸，不出 `IQ#` 终稿，窗口不关。用户要把提纲写成已访谈、把笔录结构写成已笔录、把签名写成犯罪承认、把内部访谈写成刑事讯问、把统一口径写成配合监察、把已立案一词写成必须关窗、把单人闭门写成可靠、把先谈话后取证写成可靠路径、把「不承认就开除」写成告知套话、把刑诉第五十二条写成企业内部必须关窗条款，仍正触发：对应格填 `现有依据不支持`，窗口不关；闸已开仍出其他 `IQ#` 草案。不得因「不实施访谈」或「不强迫自证其罪口径」改走负触发关窗。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是调查方案与访谈顺序（转 `制定调查方案与访谈计划`）；
- 主成果是收集日志终稿（转 `合法收集书证电子证与财务痕迹`）；
- 主成果是证人保护 `PT#` 终稿（转 `设计举报人保护与反报复措施`）；
- 主成果是回避名单终稿（转 `处理利益冲突与调查回避`）；
- 主成果是调查报告或事实认定（转 `形成内部调查报告`）；
- 主成果是授权范围与独立终稿（转 `确定调查授权范围与独立`）；
- 主成果是刑事讯问、辩护、控告或自首材料（转刑事领域）；
- 主成果是劳动处分、解除或职场性骚扰／日常违纪问话（转劳动领域）。

双方秘密、伪造或倒签提纲或笔录、强迫自证、威胁取出口供、承诺免责换承认、诱导性有罪预设作为方法、秘密违法录音、向证人透露他人陈述以施压、限制人身自由、空白签名套话、指导删除会计资料、阻挠合法检查**不在负触发表**，走整体停止。「提纲即已访谈」「笔录结构即已笔录」「签名即犯罪承认」「内部访谈即刑事讯问」「统一口径即配合监察」「已立案一词必须关窗」「单人闭门仍可靠」「先谈话后取证即可靠」「不承认就开除即告知」「刑诉第五十二条即企业内部必须关窗」**不在负触发表**，该格 `现有依据不支持`，窗口不关。「不实施访谈」「不强迫自证其罪口径」「不实施现场审讯」是交付禁令，不是负触发。

## 建立工作坐标

确认：书面或拟设授权；单方公司立场；拟访谈对象分层（外围证人／核心证人／被调查人／公职接触）、是否已有机关询问、是否并行检查或刑事；法域；当前检查、诉讼、监察或刑事状态。

口头「先把人叫来谈开」「提纲写完就算谈过了」「群已读」只登记 `S#`／`V#`。不得升格已访谈、已笔录或已可实施，**不得单独算作开闸材料**。已读不得升格 `R#` 已送达。纸面提纲草稿不是已访谈。

同时掌握公司与被调查对象相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。公司已开口且委托就是提纲与笔录结构、且未掌握对方秘密时，可推定公司或其调查受托律师立场。被调查对象代理不是本窗立场。无书面授权但公司立场已闭合、且已有可编号拟访谈对象或提纲碎片：提纲闸部分打开，仍交十节，不是整体停止。无一拟访谈对象且无一碎片：提纲闸关闭，仍交十节，不是整体停止。提出强迫自证、威胁取出口供、秘密违法录音、向证人透露他人陈述施压、限制人身自由或伪造笔录：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认（不是已访谈，不是已笔录）；`R#` 机关或生效文书；`C#` 内部调查制度或提纲版本；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`IQ#` 提纲行；`V#` 版本；`E#` 证据形态回链（授权范围、对象名单版本、告知稿版本，不是发送闸，不是已访谈证明）。禁止 `N#`、`EV#`、`M#`、`F#`、`ACT#`、`P#`、`K#`、`O#`、`H#`、`B#`、`U#`、`X#`、`HD#`、`W#`、`T#`、`OR#`、`LV#`、`TR#`、`PX#`、`LD#`、`SP#`、`CH#`、`CS#`、`PT#`、`RF#`、`RT#`、`AU#`、`AZ#`、`PL#`、`LG#`、`CG#`、`IV#`、`OT#`、`SA#`、`Dsc#`。技能正文中的条号是检索锚点，不是已核验 `L#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止合成「已访谈闭环」一笔。扫描不是闭集。未知人数不写零。稿件状态默认 `草案`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。本窗是提纲与笔录结构草案，范本只借栏目，**不要**升格「已访谈／已笔录／签名即承认／询问笔录即内部法定格式」。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现有罪预设、单人闭门、向证人透露他人陈述、先谈话后取证污染、统一口径干扰侦查的反例；案例只比较事实差异与翻转条件，不写成必然结果。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《民法通则》《民法总则》或其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：刑事诉讼法（2018 修正）第五十二条不得强迫任何人证实自己有罪，约束审判人员、检察人员、侦查人员，不是企业内部访谈的法定关窗条款；本窗仍禁止强迫自证口径。噪声：1979 年刑事诉讼法第五十二条审查批准逮捕纠正违法。监察法（2024 修正）第四十三条严禁以暴力、威胁、引诱、欺骗及其他非法方式收集证据，约束监察机关，只作企业内部禁止动作对标。监察法实施条例关于询问应当个别进行、调查人员不得少于二人、不得向证人泄露案情，约束监察询问，只作分别询问／双人／不得透露他人陈述的方法参考，不是内部访谈已合法。公司法（2023 修订）第六十七条董事会职权不等于已可实施访谈。42 号令第十四条组织或参与调查不等于提纲即已访谈。个人信息保护法第六条、第十三条不等于访谈可秘密录音或全员约谈。刑法第三百零七条、第三百零八条、第一百六十二条之一只作红旗。非法取证排除只作红旗，本窗不写排除裁定。噪声：已失效《合同法》、询问笔录或法院调查笔录即内部法定格式、监察同步录音录像条款即内部必须全程录音、已立案一词必须关窗、签名即犯罪承认。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变刑诉／监察并行边界或个保录音边界的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补访谈一般安排在调查最后阶段、至少两名、告知权利、避免诱导或逼迫、分别询问或分组同时访谈以防统一口径、初期不披露过多已掌握证据的反例。实务「双人」「告知」是方法参考，不是本窗已实施访谈。
- `search_template`（optional）只借告知事项、时间地点人员、问答、阅读确认、双人签名栏目。工商询问笔录、人民法院调查笔录、行政执法询问笔录不是内部提纲法定格式，不得升格已访谈或已笔录。

工具不可用时继续对象分层和 `IQ#` 编目；并行程序、个保录音边界、施行日、已访谈字段停止。不得拒跑，不得凭记忆写成提纲即已访谈或内部访谈即刑事讯问。

## 判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、提纲闸与不关窗

主成果才整案转出。强迫自证、秘密录音、双方秘密第一次停。提纲即已访谈、已立案一词必须关窗不关窗。闸关仍交十节，第 6 节不出 `IQ#` 终稿。

### 2. 对象分层、授权接口与强制接口

证人／被调查人／公职接触分列。公职身份不足则该层字段停止。授权未闭合：提纲闸可半开，不实施访谈。刑诉第五十二条、监察询问规范分列强制与方法参考。

### 3. 提纲闸与路径 `Q#`

本节禁止出 `IQ#` 终稿。有可编号拟访谈对象或提纲碎片：闸打开或半开。无一对象且无一碎片才关闸，窗口不关。口头谈开、已读不得单独开闸。

### 4. 提纲行 `IQ#`

对象、告知、问题顺序、笔录结构接口、双人规则、禁止口径分列。有罪预设、不承认就开除、向证人透露他人陈述行删除或该格不支持。状态 `草案`。

### 5. 笔录结构、禁止口径与邻窗接口

单人闭门：可靠性字段停止，窗口不关。证人保护只开 `PT#` 接口。方案顺序转方案窗。不实施访谈。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出强迫自证、威胁取出口供、承诺免责换承认、诱导性有罪预设作为方法、秘密违法录音、向证人透露他人陈述以施压、限制人身自由、空白签名套话、伪造或倒签提纲或笔录、指导删除会计资料、借提纲平行灭证、打击报复或阻挠合法检查。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无书面授权但公司立场已闭合：不是整体停止；有拟访谈对象则部分打开，无一对象则闸关闭，仍交十节。
- `字段停止`：公职身份、个保录音边界、并行程序、施行日、单人闭门下的笔录可靠性未核验。提纲即已访谈、笔录结构即已笔录、签名即犯罪承认、内部访谈即刑事讯问、统一口径即配合监察、已立案一词必须关窗、单人闭门仍可靠、先谈话后取证即可靠、不承认就开除即告知、刑诉第五十二条即企业内部必须关窗：该格 `现有依据不支持`，窗口不关；闸已开仍出其他 `IQ#` 草案。
- `目标停止`：主目标变为方案顺序终稿、收集日志、保护终稿、回避名单、调查报告、授权终稿、刑事讯问。

禁止指导强迫自证、威胁取出口供、秘密违法录音或伪造笔录。不给胜诉率。不定罪。不保证免责。不选定机关。不代提交。未知不写零。不实施访谈。不把提纲写成已访谈。不把内部访谈写成刑事讯问。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。提纲闸关闭仍交十节，第 6 节不出 `IQ#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `IQ#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。提纲闸未打开时不得交付「已访谈」或「已笔录」。边界见 [路由](references/routing.md)。
