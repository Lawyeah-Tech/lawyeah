# 边界与路由

## 正触发

已经决定调查，需要准备知情人或被调查人的访谈提纲、告知事项和笔录结构，而不是已经在问话、出调查结论或做刑事讯问。从零、对象碎片、无完整授权仍正触发：有拟设则闸开或半开，出 `IQ#` 草案。提纲即已访谈、笔录结构即已签字、讯问笔录即内部法定格式、单人闭门也可靠、交提纲即从轻，仍正触发。

双方秘密、强迫自证、威胁诱供、朗读他人陈述施压、秘密录音、伪造笔录的停止，优先于负触发。上述信号不在下表。「提纲即已访谈」「笔录结构即已签字」「讯问笔录即内部法定格式」「单人闭门也可靠」「交提纲即从轻」「第十四条即已访谈」「刑诉第五十二条即企业内部必须关窗」不在下表。「不实施访谈」「不强迫自证其罪口径」「不实施现场审讯」是交付禁令，不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 调查方案与访谈顺序 | `制定调查方案与访谈计划` |
| 收集日志终稿 | `合法收集书证电子证与财务痕迹` |
| 授权范围与独立终稿 | `确定调查授权范围与独立` |
| 调查报告或事实认定 | `形成内部调查报告` |
| 证人保护终稿 | `设计举报人保护与反报复措施` |
| 回避名单终稿 | `处理利益冲突与调查回避` |
| 劳动处分、解除或职场性骚扰／日常违纪问话 | 劳动领域 |
| 刑事讯问、辩护、控告或自首材料 | 刑事领域 |

不得因「不实施访谈」或「不强迫自证其罪口径」关窗。已立案一词不是必须关窗。主成果才是讯问／辩护才转刑事。强迫自证不进负表，走整体停止。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、解除、工伤、职场性骚扰主轴 | 劳动领域 |

综合内部调查提纲主轴可留本任务。审查起诉或检查只作背景，主成果才转。出现「访谈」「提纲」一词不是转出。

## 易混

内部访谈不是刑事讯问。提纲不是已访谈。笔录结构不是已签字笔录。笔录签名是核对记录，不是犯罪承认。单人闭门不是已可靠。双人在场是方法参考，不是已实施。讯问笔录不是内部法定格式。刑诉第五十二条不是企业内部必须关窗条款。不承认就开除不是合法告知。统一口径不是配合监察。第十四条不是已访谈。交提纲不是从轻。口头叫人不是开闸。不实施访谈、不强迫自证其罪口径是交付禁令，不是负触发。
