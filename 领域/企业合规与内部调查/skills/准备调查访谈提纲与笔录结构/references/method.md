# 评估方法

本文件是可执行判断节点。提纲不是已访谈。笔录结构不是已签字笔录。内部访谈不是刑事讯问。笔录签名不是犯罪承认。单人闭门不是已可靠。讯问笔录不是内部法定格式。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、范本填满、唯一截止日、选定机关、代提交、未知写零。本任务不实施访谈，不出方案终稿、收集日志、授权书或调查结论。本窗 `IQ#` 是提纲行，不是 `OT#`，不是 `PL#`，不是 `LG#`，不是 `AZ#`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、把刑诉第五十二条写成企业内部必须关窗、把讯问笔录写成内部法定格式时记为噪声。禁止指导强迫自证、威胁诱供、秘密录音。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`IQ#` 固定列：`编号｜对象分层（外围证人／核心证人／被调查人／公职接触）｜告知事项（身份授权／受托律师代表公司不代表受访人／主题范围／自愿可中止／将作记录／不得报复）｜问题簇（时间线／文件编号；开放在前、文件对质在后）｜禁止口径｜笔录栏目（时间地点人员／问答／阅读确认／双人签名／修改栏）｜双人在场方法参考（非已实施）｜录音依据｜机关并行／接触禁令｜E#回链｜判断三值｜缺口G#｜最强反方｜待核`。禁止合成「已访谈闭环」。无 `E#` 不得写已覆盖、已访谈、已签字。状态 `草案`。禁止 `PL#` `LG#` `AZ#` `F#` `ACT#` `Dsc#` `ST#` `IV#` `N#` `OT#` `PT#`。

口头「先把人叫来」「提纲写完就算谈过了」「群已读」只进 `S#`／`V#`，**不得算作开闸材料**。纸面提纲草稿不是已访谈。`A#` 是承认，不是已签字笔录。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

## 节点 0　分流、立场、提纲闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、强迫自证、威胁诱供、朗读他人陈述施压、秘密录音、伪造笔录不进负表。

整案转出只交付第 1、2、10 节，不出 `IQ#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是方案／访谈顺序 | 负触发 `制定调查方案与访谈计划` |
| 主成果是收集日志 | 负触发 `合法收集书证电子证与财务痕迹` |
| 主成果是授权终稿 | 负触发 `确定调查授权范围与独立` |
| 主成果是调查报告 | 负触发 `形成内部调查报告` |
| 主成果是证人保护终稿 | 负触发 `设计举报人保护与反报复措施` |
| 主成果是回避名单终稿 | 负触发 `处理利益冲突与调查回避` |
| 主成果是劳动处分／违纪问话 | 整案转劳动 |
| 主成果是刑事讯问、辩护、控告 | 整案转刑事 |

审查起诉、监管检查只作程序背景。主成果才整案转。出现「访谈」「提纲」一词不是转出。已刑事立案且主成果是讯问才整案转刑事；并行 `R#` 下要内部提纲须开闸并限缩。

提纲闸打开（可出 `IQ#` 草案，仍不得标「已访谈／已签字／已可靠」）须同时满足：单方无冲突的公司或其调查受托律师立场已闭合；主成果是告知、提纲与笔录结构；至少一条可编号拟设对象或提纲碎片。从零：有拟设即可开或半开。口头叫人、已读不算开闸材料。双方秘密或第一次强迫自证不是关闸条件，走整体停止。

提纲闸部分打开：无完整书面授权但已有对象／提纲碎片；或双人、个保录音、并行机关未核验。对应格待核。仍交十节。不得标终稿 `已形成`。

提纲闸关闭（仍正触发）：无一拟设对象且无一提纲碎片。「今天必须出已访谈终稿」而无最小事实不得开闸。不出 `IQ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `IQ#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「提纲即已访谈」「笔录结构即已签字」「讯问笔录即内部法定格式」「单人闭门也可靠」「交提纲即从轻」「第十四条即已访谈」「刑诉第五十二条即企业内部必须关窗」「不承认就开除当告知」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `IQ#` 草案。「不承认就开除」一旦写成告知或取供方法：改走整体停止。

若 if 立场或委托无法闭合，then 整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 被调查对象代理要出提纲，then 立场无法闭合，整体停止。
若 if 公司立场已闭合、无完整授权但已有拟设对象，then 提纲闸部分打开，仍交十节，不是整体停止。
若 if 公司立场已闭合但无一拟设，then 提纲闸关闭，仍交十节，不是整体停止。
若 if 提出强迫自证、威胁诱供、朗读他人陈述施压、秘密录音、伪造或倒签笔录、空白签名作为方法、限制人身自由、指导串供或统一口径干扰侦查，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　对象分层与强制接口

证人／被调查人／公职接触分列。公职身份不足：该行字段停止。告知必须含：访谈人身份与授权、受托律师代表公司不代表受访人、主题范围、自愿与可中止、将作记录、不得因合法举报被报复。

检索锚点（写入 `L#` 前须核验）：刑诉第五十二条不得强迫自证其罪约束审判／检察／侦查人员，不是企业内部访谈同一法条义务。监察法第四十三条非法方式取证禁令约束监察机关，只作禁止动作对标。监察询问「不得少于二人、个别进行、不得向证人泄露案情」只作方法参考。公司法第六十七条不等于已可实施访谈。42 号令第十四条不等于已访谈。个保法第六条、第十三条不等于全员约谈或当然录音。劳动合同法第三十九条不是「不承认就开除」告知依据。行政处罚法第三十二条：交提纲不等于从轻。刑法第三百零七条、第三百零八条、第一百六十二条之一只作红旗。

## 节点 3　提纲行 `IQ#`

按已出现对象扫描，不是默认闭集。一行一对象。开放问题在前、文件对质在后。诱导性有罪预设、承诺免责换承认：该段删除。热冲突不得保留进表。单人闭门：可靠性格不支持，窗口不关。无 `E#` 不得写已覆盖。状态 `草案`。

## 节点 4　禁止口径、双人规则与转介

必须写入：不得强迫自证、不得威胁诱供、不得承诺免责换承认、不得单人闭门当可靠、不得秘密录音、不得伪造或倒签笔录、不得空白签名、不得向证人朗读他人陈述施压、不得限制人身自由。证人保护只开接口。不可逆（已约谈、已签字、已秘密录）不得在草案阶段实施。第 7 节不得夹带 `IQ#` 终稿。不代约谈、不代提交。

下一步只转介：授权、方案、收集、保护、回避、案卷、工作产品、劳动、刑事。禁止约谈指令、此致某局。

## 本任务回链纪律

本任务成果是「提纲闸与提纲行草案」。本窗不执行访谈，不出方案、收集日志、授权书、调查结论。禁止提纲即已访谈。禁止笔录结构即已签字。禁止讯问笔录即内部法定格式。禁止单人闭门已可靠。禁止交提纲即从轻。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标提纲终稿已形成。
