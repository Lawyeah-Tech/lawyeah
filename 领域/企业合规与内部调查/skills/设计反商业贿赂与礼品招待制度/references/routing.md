# 边界与路由

## 正触发

需要反商业贿赂和礼品招待的制度框架草案，而不是审查单笔礼品、出风险图终稿或写章程级办法全文。碎片、阈值未核验仍正触发：有可编号拟设制度行或现行碎片则闸开或半开，出 `GI#` 草案。印发即生效、纸面即有效、低于阈值即合法、小额一律合法、行业惯例即合法、民企必须按 42 号令第十八条制定专项、FCPA 即中国法义务、制度印发即免责，仍正触发。

双方秘密、指导把账外或行贿写入制度、伪造账册、倒签生效、指导删除、打击报复的停止，优先于负触发。上述信号不在下表。「印发即生效」「纸面即有效」「低于阈值即合法」「小额一律合法」「行业惯例即合法」「民企必须专项」「FCPA 即中国法」「制度印发即免责」不在下表。「不保证小额即合法」「不审查竞争协议」「不把本窗写成医药细则终稿」是交付禁令，不在下表。出现「医药」「竞争」「礼品」一词不是转出。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 单笔礼品、招待、赞助或捐赠审查 | `审查礼品招待赞助与捐赠` |
| 廉洁风险图 | `评估反商业贿赂风险点` |
| 回扣账外资金链路终稿 | `评估回扣账外暗中与资金链路` |
| 章程级办法全文 | `起草合规管理办法或章程级制度` |
| 综合合规框架 | `设计合规管理体系框架` |
| 政策层级与例外批准细则 | `设计政策层级与例外批准` |
| 药品购销回扣行业细则整案 | 医疗领域 |
| 垄断协议、滥用支配或竞争协议审查 | 竞争法领域或审查起草搁置 |
| 任免、股权或章程决议本身 | 公司治理领域 |
| 刑事辩护、控告或自首 | 刑事领域 |
| 劳动规章或解除决定 | 劳动领域 |
| 未进入合规机制的交易合同改稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不保证小额即合法」「不审查竞争协议」「不写医药细则」关窗。阈值即合法、印发即生效、FCPA 当中国法该格不支持，窗口不关，不转出。主成果才转。民企硬套不得负触发到对照窗。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 药品购销回扣行业细则为主成果 | 医疗领域 |
| 垄断协议、滥用支配、经营者集中为主成果 | 竞争法领域 |

综合礼品招待制度草案主轴可留本任务。检查或已立案只作背景，主成果才转。

## 易混

草案不是已生效。印发不是生效。总部印发不对独立法人子公司当然生效。纸面不是有效。阈值不是法定安全港。有礼品政策不是已合规。无稽核不是有效制度。小额广告礼品除外不是空白支票。例外审批人不得是最终受益决策人。明示折扣入账不是贿赂。FCPA 不是中国法义务。42 号令第十八条不套民企必须制定专项。不保证小额即合法、不审查竞争协议是交付禁令，不是负触发。口头「小额即合法」不是开闸材料。可编号拟设行或现行碎片才开闸。指导账外或行贿写入制度是第一次整体停止，不是不关窗。
