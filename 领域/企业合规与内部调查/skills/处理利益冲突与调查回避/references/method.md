# 处理方法

本文件是可执行判断节点。回避名单不是已回避。宣布回避仍看材料不是已独立。换下属查领导不是独立。外部所拿被调查人预算不是独立。口述「没关系」不消除冲突。老板信任不是可不回避。公司法忠实勤勉不是当然回避已完成。42 号令不是民企必须外聘。已取证未回避：标污染风险，不自动作废全部案卷，可依赖结论字段停止。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、选定法院、代提交、未知写零。本任务不写调查结论、不任免、不写授权书终稿、不签聘用合同。本窗 `AV#` 是回避行，不是授权行 `AZ#`，不是调查认定 `F#`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1993 年公司法、把 42 号令第十四条写成已独立、把处分条例第三十一条套民企、把律师法第三十九条写成内部法务已回避、把换下属写成已独立时记为噪声。禁止指导掩盖冲突、向被调查人通风、伪造回避声明或删除冲突旧档。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现冲突扫描，不是默认闭集。
`AV#` 固定列：`编号｜冲突主体与角色｜冲突类型｜回避效果（退出项目／关系统权限／不得收过程汇报／不得接触原件）｜替代主体条件（授权／预算独立／向非冲突机关汇报）｜已形成材料污染｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已回避闭环」。无 `E#` 不得写已覆盖、已回避、已独立。`E#` 只作证据形态回链。缺项记 `G#`。扫描不是闭集。

口头「没关系」「老板信任」「已经宣布回避」「群已读」只进 `S#`／`V#`，**不得单独算作开闸材料**。已读不得升格权限已关或 `R#` 已回避。纸面草稿不是已生效。`A#` 是承认关系或曾参与，不是已回避。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上参与调查和处理的人员与被调查人有亲属、利害或其他可能影响公正的关系，应当主动申请回避。合规调查应保持独立性，不受其他部门或管理层干涉。合规部门应与内部审计相互独立。回避申请口头易争议，书面更可追溯——本窗仍不得把口头「已宣布」升格已回避。律师利益冲突查证函、无利益冲突声明只借栏目。刑诉回避决定书不是内部调查法定格式。

## 节点 0　分流、立场、回避闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、冲突主体出结论、指导掩盖、向被调查人通风、伪造回避声明、指导隐匿、打击报复、阻挠合法检查不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `AV#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是书面授权要点终稿 | 负触发 `确定调查授权范围与独立` |
| 主成果是是否启动 | 负触发 `评估是否启动内部调查` |
| 主成果是调查报告终稿 | 负触发 `形成内部调查报告` |
| 主成果是调查方案与访谈计划 | 负触发 `制定调查方案与访谈计划` |
| 主成果是取证实施 | 负触发 `合法收集书证电子证与财务痕迹` |
| 主成果是工作产品终稿 | 负触发 `评估律师工作产品与保密边界` |
| 主成果是非调查场景廉洁评估 | 负触发 `评估利益冲突与关联交易廉洁面` |
| 主成果是任免、股权或章程决议 | 整案转公司治理 |
| 主成果是劳动解除或处分文书 | 整案转劳动 |
| 主成果是刑事控告、辩护或自首 | 整案转刑事 |
| 确为中央企业且主成果是 42 号令对照终稿 | 负触发 `评估国企合规管理办法差距` |
| 「不因老板要求省略回避」「不任免」「不写调查结论」「不写授权书终稿」 | 交付禁令，不是负触发 |

审查起诉、监管检查、已立案只作程序背景。主成果才整案转。出现「回避」「独立」一词不是转出。

回避闸打开（可出 `AV#` 草案，仍不得标「已回避／已独立／已消毒」）须同时满足：单方无冲突公司立场已闭合；主成果是调查回避处理，不是授权终稿、调查结论或任免；至少一名可编号冲突主体或回避碎片。口头「没关系」「老板信任」、拟设回避草稿不算单独开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

回避闸部分打开：已有可编号冲突主体或回避碎片，但关系、预算、权限、是否国企未闭合；或无书面回避声明但已有碎片；对应格待核；仍交十节；不得标终稿 `已形成`。

回避闸关闭（仍正触发）：无一可编号冲突主体且无一回避碎片。「今天必须出已回避终稿」而无最小冲突不得开闸。不出 `AV#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `AV#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关写成「没有冲突」或「老板信任即可不回避」。

「换下属即独立」「口述没关系即无冲突」「宣布即已回避」「外所拿预算即独立」「民企必须外聘」「老板信任即可不回避」「忠实勤勉即回避完成」「第一百八十五条即调查组已回避」「交回避表即从轻／即自首」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `AV#` 草案。上述行**不得写入可执行 `AV#` 的已独立结论**。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无一可编号冲突主体且无一回避碎片，then 回避闸关闭，仍交十节，不是整体停止。
若 if 单方立场已闭合、无书面回避声明但已有可编号冲突主体或回避碎片，then 回避闸部分打开，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出冲突主体出具调查结论、指导掩盖冲突、向被调查人通风、伪造或倒签回避声明、指导隐匿、打击报复、阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。
若 if 老板要求省略回避但未要求冲突主体出结论或掩盖，then 该格 `现有依据不支持`，窗口不关，不是整体停止。

## 节点 1　主体、冲突碎片与强制接口

一行一个主体或冲突碎片。缺项记 `G#`，不得把未知人数写成 `0`。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 主体属性 | 中央企业／地方国企／参股／民企 | 把民企写成必须按 42 号令外聘调查 |
| 冲突主体×角色 | 调查组成员、审批人、访谈人、IT 提取人、经费审批 | 口述「没关系」消除角色 |
| 冲突类型 | 亲属、汇报／考核、经费、赞助、共同投资、未来就业 | 把董事会表决回避写成调查已回避 |
| 替代条件 | 授权、预算独立、向非冲突机关汇报 | 把换下属或走被查人预算写成已独立 |
| 机关状态 | 检查／监察／刑事 `R#` 有无 | 把刑诉回避决定书写成内部已回避 |

检索锚点（写入 `L#` 前须核验）：

- 公司法第一百八十条：避免利益冲突是忠实义务接口，不是调查回避已完成。
- 公司法第一百八十二条／第一百八十五条：关联交易报告、关联董事表决回避，不是内部调查回避已成立。
- 公司法第六十七条：董事会设内部机构 ≠ 已独立调查。
- 公司法第一百六十八条／第一百七十七条：国家出资公司不含参股；177 不套民企必须外聘。
- 42 号令第二条只约束中央企业。第十四条组织或参与调查 ≠ 已回避、已独立。第四十条地方国资参照。
- 国有企业管理人员处分条例第三十一条：只约束国企管理人员处分调查，不套民企内部廉洁调查。
- 律师法第三十九条：双方代理禁令只约束执业律师。内部法务通常不具备执业律师身份。
- 监察法第十八条第一款如实提供；不得指导隐匿。
- 行政处罚法（2021）第三十二条：交回避表 ≠ 从轻。
- 刑法第一百六十二条之一、第三百零七条、第三百零八条只作红旗，不得指导删档。

国企／民企／上市分列。强制接口与非强制对标分列。本节禁止出 `AV#` 终稿。

## 节点 3　回避行 `AV#`

按已出现冲突扫描，不是默认闭集。建议行型（出现才用，**不是闭集**）：

| 编号 | 含义 | 本窗允许 | 禁止 |
| --- | --- | --- | --- |
| `AV-亲` | 亲属 | 退出四件套 | 口述没关系消除 |
| `AV-上` | 汇报／考核／直接上下级 | 换下属独立性格不支持 | 升格已独立 |
| `AV-费` | 经费控制 | 预算改挂非冲突主体 | 走被查人条线仍称独立 |
| `AV-赞` | 业务赞助 | 外所条件待核 | 拿被查人预算即独立 |
| `AV-投` | 共同对外投资 | 接口 | 写成当然受贿 |
| `AV-就` | 未来就业承诺 | 接口 | 写成已定罪 |
| `AV-权` | 系统权限未关 | 关闭权限条件 | 宣布即已关 |
| `AV-外` | 外所预算不独立 | 独立性格不支持 | 升格已外聘独立 |
| `AV-下` | 换下属查领导 | 独立性格不支持 | 写入可执行已独立 |
| `AV-宣` | 宣布仍看材料 | 独立性格不支持 | 升格已回避 |

热冲突强制处理：

- 换下属即独立／口述没关系／宣布即已回避／外所拿预算即独立／民企必须外聘／老板信任即可不回避／忠实勤勉即回避完成 → 该格不支持；仍出其他 `AV#`。
- 只宣布回避仍看材料 → 回避不成立；独立性格不支持。
- 已取证因未回避 → 标污染风险；可依赖结论字段停止；**不自动作废全部案卷**。
- 替代必须同时有授权、预算独立、向非冲突机关汇报；缺一项则替代格待核或不打开。
- 冲突主体出结论或指导掩盖 → 整体停止，不是该格不支持。

事实不足以支持某回避行：该条 `依据不足，无法形成结论`，不关窗。无 `E#` 不得写已覆盖、已回避或已独立。状态 `草案`。一次只推荐下一步。可并行必须逐条写条件。

## 节点 4　权限关闭、污染、禁止文书与转介

第 7 节只开接口，不得夹带 `AV#` 终稿绕闸。闸关闭时第 7 节可写「闸未开，转介待冲突主体编号」，不得补写已回避。

回避效果四件套必须可见：退出项目、关闭系统权限、不得接收过程汇报、不得接触原件。缺一件则对应格待核，不得标已独立。

不写调查结论、任免决议、授权书终稿、聘用合同正文、发送版回避决定。不可逆（对外宣称已独立、群发已回避、向监管正式报告已独立、签署概括弃权）不得在草案阶段实施。禁止提交指令。不代提交。不选定机关。

授权转 `确定调查授权范围与独立`。报告转 `形成内部调查报告`。方案转 `制定调查方案与访谈计划`。取证转 `合法收集书证电子证与财务痕迹`。任免转公司治理。廉洁面转 `评估利益冲突与关联交易廉洁面`。工作产品转 `评估律师工作产品与保密边界`。

已有检查或刑事 `R#`：不得借回避稿干扰办案或向被调查人通风。刑法第一百六十二条之一只作红旗，不得指导隐匿。

若 if 用户催促「按零写／填满已回避终稿」，then 该格 `现有依据不支持`，窗口不关。
若 if 人数、系统范围未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「回避闸与回避草案」。本窗不执行发送。不包含：已回避证明、已独立证明、授权书终稿、调查结论、任免决议、案卷作废决定。禁止选边治愈。禁止换下属即独立。禁止宣布即已回避。禁止口述没关系。禁止外所拿预算即独立。禁止民企套 42 号令必须外聘。禁止老板信任即可不回避。禁止忠实勤勉即回避完成。禁止未回避则案卷全部作废。禁止冲突主体出结论。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标回避终稿已形成。
