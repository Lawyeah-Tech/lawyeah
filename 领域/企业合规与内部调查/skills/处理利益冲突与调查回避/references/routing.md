# 边界与路由

## 正触发

调查主体或成员与被调查人存在利益关系，需要回避名单、权限关闭、替代条件与污染接口，而不是写授权书终稿、调查结论或任免决议。关系未核验、无书面回避声明仍正触发：有可编号冲突主体或回避碎片则闸开或半开，出 `AV#` 草案。换下属即独立、口述没关系、宣布即已回避、外所拿预算即独立、民企必须外聘、老板信任即可不回避、忠实勤勉即回避完成，仍正触发。老板要求省略回避仍正触发。利益冲突未解仍正触发。

双方秘密、冲突主体出结论、指导掩盖冲突、向被调查人通风、伪造回避声明、指导隐匿、打击报复、阻挠合法检查的停止，优先于负触发。上述信号不在下表。「换下属即独立」「口述没关系即无冲突」「宣布即已回避」「外所拿预算即独立」「民企必须外聘」「老板信任即可不回避」「忠实勤勉即回避完成」不在下表。「不因老板要求省略回避」「不任免董监高」「不写调查结论」「不写授权书终稿」是交付禁令，不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 书面授权要点终稿 | `确定调查授权范围与独立` |
| 是否启动内部调查 | `评估是否启动内部调查` |
| 调查报告终稿 | `形成内部调查报告` |
| 调查方案与访谈计划 | `制定调查方案与访谈计划` |
| 取证实施 | `合法收集书证电子证与财务痕迹` |
| 工作产品终稿 | `评估律师工作产品与保密边界` |
| 非调查场景的关联交易廉洁评估 | `评估利益冲突与关联交易廉洁面` |
| 任免、股权或章程决议 | 公司治理领域 |
| 劳动解除、处分决定或劳动争议程序文书 | 劳动领域 |
| 刑事控告、辩护、自首或阅卷 | 刑事领域 |
| 确为中央企业且主成果是 42 号令对照终稿 | `评估国企合规管理办法差距` |

不得因「不因老板要求省略回避」「不任免」「不写调查结论」关窗。换下属即独立、宣布即已回避、民企必须外聘该格不支持，窗口不关，不转出。出现「回避」「独立」一词不是转出。主成果才转。民企硬套不得负触发到对照窗。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、解除、工伤、职场性骚扰主轴且回避处理不是主成果 | 劳动领域 |
| 税务处理决定、稽查实体 | 税务领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |
| 垄断、滥用支配、经营者集中 | 竞争法领域 |

综合内部调查回避处理主轴可留本任务。检查或已立案只作背景，主成果才转。已刑事立案且主成果是刑事程序：整案转刑事。已刑事立案但主成果仍是企业回避处理：留窗；指导干扰办案或向被调查人通风整体停止。

## 易混

回避名单不是已回避。宣布回避仍看材料不是已独立。换下属查领导不是独立。外部所拿被调查人预算不是独立。口述「没关系」不消除冲突。老板信任不是可不回避。公司法第一百八十条忠实勤勉不是当然回避已完成。第一百八十五条董事会表决回避不是调查回避已成立。42 号令第十四条组织或参与调查不是已独立。处分条例第三十一条不套民企内部廉洁调查。律师法第三十九条不使内部法务当然已回避。已取证未回避不是案卷全部作废，可依赖结论字段停止。不因老板要求省略回避、不任免、不写调查结论是交付禁令，不是负触发。口头「没关系」「已经宣布」不是开闸材料。可编号冲突主体或回避碎片才开闸。冲突主体出结论或指导掩盖是第一次整体停止，不是不关窗。
