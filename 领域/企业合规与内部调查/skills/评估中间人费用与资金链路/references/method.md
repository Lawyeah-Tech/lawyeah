# 中间人费用方法

本文件是可执行判断节点。明示入账佣金不是贿赂。成功费本身不是贿赂。个人卡不是单位行贿既遂。无成果不是自动定罪。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。入账三态只用 `双方如实入账`、`单方或账外`、`待核`。禁止胜诉率、必然免责、选定法院、代提交、未知写零、唯一总额。本任务不定罪，不审改中介合同全文。本窗 `MF#` 是中间人行，不是账外行 `XB#`，不是返点行 `RP#`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1993 年反不正当竞争法第八条、已失效《中介服务收费管理办法》、把 MCP「尚未施行」的 2025 反法第八条在施行日 2025-10-15 之后仍当未生效时记为噪声。禁止指导账外佣金、伪造成果或打个人卡掩盖。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现条款扫描，不是默认闭集。
`MF#` 固定列：`编号｜费用类型（咨询／佣金／成功费）｜名义收款人｜账户控制人｜最终受益人｜对价／成果｜入账三态｜红旗｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已贿赂闭环」或「入账即合法」。无 `E#` 不得写已贿赂、已合法。`E#` 只作证据形态回链。三层受益人断裂记 `G#`，不得填零或编造。缺项记 `G#`。扫描不是闭集。未知金额不写零。不输出唯一总额。

口头「中间人都是回扣」「成功费就是行贿」「打个人卡就是既遂」只进 `S#`／`V#`，**不得单独算作开闸材料**。`A#` 是承认委托或入账碎片，不是已合法。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上应对中间人做对价、入账和受益人核验，但这不是已贿赂、不是已合法。有成果且入账，不得仅因「中间人」写成贿赂。正常佣金抗辩必须单列。

## 节点 0　分流、立场、中间闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、指导账外佣金、伪造成果、打个人卡掩盖、打击报复不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `MF#` 终稿。

| 信号 | 处理 |

| 主成果是销售激励与渠道返点 | 负触发 `评估销售激励与渠道返点廉洁风险` |

| 主成果是尽调工作底稿 | 负触发 `准备第三方尽职调查工作底稿` |
| 主成果是中止或终止通知 | 负触发 `准备中止或终止高风险第三方合作通知` |
| 主成果是第三方机制草案 | 负触发 `设计第三方合规管理机制` |
| 主成果是账簿虚假报销终稿 | 负触发 `评估账簿记录与虚假报销` |

审查起诉、监管检查只作背景。主成果才整案转。出现「佣金」「咨询费」「成功费」「中间人」一词不是转出。

中间闸打开（可出 `MF#` 草案，仍不得标「已贿赂／已合法／已入账闭集」）须同时满足：单方无冲突公司立场已闭合；主成果是中间人费用评估，不是回扣账外、渠道返点或完整合同；至少一条可编号费用碎片。口头「中间人都是回扣」不算单独开闸材料。双方秘密或第一次指导账外不是关闸条件，走整体停止。

中间闸部分打开：已有碎片，但委托、成果、受益人、入账未闭合；对应格待核；仍交十节。

中间闸关闭（仍正触发）：无一可编号费用碎片。「今天必须出已贿赂或已合法终稿」而无最小碎片不得开闸。不出 `MF#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `MF#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「中间人一律贿赂」「成功费即行贿」「明示入账即合法闭集」「个人卡即单位行贿既遂」「无成果即已犯罪」「空壳即已贿赂」「本表已定罪」「FCPA 即中国法义务」「交表即从轻」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `MF#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无一可编号碎片，then 中间闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象或相对方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出指导账外佣金、指导伪造成果或发票、指导打个人卡掩盖、打击报复，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个主体或强制接口。缺项记 `G#`，不得把未知金额写成 `0`。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 主体 | 经营者／中间人／工作人员 | 把民企写成必须按 42 号令专项 |
| 中间人资格 | 是否具有合法经营资格，待核 | 资格不足写成已贿赂 |
| 费用类型 | 咨询／佣金／成功费分列 | 把渠道返点或账外折扣当本窗闭集 |

检索锚点（写入 `L#` 前须核验）：

- 反不正当竞争法（2025）第八条：明示向中间人支付佣金、双方如实入账不是贿赂。施行日 2025-10-15。
- 暂行规定第七条：佣金须给具有合法经营资格的中间人并如实入账。
- 刑法第一百六十三条、第一百六十四条、第三百九十二条只作红旗，不定罪。
- 42 号令第二条只约束中央企业。
- FCPA 不是中国法义务。

本节禁止出 `MF#` 终稿。

## 节点 3　中间人行 `MF#`

按已出现费用扫描，不是默认闭集。建议行型（出现才用，**不是闭集**）：

| 编号 | 含义 | 本窗允许 | 禁止 |
| --- | --- | --- | --- |
| `MJ-型` | 费用类型 | 咨询／佣金／成功费分列 | 把渠道返点写成中间人佣金闭集 |
| `MJ-益` | 三层受益人 | 名义收款人／账户控制人／最终受益人 | 断裂填零或编造；亲属即已贿赂 |
| `MJ-价` | 对价成果 | 委托、交付物、是否匹配 | 无成果即已犯罪；有成果仍因「中间人」定罪 |
| `MJ-账` | 入账三态 | 双方如实入账／单方或账外／待核 | 入账即合法闭集；对方账簿不可得推定账外 |
| `MJ-旗` | 红旗 | 成功费打个人、层层转包、无成果、空壳、决策人关联 | 红旗即已贿赂 |

热冲突强制处理：

- 中间人一律贿赂／成功费即行贿／入账即合法闭集／个人卡即既遂／无成果即已犯罪／空壳即已贿赂／本表已定罪／FCPA 即中国法 → 该格不支持；仍出其他 `MF#`。
- 三层受益人断裂 → 记 `G#`，不得填零。
- 对方账簿不可得 → 入账三态 `待核`，不推定账外。
- 指导账外佣金或伪造成果 → 整体停止，不是该格不支持。

无 `E#` 不得写已贿赂、已合法。状态 `草案`。正常佣金抗辩必须单列。一次只推荐下一步。

## 节点 4　回扣、返点与合同接口

第 7 节只开接口，不得夹带 `MF#` 终稿绕闸。闸关闭时第 7 节可写「闸未开，转介待费用编号」，不得补写已合法。

不写回扣账外终稿、渠道返点终稿、完整中介合同、筛查终稿、刑事文书。不可逆（对外宣称已合法、账外兑现、伪造成果）不得在草案阶段实施。禁止提交指令。不代提交。不选定机关。

回扣转 `评估回扣账外暗中与资金链路`。返点转 `评估销售激励与渠道返点廉洁风险`。完整合同搁置。筛查转 `筛查经销商代理中介廉洁风险`。尽调转 `准备第三方尽职调查工作底稿`。税务转税务领域。

若 if 用户催促「按零写／填满已贿赂或已合法终稿／给出唯一总额」，then 该格 `现有依据不支持`，窗口不关。
若 if 金额未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：民企。有居间委托、交付过促成报告、佣金双方入账；另有一笔成功费打到中间人控制的个人卡，受益人与客户经办人亲属关系待核。用户主张中间人一律贿赂、成功费就是行贿、入账了就是合法闭集、个人卡就是单位行贿既遂、空壳就是已犯罪、按 FCPA 写死、给出唯一行贿总额。中间闸打开。`Q-中`、`Q-成`、`Q-账`、`Q-卡`、`Q-壳`、`Q-美` 不打开为可靠路径。第 6 节不得把已贿赂、已合法、已既遂或唯一总额写入可执行 `MF#`；对应格 `现有依据不支持`；仍出类型、三层受益人、入账三态、红旗待证等其他 `MF#` 草案。正常佣金抗辩单列。不关窗。不定罪。未知金额不写零。

场景②：用户同时交出公司费用评估草稿与中间人抗辩，要求选对公司有利的一版，并指导「咨询费改走账外、成果报告先补一套」。命中双方秘密＋指导账外佣金／伪造成果。第一次整体停止。只交第 1、10 节。不出 `MF#`。不得问代表哪一方后继续。
