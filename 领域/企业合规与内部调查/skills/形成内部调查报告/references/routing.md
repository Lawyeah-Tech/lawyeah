# 边界与路由

## 正触发

需要对内形成可回链调查报告。授权、范围、回避或材料未齐仍正触发：有可编号命题或缺口则闸开或半开，出 `F#` 草案，保持草案。本次不定罪、不作解除、不保证免责、不代提交是交付禁令，不是开窗条件。保证已查清、今天必须出结论、猜测写成已认定、入账折扣当贿赂、报告即罪名成立、民企套 177／42 号令，仍正触发。

双方秘密、伪造认定、隐瞒关键事实、倒签、选择性不写、平行灭证的停止，优先于负触发。上述信号不在下表。不定罪不是负触发。「保证已查清」「报告即罪名成立」不在下表。隐瞒不在下表，走整体停止。
