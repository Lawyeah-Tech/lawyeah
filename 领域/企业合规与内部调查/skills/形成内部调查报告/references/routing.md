# 边界与路由

## 正触发

需要把内部调查做成可回链事实认定与处置接口，而不是披露或处分决定。授权、范围、回避或材料未闭合仍正触发：报告闸关闭，不出认定终稿，窗口不关。保证已查清、今天必须出结论、把猜测写成已核实、把折扣入账当贿赂、把回扣写成已构罪、民企套 177，仍正触发。

双方秘密、伪造认定、隐瞒关键不利或有利事实、顶替、倒签、违法取证、平行灭证、妨害作证、打击报复的停止，优先于负触发。上述信号不在下表。「保证已查清」「今天必须出结论」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 是否启动内部调查 | `评估是否启动内部调查` |
| 案卷矩阵 | `建立内部调查证据案卷` |
| 金额测算终稿 | `测算舞弊损失与追偿` |
| 向机关披露或交自查 | `准备主动披露或自查报告` |
| 整改方案 | `准备合规整改方案` |
| 对内通报或对外口径发送稿 | `准备对内通报与对外口径` |
| 解除劳动合同或日常处分决定正文 | 劳动领域 |
| 刑事控告、自首材料或辩护 | 刑事领域 |
| 董事会内部汇报且不含调查事实认定 | `准备董事会合规汇报材料` |

已经决定就某一线索出披露或解除决定时负触发。不得因「要求今天出结论」或「要求保证已查清」关窗。不得因「是否调查尚未判断」负触发吞掉本窗；查不查只转介 `评估是否启动内部调查`，认定草案可留。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、阅卷、辩护词、刑事控告、自首材料为主成果 | 刑事领域 |
| 劳动合同、解除、工伤、职场性骚扰或日常处分决定主轴 | 劳动领域 |
| PIPL 合法性、出境、等保、网安事件专项 | 数据隐私领域 |
| 垄断协议、滥用支配地位、经营者集中申报 | 竞争法领域 |
| 税务处理、稽查实体 | 税务领域 |
| 药品购销回扣行业细则主轴 | 医疗医药领域 |

综合认定主轴可留本任务；专项只作为背景时在缺口标明。渠道回扣线索不是不正当竞争整案转出信号；反法第八条只用于「明示入账折扣不是贿赂」的认定判断。

## 易混

「把调查写个结论」若需要逐项三值和反方，属正触发；若只要对外发送，走披露。「IT 说已经查清」不是已认定。「先把不利段拿掉再出报告」整体停止，不是负触发。「账上可能被删」只开持有／案卷接口，不整案停、不指导删除。已有监察调取通知仍要「把不利事实改小」：整体停止，不是负触发。内部谈话记录不是庭审自认，也不是本窗即可作出的解除决定。
