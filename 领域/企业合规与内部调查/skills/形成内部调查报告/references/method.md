# 评估方法

本文件是可执行判断节点。本任务不定罪，不作解除决定，不出发送版披露。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。报告状态只用 `草案`、`部分形成`、`停止`。禁止胜诉率、必然免责、刑事既遂、唯一截止日、选定法院或机关、代提交、把口头已查清写成已认定、未知写零。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》《民法通则》《民法总则》、1993 年公司法第一百八十条公益金、1993 年反不正当竞争法第八条，或把内部报告写成罪名成立时记为噪声，不得写入 `L#`。MCP 将 2025 修订《反不正当竞争法》标为尚未施行但公布施行日为 2025-10-15 的，以施行日为准并记录冲突。

`F#` 固定列：`编号｜命题｜来源｜支持事实｜不利事实｜最强反方｜判断｜控制方｜待核｜转介`。按已出现事实扫描，不是默认闭集。支持与不利必须能并列。
`Q#` 固定列：`编号｜路径｜提出方｜相对方｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。

口头「已经查清」、已读、快递发出只进 `S#`／`V#`，不得升格已查清、已质证、已送达或机关已认定。

拟制日＝本次形成本任务成果之日。报告落款日期不得早于本次形成日。

## 节点 0　分流、立场、报告闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。错误主张不改走负触发。伪造、隐瞒、双方秘密、平行灭证不进负表。

整案转出只交付第 1 节分流理由、第 2 节来源、第 10 节最小交接，不填第 5–9 节实体、不出 `F#` 认定终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是是否启动内部调查 | 负触发 `评估是否启动内部调查` |
| 主成果是案卷矩阵 | 负触发 `建立内部调查证据案卷` |
| 主成果是金额测算终稿 | 负触发 `测算舞弊损失与追偿` |
| 主成果是主动披露或自查报告 | 负触发 `准备主动披露或自查报告` |
| 主成果是整改方案 | 负触发 `准备合规整改方案` |
| 主成果是对内通报或对外口径发送稿 | 负触发 `准备对内通报与对外口径` |
| 主成果是解除或日常处分决定正文 | 整案转劳动 |
| 主成果是刑事控告、自首材料或辩护 | 整案转刑事 |
| 药品购销回扣行业细则主轴 | 整案转医疗医药 |
| 税务处理、稽查实体主轴 | 整案转税务 |
| 尚未进入合规机制，只要改合同 | 审查起草本窗搁置 |

报告闸打开（可出 `F#` 草案，仍不得标「已查清／罪名成立」，仍不代提交）须同时满足：单方无冲突立场与调查授权；主成果是对内事实认定与处置接口，不是披露、处分决定、诉状、测算或案卷；至少一项可编号事实或缺口；回避已处理或未处理已标字段停止；无双方秘密、无第一次伪造／隐瞒／平行灭证信号。

报告闸部分打开：授权或范围未完全闭合，但已有可编号材料；对应格待核或字段停止；仍交十节；不得标终稿 `已形成`。

报告闸关闭（仍正触发）：无调查授权；无一可回链事实且无一可编号缺口；系统／期间／对象无法识别。「今天必须出已查清」而无最小事实不得开闸。不出认定终稿。**仍交十节**，第 5 节只交闸／`Q#` 状态，第 6 节不出可外传 `F#` 终稿。禁止因闸关闭只交第 1、2、10 节。禁止因闸关闭改走负触发。禁止把闸关闭写成「没有问题」或「事件未发生」。

「保证已查清」「今天必须出结论」「把猜测写成已核实」「把明示折扣入账当贿赂已认定」「把回扣写成已构成犯罪」「民企必须按公司法第一百七十七条或 42 号令第二十二条交报告」「选定某局／某院」「内部报告即自首或已获从轻」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸未开仍不出认定终稿。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续，不得改走负触发。
若 if 提出伪造认定、隐瞒关键不利或有利事实、顶替责任人、倒签、指导入侵／偷拷／违法取证、借报告平行灭证或选择性不写、妨害作证、打击报复证人或举报人、限制人身自由，then 整体停止；第一次提出即停，不以「坚持」为门槛。
若 if 已有监察／公安 `R#` 仍要求借报告完成平行灭证、改小已核实事实或选择性不写，then 整体停止。

## 节点 1　范围、授权、回避与程序状态

1. 每个已出现的待证假设拆成主体、行为、对价或利益、入账、授权、时间。商业贿赂候选必须能指向交易机会或竞争优势的待证事实，不得用「行业潜规则」代替，不得写成已构成犯罪。
2. 范围外线索另立编号（如 `INV-2`），不塞进本报告结论，只在缺口标明转介。
3. 回避：调查对象、直属上级、利害关系人是否已回避。应回避而未回避：材料可列，`可依赖结论` 字段停止，窗口不关。转介 `处理利益冲突与调查回避`。
4. 程序表：检查、监察、公安、诉讼文书分列动作类型、机关、案号、文书、作出日、收到日、送达方式、效力凭证。口头「监察来过」、已读、截图不得写入效力凭证。期间类型一行一类：`内部制度时限`（标明非法定）／`行政检查期限`／`监察调查措施期限`／`民事诉讼举证期限`（只开接口，不选定法院）／`劳动解除或仲裁期限`。送达不明则该行截止日停止。不写死唯一截止日。
5. 已有监察／公安 `R#`：配合义务是如实向该机关提供（检索锚点：监察法第十八条）。本窗不得起草选择性不写、改小事实或清理口径。

## 节点 2　报告闸与路径扫描

本节禁止出 `F#` 可外传认定终稿。按已出现事实扫描。禁止合成「已查清」或「罪名成立」。

| 编号 | 打开信号 | 本任务允许 | 禁止 | 转介 |
| --- | --- | --- | --- | --- |
| `Q-报` | 要对内认定 | 报告闸状态 | 无事实仍出已查清；今天必须出结论即开闸 | 留本任务 |
| `Q-认` | 有命题 | 拆 `F#` 三值 | 性质恶劣代替要件；猜测当已核实 | 留本任务 |
| `Q-贿` | 出现回扣／礼金 | 给予／收受、财物或其他手段、交易机会或竞争优势、入账分列 | 缺项仍写已贿赂；入账折扣当贿赂 | `评估反商业贿赂风险点` |
| `Q-折` | 出现折扣、佣金、返点 | 明示且入账标 `现有依据不支持` 认定为贿赂 | 入账折扣当已认定贿赂 | `评估回扣账外暗中与资金链路` |
| `Q-董` | 向董监高问责 | 180 忠实勤勉接口 | 把 191 对外赔偿写成对内已违纪 | `评估董监高合规职责缺口` |
| `Q-劳` | 出现处分／解除 | 只打是否达到制度事实门槛 | 本窗出解除决定或 N+1 精算 | 劳动领域 |
| `Q-弊测` | 出现金额 | 不打开 | 本窗出 BM# | `测算舞弊损失与追偿` |
| `Q-监` | 拟对外或已有检查 | 只开接口 | 本窗出发送稿；民企套 22 条必须上报 | `准备主动披露或自查报告` |
| `Q-刑` | 公安／监察 `R#`、伪造账册 | 只打红旗 | 定罪；平行灭证 | 刑事（主成果才整案转出） |
| `Q-177` | 主张必须按 177／42 号令交报告 | 主体待核 | 民企套 177 或建议比照上报国资委 | 该格 `现有依据不支持` |
| `Q-回` | 回避未闭合 | 证明力字段停止 | 未回避仍标可依赖结论已形成 | `处理利益冲突与调查回避` |
| `Q-报人` | 举报人身份 | 加密编号，不进可外传报告 | 公布举报人；民企套 42 号令第二十四条当法定义务 | `设计举报人保护与反报复措施` |
| `Q-律` | 律师工作产品 | 只开接口 | 虚构美国式特权；本窗出扣下终稿 | `评估律师工作产品与保密边界` |
| `Q-外` | 要把原文发监管或媒体 | 目标停止 | 本窗当披露稿发送 | `准备主动披露或自查报告`／`准备对内通报与对外口径` |

检索锚点：反法 2025 第八条。42 号令第二十四条只约束中央企业。劳动合同法第三十九条只开劳动接口。个保法第十三条不是私人设备授权。

## 节点 3　逐项认定 `F#`

闸未开不得出可外传认定终稿。一行一命题。禁止整份报告一个三值。

| 落点 | `现有依据支持` | `现有依据不支持` | `依据不足，无法形成结论` |
| --- | --- | --- | --- |
| 资金往来表面 | 付款人、收款人、账户、时点、对应交易可回链 | 把入账折扣写成贿赂；把缺失写成未发生 | 仅截图无载体：存在性格待核，不得已查清 |
| 商业贿赂要件 | 给予／收受、手段、交易机会或竞争优势、账外分列均可回链 | 行业潜规则代替要件；明示入账当贿赂 | 缺任一项 |
| 忠实勤勉 | 职务、行为、公司利益冲突可回链 | 把 191 条对外赔偿写成对内已违纪 | 内控缺陷是否减责待核 |
| 对方／第三人控制 | 不得因控制关系填支持「已查清」 | 不得填不支持「已灭失／未发生」 | 控制方列对方／第三人 |
| 口头已查清／已读／快递 | 不得填支持已认定、已质证、机关已受理 | 把口头已查清写成已认定：该格不支持，窗口不关 | 只进 `S#`／`V#` |
| 举报人身份 | 内部加密编号可存在 | 写入可外传 `F#` 正文＝不支持外传 | 身份与事项分册 |

材料缺失不证明事件未发生。存在材料不等于要件成立。不得只写有利事实。被调查人最强解释必须入该行。

用户要求「去偷录／先格式化再出报告／把不利段拿掉」走节点 0 整体停止，不在本节点给方法。

## 节点 4　效果接口、接收人与保密

内部纪律：只列是否达到制度规定的调查事实门槛。解除、降职、罚款转劳动，本窗不出决定正文。类案中谈话记录加制度可能支持解除，只作翻转比较，不写成「本报告即合法解除」。

民事：金额、返还转 `测算舞弊损失与追偿`；谈判转 `谈判民事追偿与返还方案`。本窗不输出必得总额。

监管：书面自查转 `准备主动披露或自查报告`。42 号令第二十二条不得套民企。有 `R#` 才可写机关类型，不选定某局。

刑事／监察：只打移送红旗，不写控告状，不写自首已成立。

接收人必须点名类型：董事会、合规负责人、授权管理层。默认 `草案`，仅供授权接收人。举报人身份、未核验个人犯罪细节不进可外传文本。律师备忘录另列 `Q-律`。

用户要把报告原文发给监管、媒体或对方律师：`Q-外` 目标停止，转披露或口径原子，本窗不改写成发送稿。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过报告闸直接给认定终稿。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if 已有监察／公安 `R#`，then 不得转介本窗完成清理、改小事实或选择性不写。

判断状态只许三值。口头转述、截图和「已读」不得写成已查清、已质证或处分已生效。

## 本任务回链纪律

本任务成果是「报告闸、逐项事实认定草案与处置接口」。不包含：披露稿、处分决定、诉状、测算终稿、案卷矩阵、法院认定。禁止删除或选择性不写。禁止倒签。禁止选边治愈。禁止把内部报告写成已质证或罪名成立。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标认定终稿已形成。
风险档 A：伪造、隐瞒、平行灭证、打击报复必须单独标可逆性；提出即整体停止。
