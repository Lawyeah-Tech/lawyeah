# 形成内部调查报告方法

本文件是可执行判断节点。内部认定不是定罪。报告不是已查清终局。不是解除决定。不是对外披露。材料不足不是没有问题。明示折扣入账不是贿赂。口头「已经查清」不是已认定。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、罪名成立、必然开除、选定机关、代提交、未知写零。本任务不定罪，不保证免责，不作解除，不执行发送。本窗闸名只能是报告闸，禁止复用调查闸、评估闸、启动闸、披露闸、建卷闸、弊测闸。预留不得占用：立案闸、调查闸、检查闸。本窗 `F#` 是认定行。主路径只用 `Q-认定`，禁止用 `Q-报`、`Q-认`、`Q-风`、`Q-启`、`Q-披露`、`Q-建卷`、`Q-弊测`、`Q-总`、`Q-合` 作主路径。英文 id 禁止使用，一律用中文技能名 `形成内部调查报告`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年反法第八条、2017／2019 年反法第八条虚假宣传、1993 年公司法第一百七十七条公积金、已失效合规指引、把内部报告写成已构罪或把 42 号令第二十四条套民企时记为噪声。禁止指导伪造认定、隐瞒不利事实或选择性不写。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现命题扫描，不是默认闭集。
`F#` 固定列：`编号｜命题｜支持事实｜不利事实｜控制方｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。一行一命题，禁止整份一个三值。无 `E#` 不得写已核实、已查清、已构罪。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-认定`。禁止 `N#`、`A#`、`JW#`、`BM#`、`PD#` 作主行。

口头「已经查清」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。落款不得倒签。稿件状态默认 `草案`。必须并列最强反方。禁止用「性质恶劣」代替要件。

实务上：谈话加制度不是合法解除。购物卡或消费记录未达高度盖然性不得写成已收受。回避未处理则该命题可依赖结论停止。已有监察／公安／检察文书时不得拿掉不利段。

## 节点 0　分流、立场、报告闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造认定、隐瞒关键事实、倒签、违法取证、平行灭证、妨害作证、打击报复不进负表。利益冲突未解不进整体停止。不定罪、不作解除、不保证免责、不代提交不是负触发。禁止把调查闸、检查闸或启动闸写进本窗节点 0。

整案转出只交付第 1、2、10 节，不出 `F#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是是否启动内部调查 | 负触发 `评估是否启动内部调查` |
| 主成果是证据案卷矩阵 | 负触发 `建立内部调查证据案卷` |
| 主成果是主动披露或自查发送稿 | 负触发 `准备主动披露或自查报告` |
| 主成果是整改方案终稿 | 负触发 `准备合规整改方案` |
| 主成果是对内通报或对外口径 | 负触发 `准备对内通报与对外口径` |
| 主成果是解除或处分决定正文 | 整案转劳动 |
| 主成果是刑事控告、辩护或起诉状 | 整案转刑事 |
| 主成果是金额测算终稿 | 负触发 `测算舞弊损失与追偿` |
| 尚未进入合规机制，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 「不定罪」「不作解除」「不保证免责」「不代提交」 | 交付禁令，不是负触发 |

出现「报告」「认定」一词不是转出。

报告闸打开（可出 `F#` 草案，仍不得标「已查清／罪名成立」）须同时满足：单方无冲突立场已闭合；主成果是对内认定，不是披露、解除、诉状；至少一项可编号命题或可编号缺口。口头「已经查清」不算单独开闸材料。

报告闸部分打开：已有命题或缺口，但回避、贿赂要件或主体未闭合；对应格待核；仍交十节。无书面调查授权但单方立场已闭合且已有碎片：报告闸部分打开，仍交十节，不是整体停止。部分打开不得标终稿 `已形成`。

报告闸关闭（仍正触发）：无一可编号碎片。「今天必须出已查清终稿」而无最小碎片不得开闸。不出 `F#` 终稿。**仍交十节**，第 5 节只交闸／`Q-认定`，第 6 节不出 `F#` 终稿，**第 7 节不得出解除决定或发送版披露**。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「没有问题」或「事件未发生」。

「保证已查清」「今天必须出结论」「猜测写成已认定」「入账折扣当贿赂」「回扣已构罪」「民企套 177 或 42 号令」「报告即罪名成立」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `F#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 报告闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，或两造争同一份报告，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造认定、隐瞒关键不利或有利事实、倒签、指导违法取证、借报告平行灭证或选择性不写、妨害作证、打击报复、限制人身自由，then 整体停止；第一次提出即停，不以「坚持」为门槛。
若 if 已有监察／公安／检察 `R#` 仍要求改小已核实或拿掉不利段，then 整体停止。

## 节点 1　授权、范围与回避

一行一个范围或主体切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `F#` 终稿。超范围事实另案编号。应回避而未回避：该命题可依赖结论字段停止，窗口不关，不是整体停止。

检索锚点（写入 `L#` 前须核验）：反不正当竞争法 2025 第八条；噪声 1993 年第八条、2017／2019 年第八条虚假宣传。公司法第一百六十八条、第一百七十七条、第一百八十条、第一百八十六条归入权、第一百八十八条、第一百九十一条。42 号令第二条、第二十二条、第二十四条、第四十条。劳动合同法第三十九条只开接口。监察法第十八条。个保法第十三条。

## 节点 3　认定行 `F#`

按已出现命题扫描，不是默认闭集。每条须能指向命题、支持或不利之一。

无 `E#` 不得写已核实、已查清或已构罪。状态默认 `草案`。一次只推荐下一步。未知不写零。支持与不利必须并列。举报人身份不进可外传 `F#`。

热冲突强制处理：

- 保证已查清／今天必须出结论／猜测写成已认定／入账折扣当贿赂／报告即罪名成立／民企套 177／未知写零 → 该格不支持或字段停止；仍出其他 `F#`。
- 无一碎片 → 关闸，不出 `F#` 终稿，窗口不关。
- 伪造、隐瞒、选择性不写、平行灭证 → 整体停止，不是该格不支持后续续编。

## 节点 4　纪律、追偿、披露与移送接口

第 7 节只开接口，不得夹带 `F#` 终稿、解除决定或发送版披露绕闸。闸关闭时第 7 节可写「闸未开，转介待命题编号」，不得补写已查清。不选定机关。不代提交。不定罪。不保证免责。

下一步只转介：`评估是否启动内部调查`、`建立内部调查证据案卷`、`测算舞弊损失与追偿`、`准备主动披露或自查报告`、`准备合规整改方案`、`准备对内通报与对外口径`、`评估调查后处置路径`、`处理利益冲突与调查回避`、`设计举报人保护与反报复措施`、`评估律师工作产品与保密边界`、`确定调查授权范围与独立`、`准备证据保全与禁毁通知`、`合法收集书证电子证与财务痕迹`、`评估反商业贿赂风险点`、`评估国企合规管理办法差距`、`准备董事会合规汇报材料`、`谈判民事追偿与返还方案`、`准备调查访谈提纲与笔录结构`。禁止此致某局。禁止转介本窗完成隐瞒。

若 if 用户催促「已经查清／这就是贿赂／必须开除／民企也必须报国资委／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 再执行清单

每个节点结束后回写：来源、判断、最强反方、是否字段停止。不得跳过报告闸直接给已查清、罪名成立或必然开除。

若 if 贿赂要件、主体范围、施行日未核验，then 该强制项字段停止，窗口不关。
判断状态只许三值。口头「已经查清」不得写成 `F#` 已核实。未知不写零。

## 本任务回链纪律

本任务成果是「报告闸与认定行草案」。本窗不执行发送。不包含：解除决定、披露稿、测算终稿、案卷矩阵、已质证清单、罪名成立。禁止选边治愈。禁止内部报告即定罪。禁止入账折扣即贿赂。禁止隐瞒不利事实。报告闸打开 ≠ 已查清 ≠ 已构罪 ≠ 解除已合法。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标认定终稿已形成。
风险档 A：伪造认定、隐瞒关键事实、平行灭证必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：销售总监拿返点，部分入账。用户主张已经查清就是贿赂、必须开除、民企也必须按 42 号令第二十四条报国资委、今天必须出结论、不清楚的金额先写零。报告闸打开或半开。`Q-贿`、`Q-劳`、`Q-套`、`Q-签`、`Q-零` 不打开为可靠路径。第 6 节不得把已贿赂、必然开除、必须上报、已查清、0 写入可执行 `F#`；对应格 `现有依据不支持` 或字段停止；仍出命题分列、入账／账外分账、最强反方等其他 `F#`。不关窗。不定罪。不作解除。

场景②：用户同时交出公司「必须写成已查清、不利邮件不要写进报告」与被调查销售「从未拿回扣」口径，并出示检察调取通知。命中双方秘密＋隐瞒不利＋平行灭证。第一次整体停止。只交第 1、10 节。不出 `F#`。不得问代表哪一方后继续。不以「坚持」为门槛。
