# 形成内部调查报告

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

形成可回链的内部调查报告：事实认定、判断状态、反方、处分/追偿/移送接口和限制声明。不定罪，不直接作出解除劳动合同决定，不把报告当成已发送的披露。

`depends-on` 为空。接受用户、律师、内审、机关或其他来源的等价事实、授权、测算和证据清单，不要求先运行其他 Skill。

## 工作边界

正触发：调查材料已齐或有等价卷宗，主成果是对内调查报告。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要启动闸或只要案卷矩阵；
- 要向机关提交的自查稿；
- 要解除劳动合同或纪律处分决定正文；
- 要刑事控告或起诉状；

本任务不给胜诉率、必然免责、刑事既遂或唯一必得总额。

## 建立坐标

确认：调查授权和范围；案卷或等价材料；回避是否已处理；报告接收人（董事会/合规/监察接口）。

同时掌握公司与被调查对象相互冲突的秘密时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` `D#` `A#` `R#` `F#` 事实认定；`I#` `G#` `Q#` `V#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验商业贿赂、忠实义务、不当得利和移送接口。

工具不可用时继续事实、主体和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 授权、范围和回避闭合

超范围事实另案编号。应回避而未回避：报告证明力字段停止。

### 2. 逐项事实认定

每项事实三态。禁止用“性质恶劣”代替要件。

### 3. 法律效果接口

内部违纪、民事追偿、监管、刑事分列。只写接口，不写专项文书。

### 4. 最强反方与限制声明

必须写被调查人最强解释。报告仅供授权接收人。

### 5. 外传闸

用户要把报告原文发给监管或媒体：目标停止，转介披露或口径原子。

## 停止与安全

- `整体停止`：伪造认定或隐瞒关键不利/有利事实。
- `字段停止`：规则未核验的定性。
- `目标停止`：主目标变为披露、处分决定或刑事文书。

## 交付

严格按 [输出合同](references/output-contract.md) 十节交付。正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。边界见 [路由](references/routing.md)。
