# 形成内部调查报告

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《民法通则》《民法总则》或其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成对内调查报告草案：报告闸、`Q#` 路径、`F#` 逐项事实认定（判断三值）、最强反方、内部纪律／民事追偿／监管／刑事移送接口。本任务不定罪，不直接作出解除劳动合同或纪律处分决定，不是发送版披露或自查稿，不代提交、不代发送。

`depends-on` 为空。是否启动转 `评估是否启动内部调查`。案卷转 `建立内部调查证据案卷`。金额转 `测算舞弊损失与追偿`。披露转 `准备主动披露或自查报告`。整改转 `准备合规整改方案`。口径转 `准备对内通报与对外口径`。董事会内部汇报转 `准备董事会合规汇报材料`。回避转 `处理利益冲突与调查回避`。处置路径转 `评估调查后处置路径`。

## 工作边界

正触发：需要对内形成可回链调查报告。授权、范围、回避或事实未闭合、材料未齐仍正触发：报告闸关闭，不出报告终稿，窗口不关。用户要保证已查清、今天必须出结论、把猜测写成已认定、用「性质恶劣」代替要件、把入账折扣写成贿赂、把报告写成罪名成立、民企按公司法第一百七十七条或 42 号令第二十二条／第二十四条必须上报或移交，仍正触发：对应格填 `现有依据不支持` 或字段停止，闸未开则不出报告终稿，窗口不关。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是是否启动内部调查（转 `评估是否启动内部调查`）；
- 主成果是证据案卷矩阵（转 `建立内部调查证据案卷`）；
- 主成果是向机关主动披露或自查报告发送稿（转 `准备主动披露或自查报告`）；
- 主成果是整改方案终稿（转 `准备合规整改方案`）；
- 主成果是对内通报或对外口径发送稿（转 `准备对内通报与对外口径`）；
- 主成果是解除劳动合同或纪律处分决定正文（转劳动领域）；
- 主成果是刑事控告、辩护或起诉状（转刑事领域）；
- 主成果是金额测算终稿（转 `测算舞弊损失与追偿`）。

双方秘密、伪造认定、隐瞒关键不利或有利事实、倒签、指导违法取证凑结论**不在负触发表**，走整体停止。「保证已查清」「今天必须出结论」「把报告写成罪名成立」**不在负触发表**，只关对应格，窗口不关。

## 建立工作坐标

确认：调查授权和范围；单方立场（公司／被调查对象，互斥）；案卷或等价材料；回避是否已处理；报告接收人（董事会／合规，不是监管机关或媒体）；是否并行监察／公安／诉讼。

口头「已经查清」「性质恶劣」「够立案了」只登记 `S#`／`V#`。不得升格已认定、罪名成立或机关已立案。

同时掌握公司与被调查对象相互冲突的秘密，或两造争同一份报告：`整体停止`，不得以选边治愈，也不得改走负触发，不得问代表哪一方后继续。公司已开口且委托范围就是对内报告、且未掌握被调查对象秘密时，可推定公司立场。提出伪造认定、隐瞒关键不利或有利事实、倒签、指导违法取证、借报告平行灭证或选择性不写：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 制度或合同；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径接口；`F#` 事实认定；`V#` 版本。禁止 `EV#`、`Dsc#`、`Ntc#`。本窗不用 `N#`（通知／披露正文）、`E#`（到达／案卷编目）或 `M#`（测算行）。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。报告状态只用 `草案`、`部分形成`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。本任务默认 `草案`。禁止「罪名成立」「必然开除」「已查清并可外传」。材料缺失不证明事件未发生。存在材料不等于要件成立。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：反不正当竞争法 2025 修订第八条（施行日 2025-10-15），明示折扣佣金如实入账不是贿赂；商业贿赂候选须分列给予／收受、财物或其他手段、交易机会或竞争优势、入账，缺一项则该效果 `依据不足，无法形成结论`。公司法董事、监事、高级管理人员忠实义务（条文运行时核验）、不得侵占公司财产、违反忠实义务所得收入应当归公司：只作内部／民事接口，本窗不定罪；第一百七十七条不是民企法定对外报告义务；第一百六十八条国家出资公司不含国有资本参股。中央企业合规管理办法报告／移交条款（常见检索第二十二条、第二十四条）只约束国资委履行出资人职责的中央企业，第四十条是对地方国资机构的参照授权，不得写成全部民企必须向国务院国资委报告或移交，不得建议比照上报。刑法职务侵占、挪用资金、行贿受贿只作移送红旗，不得写罪名成立。劳动法解除劳动合同、纪律处分决定正文不在本窗，只开接口。监察法（2024 修正）第十八条，如实提供，不得伪造、隐匿、毁灭证据；已有监察文书时不得借报告完成平行灭证或选择性不写不利事实。噪声：已失效《合同法》、入账折扣＝贿赂、内部报告＝已构罪、民企套 177 或 42 号令、用「性质恶劣」代替要件、未知写零、把对内报告写成已质证诉讼证据。MCP 若仍标 2025 反法尚未施行，以公布施行日为准并记录冲突。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变贿赂要件、主体范围或移送结论的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补内部报告不定罪、入账折扣不是贿赂、隐瞒不利事实不可用、回避未处理则结论不可依赖、内部谈话不是庭审自认的反例。
- `search_case_by_fact` 只比较事实差异与翻转条件（例如谈话记录加制度仍须劳动路径核验解除，购物卡消费记录未达高度盖然性不得写成已收受），不写成罪名或必然开除。

工具不可用时继续 `F#` 认定和缺口；法律效果、期限、机关路径字段停止。不得拒跑，不得凭记忆写成罪名成立或指导隐瞒不利事实。

## 判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、报告闸与不关窗

主成果才整案转出。伪造、隐瞒第一次停。保证已查清、今天必须出结论、猜测写成已认定、报告写成罪名成立不关窗。闸关仍交十节，第 6 节不出报告终稿。

### 2. 授权、范围与回避

超范围事实另案编号。应回避而未回避：可依赖结论字段停止，窗口不关。

### 3. 报告闸与路径 `Q#`

本节禁止出 `F#` 认定终稿。无回链材料则 `Q-报` 关闭，窗口不关。

### 4. 逐项事实认定 `F#`

闸未开不得出报告终稿。每项三值。必须并列最强反方。禁止用「性质恶劣」代替要件。

### 5. 法律效果接口与外传限制

内部纪律、民事、监管、刑事分列只开接口。要把原文发给监管或媒体：`Q-外` 不打开，转介披露或口径；主成果才是披露则负触发。不等于已经可外传。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；提出伪造认定、隐瞒关键不利或有利事实、倒签、指导违法取证、借报告平行灭证或选择性不写、妨害作证、打击报复证人或举报人、限制人身自由。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：贿赂要件、主体范围、回避、送达未核验。保证已查清、今天必须出结论、猜测写成已认定、报告写成罪名成立、入账折扣计为贿赂、民企套 177 或 42 号令：该格停止，窗口不关；闸未开仍不出报告终稿。
- `目标停止`：主目标变为披露发送稿、解除决定、刑事控告或诉状。

禁止指导伪造、隐瞒或定罪。不给胜诉率。不定罪。不选定机关。不代提交。未知不写零。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。报告闸关闭或不关窗信号仍交十节；第 6 节不出报告终稿。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。报告闸未打开时不得交付报告终稿或「罪名成立」。边界见 [路由](references/routing.md)。
