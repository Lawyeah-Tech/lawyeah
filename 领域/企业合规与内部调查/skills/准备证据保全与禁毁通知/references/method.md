# 准备证据保全与禁毁通知方法

本文件是可执行判断节点。口头备份不是已保全。已读不是到达。持有函不是民诉证据保全裁定。保存通知不是证据保全。复制或哈希不是已固定、不是已公证。草稿不是已发送。全员无边界禁毁不是可发送。倒签不是已发出。拒不提交推定诉前不当然成立。行政先行登记保存七日不是内部通知法定期限。持有函无法定答复期。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已保全、已发送、已到达、选定机关或法院、代发送、未知写零。本任务不定罪，不执行发送，不写法院或公证申请书。本窗闸名只能是持有闸，禁止复用发送闸、通知闸、保全闸、评估闸、合规闸、启动闸、争议闸、调查闸、检查闸。预留不得占用：立案闸、调查闸、检查闸、发送闸、保全闸。本窗 `LH#` 是持有行。主路径只用 `Q-持有`，禁止用 `Q-发`、`Q-函`、`Q-持`、`Q-证`、`Q-保`、`Q-禁`、`Q-风`、`Q-启`、`Q-总` 作主路径。英文 id 禁止使用，一律用中文技能名 `准备证据保全与禁毁通知`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1991 年民事诉讼法第八十四条公告送达、2017 年民事诉讼法第八十四条送达回证、2012／2017 年民事诉讼法第八十一条证据保全、2017 年行政处罚法第三十七条先行登记保存、刑法第一百六十二条妨害清算当作第一百六十二条之一、把持有函写成保全裁定或把拒不提交推定写成诉前已成立时记为噪声。禁止指导删除、格式化、藏匿、倒签或伪造回证。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现范围或红旗碎片扫描，不是默认闭集。
`LH#` 固定列：`编号｜范围切片（系统×期间×对象）｜接收人与管理员｜持有／禁毁义务｜到达渠道与回证｜打开接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已保全」或「已发送」。无 `E#` 不得写已发送、已到达、已保全。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-持有`。禁止 `N#`、`A#`、`GT#`、`QI#`、`HF#`、`RF#`。旧 `N-持`／`N-禁`／`N-IT`／`N-证` 并入 `LH#` 分行，禁止再作主行。

口头「已经备份」「今晚发出」「微信已读」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。函面、落款、寄出、拟制四类日期均不得早于本次形成日。稿件状态默认 `草案`。

实务上：诉讼外持有函是公司指示／劳动纪律候选，不产生查封扣押效力。微信已读、邮件未离开发件箱的草稿、回证未形成，都不得起算保存义务。全员无边界禁毁难执行。已有监察／公安／检察文书时配合义务是如实提供，不是企业自行全员清理。

## 节点 0　分流、立场、持有闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、删除、格式化、换机灭证、藏匿、倒签、伪造回证、打击报复、限制人身自由、平行灭证不进负表。利益冲突未解不进整体停止。不定罪、不等于法院保全、不执行发送不是负触发。禁止把调查闸、检查闸或启动闸写进本窗节点 0。

整案转出只交付第 1、2、10 节，不出 `LH#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是是否启动内部调查 | 负触发 `评估是否启动内部调查` |
| 主成果是调查报告终稿 | 负触发 `形成内部调查报告` |
| 主成果是证据卷终稿 | 负触发 `建立内部调查证据案卷` |
| 主成果是主动披露或自查报告发送稿 | 负触发 `准备主动披露或自查报告` |
| 主成果是检查现场应对 | 负触发 `应对监管检查或突击检查` |
| 主成果是账户冻结或资金止付 | 负触发 `评估内部账户冻结与资金保全` |
| 主成果是合法收集、镜像或现场取证步骤 | 负触发 `合法收集书证电子证与财务痕迹` |
| 主成果是刑事立案、控告或辩护 | 整案转刑事 |
| 主成果是劳动处分、解除或扣薪划卡 | 整案转劳动 |
| 主成果是数据出境或网安专项 | 整案转数据隐私 |
| 尚未进入合规机制，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 「不定罪」「不等于法院保全」「不执行发送」 | 交付禁令，不是负触发 |

出现「保全」「通知」「备份」一词不是转出。启动闸未开仍可因灭失风险正触发本窗。

持有闸打开（可出 `LH#` 草案，仍不得标「已发送／已到达／已保全」）须同时满足：单方无冲突立场已闭合；主成果是持有／禁毁通知，不是报告、披露或处分；至少一项可编号范围切片（系统／期间／对象至少一类可识别）；至少一名接收人或管理员可列。口头「已经备份」不算单独开闸材料。

持有闸部分打开：已有范围碎片，但期间、对象、接收人或个保基础未闭合；对应格待核；仍交十节。无书面签发授权但单方立场已闭合且已有范围碎片：持有闸部分打开，仍交十节，不是整体停止。部分打开不得出可发送终稿。

持有闸关闭（仍正触发）：范围无法识别，且接收人与管理员都不可列。「今天必须发出已保全终稿」而无最小碎片不得开闸。不出 `LH#` 终稿。**仍交十节**，第 5 节只交闸／`Q-持有`／`Q-围`，第 6 节不出 `LH#` 终稿，**第 7 节不得出发送版或已保全**。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「证据已固定」或「没有灭失风险」。

「全员一律禁毁」「今天必须发出」「口头备份即已保全」「已读即到达」「草稿即已发送」「复制哈希即已固定或已公证」「选定某局」「保证已固定」「未知写零」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `LH#` 草案。全员无范围：`Q-围` 不打开，持有闸关闭，窗口不关。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号范围且接收人与管理员都不可列，then 持有闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，或两造争同一份持有通知，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出删除、格式化、换机灭证、藏匿、选择性清理、倒签、伪造回证、打击报复、威胁证人、妨害作证、限制人身自由，then 整体停止；第一次提出即停，不以「坚持」为门槛。
若 if 已有监察／公安／检察 `R#` 仍要求发全员禁毁或清理设备，then 整体停止；不得借本窗完成平行灭证。

## 节点 1　范围、接收人与程序状态

一行一个范围切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `LH#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 范围 | 系统 × 期间 × 对象／账户／关键词分列 | 无边界一律禁毁；监察文书下扩成全员 |
| 接收人 | 岗位、是否被调查人、管理员替代分列 | 被调查人写成唯一接收人 |
| 程序 | 检查、监察、公安、检察、诉讼文书作出日、收到日、送达分列 | 口头来过升格已立案；已读升格已送达 |

检索锚点（写入 `L#` 前须核验）：民事诉讼法第八十四条。噪声 1991 年第八十四条公告送达、2017 年第八十四条送达回证、2012／2017 年第八十一条。民事诉讼法解释第一百一十二条。监察法第十八条。刑事诉讼法第五十四条。行政处罚法第五十六条。刑法第一百六十二条之一、第三百零七条、第三百零八条。会计法第二十三条。个人信息保护法第十三条。劳动合同法第九条。劳动法第一百零一条只作停止红旗。

已有法院证据保全裁定 `R#` 时，范围不得超过裁定载明的系统、期间和对象，仍不得扩成全员。监察／公安／检察文书不是打开全员禁毁或清理设备的授权。接收人是唯一被调查人且无回避：必须另列信息技术或合规管理员。

期间类型必须点名、一行一类：`内部制度时限`（答复期标明非法定）／`会计资料法定保存期限`（只待核）／`行政先行登记保存期限`（噪声，不得写入内部通知）／`行政检查期限`／`监察调查措施期限`／`民事诉讼证据保全期限`（只开接口，字段停止）／`劳动解除或仲裁期限`／`刑事追诉时效`。送达不明则该行截止日停止。未知不写零，不写死唯一截止日。

## 节点 3　持有行 `LH#`

按已出现范围或红旗碎片扫描，不是默认闭集。每条须能指向范围切片、接收人、持有／禁毁义务或到达渠道之一。

无 `E#` 不得写已发送、已到达或已保全。状态默认 `草案`。一次只推荐下一步。未知不写零。已有监察／公安／检察 `R#`：配合义务是如实向该机关提供；全员禁毁行不打开。

热冲突强制处理：

- 全员无范围／今天必须发出／口头备份即已保全／已读即到达／草稿即已发送／复制即已固定／保证已固定／选定某局／未知写零 → 该格不支持或字段停止；仍出其他 `LH#`。
- 无一范围且接收人与管理员都不可列 → 关闸，不出 `LH#` 终稿，窗口不关。
- 指导删除、格式化、藏匿、倒签、伪造回证、打击报复、平行灭证 → 整体停止，不是该格不支持。

到达：每次预列实施人、文本版本、渠道、回证设计。微信已读、孤立截图、口头转述、邮件未离开发件箱的草稿、回证未形成，都不得升已到达，也不得据此起算保存义务。劳动合同或员工手册送达条款只作候选，运行时核验，不得把内部到达写成诉讼期间起算。民诉第九十条电子送达只适用于人民法院送达诉讼文书。本任务不执行发送，不补造回证。

## 节点 4　收集、案卷、检查与资金接口

第 7 节只开接口，不得夹带 `LH#` 终稿、调查报告或发送版绕闸。闸关闭时第 7 节可写「闸未开，转介待范围编号」，不得补写已保全。不选定机关。不代发送。不定罪。已有监察／公安／检察 `R#` 时不得打开全员禁毁接口。法院证据保全申请与公证本包无对应原子：字段停止，不选定法院或公证处。账户止付只转 `评估内部账户冻结与资金保全`，不得与法院证据保全搅在一句。

下一步只转介：`评估是否启动内部调查`、`建立内部调查证据案卷`、`合法收集书证电子证与财务痕迹`、`评估企业合规风险总图`、`应对监管检查或突击检查`、`准备主动披露或自查报告`、`确定调查授权范围与独立`、`处理利益冲突与调查回避`、`评估内部账户冻结与资金保全`、`形成内部调查报告`、`设计举报人保护与反报复措施`、`评估打击报复风险`、`评估单件举报可查性`、`制定调查方案与访谈计划`、`评估律师工作产品与保密边界`、`准备调查访谈提纲与笔录结构`、`协调跨境内部调查并分流涉外`。禁止此致某局。禁止转介本窗完成毁证。

若 if 用户催促「已经备份就是保全／已读就是到达／今天必须发出／全员一律禁毁／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「持有闸与持有行草案」。本窗不执行发送。不包含：调查报告、披露稿、处分决定、账户冻结、法院保全裁定、已保全证明。禁止选边治愈。禁止口头备份即已保全。禁止已读即到达。禁止指导删除或平行灭证。持有闸打开 ≠ 已发送 ≠ 已到达 ≠ 已保全 ≠ 法院裁定。
