# 评估方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。通知状态只用 `草案`、`待发送`、`已发送待证明到达`、`停止`。禁止胜诉率、必然免责、刑事既遂、唯一截止日、选定机关或法院、代发送、把口头备份写成已保全、未知写零。本任务不定罪，不执行发送。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、把持有函写成民诉证据保全裁定、把行政先行登记保存七日写成内部通知法定期限、把拒不提交推定写成诉前已成立时记为噪声。禁止指导删除、格式化、藏匿、倒签或伪造回证。

`N#` 固定列：`版本｜状态（草案/待发送/停止）｜签发主体｜接收人｜系统×期间×对象｜持有义务｜禁止销毁篡改｜禁止自行接触证人｜IT备份接口｜答复渠道（标明非法定）｜禁止夹带结论/罪名/倒签｜来源回链`。
`E#` 固定列：`实施人｜文本版本｜渠道｜地址｜回证｜失败升级（只点转介名）`。一行一个接收人。
`Q#` 固定列：`编号｜路径｜提出方｜相对方｜法律效果假设｜成立条件｜支持事实｜不利事实｜控制方／证明负担红旗｜最强反方｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。

拟制日＝本次形成本任务成果之日。函面、落款、寄出、拟制四类日期均不得早于本次形成日。

口头「已经备份」、已读只进 `S#`／`V#`，不得升格已保全、已送达。

## 节点 0　分流、立场、发送闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。错误主张不改走负触发。删除、格式化、藏匿不进负表。

整案转出只交付第 1 节分流理由、第 2 节来源、第 10 节最小交接，不填第 5–9 节实体、不出 `N#` 发送前终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是是否启动内部调查 | 负触发 `评估是否启动内部调查` |
| 主成果是调查报告终稿 | 负触发 `形成内部调查报告` |
| 主成果是证据卷终稿 | 负触发 `建立内部调查证据案卷` |
| 主成果是主动披露或自查报告 | 负触发 `准备主动披露或自查报告` |
| 主成果是检查现场应对 | 负触发 `应对监管检查或突击检查` |
| 主成果是账户冻结或资金止付 | 负触发 `评估内部账户冻结与资金保全` |
| 侦查、起诉、审判、辩护、控告为主成果 | 整案转刑事；持有接口可留时刑事段只红旗 |
| 劳动处分、解除、扣薪划卡为主成果 | 整案转劳动 |
| 个人信息、数据出境、网安专项体系为主成果 | 整案转数据隐私 |
| 垄断、滥用支配、经营者集中为主成果 | 整案转竞争法 |
| 尚未进入合规机制，只要改合同 | 审查起草本窗搁置 |

发送闸打开（可出 `N#` 待发送草案，仍不执行发送）须同时满足：单方无冲突立场与签发授权；存在具体线索、检查或诉讼威胁，而非年度例行；范围可用系统／期间／对象识别；至少一名接收人或管理员可列；主成果是持有／禁毁通知，不是报告、披露或处分。

发送闸关闭（仍正触发）：范围无法识别；接收人无线索且无管理员替代；无签发授权。不出发送前终稿。十节表头可保留；第 6 节不得出可发送正文。禁止因闸关闭改走负触发。禁止把闸关闭写成「证据已固定」或「没有灭失风险」。

「全员一律禁毁」「今天必须发出」「口头备份即已保全」「已读即到达」「选定某局」「保证已固定」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸未开仍不出发送前终稿。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续，不得改走负触发。
若 if 提出删除、格式化、换机、藏匿、选择性清理、倒签、伪造回证、报复接收人或举报人、限制人身自由，then 整体停止；第一次提出即停，不以「坚持」为门槛。
若 if 已有监察／公安 `R#` 仍要求发全员禁毁或清理设备，then 整体停止；不得借本窗完成平行灭证。

## 节点 1　范围、接收人与程序状态

1. 范围用「系统 × 期间 × 对象／账户／关键词」闭合。禁止无边界「全部资料一律不得删除」，除非用户材料给出对等的监管或诉讼保全文书 `R#`。用户要全员禁毁而无范围：`Q-围` 不打开，发送闸关闭，窗口不关。
2. 接收人与管理员分列。接收人是唯一被调查人且无回避方案：必须另列信息技术或合规管理员接收，`Q-避` 待核。不得把被调查人写成唯一接收人。
3. 程序表：检查、监察、公安、诉讼文书分列机关、案号、文书、作出日、收到日、送达方式、效力凭证。口头「监察来过」、已读不得升格已立案或期限已起算。
4. 已有监察／公安 `R#`：配合义务是如实向该机关提供（检索锚点：监察法第十八条）。本窗不得起草全员禁毁、清理无关设备或格式化口径。`Q-监` 打开红旗，`N-禁` 全员行不打开。

## 节点 2　发送前正文与路径扫描

按已出现事实扫描。禁止合成「证据已保全」一笔。

| 编号 | 打开信号 | 本任务允许 | 禁止 | 转介 |
| --- | --- | --- | --- | --- |
| `Q-发` | 授权、线索、范围、接收人可编号 | 发送闸状态 | 无范围仍出可发送终稿；今天必须发即开闸 | 留本任务 |
| `Q-围` | 拟划范围 | 系统×期间×对象 | 无边界全员；全盘拷贝 | 留本任务 |
| `N-持` | 闸开且范围可写 | 持有义务草案 | 写成已保全 | 留本任务 |
| `N-禁` | 闸开且无毁证请求 | 禁止销毁篡改 | 给删除步骤；监察文书下全员禁毁 | 留本任务 |
| `N-IT` | 需管理员备份 | 备份接口、待核状态 | 口头备份即已完成 | `合法收集书证电子证与财务痕迹` |
| `N-证` | 存在被指向人或证人 | 禁止自行接触证人 | 公布举报人；要求认罪书 | `准备调查访谈提纲与笔录结构` |
| `Q-达` | 需到达设计 | 最小 `E#` | 已读即到达；补造回证 | 留本任务 |
| `Q-劳` | 停职、扣私人设备、扣薪 | 只标劳动红旗 | 本通知直接实施 | 劳动领域 |
| `Q-数` | 全员邮箱、定位、生物识别 | 合法基础待核 | 通知授权违法监控 | 数据隐私 |
| `Q-监` | 监察／公安 `R#` | 如实提供红旗 | 平行灭证；全员清理 | 刑事领域（主成果才整案转出） |
| `Q-院` | 可能需要法院保全 | 只开接口 | 写成已准许；选定某院 | 评估内部账户冻结以外的法院路径只标接口；民事保全申请不在本包则字段停止 |
| `Q-账` | 要停账户或划卡 | 不打开 | 把止付写进持有通知 | `评估内部账户冻结与资金保全` |
| `Q-报` | 对接收人／举报人调岗或扬言报复 | 只标停 | 写进通知当调查步骤 | `设计举报人保护与反报复措施`；提出即整体停止 |

检索锚点：民事诉讼法关于证据可能灭失或以后难以取得时申请保全的条款（条号运行时核验）。本窗持有通知不是裁定，不产生查封扣押效力。诉讼中责令提交及无正当理由拒不提交的推定，以诉讼中法院责令为前提，诉前持有函不得写成已成立。行政先行登记保存「七日」不得写成内部通知法定期限。

允许写入正文：持有义务、禁止销毁篡改、立即停止自行接触证人、向指定邮箱报告已持有材料、违反可能导致纪律或法律责任（不写罪名既遂）。禁止：点名定罪、公布举报人、要求认罪书、倒签、授权违法取证、保证已固定。

## 节点 3　到达设计

每次发送预列实施人、文本版本、渠道、回证、失败升级。劳动合同或员工手册中的送达条款只作候选，运行时核验。微信已读、孤立截图、口头转述最多升到 `已发送待证明到达`，不得升已到达，也不得据此起算保存义务或覆盖倒计时。本任务不执行发送，不补造回证。

失败升级只点转介名：`合法收集书证电子证与财务痕迹`、`建立内部调查证据案卷`、`评估是否启动内部调查`。法院证据保全申请不在本包则字段停止，不选定法院。

## 节点 4　劳动、数据与资金边界

扣押个人手机、强制交出私人账号、停职停薪：本通知不得直接实施，转劳动。批量导出员工通讯录或客户个人信息：转数据，本任务只标接口。停付公司应付款或冻结账户：转 `评估内部账户冻结与资金保全`，不得把扣薪或划卡写进持有通知。

任何字段不得把「待发送」写成「已保全」。备份任务未完成的，备份状态单独一行待核。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过发送闸直接给发送前终稿。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if 已有监察／公安 `R#`，then `N-禁` 全员行不打开，不得转介本窗完成清理。

判断状态只许三值。口头转述、截图和「已读」不得写成已保全、已送达或保存义务已激活。

## 本任务回链纪律

本任务成果是「发送前对内持有／禁毁通知与最小到达设计」。不包含：调查报告、披露稿、处分决定、账户冻结、法院保全裁定、合法收集步骤终稿。禁止删除步骤。禁止倒签。禁止选边治愈。禁止把持有函写成已保全。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标发送前终稿已形成。
风险档 A：删除、藏匿、报复、平行灭证必须单独标可逆性；提出即整体停止。
