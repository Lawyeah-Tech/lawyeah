# 持有通知方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。通知状态只用 `草案`、`待发送`、`发送闸关闭`、`已发送待证明到达`、`停止`。禁止胜诉率、必然免责、刑事既遂、把口头备份写成已保全、把已读写成到达、唯一截止日、选定机关、代发送、未知写零。本任务不定罪，不代发送，不补造回证。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、把口头备份写成已保全、把微信已读写成已到达、把无边界一律禁毁写成当然有效、把刑法摘要写成已构成隐匿销毁会计资料罪时记为噪声，不得写入 `L#`。禁止指导删除、格式化、藏匿、伪造备份或阻挠检查。

`Ntc#` 固定列：`编号｜接收人（岗位／个人，被调查人与管理员分列）｜签发主体｜范围（系统×期间×项目或账户）｜禁止动作（持有／禁毁／禁止自行接触证人／报告IT）｜渠道｜回证设计｜已读不得填到达｜备份任务（待核，口头备份不得填已完成）｜判断三值｜通知状态｜待核｜转介｜来源回链`。没有接收和范围事实，禁止写「证据已固定」。

口头「已经备份」、微信已读只进 `S#`／`V#`，不得升格 `E#` 已到达或备份已完成。

## 节点 0　分流、立场、发送闸与不关窗

整案转出或闸关闭只交付第 1、2、10 节或标注停止的 `Ntc#`，不得交付待发送终稿或已保全。闸部分打开时：仅对可回链的接收人和范围行给出草案，其余行停止或不打开。

| 信号 | 处理 |
| --- | --- |
| 主成果是是否启动内部调查 | 负触发 `评估是否启动内部调查` |
| 主成果是调查证据卷 | 负触发 `建立内部调查证据案卷` |
| 主成果是调查报告 | 负触发 `形成内部调查报告` |
| 主成果是向机关披露或自查报告 | 负触发 `准备主动披露或自查报告` |
| 主成果是账户止付或资金保全 | 负触发 `评估内部账户冻结与资金保全`；未安装则 `unavailable` |
| 主成果是检查应对 | 负触发 `应对监管检查或突击检查` |
| 主成果是扣个人手机、停职停薪或解除 | 整案转劳动或负触发劳动；持有通知可留时劳动段分流 |
| 批量导出通讯录、客户信息或网安专项 | 数据字段停止并转介数据隐私；主成果是专项体系则整案转出 |
| 侦查、起诉、辩护且不要企业持有通知 | 整案转刑事 |
| 提出删除、格式化、藏匿、选择性清理 | **整体停止**，不转介方法 |
| 无任何范围却要保证已保全或先发全员 | **正触发**，发送闸关，窗口不关 |

发送闸打开（可出 `Ntc#` 草案，仍不代发送）须同时满足：单方无冲突企业立场与签发授权；存在具体线索、检查或诉讼威胁，而非年度例行；范围可用系统／期间／项目识别；接收人可编号。用户要先发全员再想范围、口头备份即已保全、已读即到达、无边界一律禁毁、保证已固定：**仍开闸**（有可识别范围时），只关对应格。指导删除、藏匿、倒签、报复不在开闸清单，走整体停止。

「先发全员再想范围」「口头备份即已保全」「已读即到达」「保证已固定」「无边界一律禁毁」**不关窗**。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握企业与被指向人相互冲突的秘密，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出删除、格式化、换设备、藏匿、选择性清理、伪造备份、倒签日期、打击报复接收人、阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　授权、接收人与回避

打开发送闸的授权条件：

1. 单方企业立场与签发授权可回链；
2. 存在具体线索、检查或诉讼威胁，而非年度例行；
3. 范围可用系统／期间／项目识别；
4. 接收人不是唯一被调查人且无回避方案时，须另列管理员接收。

缺一项则发送闸关闭或该行停止，窗口不关，只输出缺口，不产出发送前终稿。

---

## 节点 2　范围

按系统 × 期间 × 项目／账户列范围。禁止「全部资料一律不得删除」而无边界，除非已有对等的监管或诉讼保全文书。无文书：该格 `现有依据不支持`，窗口不关。未知范围不写「全公司」。

---

## 节点 3　正文约束

允许：持有义务、禁止销毁篡改、立即停止自行接触证人、向指定邮箱报告已持有材料、违反可能导致纪律或法律风险（不写罪名既遂）。

禁止：点名定罪、公布举报人、要求被调查人写认罪书、倒签日期、授权违法取证或全员监控。

检索锚点：隐匿或故意销毁依法应当保存的会计凭证、会计账簿、财务会计报告，情节严重的，只作红旗，本窗不定罪，通知不得写成指导删除。会计法关于依法保存会计资料的义务可作持有理由待核。

---

## 节点 4　到达与留痕

每次发送预列实施人、文本版本、渠道、回证、失败升级。劳动合同或员工手册中的送达条款只作候选，运行时核验。微信已读 ≠ 到达。电子到达以可核验的系统到达为准，已读截图不得填 `E#`。本任务不补造回证，不代发送。备份任务未完成的，备份状态单独一行待核；口头「已经备份」不得填已完成。

任何字段不得把「待发送」写成「已保全」。

---

## 节点 5　劳动、数据、检查边界

扣押个人手机、强制交出私人账号、停职停薪：本通知不得直接实施，转劳动。批量导出员工通讯录或客户个人信息：转数据，本任务只标接口。检索锚点：个人信息保护法，人力资源管理所必需不等于授权全员监控或批量导出。

已有监察或行政检查 `R#`：内部通知不得对抗合法检查，不得授权藏匿或选择性提交。口头「有人来过」不够打开检查配合格。

账户止付、划卡、扣薪不得写入持有通知，转 `评估内部账户冻结与资金保全`。

| 接口 | 本窗 | 转介 |
| --- | --- | --- |
| 是否调查 | 负触发 | `评估是否启动内部调查` |
| 案卷 | 负触发 | `建立内部调查证据案卷` |
| 合法收集 | 只转介 | `合法收集书证电子证与财务痕迹` |
| 披露 | 负触发 | `准备主动披露或自查报告` |
| 检查应对 | 负触发或红旗 | `应对监管检查或突击检查` |
| 资金冻结 | 负触发 | `评估内部账户冻结与资金保全` |

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过发送闸直接给已保全、已读即到达或指导删除。

若 if 日期、送达或动态规则未核验，then 依赖该规则的到达和法律结论字段停止，不编造唯一截止日。
若 if C 端只要大众体检，then 只分流不回改。

判断状态只许三值。口头转述、截图和「已读」不得写成已保全、已送达或期限已起算。

## 本任务回链纪律

本任务成果是「不代发送的对内持有或禁毁通知草案」。必须包含：发送闸；口头备份不是已保全；已读不是到达；指导删除第一次整体停止。不包含：调查报告、启动闸终稿、披露稿、资金冻结。禁止选边治愈。禁止把先发全员、口头备份即已保全写成负触发或整体停止（删除、藏匿、倒签除外）。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标待发送终稿已形成。双方秘密未解不得进入「部分形成」。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接。
风险档 A：删除、藏匿、倒签、阻挠检查必须单独标可逆性。
