# 边界与路由

## 正触发

中国大陆企业需要对内发出持有或禁毁通知以固定可能被删改的材料。启动闸未开、范围或接收人未闭合仍正触发：有可编号范围切片且可列接收人或管理员则闸开或半开，出 `LH#` 草案，保持草案。本次不定罪、不等于法院保全、不执行发送、不出调查报告是交付禁令，不是开窗条件。全员无范围、今天必须发出、口头备份即已保全、已读即到达、草稿即已发送、保证已固定、选定某局、未知写零，仍正触发。

双方秘密、删除、格式化、藏匿、倒签、伪造回证、打击报复、限制人身自由、已有监察公安检察文书仍要全员禁毁的停止，优先于负触发。上述信号不在下表。不定罪不是负触发。「口头备份即已保全」「已读即到达」「持有函即裁定」不在下表。删除藏匿不在下表，走整体停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 是否启动内部调查 | `评估是否启动内部调查` |
| 调查报告终稿 | `形成内部调查报告` |
| 完整证据卷 | `建立内部调查证据案卷` |
| 主动披露或自查报告发送稿 | `准备主动披露或自查报告` |
| 检查或突击检查现场应对 | `应对监管检查或突击检查` |
| 内部账户冻结或资金止付 | `评估内部账户冻结与资金保全` |
| 合法收集、镜像或现场取证步骤 | `合法收集书证电子证与财务痕迹` |
| 刑事辩护、控告、自首 | 刑事领域 |
| 劳动处分、解除或扣薪划卡 | 劳动领域 |
| 数据出境或网安专项 | 数据隐私领域 |
| 尚未进入合规机制，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不定罪」或「不等于法院保全」关窗。拟持有通知仍正触发，不得写成已保全、已发送或已到达。检查已开始不是本窗负触发。是否调查尚未判断不负触发吞窗。

## 易混

本窗闸名只能是持有闸，不是发送闸，不是保全闸，不是通知闸，不是评估闸，不是启动闸，不是检查闸。`LH#` 不是 `N#`，不是 `QI#`，不是 `A#`。主路径是 `Q-持有`，不是 `Q-发`，不是 `Q-函`，不是 `Q-持`，不是 `Q-证`，不是 `Q-保`。`发送闸`／`HF#`／`Q-函` 是合同包 `准备解除通知`。`Q-持` 是公司治理包代持主路径。邻窗 `评估是否启动内部调查`、`评估企业合规风险总图`、`合法收集书证电子证与财务痕迹`、`制定调查方案与访谈计划`、`建立内部调查证据案卷` 的持有转介改挂 `Q-持有`。口头备份不是已保全。已读不是到达。持有函不是民诉证据保全裁定。1991 年民事诉讼法第八十四条公告送达不是证据保全。行政处罚法第五十六条七日不是内部通知法定期限。提出「无关电脑先格式化、落款改到上周」整体停止。已有监察／公安／检察文书不得借本窗完成平行灭证。本窗不代发送。不选定机关。不定罪。不保证已固定。不出调查报告。
