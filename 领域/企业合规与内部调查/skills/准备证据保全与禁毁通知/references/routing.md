# 边界与路由

## 正触发

需要对内发出持有或禁毁通知以固定证据。范围或接收人未闭合仍正触发：发送闸关闭，不出发送前终稿，窗口不关。全员无范围、今天必须发出、口头备份即已保全、已读即到达、选定某局、保证已固定，仍正触发。

双方秘密、删除、格式化、藏匿、倒签、报复接收人、借全员禁毁平行灭证的停止，优先于负触发。上述信号不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 是否启动内部调查 | `评估是否启动内部调查` |
| 只要案卷不要通知 | `建立内部调查证据案卷` |
| 合法收集步骤终稿 | `合法收集书证电子证与财务痕迹` |
| 向机关披露或交自查 | `准备主动披露或自查报告` |
| 检查或突击检查现场应对 | `应对监管检查或突击检查` |
| 内部账户止付或资金保全 | `评估内部账户冻结与资金保全` |
| 调查报告终稿 | `形成内部调查报告` |
| 劳动处分、解除、扣薪划卡 | 劳动领域 |
| 刑事辩护、控告、自首 | 刑事领域 |
| 个人信息或网安专项体系 | 数据隐私领域 |

已经决定就某一线索出报告或向机关交材料时负触发。不得因「要求今天发出」或「要求全员禁毁」关窗。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、阅卷、辩护词为主成果 | 刑事领域 |
| 劳动合同、解除、工伤、职场性骚扰主轴 | 劳动领域 |
| PIPL 合法性、出境、等保、网安事件专项 | 数据隐私领域 |
| 垄断协议、滥用支配地位、经营者集中申报 | 竞争法领域 |

综合持有主轴可留本任务；专项只作为背景时在缺口标明。渠道回扣线索不是不正当竞争整案转出信号。

## 易混

IT 口头说「已经备份」不是持有通知，也不是已保全。要对监管交材料走披露或检查应对。停付公司应付款或评估冻结账户不是禁毁通知，不得把扣薪或划卡写进持有通知。「是否调查尚未判断」若同时要持有通知：本窗正触发，启动闸只转介，不负触发吞掉本窗。已有监察调取通知仍要「先全员禁毁、把无关电脑格式化」：整体停止，不是负触发。
