# 边界与路由

## 正触发

关键邮件、财务、即时通讯或设备可能被删改，需要发送前的对内持有或禁毁通知。「先把邮件和账套冻住」正触发。先发全员再想范围、口头备份即已保全、已读即到达、保证证据已固定、无边界一律禁毁、选定某局、倒签，仍正触发：错误主张只关对应格，范围可识别则发送闸仍可开出 `Ntc#` 草案，窗口不关。廉洁线索与劳动外观同时出现，仍正触发：劳动段分流，持有 `Ntc#` 可留。

双方秘密、指导删除、格式化、藏匿、选择性清理、伪造备份、倒签、打击报复、阻挠检查的停止，优先于负触发。不得改走负触发去出一方通知或完成毁证。先发全员、口头备份即已保全、已读即到达不在下表。删除藏匿不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 是否调查尚未判断 | `评估是否启动内部调查` |
| 只要案卷不要通知 | `建立内部调查证据案卷` |
| 调查报告终稿 | `形成内部调查报告` |
| 向机关披露或自查报告 | `准备主动披露或自查报告` |
| 内部账户止付或资金保全 | `评估内部账户冻结与资金保全`（未安装则 `unavailable`） |
| 检查或突击检查现场应对 | `应对监管检查或突击检查` |
| 扣个人手机、停职停薪或解除处分 | 劳动领域 |
| 个人信息、数据出境或网安专项体系 | 数据隐私领域 |
| 刑事辩护、控告或自首 | 刑事领域 |
| C 端大众体检 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「先把电脑格式化再发通知」「两边材料都给你选边」不在本表，走整体停止。指导删除不转介方法。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护且不要企业持有通知 | 刑事领域（交第 1、2、10 节） |
| 劳动合同、解除、工伤、职场性骚扰或日常违纪处分主轴 | 劳动领域 |
| 个人信息、出境、等保、网安事件专项 | 数据隐私领域 |
| 垄断、经营者集中、不正当竞争专项 | 竞争法领域 |
| 税务稽查实体 | 税务领域 |
| 指导删除、藏匿、伪造备份或阻挠检查 | 整体停止 |

综合持有／禁毁可留本任务；专项只作为背景时在缺口标明。IT 口头备份不是持有通知。停付公司应付款或评估冻结账户不是禁毁通知，不得把扣薪或划卡写进持有通知。

## 易混

「先把邮件和账套冻住」正触发。「这封匿名信查不查」走启动闸。「IT 说已经备份了」不是已保全，本窗正触发、备份格待核。「要对监管交材料」走披露。「先格式化再发通知」整体停止。
