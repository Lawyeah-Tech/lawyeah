# 准备证据保全与禁毁通知

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在调查启动评估或等价材料支持发出对内持有通知时，形成“发送前证据保全与禁毁通知包”：发送闸、范围、接收人、禁止动作、留痕设计和失败升级。本任务不执行发送，不把口头备份写成已保全。

`depends-on` 为空。接受用户、律师、内审、机关或其他来源的等价事实、授权、测算和证据清单，不要求先运行其他 Skill。

## 工作边界

正触发：关键邮件、财务、即时通讯或设备可能被删改，公司需要发送前的对内持有/禁毁通知。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要判断是否调查，不要发通知；
- 只要调查报告或主动披露稿；
- 用户要求指导删除、格式化、藏匿设备或选择性清理；
- 要对监管机关提交自查；

本任务不给胜诉率、必然免责、刑事既遂或唯一必得总额。

## 建立坐标

确认：签发主体与授权；接收岗位与个人；系统管理员；拟保全的系统、期间、关键词；是否已有检查或诉讼；拟发送渠道。

同时掌握公司与被调查对象相互冲突的秘密时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 陈述；`D#` 材料；`R#` 机关文书；`C#` 制度/劳动合同/保密协议定位；`L#` 规则；`I#` 判断；`G#` 缺口；`V#` 通知版本；`E#` 发送凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验毁证、妨害作证、非法证据排除和劳动信息处理接口；`search_template` 只借鉴通知栏目。

工具不可用时继续事实、主体和问题清单；依赖未核验规则的法律结论、期限或机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 发送闸与授权

无调查授权或等价材料、范围无法识别：打不开发送闸。用户“先发全员再想范围”：停止终稿。

### 2. 范围闭合

按系统、期间、项目、账户列范围。禁止“全部资料一律不得删除”而无边界，除非已有对等的监管/诉讼保全文书。

### 3. 发送前正文

只写持有、禁毁、报告IT、禁止自行调查或接触证人。不写调查结论，不指控犯罪，不倒签。

### 4. 到达与留痕

预列接收人、渠道、回执、管理员备份。已读不等于到达。本任务不补造回证。

### 5. 禁止动作与劳动/数据接口

通知不得授权违法监控。停职、扣设备若改变劳动权利：只留接口，转劳动。涉及个人信息批量调取：转数据。

## 停止与安全

- `整体停止`：用户坚持删改、藏匿、伪造备份或报复接收人。
- `字段停止`：范围、接收人、授权未闭合。
- `目标停止`：主目标变为报告、披露或劳动处分。
