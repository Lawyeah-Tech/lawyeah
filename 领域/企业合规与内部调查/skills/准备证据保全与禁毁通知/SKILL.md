# 准备证据保全与禁毁通知

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《民法通则》《民法总则》或其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成发送前对内持有／禁毁通知包：发送闸、范围（系统 × 期间 × 对象）、`N#` 草案、接收人与管理员、最小 `E#` 到达设计。本任务不执行发送，不伪造送达，不等于法院证据保全裁定，不是搜查令，不把口头备份写成已保全。不写调查结论、披露稿、处分决定或账户冻结终稿。

`depends-on` 为空。是否启动调查转 `评估是否启动内部调查`。案卷转 `建立内部调查证据案卷`。合法收集步骤转 `合法收集书证电子证与财务痕迹`。账户止付转 `评估内部账户冻结与资金保全`。向机关交材料转 `准备主动披露或自查报告`。检查现场转 `应对监管检查或突击检查`。

## 工作边界

正触发：关键邮件、财务、即时通讯或设备可能被删改，公司需要发送前的对内持有／禁毁通知。范围、接收人未闭合仍正触发：发送闸关闭，不出发送前终稿，窗口不关。用户要全员一律禁毁、今天必须发出、口头已备份即已保全、已读即到达、选定某局、保证已固定，仍正触发：对应格填 `现有依据不支持` 或字段停止，闸未开则不出发送前终稿，窗口不关。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是是否启动内部调查（转 `评估是否启动内部调查`）；
- 主成果是调查报告或证据卷终稿（转 `形成内部调查报告`／`建立内部调查证据案卷`）；
- 主成果是向机关主动披露或自查报告发送稿（转 `准备主动披露或自查报告`）；
- 主成果是检查或突击检查现场应对（转 `应对监管检查或突击检查`）；
- 主成果是内部账户冻结或资金止付（转 `评估内部账户冻结与资金保全`）；
- 主成果是劳动处分、解除或扣薪划卡（转劳动领域）；
- 主成果是个人信息、数据出境或网安专项体系（转数据隐私领域）；
- 主成果是刑事立案、控告或辩护（转刑事领域）。

删除、格式化、换机、藏匿设备、选择性清理、倒签、伪造回证、打击报复接收人**不在负触发表**，走整体停止。已有监察／公安文书时借全员禁毁或清理设备完成平行灭证，第一次即整体停止。

## 建立工作坐标

确认：签发主体与授权；单方立场（公司／被调查对象，互斥）；接收岗位与个人；系统管理员；拟保全的系统、期间、关键词或账户；是否已有检查、诉讼、监察或公安文书；拟发送渠道。

口头「已经备份」「已经发过」「微信已读」只登记 `S#`／`V#`。不得升格已保全、已送达或期限已起算。

同时掌握公司与被调查对象相互冲突的秘密，或两造争同一份持有通知：`整体停止`，不得以选边治愈，也不得改走负触发。公司已开口且委托范围就是持有通知、且未掌握被调查对象秘密时，可推定公司立场。提出删除、格式化、藏匿、倒签、伪造回证、对接收人或举报人调岗报复、威胁证人、妨害作证：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 制度、劳动合同或保密协议；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`N#` 通知稿；`Q#` 路径接口；`V#` 版本；`E#` 发送／到达设计。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。通知状态只用 `草案`、`待发送`、`已发送待证明到达`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。本任务默认 `草案`，不执行发送。禁止「证据已固定」「持有函即保全裁定」「已读即到达」。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：诉讼外持有／禁毁通知不等于民事诉讼法证据保全裁定；起诉前向人民法院申请证据保全是另一路径，本窗不写申请书。刑法第一百六十二条之一及会计资料保存义务：隐匿、故意销毁依法应当保存的会计凭证、会计账簿、财务会计报告只作红旗并待核持有理由，本窗不定罪，不得把「账上可能被删」写成整体停止，也不得把通知写成指导删除。刑法第三百零七条、第三百零八条：妨害作证、帮助毁灭证据、打击报复证人只作停止红旗，提出威胁证人即整体停止。监察法（2024 修正）第十八条，有关单位和个人应当如实提供，不得伪造、隐匿或者毁灭证据；已有监察文书时不得借本窗全员禁毁完成平行灭证。个人信息保护法第十三条，人力资源管理所必需不等于全员邮箱或定位当然授权。劳动法第一百零一条，打击报复举报人员只作停止红旗。劳动合同或员工手册送达条款只作到达候选，运行时核验；微信已读不等于劳动法或民事诉讼意义上的送达，不得据此起算保存义务。噪声：把持有函写成保全裁定、把行政先行登记保存七日写成内部通知法定期限、把拒不提交推定写成诉前已成立、口头备份即已保全、已读即送达、把第一百六十二条之一摘要写成已构成犯罪或据此拒发禁毁通知。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变保全性质、到达或禁止毁证结论的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补持有函不等于法院保全、已读不等于到达、口头备份不是已保全的反例。
- `search_template` 只借持有／禁毁通知栏目，不把范本当法定格式或已发出文本。

工具不可用时继续范围、接收人和正文结构；法律效果、期限、机关路径字段停止。

## 判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、发送闸与不关窗

主成果才整案转出。删除藏匿第一次停。全员无范围、今天必须发出、口头备份即已保全不关窗。已有监察文书不得借本窗平行灭证。

### 2. 范围、接收人与回避

系统 × 期间 × 对象闭合。禁止无边界「全部资料一律不得删除」。已有法院证据保全裁定 `R#` 时，范围不得超过裁定载明的系统、期间和对象，仍不得借裁定扩成全员。已有监察／公安文书不得据此打开全员禁毁或清理设备。接收人是唯一被调查人且无回避：须另列管理员接收。

### 3. 发送前正文

只写持有、禁毁、报告 IT、禁止自行调查或接触证人。不写调查结论，不指控犯罪，不倒签，不公布举报人。

### 4. 到达与留痕

预列接收人、渠道、回执、管理员备份。已读不等于到达。本任务不执行发送、不补造回证。

### 5. 禁止动作与升级接口

不得授权违法监控。停职、扣私人设备、调岗不得写入通知正文，转劳动。批量调取个人信息转数据；全员邮箱或定位合法基础未核验不得写入可发送正文。合法收集转 `合法收集书证电子证与财务痕迹`。法院保全申请与公证本包无对应原子：字段停止，不选定法院或公证处，不得写成已准许。不等于已经保全。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；提出删除、格式化、藏匿、倒签、伪造回证、报复接收人或举报人、威胁证人、妨害作证、限制人身自由；已有监察／公安文书仍要求全员禁毁或清理设备以完成平行灭证。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：范围、接收人、授权、到达规则未闭合。全员无范围、今天必须发出、口头备份即已保全、已读即到达、选定某局、保证已固定：该格停止，窗口不关；闸未开仍不出发送前终稿。
- `目标停止`：主目标变为调查报告、披露稿、处分、账户冻结或法院保全申请书。

禁止指导删除、隐匿、倒签或违法监控。不给胜诉率。不定罪。不选定机关或法院。不代发送。未知不写零。
