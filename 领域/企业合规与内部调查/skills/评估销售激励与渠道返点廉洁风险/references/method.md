# 评估方法

本文件是可执行判断节点。激励闸打开不等于已回扣不等于已合法。渠道返利政策入账不是自动回扣。打到个人卡不是自动合法奖金。从公开返利中截留给个人不是政策本身已回扣。入账不是合法闭集。行业惯例不是合法。红旗待证不是已账外暗中。销售越权承诺的返点不是当然对外有效。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。入账三态只用 `双方如实入账`、`单方或账外`、`待核`。禁止胜诉率、必然免责、刑事既遂、选定法院、代提交、未知写零。本窗不定罪，不设计薪酬效果，不写经销合同全文，不写回扣账外专项终稿。本窗 `RP#` 是返点行，不是账外行 `XB#`，不是账簿行 `BX#`，不是风险点 `BR#`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1993 年反不正当竞争法第八条、把返点写成回扣时记为噪声。禁止指导账外兑现、伪造激励台账或打个人卡掩盖。禁止 `search_template` 生成已合法激励证明。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现激励扫描，不是默认闭集。
`RP#` 固定列：`编号｜激励类型（返点／销售奖／渠道激励／其他）｜计算基础｜支付对象（对方公司／对方个人／指定第三方／待核）｜入账三态（双方如实入账／单方或账外／待核）｜是否有权批准｜是否与具体订单挂钩｜红旗｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已回扣闭环」。无 `E#` 不得写已覆盖、已合法、已回扣。`E#` 只作证据形态回链。缺项记 `G#`。扫描不是闭集。双方如实入账 ≠ 已合法闭集。单方或账外 ≠ 已回扣既遂。对方个人 ≠ 合法奖金。红旗 ≠ 已账外暗中。

口头「都是回扣」「行业都这样」「打个人卡就是奖金」「入账了就合法」只进 `S#`／`V#`，**不得单独算作开闸材料**。激励政策、经销协议封面、付款回单、入账科目、个人卡流水可编号开闸。政策能开闸，不能升格已合法。`A#` 是承认该笔激励存在或已付，不是已合法。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上合法折扣、佣金须明示并如实入账；回扣是账外暗中未如实记载。公开入账渠道返利政策不是自动回扣。类案账外打给对方经办人个人可支撑对非国家工作人员行贿，不等于入账政策本身已回扣；从公司返利中截留给个人是另一事实，不得倒推政策必然违法。

## 节点 0　分流、立场、激励闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、指导账外兑现、指导伪造激励台账、指导打个人卡掩盖、打击报复、阻挠检查不进负表。利益冲突未解不进整体停止。不设计薪酬效果、不把激励一律写成回扣、不审经销合同全文不进负表。

整案转出只交付第 1、2、10 节，不出 `RP#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是劳动薪酬或提成争议 | 整案转劳动 |
| 主成果是回扣账外资金链路终稿 | 负触发 `评估回扣账外暗中与资金链路` |
| 主成果是账簿虚假报销终稿 | 负触发 `评估账簿记录与虚假报销` |
| 主成果是礼品单笔审查 | 负触发 `审查礼品招待赞助与捐赠` |
| 主成果是中间人费用终稿 | 负触发 `评估中间人费用与资金链路` |
| 主成果是第三方机制终稿 | 负触发 `设计第三方合规管理机制` |
| 主成果是廉洁风险图 | 负触发 `评估反商业贿赂风险点` |
| 主成果是是否启动内部调查 | 负触发 `评估是否启动内部调查` |
| 主成果是经销合同全文 | 负触发审查起草（本窗搁置） |
| 主成果是刑事辩护、控告或自首 | 整案转刑事 |
| 「不设计薪酬制度劳动效果」「不把激励一律写成回扣」「不审经销合同全文」 | 交付禁令，不是负触发 |

审查起诉、监管检查、已立案只作程序背景。主成果才整案转。出现「返点」「奖金」「渠道」一词不是转出。

激励闸打开（可出 `RP#` 草案，仍不得标「已回扣／已合法／已定罪」）须同时满足：单方无冲突公司立场已闭合；主成果是激励廉洁评估，不是薪酬制度、回扣专项或经销合同；至少一条可编号激励碎片。口头「都是回扣」不算单独开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

激励闸部分打开：已有可编号激励碎片，但入账、账户、批准、权限未闭合；或无书面评估授权但已有碎片；对应格待核；仍交十节；不得标终稿 `已形成`。

激励闸关闭（仍正触发）：无一可编号激励碎片。「今天必须出已合法或已回扣终稿」而无最小件不得开闸。不出 `RP#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `RP#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关写成「没有回扣」或「已合规」。

「返点一律回扣」「销售奖即贿赂」「渠道激励即买业务」「入账即合法闭集」「行业惯例即合法」「个人卡即合法奖金」「红旗即已账外暗中」「本表已定罪」「交表即从轻」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `RP#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无一可编号激励碎片，then 激励闸关闭，仍交十节，不是整体停止。
若 if 单方立场已闭合、无书面授权但已有可编号碎片，then 激励闸部分打开，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象或相对方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出指导账外兑现、指导伪造激励台账、指导打个人卡掩盖、打击报复、阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。
若 if 利益冲突未解但未要求隐瞒或伪造，then 窗口不关，不是整体停止。

## 节点 1　主体、激励碎片与强制接口

一行一个激励碎片。缺项记 `G#`，未知金额不得写 `0`。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 类型 | 返点／销售奖／渠道激励／其他 | 一律写成回扣 |
| 支付对象 | 对方公司／对方个人／指定第三方／待核 | 个人卡即合法奖金 |
| 入账 | 双方如实入账／单方或账外／待核 | 入账即合法闭集 |
| 权限 | 有权批准／越权口头／待核 | 口头即已批准 |
| 订单挂钩 | 是／否／待核 | 挂钩即已买业务 |
| 施行日 | 行为时点相对 2025-10-15 | 跨日用唯一条文 |

检索锚点（写入 `L#` 前须核验）：反不正当竞争法（2025）第八条，施行日 2025-10-15；明示折扣、向中间人支付佣金可以，双方应当如实入账。噪声：1993 年第八条。1996 暂行规定第六条／第七条须核验冲突。刑法第一百六十三条／第一百六十四条只作红旗。行政处罚法第三十二条交表 ≠ 从轻。42 号令只约束中央企业。劳动合同法只开劳动接口。本节禁止出 `RP#` 终稿。

## 节点 3　返点行 `RP#`

按已出现激励扫描，不是默认闭集。建议行型（出现才用，**不是闭集**）：

| 编号 | 含义 | 本窗允许 | 禁止 |
| --- | --- | --- | --- |
| `RP-政` | 公开渠道返利政策 | 入账三态分列 | 政策入账即已合法或已回扣 |
| `RP-奖` | 销售奖 | 支付对象可见 | 销售奖即贿赂 |
| `RP-卡` | 打到对方个人账户 | 待核；红旗可见 | 即合法奖金或即已回扣 |
| `RP-口` | 无权口头加点数 | 红旗待证 | 即已账外暗中 |
| `RP-库` | 账外小金库兑现 | 红旗；转回扣接口 | 本窗写成回扣既遂 |
| `RP-权` | 销售越权承诺 | 对内／对外分列 | 本窗改合同或定对外无效 |

热冲突强制处理：

- 返点一律回扣／销售奖即贿赂／入账即合法闭集／行业惯例即合法／个人卡即合法奖金／红旗即已账外暗中 → 该格不支持；仍出其他 `RP#`。
- 账外台账、个人卡、与具体订单挂钩的私下承诺、无权口头加点数 → 红旗待证，须资金链核验后才升格账外暗中。
- 从公开返利中截留给个人 → 与政策分行；不得倒推政策必然违法。
- 指导账外兑现、伪造台账或双方秘密 → 整体停止，不是该格不支持。

事实不足以支持某返点行：该条 `依据不足，无法形成结论`，不关窗。无 `E#` 不得写已覆盖、已合法或已回扣。状态 `草案`。一次只推荐下一步。

## 节点 4　劳动、账外、合同接口、禁止文书与转介

第 7 节只开接口，不得夹带 `RP#` 终稿绕闸。闸关闭时第 7 节可写「闸未开，转介待激励编号」，不得补写已合法。

不写薪酬制度、经销合同全文、回扣账外专项终稿、刑事文书、启动闸。不可逆（对外宣称激励已合法、向监管正式报告已无回扣、签署虚假入账、账外兑现）不得在草案阶段实施。禁止提交指令。不代提交。不选定机关。

账外展开转 `评估回扣账外暗中与资金链路`。薪酬提成转劳动。经销合同转审查起草（搁置）。经销商体系转 `设计第三方合规管理机制`。

若 if 用户催促「按零写／填满已合法或已回扣终稿」，then 该格 `现有依据不支持`，窗口不关。
若 if 金额未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：民企。经销协议写明按销售额返点且双方入账；另有销售向对方采购经理个人卡打款并口头加点数。用户主张渠道返利一律是回扣、销售奖就是贿赂、行业都这样所以合法、今天给已回扣终稿。激励闸打开。`Q-折`、`Q-奖`、`Q-惯`、`Q-卡` 不打开为可靠路径。第 6 节返点一律回扣格、入账即合法格 `现有依据不支持`；政策入账行与个人卡行分列；个人卡、口头加点数标红旗待证，不是已账外暗中。仍出类型、支付对象、入账三态、权限等其他 `RP#` 草案。不关窗。不定罪。不写经销合同全文。

场景②：用户同时交出公司激励台账与经销商抗辩，要求「你帮我们选边，账外返点改走咨询费，台账先改一版」。命中双方秘密＋指导账外兑现＋指导伪造激励台账。第一次整体停止。只交第 1、10 节。不出 `RP#`。不得问代表哪一方后继续。
