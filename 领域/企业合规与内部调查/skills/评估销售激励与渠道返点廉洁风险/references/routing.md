# 边界与路由

## 正触发

有可编号的返点、销售奖或渠道激励碎片，需要评估结构、入账、支付对象与代理权限，而不是做薪酬制度、回扣账外专项或经销合同改稿。入账、账户未核验仍正触发：有可编号激励碎片则激励闸开或半开，出 `RP#` 草案。返点一律回扣、销售奖即贿赂、入账即合法闭集、个人卡即合法奖金、本表已定罪，仍正触发。

双方秘密、指导账外兑现、指导伪造激励台账、指导打个人卡掩盖、打击报复、阻挠合法检查的停止，优先于负触发。上述信号不在下表。「返点一律回扣」「销售奖即贿赂」「渠道激励即买业务」「入账即合法闭集」「行业惯例即合法」「个人卡即合法奖金」不在下表。「不设计薪酬制度劳动效果」「不把激励一律写成回扣」「不审经销合同全文」是交付禁令，不在下表。出现「返点」「奖金」「渠道」一词不是转出。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 劳动薪酬、提成工资或未发奖金劳动争议 | 劳动领域 |
| 回扣账外资金链路终稿 | `评估回扣账外暗中与资金链路` |
| 账簿虚假报销终稿 | `评估账簿记录与虚假报销` |
| 礼品、招待、赞助或捐赠单笔审查 | `审查礼品招待赞助与捐赠` |
| 中间人费用终稿 | `评估中间人费用与资金链路` |
| 第三方合规机制终稿 | `设计第三方合规管理机制` |
| 廉洁风险图 | `评估反商业贿赂风险点` |
| 是否启动内部调查 | `评估是否启动内部调查` |
| 经销合同全文改稿 | 审查起草领域（本窗搁置，只说明） |
| 刑事辩护、控告、自首或阅卷 | 刑事领域 |

不得因「不设计薪酬制度劳动效果」「不把激励一律写成回扣」「不审经销合同全文」关窗。返点一律回扣、入账即合法该格不支持，窗口不关，不转出。主成果才转。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、工资、提成、解除为主成果 | 劳动领域 |
| 药品购销回扣行业细则为主成果 | 医疗领域 |
| 税务处理决定、稽查实体 | 税务领域 |
| 垄断协议、滥用支配、经营者集中为主成果 | 竞争法领域 |

综合激励廉洁评估主轴可留本任务。检查或已立案只作背景，主成果才转。已刑事立案且主成果是刑事程序：整案转刑事。已立案但主成果仍是企业激励评估：留窗；指导账外兑现整体停止。

## 易混

渠道返利政策入账不是自动回扣。打到个人卡不是自动合法奖金。从公开返利中截留给个人不是政策本身已回扣。入账不是合法闭集。行业惯例不是合法。红旗待证不是已账外暗中。销售越权承诺的返点不是当然对外有效，也不是当然已构成账外暗中。明示折扣佣金如实入账不是贿赂。1993 年反不正当竞争法第八条不是现行 `L#`。反法 2025 第八条施行日 2025-10-15；MCP 标尚未施行的以施行日为准。不设计薪酬效果、不把激励一律写成回扣、不审经销合同全文是交付禁令，不是负触发。口头「都是回扣」不是单独开闸材料。可编号激励碎片才开闸。指导账外兑现或伪造激励台账是第一次整体停止，不是不关窗。利益冲突未解不是本窗整体停止。本窗 `RP#` 不是账外行 `XB#`，不是账簿行 `BX#`。
