# 评估方法

本文件是可执行判断节点。通识课不是岗位培训。签到不是考核。完成培训不是免责。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、范本填满、唯一截止日、选定机关、代提交、未知写零。本任务不写劳动培训制度全文，不替代调查或处分，不定罪，不代组织培训。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1996 行政处罚法第三十二条、2018 年《中央企业合规管理指引（试行）》培训条款当现行第 30 条、把 42 号令第三十条或第一百七十七条套民企、把签到写成已合格、把 FCPA 写成中国法义务时记为噪声。MCP 将法治宣传教育法标为尚未施行但公布施行日为 2025-11-01 的，以施行日为准；无法独立核验施行日则该规则字段停止。禁止指导伪造签到或删除会计资料。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`PX#` 固定列：`编号｜对象层（董监高／管理人员／重点岗位／新入职／通用／第三方）｜场景｜应知应会要点｜考核（通过／未通过／补训闸）｜记录与E#｜红旗｜判断三值｜缺口G#｜最强反方｜待核`。本窗 `PX#` 是培训行，不是验收计划；禁止 `TR#`（税务协定占用）。禁止合成「已有效培训闭环」一笔。`E#` 只作证据形态回链。缺项记 `G#`，不得用「参照最佳实践」或范本栏目填满。扫描不是闭集。

口头「年年都训」「群已读就是已训」「签到就算合格」只进 `S#`／`V#`，**不得算作开闸材料**。签到、转发、拍照留念不得升格考核通过。`A#` 是承认，不是已培训。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

## 节点 0　分流、立场、培训闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。伪造签到、倒签考核、假培训记录、指导删除、平行灭证、打击报复、阻挠合法检查、双方秘密不进负表。

整案转出只交付第 1、2、10 节，不出 `PX#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是已有体系或培训是否运转 | 负触发 `评估合规管理体系有效性` |
| 主成果是正式有效性评价 | 负触发 `开展合规有效性评价` |
| 主成果是劳动培训或入职规章全文 | 整案转劳动 |
| 主成果是劳动处分或解除 | 整案转劳动 |
| 主成果是数据或反垄断专项培训整案 | 整案转相应领域 |
| 主成果是反贿赂制度全文 | 负触发 `设计反商业贿赂与礼品招待制度` |
| 主成果是义务地图终稿 | 负触发 `建立合规义务与责任主体地图` |
| 主成果是是否启动调查 | 负触发 `评估是否启动内部调查` |
| 主成果是只要框架不要培训方案 | 负触发 `设计合规管理体系框架` |
| 确为中央企业且主成果是 42 号令对照终稿 | 负触发 `评估国企合规管理办法差距` |
| 侦查、起诉、辩护为主成果 | 整案转刑事 |

审查起诉、监管检查只作程序背景。主成果才整案转。出现「培训」一词不是转出。

培训闸打开（可出 `PX#` 草案，仍不得标「已有效培训／已履职／已免责」）须同时满足：单方无冲突公司立场已闭合；主成果是对象×场景×考核×记录，不是劳动规章、有效性终稿或专项课整案；至少一项可编号岗位风险或拟设培训行。从零：有拟设对象×场景即可开或半开，缺项记 `G#`。口头已训、群已读、签到、无风险的全员网课不算开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

培训闸部分打开：主体或保存周期未核验，但已有可编号范围；或无书面设计授权但已有拟设行；对应格待核；仍交十节；不得标终稿 `已形成`。不得因无授权文件关掉拟设草案。

培训闸关闭（仍正触发）：无一岗位风险且无一拟设行。「今天必须出已覆盖／已完成培训证明」而无最小事实不得开闸。不出 `PX#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `PX#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「没有缺口」或「已有效培训」。没有岗位风险输入不得输出「全员一年一次」充数。

「完成培训即免责」「签到或转发即合格」「全员同一课件即有效岗位培训」「民企必须按 42 号令第三十条必修并上报」「把 FCPA 培训写成中国法义务」「把突击补签写成已有效培训」「口头已训即已履职」「交方案即从轻」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `PX#` 草案。闸未开才不出 `PX#` 终稿。开口径无通过／未通过考核：该行删除或该考核字段停止。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合、无书面设计授权但已有拟设行或风险碎片，then 培训闸部分打开，仍交十节，不是整体停止。
若 if 公司立场已闭合但无一拟设且无一风险碎片，then 培训闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造签到、倒签考核、假合格证明、指导删除会计资料、借培训稿平行灭证、打击报复或阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。
若 if 调查开始后突击补签仅主张写成已有效、未要求伪造或倒签，then 该格不支持，不关窗。
若 if 同一句要求改日期、代签或造分，then 整体停止。

## 节点 1　主体与强制接口

名称、规模、是否中央企业／国家出资公司／上市分列。不自动合并。独立法人子公司不与母公司自动合并。

检索锚点（写入 `L#` 前须核验）：

- 公司法第一百六十八条：国家出资公司不含参股。第一百七十七条仅国家出资公司对内合规，不套民企。
- 公司法第六十七条：董事会制定基本管理制度，不等于培训方案已覆盖。
- 42 号令第十四条（五）、第三十条、第二十九条、第三十二条、第四十条：只约束中央企业。第三十条管理人员、重点岗位、新入职必修，不得用全员网课冒充三层。第十四条（五）组织或协助培训不是交了签到即已履职。第二十九条党委法治专题学习不是本窗培训方案主轴。第三十二条接受合规培训不等于全员同一课件已有效，不等于免责。民企硬套第三十条：该格 `现有依据不支持`，强制对照行删除，不关窗。不得建议民企上报国务院国资委。
- 法治宣传教育法第二十九条：企业加强对职工的法治教育培训，施行日 2025-11-01。加强法治教育不是完成培训即免责，不是全员同一课件。
- 行政处罚法第三十二条：提交培训方案或记录不等于情节成就。
- 个人信息保护法第六条、第十三条：人力资源管理所必需不等于全员培训可收集微信或定位。
- 不得把美国《反海外腐败法》培训程序写成中国法定义务；可作非强制对标并标明法域。

国企适用办法条款才写入强制项。强制接口与非强制对标分列，不选对用户有利的一版。

## 节点 3　对象×场景×考核行 `PX#`

先有岗位风险输入（用户材料或等价义务地图接口），再排课程。没有风险输入：先列 `G#`，不得输出「全员一年一次」充数。按已出现岗位扫描，不是默认闭集。

每类对象至少有一个与其决策权匹配的场景。销售对礼品和渠道返点；采购对供应商和回扣；财务对账簿与虚假报销；董监高对职责与回避。缺类记 `G#`。数据隐私、反垄断专项培训整案转出，本方案只留接口课时。

签到、转发文件、拍照留念不构成考核。考核须能区分通过／未通过，并有补训闸。外包讲师资质不明：记缺口，不写成已合格。开口径无通过／未通过考核：该行删除或该考核字段停止。

无效培训红旗（该格不支持「已有效培训」，不关窗）：课件与岗位无关、全员同一课件、高管集体缺席、调查开始后突击补签（未伪造）、记录可随意改写。

## 节点 4　记录、可逆性与转介

记录保存周期待核则字段停止。培训方案不产生劳动处分。不得承诺完成培训即免除行政或刑事责任。劳动培训制度全文转劳动。本窗不做完民主程序。

可逆动作与不可逆动作分列。不可逆（对外宣称已覆盖、以培训代替处分、代提交、代组织已完成培训）不得在草案阶段实施。禁止提交指令。不代组织、不代提交。

下一步只转介：有效性、义务地图、反贿赂制度、董监高缺口、框架、办法。禁止一次写完全部邻窗终稿。

已有监察或检查 `R#`：不得借培训稿平行灭证。刑法第一百六十二条之一只作红旗，不得指导删除。

## 本任务回链纪律

本任务成果是「培训闸与对象×场景×考核草案」。不包含：已有效培训证明、免责结论、劳动规章全文、有效性终稿、专项课整案、调查启动、反贿赂制度全文。禁止伪造签到。禁止选边治愈。禁止签到即合格。禁止培训即免责。禁止民企套 42 号令第三十条。禁止 FCPA 当中国法。禁止占用 `TR#`。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标培训终稿已形成。
风险档 A：伪造签到、倒签考核必须单独标可逆性；提出即整体停止。
