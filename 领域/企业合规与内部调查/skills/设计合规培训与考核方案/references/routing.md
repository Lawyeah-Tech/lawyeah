# 边界与路由

## 正触发

公司要按岗位风险设计可考核、可留痕的培训方案，而不是通识课充数、评价已有体系或写劳动规章。岗位风险碎片、保存周期未核验仍正触发：培训闸关闭则不出 `TR#` 终稿，窗口不关。培训即免责、签到即合格、全员同一课件即有效、民企套第 29 条、突击补签即已有效、FCPA 当中国法，仍正触发。

双方秘密、伪造签到、倒签考核、假培训记录、指导删除、平行灭证、打击报复、阻挠合法检查的停止，优先于负触发。上述信号不在下表。「培训即免责」「签到即合格」「全员同一课件即有效」「民企套 42 号令」「FCPA 当中国法」「突击补签即已有效」不在下表。「不保证免责」「不替代调查或处分」「不写劳动培训制度全文」是交付禁令，不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 已有体系或培训是否运转 | `评估合规管理体系有效性` |
| 正式有效性评价项目 | `开展合规有效性评价` |
| 劳动培训或入职规章全文 | 劳动领域 |
| 劳动处分、解除或日常违纪 | 劳动领域 |
| 数据或反垄断专项培训整案 | 数据隐私或竞争法领域 |
| 反贿赂与礼品招待制度全文 | `设计反商业贿赂与礼品招待制度` |
| 义务地图终稿 | `建立合规义务与责任主体地图` |
| 是否启动调查 | `评估是否启动内部调查` |
| 只要框架不要培训方案 | `设计合规管理体系框架` |
| 42 号令对照终稿 | `评估国企合规管理办法差距` |
| 刑事辩护、控告 | 刑事领域 |

不得因「保证免责」或「要求按第 29 条写死」或「签到视为合格」关窗。无书面授权仍正触发，不得写成已有效培训。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、解除、工伤主轴 | 劳动领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |
| 垄断、滥用支配、经营者集中 | 竞争法领域 |
| 章程、股权、任免本身为主成果 | 公司治理领域 |
| 银行保险机构行业合规办法主轴 | 金融领域 |
| 药品购销回扣行业细则主轴 | 医疗医药领域 |
| 税务处理决定、稽查实体 | 税务领域 |
| 出口管制、制裁名单 | 涉外领域 |

综合合规培训方案主轴可留本任务。审查起诉或检查只作背景，主成果才转。出现「培训」一词不是整案转出。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 评价培训或体系是否有效 | `评估合规管理体系有效性` 或 `开展合规有效性评价` |
| 反贿赂制度全文 | `设计反商业贿赂与礼品招待制度`（本窗只留场景课一行） |
| 义务—主体全表 | `建立合规义务与责任主体地图` |
| 董监高是否履职 | `评估董监高合规职责缺口` |
| 确为中央企业且主成果是 42 号令对照 | `评估国企合规管理办法差距` |
| 只要框架图 | `设计合规管理体系框架` |
| 调查启动 | `评估是否启动内部调查` |

## 易混

培训记录不能写成已经免责。全员网课不是高风险岗位培训。签到不是考核。口头「都培训过了」不是已履职。调查开始后突击补签不是已有效培训；要求伪造或倒签则整体停止。民企套 42 号令第二十九条或第一百七十七条：该格不支持，不关窗。FCPA 培训对标不是中国法义务。法治宣传教育法第二十九条加强法治教育不是完成培训即免责。「先补假签到再出已训稿」整体停止。劳动培训规章全文和处分不在本窗。
