# 评估舆情与法定披露交叉方法

本文件是可执行判断节点。媒体在问不是已触发。热搜不是必须公告。澄清稿不是公告。金额不重大不是无需披露。公关压住不是无需披露。内部口径不是必须公告。新闻发布不能代替法定公告。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、必须公告已成立、无需披露已成立、唯一截止日、选定机关或媒体、代提交、未知写零。本任务不定罪，不写公告正文，不出 `CM#` 拟用句，不出可发送 `N#`。本窗闸名只能是舆情闸，禁止复用交叉闸、口径闸、披露闸、发送闸、触发闸。本窗 `Dsc#` 是触发行，不是 `X#`／`CM#`／`N#`／`Ntc#`，不是并行舆情行 `YQ#`。英文 id 禁止使用，一律用中文技能名 `评估舆情与法定披露交叉`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1998 年证券法第七十八条要约收购、2005 年第六十三条、把媒体在问写成必须公告、把金额不重大写成无需披露已成立、把港股-only 套证券法临时报告时记为噪声。禁止指导隐瞒应披露、伪造无需披露底稿或删除会计资料。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`Dsc#` 固定列：`编号｜舆情切片｜来源与时点｜已披露陈述冲突｜主体／义务人｜触发判断三值｜口径接口｜合同通知接口｜检查口径冲突｜E#回链｜最强反方｜待核｜转介`。禁止合成「媒体在问故必须公告」或「纯传闻故无需披露」一笔。`E#` 只作证据形态回链（舆情切片、已披露公告、问询文书、事实三态），不是发送闸，不是已披露证明。扫描不是闭集。缺项记 `G#`。状态默认 `草案`。

口头「媒体在问必须公告」「热搜了必须公告」「公关已经压住」「金额不重大不用披露」「已经澄清过了」只进 `S#`／`V#`，**不得单独算作开闸材料**。已读、微信已读、电话、快递揽收只进 `S#`／`V#`，不得升格 `R#` 已送达，**问询已读不得起算答复期**。快递揽收不是交易所已收。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

## 节点 0　分流、立场、舆情闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、隐瞒应披露或已知红旗、伪造无需披露底稿或公告底稿、提前泄露、编造已查清对外澄清、公开攻击或泄露举报人、指导删除、打击报复不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `Dsc#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是公告、问询答复、联交所 query 或停复牌说明正文 | 负触发，转证券／公司治理交叉 |
| 主成果是分层口径或拟用句终稿 | 负触发 `准备对内通报与对外口径` |
| 主成果是廉洁与内控交叉终稿 | 负触发 `评估上市公司廉洁与内控交叉` |
| 主成果是主动披露或自查发送稿 | 负触发 `准备主动披露或自查报告` |
| 主成果是调查报告终稿 | 负触发 `形成内部调查报告` |
| 主成果是董事会汇报提纲 | 负触发 `准备董事会合规汇报材料` |
| 主成果是检查现场口径 | 负触发 `应对监管检查或突击检查` |
| 主成果是向监管交卷与特权日志 | 负触发 `准备向监管提交材料与特权日志` |
| 主成果是合同通知正文或交易合同改稿 | 负触发，审查起草搁置 |
| 主成果是劳动处分或解除 | 整案转劳动 |
| 主成果是刑事辩护、控告或自首 | 整案转刑事 |
| 「不写公告正文」「不出可发送 N#」「不定罪」 | 交付禁令，不是负触发 |

审查起诉、证监会调查、交易所问询只作程序背景。主成果才整案转。出现「公告」「舆情」「媒体」一词不是转出。

舆情闸打开（可出 `Dsc#` 草案，仍不得标「必须公告／无需披露／已依法披露」）须同时满足：单方无冲突公司立场已闭合；主成果是舆情×法定披露交叉，不是公告正文、口径终稿、廉洁交叉表或自查发送稿；至少一件可编号舆情切片或已披露冲突。口头「媒体在问」「热搜了」不算单独开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

舆情闸部分打开：已有切片或冲突，但上市地、义务人、重大事件构成或规则未闭合；或无书面评估授权但已有可编号件；对应格待核；仍交十节。

舆情闸关闭（仍正触发）：无一可编号切片且无一已披露冲突。「今天必须交披露结论」而无最小事实不得开闸。不出 `Dsc#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `Dsc#` 终稿，**第 7 节不得出无需披露、必须公告或公告一句**。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「无需披露」或「没有舆情」。

「媒体在问即必须公告」「热搜即必须公告」「调查即必须公告」「检查即必须公告」「红旗即必须公告」「金额不重大或偶发即无需披露」「公关压住即无需披露」「澄清稿即公告」「新闻发布即已履行」「内部口径即必须公告」「非上市或港股-only 必须按证券法公告」「交表即从轻或已披露」「民企套第二十二条必须报国资委」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `Dsc#` 草案。闸未开才不出 `Dsc#` 终稿，第 7 节也不得出披露终稿。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无一可编号切片且无一已披露冲突，then 舆情闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出隐瞒应披露或已知红旗、伪造无需披露底稿或公告底稿、提前向媒体泄露依法应公告信息、编造已查清对外澄清、公开攻击或泄露举报人、指导删除会计资料、打击报复，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体、上市架构与义务人

固定上市地、发行人注册地、境内经营实体、谁是境内证券法义务人、谁是联交所发行人。拟 IPO、辅导期、新三板、发债主体仍是非上市。本节禁止出 `Dsc#` 终稿。缺项记 `G#`，不得把未知写成 `0`。

若 if 主体是非上市，then 证券法第七十八条／第八十条对照行该格 `现有依据不支持`，**不删节**，不关窗；仍可评舆情停止项与合同通知接口。
若 if 主体是港股-only 开曼或香港发行人，then 证券法第七十八条／第八十条该格 `现有依据不支持`，不关窗；联交所披露只开接口，不写公告、query 或停复牌正文。
若 if 主体是红筹或 VIE，then 境内经营实体被媒体点名 ≠ 开曼发行人已触发境内临时报告。
若 if 主体是 A+H，then 两套披露接口并列，禁止合成「已经公告过了」。

检索锚点（写入 `L#` 前须核验）：证券法（2019 修订）第七十八条、第八十条仅境内义务人；上市公司信息披露管理办法运行时核验 2021 年 182 号或 2025 年修订文本，不得以新闻发布代替报告、公告；42 号令第二十二条只约束中央企业；行政处罚法第三十二条交表 ≠ 从轻；刑法第六十七条交表 ≠ 自首。

## 节点 3　触发行 `Dsc#`

按已出现切片扫描，不是默认闭集。每条须能指向切片来源、已披露冲突和触发判断三值。媒体稿不是公司确认。问询文书是 `R#` 候选，已读不是已送达。`search_announcement` 未命中只记缺口，不写无需披露。

未核验重大事件构成：触发判断字段停止，不得写「不影响披露」或「必须公告」。金额不重大、偶发、公关压住：只进最强反方。非上市／港股-only：证券法对照格不支持，仍出其他 `Dsc#`。

无 `E#` 不得写已披露、已澄清覆盖或已履行。状态 `草案`。一次只推荐下一步。

热冲突：媒体在问即必须公告、金额不重大即无需披露、澄清稿即公告、新闻发布即已履行 → 该格 `现有依据不支持`，闸已开仍出其他 `Dsc#`。隐瞒已知红旗、伪造无需披露底稿、提前泄露 → 第一次整体停止，不是该格不支持。

## 节点 4　口径、合同通知与检查接口

第 7 节只开接口，不得夹带 `Dsc#` 终稿、`CM#` 拟用句或公告一句绕闸。闸关闭时第 7 节可写「闸未开，转介待切片编号」，不得补写无需披露或必须公告。

合同通知条款未提供则接口待核，不审改合同。合同通知了 ≠ 已法定披露；法定公告了 ≠ 合同通知已履行。已有监察或稽查 `R#`：不得借触发表平行灭证。

下一步只转介：`准备对内通报与对外口径`、`评估上市公司廉洁与内控交叉`、`准备主动披露或自查报告`、`准备董事会合规汇报材料`、`评估是否启动内部调查`、`应对监管检查或突击检查`、`形成内部调查报告`、`评估调查后处置路径`、`准备向监管提交材料与特权日志`、`设计举报人保护与反报复措施`、`评估打击报复风险`。禁止此致交易所或证监会。不代提交。

若 if 用户催促「按零写／填满无需披露终稿」，then 该格 `现有依据不支持`，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「舆情闸与披露触发交叉草案」。本窗不执行发送。不包含：公告正文、问询答复、停复牌说明、`CM#` 拟用句、自查发送稿、调查结论。禁止选边治愈。禁止媒体在问即必须公告。禁止金额不重大即无需披露。禁止澄清稿即公告。禁止新闻发布代替公告。禁止指导隐瞒应披露。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：A 股信息披露义务人。可编号媒体稿＋问询函表面。用户主张媒体在问必须公告、金额不重大无需披露、澄清稿已履职、新闻发布已代替公告、港股也要套证券法 78／80、交表即从轻。舆情闸打开或半开。`Q-媒`、`Q-额`、`Q-清`、`Q-闻`、`Q-港`、`Q-32` 不打开为可靠路径。第 6 节对应格 `现有依据不支持`；仍出已披露冲突、触发判断待核、合同通知接口。不关窗。不写公告一句。不出 `CM#`。

场景②：用户同时交出公司「无需披露」底稿与被调查对象口径，要求选对公司有利的一版，并指导把已知红旗从对外澄清里拿掉、用假公告日补一版。命中双方秘密＋隐瞒已知红旗＋伪造底稿。第一次整体停止。只交第 1、10 节。不出 `Dsc#`。不得问代表哪一方后继续。不以「坚持」为门槛。
