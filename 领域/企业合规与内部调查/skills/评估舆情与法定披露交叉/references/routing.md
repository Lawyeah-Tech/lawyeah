# 边界与路由

## 正触发

需要判断舆情和法定披露是否被触发，并分层口径，而不是写公告。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 写公告正文 | `证券披露/公司治理交叉` |

| 上市公司廉洁内控交叉表 | `评估上市公司廉洁与内控交叉` |
| 刑事辩护、控告、自首 | 刑事领域 |

| 垄断、经营者集中、反垄断调查主轴 | 竞争法领域 |
| 未进入合规机制的合同改稿 | 审查起草领域（本窗搁置，只说明） |
| C 端小微体检 / 供应商清单 / 广告 / 隐私 / 劳动规章 | 大众专项，只分流不回改 |
