# 边界与路由

## 正触发

调查、检查、媒体或股价材料需要判断是否交叉法定披露，主成果不是公告正文、不是分层口径终稿。切片、义务人、重大事件构成未核验仍正触发：有切片或已披露冲突则闸开或半开，出 `Dsc#` 草案，保持草案。媒体在问即必须公告、金额不重大即无需披露、澄清稿即公告，仍正触发。

双方秘密、隐瞒应披露或已知红旗、伪造无需披露底稿或公告底稿、提前泄露、编造已查清对外澄清、公开攻击或泄露举报人、指导删除会计资料、打击报复的停止，优先于负触发。上述信号不在下表。「媒体在问即必须公告」「热搜即必须公告」「金额不重大即无需披露」「公关压住即无需披露」「澄清稿即公告」「新闻发布即已履行」「内部口径即必须公告」「港股或非上市必须按证券法公告」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 公告、问询答复、联交所 query 或停复牌说明正文 | 证券／公司治理交叉 |
| 分层口径或拟用句终稿 | `准备对内通报与对外口径` |
| 廉洁与内控交叉终稿 | `评估上市公司廉洁与内控交叉` |
| 主动披露或自查发送稿 | `准备主动披露或自查报告` |
| 调查报告终稿 | `形成内部调查报告` |
| 董事会汇报提纲 | `准备董事会合规汇报材料` |
| 检查现场口径 | `应对监管检查或突击检查` |
| 向监管交卷与特权日志 | `准备向监管提交材料与特权日志` |
| 客户合同通知正文或交易合同改稿 | 审查起草领域（本窗搁置，只说明） |
| 劳动处分或解除 | 劳动领域 |
| 刑事辩护、控告或自首 | 刑事领域 |

不得因「不写公告正文」或「不隐瞒红旗」关窗。拟评估仍正触发，不得写成必须公告或无需披露。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、解除、工伤主轴 | 劳动领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |
| 垄断、滥用支配、经营者集中 | 竞争法领域 |
| 税务处理决定、稽查实体 | 税务领域 |
| 银行保险机构行业合规办法主轴 | 金融领域 |
| 出口管制、制裁名单 | 涉外领域 |
| 章程、股权、任免本身为主成果 | 公司治理领域 |

综合舆情与法定披露交叉主轴可留本任务。审查起诉、证监会调查或交易所问询只作背景，主成果才转。出现「公告」「舆情」「媒体」一词不是转出。

| 信号 | 转介 |

| 要分层口径拟用句 | `准备对内通报与对外口径` |
| 廉洁与内控交叉表 | `评估上市公司廉洁与内控交叉` |

| 主动披露或自查发送稿 | `准备主动披露或自查报告` |
| 合同通知条款审查起草 | 审查起草领域（搁置） |

## 易混

媒体在问不是已经触发法定披露。热搜不是必须公告。澄清稿不是公告。新闻发布不能代替法定公告。定期报告不能代替临时公告。内部口径不是必须公告。金额不重大不是无需披露已成立。公关压住不是无需披露。问询已读不是答复期起算。快递揽收不是交易所已收。非上市或港股-only 套证券法临时报告：该格不支持，不关窗，不删节。本窗 `Dsc#` 不是口径窗 `CM#`，不是廉洁交叉 `X#`，不是发送版 `N#`，不是并行舆情行 `YQ#`。本窗闸名只能是舆情闸。「把已知红旗从对外澄清里拿掉」整体停止。本窗不执行发送，不代提交。审查起诉只作背景，主成果才转刑事。
