# 边界与路由

## 正触发

已经决定调查，需要按合法权限收集书证、电子数据和财务痕迹并留下可复核日志，而不是出调查结论、案卷要件或发送版禁毁通知。从零、材料碎片、无完整授权仍正触发：有拟设则闸开或半开，出 `LG#` 草案。IT 拷贝即合法、公司电脑当然全盘、个保 13 即私人微信、账外常见即已收集、缺哈希仍已保全、交日志即从轻，仍正触发。

双方秘密、入侵、黑客、秘密录音、选择性删邮、伪造日志、偷拷私人设备、指导删除、阻挠检查的停止，优先于负触发。上述信号不在下表。「IT 拷贝即合法」「公司电脑当然全盘」「个保 13 即私人微信」「账外常见即已收集」「缺哈希仍已保全」「交日志即从轻」「第十四条即已取证」不在下表。「不入侵」「不写调查结论」「不保证可采」是交付禁令，不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 授权范围与独立终稿 | `确定调查授权范围与独立` |
| 调查方案与访谈计划 | `制定调查方案与访谈计划` |
| 案卷要件矩阵 | `建立内部调查证据案卷` |
| 发送版持有禁毁通知 | `准备证据保全与禁毁通知` |
| 访谈提纲与笔录结构终稿 | `准备调查访谈提纲与笔录结构` |
| 调查报告或事实认定 | `形成内部调查报告` |
| 出境方案或跨境调取终稿 | `协调跨境内部调查并分流涉外` |
| 全员监控或个保／数据专项体系 | 数据隐私领域 |
| 税务稽查实体 | 税务领域 |
| 劳动处分、解除或职场性骚扰调查 | 劳动领域 |

不得因「不入侵」或「不写调查结论」关窗。IT 拷贝即合法主张该格不支持，窗口不关。民企硬套不得负触发到对照窗。入侵／黑客不进负表，走整体停止、不转介方法。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、解除、工伤、职场性骚扰主轴 | 劳动领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |
| 税务处理决定、稽查实体 | 税务领域 |

综合内部调查收集主轴可留本任务。审查起诉或检查只作背景，主成果才转。出现「收集」「邮件」一词不是转出。

## 易混

IT 拷贝不是合法收集。无权限全盘镜像是风险不是勤勉。公司电脑不是当然全盘，不等于私人微信可取。个保法第十三条不是私人微信或全员邮箱授权。截图不是已保全。已读不是已收集。缺哈希不是已保全。账外常见不是已收集。日志不是已合法取证。授权稿不是已合法取证。第十四条不是已取证。法院调查令不是内部收集令。持有函不是已收集。案卷目录不是收集日志。交日志不是从轻。不入侵、不写调查结论是交付禁令，不是负触发。
