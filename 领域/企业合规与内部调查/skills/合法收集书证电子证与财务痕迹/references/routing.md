# 边界与路由

## 正触发

已经决定调查，需要按合法权限收集书证、电子数据和财务痕迹并留下可复核日志，而不是出调查结论、案卷要件或发送版禁毁通知。从零、材料碎片、无书面可提取依据仍正触发：有拟收集对象或材料碎片则闸开或半开，出 `LG#` 草案。IT 拷贝即合法、无权限镜像即勤勉、手册即私人设备可取、口头即可提取、缺校验仍已完整，仍正触发。

双方秘密、伪造或倒签收集日志、指导违法取证、入侵系统、购买黑客服务、撞库、木马、秘密违法录音或远控、偷拷私人设备、选择性删除不利邮件、伪造补充、限制人身自由、指导删除、阻挠合法检查的停止，优先于负触发。上述信号不在下表。「IT 拷贝即合法收集」「无权限全盘镜像即勤勉」「手册邮箱权即私人设备可取」「口头授权即可提取」「授权稿即已合法取证」「缺校验仍已完整」「账外常见做法即已收集」「公司法 67 或 42 号令 14 即已可取证」「调取证据通知书即内部法定格式」不在下表。「不入侵」「不写调查结论」「不保证可采或免责」是交付禁令，不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 授权范围与独立终稿 | `确定调查授权范围与独立` |
| 调查方案与访谈计划 | `制定调查方案与访谈计划` |
| 案卷要件矩阵 | `建立内部调查证据案卷` |
| 发送版持有禁毁通知 | `准备证据保全与禁毁通知` |
| 调查报告或事实认定 | `形成内部调查报告` |
| 访谈提纲与笔录结构终稿 | `准备调查访谈提纲与笔录结构` |
| 出境方案或跨境调取终稿 | `协调跨境内部调查并分流涉外` |
| 全员监控或个保／数据专项体系 | 数据隐私领域 |
| 税务稽查实体 | 税务领域 |
| 劳动处分、解除或职场性骚扰调查 | 劳动领域 |
| 交易合同改稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不入侵」或「不写调查结论」关窗。IT 拷贝、无权限镜像、手册即私人设备可取该格不支持，窗口不关。授权未闭合且主成果仍是收集日志：收集闸半开，只开授权接口，不负触发授权窗。入侵、黑客不进本表，走整体停止。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、解除、工伤、职场性骚扰主轴 | 劳动领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |
| 税务处理决定、稽查实体 | 税务领域 |
| 垄断、滥用支配、经营者集中 | 竞争法领域 |

综合内部调查收集主轴可留本任务。审查起诉或检查只作背景，主成果才转。出现「收集」「镜像」「刑事」一词不是转出。已刑事立案且主成果是刑事程序：整案转刑事。已刑事立案但主成果仍是内部收集日志：留窗；不得借收集平行灭证。

## 易混

IT 拷贝不是合法收集。没有权限依据的全盘镜像是风险而不是勤勉。口头「你们去拷」不是可提取。授权稿不是已合法取证。手册邮箱查看权不是私人设备、私人微信或定位当然可取。人力资源管理所必需不是全员邮箱或生物识别。缺校验不是已完整。账外候选不是已收集。公司法第六十七条董事会职权不是已可取证。42 号令第十四条组织或参与调查不是已可取证。调取证据通知书或登记保存清单栏目不是内部收集法定格式。监管调查人员提取电子数据条款不是企业内部法定格式。收集日志不是调查结论。不入侵、不写调查结论是交付禁令，不是负触发。
