# 输出合同

按触发结果选择交付形状。收集闸未打开不得交付「已合法取证」或「已完整」。禁止把 IT 拷贝写成合法收集。禁止把无权限全盘镜像写成勤勉。禁止把手册邮箱权写成私人设备可取。禁止选边治愈。不保证可采或免责。未知不写零。不写调查结论。不给出境方案。本窗 `LG#` 是收集行，不是授权行，不是方案行，不是案卷编目，不是调查认定。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出 | 第 1 节（触发与分流）、第 2 节（来源）、第 10 节（交接）。不填第 5–9 节 |
| 整体停止 | 第 1 节（停止原因）、第 10 节。禁止 `LG#` 正文、选边、违法取证步骤。双方秘密、伪造或倒签日志、指导违法取证、入侵黑客、选择性毁证、限制人身自由第一次即停，优先于负触发；无选边治愈，无「坚持」门槛；禁止「该部分停止后继续收其余」 |
| 收集闸关闭（仍正触发） | 十节表头均出现；第 5 节只交闸／`Q#`；第 6 节不出 `LG#` 终稿；不得改走负触发或只交 1+2+10 |
| 用户要 IT 拷贝即合法、无权限镜像即勤勉、手册即私人设备可取、口头即可提取、授权稿即已合法取证、缺校验仍已完整、账外常见做法即已收集、公司法 67 或 42 号令 14 即已可取证、调取证据通知书即内部法定格式（不关窗） | 十节表头均出现；对应格填 `现有依据不支持`；闸已开仍出其他 `LG#` 草案；不得标终稿 `已形成` |
| 正触发且闸开 | 下列十节表头均出现；未核验格填待核；禁止为填满而写已合法取证或已完整 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入收集终稿已形成。双方秘密未解不得进入「部分形成」。每个 `LG#`／`Q#` 必须带来源和判断三值。`L#` 不得直接抄技能内条号。稿件状态默认 `草案`。本窗不执行发送。不代提取。不代提交。

分流理由只放第 1 节。第 3 节不再写专项分流。第 7 节只保留完整性与禁止方法接口，不得把 `LG#` 终稿改放到第 7 节绕闸。

## 1. 触发、单方立场、收集闸与成果状态

谁要收集日志。立场互斥（默认公司或其调查受托律师）。收集闸是否打开。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。不定罪。不保证可采或免责。IT 拷贝不是合法收集。

## 2. 来源登记与 MCP 调用表

`S/D/A/R/C/L/I/G/Q/CG/V/E`。口头你们去拷、IT 已经镜像、群已读只登记 `S#`／`V#`。`E#` 是证据形态回链（授权件、同意书、系统控制方、校验记录），不是发送闸。MCP 未调用也留一行。噪声命中须登记：1993 公司法第六十七条、177 套民企、IT 拷贝即合法、调取证据通知书即内部法定格式、监管提取电子数据条款即内部已合法。

## 3. 权限依据、系统控制方与公司／个人设备边界

中央企业／地方国企／参股／民企分列。公司邮箱／办公电脑／财务系统／个人设备分列。授权未闭合：对应格待核，收集闸可半开。个保调取、42 号令、监察并行分列强制与非强制。本节禁止出 `LG#` 终稿。

## 4. 拟收集对象扫描与检查／监察／诉讼程序状态

拟收集对象、可能灭失点、已有检查或刑事文书并列。两份打架不选有利一版。已有检查不得借收集平行灭证。扫描不是闭集。本节禁止出 `LG#` 终稿。

## 5. 收集闸与路径矩阵 `Q#`

本节禁止出 `LG#` 终稿。无拟收集对象则 `Q-收` 关闭，窗口不关。`Q-拷`／`Q-镜`／`Q-手`／`Q-口`／`Q-授取`／`Q-校`／`Q-账`／`Q-67`／`Q-14`／`Q-令` 不得打开已合法取证、已完整或当然可取。`Q-出`／`Q-案`／`Q-方`／`Q-授`／`Q-报`／`Q-持` 只开接口或按主成果负触发。

## 6. 收集行 `LG#`

闸未开不得出收集终稿。闸已开且仅部分格被错误主张打中：仍出其他 `LG#` 草案，被打中的格填 `现有依据不支持`。无 `E#` 不得写已覆盖。状态 `草案`。禁止 IT 拷贝当合法收集。禁止无权限全盘镜像。禁止私人设备无依据。禁止编造哈希。禁止本窗出 `F#` 认定、案卷编目终稿、`N#` 发送稿或出境方案。

## 7. 完整性校验与禁止方法接口

缺校验：完整性格 `依据不足，无法形成结论`，禁止编造哈希、禁止写零。禁止事项必须列出。入侵、黑客、选择性毁证作为方法提出：第一次整体停止，本节不得改写为方法教程。本节不得夹带 `LG#` 终稿。不代提取、不代提交。

## 8. 财务痕迹候选、合法性红旗与最强反方

银行回单、账套分录、发票、报销、第三方付款指令分列候选，不得因常见做法写成已收集。排除只作红旗，不写排除裁定。跨境只标冲突，不给出境方案。须列 IT 拷贝即合法、无权限镜像更勤勉、手册即私人设备可取、缺哈希也能用、口头即可提取、两边选边等最强反方。

## 9. 风险与下一步

每项含可逆性。只转介：`确定调查授权范围与独立`、`制定调查方案与访谈计划`、`准备证据保全与禁毁通知`、`建立内部调查证据案卷`、`形成内部调查报告`、`协调跨境内部调查并分流涉外`、`评估律师工作产品与保密边界`、`评估内部账户冻结与资金保全`。禁止提交指令、提取指令、此致某局、出境方案。不代提交。

## 综合提问的强制降级

用户同时问能不能拷私人微信、IT 镜像算不算合法、要不要先出调查结论时，第 5–8、9 节仍只给接口和转介，对应格不支持，闸已开仍出其他 `LG#`。主成果是案卷要件：负触发转 `建立内部调查证据案卷`。提出入侵、黑客或选择性毁证：第一次整体停止，只交第 1、10 节。
