# 评估方法

本文件是可执行判断节点。IT 拷贝不是合法收集。无权限全盘镜像不是勤勉。口头授权不是可提取。授权稿不是已合法取证。手册邮箱查看权不是私人设备当然可取。缺校验不是已完整。账外候选不得因常见做法写成已收集。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、范本填满、唯一截止日、选定机关、代提交、未知写零。本任务不写调查结论，不实施访谈，不定罪，不代提交，不给出境方案。本窗 `LG#` 是收集日志行，不是工程催告 `CG#`，不是授权行 `AZ#`，不是方案行 `PL#`，不是案卷编目，不是调查认定 `F#`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1993 年公司法第六十七条、把第一百七十七条或 42 号令套民企、把 IT 拷贝写成合法收集、把调取证据通知书写成内部法定格式、把监管调查人员提取电子数据条款写成内部已合法时记为噪声。禁止指导伪造日志、违法取证、限制人身自由或删除会计资料。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`LG#` 固定列：`编号｜行类（书证／电子数据／财务痕迹）｜载体与来源系统｜控制方｜权限依据｜提取人｜见证人｜提取时点｜范围（系统×期间×对象）｜校验值｜存放｜原件或副本｜E#回链｜判断三值｜缺口G#｜最强反方｜待核`。禁止合成「已合法收集闭环」。无法判断则该条待核，**不得默认保留无权限全盘镜像或私人设备提取**。缺校验：完整性格填 `依据不足，无法形成结论`，**禁止编造哈希、禁止写零**。`E#` 只作证据形态回链。缺项记 `G#`。扫描不是闭集。

口头「你们去拷」「IT 已经镜像了」「群已读」只进 `S#`／`V#`，**不得单独算作开闸材料**。已读、揽收不得升格 `R#` 已送达。纸面草稿不是已提取。`A#` 是承认，不是已合法取证。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上完整性校验值应与算法一并保存；优先原件、原始载体；复制件须说明过程。这是方法参考，不是本窗已合法取证。手册或劳动合同写明企业邮箱查看权，不等于私人设备、私人微信、定位当然可取。

## 节点 0　分流、立场、收集闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。伪造或倒签日志、指导违法取证、入侵、黑客、撞库、木马、秘密违法录音或远控、偷拷私人设备、选择性删除不利邮件、伪造补充、限制人身自由、指导删除、阻挠合法检查、双方秘密不进负表。

整案转出只交付第 1、2、10 节，不出 `LG#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是授权范围与独立终稿 | 负触发 `确定调查授权范围与独立` |
| 主成果是调查方案与访谈计划 | 负触发 `制定调查方案与访谈计划` |
| 主成果是案卷要件矩阵 | 负触发 `建立内部调查证据案卷` |
| 主成果是发送版持有禁毁 | 负触发 `准备证据保全与禁毁通知` |
| 主成果是调查报告或事实认定 | 负触发 `形成内部调查报告` |
| 主成果是访谈提纲与笔录结构终稿 | 负触发 `准备调查访谈提纲与笔录结构` |
| 主成果是出境方案或跨境调取终稿 | 负触发 `协调跨境内部调查并分流涉外` |
| 主成果是全员监控或个保专项 | 整案转数据隐私 |
| 主成果是税务稽查实体 | 整案转税务 |
| 主成果是劳动处分、解除或性骚扰调查 | 整案转劳动 |
| 侦查、起诉、辩护为主成果 | 整案转刑事 |

审查起诉、监管检查只作程序背景。主成果才整案转。出现「收集」「镜像」「刑事」一词不是转出。已刑事立案或已有检查：不得借收集平行灭证；主成果是刑事程序则整案转刑事。

收集闸打开（可出 `LG#` 草案，仍不得标「已合法取证／已完整／已可采」）须同时满足：单方无冲突公司立场已闭合；主成果是收集日志、权限依据与完整性，不是授权终稿、案卷要件或调查结论；至少一条可编号拟收集对象或材料碎片。从零：有拟收集对象或碎片即可开或半开，缺项记 `G#`。口头指示、IT 已拷、已读不算单独开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

收集闸部分打开：授权主体职权、个保边界或校验未核验，但已有可编号拟收集对象；或无书面可提取依据但已有拟收集对象；对应格待核；仍交十节；不得标终稿 `已形成`。授权未闭合且主成果仍是收集日志：半开，转介授权窗，**不负触发**。不可逆提取不得在草案阶段实施。

收集闸关闭（仍正触发）：无一可编号拟收集对象且无一材料碎片。「今天必须出已合法取证终稿」而无最小事实不得开闸。不出 `LG#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `LG#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「IT 拷贝即合法收集」「无权限全盘镜像即勤勉」「手册邮箱权即私人设备可取」「口头授权即可提取」「授权稿即已合法取证」「缺校验仍已完整」「账外常见做法即已收集」「公司法第六十七条或 42 号令第十四条即已可取证」「调取证据通知书即内部法定格式」「交收集表即从轻」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `LG#` 草案。无权限全盘镜像、私人设备无依据行**不得写入可执行 `LG#`**。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合、无书面可提取依据但已有拟收集对象或材料碎片，then 收集闸部分打开，仍交十节，不是整体停止。
若 if 公司立场已闭合但无一拟收集对象且无一碎片，then 收集闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造或倒签收集日志、指导违法取证、入侵系统、购买黑客服务、撞库、木马、秘密违法录音或远控、偷拷私人设备、选择性删除不利邮件、伪造补充、限制人身自由、指导删除会计资料、借收集平行灭证、打击报复或阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。禁止「该部分停止后继续收其余」。

## 节点 1　主体、权限依据与强制接口

中央企业／地方国企／参股／民企分列。每类对象单独写权限依据：公司邮箱、办公电脑、财务系统、门禁、个人手机、私人微信、定位、生物识别。无权主体：授权字段停止；有拟收集对象则收集闸半开，不可逆提取不得实施。

检索锚点（写入 `L#` 前须核验）：

- 公司法（2023 修订）第六十七条：董事会职权不等于已签发调查授权、已可提取。噪声：1993 年第六十七条。
- 公司法第一百七十七条：不套民企必须取证上报。
- 42 号令第二条、第四十条、第十四条：第十四条组织或参与调查不等于已可取证。
- 个保法第六条、第十三条：人力资源管理所必需 ≠ 全员邮箱、私人微信、定位、生物识别。
- 监察法（2024 修正）第十八条：不得伪造、隐匿、毁灭。第四十三条只作禁止动作对标。
- 刑法第一百六十二条之一、第三百零七条、第三百零八条只作红旗。
- 法释〔2019〕19 号电子数据真实性综合判断：缺校验则完整性依据不足，不是已可采。

强制接口与非强制对标分列。非法取证排除效果只作红旗，本窗不写排除裁定。金融监管调查人员提取电子数据条款、公安机关登记保存、检察院调取证据通知书不是内部法定格式。

## 节点 3　收集行 `LG#`

按已出现载体与对象扫描，不是默认闭集。范围用系统 × 期间 × 对象闭合。一行一载体／一次提取。用户要求「IT 已经整盘镜像了，哈希回头补」：该行不得写入可执行 `LG#`，完整性格 `依据不足，无法形成结论`，窗口不关。用户要求「手册写了邮箱权，私人微信和定位一起拷」：超出部分该格不支持，不得写入可执行行。

建议行型（按已出现事实选用，**不是默认闭集**）：

| 编号 | 含义 | 本窗允许 | 禁止 |
| --- | --- | --- | --- |
| `CG-书` | 书证／合同／制度文本 | 来源、是否原件、存放 | 写成已可采 |
| `CG-电` | 电子数据／企业邮箱／办公电脑 | 权限依据、校验、见证人 | 无权限全盘镜像；私人设备无依据 |
| `CG-财` | 财务痕迹 | 回单／分录／发票／报销／第三方付款分列 | 账外常见做法即已收集 |
| `CG-门` | 门禁或办公系统日志 | 范围与权限接口 | 全员定位／生物识别 |

热冲突强制处理（不得保留为可执行行）：

- 无权限全盘镜像、IT 拷贝冒充合法收集 → 该格不支持；仍出其他 `LG#`。
- 私人设备、私人微信、定位、生物识别无单独合法基础 → 删除或该格不支持。
- 缺校验、口头备份、哈希回头补 → 完整性依据不足；禁止编造。
- 账外候选因常见做法写成已收集 → 该格不支持。
- 入侵、黑客、撞库、木马、秘密违法录音或远控、偷拷私人设备、选择性删除不利邮件、伪造补充 → 作为方法提出则整体停止。
- 干扰侦查或对抗合法检查、借收集平行灭证 → 指导则整体停止。

无 `E#` 不得写已覆盖、已合法取证或已完整。状态 `草案`。实务「至少两名」「写保护」「原件优先」写入方法参考，不得写成已合法取证。

## 节点 4　禁止方法、邻窗接口、可逆性与转介

必须写入禁止事项接口：不得入侵系统、不得购买黑客服务、不得撞库或木马、不得秘密违法录音或远控、不得偷拷私人设备、不得选择性删除不利邮件、不得伪造补充、不得限制人身自由、不得销毁会计资料、不得向被调查人通风。用户要求写规避检查：整体停止。

案卷要件转 `建立内部调查证据案卷`。调查结论转 `形成内部调查报告`。发送版持有通知转 `准备证据保全与禁毁通知`。跨境调取转 `协调跨境内部调查并分流涉外`，本窗不给出境方案。授权未闭合只开授权接口，不负触发，除非主成果是授权终稿。

可逆与不可逆分列。不可逆（开始镜像全员邮箱、提取私人设备、格式化旧档、对外发送收集结果）不得在草案阶段实施。禁止提交指令。不代提取、不代提交。不实施访谈。不写调查结论。

下一步只转介：授权、方案、案卷、禁毁、报告、跨境、工作产品。禁止一次写完全部邻窗终稿。

已有监察或检查 `R#`：不得借收集平行灭证。刑法第一百六十二条之一只作红旗，不得指导删除。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：用户要求「手册写了可以查工作邮箱，私人微信和全员定位一起镜像，哈希回头补。」收集闸打开。`Q-手`、`Q-镜`、`Q-校` 不打开为可靠路径。第 6 节不得把私人微信、定位或无校验镜像写入可执行 `LG#`；对应格 `现有依据不支持` 或完整性依据不足；仍可出企业邮箱／办公电脑等其他草案行。不关窗。不代提取。

场景②：用户主成果是「把收集到的材料做成要件案卷矩阵并下调查结论。」负触发 `建立内部调查证据案卷` 或 `形成内部调查报告`（以主成果为准），一句路由，不填本窗实体十节。
