# 评估方法

本文件是可执行判断节点。IT 拷贝不是合法收集。公司电脑不是当然全盘。个保法第十三条不是私人微信。缺哈希不是已保全。账外常见不是已收集。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、范本填满、唯一截止日、选定机关、代提交、未知写零。本任务不实施取证，不代镜像，不出授权书终稿、方案终稿、案卷矩阵、持有通知或调查结论。本窗 `LG#` 是收集日志行，不是 `CG#`，不是 `CL#`，不是 `AZ#`，不是 `PL#`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、把个保法第十三条写成私人微信授权、把 IT 拷贝写成合法收集时记为噪声。禁止指导入侵、删除会计资料。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`LG#` 固定列：`编号｜对象类型（书证／电子数据／财务痕迹）｜来源系统或载体｜控制方（公司／个人／第三人）｜权限依据回链｜拟设动作（只规划）｜提取人／见证人接口｜时间／范围｜哈希／完整性计划｜原始载体或视为原件介质｜存放位置｜禁止动作｜E#回链｜判断三值｜缺口G#｜最强反方｜待核`。禁止合成「已收集闭环」。无 `E#` 不得写已覆盖、已提取、已保全。缺校验：完整性 `依据不足，无法形成结论`。状态 `草案`。财务痕迹必须分列：银行回单／账套分录／发票／报销单／第三方付款指令。禁止 `PL#` `AZ#` `CL#` `CG#` `EV#` `F#` `ACT#` `Dsc#` `PT#` `RF#`。

口头「把硬盘拿来」「IT 已经拷了」「群已读」只进 `S#`／`V#`，**不得算作开闸材料**。截图不是已保全。IT 拷贝不是合法收集。`A#` 是承认，不是已提取。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

## 节点 0　分流、立场、收集闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。入侵、黑客、秘密录音、选择性删邮、伪造日志、双方秘密不进负表。

整案转出只交付第 1、2、10 节，不出 `LG#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是授权终稿 | 负触发 `确定调查授权范围与独立` |
| 主成果是方案／访谈计划 | 负触发 `制定调查方案与访谈计划` |
| 主成果是案卷矩阵 | 负触发 `建立内部调查证据案卷` |
| 主成果是持有／禁毁发送稿 | 负触发 `准备证据保全与禁毁通知` |
| 主成果是访谈提纲笔录 | 负触发 `准备调查访谈提纲与笔录结构` |
| 主成果是调查报告 | 负触发 `形成内部调查报告` |
| 主成果是全员监控／个保／出境专项 | 整案转数据隐私 |
| 主成果是税务稽查实体 | 整案转税务 |
| 主成果是劳动处分、解除或性骚扰 | 整案转劳动 |
| 侦查、起诉、辩护为主成果 | 整案转刑事 |

审查起诉、监管检查只作程序背景。主成果才整案转。出现「收集」「邮件」一词不是转出。

收集闸打开（可出 `LG#` 草案，仍不得标「已收集／已保全／已合法取证」）须同时满足：单方无冲突的公司或其调查受托律师立场已闭合；主成果是收集日志、权限依据、完整性与禁止项；至少一条可编号拟设收集行。从零：有拟设即可开或半开。口头已拷、已读不算开闸材料。双方秘密或第一次入侵不是关闸条件，走整体停止。

收集闸部分打开：无完整书面授权但已决定要查且有拟设对象；或公私权属、个保、哈希未核验。对应格待核。仍交十节。不得标终稿 `已形成`。

收集闸关闭（仍正触发）：无一拟设收集行。「今天必须出已收集终稿」而无最小事实不得开闸。不出 `LG#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `LG#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「IT 拷贝即合法」「公司电脑当然全盘」「个保 13 即私人微信」「账外常见即已收集」「缺哈希仍已保全」「交日志即从轻」「第十四条即已取证」「口头已拷即已收集」**不关窗**。对应格 `现有依据不支持` 或完整性依据不足。闸已开仍出其他 `LG#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 被调查对象代理要出收集日志，then 立场无法闭合，整体停止。
若 if 公司立场已闭合、无完整授权但已有拟设收集行，then 收集闸部分打开，仍交十节，不是整体停止。
若 if 公司立场已闭合但无一拟设，then 收集闸关闭，仍交十节，不是整体停止。
若 if 提出入侵、购买黑客、秘密录音、偷拷私人设备、选择性删邮、伪造或倒签日志、指导删除、借收集平行灭证、限制人身自由、阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与权限分列

中央企业／地方国企／参股／民企分列。公司邮箱／办公电脑／财务系统／门禁 vs 个人手机／私人微信／个人云盘分列。无合法同意且无机关文书：私人设备行不得设计提取。权属争而未闭合不得推定为企业设备。BYOD 混用不得推定为企业设备。企业微信工作区不等于私人微信。手册邮箱查看权不等于私人设备当然可取。

检索锚点（写入 `L#` 前须核验）：个保法第六条、第十三条；公司法第六十七条、第一百六十八条、第一百七十七条；42 号令第二条、第十四条、第四十条；民诉非法证据排除（通常解释第一百零六条）只开接口；民事诉讼证据规定电子数据原件与完整性；监察法第十八条；刑法第一百六十二条之一、第三百零七条、第三百零八条只作红旗；行政处罚法第三十二条。

## 节点 3　收集日志行 `LG#`

按已出现对象扫描，不是默认闭集。一行一条。财务痕迹分列，禁止合成「账已取回」。账外候选不得因常见做法写成已收集。

热冲突不得保留为可执行行：入侵、木马、购买黑客、秘密违法录音、选择性删邮、导出后毁源、伪造或倒签日志、偷拷私人设备。作为方法提出则整体停止。

公司电脑全盘含私人微信／私人云：超出部分该格不支持或删除。无哈希不得写完整性支持。无 `E#` 不得写已覆盖。状态 `草案`。

## 节点 4　禁止方法、完整性与转介

必须写入：不得入侵／木马／购买黑客、不得秘密违法录音或远控、不得选择性删邮、不得伪造或倒签日志、不得偷拷私人设备、不得限制人身自由、不得指导删除会计资料。已有监察 `R#`：不得借收集日志平行灭证。刑法第一百六十二条之一只作红旗，不得指导删除。

完整性只开接口（哈希算法、原始载体、双人在场、存放）。缺校验不得写成已保全。不可逆（全员镜像、私人设备提取、格式化）不得在草案阶段实施。第 7 节不得夹带 `LG#` 终稿。不代提取、不代镜像、不代提交。

下一步只转介：授权、方案、持有、案卷、提纲、报告、工作产品、跨境、回扣链路、账户冻结。禁止提取指令、删除指令、此致某局。
