# 合法收集书证电子证与财务痕迹

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。本窗是收集日志草案，范本只借栏目，**不要**升格「已合法取证／已完整／已保全／调取证据通知书即内部法定格式」。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现 IT 拷贝冒充合法收集、无权限全盘镜像、个保第十三条冒充私人微信可取、缺哈希仍称已保全的反例；案例只比较事实差异与翻转条件，不写成必然结果。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《民法通则》《民法总则》或其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下（公司或其调查受托律师，互斥；不允许被调查对象代理），形成内部调查收集日志草案：收集闸、主体与强制接口、`Q#` 路径、`LG#` 收集日志行（对象类型／来源系统／权限依据／拟设动作／提取人见证人／范围／哈希完整性／存放／原件副本／禁止动作）。本窗 `LG#` 是收集日志行，不是工程催告 `CG#`，不是授权 `AZ#`，不是方案 `PL#`，不是案卷编目。IT 拷贝不是合法收集。公司电脑不是当然全盘。个保法第十三条不是私人微信。缺哈希不是已保全。账外常见不是已收集。交日志不是从轻。不写调查结论。不代提取。不给出境方案。不保证可采或免责。不代提交。

`depends-on` 为空。授权终稿转 `确定调查授权范围与独立`。方案终稿转 `制定调查方案与访谈计划`。案卷矩阵转 `建立内部调查证据案卷`。持有禁毁发送稿转 `准备证据保全与禁毁通知`。调查报告转 `形成内部调查报告`。跨境调取转 `协调跨境内部调查并分流涉外`。全员监控或个保专项转数据隐私。税务稽查实体转税务。

## 工作边界

正触发：已经决定调查，需要按合法权限收集书证、电子数据和财务痕迹并留下可复核日志，而不是出调查结论、案卷要件或发送版禁毁通知。材料碎片、授权未核验仍正触发：有可编号拟设收集行则收集闸打开或半开，第 6 节出 `LG#` 草案，缺项记 `G#`。无书面可提取依据但有拟设对象：部分打开。无一拟设、又要求「今天必须出已合法取证终稿」才关闸，不出 `LG#` 终稿，窗口不关。用户要把 IT 拷贝写成合法收集、把公司电脑写成当然全盘、把个保法第十三条写成私人微信授权、把账外常见写成已收集、把缺哈希写成已保全、把交日志写成从轻，仍正触发：对应格填 `现有依据不支持`，窗口不关；闸已开仍出其他 `LG#` 草案。不得因「不入侵」或「不写调查结论」改走负触发关窗。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是授权范围与独立终稿（转 `确定调查授权范围与独立`）；
- 主成果是调查方案与访谈计划（转 `制定调查方案与访谈计划`）；
- 主成果是案卷要件矩阵（转 `建立内部调查证据案卷`）；
- 主成果是发送版持有禁毁通知（转 `准备证据保全与禁毁通知`）；
- 主成果是调查报告或事实认定（转 `形成内部调查报告`）；
- 主成果是访谈提纲与笔录结构终稿（转 `准备调查访谈提纲与笔录结构`）；
- 主成果是出境方案或跨境调取终稿（转 `协调跨境内部调查并分流涉外`）；
- 主成果是全员监控或个保／数据专项体系（转数据隐私领域）；
- 主成果是税务稽查实体（转税务领域）；
- 主成果是劳动处分、解除或职场性骚扰调查（转劳动领域）。

双方秘密、伪造或倒签收集日志、入侵系统、购买黑客、秘密违法录音、偷拷私人设备、选择性删邮、指导删除、限制人身自由、阻挠合法检查**不在负触发表**，走整体停止。「IT 拷贝即合法」「公司电脑当然全盘」「个保 13 即私人微信」「账外常见即已收集」「缺哈希仍已保全」「交日志即从轻」「第十四条即已取证」**不在负触发表**，该格 `现有依据不支持`，窗口不关。「不入侵」「不写调查结论」「不保证可采」是交付禁令，不是负触发。

## 建立工作坐标

确认：书面或拟设授权；单方立场；系统控制方、公司设备与个人设备边界、财务账套、拟收集对象；法域；当前检查、诉讼、监察或刑事状态。

口头「把硬盘拿来」「IT 已经拷了」「群已读」只登记 `S#`／`V#`。不得升格已提取、已保全或已合法取证，**不得单独算作开闸材料**。截图不是已保全。纸面收集草稿不是已提取。

同时掌握公司与被调查对象相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。公司已开口且委托就是收集日志、且未掌握对方秘密时，可推定公司或其调查受托律师立场。被调查对象代理不是本窗立场。无书面可提取依据但公司立场已闭合、且已有拟设收集行：收集闸部分打开，仍交十节，不是整体停止。无一拟设：收集闸关闭，仍交十节，不是整体停止。提出入侵、黑客、选择性删邮、伪造日志、限制人身自由：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认（不是已合法取证，不是已保全）；`R#` 机关或生效文书；`C#` 内部授权、手册或系统权限条款；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`LG#` 收集日志行；`V#` 版本；`E#` 证据形态回链（授权范围、载体控制方、校验值，不是发送闸，不是已提取证明，不是案卷矩阵）。禁止 `N#`、`EV#`、`M#`、`F#`、`ACT#`、`P#`、`K#`、`O#`、`H#`、`B#`、`U#`、`X#`、`HD#`、`W#`、`T#`、`OR#`、`LV#`、`TR#`、`PX#`、`LD#`、`SP#`、`CH#`、`CS#`、`PT#`、`RF#`、`RT#`、`AU#`、`AZ#`、`PL#`、`CL#`、`CG#`、`SA#`、`Dsc#`。技能正文中的条号是检索锚点，不是已核验 `L#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止合成「已合法收集闭环」一笔。扫描不是闭集。未知件数、校验值、金额不写零。稿件状态默认 `草案`。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：个保法第六条最小必要、第十三条人力资源管理所必需，不等于私人微信、私人手机、定位、生物识别或全员邮箱。公司法第六十七条董事会职权不等于已合法取证。第一百六十八条不含参股。第一百七十七条不套民企必须交日志上报。42 号令第二条、第四十条只约束中央企业；第十四条组织或参与调查不是已合法取证。民诉非法证据排除（通常解释第一百零六条）只开接口，不写裁定。民事诉讼证据规定电子数据原件或视为原件、真实性完整性综合判断，无哈希不得写成已保全。监察法（2024 修正）第十八条如实提供，不得伪造、隐匿、毁灭。刑法第一百六十二条之一、第三百零七条、第三百零八条只作红旗，不得指导删除。行政处罚法第三十二条交日志不等于从轻。噪声：失效《合同法》、IT 拷贝即合法、公司电脑当然全盘、个保 13 即私人微信、账外常见即已收集、缺哈希仍已保全、交日志即从轻、刑事勘验笔录即内部法定格式。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变个保边界、完整性或排除接口的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补 IT 拷贝冒充合法收集、全盘含私人微信、缺哈希标已保全、账外常见标已收集、口头已拷冒充已提取的反例。双人在场、原始载体、哈希是方法参考，不是本窗已实施取证。
- `search_template`（optional）只借来源、提取人、见证人、时间、范围、校验、存放栏目。刑事电子数据勘验笔录、公证保全、人民法院调查令不是内部收集法定格式，不得升格已收集或已保全。

工具不可用时继续拟设对象和 `LG#` 编目；个保边界、完整性、排除、施行日字段停止。不得拒跑，不得凭记忆写成 IT 拷贝即合法或缺哈希仍已保全。

## 判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、收集闸与不关窗

主成果才整案转出。入侵、选择性删邮、双方秘密第一次停。IT 拷贝即合法、公司电脑当然全盘、个保 13 即私人微信不关窗。闸关仍交十节，第 6 节不出 `LG#` 终稿。

### 2. 主体、权限分列与强制接口

中央企业／地方国企／参股／民企分列。公司邮箱／办公电脑／财务系统／门禁 vs 个人手机／私人微信分列。授权未闭合：收集闸可半开，不可逆提取不得实施。

### 3. 收集闸与路径 `Q#`

本节禁止出 `LG#` 终稿。有可编号拟设收集行：闸打开或半开。无一拟设才关闸，窗口不关。口头拿盘、IT 已拷、已读不得单独开闸。

### 4. 收集日志行 `LG#`

对象、来源、权限、拟设动作、提取人见证人、范围、哈希、存放分列。财务痕迹分列回单／分录／发票／报销／第三方指令。缺校验：完整性依据不足。状态 `草案`。

### 5. 禁止方法、完整性接口与转介

入侵、黑客、选择性毁证作为方法提出：第一次整体停止。案卷、报告、跨境、禁毁只开接口。不写调查结论。不给出境方案。第 7 节不得夹带 `LG#` 终稿。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出入侵、购买黑客、秘密录音、偷拷私人设备、选择性删邮、伪造或倒签日志、指导删除、限制人身自由、借收集平行灭证、阻挠合法检查。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无书面可提取依据但公司立场已闭合：不是整体停止；有拟设则部分打开，无一拟设则闸关闭，仍交十节。
- `字段停止`：授权、个保边界、权属公私争、校验值、施行日未核验。IT 拷贝即合法、公司电脑当然全盘、个保 13 即私人微信、账外常见即已收集、缺哈希仍已保全、交日志即从轻、第十四条即已取证：该格 `现有依据不支持`，窗口不关；闸已开仍出其他 `LG#` 草案。
- `目标停止`：主目标变为授权终稿、调查方案、案卷要件、发送版禁毁、调查报告、出境方案。

禁止指导伪造日志、违法取证、限制人身自由或删除会计资料。不给胜诉率。不定罪。不保证可采或免责。不选定机关。不代提交。未知不写零。不写调查结论。不把 IT 拷贝写成合法收集。不把私人设备写成当然可取。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。收集闸关闭仍交十节，第 6 节不出 `LG#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `LG#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。收集闸未打开时不得交付「已合法取证」或「已保全」。边界见 [路由](references/routing.md)。
