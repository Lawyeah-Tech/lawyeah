# 企业合规领域边界

本表只说明归属。每次路由先核对 [当前能力地图](capability-map.md)；未安装入口输出 `unavailable`。

| 相邻 | 本包入口 | 转出 |
| --- | --- | --- |
| 刑事辩护与刑事代理 | 评估或报告中的刑事红旗、移送接口 | 辩护、控告、自首、取保、阅卷、量刑 |
| 劳动用工与劳动争议 | 调查后的处分接口；举报报复的保护建议 | 职场违纪调查、性骚扰专项、解除劳动合同、纪律处分决定、薪酬工时 |
| 数据、隐私与网络安全 | 综合治理中的数据红旗 | 个人信息合法性、影响评估、出境、等保、网安事件专项体系 |
| 竞争法与反垄断 | 综合机制中的竞争红旗 | 垄断协议、滥用支配地位、经营者集中、不正当竞争专项评估 |
| 合同审查与起草 | 无。未进入合规机制只要改合同或出稿：本窗搁置，只说明不实施 | 审查起草领域（用户单独策略） |
| 公司治理与股权 | 董监高合规职责接口 | 章程、股东会、股权结构、公司决议本身 |
| 税务 | 账簿完整性红旗 | 税务处理、稽查实体 |
| 金融 | 通用治理接口 | 银行保险机构行业合规办法 |
| 医疗医药 | 通用廉洁接口 | 药品购销回扣行业细则 |
| 涉外 | 跨境调查境内段 | 出口管制、制裁、境外当地法 |
| 行政争议 | 检查应对中的救济接口 | 行政复议、行政诉讼文书 |
| C 端小微体检 | 专业总图，不降成清单 | 大众第一轮风险体检 |
| C 端供应商清单 | 专业第三方机制/筛查/尽调（已安装） | 大众勾选清单 |
| C 端广告 / APP 隐私 / 劳动规章 | 无 | 对应大众专项 |

综合合规主轴可留本包；专项段只分流，不把专项规则写入本包结论。
