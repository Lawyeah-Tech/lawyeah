# 原子 Skill 选择方法

## 一、先识别成果

先问这一次要拿到什么可独立验收的成果，而不是按行业、罪名或“反贿赂”标签匹配：

P0：

- 企业级合规风险总图；
- 是否启动内部调查；
- 证据持有/禁毁通知；
- 向机关的主动披露或自查报告；
- 调查证据案卷；
- 舞弊损失测算；
- 内部调查报告；
- 普通整改方案；
- 监管检查应对；
- 涉案企业合规整改验收。

P1 另包括：体系有效性与义务地图、董监高职责、国企办法差距、集团穿透、行业叠加分流、上市廉洁内控交叉、董事会汇报；体系框架与章程级制度、三道防线、政策层级、培训、有效性评价、集团政策落地；举报渠道、单件可查性、保护与报复评估；调查授权、方案、收集、访谈提纲、特权边界、处置路径、对内对外口径、回避；反贿赂风险与制度、礼品赞助、利益冲突、回扣账外、公职接触、账簿、销售激励；第三方机制、筛查、尽调底稿、中止通知、中间人费用；突击预案、独立监察、交卷清单、民事谈判与起诉、根因、整改跟踪、舆情披露交叉、跨境调查境内段、内部资金保全。

未安装的 P2（匿名件处理、结案重开、高风险准入监控、外聘分工、保险接口等）输出 `unavailable`。

## 二、再确认上下文

只确认会改变入口的最小信息：

1. 单方立场与授权（公司还是被调查人）；
2. 是否已有具体线索、检查文书或检察程序；
3. 本次要分析、发通知、建卷、测算、出报告还是应对现场；
4. 主成果是否其实是刑事、劳动、数据或竞争专项。

## 三、处理混合请求

1. 列出每项可独立验收的成果及对应入口；
2. 只问：`这次要先取得哪一项成果？`；
3. 回答前不指定主要 Skill，不暗示必须先评估再调查；
4. 用户确认后只启动所选入口；等价评估、案卷或测算可由用户或律师提供。

## 四、停止

立场冲突、专项主轴或未进入合规机制的合同改稿，说明边界并转出，不代做。信息不足时每轮只追问一个最能改变入口的问题。
