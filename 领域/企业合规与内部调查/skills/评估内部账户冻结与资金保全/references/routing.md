# 边界与路由

## 正触发

担心涉案资金被转走，需要评估内部止付权限、合同或财务依据和违法冻结红旗，而不是写保全申请书或划走个人账户。从零、碎片、权属未核验、无书面评估授权仍正触发：有账户或依据则闸开或半开，出 `ZF#` 草案，保持草案。内部止付即已保全、口头冻结即已止付、担心转走必须划走，仍正触发。

双方秘密、指导划走个人账户、锁工资卡、扣证件逼还、转移已被查冻资金、伪造冻结凭证、阻挠合法查冻的停止，优先于负触发。上述信号不在下表。「内部止付即已保全」「口头冻结即已止付」「公司账户止付即可划个人账户」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 法院保全申请书全文 | 诉讼保全接口／争议程序文书 |
| 民事追偿谈判终稿 | `谈判民事追偿与返还方案` |
| 起诉状或诉材终稿 | `准备民事追偿诉讼材料` |
| 劳动扣工资或解除决定 | 劳动领域 |
| 刑事冻结、查封程序或辩护 | 刑事领域 |
| 调查报告终稿 | `形成内部调查报告` |
| 舞弊损失测算终稿 | `测算舞弊损失与追偿` |

不得因「不替代法院保全」关窗。指导划走个人账户走整体停止，不是负触发。拟止付评估仍正触发，不得写成已保全或已可划转。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、解除、工伤、克扣工资主轴 | 劳动领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |
| 垄断、滥用支配、经营者集中 | 竞争法领域 |
| 税务处理决定、稽查实体 | 税务领域 |
| 银行保险机构行业合规办法主轴 | 金融领域 |
| 药品购销回扣行业细则主轴 | 医疗医药领域 |
| 出口管制、制裁名单 | 涉外领域 |
| 章程、股权、任免本身为主成果 | 公司治理领域 |

综合内部止付评估主轴可留本任务。审查起诉、监察查冻只作背景，主成果才转。出现「冻结」「保全」「止付」一词不是转出。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 只要法院保全申请书 | 诉讼保全接口 |
| 只要追偿谈判方案 | `谈判民事追偿与返还方案` |
| 只要起诉材料 | `准备民事追偿诉讼材料` |
| 扣工资或解除 | 劳动领域 |
| 资金链路未查清 | `评估回扣账外暗中与资金链路` |
| 只要损失测算终稿 | `测算舞弊损失与追偿` |

## 易混

停付公司对供应商的应付款不是冻结个人存款。担心转移不是已经有权划走。内部止付不是法院已保全。口头冻结不是已止付。公司账户止付不是可划个人账户。工资卡不得擅自冻结。农民工工资专用账户不得因调查冻结。本窗闸名只能是止付闸，禁止复用保全闸、冻结闸。本窗 `ZF#` 不是返还窗 `FH#`，不是诉材窗 `QS#`，不是跨境窗 `KJ#`。「已经司法冻结的先转走」整体停止。本窗不执行划转，不代提交。不选定法院。
