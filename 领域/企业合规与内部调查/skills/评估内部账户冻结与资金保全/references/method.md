# 评估内部账户冻结与资金保全方法

本文件是可执行判断节点。内部止付不是法院已保全。口头冻结不是已止付。公司账户止付不是可划个人账户。担心转走不是必须立即划走。停付供应商应付款不是冻结个人存款。工资卡不得擅自冻结。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、唯一截止日、选定法院、代提交、未知写零。本任务不定罪，不替代法院保全，不指导划走个人账户。本窗闸名只能是止付闸，禁止复用保全闸、返还闸、诉材闸、跨境闸。本窗 `ZF#` 是止付行，不是 `FH#`／`QS#`／`KJ#`。英文 id 禁止使用，一律用中文技能名 `评估内部账户冻结与资金保全`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、把内部止付写成已保全、把口头冻结写成已止付、把工资卡写成可冻、把未知金额写成零时记为噪声。禁止指导划走个人账户或规避司法查冻。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现账户扫描，不是默认闭集。
`ZF#` 固定列：`编号｜账户权属｜止付依据｜范围与金额｜期限｜红旗｜司法或监察接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「内部止付即已保全」。无 `E#` 不得写已止付、已保全或已可划转。`E#` 只作证据形态回链，不是发送闸。扫描不是闭集。缺项记 `G#`。承认只进 `S#`／`D#`，不得占用 `A#`。未知金额写 `未知`／`G#`，禁止写零。

口头「先冻住再说」「工资卡一起冻」「内部冻了就等于保全了」只进 `S#`／`V#`，**不得单独算作开闸材料**。已读不得升格已止付。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：财产保全由人民法院依裁定实施，内部止付没有对外冻结效力。协助执行后擅自处分或解冻已冻结款项，构成妨碍司法。内部调查不得限制人身自由；扣留设备须基于权属和事先约定。农民工工资专用账户不得因支付农民工工资之外的原因被查封、冻结或者划拨。

## 节点 0　分流、立场、止付闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、指导划走个人账户、锁工资卡、扣证件逼还、转移已被查冻资金、伪造冻结凭证、阻挠合法查冻不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `ZF#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是法院保全申请书全文 | 负触发，转诉讼保全接口 |
| 主成果是民事追偿谈判终稿 | 负触发 `谈判民事追偿与返还方案` |
| 主成果是起诉状或诉材终稿 | 负触发 `准备民事追偿诉讼材料` |
| 主成果是劳动扣工资或解除决定 | 整案转劳动 |
| 主成果是刑事冻结、查封程序或辩护 | 整案转刑事 |
| 主成果是调查报告终稿 | 负触发 `形成内部调查报告` |
| 「不替代法院保全」「不定罪」 | 交付禁令，不是负触发 |
| 指导划走个人账户或规避查冻 | 整体停止，不是负触发 |

审查起诉、监察查冻只作程序背景。主成果才整案转。出现「冻结」「保全」「止付」一词不是转出。

止付闸打开（可出 `ZF#` 草案，仍不得标「已止付／已保全／已可划转」）须同时满足：单方无冲突公司立场已闭合；主成果是内部止付评估，不是保全申请书、不是追偿终稿、不是划款指令；至少一项可编号账户切片或止付依据碎片。口头「先冻住」不算单独开闸材料。

止付闸部分打开：已有碎片，但权属或依据未闭合；对应格待核；仍交十节。

止付闸关闭（仍正触发）：无一可编号碎片。「今天必须出已保全／已划走终稿」而无最小碎片不得开闸。不出 `ZF#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `ZF#` 终稿，**第 7 节不得出保全申请书或划款指令**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「内部止付即已保全」「口头冻结即已止付」「公司账户止付即可划个人账户」「担心转走必须立即划走」「停付供应商即冻结个人存款」「未知写零」「交表即从轻」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `ZF#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无一可编号碎片，then 止付闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出擅自划走个人账户、锁工资卡、扣证件逼还、转移已被查冻资金、伪造冻结凭证、阻挠合法查冻，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　账户权属

一行一个账户。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `ZF#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 权属 | 公司账户／共管／个人账户／工资专用账户分列 | 个人账户设计擅自划转；工资专户因调查冻结 |
| 依据碎片 | 授权、合同停付条款、财务制度分列 | 口头「先冻住」当依据 |
| 查冻状态 | 已有司法或监察查冻分列 | 设计转移对抗 |

检索锚点（写入 `L#` 前须核验）：

- 劳动法第五十条：不得克扣工资。劳动合同法第三十条及时足额支付。
- 保障农民工工资支付条例第三十三条：工资专用账户不得因其他原因冻结划拨。
- 民事诉讼法财产保全及法释〔2020〕21 号第十五条：冻结银行账户须明确数额；本窗只开接口。
- 储蓄管理条例第十四条：不得违反规定拒绝支付储蓄存款。

资金在公司账户：可评估内部止付。在个人账户：不得设计擅自划走或冻结个人财产，只能评估民事请求、报警或法院保全接口。权属不明：操作字段停止。

## 节点 3　止付行 `ZF#`

按已出现账户扫描，不是默认闭集。每条须能指向权属、依据、范围和是否只开司法接口。口头冻结、担心转走、公司账户止付单独不足支撑已保全或可划个人账户。

无 `E#` 不得写已止付、已保全或已可划转。状态 `草案`。一次只推荐下一步。

热冲突强制处理：

- 内部止付即已保全／口头冻结即已止付／公司账户即可划个人／担心转走必须划走／工资卡可冻 → 该格不支持；仍出其他 `ZF#`。
- 无一碎片 → 关闸，不出 `ZF#` 终稿，窗口不关。
- 指导划走个人账户、锁工资卡、转移已查冻资金、伪造冻结凭证 → 整体停止，不是该格不支持。

## 节点 4　保全、追偿与劳动接口

第 7 节只开接口，不得夹带 `ZF#` 终稿、保全申请书或划款指令绕闸。闸关闭时第 7 节可写「闸未开，转介待账户编号」，不得补写已保全。已有查冻：依法配合，不得设计规避。止付是风控手段，不是债务确认。

下一步只转介：`谈判民事追偿与返还方案`、`准备民事追偿诉讼材料`、`评估调查后处置路径`、`合法收集书证电子证与财务痕迹`、`形成内部调查报告`。禁止此致某法院。不选定法院。不代提交。

若 if 用户催促「内部冻了就是保全／工资卡一起冻／填满已划走终稿」，then 该格 `现有依据不支持`，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：经销商回扣调查，公司账户有待付佣金，用户主张内部止付就算已保全、口头通知银行就算已止付、员工工资卡一起冻、金额不清楚先写零、担心转走必须立刻划到公司账。止付闸打开或半开。`Q-完`、`Q-口`、`Q-工`、`Q-转`、`Q-零` 不打开为可靠路径。第 6 节不得把已保全、已止付、可划个人账户写入可执行 `ZF#`；对应格 `现有依据不支持`；仍出公司账户依据待核、司法保全接口、金额 `G#` 等其他 `ZF#`。不关窗。不写保全申请书。不选定法院。

场景②：用户同时交出公司「先把个人卡里的钱划过来」口径与被调查对象「那是工资」材料，要求选对公司有利的一版，并指导「已经司法冻结的那笔转到境外」。命中双方秘密＋划走个人账户／转移已查冻资金。第一次整体停止。只交第 1、10 节。不出 `ZF#`。不得问代表哪一方后继续。不以「坚持」为门槛。
