# 主动披露方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。披露状态只用 `草案`、`待发送`、`发送闸关闭`、`已提交待签收`、`停止`。禁止胜诉率、必然免责、刑事既遂、把提交写成已获从轻减轻或不起诉、唯一截止日、选定机关、代提交、未知写零。本任务不定罪，不代提交。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、把从轻条款写成必然免罚、把 42 号令报告义务套到全部民企、把猜测写成已查清、把快递发出写成机关已认定时记为噪声，不得写入 `L#`。禁止伪造情节、隐匿不利事实、顶替责任人或倒签。

`Dsc#` 固定列：`编号｜分账（已核实／情景／无法估计）｜事实摘要｜支持来源｜不利事实是否入稿｜金额（未知写无法估计，禁止写零）｜是否写入正文｜从宽接口（待核／不打开）｜判断三值｜披露状态｜待核｜转介｜来源回链`。不得把提交写成已获从轻、减轻或不起诉。

口头「已经报过」、快递单只进 `S#`／`V#`，不得升格 `E#` 机关已受理或已认定。

## 节点 0　分流、立场、发送闸与不关窗

整案转出或闸关闭只交付第 1、2、10 节或标注停止的 `Dsc#`，不得交付待发送终稿或已获宽大。闸部分打开时：仅对可回链的已核实行给出草案，情景和无法估计行停止或不打开写入。

| 信号 | 处理 |
| --- | --- |
| 主成果是内部调查报告、不对外 | 负触发 `形成内部调查报告` |
| 主成果是检察合规第三方评估或验收 | 负触发 `准备涉案企业合规整改与验收` |
| 主成果是现场检查纪律或应对 | 负触发 `应对监管检查或突击检查` |
| 主成果是自然人自首、认罪认罚或辩护 | 负触发刑事领域 |
| 主成果是对内董事会汇报 | 负触发 `准备董事会合规汇报材料`；未安装则 `unavailable` |
| 主成果是对内持有禁毁通知 | 负触发 `准备证据保全与禁毁通知` |
| 主成果是是否启动调查 | 负触发 `评估是否启动内部调查` |
| 税务稽查实体主轴 | 整案转税务；企业向市监的书面自查可留时税务段分流 |
| 垄断或经营者集中申报主轴 | 整案转竞争法 |
| 提出伪造、隐匿不利事实、顶替责任人 | **整体停止** |
| 事实不足仍要写已查清免罚 | **正触发**，该格不支持，窗口不关 |

发送闸打开（可出 `Dsc#` 草案，仍不代提交）须同时满足：单方无冲突企业立场与签发授权；接收机关可识别；至少一行已核实事实有 `D#`／`A#`／`R#` 支撑；不利事实未被要求删除。用户要已查清并整改完毕、提交即免罚、民企必须报国资委、金额写零、快递即认定：**仍开闸**（有可回链事实时），只关对应格。伪造、隐匿、顶替不在开闸清单，走整体停止。

「已查清并整改完毕」「提交即免罚」「民企必须报国资委」「猜测当已查清」「金额写零」「快递即认定」**不关窗**。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握企业与被指向人相互冲突的秘密，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出伪造情节、隐匿关键不利事实、顶替责任人、倒签、阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　发送闸与机关

同时满足：接收机关可识别且不预填「此致某局」为唯一选定；披露事实有 `D#`／`A#`／`R#` 支撑；签发人有授权；不利事实未被要求删除。缺一则发送闸关闭，窗口不关，不产出发送前终稿。

国资重大合规风险是否必须向国资监管报告：对照《中央企业合规管理办法》报告条款，仅国务院国资委履行出资人职责的中央企业；地方国资机构参照指导所出资企业。主体不适用则整行删除，不写「建议比照上报国资委」。展开转 `评估国企合规管理办法差距`。

## 节点 2　事实分账

已核实事实可写入正文。情景用单独附件或单独 `Dsc#` 行，标明未闭合。无法估计的金额写「无法估计」，禁止补零。员工个人行为是否视为经营者行为：运行时核验反不正当竞争法商业贿赂条款，核验失败字段停止，不得写成已构成商业贿赂。

保留项须标明「尚未核验」。禁止用「全面合规」「已全部整改完毕」遮盖未核验事实。

## 节点 3　从宽接口

检索锚点：当事人主动消除或者减轻违法行为危害后果的，可以从轻或者减轻行政处罚；主动供述行政机关尚未掌握的违法行为的，可以从轻或者减轻；配合行政机关查处违法行为有立功表现的，可以从轻或者减轻。依法可以不予处罚的情形须另核。上述均为「可以」，不是提交自查即免罚，也不是必然从轻。

任何从轻、减轻、不予处罚、合规从宽表述必须回链已核验 `L#`。规则未检出则整段停止，改为「从宽效果待核，提交本身不产生既定宽大」。刑法自首、坦白、认罪认罚不在本窗展开，转刑事。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过发送闸直接给已获宽大、已查清或金额写零。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if 金额参数不足，then 该行标无法估计，禁止写零。

判断状态只许三值。口头转述、截图和「已读」不得写成已受理、已认定或已获宽大。

## 本任务回链纪律

本任务成果是「不代提交的对外自查或主动披露草案」。必须包含：发送闸；提交不是免罚；未知不写零；伪造隐匿顶替第一次整体停止。不包含：内部调查报告、检察合规验收、现场检查纪律、自然人自首材料。禁止选边治愈。禁止把已查清免罚、民企报国资委写成负触发或整体停止（伪造、隐匿、顶替除外）。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标待发送终稿已形成。双方秘密未解不得进入「部分形成」。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接。
风险档 A：伪造、隐匿、顶替、倒签必须单独标可逆性。
