# 准备主动披露或自查报告方法

本文件是可执行判断节点。提交不是已获从轻、减轻、不予处罚或不起诉。披露不是刑事自首。交稿不是已查清。42 号令第二十二条不是民企上报义务。草稿不是已提交。已读不是签收。快递揽收不是机关已认定。未知金额不写零。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已获宽大、已自首、已查清、选定机关、代提交、未知写零。本任务不定罪，不执行发送，不保证免罚。本窗闸名只能是披露闸，禁止复用发送闸、报告闸、检查闸、评估闸、合规闸、启动闸、持有闸。预留不得占用：立案闸、调查闸、检查闸、发送闸、报告闸。本窗 `PD#` 是披露行。主路径只用 `Q-披露`，禁止用 `Q-发`、`Q-披`、`Q-函`、`Q-风`、`Q-启`、`Q-持有`、`Q-总` 作主路径。英文 id 禁止使用，一律用中文技能名 `准备主动披露或自查报告`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1996／2017 年行政处罚法第三十二条陈述申辩、旧法第二十七条从轻条款、2021 年第二十七条行刑衔接当从宽、1993 年公司法第一百六十八条记名债券、1993 年公司法第一百七十七条公积金、把 42 号令第二十二条套民企或把披露写成自首已成立时记为噪声。禁止指导伪造、隐匿、顶替或交虚假自查稿。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实碎片扫描，不是默认闭集。
`PD#` 固定列：`编号｜事实切片（已核实／情景／无法估计）｜签发主体与拟接收机关类型｜禁止夹带｜打开接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已查清并整改完毕」或「已获宽大」。无 `E#` 不得写已提交、已签收、已认定、已获宽大。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-披露`。禁止 `N#`、`A#`、`GT#`、`QI#`、`LH#`、`RF#`。旧 `N-实`／`N-情`／`N-未` 并入 `PD#` 分行，禁止再作主行。

口头「已经交了」「快递发出了」「微信已读」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。函面、落款、寄出、拟制四类日期均不得早于本次形成日。稿件状态默认 `草案`。

实务上：第三十二条「应当」从轻减轻的五项条件须逐项单核，提交自查不能补齐任一项。第三十三条三层（不予／可以不予／无主观过错不予）须另核。单位对外自查不是自动投案。自查稿一旦被机关接收，可能进入处罚、监察或刑事卷，撤回申请不是已撤回。

## 节点 0　分流、立场、披露闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、虚假情节、隐匿不利事实、顶替、倒签、交虚假自查稿、毁灭证据、阻挠检查不进负表。利益冲突未解不进整体停止。不定罪、不保证免罚、不执行发送、不代提交不是负触发。禁止把检查闸、调查闸、启动闸或持有闸写进本窗节点 0。

整案转出只交付第 1、2、10 节，不出 `PD#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是是否启动内部调查 | 负触发 `评估是否启动内部调查` |
| 主成果是向监管交卷与特权日志 | 负触发 `准备向监管提交材料与特权日志` |
| 主成果是刑事自首、认罪认罚或辩护 | 整案转刑事 |
| 主成果是检察合规验收包 | 负触发 `准备涉案企业合规整改与验收` |
| 主成果是内部调查报告、不对外 | 负触发 `形成内部调查报告` |
| 主成果是检查现场应对 | 负触发 `应对监管检查或突击检查` |
| 主成果是对内持有或禁毁通知 | 负触发 `准备证据保全与禁毁通知` |
| 主成果是上市公司公告或法定信息披露正文 | 负触发 `评估舆情与法定披露交叉` |
| 主成果是董事会内部汇报 | 负触发 `准备董事会合规汇报材料` |
| 主成果是税务稽查实体说明 | 整案转税务 |
| 尚未进入合规机制，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 「不定罪」「不保证免罚」「不执行发送」「不代提交」 | 交付禁令，不是负触发 |

出现「披露」「自查」「报告」一词不是转出。查不查尚未判断不负触发吞窗。

披露闸打开（可出 `PD#` 草案，仍不得标「已提交／已获宽大／已自首」）须同时满足：单方无冲突立场已闭合；主成果是发送前自查或主动披露，不是报告终稿、不是验收包、不是公告、不是持有通知；至少一项可编号已核实或保留项碎片。口头「已经交了」不算单独开闸材料。

披露闸部分打开：已有事实碎片，但机关类型、从宽条件或 42 号令主体未闭合；对应格待核；仍交十节。无书面签发授权但单方立场已闭合且已有事实碎片：披露闸部分打开，仍交十节，不是整体停止。部分打开不得出可发送终稿。

披露闸关闭（仍正触发）：无一可编号事实碎片。「今天必须出已获宽大终稿」而无最小碎片不得开闸。不出 `PD#` 终稿。**仍交十节**，第 5 节只交闸／`Q-披露`，第 6 节不出 `PD#` 终稿，**第 7 节不得出发送版或已获宽大**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「保证免罚」「选定某局」「今天必须交」「猜测写成已查清」「民企套 42 号令或建议比照上报」「披露即自首」「未知写零」「草稿即已提交」「已读即签收」「快递即已认定」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `PD#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号事实碎片，then 披露闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，或两造争同一份披露稿，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造情节、隐匿关键不利事实、把已核实金额改写成零、顶替责任人、倒签、交虚假自查稿、毁灭证据、阻挠检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　已核实、情景与无法估计

一行一个事实切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `PD#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 已核实 | 可回链材料、来源编号 | 把猜测写入已核实 |
| 情景 | 单独附件，标明未核验 | 写成已查清并整改完毕 |
| 无法估计 | 写「无法估计」 | 补零；把已核实金额改零（改零＝整体停止） |

检索锚点（写入 `L#` 前须核验）：行政处罚法第三十二条五项、第三十三条三层。噪声 1996／2017 年第三十二条陈述申辩、旧法第二十七条、2021 年第二十七条行刑衔接。42 号令第二条、第二十二条、第四十条。公司法第一百六十八条、第一百七十七条。刑法第六十七条。监察法第十八条。反不正当竞争法 2025 第八条。

已有责令、立案或送达 `R#` 才可写该机关名称，仍不得写排他管辖或「必须由该局从宽」。无 `R#` 只写机关类型。

## 节点 2　披露闸与路径扫描

本节禁止出 `PD#` 终稿。主路径只用 `Q-披露`。`Q-宽`、`Q-披` 不得升主路径。从宽条件未核验则效果结论停止，待核接口仍可开，不得把整段 `Q-宽` 删掉，也不得把待核写成已打开从宽路径。

| 编号 | 打开信号 | 本任务允许 | 禁止 | 转介 |
| --- | --- | --- | --- | --- |
| `Q-披露` | 要发送前自查或主动披露 | 披露闸；`PD#` 草案 | 已提交／已获宽大／已自首／已查清 | 留本任务 |
| `Q-宽` | 用户问从轻减轻或不予处罚 | 条件待核接口 | 升主路径；提交即从轻；第 33 条当然免罚 | 留本任务该格待核 |
| `Q-机` | 拟写接收机关 | 只写类型；有 `R#` 才写名称 | 选定某局；排他管辖 | 该格不支持或待核 |
| `Q-达` | 需到达设计 | 最小渠道与回证扫描 | 已读即签收；揽收即认定；草稿即已提交 | 留本任务 |
| `Q-刑` | 夹带自然人自首或个人犯罪终稿 | 只标红旗；企业事实段可留 | 写成自首已成立 | 主成果才整案转刑事 |
| `Q-检合` | 夹带检察合规验收 | 只开接口 | 本窗出验收包或保证不起诉 | `准备涉案企业合规整改与验收` |
| `Q-22` | 主张必须按 42 号令向国资委交自查 | 主体待核 | 民企或地方国企套第 22 条；建议比照上报 | 该格不支持；展开转 `评估国企合规管理办法差距` |
| `Q-查` | 主成果是是否启动调查 | 不打开 | 披露闸打开写成已经在查 | `评估是否启动内部调查` |

| `Q-报` | 主成果是内部调查报告 | 不打开 | 把内部已查清粘进对外稿 | `形成内部调查报告` |
| `Q-检` | 主成果是检查现场 | 不打开 | 本窗出现场纪律 | `应对监管检查或突击检查` |
| `Q-披` | 主成果是上市法定披露或公告正文 | 不打开 | 升主路径；自查＝已履行临时报告 | `评估舆情与法定披露交叉` |

不可逆：机关接收后可能作为当事人陈述进入处罚、监察或刑事卷；撤回申请不是已撤回、不是未陈述；推翻须另证。不可逆提示不得写成「有从宽所以值得交」。

## 节点 3　披露行 `PD#`

按已出现事实碎片扫描，不是默认闭集。每条须能指向已核实、情景或无法估计之一。

无 `E#` 不得写已提交、已签收、已认定或已获宽大。状态默认 `草案`。一次只推荐下一步。未知不写零。

热冲突强制处理：

- 保证免罚／选定某局／今天必须交／猜测写成已查清／民企套 22 条／披露即自首／未知写零／草稿即已提交／已读即签收 → 该格不支持或字段停止；仍出其他 `PD#`。
- 无一事实碎片 → 关闸，不出 `PD#` 终稿，窗口不关。
- 虚假、隐匿、顶替、倒签、已知改零 → 整体停止，不是该格不支持。

到达：微信已读、快递揽收、未离开发件箱的草稿、回证未形成，都不得升已提交、已签收、已认定或已获宽大。本任务不执行发送，不补造回证。

## 节点 4　从宽待核与邻居接口

第 7 节只开接口，不得夹带 `PD#` 终稿或发送版绕闸。闸关闭时第 7 节可写「闸未开，转介待事实编号」，不得补写已获宽大。不选定机关。不代提交。不定罪。从宽效果结论未核验则停止，待核接口仍可开。

下一步只转介：`形成内部调查报告`、`准备涉案企业合规整改与验收`、`应对监管检查或突击检查`、`准备证据保全与禁毁通知`、`评估是否启动内部调查`、`评估企业合规风险总图`、`建立内部调查证据案卷`、`准备向监管提交材料与特权日志`、`评估舆情与法定披露交叉`、`评估国企合规管理办法差距`、`准备董事会合规汇报材料`、`评估律师工作产品与保密边界`、`测算舞弊损失与追偿`、`评估反商业贿赂风险点`、`准备对内通报与对外口径`、`评估调查后处置路径`、`准备合规整改方案`。禁止此致某局。禁止转介本窗完成虚假自查。

若 if 用户催促「交了就能免罚／此致某局／今天必须交／民企也必须报国资委／这就是自首／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`无法估计`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「披露闸与披露行草案」。本窗不执行发送。不包含：调查报告终稿、验收包、公告正文、持有通知、已获宽大证明、自首材料。禁止选边治愈。禁止提交即免罚。禁止披露即自首。禁止民企套 22 条。披露闸打开 ≠ 已提交 ≠ 已从轻 ≠ 已自首。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标发送前终稿已形成。
风险档 A：虚假、隐匿、顶替、倒签必须单独标可逆性；提出即整体停止。陈述作出后难以单方撤回。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：民企销售有返点，拟向「某市监局」交自查，主张交了就能免罚、这就是自首、民企也必须按 42 号令第二十二条报国资委、今天必须交、不清楚的金额先写零、微信已读就是签收。披露闸打开或半开。`Q-宽`、`Q-套`、`Q-签`、`Q-读`、`Q-零`、`Q-机` 不打开为可靠路径。第 6 节不得把已获宽大、已自首、必须上报、0、选定某局、已提交写入可执行 `PD#`；对应格 `现有依据不支持` 或字段停止；仍出已核实／情景／无法估计分列等其他 `PD#`。不关窗。不代提交。不选定机关。

场景②：用户同时交出公司「先拿掉不利事实、金额改成零、落款改到上周」与被调查销售「从未拿回扣」口径。命中双方秘密＋隐匿＋已知改零＋倒签。第一次整体停止。只交第 1、10 节。不出 `PD#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代违法方案。
