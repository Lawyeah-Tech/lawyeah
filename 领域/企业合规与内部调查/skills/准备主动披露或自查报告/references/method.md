# 评估方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。披露状态只用 `草案`、`待发送`、`已交寄待证明到达`、`停止`。禁止胜诉率、必然免责或免罚、刑事既遂、唯一截止日、选定机关、代提交、未知写零。不得把提交写成已获从轻、减轻、不予处罚或不起诉。本任务不定罪，不执行发送。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1996 年行政处罚法第三十二条陈述申辩或旧法第二十七条当现行第三十二条、把第三十二条「应当」在条件未核验时写成已获从轻、把 42 号令第二十二条套全部民企或建议比照上报国资委、把披露稿写成刑法第六十七条自首已成立时记为噪声。禁止指导伪造、隐匿不利事实或顶替责任人。

`N#` 固定列：`版本｜状态（草案/待发送/停止）｜签发主体｜拟接收机关类型（不写某局名称）｜已核实事实｜情景附件｜尚未核验／无法估计｜禁止夹带已查清/已整改完毕/已获宽大/自首已成立/倒签｜来源回链`。
`E#` 固定列：`实施人｜文本版本｜渠道｜回证｜失败升级（只点转介名）`。
`Q#` 固定列：`编号｜路径｜提出方｜相对方｜法律效果假设｜成立条件｜支持事实｜不利事实｜控制方／证明负担红旗｜最强反方｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。

拟制日＝本次形成本任务成果之日。函面、落款、寄出、拟制四类日期均不得早于本次形成日。

口头「已经交了」、快递发出、已读只进 `S#`／`V#`，不得升格已签收、已认定或已获宽大。

## 节点 0　分流、立场、发送闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。错误主张不改走负触发。虚假、隐匿、顶替不进负表。

整案转出只交付第 1 节分流理由、第 2 节来源、第 10 节最小交接，不填第 5–9 节实体、不出 `N#` 发送前终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是是否启动内部调查 | 负触发 `评估是否启动内部调查` |
| 主成果是内部调查报告、不对外 | 负触发 `形成内部调查报告` |
| 主成果是检察合规第三方评估或验收包 | 负触发 `准备涉案企业合规整改与验收` |
| 主成果是检查或突击检查现场应对 | 负触发 `应对监管检查或突击检查` |
| 主成果是对内持有或禁毁通知 | 负触发 `准备证据保全与禁毁通知` |
| 主成果是向监管交卷与特权日志 | 负触发 `准备向监管提交材料与特权日志` |
| 主成果是上市公司公告或法定信息披露 | 负触发 `评估舆情与法定披露交叉` |
| 主成果是董事会内部汇报、接收人不是监管机关 | 负触发 `准备董事会合规汇报材料` |
| 主成果是刑事自首、认罪认罚或辩护 | 整案转刑事 |
| 主成果是税务稽查实体说明 | 整案转税务 |
| 垄断、滥用支配、经营者集中申报为主成果 | 整案转竞争法；渠道回扣自查可留本窗 `N-实` 接口 |
| 尚未进入合规机制，只要改合同 | 审查起草本窗搁置 |

发送闸打开（可出 `N#` 待发送草案，仍不执行发送）须同时满足：单方无冲突立场与签发授权；拟接收机关**类型**可识别（不要求选定某局）；至少一项披露事实有 `D#`／`A#`／`R#` 支撑；不利事实未被要求删除；主成果是对外书面自查或披露，不是报告、验收、现场纪律或自首。

发送闸关闭（仍正触发）：无签发授权；无任何可回链事实；拟接收机关类型无法识别。「今天必须交」本身不得开闸。不出发送前终稿。**仍交十节**，第 5 节只交 `Q-发` 状态，第 6 节不出可发送 `N#` 正文。禁止因闸关闭只交第 1、2、10 节。禁止因闸关闭改走负触发。禁止把闸关闭写成「没有问题不必披露」。

「保证免罚或宽大」「选定某局」「今天必须交」「把猜测写成已查清并整改完毕」「民企套 42 号令第二十二条向国资委报」「披露即自首已成立」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸未开仍不出发送前终稿。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续，不得改走负触发。
若 if 提出伪造情节、隐匿关键不利事实、顶替责任人、倒签、毁灭证据、交虚假自查稿、阻挠检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　机关类型、主体范围和程序状态

1. 拟接收机关只写**类型**：市场监管、国资监管、行业监管、主管行政机关。禁止写成「此致某市监局／某区国资委」。用户指定某局：该格字段停止，窗口不关。
2. 检索锚点：公司法第一百六十八条，国家出资公司是国有独资公司、国有资本控股公司，**不含国有资本参股**。第一百七十七条不是民企法定对外披露义务。参股或民企主张必须按 177 交自查：该格 `现有依据不支持`，窗口不关。
3. 《中央企业合规管理办法》第二十二条第三款：中央企业发生重大合规风险事件，应当按照相关规定及时向国资委报告。主体不适用则 `Q-22` 不打开，对照行删除，不写「建议比照上报」。第四十条不得写成地方国企或民企对国务院国资委的报告义务。展开转 `评估国企合规管理办法差距`。
4. 程序表：检查、监察、公安、检察合规、行政处罚分列动作类型、机关、案号、文书、作出日、收到日、送达方式、效力凭证。口头「有人来过」、已读不得写入效力凭证，不得升格已立案或期限已起算。期间类型一行一类：`行政检查期限`／`行政处罚追责时效`／`监察调查措施期限`／`检察合规考察期`／`内部制度时限`／`国资报告时限`（仅主体适用）。送达不明则截止日停止。未知不写零。

## 节点 2　分账与路径扫描

按已出现事实扫描。禁止合成「已获宽大」或「已查清」一笔。

| 编号 | 打开信号 | 本任务允许 | 禁止 | 转介 |
| --- | --- | --- | --- | --- |
| `Q-发` | 授权、事实、机关类型可编号 | 发送闸状态 | 无事实仍出可发送终稿；今天必须交即开闸 | 留本任务 |
| `N-实` | 闸开且有 `D#`／`A#`／`R#` | 已核实事实草案 | 猜测写成已查清 | 留本任务 |
| `N-情` | 存在未闭合情景 | 单独附件、标明情景 | 与已核实混写 | 留本任务 |
| `N-未` | 金额或后果未知 | 「无法估计」 | 补零；全面合规遮盖 | `测算舞弊损失与追偿` |
| `Q-宽` | 用户问从轻、减轻、不予处罚 | 只开待核接口 | 写成已获宽大；提交即免罚 | 留本任务 |
| `Q-机` | 需列接收机关类型 | 类型待核 | 选定某局 | 留本任务 |
| `Q-达` | 需到达设计 | 最小 `E#` | 快递发出＝已认定；已读＝签收 | 留本任务 |
| `Q-刑` | 公职、大额账外、已有刑事 | 只打红旗 | 披露稿写成自首已成立 | 刑事领域（主成果才整案转出） |
| `Q-检合` | 检察合规／第三方机制信号 | 是否适用接口 | 保证不起诉；本窗写验收包 | `准备涉案企业合规整改与验收` |
| `Q-22` | 中央企业重大合规风险事件 | 报告义务待核 | 套民企或地方国企必须报国务院国资委 | `评估国企合规管理办法差距` |
| `Q-披` | 上市公司内控或公告红旗 | 只开接口 | 写公告正文 | `评估舆情与法定披露交叉` |
| `Q-查` | 人员已在现场 | 只转介 | 本窗写现场纪律 | `应对监管检查或突击检查` |
| `Q-报` | 用户要内部事实结论 | 只转介 | 本窗出调查报告 | `形成内部调查报告` |

检索锚点：行政处罚法（2021 修订）第三十二条，主动消除或者减轻危害后果、主动供述尚未掌握的违法行为、配合查处有立功表现等，**应当**从轻或者减轻；条件未核验不得写成已获从轻。「可以／必然从轻」不是该条用语，只作未核验效果禁令。第三十三条不予处罚或者可以不予处罚须另核。**提交书面自查本身不产生既定宽大**，不等于危害后果已消除或已有立功。规则未核验则 `Q-宽` 整段停止，改为「从宽效果待核」。监察法第十八条：如实提供，不得伪造、隐匿、毁灭证据。反不正当竞争法 2025 修订第八条：员工个人行为是否视为经营者行为，核验失败字段停止；入账折扣不得写成已贿赂。

允许写入正文：已核实事实、尚未核验清单、无法估计的金额行、配合调查意愿（不保证结果）。禁止：未核验的犯罪构成、承诺他人罪责、保证免罚、全面合规遮盖、倒签、选定某局、自首已成立。

## 节点 3　到达与不可逆

每次提交预列实施人、文本版本、渠道、地址、回证、失败升级。本任务不执行发送，不补造签收。快递发出、已读只进 `S#`／`V#`，最多升到 `已交寄待证明到达`，不得写成已提交、已签收、已认定或已获宽大。失败升级须含 `评估舆情与法定披露交叉`。

不可逆必须可见：陈述可能被用于后续处罚或刑事；难以撤回；与保险通知、民事追偿、内部处分口径可能冲突。用户要今天提交且闸未开：该格字段停止，窗口不关，不因「坚持」改开闸或改走目标停止。

失败升级只点转介名：`形成内部调查报告`、`应对监管检查或突击检查`、`准备涉案企业合规整改与验收`、`准备向监管提交材料与特权日志`。

## 节点 4　刑事、检察合规与检查边界

自然人自首材料：整案转刑事。本窗企业事实段可留接口，不得把披露稿写成刑法第六十七条自首已成立。单位自首是否成立一律待核，本窗不定罪。

检察合规第三方机制：主成果才负触发验收原子；并行时本窗只开 `Q-检合` 接口，不写考察期保证不起诉。

检查人员已在现场：只转介检查应对，书面披露可留；主成果才是现场纪律时才负触发。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过发送闸直接给发送前终稿。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if 金额参数不足，then 该行标无法估计，禁止写零。
若 if 从宽规则未核验，then `Q-宽` 字段停止，不得写已获宽大。

判断状态只许三值。口头转述、截图和「已读」不得写成已提交、已认定或期限已起算。

## 本任务回链纪律

本任务成果是「发送前自查／主动披露草案与最小到达设计」。不包含：内部调查报告、检察合规验收、现场检查纪律、持有通知、上市公告、刑事自首。禁止保证宽大。禁止选定机关。禁止选边治愈。禁止把猜测写成已查清。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标发送前终稿已形成。
风险档 A：伪造、隐匿、顶替必须单独标可逆性；提出即整体停止。
