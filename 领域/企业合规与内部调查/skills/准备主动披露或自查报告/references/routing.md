# 边界与路由

## 正触发

拟向市场监管、国资监管、主管机关或行业监管提交书面自查、情况说明或主动披露。「要给市监交一份自查」正触发。事实不足仍写已查清并整改完毕、提交即免罚、民企必须按 42 号令向国资委报告、猜测当已查清、金额写零、快递发出即已认定、选定某局、今天必须交，仍正触发：错误主张只关对应格，有可回链事实则发送闸仍可开出 `Dsc#` 草案，窗口不关。

双方秘密、伪造情节、隐匿关键不利事实、顶替责任人、倒签、阻挠检查的停止，优先于负触发。上述信号不在下表。已查清免罚、民企报国资委、金额写零不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要内部调查报告，不对外 | `形成内部调查报告` |
| 检察合规第三方评估或验收 | `准备涉案企业合规整改与验收` |
| 检查人员已在现场的现场纪律或应对 | `应对监管检查或突击检查` |
| 自然人自首、认罪认罚或刑事辩护 | 刑事领域 |
| 对内董事会汇报，接收人不是监管机关 | `准备董事会合规汇报材料`（未安装则 `unavailable`） |
| 对内持有或禁毁通知 | `准备证据保全与禁毁通知` |
| 是否启动内部调查 | `评估是否启动内部调查` |
| C 端大众体检 | 只分流 |
| 未成争改合同 | 审查起草搁置 |

「把高管的事换成离职员工」「关键不利事实先不写」不在本表，走整体停止。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护、自首材料且不要企业书面披露 | 刑事领域（交第 1、2、10 节） |
| 税务处理、稽查实体 | 税务领域 |
| 垄断协议、滥用支配、经营者集中申报 | 竞争法领域 |
| 药品购销回扣行业细则主轴 | 医疗医药领域 |
| 出口管制、制裁名单 | 涉外领域 |
| 伪造、隐匿、顶替 | 整体停止 |

综合向市监或主管机关的书面自查可留本任务；专项只作为背景时在缺口标明。「给领导的情况说明」若接收人是监管机关则正触发；若只是董事会汇报，转董事会汇报原子。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 内部事实结论 | `形成内部调查报告` |
| 检察合规验收 | `准备涉案企业合规整改与验收` |
| 现场检查 | `应对监管检查或突击检查` |
| 自然人刑事责任 | 刑事领域 |
| 国企报告义务对照 | `评估国企合规管理办法差距` |
| 是否调查 | `评估是否启动内部调查` |
| 对内禁毁 | `准备证据保全与禁毁通知` |

## 易混

「要给市监交一份自查」正触发。「调查报告先给董事会」走内部报告或董事会汇报。「检察要第三方验收」走验收原子。「人已经在现场」走检查应对。「本人去自首」走刑事。「交了就能免罚、金额先写零」正触发不关窗，对应格不支持。
