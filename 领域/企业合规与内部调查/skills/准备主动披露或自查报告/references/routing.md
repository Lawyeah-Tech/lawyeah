# 边界与路由

## 正触发

拟向主管或监管机关提交书面自查或主动披露，主成果是发送前稿。接收机关类型或事实未闭合仍正触发：发送闸关闭，不出发送前终稿，窗口不关。保证免罚、选定某局、今天必须交、把猜测写成已查清、民企套 42 号令第二十二条、披露即自首，仍正触发。

双方秘密、伪造情节、隐匿不利事实、顶替责任人、倒签的停止，优先于负触发。上述信号不在下表。「事实不足仍要求宣称已查清」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 内部调查报告、不对外 | `形成内部调查报告` |
| 检察合规第三方评估或验收 | `准备涉案企业合规整改与验收` |
| 检查或突击检查现场应对 | `应对监管检查或突击检查` |
| 对内持有或禁毁通知 | `准备证据保全与禁毁通知` |
| 向监管交卷与特权日志 | `准备向监管提交材料与特权日志` |
| 上市公司公告或法定信息披露 | `评估舆情与法定披露交叉` |
| 董事会内部汇报、接收人不是监管机关 | `准备董事会合规汇报材料` |
| 刑事自首、认罪认罚或辩护 | 刑事领域 |
| 税务稽查实体说明 | 税务领域 |

不得因「要求今天提交」或「要求保证免罚」关窗。不得因「是否调查尚未判断」负触发吞掉本窗；查不查只转介 `评估是否启动内部调查`，披露稿可留。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、阅卷、辩护词、自然人自首材料为主成果 | 刑事领域 |
| 劳动合同、解除、工伤、职场性骚扰主轴 | 劳动领域 |
| PIPL 合法性、出境、等保、网安事件专项 | 数据隐私领域 |
| 垄断协议、滥用支配地位、经营者集中申报 | 竞争法领域 |
| 税务处理决定、稽查实体 | 税务领域 |

综合披露主轴可留本任务；专项只作为背景时在缺口标明。渠道回扣自查不是不正当竞争整案转出信号。

## 易混

「给领导的情况说明」：接收人是监管机关则正触发；只是董事会则负触发董事会汇报原子。「交了就免罚」正触发不关窗，从宽格停止。「民企也必须按 42 号令报国资委」正触发，`Q-22` 不打开。「这就是去自首」：主成果才整案转刑事；企业书面自查可留接口，不得写成自首已成立。人员和检查组已在现场：只转介检查应对，书面披露可留；主成果才是现场纪律时才负触发。
