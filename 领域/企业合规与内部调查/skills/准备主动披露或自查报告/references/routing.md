# 边界与路由

## 正触发

中国大陆企业拟向主管或监管机关提交书面自查或主动披露。机关类型未闭合、事实未核验完仍正触发：有可编号已核实或保留项碎片则闸开或半开，出 `PD#` 草案，保持草案。本次不定罪、不保证免罚、不执行发送、不代提交是交付禁令，不是开窗条件。保证免罚、选定某局、今天必须交、猜测写成已查清、民企套 42 号令、披露即自首、未知写零、草稿即已提交、已读即签收，仍正触发。

双方秘密、虚假情节、隐匿不利事实、顶替、倒签、交虚假自查稿的停止，优先于负触发。上述信号不在下表。不定罪不是负触发。「提交即免罚」「披露即自首」「民企套 22 条」不在下表。虚假隐匿不在下表，走整体停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 是否启动内部调查 | `评估是否启动内部调查` |
| 向监管交卷与特权日志 | `准备向监管提交材料与特权日志` |
| 刑事自首、认罪认罚或辩护 | 刑事领域 |
| 检察合规验收包 | `准备涉案企业合规整改与验收` |
| 内部调查报告、不对外 | `形成内部调查报告` |
| 检查或突击检查现场应对 | `应对监管检查或突击检查` |
| 对内持有或禁毁通知 | `准备证据保全与禁毁通知` |
| 上市公司公告或法定信息披露正文 | `评估舆情与法定披露交叉` |
| 董事会内部汇报 | `准备董事会合规汇报材料` |
| 税务稽查实体说明 | 税务领域 |
| 尚未进入合规机制，改合同或出稿 | 审查起草领域（本窗搁置，只说明） |

不得因「不定罪」或「不保证免罚」关窗。拟披露稿仍正触发，不得写成已提交、已获宽大或已自首。查不查尚未判断不负触发吞窗。人员已在现场只转介检查窗，书面披露可留。

## 易混

本窗闸名只能是披露闸，不是发送闸，不是报告闸，不是检查闸，不是评估闸，不是启动闸，不是持有闸。`PD#` 不是 `N#`，不是 `QI#`，不是 `A#`。主路径是 `Q-披露`，不是 `Q-发`，不是 `Q-披`，不是 `Q-函`。`发送闸`／`HF#`／`Q-函` 是合同包 `准备解除通知`。`Q-披` 是舆情窗法定公告扫描，本窗只作转介。邻窗主动披露转介改挂 `Q-披露`。提交不是已获宽大。披露不是刑事自首。42 号令第二十二条不是民企上报义务。1996 年行政处罚法第三十二条陈述申辩不是现行从宽条款。提出「先拿掉不利事实、金额改成零」整体停止。本窗不代提交。不选定机关。不定罪。不保证免罚。不出调查报告终稿。
