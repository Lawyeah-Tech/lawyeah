# 输出合同

按触发结果选择交付形状。发送闸未打开不得交付发送前终稿或「已获宽大」。禁止把披露稿写成刑事自首已成立。禁止保证免罚。禁止选定某局。禁止把猜测写成已查清。禁止倒签。禁止选边治愈。不执行发送。不代提交。未知不写零。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出 | 第 1 节（触发与分流）、第 2 节（来源）、第 10 节（交接）。不填第 5–9 节 |
| 整体停止 | 第 1 节（停止原因）、第 10 节。禁止 `N#` 正文、虚假或隐匿步骤、选边。双方秘密、伪造情节、隐匿不利事实、顶替责任人、倒签第一次即停，优先于负触发；无选边治愈，无「坚持」门槛 |
| 用户要保证免罚、选定某局、今天必须交、把猜测写成已查清、民企套 42 号令向国资委报、披露即自首（不关窗） | 十节表头均出现；对应格填 `现有依据不支持` 或字段停止；闸未开则第 6 节不出可发送正文；不得改走负触发关窗；不得标发送前终稿 `已形成` |
| 正触发且闸开 | 下列十节表头均出现；未核验格填待核；禁止为填满而写已获宽大、已查清或已自首 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入发送前终稿已形成。双方秘密未解不得进入「部分形成」。每个 `N#`／`E#`／`Q#` 必须带来源和判断三值。`L#` 不得直接抄技能内条号。稿件状态默认 `草案`。

分流理由只放第 1 节。第 3 节不再写专项分流，不选定某局。

## 1. 触发、单方立场、授权与成果状态

谁要披露稿。代表公司还是被调查对象，互斥。发送闸是否打开。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。披露状态默认 `草案` 或 `待发送`。不定罪。不保证免责。

## 2. 来源登记与 MCP 调用表

`S/D/A/R/C/L/I/G/N/Q/V/E`。口头已交、已读只登记 `S#`／`V#`。MCP 未调用也留一行。噪声命中须登记。1996 年行政处罚法第三十二条当从宽、42 号令第二十二条套民企若返回则记噪声。

## 3. 签发主体、拟接收机关类型和程序状态

签发授权。机关只写类型，不写某局名称。42 号令主体范围待核。程序表：机关、案号、文书、作出、收到、送达、效力。口头不得升格已立案。期间类型一行一类。

## 4. 已核实、情景及无法估计时间线

三列分列。冲突并列。不得把猜测写成已查清。未知金额不写零。

## 5. 发送闸与路径矩阵 `Q#`

本节禁止出 `N#` 可发送正文。完整 `Q#` 固定列。无回链事实则 `Q-发` 关闭，窗口不关。`Q-宽` 不得打开「已获宽大」。

## 6. 发送前披露正文 `N#`

闸未开不得出可发送正文。`N-实`／`N-情`／`N-未` 分行，禁止合成「已查清并整改完毕」。不写罪名、自首、免罚、倒签、某局名称。状态 `草案`／`待发送`。

## 7. 到达设计 `E#`

最小列。不执行发送。快递发出不是已认定。已读不是签收。不补造回证。

## 8. 从宽待核、不可逆与刑事／检察合规接口

从宽规则未核验则整段停止。不可逆提示必须可见。披露≠自首。验收包、现场纪律只转介。

## 9. 风险与下一步

每项含可逆性。只转介：`形成内部调查报告`、`应对监管检查或突击检查`、`准备涉案企业合规整改与验收`、`准备向监管提交材料与特权日志`、`评估舆情与法定披露交叉`、`准备董事会合规汇报材料`、`评估国企合规管理办法差距`、`准备证据保全与禁毁通知`。禁止提交指令、保证宽大、此致某局。不代提交。

## 10. 缺口、停止项与提示

须列对方最强解释：交了就免罚、此致某局、今天必须交、已经查清并整改完毕、民企必须按 42 号令报国资委、这就是自首、快递发出机关已认定、两边材料选边、先把不利事实拿掉再交。

本成果不是内部调查报告、不是验收包、不是现场纪律、不是持有通知、不是上市公告、不是刑事自首、不保证宽大。不执行发送。不定罪。

## 综合提问的强制降级

用户同时问交不交、交给谁、罚多少、哪天到期、能不能保证免罚、要不要当自首时，第 5–8、9 节仍只给接口和转介；保证宽大格停止；自首主成果才整案转刑事。
