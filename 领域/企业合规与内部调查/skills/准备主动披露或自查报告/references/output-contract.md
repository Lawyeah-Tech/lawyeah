# 输出合同

按触发结果选择交付形状。发送闸未打开不得交付待发送终稿或「已获宽大」。禁止提交即免罚。禁止事实不足写成已查清并整改完毕。禁止未知金额写零。禁止选定唯一监管机关。禁止把快递发出写成机关已认定。禁止选边治愈。不定罪。不代提交。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 发送闸关闭或节点 0 整案转出 | 第 1、2、10 节：关闭理由、事实待核和最小补证。可附停止的 `Dsc#`。禁止待发送终稿、已获宽大。企业书面披露可留时不得因税务或刑事背景整案抹掉 `Dsc#` |
| 整体停止 | 第 1、10 节。禁止 `Dsc#` 策略包、选边、伪造或顶替步骤。双方秘密、伪造情节、隐匿不利事实、顶替责任人、倒签第一次即停，优先于负触发；无选边治愈，无「坚持」门槛 |
| 用户要已查清并整改完毕、提交即免罚、民企必须报国资委、猜测当已查清、金额写零、快递即认定、选定某局（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；闸未开则仍只交 1、2、10；不得改走负触发关窗；不得标待发送终稿 `已形成` |
| 正触发且闸开（可部分开） | 下列十节表头均出现；未核验格待核；禁止为填满而写已获宽大、已查清或金额写零 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入待发送终稿已形成。双方秘密未解不得进入「部分形成」。每个 `Dsc#` 必须带来源和三值判断。`L#` 不得直接抄技能内条号。稿件默认 `草案`。披露状态只用 `草案`、`待发送`、`发送闸关闭`、`已提交待签收`、`停止`。

## 1. 触发、接收机关、签发授权与成果状态

发送闸开、部分开或关。单方立场必须标明。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。不定罪。不代提交。不保证宽大。

## 2. 来源登记与 MCP 调用表

`S/D/A/R/C/L/I/G/Dsc/V/E`。口头已经报过、快递单只登记 `S#`／`V#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 事实范围：已核实／情景／无法估计

`Dsc#` 分列。未知金额写无法估计。禁止写零。

## 4. 保留项与未核验清单

须标明尚未核验。禁止用全面合规遮盖。

## 5. 发送闸是否打开及理由

缺事实或授权则关闭。事实不足仍要已查清：该格不支持，窗口不关。

## 6. 发送前披露正文

只写入已核实行。不承认未核验犯罪构成。不承诺他人罪责。不倒签。

## 7. 到达设计与版本控制

渠道、签收、副本。快递发出不是已认定。不补造签收。

## 8. 从宽规则待核与不可逆提示

从轻、减轻、不予处罚须 `L#`。未核验则写提交不产生既定宽大。列明难以撤回、可能被后续处罚或刑事使用。

## 9. 与刑事、检察合规、检查应对的接口

只点名转介。不写自首材料。不写验收包。不写现场纪律。

## 10. 缺口、停止项与提示

须列对方最强解释：交了就能免罚、问题已经全部查清并整改完毕、金额先写零、民企也必须报国资委、快递发出机关就算认了、此致某局、两边材料选边写、把高管的事换成离职员工、关键不利事实先不写。

本成果不是已提交报告、不是已获宽大、不是内部调查报告、不是检察合规验收、不是自首材料、不是发送版。不代提交。不定罪。不得写已获宽大。
