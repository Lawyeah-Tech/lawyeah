# 边界与路由

## 正触发

民事追偿仍可与责任人或第三人谈返还，需要底线、弃权边界和执行力提示，而不是签署和解、起诉、劳动补偿或刑事从宽承诺。从零、碎片、测算未核验、无书面谈判授权仍正触发：有相对人或请求权则闸开或半开，出 `FH#` 草案，保持草案。口头同意即已返还、谈拢即已履行、返还即不起诉、无测算写唯一总额、保证法院支持底线，仍正触发。

双方秘密、指导伪造返还凭证、倒签收据、威胁、打击报复、隐匿财产的停止，优先于负触发。上述信号不在下表。「口头同意即已返还」「谈拢即已履行」「概括弃权覆盖未知账户」「返还即承诺不起诉」「无测算写唯一总额」「保证法院支持底线」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 损失测算终稿 | `测算舞弊损失与追偿` |
| 民事起诉材料 | `准备民事追偿诉讼材料` |
| 调查后路径比较 | `评估调查后处置路径` |
| 已谈拢和解或返还协议全文 | 审查起草领域（本窗搁置，只说明不实施） |
| 劳动经济补偿、解除或处分 | 劳动领域 |
| 刑事控告、退赃从宽承诺、辩护或自首 | 刑事领域 |
| 资金保全或冻结方案 | `评估内部账户冻结与资金保全` |
| 调查报告终稿 | `形成内部调查报告` |
| 整改方案 | `准备合规整改方案` |

不得因「不写已谈拢协议终稿」或「今天视为已返还」关窗。拟谈仍正触发，不得写成已谈拢或已返还。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、解除、工伤、经济补偿主轴 | 劳动领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |
| 垄断、滥用支配、经营者集中 | 竞争法领域 |
| 税务处理决定、稽查实体 | 税务领域 |
| 银行保险机构行业合规办法主轴 | 金融领域 |
| 药品购销回扣行业细则主轴 | 医疗医药领域 |
| 出口管制、制裁名单 | 涉外领域 |
| 章程、股权、任免本身为主成果 | 公司治理领域 |

综合民事追偿谈判主轴可留本任务。审查起诉只作背景，主成果才转。专项只作为背景时在缺口标明。出现「返还」「和解」「追偿」一词不是转出。

## 易混

谈判方案不是已达成和解。口头同意不是已返还。谈拢不是已履行。返还不是刑事从宽承诺，更不能承诺不起诉或撤案。概括「再无任何争议」不得覆盖未知账外账户。无测算不得写唯一必得总额。法院一定支持底线没有依据。执行和解范本是判决后文书，不是本窗已可强制执行。群已读不是已送达。还款协议栏目不是已谈拢。本窗 `FH#` 不是测算行，不是处置路径，不是追偿行 `ZC#`。本窗闸名只能是返还闸。劳动经济补偿不在本窗做完。「先补假还款收据再谈」整体停止。本窗不执行发送，不代收款。审查起诉只作背景，主成果才转刑事。
