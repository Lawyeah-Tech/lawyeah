# 谈判民事追偿与返还方案方法

本文件是可执行判断节点。谈判方案不是已达成和解。口头同意不是已返还。谈拢不是已履行。返还不是刑事从宽承诺。概括弃权不是覆盖未知账户。无测算不是唯一必得总额。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、必得总额、选定法院、代提交、未知写零。本任务不定罪，不写已谈拢协议终稿，不代签署，不代收款。本窗闸名只能是返还闸，禁止复用追偿闸、合意闸、和解闸、测算闸。本窗 `FH#` 是返还行，不是测算行 `BM#`，不是处置路径 `DP#`，不是追偿行 `ZC#`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》《民法通则》、1993 年公司法第一百九十一条清算组、把返还写成可承诺不起诉、把口头同意写成已返还、把执行和解范本写成已可强制执行时记为噪声。禁止指导伪造返还凭证或威胁。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`FH#` 固定列：`编号｜相对人｜请求权接口（不当得利／侵权／违约／归入／董监高赔偿）｜底线（本金／孳息／分期／担保）｜弃权范围｜执行力提示｜测算碎片回链｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已谈拢闭环」或「已返还」。无 `E#` 不得写已返还、已谈拢、已可执行。`E#` 只作证据形态回链（测算碎片、财产线索、谈判授权、相对人承认），不是发送闸。扫描不是闭集。缺项记 `G#`，不得用范本栏目填满。测算碎片只回链测算窗，本窗不出 `M#` 终稿。

口头「他答应还了」「微信说没问题」「群已读就是已送达」「内部定了就是已谈拢」只进 `S#`／`V#`，**不得单独算作开闸材料**。已读不得升格 `R#` 已送达。口头答应不等于清偿。`A#` 是承认相对人或请求权碎片，不是已返还。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：刑事责任不影响民事责任；刑事和解不能由当事人约定撤案或免除刑事责任。口头合同在未履行主要义务时不得升格已返还。概括「双方再无任何争议」不得覆盖未知账外账户和法定不可弃权项。

## 节点 0　分流、立场、返还闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、指导伪造返还凭证、倒签收据、威胁、打击报复、隐匿财产不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `FH#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是损失测算终稿 | 负触发 `测算舞弊损失与追偿` |
| 主成果是民事起诉材料 | 负触发 `准备民事追偿诉讼材料` |
| 主成果是调查后路径比较 | 负触发 `评估调查后处置路径` |
| 主成果是已谈拢和解或返还协议全文 | 目标停止，审查起草本窗搁置 |
| 主成果是劳动经济补偿、解除或处分 | 整案转劳动 |
| 主成果是刑事控告、退赃从宽承诺、辩护或自首 | 整案转刑事 |
| 主成果是资金保全或冻结方案 | 负触发 `评估内部账户冻结与资金保全` |
| 主成果是调查报告终稿 | 负触发 `形成内部调查报告` |
| 主成果是整改方案 | 负触发 `准备合规整改方案` |
| 「不写已谈拢协议终稿」「不定罪」「不保证法院支持」「不输出唯一必得总额」 | 交付禁令，不是负触发 |

审查起诉、监管检查只作程序背景。主成果才整案转。出现「返还」「和解」「追偿」一词不是转出。

返还闸打开（可出 `FH#` 草案，仍不得标「已谈拢／已返还／已可执行」）须同时满足：单方无冲突公司立场已闭合；主成果是谈判方案，不是测算终稿、不是起诉状、不是协议全文、不是劳动补偿；至少一名可编号相对人或一块可编号损失／得利碎片。口头「他答应还了」不算单独开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

返还闸部分打开：已有相对人或数字碎片，但测算、财产线索、授权或执行力未闭合；对应格待核；仍交十节。无书面谈判授权但有相对人或数字碎片：部分打开。

返还闸关闭（仍正触发）：无一可编号相对人且无一数字／得利碎片。「今天必须出已谈拢／已返还终稿」而无最小碎片不得开闸。不出 `FH#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `FH#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「口头同意即已返还」「谈拢即已履行」「概括弃权覆盖未知账户」「返还即承诺不起诉」「无测算写唯一总额」「保证法院支持底线」「选定某法院」「群已读即已送达」「劳动补偿写入返还即劳动已了结」「追缴即民事责任消灭」「私下和解即已赋强」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `FH#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无一可编号相对人且无一数字／得利碎片，then 返还闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与相对人相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出指导伪造欠条或返还凭证、倒签收据、用刑事报案逼签民事弃权、扣证件或扣工资换签字、隐瞒已收回以提高要价、要本窗写出概括弃权可签文本、打击报复、隐匿财产，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个主体或强制接口。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `FH#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 相对人 | 责任人／第三人／担保人分列 | 写成已送达或已返还 |
| 请求权 | 不当得利／侵权／违约／归入／董监高赔偿分列 | 合成唯一必得总额 |
| 民刑并行 | 刑责不影响民责 | 写成先刑后民所以不能谈 |
| 劳动分界 | 经济补偿只开接口 | 本窗出补偿协议 |

检索锚点（写入 `L#` 前须核验）：

- 民法典第一百八十七条：刑责不影响民责；财产不足优先民事责任。
- 民法典第九百八十五条至第九百八十八条不当得利返还；善意已不存在、知情赔偿、无偿转第三人须逐件核验。
- 民法典第一百八十六条违约与侵权择一。公司法第一百八十条忠实勤勉是接口不是必得公式。
- 公司法第一百八十八条：过错与损失待核，不是必得。第一百八十六条归入权不是已返还。第一百九十一条对外赔偿 ≠ 对内追偿当然依据。噪声：1993 年第一百九十一条。
- 侵权责任编解释（一）第十七条：已完成追缴、退赔可扣减，不是民事责任消灭。
- 刑事和解不能由本窗承诺撤案或不起诉。
- 司法确认、公证、执行和解未核验则执行力字段停止。私下和解不能当然司法确认。公证赋强只提示不保证。执行和解范本是判决后文书。
- 行政处罚法第三十二条交谈判表 ≠ 从轻。刑法第六十七条交方案 ≠ 自首。

## 节点 3　返还行 `FH#`

按已出现相对人与请求权扫描，不是默认闭集。底线可含本金、孳息接口、分期、担保、违约恢复起诉。未知不写零。不得输出「法院一定支持该底线」。

弃权须列明请求权类型和相对人。概括「再无任何争议」且覆盖未知账外账户、未知第三人、劳动或刑事法定不可弃权项：该句删除或该格 `现有依据不支持`。

执行力：司法确认、公证、担保、可直接执行条款只作提示，规则未核验则字段停止。仅口头或无执行条款：提示弱，不得写成已可执行。执行和解范本不得升格本窗。

热冲突强制处理：

- 口头同意即已返还／谈拢即已履行／返还即不起诉／无测算写唯一总额／保证法院支持 → 该格不支持；仍出其他 `FH#`。
- 无测算 → 记 `G#`，金额待核，不写唯一总额。
- 指导伪造凭证、威胁 → 整体停止，不是该格不支持。

无 `E#` 不得写已返还、已谈拢。状态 `草案`。一次只推荐下一步。本窗不执行发送，不代收款。

## 节点 4　测算、起诉、劳动与刑事接口

第 7 节只开接口，不得夹带 `FH#` 终稿或协议正文绕闸。闸关闭时第 7 节可写「闸未开，转介待相对人编号」，不得补写已返还。

可逆动作与不可逆动作分列。不可逆（对外宣称已和解、放弃未知请求、对外提交弃权）不得在草案阶段实施。禁止提交指令。不代收款。不选定法院。

下一步只转介：`测算舞弊损失与追偿`、`准备民事追偿诉讼材料`、`评估调查后处置路径`、`评估内部账户冻结与资金保全`、`形成内部调查报告`、`准备合规整改方案`。禁止此致某法院。

若 if 用户催促「保证支持／写唯一总额／填满已返还终稿」，then 该格 `现有依据不支持`，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

本任务成果是「返还闸与谈判方案草案」。本窗不执行发送。不包含：已谈拢协议终稿、已返还证明、起诉状、劳动补偿协议、刑事从宽承诺、测算终稿。禁止选边治愈。禁止口头同意即已返还。禁止返还即不起诉。禁止概括弃权覆盖未知账户。禁止唯一必得总额。禁止指导伪造凭证。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：调查显示销售经理可能侵占渠道费，尚无测算终稿。用户主张他微信答应还了就是已返还、今天必须写出唯一必得总额、和解写「再无任何争议」覆盖未知账户、还了就不报案并保证法院支持底线、选定某中院。返还闸打开或半开。`Q-口`、`Q-额`、`Q-弃`、`Q-刑`、`Q-院` 不打开为可靠路径。第 6 节不得把已返还、已弃权闭集、不起诉、必得总额写入可执行 `FH#`；对应格 `现有依据不支持`；仍出相对人、不当得利接口、底线待核、弃权限缩等其他 `FH#`。无测算记 `G#`。不关窗。不写协议终稿。不定罪。

场景②：用户同时交出公司追偿草稿与该经理律师的抗辩要点，要求选对公司有利的一版，并指导「先出一张今年来的还款收据，没有转账也行」。命中双方秘密＋伪造返还凭证。第一次整体停止。只交第 1、10 节。不出 `FH#`。不得问代表哪一方后继续。不以「坚持」为门槛。
