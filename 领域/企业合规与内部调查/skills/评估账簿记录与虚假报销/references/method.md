# 评估方法

本文件是可执行判断节点。账簿闸打开不等于已虚假不等于已合法不等于已入账合规。已报销不是已合法。有发票不是真实劳务。红旗是待证不是已虚假。账簿问题不是回扣既遂。缺附件不写零。不输出补税金额。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、刑事既遂、选定机关、代提交、未知写零。本窗不定罪，不定伪造票证罪，不作出税务处理决定。本窗 `VR#` 是凭证行，不是账外行 `XB#`，不是税务函调 `VR#`，不是测算 `M#`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年会计法、已失效《合同法》、把已报销写成合法、把红旗写成已虚假时记为噪声。禁止指导伪造变造、调账掩盖、补假发票、隐匿销毁会计资料。禁止 `search_template` 生成已入账合法或已虚假证明。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现凭证碎片扫描，不是默认闭集。
`VR#` 固定列：`编号｜科目或报销件｜付款形态（对公／个人垫付／待核）｜发票三态（票面待核／无票或票面冲突待核／待核）｜附件与事实｜受益人｜审批链｜红旗（待证≠已虚假）｜E#回链｜判断三值｜G#｜最强反方｜状态`。发票三态禁止写入「假票」或「真实劳务」标签。无 `E#` 不得写已覆盖、已合法、已虚假。`E#` 只作证据形态回链。缺项记 `G#`。扫描不是闭集。状态默认 `草案`。禁止本窗用 `M#` 写补税总额。

口头「已经报销所以合法」「有发票就是真的」「咨询费都这样」「按零写」只进 `S#`／`V#`，**不得单独算作开闸材料**。报销单能开闸，不能升格已合法。`A#` 是承认该笔存在或已付，不是已合法。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

## 节点 0　分流、立场、账簿闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、指导伪造变造、指导调账掩盖、指导补假发票、指导隐匿销毁、打击报复会计人员、阻挠检查不进负表。

整案转出只交付第 1、2、10 节，不出 `VR#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是回扣账外资金链路终稿 | 负触发 `评估回扣账外暗中与资金链路` |
| 主成果是销售激励与渠道返点终稿 | 负触发 `评估销售激励与渠道返点廉洁风险` |
| 主成果是礼品单笔审查 | 负触发 `审查礼品招待赞助与捐赠` |
| 主成果是中间人费用终稿 | 负触发 `评估中间人费用与资金链路` |
| 主成果是舞弊损失测算终稿 | 负触发 `测算舞弊损失与追偿` |
| 主成果是是否启动内部调查 | 负触发 `评估是否启动内部调查` |
| 主成果是调查报告终稿 | 负触发 `形成内部调查报告` |
| 主成果是税务处理或偷逃税认定 | 整案转税务 |
| 主成果是刑事辩护、控告或自首 | 整案转刑事 |
| 「不作出税务处理决定」「不定伪造票证罪」「不输出补税金额」 | 交付禁令，不是负触发 |

审查起诉、监管检查、已立案只作程序背景。主成果才整案转。出现「报销」「发票」「税务」一词不是转出。

账簿闸打开（可出 `VR#` 草案，仍不得标「已虚假／已合法／已入账合规」）须同时满足：单方无冲突公司立场已闭合；主成果是账簿完整性与红旗评估；至少一条可编号凭证碎片。报销单、发票、入账科目、审批单、银行回单可编号开闸。口头「已经报销所以合法」不算单独开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

账簿闸部分打开：已有可编号碎片，但发票、附件、受益人、审批未闭合；或无书面评估授权但已有碎片。对应格待核；仍交十节；不得标终稿 `已形成`。

账簿闸关闭（仍正触发）：无一可编号凭证碎片。「今天必须出已合法或已虚假终稿」而无最小件不得开闸。不出 `VR#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `VR#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关写成「没有虚假」或「已合规」。

「已报销即合法」「有发票即真实」「咨询费即合法对价」「市场费即当然市场费用」「科目错误即无故意即合法」「红旗即已虚假」「账簿问题即回扣既遂」「缺附件即零」「开票方与收款方不一致即伪造」「本表已定罪」「交表即从轻／自首」「民企必须按 42 号令专项」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `VR#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无一可编号凭证碎片，then 账簿闸关闭，仍交十节，不是整体停止。
若 if 单方立场已闭合、无书面授权但已有可编号碎片，then 账簿闸部分打开，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象或相对方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出指导伪造或变造会计凭证账册、指导调账掩盖、指导补假发票或假附件、指导隐匿或销毁会计资料、打击报复会计人员、阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体、凭证碎片与强制接口

一行一个凭证碎片。缺项记 `G#`，未知金额不得写 `0`。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 科目 | 咨询费／市场费／差旅／会议／其他，分列 | 合成「费用都不实」 |
| 发票 | 三态分列 | 有发票即真实；开票方≠收款方即伪造 |
| 附件 | 有／无／待核 | 缺附件写零 |
| 红旗 | 待证 | 红旗即已虚假 |

检索锚点（写入 `L#` 前须核验）：会计法（2024 修正）第十三条会计凭证、账簿、财务会计报告必须符合国家统一的会计制度，不得伪造、变造会计凭证、会计账簿及其他会计资料，不得提供虚假财务会计报告。第十六条各项经济业务应当在依法设置的会计账簿上统一登记核算，不得私设会计账簿。第五条不得授意、指使、强令伪造变造，不得对依法履行职责的会计人员打击报复。第四十一条伪造、变造会计凭证、会计账簿，编制虚假财务会计报告，隐匿或者故意销毁依法应当保存的会计资料。会计法打击报复会计人员条款只约束对会计人员的报复，不是全体员工当然恢复原职，劳动效果转劳动领域。噪声：1993 年会计法。刑法第一百六十二条之一只作红旗，不得指导销毁。噪声：刑法第一百六十二条妨害清算。反不正当竞争法（2025）第八条入账不是合法闭集。虚开发票只开税务或刑事接口，本窗不做出税务处理决定。行政处罚法第三十二条交评估表 ≠ 从轻。监察法第十八条不得伪造隐匿。42 号令只约束中央企业。本节禁止出 `VR#` 终稿。

## 节点 3　凭证行 `VR#`

按已出现凭证碎片扫描，不是默认闭集。建议行型（出现才用）：

| 编号 | 含义 | 本窗允许 | 禁止 |
| --- | --- | --- | --- |
| `VR-咨` | 咨询费 | 红旗待证 | 无附件即合法对价；无附件即已虚假 |
| `VR-市` | 市场费 | 红旗待证 | 市场费即当然市场费用 |
| `VR-差` | 差旅会议 | 行程冲突标红旗 | 行程冲突即已虚假 |
| `VR-票` | 发票形态 | 开票方与收款方分列待核 | 不一致即伪造 |
| `VR-垫` | 个人垫付 | 长期未结算加重红旗 | 垫付即已虚假 |
| `VR-拆` | 拆单整数 | 周末整数标红旗 | 整数即已虚假 |

热冲突强制处理：

- 已报销即合法／有发票即真实／红旗即已虚假／缺附件即零 → 该格不支持；仍出其他 `VR#`。
- 开票方与收款方不一致 → 待核，不等于虚报伪造。
- 缺附件 → 记 `G#`，不写零。
- 对方账簿不可得 → 记 `G#`，不推定存在。
- 指导改账或补假发票 → 整体停止，不是该格不支持。

无 `E#` 不得写已覆盖、已合法或已虚假。状态 `草案`。一次只推荐下一步。

## 节点 4　税务、回扣、收集接口与转介

第 7 节只开接口，不得夹带 `VR#` 终稿绕闸。闸关闭时第 7 节可写「闸未开，转介待凭证编号」，不得补写已合法或已虚假。

不写回扣账外终稿、测算总额、税务处理决定、刑事文书。不可逆（对外宣称已入账合法、补假发票、调账掩盖）不得在草案阶段实施。禁止提交指令。不代提交。不选定机关。

下一步只转介：`评估回扣账外暗中与资金链路`、`评估销售激励与渠道返点廉洁风险`、`审查礼品招待赞助与捐赠`、`评估中间人费用与资金链路`、`测算舞弊损失与追偿`、`合法收集书证电子证与财务痕迹`、`评估是否启动内部调查`、`形成内部调查报告`、税务领域。

若 if 用户催促「按零写／填满已虚假终稿／给补税金额」，then 该格 `现有依据不支持`，窗口不关。
若 if 金额未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「账簿闸与凭证行草案」。本窗不执行发送。不包含：已合法证明、已虚假证明、回扣账外终稿、测算总额、税务处理决定、刑事意见。禁止选边治愈。禁止已报销即合法。禁止有发票即真实。禁止红旗即已虚假。禁止缺附件写零。禁止补税金额。禁止指导销毁会计资料。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标账簿终稿已形成。
风险档 A：指导改账、补假发票、销毁会计资料必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：民企。咨询费、市场费已报销且有发票；咨询报告不存在、发票与行程冲突。用户主张已经报销所以合法、有发票就是真实、咨询费就是合法对价，并要补税金额和虚假报销定罪。账簿闸打开。`Q-合`、`Q-票`、`Q-咨`、`Q-税`、`Q-罪` 不打开为可靠路径。第 6 节已报销即合法格、有发票即真人格 `现有依据不支持`；咨询报告不存在只标红旗待证，不得升格已虚假。仍出其他 `VR#` 草案。不关窗。不定罪。不输出补税金额。

场景②：用户同时交公司报销台账与被调查销售抗辩，要求选边，并指导「科目先调一版、缺的附件补假发票」。命中双方秘密＋指导调账掩盖＋指导补假发票。第一次整体停止。只交第 1、10 节。不出 `VR#`。不得问代表哪一方后继续。
