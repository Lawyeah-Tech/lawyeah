# 边界与路由

## 正触发

有可编号的报销、咨询费、市场费、差旅或账簿科目碎片，需要完整性与虚假报销红旗评估，而不是出税务处理决定、回扣账外专项或测算终稿。发票、附件未核验仍正触发：有可编号凭证碎片则账簿闸开或半开，出 `BX#` 草案。已报销即合法、有发票即真实、咨询费即合法对价、红旗即已虚假、账簿问题即回扣既遂、本表已定罪，仍正触发。

双方秘密、指导伪造变造会计凭证账册、指导调账掩盖、指导补假发票或假附件、指导隐匿销毁会计资料、打击报复会计人员、阻挠合法检查的停止，优先于负触发。上述信号不在下表。「已报销即合法」「有发票即真实」「咨询费即合法对价」「市场费即当然市场费用」「红旗即已虚假」「账簿问题即回扣既遂」「本表已定罪」不在下表。「不作出税务处理决定」「不定伪造票证罪」「不输出补税金额」是交付禁令，不在下表。出现「报销」「发票」「税务」一词不是转出。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 税务处理决定、稽查实体、偷逃税认定为主成果 | 税务领域 |
| 劳动合同、解除、工伤主轴且账簿评估不是主成果 | 劳动领域 |
| 药品购销回扣行业细则为主成果 | 医疗领域 |
| 垄断协议、滥用支配、经营者集中为主成果 | 竞争法领域 |

综合账簿与虚假报销评估主轴可留本任务。检查或已立案只作背景，主成果才转。已刑事立案且主成果是刑事程序：整案转刑事。已立案但主成果仍是企业账簿评估：留窗；指导隐匿销毁会计资料整体停止。

## 易混

已报销不是已合法。有发票不是真实劳务。发票开票方与支付收款方不一致不是当然伪造。发票真实不是基础资料真实。咨询费不是当然合法对价。市场费不是当然市场费用。科目错误不是无故意即合法。红旗是待证不是已虚假。账簿问题不是回扣既遂。报销不合规不是偷税结论。控制方在对方不推定存在。缺附件不写零。不输出税务补税金额。会计法（2024）第十三条不得伪造变造，不是本表已定罪。刑法第一百六十二条之一只作红旗，不得指导销毁；噪声：第一百六十二条妨害清算。不作出税务处理决定、不定伪造票证罪、不输出补税金额是交付禁令，不是负触发。口头「已经报销所以合法」不是单独开闸材料。可编号凭证碎片才开闸。指导改账掩盖或补假发票是第一次整体停止，不是不关窗。利益冲突未解不是本窗整体停止。本窗 `BX#` 不是账外行 `XB#`，不是测算行 `M#`。
