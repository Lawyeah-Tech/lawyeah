# 起草合规管理办法或章程级制度

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。本窗是起草类草案，范本只借栏目，**不要**升格「已生效／已合规／已审议通过」，不得照抄境外范本当中国法。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现空话义务、无留痕例外、冲突只留有利版本的反例；案例只比较事实差异与翻转条件，不写成必然结果。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《民法通则》《民法总则》或其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成可审议的合规基本制度草案：起草闸、制定机关与效力层级、`Q#` 路径、`N#` 办法草案（职责／例外批准／冲突规则／生效废止）、`E#` 回链。草案不是已生效，不是已合规，不是公司章程已通过，不替股东会改章程。不写劳动规章全文，不写交易合同。不保证免责。不代提交。不执行发送。

`depends-on` 为空。只要框架不要文本转 `设计合规管理体系框架`。只要政策层级方案不要正文转 `设计政策层级与例外批准`。三道防线岗位细节转 `配置合规机构与三道防线`。42 号令对照终稿转 `评估国企合规管理办法差距`。劳动规章全文转劳动领域。公司章程本身转公司治理领域。

## 工作边界

正触发：公司需要一份可提交董事会或经理层审议的合规基本制度草案。审议机关、冲突或废止清单未闭合仍正触发：起草闸关闭，不出 `N#` 终稿，窗口不关。用户要把草案写成已生效、写「遵守本办法即免除法律责任」、只要有利版本的冲突制度、开口径「经领导同意可突破」无留痕、民企按 42 号令第八条必须由董事会批准并上报、今天必须出已生效文本，仍正触发：对应格填 `现有依据不支持`，窗口不关；闸已开仍出其他 `N#` 草案。不得因「要求写成已生效」改走负触发关窗。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是综合框架不要文本（转 `设计合规管理体系框架`）；
- 主成果是政策层级方案不要正文（转 `设计政策层级与例外批准`）；
- 主成果是劳动规章或员工手册纪律全文（转劳动领域）；
- 主成果是交易合同改稿（审查起草本窗搁置）；
- 主成果是公司章程修订本身（转公司治理领域）；
- 主成果是三道防线岗位配置终稿（转 `配置合规机构与三道防线`）；
- 确为中央企业且主成果是 42 号令对照终稿（转 `评估国企合规管理办法差距`）。

双方秘密、伪造已审议纪要、倒签生效日、指导删除会计资料、打击报复**不在负触发表**，走整体停止。「草案即已生效」「遵守即免责」「只要有利冲突版本」「民企套第八条」「无留痕例外」**不在负触发表**，该格 `现有依据不支持`，窗口不关；闸已开仍出其他 `N#`。

## 建立工作坐标

确认：起草授权；单方立场；制定机关（董事会／经理层，不是代股东会改章程）；效力层级；与章程、授权清单、专项办法的冲突；生效、公布、废止安排；是否中央企业或上市。

口头「已经过会了」「领导都同意了」只登记 `S#`／`V#`。不得升格已审议、已生效或已合规，**不得算作开闸材料**。已读、微信已读、电话、口头尽快、快递揽收只进 `S#`／`V#`，不得升格 `R#` 已送达或已公布生效。口头备份不等于已保全。

同时掌握公司与被调查对象相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。公司已开口且委托就是办法草案、且未掌握对方秘密时，可推定公司立场。无书面起草授权但公司立场已闭合：起草闸关闭，仍交十节，不是整体停止。提出伪造已审议纪要、倒签生效日、指导删除或打击报复：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认（不是已审议，不是已生效）；`R#` 机关或生效文书；`C#` 现有制度或章程条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`N#` 办法草案（不是公告正文，不是已生效文本）；`V#` 版本；`E#` 证据形态回链（授权、冲突文本、审议安排，不是发送闸）。禁止 `EV#`、`M#`、`F#`、`ACT#`、`P#`、`K#`、`O#`、`H#`、`B#`、`U#`、`X#`、`W#`、`HD#`。技能正文中的条号是检索锚点，不是已核验 `L#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态只用 `草案`、`待审议`、`停止`。禁止合成「已生效合规」一笔。扫描不是闭集。未知不写零。未定审议机关和公布方式：保持 `草案`。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：公司法股东会修改章程、董事会职权分列，本窗不替股东会改章程。中央企业合规管理办法第八条董事会审议批准合规管理基本制度，只约束国资委履行出资人职责的中央企业；民企套第八条该格 `现有依据不支持`，不关窗。第四十条是对地方国资机构的参照指导。第一百七十七条仅国家出资公司对内合规，不是民企必须出台办法的法定义务。行政处罚法第三十二条提交草案本身不等于情节成就。监察法第十八条如实提供，不得伪造、隐匿、毁灭。刑法第一百六十二条之一只作红旗，**不得指导删除**。噪声：已失效《合同法》、42 号令第八条套民企、草案即已生效、遵守即免责、境外范本当中国法、交稿即从轻。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变制定机关或 42 号令主体的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补空话义务、无留痕例外、冲突只留有利版本、未审议写成已生效的反例。
- `search_template`（optional）只借办法栏目，不把范本当法定格式、已生效文本或中国法义务；不得照抄境外范本冒充中国法。无范本不拒跑。

工具不可用时继续机关、冲突和 `N#` 编目；主体义务、生效条件字段停止。不得拒跑，不得凭记忆写成已生效、遵守即免责或民企必须按第八条报董事会并上报国资委。

## 判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、起草闸与不关窗

主成果才整案转出。审查起诉只作背景。伪造已审议或倒签生效第一次停。草案即已生效、遵守即免责、民企套第八条不关窗。闸关仍交十节，第 6 节不出 `N#` 终稿。

### 2. 制定机关、效力与冲突

董事会／经理层／章程授权分列。与章程、专项办法冲突并列。不替股东会改章程。

### 3. 起草闸与路径 `Q#`

本节禁止出 `N#` 终稿。无一可编号条款或现有制度则闸可关，窗口不关。口头已过会不得开闸。

### 4. 办法草案 `N#`

目的、适用范围、职责、政策层级、举报、调查、礼品与第三方接口、例外批准、考核接口、生效解释。每条义务能指向岗位。例外必须留痕。

### 5. 生效、边界与转介

未定审议机关和公布方式：保持草案。劳动、合同、专项只留接口。不保证免责。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造已审议纪要、倒签生效日、指导删除会计资料、借制度稿平行灭证或打击报复。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无书面起草授权但公司立场已闭合：不是整体停止，起草闸关闭，仍交十节。
- `字段停止`：制定机关、冲突规则、生效公布方式未核验。草案即已生效、遵守即免责、只要有利冲突版本、无留痕例外、民企套第八条：该格 `现有依据不支持` 或该条删除，窗口不关；闸已开仍出其他 `N#` 草案；闸未开才不出 `N#` 终稿。
- `目标停止`：主目标变为公司章程修订、劳动规章全文、交易合同或框架终稿。

禁止指导伪造已审议或删除会计资料。不给胜诉率。不定罪。不保证免责。不选定机关。不代提交。未知不写零。不替股东会改章程。不写劳动规章全文。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。起草闸关闭仍交十节，第 6 节不出 `N#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `N#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。起草闸未打开时不得交付办法终稿或「已生效」。边界见 [路由](references/routing.md)。
