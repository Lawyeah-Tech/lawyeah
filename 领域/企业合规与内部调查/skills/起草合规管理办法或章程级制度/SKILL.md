# 起草合规管理办法或章程级制度

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。本窗是起草类制度稿，范本只借栏目，**不要**升格「已生效／已审议通过／法定格式」。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现空壳办法、未审议写成已生效、口头突破无留痕的反例；案例只比较事实差异与翻转条件，不写成必然结果。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《民法通则》《民法总则》或其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成可审议的合规基本制度草案：审议闸、主体与强制接口、`Q#` 路径、`T#` 制度条文（目的／适用范围／职责接口／举报调查接口／礼品第三方接口／例外留痕接口／生效废止）、劳动与专项边界、生效条件。章程级合规办法不是公司章程。发送前稿不是已生效，不是已审议通过，不是劳动规章全文，不是框架图替代，不是交易合同。不保证免责。不代提交。

`depends-on` 为空。只要框架不要条文转 `设计合规管理体系框架`。只要政策层级与例外方案不要正文转 `设计政策层级与例外批准`。三道防线岗位细节转 `配置合规机构与三道防线`。已有体系要判断是否运转转 `评估合规管理体系有效性`。42 号令对照终稿转 `评估国企合规管理办法差距`。集团模板在境内独立法人落地转 `落地集团政策到境内实体`。公司章程、股东会、股权、任免本身转公司治理。

## 工作边界

正触发：公司需要一份可提交董事会或经理层审议的合规基本制度发送前稿，而不是只要框架图、只要层级方案或评价已有体系。碎片制度、审议机关未核验、资源不足仍正触发：审议闸关闭，不出 `T#` 终稿，窗口不关。用户要把草案写成已生效或已审议通过、把「遵守本办法即免除法律责任」写入正文、民企按公司法第一百七十七条或 42 号令必须达标上报、把 FCPA 程序写成中国法义务、口头领导同意即可突破、今天必须出已生效终稿，仍正触发：对应格填 `现有依据不支持`，窗口不关；闸已开仍出其他 `T#` 草案。不得因「保证免责」或「今天视为已生效」改走负触发关窗。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是只要框架不要条文（转 `设计合规管理体系框架`）；
- 主成果是政策层级与例外方案不要办法正文（转 `设计政策层级与例外批准`）；
- 主成果是三道防线岗位配置终稿（转 `配置合规机构与三道防线`）；
- 主成果是已有体系是否运转或正式评价项目（转 `评估合规管理体系有效性` 或 `开展合规有效性评价`）；
- 主成果是劳动规章或员工手册纪律全文（转劳动领域）；
- 主成果是交易合同改稿（审查起草本窗搁置）；
- 主成果是公司章程、股东会、股权或任免本身（转公司治理）；
- 确为中央企业且主成果是 42 号令对照终稿（转 `评估国企合规管理办法差距`）；民企或参股要求按 42 号令写办法仍正触发，该格 `现有依据不支持`，不得建议上报国资委。
- 主成果是数据或竞争专项制度全文（转相应领域）。

双方秘密、伪造审议或公布记录、倒签生效、指导删除会计资料、打击报复**不在负触发表**，走整体停止。「办法即免责」「未审议写成已生效」「口头突破」「民企套 177 或 42 号令」「FCPA 当中国法」「范本即法定格式」**不在负触发表**，该格 `现有依据不支持`，窗口不关；闸已开仍出其他 `T#`。

## 建立工作坐标

确认：制定授权；单方立场；主体（中央企业／地方国企／参股／民企／是否上市）；审议机关；现行制度与冲突；生效和废止安排；行业信号；当前检查、诉讼、监察或刑事状态。

口头「今天视为已生效」「群已读就是已公布」「领导点头即可突破」「范本拿来就能用」只登记 `S#`／`V#`。不得升格已审议、已公布或已生效，**不得算作开闸材料**。已读、快递揽收不得升格 `R#` 已送达，不得升格制度已生效。口头备份不等于已保全。口头知情不是已履职。

同时掌握公司与被调查对象相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。公司已开口且委托就是发送前办法、且未掌握对方秘密时，可推定公司立场。无书面制定授权但公司立场已闭合：审议闸关闭，仍交十节，不是整体停止。提出伪造审议纪要、倒签生效、指导删除或打击报复：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认（不是整改动作，不是已生效）；`R#` 机关或生效文书；`C#` 现行制度或章程授权；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`T#` 制度条文行；`V#` 版本；`E#` 证据形态回链（制定授权、审议职权、现行文本、旧规冲突件、拟公布方式，不是发送闸，不是已送达监管）。禁止 `N#`、`EV#`、`M#`、`F#`、`ACT#`、`P#`、`K#`、`O#`、`H#`、`B#`、`U#`、`X#`、`HD#`、`W#`。技能正文中的条号是检索锚点，不是已核验 `L#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止合成「已生效闭环」一笔。扫描不是闭集。缺项记 `G#`，不得用最佳实践或范本栏目填满。未知不写零。稿件状态默认 `草案`。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：公司法第六十七条董事会制定公司的基本管理制度，不等于已审议通过、已生效或免责。第一百六十八条国家出资公司不含参股。第一百七十七条仅约束国家出资公司对内合规，不是对外交稿或民企法定义务。中央企业合规管理办法第二条只约束国资委履行出资人职责的中央企业（主体须运行时核验）；第八条董事会审议批准合规管理基本制度、第九条经理层拟订基本制度，只约束中央企业。第四十条是对地方国资机构的参照指导，不是民企对国务院国资委义务。劳动合同法第四条劳动纪律民主程序只开接口，本窗不做完。行政处罚法第三十二条提交办法本身不等于从轻情节成就（噪声：1996 年第三十二条陈述申辩）。监察法第十八条如实提供，不得伪造、隐匿、毁灭。刑法第一百六十二条之一只作红旗，**不得指导删除**。不得把美国《反海外腐败法》或萨班斯内控程序写成中国法义务。噪声：已失效《合同法》、1993 公司法第一百七十七条公积金、42 号令套民企、办法即免责、未审议写成已生效、范本当法定格式、FCPA 当中国法、交办法即从轻。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变制定机关、主体义务范围或审议权限的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补空壳办法、未审议写成已生效、例外无留痕、口头突破的反例。
- `search_template`（optional）只借章程级办法栏目，不把范本当法定格式、已审议证明或已生效结论。无范本不拒跑。

工具不可用时继续主体、冲突和 `T#` 编目；主体义务、审议权限、施行日字段停止。不得拒跑，不得凭记忆写成民企必须适用 42 号令或草案已生效。

## 判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、审议闸与不关窗

主成果才整案转出。审查起诉或监管检查只作背景。伪造审议、倒签生效第一次停。办法即免责、未审议写成已生效、民企套 42 号令、FCPA 当中国法不关窗。闸关仍交十节，第 6 节不出 `T#` 终稿。

### 2. 主体与强制接口

中央企业／地方国企／参股／民企分列。强制接口与非强制对标分列。主体不适用则对照行删除。总部制度不能直接在独立法人子公司生效。

### 3. 审议闸与路径 `Q#`

本节禁止出 `T#` 终稿。无一可编号条文或现行碎片则闸可关，窗口不关。口头已生效、已读揽收不得开闸。

### 4. 制度条文 `T#`

每条义务能指向岗位。禁止「全面合规」无主句。开口径「经领导同意可突破」删除或该格停止。缺项记 `G#`。状态 `草案`。

### 5. 边界、生效条件与转介

劳动、数据、竞争、合同、公司章程只留接口。未确定审议机关不得写已生效。例外审批方案终稿转政策层级窗。不可逆动作不得在草案阶段实施。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造审议或公布记录、倒签生效、指导删除会计资料、借制度稿平行灭证或打击报复。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无书面制定授权但公司立场已闭合：不是整体停止，审议闸关闭，仍交十节。
- `字段停止`：42 号令主体、审议机关、施行日未核验；两份制度打架且用户要求只留有利版本。办法即免责、未审议写成已生效、口头突破、民企套 177 或 42 号令、FCPA 当中国法、范本即法定格式、保证免责：该格 `现有依据不支持`，窗口不关；闸已开仍出其他 `T#` 草案；闸未开才不出 `T#` 终稿。
- `目标停止`：主目标变为框架图、层级方案终稿、劳动规章全文、交易合同改稿、数据或竞争专项、公司章程本身。

禁止指导伪造审议或删除会计资料。不给胜诉率。不定罪。不保证免责。不选定机关。不代提交。未知不写零。不写劳动规章全文。不把章程级办法写成公司章程。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。审议闸关闭仍交十节，第 6 节不出 `T#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `T#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。审议闸未打开时不得交付制度终稿或「已生效」。边界见 [路由](references/routing.md)。
