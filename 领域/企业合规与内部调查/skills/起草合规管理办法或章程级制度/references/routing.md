# 边界与路由

## 正触发

公司需要一份可提交董事会或经理层审议的合规基本制度草案。审议机关、冲突或废止清单未闭合仍正触发：起草闸关闭，不出 `N#` 终稿，窗口不关。草案即已生效、遵守即免责、只要有利冲突版本、无留痕例外、民企套 42 号令第八条，仍正触发。

双方秘密、伪造已审议、倒签生效、指导删除、平行灭证、打击报复的停止，优先于负触发。上述信号不在下表。「草案即已生效」「遵守即免责」「只要有利冲突版本」「民企套第八条」「无留痕例外」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要框架不要文本 | `设计合规管理体系框架` |
| 政策层级方案不要正文 | `设计政策层级与例外批准` |
| 劳动规章或员工手册纪律全文 | 劳动领域 |
| 交易合同审查起草 | 审查起草领域（本窗搁置，只说明） |
| 公司章程修订本身 | 公司治理领域 |
| 三道防线岗位细节 | `配置合规机构与三道防线` |
| 确为中央企业且主成果是 42 号令对照终稿 | `评估国企合规管理办法差距` |

不得因「要求写成已生效」或「遵守即免责」关窗。未定审议机关仍正触发，保持草案。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、解除、工伤主轴 | 劳动领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |
| 垄断、滥用支配、经营者集中 | 竞争法领域 |
| 章程、股权、任免本身为主成果 | 公司治理领域 |

综合合规办法主轴可留本任务。审查起诉或检查只作背景，主成果才转。

## 易混

章程级合规办法不是公司章程，也不等于交易合同。发送前稿不是已生效制度。口头过会不是已审议。遵守本办法不是免责。「经领导同意可突破」无留痕不是例外批准。民企套 42 号令第八条：该格不支持，不关窗，不得建议上报国资委。「先补假纪要再出已生效稿」整体停止。已读不是已公布生效。
