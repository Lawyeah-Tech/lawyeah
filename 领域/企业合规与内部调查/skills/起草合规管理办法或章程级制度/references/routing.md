# 边界与路由

## 正触发

公司需要一份可提交董事会或经理层审议的合规基本制度发送前稿，而不是只要框架图、只要层级方案或评价已有体系。从零或审议机关未核验仍正触发：有拟设条文则闸开或半开，出 `T#` 草案，生效条件待核，保持草案。办法即免责、未审议写成已生效、口头突破、民企套 177 或 42 号令、FCPA 当中国法、范本即法定格式，仍正触发。

双方秘密、伪造审议、倒签生效、指导删除、平行灭证、打击报复的停止，优先于负触发。上述信号不在下表。「办法即免责」「未审议写成已生效」「口头突破」「民企套 42 号令」「FCPA 当中国法」「范本即法定格式」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 只要框架不要条文 | `设计合规管理体系框架` |
| 政策层级与例外方案不要办法正文 | `设计政策层级与例外批准` |
| 三道防线岗位配置终稿 | `配置合规机构与三道防线` |
| 已有体系是否运转 | `评估合规管理体系有效性` |
| 正式有效性评价项目 | `开展合规有效性评价` |
| 劳动规章或员工手册纪律全文 | 劳动领域 |
| 数据或竞争专项制度全文 | 数据隐私或竞争法领域 |
| 公司章程、股东会、股权或任免本身 | 公司治理领域 |
| 确为中央企业且主成果是 42 号令对照终稿 | `评估国企合规管理办法差距` |
| 交易合同改稿 | 审查起草领域（本窗搁置，只说明） |

不得因「保证免责」或「要求按 42 号令写死」或「今天视为已生效」关窗。未审议仍正触发，不得写成已生效。

## 易混

章程级合规办法不是公司章程，也不等于交易合同。发送前稿不是已生效制度。通过审议不是已合规，更不是免责。未审议不得写已生效。已读、揽收不是已公布，口头备份不是已保全。口头领导同意不是例外批准。民企套 42 号令或第一百七十七条：该格不支持，不关窗，不转出，不得建议上报国资委。FCPA 对标不是中国法义务。总部印发不能直接在独立法人子公司生效。「先补假审议纪要再出已生效稿」整体停止。劳动规章全文不在本窗。审查起诉只作背景，主成果才转刑事。
