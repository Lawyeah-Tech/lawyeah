# 评估方法

本文件是可执行判断节点。发送前稿不是已生效，不是已审议通过，不是劳动规章，不是公司章程。未审议不得写已生效。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、范本填满、唯一截止日、选定机关、代提交、未知写零。本任务不定罪，不写劳动规章全文，不改公司章程，不建设数据或竞争专项体系。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1993 公司法第一百七十七条公积金、1996 行政处罚法第三十二条陈述申辩、把 42 号令或第一百七十七条套民企、把草案写成已生效、把 FCPA 写成中国法义务、把范本当法定格式时记为噪声。禁止指导伪造审议或删除会计资料。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`T#` 固定列：`编号｜章节／条旨｜拟设要点｜指向岗位｜效力层级｜例外／升级接口｜E#回链｜判断三值｜缺口G#｜最强反方｜待核`。禁止合成「已生效闭环」一笔。`E#` 只作证据形态回链。缺项记 `G#`，不得用「参照最佳实践」或范本栏目填满。扫描不是闭集。禁止无岗位的「全面合规」空句。

口头「今天视为已生效」「群已读就是已公布」「领导点头即可突破」「范本拿来就能用」只进 `S#`／`V#`，**不得算作开闸材料**。已读、快递揽收不得升格制度已生效。口头知情不是已履职。`A#` 是承认，不是已生效。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

## 节点 0　分流、立场、审议闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。伪造审议、倒签生效、指导删除、平行灭证、打击报复、双方秘密不进负表。

整案转出只交付第 1、2、10 节，不出 `T#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是只要框架不要条文 | 负触发 `设计合规管理体系框架` |
| 主成果是政策层级与例外方案不要正文 | 负触发 `设计政策层级与例外批准` |
| 主成果是三道防线岗位配置终稿 | 负触发 `配置合规机构与三道防线` |
| 主成果是已有体系是否运转 | 负触发 `评估合规管理体系有效性` |
| 主成果是正式有效性评价项目 | 负触发 `开展合规有效性评价` |
| 主成果是劳动规章或员工手册纪律全文 | 整案转劳动 |
| 主成果是数据或竞争专项制度全文 | 整案转相应领域 |
| 主成果是交易合同改稿 | 审查起草本窗搁置 |
| 主成果是公司章程、股东会、股权或任免本身 | 整案转公司治理 |
| 主成果是 42 号令对照终稿 | 负触发 `评估国企合规管理办法差距` |
| 侦查、起诉、辩护为主成果 | 整案转刑事 |

审查起诉、监管检查只作程序背景。主成果才整案转。

审议闸打开（可出 `T#` 草案，仍不得标「已生效／已审议通过／已免责终稿」）须同时满足：单方无冲突公司立场已闭合；主成果是合规基本制度发送前稿，不是框架图、层级方案、劳动规章或公司章程本身；存在书面制定授权（章程／董事会职权／授权清单可编号）；至少一项可编号拟设条文或现行碎片可改写。口头已生效、已读揽收不算开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

审议闸部分打开：主体或审议机关未闭合，但已有可编号范围；对应格待核；仍交十节；不得标终稿 `已形成`。

审议闸关闭（仍正触发）：公司立场已闭合但无书面制定授权；无一拟设条文且无一现行碎片。「今天必须出已生效终稿」而无最小事实不得开闸。不出 `T#` 终稿。**仍交十节**，第 5 节只交闸／`Q#` 状态，第 6 节不出 `T#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「已经生效」或「没有缺口」。

「遵守本办法即免除法律责任」「未审议写成已生效或已公布」「口头领导同意即可突破」「民企必须按 177 或 42 号令达标上报」「把 FCPA 或萨班斯程序写成中国法义务」「把范本当法定格式」「保证通过即免责」「提交办法即应当从轻」「两份制度打架只留有利版本」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `T#` 草案。闸未开才不出 `T#` 终稿。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无书面制定授权，then 审议闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造审议或公布记录、倒签生效、指导删除会计资料、借制度稿平行灭证或打击报复，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

名称、规模、是否中央企业／国家出资公司／上市分列。不自动合并。独立法人子公司不与母公司自动合并。

检索锚点（写入 `L#` 前须核验）：

- 公司法第六十七条：董事会制定公司的基本管理制度，不等于已审议通过、已生效或免责。
- 公司法第一百六十八条：国家出资公司不含参股。第一百七十七条仅国家出资公司对内合规，不是对外交稿或民企义务。
- 42 号令第二条、第八条、第九条、第四十条：只约束中央企业；第八条董事会审议批准合规管理基本制度、第九条经理层拟订；第四十条是对地方国资机构的参照指导。民企制度是风险控制文本，强制对照行删除，该格 `现有依据不支持`，不关窗。不得建议民企上报国务院国资委。
- 公司法第三条：公司有独立法人财产。总部规章制度不能直接在独立法人子公司生效，须子公司有权机关批准；只开接口到 `落地集团政策到境内实体`。
- 劳动合同法第四条：劳动纪律民主程序只开接口，本窗不做完讨论协商公示证据。
- 不得把美国《反海外腐败法》或萨班斯内控条款写成中国法定义务；可作非强制对标并标明法域。
- 行政处罚法第三十二条：提交办法不等于情节成就。噪声：1996 年第三十二条陈述申辩。
- 民营经济促进法第三十九条是支持引导依法合规，不是必须按 42 号令达标上报。

国企适用办法条款才写入强制项。强制接口与非强制对标分列，不选对用户有利的一版。金融机构行业合规办法与 42 号令适用范围不同，主轴转金融领域。

## 节点 3　制度条文 `T#`

本任务文本范围按已出现需求扫描，不是默认闭集：目的、适用范围、职责接口、政策层级接口、举报与反报复接口、调查授权接口、礼品与第三方接口、例外留痕接口、考核接口、生效解释。缺项记 `G#`，不得用「参照最佳实践」或范本栏目填满。

每条义务必须能指向岗位。禁止「全面合规」无主句；无岗位则删除或改 `G#`。

例外必须可留痕：书面申请、审批层级、有效期、登记、事后稽核。开口径「经领导同意可突破」且无留痕：**该条删除或该例外字段停止**。口头同意不得高于书面，不得写成已批准。例外审批方案终稿转 `设计政策层级与例外批准`。本窗只留接口句。

冲突处理：上位优于下位、特别优于一般、新优于旧；无法判断则升级有权机关。两份现行制度打架且用户要求只保留有利版本：**冲突节字段停止**，两行并列，不选边。明示折扣佣金如实入账不是贿赂（反法 2025 第八条，施行日 2025-10-15，未核验则字段停止）；账外暗中不得写成合法。

劳动纪律、工时、解除只留「转劳动制度」接口，本窗不做完劳动合同法第四条民主程序证据。交易合同只留接口要点。处分员工只留接口。

## 节点 4　生效条件、可逆性与转介

未确定审议机关和公布方式：状态保持草案，不得写已生效。废止清单缺失：旧规并行冲突写入最强反方。已读、揽收、群转发、口头传达不得打开已生效路径。

可逆动作与不可逆动作分列。不可逆（对外披露、处分、终止第三方、对员工公布发生劳动纪律效力）不得在草案阶段实施。禁止提交指令。不代审议、不代公布、不代废止。

下一步只转介：框架、政策层级、三道防线、有效性、义务地图、举报渠道、反贿赂制度、集团落地、董事会汇报。禁止一次写完全部专项全文。

已有监察或检查 `R#`：不得借审议稿平行灭证。刑法第一百六十二条之一只作红旗，不得指导删除。

文本不得写「遵守本办法即免除法律责任」。涉及处分员工：只留接口，处分程序转劳动。

## 本任务回链纪律

本任务成果是「审议闸与发送前制度条文草案」。不包含：已生效制度、框架模块终稿、例外审批方案终稿、劳动规章全文、公司章程、数据或竞争专项、已审议通过证明。禁止伪造审议。禁止选边治愈。禁止未审议写成已生效。禁止办法即免责。禁止民企套 42 号令。禁止 FCPA 当中国法。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标制度终稿已形成。
