# 评估方法

本文件是可执行判断节点。草案不是已生效，不是已合规，不是公司章程已通过。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态只用 `草案`、`待审议`、`停止`。禁止胜诉率、必然免责、遵守即免责、唯一截止日、选定机关、代提交、未知写零。本任务不定罪，不写劳动规章全文，不写交易合同，不替股东会改章程。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、把 42 号令第八条套民企、把草案写成已生效、把遵守本办法写成免责、把境外范本当中国法时记为噪声。禁止指导伪造已审议或删除会计资料。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`N#` 固定列：`编号｜条款簇｜拟写要点｜指向岗位｜例外／冲突｜E#回链｜判断三值｜最强反方｜待核`。禁止合成「已生效合规」一笔。`E#` 只作证据形态回链。禁止把 `N#` 写成公告正文或已生效文本。扫描不是闭集。

口头「已经过会了」「领导都同意了」只进 `S#`／`V#`，**不得算作开闸材料**。已读、快递揽收不得升格 `R#` 已送达或已公布生效。口头备份不等于已保全。`A#` 是承认，不是已审议、不是已生效。拟制日＝本次形成本任务成果之日。

## 节点 0　分流、立场、起草闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。伪造已审议、倒签生效、指导删除、平行灭证、打击报复、双方秘密不进负表。

整案转出只交付第 1、2、10 节，不出 `N#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是综合框架不要文本 | 负触发 `设计合规管理体系框架` |
| 主成果是政策层级方案不要正文 | 负触发 `设计政策层级与例外批准` |
| 主成果是劳动规章或员工手册纪律全文 | 整案转劳动 |
| 主成果是交易合同改稿 | 审查起草本窗搁置 |
| 主成果是公司章程修订本身 | 负触发，转公司治理领域 |
| 主成果是三道防线岗位细节 | 负触发 `配置合规机构与三道防线` |
| 确为中央企业且主成果是 42 号令对照终稿 | 负触发 `评估国企合规管理办法差距` |
| 侦查、起诉、辩护为主成果 | 整案转刑事 |

审查起诉、监管检查只作程序背景。主成果才整案转。民企主张必须按 42 号令第八条出台办法：**不负触发**，走不关窗。

起草闸打开（可出 `N#` 草案，仍不得标「已生效／已审议通过／遵守即免责」）须同时满足：单方无冲突公司立场已闭合；主成果是合规基本制度草案，不是章程修订、劳动规章或交易合同；至少一项可编号条款簇或现有制度冲突。口头已过会不算开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

起草闸部分打开：审议机关或废止清单未闭合，但已有可编号条款或冲突文本；对应格待核；仍交十节；不得标终稿 `已形成`。

起草闸关闭（仍正触发）：公司立场已闭合但无书面起草授权；无一条款簇且无一现有制度。「今天必须出已生效文本」而无最小事实不得开闸。不出 `N#` 终稿。**仍交十节**，第 5 节只交闸／`Q#` 状态，第 6 节不出 `N#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「已生效」或「没有冲突」。

「草案即已生效」「遵守本办法即免除法律责任」「只要有利版本的冲突制度」「开口径经领导同意可突破且无留痕」「民企必须按 42 号令第八条由董事会批准并上报」「今天必须出已生效文本」「提交草案即应当从轻」**不关窗**。对应格 `现有依据不支持` 或该条删除。闸已开仍出其他 `N#` 草案。闸未开才不出 `N#` 终稿。不得建议民企向国务院国资委交办法。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无书面起草授权，then 起草闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造已审议纪要、倒签生效日、指导删除会计资料、借制度稿平行灭证或打击报复，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　制定机关、效力与冲突

固定制定机关、效力层级、与章程／授权清单／专项办法的关系。章程修订本身转公司治理。合规管理办法通常由董事会或经理层审议，不得写成已代股东会改章程。

检索锚点（写入 `L#` 前须核验）：

- 公司法：股东会修改章程；董事会职权分列。本窗不替股东会改章程。
- 42 号令第八条：中央企业董事会审议批准合规管理基本制度。只约束国资委履行出资人职责的中央企业。民企、参股套该条：该格 `现有依据不支持`，不关窗。
- 第四十条：地方国资机构参照指导，不是民企对国务院国资委交办法的义务。
- 第一百七十七条：仅国家出资公司对内合规，不是民企必须出台办法的法定义务。
- 行政处罚法第三十二条：提交草案不等于情节成就。
- 监察法第十八条：如实提供，不得伪造、隐匿、毁灭。

两份现行制度打架：并列并标待核。用户要求只保留有利版本：冲突节字段停止，不选边。

## 节点 3　办法草案 `N#`

文本范围：目的、适用范围、职责、政策层级、举报、调查、礼品与第三方接口、例外批准、考核接口、生效解释。按已出现需求扫描，不是默认闭集。每条义务必须能指向岗位。禁止「全面合规」无主句。

例外必须同时具备：书面申请、审批层级、有效期、公开或登记、事后稽核。开口径「经领导同意可突破」且无留痕：该条删除或改为字段停止。

冲突处理必须可执行：上位优于下位、特别优于一般、新规定优于旧规定，以及无法判断时的升级路径。

## 节点 4　生效、边界与转介

未确定审议机关和公布方式：状态保持 `草案`，不得写已生效。废止清单缺失：旧规并行冲突写入最强反方。文本不得写「遵守本办法即免除法律责任」。涉及处分员工：只留接口，处分程序转劳动。

不可逆（对外公布为已生效、处分、终止第三方）不得在草案阶段实施。下一步只转介邻居。禁止提交指令、此致董事会作为代提交。

已有监察或检查 `R#`：不得借制度稿平行灭证。刑法第一百六十二条之一只作红旗，不得指导删除。
