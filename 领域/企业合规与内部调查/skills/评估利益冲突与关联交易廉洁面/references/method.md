# 评估方法

本文件是可执行判断节点。在关联方清单上不等于已经廉洁。口头据说已说不是已披露。披露晚于决策不是有效披露。回避后经秘书或下属施加影响则回避不成立。公司法第一百八十五条董事会表决回避不是调查回避已成立。第一百八十二条报告与决议只开接口，不是已公允。第一百八十条忠实勤勉不是已履职、不是已廉洁。亲属供货不是当然贿赂，也不是当然全额归入。关联批准不是当然合法。利益冲突未解不是整体停止。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。披露三态只用 `书面且决策前`、`决策后补或隐瞒`、`口头待核`。回避有效性只用 `离开决策链`、`秘书或下属代行则不成立`、`调查回避转出`。禁止胜诉率、必然免责、刑事既遂、选定法院、代提交、代批准、未知写零。本窗不定罪，不写决议正文，不审合同全文，不出调查回避终稿。本窗 `IC#` 是冲突行，不是调查回避行 `AV#`，不是风险点 `BR#`，不是礼品审查行 `GF#`，不是制度行 `GP#`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1993 年公司法第一百八十条法定公益金、第一百九十一条清算组、把清单写成已廉洁、把银保办法写成一般企业必须适用时记为噪声。禁止指导隐瞒关联关系、把未披露改成会前已披露、拿掉不利关系或伪造披露。禁止 `search_template` 生成已廉洁清单、决议正文或合同改稿。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现冲突或交易扫描，不是默认闭集。
`IC#` 固定列：`编号｜冲突主体与角色｜关系类型｜相对方｜交易碎片｜披露三态（书面且决策前／决策后补或隐瞒／口头待核）｜回避有效性（离开决策链／秘书或下属代行则不成立／调查回避转出）｜182／185批准与公允接口（只开接口）｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已廉洁闭环」。无 `E#` 不得写已覆盖、已廉洁、已披露、已公允。`E#` 只作证据形态回链。缺项记 `G#`。扫描不是闭集。书面且决策前 ≠ 已廉洁。决策后补或隐瞒 ≠ 已贿赂。离开决策链 ≠ 调查已回避。批准接口打开 ≠ 已公允 ≠ 已合法。

口头「在清单上了」「会上说过」「补一份披露就行」「董事会已经回避了所以调查也回避了」「批过了就是合法」「亲属供货就是行贿」只进 `S#`／`V#`，**不得单独算作开闸材料**。清单能开闸，不能升格已廉洁。表决回避记录能开闸，不能升格调查已回避。`A#` 是承认关系或交易存在，不是已廉洁。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上董监高应及时报送关联人名单；禁止隐瞒关联关系规避披露；决策时应披露并回避；关联交易低价或高价认定更严——本窗仍不得把报送名单升格已廉洁，不得把程序走完升格已公允。明示折扣佣金如实入账不是贿赂。类案未向董事会报告近亲属控制企业交易可支撑违反忠实义务，但归入权限于溢出利益须证明，交易款项或亲属工资不当然全额归入。

## 节点 0　分流、立场、冲突闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、指导隐瞒关联关系、指导把未披露改成会前已披露、指导拿掉不利关系、伪造或倒签披露、打击报复、阻挠合法检查不进负表。利益冲突未解不进整体停止。不写决议、不审合同不进负表。

整案转出只交付第 1、2、10 节，不出 `IC#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是调查回避终稿 | 负触发 `处理利益冲突与调查回避` |
| 主成果是关联交易股东大会或董事会决议正文 | 整案转公司治理 |
| 主成果是尚未进入合规机制的交易合同改稿 | 负触发审查起草（本窗搁置，只说明不实施） |
| 主成果是廉洁风险图 | 负触发 `评估反商业贿赂风险点` |
| 主成果是礼品、招待、赞助或捐赠单笔审查 | 负触发 `审查礼品招待赞助与捐赠` |
| 主成果是回扣账外资金链路终稿 | 负触发 `评估回扣账外暗中与资金链路` |
| 主成果是是否启动内部调查 | 负触发 `评估是否启动内部调查` |
| 主成果是调查报告终稿 | 负触发 `形成内部调查报告` |
| 主成果是董监高履职缺口终稿 | 负触发 `评估董监高合规职责缺口` |
| 主成果是上市披露或内控交叉终稿 | 负触发 `评估上市公司廉洁与内控交叉` |
| 主成果是刑事辩护、控告或自首 | 整案转刑事 |
| 主成果是劳动解除或处分决定 | 整案转劳动 |
| 「不写关联交易股东大会决议」「不审查交易合同全文」「不定罪」「不保证已廉洁」 | 交付禁令，不是负触发 |

审查起诉、监管检查、已立案只作程序背景。主成果才整案转。出现「关联」「回避」「合同」一词不是转出。

冲突闸打开（可出 `IC#` 草案，仍不得标「已廉洁／已披露／已公允／已履职」）须同时满足：单方无冲突公司立场已闭合；主成果是廉洁面评估，不是决议、合同改稿或调查回避终稿；至少一名可编号冲突主体或一条交易碎片。关联方清单、股权穿透材料、供货合同封面或订单、亲属关系说明、董事会回避记录、口头承认关系的会议纪要可编号开闸。口头「在清单上了」「会上说过」不算单独开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

冲突闸部分打开：已有可编号冲突主体或交易碎片，但近亲属范围、披露时点、决策链、是否国企或上市未闭合；或无书面评估授权但已有碎片；对应格待核；仍交十节；不得标终稿 `已形成`。

冲突闸关闭（仍正触发）：无一可编号冲突主体且无一交易碎片。「今天必须出已廉洁终稿」而无最小件不得开闸。不出 `IC#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `IC#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关写成「没有关联」或「在清单上即已廉洁」。

「在清单上即已廉洁」「口头披露即已披露」「决策后补披露即有效」「表决回避即调查已回避」「关联批准即当然合法」「亲属供货即贿赂或全额归入」「忠实勤勉即已履职」「交关联表即从轻或自首」「民企必须按 42 号令专项或本笔已合规」「银保办法即一般企业必须适用」「本表已定罪」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `IC#` 草案。上述行**不得写入可执行 `IC#` 的已廉洁结论**。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无一可编号冲突主体且无一交易碎片，then 冲突闸关闭，仍交十节，不是整体停止。
若 if 单方立场已闭合、无书面评估授权但已有可编号碎片，then 冲突闸部分打开，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象或相对方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出指导隐瞒关联关系、指导把未披露改成会前已披露、指导拿掉不利关系、伪造或倒签披露、打击报复、阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。
若 if 利益冲突未解但未要求隐瞒或伪造，then 窗口不关，不是整体停止，继续出 `IC#` 草案。

## 节点 1　主体、关系碎片与强制接口

一行一个冲突主体或交易碎片。缺项记 `G#`，未知金额不得写 `0`。近亲属范围依据不足：该行待核，不缩小也不扩大写成必然违法。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 主体属性 | 中央企业／地方国企／参股／民企／上市／银保机构 | 把民企写成必须按 42 号令专项；把银保办法写成一般企业必须适用 |
| 冲突主体×角色 | 董监高、员工、近亲属、控制企业、隐性中介 | 口述「在清单上了」消除角色 |
| 关系类型 | 本人／近亲属／控制／共同投资／隐性中介 | 近亲属未核验写成必然违法或必然无关 |
| 相对方与交易 | 采购、供货、租赁、资金占用、担保、服务 | 未知金额写零 |
| 披露时点 | 相对决策时点 | 口头升格书面决策前 |
| 决策链 | 是否离开；秘书或下属是否代行 | 表决回避写成调查已回避 |
| 机关状态 | 检查／监察／刑事 `R#` 有无 | 把交关联表写成从轻 |

检索锚点（写入 `L#` 前须核验）：

- 公司法第一百八十条：避免利益冲突是忠实义务接口，不是已廉洁、不是已履职。噪声：1993 年第一百八十条法定公益金。
- 公司法第一百八十二条：董监高及其近亲属、所控制企业关联交易须向董事会或股东会报告并决议；只开接口，本窗不写决议，不写成已公允。
- 公司法第一百八十五条：关联董事不得表决；无关联董事不足三人提交股东会。是董事会表决回避，不是调查已回避，不是已公允。
- 证券法第七十八条、第八十条：只约束境内信息披露义务人；本窗不写公告正文。
- 42 号令第二条只约束中央企业。第十八条重点领域专项不套民企必须制定。
- 银行保险机构关联交易管理办法：只约束银保机构。
- 反不正当竞争法（2025）第八条：明示折扣佣金如实入账不是贿赂；亲属供货不是当然贿赂。
- 行政处罚法（2021）第三十二条：交关联表 ≠ 从轻。
- 监察法第十八条第一款如实提供；不得指导隐匿。
- 刑法第一百六十三条、第一百六十四条、第三百八十五条、第三百八十九条只作红旗，不定罪。刑法第一百六十二条之一、第三百零七条、第三百零八条只作红旗，不得指导删档。

国企／民企／上市／银保分列。强制接口与非强制对标分列。本节禁止出 `IC#` 终稿。

## 节点 3　关联行 `IC#`

按已出现冲突或交易扫描，不是默认闭集。建议行型（出现才用，**不是闭集**）：

| 编号 | 含义 | 本窗允许 | 禁止 |
| --- | --- | --- | --- |
| `AT-董` | 董监高本人 | 冲突行草案 | 忠实勤勉即已廉洁 |
| `AT-亲` | 近亲属 | 范围待核不扩不缩 | 写成必然违法或必然无关 |
| `AT-控` | 控制企业 | 报告与决议只开接口 | 写成已公允 |
| `AT-隐` | 隐性中介或未入清单 | 红旗可见 | 未入清单即无冲突 |
| `AT-披` | 披露三态 | 书面决策前／决策后补或隐瞒／口头待核分列 | 口头或补披露升格有效 |
| `AT-回` | 决策回避有效性 | 离开决策链才支持；秘书或下属代行则不成立 | 表决回避写成调查已回避 |
| `AT-批` | 182／185 批准与公允接口 | 只开接口 | 本窗出决议或已合法 |
| `AT-单` | 清单覆盖主张 | 该格不支持已廉洁 | 写入可执行已廉洁 |

热冲突强制处理：

- 清单即已廉洁／口头即已披露／补披露即有效／表决回避即调查已回避／关联批准即当然合法／亲属供货即贿赂或全额归入／忠实勤勉即已履职 → 该格不支持；仍出其他 `IC#`。
- 回避后经秘书或下属施加影响 → 回避不成立。
- 近亲属范围依据不足 → 该行待核，不缩小也不扩大写成必然违法。
- 亲属供货未向董事会报告 → 可标忠实义务红旗；归入或追偿须溢出利益待核，不得写成当然贿赂或当然全额归入。
- 用户主成果要决议或改合同 → 负触发转出，不是在本窗第 6 节写正文。
- 指导隐瞒、伪造披露或双方秘密 → 整体停止，不是该格不支持。

事实不足以支持某关联行：该条 `依据不足，无法形成结论`，不关窗。无 `E#` 不得写已覆盖、已廉洁、已披露或已公允。状态 `草案`。一次只推荐下一步。可并行必须逐条写条件。

## 节点 4　交易、调查接口、禁止文书与转介

第 7 节只开接口，不得夹带 `IC#` 终稿绕闸。闸关闭时第 7 节可写「闸未开，转介待冲突主体编号」，不得补写已廉洁。

第一百八十二条、第一百八十五条只开报告、决议与表决回避接口。不写股东大会或董事会决议正文。不审查、不改交易合同全文。不写成已公允、已合法。调查场景回避转 `处理利益冲突与调查回避`，本窗不出 `AV#`。账外利益转 `评估回扣账外暗中与资金链路` 或 `评估是否启动内部调查`。礼品单笔转 `审查礼品招待赞助与捐赠`。上市披露转 `评估上市公司廉洁与内控交叉`，本窗不写公告。

不可逆（对外宣称已廉洁、群发已无关联、向监管正式报告已公允、签署虚假披露、把未披露改成会前已披露）不得在草案阶段实施。禁止提交指令。不代提交。不代批准。不选定机关。

已有检查或刑事 `R#`：不得借评估稿干扰办案或隐瞒关联关系。刑法第一百六十二条之一只作红旗，不得指导隐匿。

若 if 用户催促「按零写／填满已廉洁终稿」，then 该格 `现有依据不支持`，窗口不关。
若 if 金额、近亲属范围未知，then 写 `未知`／`G#`，禁止写 `0`，禁止缩小或扩大写成必然结论。
