# 评估方法

本文件是可执行判断节点。本任务不保证不起诉，不辩护个人刑事责任，无证据不得写已通过验收。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。计划状态只用 `草案`、`待核`、`可验证`、`停止`。禁止胜诉率、必然免责、唯一截止日、选定检察院、代提交、未知写零。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。禁止编造最高检指导意见条号或文号。`search_law` 返回 1979 年刑法第六十七条缓刑条款、把企业合规材料写成自首已成立、或把 42 号令写成检察合规机制时记为噪声。

`P#` 固定列：`编号｜针对的涉案原因｜动作｜责任人｜时点类型｜验收证据形态｜状态词｜判断｜待核`。
`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持｜不利｜互斥／转介｜状态｜待核`。

口头「已经过了」、已读、快递发出只进 `S#`／`V#`，不得升格已通过验收或已不起诉。拟制日＝本次形成本任务成果之日。验收日、落款不得早于本次形成日。

## 节点 0　分流、立场、验收闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。伪造证据、利诱评估、双方秘密不进负表。

整案转出只交付第 1、2、10 节，不出验收终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是无检察程序的普通内部整改 | 负触发 `准备合规整改方案` |
| 主成果是调查报告 | 负触发 `形成内部调查报告` |
| 主成果是市监等行政自查、无检察程序 | 负触发 `准备主动披露或自查报告` |
| 主成果是跟踪已列动作的验收与复发 | 负触发 `跟踪整改验收与复发监测` |
| 主成果是自然人辩护、取保、量刑、阅卷 | 整案转刑事 |
| 税务稽查实体 | 整案转税务 |
| 数据专项体系主轴 | 整案转数据隐私 |

验收闸打开（可出 `P#` 草案，仍不得标「已通过／必然不起诉」，仍不代提交）须同时满足：单方无冲突企业立场与材料授权；主成果是检察合规计划或验收材料，不是普通整改、个人辩护或行政自查；至少一项可编号涉案原因或计划／证据缺口；机制文件已检索（有或无结果均须登记）；无双方秘密、无第一次伪造／利诱／走过场信号。

验收闸部分打开：文件未核验或第三方未选任，但已有检察阶段事实和可编号整改动作；对应格待核；仍交十节；不得标终稿 `已形成`。

验收闸关闭（仍正触发）：无检察程序信号且用户仍要本窗；无一可回链计划或证据。「今天必须过验收」而无最小事实不得开闸。不出计划终稿。**仍交十节**，第 5 节只交闸／`Q#` 状态，第 6 节不出 `P#` 计划终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「不适用所以必然起诉」或「已经过关」。

「保证不起诉、撤销案件或免罚」「规范文件未核验仍要写成法定必然适用」「今天必须过验收」「把计划写成已通过」「合规材料即自首已成立」「选定某检察院」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸未开仍不出验收终稿。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握企业与自然人犯罪嫌疑人相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 伪造整改或验收证据、利诱评估人员、设计走过场、隐瞒未改项、倒签验收日，then 整体停止；第一次提出即停，不以「坚持」为门槛。

自然人辩护、罪名、量刑、羁押必要性：整段转刑事。本任务只处理企业合规计划与验收材料。

## 节点 1　文件核验与适用接口

检索并核验最高检《关于建立涉案企业合规第三方监督评估机制的指导意见（试行）》及《涉案企业合规建设、评估和审查办法（试行）》的名称、文号、效力、施行日和适用范围。MCP 无结果：适用与验收法律结论停止，仍可整理企业已有整改事实，并明确「机制条款待核」。禁止编造条号。

机制由人民检察院在办理涉企犯罪案件时启动；结果是依法处理案件的重要参考，不是必然不起诉。检索锚点：人民检察院刑事诉讼规则（2019）第三百三十九条。个人犯罪与企业责任分列。无检察程序：负触发普通整改，并在缺口标明机制条件待核。

小微企业未启动第三方时，检察院可直接审查其提交的合规计划和整改报告——只开接口，本窗不得写成已经替代第三方或已经从宽。

## 节点 3　针对原因的计划 `P#`

计划必须回链涉案业务、决策链、资金和监督失效点。制度、执行、监督、培训、问责须可验收。复制通用合规章程而不针对原因：退回重写。无验收证据不得把状态词升为 `可验证` 以上。当场改正截图不等于已通过第三方评估。

---

## 节点 4　第三方、验收对照与不得承诺

评估人与企业、被害人、承办律师有利害关系：回避。企业不得设计「评估走过场」的脚本。未启动则只写接口。

验收对照：`P#`｜承诺｜证据｜判断三值。允许写：材料是否齐备、整改是否可验证、缺口。禁止：预测起诉或不起诉、保证从宽、标已通过验收而无证据。

不得承诺清单必须出现：必然不起诉、撤销案件、免于处罚、法定应当适用、自首已成立、选定某检察院。

## 再执行清单

每个节点结束后回写：来源、判断、最强反方、是否字段停止。不得跳过验收闸直接给已通过。

若 if 机制文件未核验，then 适用与验收法律结论字段停止，不写依法应当适用。
若 if 已有检察 `R#`，then 不得借验收完成隐瞒未改项或伪造证据。

## 本任务回链纪律

本任务成果是「验收闸、适用接口、针对原因的计划与验收对照草案」。不包含：不起诉决定预测、个人辩护、普通整改终稿、披露发送稿。禁止把计划写成已通过。禁止倒签。禁止选边治愈。禁止利诱评估。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标验收终稿已形成。
风险档 A：伪造证据、利诱评估、走过场必须单独标可逆性；提出即整体停止。
