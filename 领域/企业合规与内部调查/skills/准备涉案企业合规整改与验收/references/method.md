# 准备涉案企业合规整改与验收方法

本文件是可执行判断节点。第三方评估是办案重要参考，不是必然不起诉。交计划不是不起诉。企业交合规材料不是自首。复制通用章程不是计划。42 号令不是检察合规机制。口头「已经过了」不是已通过。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。计划状态只用 `草案`、`待核`、`可验证`、`停止`。禁止胜诉率、必然不起诉、选定检察院、代提交、未知写零。本任务不定罪，不保证不起诉，不辩护个人刑事责任。本窗闸名只能是验收闸，禁止复用整改闸、检查闸、监测闸、评估闸。预留不得占用：立案闸、调查闸。本窗 `YA#` 是验收行。主路径只用 `Q-验`，禁止用 `Q-检`、`Q-检合`、`Q-整改`、`Q-监`、`Q-总` 作主路径。英文 id 禁止使用，一律用中文技能名 `准备涉案企业合规整改与验收`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。禁止编造最高检指导意见或建设评估审查办法条号。`search_law` 返回 1979 年刑法第六十七条缓刑、1996／2017 年行政处罚法第三十二条陈述申辩、把企业合规材料写成自首、把 42 号令写成检察机制时记为噪声。禁止指导伪造、利诱或走过场。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。
`YA#` 固定列：`编号｜计划切片（须回链涉案原因：业务／决策链／资金／监督失效）｜责任人与时点｜验收证据形态｜第三方／回避｜打开接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。无 `E#` 不得写 `可验证` 以上。`可验证` 不等于已通过。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-验`。禁止 `P#`、`N#`、`A#`、`K#` 作主行。

口头「已经过了」「检察说没问题」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。验收日不得倒签。稿件状态默认 `草案`。每一条计划必须回链涉案原因。复制章程不得开闸。

实务上：计划须围绕与涉嫌犯罪密切相关的治理、制度、人员问题。考察结果是办案重要参考。发现未掌握犯罪或新犯罪应中止评估并报告，不得隐瞒。

## 节点 0　分流、立场、验收闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造、利诱、走过场、隐瞒未改、倒签不进负表。利益冲突未解不进整体停止。不定罪、不保证不起诉、不代提交不是负触发。禁止把整改闸、检查闸、监测闸写进本窗节点 0。

整案转出只交付第 1、2、10 节，不出 `YA#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是无检察程序的普通内部整改 | 负触发 `准备合规整改方案` |
| 主成果是调查报告 | 负触发 `形成内部调查报告` |
| 主成果是市监等行政自查、无检察程序 | 负触发 `准备主动披露或自查报告` |
| 主成果是跟踪已列动作的台账闭合 | 负触发 `跟踪整改验收与复发监测` |
| 主成果是检查现场应对 | 负触发 `应对监管检查或突击检查` |
| 主成果是内部独立监察或监管人人选 | 负触发 `设置合规监管人或独立监察` |
| 主成果是三道防线岗位配置 | 负触发 `配置合规机构与三道防线` |
| 主成果是自然人辩护、取保、量刑、阅卷 | 整案转刑事 |
| 主成果是税务实体处理（非涉税犯罪之检察计划） | 整案转税务 |
| 主成果是数据专项体系（非数据犯罪之检察计划） | 整案转数据隐私 |
| 「不定罪」「不保证不起诉」「不代提交」 | 交付禁令，不是负触发 |

出现「验收」「合规」「不起诉」一词不是转出。审查起诉阶段、涉案罪名作背景留本窗。涉税或数据犯罪的检察合规计划可留本窗。

验收闸打开（可出 `YA#` 草案，仍不得标「已通过／必然不起诉」）须同时满足：单方无冲突企业立场已闭合；主成果是检察合规计划或验收对照，不是普通整改、个人辩护或行政自查；至少一项可回链涉案原因的计划或证据碎片。口头「已经过了」、复制通用章程不算单独开闸材料。

验收闸部分打开：文件未核验或第三方未由管委会选任，但已有检察阶段事实且已有可编号涉案原因；对应格待核；仍交十节。无书面材料授权但单方立场已闭合且已有检察触点或原因碎片：验收闸部分打开，仍交十节，不是整体停止。

验收闸关闭（仍正触发）：无一可回链涉案原因；复制通用合规章程当计划；「今天必须过验收」而无最小事实。不出 `YA#` 终稿。**仍交十节**，第 5 节只交闸／`Q-验`，第 6 节不出 `YA#` 终稿，**第 7 节不得出已通过或发送版**。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「不适用所以必然起诉」或「已经过关」。无检察程序且主成果是内部整改：负触发 `准备合规整改方案`，不得用闸关留本窗十节壳。

「保证不起诉、撤销案件、不批捕、从宽量刑或免罚」「文件未核验写成法定必然适用」「今天必须过验收」「把计划写成已通过」「合规材料即自首」「选定某检察院」「小微未请第三方即已从宽」「42 号令应当进入第三方」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `YA#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可回链涉案原因，then 验收闸关闭，仍交十节，不是整体停止。
若 if 同时掌握企业与自然人犯罪嫌疑人相互冲突的秘密，或两造争同一份验收稿，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造整改或验收证据、利诱评估人员、设计走过场、隐瞒未改项、倒签验收日、指导拒不报告新罪，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　文件核验与适用接口

一行一个适用或主体切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `YA#` 终稿。

检索锚点（写入 `L#` 前须核验）：最高检指导意见（试行）及建设评估审查办法（试行）的名称、文号、效力、施行日、适用范围；未检出则适用字段停止。刑诉规则 2019 第三百三十九条不得预测起诉或不起诉。刑法 2023 第六十七条企业材料 ≠ 自首；噪声 1979 年第六十七条缓刑。行政处罚法第三十二条交计划 ≠ 从轻；噪声 1996／2017 年第三十二条。42 号令不是检察机制。小微直接审查出处是建设评估审查办法，未核验不得编条号，只开接口。

个人犯罪与企业责任分列。无检察程序：负触发普通整改。

## 节点 3　验收行 `YA#`

按已出现涉案原因扫描，不是默认闭集。每一条必须回链业务、决策链、资金或监督失效之一。禁止只贴完善制度、加强培训、重申手册。制度／执行／监督／培训／问责须可拆。培训签到、当场改正截图、再发文件单独不得升 `可验证`。

无 `E#` 不得写 `可验证` 以上。状态默认 `草案`。一次只推荐下一步。未知不写零。时点分列：内部计划时点（非法定）／第三方考察期限（待核）／检察文书时点。禁止唯一「今天必须过验收」。

热冲突强制处理：

- 保证不起诉／法定必然适用／今天必须过验收／计划写成已通过／合规即自首／选定某检察院／复制章程就够／小微即已从宽 → 该格不支持或字段停止；仍出其他 `YA#`。
- 无一原因碎片或复制通用章程 → 关闸，不出 `YA#` 终稿，窗口不关。
- 伪造、利诱、走过场、隐瞒未改、倒签 → 整体停止。

## 节点 4　第三方、回避与不得承诺

第 7 节只开接口，不得夹带 `YA#` 终稿或已通过绕闸。闸关闭时第 7 节可写「闸未开，转介待原因编号」，不得补写已通过。不选定检察院。不代提交。不定罪。不保证不起诉。评估人应回避未回避：该格不支持，不是整体停止。企业不得设计走过场脚本。未启动则只写接口。

不得承诺：必然不起诉、撤销案件、不批捕、从宽量刑、免于处罚、法定应当适用、自首已成立、选定某检察院。第三方考察材料对办案是参考，不是本窗产品可决定从宽。

下一步只转介：`准备合规整改方案`、`形成内部调查报告`、`准备主动披露或自查报告`、`应对监管检查或突击检查`、`跟踪整改验收与复发监测`、`设置合规监管人或独立监察`、`准备根因分析与控制补强`、`评估是否启动内部调查`、`建立内部调查证据案卷`、`评估国企合规管理办法差距`、`处理利益冲突与调查回避`、`评估律师工作产品与保密边界`、`准备向监管提交材料与特权日志`、`准备董事会合规汇报材料`、`评估企业合规风险总图`、`测算舞弊损失与追偿`、`评估调查后处置路径`、`开展合规有效性评价`。禁止此致某检察院。禁止转介本窗完成伪造。

若 if 用户催促「保证不起诉／章程就够／今天必须过验收／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：单位行贿审查起诉，企业交集团合规章程和培训签到，主张今天必须过验收、交了应当不起诉、这就是自首、按 42 号令必须进第三方、此致某检察院。验收闸关闭或半开。`Q-诉`、`Q-67`、`Q-42`、`Q-签` 不打开为可靠路径。第 6 节不得把已通过、必然不起诉、自首已成立写入可执行 `YA#`；对应格 `现有依据不支持`；有涉案资金／审批链碎片则出其他 `YA#` 草案，仅有章程则不出终稿。不关窗。不保证不起诉。不定罪。

场景②：用户同时交出企业「必须写成已全面整改、未改项不要给第三方」与自然人嫌疑人「从未参与」口径，并要求补上周验收签字、请评估人吃饭。命中双方秘密＋隐瞒未改＋倒签＋利诱。第一次整体停止。只交第 1、10 节。不出 `YA#`。不得问代表哪一方后继续。不以「坚持」为门槛。
