# 边界与路由

## 正触发

检察企业合规程序或第三方评估／验收是主成果。机制文件未核验、第三方未选任、证据未齐仍正触发：验收闸关闭，不出验收终稿，窗口不关。保证不起诉、法定必然适用、今天必须过验收，仍正触发。

双方秘密、伪造整改证据、利诱评估人员、走过场、隐瞒未改项、倒签的停止，优先于负触发。上述信号不在下表。「保证不起诉」「法定必然适用」「今天必须过验收」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 无检察程序的普通内部整改 | `准备合规整改方案` |
| 内部调查报告 | `形成内部调查报告` |
| 向市监等行政机关自查、无检察程序 | `准备主动披露或自查报告` |
| 跟踪已列动作的验收与复发 | `跟踪整改验收与复发监测` |
| 个人刑事辩护、取保、量刑、阅卷 | 刑事领域 |

已经决定就某一线索出辩护意见或普通整改终稿时负触发。不得因「要求保证不起诉」或「要求今天过验收」关窗。企业想「做个合规应付一下案子」但无检察程序：走普通整改，并说明检察机制条件待核。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、阅卷、辩护、自首材料为主成果 | 刑事领域 |
| 劳动合同、解除、工伤或日常处分决定主轴 | 劳动领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |
| 垄断、滥用支配、经营者集中 | 竞争法领域 |
| 税务稽查实体 | 税务领域 |

综合企业合规材料主轴可留本任务。自然人罪名与量刑整段转刑事。

## 必转介接口

| 信号 | 转介 |

| 个人辩护 | 刑事领域 |

## 易混

「先把未改的写成已通过再补证据」整体停止，不是负触发。「交了计划就应当不起诉」不关窗，该格不支持。「小微企业没请第三方所以可以直接认定从宽」只开接口，不得写成已经从宽。企业合规材料不是单位自首已成立，更不是个人当然自首。
