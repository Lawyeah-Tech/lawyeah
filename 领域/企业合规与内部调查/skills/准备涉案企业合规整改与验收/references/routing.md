# 边界与路由

## 正触发

检察机关提出或企业拟申请进入企业合规第三方监督评估，或单位未作被告但检察院对企业启动合规，主成果是针对涉案原因的计划与验收对照。机制文件未核验、第三方未选任、证据未齐仍正触发：闸半开，对应格待核。复制通用章程、无一原因碎片仍正触发：闸关，仍交十节，第 6 节不出 `YA#` 终稿。本次不定罪、不保证不起诉、不代提交是交付禁令，不是开窗条件。保证不起诉、法定必然适用、今天必须过验收、合规即自首、选定某检察院，仍正触发。

双方秘密、伪造证据、利诱评估、走过场、隐瞒未改、倒签的停止，优先于负触发。上述信号不在下表。不定罪不是负触发。「保证不起诉」「今天必须过验收」不在下表。伪造不在下表，走整体停止。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 无检察程序的普通内部整改 | `准备合规整改方案` |
| 调查报告终稿 | `形成内部调查报告` |
| 市监等行政自查、无检察程序 | `准备主动披露或自查报告` |
| 跟踪已列动作的台账闭合 | `跟踪整改验收与复发监测` |
| 检查现场应对 | `应对监管检查或突击检查` |
| 内部独立监察或监管人人选 | `设置合规监管人或独立监察` |
| 三道防线岗位配置 | `配置合规机构与三道防线` |
| 自然人辩护、取保、量刑、阅卷 | 刑事领域 |

不得因「不定罪」或「不保证不起诉」关窗。无检察程序不得用闸关留本窗十节壳。出现「验收」「合规」「不起诉」一词不是转出。审查起诉阶段本身不整案转刑事。

## 易混

本窗闸名只能是验收闸，不是整改闸，不是检查闸，不是监测闸，不是评估闸。`YA#` 不是 `P#`，不是 `ZG#`，不是 `YS#`，不是 `XR#`。主路径是 `Q-验`，不是 `Q-检`，不是 `Q-检合`，不是 `Q-整改`，不是 `Q-监`。邻窗 `准备合规整改方案`、`应对监管检查或突击检查`、`跟踪整改验收与复发监测`、`设置合规监管人或独立监察`、`准备根因分析与控制补强`、`准备主动披露或自查报告` 的检察验收转介改挂 `Q-验`。`Q-检合` 只作过渡别名，不升主路径。评估结果是办案重要参考，不是应当不起诉。交计划不是自首。复制章程不是计划。42 号令不是检察机制。1979 年刑法第六十七条不是现行自首条。提出「未改的先写成已完成、请评估人吃饭」整体停止。本窗不代提交。不选定检察院。不定罪。不保证不起诉。不出普通整改终稿。
