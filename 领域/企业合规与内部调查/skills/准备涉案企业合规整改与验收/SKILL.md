# 准备涉案企业合规整改与验收

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《民法通则》《民法总则》或其解释当作现行规则。不得把 1979 年刑法第六十七条缓刑条款当现行自首规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成涉案企业合规材料包：验收闸、适用接口、针对涉案原因的 `P#` 计划、第三方机制对接与回避、验收证据对照。不辩护个人刑事责任，不保证不起诉、撤销案件、缓刑或免罚，不把企业合规材料写成自首已成立。无验收证据不得写已通过。不执行发送，不代提交，不倒签。

`depends-on` 为空。无检察程序的内部整改转 `准备合规整改方案`。调查结论转 `形成内部调查报告`。市监等行政自查转 `准备主动披露或自查报告`。跟踪已列动作转 `跟踪整改验收与复发监测`。个人辩护、取保、量刑转刑事领域。

## 工作边界

正触发：检察机关提出或企业拟申请进入企业合规第三方监督评估，或需要提交合规计划／验收材料。机制文件未核验、第三方未选任、证据未齐仍正触发：验收闸关闭，不出验收终稿，窗口不关。用户要保证不起诉、撤销案件或免于处罚、把规范文件未核验写成法定必然适用、今天必须过验收、把计划写成已通过、把合规材料写成自首已成立、选定某检察院，仍正触发：对应格填 `现有依据不支持` 或字段停止，闸未开则不出验收终稿，窗口不关。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是无检察程序的普通内部整改方案（转 `准备合规整改方案`）；
- 主成果是内部调查报告（转 `形成内部调查报告`）；
- 主成果是向市监等行政机关自查、无检察程序（转 `准备主动披露或自查报告`）；
- 主成果是跟踪已列动作的验收与复发监测（转 `跟踪整改验收与复发监测`）；
- 主成果是犯罪嫌疑人辩护、取保、量刑意见或阅卷（转刑事领域）。

双方秘密、伪造整改或验收证据、利诱评估人员、设计评估走过场、隐瞒未改项、倒签验收日**不在负触发表**，走整体停止。「保证不起诉」「法定必然适用」「今天必须过验收」**不在负触发表**，只关对应格，窗口不关。

## 建立工作坐标

确认：使用者与授权；单方立场（企业；自然人辩护不在本窗）；企业是否涉案；个人与企业责任是否分离；检察阶段；是否已启动第三方机制；已有整改动作；机制文件是否已核验。

口头「已经过了」「检察说没问题」「微信已读」只登记 `S#`／`V#`。不得升格已通过验收、已不起诉或自首已成立。

同时掌握企业与自然人犯罪嫌疑人相互冲突的秘密，或两造争同一份验收稿：`整体停止`，不得以选边治愈，也不得改走负触发，不得问代表哪一方后继续。企业已开口且委托范围就是企业合规材料、且未掌握自然人秘密时，可推定企业立场。提出伪造整改证据、利诱评估人员、走过场脚本、隐瞒未改项、倒签：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 检察或生效文书；`C#` 制度或承诺；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`N#` 计划封面草稿；`Q#` 路径接口；`V#` 版本；`E#` 验收证据回链；`P#` 计划项。禁止 `Dsc#`。`E#` 不是案卷编目、不是到达回证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。计划状态只用 `草案`、`待核`、`可验证`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。禁止「必然不起诉」「依法应当适用本机制」「已通过验收」「自首已成立」「此致某检察院」。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：最高人民检察院《关于建立涉案企业合规第三方监督评估机制的指导意见（试行）》及《涉案企业合规建设、评估和审查办法（试行）》的**名称、文号、效力、施行日和适用范围**；未检出则适用与验收法律结论字段停止，仍可整理已有整改事实并标明「机制条款待核」。禁止编造条号或文号。机制由人民检察院在办理涉企犯罪案件时启动，结果是依法处理案件的重要参考，**不是必然不起诉**。人民检察院刑事诉讼规则（2019）第三百三十九条：审查后应当依法作出起诉或者不起诉决定，本窗不得预测该决定。刑事诉讼法不起诉类型（法定／相对／存疑等，条号运行时核验）不等于合规改革必然不起诉；企业交计划不等于第十六条或相对不起诉已成立。刑法（2023 修正）第六十七条自首：自动投案并如实供述；**企业提交合规整改材料不等于自首已成立**。1979 年刑法第六十七条缓刑条款是噪声。行政处罚法（2021 修订）第三十二条应当从轻的条件须另核，**提交合规计划本身不等于危害后果已消除或已获从轻**。42 号令整改条款不是检察合规机制，不得套用为「依法应当进入第三方评估」。噪声：把计划写成已通过、把合规材料当自首、保证不起诉、编造指导意见条号、42 号令当检察合规、未知写零。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变适用条件、第三方选任或验收效果的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补虚假合规、计划须针对涉案原因、第三方不得走过场、小微企业可由检察院直接审查计划与整改报告、单位自首效力不及当然及于个人的反例。
- `search_template` 只借合规计划或验收对照栏目，不把范本当法定格式、已通过验收或不起诉保证。

工具不可用时继续已有整改事实、计划缺口和回避清单；适用、验收、从宽字段停止。不得拒跑，不得凭记忆写成依法应当适用或必然不起诉。

## 判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、验收闸与不关窗

主成果才整案转出。审查起诉阶段本身不整案转刑事。伪造证据、利诱评估、双方秘密第一次停。保证不起诉、法定必然适用、今天必须过验收不关窗。闸关仍交十节，第 6 节不出 `P#` 计划终稿。

### 2. 适用接口与文件核验

机制文件未核验不得写依法应当适用。个人犯罪与企业责任分列。无检察程序走普通整改。

### 3. 验收闸与路径 `Q#`

本节禁止出 `P#` 计划终稿。文件未核验或无一可回链计划／证据则闸关闭，窗口不关。`Q-刑` 只打红旗。

### 4. 针对原因的计划 `P#` 与验收证据

计划必须回链涉案业务、决策链、资金和监督失效点。复制通用合规章程而不针对原因：退回重写。无验收证据不得写已通过。

### 5. 第三方、回避与不得承诺

评估人与企业、被害人、承办律师有利害关系：回避。不得设计走过场脚本。禁止预测检察决定。自然人辩护转刑事。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；伪造整改或验收证据；利诱评估人员；设计评估走过场；隐瞒未改项；倒签验收日。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：机制文件、适用条件、第三方选任、验收标准未核验。保证不起诉、法定必然适用、今天必须过验收、合规即自首、选定某检察院：该格停止，窗口不关；闸未开仍不出验收终稿。
- `目标停止`：主目标变为个人辩护或无检察程序的普通整改。

禁止指导伪造、利诱或走过场。不给胜诉率。不保证不起诉。不定罪。不选定检察院。不代提交。未知不写零。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。验收闸关闭或不关窗信号仍交十节；第 6 节不出 `P#` 计划终稿。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。验收闸未打开时不得交付计划终稿或「必然不起诉」。边界见 [路由](references/routing.md)。
