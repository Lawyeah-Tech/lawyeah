# 准备涉案企业合规整改与验收

## 任务目标

在明确、无利益冲突的单方立场下（企业，互斥；自然人犯罪嫌疑人不得用本窗出对自己有利的「已从宽」稿），形成检察合规计划与验收对照草案：验收闸、`Q#` 路径、`YA#` 验收行（计划切片须回链涉案原因／责任人与时点／验收证据形态／第三方与回避／打开接口／`E#` 回链）。本窗 `YA#` 是验收行草案，不是已通过，不是必然不起诉，不是普通整改终稿，不是岗位行，不是监测闭合，不是披露发送稿，不是个人辩护。本窗闸名只能是验收闸，禁止复用整改闸、检查闸、监测闸、评估闸、合规闸、启动闸、持有闸、披露闸、建卷闸、报告闸、监察闸、交卷闸、预案闸、应对闸、配置闸。预留不得占用：立案闸、调查闸。本窗主行只能是 `YA#`，禁止 `P#`、`N#`、`A#`、`K#`、`YS#`、`ZG#`、`XR#`、`YG#`、`MO#`、`GT#`、`F#`、`ACT#`。主路径只用 `Q-验`，禁止用 `Q-检`、`Q-检合`、`Q-整改`、`Q-监`、`Q-风`、`Q-启`、`Q-认定`、`Q-总`、`Q-合` 作主路径。邻窗 `Q-验` 只作转介进本窗；本窗打开为主路径，不是已通过、不是必然不起诉。验收闸打开不等于已通过第三方评估不等于必然不起诉不等于自首已成立不等于机关已验收不等于待提交。计划不是已完成。交计划不是不起诉。交计划不是行政处罚法第三十二条从轻已成就。企业交合规材料不是刑法第六十七条自首已成立，不是单位自首效力当然及于个人。复制通用合规章程不是计划。仅有制度缺口不得开验收闸。企业自聘律师或内部监察不是管委会选任的第三方。42 号令不是检察合规机制。小微企业由检察院直接审查只开接口，不是已替代第三方，不是已从宽。无 `E#` 不得写 `可验证` 以上。`可验证` 不等于已通过。口头「已经过了」不是已验收。未知不写零。不定罪。不保证不起诉。不执行发送。不代提交。不选定检察院。不写唯一法定截止日。不编造指导意见或建设评估审查办法条号。

`depends-on` 为空。无检察程序的内部整改转 `准备合规整改方案`。调查结论转 `形成内部调查报告`。市监等行政自查转 `准备主动披露或自查报告`。跟踪已列动作转 `跟踪整改验收与复发监测`。现场检查转 `应对监管检查或突击检查`。内部独立监察转 `设置合规监管人或独立监察`。个人辩护、取保、量刑转刑事领域。英文 id `prepare-prosecutorial-compliance` 禁止使用，一律用中文技能名。

## 工作边界

正触发：检察机关提出或企业拟申请进入企业合规第三方监督评估，或单位未作被告但检察院对企业启动合规，主成果是针对涉案原因的计划与验收对照。机制文件未核验、第三方未选任、证据未齐仍正触发：验收闸部分打开，对应格待核，仍交十节。复制通用章程、无一可回链涉案原因才关闸，仍交十节，第 6 节不出 `YA#` 终稿，窗口不关。用户要保证不起诉、撤销案件、不批捕、从宽量刑或免罚、把文件未核验写成法定必然适用、今天必须过验收、把计划写成已通过、把合规材料写成自首已成立、选定某检察院、小微未请第三方即已从宽、42 号令应当进入第三方，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `YA#` 草案。不得因「不定罪」「不保证不起诉」「不代提交」改走负触发关窗。利益冲突未解不是整体停止。无书面材料授权但单方立场已闭合且已有检察触点或原因碎片：验收闸部分打开，仍交十节，不是整体停止。口头「已经过了」「检察说没问题」不得单独算作开闸材料。无检察程序且主成果是内部整改：负触发，不借闸关留本窗十节壳。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是无检察程序的普通内部整改方案（转 `准备合规整改方案`）；
- 主成果是内部调查报告（转 `形成内部调查报告`）；
- 主成果是向市监等行政机关自查、无检察程序（转 `准备主动披露或自查报告`）；
- 主成果是跟踪已列动作的验收与复发监测（转 `跟踪整改验收与复发监测`）；
- 主成果是检查或突击检查现场应对（转 `应对监管检查或突击检查`）；
- 主成果是内部独立监察或监管人人选（转 `设置合规监管人或独立监察`）；
- 主成果是三道防线岗位配置（转 `配置合规机构与三道防线`）；
- 主成果是犯罪嫌疑人辩护、取保、量刑意见或阅卷（转刑事领域）。

双方秘密、伪造整改或验收证据、利诱评估人员（含直接付费、宴请、许诺事后顾问）、设计评估走过场、隐瞒未改项、倒签验收日、指导拒不向第三方或检察院报告新罪**不在负触发表**，走整体停止。「保证不起诉」「法定必然适用」「今天必须过验收」「合规即自首」**不在负触发表**。「不定罪」「不保证不起诉」「不代提交」是交付禁令，不是负触发。主成果才转；出现「验收」「合规」「不起诉」一词不是转出。审查起诉阶段本身不整案转刑事。

## 建立工作坐标

确认：使用者与授权；单方立场（企业；自然人辩护不在本窗）；企业或与生产经营密切相关的人员是否涉案；个人与企业责任是否分离；检察阶段；是否已启动第三方及是否由管委会选任；已有整改动作；机制文件是否已核验。

口头「已经过了」「检察说没问题」「微信已读」「快递发出」只登记 `S#`／`V#`。不得升格已通过验收、已不起诉或自首已成立，**不得单独算作开闸材料**。可编号、能回链涉案原因的计划或证据碎片可开闸。本窗不执行发送，不代提交，不定罪，不保证不起诉。

立场只许企业出稿。自然人犯罪嫌疑人不得用本窗出对自己有利的「已从宽」稿。同时掌握企业与自然人相互冲突的秘密，或两造争同一份验收稿：`整体停止`，不得选边，不得问代表哪一方后继续。无一可回链涉案原因：验收闸关闭，仍交十节，不是整体停止。提出伪造证据、利诱评估、走过场、隐瞒未改、倒签：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。评估人应回避未回避：该格不支持或闸半开，不是整体停止。开口不等于立场闭合。无检察文书 `R#` 不得写机关名称，只写类型。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 检察或生效文书；`C#` 制度或承诺；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`YA#` 验收行；`V#` 版本；`E#` 验收证据回链（不是已通过证明）。承认只进 `S#`／`D#`，不得占用 `A#`。禁止 `N#`、`A#`、`P#`、`K#`、`YS#`、`ZG#` 作主行。技能正文中的条号是检索锚点，不是已核验 `L#`。稿件状态默认 `草案`。计划状态只用 `草案`、`待核`、`可验证`、`停止`。无 `E#` 不得写 `可验证` 以上。未知不写零。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。考察材料 ≠ 应当不起诉。交计划 ≠ 自首。复制章程 ≠ 计划。42 号令 ≠ 检察机制。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或文书范本检索。本窗是准备计划表，`search_template` 只借合规计划／验收对照栏目，**不要**把范本升格为法定格式、已通过验收、不起诉保证或 `YA#` 终稿。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现计划未针对涉案原因、验收写成不起诉、走过场的反例。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把 1979 年刑法第六十七条缓刑、1996／2017 年行政处罚法第三十二条陈述申辩、42 号令整改条款当作检察合规机制。禁止编造指导意见或建设评估审查办法条号。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的适用、验收、从宽或期限保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：最高人民检察院《关于建立涉案企业合规第三方监督评估机制的指导意见（试行）》及《涉案企业合规建设、评估和审查办法（试行）》的名称、文号、效力、施行日和适用范围；未检出则适用与验收法律结论字段停止，仍可整理已有整改事实并标明「机制条款待核」。禁止编造条号或文号。机制由人民检察院在办理涉企犯罪案件时启动，结果是依法处理案件的重要参考，**不是必然不起诉**。人民检察院刑事诉讼规则（2019）第三百三十九条：审查后应当依法作出起诉或者不起诉决定，本窗不得预测该决定。刑法（2023 修正）第六十七条自首：自动投案并如实供述；**企业提交合规整改材料不等于自首已成立**。噪声：1979 年刑法第六十七条缓刑。行政处罚法（2021）第三十二条应当从轻的条件须另核，**提交合规计划本身不等于危害后果已消除或已获从轻**。噪声：1996／2017 年第三十二条陈述申辩。42 号令整改条款不是检察合规机制。小微企业未启动第三方时检察院可直接审查计划与整改报告，出处是建设评估审查办法，未核验不得编条号，只开接口。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变适用条件、第三方选任或验收效果的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补虚假合规、计划须针对涉案原因、第三方不得走过场、小微直接审查不是已从宽、单位自首效力不及当然及于个人的反例。
- `search_template` 只借合规计划或验收对照栏目。禁止升格法定格式、已通过验收、不起诉保证或 `YA#` 终稿。

工具不可用时继续 `YA#` 与缺口；适用、验收、从宽、期限字段停止。不得拒跑，不得凭记忆写成依法应当适用或必然不起诉。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、验收闸与不关窗

主成果才整案转出。审查起诉阶段本身不整案转刑事。伪造、利诱、双方秘密第一次停。保证不起诉、法定必然适用、今天必须过验收不关窗。闸关仍交十节，第 6 节不出 `YA#` 终稿。利益冲突未解不是整体停止。禁止把整改闸、检查闸、监测闸写进本窗节点 0。无检察程序内部整改：负触发整改窗。夹带保证不起诉留本窗，对应格不支持。

### 2. 适用接口与文件核验

机制文件未核验不得写依法应当适用，对应格字段停止或闸半开，不是关闸。个人犯罪与企业责任分列。无检察程序走普通整改。本节禁止出 `YA#` 终稿。

### 3. 验收闸与路径 `Q#`

本节禁止出 `YA#` 终稿。有可回链涉案原因碎片：闸打开或半开。主路径只用 `Q-验`。`Q-检`、`Q-检合`、`Q-整改`、`Q-监` 不得升主路径。

### 4. 验收行 `YA#`

每一条必须回链涉案业务、决策链、资金或监督失效。复制通用章程：关闸，不出 `YA#` 终稿，窗口不关。无 `E#` 不得写 `可验证` 以上。状态 `草案`。`可验证` 不等于已通过。

### 5. 第三方、回避与不得承诺

评估人与企业、被害人、承办律师有利害关系：该格不支持或须回避，不是整体停止。不得设计走过场。禁止预测检察决定。自然人辩护转刑事。第 7 节不得夹带 `YA#` 终稿绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；两造争同一份验收稿；伪造整改或验收证据；利诱评估人员；设计评估走过场；隐瞒未改项；倒签验收日；指导拒不报告新罪。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可回链涉案原因：验收闸关闭，仍交十节，不是整体停止。无书面授权但有碎片：验收闸部分打开，不是整体停止。利益冲突未解：不是整体停止。应回避未回避：该格不支持，不是整体停止。复制章程：关闸不关窗；同时要求伪造验收则整体停止。
- `字段停止`：机制文件、适用条件、第三方选任、验收标准、施行日未核验。保证不起诉、法定必然适用、今天必须过验收、合规即自首、选定某检察院、小微即已从宽、42 号令即检察机制：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `YA#` 草案。
- `目标停止`：主目标变为个人辩护或无检察程序的普通整改。禁止把「保证不起诉」当作用户错误主张时的目标停止；那是不关窗。

禁止指导伪造、利诱或走过场。不给胜诉率。不保证不起诉。不定罪。不选定检察院。不代提交。未知不写零。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。验收闸关闭仍交十节，第 6 节不出 `YA#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `YA#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。验收闸未打开时不得交付计划终稿或「必然不起诉」。边界见 [路由](references/routing.md)。
