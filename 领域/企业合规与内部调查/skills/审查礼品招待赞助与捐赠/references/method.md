# 审查方法

本文件是可执行判断节点。小额不是自动允许。节日礼品不是自动合法。临近招标或许可不得标允许。已报销不是已合法。口头点头不是已批准。赞助冠名不是捐赠。捐赠收据不是税前扣除已成就。审批盖章不是已合法。允许不是已合法终局。明示折扣佣金如实入账不是贿赂，入账不是合法闭集。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。三态结论只用 `允许`、`禁止`、`待核`。禁止胜诉率、必然免责、刑事既遂、选定机关、代提交、代批准、未知写零。本窗不定罪，不写制度终稿，不写风险图终稿，不做出税前扣除结论。本窗 `GF#` 是单笔审查行，不是制度行 `GP#`，不是风险点 `BR#`，不是税务包无偿转让事件。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1993 年反不正当竞争法第八条、把小额写成已允许、把 FCPA 写成中国法时记为噪声。禁止指导补假批准、账外路径或行贿步骤。禁止 `search_template` 生成已允许清单或已合法证明。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现给付扫描，不是默认闭集。
`GF#` 固定列：`编号｜类型（礼品／招待／赞助／捐赠）｜受益人身份｜形态｜时点窗口｜入账三态（明示入账／未入账或账外／待核）｜审批留痕｜三态结论（允许／禁止／待核）｜E#回链｜判断三值｜G#｜最强反方｜状态`。入账三态里，明示入账 ≠ 已合法；未入账或账外 ≠ 已贿赂。允许 ≠ 已合法 ≠ 已合规 ≠ 已批准。禁止 ≠ 已贿赂 ≠ 已定罪。无 `E#` 不得写已覆盖、已允许、已合法。`E#` 只作证据形态回链。开口径无留痕例外：该行删除或该例外字段停止。缺项记 `G#`。扫描不是闭集。状态默认 `草案`。

口头「小额即合法」「节日都这样」「老板点头了」「已经报销了所以合法」只进 `S#`／`V#`，**不得单独算作开闸材料**。报销单能开闸，不能升格已合法。审批盖章不是已合法。捐赠收据不是税前扣除已成就。聊天「领导点头」截图仍只是 `S#`／`D#`。`A#` 是承认该笔存在或已付，不是已允许。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

## 节点 0　分流、立场、审查闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、指导补假批准、指导账外或行贿、伪造发票或账册、倒签批准、指导删除、打击报复、阻挠检查不进负表。

整案转出只交付第 1、2、10 节，不出 `GF#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是礼品招待制度终稿 | 负触发 `设计反商业贿赂与礼品招待制度` |
| 主成果是廉洁风险图 | 负触发 `评估反商业贿赂风险点` |
| 主成果是回扣账外资金链路终稿 | 负触发 `评估回扣账外暗中与资金链路` |
| 主成果是公职接触点总图 | 负触发 `梳理公职人员接触点与审批` |
| 主成果是非调查关联交易廉洁评估 | 负触发 `评估利益冲突与关联交易廉洁面` |
| 主成果是虚假报销终稿 | 负触发 `评估账簿记录与虚假报销` |
| 主成果是中间人费用终稿 | 负触发 `评估中间人费用与资金链路` |
| 主成果是销售激励与渠道返点终稿 | 负触发 `评估销售激励与渠道返点廉洁风险` |
| 主成果是捐赠税前扣除或慈善税务实体 | 整案转税务 |
| 主成果是是否启动内部调查 | 负触发 `评估是否启动内部调查` |
| 主成果是调查报告终稿 | 负触发 `形成内部调查报告` |
| 主成果是药品购销回扣行业细则 | 整案转医疗 |
| 主成果是刑事辩护、控告或自首 | 整案转刑事 |
| 主成果是劳动解除或处分决定 | 整案转劳动 |
| 「不保证小额即合法」「不定行贿罪」「不代做税务扣除」 | 交付禁令，不是负触发 |

审查起诉、监管检查、已立案只作程序背景。主成果才整案转。出现「礼品」「捐赠」「税务」一词不是转出。

审查闸打开（可出 `GF#` 草案，仍不得标「已允许／已合法／已定罪」）须同时满足：单方无冲突公司立场已闭合；主成果是单笔或一批审查，不是制度、风险图或税务实体；至少一条可编号给付碎片。发票、审批单、会议纪要（点名该笔）、聊天记录（对象／金额／时点可识别）、银行回单、报销单、赞助协议、捐赠协议或捐赠收据可编号开闸。口头「小额即合法」「节日都这样」「老板点头了」「已经报销了所以合法」不算单独开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

审查闸部分打开：已有可编号给付碎片，但授权、身份、入账、时点、审批未闭合；或无书面审查授权但已有件。对应格待核；仍交十节；不得标终稿 `已形成`。

审查闸关闭（仍正触发）：无一可编号给付碎片。「今天必须出允许终稿」而无最小件不得开闸。不出 `GF#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `GF#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关写成「没有问题」或「已合规」。

「小额一律合法」「节日礼品自动合法」「行业惯例即合法」「已报销即合法」「口头同意即已批准」「公益捐赠一律合法」「赞助即市场费用当然合法」「低于阈值即合法」「入账即合法闭集」「审批盖章即已合法」「捐赠收据即税前扣除已成就」「允许即已合规」「交表即从轻或自首」「民企必须按 42 号令第十八条专项或本笔已合规」「FCPA 即中国法已允许」「本表已定罪」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `GF#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无一可编号给付碎片，then 审查闸关闭，仍交十节，不是整体停止。
若 if 单方立场已闭合、无书面授权但已有可编号件，then 审查闸部分打开，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象或相对方相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出指导补假批准、指导账外或行贿、伪造发票或账册、倒签批准、指导删除、打击报复、阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体、给付碎片与强制接口

一行一个给付件。缺项记 `G#`，未知金额不得写 `0`。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 主体 | 经营者／工作人员；民企／国家出资公司／上市 | 民企必须按 42 号令第十八条专项 |
| 类型 | 礼品／招待／赞助／捐赠，分列 | 赞助写成捐赠 |
| 受益人 | 公职／国有单位人员／交易决策人／纯商业相对方／待核 | 身份不明标允许 |
| 形态 | 现金／卡／实物／宴请旅游娱乐／冠名／捐款等 | 形态不明写零 |
| 时点 | 临近招标评标许可续约／非窗口／待核 | 窗口内标允许 |
| 入账 | 明示入账／未入账或账外／待核 | 已报销即已入账合法 |
| 审批 | 书面／口头或无／待核 | 口头即已批准 |
| 施行日 | 行为时点相对 2025-10-15 | 跨日用唯一条文 |

检索锚点（写入 `L#` 前须核验）：反不正当竞争法（2025）第八条，施行日 2025-10-15；明示折扣、向中间人支付佣金可以，双方应当如实入账；入账不是礼品合法闭集。噪声：1993 年第八条。1996 暂行规定第八条小额广告礼品除外不是空白支票。公职人员政务处分法第三十四条只开公职受礼接口，不定罪。公益事业捐赠法第四条不得以捐赠为名从事营利活动。企业所得税法第九条只开税务接口。刑法第一百六十三条／第一百六十四条／第三百八十五条／第三百八十九条／第三百九十一条／第三百九十三条只作红旗，不定罪。公司法第一百八十条不等于该笔已回避或已批准。行政处罚法第三十二条交审查表 ≠ 从轻。刑法第六十七条交表 ≠ 自首。监察法第十八条不得伪造隐匿。刑法第一百六十二条之一、第三百零七条、第三百零八条只作红旗，不得指导删除。42 号令只约束中央企业。FCPA／英国反贿赂法不是中国法义务。本节禁止出 `GF#` 终稿。

## 节点 3　审查行 `GF#`

按已出现给付扫描，不是默认闭集。建议行型（出现才用）：

| 编号 | 含义 | 本窗允许 | 禁止 |
| --- | --- | --- | --- |
| `GF-礼` | 礼品 | 审查行草案 | 小额即允许；节日即合法 |
| `GF-招` | 招待 | 审查行草案 | 指向审批人的旅游标允许 |
| `GF-赞` | 赞助 | 形态分列；对价可见 | 冠名写成捐赠 |
| `GF-捐` | 捐赠 | 自愿无偿待核 | 假捐赠回流标允许；收据即税扣 |
| `GF-公` | 公职受益人 | 只开接口 | 见过官员即行贿；身份不明标允许 |
| `GF-窗` | 时点窗口 | 窗口内允许路径不打开 | 已入账即可允许 |
| `GF-账` | 入账分账 | 三态并列 | 账外即已贿赂；明示入账即已合法 |
| `GF-批` | 审批留痕 | 书面／口头或无／待核 | 口头即已批准；开口径无留痕仍标允许 |

热冲突强制处理：

- 小额一律合法／节日自动合法／行业惯例即合法／已报销即合法／口头即已批准／低于阈值即合法／入账即合法闭集／赞助即捐赠／公益捐赠一律合法 → 该格不支持；仍出其他 `GF#`。
- 现金、等价物、假发票、指向决策人的旅游 → 禁止。
- 购物卡、个人微信、第三方代付、个人垫付未入账 → 入账三态 ≠ 明示入账；不支持允许。
- 临近招标／评标／许可／续约 → 允许路径不打开。
- 赞助实为对价／假捐赠回流 → 形态不得改捐赠；常转回扣或调查接口。
- 中间人代送礼 → 不支持允许；转中间人费用窗。
- 开口径无留痕例外 → 该行删除或该例外字段停止。
- 已发生禁止或待核 → 转介补证／追偿／调查，不得倒签批准、不得补假发票。后补真件只登记 `D#`／`E#`，三态仍按发生时点判断。
- 指导补假批准、伪造入账或双方秘密 → 整体停止，不是该格不支持。

无 `E#` 不得写已覆盖、已允许或已合法。状态 `草案`。一次只推荐下一步。

## 节点 4　入账、公职、税务接口、禁止文书与转介

第 7 节只开接口，不得夹带 `GF#` 终稿绕闸。闸关闭时第 7 节可写「闸未开，转介待给付编号」，不得补写已允许。

不写制度全文、风险图终稿、回扣账外专项终稿、税前扣除结论、刑事文书、启动闸。不可逆（对外宣称该笔已合法、向监管正式报告已无问题、签署虚假入账、倒签批准）不得在草案阶段实施。禁止提交指令。不代提交。不代批准。不选定机关。

已发生禁止或待核转介：是否调查 → `评估是否启动内部调查`；假票／假报销 → `评估账簿记录与虚假报销`；账外资金 → `评估回扣账外暗中与资金链路`；追偿测算 → `测算舞弊损失与追偿`；禁毁保全 → `准备证据保全与禁毁通知`。转介最低程序：保全原件与电子痕迹；停止继续给付；利益冲突人退出该笔后续审批（公司法 180 只开接口 ≠ 已回避）。

下一步只转介：`设计反商业贿赂与礼品招待制度`、`评估反商业贿赂风险点`、`评估回扣账外暗中与资金链路`、`评估销售激励与渠道返点廉洁风险`、`评估中间人费用与资金链路`、`评估利益冲突与关联交易廉洁面`、`梳理公职人员接触点与审批`、`评估账簿记录与虚假报销`、`评估是否启动内部调查`、`评估调查后处置路径`、`形成内部调查报告`、`设计第三方合规管理机制`、税务领域。

若 if 用户催促「按零写／填满已允许终稿」，then 该格 `现有依据不支持`，窗口不关。
若 if 金额未知，then 写 `未知`／`G#`，禁止写 `0`。
