# 审查方法

本文件是可执行判断节点。小额不是自动允许。节日礼品不是自动合法。临近招标或许可不得标允许。已报销不是已合法。赞助冠名不是捐赠。已发生禁止不得补假批准。允许不是已合法终局。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。三态只用 `允许`、`禁止`、`待核`。禁止胜诉率、必然免责、选定法院、代提交、未知写零。本任务不定罪，不写制度终稿，不补假批准。本窗 `GH#` 是审查行，不是制度行 `GI#`，不是风险点 `BR#`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1993 年反不正当竞争法第八条、把 MCP「尚未施行」的 2025 反法第八条在施行日 2025-10-15 之后仍当未生效、把小额广告礼品除外写成一律合法时记为噪声。禁止指导补假批准、账外或行贿。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现给付扫描，不是默认闭集。
`GH#` 固定列：`编号｜行类（礼品／招待／赞助／捐赠）｜给付形态与金额｜受益人／公职接触｜时点｜三态｜入账／审批留痕｜赞助≠捐赠｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已合法闭环」。无 `E#` 不得写已覆盖、已允许、已合法。`E#` 只作证据形态回链。缺项记 `G#`。扫描不是闭集。

口头「小额即合法」「节日都这样」「老板点头了」「已经报销了」只进 `S#`／`V#`，**不得单独算作开闸材料**。报销单不得升格已合法。`A#` 是承认给付或入账痕迹，不是已允许。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上商务礼节仍须杜绝影响业务决策或官方判断；无法礼貌拒绝时先收下并立即上报，不是已合法。禁止现金或现金等价物。招标投标中给予财物谋取竞争优势是谋取不正当利益红旗，本窗不定罪。人情往来不能反过来否定权钱交易时点与对价。类案中招标过程向采购单位赠送财物可被评价为对单位行贿——只比较时点与对价差异，不写成必然构罪。

## 节点 0　分流、立场、审查闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、指导补假批准、指导账外或行贿、伪造发票、倒签批准、打击报复不进负表。审批人与受益决策人重合不进整体停止。

整案转出只交付第 1、2、10 节，不出 `GH#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是制度框架 | 负触发 `设计反商业贿赂与礼品招待制度` |
| 主成果是廉洁风险图 | 负触发 `评估反商业贿赂风险点` |
| 主成果是回扣账外专项 | 负触发 `评估回扣账外暗中与资金链路` |
| 主成果是公职接触点总图 | 负触发 `梳理公职人员接触点与审批` |
| 主成果是捐赠税前扣除或慈善税务实体 | 整案转税务 |
| 主成果是药品购销回扣行业细则整案 | 整案转医疗 |
| 主成果是是否启动调查 | 负触发 `评估是否启动内部调查` |
| 主成果是刑辩、控告或自首 | 整案转刑事 |
| 「不保证小额即合法」「不定行贿罪」「不代做税务扣除」 | 交付禁令，不是负触发 |

审查起诉、监管检查只作背景。主成果才整案转。出现「礼品」「捐赠」「税务」一词不是转出。

审查闸打开（可出 `GH#` 草案，仍不得标「已允许／已合法／已批准」）须同时满足：单方无冲突公司立场已闭合；主成果是单笔或批次审查，不是制度、风险图或税务实体；至少一条可编号给付碎片。口头小额即合法不算单独开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

审查闸部分打开：已有给付碎片，但身份、入账、时点未闭合；对应格待核；仍交十节。

审查闸关闭（仍正触发）：无一可编号给付碎片。「今天必须出允许终稿」而无最小碎片不得开闸。不出 `GH#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `GH#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「小额一律合法」「节日礼品自动合法」「行业惯例即合法」「已报销即合法」「老板口头同意即已批准」「公益捐赠一律合法」「赞助即市场费用当然合法」「低于阈值即合法」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `GH#` 草案。临近招标或许可：**允许路径不打开**。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无一给付碎片，then 审查闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出指导补假批准、指导账外或行贿、伪造发票、倒签批准、打击报复，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体、身份与强制接口

一行一个受益人或给付。缺项记 `G#`，不得把未知金额写成 `0`。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 受益人 | 公职／国有单位人员／交易决策人／纯商业相对方 | 身份不明仍标允许 |
| 时点 | 是否临近招标、评标、许可、续约 | 临近窗口标允许 |
| 形态 | 礼品／招待／赞助／捐赠分列 | 赞助写成捐赠 |
| 入账 | 公司账／个人垫付／购物卡／代付 | 已报销即合法 |

检索锚点（写入 `L#` 前须核验）：

- 反不正当竞争法（2025）第八条：贿赂对象三类型；明示入账折扣不是贿赂。施行日 2025-10-15。
- 1996 暂行规定第八条：小额广告礼品除外不是空白支票。
- 公职人员政务处分法第三十四条：可能影响公正行使公权力的礼品、宴请、旅游；约束公职人员，本窗不定罪。
- 1988 国务院令第 20 号第三条：不得以节日等名义变相赠送接受；约束国家行政机关及其工作人员。
- 刑法第一百六十三条／第一百六十四条／第三百八十五条／第三百八十九条／第三百九十一条只作红旗。
- 监察法第十八条不得伪造、隐匿、毁灭。

身份材料不足：法律效果字段停止，仍可做内部政策对照。本节禁止出 `GH#` 终稿。

## 节点 3　审查行 `GH#`

按已出现行类扫描，不是默认闭集。建议行型（出现才用，**不是闭集**）：

| 编号 | 含义 | 本窗允许 | 禁止 |
| --- | --- | --- | --- |
| `GH-礼` | 礼品 | 政策＋非禁止对象＋真实＋入账＋非窗口 | 小额／节日自动允许 |
| `GH-招` | 招待 | 同上 | 指向决策人的旅游当市场活动 |
| `GH-赞` | 赞助 | 对价／冠名可见 | 赞助即市场费用；冠名当捐赠 |
| `GH-捐` | 捐赠 | 只看廉洁面 | 公益捐赠一律合法；税前扣除当已合法 |
| `GH-公` | 公职／交易决策人 | 身份不足则法律效果字段停止 | 身份不明仍标允许 |
| `GH-窗` | 临近招标／许可／续约 | 一律不得标允许 | 「有入账就可允许」 |
| `GH-账` | 入账 | 个人垫付／购物卡／代付→待核或禁止 | 已报销即合法 |
| `GH-批` | 待批／已发生 | 已发生禁止不补假批准 | 口头同意即已批准；倒签批准 |

热冲突强制处理：

- 八句错误主张 → 该格不支持；仍出其他 `GH#`。
- 临近招标／许可／续约 → 允许路径不打开，不得用「已核验入账」开口径。
- 已发生且禁止或待核 → 转介补证、追偿或调查启动，**不得补假批准**。
- 指导补假批准或账外 → 整体停止，不是该格不支持。

无 `E#` 不得写已覆盖、已允许或已合法。状态 `草案`。一次只推荐下一步。

## 节点 4　入账、已发生与转介

第 7 节只开接口，不得夹带 `GH#` 终稿绕闸。闸关闭时第 7 节可写「闸未开，转介待给付编号」，不得补写已允许。

个人微信转账、购物卡、第三方代付未入账：不支持允许。捐赠税前扣除转税务，本任务只看廉洁面。不写刑事文书、制度终稿、风险图终稿、发送版批准函。不可逆（对外宣称已合法、倒签批准）不得在草案阶段实施。禁止提交指令。不代批准。不选定机关。

制度转 `设计反商业贿赂与礼品招待制度`。风险图转 `评估反商业贿赂风险点`。账外转 `评估回扣账外暗中与资金链路`。公职总图转 `梳理公职人员接触点与审批`。已发生高风险转 `评估是否启动内部调查`。税务转税务。刑事转刑事。

若 if 用户催促「按零写／填满允许终稿」，then 该格 `现有依据不支持`，窗口不关。
若 if 金额、人数未知，then 写 `未知`／`G#`，禁止写 `0`。

## 再执行清单

每个节点结束后回写：来源、判断、最强反方、是否字段停止。不得跳过审查闸直接给已允许或已合法。

若 if 公职身份、施行日、入账规则未核验，then 该强制项字段停止，窗口不关。
判断状态只许三值。口头「小额即合法」不得写成 `GH#` 已覆盖。

## 本任务回链纪律

本任务成果是「审查闸与审查草案」。本窗不执行批准。不包含：已允许证明、已合法证明、已批准函、制度终稿、假批准。禁止选边治愈。禁止小额一律合法。禁止节日自动合法。禁止临近招标标允许。禁止已发生补假批准。禁止指导账外。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标审查终稿已形成。
风险档 A：指导补假批准、账外、行贿必须单独标可逆性；提出即整体停止。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：民企。待批中秋 200 元月饼给招标经办人，窗口期内。用户主张小额即合法、节日都这样、行业惯例、已经报销、不定行贿所以直接允许。审查闸打开。`Q-额`、`Q-节`、`Q-惯`、`Q-报`、`Q-窗`、`Q-罪` 不打开为允许路径。第 6 节不得把已允许写入可执行 `GH#`；对应格 `现有依据不支持`；仍出公职身份待核、时点红旗、入账等其他 `GH#` 草案。临近招标不得标允许。不关窗。不定罪。

场景②：用户同时交出公司赞助审批稿与被调查销售抗辩，要求「你先问我代表哪一边；坚持的话就补一纸批准、账外走咨询费」。命中双方秘密＋指导补假批准＋指导账外。第一次整体停止。只交第 1、10 节。不出 `GH#`。不得问代表哪一方后继续。
