# 边界与路由

## 正触发

有可编号的单笔或一批礼品、招待、赞助或捐赠需要允许、禁止或待核判断，而不是写制度终稿、风险图或税务扣除结论。碎片、入账未核验仍正触发：有可编号给付碎片则审查闸开或半开，出 `GF#` 草案。小额一律合法、节日礼品自动合法、行业惯例即合法、已报销即合法、口头同意即已批准、公益捐赠一律合法、赞助即市场费用当然合法、低于阈值即合法、入账即合法闭集、审批盖章即已合法、捐赠收据即税前扣除已成就、允许即已合规、本表已定罪，仍正触发。

双方秘密、指导补假批准、指导账外或行贿、伪造发票或账册、倒签批准、指导删除、打击报复、阻挠合法检查的停止，优先于负触发。上述信号不在下表。「小额一律合法」「节日礼品自动合法」「行业惯例即合法」「已报销即合法」「口头同意即已批准」「公益捐赠一律合法」「赞助即市场费用当然合法」「低于阈值即合法」「入账即合法闭集」「审批盖章即已合法」「捐赠收据即税前扣除已成就」「允许即已合规」「本表已定罪」不在下表。「不保证小额即合法」「不定行贿罪」「不代做税务扣除结论」是交付禁令，不在下表。出现「礼品」「捐赠」「税务」一词不是转出。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 捐赠税前扣除、稽查实体为主成果 | 税务领域 |
| 药品购销回扣行业细则为主成果 | 医疗领域 |
| 劳动合同、解除、工伤主轴且单笔审查不是主成果 | 劳动领域 |

综合单笔审查主轴可留本任务。检查或已立案只作背景，主成果才转。已刑事立案且主成果是刑事程序：整案转刑事。已刑事立案但主成果仍是企业单笔审查：留窗；指导干扰办案或隐匿整体停止。

## 易混

小额不是自动允许。节日礼品不是自动合法。临近招标或许可不得标允许。已报销不是已合法。口头点头不是已批准。赞助冠名不是捐赠。捐赠收据不是税前扣除已成就。审批盖章不是已合法。允许不是已合法终局。明示折扣佣金如实入账不是贿赂。入账不是合法闭集。现金、购物卡、个人微信、第三方代付未入账不支持允许。指向决策人的旅游进禁止。假捐赠回流不是慈善。1988 年国内公务活动礼品规定约束行政机关工作人员，不是民企可送抗辩。1993 年反不正当竞争法第八条不是现行 `L#`。反法 2025 第八条施行日 2025-10-15；MCP 标尚未施行的以施行日为准。阈值不是法定安全港。公司法 180 不是该笔已回避或已批准。政务处分法 34 只开公职接口，不定罪。不定罪、不保证小额即合法、不代做税务扣除是交付禁令，不是负触发。口头「小额即合法」不是开闸材料。可编号给付碎片才开闸。指导补假批准或账外是第一次整体停止，不是不关窗。本窗 `GF#` 不是税务包无偿转让事件。
