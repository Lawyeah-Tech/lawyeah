# 边界与路由

## 正触发

有可编号的单笔或一批礼品、招待、赞助或捐赠需要允许、禁止或待核判断，而不是写制度终稿、风险图或税务扣除结论。身份、入账未核验仍正触发：有可编号给付碎片则闸开或半开，出 `GH#` 草案。小额一律合法、节日自动合法、行业惯例即合法、已报销即合法、口头同意即已批准、公益捐赠一律合法、赞助即市场费用当然合法、低于阈值即合法，仍正触发。

双方秘密、指导补假批准、指导账外或行贿、伪造发票、倒签批准、打击报复的停止，优先于负触发。上述信号不在下表。「小额一律合法」「节日礼品自动合法」「行业惯例即合法」「已报销即合法」「口头同意即已批准」「公益捐赠一律合法」「赞助即市场费用当然合法」「低于阈值即合法」不在下表。「不保证小额即合法」「不定行贿罪」「不代做税务扣除结论」是交付禁令，不在下表。出现「礼品」「捐赠」「税务」一词不是转出。

## 易混

小额不是自动允许。节日礼品不是自动合法。临近招标或许可不得标允许。已报销不是已合法。老板口头同意不是已批准。公益捐赠不是一律合法。赞助冠名不是捐赠定性。允许不是已合法终局。已发生禁止不得补假批准。1996 暂行规定第八条小额广告礼品除外不是空白支票。政务处分法第三十四条约束公职人员，本窗不定罪。不保证小额即合法、不定行贿罪是交付禁令，不是负触发。口头「小额即合法」不是开闸材料。可编号给付碎片才开闸。指导补假批准或账外是第一次整体停止，不是不关窗。
