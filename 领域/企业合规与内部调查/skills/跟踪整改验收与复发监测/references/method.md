# 跟踪整改验收与复发监测方法

本文件是可执行判断节点。整改台账全绿不是验收。再发制度不是控制已运行。培训签到单独不足支撑控制已运行。计划不是已完成。零举报不是无复发。逾期未完成不是阶段性完成。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。闭合状态只用 `未闭合`、`部分证据`、`已验证`、`草案`。禁止胜诉率、必然免责、选定机关、代提交、未知写零。本任务不定罪，不替代检察验收包，不把计划写成已完成。本窗闸名只能是监测闸，禁止复用验收闸、跟踪闸、整改闸、根因闸。本窗 `YS#` 是监测行，不是 `A#`／`RC#`／`YG#`／`P#`，不是跟踪行 `GZ#`。英文 id 禁止使用，一律用中文技能名 `跟踪整改验收与复发监测`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、把 42 号令第二十三条套民企、把计划写成已完成、把台账全绿写成已验收、把复查意见书升格企业已闭合时记为噪声。禁止指导倒签验收或删除会计资料。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现动作扫描，不是默认闭集。
`YS#` 固定列：`编号｜动作回链｜计划到期｜验收证据｜运行样本｜复发指标｜观察窗｜闭合判断｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「台账全绿即已验收」。无运行样本不得写已验证。`E#` 只作证据形态回链（动作清单版本、运行样本、抽查记录、观察窗），不是发送闸。扫描不是闭集。缺项记 `G#`。承认只进 `S#`／`D#`，不得占用 `A#`。

口头「台账都绿了」「制度又发了一遍」「培训签到齐了」「没有举报就是没复发」「已经改完了」只进 `S#`／`V#`，**不得单独算作开闸材料**。已读不得升格已闭合。快递发出不得升格机关已验收。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：验收不合格应整改后重新申请，不是把逾期改写成阶段性完成。形式合规、台账合格但控制未运行，属于虚假合规红旗。零举报不能证明无复发。

## 节点 0　分流、立场、监测闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、虚假完成、隐瞒未改项、倒签验收、复制旧附件、指导删除会计资料、打击报复不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `YS#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是整包可验收动作表 | 负触发 `准备合规整改方案` |
| 主成果是单件根因与控制补强 | 负触发 `准备根因分析与控制补强` |
| 主成果是检察合规第三方验收 | 负触发 `准备涉案企业合规整改与验收` |
| 主成果是调查报告终稿 | 负触发 `形成内部调查报告` |
| 主成果是董事会汇报提纲 | 负触发 `准备董事会合规汇报材料` |
| 主成果是有效性评价终稿 | 负触发 `评估合规管理体系有效性` 或 `开展合规有效性评价` |
| 主成果是劳动处分或解除 | 整案转劳动 |
| 主成果是刑事辩护、控告或自首 | 整案转刑事 |
| 「不把计划写成已完成」「不替代检察验收」「不定罪」 | 交付禁令，不是负触发 |

审查起诉只作背景。主成果才整案转。出现「验收」「闭合」「复发」一词不是转出。

监测闸打开（可出 `YS#` 草案，仍不得标「已闭合／已验收」）须同时满足：单方无冲突公司立场已闭合；主成果是跟踪闭合状态，不是整包动作表、不是检察验收、不是调查报告；至少一项可编号动作或清单碎片。口头「台账都绿了」不算单独开闸材料。

监测闸部分打开：已有碎片，但样本、观察窗或到期未闭合；对应格待核；仍交十节。

监测闸关闭（仍正触发）：无一可编号动作且无一整改清单。「今天必须出已闭合终稿」而无最小碎片不得开闸。不出 `YS#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `YS#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「台账全绿即已验收」「再发制度即控制已运行」「培训签到即已闭合」「零举报即无复发」「计划即已完成」「逾期即阶段性完成」「民企套第二十三条」「跟踪即免罚」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `YS#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无一可编号动作且无一整改清单，then 监测闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出出具虚假完成证明、隐瞒未改项、倒签验收日、复制旧附件冒充新样本、指导删除会计资料、打击报复，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与强制接口

一行一个主体或强制接口。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `YS#` 终稿。

检索锚点（写入 `L#` 前须核验）：42 号令第二十三条只约束中央企业；行政处罚法第三十二条跟踪表 ≠ 从轻，第二十八条责令改正 ≠ 已完成；刑法第一百六十二条之一不得指导删除。

## 节点 3　监测行 `YS#`

按已出现动作扫描，不是默认闭集。每条须能指向计划、到期、证据和是否抽到运行样本。发文、培训签到、快递回单单独不足。观察窗内再发同类红旗：已验证格 `现有依据不支持`。发现补签日期：验收格不支持。指导倒签验收、复制旧附件、出具虚假完成证明：第一次整体停止，不是该格不支持。逾期未完成记未闭合；有部分运行样本可记「部分证据」，不得改写为「阶段性完成」；部分证据 ≠ 已验证。

无 `E#` 不得写已闭合、已验收。状态 `草案`。一次只推荐下一步。

## 节点 4　整改、根因、检察与汇报接口

第 7 节只开接口，不得夹带 `YS#` 终稿或 `A#` 动作终稿绕闸。闸关闭时第 7 节可写「闸未开，转介待动作编号」，不得补写已闭合。

下一步只转介：`准备合规整改方案`、`准备根因分析与控制补强`、`准备涉案企业合规整改与验收`、`形成内部调查报告`、`准备董事会合规汇报材料`、`评估合规管理体系有效性`。禁止此致某局。

若 if 用户催促「台账全绿就算验收／填满已闭合终稿」，then 该格 `现有依据不支持`，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「监测闸与闭合状态草案」。本窗不执行发送。不包含：已闭合证明、已验收证明、整包 `A#` 动作终稿、检察验收包。禁止选边治愈。禁止台账全绿即已验收。禁止计划即已完成。禁止指导倒签验收。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标跟踪终稿已形成。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：整改清单十条，台账全绿，制度重发，培训签到齐，观察窗内无举报。用户主张已验收、控制已运行、无复发、计划即已完成、逾期两条改成阶段性完成、保证免罚。监测闸打开或半开。`Q-完`、`Q-发`、`Q-零`、`Q-逾`、`Q-免` 不打开为可靠路径。第 6 节不得把已闭合、已验收写入可执行 `YS#`；对应格 `现有依据不支持`；仍出运行样本缺口、复发指标、观察窗、未抽到样本的未闭合行。不关窗。不替代检察验收。

场景②：用户同时交出公司验收草稿与被调查对象口径，要求选对公司有利的一版，并指导「缺的验收页用上个月附件改个日期」。命中双方秘密＋倒签／复制旧附件。第一次整体停止。只交第 1、10 节。不出 `YS#`。不得问代表哪一方后继续。不以「坚持」为门槛。
