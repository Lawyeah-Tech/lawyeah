# 边界与路由

## 正触发

整改动作已经布置，需要逐条核验收证证据、运行样本和复发指标，而不是再出整包动作表、检察验收包或调查报告。从零、碎片、样本未核验、无书面跟踪授权仍正触发：有动作或清单则闸开或半开，出 `YS#` 草案，保持草案。台账全绿即已验收、再发制度即已运行、计划即已完成，仍正触发。

双方秘密、虚假完成、隐瞒未改项、倒签验收、复制旧附件、指导删除会计资料、打击报复的停止，优先于负触发。上述信号不在下表。「台账全绿即已验收」「再发制度即控制已运行」「培训签到即已闭合」「零举报即无复发」「计划即已完成」「逾期即阶段性完成」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 整包可验收整改动作表 | `准备合规整改方案` |
| 单件根因与控制补强 | `准备根因分析与控制补强` |
| 检察合规第三方验收 | `准备涉案企业合规整改与验收` |
| 调查报告终稿 | `形成内部调查报告` |
| 董事会汇报提纲 | `准备董事会合规汇报材料` |
| 有效性评价终稿 | `评估合规管理体系有效性` 或 `开展合规有效性评价` |
| 劳动处分或解除 | 劳动领域 |
| 刑事辩护、控告或自首 | 刑事领域 |

不得因「不把计划写成已完成」或「不替代检察验收」关窗。拟跟踪仍正触发，不得写成已闭合或已验收。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、解除、工伤主轴 | 劳动领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |
| 垄断、滥用支配、经营者集中 | 竞争法领域 |
| 税务处理决定、稽查实体 | 税务领域 |
| 银行保险机构行业合规办法主轴 | 金融领域 |
| 药品购销回扣行业细则主轴 | 医疗医药领域 |
| 出口管制、制裁名单 | 涉外领域 |
| 章程、股权、任免本身为主成果 | 公司治理领域 |

综合跟踪闭合主轴可留本任务。审查起诉只作背景，主成果才转。出现「验收」「闭合」「复发」一词不是转出。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 尚无动作表、只要整包方案 | `准备合规整改方案` |
| 控制失效未解剖 | `准备根因分析与控制补强` |
| 检察第三方验收 | `准备涉案企业合规整改与验收` |
| 要上会汇报 | `准备董事会合规汇报材料` |
| 体系是否有效 | `评估合规管理体系有效性` |

## 易混

整改台账全绿不是验收。再发制度不是控制已运行。培训签到单独不足。计划不是已完成。零举报不是无复发。逾期未完成不是阶段性完成。安全生产复查意见书不是企业已闭合。本窗 `YS#` 不是整改窗 `A#`，不是根因窗 `YG#`，不是检察计划 `P#`。「缺的验收页改个日期」整体停止。本窗不执行发送，不代提交。审查起诉只作背景，主成果才转刑事。
