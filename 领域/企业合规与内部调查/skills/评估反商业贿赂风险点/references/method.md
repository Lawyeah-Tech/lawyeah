# 评估方法

本文件是可执行判断节点。明示折扣佣金如实入账不是贿赂。有销售费用不是商业贿赂。管理不规范不是商业贿赂。中间人报酬不成比例是红旗不是已贿赂。员工个人收钱不自动等于经营者行为。红旗不是必须刑事控告。纸面制度不是已合规。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、刑事既遂、选定机关、代提交、未知写零。本窗不定罪，不写制度终稿，不写回扣账外专项终稿。本窗 `BR#` 是风险点行，不是调查认定 `F#`，不是测算 `M#`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1993 年反不正当竞争法第八条、把折扣写成已贿赂、把 42 号令套民企必须上报时记为噪声。禁止指导做假账、账外暗中路径或行贿步骤。禁止 `search_template` 生成已贿赂清单或已合规证明。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现场景扫描，不是默认闭集。
`BR#` 固定列：`编号｜场景｜相对方／中间人｜给付形态｜入账三态（明示入账／账外暗中／待核）｜公职接触｜红旗三态｜E#回链｜判断三值｜G#｜最强反方`。入账三态里，明示入账 ≠ 已合法；账外暗中 ≠ 已贿赂。红旗打开只表示须展开或转介，不是构成要件已闭合。缺给予／收受、财物或其他手段、交易机会或竞争优势、入账任一项：该效果 `依据不足，无法形成结论`，不得写成已贿赂。无 `E#` 不得写已覆盖、已贿赂、已入账闭环。`E#` 只作证据形态回链。缺项记 `G#`。扫描不是闭集。

口头「都是回扣」「有销售费用就是贿赂」「行业都这样」「制度印了就合规」只进 `S#`／`V#`，**不得单独算作开闸材料**。合同写「折扣」不是双方已如实入账。截图不是已入账。员工承认收款不是经营者行为已成立。`A#` 是承认给付或入账痕迹，不是已贿赂。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

审查起诉、监管检查、已立案只作程序背景。主成果才整案转。出现「不正当竞争」「回扣」一词不是转出。

廉洁闸打开（可出 `BR#` 草案，仍不得标「已贿赂／已合法／已定罪」）须同时满足：单方无冲突公司立场已闭合；主成果是廉洁风险图，不是制度、账外专项、刑辩或垄断专项；至少一条可编号业务场景或接触点。口头「都是回扣」、行业惯例不算单独开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

廉洁闸部分打开：已有可编号场景或接触点，但授权、入账、中间人、公职身份、施行日未闭合；或无书面评估授权但已有场景。对应格待核；仍交十节；不得标终稿 `已形成`。

廉洁闸关闭（仍正触发）：无一可编号业务场景且无一接触点。「今天必须出已贿赂终稿」而无最小场景不得开闸。不出 `BR#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `BR#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关写成「没有贿赂风险」或「已合规」。

「折扣一律回扣」「入账折扣即贿赂」「销售费用即贿赂」「管理不规范即商业贿赂」「中间人即已贿赂」「红旗必须刑事控告」「纸面制度即已合规」「民企必须按 42 号令上报」「员工个人收钱即经营者行贿」「交风险表即从轻／即自首」「行业惯例即合法」「本图已定罪」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `BR#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无一可编号场景且无一接触点，then 廉洁闸关闭，仍交十节，不是整体停止。
若 if 单方立场已闭合、无书面授权但已有可编号场景，then 廉洁闸部分打开，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造账册、指导账外暗中、指导行贿步骤、隐匿证据、打击报复、阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体、场景碎片与强制接口

一行一个场景或接触点。缺项记 `G#`，未知金额不得写 `0`。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 主体 | 经营者／工作人员；民企／国家出资公司／上市 | 民企必须按 42 号令上报 |
| 场景 | 销售／采购／项目／许可／招标／公职接触，分列 | 合成「有廉政风险」 |
| 给付 | 给予或收受候选；财物或其他手段 | 缺项写成已贿赂 |
| 入账 | 明示入账／账外暗中／待核 | 合同写折扣即已入账 |
| 施行日 | 行为时点相对 2025-10-15 | 跨日用唯一条文 |

检索锚点（写入 `L#` 前须核验）：反不正当竞争法（2025）第八条，施行日 2025-10-15；明示折扣、向中间人支付佣金可以，双方应当如实入账；工作人员贿赂原则上认定为经营者行为，但与谋取交易机会或竞争优势无关的抗辩除外。施行日前未持续行为适用修改前文本（通常 2019 修正第七条）。噪声：1993 年第八条。刑法第一百六十三条／第一百六十四条／第三百八十五条／第三百八十九条只作红旗，不定罪。公司法第一百六十八条／第一百七十七条不套民企。42 号令只约束中央企业。行政处罚法第三十二条交风险表 ≠ 从轻。刑法第六十七条交表 ≠ 自首。监察法第十八条不得伪造隐匿。刑法第一百六十二条之一、第三百零七条、第三百零八条只作红旗，不得指导删除。本节禁止出 `BR#` 终稿。

## 节点 3　风险点行 `BR#`

按已出现场景扫描，不是默认闭集。建议行型（出现才用）：

| 编号 | 含义 | 本窗允许 | 禁止 |
| --- | --- | --- | --- |
| `BR-销` | 销售接触 | 风险行草案 | 销售费用即贿赂 |
| `BR-采` | 采购接触 | 风险行草案 | 入账折扣即回扣 |
| `BR-项` | 项目／招标 | 风险行草案 | 中标即已贿赂 |
| `BR-中` | 中间人 | 不成比例红旗 | 报酬即已贿赂 |
| `BR-公` | 公职接触 | 只开接口 | 见过官员即行贿 |
| `BR-账` | 入账分账 | 三态并列 | 账外即已贿赂；明示入账即已合法 |

热冲突强制处理：

- 折扣一律回扣／销售费用即贿赂／中间人即已贿赂／行业惯例即合法 → 该格不支持；仍出其他 `BR#`。
- 缺四项要件任一项 → 该效果依据不足，不得写成已贿赂。
- 员工个人收钱 → 第 8 条第 4 款抗辩待核，不得提前锁定经营者行为。
- 指导账外暗中或伪造入账 → 整体停止，不是该格不支持。

无 `E#` 不得写已覆盖、已贿赂或已入账闭环。状态 `草案`。一次只推荐下一步。

## 节点 4　分账、公职接口、禁止文书与转介

第 7 节只开接口，不得夹带 `BR#` 终稿绕闸。闸关闭时第 7 节可写「闸未开，转介待场景编号」，不得补写已贿赂。

不写制度全文、回扣账外专项终稿、礼品允许表、刑事文书、启动闸。不可逆（对外宣称已合规、向监管正式报告已无贿赂、签署虚假入账）不得在草案阶段实施。禁止提交指令。不代提交。不选定机关。

下一步只转介：`设计反商业贿赂与礼品招待制度`、`审查礼品招待赞助与捐赠`、`评估回扣账外暗中与资金链路`、`评估销售激励与渠道返点廉洁风险`、`评估中间人费用与资金链路`、`筛查经销商代理中介廉洁风险`、`评估利益冲突与关联交易廉洁面`、`梳理公职人员接触点与审批`、`评估账簿记录与虚假报销`、`评估是否启动内部调查`、`评估企业合规风险总图`、`设计第三方合规管理机制`。

若 if 用户催促「按零写／填满已贿赂终稿」，then 该格 `现有依据不支持`，窗口不关。
若 if 金额、人数未知，then 写 `未知`／`G#`，禁止写 `0`。
