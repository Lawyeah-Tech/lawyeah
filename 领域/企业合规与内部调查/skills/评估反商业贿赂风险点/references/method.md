# 评估方法

本文件是可执行判断节点。明示折扣佣金如实入账不是贿赂。有销售费用不是商业贿赂。管理不规范不是商业贿赂。中间人报酬不成比例是红旗不是已贿赂。员工个人收钱不自动等于经营者行为。红旗不是必须刑事控告。纸面制度不是已合规。不定罪。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、刑事既遂、选定法院、代提交、未知写零。本任务不定罪，不写制度终稿，不给出账外操作步骤。本窗 `BR#` 是风险点行，不是调查认定 `F#`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1993 年反不正当竞争法第八条、把 MCP「尚未施行」的 2025 反法第八条在施行日 2025-10-15 之后仍当未生效、把折扣写成回扣时记为噪声。禁止指导做假账、账外暗中路径或行贿步骤。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现场景扫描，不是默认闭集。
`BR#` 固定列：`编号｜场景｜给予或收受候选｜对象类型｜财物或其他手段｜入账四态｜中间人与资金链路｜公职接触｜E#回链｜判断三值｜G#｜最强反方｜状态`。入账四态只用 `合同明示／双方如实入账／账外／去向不明`。状态默认 `草案`。禁止合成「已贿赂闭环」。无 `E#` 不得写已覆盖、已贿赂、已入账合规。`E#` 只作证据形态回链。缺项记 `G#`。扫描不是闭集。

口头「都是回扣」「有销售费用就是贿赂」「制度印了就合规」「红旗必须报」只进 `S#`／`V#`，**不得单独算作开闸材料**。付款回单不得升格已贿赂。合同写「折扣」不得单独升格合法或回扣。`A#` 是承认支付或入账痕迹，不是已贿赂。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上商业贿赂认定看财务往来实质：是否明示、是否入账，而不是合同把款项叫「折扣」。折扣与回扣的根本区别在于是否公开、是否入账。中间人佣金须符合劳务实质并如实入账。工作人员贿赂原则上可归经营者，但与谋取交易机会或竞争优势无关的抗辩待核。单位行贿须单位意志与利益归属待核。刑法罪名只作红旗。

风险闸打开（可出 `BR#` 草案，仍不得标「已贿赂／已定罪／已合规」）须同时满足：单方无冲突公司立场已闭合；主成果是风险点图，不是制度、账外专项、调查结论或刑事文书；至少一条可编号场景、资金、账簿或公职接触碎片。口头「都是回扣」不算单独开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

风险闸部分打开：已有可编号碎片，但入账、中间人、是否公职、施行日未闭合；对应格待核；仍交十节；不得标终稿 `已形成`。

风险闸关闭（仍正触发）：无一可编号场景、资金、账簿或公职接触碎片。「今天必须出已构成贿赂终稿」而无最小碎片不得开闸。不出 `BR#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `BR#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关写成「没有贿赂」或「已合规」。

「折扣一律回扣」「入账折扣即贿赂」「销售费用即贿赂」「管理不规范即商业贿赂」「中间人即已贿赂」「红旗必须刑事控告」「纸面制度即已合规」「民企必须按 42 号令上报」「员工个人收钱即经营者行贿」「本图已定罪」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `BR#` 草案。上述行**不得写入可执行 `BR#` 的已贿赂结论**。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无一可编号碎片，then 风险闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出指导做假账或账外暗中步骤、指导行贿步骤、伪造账册、隐匿证据、打击报复、阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体、场景碎片与强制接口

一行一个主体或场景碎片。缺项记 `G#`，不得把未知金额写成 `0`。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 主体 | 经营者／工作人员；民企／国家出资公司／上市 | 把员工个人收钱写成当然经营者行贿 |
| 场景 | 销售／采购／项目／许可／招标／公职接触，分行 | 合成「有廉政风险」 |
| 入账 | 合同明示／双方入账／账外／去向不明 | 把入账折扣写成回扣 |
| 中间人 | 报酬与工作量是否可对上 | 把中间人写成已贿赂 |
| 时点 | 行为是否跨越 2025-10-15 | 给唯一条文覆盖全程 |

检索锚点（写入 `L#` 前须核验）：

- 反不正当竞争法（2025）第八条：贿赂对象三类型；明示折扣佣金双方如实入账；工作人员贿赂原则上归经营者，无关抗辩待核。施行日 2025-10-15。MCP 标尚未施行则以施行日为准并记冲突。
- 施行日前未持续行为：通常 2019 修正第七条。噪声：1993 年第八条。
- 第二十四条行政处罚不是本窗定罪。
- 1996 禁止商业贿赂暂行规定第三条／第六条：须核验与 2025 文本冲突后再写入 `L#`。
- 刑法第一百六十三条／第一百六十四条只作红旗，不定罪。
- 刑法第一百六十二条之一、第三百零七条、第三百零八条只作红旗，不得指导删除。
- 公司法第一百七十七条、42 号令第二条不套民企必须上报。
- 行政处罚法（2021）第三十二条：交风险图 ≠ 从轻。

本节禁止出 `BR#` 终稿。

## 节点 3　风险点行 `BR#`

按已出现场景扫描，不是默认闭集。建议行型（出现才用，**不是闭集**）：

| 编号 | 含义 | 本窗允许 | 禁止 |
| --- | --- | --- | --- |
| `BR-销` | 销售／渠道 | 入账四态 | 合成有廉政风险 |
| `BR-采` | 采购 | 对象类型分列 | 供应商请客即已受贿 |
| `BR-项` | 项目／招标 | 红旗与缺口 | 已定罪 |
| `BR-折` | 折扣／佣金 | 明示入账抗辩 | 一律回扣 |
| `BR-中` | 中间人 | 报酬不成比例红旗 | 已贿赂 |
| `BR-账` | 账外／去向不明 | 指向未依法入账 | 给账外操作步骤 |
| `BR-职` | 公职接触 | 只开接口 | 行贿既遂 |
| `BR-员` | 工作人员个人 | 无关抗辩待核 | 当然经营者 |

热冲突强制处理：

- 折扣一律回扣／入账折扣即贿赂／销售费用即贿赂／管理不规范即贿赂／中间人即已贿赂／红旗必须刑事／纸面即合规／民企必须上报／个人即经营者／本图已定罪 → 该格不支持；仍出其他 `BR#`。
- 账外暗中必须指向未在依法账簿记载；指向不清则该条待核，不关窗。
- 评估**已发生**账外痕迹可以编号红旗；给出账外或行贿**步骤**＝整体停止。
- 公职接触与大额账外只开刑事／公职接触接口，不定罪。

事实不足以支持某风险点：该条 `依据不足，无法形成结论`，不关窗。无 `E#` 不得写已覆盖、已贿赂或已合规。状态 `草案`。一次只推荐下一步。

制度转 `设计反商业贿赂与礼品招待制度`。账外展开转 `评估回扣账外暗中与资金链路`。中间人转 `评估中间人费用与资金链路`。启动转 `评估是否启动内部调查`。报告转 `形成内部调查报告`。刑事转刑事。竞争法转竞争法。

若 if 用户催促「按零写／填满已贿赂终稿」，then 该格 `现有依据不支持`，窗口不关。
若 if 金额、人数未知，then 写 `未知`／`G#`，禁止写 `0`。
