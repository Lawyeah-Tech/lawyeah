# 评估集团与子公司合规穿透

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例检索。本窗是评估类穿透，**不要**用文书范本检索生成「已覆盖／已穿透」清单。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现并表与覆盖错配、总部制度直接生效的反例；案例只比较事实差异与翻转条件，不写成必然结果。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《民法通则》《民法总则》或其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成集团对子公司的穿透草案：穿透闸、控制关系、`Q#` 路径、`U#` 穿透单元（政策是否生效／举报是否可达／取证是否合法／处分主体）、报告线、当地强制规则接口。并表不是穿透。不设计股权控制，不给出境传输方案，不写境外当地法结论。不保证合规免责。不代提交。

`depends-on` 为空。政策落地文本转 `落地集团政策到境内实体`。跨境调查转 `协调跨境内部调查并分流涉外`。确为中央企业且主成果是 42 号令对照终稿才转 `评估国企合规管理办法差距`；民企集团套第三十九条仍正触发，该格 `现有依据不支持`。义务地图转 `建立合规义务与责任主体地图`。股权／章程转公司治理领域。数据出境整案转数据隐私领域。

## 工作边界

正触发：集团或单一子公司需要判断总部政策、举报、调查和报告线是否覆盖特定子公司、分公司或并表范围。控制关系不明、授权冲突、当地规则未核验仍正触发：穿透闸关闭，不出 `U#` 终稿，窗口不关。用户要把并表写成已穿透、总部可调阅全球邮箱当然合法、民企子公司必须按 42 号令向国资委报告、保证穿透即免责、今天必须给已覆盖结论，仍正触发：对应格填 `现有依据不支持` 或字段停止，闸未开则不出穿透终稿，窗口不关。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是把集团模板改成境内实体可执行文本（转 `落地集团政策到境内实体`）；
- 主成果是跨境调查协调（转 `协调跨境内部调查并分流涉外`）；
- 主成果是 42 号令条款对照终稿（转 `评估国企合规管理办法差距`）；
- 主成果是义务—主体地图（转 `建立合规义务与责任主体地图`）；
- 主成果是股权控制、章程或表决权安排（转公司治理领域）；
- 主成果是境外当地法或制裁结论（转涉外领域）；
- 主成果是数据出境或个人信息专项体系（转数据隐私领域）；
- 主成果是董监高履职缺口终稿（转 `评估董监高合规职责缺口`）；
- 主成果是调查回避终稿（转 `处理利益冲突与调查回避`）。

双方秘密、伪造穿透证明、伪造子公司授权、倒签集团文件、指导删除会计资料、打击报复**不在负触发表**，走整体停止。「并表即已覆盖」「全球邮箱当然合法」「民企子公司套 42 号令」**不在负触发表**，只关对应格，窗口不关。

## 建立工作坐标

确认：穿透评估授权；单方立场（集团／子公司，互斥）；母公司、子公司、分公司、合营、协议控制清单；股权与并表范围；授权文件；当地强制规则信号；跨境因素。

口头「已经全覆盖」「并表了所以穿透了」「集团政策全球适用」只登记 `S#`／`V#`。不得升格已覆盖，**不得算作开闸材料**。列出子公司不是已覆盖。已读、微信已读、电话、口头尽快、快递揽收只进 `S#`／`V#`，不得升格 `R#` 已送达，不得填「政策已对子公司生效」，不得起算法定更新日。口头备份不等于已保全。名称相似不自动合并。口述「实质控制」而无股权或协议：控制关系字段停止，不写已穿透。

同时掌握集团与子公司、或两家子公司相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。集团已开口且委托就是穿透评估、且未掌握子公司秘密时，可推定集团立场。无书面穿透评估授权但集团立场已闭合：穿透闸关闭，仍交十节，不是整体停止。提出伪造穿透证明、伪造控制图、伪造并表口径、伪造授权、倒签任命或集团文件、指导删除或打击报复：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 内部制度、章程或授权；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`U#` 穿透单元；`V#` 版本；`E#` 证据形态回链（股权证明、授权、并表口径、子公司机关批准、政策送达，不是发送闸）。禁止 `N#`、`EV#`、`M#`、`F#`、`ACT#`、`P#`、`K#`、`O#`、`H#`、`B#`。技能正文中的条号是检索锚点，不是已核验 `L#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止合成「集团已全覆盖」一笔。未知不写零。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：公司法（2023 修订）第三条公司是企业法人、有独立的法人财产（噪声：1993 年第三条）。总部规章制度不能直接在独立法人子公司生效，须履行子公司机关批准或民主程序。第二十三条人格否认是债权人保护例外，不得写成集团政策即可刺破，也不得写成未穿透即母公司当然连带。民法典第七十四条：分支机构以自己名义从事民事活动，民事责任由法人承担——分公司与独立法人子公司分列。公司法第一百六十八条国家出资公司不含参股；第一百七十七条仅约束国家出资公司对内合规，不得套民企子公司。中央企业合规管理办法第三十九条中央企业应当推动所属单位建立健全合规管理体系，只约束国资委履行出资人职责的中央企业；推动建立健全 ≠ 四问已覆盖。第二十八条纳入对所属单位考核评价，不是民企子公司对国务院国资委的报告义务。第四十条是对地方国资机构的参照指导，不是地方国企集团自动承受第三十九条。个保法第十三条人力资源管理所必需，不等于全员邮箱、私人微信或定位当然授权；第六条收集应限于最小范围。行政处罚法第三十二条提交穿透表本身不等于情节成就。监察法第十八条如实提供，不得伪造、隐匿、毁灭。噪声：已失效《合同法》、并表即穿透、总部政策当然覆盖全球、调阅全球邮箱当然合法、人格否认当集团连带、42 号令第三十九条套民企集团、民法典第一百六十八条／一百七十七条当国家出资公司条款。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变独立法人效果、42 号令所属单位范围或个保合法性基础的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补总部制度须经子公司董事会或民主程序才生效、并表不等于调查权已覆盖、混同用工与独立法人分列的反例。
- `search_case_by_fact` 只比较事实差异与翻转条件（如全资仍各为独立法人；手册写明适用子公司不等于调查权已合法），不写成必然已穿透或必然混同。

工具不可用时继续实体、控制关系和 `U#` 编目；控制关系、取证合法性、期限字段停止。不得拒跑，不得凭记忆写成并表即已覆盖或总部可调阅全球邮箱。

## 判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、穿透闸与不关窗

主成果才整案转出。伪造控制图或并表口径第一次停。并表即覆盖、全球邮箱当然合法、民企套 42 号令第三十九条、未穿透即母公司连带不关窗：该格不支持，闸已开仍出其他 `U#`。闸关仍交十节，第 6 节不出 `U#` 终稿。集团与子公司立场互斥。

### 2. 控制关系图

股权、并表、协议控制、分支机构分列。名称相似不自动合并。境外实体只标接口。

### 3. 穿透闸与路径 `Q#`

本节禁止出 `U#` 终稿。无一可编号实体则闸可关，窗口不关。

### 4. 穿透单元 `U#`

每家实体四问：政策是否对其生效、举报是否可达总部、总部取证是否合法、处分／追偿由谁作出。任一问为否或依据不足：不得写入已被覆盖。

### 5. 报告线、当地规则与转介

被调查人控制报告线：独立性字段停止，转介 `处理利益冲突与调查回避`。数据、劳动、国资只开接口。调阅全球邮箱只记穿透障碍，数据整案才转数据隐私。境外当地法**主成果**才转涉外。不设计股权。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造穿透证明、伪造控制图、伪造并表口径、伪造授权、倒签任命或集团文件、指导删除会计资料、借已有监察／检查文书对子公司平行灭证或打击报复。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无书面穿透评估授权但集团立场已闭合：不是整体停止，穿透闸关闭，仍交十节。
- `字段停止`：控制关系、当地强制规则、取证合法性未核验。并表即覆盖、全球邮箱当然合法、民企套 42 号令第三十九条、未穿透即母公司连带、保证免责：该格 `现有依据不支持`，窗口不关；闸已开仍出其他 `U#` 草案；闸未开才不出 `U#` 终稿。
- `目标停止`：主目标变为股权设计、政策落地终稿、跨境调查终稿、出境方案或境外当地法结论。

禁止指导伪造穿透或删除会计资料。不给胜诉率。不定罪。不保证免责。不选定机关。不代提交。未知不写零。不给出境方案。不设计股权。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。穿透闸关闭仍交十节，第 6 节不出 `U#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `U#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。穿透闸未打开时不得交付穿透终稿或「已覆盖」。边界见 [路由](references/routing.md)。
