# 边界与路由

## 正触发

集团或单一子公司需要判断总部政策、举报、调查和报告线是否覆盖特定实体。控制关系不明、授权冲突仍正触发：穿透闸关闭，不出 `U#` 终稿，窗口不关。并表即覆盖、全球邮箱当然合法、民企子公司套 42 号令，仍正触发。

双方秘密、伪造穿透证明、伪造授权、倒签集团文件、对子公司平行灭证、打击报复的停止，优先于负触发。上述信号不在下表。「并表即覆盖」「全球邮箱当然合法」「民企子公司套 42 号令」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 集团模板改成境内可执行文本 | `落地集团政策到境内实体` |
| 跨境调查协调 | `协调跨境内部调查并分流涉外` |
| 42 号令条款对照终稿 | `评估国企合规管理办法差距` |
| 义务—主体地图 | `建立合规义务与责任主体地图` |
| 股权控制、章程、表决权安排 | 公司治理领域 |
| 境外当地法或制裁结论 | 涉外领域 |
| 数据出境或个人信息专项体系 | 数据隐私领域 |
| 董监高履职缺口终稿 | `评估董监高合规职责缺口` |
| 调查回避终稿 | `处理利益冲突与调查回避` |
| 刑事辩护、控告 | 刑事领域 |
| 劳动处分决定 | 劳动领域 |

不得因「要求写成已覆盖」或「并表了」关窗。并表仍正触发，不得写成已穿透。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、解除、工伤主轴 | 劳动领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |
| 垄断、滥用支配、经营者集中 | 竞争法领域 |
| 税务稽查实体 | 税务领域 |
| 出口管制、制裁名单 | 涉外领域 |
| 章程、股权、任免本身为主成果 | 公司治理领域 |

综合合规穿透主轴可留本任务。审查起诉或检查只作背景，主成果才转。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 要把集团模板改成境内文本 | `落地集团政策到境内实体` |
| 证据或监管已跨境 | `协调跨境内部调查并分流涉外` |
| 确为中央企业且主成果是 42 号令对照终稿 | `评估国企合规管理办法差距` |
| 当地总经理是被调查人 | `处理利益冲突与调查回避` |
| 只要义务地图 | `建立合规义务与责任主体地图` |
| 只要总图 | `评估企业合规风险总图` |
| 要设计股权加强控制 | 公司治理领域 |
| 要给出境传输方案 | 数据隐私领域 |

## 易混

并表不等于合规穿透。财务并表不能写成调查权、举报渠道或处分权已经覆盖。全资仍是独立法人。总部手册写明适用子公司，不等于已履行当地生效程序。分公司规则不是子公司当然覆盖。混同用工只开劳动接口。民企套 42 号令第三十九条：该格不支持，不关窗，不转出。第四十条不是地方国企集团自动义务。未穿透不是母公司依第二十三条当然连带。调阅全球邮箱只记障碍，数据整案才转。「集团统一清场」整体停止。口头备份不是已保全。列出子公司不是已覆盖。
