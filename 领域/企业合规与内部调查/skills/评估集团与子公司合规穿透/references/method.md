# 评估方法

本文件是可执行判断节点。并表不是穿透。总部制度不能直接在独立法人子公司生效。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、已覆盖闭集、唯一截止日、选定机关、代提交、出境方案、股权设计、未知写零。本任务不定罪。集团与子公司立场互斥。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1993 年公司法第三条、把并表写成已穿透、把 42 号令第三十九条套民企集团、把公司法第二十三条写成集团政策即可刺破或未穿透即母公司连带、把民法典第一百六十八条／一百七十七条当国家出资公司条款时记为噪声。禁止指导伪造穿透或删除会计资料。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`U#` 固定列：`编号｜实体｜控制关系（股权／并表／协议／分支）｜政策是否对其生效｜举报是否可达总部｜总部取证是否合法｜处分／追偿主体｜E#回链｜当地强制规则接口｜判断三值｜最强反方｜待核`。禁止合成「集团已全覆盖」一笔。`E#` 只作证据形态回链，禁止 `N#`／`EV#`／`M#`／`F#`／`ACT#`／`P#`／`K#`／`O#`／`H#`／`B#`。扫描不是闭集。列出子公司不是已覆盖。

口头「已经全覆盖」「集团政策全球适用」只进 `S#`／`V#`，**不得算作开闸材料**。已读、快递揽收、口头尽快、电话不得升格总部指令已到达，不得填「政策已对子公司生效」。口头备份不等于已保全。拟制日＝本次形成本任务成果之日。

## 节点 0　分流、立场、穿透闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。伪造穿透证明、伪造控制图、伪造并表口径、伪造授权、倒签任命、指导删除、平行灭证、打击报复、双方秘密不进负表。

整案转出只交付第 1、2、10 节，不出 `U#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是集团模板改成境内可执行文本 | 负触发 `落地集团政策到境内实体` |
| 主成果是跨境调查协调 | 负触发 `协调跨境内部调查并分流涉外` |
| 主成果是 42 号令条款对照终稿 | 负触发 `评估国企合规管理办法差距` |
| 主成果是义务—主体地图 | 负触发 `建立合规义务与责任主体地图` |
| 主成果是股权、章程或表决权安排 | 负触发，转公司治理领域 |
| 主成果是境外当地法或制裁 | 整案转涉外 |
| 主成果是数据出境或个人信息专项 | 整案转数据隐私 |
| 主成果是董监高履职缺口终稿 | 负触发 `评估董监高合规职责缺口` |
| 主成果是调查回避终稿 | 负触发 `处理利益冲突与调查回避` |
| 侦查、起诉、辩护为主成果 | 整案转刑事 |
| 劳动处分决定为主成果 | 整案转劳动 |

审查起诉、监管检查只作程序背景。主成果才整案转。

穿透闸打开（可出 `U#` 草案，仍不得标「已覆盖／已穿透／免责」）须同时满足：单方无冲突立场（集团或子公司，互斥）已闭合；主成果是穿透评估，不是政策落地、跨境调查、股权设计或出境方案；至少一家可编号实体，且控制关系有股权、协议或分支**书面**材料可编号。并表清单或口头全球适用不算开闸材料。双方秘密或第一次伪造控制图／授权／并表口径不是关闸条件，走整体停止。

穿透闸部分打开：控制关系或当地规则未闭合，但已有可编号实体；对应格待核；仍交十节；不得标终稿 `已形成`。

穿透闸关闭（仍正触发）：集团立场已闭合但无书面穿透评估授权；无一可编号实体；只有口述实质控制。「今天必须给已覆盖结论」而无最小事实不得开闸。不出 `U#` 终稿。**仍交十节**，第 5 节只交闸／`Q#` 状态，第 6 节不出 `U#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「已经全覆盖」或「没有子公司」。

「并表即已穿透」「名称相似自动合并」「总部政策当然覆盖全球」「可调阅全球邮箱当然合法」「民企集团必须按 42 号令第三十九条穿透全部并表子公司」「未穿透即母公司依第二十三条连带」「保证穿透即免责」「今天必须给已覆盖结论」「提交穿透表即应当从轻」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `U#` 草案，不得因错误主张扣掉整张表。闸未开才不出 `U#` 终稿。民企套第三十九条不得负触发到 `评估国企合规管理办法差距`。

若 if 立场或委托无法闭合，then 整体停止。
若 if 集团立场已闭合但无书面穿透评估授权，then 穿透闸关闭，仍交十节，不是整体停止。
若 if 同时掌握集团与子公司或两家子公司相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造穿透证明、伪造控制图、伪造并表口径、伪造授权、倒签任命或集团文件、指导删除会计资料、借已有监察／检查文书对子公司平行灭证或打击报复，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　控制关系图

固定母公司、子公司、分公司、合营、协议控制。股权比例不明或「实质控制」只有口述：控制关系字段停止，不写已穿透。名称相似不自动合并。并表范围与股权不一致：两行并列。

检索锚点（写入 `L#` 前须核验）：

- 公司法（2023 修订）第三条（条号运行时核验）：公司是企业法人，有独立的法人财产。噪声：1993 年第三条。子公司独立承担民事责任，总部规章制度不能直接在子公司生效，须履行子公司机关批准或民主程序。
- 公司法第二十三条：人格否认是债权人保护例外。不得写成集团政策即可刺破，也不得写成未穿透即母公司当然连带。
- 民法典第七十四条：分支机构以自己名义从事民事活动，民事责任由法人承担。分公司与独立法人子公司分列，不得把分公司规则写成子公司当然覆盖。
- 公司法第一百六十八条：国家出资公司不含参股。公司法第一百七十七条仅国家出资公司对内合规。噪声：把民法典第一百六十八条／一百七十七条当这两条。
- 42 号令第三十九条：中央企业推动所属单位建立健全合规管理体系，只约束国资委履行出资人职责的中央企业。推动建立健全 ≠ 四问已覆盖。第二十八条纳入对所属单位考核评价，不是民企对国务院国资委报告义务。第四十条是对地方国资机构的参照指导，不是地方国企集团自动承受第三十九条。
- 个保法第十三条第二项人力资源管理所必需，不等于全员邮箱、私人微信或定位；第六条最小范围。总部「可调阅全球邮箱」与境内个保冲突：两行并列，本窗只记穿透障碍；仅当主成果是数据出境或个人信息专项才转数据隐私。

境外子公司、代表处：境内可做段可留，当地法结论转涉外。出口管制或制裁主轴转涉外。

## 节点 3　穿透单元 `U#`

对每家实体四问，分行判断：

1. 总部政策是否对其生效（独立法人须当地批准／民主程序；分公司另核）
2. 举报是否可达总部（渠道、拦截、当地强制）
3. 总部能否合法取证（个保、劳动、通信、当地程序）
4. 处分／追偿由谁作出（当地用人单位还是总部）

任一问为否或 `依据不足`：该社不得写入「已被覆盖」。财务并表不能写成调查权、举报渠道或处分权已覆盖。名称相似、全资持股，均不得单独打开已覆盖。总部不得当然对子公司员工作出劳动处分。无 `E#` 回链不得写政策已生效。混同用工是劳动事实，只开劳动接口，不写成合规机制已穿透。

总部授权「可调阅全球邮箱」与境内个保或劳动规则冲突：两行并列，不选对用户有利的一版。授权复印件不能填当地法定义务空格，也不能填对国资委报告空格。

## 节点 4　报告线、当地规则与转介

子公司合规负责人由当地总经理考核，且当地总经理是被调查人：报告线失效风险写入最强反方，独立性字段停止，转介 `处理利益冲突与调查回避`。

境内劳动、数据、国资强制规则只列接口。境外当地法**主成果**才转涉外，境内实体四问可留。不给出境传输方案。

要把集团模板改成境内实体可执行文本：转介 `落地集团政策到境内实体`。证据或监管已跨境：转介 `协调跨境内部调查并分流涉外`。用户要求设计股权或表决权安排以加强控制：目标停止，转公司治理。

已有监察或检查 `R#`：不得借「集团统一清场」对子公司平行灭证。刑法第一百六十二条之一只作红旗，不得指导删除。

## 本任务回链纪律

本任务成果是「穿透闸与各实体覆盖四问草案」。不包含：政策落地终稿、跨境调查终稿、股权方案、出境方案、境外当地法结论、42 号令对照终稿。禁止伪造穿透。禁止选边治愈。禁止并表即覆盖。禁止全球邮箱当然合法。禁止民企子公司报国务院国资委。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标穿透终稿已形成。
