# 边界与路由

## 正触发

已有具体举报件，需要判断可查性和分流，而不是出调查结论或建渠道。要素不全、开箱未核验仍正触发：有可编号件则闸开或半开，出 `CS#` 草案。匿名即不实、否认即不查、可查即属实、HR 已沟通即已评估、民企套第 24 条必须立案，仍正触发。

双方秘密、伪造线索、倒签收件、指导追踪匿名、指导删除、打击报复的停止，优先于负触发。上述信号不在下表。「匿名即不可查／即不实」「否认即不立案」「影响业务即不查」「HR 已沟通即已评估」「可查即属实」「民企套第 24 条」不在下表。「不出调查结论」「不因匿名推定不实」是交付禁令，不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 建渠道、没有具体件 | `建设内部举报渠道与受理规则` |
| 完整启动闸 | `评估是否启动内部调查` |
| 保护方案终稿 | `设计举报人保护与反报复措施` |
| 报复是否已发生 | `评估打击报复风险` |
| 事实认定或调查报告 | `形成内部调查报告` |
| 职场性骚扰、工资工时、日常违纪处分 | 劳动领域（可留保护接口） |
| 回避决定终稿 | `处理利益冲突与调查回避` |
| 刑事辩护、控告、自首 | 刑事领域 |

不得因「匿名所以不查」或「要求按第 24 条立案上报」关窗。拟设仍正触发，不得写成已立案。民企硬套不得负触发到对照窗。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、解除、工伤、职场性骚扰主轴 | 劳动领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |
| 垄断、滥用支配、经营者集中 | 竞争法领域 |
| 税务处理决定、稽查实体 | 税务领域 |

综合合规单件可查主轴可留本任务。审查起诉或检查只作背景，主成果才转。出现「举报」一词不是转出。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 谁查、查到哪、预算 | `评估是否启动内部调查` |
| 调查授权书 | `确定调查授权范围与独立` |
| 回避名单终稿 | `处理利益冲突与调查回避` |
| 保护方案终稿 | `设计举报人保护与反报复措施` |
| 报复已出现不利动作 | `评估打击报复风险` |
| 渠道缺口、无具体件 | `建设内部举报渠道与受理规则` |
| 要逐项属实认定 | `形成内部调查报告` |

## 易混

可查不是属实。匿名不是不实，也不等于已查实。缺联系方式不是不可查。人力资源「已沟通」不是立案评估。群已读不是已立案。截图不是原文已保全。受理编号不是立案。被指向人开箱不是已独立初核，也不因此关窗。民企套 42 号令第二十四条：该格不支持，不关窗，不转出，不得建议上报国资委。指导追踪匿名第一次整体停止。完整启动闸、保护方案、调查报告不在本窗。劳动性骚扰主轴转劳动，可留保护接口。
