# 评估方法

本文件是可执行判断节点。可查不是属实。匿名不是不实。HR 已沟通不是立案评估。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。可查三态只用 `支持初核`、`不支持正式初核`、`依据不足`。禁止胜诉率、必然免责、必然立案、唯一截止日、选定机关、代提交、未知写零。本任务不出调查结论，不写完整启动闸，不写保护方案终稿。本窗 `CS#` 是可查性行，不是 `CH#`，不是 `F#`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1993 公司法第一百七十七条、把 42 号令第二十四条套民企必须立案、把匿名写成诬告时记为噪声。禁止指导追踪匿名或删除会计资料。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`CS#` 固定列：`编号｜件次／收件形态｜可核验点（时／地／人／交易／账户／书证）｜指向人与原件控制｜回避红旗｜即时保护接口｜分流｜可查三态｜E#回链｜判断三值｜G#｜最强反方｜待核`。禁止合成「已立案／已查实闭环」。`E#` 只作证据形态回链。缺项记 `G#`。扫描不是闭集。

口头「有人举报了」「HR 已经沟通过」「群已读」只进 `S#`／`V#`，**不得算作开闸材料**。已读、揽收不得升格 `R#` 已送达，不得升格已立案。截图／转发不是原文已保全。口头备份不等于已保全。`A#` 是承认收件／开箱，不是已查实。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

## 节点 0　分流、立场、可查闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。伪造线索、倒签收件、指导追踪匿名、指导删除、平行灭证、打击报复、双方秘密不进负表。

整案转出只交付第 1、2、10 节，不出 `CS#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是建渠道、没有具体件 | 负触发 `建设内部举报渠道与受理规则` |
| 主成果是完整启动闸 | 负触发 `评估是否启动内部调查` |
| 主成果是保护方案终稿 | 负触发 `设计举报人保护与反报复措施` |
| 主成果是报复是否已发生 | 负触发 `评估打击报复风险` |
| 主成果是事实认定或调查报告 | 负触发 `形成内部调查报告` |
| 主成果是职场性骚扰或日常违纪处分 | 整案转劳动（可留保护接口） |
| 主成果是回避决定终稿 | 负触发 `处理利益冲突与调查回避` |
| 侦查、起诉、辩护为主成果 | 整案转刑事 |
| 数据或竞争专项整案 | 整案转相应领域 |

审查起诉、监察检查只作程序背景。主成果才整案转。出现「举报」一词不是转出。

可查闸打开（可出 `CS#` 草案，仍不得标「已立案／已查实／已不可查闭环」）须同时满足：单方无冲突公司立场已闭合；主成果是单件可查性，不是渠道、启动闸或报告；至少一件可编号原文或带可核验点的衍生件。口头举报、已读、HR 已沟通不算开闸材料。双方秘密或第一次伪造不是关闸条件，走整体停止。

可查闸部分打开：有件但可核验点、指向人或开箱未闭合；或无书面评估授权但已有件；对应格待核；仍交十节；不得标终稿 `已形成`。

可查闸关闭（仍正触发）：无一可编号件且无一可核验点。「今天必须出已立案或已查实终稿」而无最小事实不得开闸。不出 `CS#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `CS#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「没有问题」或「匿名即诬告」。没有具体件、要建热线：负触发渠道窗，不是本窗关闸。

「匿名即不可查或即不实」「被指向人否认即不立案」「会影响业务即不查」「HR 已沟通即已评估」「可查即属实」「民企必须按第二十四条立案上报」「群已读即已立案」「交可查表即从轻」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `CS#` 草案。闸未开才不出 `CS#` 终稿。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合、无书面评估授权但已有可编号件，then 可查闸部分打开，仍交十节，不是整体停止。
若 if 公司立场已闭合但无一可编号件，then 可查闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被指向人或举报人相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造举报、补假线索、倒签收件、指导追踪匿名、向被指向人核实身份以便报复、指导删除、打击报复或阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 3　可查性行 `CS#`

按本件已出现要素扫描，不是默认闭集。三态操作：

- **支持初核**：至少一项可核验点（期间、地点、交易／账户、相对方、书证／系统、可定位证人岗位）。转介启动闸只开接口。不得写成已查实或必须立案上报。
- **不支持正式初核**：纯抽象谩骂、无可核验人／事／时／账。写材料保存与复核时点。不得写成「没有问题」或「匿名即诬告」。
- **依据不足**：有指向但缺关键期间、对象或书证钩子。限缩补证接口。P2 `处理匿名举报与材料不足` 未安装则 `unavailable`，本窗不代做。不得因不足写成不实，也不得因不足推迟保护接口。

匿名缺联系方式：有可核验点仍可支持初核；无钩子则依据不足，不是「匿名所以不支持立案」。不得指导查 IP、设备、快递、支付或内部日志识别匿名人。

保护并行：不因尚未立案或三态为「不支持正式初核」而推迟保护接口。本窗只列知悉范围最小化、禁止不利人事动作接口。不写解除、调岗、处分。实名或可识别匿名立即标暴露风险。

## 节点 4　分流、可逆性与转介

可查 → 转介启动闸或授权原子，本窗不写谁查、预算、范围闭合。不可查／依据不足 → 复核时点与材料保存。用户要已查实：目标停止或 `Q-实` 不打开。

可逆与不可逆分列。不可逆（向被指向人出示原件、全员点名、格式化、对外宣称已立案）不得在草案阶段实施。禁止提交指令。不代立案、不代调查、不代提交。

下一步只转介：启动闸、调查授权、回避、保护、打击报复、渠道（仅渠道缺口）、证据保全接口、调查报告。P2 回执未安装则 `unavailable`，不出发送版回执。

已有监察或检查 `R#`：不得借可查表平行灭证。刑法第一百六十二条之一只作红旗，不得指导删除。
