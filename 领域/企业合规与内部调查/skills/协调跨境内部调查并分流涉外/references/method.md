# 协调跨境内部调查并分流涉外方法

本文件是可执行判断节点。境外母公司不是已可全球调取邮箱。外国特权不是中国法免交。FCPA、SOX、ACP 不是中国法义务。境外证人不是必须出境调取。境外服务器不是必须本地镜像完成。外国律师函不是已阻断中国监管。集团全球程序不是境内已授权。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、唯一截止日、选定机关、代提交、未知写零。本任务不定罪，不给出境传输方案，不写外国法结论。本窗闸名只能是跨境闸，禁止复用落地闸、舆情闸、监测闸、交叉闸。本窗 `KJ#` 是跨境行，不是 `LD#`／`YQ#`／`LG#`／`WP#`。英文 id 禁止使用，一律用中文技能名 `协调跨境内部调查并分流涉外`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、把总部写成已可全球调取、把 ACP 写成中国法免交、把 FCPA 写成中国法义务、把未经批准向外国执法提供境内个人信息写成已合法时记为噪声。禁止指导隐匿境外证据或删除境外日志。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现切片扫描，不是默认闭集。
`KJ#` 固定列：`编号｜法域切片｜证据或证人所在｜境内可做｜冲突点｜涉外接口｜数据接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「总部即可全球调取」。无 `E#` 不得写已调取、已免交或出境已合法。`E#` 只作证据形态回链，不是发送闸。扫描不是闭集。缺项记 `G#`。承认只进 `S#`／`D#`，不得占用 `A#`。

口头「总部全球一套」「美国律师说有特权不用交」「邮箱都在境外直接镜像」只进 `S#`／`V#`，**不得单独算作开闸材料**。已读不得升格已授权。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：跨境电子数据优先司法协助，而非径直向境外服务商或母公司整包调取。外国司法或执法机构索要存储于境内的个人信息，非经中国主管机关批准不得提供。律师—客户特权不是现行中国法免交理由。

## 节点 0　分流、立场、跨境闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、隐匿境外证据、伪造无跨境、删除境外日志、阻挠合法检查、未经批准向外国执法提供境内个人信息、打击报复不进负表。利益冲突未解不进整体停止。

整案转出只交付第 1、2、10 节，不出 `KJ#` 终稿。

审查起诉、外国监管问询只作程序背景。主成果才整案转。出现「跨境」「境外」「FCPA」一词不是转出。

跨境闸打开（可出 `KJ#` 草案，仍不得标「已可全球调取／已免交／出境已合法」）须同时满足：单方无冲突公司立场已闭合；主成果是跨境协调与分流，不是出境方案、不是出口管制评估、不是调查报告；至少一项可编号法域切片、境外证据或证人碎片。口头「总部全球一套」不算单独开闸材料。

跨境闸部分打开：已有碎片，但法域或授权未闭合；对应格待核；仍交十节。

跨境闸关闭（仍正触发）：无一可编号碎片。「今天必须出全球调取／已免交终稿」而无最小碎片不得开闸。不出 `KJ#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `KJ#` 终稿，**第 7 节不得出出境方案或外国法结论**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「境外母公司即可全球调取」「外国特权即中国法免交」「FCPA 即中国法义务」「境外证人必须出境调取」「境外服务器必须本地镜像」「外国律师函已阻断中国监管」「集团全球程序即境内已授权」「民企必须报国资委跨境」「交表即从轻」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `KJ#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无一可编号碎片，then 跨境闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出隐匿境外证据、伪造无跨境、删除境外日志、阻挠合法检查、未经批准向外国执法提供境内个人信息、打击报复，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体与法域切片

一行一个主体或法域切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `KJ#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 主体类型 | 境内独立法人子公司／分公司／境外母公司／外国分支分列 | 母公司指令升格境内已授权 |
| 落点 | 人、系统、证据、监管分列法域 | 口头「都在境外」当闭集 |
| 外国法信号 | 只作背景 | 写成中国法义务或已免交 |

检索锚点（写入 `L#` 前须核验）：

- 公司法第十三条：子公司独立法人。境外母公司 ≠ 已可全球调取。
- 个保法第三十八条：出境只开接口。第四十一条：未经批准不得向外国司法或执法机构提供存储于境内的个人信息。数据安全法第三十六条：未经批准不得向外国司法或执法机构提供存储于境内的数据，只开接口。
- 监察法第十八条：如实提供，不得伪造、隐匿、毁灭。外国特权 ≠ 免交。
- 律师法第三十八条：执业保密 ≠ ACP。
- 行政处罚法第三十二条：交表 ≠ 从轻。

## 节点 3　跨境行 `KJ#`

按已出现切片扫描，不是默认闭集。每条须能指向法域、所在、境内可做和只开接口的冲突。境外母公司、集团指令、外国律师函单独不足支撑已可全球调取或已免交。

境内可做只列中国大陆合法权限内动作接口（授权、持有通知、境内收集、境内访谈提纲），不写成已完成。出境、出口管制、外国劳动法只开转介，不填实体结论。

无 `E#` 不得写已调取、已免交或出境已合法。状态 `草案`。一次只推荐下一步。

热冲突强制处理：

- 总部即可全球调取／ACP 即免交／FCPA 即中国法／证人必须出境／服务器必须镜像／律师函已阻断 → 该格不支持；仍出其他 `KJ#`。
- 无一碎片 → 关闸，不出 `KJ#` 终稿，窗口不关。
- 指导隐匿境外证据、删除境外日志、未经批准向外国执法提供境内个人信息 → 整体停止，不是该格不支持。

## 节点 4　数据、涉外、收集与特权接口

第 7 节只开接口，不得夹带 `KJ#` 终稿、出境方案或外国法结论绕闸。闸关闭时第 7 节可写「闸未开，转介待切片编号」，不得补写已可全球调取。境外要求的黎明突袭若涉及中国检查：不得教阻挠。

下一步只转介：`落地集团政策到境内实体`、`合法收集书证电子证与财务痕迹`、`评估律师工作产品与保密边界`、`制定调查方案与访谈计划`、`形成内部调查报告`、`准备向监管提交材料与特权日志`。禁止此致外国执法机关。不代提交。

若 if 用户催促「总部即可调邮箱／特权不用交／填满全球调取终稿」，then 该格 `现有依据不支持`，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：在华独立法人子公司启动内部调查，境外母公司要求把境内员工邮箱整包镜像到美国，主张 FCPA 是中国法义务、ACP 可以不向中国监管交材料、境外证人必须出境取证、外国律师函已经阻断中国检查。跨境闸打开或半开。`Q-外`、`Q-特`、`Q-证`、`Q-镜`、`Q-函`、`Q-集` 不打开为可靠路径。第 6 节不得把已可全球调取、已免交写入可执行 `KJ#`；对应格 `现有依据不支持`；仍出境内可做接口、个保法第四十一条待核、数据／涉外转介等其他 `KJ#`。不关窗。不给出境方案。不写外国法结论。
