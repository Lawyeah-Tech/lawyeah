# 边界与路由

## 正触发

证据、证人或监管在境外或外国法并行，需要划分境内可做段并分流涉外与数据，而不是做出境方案或外国法结论。从零、碎片、法域未核验、无书面调查授权仍正触发：有切片则闸开或半开，出 `KJ#` 草案，保持草案。总部即可全球调取、ACP 即免交、FCPA 即中国法，仍正触发。

双方秘密、隐匿境外证据、伪造无跨境、删除境外日志、阻挠合法检查、未经批准向外国执法提供境内个人信息、打击报复的停止，优先于负触发。上述信号不在下表。「境外母公司即可全球调取」「外国特权即中国法免交」「FCPA 即中国法义务」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 出境传输方案或个人信息出境专项 | 数据隐私领域 |
| 出口管制、制裁名单或境外经营准入 | 涉外领域 |
| 集团政策落地对照 | `落地集团政策到境内实体` |
| 境内收集日志终稿 | `合法收集书证电子证与财务痕迹` |
| 工作产品与特权终稿 | `评估律师工作产品与保密边界` |
| 调查方案终稿 | `制定调查方案与访谈计划` |
| 调查报告终稿 | `形成内部调查报告` |
| 劳动处分或境外当地劳动法结论 | 劳动或涉外领域 |
| 刑事辩护、控告或自首 | 刑事领域 |

不得因「不给出境传输方案」或「不写外国法结论」关窗。拟跨境协调仍正触发，不得写成已可全球调取或已免交。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、辩护为主成果 | 刑事领域 |
| 劳动合同、解除、工伤主轴 | 劳动领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |
| 垄断、滥用支配、经营者集中 | 竞争法领域 |
| 税务处理决定、稽查实体 | 税务领域 |
| 银行保险机构行业合规办法主轴 | 金融领域 |
| 药品购销回扣行业细则主轴 | 医疗医药领域 |
| 出口管制、制裁名单 | 涉外领域 |
| 章程、股权、任免本身为主成果 | 公司治理领域 |

综合跨境内部调查主轴可留本任务。审查起诉、外国监管问询只作背景，主成果才转。出现「跨境」「境外」「FCPA」一词不是转出。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 只要出境传输方案 | 数据隐私领域 |
| 只要出口管制或制裁评估 | 涉外领域 |
| 集团模板要落地对照 | `落地集团政策到境内实体` |
| 境内书证电子证收集 | `合法收集书证电子证与财务痕迹` |
| 外国特权是否中国法免交 | `评估律师工作产品与保密边界` |

## 易混

有境外母公司不是已经可以全球调取邮箱。外国特权不是中国法免交理由。FCPA 不是中国法义务。ACP 不是中国法免交。境外证人不是必须出境调取。境外服务器不是必须本地镜像完成。外国律师函不是已阻断中国监管。集团全球程序不是境内已授权。未经批准不得向外国执法提供存储于境内的个人信息。本窗 `KJ#` 不是落地窗 `LD#`，不是舆情窗 `YQ#`，不是收集日志 `LG#`。「境外日志先删掉」整体停止。本窗不执行发送，不代提交。不教阻挠中国检查。
