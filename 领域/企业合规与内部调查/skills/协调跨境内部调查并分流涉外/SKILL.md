# 协调跨境内部调查并分流涉外

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务或裁判案例检索。本窗是跨境分流评估，**不要**用 `search_template` 或文书范本生成出境传输方案、司法协助请求或「已可全球调取」，也不得代写司法协助请求。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现境外母公司即可全球调取、外国特权即中国法免交、FCPA 即中国法义务、外国律师函即已阻断中国监管的反例；案例只比较事实差异与翻转条件，不写成必然结果。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《民法通则》《民法总则》或其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下（公司或其调查受托律师，互斥），形成跨境内部调查的境内可做与分流草案：跨境闸、主体与法域切片、`Q#` 路径、`KJ#` 跨境行（法域切片／证据或证人所在／境内可做／冲突点／涉外接口／数据接口／`E#` 回链）。本窗 `KJ#` 是跨境行，不是落地条款 `LD#`，不是舆情行 `YQ#`，不是收集日志 `LG#`，不是工作产品 `WP#`。本窗闸名只能是跨境闸，禁止复用落地闸、出境闸、分流闸、舆情闸、监测闸、交叉闸。跨境闸打开不等于已可全球调取不等于外国特权已免交不等于出境已合法。境外母公司不是已可全球调取邮箱。外国特权不是中国法免交。FCPA、SOX、ACP 不是中国法义务。境外证人不是必须出境调取。境外服务器不是必须本地镜像完成。外国律师函不是已阻断中国监管。集团全球程序不是境内已授权。个保法出境只开接口。不给出境传输方案。不写外国法结论。不写出口管制或制裁评估。不定罪。不保证免责。不代提交。未知不写零。

`depends-on` 为空。主成果是出境传输方案转数据隐私领域。主成果是出口管制或制裁转涉外领域。主成果是集团政策落地对照转 `落地集团政策到境内实体`。主成果是境内收集日志转 `合法收集书证电子证与财务痕迹`。主成果是工作产品与特权终稿转 `评估律师工作产品与保密边界`。主成果是调查方案转 `制定调查方案与访谈计划`。主成果是调查报告转 `形成内部调查报告`。英文 id 禁止使用，一律用中文技能名。

## 工作边界

正触发：证据、证人或监管在境外或外国法并行，需要划分境内可做段并分流涉外与数据，而不是做出境方案或外国法结论。法域、证据位置未核验仍正触发：有可编号法域切片、境外证据或证人碎片则跨境闸打开或半开，第 6 节出 `KJ#` 草案，缺项记 `G#`。无一可编号碎片、又要求「今天必须出全球调取／已免交终稿」才关闸，仍交十节，第 6 节不出 `KJ#` 终稿，第 7 节不得出出境方案或外国法结论，窗口不关。用户要把境外母公司写成已可全球调取、把外国特权写成中国法免交、把 FCPA 写成中国法义务、把境外证人写成必须出境调取、把境外服务器写成必须本地镜像、把外国律师函写成已阻断中国监管、把集团全球程序写成境内已授权、把民企套必须向国资委报跨境、把交跨境表写成从轻，仍正触发：对应格填 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `KJ#` 草案。不得因「不给出境传输方案」「不写外国法结论」改走负触发关窗。利益冲突未解不是整体停止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是出境传输方案或个人信息出境专项（转数据隐私领域）；
- 主成果是出口管制、制裁名单或境外经营准入（转涉外领域）；
- 主成果是集团政策落地对照（转 `落地集团政策到境内实体`）；
- 主成果是境内收集日志终稿（转 `合法收集书证电子证与财务痕迹`）；
- 主成果是工作产品与特权终稿（转 `评估律师工作产品与保密边界`）；
- 主成果是调查方案终稿（转 `制定调查方案与访谈计划`）；
- 主成果是调查报告终稿（转 `形成内部调查报告`）；
- 主成果是是否启动内部调查终稿（转 `评估是否启动内部调查`）；
- 主成果是劳动处分或境外当地劳动法结论（转劳动或涉外，按主轴）；
- 主成果是刑事辩护、控告或自首（转刑事领域）。

双方秘密、隐匿境外证据、伪造无跨境、删除境外日志、阻挠合法检查、指导向外国执法径直提供境内个人信息、打击报复**不在负触发表**，走整体停止。「境外母公司即可全球调取」「外国特权即中国法免交」「FCPA 即中国法义务」「境外证人必须出境调取」「境外服务器必须本地镜像」「外国律师函已阻断中国监管」「集团全球程序即境内已授权」「民企必须报国资委跨境」「交表即从轻」**不在负触发表**，该格 `现有依据不支持` 或字段停止，窗口不关。「不给出境传输方案」「不写外国法结论」「不定罪」是交付禁令，不是负触发。主成果才转；出现「跨境」「境外」「FCPA」一词不是转出。

## 建立工作坐标

确认：调查授权；单方立场（公司或其调查受托律师，互斥）；境内实体与境外母公司／分支分列；证据、证人、系统、监管落点；外国法或集团指令信号；法域；当前检查、诉讼、监察或刑事状态。

口头「总部说全球一套程序」「美国律师说有特权不用交」「邮箱都在境外所以直接镜像」只登记 `S#`／`V#`。不得升格已可全球调取、已免交或出境已合法，**不得单独算作开闸材料**。可编号法域切片、境外证据或证人碎片可开闸。已读不等于送达。外国监管问询已读不得起算答复期。快递揽收不是外国执法已收，不是个保法第四十一条或数据安全法第三十六条批准已成就。本窗不执行发送，不代提交，不定罪，不给出境方案。

立场只许「公司」或其调查受托律师，互斥。被调查对象不得用本窗出对自己有利的「外国特权免交」稿。同时掌握公司与被调查对象相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。公司已开口且委托就是本件跨境协调、且未掌握对方秘密时，可推定公司立场。无一可编号碎片：跨境闸关闭，仍交十节，不是整体停止。无书面调查授权但单方立场已闭合、且已有可编号碎片：跨境闸部分打开，仍交十节，不是整体停止。提出隐匿境外证据、伪造无跨境、删除境外日志、阻挠合法检查、未经批准向外国执法提供存储于境内的数据或个人信息、打击报复：第一次提出即整体停止，不以「坚持」为门槛。利益冲突未解：不是整体停止。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`R#` 机关或生效文书；`C#` 内部制度或集团指令版本；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`KJ#` 跨境行；`V#` 版本；`E#` 证据形态回链（法域切片、证据或证人所在、集团指令版本、冲突点，不是发送闸，不是已全球调取证明）。承认只进 `S#`／`D#`，不得占用整改窗 `A#`。禁止 `N#`、`EV#`、`M#`、`F#`、`ACT#`、`A#`、`P#`、`K#`、`O#`、`H#`、`B#`、`U#`、`X#`、`HD#`、`W#`、`T#`、`RC#`、`YG#`、`CM#`、`LD#`、`LG#`、`WP#`、`YQ#`、`Dsc#`、`QS#`、`FH#`、`MO#`、`YU#`、`GZ#`、`YS#`。技能正文中的条号是检索锚点，不是已核验 `L#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止合成「总部即可全球调取」。扫描不是闭集。未知不写零。境外母公司 ≠ 已可全球调取。外国特权 ≠ 中国法免交。FCPA ≠ 中国法义务。外国律师函 ≠ 已阻断中国监管。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：公司法（2023 修订）第十三条子公司具有法人资格、依法独立承担民事责任，境外母公司指令不是境内子公司已授权全球调取。个人信息保护法第三十八条出境只开接口，本窗不做出境方案；第四十一条非经中华人民共和国主管机关批准，个人信息处理者不得向外国司法或者执法机构提供存储于境内的个人信息。数据安全法第三十六条非经主管机关批准不得向外国司法或者执法机构提供存储于境内的数据，只开接口。国际刑事司法协助法第四条只开接口：外国机构不得在境内进行刑事诉讼活动，境内主体不得擅自向外国提供证据材料；不得写成已可径直向境外服务商整包调取。监察法（2024 修正）第十八条如实提供，不得伪造、隐匿、毁灭；外国特权不是中国法免交理由。律师法（2017 修订）第三十八条执业保密不是 ACP、不是对抗中国监管的免交。行政处罚法（2021）第三十二条交跨境表不等于从轻。刑法第一百六十二条之一只作红旗，不得指导删除境外或境内会计资料。不得把美国 FCPA、SOX 或 ACP 写成中国法义务。噪声：已失效《合同法》、总部即可全球调取、ACP 即免交、FCPA 即中国法、未经批准向外国执法提供境内个人信息、第 22 条套民企必须报跨境。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变独立法人效果、出境批准或向外国执法提供边界的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补跨境电子数据优先司法协助而非径直向境外调取、外国司法执法数据请求须主管机关批准、律师—客户特权不是现行中国法免交的实务反例。
- `search_case_by_fact` 只比较事实差异与翻转条件：境外母公司≠已可全球调取；集团指令≠境内授权；外国特权≠对抗中国检查。无类案不得写成已可全球调取或已免交。

工具不可用时继续法域切片和 `KJ#` 编目；独立法人、出境批准、施行日字段停止。不得拒跑，不得凭记忆写成总部即可全球调取、ACP 即免交或 FCPA 即中国法义务。

## 判断节点

执行顺序和停止条件以 [方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、跨境闸与不关窗

主成果才整案转出。双方秘密、隐匿境外证据、删除境外日志第一次停。总部即可全球调取、ACP 即免交不关窗。闸关仍交十节，第 6 节不出 `KJ#` 终稿。利益冲突未解不是整体停止。

### 2. 主体与法域切片

境内独立法人子公司／分公司／境外母公司／外国分支分列。公司法第十三条、个保法第四十一条、监察法第十八条分列强制接口。FCPA 只作外国法背景，该格不支持升格中国法义务。

### 3. 跨境闸与路径 `Q#`

本节禁止出 `KJ#` 终稿。有可编号碎片：闸打开或半开。无一可编号件才关闸，窗口不关。口头「总部全球一套」不得单独开闸。

### 4. 跨境行 `KJ#`

法域切片、证据或证人所在、境内可做、冲突点、涉外接口、数据接口分列。状态 `草案`。禁止升格已可全球调取、已免交、出境已合法。无 `E#` 不得写已调取。

### 5. 数据、涉外、收集与特权接口

出境方案转数据隐私。出口管制转涉外。境内收集转收集窗。特权终稿转工作产品窗。第 7 节不得夹带 `KJ#` 终稿或出境方案绕闸。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出隐匿境外证据、伪造无跨境、删除境外日志、阻挠合法检查、未经批准向外国执法提供存储于境内的数据或个人信息、打击报复。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无一可编号碎片：跨境闸关闭，仍交十节，不是整体停止。无书面调查授权但有可编号碎片：跨境闸部分打开，不是整体停止。利益冲突未解：不是整体停止。
- `字段停止`：独立法人效果、出境批准、个保法第四十一条、施行日未核验。境外母公司即可全球调取、外国特权即免交、FCPA 即中国法、境外证人必须出境调取、服务器必须镜像、外国律师函已阻断、集团程序即境内授权、交表即从轻：该格 `现有依据不支持` 或字段停止，窗口不关；闸已开仍出其他 `KJ#` 草案。催写零不关窗。
- `目标停止`：主目标变为出境方案、出口管制评估、调查报告、收集日志或落地对照终稿。

禁止指导隐匿境外证据或删除日志。不给胜诉率。不定罪。不保证免责。不选定机关。不代提交。未知不写零。不给出境传输方案。不写外国法结论。不教阻挠中国检查。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。跨境闸关闭仍交十节，第 6 节不出 `KJ#` 终稿，第 7 节不得出出境方案或外国法结论。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `KJ#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。跨境闸未打开时不得交付「已可全球调取」或「外国特权已免交」。边界见 [路由](references/routing.md)。
