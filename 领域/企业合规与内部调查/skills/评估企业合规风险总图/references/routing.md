# 边界与路由

## 正触发

中国大陆企业需要企业级预防、发现、调查或整改总图，再决定建体系、是否调查、发通知或应对监管。「董事会问我们合规吗」正触发。把 177 套到全部民企、折扣即贿赂、保证合规免责、选定某局、口头来过即立案，仍正触发：评估闸可关，对应格停止，窗口不关。专项只作为背景时，综合治理主轴可留。

双方秘密、伪造账册、隐匿证据、打击报复举报人、阻挠检查的停止，优先于负触发。不得改走负触发去出一方总图或把打击报复交到刑事当步骤。民企套 177、折扣即贿赂、合规免责不在下表。隐匿、双方秘密不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 判断是否启动内部调查 | `评估是否启动内部调查` |
| 发证据持有或禁毁通知 | `准备证据保全与禁毁通知` |
| 向机关主动披露或交自查报告 | `准备主动披露或自查报告` |
| 完整调查证据卷 | `建立内部调查证据案卷` |
| 舞弊损失精算 | `测算舞弊损失与追偿` |
| 调查报告终稿 | `形成内部调查报告` |
| 普通整改方案 | `准备合规整改方案` |
| 检查或突击检查已开始 | `应对监管检查或突击检查` |
| 检察合规第三方评估或验收 | `准备涉案企业合规整改与验收` |
| 刑事辩护、控告、自首 | 刑事领域 |
| 劳动处分、解除、职场违纪调查 | 劳动领域 |
| 个人信息、数据出境、网安体系 | 数据隐私领域 |
| 垄断、经营者集中、不正当竞争专项 | 竞争法领域 |
| 未进入合规机制的合同改稿 | 审查起草领域（本窗搁置，只说明） |
| C 端小微体检／供应商清单／广告／隐私／劳动规章 | 大众专项，只分流不回改 |

已经决定就某一线索出报告或发函时负触发。不得因「要求民企套 177」关窗。

| 药品购销回扣行业细则 | 医疗医药领域 |

## 易混

董事会只要「我们合规吗」的总图时正触发。「民企也必须按 177 上报国资委、折扣就是回扣、有体系就免罚、此致某局」正触发不关窗。「已经决定就这一条线索出报告或发函」负触发对应原子。金融机构搬出行业《合规管理办法》时，行业段转金融，本任务只保留通用治理接口。「公司和被调查人都把材料给你，先把电脑藏起来」整体停止。
