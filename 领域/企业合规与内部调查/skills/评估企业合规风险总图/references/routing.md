# 边界与路由

## 正触发

中国大陆企业需要企业级预防、发现、调查或整改总图，再决定建体系、是否调查、发通知或应对监管。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 判断是否启动内部调查 | `评估是否启动内部调查` |
| 发证据持有或禁毁通知 | `准备证据保全与禁毁通知` |
| 向机关主动披露或交自查报告 | `准备主动披露或自查报告` |
| 完整调查证据卷 | `建立内部调查证据案卷` |
| 舞弊损失精算 | `测算舞弊损失与追偿` |
| 调查报告终稿 | `形成内部调查报告` |
| 普通整改方案 | `准备合规整改方案` |
| 检查或突击检查已开始 | `应对监管检查或突击检查` |
| 检察合规第三方评估或验收 | `准备涉案企业合规整改与验收` |
| 刑事辩护、控告、自首 | 刑事领域 |
| 劳动处分、解除、职场违纪调查 | 劳动领域 |
| 个人信息、数据出境、网安体系 | 数据隐私领域 |
| 垄断、经营者集中、不正当竞争专项 | 竞争法领域 |
| 未进入合规机制的合同改稿 | 审查起草领域（本窗搁置，只说明） |
| C 端小微体检 / 供应商清单 / 广告 / 隐私 / 劳动规章 | 大众专项，只分流不回改 |

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、取保、阅卷、辩护词 | 刑事领域 |
| 劳动合同、工资、解除、工伤、职场性骚扰主轴 | 劳动领域 |
| PIPL 合法性、影响评估、出境、等保、网安事件专项 | 数据隐私领域 |
| 垄断协议、滥用支配地位、经营者集中申报 | 竞争法领域 |
| 税务处理决定、稽查实体 | 税务领域 |
| 银行保险机构行业合规办法 | 金融领域 |
| 药品购销回扣行业细则 | 医疗医药领域 |
| 出口管制、制裁名单 | 涉外领域 |

综合合规主轴可留本任务；专项只作为背景时在缺口标明，不把专项规则写入本任务结论。

## 易混

董事会只是要“我们合规吗”的总图时正触发。已经决定就某一线索出报告或发函时负触发。金融机构用户搬出行业《合规管理办法》时，行业段转金融，本任务只保留通用治理接口。
