# 边界与路由

## 正触发

中国大陆企业需要企业级预防、发现、调查或整改总图。从零、碎片、主体未核验、无书面评估授权仍正触发：有可编号主体、治理或红旗碎片则闸开或半开，出 `GT#` 草案，保持草案。本次不定罪、不保证免责、不发持有通知、不出调查报告是交付禁令，不是开窗条件。红旗即已构罪、制度即已有效、培训即已免责、民企套 177／42 号令、折扣即贿赂、未知写零，仍正触发。

双方秘密、销毁证据、串供、阻挠检查、打击报复的停止，优先于负触发。上述信号不在下表。不定罪不是负触发。「红旗即已违规或已构罪」「制度即已有效运转」「培训即已免责」「集团模板即已落地」不在下表。销毁串供不在下表，走整体停止。
