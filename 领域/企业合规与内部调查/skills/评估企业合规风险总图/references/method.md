# 评估企业合规风险总图方法

本文件是可执行判断节点。红旗不是已违规。红旗不是已构罪。制度文本不是已有效运转。培训记录不是已免责。集团模板不是已落地境内强制规则。公司法第一百七十七条只约束国家出资公司。明示折扣佣金如实入账不是商业贿赂。口头或已读不是已立案。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、已合规、已构罪、已免责、选定机关、代提交、未知写零。本任务不定罪，不发持有通知，不出调查报告。本窗闸名只能是合规闸，禁止复用评估闸、争议闸、侵权闸、调查闸、检查闸、启动闸。预留不得占用：立案闸、调查闸、检查闸。本窗 `GT#` 是合规总图行。主路径只用 `Q-风`，禁止用 `Q-总`、`Q-责`、`Q-合`、`Q-规`、`Q-图`、`Q-检`、`Q-预` 作主路径。英文 id 禁止使用，一律用中文技能名 `评估企业合规风险总图`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1993 年公司法第一百七十七条公积金条款、1993 年反不正当竞争法第八条、已失效《中央企业合规管理指引（试行）》、把红旗写成已构罪或把民企写成必须按 42 号令上报时记为噪声。禁止指导销毁证据、串供、打击报复或阻挠检查。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现义务簇或红旗碎片扫描，不是默认闭集。
`GT#` 固定列：`编号｜义务簇切片｜红旗与材料｜主体岗位｜专项分流｜打开接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。禁止合成「已合规」或「已构罪」。无 `E#` 不得写已合规、已立案、已贿赂、已免责。承认只进 `S#`／`D#`，不得占用 `A#`。主路径只用 `Q-风`。禁止 `ZT#`、`QG#`、`A#`、`N#`、`RF#`。预防／发现／调查／整改只作切片标签，不是主路径。

口头「有人来过」「已经合规了」「交了培训就能免责」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。

实务上：民企合规是治理安排，不得倒推必须报国资委。央企重大合规风险事件按 42 号令报告接口另核。折扣入账与账外暗中分列。

## 节点 0　分流、立场、合规闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、伪造账册、隐匿证据、串供、威胁证人、打击报复举报人、阻挠合法检查、指导销毁不进负表。利益冲突未解不进整体停止。不定罪、不保证免责、不发持有通知不是负触发。禁止把调查闸或检查闸写进本窗节点 0。

整案转出只交付第 1、2、10 节，不出 `GT#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是是否启动内部调查 | 负触发 `评估是否启动内部调查` |
| 主成果是发送版持有或禁毁通知 | 负触发 `准备证据保全与禁毁通知` |
| 主成果是主动披露或自查报告发送稿 | 负触发 `准备主动披露或自查报告` |
| 主成果是完整证据卷 | 负触发 `建立内部调查证据案卷` |
| 主成果是测算工作表 | 负触发 `测算舞弊损失与追偿` |
| 主成果是调查报告终稿 | 负触发 `形成内部调查报告` |
| 主成果是普通整改方案 | 负触发 `准备合规整改方案` |
| 主成果是检查或突击检查现场应对 | 负触发 `应对监管检查或突击检查` |
| 主成果是检察合规验收包 | 负触发 `准备涉案企业合规整改与验收` |
| 主成果是刑事辩护、控告或自首 | 整案转刑事 |
| 主成果是劳动处分或职场违纪调查 | 整案转劳动 |
| 主成果是数据出境或网安专项 | 整案转数据隐私 |
| 主成果是垄断或不正当竞争专项 | 整案转竞争法 |
| 尚未进入合规机制，只要改合同或出稿 | 整案转审查起草（本窗搁置，只说明不实施） |
| 「不定罪」「不保证免责」「不发持有通知」 | 交付禁令，不是负触发 |

出现「调查」「整改」「检查」一词不是转出。综合治理主轴可留，专项段只分流。

合规闸打开（可出 `GT#` 草案，仍不得标「已合规／已构罪／已免责」）须同时满足：单方无冲突立场已闭合；主成果是企业级合规风险总图，不是调查报告、不是持有通知、不是整改验收、不是检查现场应对；至少一项可编号主体、治理或红旗碎片。口头「已经合规了」不算单独开闸材料。

合规闸部分打开：已有碎片，但主体范围、施行日或红旗定性未闭合；对应格待核；仍交十节。无书面评估授权但单方立场已闭合且已有碎片：合规闸部分打开，仍交十节，不是整体停止。

合规闸关闭（仍正触发）：无一可编号碎片。「今天必须出已合规／已构罪终稿」而无最小碎片不得开闸。不出 `GT#` 终稿。**仍交十节**，第 5 节只交闸／`Q#`，第 6 节不出 `GT#` 终稿，**第 7 节不得出调查报告、持有通知或整改验收**。禁止因闸关闭只交第 1、2、10 节或改走负触发。

「红旗即已违规或已构罪」「制度即已有效运转」「培训即已免责」「集团模板即已落地」「民企套第一百七十七条或 42 号令」「折扣即贿赂」「合规即可免责」「口头来过即立案」「未知写零」「选定某局」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `GT#` 草案。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一可编号碎片，then 合规闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，或两造争同一份总图，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造账册、隐匿证据、串供、威胁证人、打击报复举报人、阻挠合法检查或指导销毁，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体、治理坐标与制度版本

一行一个主体或义务簇切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `GT#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 主体 | 企业名称变体、是否国家出资公司／中央企业分列 | 名称不一致自动合并；民企写成必须报国资委 |
| 制度 | 章程、办法、集团模板冲突并列 | 纸面升格已有效运转；集团模板升格已落地 |
| 红旗 | 线索、账簿、接触点分列 | 红旗升格已违规或已构罪 |

检索锚点（写入 `L#` 前须核验）：公司法第一百六十八条、第一百七十七条。中央企业合规管理办法第二条适用范围、第二十二条重大合规风险应对与报告、第四十条地方国资参照。反不正当竞争法 2025 第八条；噪声 1993 年反法第八条、1993 年公司法第一百七十七条公积金。行政处罚法第三十二条。刑法第一百六十四条只开红旗。

## 节点 3　总图行 `GT#`

按已出现义务簇或红旗碎片扫描，不是默认闭集。每条须能指向义务簇、红旗、主体岗位或专项分流之一。

无 `E#` 不得写已合规、已立案、已贿赂或已免责。状态默认 `草案`。一次只推荐下一步。未知不写零。

热冲突强制处理：

- 红旗即已构罪／制度即已有效／培训即已免责／集团模板即已落地／民企套 177／折扣即贿赂／未知写零 → 该格不支持或字段停止；仍出其他 `GT#`。
- 无一碎片 → 关闸，不出 `GT#` 终稿，窗口不关。
- 指导销毁、串供、隐匿、阻挠检查 → 整体停止，不是该格不支持。

## 节点 4　调查、检查、整改与披露接口

第 7 节只开接口，不得夹带 `GT#` 终稿、调查报告或持有通知绕闸。闸关闭时第 7 节可写「闸未开，转介待义务簇编号」，不得补写已合规。不选定机关。不代提交。不定罪。

下一步只转介：`评估是否启动内部调查`、`准备证据保全与禁毁通知`、`建立内部调查证据案卷`、`应对监管检查或突击检查`、`准备合规整改方案`、`建立合规义务与责任主体地图`、`评估反商业贿赂风险点`、`评估国企合规管理办法差距`、`评估董监高合规职责缺口`、`评估行业叠加义务并分流`、`评估集团与子公司合规穿透`、`评估合规管理体系有效性`、`设计合规管理体系框架`、`准备主动披露或自查报告`、`形成内部调查报告`、`配置合规机构与三道防线`、`制定突击检查现场预案`。禁止此致某局。

若 if 用户催促「红旗就是贿赂／培训完就能免责／民企也必须报国资委／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「合规闸与合规总图草案」。本窗不执行发送。不包含：调查报告、持有通知、整改验收、已合规证明、已构罪。禁止选边治愈。禁止红旗即已构罪。禁止制度即已有效。禁止指导销毁或阻挠检查。合规闸打开 ≠ 已合规 ≠ 已免责 ≠ 应调查。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标总图终稿已形成。

## 场景对抗（运行时自检，不写入用户可见闭集）

场景①：民企销售有返点，集团发了英文合规手册，做过一次培训签到。用户主张红旗已经是贿赂、手册落地了所以境内已合规、培训完就能免责、民企也必须按 42 号令报国资委、不清楚的金额先写零、去某局自首。合规闸打开或半开。`Q-贿`、`Q-合`、`Q-培`、`Q-套`、`Q-零`、`Q-院` 不打开为可靠路径。第 6 节不得把已贿赂、已合规、已免责、0、选定机关写入可执行 `GT#`；对应格 `现有依据不支持` 或字段停止；仍出义务簇分列、主体范围红旗、折扣入账接口、专项分流等其他 `GT#`。不关窗。不定罪。不选定机关。

场景②：用户同时交出公司「必须写成已合规」与被调查销售「从未拿回扣」口径，并指导「账外笔记本先烧掉、统一口径」。命中双方秘密＋销毁／串供。第一次整体停止。只交第 1、10 节。不出 `GT#`。不得问代表哪一方后继续。不以「坚持」为门槛。不得给替代违法方案。
