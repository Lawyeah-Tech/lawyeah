# 评估方法

本文件是可执行判断节点，不是栏目说明书。每个会改变分流、红旗定性、机关路径或下一步的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出胜诉率、必然免责、必然行政处罚、刑事既遂或唯一必得追偿总额。

`search_law` 返回已失效《合同法》《民法通则》《民法总则》或其解释时记为噪声，不得写入 `L#`。MCP 将 2025 修订《反不正当竞争法》标为尚未施行但公布施行日为 2025-10-15 的，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

## Q# 矩阵

固定列：`编号｜义务簇｜场景｜法律或政策效果｜成立条件｜支持事实｜不利事实｜控制方｜最强反方｜主备位｜判断｜待核`。

预防机制缺口、发现机制缺口、已发生红旗事件、整改失效分列。同一事实支持多项时分别说明效果，不重复金额。管理不规范不等于商业贿赂，更不等于单位犯罪。

## 节点 0　专项分流

先于实体判断。命中任一项且该专项是**主要成果**则整案转出，本任务只交付分流理由和最小交接，不填总体评估十节实体结论。

| 信号 | 转出 |
| --- | --- |
| 侦查、审查起诉、审判、取保、阅卷、辩护、刑事控告 | 刑事领域 |
| 劳动合同、工资工时、解除劳动合同、工伤、职场性骚扰主轴 | 劳动领域 |
| 个人信息合法性基础、影响评估、数据出境、等保、网安事件专项体系 | 数据隐私领域 |
| 垄断协议、滥用市场支配地位、经营者集中申报 | 竞争法领域 |
| 税务处理、稽查实体、偷逃税认定 | 税务领域 |
| 银行保险机构行业《合规管理办法》主轴 | 金融领域 |
| 药品购销回扣、医疗反腐行业细则主轴 | 医疗医药领域 |
| 出口管制、制裁名单、境外经营准入 | 涉外领域 |
| 尚未进入合规机制，只要改交易合同或出稿 | 审查起草领域（本窗搁置，只说明不实施） |
| 章程、股东会、股权结构本身 | 公司治理领域 |

混合信号：综合合规治理主轴可留本任务；专项只作为背景时在缺口标明，不把专项规则硬套进本任务结论。C 端小微体检只要第一轮清单：负触发，只分流。

## 节点 1　主体、治理坐标和制度版本

1. 固定企业名称、统一社会信用代码、注册地、实际经营地、控股股东/实际控制人、并表子公司。名称不一致不自动合并。
2. 治理表记录党委/董事会/经理层/合规负责人/业务部门/监督部门。国资委令第 42 号第 8、9、13 条只对中央企业及参照适用的地方国企作为对照，不得写成全部民营企业法定义务。
3. 公司法第一百七十七条仅约束国家出资公司“加强内部合规管理”。对民营企业，内部合规是治理安排和风险控制，不是同一条的法定义务；不得用该条倒推民企董事会违法。
4. 制度版本表并列章程、合规管理办法、举报制度、礼品招待、第三方管理、授权清单。冲突并列，不选对用户有利的一版冒充唯一文本。
5. 同时掌握相互冲突的双方秘密或立场不明：整体停止策略输出。

## 节点 2　义务簇与红旗事件

每个 `Q#` 先写法律或政策效果，再写成立条件。禁止合成“合规风险”一笔。

默认主位候选按事实分别建立：

- `Q-预` 预防机制（政策、培训、审批、隔离）是否可运行
- `Q-发` 发现机制（举报、监测、审计）是否可触发
- `Q-查` 已出现线索是否达到内部调查启动红旗（只留接口，不代替启动闸原子）
- `Q-贿` 商业贿赂 / 账外暗中候选（须分账）
- `Q-利` 利益冲突 / 关联交易廉洁面
- `Q-三` 第三方或中间人失控
- `Q-账` 账簿记录不完整或虚假报销
- `Q-改` 已知事件后整改是否闭合
- `Q-机` 监管检查、监察、检察合规路径

### 2.1 商业贿赂分账

运行时核验 2025 修订《反不正当竞争法》第八条。核验失败则本节点贿赂法律结论停止，事实清单继续。

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 存在折扣、返点或佣金 | 已构成商业贿赂 |
| 有礼品或招待 | 必然违法 |
| 员工个人收钱 | 必然视为经营者行为 |
| 匿名举报 | 回扣已查实 |

工作人员贿赂原则上可归入经营者行为；但经营者有证据证明与谋取交易机会或竞争优势无关的，单列抗辩，判断用三态，不提前锁定。明示折扣/佣金且双方如实入账，不得直接写成回扣。账外暗中候选须指向未在依法账簿按制度明确记载。

2025-10-15 前发生且未持续的行为，适用修改前文本（通常为 2019 修正第七条）。行为跨越施行日：记录冲突，分别建情景，不给唯一条文。

### 2.2 刑事与监察红旗

出现公职人员、国有单位人员、大额账外资金、伪造账册或已有监察/公安问询：标红旗并转介刑事或检查应对原子。本任务不得写“已构成第 164 条犯罪”或“监察对象必然被留置”。

## 节点 3　第三方、公职接触和集团穿透

1. 第三方表：经销商、代理、中介、顾问、供应商。记录引入人、报酬结构、实际受益人。报酬去向不明标 `G#`，不写成已贿赂。
2. 公职接触表：许可、执法、招标、国企采购。接触不等于行贿。
3. 集团穿透：子公司是否被总部机制覆盖；境外实体只标涉外接口，不写当地法结论。
4. 上市公司出现内控或关联方红旗：只留披露接口，不写公告正文。

---

## 节点 4　机关路径、期限和后果区间

分别判断：内部整改、监管检查、主动披露、检察合规、民事追偿、劳动程序、刑事程序。本任务不写这些文书。

- 国资企业重大合规风险事件是否需向国资监管报告：对照第 42 号令第二十二条，主体不适用则整行删除，不写“建议比照上报”。
- 检查或监察文书送达日缺失：期限字段停止。口头“有人来过”不得写成已立案。
- 后果分项：监管罚款区间（规则未核验则停止）、民事追偿区间、商誉/资格、刑事红旗。未知不写零。不得输出“交了整改就能免罚”。

---

## 节点 5　证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在。

下一步按以下顺序，且必须标可逆性：

1. 证据可能灭失 → 转介持有通知，本任务不出发送稿；
2. 检查已开始 → 转介检查应对；
3. 线索达到调查闸 → 转介启动评估；
4. 需要数字 → 转介测算；
5. 需要事实结论 → 转介调查报告；
6. 需要整改动作 → 转介整改方案。

用户坚持今天发出披露或持有通知终稿：目标停止，转介相应原子。

首次要求伪造账册、隐匿电脑、威胁证人、打击报复举报人或阻挠合法检查：该部分整体停止，不提供方法。
