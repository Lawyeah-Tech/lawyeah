# 评估方法

本文件是可执行判断节点。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态只用 `草案`、`评估闸关闭`、`提交前待核`、`停止`。禁止胜诉率、必然免责、必然行政处罚、刑事既遂、唯一必得追偿总额、唯一截止日、选定机关或法院、代提交、未知写零。本任务不定罪，不发通知，不出报告。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》《民法通则》《民法总则》、1993 年公司法第一百七十七条公积金条款、1993 年反不正当竞争法第八条直接当现行、把 177 或 42 号令套到全部民企时记为噪声，不得写入 `L#`。反不正当竞争法 2025 修订第八条施行日为 2025-10-15；MCP 若仍标尚未施行，以公布施行日为准并记录冲突。禁止指导伪造账册、隐匿证据、威胁证人、打击报复或阻挠检查。

`Q#` 固定列：`编号｜义务簇（预防／发现／调查接口／整改／商业贿赂候选／利益冲突／第三方／账簿／机关路径）｜场景｜法律或政策效果｜成立条件｜支持事实｜不利事实｜控制方｜最强反方｜主备位｜判断三值｜待核｜来源回链`。按已出现事实扫描，不是默认闭集。管理不规范不等于商业贿赂，更不等于单位犯罪。同一事实支持多项时分别说明效果，不重复金额。

口头「有人来过」、已读只进 `S#`／`V#`，不得升格 `R#` 已立案或期限已起算。

## 节点 0　分流、立场、评估闸与不关窗

整案转出或闸关闭只交付第 1、2、10 节或标注停止的 `Q#`，不得交付总图终稿、「已合规」或发送版。专项只作为背景时综合治理主轴可留，专项段只分流。

| 信号 | 处理 |
| --- | --- |
| 主成果是是否启动内部调查 | 负触发 `评估是否启动内部调查` |
| 主成果是发送版持有或禁毁通知 | 负触发 `准备证据保全与禁毁通知` |
| 主成果是主动披露或自查报告 | 负触发 `准备主动披露或自查报告` |
| 主成果是调查报告终稿 | 负触发 `形成内部调查报告` |
| 主成果是普通整改方案 | 负触发 `准备合规整改方案` |
| 主成果是检查现场应对 | 负触发 `应对监管检查或突击检查` |
| 主成果是检察合规验收包 | 负触发 `准备涉案企业合规整改与验收` |
| 侦查、审查起诉、审判、取保、阅卷、辩护、刑事控告为主成果 | 整案转刑事；综合治理主轴可留时刑事段只红旗 |
| 劳动合同、工资工时、解除、工伤、职场性骚扰为主成果 | 整案转劳动 |
| 个人信息、数据出境、等保、网安事件专项体系为主成果 | 整案转数据隐私 |
| 垄断协议、滥用支配地位、经营者集中申报为主成果 | 整案转竞争法 |
| 税务处理、稽查实体为主成果 | 整案转税务 |
| 银行保险机构行业合规办法为主成果 | 整案转金融；通用治理接口可留 |
| 药品购销回扣行业细则为主成果 | 整案转医疗医药 |
| 出口管制、制裁名单、境外经营准入为主成果 | 整案转涉外 |
| 章程、股东会、股权结构本身为主成果 | 整案转公司治理 |
| 尚未进入合规机制，只要改交易合同 | 审查起草本窗搁置 |
| C 端小微体检只要第一轮清单 | 负触发，只分流 |

评估闸打开（可出 `Q#` 草案，仍不代提交、不保证免责）须同时满足：单方无冲突立场与授权；主成果是企业级总图，不是调查报告、持有通知、整改验收、刑辩或专项终稿；拟交付不含定罪、合规即可免责、177 套全部民企、折扣即贿赂、选定机关、发送版。

闸关闭（仍正触发）：把 177 或 42 号令写成全部民企法定义务；折扣佣金如实入账写成已构成商业贿赂；保证合规即可免责或免罚；选定某局；口头来过即立案；管理不规范即单位犯罪。闸未开则仍只交 1、2、10 节。

「民企套 177」「折扣即贿赂」「合规即可免责」「选定机关」「口头来过即立案」**不关窗**。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，或两造争同一份总图且未获冲突豁免，then 整体停止，不得选边治愈，也不得改走负触发。
若 if 提出伪造账册、隐匿电脑或证据、威胁证人、打击报复举报人、阻挠合法检查，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体、治理坐标和制度版本

1. 固定企业名称、统一社会信用代码、注册地、实际经营地、控股股东／实际控制人、并表子公司。名称不一致不自动合并。
2. 治理表记录党委／董事会／经理层／合规负责人／业务部门／监督部门。
3. 检索锚点：公司法（2023 修订）第一百七十七条，国家出资公司应当依法建立健全内部监督管理和风险控制制度，加强内部合规管理。对民营企业，内部合规是治理安排和风险控制，不是同一条的法定义务；不得用该条倒推民企董事会违法。1993 年第一百七十七条公积金条款是噪声。
4. 《中央企业合规管理办法》（国资委令第 42 号）适用于国资委履行出资人职责的中央企业；第四十条，地方国有资产监督管理机构参照本办法，指导所出资企业。不得写成全部民营企业必须向国资委报告重大合规风险事件。主体不适用则 42 号令对照行删除，不写「建议比照上报」。展开转 `评估国企合规管理办法差距`。
5. 制度版本表并列章程、合规管理办法、举报制度、礼品招待、第三方管理、授权清单。冲突并列，不选对用户有利的一版冒充唯一文本。

## 节点 2　义务簇与红旗事件 `Q#`

每个 `Q#` 先写法律或政策效果，再写成立条件。禁止合成「合规风险」一笔。按已出现事实扫描。

默认主位候选（有事实才打开）：

- `Q-预` 预防机制（政策、培训、审批、隔离）是否可运行
- `Q-发` 发现机制（举报、监测、审计）是否可触发
- `Q-查` 已出现线索是否达到内部调查启动红旗（只留接口，不代替 `评估是否启动内部调查`）
- `Q-贿` 商业贿赂／账外暗中候选（须分账）
- `Q-利` 利益冲突／关联交易廉洁面
- `Q-三` 第三方或中间人失控
- `Q-账` 账簿记录不完整或虚假报销
- `Q-改` 已知事件后整改是否闭合
- `Q-机` 监管检查、监察、检察合规路径

### 2.1 商业贿赂分账

检索锚点：反不正当竞争法 2025 修订第八条（施行日 2025-10-15）。经营者不得采用给予财物或其他手段贿赂交易相对方工作人员、受委托办理事务者、利用职权或影响力影响交易者，以谋取交易机会或竞争优势；明示折扣、佣金应当如实入账；工作人员贿赂原则上认定为经营者行为，但经营者有证据证明与谋取交易机会或竞争优势无关的除外。施行日前未持续的行为适用修改前文本（通常为 2019 修正第七条）。行为跨越施行日：记录冲突，分别建情景，不给唯一条文。展开转 `评估反商业贿赂风险点`／`评估回扣账外暗中与资金链路`。

| 已能支持的事实 | 不得写成 |
| --- | --- |
| 存在折扣、返点或佣金且如实入账 | 已构成商业贿赂 |
| 有礼品或招待 | 必然违法 |
| 员工个人收钱 | 必然视为经营者行为 |
| 匿名举报 | 回扣已查实 |
| 管理不规范 | 已构成单位犯罪 |

明示折扣／佣金且双方如实入账，该贿赂格 `现有依据不支持` 或待核，窗口不关。账外暗中候选须指向未在依法账簿按制度明确记载。

### 2.2 刑事与监察红旗

出现公职人员、国有单位人员、大额账外资金、伪造账册或已有监察／公安问询：标红旗并转介，本任务不得写「已构成刑法第一百六十四条犯罪」或「监察对象必然被留置」。

## 节点 3　第三方、公职接触和集团穿透

1. 第三方表：经销商、代理、中介、顾问、供应商。记录引入人、报酬结构、实际受益人。报酬去向不明标 `G#`，不写成已贿赂。
2. 公职接触表：许可、执法、招标、国企采购。接触不等于行贿。
3. 集团穿透：子公司是否被总部机制覆盖；境外实体只标涉外接口，不写当地法结论。转 `评估集团与子公司合规穿透`。
4. 上市公司出现内控或关联方红旗：只留披露接口，不写公告正文。转 `评估上市公司廉洁与内控交叉`。

## 节点 4　机关路径、期限和后果区间

分别判断：内部整改、监管检查、主动披露、检察合规、民事追偿、劳动程序、刑事程序。本任务不写这些文书。

- 中央企业重大合规风险事件是否需向国资委报告：对照 42 号令第二十二条，主体不适用则整行删除。
- 检查或监察文书送达日缺失：期限字段停止。口头「有人来过」不得写成已立案。
- 后果分项：监管罚款区间（规则未核验则停止）、民事追偿区间、商誉／资格、刑事红旗。未知不写零。不得输出「交了整改就能免罚」。不选定某局或某院。

## 节点 5　证据、反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口和最晚时点。不能因对方控制而推定材料存在或内容有利。

下一步按以下顺序，且必须标可逆性；本窗只转介，不出发送稿：

1. 证据可能灭失 → `准备证据保全与禁毁通知`
2. 检查已开始 → `应对监管检查或突击检查`
3. 线索达到调查闸 → `评估是否启动内部调查`
4. 需要数字 → `测算舞弊损失与追偿`
5. 需要事实结论 → `形成内部调查报告`
6. 需要整改动作 → `准备合规整改方案`

用户要今天发出披露或持有通知终稿：目标停止，转介相应原子。第 9 节不得写成发送或立案指令。

## 再执行清单

每个节点结束后回写：来源编号、判断状态、最强反方、是否字段停止。不得跳过评估闸直接给合规免责、177 套民企、折扣即贿赂或已立案。

若 if 日期、送达或动态规则未核验，then 依赖该规则的期限和法律结论字段停止，不编造唯一截止日。
若 if 金额参数不足，then 该行标未知，禁止写零。
若 if C 端只要大众准备包，then 只分流不回改。

判断状态只许三值。口头转述、截图和「已读」不得写成已受理、已送达、已立案或期限已起算。

## 本任务回链纪律

本任务成果是「不代提交的企业合规风险总图」。必须包含：评估闸；177 不套全部民企；折扣入账不是贿赂；不定罪；不保证免责。不包含：调查报告、持有通知、整改验收、刑辩、劳动处分、数据或竞争专项终稿。禁止选边治愈。禁止把民企套 177、折扣即贿赂、合规免责写成负触发或整体停止（伪造、隐匿、打击报复除外）。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标总图终稿已形成。
若 if 相邻专项已打开且用户改要该专项终稿，then 目标停止，交付最小交接。
风险档 A：隐匿证据、打击报复、阻挠检查必须单独标可逆性。
