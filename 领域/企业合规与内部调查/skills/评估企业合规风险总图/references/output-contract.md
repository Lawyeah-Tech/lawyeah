# 输出合同

按触发结果选择交付形状。评估闸未打开不得交付总图终稿或「已合规」。禁止把 177 或 42 号令写成全部民企法定义务。禁止折扣入账即贿赂。禁止合规即可免责。禁止选定机关。禁止口头来过即立案。禁止选边治愈。不定罪。不代提交。未知不写零。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 评估闸关闭或节点 0 整案转出 | 第 1、2、10 节。禁止发送版、免责结论。综合治理可留时不得因专项背景整案转出 |
| 整体停止 | 第 1、10 节。禁止 `Q#` 策略包、选边、隐匿或打击报复步骤。双方秘密、伪造账册、隐匿证据、打击报复举报人、阻挠检查第一次即停，优先于负触发；无选边治愈，无「坚持」门槛 |
| 用户要民企套 177、折扣即贿赂、合规免责、选定某局、口头来过即立案（不关窗） | 十节表头可出现；对应格填 `现有依据不支持` 或字段停止；闸未开则仍只交 1、2、10；不得改走负触发关窗；不得标总图终稿 `已形成` |
| 正触发且闸开 | 下列十节表头均出现；未核验格填待核；禁止为填满而写已合规、已构罪或选定机关 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入总图终稿已形成。双方秘密未解不得进入「部分形成」。每个 `Q#` 必须带来源和判断三值。`L#` 不得直接抄技能内条号。177 套民企、折扣即贿赂若返回则记噪声。稿件状态默认 `草案`。

## 1. 触发、单方立场、授权与成果状态

谁要总图。评估闸是否打开。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。不定罪。不保证免责。稿件默认 `草案`。

## 2. 来源登记与 MCP 调用表

`S/D/A/R/C/L/I/G/Q/V/E`。口头来过、已读只登记 `S#`／`V#`。MCP 未调用也留一行。噪声命中须登记。施行日与 MCP 效力标签冲突须记录。

## 3. 主体、治理坐标和专项分流

企业、控制关系、是否国家出资公司或中央企业、董监高、合规负责人。177／42 号令主体范围待核。刑事／劳动／数据／竞争等分流结果。专项只接口时综合治理可留。

## 4. 已确认、争议及缺失事实时间线

线索、检查、问询分列。口头不得升格已立案。

## 5. 义务簇与红旗事件矩阵 `Q#`

完整固定列。预防、发现、调查接口、整改分列。主备位和互斥必须可见。管理不规范不等于商业贿赂或单位犯罪。

## 6. 机关路径、期限待核表

检查、监察、检察合规、民事、劳动、刑事分列。每种期间单独一行。送达不明则该行停止。不选定某局。不写死唯一截止日。

## 7. 金钱或非金钱后果区间和测算接口

未知不写零。不输出唯一必得总额。不定罪。不保证免责或免罚。测算终稿转介。

## 8. 关键证据、冲突和最强反方

不能因对方控制而推定内部材料有利。不利事实必须入表。

## 9. 下一步与转介

只点名：启动调查、持有通知、披露、调查报告、整改、检查应对。不打开则填 `不打开`。禁止发送指令、披露指令、出报告指令。不代提交。

## 10. 缺口、停止项与提示

须列对方最强解释：民企也必须按 177／42 号令上报国资委、折扣佣金就是回扣、有合规体系就一定免罚、管理不规范就是单位犯罪、微信已读检查通知就算立案、此致某局、两边材料选边、先把电脑藏起来、对举报人秋后算账。

本成果不是调查报告、不是持有通知、不是整改验收、不是证据卷、不是发送版、不给胜诉率、不是「已合规」。不代提交。不定罪。
