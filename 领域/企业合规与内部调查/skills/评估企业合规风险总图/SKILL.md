# 评估企业合规风险总图

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《民法通则》《民法总则》或其解释当作现行规则。不得把 1993 年公司法第一百七十七条公积金条款、1993 年反不正当竞争法第八条直接当现行。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成不代提交的企业级合规风险总图：评估闸、主体与治理坐标、`Q#` 义务簇与红旗（预防／发现／调查接口／整改，扫描不是闭集）、专项分流、期限与机关路径待核、后果区间、证据缺口和下一步转介。不定罪。不保证合规免责或免罚。不发持有通知、不出调查报告、不写整改验收包。不选定监管机关或法院。不写死唯一截止日。未知金额不写零。

`depends-on` 为空。是否立案调查转 `评估是否启动内部调查`。持有禁毁通知转 `准备证据保全与禁毁通知`。主动披露转 `准备主动披露或自查报告`。调查报告转 `形成内部调查报告`。整改方案转 `准备合规整改方案`。检查已开始转 `应对监管检查或突击检查`。检察合规验收转 `准备涉案企业合规整改与验收`。国企 42 号令差距展开转 `评估国企合规管理办法差距`。商业贿赂点展开转 `评估反商业贿赂风险点`。

## 工作边界

正触发：中国大陆企业需要企业级预防、发现、调查或整改总图，再决定建体系、是否调查、发通知或应对监管。「董事会问我们合规吗」正触发。把公司法第一百七十七条套到全部民企、把民企写成必须按 42 号令上报国资委、把折扣佣金写成已构成商业贿赂、保证合规即可免责或免罚、选定某局、口头来过或已经立案即起算、管理不规范即单位犯罪，仍正触发：错误主张只关对应格，有可编号主体则评估闸仍可开出 `Q#` 草案，窗口不关，不得改走负触发，不得标总图终稿已形成。刑事、劳动、数据、竞争等只作为背景时，综合治理主轴可留，专项段只分流。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是是否启动内部调查（转 `评估是否启动内部调查`）；
- 主成果是发送版持有或禁毁通知（转 `准备证据保全与禁毁通知`）；
- 主成果是主动披露或自查报告发送稿（转 `准备主动披露或自查报告`）；
- 主成果是调查报告终稿（转 `形成内部调查报告`）；
- 主成果是普通整改方案（转 `准备合规整改方案`）；
- 主成果是检查或突击检查现场应对（转 `应对监管检查或突击检查`）；
- 主成果是检察合规第三方评估或验收包（转 `准备涉案企业合规整改与验收`）；
- 主成果是刑事辩护、控告或自首（转刑事领域）；
- 主成果是劳动处分、解除劳动合同或职场违纪调查（转劳动领域）；
- 主成果是个人信息、数据出境或网络安全专项体系（转数据隐私领域）；
- 主成果是垄断协议、经营者集中或不正当竞争专项评估（转竞争法领域）；
- 尚未进入合规机制，只要改交易合同或出稿（审查起草搁置）；
- C 端小微体检只要第一轮清单（只分流）。

民企套 177、折扣即贿赂、合规即可免责、选定机关、口头来过即立案**不在负触发表**，窗口不关。双方秘密、伪造账册、隐匿电脑、威胁证人、打击报复举报人、阻挠合法检查**不在负触发表**，走整体停止。

## 建立工作坐标

确认：使用者与授权；单方立场（公司／被调查对象／合规负责人，互斥）；企业及控制关系；行业与监管条线；是否国家出资公司或中央企业；董监高和合规负责人；已知线索；法域；当前检查、诉讼、监察或刑事状态。

口头「有人来过」「已经立案」「微信已读检查通知」只登记 `S#`／`V#`。不得升格已立案、已送达或期限已起算。用户坚持「民企也必须按 177／42 号令上报国资委」「交了整改一定免罚」不构成打开该格的授权。

同时掌握公司与被调查对象相互冲突的秘密，或两造同时交材料争同一份总图：`整体停止`，不得以选边治愈，也不得改走负触发。公司已开口且委托范围就是总图、且未掌握被调查对象秘密时，可推定公司立场。只要同时掌握双方秘密，无例外整体停止。提出伪造账册、隐匿电脑或证据、威胁证人、打击报复举报人、阻挠合法检查：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 内部制度或合同条款；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 风险／处置假设；`V#` 评估版本；`E#` 发送／送达凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。稿件状态只用 `草案`、`评估闸关闭`、`提交前待核`、`停止`。技能正文中的条号是检索锚点，不是已核验 `L#`。本任务默认 `草案`，不代提交。禁止「合规即可免责」「已构成商业贿赂」「已构成单位犯罪」「此致某局」。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：国家出资公司应当依法建立健全内部监督管理和风险控制制度，加强内部合规管理；《中央企业合规管理办法》适用于国资委履行出资人职责的中央企业，地方国资监管机构可参照指导所出资企业，不得写成全部民营企业法定义务；经营者不得采用财物或其他手段贿赂以谋取交易机会或竞争优势，明示折扣、佣金应当如实入账；工作人员贿赂原则上可认定为经营者行为，但与谋取交易机会或竞争优势无关的抗辩待核。技能正文条号不是 `L#`。噪声：1993 年公司法第一百七十七条公积金条款当现行合规义务、1993 年反不正当竞争法第八条直接当现行、把 177 或 42 号令套到全部民企、折扣佣金如实入账即回扣、合规即可免责或免罚、口头来过即立案、管理不规范即单位犯罪、选定某局、未知写零。反不正当竞争法 2025 修订第八条施行日为 2025-10-15；MCP 若仍标尚未施行，以公布施行日为准并记录冲突。施行日前未持续的行为适用修改前文本（通常为 2019 修正第七条）。不可用则 177 适用范围、42 号令主体、商业贿赂定性、期限字段停止。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变 177 适用范围、42 号令主体、商业贿赂定性或期限结论的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补明示入账折扣不当然贿赂、管理混乱不等于单位犯罪、内控可作抗辩但不是免责金牌的实务反例。
- 特殊事实用 `search_case_by_fact`，只比较差异，不写成必然免责或必然构罪。

工具不可用时继续主体、治理、事件和 `Q#` 编目；法律结论、期限、机关路径字段停止。不得凭记忆写成民企负 177 法定义务、折扣即贿赂、合规即可免责或已立案。

## 判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、评估闸与不关窗

刑事、劳动、数据、竞争、税务、金融、医药、涉外：主成果才整案转出。综合治理主轴可留，专项只接口。双方秘密、隐匿、打击报复第一次停。民企套 177、折扣即贿赂、合规免责不关窗。主成果是调查报告或持有通知才负触发。

### 2. 主体、治理坐标和制度版本

名称变体不合并。177 只对国家出资公司。42 号令不对全部民企。制度冲突并列，不选对用户有利的一版。

### 3. 义务簇与红旗 `Q#`

按已出现事实扫描，不是默认闭集。预防、发现、调查接口、整改分列。管理不规范不等于商业贿赂，更不等于单位犯罪。

### 4. 机关路径、期限和后果区间

检查、监察、检察合规、民事、劳动、刑事分列。送达不明则期限停止。未知不写零。不保证免罚。不选定机关。

### 5. 证据与转介

不能因对方控制而推定内部材料有利。第 9 节只转介，不发通知、不出报告、不写发送版。

## 停止与安全

- `整体停止`：立场或授权不明；双方秘密未解；公司与被调查对象同时交材料；基础主体无法建立；提出伪造账册、隐匿电脑或证据、威胁证人、打击报复举报人、阻挠合法检查。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。
- `字段停止`：法域、施行日、177／42 号令主体范围、商业贿赂定性、动态规则、机关文书送达未核验。评估闸未开则终稿停止，窗口不关。用户要民企套 177、折扣即贿赂、合规即可免责、选定某局、口头来过即立案、未知写零则该格停止，窗口不关。
- `目标停止`：主目标变为发通知、出报告、精算、整改验收或程序文书。民企套 177、折扣即贿赂、合规免责不在目标停止。

禁止指导伪造、隐匿、威胁、打击报复或阻挠检查。不给胜诉率。不定罪。不保证免责或免罚。不选定机关或法院。不代提交。不编唯一截止日。不把未知写成零。
