# 评估企业合规风险总图

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、举证和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在明确、无利益冲突的单方立场下，形成“企业合规风险总体评估矩阵”：主体与治理坐标、义务簇、红旗事件、专项分流、期限与机关路径待核、金额或后果区间、证据缺口、对方或监管最强解释和下一步。

`depends-on` 为空。接受用户、律师、内审、机关或其他来源的等价事实、制度清单和线索。

## 工作边界

正触发：中国大陆企业需要企业级预防、发现、调查或整改总图，再决定建体系、查案、发通知或应对监管。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只要调查报告终稿、持有通知或主动披露发送稿；
- 只要整改验收包或检察合规第三方材料；
- 主成果是刑事辩护、控告或自首；
- 主成果是劳动处分、解除劳动合同或职场违纪调查；
- 主成果是个人信息、数据出境或网络安全专项体系；
- 主成果是垄断协议、经营者集中或不正当竞争专项评估；
- 尚未进入合规机制，只要改交易合同或出稿（审查起草领域，本生产线搁置，只说明不实施）。

本任务不生成发送版通知、调查结论、可提交诉状或行政处罚复议材料，不给胜诉率或“合规即可免责”。

## 建立评估坐标

确认：使用者与授权；单方立场；企业及控制关系；行业与监管条线；董监高和合规负责人；已知线索或事件；法域；当前检查、诉讼、监察或刑事状态；关键材料及缺失。

同时掌握公司与被调查对象相互冲突的秘密时，先停止策略输出，澄清代表哪一方。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 内部制度或合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 风险／处置假设；`V#` 评估版本；`E#` 发送／送达／履行凭证。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验国企合规办法、公司法内部合规条款、商业贿赂、监察配合义务；`search_practiced` 补路径与反例；特殊事实用 `search_case_by_fact`。不虚构监管系统。

工具不可用时继续主体、治理、事件和问题清单；法律结论、期限、机关路径字段停止。

## 五个判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 专项分流、主体和治理坐标

先做刑事、劳动、数据、竞争、金融、税务、医药、涉外分流，再固定企业主体、控制关系、董事会/经理层/合规部门职责。不得把公司法第一百七十七条写成全部民营企业的同一法定义务。

### 2. 义务簇与红旗事件

按预防、发现、调查、整改分列义务簇。每件红旗事件独立编号，不把“管理不规范”写成已构成商业贿赂或单位犯罪。

### 3. 账簿、第三方和公职接触面

明示折扣/佣金与账外暗中分账。第三方、中间人、公职接触点单独列表。行业专项只留接口。

### 4. 机关路径、期限和后果区间

检查、监察、检察合规、民事追偿、劳动、刑事分列。期限未核验则停止。未知金额不写零。

### 5. 证据、最强反方和下一步

证据矩阵列待证事实、支持与不利、控制方、合法取得、缺口。下一步按证据灭失、机关期限、可逆性排序。发送持有通知、披露、出报告标为转介。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；基础主体无法建立；用户坚持伪造、隐匿、威胁、打击报复或违法取证。
- `字段停止`：法域、施行日、动态规则、机关文书送达未核验。
- `目标停止`：主目标已变为发通知、出报告、精算、整改验收或程序文书。
