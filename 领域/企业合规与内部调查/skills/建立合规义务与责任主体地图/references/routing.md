# 边界与路由

## 正触发

公司需要一张可更新的综合合规义务与责任主体地图。制度不齐、岗位空缺、规则未核验、无书面地图授权仍正触发：地图闸关闭，不出 `O#` 终稿，窗口不关。保证免责、穷尽清单、民企或参股套 177 或 42 号令、列出义务＝已合规、内部政策覆盖未核验法律，仍正触发。

双方秘密、伪造义务表、伪造授权、倒签任命、指导删除会计资料、借已有监察文书平行灭证、打击报复的停止，优先于负触发。上述信号不在下表。「保证免责」「穷尽清单」「民企或参股套 177 或 42 号令」「内部政策覆盖未核验法律」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 企业级风险总图 | `评估企业合规风险总图` |
| 已有体系是否运转 | `评估合规管理体系有效性` |
| 董监高合规职责缺口终稿 | `评估董监高合规职责缺口` |

| 集团与子公司穿透终稿 | `评估集团与子公司合规穿透` |
| 42 号令差距对照终稿 | `评估国企合规管理办法差距` |
| 从零设计体系框架 | `设计合规管理体系框架` |
| 三道防线岗位配置 | `配置合规机构与三道防线` |
| 单件线索或违规认定 | `评估是否启动内部调查` |

不得因「要求写成穷尽」或「要求合规免责」关窗。岗位空缺仍正触发，不得写成已覆盖。

## 易混

列出「禁止商业贿赂」不等于已经发生回扣。内部礼品制度不是反法第八条已覆盖。挂名合规负责人不是实际授权。民企或参股套 42 号令或公司法第一百七十七条：该格不支持，不关窗，不转出。地方国企不得仅因第四十条自动套 42 号令。无人认领不是已覆盖。口头全覆盖不是开闸材料。「先补假授权再出图」整体停止。扫描不是闭集。
