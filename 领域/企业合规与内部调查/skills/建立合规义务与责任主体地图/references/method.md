# 评估方法

本文件是可执行判断节点。本任务扫描不是闭集，列出义务不是已合规，也不是违规已成立。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止胜诉率、必然免责、刑事既遂、唯一截止日、选定机关、代提交、穷尽闭集、未知写零。本任务不定罪，不重写全部制度。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回已失效《合同法》、1993 年公司法第一百七十七条公积金、1993 年第一百八十条公益金、1993 年第一百九十一条清算、1993 年反法第八条、把 42 号令套全部民企、把列出义务写成已合规时记为噪声。MCP 将 2025 修订《反不正当竞争法》标为尚未施行但公布施行日为 2025-10-15 的，以施行日为准并记录冲突。禁止指导伪造义务表或删除会计资料。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`O#` 固定列：`编号｜义务簇｜规则锚点｜效果假设｜责任岗位｜授权来源｜控制活动｜证据形态｜更新触发｜状态｜判断三值｜最强反方｜待核`。禁止合成「合规义务」一笔。`E#` 只作证据形态回链（岗位授权、监管函送达凭证），禁止 `N#`／`EV#`／`M#`／`F#`／`ACT#`／`P#`／`K#`。

口头「制度很全」「岗位都有人」只进 `S#`／`V#`，不得升格已覆盖或已合规，**不得算作开闸所需的义务簇或岗位**。拟制日＝本次形成本任务成果之日。

## 节点 0　分流、立场、地图闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。伪造义务表、伪造授权、倒签任命、指导删除会计资料、借已有监察／检查文书平行灭证、打击报复、双方秘密不进负表。

整案转出只交付第 1、2、10 节，不出 `O#` 终稿。

| 主成果是已有体系是否运转 | 负触发 `评估合规管理体系有效性` |
| 主成果是董监高职责缺口终稿 | 负触发 `评估董监高合规职责缺口` |
| 主成果是行业叠加整案分流 | 负触发 `评估行业叠加义务并分流` |

| 主成果是 42 号令差距终稿 | 负触发 `评估国企合规管理办法差距` |

| 尚未进入合规机制，只要改合同 | 审查起草本窗搁置 |
| 章程、股权、公司决议本身为主成果 | 公司治理领域 |

审查起诉、监管检查只作程序背景，**不是**转出信号。主成果才整案转。混合信号：综合合规义务地图主轴可留本任务；专项只作为背景时在缺口标明。

地图闸打开（可出 `O#` 草案，仍不得标「已穷尽／已合规／已免责」，仍不代提交）须同时满足：单方无冲突公司立场已闭合；主成果是义务—主体地图，不是总图、有效性、董监高缺口终稿、行业专项整案或违规认定；至少一项可编号义务簇、内部政策文本或书面岗位／授权。口头全覆盖不算开闸材料。双方秘密或第一次伪造义务表／授权不是关闸条件，走整体停止。

地图闸部分打开：主体或规则未闭合，但已有可编号内部政策或书面岗位；对应格待核；仍交十节；不得标终稿 `已形成`。挂名合规负责人无实际授权：可半开，授权来源 `依据不足`。

地图闸关闭（仍正触发）：公司立场已闭合但无书面地图授权；无一义务簇且无一书面岗位。「今天必须交穷尽清单」而无最小事实不得开闸。不出 `O#` 终稿。**仍交十节**，第 5 节只交闸／`Q#` 状态，第 6 节不出 `O#` 终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「已全覆盖」或「没有义务」。

「保证合规免责」「穷尽全部法定义务」「民企或参股必须按 177 或 42 号令全表达标上报」「列出义务＝已合规或违规已成立」「内部政策覆盖未核验法律」「无人认领写成已覆盖」「折扣即贿赂」「第一百八十条必得追偿」「第一百九十一条对内追偿当然依据」「交了地图即应当从轻」**不关窗**。对应格 `现有依据不支持`。闸已开仍出其他 `O#` 草案，不得因错误主张扣掉整张表。闸未开才不出 `O#` 终稿。民企或参股套 42 号令不得负触发到 `评估国企合规管理办法差距`。

若 if 立场或委托无法闭合，then 整体停止。
若 if 公司立场已闭合但无书面地图授权，then 地图闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出伪造义务表、伪造授权、倒签任命、指导删除会计资料、借已有监察／检查文书平行灭证或打击报复，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　主体、出资属性与适用规则

名称、统一社会信用代码、并表范围不一致：不自动合并，先建主体表。

检索锚点（写入 `L#` 前须核验）：

- 公司法（2023 修订）第一百六十八条：国家出资公司＝国家出资的国有独资公司、国有资本控股公司；**不含参股**。
- 第一百七十七条：国家出资公司应当依法建立健全内部监督管理和风险控制制度，加强内部合规管理。只约束国家出资公司对内合规，不是对外自查或向国资委交稿；不得倒推民企董事会违法或必须达标上报。
- 中央企业合规管理办法（国资委令第 42 号）：适用于国资委履行出资人职责的中央企业。第四十条是对地方国资机构的参照指导，不是民企或地方国企自动承受同一法定义务；地方是否参照＝地方细则待核。主体不适用则对照行删除。
- 第一百八十条：董监高忠实、勤勉；控股股东、实际控制人实际执行公司事务的适用前两款。只开高管追偿接口，不是必得公式。缺口终稿转 `评估董监高合规职责缺口`。
- 第一百八十八条：执行职务违反法律、行政法规或章程给**公司**造成损失的赔偿，与对外赔偿分列。
- 第一百九十一条（条号运行时核验）：执行职务给**他人**造成损害的对外赔偿接口，不得写成对内追偿当然依据。噪声：1993 年第一百九十一条清算。
- 反不正当竞争法（2025 修订）第八条，施行日 2025-10-15：明示折扣、佣金双方应当如实入账，不是贿赂。工作人员贿赂原则上认定经营者行为，无关抗辩待核。

分列主体，不得合并：中央企业（国务院国资委履行出资人职责，核验后 42 号令对照行可建）；国家出资公司（独资／控股，不含参股，177 只约束对内合规，不是向国资委交稿）；国有资本参股（有国资 ≠ 国家出资公司，177 与 42 号令对照行删除）；地方国企（第四十条不是自动适用 42 号令）；民营企业（177 与 42 号令不得写成法定义务行，要求按 42 号令穷尽列表仍正触发，该格 `现有依据不支持`，不转出）。

## 节点 3　义务行 `O#`

每条 `O#` 必须能回答：谁必须做什么、依据哪条已核验或待核规则、用什么控制、留下什么证据、什么事件触发复核。禁止合成「合规义务」一笔。

若规则未核验：该行法律效果字段停止，仍可列用户陈述的内部政策行并标 `C#`。内部政策与法律冲突：两行并列，冲突写入最强反方。不得用内部政策覆盖未核验法律。

责任岗位与授权清单冲突时并列，不选对用户有利的一版。岗位撤销、借调、外包或「兼管」：记控制方缺口。无人认领记 `G#`，不得写成已覆盖。不把董事会写成经办岗位。挂名合规负责人无实际授权：授权来源 `依据不足`，不得升格已覆盖。

红旗只标「待核场景」，不得写成某次商业贿赂或单位犯罪已成立。用户要本表认定违规：目标停止，转介 `评估是否启动内部调查`。

刑法第一百六十二条之一隐匿、故意销毁会计凭证、会计账簿、财务会计报告只作红旗，**不得指导删除**。监察法第十八条如实提供，不得伪造、隐匿、毁灭。已有监察或检查文书，不得借做地图平行灭证；提出即整体停止。行政处罚法第三十二条条件须核验，提交本表不等于从轻或减轻已成就。

## 节点 4　更新触发、专项接口与转介

默认更新触发分列：法律公布／施行、监管函送达、组织架构生效、重大事件结案、并购交割。送达日缺失：期限字段停止，不写「应已更新」。口头尽快、电话、已读、快递揽收只进 `S#`／`V#`，不得起算法定更新日，不得升格 `R#` 已送达。口头备份不等于已保全，不得把 `E#` 写成已覆盖。

行业专项（数据、反垄断、金融、医药、税务、涉外）只留接口行，不填专项结论。董监高缺口、穿透、总图、有效性、三道防线只开接口。

下一步只转介邻居，禁止提交指令。用户要求本任务认定违规、重写全部制度或出穷尽闭集：目标停止或对应格不支持。

## 本任务回链纪律

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标义务地图终稿已形成。
