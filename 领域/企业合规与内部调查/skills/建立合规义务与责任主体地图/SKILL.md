# 建立合规义务与责任主体地图

## 任务目标

在明确、无利益冲突的单方立场下，形成可更新的义务—主体地图草案：地图闸、主体与出资属性、`Q#` 路径、`O#` 义务行（效果／岗位／控制／证据／更新触发）、行业专项与董监高接口。扫描不是闭集。列出义务不是已合规，也不是某次违规已成立。不重写全部制度，不替代单件调查或有效性评价，不保证合规免责，不代提交。

`depends-on` 为空。只要总图转 `评估企业合规风险总图`。有效性判断转 `评估合规管理体系有效性`。董监高职责缺口终稿转 `评估董监高合规职责缺口`。行业叠加整案转 `评估行业叠加义务并分流`。集团穿透终稿转 `评估集团与子公司合规穿透`。确为中央企业且主成果是 42 号令差距对照终稿才转 `评估国企合规管理办法差距`；民企或参股要求按 42 号令列表仍正触发，该格 `现有依据不支持`。从零设计框架转 `设计合规管理体系框架`。三道防线配置转 `配置合规机构与三道防线`。

## 工作边界

正触发：公司需要一张可更新的综合合规义务与责任主体地图，而不是判断某次违规、重写体系或做专项整案。制度文本不齐、岗位空缺、规则未核验、无书面地图授权仍正触发：地图闸关闭，不出 `O#` 终稿，窗口不关。用户要保证合规免责、穷尽全部法定义务、民企或参股按公司法第一百七十七条或 42 号令必须全表达标并上报、把内部政策写成已覆盖未核验法律、把列出义务写成已合规或违规已成立、把提交地图写成应当从轻，仍正触发：该格填 `现有依据不支持`，窗口不关；闸已开仍出其他 `O#` 草案。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主成果是企业级风险总图（转 `评估企业合规风险总图`）；
- 主成果是已有体系是否运转（转 `评估合规管理体系有效性`）；
- 主成果是董监高合规职责缺口终稿（转 `评估董监高合规职责缺口`）；
- 主成果是行业叠加整案分流（转 `评估行业叠加义务并分流`）；
- 主成果是集团与子公司穿透终稿（转 `评估集团与子公司合规穿透`）；
- 主成果是 42 号令差距对照终稿（转 `评估国企合规管理办法差距`）；
- 主成果是从零设计体系框架（转 `设计合规管理体系框架`）；
- 主成果是三道防线岗位配置（转 `配置合规机构与三道防线`）；
- 主成果是单件线索是否启动调查或违规认定（转 `评估是否启动内部调查`）。

双方秘密、伪造义务表、伪造授权或倒签任命、指导删除会计资料、借已有监察文书平行灭证、打击报复**不在负触发表**，走整体停止。「保证免责」「穷尽清单」「民企或参股套 177 或 42 号令」「列出义务＝已合规」「内部政策覆盖未核验法律」「交地图即从轻」**不在负触发表**，该格 `现有依据不支持`，窗口不关；闸已开仍出其他 `O#` 草案。

## 建立工作坐标

确认：地图授权；单方立场（公司／被调查对象，互斥）；被建图主体（集团／境内实体／是否国家出资公司或中央企业）；组织图与岗位授权；现行政策清单；已知监管函。

口头「制度很全」「岗位都有人」「已经全覆盖」只登记 `S#`／`V#`。不得升格义务已覆盖、已合规或违规已成立，**不得算作开闸所需的义务簇或岗位**。已读、微信已读、电话、口头尽快、快递揽收只进 `S#`／`V#`，不得升格 `R#` 已送达，不得起算法定更新日。口头备份不等于已保全。

同时掌握公司与被调查对象相互冲突的秘密：`整体停止`，不得选边，不得问代表哪一方后继续。公司已开口且委托就是义务地图、且未掌握对方秘密时，可推定公司立场。无书面地图授权但公司立场已闭合：地图闸关闭，仍交十节，不是整体停止。提出伪造义务表、伪造授权、倒签任命、指导删除会计资料、借已有监察文书平行灭证或打击报复：第一次提出即整体停止，不以「坚持」为门槛。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`R#` 机关或生效文书；`C#` 内部制度或合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口；`Q#` 路径；`O#` 义务行；`V#` 版本；`E#` 证据形态回链（岗位授权、监管函送达凭证，不是到达／案卷）。禁止 `N#`（通知／披露正文）、`EV#`、`M#`、`F#`、`ACT#`、`P#`、`K#`。技能正文中的条号是检索锚点，不是已核验 `L#`。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。禁止合成「合规义务」一笔。扫描不是闭集。未知不写零。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例检索。本窗是评估类地图，**不要**用文书范本检索生成「已覆盖／已合规」清单。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现义务与岗位错配；案例只比较事实差异与翻转条件，不写成必然结果。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《民法通则》《民法总则》或其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成可处理部分；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law` 核验将被写入 `L#` 的现行规则：公司法（2023 修订）第一百六十八条国家出资公司是国有独资公司、国有资本控股公司，**不含参股**；第一百七十七条仅约束国家出资公司应当依法建立健全内部监督管理和风险控制制度、加强内部合规管理，不是对外自查或向国资委交稿义务，不得套全部民企。中央企业合规管理办法（国资委令第 42 号）适用于国资委履行出资人职责的中央企业；第四十条是对地方国资机构的参照授权，不得写成民企或地方国企自动承受同一法定义务。第一百八十条忠实勤勉是高管追偿接口，不是必得公式。第一百九十一条（条号运行时核验）是执行职务给他人造成损害的对外赔偿接口，不得写成对内追偿当然依据；噪声：1993 年公司法第一百九十一条清算条款。反不正当竞争法（2025 修订）第八条：明示折扣或佣金双方应当如实入账，不是贿赂；工作人员贿赂原则上认定经营者行为，但无关抗辩待核；施行日 2025-10-15。MCP 将 2025 反法标「尚未施行」但公布施行日为 2025-10-15 的，以施行日为准并记录冲突。个保法第十三条人力资源管理所必需，不等于全员邮箱、私人微信或定位当然授权。行政处罚法第三十二条条件成立时应当从轻或减轻，**提交义务地图本身不等于情节成就**。监察法第十八条如实提供，不得伪造、隐匿、毁灭；已有监察文书不得借做地图平行灭证。噪声：已失效《合同法》、1993 年公司法第一百七十七条公积金、1993 年第一百八十条公益金、1993 年反法第八条当现行、42 号令套民企、折扣即贿赂、列出义务即已合规或已免责、交地图即从轻、穷尽闭集。
- 已有真实 `regulation_id` 且宿主暴露 `get_law_detail` 时，核验将改变国家出资公司范围、42 号令适用或商业贿赂入账规则的正文再写入 `L#`。不得编造 `regulation_id`。
- `search_practiced` 补义务与岗位错配、挂名合规负责人无授权、内部政策覆盖未核验法律的反例。
- `search_case_by_fact` 只比较事实差异与翻转条件（如岗位挂名≠实际授权），不写成必然已合规、必然免责或必然违规。

工具不可用时继续主体、岗位和 `O#` 编目；主体义务范围、期限、机关路径字段停止。不得拒跑，不得凭记忆写成民企必须适用 42 号令、列出义务即已合规或保证免责。

## 判断节点

执行顺序和停止条件以 [评估方法](references/method.md) 为准。这里只列入口，不代替节点。

### 1. 分流、立场、地图闸与不关窗

主成果才整案转出。伪造义务表或授权第一次停。保证免责、穷尽清单、民企或参股套 177 或 42 号令不关窗：该格不支持，闸已开仍出其他 `O#`。闸关仍交十节，第 6 节不出 `O#` 终稿。扫描不是闭集。

### 2. 主体、出资属性与适用规则

集团／境内实体／国家出资公司／中央企业分列。名称与并表范围不一致不自动合并。主体不适用则对照行删除，不倒推民企董事会违法。

### 3. 地图闸与路径 `Q#`

本节禁止出 `O#` 终稿。无一义务簇且无一书面岗位则闸可关，窗口不关。口头「岗位都有人」不得开闸。

### 4. 义务行 `O#`

一条义务一行。规则未核验则法律效果字段停止，仍可列内部政策行并标 `C#`。内部政策与法律冲突两行并列。无人认领记 `G#`，不得写成已覆盖。

### 5. 更新触发、专项接口与转介

法律公布／施行、监管函、组织变更、并购交割分列。送达日缺失则期限字段停止。行业专项、董监高缺口、穿透、总图、有效性只开接口。

## 停止与安全

- `整体停止`：立场或委托无法闭合；双方秘密未解；提出伪造义务表、伪造授权、倒签任命、指导删除会计资料、借已有监察文书平行灭证或打击报复。整体停止优先于负触发。不以「坚持」为门槛。第一次提出即停。不得选边治愈。无书面地图授权但公司立场已闭合：不是整体停止，地图闸关闭，仍交十节。
- `字段停止`：42 号令主体、施行日、动态规则、机关文书送达未核验。保证免责、穷尽清单、民企或参股套 177 或 42 号令、列出义务＝已合规、内部政策覆盖未核验法律、交地图即从轻：该格 `现有依据不支持`，窗口不关；闸已开仍出其他 `O#` 草案；闸未开才不出 `O#` 终稿。
- `目标停止`：主目标变为总图、有效性终稿、董监高缺口终稿、行业专项整案、制度全文或违规认定。

禁止指导伪造义务表或删除会计资料。不给胜诉率。不定罪。不保证免责。不选定机关。不代提交。未知不写零。

## 交付

严格按 [输出合同](references/output-contract.md) 交付。地图闸关闭仍交十节，第 6 节不出 `O#` 终稿。不关窗主张仍交十节，该格不支持，闸已开仍出其他 `O#`。节点 0 整案转出只交第 1、2、10 节。整体停止只交第 1、10 节。地图闸未打开时不得交付义务地图终稿或「已穷尽／已合规」。边界见 [路由](references/routing.md)。
