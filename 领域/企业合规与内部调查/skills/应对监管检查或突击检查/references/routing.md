# 边界与路由

## 正触发

检查已开始或检查通知已到达，需要现场和首轮应对。证件不全、范围有争议、人员已在现场仍正触发：检查闸可关或只开最小必要配合，不出可交材料终稿，窗口不关。保证过关、今天必须交完、选定某局、口头尽快当截止日，仍正触发。

双方秘密、阻挠合法检查、毁证、伪证、藏匿、关门藏物、指导拒绝出示合法证件后的检查，优先于负触发。上述信号不在下表。「保证过关」「今天必须交完」不在下表。

## 负触发

| 主要目标 | 路由 |
| --- | --- |
| 尚未发通知的完整现场预案 | `制定突击检查现场预案` |
| 交卷清单与特权日志终稿 | `准备向监管提交材料与特权日志` |
| 主动书面披露或自查 | `准备主动披露或自查报告` |
| 整改方案 | `准备合规整改方案` |
| 行政复议或行政诉讼文书 | 行政争议领域 |
| 税务稽查实体 | 税务领域 |
| 刑事侦查辩护、取保、阅卷 | 刑事领域 |

已经决定就某一线索出复议状或刑事辩护时负触发。不得因「要求今天交完」或「要求保证过关」关窗。不得因「证件还没看清」负触发吞掉本窗；证件争议只关对应格，现场纪律可留。人员已在现场不关书面披露接口。

## 专项整案转出

| 主轴信号 | 路由 |
| --- | --- |
| 侦查、起诉、审判、阅卷、辩护、自首材料为主成果 | 刑事领域 |
| 劳动合同、解除、工伤或日常处分决定主轴 | 劳动领域 |
| PIPL、出境、等保、网安专项 | 数据隐私领域 |
| 垄断、滥用支配、经营者集中 | 竞争法领域 |
| 税务稽查实体 | 税务领域 |

综合检查应对主轴可留本任务。监察文书出现时配合义务可留，职务犯罪辩护整案转刑事。

## 必转介接口

| 信号 | 转介 |
| --- | --- |
| 尚未发通知的预案 | `制定突击检查现场预案` |
| 交卷与特权 | `准备向监管提交材料与特权日志` |
| 披露 | `准备主动披露或自查报告` |
| 整改 | `准备合规整改方案` |
| 律师工作产品 | `评估律师工作产品与保密边界` |
| 检察合规 | `准备涉案企业合规整改与验收` |
| 复议诉讼 | 行政争议领域 |
| 税务实体 | 税务领域 |
| 刑事侦查 | 刑事领域 |

## 易混

「明天可能来检查」且尚未发通知：最小现场纪律可留本窗，完整预案走 `制定突击检查现场预案`。「先把电脑藏起来再谈证件」整体停止，不是负触发。「证件没出示所以可以关门」不关窗：记录异议、最小必要配合，不教藏匿；若已下达藏匿指令则整体停止。口头「尽快」不是法定截止日。已读不是送达。
