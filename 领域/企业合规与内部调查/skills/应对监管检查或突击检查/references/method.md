# 评估方法

本文件是可执行判断节点。本任务不阻挠合法检查，不教藏匿，不写复议诉讼文书。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。材料状态只用 `可交`、`扣下`、`待核`、`停止`。禁止胜诉率、必然过关、唯一截止日、选定机关、代提交、未知写零。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 2017 年行政处罚法第三十七条不经核验当 2021 条号、1996 年第三十二条当出示证件规则、1993 年反法第十八条，或把不出示证件写成可以关门藏物时记为噪声。MCP 将 2025 修订《反不正当竞争法》标为尚未施行但公布施行日为 2025-10-15 的，以施行日为准并记录冲突。

`K#` 固定列：`编号｜文书｜作出日｜送达／到达待核｜送达方式｜期间类型｜截止字段状态｜来源`。口头「尽快」不得写入截止。
`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持｜不利｜互斥／转介｜状态｜待核`。

口头「尽快交」、已读、快递发出只进 `S#`／`V#`，不得升格已送达或期限已起算。

## 节点 0　分流、立场、检查闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。阻挠、毁证、藏匿不进负表。

整案转出只交付第 1、2、10 节，不出可交材料终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是尚未发通知的完整预案 | 负触发 `制定突击检查现场预案` |
| 主成果是交卷清单与特权日志终稿 | 负触发 `准备向监管提交材料与特权日志` |
| 主成果是书面披露或自查 | 负触发 `准备主动披露或自查报告` |
| 主成果是整改方案 | 负触发 `准备合规整改方案` |
| 主成果是复议或行政诉讼文书 | 整案转行政争议 |
| 主成果是税务稽查实体 | 整案转税务 |
| 主成果是刑事侦查辩护、取保、阅卷 | 整案转刑事 |
| 数据专项体系主轴 | 整案转数据隐私 |
| 垄断／经营者集中主轴 | 整案转竞争法 |

检查闸打开（可出可交材料草案，仍不得标「已过关」，仍不代提交）须同时满足：单方无冲突立场与现场授权；主成果是现场与首轮应对，不是预案、交卷终稿、披露、复议或刑事辩护；已有到场人员或已到达的检查通知／文书；无双方秘密、无第一次阻挠／毁证／藏匿信号。

检查闸部分打开：证件或文书未完全闭合，但人员已在现场或已有通知表面；对应格待核；只做最小必要配合；仍交十节；不得标终稿 `已形成`。

检查闸关闭（仍正触发）：无一证件、无一文书、无人到场且通知未到达。「今天必须交完」而无最小事实不得开闸。不出可交材料终稿。**仍交十节**，第 5 节只交闸／`Q#` 状态，第 6 节不出可交材料终稿。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「可以不配合」或「已经过关」。

「保证过关或免罚」「今天必须交完」「选定某局」「口头尽快当截止日」「未出示证件就可以拒绝后关门」**不关窗**。对应格 `现有依据不支持` 或字段停止。未出示证件：记录异议，最小必要配合，**不教关门藏物**。人员已在现场不关窗。

若 if 使用者与授权或单方立场无法闭合，then 整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出阻挠合法检查、毁证、伪证、藏匿、拖延销毁、关门藏物、指导拒绝出示合法证件后的检查、已有监察文书仍要求借现场平行灭证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　证件、文书与现场纪律

记录：姓名、单位**类型**（不选定某局）、执法证或监察证编号、文书名称、检查范围、起止、在场人数。执法人员不得少于两人并出示证件（检索锚点：行政处罚法 2021，条号运行时核验）。监察措施另核监察法第四十四条：出示证件、书面通知、二人以上。

信息不全：书面记录异议和要求补正，同时避免肢体冲突。**不得**输出关门、藏物、拔网线、格式化。指定唯一对接人；禁止擅自接受采访式闲聊；禁止销毁。

监察调查与市场监管行政检查分账。监察文书出现：配合义务按监察法第十八条核验，本窗不变成职务犯罪辩护。

## 节点 2　检查闸与路径扫描

本节禁止出可交材料终稿。

| 编号 | 打开信号 | 本任务允许 | 禁止 | 转介 |
| --- | --- | --- | --- | --- |
| `Q-检` | 到场或通知已到 | 检查闸状态 | 无人无文书仍出可交终稿；今天交完即开闸 | 留本任务 |
| `Q-证` | 证件／文书争议 | 异议记录＋最小必要配合 | 不出示证件＝关门藏物 | 留本任务 |
| `Q-交` | 要交材料 | 可交／扣下／待核分列 | 临时做假账；范围外整包交出 | `准备向监管提交材料与特权日志` |
| `Q-律` | 律师备忘录 | 扣下并写理由 | 虚构美国式特权；业务文件因律师在场免交 | `评估律师工作产品与保密边界` |
| `Q-数` | 全员通讯录／私人微信／定位 | 合法基础待核 | 检查即授权个保第 13 条覆盖 | 数据隐私 |
| `Q-期` | 出现答复期限 | `K#` 一行一类 | 口头尽快当法定日；已读起算 | 留本任务 |
| `Q-监` | 监察 `R#` | 如实提供红旗 | 平行灭证、选择性不交 | 刑事（主成果才整案转出） |
| `Q-税` | 税务稽查实体 | 只打红旗 | 本窗写税务实体结论 | 税务 |
| `Q-救` | 要复议诉讼 | 只开接口 | 本窗出复议状 | 行政争议 |
| `Q-整改` | 检查后要整改 | 只开接口 | 本窗出整改终稿 | `准备合规整改方案` |
| `Q-预` | 尚未发通知 | 最小纪律可留 | 本窗出完整预案终稿 | `制定突击检查现场预案` |

检索锚点：行政处罚法出示证件与不得阻挠；监察法第十八条；反法 2025 第十六条、第十七条。先行登记保存七日不得写入内部期限。

## 节点 3　材料与期限

原件提交记副本。与检查范围无关的个人信息、其他客户商业秘密、律师工作产品：`扣下` 并写理由。不得临时制作假账补交。已核实可交；猜测标待核；未知不写零。

每份通知／决定单独一张 `K#`。期间类型一行一类：`责令改正期限`／`陈述申辩期限`／`先行登记保存期限`（只待核，不得改写内部期限）／`内部响应时点`（标明非法定）。作出日、送达日、送达方式分列。未核验则截止字段停止。口头电话、已读、快递揽收不是送达。

---

## 节点 4　口径与后续

已回答问题登记：问句、答句、是否超出范围、是否待核。禁止承诺未核验的犯罪构成或保证过关。

后续只开接口：整改、披露、交卷特权、检察合规、行政救济。人员已在现场：书面披露仍可转介，本窗现场纪律可留。不等于已经过关、已验收或已获从轻。

---

## 再执行清单

每个节点结束后回写：来源、判断、最强反方、是否字段停止。不得跳过检查闸直接给可交终稿。

若 if 证件或文书未核验，then 权限与期限字段停止，最小必要配合，不教藏匿。
若 if 已有监察 `R#`，then 不得借现场完成清理或选择性不交。

## 本任务回链纪律

本任务成果是「检查闸、权限核验、现场纪律与材料分列草案」。不包含：复议状、税务实体结论、刑事辩护、整改终稿、披露发送稿、完整未通知预案。禁止指导阻挠或藏匿。禁止倒签。禁止选边治愈。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标可交材料终稿已形成。
风险档 A：阻挠、毁证、藏匿必须单独标可逆性；提出即整体停止。
