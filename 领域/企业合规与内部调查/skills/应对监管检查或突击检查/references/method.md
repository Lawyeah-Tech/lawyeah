# 应对监管检查或突击检查方法

本文件是可执行判断节点。拒绝接受调查不是授权关门、藏匿或销毁。未出示执法证件不是可以关门藏物。口头尽快不是法定截止日。已读不是送达。快递揽收不是送达。草稿不是已提交。先行登记保存七日不是企业内部期限。最小必要配合不是已过关。扣下不是藏匿。待核不是拖延合法检查。律师在场不是美国式特权。电话预约不是检查已开始。判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。闸状态只用 `打开`、`部分打开`、`关闭`。路径状态只用 `打开接口`、`不打开`、`待核`。材料状态只用 `可交`、`扣下`、`待核`、`停止`。禁止胜诉率、已过关、已提交、选定机关、代提交、未知写零。本任务不定罪，不保证过关，不阻挠合法检查，不教藏匿。本窗闸名只能是检查闸，禁止复用交卷闸、预案闸、评估闸、应对闸、验收闸。预留不得占用：立案闸、调查闸。本窗 `XR#` 是现场应对行。`K#` 只作期限辅行。主路径只用 `Q-检`，禁止用 `Q-交`、`Q-预`、`Q-风`、`Q-启`、`Q-监`、`Q-证`、`Q-总` 作主路径。英文 id 禁止使用，一律用中文技能名 `应对监管检查或突击检查`。

技能正文和本文件中的条号是检索锚点，不是已核验 `L#`。`search_law` 返回 1996 年行政处罚法第五十五条违法处罚责任、2017 年第三十七条、1996／2017 年第三十二条陈述申辩、2018 年监察法第四十一条、1993 年反法第十八条、把拒绝接受调查写成可以关门藏物时记为噪声。禁止指导阻挠、藏匿、毁证或关门。

`Q#` 固定列：`编号｜路径｜法律效果假设｜成立条件｜支持事实｜不利事实｜互斥／转介｜状态｜待核`。按已出现事实扫描，不是默认闭集。
`XR#` 固定列：`编号｜来人与文书切片｜证件与权限异议｜材料（可交／扣下／待核）｜打开接口｜E#回链｜判断三值｜G#｜最强反方｜状态`。状态默认 `草案`。无 `E#` 不得写已过关、已提交、已送达。承认只进 `S#`／`D#`，不得占用 `A#`。
`K#` 固定列：`编号｜文书｜作出日｜送达／到达待核｜送达方式｜期间类型｜截止字段状态｜来源`。不得升主行。口头「尽快」不得写入截止。
主路径只用 `Q-检`。禁止 `A#`、`N#`、`K#`、`SL#`、`YU#`、`F#` 作主行。

口头「尽快交」「已经过关了」「微信已读」只进 `S#`／`V#`，**不得单独算作开闸材料**。拟制日＝本次形成本任务成果之日。稿件状态默认 `草案`。来人只写单位类型，不选定某局。

实务上：不出示证件时记录异议、最小必要配合，不教关门。已出示合法证件仍拒绝配合是阻挠。查封扣押须清单。监察文书出现按第十八条如实提供，本窗不变成职务犯罪辩护。

## 节点 0　分流、立场、检查闸与不关窗

节点 0 只做三件事：专项整案转出、立场闸、不关窗。双方秘密、阻挠、毁证、伪证、藏匿、拖延销毁、关门藏物、指导拒绝合法检查、平行灭证不进负表。利益冲突未解不进整体停止。不定罪、不保证过关、不代提交、不阻挠合法检查不是负触发。禁止把交卷闸、预案闸、启动闸写进本窗节点 0。

整案转出只交付第 1、2、10 节，不出 `XR#` 终稿。

| 信号 | 处理 |
| --- | --- |
| 主成果是尚未发通知的完整现场预案，或仅电话预约、人未到场且书面通知未送达 | 负触发 `制定突击检查现场预案` |
| 主成果是交卷清单与特权日志终稿 | 负触发 `准备向监管提交材料与特权日志` |
| 主成果是主动书面披露或自查 | 负触发 `准备主动披露或自查报告` |
| 主成果是整改方案 | 负触发 `准备合规整改方案` |
| 主成果是检察合规验收包，或夹带过验收／保证不起诉 | 负触发 `准备涉案企业合规整改与验收` |
| 主成果是律师工作产品标记专项终稿 | 负触发 `评估律师工作产品与保密边界` |
| 主成果是行政复议或行政诉讼文书 | 整案转行政争议 |
| 主成果是税务稽查实体 | 整案转税务 |
| 主成果是刑事侦查辩护、取保或阅卷 | 整案转刑事 |
| 数据专项体系主轴 | 整案转数据隐私 |
| 垄断／经营者集中主轴 | 整案转竞争法 |
| 「不定罪」「不保证过关」「不代提交」「不阻挠合法检查」 | 交付禁令，不是负触发 |

出现「检查」一词不是转出。人员已在现场：书面披露仍可转介，本窗现场纪律可留。

检查闸打开（可出 `XR#` 草案，仍不得标「已过关／已提交」）须同时满足：单方无冲突公司或合规负责人立场已闭合；主成果是现场与首轮应对，不是预案、交卷终稿、披露、复议或刑事辩护；至少有到场人员或已到达的检查通知／文书。口头「尽快交」、已读、快递揽收、电话预约不算单独开闸材料。

检查闸部分打开：证件或文书未完全闭合，但人员已在现场或已有通知表面；对应格待核；只做最小必要配合；仍交十节。无书面现场授权但单方立场已闭合且已有到场或通知碎片：检查闸部分打开，仍交十节，不是整体停止。人员已在现场、证件未出示：部分打开，不是关闭。

检查闸关闭（仍正触发）：无一到场人员且通知未到达。「今天必须交完」而无最小事实不得开闸。不出 `XR#` 终稿。**仍交十节**，第 5 节只交闸／`Q-检`，第 6 节不出 `XR#` 终稿，**第 7 节不得出已过关或交卷终稿**。禁止因闸关闭只交第 1、2、10 节或改走负触发。禁止把闸关闭写成「可以不配合」或「已经过关」。若主成果是完整未通知预案，负触发预案窗，不在本窗关闸续跑出预案终稿。

「保证过关或免罚」「今天必须交完」「选定某局」「口头尽快当截止日」「未出示证件就可以拒绝后关门」「已读即送达」「草稿即已提交」**不关窗**。对应格 `现有依据不支持` 或字段停止。闸已开仍出其他 `XR#` 草案。未出示证件：记录异议，最小必要配合，**不教关门藏物**。人员已在现场不关窗。

若 if 立场或委托无法闭合，then 整体停止。
若 if 单方立场已闭合但无一到场人员且通知未到达，then 检查闸关闭，仍交十节，不是整体停止。
若 if 同时掌握公司与被调查对象相互冲突的秘密，或两造争同一套现场口径，then 整体停止，不得选边，不得问代表哪一方后继续。
若 if 提出阻挠合法检查、毁证、伪证、藏匿、拖延销毁、关门藏物、指导拒绝出示合法证件后的检查、已有监察／公安／检察 `R#` 仍要求借现场平行灭证，then 整体停止；第一次提出即停，不以「坚持」为门槛。

## 节点 1　证件、文书与现场纪律

一行一个来人或文书切片。缺项记 `G#`，不得把未知写成 `0`。本节禁止出 `XR#` 终稿。

| 字段 | 必须记录 | 禁止 |
| --- | --- | --- |
| 来人 | 姓名、单位**类型**、是否二人以上 | 此致某局；民企写成必须接待国资委 |
| 证件文书 | 执法证／监察证编号、文书名称、范围、起止 | 不出示＝关门藏物；口头来过＝已到达 |
| 现场 | 指定唯一对接；禁止闲聊销毁 | 驱离、拔网线、格式化 |

检索锚点（写入 `L#` 前须核验）：行政处罚法 2021 第五十五条出示证件／拒绝接受调查／如实协助，第五十六条先行登记保存七日＝机关处理期限。噪声：1996 年第五十五条、2017 年第三十七条、1996／2017 年第三十二条。行政强制法第十八条。监察法第十八条、第四十四条；噪声 2018 年第四十一条。反法 2025 第十六条、第十七条；施行日 2025-10-15。个保法第十三条。42 号令第二条。

监察调查与市场监管行政检查分账。监察文书出现：配合义务按第十八条核验，本窗不变成职务犯罪辩护。

## 节点 3　现场应对行 `XR#`

按已出现来人、文书或材料扫描，不是默认闭集。每条须能指向来人与文书、证件异议或材料三态之一。

已核实、在文书范围内 → `可交`（草案，不代提交）。范围外个人信息、其他客户秘密、律师工作产品 → `扣下` 并写理由。猜测、未核验范围、个保基础未核 → `待核`。不得临时制作假账。原件提交记副本。私人设备／私人微信／定位默认待核或扣下。

无 `E#` 不得写已过关、已提交或已送达。状态默认 `草案`。一次只推荐下一步。未知不写零。来人只写单位类型。

热冲突强制处理：

- 保证过关／今天必须交完／选定某局／口头尽快当截止／未出示即可关门／已读即送达／草稿即已提交／未知写零 → 该格不支持或字段停止；仍出其他 `XR#`。
- 无一到场且通知未到达 → 关闸，不出 `XR#` 终稿，窗口不关。
- 阻挠、毁证、藏匿、关门藏物、平行灭证 → 整体停止，不是该格不支持后续续编。

## 节点 4　期限辅行、口径与后续接口

`K#` 每份通知／决定一行一类：`责令改正期限`／`陈述申辩期限`／`先行登记保存期限`（只待核，不得改写内部期限）／`内部响应时点`（标明非法定）。作出日、送达日、送达方式分列。未核验则截止字段停止。口头电话、已读、快递揽收不是送达。

已回答问题登记：问句、答句、是否超出范围、是否待核。禁止承诺未核验的犯罪构成或保证过关。

第 7 节只开接口，不得夹带 `XR#` 终稿、交卷终稿或已过关绕闸。闸关闭时第 7 节可写「闸未开，转介待来人编号」，不得补写已过关。不选定机关。不代提交。不定罪。不保证过关。现场口头「一周内改完」不是责令期限。

下一步只转介：`制定突击检查现场预案`、`准备向监管提交材料与特权日志`、`准备主动披露或自查报告`、`准备合规整改方案`、`评估律师工作产品与保密边界`、`准备涉案企业合规整改与验收`、`准备证据保全与禁毁通知`、`合法收集书证电子证与财务痕迹`、`形成内部调查报告`、`评估是否启动内部调查`、`建立内部调查证据案卷`、`评估国企合规管理办法差距`、`处理利益冲突与调查回避`、`准备董事会合规汇报材料`、`设置合规监管人或独立监察`、`评估舆情与法定披露交叉`、`评估企业合规风险总图`、`准备根因分析与控制补强`。禁止此致某局。禁止转介本窗完成藏匿。

若 if 用户催促「不出示就可以关门／今天必须交完／保证过关／民企必须接待国资委／不清楚先写零」，then 该格 `现有依据不支持` 或字段停止，窗口不关。
若 if 未知，then 写 `未知`／`G#`，禁止写 `0`。

## 本任务回链纪律

本任务成果是「检查闸与现场应对行草案」。本窗不执行发送。不包含：复议状、税务实体结论、刑事辩护、整改终稿、披露发送稿、交卷终稿、完整未通知预案、已过关证明。禁止选边治愈。禁止拒绝调查即关门。禁止未出示即可藏物。禁止口头尽快即截止。检查闸打开 ≠ 已过关 ≠ 已提交 ≠ 可以不配合合法检查。

若 if 材料只能支持部分字段，then 成果状态用 `部分形成并明确受限字段`；闸关闭不得标可交终稿已形成。
风险档 A：阻挠、毁证、藏匿、关门藏物必须单独标可逆性；提出即整体停止。
