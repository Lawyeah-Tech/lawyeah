# 输出合同

按触发结果选择交付形状。检查闸未打开不得交付可交材料终稿或「已过关」。禁止指导阻挠合法检查、藏匿或毁证。禁止倒签。禁止选边治愈。不执行发送。不代提交。未知不写零。不保证过关。

## 交付形状

| 状态 | 交付 |
| --- | --- |
| 负触发 | 一句 `触发判定：负触发，未启动本任务` + 路由去向，不填实体十节 |
| 节点 0 整案转出 | 第 1、2、10 节。不填第 5–9 节 |
| 整体停止 | 第 1、10 节。禁止可交材料终稿、藏匿步骤、选边。双方秘密、阻挠合法检查、毁证伪证藏匿、关门藏物第一次即停，优先于负触发；无选边治愈，无「坚持」门槛 |
| 用户要保证过关、今天必须交完、选定某局、口头尽快当截止日、证件不全就可以关门（不关窗） | 十节表头均出现；对应格填 `现有依据不支持` 或字段停止；未出示证件则记录异议、最小必要配合，不教关门藏物；闸未开则第 6 节不出可交材料终稿；不得改走负触发关窗 |
| 正触发且闸开 | 十节表头均出现；未核验格填待核；禁止为填满而写已过关、可关门或已送达 |

正触发状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。闸未开不得进入可交材料终稿已形成。双方秘密未解不得进入「部分形成」。每个 `K#`／`Q#` 必须带来源和判断三值。`L#` 不得直接抄技能内条号。稿件状态默认 `草案`。

分流理由只放第 1 节。

## 1. 触发、单方立场、授权、检查闸与成果状态

谁要应对。公司立场。检查闸是否打开。双方秘密未解不得进入「部分形成」。不得写「澄清代表哪一方后继续」。不保证过关。

## 2. 来源登记与 MCP 调用表

`S/D/A/R/C/L/I/G/Q/K/V`。口头尽快、已读、快递发出只登记 `S#`／`V#`。MCP 未调用也留一行。噪声命中须登记。

## 3. 来人单位类型、证件、文书与权限异议

单位类型不选定某局。证件编号、文书名称、范围、起止。不全则异议记录。监察与行政检查分账。

## 4. 现场角色与纪律

对接人。禁止擅自闲聊、禁止销毁。未出示证件：最小必要配合，不教关门藏物。

## 5. 检查闸与路径矩阵 `Q#`

本节禁止出可交材料终稿。无证件且无文书则 `Q-检` 关闭或部分打开，窗口不关。`Q-刑`／`Q-税` 只打红旗。

## 6. 可交／扣下／待核材料表

闸未开不得出可交材料终稿。一行一条。原件／副本。扣下须写理由。不得假账。状态 `草案`。

## 7. 期限卡 `K#` 与已答口径

每份文书一行。口头电话不等于送达。已读不得起算。禁止唯一截止日。口径不得承诺未核验罪责或保证过关。

## 8. 后续整改、披露、交卷、救济接口

只开接口。不等于已经过关或已验收。人员已在现场不关书面披露接口。

## 9. 风险与下一步

每项含可逆性。只转介：`制定突击检查现场预案`、`准备向监管提交材料与特权日志`、`准备主动披露或自查报告`、`准备合规整改方案`、`评估律师工作产品与保密边界`、`准备涉案企业合规整改与验收`。禁止藏匿指令、关门指令、此致某局。不代提交。

## 10. 缺口、停止项与提示

须列对方最强解释：不出示证件就可以关门藏物、口头尽快就是法定期限、已读就是送达、配合就是已过关、律师在场就是美国式特权、先行登记保存七日就是内部期限、两边材料选边、阻挠只是策略不是违法。

本成果不是复议状、不是税务实体结论、不是刑事辩护、不是整改终稿、不是披露发送稿、不是完整未通知预案、不保证过关。不执行发送。不阻挠合法检查。

## 综合提问的强制降级

用户同时问能不能关门、哪天到期、向哪个局交、能不能先把电脑藏起来时，第 5–7、9 节仍只给接口和转介；藏匿或阻挠走整体停止，不在本任务完成过关或毁证。
