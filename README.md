# Lawyeah 法律技能

面向中国大陆执业律师、律师助理的可安装法律技能包。授权 [Apache License 2.0](LICENSE)。

仓库按律师查找用中文目录组织，**不再区分专业版 / 升级版**。每个包是完整能力，整包安装、整包卸载。

## 目录

| 目录 | 内容 |
| --- | --- |
| [领域/](领域/) | 21 个办案领域 |
| [合同/](合同/) | 11 个合同审查与起草包 |

每个包内是一个入口技能和若干原子技能。点开中文文件夹即可。

## 包的结构

```text
领域/房地产与物业/
  README.md
  LICENSE
  NOTICE
  pack.json
  skills/
    房地产与物业导航/
    评估房地产与物业争议/
    ...
```

## 使用

把对应包的文件夹装进电脑端 Agent（WorkBuddy、Claude、Codex 等）。技能较多时先开入口技能，再进入具体原子。可选使用 [律页 MCP](https://www.lawyeah.cn) 做法规、实务、案例或范本检索；未配置也可按包内方法使用。

商品安装包（ZIP、网盘发货）是另一条渠道，不在本仓库。
