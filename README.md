# 律页法律技能 · Lawyeah Legal Skills

[Website](https://www.lawyeah.cn) · [Install](docs/安装.md) · [Pack catalog](SKILLS.md) · [Apache-2.0](LICENSE)

Open **Agent Skills** for **Chinese mainland** legal practice: 32 packs, 1998 atomic skills. Clone the repo, copy one pack folder into your Agent, call it with `/`.

面向中国大陆执业律师、律师助理的公开法律技能库。把对应中文包装进电脑端 Agent 后，按办案领域或合同类型调用。

```bash
git clone --depth 1 https://github.com/Lawyeah-Tech/lawyeah.git
```

仓库地址：https://github.com/Lawyeah-Tech/lawyeah

## 三步安装

1. 克隆本仓库（或下载 ZIP）。
2. 从 [`领域/`](领域/) 或 [`合同/`](合同/) **整包取出一个中文目录**，不要拆成单个技能。
3. 把该目录（或打成的 zip）拖进 Agent 对话框：
   - WorkBuddy：「把这个技能套件整包安装到本机，不要拆成单个技能。」
   - Codex：把「套件」换成「插件」。

装完用 `/` 召唤具体技能。技能多的包，先开入口技能看边界。截图和装到哪里，见 [技能安装说明](docs/安装.md)。

更新时用同名目录整体替换。Agent 发现入口另见 [`skills/lawyeah-legal-skills/`](skills/lawyeah-legal-skills/)。

## 我们是谁

我们做[法律 AI 工作台](https://www.lawyeah.cn)，把检索、对话、办案材料和团队协作放在同一条工作流里。这个仓库是把办案方法抽出来、做成可安装技能包的地方。

通用模型会写、会搜。办案时卡住的往往是：先走哪条路、材料缺什么、该停在哪。每个原子对应一项用户目标和一份可验收成果。入口技能只说明边界和分流。法域是中国大陆。技能不是法律服务，也不出庭、不出具法律意见。

## 律页 MCP

技能自己带方法、边界和成果形状。要核验现行法条、类案、实务或范本时，可以接 [律页 MCP](https://www.lawyeah.cn)。这是可选增强，不是运行前提。没接的时候，按包内方法继续做能做的部分；依赖未核验规则的结论、期限或机关路径应当停止或待核。

MCP 只读。当前公开工具：

| 你要做什么 | 用哪个工具 |
| --- | --- |
| 查法律法规、司法解释、具体法条 | `search_law` |
| 已有 `regulation_id`，要法规详情或正文 | `get_law_detail` |
| 查办案策略、举证、诉讼流程或实务 | `search_practiced` |
| 已有完整案情，找相似案例 | `search_case_by_fact` |
| 按案由、法院、地区、年份等条件筛案例 | `search_case_by_filter` |
| 已有案例 ID 或案号，要详情 | `get_case_detail` |
| 查上市公司公告 | `search_announcement` |
| 查合同、诉讼文书等范本 | `search_template` |
| 已有 `template_id`，要范本正文 | `get_template_detail` |

到[官网](https://www.lawyeah.cn)申请授权。不要把完整 API Key 写进技能、Issue 或聊天记录。
