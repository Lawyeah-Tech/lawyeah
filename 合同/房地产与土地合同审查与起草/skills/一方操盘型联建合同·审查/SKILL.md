# 一方操盘型联建合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、2005 年土地使用权解释旧条号、1993 年《房地产开发企业资质管理规定》、民法通则联营条或 1990 年联营解答当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **房地产合同 / 一方操盘型联建合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「一方操盘型联建合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、把联合操盘/委托代建/不共担风险联建/施工总包/纯销售代理整案改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **操盘权限**：双方共同投资、共享利润、共担风险，但执行控制权集中授权给一方。操盘范围须分列前期报建、工程招采与现场、销前销售、竣工交付。重大事项（规划/容积率变更、开盘价、超预算、单笔大额采购、土地或在建工程抵押、对外担保借款）须非操盘方书面签认或共同决策；日常经营由操盘方决定。非操盘方应能委派财务总监或成本主管联签，并对规划设计方案、定价方案保留否决。禁止写成“全权决策、甲方不得干预”，也禁止把股东会/董事会重大决策权全部剥给操盘方。
2. **印章与资金**：项目收支进入共管账户，大额划拨双签。项目公章、财务章双方共管或双人双锁；报建/销售业务章可由操盘方掌管，但不得单方对外担保、借款或抵押。缺失证照印章共管，或允许操盘方单独掌握全部印鉴与账户，必须改或红线。
3. **与联合操盘切开**：交叉审批、双钥匙、双方均现场派岗共同执行 → 负触发 `联合操盘型联建合同·审查`。不得打开或抄写该原子方法，不得删双钥匙栏目后硬套。

配套切开：操盘方不是投资主体、只收管理费且不担亏损 → 负触发 `或` 或 `或`。不担经营风险、只收固定货币或固定房屋 → 负触发 `不共担风险型联建合同·审查` 或按土地使用权解释重新定性簇识别借款/买卖/租赁/转让，不得按本类型合作开发放行。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签一方操盘联建正文，尚未签署，尚未成争，核心给付是共担风险的合作开发，并将执行权集中授权给一方、另一方监督联签，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 交叉审批、双钥匙、双方共同现场执行 → `联合操盘型联建合同·审查`；
- 代建方不担投资风险、只收管理费，或商业品牌代建 → `或` / `或`；用户按土地使用权货架审查委托代建 → `委托代建合同·审查`；
- 不共担亏损、固定货币/固定房屋回报 → `不共担风险型联建合同·审查`；
- 共担风险但未配置单方操盘授权 → `共担风险型联建合同·审查`；
- 争议主轴是出地出钱结构而非操盘授权 → `一方出地一方出钱联建·审查` / `一方出地双方出钱联建·审查` / `“双方出地”型联建合同·审查`；
- 隐名参建或联建模式主轴 → `隐名参建联建·审查` / `联建模式联建合同·审查`；
- 用户按土地使用权货架审查合作开发整案 → `房地产合作开发类合同·审查`；
- 操盘方入股项目公司并按股权代建/小股操盘改完整案 → `操盘方入股项目公司并按股权代建小股操盘改完整案→`；
- 操盘方自己施工或按造价取费 → `操盘方自己施工或按造价取费→` / `或`；
- 只做销售代理 → `只做销售代理→`；
- 无文本、本类型条件已谈妥、要出己方稿 → `一方操盘型联建合同·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

挂靠、违法分包、规避限购或规避预售资金监管：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（操盘方或非操盘方择一）；相对方；全文及附件/计划书/测算表/授权清单/印章资金指引版本；土地使用权与立项归属；谁操盘；是否交叉审批或双钥匙；是否共担亏损；印章账户安排；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `一方操盘型联建合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有一方操盘联建文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。联合操盘、委托代建、不共担风险、施工、纯销售代理负触发。

### 2. 主体、土地手续、资质与授权

签约名、履行名、付款名、发票名分列。土地使用权和立项必须可识别。口头“现场能签”不得写成已授权。至少一方开发资质未核验则效力字段停止。

### 3. 操盘权限与重大事项清单

四段操盘范围 + 重大事项共同决策 + 日常事项操盘方决定 + 非操盘方联签/否决。

### 4. 印章与资金

共管账户、双签、公章财务章共管、禁止单方抵押担保。

### 5. 风险共担、操盘费与关联交易

必须共担经营亏损和市场风险。操盘管理费单独计价为项目成本。内部管理费分摊和关联承包须招标与否决安排。

### 6. 激励、撤换与接管

工期/成本/溢价奖励可谈；停工或严重质量纠纷可撤换操盘权；债务危机预设接管。核心团队锁定是合同安排，不是法定。

### 7. 格式条款、强制规范与退出

无核验引文则法律结论字段停止。不得把内部按份约定写成已对抗第三人。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把联合操盘或代建主轴改成本类型、把挂靠或规避预售监管改成可履行、或把不共担亏损文本按合作开发放行。
- `字段停止`：法域、土地使用权、立项规划、双方资质、预售监管账户、地方必须招标范围未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
