# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的费率、面积、节点、金额；把已失效《合同法》及其解释、2005 年土地使用权解释旧条号、1993 年资质规定或民法通则联营条写入结论。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。成果名称写「审查一方操盘型联建合同（房地产合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、1993 年资质规定、2005 年土地使用权解释旧条号单独引用、民法通则联营条时记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 **房地产合同**、子级 **一方操盘型联建合同**、定性理由、与 `联合操盘型联建合同·审查` / `或` / `不共担风险型联建合同·审查` 的切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读其他类型。挂靠、违法分包、规避预售资金监管写停笔告知，不填可履行结构。

## 4. 主体、授权、资质与文本版本

主体表：签约名、履行名、付款名、发票名、授权签字人、土地使用权人、立项主体、操盘方、非操盘方委派财务/成本人员是否有书面授权。版本表：正文、开发经营计划书、费用测算表、管理权授权清单、财务/印章监管指引、销售定价管理办法、聊天确认；冲突并列，不选对用户有利的一版。

## 5. 给付闭环

操盘四段范围、重大事项清单与日常授权、联签与否决、共管账户与双签、公章/财务章/业务章分管、风险共担与利润分配、操盘管理费是否单列、关联采购与内部管理费、验收移交与产权分割。缺口标 `G#`，不补商业数字。预售许可、监管账户写成双方义务或条件，不写成已经完成。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹；异常条款（全权操盘不得干预、单方掌握全部印鉴账户、不共担亏损、内部按份对外免责、操盘方单方抵押担保）。强制规范只区分是否导致民事行为无效。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔/转出口径。禁止输出无修改句的色块表。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`，不编造。禁止只给原则、不给句子。

## 9. 谈判与签署提醒

谈判顺序：先红线，再必须改，最后可优化。签署提醒：授权、用印、日期、计划书/测算表/授权清单/印章资金指引入附件、共管账户开立条件、项目负责人签章样式。不指导倒签或补假授权。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书或效力保证。
