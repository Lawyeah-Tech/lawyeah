# 边界与路由

本技能只审查 **房地产合同 / 一方操盘型联建合同** 的待签文本。中文展示名是「审查一方操盘型联建合同（房地产合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 交叉审批、双钥匙、双方均现场派岗共同执行 | `联合操盘型联建合同·审查`。不得抄该原子方法，不得删双钥匙栏目后硬套本技能 |
| 代建方不担投资风险、只收管理费；无共担亏损 | `或`；含品牌输出和管理费拆分 → `或` |
| 用户按「土地使用权」货架审查委托代建 | `委托代建合同·审查` |
| 不共担经营风险，固定货币、固定房屋或保底回报 | `不共担风险型联建合同·审查` |
| 共担风险，但未把执行权集中授权给一方 | `共担风险型联建合同·审查` |
| 争议主轴是出地/出钱结构，而不是操盘授权 | `一方出地一方出钱联建·审查`、`一方出地双方出钱联建·审查` 或 `“双方出地”型联建合同·审查` |
| 联建模式（法人型/合伙型/合同型联建主轴） | `联建模式联建合同·审查` |
| 隐名参建、不显名开发 | `隐名参建联建·审查` |
| 用户按「土地使用权」货架审查合作开发整案 | `房地产合作开发类合同·审查` |
| 操盘方入股项目公司、小股操盘、跟投退股要整案改完 | `操盘方入股项目公司并按股权代建小股操盘改完整案→` |
| 操盘方自己施工、按工程造价取费 | `操盘方自己施工或按造价取费→` 或 `或` |
| 只做销售代理、不管理报建和工程 | `只做销售代理→` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

一方操盘正文里夹带一小段销售代理佣金或施工承包：专条交接 `只做销售代理→` 或 `操盘方自己施工或按造价取费→`；操盘授权、印章资金、风险共担条款可继续审。用户坚持本技能把联合操盘、委托代建、不共担风险或施工整案改完：`目标停止`。
