# 共担风险型联建合同·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **房地产合同 / 共担风险型联建合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「共担风险型联建合同·起草」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、把固定回报改成可履行“假共担”、把不共担风险型联建、代建或土地使用权合作开发整案改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **亏损共担**。解释（2020 修正）第十二条以提供出让土地使用权、资金等作为共同投资，共享利润、共担风险为基本内容。本类型必须把（1）建设成本超支如何按投资或权益比例追加，（2）最终审计亏损、滞销和政策性限价损失如何分担，（3）因一方违约、行政处罚或过错导致的额外支出由责任方独立承担，写成可执行句。只写“共担风险”口号、未写亏损如何分担的，不得写成已构成共担风险型联建。
2. **与固定回报切开**。标题、正文或补充协议出现“固定回报”“保底利润”“无论盈亏均须支付”，或一方不承担经营亏损、只拿固定房屋 / 固定货币 / 固定地价 / 固定使用权的，不得按本类型放行。用户锁定不共担风险型联建 → `不共担风险型联建合同·审查`。资金方只收固定货币 → 第二十三条转 `资金方只收固定货币→第二十三条转`。土地方只收固定利益 → 运行时核验第二十一条后转 `国有土地使用权转让合同·审查`。只分固定房屋且不担风险 → 运行时核验第二十二条后回引擎按买卖。只使用房屋且不担风险 → 第二十四条回引擎按租赁。禁止在固定必付旁加一句共担空话、把“利息”改名为“合作收益”后放行。用户坚持既拿固定回报又按本类型放行：整体停止。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签联建正文，尚未签署，尚未成争，核心给付是各方以土地或资金共同投资联建并亏损共担、利润共享，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 用户或标题锁定不共担风险型联建，或经济安排是一方不担亏损只拿固定对价且用户确认按不共担联建审 → `不共担风险型联建合同·审查`（P1；未装则 `unavailable`）；
- 用户锁定「一方出地，一方出钱」/「一方出地，双方出钱」/「双方出地」型联建 → `一方出地一方出钱联建·审查` / `一方出地双方出钱联建·审查` / `“双方出地”型联建合同·审查`；
- 用户锁定一方操盘或联合操盘 → `一方操盘型联建合同·审查` / `联合操盘型联建合同·审查`；
- 用户锁定联建模式联建或参建隐名整案 → `联建模式联建合同·审查` / `隐名参建联建·审查`；
- 标题或用户锁定土地使用权 / 房地产合作开发类，拟设或已设项目公司股权合作，未锁定联建 → `房地产合作开发类合同·审查`；
- 委托人保留土地与项目、受托人只收代建费或管理费、不分享利润也不承担亏损 → `委托代建合同·审查` 或 `或` 至 `至`；
- 资金方不担风险、只收固定本息或固定货币 → `资金方只收固定货币→第二十三条转`；
- 土地方不担风险、只收固定地价或固定面积利益 → `国有土地使用权转让合同·审查`；
- 资金方不担风险、只拿固定套数或固定面积房屋 → 回引擎按房屋买卖定性；
- 资金方不担风险、只以租赁等方式使用房屋 → 回引擎按租赁定性；
- 仅联合竞买、尚未进入共同开发经营 → `一级市场联合拿地类合同·审查`；
- 整案是集体建设用地合作开发 → `集体建设用地合作开发合同·审查`；宅基地合作开发 → `宅基地合作开发合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

挂靠、违法分包、规避限购或限售、以联建套取信贷资金转贷：只出告知，不改写成可履行结构。

## 建立起草坐标

确认：使用者与授权；单方立场（出地方 / 出资方或合作方 / 拟设项目公司股东择一）；相对方；全文及预算、分房明细、监管协议版本；亏损与超支是否按比例分担；有无固定回报、保底或无论盈亏必付；是契约制联建还是同时设项目公司；土地是出让还是划拨；报建与销售主体是否具备房地产开发资质；联管会或双签安排；使用权年限是否可能超过二十年；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 起草模式

本原子只承担本类型起草。待签评改转 `共担风险型联建合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。按框架六步落稿。商业数字未给用 `【待填】`。出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。不共担风险、固定回报、代建、未锁定联建的合作开发：负触发，不按邻类出稿。

**起草必写**

- 建设成本超支如何按投资或权益比例追加。
- 最终审计亏损、滞销和政策性限价损失如何分担。
- 因一方违约、行政处罚或过错导致的额外支出由责任方独立承担。
- 共同投资、共享利润、共担风险写成可执行句，不得只写口号。

**附件必附**

- 预算。
- 分房明细附图。
- 监管协议。
- 亏损与超支分担比例表。

**禁止出现**

- 只写“共担风险”口号、未写亏损如何分担。
- 固定回报、保底利润、无论盈亏均须支付。
- 一方不承担经营亏损、只拿固定房屋／固定货币／固定地价／固定使用权。
- 在固定必付旁加一句共担空话、把“利息”改名为“合作收益”。
- 把不共担或代建整案按本类型改完。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 本任务起草模式；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有共担风险型联建文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。不共担、固定回报、代建、未锁定联建的合作开发、出资结构或操盘锁定、纯转让、纯买卖、纯租赁负触发。

### 2. 主体、土地、资质与组织模式

签约名、履行名、土地权利人、报建/销售主体名分列。权属、抵押查封、划拨审批、至少一方或项目公司资质未闭合则字段停止。契约制联建提示合伙对外连带，不写成“对内约定即可对抗第三人”。

### 3. 亏损共担

超支追加、最终亏损、滞销和政策性损失必须落到比例句。缺亏损分担或经营参与，不得写成已构成共担风险型联建。

### 4. 固定回报切开

固定本息、固定货币、固定房屋、固定利益、固定使用权且不担风险：按条转出或转 `不共担风险型联建合同·审查`，禁止化妆。

### 5. 分配、联管会与共管账户

分房附图、分钱成本口径、使用权年限；重大事项双签；销售回笼优先偿贷和建安。使用权约定期限超过二十年：超过部分按第七百零五条处理，必须改。

### 6. 程序、闲置与生效

报建名义、划拨转出让、开竣工期限。批准、登记、预售许可写成条件或期限，不写成已经完成。满两年未动工的闲置收回只作红旗，不写成必然收回。

### 7. 格式条款、免责与强制规范

限额可留，人身损害与故意/重大过失不得排除。无核验引文则法律结论字段停止。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把固定回报化妆成共担、把不共担或代建整案按本类型改完、把挂靠或规避限购改成可履行结构。
- `字段停止`：法域、划拨审批、预售许可、土增税清算口径、地方限购限售、解释第二十一条和第二十二条原文未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
