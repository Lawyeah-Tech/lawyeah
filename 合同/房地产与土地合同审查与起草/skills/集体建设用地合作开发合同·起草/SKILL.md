# 集体建设用地合作开发合同·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **土地使用权 / 集体建设用地合作开发合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「集体建设用地合作开发合同·起草」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证入市或登记一定办成、保证合作方必然取得可分割房屋所有权。

## 本类型硬闸

1. **入市／决议**：集体经营性建设用地交由单位或个人有偿使用，法定通道是出让、出租等，不是单独的“合作开发入市”。必须提取：规划确定为工业、商业等经营性用途并已依法登记；本集体经济组织形成书面意见；出让、出租前不少于十个工作日报市、县人民政府。现行农村集体经济组织法：集体经营性建设用地使用、出让、出租方案由成员大会决定，须全体成员三分之二以上同意；设立成员代表大会的，出租、出让方案可按规定由代表大会决定，须全体代表三分之二以上同意。村委会主任签字、两委纪要、微信群“没人反对”不得写成已决议。未入市、未报市县的，不改成可履行联建。
2. **共担风险**：正像是一方出地、一方出钱、共同利用土地、共享经营成果并分担开发与经营亏损。集体只收固定占地费、固定面积或固定收益且不参与损益 → 负触发租赁或按借贷切开，不得写成已构成合作开发。保底可以谈，但必须另有超额分成与亏损分担口径。
3. **与出让／入股／租赁切开**：核心给付是出让金换使用权、使用权过户到受让人名下、集体退出经营 → `集体建设用地使用权出让合同·审查`。对价是股权且集体成为股东 → `集体建设用地使用权出资入股合同·审查`。租金占场、不共同开发、不分担经营风险 → `集体建设用地使用权租赁合同·审查`。禁止打开或复制 `房地产合作开发类合同·审查`、`宅基地合作开发合同·审查` 的 method，不得套用国有出让地联建分房或宅基地成员住房过户口径。

支撑闸：

4. **标的适格**：必须是已登记集体经营性建设用地。农用地、宅基地、公益事业用地、未入市、权属争议或查封地，不改成可履行合作。村集体与组集体主体不错位。
5. **产权不分割、禁止住宅化**：房屋所有权登记在集体经济组织名下；合作方取得合作期限内的经营权、收益权、转租权。写成分割过户给非成员、对外销售住宅或小产权房的，只出告知，不改成可履行。城市规划区内集体土地经依法征收转为国有后，方可用于房地产开发经营。
6. **合同成立 ≠ 物权变动**：未办理不动产登记，不发生使用权或房屋所有权变动。不得写“签字即过户”。入市书面合同未依法载入规划条件、产业准入和生态环境保护要求的，该入市合同依法无效。
7. **期限与再定性**：若被定性为租赁，超过二十年的部分无效。不得用“经营期”空词规避租期上限后再主张已构成出让。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签集体建设用地合作开发正文，尚未签署，尚未成争，核心给付是集体以已登记经营性建设用地作为合作条件、合作方出资建设并共同经营、利润或物业经营权分成且集体不持股，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 一次性或分期出让金换取使用权过户，集体不再共同经营 → `集体建设用地使用权出让合同·审查`；
- 土地使用权作价出资，集体取得目标公司股权并按股东身份担风险 → `集体建设用地使用权出资入股合同·审查`；
- 租金或场地占用费为主给付，不共同开发、不分担经营亏损 → `集体建设用地使用权租赁合同·审查`；
- 国有出让建设用地上的房地产合作开发、联建分房、共同取证 → `房地产合作开发类合同·审查`；不打开其 method；
- 宅基地、农村住房、成员身份合作建房或过户 → `宅基地合作开发合同·审查`；不打开其 method；
- 国有土地使用权出让或转让本约 → `国有土地使用权出让合同·审查` 或 `国有土地使用权转让合同·审查`；
- 买公司股权只为拿地 → `以股拿地·审查`；
- 宅基地房屋买卖 → `宅基地内部房屋买卖·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁或行政机关已立案查处 → `或对应专项领域。` 或土地／争议专项。

以合作为名开发住宅对外销售、把农用地或宅基地改成建设用地联建、或把明知未入市土地改成可履行动工：只出告知，不改写成可履行路径。

## 建立起草坐标

确认：使用者与授权；单方立场；相对方；全文及附件／入市方案／决议／权属证版本；地块是否已登记经营性建设用地；是利润或经营权分成还是出让金、租金或股权；是否固定收益且不担亏损；房屋是否约定分割过户或对外销售；入市方案是否已报市县；书面决议比例；地上物是否一并投入；权利负担；规划条件／产业准入／环保要求是否写入入市书面合同；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 起草模式

本原子只承担本类型起草。待签评改转 `集体建设用地合作开发合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。商业数字未给用 `【待填】`。

按框架六步落稿。本类型硬闸改成下列起草必写 / 附件必附 / 禁止出现。集体建设用地合作开发与国有出让地联建、宅基地合作必须切开。

### 起草必写

- 提取：规划确定为工业、商业等经营性用途并已依法登记；本集体经济组织形成书面意见；出让、出租前不少于十个工作日报市、县人民政府；成员大会须全体成员三分之二以上同意。
- 一方出地、一方出钱、共同利用土地、共享经营成果并分担开发与经营亏损；保底可以谈，但必须另有超额分成与亏损分担口径。
- 房屋所有权登记在集体经济组织名下；合作方取得合作期限内的经营权、收益权、转租权。
- 入市书面合同必须依法载入规划条件、产业准入和生态环境保护要求；合同成立不等于物权变动。

### 附件必附

- 入市方案；成员书面决议。
- 权属证。
- 规划条件、产业准入、环保要求。

### 禁止出现

- 村委会主任签字、两委纪要、微信群“没人反对”写成已决议。
- 分割过户给非成员、对外销售住宅或小产权房。
- “签字即过户”；用“经营期”空词规避租期上限后再主张已构成出让。
- 农用地、宅基地、公益事业用地、未入市、权属争议或查封地改成可履行合作。
- 集体只收固定占地费、固定面积或固定收益且不参与损益，仍写成已构成合作开发。
- 套用国有出让地联建分房或宅基地成员住房过户口径。

出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)

禁止打开其他类型目录。`基本面.md` 把民主议定写成“民法典第五十九条”时，以 method 纠正为准。`框架.md` 出现“可以分割房屋产权给合作方”或把本约写成可对外预售商品房时，不得放行。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 本任务起草模式；已签履约 → 本套导航履约步骤；已成争 → 合同争议或土地专项。未签且目标是评改已有本类型文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。出让、入股、租赁、国有房地产合作开发、宅基地合作负触发。禁止打开 `房地产合作开发类合同·审查`、`宅基地合作开发合同·审查` 的 method。

### 2. 入市与决议

书面意见、报市县、规划条件／产业准入／环保要求写入入市合同。村主任签字不等于已决议。

### 3. 主体、村组权属与负担

签约主体必须是所有权人一侧的农村集体经济组织或依法代行职能的村民委员会；组地不得由村签。权利负担未核不得写成无负担。

### 4. 共担风险与收益结构

固定占地费且不担亏损按租赁或借贷切开。保底须配超额分成与亏损分担。

### 5. 产权、用途与期限

房屋登记在集体名下；禁止住宅化和小产权房。合同成立与物权变动切开。租期再定性走第七百零五条。

### 6. 格式条款与强制规范

无核验引文则法律结论字段停止。未写入规划条件／产业准入／环保的入市合同，效力字段按已核验第四十一条处理。

### 7. 违约、征收补偿与争议

程序瑕疵扰工、逾期建设、改用途、拒付分成须分别有后果。征收补偿按土地补偿与建设投入分列，不编造比例。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把未入市或农用地改成可履行联建、把不担风险的固定占地费改成合作外壳、把房屋分割过户或对外销售住宅改成可履行。
- `字段停止`：法域、动态规则、入市方案、决议比例、权属链、调节金、规划批复未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
