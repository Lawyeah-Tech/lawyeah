# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受、入市或登记必然办成；编造未给出的价款、分成、工期；把已失效《合同法》及其解释、1991 年土地管理法实施条例写入结论；把本约改成可分割过户或对外销售住宅。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。成果名称写「审查集体建设用地合作开发合同（土地使用权）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、1991 年土地管理法实施条例、已失效《物权法》时记噪声，不得写入 `L#`。土地管理法第六十三条全文、调节金比例、2025 年村民委员会组织法新条号未核验的，不写入 `L#`。

## 3. 类型与加载路径

父级、子级、定性理由、易混切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读其他类型，未打开 `房地产合作开发类合同·审查` 或 `宅基地合作开发合同·审查` 的 method。挂靠、违法分包、小产权房或未入市联建写停笔告知，不填可履行结构。

## 4. 主体、授权、决议与文本版本

主体表：签约名、履行名、收款名、发票名、授权签字人、所有权人（村／组）、担保人。版本表：正文、入市方案、成员决议、规划条件、配套出租／出让草本、聊天确认；冲突并列，不选对用户有利的一版。口头三分之二不得写成已决议。

## 5. 给付闭环

宗地四至与用途、入市通道（出租或出让等）、资金投入、建设与运营分工、分成与亏损分担、房屋权利（登记在集体名下）、合作期限、交地与开工、征收补偿分列。缺口标 `G#`，不补商业数字。批准、登记、入市备案写成生效条件或双方义务期限，不写成已经完成。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹；异常条款。强制规范只区分是否导致民事行为无效。入市书面合同未载规划条件、产业准入和生态环境保护要求：按已核验实施条例第四十一条处理该入市合同效力字段。无 `search_law` 引文则其他效力字段停止，事实摘录继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔／转出口径。禁止输出无修改句的色块表。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`，不编造。禁止只给原则、不给句子。

## 9. 谈判与签署提醒

谈判顺序：先红线（未入市、无书面决议、不担风险、分割过户或住宅销售），再必须改，最后可优化。签署提醒：集体公章与决议附件、入市方案及市县意见、规划条件／产业准入／环保文本、配套出租或出让书面合同、权属证与负担查询、日期不得倒签。不指导补假决议或假入市意见。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书或效力保证。复核清单至少包括：是合作还是出让／入股／租赁；书面决议比例；入市方案是否已报市县；地块是否已登记经营性建设用地；风险是否共担；房屋是否被写成可分割过户。
