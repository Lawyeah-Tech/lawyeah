# 边界与路由

本技能只审查 **土地使用权 / 与非出让人签订的勾地协议** 的待签文本。相对人是开发区管委会、土地储备中心、镇政府、城中村改造指挥部、招商局或地方人民政府等非法定出让人。中文展示名是「审查与非出让人签订的勾地协议（土地使用权）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或复制 `联合勾地协议·审查`、`国有土地使用权出让合同·审查` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 两家以上企业互约出资、联合竞买、份额、操盘 | `联合勾地协议·审查` |
| 相对人是市、县自然资源主管部门；正式《国有建设用地使用权出让合同》；成交确认后出让本约 | `国有土地使用权出让合同·审查` |
| 向自然资源主管部门提交用地预申请，无非出让人锁定主给付 | `用地预申请协议·审查` |
| 土地置换、产权置换为主给付 | `土地置换协议·审查` |
| 多家企业一级市场联合拿地、合作开发操盘为主 | `一级市场联合拿地类合同·审查` |
| 集体建设用地出让、宅基地合作、土地一级开发委托本约 | 对应场景原子或引擎重新定性 |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或对应专项领域。` 或对应专项领域 |
| 行政诉讼、出让合同纠纷或招商协议已立案 | 房地产／行政或争议专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

非出让人勾地正文里夹带一小段产业扶持或一级开发委托：专章交接对应原子或分条改写；勾地协调条款可继续审。用户坚持本技能把联合勾地、正式出让或用地预申请整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
