# 与非出让人签订的勾地协议·审查

## 任务目标

在单一立场下，只审查 **土地使用权 / 与非出让人签订的勾地协议** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「与非出让人签订的勾地协议·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证一定拿地或挂牌一定办成、保证相对人有权出让。

## 本类型硬闸

1. **相对人无权出让**：开发区管委会、土地储备中心、镇政府、城中村改造指挥部、招商局、地方人民政府不是法定出让人。出让合同应由市、县人民政府土地／自然资源主管部门与土地使用者签订。标题写成“土地出让合同”、主体写成“出让方／出卖人”、直接约定把土地使用权出让给特定主体的，该部分不得放行。管委会作为出让方订立的出让合同，应认定无效。本任务只评改招商／投资／勾地协调文本，不把相对人改成出让人。
2. **规避招拍挂只告知**：工业、商业、旅游、娱乐和商品住宅等经营性用地以及同一宗地有两个以上意向用地者，应当招标、拍卖或挂牌。协议不得免除公开竞价、内定中标、保证竞得或“直接给予”。只出告知，不改写成可履行锁定。可改成“推动挂牌＋产业准入条件建议（是否写入公告由法定出让人依法决定）”。
3. **与联合勾地切开**：两家以上企业之间分配出资、联合竞买、份额、操盘 → `联合勾地协议·审查`。本技能是**一家企业与非出让人**。
4. **与出让合同切开**：相对人是市、县自然资源主管部门，文本是正式《国有建设用地使用权出让合同》、成交确认后出让本约或按第三百四十八条展开出让必备项 → `国有土地使用权出让合同·审查`。禁止打开或复制其 method，禁止把付清出让金办证、分割发证、出让年限登记做成主路径。
5. **返还出让金／先缴后返／阴阳合同只告知**：禁止以土地换项目、先征后返、补贴、奖励等形式变相减免出让价款。勾地协议与出让合同差价地下交易只告知。产业扶持可另约，不得写成出让金返还路径。
6. **毛地不得勾成可供应**：未完成补偿安置、权利不清晰、规划条件不明的，不得写成可上市净地。供地相关条款以规划调整及挂牌程序完成为前提，不得写成已经取得建设用地使用权。
7. **越权承诺不得确保**：容积率、地价、规划调整、审批办成只能写协助／协调／力争，不得写“确保办理成功”。程序性违约（逾期不启动拆迁、不组织报批挂牌）可约责任；不得按尚未形成的成交价写土地价款违约金。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签正文，尚未签署，尚未成争，相对人是非法定出让人，核心给付是协调特定地块一级开发、推动招拍挂、产业承诺与未能拿地时的结算，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 两家以上企业之间分配出资、联合竞买、份额或操盘 → `联合勾地协议·审查`；
- 相对人是市、县自然资源主管部门，文本是正式出让合同或成交确认后出让本约 → `国有土地使用权出让合同·审查`；
- 向自然资源主管部门提交用地预申请、无非出让人锁定条款 → `用地预申请协议·审查`；
- 多家企业在一级市场联合拿地、合作开发操盘为主给付 → `一级市场联合拿地类合同·审查`；
- 土地置换、集体建设用地出让、宅基地合作 → 对应场景原子；
- 无文本、本类型条件已谈妥、要出己方稿 → `与非出让人签订的勾地协议·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁或行政诉讼已立案 → `或对应专项领域。` 或房地产／行政争议专项。

以勾地为名规避招拍挂、内定中标、返还出让金、阴阳合同，或把无权主体改成可履行出让：只出告知，不改写成可履行路径。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方法定身份与授权文件；全文及附件／规划图／纪要版本；地块四至、用途、是否净地、是否已入储备或年度供应计划；是否写成出让或保证中标；是否返还出让金；保证金名称与金额；产业指标；一级开发主体；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `与非出让人签订的勾地协议·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议或房地产／行政。未签且目标是评改已有非出让人勾地文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与相对人身份一致才继续。联合勾地、正式出让、用地预申请、联合拿地负触发。

### 2. 相对人无权出让

不得把管委会等写成出让人。法定出让程序必须由市、县自然资源主管部门启动。

### 3. 标的、净地与规划

四至、用途、规划条件、是否净地、是否入计划。毛地不得写成可供应。

### 4. 招拍挂不可绕过

推动挂牌，不直接给予。内定、保证中标、免除竞价只告知。

### 5. 对价、保证金与返还出让金切开

意向金／投资保证金不宜写成定金。返还出让金、先缴后返只告知。产业扶持另约。

### 6. 越权承诺、生效与 1+1 结构

协助办理，不确保审批。供地条款附条件；投资协调条款与结算条款可独立存续。拿地后再由项目公司与自然资源主管部门签出让合同，本任务不代审出让本约。

### 7. 格式条款与强制规范

无核验引文则法律结论字段停止。无权出让、规避招拍挂、返还出让金不得改成可履行。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、保证一定拿地、把无权主体改成可履行出让、把规避招拍挂或返还出让金改成可履行并放行。
- `字段停止`：法域、动态规则、规划与净地、授权纪要、产业扶持审批未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
