# 边界与路由

本技能只审查 **房地产合同 / 城市更新项目合作合同（村集体与合作企业）** 的待签文本。中文展示名是「审查城市更新项目合作合同（村集体与合作企业）（房地产合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 不经更新单元，仅就宅基地房屋与外来资本合作建房或盘活宅基地 | `宅基地合作开发合同·审查`。不得抄该原子方法，不得删宅基地身份限制后硬套本技能 |
| 本集体经济组织内部宅基地房屋买卖 | `宅基地内部房屋买卖·审查` |
| 宅基地房屋租赁或委托运营 | `宅基地房屋租赁运营·审查` |
| 已登记集体经营性建设用地出让、出租或入股，不以回迁复建为给付 | `集体建设用地合作开发合同·审查`。不得抄该原子方法，不得把入市出让本约改成更新合作 |
| 给付是意愿征集、策划摸查、前期顾问费 | `城市更新项目前期服务合同·审查` |
| 开发商与前期服务公司分成、独家顾问或信息费 | `城更合作（开发商与前期服务）·审查`。禁止打开或抄写该原子 method |
| 双方均为开发主体，主轴是项目公司股权比例和出资，村集体不是出地一方 | `城更股权合作·审查` |
| 意向、框架或招商前预备，尚未锁定实施阶段权利义务 | `城市更新项目意向合作协议·审查` |
| 用户只拿安置资金监管协议 | `资金监管协议·审查` |
| 针对每一户的拆迁补偿安置协议 | `拆迁补偿安置协议·审查` |
| 政府与实施主体的监管协议 | `实施主体监管协议·审查` |
| 普通“一方出地、一方出钱”联建，无更新政策、无回迁双95%、无公开招商中选 | `一方出地一方出钱联建·审查` |
| 政府委托土地一级开发，村集体不是合作一方 | `土地一级开发委托，或名为一级开发实为投资借贷` |
| 与自然资源主管部门签署的国有土地使用权出让合同 | 转引擎重新定性，不按本类型改出让金条款 |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争，或成员已起诉撤销决议/合同 | `或对应专项领域。` 或对应专项领域 |
| C 端征收补偿材料整理 | `C端征收补偿材料整理`，只分流，不回改 |
| C 端农村土地承包与流转材料整理 | `承包地／土地经营权流转`，只分流，不回改 |

本类型正文里夹带一小段资金监管或户级安置方案要点：专条交接 `资金监管协议·审查` / `拆迁补偿安置协议·审查`；集体决议、复建融资分区、临迁费、股权锁定条款可继续审。用户坚持本技能把宅基地合作、集体建设用地入市、前期服务或普通联建整案改完：`目标停止`。
