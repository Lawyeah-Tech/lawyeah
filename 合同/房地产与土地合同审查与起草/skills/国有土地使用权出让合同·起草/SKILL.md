# 国有土地使用权出让合同·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **土地使用权 / 国有土地使用权出让合同**，出稿后用本类型硬闸自审，输出可编辑草稿、未决项、自审风险表和自审后修改句。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「国有土地使用权出让合同·起草」。`depends-on` 为空。不要求先跑导航。

主线是**市、县人民政府自然资源主管部门将一定年期的国有建设用地使用权有偿出让给受让人**。不是二级市场转让，也不是集体经营性建设用地入市出让。

不交付：他类审查、从零起草、履约交底、争议文书、有效性或必然完成不动产登记保证、转让／集体出让／勾地／联合拿地／以股拿地／合作开发的整份代审。

## 工作边界

正触发：已有可读待签文本要评改（审查模式），或本类型条件已谈妥要出己方稿（起草模式）；尚未签署，尚未成争；核心给付是市、县人民政府自然资源主管部门（或文本自称的出让人）将国有建设用地使用权在一定年限内出让，受让人支付土地出让金。划拨转出让补办本约、且文本以补缴出让金换取出让使用权的，仍可留本任务，但批准字段停止至见到有批准权的人民政府批准。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 转让人是已取得不动产权证的使用权人，对价是转让价款，政府不是出让方 → `国有土地使用权转让合同·审查`；
- 出让人是农村集体经济组织或村民委员会，标的是集体经营性建设用地，须村民会议或村民代表三分之二同意 → `集体建设用地使用权出让合同·审查`；
- 主文件是用地预申请 → `用地预申请协议·审查`；
- 与非出让人（管委会、平台、招商办）签订的勾地／意向 → `与非出让人签订的勾地协议·审查`；
- 多方联合勾地 → `联合勾地协议·审查`；
- 一级市场联合竞买／合资拿地投资协议，本约只是附件 → `一级市场联合拿地类合同·审查`；
- 收购项目公司股权以获取土地为目的 → `以股拿地·审查`；
- 共同投资、共享利润、共担风险的合作开发为主给付 → `房地产合作开发类合同·审查`；
- 土地置换为主给付 → `土地置换协议·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问交地日、缴款日、办证留痕 → 本套导航的履约步骤；
- 已成争（催缴出让金、闲置认定／收回、解除、行政诉讼或民事诉讼立案、开庭、仲裁）→ **土地／行政争议领域**，不填签前十节。

管委会／街道办／平台公司顶替出让人、经营性用地规避招拍挂、财政返还出让金、以股权并购规避闲置或转让限制：只出告知，不改写成可履行结构。

## 建立起草坐标

确认：使用者与授权；代表受让人／竞得人还是出让人；正文、成交确认书／中标通知书、宗地图、规划条件版本；用途是否经营性及是否已招拍挂；出让金与开竣工；交地标准；不可接受事项；法域与拟签时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的出让金、面积、开竣工日用 `【待填】`，不编造。

## 本类型硬闸

审查过程必须逐项点名，每闸必须有修改句，不得用转让 25% 投资额交割包或集体入市村民决议清单代替：

1. **出让主体**：出让人必须是市、县人民政府自然资源主管部门。街道办、开发区／园区管委会、城投或平台公司、乡镇政府不得作为出让人。开发区管委会作出让方的合同应认定无效；解释实施前订立且起诉前经追认的例外不得写成签前可放行。
2. **招拍挂**：工业、商业、旅游、娱乐和商品住宅等经营性用地，以及同一宗地有两个以上意向用地者，应当招标、拍卖或挂牌。经营性用地不得以“只有一个意向用地者”走协议出让。
3. **开发期限闲置**：必须写清开工、竣工日期，并把开工界定为取得施工许可证并实际破土动工。满一年未动工**可以**征收出让金**百分之二十以下**闲置费；满两年**可以**无偿收回。政府未按约交净地的，开竣工应顺延。不得把“固定 20%”或“满两年必然收回”写成默认。
4. **与转让 `国有土地使用权转让合同·审查`／集体建设用地 `集体建设用地使用权出让合同·审查` 切开**：一级市场、政府出让、出让金 → 本类型。已持证使用权人转让 → `国有土地使用权转让合同·审查`。集体所有、村集体作出让人、村民决议 → `集体建设用地使用权出让合同·审查`。标题只是线索。


## 起草模式

本原子只承担本类型起草。待签评改转 `国有土地使用权出让合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。商业数字未给用 `【待填】`。

按框架六步落稿。本类型硬闸改成下列起草必写 / 附件必附 / 禁止出现。不得灌入商品房五证规则或二级市场转让 25% 投资额交割包。

### 起草必写

- 出让人必须是市、县人民政府自然资源主管部门；主线是将一定年期国有建设用地使用权有偿出让，受让人支付土地出让金。
- 工业、商业、旅游、娱乐和商品住宅等经营性用地，以及同一宗地有两个以上意向用地者，应当招标、拍卖或挂牌。
- 写清开工、竣工日期；开工界定为取得施工许可证并实际破土动工。满一年未动工可以征收出让金百分之二十以下闲置费，满两年可以无偿收回；政府未按约交净地的，开竣工应顺延。
- 划拨转出让补办本约的，批准字段停至见到有批准权的人民政府批准。

### 附件必附

- 成交确认书或中标通知书。
- 宗地图、规划条件。
- 划拨转出让的有批准权人民政府批准文件（如有该路径）。

### 禁止出现

- 街道办、开发区／园区管委会、城投或平台公司、乡镇政府作为出让人。
- 经营性用地以“只有一个意向用地者”走协议出让，或把规避招拍挂改成可履行。
- 把闲置费写成固定 20%，或把满两年写成必然收回。
- 财政返还出让金；以股权并购规避闲置或转让限制。
- 二级市场转让价款、集体入市村民决议、商品房五证作为本约主路径。

出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录，禁止为对照打开转让 25% 投资额主路径或集体入市村民决议清单。`基本面.md` 中把闲置费写成固定“出让金 20%”、把未招拍挂一律“效力性强制无效”、把成交后“10 个工作日”当法定、把股权并购写成可规避闲置／转让的默认可履行、把争议写成“必须行政诉讼”的，不得照抄为可履行结论。

必须有修改句。禁止只打红黄绿。每个风险回链文本位置。交付按 [输出合同](references/output-contract.md)。边界见 [路由](references/routing.md)。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签或补假招拍挂／假成交确认书、把管委会／平台公司顶替出让人改成可履行、把经营性用地协议出让或财政返还出让金改成可履行、保证有效或必然完成不动产登记。
- `字段停止`：未见出让人是否为市、县自然资源主管部门；经营性或用途不明且无招拍挂痕迹；开竣工或开工定义缺失；划拨转出让未见批准；宗地四至／规划条件未附。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或文本已滑入转让／集体出让／勾地／以股拿地。

生存级出让金或个人／母公司无限连带且用户拒绝升级：停止“可以签署”建议。
