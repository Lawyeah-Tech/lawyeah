# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、必然完成不动产登记、对方必然接受；编造未给出的出让金、面积、开竣工日；把已失效《合同法》、1999 年闲置办法、2002 年招拍挂旧规定、1992 年划拨办法写入结论；把转让 25% 投资额交割包或集体入市村民决议硬套本类型；输出可履行的“管委会当出让人”“经营性用地直接协议出让”“财政返还出让金”结构。

## 1. 触发、单方立场与成果状态

立场（受让人／竞得人，或市、县人民政府自然资源主管部门）、授权、签署状态、主要目标。转让、集体出让、勾地、联合拿地、以股拿地、已成争或其他负触发写路由，不启动实体审查。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》、1999 年闲置办法、2002 年招拍挂旧规定、1992 年划拨办法或已失效土地登记办法时记噪声，不得写入 `L#`。2012 年闲置办法第二条、第十四条，城市房地产管理法第十三条、第二十六条未核验现行正文前不得写入 `L#`。

## 3. 类型与加载路径

父级 `土地使用权`，子级 `国有土地使用权出让合同`。写定性理由和与国有转让、集体建设用地出让、勾地、以股拿地的切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识稿中的固定 20% 闲置费、效力性强制无效口诀、10 个工作日当法定、股权并购规避闲置写停笔告知或降级，不填可履行规避结构。

## 4. 主体、授权、资质与文本版本

主体表：出让人全称与是否市、县自然资源主管部门、受让人／竞得人、拟承接的项目公司、母公司保证人、授权签字人。版本表：正文、附件、成交确认书／中标通知书、宗地图、规划条件、划拨转出让批准、聊天确认；冲突并列，不选对用户有利的一版。

## 5. 给付闭环（本类型必填）

固定检查并回链文本：

- 出让人是否市、县人民政府自然资源主管部门；是否出现管委会／街道办／平台公司；
- 用途（居住／工业／商业等）与最高年限是否对应；经营性或同一宗地多意向是否已招拍挂；成交确认书／中标通知书编号；
- 宗地编号、坐落、四至、出让面积与净用地面积、实测多退少补；
- 规划指标：容积率上下限、建筑密度、绿地率、高度、自持比例；
- 出让金总额及构成（是否含市政配套、拆迁补偿）；定金／保证金是否转定金；分期节点与逾期违约金；
- 交地标准（净地／五通一平／现状）与交付确认书；
- 开工日期、竣工日期、开工定义（施工许可＋实际破土）；闲置一年／两年后果及政府原因顺延；
- 付清全部出让金后方可申请登记；禁止按已缴比例分割发证；
- 划拨转出让：批准机关与补缴出让金；
- 地下空间是否另行出让。

缺口标 `G#`，不补商业数字。招拍挂、批准、登记写成义务或条件，不写成已经完成。

## 6. 格式条款与强制规范

是否构成格式条款（含自然资源部示范文本填充版）；提示说明痕迹。强制规范只区分是否导致民事／行政行为无效与是否仅造成履行或登记障碍（出让主体不适格、经营性未招拍挂、未付清出让金不得登记）。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。不得用已失效“效力性／管理性”口诀。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。硬闸四项若文本或事实触及或沉默，必须各有至少一行，不得用色块代替。

## 8. 修改句

按框架六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点、不接受时的红线。未给出的商业数字用 `【待填】`。禁止只给原则、不给句子。禁止输出“管委会可作为出让人”“经营性用地可直接协议出让”“闲置满两年必然无偿收回且不问政府原因”“财政返还出让金”充当可放行修改句。

## 9. 谈判与签署提醒

谈判顺序：先红线（出让主体不适格、经营性未招拍挂、财政返还、现状交地推卸净地责任），再必须改（开竣工与开工定义、出让金付清挂钩登记、年限与用途、交地标准、政府原因顺延），最后可优化。签署提醒：成交确认书、宗地图、规划条件作为附件、日期不得倒签。不指导倒签或补假招拍挂。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书、代办不动产登记或效力保证。
