# 审查方法（锁定 土地使用权 / 国有土地使用权出让合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型，禁止打开国有土地使用权转让、集体建设用地出让、勾地或合作开发双文件“对照一下”。

本文件是**国有建设用地使用权一级市场出让**的签前判断节点，不是栏目说明书，也不是二级转让或集体入市审查清单。禁止把 25% 投资额转让限制、带押过户、村民会议三分之二入市写入本类型默认结论。

每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、必然完成不动产登记、对方必然接受或唯一必得金额。

`search_law` 返回已失效《合同法》及其解释、1999 年《闲置土地处置办法》、2002 年《招标拍卖挂牌出让国有土地使用权规定》、1992 年《划拨土地使用权管理暂行办法》、已失效《土地登记办法》、2014 年《土地管理法实施条例》、担保法解释或涉外经济合同法时记为噪声，不得写入 `L#`。2012 年闲置办法第二条、第十四条，城市房地产管理法第十三条、第二十六条未核验现行正文前不得写入 `L#`；一年／两年闲置以后以城市房地产开发经营管理条例（2020）第十五条为已核验同向。出让主体以暂行条例（2020）第十一条和解释（2020）第一条为已核验同向。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突。

示范文本只参考结构。自然资源部与市场监管总局国有建设用地使用权出让合同示范文本不证明本约条款已被接受；符合格式条款定义的，仍按格式条款审查。

### 双文件使用（标题与文件名不完全对应时不拒跑）

同目录两份知识文件按标题语义使用，不回改正文，不因文件名拒跑：

- 含“首部 / 交易条款 / 配套 / 尾部 / 语言”的当框架级条款清单，供节点 8 出句；

- 文件不可用（空、代码块、与本类型明显无关）：记 `G#`，用本方法节点继续，不得改去加载转让或集体出让双文件，不得编造出让金或开竣工日。

## 节点 1　类型识别与负触发

### 1.1 本类型正像

同时满足才继续：

- 核心给付是国家将一定年期的**国有建设用地使用权**有偿出让给受让人，受让人支付**土地出让金**；
- 出让方在规范上应是**市、县人民政府自然资源主管部门**（文本自称不符的，留本任务按硬闸 A 处理，不改定性）；
- 本约是一级市场原始取得或划拨转出让补办，不是已持证使用权人之间的流转。

标题写成“国有建设用地使用权出让合同”“国有土地使用权出让合同”只是线索。名实不符按核心给付归类，标题冲突写入 `C#`。

## 硬闸 A　出让主体

本闸改变能否放行签署。

1. **法定出让人**  
   土地使用权出让合同应由市、县人民政府土地管理部门作为出让方与土地使用者签订（暂行条例第十一条已核验）。2020 年解释第一条将出让方表述调整为**市、县人民政府自然资源主管部门**。机构改革后印章和名称以自然资源主管部门为准，不得写“土地管理局旧章也可”。  
   **修改句**：`出让人为【某市／某县人民政府自然资源和规划局（自然资源局）】。本合同仅由该主管部门作为出让人签署。任何街道办事处、开发区管理委员会、园区管委会、乡镇人民政府或政府平台公司均不得作为出让人，亦不得以“代为出让／受托出让”替代。`

2. **管委会、平台公司、街道办**  
   开发区管理委员会作为出让方订立的土地使用权出让合同，应当认定无效；本解释实施前订立、起诉前经市、县人民政府自然资源主管部门追认的，可以认定有效（解释第二条已核验）。签前文本仍由管委会、平台或街道办作出让人的：红线。不得写成“签署后追认即可”。  
   **修改句**：`删除将【某开发区管理委员会／某城投公司／某街道办事处】列为出让人的条款。改由宗地所在地市、县人民政府自然资源主管部门作为出让人重新签署。用户要求保留管委会或平台公司作为出让人、或写成“签署后由主管部门追认即有效”的，停止出具可签署意见。`

3. **受让人与项目公司承接**  
   受让人通常为招拍挂中标人／竞得人。联合体或投资人成交后拟由全资项目公司承接的，须写明成立期限、股权结构、补充协议变更受让人、原竞得人是否连带。不得在未见出让人书面同意时写成“自动由项目公司承继”。  
   **修改句**：`受让人为成交确认书载明的竞得人【名称】。如需由竞得人设立的全资项目公司承继本合同权利义务，应在【待填】日内完成设立，并与出让人另行签订补充协议变更受让人。未经出让人书面同意，不得视为项目公司已经承继。竞得人对出让金支付和开竣工义务在变更完成前继续承担。`

4. **最强反方**  
   相对方可主张合同已成立、管委会曾获授权或事后可追认。签前仍不得把不适格主体写成可放行。授权委托书未附：签署能力字段停止，不写“可以盖章”。

核验失败：无效／追认例外的法律结论字段停止；“必须改为市、县自然资源主管部门、管委会不得作出让人”的修改句草稿继续。

## 硬闸 B　招拍挂

1. **经营性与多意向必须公开竞价**  
   工业、商业、旅游、娱乐和商品住宅等经营性用地以及同一土地有两个以上意向用地者的，应当采取招标、拍卖等公开竞价方式出让（民法典第三百四十七条已核验）。招拍挂规定第四条同向，工业用地含仓储、不含采矿。国有土地使用权出让应纳入统一公共资源交易平台；除依法可以协议外，应当招拍挂（实施条例第十八条已核验）。  
   **修改句**：`各方确认：本宗地用途为【工业／商业／旅游／娱乐／商品住宅／其他】。属于经营性用地或同一宗地有两个以上意向用地者的，必须以招标、拍卖或挂牌方式出让。本合同以【成交确认书／中标通知书，编号【待填】】为订立基础，该文件作为附件。未见合法招拍挂成交文件的，受让人有权拒绝签署，出让人不得要求以协议方式替代。`

2. **经营性不得协议**  
   同一地块只有一个意向用地者的，市、县国土资源行政主管部门方可协议出让，**但商业、旅游、娱乐和商品住宅等经营性用地除外**（协议出让规定第九条已核验）。文本写“仅一方有意向故协议出让”而用途为商品住宅或商服：红线。  
   **修改句**：`删除“因只有一个意向用地者，双方协议出让”的条款。本宗地用途为【商业／旅游／娱乐／商品住宅】的，不得协议出让。应退回并依法组织招标、拍卖或挂牌；在此之前本合同不签署。`

3. **成交确认与本约**  
   确定中标人、竞得人后，投标／竞买保证金转作受让地块的定金；出让人应发出中标通知书或签订成交确认书，该文件对双方具有法律效力（招拍挂规定第二十条已核验）。知识稿“成交确认后 10 个工作日内签合同”未核验为现行法定，不得写入 `L#`，可作可优化期限。本约不得实质性背离成交确认的宗地、价款、用途。  
   **修改句**：`本合同项下宗地、成交价款、土地用途应与附件成交确认书／中标通知书一致。不一致的，以成交确认书载明且已经公示的条件为准，并在签署前书面修正本合同对应条款。竞买保证金人民币【待填】元在本合同签署后转作定金，定金数额不超过出让价款的百分之二十；超过部分作为预付出让金，不适用定金罚则。`

4. **协议出让低价**  
   经批准的协议出让，出让金低于订立合同时当地政府按国家规定确定的最低价的，价格条款无效；可按订约时市场评估价补足，受让方不同意补足可请求解除（解释第三条已核验）。  
   **修改句（仅依法可协议的宗地）**：`协议出让价款不得低于订立本合同时当地政府按规定确定的最低价。低于最低价的条款不发生效力，受让人应在【待填】日内按订约时市场评估价补足；受让人不同意补足的，任何一方可书面解除，已收款扣除合法定金后返还。`

5. **最强反方**  
   未走招拍挂并不当然使一切条款均无约束；受让人可能已投入前期费用。签前不得写成“未招拍挂则合同当然全部无效”，也不得写成“双方同意即可补走协议”。经营性未招拍挂：不改成可履行。

核验失败：招拍挂是否导致无效的法律结论字段停止；“经营性必须公开竞价、成交文件作附件”的修改句草稿继续。

## 硬闸 C　开发期限与闲置

1. **必须写清开竣工，并界定开工**  
   房地产开发企业应按出让合同约定的土地用途、动工开发期限开发（开发经营条例第十五条已核验）。框架要求开工日期必须界定为“取得施工许可证并实际破土动工”，防止因标准模糊导致闲置争议。只有“尽快开工”“具备条件后开工”视为必须改。  
   **修改句**：`受让人应于【年／月／日】前开工，于【年／月／日】前竣工。开工是指受让人已依法取得建设工程施工许可证，并在宗地现场实际破土动工。仅完成围挡、临建、场地平整或取得施工许可但未破土的，不视为开工。竣工是指【通过规划核实／竣工验收备案，见附件标准】。`

2. **满一年、满两年**  
   约定动工开发期限满 1 年未动工的，**可以**征收相当于土地使用权出让金 **20% 以下**的土地闲置费；满 2 年未动工的，**可以**无偿收回土地使用权。因不可抗力或者政府、政府有关部门的行为或者动工开发必需的前期工作造成动工迟延的除外（开发经营条例第十五条已核验）。知识稿“闲置费＝出让金 20%”“满两年无偿收回”应降级为上限和裁量，不得写成必然、固定。2012 年闲置办法第二条、第十四条运行时再核，不写入 `L#`。  
   **修改句**：`因受让人自身原因，超过约定动工开发日期满一年未动工开发的，出让人可以依法征收不超过出让价款百分之二十的土地闲置费；满两年未动工开发的，出让人可以依法无偿收回国有建设用地使用权。闲置费比例、是否收回，应在调查核实并送达相应决定后执行，不得写成签约即预收闲置费，亦不得写成满两年必然无偿收回、不问除外情形。`

3. **政府原因与交地挂钩**  
   因未按有偿使用合同约定期限、条件交地致使不具备动工条件，或因规划依法修改、国家政策、信访、军事管制、文物保护等政府行为造成动工延迟的，使用权人应说明原因，经审核属实后按延长动工期限（补充协议重新约定，延长最长不超过一年）、调整用途规划、临时使用、协议有偿收回或置换等方式处置（闲置办法第八、十二条已核验）。因政府拆迁未净导致延期交付的，受让人有权要求顺延开竣工。  
   **修改句**：`出让人应于【年／月／日】前按附件标准交付净地，并签署土地交付确认书。净地是指权属清晰、补偿安置到位、地块内无合法障碍物、具备约定开工条件。因出让人或政府有关部门未按约定期限、条件交地，或因规划依法修改、文物发现、不可预见地下障碍物等政府原因致使受让人不能按期开工的，开竣工日期相应顺延，顺延天数不少于实际延误天数，且不得据此认定土地闲置或计收闲置费。需要延长动工开发期限的，双方应签订补充协议，重新约定的动工开发日期起算后，延长期限按闲置土地处置规则办理。`

4. **现状交地陷阱**  
   文本以“现状交付”推卸拆迁未净：必须改。五通一平、七通一平、现状交地必须落到可核验清单。  
   **修改句**：`删除“按现状交地、受让人自行负责拆迁清表且不影响开竣工起算”的条款。交地标准为【五通一平／七通一平／附件交地条件清单】。未达到该标准的，交付日不成立，开竣工起算日不开始。`

5. **最强反方**  
   闲置认定须调查、下达认定书，不是合同自动发生；满两年收回是“可以”而非必然。签前不得写成“逾期一天即视为闲置并收回”，也不得写成“双方约定排除闲置规定”。政府原因除外不得被合同单方删除。

核验失败：百分之二十以下、满两年收回的法律结论字段停止；开竣工落句、开工定义、交地挂钩顺延的修改句草稿继续。

## 硬闸 D　与转让、集体建设用地切开

1. **资金流向与主体**  
   本类型对价是受让人向国家支付的**出让金**，收款账户应为财政或自然资源主管部门规定账户。对价付给已持证使用权人或村集体、乡镇：按节点 1.2 转出。  
   **修改句**：`本合同项下款项性质为国有建设用地使用权出让金，由受让人缴入【财政／自然资源主管部门指定账户】。任何将本价款改付已登记使用权人、农村集体经济组织、村民委员会或平台公司一般户的安排，均不得解释为本合同的履行。`

2. **标题噪声**  
   标题写“转让”但出让人是市、县自然资源主管部门、对价是出让金 → 留本任务，标题必须改。标题写“出让”但卖方是已持证使用权人 → `国有土地使用权转让合同·审查`。标题写“国有出让”但出让人是村委会、地是集体经营性建设用地 → `集体建设用地使用权出让合同·审查`。  
   **修改句**：`合同名称由“土地使用权转让合同／集体土地出让合同”改为“国有建设用地使用权出让合同”。全文“转让价款”“转让人”统一改为“出让金”“出让人”。删除把已持证使用权人或村民委员会列为出让人的表述。`

3. **禁止用本任务改转让或入市结构**  
   出现投资额 25%、带押过户、优先购买：不得当出让条款改完。出现村民会议三分之二、土地增值收益调节金、集体土地所有权不变：不得当国有出让改完。  
   **修改句（仅告知，不提供规避路径）**：正文出现已持证使用权人转让或集体经营性建设用地入市结构的，停止按国有出让完成本任务，转 国有土地使用权转让合同·审查 或 集体建设用地使用权出让合同·审查。不得删除 25% 投资额或村民决议条款后继续按本类型出可签署意见。

4. **最强反方**  
   用户称“就是拿地合同，先按出让改”。签前按核心给付分流，不两套都审。

## 节点 2　主体、授权、规划与批准

1. 建主体表：出让人全称与印章名称、受让人／竞得人、拟承接项目公司、母公司保证人、法定代表人／授权签字人。名称不一致不自动合并。
2. 核验出让人是否市、县自然资源主管部门。口头“管委会说局里会盖章”不得写成已授权。
3. 受让人涉及重大资产购置的内部董事会／股东会决议未附：企业签署字段停止，不写“可以盖章”。
4. 划拨转出让：未见有批准权的人民政府批准及补缴出让金安排，转出让字段停止。1992 年划拨办法不得当现行依据。
5. 外资、负面清单、安全审查未核：准入字段停止。
6. 规划用途与出让年限必须对应：居住 70 年、工业 50 年、教育科技文化卫生体育 50 年、商业旅游娱乐 40 年、综合或其他 50 年（暂行条例第十二条已核验）。年限与用途冲突：必须改。

不足：字段停止，列出待补材料，不补主体。

## 节点 3　标的、净地、地下空间

1. 宗地须写到：编号、坐落、四至、出让面积与净用地面积、宗地图。只有“某区一块地”则标缺口。实测面积与出让面积不符，须约定价款多退少补。
2. 规划指标：容积率上下限、建筑密度、绿地率、建筑高度、自持比例、限制销售对象。擅自改变用途或超容积率：解释第五、六条点名调整出让金或解除，不在本任务宣告已解除。
3. 地下空间、人防、轨道交通预留未界定：必须改，不得默认地表出让含地下。
4. 权利负担：查封、抵押、未了结征收、红线重叠。材料未提及不得写成“无权利负担”，只能写 `依据不足`。
5. 风险自土地交付确认书签署之日起转移。未签确认书不得写成已交付。

## 节点 4　程序与生效

把招拍挂、成交确认、批准、交地、付清出让金、登记写成**义务和期限**，不写成已经完成。

| 文本写法 | 本任务动作 |
| --- | --- |
| “本合同签字盖章后立即生效，三日内核发不动产权证” | 拆成成立 vs 付清出让金 vs 登记设立；删除立即发证 |
| “视为已招拍挂／已净地／已无闲置风险” | 纠正：招拍挂、交地、闲置除外须有可核验事实 |
| 把不动产登记写成合同成立要件 | 纠正：建设用地使用权自登记时设立（民法典第三百四十九条），未登记不等于本约未成立 |
| 未付清出让金却按比例分割发证 | 纠正：付清全部出让价款后方可申请登记，不得按缴纳比例分割发证（招拍挂规定第二十三条；暂行条例第十六条） |
| 用户要求倒签或补假招拍挂 | 整体停止 |

暂行条例第十四条：土地使用者应当在签订出让合同后六十日内支付全部出让金，逾期未全部支付的，出让方有权解除并请求违约赔偿。实务常分期：可谈分期，但未付清不得登记、不得写成已排除解除权。出让方未按合同提供土地使用权的，土地使用者有权解除并请求违约赔偿（第十五条）。

不得把“双方同意视为已招拍挂／已批准／已交净地”写成可放行结构。

## 节点 5　对价、定金、违规返还

1. 出让金总额、是否含市政配套和拆迁补偿、币种、发票、支付节点分列。未给出的数字写 `【待填】`。
2. 定金：必须使用“定金”二字才讨论罚则。招拍挂规定第二十条：保证金转作定金。约定或推算超过主合同标的额百分之二十：超过部分不产生定金效力。无核验引文不得把 20% 写成现行法结论。
3. 分期利息与违约金叠加：标必须改，避免重复计收，基数写清是总地价还是未付部分。
4. 财政补贴、返还、奖励变相退还出让金：红线，只告知，不改成可履行。
5. 禁止编造单价、总价、开竣工日。

## 节点 6　格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 格式条款

政府示范文本填充版仍可能构成格式条款。审查最终解释权、无偿收回、单方调整规划、管辖是否有显著提示。仅电子勾选不足。出让人单方保留“最终解释权”或“根据规划调整无偿收回”：标红旗，给出删除或对价调整句，不在本任务宣告该条已经无效。

### 6.2 强制规范

违反法律、行政法规强制性规定不一律无效（民法典第一百五十三条）。区分规范目的是否导致民事行为无效、是否只规制履行或行政管理。禁止用已失效“效力性／管理性”口诀。经营性未招拍挂、出让主体不适格：多用解释第二条、民法典第三百四十七条作为红线理由，不轻易写“未招拍挂则一切条款当然无效”。财政返还、商办改住、掩盖未净地：只告知，不写假架构。

## 节点 7　违约、解除、争议解决

1. 受让人逾期付款、逾期开竣工；出让人逾期交地、规划指标与附件不符：必须分别有日违约金或固定金额，以及达到【待填】日的解除权。只有“依法承担违约责任”视为必须改。出让人迟延交地超过约定期限（如 60 日），受让人侧可谈单方解除和定金返还；受让人逾期付款超约定期限，出让人可解除。不得把知识稿 60 日写成已核验法定。
2. 构成违约不等于当然解除。法定或行政收回只点名调查、决定书，不在本任务作出已收回结论。
3. 违约金避免“不得调整”或“按总地价百分之三十必得”。计收基数写清总地价还是未付部分。
4. 争议解决：  
   - 行政协议规定第二条将“矿业权等国有自然资源使用权出让协议”列入行政诉讼受案范围。国有建设用地使用权出让合同主流观点倾向行政协议，但 2020 年民事解释仍然现行。签前可提示管辖可能走行政诉讼，**不得**写“必须行政诉讼、民事解释已废”或擅自把已有仲裁／管辖条款改成“应向某法院行政庭起诉”并假装已选定。  
   - 或裁或诉、机构不明：改成单一连结点；土地所在地可作为约定连结点，须写成约定。
5. 微信已读不写成已经送达，除非合同把该渠道定为送达。

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

对照已加载框架级文件和本方法硬闸，按六步逐段出句。

| 步 | 本类型必须盯的点 | 必须产出 |

| 常见问题 | 管委会当出让人、经营性协议出让、现状交地、地下空间未界定、最终解释权、股权并购规避闲置 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（出让主体不适格、经营性未招拍挂、财政返还、未净地视为已交、查封地可登记、补假招拍挂）；

- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级出让金或个人／母公司无限连带且用户拒绝升级：停止“可以签署”建议。
