# 边界与路由

本技能只审查 **房地产合同 / 联建模式联建合同**。

必须同时读出：双方共同开发特定地块；以及以**双名义报建、共同确权、竣工后直接初始登记**为主结构。标题叫“联建”但手续单名义、确权走二次过户的，不得留在本技能做实体结论。禁止把全部联建子类型写进本技能审完。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或标题联建、核心给付明显不是双名义报建加直接初始登记 | 本套导航的类型切开步骤 |
| 单名义报建，投资方隐名，确权走商品房买卖或资产转让过户 | `隐名参建联建·审查`；专业版未收录该 P1 时输出 `unavailable`，不得硬套本技能改成二次过户 |
| “一方出地，一方出钱”，审查重点是出资结构而非双名义手续 | `一方出地一方出钱联建·审查` |
| “一方出地，双方出钱” | `一方出地双方出钱联建·审查` |
| “双方出地” | `“双方出地”型联建合同·审查` |
| 不共担风险，固定货币、固定房屋或只使用 | `不共担风险型联建合同·审查`；固定货币还可提示 `资金方只收固定货币→第二十三条转` |
| 共担风险但无双名义、无直接确权主结构 | `共担风险型联建合同·审查` |
| 一方单独操盘 | `一方操盘型联建合同·审查` |
| 联合操盘但无双名义办证 | `联合操盘型联建合同·审查` |
| 概括合作开发，读不出双名义直接确权 | `房地产合作开发类合同·审查` |
| 委托代建，无共同权利人地位 | `委托代建合同·审查` 或 `或` |
| 单纯出让土地使用权转让，或未达投资额变相卖地 | `国有土地使用权转让合同·审查` |
| 新设或收购项目公司、股权取得土地或开发权 | `以股拿地·审查`、`或` 或 `城更股权合作·审查` |
| 宅基地或集体土地合作建房 | `宅基地合作开发合同·审查` |
| 资金监管专约，联建正文已另审 | 可提示 `资金监管协议·审查`；双名义与直接确权仍是放行关键则留本技能 |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、问报建进度、出资、验收 | 本套导航的履约步骤 |
| 已成争 | 合同争议领域或对应专项；不写确权诉状、执行异议申请 |
| 用户只要税额或分房面积终局数字 | 税务或测算；本技能只审条款 |
| C 端大众快检 | 只分流，不回改 |

同一文本既写“双名义直接登记”又写“先办出地方大证再买卖过户”：按核心结构切开。双名义且直接初始登记主导 → 留本技能，过户句必须改。二次过户主导 → `隐名参建联建·审查`。两可且无法判断：负触发引擎，不灌两套知识。

挂靠、违法分包、规避限购、未达百分之二十五投资额变相转让：停笔告知，不改写成可履行文本。

禁止在正文写半截 Skill ID。转出时必须写完整 ID，例如 `隐名参建联建·审查`、`一方出地一方出钱联建·审查`。
