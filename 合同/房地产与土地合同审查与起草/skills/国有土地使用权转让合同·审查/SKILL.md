# 国有土地使用权转让合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、《物权法》、2005 年《最高人民法院关于审理涉及国有土地使用权合同纠纷案件适用法律问题的解释》已删除的第九条／第十一条／第十六条、已失效《划拨土地使用权管理暂行办法》当作现行规则。命中 1994 年《城市房地产管理法》旧条序时，改走 2019 修正本：第三十九条是出让地再转让条件，第四十条是划拨地转让报批。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **土地使用权 / 国有土地使用权转让合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「国有土地使用权转让合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性或过户保证、把出让／股权拿地／真实合作开发／集体建设用地改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **投资开发条件**：出让地再转让须符合《城市房地产管理法》第三十九条：已付清全部土地使用权出让金并取得土地使用权证书；房屋建设工程完成开发投资总额百分之二十五以上；成片开发土地须形成工业用地或其他建设用地条件。房屋已经建成的，还应当持有房屋所有权证书。未达投资条件**不得写成合同必然无效**，也不得保证一定能办变更登记。修改句必须把专项审计（并约定投资总额是否含土地取得费）、形象进度和证书作为中期款或过户条件。伪造审计、倒签投资进度：红线。
2. **变更登记**：建设用地使用权转让应当向登记机构申请变更登记（民法典第 355、209 条）。未办理物权登记不影响合同效力（第 215 条；2020 年国有土地使用权合同解释第 8 条），但物权不发生转移。修改句必须拆开合同成立／生效与权利变动，写清申请主体、申请期限、税费清缴顺序、因不可归责于双方的原因无法过户时解除并原数退款。禁止“签字即视为已过户”或“双方同意视为已登记”。
3. **划拨补办出让**：划拨土地使用权转让须报有批准权的人民政府审批；准予转让的，由受让方办理出让手续并缴纳土地使用权出让金；政府决定不办理出让手续的，转让方上缴土地收益，或按 2020 年解释第 10、11 条作补偿性质合同处理（《城市房地产管理法》第四十条；暂行条例第四十五条；民法典第 502 条）。未批准不得写成可以过户。禁止“双方同意视为已批准”“先过户再补办”。
4. **与股权拿地切开**：核心给付是收购项目公司股权或控制权、土地仍登记在公司名下的，负触发 `以股拿地·审查`。不得把股权协议改成土地使用权变更登记结构，也不得在本任务宣告“买股权就是买地、合同无效／有效”。

配套必须改：付给转让人的对价只能写成“转让价款”，禁止用“出让金”指这笔钱；供地方不承担经营风险、只收取固定现金或固定面积的，按本类型穿透，不转真实合作开发；闲置未处置、查封未解：不得写成可过户。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签转让正文或可核对的合作外观文本，尚未签署，尚未成争，核心给付是土地使用权人把国有土地使用权流转给受让人、受让人支付转让价款；或供地方不担风险、只收固定利益。用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 出让方是市、县人民政府自然资源主管部门，对价是土地使用权出让金 → `国有土地使用权出让合同·审查`；不得按本技能改招拍挂或行政协议专章；
- 对价是项目公司股权／控制权，土地不办理权利人变更登记 → `以股拿地·审查`；专业版未装则 `unavailable`；
- 双方共同投资、共享利润、**共担风险** → `房地产合作开发类合同·审查`；
- 土地置换 → `土地置换协议·审查`；一级市场联合拿地 → `一级市场联合拿地类合同·审查`；
- 集体建设用地、宅基地类 → `集体建设用地使用权出让合同·审查` 及后续集体／宅基地原子；
- 一般公司股权转让且不以获取该地块为交易目的 → `或` 或 `或`；
- 无文本、本类型条件已谈妥、要出己方稿 → `国有土地使用权转让合同·起草`；
- 已签只问付款日、交地日、过户留痕 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

阴阳低价备案避税、伪造投资额、补假批准、规避限购：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（转让人侧或受让人侧择一）；相对方；全文及原出让合同／权属证书／划拨决定书版本；取得方式；出让金是否缴清；投资额与基数；闲置、抵押、查封、租赁；划拨报批与补缴主体；价款是否分列地价与地上物；税费是否写明土地增值税；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `国有土地使用权转让合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有二级市场转让文本，才进入本任务。

### 1. 类型锁死与邻接切开

标题、核心给付与对价方式一致才继续。出让、股权拿地、真实合作开发、集体土地负触发。留下本类型的，必须标明取得方式（出让／划拨）和是否“名为合作、实为转让”。

### 2. 主体、权属与负担

转让人须是证载权利人或有权处分人。共有、国资评估进场、抵押、查封、租赁、居住权未闭合：字段停止，不写“可以过户”。

### 3. 硬闸：投资开发条件

核验出让金、证书、25% 或成片开发条件、已建成房屋所有权证书。缺审计口径必须改。未达标：锁死付款／过户条件，不宣告合同无效。

### 4. 硬闸：变更登记

拆开债物。补申请义务、期限、税费顺序、无法过户退出。禁止视为已登记。

### 5. 硬闸：划拨补办出让

报批主体、批准前不得过户、受让人办出让并缴出让金或按政府决定走土地收益／补偿合同。禁止先过户再报批。

### 6. 价款、税费、闲置、交付与抵押

价税分离；土地增值税点名；闲置与动工延期；现状交地还是净地；带押须通知抵押权人并写清解押或带押过户路径。

### 7. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效或保证过户、伪造投资审计、补假批准、划拨未批先过户、阴阳低价备案、把股权拿地改成直接变更登记仍要放行。
- `字段停止`：法域、地方转让审批是否生效要件、25% 是否达标、批准能否取得、带押过户窗口、土增税金额未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。

生存级已付价款或个人无限连带且用户拒绝升级：停止“可以签署”建议。
