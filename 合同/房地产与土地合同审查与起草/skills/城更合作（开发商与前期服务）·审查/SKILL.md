# 城更合作（开发商与前期服务）·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、1993 年《反不正当竞争法》第七条旧义、失效技术合同法实施条例当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **房地产合同 / 城市更新项目合作合同（开发商与前期服务公司）** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「城更合作（开发商与前期服务）·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证中选或批文一定办成。

## 本类型硬闸

1. **名合作实委托服务（射幸＋居间＋事务处理）**：标题写合作、顾问、拓展，不决定类型。本约是开发商委托前期服务公司处理特定更新单元事务，报酬绑定“委托方正式签约成为合作企业”这一不确定结果，并叠合报告／促成交易机会。对价是服务费，不是利润分成，也不是出资入股。共享利润或共担建设经营风险 → 合作开发，不是本类型。
2. **与前期服务合同 `城市更新项目前期服务合同·审查` 切开**：当事人是村集体／更新主体与前期服务公司，或核心只是意愿征集、测绘、入库、方案编制等前期作业，不以本开发商正式签约成为合作企业为成功标准、无排他支持该开发商 → 负触发 `城市更新项目前期服务合同·审查`。禁止打开或复制其 method。
3. **与股权合作 `城更股权合作·审查` 切开**：主结构是项目公司／SPV、股权出资、持股比例、对赌摊薄、股东一票否决、股权回购或收购前期服务公司股权以完成项目更替 → 负触发 `城更股权合作·审查`。框架里的“股权锁定把承揽转合伙”若已经是主给付，不得留在本技能改完。禁止打开或复制其 method。
4. **禁止包办批文／确保中选**：不得放行“包办批文”“确保中选／过会／推选通过”。改为节点化协助与可核验 KPI。行政机关、村集体决定不能被合同买断。
5. **廉洁／商业贿赂红线**：无实际服务的畸高协调费、账外咨询费、向利用职权或影响力的单位或个人输送利益，只出告知，不改成可履行路径。对价名称用“前期拓展服务费”，佣金须明示入账。
6. **禁止一次性全额预付；阶梯支付＋共管**：写成少量启动金＋节点达成费＋中选成功费＋质保尾款；大额款项优先共管。规划指标变动须同向调整计费基数。测绘费、专家费是否包含必须闭合。
7. **资源筹码闭合＋一马多卖／跳单**：村集体前期服务协议、内部表决或成员大会、政府备案或先发优势未闭合则字段停止。双向排他，锁定核心执行人。开发商利用已移交资料绕开受托方对接，不得写成可以停付。
8. **成功标准锁死＋非中选／政策结算分流**：成功只认委托方或其指定主体正式签约成为项目合作企业。区分促成签约与仅提供信息。非中选按受托方违约／委托方原因／政策收储／后续中选方补偿金归属分流。政策强制性调整导致无法推进的，互不违约、按实结算。费用结清后资料与申报成果归开发商；底价、公关路径、财务测算永久保密。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签正文，尚未签署，尚未成争，当事人是开发商与前期服务公司，核心给付是排他促成该开发商成为合作企业并处理相应事务，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 当事人是村集体／更新主体与前期服务公司，或只做前期作业、无“本开发商成为合作企业”成功标准 → `城市更新项目前期服务合同·审查`；
- 主结构是股权、SPV、持股、对赌、回购前期公司股权 → `城更股权合作·审查`；
- 仅意向、无成功费与排他闭环 → `城市更新项目意向合作协议·审查`；
- 当事人是村集体与合作企业，分配物业或土地权益、选定实施主体 → `城更合作（村集体与企业）·审查`；
- 共同出资、共享利润、共担建设经营风险 → `房地产合作开发类合同·审查`；宅基地或集体建设用地合作开发外观 → `宅基地合作开发合同·审查` 或 `集体建设用地合作开发合同·审查`；
- 主文件只是资金监管协议 → `资金监管协议·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `城更合作（开发商与前期服务）·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁或已立案调查 → `或对应专项领域。` 或对应专项。

挂靠、违法分包、规避限购、包办批文、空转贿赂、伪造表决：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及附件／红线图／村集体协议／廉洁协议／资金监管协议版本；更新单元是否特定；当事人是否确为开发商与前期服务公司；成功标准如何写；费用是服务费还是利润／股权；是否排他；村集体筹码与备案；是否出现包办批文、咨询费、明服暗贷；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `城更合作（开发商与前期服务）·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议或专项。未签且目标是评改已有本类型文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。前期服务、股权合作、意向协议、村集体本约、合作开发负触发。

### 2. 主体、资质、村集体筹码

开发商房地产开发资质与资金调度；前期服务公司村集体协议、表决、备案；核心团队；授权签字人。

### 3. 成功标准、服务范围与资料归属

正式签约成为合作企业；节点 KPI；排他与招商文件介入须经开发商书面确认；资料结清后归开发商。

### 4. 对价、共管、定金与政策／非中选结算

阶梯支付；禁止一次预付；规划指标同向调整；二次收费闭合；政策按实结算；后续补偿金归属。

### 5. 跳单、排他期解除与核心人员

双向排他；跳单应付报酬；排他期满无实质进展可单方终止；核心人员锁定。

### 6. 廉洁、强制规范与格式条款

空转咨询费、包办批文、向影响力主体输送利益停笔。无核验引文则法律结论字段停止。

### 7. 违约、解除、争议

跳单、一马多卖、服务失败、政策叫停必须分别有可执行后果。禁止“不得调整”的违约金。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效或保证中选、把前期服务或股权合作改成其外壳仍放行、把包办批文或空转贿赂改成可履行。
- `字段停止`：法域、动态规则、村集体表决、备案、规划指标、非中选原因未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
