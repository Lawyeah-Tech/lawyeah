# 隐名参建联建·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《物权法》《担保法》及其解释、已失效《关于审理联营合同纠纷案件若干问题的解答》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **房地产合同 / 参建模式联建合同（隐名开发模式）** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「隐名参建联建·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证过户或排除执行、显名联建或借款文本评改。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **隐名对外**：立项、报建、施工许可、预售许可、总包、采购、对外销售一律以出地方单一名义。投资方不得以自己名义对外签署商品房买卖合同或充当预售出卖人。出现双名义报建或双方同为开发主体 → 负触发 `联建模式联建合同·审查`。
2. **物权 / 销售资格**：投资方不因参建协议取得土地、在建工程或建成房屋的登记物权。首次登记只能做出地方。销售资格只在具备房地产开发资质并取得预售许可的出地方。二次确权走商品房买卖或资产转让，且以出地方已具备销售条件为前提。禁止写成投资方享有共有物权、准物权或初始登记权。
3. **与显名联建切开**：双名义报建、共同出现在许可或销售文件上 → `联建模式联建合同·审查`。禁止打开或抄写该原子 method。标题写“联建”但正文单一名义、投资方隐名：留本技能，标题冲突写入 `C#`。
4. **共担风险**：不分担亏损、只收取固定回报或固定本息 → 负触发 `资金方只收固定货币→第二十三条转` 或 `不共担风险型联建合同·审查`。禁止把“再签一份借款合同当资金输出名义”写成可放行最佳实践。
5. **内部协议不对抗第三人**：未办理抵押登记或符合条件的预告登记前，投资方对出地方债权人通常只是普通债权。禁止写成已经优先受偿或必然排除执行。
6. **二次过户税费与预告登记条件**：契税、增值税、土地增值税必须预提分担。预告登记须有买卖房屋或其他物权协议，不能仅凭参建协议办理。
7. **违法结构只告知**：规避限购、未达转让条件变相转地、出借资质挂靠、阴阳借款包装：不改成可履行结构。用户坚持：整体停止。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签参建/隐名开发正文，尚未签署，尚未成争，核心给付是共同出资、共担风险、共享利润，但行政报建与对外销售只显示出地方，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 双名义报建，双方同为立项、施工许可或预售许可上的开发主体 → `联建模式联建合同·审查`；
- 不分担亏损、只收取固定回报或固定本息 → `不共担风险型联建合同·审查` 或 `资金方只收固定货币→第二十三条转`；企业间借款主文件 → `或`；
- 出地方只出地、对方收固定代建费或不共担经营风险 → `委托代建合同·审查` 或 `或`；
- 核心给付是出让土地使用权直接转让 → `国有土地使用权转让合同·审查`；
- 主文件是商品房买卖本约 → `普通商品房买卖价款五证网签主结构→`；不得删掉本约条款后继续当参建审；
- 一方出资不显名、不参与项目监督、不承担亏损 → `一方出资不显名不参与项目监督不承担亏损→`；股权代持作为主文件 → `或` 或 `或`；
- 主文件是施工承包 → `操盘方自己施工或按造价取费→`；
- 无文本、本类型条件已谈妥、要出己方稿 → `隐名参建联建·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、查封执行异议、破产债权申报、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

规避限购、未达转让条件变相转地、挂靠资质：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（出地方/显名开发方或投资方/隐名参建方择一）；相对方；全文及二次过户方案、共管账户、抵押质押附件版本；报建与预售是否单一名义；是否共担亏损；出地方土地使用权与开发资质；投资方是否被写成出卖人或共有登记权利人；二次确权路径与税费；拟登记担保；销售回款账户；土地出让合同是否禁止改变投资主体；不可接受事项；法域、项目所在地与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的出资、比例、税费、期限用 `【待填】`，不编造。

宿主可调用时：`search_law` 核验合作开发定义与资质、不承担经营风险的定性、物权公示与预告登记、预售许可与销售主体、执行异议买受人条款；`search_practiced` 只补审查反例；`search_template` 只借栏目结构。不虚构案件系统。

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。禁止打开 `联建模式联建合同·审查` 的 method。`基本面.md` 中“联建模式具有准物权效力”不得当成现行规则；“参建合作协议 + 借款合同作为资金输出名义”不得当最佳实践放行。`框架.md` 中“严禁使用初始登记”只禁止把投资方写成首次登记权利人，出地方办理首次登记后二次买卖变更登记才是本类型路径。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `隐名参建联建·起草`；已签履约 → 本套导航履约步骤；已成争或执行异议/破产 → 合同争议。未签且目标是评改已有隐名参建文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。双名义显名联建、固定回报、代建、转地、买卖本约、隐名合伙负触发。

### 2. 主体、资质与单一名义

出地方土地使用权与开发资质未核：字段停止。报建与对外合同必须锁死出地方单一名义。

### 3. 物权定位、销售资格与二次确权

投资方是合同债权人。首次登记做出地方。销售资格只在出地方。二次过户税费必须落句。

### 4. 共担风险与资金闭环

亏损分担、超支、行政处罚对内分担必须写清。固定回报负触发。共管账户不得写成已优先于出地方债权人。

### 5. 担保、预告登记与执行风险

股权质押、土地或在建工程抵押须办理登记才可能优先受偿。预告登记须有买卖或抵押协议。不得保证排除执行。

### 6. 格式条款与强制规范

无核验引文则法律结论字段停止。25% 投资额条款不当然写成民事无效。

### 7. 违约、解除与争议

挪用资金、拒绝二次过户、出地方失信须有可执行后果。不选定唯一法院充作意见。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、保证过户或排除执行、把投资方改成预售出卖人或首次登记权利人、把固定回报或未达转让条件变相转地改成可履行结构。
- `字段停止`：法域、出地方资质与权证、出让合同限制、预售许可、地方资金监管、税负口径未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议或执行异议文书，或已锁他类。
