# 边界与路由

本技能只审查 **土地使用权 / 国有土地使用权出让合同**。主线是市、县人民政府自然资源主管部门将一定年期的国有建设用地使用权有偿出让，受让人支付出让金。不是二级市场转让，也不是集体建设用地入市。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 转让人是已取得不动产权证的使用权人；对价是转让价款；政府不是出让方；出现 25% 投资额、带押过户、优先购买 | `国有土地使用权转让合同·审查` |
| 出让人是农村集体经济组织或村民委员会；标的是集体经营性建设用地；须村民会议或村民代表三分之二同意 | `集体建设用地使用权出让合同·审查` |
| 主文件是用地预申请、意向用地申请 | `用地预申请协议·审查` |
| 与非出让人（管委会、平台公司、招商办）签订的勾地、拿地意向 | `与非出让人签订的勾地协议·审查` |
| 多方联合勾地 | `联合勾地协议·审查` |
| 一级市场联合竞买、合资拿地投资协议；出让合同只是附件 | `一级市场联合拿地类合同·审查` |
| 收购项目公司股权以获取土地 | `以股拿地·审查` |
| 共同投资、共享利润、共担风险的合作开发为主给付 | `房地产合作开发类合同·审查` |
| 委托代建为主给付 | `委托代建合同·审查` |
| 土地置换为主给付 | `土地置换协议·审查` |
| 集体建设用地出资入股、租赁、合作开发 | `集体建设用地使用权出资入股合同·审查` 及对应集体原子 |
| 宅基地合作开发、内部买卖、租赁／委托运营 | 对应宅基地原子；不按本类型硬套 |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、问交地日／缴款日／办证留痕 | 本套导航的履约步骤 |
| 催缴出让金、闲置认定／收回、解除、行政诉讼或民事诉讼已催告、立案、开庭或仲裁 | 土地／行政争议领域；不填签前十节 |
| 街道办、管委会、平台公司被写成出让人 | 留本任务只出红线；用户坚持改成可履行则整体停止 |
| 经营性用地未招拍挂却直接协议出让 | 留本任务只出红线；用户坚持则整体停止 |
| 财政补贴返还出让金、商办改住、以股规避闲置或转让限制 | 留本任务只出告知；用户坚持改成可履行则整体停止 |
| 国资未评估／未批或外资／安全审查未核 | 字段停止；不写场外可履行 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。

本技能不得转去加载转让或集体建设用地双文件完成本类型审查，也不得把 25% 投资额转让交割包或村民会议三分之二入市清单写成国有出让默认主路径。
