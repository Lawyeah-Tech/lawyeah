# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受、预售或登记必然办成；编造未给出的出资额、分成、工期；把已失效《合同法》及其解释、1990 年联营解答、解释原第十六条、2005 年解释同号旧义写入结论；把本约改成出地方不再出钱或项目公司股权主路径。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。成果名称写「审查“一方出地，双方出钱” 型联建合同（房地产合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、1990 年联营解答、解释原第十六条、2005 年解释同号旧义时记噪声，不得写入 `L#`。解释第二十一、二十三条全文未核验的，不写入 `L#`。

## 3. 类型与加载路径

父级、子级、定性理由、易混切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读其他类型，未打开 `一方出地一方出钱联建·审查` 或 `房地产合作开发类合同·审查` 的 method。挂靠、违法分包或先干后补出让写停笔告知，不填可履行结构。

## 4. 主体、授权、决议与文本版本

主体表：签约名、履行名、付款名、发票名、土地权利人、报建名义人、销售主体、授权签字人。版本表：正文、投资预算表、分成明细、资金监管协议、抵押银行意见、聊天确认；冲突并列，不选对用户有利的一版。口头同意不得写成已决议。

## 5. 给付闭环

宗地四至与用途、土地作价、双方现金比例与里程碑、超支追加、实物或货币分成、亏损分担、共管账户、报建名义、预售条件、抵押负担。缺口标 `G#`，不补商业数字。批准、登记、预售许可写成生效条件或双方义务期限，不写成已经完成。预售款不得写成可充抵出资。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹；异常条款。强制规范只区分是否导致民事行为无效。双方均无开发资质：按已核验解释第十三条处理效力字段。无 `search_law` 引文则其他效力字段停止，事实摘录继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔／转出口径。禁止输出无修改句的色块表。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`，不编造。禁止只给原则、不给句子。

## 9. 谈判与签署提醒

谈判顺序：先红线（出地方不再出钱、固定必付、划拨／集体地先动工、挂靠、预售款充抵），再必须改（同比例、追加、共管、治理、抵押同意、安全求偿），最后可优化。签署提醒：双方法人公章与内部决议、权属证与负担查询、预算表与分成明细、资金监管协议、抵押权人书面同意、日期不得倒签。不指导补假批准或假银行同意函。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书或效力保证。复核清单至少包括：出地方是否另出建设资金；是否共担亏损；是否被写成项目公司股权或一方单独出钱；土地是否出让；至少一方或拟设企业是否有开发资质；共管账户与追加投资是否闭合。
