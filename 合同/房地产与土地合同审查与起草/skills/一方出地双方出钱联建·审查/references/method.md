# 审查方法（锁定 房地产合同 / “一方出地，双方出钱” 型联建合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止打开或复制 `一方出地一方出钱联建·审查` 的「一方出地、一方单独出钱」主路径，禁止打开或复制 `房地产合作开发类合同·审查` 的项目公司股权／注册资本主路径，禁止复制操盘授权、双名义报建、隐名参建或代建费主路径。

定性校验：标题、核心给付与本类型一致才继续；出地方不再出钱、双方出地、项目公司股权、操盘／参建／双名义、代建或固定回报明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、保证预售或登记一定办成或唯一必得金额。

`search_law` 返回已失效《合同法》及其解释、1990 年联营解答、解释（2005）同号旧义、解释原第十六条（划拨地合作一律无效）时记为噪声，不得写入 `L#`。解释（2020 修正）第二十一、二十三条本窗未稳定命中全文：出地方固定利益按转让切开、资金方固定货币按借款切开，条号运行时再核。

示范文本只参考结构。检索到的《房地产联建协议》常写“乙方出全部建设资金、分得固定回报”：这是 `一方出地一方出钱联建·审查` 或借贷信号，不是本类型已成立的证明。项目公司合资开发范本不得当本约模板。

知识库纠正（不回写双文件）：

- `基本面.md` “当事人应当具备房地产开发资质”：解释第十三条是**一方**具备即有效；双方都不具备，起诉前一方取得或依法成立有资质房地产开发企业的，仍认定有效。不得写成双方都必须有证，也不得写成谁都不必有证。
- `基本面.md` “隐名联营”：只描述本类型常不设公司、内部按投资分配。用户锁定单名义隐名参建 → 负触发 `隐名参建联建·审查`，不得在本任务按隐名参建改完。
- `基本面.md` “出地方在法律上往往是第一责任人”：出地方常兼建设单位或土地使用权人，对外可能被追索；修改句要求施工安全求偿，不得写成出地方必然是第一责任人，也不得写成一纸免责即可对外免责。
- `基本面.md` 划拨地／集体地“合同效力存在争议”：解释原第十六条已删除，不得一律宣告划拨合作无效。划拨走城市房地产管理法第四十条报批／补出让；集体地整案转 `集体建设用地合作开发合同·审查` 或 `宅基地合作开发合同·审查`。
- `框架.md` “项目所在地法院管辖、不动产专属管辖”：合作开发合同本身不当然等于民诉解释第二十八条的不动产物权纠纷。修改句可备选项目所在地法院，管辖只标红旗，不宣称专属管辖已经锁定。2023 年民事诉讼法条号运行时再核。
- 土地增值税征免、合作建房税务定性：本窗未核验部门规章全文，负担主体和比例标 `G#` 或待核，不写入 `L#`。
- 1990 年联营解答“保底无效、收缴利息”：噪声。名实走解释第十二条三要件及已核验的第二十二条／第二十四条；固定货币／固定利益条号运行时再核。

### 1.1 定性（硬闸 1、3）

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

- 城市房地产管理法第二十八条：依法取得的土地使用权，可以依照法律、行政法规作价入股，合资、合作开发经营房地产。作价入股并成立公司的，按项目公司路径切开。

必须切开后再加载，禁止两可时灌入两套知识：

## 节点 2　土地、主体、资质与负担（支撑闸 4、6）

### 2.1 主体表

建表：签约名、履行名、付款名、发票名、土地权利人、报建名义人、销售主体、授权签字人。名称不一致不自动合并。出地方以土地合作属于重大资产处置的，章程或内部决议未附则签署能力字段停止，不写成“可以盖章”。

口头“我们老板同意了”不得写成已授权。国资、上市公司、村集体：未闭合内部程序则字段停止；村集体决议不得用主任签字代替。

### 2.2 土地适格

逐宗：坐落、四至、面积、用途、出让合同号或不动产权证号、剩余年限、规划条件。禁止只写“厂区那块地”。

| 地类或状态 | 本任务动作 |
| --- | --- |
| 国有出让建设用地，证载用途与报建目标一致 | 继续；用途变更须走规划与出让合同变更 |
| 划拨地 | 必须改：补办出让或报有批准权人民政府审批写成生效或开工前提；不得写成可立即动工。解释原第十六条已删除，效力字段走第一百五十三条和房地产管理法第四十条，不宣告一律无效 |
| 集体建设用地或宅基地 | 负触发 `集体建设用地合作开发合同·审查` 或 `宅基地合作开发合同·审查` |
| 闲置、查封、权属争议、未缴清出让金 | 字段停止；不写可以先合作 |
| 已抵押 | 必须改：取得抵押权人书面同意作为附件；未同意则预售许可字段停止 |

城市房地产管理法第三十九条：出让地转让须付清出让金、取得证书，房屋建设工程完成开发投资总额百分之二十五以上。本类型不是转让本约，但若条款实质把土地处置给对方，按节点 4 切开后适用该条。城市房地产开发经营管理条例第十二条：房地产开发用地应当以出让方式取得，法律和国务院另有规定除外。

材料未提及不得写成“无权利负担”，只能写 `依据不足`。

### 2.3 资质（纠正双方都必须有证）

解释第十三条：一方具备房地产开发经营资质，应当认定合同有效；双方均不具备的，应当认定无效，但起诉前一方已经取得或已依法合作成立具有房地产开发经营资质的房地产开发企业的，应当认定有效。房地产开发企业资质管理规定（2022 修正）第三条：未取得资质证书不得从事房地产开发经营。

| 文本或事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 至少一方已有相应资质，报建与销售用该名义 | 可接受方向；仍核等级是否匹配项目 | 有证就一定能预售 |
| 双方都没有，约定起诉前补办或成立有资质企业 | 必须改：把补办或成立写成生效或报建前提，并写未完成的解除 | 先签后补一定有效 |
| 双方都没有，也不约定补办 | 效力字段按第十三条停止或红线 | 民事合同不受资质影响 |
| 出借资质、只收管理费 | 停笔告知，不改成可履行挂靠 | 假内部承包 |

### 2.4 合同成立与物权变动

民法典第二百十五条：设立、变更、转让、消灭不动产物权的合同，除法律另有规定或当事人另有约定外，自成立时生效；未办理物权登记不影响合同效力。第二百零九条：不动产物权经依法登记发生效力。

修改句必须分条：协议成立／生效条件；土地使用权或房屋所有权变动以登记为准；签字、交地、首期款进入共管账户均不等于物权已移转。禁止放行“本合同签字之日起土地及地上物归乙方所有”。

## 节点 3　双方出钱、同比例与追加（硬闸 1、支撑闸 5）

本节点是本类型与 `一方出地一方出钱联建·审查` 的执行差。不讨论“出地方要不要出钱”——出地方必须出钱，否则应已在节点 1 转出。

### 3.1 土地作价＋双方现金

提取并分列：

1. 土地使用权作价方式（评估或协商）及作价金额 `【待填】`，计入出地方总出资；
2. 出地方现金出资额、比例、账户；
3. 合作方现金出资额、比例、账户；
4. 总投资预估与《项目预算清单》是否列为附件。

禁止把土地作价写成出地方“已经完成全部出资”，从而把后续建设资金全部推给对方——那种写法回到 `一方出地一方出钱联建·审查`。

框架要求标题体现**共同出资**。标题只有“联建”或“一方出地一方出钱”：必须改，或在鉴于中写明双方现金义务。

### 3.2 里程碑与同比例

投入时点须锁在可核验节点：签约后、取得施工许可后、主体封顶前等。默认结构是双方按比例同比例跟进。一方先行垫付的，必须写明垫付期限、计息或不计息、以及对方跟进失败时的稀释或债权化。

“同比例”盯死：注资比例与分配比例必须对应。允许谈不同比例，但必须显式约定，不得口头“出钱多的多分一点”。解释第十九条：约定仅以投资数额确定利润分配比例，当事人未足额交纳出资的，按照实际投资比例分配利润。修改句要求未足额出资按实际出资分配，并保留违约金。

### 3.3 超支追加（解释第十四条）

解释第十四条：投资数额超出约定，对增加投资的承担比例协商不成的，按照当事人的违约情况确定；因不可归责于当事人的事由或违约情况无法确定的，按照约定的投资比例确定；没有约定投资比例的，按照约定的利润分配比例确定。

框架认定：缺失追加投资约定是结构性缺陷。修改句必须写：

1. 超支预算的审批程序（联合管委会一致通过或造价咨询复核）；
2. 各方按原出资比例追加的期限；
3. 不跟进方的权益稀释，或由跟进方代垫并计为债权／调增分成；
4. 不得把第十四条当成“可以先不约定”。

禁止编造超支金额。

### 3.4 对价、保证金与定金

投入总额、分阶段到位、共管账户。履约保证金与定金分列。必须使用“定金”二字才讨论罚则。民法典第五百八十六条：不得超过主合同标的额百分之二十，超过部分不产生定金效力。无核验引文不得把 20% 写成现行法结论。

## 节点 4　共担风险与名实穿透（硬闸 2）

### 4.1 三要件

解释第十二条三要件：共同投资、共享利润、共担风险。本类型还要求共同投资中的资金一侧是**双方现金**。缺亏损分担或经营参与，不得写成已构成本类型。

| 文本写法 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 出地方只管拿地并收固定地价款，其余全权对方，不参与管理、不担亏损 | 名合实买，负触发 `国有土地使用权转让合同·审查` | 有“联建”二字就是合作 |
| 出地方或资金方不论盈亏按期收回本息或固定货币 | 负触发 `资金方只收固定货币→第二十三条转`；用户锁定不共担风险型 → `不共担风险型联建合同·审查` | 保底合作一定有效 |
| 资金方不担风险，只分配固定数量房屋 | 按解释第二十二条认定为房屋买卖，回引擎 | 固定套数＝联建分房 |
| 资金方不担风险，只以租赁等方式使用房屋 | 按解释第二十四条认定为房屋租赁，回引擎 | 经营期空词避开租赁 |
| 保底收益＋超额分成，并写明亏损如何分担 | 可保留本类型；必须改补亏损分担、审计、查阅账册 | 有保底就自动是借贷 |
| 口号“共担风险”但无亏损分担句 | 必须改；拒改则不得写成已构成合作开发 | 加一句共担即可避开穿透 |

最强反方：相对方主张“出地方已经拿土地风险了，现金可以保底”。回应：本类型的识别点是出地方**同时**出地和出钱；土地风险不能代替现金侧亏损分担。出地方现金拿固定回报，资金侧会被按借贷或转让审查。

解释第二十一、二十三条全文未稳定命中：固定利益＝转让、固定货币＝借款的条号运行时再核；切开动作仍执行。

### 4.2 分配口径

实物分成：按面积比例划定楼栋或单元，须附《分房／利润分配明细》。货币分成：扣除项穷尽列举（是否扣除总部管理费、资金占用费、不可预见费）。“净利润”未定义视为必须改。

解释第十六条：未批准、未取得建设工程规划许可证或擅自变更规划时，请求分配项目利益不予受理。修改句禁止“未批先分房”。解释第十七条：超规划面积经批准后，超出部分按利润分配比例；增加投资按投资比例。数字用 `【待填】`。

阶段性结算：每完成一期立即分配一次的，须写清已分配部分不被后期亏损追回的范围，以及未分配成本如何结转。

### 4.3 预售款不得充抵出资

解释第二十条：合作开发房地产合同的当事人要求将房屋预售款充抵投资参与利润分配的，不予支持。修改句删除“销售回款视同出资”或“预售款抵作未缴资本金”。回款进入共管账户后，只能按已约定用途支出，不得改写出资比例。

城市房地产开发经营管理条例第二十二条：预售须取得出让证书、规划与施工许可、投入达工程建设总投资 25% 以上并取得预售许可证明。抵押未解除、银行未书面同意：预售字段停止。

## 节点 5　双头治理、共管与成本（支撑闸 5、6）

### 5.1 决策架构

双方都出钱，往往都要话语权。缺治理句视为必须改。优先结构（框架）：**一方管理、一方委派财务主管**；或成立联合管理委员会，重大事项（设计变更、单价调整、融资、抵押、销售均价）一致通过，日常事务按权限。

| 文本写法 | 本任务动作 |
| --- | --- |
| 双方均有一票否决，无僵局出口 | 必须改：一方收购另一方权益退出，或指定期限后提交调解／仲裁 |
| “共同管理”无席位、无权限表 | 必须改：补人员比例、签字权限、印章共管 |
| 把全部执行权授予一方，另一方只分红 | 评估是否应负触发 `一方操盘型联建合同·审查`；若用户锁定本类型，须补监督、财务委派和信息权，不得假装已是联合管理 |
| 未经双方同意单方抵押土地或在建工程 | 红线删除。框架：融资限制 |

本任务不把联合管委会改成董事会，也不把本约改成章程。那是 `房地产合作开发类合同·审查` 的路径。

### 5.2 资金监管

最佳实践：银行资金监管三方协议，支出须双方经办人及财务负责人共同核签。修改句要求：共管账户、用途清单、禁止体外循环、销售回款原路进入共管账户。主导销售一方截留回款：须有解除、赔偿和账户接管。

### 5.3 成本认定

高频争议：虚报工程成本或行政公关费用。修改句要求：成本范围穷尽列举、指定审计机构、查阅账册和工程资料的权利、超范围支出不得计入可分配成本。

### 5.4 安全求偿

建设期间人身意外、工程质量：对内按投资比例或管理分工承担，对外由项目主体或建设单位承担。出地方常被对外追索。修改句设求偿，禁止“出地方对施工现场一切事故免责”且相对方不投保、不赔偿。造成人身损害或因故意、重大过失造成对方财产损失的免责不得放行（民法典第五百零六条）。

## 节点 6　格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 强制规范

民法典第一百五十三条：违反法律、行政法规强制性规定的民事法律行为无效，但该强制性规定不导致该民事法律行为无效的除外。禁止用已失效“效力性／管理性”口诀代替本条。第一百五十四条：恶意串通损害他人合法权益的民事法律行为无效。挂靠、违法分包、以合法形式掩盖非法目的：不改写成有效履行结构。

合同编通则解释第十六条未在本窗逐款核验的，细分路径运行时再核。

### 6.2 格式条款

为重复使用而预先拟定、订立时未与对方协商的条款，按民法典第四百九十六条审查。小字、夹在附件、仅有网络勾选：不得写成已尽提示义务。依据示范文本制作，不当然排除格式条款。

### 6.3 注册资本与合作投入金

框架要求区分：若将来成立 SPV，注册资本与股东借款／合作投入金分列。本类型默认不设公司；出现注册资本条款时，评估是否应转 `房地产合作开发类合同·审查`，不得在本任务把注册资本改成联建投入金而不提示类型风险。

## 节点 7　违约、僵局、中止与争议

出资违约：逾期违约金；严重时同比例稀释收益份额或解除。框架“违约自动退出”：出钱方逾期超过约定期限，出地方可退还已投入资金（或部分退还）解除并收回主导权——可作修改句，但须写清算公式，不得写成无偿没收全部已投入。土地瑕疵、查封导致无法施工：出地方赔偿责任须可执行，不得只写“依法承担”。

僵局：一方收购另一方权益退出，预设优先购买权。善后：已建工程及剩余材料按出资比例折价归并。

项目中止补偿（基本面建议）：因不可抗力或政府规划调整无法开发时，按双方已投入资金和土地资源价值拆分或清退。不可抗力须细化是否包含规划临时调整；不得把“市场下行、融资失败”写成不可抗力。

争议解决：出现仲裁条款，不得改写成“应向某法院起诉”。或裁或诉、机构不明：标待核，改成单一机构或单一法院连结点。框架建议项目所在地法院：可作备选，不宣称专属管辖已经锁定。

通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。
