# 边界与路由

本技能只审查 **房地产合同 / “一方出地，双方出钱” 型联建合同** 的待签、一方出地且双方均出建设资金、通常不设项目公司、对实物或销售款分配并共担亏损的文本。中文展示名是「审查“一方出地，双方出钱” 型联建合同（房地产合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开 `一方出地一方出钱联建·审查`、`房地产合作开发类合同·审查` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 出地方只出地，建设资金全部由对方承担；用户锁定「一方出地，一方出钱」 | `一方出地一方出钱联建·审查`；不打开其 method |
| 双方各自出地、合宗或统一规划 | `“双方出地”型联建合同·审查` |
| 用户锁定不共担风险型；一方不担亏损只拿固定利益 | `不共担风险型联建合同·审查` 或按名实穿透转出 |
| 用户锁定共担风险型，但不强调双方出钱结构 | `共担风险型联建合同·审查` |
| 核心是一方操盘授权，另一方只监督 | `一方操盘型联建合同·审查` |
| 现场联合办公、印章共管、交叉审批为主轴 | `联合操盘型联建合同·审查` |
| 双名义报建、行政共同确权为主路径 | `联建模式联建合同·审查` |
| 单名义报建，投资方隐名 | `隐名参建联建·审查` |
| 新设项目公司；注册资本；按股权分红 | `房地产合作开发类合同·审查`；不打开其 method |
| 委托／商业／政府／资本／股权代建；对价是代建费 | `委托代建合同·审查` 或 `或` 至 `至` |
| 资金方不担风险、只收固定本息或固定货币 | `资金方只收固定货币→第二十三条转` |
| 出地方不担风险、只收固定地价 | `国有土地使用权转让合同·审查` |
| 资金方不担风险、只分固定房屋 | 回 本套导航的类型切开步骤 按房屋买卖定性 |
| 资金方不担风险、只使用房屋 | 回 本套导航的类型切开步骤 按租赁定性 |
| 集体建设用地合作开发 | `集体建设用地合作开发合同·审查` |
| 宅基地合作开发 | `宅基地合作开发合同·审查` |
| 技术合作开发，不以地和开发资金为共同投资 | `共同研发技术专利申请权安排，不以地和开发资金为共同投资→` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

双方出钱正文里夹带一小段操盘授权或资金监管专章：专章交接对应原子；双方现金与分成条款可继续审。用户坚持本技能把「一方出地一方出钱」、项目公司合作、操盘或参建整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
