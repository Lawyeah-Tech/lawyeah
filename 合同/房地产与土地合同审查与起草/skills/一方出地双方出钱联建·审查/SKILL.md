# 一方出地双方出钱联建·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、1990 年《关于审理联营合同纠纷案件若干问题的解答》、解释（2005）同号旧义、解释原第十六条（划拨地合作一律无效，2020 已删除）当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **房地产合同 / “一方出地，双方出钱” 型联建合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「一方出地双方出钱联建·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、把固定回报改成可履行假共担、把「一方出地，一方出钱」或项目公司合作开发整案改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **双方出钱（与 `一方出地一方出钱联建·审查`／`“双方出地”型联建合同·审查` 切开）**：正像是一方提供土地使用权，且出地方与合作方均承担建设资金出资义务。出地方只出地、全部建设资金由对方单独承担 → 负触发 `一方出地一方出钱联建·审查`。双方各自提供土地使用权、不以单方出地为骨架 → 负触发 `“双方出地”型联建合同·审查`。禁止打开或复制 `一方出地一方出钱联建·审查` 的 method。
2. **共担风险／名实穿透**：双方货币出资均须承受项目亏损。出地方不担风险只收固定利益或固定地价 → 按土地使用权转让切开，转 `国有土地使用权转让合同·审查`；用户锁定不共担风险型联建 → `不共担风险型联建合同·审查`。资金方不担风险只收固定本息或固定货币 → `资金方只收固定货币→第二十三条转`。资金方不担风险只分固定房屋 → 回引擎按房屋买卖定性。资金方不担风险只使用房屋 → 回引擎按租赁定性。禁止用“加一句共担”把固定必付化妆成合作。
3. **与项目公司合作开发、操盘子型、参建／双名义切开**：新设项目公司、按股权分红、注册资本路径为主给付 → `房地产合作开发类合同·审查`。核心是操盘权单方授予 → `一方操盘型联建合同·审查`。联合操盘现场共治为主轴 → `联合操盘型联建合同·审查`。双名义报建确权为主路径 → `联建模式联建合同·审查`。单名义隐名参建 → `隐名参建联建·审查`。标题或用户锁定共担风险型但不强调双方出钱结构 → `共担风险型联建合同·审查`。对价是代建费或管理费、不分担亏损 → `委托代建合同·审查` 或 `或` 至 `至`。禁止打开上述 method 对照改写。

支撑闸：

4. **国有出让地＋资质**：标的须为国有出让建设用地。划拨地须把补办出让或报批写成生效或履行前提，不得改成可履行动工；不得用已删除的解释原第十六条宣告整约无效。集体建设用地或宅基地整案 → `集体建设用地合作开发合同·审查`／`宅基地合作开发合同·审查`。双方均无房地产开发经营资质：效力字段按解释第十三条处理；至少一方或起诉前成立的有资质房地产开发企业即可，不得写成双方都必须有证。挂靠出借资质只告知。
5. **同比例注资与分成、追加投资、双头治理**：资金分担比例、里程碑同比例跟进、超支追加或不跟进稀释／代垫债权化必须落句。缺联合管理委员会或“一方管理、一方委派财务”、缺共管账户视为必须改。注资比例与分配比例必须对应。预售款不得充抵投资参与利润分配。
6. **抵押预售、安全求偿、中止拆分**：已抵押须抵押权人书面同意，否则预售许可字段停止。出地方常兼建设单位，须设施工安全求偿，不得写成必然免责。土地增值税、企业所得税预留必须分列，比例待核。因规划调整或不可抗力无法开发的，须有按已投入资金和土地资源价值拆分的中止补偿句。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签正文，尚未签署，尚未成争，核心给付是一方出地且双方均出建设资金、通常不新设项目公司、对实物或销售净利润分配并共担亏损，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 出地方只出地、不再出建设资金 → `一方出地一方出钱联建·审查`；不打开其 method；
- 双方各自出地、不以单方出地为骨架 → `“双方出地”型联建合同·审查`；
- 用户锁定不共担风险型联建，或一方不担风险只拿固定利益 → `不共担风险型联建合同·审查` 或按第 2 闸穿透；
- 用户锁定共担风险型但不强调双方出钱结构 → `共担风险型联建合同·审查`；
- 核心是一方操盘授权 → `一方操盘型联建合同·审查`；联合操盘现场共治 → `联合操盘型联建合同·审查`；
- 双名义报建确权为主路径 → `联建模式联建合同·审查`；单名义隐名参建 → `隐名参建联建·审查`；
- 新设项目公司、按股权分红为主给付 → `房地产合作开发类合同·审查`；不打开其 method；
- 委托／商业／政府／资本／股权代建，对价是代建费 → `委托代建合同·审查` 或 `或` 至 `至`；
- 资金方不担风险、只收固定本息或固定货币 → `资金方只收固定货币→第二十三条转`；
- 出地方不担风险、只收固定地价 → `国有土地使用权转让合同·审查`；
- 集体建设用地合作开发 → `集体建设用地合作开发合同·审查`；宅基地合作开发 → `宅基地合作开发合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `一方出地双方出钱联建·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

挂靠、违法分包、规避限购或限售、以合作套取信贷资金转贷：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（出地方兼出资方／合作出资方择一）；相对方；全文及预算表、分成明细、资金监管协议版本；出地方是否另出建设资金及比例、时点；是否新设项目公司；土地是出让、划拨还是集体；是否固定回报或不担亏损；谁主导开发、销售、财务；共管账户与超支追加；抵押与预售；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `一方出地双方出钱联建·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有本类型文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。出地方不再出钱、双方出地、项目公司股权、操盘／参建／双名义、代建、固定回报负触发。禁止打开 `一方出地一方出钱联建·审查` 的 method。

### 2. 土地、资质与负担

出让／划拨／集体分列。划拨补出让写成条件。至少一方或拟设企业资质未闭合则字段停止。已抵押须书面同意。

### 3. 双方出钱与同比例

土地作价＋双方现金比例、里程碑跟进、超支追加或不跟进稀释必须落句。注资与分配比例对应。

### 4. 共担风险与名实穿透

固定必付、固定房屋、固定地价且不担风险：按条转出，禁止化妆。

### 5. 双头治理、共管与成本

联合管委会或一方管理一方财务；共管账户；成本认定与销售回款不得体外循环。预售款不得充抵出资。

### 6. 格式条款与强制规范

无核验引文则法律结论字段停止。人身损害与故意／重大过失免责不得放行。

### 7. 违约、僵局、中止与争议

出资违约须有违约金、稀释或退出。决策死锁须有收购退出。规划调整须有已投入拆分。管辖只标红旗，不宣称专属管辖已经锁定。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把固定回报化妆成共担、把 `一方出地一方出钱联建·审查` 或其他联建子型整案按本类型改完、把划拨或集体地改成可履行动工、把挂靠或规避限购改成可履行结构。
- `字段停止`：法域、划拨／集体审批、预售许可、土增税清算口径、地方限购限售、解释第二十一／二十三条全文未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
