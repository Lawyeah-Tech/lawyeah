# 城市更新项目意向合作协议·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **房地产合同 / 城市更新项目意向合作协议** 的待签文本：公开招商或政府确定合作主体之前，村集体与意向企业之间的排他谈判、前期配合和意向保证金安排。输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「城市更新项目意向合作协议·起草」。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查、从零起草、履约交底、争议文书、有效性保证、把本约改成已锁定实施权或正式合作主体资格、前期服务整案、正式村企合作整案、股权合作整案、补偿安置整案。

## 工作边界

正触发：已有可读待签文本要评改（审查模式），或本类型条件已谈妥要出己方稿（起草模式）；尚未签署，尚未成争；核心给付是城市更新意向阶段的**项目推进配合权**、排他谈判和意向保证金，而不是建设分红、回迁交付或正式开发义务。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 对价是测绘、方案编制、意愿征集、表决组织等服务费，服务商角色是孵化器而非未来开发主体 → `城市更新项目前期服务合同·审查`；
- 开发商与前期服务公司之间的费用转嫁、联合体或资源锁定 → `城更合作（开发商与前期服务）·审查`；
- 设立 SPV、股权对价、明股实债或联合获取开发权 → `城更股权合作·审查`；
- 已写回迁建设、补偿安置总包、利润分配、正式履约保函，或双方已按中选合作主体履约 → `城更合作（村集体与企业）·审查`；
- 主文件是三方资金监管 → `资金监管协议·审查`；与被搬迁人约定补偿方式、面积、搬迁期限 → `拆迁补偿安置协议·审查`；政府与已确定实施主体的监管协议 → `实施主体监管协议·审查`；
- 一方出地一方出钱、共担风险、操盘分成的联建本约 → 本套导航的类型切开步骤 重新定性，或对应联建原子；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问保证金到账、摸底进度、招商公告日 → 本套导航的履约步骤；
- 已成争（催告退还保证金、排他违约索赔、确认开发权、立案仲裁）→ `或对应专项领域。` 或对应专项。

挂靠、违法分包、规避限购、跳过公开招商锁定实施权、阴阳协议损害集体利益、保证金入个人账户：只出告知，不改写成可履行结构。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成。每一闸必须给出修改句或明确转出口径，禁止只打红黄绿。

1. **预约／意向约束力**。不用标题单独定性。打开解释第 6 条三层：仅表达意向、未约定将来一定期限内订立合同或主体标的难以确定 → 不得主张整份预约成立，但已写明的排他、保密、保证金、前期配合仍按已约定模块审查。约定将来一定期限订立正式合作／招商文件且主体标的可确定 → 预约成立，违反时走第 495 条和第 7、8 条，赔偿不是自动取得本约履行。已就开发范围、利益分配、价款等主要内容达成合意且未约定另行订立本约，或已开始按本约履行并被接受 → 按本约候选处理，通常负触发 `城更合作（村集体与企业）·审查`，不得留在本技能改成可履行开发。修改句必须列出**有约束力模块**和**无约束力／待本约模块**。
2. **排他谈判**。必须写：排他相对方（不得与其他企业接触、洽谈、签署同类意向或平行申报）；起算与截止（建议绑节点，如立项批复、招商公告发布、最长不超过【待填】个月，以先到为准）；违约金或解除后果。无截止日或“长期独家／永久独家”：红线。排他期内村集体以“村民反对”另寻下家的，不得写成当然免责且不退保证金。排他**不等于**已获得实施权。
3. **与正式合作切开**。本约用语锁定“意向合作关系”，禁止“正式合作主体”“实施主体”“开发权人”。禁止打开或复制 `城更合作（村集体与企业）·审查`、`城市更新项目前期服务合同·审查` method。夹带回迁建设、利润分配、土地出让分成专章：该专章交接对应原子；用户坚持本技能把正式合作整案改完 → `目标停止`。
4. **禁止把意向写成已锁定实施权**。下列原文红线删除或改成未来程序条件，不得改成可履行锁定：自动转为合作主体；可不经公开招商取得开发权；视为已中选；政府必须确定乙方为实施主体；同等条件优先权写成已经获得开发权。合规声明必须保留：“本合同不代表最终获得开发权或实施主体资格；正式合作须经依法公开招商或当地规定的选聘程序及政府确认。”优先权如当地政策允许，最多写成“在不违反公开招商强制性程序的前提下，可在招商文件中申请列明同等条件优先谈判，最终以公告和中选结果为准”，并标地方政策待核。

附加必落句（有事实则单列，无事实在缺口节说明）：

- **保证金 ≠ 定金**：未写“定金”且未约定定金性质的，不得适用第 587 条双倍返还。解释第 67 条。想要惩罚性返还，改成可执行违约金，或在用户明确选择定金时单列定金并提示本约尚无稳定“主合同标的额”，第 586 条百分之二十字段通常停止。
- **监管账户**：保证金进入村集体／合作社对公监管账户或政府监管账户，支出须街道或镇政府备案；禁止村长、村委个人账户。
- **退还触发**：未中选、政策调整或项目终止、后续方案表决未通过 → 限期内本息原路退还；企业无故退出或串通投标 → 可约定不退。逾期退还另约定违约金。不得把“村民反对”单独写成不予退还。
- **民主决策匹配事项**：签署本约至少要有成员大会或依法授权的成员代表大会／村民会议决议作附件。涉及土地补偿费分配使用（农村集体经济组织法第 26 条第 10 项）不得仅由代表大会决定。未附决议：字段停止，修改句把决议列为生效条件。

必须有修改句。每个风险回链文本位置。禁止复制 `城市更新项目前期服务合同·审查` 或 `城更合作（村集体与企业）·审查` method。

## 建立起草坐标

确认：使用者与授权；单方立场（意向企业／村集体或股份经济合作社）；相对方；全文及红线图、表决决议、保证金账户文件版本；当地是否允许预锁定；是否已发布招商或已确定实施主体；排他期；保证金金额与账户；文本是否自称实施主体；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的金额、面积、期限用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law`（法律结论 required）：核验预约与本约、意向书不当然成立预约、定金与保证金、格式条款、强制规范、村集体／集体经济组织民主决策职权、集体经营性建设用地须按方案以招标拍卖挂牌或协议确定使用者。
- `search_practiced`（optional）：补意向书与预约区分、保证金退还争点。返回“标题是意向即无约束力”“签了就锁定开发权”时记噪声。
- `search_template`（optional）：只借栏目。范本写“乙方负责项目实施／自动成为合作主体”不得当规则。可借鉴的栏目：项目范围、排他期、前期配合、保证金缴退、保密廉洁、不代表最终开发权声明、表决决议附件。

不虚构案件系统。`search_law` 返回已失效《合同法》及其解释、担保法解释时记为噪声，不得写入 `L#`。


## 起草模式

本原子只承担本类型起草。待签评改转 `城市更新项目意向合作协议·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。按框架六步落稿。商业数字未给用 `【待填】`。出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。正式村企合作、前期服务、股权合作、补偿安置：负触发，不按邻类出稿。

**起草必写**

- 列出有约束力模块（排他、保密、保证金、前期配合）和无约束力／待本约模块。
- 用语锁定“意向合作关系”。
- 排他相对方、起算与截止（建议绑节点，最长不超过【待填】个月，以先到为准）、违约金或解除后果。
- 合规声明：本合同不代表最终获得开发权或实施主体资格；正式合作须经依法公开招商或当地规定的选聘程序及政府确认。
- 保证金性质写清：未写“定金”且未约定定金性质的，不得适用双倍返还。
- 退还触发：未中选、政策调整或项目终止、后续方案表决未通过 → 限期内本息原路退还；企业无故退出或串通投标可约定不退；逾期退还另约定违约金。
- 签署本约以成员大会或依法授权的成员代表大会／村民会议决议为生效条件。

**附件必附**

- 成员大会或依法授权的成员代表大会／村民会议决议。
- 红线图。
- 保证金监管账户文件（村集体／合作社对公监管账户或政府监管账户）。

**禁止出现**

- “正式合作主体”“实施主体”“开发权人”。
- 无截止日或“长期独家／永久独家”。
- 排他期内村集体以“村民反对”另寻下家当然免责且不退保证金。
- 自动转为合作主体、可不经公开招商取得开发权、视为已中选、政府必须确定乙方为实施主体。
- 同等条件优先权写成已经获得开发权。
- 保证金入村长、村委个人账户。
- 把“村民反对”单独写成不予退还。
- 夹带回迁建设、利润分配、土地出让分成专章当本约改完。
- 土地补偿费分配使用仅由代表大会决定。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造表决或倒签、把保证金打入个人账户、把跳过公开招商锁定实施权改成可履行、保证必然中选或本约必然有效。
- `字段停止`：法域、地方是否允许预锁定、表决机关是否匹配事项、保证金是否定金、预约是否成立未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或要把本约改成正式开发／已锁定实施权。
