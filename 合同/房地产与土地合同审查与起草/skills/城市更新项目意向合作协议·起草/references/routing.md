# 边界与路由

本技能只审查 **房地产合同 / 城市更新项目意向合作协议** 的待签、招商或确定合作主体之前的排他谈判与意向保证金文本。中文展示名是「审查城市更新项目意向合作协议（房地产合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或抄写 `城市更新项目前期服务合同·审查`、`城更合作（村集体与企业）·审查` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 测绘、方案、意愿征集、表决组织等服务费；服务商不是未来开发主体 | `城市更新项目前期服务合同·审查` |
| 开发商与前期服务公司费用转嫁、联合体、资源锁定 | `城更合作（开发商与前期服务）·审查` |
| SPV、股权对价、联合获取开发权、明股实债 | `城更股权合作·审查` |
| 回迁建设、利益分配、正式履约保函、已中选合作主体义务 | `城更合作（村集体与企业）·审查` |
| 三方资金监管为主文件 | `资金监管协议·审查` |
| 与被搬迁人约定补偿方式、面积、搬迁期限 | `拆迁补偿安置协议·审查` |
| 政府与已确定实施主体的监管考核 | `实施主体监管协议·审查` |
| 出地出资、利润分成、操盘的联建本约 | 本套导航的类型切开步骤 或对应联建原子 |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

意向正文里夹带一小段回迁比例或分户补偿：专章交接 `城更合作（村集体与企业）·审查` 或 `拆迁补偿安置协议·审查`；意向模块可继续审。用户坚持本技能把正式合作、前期服务、股权合作或补偿安置整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
