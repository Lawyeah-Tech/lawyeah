# 资金监管协议·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **房地产合同 / 资金监管协议** 的待签文本，输出：监管子类型切开、专户与入账范围、拨付节点与指令权限、风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他合同类型。本原子只承担本类型起草。待签评改转 `资金监管协议·审查`。场景分层为 **P0**。

`depends-on` 为空。不要求先跑导航。

不交付：商品房或施工本约审查；整份从零起草；履约交底；争议文书；有效性、抗划扣或兑付保证。

## 工作边界

正触发：已有可读待签文本要评改（审查模式），或本类型条件已谈妥要出己方稿（起草模式）；尚未签署，尚未成争，核心给付是对特定用途资金设立专户、约定入账范围、拨付节点、指令权限和退还。三类均正触发：商品房预售资金监管、工程款/农民工工资监管、更新拆迁资金监管。专户封闭是主轴，更新拆迁不是唯一正像。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 文本是商品房买卖或预售本约（房号、面积、交房办证换价款）→ `普通商品房买卖价款五证网签主结构→`；
- 文本是二手房/存量房买卖本约，即便标题写资金监管 → `文本是二手房存量房买卖本约，即便标题写资金监管→`；该原子不可用则转 本套导航的类型切开步骤；
- 文本是建设工程施工本约（按图施工换工程价款）→ `操盘方自己施工或按造价取费→`；
- 普通仓储/保管、无房地产专项用途约束 → 引擎重新定性；
- 核心给付是借款或融资放款 → `或` 或 `或`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问拨付日、对账留痕 → 本套导航的履约步骤；
- 已成争（挪用追索、拒付、划扣异议、催告、诉讼仲裁）→ `或对应专项领域。` 或对应专项，不在本任务做追索方案。

挂靠、违法分包、规避限购、把预售款/工程款改道进非监管户：只出告知，不改写成可履行结构。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成。每闸必须有修改句或明确停笔，禁止只打色块。

1. **监管 ≠ 本约 ≠ 结算**。本技能不审商品房买卖或施工本约。只审专户、入账、拨付节点、指令权限、退还。纯结算账户无用途、节点、指令约束：负触发或必须改成监管。修改句须写明“本协议不设立买卖或施工权利义务，账户不得当一般结算户使用”。
2. **专户特定化**。唯一账号、不得质押给无关债权人、入账范围（预售款/工程款/拆迁款）写死。收款进开发商/承包人一般户、营销户或个人卡：红线。修改句须写出户名、开户行、`【待填唯一账号】`、资金种类和禁质押。
3. **拨付节点可核验**。形象进度、竣工、交房、拆迁完成等须附证明文件类型和审核人。禁止“监管方/企业单方电话即可全额划出”。修改句须列出申请材料、审核人和银行拒绝划付条件。
4. **多方权限**。银行形式审查 vs 实质审核义务必须写清；政府/街道签字须有法定职责或主合同授权，否则字段停止，不编造行政机关保证兑付。修改句须拆开银行表面一致性校验与现场核验，并写明政府签字不构成兑付保证。
5. **主合同牵连**。主合同无效/解除时监管资金如何退还、对谁退、是否独立运转。禁止“主合同怎样都不影响，银行可任意解付”。修改句须写退还对象和未决期间不得单方解付。
6. **规避监管**。把预售款/工程款改道进非监管户“更方便”：只告知违法或监管风险。用户坚持则整体停止，不给出可履行改道句。

必须有修改句。禁止只打红黄绿。每个风险回链文本位置。

## 建立起草坐标

确认：使用者与授权；单方立场（不得同时服务利益冲突各方）；相对方；全文、附件、主合同关键页与开户材料版本；资金种类与项目名称；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的账号、额度、地方百分比用 `【待填】`，不编造。

`基本面.md` 偏城市更新拆迁监管，且含“约定隔离法院划扣”表述。以本技能 `method.md` 与运行时核验为准，不把更新节点硬套预售或工资，不把抗划扣写成已核验规则。

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构，不证明本约条款已被接受。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把知识库“监管账户约定即可对抗法院划扣”写成已核验规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时优先：

- `search_law`：城市商品房预售管理办法第 11 条；城市房地产管理法第 45 条第三款；城市房地产开发经营管理条例预售相关条（本次核验到第 22 条预售条件；“所得款项用于工程建设”落在房地产管理法第 45 条，条例未稳定返回专条）；保障农民工工资支付条例第 24、26、27、29、31、33 条；民法典第 888、894、895、919、922、929 条；第 153、496、586 条。
- `search_practiced`：预售资金挪用、工资专户划扣、监管银行审查义务的审查反例。
- `search_template`：只借监管协议栏目结构。

`search_law` 对法律结论为 required。不可用时不拒跑，只停止法律结论字段。返回失效合同法及其解释时记噪声，不得写入 `L#`。地方细则和建房〔2022〕16 号重点额度运行时核验，不硬编码某市阈值。


## 起草模式

本原子只承担本类型起草。待签评改转 `资金监管协议·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。按框架六步落稿。商业数字未给用 `【待填】`。出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。商品房或施工本约、普通保管、借款：负触发，不按本约出稿。

**起草必写**

- 本协议不设立买卖或施工权利义务，账户不得当一般结算户使用。
- 唯一账号、户名、开户行、资金种类（预售款／工程款／拆迁款）写死；不得质押给无关债权人。
- 拨付节点须附证明文件类型和审核人；列出申请材料、审核人和银行拒绝划付条件。
- 银行形式审查与实质审核义务写清；政府／街道签字须有法定职责或主合同授权，且不构成兑付保证。
- 主合同无效／解除时监管资金如何退还、对谁退；未决期间不得单方解付。

**附件必附**

- 开户材料与唯一账号。
- 主合同关键页。
- 拨付节点证明文件类型清单。
- 政府／街道签字时的法定职责或主合同授权依据。

**禁止出现**

- 收款进开发商／承包人一般户、营销户或个人卡。
- 监管方／企业单方电话即可全额划出。
- “主合同怎样都不影响，银行可任意解付”。
- 把预售款／工程款改道进非监管户。
- 编造行政机关保证兑付；约定即可对抗法院划扣。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；用户坚持伪造倒签、把预售款/工程款改道进非监管户、编造行政机关保证兑付、保证约定即可对抗法院划扣。
- `字段停止`：账号未特定化；政府签字无职责或授权依据；地方额度/细则未核验；主合同解除后退还对象不明。
- `目标停止`：主目标已变为从零起草、履约交底、买卖/施工本约审查或挪用追索文书。

生存级预售盘或工资专户金额且用户拒绝升级：停止“可以签署”建议。
