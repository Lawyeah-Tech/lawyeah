# 边界与路由

本技能只审查 **房地产合同 / 资金监管协议**（专户封闭：商品房预售资金、工程款/农民工工资、更新拆迁资金）。更新拆迁不是唯一正像。

| 已能支持的事实 | 路由 | 不得写成 |
| --- | --- | --- |
| 待签、核心给付是专户+入账范围+拨付节点+指令权限+退还 | 留本任务 | 已完成签约或已生效 |
| 商品房买卖/预售本约：房号面积交房办证换价款 | `普通商品房买卖价款五证网签主结构→` | 用本技能改五证、面积 3%、贷款失败 |
| 业主出售存量房，即便标题写资金监管或资金托管 | `文本是二手房存量房买卖本约，即便标题写资金监管→`；该原子不可用则引擎重新定性 | 用本技能审过户、户口、居间佣金 |
| 建设工程施工本约：按图施工换工程价款 | `操盘方自己施工或按造价取费→` | 用本技能套解释二施工节点、质保金 3% |
| 普通仓储、保管、保险箱，无房地产专项用途 | 引擎重新定性 | 硬套预售或工资专户规则 |
| 持牌机构贷款或自然人借款主文件 | `或` 或 `或` | 把监管协议改写成借款 |
| 纯结算账户：只有收付，无用途、节点、指令约束 | 负触发或必须改成监管后才留本任务 | 标绿放行 |
| 无可读正文，本类型条件已谈妥，要出己方稿 | 本任务起草模式（出稿后自审） | 已经完成审查；转通用起草引擎出本类型终稿 |
| 已签，问哪天拨、对账单、通知留痕 | 本套导航的履约步骤 | 签前意见 |
| 已出现挪用追索、拒付、划扣异议、催告、立案、仲裁 | `或对应专项领域。` 或对应专项 | 继续当签前审查出追索方案 |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 | 两可时灌入买卖/施工知识 |
| C 端大众快检 | 只分流，不回改 | 降成快检 |

把预售款/工程款改道进非监管户、挂靠、违法分包、规避限购：留在本技能只出告知并停笔，不转去“改成可履行稿”，也不转争议原子充作签前修改。用户坚持改到能签：整体停止。

专业版未收录的 P1 场景不会安装对应原子。若用户拿这些文本来找专业版：输出 `unavailable`，提示或回引擎，不得用本监管原子硬套本约。
