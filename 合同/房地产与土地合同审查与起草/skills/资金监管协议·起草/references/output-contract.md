# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受、约定即可对抗法院划扣或行政机关保证兑付；编造未给出的账号、额度、地方百分比；把已失效《合同法》及其解释写入结论；把更新拆迁节点硬套预售或工资。

## 1. 触发、单方立场与成果状态

立场（开发企业 / 施工总承包 / 出资或合作企业 / 监管银行 / 主管部门或街道之一侧）、授权、签署状态、监管子类型（预售资金 / 工程款或工资 / 更新拆迁）、主要目标。负触发写路由，不启动实体审查。已成争挪用追索：负触发转争议。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释时记噪声，不得写入 `L#`。知识库“约定抗划扣”不得写入 `L#`。

## 3. 类型与加载路径

父级 `房地产合同`，子级 `资金监管协议`。定性理由必须写清：核心给付是否专户封闭；子类型是预售、工资还是更新；是否已排除买卖本约、施工本约、纯结算、保管、借款。

加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。加载后须执行知识库纠正：更新不是唯一正像；约定抗划扣不是已核验规则。规避监管、挂靠写停笔告知，不填可履行结构。

## 4. 主体、授权、专户与文本版本

主体表：签约名、履行名、**监管账户户名**、付款/入账义务人、收款/受益人、授权签字人、监管银行、政府或街道（如有）及签字依据（法定职责文件或主合同授权条款 / `G#`）。名称不一致不自动合并。政府签字无依据：该字段停止，不写成保证兑付。

专户表（每户一行：资金种类｜户名｜开户行｜账号或`G#`｜是否唯一｜是否禁质押｜入账范围是否写死）：

- 商品房预售资金监管账户
- 农民工工资专用账户 / 工程款监管账户
- 拆迁补偿或更新项目监管账户

版本表：监管协议正文、拨付流程单、预留印鉴卡、授权委托书、主合同关键页、主管部门公布的监管账户页、聊天确认。冲突并列，不选对用户有利的一版。

## 5. 给付闭环（本类型必填）

固定回答，缺项标 `G#`，不补商业数字和地方百分比：

- 监管资金种类是否锁定为预售款 / 工程款或人工费 / 拆迁补偿款之一，且未与本约给付混写
- 入账是否直存唯一专户；是否出现一般户、营销户、个人卡或“先收再转”
- 拨付节点是否逐项绑定证明文件类型和审核人；是否存在电话或单方指令全额划出
- 银行审查义务：形式审查（印鉴、户名、账号、金额、附件表面一致）与现场核验是否拆开；发现不一致是否必须拒绝划付
- 主合同无效、解除或目的不能实现时：剩余资金退还对象、通知和不得任意解付
- 利息/孳息归属是否写明且仍受监管
- 批准、开户、备案写成生效条件或期限，不写成已经完成

地方重点额度、工资保证金比例、某市拨付百分比未核验：标 `G#`，不硬编码。

## 6. 格式条款与强制规范

是否构成格式条款；银行示范文本不排除格式条款；提示说明痕迹；银行免责过宽、单方电话划付、任意解付等异常条款。强制规范只区分是否导致民事行为无效。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

不得把预售管理办法第 11 条、工资条例专户规则写成“仅倡导”。不得把合同抗划扣条款写成必然排除执行。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔/转出口径。禁止输出无修改句的色块表。

本类型默认应出现（有事实则单列，无事实则在缺口节说明未检出）：专户未特定化或进一般户、拨付无证明文件、电话即可划出、银行免责过宽、政府签字无授权、主合同解除后退还空白、改道非监管户。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点、不接受时的红线。未给出的商业数字用 `【待填】`，不编造。

硬闸对应句不得省略：

- 监管与本约切开：写明本协议不设立买卖或施工权利义务。
- 专户：户名、开户行、`【待填唯一账号】`、资金种类、禁质押、禁止进一般户。
- 拨付：证明文件类型 + 审核人 + 银行拒绝划付条件；删除电话全额划出。
- 权限：银行表面一致性义务；政府签字不构成兑付保证。
- 牵连：主合同无效或解除时的退还对象；禁止任意解付。

规避监管不给可履行改道句。

## 9. 谈判与签署提醒

谈判顺序：先红线（非监管户收款、电话全额划出、任意解付、规避改道），再必须改（证明文件与审核人、银行拒绝划付、退还对象、政府授权附件），最后可优化（对账频率、孳息、预警余额）。

签署提醒：开户证实书与协议账号一致后再允许入账；预留印鉴卡与授权委托书作为附件；主合同解除条款与本协议退还条款交叉引用；不倒签；不指导先收款进一般户再补监管。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书、效力保证、抗划扣保证或行政机关兑付保证。
