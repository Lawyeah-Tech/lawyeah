# 边界与路由

本技能只审查 **土地使用权 / 土地置换协议** 的待签、行政收回旧地并以新地补偿或安置的文本。中文展示名是「审查土地置换协议（土地使用权）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或复制 `国有土地使用权出让合同·审查`、`国有土地使用权转让合同·审查` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 只有新地出让；出让金；竞买／成交确认；普通协议出让；无旧地收回 | `国有土地使用权出让合同·审查` |
| 两个民事主体买卖或互换已登记建设用地使用权；对价是转让款；政府不是收回方 | `国有土地使用权转让合同·审查` |
| 用地预申请、意向用地 | `用地预申请协议·审查` |
| 与非出让人签订的勾地承诺 | `与非出让人签订的勾地协议·审查` |
| 联合勾地 | `联合勾地协议·审查` |
| 一级市场联合拿地、联合竞买 | `一级市场联合拿地类合同·审查` |
| 以股权间接取得土地使用权 | `以股拿地·审查` |
| 合作开发、联建，权属不因行政收回而消灭 | `房地产合作开发类合同·审查` |
| 房屋或集体土地征收决定、征收补偿协议 | 征收或行政专项，不启动本任务 |
| 集体经营性建设用地出让、出租或互换本约 | 对应集体建设用地原子，不启动本任务 |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、只问腾退、补差、办证节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或对应专项领域。` 或对应专项领域 |
| 收回决定、不履行置换、行政诉讼或复议已立案 | 行政或房地产专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

置换正文里夹带一小段后续出让合同或地上物拆除承包：专章交接对应原子或分条改写；收回与换地条款可继续审。用户坚持本技能把出让、转让、征收或勾地整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
