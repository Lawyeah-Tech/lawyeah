# 审查方法（锁定 房地产合同 / 联建模式联建合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止打开或复制 `隐名参建联建·审查` method。禁止把一方出地一方出钱、双方出地、不共担风险、共担风险、一方操盘、联合操盘写成同一套判断主线。禁止套用委托代建、项目公司股权、土地使用权转让或商品房买卖的主路径。禁止把本技能写成“所有联建通用审查”。

定性校验：核心结构是双名义报建 + 共同确权 + 直接初始登记，才继续；明显他类则负触发，不填十节实体结论。

本文件是可执行判断节点，不是栏目说明书。每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、已经取得典型物权、必然对抗执行、必然暂免土地增值税，或唯一必得分房面积。

`search_law` 返回已失效《合同法》《物权法》及其解释、2005 年国有土地使用权合同解释已删除的划拨合作无效专条（原第 16 条）、已失效《划拨土地使用权管理暂行办法》第 40 条时记为噪声，不得写入 `L#`。`search_practiced` 仍写“双方都必须有资质否则合同无效”“联建手续即物权、必然排除执行”“划拨合作一律无效”的，同样记噪声。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

示范文本只参考结构。写“乙方只提供资金、不担风险、拿固定回报”“全部手续由甲方单方办理”“建成后先登记在出地方名下再过户”的范本与本类型硬闸冲突，不得当规则。引用已失效《合同法》的范本只借栏目。

知识库口径冲突以本方法为准，不回写知识正文：

- `基本面.md` 写“双方原则上均应具备房地产开发资质”是**行政报建门槛**，不是民事效力唯一条件。民事效力按 2020 年修正解释第 13 条：一方具备资质即可有效；双方均不具备且起诉前未补的，应认定无效。
- `基本面.md`/`框架.md` 把联建手续写成“具有物权效力”“准所有人”“对抗执行”：纠正为行政公示上的共同权利人地位，**不是**民法典上的典型物权；对抗执行必须另核预告登记或执行异议条件，不得保证。
- 把合作建房“暂免土地增值税”写成已经适用：纠正为须向税务机关核验现行口径，并必须约定认定失败后的税负分担。
- 2005 年解释第 16 条（未经批准以划拨地合作开发无效）已被 2020 年修正删除：不得再当现行无效专条。划拨地另核城市房地产管理法划拨转让批准规则与解释第 10、11 条补偿合同路径。
- 报批失败“转为一方出地一方出钱”：不得在本技能改写成 `一方出地一方出钱联建·审查` 可履行文本；只点名备选或免责解除，用户要改类型则负触发。

开发窗口 2026-08-18 已核验、可供对照但不得代替运行时核验的规则：

- 民法典第 209 条：不动产物权经依法登记发生效力；未经登记不发生效力，法律另有规定除外。
- 民法典第 215 条：设立、变更、转让和消灭不动产物权的合同，除法律另有规定或当事人另有约定外，自成立时生效；未办理物权登记不影响合同效力。
- 民法典第 221 条：当事人签订买卖房屋的协议或者签订其他不动产物权的协议，可按约定申请预告登记；未经预告登记权利人同意处分该不动产的，不发生物权效力；债权消灭或自能够进行不动产登记之日起九十日内未申请登记的，预告登记失效。
- 物权编解释（一）第 4 条：未经预告登记权利人同意转让所有权或设立建设用地使用权、居住权、地役权、抵押权等，不发生物权效力。
- 城市房地产管理法（2019 修正）第 28 条：依法取得的土地使用权可以依照法律、行政法规作价入股，合资、合作开发经营房地产。
- 同法第 39 条：出让土地使用权转让房地产，须付清出让金并取得土地证；房屋建设工程须完成开发投资总额百分之二十五以上。
- 城市房地产开发经营管理条例（2020 第二次修订）第 5、9 条：设立条件与按核定资质承担项目。
- 房地产开发企业资质管理规定（2022 修正）第 3 条：未取得资质证书不得从事房地产开发经营业务；第 16 条：无资质经营的行政处罚。
- 法释〔2020〕17 号《关于审理涉及国有土地使用权合同纠纷案件适用法律问题的解释（2020 修正）》第 12 条：合作开发房地产合同指以提供出让土地使用权、资金等作为共同投资，共享利润、共担风险为基本内容的合同。
- 同解释第 13 条：一方具备房地产开发经营资质的，应当认定合同有效；双方均不具备的，应当认定无效，但起诉前一方已取得资质或已依法合作成立有资质房地产开发企业的，应当认定有效。
- 同解释第 16 条：未经批准、未取得建设工程规划许可证或擅自变更规划的，请求分配项目利益不予受理或驳回起诉。
- 同解释第 23 条：提供资金的当事人不承担经营风险、只收取固定数额货币的，应当认定为借款合同。
- 同解释第 24 条：不承担经营风险、只以租赁或其他形式使用房屋的，应当认定为房屋租赁合同。
- 执行异议复议规定（2020 修正）第 30 条：金钱债权执行中，对被查封且已办理受让物权预告登记的不动产，受让人停止处分异议应予支持；符合物权登记条件的排除执行异议应予支持。
- 不动产登记暂行条例（2024 修订）第 22 条：权属争议等情形不予登记。
- 不动产登记暂行条例实施细则（2024 修正）第 24 条：未办理首次登记，不得办理其他类型登记，法律、行政法规另有规定除外；第 85 条：预告登记情形与三个月转登记。

本次检索未返回可写入 `L#` 的正文，运行时必须重核、不得凭记忆落法律结论：2020 年修正解释中“不承担经营风险只获得土地使用权／只分配固定房屋”的现行条号（2005 年第 24、25 条已被修改）；城市房地产管理法（2019 修正）划拨房地产转让现行条号；合作建房暂免土地增值税的现行财税文件（财税字〔1995〕48 号本次未返回可核验正文）；执行异议复议规定（2020 修正）不动产买受人四要件现行条号（2015 年第 28 条文本已被修改）。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用核心给付和行政手续结构定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须同时满足才正触发：

1. 双方拟共同开发特定地块上的房地产，而不是单纯买卖、单纯借款、单纯代建。
2. 主结构是**双名义报建 + 直接初始登记**：行政审批记载双方名称，投资方上升为共同权利人，而不是隐名债权后再二次过户。

## 节点 2　主体、双资质、土地洁净与决议

1. 建主体表：土地提供方、投资联建方、共同项目管理机构、授权签字人。名称不一致不自动合并。角色必须同时标出民事合作身份和行政报建名义。
2. 土地权属：土地提供方须持有合法使用权证。用途应为城镇住宅或商服等可开发用途。材料未出示权属证书或与红线图不一致：该处分能力字段停止，不得写成“可以联建”。
3. 土地洁净：抵押、查封、闲置预警、权属争议。材料未提及不得写成“无权利负担”。已抵押或查封：红线。告知在系统中通常无法添加第二权利人，不写“签约后查封自然解除”。
4. 划拨地、集体土地、宅基地：不得按本类型城镇出让地联建放行。划拨须另核批准；集体/宅基地负触发 `宅基地合作开发合同·审查` 或停止签署建议。不得使用已删除的 2005 年解释第 16 条作为唯一无效依据。
5. 民事资质：至少一方具备房地产开发经营资质，否则民事效力字段在核验后按解释第 13 条处理；起诉前补办不得写成已经补办。
6. 行政双资质：双名义报建是否要求双方均有开发或相应建设资质，运行时按当地政策核验。未核验：报建可行性字段停止。不得把一方有资质写成“证照一定能办下”。
7. 国资、集体、上市公司以土地或重大资产合作：按章程或监管要求决议。未附决议：字段停止，修改句要求作为附件且未获批准不生效、不报建。
8. 口头“我们局长说可以联建”“对方老板同意了”不得写成已批准或已授权。

不足：字段停止，列出待补材料，不补主体、不补洁净、不补已批准。

## 节点 3　双名义报建闭环与共同发包（硬闸）

本类型的核心交换不是“一方出钱一方分房”，而是**行政共同名义**。

| 文本写法 | 本任务动作 |
| --- | --- |
| 只写“双方联合开发、依法办理手续” | 必须改。拆成立项、规划许可、施工许可、竣工验收备案四段，每段写谁、何日、向谁提交、达不到的救济 |
| “全部报建由出地方单方办理，投资方予以配合” | 红线或负触发 `隐名参建联建·审查`。本类型不得放行单名义主路径 |
| 未写每一证照必须记载双方名称 | 必须改。取得后【待填】日内交换原件或查询结果核验双名称 |
| 对外施工/EPC 合同由一方单独发包 | 必须改。双方为共同发包人；一方拒签视为配合报建违约 |
| 一方拒不在联建审批表盖章无后果 | 必须改。逾期【待填】日的违约金、赔偿停工损失，并可启动印章托管或解除 |
| “签字即视为已完成联建备案/已是共同权利人” | 红线。禁止拟制行政审批 |

批准、备案、许可写成双方义务期限或合同生效条件，不写成已经完成。当地是否仍受理双名义联建未核验：该字段停止，修改句要求把《政府关于联建政策的咨询纪要》作附件。

## 节点 4　直接初始登记、分房特定化与语言（硬闸）

物权变动以登记为准。联建协议本身不产生房屋所有权。直接初始登记是本模式区别于参建隐名的成果闸。

| 文本写法 | 本任务动作 |
| --- | --- |
| 主路径“先登记在出地方名下，再过户给投资方” | 负触发 `隐名参建联建·审查` |
| 使用“过户登记”指称投资方拿证 | 必须改。改为「初始登记」或「直接登记」 |
| 分房只写“按投资比例分配”，无部位、楼层、面积 | 必须改。附件《项目拟分配明细表》特定到幢/层/号或可测绘范围，并作为报建备案附件 |
| 未写土地是共有登记还是仅建筑物按份持有 | 必须改。按后期确权需求二选一，不得两可 |
| “本合同签字即取得房屋所有权/准物权” | 红线。拆成：合同成立生效 vs 不动产登记发生物权效力 |
| 政策变化必须走转让过户 | 本类型写税费分担、解除或转项目公司；不改成可履行买卖过户文本 |

预告登记：联建手续办理后，针对拟分得部位申请预告登记。办不成不得写成已经对抗。预告登记失效期限按第 221 条核验后落句。

## 节点 5　共担风险、税务失败预案与发票（硬闸）

共同投资、共同开发、共担风险是合作开发的基本内容，也是申请合作建房税务处理的形式要件。

| 文本写法 | 本任务动作 |
| --- | --- |

## 节点 6　准物权边界与对抗执行（硬闸）

联建手续使投资方在行政审批上成为共同权利人，但法律层级上仍不是典型物权。出地方债务、查封、破产时，投资方可能无法排除执行。

核验后可引用的判断点（须 `search_law` 写入 `L#` 再落法律结论）：

- 未登记不发生物权效力。
- 预告登记可限制处分；符合物权登记条件时，停止处分或排除执行才可能得到支持。
- 仅以“合作开发、实际出资、登记在对方名下”主张排除执行的，实务上常不被支持。

| 文本写法 | 本任务动作 |
| --- | --- |
| “联建手续具有物权效力，可对抗任何第三人执行” | 红线。改为：双方确认联建手续旨在使投资方成为行政审批上的共同权利人；能否排除强制执行取决于届时登记状态、预告登记及执行异议规则，任何一方不得保证结果 |
| 土地证仍仅登记出地方，无预告登记安排 | 必须改。补预告登记义务；并提示投资方保留全部出资凭证，款项性质写清为合作开发投入/购建房款，**不保证**买受人四要件成就 |
| 因出地方债务致土地被查封、无法初始登记 | 必须改。出地方按约定部位届时市场价赔偿，并配合排除妨碍；不得写成查封自动失效 |
| 用户要求保证“签了就能对抗执行/破产隔离” | 整体停止该结论 |

买受人对抗执行四要件（2015 年第 28 条）本次仅返回已被修改文本，2020 年修正对应条号运行时重核，不得凭记忆落“现有依据支持已能排除执行”。

## 节点 7　政策断档、解除与配合违约

1. 当地停止办理新的联建手续、强制要求项目公司：必须有备选。修改句：主管部门书面不予受理或政策废止双名义的，双方应在【待填】日内协商依法设立具有房地产开发经营资质的项目公司承继权利义务；协商不成，任何一方可通知解除，已投入按【待填】清算，互不追究报批不能的违约责任——但因一方拒不配合导致不能的除外。
2. 不得在本技能把备选改写成可签署的 `一方出地一方出钱联建·审查` 或 `隐名参建联建·审查` 文本。用户要转类型：负触发对应原子。
3. 配合报建违约与确权受阻必须分别有可执行后果。只有“依法承担违约责任”视为必须改。
4. 生效：通常“双方签章且联建申请获主管部门受理之日起生效”。若写成签字立即全面生效、无视批准：拆成合同成立 vs 报建义务开始 vs 物权变动。
5. 用户要求倒签“已经受理”或补假咨询纪要：整体停止。
