# 联建模式联建合同·审查

## 任务目标

在单一立场下，只审查 **房地产合同 / 联建模式联建合同** 的待签文本：核心结构是双方以**联合名义**办理立项、规划、施工至竣工验收，并在验收后把约定比例或特定部位房屋**直接初始登记**到投资方名下，而不是二次转让过户。输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「联建模式联建合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查、从零起草、履约交底、争议文书、有效性或必然确权保证、必然对抗执行保证、暂免土地增值税保证、参建隐名整案、其他联建子类型整案、项目公司股权合作整案、委托代建整案。

## 工作边界

正触发：已有可读待签文本要评改，；尚未签署，尚未成争；核心给付是双方在**不新设项目公司（或不以项目公司持股为主结构）**的前提下，以**双名义报建、共同确权、直接初始登记**开发房地产。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 立项、规划许可、施工许可、竣工验收备案只出地方或一方单名义办理，投资方隐名，确权主路径是出地方先拿大证再商品房买卖或资产转让过户 → `隐名参建联建·审查`；
- 标题或核心是“一方出地、一方出钱”的出资结构，审查重点不是双名义行政手续 → `一方出地一方出钱联建·审查`；
- “一方出地、双方出钱” → `一方出地双方出钱联建·审查`；
- “双方出地” → `“双方出地”型联建合同·审查`；
- 投资方不分担亏损、只拿固定货币、固定房屋或只使用房屋 → `不共担风险型联建合同·审查`，或按解释第 23、24 条切开 `资金方只收固定货币→第二十三条转` / 房屋买卖 / 租赁；
- 共担风险但文本主轴是风险分配而不是双名义报建 → `共担风险型联建合同·审查`；
- 一方单独操盘、另一方不共同签署工程合同 → `一方操盘型联建合同·审查`；
- 联合操盘但无双名义办证主结构 → `联合操盘型联建合同·审查`；
- 新设或收购项目公司、以股权取得土地或开发权为主结构 → `以股拿地·审查`、`或` 或 `城更股权合作·审查`；
- 委托代建、无共同权利人地位 → `委托代建合同·审查` 或 `或`；
- 单纯国有土地使用权转让、未达投资额变相卖地 → `国有土地使用权转让合同·审查`；
- 宅基地或集体土地合作建房 → `宅基地合作开发合同·审查`；
- 土地使用权项下概括“房地产合作开发类合同”、无法读出双名义直接确权 → `房地产合作开发类合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `联建模式联建合同·起草`；
- 已签只问报建进度、出资节点、验收日 → 本套导航的履约步骤；
- 已成争（催告、解除、确权诉讼、执行异议、立案仲裁）→ 合同争议或对应专项领域。

挂靠、违法分包、规避限购、未达开发投资额变相转让土地使用权：只出告知，不改写成可履行结构。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成。每一闸必须给出修改句或明确转出口径，禁止只打红黄绿。禁止把全部联建写成一份 method。

1. **双名义报建与共同确权**。从立项、招标、建设用地/建设工程规划许可、施工许可到竣工验收备案，均必须以双方共同名义办理。修改句写清：谁在何日向何机关提交何表、另一方几日内盖章；每一证照取得后【待填】日内核验是否记载双方名称；缺一方名称视为未完成该阶段。只签“联建”但约定或事实仍用一方名义报建：红线，不得当本类型放行；能改成可执行双名义义务则必须改，用户坚持单名义则负触发 `隐名参建联建·审查`。
2. **直接初始登记，禁止二次过户主路径**。竣工验收后，按联建协议及主管部门备案，把约定比例或特定部位房屋**直接初始登记**在投资方名下，无需二次转让。用语必须是「初始登记」或「直接登记」，不得把主路径写成「过户登记」。主路径是出地方先办大证，再以商品房买卖或资产转让过户给投资方：负触发 `隐名参建联建·审查`。政策变化导致必须走转让的，本类型只写税费分担与解除/转项目公司备选，不在本包改成可履行买卖过户。
3. **与参建隐名 `隐名参建联建·审查` 切开**。本技能是双名义、准物权公示、直接确权、发票按约定开给双方。`隐名参建联建·审查` 是单名义、隐名债权、二次确权、发票开给出地方。禁止打开或复制其 method。禁止把股权质押、出地方抵押、买卖过户做成主路径来“补强”本类型。
4. **禁止把全部联建写成一份 method**。出资结构走 `一方出地一方出钱联建·审查`/`一方出地双方出钱联建·审查`/`“双方出地”型联建合同·审查`；风险分担走 `不共担风险型联建合同·审查`/`共担风险型联建合同·审查`；操盘走 `一方操盘型联建合同·审查`/`联合操盘型联建合同·审查`。本技能只审行政双名义联建模式。禁止套用这些邻类的出资比例精算、操盘权表决或固定回报主线。
5. **民事资质与行政双资质分账**。民事上，合作开发房地产合同一方具备房地产开发经营资质即可认定有效；双方均不具备且起诉前未补办或未依法合作成立有资质企业的，应认定无效。行政上，双名义报建通常要求双方均具备开发或相应建设资质，未闭合则**报建可行性字段停止**，不得写成“一方有资质就一定能办下双名义证”。不得把“双方必须都有资质否则合同无效”写成现行民事规则。
6. **税务认定与对抗执行不得保证**。共同出资、共同开发、共担风险是申请按合作建房处理的形式要件，不是已经获准暂免土地增值税。必须写税务认定失败（按转让、房产交换或其他税目课税）时的分担、发票双开和成本扣除。联建手续不是典型物权；不得保证能对抗出地方债权人强制执行或破产处置。可写预告登记、分房备案、购建房款凭证作为增强，不保证结果。

附加必落句（有事实则单列，无事实在缺口节说明）：

- **土地洁净前置**：办理联建手续前土地须无抵押、无查封；已负担则红线，不写“签约后自然解除”。
- **共同发包人**：对外总包/施工合同以双方共同发包人签署；一方拒不盖章的违约与替代路径。
- **政策断档备选**：当地不再受理双名义联建时，转为依法设立有资质项目公司或免责解除；不得改成未达投资额变相转让或规避限购。
- **共有与按份**：土地是共有登记还是仅地上建筑物按份持有必须写清；分房位置图作行政备案附件。

必须有修改句。每个风险回链文本位置。禁止复制 `隐名参建联建·审查` 或其他联建子类型 method。

## 建立审查坐标

确认：使用者与授权；单方立场（土地提供方、投资联建方）；相对方；全文及土地证、红线图、分房明细、政策咨询纪要、资质证书附件版本；地块坐落与用途；是否拟双名义报建；确权是直接初始登记还是二次过户；出资与风险是否共担；当地是否仍受理联建；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law`（法律结论 required）：核验合作开发定义与资质效力、固定回报定性、合同效力与物权登记分离、预告登记、房地产开发资质、出让土地转让投资额条件、执行异议中买受人或预告登记对抗。
- `search_practiced`（optional）：补双名义与隐名切开、执行异议、地方停办联建等争点。返回“双方都必须有资质否则合同无效”“联建手续即物权、必然对抗执行”“划拨合作一律无效（2005 年第 16 条）”时记噪声。
- `search_template`（optional）：只借栏目结构。范本写固定回报、单名义报建、二次过户或引用已失效《合同法》的，不得当规则。

不虚构案件系统。`search_law` 返回已失效《合同法》《物权法》及其解释、2005 年解释已删除第 16 条、失效划拨联建视同转让专条时记为噪声，不得写入 `L#`。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口，不代替节点。

0. 签署状态与成果分流
1. 类型识别与单目录加载（双名义 + 直接确权；切开 `隐名参建联建·审查` 及其他联建子类型）
2. 主体、双资质、土地洁净、集体/国资决议
3. 双名义报建闭环与共同发包
4. 直接初始登记、分房备案、语言（初始登记 ≠ 过户）
5. 共担风险、税务认定失败预案、发票双开
6. 准物权边界、预告登记、对抗执行不得保证
7. 政策断档、报批失败解除、配合盖章违约
8. 按框架六步出修改句

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签或假批文、把未达投资额变相转让或规避限购改成可履行、保证必然直接确权或必然对抗执行、把单名义隐名结构硬留在本技能改完。
- `字段停止`：法域、当地是否仍受理双名义联建、双方资质、土地抵押/查封、税务合作建房口径未核验；分房部位无法特定。
- `目标停止`：主目标已变为从零起草、履约交底、确权或执行异议诉讼文书，或用户要把本约改成参建隐名二次过户以便本技能代做 `隐名参建联建·审查`。

集体土地、宅基地、划拨地未批先建且用户拒绝升级：停止“可以签署”建议。
