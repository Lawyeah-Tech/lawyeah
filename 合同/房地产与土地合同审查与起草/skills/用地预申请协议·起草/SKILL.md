# 用地预申请协议·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、1986 年未修正《土地管理法》、1994 年未修正《城市房地产管理法》或已失效担保法当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **土地使用权 / 用地预申请协议**，出稿后用本类型硬闸自审，输出可编辑草稿、未决项、自审风险表和自审后修改句。

本原子只承担本类型起草。待签评改转 `用地预申请协议·审查`。本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「用地预申请协议·起草」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、待签文本签前审查、履约交底、争议文书、有效性保证、保证一定挂牌、保证一定摘牌或一定取得建设用地使用权、把定向出让或萝卜条款改成可履行结构。

## 本类型硬闸

1. **预申请 ≠ 出让合同**：本约是招拍挂成交后由市、县自然资源主管部门与竞得人签订的建设用地使用权出让合同。预申请只安排“承诺报价、适时组织公开出让、参加竞买”，不设立建设用地使用权，不产生缴纳全部出让金、交净地、办首次登记的本约义务。正文已是成交确认、出让金分期、交地与登记 → `国有土地使用权出让合同·审查`。禁止把预申请改写成出让合同示范文本。
2. **与勾地切开**：相对方是市、县人民政府自然资源主管部门，核心给付是制度化预申请（承诺不低于某价参加招拍挂，换取出让人在约定期限内组织公开出让）→ 本技能。相对方是管委会、平台公司、招商局、储备中心等**非出让人**协调锁定地块 → `与非出让人签订的勾地协议·审查`。两家以上民商事主体联合拿地、资源互换或先勾后转 → `联合勾地协议·审查`。禁止打开或复制上述邻类 method。
3. **不得定向出让、萝卜条款或不经招拍挂直接供地**：工业、商业、旅游、娱乐、商品住宅等经营性用地以及同一宗地有两个以上意向用地者的，应当招标、拍卖或挂牌。不得约定“只卖给申请人”“设置排他性竞买条件确保中标”“不经程序直接供地”。该类条款只告知、删除或改成公开出让安排，不改写成可履行定向结构。
4. **出让人适格**：法定出让人是市、县人民政府自然资源主管部门。开发区管委会作为出让方订立的**出让合同**应认定无效。预申请若由管委会、街道办、平台公司签署并承诺供地，按非出让人勾地切开或字段停止，不得写成已获法定出让授权。
5. **承诺价 ≠ 法定评估价或底价**：标底或底价应根据土地估价结果和产业政策综合确定，实行集体决策，且不得低于国家规定的最低价标准。协议承诺价只约束预申请人参加竞买时的最低报价，不能代替评估和底价决策，也不能写成“承诺价即为成交价或出让底价”。
6. **保证金 ≠ 定金**：未使用“定金”二字、未约定定金性质的，不得适用定金罚则。预申请保证金不是招拍挂成交后转作受让地块定金的竞买保证金。不得把“政府原因不挂牌即双倍返还”写成法定义务；政府原因未组织出让，优先写成退还本金并约定利息或补偿。
7. **预约 ≠ 已拿地**：预约合同只产生订立本约或参加公开出让的安排。不得写成已取得建设用地使用权、已锁定成交人或预申请等于预告登记。正式出让规划条件较预申请发生实质性不利变更的，应允许撤回预申请且不承担违约责任。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。禁止使用半截 Skill ID。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿，相对方为市、县自然资源主管部门或以其名义并附授权，尚未签署，尚未成争，核心给付是承诺参加公开出让并换取约定期限内组织招拍挂。有完整待签文本要评改时转 `用地预申请协议·审查`。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 相对方是管委会、平台、招商局等非出让人，主给付是协调供地或招商锁定 → `与非出让人签订的勾地协议·审查`；
- 两家以上企业联合拿地、产业换地、先勾后转股权 → `联合勾地协议·审查`；
- 正文已是出让合同：出让金、交地、登记、使用条件、成交确认 → `国有土地使用权出让合同·审查`；
- 协议出让方案、同一地块唯一意向且非经营性用地走协议程序 → 不按本技能改成预申请外壳，转引擎或出让原子；
- 建设项目用地预审、选址预审、农转用报批 → 不是本类型；
- 集体建设用地出让、未征收集体土地直接供地商品房开发 → `集体建设用地使用权出让合同·审查` 或停止；
- 土地置换、股权拿地、合作开发、委托代建 → `土地置换协议·审查` / `以股拿地·审查` / `房地产合作开发类合同·审查` / `委托代建合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁或纪检已介入 → `或对应专项领域。` 或行政／争议专项。

以预申请为名约定不经招拍挂直接供地、围标陪标、伪造净地或倒签批准：只出告知，不改写成可履行路径。

## 建立起草坐标

确认：使用者与授权；单方立场（预申请人或出让人，择一）；相对方是否市、县自然资源主管部门；全文及附件／宗地图／规划条件／会议纪要版本；地块四至、用途、面积、容积率；是否经营性用地；承诺单价或总价；保证金性质与金额；组织招拍挂的期限；竞买义务与低于承诺价的后果；规划变更退出；项目公司承接；产业监管或投资协议是否另册；不可接受事项；法域与拟签署日。缺立场或本类型条件未谈妥则不启动起草。有完整待签文本要评改时转 `用地预申请协议·审查`。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 起草模式

本原子只承担本类型起草。待签评改转 `用地预申请协议·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。商业数字未给用 `【待填】`。

按框架六步落稿。本类型硬闸改成下列起草必写 / 附件必附 / 禁止出现。

### 起草必写

- 相对方写市、县人民政府自然资源主管部门；核心给付只安排承诺不低于某价参加招拍挂，换取约定期限内组织公开出让。
- 写明本协议不设立建设用地使用权，不产生缴纳全部出让金、交净地、办首次登记的本约义务；出让合同仅在依法确定中标人、竞得人后另行签订。
- 承诺价只约束预申请人参加竞买时的最低报价，不得写成成交价或法定底价；组织出让须落到工作日期限和通知渠道。
- 保证金未约定定金性质的，按履约保证金写退还与扣留；政府原因未组织出让，优先退还本金并约定利息或补偿。
- 正式出让规划条件较预申请发生实质性不利变更的，预申请人可撤回且不承担违约。

### 附件必附

- 宗地图、规划条件。
- 政府批准文件或会议纪要编号；未获批准不生效。
- 预申请人内部决议与授权；拟由项目公司承接的，附承接条件。

### 禁止出现

- 定向出让、萝卜条款、不经招拍挂直接供地，或改写成可履行定向结构。
- 把预申请改写成出让合同示范文本，或写成交确认、出让金分期、交地与登记作为本约主给付。
- 管委会、街道办、平台公司作为法定出让人，或写成已获法定出让授权。
- “承诺价即为成交价或出让底价”；“政府原因不挂牌即双倍返还”写成法定义务。
- 已取得建设用地使用权、已锁定成交人、预申请等于预告登记。

出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 留本任务起草并自审；已签履约 → 本套导航履约步骤；已成争 → 合同争议或行政专项。有完整待签文本要评改 → `用地预申请协议·审查`。未签且本类型条件已谈妥、要出己方稿，才进入本任务。

### 1. 类型锁死

标题、相对方与核心给付一致才继续。勾地、联合勾地、出让本约、协议出让、建设项目用地预审、集体土地未征收负触发。

### 2. 主体与授权

出让人名称是否市、县自然资源主管部门；预申请人与拟设立项目公司；内部决议与授权是否可见。

### 3. 标的、净地与规划

四至、面积、用途、容积率是否特定；是否净地、是否集体土地未征收；权利负担未披露不得写成没有。

### 4. 招拍挂程序与承诺价

组织出让期限；通知竞买；承诺价只约束最低报价；底价集体决策不得被协议代替。

### 5. 保证金、退出与项目公司

保证金定性；规划变更撤回；政策变动重新协商；中标后 SPV 承接不得写成已取得使用权。

### 6. 格式条款与强制规范

定向出让、萝卜条款、围标不得改成可履行。无核验引文则法律结论字段停止。

### 7. 违约、管辖与行政协议色彩

分别写清不报价、不挂牌、规划变更的后果。不得保证行政诉讼或民事诉讼一定成立。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；条件未谈妥仍要整稿；用户坚持倒签、保证有效、保证一定摘牌、把定向出让或萝卜条款改成可履行、把预申请改成不经招拍挂的出让外壳。
- `字段停止`：法域、动态规则、主体授权、净地与征收、评估底价、产业准入未核验。
- `目标停止`：主目标已变为待签评改（转 `用地预申请协议·审查`）、履约交底、争议文书，或已锁他类。
