# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受、一定挂牌或一定摘牌；编造未给出的价款、面积、期限；把已失效《合同法》、1986 年土地管理法旧义或 1994 年未修正房地产法写入结论；把勾地、联合勾地或出让合同当成已完成的本类型审查；写“预申请即已取得建设用地使用权”；写“承诺价就是法定底价”；把未写定金的保证金写成当然双倍返还。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查用地预申请协议（土地使用权）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、1986 年土地管理法旧义、1994 年未修正房地产法或建设项目用地预审条文时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `土地使用权`，子级 `用地预申请协议`。定性理由、易混切开结果（非出让人勾地 / 联合勾地 / 出让本约 / 协议出让 / 建设项目用地预审 / 集体土地）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、授权、地块与文本版本

主体表：签约名、竞买名、付款名、拟设立 SPV、授权签字人。出让人是否市、县自然资源主管部门。版本表：正文、宗地图、规划条件、会议纪要、产业协议摘要、聊天确认；冲突并列。

## 5. 给付闭环：预申请安排而非出让本约

地块是否特定；是否经营性用地；承诺价与法定底价是否切开；组织出让期限是否可执行；竞买义务与低于承诺价的后果；保证金定性；规划变更撤回；项目公司承接。缺口标 `G#`。不输出已交地、已登记、已缴纳全部出让金的本约口径。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹。定向出让、萝卜条款、不经招拍挂直接供地、未征收集体土地供商品住宅不得写成可放行。强制规范只按第一百五十三条区分是否导致民事行为无效，不用失效口诀。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把“尽快组织出让”留作可接受空词。

## 9. 谈判与签署提醒

谈判顺序：先红线（实为出让或勾地、定向出让、萝卜条款、未征收即供地），再必须改（组织出让期限、承诺价与底价分列、保证金定性、规划变更撤回、主体授权），最后可优化。签署提醒：主管部门公章、授权书、宗地图、规划条件、内部决议、保证金账户。不指导倒签或补假批准。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书或效力保证，也不是勾地、联合勾地或出让合同安排。
