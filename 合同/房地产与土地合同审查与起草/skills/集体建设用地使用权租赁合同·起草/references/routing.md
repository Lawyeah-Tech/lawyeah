# 边界与路由

本技能只审查 **土地使用权 / 集体建设用地使用权租赁合同**。主线是农村集体经济组织将已登记的集体经营性建设用地，以租金为对价、在法定期限内出租给单位或个人使用。不是出让，不是农地承包或土地经营权流转，也不是宅基地房屋租赁。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 出让金、出让年限、用益物权式集体建设用地使用权设立 | `集体建设用地使用权出让合同·审查` |
| 国有土地使用权出让，出让人为政府或自然资源主管部门 | `国有土地使用权出让合同·审查` |
| 集体建设用地使用权出资入股、作价取得股权 | `集体建设用地使用权出资入股合同·审查` |
| 双方共担开发风险、分配房屋或利润 | `集体建设用地合作开发合同·审查` |
| 宅基地上房屋出租、委托运营 | `宅基地房屋租赁运营·审查` |
| 宅基地房屋买卖（集体经济组织内部） | `宅基地内部房屋买卖·审查` |
| 宅基地合作开发 | `宅基地合作开发合同·审查` |
| 家庭承包地出租、土地承包经营权租赁 | `标的是耕地林地草地或家庭承包地，维持农业用途或流转承包经营权／土地经营权→` |
| 保留承包权、流转土地经营权 | `保留承包权流转土地经营权→` |
| 对农用地成立普通债权租赁 | `对农用地成立普通债权租赁不设承包经营权或土地经营权→` |
| 国有建设用地租赁、出租人是市县政府或自然资源主管部门 | 本套导航的类型切开步骤 重新定性；禁止套用本类型决议闸 |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、问交地日／付租日／备案日 | 本套导航的履约步骤 |
| 腾退、决议效力、违法占地已被催告、立案、开庭或仲裁 | `或对应专项领域。` 或对应专项；不填签前十节 |
| 名为合作开发、实为固定租金或不承担风险 | 留本任务按租赁审；租期仍受二十年限制 |
| 超过二十年、无决议即视为已表决、农用地非农建设 | 留本任务只出红线；用户坚持改成可履行则整体停止 |
| C 端大众快检或 `承包地／土地经营权流转` | 只分流，不回改、不引用其目录 |

专业版未收录的邻接场景不会作为本原子的实体审查对象。若用户拿这些文本来找本技能：输出 `unavailable` 或负触发路由，不得用本类型硬套。

本技能不得转去加载出让、农地流转、国有租赁或宅基地房屋租赁双文件完成本类型审查，也不得把出让最高年限、承包经营权登记或宅基地资格写成集体建设用地租赁的默认主路径。
