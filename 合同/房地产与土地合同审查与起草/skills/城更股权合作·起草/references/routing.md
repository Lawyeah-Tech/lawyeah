# 边界与路由

本技能只审查 **房地产合同 / 城市更新项目合作合同（股权合作）**。中文成果名称必须是「审查城市更新项目合作合同（股权合作）（房地产合同）」。

负触发只输出 `触发判定：负触发，未启动本任务`、路由全 ID 和最小交接，不填十节实体结论。禁止半截 ID。禁止打开邻类 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 无股权纽带，开发商与前期服务公司只在项目层分工或分成 | `城更合作（开发商与前期服务）·审查` |
| 村集体经济组织作为签约一方与合作企业直接缔约 | `城更合作（村集体与企业）·审查` |
| 只做摸底、方案、前期服务，不转实施主体、不持股 | `城市更新项目前期服务合同·审查` |
| 仅意向或备忘，无设立项目公司或出资义务 | `城市更新项目意向合作协议·审查` |
| 无更新单元和实施主体转化的存量股权转让 | `或` 或 `或` |
| 普通出让土地使用权合作开发，无城市更新行政节点 | `房地产合作开发类合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、问出资日或申报节点 | 本套导航的履约步骤 |
| 已成争 | `或对应专项领域。` 或对应专项领域 |
| C 端普通商业审查 | 只分流，不回改 |

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。

夹带专章：

- 一小段前期服务费：可摘录后提示 `城市更新项目前期服务合同·审查`，股权与实施主体条款留在本任务。
- 一小段存量转股：可摘录后提示 `或`，不得把优先购买权做成主路径。
- 用户要求本任务把项目层合作或普通转股整案改完：目标停止。
