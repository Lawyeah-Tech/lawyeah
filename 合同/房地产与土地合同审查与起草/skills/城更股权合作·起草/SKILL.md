# 城更股权合作·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 1993 年旧公司法条号、地方城市更新办法当然导致整约无效、签字即取得实施主体当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **房地产合同 / 城市更新项目合作合同（股权合作）** 的待签文本：双方通过设立或入股项目公司（SPV），把开发商的资金与前期服务公司的更新单元资源绑在同一股权结构上，核心交换是持股、出资、治理和实施主体转化，而不是项目层分工事权或存量股权买卖。输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「城更股权合作·起草」。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查、从零起草、履约交底、争议文书、合同或实施主体确认有效性保证、把本约改成可强制履行的项目层合作或普通股权转让、实施主体申报代办、税务精算终局数字。

## 工作边界

正触发：已有可读待签文本要评改（审查模式），或本类型条件已谈妥要出己方稿（起草模式）；尚未签署，尚未成争；标题或外壳是城市更新股权合作、项目公司合资或 SPV 入股；**且**核心给付是双方以持股、章程、出资和实施主体转化为交换，而不是单纯服务费、项目层分成或存量股权价款。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 不设或未入股项目公司，只在项目层分工、服务费或销售分成 → `城更合作（开发商与前期服务）·审查`；
- 村集体经济组织作为签约一方与合作企业直接缔约 → `城更合作（村集体与企业）·审查`；
- 只做摸底、方案、前期服务，不转实施主体、不设股权纽带 → `城市更新项目前期服务合同·审查`；
- 仅意向、备忘，无设立项目公司或出资义务 → `城市更新项目意向合作协议·审查`；
- 无更新单元、无实施主体转化，对价只是存量股权价款 → `或` 或 `或`；
- 普通出让土地使用权 + 资金的合作开发，无城市更新行政节点 → `房地产合作开发类合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问出资日、申报进度、工商变更节点 → 本套导航的履约步骤；
- 已成争（催告回购、确认实施主体、股权冻结、诉讼仲裁）→ 合同争议或对应专项领域。

挂靠、违法分包、规避公开出让或合作主体确认、用假批复包装开发权：只出告知，不改写成可履行结构。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成。每一闸必须给出修改句或明确转出口径，禁止只打红黄绿。

1. **股权合作 vs 项目合作**。标题写城市更新或股权投资不决定类型。必须同时读出三组事实：是否设立或入股项目公司；对价是持股、章程、董事会席位和出资，还是项目层工作分工、服务费或利润分成；失败时清理的是股权回购／减资／清算，还是项目层解约和费用结算。没有股权纽带的，负触发 `城更合作（开发商与前期服务）·审查`。村集体是签约主体的，负触发 `城更合作（村集体与企业）·审查`。目标公司只是普通经营公司、没有更新单元和实施主体转化的，负触发 `或` 或 `或`。修改句必须把鉴于改成：双方确认本协议项下拟设立或入股的项目公司名称为【待填】，甲方拟持有【待填】%、乙方拟持有【待填】%，本协议的主给付是完成出资、章程一致和以项目公司申报实施主体，不因此视为已经取得城市更新开发权。禁止打开 `城更合作（开发商与前期服务）·审查` 或普通股权转让 method。禁止套优先购买权、股东会同意作为本任务主路径。
2. **实施主体资格**。项目公司股东地位不等于已经取得或必然取得实施主体／合作主体资格。必须读出更新单元范围、当前阶段、谁负责申报、未转化成功时如何回购或清算。不得把签字、内部决议或缴纳首期出资写成已经完成确认。当地政策限制合作主体确认前后股权变动的，标红旗并要求运行时核验地方规则；不得把地方规章写成全国统一无效依据，也不得写成“完善内部决议即可取得实施主体”。转化失败必须有评估价或成本价回购、减资或清算句，禁止只写“双方协商”。

附加必落句（有事实则单列，无事实在缺口节说明）：

- **资源入股**：前期投入、批文、方案可以作价的，必须可评估、可转让并办理权属或债权凭证；空泛“资源、关系、打招呼”不得写成合法出资。未评估的，出资字段停止。
- **明股实债**：无论专项规划是否批复、无论是否取得实施主体均支付固定货币或保底收益、且不承担亏损的，按借款识别，不得改名为“分红”后放行。合法路径是共担风险的利润分配，并走弥补亏损、提取公积金程序。
- **股权锁定**：合作主体确认前，限制向第三方转股或质押；退出条款不得写成可以绕过当地股权变更禁令的即刻过户。
- **两类费用**：前期成本（已发生规费、服务成本）与开发成本（后续拆迁、补缴地价）分列，不得混成一笔“投资款”。
- **模拟利润 vs 法定利润**：长周期预分配只能写成“模拟利润分配”，并约定税务合规与亏损弥补完成前不得构成公司法上的利润分配。
- **代持**：名义股东与实际出资人必须写清隔离和对内请求权；代持不能替代实施主体资格，也不得保证能够显名。
- **最终解释权**：按格式条款审查，不写成当然无效，也不放行单方解释项目节点。

必须有修改句。每个风险回链文本位置。禁止复制 `城更合作（开发商与前期服务）·审查` 或普通股权转让 method。

## 建立起草坐标

确认：使用者与授权；单方立场（开发商／资金方，或前期服务公司／资源方，择一）；相对方；全文及章程／托管或质押／村集体文件版本；项目公司是否已设；持股与出资；更新单元与阶段；当地实施主体规则是否已知；有无固定收益；转化失败公式；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的金额、比例、期限用 `【待填】`，不编造。

知识库若写“本类型属于承揽”“类似于一级整理联营所以就是联营”“最终解释权当然无效”“地方政策禁止股权变动所以合同当然无效”，或以空泛资源直接入股为合法出资，以本文件和 `method.md` 纠正为准，不回写知识正文。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law`（法律结论 required）：核验名实认定、强制规范是否导致无效、批准生效、非货币出资、利润分配、固定货币＝借款、代持、格式条款、村集体决议。
- `search_practiced`（optional）：补股权合作与借贷切开、实施主体审批争点。返回“地方办法当然无效”“持股即开发权”时记噪声。
- `search_template`（optional）：只借栏目结构。范本写“保底利润且不参与经营”或只有普通转股价款的，不得当规则。

不虚构案件系统。`search_law` 返回已失效《合同法》及其解释、1993 年旧公司法条号、失效注册资本登记规定时记为噪声，不得写入 `L#`。


## 起草模式

本原子只承担本类型起草。待签评改转 `城更股权合作·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。按框架六步落稿。商业数字未给用 `【待填】`。出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。无股权纽带的项目层合作、村集体直接缔约、普通股权转让：负触发，不按邻类出稿。

**起草必写**

- 鉴于写明：拟设立或入股的项目公司名称为【待填】，甲方拟持有【待填】%、乙方拟持有【待填】%；主给付是完成出资、章程一致和以项目公司申报实施主体，不因此视为已经取得城市更新开发权。
- 更新单元范围、当前阶段、谁负责申报。
- 未转化成功时按评估价或成本价回购、减资或清算，禁止只写“双方协商”。
- 资源入股须可评估、可转让并办理权属或债权凭证；空泛“资源、关系、打招呼”不得写成合法出资。
- 前期成本与开发成本分列，不得混成一笔“投资款”。
- 长周期预分配写成“模拟利润分配”；税务合规与亏损弥补完成前不得构成公司法上的利润分配。
- 合作主体确认前限制向第三方转股或质押。
- 代持须写清隔离和对内请求权；代持不能替代实施主体资格，也不得保证能够显名。

**附件必附**

- 项目公司章程或章程一致文本。
- 更新单元范围文件。
- 资源入股时的对价评估。
- 转化失败回购／减资／清算公式。

**禁止出现**

- 签字、内部决议或缴纳首期出资即已经完成实施主体确认。
- “完善内部决议即可取得实施主体”；把地方规章写成全国统一无效依据。
- 无论专项规划是否批复、无论是否取得实施主体均支付固定货币或保底收益且不承担亏损。
- 退出条款写成可以绕过当地股权变更禁令的即刻过户。
- 套优先购买权、股东会同意作为本任务主路径。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口，不代替节点。

0. 签署状态与成果分流
1. 类型识别与单目录加载（股权纽带 + 更新单元；切开项目合作／普通转股／前期服务／村集体直接缔约）
2. 实施主体资格与行政阶段
3. 主体、资源锁定、村集体决议
4. 出资、资源入股、明股实债
5. 治理、一票否决、资金闭环
6. 分配、转化失败、锁定退出
7. 格式条款与强制规范
8. 按框架六步出修改句

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签或补假实施主体／专项规划批复、把未确认的实施主体改成可履行开发权、把规避公开出让或确认前股权腾挪改成可履行结构、保证必然获批或固定收益必然受保护、按普通股权转让或项目合作改完且拒绝切开。
- `字段停止`：法域、当地实施主体规则、资源对价评估、固定收益是否构成借款、村集体决议、项目公司是否已设立。
- `目标停止`：主目标已变为从零起草、履约交底、确认实施主体诉讼文书，或用户要把本约改成项目层合作或普通转股以便请求实际履行。

生存级资金占用或个人无限连带且用户拒绝升级：停止“可以签署”建议。
