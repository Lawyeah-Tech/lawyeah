### **与非出让人签订的勾地协议审查要点**

#### **一、首部 要素审查**

* 
**合同标题**：通常命名为“投资合作协议”、“地块开发意向协议”或“项目推进协议” 。


* 
**风险识别**：此类协议不应命名为“土地出让合同”，因开发区管委会、土地储备中心并非法定的土地出让主体，直接签订土地出让合同将因违反法律强制性规定而无效 。




* **合同主体**：
* 
**甲方（非出让人）**：开发区管委会、土地储备中心、镇政府或城中村改造指挥部 。此类主体拥有土地一级开发或招商权限，但无土地所有权处置权 。


* 
**乙方（用地需求方）**：通常为具备房地产开发资质或投资能力的法人主体 。




* 
**鉴于条款**：应详述双方合作背景，如地块已纳入“土地储备开发计划”或“年度招拍挂计划”，以证明合作事项具有行政层面的合法性前提 。



#### **二、交易条款 审查**

* **标的条款**：
* 
**描述**：明确目标地块的四至范围、预估面积及规划用途（如工业、商业、住宅） 。


* 
**交付标准**：约定由甲方负责土地一级开发，确保在招拍挂前达到“净地”交付标准，包括拆迁补偿安置及基础设施配套（七通一平） 。




* **承诺价格与补偿**：
* 
**价格锁定**：乙方承诺参与招拍挂时的起拍价或最高限价。若乙方最终以超出承诺价格成交，甲方通常承诺通过财政奖励或产业扶持资金等形式给予补偿 。


* 
**陷阱防范**：直接约定“返还土地出让金”条款极易被认定为损害国家利益而无效，建议采取“项目落地奖励”等合法表述 。




* **履行条款**：
* 
**时间节点**：明确甲方启动拆迁的期限、完成一级开发的期限及组织地块上市（招拍挂）的具体预估时间 。


* **排他性安排**：在法律允许范围内，约定甲方在特定期限内不再就该地块与第三方洽谈同类合作，以锁定交易机会。



#### **三、配套条款 审查**

* **违约责任条款（核心）**：
* 
**甲方违约**：若甲方未能按期完成拆迁或地块因政府规划调整无法上市，应约定甲方退还乙方已投入的预付款/保证金，并承担利息及前期调研成本赔偿 。


* 
**乙方违约**：若乙方未按约定参与招拍挂或在竞买中未按承诺报价，甲方有权没收履约保证金或要求乙方支付违约金 。




* **定金与保证金条款**：
* 
**性质区分**：此类协议中支付的通常为“投资保证金”或“意向金”，不宜直接定性为“定金”，以避免受定金罚则及数额上限（20%）的严格限制 。


* 
**抵扣机制**：约定乙方竞买成功后，该笔资金可转为土地出让金或项目开发履约金 。




* **解除与终止条款**：
* 
**约定解除**：当发生重大政策变动（如招拍挂规则由“协议出让”改为“竞地价、竞自持”）导致乙方投资目的落空时，应赋予乙方无责解除权 。





#### **四、尾部 要素审查**

* **生效条款**：
* 
**附条件生效**：可约定“本协议自乙方通过公开招拍挂取得目标地块使用权之日起正式生效” 。若未能取得地块，则协议自动失效或转为结算条款。




* **附件审查**：
* 
**规划详图**：作为协议有效组成部分，确保地块技术指标与招拍挂公告一致，防止“勾地”目标与实际出让标的脱节 。





#### **五、合同语言审查**

* **准确性**：
* 使用“**应当协助办理**”而非“**确保办理成功**”，因甲方（如管委会）对最终的土地出让审批仅有推进义务而非决定权 。


* 明确“**一级开发成本补偿**”与“**土地出让价款**”的边界，防止税务合规风险 。




* **重点词语辨析**：
* 
**“确保”与“力争”**：在涉及政府行政审批事项时，使用“力争”或“积极协调”以降低甲方的行政违约风险；乙方则倾向于要求甲方“确保”地块准时上市 。





#### **六、常见问题与最佳实践**

* 
**结构性缺陷**：协议主体不适格。管委会直接处分土地所有权属于越权行为。最佳实践是甲方以“招商引资主体”身份承诺提供政策支持，而非作为“出卖人”处分土地 。


* 
**条款设计陷阱**：约定“内定中标”。此类条款因违反《招标投标法》及《招标拍卖挂牌出让国有土地使用权规定》而绝对无效，且可能导致整个协议被撤销 。


* 
**最佳实践模式**：采取“**勾地协议 + 产业扶持协议**”的双重结构。勾地协议处理土地预申请及一级开发衔接；产业扶持协议处理后续的财税奖补，以实现商业逻辑的合规闭环 。
