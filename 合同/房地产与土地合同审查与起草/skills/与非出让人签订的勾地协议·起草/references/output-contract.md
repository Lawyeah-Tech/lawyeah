# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受、必然可执行或一定拿地；编造未给出的地价、面积、挂牌日；把已失效《合同法》、1986 年土地管理法或 1994 年房地产管理法旧条号写入结论；把联合勾地或正式出让文本当成已完成的本类型审查；写“管委会签字即取得使用权”；把规避招拍挂或返还出让金改成可履行结构。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查与非出让人签订的勾地协议（土地使用权）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、1986 年土地管理法或 1994 年房地产管理法旧条号时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `土地使用权`，子级 `与非出让人签订的勾地协议`。定性理由、易混切开结果（联合勾地 / 出让合同 / 用地预申请 / 联合拿地）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。无权出让或规避招拍挂写停笔告知，不填可履行供地结构。

## 4. 主体、授权、地块身份与文本版本

主体表：签约名、履行名、付款名、发票名、授权签字人；相对人法律身份（管委会／储备中心／镇政府等）及是否被误写成出让人。地块表：四至、用途、是否声称净地、是否入计划。版本表：正文、规划图、会议纪要、产业准入通知、聊天确认；冲突并列。

## 5. 给付闭环

协调义务、推动挂牌时点、净地标准、产业指标、保证金与返还规则、未能拿地结算。缺口标 `G#`，不补商业数字。规划调整、挂牌、出让写成条件或双方协助期限，不写成已经完成，不写成已经取得建设用地使用权。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹。无权出让、规避招拍挂、返还出让金、阴阳合同不得写成可放行。强制规范只按第一百五十三条区分是否导致民事行为无效，不用失效口诀。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把出让必备项、付清出让金办证直接写成勾地主给付。

## 9. 谈判与签署提醒

谈判顺序：先红线（写成出让、内定中标、返还出让金、毛地当净地、保证拿地），再必须改（身份改协调主体、净地披露、挂牌时点、保证金结算、生效切分、越权确保改协助），最后可优化。签署提醒：授权或纪要附件、规划详图、地块清单、披露清单、条件成就凭证。不指导倒签或补假纪要。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书或效力保证，也不是联合勾地、正式出让或用地预申请安排。
