# 边界与路由

本技能只审查 **房地产合同 / 拆迁补偿安置协议**。

必须同时读出：补偿方向被征收人／被拆迁人／退出权属人给付货币或安置房屋；对价是房屋腾退或土地交出；文本处理补偿方式、补偿项目、搬迁或过渡。标题叫“拆迁补偿安置”但正文是征收部门与实施单位的委托、村企开发分成或普通商品房买卖的，不得留在本技能做实体结论。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或标题补偿安置、核心给付明显不是对权属人的补偿 | 本套导航的类型切开步骤 |
| 房屋征收部门与实施单位订立委托；对价是劳务费、权限、具体工作；讨论不得营利或不得代签 | `意向合作）。禁止打开上述method当本类型主路径。禁止抄` |
| 政府或储备机构委托企业做一级开发，核定成本回收 | `土地一级开发委托，或名为一级开发实为投资借贷` |
| 一级整理绑定二级优先、定向出让、保证摘牌 | `政府作为一方一级整理加二级联动→` |
| 村集体与合作企业的开发合作、出地分成 | `城更合作（村集体与企业）·审查` |
| 普通商品房买卖价款、五证、网签 | `普通商品房买卖价款五证网签主结构→` |
| 资金监管本约 | `资金监管协议·审查` |
| 实施主体监管本约 | `实施主体监管协议·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、问付款、交房、选房 | 本套导航的履约步骤 |
| 已成争 | 合同争议或行政争议专项；不写起诉状、复议申请或仲裁申请 |
| 用户只要补偿终局数字 | 测算技能或人工精算；本技能只审条款 |
| C 端大众材料整理 | 只分流，不回改 |

专业版未收录的 P1 场景不会安装本原子。若用户拿本类型文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。

同一文本既有对住户的补偿表，又夹带对实施单位的委托权限：补偿专章可继续审，委托专章交接 `意向合作）。禁止打开上述method当本类型主路径。禁止抄`；用户坚持整案按本技能改完则目标停止。不得删掉委托条款后硬套。标题写“拆迁委托”、正文全是住户补偿：留本技能并记录标题冲突。

挂靠、伪造征收决定、停水电或建设单位参与搬迁、自行强制拆除：停笔告知，不改写成可履行文本。

禁止在正文写半截 Skill ID。转出时必须写完整 ID，例如 `意向合作）。禁止打开上述method当本类型主路径。禁止抄`、`土地一级开发委托，或名为一级开发实为投资借贷`、`城更合作（村集体与企业）·审查`、`普通商品房买卖价款五证网签主结构→`。
