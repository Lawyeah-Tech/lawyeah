# 审查方法（锁定 房地产合同 / “双方出地” 型联建合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止打开或复制 `一方出地一方出钱联建·审查`、`一方出地双方出钱联建·审查` method。禁止套用一方出地文本的“出地换钱、固定还房、出钱方单独出资”节点。禁止套用土地置换的差价互换、各取对宗节点。禁止套用商品房买卖的五证、面积误差、网签转登记节点。禁止把本技能写成一方出地联建或土地置换换标题。

定性校验：核心给付是双方以土地使用权出资做土地整合型共同开发，才继续；明显他类则负触发，不填十节实体结论。

本文件是可执行判断节点，不是栏目说明书。每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、合宗必然获批、权属已经并证，或唯一必得面积/补地价。

`search_law` 返回已失效《合同法》及其解释、2005 年《最高人民法院关于审理涉及国有土地使用权合同纠纷案件适用法律问题的解释》未修正条号、1994 年《城市房地产管理法》第 38 条、失效《土地登记办法》、失效《划拨土地使用权管理暂行办法》、民法典第 855 条技术合作开发时记为噪声，不得写入 `L#`。`search_practiced` 仍写“转让合同未经登记不生效”“双方均须有资质否则当然无效”“合作建房一律免征土地增值税”的，同样记噪声。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

引用国有土地使用权合同纠纷解释时必须写全称《最高人民法院关于审理涉及国有土地使用权合同纠纷案件适用法律问题的解释（2020修正）》并点条号。禁止只写“法释〔2020〕17 号第十三条”而不写解释名称：同一文号还修正了民间借贷规定，条号会串。

示范文本只参考结构。写“一方出地、一方出资”或“本合同签字即完成土地合并过户”的范本与本类型硬闸冲突，不得当规则。

知识库口径冲突以本方法为准，不回写知识正文：

- `基本面.md` 写“联建双方原则上均应具备房地产开发资质”：纠正为 2020 修正解释第 13 条——一方具备房地产开发经营资质的，应当认定合同有效；双方均不具备的，应当认定合同无效，但起诉前一方取得资质或依法合作成立有资质房地产开发企业的，应当认定合同有效。签前仍应把资质补办或项目公司设立写成履行前提，不得保证起诉前补办成功。
- `基本面.md` 写联建“权属保留基础上的共同开发”：纠正为保留权属只是不合宗模式下的选项。若约定并至一方名下或作价入股项目公司，权属依法发生转移；未办理登记不发生物权效力，但不因此使合同未生效。
- `框架.md` 写“设定极高惩罚性违约金，并约定通过司法强制执行完成权属移转”：纠正为违约金可约定但不得写成不可调整；不得把未完成的行政批准或登记改成可强制过户的履行结构。
- 实务“土地使用权转让合同须登记才生效”：纠正为民法典第 215 条，未办理物权登记不影响合同效力。
- 土增税“合作建房暂免”：未核验到可写入 `L#` 的现行条文前，税负结论字段停止，不得默写免征。

开发窗口 2026-08-18 已核验、可供对照但不得代替运行时核验的规则：

- 《最高人民法院关于审理涉及国有土地使用权合同纠纷案件适用法律问题的解释（2020修正）》第 12 条：合作开发房地产合同，是以提供出让土地使用权、资金等作为共同投资，共享利润、共担风险合作开发房地产为基本内容的合同。
- 同解释第 13 条：一方具备房地产开发经营资质的，应当认定合同有效；双方均不具备的，应当认定合同无效，但起诉前一方取得资质或依法合作成立有资质房地产开发企业的，应当认定合同有效。
- 同解释第 19 条：仅以投资数额确定利润分配比例，未足额交纳出资的，按照实际投资比例分配利润。
- 同解释第 20 条：当事人要求将房屋预售款充抵投资参与利润分配的，不予支持。
- 同解释第 23 条：约定提供资金的当事人不承担经营风险，只收取固定数额货币的，应当认定为借款合同。
- 同解释第 24 条：约定提供资金的当事人不承担经营风险，只以租赁或者其他形式使用房屋的，应当认定为房屋租赁合同。
- 民法典第 209 条：不动产物权经依法登记发生效力；未经登记不发生效力，法律另有规定除外。
- 民法典第 215 条：设立、变更、转让和消灭不动产物权的合同，除法律另有规定或当事人另有约定外，自成立时生效；未办理物权登记不影响合同效力。
- 民法典第 502 条：依法成立的合同自成立时生效，法律另有规定或当事人另有约定除外；应当办理批准等手续的，依照其规定；未办理批准影响合同生效的，不影响报批义务条款的效力。
- 民法典第 967–969 条：合伙合同共享利益、共担风险；合伙人按约定出资；合伙财产在合同终止前不得请求分割。
- 《城市房地产管理法》（2019 修正）第 28 条：依法取得的土地使用权可以作价入股，合资、合作开发经营房地产。
- 同法第 39 条：出让土地使用权转让房地产，须已支付全部出让金并取得证书，房屋建设工程须完成开发投资总额百分之二十五以上（成片开发须形成建设用地条件）。
- 同法第 40 条：划拨土地使用权转让房地产，应当报有批准权的人民政府审批；准予转让的，由受让方办理出让手续并缴纳出让金，或按决定不办出让手续而将土地收益上缴国家。
- 《城市房地产开发经营管理条例》（2020 第二次修订）第 9 条：房地产开发企业按核定资质等级承担项目；第 39 条：城市规划区内集体土地经依法征收转为国有后，方可用于房地产开发经营。
- 《房地产开发企业资质管理规定》（2022 修正）第 3 条：未取得资质证书的企业，不得从事房地产开发经营业务。
- 公司法解释（三）（2020 修正）第 8 条：以划拨土地使用权出资或以设定权利负担的土地使用权出资，应在指定期间办理土地变更或解除负担，逾期认定未依法全面履行出资义务。
- 《契税法》第 2 条：土地使用权转让包括出售、赠与、互换；以作价投资（入股）等方式转移土地、房屋权属的，应当征收契税。
- 《城市房地产转让管理规定》（2001 修正）第 3 条：一方提供土地使用权、另一方或多方提供资金合资合作开发并使权属发生变更的，属于房地产转让的其他合法方式。本类型双方出地并证或入股导致权属变更时，转让条件与报批义务仍要逐项核对，不得写成“联建就不是转让”。

本次检索未返回可写入 `L#` 的正文，运行时必须重核、不得凭记忆落法律结论：2020 修正解释中“不承担风险、只分配固定房屋”的现行条号；土地增值税合作建房减免是否仍有效；民诉法不动产专属管辖现行条号。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用核心给付和出资结构定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须同时满足才正触发：

1. 双方（或多方）各自以土地使用权作为核心出资，而不是一方出地、其余只出钱。
2. 交易目的是相邻或可整合地块的集合利用与共同开发（合宗、重新划线或统一规划），共享利润、共担风险。

必须切开，禁止两可时灌入两套知识：

| 信号 | 归入 | 本技能动作 |
| --- | --- | --- |
| 两宗及以上土地使用权，各方均为权利人，拟合宗/并证或统一规划共同开发 | 本类型 | 加载本目录双文件 |
| 仅一方出地，另一方出全部或主要建设资金 | `一方出地一方出钱联建·审查` | 负触发；不套出地换钱主路径 |
| 一方出地，双方均出建设资金 | `一方出地双方出钱联建·审查` | 负触发；不套双方出钱节点 |
| 互换权属、结算差价，不共同报建、不共担后续建安 | `土地置换协议·审查` | 负触发；不按联建分成出句 |
| 土地使用权父级笼统合作开发，读不出双方出地整合 | `房地产合作开发类合同·审查` | 负触发 |
| 不承担经营风险，只收固定货币 / 固定房屋 / 只租赁使用 | `不共担风险型联建合同·审查` | 负触发；提示可能重定为借款、买卖或租赁 |
| 宅基地合作 | `宅基地合作开发合同·审查` | 负触发 |
| 未入市集体建设用地合作 | `集体建设用地合作开发合同·审查` | 负触发 |

本技能已锁定 **房地产合同 / “双方出地” 型联建合同**。只打开 `references/基本面.md` 与 `框架.md`。禁止读其他类型目录，禁止为对照再开第二类。禁止打开 `一方出地一方出钱联建·审查`、`一方出地双方出钱联建·审查` 的 method。

加载后或定性中出现：借用开发或施工资质、挂靠、违法分包、伪造内部承包包装、规避限购或借名过户、指导伪造合宗批文或倒签批准日、把查封地或禁止开发地包装成可并证、把集体土地/宅基地改成可履行国有出让整合。

1. 交付告知：该结构可能违反法律、行政法规的强制性规定或公序良俗，不得改写成可履行、可强制过户的文本。

3. 风险表只保留识别依据和转出/改道提示。
4. 用户坚持“改到能签、能直接并证、能保证获批”：整体停止。

合规改道（真实项目公司、真实专业分包、先完成征收转出让再谈联建）只点名，不在本任务起草。

## 节点 2　主体、权属、资质与决议

1. 建主体表：各方签约名、各地块权利人、拟设项目公司、报建主体、共有人、抵押权人、村集体或股东会。名称不一致不自动合并。每一方必须同时标出“地主”身份和拟承担的开发角色。
2. 权属：各方须对拟出资地块享有建设用地使用权。核对证号、四至、面积、用途、剩余年限。材料未出示权属证书或与四至图不一致：该处分能力字段停止，不得写成“可以并证”。
3. 物理可整合：两块地是否相邻、是否存在夹缝地或无法利用死角。材料未提供宗地矢量图或四至图：标 `G#`，修改句要求《各宗地四至范围图》作附件。不得把“听说挨着”写成已具备合宗条件。
4. 禁止或限制流通：划拨地未经批准、集体土地未经征收转出让、宅基地、已被查封、权属争议、出让合同限制转让。命中则红线或把批准写成前提，不写可履行并证路径。
5. 内部决策：双方都是地主，重大资产处置须有董事会/股东会决议。涉及村集体土地须附村民代表大会通过的决议。口头“我们老板同意了”、打印决议栏但未签：不得写成已授权。代签、伪造：整体停止。
6. 资质：查各方是否具备房地产开发经营资质，或是否约定设立有资质项目公司。双方均无且未约定补办路径：必须改。一方有资质：效力字段可在核验第 13 条后继续，但仍要把报建名义和资质维持写成义务。
7. 公司法解释（三）第 8 条：拟作价入股的地块若为划拨或已设抵押，修改句要求在指定期间办理出让/变更或解除负担，逾期视为未完成出资。

不足：字段停止，列出待补材料，不补主体、不补权属、不补已批准。

## 节点 3　并证 / 过户路径与合同效力分离（硬闸）

本类型的土地过户不是买卖过户，而是整合路径。三种合法结构必须择一落句，禁止用“依法办理”代替。

| 文本写法 | 本任务动作 |
| --- | --- |
| “双方依法办理土地合宗及过户手续” | 必须改。补：并至谁名下或由哪家项目公司接收；申请义务人；【待填】日前向【待填】机关提交的文件清单；契税、登记费、评估费分担；未完成则不得开工/不得投入后续资金，并可解除 |
| “本合同自合宗登记之日起生效；未登记未生效” | 必须改。拆成：合作合同成立即生效（或另附政府整合意向函、清场完成等约定条件）；物权变动自登记完成时发生。合宗可另作实质履行或出资到位条件 |
| “签字即视为已合宗、已取得对方土地使用权” | 红线。禁止拟制公示 |
| 不合宗，只写“统一规划” | 可以留本技能，但必须补：如何分别确权、公共设施占用谁的地、预售和竣工如何分宗办理 |
| 并至一方名下，未写失败后如何回转 | 必须改。预置土地分割还原理则和回转登记义务 |
| 作价入股项目公司，未写股权对应权益比例 | 必须改。股权比例与土地权益比例对齐，或写明差异及补偿 |
| 一方地块已抵押，仍约定必须合宗 | 红旗。提示抵押权人不同意则合宗失败；修改句把解押或抵押权人书面同意写成合宗前提；解押不成则解除、各自收回 |
| 用户要求把日期写成已经合宗或补假批文 | 整体停止 |

批准、合宗、变更登记写成生效条件或双方义务期限，不写成已经完成。材料未提及不得写成“无在先抵押、查封、租赁”。

出让地再转让或并证导致权属变更时，核验房管法 2019 修正第 39 条的投资进度条件。未达 25% 且属于房屋建设工程：字段停止，修改句把达标或取得有权机关同意写成并证前提，不保证行政机关放行。

## 节点 4　土地权益比例、评估与分配（硬闸）

本类型的份额不是施工产值比，也不是占地面积比。

1. 评估基准必须写清：基准日、评估机构选聘方式、评估对象（各宗土地使用权及地上物）、是否含规划奖励预期。未附《土地作价评估报告》：份额字段停止。
2. 土地权益比例 = 经确认的各宗评估价 / 合计评估价，或合同明确的其他价值权重。修改句删除“按占地面积平均分配”“按证载面积 1:1”。位置优劣、临路与靠里、配建负担必须进入价值平衡。
3. 容积率贡献与奖励面积：整合后总建筑面积、因整合获得的奖励面积如何按权益比例或另行约定分配。只写“奖励面积双方协商”视为未约定。
4. 分配模式必须择一：实物分配（在《整合后规划草图》《房屋分割明细图》上预划区域）或价值分配（按可售货值或实际销售总额比例分成）。两套并行且无冲抵：标 `C#`，必须改。
5. 公配与公摊：变电站、绿地、学校、共同道路占用哪方土地、造价谁担、是否在权益比例中补偿。政府事后加码的配建，走成本预警线和分担公式。
6. 模拟清算：预先设定容积率高于/低于【待填】时的利益调整公式。禁止把签约时的面积表写成不可调整的终局权利。
7. 后续建安、规费、补缴出让金按权益比例或另行约定承担。预售款不得充抵投资参与利润分配。
8. 未足额出资：提示按实际投资比例分配利润的规则，修改句把出资缴付期限和不足额的后果写清。

反方常见抗辩：面积相等就应 50/50；评估过时应重估。本任务不得在未约定重估机制时按市场波动改写比例，也不得把面积比放行。

## 节点 5　性质不一、补地价与规划整合

1. 列出各宗：出让/划拨、用途、年限、规划限高、环保或地质限制。性质不一而未写统一路径：必须改。
2. 划拨地：修改句把“报有批准权的人民政府审批，准予后由【待填】办理出让手续并缴纳出让金，或按决定将土地收益上缴”写成生效或实质履行前提。双方同意视为已批准：红线。
3. 用途变更（工业改居住/商业）：写成附条件，条件不成就则解除、费用按约定清算，不保证规划许可。
4. 规划程序：统一委托设计单位编制《整体开发方案》，共同向规划部门申请统一批办。明确报建主体。重大设计变更走联合开发管理委员会，并适用一票确认。
5. 管理机制：主导方负责制或共管票决制必须择一；销售定价、融资、设计变更的表决规则要有反说（达不成时中止或按评估价收购退出）。
6. 清场：整合范围内搬迁未完成的，写成附条件生效或实质履行前提，避免钉子地块拖垮已清场地块。

## 节点 6　共担风险、一票确认、禁止单方负担、退出回落

1. 共担风险是本类型留在合作开发轨道的条件。约定一方不担风险、只拿固定货币：按解释第 23 条可能被认定为借款，负触发 `不共担风险型联建合同·审查` 或在本技能停笔并转出。只以租赁形式使用房屋：第 24 条可能认定为租赁。只拿固定房屋、不担风险：现行条号运行时核验，未核验则名实字段停止，不得继续按联建成交结构出可履行句。
2. 一票确认权：任何一方拟变更本宗规划条件、新设抵押、长期出租或同意查封的，须书面通知并取得另一方确认；未确认不得对外签署。正说必须有反说。
3. 并证或入股完成前，严禁任何一方擅自抵押其名下拟整合地块。违反则对方可中止投入、解除并主张窝工及约定损失。
4. 优先购买权：一方拟转让本项目权益，另一方在同等条件下优先购买，以维持整合稳定。
5. 行政审批失败：规划部门不予批准整合方案的，各方可免责解除，各自收回土地，已发生的共同费用按【待填】分担。不得把审批失败写成一方违约。
6. 项目公司解散或目的落空：预置土地分割还原理则（按原四至或按权益比例分割），谁在【待填】日内申请回转登记。缺失视为结构性缺陷，必须改。
7. 未动工前一方无法继续：另一方按评估价优先收购其土地权益。收购价、评估时点和付款期必须可执行。
8. 一方地块被查封导致整体无法预售或竣工：违约方承担窝工损失及约定范围内的预期利益。禁止写“过户后查封自然解除”。

## 节点 7　税费与名实（换地、作价入股）

1. 并证、入股、互换都可能发生权属转移。修改句列出契税、登记费、评估费、可能的土地增值税和所得税的承担方，用 `【待填】` 留金额，不编造税率结论。
2. 契税法：土地使用权互换、作价投资（入股）属于应税转移。不得写“联建不是转让所以不征契税”。
3. 名为联建实为换地：双方通过联建完成土地版图对调、差价结算、不共同开发。动作：税旗；建议转 `土地置换协议·审查`；本技能不改写成可履行换地，不保证土增税减免。
4. 用户要求保留联建外壳以规避招拍挂、规避土增税或规避转让审批：整体停止该结论。
5. 资金监管：公共配套超支走成本预警线；后续出资进入监管账户。本任务只审对本约放行的影响，不展开监管协议整案；深度文本可提示 `资金监管协议·审查`。

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`
