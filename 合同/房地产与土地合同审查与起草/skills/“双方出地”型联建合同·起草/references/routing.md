# 边界与路由

本技能只审查 **房地产合同 / “双方出地” 型联建合同**。

必须同时读出：各方均为拟整合地块的法定权利人；以土地使用权作为核心出资；目的是合宗、并证或统一规划后的共同开发。标题叫“双方出地联建”但只有一宗地、或实质是换地差价的，不得留在本技能做实体结论。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或标题联建、核心给付明显不是双方出地整合 | 本套导航的类型切开步骤 |
| 仅一方出地，另一方出全部或主要建设资金；固定还房、出地价款主导 | `一方出地一方出钱联建·审查`；专业版未收录该 P1 时输出 `unavailable`，不得硬套本技能改成出地换钱 |
| 一方出地，双方均出建设资金 | `一方出地双方出钱联建·审查` |
| 互换权属、结算差价，不共同报建、不共担后续建安 | `土地置换协议·审查` |
| 土地使用权父级笼统合作开发，读不出双方出地整合 | `房地产合作开发类合同·审查` |
| 不承担经营风险，只收固定货币、固定房屋或只租赁使用 | `不共担风险型联建合同·审查`；提示可能被重定为借款、买卖或租赁 |
| 按风险共担定性、但并非双方出地整合 | 可提示 `共担风险型联建合同·审查`；双方出地仍是放行关键则留本技能 |
| 操盘分工为主、只有一宗地 | 可提示 `一方操盘型联建合同·审查`；双方出地且共担风险则留本技能审并证与份额 |
| 宅基地合作开发 | `宅基地合作开发合同·审查` |
| 未入市集体建设用地合作开发 | `集体建设用地合作开发合同·审查` |
| 只解决采光、排水、管线，不共同经营 | 引擎按相邻关系或地役定性 |
| 城市更新村企合作、征收安置主导 | `城更合作（村集体与企业）·审查` 或 `拆迁补偿安置协议·审查`；本技能不审安置补偿整案 |
| 资金监管协议单独送审 | `资金监管协议·审查`；本约只审监管条款对本约放行的影响 |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、问合宗进度、出资日、分房交付 | 本套导航的履约步骤 |
| 已成争 | 合同争议领域或对应专项；不写确权诉状、行政诉讼材料 |
| 用户只要补地价、契税或分成面积的终局数字 | 测算、税务专业或人工精算；本技能只审条款 |
| C 端大众快检 | 只分流，不回改 |

同一文本既写“双方出地整合”又写“乙方支付固定地价款、不担风险”：按核心给付切开。固定对价且不担风险 → `不共担风险型联建合同·审查` 或按解释第 23 条提示借款。双方仍出地、仍共担后续开发 → 留本技能，把固定对价改成权益比例。两可且无法判断：负触发引擎，不灌两套知识。

挂靠、违法分包、伪造合宗批文、把查封地或集体土地改成可并证、借名规避限购：停笔告知，不改写成可履行文本。

禁止在正文写半截 Skill ID。转出时必须写完整 ID，例如 `一方出地一方出钱联建·审查`、`一方出地双方出钱联建·审查`、`土地置换协议·审查`。
