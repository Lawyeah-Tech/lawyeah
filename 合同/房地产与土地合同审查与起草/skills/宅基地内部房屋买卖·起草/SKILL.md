## 任务目标

在单一立场下，只按已谈妥条件起草 **土地使用权 / 宅基地房屋买卖合同（集体经济组织内部）** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「宅基地内部房屋买卖·起草」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证转移登记或乡镇批准一定办成、把非本集体成员或城镇居民买房改成可履行过户、把买卖改成可履行长期租赁或合作开发。

## 本类型硬闸

1. **仅本集体成员**：买受人必须是房屋所在地**同一农村集体经济组织成员**。成员资格按《农村集体经济组织法》第十一条、第十二条核成员名册、户籍与权利义务关系，不得把“户口本同村”“同镇外村”“已迁出原户但仍住村里”自动写成适格。同村不同组：仅在该土地由村级集体统一经营、管理（土地管理法2019修正第十一条）且双方均在同一成员名册时，才可继续本类型；组级分别所有而未闭合的，字段停止。出卖人须为该宅基地合法使用权人及地上房屋权利人。
2. **对外转让无效风险只告知**：城镇居民、其他集体经济组织成员、公司或非本集体主体购买，只出告知，不改写成可履行过户、可履行网签、可履行贷款或“先签再迁户/等征收转国有再有效”。用户坚持把对外转让“改到能签”：整体停止。不得引用失效《房屋登记办法》第八十七条当现行法，但非成员通常无法办理转移登记的事实风险必须点明。
3. **与租赁运营、合作开发切开**：租期、租金、委托运营、民宿分成、永久或超二十年占用 → `宅基地房屋租赁运营·审查`。出地加出资共建、建成后分房或固定收益、名为合作实为买断 → `宅基地合作开发合同·审查`。禁止打开或复制 `普通商品房买卖价款五证网签主结构→`（一般商品房买卖）、`文本是二手房存量房买卖本约，即便标题写资金监管→`（二手房／存量房买卖）、`宅基地房屋租赁运营·审查`、`宅基地合作开发合同·审查` 的 method。不得把报批不成改写成“永久使用权租赁”。

配套纪律（写入方法节点，不得用商品房口径替代）：

- 地随房走：标的是地上房屋及其占用范围内的**宅基地使用权**，不是土地所有权。土地仍归农民集体所有（土地管理法2019修正第二条、第十条、第十一条）。写成“出卖宅基地所有权”必须改。
- 家庭共有闭合：宅基地以户为单位，户内共有人（含配偶、成年子女等）未全体签署或未出具同意书的，该处分字段停止。
- 合同成立 ≠ 物权变动：未办理变更／注销登记，不当然导致合同未成立；也不得写成“签字即取得使用权并可对抗一切第三人”。已登记的，转让或消灭应及时变更或注销登记（民法典第三百六十五条）。
- 一户一宅：买受后再形成一户多处宅基地的，告知登记障碍与集体收回风险，不据此单独宣告买卖必然无效，也不改成可履行的一户多宅过户时间表。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签宅基地房屋买卖正文，尚未签署，尚未成争，双方均陈述或材料显示为本集体经济组织成员，核心给付是房屋连同占用范围内宅基地使用权的内部让与，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 承租、转租、委托运营、民宿托管、固定租金或运营分成、租期（含“永久”“终身”） → `宅基地房屋租赁运营·审查`；
- 一方出地、一方出资改建或新建，按面积分房或固定收益，使用权仍登记在原村民名下 → `宅基地合作开发合同·审查`；
- 国有土地上商品房预售／现售、开发商销售、网签备案、按揭、面积误差、交房条件 → `普通商品房买卖价款五证网签主结构→`；
- 国有土地存量房、城市二手房过户、限购核验、资金监管、物业交割 → `文本是二手房存量房买卖本约，即便标题写资金监管→`；
- 集体经营性建设用地出让、出租、出资入股或合作开发 → `集体建设用地使用权出让合同·审查`／`集体建设用地使用权租赁合同·审查`／`集体建设用地使用权出资入股合同·审查`／`集体建设用地合作开发合同·审查`；
- 国有土地使用权转让 → `国有土地使用权转让合同·审查`；
- 承包地／土地经营权流转 → 农村土地承包专项或 `承包地／土地经营权流转`，不在本任务评改；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁或征收补偿争议已立案 → `或对应专项领域。` 或征收／争议专项。

对外转让、阴阳长期租赁规避买卖、伪造成员身份或倒签批准：只出告知，不改写成可履行路径。

## 建立起草坐标

确认：使用者与授权；单方立场；相对方；全文及权属证书／户口簿或成员名册／家庭成员同意书／村集体书面意见版本；买卖双方是否同一集体经济组织成员；房屋坐落、四至、宅基地面积与证载是否一致；共有人是否到场；有无抵押、查封、权属争议、规划或违建；是否已进入或即将征收；集体同意与乡镇审核如何写；转移登记是否被误写成合同生效或签字即物权；价款是否拆房屋价值与使用权补偿；户口迁出如何约；征收补偿如何切；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 起草模式

本原子只承担本类型起草。待签评改转 `宅基地内部房屋买卖·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。商业数字未给用 `【待填】`。

按框架六步落稿。本类型硬闸改成下列起草必写 / 附件必附 / 禁止出现。宅基地房屋买卖仅本集体内部。

### 起草必写

- 买受人必须是房屋所在地同一农村集体经济组织成员；出卖人须为该宅基地合法使用权人及地上房屋权利人。
- 标的是地上房屋及其占用范围内的宅基地使用权，不是土地所有权；土地仍归农民集体所有。
- 户内共有人（含配偶、成年子女等）须全体签署或出具同意书。
- 集体同意、乡镇审核写成双方义务或生效／付款条件，不写成已经完成；合同成立不等于物权变动。
- 买受后再形成一户多处宅基地的，告知登记障碍与集体收回风险，不改成可履行的一户多宅过户时间表。

### 附件必附

- 权属证书；户口簿或成员名册。
- 家庭成员同意书。
- 村集体书面意见。

### 禁止出现

- 城镇居民、其他集体经济组织成员、公司或非本集体主体购买，并改成可履行过户、网签、贷款或“先签再迁户／等征收转国有再有效”。
- “出卖宅基地所有权”；“签字即取得使用权并可对抗一切第三人”。
- 报批不成改写成“永久使用权租赁”。
- 商品房五证、网签备案、按揭、面积误差、城市二手房过户口径。
- 伪造成员身份或倒签批准。

出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 本任务起草模式；已签履约 → 本套导航履约步骤；已成争 → 合同争议或征收专项。未签且目标是评改已有本集体内部宅基地房屋买卖文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。租赁运营、合作开发、商品房、二手房、集体经营性建设用地、承包地流转负触发。

### 2. 成员身份与共有人

双方成员资格闭合；户内共有人全体签署或同意。非本集体成员停笔告知。

### 3. 标的一体与权利负担

房屋与占用范围内宅基地使用权不可分；证载四至与现状；抵押、查封、争议、规划违建。未核不得写“无权利负担”。

### 4. 程序：集体同意、乡镇审核、登记切开

批准与登记写成双方义务或生效／付款条件，不写成已经完成。签字不代替物权变动。

### 5. 对价、户口、征收预切

价款构成、定金、腾退与证件移交、户口迁出。征收利益只在双方之间切，不保证安置指标或对抗征收机关。

### 6. 格式条款与强制规范

无核验引文则法律结论字段停止。对外转让与阴阳租赁不得改成可履行。

### 7. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把非本集体成员改成可过户、把买卖改成永久租赁或合作开发外壳、伪造成员名册或集体同意。
- `字段停止`：法域、地方窗口细则、成员名册、共有人名单、证载与现状差异、征收范围未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
