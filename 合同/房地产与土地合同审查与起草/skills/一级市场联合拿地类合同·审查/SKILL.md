# 一级市场联合拿地类合同·审查

## 任务目标

在单一立场下，只审查 **土地使用权 / 一级市场联合拿地类合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「一级市场联合拿地类合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证一定竞得或一定办出不动产权证、保证内部按股即可免除对出让人的连带。

## 本类型硬闸

1. **联合体协议 ≠ 出让合同**：本约是合作方之间就竞买资格、保证金、举牌、出资和竞得后权利移交所作的私法安排。建设用地使用权出让合同的出让人只能是市、县人民政府自然资源主管部门（土地使用权合同解释第一条）。民法典第三百四十八条约束的是出让合同书面与必备项，不是本协议。不得把本协议写成已经设立建设用地使用权，不得写“本合同即为出让合同”，不得承诺“保证取得土地使用权”。
2. **出资 ≠ 操盘**：保证金归集、出让金分期、差额补足是出资轴；现场举牌授权、最高限价决策、成交后谁持章、谁任法定代表人、董事会席位和一票否决是操盘轴。两轴必须分条。只写“按股权比例办理”视为未锁定操盘。
3. **联合拿地 ≠ 合作开发**：本类型停在土地使用权**尚未取得**之前的联合竞买，以及成交后的项目公司设立或股权／权益移交。地块已交付或已持证，核心给付变成共同出资建设、按面积分房、共享利润共担风险（土地使用权合同解释第十二条）→ `房地产合作开发类合同·审查`。禁止打开或复制 `房地产合作开发类合同·审查`、`联合勾地协议·审查` 的 method。标题写“合作开发”但正文仍是竞买安排加成交后移交的，按核心给付留本技能，标题冲突写入 `C#`。
4. **邻类切开**：尚未挂牌、只谈产业条件与入市节奏 → `联合勾地协议·审查`／`与非出让人签订的勾地协议·审查`／`用地预申请协议·审查`。相对人是政府、文本是出让合同示范文本 → `国有土地使用权出让合同·审查`。已持证土地使用权直接转让 → `国有土地使用权转让合同·审查`。已持证项目公司股权买卖为主给付 → `以股拿地·审查`。建设工程施工联合体 → `建设工程施工联合体→`。
5. **串通投标／非法倒卖停笔**：联合压价、陪标、约定排挤其他竞买人、为特定主体设置萝卜坑、无开发实力倒卖批文或拿地名额：只出告知，不改写成可履行围标或倒卖结构。依据走民法典第一百五十三、一百五十四条；刑事线索点名刑法第二百二十三、二百二十八条，不在本任务定罪。
6. **失败回溯 + 截胡 + 溢价上限 + 禁售期**：未竞得，后续股权转让、土地转让、项目公司安排必须自动终止并分清沉没成本，不得互锁。竞得后拒绝按约移交或拒绝共同设立项目公司，是截胡红线。必须写最高竞买限价，以及超限是全体放弃还是由指定一方单独承接。出让公告股权锁定期未核，一方竞买＋股权取得字段停止。
7. **对外连带 ≠ 对内按股免责**：联合体或共同申请人对出让人的地价、违约金连带，不能被“内部按出资比例承担责任”一句抹掉。内部追偿、差额补足、共管账户、母公司保证必须单列。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签联合拿地／联合竞买文本，尚未签署，尚未成争，目标宗地使用权尚未出让给任一方，核心给付是联合或一方举牌参与招拍挂并锁定成交后的出资、操盘和权利移交，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 相对人是市、县自然资源主管部门，给付是出让金换建设用地使用权，文本是出让合同或成交确认书 → `国有土地使用权出让合同·审查`；
- 尚未挂牌，正文是产业条件磋商、勾地节奏、与非出让人锁定入市预期 → `联合勾地协议·审查` 或 `与非出让人签订的勾地协议·审查`；与政府预申请、触发招拍挂 → `用地预申请协议·审查`；
- 地块已出让并交付或已持证，核心是共同出资建设、分房、共担开发风险 → `房地产合作开发类合同·审查`；宅基地或集体建设用地合作开发 → `宅基地合作开发合同·审查`／`集体建设用地合作开发合同·审查`；
- 已持证项目公司股权买卖、土地已在目标公司名下 → `以股拿地·审查`；
- 已持证土地使用权直接转让 → `国有土地使用权转让合同·审查`；
- 主给付是建设工程施工联合体投标 → `建设工程施工联合体→`；
- 无文本、本类型条件已谈妥、要出己方稿 → `一级市场联合拿地类合同·起草`；
- 已签只问履约节点（缴地价日、交地日） → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁，或已因出让合同违约被收回土地 → `或对应专项领域。` 或土地／房地产专项。

以联合拿地为名约定围标、陪标、倒卖批文，或把明知无权处分的拿地名额改成可履行买卖：只出告知，不改写成可履行路径。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方是合作伙伴而非政府；全文及附件／联合竞买申请书／授权委托书／章程草案／资金监管协议版本；目标宗地是否已挂牌、是否已有人持证；竞买主体是联合体、存量项目公司还是一方先行举牌；最高限价与超限处理；保证金与出让金谁出、是否共管；操盘、印章、董事会如何分；未竞得是否自动终止后续安排；出让公告有无股权锁定期或产业监管；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)

禁止打开其他类型目录。`基本面.md` 把串通投标写成“绝对无效整约”时，以 method 纠正为准：围标条款停笔删除，不当然宣告全部出资与共管安排无效。`框架.md` 出现“保证取得土地”或把管辖直接写成项目所在地法院唯一解时，不得放行空词。禁止打开 `联合勾地协议·审查`、`房地产合作开发类合同·审查` 的 method。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `一级市场联合拿地类合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议或土地专项。未签且目标是评改已有联合拿地文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。出让合同、勾地、预申请、已持证转让、已持证股权买卖、合作开发本约、施工联合体负触发。

### 2. 联合体协议与出让合同切割

本协议不设立建设用地使用权。成交后另签出让合同。禁止“保证拿地”。

### 3. 出资轴与操盘轴

资金共管、分摊、差额补足与举牌授权、限价、印章、董事会分条。

### 4. 主体、资格、禁售期

产业条件、开发资质、国资／上市决议、出让公告锁定期未闭合则字段停止。

### 5. 竞买安排、溢价、保证金

竞买主体、最高限价、超限处理、保证金性质（不是当然定金）。

### 6. 失败回溯、截胡、税费倒灌

未竞得自动终止后续安排；截胡高额可调违约金；契税／土增税承担不得空置。

### 7. 格式条款与强制规范

无核验引文则法律结论字段停止。围标、倒卖不得改成可履行。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证一定竞得、把本协议写成出让合同并放行、把围标或倒卖批文改成可履行。
- `字段停止`：法域、动态规则、出让公告锁定期、产业资格、国资决议、精确税负未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
