# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受、必然竞得或必然可执行；编造未给出的地价、比例、期限；把已失效《合同法》、1999 年未修正招标投标法单独文本、2005 年土地使用权解释旧条号写入结论；保证内部按股即对政府免责；把本协议写成已设立建设用地使用权；把出让合同、勾地或合作开发本约当成已完成的本类型审查。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查一级市场联合拿地类合同（土地使用权）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、1998 年禁止串通投标暂行规定、2005 年未修正解释旧条号时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `土地使用权`，子级 `一级市场联合拿地类合同`。定性理由、易混切开结果（出让合同 / 联合勾地 / 预申请 / 合作开发 / 已持证转让 / 已持证股权取得 / 施工联合体）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、竞买结构、禁售期与文本版本

主体表：签约名、竞买申请人、保证金付款名、出让金付款名、授权举牌人、保证人。结构表：联合体 / 存量项目公司 / 一方先行举牌；出资比例；操盘权；印章；董事会。禁售期：出让公告或产业监管协议是否限制股权变更。版本表：正文、联合竞买申请书、授权委托书、章程草案、资金监管协议、公告摘录、聊天确认；冲突并列。

## 5. 给付闭环：出资、操盘、限价、回溯

竞买主体是否特定；最高限价与超限处理；保证金归集与性质；出让金节点；失败是否自动终止后续股权／转让安排；截胡后果；对外连带与对内追偿是否分列；税费承担。缺口标 `G#`。不输出“保证取得土地”，不输出开发期分房主路径，不把本协议写成出让合同。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹。围标、陪标、倒卖批文、保证拿地不得写成可放行。强制规范只按第一百五十三条、第一百五十四条区分是否导致民事行为无效，不用失效口诀。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把“另行协商”留在转让价款或持股比例上。

## 9. 谈判与签署提醒

谈判顺序：先红线（实为出让合同或合作开发、围标／倒卖、保证拿地、拒写失败回溯、拒写限价、截胡无后果），再必须改（出资与操盘分条、对外连带与对内追偿、禁售期、税费、共管账户），最后可优化。签署提醒：各方权力机构决议、举牌授权书、联合竞买申请书与正文一致、章程草案和资金监管协议作为附件、日期与公告截止不倒签。不指导伪造竞买资格或补假批准。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书或效力保证，也不是出让合同、勾地或合作开发安排。
