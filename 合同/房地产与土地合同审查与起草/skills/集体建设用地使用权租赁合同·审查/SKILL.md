# 集体建设用地使用权租赁合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构，不证明本约条款已被接受。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、2004 年《土地管理法》第六十三条（禁止集体土地使用权出租用于非农业建设）、1986 年《土地管理法》第四十四条、1991 年或 2014 年已被修改的实施条例旧文本当作本类型默认规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **土地使用权 / 集体建设用地使用权租赁合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「集体建设用地使用权租赁合同·审查」。`depends-on` 为空。不要求先跑导航。

主线是农村集体经济组织作为土地所有权人（或经其书面授权的代签人），将**已经依法登记、规划确定为工业／商业等经营性用途**的集体建设用地，在约定期限内交给承租人使用、收益，承租人支付**租金**。核心给付是债权性租赁，不是设立长期用益物权式出让，也不是土地承包经营权或土地经营权流转。

不交付：他类审查、从零起草、履约交底、争议文书、有效性或必然完成备案／不动产登记保证、集体建设用地出让／出资入股／合作开发整案、国有土地使用权出让整案、农地承包／经营权流转整案、宅基地房屋租赁整案。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **租期硬闸**：租赁期限不得超过二十年；超过二十年的，超过部分无效。期限届满可以续订，但约定的租赁期限自续订之日起仍不得超过二十年。依据：民法典第七百零五条。禁止在签署时一次性锁死四十年、五十年并收齐后段租金；禁止把「二十年＋自动续二十年」写成已经取得四十年租期。土地管理法实施条例（2021 修订）第四十三条「出租参照同类用途国有建设用地执行」**不得**写成「本租赁合同可以约定五十年并当然有效」。要更长、更稳定的权利，转 `集体建设用地使用权出让合同·审查` 评改出让，不在本任务改写成出让。
2. **集体决议硬闸**：集体经营性建设用地出租方案，由农村集体经济组织成员大会决定；成员较多的，成员代表大会可依章程行使该项职权，但须经全体成员代表三分之二以上同意。成员大会须有三分之二以上具有完全民事行为能力的成员参加，作出决定须经全体成员三分之二以上同意，法律法规或章程有更严规定的从其规定。依据：农村集体经济组织法第二十六条第一款第九项、第二十七条、第二十八条。未见书面决议、签到、表决记录或章程：决议与签署能力字段停止。禁止「双方同意视为已开会／已三分之二通过」。村委会或村民小组代签，须有集体经济组织法人授权；口头「书记同意了」不得写成已决议。
3. **与出让／农地流转切开**：支付出让金、锁死四十年以上使用权、约定期满后使用权归承租人或可抵押处分、按出让最高年限写「取得集体建设用地使用权」→ `集体建设用地使用权出让合同·审查`。国有土地、自然资源主管部门作出让人 → `国有土地使用权出让合同·审查`。标的是耕地、林地、草地或家庭承包地，维持农业用途或流转承包经营权／土地经营权 → `标的是耕地林地草地或家庭承包地，维持农业用途或流转承包经营权／土地经营权→`／`保留承包权流转土地经营权→`／`对农用地成立普通债权租赁不设承包经营权或土地经营权→`。宅基地上房屋出租或委托运营 → `宅基地房屋租赁运营·审查`。不得删掉出让金、承包权或宅基地条款后硬套本技能。禁止打开国有建设用地租赁或 `宅基地房屋租赁运营·审查` 的 method「对照一下」。
4. **标的必须是已登记经营性建设用地**：租赁农用地做厂房、民宿、仓储等非农建设，只出告知，不改写成可履行用地结构。规划条件、产业准入和生态环境保护要求未写入合同：实施条例第四十一条明示合同无效，必须补入，不得用「双方已知规划」代替。
5. **书面、备案与登记拆分**：六个月以上应当书面；无法确定期限的视为不定期租赁。依据：民法典第七百零七条、第七百三十条。实施条例第四十一条要求书面合同并报市、县自然资源主管部门备案。未办理租赁备案，不影响合同效力。依据：民法典第七百零六条。禁止「未备案则合同未成立」或「签字即视为已完成不动产登记」。
6. **征收、期满与地上物必须闭环**：实施条例第四十一条要求约定提前收回条件、补偿方式、届满续期和地上建筑物、构筑物等附着物处理。禁止只写「依法处理」。土地补偿、安置补助与地上附着物、停产停业损失如何分配必须落句；常见拆分只是可谈结构，不是已核验法定分配。
7. **语言闸**：统一使用「租金」，禁止「出让金」「出让年限」「国有建设用地使用权」。名为合作开发、实为固定租金或不承担经营风险：按本类型租赁审，不转去代审 `集体建设用地合作开发合同·审查`，也不改写成有效四十年合作外壳。

## 工作边界

正触发：已有可读待签《集体建设用地使用权租赁合同》《集体建设用地租赁协议》或同等出租文本，尚未签署，尚未成争；出租人是农村集体经济组织或其书面授权代签人；标的是集体经营性建设用地使用权在约定期限内的使用、收益；对价是租金。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 出让金、出让年限、用益物权式使用权设立作为主给付 → `集体建设用地使用权出让合同·审查`；
- 国有土地使用权出让、出让人为市县人民政府或自然资源主管部门 → `国有土地使用权出让合同·审查`；
- 集体建设用地使用权出资入股、作价取得股权 → `集体建设用地使用权出资入股合同·审查`；
- 双方共担开发风险、分配房屋或利润的合作开发 → `集体建设用地合作开发合同·审查`；
- 宅基地上房屋出租、委托运营 → `宅基地房屋租赁运营·审查`；
- 宅基地房屋买卖（集体经济组织内部）→ `宅基地内部房屋买卖·审查`；
- 家庭承包地出租、土地承包经营权租赁 → `标的是耕地林地草地或家庭承包地，维持农业用途或流转承包经营权／土地经营权→`；
- 保留承包权、流转土地经营权 → `保留承包权流转土地经营权→`；
- 对农用地成立普通债权租赁、不设承包经营权或土地经营权 → `对农用地成立普通债权租赁不设承包经营权或土地经营权→`；
- 无文本、本类型条件已谈妥、要出己方稿 → `集体建设用地使用权租赁合同·起草`；
- 已签只问交地日、付租日、备案日 → 本套导航的履约步骤；
- 已成争（催告腾退、决议效力之诉、违法占地查处、立案、开庭、仲裁）→ `或对应专项领域。` 或对应专项，不填签前十节。

农用地非农建设、无决议即放行、超过二十年仍写成全部有效、把租赁改成出让外壳、倒签决议：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；代表出租人（集体经济组织）还是承租人；土地是否已登记为集体经营性建设用地；正文、不动产权证、出租方案决议、规划条件、宗地图版本；拟租年限与付租方式；是否出现出让金或农地耕种表述；不可接受事项；法域与拟签时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密时，先停止策略输出。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签决议、把农用地改成可履行非农建设、把超过二十年的租期写成全部有效、把本约改成出让或农地流转外壳、保证有效或必然完成备案登记。
- `字段停止`：未见集体经营性建设用地权属证书或规划用途；未见成员大会／成员代表大会书面决议；村委会代签未见授权；规划条件、产业准入、环保要求未纳入；租期起算日或面积四至不明。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或文本已滑入出让、出资入股、农地流转、宅基地房屋租赁。

生存级地价或个人无限连带且用户拒绝升级：停止「可以签署」建议。
