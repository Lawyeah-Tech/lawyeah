# 审查方法（锁定 土地使用权 / 委托代建合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制 `或`、`或`、`政府代建` 的“任意解除 / 转委托 / 报告 / 委托费用预付”主路径，禁止复制 `房地产合作开发类合同·审查` 的“共同投资 / 分房分利 / 项目公司僵局”主路径，禁止复制 `操盘方自己施工或按造价取费→` 的“工程价款 / 工期质量 / 施工解释一无效”主路径。

定性校验：标题、核心给付与本类型一致才继续；合作开发、施工、委托合同族代建、土地使用权转让或他类明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受或唯一必得金额。

`search_law` 返回已失效《合同法》及其解释、已失效《担保法》、法释〔2005〕5 号未修正条号、1999 年未修正《招标投标法》时记为噪声，不得写入 `L#`。

示范文本只参考结构。深圳、北京、厦门等地政府投资代建示范文本证明那是 `政府代建` 邻类，不得当本类型模板粘贴。房屋委建契约书偏施工，只作负向切开。

知识库纠正（不回写双文件）：

- `基本面.md` “受托方通常要求房地产开发一级资质”：过宽。不得写成无一级资质则代建合同无效。法释〔2020〕17 号第十三条是**合作开发**合同的资质规则，不得套到本类型。代建方资质、品牌和同类项目业绩作为尽调字段停止或必须改，不升格为效力门槛。
- `基本面.md` “垫资代建违反禁止企业间拆借”：过时。企业间借款不当然无效。垫资加固定利息按借款识别；政府投资项目不得由施工单位垫资（保障农民工工资支付条例第二十三条）。
- `框架.md` 把“完成开发投资总额百分之二十五”写成代建合同生效或防转让的合同内条件：纠正。城市房地产管理法（2019 修正）第三十九条约束的是**出让土地使用权转让**，不是代建管理合同自身的生效要件。只有当交易被穿透为转让时，才把第三十九条作为转让路径的停止条件。
- `框架.md` “全权委托应谨慎使用”：采用方向，但民法典第九百二十条允许概括委托。本任务要求把概括委托细化为分权手册，防止第 172 条表见代理，而不是宣布概括委托一律无效。
- 失效《合同法》、法释〔2005〕5 号第二十四条（该号解释 2020 年修正后第二十四条已改为租赁穿透）：噪声。合作开发定义走 2020 修正第十二条。固定利益/固定货币穿透规则仍采用，**条号运行时核 2020 文本后再写 `L#`**。

## 节点 1　类型识别与单目录加载（硬闸：代建 vs 合作开发 vs 施工）

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

支持切开的规范（法律结论须运行时复核）：

- 法释〔2020〕17 号第十二条：合作开发房地产合同以提供出让土地使用权、资金等作为**共同投资，共享利润、共担风险**为基本内容。
- 法释〔2020〕17 号第七条：土地使用权转让合同是土地使用权人把出让土地使用权转让于受让方、受让方支付价款。
- 民法典第七百八十八条：建设工程合同是承包人进行工程建设、发包人支付价款，包括勘察、设计、施工。
- 民法典第九百一十九条：委托合同是受托人处理委托人事务。本类型借用委托外壳，但组织轴是土地使用权权属不转移，不是委托编主路径。
- 民法典第三百五十二条：建设用地使用权人建造的建筑物、构筑物及其附属设施的所有权属于建设用地使用权人，有相反证据除外。

必须切开后再加载，禁止两可时灌入两套知识：

| 双方共同出资，按面积或利润分配，共担亏损或共担销售风险 | 房地产合作开发 | 负触发 `房地产合作开发类合同·审查` |

## 节点 2　土地使用权人、主体与负担

### 2.1 主体表

建表：签约名、履行名、付款名、发票名、授权签字人、不动产权证或出让合同记载的土地使用权人。名称不一致不自动合并。

委托方必须是合法取得土地使用权的权利主体或其设立的项目公司。用户只交营业执照、不交土地证或出让合同：标 `G#`，权利人字段不得写成已核验。口头“地是我们的”不得写成已权属。

国资、集体、上市公司内部决议未附：该签署能力字段停止，不写成“可以盖章”。

### 2.2 土地条件

审查清单，缺一项则该字段不得写成已闭环：

1. 宗地位置、面积、用途、容积率、出让年限。
2. 土地使用权证书或出让合同编号；出让金是否按约定缴清。
3. 红线是否与代建范围一致。
4. 抵押、查封、预告登记、闲置土地查处。

材料未提及负担：只能写 `依据不足`，不得写成“无权利负担”。已抵押：取得抵押权人书面同意前，涉及处分或重大规划变更的字段停止。

划拨地或集体建设用地上做商业代建：审批字段停止；不得写成“先代建后补转出让”。

### 2.3 代建方

记录品牌、管理团队派驻、是否同时具备施工承包意图。不得把“无房地产开发一级资质”写成合同当然无效。品牌撤销条件未写：必须改。

## 节点 3　权属与管理分离（硬闸）

第 352 条：建成物业原则上归建设用地使用权人。本类型的交易对象是**管理服务**，不是土地或房屋所有权。

| 文本写法 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 项目建成后土地使用权或房屋所有权登记至代建方名下 | 红线删除。改成：土地及地上建筑物、附属设施的所有权归委托方 | 代建可以过户 |
| 图纸、报建批文、销售系统归代建方所有 | 必须改：项目文件与批文归委托方；品牌元素按许可期限使用 | 谁做的归谁 |
| 代建范围与出让红线不一致，或“等周边地块一并代建” | 必须改：范围锁到证载宗地和规划指标 | 口头扩大红线 |
| 全过程与阶段性未区分 | 必须改：列报批报建、勘察设计管理、招标采购、施工管理、竣工交付、销售是否纳入 | 标题有全过程就够 |

最强反方：相对方主张“代建方实际操盘，权属挂谁都一样”。修改句必须保留委托方的物权归属和重大事项决定权。

## 节点 4　费用与风险（硬闸）

本节点是本类型与合作开发、借款、转让的分账闸。

### 4.1 正像：管理费结构

基础代建管理费按总投资比例、建筑面积或固定总额计取，与形象进度或销售额节点挂钩。可加：成本节约奖、进度奖、销售溢价奖。数字用 `【待填】`。禁止编造费率。

第九百二十一条：委托人应当预付处理委托事务的费用；受托人垫付的必要费用，委托人应当偿还并支付利息。项目建设资金原则上由委托方筹措并拨付至共管账户，与代建报酬分列。

### 4.2 风险留在委托方

投资风险、市场去化风险、土地出让对价、对外行政责任（环评、安监处罚）第一责任人仍是委托方（建设单位）。代建方在管理范围内对工期延误、质量缺陷、越权签约、挪用资金承担责任（第九百二十九条：有偿委托因过错致损应赔；超越权限应赔）。

| 文本写法 | 动作 |
| --- | --- |
| 代建方承担项目全部经营盈亏，委托方只收固定金额或固定面积 | 现有依据不支持按纯代建放行。按固定利益穿透为土地使用权转让，负触发 `国有土地使用权转让合同·审查`，或整体停止可履行改写 |
| 双方共担亏损、共享剩余利润，激励变成投资回报 | 负触发 `房地产合作开发类合同·审查` |
| 超额激励有封顶，委托方保留定价和停工决定权，代建方不承担亏损 | 可留在本类型；必须改写清激励基数、审计口径、封顶 |
| 工程超支未区分委托方变更与代建方管理不善 | 必须改：因委托方指令或规划变更导致的增加由委托方承担；因代建方未经审批的超支由代建方自行承担 |
| 委托方资金不到位是否停工、如何撤场未写 | 必须改：通知、停工权、团队成本补偿、印章与资料交还 |

### 4.3 垫资

| 文本写法 | 动作 |
| --- | --- |
| 代建方垫付建设资金，按固定利率计息，不参与管理 | 按借款识别，不写成可履行资本代建。政府投资项目：条例第二十三条不得由施工单位垫资，停笔 |
| 代建方阶段性垫资，同时履行管理义务，利息与管理费分列，回款优先还本息 | 本类型可继续，但必须改：注入方式、利率上限字段待核、预售回款优先顺位、不得把垫资写成地价 |
| “保证金”远高于管理费且可抵地价或抵购房款 | 红线：识别是否名为代建实为转让；不改成可履行过户 |

税收：代建费按服务开票。不得指导用畸高代建费规避土地增值税。税法定性字段无核验则停止。

定金：必须使用“定金”二字才讨论罚则。无核验引文不得把百分之二十写成现行法结论。

## 节点 5　授权边界、对外名义与印章

第九百二十条允许特别委托或概括委托。本任务把“全权委托”视为必须改的空词，细化为《权责划分表》。

修改句必须同时写清：

1. **对外名义**：施工、勘察、设计、采购、销售合同以委托方名义签署，或列明哪些可由代建方名义直签及委托方的追认/穿透义务。
2. **审批阈值**：规划变更、超过预算【待填】% 的支出、销售定价、融资、抵押，须委托方书面决定。
3. **印章与证照**：人名章、合同章、报建证照双人共管或按次外借登记；禁止长期外放。
4. **资金账户**：建设资金共管；代建费走单独结算，不得与工程款混拨。
5. **越权后果**：未经审批的承诺对委托方不当然发生内部效力；但第 172 条表见代理仍可能对外有效，故必须压缩表见外观（工牌、授权书、印章）。

代建方直签施工合同：必须改写委托方对底层合同的知情、备案和农民工工资资金安排（条例第二十九条：建设单位未按约拨付工程款导致欠薪的，以未结清工程款为限先行垫付）。不得把“与本约无关”写成可隔离。

## 节点 6　招标、挂靠与施工切开

招标投标法（2017 修正）第三条、必须招标的工程项目规定、质量管理条例第八条：依法必须招标的勘察、设计、施工、监理及重要设备材料采购，不得以代建名义化整为零规避。

施工解释一第一条：承包人无资质或挂靠、必须招标而未招标或中标无效的施工合同，依据第 153 条第一款认定无效；转包、违法分包亦然。这是**底层施工合同**规则，不是本类型主路径。

| 文本写法 | 动作 |
| --- | --- |
| 政府投资或依法必须招标项目，代建单位或施工单位“直接指定、免招” | 红线告知；不写可履行免招结构。代建服务本身是否必须招标：运行时核范围后字段停止或必须改 |
| 代建方同时作为施工总承包 | 负触发 `操盘方自己施工或按造价取费→`，或要求拆成两份文本后本任务只审管理段 |
| 代建方“自行组织施工班组、收取管理费” | 挂靠停笔 |
| 未写代建方对所选施工人欠付工程款、欠薪的责任分配 | 必须改：选人尽责、担保或追偿，不得把风险全甩给土地使用权人却不设约束 |

不得把施工解释一第一条、第七百九十一条当成代建合同效力的普遍公式。

## 节点 7　格式条款、解除与争议

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 7.1 格式条款

为重复使用而预先拟定、订立时未与对方协商。品牌代建方提供的标准文本常构成格式条款。免责、限责、单方调价、最终解释权须有提示说明痕迹。网络勾选或夹在附件不写成已尽提示。

第 506 条：人身损害、故意或重大过失财产损失的免责无效。代建方不得排除越权签约、挪用资金、故意或重大过失管理导致的责任。

### 7.2 解除

第九百三十三条：委托合同双方可随时解除；有偿委托的解除方应赔偿直接损失和合同履行后可以获得的利益。本条**只作配套**，不升格为审查主路径（那是 `或`）。

修改句：委托方可单方解除，但须书面通知、结算已完成管理阶段、补偿已发生团队成本及约定范围内的预期管理费；代建方因委托方停拨资金解除的，同样给通知和撤场清理。禁止只写“双方协商解除”。

不得输出“任意解除权因此无效”或“因此必然赔偿全部预期利润”。

### 7.3 违约与争议

工期、质量、越权、挪用、逾期支付代建费必须分别有可执行后果。只有“依法承担违约责任”视为必须改。违约金不是必得金额。

争议解决：出现仲裁条款，不得改写成“应向某法院起诉”。或裁或诉、机构不明：标待核。专属管辖可能：只标红旗。底层施工争议与本约争议的联动只点名，不在本任务选定唯一法院充作法律意见。

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

打开已加载的 `框架.md`，按六步逐段对照正文。`基本面.md` 用于校验类型、主体、标的、程序和红旗，不代替本节点出句。

| 常见问题 | 权利真空；名为代建实为转让；无共管印章资金；无超支分账 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（类型切错、权属过户、固定回报穿透转让、挂靠/规避招标、坚持本技能改完合作开发或施工）；

- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级金额或个人无限连带且用户拒绝升级：停止“可以签署”建议。
