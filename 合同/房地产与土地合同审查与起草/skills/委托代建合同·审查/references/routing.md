# 边界与路由

本技能只审查 **土地使用权 / 委托代建合同** 的待签文本。中文展示名是「审查委托代建合同（土地使用权）」。

组织轴：土地使用权人保留权属，委托他人做开发管理；对价是代建管理费；投资与市场风险留在委托方。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止抄 `或`、`或`、`政府代建`、`房地产合作开发类合同·审查` 或 `操盘方自己施工或按造价取费→` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 共同出资、共享利润、共担风险；按面积分房或按股比共担亏损 | `房地产合作开发类合同·审查` |
| 核心给付是建筑安装施工、工程价款、工期质量验收；代建方就是施工承包人 | `操盘方自己施工或按造价取费→` |
| 组织轴是委托事务、转委托、任意解除、报告义务，不把宗地权属和出让条件当组织轴 | `或` |
| 品牌输出型商业代建为主轴，不审土地使用权人/出让红线 | `或` |
| 政府投资代建制，委托人/代建人/使用人三方，概算控制为主轴 | `政府代建` |
| 土地使用权过户、转让价款；委托方只收固定利益、代建方取得实质开发权 | `国有土地使用权转让合同·审查` |
| 以收购项目公司股权取得土地 | `以股拿地·审查` |
| 宅基地或集体建设用地上的合作/代建混装 | `宅基地合作开发合同·审查` 或 `集体建设用地合作开发合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

土地使用权项下委托代建正文里夹带一小段品牌许可或目标责任书：专章可继续审。若核心给付变成共担风险分房、施工承包或土地使用权过户，整案转出。用户坚持本技能把合作开发、施工或委托合同族代建整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
