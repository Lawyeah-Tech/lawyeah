# 委托代建合同·审查

## 任务目标

在单一立场下，只审查 **土地使用权 / 委托代建合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「委托代建合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、把代建改写成可履行的土地转让或施工承包。

## 本类型硬闸

1. **代建 ≠ 合作开发 ≠ 施工**：正像是土地使用权人保留土地及建成物业权属，委托他人做报批报建、招标管理、成本与进度、品牌或销售等管理服务。共同出资、共享利润、共担风险 → `房地产合作开发类合同·审查`。核心给付是建筑安装施工、工程价款、工期质量验收 → `操盘方自己施工或按造价取费→`。禁止把施工解释一无效规则或合作开发分配/僵局当本类型主路径。
2. **费用与风险必须分账**：对价是基础代建管理费，可加绩效考核或超额激励，但投资风险、市场风险和土地出让对价仍归委托方（土地使用权人）。代建方承担全部经营盈亏、只让委托方拿固定回报，或对价主要是资金占用费：不得按纯代建放行。
3. **与 `或` / `房地产合作开发类合同·审查` 切开**：组织轴是宗地权属不转移、出让红线、成果物权归建设用地使用权人，不是委托编“任意解除 / 转委托 / 报告”主路径，也不是合作开发“共同投资 / 分房分利 / 项目公司僵局”主路径。标题“委托代建”但正文按共担风险分房，或只谈委托事务不问土地权属：负触发对应原子。禁止抄 `或`、`或`、`政府代建` 或施工 method。
4. **权属与管理分离**：土地及地上建筑物原则上归建设用地使用权人（民法典第 352 条）。图纸、批文、建成房产不得写成归代建方所有。禁止用代建规避城市房地产管理法第三十九条的转让条件。
5. **名为代建实为转让或借款须切开**：代建方支付高额“保证金”并取得实质开发权、委托方只收固定利益 → 按土地使用权转让识别，转 `国有土地使用权转让合同·审查` 或停止可履行改写。垫资且报酬体现为固定利息 → 按借款识别，不写成可履行的“资本代建”。
6. **授权边界**：禁止空的“全权委托”。必须落到分权手册：谁以谁的名义对外签施工/采购合同、哪一级金额须报批、印章与资金如何共管。未细化则表见代理风险（第 172 条）标必须改。
7. **挂靠、违法分包、规避招标或限购只告知**：不得改写成可履行结构。必须招标项目未招选定施工单位，底层施工合同按施工解释一第一条可能无效；不得用代建名义规避施工招标。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签委托代建正文，尚未签署，尚未成争，核心给付是土地使用权人就特定宗地委托管理服务、权属不转移，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 共同出资、共享利润、共担风险，或按面积分房、按股比共担亏损 → `房地产合作开发类合同·审查`；
- 核心给付是建筑安装施工、工程价款结算、工期质量验收，代建方就是施工承包人 → `操盘方自己施工或按造价取费→`；
- 组织轴是委托事务、转委托、任意解除、报告义务，不把宗地权属和出让条件当组织轴 → `或`；
- 品牌输出型商业代建、政府投资代建制（使用人/代建人/委托人三方）为主轴 → `或` 或 `政府代建`；
- 土地使用权过户、转让价款、完成开发投资总额百分之二十五作为交易条件 → `国有土地使用权转让合同·审查`；
- 以股权取得项目公司从而拿地 → `以股拿地·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `委托代建合同·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁 → `或对应专项领域。` 或对应专项。

挂靠、违法分包、伪造内部承包、规避限购或必须招标：只出告知，不改写成可履行路径。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及附件/权责划分表/土地证或出让合同版本；委托方是否土地使用权人、出让金是否缴清、红线与规划指标；代建范围是全过程还是阶段性；对价是管理费还是利润分成/固定回报/利息；对外签约以谁的名义；印章与资金是否共管；是否垫资；是否政府投资或必须招标；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `委托代建合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有土地使用权项下委托代建文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。合作开发、施工、委托合同族代建、土地使用权转让负触发。

### 2. 土地使用权人与授权

委托方须是证载权利人或其项目公司。出让金、抵押/查封、内部决议未闭合：字段停止。

### 3. 权属与管理分离

成果物权归委托方。红线与出让合同一致。禁止权属过户句。

### 4. 费用与风险

管理费 + 节点；投资与市场风险留委托方。固定回报、固定利息、共担亏损分别切开。

### 5. 授权边界与对外名义

分权手册、印章共管、以谁的名义签底层合同。空的“全权委托”必须改。

### 6. 垫资、招标、挂靠

垫资与借款切开。必须招标未招、挂靠、违法分包停笔。

### 7. 格式条款与强制规范

无核验引文则法律结论字段停止。第 933 条任意解除只作配套补偿句，不升格为主路径。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把代建改成可履行的土地转让或规避招标/挂靠结构、坚持代建方取得土地或房屋所有权。
- `字段停止`：法域、动态招标范围、出让金与土地证、抵押同意、必须招标认定、税收定性未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
