# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证合同有效、已经共担风险、已经完成划拨转出让或对方接受；编造未给出的面积、出资额、分成比例、证号、期限；把已失效《合同法》及其解释、1990 年联营解答写入结论；把“双方均须具备房地产开发资质”写成现行门槛；把划拨地联建或集体地联建写成当然无效或已经有效；把固定回报化妆成可履行联建；把双方出钱或不共担风险型联建、合作开发主类型、代建、施工留在本技能改完。

## 1. 触发、单方立场与成果状态

立场（出地方、出资方、拟设项目公司、抵押权人、保证人）、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明是否同时满足：一方只出地、一方出建设资金、双方共担经营风险并共享开发利益。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、1990 年《关于审理联营合同纠纷案件若干问题的解答》、2005 年解释被删除的原第十六条、2004 年土地管理法第六十三条旧文时记噪声，不得写入 `L#`。共担风险三要件、名实穿透、资质、划拨/集体地程序无 `verified-result` 时，对应法律结论字段停止。

## 3. 类型与加载路径

父级 `房地产合同`，子级 `“一方出地，一方出钱” 型联建合同`。定性理由必须同时满足：出地方以出让建设用地使用权作为主要投入，出资方承担全部或约定范围内的建设资金，双方共享开发利益并共担亏损、超支、滞销或闲置风险。

易混切开：`一方出地双方出钱联建·审查` 双方出钱、`不共担风险型联建合同·审查` 不共担风险型、`“双方出地”型联建合同·审查` 双方出地、`共担风险型联建合同·审查` 共担风险型（未锁本投入结构）、`一方操盘型联建合同·审查`/`联合操盘型联建合同·审查` 操盘型、`联建模式联建合同·审查` 双名义联建模式、`隐名参建联建·审查` 隐名参建、`房地产合作开发类合同·审查` 合作开发主类型、代建、施工、名实借贷、土地使用权转让。

加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读其他类型、未打开 `房地产合作开发类合同·审查` 或联建族其他原子 method。挂靠、违法分包、规避限购、伪造村民决议或假批准写停笔告知，不填可履行结构。

## 4. 主体、授权、资质与文本版本

主体表：出地方、出资方、报建/销售名义人、拟设或已设项目公司、土地使用权人、抵押权人、保证人。名称不一致不自动合并。

版本表：联建正文、分房协议或附图、资金监管协议、成本估算、土地红线图、权属证书、内部决议或村民决议、抵押权人同意、聊天确认。冲突并列，不选对用户有利的一版。口头“村里都点头了”“土地没负担”不得写成已决议或无负担。

## 5. 出地、出钱与共担风险给付闭环

分列并回链文本位置：

- 土地：宗地号、坐落、面积、用途、出让/划拨、剩余年限、抵押查封、开竣工期限。
- 出钱范围：建安、补缴出让金、规费、税费、报建费是否列入出资方义务；出地方是否另掏建设资金。
- 共担风险：亏损、超支、滞销、闲置处罚如何分担；有无固定必付货币或固定套数且不担亏损。
- 分配：房屋分成或利润分成；楼栋/楼层/朝向/装修标准；公建配套和车位；面积差异结算。
- 管理：联管会席位、图纸和销售定价审批、出地方监督权；报建名义。
- 资金：共管或监管账户、专地专用、形象进度拨付。
- 程序：划拨转出让、合作备案、四证、预售、分阶段确权。
- 融资限制：未经书面同意不得抵押土地或在建工程。

缺口标 `G#`，不补商业数字、证号或已批准事实。批准、登记、备案写成条件或双方义务期限，不写成已经完成。

## 6. 格式条款、强制规范与本类型效力红旗

职业文本或一方预先拟定且未协商的，按格式条款审查提示说明。

强制规范与效力红旗只在核验后落法律结论：双方均无房地产开发经营资质且未约定补齐路径；划拨地未报批即按已可开发履行；农用地或宅基地直接联建商品房；固定回报化妆共担；预售款充抵投资参与利润分配；未取得规划许可却先分房。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

不得把“集体地联建一律无效”“划拨地联建一律无效”“保底条款因房地产管理法当然无效并收缴利息”写成已核验结论。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔/转出口径。禁止输出无修改句的色块表。

本类型至少检查：出地/出钱角色错位或双方出钱；只有共担口号没有亏损分担；出地方或出资方固定必付；名联建实借贷未切开；出地方不参与任何经营只拿固定房屋；分房未特定化或漏不可售面积；划拨/集体地程序未闭合；双方均无资质；资金未共管；动工期限未锁；未经同意可抵押；两次确权税费未分摊。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字、证号用 `【待填】`，不编造。禁止只给原则、不给句子。框架与硬闸冲突时按硬闸出句。

建议句必须覆盖本类型硬闸：共同投资、共担风险、共享利益写入鉴于并落到亏损分担；删除或改写固定必付；出地/出钱角色不得改成双方出钱；与不共担风险型切开的负触发不得在本技能改完。

## 9. 谈判与签署提醒

谈判顺序：先红线（固定必付假共担、双方均无资质且不补路径、挂靠或规避限购、伪造决议/批准、倒签），再必须改（三要件落句、土地程序、出钱范围、分房特定化、共管账户、动工期限、监督权），最后可优化。

签署提醒：出地方与出资方本人签或有权代表签；权属证书原件核对；抵押权人书面同意、内部决议或村民决议作附件；分房附图、成本估算、资金监管协议与正文同时签署；日期真实。不指导倒签、补假批准或假村民决议。

出地方立场必须提示：签字后土地可能被抵押或闲置收回，对外常仍是报建主体。出资方立场必须提示：共担亏损不是“出完钱就拿固定房子”；未取得规划许可不得请求分配项目利益。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书、税额精算终局或效力保证。
