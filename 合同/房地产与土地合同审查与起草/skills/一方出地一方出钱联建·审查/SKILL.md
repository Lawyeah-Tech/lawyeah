# 一方出地一方出钱联建·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、1990 年《关于审理联营合同纠纷案件若干问题的解答》、2005 年土地使用权解释被删除的原第十六条、2004 年《土地管理法》第六十三条旧文当作现行规则。不得把“双方均须具备房地产开发资质”或“划拨地/集体地联建一律无效”写成现行结论。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **房地产合同 / “一方出地，一方出钱” 型联建合同** 的待签文本：一方以建设用地使用权作为主要投入，另一方承担建设资金，双方共同投资、共享利润、共担风险。输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「一方出地一方出钱联建·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查、从零起草、履约交底、争议文书、合同有效性保证、双方出钱联建整案、不共担风险型联建整案、其他七种联建子型整案、合作开发主类型整案、代建或施工整案、税额或分成终局数字。

## 工作边界

正触发：已有可读待签文本要评改，；尚未签署，尚未成争；**必须同时满足**：

1. 出地方以宗地使用权作为主要投入，自身不再按比例掏建设资金。
2. 出资方承担全部或约定范围内的建设资金（含用户已列入的补缴出让金、规费、税费、报建费）。
3. 双方共享开发利益，并共担亏损、超支、滞销或闲置等经营风险。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 出地方除出地外还按比例出建设资金 → `一方出地双方出钱联建·审查`；
- 用户锁定不共担风险型，或确认交易就是保底、固定必付、不要改成共担 → `不共担风险型联建合同·审查`；
- 双方出地 → `“双方出地”型联建合同·审查`；用户锁定共担风险型但投入结构不是本类型 → `共担风险型联建合同·审查`；
- 审查重点是一方操盘或联合操盘 → `一方操盘型联建合同·审查` / `联合操盘型联建合同·审查`；
- 用户锁定双名义联建模式或隐名参建 → `联建模式联建合同·审查` / `隐名参建联建·审查`；
- 用户未指定联建子型，核心是项目公司股权与分红 → `房地产合作开发类合同·审查`；
- 代建管理费主导、不分担亏损 → `委托代建合同·审查` 或 `或` 至 `至`；
- 按图施工、工程价款主导，施工方无项目权益 → `操盘方自己施工或按造价取费→`；
- 联建外壳被抽空，只剩固定本息 → `资金方只收固定货币→第二十三条转` / `或`；
- 出地方不担风险、交易目的是过户土地 → `国有土地使用权转让合同·审查`；
- 整案集体经营性建设用地或宅基地合作 → `集体建设用地合作开发合同·审查` / `宅基地合作开发合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `一方出地一方出钱联建·起草`；
- 已签只问出资、报建、分房、监管划扣 → 本套导航的履约步骤；
- 已成争（催告、解除、索赔、立案仲裁）→ 合同争议或对应专项领域。

挂靠、违法分包、规避限购、伪造村民决议或假批准：只出告知，不改写成可履行结构。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成。每一闸必须给出修改句或明确转出口径，禁止只打红黄绿。

1. **共担风险必须落地**。标题写“联建”“合作开发”不决定类型。必须在鉴于和风险条款同时写清：共同投资、共享利益、共担亏损/超支/滞销/闲置。只有口号、亏损全部由一方承担，视为未共担。不得把本约改成可履行的保底结构。
2. **名联建实借贷必须切开**。出资方不承担经营风险、无论盈亏均收取固定货币、固定利息或固定年化的，按《最高人民法院关于审理涉及国有土地使用权合同纠纷案件适用法律问题的解释（2020修正）》第二十三条方向识别为借款。出地方不承担经营风险、只收取固定利益的，按同解释第二十一条方向识别为土地使用权转让。用户要保留联建定性：删除固定必付，补真实亏损分担和监督权。用户确认就是保底：负触发 `不共担风险型联建合同·审查` 或 `资金方只收固定货币→第二十三条转`。禁止加一句“共担风险”给固定回报化妆。
3. **与双方出钱、不共担风险切开**。出地方另掏建设资金、双方按比例出钱 → 负触发 `一方出地双方出钱联建·审查`。交易设计就是不共担风险 → 负触发 `不共担风险型联建合同·审查`。禁止打开或复制 `房地产合作开发类合同·审查` 或联建族其他原子 method。禁止把九种联建写成同一套判断。

附加必落句（有事实则单列，无事实在缺口节说明）：

- **出钱范围**：建设资金是否包含补缴出让金、规费、税费、报建费；缺项用 `【待填】`，不编造。
- **分房特定化**：房屋分成必须落到楼栋/楼层/朝向/装修标准（毛坯或精装）和不可售面积；禁止只写“按 6:4 分房”。
- **出地方监督权**：出地方不参与任何经营、只拿固定房屋的，按明联实转处理；修改句补进度与质量审批权，或转转让/买卖审查。
- **资金监管**：建设资金进共管或监管账户，按形象进度拨付，禁止出资方抽调。
- **动工期限**：锁定出让合同或约定动工日，防止闲置一年收费、两年收回。
- **划拨/集体地**：报批、补缴出让金或入市程序写成生效或履行条件，不写成已经完成，也不按已删除旧条宣告当然无效。

必须有修改句。每个风险回链文本位置。禁止套用 `房地产合作开发类合同·审查` 的项目公司股权、联合竞买或德州枪手主路径。禁止复制其他八种联建 method。

## 建立审查坐标

确认：使用者与授权；单方立场（出地方、出资方、拟签字的项目公司、抵押权人）；相对方；全文及分房/监管/决议附件版本；宗地与权属；出钱范围；分成方式；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的面积、出资额、比例、证号、期限用 `【待填】`，不编造。

宿主可调用时：

- `search_law`（法律结论 required）：核验合作开发定义与共担风险、资质、名实穿透、划拨转让报批、集体经营性建设用地入市、闲置土地、强制规范是否导致无效、格式条款提示说明。

- `search_template`（optional）：只借栏目结构。写“乙方分得固定回报”“无论盈亏支付”的联建范本不得当本约规则。

不虚构案件系统。`search_law` 返回已失效《合同法》及其解释、1990 年联营解答、2005 年解释原第十六条、民法通则/民法总则已被替代条文时记为噪声，不得写入 `L#`。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口，不代替节点。

0. 签署状态与成果分流
1. 类型识别与单目录加载（一方出地 + 一方出钱 + 共担风险；切开双方出钱/不共担风险/其他联建/合作开发/代建/施工/借贷）
2. 主体、土地、资质、抵押权人与集体决议
3. 共担风险落地（硬闸）
4. 名联建实借贷与第二十一条至第二十四条穿透（硬闸）
5. 出地/出钱结构、分房特定化、资金监管
6. 报建名义、联管会、划拨/集体地、动工防闲置
7. 违约、解除、格式条款与强制规范
8. 按框架六步出修改句

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、补假批准或假村民决议、把固定回报化妆成共担、把禁止开发土地改成可联建商品房、保证合同必然有效。
- `字段停止`：法域、资质、土地性质与负担、共担条款、名实穿透、划拨/集体地程序未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或用户要把本约改成双方出钱或不共担风险以便绕开本类型硬闸。

出地方唯一土地被设定“无论盈亏必须支付固定回报”且用户拒绝删除：停止“可以签署”建议。
