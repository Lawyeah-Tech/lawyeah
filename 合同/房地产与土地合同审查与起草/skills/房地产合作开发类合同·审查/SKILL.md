# 房地产合作开发类合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、已失效《担保法》及其解释、1990 年《关于审理联营合同纠纷案件若干问题的解答》、2004 年《土地管理法》第六十三条旧文当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **土地使用权 / 房地产合作开发类合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「房地产合作开发类合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、把固定回报改成可履行“假共担”、把联建族或代建整案改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **共担风险、共享收益**：解释（2020 修正）第十二条要求以提供出让土地使用权、资金等作为**共同投资，共享利润、共担风险**。三要件缺一，不得写成已构成合作开发。土地方或资金方不承担经营风险、只拿固定利益 / 固定房屋 / 固定货币 / 固定使用权 → 按第二十一条至第二十四条穿透，不按本类型放行。
2. **名合作实借贷**：资金方不承担经营风险、只收取固定数额货币或固定本息 → 第二十三条认定为借款合同。负触发 `资金方只收固定货币→第二十三条转`（企业间借款主轴则回引擎按借款类定性）。禁止用“保底分红 + 超额分成，但法律形式上写风险共担”把借贷化妆成合作开发。用户坚持无论盈亏都必须付固定回报仍按本类型放行：整体停止。
3. **与联建族、代建切开**：标题或用户锁定联建子型（一方出地一方出钱、双方出地、操盘型、不共担风险型、共担风险型、联建模式、参建隐名）→ 负触发 `一方出地一方出钱联建·审查` 至 `隐名参建联建·审查` 对应原子。委托人保留土地与项目、受托人只收代建费或管理费、不分享利润也不承担亏损 → 负触发 `委托代建合同·审查` 或 `或` 至 `至`。禁止打开联建或代建 method 对照改写。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签合作开发正文，尚未签署，尚未成争，核心给付是各方以出让土地使用权、资金等共同投资开发房地产并共享利润、共担风险，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 标题或用户指定联建族某一子型 → `一方出地一方出钱联建·审查` 至 `隐名参建联建·审查` 对应原子（P1；未装则 `unavailable`）；
- 委托代建、商业代建、政府代建、资本代建、股权代建、商业代建加贷款配资 → `委托代建合同·审查` 或 `或` 至 `至`；
- 资金方不担风险、只收固定本息或固定货币 → `资金方只收固定货币→第二十三条转`；
- 土地方不担风险、只收固定地价或固定面积 → `国有土地使用权转让合同·审查`；
- 资金方不担风险、只拿固定套数或固定面积房屋 → 回引擎按房屋买卖定性；
- 资金方不担风险、只以租赁等方式使用房屋 → 回引擎按租赁定性；
- 仅联合竞买、尚未进入共同开发经营 → `一级市场联合拿地类合同·审查`；
- 以收购股权拿地为主给付、不共同开发经营 → `以股拿地·审查`；
- 整案是集体建设用地合作开发 → `集体建设用地合作开发合同·审查`；宅基地合作开发 → `宅基地合作开发合同·审查`；
- 共同研发技术、专利申请权安排，不以地和开发资金为共同投资 → `共同研发技术专利申请权安排，不以地和开发资金为共同投资→`；
- 无文本、本类型条件已谈妥、要出己方稿 → `房地产合作开发类合同·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

挂靠、违法分包、规避限购或限售、以合作套取信贷资金转贷：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（土地方 / 资金方 / 拟设项目公司股东择一）；相对方；全文及土地权属、出资计划、治理权限、分配方案版本；各方是否共同投资并承担经营亏损；有无固定回报或固定分房且不担风险；是新设项目公司还是不成立公司的联合建设；土地是出让、划拨还是集体建设用地；报建与销售主体是否具备房地产开发资质；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `房地产合作开发类合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有合作开发文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。联建子型、代建、固定回报借贷、纯转让、纯买卖、纯租赁、集体地/宅基地整案、技术合作开发负触发。

### 2. 主体、土地与资质

签约名、履行名、土地权利人、项目公司名、销售主体名分列。权属、抵押查封、划拨/集体审批、至少一方或项目公司资质未闭合则字段停止。

### 3. 共担风险、共享收益

共同投资、共享利润、共担亏损三件都要落到可执行句。缺亏损分担或经营参与，不得写成已构成合作开发。

### 4. 名合作实借贷与第 21–24 条穿透

固定本息、固定货币、固定房屋、固定利益、固定使用权且不担风险：按条转出，禁止化妆。

### 5. 出资路径、项目公司与分配清算

注册资本、股东借款、超支追加、分房/分红、土增税保证金、资金共管。优先回报仅在可分配利润范围内才可留，不得写成无论盈亏必付。

### 6. 程序、四证与生效

拿地审批—成立公司—资金注入—建设销售—清算分配。批准、登记、预售许可写成条件或期限，不写成已经完成。

### 7. 格式条款、免责与强制规范

限额可留，人身损害与故意/重大过失不得排除。无核验引文则法律结论字段停止。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把固定回报化妆成共担、把联建或代建整案按本类型改完、把挂靠或规避限购改成可履行结构。
- `字段停止`：法域、划拨/集体审批、预售许可、土增税清算口径、地方限购限售未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
