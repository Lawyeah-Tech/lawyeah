# 边界与路由

本技能只审查 **土地使用权 / 房地产合作开发类合同** 的待签文本。中文展示名是「审查房地产合作开发类合同（土地使用权）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。专业版未收录本 P1 原子：输出 `unavailable`，提示，不得用联建或代建邻类硬套。
