# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的出资额、面积、地价、分成；把已失效《合同法》、1990 年联营解答、2004 年土地管理法第六十三条旧文写入结论；把固定回报化妆成共担；把联建族或代建文本当成已完成的本类型审查。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查房地产合作开发类合同（土地使用权）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、1990 年联营解答、2004 年土地管理法第六十三条旧文时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `土地使用权`，子级 `房地产合作开发类合同`。定性理由、易混切开结果（联建族 / 代建 / 名合作实借贷 / 转让 / 买卖 / 租赁 / 联合拿地 / 集体地或宅基地合作 / 技术合作开发）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型、未打开联建或代建 method。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、土地、资质与文本版本

主体表：签约名、履行名、土地权利人、项目公司名、销售/报建主体、付款名、发票名、授权签字人。土地表：宗地号、用途、容积率、出让/划拨/集体、抵押查封、闲置与欠缴出让金。资质表：哪一方或项目公司持有房地产开发经营资质。版本表：正文、出资计划、治理权限清单、进度计划、聊天确认；冲突并列。

## 5. 共担风险、名实穿透与分配清算

共同投资形式是否落到可核验清单；利润如何分享；亏损如何分担；有无固定回报、固定分房、固定占地费；优先回报是否以可分配利润为限；分房模式下的税费与土增税保证金；资金共管。缺口标 `G#`。命中解释第二十一条至第二十四条的，写清转出原子，不在本节写成已审完的合作开发。

## 6. 程序、格式条款与强制规范

内部决议、划拨转出让或集体地入市书面意见、四证与预售许可、联合竞买备案。是否构成格式条款；提示说明痕迹。限额与除外（人身损害、故意或重大过失不得排除）。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把框架里的“德州枪手 / 左轮手枪”写成中国法上的法定退出权，不得把“保底分红”改成可履行假共担。

## 9. 谈判与签署提醒

谈判顺序：先红线（固定回报假共担、联建/代建整案误入、无亏损分担、挂靠或规避限购、倒签），再必须改（三要件落句、资质与土地程序、出资与超支、分配与税务保证金、资金共管、僵局退出），最后可优化。签署提醒：授权、用印、日期、出资计划/权限清单/进度表作为附件、审批是否作为生效条件。不指导倒签或补假批准。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书或效力保证，也不是联建族、代建或借款安排。
