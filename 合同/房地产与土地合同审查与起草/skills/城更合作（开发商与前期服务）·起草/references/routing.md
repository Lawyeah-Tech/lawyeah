# 边界与路由

本技能只审查 **房地产合同 / 城市更新项目合作合同（开发商与前期服务公司）** 的待签文本。中文展示名是「审查城市更新项目合作合同（开发商与前期服务公司）（房地产合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或复制 `城市更新项目前期服务合同·审查`、`城更股权合作·审查` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 当事人是村集体／更新主体与前期服务公司；或只做意愿征集、测绘、入库、方案编制，无“本开发商正式签约成为合作企业”成功标准与排他支持 | `城市更新项目前期服务合同·审查` |
| 主结构是项目公司／SPV、股权出资、持股比例、对赌摊薄、股东一票否决、股权回购或收购前期服务公司股权 | `城更股权合作·审查` |
| 仅意向、无成功费与排他闭环，双方还要再签本约 | `城市更新项目意向合作协议·审查` |
| 当事人是村集体与合作企业，分配物业、土地权益或选定实施主体 | `城更合作（村集体与企业）·审查` |
| 共同出资、共享利润、共担建设经营风险 | `房地产合作开发类合同·审查` |
| 宅基地合作开发外观 | `宅基地合作开发合同·审查` |
| 集体建设用地合作开发外观 | `集体建设用地合作开发合同·审查` |
| 主文件只是资金监管／共管协议 | `资金监管协议·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或对应专项领域。` 或对应专项领域 |
| 已涉行贿、串通招标或职务犯罪立案 | 刑事／监察或争议专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

本约夹带一小段资金监管或廉洁协议：专章可审其对放行的影响；若用户要把股权合作、前期服务或村集体本约整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
