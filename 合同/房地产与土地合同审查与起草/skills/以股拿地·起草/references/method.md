# 审查方法（锁定 土地使用权 / 以土地获取为目的的股权取得类合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止套用买卖验收、定金比例或挂靠改写节点。禁止把本技能写成普通股权转让换标题，禁止只审股权比例、优先购买权和工商变更而不审地块。禁止把本技能写成直接土地使用权转让换标题，禁止灌入不动产变更登记、土地二级市场网签或契税过户主路径。禁止把本技能写成房地产项目股权换标题，禁止灌入五证、预售资金监管、施工总包或已售未交付主路径。

定性校验：目标公司绑定特定宗地，核心给付是通过股权间接拿地，文本不以土地过户或在建预售为履行主轴，才继续；明显他类则负触发，不填十节实体结论。

本文件是可执行判断节点，不是栏目说明书。每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、必然能开发、对方必然接受，或唯一必得金额。

`search_law` 返回已失效《合同法》及其解释、1994 年《城市房地产管理法》旧编号（当时第 38 条为 25% 条件）、1999 年《闲置土地处置办法》、已被修改的公司法、物权法/担保法充作现行担保规范时记为噪声，不得写入 `L#`。`search_practiced` 仍写“走股权即可合法规避 25%”“全额转让股权即视为土地转让当然无效”“签字即应过户土地”的，同样记噪声。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

示范文本只参考结构。写“自双方签字盖章之日起生效”或普通股权转让栏目的范本，不得覆盖本类型地块绑定、投资开发条件审查和锁定期。

知识库口径冲突以本方法为准，不回写知识正文：

- `基本面.md` 把“规避投资额 25%”写成股权路径的优势：纠正为**必须审查是否被规避**。可以记录当事人选择股权形式的商业动机，不得写成合法绕过工具，不得帮助设计规避条款。
- `基本面.md` 写民事效力“普遍认可”：纠正为不得输出必然有效。第 39 条约束的是房地产转让，不当然导致股权合同无效；出让合同或招商协议锁股、闲置未处置、国资未进场、恶意规避强制规范或偷逃税款，仍构成目的落空、履行不能或效力争点。
- `框架.md` 默认签字盖章即生效：有锁股、国资进场、划拨报批或“成功竞得”前提时，必须拆成立与生效。
- 境外间接转让、7 号公告本窗未取得现行核验引文：用户材料出现离岸持股平台时标 `G#`，运行时核验，不得把记忆中的公告号写成已核验。
- 不得把 1999 年闲置土地办法第 2 条定义写成现行条文。现行有效文本为 2012 年修订；精确定义以运行时 `search_law` 对 2012 文本第 2 条为准。已核验可用：第 9 条（符合第 2 条则下达认定书）、第 24 条（处置完毕前不得办理转让、出租、抵押和变更登记）。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用核心给付、对价付给谁、地块是否仍登记在目标公司名下、有无在建预售主价值、用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须同时满足才正触发：

1. 存在或将存在持有特定宗地的目标公司。
2. 受让人通过对价取得该公司股权或控股权，土地仍登记在目标公司名下，不办理土地使用权人变更。
3. 商业目的是控制、开发该地块；鉴于、定义或陈述中能回链“拿地/地块/宗地/出让合同”。
4. 文本不以不动产变更登记为履行轴，也不以在建工程、预售、五证开发为主要价值。

必须切开，禁止两可时灌入两套知识：

| 信号 | 归入 | 本技能动作 |
| --- | --- | --- |
| 买项目公司股权 + 地块是核心资产 + 目的拿地 + 无实质在建预售主价值 | 本类型 | 加载本目录双文件 |
| 用户明确以本类型提交，证号未闭合，但已排除直接过户与项目股权 | 本类型 | 进入后地块字段停止 |
| 转让人是土地使用权人；对价是地价款；办土地或不动产变更登记 | `国有土地使用权转让合同·审查` | 负触发；不审股权交割 |
| 已有实质在建、施工总包、预售或网签、预售监管、五证开发主路径 | `或` | 负触发；不审预售和工程款主路径 |
| 无地块绑定、无拿地目的，只转让经营性公司股权 | `或` 或 `或` | 负触发 |
| 土地尚未出让，联合竞买、配资拿地主路径 | `一级市场联合拿地类合同·审查` | 负触发；仅“竞得后继续履行”可留审该条件 |
| 共同出资报建、共担风险，不转移控股权 | `房地产合作开发类合同·审查` | 负触发 |
| 固定回报、到期强制回购、不承担开发风险 | 名股实债外观 | 可留本技能点名，不改成可履行借贷或保底 |
| 移转标的物所有权换价款 | 买卖类场景原子 | 负触发 |

两可规则：目标公司除一块未开发或仅完成前期的土地外无其他实质资产 → 留本技能。已进入施工、预售或销售回款，土地只是项目底盘 → 转 `或`。同时出现土地过户条款和股权变更条款 → 负触发回引擎重新定性，不得两套方法一起写。

### 1.2 加载协议（硬闸）

本技能已锁定 **土地使用权 / 以土地获取为目的的股权取得类合同**。只打开 `references/基本面.md` 与 `框架.md`。禁止读其他类型目录，禁止为对照再开 `国有土地使用权转让合同·审查` 或 `或` 双文件。

### 1.3 违法结构停笔

加载后或定性中出现：指导伪造土地证、投资进度或闲置处置完毕文件；把未达投资开发条件或锁定期内变更股权改成可履行规避结构；设计隐名代持拿地；把固定回报回购改成可履行；倒签交割日或政府同意函。

动作：

1. 交付告知：该结构涉嫌规避土地管理强制规范或伪造，不得改写成可履行文本。
2. 不写假投资进度、假“视同已达 25%”、假政府同意变更股权。

## 节点 2　主体、优先购买权、国资与目标公司

1. 建主体表：转让人（项目公司股东）、受让人、目标公司、共管或收款账户名。名称不一致不自动合并。
2. **目标公司反向闸。** 材料显示土地登记在转让人名下、目标公司不持有该地：回到节点 1 负触发 `国有土地使用权转让合同·审查`。未出示目标公司持地外观不得写成“已经持有净地”，只说明“目前未见持地外观”并字段停止。
3. **股权负担与实缴。** 摘录质押、冻结、未实缴。公司法第 88 条：未届出资期限的股权转让后由受让人缴纳，转让人补充责任；瑕疵出资转让人与受让人在不足范围内连带，善意受让人除外。未写实缴或未安排承继：必须改。不得写成已经实缴。
4. **优先购买权。** 有限公司向股东以外的人转让：书面通知数量、价格、支付方式和期限；三十日内未答复视为放弃。章程另有规定从其规定。口头“其他股东没意见”不得写成已放弃。修改句要求放弃声明作为附件，或把通知期满无异议列为交割先决。
5. **国资。** 转让方或标的呈现国有：修改句把评估、进场交易或依法可协议转让的批准列为生效条件。企业国有资产法第 54 条：除可直接协议转让外应当在产权交易场所公开进行。第 72 条：恶意串通损害国有资产权益的交易无效。未出示评估进场：字段停止，不得写成已经完成。用户要求绕开进场：整体停止。
6. **目标公司鉴证。** 本类型目标公司通常应作为鉴证方或履约保障方盖章，以便交接印章、证照和配合变更登记。未列目标公司：必须改。
7. **自然人股东与内部决议。** 配偶同意、股东会或董事会决议未附：字段停止，修改句要求作为附件；不得写成“公章即充分授权”。婚姻家庭编解释（二）第 9 条：一方转让登记在自己名下的用夫妻共同财产出资的股权，他方不得仅以未经同意主张合同无效，恶意串通除外。因此配偶同意是风险控制，不是未经核验就写成效力要件。
8. **外资。** 名称或陈述显示外资并购境内房地产企业：标 `G#`，修改句把依法需办理的准入、安全审查或登记列为条件；不得写成已经备案。

不足：字段停止，列出待补材料，不补主体、不补“已放弃优先购买”“已进场”。

## 节点 3　名股实地：股权与地块双锁定（硬闸）

本节点落实“披着股权外衣的土地买卖”。缺地块绑定则不得宣称本类型审查完成。

核验后可引用的判断点（须 `search_law` 写入 `L#` 再落法律结论）：

- 依法成立的合同自成立时生效，法律另有规定或当事人另有约定除外；报批义务条款可独立有效。
- 股权转让后受让人自记载于股东名册时起可向公司主张股东权利；变更登记是对抗/公示，不是土地物权变动。
- 不得把本约履行写成土地使用权变更登记。

必须同时锁死两类标的：

| 栏目 | 最低应写清 | 缺则动作 |
| --- | --- | --- |
| 股权 | 比例、对应出资额、实缴、有无质押冻结 | `G#`；修改句用 `【待填】` |
| 地块 | 证号或不动产单元号、坐落四至、用途、面积、容积率、出让/划拨、出让金是否缴清、开竣工期限 | `G#`；无任何地块描述则质疑定性或字段停止 |
| 目的 | 鉴于写明通过取得股权控制并开发该地块 | 必须改。补鉴于，删除“与土地无关的普通股权投资”表述 |
| 处分限制 | 交割前目标公司不得新设抵押、出租、改变规划、弃地或签署处置土地的协议 | 必须改 |
| 风险转移 | 股权变更登记完成日与现场管理权交付日分列 | 必须改；不得写成土地过户日 |

| 文本写法 | 本任务动作 |
| --- | --- |
| 只写“转让目标公司 100% 股权”，地块以“相关资产”带过 | 必须改。把地块要素写入定义或附件，并与股权绑定 |
| 约定“交割后办理土地使用权人变更至受让人名下” | 红线或负触发。这是直接土地转让外观，转 `国有土地使用权转让合同·审查` 或删除过户义务，改为土地仍登记在目标公司 |
| 把土地评估价直接写成股权转让价款且声明“不含负债” | 必须改。拆股权价值、溢价、负债承继 |
| 用户要求按普通股权转让稿删掉全部地块条款 | 整体停止该条放行；失去名股实地审查对象 |

修改句示范：

`第【待填】条建议改为：甲方将持有的目标公司【待填】%股权（对应认缴出资【待填】元，实缴【待填】元）转让给乙方。各方确认，本次转让的商业目的是使乙方通过取得该股权间接控制并开发目标公司名下【证号/单元号待填】地块（用途【待填】，容积率【待填】）。自本协议签署之日至交割日，未经乙方书面同意，甲方应确保目标公司不得就该地块新设抵押、出租、改变规划条件或签署任何处分协议。`

## 节点 4　土地投资开发条件与规避审查（硬闸）

先摘录文本和附件中关于出让金、取证、投资进度、开竣工、锁股、闲置的全部句子，再对照规范，最后判断文本是否把股权路径写成规避工具。

核验后可引用（须写入 `L#`）：

- 城市房地产管理法（2019 修正）第 39 条：出让土地使用权转让房地产，须缴清出让金并取得证书；房屋建设工程完成开发投资总额百分之二十五以上，成片开发形成工业用地或其他建设用地条件。
- 同法第 38 条：不符合第 39 条等情形的房地产不得转让。
- 同法第 40 条：划拨土地使用权转让房地产须报有批准权的人民政府审批；准予转让的由受让方办出让手续并缴出让金。
- 城镇国有土地使用权出让和转让暂行条例第 19 条：未按出让合同规定的期限和条件投资开发、利用土地的，土地使用权不得转让。
- 城市房地产开发经营管理条例第 19 条：转让房地产开发项目应当符合房管法第 39、40 条。
- 同条例第 15 条：动工开发期限满一年未动工的，可征相当于出让金百分之二十以下闲置费；满二年可无偿收回，不可抗力或政府原因等除外。
- 闲置土地处置办法（2012）第 24 条：闲置土地依法处置完毕前，不得办理被认定闲置土地的转让、出租、抵押和变更登记。
- 民法典第 153 条、合同编通则解释第 16 条：违反强制规定不一律无效；规范若旨在维护土地出让金等国家利益，认定合同有效不影响规范目的实现的，可以不因此无效；强制规范若规制履行行为，原则上不因此认定订立无效。

本节点动作分层，禁止两极跳：

| 已有事实 | 不得写成 | 应写成 |
| --- | --- | --- |
| 土地未达第 39 条投资开发条件，当事人改走股权 | 走股权即合法绕过 25%；或股权合同必然无效 | 点名：第 39 条约束的是房地产转让；本约不办土地过户，不当然无效；同时存在行政监管、税务穿透、出让合同违约和目的落空风险 |
| 出让合同或招商协议约定锁定期内不得变更股权 | 工商变更即可对抗出让人 | 把取得出让人/政府书面同意或锁定期届满列为生效或交割先决；未成就则中止或解除 |
| 出现闲置认定书或满一年未动工外观 | 交割后由受让人自行处理即可 | 红线或必须改：处置完毕或书面确认不构成闲置前，不得放尾款，不得承诺“无障碍开发” |
| 文本写“为规避投资额限制，各方同意以股权方式转让土地” | 可接受的交易结构说明 | 红线。删除规避目的句；改为如实描述股权转让及地块控制目的。用户坚持保留规避目的：整体停止 |
| 划拨地，未写政府审批 | 股权变更后即可开发 | 必须改。报批作为生效或交割条件；未批准则解除 |

示范句（规避审查）：

`第【待填】条原文中“为避免未达开发投资总额百分之二十五不能转让土地，各方同意以股权转让代替土地使用权转让”删除，改为：各方确认，本协议项下变更的是目标公司股权，土地使用权仍登记在目标公司名下。甲方陈述：截至签署日，（一）出让金已/未缴清【待填】；（二）投资开发进度为【待填】；（三）《国有建设用地使用权出让合同》第【待填】条【有/无】限制股权变更；（四）该地块【未被/已被/是否已被未知】认定为闲置土地。上述第（三）（四）项未消除前，乙方有权中止支付【待填】期价款并书面解除本协议。本协议任何条款不得解释为授权任何一方规避法律、行政法规关于土地使用权转让条件的规定。`

用户要求“改到能在锁定期内过户股权且政府管不着”：整体停止，不给规避路径。

## 节点 5　对价、地块节点付款、共管与保留金

1. **价款拆解。** 必须分列股权对价、项目溢价、股东借款承继或清偿、目标公司账面负债。未拆解：必须改。不得把土地评估价直接等同股权价并声称不含债。
2. **禁止先付款再尽调、签署即付清。** “签署后三个工作日内付清且与地块节点无关”：红线或必须改。付款应与节点挂钩，例如：定金/订金 → 尽调无红旗并签署 → 工商变更并取得新执照 → 土地证、印章、档案移交 → 确认无闲置/无新设负担后释放保留金。未给出数字用 `【待填】`。
3. **定金。** 必须使用“定金”二字才讨论罚则。“订金、保证金”无定金性质约定的，不得写成定金。本类型不把定金 20% 当主路径；无核验引文不得把 20% 写成现行法结论。
4. **共管。** 建议银行联名共管。工商变更完成且土地证、公章移交前，资金不释放给转让人。未写共管：必须改或标可优化但仍要给句。
5. **保留金。** 预留对价一定比例，覆盖交割前隐性债务、税务穿透补税、闲置处罚。框架建议区间仅作谈判参考，不得把 10%–20% 写成法定。未写保留金：必须改。
6. **禁止编造**单价、总价、保留金比例、节点日期。

## 节点 6　陈述保证、隐性债务、税费与地权落空

1. **土地合规陈述。** 转让人应保证：已缴清出让金及违约金；未欠配套费；无闲置认定或已处置完毕；无动工违约被收回风险；无未披露抵押、查封、地役、租约；无未披露的村集体或政府补偿承诺。口头“地是干净的”不得写成已核验。
2. **隐性债务。** 交割日前或有负债由转让人承担，并约定无限连带或保留金扣减。未写：必须改。“以审计为准”但无截止日、无争议解决：必须改。
3. **税费。** 股权转让所得税/个人所得税由谁承担必须写清。税务穿透补征土地增值税或被核定为转让房地产时的额外税负，必须有分担或补偿条款。不得写成“股权转让依法不涉及土地增值税”的保证。土地增值税暂行条例第 12 条约束的是土地权属变更手续，不得直接拿来证明股权交易免税。
4. **地权落空。** 因转让人隐瞒债务、土地违法、锁定期或闲置导致股权无法变更或土地被收回：受让人可解除并要求返还已付款及赔偿。可得利益（预期开发收益）如写入，须有可识别计算口径或上限，不得写成必得金额。政策调整致容积率大幅下调或无法开发：赋予受让人解除权。
5. **反反转。** 签约后交割前转让人不得利用控制权处分项目公司资产。
6. **原股东离场。** 其委派的董事、监事、高管须在交割日辞职并完成变更登记。未写：必须改。
7. **名股实债红旗。** 固定年化、到期回购、不参与开发：点名，不改成可履行借贷。

## 节点 7　格式痕迹、解除与争议解决

### 7.1 格式与异常条款

转让人重复使用的并购模板，按格式条款审查单方认定陈述真实、送达拟制、放弃抗辩、无限责任。仅有小字或网络勾选：不得写成已尽提示或说明义务。

“尽快”“重大”“净地”必须改成可识别标准或工作日、检测标准。

### 7.2 争议解决

涉及股权变更和项目公司所在地不动产，约定单一仲裁机构或单一法院连结点。或裁或诉、两个仲裁机构：必须改。原文已是有效仲裁条款的，不得改写成“应向某法院起诉”并假装已选定诉讼。专属管辖可能只标红旗，不选定唯一法院充作法律意见。

### 7.3 配套文件

尽调报告、共管协议、股东借款协议、出让合同摘录只审：是否列入附件、冲突以哪一份为准、是否把“无闲置/已达 25%”写进附件却与主文相反。冲突并列，修改句指定以主协议陈述保证和先决条件为准。
