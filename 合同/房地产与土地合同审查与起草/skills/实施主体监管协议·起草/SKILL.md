# 实施主体监管协议·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **房地产合同 / 实施主体监管协议** 的待签文本：一方是区级以上城市更新主管部门，另一方是经确认的项目公司实施主体；核心给付是公共贡献义务和全过程监管，不是利润分成。输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「实施主体监管协议·起草」。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查、从零起草、履约交底、争议文书、合同或资格不被撤销的保证、把本约改成民事合作或更新合作、土地出让本约整案、拆迁安置本约整案、资金监管专户整案、预售许可终局预测。

## 工作边界

正触发：已有可读待签文本要评改（审查模式），或本类型条件已谈妥要出己方稿（起草模式）；尚未签署，尚未成争；一方为城市更新主管部门（或受其合法委托的更新中心），另一方为已确认实施主体；核心给付是公共贡献、节点监管、移交核销和行政处置手段。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 双方是村集体与合作企业，核心是补偿、物业返还、分成 → `城更合作（村集体与企业）·审查`；
- 开发商与前期服务公司，核心是服务费和申报代理 → `城更合作（开发商与前期服务）·审查`；
- 以项目公司股权合作推进更新 → `城更股权合作·审查`；
- 更新意向、框架、排他谈判 → `城市更新项目意向合作协议·审查`；
- 更新前期服务本约 → `城市更新项目前期服务合同·审查`；
- 主文件是国有土地使用权出让，核心是出让金与交地 → `国有土地使用权出让合同·审查`；
- 独立资金监管专户拨付主文件 → `资金监管协议·审查`；
- 对被拆迁人的补偿安置本约 → `拆迁补偿安置协议·审查`；
- 出地出钱、共担风险、联合操盘、隐名参建 → `房地产合作开发类合同·审查` 或 `一方出地一方出钱联建·审查` 至 `隐名参建联建·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问移交节点、保函释放、报批进度 → 本套导航的履约步骤；
- 已成争（催告、拟撤销实施主体、索赔、复议、诉讼仲裁）→ 合同争议或行政争议领域。

挂靠、违法分包、规避限购、伪造实施主体确认：只出告知，不改写成可履行结构。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成。每一闸必须给出修改句或明确转出口径，禁止只打红黄绿。

1. **监管权限 vs 民事合作**。标题或用户口述“合作”不决定类型。必须同时读出：监管方行使城市更新监管权；实施主体负担无偿移交用地、配建、安置、资金监管等公共贡献。修改句把鉴于改成：因【项目名称／单元】已取得实施主体确认〔文号【待填】〕，双方订立本监管协议，将公共贡献转化为合同义务；本协议不构成合作开发、利益分配或股权合作。禁止把利润分成、操盘权、股东会席位写成主给付。
2. **与更新合作切开**。主文件是村企合作、股权合作、前期服务或意向 → 负触发对应原子。本任务禁止输出分成表、回迁物业结算、服务费抵扣股权作为主路径。禁止打开 `城市更新项目前期服务合同·审查` 至 `城更合作（村集体与企业）·审查` 的 method。
3. **与土地出让切开**。出让金、交地、出让年限主导 → 负触发 `国有土地使用权出让合同·审查`。本约可约定申请出让的先决条件，但不审、不改出让价款公式。
4. **禁止抄合作开发／联建**。出地出钱、共管账户、联合操盘 → 负触发 `房地产合作开发类合同·审查` 或联建原子。禁止打开其 method，禁止把利润分配节点搬进本约。
5. **行政协议争议解决不得商事仲裁**。出现仲裁委、或裁或诉：红线。修改句改为依法申请行政复议或提起行政诉讼。不得保证整份协议有效，只标仲裁条款不能放行。
6. **资格撤销与捆绑审批不得改成可绕过结构**。原文“双方协商解除即恢复如初、前期投入由政府买单”或“公建未完成仍可预售”：红线。资格撤销是行政处理，修改句只补程序、告知、补偿接口，不写成民事协商即可消灭监管权。预售、竣工备案、首次登记必须与公建节点挂钩。
7. **与资金监管、拆迁补偿切开**。本约引用《资金监管协议》或安置义务的，只审引用是否闭环；专户细则整案转 `资金监管协议·审查`，对被拆迁人补偿整案转 `拆迁补偿安置协议·审查`。

附加必落句（有事实则单列，无事实在缺口节说明）：

- **实施主体适格**：签约乙方须与确认文件、公示名单一致。未确认或主体不一致：字段停止，不写成可以报批。
- **三同步与挂钩**：公共设施与融资区同步设计、施工、验收；公建未达【待填节点】前，不得办理融资区预售许可。
- **移交定义**：交付政府＝完成不动产登记并将权属证件移交指定接收单位；移交前风险由实施主体承担；移交资产不设抵押。
- **接收标准锁定**：以专项规划批复、附件清单和签订时已公布标准为准；接收单位事后加码不当然构成违约。
- **非归责顺延**：征收拆迁受阻、规划调整、接收单位未按时接管可顺延；经营不善、融资失败不列入不可抗力。
- **股权锁定**：公建及安置移交核销前，实际控制人变更须书面同意。
- **保函阶梯**：允许银行不可撤销履约保函替代现金，并按完成量调减。
- **分期隔离**：各期监管责任分列，一期违约不当然卡死已达标分期。
- **税收兜底**：亩均税收、入驻率缺额补足标红旗，补考核期、免责和是否收回房屋；不编造可承受额。

必须有修改句。每个风险回链文本位置。禁止套用买卖五证、定金百分之二十、合作开发分成或更新合作服务费节点。

## 建立起草坐标

确认：使用者与授权；单方立场（实施主体／项目公司、监管机关、拟提供连带保证的母公司）；相对方；全文及清单／标准／资金监管细则／确认文件／规划批复附件版本；项目单元与文号；公共贡献范围；保证金或保函；挂钩节点；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的面积、文号、保证金、税收指标用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law`（法律结论 required）：核验行政协议定义与受案、仲裁条款效力、行政机关单方变更解除及补偿、不依法履行的判决路径、预售许可法定条件、规划条件与出让合同关系、配套幼儿园同步移交、不可抗力、独立保函识别。项目所在地城市更新办法按地名另查。
- `search_practiced`（optional）：补行政协议定性、仲裁无效、接收标准争议等争点。返回“监管协议就是民事合同、可仲裁、删掉挂钩就能先卖”时记噪声。
- `search_template`（optional）：只借栏目结构。范本是更新合作、股权合作开发或只写利润分成的，不得当本约规则。

不虚构案件系统。`search_law` 返回已失效《合同法》、1989 年行政诉讼法第十二条旧义、法释〔2015〕9 号、失效出让规章时记为噪声，不得写入 `L#`。


## 起草模式

本原子只承担本类型起草。待签评改转 `实施主体监管协议·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。按框架六步落稿。商业数字未给用 `【待填】`。出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。村企合作、股权合作、前期服务、意向、土地出让本约、资金监管专户、拆迁补偿、联建：负触发，不按邻类出稿。

**起草必写**

- 鉴于写明：因【项目名称／单元】已取得实施主体确认〔文号【待填】〕，双方订立本监管协议，将公共贡献转化为合同义务；本协议不构成合作开发、利益分配或股权合作。
- 签约乙方须与确认文件、公示名单一致。
- 公共设施与融资区同步设计、施工、验收；公建未达【待填节点】前，不得办理融资区预售许可。
- 交付政府＝完成不动产登记并将权属证件移交指定接收单位；移交前风险由实施主体承担；移交资产不设抵押。
- 接收标准以专项规划批复、附件清单和签订时已公布标准为准。
- 征收拆迁受阻、规划调整、接收单位未按时接管可顺延；经营不善、融资失败不列入不可抗力。
- 公建及安置移交核销前，实际控制人变更须书面同意。
- 允许银行不可撤销履约保函替代现金，并按完成量调减；各期监管责任分列，一期违约不当然卡死已达标分期。
- 争议解决改为依法申请行政复议或提起行政诉讼。

**附件必附**

- 实施主体确认文件、公示名单。
- 专项规划批复。
- 公共贡献／移交清单与接收标准。
- 引用资金监管协议时只审引用是否闭环，专户细则不在本约展开。

**禁止出现**

- 利润分成、操盘权、股东会席位作为主给付。
- 分成表、回迁物业结算、服务费抵扣股权作为主路径。
- 出让价款公式。
- 仲裁委、或裁或诉。
- “双方协商解除即恢复如初、前期投入由政府买单”；“公建未完成仍可预售”。
- 资格撤销写成民事协商即可消灭监管权。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口，不代替节点。

0. 签署状态与成果分流
1. 类型识别与单目录加载（监管权限 vs 民事合作；切开更新合作／出让／资金监管／拆迁／联建）
2. 主体：监管方职权、实施主体确认、股权锁定、母公司保证、接收单位
3. 行政协议定性、单方变更解除补偿、争议解决禁止商事仲裁
4. 公共贡献标的、规划一致性、移交定义与接收标准
5. 程序：保证金／保函、三同步、核销、资金监管引用、捆绑审批、分期隔离
6. 违约、资格撤销、不可抗力与非归责顺延、税收兜底
7. 格式条款与强制规范（不把行政法义务改成可抛弃民事条款）
8. 按框架六步出修改句

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造确认文件或倒签、把未确认主体改成可报批、把行政协议改成可仲裁民事合作、删除公建挂钩以便先卖融资房、保证必然不被撤销或预售一定办成。
- `字段停止`：法域、地方更新办法、确认文件、规划指标、接收标准、税收条款未核验。
- `目标停止`：主目标已变为从零起草、履约交底、复议或诉讼文书，或用户要把本约改成更新合作／合作开发以便分配利润。

生存级安置未闭环且用户拒绝升级：停止“可以签署”建议。
