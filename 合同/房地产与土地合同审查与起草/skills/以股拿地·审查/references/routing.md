# 边界与路由

本技能只审查 **土地使用权 / 以土地获取为目的的股权取得类合同**。

目标公司必须绑定特定宗地，核心给付必须是通过股权间接拿地。标题叫“股权转让协议”但实际是直接土地过户、带在建预售的项目股权，或与土地无关的普通股权转让的，不得留在本技能做实体结论，也不得改写成“视同名股实地”。

本类型与直接土地使用权转让、房地产项目股权、普通股权转让不是同一方法。直接过户路径处理 25% 作为土地变更登记条件、契税和土地增值税申报、不动产登记；项目股权路径处理五证、在建、预售监管和工程欠款；普通股权路径处理优先购买权和工商变更，不审地块开发条件。本技能不打开那三套栏目。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或标题股权、核心给付明显不是拿地 | 本套导航的类型切开步骤 |
| 转让人是土地使用权人；对价是地价款；履行轴是不动产变更登记或土地二级市场网签 | `国有土地使用权转让合同·审查`；禁止用本技能审土地过户、契税过户或带押过户 |
| 已有实质在建、施工总包、预售或网签购房人、预售资金监管、五证开发主路径 | `或`；禁止用本技能审预售监管或工程款优先 |
| 无拿地目的、无地块四至或证号绑定，只审股权比例和对价 | `或` 或 `或` |
| 土地尚未出让，联合竞买、配资拿地为主 | `一级市场联合拿地类合同·审查`；本约仅以竞得为继续履行条件的，留本技能只审该条件 |
| 共同出资报建、共担风险，不转移控股权 | `房地产合作开发类合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、问工商变更日、共管放款、证照移交 | 本套导航的履约步骤 |
| 已成争、催告、诉讼仲裁 | 合同争议领域；不写催告函、起诉状 |
| 用户只要“一定有效”或“走股权一定能绕过 25%” | 停止该结论；本技能只审条款并点名规避风险 |
| C 端大众快检 | 只分流，不回改 |

附带股东借款承债、共管账户或税费补偿时：本技能只审对本约放行的影响（是否列入附件、付款节点是否冲突、未落实能否交割），不展开借贷或税务专项整案。

规避投资开发条件、出让合同锁股、闲置土地未处置完毕仍承诺“过户无障碍”、隐名代持、名股实债：停笔告知，不改写成可履行结构。
