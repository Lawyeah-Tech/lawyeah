# 拆迁补偿安置协议·审查

## 任务目标

在单一立场下，只审查 **房地产合同 / 拆迁补偿安置协议** 的待签文本：补偿方向被征收人／被拆迁人／退出权属人给付货币或安置房屋，对价是房屋拆除、土地腾退或权属注销。输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「拆迁补偿安置协议·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查、从零起草、履约交底、争议文书、有效性或必得金额保证、拆迁委托整案、一级开发整案、村企合作整案、商品房买卖整案、可履行逼迁结构。

## 工作边界

正触发：已有可读待签文本要评改，；尚未签署，尚未成争；核心给付是对被征收人／被拆迁人的补偿安置——货币、产权调换／安置房、搬迁与临时安置、停产停业或集体土地法定补偿项目。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 房屋征收部门与实施单位订立委托，对价是劳务费、权限或具体工作 → `意向合作）。禁止打开上述method当本类型主路径。禁止抄`；
- 政府或储备机构委托企业做一级开发，对价是核定成本回收 → `土地一级开发委托，或名为一级开发实为投资借贷`；
- 村集体与合作企业的开发合作、分成或保证摘牌 → `城更合作（村集体与企业）·审查` 或 `政府作为一方一级整理加二级联动→`；
- 普通商品房买卖价款、五证、网签主结构 → `普通商品房买卖价款五证网签主结构→`；
- 资金监管本约 → `资金监管协议·审查`；实施主体监管本约 → `实施主体监管协议·审查`；
- 类型未定或名实两可 → 本套导航的类型切开步骤；
- 无文本、本类型条件已谈妥、要出己方稿 → `拆迁补偿安置协议·起草`；
- 已签只问付款日、交房日、选房日 → 本套导航的履约步骤；
- 已成争（催告、解除、索赔、强拆、复议、诉讼仲裁）→ 合同争议或行政争议专项。

挂靠、违法分包、规避限购、伪造征收决定、把停水电或建设单位搬迁改成可履行：只出告知，不改写成可履行结构。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成。每一闸必须给出修改句或明确转出口径，禁止只打红黄绿。

1. **征收主体**。国有土地：市、县级人民政府作出征收决定；房屋征收部门与被征收人订立补偿协议。集体土地：县级以上地方人民政府组织有关部门与所有权人、使用权人签订。实施单位可受委托承担具体工作，但不得单独写成征收机关，也不得以项目部章冒充成交。指挥部、拆迁事务所、建设单位无书面委托或实施主体批复：签署能力字段停止。修改句把征收决定／补偿方案／书面委托列为附件，并写“主体不适格或未获批准不生效”。
2. **补偿项目**。国有土地按房屋价值（或产权调换地点、面积及差价）、搬迁费、临时安置费或周转用房、停产停业损失、补助奖励、搬迁期限、过渡方式与期限、支付期限分列。集体土地按土地补偿费、安置补助费、农村村民住宅、地上附着物和青苗、社会保障、搬迁与临时安置分列。一口价“已包含全部补偿”、合法面积与违法面积混算、先搬后补：必须改或红线。未给出的数字用 `【待填】`，不编造，不输出唯一必得额。国有土地类似房地产市场价格与集体土地区片综合地价不得混成一套公式。
3. **与委托拆迁切开**。正像是补偿方与被征收人／被拆迁人之间的退出补偿。对价绑实施单位劳务费、受托权限、不得营利、不得代签 → `意向合作）。禁止打开上述method当本类型主路径。禁止抄`。禁止打开或复制 `意向合作）。禁止打开上述method当本类型主路径。禁止抄` 的 method，禁止把本约改成对实施单位的委托文本，禁止按委托权限改补偿标准。

附加必落句（有事实则单列，无事实在缺口节说明）：

- **先补偿后搬迁**：支付或安置到位后再交房；删除“先腾空、款视融资到位后支付”。
- **禁止逼迁**：删除停水、停电、停气、阻断交通、建设单位参与搬迁、可自行强制拆除。
- **面积三分**：合法建筑面积、现状建筑面积、补偿计算面积分列；回迁建筑面积含公摊须写明。
- **共有人**：登记权利人、配偶、继承人本人签或经公证授权；户主代签字段停止。
- **回迁锁定**：地块／平面图或“改建地段或就近地段”；“后期通知”必须改。
- **争议解决**：构成行政协议的，仲裁条款原则上无效，改为行政诉讼或按不动产所在地管辖；是否构成行政协议须个案判断。

必须有修改句。每个风险回链文本位置。禁止复制 `意向合作）。禁止打开上述method当本类型主路径。禁止抄`、`土地一级开发委托，或名为一级开发实为投资借贷`、`普通商品房买卖价款五证网签主结构→` method。

## 建立审查坐标

确认：使用者与授权；单方立场（征收／补偿方或被征收／被拆迁人）；相对方；全文及测绘／明细／选房／家庭成员声明附件版本；土地性质；征收决定或补偿方案是否覆盖标的；补偿方式；权属与共有；经营性用房；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的面积、金额、期限、文号用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law`（法律结论 required）：核验征收主体、补偿项目、先补偿后搬迁、禁止逼迁、产权调换选择权、违法建筑认定、行政协议识别与仲裁条款、强制规范。
- `search_practiced`（optional）：补签约主体、协议应载事项、协议与补偿决定关系等争点。返回“拆迁人可行政强拆”“实施单位当然可代征收机关成交”时记噪声。
- `search_template`（optional）：只借栏目结构。范本写“先搬后补”“停水电”“拆迁人申请行政强拆”不得当规则。

不虚构案件系统。`search_law` 返回已失效《合同法》及其解释、2001 年拆迁条例、1991 年实施条例同号旧义、已废止征收土地公告办法、1989 年行政诉讼法第十二条时记为噪声，不得写入 `L#`。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口，不代替节点。

0. 签署状态与成果分流
1. 类型识别与单目录加载（补偿安置；切开委托拆迁）
2. 征收主体、权属与共有
3. 补偿项目、面积与安置方式
4. 程序附件、生效与方案符合性
5. 搬迁顺序、禁止逼迁与强制执行路径
6. 行政协议识别、格式条款与争议解决
7. 权利负担、租客清退与强制规范
8. 按框架六步出修改句

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签或假征收决定、把无权主体改成可冒充征收机关、把停水电或建设单位搬迁改成可履行、保证必然有效或必得补偿额、坚持用 2001 年拆迁条例出法律结论。
- `字段停止`：法域、土地性质、征收决定覆盖、书面委托、权属共有、是否构成行政协议未核验。
- `目标停止`：主目标已变为从零起草、履约交底、复议或起诉状，或用户要把本约改成委托拆迁、一级开发、村企合作或商品房买卖本约。

生存级住房被要求先搬后补或个人无限连带且用户拒绝升级：停止“可以签署”建议。
