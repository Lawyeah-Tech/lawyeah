- 国有土地上房屋征收与补偿条例第四条：市、县级人民政府负责本行政区域的房屋征收与补偿工作；其确定的房屋征收部门组织实施。
- 同条例第五条：房屋征收部门可以委托房屋征收实施单位承担具体工作；实施单位不得以营利为目的；征收部门对委托范围内的行为后果承担法律责任。
- 同条例第十三条：征收决定应及时公告，公告载明征收补偿方案和行政复议、行政诉讼权利；房屋被依法征收的，国有土地使用权同时收回。
- 同条例第十七条：补偿包括被征收房屋价值，搬迁、临时安置，停产停业损失；市、县级人民政府应当制定补助和奖励办法。
- 同条例第十九条：房屋价值补偿不得低于房屋征收决定公告之日被征收房屋类似房地产的市场价格；由相应资质评估机构评估；对评估有异议可复核、鉴定。
- 同条例第二十一条：被征收人可以选择货币补偿或房屋产权调换；旧城区改建征收个人住宅且选择在改建地段调换的，应提供改建地段或者就近地段的房屋。
- 同条例第二十四条：征收决定前应对未经登记建筑调查、认定、处理；合法建筑和未超过批准期限的临时建筑给予补偿；违法建筑和超过批准期限的临时建筑不予补偿。
- 同条例第二十五条：房屋征收部门与被征收人就补偿方式、补偿金额和支付期限、产权调换房屋的地点和面积、搬迁费、临时安置费或者周转用房、停产停业损失、搬迁期限、过渡方式和过渡期限等事项订立补偿协议。
- 同条例第二十六条：签约期限内达不成协议或所有权人不明确的，由房屋征收部门报请作出征收决定的市、县级人民政府按照补偿方案作出补偿决定并公告。
- 同条例第二十七条：先补偿、后搬迁；任何单位和个人不得采取暴力、威胁或违反规定中断供水、供热、供气、供电和道路通行等非法方式迫使搬迁；禁止建设单位参与搬迁活动。
- 同条例第二十八条：法定期限不申请复议或诉讼、在补偿决定期限内又不搬迁的，由作出征收决定的市、县级人民政府申请人民法院强制执行。
- 土地管理法（2019 修正）第四十七条：国家征收土地由县级以上地方人民政府公告并组织实施；拟申请征收前应开展调查和稳评、公告至少三十日；与所有权人、使用权人就补偿、安置签订协议。
- 土地管理法修改决定中第四十八条文本（2019 修正本对应条运行时按条重核）：及时足额支付土地补偿费、安置补助费、农村村民住宅、地上附着物和青苗等费用并安排社会保障；农用地的土地补偿费、安置补助费由区片综合地价确定；农村村民住宅先补偿后搬迁。
- 土地管理法实施条例（2021 修订）第二十九条：县级以上地方人民政府组织有关部门与拟征收土地的所有权人、使用权人签订征地补偿安置协议。
- 同条例第三十二条：区片综合地价；有关费用未足额到位的，不得批准征收土地。
- 同条例第三十六条：禁止强迫农村村民搬迁退出宅基地。
- 民法典第一百一十七条、第二百四十三条、第三百二十七条：公平合理补偿；集体土地补偿项目名称；征收个人住宅应保障居住条件；禁止贪污挪用私分截留拖欠；用益物权人可获相应补偿。
- 行政诉讼法（2017 修正）第十二条第一款第十一项：认为行政机关不依法履行、未按照约定履行或者违法变更、解除土地房屋征收补偿协议等协议的，属于受案范围。
- 同法第二十条：因不动产提起的行政诉讼，由不动产所在地人民法院管辖。
- 行政协议司法解释第一条：行政机关为了实现行政管理或者公共服务目标，与公民、法人或者其他组织协商订立的具有行政法上权利义务内容的协议，属于行政协议。
- 同解释第二条：土地、房屋等征收征用补偿协议属于应当依法受理的行政协议。
- 同解释第四条：受委托组织订立的，委托的行政机关是被告。
- 同解释第五条：被征收征用土地、房屋等不动产的用益物权人、公房承租人认为征收征用补偿协议损害其合法权益的，可以起诉。
- 同解释第十二条：存在行政诉讼法第七十五条重大且明显违法情形的，确认行政协议无效；也可适用民事法律规范确认无效。
- 同解释第二十六条：行政协议约定仲裁条款的，该条款无效，但法律、行政法规或我国缔结、参加的国际条约另有规定的除外。
- 同解释第二十七条：审理行政协议案件适用行政诉讼法；行政诉讼法没有规定的，参照民事诉讼法；可以参照适用民事法律规范关于民事合同的规定。

## 节点 2　征收主体、权属与共有（硬闸）

先分轨，再查主体。土地性质不明：字段停止，并列国有／集体两套待核项，不混算。

1. 建主体表：补偿方（机关名称或项目公司名称）、被补偿方（登记权利人）、公有房屋承租人、共有人／配偶／继承人、实施单位或项目公司、见证方（村集体）、付款名、授权签字人。名称不一致不自动合并。
2. 国有土地：文本或附件须能回链市、县级人民政府征收决定和房屋征收部门身份。甲方只写“旧改指挥部”“项目部”“拆迁事务所”“建设单位”且无房屋征收部门签章或书面委托：签署能力字段停止。实施单位可以列为委托经办方，但协议须写明征收部门是补偿义务主体。
3. 集体土地：文本或附件须能回链县级以上地方人民政府组织实施和补偿安置方案。有关部门代签的，写明组织实施的政府。
4. 城市更新／旧村改造：项目公司当甲方的，须回链政府确认的实施主体资格和村集体表决通过并备案的补偿安置方案。无批复：字段停止。不得把项目公司写成“征收机关”。
5. 被补偿方：查验房产证、不动产登记、宅基地证、公房租赁凭证或村集体权属证明。权属人已故：查继承材料。仅户主或长子签字：共有人字段停止；修改句要求全体登记权利人和配偶签署或经公证授权。
6. 限制行为能力人、监护处分：字段停止，不写成监护人当然可以处分生存住房。
7. 口头“街道同意了”“指挥部章就能成交”不得写成已授权。用户要求补假征收决定或假委托：整体停止。

不足：字段停止，列出待补材料，不补主体、不补已授权、不补共有人已同意。

反方常见抗辩：实务中实施单位经常代签。本任务仍要求征收部门作为补偿义务主体可回链；解释第四条下，受委托组织订立的，被告仍可能是委托的行政机关。

## 节点 3　补偿项目、面积与安置方式（硬闸）

本类型对价是补偿安置，不是商品房价款，也不是委托劳务费。

### 3.1 国有土地项目清单

| 有房屋价值，无搬迁费或无临时安置费／周转用房 | 必须改。补标准、支付节点或周转用房地点 |
| 经营性用房或证载非住宅，无停产停业损失 | 必须改或标 `G#`。住宅擅自改经营且材料未支持的，不得自行补停产停业 |
| 产权调换未写地点、面积、差价结算 | 必须改。旧城区改建个人住宅选择原地段的，写改建地段或就近地段，不得只写“后期通知” |
| 房屋价值明显低于公告之日类似房地产市场价格且无评估 | 红旗。修改句要求按评估办法评估，并保留复核、鉴定 |
| 把未经认定的阁楼、露台全部按合法面积或全部按违法面积计算 | 必须改。等待调查认定；合法与未超期临时建筑给补偿，违法和超期临时建筑不予补偿 |

### 3.2 集体土地项目清单

对照民法典第二百四十三条和土地管理法第四十八条文本：

| 文本写法 | 本任务动作 |
| --- | --- |
| 未分列土地补偿费、安置补助费、住宅、附着物青苗、社会保障 | 必须改。缺项用 `【待填】` |
| 用“类似房地产市场价格”替代区片综合地价，或反过来 | 红旗。两套标准不得混算 |
| 农村村民住宅未给货币、安置房或宅基地重建选项 | 必须改。尊重意愿，先补偿后搬迁 |
| 社会保障费用未单独列支 | 必须改或标 `G#` |

### 3.3 面积语言

严谨区分：合法建筑面积、现状建筑面积、补偿计算面积；回迁房建筑面积是否含公摊。三者混用：必须改。最终面积以有权机关或约定测绘机构结果为准，不得由一方“目测确认”。

禁止编造单价、总价、置换比和交付日。材料未提及不得写成“评估已经完成”或“方案已覆盖全部合法面积”。

## 节点 4　程序附件、生效与方案符合性

把征收决定、补偿方案、村集体表决、实施主体批复、评估报告写成**生效条件或履行前提**，不写成已经完成。

| 文本写法 | 本任务动作 |
| --- | --- |
| “本合同签字盖章后立即生效”，但文本同时要求征收决定或整体签约率 | 必须改。拆成签字成立 vs 征收决定／方案覆盖／约定签约率成就后生效 |
| 补偿标准明显背离已公布或已备案的征收补偿方案 | 红旗。修改句改为“不低于已公布方案对应项目；方案外承诺须书面且不得低于法定项目” |
| “双方同意视为已作出征收决定／已评估” | 红线。删除拟制 |
| 签约率未达标自动失效且“互不负责”，已搬迁或已交权属原件 | 必须改。写明返还已交房屋或权属、已收款清理、临迁费结算 |
| 用户要求倒签征收决定日或评估基准日 | 整体停止 |

附件至少点名：测绘报告、补偿明细表、安置房选房确认单或平面图、家庭成员声明、权属证书复印件。缺失列入 `G#`，不补造附件内容。

达不成协议：只提示条例第二十六条补偿决定路径，本任务不代拟补偿决定。

## 节点 5　搬迁顺序、禁止逼迁与强制执行路径

1. 顺序必须是：补偿或安置到位（或专户存储／监管账户可核验）→ 搬迁 → 移交空房和权属原件 → 签署移交确认书。先搬后补：红线。
2. 临时安置费：标准、按月或按季、起算与截止（至回迁房**交付**而非仅发出通知后若干月）；逾期交付回迁房的，临迁费按约定倍率递增。框架建议的“超过约定期限后加倍”可作必须改，但不得编造倍率和期限。
3. 搬家补助一次性标准和支付日。
4. “交付”指钥匙及相关证明实际移交，不是仅发出入住通知。
5. 出现停水、停电、停气、停热、阻断道路、威胁、建设单位参与搬迁、甲方可自行拆除：红线删除。用户坚持保留：整体停止。
6. 强制搬迁只能写成：补偿决定作出且法定救济期限届满仍不搬迁的，由作出征收决定的市、县级人民政府申请人民法院强制执行。不得写成征收部门、实施单位、建设单位或指挥部自行强拆。
7. 集体土地路径：不得写成可强迫退出宅基地。拒不交出土地的，只提示依法申请法院强制执行，不判断应否准予。

反方常见抗辩：不搬就全项目停工。可以约定逾期搬迁的违约金或扣除超期奖励，不得把逼迁手段改成可履行。

## 节点 6　行政协议识别、格式条款与争议解决

是否构成行政协议，按已核验的第一条三要素判断；土地、房屋征收征用补偿协议在第二条被点名。结论只能是 `现有依据支持`／`不支持`／`依据不足`。不得写“拆迁补偿安置协议当然是行政协议”或“当然是民事合同”。城市更新项目公司文本：主体是民事主体时可能不构成行政协议，仍须审查是否借用征收名义、是否受补偿方案强制拘束。

| 文本写法 | 本任务动作 |
| --- | --- |
| 争议“提交某仲裁委员会仲裁”，且文本具备行政协议要素或点名征收补偿 | 必须改。提示解释第二十六条：仲裁条款原则上无效；修改句改为行政诉讼，管辖连结点用不动产所在地 |
| “本合同为平等民事主体之间的民事合同，排除行政诉讼” | 不得当成已排除行政协议审查；名称不决定性质 |
| 或裁或诉、机构不明 | 标待核，改成单一路径 |
| 征收方预先拟定、未协商的免责、排除选择货币或产权调换、单方最终解释权 | 按格式条款审查提示说明；无核验引文则法律结论字段停止 |

行政复议法第七十一条只作权利名称，不在本任务代写复议申请。

## 节点 7　权利负担、租客清退与强制规范

1. 抵押、查封、居住权未清除：不得写成可立即注销原证或可立即回迁登记。修改句要求移交前由权利人自行解除，或把负担处理写成生效／付款条件。材料未提及不得写成“无权利负担”。
2. 租赁：由业主负责清退承租人和占用人，移交时为空房；补偿方不介入租赁纠纷。公有房屋承租人可能是独立补偿对象，不得被业主条款吞掉。
3. 风险转移：自签署移交确认书之日起，房屋管理、防火、防倒塌责任转补偿方或实施单位；此前不得写成已转移。
4. 税费：产权调换首次登记税费由谁承担须写明；框架建议项目公司承担首次登记法定税费，可作可优化，不编造免税结论。
5. 资金监管：补偿资金进入政府或约定监管账户的，写明开户行、账户名、支付指令条件。无账户不得写成“资金已监管”。监管协议整案转 `资金监管协议·审查`。
6. 强制规范：违反法律、行政法规强制性规定不一律无效。禁止用已失效“效力性／管理性”口诀。逼迁、建设单位参与搬迁、伪造征收决定：不改写成有效履行结构。
7. 政策衔接：转为政府征收时，不得用本约压低法定补偿项目；只能写“法定补偿项目和下限仍适用，本约已付部分结算抵扣”。
