# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受、必然可办证或必然可执行；编造未给出的价款、面积、年限；把已失效《合同法》及其解释、2004 年土地管理法第六十三条旧文写入结论；把租赁、入股或国有出让文本当成已完成的本类型审查；输出诉讼请求或举证策略。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查集体建设用地使用权出让合同（土地使用权）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、《物权法》、2004 年土地管理法第六十三条旧文或 1991 年实施条例时记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `土地使用权`，子级 `集体建设用地使用权出让合同`。定性理由、与国有出让 / 租赁 / 入股 / 合作开发的切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型、未加载 `国有土地使用权出让合同·审查`。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、集体决议与文本版本

主体表：签约名、履行名、收款名、开票名、授权签字人、是否村委会代行。决议闸：会议类型（成员大会 / 成员代表大会 / 村民会议）、同意比例、签名页、公示、会前通知。版本表：正文、附件、规划条件书、产业准入和环保要求、成交确认书、聊天确认；冲突并列。

## 5. 入市条件、标的与给付闭环

规划用途、所有权登记、方案是否已报市县人民政府、界址面积用途年限、权利负担、交地与开工竣工、价款与监管账户、调节金。缺口标 `G#`。批准、备案、登记写成生效条件或期限，不写成已经完成。

## 6. 规划条件入合同与强制规范

规划条件、产业准入、生态环境保护要求是否纳入合同；改变用途、小产权房、农用地伪入市。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和补件句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。框架里的“集体入股 + 合作开发”“先按租赁再当出让放行”不得直接当作建议句。

## 9. 谈判与签署提醒

谈判顺序：先红线（无决议、入市条件不具备、规划条件未入合同、农用地/宅基地/小产权房、价款入个人账户），再必须改，最后可优化。签署提醒：决议及签名页、规划条件书、产业准入和环保要求、界址图、方案报送回执、监管账户、备案和登记义务人。不指导倒签或补假决议。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、入市报批代办、争议文书或效力保证。
