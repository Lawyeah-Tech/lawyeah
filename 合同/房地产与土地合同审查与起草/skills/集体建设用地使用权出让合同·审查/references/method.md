本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止把国有出让 `国有土地使用权出让合同·审查` 的审查正文抄进本任务。

定性校验：标题、核心给付与本类型一致才继续；国有出让、租赁、入股、合作开发、宅基地或承包经营权明显则负触发，不填十节实体结论。

本技能已锁定 **土地使用权 / 集体建设用地使用权出让合同**。只打开 `references/基本面.md` 与 `references/框架.md`。禁止读其他子目录，禁止为对照再开第二类，禁止打开 `国有土地使用权出让合同·审查` 的 method。

### 1.3 规避结构停笔

加载后或定性中出现：农用地或未登记土地以出让合同包装非农建设；宅基地或公益用地伪称经营性入市；在集体土地上开发住宅对外销售（小产权房）；倒签或补造村民决议。

动作：

1. 交付告知：土地管理法第八十二条指向擅自将农民集体所有土地出让用于非农业建设，或违反规定将集体经营性建设用地交由单位或个人使用；城市房地产开发经营管理条例第三十九条指向城市规划区内集体土地须先征收方可房地产开发。不得改写成可履行规避文本。
2. 不写假农转用路径、假决议、可销售小产权房、体外循环地价款。
3. 风险表只保留识别依据和转出/改道提示。
4. 用户坚持“改到能签且仍规避”：整体停止。

合规改道（先依法办理农用地转用和征收、或改走已入市地块）只点名，不在本任务起草。

## 节点 3　入市条件、标的与权利负担

### 3.1 入市条件（硬闸）

支持依据：实施条例第三十七条、第三十九条、第四十条；农村集体经济组织法第三十九条；土地管理法第六十四条、第八十二条；民法典第三百六十一条。2019 年土地管理法第六十三条全文运行时核验。

审查清单，缺一项则该字段不得写成已具备入市条件：

1. 规划用途为工业、商业等经营性用途，而非农用地、宅基地、公益事业用地。
2. 集体土地所有权已依法登记。未确权登记：现有依据不支持入市，修改句停止在补登记之前签署物权性出让。
3. 市、县人民政府自然资源主管部门已提出规划条件，并会同有关部门提出产业准入和生态环境保护要求。
4. 出让方案已编制，并载明界址、面积、用途、规划条件、产业准入和环保要求、使用期限、交易方式、入市价格、集体收益分配安排。
5. 方案已在出让前不少于十个工作日报市、县人民政府；若政府在五个工作日内提出修改意见，方案已按意见修改。

| 文本写法 | 动作 |
| --- | --- |
| 农用地、耕地、设施农用地“一并出让搞厂房” | 红线；停笔；不写假农转用 |
| 宅基地、村民住宅用地对外出让 | 红线；不改写成可履行 |
| 学校、卫生室等公益用地出让给商业开发 | 现有依据不支持全面入市；红线 |
| 城市规划区内做商品房或小产权房销售 | 红线。城市房地产开发经营管理条例第三十九条 | 
| “政府口头同意就算入市” | 必须改：方案书面报送及回执作为附件 |

### 3.2 标的描述与权利负担

宗地坐落、面积、界址、用途必须确定到可登记。只有“村东那块地”则标缺口。

使用年限参照同类用途国有建设用地：工业最高五十年，商业、旅游、娱乐最高四十年，综合或其他五十年（城镇国有土地使用权出让和转让暂行条例第十二条；实施条例第四十三条）。集体经营性建设用地原则上不按居住用地七十年放行住宅开发。

权利负担：抵押、查封、未到期土地承包经营权、既有租赁。材料未提及不得写成“无权利负担”，只能写 `依据不足`。存在未到期承包经营权：必须改，要求交回或补偿文件作为附件，不编造补偿金额。

严禁约定把集体土地所有权转让给受让人。

## 节点 4　方案、公开交易、合同必备记载与登记

### 4.1 确定使用者的方式

实施条例第四十一条：土地所有权人依据出让方案，以招标、拍卖、挂牌或者协议等方式确定土地使用者。协议出让须在方案和合同中写明理由与价格形成过程，不得只写“双方协商确定”而无方案依据。

### 4.2 合同应当载明的事项（硬闸）

实施条例第四十一条：书面合同载明土地界址、面积、用途、规划条件、使用期限、交易价款支付、交地时间和开工竣工期限、产业准入和生态环境保护要求；约定提前收回的条件、补偿方式、使用权届满续期和地上建筑物、构筑物等附着物处理方式，以及违约责任和解决争议的方法；并报市、县人民政府自然资源主管部门备案。

**未依法将规划条件、产业准入和生态环境保护要求纳入合同的，合同无效；造成损失的，依法承担民事责任。**

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 三项要求已作为合同条款或编号附件，与规划条件书一致 | 继续；冲突则并列 | 合同必然有效 |
| 三项要求只在鉴于或招标文件出现，未纳入合同 | 必须改：纳入正文或附件并约定附件效力 | 已经纳入 |
| 用户要求删掉产业准入或环保条款“以免被管” | 红线；拒绝删除；坚持则整体停止 | 删掉不影响效力 |
| 文本写“本合同签字即生效，备案不影响效力”且缺三项要求 | 红线补三项；备案写成双方义务和期限，不写成已经完成 | 签字即物权设立 |

民法典第三百四十八条的出让合同一般条款作结构对照，集体土地适用第三百六十一条，不得用第三百四十七条的国有公开竞价规则替代实施条例第四十一条。

### 4.3 登记与生效

民法典第二百零九条：不动产物权经依法登记发生效力，法律另有规定的除外。实施条例第四十二条：使用者支付价款并依法纳税后，申请集体经营性建设用地使用权及地上建筑物所有权登记。

把批准、备案、登记写成生效条件或双方义务期限，不写成已经完成。用户要求倒签成交日或补假备案：整体停止。

## 节点 5　价款、调节金、交付、开发与收回

### 5.1 价款

价金构成、币种、税、发票、支付节点、监管账户分列。未给出的数字写 `【待填】`。实施条例第四十二条：使用者应当按照约定及时支付集体经营性建设用地价款，并依法缴纳相关税费。

支付路径：优先写集体经济组织账户或乡镇财政/交易平台监管账户。支付到村干部个人账户：红线。

定金：必须使用“定金”二字才讨论罚则；推算超过主合同标的额百分之二十的部分不产生定金效力。无核验引文不得把百分之二十写成现行法结论。

### 5.2 土地增值收益调节金

知识库要求约定调节金承担方。本次 MCP 未返回统一的全国比例文件。地方征收标准、缴纳义务人、是否从地价中预扣：标 `G#`，修改句要求写明承担方、缴纳时点、未缴对交地和登记的影响，不编造比例。

### 5.3 交付、开发与闲置

明确交地标准（净地或含地上物）、红线外道路供水供电由谁接通。因集体未完成土地整理导致延期动工：受让人立场锁定免责和工期顺延；出让人立场锁定受让人配合清场。

闲置土地处置办法第三十一条：集体所有建设用地闲置的调查、认定和处置参照该办法。修改句写明闲置认定机关、通知和收回程序，不得写成集体可任意收回。

土地管理法第六十六条：收回集体经营性建设用地使用权，依照双方签订的书面合同办理，法律、行政法规另有规定的除外。不按批准用途使用土地的收回，须在合同中写程序，不得写成“集体单方口头收回即生效”。

### 5.4 转让、出租、抵押

实施条例第四十三条：通过出让等方式取得的使用权依法转让、互换、出资、赠与或者抵押的，双方应当签订书面合同，并书面通知土地所有权人。最高年限、转让、抵押参照同类用途国有建设用地，法律、行政法规另有规定的除外。

文本要求每一次转让、抵押须再经成员大会同意：受让人立场标必须改或可优化（至少改为书面通知 + 合同另有约定的除外）；出让人立场可保留，但须与第四十三条“书面通知”并列，避免做成无期限否决权。本任务不展开担保或公司专项整案。

## 节点 6　格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 格式条款

示范文本或交易平台制式文本，订立时未与对方协商的，按格式条款审查提示说明。仅有网络勾选不得写成已尽提示义务。

### 6.2 强制规范

支持依据：民法典第一百五十三条；实施条例第四十一条；土地管理法第八十二条；城市房地产开发经营管理条例第三十九条。

| 情形 | 动作 |
| --- | --- |
| 未纳入规划条件、产业准入、环保要求 | 红线补入；告知条例“合同无效”风险，不代替裁判 |
| 农用地/宅基地伪入市、小产权房销售 | 停笔，不改写成可履行 |
| 改变工业/商业用途为住宅销售 | 红线；集体有权依合同解除并收回，程序须可执行 |
| 约定转让集体土地所有权 | 红线删除 |

禁止用已失效“效力性/管理性”口诀代替核验。挂靠、违法分包、以合法形式掩盖非法目的：不改写成有效履行结构。

## 节点 7　违约、征收、争议解决

1. 逾期付款、逾期交地、改变用途、闲置必须分别有可执行后果。只有“依法承担违约责任”视为必须改。
2. 构成违约不等于当然解除。法定或约定解除只点名催告和通知，不在本任务作出已解除结论。
3. 违约金不是必得金额；修改句避免“不得调整”或“按总价百分之三十必得”。
4. 征收补偿预设（框架核心）：合同期内国家征收的，地上附着物和青苗补偿、搬迁和停产停业损失与剩余年期使用权补偿的归属必须分列；土地补偿费与所有权相关部分归集体。不得写成“全部归受让人”或“全部归集体”而不拆项。征收整案材料转 `C端征收补偿材料整理`。
5. 争议解决：优先土地所在地法院可作为修改句，但不选定唯一法院充作法律意见。出现或裁或诉、机构不明：标待核。不动产纠纷可能涉及专属管辖：只标红旗。
6. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。
