# 集体建设用地使用权出让合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、已失效《物权法》、2004 年《土地管理法》第六十三条“集体土地不得出让”旧文当作现行规则。引用土地管理法第六十三条时，必须使用 2019 年修正、2020-01-01 施行文本；本次检索若只返回 2004 文本，记噪声并运行时重核。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **土地使用权 / 集体建设用地使用权出让合同** 的待签书面文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「集体建设用地使用权出让合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、国有出让评改、租赁或入股评改、入市批准代办、有效性保证。

## 本类型硬闸

1. **集体决议 / 村民程序**：出让方案须由本集体经济组织依法形成书面意见。已设立农村集体经济组织的，成员大会决定出让方案，须经全体成员三分之二以上同意；章程允许成员代表大会行使该职权的，须经全体成员代表三分之二以上同意。理事会过半数、村干部签字或“乡镇已同意”不得写成已完成民主程序。未设立集体经济组织、由村民委员会代行的，另核村民会议或村民代表会议，且不得用到会过半数替代法定成员多数。缺决议、签名页或公示痕迹：签署能力字段停止。
2. **入市条件**：标的须是规划确定为工业、商业等经营性用途、并已办理集体土地所有权登记的集体经营性建设用地。农用地、宅基地、公益事业用地不得经本类型合同“转成”建设用地。出让方案须报市、县人民政府；不得把已报送写成已经批准入市。
3. **与租赁切开**：核心给付是债权性使用、对价为租金、期限受二十年约束 → `集体建设用地使用权租赁合同·审查`。
4. **与出资入股切开**：对价是股权、集体成为股东或土地使用权作实缴出资 → `集体建设用地使用权出资入股合同·审查`。
5. **不按国有出让审**：出让人不是市、县人民政府或其自然资源主管部门 → 若实为国有出让，负触发 `国有土地使用权出让合同·审查`。禁止抄国有出让审查口径。
6. **规划条件、产业准入、生态环境保护要求必须入合同**：未依法纳入的，实施条例规定合同无效。修改句补入并作为附件；不得删除后放行。
7. **已成争转出；无文本转起草；已签履约转履约。** 小产权房、规避宅基地、农用地伪入市：只告知，不改写成可履行结构。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签出让合同正文，尚未签署，尚未成争，核心给付是集体土地所有权人将一定年期的集体经营性建设用地使用权有偿让与受让人并拟办不动产登记，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 出让人是市、县人民政府或自然资源主管部门，标的是国有建设用地 → `国有土地使用权出让合同·审查`；
- 核心给付是出租、租金、租期，或标题为租赁 → `集体建设用地使用权租赁合同·审查`；
- 对价是股权、集体作股东、土地使用权出资入股 → `集体建设用地使用权出资入股合同·审查`；
- 共同投资建设、利润分成且不设立出让使用权 → `集体建设用地合作开发合同·审查`；
- 宅基地、农村土地承包经营权或土地经营权流转 → 对应场景原子或 `承包地／土地经营权流转`，回 本套导航的类型切开步骤 重新定性；
- 无文本、本类型条件已谈妥、要出己方稿 → `集体建设用地使用权出让合同·起草`；
- 已签只问交地、付款、登记节点 → 本套导航的履约步骤；
- 已催告、已解除、已索赔、已立案或仲裁 → `或对应专项领域。` 或对应专项，不审诉讼策略。

挂靠、违法分包、规避限购、小产权房对外销售：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及附件版本；出让人主体资格；成员大会/村民会议决议；宗地权属与规划用途；出让方案是否已报市、县人民政府；规划条件、产业准入和环保要求；价款与调节金；不可接受事项；法域与拟签署日。缺立场或无可读书面文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

### 0. 签署状态与成果分流

无书面文本 → `集体建设用地使用权出让合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 争议领域。未签且目标是评改已有出让文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与主体一致才继续。国有出让、租赁、入股、合作开发、宅基地、承包经营权负触发。

### 2. 主体与集体决议

出让人资格；成员大会/村民会议书面意见；签名页与公示。理事会或村干部单独决定不得放行。

### 3. 入市条件与标的

经营性用途、所有权登记、规划条件、禁止农用地/宅基地/住宅销售。承包经营权冲突标缺口。

### 4. 方案、公开交易与生效

方案报市、县人民政府；招拍挂或协议；备案和登记写成义务期限，不写成已经完成。

### 5. 价款、调节金、交付与开发

支付路径、监管账户、调节金承担方；交地与开工竣工；闲置和改变用途的收回程序。

### 6. 强制规范

规划条件/产业准入/环保未入合同；擅自出让农用地；小产权房。不改写成可履行规避结构。

### 7. 转让、抵押、征收与争议

二级市场流转是否须再经集体书面同意；征收补偿预设；争议解决不选唯一法院充作意见。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、补假决议、把农用地/宅基地/小产权房改成可履行结构、删除规划条件仍要放行、保证有效或一定办证。
- `字段停止`：法域、2019 年第六十三条全文、地方调节金、入市细则、表决人数未核验。
- `目标停止`：主目标已变为从零起草、履约交底、入市报批代办、诉讼策略或租赁/入股整案。
