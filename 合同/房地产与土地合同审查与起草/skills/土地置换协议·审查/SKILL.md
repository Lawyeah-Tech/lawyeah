# 土地置换协议·审查

## 任务目标

在单一立场下，只审查 **土地使用权 / 土地置换协议** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「土地置换协议·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证新证或财政退差一定办成、保证置换当然豁免招拍挂。

## 本类型硬闸

1. **批准**：收回国有土地使用权，须由有关人民政府自然资源主管部门报经原批准用地的人民政府或者有批准权的人民政府批准（《土地管理法》（2019 修正）第五十八条）。置换方案未经有权机关批准的，不得写成签字盖章立即全面生效。法律、行政法规规定应经其他机关批准后生效的行政协议，未获批准则未生效（法释〔2019〕17 号第十三条）。开发区管委会、招商部门、平台公司单独签署且无市、县自然资源主管部门确认的，不得写成已具备收回与供应职权。
2. **价值补差**：新旧两宗必须同一评估基准日、可比评估方法。等值或差额补缴／退还须落到金额或公式、支付时限、逾期后果。划拨旧地换出让新地必须另计出让金，不得写成置换即豁免。新地协议供应价格不得低于可核验的协议出让最低价口径。评估未附或基准日不一致：字段停止，不编造差价。
3. **权属变更**：旧建设用地使用权注销与新建设用地使用权登记分步写清。建设用地使用权自登记时设立（民法典第三百四十九条）；消灭应及时注销并收回权属证书（第三百六十条）。禁止“直接过户”“签字即换证”“交旧证即取得新地”。旧地有抵押、查封、租赁的，须取得同意并设计旧押解除与新押衔接，不得让权利悬空。
4. **与出让／转让切开**：正像是行政机关依法收回原宗地，并以另一宗可供应地块作为补偿或安置。仅有一块新地、对价是出让金、路径是招拍挂或普通协议出让、无旧地收回 → `国有土地使用权出让合同·审查`。两个民事主体转让或互换已取得的建设用地使用权、无行政收回 → `国有土地使用权转让合同·审查`。禁止打开或复制上述两原子的 method。不得删掉招拍挂成交条款或民事转让价款后硬套本技能。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签土地置换或收回与置换正文，尚未签署，尚未成争，核心给付是行政收回旧地并以新地补偿或安置，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只有新地出让、出让金、竞买、成交确认或普通协议出让，无旧地收回 → `国有土地使用权出让合同·审查`；
- 两个民事主体买卖、互换已登记建设用地使用权，对价是转让价款或互找差价，无行政机关作为收回方 → `国有土地使用权转让合同·审查`；
- 用地预申请、意向拿地、非出让人勾地、联合勾地 → `用地预申请协议·审查`、`与非出让人签订的勾地协议·审查` 或 `联合勾地协议·审查`；
- 一级市场联合竞买或联合拿地主文件 → `一级市场联合拿地类合同·审查`；
- 以股权间接取得土地 → `以股拿地·审查`；
- 合作开发、联建，权属不因收回而消灭 → `房地产合作开发类合同·审查`；
- 房屋或集体土地征收决定及征收补偿协议 → 征收或行政专项，不启动本任务；
- 无文本、本类型条件已谈妥、要出己方稿 → `土地置换协议·起草`；
- 已签只问交地、补差或办证节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、复议、诉讼或仲裁 → `或对应专项领域。` 或房地产／行政专项。

以置换为名给无证、违法占地或经营性用地规避招拍挂：只出告知，不改写成可履行供应结构。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方是否为市、县自然资源主管部门；全文及附件／评估／批复／规划条件版本；收回法定事由；批准是否已作出或仅有意向；旧地权属与负担；新地四至、用途、容积率、是否经营性用地；两宗评估与差价；划拨或出让属性；权属变更顺序；抵押银行态度；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `土地置换协议·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议或行政／房地产专项。未签且目标是评改已有土地置换文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。出让、转让／互换、征收、勾地、合作开发负触发。

### 2. 批准与主体

有权机关、收回法定事由、行政协议批准生效。管委会单独签署不得写成已有供应职权。

### 3. 价值补差

两宗评估、差价公式、划拨补出让金、协议出让最低价。

### 4. 权属变更

注销与新登记分步；抵押衔接；禁止直接过户。

### 5. 新地特定化与招拍挂红旗

规划条件锁定；经营性用地不得以置换规避公开出让。

### 6. 格式条款与强制规范

无核验引文则法律结论字段停止。规避招拍挂、无证置换不得改成可履行。

### 7. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签批准、保证有效、把出让或转让改成置换外壳、把无证占地或经营性用地规避招拍挂改成可履行。
- `字段停止`：法域、动态规则、批准文号、评估采信、闲置或污染调查、抵押银行态度未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
