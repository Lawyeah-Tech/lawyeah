# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的面积、差价、批准文号；把已失效《合同法》、1994 年房地产管理法第十九条或 1999 年闲置土地处置办法写入结论；保证新证、财政退差或批准一定办成；写“置换当然豁免招拍挂”；写“未批准也已生效”；写“直接过户即取得新地”；把出让或转让文本当成已完成的本类型审查。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查土地置换协议（土地使用权）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、1994 年房地产管理法第十九条或 1999 年闲置土地处置办法时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `土地使用权`，子级 `土地置换协议`。定性理由、易混切开结果（出让 / 转让或互换 / 征收 / 勾地 / 合作开发）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、批准、负担与文本版本

主体表：签约名、履行名、补差／退差名、发票名、授权签字人。批准表：有权人民政府、自然资源主管部门、会议纪要或批复是否已作出。负担表：抵押、查封、租赁、闲置调查、污染线索、共有。版本表：正文、评估、规划条件书、批复、同意函、聊天确认；冲突并列。

## 5. 补差、权属变更与给付闭环

两宗评估基准日是否一致；差价公式与时限；划拨是否另计出让金；旧地腾退与新地交付是否互为前提；注销登记与新登记是否分步；是否出现“直接过户”。缺口标 `G#`。不输出招拍挂竞买主路径，不输出民事转让投资开发条件主路径。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹。无证置换、无批准拟制生效、经营性用地规避招拍挂不得写成可放行。强制规范只按第一百五十三条及行政协议司法解释第十二条区分是否导致无效，不用失效口诀。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把招拍挂成交或民事转让价款直接写成“置换类型”而不问是否行政收回。

## 9. 谈判与签署提醒

谈判顺序：先红线（实为出让或转让、无批准拟制生效、无具体新地、直接过户、规避招拍挂、先交旧地无回溯），再必须改（评估与差价、登记分步、抵押同意、划拨补出让金、开竣工顺延），最后可优化。签署提醒：有权机关印章、原证载权利人、共有人和抵押权人书面同意、批准文件或生效条件、两宗评估、规划条件书、红线图。不指导倒签或把未批准写成已生效。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书或效力保证，也不是出让、转让、征收或勾地安排。
