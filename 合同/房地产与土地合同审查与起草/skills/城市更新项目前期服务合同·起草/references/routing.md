# 边界与路由

本技能只审查 **房地产合同 / 城市更新项目前期服务合同** 的待签文本。村集体委托服务公司做意愿征集、摸底测绘、方案编制和招商组织，对价是服务费，不当然取得实施主体或开发权。中文展示名是「审查城市更新项目前期服务合同（房地产合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止把本任务做成咨询审查或拆迁委托审查。
