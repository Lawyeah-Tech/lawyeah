# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的价款、面积、日期；把已失效《合同法》、《物权法》、《房屋登记办法》、1986/2004 年未修正《土地管理法》写入结论；保证登记或乡镇批准一定办成；把租赁运营、合作开发、商品房或二手房文本当成已完成的本类型审查；写“签字即取得宅基地使用权并可对抗第三人”；写“未登记则本合同未生效”；把非本集体成员改成可履行过户；把报批不成改成永久使用权租赁。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查宅基地房屋买卖合同（集体经济组织内部）（土地使用权）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、《物权法》、《房屋登记办法》、1986/2004 年未修正《土地管理法》或 1991 年实施条例时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `土地使用权`，子级 `宅基地房屋买卖合同（集体经济组织内部）`。定性理由、易混切开结果（租赁运营 / 合作开发 / 商品房 / 二手房 / 集体经营性建设用地 / 承包地）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。对外转让写停笔告知，不填可履行过户结构。

## 4. 主体、成员身份、共有与文本版本

主体表：签约名、履行名、付款名、收款名、授权签字人。成员表：双方是否载入同一农村集体经济组织成员名册；同村不同组时土地是否由村级统一经营管理。共有表：户内共有人是否全体签署或出具同意书。版本表：正文、权属证书、户口簿或成员名册、家庭同意书、村集体书面意见、四至示意图、聊天确认；冲突并列。

## 5. 标的一体、程序与给付

房屋与占用范围内宅基地使用权是否一体；所有权仍归集体是否写清；证载与现状；抵押查封争议规划；集体书面同意与乡镇审核写成义务或条件而非已完成；登记与合同成立切开；价款构成、定金、腾空／钥匙／证件、户口迁出、征收预切。缺口标 `G#`。不输出商品房网签、按揭或二手房资金监管口径，不输出永久租赁或合作分房口径。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹。对外转让、阴阳长期租赁、伪造成员或批准不得写成可放行。强制规范只按第一百五十三条区分是否导致民事行为无效，不用失效口诀。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把永久租赁或商品房过户直接写成“本类型补救条款”。

## 9. 谈判与签署提醒

谈判顺序：先红线（非本集体成员、阴阳永久租赁、签字即物权、共有人未全体签署、明知查封或无权处分），再必须改（成员身份附件、一体标的、登记与生效切开、价款节点、集体同意作为条件、户口迁出、征收预切），最后可优化。签署提醒：证载权利人亲签、户内共有人全部签署或同意书、村集体见证栏、授权书须含处分本户宅基地房屋、证书复制件、成员名册或户口簿页、四至示意图。不指导倒签或把对外转让改成可过户。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书或效力保证，也不是租赁运营、合作开发、商品房或二手房安排。
