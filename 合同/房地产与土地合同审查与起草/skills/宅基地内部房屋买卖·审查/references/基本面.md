### **一、 合同类型（法律性质）分析**
1. **法律定性**：宅基地房屋买卖合同属于**非典型买卖合同**。根据“地随房走”原则，农村房屋的转让必然涉及宅基地使用权的流转 。由于宅基地属于集体所有，其使用权具有身份属性，故此类合同在法律性质上受《民法典》、《土地管理法》及相关土地政策的高度规制 。

2. **效力认定原则**：
* **有效情形**：发生在本集体经济组织**成员内部**（如同村村民）之间的房屋买卖，且符合“一户一宅”原则的，通常认定有效 。
* **原则无效**：向本集体经济组织以外的人员（尤其是**城镇居民**）转让的合同，因违反《土地管理法》关于宅基地身份限制的强制性规定，原则上认定无效 。
* **特殊有效转化**：若在起诉前，宅基地因征收已转为国有土地，或买受人已将户口迁入并加入该集体经济组织，合同可认定为有效 。

3. **适用场景**：主要适用于农村拆迁腾退、村民进城落户或同一村集体内部调剂住房等场景。

### **二、 合同主体（交易对手）分析**
1. **主体适格性（核心）**：
* **出卖人**：必须是拥有合法宅基地使用权及房屋所有权的农村村民 。
* **买受人**：原则上仅限于**同一集体经济组织成员** 。
2. **身份识别与范围**：
* **同村不同组**：若该村土地由村集体统一经营管理，同村不同村民小组的村民通常被视为同一集体经济组织成员，具备购买资格 。
* **禁止对象**：严禁城镇居民在农村购置宅基地及房屋 。
3. **关联主体权益**：
* **家庭共有**：农村房屋通常为家庭成员共有，签约时需确保所有共有权人（包括配偶、成年子女等）均签字同意，避免产生无权处分纠纷 。
* **集体监督**：转让行为应当征得本集体经济组织（如村委会或经济合作社）的同意 。

### **三、 合同标的（交易对象）分析**
1. **标的一体性**：合同标的不仅指地上建筑物（房屋），还包括该房屋占有范围内的宅基地使用权，二者不可分割 。
2. **权属核查**：
* **权利证明**：需核实《集体土地使用证》、《房屋所有权证》或最新的《不动产权证书》。
* **现状核实**：确认房屋是否存在违建、是否处于征收补偿范围、是否存在抵押（虽受限但实践中存在抵押备案）等权利负担。
3. **禁止流转情形**：
* 权属有争议的土地及房屋。
* 司法或行政机关依法裁定查封的房产。
* 不符合土地利用总体规划或村庄规划的建筑。

### **四、 合同程序（交易步骤）分析**
1. **内部审批程序**：
* **集体同意**：根据《不动产登记暂行条例》及地方指引，宅基地流转须经本集体经济组织成员会议或村民代表会议同意 。
* **乡镇审批**：转让宅基地及房屋需报乡（镇）人民政府审核批准 。
2. **法定登记程序**：
* **变更登记**：虽然登记不是合同生效要件，但为了完成物权变动并对抗第三人，双方应共同前往不动产登记机构办理宅基地使用权及房屋所有权转移登记 。
* **注销旧证**：原宅基地使用者在转让或取得新住房时，需申请注销原土地使用证 。
3. **税费缴纳**：买受人需按照规定缴纳契税等相关交易税费，部分地区需向集体经济组织缴纳一定的土地增值收益金 。

### **五、 交易结构设计（风险规避方案）**
1. **风险告知与承诺**：
* 在合同中明确约定买受人的成员身份状况，并由出卖人承诺其已取得家庭共有人的授权及集体经济组织的同意。
2. **补偿与返还机制（针对无效风险）**：
* **违约责任强化**：约定若因一方原因导致合同被认定无效（如出卖人反悔主张无效），违约方需赔偿对方信赖利益损失，包括房屋增值收益损失 。
* **添附补偿**：约定合同无效时，出卖人需对买受人进行的装修、翻建、扩建等添附价值进行全额补偿 。
3. **征收补偿权益分配**：
* 鉴于农村房屋易涉及征收，建议在合同中明确约定：若未来发生征收，拆迁补偿款、安置房指标等利益在双方之间的具体分配比例 。
4. **文本形态选择**：
* 建议采用“**书面买卖合同 + 村委会见证盖章 + 共有权人放弃权利声明**”的成套结构，提高交易在集体内部的确定性。

### **六、 宏观风险预警与尽调指引**
1. **高频争议点**：
* 出卖人因土地升值、拆迁补偿巨大利益驱动，利用“买受人非本村成员”等理由主张合同无效 。
* 同村不同组村民身份认定的效力争议 。

2. **尽职调查清单**：
* **户籍核查**：核对买卖双方户口本，确认是否属于同一农村集体经济组织成员 。
* **政策核查**：调查当地政府是否允许宅基地流转，以及是否有特定的准入条件。
* **公示核查**：确认转让行为是否已在村集体内部进行公示并记录备案 。

3. **根本性风险预警**：
* **“阴阳合同”风险**：严禁通过名为“长期租赁”实为“买卖”的方式规避法律，超过20年的租赁部分无效且可能无法获得拆迁安置权益 。
* **一户多宅禁止**：若买受人购买后将形成“一户多宅”，将面临无法办理登记及被集体收回的风险 。
