# 边界与路由

本技能只审查 **土地使用权 / 宅基地房屋买卖合同（集体经济组织内部）** 的待签、双方均为同一农村集体经济组织成员的房屋连同占用范围内宅基地使用权让与文本。中文展示名是「审查宅基地房屋买卖合同（集体经济组织内部）（土地使用权）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或复制 `普通商品房买卖价款五证网签主结构→`、`文本是二手房存量房买卖本约，即便标题写资金监管→`、`宅基地房屋租赁运营·审查`、`宅基地合作开发合同·审查` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 租期、租金、转租、委托运营、民宿托管、分成、永久或终身占用 | `宅基地房屋租赁运营·审查` |
| 一方出地、一方出资改建新建，按面积分房或固定收益 | `宅基地合作开发合同·审查` |
| 开发商预售／现售、商品房买卖、预售许可、网签、按揭、面积误差 | `普通商品房买卖价款五证网签主结构→` |
| 国有土地存量房、城市二手房、限购核验、资金监管、物业交割 | `文本是二手房存量房买卖本约，即便标题写资金监管→` |
| 集体经营性建设用地出让 | `集体建设用地使用权出让合同·审查` |
| 集体建设用地使用权租赁 | `集体建设用地使用权租赁合同·审查` |
| 集体建设用地使用权出资入股 | `集体建设用地使用权出资入股合同·审查` |
| 集体建设用地合作开发 | `集体建设用地合作开发合同·审查` |
| 国有土地使用权转让 | `国有土地使用权转让合同·审查` |
| 承包地或土地经营权流转 | 农村土地承包专项；材料整理可点 `承包地／土地经营权流转` |
| 征收补偿材料或已启动征收争议 | `C端征收补偿材料整理` 或争议／征收专项 |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或对应专项领域。` 或对应专项领域 |
| 城镇居民或非本集体成员购买 | 不启动本类型实体放行；只告知无效风险；用户要改成可过户则整体停止 |
| C 端大众快检 | 只分流，不回改 |

宅基地房屋买卖正文里夹带一小段真实、独立且不超过二十年的出租：租赁专章交接 `宅基地房屋租赁运营·审查`；内部买卖条款可继续审。用户坚持本技能把租赁运营、合作开发、商品房或二手房整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
