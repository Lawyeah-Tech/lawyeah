# 边界与路由

本技能只审查 **土地使用权 / 联合勾地协议** 的待签、挂牌前企业间资源互换并锁定联合竞买身份与份额的文本。中文展示名是「审查联合勾地协议（土地使用权）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 对方是市县自然资源主管部门；预申请、用地预审、官民招商承诺 | `用地预申请协议·审查` |
| 与非出让人单方勾地、居间撮合、只付勾地费或渠道费、不锁联合竞买身份与份额 | `与非出让人签订的勾地协议·审查` |
| 市县自然资源主管部门作为出让方；成交确认书后的出让合同 | `国有土地使用权出让合同·审查` |
| 宗地已公告、无产业勾地或一级关系前置，主文件就是联合体竞买协议 | `一级市场联合拿地类合同·审查` |
| 已持证国有土地使用权转让 | `国有土地使用权转让合同·审查` |
| 已设项目公司，主给付是买股权取得土地控制权 | `以股拿地·审查` |
| 已取得或即将取得土地使用权后，共同投资、共享利润、共担风险开发建设 | `房地产合作开发类合同·审查` |
| 一方出资、另一方只收代建费或按进度取费，不锁竞买份额 | `委托代建合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或对应专项领域。` 或对应专项领域 |
| 土地出让调查、串通竞买查处、刑事立案 | 土地／行政／刑事专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

联合勾地正文里夹带一小段拍后开发原则或预签股东协议：专章交接 `房地产合作开发类合同·审查` 或分条改写；挂牌前竞买与份额条款可继续审。用户坚持本技能把单方勾地、已挂牌联合拿地或合作开发整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
