# 联合勾地协议·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **土地使用权 / 联合勾地协议**，出稿后用本类型硬闸自审，输出可编辑草稿、未决项、自审风险表和自审后修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「联合勾地协议·起草」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证一定竞得、保证出让合同一定签成。

## 本类型硬闸

1. **联合竞买／份额必须闭合**：正像是两家以上非出让人企业，在目标宗地成交前互换产业准入、一级关系或操盘能力与资金，并锁定竞买身份与份额。身份只能是联合体、新设项目公司或一方名义竞买三者之一。保证金、出让金、拍后股权或权益份额必须写成可核对数字或公式。缺一项不得写成“已经联合拿地”。
2. **举牌授权与最高限价**：必须写明土拍现场举牌人、授权范围、最高限价、超授权报价的归属与解除后果。未经需求方书面指令，资源方不得擅自报价或撤回竞买申请。
3. **拿地后合作开发切开 `房地产合作开发类合同·审查`**：本约只审挂牌前资源互换、联合竞买安排和拍后退出／交割路径。正文主轴变成共同投资、共享利润、共担风险的开发建设、施工发包、销售去化、面积分配 → 负触发 `房地产合作开发类合同·审查`。不得删掉开发条款后硬套本技能。
4. **禁止内定／串通／确保拿地**：写“确保摘牌”“互不抬价”“安排陪标人”“排斥其他竞买人”的部分只告知，不改成可履行。国有建设用地招拍挂适用国土资源部令第 39 号，不自动套用《招标投标法》。恶意串通竞得结果无效（第 39 号令第二十五条）；民事上走民法典第一百五十三条、第一百五十四条。
5. **标的不是现成土地使用权**：标的是参与招拍挂的机会和拍后项目公司权益，不是已持证地块过户。已持证再转 → `国有土地使用权转让合同·审查`。已设项目公司、买股权拿地 → `以股拿地·审查`。
6. **三极端退出必须可执行**：拍不到、成交价超限、规划或产业条件变更，须有无责或按过错解除、保证金分担、沉没成本清理。禁止只写“双方协商解决”。
7. **禁止抄 `与非出让人签订的勾地协议·审查`**：单方付费换信息、关系或“帮你拿地”、不锁联合竞买份额 → `与非出让人签订的勾地协议·审查`。禁止打开或复制其 method。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签联合勾地正文，尚未签署，尚未成争，核心给付是挂牌前企业间资源互换并锁定联合竞买身份与份额，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 对方是市县自然资源主管部门，文本对应预申请或招商承诺 → `用地预申请协议·审查`；
- 与非出让人单方勾地、居间撮合、不锁竞买身份与份额 → `与非出让人签订的勾地协议·审查`；
- 市县自然资源主管部门作为出让方的出让合同 → `国有土地使用权出让合同·审查`；
- 宗地已公告、无产业勾地前置，主文件就是联合体竞买协议 → `一级市场联合拿地类合同·审查`；
- 已持证国有土地使用权转让 → `国有土地使用权转让合同·审查`；
- 已设项目公司、以股权取得土地控制权为主给付 → `以股拿地·审查`；
- 已取得或即将取得土地使用权后，长期共担开发风险 → `房地产合作开发类合同·审查`；
- 一方出资、另一方只收代建费、不锁竞买份额 → `委托代建合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁，或土地出让／串通竞买已立案查处 → `或对应专项领域。` 或土地／争议专项。

围标、陪标、商业贿赂、权力寻租：只出告知，不改写成可履行结构。

## 建立起草坐标

确认：使用者与授权；单方立场；相对方角色（资金／开发需求方，或产业／资源提供方）；全文及附件／授权委托书／章程草案／预签股权文件版本；目标地块是否已公告；竞买身份；保证金与出让金份额；举牌人与最高限价；产业资质或一级关系如何写；资金是否走监管账户；拍后是退出交割还是共同开发；出让条件是否限制股权变更；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 起草模式

本原子只承担本类型起草。待签评改转 `联合勾地协议·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。商业数字未给用 `【待填】`。

按框架六步落稿。本类型硬闸改成下列起草必写 / 附件必附 / 禁止出现。

### 起草必写

- 竞买身份在联合体、新设项目公司、一方名义竞买三者中锁定其一；保证金、出让金、拍后股权或权益份额写成可核对数字或公式。
- 写明土拍现场举牌人、授权范围、最高限价、超授权报价的归属与解除后果；未经需求方书面指令，资源方不得擅自报价或撤回竞买申请。
- 本约只写挂牌前资源互换、联合竞买安排和拍后退出／交割路径；标的是参与招拍挂的机会和拍后项目公司权益。
- 拍不到、成交价超限、规划或产业条件变更，须有无责或按过错解除、保证金分担、沉没成本清理。

### 附件必附

- 举牌授权委托书。
- 章程草案或预签股权文件。
- 产业发展监管协议或出让条件限制股权变更的摘录（如有）。

### 禁止出现

- “确保摘牌”“互不抬价”“安排陪标人”“排斥其他竞买人”；围标陪标只告知，不改成可履行。
- 把本约写成已持证地块过户，或把开发建设、施工发包、销售去化、面积分配写成主轴。
- 退出只写“双方协商解决”。
- 单方付费换信息、关系或“帮你拿地”、不锁联合竞买份额（那是非出让人勾地）。

出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 本任务起草模式；已签履约 → 本套导航履约步骤；已成争 → 合同争议或土地专项。未签且目标是评改已有联合勾地文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。预申请、单方勾地、出让合同、已挂牌联合拿地、股权拿地、合作开发、代建负触发。

### 2. 联合竞买身份与份额

三者择一；保证金、出让金、拍后权益份额闭合。

### 3. 举牌授权、限价与资金路径

授权委托书、最高限价、监管账户、通道模式。

### 4. 串通、确保拿地与本约性

删除或红线内定条款；本约而非意向书。

### 5. 三极端退出与拍后路径

拍不到／超限／规划变更；拍后退出不得直接写成合作开发。

### 6. 出让限制、国资与产业监管

锁定期、国资决议、产业发展监管协议作附件。

### 7. 格式条款与强制规范

无核验引文则法律结论字段停止。串通条款不得改成可履行。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证一定竞得、把围标陪标或商业贿赂改成可履行并放行。
- `字段停止`：法域、动态规则、联合体资格细则、国资评估、产业监管协议终稿、出让锁定期未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
