# 边界与路由

本技能只审查 **房地产合同 / 实施主体监管协议**。

必须同时读出：区级以上城市更新主管部门（或受其委托的机构）与已确认实施主体；核心给付是公共贡献义务加全过程监管。标题叫“更新合作监管”但双方其实是村企分成、股东对价或出地出钱的，不得留在本技能做实体结论。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或标题监管协议、核心给付明显不是公共贡献监管 | 本套导航的类型切开步骤 |
| 村集体与合作企业，补偿、物业返还、分成主导 | `城更合作（村集体与企业）·审查`；专业版未收录该 P1 时输出 `unavailable`，不得硬套本技能改成分成 |
| 开发商与前期服务公司，服务费和申报代理主导 | `城更合作（开发商与前期服务）·审查` |
| 股权合作换更新项目控制权 | `城更股权合作·审查` |
| 更新意向、排他谈判、框架 | `城市更新项目意向合作协议·审查` |
| 更新前期服务本约 | `城市更新项目前期服务合同·审查` |
| 国有土地使用权出让，出让金与交地主导 | `国有土地使用权出让合同·审查` |
| 独立资金监管专户拨付主文件 | `资金监管协议·审查` |
| 对被拆迁人／被征收人的补偿安置本约 | `拆迁补偿安置协议·审查` |
| 出地出钱、共担风险、联合操盘、隐名参建 | `房地产合作开发类合同·审查` 或 `一方出地一方出钱联建·审查` 至 `隐名参建联建·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、问移交、保函释放、报批进度 | 本套导航的履约步骤 |
| 已成争 | 合同争议或行政争议领域；不写复议申请书、起诉状 |
| 用户只要保证金或税收补足终局数字 | 测算技能或人工精算；本技能只审条款 |
| C 端大众快检 | 只分流，不回改 |

同一文本既写监管又写村企分成：按签约主体和主给付切开。主管部门与项目公司的公共贡献监管留本技能；村企利益分配另纸转更新合作原子。两可且无法判断：负触发引擎，不灌两套知识。

本约引用资金监管协议或安置协议：只审引用和挂钩，专户或补偿整案转对应原子。

伪造确认、规避限购、把应移交公建改成可售或先抵再移交、删除挂钩以便先卖：停笔告知，不改写成可履行文本。

专业版未收录的 P1 场景不会安装本原子。若用户拿本类型文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。

禁止在正文写半截 Skill ID。转出时必须写完整 ID，例如 `城更合作（村集体与企业）·审查`、`国有土地使用权出让合同·审查`、`房地产合作开发类合同·审查`。
