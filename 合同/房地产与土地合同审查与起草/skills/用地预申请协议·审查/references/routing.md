# 边界与路由

本技能只审查 **土地使用权 / 用地预申请协议** 的待签、与市县自然资源主管部门之间就公开出让所作的预申请文本。中文展示名是「审查用地预申请协议（土地使用权）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 相对方为管委会、平台公司、招商局、储备中心等非出让人；主给付是协调供地或招商锁定 | `与非出让人签订的勾地协议·审查` |
| 两家以上企业联合竞买、产业换地、先勾后转项目公司股权 | `联合勾地协议·审查` |
| 已确定竞得人；出让金、交地、登记、使用条件、成交确认或中标通知 | `国有土地使用权出让合同·审查` |
| 土地置换、指标互换 | `土地置换协议·审查` |
| 一级市场联合拿地主文件 | `一级市场联合拿地类合同·审查` |
| 已取得的国有建设用地使用权再转让 | `国有土地使用权转让合同·审查` |
| 以获取土地为目的的股权收购 | `以股拿地·审查` |
| 房地产合作开发 | `房地产合作开发类合同·审查` |
| 委托代建 | `委托代建合同·审查` |
| 集体建设用地使用权出让，或未征收集体土地直接供地 | `集体建设用地使用权出让合同·审查` 或整体停止 |
| 协议出让方案（非经营性且唯一意向） | 不按本技能改成预申请外壳；转引擎或 `国有土地使用权出让合同·审查` 判断 |
| 建设项目用地预审、选址预审、农转用报批 | 不启动本任务；提示这是审批环节不是预申请协议 |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或对应专项领域。` 或对应专项领域 |
| 行政诉讼、复议或纪检已立案 | 行政或争议专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

预申请正文里夹带一小段产业投资监管或代建安排：专章交接对应原子；预申请条款可继续审。用户坚持本技能把勾地、联合勾地或出让合同整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
