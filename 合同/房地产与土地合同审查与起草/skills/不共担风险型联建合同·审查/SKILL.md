# 不共担风险型联建合同·审查

## 任务目标

在单一立场下，只审查 **房地产合同 / 不共担风险型联建合同** 的待签文本：先完成固定回报穿透，再按穿透后的真实性质输出风险表、可回给对方的修改句或红线、税负与行政程序提醒、谈判与签署提醒。

本技能类型锁死。不扫描其他合同类型。场景分层为 **P1**。

`depends-on` 为空。不要求先跑导航。

不交付：他类型起草、履约交底、争议文书、有效性或税负/过户保证。**禁止按共担风险联建改完。**

## 工作边界

正触发：已有可读待签文本要评改，；尚未签署，尚未成争；标题或陈述为联建、联合开发、合作建房；至少一方不承担经营风险，只收取固定利益（固定货币、固定房屋、固定收益或长期使用权）。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 双方共同投资、共享利润**并且**按约定分担亏损/超支，无保底、无论盈亏或固定回报 → 转 `共担风险型联建合同·审查`，不得在本任务补共担条款后当作本类型审完；
- 文本是无联建外观的纯土地使用权转让、纯借款、纯商品房买卖或纯租赁 → 转 本套导航的类型切开步骤 或对应专项，不套本类型穿透表充作他类审查；
- 用户只要出资结构/操盘分工、且风险共担已闭合 → `一方出地一方出钱联建·审查`、`“双方出地”型联建合同·审查`、`一方操盘型联建合同·审查` 等出资或操盘原子（不可用则引擎）；
- 无文本、本类型条件已谈妥、要出己方稿 → `不共担风险型联建合同·起草`；
- 已签只问出资日、分房日、还款留痕 → 本套导航的履约步骤；
- 已成争（催告、解除、索赔、诉讼仲裁）→ `或对应专项领域。` 或金融/房地产专项，不在本任务做效力或返还结论。

挂靠、违法分包、规避土地转让/预售/限购/金融特许：只出告知，不改写成可履行结构。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成：

1. **固定回报穿透（第一道实体闸）**。先摘录谁不担风险、固定利益是什么，再归入四分支之一，禁止停在“名为联建”：
   - 出地方不担经营风险、只收固定利益 → 按土地使用权转让审（2020 年解释第 21 条）；
   - 出资方不担风险、只分配固定数量房屋 → 按房屋买卖审（第 22 条）；
   - 出资方不担风险、只收取固定数额货币（本息/保底） → 按借款审（第 23 条）；
   - 出资方不担风险、只以租赁或其他形式使用房屋 → 按房屋租赁审（第 24 条）。
   判断依据是核心给付，不是标题。禁止引用 2005 年解释旧第 24–27 条号当现行号。
2. **与共担风险切开**。真共担（共投、共享、共亏，无保底）转 `共担风险型联建合同·审查`。禁止为“看起来像联建”而写入按比例分担亏损、联合管委会共签、取消保底改分红。知识库框架里的“风险修正/参与决策”是改类型，本技能不得执行。
3. **按真实性质闭环，不按联建空话放行**。转让要锁土地四至、对价、过户与税费；买卖要锁房号/面积/交付/预售许可；借款要锁本金、期限、利率、还款与增信；租赁要锁租期、租金、交付与备案。缺数字用 `【待填】`。
4. **25% 与划拨不是当然无效句**。出让地未达开发投资总额 25%、或划拨地未经批准：标行政过户/审批障碍和履行不能风险。2020 年解释已删除原第 9、11、16 条。不得写“未达 25% 合同必然无效”，也不得写“不影响过户”。民法典第 215 条：未办物权登记不当然影响合同效力。
5. **借款利率与放贷资格**。穿透为借款后，约定利率超过合同成立时一年期 LPR 四倍的部分不得写成可强制执行；疑似未取得放贷资格、面向不特定对象营利放贷：字段停止或整体停止，不包装成合法联建。禁止用 1990 年联营解释写“企业间借贷一律无效”。
6. **税负与对外效力必须点名**。穿透后税种可能从“合作分成”变为土增税、契税、增值税或利息所得税。内部“风险由操盘方承担”不当然对抗政府、债权人、购房人或侵权受害人。
7. **分房即预售红旗**。未取得商品房预售许可却以固定房屋作为出资对价：不得改成可履行预售。用户坚持包装：整体停止。

必须有修改句。禁止只打红黄绿。每个风险回链文本位置。

## 判断节点

以 [审查方法](references/method.md) 为准。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。交付按 [输出合同](references/output-contract.md)。边界见 [路由](references/routing.md)。

入口（细节以 method 为准）：

0. 签署状态分流：已成争 → 争议；无文本且本类型条件已谈妥 → `不共担风险型联建合同·起草`；已签履约 → 本套导航履约步骤。
1. 类型切开：不共担固定回报才留本任务；真共担转 `共担风险型联建合同·审查`。
2. 固定回报四分支：转让 / 买卖 / 借款 / 租赁。
3. 主体、国资决议、土地权利人、职业放贷、资金来源。
4. 土地/房屋锁定、权利负担、固定利益可执行性。
5. 批准、登记、过户、预售许可写成条件或期限，不写成已经完成。
6. 对价、利率四倍、税款承担、增信与退出。
7. 格式条款；强制规范走通则解释第 16 条；规避监管停笔。
8. 按框架六步出**符合真实性质**的修改句，不改成共担联建。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；用户坚持伪造倒签、补假批准或假预售证；以联建规避转让/预售/限购/金融特许；要求保证不被穿透或保证有效；要求写成共担外观但保留保底。
- `字段停止`：土地证书与负担、25%/划拨批准、预售许可、利率与 LPR、资金来源、国资决议未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或用户确认真实意愿是共担风险联建。

生存级出资或个人无限连带且用户拒绝升级：停止“可以签署”建议。
