# 城市更新项目前期服务合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、《民法通则》、《民法总则》、《加工承揽合同条例》、《城市房屋拆迁管理条例》或《城市房屋拆迁单位管理规定》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **房地产合同 / 城市更新项目前期服务合同** 的待签文本：村集体经济组织（或依法代行职能的村民委员会）委托专业服务公司，完成更新意愿征集与表决协助、权属与房屋摸底测绘、更新方案/可行性研究/补偿方案初稿、招商文件编制与公开引入组织。输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「城市更新项目前期服务合同·审查」。本技能不代替审查城市更新合作合同、股权合作、意向合作、实施主体监管、拆迁委托或普通咨询。

`depends-on` 为空。不要求先跑导航。

不交付：开发商与前期服务公司合作整案；村集体与合作企业开发整案；股权合作整案；意向合作整案；实施主体监管整案；拆迁委托或拆迁补偿安置整案；普通咨询/技术咨询/工程咨询整案；他类文本审查；从零起草；履约交底；诉讼或仲裁策略；有效性保证；可履行的实施主体锁定或招商操纵结构。

## 本类型硬闸

1. **前期服务 vs 实施主体**：本约性质是协助与顾问，把分散更新意愿做成可申报、可招商的熟化项目。不得把“完成前期服务”写成“乙方当然成为实施主体、合作企业或取得开发权、土地使用权”。修改句只拆转化、补公开招商结果为准；不把本约改成更能锁实施主体的结构。
2. **与合作 / 股权合作切开**：核心给付变成共同投资、建设分红、持股开发、锁死后续合作企业身份 → 负触发 `城更合作（开发商与前期服务）·审查`（开发商与前期服务公司）、`城更股权合作·审查`（股权合作）、`城更合作（村集体与企业）·审查`（村集体与合作企业）或 `城市更新项目意向合作协议·审查`（意向合作）。禁止打开上述 method 当本类型主路径。禁止抄 `意向合作）。禁止打开上述method当本类型主路径。禁止抄`（拆迁委托）或 `拆迁委托）或`／`的method当本类型主路径。禁止把拆迁委托拆迁补偿咨询服务或合作开发正文抄进本任务。`（咨询）换标题。
3. **服务费不是投资款**：前期报酬是劳务与成本补偿，由后续中选合作企业承接支付或按阶段固定报酬结算。不得写成投资款、保底分成或建设利润。招商失败的商业风险与政策关闸的费用分担必须分列。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。禁止把知识库里的“80%/90% 通过率”写成全国强制指标。禁止把“结清前服务商保留成果”写成可以扣留已付款后的政府申报必需数据。

## 工作边界

正触发：已有可读待签正文，尚未签署，尚未成争，核心给付是城市更新/旧村改造的前期协助（意愿征集、摸底测绘、方案编制、招商组织），双方是村集体与前期服务公司，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 服务公司同时取得开发权、建设分红或当然实施主体 → `城更合作（村集体与企业）·审查` 或 `实施主体监管协议·审查`；
- 开发商与前期服务公司就后续权益、垫资或权益预支合作 → `城更合作（开发商与前期服务）·审查`；
- 以持股、项目公司股权分配开发利润 → `城更股权合作·审查`；
- 只有合作意向、排他谈判、尚未形成前期服务给付 → `城市更新项目意向合作协议·审查`；
- 只有拆迁实施委托，不连摸底方案招商 → `意向合作）。禁止打开上述method当本类型主路径。禁止抄`；已是补偿安置协议 → `拆迁补偿安置协议·审查`；
- 只有法律意见、规划咨询或工程咨询，不做意愿征集/招商组织 → `拆迁委托）或`／`的method当本类型主路径。禁止把拆迁委托拆迁补偿咨询服务或合作开发正文抄进本任务。`／`建设工程咨询服务合同·审查`；
- 政府作为一方、一级整理加二级联动 → `政府作为一方一级整理加二级联动→`；纯一级开发委托 → `土地一级开发委托，或名为一级开发实为投资借贷`；
- 无文本、本类型条件已谈妥、要出己方稿 → `城市更新项目前期服务合同·起草`；
- 已签只问付款日、汇报日、成果交接 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼仲裁 → `或对应专项领域。`，不审应诉策略。

挂靠、伪造表决、阴阳合同、贿赂村民、操纵招商：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（村集体或前期服务公司择一）；相对方是否经登记的集体经济组织或其法定代表人/理事长；全文、附件项目范围图、服务清单及进度表、成员大会或成员代表大会决议、街道/镇备案；服务四项是否齐（意愿、摸底、方案、招商）；是否出现实施主体/开发权语句；服务费支付主体与落空安排；保证金账户；排他期与合同期；争议解决；不可接受事项；法域与拟签署日。缺立场或无可读书面文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)

禁止打开其他类型目录。`基本面.md` 把 80%/90% 表决率写成硬指标的，按 method 纠正为地方或当次约定，运行时核验。`框架.md` 把终止后成果一律归村集体、与“结清前服务商保留”冲突的，按 method 分付款前后处理，不回写双文件。

### 0. 签署状态与成果分流

无书面文本 → `城市更新项目前期服务合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 争议领域。未签且目标是评改已有前期服务文本，才进入本任务。

### 1. 类型锁死与邻类切开

标题、签署方与核心给付一致才继续。合作开发、股权合作、实施主体监管、拆迁委托、普通咨询负触发。禁止两可时灌入邻类知识。

### 2. 实施主体闸

拆开前期协助与后续开发权。自动转化、保证中选、干预投标必须改或停笔。

### 3. 民主决策与签署能力

成员大会/成员代表大会决议、会议记录未见则签署能力字段停止。不把社长单独盖章写成已完成集体决定。

### 4. 服务范围、转包、数据与成果

四项服务颗粒度；核心表决组织不得擅自转包；测绘须可备案；村民身份与房产数据按个人信息保护约定。

### 5. 对价、保证金、排他与政策变更

服务费分期与落空；保证金共管；排他期短于合同期；全面改转微改按情势变更协商，不写成当然免责或当然全额收回。

### 6. 按框架六步出修改句

必须有可回给对方的修改句或红线。框架与硬闸冲突时，以 method 为准。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持写成当然实施主体、保证中选、伪造表决、阴阳合同、贿赂村民或操纵招商。
- `字段停止`：法域、成员决议、地方实施主体确认规则、测绘精度、服务费承担主体、保证金账户未核验。
- `目标停止`：主目标已变为从零起草、履约交底、合作/股权整案、拆迁委托、咨询整案、诉讼或仲裁策略。
