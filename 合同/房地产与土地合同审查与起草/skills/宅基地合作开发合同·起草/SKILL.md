# 宅基地合作开发合同·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **土地使用权 / 宅基地合作开发合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「宅基地合作开发合同·起草」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证规划许可或过户一定办成、把对外买断或纯租赁改成可履行“合作开发”。

## 本类型硬闸

1. **成员资格**：出地方必须是该宅基地所在农村集体经济组织成员，且为证载宅基地使用权人（或户内依法共有）。成员资格按《农村集体经济组织法》第十一条、第十二条核成员名册、户籍与权利义务关系，不得把“户口本同村”“同镇外村”“已迁出仍住村里”自动写成适格。户内共有人未全体签署或未出具书面同意的，该处分字段停止。拟签日在 2025-05-01 之前的，该法条号不得直接套用，改走土地管理法第六十二条和实施条例第三十四条，字段待核。
2. **对外合作限制**：合作方可以是本集体以外的主体，但不得因出资自动取得宅基地使用权或房屋所有权。土地所有权归农民集体（土地管理法第二条、第十一条）；使用权原则上仍登记在农户名下。禁止写成向城镇居民、其他集体经济组织成员或公司过户、永久买断、对外销售小产权房。对外买断只出告知，不改成可履行过户或“先签再迁户变有效”。
3. **与买卖／租赁切开**：正像是农户出地、合作方出资共建，分配约定期限内的经营收益或房屋使用权，权属不外转。一次性价款换永久房屋／使用权、旨在过户 → `宅基地内部房屋买卖·审查`（仅双方均为本集体成员）或整体停止（对外买卖）。无共建、核心是租金占场或委托运营 → `宅基地房屋租赁运营·审查`。标题写“合作开发”但正文全是买断或年租金的，负触发对应原子，禁止删句后硬套本技能。禁止打开或复制 `房地产合作开发类合同·审查`、`集体建设用地合作开发合同·审查` 的 method。

支撑闸：

4. **标的适格**：必须是依法取得的农村宅基地及地上住宅／附属设施。农用地、永久基本农田、未入市集体经营性建设用地、权属争议或查封的，不改成可履行合作开发。
5. **报建主体**：农村村民住宅翻建／改建须以农户名义申请。合作方只提供资金和技术支持，不得写成独立报建主体。建筑施工资质挂靠、违法分包只出告知。
6. **合同成立 ≠ 物权变动 ≠ 规划许可**：书面合同可以约定生效条件；宅基地使用权的取得、行使和转让适用土地管理法律和国家有关规定（民法典第三百六十三条）。禁止写“签字即过户”或“永久使用对抗一切第三人”。无乡村规划许可／宅基地审批不得写成已可开工。
7. **身份丧失与征收预切**：农户迁户、丧失成员身份（农村集体经济组织法第十七条）或遇征收时的承接和补偿切分必须落句。不保证安置资格，不对抗征收机关。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签宅基地合作开发正文，尚未签署，尚未成争，核心给付是农户以宅基地及房屋作为合作条件、合作方出资共建并分配约定期限经营权或收益，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 双方均为本集体成员，核心是房屋连同宅基地使用权内部让与、过户 → `宅基地内部房屋买卖·审查`；
- 城镇居民、外村成员或公司买断、永久使用、分割过户 → 不改成可履行；对外买卖整体停止或回引擎，不按本类型放行；
- 租金、租期、占场、委托运营、无共建 → `宅基地房屋租赁运营·审查`；
- 出让国有建设用地共同投资、共享利润、共担风险 → `房地产合作开发类合同·审查`；
- 已登记集体经营性建设用地共建或入市合作 → `集体建设用地合作开发合同·审查`；
- 集体建设用地出让／租赁／出资入股 → `集体建设用地使用权出让合同·审查`／`集体建设用地使用权租赁合同·审查`／`集体建设用地使用权出资入股合同·审查`；
- 国有土地使用权出让或转让 → `国有土地使用权出让合同·审查` 或 `国有土地使用权转让合同·审查`；
- 承包地／土地经营权流转 → 农村土地承包专项，不在本任务评改；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问开工日、分成日、备案日 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁或征收补偿争议已立案 → `或对应专项领域。` 或征收／争议专项。

以合作为名把农用地、永久基本农田或对外买断改成可履行结构：只出告知，不改写成可履行路径。

## 建立起草坐标

确认：使用者与授权；单方立场（出地方／农户或出资／运营合作方择一）；相对方；全文及权属证书／成员名册／家庭成员同意书／集体书面意见／设计图纸版本；出地方是否本集体成员及证载权利人；合作方身份；是否约定过户或永久使用；是共建还是纯出租／托管；地块是否宅基地；规划许可与翻建申请状态；合作期限；征收与户口迁出安排；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 起草模式

本原子只承担本类型起草。待签评改转 `宅基地合作开发合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。商业数字未给用 `【待填】`。

按框架六步落稿。本类型硬闸改成下列起草必写 / 附件必附 / 禁止出现。宅基地合作仅能分配约定期限内的经营收益或使用权，权属不外转。

### 起草必写

- 出地方必须是该宅基地所在农村集体经济组织成员，且为证载宅基地使用权人（或户内依法共有）；户内共有人未全体签署或未出具书面同意的，该处分字段停止。
- 合作方可以是本集体以外的主体，但不得因出资自动取得宅基地使用权或房屋所有权；使用权原则上仍登记在农户名下。
- 核心给付是农户出地、合作方出资共建，分配约定期限内的经营收益或房屋使用权。
- 农村村民住宅翻建／改建须以农户名义申请；合作方只提供资金和技术支持。
- 农户迁户、丧失成员身份或遇征收时的承接和补偿切分必须落句。

### 附件必附

- 权属证书；成员名册。
- 家庭成员同意书；集体书面意见。
- 设计图纸；乡村规划许可／宅基地审批写成条件或期限。

### 禁止出现

- 向城镇居民、其他集体经济组织成员或公司过户、永久买断、对外销售小产权房；“先签再迁户变有效”。
- “签字即过户”或“永久使用对抗一切第三人”。
- 合作方写成独立报建主体；无乡村规划许可／宅基地审批写成已可开工。
- 农用地、永久基本农田、未入市集体经营性建设用地改成可履行合作开发。
- 一次性价款换永久房屋／使用权，或无共建的租金占场（那是买卖或租赁）。

出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 本任务起草模式；已签履约 → 本套导航履约步骤；已成争 → 合同争议或征收专项。未签且目标是评改已有宅基地合作开发文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。买卖、租赁／委托运营、房地产合作开发、集体建设用地合作开发、承包地流转负触发。

### 2. 成员资格与共有人

出地方成员资格闭合；户内共有人全体签署或同意。非本集体成员作为出地方：字段停止或整体停止。

### 3. 对外合作限制

合作方不取得宅基地使用权或房屋所有权。过户、永久买断、对外销售小产权房停笔。

### 4. 标的适格与权利负担

宅基地及地上房屋；证载四至；不得占永久基本农田；抵押、查封、争议、规划违建。未核不得写“无权利负担”。

### 5. 报建、规划许可与集体书面意见

农户名义申请翻建／改建；乡村规划许可／乡镇宅基地审批写成条件或期限；集体书面意见未附则字段停止。

### 6. 对价、期限、征收与身份丧失

投资与分成、合作期限、期满残值、征收切分、迁户承接。被认定为租赁时点名第七百零五条，但不把整约改写成租赁以规避买卖。

### 7. 格式条款与强制规范

无核验引文则法律结论字段停止。对外买断、占永久基本农田、无证超建不得改成可履行。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把对外买断或纯租赁改成合作开发外壳、把无成员资格或无集体同意改成可履行、把永久基本农田或对外销售小产权房改成可履行。
- `字段停止`：法域、地方盘活细则、成员名册、共有人名单、证载与现状差异、规划许可、征收范围未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
