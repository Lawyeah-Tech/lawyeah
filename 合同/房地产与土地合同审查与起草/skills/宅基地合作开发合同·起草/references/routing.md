# 边界与路由

本技能只审查 **土地使用权 / 宅基地合作开发合同** 的待签、农户出宅基地、合作方出资共建并分配约定期限经营权或收益的文本。中文展示名是「审查宅基地合作开发合同（土地使用权）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或复制 `房地产合作开发类合同·审查`、`集体建设用地合作开发合同·审查` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 双方均为本集体成员；核心是房屋连同占用范围内宅基地使用权内部让与、过户 | `宅基地内部房屋买卖·审查` |
| 城镇居民、外村成员或公司买断、永久使用、分割过户、对外销售小产权房 | 不改成可履行；对外买卖整体停止或回引擎，不按本类型放行 |
| 租金、租期、占场使用、委托运营、民宿托管，无共建或共建已完成只谈占场 | `宅基地房屋租赁运营·审查` |
| 出让国有建设用地共同投资、共享利润、共担风险、按面积分房 | `房地产合作开发类合同·审查` |
| 已登记集体经营性建设用地共建、入市合作或利润分成 | `集体建设用地合作开发合同·审查` |
| 集体经营性建设用地出让 | `集体建设用地使用权出让合同·审查` |
| 集体建设用地使用权租赁 | `集体建设用地使用权租赁合同·审查` |
| 集体建设用地使用权出资入股 | `集体建设用地使用权出资入股合同·审查` |
| 国有土地使用权出让或转让 | `国有土地使用权出让合同·审查` 或 `国有土地使用权转让合同·审查` |
| 承包地／土地经营权流转 | 农村土地承包专项或 `承包地／土地经营权流转` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、只问开工日、分成日、备案日 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或对应专项领域。` 或对应专项领域 |
| 征收补偿争议已立案、强拆或规划处罚已作出 | 征收／行政专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

宅基地合作开发正文里夹带一小段内部买卖过户或一份纯租赁附件：专章交接对应原子；共建与经营权分配条款可继续审。用户坚持本技能把买卖、租赁、房地产合作开发或集体建设用地合作开发整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
