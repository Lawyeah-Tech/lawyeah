# 边界与路由

本技能只审查 **土地使用权 / 集体建设用地使用权出让合同** 的待签书面文本。中文展示名是「审查集体建设用地使用权出让合同（土地使用权）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或抄写 `国有土地使用权出让合同·审查` 的审查正文。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 出让人是市、县人民政府或自然资源主管部门，标的为国有建设用地 | `国有土地使用权出让合同·审查` |
| 集体建设用地使用权租赁、租金、租期，或租期超过二十年的“租赁” | `集体建设用地使用权租赁合同·审查` |
| 集体建设用地使用权出资入股、以地换股、集体成为股东 | `集体建设用地使用权出资入股合同·审查` |
| 集体建设用地合作开发、联建分成、不设立出让使用权 | `集体建设用地合作开发合同·审查` |
| 宅基地使用权流转、农户住宅用地对外转让 | 回引擎重新定性；不按本类型改完 |
| 农村土地承包经营权或土地经营权流转 | `承包地／土地经营权流转` 或对应审查原子 |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、只问交地、付款、登记节点 | 本套导航的履约步骤 |
| 征收已启动、补偿项目整理 | `C端征收补偿材料整理`；本任务只审征收预设条款 |
| 已催告、已解除、已立案、成员起诉确认无效 | `或对应专项领域。` 或对应专项。本技能不审诉讼策略 |
| C 端大众快检 | 只分流，不回改 |

出让合同正文里夹带入股对赌或长期租赁专章：专章交接对应原子；其余出让条款继续审。用户坚持本技能给出入股效力、租赁二十年效力终局意见或诉讼胜率：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿本类型文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
