# 边界与路由

本技能只审查 **土地使用权 / 一级市场联合拿地类合同** 的待签、尚未取得土地使用权之前的联合竞买与成交后移交文本。中文展示名是「审查一级市场联合拿地类合同（土地使用权）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或复制 `联合勾地协议·审查`、`房地产合作开发类合同·审查` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 相对人是市、县自然资源主管部门；给付是出让金换建设用地使用权；出让合同示范文本或成交确认书 | `国有土地使用权出让合同·审查` |
| 尚未挂牌；正文是产业条件、入市节奏、联合勾地，尚无竞买主体／举牌／限价安排 | `联合勾地协议·审查` |
| 与非出让人（平台公司、中介、村集体以外的资源方）锁定勾地预期，政府不是相对人 | `与非出让人签订的勾地协议·审查` |
| 与出让人签预申请、触发招拍挂的预约 | `用地预申请协议·审查` |
| 地块已出让并交付或已持证；核心是共同出资建设、按面积分房、共享利润共担风险 | `房地产合作开发类合同·审查` |
| 宅基地合作开发 | `宅基地合作开发合同·审查` |
| 集体建设用地合作开发 | `集体建设用地合作开发合同·审查` |
| 已持证项目公司股权买卖，土地已在目标公司名下 | `以股拿地·审查` |
| 已持证土地使用权直接转让 | `国有土地使用权转让合同·审查` |
| 土地置换 | `土地置换协议·审查` |
| 委托代建、商业代建 | `委托代建合同·审查` 或对应委托原子 |
| 建设工程施工联合体投标、对招标人连带的工程联合体协议 | `建设工程施工联合体→` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、只问缴地价日、交地日、办证窗口 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或对应专项领域。` 或对应专项领域 |
| 出让合同解除、收回土地、串通投标刑事立案已发生 | 土地／房地产或刑事专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

联合拿地正文里夹带一小段远期开发分房或一份出让合同附件：专章交接对应原子；竞买与成交后移交条款可继续审。用户坚持本技能把出让合同、勾地、合作开发本约或已持证股权买卖整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
