# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的代建费、面积、工期；把已失效《合同法》《担保法》或法释〔2005〕5 号未修正条号写入结论；把代建写成合作开发或施工已审完；把城房法第三十九条百分之二十五写成代建合同自身生效条件；写可履行的规避招标或挂靠路径。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查委托代建合同（土地使用权）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、已失效《担保法》、法释〔2005〕5 号未修正条号、1999 年未修正招标投标法时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `土地使用权`，子级 `委托代建合同`。定性理由、易混切开结果（合作开发 / 施工 / 委托合同族代建 / 土地使用权转让）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、土地使用权与文本版本

主体表：签约名、履行名、付款名、发票名、授权签字人、证载土地使用权人、抵押权人。土地表：证号或出让合同编号、出让金、用途与容积率、红线是否一致、抵押/查封。版本表：正文、权责划分表、土地证/出让合同、聊天确认；冲突并列。

## 5. 给付、费用与风险、授权边界

代建范围（全过程/阶段性）；对外签约名义；分权手册；基础管理费与激励；投资/市场风险归谁；垫资本息与回款顺位；成果物权归属；印章与资金共管。缺口标 `G#`。不输出合作开发分房口径或施工工程价款结算口径作为本约主给付。

## 6. 格式条款、强制规范与招标/挂靠

是否构成格式条款；提示说明痕迹。必须招标、挂靠、违法分包不得写成可放行。强制规范只按第 153 条和合同编通则解释第 16、18 条区分，不用失效口诀。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把共担亏损句改成“尽量协商”后按本类型放行。

## 9. 谈判与签署提醒

谈判顺序：先红线（类型切错、权属过户、固定回报穿透转让、挂靠/规避招标），再必须改（分权手册、费用与风险分账、对外名义、印章资金共管、垫资与借款切开），最后可优化。签署提醒：授权、用印、日期、土地证/出让合同、权责划分表、目标责任书、品牌许可。不指导倒签或先签再补招标。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书或效力保证，也不是合作开发安排、施工承包安排或委托合同族代建安排。
