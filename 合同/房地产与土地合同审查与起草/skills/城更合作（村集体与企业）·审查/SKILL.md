# 城更合作（村集体与企业）·审查

## 任务目标

在单一立场下，只审查 **房地产合同 / 城市更新项目合作合同（村集体与合作企业）** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「城更合作（村集体与企业）·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、把宅基地合作/集体建设用地入市合作/前期服务/开发商前期合作/股权合作/户级拆迁补偿/普通联建整案改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **集体决议**：已登记农村集体经济组织的，投资等重大事项、集体经营性建设用地使用/出让/出租方案由成员大会决定；成员代表大会不得行使土地承包、宅基地使用、经营性财产收益权份额量化、土地补偿费等分配使用、合并分立等专属职权。成员大会须提前十日通知、三分之二以上具有完全民事行为能力的成员参加，并经全体成员三分之二以上同意（法律或章程更严从其规定）。村委会主任、理事长单独签字或“村两委研究同意”不得写成已完成法定决议。决议未附、通知/到会/票数不可见：字段停止，不写“可以盖章生效”。
2. **成员利益**：复建安置面积与交付标准、临迁费及逾期递增、土地补偿费等使用分配办法、成员住宅补偿路径必须落到可核验方案和附件，不得写成“由甲方村委会/理事会自行决定分配”。优先保障回迁，不得把成员安置压在融资物业预售套现之后。集体财产不得分割到成员个人，也不得低价折股、转让、租赁。侵害成员合法权益的决定存在撤销风险；签前不得宣布合同必然无效或必然有效。
3. **与宅基地/集体建设用地合作切开**：不经城市更新单元批复、不以回迁复建为对价、仅就宅基地房屋与外来资本合作建房 → 负触发 `宅基地合作开发合同·审查`。仅就已登记集体经营性建设用地出让、出租或入股、不以更新回迁安置为给付 → 负触发 `集体建设用地合作开发合同·审查`。不得打开或抄写上述原子方法，也不得抄 `城更合作（开发商与前期服务）·审查`（开发商与前期服务公司）的服务费/独家顾问主路径。不得把本类型改成宅基地对外买卖或集体建设用地入市出让本约。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签正文，尚未签署，尚未成争，核心给付是村集体以更新单元内集体土地及相关权益投入、合作企业出资并实施旧村/旧城镇更新、双方分配复建安置物业与融资物业，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 不经更新单元、仅就宅基地房屋合作建房或对外流转 → `宅基地合作开发合同·审查`；宅基地房屋买卖或租赁主轴 → `宅基地内部房屋买卖·审查` / `宅基地房屋租赁运营·审查`；
- 已登记集体经营性建设用地出让/出租/入股，不以回迁复建为给付 → `集体建设用地合作开发合同·审查`；
- 给付是意愿征集、策划摸查、前期服务费 → `城市更新项目前期服务合同·审查`；开发商与前期服务公司分成或独家顾问 → `城更合作（开发商与前期服务）·审查`；
- 双方均为开发主体，主轴是项目公司股权比例和出资，村集体不是出地一方 → `城更股权合作·审查`；
- 明确为意向、框架或招商前预备，尚未锁定实施阶段权利义务 → `城市更新项目意向合作协议·审查`；
- 用户只拿资金监管协议 → `资金监管协议·审查`；只拿户级拆迁补偿安置协议 → `拆迁补偿安置协议·审查`；只拿政府与实施主体的监管协议 → `实施主体监管协议·审查`；
- 普通“一方出地、一方出钱”联建，无更新政策、无回迁双95%、无公开招商中选 → `一方出地一方出钱联建·审查`；
- 政府委托一级开发、不以村集体为合作一方 → `土地一级开发委托，或名为一级开发实为投资借贷`；与自然资源主管部门签署的土地出让合同 → 转引擎重新定性；
- 无文本、本类型条件已谈妥、要出己方稿 → `城更合作（村集体与企业）·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁，或成员已起诉撤销决议 → `或对应专项领域。` 或对应专项领域。C 端征收材料整理或农村土地承包流转整理只分流，不回改。

规避征收转用、未批先建、伪造决议、低价处分集体财产、挂靠开发资质：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（村集体/股份经济合作社侧或合作企业侧择一）；相对方；全文及决议/招商/安置方案/复建清单版本；签约主体是农村集体经济组织还是村委会；成员大会是否审议合同文本、招商结果与补偿分配；更新单元批复与规划指标；复建区与融资区；临迁费；履约保证金；中选主体与签约主体是否同一；不可接受事项；法域、项目所在地与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的面积、金额、比例、工期用 `【待填】`，不编造。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`基本面.md` 中“村民大会或代表大会”不得写成代表大会可决定土地补偿费分配；“未经招商往往无效”不得写成全国一律无效。“回迁房是定作人工作成果”不得写成应转承揽。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `城更合作（村集体与企业）·起草`；已签履约 → 本套导航履约步骤；已成争或成员已诉请撤销决议 → 合同争议。未签且目标是评改已有本类型文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。宅基地合作、集体建设用地入市合作、前期服务、开发商前期合作、股权合作、意向、户级补偿、普通联建负触发。

### 2. 主体、中选人与文本版本

签约名须落到农村集体经济组织或依法代表行使所有权的村民委员会。中选主体与签约主体不一致须有变更说明及担保。决议、招商文件、安置方案与正文冲突并列。

### 3. 集体决议（硬闸）

合同文本、招商结果、投资合作、补偿费分配使用办法的决议范围、通知、到会和票数必须可回链。专属成员大会事项不得仅由代表大会或村两委决定。

### 4. 成员利益与复建融资分区（硬闸）

复建物业面积、位置、交付标准、临迁费递增、补偿分配办法入附件。复建须先于或同步于融资物业。禁止“自行分配”和先售后迁。

### 5. 土地路径、规划指标与资金监管

征收转用、农用地转用或集体经营性建设用地路径写为双方义务和条件，不写成已经完成。规划指标锁定。安置资金三方共管。

### 6. 格式条款、强制规范与停笔结构

无核验引文则法律结论字段停止。规避征收、伪造决议、低价处分集体财产、挂靠资质停笔。

### 7. 违约、强制退出、股权锁定与争议

逾期临迁费、逾期回迁、资金链断裂分别有可执行后果。股权倒卖限制。争议宜先街道/更新机构协调，再单一仲裁或诉讼。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、补假决议、保证有效、把补偿费交村委自行分配、规避征收转用、或把宅基地/入市/前期服务主轴改成可履行本类型。
- `字段停止`：法域、当地更新招商规则、决议票数、征收转用批文、规划指标、中选主体变更未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
