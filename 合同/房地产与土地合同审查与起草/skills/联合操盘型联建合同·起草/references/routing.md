# 边界与路由

本技能只审查 **房地产合同 / 联合操盘型联建合同** 的待签、共担风险且双头管理文本。中文展示名是「审查联合操盘型联建合同（房地产合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 一方独占操盘权；另一方仅知情、监督、审计或事后追认；单方最终决定权 | `一方操盘型联建合同·审查` |
| 不承担经营风险；只收固定货币、固定房屋或固定利润 | `不共担风险型联建合同·审查` |
| 共担风险但未锁双头管理，现场执行权未共同配置 | `共担风险型联建合同·审查` |
| 联建模式主文件，未进入联合操盘安排 | `联建模式联建合同·审查` |
| 隐名参建、对外不显名 | `隐名参建联建·审查` |
| 单纯土地使用权转让、项目公司股权收购，联建只是外壳 | 引擎重新定性 |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

联合操盘正文里夹带一小段委托代建或品牌许可：专章交接对应原子；双头管理条款可继续审。用户坚持本技能把一方操盘、固定回报或不共担风险整案改完：`目标停止`。

本场景为 P1。专业版未收录的 P1 场景不会安装本原子。若用户拿本类文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
