# 联合操盘型联建合同·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、已失效民法通则联营条文或 1990 年联营解答当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **房地产合同 / 联合操盘型联建合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「联合操盘型联建合同·起草」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证必然过规划或预售。

## 本类型硬闸

1. **与一方操盘切开**：正像是双方均不放弃现场执行权，重大事项和日常经营走联席合意或按分工交叉执行。一方独占操盘权、另一方仅知情、监督、审计或事后追认 → `一方操盘型联建合同·审查`。标题写“联合操盘”、正文把最终决定权交给一方：按核心给付负触发，不得删掉单方操盘句后硬套本技能。禁止打开或复制 `一方操盘型联建合同·审查` 的 method。
2. **双签／联席**：须同时具备：（a）等额联管会或等价联席机构，重大事项清单穷尽；（b）共管账户，资金拨付双签；（c）公章、合同章、财务章交叉共管，双人到场。缺任一项标必须改。若缺双签／联席且出现单方最终决定权，回到闸 1 负触发，不写成“监督加强版联合操盘”。
3. **僵局**：重大事项一致决必须配时限、升级和合同退出（投标退出、评估价收购或共同挂牌）。不得只用“友好协商”“提交仲裁／起诉”或“可依公司法请求解散公司”代替。司法解散是最后手段，签署前不能当作出路。停摆超过约定日仍无退出：红线。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签联合操盘联建正文，尚未签署，尚未成争，核心给付是共担风险上的共同经营、双头管理，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 一方全权操盘，另一方仅监督／知情／审计 → `一方操盘型联建合同·审查`；
- 不承担经营风险，只收固定货币、固定房屋或固定利润 → `不共担风险型联建合同·审查`，并按解释第 21、23 条标转性信号；
- 共担风险但未锁双头管理、现场执行权未共同配置 → `共担风险型联建合同·审查`；
- 联建模式主文件、未进入联合操盘安排 → `联建模式联建合同·审查`；
- 隐名参建、对外不显名 → `隐名参建联建·审查`；
- 单纯土地使用权转让、项目公司股权收购，联建只是外壳 → 引擎重新定性；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问注资日、验收日、用印留痕 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁或项目已停工成争 → `或对应专项领域。` 或对应专项。

挂靠、违法分包、规避限购、以联合操盘包装出借开发资质：只出告知，不改写成可履行路径。

## 建立起草坐标

确认：使用者与授权；单方立场；相对方；全文及股东协议／权责清单／财务印章制度／品牌协议版本；是否双方均有现场执行权；联管会组成与表决；资金双签与印章共管；僵局期限与退出；开发资质与项目公司；土地权属与规划许可；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价款、比例、期限用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验土地使用权合同解释第 12、13、16、19–21、23 条，民法典第 153、490、496、506、562、563、585、586、791、967、968、970、972、973 条，合同编通则解释第 10、15、16 条，公司法（2023）第 231 条，资质管理规定第 3 条；`search_practiced` 只补审查反例；`search_template` 只借栏目。不虚构案件系统。

## 起草模式

本原子只承担本类型起草。待签评改转 `联合操盘型联建合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。按框架六步落稿。商业数字未给用 `【待填】`。出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。一方操盘、不共担风险、笼统共担、联建模式、隐名参建：负触发，不按邻类出稿。

**起草必写**

- 双方均不放弃现场执行权，重大事项和日常经营走联席合意或按分工交叉执行。
- 等额联管会或等价联席机构，重大事项清单穷尽。
- 共管账户，资金拨付双签。
- 公章、合同章、财务章交叉共管，双人到场。
- 重大事项一致决必须配时限、升级和合同退出（投标退出、评估价收购或共同挂牌）。

**附件必附**

- 权责清单。
- 财务印章制度。
- 联管会组成与表决规则。
- 僵局退出方案。

**禁止出现**

- 一方独占操盘权、另一方仅知情、监督、审计或事后追认。
- 标题写“联合操盘”、正文把最终决定权交给一方。
- 只用“友好协商”“提交仲裁／起诉”或“可依公司法请求解散公司”代替退出。
- 停摆超过约定日仍无退出；司法解散当作出路。
- 以联合操盘包装出借开发资质。

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 本任务起草模式；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有联合操盘文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。一方操盘、不共担风险、笼统共担、联建模式、隐名参建负触发。

### 2. 主体、资质与项目公司

签约名、履行名、付款名、发票名分列。至少一方或项目公司须有开发资质，否则效力字段停止，不写“可以先签后补”。

### 3. 双签／联席

联管会等额、重大事项清单、资金双签、印章交叉共管。缺一项不得写成已闭环。

### 4. 僵局

一致决超时、升级路径、投标退出或评估收购。司法解散不得写成唯一出口。

### 5. 出资、分配与共担

同比例跟投、共管账户、预售款不得充抵投资。固定回报按转性切开。

### 6. 格式条款与强制规范

无核验引文则法律结论字段停止。挂靠／违法分包停笔。

### 7. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把一方操盘改成联合操盘外壳仍放行、把挂靠／违法分包／规避限购改成可履行。
- `字段停止`：法域、动态规则、资质补正、集体／国资决议、土地权属未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
