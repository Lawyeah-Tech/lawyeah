# 边界与路由

本技能只审查 **土地使用权 / 集体建设用地合作开发合同** 的待签、集体以已登记经营性建设用地出地、合作方出资并共同经营、利润或经营权分成且集体不持股的文本。中文展示名是「审查集体建设用地合作开发合同（土地使用权）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开 `房地产合作开发类合同·审查`、`宅基地合作开发合同·审查` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 出让金换使用权；使用权过户到受让人名下；集体退出经营；招拍挂成交确认书绑出让价款 | `集体建设用地使用权出让合同·审查` |
| 土地使用权作价出资；集体取得股权；章程／增资；评估作价换股份 | `集体建设用地使用权出资入股合同·审查` |
| 租金或场地占用费；不共同开发；不分担经营亏损；只占场经营 | `集体建设用地使用权租赁合同·审查` |
| 国有出让建设用地；联建分房；共同申请国有建设用地上的房屋所有权 | `房地产合作开发类合同·审查`；不打开其 method |
| 宅基地、农村住房、成员身份合作建房或过户 | `宅基地合作开发合同·审查`；不打开其 method |
| 国有土地使用权出让本约 | `国有土地使用权出让合同·审查` |
| 国有土地使用权转让本约 | `国有土地使用权转让合同·审查` |
| 买项目公司股权只为拿地 | `以股拿地·审查` |
| 宅基地房屋买卖 | `宅基地内部房屋买卖·审查` |
| 固定收益加到期还本、不参与损益 | `资金方只收固定货币→第二十三条转` 或整体停止 |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或对应专项领域。` 或对应专项领域 |
| 违法用地查处、成员撤销决议已立案 | 土地或争议专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

合作开发正文里夹带一小段出租或入市出让：专章交接对应原子；共同经营与分成条款可继续审。用户坚持本技能把出让、入股、租赁、国有联建或宅基地合作整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
