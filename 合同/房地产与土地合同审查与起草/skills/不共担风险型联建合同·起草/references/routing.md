# 边界与路由

本技能只审查 **房地产合同 / 不共担风险型联建合同**（标题或陈述为联建/联合开发/合作建房，且至少一方不承担经营风险、只收取固定利益）。

| 已能支持的事实 | 路由 | 不得写成 |
| --- | --- | --- |
| 待签、有联建外观、一方不担风险只取固定货币/固定房屋/固定利益/长期使用权，目标是评改文本 | 留本任务，先穿透再按真实性质改句 | 已经是合法合作开发；已完成签约 |
| 双方共同投资、共享利润**并且**分担亏损/超支，无保底、无论盈亏、固定回报 | `共担风险型联建合同·审查` | 在本任务补共担条款、联合管委会后当作本类型审完 |
| 正文写共担、附件或结算写保底/无论盈亏 | 留本任务；按不共担穿透，冲突写入 `C#` | 采用对用户有利的“共担”版本 |
| 用户确认真实意愿改为共担亏损、取消保底 | `共担风险型联建合同·审查` 或起草引擎 | 本任务直接改成共担联建整稿 |
| 无联建外观的纯土地使用权转让、纯借款、纯商品房买卖、纯租赁 | 本套导航的类型切开步骤 或对应专项 | 用本技能穿透表硬套他类文本 |
| 只要出资结构或操盘分工，且风险共担已闭合 | `一方出地一方出钱联建·审查` / `“双方出地”型联建合同·审查` / `一方操盘型联建合同·审查` / `联合操盘型联建合同·审查`；不可用则引擎 | 用本技能代替出资或操盘维度专项 |
| 无可读正文，本类型条件已谈妥，要出己方稿 | 本任务起草模式（出稿后自审） | 已经完成审查；转通用起草引擎出本类型终稿 |
| 已签，问出资日、分房日、还款日、过户留痕 | 本套导航的履约步骤 | 签前意见 |
| 已出现催告、解除、索赔、立案、开庭、仲裁 | `或对应专项领域。` 或金融/房地产专项 | 继续当签前审查出修改句充作返还或效力方案 |
| 类型未定或名实明显不符且无法判断是否存在固定回报 | 本套导航的类型切开步骤 | 两可时灌入共担与不共担两套知识 |
| C 端大众快检 | 只分流，不回改 | 降成公众技能 |

挂靠、违法分包、规避土地转让税费或 25% 条件、无证预售分房、无放贷资格面向不特定对象放贷：只告知违法风险，不改写成可履行文本。用户坚持改到能签：整体停止。

专业版未收录的 P1 场景不会安装本原子。若用户拿本类型文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
