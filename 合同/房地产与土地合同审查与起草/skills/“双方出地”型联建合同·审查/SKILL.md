# “双方出地” 型联建合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 2005 年国有土地使用权合同纠纷解释未修正条号、1994 年《城市房地产管理法》第 38 条当作现行条号。不得把民法典第 855 条技术合作开发写成房地产联建依据。不得把“转让合同未经登记不生效”写成现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **房地产合同 / “双方出地” 型联建合同** 的待签文本：双方各自以土地使用权作为核心出资，拟合宗、并证或统一规划后共同开发。输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「“双方出地” 型联建合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查、从零起草、履约交底、争议文书、合同或合宗获批保证、把本约改成可强制过户的土地置换、一方出地联建整案、不共担风险联建整案、土增税或契税精算终局。

## 工作边界

正触发：已有可读待签文本要评改，；尚未签署，尚未成争；**双方（或多方）均出地**，核心给付是相邻或可整合地块的集合利用与共同开发，而不是一方出地换资金、也不是互换权属后各走各路。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 仅一方出地、另一方出全部或主要建设资金 → `一方出地一方出钱联建·审查`；专业版未收录该原子时输出 `unavailable`，不得用本技能改成出地换钱结构；
- 一方出地、双方出钱 → `一方出地双方出钱联建·审查`；
- 核心是互换权属加差价、不共同报建、不共担后续建安 → `土地置换协议·审查`；
- 土地使用权父级笼统合作开发，读不出双方出地整合 → `房地产合作开发类合同·审查`；
- 约定不承担经营风险，只收取固定货币、固定房屋或只租赁使用 → `不共担风险型联建合同·审查`，并提示可能被重定为借款、买卖或租赁；
- 标的是宅基地或未入市集体建设用地 → `宅基地合作开发合同·审查` 或 `集体建设用地合作开发合同·审查`；
- 只解决采光、排水、管线，不共同经营 → 转引擎，按相邻关系或地役文本定性；
- 无文本、本类型条件已谈妥、要出己方稿 → `“双方出地”型联建合同·起草`；
- 已签只问合宗进度、出资节点、分房交付 → 本套导航的履约步骤；
- 已成争（催告、解除、索赔、立案仲裁）→ 合同争议或对应专项领域。

挂靠、违法分包、规避限购、伪造合宗批文：只出告知，不改写成可履行结构。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成。每一闸必须给出修改句或明确转出口径，禁止只打红黄绿。

1. **双方出地、土地整合**。必须同时读出：各方均为拟整合地块的法定权利人；地块相邻或存在可合宗/统一规划的物理基础；目的是共同开发、共享利润、共担风险。修改句必须把鉴于改成：甲方持有【证号/四至待填】、乙方持有【证号/四至待填】，双方拟通过土地整合提高容积率或满足连片开发要求，共同投资、共享利润、共担风险。标题优先用“相邻地块联合开发合同”或“土地整合联建协议”。无第二宗地、对方只出钱：负触发一方出地原子。
2. **土地过户/并证路径必须落句**。正文必须在下列三选一中锁定，并写清义务人、期日、申请机关、税费和失败后果：并至一方名下；各方土地使用权作价入股，由新设或指定项目公司接收；不合宗，统一规划、分别确权。只写“依法办理合宗/过户/变更登记”视为未约定。修改句拆成：合同成立即生效（或另附行政意向前提）；物权变动自登记完成时发生。未登记不得写成“权属已并”或“已可对抗第三人”。并证完成前任何一方不得单方抵押、转让或新设负担。
3. **份额锁死土地权益比例**。出资、分成、奖励面积、公配占用补偿一律使用评估后的土地权益比例，禁止只用占地面积比例。必须选定实物分配（规划图上预划区域）或价值分配（按销售总额比例），并预置不同容积率结果下的模拟清算公式。缺评估基准日、评估机构或附件《土地作价评估报告》：份额字段停止，修改句要求评估报告作为合同附件且未确认评估前不锁定比例。
4. **地块性质不一须统一性质补地价**。一出让一划拨、一商业一工业、剩余年限不一：把“完成统一用途/性质、补缴出让金并取得有权机关批准”写成生效条件或实质履行前提。划拨路径必须指向报有批准权的人民政府审批，不得写成双方同意视为已批准。集体土地、宅基地：红线，不写可履行国有出让整合。
5. **与土地置换 / 名为联建实为换地切开**。读出“你的地归我、我的地归你 + 差价、不共同报建”：负触发 `土地置换协议·审查`。仍挂联建标题但实质对调版图：税旗，提示互换和作价入股可能征收契税，土地增值税是否发生须税务核验；不得改写成可履行换地，不得默写“合作建房暂免”。
6. **与一方出地切开，禁止抄 `一方出地一方出钱联建·审查` / `一方出地双方出钱联建·审查`**。主结构是一方出地、另一方或双方出钱 → 负触发对应原子。本任务禁止输出“出地价款、固定还房套数、出钱方单方出资表”作为主路径。禁止打开其 method。

附加必落句（有事实则单列，无事实在缺口节说明）：

- **资质**：至少一方或拟设项目公司须具备房地产开发经营资质。双方均无：修改句约定共同设立有资质项目公司或由有资质一方名义实施，并作为开工/预售前提。不得保证起诉前补办一定成功。
- **一票确认权**：任何一方不得在未书面告知并取得另一方确认的情况下，单方修改本宗规划条件或新设抵押、查封配合、长期租赁。
- **退出与土地回落**：行政审批失败，各方免责解除、各自收回土地；项目公司解散须预置分割还原理则。未动工前一方退出，另一方按评估价优先收购。
- **权属瑕疵违约**：一方地块被查封或权利瑕疵导致整体无法预售/竣工的，违约方赔偿窝工损失及约定范围内的预期利益，不写“查封自动解除”。
- **合同组**：联合开发总协议 + 规划指标分配方案表 + 资金监管协议 + 房屋分割明细图 + 各宗四至图 + 作价评估报告，必须交叉引用。

必须有修改句。每个风险回链文本位置。禁止套用一方出地的出钱对价节点、土地置换的差价互换节点、商品房买卖的五证/面积 3% 节点。禁止复制 `一方出地一方出钱联建·审查` 或 `一方出地双方出钱联建·审查` method。

## 建立审查坐标

确认：使用者与授权；单方立场（甲方地块权利人、乙方地块权利人、拟设项目公司、拟签字的共有人或村集体）；相对方；全文及四至图/规划草图/评估报告/决议附件版本；各方证号与性质；是否拟合宗或入股；评估基准；分成方式；报建主体与资质；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的证号、评估价、比例、期日用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law`（法律结论 required）：核验合作开发定义与资质、划拨转让报批、出让地再转让投资条件、合同效力与物权登记分离、批准生效与报批义务、不共担风险的重定、划拨或设负担土地使用权作价出资、契税对互换和作价入股。
- `search_practiced`（optional）：补合建权属约定、未登记不得对抗、夹缝地尽调等争点。返回“转让合同未登记不生效”“双方均须有资质否则当然无效”“合作建房一律免土增税”时记噪声。
- `search_template`（optional）：只借栏目结构。范本写“一方出地一方出钱”或“签字即完成合宗过户”不得当规则。

不虚构案件系统。`search_law` 返回已失效《合同法》、2005 年解释未修正条号、1994 年房管法第 38 条、失效《土地登记办法》、民法典第 855 条技术合作开发时记为噪声，不得写入 `L#`。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口，不代替节点。

0. 签署状态与成果分流
1. 类型识别与单目录加载（双方出地整合；切开 s184 / s185 / s100 / s187 / s104）
2. 主体、权属、资质、内部或村集体决议
3. 并证/过户路径与合同效力分离
4. 土地权益比例、评估基准、实物或价值分配
5. 性质不一、补地价、规划整合
6. 共担风险、一票确认、禁止单方负担、退出回落
7. 税费与名实（换地、作价入股）
8. 按框架六步出修改句

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、补假合宗批文、伪造决议、把查封地或集体土地改成可并证、保证必然获批或必然有效、把面积比锁死且拒绝评估。
- `字段停止`：法域、资质、权属/查封、评估基准、并证模式、划拨报批路径未核验。
- `目标停止`：主目标已变为从零起草、履约交底、行政诉讼或确权诉讼文书，或用户要把本约改成可强制过户的置换。

村集体土地未附村民代表大会决议且用户拒绝升级：停止“可以签署”建议。
