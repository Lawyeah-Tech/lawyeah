# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证合同有效、合宗必然获批、权属已经并证或对方接受；编造未给出的证号、评估价、权益比例、补地价、期日；把已失效《合同法》及其解释写入结论；把 2005 年国有土地使用权合同纠纷解释未修正条号或 1994 年房管法第 38 条写成现行依据；把面积比例写成土地权益比例；把未登记写成权属已并；把划拨地写成签字即可并证；把本约改成可强制过户的土地置换；把一方出地联建留在本技能改完。

## 1. 触发、单方立场与成果状态

立场（甲方地块权利人、乙方地块权利人、拟设项目公司、拟签字共有人或村集体）、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明是否同时存在双方出地和土地整合目的，以及拟采用的并证模式（并至一方 / 项目公司接收 / 不合宗分别确权）。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》、2005 解释未修正条号、1994 年房管法第 38 条、民法典第 855 条技术合作开发时记噪声，不得写入 `L#`。合作开发定义与资质、划拨报批、物权与合同效力分离、不共担风险重定、契税无 `verified-result` 时，对应法律结论字段停止。

## 3. 类型与加载路径

父级 `房地产合同`，子级 `“双方出地” 型联建合同`。定性理由必须同时满足：各方以土地使用权出资；交易目的是整合后共同开发。易混切开：一方出地一方出钱、一方出地双方出钱、土地置换、不共担风险联建、笼统合作开发、宅基地或集体建设用地、相邻权协议。

加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读其他类型、未打开 `一方出地一方出钱联建·审查` 或 `一方出地双方出钱联建·审查` method。挂靠、假批文、查封地包装或集体土地改国有整合写停笔告知，不填可履行结构。

## 4. 主体、授权、资质与文本版本

主体表：各方权利人、拟设项目公司、报建主体、共有人、抵押权人、决议机关。自然人写姓名与证件号是否与文本一致；法人写名称与统一社会信用代码。

版本表：联建正文、四至范围图、整合规划草图、土地作价评估报告、权属证明、内部或村民决议、出让合同、抵押清单、聊天确认。冲突并列，不选对用户有利的一版。口头“已经合宗了”“村委会同意了”不得写成已登记或已决议。

## 5. 土地整合与份额给付闭环

分列并回链文本位置：

- 地块：各方证号、四至、面积、用途、出让/划拨、剩余年限。
- 名实：鉴于是否锁定双方出地、相邻或可整合、共同开发而非换地。
- 并证路径：并至一方 / 项目公司接收 / 不合宗分别确权；义务人、期日、机关、文件、税费。
- 合同效力与物权：是否把合宗登记写成合同生效或已经完成权属转移。
- 份额：评估基准、土地权益比例、是否误用面积比例。
- 分配：实物预划或价值分成；奖励面积；公配占用与补偿。
- 后续出资：建安、规费、补地价是否按权益比例；预售款是否被拿去充抵投资。
- 资质与报建主体：谁具备房地产开发经营资质，或是否设立项目公司。
- 负担：抵押、查封、租赁；并证前是否禁止单方新设负担。
- 退出回落：审批失败各自收回；项目公司解散如何分割还原；优先收购。

缺口标 `G#`，不补评估价、证号或已合宗事实。批准、合宗、变更登记写成条件或双方义务期限，不写成已经完成。

## 6. 格式条款、强制规范与本类型效力红旗

一方预先拟定且未协商的联建文本，按格式条款审查提示说明。两家地主对谈形成的文本通常不是格式条款，但仍审查异常的单方收回、单方定价、最终解释权。

强制规范与效力红旗只在核验后落法律结论：双方均无开发资质；划拨未报批即并证；集体土地未征收即开发；查封地强制过户；挂靠或违法分包；以联建规避转让审批或税收。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

不得把“双方均须有资质否则当然无效”或“未合宗则合同未生效”写成已核验结论。不得把知识库“原则上双方均应具备资质”代替解释第 13 条。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔/转出口径。禁止输出无修改句的色块表。

本类型至少检查：未锁定双方出地或实为一方出地/换地；并证路径只写依法办理；把合宗写成合同生效或把未登记写成权属已并；按面积比例而非土地权益比例分成；缺评估报告；性质不一未设补地价前提；并证前可单方抵押；缺一票确认；缺土地回落；双方均无资质且未约定项目公司；村集体未决议；名为联建实为换地的税旗。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字、证号用 `【待填】`，不编造。禁止只给原则、不给句子。框架与硬闸冲突时按硬闸出句。

建议句必须覆盖本类型硬闸：鉴于锁定双方出地与整合目的；并证三选一落句；合同生效与物权变动分列；土地权益比例替代面积比例；性质补地价前提；一票确认与禁止单方抵押；审批失败回落。

## 9. 谈判与签署提醒

谈判顺序：先红线（假批文、查封地并证、集体土地改国有整合、保证获批、面积比锁死且拒评估、换地避税），再必须改（并证路径、评估与权益比例、补地价前提、资质与项目公司、土地回落），最后可优化。

签署提醒：双方法人章；村集体决议或股东会决议作附件；权属证书原件与四至图核对；评估报告、规划草图、房屋分割明细图与正文交叉引用；日期真实。不指导倒签、补假合宗批文或假决议。

出地较多或评估价较高一方：可坚持评估锁定权益比例、一票确认、并证前禁止对方抵押。出地较少或位置较差一方：必须提示签字并证后可能失去独立处分本宗地的能力，审批失败须有回转登记。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、行政诉讼或确权文书、补地价或税额精算终局或效力保证。
