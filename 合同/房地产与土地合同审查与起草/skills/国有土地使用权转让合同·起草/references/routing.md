# 边界与路由

本技能只审查 **土地使用权 / 国有土地使用权转让合同** 的待签文本。中文展示名是「审查国有土地使用权转让合同（土地使用权）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 出让方是市、县人民政府自然资源主管部门，对价是土地使用权出让金，文本走招拍挂／成交确认书 | `国有土地使用权出让合同·审查`。不得删掉出让人后继续当二级市场转让审 |
| 对价是项目公司股权或控制权，土地仍登记在目标公司名下 | `以股拿地·审查`。P1：专业版未装则 `unavailable`，提示，不得用本技能改出土地使用权变更登记专章，也不得在本任务宣告股权合同有效或无效 |
| 一般公司股权转让／收购，不以获取该地块为交易目的 | `或` / `或` |
| 双方共同投资、共享利润、共担开发风险 | `房地产合作开发类合同·审查`。供地方不担风险、只收固定利益的，留在本技能穿透 |
| 土地置换、以地换地 | `土地置换协议·审查` |
| 一级市场联合竞买、联合拿地 | `一级市场联合拿地类合同·审查` |
| 委托代建、代建管理费 | `委托代建合同·审查` |
| 集体建设用地出让／出资／租赁，宅基地房屋 | `集体建设用地使用权出让合同·审查` / `集体建设用地使用权出资入股合同·审查` / `集体建设用地使用权租赁合同·审查` / `宅基地内部房屋买卖·审查` 及后续集体、宅基地原子 |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、只问付款／交地／过户留痕 | 本套导航的履约步骤 |
| 已成争 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

用户坚持本技能把出让合同、股权拿地或真实合作开发整案改完：`目标停止`。名为合作、实为固定利益的文本可以留在本任务，但必须改标题与风险分配，不得维持虚假合作外观以规避转让条件或税收。
