# 边界与路由

本技能只审查 **房地产合同 / “一方出地，一方出钱” 型联建合同**。

必须同时读出：一方以建设用地使用权作为主要投入，另一方承担建设资金；双方共享开发利益并共担经营风险。标题叫“联建”“合作开发”但资金结构是双方出钱、双方出地，或以保底、固定回报为交易设计的，不得留在本技能做实体结论。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或标题含联建/合作开发、核心给付明显不是一方出地一方出钱 | 本套导航的类型切开步骤 |
| 出地方除出地外，还按比例掏建设资金、与出资方一起出钱 | `一方出地双方出钱联建·审查` |
| 用户或标题锁定不共担风险型联建；或全文以保底、固定必付为交易设计，且用户确认不要改成共担 | `不共担风险型联建合同·审查` |
| 双方都提供土地使用权 | `“双方出地”型联建合同·审查` |
| 用户锁定共担风险型联建，但投入结构不是一方出地一方出钱 | `共担风险型联建合同·审查` |
| 审查重点是单方操盘权、品牌输出或管理权移交，不是出地/出钱结构 | `一方操盘型联建合同·审查` |
| 审查重点是联合操盘、双总部派员和交叉否决 | `联合操盘型联建合同·审查` |
| 用户锁定联建模式，审查重点是双名义报建、共同确权的行政公示 | `联建模式联建合同·审查` |
| 用户锁定参建/隐名开发，出资方不出现在报建和权属登记 | `隐名参建联建·审查` |
| 用户未指定联建子型；核心是项目公司股权、股东出资和利润分红 | `房地产合作开发类合同·审查` |
| 委托人保留土地与项目，受托人收代建费或管理费，不分担亏损 | `委托代建合同·审查` 或 `或` 至 `至` 对应原子 |
| 按图施工、工程价款、竣工验收主导，施工方不拥有项目权益 | `操盘方自己施工或按造价取费→` |
| 固定本息、不参与开发经营，联建外壳被抽空 | `资金方只收固定货币→第二十三条转` 或 `或` |
| 出地方不担风险，只收固定地价或固定利益，交易目的是过户土地 | `国有土地使用权转让合同·审查` |
| 仅联合竞买、尚未进入共同开发经营 | `一级市场联合拿地类合同·审查` |
| 整案标的是集体经营性建设用地入市后的合作 | `集体建设用地合作开发合同·审查` |
| 整案标的是宅基地上合作建房 | `宅基地合作开发合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、问出资日、报建日、分房日、监管划扣 | 本套导航的履约步骤 |
| 已成争 | 合同争议领域或对应专项；不写催告、解除通知或诉状 |
| C 端大众快检 | 只分流，不回改 |

同一文本既写“一方出地，一方出钱、共担风险”又写“无论盈亏支付固定回报”：按对价切开。用户要保留联建定性 → 留本技能，按名联建实借贷硬闸删固定必付、补真实亏损分担。用户确认交易就是保底、不担风险 → 负触发 `不共担风险型联建合同·审查`；联建义务被抽空只剩还本付息 → `资金方只收固定货币→第二十三条转`。两可且无法判断：负触发引擎，不灌两套知识。

出地方名义报建、不设项目公司，本身不构成负触发。那是本类型常见的合伙型路径，不是自动改走 `隐名参建联建·审查`。只有用户把“隐名参建”锁成审查对象时才转出。

挂靠施工、违法分包、规避限购、伪造村民决议或假批准、把固定回报化妆成共担：停笔告知，不改写成可履行文本。

禁止在正文写半截 Skill ID。转出时必须写完整 ID，例如 `一方出地双方出钱联建·审查`、`不共担风险型联建合同·审查`、`房地产合作开发类合同·审查`。
