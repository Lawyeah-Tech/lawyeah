# 边界与路由

本技能只审查 **房地产合同 / 参建模式联建合同（隐名开发模式）** 的待签、单一名义、共担风险文本。中文展示名是「审查参建模式联建合同（隐名开发模式）（房地产合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开 `联建模式联建合同·审查` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 双名义报建，双方同为立项、施工许可或预售许可上的开发主体 | `联建模式联建合同·审查` |
| 不分担亏损，只收取固定回报或固定本息 | `不共担风险型联建合同·审查` 或 `资金方只收固定货币→第二十三条转` |
| 企业间借款作为主文件 | `或` |
| 不动产抵押登记为主结构的借款 | `不动产抵押登记为主结构的借款` |
| 出地方只出地，对方收固定代建费或不共担经营风险 | `委托代建合同·审查` 或 `或` |
| 出让土地使用权直接转让、变更登记到受让方 | `国有土地使用权转让合同·审查` |
| 主文件是商品房买卖或预售本约 | `普通商品房买卖价款五证网签主结构→` |
| 土地使用权目录下的合作开发类主文件，且不是隐名参建结构 | `房地产合作开发类合同·审查` |
| 一方出资不显名、不参与监督、不承担亏损 | `一方出资不显名不参与项目监督不承担亏损→` |
| 股权代持作为主文件 | `或` 或 `或` |
| 施工承包主文件 | `操盘方自己施工或按造价取费→` |
| 共担风险但双方联合操盘、共同出现在对外文件 | `联合操盘型联建合同·审查`；一方操盘且双名义 → `一方操盘型联建合同·审查` 或 `联建模式联建合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争、执行异议、破产债权申报 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

隐名参建正文里夹带一小段股权质押或特定房屋买卖：专章交接对应原子；单一名义、共担风险条款可继续审。用户坚持本技能把显名联建、借款、代建或买卖本约整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
