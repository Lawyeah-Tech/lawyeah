# 审查方法（锁定 土地使用权 / 宅基地房屋租赁合同_委托运营合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止打开或复制 `禁止打开或复制` 的城市房屋维修／优先购买／买卖不破租赁主路径，禁止打开或复制 `宅基地内部房屋买卖·审查` 的本集体内部买卖过户主路径。

定性校验：标题、核心给付与本类型一致才继续；买卖、合作开发、国有土地房产租赁、集体建设用地出租或承包地流转明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、保证备案或执照一定办成或唯一必得金额。

`search_law` 返回已失效《合同法》及其解释、《物权法》、《房屋登记办法》、1991 年《土地管理法实施条例》、1982 年《村镇建房用地管理条例》、1995 年《城市房屋租赁管理办法》或 2009 年未修正城镇房屋租赁解释时记为噪声，不得写入 `L#`。

示范文本只参考结构。检索到的民宿委托运营范本栏目（房屋信息、委托项目、收益费用、维修保险、解除）可对照缺口；不得把城市住房托管或承包地委托流转范本当成本约。

知识库纠正（不回写双文件）：

- `框架.md` “委托运营虽不受二十年强制限值”：仅对**真委托**成立。名委实租（独占占有＋固定或保底租金）仍受第七百零五条约束。不得写成标题一换就不受二十年限制。
- `框架.md` 实务中常约定二十至三十年合作期：合作期超过二十年且给付是租赁的，修改句截到二十年；不得把“投资回收需要三十年”写成可以放行的例外。
- `框架.md` “三方合作、农户—平台公司—运营方转租”：结构级讨论可以点名，本任务不改写成另一份可履行转租或合作开发文本，也不因此打开 `宅基地合作开发合同·审查`。
- `框架.md` 建议使用“经营权流转”等政策术语：政策语言不能把租赁写成宅基地使用权转让，也不能写成承租人已取得可对抗集体的资格权。
- `基本面.md` “违章建筑租赁无效，一审辩论终结前补证可有效”：城镇房屋租赁解释（2020 修正）第一条允许乡、村庄规划区内房屋租赁**参照**；第二条证件表述是建设工程规划许可证。农房对应乡村建设规划许可或宅基地报建。签前不得把“起诉后补证”写成已经有效的放行路径。
- `基本面.md` “法律并未禁止城镇居民承租农村房屋”：采用方向，仅适用于租赁／委托运营，不适用于买卖过户。
- 土地管理法第六十二条第五款“出卖、出租、赠与住宅后再申请宅基地不予批准”：须告知农户侧，不得据此单独宣告本租赁必然无效。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

支持切开的规范（法律结论须运行时复核）：

- 第七百零三条：租赁是出租人将租赁物交付承租人使用、收益，承租人支付租金。
- 第九百十九条：委托是受托人处理委托人事务。
- 第七百零五条：租期不得超过二十年；超过部分无效。
- 第三百六十二条、三百六十三条：宅基地使用权人占有使用、建造住宅；取得、行使、转让适用土地管理法律和国家有关规定。
- 土地管理法（2019 修正）第六十二条：一户一宅；村民出卖、出租、赠与住宅后再申请宅基地不予批准；鼓励盘活闲置宅基地和闲置住宅。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 已建农房交付对方独占占有；对价称租金、年租、保底租金；农户不得自行入住或再出租 | 本类型·租赁 | 正触发；期限走第七百零五条 |
| 农户仍可控制房屋或仅授予招商、上架、代订、代管；对价称管理费、服务费或净利润分成；经营风险主要由农户承担 | 本类型·委托运营 | 正触发；期限不套第七百零五条强制限值，但须写第九百三十三条 |
| 独占交付＋固定或保底租金＋可转租，仅标题写委托／托管／合作 | 名委实租 | 按租赁审期限与转租；在意见中写明穿透理由 |
| 永久、终身、一次性高额买断、“转让宅基地使用权”、过户、迁户后归买方 | 买卖 | 双方均本集体成员 → 负触发 `宅基地内部房屋买卖·审查`；否则只告知，不改成可履行过户 |

| 权证为国有建设用地使用权，房屋在城市或镇规划区 | 房产租赁 | 负触发 `禁止打开或复制`；不打开其 method |
| 标的是集体经营性建设用地使用权出租，无村民住宅 | 集体建设用地租赁 | 负触发 `集体建设用地使用权租赁合同·审查` |
| 承包地、土地经营权流转 | 农地专项 | 不启动本任务 |
| 主给付是设立居住权登记 | 居住权 | 负触发 `主给付是设立居住权→` |

标题写“租赁”“委托运营”，正文全是过户、永久买断或分房：负触发对应原子，不删过户句后硬套本技能。

本技能已锁定 **土地使用权 / 宅基地房屋租赁合同_委托运营合同**。只打开 `references/基本面.md` 与 `框架.md`。禁止读其他子目录，禁止为对照再开第二类。禁止打开 `禁止打开或复制`、`宅基地内部房屋买卖·审查`、`宅基地合作开发合同·审查` 的 method。

### 1.3 违法或不可交易结构停笔

加载后或定性中出现：以租赁或委托为名把宅基地卖给非本集体成员并要求过户；强制农户退出宅基地或把进城落户写成交地条件；利用房屋从事赌博、色情、非法集资等违法经营并要求写成可履行业态；明知未报建违建仍要写成已可对外经营并免责；查封后倒签租约对抗执行。

动作：

1. 交付告知：对外买卖不能改成可履行过户或永久占用；强制退出违反土地管理法实施条例第三十六条；违法用途不得改成可履行经营条款。
2. 不写“先租后卖等征收转国有再有效”“知情但合同免责”口径。
3. 风险表只保留识别依据和转出／删除提示。
4. 用户坚持“改到能签且仍做这些事”：整体停止。

## 节点 2　租赁与委托运营切开（硬闸）

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 交付钥匙、对方可排他使用、对价按年或按季固定 | 定性为租赁；加载第七百零三条以下 | 因为标题有“托管”所以不是租赁 |
| 农户继续居住一部分，对方只做上架和代订，收取佣金 | 定性为委托运营；写代理权限、报告义务、第九百三十三条 | 因为有分成所以一定是租赁 |
| 保底租金＋超额分成，对方独占 | 按租赁审期限；分成条款当租金构成，不因此改定性 | 有分成就不受二十年限制 |
| 相对方主张“乡村振兴政策允许三十年经营权” | 政策不是第七百零五条的例外；租赁仍截断 | 政策大于民法典 |

最强反方：运营方主张不独占就无法装修和办证。回应：办证和装修可以写成配合义务，不必也不许用独占加超二十年租期规避第七百零五条；真要独占，就按租赁截到二十年。

## 节点 3　成员资格、共有人与无权代理（硬闸）

### 3.1 出租人／委托人必须是权利人

建主体表：签约名、履行名、付款名、发票名、授权签字人。名称不一致不自动合并。穿透权证（《集体土地使用证》《不动产权证书》《农村宅基地批准书》）上的名字。严禁只与自称二房东或非权利人的家属签约并写成已获处分权。

口头“我们户主同意了”不得写成已授权。代理人授权书必须写明“出租该宅基地房屋”或“委托运营该房屋”，仅有“帮忙看房子”不得写成已获本约权限。

### 3.2 户内共同共有

宅基地以户为单位。处分房屋或改变用途，共同共有须全体共同共有人同意（第三百零一条，另有约定除外）。

| 文本或事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 仅户主签字，材料显示有配偶、成年子女同户 | 字段停止或红线：补全体签署或书面同意函 | 户主签字即拘束全户 |
| 同意函未列房屋坐落或未写“同意出租／委托运营” | 必须改 | 一张“家属无异议”空白条已足够 |
| 共有人下落不明 | 字段停止；不编造公告或代签 | 可以先签后补 |
| 用户要求把未签字的子女写成“视为同意” | 整体停止该拟制 | 合同可以拟制家庭同意 |

### 3.3 承租人／运营方不必是本集体成员

土地管理法第六十二条将“出租住宅”与“出卖住宅”并列，并鼓励盘活闲置住宅。不得仅因对方是城镇居民、公司或外村人就写成租赁必然无效。

成员资格审查对象是**出租人是否权利人**，不是承租人是否可以买地。成员确认走农村集体经济组织法第十一条、第十二条（户籍或曾在本集体、稳定权利义务、以集体土地为基本生活保障；成员大会确认并登记名册）。不得把“户口本同村”自动写成适格权利人。

把承租人写成买受人、把租赁改成可履行过户或“迁户后转有效”：只告知，不改写。对外买卖整体停止。

最强反方：相对方主张“城镇居民连租都不能租，否则就是变相买卖”。回应：买卖才受成员资格限制；真租赁交付占有换租金，承租人不取得宅基地使用权。若文本已是永久买断，按节点 1.1 切出，不在本任务“改成能租”。

## 节点 4　期限、书面与备案

### 4.1 二十年截断（硬闸）

构成租赁的，适用第七百零五条。

| 文本写法 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 租期三十年、五十年、永久、终身 | 红线或必须改：截到二十年；超过部分告知无效 | 整约当然无效；永久可以因为已付款 |
| “二十年到期后自动再续二十年，无需再签” | 必须改：删除自动续期。续订须到期另行书面合意，且自续订日起仍不得超过二十年 | 这就是第七百零五条第二款 |
| 委托运营合作期二十五年，正文是独占＋保底租金 | 按租赁穿透并截断 | 标题是委托所以合法 |
| 真委托，约定期限十年，写“任何一方不得解除” | 必须改：保留第九百三十三条随时解除；可约有偿委托解除时赔偿直接损失和履行后可得利益 | 不可解除的经营权 |
| 未写起止日期 | 必须改：起算日、届满日用 `【待填】` | 推定二十年或永久 |

### 4.2 书面与不定期

第七百零七条：租赁期限六个月以上应当书面；未书面且无法确定期限的，视为不定期。第七百三十条：期限不明经补充仍不能确定的，视为不定期，可随时解除但应合理期限前通知。

只有微信“先住着，钱以后算”：不启动实体放行；告知应补书面，期限与租金仍未特定。不得写成口头一律无效，也不得保证微信一句已成立二十年租期。

### 4.3 备案不是生效要件

第七百零六条：未依照法律、行政法规办理租赁登记备案，不影响合同效力。

| 文本写法 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| “未办租赁备案／未盖村委会章则本合同未生效” | 必须改：删除生效挂钩。可约定一方在【待填】日内配合备案或征求村委会书面知晓；逾期不配合视为违约 | 未备案未生效 |
| 无村委会意见栏 | 可接受可优化：尾部加意见栏，写明备案或知晓不影响合同成立 | 没有村委会章就不能租 |
| 大面积连片流转以乡镇备案为生效条件 | 可保留为双方约款，但须写谁主办、几日内、未完成的解除或中止 | 双方同意视为已备案 |

## 节点 5　标的、报建、权利负担与改建

### 5.1 房屋必须特定

写明坐落、四至、层数、建筑面积、附属设施，并附现状照片及测绘图、设施设备清单。禁止只写“东溪村张户房子一处”。宅基地所有权仍归农民集体，承租人／运营方不取得土地所有权或宅基地资格权。

### 5.2 报建与违建

核《乡村建设规划许可证》、宅基地批准书或不动产权证。未取得合法报建手续的房屋：不得写成可履行对外经营放行。城镇房屋租赁解释（2020 修正）第一条允许乡、村庄规划区参照；第二条的补证时点是“一审法庭辩论终结前”，那是争议阶段口径，签前只能标风险并要求补证或缩小占用范围，不得写“先签，起诉前再补就有效”。

城乡规划法 2019 修正本第四十一条全文本次未稳定核验，改建报批写成合同义务，许可结果标 `G#`。

### 5.3 权利负担

抵押、查封、在先租赁、居住权（第三百六十六条）未核验，不得写成“无权利负担”，只能写 `依据不足`。已登记居住权未取得居住权人书面安排的，入住字段停止。查封后新订租约对抗执行：停笔。

主给付若是设立居住权，负触发 `主给付是设立居住权→`。

### 5.4 改建与增添物

改变结构、加层、加装电梯、外立面改动：必须书面经权利人及户内共有人同意，并约定由农户协助办理乡镇规划或报建。未批准不得开工。不得写成“运营方可自行改建，农户不得干涉”。

合同终止后：不可移动装修无偿留存还是按残值补偿，必须二选一写明；“原状恢复”对运营方应允许争取“按现状移交、不负拆除”，但不得因此把加建部分写成已归运营方所有。

## 节点 6　对价、征收预切、证照与保险

### 6.1 对价结构

- 租赁：固定租金及递增。未给出的数字用 `【待填】`。
- 委托运营：保底费用（如有）＋分成。必须写分成基数（总营收或净利润）、审计权、账簿查阅、结算周期。只写“利润分成”视为必须改。
- 押金、保证金、订金未约定定金性质的，不得适用定金罚则。真定金才核第五百八十六条百分之二十；无核验引文不得把 20% 写成现行法结论。
- 签字即付清多年租金或一次性大额预付：必须配套无权处分、提前解除、合同无效时的返还；否则红线。一次性高额预付加永久占用，按买卖切开。

### 6.2 征收预切

合同期内征收：土地补偿、安置补助原则上归农户／土地权利人；运营方投入形成的装修补偿、搬迁费、停产停业损失可约定归实际投入并经营的一方。修改句只在双方之间切，不保证征收机关按合同兑付，不保证安置指标。

已进入征收范围仍要新签长期占用：字段停止或建议缓签。

### 6.3 证照、邻里与保险

民宿、旅馆等经营：治安、消防、特种行业许可由运营方办理，农户协助提供权属材料。未核地方许可清单则证照字段停止，不编造办成时间。

红线外化粪池、停车、通行：农户可承诺协调，不得写成已为运营方设立地役权或公共用地使用权。

可要求运营方投保公众责任险和财产险。经营债务、人身损害与农户隔离：可写“运营方自行承担经营中对第三人的损害赔偿”，但不得写成农户对故意或重大过失也免责。

## 节点 7　格式条款、强制规范、违约与争议

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 7.1 格式条款

第四百九十六条、第四百九十七条。运营方提供的制式托管合同：免责、单方调分成、自动续期、最终解释权须有提示。小字、夹在附件：不得写成已尽提示义务。

### 7.2 强制规范

第一百五十三条。超二十年只超过部分无效，不当然整约无效。强制农户退出宅基地、违法用途、对外买卖过户：删除或停笔，不改成可履行。禁止用已失效“效力性／管理性”口诀代替第一百五十三条。合同编通则解释第十六条全文本次若未核验，细分路径运行时再核。

### 7.3 违约与解除

农户干扰（断水断电、阻拦经营）：按日可执行后果，不写空泛“依法承担违约责任”。运营方欠付达约定期限：解除、收回房屋及固定装修。构成违约不等于当然解除。

真委托：双方可随时解除（第九百三十三条）；有偿委托解除方赔偿直接损失和履行后可得利益。禁止“不得解除”。

租赁不定期：合理期限前通知即可解除，不要抄城市房产租赁的解除清单当本类型主路径。

违约金不是必得金额；禁止写“不得调整”。第五百八十五条全文本次若未核验，调整机制法律结论字段停止。

### 7.4 争议

项目所在地法院可约定。出现仲裁条款，不得改写成“应向某法院起诉”。或裁或诉、机构不明：改成单一机构或单一法院连结点。村委会先行调解可作前置协商，不得写成未经调解不得起诉且因此剥夺诉权。

通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。

户主去世：可写本合同对继承人具有约束力，但不得代替继承和共有闭合，也不得写成运营方因此取得宅基地使用权。
