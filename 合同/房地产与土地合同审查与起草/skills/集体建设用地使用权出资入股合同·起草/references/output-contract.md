# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的评估值、股比、年限；把已失效《合同法》《物权法》《担保法》、1993 年公司法第四十八条旧义写入结论；保证入市批复或过户／公司登记一定办成；把出让、租赁或合作开发文本当成已完成的本类型审查；写“签字即过户”；写“未评估也可以先入股”；写“口头三分之二已形成决议”；写“期满土地自动退出破产财产”。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查集体建设用地使用权出资入股合同（土地使用权）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、1991 年土地管理法实施条例或 1993 年公司法第四十八条旧义时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `土地使用权`，子级 `集体建设用地使用权出资入股合同`。定性理由、易混切开结果（出让 / 租赁 / 合作开发 / 明股实债 / 一般出资 / 国有土地）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型、未打开 `集体建设用地使用权出让合同·审查` method。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、决议、评估与文本版本

主体表：签约名、履行名、登记权利人、股权登记名、授权签字人。决议表：会议类型、到会与同意比例、是否先经党组织研究讨论、是否形成书面意见并报送市县。评估表：机构、资质、基准日、评估值、计入注册资本额、溢价。版本表：正文、评估报告、成员决议及名册、入市方案、配套出让草本、章程修正案、聊天确认；冲突并列。

## 5. 标的、作价、双登记与入市程序

地块是否已登记为集体经营性建设用地；年限是否超出参照同类国有建设用地的上限；地上物是否分项；规划条件／产业准入／环保要求是否写入书面合同；使用权变更登记与公司登记是否分列；生效条件是否挂钩书面决议、评估和市县书面意见。缺口标 `G#`。不输出出让金定价主路径，不输出租金递增主路径。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹。农用地入股、未入市、住宅化、假决议、明股实债、集体无限连带不得写成可放行。强制规范只按第一百五十三条区分是否导致民事行为无效，不用失效口诀。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把出让金或租金直接改写成“出资额”而不问是否持股。

## 9. 谈判与签署提醒

谈判顺序：先红线（实为出让／租赁／合作开发、无评估、无集体书面决议、农用地或未入市、明股实债、住宅化、签字即过户），再必须改（方案报送、规划条件三项、双登记期限、地上物与征收、资本公积），最后可优化。签署提醒：集体经济组织公章或依法代行的村委会公章、成员决议及名册、评估报告、入市方案及市县书面意见、配套出让备案件、章程修正案、不动产登记申请材料。不指导倒签或先过户后补决议。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书或效力保证，也不是出让、租赁或合作开发安排。
