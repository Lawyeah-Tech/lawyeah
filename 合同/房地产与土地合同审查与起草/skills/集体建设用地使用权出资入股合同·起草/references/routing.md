# 边界与路由

本技能只审查 **土地使用权 / 集体建设用地使用权出资入股合同** 的待签、已登记集体经营性建设用地使用权作价换股权文本。中文展示名是「审查集体建设用地使用权出资入股合同（土地使用权）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开 `集体建设用地使用权出让合同·审查`、`集体建设用地使用权租赁合同·审查`、`集体建设用地合作开发合同·审查` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 出让金、招拍挂或协议出让、交地起算年期、不形成股权 | `集体建设用地使用权出让合同·审查` |
| 租金、租期、占场使用、到期交回，使用权不作为出资 | `集体建设用地使用权租赁合同·审查` |
| 一方出地一方出钱、利润或物业分成、集体不持股 | `集体建设用地合作开发合同·审查` |
| 房地产货架下的合作开发、联建分房 | `房地产合作开发类合同·审查` |
| 宅基地合作开发 | `宅基地合作开发合同·审查` |
| 宅基地房屋买卖（集体经济组织内部） | `宅基地内部房屋买卖·审查` |
| 国有土地使用权出让 | `国有土地使用权出让合同·审查` |
| 国有土地使用权转让 | `国有土地使用权转让合同·审查` |
| 买项目公司股权只为间接收地 | `以股拿地·审查` |
| 一般货币或实物出资，与集体建设用地无关 | `或` 或 `或` |
| 固定收益、到期回购、不共担损益 | `资金方只收固定货币→第二十三条转` |
| 股权回购条款需要单独成篇且已脱离入股主给付 | `股权回购条款需要单独成篇且已脱离入股主给付` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、只问过户或分红节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或对应专项领域。` 或对应专项领域 |
| 成员起诉撤销决议、债权人执行入股土地已立案 | 争议或执行专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

出资入股正文里夹带一小段配套出让或场地临时占用：出让执行件交接 `集体建设用地使用权出让合同·审查`，临时占用按租赁提示 `集体建设用地使用权租赁合同·审查`；作价换股权条款可继续审。用户坚持本技能把出让、租赁或合作开发整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
