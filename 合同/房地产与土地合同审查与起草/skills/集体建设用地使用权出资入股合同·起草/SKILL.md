# 集体建设用地使用权出资入股合同·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **土地使用权 / 集体建设用地使用权出资入股合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「集体建设用地使用权出资入股合同·起草」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证入市批复或过户／公司登记一定办成、保证评估值必然被登记机关或后续审计接受。

## 本类型硬闸

1. **评估作价**：土地使用权是可以用货币估价并依法转让的非货币财产。对作为出资的非货币财产应当依法评估作价、核实财产，不得高估或者低估。双方口头议价、村干部拍板、“参考周边地价”不得代替评估报告。评估值高于计入注册资本的部分约定计入资本公积。未附评估报告则出资是否缴足字段停止，不得写成“可以先签后补评估”。
2. **集体决议**：集体经营性建设用地使用、出让、出租方案及投资等重大事项，由成员大会决定；成员大会作出决定应当经全体成员三分之二以上同意，成员代表大会应当经全体代表三分之二以上同意。入市方案须依照土地管理法第六十三条由本集体经济组织形成书面意见，并在出让、出租等前不少于十个工作日报市、县人民政府。村委会主任单独签字、两委会议纪要、微信群“没人反对”不得写成已形成法定书面意见。
3. **与出让／租赁／合作开发切开**：正像是集体（或已取得该使用权的主体）以土地使用权**作价换股权**，集体成为股东并承受经营损益。核心给付是出让金、不形成股权 → `集体建设用地使用权出让合同·审查`。核心给付是租金占场、使用权不作为出资 → `集体建设用地使用权租赁合同·审查`。一方出地一方出钱、利润或物业分成、集体不持股 → `集体建设用地合作开发合同·审查`。标题写“入股”但正文全是出让金或年租金的，负触发对应原子，禁止删句后硬套本技能。禁止打开或复制 `集体建设用地使用权出让合同·审查` 的 method。

支撑闸：

4. **标的适格**：必须是国土空间规划确定为工业、商业等经营性用途并已依法登记的集体经营性建设用地。农用地、宅基地、公益事业用地、未入市、权属争议、查封或未解除的在先租赁，不改成可履行入股。
5. **名股实债不得放行**：目标公司定期支付固定收益、到期回购股权、不参与损益、以入股土地抵押担保本息的，按借贷切开 `资金方只收固定货币→第二十三条转` 或整体停止。
6. **合同成立 ≠ 使用权移转 ≠ 股权登记**：书面合同可以约定生效条件；集体建设用地使用权出资应当申请变更登记；股权须记载并办理公司登记。禁止写“签字盖章即视为过户完成”。禁止写“入股期满土地使用权自动归还集体、不属于破产财产”。
7. **禁止住宅化与无限连带**：借入股在工业／商业用地上开发住宅、别墅、私人会所或对外销售小产权房，只出告知。集体组织不得被改写成以全部集体财产为目标公司债务提供连带担保。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签出资入股正文，尚未签署，尚未成争，核心给付是已登记集体经营性建设用地使用权作价换股权，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 收取出让金、招拍挂或协议出让、不形成股权 → `集体建设用地使用权出让合同·审查`；
- 租金、租期、占场使用、到期交回，使用权不作为出资 → `集体建设用地使用权租赁合同·审查`；
- 一方出地一方出钱、利润或物业分成、集体不持股 → `集体建设用地合作开发合同·审查`；房地产货架下同类合作开发 → `房地产合作开发类合同·审查`；宅基地合作开发 → `宅基地合作开发合同·审查`；
- 买项目公司股权只为获取土地 → `以股拿地·审查`；
- 国有建设用地出让或转让 → `国有土地使用权出让合同·审查` 或 `国有土地使用权转让合同·审查`；
- 一般货币或实物出资、与集体建设用地无关 → `或` 或 `或`；
- 固定收益加回购、不共担损益 → `资金方只收固定货币→第二十三条转`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问过户日、验资日、分红日 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁或成员起诉撤销决议 → `或对应专项领域。` 或对应专项。

以入股为名把农用地、未入市土地或住宅开发改成可履行结构：只出告知，不改写成可履行路径。

## 建立起草坐标

确认：使用者与授权；单方立场；相对方；全文及附件／评估报告／成员决议／入市方案／配套出让合同版本；地块是否已登记为集体经营性建设用地；对价是股权还是出让金／租金／分成；是否固定收益加回购；决议机构与比例；评估机构与基准日；目标公司新设或增资；地上物是否一并入股；权利负担；规划条件／产业准入／环保要求是否写入书面合同；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 起草模式

本原子只承担本类型起草。待签评改转 `集体建设用地使用权出资入股合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。商业数字未给用 `【待填】`。

按框架六步落稿。本类型硬闸改成下列起草必写 / 附件必附 / 禁止出现。

### 起草必写

- 核心给付是已登记集体经营性建设用地使用权作价换股权，集体成为股东并承受经营损益。
- 非货币财产必须依法评估作价；评估值高于计入注册资本的部分约定计入资本公积。
- 成员大会作出决定须经全体成员三分之二以上同意（代表大会须全体代表三分之二以上）；入市方案报市、县人民政府不少于十个工作日。
- 书面合同可以约定生效条件；使用权变更登记与公司股权登记分列，合同成立不等于使用权移转，也不等于股权登记完成。

### 附件必附

- 评估报告。
- 成员书面决议、签到、表决记录或章程。
- 入市方案；规划条件、产业准入、环保要求。
- 权属证书；地上物分项评估（如一并入股）。

### 禁止出现

- 口头议价、村干部拍板、“参考周边地价”代替评估，或“可以先签后补评估”。
- “签字盖章即视为过户完成”；“入股期满土地使用权自动归还集体、不属于破产财产”。
- 目标公司定期支付固定收益、到期回购股权、不参与损益、以入股土地抵押担保本息。
- 借入股在工业／商业用地上开发住宅、别墅、私人会所或对外销售小产权房。
- 集体组织以全部集体财产为目标公司债务提供连带担保。
- 把出让金或年租金主给付改写入股外壳。

出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 本任务起草模式；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有出资入股文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。出让、租赁、合作开发、明股实债、一般出资、国有土地、宅基地负触发。

### 2. 主体与集体决议

已设立农村集体经济组织的，由该组织签约；未设立的，村民委员会方可依法代行。成员书面决议未达法定比例则签署能力字段停止。

### 3. 标的适格与权利负担

经营性建设用地、证书、负担、地上物分项评估。材料未提负担不得写成无负担。

### 4. 评估作价与股权

评估报告、出资额、股比、溢价入资本公积。未评估不得放行。

### 5. 入市方案、配套出让与双登记

方案报市县；规划条件／产业准入／环保要求写入书面合同；使用权变更登记与公司登记分列。配套出让只作备案执行件，不改走 `集体建设用地使用权出让合同·审查`。

### 6. 格式条款与强制规范

无核验引文则法律结论字段停止。农用地入股、住宅开发、假决议不得改成可履行。

### 7. 退出、征收、破产与担保

回赎或优先购买可写；不得写成自动退出破产财产。集体仅以出资额为限承担责任。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把租赁或合作开发改成入股外壳、把无评估或无集体决议改成可履行、把农用地或住宅开发改成可履行。
- `字段停止`：法域、动态规则、决议比例、评估基准、入市书面意见、权属负担未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
