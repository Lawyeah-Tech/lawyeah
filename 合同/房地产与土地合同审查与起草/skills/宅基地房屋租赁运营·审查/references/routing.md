# 边界与路由

本技能只审查 **土地使用权 / 宅基地房屋租赁合同_委托运营合同** 的待签、集体土地上已建村民住宅的租赁或委托运营文本。中文展示名是「审查宅基地房屋租赁合同_委托运营合同（土地使用权）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或复制 `禁止打开或复制`、`宅基地内部房屋买卖·审查` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 房屋连同宅基地使用权让与；过户；永久或终身买断；双方均本集体成员 | `宅基地内部房屋买卖·审查` |
| 城镇居民、外集体或公司购买农房、要求过户或“转让宅基地使用权” | 只告知，不改成可履行过户，不启动本任务实体放行 |
| 一方出地、一方出资改建或新建；按层或面积分房；固定收益换长期占用且权证仍在原村民名下 | `宅基地合作开发合同·审查` |
| 国有建设用地上城市或镇规划区内房屋占有换租金 | `禁止打开或复制` |
| 集体经营性建设用地出租 | `集体建设用地使用权租赁合同·审查` |
| 集体经营性建设用地出让／出资入股／合作开发 | `集体建设用地使用权出让合同·审查`／`集体建设用地使用权出资入股合同·审查`／`集体建设用地合作开发合同·审查` |
| 承包地或土地经营权流转 | 农村土地承包专项，不在本任务评改 |
| 主给付是设立居住权 | `主给付是设立居住权→` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或对应专项领域。` 或对应专项领域 |
| 征收补偿争议已立案 | 征收或争议专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

租赁或委托运营正文里夹带一小段居住安排或装修标准：可留在本约配套条款改。用户坚持本技能把买卖、合作开发或城市房产租赁整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿本类型文本来找未装本原子的专业版：输出 `unavailable`，提示，不得用邻类硬套。
