# 宅基地房屋租赁运营·审查

## 任务目标

在单一立场下，只审查 **土地使用权 / 宅基地房屋租赁合同_委托运营合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「宅基地房屋租赁运营·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证村委会备案或民宿执照一定办成、把对外买卖改成可履行过户、把出地共建改成可履行合作开发。

## 本类型硬闸

1. **租赁 ≠ 委托运营**：按核心给付切开，不用标题单独定性。出租人把房屋交付对方占有、使用、收益，对价是租金（含保底租金）→ 租赁，走民法典第七百零三条以下。委托人仍控制房屋或仅授予招商、管理、代订客单权限，对价是管理费或利润分成，经营风险主要由委托人承担 → 委托运营，走第九百一十九条以下。名委实租（独占交付、可转租、固定或保底租金、委托人不得入住）按租赁审期限与转租，不按“委托不受二十年限制”放行。
2. **期限**：构成租赁的，租期不得超过二十年；超过部分无效。修改句截到二十年，不把整约写成当然无效。签约时即约定“二十年后再自动续二十年”不得当作第七百零五条第二款的有效续订。标题写委托运营、合作期二十至三十年，但给付仍是独占占有加固定或保底租金的，按租赁穿透。真委托不受第七百零五条强制限值，但须写明第九百三十三条随时解除及有偿委托的损害赔偿，不得写成“不可解除的三十年经营权”。
3. **成员资格**：出租人／委托人必须是该宅基地及房屋的合法权利人。宅基地以户为单位，户内共同共有人未全体签署或未出具书面同意的，该处分字段停止。承租人／运营方可以是城镇居民、法人或非法人组织；不得仅因对方不是本集体成员就写成租赁必然无效。成员资格按《农村集体经济组织法》第十一条、第十二条核名册与权利义务关系，不得把“户口本同村”自动写成适格权利人。把非本集体成员的占用改成可履行买卖过户：只告知，整体停止。
4. **与买卖／合作开发切开**：永久或终身占用、一次性高额买断、约定过户或“转让宅基地使用权” → `宅基地内部房屋买卖·审查`（仅当双方均为本集体成员时才交接该原子；对外买卖只告知，不改成可履行过户）。一方出地、一方出资改建或新建、建成后分房或固定收益、使用权仍登记在原村民名下 → `宅基地合作开发合同·审查`。禁止打开或复制 `禁止打开或复制`、`宅基地内部房屋买卖·审查` 的 method。不得把报批不成改写成“永久使用权租赁”，也不得把本约改成城市房屋维修／优先购买主路径。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签宅基地房屋租赁或委托运营正文，尚未签署，尚未成争，核心给付是集体土地上已建村民住宅的占有使用换租金，或受托就该房屋经营并分配收益，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 房屋连同占用范围内宅基地使用权让与、过户、永久买断 → `宅基地内部房屋买卖·审查`（双方均本集体成员）；城镇居民、外集体或公司买房 → 只告知，不改成可履行过户，不启动本任务实体放行；
- 一方出地、一方出资改建或新建，按面积或层数分房，或固定收益换长期占用 → `宅基地合作开发合同·审查`；
- 国有建设用地上城市、镇规划区内房屋占有换租金，权证为国有土地使用权 → `禁止打开或复制`；
- 集体经营性建设用地出租、出让、出资入股或合作开发 → `集体建设用地使用权租赁合同·审查`／`集体建设用地使用权出让合同·审查`／`集体建设用地使用权出资入股合同·审查`／`集体建设用地合作开发合同·审查`；
- 承包地或土地经营权流转 → 农村土地承包专项，不在本任务评改；
- 主给付是设立居住权 → `主给付是设立居住权→`；
- 无文本、本类型条件已谈妥、要出己方稿 → `宅基地房屋租赁运营·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁或征收补偿争议已立案 → `或对应专项领域。` 或征收／争议专项。

挂靠、违法分包、规避限购、强制农户退出宅基地、违法经营用途、查封后倒签租约：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及权属证书／户口或成员名册／家庭成员同意书／村集体意见版本；是独占交付还是代为经营；租期或合作期起止；对价是固定租金、保底加分成还是纯管理费；户内共有人是否到场；房屋报建与规划许可；抵押、查封、居住权；拟经营业态与证照；征收是否已启动；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `宅基地房屋租赁运营·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议或征收专项。未签且目标是评改已有本类型文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。买卖、合作开发、城市房产租赁、集体建设用地出租、承包地流转负触发。

### 2. 租赁与委托运营切开

独占占有加租金按租赁；代为经营加管理费或分成按委托。名委实租按租赁审。

### 3. 成员资格与共有人

出租人须为权利人；户内共有人全体签署或同意。承租人不必是本集体成员。对外买卖停笔。

### 4. 期限与书面

租赁截到二十年；六个月以上应当书面；备案不是生效要件。真委托写随时解除。

### 5. 标的、报建、负担与改建

四至与证载；规划报建；抵押、查封、居住权；改建须书面同意并协助报批，不得写成已可加建。

### 6. 对价、征收预切与证照

租金或分成基数；增添物归属；土地补偿归农户，装修和停产停业损失可另切；经营证照由运营方办理。

### 7. 格式条款与强制规范

无核验引文则法律结论字段停止。违法用途、强制退出宅基地不得改成可履行。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把对外买卖改成可过户或永久租赁、把出地共建改成租赁外壳、把违建或违法用途改成可履行、强制农户退出宅基地。
- `字段停止`：法域、地方盘活或许可窗口、成员名册、共有人名单、证载与现状差异、征收范围未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
