# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的本金、利率、账户；把已失效《合同法》借款章、24%/36%/旧四倍写入结论；把第 679 条写成混主体成立规则；把持牌小贷按民间四倍改完；把转贷、职业放贷或资金池改成可履行；把无决议写成可以盖章；把配偶未签写成已经共债；把流质过户写成可履行。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查广义民间借款合同（借款合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》借款章、法释〔2015〕18 号 24%/36%、法释〔2018〕2 号、1991 年借贷意见时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `借款合同`，子级 `广义民间借款合同`。定性理由、易混切开结果（金融机构借款、自然人之间的借款、企业间借款、狭义民间借款、保证借款、抵押借款、让与担保）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。挂靠、职业放贷、转贷、资金池写停笔告知，不填可履行放贷结构。

## 4. 主体、决议、资质与文本版本

主体表：签约名、履行名、付款名、自然人身份或企业执照名、法定代表人或授权签字人。资格表：哪一方是自然人、哪一方是企业、出借人是否持牌、是否以放贷为业、平台是否签约主体。决议/共签表：企业章程机关与董事会/股东会决议；自然人借款人配偶共签或追认痕迹。版本表：正文、附件、平台页、决议、聊天确认；冲突并列。未见企业决议：该签署能力字段停止。未见共签：共债字段停止，不写成已经是共同债务。

## 5. 给付闭环

本金大小写与币种；到账账户与是否预扣（含平台费）；用途；资金是否自有；利率与费用；期限与还本付息节点。缺口标 `G#`，不补商业数字。批准、登记、内部决议、电子签名核验写成生效条件或期限，不写成已经完成。不输出银行受托支付、自然人交付成立主路径或企业间第 10 条生产经营主路径。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹；异常加速到期；平台格式勾选。强制规范只按第 153 条和解释第 16 条区分。第 13 条转贷/职业放贷/知情违法、平台资金池只保留识别与停笔。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把框架里的持牌小贷准入、P2P 备案经营或“一律实践合同”写成默认句。

## 9. 谈判与签署提醒

谈判顺序：先红线（持牌/双方自然人/双方企业错位、转贷、职业放贷、资金池、知情违法、流质过户），再必须改（成立分轨、到账本金、利率落入 LPR×4、企业决议附件、删除 24%/36%），最后可优化。签署提醒：企业公章 + 法定代表人或授权人签字；自然人亲笔签名；决议、资金来源承诺入附件；配偶共签只作字段，不写成已认定共债。不指导倒签或补假决议。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本任务只出审查意见与修改句，不出整份起草终稿。无文本出稿转配对起草原子。不是履约交底、争议文书、清收策略或效力保证，也不是金融机构借款、自然人实践性借款、企业间借款或狭义偶发民间借款审查。
