一、合同类型（法律性质）分析

1.  **法律定性**
    * **定义**：民间借款合同是借款人向贷款人借款，到期返还借款并支付利息的合同。本类型特指排除持牌金融机构，但包括小额贷款公司、P2P网络借贷平台、私人钱庄等准金融组织在内的广义民间借贷。
    * **法律适用**：主要适用《民法典》借款合同章及《最高人民法院关于审理民间借贷案件适用法律若干问题的规定》（简称《民间借贷司法解释》）。
    * **合同成立**：民间借款合同是实践合同，自贷款人提供借款时成立。但当事人另有约定（如约定放款日）或为网络借贷等形式的除外。

2.  **易混淆辨析**
    * **名为A实为B**：
        * **名为投资，实为借贷**：约定固定回报，不承担经营风险的“投资款”，通常被认定为借贷。
        * **名为买卖，实为借贷**：约定“回购”或“差价”，但无真实货物交付的“贸易”，实质是借贷。
        * **名为居间，实为借贷**：P2P平台等网络中介，如提供担保或建立资金池，可能被认定为承担共同借款责任或非法集资。
    * **法律后果**：穿透审查交易实质，按实际法律关系（借贷）处理，特别是关于利息上限的规定。

3.  **效力认定（高风险）**
    * **合同无效的法定情形**：
        * **非法目的**：明知借款用于赌博、吸毒、走私等违法犯罪活动。
        * **“套路贷”**：以非法占有为目的，通过虚增债务、伪造证据等方式形成的借贷。
        * **“高利转贷”**：从金融机构套取信贷资金，再高利转借他人，且出借人明知。
        * **非法集资**：出借人明知集资人从事非法集资（如非法吸收公众存款）仍提供借款。
        * **职业放贷**：未经监管部门批准，以营利为目的，向社会不特定对象提供借款，扰乱金融市场秩序。
        * **违反公序良俗**：其他违反法律、行政法规强制性规定或公序良俗的行为。
    * **利息约定（核心风险）**：
        * **利率上限**：双方约定的利率，**不得超过合同成立时一年期贷款市场报价利率（LPR）的四倍**。超过部分无效。
        * **预扣利息（砍头息）**：出借人预先在本金中扣除利息。**法律严禁此行为**。如发生，应以**实际出借的金额**（扣除利息后）作为本金。
        * **复利限制**：约定的复利（利滚利）必须以未支付的利息为基数，且计入本金后的总利率**不得超过LPR的四倍**。
        * **其他费用**：出借人与借款人约定的逾期利率、违约金、律师费等**其他费用总计**，超过合同成立时一年期LPR四倍的部分，法院不予支持。

4.  **适用场景**
    * 传统私人借贷、亲友互助。
    * 企业间临时周转（非以放贷为主业）。
    * 小额贷款公司、融资租赁公司等准金融机构业务。
    * P2P、网络小贷等互联网金融平台。

二、合同主体（交易对手）分析

1.  **主体适格性**
    * **出借人（贷款人）**：
        * **自然人**：具有完全民事行为能力。
        * **非金融企业**：允许偶发性、非经常性借贷。**严禁“职业放贷”**，即未经批准，以放贷为常业。
        * **准金融组织**：如小额贷款公司、担保公司、P2P平台，必须持有相应的**经营资质**或**备案**。
    * **借款人（借款人）**：
        * 自然人、个体工商户、法人、非法人组织。
        * 如借款人为自然人，需关注其是否已婚，配偶是否知悉。

2.  **资质许可**
    * 小额贷款公司、融资租赁公司、担保公司等，必须取得政府金融主管部门的**批准文件**或许可证。
    * P2P网络借贷平台，需符合网络借贷信息中介机构的监管要求。

3.  **高频风险**
    * **主体不适格**：出借人属于**“职业放贷”**主体，合同可能被认定无效。
    * **无权/越权代表**：借款方经办人无充分授权（如职务代理或书面授权）。
    * **P2P平台风险**：平台可能存在自融、设立资金池、提供担保等违规行为，甚至构成非法集资。

4.  **关联主体（重要）**
    * **配偶（借款人为自然人时）**：
        * **风险**：该债务是否构成**夫妻共同债务**。
        * **认定**：关键看是否有“共同签字”或“事后追认”，或者借款用于“夫妻共同生活、共同生产经营”。
        * **措施**：如希望认定为共同债务，应要求其配偶**共同签字**或出具《知晓并同意借款函》。
    * **保证人**：
        * **风险**：保证人主体不适格（如未经授权的分支机构、公益性事业单位）。
        * **措施**：审查保证人资格，明确约定保证方式（一般保证或连带责任保证）和保证期间。
    * **公司（借款人为公司时）**：
        * **风险**：借款事项（尤其涉及对外担保时）未履行《公司法》规定的内部决策程序。
        * **措施**：要求对方提供相应的**股东（大）会决议**或**董事会决议**。

三、合同标的（交易对象）分析

1.  **标的适格性**
    * **标的**：**货币**。
    * **出借人资金来源（高风险）**：
        * **禁止“高利转贷”**：出借人不得使用**从银行等金融机构套取的信贷资金**转贷牟利。
        * **禁止非法集资**：出借人的资金不得来源于非法吸收公众存款、集资诈骗等。
        * **后果**：如资金来源非法，借款合同可能被认定无效。
    * **借款人资金用途（高风险）**：
        * **用途限制**：借款人不得将借款用于**非法活动**（如赌博、贩毒、走私）。
        * **后果**：如出借人明知借款人用于非法活动，合同无效，且利息、本金（系赃款的）可能被没收。

2.  **权属风险**
    * 不适用（标的为货币）。

3.  **特殊标的**
    * 不适用。

4.  **风险转移**
    * **本金交付（风险点）**：
        * **风险**：借款合同自**款项交付**时成立（实践合同）。如未交付或交付凭证缺失，合同不成立或本金数额认定困难。
        * **防范**：
            * **禁止现金**：尽量避免大额现金交付，应通过**银行转账**。
            * **明确附言**：转账凭证应备注“借款”、“贷款”等。
            * **凭证合一**：确保《借款合同》、**《借条》**（或《收据》）与**银行转账凭证**三者在主体、金额、时间上能相互印证。
    * **预扣利息的认定**：
        * **风险**：出借人主张按借条/合同金额（如70万）为本金，借款人主张按实际收款（如50万）为本金。
        * **认定**：法院会以**实际交付**的金额（50万）作为本金，预扣的20万计入利息。

四、合同程序（交易步骤）分析

1.  **法定前置程序**
    * **批准（审批）**：
        * 准金融组织（如小贷公司）的**设立**和**经营范围**需经金融主管部门批准。
        * P2P平台需按规定**备案**。
    * **登记/备案**：以房产、车辆、股权等提供抵押/质押担保的，必须办理**抵押/质押登记**，担保物权自登记时设立。

2.  **内部决策程序**
    * **公司借款（借款人）**：公司为他人（尤其是股东或实际控制人）提供担保的，必须依据《公司法》和公司章程，由**董事会**或**股东（大）会**作出决议。
    * **准金融组织（出借人）**：应有合规的内部信审和放款流程。

3.  **特殊交易程序**
    * **网络借贷（P2P）**：需通过平台进行实名认证、信息发布、电子合同签订、资金存管账户划转等特定程序。

4.  **附加程序**
    * **公证**：为规避诉讼，可（非必须）对借款合同办理**强制执行公证**。一旦借款人违约，出借人可凭公证文书直接申请法院强制执行。

五、交易结构设计（风险规避方案）

1.  **担保措施**
    * **典型担保**：
        * **保证**：要求借款人的关联方（如配偶、股东、实际控制人）或第三方提供连带责任保证。
        * **抵押**：要求借款人提供不动产、车辆等作为抵押。
        * **质押**：要求借款人提供股权、应收账款、存款单等作为质押。
    * **非典型担保**：
        * **律师费/实现债权费用**：在合同中明确约定，借款人违约的，应**另行承担**出借人为实现债权所支付的律师费、诉讼费等（总额受4倍LPR上限约束）。
        * **利息转本金**：如借款到期，可（在不超过上限的前提下）将利息转为本金，并**重新签订借款合同**或补充协议，此为合法。

2.  **结构选择**
    * **避免“砍头息”**：
        * **错误结构**：借50万，出具70万借条，实际转账50万。
        * **正确结构**：借50万，出具50万借条，转账50万。利息按月或按季另行支付。
    * **利息支付方式**：
        * 为防止借款人到期无力支付高额利息，可设计为**按月**或**按季**支付利息，到期归还本金。

3.  **风险隔离**
    * **P2P平台**：严格遵守**信息中介**定位，不得设立资金池，应通过**银行存管**实现资金隔离，避免平台自身承担借款责任或被认定为非法集资。

4.  **文本形态设计**
    * **文件组合**：
        * **《借款合同》**：明确约定利率、期限、违约责任等核心条款。
        * **《借条》/《收据》**：作为款项交付的凭证，应由借款人亲笔出具。
        * **《转账凭证》**：银行流水，是证明款项交付的最重要证据。
    * **还款文件**：
        * 借款人还款时，应要求出借人出具**《收据》**，并**收回《借条》**原件。如部分还款，应在原借条上注明或重新出具借条。

六、宏观风险预警与尽调指引

1.  **高频争议点**
    * **本金数额认定**：尤其是大额现金交付、转账后立即回转、“砍头息”等情形。
    * **利率与费用**：利息约定不明、超过4倍LPR上限、违约金/律师费等其他费用合计超限。
    * **款项交付**：未实际支付（合同不成立）。
    * **是否构成夫妻共同债务**。
    * **P2P平台责任**：平台是中介、保证人还是共同借款人。

2.  **尽职调查清单**
    * **出借人（自查）**：
        * 资金来源是否合法？是否涉嫌“高利转贷”或“非法集资”？
        * 是否构成“职业放贷”？（如一年内多次放贷）
    * **借款人（调查）**：
        * 主体身份真实性、民事行为能力。
        * 借款真实**用途**？（防止用于非法活动）
        * 信用状况、偿债能力。
        * （如为公司）是否履行内部决策程序？
        * （如为个人）婚姻状况？
    * **担保人（调查）**：
        * 担保资格、担保能力。
        * （如为公司）是否履行内部决策程序？

3.  **宏观风险预警**
    * **最高风险：刑事犯罪**
        * **出借人**：可能触犯**非法吸收公众存款罪**、**集资诈骗罪**（如P2P平台）、**高利转贷罪**。
        * **借款人**：可能触犯**贷款诈骗罪**（如提供虚假材料）。
        * **双方**：可能涉及洗钱、“套路贷”等。
    * **次高风险：合同无效**
        * 因主体不适格（职业放贷）、标的非法（高利转贷、非法集资款）、目的非法（用于赌博），导致合同无效，**利息约定无效**，本金收回可能面临重大障碍。
    * **核心风险：利率无效**
        * **利息总和（利息+违约金+其他费用）不得超过合同成立时LPR的四倍**。这是民间借贷的“天条”，任何试图通过“阴阳合同”、“服务费”、“咨询费”等名目规避的行为，均不被法律支持。
