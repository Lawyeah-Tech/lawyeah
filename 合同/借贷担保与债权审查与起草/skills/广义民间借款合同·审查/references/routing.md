# 边界与路由

本技能只审查 **借款合同 / 广义民间借款合同** 的待签文本。中文展示名是「审查广义民间借款合同（借款合同）」。主线是非持牌混主体互借，以及平台/电子/未持牌准金融外壳。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 出借人是商业银行等持牌放贷机构，或法释〔2020〕27 号七类地方金融组织 | `金融机构借款合同·审查`。不得用本技能的民间四倍审持牌稿 |
| 双方均为自然人，且平台不是签约主体、也无资金池/兑付主导 | `自然人之间的借款合同·审查`。不得用本技能的诺成分轨否定自然人实践性 |
| 双方均为非金融企业，用途为生产经营拆借 | `企业间借款合同·审查`。不得用本技能的混主体规则改企业互借 |
| 偶发、非经营性、无平台、无准金融外壳、也不是混主体主结构 | `狭义民间借款合同·审查`。不得把狭义偶发借条硬留本技能 |
| 同一文本以保证条款 + 保证人签章为主结构 | `保证借款合同·审查`。本约只审对保证的引用是否闭环 |
| 抵押财产、登记、流押主导放行 | `抵押借款合同·审查` |
| 质押、权利凭证移交或股权出质主导 | `质押借款合同·审查` |
| 买卖过户、回购或不清算归债权人所有作为还款担保的主结构 | `让与担保型借款合同·审查`。不得改成可过户履行 |
| 真实合伙、共负盈亏、无法人执照的个人合伙 | `真实合伙共负盈亏无法人执照的个人合伙`。保底固定回报不走合伙 |
| 无文本、本类型条件已谈妥、要出己方稿 | `广义民间借款合同·起草` |
| 已签未争、只问放款或还本付息节点 | 本套导航的履约步骤 |
| 已成争、催告、立案或清收 | `或` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

混主体正文里夹带一小段保证或抵押：专条交接对应担保原子；本金、到账、利率、平台角色、企业决议条款可继续审。用户坚持本技能把银行贷款、双方自然人实践性、企业间生产经营、狭义偶发借条、保证/抵押主文件或清收整案改完：`目标停止`。

不得把本约改写成持牌贷款、委托贷款通道或可履行的无证放贷/网贷资金池。P2P 清退后不得出“补备案就能经营平台放贷”的改写。
