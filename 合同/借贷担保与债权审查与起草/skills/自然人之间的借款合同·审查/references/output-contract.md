# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的本金、利率、期限、账户；把已失效《合同法》《担保法》及其解释写入结论；把银行利率旧四倍、年利率 24% 或 36% 写成现行保护上限；把签字写成合同已经成立；把已婚写成夫妻共同债务；把“担保/保证”写成连带责任保证。

## 1. 触发、单方立场与成果状态

立场（出借人 / 借款人 / 拟签字配偶或保证人）、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明双方是否均为自然人。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》《担保法》及其解释、1991 年借贷意见或 2015 年 24%/36% 条文时记噪声，不得写入 `L#`。利率上限、实践性、砍头息、共债、保证方式无 `verified-result` 时，对应法律结论字段停止。

## 3. 类型与加载路径

父级 `借款合同`，子级 `自然人之间的借款合同`。定性理由必须同时满足：双方自然人；核心给付为资金借贷。易混切开：企业间、金融机构、狭义民间（含企业一方）、保证/抵押/质押主结构、让与担保、名为投资实为借贷。

加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读其他类型。职业放贷、转贷或违法用途写停笔告知，不填可履行放贷结构。

## 4. 主体、授权、资质与文本版本

主体表：出借人、借款人、指定收款人、共同借款人栏、保证人、拟签字配偶。自然人写姓名与证件号是否与文本一致；名称不一致不自动合并。

版本表：正文、借条/收条、账户页、聊天确认。冲突并列，不选对用户有利的一版。口头“配偶同意了”不得写成已追认。

## 5. 借贷给付闭环

分列并回链文本位置：

- 本金：阿拉伯数字与大写、币种；不一致标 `C#`，修改句写明以何者为准，不擅自改数。
- 交付：转账 / 现金 / 票据 / 指定第三人账户；指定账户户名是否与借款人一致。
- 实际提供额：面额、预扣、服务费、保证金是否从本金扣除。
- 成立时点：是否写成签字即成立、签字即生效。必须改成提供借款时成立，并指向实际交付完成的判断点。
- 用途：具体用途与禁止违法用途、禁止转贷。
- 利息与费用：有无书面利率；年利率还是月利率；服务费、咨询费、违约金、逾期利息是否并行。
- 期限与还款：起止日、还款方式、还款账户、提前还款、加速到期。

缺口标 `G#`，不补商业数字。批准、公证、抵押登记写成条件或双方义务期限，不写成已经完成。

## 6. 格式条款、强制规范与本类型效力红旗

自然人互借通常不是重复使用的格式条款；一方以经营放贷为业、预先拟定且未协商的，仍按格式条款审查提示说明。

强制规范与效力红旗只在核验后落法律结论：套取金融机构贷款转贷；集资或非法吸收资金转贷；未取得放贷资格而以营利为目的向不特定对象提供借款；出借人事先知道或应当知道用于违法犯罪仍提供借款。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔/转出口径。禁止输出无修改句的色块表。

本类型至少检查：实践性被写成签字成立；砍头息或面额与实付不一致；利率/费用未核验或疑似超过保护上限；利息约定不明却按有息执行；已婚或打印配偶栏被写成共债；保证方式不明被写成连带；保证期间写成还清为止或两年推定；现金大额无收条；账户户名不一致；倒签日期。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`，不编造。禁止只给原则、不给句子。

建议句必须覆盖本类型硬闸：成立时点、实际交付本金、利率上限待核表述、共债共签不得写成已成立共债、保证方式与期间点名。

## 9. 谈判与签署提醒

谈判顺序：先红线（违法用途、转贷、职业放贷、倒签、流质），再必须改（成立时点、砍头息、利率核验、保证方式、账户一致），最后可优化。

签署提醒：本人签名与指印；配偶或保证人必须本人签，不得代签；日期真实；附件含收款确认书或转账回单；打款备注写明借款。不指导倒签或补假授权、假收条。

出借人立场可建议共债共签作为增信，但必须同时写明：未共签不得当成已是夫妻共同债务。借款人或配偶立场必须提示：签字可能构成共同意思表示，扩张责任。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本任务只出审查意见与修改句，不出整份起草终稿。无文本出稿转配对起草原子。不是履约交底、争议文书、利息精算终局或效力保证。
