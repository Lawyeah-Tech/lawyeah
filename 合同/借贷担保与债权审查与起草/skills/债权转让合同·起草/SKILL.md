# 债权转让合同·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构，不证明本约条款已被接受。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》第七十九条至第八十三条及其解释、已失效《物权法》《担保法》及其解释当作现行规则。不得把禁止转让特约一律写成“不得对抗善意第三人”，也不得写成特约使转让合同当然无效。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **债权转让合同 / 债权转让合同**，输出可编辑草稿、未决项、自审风险表与自审后修改句。有完整待签文本要评改时，转 `债权转让合同·审查`。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。`depends-on` 为空。不要求先跑导航。

不交付：他类审查或起草、待签文本评改、履约催收交底、争议追索文书、有效性或必然收款保证、整份保证／抵押主文件审查。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿；尚未签署，尚未成争；核心给付是**不改变债之内容**，债权人将已特定（或可特定）的全部或部分债权让与第三人，受让人支付对价（无偿须点名）；债务人主体不变。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 债务人换人、须债权人同意 → `债务人换人须债权人同意→`；
- 代付款三方、第三人不加入债务只代为支付 → `代付款三方第三人不加入债务只代为支付→`；
- 保理（有追索／无追索融资、将有应收账款管理或付款担保为主结构）→ 本套导航的类型切开步骤 或保理专项；不得删掉融资条款后继续当单纯让与审；
- 买的是股权 → `买的是股权→`；
- 买特定资产、不按债权让与 → `买特定资产不按债权让与→`；
- 主文件是保证或抵押借款 → `一般保证合同·审查`／`连带责任保证合同·审查`／`抵押借款合同·审查`；本约若另有让与正文，担保只作从权利红旗；
- 有完整待签文本要评改 → `债权转让合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问催收、通知留痕、回款节点 → 本套导航的履约步骤；
- 已成争（催告、追索起诉策略、立案、开庭、仲裁）→ 合同争议领域，不填签前十节。

虚构债权、通谋逃债或洗钱、场外国资重大资产转让规避进场：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；转或受单一立场；债务人是否列为一方；正文、债权清单、通知书、基础合同版本；标的是否特定；不可接受事项；法域与拟签时限。缺立场或本类型条件未谈妥则不启动起草。同时掌握双方秘密时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的金额、清单编号、通知日用 `【待填】`，不编造。

## 本类型硬闸

审查过程必须逐项点名，不得用股权优先购买或保证从属性清单代替：

1. **可转让性（545）**：性质不得转（人身信任、抚养费、人身损害赔偿）、法律禁止转、约定不得转。约定特约按核验条：非金钱债权不得对抗善意第三人，金钱债权不得对抗第三人——不编造绝对无效。虚构债权、已过时效未披露：陈述保证 + 解除／降价。
2. **通知债务人（546）**：未经通知对债务人不发生效力。修改句把书面通知（内容、送达、共同通知）写成付款先决条件。禁止写成“未通知则转让合同无效”。诉讼送达可视为通知，但签前不得依赖“起诉时再说”。
3. **从权利随同（547）**：担保、利息等一并转移，专属于转让人的除外。抵押权等须办变更登记以免处分风险。保证人通知按第 696 条。本任务不整份代审保证／抵押主文件（转 `一般保证合同·审查`／`连带责任保证合同·审查`／`抵押借款合同·审查`）。
4. **债务转移切开**：债务人换人、须债权人同意 → `债务人换人须债权人同意→`。代付款三方 → `代付款三方第三人不加入债务只代为支付→`。保理融资不按单纯债权让与放行全部融资条款。
5. **对价与真实性**：转让价款、交割、债权清单、基础合同与履行凭证必须特定。禁止“一切现有未来应收账款一揽子”而无清单仍当本类型放行。
6. **国资／不良资产**：国企债权进场评估挂牌未履行：生效字段停止，不写场外协议可履行。受让人负面清单（法规限制的主体）未核验：字段停止。
7. **债务人抗辩与抵销（548／549）**：必须提示受让人：债务人可向受让人主张对原债权人的抗辩；符合条件可抵销。禁止写成“转让后债务人不得再抗辩”。


## 起草模式

本原子只承担本类型起草。待签评改转 `债权转让合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。本类型硬闸改成正文必写、附件必附或禁止出现。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 标的债权可特定：基础合同、未偿金额或确定方法；陈述保证覆盖真实性，已过时效须披露。
- 书面通知债务人（内容、送达、共同通知）写成对债务人发生效力及（如有）付款先决条件；不写未通知则转让合同无效。
- 担保、利息等从权利一并转移，专属于转让人的除外；抵押权等写变更登记安排；保证人通知按第 696 条。
- 转让价款、交割、债权清单必须特定。
- 提示受让人：债务人可向受让人主张对原债权人的抗辩；符合条件可抵销。

### 附件必附

- 债权清单、基础合同与履行凭证。
- 书面通知债务人文本。
- 有抵押权等从权利时：变更登记安排；保证人通知安排。
- 国企债权：进场评估挂牌材料（未履行则不写场外协议可履行）。
- 无对应事实不编造附件，缺项写入未决项。

### 禁止出现

- “未通知则转让合同无效”；签前依赖“起诉时再说”完成通知。
- “一切现有未来应收账款一揽子”而无清单仍按本类型放行。
- “转让后债务人不得再抗辩”。
- 债务人换人、须债权人同意仍按本类型改完。
- 保理融资条款按单纯债权让与放行。
- 场外国资重大资产转让写成可履行。
- 约定不得转不核验对抗效力即写成绝对无效。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典第五百四十五条至第五百四十九条、第五百五十一条、第四百零七条、第六百九十六条，以及《合同编通则解释》第四十九条、第五十条；`search_practiced` 补通知与二重转让反例；`search_template` 只借修改句结构。不虚构案件系统。

`search_law` 对法律结论为 required 级节点：不可用时不拒绝执行，只停止法律结论字段。返回已失效《合同法》第七十九条至第八十三条或其解释时记为噪声，不得写入 `L#`。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；条件未谈妥仍要出可签署终稿；用户坚持伪造倒签、虚构债权、通谋逃债或洗钱、把人身性或法律禁止转让债权改成可履行让与、场外规避国资进场、保证未通知则合同无效或转让后不得抗辩、保证必然收到债款。
- `字段停止`：基础合同禁止转让条款、通知回证、债权清单、国资进场或受让人负面清单、担保登记未核验；关键价款或未偿额缺失。
- `目标停止`：主目标已变为待签评改、履约催收、争议追索，或文本已滑入债务转移／代付款／保理。

生存级价款或个人无限回购／连带且用户拒绝升级：停止“可以签署”建议。
