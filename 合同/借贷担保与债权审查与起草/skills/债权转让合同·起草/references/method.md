# 审查方法（锁定 债权转让合同 / 债权转让合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型，禁止打开股权转让、债务转移、保证或抵押双文件“对照一下”。

本文件是**不改变债之内容、债权人将债权让与第三人**的签前判断节点，不是栏目说明书，也不是债务承担、代付款或保理融资审查清单。禁止把债务人换人、债权人同意、有追索融资或未来应收账款管理写入本类型默认结论。

每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、必然收到债款、对方必然接受或唯一必得金额。

`search_law` 返回已失效《合同法》第七十九条至第八十三条及其解释、担保法解释、物权法或涉外经济合同法时记为噪声，不得写入 `L#`。返回《合同法》第七十九条而无第五百四十五条第二款金钱／非金钱对抗分层时，改走民法典第五百四十五条。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突。

示范文本只参考结构。资产包或中介填充稿不证明本约条款已被接受；符合格式条款定义的，仍按格式条款审查。

### 双文件使用（标题与文件名不完全对应时不拒跑）

同目录两份知识文件按标题语义使用，不回改正文，不因文件名拒跑：

- 含“首部 / 交易条款 / 配套 / 尾部 / 语言”的当框架级条款清单，供节点 8 出句；
- 宏观的类型切开、主体、可转让性、通知、从权利、抗辩抵销由本方法节点承担。知识稿把禁止转让特约一律写成“不得对抗善意第三人”的，**降级**：金钱债权不得对抗第三人，非金钱债权不得对抗善意第三人。知识稿把未通知写成合同不生效、把未进场写成当然无效、把物权法当从权利依据的，按本方法纠正。
- 文件不可用（空、代码块、与本类型明显无关）：记 `G#`，用本方法节点继续，不得改去加载股权或保证双文件，不得编造通知已完成或债权已特定。

## 节点 1　类型识别与负触发

### 1.1 本类型正像

同时满足才继续：

- 标的是已成立、内容不变的债权（货款、借款返还、判决确定金钱债权等），不是新设债务；
- 核心给付是**原债权人退出对债务人的债权人地位、第三人取得该债权**；债务人仍是原债务人；
- 交易不是以债务人换人、第三人代付款或保理融资（资金融通 + 应收账款管理／催收／付款担保）为主结构。

标题写成“债权转让协议”“应收账款转让合同”只是线索。名实不符按核心给付归类，标题冲突写入 `C#`。

### 1.2 必须切开（禁止两套知识）

| 信号 | 归入 | 本技能动作 |
| --- | --- | --- |
| 原债务人退出，新债务人加入，须债权人同意 | 债务转移三方协议 | **负触发** → `债务人换人须债权人同意→`。不得当债权让与审 |
| 第三人不加入债务，只按指示付款 | 代付款三方协议 | **负触发** → `代付款三方第三人不加入债务只代为支付→` |
| 保理人提供融资、应收账款管理或催收、付款担保；有追索／无追索；将有应收账款 | 保理 | **负触发** → 引擎或专项。不得删掉融资条款后继续当本类型审 |
| 权利义务一并转让、合同主体概括承受 | 合同权利义务概括转移 | 负触发 → 引擎。点名须对方同意 |
| 买股权、注册资本不变 | 股权转让 | 负触发 → `买的是股权→` |
| 买设备、房产、专利等特定资产 | 资产转让 | 负触发 → `买特定资产不按债权让与→` |
| 主文是保证或抵押借款 | 保证／抵押主文件 | 负触发 → `一般保证合同·审查`／`s060`／`s069`；本约若另有让与正文，担保只作从权利红旗 |
| 一切现有及未来应收账款一揽子、无特定清单，且对价按融资额度／保证金／回购计 | 保理或最高额结构 | 负触发或字段停止，不按单纯让与放行 |

债务转移、代付款、保理误入是硬闸：一旦核心给付滑入上述结构，立即停笔转出。

### 1.3 加载协议

只打开本目录 `基本面.md` 与 `框架.md`。禁止读 `types/` 或其他场景原子目录。

### 1.4 违法结构停笔（本类型）

出现下列任一结构，只出告知，不改写成可履行文本：

- 虚构基础交易构造债权再转让，或通谋逃债、洗钱、虚假诉讼；
- 明知人身性或法律禁止转让的债权，要求写成可向债务人收款的路径；
- 国企重大资产／债权依法应评估挂牌，要求设计场外协议规避进场；
- 倒签合同或通知日期，以制造“通知在先”或改变时效中断时点。

用户坚持“改到能签／能避开进场／能假装已通知”：整体停止。合规改道（真实披露、真实进场、真实通知后再签）只点名，不在本任务起草规避方案。

## 硬闸 A　可转让性（545）

本闸改变能否放行。材料未提及不得写成“依法可转让、无禁止特约”，只能写 `依据不足`。

1. **三项除外，分别处理**  
   - **性质不得转**：基于个人信任的劳务／诊疗、抚养费／扶养费／赡养费请求权、人身损害赔偿请求权等。命中：红线。修改句不得改成可向第三人主张的履行结构；建议停止或改道（如仅转让已确定的金钱判决债权且法律允许时再审）。  
   - **法律禁止转**：专项拨款、依法不得让与的财政性或管制债权。未核验到具体禁条：该字段停止，不编造禁转清单。  
   - **约定不得转**：必须核对基础合同原文。禁止只凭口头“好像不能转”。

2. **禁止转让特约的对抗（必须按核验条，禁止一刀切）**  
   民法典第五百四十五条第二款：当事人约定**非金钱债权**不得转让的，不得对抗**善意第三人**；约定**金钱债权**不得转让的，不得对抗**第三人**。  
   **不得写成**：特约使转让合同当然无效；或一律“不得对抗善意第三人”。  
   **也不得写成**：受让人已经善意、已经取得完整权利。善意／知悉是事实问题。  
   修改句（受让人立场，金钱债权示例）：  
   `定位｜原文“基础合同禁止转让则本次转让无效”｜建议改为：甲方陈述并保证基础合同【编号】对金钱债权未约定不得转让；即便存在该特约，甲方仍应就因此不能向债务人主张的损失向乙方承担【待填】回购或降价责任。乙方付款前有权核验基础合同禁止转让条款。｜理由 L# 545｜可退让：先取得债务人书面同意再付尾款｜红线：把特约写成合同当然无效，或要求乙方自担全部不能对抗风险且不披露特约`

3. **虚构债权、已过时效未披露**  
   转让人必须陈述保证：债权真实存在、未被清偿／抵销／撤销、诉讼时效未届满或已中断的事实可核验。违反则解除或按未偿净值降价，并返还已付款加【待填】违约金。  
   不得把“甲方保证真实”写成已经核实。凭证未附：真实性 `依据不足`。

4. **最强反方**  
   金钱债权禁止转让特约原则上不能对抗受让人；受让人知悉特约仍可能对让与人负违约责任，但不当然拿不到对债务人的权利。  
   签前仍须披露特约并安排债务人同意或回购，避免履行障碍。

核验失败：可转让性法律结论字段停止，事实摘录和修改句草稿继续。

## 硬闸 B　通知债务人（546）

未经通知，转让**对债务人不发生效力**。通知约束的是债务人履行对象，不是让与人与受让人之间合同的成立。

1. **禁止写法**  
   - “未通知则本合同无效／不成立／对双方不生效”；  
   - “签字即视为已通知债务人”；  
   - “起诉时再说，先付全款”。

2. **通知要素（修改句必须落到付款先决）**  
   书面通知至少载明：基础债权识别信息、转让人与受让人、转让范围（全部或部分及金额）、履行对象变更为受让人、受让人收款账户、发出人签章。  
   送达：原合同约定地址、法定地址 + EMS／公证／可核验电子送达。共同通知：转让人与受让人共同签署《债权转让通知书》作为附件。  
   修改句：  
   `定位｜原文“本合同签字后即对债务人生效，无须另行通知”｜建议改为：甲方应于本合同签署后【待填】日内与乙方共同向债务人发出书面《债权转让通知书》（附件【待填】），并取得签收或邮件妥投记录。乙方支付转让价款的【待填】%以上款项，以该通知到达债务人且甲方交付回证为前提。未经通知，该转让对债务人不发生效力；但这不使本合同在甲乙之间无效。｜理由 L# 546｜可退让：先付订金／定金，通知回证后付尾款｜红线：先全款后通知，或把未通知写成合同无效`

3. **诉讼送达**  
   起诉状送达债务人可视为通知。**签前不得**把“将来起诉即视为已通知”写成已完成义务，也不得据此放行全额付款。

4. **通知不得撤销**  
   除经受让人同意。修改句禁止单方撤回通知。

5. **二重转让**  
   《合同编通则解释》第五十条：债务人向**最先到达**的通知所载受让人履行的，应予支持。付款前须陈述保证“未向他人转让或通知”，违反则回购。不得只写“以签约先后为准”。

6. **时效**  
   通知到达之日起诉讼时效中断。通知书应同时催告履行。不在本任务计算时效终点。

7. **最强反方**  
   未通知不影响甲乙之间合同效力；受让人仍可请求转让人通知或承担违约。债务人在通知前向原债权人清偿有效。  
   因此付款必须挂通知回证，而不是争论合同无效。

## 硬闸 C　从权利随同（547）

1. **法定随同**  
   受让人取得与债权有关的从权利，专属于债权人自身的除外。未办理转移登记或未转移占有，**不影响取得**从权利。  
   不得写成“未变更登记则抵押权未转移给受让人”。  
   也不得写成“未登记已可对抗任意第三人的再处分”。

2. **必须办的动作**  
   抵押权、在建工程抵押、应收账款质押等：修改句锁定变更登记义务人、【待填】日、逾期违约金和尾款扣留。不动产登记细则允许持主债权转让协议和已通知债务人的材料申请抵押权转移登记。  
   最高额抵押：债权确定前部分转让的，最高额抵押权原则上不得转让，另有约定除外。点名第 421 条，字段停止或要求先确定债权。

3. **保证人**  
   未通知保证人，转让对保证人不发生效力。保证人与债权人约定禁止债权转让，未经保证人书面同意的，保证人对受让人不再承担保证责任。  
   修改句：通知保证人 + 取得书面确认或同意，作为付款／交割先决。  
   **本任务不整份代审保证或抵押主文件。** 深度保证／抵押文本转 `一般保证合同·审查`／`s060`／`s069`。

4. **利息、违约金、担保物权**  
   写清基准日前已发生未付利息／违约金是否一并转让。禁止只写“相关权利一并转移”而无清单。

5. **最强反方**  
   从权利已法定转移，登记只是对抗和处分风险问题。签前仍须把登记做成义务，避免转让人再处分或第三人善意取得负担。

## 硬闸 D　对价与真实性

1. **标的必须特定**  
   最低要素：债务人名称、基础合同名称及编号、债权性质、转让基准日未偿本金／利息／违约金、全部或部分。必须有《债权清单》附件，且与基础合同、发票、对账单、催收函或判决书勾稽。  
   “本公司一切现有及未来应收账款”“全部经营性往来”而无清单：不得当本类型放行。判断是否滑向保理或最高额——是则负触发；否则红线，补清单前字段停止。

2. **价款与交割**  
   总价、是否按未偿净值折价、差额是否视为折扣、付款账户须与转让人一致。数字未给用 `【待填】`。  
   付款必须挂可核验条件：清单与凭证移交、通知回证、解押或质权人同意、国资进场成交（如适用）。禁止“签约当日全额转入且无返还路径”。

3. **材料移交**  
   基础合同原件或核验件、履行凭证、催收与时效证据、担保合同与登记证明、判决或调解书、通知书模板。逾期未交：尾款止付 + 解除。

4. **真实性违约**  
   债权虚假、已清偿、已过时效未披露、已被另案让与：转让人回购或赔偿全部损失（含合理维权费用）。不得保证法院必然支持预期利益。

5. **最强反方**  
   债务人曾确认债权存在的，事后不得再以不存在对抗善意受让人（《合同编通则解释》第四十九条）。签前仍须尽调凭证，不得把一纸确认写成已经核验无抗辩。

## 硬闸 E　国资／不良资产

1. **国有及国有控股、实际控制企业转让债权**  
   《企业国有资产交易监督管理办法》第二、三条：企业国有资产交易原则上在依法设立的产权交易机构公开进行；行为包括产权转让、增资、**重大资产转让**。评估规则见《国有资产评估管理办法（2020 修订）》第三条。  
   材料显示转让人为国企、标的可能构成重大资产，但无评估、无进场、无成交确认：  
   **生效字段停止。** 修改句把评估备案／挂牌成交写成生效或付款条件。  
   **禁止**写“双方同意场外履行即可”“补个内部决议就行”。用户要求设计规避进场：整体停止。  
   是否属于“重大”未核验：该定性字段停止，不编造金额门槛。

2. **受让人负面清单**  
   金融不良资产、资产管理公司资产包常有受让人限制。本窗不硬编码公务员、金融机构工作人员等名单。  
   动作：运行时 `search_law` 核验当期限制；核验失败则**受让主体字段停止**，修改句要求受让人陈述不属于限制主体并附依据。不得把知识库名单写成已核验禁止。

3. **最强反方**  
   未进场不一律导致民事合同当然无效，但监管程序未闭合构成重大履行和法律风险。签前按字段停止处理，不给出可履行场外结构。

## 硬闸 F　债务人抗辩与抵销（548／549）

1. **抗辩延续**  
   债务人接到通知后，对让与人的抗辩可以向受让人主张。包括：基础合同未履行或瑕疵履行、同时履行或先履行抗辩、诉讼时效、债权已消灭、管辖或仲裁约定等。  
   **禁止**修改成“转让后债务人不得再向受让人主张任何抗辩”。该句即使双方愿意，也不能写成已经发生的对债务人生效的放弃，除非债务人**本人**另行明确放弃且放弃范围可识别。

2. **抵销**  
   有下列情形之一，债务人可以向受让人主张抵销：  
   - 接到通知时对让与人享有债权，且该债权先于或与转让债权同时到期；  
   - 两债权基于同一合同产生。  
   修改句（受让人立场）：要求转让人披露已知互负债务，并保证通知时不存在符合第 549 条的抵销；违反则降价或回购。可谈判让债务人出具《债务确认及放弃抵销声明》作为附件——这是增信，不是法定已放弃。

3. **不得写成的结论**  
   “转让后债务人不得抗辩”；“已过时效不影响受让人”；“有质量异议也必须向受让人全额付款”。

4. **最强反方**  
   受让人不是基础合同当事人，不能比让与人享有更优的实体地位。签前把抗辩抵销当价格因素，而不是用条款抹掉。

---

## 节点 2　主体、权属负担、授权

1. 建主体表：转让人、受让人、债务人、保证人、抵押人、质权人、付款名、授权签字人。名称不一致不自动合并。
2. 转让人须是债权人。核对基础合同债权人名称与签约名；已被另案让与、出质、保全的，并列 `D#`。口头“债是我的”不得写成已核权属。
3. 债权出质（中登登记等）或司法冻结：不得写成转让合同当然无效。修改句锁定解押或保全解除期限、责任人、逾期解除权。用户要求掩盖冻结：整体停止。
4. 国资、上市公司、集体决议未附：签署能力字段停止。
5. 担保人、加入履行的第三人只记录对本约放行的影响，不展开担保整案。

不足：字段停止，列出待补材料，不补主体。

---

## 节点 3　程序与生效

把通知、担保变更登记、国资进场、内部决议写成**义务和期限**，不写成已经完成。

| 文本写法 | 本任务动作 |
| --- | --- |
| “本合同签字即对债务人发生效力” | 拆成甲乙之间生效 vs 通知后对债务人生效 |
| “无须通知／起诉时再通知” | 硬闸 B；通知作为付款先决 |
| “从权利自动转移，无须登记” | 承认 547 第二款取得，补变更登记义务 |
| “签字后立即生效”但国企重大资产未进场 | 硬闸 E；生效字段停止 |
| 用户要求倒签通知日或补假回证 | 整体停止 |

不得把“双方同意视为已通知／已进场／已登记”写成可放行结构。

## 节点 4　格式条款、强制规范与退出

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

示范文本或资产包填充版仍可能构成格式条款。审查“不得抗辩”“先款后通知”“最终解释权”。

违反法律、行政法规强制性规定不一律无效。通知未完成、特约不能对抗、登记不能对抗、进场未履行：多用履行障碍、解除和返还处理。禁止用已失效“效力性／管理性”口诀。禁止用《合同法》第七十九条代替第五百四十五条第二款。

退出：通知或材料移交未在最终截止日前完成、真实性不实、进场不能，应有解除、返还和已付款清理。禁止只写“双方协商解除”。

---

## 节点 5　违约、解除、争议解决

1. 逾期移交材料、逾期通知、陈述不实、二重转让必须分别有日违约金或固定金额，以及达到【待填】日的解除权。只有“依法承担违约责任”视为必须改。
2. 构成违约不等于当然解除。法定解除只点名催告或目的不能实现，不在本任务作出已解除结论。
3. 违约金避免“不得调整”或“按总价百分之三十必得”。
4. 争议解决：已有仲裁条款，不得改成假装已选定诉讼；或裁或诉、机构不明，改成单一机构或单一法院连结点。原基础合同管辖对受让人原则上有效，但转让时受让人不知道或另有约定且债务人同意的除外——只点名，不编造唯一法院。
5. 微信已读不写成通知已经到达，除非合同把该渠道定为送达且有发送记录。

## 节点 6　跨境与其他结构

1. 涉外主体或境外付款：准据法不明则停止外国法结论。本类型只审中国大陆法下的债权让与和人民币价款安排。
2. 债权为夫妻共同财产时，建议取得配偶书面同意作为附件。不得写成“无配偶签字则让与无效”。
3. 让与担保式“名为转让、到期回购且不清算”：字段停止并转出，不按真实让与出收款修改句。

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

对照已加载框架级文件和本方法硬闸，按六步逐段出句。

| 步 | 本类型必须盯的点 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题名实（不是债务承担／保理）；转让人与基础合同债权人一致；鉴于只描述债权来源和未偿额，不把通知写成已完成 | 主体与鉴于修改句 |
| 交易条款 | 清单特定；金钱／非金钱特约分层；单一价款；通知作为付款先决；从权利与登记；抗辩抵销披露 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 真实性陈述与回购／降价；二重转让禁止；逾期通知／移交违约金；保证人通知 | 可执行后果句 |
| 尾部 | 授权签字；附件：清单、通知书、基础合同、凭证、放弃抵销声明（如有）、进场成交文件 | 生效与附件修改句 |
| 语言 | 正说加反说；对债务人生效 ≠ 合同成立；不得写“未通知则合同无效”；不得写“转让后不得抗辩” | 替换空词的句子 |
| 常见问题 | 先全款后通知、无清单一揽子、场外国资、人身性债权、依赖起诉通知 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（人身性／法律禁止、虚构或时效未披露、无清单一揽子、国资未进场、先全款后通知、转让后不得抗辩）；
- `必须改`：可谈但签署前要落句（通知先决、从权利登记、抗辩抵销披露、真实性回购）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级价款或个人无限回购／连带且用户拒绝升级：停止“可以签署”建议。
