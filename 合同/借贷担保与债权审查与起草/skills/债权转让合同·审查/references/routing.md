# 边界与路由

本技能只审查 **债权转让合同 / 债权转让合同**。主线：不改变债之内容，债权人将债权让与第三人。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 债务人换人、免原债务人、须债权人同意 | `债务人换人须债权人同意→` |
| 第三人不加入债务，只代为付款 | `代付款三方第三人不加入债务只代为支付→` |
| 保理、有追索／无追索融资、将有应收账款管理或付款担保为主结构 | 引擎或保理专项；不得用本类型硬套融资条款 |
| 权利义务一并转让、概括承受 | 引擎；点名须对方同意，不按单纯让与放行 |
| 买的是股权 | `买的是股权→` |
| 买特定资产、不按债权让与 | `买特定资产不按债权让与→` |
| 主文件是一般保证／连带保证 | `一般保证合同·审查` 或 `连带责任保证合同·审查` |
| 主文件是抵押借款 | `抵押借款合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `债权转让合同·起草` |
| 已签未争、催收或通知留痕、回款节点 | 本套导航的履约步骤 |
| 已成争：追索诉讼策略、催告索赔立案仲裁 | 合同争议领域；不填签前十节 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

专业版未收录的保理或不良资产专项不会作为本原子的实体审查对象。若用户拿这些文本来找本技能：输出 `unavailable` 或负触发路由，不得用本类型硬套。

本技能不得转去加载股权转让、债务转移或保证双文件完成本类型审查。
