定性校验：核心给付是资金借贷，且让与担保是主结构，才继续；明显他类则负触发，不填十节实体结论。

本文件是可执行判断节点，不是栏目说明书。每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、已经取得完整所有权、必然优先受偿，或唯一必得本息。

示范文本只参考结构。写“到期不回购则标的物归买受人所有”或“本合同自过户之日起买受人取得完整所有权、可自由处分”的范本与流质禁止、名义权利人限制冲突，不得当规则。

知识库口径冲突以本方法为准，不回写知识正文：

- `基本面.md`/`框架.md` 把“阴阳合同”写成买卖合同无效即担保目的必然落空：纠正为表面买卖可能因虚假意思表示无效，隐藏的借贷与提供担保的意思按现行让与担保规则处理；流质约定无效不影响担保意思。
- 实务或旧口径称让与担保因物权法定一律无效：纠正为清算型约定有效；已完成权利变动公示的，可请求参照担保物权优先受偿；归己所有的约定无效。
- 把未过户写成合同未生效：纠正为设立、变更物权的合同原则上成立即生效；未办理物权登记不影响合同效力，但不得写成已经参照担保物权优先受偿。
- 称必须拆成三份独立合同：纠正为合并一份或主从分立均可，关键是交叉引用锁定“借款为目的、转移为担保”。
- 利率“四倍”必须运行时核验，不得写成银行利率旧四倍或 24%/36%。

开发窗口 2026-08-18 已核验、可供对照但不得代替运行时核验的规则：

- 民法典第 146 条：虚假意思表示实施的民事法律行为无效；隐藏行为的效力依照有关法律规定处理。
- 民法典第 209 条：不动产物权经依法登记发生效力；未经登记不发生效力，法律另有规定除外。
- 民法典第 215 条：设立、变更、转让和消灭不动产物权的合同，除法律另有规定或当事人另有约定外，自成立时生效；未办理物权登记不影响合同效力。
- 民法典第 366、368 条：居住权满足生活居住需要；居住权自登记时设立。
- 民法典第 388、389 条：担保合同是从合同；担保范围包括主债权、利息、违约金、损害赔偿金、保管费用和实现担保物权的费用，另有约定从约定。
- 民法典第 401、428 条：期前约定抵押财产或质押财产归债权人所有的，只能依法优先受偿。
- 担保制度解释第 68 条：形式上转移到债权人名下、到期可折价或拍卖变卖偿债的约定有效；已完成权利变动公示的，可请求参照担保物权优先受偿。约定财产归债权人所有的无效，但不影响提供担保的意思。回购加到期归债权人所有的，参照该款。回购对象自始不存在的，按第 146 条第二款按实际法律关系处理。
- 担保制度解释第 69 条：股权转移到债权人名下作担保的，公司或公司债权人不得仅因此要求名义股东的债权人与股东就未出资或抽逃出资连带负责。
- 法释〔2020〕17 号第 23 条：以订立买卖合同作为民间借贷担保，出借人请求履行买卖合同的，按民间借贷审理；判决生效后借款人不履行金钱债务的，可申请拍卖标的物偿债，差价多退少补。
- 同规定第 25、26、28、29 条：利率不超过合同成立时一年期 LPR 四倍；预扣利息按实际出借额计本金；逾期利率与费用总和同上限。
- 公司法（2023 修订）第 15 条：公司为他人担保由董事会或股东会决议；为股东或实际控制人须股东会且关联股东回避。
- 合同编通则解释第 14 条：同一交易多份合同中，以虚假意思表示订立的合同无效；隐藏合同另依法认定。
- 时间效力规定第 7 条：民法典施行前的流押/流质约定，适用第 401、428 条。
- 法释〔2020〕27 号：经地方金融监管部门监管的七类地方金融组织，不适用新民间借贷司法解释。

## 节点 2　主体、权属、共有人、承租人与公司决议

1. 建主体表：出借人/名义买受人、借款人/名义出卖人、提供财产的第三人、共有人、配偶、承租人、保证人（如有）。名称不一致不自动合并。角色必须同时标出借贷身份和名义买卖身份。
2. 权属：提供财产的一方须对担保财产有所有权或处分权。材料未出示权属证书或与清单不一致：该处分能力字段停止，不得写成“可以过户”。
3. 禁止或限制流通：划拨土地使用权未经批准、小产权房、违章建筑、已被查封、农村宅基地、章程或锁定期限制的股权。命中则红线，不写可履行过户路径。
4. 共有与配偶：夫妻共同财产或其他共有，须有共有人本人书面同意。口头“配偶同意了”、合同打印共有人栏但未签：不得写成已同意。代签、伪造：整体停止。
5. 承租人：财产已出租的，形式上的“买卖”可能触发优先购买。未取得放弃优先购买声明：字段停止，修改句要求声明作附件。已登记居住权：红旗，提示担保物价值严重贬损，不得写成不影响处置。
6. 公司以重大资产或为他人提供让与担保：按章程由董事会或股东会决议；为股东或实际控制人须股东会决议，该股东不得表决。未附决议：字段停止，修改句要求作为附件且未获批准不过户、不放款。公司法条号用 2023 年修订第十五条。
7. 口头“我们老板同意了”不得写成已授权或已决议。

不足：字段停止，列出待补材料，不补主体、不补权属、不补已同意。

## 节点 3　名实锁定与合同组交叉引用（硬闸）

本类型是合同组：借款是主法律关系，买卖/转让/回购是从担保安排。

核验后可引用的判断点（须 `search_law` 写入 `L#` 再落法律结论）：

- 以虚假意思表示实施的行为无效；隐藏行为另依法认定。
- 以订立买卖合同作为民间借贷担保，出借人请求履行买卖合同的，按民间借贷审理，不得按真实买卖强制过户。
- 清算型让与担保约定有效；归己所有约定无效，不影响提供担保的意思。

| 文本写法 | 本任务动作 |
| --- | --- |
| 仅有《买卖合同》，无借款本金、无回购，用户称“其实是借款” | 追问主文件。主文件实为房屋买卖外观 → 负触发 `以房屋买卖网签过户或回购外观为借款提供担保→`。能读出借款主给付且财产过户作担保 → 留本技能，修改句补借款主合同和交叉引用 |
| 借款、买卖、回购三份文本条款割裂，价款、目的互相否定 | 必须改。三份文件交叉引用：买卖/过户仅为担保借款；名义价款与本金冲抵 |
| 鉴于只写“双方自愿买卖”，正文另有借据 | 必须改。鉴于改为借款合意 + 担保目的，并约定鉴于对正文有解释约束力 |
| 用户要求保留“真实买卖”外壳以便将来起诉过户 | 整体停止该结论。修改句不得写成可强制实际履行的买卖 |

反方常见抗辩：有买卖合同和过户即可请求继续履行。本任务不得把该抗辩写成可放行结构。

## 节点 4　流质禁止与清算多退少补（硬闸）

期前约定债务人不履行到期债务时财产归债权人所有的，只能依法就该财产优先受偿。让与担保路径：归己所有的约定无效，但不影响担保意思；已完成公示的，可请求参照担保物权折价或拍卖、变卖后优先受偿；债务人清偿后可请求返还。

| 文本写法 | 本任务动作 |
| --- | --- |
| “到期不还，房屋/股权/设备归甲方所有并配合过户，甲方无需清算” | 红线。改为折价、拍卖或变卖后优先受偿，多退少补 |
| “到期未回购，视为借款人放弃所有权/回购权” | 红线。删除“视为”；改为启动清算 |
| “按转让价款（即本金）折价归出借人，禁止评估” | 红线或必须改。折价须参照市价，余款返还 |
| “出借人有权继续履行买卖合同，借款人不得抗辩” | 红线。提示按民间借贷审理；不得改成可强制履行买卖 |
| 履行期届满后另行达成以物抵债 | 本任务是签前文本；不得把预埋的期前流质包装成“到期后再签”来放行 |
| 用户要求保留流质以便直接取得所有权 | 整体停止 |

清算句最低要素：触发情形；折价或拍卖、变卖；参照市价；清偿顺序（实现费用、本金、利息、违约金）；余款返还；不足追偿。缺一项补一项。

## 节点 5　公示分层与合同效力分离（硬闸）

合同效力与权利变动是两个事实。未办理物权登记，不影响合同效力，也不等于已经取得参照担保物权的优先受偿地位。当事人已经完成财产权利变动公示的，债务人不履行到期债务时，债权人才可能请求参照担保物权优先受偿。

| 文本写法 | 本任务动作 |
| --- | --- |
| “本合同自过户登记之日起生效” | 必须改。拆成：借款与担保安排自成立时生效；权利变动自登记或法定公示完成时发生。过户可另作放款先决条件 |
| “签字即视为已过户、已取得完整所有权、已有优先受偿权” | 红线。禁止拟制公示 |
| 未写谁在几日内申请过户/变更登记、未完成的后果 | 必须改。补义务主体、期限、未完成不得放款或可解除 |
| 仅有买卖协议，明确不过户 | 可以留本技能，但优先受偿结论字段停止；修改句写明仅普通债权 |
| 不动产拟过户但财产已被查封 | 红线。告知无法办理转移登记，结构失败，不写可履行过户 |
| 用户要求把日期写成已经过户或补假登记回单 | 整体停止 |

批准、过户、变更登记写成生效条件或双方义务期限，不写成已经完成。材料未提及不得写成“无在先抵押、查封、租赁或居住权”。

出借人已是登记名义人时，必须提示：其向善意第三人转卖或自身负债被查封，借款人可能无法追回财产。修改句限制担保期间处分，并评估回购预告登记是否可谈；预告登记办不成不得写成已经对抗。

## 节点 6　回购闭环、名义价款、占有与风险

1. 回购权与借款期限挂钩。本息清偿后【待填】日内，出借人必须配合返还财产或过户回借款人。逾期配合义务必须有违约金。正说必须有反说。
2. 回购价款构成写清：本金、约定利息、实现费用。与第 7 节点一并做上限审查。
3. 名义转让价款通常等于本金或本金加利息，并与放款冲抵。必须写明出借人无需另行支付购买价款。两套价款互不等且无冲抵：标 `C#`，必须改。
4. 动产可占有改定，财产仍由借款人占有使用；风险在回购期满前由借款人承担。不得写成已卖断、风险已转移给出借人。
5. 担保期间出借人不得转让、抵押、出租或以该财产清偿自身债务；违反则赔偿，并不得对抗已完成的善意取得——本任务不保证能追回。
6. 回购对象自始不存在（虚构财产）：按隐藏的实际借贷关系处理，不得写成已经设立让与担保。

## 节点 7　主债利率与费用（运行时核验）（硬闸）

禁止直接输出下列口径作为现行保护标准：

- 银行同类贷款利率四倍（1991 年意见口径）；
- 年利率 24%、年利率 36%（2015 年司法解释口径）；
- 任何未核验的“四倍”。

动作：

1. 先判断贷款人是否为金融监管部门批准的放贷机构，或法释〔2020〕27 号所列七类地方金融组织。是：不得套用民间借贷上限；利率是否合规改走监管规则核验，核验失败则该法律结论停止。
2. 民间借贷路径：调用 `search_law` 查询“民间借贷利率司法保护上限 现行规定”。仅当返回现行有效规则时写入 `L#`，再对照文本利率、回购溢价年化与“合同成立时”的保护标准。
3. 开发窗口 2026-08-18 核验结果见文首对照表。核验失败或只返回已修改文本：利率法律结论字段停止。仍可摘录文本利率并给出“待核验现行上限后改写”的修改句草稿。
4. 一年期 LPR 当次数值未核验：不编造百分比，用 `【合同成立时一年期 LPR × 核验所得倍数，待填】`。
5. 回购价−名义出售价、溢价、咨询费、通道费、逾期利息、违约金并行时按费用总和审查。预扣利息、砍头息按实际放款额计本金。
6. 不得把定金罚则塞进本类型充利息。预扣利息不是定金。
