# 边界与路由

本技能只审查 **借款合同 / 让与担保型借款合同**。

必须同时读出资金借贷合意，以及以财产形式上转移到出借人名下（或约定过户/变更登记）并设回购、回赎的主结构。标题叫“让与担保借款”但没有过户/回购安排、或主文件其实是房屋买卖本约的，不得留在本技能做实体结论。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或标题让与担保借款、核心给付明显不是资金借贷加形式上过户/回购 | 本套导航的类型切开步骤 |
| 主文件是商品房/存量房/资产买卖外观，借款只是背景；网签、五证、面积争议主导 | `以房屋买卖网签过户或回购外观为借款提供担保→`；专业版未收录该 P1 时输出 `unavailable`，不得硬套本技能改成真实买卖 |
| 名为投资、联营、咨询、买卖，无财产形式上过户、无回购回赎 | `名为其他实为借贷·审查` |
| 不转移所有权，以不动产、在建工程或动产抵押登记为主结构 | `抵押借款合同·审查` |
| 动产移交占有或权利凭证交付/出质登记为主结构，无所有权形式上转移 | `质押借款合同·审查` |
| 双方自然人或一方企业的普通借款，无让与担保 | `自然人之间的借款合同·审查` 或 `狭义民间借款合同·审查` |
| 企业互借且过户只是附带一句、审查重点是拆借效力 | 可提示 `企业间借款合同·审查`；让与担保名实、流质与清算仍是放行关键则留本技能 |
| 持牌机构贷款文本，审查重点是监管利率与放款条件 | 可提示 `金融机构借款合同·审查`；让与担保结构仍是放行关键则留本技能 |
| 真实购房，无借贷担保、无回购 | `或` 或 `等）；` |
| 有完整待签文本要评改 | `让与担保型借款合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 留本任务起草并自审 |
| 已签未争、问放款、过户进度、回过户 | 本套导航的履约步骤 |
| 已成争 | 合同争议领域或对应专项；不写确认所有权诉状、拍卖申请书 |
| 用户只要利息或优先受偿额的终局数字 | 测算技能或人工精算；本技能只审条款 |
| C 端大众快检 | 只分流，不回改 |

附带保证、配偶签字栏时：本技能只审对本约放行的影响，不展开保证合同专项整案。深度保证文本转 `保证借款合同·审查`。

同一文本既写“抵押登记”又写“先过户再回购”：按核心结构切开。不转移所有权、走抵押登记 → `抵押借款合同·审查`。财产须形式上过户或变更到出借人名下 → 留本技能。两可且无法判断：负触发引擎，不灌两套知识。

职业放贷、转贷、违法用途、禁止流通财产包装、流质改过户归己、借名规避限购：停笔告知，不改写成可履行文本。

禁止在正文写半截 Skill ID。转出时必须写完整 ID，例如 `以房屋买卖网签过户或回购外观为借款提供担保→`、`名为其他实为借贷·审查`。
