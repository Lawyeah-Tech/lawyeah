# 让与担保型借款合同·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《担保法》《物权法》及其解释当作现行规则。不得把年利率 24%/36% 两线、1991 年银行利率旧四倍当作现行上限。不得把“让与担保因物权法定一律无效”或“买卖合同可强制实际履行过户”写成现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **借款合同 / 让与担保型借款合同**：主文件是借款或借据，买卖/转让/过户/回购是为该笔借款设定的非典型担保。输出可编辑草稿、未决项、自审风险表与自审后修改句。有完整待签文本要评改时，转 `让与担保型借款合同·审查`。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「审查让与担保型借款合同（借款合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查或起草、待签文本评改、履约交底、争议文书、合同或优先受偿有效性保证、把本约改成可强制履行的真实买卖、房产让与担保买卖本约整案、无过户回购结构的名其他实借贷整案、利息精算终局数字。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿；尚未签署，尚未成争；核心给付是资金借贷，**且让与担保是主结构**——财产形式上转移到出借人名下，或约定过户/变更登记，并以回购、回赎或溢价买回担保该借款。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 送审主文件是《商品房买卖合同》《存量房买卖合同》或买卖外观主导，借款只作背景 → `以房屋买卖网签过户或回购外观为借款提供担保→`；专业版未收录该原子时输出 `unavailable`，不得用本技能改成真实买卖履行结构；
- 名为投资、联营、咨询、买卖，但没有财产形式上转移到出借人名下、也没有回购/回赎担保结构 → `名为其他实为借贷·审查`；
- 不转移所有权，以不动产或动产抵押登记为主结构 → `抵押借款合同·审查`；
- 动产移交占有或权利出质登记为主结构 → `质押借款合同·审查`；
- 无让与担保、无抵押、无质押的自然人互借或狭义民间借款 → `自然人之间的借款合同·审查` 或 `狭义民间借款合同·审查`；
- 真实购房、无借贷担保意思、无回购 → `或` 或 `等）；`；
- 有完整待签文本要评改 → `让与担保型借款合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问放款、过户进度、回过户节点 → 本套导航的履约步骤；
- 已成争（催告还款、请求确认归债权人所有、拍卖清算诉讼、立案仲裁）→ 合同争议或对应专项领域。

职业放贷、套取金融机构贷款转贷、明知违法犯罪用途仍出借、规避限购或借名过户、把查封/小产权/宅基地改成可过户担保：只出告知，不改写成可履行结构。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成。每一闸必须给出修改句或明确转出口径，禁止只打红黄绿。

1. **名买卖实借贷**。标题写买卖不决定类型。必须同时读出：出借货币资金、到期返还本金；以及为该债权把财产形式上转到出借人名下或约定过户，并设回购/回赎。修改句必须把鉴于改成：因借款人向出借人借款本金【待填】元，为担保该债权，双方办理财产形式上的转移/过户/变更登记；本安排性质为担保，出借人为名义权利人，不享有完整处分权。名义转让价款与借款本金冲抵，出借人无需另行支付购买价款。三份或两份文本必须交叉引用主从和担保关系。无借贷信号、买受人真实买物：负触发买卖类原子。
2. **流质/流押禁止**。原文“到期不还财产归出借人所有”“视为放弃所有权或回购权”“自动转让且不再清算”“买受人有权直接过户并不再评估”：红线。修改句删除归己所有，改为：出借人不得请求确认财产归其所有；仅有权对财产折价或拍卖、变卖，并就所得价款优先受偿。流质约定无效，**不影响**提供担保的意思。不得把流质写成整组合同必然无效。
3. **清算义务（多退少补）**。必须写清：参照市价折价或拍卖、变卖；所得扣除约定本息及合理实现费用后余款返还借款人；不足部分继续追偿。只写“依法处理/自行处置/直接抵债/按转让价款折价归出借人”视为未约定清算。出借人请求“继续履行买卖合同过户”的，提示应按民间借贷审理，不得把本约改成可强制实际履行的真实买卖。
4. **利率上限运行时核验**。回购价−名义出售价、溢价、资金占用费、回租租金折算年化，民间借贷路径不得超过合同成立时一年期 LPR 四倍；超额改到上限内或标明不受司法保护。预扣利息按实际放款额计本金。出借人是持牌金融机构或七类地方金融组织：利率字段停止，不套四倍。禁止默写 24%/36%/银行利率旧四倍。
5. **与 `以房屋买卖网签过户或回购外观为借款提供担保→` 切开**。主文件是房产买卖外观 → 负触发该原子。本任务禁止输出预售五证表、面积误差 3%、网签 90 日转登记、先验房、学区、户口作为主路径。禁止打开其 method。
6. **与 `名为其他实为借贷·审查` 切开**。名其他实借贷但无“形式上过户 + 回购/回赎” → 负触发该原子。禁止用普通借款或名实穿透换皮审完本类型。

附加必落句（有事实则单列，无事实在缺口节说明）：

- **公示分层**：仅有协议、未完成权利变动公示＝普通债权，不得写参照担保物权优先受偿。已完成过户/变更登记＝才可能参照担保物权优先受偿，仍须清算。修改句按实际模式写过户义务、未完成不得放款，不保证结果。
- **回购闭环**：本息清偿后【待填】日内，出借人必须配合过户回借款人或撤销名义登记；逾期按【待填】付违约金。正说必须有反说。担保期间出借人不得转让、抵押或以该财产清偿自身债务。
- **占有与风险**：财产通常仍由借款人占有使用。毁损灭失风险在回购期满前由借款人承担，不得写成已卖断风险转移。
- **合同组**：借款主合同、担保买卖/转让、回购协议必须交叉引用；割裂的阴阳文本必须改，不得假装两套都真实。

必须有修改句。每个风险回链文本位置。禁止套用买卖合同的标的验收、定金百分之二十或挂靠改写节点。禁止套用抵押登记设立、质押交付设立、保证期间节点。禁止复制 `以房屋买卖网签过户或回购外观为借款提供担保→` 或普通借款 method。

## 建立审查坐标

确认：使用者与授权；单方立场（出借人/名义买受人、借款人/名义出卖人、提供财产的第三人、拟签字共有人）；相对方；全文及买卖/回购/权属/决议附件版本；主债权本金；担保财产种类；是否拟过户；回购价构成；利率与费用；不可接受事项；法域与签署时限。缺立场或本类型条件未谈妥则不启动起草。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 起草模式

本原子只承担本类型起草。待签评改转 `让与担保型借款合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。本类型硬闸改成正文必写、附件必附或禁止出现。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 鉴于改成：因借款人向出借人借款本金【待填】元，为担保该债权办理财产形式上的转移／过户／变更登记；本安排性质为担保，出借人为名义权利人，不享有完整处分权。
- 名义转让价款与借款本金冲抵，出借人无需另行支付购买价款。
- 删除归己所有，改为：出借人不得请求确认财产归其所有；仅有权折价或拍卖、变卖并就所得价款优先受偿。流质约定无效不影响提供担保的意思。
- 清算义务：参照市价折价或拍卖、变卖；扣除约定本息及合理实现费用后余款返还借款人；不足部分继续追偿。
- 公示分层：仅有协议、未完成权利变动公示＝普通债权；已完成过户／变更登记才可能参照担保物权优先受偿，仍须清算。
- 回购闭环：本息清偿后【待填】日内配合过户回借款人或撤销名义登记；担保期间出借人不得转让、抵押或以该财产清偿自身债务。
- 占有与风险：财产通常仍由借款人占有使用；回购期满前毁损灭失风险由借款人承担。
- 回购价减名义出售价、溢价、资金占用费、回租租金折算年化；民间路径不得超过合同成立时一年期 LPR 四倍；预扣按实际放款额计本金。

### 附件必附

- 借款主合同、担保买卖／转让、回购协议必须交叉引用。
- 按实际模式写过户／变更登记义务安排；未完成不得放款。
- 无对应事实不编造附件，缺项写入未决项。

### 禁止出现

- 把让与担保包装成真实买卖或可强制实际履行的过户。
- “到期不还财产归出借人所有”“视为放弃回购权”“自动转让且不再清算”“直接过户并不再评估”。
- 只写“依法处理／自行处置／直接抵债／按转让价款折价归出借人”而无清算。
- 未完成公示却写参照担保物权优先受偿；已卖断风险转移。
- 默写 24%／36%／银行利率旧四倍；出借人是持牌机构或七类地方金融组织仍套四倍。
- 输出预售五证、面积误差 3%、网签 90 日等房屋买卖主路径。
- 把流质写成整组合同必然无效。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；条件未谈妥仍要出可签署终稿；用户坚持伪造倒签、补假过户、伪造共有人同意或公司决议、把流质改成可过户归己、把禁止流通财产改成可过户担保、包装职业放贷或规避限购、保证必然优先受偿或必然能强制履行买卖。
- `字段停止`：法域、利率上限、权属/共有、公司决议未核验；担保财产无法特定；是否完成权利变动公示无法识别。
- `目标停止`：主目标已变为待签评改、履约交底、过户诉讼文书，或用户要把本约改成真实买卖以便请求实际履行。

生存级住房被设定让与担保且用户拒绝升级：停止“可以签署”建议。
