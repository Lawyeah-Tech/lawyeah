# 最高额保证合同·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **保证合同 / 最高额保证合同**，输出可编辑草稿、未决项、自审风险表与自审后修改句。有完整待签文本要评改时，转 `最高额保证合同·审查`。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文名必须是「审查最高额保证合同（保证合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类合同审查或起草；待签文本评改；履约交底；争议文书或行权策略；有效性保证；把无连续发生、无最高限额的文本按本类型放行；把普通最高额保证改成独立保函。

## 本类型硬闸

1. **最高额 ≠ 单笔保证 ≠ 独立保函**。正触发必须同时看见：最高债权额限度、一定期间连续发生的债权、可识别的债权确定期间（或依法可确定的事由）。缺连续发生或缺限额 → `一般保证合同·审查` / `连带责任保证合同·审查`。见索即付、URDG、相符交单 → `独立保函·审查`。同一文本里单笔借款主从一体 → `保证借款合同·审查`。
2. **最高限额必须特定**。写清是“本金限额”还是“债权总限额”。未写明时按解释第十五条，最高债权额默认包含利息、违约金、损害赔偿和实现债权费用等全部债权，但须出显化句，不得假装已经约定为本金限额。公司决议必须覆盖该限额、对象和期间；决议只批单笔却签最高额：越权红线。
3. **债权确定期间 ≠ 保证期间**。两套期间拆开写。确定期间管哪些债权进入担保池，届满后结算，不再纳入新债权。保证期间管确定后债权人如何主张。有约定的计算方式和起算从约定；没有约定或约定不明，按解释第三十条：被担保债权履行期限均已届满的，自债权确定之日起算；尚未届满的，自最后到期债权履行期限届满之日起算。债权确定之日依民法典第四百二十三条认定。“还清为止”等类似内容仍按解释第三十二条视为约定不明，该段保证期间按六个月处理，不得写成二年或无限期。
4. **方式仍须显化**。未约定或约定不明，按民法典第六百八十六条一般保证。最高额不自动变成连带。标题“连带”+正文“不能履行”冲突时并列，不选对用户有利的一版。
5. **公司决议 + 禁止主体**。为股东或实际控制人提供最高额保证须股东会决议且关联股东回避。机关法人、以公益为目的的非营利法人或学校医院作保证：只出告知。用户坚持改到能签：停止。公司法条号用 2023 年修订第十五条。
6. **从属性**。主债权债务合同无效的，保证合同无效，但是法律另有规定的除外。普通保证中的独立性约款无效，不得改成独立保函。知识库“单笔主合同无效不影响最高额保证”**不是**第六百八十二条的内容，不得写成已核验现行规则，不得写成“一律不影响”。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

禁止表述：最高额就是连带；法定期间二年；未登记则保证未生效；保证一定有效；单笔主合同无效一律不影响最高额保证；确定期间届满即保证责任消灭。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿；尚未签署，尚未成争，核心给付是第三人为一定期间内连续发生的债权在最高限额内提供保证；用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 已特定单笔主债，无连续发生期间、无最高限额 → `一般保证合同·审查` 或 `连带责任保证合同·审查`；
- 独立保函、见索即付、URDG / 相符交单 → `独立保函·审查`（专业版未装则 `unavailable`，提示，不得用本技能硬套）；
- 安慰函、维好协议、仅“知晓／督促／尽合理努力” → `安慰函·审查`（未装则 `unavailable`）；
- 差额补足、流动性支持、回购承诺等增信主轴 → `增信措施类保证合同·审查`（未装则 `unavailable`）；
- 同一文本是单笔借款加保证，主从一体 → `保证借款合同·审查`；
- 有完整待签文本要评改 → `最高额保证合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点、额度占用台账或行权日历 → 本套导航的履约步骤；
- 已催告、索赔、立案、开庭、仲裁，或主问保证责任是否消灭、怎么起诉、共同被告怎么列 → `或` 或 `或`。

机关法人、公益性主体违规保证，或伪造决议、倒签：只出告知，不改写成可履行规避结构。

## 建立审查坐标

确认：使用者与授权；单方立场（债权人 / 保证人 / 债务人择一）；相对方；全文及附件版本；最高限额原句及本金/总限额定性；债权确定期间起止；被担保业务种类；保证方式原句；保证期间原句；公司决议是否覆盖该限额、对象和期间；不可接受事项；法域与拟签署日。缺立场或本类型条件未谈妥则不启动起草。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的金额、限额、期间用 `【待填】`，不编造。

## 起草模式

本原子只承担本类型起草。待签评改转 `最高额保证合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。本类型硬闸改成正文必写、附件必附或禁止出现。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 同时写清：最高债权额限度、一定期间连续发生的债权、可识别的债权确定期间（或依法可确定的事由）。
- 最高限额写明是“本金限额”还是“债权总限额”；未写明时出显化句（默认包含利息、违约金、损害赔偿和实现债权费用等全部债权）。
- 债权确定期间与保证期间拆开写：确定期间管哪些债权进入担保池，保证期间管确定后如何主张。
- 无约定或不明的保证期间按解释第三十条两支起算；“还清为止”按六个月。
- 保证方式必须显化；未约定或不明按一般保证；最高额不自动变成连带。
- 从属性：主债权债务合同无效的，保证合同无效，但是法律另有规定的除外。

### 附件必附

- 公司作保时：覆盖该限额、对象和期间的决议；为股东或实际控制人提供时须股东会决议且关联股东回避。
- 无对应事实不编造附件，缺项写入未决项。

### 禁止出现

- 最高额就是连带；最高额当然连带。
- 法定期间二年；“还清为止”写成二年或无限期。
- 未登记则保证未生效；保证一定有效。
- 单笔主合同无效一律不影响最高额保证。
- 确定期间届满即保证责任消灭。
- 独立性约款改成独立保函。
- 缺连续发生或缺限额仍按本类型放行。
- 机关、公益主体作保改成可履行。
- 决议只批单笔却签最高额仍放行。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`基本面.md` 把“单笔主合同无效不影响最高额保证”挂在第六百八十二条、写“突破从属性”、写保证期间原则上自每笔履行期限届满起算：按 method 纠正，不回写知识库。`框架.md` 把“本合同具有独立性”、本金限额当法定默认、期间二年或三年当法定：按 method 当作谈判口径或禁止建议。

### 0. 签署状态与成果分流

无书面文本、条件已谈妥 → 留本任务起草；已签履约 → 本套导航履约步骤；已成争或主问责任消灭／起诉策略 → 争议或 `或`。有完整待签文本要评改时转 `最高额保证合同·审查`。本类型条件已谈妥、要出己方稿，才进入本任务。

### 1. 类型锁死（三要素）

标题、核心给付与最高额三要素一致才继续。已特定单笔主债、独立保函、安慰函、增信、保证借款同文本负触发。

### 2. 主体、禁入与决议覆盖限额

保证人是否机关或公益性主体；公司对外担保决议是否写明最高限额、对象和期间。决议只批单笔却签最高额：越权红线。口头“董事会同意了”不得写成已授权。

### 3. 最高限额与债权种类

限额必须定量。写清本金限额或债权总限额。种类超出约定业务类型的，不纳入担保池。使用“最高余额”，不用“累计发生额”冒充限额。

### 4. 债权确定期间与确定事由

起始日、截止日和提前确定事由分列。确定期间届满只表示停止纳入新债权，不是保证责任消灭。423 第四项查封扣押不得虚构为保证已有抵押物。

### 5. 保证方式仍须显化

最高额不改变 686。不明按一般保证并出先诉路径句。债权人要连带必须显化“不履行 + 可直接请求”，不得靠惯例推定。

### 6. 保证期间（第二套时钟）

运行时核验解释 30 两支和解释 32。还清为止按六个月处理该段。主张对象跟方式走。不得把确定期间写成保证期间。

### 7. 从属性、单笔无效、转让与变更

独立性约款删除。单笔交易无效不写成一律不影响框架，也不写成框架当然整体无效。确定前部分转让原则上不转最高额保证权。限额或期间变更须保证人书面同意。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。两套期间句和限额定性句不得省略。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；条件未谈妥仍要出可签署终稿；用户坚持倒签、伪造决议、把机关或公益主体改成可履行保证人、把独立性条款改成独立保函、把约定不明写成已经是连带、把无限额或无确定期间文本按本类型放行、把“单笔无效一律不影响”写成已核验规则、保证有效。
- `字段停止`：法域、动态规则、决议真伪、限额数字或确定期间未核验。
- `目标停止`：主目标已变为待签评改、履约交底、争议文书、保证责任评估，或把本合同改成独立保函／单笔保证。

生存级金额或自然人无限最高额且用户拒绝升级：停止放行建议，只列风险与转介。
