# 审查方法（锁定 保证合同 / 最高额保证合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止把 `一般保证合同·审查`、`连带责任保证合同·审查` 或 `保证借款合同·审查` 的 method 拼贴后换标题当作本文件。禁止套用买卖验收、定金比例或挂靠改写。

本文件的主线是 **最高债权额限度 + 一定期间连续发生的债权**。两套时钟必须走完：债权确定期间管池子，保证期间管主张。缺一闸不得宣称审查完成。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、最高额当然连带、单笔无效一律不影响，或唯一必得金额。

`search_law` 返回已失效《合同法》及其解释、已失效《担保法》及其解释、法释〔2002〕38 号时记为噪声，不得写入 `L#`。把“单笔主合同无效不影响最高额保证”写成第六百八十二条的，同样记噪声。

示范文本只参考结构。检索到的最高额保证范本多为连带责任保证、含“不可撤销”、期间两年，不得照抄当本约建议句。

知识库纠正（不回写双文件）：

- `基本面.md` 写“根据《民法典》第682条，单笔债权无效不影响最高额保证合同”：2026-08-18 `search_law` **未命中任何现行条文**支持该命题。第六百八十二条写的是从属性：主债权债务合同无效的，保证合同无效，但是法律另有规定的除外。不得把 682 改写成“突破从属性”。实务上或有“某一具体交易无效不当然使最高额保证框架整体无效”的争点，只标争点，**不得写成已核验规则，不得写成一律不影响**。
- `基本面.md` “相对独立性（突破从属性）”：690 是参照最高额抵押，不是独立保函。解释第二条对普通保证人的独立性约定仍无效。
- `基本面.md` “保证期间原则上自每笔债权履行期限届满之日起算”：与解释第三十条冲突。有约定从约定；无约定或不明走两支，不写“原则上逐笔起算”当法定。
- `框架.md` 鉴于写“本合同具有独立性”：禁止建议句。
- `框架.md` “最佳实践写成本金限额，利息在限额之外”：只是债权人谈判口径。解释第十五条默认最高债权额包含全部债权，另有约定除外。未约定不得假装已经是本金限额。
- `框架.md` “建议保证期间自确定期间届满之日起计算三年”：谈判口径，不是法定默认。无约定或还清为止按解释 30 + 32 处理。
- `框架.md` “单笔主合同无效不影响保证人对其他有效主债权承担责任”可作结算层修改句，但必须同时删除“效力独立于主合同”“对无效后果承担担保责任”。
- 公司决议条号：2023 年修订公司法第十五条（2024-07-01 施行）。知识库未写条号或旧第十六条，运行时并列说明。
- 本任务审查的是拟在民法典施行后签署的新文本。时间效力规定第二十七条只处理施行前已成立合同的期间过渡，不得给待签稿套旧二年。

先于类型识别。命中任一项则本任务不填十节实体结论，只交付分流理由和最小交接。

| 已能支持的事实 | 走向 | 不得写成 |
| --- | --- | --- |
| 无可读正文和附件，或只有“给银行授信额度担保一下”的口头要点，本类型条件已谈妥、要出己方稿 | 进入本任务起草 | 已经完成审查；可以签 |

## 节点 1　最高额三要素识别与单目录加载

### 1.1 定性（本类型灵魂闸）

用标题、核心给付和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须同时满足才正触发：

1. **最高债权额限度可读**：有确定金额或可核验的确定方法，而不是“额度另议”“以实际发生为准”且无限额。
2. **一定期间连续发生**：文本指向将来一段时间内多次、连续或不特定发生的债权，而不是已经特定的一笔主合同。
3. **债权确定期间或依法可确定的事由**：有起止日，或能对照第四百二十三条列出确定事由。

缺第 1 项或第 2 项：不是本类型。禁止用邻类知识把缺项补成“完整最高额”后宣称审完。

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 《最高额保证合同》，写明最高债权额 + 确定期间内连续发生的授信／贸易／保理等 | 本类型 | 正触发；两套时钟都审 |
| 标题普通保证，正文却有最高限额和连续发生期间 | 本类型 | 正触发；标题必须改正 |
| 已特定主合同名称编号金额期限，无连续发生、无最高限额 | 单笔保证 | 负触发 `一般保证合同·审查` 或 `连带责任保证合同·审查` |
| “现在及将来一切债务”，既无期间也无限额 | 空白支票 | 不按本类型放行。红线要求补三要素，或转出后按单笔保证处理 |
| 同一文本是一笔借款加保证人签章 | 保证借款 | 负触发 `保证借款合同·审查` |
| 银行或非银行金融机构开立；见索即付；相符交单；URDG / ISP98 | 独立保函 | 负触发 `独立保函·审查`（未装则 `unavailable`） |
| 安慰函、维好、意愿书；仅知晓、关注、督促、尽合理努力 | 安慰函 | 负触发 `安慰函·审查`（未装则 `unavailable`） |
| 差额补足、流动性支持、回购承诺作为主给付 | 增信措施 | 负触发 `增信措施类保证合同·审查`（未装则 `unavailable`） |
| 最高额抵押、最高额质押，保证只是名称混用 | 物权担保 | 转对应抵押／质押场景；本任务不审登记整案 |

### 1.2 加载协议（硬闸）

本技能已锁定 **保证合同 / 最高额保证合同**。只打开 `references/基本面.md` 与 `框架.md`。禁止读其他类型目录，禁止为对照再开第二类。

### 1.3 规避结构停笔

加载后或定性中出现：伪造或补假股东会／董事会决议；倒签保证合同或确定期间；把机关法人或公益性非营利法人改成“可签的保证人”；把普通最高额保证改写成见索即付独立保函以规避从属性；把无限额“一切债务”包装成最高额却拒补限额。

动作：

1. 交付告知：该结构违反民法典第六百八十二条、第六百八十三条、第六百九十条或公司决议程序，不得改写成可履行规避文本。
2. 不写假决议模板、倒签步骤、可履行的机关保证或非金融机构独立保函路径。
3. 风险表只保留识别依据和删除／改正句。
4. 用户坚持“改到能签且仍规避”：整体停止。

## 节点 2　主体、禁入与决议覆盖限额

### 2.1 主体表

建表：债权人、债务人、保证人、签约名、授权签字人。名称不一致不自动合并。最高额跨度长、总额大，记录保证人是否已有其他最高额占用，材料没有则标 `G#`，不得写成“资产充足”或“已经超负荷”。

支持依据（运行时核验）：民法典第六百八十三条；担保制度解释第五、六条。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 保证人为机关法人 | 红线。国务院批准转贷除外须见材料 | 改成可履行机关保证 |
| 以公益为目的的非营利法人、非法人组织 | 红线。解释第六条例外不在本任务展开成可签保证 | 学校医院“加个决议就能保证” |
| 村委会／居委会 | 原则上无效；代行村集体经济组织职能且履行讨论程序除外，材料不足则 `G#` | 已经有效 |
| 企业法人分支机构以自己名义保证 | 须见法人书面授权。无授权：字段停止 | 盖了分公司章就可以 |
| 登记为营利法人的民办学校／医院 | 不得仅以名称否定担保资格；仍核决议是否覆盖限额 | 当然无效或当然有效 |

口头“我们老板同意了”不得写成已授权。

### 2.2 公司对外担保决议必须覆盖该限额（硬闸）

支持依据：2023 年修订公司法第十五条（2024-07-01 施行）；担保制度解释第七、八条。

最高额的决议闸比单笔更严：决议记载的金额、对象、期间必须能罩住合同中的最高限额和确定期间。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 公司为他人提供最高额保证，未见章程指定的董事会或股东会决议 | 必须改：决议作为附件，未获决议不生效；债权人侧提示形式审查 | 法定代表人签字即对公司发生效力 |
| 为股东或实际控制人提供最高额保证 | 必须股东会决议，关联股东回避 | 董事会决议即可 |
| 决议只批准“单笔借款／单笔贸易【待填】万元”，合同却签最高额连续发生 | **越权红线**。必须改决议或改合同，使授权覆盖最高限额和确定期间 | 事后追认即可；按较大额理解 |
| 决议限额低于合同最高限额，或决议期间短于确定期间 | 并列冲突；必须改到一致 | 按合同较大额放行 |
| 相对人已做合理审查 vs 明知伪造 | 只分层，不认定善意或恶意 | 已经善意／已经无效 |
| 解释第八条例外 | 材料能回链才标可能例外；上市公司不适用其中若干项 | 无决议一律放过或一律无效 |

自然人保证：记录配偶是否签署。未签不得写成“一定不是共同债务”，也不得写成“必须共签才有效”。生存级个人无限最高额且用户拒绝升级：停止“可以签署”建议。

## 节点 3　最高限额与被担保债权种类

### 3.1 限额必须定量且定性（硬闸）

支持依据：民法典第六百九十条；担保制度解释第十五条。

审查清单，缺一项则不得写成限额已特定：

1. 最高债权额有阿拉伯数字和大写，或有可核验的确定方法。
2. 写明该限额是 **本金限额** 还是 **债权总限额**（含利息、违约金、损害赔偿、实现债权费用）。
3. 使用“最高余额／最高债权额”，而不是“累计发生额”。累计发生额不考虑还款回转，会把限额提前耗尽或引发解释争议。

| 文本写法 | 动作 | 不得写成 |
| --- | --- | --- |
| 空白、另议、以实际发生为准且无限额 | 红线。不按本类型放行 | 已经是最高额 |
| 只写“最高额人民币【待填】元”，未定性本金或总额 | 必须改。说明：未另约定时，解释第十五条将最高债权额理解为包括全部债权 | 已经是本金限额；已经是总额限额却不写 |
| 债权人要本金限额、利息费用在外 | 可作谈判句，必须显化“本金限额为……；利息、违约金和实现债权费用在该限额之外另行计算” | 不写就当然在外 |
| 保证人要总限额封顶 | 可作谈判句，显化“包括本金、利息、违约金、损害赔偿和实现债权费用在内的全部债权余额不超过……” | 不写就当然不含利息 |
| “累计发生额不超过” | 必须改成最高余额 | 已经按余额理解 |

超出最高限额的部分，现有依据不支持保证人承担责任。本任务不计算占用余额，只要求文本写清结算时以确定日的债权余额与限额比较。

### 3.2 债权种类与已存在债权

支持依据：第六百九十条；第四百二十条第二款（690 参照）。

- 必须列明业务类型：借款、信用证、承兑、保函、保理、买卖货款等。超出种类的债权不纳入。
- “无论单笔数额、频率及形式如何”只能在**已列明的种类之内**使用，不得用来吞掉种类限制。
- 确定期间起算前已经存在的债权，须当事人同意才转入。修改句单独写转入清单，未同意不得写成已经纳入。
- 1+N 结构可以保留：最高额母协议 + 期间内符合种类和限额的业务合同自动纳入，无需就每笔再签保证确认书。这是结构建议，不是“无需主合同”。

## 节点 4　债权确定期间与确定事由（第一套时钟）

本节点只处理“哪些债权进入池子、何时停止进入”。不在本节点写保证期间起算。

支持依据：民法典第六百九十条参照第四百二十条至第四百二十三条。

### 4.1 确定期间必须有起止

| 文本写法 | 动作 | 不得写成 |
| --- | --- | --- |
| “自【待填】年【待填】月【待填】日起至【待填】年【待填】月【待填】日止” | 可接受；核对是否与决议期间一致 | 已经生效 |
| 未写起止，也未写确定事由 | 必须改。说明：没有约定或约定不明，参照 423 第二项，设立满二年后当事人才可请求确定 | 已经可以随时确定；已经无限期纳入 |
| 把确定期间写成“保证期间”或“保证责任至该日终止” | 必须拆开。确定期间届满只表示停止纳入新债权，保证责任是否消灭看第二套时钟 | 确定期间届满＝保证人免责 |
| 新旧两份最高额期间重叠 | 并列；修改句写明是滚动承接还是并行新增，避免双重占用 | 当然是旧债续保 |

### 4.2 提前确定事由（参照 423，改写保证语境）

有下列情形之一的，被担保债权确定。修改句用“视为确定”，并列举：

1. 约定的债权确定期间届满。
2. 没有约定或约定不明，自本合同成立之日起满二年后，债权人或保证人请求确定。
3. 新的债权不可能发生。
4. 债务人被宣告破产或者解散。
5. 保证人被宣告破产或者解散。
6. 当事人约定的其他确定情形（例如债务人发生约定的违约事件，债权人书面通知停止产生新债权）。

第四百二十三条第四项是“抵押权人知道或者应当知道**抵押财产**被查封、扣押”。最高额保证没有抵押财产。不得把该款原样抄成“保证人财产被查封则债权确定”，除非当事人另行约定且不假装这是法定。当事人要约定保证人主要财产被查封即确定：标为特约，运行时核验后再落句。

确定后应结算。债权人侧可要求保证人对确定日余额书面签章确认；未签章不得写成已经确认。保证人侧可要求出示确定日债权清单和占用明细。本任务不代做结算数字。

## 节点 5　保证方式仍须显化（最高额不自动连带）

支持依据：民法典第六百八十六条、第六百八十七条、第六百八十八条；担保制度解释第二十五条。运行时必须核验。第六百九十条没有改写方式推定。

| 文本迹象 | 判断形状 | 本任务动作 |
| --- | --- | --- |
| 明确“最高额连带责任保证”，且写“债务人不履行到期债务时债权人可直接请求保证人” | 现有依据支持按连带审查 | 继续；标题、方式条款、签章页三处对齐 |
| 明确“最高额一般保证”，且写清不能履行 + 审判或仲裁 + 强制执行仍不能履行前有权拒绝 | 现有依据支持按一般保证审查 | 继续；期间内主张对象锁死为对债务人起诉或申请仲裁 |
| 未写一般或连带；只写“提供最高额保证” | 约定不明 → 按一般保证 | 必须改。不得写成已经是连带。禁止“金融惯例就是连带” |
| 标题连带、正文不能履行或先诉抗辩 | 约定冲突 | 并列，不选有利版。未消除前不出“已经是某一种方式”的放行意见 |
| 用户称“最高额没写就连带／按老担保法没写就连带” | 现有依据不支持 | 拒绝该口径 |

债权人侧方式不明时必须二选一，禁止保持空白：

- 选项 A：显化最高额一般保证 + 687 不能履行路径。
- 选项 B：显化最高额连带责任保证 + 不履行即可请求。须标明这是谈判升格，不是法定默认。

保证人侧默认按选项 A 出句。用户被要求签选项 B 时，必须提示放弃先诉抗辩、可被直接请求的后果。

## 节点 6　保证期间（第二套时钟）

支持依据（当次 `search_law` 写入 `L#`）：担保制度解释第三十条、第三十二条；民法典第六百九十二条、第六百九十三条。

规则形状（核验失败则效力字段停止，摘录和修改句草稿继续）：

1. 保证期间不发生中止、中断和延长。不得把三年诉讼时效写成保证期间。
2. **有约定的计算方式和起算时间，按照约定。** 可以约定“自债权确定之日起【待填】个月”，也可以约定逐笔自该笔履行期限届满之日起算。二者都是约定，不是法定唯一解。
3. **没有约定或约定不明**，适用解释第三十条两支：
   - 被担保债权的履行期限**均已届满**的，保证期间自**债权确定之日**起开始计算；
   - 被担保债权的履行期限**尚未届满**的，保证期间自**最后到期债权**的履行期限届满之日起开始计算。
   - 债权确定之日，依照第四百二十三条认定。
4. 约定“直至主债务本息还清时为止”等类似内容，视为约定不明。解释第三十二条把该段期间按六个月处理。最高额场合：期间长度按六个月；起算仍按解释第三十条两支，不得把单笔保证的“自主债务履行期限届满之日起六个月”生搬成唯一写法而不提确定日／最后到期日。
5. **主张对象跟方式走**：一般保证——期间内须对**债务人**提起诉讼或申请仲裁；连带责任保证——期间内须**请求保证人**。
6. 不得把确定期间届满写成保证期间届满。确定期间管入池，保证期间管主张。

| 文本写法 | 动作 | 不得写成 |
| --- | --- | --- |
| “保证期间自债权确定之日起【待填】个月／年”，且方式、主张对象齐全 | 可接受或可优化 | 法定就是二年或三年 |
| 未写保证期间，只写了确定期间 | 必须改。说明两套时钟；不明则解释 30 + 692 六个月 | 确定期间就是保证期间 |
| “直至本息还清为止”“保证责任随主债存在而存在” | 必须改。该段视为六个月；起算按解释 30 两支写清 | 长期有效；法定二年 |
| 把知识库“原则上逐笔起算”或“一律自确定日起算”写成已经是法定 | 现有依据不支持作为唯一法定 | 已经核验为唯一规则 |
| 方式是一般保证，却写“期间内向保证人催收即可” | 必须改主张对象 | 已经按连带行权 |
| 用户要本任务计算期间是否已经届满 | 目标停止，转保证责任评估 | 已经脱保／尚未脱保 |

示范修改句（期间拆开）：

`定位期间条款｜原文：保证期间与债权确定期间相同，至本息还清时为止｜建议改为：一、债权确定期间为【待填】年【待填】月【待填】日至【待填】年【待填】月【待填】日。该期间届满或发生本合同约定的确定事由后，不再纳入新的被担保债权，双方按确定日余额在最高限额内结算。二、保证期间自债权确定之日起【待填】个月。如确定时仍有被担保债权未届履行期限，保证期间自最后到期债权履行期限届满之日起【待填】个月。三、如本保证为一般保证，债权人应当在保证期间内对债务人提起诉讼或者申请仲裁；如本保证为连带责任保证，债权人应当在保证期间内请求保证人承担保证责任。｜理由：L# 解释第三十条、第三十二条，第六百九十二条、第六百九十三条｜可退让点：债权人可谈判长于六个月的约定期限，须写明起算点｜不接受时的红线：拒改“还清为止”或拒拆两套期间仍要放行`

解释第三十四条：期间届满后保证人在催收单上签字，原则上不恢复保证责任，除非成立新保证合同。签署提醒可写：不要在含义不明的催收单上签字。不指导“签字起死回生”。

## 节点 7　从属性、单笔无效、转让与变更

### 7.1 从属性；独立性约款删除

支持依据：第六百八十二条；担保制度解释第二条。

- 保证合同是从合同。主债权债务合同无效的，保证合同无效，但是法律另有规定的除外。无效后按过错承担相应民事责任，不是当然免责，也不是保证责任照旧。
- 当事人约定担保合同效力独立于主合同，或约定担保人对主合同无效的法律后果承担担保责任：该独立性约定无效。
- 非金融机构文本写“见索即付／效力独立”：不得改成独立保函。修改句删除独立性约定，恢复从属性。
- 金融机构开立的独立保函：负触发 `独立保函·审查`。

### 7.2 单笔交易无效：按核验条写，不编造一律不影响

开发窗口核验结论（运行时仍须复核，不得省略 `search_law`）：

- **没有**现行法律或司法解释条文写“最高额保证项下某一单笔主合同无效，不影响最高额保证合同的效力”。
- 不得把该句挂在第六百八十二条上。682 说的是相反方向的从属性。
- 分层处理，禁止第三种“一律”：
  1. **该笔交易本身无效**：该笔债权能否进入确定日余额，现有依据不足以写成“当然仍在担保池”或“当然整份最高额保证有效”。修改句可写：无效或被撤销的单笔交易，其返还或赔偿之债是否纳入，须另有合法约定并经保证人书面确认；未确认的，不得计入确定日余额。
  2. **最高额保证所对应的基础交易整体无效，或最高额保证自身因主体、决议、虚假意思而无效**：按 682 和解释 2，不得写成框架仍有效。
  3. **最高额保证自身有效、其余单笔交易有效**：结算时对其余有效债权在限额内承担责任，这是结算结果，不是“突破从属性”。
- 实务观点“具体债权与最高额保证无一一对应，故单笔无效不影响框架”只标争点，**不得写入 `L#`，不得写成一律不影响**。

禁止建议句：“本合同效力独立于任何单笔主合同”“保证人对主合同无效的法律后果承担担保责任”。

允许结算句（须同时删除独立性用语）：

`定位效力条款｜原文：本合同独立于主合同，任一单笔主合同无效不影响本合同｜建议改为：本合同为从合同。某笔基础交易被确认无效或被撤销的，该笔债权不计入确定日余额，除非双方另行书面确认该笔返还或赔偿之债属于被担保债权种类并占用最高限额。其余在确定期间内合法成立的债权，仍按本合同在最高限额内结算。本合同任何独立性约定无效。｜理由：L# 第六百八十二条、解释第二条；不得把单笔无效写成一律不影响｜可退让点：债权人可谈判把返还之债明确列入种类｜不接受时的红线：坚持改成独立保函或写“一律不影响”当已核验规则`

### 7.3 确定前部分转让与额度变更

支持依据：第四百二十一条、第四百二十二条（690 参照）；第六百九十五条至第六百九十七条。

- 债权确定前，部分债权转让的，最高额保证权原则上不随该部分转让，但是当事人另有约定的除外。修改句写清：未约定则受让人不得就该部分向保证人主张最高额保证；另有约定须保证人书面同意。
- 确定前变更确定期间、债权种类或最高限额，须保证人书面同意。参照 422 的“不得对其他抵押权人产生不利影响”在保证语境下改写为：不得损害其他担保权人或后顺位权利人。
- 未经保证人书面同意加重债务的，加重部分不负责；展期未经书面同意的，保证期间不受影响。框架里“无论是否同意均继续负责”不得当放行默认。
- 借新还旧、以贷还贷：须书面披露并由保证人确认知道该事实。未披露：债权人侧红线补告知；保证人侧标重大抗辩线索，不写成已经免责。

### 7.4 争议解决：改写法，不审策略

或裁或诉、机构不明：标待核，改成单一仲裁机构或单一法院连结点。出现仲裁条款：不得改写成“应向某法院起诉”并假装已选定诉讼。用户追问共同被告、执行不能证明、胜率：目标停止，转争议或 `或`。本技能不写起诉策略。

通知送达：可约定邮寄至载明地址第 X 日视为送达。不得把微信已读写成已经送达的唯一充分条件。
