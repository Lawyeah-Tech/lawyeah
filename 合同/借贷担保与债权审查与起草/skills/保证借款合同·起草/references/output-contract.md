# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的本金、利率、期限、账户、期间；把已失效《合同法》《担保法》及其解释写入结论；把约定不明写成已经是连带责任保证；把签字写成自然人借款已经成立；把砍头息后的面额当本金；把 24%、36% 或银行利率旧四倍写成现行保护上限；把还清为止写成长期有效或法定二年；输出起诉策略或保证责任已消灭。

## 1. 触发、单方立场与成果状态

立场（出借人 / 借款人 / 保证人）、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查保证借款合同（借款合同）」。写明主从一体是否成立：借款主文与保证人签章是否同在一份文本。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》《担保法》及其解释、1991 年借贷意见、2015 年 24%/36% 条文，或把“约定不明=连带／二年”写成现行规则时，记噪声，不得写入 `L#`。利率上限、679、670、686、692 无 `verified-result` 时，对应法律结论字段停止。

## 3. 类型与加载路径

父级 `借款合同`，子级 `保证借款合同`。定性理由必须同时满足：核心给付为资金借贷；同一文本存在保证从债且保证人有签章栏。易混切开：纯保证、纯借款、抵押借款、金融机构借款、最高额、独立保函、安慰函。

加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。职业放贷、转贷、机关或公益主体保证写停笔告知，不填可履行结构。

## 4. 三方主体、决议与文本版本

主体表：出借人、借款人、保证人、指定收款人、授权签字人。分列出借人是否持牌、保证人是否机关/公益/公司、是否为股东或实控人担保。名称不一致不自动合并。

版本表：正文、借条/收条、账户页、决议、授权、聊天确认。冲突并列，不选对用户有利的一版。口头“董事会同意了”“保证人点头了”不得写成已授权或已提供保证。

## 5. 双闸给付闭环

借款闸与保证闸分列，均须回链文本位置。

借款闸：

- 本金：阿拉伯数字与大写、币种；面额与拟到账额。
- 交付：转账 / 现金 / 指定第三人账户；户名是否与借款人一致。
- 成立时点：双方是否自然人；是否写成签字即成立。自然人路径必须落到提供借款时成立。
- 利息与费用：书面年利率；服务费、咨询费、违约金是否并行；出借人是否持牌决定上限口径。
- 用途、期限、还款账户、加速到期。

保证闸：

- 保证方式原句与判断（一般 / 连带 / 不明）。不明不得写成已经是连带。
- 保证期间原句、起算点；“还清为止”必须标为约定不明＝六个月。
- 期间内主张对象：一般保证＝对债务人起诉或申请仲裁；连带＝请求保证人。
- 保证范围是否跟着实付本金，而非面额。
- 主债是否特定到本笔借款。

缺口标 `G#`，不补商业数字。决议、公证、登记写成条件或双方义务期限，不写成已经完成。

## 6. 从属性、强制规范与利率口径

是否存在“效力独立于主合同”“见索即付”等独立性约定（删除，不改独立保函）。公司决议或越权担保。机关／公益主体禁入。利率：非持牌才对照法释〔2020〕17 号第 25 条；持牌转出或停止民间四倍结论。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。禁止输出无修改句的色块表。

本类型至少检查：主从缺一；方式不明被写成连带；期间还清为止或二年推定；主张对象写反；自然人签字即成立；砍头息按面额；民间利率未核验或套 24%/36%；持牌被套民间四倍；独立性约款；无决议；主债不特定；保证人未签。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`，不编造。禁止只给原则、不给句子。

建议句必须覆盖双闸：成立时点或到账本金；利率上限待核表述；保证方式显化（一般保证路径或点名连带）；期间定量且主张对象正确。框架里的 24%、期间三年当法定、不明即连带，不得直接当作建议句。

## 9. 谈判与签署提醒

谈判顺序：先红线（主体禁入、倒签、假决议、独立性改独立保函、职业放贷、违法用途、主债不特定），再必须改（方式显化、期间六个月口径、砍头息、成立时点、决议附件），最后可优化。

签署提醒：三方本人签或盖章；自然人建议签名并捺印；保证人必须本人签，不得代签；决议原件作为附件；日期真实；附件含到账确认。债权人侧：期间内按方式正确主张（一般保证起诉债务人，连带请求保证人）。保证人侧：勿在含义不明催收单上签字。不指导倒签、补假决议或起诉策略。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本任务交付可编辑草稿、未决项、自审风险表与自审后修改句。草稿必须覆盖本类型起草必写、附件必附与禁止出现。有完整待签文本要评改时转配对审查原子。不是履约交底、争议文书、保证责任评估或效力保证。
