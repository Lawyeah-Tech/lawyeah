# 边界与路由

本技能只审查 **借款合同 / 保证借款合同**。

正触发前提：同一份待签文本里同时存在借款主文和保证从债。缺一不可。标题叫“保证借款合同”但缺保证人签章或不见借款给付的，不得留在本技能做实体结论。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或标题保证借款、核心给付明显不是资金借贷加保证 | 本套导航的类型切开步骤 |
| 只有保证合同 / 保证函 / 保证条款册，不见借款金额、交付、返还 | 一般保证迹象 → `一般保证合同·审查`；可直接请求 / 明确连带 → `连带责任保证合同·审查` |
| 双自然人互借，保证人栏空白或无人签章 | `自然人之间的借款合同·审查` |
| 一方为企业的非持牌民间借款，无保证人签章 | `广义民间借款合同·审查` / `狭义民间借款合同·审查` |
| 企业之间拆借、资金占用费，无保证人签章 | `企业间借款合同·审查` |
| 出借人为商业银行、消费金融、信托等持牌机构，文本是格式贷款 | `金融机构借款合同·审查` |
| 抵押财产、登记、流押主导放行 | `抵押借款合同·审查` |
| 质押物或权利凭证移交主导 | `质押借款合同·审查` |
| 买卖/过户/股权转让作为还款担保，或到期不还则过户 | `让与担保型借款合同·审查`；专业版未收录该 P1 时输出 `unavailable`，不得硬套本技能改成可过户结构 |
| 最高债权额 + 一定期间连续发生，或保证“一切债务”而无本笔特定 | `最高额保证合同·审查` 或红线，不按单笔保证借款放行 |
| 独立保函、见索即付、URDG / 相符交单 | `独立保函·审查`（未装则 `unavailable`） |
| 安慰函、维好、仅知晓／督促／尽合理努力 | `安慰函·审查`（未装则 `unavailable`） |
| 差额补足、流动性支持、回购承诺作为主给付 | `增信措施类保证合同·审查`（未装则 `unavailable`） |
| 有完整待签文本要评改 | `保证借款合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 留本任务起草并自审 |
| 已签未争、问放款日、催收留痕、行权日历 | 本套导航的履约步骤 |
| 已成争，或主问保证责任是否消灭、怎么起诉、共同被告怎么列 | `或` 或 `或`；不写起诉策略 |
| 用户只要利息或逾期精算终局数字 | 测算技能或人工精算；本技能只审条款 |
| C 端大众快检 | 只分流，不回改 |

持牌机构若只是出借人身份、但用户拿来的是三方民间体例《保证借款合同》而非银行格式贷款：先核许可证。确认持牌且文本是机构格式贷款 → 转 `金融机构借款合同·审查`。许可证不明：利率法律结论字段停止，不把民间四倍写成银行上限。

职业放贷、套取金融机构贷款转贷、明知违法犯罪用途仍出借、伪造决议、倒签：停笔告知，不改写成可履行放贷或可履行保证文本。
