# 保证借款合同·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《担保法》及其解释当作现行规则。保证方式约定不明按一般保证，不得写原担保法默认连带。法定保证期间不明为六个月，不得写旧二年。民间利率上限须运行时核验，不得写 24%、36% 或银行利率旧四倍。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **借款合同 / 保证借款合同**，输出可编辑草稿、未决项、自审风险表与自审后修改句。有完整待签文本要评改时，转 `保证借款合同·审查`。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。中文名必须是「审查保证借款合同（借款合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查或起草；待签文本评改；履约交底；争议文书或起诉策略；有效性保证；利息精算终局数字；把普通保证改成独立保函；把约定不明写成已经是连带责任保证。

## 本类型硬闸

1. **主从一体**。同一份文本必须同时看得到借款主文和保证从债（保证条款 + 保证人签章栏）。来稿只有保证、没有借款主文 → `一般保证合同·审查` / `连带责任保证合同·审查`；只有借款没有保证人签章 → `自然人之间的借款合同·审查` / `广义民间借款合同·审查` / `企业间借款合同·审查`；物保为主 → `抵押借款合同·审查`；银行格式贷款 → `金融机构借款合同·审查`。
2. **保证方式必须显化**。未写清一般保证或连带责任保证，按民法典第六百八十六条按一般保证。债权人侧必须改“不能履行 + 先诉抗辩”或显化连带。禁止用旧担保法写成已经是连带。
3. **保证期间**。未约定或“还清为止”= 六个月。一般保证期间内须对**债务人**起诉或申请仲裁；连带期间内须请求保证人。
4. **从属性**。主债无效则保证无效（法律另有规定除外）。独立性约款删除，不改成独立保函（`独立保函·审查`）。
5. **借款侧**。自然人之间未交付则合同未成立（第六百七十九条）；砍头息以到账为本金（第六百七十条）；民间利率上限运行时核验合同成立时一年期 LPR 四倍，禁止 24%、36%、旧四倍。出借人是持牌金融机构则负触发 `金融机构借款合同·审查`，不得用民间四倍审银行稿。
6. **禁止主体与公司决议**。机关、学校、医院作保只告知，不改成可履行。公司为股东或实际控制人须股东会决议且关联股东回避；未见决议字段停止。公司法条号用 2023 年修订第十五条。
7. **主债特定**。保证“一切债务”而无本笔借款的金额、期限或编号 → 转最高额 `最高额保证合同·审查` 或红线。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句，且借款闸与保证闸都要有句。

禁止表述：约定不明就是连带；法定期间二年；签字即成立；砍头息后仍按面额计息；24%/36%/旧四倍为现行上限；未登记则保证未生效；保证一定有效。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿；尚未签署，尚未成争，核心给付是资金借贷，且同一文本内有保证条款并由拟签字保证人承担从债；用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只有保证合同或保证函，不见借款金额、交付、返还安排 → `一般保证合同·审查`（先诉/不能履行）或 `连带责任保证合同·审查`（可直接请求）；
- 只有借款双方，保证人栏空白或无人签章 → `自然人之间的借款合同·审查`（双自然人）/ `广义民间借款合同·审查` 或 `狭义民间借款合同·审查`（民间含企业一方）/ `企业间借款合同·审查`（企业互借）；
- 抵押财产、登记、流押主导放行 → `抵押借款合同·审查`；
- 出借人是商业银行等持牌机构，文本是格式贷款合同 → `金融机构借款合同·审查`；
- 最高额、一定期间连续发生、最高债权额限度 → `最高额保证合同·审查`；
- 独立保函、见索即付、URDG → `独立保函·审查`（未装则 `unavailable`）；
- 安慰函、仅知晓/督促/尽合理努力 → `安慰函·审查`（未装则 `unavailable`）；
- 有完整待签文本要评改 → `保证借款合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问放款、催收或行权日历 → 本套导航的履约步骤；
- 已催告、立案、开庭、仲裁，或主问保证责任是否消灭、怎么起诉 → `或` 或 `或`。

机关法人、公益性主体违规保证，或伪造决议、倒签、职业放贷、转贷：只出告知，不改写成可履行规避结构。

## 建立审查坐标

确认：使用者与授权；单方立场（出借人 / 借款人 / 保证人择一）；相对方；全文及附件版本；出借人是否持牌；双方是否自然人；本金、到账、利率、用途、期限；保证方式原句；保证期间原句；保证人是否本人签章；公司决议或授权；不可接受事项；法域与拟签署日。缺立场或本类型条件未谈妥则不启动起草。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的本金、利率、期限、账户、期间用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law`（法律结论 required）：核验 679 实践性、670 砍头息、680 与民间利率上限、686/687/688 保证方式、692/693 期间与主张对象、解释 32、682 从属性、683 禁入、公司法 15、法释〔2020〕17 号第 1 条与第 25 条的适用范围。
- `search_practiced`（optional）：补预扣、交付、方式措辞争点。返回“保证不明即连带”“24%/36%/旧四倍”“还清为止=二年”时记噪声。
- `search_template`（optional）：只借栏目结构。范本写连带、效力独立、期间二年或还清为止，不得当本约建议句。

不虚构案件系统。`search_law` 返回已失效《合同法》《担保法》及其解释、1991 年借贷意见、2015 年 24%/36% 条文时记为噪声，不得写入 `L#`。


## 起草模式

本原子只承担本类型起草。待签评改转 `保证借款合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。本类型硬闸改成正文必写、附件必附或禁止出现。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 同一份文本同时写借款主文和保证从债（保证条款 + 保证人签章栏）。
- 保证方式必须显化一般保证或连带责任保证；未写清按一般保证，债权人侧须改“不能履行 + 先诉抗辩”或显化连带。
- 保证期间写清起算与届满；未约定或“还清为止”按六个月。一般保证期间内须对债务人起诉或申请仲裁；连带期间内须请求保证人。
- 主债无效则保证无效（法律另有规定除外）；删除独立性约款。
- 借款侧：自然人之间未交付则合同未成立；本金以到账为准；民间利率上限按合同成立时一年期 LPR 四倍核验。
- 主债特定：本笔借款的金额、期限或编号。

### 附件必附

- 保证人签章栏（自然人本人签或公司有权签章）。
- 公司为股东或实际控制人作保时：股东会决议且关联股东回避。
- 无对应事实不编造附件，缺项写入未决项。

### 禁止出现

- 约定不明就是连带；法定期间二年。
- 签字即成立（自然人之间未交付）。
- 砍头息后仍按面额计息；24%／36%／旧四倍为现行上限。
- 未登记则保证未生效；保证一定有效。
- 独立性约款改成独立保函。
- 机关、学校、医院作保改成可履行。
- 保证“一切债务”而无本笔金额、期限或编号仍按本类型放行。
- 出借人是持牌金融机构仍用民间四倍审银行稿。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；条件未谈妥仍要出可签署终稿；用户坚持伪造倒签、补假决议、把机关或公益主体改成可履行保证人、把独立性条款改成独立保函、按旧担保法把约定不明写成连带、包装职业放贷或转贷、保证有效。
- `字段停止`：法域、利率上限、出借人是否持牌、679 成立、686/692 未核验；本金、到账、决议关键事实缺失。
- `目标停止`：主目标已变为待签评改、履约交底、争议文书、保证责任评估，或把本合同改成独立保函。

生存级金额或自然人无限保证且用户拒绝升级：停止“可以签署”建议。
