# 审查方法（锁定 借款合同 / 保证借款合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止把 `一般保证合同·审查`、`连带责任保证合同·审查` 或 `自然人之间的借款合同·审查` 的 method 拼贴后换标题当作本文件。禁止套用买卖验收、定金比例或挂靠改写。

本文件的主线是 **同一份文本里的借款主债 + 保证从债**。两套闸都要走完，缺一闸不得宣称审查完成。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、签字即成立、保证不明即连带，或唯一必得本息。

`search_law` 返回已失效《合同法》《担保法》及其解释、1991 年借贷意见、2015 年 24%/36% 条文、法释〔2020〕6 号已被修改文本时记为噪声，不得写入 `L#`。`search_practiced` 仍写“保证不明推定连带”“还清为止=二年”“银行利率四倍”的，同样记噪声。

示范文本只参考结构。检索到的保证借款范本多为连带责任保证、含独立性条款、期间二年或“至偿清之日终止”，不得照抄当本约建议句。

知识库纠正（不回写双文件）：

- `基本面.md` 把本类型利率一律写成 LPR 四倍：仅民间非持牌适用。出借人是持牌金融机构，负触发 `金融机构借款合同·审查`，或利率闸改走监管口径，不得用第 25 条审银行稿。
- `框架.md` 写年利率 24% 可能不被支持：2015 年旧口径，禁止当现行红旗数字。
- `框架.md` 建议保证期间“届满之日后三年”：只是债权人谈判口径，不是法定默认。无约定或“还清为止”按第六百九十二条和解释第三十二条为六个月。
- `框架.md` 把“主合同任何变更无论是否取得保证人同意保证人均负责”当最佳实践：与第六百九十五条冲突，加重部分未经书面同意不当然约束保证人。只可作债权人谈判句，须标明可能不被支持。
- 保证无需登记才生效。不得写“未登记则保证未生效”。
- 本任务审查的是拟在民法典施行后签署的新文本。时间效力规定第二十七条只处理施行前已成立合同的期间过渡，不得给待签稿套旧担保法默认或旧二年期间。

## 节点 1　主从一体识别与单目录加载

### 1.1 定性（本类型灵魂闸）

用标题、核心给付和签章栏定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须同时满足才正触发：

1. **借款主文可读**：能读出出借人、借款人、本金或确定方法、返还安排（期限或还款方式至少有一项）。
2. **保证从债同在**：正文有保证条款，或保证人栏由拟签字第三人承担代为清偿或保证责任；保证人不是借款人本人。

缺第 1 项：不是本类型。缺第 2 项：不是本类型。禁止用邻类知识把缺项补成“完整保证借款”后宣称审完。

附带一句抵押或质押、但放行关键仍是保证人签章与借款给付：留本技能，物保只审对本约的引用是否闭环，不展开登记整案。抵押一旦成为主结构，转 `抵押借款合同·审查`。

### 1.3 违法结构停笔

## 节点 2　三方主体、禁入与决议

### 2.1 主体表

建表：出借人、借款人、保证人、指定收款人、授权签字人。姓名／名称、证件号或统一社会信用代码、送达地址分列。不一致不自动合并。

出借人是否持牌在本节点先标，供节点 3 选利率口径。许可证未出示：不把“看起来像银行”写成已经是金融机构，也不把民间四倍写成已经适用。

保证人与借款人不得是同一法律主体。法定代表人为本公司借款签字，不等于个人保证；要个人保证必须另有本人保证意思和签章位置。

### 2.2 禁止主体（只告知，不改可履行）

支持依据（运行时核验）：民法典第六百八十三条；担保制度解释第五、六条。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 保证人为机关法人 | 红线。国务院批准转贷除外须见材料 | 改成可履行机关保证 |
| 以公益为目的的非营利法人、学校、幼儿园、医院 | 红线 | 加个决议就能签 |
| 村委会／居委会 | 原则上无效；代行村集体经济组织职能且履行讨论程序除外，材料不足则 `G#` | 已经有效 |
| 企业法人分支机构以自己名义保证 | 须见法人书面授权。无授权：字段停止 | 盖了分公司章就可以 |
| 登记为营利法人的民办学校／医院 | 不得仅以名称否定担保资格；仍核决议 | 当然无效或当然有效 |

用户坚持把禁入主体改到能签：整体停止。

### 2.3 公司对外担保决议（硬闸）

支持依据：2023 年修订公司法第十五条（2024-07-01 施行）；担保制度解释第七、八条。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 公司为他人保证，未见章程指定的董事会或股东会决议 | 必须改：决议作为附件，未获决议不生效；债权人侧提示形式审查 | 法定代表人签字即对公司发生效力 |
| 为股东或实际控制人保证 | 必须股东会决议，关联股东回避 | 董事会决议即可；口头“董事会同意了”即已授权 |
| 决议金额、对象、期限与本合同不一致 | 并列冲突；必须改到一致 | 按较大额理解 |
| 解释第八条例外（金融机构开保函、担保公司、全资子公司、持三分之二以上表决权股东签字） | 材料能回链才标可能例外 | 无决议一律放过或一律无效 |

口头“我们老板同意了”不得写成已授权。未见决议字段：该签署能力字段停止，不出“可以盖章”的放行意见。

自然人保证：记录配偶是否签署。未签不得写成“一定不是共同债务”，也不得写成“必须共签才有效”。生存级个人无限保证且用户拒绝升级：停止“可以签署”建议。

## 节点 3　借款主债闸（成立、到账、利率）

本闸审主债。主债写残，保证闸再漂亮也不能放行。

### 3.1 成立时点：自然人实践性，其他人诺成

双方均为自然人：借款合同自贷款人**提供借款**时成立（第六百七十九条）。仅有三方签字，不得写成主债已经成立，也不得写成保证已经附着于一笔已成立债权。

核验后可引用的提供借款判断点（须 `search_law` 写入 `L#`）：现金自借款人收到时；转账自资金到达借款人账户时；票据自依法取得票据权利时；授权支配特定账户自取得实际支配权时。

| 文本写法 | 本任务动作 |
| --- | --- |
| “本合同自三方签字之日起成立／生效”，且双方自然人 | 必须改。拆成：书面文本固定借贷合意与保证意思；自然人之间的借款合同自出借人实际提供借款时成立；保证随主债成立而附着 |
| “签字即视为已经收到全部借款”且无独立到账安排 | 红线或必须改。禁止用拟制收到代替交付事实 |
| 出借人或借款人至少一方不是自然人 | 不适用 679。诺成成立，但仍须写清放款账户与到账视为履行 |
| 用户要求把日期写成已经放款或倒签成立日 | 整体停止 |

未实际提供借款时：借款人无权请求交付；出借人不得把未成立主债写成已经可执行；保证人不得被写成已经对一笔不存在的主债负责。本任务是签前评改，不得把未来放款写成已经完成。

### 3.2 本金与砍头息（第六百七十条）

1. 本金必须同时有阿拉伯数字与大写。不一致并列，修改句写明以大写为准或重新核对后填写同一数字，不擅自改数。
2. 利息预先在本金中扣除的，应当按照实际借款数额返还借款并计算利息。保证范围中的“本金”必须跟到账额，不得跟面额。
3. 下列写法按预扣或变相预扣处理：先行扣除利息／服务费／渠道费后支付；面额与转账条款不一致；放款时扣留“保证金、咨询费”且不独立结算。
4. 修改句固定方向：`借款本金以出借人实际提供并到达约定账户的金额为准，预扣的利息或费用不计入本金。保证人对前述实际提供金额及依该金额计算的合法利息承担责任。`

### 3.3 利率口径必须先定性出借人

禁止直接输出银行同类贷款利率四倍、年利率 24%、年利率 36%，或任何未核验的“四倍”，作为现行保护标准。

动作：

1. 先判断出借人是不是经金融监管部门批准设立的贷款机构或其分支。是 → 负触发 `金融机构借款合同·审查`，本任务不把法释〔2020〕17 号第 25 条写成该稿上限。
2. 不是持牌、属于民间借贷：调用 `search_law` 核验现行民间利率上限。开发窗口 2026-08-18 核验结果（供对照，不得代替运行时核验）：法释〔2020〕17 号第 25 条，约定利率超过**合同成立时**一年期贷款市场报价利率四倍的部分不予支持。逾期利息、违约金或其他费用总和见第 28、29 条。
3. 核验失败或结果冲突：利率法律结论字段停止。仍可摘录文本利率并给出“待核验现行上限后改写”的修改句草稿。
4. 一年期 LPR 当次数值未核验：不编造百分比，用 `【合同成立时一年期 LPR × 核验所得倍数，待填】`。
5. 知识库“一律 LPR×4”不得用于持牌机构，也不得在未核验时写成已核验结论。

自然人之间对支付利息没有约定或约定不明确：视为没有利息。仅有“利息面议”“适当付点”视为约定不明。出借人立场必须改成书面年利率或明确无息。

服务费、咨询费、通道费与利息并行时，按费用总和审查，不得拆成“利息合法 + 费用另算”。

### 3.4 用途、期限、账户

用途必须具体。出现赌博、吸毒、放高利、归还赌债：追问出借人是否知情；知情或应知仍出借：效力红旗，停笔。指定收款账户户名须与借款人一致；打入第三人或保证人账户，必须有借款人本人签署的指定收款条款。期限须有起止或“自实际提供借款之日起【待填】个月”。加速到期可以谈，但条件要可识别；禁止“出借人认为必要即可提前收回”无条件放行。

## 节点 4　保证方式必须显化（从债闸一）

支持依据：民法典第六百八十六条、第六百八十七条、第六百八十八条。运行时必须核验，不得用记忆中的旧担保法第十九条。

本节点的任务不是替用户选一种方式然后假装文本已经写清。任务是：**把方式从文本里读出来；读不出来就按一般保证处理，并强制出显化句。**

### 4.1 认定表

| 文本迹象 | 判断形状 | 本任务动作 |
| --- | --- | --- |
| 明确“一般保证”，且写清“不能履行”+ 审判或仲裁 + 强制执行仍不能履行前有权拒绝 | 现有依据支持按一般保证 | 继续；标题、保证条款、签章页三处对齐 |
| “不能履行”“无力偿还”“经法院执行仍不能偿还” | 一般保证迹象 | 路径不完整的，必须补 4.2 句 |
| 未写一般或连带；只写“提供保证／由某某担保” | 约定不明 → 按一般保证 | 必须改。不得写成已经是连带。禁止引用失效担保法第十九条 |
| 明确“连带责任保证”，或“不履行即承担／可直接请求／无条件承担”，无债务人先行意思 | 连带迹象 | 留本技能（因为主债同文本）。必须把“连带责任保证”四字和可直接请求写进建议句，供双方看见；不改成先诉后宣称仍是本类型审完 |
| 标题连带、正文一般或先诉抗辩，冲突未消除 | 约定冲突 | 并列，不选有利版。未消除前不出“已经是某一种方式”的放行意见 |
| 用户称“按老担保法，没写就连带” | 现有依据不支持 | 拒绝该口径；不明按 686 一般保证并出显化句 |

### 4.2 债权人侧必须二选一（硬闸）

方式不明时，债权人侧不得接受“先这么签，出事再解释”。修改句必须落到下列之一，禁止第三种“保持空白”：

**选项 A（法定默认落地）**：显化一般保证，写清不能履行路径。

`定位保证条款｜原文：由丙方提供担保｜建议改为：本保证为一般保证。保证人仅在借款人不能履行债务时承担保证责任。在主合同纠纷未经审判或者仲裁，并就借款人财产依法强制执行仍不能履行债务前，保证人有权拒绝向出借人承担保证责任。｜理由：L# 第六百八十六条、第六百八十七条｜可退让点：可补写 687 第二款四项例外，放弃须书面｜不接受时的红线：对方坚持空白不写方式，或要求按旧担保法视为连带`

**选项 B（谈判升格）**：显化连带责任保证。

`定位保证条款｜原文：由丙方提供担保｜建议改为：本保证为连带责任保证。借款人不履行到期债务或者发生本合同约定的情形时，出借人可以请求借款人履行债务，也可以请求保证人在保证范围内承担保证责任。｜理由：L# 第六百八十八条；本句是谈判升格不是法定默认｜可退让点：保证人拒签连带则回到选项 A｜不接受时的红线：不得在意见里把未改文本写成已经是连带`

保证人侧：默认按选项 A 出句；用户被要求签选项 B 时，必须提示放弃先诉抗辩、可被直接请求的后果。不得替保证人默示接受连带。

口头“保证人说了算连带／算一般”：现有依据不支持写成已约定。放弃先诉抗辩须书面。全面书面放弃先诉且允许直接请求的，按连带条款审查，不再假装仍是一般保证。

### 4.3 语言闸

一般保证必须使用“不能履行”，避免单独使用“不履行”却不写先行路径。连带必须出现“连带责任保证”或可直接请求的完整句。多名保证人：未约定份额的，写清按份或连带共同保证，不得默认“互相无追偿”。保证人未签字、代签、只在见证栏出现：不成立保证字段。

## 节点 5　保证期间与主张对象（从债闸二）

支持依据（当次 `search_law` 写入 `L#`）：民法典第六百九十二条、第六百九十三条；担保制度解释第三十二条。

规则形状（核验失败则效力字段停止，摘录和修改句草稿继续）：

1. 保证期间不发生中止、中断和延长。
2. 约定早于或与主债务履行期限同时届满的，视为没有约定。
3. 没有约定或者约定不明确的，保证期间为主债务履行期限届满之日起六个月。
4. 约定“直至主债务本息还清时为止”等类似内容，视为约定不明，期间为届满之日起六个月。
5. 主债务履行期限没有约定或约定不明的，期间自债权人请求债务人履行的宽限期届满之日起计算。
6. **主张对象必须跟方式走**：一般保证——债权人未在保证期间内对**债务人**提起诉讼或者申请仲裁的，保证人不再承担保证责任。连带责任保证——债权人未在保证期间内**请求保证人**承担保证责任的，保证人不再承担保证责任。
7. 不得把三年诉讼时效写成保证期间。不得把框架建议的二年或三年写成法定默认。

| 文本写法 | 动作 | 不得写成 |
| --- | --- | --- |
| 明确“自主债务履行期限届满之日起【待填】个月／年”，且晚于履行期限届满 | 可接受或可优化 | 法定就是二年或三年 |
| 未写期间 | 必须改。说明现行默认六个月 | 担保法下二年 |
| “直至本息还清为止”“保证责任随主债存在而存在” | 必须改。视为约定不明＝六个月 | 视为无限期或二年 |
| 方式是一般保证，却写“期间内向保证人催收即可” | 必须改。主张对象改为对借款人起诉或申请仲裁 | 已经按连带行权 |
| 方式是连带，却写“必须先起诉借款人并执行不能” | 与 688 冲突；并列后按用户选定方式改主张对象 | 悄悄改成一般保证或悄悄改成连带 |
| 用户要本任务计算期间是否已经届满 | 目标停止，转保证责任评估 | 已经脱保／尚未脱保 |

示范修改句：

`定位保证期间条款｜原文：保证人承担保证责任直至借款本息全部还清时为止｜建议改为：保证期间自主债务履行期限届满之日起【待填】个月。如本保证为一般保证，出借人应当在保证期间内对借款人提起诉讼或者申请仲裁；如本保证为连带责任保证，出借人应当在保证期间内请求保证人承担保证责任。逾期未依法行使权利的，保证人不再承担保证责任。｜理由：L# 第六百九十二条、第六百九十三条、解释第三十二条｜可退让点：债权人可谈判长于六个月的约定期限，须写明起算点｜不接受时的红线：拒改“还清为止”仍要按长期有效或法定二年放行`

解释第三十四条：期间届满后保证人在催收单上签字，原则上不恢复保证责任，除非成立新保证合同。签署提醒可写：不要在含义不明的催收单上签字。不指导“签字起死回生”。

## 节点 6　从属性与主债特定

### 6.1 主债必须特定到本笔借款

审查清单，缺一项则不得写成主债已特定：

1. 本金数额或可核验的确定方法（并与节点 3.2 的实付口径一致）。
2. 出借人与借款人与保证条款记载一致。
3. 履行期限或宽限期起算安排。
4. 保证范围指向本合同项下债务，而不是“保证人名下一切债务”。

| 文本写法 | 动作 |
| --- | --- |
| “为本公司现在及将来一切债务提供保证”，无期间、无限额 | 不按本类型放行。转 `最高额保证合同·审查` 或红线，要求特定到本笔借款 |
| 本金、期限空白仍要可签署意见 | `G#`；不得出可签署意见 |
| 主合同与备案合同、阴阳两份金额 | 并列，不选有利版；禁止改成可履行避税结构 |

### 6.2 从属性；独立性约款删除

支持依据：第六百八十二条；担保制度解释第二条。

- 保证是从合同。主债权债务合同无效的，保证合同无效，但是法律另有规定的除外。无效后按过错承担相应民事责任，不是当然免责，也不是保证责任照旧。
- 当事人约定担保合同效力独立于主合同，或约定担保人对主合同无效的法律后果承担担保责任：该独立性约定无效。
- 非金融机构文本写“见索即付／效力独立”：不得改成独立保函。修改句删除独立性约定，恢复从属性。
- 金融机构开立的独立保函：负触发 `独立保函·审查`。

自然人路径下，主债因未交付而未成立：保证无所附。修改句把保证生效时点接到主债依 679 成立之后，不得写成“保证条款签字即独立生效”。

## 节点 7　范围、变更、混合担保、争议条款

### 7.1 保证范围

未另约定时，范围包括主债权及其利息、违约金、损害赔偿金和实现债权的费用。债权人侧可用“包括但不限于诉讼费、仲裁费、律师费、保全费、执行费”作列举，数字用 `【待填】`。保证人侧：超主债范围的部分应限缩；“全额无限”标红旗。范围中的本金必须是节点 3.2 的实际提供额。

### 7.2 主合同变更

第六百九十五条：未经保证人书面同意，减轻债务的仍对变更后债务负责；加重部分不负责。变更履行期限未经书面同意的，保证期间不受影响。

修改句：展期、增加本金、提高利率、借新还旧须事先书面通知并征得保证人同意，否则保证人仅在原范围内或依法对加重部分免责。框架里“无论是否同意均继续连带负责”不得当放行默认。不在本任务认定已经免责。

### 7.3 混合担保

第三百九十二条：有约定从约定。无约定或约定不明：债务人自己提供物保的，债权人应先就该物保实现；第三人提供物保的，债权人可选择。物保条款一旦主导文本结构，转 `抵押借款合同·审查`。本任务不得把未约定写成“已经可以跳过债务人物保和先诉抗辩”。

### 7.4 争议解决：改写法，不审策略

或裁或诉、机构不明：标待核，改成单一仲裁机构或单一法院连结点。出现仲裁条款：不得改写成“应向某法院起诉”并假装已选定诉讼。用户追问共同被告、执行不能证明、胜率：目标停止，转争议或 `或`。本技能不写起诉策略。

通知送达：可约定邮寄至载明地址第 X 日视为送达。不得把微信已读写成已经送达的唯一充分条件。
