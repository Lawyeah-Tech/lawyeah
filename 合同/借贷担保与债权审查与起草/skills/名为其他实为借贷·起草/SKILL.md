# 名为其他实为借贷·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《担保法》《物权法》及其解释当作现行规则。不得把年利率 24%/36%、银行同类贷款利率旧四倍当作现行上限。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **借款合同 / “名为其他合同，实为借贷” 的合同**：标题常是投资、合伙、合作开发、融资租赁、咨询服务或设备买卖，真实意思是还本付息。输出可编辑草稿、未决项、自审风险表与自审后修改句。有完整待签文本要评改时，转 `名为其他实为借贷·审查`。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「审查“名为其他合同，实为借贷” 的合同（借款合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查或起草、待签文本评改、履约交底、争议文书、合同有效性保证、固定回报必然可执行、利息精算终局数字、把阳合同改成可强制入股或可强制过户的履行结构。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿；尚未签署，尚未成争；**外观不是借款**，核心给付却是一方提供资金、另一方到期返还本金并支付固定或保底回报，出资方不承担经营风险。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 送审主文件已是《借款合同》或借据，过户、回购或不清算归己是担保主结构 → `让与担保型借款合同·审查`；专业版未收录该 P1 时输出 `unavailable`，不得硬套本技能改成可过户结构；
- 以房屋买卖、网签、过户或回购外观为借款提供担保 → `以房屋买卖网签过户或回购外观为借款提供担保→`；
- 真实移转标的物所有权换价款，买受人真实取得使用或处分，无还本付息意思 → 买卖类场景原子（`标的物所有权换价款，买受人真实取得使用或处分，无还本付息意思→买卖类场景原子（` / `或` / `等）；` 等）；
- 真实股权投资或合伙：共享收益、共担风险、出资方参与经营或按业绩分配，退出价格不与经营脱钩的固定回购 → 引擎或对应投资/合伙原子，不得按借贷改完；
- 标题已是借款、无伪装主结构 → `狭义民间借款合同·审查` / `自然人之间的借款合同·审查` / `企业间借款合同·审查` / `金融机构借款合同·审查`；
- 保证/抵押/质押是已标明借款的主结构 → `保证借款合同·审查` / `抵押借款合同·审查` / `质押借款合同·审查`；
- 有完整待签文本要评改 → `名为其他实为借贷·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问放款、回购、撤销登记或付款节点 → 本套导航的履约步骤；
- 已成争（催告还本、请求履行买卖/入股、诉讼仲裁）→ 合同争议或对应专项领域。

挂靠、违法分包、规避限购、包装职业放贷或转贷、虚构租赁物：只出告知，不改写成可履行结构。

## 本类型硬闸

1. **穿透定性**。标题、鉴于、发票税目和工商外观不决定类型。同时满足“提供资金 + 到期还本 + 固定或保底回报 + 不承担经营风险”，按民间借贷审查。修改句必须把鉴于和核心给付改成可识别的借贷事实（本金、期限、回报折算），不得继续用“投资/租金/服务费”掩盖还本付息。无上述实质、相对方真实共担风险：负触发，不填十节实体结论。
2. **利率上限必须运行时核验**。民间借贷路径禁止把银行同类贷款利率四倍、年利率 24%、年利率 36% 写成现行保护标准。核验后：超过合同成立时一年期贷款市场报价利率四倍的部分不予支持（法释〔2020〕17 号第 25 条）。固定收益、回购溢价、租金、咨询费、服务费、管理费、逾期利息、违约金按第 29 条合并计算。持牌机构不得套用该上限。核验失败则利率法律结论字段停止。
3. **与让与担保借款 `让与担保型借款合同·审查`、买卖切开**。借款主文件加过户/不清算归己，或房屋买卖担保，不得留在本技能改成可过户、可强制履行买卖。真实买卖不得套本技能。禁止把本技能写成普通借款换标题：不走实践性成立、保证期间、抵押登记或质权交付主线。
4. **砍头息与拆分合同必须合并折算**。预先扣除的利息、服务费、咨询费、管理费、投资溢价款，按实际出借金额认定本金（民法典第 670 条；法释〔2020〕17 号第 26 条）。阳合同加服务/咨询/顾问合同必须合并审查。不得写成“另签服务合同即可合法收取”。
5. **职业放贷、转贷、虚构租赁物不得改写成可履行**。未取得放贷资格而以营利为目的向社会不特定对象提供借款、套取金融机构贷款转贷（法释〔2020〕17 号第 13 条）、以虚构租赁物订立融资租赁合同（民法典第 737 条）：停笔告知，不写可履行放贷或可履行租赁路径。

## 建立审查坐标

确认：使用者与授权；单方立场（资金方/名义投资人/出租人/买方，或融资方/标的公司/承租人/卖方）；相对方；全文及补充协议、回购/对赌、服务咨询合同、转账与发票、决议等附件版本；伪装形态（名股实债、名合实贷、名租实贷、名买卖实拆借、拆分费用）；是否参与经营、是否承担亏损；回报是否固定；是否无条件回购；是否另有过户或让与担保；不可接受事项；法域与签署时限。缺立场或本类型条件未谈妥则不启动起草。同时掌握双方秘密或潜在冲突时，先停止策略输出。

宿主可调用时：

## 起草模式

本原子只承担本类型起草。待签评改转 `名为其他实为借贷·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。本类型硬闸改成正文必写、附件必附或禁止出现。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 鉴于和核心给付改成可识别的借贷事实：提供资金、到期还本、固定或保底回报折算、出资方不承担经营风险。
- 本金、期限、回报折算年化写清。
- 阳合同与服务／咨询／顾问合同合并折算；预扣利息、服务费、咨询费、管理费、投资溢价款按实际出借金额认定本金。
- 利率上限运行时核验：超过合同成立时一年期 LPR 四倍的部分不予支持；固定收益、回购溢价、租金、咨询费、服务费、管理费、逾期利息、违约金合并计算。

### 附件必附

- 与本约同时存在的服务／咨询／顾问／回购协议。
- 有费用拆分时：转账与费用拆分材料。
- 无对应事实不编造附件，缺项写入未决项。

### 禁止出现

- 继续用“投资／租金／服务费”掩盖还本付息。
- “另签服务合同即可合法收取”。
- 24%／36%／银行同类贷款利率旧四倍写成现行保护标准。
- 持牌机构套用民间上限。
- 把过户／不清算归己或房屋买卖担保改成可过户、可强制履行买卖。
- 职业放贷、转贷、虚构租赁物改成可履行放贷或可履行租赁。
- 把阳合同改成可强制入股或可强制过户。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口，不代替节点。

0. 签署状态与成果分流
1. 类型识别与单目录加载（穿透；切开让与担保、买卖、真投资、普通借款）
2. 主体、职业放贷红旗、决议错位
3. 实质标的与名义标的
4. 回报、回购、阴阳合同合并
5. 利率上限、砍头息、费用总和
6. 流质/过户夹带：切开或停笔，不改成可取得所有权
7. 程序规避、公证债权文书、内部决议
8. 按框架六步出修改句

必须有修改句。禁止只打红黄绿。每个风险回链文本位置。禁止套用买卖合同的标的验收、定金百分之二十或挂靠改写节点。禁止套用普通借款的实践性成立、保证期间、抵押登记或质权交付主线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；条件未谈妥仍要出可签署终稿；用户坚持伪造倒签或假放款、包装职业放贷或转贷、把流质改成可过户、把阳合同改成可强制履行的真实投资或真实买卖、保证固定回报必然可执行。
- `字段停止`：法域、利率上限、是否持牌或职业放贷、是否真实共担风险、全套阴阳合同未齐。
- `目标停止`：主目标已变为待签评改、履约交底、争议文书或利息精算终局。

生存级金额或用户拒绝升级：停止“可以签署”建议。
