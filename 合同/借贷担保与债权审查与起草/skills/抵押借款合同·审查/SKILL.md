# 抵押借款合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《担保法》《物权法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **借款合同 / 抵押借款合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查、从零起草、履约交底、争议文书、抵押权或合同有效性保证、优先受偿终局认定、利息精算终局数字。

## 工作边界

正触发：已有可读待签文本要评改，尚未签署，尚未成争，核心给付是资金借贷，**且抵押是主结构**——存在可识别的抵押人/抵押权人，并以特定财产不转移占有为借款提供担保。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 以买卖、过户、回购或“到期不还则归债权人所有且不清算”作为还款担保，或财产形式上先转到债权人名下 → `让与担保型借款合同·审查`；专业版未收录该 P1 时输出 `unavailable`，不得硬套本技能改成可过户结构；
- 无抵押财产、无抵押条款，只有保证人/保证条款 → `保证借款合同·审查`；
- 无抵押、无保证的自然人互借 → `自然人之间的借款合同·审查`；一方为企业的狭义民间借款 → `狭义民间借款合同·审查`；
- 主结构为质押、权利凭证移交或股权出质 → `质押借款合同·审查`；
- 文本明显是买卖、租赁、投资入股且无抵押借款核心给付 → 本套导航的类型切开步骤 或对应场景原子；
- 无文本、本类型条件已谈妥、要出己方稿 → `抵押借款合同·起草`；
- 已签只问履约、登记办理进度或放款节点 → 本套导航的履约步骤；
- 已成争（催告、解押、实现抵押权、诉讼仲裁）→ 合同争议或对应专项领域。

持牌机构放贷且审查重点是监管利率、放款条件而非抵押从属与物权设立时，可提示并行 `金融机构借款合同·审查`；只要抵押财产、登记、流押、从属仍是放行关键，留本技能。

职业放贷、套取金融机构贷款转贷、明知违法犯罪用途仍出借、把禁止抵押财产改成可登记结构：只出告知，不改写成可履行放贷或可设立抵押权的文本。

## 本类型硬闸

1. **流质（流押）禁止**。债务履行期限届满前约定“到期不还则抵押财产归债权人所有”的，不得写成可以过户履行；只能改成折价、拍卖或变卖后优先受偿。不得把让与担保买卖文本留在本技能改成可过户条款。
2. **抵押财产必须特定化，并分开合同效力与抵押权设立**。不动产、在建建筑物抵押权自登记时设立；动产抵押权自抵押合同生效时设立，未经登记不得对抗善意第三人。未办理物权登记，不得写成抵押合同未生效，也不得写成已经取得优先受偿权。
3. **担保范围必须写清并与登记簿对齐**。法定范围是主债权及其利息、违约金、损害赔偿金、保管担保财产和实现担保物权的费用；另有约定从约定。不动产登记簿记载与合同约定不一致时，优先受偿范围以登记簿为准，不得只按合同扩张。
4. **主债与抵押从属**。抵押合同是主债权债务合同的从合同。主合同无效，抵押合同无效，法律另有规定的除外。约定“抵押合同独立生效/主合同无效仍承担担保责任”的独立性条款无效。不得把抵押人写成保证人，也不得把商品房按揭贷款与商品房买卖写成主从合同。
5. **抵押期间处分按现行规则**。默认抵押人可以转让抵押财产，另有约定的按约定；转让的，抵押权不受影响，抵押人应当及时通知抵押权人。禁止把已失效的“须经抵押权人同意才能转让，否则转让无效”写成现行默示规则。
6. **利率司法保护上限必须运行时核验**。民间借贷路径禁止把银行同类贷款利率四倍、年利率 24%、年利率 36% 写成现行保护标准。持牌机构路径不得套用民间借贷上限。核验失败则利率法律结论字段停止。

## 建立审查坐标

确认：使用者与授权；单方立场（出借人/抵押权人、借款人、第三人抵押人、拟签字共有人）；相对方；全文及抵押物清单、权属证明、决议等附件版本；主债权种类与数额；抵押财产是否特定；登记安排；担保范围；处分限制；利率与费用；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的本金、抵押物坐落、权证号、利率、期限用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law`（法律结论 required）：核验流押禁止、抵押书面与特定化、不动产/动产设立规则、合同效力与物权变动分离、担保范围、从属性与独立性约款、抵押期间转让、禁止抵押财产、房地一体、公司对外担保决议、民间借贷利率上限。
- `search_practiced`（optional）：补未登记责任、共有人同意、预告登记、借新还旧争点。返回“抵押合同自登记之日起生效”“须抵押权人同意转让否则无效”“保证不明即连带”“24%/36%/银行利率旧四倍”时记噪声。
- `search_template`（optional）：只借栏目结构。范本写“自抵押物办理登记之日起合同生效”不得当合同生效规则。

不虚构案件系统。`search_law` 返回已失效《合同法》《担保法》《物权法》及其解释、1991 年借贷意见、2015 年 24%/36% 条文时记为噪声，不得写入 `L#`。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口，不代替节点。

0. 签署状态与成果分流
1. 类型识别与单目录加载（借贷 + 抵押主结构）
2. 主体、权属、共有人、第三人抵押与公司决议
3. 主债与抵押从属
4. 抵押财产特定化、禁止抵押与登记
5. 担保范围及与登记簿对齐
6. 流质禁止与实现方式
7. 抵押期间处分；利率上限运行时核验
8. 按框架六步出修改句

必须有修改句。禁止只打红黄绿。每个风险回链文本位置。禁止套用买卖合同的标的验收、定金百分之二十或挂靠改写节点。禁止把本技能写成自然人互借换标题。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、补假登记、伪造共有人同意或公司决议、把流押改成可过户、把禁止抵押财产改成可登记、包装职业放贷或转贷、保证抵押权必然设立或必然优先受偿。
- `字段停止`：法域、利率上限、担保范围与登记、权属/共有、公司决议未核验；抵押财产无法特定。
- `目标停止`：主目标已变为从零起草、履约交底、实现抵押权文书或利息精算终局。

生存级金额、个人住房或第三人全部责任财产被抵押且用户拒绝升级：停止“可以签署”建议。
