# 狭义民间借款合同·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **借款合同 / 狭义民间借款合同**，输出可编辑草稿、未决项、自审风险表与自审后修改句。有完整待签文本要评改时，转 `狭义民间借款合同·审查`。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查或起草、待签文本评改、履约交底、争议文书、有效性或对方接受的保证、抵押权或保证责任终局认定、利息精算终局数字、P2P/小贷平台整案、职业放贷可履行结构。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿；尚未签署，尚未成争，**出借人是一般企业或自然人**，未持贷款牌照，也不是小贷、典当、网络小贷或网贷平台，核心给付是临时性、非经营性的货币融通，借款人到期返还本金并支付利息或无息。典型留本技能的，是自然人与企业之间的点对点拆借。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 文本出现 P2P、网络借贷信息中介、资金存管银行、小额贷款公司、典当、网络小贷或平台撮合额度 → `广义民间借款合同·审查`；不得用本技能审平台备案或 20 万/100 万限额；
- 双方均为自然人，文本形态是生活互借、借条或共债主线 → `自然人之间的借款合同·审查`；
- 双方均为非金融企业或非法人组织，且主结构是经营性拆借、资金占用费 → `企业间借款合同·审查`；
- 出借人是持牌金融机构或其分支机构 → `金融机构借款合同·审查`；
- 主结构是保证、抵押、质押或让与担保 → `保证借款合同·审查` / `抵押借款合同·审查` / `质押借款合同·审查` / `让与担保型借款合同·审查`；本技能只审借款主文对担保的引用是否闭环；
- 名为投资、合伙、买卖，固定回报或回购过户主导 → 引擎或对应原子；不在本任务改成可履行投资或过户；
- 文本明显是买卖、租赁且无资金借贷核心给付 → 本套导航的类型切开步骤 或对应场景原子；
- 有完整待签文本要评改 → `狭义民间借款合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问放款、还本付息节点 → 本套导航的履约步骤；
- 已成争（催告、解除、索赔、诉讼仲裁）→ 合同争议或对应专项领域。

职业放贷、套取信贷转贷、非法资金来源转贷、明知违法用途、套路贷：只出告知，不改写成可履行放贷结构。

## 本类型硬闸

1. **狭义，不是广义。** 本类型排除准金融机构和网贷平台。出借人应是一般企业或自然人，资金往来是临时性融通、不具经营性。出现小贷牌照、典当、P2P、资金存管、电子平台撮合：负触发 `广义民间借款合同·审查`，禁止把两类写成同一套审查方法。
2. **成立按主体组合分岔，禁止整类实践或整类诺成。** 仅双方均为自然人时，才适用民法典第 679 条和法释〔2020〕17 号第 9 条：自提供借款时成立。一方或双方为企业时，合同原则上自承诺生效时成立，不以交付为成立要件；未按约放款走继续履行或赔偿，不写成法定未成立。框架尾部“民间借款一律实践生效”不得覆盖本分岔。
3. **利率走合同成立时一年期 LPR 四倍。** 借期内利率、逾期利率、违约金、律师费等其他费用，总计不得超过该上限。禁止把年利率 24%、年利率 36% 或银行利率旧四倍写成现行上限。当次 LPR 未核验时不编造数值。
4. **利息约定不明也要分岔。** 双方自然人：约定不明视为没有利息。有企业或非法人组织参与：不得一律写成无息，应结合交易方式、交易习惯和市场报价利率确定，并要求改成明确年利率或月利率。没有约定利息与约定不明不得混写。
5. **砍头息。** 利息预先在本金中扣除的，以实际出借金额为本金并计息。面额抗辩不能推翻实付。
6. **效力红旗只告知，不改可履行。** 未取得放贷资格而以营利为目的向社会不特定对象提供借款；套取金融机构贷款转贷；以集资或向其他营利法人借贷的资金转贷；事先知道或应当知道用于违法犯罪仍出借；虚增债务、阴阳合同等套路贷外观。用户要求改到能继续放贷：整体停止。
7. **担保和配偶是配套。** 保证、抵押、质押已成主文件则负触发对应原子。本约只审引用是否闭环。配偶共签或同意函未附：字段停止，不写成已经是夫妻共同债务。

## 建立审查坐标

确认：使用者与授权；单方立场（出借人、借款人、拟签字的企业负责人或配偶）；相对方；全文及附件版本；主体属性（自然人/企业）与有无平台或牌照外观；本金、到账、利率、期限、用途、资金来源；成立条款写法；不可接受事项；法域与签署时限。缺立场或本类型条件未谈妥则不启动起草。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

## 起草模式

本原子只承担本类型起草。待签评改转 `狭义民间借款合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。本类型硬闸改成正文必写、附件必附或禁止出现。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 出借人是一般企业或自然人；资金往来写临时性融通、不具经营性。
- 成立按主体组合分岔：仅双方均为自然人才写自提供借款时成立；一方或双方为企业则书面诺成，未按约放款走继续履行或赔偿。
- 借期内利率、逾期利率、违约金、律师费等其他费用总计不超过合同成立时一年期 LPR 四倍。
- 利息约定不明也分岔：双方自然人视为没有利息；有企业或非法人组织参与不得一律写成无息，应改成明确年利率或月利率。
- 本金以实际出借金额为准；面额抗辩不能推翻实付。
- 有担保时只写引用是否闭环（合同名称、编号、担保范围是否指向本债）。

### 附件必附

- 有保证／抵押／质押时：担保合同名称与编号（只作引用，不改成担保主文件）。
- 拟主张夫妻共同债务时：配偶共签或同意函。
- 无对应事实不编造附件，缺项写入未决项。

### 禁止出现

- 把小贷牌照、典当、P2P、资金存管、电子平台撮合按本类型改完。
- “民间借款一律实践生效”覆盖企业参与一方。
- 年利率 24%、36% 或银行利率旧四倍写成现行上限。
- 没有约定利息与约定不明混写；企业参与仍一律写成无息。
- 砍头息后仍按面额计息。
- 未取得放贷资格而以营利为目的向社会不特定对象提供借款、转贷、知情违法用途、虚增债务或阴阳合同等套路贷外观改到能继续放贷。
- 配偶未签写成已经是夫妻共同债务。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口，不代替节点。

0. 签署状态与成果分流
1. 类型识别与单目录加载（狭义 vs 广义/持牌/自然人专项/企业间）
2. 主体、职业放贷外观与企业出借人经常性
3. 成立分岔：679 仅双方自然人；混主体或企业侧诺成
4. 本金、到账与砍头息
5. 利率 LPR 四倍、息费总和、利息约定不明分岔
6. 用途、资金来源与无效红旗
7. 加速到期与格式痕迹；担保和配偶只审引用闭环
8. 按框架六步出修改句

必须有修改句。禁止只打红黄绿。每个风险回链文本位置。禁止套用买卖验收、定金百分之二十、P2P 平台主路径、自然人互借实践性主路径或银行受托支付主路径。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；条件未谈妥仍要出可签署终稿；用户坚持伪造倒签、把职业放贷或平台自融改成可履行、把转贷或违法用途改成可履行、保证有效、按 24%/36% 出现行上限、把整类写成实践或整类写成无息。
- `字段停止`：法域、主体组合、LPR 时点、资金来源、职业放贷外观未核验；本金或到账关键事实缺失。
- `目标停止`：主目标已变为待签评改、履约交底、催收文书或利息精算终局。

生存级金额或个人无限连带且用户拒绝升级：停止“可以签署”建议。
