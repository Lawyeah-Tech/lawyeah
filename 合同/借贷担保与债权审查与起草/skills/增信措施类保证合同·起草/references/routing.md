# 边界与路由

本技能只审查 **保证合同 / 增信措施类保证合同** 的待签文本。中文展示名是「审查增信措施类保证合同（保证合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 已特定单笔主债；文本就是一般保证；先诉抗辩或“不能履行”为主线；无差额补足／流动性支持／回购产品结构 | `一般保证合同·审查` |
| 已特定单笔主债；明确连带责任保证；债权人可直接请求；无增信产品结构 | `连带责任保证合同·审查` |
| 最高债权额 + 一定期间连续发生 + 债权确定期间 | `最高额保证合同·审查` |
| 独立保函；见索即付；URDG／ISP98；金融机构相符交单付款 | `独立保函·审查`；专业版未装则 `unavailable`，提示，不得用本技能硬套 |
| 安慰函、维好协议、意愿书；仅知晓、关注、督促、尽合理努力、视情况支持 | `安慰函·审查`；专业版未装则 `unavailable` |
| 同一文本是单笔借款主文加保证从债 | `保证借款合同·审查` |
| 主文件是金融机构借款、民间借贷等，增信只是附件名称混用且无差额／流动性／回购结构 | 对应借款场景原子；本任务不审利率或放款条件整案 |
| 有完整待签文本要评改 | `增信措施类保证合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 留本任务起草并自审 |
| 已签未争、只问补足通知、划款日或核算窗口 | 本套导航的履约步骤 |
| 已催告、索赔、立案、开庭，或主问保证责任是否消灭、能否免责、怎么起诉、共同被告 | `或` 或 `或` |
| 企业融资整包、对赌或结构化增信要放行意见 | `企业融资整包对赌或结构化增信要放行意见`；本任务不放行融资结构 |
| 配偶是否共同债务 | 只标缺口；整案 `配偶是否共同债务` |
| 追股东或法人格 | `追股东或法人格` |
| C 端大众快检 | 只分流，不回改 |

增信正文里夹带一小段典型保证或回购买卖：专章交接对应原子或分条改写；增信定性条款可继续审。用户坚持本技能把安慰函、独立保函、单笔保证或最高额整案改完：`目标停止`。

普通增信里夹带一句“本合同独立于基础交易”：不整案转独立保函；按从属性删除或改正该句后继续审。用户坚持改成见索即付独立保函：`目标停止`，转 `独立保函·审查` 或标明 `unavailable`。

标题写“差额补足／流动性支持”、条款未选保证或加入：留在本任务，按解释第三十六条四层落表并出显化句，不得按连带放行，也不得按“没有保证期间”放行。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
