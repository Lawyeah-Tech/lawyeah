# 边界与路由

本技能只审查 **借款合同 / 企业间借款合同** 的待签文本。中文展示名是「审查企业间借款合同（借款合同）」。主线是非持牌企业之间为生产经营拆借。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 出借人是商业银行等持牌放贷机构或其分支机构 | `金融机构借款合同·审查`。不得用本技能的民间四倍或第 10 条审银行稿 |
| 双方均为自然人 | `自然人之间的借款合同·审查`。不得用本技能的诺成规则否定自然人实践性 |
| 一方为自然人（股东个人出借、单位向职工集资、企业借给个人） | `广义民间借款合同·审查` 或 `狭义民间借款合同·审查`。第 11 条内部集资不留本技能 |
| 同一文本以保证条款 + 保证人签章为主结构 | `保证借款合同·审查`。本约只审对保证的引用是否闭环 |
| 抵押财产、登记、流押主导放行 | `抵押借款合同·审查` |
| 质押、权利凭证移交或股权出质主导 | `质押借款合同·审查` |
| 买卖过户、回购或不清算归债权人所有作为还款担保的主结构 | `让与担保型借款合同·审查`。不得改成可过户履行 |
| 真实合伙、共负盈亏、无法人执照的个人合伙 | `真实合伙共负盈亏无法人执照的个人合伙`。保底固定回报不走合伙 |
| 有完整待签文本要评改 | `企业间借款合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 留本任务起草并自审 |
| 已签未争、只问放款或还本付息节点 | 本套导航的履约步骤 |
| 已成争、催告、立案或清收 | `或` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

企业借款正文里夹带一小段保证或抵押：专条交接对应担保原子；本金、用途、资金来源、利率、决议条款可继续审。用户坚持本技能把银行贷款、自然人借款、保证/抵押主文件或清收整案改完：`目标停止`。

不得把本约改写成委托贷款通道、银行授信或可履行的无证放贷业务。委托贷款只可作为用户另行选择的合规改道点名，不在本任务出整稿。
