# 企业间借款合同·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、1996 年企业互借无效口径、2015 年 24%/36%、银行利率旧四倍当作现行规则。民法典第 679 条仅适用于自然人之间的借款合同，不得写成企业合同成立规则。商业银行法只作负向：证明出借人不是银行，不得单独写成企业互借民事无效。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **借款合同 / 企业间借款合同**，输出可编辑草稿、未决项、自审风险表与自审后修改句。有完整待签文本要评改时，转 `企业间借款合同·审查`。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。中文名必须是「审查企业间借款合同（借款合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查或起草；待签文本评改；履约交底；争议文书或清收策略；有效性保证；利息精算终局数字；把无证放贷改成可履行放贷业务；把转贷改成可履行通道；把流质或过户担保改成可履行物权转移。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **企业间民间借贷 ≠ 银行贷款 ≠ 自然人借款**。双方须为非金融企业或非法人组织，出借人未持贷款牌照。出借人持牌 → 负触发 `金融机构借款合同·审查`。一方或双方为自然人 → 负触发 `广义民间借款合同·审查` / `狭义民间借款合同·审查` / `自然人之间的借款合同·审查`。未获许可以放贷为业、向社会不特定对象提供借款：告知无效风险，不改成可履行放贷业务。
2. **生产经营需要**。用途须写生产经营。出借人事先知道或应当知道借款用于违法犯罪仍提供：停止，不改成可履行。
3. **资金来源红线**。套取金融机构贷款转贷，或以向其他营利法人借贷、向本单位职工集资、向公众非法吸收存款等方式取得资金转贷：告知无效风险，不改成可履行转贷结构。
4. **利率**。合同成立时一年期贷款市场报价利率四倍。禁止 24%、36%、银行利率旧四倍。持牌监管利率、受托支付、贷款管理办法不得套进来。
5. **670 砍头息**。利息、咨询费、保证金预先从本金扣除的，以实际到账为本金和计息基数。
6. **内部决议**。大额拆出或拆入按章程由董事会或股东会决议。未见决议字段停止，不写“可以盖章”。上市公司对外财务资助另核审议与披露。
7. **名为投资/买卖实为借贷**。保底固定回报、不承担经营风险：切开按本类型审，删除投资外壳。让与担保过户或到期归出借人所有：切开或停笔清算，不写成可履行流质。

禁止表述：企业互借一律无效；未放款则合同未成立；24%/36%/旧四倍为本类型上限；银行 LPR 加减点是本类型法定上限；砍头息后仍按面额计息；无决议可以盖章；职业放贷改到能签；转贷改到能签。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿；尚未签署，尚未成争，双方均为非金融企业或非法人组织，核心给付是为生产、经营需要提供资金、到期返还本金（可约定利息或资金占用费）；用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 出借人是商业银行、消费金融、信托、财务公司、小额贷款公司等持牌放贷机构或其分支机构 → `金融机构借款合同·审查`；
- 双方均为自然人 → `自然人之间的借款合同·审查`；
- 一方为自然人（含单位向职工集资、股东个人出借）→ `广义民间借款合同·审查` / `狭义民间借款合同·审查`；
- 同一文本以保证条款和保证人签章为主结构 → `保证借款合同·审查`；
- 抵押财产、登记、流押主导放行 → `抵押借款合同·审查`；
- 质押或权利凭证移交主导 → `质押借款合同·审查`；
- 买卖过户、回购或不清算归债权人所有作为还款担保的主结构 → `让与担保型借款合同·审查`；
- 文本明显是买卖、租赁且无企业拆借核心给付 → 本套导航的类型切开步骤 或对应场景原子；
- 有完整待签文本要评改 → `企业间借款合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问放款、还本付息节点 → 本套导航的履约步骤；
- 已成争（催告、解除、索赔、诉讼仲裁、清收）→ 合同争议或对应专项领域。

职业放贷、套取信贷转贷、转手牟利转贷、知情违法用途：只出告知，不改写成可履行放贷或转贷结构。

## 建立审查坐标

确认：使用者与授权；单方立场（出借企业 / 借款企业择一）；相对方；全文及附件版本；双方是否均为非金融企业；出借人是否持牌或以放贷为业；本金、到账、利率、用途、期限；资金来源陈述；章程与决议；是否关联或上市公司；不可接受事项；法域与拟签署日。缺立场或本类型条件未谈妥则不启动起草。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的本金、利率、期限、账户用 `【待填】`，不编造。

- `search_law`（法律结论 required）：核验第 667–668 条书面诺成、第 679 条仅自然人、第 670 条砍头息、第 671/673 条放款与用途、第 680 条与法释〔2020〕17 号第 1、10、11、13、25、29 条，以及公司法决议/关联交易。商业银行法第 11 条只作负向。
- `search_practiced`（optional）：补转贷、职业放贷、决议争点。返回“企业互借一律无效”“未放款则未成立”“24%/36%/旧四倍”“银行利率适用于企业拆借”时记噪声。
- `search_template`（optional）：只借栏目结构。范本写委托贷款通道、实控人夫妇连带、签字即成立，不得当本约建议句。

## 起草模式

本原子只承担本类型起草。待签评改转 `企业间借款合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。本类型硬闸改成正文必写、附件必附或禁止出现。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 双方为非金融企业或非法人组织，出借人未持贷款牌照。
- 用途写生产经营需要。
- 利率不超过合同成立时一年期 LPR 四倍。
- 本金以实际到账为准；预扣利息、咨询费、保证金不计入本金。
- 大额拆出或拆入按章程由董事会或股东会决议。
- 保底固定回报、不承担经营风险：删除投资外壳，按借贷落稿。

### 附件必附

- 大额拆出或拆入的董事会或股东会决议。
- 上市公司对外财务资助的审议与披露材料（适用时）。
- 无对应事实不编造附件，缺项写入未决项。

### 禁止出现

- 企业互借一律无效；未放款则合同未成立。
- 24%／36%／旧四倍为本类型上限；银行 LPR 加减点是本类型法定上限。
- 砍头息后仍按面额计息；无决议可以盖章。
- 未获许可以放贷为业、向社会不特定对象提供借款改成可履行放贷业务。
- 套取金融机构贷款转贷，或以向其他营利法人借贷、向本单位职工集资、向公众非法吸收存款等方式取得资金转贷，改成可履行。
- 事先知道或应当知道用于违法犯罪仍出借并改成可履行。
- 让与担保过户或到期归出借人所有写成可履行流质。
- 持牌监管利率、受托支付、贷款管理办法套进来。

0. 签署状态与成果分流
1. 类型锁死：双方非金融企业 + 生产经营拆借
2. 主体、职业放贷负向、内部决议与上市披露
3. 书面诺成成立：679 仅自然人；未放款走 671
4. 生产经营用途与知情违法停笔
5. 资金来源红线与 670 到账本金
6. 利率与费用总和：成立时一年期 LPR 四倍
7. 配套：673 用途监管、担保只审引用、格式条款
8. 按框架六步出修改句

必须有修改句。禁止只打红黄绿。每个风险回链文本位置。禁止套用买卖验收、定金百分之二十、银行受托支付或自然人 679 实践性主路径。禁止把本技能写成金融机构借款或自然人借款换标题。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；条件未谈妥仍要出可签署终稿；用户坚持伪造倒签或假决议、把职业放贷包装成普通拆借、把转贷或知情违法用途改成可履行、把流质过户改成可履行物权转移、保证有效、按 24%/36%/旧四倍或银行监管利率出本类型合法上限。
- `字段停止`：法域、LPR 时点、资金是否信贷资金、是否以放贷为业、章程决议机关、上市披露未核验；本金或到账关键事实缺失。
- `目标停止`：主目标已变为待签评改、履约交底、清收文书、利息精算终局，或把本合同改成银行贷款/委托贷款整案。

生存级金额或个人无限连带且用户拒绝升级：停止“可以签署”建议。
