# 边界与路由

本技能只审查 **借款合同 / 质押借款合同**。

必须同时读出资金借贷合意，以及以动产移交占有或权利凭证交付/出质登记设定质权的主结构。标题叫“质押借款合同”但没有出质财产、或质押已被买卖过户/回购替代的，不得留在本技能做实体结论。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或标题质押借款、核心给付明显不是资金借贷加质押 | 本套导航的类型切开步骤 |
| 买卖、过户、回购、让与担保；到期不还则财产或股权归债权人且不清算；财产或股权先过户再借款 | `让与担保型借款合同·审查`；专业版未收录该 P1 时输出 `unavailable`，不得硬套本技能改成可过户结构 |
| 无出质财产、无质押条款，只有保证人、保证方式、保证期间 | `保证借款合同·审查` |
| 不转移占有，以不动产、在建工程或动产抵押登记为主结构 | `抵押借款合同·审查` |
| 双方自然人或一方企业的普通借款，无质押 | `自然人之间的借款合同·审查` 或 `狭义民间借款合同·审查` |
| 企业互借且质押只是附带一句、审查重点是拆借效力 | 可提示 `企业间借款合同·审查`；质权设立与从属仍是放行关键则留本技能 |
| 持牌机构贷款文本，审查重点是监管利率与放款条件 | 可提示 `金融机构借款合同·审查`；质权设立仍是放行关键则留本技能 |
| 有完整待签文本要评改 | `质押借款合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 留本任务起草并自审 |
| 已签未争、问交付进度、出质登记、放款日、返还质物 | 本套导航的履约步骤 |
| 已成争 | 合同争议领域或对应专项；不写实现质权申请书、起诉状 |
| 用户只要利息或优先受偿额的终局数字 | 测算技能或人工精算；本技能只审条款 |
| C 端大众快检 | 只分流，不回改 |

附带保证、配偶签字栏时：本技能只审对本约放行的影响（物保与人保并存时不得默认先物后人，也不得把出质人写成保证人），不展开保证合同专项整案。深度保证文本转 `保证借款合同·审查`。

同一文本既写“抵押”又写“质押”：按核心公示方式切开。财产不转移占有、走不动产或动产抵押登记 → `抵押借款合同·审查`。财产须移交占有或办理出质登记 → 留本技能。两可且无法判断：负触发引擎，不灌两套知识。

职业放贷、转贷、违法用途、禁止转让财产包装、流质改过户、出质人继续占有却写成已交付：停笔告知，不改写成可履行文本。
