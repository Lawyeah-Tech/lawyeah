# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证合同有效、质权已经设立、必然优先受偿或对方接受；编造未给出的本金、规格、凭证号、利率、期限；把已失效《合同法》《担保法》《物权法》及其解释写入结论；把银行利率旧四倍、年利率 24% 或 36% 写成现行保护上限；把质押合同写成自交付或登记之日起才生效；把未交付或未登记写成已取得优先受偿权；把流质写成可以过户；把出质人写成保证人；把出质人继续占有写成已经交付；把抵押或保证文本留在本技能改成可履行质押；把让与担保买卖留在本技能改成可履行买卖。

## 1. 触发、单方立场与成果状态

立场（出借人/质权人、借款人、第三人出质人、拟签字共有人）、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明是否同时存在质押主结构，以及是动产出质还是哪一类权利出质。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》《担保法》《物权法》及其解释、1991 年借贷意见、2015 年 24%/36% 条文或已失效《应收账款质押登记办法（2019）》时记噪声，不得写入 `L#`。流质、从属、交付/登记与合同效力分离、担保范围、保管义务、利率上限无 `verified-result` 时，对应法律结论字段停止。

## 3. 类型与加载路径

父级 `借款合同`，子级 `质押借款合同`。定性理由必须同时满足：资金借贷；质押为主结构。易混切开：抵押（不转移占有）、纯保证、无质押自然人/民间借款、让与担保/买卖过户担保、金融机构监管条款主审、企业拆借。

加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读其他类型。职业放贷、转贷、禁止转让财产包装、流质过户或假交付写停笔告知，不填可履行结构。

## 4. 主体、授权、资质与文本版本

主体表：出借人/质权人、借款人、出质人、共有人、保证人（如有）、指定收款人。自然人写姓名与证件号是否与文本一致；法人写名称与统一社会信用代码。出质人与借款人是否同一人必须写明。

版本表：正文、质押财产清单、权属证明、权利凭证、内部决议、账户页、聊天确认。冲突并列，不选对用户有利的一版。口头“已经交给对方了”“工商已经能登”不得写成已交付或已登记。

## 5. 主债与质押给付闭环

分列并回链文本位置：

- 主债权：合同名称与编号、本金大小写、币种、履行期限。
- 从属：是否写明质押合同从属于该主债；有无独立性约款。
- 质押财产：名称、规格或权利内容、数量、权属、凭证号、是否禁止转让/出质。
- 设立公示：动产谁在几日内交付、交付地点、占有人是否为质权人或其委托的监管人；权利凭证是否交付并记载质押；股权/知识产权/应收账款的登记机关、申请义务人与期限。
- 合同效力与物权：是否把交付或登记写成合同生效条件。
- 担保范围：合同列举是否覆盖法定项目（含保管费用）。
- 保管与返还：质权人保管义务、禁止擅自使用、债务清偿后返还与解押。
- 实现：折价/拍卖/变卖优先受偿，还是流质过户。
- 利息与费用：有无书面利率；是否民间借贷路径；费用是否并入上限审查。
- 放款条件：未交付或未登记是否仍允许放款。

缺口标 `G#`，不补商业数字、凭证号或已交付/已登记事实。批准、交付、登记写成条件或双方义务期限，不写成已经完成。

## 6. 格式条款、强制规范与本类型效力红旗

银行或职业放贷人预先拟定且未协商的，按格式条款审查提示说明。自然人偶发互借通常不是格式条款。

强制规范与效力红旗只在核验后落法律结论：流质；禁止转让财产出质；独立性约款；套取金融机构贷款转贷；未取得放贷资格而向不特定对象放贷；出借人事先知道或应当知道用于违法犯罪仍提供借款；公司对外出质未审查决议。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔/转出口径。禁止输出无修改句的色块表。

本类型至少检查：流质或放弃清算；质押财产未特定；禁止出质财产；把交付/登记写成合同生效或把未交付/未登记写成已设立；出质人继续占有或占有改定；权利出质未写登记机关；担保范围空白；独立性约款；利率/费用未核验或疑似超过保护上限；共有人未签；公司决议未附；质权人保管义务缺失。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字、凭证号用 `【待填】`，不编造。禁止只给原则、不给句子。框架与硬闸冲突时按硬闸出句。

建议句必须覆盖本类型硬闸：删除或改写流质；财产特定化与交付/登记义务；合同生效与质权设立分列；禁止占有改定；担保范围列举；从属主债、删除独立性约款；补质权人保管义务；利率上限待核表述。

## 9. 谈判与签署提醒

谈判顺序：先红线（流质过户、禁止出质财产、伪造交付/登记/决议、违法放贷、出质人继续占有却写成已交付），再必须改（特定化、交付或登记义务、从属、担保范围、保管义务、利率核验），最后可优化。

签署提醒：出质人与共有人本人签；公司决议作附件；权属证书或权利凭证原件核对；约定先交付或先登记后放款；日期真实；附件含质押财产清单、权属证明、决议。不指导倒签、补假交付、补假登记或假同意。

出借人立场可建议共有人签署和完成交付/登记作为增信，但必须同时写明：未交付或未登记不得当成已有优先受偿权。出质人或借款人立场必须提示：签字、移交占有、配合登记和扩大担保范围会扩张责任财产风险。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本任务交付可编辑草稿、未决项、自审风险表与自审后修改句。草稿必须覆盖本类型起草必写、附件必附与禁止出现。有完整待签文本要评改时转配对审查原子。不是履约交底、实现质权文书、利息精算终局或效力保证。
