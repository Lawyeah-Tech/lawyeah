# **第一步：合同类型（法律性质）分析**

* **法律定性**：狭义民间借款合同是出借人（一般企业或自然人）向借款人（一般企业或自然人）提供资金，借款人到期归还本金并支付利息（或无息）的合同。其本质是资金的临时性融通，不具有经营性。
* **易混淆辨析**：
    1.  **名为投资、买卖、合伙，实为借贷**：实务中常通过股权回购、商品“假买卖”等形式掩盖借贷目的。法院审查时会适用“穿透原则”，考察当事人有无真实的投资、买卖或合伙合意，以及是否存在“固定回报”和“保底条款”，如存在，大概率认定为借贷关系。
    2.  **与准金融业务的区别**：本类型排除小额贷款公司、典当行等持牌机构的放贷行为，核心区别在于出借人是否具有“放贷”的经营资质和营利性。
* **效力认定（高风险）**：
    1.  **合同无效的根本风险**：
        * **职业放贷**：一般企业或个人，如在一定期限内（如两年）向不特定多人（如超过10人）以营利为目的（利率明显偏高）出借资金，可能被认定为“职业放贷”行为，合同无效。
        * **非法资金来源**：出借人使用非法集资、非法吸收公众存款或套取金融机构信贷资金等方式获得的钱款对外放贷，合同无效。
        * **明知非法用途**：出借人明知借款人将资金用于赌博、毒品、走私等非法活动，合同无效。
        * **“套路贷”**：以非法占有为目的，通过“虚增债务”、“签订阴阳合同”、“肆意认定违约”等方式实施的借贷，合同无效，且涉嫌刑事犯罪。
    2.  **利率与利息的效力**：
        * **利率上限**：双方约定的利率（包括逾期利息、违约金和其他费用）**总计不得超过合同成立时一年期贷款市场报价利率（LPR）的四倍**。超过部分无效，借款人有权请求返还已支付的超过部分。
        * **预扣利息（砍头息）**：出借人预先在本金中扣除利息的，法院认定本金时应按照**借款人实际收到的数额**计算。
        * **复利（利滚利）**：约定将利息计入本金计算复利的，必须有明确书面约定，且**总计利率不得超过4倍LPR上限**。
* **适用场景**：自然人之间因生活消费、购房、装修等临时周转；一般企业之间为解决短期生产经营困难的临时资金拆借。

# **第二步：合同主体（交易对手）分析**

* **主体适格性**：
    1.  **一般要求**：出借人与借款人均应为具有完全民事行为能力的自然人或依法登记存续的法人、非法人组织（如合伙企业）。
    2.  **特殊限制（出借人）**：**一般企业作为出借人是核心风险点**。企业不得以放贷为主营业务或经常性业务，否则可能被认定为“职业放贷”导致合同无效。
* **资质许可**：本类型合同的主体**均不应具备**金融放贷资质。如出借人具备相关金融或准金融资质，则不属于本类型合同。
* **高频风险**：
    1.  **签约能力**：借款人如为限制民事行为能力人（如未成年人），合同效力待定。
    2.  **企业间借贷的效力**：企业为生产、经营需要，临时拆借资金，原则上有效，但不得违反“职业放贷”和“非法资金来源”的红线。
* **关联主体（重要）**：
    1.  **风险识别**：**借款人的配偶**。
    2.  **应对措施**：
        * 为防止借款被认定为借款人个人债务，出借人应尽力明确该借款用于“夫妻共同生活、共同生产经营”。
        * **最佳风控**：要求借款人的**配偶作为共同借款人或保证人**在合同上签字，或单独出具《共同还款承诺函》或《配偶同意函》。

# **第三步：合同标的（交易对象）分析**

* **标的适格性**：标的物为**货币**。
* **权属风险（高风险）**：
    1.  **出借人资金来源**：必须确保资金来源合法。**严禁使用非法集资、套取银行贷款等违法所得进行出借**。
    2.  **借款人资金用途**：必须约定合法用途（如生产经营、生活周转）。
* **特殊标的**：无。
* **风险转移**：借款合同多为**实践合同**（尤其是自然人之间），自**出借人提供借款时**（即资金交付时）生效。因此，出借人必须保留**银行转账凭证、付款回单**等证明资金已实际交付。

# **第四步：合同程序（交易步骤）分析**

* **法定前置程序**：
    1.  **合同生效（重要）**：
        * **自然人之间**：多认定为**实践合同**，除签字外，还需**交付款项**后合同才生效。
        * **企业之间**：多认定为**诺成合同**，双方签字盖章即成立并生效（除非另有约定）。
    2.  **登记/备案**：借款合同本身无需登记备案。但如果涉及**抵押担保**（见第五步），则不动产抵押、车辆抵押、股权质押等必须办理**法定登记**，否则抵押权/质押权不设立或不得对抗第三人。
* **内部决策程序**：
    1.  **公司借款**：借款人（或出借人）为公司的，应审查其《公司章程》关于借款、对外担保的决策权限规定，并要求其提供**股东（大）会决议或董事会决议**。
    2.  **关联担保**：如公司为股东或实际控制人借款提供担保，必须经**股东（大）会决议**，且关联股东应回避表决。
* **附加程序**：
    1.  **公证（重要风控）**：为实现快速执行、规避诉讼，强烈建议出借人与借款人共同办理**具有强制执行效力的债权文书公证**。一旦借款人违约，出借人可凭《执行证书》直接向法院申请强制执行。

# **第五步：交易结构设计（风险规避方案）**

* **担保措施**：
    1.  **典型担保**：
        * **保证**：要求借款人的配偶、股东、实际控制人或有实力的第三方提供**连带责任保证**。
        * **抵押**：要求借款人提供其（或第三方）所有的**不动产、车辆**等财产进行抵押，并**必须办理抵押登记**。
        * **质押**：要求借款人提供其（或第三方）所有的**股权、基金份额、存单**等权利进行质押，并**必须办理质押登记或交付**。
    2.  **非典型担保（高风险）**：
        * **所有权保留/让与担保**：不建议在民间借贷中采用。
        * **“假买卖”**：签订“假”的《房屋买卖合同》作为担保，在司法实践中可能被认定为“让与担保”，也可能因“通谋虚伪表示”被认定无效。
* **结构选择**：
    1.  **“名股实债”**：出借人以“股权投资”名义注入资金，但约定“固定分红、到期回购”，实为借贷。此结构复杂，且在法律上存在被认定为无效投资或有效借贷的不确定性。
    2.  **“名卖实贷”**：以“房屋买卖”并设定“回购期”的方式进行担保，风险极高，不建议使用。
* **风险隔离**：要求借款人设立**保证金账户**或提供**账户监管**，确保资金用途和回款来源。
* **文本形态设计**：
    1.  **简单交易**：使用规范的**《借条》**，必须载明出借人、借款人、借款金额（大小写）、利率、还款期限、双方签字日期。
    2.  **复杂交易**：必须使用“**主合同 + 担保合同**”的成套合同结构。
        * **《借款合同》**（主合同）：明确约定本金、利率（含复利）、期限、资金用途、违约责任（明确约定律师费、公证费、保全费等由借款人承担）。
        * **《保证合同》/《抵押合同》/《质押合同》**（从合同）：与担保人/抵押人/出质人另行签订，并严格履行登记等法定程序。
    3.  **利息转本金**：如借款到期，借款人无法支付利息，双方可**另行签订补充协议**，将已到期且不超过4倍LPR的利息转为本金，重新计算利息。

# **第六步：宏观风险预警与尽调指引**

* **高频争议点**：
    1.  **本金数额争议**：集中在**“砍头息”**（预扣利息）的认定，法院只认可实际支付的金额为本金。
    2.  **利息费率争议**：双方约定的利息、罚息、违约金、服务费等**所有费用总和是否超过4倍LPR**。
    3.  **借贷事实争议**：仅有借条或转账凭证，一方抗辩。**“借条+转账凭证”**是认定借贷事实的强力证据链。
    4.  **夫妻共同债务争议**：借款是否用于夫妻共同生活，配偶是否知情并同意。
* **尽职调查清单**（出借人视角）：
    1.  **主体调查**：核实借款人（及担保人）身份信息、婚姻状况、征信报告、涉诉情况。
    2.  **资质调查**：如借款人为企业，核查其营业执照、公司章程、内部决议文件。
    3.  **用途调查**：核实借款真实用途，确保其合法性，避免卷入非法活动。
    4.  **财产调查**：核实借款人（及担保人）名下的财产线索，重点关注不动产、车辆、股权等，评估其偿债能力和可供担保的财产。
* **宏观风险预警**：
    1.  **“职业放贷”红线**：企业或个人绝对禁止从事经常性、营利性的放贷业务。
    2.  **“非法集资”红线**：出借人的资金来源必须合法，严禁通过向公众承诺高额回报的方式筹集资金后再转贷。
    3.  **“4倍LPR”红线**：任何形式的利息和费用总和不得超过该上限，否则不受法律保护。
    4.  **“证据链”缺失风险**：必须同时保留**书面合同（借条）**和**付款凭证（转账记录）**，二者缺一不可。
