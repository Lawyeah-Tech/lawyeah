# 审查方法（锁定 借款合同 / 狭义民间借款合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止套用买卖合同的标的验收、定金比例或挂靠改写节点。禁止把本技能写成广义民间借款换标题，禁止灌入 P2P 备案、资金存管、平台额度或小贷牌照栏目。禁止把本技能写成自然人互借换标题，禁止把 679 实践性或共债写成全类型主路径。

定性校验：出借人是一般企业或自然人，资金往来是临时性、非经营性融通，且核心给付是货币借贷，才继续；明显他类则负触发，不填十节实体结论。

本文件是可执行判断节点，不是栏目说明书。每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受，或唯一必得本息。

`search_law` 返回已失效《合同法》借款章、《借款合同条例》、1991 年《关于人民法院审理借贷案件的若干意见》、2015 年民间借贷司法解释中 24%/36% 条文、已被删除的旧第 10 条成立规则时记为噪声，不得写入 `L#`。`search_practiced` 仍写“民间借款一律实践性”“24%/36% 仍是上限”“P2P 额度适用于点对点民间合同”的，同样记噪声。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

示范文本只参考结构。写“自双方签字盖章之日起生效”的范本，不得覆盖双方自然人的 679 分岔，也不得当利率规则。

知识库口径冲突以本方法为准，不回写知识正文：

- `框架.md` 尾部把民间借款一律写成实践生效：纠正为仅双方自然人才适用第 679 条；一方或双方为企业时原则上诺成。
- `基本面.md` 把“两年向超过 10 人”写成职业放贷识别标准：纠正为法释〔2020〕17 号第 13 条第 3 项三要件（未取得放贷资格 + 以营利为目的 + 向社会不特定对象提供借款）。两年/10 人只是部分地方法院探索线索，不得写成全国统一阈值。
- 不得把 24%、36% 或银行利率旧四倍写成现行上限。本类型正用法释第 25、28、29 条：合同成立时一年期 LPR 四倍，息费总计同限。
- 空白保证条款不得写成已是连带保证。未约定保证方式时不得推定连带。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用出借人属性、有无平台或牌照、资金往来是否临时非经营、核心给付和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须同时满足才正触发：

1. 出借人是一般企业或自然人，不是持牌放贷机构，也不是小贷、典当、网络小贷或网贷信息中介。
2. 核心给付是点对点提供货币，借款人到期返还本金并支付利息或无息。
3. 资金往来外观是临时性融通，而不是以放贷为业或平台撮合。

必须切开，禁止两可时灌入两套知识：

| 信号 | 归入 | 本技能动作 |
| --- | --- | --- |
| 自然人出借给企业，或企业出借给自然人，临时周转，无平台无牌照 | 本类型 | 加载本目录双文件 |
| 用户明确以狭义民间借款合同提交，主体组合未闭合，但已排除平台与牌照 | 本类型 | 进入后按主体组合分岔；主体未闭合则字段停止 |
| P2P、资金存管、小贷、典当、网络小贷、电子平台额度 | `广义民间借款合同·审查` | 负触发；不审备案、存管或平台限额 |
| 双方自然人，借条或生活互借主导 | `自然人之间的借款合同·审查` | 负触发；不把共债写成主路径 |
| 双方非金融企业，经营性拆借或资金占用费主导 | `企业间借款合同·审查` | 负触发；不审发票进项或委托贷款通道 |
| 商业银行、消费金融、信托等持牌放贷 | `金融机构借款合同·审查` | 负触发；不把四倍写成银行上限 |
| 抵押财产、登记、流押主导放行 | `抵押借款合同·审查` | 负触发；本约仅有担保引用句则留本技能只审闭环 |
| 保证条款构成主标题或主导文本 | `保证借款合同·审查` | 负触发 |
| 质押物或权利凭证移交主导 | `质押借款合同·审查` | 负触发 |
| 买卖/过户/回购作为还款担保 | `让与担保型借款合同·审查` | 负触发；不改成可过户 |
| 固定回报投资/合伙且无真实共担风险 | 引擎或对应原子 | 负触发；可点名“名股实债”外观，不按投资稿审 |
| 移转标的物所有权换价款 | 买卖类场景原子 | 负触发 |

### 1.2 加载协议（硬闸）

本技能已锁定 **借款合同 / 狭义民间借款合同**。只打开 `references/基本面.md` 与 `框架.md`。禁止读其他类型目录，禁止为对照再开广义或自然人专项双文件。

### 1.3 职业放贷、转贷与违法结构停笔

加载后或定性中出现：未取得放贷资格却以格式文本向不特定对象放贷、把本约改成可经营的放贷业务、套取信贷资金转贷、以集资款或向其他营利法人借贷的资金转贷、明知赌博吸毒走私仍要求改成可履行、虚增本金或阴阳合同、指导倒签放款。

动作：

1. 交付告知：该结构可能符合法释第 13 条无效情形或涉嫌刑事，不得改写成可履行放贷文本。
2. 不写假自有资金、假用途、假“偶发拆借”包装。
3. 风险表只保留识别依据和转出/改道提示。
4. 用户坚持“改到能继续对外放贷、能转贷、能进赌场”：整体停止。

合规改道（停止经常性放贷、改为真实临时拆借、停止转贷、改合法用途）只点名，不在本任务起草。

## 节点 2　主体、职业放贷外观与签约能力

1. 建主体表：出借人、借款人、指定收款账户名、引用中的担保人或配偶。名称不一致不自动合并。
2. **牌照与平台反向闸。** 材料出现金融许可证、小贷牌照、典当、网络小贷或平台存管：回到节点 1 负触发。未出示不等于已经适格，只说明“目前未见持牌或平台外观”。
3. **企业出借人是核心风险点。** 摘录：是否使用统一格式合同、利率是否明显偏高、是否自称资金业务或过桥、用户是否陈述近期多笔对外出借。外观满足经常性、营利性、对象不特定时，标红线并走节点 1.3，**不得**写成“已经构成职业放贷”的终局认定，也不得改成可履行放贷条款。
4. 自然人出借人：完全民事行为能力未闭合则字段停止。限制民事行为能力人作为借款人：效力待定，不写成可以盖章。
5. 企业借款人或出借人：名称、统一社会信用代码、存续是否被文本提及。章程对借款或对外提供资金的决议未附：字段停止，修改句要求作为附件；不得写成“公章即充分授权”。
6. 口头“我们老板同意了”“配偶知道”不得写成已授权或已共债。

不足：字段停止，列出待补材料，不补主体、不补“非职业放贷”结论。

## 节点 3　成立分岔（禁止整类实践或整类诺成）

先确定主体组合，再选成立规则。禁止引用框架尾部“民间借款一律实践生效”覆盖全类型。

| 主体组合 | 成立默认 | 本任务动作 |
| --- | --- | --- |
| 双方均为自然人 | 第 679 条；法释第 9 条列明现金收到、转账到账等视为成立的时点 | 若文本写“签字即成立、未放款也可请求放款”：必须改。成立与交付分列；未交付则请求放款基础不足 |
| 一方或双方为企业、非法人组织 | 原则上诺成：承诺生效时成立（民法典第 483 条路径），不以交付为成立要件 | 若文本写“未放款视为未成立、出借人无需任何责任”：必须改。未按约放款走继续履行或赔偿，不写成法定未成立 |
| 主体组合未闭合 | 依据不足 | 成立法律结论字段停止；修改句用括号列出两种写法，待主体补齐后再删一种 |

核验后可引用的判断点（须 `search_law` 写入 `L#` 再落法律结论）：

- 自然人之间的借款合同，自贷款人提供借款时成立。
- 自然人之间以转账支付的，自资金到达借款人账户时可以视为成立。
- 借款合同应当采用书面形式，但是自然人之间借款另有约定的除外。一方为企业时，书面形式视为必须改的缺口，不得用“口头也行”放行。
- 法释〔2020〕6 号旧第 10 条（非自然人自成立时生效）已被二次修正删除，不得写入 `L#`。非自然人侧改用民法典合同成立规则，不把已删条文当现行依据。

| 文本写法 | 本任务动作 |
| --- | --- |
| 混主体合同写“本合同自双方签字盖章之日起成立并生效” | 可接受为诺成默认。另有放款先决的，拆成：合同成立；放款义务在条件成就后发生 |
| 混主体合同写“未实际提供借款则合同不成立” | 必须改。除非当事人明确另有约定且已提示；即使另有约定，也不得写成第 679 条的法定效果 |
| 双方自然人合同写“签字后借款人有权请求放款” | 必须改。补交付成立，并写明未交付时不得请求强制放款 |
| 用户要求把混主体合同按 679 写成未放款即未成立，以逃避放款义务 | 整体停止该结论 |
| 用户要求把双方自然人合同写成未放款也可强制放款 | 整体停止该结论 |

内部决议、配偶同意写成生效条件或放款先决，不写成已经完成。用户要求倒签签约日或放款日：整体停止。

## 节点 4　本金、到账与砍头息

1. 本金必须同时有阿拉伯数字与大写，并写明币种。不一致并列，修改句写明以大写或借据孰为准，不擅自改数。
2. **砍头息硬闸。** 利息不得预先在本金中扣除；预先扣除的，按实际借款数额返还并计息。法释第 26 条：债权凭证载明金额一般认定为本金，预先扣除利息的，以实际出借金额认定为本金。
3. 下列写法按预扣或变相预扣处理，本金改到实际出借额：

   - 合同写 70 万，条款写“先行扣除利息/咨询费/通道费后支付”；
   - 面额与拟付说明、收款收据不一致；
   - “当日支付首月利息”且与放款同一时点、不独立结算。

4. 修改句固定锁到账：`本合同项下借款本金以出借人实际划付并到达借款人【待填】账户的金额为准；预先扣除的利息、咨询费、通道费不计入本金，不计收该部分利息。出借人应通过银行转账支付，转账备注载明“借款”。`
5. 现金交付：出借人侧必须改成转账，或补“收款收据 + 金额大小写 + 现金字样 + 日期”。大额现金未给合理说明：标必须改，不写成已经完成交付。
6. 禁止把面额本金写成已可请求的全部债权。借据与合同冲突：并列，修改句指定以何者为准。

## 节点 5　利率、息费总和与约定不明（LPR 四倍硬闸）

### 5.1 必须写清“有约定 / 未约定 / 约定不明”

只写“按约定”“适当利息”“市场利率”“参照银行贷款利率”视为约定不明，必须改成“年利率【待填】%”或“月利率【待填】%”，并写明自实际放款日起算至实际清偿日止。

没有约定利息与约定不明不得混写：

| 主体组合 | 没有约定利息 | 约定不明 |
| --- | --- | --- |
| 双方自然人 | 视为没有利息 | 视为没有利息 |
| 有企业或非法人组织参与 | 视为没有利息 | **不得**写成无息。应结合合同内容、交易方式、交易习惯、市场报价利率确定；签署前必须改成明确数字 |

用户坚持把有企业参与的约定不明写成“依法无息”：停止该结论。

### 5.2 合同成立时一年期 LPR 四倍

核验后可引用（须写入 `L#`）：

- 约定利率超过合同成立时一年期贷款市场报价利率四倍的，超过部分不予支持。
- 一年期 LPR 指全国银行间同业拆借中心自 2019-08-20 起每月公布的一年期报价。
- 逾期利率有约定的从约定，但仍以该四倍为限。
- 逾期利息、违约金或者其他费用可以一并主张，但总计超过四倍的部分不予支持。
- 前期利息转入后期本金的，前期利率不得超四倍；整个借款期间本息之和不得超“最初本金 + 最初本金×四倍×期间”。

禁止直接输出下列口径作为本类型现行上限：

- 年利率 24%、年利率 36%（2015 年口径）；
- 银行同类贷款利率四倍（1991 年意见口径）。

动作：

1. 摘录借期内利率、逾期利率、违约金、律师费、服务费，折成年化并并列。
2. 调用 `search_law` 核验第 25、28、29 条。仅当返回现行有效规则时写入 `L#`。
3. 当次一年期 LPR 未核验：不编造数值，用 `【合同成立时全国银行间同业拆借中心公布的一年期 LPR × 4，待填】`。修改句把超限部分改成不超过该上限，或删除重复计收的费用。
4. 核验失败：是否“超过四倍”的法律结论字段停止。仍可摘录文本数字并给出“待核验当次 LPR 后改写”的修改句草稿。
5. 用户要求按 24%/36% 出“现行合法上限”：停止该结论。

### 5.3 复利

复利必须有明确书面约定。即使约定，折算后的实际负担仍受四倍限制。未写明而只写“利滚利”：必须改成可执行公式，或删除。

## 节点 6　用途、资金来源与无效红旗

1. 用途必须具体到可核查（个人装修、采购某批货物、支付某笔到期货款）。只写“周转”“生活需要”标必须改。正说加反说都要落句。
2. **禁止用途。** 出借人事先知道或应当知道用于赌博、吸毒、走私等违法犯罪仍提供借款的，合同无效。用户要把用途改成“可以进赌场、可以转去放贷”：红线告知，不改成可履行。
3. **资金来源。** 文本或用户材料指向套取金融机构贷款转贷，或以向其他营利法人借贷、向本单位职工集资、向公众吸收存款取得的资金转贷：走节点 1.3，不改成可履行转贷。修改句可要求出借人书面陈述资金为自有合法资金，但该陈述不构成已核验。
4. 未按约定用途使用：核验后可点名停止发放、提前收回或解除（第 673 条）。修改句把该救济绑到可识别挪用事实和书面催告，不写成无需任何事实的随时收回。
5. 单位内部向职工集资：不是本类型主路径，负触发或停笔点名，不改成可履行集资结构。

## 节点 7　加速到期、格式痕迹；担保和配偶只审引用

### 7.1 加速到期与异常条款

企业出借人使用重复文本时，按格式条款审查免责、单方认定违约、加速到期、送达拟制。仅有小字或网络勾选：不得写成已尽提示或说明义务。

| 文本写法 | 本任务动作 |
| --- | --- |
| “出借人有权随时提前收回全部借款，无需理由、无需通知” | 红线或必须改。改为：发生合同列明的违约情形（逾期支付本金或利息、挪用、提供虚假负债信息等）且经【待填】日书面催告未纠正的，可以宣布加速到期 |
| “借款人未提出书面异议的，视为已收到全额款项” | 必须改。到账以银行回单或收据为准，不得用沉默拟制收款 |
| 送达地址空白或只写微信号 | 必须改。补通讯地址为司法送达地址，变更须书面通知 |
| 用户要求保留无催告无违约事件的随时收回 | 整体停止该条放行 |

争议解决：或裁或诉、机构不明必须改成单一仲裁机构或单一法院连结点。民间借款履行地随“接受货币一方”变动，约定“出借人住所地人民法院”可作为出借人侧优化句，不得写成唯一合法管辖。

### 7.2 担保引用与配偶签字栏

本约出现保证、抵押、质押时：

1. 只检查：是否写明担保文件名称与签署人、担保范围是否指向本合同项下本息及约定费用、未签署或未登记时能否放款。
2. 空白保证方式：修改句要求写明连带或一般；**不得**把空白写成已经是连带保证。
3. 抵押/保证条款已长到主导放行：负触发对应原子。
4. 不得把担保引用缺失写成“已经有足额担保”。

借款人为自然人且金额明显超出日常家事：出借人侧修改句可要求配偶作为共同借款人或另行出具同意函。未签署不得写成已经构成夫妻共同债务。配偶文件已成独立保证主文：负触发 `保证借款合同·审查`。

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

| 步 | 动作 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题用借款合同/借款协议，不用投资协议或平台贷款合同；主体身份信息与账户；鉴于不写本金利率 | 标题或主体修改句 |
| 交易条款 | 本金大小写、到账额、成立与放款按主体组合分列、明确年/月利率、四倍总和、用途正反说、转账备注 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 逾期利息与违约金、律师费受四倍总和约束；加速到期绑定违约事件与催告；担保和配偶只补引用闭环 | 可执行后果句 |
| 尾部 | 自然人签名按指印；企业公章加法定代表人或授权人；日期真实；附件含证照、账户、收据/回单 | 生效与附件修改句 |

| 常见问题 | 误入广义平台稿、整类实践、整类无息、砍头息、24%/36%、职业放贷可履行化 | 结构级改法或红线 |
