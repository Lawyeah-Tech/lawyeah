# 边界与路由

本技能只审查 **借款合同 / 狭义民间借款合同**。

出借人必须是一般企业或自然人，资金往来必须是临时性、非经营性融通。标题叫“民间借款合同”但实际是平台撮合、小贷放贷或银行贷款的，不得留在本技能做实体结论，也不得改写成“视同狭义民间”。

狭义与广义不是同一方法。广义路径处理准金融机构、P2P、资金存管和电子平台额度；本技能不打开那套栏目。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或标题借款、核心给付明显不是点对点临时融通 | 本套导航的类型切开步骤 |
| P2P、网络借贷信息中介、资金存管、小额贷款、典当、网络小贷、平台撮合额度 | `广义民间借款合同·审查`；禁止用本技能审备案、电信许可或 20 万/100 万限额 |
| 双方自然人，生活互借、借条或共债主导 | `自然人之间的借款合同·审查` |
| 双方非金融企业或非法人组织，经营性拆借或资金占用费主导 | `企业间借款合同·审查` |
| 出借人持金融许可证且经营范围含贷款 | `金融机构借款合同·审查` |
| 主结构为不动产/动产抵押借款，登记或流押主导放行 | `抵押借款合同·审查` |
| 主标题或主结构为保证借款 | `保证借款合同·审查` |
| 主结构为权利或动产质押 | `质押借款合同·审查` |
| 买卖/过户/回购为还款担保，或让与担保 | `让与担保型借款合同·审查`；专业版未收录该 P1 时输出 `unavailable`，不得硬套本技能改成可过户结构 |
| 名为投资、合伙，固定回报且无真实共担风险 | 引擎或对应原子；可在分流中点名“名股实债/名伙实贷”外观，不按投资稿审 |
| 无文本、本类型条件已谈妥、要出己方稿 | `狭义民间借款合同·起草` |
| 已签未争、问放款日、还本付息 | 本套导航的履约步骤 |
| 已成争、催收、诉讼仲裁 | 合同争议领域；不写催收函、起诉状 |
| 用户只要利息或息费精算终局数字 | 测算技能或人工精算；本技能只审条款 |
| C 端大众快检 | 只分流，不回改 |

附带保证、抵押或配偶签字栏时：本技能只审对本约放行的影响（是否被引用、未落实能否放款、空白保证方式不得写成已连带），不展开抵押登记或保证期间专项。

职业放贷、转贷、违法用途、套路贷：停笔告知，不改写成可履行放贷文本。
