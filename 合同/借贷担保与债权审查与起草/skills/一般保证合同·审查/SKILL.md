# 一般保证合同·审查

## 任务目标

在单一立场下，只审查 **保证合同 / 一般保证合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文名必须是「审查一般保证合同（保证合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类合同审查；从零起草；履约交底；争议文书或行权策略；有效性保证；把先诉抗辩改成债权人可直接请求；把约定不明写成已经是连带责任保证。

## 本类型硬闸

1. **先诉抗辩是本类型灵魂**。保证人在主合同纠纷未经审判或者仲裁，并就债务人财产依法强制执行仍不能履行债务前，有权拒绝向债权人承担保证责任。修改句必须写清这条“不能履行”路径，不得改成债权人可直接请求保证人（那是连带责任保证，转 `连带责任保证合同·审查`）。
2. **约定不明按一般保证**。对保证方式没有约定或约定不明确的，按民法典第六百八十六条按一般保证承担保证责任。禁止把原《担保法》第十九条“约定不明=连带”当作现行规则。标题写“连带”、正文写“不能履行”或先诉抗辩时，冲突并列，不选对用户有利的一版。
3. **保证期间须运行时核验现行条**。无约定、约定不明或“直至主债务本息还清时为止”等类似内容，按现行规则视为六个月，不得写担保法解释“约定不明=二年”。一般保证期间内的主张对象是对**债务人**提起诉讼或申请仲裁，不是直接请求保证人。条号与效力以当次 `search_law` 为准。
4. **从属性**。主债权债务合同无效的，保证合同无效，但是法律另有规定的除外。普通保证中的独立性约款无效，不得改成独立保函。
5. **禁止主体只告知，不改成可履行**。机关法人、以公益为目的的非营利法人或学校医院作保证：只出告知。用户坚持改到能签：停止。
6. **公司决议**。为股东或实际控制人提供保证须股东会决议且关联股东回避。口头“董事会同意了”不得写成已授权。公司法条号用 2023 年修订第十五条，不用知识库未写条号或旧第十六条。
7. **主债必须特定**。须能回链主合同名称或编号、双方、金额或确定方法、履行期限。概括“一切债务”而无期间和限额的，转 `最高额保证合同·审查` 或红线，不得按本类型放行。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

禁止表述：约定不明就是连带；法定期间二年；未登记则保证未生效；保证一定有效；先诉抗辩可以口头放弃且无法定例外说明。

## 工作边界

正触发：已有可读待签文本要评改，尚未签署，尚未成争，核心给付是第三人为已特定主债提供一般保证，或保证方式未约定／约定不明因而依法按一般保证；用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 明确连带责任保证，触发用“不履行／未履行”，债权人可直接请求保证人，且无先诉抗辩 → `连带责任保证合同·审查`；
- 最高额、一定期间连续发生、最高债权额限度 → `最高额保证合同·审查`；
- 独立保函、见索即付、URDG / 相符交单 → `独立保函·审查`（专业版未装则 `unavailable`，提示，不得用本技能硬套）；
- 安慰函、维好协议、仅“知晓／督促／尽合理努力” → `安慰函·审查`（未装则 `unavailable`）；
- 差额补足、流动性支持、回购承诺等增信主轴 → `增信措施类保证合同·审查`（未装则 `unavailable`）；
- 主文件是借款，保证只是从条款 → `保证借款合同·审查` 或对应借款场景原子；
- 无文本、本类型条件已谈妥、要出己方稿 → `一般保证合同·起草`；
- 已签只问履约节点或行权日历 → 本套导航的履约步骤；
- 已催告、索赔、立案、开庭、仲裁，或主问保证责任是否消灭、怎么起诉、共同被告怎么列、执行不能怎么证明 → `或` 或 `或`。

机关法人、公益性主体违规保证，或伪造决议、倒签：只出告知，不改写成可履行规避结构。

## 建立审查坐标

确认：使用者与授权；单方立场（债权人 / 保证人 / 债务人择一）；相对方；全文及附件版本；主合同文本或要点；保证方式原句；先诉抗辩原句；保证期间原句；保证范围；公司决议或授权；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的金额、期间、主合同编号用 `【待填】`，不编造。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、已失效《担保法》及其解释当作现行规则。保证方式约定不明按一般保证，不得写原担保法默认连带。法定保证期间不明为六个月，不得写旧二年。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验保证方式、先诉抗辩及例外、保证期间、从属性、主体禁入和公司决议；`search_practiced` 只补审查反例，不写办案策略；`search_template` 只借栏目结构。不虚构案件系统。

`search_law` 对上述法律结论为 required 级：不可用时不拒绝执行，只停止效力字段。返回已失效《合同法》或其解释、已失效《担保法》或其解释、法释〔2002〕38 号时记为噪声，不得写入 `L#`。

### 0. 签署状态与成果分流

无书面文本 → `一般保证合同·起草`；已签履约 → 本套导航履约步骤；已成争或主问责任消灭／起诉策略 → 争议或 `或`。未签且目标是评改已有一般保证合同，才进入本任务。

### 1. 类型锁死

标题、核心给付与一般保证或约定不明一致才继续。连带可直接请求、独立保函、安慰函、最高额、增信、借款主文件负触发。

### 2. 主体、禁入与决议

保证人是否机关或公益性主体；公司对外担保决议与章程限额；分支机构授权。口头“董事会同意了”不得写成已授权。

### 3. 主债特定与从属性

主合同名称编号、金额、履行期限必须可回链。独立性约定按现行解释无效，不得改成独立保函。

### 4. 先诉抗辩与保证方式

必须写清“不能履行”路径和先诉抗辩。不得改成可直接请求。口头放弃不成立。书面全面放弃改变本质，转 `连带责任保证合同·审查`。约定不明按一般保证，不按旧担保法推定连带。

### 5. 保证范围与混合担保

范围可核对主债、利息、违约金、损害赔偿和实现债权费用。物保加保证未约定顺位的，标法定默认，不擅自选定。

### 6. 保证期间

运行时核验现行条。无约定、不明或“还清为止”按六个月处理并出修改句。期间内主张对象是起诉或仲裁债务人。分期履行起算标待核，不编造。

### 7. 变更、财产线索与争议条款

主债加重或展期须书面同意。保证人提供可供执行财产线索的条款可保留，但不写执行策略。争议条款只改单一连结点。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。先诉抗辩路径句不得省略。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、伪造决议、把机关或公益主体改成可履行保证人、把独立性条款改成独立保函、按旧担保法把约定不明写成连带、把先诉抗辩改成可直接请求仍按本类型放行、主张口头放弃先诉抗辩且无法定例外说明、保证有效。
- `字段停止`：法域、动态规则、决议真伪、主债金额或履行期限未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书、保证责任评估，或把本合同改成连带责任保证／独立保函。

生存级金额或自然人无限保证且用户拒绝升级：停止放行建议，只列风险与转介。
