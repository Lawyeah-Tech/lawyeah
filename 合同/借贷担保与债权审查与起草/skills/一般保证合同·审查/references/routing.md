# 边界与路由

本技能只审查 **保证合同 / 一般保证合同** 的待签文本。中文展示名是「审查一般保证合同（保证合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 连带责任保证；“不履行／未履行即可请求保证人”；债权人可直接请求；无先诉抗辩 | `连带责任保证合同·审查` |
| 最高额保证；一定期间连续发生；最高债权额限度；债权确定期间 | `最高额保证合同·审查` |
| 独立保函；见索即付；URDG / ISP98；金融机构相符交单付款 | `独立保函·审查`；专业版未装则 `unavailable`，提示，不得用本技能硬套 |
| 安慰函、维好协议、意愿书；仅知晓、关注、督促、尽合理努力 | `安慰函·审查`；专业版未装则 `unavailable` |
| 差额补足、流动性支持、回购承诺等增信主文件 | `增信措施类保证合同·审查`；专业版未装则 `unavailable` |
| 主文件是借款，保证仅为从条款 | `保证借款合同·审查` 或对应借款场景原子 |
| 主文件是金融机构借款、民间借贷等，保证只是附件名称混用 | 对应借款场景原子；本任务不审利率或放款条件整案 |
| 无文本、本类型条件已谈妥、要出己方稿 | `一般保证合同·起草` |
| 已签未争、只问行权日历或履约节点 | 本套导航的履约步骤 |
| 已催告、索赔、立案、开庭，或主问保证责任是否消灭、能否免责、怎么起诉、共同被告、执行不能怎么证明 | `或` 或 `或` |
| 企业融资整包、对赌或结构化增信要放行意见 | `企业融资整包对赌或结构化增信要放行意见`；本任务不放行融资结构 |
| 配偶是否共同债务 | 只标缺口；整案 `配偶是否共同债务` |
| 追股东或法人格 | `追股东或法人格` |
| C 端大众快检 | 只分流，不回改 |

普通保证合同里夹带一句“本合同独立于主合同”：不整案转独立保函；按从属性删除或改正该句后继续审。用户坚持改成见索即付独立保函：`目标停止`，转 `独立保函·审查` 或标明 `unavailable`。

用户坚持删除先诉抗辩、改成“债权人可直接请求保证人”：`目标停止`，转 `连带责任保证合同·审查`。不得在本技能把一般保证改成连带后宣称审查完成。

标题写“保证合同”、条款未选一般或连带：按第六百八十六条现状为一般保证，留在本任务；必须出先诉抗辩路径修改句，不得按连带放行。
