# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的金额、期间、主合同编号；把已失效《合同法》《担保法》及其解释写入结论；把约定不明写成已经是连带责任保证；把先诉抗辩改成可直接请求；输出起诉策略、共同被告方案或“怎么证明执行不能”；写先诉抗辩可以口头放弃且无法定例外说明；写未登记则保证未生效。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查一般保证合同（保证合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、已失效《担保法》及其解释、法释〔2002〕38 号，或把“约定不明=连带／二年”写成现行规则时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `保证合同`，子级 `一般保证合同`。定性理由、易混切开结果（连带责任保证／独立保函／安慰函／最高额／增信／借款）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、决议与文本版本

主体表：债权人、债务人、保证人、签约名、授权签字人、决议机构。禁入与决议闸：机关／公益主体、章程限额、股东或实控人担保回避、分支机构书面授权。版本表：保证合同正文、主合同、决议、授权委托、配偶同意函、聊天确认；冲突并列。

## 5. 主债特定、先诉抗辩、范围与期间

主合同名称或编号、金额或确定方法、履行期限；保证方式原句与判断（一般 / 连带 / 不明）；先诉抗辩路径是否完整（审判或仲裁 + 强制执行仍不能履行 + 有权拒绝）；保证范围清单；保证期间原句、起算点、期间内主张对象（须为对债务人起诉或申请仲裁）、对照现行规则后的判断。缺口标 `G#`。不输出唯一应付金额或“保证责任已消灭”终局结论。

## 6. 从属性、独立性条款与强制规范

是否存在“效力独立于主合同”“见索即付”等独立性约定；公司决议或越权担保；机关／公益主体禁入；口头放弃先诉抗辩的主张。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和删除句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。必须至少有一条先诉抗辩路径句，写清“不能履行”，不得改成可直接请求。框架里的二年期间当法定、标题冲突即丧失先诉抗辩、诉讼共同被告策略不得直接当作建议句。

## 9. 谈判与签署提醒

谈判顺序：先红线（先诉抗辩被改成直接请求、约定不明当连带、期间还清为止、主债不特定、独立性条款、禁入主体、无决议仍要放行、口头放弃先诉抗辩），再必须改，最后可优化。签署提醒：保证人签字或盖章、自然人建议签名并捺印、决议原件或核验件作为附件、主合同与保证合同互相引用、送达地址；债权人侧提醒期间内须对债务人起诉或申请仲裁；保证人侧提醒勿在含义不明催收单上签字、勿口头承诺放弃先诉抗辩。不指导倒签、补假决议、伪造催收或起诉策略。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本任务只出审查意见与修改句，不出整份起草终稿。无文本出稿转配对起草原子。不是履约交底、争议文书、保证责任评估或效力保证。
