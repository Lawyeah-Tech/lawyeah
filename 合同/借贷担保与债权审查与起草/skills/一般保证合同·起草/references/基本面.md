### **第一步：合同类型（法律性质）分析**

* 
**法律定性**：一般保证合同是保证合同的基础类型 。根据《民法典》第681条，它是保证人和债权人约定，当债务人不履行到期债务时，由保证人履行债务或承担责任的从合同 。


* 
**构成要件与推定规则**：一般保证的核心特征是保证人享有先诉抗辩权 。若保证合同中对保证方式未约定或约定不明，根据《民法典》第686条第2款，推定为一般保证 。


* **易混淆辨析**：
* 
**一般保证 vs 连带责任保证**：前者债务人“不能履行”时保证人才承担责任（客观无清偿能力）；后者债务人“不履行”时保证人即需承担责任 。


* 
**保证合同 vs 安慰函**：安慰函通常不含有“保证”或“代为清偿”的意思表示，仅表达知晓、监察或道义责任，不构成法律意义上的保证 。




* **效力认定（高风险）**：
* 
**从属性风险**：主合同无效则保证合同无效 。


* 
**违法无效情形**：国家机关、以公益为目的的事业单位及社会团体违规提供保证的，合同无效 。





### **第二步：合同主体（交易对手）分析**

* **主体适格性**：
* 
**一般要求**：保证人需具有代为清偿能力 。


* 
**禁止性主体**：国家机关（除非经国务院批准转贷）、公益性事业单位（如学校、医院）、公益性社会团体原则上不得为保证人 。




* **特殊授权要求**：
* 
**公司主体**：必须依照公司章程由董事会或股东会决议。为股东或实际控制人提供保证的，必须由股东会决议，且关联股东回避 。


* 
**分支机构**：企业法人的分支机构未经法人书面授权，不得提供保证 。




* 
**代理风险**：需核查法定代表人或代理人是否越权或伪造决议 。相对人若未尽到形式审查决议的注意义务，可能无法适用表见代理 。



### **第三步：合同标的（交易对象）分析**

* 
**标的适格性**：一般保证的标的是保证人基于主债务而不履行的代为履行义务或承担责任，性质上属于金钱给付或劳务给付 。


* 
**保证范围**：通常包括主债权及其利息、违约金、损害赔偿金和实现债权的费用。当事人未约定范围时，保证人对全部债务承担责任 。


* **风险转移与限制**：
* 
**主合同变更**：债权人与债务人协商变更主合同内容（如增加债务额、延长清偿期限），未经保证人书面同意的，保证人可能减轻或免除责任 。


* 
**债权/债务转让**：债权转让通常需通知保证人；债务转让未经保证人书面同意的，保证人不再承担保证责任 。





### **第四步：合同程序（交易步骤）分析**

* 
**内部决策程序**：债权人应要求公司制保证人提供符合章程的董事会或股东会决议，并进行形式审查（如签名、盖章核对） 。


* 
**先诉抗辩权行使程序**：这是一般保证的核心程序，债权人必须先对债务人提起诉讼或仲裁，并就债务人财产依法强制执行仍不能履行债务后，方可要求一般保证人承担责任 。


* **期间管理程序**：
* 
**保证期间**：债权人必须在合同约定或法律规定的保证期间内向债务人提起诉讼或仲裁 。否则，保证人免除保证责任 。


* 
**诉讼时效**：在一般保证中，保证债务的诉讼时效自保证人青偿义务触发（即债务人强制执行不能）之日起算 。





### **第五步：交易结构设计（风险规避方案）**

* **担保结构组合**：
* 
**混合担保**：同一债权既有保证又有抵押/质押时，若无约定，应先执行债务人提供的物保；不足部分由保证人承担补充责任 。


* 
**共同保证**：可设计为“按份共同保证”以限定各保证人责任比例，或“连带共同保证”增强债权保障 。




* 
**抗辩权放弃条款**：债权人可与保证人约定其放弃某些抗辩权，但不得通过约定排除法律强制性保护（如禁止约定独立保证） 。


* 
**风险隔离设计**：通过要求保证人提供反担保（由债务人或第三人向保证人提供担保），降低保证人最终损失风险 。


* **文本形态**：
* 
**单方文件**：保证人可出具保证承诺书或在主合同上以保证人身份签字 。


* 
**主从协议**：设计独立的保证合同作为主合同的附件，明确保证范围、期间及先诉抗辩权的触发条件 。





### **第六步：宏观风险预警与尽调指引**

* **高频争议点**：
* 
**期间经过风险**：债权人因未在保证期间内起诉债务人导致保证人脱保 。


* 
**主体越权风险**：公司高管未经决议擅自担保导致合同无效 。




* **尽职调查清单**：
* 核查保证人的资产负债表及征信记录（代为清偿能力） 。


* 调取保证人公司章程，确认担保决策机构（董事会或股东会） 。


* 审核担保决议的真实性及出席人员签名是否合规 。




* **重大风险预警**：
* 严禁接受行政机关、学校、医院等公益性主体的保证，该类合同几乎必然无效且追偿受限 。


* 警惕主合同虚假或走私等非法行为，若主合同因违法无效，保证人仅承担过错赔偿责任而非保证责任 。
