### **一、 首部 要素审查**

1. **合同标题**：
* 
**标准命名**：通常命名为“保证合同”或“一般保证协议” 。


* 
**审查要点**：若标题仅为“保证合同”，须在正文通过特定措辞明确“一般保证”方式，否则根据《民法典》第686条第2款，未约定或约定不明的推定为一般保证 。




2. **合同主体**：
* 
**资格审查**：国家机关（除经国务院批准转贷外）、以公益为目的的事业单位及社会团体（如学校、医院）不得作为保证人，否则合同无效 。


* 
**分支机构**：企业法人的分支机构未经法人书面授权不得作保证人 。




3. **鉴于条款**：
* **功能定位**：用于交代主债权背景（如借款合同编号、金额）。
* 
**核心风险**：严禁将“保证人愿意承担一般保证责任”等实质义务仅写在鉴于条款中，应落实到交易条款正文 。





### **二、 交易条款 审查**

1. **被担保的主债权（标的）**：
* 
**描述**：明确主合同的种类、金额、履行期限 。


* 
**从属性**：保证合同是主合同的从合同。主合同无效，保证合同随之无效 。




2. **保证方式（核心交易项）**：
* **专业表述**：必须明确表述为“**一般保证**”。
* 
**先诉抗辩权条款**：一般保证人享有先诉抗辩权，即“在主合同纠纷未经审判或者仲裁，并就债务人财产依法强制执行仍不能履行债务前，保证人有权拒绝承担保证责任” 。


* 
**陷阱识别**：若约定“无条件、不可撤销”或“见索即付”，可能被合理解释为放弃先诉抗辩权的连带保证 。




3. **保证担保范围**：
* 
**构成**：包括主债权及其利息、违约金、损害赔偿金和实现债权的费用 。


* 
**最佳实践**：若未约定范围，保证人对全部债务承担责任。建议通过“正说”明确涵盖范围，或通过“列举+概括”方式表述 。




4. **履行期限与保证期间**：
* 
**保证期间**：具有法定性和强制性。若未约定，期间为主债务履行期限届满之日起六个月 。


* 
**起算点**：明确从“债务履行期限届满之日”起算 。


* 
**风险辨析**：区分保证期间与诉讼时效。保证期间届满债权人未主张权利，保证人免责 。





### **三、 配套条款 审查**

1. **违约责任条款**：
* **违约情形**：保证人拒绝履行到期保证责任、提供虚假财务证明等。
* 
**救济措施**：要求保证人支付违约金、赔偿损失（含律师费等实现债权的费用） 。




2. **抗辩权行使**：
* 
**从属抗辩**：债务人对债权人的抗辩（如诉讼时效届满），保证人亦可享有 。


* 
**放弃抗辩**：审查是否存在保证人自愿放弃先诉抗辩权的约定，这会改变一般保证的本质 。




3. **追偿权条款**：
* 
**法律规定**：保证人承担保证责任后，有权向债务人追偿 。


* 
**混合担保顺序**：若既有保证又有债务人提供的物保，债权人未先就物保行使权利前，一般保证人可拒绝承担责任 。





### **四、 尾部 要素审查**

1. **签名盖章**：
* 
**效力识别**：建议使用“法定代表人或授权代表签字并加盖公章”的组合方式 。


* 
**共同保证风险**：若多个保证人在同一保证合同签字盖章，推定为连带共同保证，相互间有追偿权 。




2. **生效条款**：
* 
**基本约定**：自各方签字、盖章之日起生效 。


* 
**关联性**：明确保证合同生效不以主合同生效为前提，但主合同无效会牵连保证合同无效 。





### **五、 合同语言审查**

1. **准确性（“正说反说”）**：
* **正说**：保证人“应当”在债务人财产经强制执行仍不能清偿后，承担保证责任。
* 
**反说**：在主合同纠纷未经审判或仲裁前，保证人“有权拒绝”债权人的履行请求 。




2. **重点词语辨析**：
* 
**“不能履行” vs “不履行”**：一般保证对应“不能履行”（客观无力），连带保证对应“不履行”（主客观皆可） 。


* 
**“保证” vs “担保”**：保证专指人保，担保是涵盖物保、人保、定金的统称 。




3. **模糊词风险**：
* 
**“有关费用”**：应替换为“利息、违约金、诉讼费、执行费、律师费等”概括列举表述 。


* 
**“尽快”**：在涉及履行通知时，应设定具体天数（如“3个工作日内”） 。





### **六、 常见问题与最佳实践**

* 
**结构性陷阱**：在一般保证中误写入“连带”字样。即便标题是“一般保证”，若条款中出现“保证人承担连带保证责任”，将导致先诉抗辩权丧失 。


* 
**最佳实践模式**：明确约定保证期间为“主债务履行期限届满之日起二年”，以长于法定的六个月，为债权人起诉债务人及执行留足时间 。


* 
**证据留存**：债权人应留存主合同履行期限届满、向债务人催收、起诉或申请仲裁、申请强制执行及法院出具的执行终结裁定等全过程证据，以触发一般保证人的责任 。
