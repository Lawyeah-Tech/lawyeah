# 边界与路由

本技能只审查 **借款合同 / 自然人之间的借款合同**。

双方必须都是自然人。标题叫“借款合同”但主体不是双自然人的，不得留在本技能做实体结论。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或标题借款、核心给付明显不是资金互借 | 本套导航的类型切开步骤 |
| 一方或双方为企业、其他组织；企业间拆借、资金占用费 | `企业间借款合同·审查` |
| 贷款人为商业银行、消费金融、小贷、信托等持牌放贷机构 | `金融机构借款合同·审查` |
| 一方为自然人、另一方为企业，但贷款人不是持牌机构 | `狭义民间借款合同·审查` 或引擎重新定性；不留本技能 |
| 主标题或主结构为保证借款，保证条款主导放行 | `保证借款合同·审查` |
| 主结构为不动产/动产抵押借款 | `抵押借款合同·审查` |
| 主结构为权利或动产质押借款 | `质押借款合同·审查` |
| 买卖/过户/股权转让为还款担保，或流质流押 | `让与担保型借款合同·审查`；专业版未收录该 P1 时输出 `unavailable`，提示，不得硬套本技能改成可过户结构 |
| 名为投资、合伙、买卖，固定回报且不承担经营风险 | `名为其他实为借贷·审查` 或引擎定性；专业版未收录该 P1 时输出 `unavailable` |
| 有完整待签文本要评改 | `自然人之间的借款合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 留本任务起草并自审 |
| 已签未争、问放款日、还款日、催收留痕 | 本套导航的履约步骤 |
| 已成争 | 合同争议领域或对应专项；不写催告函、起诉状 |
| 用户只要利息或逾期精算终局数字 | 测算技能或人工精算；本技能只审条款，不输出唯一应付总额 |
| C 端大众快检 | 只分流，不回改 |

附带保证、抵押或配偶签字栏时：本技能审查对本约放行的影响（方式不明、期间不明、未本人签），不展开保证合同、不动产登记或夫妻债务专项整案。

职业放贷、转贷、违法用途、虚假诉讼：停笔告知，不改写成可履行放贷文本。
