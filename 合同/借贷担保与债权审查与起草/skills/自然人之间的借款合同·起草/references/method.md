# 审查方法（锁定 借款合同 / 自然人之间的借款合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止套用买卖合同的标的验收、定金比例、挂靠改写或工程分包节点。

定性校验：双方均为自然人，且核心给付是资金借贷，才继续；明显他类则负触发，不填十节实体结论。

本文件是可执行判断节点，不是栏目说明书。每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、已婚即共债、保证不明即连带，或唯一必得本息。

`search_law` 返回已失效《合同法》《担保法》及其解释、1991 年《关于人民法院审理借贷案件的若干意见》、2015 年民间借贷司法解释中 24%/36% 条文时记为噪声，不得写入 `L#`。`search_practiced` 仍写“保证不明推定连带”或“银行利率四倍”的，同样记噪声。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

示范文本只参考结构。写“自双方签字盖章之日起生效”的范本与自然人借款实践性冲突，不得当成立规则。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用主体属性、核心给付和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须同时满足才正触发：

1. 出借人与借款人均为自然人（含共同借款人栏中的自然人）。
2. 核心给付是出借人提供货币资金，借款人到期返还本金；利息有无可另审。

必须切开，禁止两可时灌入两套知识：

### 1.2 加载协议（硬闸）

本技能已锁定 **借款合同 / 自然人之间的借款合同**。只打开 `references/基本面.md` 与 `references/框架.md`。禁止读其他类型目录，禁止为对照再开第二类。

知识库用于校验类型、红旗和框架六步。下列口径以本方法为准，不回写知识正文：

- 利率上限必须运行时核验，不得把知识库中的“四倍”直接当已核验结论，更不得写成银行利率旧四倍或 24%/36%。
- “必须要求配偶签字”只是出借人增信建议，不得写成已婚即共债。
- “保证方式必须写成连带”是谈判目标，不是现行默示规则。

### 1.3 违法放贷与虚假结构停笔

加载后或定性中出现：向不特定对象经营性放贷、套取金融机构贷款转贷、集资或非法吸收资金转贷、明知赌博吸毒等违法犯罪用途仍出借、以合法形式掩盖非法目的、指导伪造收条或倒签。

动作：

1. 交付告知：该结构可能违反强制性规定或公序良俗，不得改写成可履行放贷文本。
2. 不写“换个用途就能签”、假资金来源、假交付路径。
3. 风险表只保留识别依据和转出/改道提示。
4. 用户坚持“改到能签”：整体停止。

合规改道（停止放贷、改为一次性亲友互助并如实披露资金来源）只点名，不在本任务起草。

## 节点 2　主体、行为能力、账户与资金来源

1. 建主体表：出借人、借款人、指定收款人、共同借款人栏、保证人、拟签字配偶。姓名、证件号、联系地址分列。不一致不自动合并。
2. 双方必须是自然人。出现公司名称、统一社会信用代码、法定代表人代表公司借款：回到节点 1 负触发。
3. 行为能力：未成年、被宣告无/限制民事行为能力，该签署能力字段停止，不写成可以代签。
4. 账户一致：指定收款账户户名必须与借款人一致。打入第三人或出借人自己控制的账户，必须有借款人本人签署的指定收款或委托付款条款，否则标必须改。
5. 资金来源：文本或陈述出现房贷、经营贷、信用卡套现、银行贷款转借，标红旗。不得把“自有资金”写成已经核实。材料未提及不得写成资金来源合法。
6. 口头“我们家里同意了”“保证人点头了”不得写成已授权或已提供保证。

不足：字段停止，列出待补材料，不补主体。

## 节点 3　实践性与交付（成立硬闸）

自然人之间的借款合同自贷款人提供借款时成立。本节点不因双方已签字而写成合同成立。

核验后可引用的成立判断点（须 `search_law` 写入 `L#` 再落法律结论）：

- 现金：借款人收到借款时；
- 银行转账或电子汇款：资金到达借款人账户时；
- 票据：借款人依法取得票据权利时；
- 授权支配特定资金账户：借款人取得实际支配权时；
- 其他约定方式：实际履行完成时。

| 文本写法 | 本任务动作 |
| --- | --- |
| “本合同自双方签字之日起成立/生效” | 必须改。拆成：书面文本固定合意；合同自出借人实际提供借款时成立 |
| “签字即视为已经收到全部借款”且无独立收条或到账安排 | 红线或必须改。禁止用拟制收到代替交付事实 |
| 只约定将签署、未约定账户、金额、交付时点 | 标 `G#`；修改句补账户、金额、到账视为提供借款 |
| 大额现金，无收条、无取现说明 | 必须改；提示举证风险，不编造已交付 |
| 用户要求把日期写成已经放款或倒签成立日 | 整体停止 |

未实际提供借款时：借款人无权请求交付；出借人亦不得把未成立合同写成已经可执行债权。本任务是签前评改，不得把未来放款写成已经完成。

## 节点 4　本金与砍头息

1. 本金必须同时有阿拉伯数字与大写。不一致并列，修改句写明以大写为准或重新核对后填写同一数字，不擅自改数。
2. 币种未写：修改句补人民币或其他币种及汇率，不默认外币。
3. **砍头息硬闸**。利息预先在本金中扣除的，应当按照实际借款数额返还借款并计算利息。
4. 下列写法按预扣或变相预扣处理，本金改到实际交付额：

   - 合同写 10 万，条款写“先行扣除利息/服务费/渠道费后支付”；
   - 面额 10 万，转账条款或备注为 9 万；
   - “保证金、咨询费、中介费”在放款时从本金扣留且不独立结算。

5. 禁止把面额本金写成已可请求的债权。修改句固定格式：`借款本金以出借人实际提供并到达约定账户的金额为准，预扣的利息或费用不计入本金。`
6. 复利或“利滚利”重新出具借条：只审条款风险；本息之和是否超过保护上限，无核验不得写成合法。

## 节点 5　利息、费用与司法保护上限（运行时核验硬闸）

### 5.1 有无利息

自然人之间借款：对支付利息没有约定，或约定不明确且不能达成补充协议的，视为没有利息。仅有“利息按约定”“利息面议”“适当付点利息”视为约定不明。出借人立场必须改成书面年利率或明确无息；借款人立场可保持不明并提示依法视为无息，但仍要给可回传的澄清句，防止对方事后补高息。

禁止把口头利率、聊天里的“三分”“几分”在无书面落句时写成已经约定。

### 5.2 上限必须当次核验

禁止直接输出下列已废止或已被修改的口径作为现行保护标准：

- 银行同类贷款利率四倍（1991 年意见口径，下称“旧四倍”）；
- 年利率 24%、年利率 36%（2015 年司法解释口径）；
- 任何未核验的“四倍”。

动作：

1. 调用 `search_law` 查询“民间借贷利率司法保护上限 现行规定”。
2. 仅当返回现行有效规则时写入 `L#`，再把文本利率与“合同成立时”的保护标准对照。
3. 开发窗口 2026-08-18 核验结果（供对照，不得代替运行时核验）：《最高人民法院关于审理民间借贷案件适用法律若干问题的规定（2020 第二次修正）》法释〔2020〕17 号第 25 条，约定利率超过合同成立时一年期贷款市场报价利率四倍的部分不予支持；一年期 LPR 指全国银行间同业拆借中心自 2019-08-20 起每月发布的一年期 LPR。逾期利率见第 28 条；逾期利息、违约金或其他费用总和见第 29 条，总计超过上述标准的部分不予支持。
4. 核验失败、结果冲突或只返回已修改文本：利率法律结论字段停止。仍可摘录文本利率并给出“待核验现行上限后改写”的修改句草稿，不得写成“按 24% 合法”或“按旧四倍合法”。
5. 一年期 LPR 当次数值未核验：不编造百分比，用 `【合同成立时一年期 LPR × 核验所得倍数，待填】`。

### 5.3 费用并入

服务费、咨询费、通道费、会员费、逾期利息、违约金并行时，按费用总和审查，不得拆成“利息合法 + 费用另算”以规避上限。无核验不得输出唯一合法年利率数字。

## 节点 6　用途、期限、还款与加速到期

1. 用途必须具体。空白用途标必须改。出现赌博、吸毒、放高利、归还赌债、炒币配资等，追问出借人是否知情；知情或应知仍出借：效力红旗，停笔。
2. 期限必须有起止日或“自实际提供借款之日起【待填】个月”。未约定还款期限：修改句补期限或补催告后宽限期，不在本任务起算诉讼时效终点。
3. 还款方式、还款账户、提前还款是否免息或计补偿，分列。还款账户户名应与出借人一致。
4. 加速到期可以谈，但条件要可识别（逾期付息、逾期还本、明确的失信事件）。禁止把“出借人认为必要即可提前收回”无条件放行。
5. 律师费、保全费由违约方承担：未写则提示法院通常难以支持；修改句可补，但不保证必然判得。
6. 管辖或仲裁：或裁或诉、机构不明标待核，不改写成假装已选定的唯一法院。

## 节点 7　夫妻共债不得默认；保证方式不明按一般保证

### 7.1 夫妻共债（硬闸）

不得因下列任一事实写成已经构成夫妻共同债务：

- 借款人已婚；
- 文本打印“共同借款人：配偶”；
- 配偶知情、在场、收过钱但未签字；
- 用途写成生活、装修、家庭开支但无共签或追认，且金额是否属于家庭日常生活需要无法判断；
- 出借人单方陈述“肯定是两口子一起用的”。

核验后可引用的成立路径（须 `L#`）：夫妻双方共同签名；一方事后追认等共同意思表示；一方以个人名义为家庭日常生活需要所负债务。超出家庭日常生活需要的，不属于夫妻共同债务，除非债权人能证明用于共同生活、共同生产经营或基于共同意思表示。

出借人立场：可建议配偶作为共同借款人本人签署，或另签知情确认。这是增信谈判，不是把未签文本升级成已共债。

借款人或配偶立场：必须提示签字可能构成共同意思表示，扩张责任；代签、伪造配偶签名整体停止。

婚前个人债务、赌博吸毒所负债务：不得建议写成共同债务。

### 7.2 保证（硬闸）

保证方式没有约定或约定不明确：按照一般保证承担保证责任。一般保证人在主合同纠纷未经审判或仲裁，并就债务人财产依法强制执行仍不能履行债务前，有权拒绝承担责任（法定例外除外）。

| 文本写法 | 本任务认定 | 不得写成 |
| --- | --- | --- |
| “由某某担保/保证”“担保人：张某” | 方式不明 → 按一般保证审查 | 连带责任保证 |
| “不能履行/无力偿还时承担责任” | 一般保证 | 连带 |
| “不履行即承担”“无条件承担”“连带责任保证” | 可按连带表述审查 | 必然有效 |
| “保证至本息还清时为止” | 期间约定不明 → 主债务履行期限届满之日起六个月 | 保证期间两年或一直有效 |

保证人未签字、代签、只在见证栏出现：不成立保证字段，不得写成已提供保证。

公司或配偶仅在“担保人”栏出现：分清保证与共债，不互相推定。深度保证文本转 `保证借款合同·审查`。

禁止引用已失效规则：保证不明推定连带；保证期间默认两年。

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

打开已加载的 `框架.md`，按下列六步逐段对照正文。`基本面.md` 用于校验类型、主体、标的、程序、结构和红旗，不代替本节点出句。

| 步 | 动作 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题用借款合同而非单纯欠条；主体姓名证件；不把配偶未签写成共同借款人已成立 | 标题或主体修改句 |
| 交易条款 | 本金大小写、交付账户、成立时点、实际放款额、用途、书面利率、期限还款 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 逾期利息与费用总和待核验上限；加速到期；律师费；保证方式与期间；送达地址 | 可执行后果句；保证不明改一般或点名连带 |
| 尾部 | 本人签、指印；日期真实；附件含收款确认；禁止倒签 | 生效与附件修改句 |
| 语言 | 出借给 / 向……借款；今归还 / 尚欠；不写“今还欠款”；借条与收据分离 | 替换歧义句 |
| 常见问题 | 无交付安排、砍头息、高利面额、未共签却写共债、保证不明当连带 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止；
- `必须改`：可谈但签署前要落句；
