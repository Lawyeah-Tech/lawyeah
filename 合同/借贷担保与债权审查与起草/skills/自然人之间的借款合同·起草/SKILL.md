# 自然人之间的借款合同·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **借款合同 / 自然人之间的借款合同**，输出可编辑草稿、未决项、自审风险表与自审后修改句。有完整待签文本要评改时，转 `自然人之间的借款合同·审查`。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查或起草、待签文本评改、履约交底、争议文书、有效性或对方接受的保证、共债或保证责任的终局认定、利息精算终局数字。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿；尚未签署，尚未成争，双方均为自然人，核心给付是一方提供资金、另一方到期返还本金（可约定利息）。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 一方或双方为企业、农民专业合作社、其他组织，或核心给付是企业间拆借 → `企业间借款合同·审查`；
- 贷款人是商业银行、消费金融公司、小额贷款公司等持牌放贷机构或其分支机构 → `金融机构借款合同·审查`；
- 文本明显是买卖、租赁、投资入股且无自然人互借核心给付 → 本套导航的类型切开步骤 重新定性，或转对应场景原子；
- 主结构是保证借款、抵押借款、质押借款或让与担保 → `保证借款合同·审查` / `抵押借款合同·审查` / `质押借款合同·审查` / `让与担保型借款合同·审查`；本技能不把附带保证句整案做成保证专项；
- 有完整待签文本要评改 → `自然人之间的借款合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已成争（催告、解除、索赔、诉讼仲裁、违法催收）→ 合同争议或对应专项领域。

职业放贷、套取金融机构贷款转贷、明知违法犯罪用途仍出借：只出告知，不改写成可履行放贷结构。

## 本类型硬闸

1. **实践性**。自然人之间的借款合同自贷款人提供借款时成立。仅有签字、盖章或按指印，不得写成合同已经成立或借款人有权请求交付。修改句必须把成立时点落到实际提供借款，并分开“借贷合意”与“款项交付”。
2. **利率司法保护上限必须运行时核验**。禁止把银行同类贷款利率四倍、年利率 24%、年利率 36% 写成现行保护标准。禁止把记忆中的“四倍”直接当结论。`search_law` 核验现行口径后，方可引用核验所得规则；核验失败则利率法律结论字段停止。
3. **砍头息**。利息不得预先在本金中扣除。面额与实际交付不一致时，本金和计息基数按实际交付额，不得按面额放行。
4. **夫妻共债不得默认**。已婚、用于生活、配偶知情、合同打印“共同借款人”但配偶未签，均不得写成已经构成夫妻共同债务。
5. **保证方式不明按一般保证**。只写“担保”“保证”或约定不明，按一般保证审查，不得按已失效《担保法》推定连带。保证期间没有约定或约定不明，按主债务履行期限届满之日起六个月处理，不得写成两年。

## 建立审查坐标

确认：使用者与授权；单方立场（出借人 / 借款人 / 拟签字配偶或保证人）；相对方；全文及附件版本；双方是否均为自然人；本金、交付、利率、用途、期限；不可接受事项；法域与签署时限。缺立场或本类型条件未谈妥则不启动起草。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的本金、利率、期限、账户用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law`（法律结论 required）：核验实践性、砍头息、自然人利息约定不明、利率司法保护上限、逾期利息与费用总和、无效情形、保证方式与期间、夫妻共同债务。
- `search_practiced`（optional）：补现金交付、账户不一致、保证措辞争点。返回“保证不明即连带”或“24%/36%/银行利率四倍”时记噪声。
- `search_template`（optional）：只借栏目结构。范本写“签字盖章之日起生效”不得当成立规则。

不虚构案件系统。`search_law` 返回已失效《合同法》《担保法》及其解释、1991 年借贷意见、2015 年 24%/36% 条文时记为噪声，不得写入 `L#`。


## 起草模式

本原子只承担本类型起草。待签评改转 `自然人之间的借款合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。本类型硬闸改成正文必写、附件必附或禁止出现。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 双方均为自然人。
- 成立时点落到实际提供借款；分开“借贷合意”与“款项交付”。仅有签字、盖章或按指印，不得写成合同已经成立或借款人有权请求交付。
- 利率司法保护上限运行时核验后再写；核验失败则利率法律结论字段停止。
- 利息不得预先在本金中扣除；本金和计息基数按实际交付额。
- 有保证时方式必须显化；只写“担保”“保证”或约定不明按一般保证；保证期间无约定或不明按主债务履行期限届满之日起六个月。

### 附件必附

- 有保证人时：保证方式与保证期间显化条款。
- 主张夫妻共同债务时：配偶本人签署或追认。已婚、用于生活、配偶知情或合同打印“共同借款人”但配偶未签，不得当成已附。
- 无对应事实不编造附件，缺项写入未决项。

### 禁止出现

- 仅有签字即合同成立，或借款人有权请求交付。
- 银行同类贷款利率四倍、年利率 24%、年利率 36% 写成现行保护标准；记忆中的“四倍”直接当结论。
- 面额与实际交付不一致时仍按面额计息。
- 配偶未签写成已经构成夫妻共同债务。
- 保证方式不明按已失效《担保法》推定连带；保证期间不明写成两年。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口，不代替节点。

0. 签署状态与成果分流
1. 类型识别与单目录加载（双方自然人 + 资金互借）
2. 主体、行为能力、账户一致、资金来源
3. 实践性与交付闭环
4. 本金、砍头息、币种与大小写
5. 利息、费用与司法保护上限（运行时核验）
6. 用途、期限、还款与加速到期
7. 夫妻共债不得默认；保证方式不明按一般保证
8. 按框架六步出修改句

必须有修改句。禁止只打红黄绿。每个风险回链文本位置。禁止套用买卖合同的标的验收、定金百分之二十或挂靠改写节点。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；条件未谈妥仍要出可签署终稿；用户坚持伪造倒签、补假收条、包装职业放贷或转贷、把违法用途改成可履行文本、保证有效。
- `字段停止`：法域、利率上限、共债、保证方式/期间未核验；主体、本金或交付关键事实缺失。
- `目标停止`：主目标已变为待签评改、履约交底、催收文书或利息精算终局。

生存级金额或个人无限连带且用户拒绝升级：停止“可以签署”建议。
