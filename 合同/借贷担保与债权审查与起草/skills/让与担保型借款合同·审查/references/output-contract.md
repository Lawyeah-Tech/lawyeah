# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证合同有效、已经取得完整所有权、必然优先受偿或对方接受；编造未给出的本金、证号、回购价、利率、期限；把已失效《合同法》《担保法》《物权法》及其解释写入结论；把银行利率旧四倍、年利率 24% 或 36% 写成现行保护上限；把未过户写成合同未生效；把未完成权利变动公示写成已有优先受偿权；把流质写成可以过户归己；把本约改成可强制实际履行的真实买卖；把房产让与担保买卖或无过户结构的名其他实借贷留在本技能改完。

## 1. 触发、单方立场与成果状态

立场（出借人/名义买受人、借款人/名义出卖人、提供财产的第三人、拟签字共有人）、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明是否同时存在借款主给付和让与担保主结构，以及担保财产种类、是否拟办理过户或变更登记。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》《担保法》《物权法》及其解释、1991 年借贷意见、2015 年 24%/36% 条文时记噪声，不得写入 `L#`。名实、流质、清算、公示与优先受偿、合同效力分离、利率上限无 `verified-result` 时，对应法律结论字段停止。

## 3. 类型与加载路径

父级 `借款合同`，子级 `让与担保型借款合同`。定性理由必须同时满足：资金借贷；让与担保为主结构。易混切开：房产让与担保买卖主文件、无过户回购的名其他实借贷、抵押、质押、真实房屋买卖、金融机构监管条款主审。

加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读其他类型、未打开 `以房屋买卖网签过户或回购外观为借款提供担保→` 或普通借款 method。职业放贷、转贷、禁止流通财产包装、流质过户归己或假过户写停笔告知，不填可履行结构。

## 4. 主体、授权、资质与文本版本

主体表：出借人/名义买受人、借款人/名义出卖人、提供财产的第三人、共有人、配偶、承租人、保证人（如有）。自然人写姓名与证件号是否与文本一致；法人写名称与统一社会信用代码。

版本表：借款正文、买卖/转让协议、回购协议、权属证明、内部决议、放弃优先购买声明、放款凭证草稿、聊天确认。冲突并列，不选对用户有利的一版。口头“已经过户了”“配偶同意了”不得写成已公示或已同意。

## 5. 借款与让与担保给付闭环

分列并回链文本位置：

- 主债权：合同名称与编号、本金大小写、币种、履行期限、放款方式。
- 名实：鉴于是否锁定借款目的、转移为担保；三份或两份文本是否交叉引用。
- 担保财产：名称、坐落或识别码、权属、证号、是否禁止或限制转让。
- 名义价款：是否与本金冲抵；出借人是否另需支付购买价款。
- 公示：谁在几日内办理过户或变更登记；未完成是否仍允许放款。
- 合同效力与物权：是否把过户写成合同生效或已经取得完整所有权。
- 回购：期限、价款构成、清偿后返还或回过户义务、逾期违约金。
- 占有与风险：谁占有；毁损灭失风险是否仍由借款人承担。
- 实现：折价/拍卖/变卖优先受偿并多退少补，还是流质归己。
- 利息与费用：书面利率、回购溢价、费用是否并入上限审查。
- 处分限制：担保期间出借人不得转卖、抵押或清偿自身债务。

缺口标 `G#`，不补商业数字、证号或已过户事实。批准、过户、变更登记写成条件或双方义务期限，不写成已经完成。

## 6. 格式条款、强制规范与本类型效力红旗

职业放贷人或机构预先拟定且未协商的，按格式条款审查提示说明。自然人偶发互借通常不是格式条款。

强制规范与效力红旗只在核验后落法律结论：流质/归己所有；禁止流通财产过户；虚假意思表示的表面买卖；套取金融机构贷款转贷；未取得放贷资格而向不特定对象放贷；出借人事先知道或应当知道用于违法犯罪仍提供借款；公司对外让与担保未审查决议。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

不得把“让与担保因物权法定一律无效”或“整组合同因流质而全部无效”写成已核验结论。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔/转出口径。禁止输出无修改句的色块表。

本类型至少检查：名实未锁定或阴阳合同割裂；流质或视为放弃所有权；未约定清算或多退少补；把过户写成合同生效或把未过户写成已有优先受偿；回购无闭环；名义价款与本金未冲抵；利率/溢价未核验或疑似超过保护上限；共有人未签；承租人优先购买未弃权；居住权未核；公司决议未附；担保期间出借人可自由处分。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字、证号用 `【待填】`，不编造。禁止只给原则、不给句子。框架与硬闸冲突时按硬闸出句。

建议句必须覆盖本类型硬闸：鉴于与交叉引用锁定借款+担保；删除或改写流质；写入清算多退少补；合同生效与物权变动分列；未完成公示不得写成优先受偿；回购返还闭环；利率上限待核表述。

## 9. 谈判与签署提醒

谈判顺序：先红线（流质归己、禁止流通财产过户、伪造过户/决议、违法放贷、借名规避限购），再必须改（名实交叉引用、清算、过户义务、回购闭环、利率核验），最后可优化。

签署提醒：借款人、出借人与共有人本人签；公司决议、放弃优先购买声明作附件；权属证书原件核对；约定先完成约定公示后放款；日期真实。不指导倒签、补假过户或假同意。

出借人立场可建议完成过户或变更登记作为增信，但必须同时写明：未完成公示不得当成已有优先受偿权；即使已过户也不得自由转卖。借款人立场必须提示：签字和过户后，出借人是登记名义人，存在被转卖或被其债权人查封的风险。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本任务只出审查意见与修改句，不出整份起草终稿。无文本出稿转配对起草原子。不是履约交底、确认所有权诉讼文书、利息精算终局或效力保证。
