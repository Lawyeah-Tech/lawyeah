# 审查方法（锁定 保证合同 / 连带责任保证合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止把争议评估或融资放行原子正文抄进本任务。

定性校验：标题、核心给付与本类型一致才继续；一般保证、独立保函、安慰函、最高额、增信或借款主文件明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、保证责任必然消灭或唯一必得金额。

示范文本只参考结构。银行业协会或机构模板不证明本约条款已被接受。

知识库纠正（不回写双文件）：

- `基本面.md` 写“《公司法》第16条”：2023 年修订公司法对外担保程序在第十五条（2024-07-01 施行，现行有效）。担保制度解释、执行担保规定仍可能引用旧“第十六条”，运行时并列说明，结论条号以 2023 修订为准。
- `基本面.md` “主合同无效，保证合同必然无效”：改走民法典第六百八十二条——法律另有规定除外；无效后按过错担相应民事责任，不是当然免责。
- `基本面.md` 保证范围写“保管担保财产”：那是担保物权范围。保证范围按第六百九十一条为：主债权及其利息、违约金、损害赔偿金和实现债权的费用；另有约定除外。
- `框架.md` “本合同的效力独立于主合同”：担保制度解释第二条，普通保证中的独立性约定无效。不得当建议句，不得据此改成独立保函。
- `框架.md` “建议保证期间二年或三年”：只是债权人谈判口径，不是法定默认。无约定或约定不明按第六百九十二条为六个月。
- `框架.md` 最高额保证段落：本技能不审，转 `最高额保证合同·审查`。
- `框架.md` “将债务人与保证人作为共同被告”：争议策略，本任务不写。
- `基本面.md` “尽量要求配偶共同签署”：不是法定义务。债权人侧可作风险提示；是否共同债务转 `配偶是否共同债务`，本任务不认定。
- 本任务审查的是拟在民法典施行后签署的新文本。时间效力规定第二十七条只处理施行前已成立合同的期间过渡，不得用来给待签稿套旧担保法默认。

## 节点 3　主债特定与从属性

### 3.1 主债必须特定（硬闸）

支持依据：民法典第六百八十一条、第六百八十四条、第六百八十五条。

审查清单，缺一项则不得写成主债已特定：

1. 主合同名称或编号，且保证合同与主合同互相引用。
2. 主合同双方与保证合同记载一致。
3. 主债权种类、金额或可核验的确定方法。
4. 债务人履行期限；未约定则保证期间起算按第六百九十二条第三款，标待核。

| 文本写法 | 动作 |
| --- | --- |
| “为本公司一切债务／现在及将来全部债务提供连带保证”，无期间、无限额 | 不按本类型放行。若实为最高额，转 `最高额保证合同·审查`；否则红线，要求特定到具体主合同 |
| 主合同未附、编号空白、金额 `【待填】` 仍空白 | `G#`；不得出可签署意见 |
| 保证合同可以是单独书面合同，也可以是主合同中的保证条款；第三人单方书面保证且债权人接收未异议的，合同可成立 | 本任务仍要见到可读保证条款。单方承诺函若无代为清偿意思，转安慰函 |
| 主合同与备案合同、阴阳两份金额 | 并列，不选有利版；禁止改成可履行避税或规避监管结构 |

### 3.2 从属性与独立性条款

支持依据：第六百八十二条；担保制度解释第二条。

- 保证合同是从合同。主债权债务合同无效的，保证合同无效，但是法律另有规定的除外。
- 当事人约定担保合同效力独立于主合同，或约定担保人对主合同无效的法律后果承担担保责任：该独立性约定无效。
- 主合同有效的，独立性约定无效不影响担保合同其余部分；主合同无效的，认定担保合同无效，法律另有规定除外。
- 金融机构开立的独立保函，适用独立保函规定，本任务负触发。
- 非金融机构文本写“见索即付／效力独立”：不得改成独立保函。修改句删除独立性约定，恢复从属性；主合同无效后的责任只点名过错赔偿，不写成“仍按保证责任全额赔”。

框架里把独立性条款当作“强化债权人请求权”的建议：禁止采用。

## 节点 4　保证方式（硬闸）

支持依据：民法典第六百八十六条、第六百八十七条、第六百八十八条；担保制度解释第二十五条。运行时必须核验，不得用记忆中的旧担保法第十九条。

### 4.1 认定表

| 文本迹象 | 判断形状 | 本任务动作 |
| --- | --- | --- |
| 明确“连带责任保证”，且写“债务人不履行到期债务或发生约定情形时，债权人可请求债务人履行，也可直接请求保证人” | 现有依据支持按连带审查 | 继续；标题、鉴于、方式条款三处对齐 |
| “不能履行”“无力偿还”“经法院执行仍不能偿还”等，具有债务人应当先承担责任的意思 | 一般保证 | 负触发 `一般保证合同·审查`，不按连带改完 |
| 未写一般或连带；或标题连带、正文一般，冲突未消除 | 约定不明 → 按一般保证 | 不得写成已经是连带。债权人侧修改句显化连带责任保证并改“不履行”；保证人侧告知现状依法为一般保证 |
| 用户称“按老担保法，没写就连带” | 现有依据不支持 | 拒绝该口径；整体停止该字段的放行 |
| “无条件承担保证责任”“不履行即承担”且无债务人先行意思 | 可认定为连带 | 仍须补“连带责任保证”字样，避免再被争成不明 |

连带责任保证人不享有先诉抗辩权。文本不得再写入先诉抗辩或“须先执行债务人”。

### 4.2 语言闸

连带责任保证必须使用“不履行”或“未履行”，避免“不能履行”。正说还要有反说：债权人可以直接请求保证人，不以对债务人取得胜诉或执行依据为前提。

多名保证人：未约定份额的，债权人可请求任一保证人在其保证范围内承担责任（第六百九十九条）。修改句写清按份或连带共同保证；“保证人之间无追偿权”只在用户明确要放弃时写，不得当默认最佳实践。保证人承担责任后向债务人追偿（第七百条）可保留。

## 节点 5　保证范围与混合担保

### 5.1 范围

支持依据：第六百九十一条。未另约定时，范围包括主债权及其利息、违约金、损害赔偿金和实现债权的费用。

- 债权人侧：可用“包括但不限于诉讼费、仲裁费、律师费、保全费、执行费、评估费、公告费”作列举，但数字用 `【待填】` 或保持概括，不编造费率。
- 保证人侧：超主债范围的部分应限缩；“全额无限”标红旗。
- 超过主债务的部分，现有依据不支持保证人承担。不把“保管担保财产费用”塞进保证范围。

### 5.2 混合担保

支持依据：第三百九十二条。有约定从约定。无约定或约定不明：债务人自己提供物保的，债权人应先就该物保实现；第三人提供物保的，债权人可选择物保或保证。

- 债权人侧可谈判“无论是否存在债务人物保，债权人均有权直接请求保证人”，这是约定排除法定默认，必须显化。
- 不得把未约定写成“已经可以跳过债务人物保”。
- 债权人放弃债务人提供的物保：告知保证人可能在丧失优先受偿权益范围内免责；具体条号运行时核验，本任务不认定已经免责。

反担保：可建议保证人另签反担保，本任务不起草抵押质押整案。

## 节点 6　保证期间（硬闸，运行时核验）

支持依据（当次 `search_law` 写入 `L#`）：民法典第六百九十二条、第六百九十三条、第六百九十四条；担保制度解释第三十二条。最高额期间计算见解释第三十条，本任务遇最高额已转出。

规则形状（核验失败则效力字段停止，摘录和修改句草稿继续）：

1. 保证期间是确定保证人承担责任的期间，不发生中止、中断和延长。
2. 可以约定期间，但约定早于或与主债务履行期限同时届满的，视为没有约定。
3. 没有约定或者约定不明确的，保证期间为主债务履行期限届满之日起六个月。
4. 约定“直至主债务本息还清时为止”等类似内容，视为约定不明，期间为届满之日起六个月。
5. 主债务履行期限没有约定或约定不明的，期间自债权人请求债务人履行的宽限期届满之日起计算。
6. 连带责任保证：债权人未在保证期间请求保证人的，保证人不再承担保证责任。一般保证是未在期间内对债务人起诉或申请仲裁——本任务遇一般保证已转出。
7. 连带责任保证的诉讼时效，从债权人在期间内请求保证人之日起算。期间与时效必须分列，不得把三年时效写成保证期间。

| 文本写法 | 动作 | 不得写成 |
| --- | --- | --- |
| 明确“自主债务履行期限届满之日起【待填】年／月”，且晚于履行期限届满 | 可接受或可优化；核对是否早于届满 | 法定就是二年或三年 |
| 未写期间 | 必须改。说明现行默认六个月 | 担保法下二年；已经是三年 |
| “直至本息还清为止”“保证责任随主债存在而存在” | 必须改。视为约定不明＝六个月 | 视为约定了无限期或二年 |
| 框架建议的二年或三年 | 仅可作为债权人谈判句，须标明是约定不是法定 | 法律规定至少二年 |
| 分期履行未写起算 | 标待核；修改句可写“最后一期债务履行期限届满之日起”供谈判 | 已经按每期分别起算或已经按最后一期起算的终局结论 |
| 用户要本任务计算期间是否已经届满 | 目标停止，转保证责任评估 | 已经脱保／尚未脱保 |

解释第三十四条：期间届满后保证人在催收单上签字，原则上不恢复保证责任，除非成立新保证合同。本任务只作签署提醒：不要在含义不明的催收单上签字。不指导“签字起死回生”。

## 节点 7　变更、借新还旧、争议条款

### 7.1 主合同变更与转让

- 第六百九十五条：未经保证人书面同意，减轻债务的仍对变更后债务负责；加重部分不负责。变更履行期限未经书面同意的，保证期间不受影响。
- 第六百九十六条：债权转让未通知保证人的，对保证人不发生效力；约定禁止转让而未经书面同意的，对受让人不再承担。
- 第六百九十七条：债务转移未经书面同意，对转移部分不再承担。

修改句：主合同变更、展期、借新还旧、债务加入须事先书面通知并征得保证人同意，否则保证人仅在原范围内或依法免责。不在本任务认定已经免责。

### 7.2 借新还旧

支持依据：担保制度解释第十六条。

新贷还旧贷：旧贷担保人不当然转承。新贷担保人与旧贷相同的，债权人请求新贷担保人，现有依据通常支持；担保人不同或旧贷无担保的，原则上不支持，但债权人能证明新贷保证人知道或应当知道借新还旧的除外。

审查动作：主合同或沟通记录出现借新还旧、以贷还贷、转贷，必须在保证合同中书面披露，并由保证人确认知道该事实。未披露：债权人侧红线补告知；保证人侧标重大抗辩线索，不写成已经免责。

### 7.3 争议解决：改写法，不审策略

出现仲裁条款：不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核，改成单一仲裁机构或单一法院连结点。专属管辖可能：只标红旗，不选定唯一法院充作法律意见。

用户继续追问请求、证据、时效怎么卡、共同被告、胜率：目标停止，转争议或 `或`。

通知送达：可约定邮寄至载明地址第 X 日视为送达。不得把微信已读写成已经送达的唯一充分条件。

保证人可主张债务人的抗辩（第七百零一条）；债务人对债权人享有抵销或撤销权的，保证人可在相应范围内拒绝（第七百零二条）。签前只保留抗辩不被预先放弃的修改句。全面放弃法定抗辩：保证人侧红线。
