# 连带责任保证合同·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **保证合同 / 连带责任保证合同**，输出可编辑草稿、未决项、自审风险表与自审后修改句。有完整待签文本要评改时，转 `连带责任保证合同·审查`。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文名必须是「审查连带责任保证合同（保证合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类合同审查或起草；待签文本评改；履约交底；争议文书或行权策略；有效性保证；把约定不明写成已经是连带责任保证。

## 本类型硬闸

1. **必须写明连带责任保证**。标题、鉴于和保证方式条款须同时出现“连带责任保证”，触发条件用“不履行”或“未履行”，并写明债权人可直接请求保证人。
2. **约定不明按一般保证**。对保证方式没有约定或约定不明确的，按民法典第六百八十六条按一般保证承担保证责任。禁止把原《担保法》第十九条“约定不明=连带”当作现行规则。
3. **保证期间须运行时核验现行条**。无约定、约定不明或“直至主债务本息还清时为止”等类似内容，按现行规则视为六个月，不得写担保法解释“约定不明=二年”。条号与效力以当次 `search_law` 为准。
4. **主债必须特定**。须能回链主合同名称或编号、双方、金额或确定方法、履行期限。概括“一切债务”而无期间和限额的，不得按本类型放行。
5. **独立保函、安慰函负触发**。见索即付、相符交单、金融机构开立的独立保函，或仅表达知晓、督促、维好而无代为清偿意思的安慰函，不按本类型改完。
6. **一般保证文本负触发**到 `一般保证合同·审查`。出现“不能履行”“无力偿还”“先诉抗辩”或标题即为一般保证的，不按连带改完。
7. **不保证有效，不审争议策略**。已成争转出。禁止把独立性条款改成可履行的独立保函结构。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿；尚未签署，尚未成争，核心给付是第三人为已特定主债提供连带责任保证，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 一般保证、先诉抗辩或“不能履行”为核心 → `一般保证合同·审查`；
- 最高额、一定期间连续发生、最高债权额限度 → `最高额保证合同·审查`；
- 独立保函、见索即付、URDG / 相符交单 → `独立保函·审查`（专业版未装则 `unavailable`，提示，不得用本技能硬套）；
- 安慰函、维好协议、仅“知晓／督促／尽合理努力” → `安慰函·审查`（未装则 `unavailable`）；
- 差额补足、流动性支持、回购承诺等增信主轴 → `增信措施类保证合同·审查`（未装则 `unavailable`）；
- 主文件是借款，保证只是从条款 → `保证借款合同·审查` 或对应借款场景原子；
- 有完整待签文本要评改 → `连带责任保证合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点或行权日历 → 本套导航的履约步骤；
- 已催告、索赔、立案、开庭、仲裁，或主问保证责任是否消灭 → `或` 或 `或`。

机关法人、公益性主体违规保证，或伪造决议、倒签：只出告知，不改写成可履行规避结构。

## 建立审查坐标

确认：使用者与授权；单方立场（债权人 / 保证人 / 债务人择一）；相对方；全文及附件版本；主合同文本或要点；保证方式原句；保证期间原句；保证范围；公司决议或授权；不可接受事项；法域与拟签署日。缺立场或本类型条件未谈妥则不启动起草。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的金额、期间、主合同编号用 `【待填】`，不编造。

## 起草模式

本原子只承担本类型起草。待签评改转 `连带责任保证合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。本类型硬闸改成正文必写、附件必附或禁止出现。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 标题、鉴于和保证方式条款同时出现“连带责任保证”。
- 触发条件用“不履行”或“未履行”，并写明债权人可直接请求保证人。
- 主债特定：主合同名称或编号、双方、金额或确定方法、履行期限。
- 保证期间写清；无约定、不明或“还清为止”按六个月。

### 附件必附

- 主合同或可回链的主债要点。
- 无对应事实不编造附件，缺项写入未决项。

### 禁止出现

- 对保证方式没有约定或约定不明确仍按连带落稿；原《担保法》第十九条。
- 出现“不能履行”“无力偿还”“先诉抗辩”或标题为一般保证仍按连带改完。
- 见索即付、相符交单、独立保函，或仅知晓、督促、维好而无代为清偿意思的安慰函，按本类型改完。
- 概括“一切债务”而无期间和限额仍按本类型放行。
- 独立性条款改成可履行的独立保函。
- 法定期间二年；保证一定有效。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`基本面.md` 中“公司法第六条／第十六条”按 method 改走 2023 年修订公司法现行条；“主合同无效则保证必然无效”按第六百八十二条留“法律另有规定除外”和过错责任。`框架.md` 中独立性条款、最高额段落、诉讼共同被告策略，按 method 当作审查风险或禁止建议，不当作默认改法。

### 0. 签署状态与成果分流

无书面文本、条件已谈妥 → 留本任务起草；已签履约 → 本套导航履约步骤；已成争或主问责任消灭 → 争议或 `或`。有完整待签文本要评改时转 `连带责任保证合同·审查`。本类型条件已谈妥、要出己方稿，才进入本任务。

### 1. 类型锁死

标题、核心给付与连带责任保证一致才继续。一般保证、独立保函、安慰函、最高额、增信、借款主文件负触发。

### 2. 主体、禁入与决议

保证人是否机关或公益性主体；公司对外担保决议与章程限额；分支机构授权；自然人生存级无限连带。口头“老板同意了”不得写成已授权。

### 3. 主债特定与从属性

主合同名称编号、金额、履行期限必须可回链。独立性约定按现行解释无效，不得改成独立保函。

### 4. 保证方式

必须写明连带责任保证；“不能履行”切开到一般保证；约定不明按一般保证，不按旧担保法推定连带。

### 5. 保证范围与混合担保

范围可核对主债、利息、违约金、损害赔偿和实现债权费用。物保加保证未约定顺位的，标法定默认，不擅自选定。

### 6. 保证期间

运行时核验现行条。无约定、不明或“还清为止”按六个月处理并出修改句。分期履行起算标待核，不编造。

### 7. 变更、借新还旧与争议条款

主债加重或展期须书面同意；借新还旧须告知保证人。争议条款只改单一连结点，不写起诉策略或共同被告方案。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；条件未谈妥仍要出可签署终稿；用户坚持倒签、伪造决议、把机关或公益主体改成可履行保证人、把独立性条款改成独立保函、按旧担保法把约定不明写成连带、保证有效。
- `字段停止`：法域、动态规则、决议真伪、主债金额或履行期限未核验。
- `目标停止`：主目标已变为待签评改、履约交底、争议文书或保证责任评估。

生存级金额或自然人无限连带且用户拒绝升级：停止放行建议，只列风险与转介。
