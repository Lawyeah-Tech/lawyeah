# 边界与路由

本技能只审查 **借款合同 / 金融机构借款合同**。

出借人必须是持牌金融机构或其分支机构。标题叫“金融机构借款合同”但贷款人无金融许可证、经营范围不含贷款的，不得留在本技能做实体结论，也不得改写成“视同银行”。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或标题借款、核心给付明显不是持牌机构放贷 | 本套导航的类型切开步骤 |
| 双方自然人互借，贷款人不是持牌机构 | `自然人之间的借款合同·审查` |
| 非持牌民间借贷、职业放贷、投资公司放贷 | `广义民间借款合同·审查` 或 `狭义民间借款合同·审查`；禁止包装成本技能 |
| 企业互借、资金占用费，出借人无贷款牌照 | `企业间借款合同·审查` |
| 主结构为不动产/动产抵押借款，登记或流押主导放行 | `抵押借款合同·审查` |
| 主标题或主结构为保证借款 | `保证借款合同·审查` |
| 主结构为权利或动产质押 | `质押借款合同·审查` |
| 买卖/过户/回购为还款担保，或让与担保 | `让与担保型借款合同·审查`；专业版未收录该 P1 时输出 `unavailable`，不得硬套本技能改成可过户结构 |
| 名为投资、合伙、理财，固定回报且出借人非持牌 | 引擎或民间/企业间原子；不按银行稿审 |
| 无文本、本类型条件已谈妥、要出己方稿 | `金融机构借款合同·起草` |
| 已签未争、问放款日、还本付息、贷后检查 | 本套导航的履约步骤 |
| 已成争、不良清收、诉讼仲裁 | 合同争议领域或金融专项；不写催收函、起诉状 |
| 用户只要利息或罚息复利精算终局数字 | 测算技能或人工精算；本技能只审条款 |
| C 端大众快检 | 只分流，不回改 |

附带保证、抵押或配偶签字栏时：本技能只审对本约放行的影响（担保合同是否被引用、未落实能否放款），不展开抵押登记或保证方式专项。深度担保文本转对应原子。

无证放贷、转贷、违法用途、职业放贷包装：停笔告知，不改写成可履行放贷文本。
