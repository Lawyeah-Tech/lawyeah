# 审查方法（锁定 借款合同 / 金融机构借款合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止套用买卖合同的标的验收、定金比例、挂靠改写或工程分包节点。禁止把本技能写成自然人互借换标题，禁止把 679 实践性或抵押物流押/登记写成主路径。

定性校验：出借人是持牌金融机构，且核心给付是资金借贷，才继续；明显他类则负触发，不填十节实体结论。

本文件是可执行判断节点，不是栏目说明书。每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、未放款即未成立，或唯一必得本息。

`search_law` 返回已失效《合同法》借款章、《借款合同条例》、1991 年《关于人民法院审理借贷案件的若干意见》、2015 年民间借贷司法解释中 24%/36% 条文时记为噪声，不得写入 `L#`。`search_practiced` 仍写“银行贷款也适用 LPR 四倍”“未放款则合同未成立”“人民银行同期贷款利率四倍”的，同样记噪声。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

示范文本只参考结构。写“自放款之日起合同成立”的范本与本类型诺成默认冲突，不得当法定成立规则。

知识库口径冲突以本方法为准，不回写知识正文：

- `基本面.md` 写“参照适用民间借贷合同的有关规定”：纠正为适用民法典借款合同章及金融监管规则；法释〔2020〕17 号第 1 条明确持牌机构发放贷款纠纷不适用该解释。第 25 条四倍仅作负向。
- `基本面.md` 把证券公司列为默认贷款人：券商一般不得经营贷款，不得默认适格。
- `基本面.md` 仍写“三个办法一个指引”、变相费用“受利率上限规制”：2024-07-01 起核验金监总局流动资金/固定资产/个人贷款管理办法；不得把民间四倍写成银行上限。
- 不得把第 679 条写成金融机构借款的成立规则。

## 节点 0　签署状态与成果分流

先于类型识别。命中任一项则本任务不填十节实体结论，只交付分流理由和最小交接。

| 已能支持的事实 | 走向 | 不得写成 |
| --- | --- | --- |
| 无可读正文和附件，或只有口头交易要点，本类型条件已谈妥、要出己方稿 | 进入本任务起草 | 已经完成审查 |
| 未签，目标是评改已有文本 | `金融机构借款合同·审查` | 本任务出审查意见 |
| 残缺模板，用户要按己方条件重写整稿 | 进入本任务起草 | 转审查原子评改残稿 |

| 用户只要应付利息或罚息复利的终局数字 | 测算或人工精算 | 本任务输出唯一应付额 |

## 节点 1　类型识别与单目录加载

### 1.1 定性

用出借人主体属性、核心给付和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须同时满足才正触发：

1. 出借人（贷款人）是经金融监管部门批准设立、持有金融许可证（或现行等效许可）且经营范围含贷款的金融机构或其分支机构。
2. 核心给付是贷款人提供货币资金，借款人到期返还本金并支付利息。

必须切开，禁止两可时灌入两套知识：

| 信号 | 归入 | 本技能动作 |
| --- | --- | --- |
| 商业银行、政策性银行、消费金融、信托、财务公司、金融租赁、汽车金融，或依法获批经营贷款的地方金融组织 + 贷款合同 | 本类型 | 加载本目录双文件 |
| 双方自然人互借，贷款人无牌照 | `自然人之间的借款合同·审查` | 负触发；不套本技能先决条件 |

| 企业互借、资金占用费，无贷款牌照 | `企业间借款合同·审查` | 负触发 |

| 固定回报投资/合伙且出借人非持牌 | 引擎或民间/企业间 | 负触发；不按银行稿审 |
| 移转标的物所有权换价款 | 买卖类场景原子 | 负触发 |

本技能已锁定 **借款合同 / 金融机构借款合同**。只打开 `references/基本面.md` 与 `references/框架.md`。禁止读其他类型目录，禁止为对照再开第二类。

### 1.3 无证放贷与违法结构停笔

加载后或定性中出现：无金融许可证却以银行名义放贷、职业放贷包装成“金融机构”、套取信贷资金转贷牟利、明知赌博吸毒或流入股市/违规房市仍要求改成可履行、指导伪造许可证或倒签放款。

1. 交付告知：该结构可能违反强制性规定或金融监管，不得改写成可履行放贷文本。
2. 不写假许可证、假用途、假受托支付路径。
3. 风险表只保留识别依据和转出/改道提示。
4. 用户坚持“改到能签、能转贷、能进股市”：整体停止。

合规改道（改为持牌机构真实放贷、停止转贷、改合法用途）只点名，不在本任务起草。

## 节点 2　主体、许可证、分支授权与借款人资格

1. 建主体表：贷款人（总行/分行/支行）、借款人、指定收款人或受托支付对象、引用中的担保人。名称不一致不自动合并。
2. **许可证硬闸**。材料或文本须能指向：金融许可证（或现行等效许可）+ 营业执照经营范围含贷款。未出示：该适格字段停止，不得写成“已经是金融机构”。投资咨询、担保、保理、普通公司：回到节点 1 负触发，禁止包装。
3. 分支机构签约：核授权范围。支行对外放贷权限未附授权或超授权：字段停止，修改句要求作为附件；不得写成“支行印章即充分授权”。
4. 借款人：法人核名称、统一社会信用代码、存续；自然人核行为能力。房地产开发贷款等特殊品种：行业资质未附则字段停止，不默写已过时的“四三二”为现行放行条件，运行时核验。
5. 证券公司、保险公司、理财公司出现在贷款人栏：不得默认有贷款资格；经营范围不含贷款则负触发或字段停止。
6. 口头“我们是持牌的”“总行已经批了”不得写成已持牌或已审批。

不足：字段停止，列出待补材料，不补主体、不补许可证。

## 节点 3　诺成成立、先决条件与提款（成立硬闸）

金融机构借款一般是诺成合同：双方意思表示一致（通常书面签署）时成立，不以交付为成立要件。民法典第 679 条只约束自然人之间的借款，不得写入本类型法定默认。

核验后可引用的判断点（须 `search_law` 写入 `L#` 再落法律结论）：

- 借款合同应当采用书面形式（自然人另有约定除外，本类型不适用该例外）。
- 贷款人未按照约定的日期、数额提供借款造成损失的，应当赔偿损失。
- 借款人未按照约定的日期、数额收取借款的，仍按照约定的日期、数额支付利息。

上述第 671 条以合同已经成立为前提。把“未放款则合同未成立”写成法定默认，会消解迟延放款责任，也消解借款人依约请求提款的基础。

| 文本写法 | 本任务动作 |
| --- | --- |
| “本合同自双方签字盖章之日起成立并生效” | 可接受为诺成默认。若另有先决条件，拆成：合同成立；放款义务在先决条件成就后发生 |
| “本合同自放款之日成立/未放款视为未成立” | 必须改。除非当事人明确另有约定且已提示；即使另有约定，也不得写成第 679 条的法定效果 |
| 先决条件空白，却写“银行有权随时决定是否放款且无需理由” | 必须改。补可核验的先决条件（决议、担保手续、未发生违约、提款申请），未成就则中止放款，不否定合同成立 |
| 提款期、提款申请、单笔限额未写 | 标 `G#`；修改句补期限、申请格式、未提部分是否自动取消 |
| 用户要求把未放款写成依法未成立，以逃避放款义务 | 整体停止该结论 |

内部信贷审批写成生效条件或放款先决，不写成已经批准。用户要求倒签批准日或放款日：整体停止。

## 节点 4　本金、到账与砍头息

1. 本金必须同时有阿拉伯数字与大写，并写明币种。不一致并列，修改句写明以大写或借款凭证孰为准，不擅自改数。授信额度须区分总额、循环与否、单笔提款。
2. **砍头息硬闸**。利息预先在本金中扣除的，应当按照实际借款数额返还借款并计算利息。
3. 下列写法按预扣或变相预扣处理，本金改到实际到账额：

   - 合同写 1000 万，条款写“先行扣除利息/保证金/咨询费/通道费后支付”；
   - 面额与提款通知、放款凭证不一致；
   - “账户监管保证金”在放款当日从本金扣留且不独立结算、不可退还。

4. 修改句固定锁到账与提款：`本合同项下借款本金以贷款人实际划付并到达约定账户（受托支付则为交易对手账户）的金额为准；预先扣除的利息、保证金、咨询费不计入本金，不计收该部分利息。提款以先决条件成就且【待填】日内足额到账为准。`
5. 禁止把面额本金写成已可请求的全部债权。借款凭证与合同冲突：并列，修改句指定以何者为准。

## 节点 5　利率、罚息、复利（监管口径硬闸）

### 5.1 定价必须写清

金融机构贷款利率通常为 LPR 加减基点，或合同载明的固定年利率。必须写明：基准（一年期/五年期以上 LPR）、加减点、重定价日、结息方式。仅写“按银行规定”“按政策利率”视为必须改。

贷款类产品应明示年化利率。内部收益率、日利率、费前利率并存时并列，修改句要求换算为年化并单独提示。

### 5.2 禁止套用民间上限

禁止直接输出下列口径作为银行贷款现行上限：

- 法释〔2020〕17 号第 25 条：合同成立时一年期 LPR 四倍（民间借贷规则，第 1 条已排除持牌机构）；
- 年利率 24%、年利率 36%（2015 年民间借贷口径）；
- 银行同类贷款利率四倍（1991 年意见口径）。

动作：

1. 先确认贷款人属于法释第 1 条或法释〔2020〕27 号范围内的持牌放贷机构。是：利率法律结论走金融监管核验（商业银行法第 38 条、央行/金监规则、合同约定的 LPR 公式）。否：回到节点 1 负触发。
2. 调用 `search_law` 核验“金融机构贷款利率监管 现行规定”以及“民间借贷司法解释是否适用于金融机构”。仅当返回现行有效规则时写入 `L#`。
3. 开发窗口 2026-08-18 核验结果（供对照，不得代替运行时核验）：法释〔2020〕17 号第 1 条第 2 款，持牌机构发放贷款纠纷不适用该规定；第 25 条不得作为银行上限。商业银行应当按照人民银行规定的贷款利率上下限确定利率。具体加减点、罚息上浮比例以合同加现行监管规则为准，不编造百分比。
4. 核验失败：利率是否“合法上限内”的法律结论字段停止。仍可摘录文本公式并给出“待核验监管口径后改写”的修改句草稿。
5. 当次 LPR 未核验：不编造数值，用 `【合同约定重定价日的相应期限 LPR ± 约定基点，待填】`。

### 5.3 罚息、复利与费用

罚息（如在执行利率基础上上浮一定比例）、复利、违约金、咨询费并行时：

- 摘录计算基数、上浮幅度、是否对欠息计复利。
- 不得默写可以叠加或不得叠加。监管或合同有核验引文再落结论。
- 个别法院曾按 2017 年金融审判政策对息费总和作 24% 调减：只标为反方/调减争点，运行时核验，**不得写成现行法定上限**。
- 借款人立场：修改句要求明示年化、分别列示罚息与复利、限制重复计收。贷款人立场：可保留合同公式，但须补提示说明，并提示过高息费被调减的争点，不保证必然判得。

## 节点 6　用途、支付方式与转贷

1. 用途必须具体到可核查（采购某类原材料、支付某项目工程款、置换某笔编号贷款）。只写“周转”“经营需要”标必须改。
2. **禁止用途**（监管口径，运行时核验）：证券投资、期货投机、违规房地产、股权投资或股东分红（流动资金贷款）、国家禁止生产经营的领域、转贷牟利。正说加反说都要落句。
3. **受托支付 / 自主支付**必须写清：适用哪种；受托支付的交易对手、金额、资料；自主支付的例外条件（个人贷款监管有金额门槛，运行时核验，不默写）。支付方式空白视为必须改。
4. 借款人要把用途改成“可以进股市、转借赚差价、过桥给第三方”：红线告知。转贷合同可能无效，本任务不改成可履行高利转贷。
5. 未按约定用途使用：核验后可点名停止发放、提前收回或解除（第 673 条）。修改句把该救济绑到可识别的挪用事实和催告/通知程序，不写成无需任何事实的随时收回。

## 节点 7　格式条款、加速到期；担保只审引用

### 7.1 格式条款与提前到期（硬闸）

银行借款合同通常为贷款人预先拟定、重复使用、订立时未协商，按格式条款审查。

须显著提示并按要求说明的异常条款至少包括：加速到期、交叉违约、单方调整利率或费用、账户扣划、提前还款补偿、管辖、免责或限责。仅有目录加粗、网络勾选或弹窗：不得写成已尽提示或说明义务。提供方对其已尽提示或说明承担举证责任。

| 文本写法 | 本任务动作 |
| --- | --- |
| “贷款人有权随时提前收回全部贷款，无需理由、无需通知” | 红线或必须改。改为：发生合同列明的违约事件（支付违约、用途挪用、交叉违约达到【待填】门槛等）且经【待填】日书面催告未纠正的，可以宣布加速到期 |
| 交叉违约扩到“任何第三方任何金额” | 必须改。补金额门槛、宽限期、是否限于金融债务 |
| “贷款人可单方调整利率，调整后立即生效” | 必须改。绑定期 LPR 重定价公式，或重大市场变动时书面通知+异议期；禁止无标准调价 |
| “有权从借款人任何账户扣划且视为借款人同意” | 必须改。限定为本合同欠款、已到期或已合法加速的款项，并通知；显著提示 |
| 用户要求保留无催告无违约事件的随时收回 | 整体停止该条放行 |

### 7.2 担保引用闭环（不是抵押主审）

本约出现保证、抵押、质押时：

1. 只检查：是否写明担保合同名称与编号、担保人、担保范围是否指向本合同项下本息及约定费用、未签署或未登记时能否放款。
2. 不展开流押、登记设立、保证方式推定。这些是 `抵押借款合同·审查` / `保证借款合同·审查` / `质押借款合同·审查` 的主路径。
3. 抵押/保证条款已长到主导放行（财产特定化、流押、登记义务占正文主体）：负触发对应原子。
4. 不得把担保引用缺失写成“已经有足额担保”。

公司为他人担保未附决议：字段停止，修改句要求作为附件且未获批准不放款。不在本任务认定担保已生效。
