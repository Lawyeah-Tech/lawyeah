# 边界与路由

本技能只审查 **借款合同 / “名为其他合同，实为借贷” 的合同**。

必须同时读出：外观不是借款（投资、合伙、合作开发、融资租赁、咨询服务、设备买卖等），以及还本付息实质（提供资金、到期返还本金、固定或保底回报、出资方不承担经营风险）。标题已是借款、或过户担保才是主结构的，不得留在本技能做实体结论。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或无法判断是伪装借贷还是真投资/真买卖 | 本套导航的类型切开步骤 |
| 主文件是借款/借据；过户、回购或不清算归己是担保主结构；财产或股权先转到债权人名下再借款 | `让与担保型借款合同·审查`；专业版未收录该 P1 时输出 `unavailable`，不得硬套本技能改成可过户结构 |
| 房屋买卖、网签、过户或回购外观为借款提供担保 | `以房屋买卖网签过户或回购外观为借款提供担保→` |
| 真实移转所有权换价款，无还本付息意思 | 买卖类场景原子 |
| 真实股权投资或合伙：共担风险、参与经营、退出价格随业绩浮动 | 引擎或对应投资/合伙原子 |
| 标题已是借款，无伪装主结构 | `狭义民间借款合同·审查` / `自然人之间的借款合同·审查` / `企业间借款合同·审查` / `金融机构借款合同·审查` |
| 已标明借款，保证/抵押/质押是主结构 | `保证借款合同·审查` / `抵押借款合同·审查` / `质押借款合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `名为其他实为借贷·起草` |
| 已签未争、问放款、回购、撤销登记或付款日 | 本套导航的履约步骤 |
| 已成争 | 合同争议领域或对应专项；不写起诉状或过户申请 |
| 用户只要利息终局数字 | 测算技能或人工精算；本技能只审条款 |
| C 端大众快检 | 只分流，不回改 |

同一交易既有伪装投资文本，又另有独立《借款合同》加过户担保：按**送审主文件**切开。主文件是借款加让与担保 → `让与担保型借款合同·审查`。主文件是投资/合伙/租赁/咨询伪装 → 留本技能，过户条款只标红旗并提示并行 `让与担保型借款合同·审查`，不得在本技能改成可过户履行。

房屋与非房屋：有特定房屋网签或过户作担保 → `以房屋买卖网签过户或回购外观为借款提供担保→`。无房的设备买卖、价款实为拆借、标的物自始不存在或仅作资金通道 → 留本技能穿透。

职业放贷、转贷、违法用途、虚构租赁物、流质改过户、把阳合同改成可强制入股或可强制买卖：停笔告知，不改写成可履行文本。
