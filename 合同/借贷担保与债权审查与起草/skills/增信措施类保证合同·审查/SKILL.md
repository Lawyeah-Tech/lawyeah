# 增信措施类保证合同·审查

## 任务目标

在单一立场下，只审查 **保证合同 / 增信措施类保证合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查增信措施类保证合同（保证合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类合同审查；从零起草；履约交底；争议文书或行权策略；有效性保证；把无代偿意思的安慰函按保证放行；把见索即付独立保函按本类型改完；把普通单笔保证或最高额保证换皮成交差。

## 本类型硬闸

1. **增信是否构成保证（四层）**：不看标题。第三人向债权人出具差额补足、流动性支持等类似承诺的，按担保制度解释第三十六条：有提供担保的意思 → 依照保证规定处理；有加入债务或与债务人共同承担债务的意思 → 民法典第五百五十二条债务加入；前两层难以确定 → 认定为保证；都不符合 → 不得按保证或连带责任请求，但不影响依承诺文件请求履行约定或承担相应民事责任。
2. **差额补足／流动性支持／回购必须分型**：先写清付给谁、触发事件、计算公式、核算主体、划款时限。补给**债权人**应付未付 → 更接近保证。只向**债务人**拆借、增资或“输血”，债权人不能直接请求付款 → 可能只是对债务人的合同义务，落入第三十六条第四款，不得写成债权人已取得保证请求权。回购以逾期或兑付失败为触发、对价覆盖未偿本息 → 按增信路径审，不得假装已是普通资产买卖。
3. **与安慰函／独立保函切开**：仅“知悉、督促、协助、关注、尽力确保、视情况支持、原则上同意” → `安慰函·审查`。见索即付、URDG／ISP98、相符交单、单据加最高金额 → `独立保函·审查`。已特定单笔主债且文本就是一般保证或连带责任保证 → `一般保证合同·审查`／`连带责任保证合同·审查`。最高债权额 + 一定期间连续发生 → `最高额保证合同·审查`。同一文本借款主从一体 → `保证借款合同·审查`。
4. **功能主义决议**：只要落入保证，或按解释第十二条参照公司对外担保规则的债务加入，就必须按对外担保标准核决议。改名“差额补足／流动性支持／回购”不能免决议。公司法条号用 2023 年修订第十五条。为股东或实控人须股东会且关联回避。上市公司还要核公开披露（解释第九条）。解释第八条是三种决议抗辩例外，**不是**“代为清偿”的定性条文。
5. **禁止主体停笔**：机关法人、地方政府及其所属部门、居委会村委会、以公益为目的的非营利法人出具增信：只出告知，不改成可履行保证。预算法第三十五条第四款：除法律另有规定外，地方政府及其所属部门不得为任何单位和个人的债务以任何方式提供担保。
6. **保证期间与方式仍须显化**：一旦定性为保证，未约定或约定不明的保证期间按第六百九十二条为主债务履行期限届满之日起六个月；“还清为止”按解释第三十二条视为六个月。方式不明按第六百八十六条一般保证。不得写成“增信没有保证期间”“增信当然连带”。
7. **从属性不得靠改名脱钩**：定性为保证后，约定担保效力独立于主合同或对主合同无效后果承担担保责任的，该独立性约定按解释第二条无效。不得把框架“无论基础交易效力如何均独立补偿”写成已核验必然有效，也不得改成独立保函。知识库“双重定性跳出从属性”只作谈判风险提示，不得当放行理由。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

禁止表述：标题不叫保证就不是保证；差额补足当然是保证；增信当然连带；增信没有保证期间；改名即可免决议；脱钩条款必然有效；无效一律只赔二分之一；保证一定有效。

## 工作边界

正触发：已有可读待签文本要评改，尚未签署，尚未成争，核心给付是第三人向债权人出具差额补足、流动性支持、回购承诺或类似增信安排，需要先判断是否构成保证；用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 已特定单笔主债，文本就是一般保证或连带责任保证，无增信产品结构 → `一般保证合同·审查` 或 `连带责任保证合同·审查`；
- 最高债权额 + 一定期间连续发生的债权 → `最高额保证合同·审查`；
- 独立保函、见索即付、URDG／相符交单 → `独立保函·审查`（专业版未装则 `unavailable`，提示，不得用本技能硬套）；
- 安慰函、维好协议、仅“知晓／督促／尽合理努力” → `安慰函·审查`（未装则 `unavailable`）；
- 同一文本是单笔借款加保证，主从一体 → `保证借款合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `增信措施类保证合同·起草`；
- 已签只问履约节点、补足通知或划款日历 → 本套导航的履约步骤；
- 已催告、索赔、立案、开庭、仲裁，或主问保证责任是否消灭、怎么起诉、共同被告怎么列 → `或` 或 `或`。

机关、政府、公益性主体违规增信，或伪造决议、倒签、规避监管／预算法：只出告知，不改写成可履行规避结构。

## 建立审查坐标

确认：使用者与授权；单方立场（债权人／出具方／债务人择一）；相对方；全文及附件版本；标题与强／弱增信原句；付给谁；触发事件与差额／回购计算公式；是否约定保证期间、保证方式、追偿；公司决议是否覆盖该增信事项；出具方是否机关、政府、公益或金融机构；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

### 0. 签署状态与成果分流

无书面文本 → `增信措施类保证合同·起草`；已签履约 → 本套导航履约步骤；已成争或主问责任消灭／起诉策略 → 争议或 `或`。未签且目标是评改已有增信文本，才进入本任务。

### 1. 类型锁死与邻接切开

标题、核心给付是差额补足／流动性支持／回购承诺或类似增信安排才继续。安慰函、独立保函、单笔保证、最高额、保证借款同文本负触发。

### 2. 解释第三十六条四层定性

先摘强／弱增信词和义务顺位，再落入保证、债务加入、不明按保证、或第四款合同义务。不得两可灌入两套知识。

### 3. 三种产品分型

差额补足、流动性支持、回购承诺分别写清付给谁、触发、公式、通知与时限。流动性支持不得默认等于保证。

### 4. 主体、禁入与决议

禁止主体停笔。公司决议必须覆盖该增信事项、对象和额度。债务加入参照解释第十二条。上市公司看披露。

### 5. 落入保证后的方式、期间、范围

686、692、解释 32、691。不得假装无期间或当然连带。

### 6. 落入债务加入或第四款后的路径

552 连带债务；无保证期间红利；决议仍可能参照担保规则。第四款只审约定义务是否可履行，不写成保证请求权。

### 7. 从属性、脱钩与无效后果

解释 2 删除独立性用语。解释 17 分层，不得写一律二分之一。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。定性句、产品分型句、决议句不得省略。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、伪造决议、把机关或公益或政府主体改成可履行保证人、把弱意愿安慰函改成可执行保证并放行、把见索即付改成本类型、把脱钩条款写成已核验规则、把约定不明写成已经是连带或已经没有保证期间、保证有效。
- `字段停止`：法域、动态规则、决议真伪、差额公式或基础债务范围未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书、保证责任评估，或把本合同改成独立保函／典型单笔保证／安慰函整案。

生存级金额或自然人无限差额且用户拒绝升级：停止放行建议，只列风险与转介。
