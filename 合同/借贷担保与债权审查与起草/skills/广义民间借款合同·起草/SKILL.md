# 广义民间借款合同·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、2015 年 24%/36%、银行利率旧四倍、法释〔2018〕2 号共债解释当作现行规则。民法典第 679 条仅适用于双方均为自然人的借款合同，不得写成混主体成立规则。法释〔2020〕27 号七类地方金融组织不适用民间借贷司法解释，不得按本类型四倍改持牌稿。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **借款合同 / 广义民间借款合同**，输出可编辑草稿、未决项、自审风险表与自审后修改句。有完整待签文本要评改时，转 `广义民间借款合同·审查`。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。中文名必须是「审查广义民间借款合同（借款合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查或起草；待签文本评改；履约交底；争议文书或清收策略；有效性保证；利息精算终局数字；把无证放贷或平台资金池改成可履行放贷/网贷业务；把转贷改成可履行通道；把流质或过户担保改成可履行物权转移。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **非持牌民间借贷 ≠ 银行贷款 ≠ 自然人实践性 ≠ 企业间拆借 ≠ 狭义偶发**。出借人未持贷款牌照。出借人持牌或属于法释〔2020〕27 号七类地方金融组织 → 负触发 `金融机构借款合同·审查`。双方均为自然人且无平台主结构 → 负触发 `自然人之间的借款合同·审查`。双方均为非金融企业且为生产经营拆借 → 负触发 `企业间借款合同·审查`。偶发、非经营性、无平台无准金融外壳 → 负触发 `狭义民间借款合同·审查`。未获许可以放贷为业、向社会不特定对象提供借款：告知无效风险，不改成可履行放贷业务。
2. **成立分轨**。第 679 条和第 9 条只约束双方自然人之互借。混主体或企业参与一方：书面诺成，未放款走第 671 条，不是法定未成立。知识库“民间借款一律实践合同”不得写入成立结论。
3. **利率**。合同成立时一年期贷款市场报价利率四倍（法释〔2020〕17 号第 25 条）。逾期利息、违约金、咨询费、平台服务费合计受第 29 条约束。禁止 24%、36%、银行利率旧四倍。持牌监管利率、受托支付不得套进来。
4. **670 砍头息**。利息、咨询费、保证金、平台费预先从本金扣除的，以实际出借金额为本金和计息基数。
5. **第 13 条红线**。套取金融机构贷款转贷、转手牟利转贷、职业放贷、知情违法用途：只出告知，不改成可履行。平台资金池、自融、保本保息、平台自身担保：不改成可履行网贷业务。
6. **混主体双闸**。企业侧大额拆出/拆入或对外担保按章程由董事会或股东会决议；未见决议字段停止。自然人借款人侧共债只作字段（共同签字或事后追认），不展开婚姻整案，不把配偶写成默认连带保证人。
7. **名为投资/合伙/买卖实为借贷**。保底固定回报、不承担经营风险：切开按本类型审，删除投资外壳。让与担保过户或到期归出借人所有：切开或停笔清算，不写成可履行流质。

禁止表述：民间借贷一律实践合同；未放款则混主体合同未成立；24%/36%/旧四倍为本类型上限；银行 LPR 加减点是本类型法定上限；砍头息后仍按面额计息；无决议可以盖章；配偶未签也一定是共同债务；职业放贷、转贷或资金池改到能签；持牌小贷按民间四倍改完。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿；尚未签署，尚未成争，出借人未持牌，核心给付是提供资金、到期返还本金（可约定利息）；主体为一方自然人与一方非金融企业或组织，或文本以平台/电子借贷包、未持牌准金融外壳呈现；用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 出借人是商业银行、消费金融、信托、财务公司，或小额贷款公司、融资担保公司、典当行、融资租赁公司、商业保理公司、地方资产管理公司、区域性股权市场等经批准从事相关金融业务的组织 → `金融机构借款合同·审查`；
- 双方均为自然人，且平台不是签约主体、也无资金池/兑付条款主导 → `自然人之间的借款合同·审查`；
- 双方均为非金融企业或非法人组织，用途为生产经营拆借 → `企业间借款合同·审查`；
- 偶发、非经营性、无平台、无准金融外壳、也不是混主体主结构 → `狭义民间借款合同·审查`；
- 同一文本以保证条款和保证人签章为主结构 → `保证借款合同·审查`；
- 抵押财产、登记、流押主导放行 → `抵押借款合同·审查`；
- 质押或权利凭证移交主导 → `质押借款合同·审查`；
- 买卖过户、回购或不清算归债权人所有作为还款担保的主结构 → `让与担保型借款合同·审查`；
- 文本明显是买卖、租赁且无还本核心给付 → 本套导航的类型切开步骤 或对应场景原子；
- 有完整待签文本要评改 → `广义民间借款合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问放款、还本付息节点 → 本套导航的履约步骤；
- 已成争（催告、解除、索赔、诉讼仲裁、清收）→ 合同争议或对应专项领域。

职业放贷、套取信贷转贷、转手牟利转贷、知情违法用途、平台资金池/自融/保本保息：只出告知，不改写成可履行放贷或网贷结构。

## 建立审查坐标

确认：使用者与授权；单方立场（出借人 / 借款人择一）；相对方；全文及附件版本；哪一方是自然人、哪一方是企业；出借人是否持牌或以放贷为业；平台是否签约、是否归集资金或承诺兑付；本金、到账、利率、用途、期限；资金来源陈述；企业章程与决议；自然人共签痕迹；不可接受事项；法域与拟签署日。缺立场或本类型条件未谈妥则不启动起草。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 起草模式

本原子只承担本类型起草。待签评改转 `广义民间借款合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。本类型硬闸改成正文必写、附件必附或禁止出现。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 出借人未持贷款牌照；主体写明一方自然人与一方非金融企业／组织，或平台／电子外壳角色。
- 混主体或企业参与一方：书面诺成，成立与放款分列；未放款走继续履行或赔偿，不写成法定未成立。
- 借期内利率及逾期利息、违约金、咨询费、平台服务费合计不超过合同成立时一年期 LPR 四倍。
- 本金以实际出借金额为准；预扣利息、咨询费、保证金、平台费不计入本金。
- 企业侧大额拆出／拆入或对外担保：正文要求按章程由董事会或股东会决议；自然人共债只写共同签字或事后追认。
- 保底固定回报、不承担经营风险：改为可识别的借贷事实（本金、期限、回报折算）。

### 附件必附

- 企业侧大额拆出／拆入或对外担保的董事会／股东会决议（有该事实时）。
- 主张共债时：自然人共同签字页或事后追认。
- 无对应事实不编造附件，缺项写入未决项。

### 禁止出现

- 民间借贷一律实践合同；未放款则混主体合同未成立。
- 24%／36%／银行利率旧四倍为本类型上限；银行 LPR 加减点是本类型法定上限。
- 砍头息后仍按面额计息。
- 无决议可以盖章；配偶未签也一定是共同债务。
- 未获许可以放贷为业、向社会不特定对象提供借款，或职业放贷、转贷、知情违法用途、平台资金池／自融／保本保息改到能签。
- 持牌小贷或法释〔2020〕27 号七类地方金融组织按民间四倍改完。
- 让与担保过户或到期归出借人所有写成可履行流质。

0. 签署状态与成果分流

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；条件未谈妥仍要出可签署终稿；用户坚持伪造倒签或假决议、把职业放贷或资金池包装成普通民间借贷、把转贷或知情违法用途改成可履行、把流质过户改成可履行物权转移、保证有效、按 24%/36%/旧四倍或银行监管利率出本类型合法上限。
- `字段停止`：法域、LPR 时点、资金是否信贷资金、是否以放贷为业、平台是否信息中介、章程决议机关、共债是否成立未核验；本金或到账关键事实缺失。
- `目标停止`：主目标已变为待签评改、履约交底、清收文书、利息精算终局，或把本合同改成银行贷款/双方自然人实践性/企业间生产经营整案。

生存级金额或个人无限连带且用户拒绝升级：停止“可以签署”建议。
