# 领域边界

处理本套已覆盖类型（借款合同、保证合同、债权转让合同）尚未形成争议的文件工作。子类型已明时分别进 `·审查` / `·起草` 成对原子。本套不安装共性技能。

本套父级：借款合同、保证合同、债权转让合同。

不在本套实施：他领域合同类型整案、已形成争议的催告解除索赔诉讼。

已形成争议（催告、解除、索赔、诉讼仲裁）转合同争议解决或其他专项争议领域，不在本套做解除评估。
