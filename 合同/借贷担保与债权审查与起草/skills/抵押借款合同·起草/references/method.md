# 审查方法（锁定 借款合同 / 抵押借款合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止套用买卖合同的标的验收、定金比例、挂靠改写或工程分包节点。禁止把本技能写成自然人互借或保证借款换标题。

定性校验：核心给付是资金借贷，且抵押是主结构，才继续；明显他类则负触发，不填十节实体结论。

本文件是可执行判断节点，不是栏目说明书。每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、抵押权已经设立、必然优先受偿，或唯一必得本息。

`search_law` 返回已失效《合同法》《担保法》《物权法》及其解释、1991 年《关于人民法院审理借贷案件的若干意见》、2015 年民间借贷司法解释中 24%/36% 条文时记为噪声，不得写入 `L#`。`search_practiced` 仍写“抵押合同自登记之日起生效”“转让须抵押权人同意否则无效”“主合同无效但当事人可约定抵押独立有效”“24%/银行利率旧四倍”的，同样记噪声。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

示范文本只参考结构。写“自抵押物办理登记之日起合同生效”的范本与民法典第 215 条冲突，不得当合同生效规则。

知识库口径冲突以本方法为准，不回写知识正文：

- `框架.md` 写“抵押合同自登记之日起生效”：纠正为抵押合同原则上成立即生效，不动产抵押权自登记时设立。

- 利率“四倍”必须运行时核验，不得写成银行利率旧四倍或 24%/36%。

## 节点 2　主体、权属、共有人、第三人抵押与公司决议

1. 建主体表：出借人/抵押权人、借款人、抵押人、指定收款人、共有人、保证人（如有）。名称不一致不自动合并。抵押人可以是借款人，也可以是第三人。
2. 权属：抵押人须对抵押财产有所有权或处分权。材料未出示权属证书原件或与清单不一致：该设立能力字段停止，不得写成“可以办理抵押登记”。
3. 共有：夫妻共同房产或其他共有财产，须有共有人本人书面同意。口头“配偶同意了”、合同打印共有人栏但未签：不得写成已同意。代签、伪造共有人签名：整体停止。
4. 第三人抵押：分清抵押人与借款人。未经抵押人书面同意允许债务人转移全部或部分债务的，抵押人不再承担相应担保责任。不得把第三人抵押人写成连带保证人。
5. 公司为他人提供抵押：按公司章程由董事会或股东会决议；为股东或实际控制人提供担保须股东会决议，该股东不得表决。相对人须对决议作合理审查，否则公司可能主张合同对其不发生效力。未附决议：字段停止，修改句要求作为附件且未获批准不设立抵押权、不放款。
6. 机关法人、居民委员会、村民委员会作抵押人：效力红旗，不得改成可履行机关担保。
7. 口头“我们老板同意了”不得写成已授权或已决议。

不足：字段停止，列出待补材料，不补主体、不补权属、不补已同意。

## 节点 3　主债与抵押从属（硬闸）

抵押合同是主债权债务合同的从合同。主债权债务合同无效的，抵押合同无效，但是法律另有规定的除外。担保合同被确认无效后，有过错的当事人承担与过错相应的民事责任，不是继续承担担保责任。

核验后可引用的判断点（须 `search_law` 写入 `L#` 再落法律结论）：

- 担保合同包括抵押合同；担保合同是主债权债务合同的从合同。
- 当事人约定担保合同效力独立于主合同，或约定担保人对主合同无效的法律后果承担担保责任的，该独立性约定无效。
- 抵押权不得与债权分离而单独转让或者作为其他债权的担保；债权转让的，抵押权一并转让，法律另有规定或当事人另有约定除外。

| 文本写法 | 本任务动作 |
| --- | --- |
| “无论主合同是否有效，抵押人仍承担担保责任”“本抵押合同独立生效” | 必须改。删除独立性约款；写明从属于被担保的主债权 |
| 抵押担保的主债权种类、合同编号、本金空白 | 标 `G#`；修改句补主合同名称、编号、本金、履行期限 |
| 借新还旧，仍援引旧贷抵押登记，未约定转入新贷 | 必须改。提示旧贷因清偿消灭则旧抵押权消灭，除非当事人同意转入新贷并办理相应登记 |
| 商品房按揭：把买卖合同写成贷款合同的主合同，或把贷款合同写成买卖的从合同 | 必须改。二者独立但关联；买卖无效、撤销或解除导致贷款目的不能实现的，只点名解除路径，不认定已解除 |
| 用户要求把主债无效改成“抵押仍然有效、仍可拍卖优先受偿” | 整体停止该结论 |

反方常见抗辩：主合同有瑕疵但抵押登记在先，主张善意取得或独立担保。本任务不把未核验的善意取得写成已经成立，也不把独立性约款放行。

## 节点 4　抵押财产特定化、禁止抵押与登记（硬闸）

### 4.1 书面与特定化

设立抵押权应当采用书面形式。抵押合同一般包括：被担保债权的种类和数额；债务人履行债务的期限；抵押财产的名称、数量等情况；担保的范围。

抵押财产必须特定到可登记、可执行：不动产写坐落、权证号、面积；动产写名称、数量、规格、权属凭证；在建工程写项目名称、规划许可或已完工部分范围。只有“名下房产一处”“相关财产”“等财产”视为未特定，标必须改，不编造坐落或证号。

### 4.2 可抵押与禁止抵押

可抵押：建筑物和其他土地附着物；建设用地使用权；海域使用权；生产设备、原材料、半成品、产品；正在建造的建筑物、船舶、航空器；交通运输工具；法律、行政法规未禁止抵押的其他财产。

不得抵押：土地所有权；宅基地、自留地、自留山等集体土地使用权（法律另有规定除外）；学校、幼儿园、医疗机构等为公益目的成立的非营利法人的教育、医疗卫生和其他公益设施；所有权、使用权不明或有争议的财产；依法被查封、扣押、监管的财产；法律、行政法规规定不得抵押的其他财产。

命中禁止抵押：红线。不得改写成“换个表述就能登记”。权属不明或未出示他项权利查询：字段停止，不得写成无权利负担。

房地一体：以建筑物抵押的，占用范围内建设用地使用权一并抵押；以建设用地使用权抵押的，土地上建筑物一并抵押。未一并写明的，修改句补入，并提示未写明亦视为一并抵押，但不编造土地证号。新增建筑物不属于抵押财产，处分时应一并处分但新增部分不得优先受偿。

在建工程：抵押权效力限于已办理抵押登记的部分，不得把续建、规划未建部分写成已经抵押。建设工程价款优先受偿权可能优于抵押权：只标红旗，不在本任务排序终局。

### 4.3 合同生效 ≠ 抵押权设立

除法律另有规定或当事人另有约定外，设立不动产物权的合同自成立时生效；未办理物权登记的，不影响合同效力。

- 建筑物、建设用地使用权、海域使用权、正在建造的建筑物：应当办理抵押登记，抵押权自登记时设立。
- 动产：抵押权自抵押合同生效时设立；未经登记，不得对抗善意第三人。动产抵押还不得对抗正常经营活动中已支付合理价款并取得抵押财产的买受人。

| 文本写法 | 本任务动作 |
| --- | --- |
| “本合同自抵押登记之日起生效” | 必须改。拆成：抵押合同自成立时生效；不动产抵押权自登记时设立 |
| “签字即视为已办理抵押登记/已取得优先受偿权” | 红线或必须改。禁止用拟制登记代替登记事实 |
| 不动产抵押未写谁在几日内申请登记、未完成的后果 | 必须改。补义务主体、期限、未登记不得放款或可解除、以及违约赔偿，不得写成已经设立 |
| 仅办理抵押预告登记，写成已经享有抵押权 | 必须改。预告登记不是当然的现实抵押权；不具备转为本登记条件时不得主张优先受偿 |
| 动产抵押不登记且写成“可以对抗任何第三人” | 必须改 |
| 用户要求把日期写成已经登记或补假登记回单 | 整体停止 |

批准、登记、网签写成生效条件或双方义务期限，不写成已经完成。材料未提及不得写成“无在先抵押、查封或租赁”。

## 节点 5　担保范围（硬闸）

担保物权的担保范围包括主债权及其利息、违约金、损害赔偿金、保管担保财产和实现担保物权的费用。当事人另有约定的，按照其约定。

动作：

1. 摘录合同担保范围。空白或只写“本金”：出借人立场必须改，补利息、违约金、损害赔偿金、实现费用（含律师费、诉讼/仲裁费、保全费、拍卖费，用 `【待填】` 列名目，不编造金额）；抵押人立场可保持限缩，但须给可回传的限缩句，并提示未约定时适用法定范围。
2. 不得把抵押人写成保证人，不得写成“约定不明即对全部债务承担责任”。
3. 不动产登记簿就抵押财产、被担保债权范围等记载与抵押合同不一致的，以登记簿确定优先受偿范围。修改句要求登记申请与合同范围一致；登记系统只能登记主债权数额时，写明合同范围并尽量在登记备注或附件中体现，仍提示可能按登记簿限缩。
4. 最高额抵押：优先受偿不超过登记的最高债权额；登记额与约定额不一致的，按登记额。
5. 担保范围不得大于主债务。专门高于主债的违约金、提前于主债到期的抵押履行期：标必须改，缩到主债范围。

无 `search_law` 引文：担保范围法律结论字段停止，仍可给出对齐登记簿的修改句草稿。

## 节点 6　流质禁止与实现方式（硬闸）

抵押权人在债务履行期限届满前，与抵押人约定债务人不履行到期债务时抵押财产归债权人所有的，只能依法就抵押财产优先受偿。

到期后实现抵押权：协议折价，或拍卖、变卖所得价款优先受偿；协议损害其他债权人的，其他债权人可以请求撤销。未达成协议的，可以请求人民法院拍卖、变卖。折价或变卖应当参照市场价格。

| 文本写法 | 本任务动作 |
| --- | --- |
| “到期不还，抵押房屋/车辆归甲方所有并配合过户” | 红线。改为只能折价、拍卖或变卖后优先受偿，多退少补 |
| “放弃清算”“禁止评估”“债权人可直接占有并处分” | 红线或必须改 |
| 同时另签买卖合同、网签或过户委托作为还款担保 | 负触发 `让与担保型借款合同·审查`，本技能不改成可过户结构 |
| 履行期届满后另行达成以物抵债 | 本任务是签前文本；不得把预埋的期前流押包装成“到期后再签”来放行 |
| 用户要求保留流押以便直接过户 | 整体停止 |

抵押权人应当在主债权诉讼时效期间行使抵押权；未行使的，人民法院不予保护。禁止引用已失效口径：担保物权在主债权时效结束后仍有两年行使期。

## 节点 7　抵押期间处分；利率上限运行时核验（硬闸）

### 7.1 抵押期间处分

抵押期间，抵押人可以转让抵押财产。当事人另有约定的，按照其约定。抵押财产转让的，抵押权不受影响。抵押人转让抵押财产的，应当及时通知抵押权人。抵押权人能够证明转让可能损害抵押权的，可以请求将转让价款提前清偿或提存。

禁止把已失效规则写成现行默示：转让必须经抵押权人同意，否则转让合同或物权变动无效。

| 文本写法 | 本任务动作 |
| --- | --- |
| 未约定限制转让 | 不得补写成“未经同意不得转让否则无效”。出借人若要限制，须明示约定，并提示未登记限制时对抗善意受让人能力受限 |
| “未经抵押权人书面同意不得转让，否则转让无效” | 可作另有约定审查，但必须改掉“转让合同无效”的绝对表述；提示限制约定应登记，否则主要发生违约责任，不当然否定转让物权效力 |
| “抵押期间不得出租”未区分先租后抵 | 必须改。先租后抵可能影响变价；后租应通知并不得损害抵押权 |
| 用户要求写成“未同意的转让一律无效，买受人必须交房” | 该绝对物权结论停止或必须改 |

### 7.2 主债利率与费用（运行时核验）

禁止直接输出下列口径作为现行保护标准：

- 银行同类贷款利率四倍（1991 年意见口径，下称“旧四倍”）；
- 年利率 24%、年利率 36%（2015 年司法解释口径）；
- 任何未核验的“四倍”。

动作：

1. 先判断贷款人是否为金融监管部门批准的放贷机构。持牌机构：不得套用民间借贷司法解释上限；利率是否合规改走监管规则核验，核验失败则该法律结论停止。
2. 民间借贷路径：调用 `search_law` 查询“民间借贷利率司法保护上限 现行规定”。仅当返回现行有效规则时写入 `L#`，再对照文本利率与“合同成立时”的保护标准。
3. 开发窗口 2026-08-18 核验结果（供对照，不得代替运行时核验）：《最高人民法院关于审理民间借贷案件适用法律若干问题的规定（2020 第二次修正）》法释〔2020〕17 号第 25 条，约定利率超过合同成立时一年期贷款市场报价利率四倍的部分不予支持。逾期利率见第 28 条；逾期利息、违约金或其他费用总和见第 29 条。
4. 核验失败或只返回已修改文本：利率法律结论字段停止。仍可摘录文本利率并给出“待核验现行上限后改写”的修改句草稿，不得写成“按 24% 合法”或“按旧四倍合法”。
5. 一年期 LPR 当次数值未核验：不编造百分比，用 `【合同成立时一年期 LPR × 核验所得倍数，待填】`。
6. 利息预扣按实际交付额计本金和利息。服务费、咨询费、通道费与逾期利息、违约金并行时按费用总和审查。
