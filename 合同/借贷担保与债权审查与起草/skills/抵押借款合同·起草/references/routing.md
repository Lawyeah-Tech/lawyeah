# 边界与路由

本技能只审查 **借款合同 / 抵押借款合同**。

必须同时读出资金借贷合意，以及以特定财产不转移占有设定抵押权的主结构。标题叫“抵押借款合同”但没有抵押财产、或抵押已被买卖过户/回购替代的，不得留在本技能做实体结论。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或标题抵押借款、核心给付明显不是资金借贷加抵押 | 本套导航的类型切开步骤 |
| 买卖、过户、回购、让与担保；到期不还则财产归债权人且不清算；财产先过户再借款 | `让与担保型借款合同·审查`；专业版未收录该 P1 时输出 `unavailable`，不得硬套本技能改成可过户结构 |
| 无抵押财产、无抵押条款，只有保证人、保证方式、保证期间 | `保证借款合同·审查` |
| 双方自然人或一方企业的普通借款，无抵押 | `自然人之间的借款合同·审查` 或 `狭义民间借款合同·审查` |
| 质押物移交、权利凭证出质、股权质押主导 | `质押借款合同·审查` |
| 企业互借且抵押只是附带一句、审查重点是拆借效力 | 可提示 `企业间借款合同·审查`；抵押从属与登记仍是放行关键则留本技能 |
| 持牌机构贷款文本，审查重点是监管利率与放款条件 | 可提示 `金融机构借款合同·审查`；抵押物权设立仍是放行关键则留本技能 |
| 有完整待签文本要评改 | `抵押借款合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 留本任务起草并自审 |
| 已签未争、问登记进度、放款日、解押 | 本套导航的履约步骤 |
| 已成争 | 合同争议领域或对应专项；不写实现抵押权申请书、起诉状 |
| 用户只要利息或优先受偿额的终局数字 | 测算技能或人工精算；本技能只审条款 |
| C 端大众快检 | 只分流，不回改 |

附带保证、配偶签字栏时：本技能只审对本约放行的影响（物保与人保并存时不得默认先物后人，也不得把抵押人写成保证人），不展开保证合同专项整案。深度保证文本转 `保证借款合同·审查`。

商品房按揭：买卖合同与担保贷款合同不是主从关系。买卖无效、撤销或解除导致贷款目的不能实现的，只点名解除路径，不在本任务认定已解除。

职业放贷、转贷、违法用途、禁止抵押财产包装、流押改过户：停笔告知，不改写成可履行文本。
