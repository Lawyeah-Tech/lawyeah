# 质押借款合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《担保法》《物权法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **借款合同 / 质押借款合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。中文名必须是「审查质押借款合同（借款合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查、从零起草、履约交底、争议文书、质权或合同有效性保证、优先受偿终局认定、利息精算终局数字。

## 工作边界

正触发：已有可读待签文本要评改，尚未签署，尚未成争，核心给付是资金借贷，**且质押是主结构**——存在可识别的出质人/质权人，并以动产移交占有或权利凭证交付/出质登记为借款提供担保。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 以买卖、过户、回购或“到期不还则归债权人所有且不清算”作为还款担保，或财产/股权形式上先转到债权人名下 → `让与担保型借款合同·审查`；专业版未收录该 P1 时输出 `unavailable`，不得硬套本技能改成可过户结构；
- 无出质财产、无质押条款，只有保证人/保证条款 → `保证借款合同·审查`；
- 不转移占有、以不动产或动产抵押登记为主结构 → `抵押借款合同·审查`；
- 无质押、无保证的自然人互借 → `自然人之间的借款合同·审查`；一方为企业的狭义民间借款 → `狭义民间借款合同·审查`；
- 文本明显是买卖、租赁、投资入股且无质押借款核心给付 → 本套导航的类型切开步骤 或对应场景原子；
- 无文本、本类型条件已谈妥、要出己方稿 → `质押借款合同·起草`；
- 已签只问履约、交付办理、出质登记进度或放款节点 → 本套导航的履约步骤；
- 已成争（催告、返还质物、实现质权、诉讼仲裁）→ 合同争议或对应专项领域。

持牌机构放贷且审查重点是监管利率、放款条件而非质押从属与质权设立时，可提示并行 `金融机构借款合同·审查`；只要交付、登记、流质、从属仍是放行关键，留本技能。

职业放贷、套取金融机构贷款转贷、明知违法犯罪用途仍出借、把禁止转让财产改成可出质、把出质人继续占有写成已经交付：只出告知，不改写成可履行放贷或可设立质权的文本。

## 本类型硬闸

1. **流质禁止**。债务履行期限届满前约定“到期不还则质押财产归债权人所有”的，不得写成可以过户、过户股权或直接收款；只能改成折价、拍卖或变卖后优先受偿。不得把让与担保买卖/股权转让文本留在本技能改成可过户条款。
2. **动产/权利质押必须按公示方式设立，并分开合同效力与质权设立**。动产质权自出质人交付质押财产时设立。汇票、本票、支票、债券、存款单、仓单、提单有权利凭证的，质权自凭证交付时设立；没有权利凭证的，自办理出质登记时设立。基金份额、股权、知识产权中的财产权、应收账款，质权自办理出质登记时设立。未交付或未登记，不得写成质押合同未生效，也不得写成已经取得优先受偿权。约定“仍由出质人占有使用即视为已交付”不得写成质权已设立。
3. **担保范围必须写清**。法定范围是主债权及其利息、违约金、损害赔偿金、保管担保财产和实现担保物权的费用；另有约定从约定。不得把出质人写成保证人，也不得写成约定不明即对全部债务承担保证责任。
4. **主债与质押从属**。质押合同是主债权债务合同的从合同。主合同无效，质押合同无效，法律另有规定的除外。约定“质押合同独立生效/主合同无效仍承担担保责任”的独立性条款无效。
5. **质权人占有期间负保管义务**。因保管不善致使质押财产毁损、灭失的，应当赔偿。修改句不得删除法定保管义务，也不得写成质权人可无偿使用质物而不承担责任。
6. **利率司法保护上限必须运行时核验**。民间借贷路径禁止把银行同类贷款利率四倍、年利率 24%、年利率 36% 写成现行保护标准。持牌机构路径不得套用民间借贷上限。核验失败则利率法律结论字段停止。

## 建立审查坐标

确认：使用者与授权；单方立场（出借人/质权人、借款人、第三人出质人、拟签字共有人）；相对方；全文及质押财产清单、权属证明、权利凭证、决议等附件版本；主债权种类与数额；质押财产是动产还是哪一类权利；交付或登记安排及登记机关；担保范围；利率与费用；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的本金、财产规格、凭证号、登记机关、利率、期限用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law`（法律结论 required）：核验流质禁止、质押书面与特定化、动产交付设立、权利凭证交付或登记设立、股权/知识产权/应收账款登记设立、合同效力与物权变动分离、担保范围、从属性与独立性约款、质权人保管义务、禁止出质财产、公司对外担保决议、民间借贷利率上限。
- `search_practiced`（optional）：补未交付、占有改定、监管人未实际控制、未登记股权/应收账款争点。返回“质押合同自登记或交付之日起生效”“出质人继续占有亦视为移交”“保证不明即连带”“24%/银行利率旧四倍”时记噪声。
- `search_template`（optional）：只借栏目结构。范本写“股权出质事项自工商登记之日起生效”或“质押合同自交付之日起生效”不得当合同生效规则。

不虚构案件系统。`search_law` 返回已失效《合同法》《担保法》《物权法》及其解释、1991 年借贷意见、2015 年 24%/36% 条文、《应收账款质押登记办法（2019）》失效文本时记为噪声，不得写入 `L#`。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口，不代替节点。

0. 签署状态与成果分流
1. 类型识别与单目录加载（借贷 + 质押主结构；切开抵押与保证）
2. 主体、权属、共有人、第三人出质与公司决议
3. 主债与质押从属
4. 质押财产特定化、禁止出质与交付/登记设立
5. 担保范围；质权人保管义务
6. 流质禁止与实现方式
7. 利率上限运行时核验
8. 按框架六步出修改句

必须有修改句。禁止只打红黄绿。每个风险回链文本位置。禁止套用买卖合同的标的验收、定金百分之二十或挂靠改写节点。禁止套用抵押借款的不动产登记、房地一体或抵押期间转让节点。禁止套用保证借款的保证方式、保证期间节点。禁止把本技能写成自然人互借换标题。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、补假交付或假登记、伪造共有人同意或公司决议、把流质改成可过户、把禁止转让财产改成可出质、把出质人继续占有写成已经交付、包装职业放贷或转贷、保证质权必然设立或必然优先受偿。
- `字段停止`：法域、利率上限、担保范围、权属/共有、公司决议未核验；质押财产无法特定；交付或登记安排无法识别。
- `目标停止`：主目标已变为从零起草、履约交底、实现质权文书或利息精算终局。

生存级金额或第三人全部责任财产被出质且用户拒绝升级：停止“可以签署”建议。
