# 审查方法（锁定 借款合同 / 质押借款合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止套用买卖合同的标的验收、定金比例、挂靠改写或工程分包节点。禁止套用抵押借款的不动产登记、房地一体、在建工程或抵押期间转让节点。禁止套用保证借款的保证方式、保证期间节点。禁止把本技能写成自然人互借或抵押借款换标题。

定性校验：核心给付是资金借贷，且质押是主结构，才继续；明显他类则负触发，不填十节实体结论。

本文件是可执行判断节点，不是栏目说明书。每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、质权已经设立、必然优先受偿，或唯一必得本息。

`search_law` 返回已失效《合同法》《担保法》《物权法》及其解释、1991 年《关于人民法院审理借贷案件的若干意见》、2015 年民间借贷司法解释中 24%/36% 条文、已失效《应收账款质押登记办法（2019）》时记为噪声，不得写入 `L#`。`search_practiced` 仍写“质押合同自交付或登记之日起生效”“出质人继续占有亦视为移交”“主合同无效但当事人可约定质押独立有效”“24%/银行利率旧四倍”的，同样记噪声。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

示范文本只参考结构。写“股权出质事项自工商登记之日起生效”或“质押合同自质物交付之日起生效”的范本与合同成立生效规则冲突，不得当合同生效规则。

知识库口径冲突以本方法为准，不回写知识正文：

- `框架.md` 写“本合同自各方签字盖章之日起成立，自质押财产交付占有或质押登记手续办理完毕之日起生效”：纠正为质押合同原则上成立即生效；动产质权自交付时设立，权利质权自凭证交付或出质登记时设立。交付或登记可作为**放款先决条件**约定，但不是法定的合同生效规则。
- `基本面.md` 称必须分别签订《借款合同》和《质押合同》：纠正为合并一份《质押借款合同》或主从分立均可，关键是主债特定、从属写清、设立公示可执行。
- 利率“四倍”必须运行时核验，不得写成银行利率旧四倍或 24%/36%。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用核心给付和担保结构定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须同时满足才正触发：

1. 核心给付是出借人提供货币资金，借款人到期返还本金（可约定利息）。
2. 主结构是质权：债务人或第三人将动产移交债权人占有，或以可出质权利办理凭证交付或出质登记，担保该借款。

必须切开，禁止两可时灌入两套知识：

| 信号 | 归入 | 本技能动作 |
| --- | --- | --- |
| 借款 + 动产移交占有或权利出质条款 + 质押财产（可待填但须有特定化位置） | 本类型 | 加载本目录双文件 |
| 不转移占有，不动产/在建工程/动产抵押登记主导 | `抵押借款合同·审查` | 负触发；不做抵押登记、房地一体节点 |
| 只有保证人、保证方式、保证期间，无出质财产 | `保证借款合同·审查` | 负触发；不做保证期间节点 |
| 买卖/过户/回购作为还款担保，或到期不还则财产、股权归债权人且不清算 | `让与担保型借款合同·审查` | 负触发；不改写成可过户履行结构 |
| 无质押、无保证的自然人互借 | `自然人之间的借款合同·审查` | 负触发 |
| 无质押的企业参与民间借贷 | `狭义民间借款合同·审查` | 负触发 |
| 移转标的物所有权换价款，无借贷担保意图 | 买卖类场景原子 | 负触发 |
| 固定回报、不承担经营风险的投资/合伙文本 | 引擎或对应场景 | 负触发或 `unavailable` |

标题写“抵押”但正文要求移交占有或办理出质登记：按质押主结构留本技能，标题冲突写入 `C#`，修改句改正名实。标题写“质押”但正文是不转移占有的不动产抵押：负触发 `抵押借款合同·审查`。

### 1.2 加载协议（硬闸）

本技能已锁定 **借款合同 / 质押借款合同**。只打开 `references/基本面.md` 与 `框架.md`。禁止读其他类型目录，禁止为对照再开第二类。

### 1.3 违法结构停笔

加载后或定性中出现：向不特定对象经营性放贷、套取金融机构贷款转贷、明知赌博吸毒等违法犯罪用途仍出借、以法律行政法规禁止转让的动产或权利包装成可出质、指导伪造交付回单或出质登记、把流质改成可过户履行、把出质人继续占有写成已经交付。

动作：

1. 交付告知：该结构可能违反强制性规定或公序良俗，不得改写成可履行、可设立质权的文本。
2. 不写假权属、假决议、假交付、假登记路径。
3. 风险表只保留识别依据和转出/改道提示。
4. 用户坚持“改到能签、能过户、能优先受偿”：整体停止。

合规改道（改为清算型优先受偿、补真实权属与决议、改为实际交付或法定登记、停止违法放贷）只点名，不在本任务起草。

## 节点 2　主体、权属、共有人、第三人出质与公司决议

1. 建主体表：出借人/质权人、借款人、出质人、指定收款人、共有人、保证人（如有）。名称不一致不自动合并。出质人可以是借款人，也可以是第三人。
2. 权属：出质人须对质押财产有所有权或处分权。材料未出示权属证书、权利凭证或与清单不一致：该设立能力字段停止，不得写成“可以交付”或“可以办理出质登记”。
3. 共有：夫妻共同财产或其他共有动产、共有知识产权，须有共有人本人书面同意。口头“配偶同意了”、合同打印共有人栏但未签：不得写成已同意。代签、伪造共有人签名：整体停止。
4. 第三人出质：分清出质人与借款人。未经出质人书面同意允许债务人转移全部或部分债务的，出质人不再承担相应担保责任。不得把第三人出质人写成连带保证人。
5. 公司为他人提供质押：按公司章程由董事会或股东会决议；为股东或实际控制人提供担保须股东会决议，该股东不得表决。相对人须对决议作合理审查，否则公司可能主张合同对其不发生效力。未附决议：字段停止，修改句要求作为附件且未获批准不设立质权、不放款。公司法条号用 2023 年修订第十五条。
6. 股权出质：有限责任公司股权出质一般无需其他股东同意，但须核章程有无限制；上市公司股票走证券登记结算机构，不得写成到市场监督管理部门登记即可。未核章程或登记机关：字段停止。
7. 应收账款出质：建议通知应收账款债务人；未通知不得写成债务人不得再向出质人清偿。应收账款真实性未确认：优先受偿结论字段停止。
8. 口头“我们老板同意了”不得写成已授权或已决议。

不足：字段停止，列出待补材料，不补主体、不补权属、不补已同意、不补已通知债务人。

## 节点 3　主债与质押从属（硬闸）

质押合同是主债权债务合同的从合同。主债权债务合同无效的，质押合同无效，但是法律另有规定的除外。担保合同被确认无效后，有过错的当事人承担与过错相应的民事责任，不是继续承担担保责任。

核验后可引用的判断点（须 `search_law` 写入 `L#` 再落法律结论）：

- 担保合同包括质押合同；担保合同是主债权债务合同的从合同。
- 当事人约定担保合同效力独立于主合同，或约定担保人对主合同无效的法律后果承担担保责任的，该独立性约定无效。
- 质权不得与债权分离而单独转让或者作为其他债权的担保。

| 文本写法 | 本任务动作 |
| --- | --- |
| “无论主合同是否有效，出质人仍承担担保责任”“本质押合同独立生效” | 必须改。删除独立性约款；写明从属于被担保的主债权 |
| 质押担保的主债权种类、合同编号、本金空白 | 标 `G#`；修改句补主合同名称、编号、本金、履行期限 |
| 借新还旧，仍援引旧贷质押登记或旧交付，未约定转入新贷 | 必须改。提示旧贷因清偿消灭则旧质权消灭，除非当事人同意转入新贷并重新交付或登记 |
| 用户要求把主债无效改成“质押仍然有效、仍可拍卖优先受偿” | 整体停止该结论 |

反方常见抗辩：主合同有瑕疵但已经交付或登记，主张善意取得或独立担保。本任务不把未核验的善意取得写成已经成立，也不把独立性约款放行。

## 节点 4　质押财产特定化、禁止出质与交付/登记设立（硬闸）

### 4.1 书面与特定化

设立质权应当采用书面形式。质押合同一般包括：被担保债权的种类和数额；债务人履行债务的期限；质押财产的名称、数量等情况；担保的范围；质押财产交付的时间、方式。

质押财产必须特定到可交付、可登记、可执行：

- 动产：名称、品牌、型号、数量、存放地点、权属凭证。
- 股权：目标公司名称、出质份额或股数、股东名称。
- 应收账款：基础合同、债务人、金额或可识别描述；将有应收账款须能合理识别。
- 知识产权：专利号、商标注册号或作品名称及权项。
- 票据、存单、仓单、提单：凭证种类、号码、金额、到期日。

只有“一批货物”“名下股权若干”“相关应收账款”“等财产”视为未特定，标必须改，不编造规格或证号。

### 4.2 可出质与禁止出质

可出质：动产；汇票、本票、支票；债券、存款单；仓单、提单；可以转让的基金份额、股权；可以转让的注册商标专用权、专利权、著作权等知识产权中的财产权；现有的以及将有的应收账款；法律、行政法规规定可以出质的其他财产权利。

法律、行政法规禁止转让的动产不得出质。权属不明、有争议或已被查封、扣押、监管的财产：红旗。不得改写成“换个表述就能出质”。材料未出示他项权利查询：字段停止，不得写成无权利负担。

命中禁止转让财产：红线。不写可履行出质路径。

### 4.3 合同生效 ≠ 质权设立

除法律另有规定或当事人另有约定外，设立物权的合同自成立时生效；未办理物权登记的，不影响合同效力。质押合同与质权是两个事实。

动产：

- 质权自出质人交付质押财产时设立。
- 交付必须使质权人或其委托的监管人取得实际控制。约定“仍由出质人占有使用，视为已交付”或占有改定：不得写成质权已设立。
- 债权人、出质人与监管人订立三方协议，监管人受债权人委托并实际控制货物的，质权自监管人实际控制之日起设立；监管人受出质人委托或未实际履行监管职责、货物仍由出质人控制的，质权未设立。

权利：

- 汇票、本票、支票、债券、存款单、仓单、提单：有权利凭证的，质权自凭证交付质权人时设立；没有权利凭证的，自办理出质登记时设立。汇票出质宜背书记载“质押”并签章后交付。
- 基金份额、股权：质权自办理出质登记时设立。有限责任公司及未在证券登记结算机构登记的股份，向市场监督管理部门办理；已在证券登记结算机构登记的股份向该机构办理。不得写成“记载于股东名册即设立”或“质押合同自工商登记之日起生效”。
- 知识产权中的财产权：质权自办理出质登记时设立。
- 应收账款：质权自办理出质登记时设立。2022-02-01 起，应收账款质押纳入中国人民银行征信中心动产融资统一登记公示系统。不得再把已失效的《应收账款质押登记办法（2019）》写成现行登记规则。统一登记范围不包括股权、基金份额、知识产权中的财产权质押。

| 文本写法 | 本任务动作 |
| --- | --- |
| “本合同自质物交付/出质登记之日起生效” | 必须改。拆成：质押合同自成立时生效；质权自交付或登记时设立。交付/登记可另作放款先决条件 |
| “签字即视为已交付/已登记/已取得优先受偿权” | 红线或必须改。禁止用拟制交付或拟制登记代替公示事实 |
| “质物仍由出质人保管使用，不影响质权设立” | 红线。改为实际交付，或改为监管人受债权人委托并实际控制；否则不得写成已设立 |
| 动产未写谁在几日内交付、交付地点、未交付的后果 | 必须改。补义务主体、期限、未交付不得放款或可解除 |
| 股权/知识产权/应收账款未写登记机关、申请义务人和期限 | 必须改。写明机关与期限，未登记不得放款 |
| 把股权出质写成到人行统一登记系统即可，或把应收账款写成到市场监管部门登记 | 必须改。按权利类型匹配机关 |
| 用户要求把日期写成已经交付或补假登记回单 | 整体停止 |

批准、交付、登记写成生效条件或双方义务期限，不写成已经完成。材料未提及不得写成“无在先质押、抵押、查封或转让限制”。

## 节点 5　担保范围与保管义务（硬闸）

担保物权的担保范围包括主债权及其利息、违约金、损害赔偿金、保管担保财产和实现担保物权的费用。当事人另有约定的，按照其约定。

动作：

1. 摘录合同担保范围。空白或只写“本金”：出借人立场必须改，补利息、违约金、损害赔偿金、保管费用、实现费用（含律师费、诉讼/仲裁费、保全费、拍卖费、登记费，用 `【待填】` 列名目，不编造金额）；出质人立场可保持限缩，但须给可回传的限缩句，并提示未约定时适用法定范围。
2. 不得把出质人写成保证人，不得写成“约定不明即对全部债务承担责任”。
3. 担保范围不得大于主债务。专门高于主债的违约金、提前于主债到期的质押履行期：标必须改，缩到主债范围。
4. 质权人负有妥善保管质押财产的义务；因保管不善致使毁损、灭失的，应当承担赔偿责任。文本删除保管义务、写成“质权人可无偿使用质物、毁损自负”：必须改。出质人因质权人行为可能致质物毁损的，可请求提存或提前清偿并返还。
5. 因不可归责于质权人的事由可能使质押财产毁损或价值明显减少、足以危害质权的，质权人有权请求补充担保；未提供的，可以拍卖、变卖并协议提前清偿或提存。修改句可补动态补仓，但不得写成质权人可任意低价处分。
6. 未经出质人同意转质造成毁损灭失的，质权人应当赔偿。禁止把“质权人可任意转质”写成已放行。

无 `search_law` 引文：担保范围与保管义务的法律结论字段停止，仍可给出列举式修改句草稿。

## 节点 6　流质禁止与实现方式（硬闸）

质权人在债务履行期限届满前，与出质人约定债务人不履行到期债务时质押财产归债权人所有的，只能依法就质押财产优先受偿。

到期后实现质权：协议折价，或拍卖、变卖所得价款优先受偿；折价或变卖应当参照市场价格。债务人履行债务或出质人提前清偿的，质权人应当返还质押财产。

| 文本写法 | 本任务动作 |
| --- | --- |
| “到期不还，设备/股权/应收账款归甲方所有并配合过户或过户变更” | 红线。改为只能折价、拍卖或变卖后优先受偿，多退少补 |
| “放弃清算”“禁止评估”“债权人可直接占有并处分、直接向应收账款债务人收款归己” | 红线或必须改 |
| 同时另签买卖合同、股权转让协议或过户委托作为还款担保 | 负触发 `让与担保型借款合同·审查`，本技能不改成可过户结构 |
| 履行期届满后另行达成以物抵债 | 本任务是签前文本；不得把预埋的期前流质包装成“到期后再签”来放行 |
| 用户要求保留流质以便直接过户或直接取得股权 | 整体停止 |

知识产权、股权出质后不得转让或许可使用，但出质人与质权人协商同意的除外；所得价款应当提前清偿或提存。修改句可写限制处分，但不得写成未经同意的转让合同一律无效且受让人必须交回。

## 节点 7　主债利率与费用（运行时核验）（硬闸）

禁止直接输出下列口径作为现行保护标准：

- 银行同类贷款利率四倍（1991 年意见口径，下称“旧四倍”）；
- 年利率 24%、年利率 36%（2015 年司法解释口径）；
- 任何未核验的“四倍”。

动作：

1. 先判断贷款人是否为金融监管部门批准的放贷机构。持牌机构：不得套用民间借贷司法解释上限；利率是否合规改走监管规则核验，核验失败则该法律结论停止。
2. 民间借贷路径：调用 `search_law` 查询“民间借贷利率司法保护上限 现行规定”。仅当返回现行有效规则时写入 `L#`，再对照文本利率与“合同成立时”的保护标准。
3. 开发窗口 2026-08-18 核验结果（供对照，不得代替运行时核验）：《最高人民法院关于审理民间借贷案件适用法律若干问题的规定（2020 第二次修正）》法释〔2020〕17 号第 25 条，约定利率超过合同成立时一年期贷款市场报价利率四倍的部分不予支持。逾期利率见第 28 条；逾期利息、违约金或其他费用总和见第 29 条。
4. 核验失败或只返回已修改文本：利率法律结论字段停止。仍可摘录文本利率并给出“待核验现行上限后改写”的修改句草稿，不得写成“按 24% 合法”或“按旧四倍合法”。
5. 一年期 LPR 当次数值未核验：不编造百分比，用 `【合同成立时一年期 LPR × 核验所得倍数，待填】`。
6. 利息预扣按实际交付额计本金和利息。服务费、咨询费、通道费与逾期利息、违约金并行时按费用总和审查。
7. 自然人之间借款：合同自贷款人提供借款时成立。未交付不得写成借款合同已成立。砍头息以到账为本金。
