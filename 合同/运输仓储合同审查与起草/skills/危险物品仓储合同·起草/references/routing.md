# 边界与路由

本技能只审查 **仓储合同 / 危险物品仓储合同**。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 普通工业品／原材料，常温通风即可，无危化专库、无经营／储存许可主给付 | `普通货物仓储合同·审查`。不得删掉“普通货”声明后当危化仓审 |
| 易腐、冷链、温湿度控制是主给付且货性不是危险物品 | `易变质物品仓储合同·审查` |
| 核心给付是危货从甲地运到乙地；运单、车辆、承运人、道路危险货物运输许可证 | `道路货物运输合同·审查`。未装或类型未定：`货运合同·审查` 或引擎。不得用运证充当仓储许可继续审 |
| 仅出租库房／货位，无储存保管劳务，事故／货损自负 | `仅出租库房／货位，保管人对货损和事故不负责→` |
| 转移货物所有权换价款 | `核心给付是转移货物所有权换价款→` |
| 港区危险货物作业／仓储且主给付是港口作业而非陆上仓储 | 许可字段停止或转引擎；港区内港口经营人仓储经营可豁免危化经营许可证，但仍须港口经营许可，不在本类型改无证港区结构 |
| 有完整待签文本要评改 | `危险物品仓储合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、入库／巡检／出库留痕 | 本套导航的履约步骤 |
| 已成争（泄漏、火灾、爆炸、污染索赔、催告、解除、立案、仲裁） | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

专业版未收录本 P1 场景。若用户拿危险物品仓储文本来找未安装本原子的专业版：输出 `unavailable`，提示，不得用普通仓储 `普通货物仓储合同·审查` 硬套。

本技能不得转去加载普通仓储、运输或租赁双文件完成本类型审查。普通货、危货运输、只租空库或卖货一旦构成主给付，立即负触发，不得删掉该部分后继续当危险物品仓储审。
