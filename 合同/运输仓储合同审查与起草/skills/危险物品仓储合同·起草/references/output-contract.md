# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、事故必然不发生、刑责可约定免除或对方接受；编造未给出的许可编号、UN 号、温度／压力参数、保险额；把已失效《合同法》仓储章、《仓储保管合同实施细则》、1987 年化学危险物品条例写入结论；把普通仓仓单／提存主路径、危货承运人责任或房屋租赁维修规则硬套本类型。

## 1. 触发、单方立场与成果状态

立场（存货人／保管人）、授权、签署状态、主要目标。普通仓稿、危货运输稿、租仓稿、易腐仓、动产买卖稿或其他负触发写路由，不启动实体审查。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》仓储章、《仓储保管合同实施细则》、1987 年化学危险物品条例或 2010 年道路危货规定时记噪声，不得写入 `L#`。返回普通仓提存主路径或危货承运人责任专属规则时标明“不适用本类型”，不得写入默认法。

## 3. 类型与加载路径

父级 `仓储合同`，子级 `危险物品仓储合同`。写定性理由和与普通仓储／危货运输／租仓／易腐仓／动产买卖的切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。无许可、禁限物品或运证冒充仓储许可写停笔告知，不填可履行规避结构。

## 4. 主体、授权、资质与文本版本

主体表：签约名、仓库经营人、存货人名、付款名、发票名、授权签字人、安全生产负责人、授权提货人。保管人写：危化经营许可证（带储存设施）或其他法定储存资格、许可范围是否覆盖品类、消防验收／环评／安全评价是否被材料提及；港区作业另写港口经营许可。存货人写生产、经营或使用资质。版本表：正文、安全协议、应急预案、MSDS 资料册、货物清单、应急联络表、聊天确认；冲突并列，不选对用户有利的一版。

## 5. 给付闭环（本类型必填）

固定检查并回链文本：

- 化学名称、危险性类别、UN 号、数量、批次；是否禁限或淘汰物品；
- 保管人许可种类、许可范围与品类是否匹配；专库地址是否在许可载明场所；
- 存货人书面告知：理化特性、禁忌、急救措施；MSDS 与安全标签是否与货物一致；
- 包装强制性标准、危险品标志和标签；渗漏、变形、品名不符必须拒收；
- 专用仓库参数（温控、压力、通风、防雷防静电、监控、泄漏报警）；禁忌混储反说；剧毒／重大危险源单独存放与双人收发；
- 入库核对（品名、数量、批次与许可文件一致）及《危险品入库安全确认单》；
- 在库巡检、数字化台账、出入库核查登记；易制毒／易制爆报备义务；
- 泄漏／火灾应急预案：报警、疏散、洗消、环境污染防控、报告机关、紧急处置事后通知；
- 仓储费构成：基础仓储费、安全监控费、危废预留、应急物资；不得只写“仓租”；
- 环境治理费用、第三人损害、安责险／环责险投保主体和保额下限；
- 过期危化报请销毁、合同终止后残留污染物清理与土壤监测。

缺口标 `G#`，不补商业数字或许可编号。许可、安全评价、消防、应急预案备案写成义务或条件，不写成已经完成。

## 6. 格式条款与强制规范

是否构成格式条款（含保管人制式危化仓文本）。重点盯“重大事故概不负责”“无 MSDS 也可入库”“运证视为仓储许可”“刑责由对方全部承担”。强制规范只区分是否导致民事行为无效与是否仅造成履行障碍（经营／储存许可、专库、禁限物品）。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。禁用已失效“效力性／管理性”口诀。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。硬闸六项若文本触及或存货人／保管人立场下原文沉默，必须各有至少一行，不得用色块代替。

## 8. 修改句

按框架六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点、不接受时的红线。未给出的商业数字用 `【待填】`。禁止只给原则、不给句子。禁止输出普通仓“口头放货／催告后提存”作为本类型主修改句，禁止输出危货承运人责任限额或租赁维修／返还房屋句。

## 9. 谈判与签署提醒

谈判顺序：先红线（无许可或范围不及、禁限物品、渗漏仍入库、运证冒充仓储许可、概括免除重大事故或刑责、无应急预案），再必须改（MSDS 与包装标识、专库参数与禁忌混储、入库确认单、报备、保险、退库清污），最后可优化。签署提醒：公章＋安全生产负责人会签、骑缝、日期不得倒签、附件清单（MSDS、安全协议、应急预案、应急联络表、入库确认单样张）。许可和安全评价不写成已经取得。不指导倒签或补假许可。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本原子只起草并自审，不评改对方来稿。待签评改转配对 ·审查 原子。草稿必须落入本类型三闸。不是出入库履约交底、事故诉讼文书、危废处置代办或效力保证。
