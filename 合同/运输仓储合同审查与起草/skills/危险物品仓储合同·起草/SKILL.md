# 危险物品仓储合同·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **仓储合同 / 危险物品仓储合同**，输出可编辑草稿和未决项，并用本类型硬闸自审后给出风险表和修改句。待签评改转 `危险物品仓储合同·审查`。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。`depends-on` 为空。不要求先跑导航。

不交付：他类审查、从零起草、出入库履约交底、泄漏／爆炸／污染争议文书、有效性或事故必然不发生／刑责可约定免除的保证。

## 工作边界

正触发：已有可读待签文本要评改（审查模式），或本类型条件已谈妥要出己方稿（起草模式）；尚未签署，尚未成争，核心给付是保管人在具备相应保管条件的专用仓库储存存货人交付的**危险物品**（易燃、易爆、有毒、腐蚀性、放射性等），存货人支付仓储费；文本常伴随危化经营／储存许可、MSDS、包装标识和泄漏应急安排。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 仓储物是普通工业品／原材料，常温通风即可，无危化专库、无经营／储存许可主给付 → `普通货物仓储合同·审查`；
- 易腐、冷链、温控是主给付且货性不是危险物品 → `易变质物品仓储合同·审查`；
- 核心给付是把危险货物从甲地运到乙地（运单、车辆、承运人、道路运输许可） → `道路货物运输合同·审查`；未装或类型未定 → `货运合同·审查` 或引擎重新定性；
- 仅出租库房／货位，保管人对货损和事故不负责 → `仅出租库房／货位，保管人对货损和事故不负责→`；
- 核心给付是转移货物所有权换价款 → `核心给付是转移货物所有权换价款→`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问入库、巡检、出库留痕 → 本套导航的履约步骤；
- 已成争（泄漏、火灾、爆炸、污染索赔、催告、解除、诉讼仲裁）→ `或对应专项领域。` 或对应专项领域。

无危化经营／储存许可仍要“改到能入”、把禁限物品改成可入库、用道路运输许可证冒充仓储许可：只出告知，不改写成可履行入库结构。

## 建立审查坐标

确认：使用者与授权；存货人或保管人单一立场；相对方；正文、安全协议、应急预案、MSDS 资料册、货物清单版本；化学名称／危险性类别／UN 号；仓库地址与专库条件；保管人许可种类及许可范围是否覆盖品类；不可接受事项；法域与拟签时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的费率、数量、温度／压力参数、保险额用 `【待填】`，不编造。

## 本类型硬闸

审查过程必须逐项点名，不得用普通仓仓单／提存清单或危货运输承运清单代替：

1. **危化仓储 ≠ 普通仓储 ≠ 危货运输 ≠ 租仓**：普通仓无专库、无危化许可、无 MSDS 主给付 → `普通货物仓储合同·审查`。道路运输经营许可不能替代仓储／经营许可；运单＋车辆＋承运是运输 → `道路货物运输合同·审查`。只租空库、事故自负 → `仅出租库房／货位，保管人对货损和事故不负责→`。
2. **危化仓储许可**：保管人须具备与品类匹配的危险化学品经营许可证（带储存设施）或其他法定储存资格；港区内港口经营人依办法可豁免经营许可证，但仍须港口经营许可。许可范围必须覆盖 UN 类别。存货人须有生产、经营或使用相应资质。无许可或范围不及：红线，不改成可履行。
3. **告知、MSDS、包装标识**：存货人应当说明理化特性、禁忌、急救措施，提交与货物一致的安全技术说明书和安全标签。包装须符合强制性标准并有明显危险品标志。渗漏、变形、品名不符、安全附件失效：**拒绝入库**，不得改成“先入后补证”。
4. **专库与禁忌混储**：必须储存在专用仓库／专用场地，分类分项；性质相抵触、灭火方法不同的不得同库。剧毒或构成重大危险源的应单独存放并实行双人收发。出入库核查登记；易制毒／易制爆按规则向公安机关等报备。
5. **泄漏应急**：合同必须有可执行应急预案：报警、疏散、洗消、环境污染防控、向应急管理和公安机关报告、紧急处置事后通知。保管人须配备应急人员和器材。不得只写“按有关规定处理”。
6. **环境责任、保险、禁限与刑责**：环境治理和第三人损害须有归属，不得概括免责吞没重大事故。高危行业应当投保安全生产责任保险；修改句要求安责险／环境污染责任险，不把“一律强制”写成未核验的全行业法。禁止流通或国家明令淘汰物品：停笔。刑事责任不得约定免除。过期危化、退库残留污染物清理必须落句。


## 起草模式

本原子只承担本类型起草。待签评改转 `危险物品仓储合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。本约锁具备相应保管条件的专用仓库储存危险物品，不用道路运输许可冒充仓储许可。

1. 先按框架六步落稿：首部锁品类／UN 号与许可范围匹配；交易条款写告知、MSDS、包装标识、专库与禁忌混储、双人收发；配套写泄漏应急、环境责任与保险；尾部写过期危化与退库清污；正说反说后按下述必写与禁忌落句。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿。自审至少核对：许可是否覆盖 UN 类别、有无先入后补证、应急预案是否可执行、刑责是否被约定免除。输出风险表和修改句。不得只交白稿。
3. 普通仓、易腐仓、危货运输、租仓出稿、已签履约、已成争：仍负触发。

**起草必写**：保管人须具备与品类匹配的危险化学品经营许可证（带储存设施）或其他法定储存资格；港区内港口经营人依办法可豁免经营许可证，但仍须港口经营许可。许可范围必须覆盖 UN 类别。存货人须说明理化特性、禁忌、急救措施，提交与货物一致的安全技术说明书和安全标签；包装须符合强制性标准并有明显危险品标志。必须储存在专用仓库／专用场地，分类分项；性质相抵触、灭火方法不同的不得同库。剧毒或构成重大危险源的应单独存放并实行双人收发。出入库核查登记；易制毒／易制爆按规则向公安机关等报备。应急预案必须可执行：报警、疏散、洗消、环境污染防控、向应急管理和公安机关报告、紧急处置事后通知；保管人须配备应急人员和器材。环境治理和第三人损害须有归属。高危行业应当投保安全生产责任保险；修改句要求安责险／环境污染责任险。过期危化、退库残留污染物清理必须落句。

**附件必附**：与货物一致的安全技术说明书和安全标签（MSDS）；可执行应急预案；货物清单（化学名称、危险性类别、UN 号）。

**禁止出现**：无许可或范围不及仍入库；先入后补证；渗漏、变形、品名不符、安全附件失效仍入库；只写“按有关规定处理”；概括免责吞没重大事故；刑事责任约定免除；道路运输经营许可替代仓储／经营许可；禁止流通或国家明令淘汰物品改成可入库。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验仓储成立、危险告知与保管条件、入库验收、危化经营／储存许可、专用仓库与出入库登记、应急预案与事故报告、安全生产责任保险、格式条款和强制规范是否导致无效；`search_practiced` 补审查反例；`search_template` 只借修改句结构。不虚构案件系统。

`search_law` 对法律结论为 required 级节点：不可用时不拒绝执行，只停止法律结论字段。返回已失效《合同法》仓储章、《仓储保管合同实施细则》、1987 年化学危险物品条例或 2010 年道路危货规定时记为噪声，不得写入 `L#`。返回普通仓提存主路径或危货承运人责任专属规则时，不得当作本类型默认法。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、把无许可或禁限物品改成可入库、用道路运输许可证冒充仓储许可、保证事故必然不发生或刑责可约定免除。
- `字段停止`：品类是否列入危化目录未核验；许可种类／范围未核验；MSDS 与货物是否一致未核验；应急预案备案层级未核验；安责险是否属于法定应当投保范围未核验。
- `目标停止`：主目标已变为他类型起草、履约交底或争议文书。

生存级货值、周边敏感受体或个人无限连带且用户拒绝升级：停止“可以签署”建议。
