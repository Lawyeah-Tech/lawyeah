# 边界与路由

本技能只审查 **运输合同 / 道路货物运输合同** 的待签文本。中文展示名是「审查道路货物运输合同（运输合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 通篇只走民法典货运节，无道路运政许可、车辆道路运输证、治超或道路危货资质主路径 | `货运合同·审查`。禁止用本技能把一般货运改成道路专项 |
| 只撮合车源或订舱，不承运，不以自己名义签发道路运单 | `货运代理合同·审查`。P1：专业版未装则 `unavailable`，提示，不得用本技能硬套。纯媒介也可交 `房屋买卖或租赁中介→` |
| 货代以自己名义签发道路运单并收取运费，或不能证明授权而以承运人代理人名义签发 | **不转出装切开**。按本类型承运人义务审查，或同时提示货代原子只处理代理段 |
| 网络货运平台入驻、无车承运人平台规则、信息撮合平台规则是主路径 | `网络货运平台模式下的运输合同·审查`。P1；未装则 `unavailable`。仅“无自有车辆但以承运人身份签道路运单、无平台规则”的，留本类型 |
| 旅客、客票、改退签、人身伤亡、随身物品 | `客运合同·审查` |
| 两种以上不同运输方式，经营人负责全程 | `多式联运合同·审查`。P1；未装则 `unavailable` |
| 只储存保管、出具仓单、不对位移负责 | `普通货物仓储合同·审查`。不得用仓单/入库验收句改道路货运 |
| 铁路运单、铁路保价与限额为主路径 | `铁路运输合同·审查`。P1；未装则 `unavailable` |
| 航空货运单、声明价值、民用航空法限额为主路径 | `航空运输合同·审查`。P1；未装则 `unavailable` |
| 提单、海商法单位责任限制为主路径 | `海上货物运输合同·审查`。P1；未装则 `unavailable` |
| 有完整待签文本要评改 | `道路货物运输合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、只问发运在途签收留痕 | 本套导航的履约步骤 |
| 已成争，或用户要货损索赔诉讼策略 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

道路货运正文里夹带一小段仓储暂存或装卸：货损期间仍先按承运人掌管期间审；独立计价且以保管为主的仓储专条可交接 `普通货物仓储合同·审查`。用户坚持本技能把一般货运、货代、网络货运平台、客运、仓储、多式联运或海商提单整案改完：`目标停止`。
