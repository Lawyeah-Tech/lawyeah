## **第一步：合同类型（法律性质）分析**

* **法律定性**：多式联运合同是多式联运经营人**以两种以上不同运输方式**负责将货物从接收地运至目的地交付收货人并收取全程运费的合同。《民法典》第838条规定，经营人负责履行或组织履行合同，对全程运输享有承运人的权利、承担承运人的义务。它是货运合同的特别类型，不是几个独立运输合同的简单捆绑。
* **必须先做的外延辨析（民法典 ≠ 海商法）**：
  * **民法典多式联运**：只要两种以上**不同运输方式**（如公路+铁路、公路+航空、铁路+内河），**不要求**其中一种是海上运输。
  * **海商法多式联运**（第102条）：必须是两种以上不同方式且**其中一种是海上运输**，经营人负责全程并收取全程运费。国际海运+内陆段、沿海国际中转等才进入海商法第四章多式联运专节。
  * 不含海运的国内公路+铁路联运，适用民法典第838—842条，**不能**直接套用海商法单位责任限制。
  * 含国际海运区段的，经营人全程责任仍在，但货损发生在海运区段时，赔偿责任和限额可能适用海商法；区段不能确定的，海商法规定适用其第四章限额，民法典规定则回到运输合同章。
* **与“同一方式联运”区分**：《民法典》第834条针对**同一运输方式**的相继运送（如两家公路承运人分段），订约承运人对全程负责，损失区段确定时与该区段承运人连带。它不是多式联运，不要在标题和责任条款里混用。
* **效力认定**：经营人无相应区段许可的，不当然否定全程合同，但转包给无资质实际承运人造成损失的，经营人不能免责。签发可转让多式联运单据后，单据持有人成为有权提货和索赔的人；伪造、无单放货按承运人根本违约处理。

## **第二步：合同主体（交易对手）分析**

* **多式联运经营人**：与托运人订约、签发多式联运单据的人，可以自己履行某一区段，也可以全部组织他人履行。审查其是否具备至少一种运输方式的经营能力或无船承运、国际货代等合法身份，以及是否有赔付能力（保险、保函）。
* **区段承运人**：公路、铁路、海运、航空实际承运人。经营人与他们的分合同**不影响**经营人对托运人、收货人的全程义务（第839条；海商法同样禁止以内部分摊对抗货方）。
* **托运人**：交付货物并申报；因托运时过错造成经营人损失的，即使单据已转让，托运人仍应赔偿（第841条）。
* **收货人 / 单据持有人**：不可转让单据记载的收货人，或可转让单据的合法持有人。两者身份必须在签发时锁定规则。
* **货代身份错位**：以自己名义签发多式联运提单或运单的货代，按经营人掌握，不得再主张“仅代理订舱”。

## **第三步：合同标的（交易对象）分析**

* **全程位移**：接收地、各换装地、目的地、运输方式组合、是否含海运，必须在合同和单据上画清。缺海运却自称“海商法多式联运”的，定性错误。
* **货物与集装箱**：箱货一体还是拆装箱、FCL/LCL、由谁装箱、铅封号，决定货损是箱体责任还是箱内货物责任。
* **单据性质**：第840条，经营人收到货物应签发多式联运单据，按托运人要求做成**可转让或不可转让**。可转让单据具有提货凭证和一定的物权凭证功能，丢失、转让背书是审查重点；不可转让单据只对记名收货人交货。
* **区段法律适用对象**：标的不是单一法域下的“一段路”，而是可能触发不同责任限额的区段组合。贵重货、冷链、危货在某一区段被禁运的，全程合同可能履行不能。

## **第四步：合同程序（交易步骤）分析**

* **接收与签单**：经营人接管货物（堆场、仓库、工厂）时起算责任。签单前的批注（不清洁单据）决定日后能否抗辩货损原已存在。
* **换装**：各区段交接应有箱体、封志、温度、货损记录。货损区段举证不宜对托运人要求过高；区段不能确定的，依第842条按民法典运输章赔偿，经营人不能把“区段不明”转成货方败诉理由。
* **交付**：凭单据或约定电放。电放须有托运人书面指示并回收全套正本或声明作废。
* **内部分摊**：经营人可与区段承运人约定追偿，但应在分合同中保留与货方面索赔相当的时效和证据配合义务。
* **行政程序**：国际段的报关、报检可以由经营人作为代理完成，合同须写清是运输义务还是另行委托，避免把海关处罚风险无交接。

## **第五步：交易结构设计（风险规避方案）**

* **网状责任 vs 约定提高**：第842条是法定网状责任——能确定区段则适用该区段法律的责任和限额，不能确定则适用民法典运输章。合同可以**书面提高**经营人责任（例如全程按实际损失、放弃某一区段限额），但不得把责任降到低于法定网状规则，也不得约定“一律适用对经营人最有利的区段法”。
* **运费**：全程一价还是分段披露。预付运费与到付、目的地费用（到付运费、滞箱、堆存）分开。经营人向区段承运人垫付的费用如何向货方归集，须有单据。
* **留置与滞箱**：经营人对未付全程运费、垫付费用，可对仍在其掌管下的货物主张留置；滞箱费属于集装箱租赁关系还是运输附随费用，应单独约定，避免用海运滞箱标准覆盖全程公路段。
* **保险**：要求投保全程一切险或预约保险，约定保险人不放弃对经营人的代位或相反；保价、声明价值只约束对应区段时，应说明未覆盖区段的处理。
* **退出**：中途变更目的地涉及多区段改签、舱位作废，费用预估应分段列明。

## **第六步：宏观风险预警与尽调指引**

* **高频争议点**：经营人主张自己只是货代；货损区段不明时的法律适用；可转让单据无单放货；海商法多式联运被误套到无海运的国内联运；分合同免责被拿来对抗货方。
* **尽职调查清单**：
  * [ ] 运输方式组合是否≥两种且互不相同
  * [ ] 是否包含海上运输，从而决定能否适用海商法多式联运专节
  * [ ] 经营人签发的是多式联运单据还是各区段分别的运单/提单
  * [ ] 单据可转让性、份数、电放条件
  * [ ] 接收地、换装地、目的地及各区段实际承运人
  * [ ] 责任条款是网状、统一还是低于法定标准
  * [ ] 经营人责任险、提单责任险是否覆盖全程
* **重大风险红旗**：无海运却引用海商法单位责任限制；只签各区段合同却在对外报价中自称“全程负责”又不签多式联运单据；可转让正本在外仍电放；要求托运人证明货损发生在某一区段才受理索赔。
