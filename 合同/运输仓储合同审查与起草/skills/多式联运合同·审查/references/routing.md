# 边界与路由

本技能只审查 **运输合同 / 多式联运合同** 的待签文本：经营人以两种以上不同运输方式负责将货物从接收地运至目的地交付收货人并收取全程运费。中文展示名是「审查多式联运合同（运输合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或复制 `货运合同·审查`、`道路货物运输合同·审查` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 仅一种运输方式；通篇货运节，无第二种不同方式 | `货运合同·审查` |
| 道路运政许可、车辆营运证、治超或道路危货资质为主路径，且只有公路 | `道路货物运输合同·审查` 或 `道路运输合同·审查` |
| 两个以上承运人以**同一**运输方式相继运送（两段公路、两段铁路、水水联运） | 民法典第八百三十四条路径；转 `货运合同·审查` 或对应单式原子，不套第八百四十二条 |
| 铁路货物运单、铁路保价限额为主文件，无第二种不同方式 | `铁路运输合同·审查` |
| 航空货运单、声明价值或民用航空法限额为主，无第二种不同方式 | `航空运输合同·审查`；国内／国际航空专项 → `国内航空运输合同·审查`／`国际航空运输合同·审查` |
| 水路运单或内河／沿海单式，无第二种不同方式 | `水路运输合同·审查` 或 `水路货物运输合同·审查` |
| 海运提单、航次租船或海上货物运输本约，无第二种不同方式 | `海上运输合同·审查` 或 `海上货物运输合同·审查` |
| 只撮合订舱、报关或代办，不以自己名义签发多式联运单据，不收全程承运对价 | `货运代理合同·审查` |
| 货代以自己名义签发多式联运提单或运单、收取全程运费 | **留本任务**，按经营人审查，不得转出装切开 |
| 网络货运平台入驻、无车承运人平台规则 | `网络货运平台模式下的运输合同·审查` |
| 客运、道路乘客、水路或海上旅客 | `客运合同·审查` 或对应乘客原子 |
| 保管、仓单、入库验收为主给付，位移只是附带 | `普通货物仓储合同·审查` |
| 国际运输或国内运输总类货架、核心却不是多式联运 | `国际运输合同（涉外运输合同）·审查` 或 `国内运输合同·审查`；不代做 |
| 无文本、本类型条件已谈妥、要出己方稿 | `多式联运合同·起草` |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或对应专项领域。` 或对应专项领域 |
| 已立案货损、海事保全、无单放货诉讼 | 争议或海商专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

多式联运正文里夹带一小段单式运单或货代报关委托：专章交接对应原子；全程经营人条款可继续审。用户坚持本技能把一般货运、道路货运、铁路／航空／海商本约或货代只撮合整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
