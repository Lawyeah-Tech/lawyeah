# 货运合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》运输章、《汽车货物运输规则》、《国内水路货物运输规则》当作现行规则。不得把仓储仓单/入库验收、客运改退票或货代佣金主路径硬套本类型。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **运输合同 / 货运合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。中文名必须是「货运合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、在途履约交底、货损争议文书、有效性或货必无损保证。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **货运 ≠ 客运 ≠ 货代 ≠ 多式联运 ≠ 仓储**：核心给付是货物的空间位移与完好交付。旅客 → `客运合同·审查`。只撮合、不调度运力、不收运费不开运费发票 → `货运代理合同·审查` 或 `房屋买卖或租赁中介→`。两种以上运输方式且经营人全程负责 → `多式联运合同·审查`。只存货不位移 → `普通货物仓储合同·审查`。货代以自己名义签发运单或提单，或不能证明承运人授权而以承运人代理人名义签发的，可能被认定为承运人，**不得假装已经切开**。
2. **货物特定化 + 运单是合同组成部分**：运单须记载名称、件数、重量、包装、收货人。未签正式合同但已签发运单并接收货物的，合同成立。禁止“运单仅供内部、不作为合同”。
3. **货损期间**：承运人对运输过程中（掌管期间）毁损、灭失承担责任，法定免责除外。格式“货损概不负责／已保险即免责”必须改。无特别法限额的道路、内河按到达地市场价格赔实际损失（第 833 条）。约定限额对托运人过苛的，可能不成为内容或无效。
4. **危险品／禁运**：未书面说明性质并包装、标志的，承运人可拒运。走私或禁止运输货物：停笔。无相应许可把危化当普通货：红线。
5. **运费与灭失**：货物因不可抗力灭失的，未收运费不得再要，已收应返还（第 835 条）。禁止“运费概不退还”。
6. **留置仅相应货物**：不支付运费、保管费或其他费用的，承运人仅对**相应的运输货物**享有留置权（第 836 条）。禁止“可留置托运人任何财产”。收货人不明或拒领：提存（第 837 条），不是擅自变卖私分。
7. **变更指令**：交付收货人前，托运人可要求中止运输、返还、变更到达地或收货人，但应赔偿承运人损失（第 829 条）。必须写通知时点与费用。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签货运正文，尚未签署，尚未成争，核心给付是承运人将货物从起运地运到约定地点并交付收货人，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 对象是旅客、客票、改退签、人身伤亡主路径 → `客运合同·审查`；
- 只撮合车源或订舱、不承运、不以自己名义签发运单 → `货运代理合同·审查`；专业版未装则 `unavailable`。纯报告订约机会也可交 `房屋买卖或租赁中介→`；
- 两种以上不同运输方式且由经营人负责全程 → `多式联运合同·审查`；未装则 `unavailable`；
- 只储存保管、不负责位移 → `普通货物仓储合同·审查`；
- 来稿明确只走道路特别规则、道路运政许可与路政责任是主路径 → `道路货物运输合同·审查`；
- 铁路运单、铁路保价与限额是主路径 → `铁路运输合同·审查`；未装则 `unavailable`；
- 航空货运单、声明价值、民用航空法限额是主路径 → `航空运输合同·审查`；未装则 `unavailable`；
- 提单、海牙/海商法单位责任限制是主路径 → `海上货物运输合同·审查`；未装则 `unavailable`；
- 网络货运平台、无车承运人平台规则是主路径 → `网络货运平台模式下的运输合同·审查`；未装则 `unavailable`；
- 无文本、本类型条件已谈妥、要出己方稿 → `货运合同·起草`；
- 已签只问发运、在途、签收留痕 → 本套导航的履约步骤；
- 已催告、货损索赔、解除、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

走私、禁运、无许可危化当普通货：只出告知，不改写成可履行承运结构。

## 建立审查坐标

确认：使用者与授权；单方立场（托运人侧或承运人侧择一）；相对方；全文及运单/货物清单版本；核心给付是承运还是撮合/储存/载客；运输方式是否两种以上；货名件数重量包装收货人；是否危货或禁运；运费预付或到付；货损限额或保价；留置范围；变更指令安排；承运人许可痕迹；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的运费、货值、期限用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验第 809、825–837 条、格式条款、835 运费返还、836 留置、833 市价；`search_practiced` 只补审查反例；`search_template` 只借栏目结构。不虚构案件系统。

`search_law` 对上述法律结论为 required 级：不可用时不拒绝执行，只停止效力字段。返回已失效《合同法》运输章、《汽车货物运输规则》、《国内水路货物运输规则》时记为噪声，不得写入 `L#`。返回仓储仓单规则、客运改退票或海商单位责任限制时，不得当作本类型默认法。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `货运合同·起草`；已签履约 → 本套导航履约步骤；已成争货损索赔 → 合同争议。未签且目标是评改已有货运文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。客运、仓储、只撮合货代、多式联运、特别法主路径负触发。货代签发运单的，留下承运责任审查，不得假装已切开。

### 2. 主体与许可

签约名、履行名、开票名、实际承运人分列。经营性许可未核：字段停止，不写“可以经营货运”。

### 3. 货物特定化与运单

名称、件数、重量、包装、收货人必须可核验。运单是合同组成部分。

### 4. 货损期间、833 与保险

掌管期间归责；法定免责须举证。已保险不免除承运人责任。

### 5. 运费 835、留置 836、提存 837

不可抗力灭失返还运费。留置仅本票货物。拒领走提存。

### 6. 危货 828、审批 826、申报 825

未书面说明可拒运。走私/无许可危化停笔。

### 7. 变更 829、通知提货 830、格式条款

交付前变更须保留并写费用。无核验引文则法律结论字段停止。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证货必无损、把走私/禁运或无许可危化改成可承运、坚持货损概不负责／运费概不退还／留置任何财产／擅自变卖。
- `字段停止`：法域、特别法限额数字、危货属性、经营许可未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。

生存级货值或个人无限连带且用户拒绝升级：停止“可以签署”建议。
