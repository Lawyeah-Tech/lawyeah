# 审查方法（锁定 运输合同 / 货运合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制仓储仓单/入库验收/催告提存仓储物主路径、客运改退票、货代佣金或海商单位责任限制精算。

定性校验：标题、核心给付与本类型一致才继续；旅客、只存货、只撮合、两种以上方式全程责任、特别法主路径明显则负触发，不填十节实体结论。货代以自己名义签发运单或提单的，**不得因标题写“代理”而假装已切开**。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、货必无损、对方必然接受或唯一必得赔偿额。

`search_law` 返回已失效《合同法》运输章、《汽车货物运输规则》、《国内水路货物运输规则》、失效经济合同法或合同法解释（二）第 14 条时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突。

示范文本只参考结构。货运示范文本不证明本约条款已被接受；符合格式条款定义的，仍按格式条款审查。

知识库纠正（不回写双文件）：

- `框架.md` “视同完好交付”：第 831 条未在约定期限或合理期限提出异议，只是视为按运输单证记载交付的**初步证据**，不得写成丧失全部索赔权。隐蔽损害须保留合理检验期。
- `基本面.md` “含短驳、含仓储”：一票到底货运的货损期间仍先按承运人掌管期间认定，不得改走仓储原子或套仓单规则。
- 海上货代司法解释 2012 年第 4 条（自己名义签发运输单证可被主张承运人责任）标注“已被修改”。运行时以 2020 修正本对应条复核后再写入 `L#`；本方法只把“可能被认定为承运人”作为切开纪律。
- 引用《汽车货物运输规则》作归责依据：删除，改引第 832、833 条及现行特别法。

### 双文件使用

- 含“首部／交易条款／配套／尾部／语言／常见问题”六步的（本目录 `框架.md`），供节点 8 出句；

## 节点 1　类型识别与邻类负触发

### 1.1 本类型正像

同时满足才继续：

- 核心给付是承运人将托运人交付的**货物**从起运地点运输到约定地点并交付收货人，托运人或收货人支付运费（空间位移与完好交付，不是储存劳务，不是载客，不是只报告车源）；
- 运输方式未锁定为必须适用铁路、航空或海商特别法的主路径；也不是两种以上方式由经营人负责全程；
- 对方接收货物并负责运达。标题写成“物流服务”“供应链服务”只是线索。

名实不符按核心给付归类，标题冲突写入 `C#`。

### 1.2 必须切开（禁止两套知识）

| 信号 | 归入 | 本技能动作 |
| --- | --- | --- |
| 对象是旅客、客票、改退签、人身伤亡 | 客运合同 | **负触发** → `客运合同·审查`。不得用货损 833 改旅客人身条款 |
| 只撮合车源或订舱，不调度运力，不收运费、不开运费发票，不以自己名义签发运单 | 货运代理 / 中介 | **负触发** → `货运代理合同·审查` 或 `房屋买卖或租赁中介→`。未装 P1 则 `unavailable` |
| 以自己名义签发运单或提单，或不能证明授权而以承运人代理人名义签发 | 可能构成承运 | **留下本类型**。按承运人义务审，不得假装已切开 |
| 两种以上不同运输方式，经营人负责全程 | 多式联运 | **负触发** → `多式联运合同·审查`。不得拆成互不相关的单式合同逃避全程责任 |
| 只储存保管、出具仓单、不对位移负责 | 仓储 | **负触发** → `普通货物仓储合同·审查`。不得用仓单/入库验收句继续审 |
| 来稿明确只走道路运政许可、路政、道路货运特别规则 | 道路货物专项 | **负触发** → `道路货物运输合同·审查`。本类型是一般货运 |
| 铁路运单、铁路保价与限额是主路径 | 铁路运输 | **负触发** → `铁路运输合同·审查` |
| 航空货运单、声明价值、民用航空法限额是主路径 | 航空运输 | **负触发** → `航空运输合同·审查` |
| 提单、海商法单位责任限制是主路径 | 海上货物运输 | **负触发** → `海上货物运输合同·审查` |
| 网络货运平台规则、无车承运人平台是主路径 | 网络货运 | **负触发** → `网络货运平台模式下的运输合同·审查` |

邻类稿误入是硬闸：一旦载客、只存货、只撮合且未签发运单、两种以上方式全程责任或特别法主路径构成主给付，立即停笔转出。不得删掉该部分后继续当一般货运审。

### 1.3 加载协议

只打开本目录 `基本面.md` 与 `框架.md`。禁止读 `types/` 或其他场景原子目录。

### 1.4 违法结构停笔

出现下列任一结构，只出告知，不改写成可履行文本：

- 托运走私货物、禁止流通物或国家禁止运输货物，仍要“改到能运”；
- 无相应危货运输许可却把危化当普通货承运；
- 倒签合同或运单日期以改变许可、保险或会计时点；
- 伪造营运证、危货许可或运单。

用户坚持“改到能运／能过检”：整体停止。合规改道（真实取得许可后再签、真实申报）只点名，不在本任务起草规避方案。

## 硬闸 A　货运 ≠ 客运 ≠ 货代 ≠ 多式联运 ≠ 仓储

本闸改变技能能否继续。依据第 809 条：运输合同是承运人将旅客或货物从起运地点运输到约定地点，旅客、托运人或收货人支付票款或运费的合同。本类型只取**货物**一侧。

1. **位移正像**  
   承运人接收货物并负责运达。文本写成“仅提供库位”或“仅介绍车辆”：标名实冲突。

2. **客运负向**  
   第 814 条：客运自出具客票成立。对象是旅客则转 `客运合同·审查`。随车押运人不是把本合同改成客运的理由。

3. **货代负向，但签发运单不得装切开**  
   只撮合、不承运、不签发运单：转 `货运代理合同·审查` / `房屋买卖或租赁中介→`。  
   正文称“代理安排车辆”，却签发以自己为承运人的运单并收取运费差价：对外身份按承运人锁定。海上货代解释 2020 修正本第 2 条：货代事务可分别形成代理、运输、仓储关系。不得因为标题写代理就免除 832 条责任。

4. **多式联运负向**  
   第 838 条：多式联运经营人对全程享有承运人权利、承担承运人义务。两种以上方式且全程负责：转 `多式联运合同·审查`。同一运输方式联运走第 834 条，订约承运人对全程负责，可留在本类型。

5. **仓储负向**  
   只存货、出仓单、不负责把货从甲地运到乙地：转 `普通货物仓储合同·审查`。运输前后暂存若独立计价且以保管为主，仓储专条可交接；一票到底货运的货损期间仍先按掌管期间认定。

6. **最强反方**  
   对方主张标题叫物流服务就应按服务合同减责，或主张“我们只是货代所以货损概不负责”。签前按是否接收货物并负责运达、是否签发运单切开。

示例修改句（托运人，文本写成代理免责）：

`第【待填】条｜原文“乙方仅代理安排车辆，运输途中货损概不负责”｜建议改为“乙方作为承运人，负责将货物自【起运地】安全运至【到达地】并交付收货人【姓名或名称】。乙方对运输过程中货物的毁损、灭失承担责任，但能证明存在法定免责事由的除外。乙方可列明实际承运人并向其追偿，但不因此免除对托运人、收货人的全程责任。若乙方仅撮合且不签发运单、不收取运费，应改签货运代理合同，不适用本货运文本”｜理由：硬闸 A；第 809、832、834 条｜可退让：实际承运人可写入附件，缔约承运人责任不减｜不接受：代理名义签发运单仍免责，红线`

## 硬闸 B　货物特定化与运单

本闸改变合同是否成立、交接依据是否可核验。运行时核验第 825 条后再写法律效果。

1. **记载事项**  
   第 825 条：托运人应准确表明收货人的姓名、名称或凭指示的收货人，货物的名称、性质、重量、数量，收货地点等必要情况。修改句补：品名、规格、性质（普通／温控／危险）、包装、件数、毛重、体积、收货人及联系方式。件数与重量同时记载，并约定以何者为交接和计费依据。缺项用 `【待填】`，不编造重量。

2. **运单是合同组成部分**  
   长期协议 + 运单是常见结构。运单记载货物状况、收货人、运费结算，是合同组成部分。  
   **禁止**“运单仅供内部使用／仅供结算、不作为合同”。未签正式合同但已签发运单并接收货物的：现有依据支持合同成立，不得写成“尚未成立所以无责任”。

3. **冲突规则必须选定**  
   运单与框架合同冲突时，修改句选定：货物状况、收货人、到达地以运单为准，责任限制、管辖以框架合同为准（或相反，但必须选定）。要求运单打印框架合同编号。

4. **申报不实**  
   因申报不实或遗漏重要情况造成承运人损失的，托运人赔偿。承运人立场：修改句保留追偿。托运人立场：限定为托运人明知或应知的重要情况，并要求承运人当场批注。

5. **最强反方**  
   承运人主张运单只是内部调度单。托运人签前必须把运单效力落成句子。

示例修改句（托运人，运单仅供内部）：

`第【待填】条｜原文“运单仅供内部结算，不作为合同”｜建议改为“每票运单是本合同组成部分。运单应记载货物名称、件数、重量、包装、收货人、起运地、到达地。运单与本合同冲突时，货物状况、收货人、到达地以运单为准；责任限制、争议解决以本合同为准。未另行签署本合同但已签发运单并接收货物的，货运合同成立。禁止将运单仅作内部单据”｜理由：硬闸 B；第 825 条｜可退让：冲突规则可反向选定，但必须书面选定｜不接受：运单仅供内部，红线`

## 硬闸 C　货损期间、833 与保险

本闸改变货损条款是否被格式免责吞没。运行时核验第 832、833、496、497、506 条。

1. **掌管期间归责**  
   第 832 条：承运人对运输过程中货物的毁损、灭失承担赔偿责任。但是，承运人证明因不可抗力、货物本身的自然性质或合理损耗以及托运人、收货人的过错造成的，不承担赔偿责任。  
   货损区段不清时，订约承运人仍应先承担责任（同一方式联运见第 834 条）。

2. **免责须举证**  
   修改句要求承运人保存并在争议时提供：起运交接与批注、封志、冷链温度记录、到达交接。不得把“包装不良”写成绝对免责而不问承运人是否应发现、是否批注。

3. **赔偿额**  
   第 833 条：有约定从约定；没有约定或约定不明确，依据第 510 条仍不能确定的，按照交付或应当交付时货物到达地的市场价格计算。法律、行政法规对计算方法和限额另有规定的，依照其规定。  
   无特别法限额的道路、内河普通货运：原则上按到达地市价赔实际损失。约定“按运费的 N 倍”对高价值货可能被认定不合理减轻责任。提高限额或保价须书面、单独计价。

4. **已保险 ≠ 承运人免责**  
   保价与保险并行时写清各自范围和代位。禁止“已投保货运险即免除承运人责任”。海商法将保险利益转让给承运人的条款方向：本类型同样不得把保险写成免责借口。

5. **禁止概不负责**  
   承运人制式“货损概不负责”“最高赔运费三倍且排除故意重大过失”：按第 496、497、506 条审查。故意或重大过失造成的财产损失不得免责。

6. **最强反方**  
   承运人主张行业惯例只赔运费倍数，或主张托运人已投保即无请求权。托运人签前必须把 832/833 和保险代位写成句子。

示例修改句（托运人，概不负责＋已保险即免责）：

`第【待填】条｜原文“运输途中货损概不负责；已投保即免除承运人责任；最高按运费三倍赔偿”｜建议改为“承运人对运输过程中货物的毁损、灭失承担赔偿责任，但能证明因不可抗力、货物自然性质或合理损耗、托运人或收货人过错造成的除外。赔偿额按货物在到达地应当交付时的市场价格计算；双方书面约定保价或声明价值的，按保价办理。托运人或收货人投保货运险的，不免除承运人责任；保险人代位后承运人仍按本条对保险人不享有额外免责。故意或重大过失造成的损失不得免除或减轻。本条为限责条款，承运人应加黑提示并由托运人单独签认”｜理由：硬闸 C；第 832、833、496、497、506 条｜可退让：特别法有限额的写明依据并单独确认；可设除故意重大过失外的合理上限，但不得低于【待填】｜不接受：概不负责或已保险即免责，红线`

## 硬闸 D　危险品／禁运

本闸改变能否继续出可履行修改句。运行时核验第 828、826、827 条。

1. **书面说明 + 包装标志**  
   第 828 条：托运易燃、易爆、有毒、有腐蚀性、有放射性等危险物品的，应按国家有关危险物品运输的规定妥善包装，做出标志和标签，并将名称、性质和防范措施的书面材料提交承运人。违反的，承运人可以拒绝运输，也可以采取措施避免损失，费用由托运人负担。

2. **审批文件**  
   第 826 条：需要办理审批、检验等手续的，托运人应当将办完手续的文件提交承运人。未提交：不得写成“可以先运后补证”。

3. **无许可当普通货：红线**  
   道路危险货物运输须取得相应许可。普通货运文本清单夹带溶剂、危化品且承运人无许可：红线。不把普通货运改写成可履行危货运输。

4. **走私或禁止运输**  
   材料显示货物为走私货、禁止流通物或法律行政法规禁止运输的货物：停笔告知，不给出运路径。道路货运站场规定：不得运输法律、行政法规禁止运输的货物。

5. **货性不明**  
   用户说“大概是化工原料，证回头再补”：货性与许可字段停止，不写“可以先运”。

6. **最强反方**  
   托运人主张“少量危化混在普通货里没关系”或“公共运输不得拒运”。第 810 条的通常、合理要求不包括未申报危货或禁运货物。

示例修改句（承运人，普通货文本夹带溶剂）：

`鉴于／第【待填】条｜原文“货物一批，按普通货承运”｜建议改为“托运货物限于附件清单列明的普通货物。托运人应于交运前书面说明货物是否属于易燃、易爆、有毒、有腐蚀性、有放射性等危险物品，并提交包装、标志和防范措施书面材料以及依法应办理的审批、检验文件。未说明或未按国家规定包装标志的，承运人有权拒绝运输或采取措施，费用由托运人负担。承运人未取得相应危险货物运输许可的，不得承运危险货物。走私物品、禁止流通物或法律、行政法规禁止运输的货物不得承揽。若实际货物属于危险物品，双方应停止使用本普通货运文本”｜理由：硬闸 D；第 828、826 条｜可退让：无｜不接受：无许可仍运危化或走私，停笔`

## 硬闸 E　运费与灭失（835）

本闸改变灭失后运费能否再要。运行时核验第 835、813 条。

1. **法定返还**  
   第 835 条：货物在运输过程中因不可抗力灭失，未收取运费的，承运人不得请求支付运费；已经收取运费的，托运人可以请求返还。法律另有规定的，依照其规定。

2. **禁止概不退还**  
   合同不得反向约定“运费概不退还，货物灭失亦不例外”。该约定与 835 冲突时，现有依据不支持按约放行。

3. **支付结构**  
   预付、到付、第三方付费必须唯一。到付须写明收货人不提货或不付费时托运人的连带支付义务。未按约定或通常路线运输而增加的费用，托运人或收货人可拒绝支付（第 813 条）。

4. **不可抗力不得混写**  
   车辆故障、司机迟到、普通堵车、转包失败不得写入不可抗力。835 的返还以不可抗力致货物灭失为条件，不得与货损免责条款混成一句“任何情况下运费不退、货损不赔”。

5. **最强反方**  
   承运人主张行业惯例运费不退，或主张“法律另有规定”但举不出特别法。无核验引文不得把例外写成已成立。

示例修改句（托运人，运费概不退还）：

`第【待填】条｜原文“运费一经收取概不退还，货物灭失亦不例外”｜建议改为“运费支付方式为【预付／到付／第三方付费，三选一】。到付时，收货人不提货或不支付应付费用的，托运人承担连带支付义务。货物在运输过程中因不可抗力灭失的，未收取的运费承运人不得请求支付；已经收取的运费，托运人可以请求返还。法律另有规定的，从其规定并书面载明依据。承运人未按约定路线或通常路线运输而增加的费用，托运人和收货人有权拒绝支付”｜理由：硬闸 E；第 835、813 条｜可退让：特别法例外须写明条文｜不接受：运费概不退还，红线`

## 硬闸 F　留置仅相应货物；拒领走提存

本闸改变欠费和拒领时承运人能做什么。必须切开**留置**与**提存**，禁止写成可变卖私分。

1. **留置对象**  
   第 836 条：托运人或收货人不支付运费、保管费或其他费用的，承运人对**相应的运输货物**享有留置权，但是当事人另有约定的除外。  
   **禁止**“可留置托运人任何财产／其他库存／无关合同项下货物”。企业之间留置仍建议写清与本票运输的牵连。

2. **行使程序**  
   修改句：行使前书面催告、宽限期【待填】日、可分物仅留置相当价值部分、变价后清算多退少补。历史欠费另设保证或账期担保，不要绑在单票留置上。

3. **拒领 → 提存**  
   第 837 条：收货人不明或收货人无正当理由拒绝受领货物的，承运人依法可以**提存**货物。  
   **禁止**写成自行变卖、拍卖后私分价款。变卖只可能出现在留置权依法行使或提存物不适于提存时的变价提存，须另写法定程序，不得在本约授权“自行处理”。

4. **通知提货**  
   第 830 条：货物运输到达后，承运人知道收货人的，应当及时通知收货人；收货人应当及时提货；逾期提货应支付保管费等费用。修改句写通知时限、方式和提货凭证，避免“到站通知某人”与收货人错位。

5. **最强反方**  
   承运人主张商业惯例可不催告变卖。签前必须把 836 留置范围和 837 提存分写。托运人主张完全禁止留置：可特约排除第 836 条，但须明示并另设预付或担保。

示例修改句（托运人，留置任何财产＋自行变卖）：

`第【待填】条｜原文“承运人可留置托运人任何财产；收货人拒领的，承运人有权自行变卖并留存价款”｜建议改为“托运人或收货人不支付运费、保管费或其他本合同费用的，承运人仅对相应的本票运输货物享有留置权，不得留置与本票无关的其他财产。行使留置前应书面催告并给予【待填】日宽限期；可分物仅留置与债务金额相当的部分；依法变价后清算，剩余返还、不足继续追索。收货人不明或无正当理由拒绝受领的，承运人依法提存货物，不得擅自变卖私分。承运人知道收货人的，应在货物到达后【待填】小时内按约定方式通知提货”｜理由：硬闸 F；第 836、837、830 条｜可退让：历史欠费另设保证，不扩单票留置｜不接受：留置任何财产或擅自变卖，红线`

## 硬闸 G　交付前变更指令（829）

本闸改变托运人中途指令是否可履行。运行时核验第 829 条。

1. **法定权利**  
   第 829 条：在承运人将货物交付收货人之前，托运人可以要求承运人中止运输、返还货物、变更到达地或将货物交给其他收货人，但是应当赔偿承运人因此受到的损失。

2. **禁止架空**  
   “货物一经装车不得变更”“任何变更承运人有权不理”必须改。已交付收货人后，本条不再支持单方变更。

3. **必须写通知时点与费用**  
   修改句固定：书面指令（紧急电话须在【待填】小时内补书面）；指令应在交付前发出；承运人在收到后【待填】小时内确认能否执行及预估空驶、仓储、改道、回运费用；费用由托运人在变更执行前垫付或按【待填】结算。

4. **无单放货风险**  
   变更收货人必须同步改运单或出具书面放货指示。电话指令放货须同步书面确认，否则承运人自担风险。

5. **最强反方**  
   承运人主张变更导致无法调度所以一律拒绝。签前须保留 829 权利，同时用费用和可执行性确认保护承运人。

示例修改句（托运人，一经装车不得变更）：

`第【待填】条｜原文“货物一经装车不得变更”｜建议改为“在承运人将货物交付收货人之前，托运人可以书面要求中止运输、返还货物、变更到达地或收货人，并赔偿承运人因此受到的空驶、仓储、改道、回运等损失。托运人应在交付前发出书面指令；紧急情况下可先以电话发出，但须在【待填】小时内补书面。承运人应在收到指令后【待填】小时内书面确认能否执行及费用预估；费用由托运人在变更执行前支付或按双方确认单结算。变更收货人的，须同步更正运单或出具书面放货指示，禁止仅凭电话无单放货”｜理由：硬闸 G；第 829 条｜可退让：费用标准可预估单价｜不接受：交付前禁止一切变更且不设费用规则`

## 节点 2　主体、许可、实际承运人

1. 建主体表：托运人、承运人、实际承运人、收货人、付款名、发票名、授权签字人。名称不一致不自动合并。收货人通常不是签约方，仍须在首部或货物条款列明名称、电话、地址或“凭指示”。
2. 承运人经营范围与许可：材料未提则许可字段停止，不写“可以经营货运”。道路运输条例第 24 条：使用总质量 4500 千克及以下普通货运车辆从事普通货运经营的，无需道路运输经营许可证及车辆营运证。不得把该例外扩到危货或超限。
3. 实际承运人与缔约承运人分离：缔约承运人对全程负责（第 834 条方向）。修改句可列履行辅助人，但不得免除订约承运人。无车无船只转包且隐匿实际承运人：红旗，修改句要求披露并保留追偿。
4. 口头“我们老板同意了”不得写成已授权。运单司机签字是否视为承运人接收，须写明授权。
5. 买卖合同叠加：查明是卖方办理托运还是买方指定承运人，只影响买卖双方风险分配，不当然改变承运人对托运人、收货人的责任。本任务不展开买卖本约。

## 节点 3　交接、期限、路线

1. 起运交接应检视外观、封志、件数；冷链写温度区间及记录仪。批注权必须当场行使。“原装原运、破来破转”如无具体破损描述，对承运人保护极弱，必须改。
2. 运到期限起算点：装车完毕、运单签发或车辆离场，须选定。禁止只写“尽快”。第 811 条：约定期限或合理期限安全运达。
3. 第 812 条：按约定或通常路线。绕道、转运、分装须事先同意，紧急情况事后立即通知。增加的费用可拒付（第 813 条）。
4. 到达通知与提货凭证（运单、身份证明、提货码）写清。货损货差应当场编制记录，任何一方拒签不影响记录作为初步证据。
5. 第 831 条异议：外观异议当场提出，隐蔽损害在约定或合理检验期内提出。不得写成当场未异议即丧失全部索赔权。

## 节点 4　格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 4.1 格式条款

承运人制式运单背面、年度运输协议、网络勾选的物流条款，均可构成格式条款（第 496 条）。示范文本不当然排除审查。审查：货损概不负责、已保险即免责、运费概不退还、留置任何财产、一经装车不得变更、管辖是否有显著提示。仅电子勾选不足（合同编通则解释第 10 条）。未提示的后果是相对方可主张不成为合同内容，不是本任务直接改判无效。

### 4.2 强制规范

违反法律、行政法规强制性规定不一律无效（第 153 条及解释第 16 条）。禁止用已失效“效力性／管理性”口诀。道路许可多为管理规范：合同可能仍成立，但不写“无许可则必然无效”，也不得把无许可危化改成可履行承运路径。走私、禁运、故意或重大过失免责：不改写成有效履行。

## 节点 5　违约、解除、争议解决

1. 甩货、无单放货、严重迟延、匿报危险品、拒付到期费用必须分别有可执行后果。只有“依法承担违约责任”视为必须改。
2. 构成违约不等于当然解除。法定解除只点名催告或目的不能实现，不在本任务作出已解除结论。
3. 迟延损失（贬值、停工、转嫁违约金）须有因果关系和可预见性，不得写成必然全额转嫁。
4. 违约金避免“不得调整”或“按货值百分之三十必得”。833 市价不是本任务精算的必得金额。
5. 争议解决：  
   - 已有仲裁条款，不得改成“应向某法院起诉”并假装已选定诉讼；  
   - 或裁或诉、机构不明：改成单一仲裁机构或单一法院连结点；  
   - 货物所在地、目的地、承运人住所地可选其一。不要把所有纠纷指定到承运人单方所在地的同时再排除托运人保全货物的法院。
6. 微信已读不写成已经送达，除非合同把该渠道定为送达。

## 节点 6　保价、保险与附件

1. 保价或声明价值须书面、单独计价、单独签认。未保价不得写成已选择限额。
2. 保险：写清货运险投保人、被保险人、保险金额不低于货值【待填】、代位安排。未投保不得写成风险已转移完毕。
3. 附件：货物清单、危货说明书、保险单、价格表、运单样张、交接记录样张。附件与正文冲突时的解释顺序必须写明。
4. 本任务不把框架式运力预约写成已经锁定全部未来车次。

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

对照已加载框架级文件和本方法硬闸，按六步逐段出句。

| 步 | 一般货运必须盯的点 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题名实（货运而非仓储／货代／客运／物流服务减责）；托运人、承运人、收货人；鉴于不写货损免责 | 标题或主体修改句 |
| 交易条款 | 货物清单特定化；运单效力与冲突规则；交接批注；运到期限与路线；运费预付或到付；829 变更时点与费用；830 通知提货 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 832/833 货损与市价或保价；835 灭失运费返还；836 本票留置；837 提存；无单放货；危货 828 | 可执行后果句或删除句 |
| 尾部 | 框架盖章；运单司机签字授权；电子运单签章与保存；附件（清单、运单样张、危货说明、保险单）及冲突顺序 | 生效与附件修改句 |
| 语言 | 正说加反说；运单≠内部单；掌管期间≠仓储期间；提存≠变卖；已保险≠免责；尽快／原则上量化 | 替换空词的句子 |
| 常见问题 | 框架与运单两张皮；货代身份与承运人混写；留置扩到任何财产；引用失效货规 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（类型错位且拒改、货损概不负责、已保险即免责、运费概不退还、留置任何财产、擅自变卖、无许可危化、走私禁运、倒签）；
- `必须改`：可谈但签署前要落句（运单记载与冲突规则、833、829 时点费用、830 通知、批注标准）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级货值或个人无限连带且用户拒绝升级：停止“可以签署”建议。
