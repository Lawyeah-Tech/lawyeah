# 边界与路由

本技能只审查 **运输合同 / 海上货物运输合同** 的待签、经海路掌管运送并凭单交付货物的文本。中文展示名是「审查海上货物运输合同（运输合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或复制 `水路货物运输合同·审查`、`海上运输合同·审查`、`海上乘客运输合同·审查`、`多式联运合同·审查`、`客运合同·审查`、`货运合同·审查` 的 method。不得按内河货运或货运代理改完本类型文本。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 内河、湖泊、封闭或半封闭水域；无海段；运单／水路货规口径 | `水路货物运输合同·审查` |
| 水路运输总类，尚未落入客或货 | `水路运输合同·审查` |
| 水路乘客、客票、内河旅客伤亡 | `水路乘客运输合同·审查` |
| 标题停在“海上运输合同”，客货未拆，或只要总类航区识别 | `海上运输合同·审查` |
| 海上旅客、客票、行李、旅客人身伤亡限额 | `海上乘客运输合同·审查` |
| 仅订舱、报关、代办、不签发提单或海运单 | `货运代理合同·审查` |
| 海段加公路／铁路／航空，区段责任按区段法 | `多式联运合同·审查` |

| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或对应专项领域。` 或对应专项领域 |
| 无单放货、货损、扣船、海事保全已立案 | 海事专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

海上货物运输正文里夹带一小段订舱代理或租约滞期：专章交接对应原子或分条改写；凭单交付、责任期间与货损条款可继续审。用户坚持本技能把水路货运、客运、父级海上或纯货代整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿本类型文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
