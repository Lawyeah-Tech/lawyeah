# 海上货物运输合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、《国内水路货物运输规则》（交通部令 2000 年第 9 号）、《水路货物运输规则》、GF—97—0404 水路货运示范文本或法发〔1992〕37 号中的《经济合同法》口径当作现行规则或本类型模板。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **运输合同 / 海上货物运输合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「海上货物运输合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类合同审查、从零起草、履约交底、争议文书、有效性保证、保证货损必赔或限额必成立、把内河运单或纯订舱代理改写成可履行海运承运、把无单放货／预借倒签／两套正本／走私禁运改成可履行结构。

## 本类型硬闸

1. **海商法海上货物运输**：第四十一条把本类型锁在承运人收取运费、将货物**经海路**由一港运至另一港。第二条第 2 款——第四章**不适用于**中华人民共和国港口之间的海上货物运输。两端中国港口的沿海内贸，即使走海路、即使签发“提单”样式，货损归责回到民法典第八百三十二条、第八百三十三条，不得主张航海过失免责、火灾免责和第五十六条单位责任限制。国际航线才按第四章设计适航、管货、法定免责和限额。禁止按内河货运或货运代理主路径改完。
2. **提单**：第七十一条——提单证明合同和收货／装船，并构成承运人据以交付的保证。必须写清提单或海运单、记名／指示／不记名、正本份数、电放条件。禁止“需要时再补签一套正本”。一套货两套流通正本、预借或倒签：红线。电放必须回收全套正本或从未签发正本，并有书面指示。无单放货由承运人自担；保函不能对抗正本持有人；无单放货不适用第五十六条。
3. **责任期间**：第四十六条——集装箱货自装货港接收至卸货港交付，货物处于承运人掌管之下的全部期间；非集装箱货自装上船至卸下船。合同可就非集装箱货装前卸后另约责任，但不得缩短强制期间。“卸入港口堆场视为已交付”必须审查是否已合法交付收货人；承运人仍掌管的，期间不因卸场而结束。

配套闸：单位责任限制（国际航线按第五十六条按件或按公斤并留申报价值入口，未申报不是放弃索赔）；适航、管货不得概括取消（第四十七条、第四十八条、第四十四条）；货代以自己名义签单或以承运人代理人名义签单但不能证明授权的，按承运人审，不转货运代理整案。仅订舱、不签发运输单证 → `货运代理合同·审查`。

最近邻切开：客票、旅客伤亡 → `海上乘客运输合同·审查`。内河、湖泊、无海段 → `水路货物运输合同·审查`。标题停在“海上运输”未落入货运或客运 → `海上运输合同·审查`。禁止打开或复制上述邻类 method。海段加公路／铁路／航空按区段法 → `多式联运合同·审查`。货运总类未锁定海段 → `货运合同·审查`。禁止打开 `客运合同·审查`、`货运合同·审查`、`多式联运合同·审查` 的 method。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签海上货物运输正文、班轮运输协议，或货代／无船承运人承诺签发自己为承运人的提单／海运单运输条件；尚未签署，尚未成争；核心给付是货物在海上区段的掌管、运送与凭单交付；用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 内河、湖泊、封闭或半封闭水域，无海段 → `水路货物运输合同·审查`；
- 客票、旅客及其行李、旅客伤亡限额为主给付 → `海上乘客运输合同·审查`；水路乘客 → `水路乘客运输合同·审查`；
- 标题或正文停在“海上运输”总类，未锁定货运 → `海上运输合同·审查`；
- 仅订舱、报关、代办、不签发运输单证的货运代理 → `货运代理合同·审查`；
- 海段加公路／铁路／航空，货损区段责任按区段法 → `多式联运合同·审查`；
- 货运总类、未锁定海段 → `货运合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `海上货物运输合同·起草`；
- 已签只问配载、到港、滞箱费起算 → 本套导航的履约步骤；
- 已催告、无单放货索赔、货损诉讼、扣船、仲裁立案 → `或对应专项领域。` 或海事专项。

运输走私、禁运货物，或把明知无单放货、预借倒签、两套正本改成可履行操作惯例：只出告知，不改写成可履行路径。

## 建立审查坐标

确认：使用者与授权；单方立场（托运人／承运人／无船承运人／收货人利益方，择一）；相对方；全文及提单样张／费率表／危规申报版本；装港、卸港、是否两端中国港口；货物是否集装箱、甲板货、危险品；责任期间如何起止；签单种类与正本份数；是否电放；签单人是承运人还是仅代理；责任限制与申报价值；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `海上货物运输合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议或海事。未签且目标是评改已有海上货物运输文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。水路货运、客运、父级海上、纯货代、多式联运负触发。不得删掉内河或代理条款后硬套本技能。

### 2. 航区与第四章

两端中国港口：标注不适用第四章，改民法典货运节。国际航线才按第四章设计免责和限额。

### 3. 责任期间硬闸

集装箱接收至交付；非集装箱装船至卸船。可延长，不得缩短。堆场不等于交付。

### 4. 提单硬闸

种类、份数、电放、凭单放货、无单放货、预借倒签、两套正本。

### 5. 主体与签单身份

承运人、实际承运人、无船承运人、货代 as carrier。授权不明字段停止。

### 6. 单位责任限制

按件或按公斤；申报价值程序。沿海不得套第五十六条。

### 7. 适航、管货与格式条款

第四十七条、第四十八条、第四十四条。无核验引文则法律结论字段停止。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、预借、两套正本、把无单放货写成操作惯例、把走私禁运货改成可履行、保证有效或保证限额一定成立。
- `字段停止`：法域、动态规则、第四章是否适用、责任期间起止、签单授权、正本下落、申报价值未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
