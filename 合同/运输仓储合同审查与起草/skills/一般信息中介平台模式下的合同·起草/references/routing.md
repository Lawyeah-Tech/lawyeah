# 边界与路由

本技能只审查 **运输合同 / 一般信息中介平台模式下的合同**。

必须同时读出：核心给付是货源／运力信息匹配与促成订约；平台不以自己名义承运；运费原则上由托运人与实际承运人结算。标题叫“信息平台”但已经收运费、开运输票、签发运单或统一调度承运的，不得留在本技能做中介实体结论。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或标题信息中介、核心给付明显不是货源／运力撮合 | 本套导航的类型切开步骤 |
| 深度调度、统一定价、以自己名义承运收款、开运输发票、签发运单、承诺运达或包赔 | `网络货运平台模式下的运输合同·审查`；禁止打开其 method；不得按网货实际承运人改完 |
| 货运代理、代为订舱报关或以自己名义签运单 | `货运代理合同·审查`；禁止打开其 method；不得按货代改完 |
| 已排他道路乘客：班线、包车、旅游、出租、网约载客、定制客运网络平台 | `道路乘客运输合同·审查`；专业版未收录时输出 `unavailable`，不得用本技能做网约车承运或班线专项 |
| 客运但未锁定公路机动车 | `客运合同·审查`；禁止打开其 method |
| 平台自己承运且客货未拆 | `道路运输合同·审查`；禁止打开其 method |
| 平台自己承运且已排他道路货物 | `道路货物运输合同·审查` |
| 货运但未锁定公路机动车，且平台承运 | `货运合同·审查`；禁止打开其 method |
| 技术转让中介、专利权或技术秘密让与媒介 | `技术转让中介专利权或技术秘密让与媒介→`；禁止打开其 method |
| 职业介绍、人力资源服务许可、岗位撮合 | `职业介绍人力资源服务许可岗位撮合→` |
| 房屋买卖或租赁中介 | `房屋买卖或租赁中介→` |
| 平台与司机／骑手用工、众包、算法管理 | `或` |
| 长期驻场司机、用工外观主导 | `类派遣长期运输·审查` |
| 出租人提供车辆甚至司机，承租人决定线路并承担运输对象风险 | `承租人决定线路并自负运输对象风险的带驾租赁→` |
| 铁路／航空／水路／海上或两种以上方式衔接且平台承运全程 | 对应运输原子或 `多式联运合同·审查` |
| 有完整待签文本要评改 | `一般信息中介平台模式下的合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、问撮合记录、清分、下架 | 本套导航的履约步骤 |
| 已成争 | 合同争议领域或对应专项；不写货损起诉状 |
| C 端大众快检 | 只分流，不回改 |

同一文本既写“仅信息撮合”又写清收运费、开运输票或统一派单：按核心给付切开，负触发 `网络货运平台模式下的运输合同·审查`。代订舱、报关、以自己名义签运单：负触发 `货运代理合同·审查`。载客主给付：负触发客运原子。两可且无法判断：负触发引擎，不灌两套知识。

明知非法营运、运输违禁品仍撮合，或要求把无许可网络货运改成可履行中介：停笔告知，不改写成可履行文本。

禁止在正文写半截 Skill ID。转出时必须写完整 ID，例如 `网络货运平台模式下的运输合同·审查`、`货运代理合同·审查`、`道路乘客运输合同·审查`、`客运合同·审查`、`道路运输合同·审查`、`货运合同·审查`、`技术转让中介专利权或技术秘密让与媒介→`。
