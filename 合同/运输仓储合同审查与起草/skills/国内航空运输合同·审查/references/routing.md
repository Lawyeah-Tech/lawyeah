# 边界与路由

本技能只审查 **运输合同 / 国内航空运输合同** 的待签、出发地点、约定经停地点和目的地点均在中国境内的航空运送文本。中文展示名是「审查国内航空运输合同（运输合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或复制 `航空运输合同·审查`、`国际航空运输合同·审查` 的 method。禁止把蒙特利尔公约或第一百二十九条限额写成国内主路径。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 约定经停或目的在境外；接续运输作为一项单一国际业务；并入蒙特利尔公约或 SDR 作为唯一限额且连结点已出境 | `国际航空运输合同·审查` |
| 只写航空运输／航司服务／包机，三点未锁境内，国内国际未分流 | `航空运输合同·审查` |
| 国内运输但方式未锁航空，或公铁水空混写未拆段 | `国内运输合同·审查` |
| 客运总类，无航空器运送意思 | `客运合同·审查` |
| 货运总类，无航空器运送意思 | `货运合同·审查` |
| 多式联运，航空只是区段 | `多式联运合同·审查` |
| 道路运输及其乘客／货物子类 | `道路运输合同·审查`、`道路乘客运输合同·审查`、`道路货物运输合同·审查` |
| 铁路运输 | `铁路运输合同·审查` |
| 水路运输及其乘客／货物子类 | `水路运输合同·审查`、`水路乘客运输合同·审查`、`水路货物运输合同·审查` |
| 海上运输及其货物／乘客子类 | `海上运输合同·审查`、`海上货物运输合同·审查`、`海上乘客运输合同·审查` |
| 国际运输（涉外运输）总类 | `国际运输合同（涉外运输合同）·审查` |
| 核心给付是揽货、订舱、报关，未以自己名义签发航空货运单、不负责运达 | `货运代理合同·审查` |
| 网络货运平台模式 | `网络货运平台模式下的运输合同·审查` |
| 一般信息中介平台 | `一般信息中介平台模式下的合同·审查` |
| 长期运输服务与劳务派遣易混淆 | `类派遣长期运输·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `国内航空运输合同·起草` |
| 已签未争、只问航班保障或签转节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

国内航空正文里夹带一小段货代订舱或地面运输：专章交接对应原子或分条改写；航空运送条款可继续审。用户坚持本技能把国际航空、父级航空、铁路／道路／海运或货代整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
