# 国内航空运输合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴货运单栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、1996 年《中国民用航空旅客、行李国内运输规则》、1996 年《中国民用航空货物国内运输规则》、1993 年《国内航空运输旅客身体损害赔偿暂行规定》、1997 年国际客规、2000 年国际货规、2016 年《民用航空危险品运输管理规定》或蒙特利尔公约／SDR 限额当作本类型现行主规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **运输合同 / 国内航空运输合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「国内航空运输合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类合同审查；从零起草；履约交底；争议文书；有效性或航线许可保证；把国内三点境内航段改写成公约抗辩；把境外连结点航段压成国内限额；国际航空、未分流航空总类、国内运输总类、铁路／道路／水路／海上、货运代理本约的实体代审。

## 本类型硬闸

1. **连结点全在境内**：民用航空法（2021 修正）第一百零七条。出发地点、约定的经停地点和目的地点均在中华人民共和国境内，才是国内航空运输。三者之一不在境内，无论有无间断或转运，是国际航空运输，负触发 `国际航空运输合同·审查`。连续承运人办理的运输被各方视为一项单一业务的，视为不可分割运输（第一百零八条）；国内延伸段并入同一国际业务的，不得在本任务用国内限额切割。合同不能把国内航段“视为国际”，也不能把国际航段“视为国内”。技术备降境外不是约定经停。港澳台机场作为约定经停或目的的，按国际航空切开。
2. **民用航空法国内段，禁止蒙特利尔公约主路径**：限额只走第一百二十八条和《国内航空运输承运人赔偿责任限额规定》。第一百二十八条第二款允许第一百二十九条**除赔偿责任限额以外**的其他规定适用于国内运输，但**不得**把第一百二十九条限额、蒙特利尔公约、SDR、华沙或海牙规则一年时效写成国内主路径。禁止打开或复制 `航空运输合同·审查`、`国际航空运输合同·审查` 的 method。
3. **客货行李分轨**：旅客人身（第一百二十四条）、随身物品与托运行李、货物（第一百二十五条）、延误（第一百二十六条）分轨。不得用货物每公斤限额覆盖旅客伤亡。行李、货物书面异议按第一百三十四条：行李七日、货物十四日、延误二十一日；诉讼时效按第一百三十五条二年。人身伤亡不适用第一百三十四条异议失权。
4. **不得压低法定限额；必须提示并开放声明价值**：第一百三十条。限额规定第三条现行对照（须按第四条运行时复核是否已调整）：每名旅客人身人民币 40 万元；随身物品 3000 元；托运行李和货物每公斤 100 元。客票或货运单须可感知提示，并提供声明价值入口。货物每公斤不得压低于现行规定。1996 货规每公斤 20 元、1996 客规行李每公斤 50 元、人身最高赔票价均为红线。
5. **延误食宿与法定赔偿责任分开**：机务维护、航班调配、机组属于承运人自身原因，不是当然不可抗力（民法典第一百八十条；航班正常管理规定第二十九条）。已提供餐饮或超售补偿不消灭第一百二十六条请求权。《航班正常管理规定》第二条第三款：货邮航班不适用该规定，货运延误不得套用餐宿条款吞掉货损请求权。超售先按旅客服务管理规定第四十六条征集自愿者，再按第四十七条赔偿并提供服务，补偿不是终局法定赔偿。
6. **代码共享与签单主体**：对实际承运人履行的运输，可分别或同时诉实际承运人或缔约承运人（第一百四十三条）。内部协议不得对抗旅客或货主。销售代理人以自己名义签发航空货运单的，按缔约承运人审查，不得再主张仅代理。
7. **无许可经营不当然使合同无效**：第九十一条只定义公共航空运输企业。无许可从事经营性运输，行政违法，民事合同不当然无效。只出告知，不改成可履行的无证结构。危险品、锂电池按 2024 年《民用航空危险品运输管理规定》申报，瞒报不得放行。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签国内航空旅客或货物运输正文、客票／运输总条件或国内航空货运单及背面条款，尚未签署，尚未成争，出发、约定经停、目的均在中国境内，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 任一约定经停或目的在境外，或接续运输作为一项单一国际业务 → `国际航空运输合同·审查`；
- 只写“航空运输／航司服务／包机”，三点未锁境内，无法确认国内还是国际 → `航空运输合同·审查` 或 本套导航的类型切开步骤；
- 国内运输但运输方式未锁航空，或公铁水空混写未拆段 → `国内运输合同·审查`；
- 客运总类、货运总类，无航空器运送意思 → `客运合同·审查` 或 `货运合同·审查`；
- 多式联运、铁路、道路、水路、海上 → `多式联运合同·审查`、`铁路运输合同·审查`、`道路运输合同·审查` 及对应子类、`水路运输合同·审查` 至 `海上乘客运输合同·审查`；
- 核心给付是揽货、订舱、报关而自己不负责运达，且未以自己名义签发航空货运单 → `货运代理合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `国内航空运输合同·起草`；
- 已签只问航班保障、签转节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁或异议期争议已立案 → `或对应专项领域。` 或运输／争议专项。

以国内航空为名运输依法禁止的危险品且拒绝申报，或把明知无公共航空运输许可的经营性运输改成可履行结构：只出告知，不改写成可履行路径。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及运输总条件／客票／货运单／声明价值申请表版本；出发、经停、到达机场三字代码和城市；客或货或客货混写；是否代码共享及实际承运人；限额与声明价值如何写；延误、取消、超售如何写；危险品或锂电池；争议解决连结点；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `国内航空运输合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有国内航空运输文本，才进入本任务。

### 1. 类型锁死与连结点

标题、核心给付与三点境内一致才继续。境外一点或单一国际业务负触发国际航空。未分国内国际转父级或引擎。

### 2. 主体、许可、代码共享与签单

航司全称与票证代号；国内航线经营许可只作告知，不写成合同当然无效；实际承运人披露；代理人以自己名义签单按缔约承运人审。

### 3. 客货行李标的与声明价值

舱位或订舱、免费行李额、货运单件数重量品名；锂电池单独成条；必须保留声明价值手续。

### 4. 限额提示与强制规范

引用限额规定现行文本；分项提示；压低限额或人身赔票价红线。无核验引文则法律结论字段停止。

### 5. 程序：出票、安检、延误超售、交付、异议时效

电子客票／电子运单可成立；机械故障不是当然不可抗力；异议期和二年时效按民用航空法。

### 6. 争议解决与附件

中国法院或国内仲裁；附件不得夹带蒙特利尔公约作为唯一限额依据。

### 7. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签出票日、保证有效、把国际航段改成国内限额外壳、保留人身赔票价或排除声明价值并放行、把危险品瞒报或无证经营改成可履行。
- `字段停止`：法域、限额是否已按第四条调整、接续运输是否单一国际业务、航线许可、危险品品名、货运单是否可转让未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
