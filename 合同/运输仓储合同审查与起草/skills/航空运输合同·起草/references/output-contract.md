# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受、航班必准点、货必无损或必然可执行；编造未给出的票价、运费、货值、许可文号、限额数字；把已失效《合同法》运输章、1996 年国内客规／货规、1997 年国际客规、2000 年国际货规、1989／1993 年旅客身体损害赔偿暂行规定写入结论；把国内限额规定与华沙／蒙特利尔写成同一主路径；把华沙或蒙特利尔套到国内航段；把空运单写成提单；把已保险写成承运人免责；把一切延误写成不可抗力；把挂靠或无许可经营性公共航空运输改成可履行结构。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查航空运输合同（运输合同）」。若已转 `国内航空运输合同·审查` 或 `国际航空运输合同·审查`，只写切开理由，不填本技能十节实体结论。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》运输章、1996 年国内客规／货规、1997 年国际客规、2000 年国际货规、1989／1993 年旅客身体损害赔偿暂行规定、1995 年民用航空法第 92 条原文时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `运输合同`，子级 `航空运输合同`。定性理由、易混切开结果（国内航空、国际航空、一般客运／货运、货代、包机湿租、地面／售票代理、多式联运、道路／铁路／海商）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。货代签发航空货运单的，写明未假装切开承运责任。来稿若已是单一国内或单一国际，写明已转对应子级，不得继续用本技能十节充数。国内段若出现华沙或蒙特利尔字样，写明已按硬闸 B 红线处理，未把公约当国内主路径。

## 4. 主体、公共航空运输经营许可与文本版本

主体表：旅客或托运人、缔约承运人、实际承运人、收货人、付款名、发票名、授权签字人、销售代理人。许可表：公共航空运输经营许可证经营范围、主运营基地、是否覆盖本协议航线类型。版本表：正文、客票或电子客票样张、航空货运单样张、运输总条件、危险品申报、保险单、聊天确认；冲突并列。未核许可：该经营能力字段停止，不写“可以经营”，也不写“合同当然无效”。

## 5. 连结点、客票／货运单、客货分轨与代码共享

连结点识别表：出发地点、约定经停地点、目的地点、是否接续运输作为一项单一业务、技术备降与约定经停是否区分。客票／行李票／航空货运单是否合同初步证据；空运单是否被误写成提单。旅客、随身物品、托运行李、货物是否分项。代码共享是否披露实际承运人。缺口标 `G#`。不输出国内限额精算表，也不输出华沙金法郎或蒙特利尔特别提款权精算表。

## 6. 分流条款、延误超售、声明价值、危险品与强制规范

国内段与国际段是否分文本指向。华沙／蒙特利尔是否误套国内。是否构成格式条款。第 130 条降低限额条款。延误是否被写成不可抗力；超售是否被写成旅客违约；声明价值入口是否存在；锂电池、活体、冷链是否按航空危险品规则。强制规范只按第 153 条区分：无许可不当然导致合同无效，但不得把无许可经营性公共航空运输或挂靠改成可履行。走私／排除人身伤害／排除公约／国内段套公约只保留识别与停笔。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字和许可文号用 `【待填】`。必须出现连结点识别表或国内／国际分流句，不得只复述一般运输 820／832。必须出现禁止国内段适用华沙或蒙特利尔的句子，若来稿有公约字样。不得在本技能输出国内每公斤限额或公约特别提款权的精算结论。

## 9. 谈判与签署提醒

谈判顺序：先红线（类型错位到单一国内或单一国际却拒转、排除公约、视同国内、国内段套华沙或蒙特利尔、人身只赔一倍票价、一切延误属不可抗力、排除人身伤害、挂靠出借许可证、走私禁运、引用失效客货规拒删），再必须改（连结点表、客货分项、客票／货运单效力、代码共享披露、声明价值入口、运输总条件版本、超售与延误分写），最后可优化。签署提醒：框架合同盖章；许可复印件入附件；电子客票／电子运单签章与保存期限；运输总条件国内文本与国际文本分列；危险品申报、保险单、客票或货运单样张入附件。不指导倒签或补假许可。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本原子只起草并自审，不评改对方来稿。待签评改转配对 ·审查 原子。草稿必须落入本类型三闸。不是履约交底、争议文书或效力保证，也不是国内航空限额精算、华沙／蒙特利尔精算、一般客运／货运、包机湿租或铁路／道路／海商专项审查。
