# 边界与路由

本技能只审查 **运输合同 / 航空运输合同** 的待签文本。中文展示名是「审查航空运输合同（运输合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 出发地、约定经停地、目的地均在中国境内，全文只走国内航空限额主路径 | `国内航空运输合同·审查`。P1；未装则 `unavailable`。禁止用本技能把国内限额规定精算做完 |
| 任一点不在中国境内，或接续运输作为一项单一国际业务，全文只走华沙公约、蒙特利尔公约或民用航空法第 129 条主路径 | `国际航空运输合同·审查`。P1；未装则 `unavailable`。禁止用本技能把公约或第 129 条精算做完 |
| 一份文本同时覆盖国内与国际，或连结点空白／冲突，或写“按民航规定／视同国内／排除公约”，或国内段印刷华沙／蒙特利尔 | **不转出装切开**。留本技能强制分流，禁止共用一段限额、异议期或管辖，禁止公约误套国内 |
| 通篇只引民法典客运节，无航空特别法、客票责任期间或民用航空法限额 | `客运合同·审查` |
| 通篇只引民法典货运节，无航空货运单、声明价值或民用航空法主路径 | `货运合同·审查` |
| 只撮合舱位或运力，不承运，不以自己名义签发客票或航空货运单 | `货运代理合同·审查`。P1；未装则 `unavailable`。纯媒介也可交 `房屋买卖或租赁中介→` |
| 货代或以代理人名义行事，却以自己名义签发航空货运单并收取运费，或不能证明授权 | **不转出装切开**。按本类型承运人义务审查 |
| 只提供航空器与机组，由对方决定航线任务，不出具客票或航空货运单 | 引擎重新定性或动产租赁路径。不得按本类型承运人限额审 |
| 机场地面服务、值机装卸、售票代理协议，对方不负责运达 | 不是承运人。转引擎重新定性，不得用本技能改成可履行承运结构 |
| 两种以上不同运输方式，经营人负责全程 | `多式联运合同·审查`。P1；未装则 `unavailable`。空运段限额回指只点名，不在本技能精算 |
| 道路运政许可、车辆道路运输证、治超或道路危货资质为主路径 | `道路货物运输合同·审查` |
| 铁路运单、铁路保价与限额为主路径 | `铁路运输合同·审查`。P1；未装则 `unavailable` |
| 提单、海商法单位责任限制为主路径 | `海上货物运输合同·审查`。P1；未装则 `unavailable`。禁止把空运单改写成提单 |
| 有完整待签文本要评改 | `航空运输合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、只问值机在途签收留痕 | 本套导航的履约步骤 |
| 已成争，或用户要伤亡／货损索赔诉讼策略 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

航空运输正文里夹带一小段机场地面服务或卡车接驳：货损期间仍先按航空运输期间判断；独立计价且以保管或公路位移为主的专条可交接对应原子。用户坚持本技能把单一国内航空、单一国际航空、一般客运／货运、包机湿租、多式联运或海商提单整案改完：`目标停止`。
