# 边界与路由

本技能只审查 **运输合同 / 海上运输合同** 的待签总类或框架文本。中文展示名是「审查海上运输合同（运输合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或复制 `海上货物运输合同·审查`、`海上乘客运输合同·审查`、`水路运输合同·审查`、`水路乘客运输合同·审查`、`水路货物运输合同·审查`、`多式联运合同·审查`、`客运合同·审查`、`货运合同·审查` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符且无法在本类型内定性 | 本套导航的类型切开步骤 |
| 正文已是完整海上货物本约：货名、件数、装港卸港、提单或运单条款、货损责任已按货运专章展开 | `海上货物运输合同·审查`；交接时可点名第二条第二款，不在本任务代审货损、无单放货或单位限制精算 |
| 正文已是完整海上旅客本约：客票、旅客人身、行李、旅客章责任限额 | `海上乘客运输合同·审查` |
| 航线全程内河、湖泊或未通海水域，未经海路 | `水路运输合同·审查`；已拆成水路旅客 → `水路乘客运输合同·审查`；已拆成水路货物 → `水路货物运输合同·审查` |
| 一般货运或客运、未显示海路；陆运＋仓储标题误写海上 | `货运合同·审查` 或 `客运合同·审查` |
| 两种以上运输方式且含海运区段，经营人负责全程并收全程运费 | `多式联运合同·审查` |
| 航次租船、定期租船、光船租赁，核心是提供船舶或舱位而不是承运人负责运送 | 本套导航的类型切开步骤；不在本任务按运输合同改租约 |
| 货运代理、无船安排但只收代理费、正文写“尽力安排船舶”且声明不是承运人 | `货运代理合同·审查` 或 `一般信息中介平台模式下的合同·审查` |
| 道路、铁路、航空本约 | `道路运输合同·审查`／`铁路运输合同·审查`／`航空运输合同·审查` 等对应原子 |
| 无文本、本类型条件已谈妥、要出己方稿 | `海上运输合同·起草` |
| 已签未争、只问开航日、签单日、到港窗口 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或对应专项领域。` 或海事专项 |
| 已出现货损索赔、无单放货、旅客伤亡、扣船、海事诉讼或仲裁 | 海事或争议专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

总类框架里夹带一小段已拆清的货物航次或旅客航次：该专章交接对应原子；识别表和适用法分轨可继续审。用户坚持本技能把完整货物本约、旅客本约或内河整案改完：`目标停止`。

江海直达：海段识别与分轨留在本任务；内河段交接水路原子，不在本任务展开水路货规。法释〔2016〕4 号“通海可航水域”只说明海事法院可能受案，不能把纯内河本约留在本技能。

两岸三地港口：字段停止，运行时再核《国际海运条例》专门规定，不得直接按第二条第二款或“视为国际”放行。

专业版未收录的 P1 场景不会安装本原子。若用户拿本 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
