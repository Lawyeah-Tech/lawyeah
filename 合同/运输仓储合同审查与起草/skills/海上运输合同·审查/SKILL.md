# 海上运输合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、已失效《国内水路货物运输规则》（2000）、已失效《经济合同法》或法发〔1992〕37 号当作现行规则。
- Agent 自主判断何时调用、调用哪一类检索；不把 MCP 当必经关卡，也不在未命中时编造条文。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **运输合同 / 海上运输合同** 的待签总类或框架文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「海上运输合同·审查」。

`depends-on` 为空。不要求先跑导航。

本原子只做识别和分轨，不把货／客并进本约。不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、货损或人身赔偿精算、保证提单一定是物权凭证、保证英国法或伦敦仲裁在中国必然可执行。

## 本类型硬闸

1. **海商法总类，不是第三种有名合同**。海上运输只包括海上货物运输和海上旅客运输，并含海江、江海直达（海商法第二条第一款）。本任务先判定：是否经海路、是否适用海商法、适用第四章还是第五章。不得把本约写成独立于货／客的第三套运输规则。
2. **第二条第二款：中国港口之间的海上货物运输不得适用第四章**。两端都是中国大陆港口的货运，不得写入航海过失免责、火灾免责、单位责任限制或国际班轮喜马拉雅条款。不得约定“视为国际运输”来改写法定适用范围。
3. **与货／客细分切开**。正文已是完整海上货物本约（货名、装港卸港、提单或运单条款）→ `海上货物运输合同·审查`。已是完整海上旅客本约（客票、旅客人身、行李）→ `海上乘客运输合同·审查`。本技能只审识别表、适用法分轨、单据匹配和客货混装分轨。禁止打开或复制 `海上货物运输合同·审查`、`海上乘客运输合同·审查` 的 method。
4. **与内河／水路切开**。未经海路的内河、湖泊、未通海水域 → `水路运输合同·审查`、`水路乘客运输合同·审查` 或 `水路货物运输合同·审查`。标题写“海上”、航线全是内河的，负触发水路。禁止抄水路运输 method，禁止用已失效《国内水路货物运输规则》当现行依据。
5. **适用法必须按识别结果分轨**。国际海上货物运输适用海商法第四章；中国港口间海上货物运输适用民法典货运节（第八百三十二条、第八百三十三条）；海上旅客运输（含沿海旅客）适用海商法第五章。禁止一句“本合同一律适用海商法”或“国际惯例优先于中国强制规定”。
6. **单据与航区匹配**。国际货运用提单或海运单；国内沿海货运用运单；客运用客票。总类合同笼统写“一律签发提单”，会把沿海货柜带进错误的流通机制。
7. **客货不得混用免责**。旅客人身不得引用第四章免责和货损限额（第一百二十六条）。客货混装必须分项计价、分轨责任。海事赔偿责任限制与合同单位责任限制不是一回事，不得混写或预先放弃依法不受限制的情形。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

禁止表述：一律适用海商法；视为国际运输所以可以航海过失免责；国内沿海货运适用普通三年时效而不核验法释〔2001〕18 号；客票可引用货物免责；删掉内河港口后按本类型放行；把完整货／客本约留在本技能改完。

## 工作边界

正触发：已有可读待签《海上运输合同》《海运服务协议》《海运总协议》或班轮框架，尚未签署，尚未成争，核心给付是承运人经海路负责运送，且文本仍是总类／框架或客货／航区未拆清。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 完整海上货物本约 → `海上货物运输合同·审查`；
- 完整海上旅客本约 → `海上乘客运输合同·审查`；
- 未经海路的内河、湖泊运输 → `水路运输合同·审查`／`水路乘客运输合同·审查`／`水路货物运输合同·审查`；
- 一般货运或客运、未显示海路 → `货运合同·审查` 或 `客运合同·审查`；
- 含海运区段且经营人负责全程的多式联运 → `多式联运合同·审查`；
- 航次／定期／光船租赁，核心是租船而不是承运人负责运送 → 引擎或租约专项，不在本任务代审；
- 货运代理、仅“尽力安排船舶”而无承运承诺 → `货运代理合同·审查` 或信息中介原子；
- 道路、铁路、航空本约 → 对应运输原子；
- 无文本、本类型条件已谈妥、要出己方稿 → `海上运输合同·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、货损索赔、无单放货、人身伤亡、诉讼、仲裁 → `或对应专项领域。` 或海事专项。

走私、禁运货物运输约定只出告知，不改写成可履行结构。挂靠经营、无相应航线许可：只告知监管与免责抗辩风险，不保证合同无效或有效。

## 建立审查坐标

确认：使用者与授权；单方立场（承运人／实际承运人／托运人／旅客或包船人）；全文及提单样张／运单／客票／航线清单版本；运送对象是旅客、货物还是客货混装；装港、卸港、是否均在中国大陆境内；是否经海路或江海直达；计划签发的单据；适用法条款是否分轨；船舶与许可；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `海上运输合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议或海事专项。未签且目标是评改已有总类／框架文本，才进入本任务。

### 1. 类型锁死（三问）

是否经海路、是否适用海商法、适用第四章还是第五章。完整货／客本约、内河水路、多式联运、租船、货代负触发。不得把货／客并进本原子。

### 2. 识别表

对象（客／货／混装）、装港、卸港、是否中国大陆港口之间、是否经海路、单据类型必须可回链。识别结论写入适用法条款。两岸三地字段停止。

### 3. 适用法分轨

第四章／第五章／民法典货运节拆开。中国港口间货运删除第四章专属免责与单位限制。

### 4. 单据、船舶、许可

提单／海运单／运单／客票与航区匹配。替换船舶不得降低适航等级和许可范围。沿海运输核船旗（第四条）。

### 5. 责任条款分轨与喜马拉雅

三套责任不得混排。喜马拉雅不得扩张成一切第三人免责。旅客不得引用货物免责。

### 6. 时效、管辖与格式条款

国际货运时效提醒走第二百五十七条；沿海货运时效不得写成普通三年；旅客走第二百五十八条。国内沿海货运不要一律写英国法＋伦敦仲裁而不评估可执行性。无核验引文则法律结论字段停止。

### 7. 按框架六步出修改句

必须有可回给对方的修改句或红线。识别表句、三轨适用法句、沿海货运删除第四章减责句、客票不得并入货物免责句不得省略（对应事实存在时）。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把走私禁运改成可履行、把内河或完整货／客本约按本类型放行、把中国港口间货运改成可执行的第四章减责。
- `字段停止`：法域、动态规则、船旗许可、保险航区、两岸三地专门规定、时效在个案中的适用未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
