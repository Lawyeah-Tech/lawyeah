# 审查方法（锁定 仓储合同 / 危险物品仓储合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型，禁止打开普通仓储、易变质仓储、运输或租赁目录“对照一下”。

本文件是危险物品仓储签前判断节点，不是栏目说明书，也不是普通仓储或危货运输审查清单。禁止把普通仓仓单／提存／口头放货主路径，危货承运人责任、运单签发、车辆资质主路径，或房屋维修、租金、返还房屋主路径写入本类型结论。

每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、事故必然不发生、刑责可约定免除、对方必然接受或唯一必得金额。

`search_law` 返回已失效《合同法》仓储章、《仓储保管合同实施细则》、1987 年《化学危险物品安全管理条例》、2002 年未修订《危险化学品安全管理条例》仓储条、2010 年《道路危险货物运输管理规定》或担保法解释时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突。

示范文本只参考结构。危化仓储示范文本不证明本约条款已被接受；符合格式条款定义的，仍按格式条款审查。

### 双文件使用

- 含“首部／交易条款／配套／尾部／语言／常见问题”六步的（本目录 `框架.md`），供节点 8 出句；
- 含类型、主体、标的、入库程序、结构、红旗的（本目录 `基本面.md`），供节点 1 与硬闸校验，不代替核验、不代替出句。
- 知识稿若写“未取得许可则合同因违反效力性强制性规定无效”：运行时按民法典第 153 条和合同编通则解释第 16 条区分是否导致民事行为无效与是否仅造成履行障碍。**不**用已失效“效力性／管理性”口诀。无许可仍不给出可履行入库结构。
- 知识稿若写保管人可持《危险货物道路运输经营许可证》（含仓储）：**纠正**。道路危险货物运输许可只覆盖运输活动，不能替代危险化学品经营／储存资格。港区内港口经营人仓储经营依经营许可证管理办法第 3 条可不取经营许可证，但仍须港口经营许可。
- 知识稿若写“强制购买安全生产责任险”适用于一切仓储：安全生产法第 51 条为高危行业、领域应当投保，其他鼓励投保。修改句仍应要求投保，不把“一律强制”写成未核验的全行业法。
- 文件不可用（空、乱码、与危险物品仓储明显无关）：记 `G#`，用本方法节点继续，不得改去加载普通仓储或运输双文件，不得编造许可编号、UN 号或应急备案层级。

## 节点 1　类型识别与邻类负触发

### 1.1 本类型正像

同时满足才继续：

- 核心给付是保管人**储存保管**存货人交付的仓储物，存货人支付仓储费（储存保管劳务，不是转移货物所有权，也不是只让出库房使用权，也不是把货从甲地运到乙地）；
- 仓储物是危险物品：易燃、易爆、有毒、有腐蚀性、有放射性等，或文本要求危化专库、经营／储存许可、MSDS、泄漏应急；
- 合同自双方意思表示一致时成立，不以交货为成立要件。

标题写成“仓储服务协议”“危险化学品仓储合同”“危化仓租协议”只是线索。名实不符按核心给付归类，标题冲突写入 `C#`。

### 1.2 必须切开（禁止两套知识）

| 信号 | 归入 | 本技能动作 |
| --- | --- | --- |
| 普通工业品／原材料，常温通风防潮即可，无专库、无危化许可、无 MSDS 主给付 | 普通货物仓储 | **负触发** → `普通货物仓储合同·审查`。不得用本方法“补一套危化条款”把普通仓改成危化仓 |
| 核心是运单、车辆、承运人、起运地到目的地；文本主证是道路危险货物运输许可证 | 危货道路运输 | **负触发** → `道路货物运输合同·审查`（或 `货运合同·审查`）。不得用运证继续审仓储 |
| 只出租库房或货位，无验收、无专库管理，明确“事故自负／保管人不负责” | 房产／场地租赁 | **负触发** → `仅出租库房／货位，保管人对货损和事故不负责→` |
| 生鲜、冷链、温湿度控制是主给付，货性不是危险物品 | 易变质物品仓储 | **负触发** → `易变质物品仓储合同·审查` |
| 转移货物所有权换价款 | 动产买卖 | **负触发** → `核心给付是转移货物所有权换价款→` |
| 无偿、无仓储费，或明确自交付才成立 | 保管合同 | **负触发** → 引擎重新定性 |

邻类稿误入是硬闸：一旦普通货、危货运输、只租空库或卖货构成主给付，立即停笔转出。不得删掉该部分后继续当危险物品仓储审。

### 1.3 加载协议

只打开本目录 `基本面.md` 与 `框架.md`。禁止读 `types/` 或其他场景原子目录。

### 1.4 违法结构停笔（本类型，不是施工挂靠）

出现下列任一结构，只出告知，不改写成可履行文本：

- 保管人无危化经营／储存许可（或港区无港口经营许可）仍要“改到能入”；
- 用道路危险货物运输许可证冒充仓储／经营许可；
- 许可范围不含本合同品类（如许可仅腐蚀品，合同接易燃液体）仍要入库；
- 存放法律禁止、国家明令淘汰或禁止流通的危险物品；
- 存货人将危化伪装成普通货，或无 MSDS／包装标识仍要求先入后补；
- 个人或无资质单位委托储存受管制危险物品；
- 倒签合同日期以改变许可、安全评价或事故时点；
- 伪造许可、安全评价、消防验收或应急预案备案。

用户坚持“改到能入／能过检／不被查”：整体停止。合规改道（真实取得许可后再签、真实补安全评价）只点名，不在本任务起草规避方案。

## 硬闸 A　危化仓储 ≠ 普通仓储 ≠ 危货运输 ≠ 租仓

本闸改变技能能否继续。依据第 904、906 条：仓储是保管人储存存货人交付的仓储物、存货人支付仓储费的合同；储存危险物品须具备相应保管条件。

1. **与普通仓储切开**  
   普通仓主给付不要求专库、危化许可、MSDS 和泄漏应急。货性是钢材、日用百货、普通包装件：转 `普通货物仓储合同·审查`。不得在本类型把普通仓“升级”成可履行危化仓，也不得把危化文本降级成普通仓验收句交差。

2. **与危货运输切开**  
   运输的核心是位移和承运人管货期间责任。文本主证是道路危险货物运输许可证、运单、车辆和驾驶员／押运员：转 `道路货物运输合同·审查`。  
   **禁止**把道路运输许可证写成“含仓储即可经营危化仓”。衔接段的装卸、短驳可在本约写清与承运人的界面，但不把承运合同吞进本仓储审查。

3. **与租仓切开**  
   仅让出库房使用权、无专库管理、明确“事故自负”：核心是租赁。转 `仅出租库房／货位，保管人对货损和事故不负责→`。不得用租赁维修、返还房屋句充当危化仓修改句。

4. **最强反方**  
   对方主张“都是化工原料，普通仓凑合也能存”，或主张“我们有危货运输证，仓也可以一起做”。签前按核心给付和许可种类切开，不按标题或口头方便放行。

示例修改句（存货人，文本把运证当仓储许可）：

`第【待填】条｜原文“乙方持有道路危险货物运输经营许可证，有权储存本合同项下危险货物”｜建议改为“本合同为危险物品仓储合同。保管人应当具备与仓储物品类匹配的危险化学品经营许可证（带储存设施）或其他法定储存资格，并在许可载明的专用仓库履行储存保管义务。道路危险货物运输许可证不得单独作为仓储经营资格。若双方实际交易为道路运输，应改签道路货物运输合同，不适用本仓储文本”｜理由：硬闸 A；第 904、906 条；经营许可证管理办法第 3 条｜可退让：入库前后短驳可另签运输合同｜不接受：运证冒充仓储许可，红线`

## 硬闸 B　危化仓储许可

本闸改变能否继续出可履行修改句。运行时核验经营许可证管理办法第 3、6、8、9 条，安全生产法第 39 条，危化条例第 36 条后再写法律效果。

1. **保管人资格**  
   经营危险化学品须取得经营许可证；未取得不得经营。带储存设施另须：规划的危化储存区域内新设仓储、安全评价、专职安全管理人员资质、符合 GB15603 等。港区内港口经营人仓储经营可不取经营许可证，但仍须港口经营许可。材料未附许可：资质字段停止，不写“可以经营危化仓储”。

2. **许可范围覆盖品类**  
   许可载明类别须覆盖合同标的（如易燃液体、腐蚀品、毒性物质）。范围不及：红线。修改句要求附件列明许可证号、有效期、储存地址和核准品类，并与货物清单逐项对照。

3. **存货人资格**  
   存货人须具备生产、经营或使用相应危险物品的合法资质。禁止个人或无资质单位委托储存剧毒、易制爆等受管制物品。向个人销售或受个人委托储存剧毒／易制爆：停笔。

4. **场所与评价**  
   仓库须是许可载明的专用仓库或专用场地；安全评价、消防验收、环评批复写成保管人提交义务和生效／收货条件，不写成已经完成。双方同意“视为已取得许可”：不可放行。

5. **最强反方**  
   保管人主张“许可证在办、先入一批”。签前必须把许可作为收货先决条件。存货人主张“普通仓先周转一下”：转出或停笔，不给无证结构。

示例修改句（存货人，保管人许可未附）：

`第【待填】条／鉴于｜原文“乙方具备危险化学品仓储能力”｜建议改为“保管人应在首次收货前向存货人提交：有效《危险化学品经营许可证》（带储存设施）或依法可替代的港口经营许可，许可范围覆盖附件清单全部品类；仓库地址与许可载明储存场所一致；安全评价报告、消防验收和应急预案备案材料。未提交或许可过期、范围不及的，存货人有权拒绝交货并解除本合同，已付费用【待填】日内返还。双方不得约定‘视为已取得许可’”｜理由：硬闸 B；经营许可证管理办法第 3、8 条；第 906 条第 3 款｜可退让：港区仓储可提交港口经营许可替代经营许可证，但仍须核验港区范围｜不接受：无许可先入，停笔`

## 硬闸 C　告知、MSDS、包装标识与拒收

本闸改变隐瞒性质和不合格包装能否入库。运行时核验第 906、907 条。

1. **法定说明义务**  
   第 906 条：储存危险物品，存货人应当说明该物品的性质，提供有关资料。违反的，保管人可以拒收或采取措施，费用由存货人负担。修改句把“资料”落到：安全技术说明书（MSDS）、安全标签、理化特性、禁配物、灭火方法、急救措施。知识稿要求的安全评价报告是保管人设施侧材料，不得改写成存货人必须提交仓库安全评价。

2. **MSDS 与货物一致**  
   道路危货规定第 28 条方向（只借“一书一签须与货物完全一致”，不把承运规则当本约默认法）：MSDS 和标签必须对应本合同批次。品名、UN 号、成分冲突：并列 `C#`，未消除前不得收货。

3. **包装与标志**  
   包装须符合国家关于危险货物包装的强制性标准，并有明显危险品标志和标签。重复使用的包装物、容器使用前应检查。修改句禁止“包装按行业惯例”。

4. **渗漏、变形必须拒收**  
   入库须做外包装密封性检查。发现渗漏、变形、安全附件失效、品名／批次与许可或 MSDS 不符：**拒绝卸货入库**。不得改成“记录后先入，责任以后再说”。

5. **入库确认**  
   双方共同签署《危险品入库安全确认单》，对包装完整度、密封性、标识、件数当面确认并留存影像。签收不等于买卖验收合格，只确认约定范围内的表面状况和标识。

6. **最强反方**  
   存货人主张“MSDS 回头补、先卸车”。保管人签前必须把完整 MSDS 和合格包装写成收货先决条件。隐瞒性质导致事故：存货人承担因此发生的损失；保管人明知且具备条件却保管不当：不得把全部事故推给存货人。

示例修改句（保管人，原文允许无 MSDS 入库）：

`第【待填】条｜原文“存货人应尽量提供安全资料，不影响入库”｜建议改为“存货人应当在卸货前书面说明仓储物的化学名称、危险性类别、UN 号、理化特性、禁配物、灭火方法和急救措施，并提交与本批次货物完全一致的安全技术说明书和安全标签。包装应当符合强制性标准并加贴危险品标志。保管人应当检查外包装密封性；发现渗漏、变形、标识缺失、品名不符或资料不全的，应当拒绝卸货入库。存货人未说明危险性质或提供虚假资料的，保管人有权立即解除本合同并要求存货人迁出货物，因此发生的事故损失、应急费用和行政责任由存货人承担。本条使用‘应当’，不得改为‘可以’或‘尽量’”｜理由：硬闸 C；第 906、907 条｜可退让：外包装验收为默认，开箱抽检比例【待填】%｜不接受：无 MSDS 或渗漏仍入库，红线`

## 硬闸 D　专库、分类储存与禁忌混储

本闸改变混储和“普通仓位凑合”能否放行。运行时核验危化条例第 21、25、26 条，经营许可证管理办法第 8、30 条。

1. **专用仓库**  
   危险化学品应储存在专用仓库、专用场地或专用储存室，专人管理。专用仓库须符合国家标准、行业标准并设置明显标志；剧毒、易制爆专用仓库应设技术防范设施；安全设施应定期检测。文本只写“乙方仓库”而无专库参数：必须改。

2. **分类、禁忌、灭火方法**  
   性质相抵触、灭火方法不同的不得同库。修改句要求附件《禁配表》或按 GB15603 列明可混贮／禁配关系。库容利用率不得成为混贮理由。

3. **剧毒与重大危险源**  
   剧毒化学品以及储存数量构成重大危险源的其他危险化学品，应在专用仓库单独存放，实行双人收发、双人保管。储存数量、地点和管理人员应向所在地应急管理部门和公安机关备案（港区报港口部门）。未写报备：必须改，不编造报备时限。

4. **出入库核查与在库监测**  
   建立出入库核查、登记制度。在库应巡检温度、湿度、泄漏报警并建立可追溯台账。知识稿“每 2 小时红外测温”只作可谈频率，不写成未核验的法定频率。

5. **易制毒／易制爆**  
   触及易制毒、易制爆：按相应治安／管理规则报备，不在本任务写可规避报备的路径。构成重大危险源的易制爆应单独存放并双人收发。

6. **最强反方**  
   保管人主张“都是液体，一个库区更省”。签前必须把禁配和单独存放写成义务，并赋予存货人抽查和拒付对应仓储费的权利。

示例修改句（存货人，原文允许混储）：

`第【待填】条｜原文“保管人可根据库容统筹安排货位”｜建议改为“仓储物必须储存在许可载明的专用仓库内，储存条件为温度【待填】、通风【待填】、防雷防静电和泄漏报警处于适用状态。性质相抵触或灭火方法不同的货物不得同库储存。剧毒化学品或构成重大危险源的货物应当单独存放并实行双人收发、双人保管。保管人应当建立出入库核查登记和巡检台账，允许存货人按约定检查或取样。违反禁配或擅自变更储存场所的，存货人有权要求立即隔离、拒付对应仓储费并解除本合同”｜理由：硬闸 D；危化条例第 21、25、26 条；办法第 30 条｜可退让：巡检频率可协商，但不得取消台账和禁配｜不接受：混储或普通仓位凑合，红线`

## 硬闸 E　泄漏应急与事故报告

本闸改变“出了事再说”能否放行。运行时核验第 912、913 条，危化条例第 70 条，安全生产法第 83 条，突发事件应对法第 36 条。

1. **应急预案必须可执行**  
   保管人应当制定危险化学品事故应急预案，配备应急救援人员和器材，定期演练，并按规则备案。合同须写明：泄漏、火灾、爆炸时的报警、疏散、洗消、环境污染防控步骤，以及双方联络人。只有“按有关规定处理”：必须改。

2. **紧急处置与事后通知**  
   第 913 条：仓储物变质损坏危及其他仓储物安全和正常保管的，保管人应当催告存货人处置；情况紧急可以必要处置，事后及时通知。修改句禁止“保管人全权任意处置、毁尸灭迹式清理”。紧急处置限于防止事故扩大，并保留现场必要证据（法律另有规定的除外）。

3. **法定报告不得约定放弃**  
   发生生产安全事故，现场人员立即报告单位负责人；负责人组织抢救并如实报告当地负有安全生产监督管理职责的部门，不得隐瞒、谎报、迟报，不得破坏现场。修改句禁止“先内部消化、不得向主管部门报告”。

4. **联合响应**  
   双方建立联合应急机制和《应急联络表》。存货人应在【待填】小时内提供处置所需技术支持和剩余货物的安全信息。保管人不得以存货人未到场为由拒绝先期处置。

5. **最强反方**  
   保管人主张应急预案是内部文件不必作为合同附件。存货人签前必须把预案、演练记录和备案证明列为附件，否则不得收货。

示例修改句（存货人，原文无应急条款）：

`配套条款／附件｜原文缺失或仅写“发生事故按有关规定处理”｜建议改为“保管人应当制定并作为本合同附件的《危险化学品事故应急预案》，配备应急人员和器材，每【待填】个月组织演练，并按法律向应急管理部门备案。发生泄漏、火灾、爆炸或其他险情时，保管人应当立即启动预案，实施报警、疏散、洗消和环境污染防控，并向应急管理、公安等部门如实报告，不得隐瞒、迟报或破坏现场。情况紧急时保管人可作必要处置，但应当在【待填】小时内书面通知存货人，并保存现场影像和台账。双方应急联络人以附件《应急联络表》为准，变更应在【待填】日内书面通知。未配备预案或拒绝先期处置的，存货人有权解除本合同”｜理由：硬闸 E；第 912、913 条；危化条例第 70 条；安全生产法第 83 条｜可退让：演练频率可协商，但不得取消预案附件和法定报告｜不接受：无预案或禁止上报，红线`

## 硬闸 F　环境责任、保险、禁限与刑责

本闸改变概括免责和禁限物品能否放行。

1. **环境与第三人损害**  
   因货物质量、隐瞒性质、包装不符导致的环境污染治理费用，原则上由存货人承担；因保管人混储、设施失效、违反操作规程导致的，由保管人承担。双方对第三人人身财产损害的内部追偿不影响对外依法承担责任。过失为侵权人提供储存便利，可能与过错相适应担责；重大过失可能更重。修改句须分列内部归属，不得写“与保管人无关”。

2. **保险**  
   安全生产法第 51 条：高危行业、领域应当投保安全生产责任保险，其他鼓励投保。修改句要求保管人投保安责险，并视货性和敏感受体投保环境污染责任保险；保额不低于【待填】；保单作为附件。未核验具体名录时，不把“一律强制”写成已核验法律结论，但高危危化仓储文本缺少保险：必须改。

3. **禁限存储**  
   法律严禁、国家明令淘汰或禁止流通的危险物品：停笔，不给出入库路径。货性是否列入危化目录未核验：字段停止，不写“可以先入”。

4. **刑事责任不可约定免除**  
   刑法第 136 条危险物品肇事罪针对生产、储存、运输、使用中违反管理规定发生重大事故。合同不能免除法定刑事责任，也不能把“对方包揽全部刑责”写成可履行条款。民事免责不得覆盖故意或重大过失。

5. **过期危化与退库清污**  
   超过储存限期无人认领的，保管人应书面催告；逾期可按规定报请有权机关销毁或依法处置，费用由存货人承担，不得私下倾倒。合同终止后，残留污染物清理和必要的土壤／地下水监测费用须预先约定归属。

6. **概括免责无效风险**  
   保管人制式“任何事故概不负责”“最高赔仓储费一倍且排除重大事故”：按第 496、497 条审查。不合理免除保管人责任、排除存货人主要权利的格式条款，存货人必须改。

7. **最强反方**  
   保管人主张危化风险全在货主。签前必须拆开：隐瞒性质／包装不符 vs 保管不当／混储／设施失效；保险是覆盖底座，不是免责证书。

示例修改句（存货人，概括免责＋无保险）：

`第【待填】条｜原文“仓储期间任何事故均由存货人自行承担，保管人概不负责”｜建议改为“因存货人未说明危险性质、提供虚假资料或包装不符合约定造成的泄漏、污染和第三人损害，由存货人承担。因保管人未按专库条件储存、禁忌混储、消防或监测设施失效、违反操作规程或未启动应急预案造成的损失，由保管人按货值【待填】、环境治理合理费用和第三人损害承担赔偿责任。故意或重大过失不得免除。双方对刑事责任的约定无效。保管人应当投保安全生产责任保险和环境污染责任保险，保额不低于【待填】，保单作为附件；未投保不得主张风险已转移。合同终止后【待填】日内，保管人配合完成库区清污；因存货人货物导致的残留治理费用由存货人承担，因保管人混储或设施失效导致的由保管人承担”｜理由：硬闸 F；第 906、917、496、497、1229 条；安全生产法第 51 条；刑法第 136 条｜可退让：赔偿上限可谈，但不得排除故意重大过失和环境治理｜不接受：概不负责或刑责包揽，红线`

## 节点 2　主体、许可、仓库条件

1. 建主体表：签约名、仓库经营人、存货人、付款名、发票名、授权签字人、安全生产负责人、授权提货人。名称不一致不自动合并。
2. 许可名义人必须与签约保管人一致；许可借给无资质主体经营：按违法结构停笔。
3. 仓库地址、权属或转租链条、是否位于规划的危化储存区域：未闭合不写成“仓库合法且已验收”。
4. 口头“我们老板同意了”不得写成已授权。安全生产负责人会签建议写入签署块，不是法定生效要件；未会签不因此认定合同不成立。
5. 放射性、民用爆炸物品、剧毒、易制毒：许可种类可能不是经营许可证一种。种类未核验：字段停止，不把单一经营许可证写成已经足够。

---

## 节点 3　费用、保险、损耗

1. 费用必须分列：基础仓储费、安全监控费、特殊设备使用费、危险废物处置预留、应急物资储备。未给数字用 `【待填】`。
2. 计费起止和发票不编造。知识稿“环境税、排污费”是否发生运行时核验，不写成必然发生。
3. 易挥发货物的合理损耗须有百分比或计量方法；未给则 `【待填】`，不编造行业默认损耗。损耗免责以保管人已按约储存和巡检为前提。
4. 押金、保证金：无“定金”二字不得写成定金罚则。

## 节点 4　程序与生效

把许可、安全评价、消防、应急预案备案、内部决议写成**义务和期限**，不写成已经完成。

| 文本写法 | 本任务动作 |
| --- | --- |
| “本合同签字即生效，货物视同已入库” | 拆成合同成立／生效 vs 许可核验且验收后保管责任开始 |
| “办完手续后收货”但无谁负责、几日内、未完成后果 | 补主体、期限、未完成则拒绝卸货或解除 |
| 用户要求倒签或补假许可、假评价、假预案 | 整体停止 |

存货人未提供合法准运证件和完整 MSDS 的，保管人有权不予卸货——这是收货先决条件，不是已经批准。

## 节点 5　格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 5.1 格式条款

保管人制式危化仓文本、进仓须知、仓单背面条款，均可构成格式条款（第 496 条）。审查：重大事故概不负责、无资料也可入库、最终解释权、禁止向主管部门报告。仅电子勾选不足（合同编通则解释第 10 条）。未提示的后果是相对方可主张不成为合同内容，不是本任务直接改判无效。

### 5.2 强制规范

违反法律、行政法规强制性规定不一律无效（第 153 条及解释第 16 条）。禁止用已失效“效力性／管理性”口诀。经营／储存许可、专库、应急备案多为规制履行行为：合同可能仍成立，但无法合法储存构成履行障碍——用拒收、解除、返还和责任分担修改句处理，不轻易写“无许可则合同无效”，也不得把无许可改成可履行入库路径。禁止流通物、以合法形式掩盖非法目的：不改写成有效履行结构。

---

## 节点 6　违约、解除、争议解决

1. 隐瞒性质、无证收货、渗漏仍入库、禁忌混储、未启动应急、逾期付款必须分别有可执行后果。只有“依法承担违约责任”视为必须改。
2. 发现伪报瞒报极度危险物品：保管人应有单方即时解除权和立即迁出请求，不在本任务作出已解除结论。
3. 违约金避免“不得调整”或“按货值百分之三十必得”。
4. 争议解决：已有仲裁条款不得改成起诉并假装已选定诉讼；或裁或诉改成单一机构或单一法院连结点。仓库所在地可作为约定连结点，**不是**不动产式专属管辖。
5. 微信已读不写成已经送达，除非合同把该渠道定为送达。

## 节点 7　文本形态与附件

本类型文本形态应为：主合同 ＋ 安全协议 ＋ 应急预案 ＋ MSDS 资料册 ＋ 应急联络表 ＋ 入库确认单样张。缺任一项：必须改附件清单，不编造已经提交。安全协议与主合同冲突时并列，修改句指定适用顺序。

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

对照已加载框架级文件和本方法硬闸，按六步逐段出句。

| 步 | 危险物品仓储必须盯的点 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题须体现危险物品／危险化学品；主体与许可范围；鉴于写化学名称、类别、UN 号和合规承诺 | 标题或主体、许可修改句 |
| 交易条款 | MSDS 与告知；包装标识；渗漏拒收；专库参数；禁忌混储；费用分列 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 隐瞒性质责任；保管不当责任；应急预案与法定报告；即时解除；保险；环境与第三人；过期销毁与退库清污 | 可执行后果句 |
| 尾部 | 公章＋安全生产负责人会签；骑缝；附件（MSDS、安全协议、应急预案、应急联络表、入库确认单）；冲突适用顺序 | 生效与附件修改句 |
| 语言 | 正说加反说；应当≠可以／尽量；先决条件：无 MSDS 和准运证件不得卸货；运证≠仓储许可 | 替换空词的句子 |
| 常见问题 | 无许可先入、无预案、混储、概括免责、过期危化无处理、刑责包揽 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（无许可或范围不及、禁限物品、运证冒充仓储许可、渗漏仍入库、无应急预案、概括免除重大事故或刑责）；
- `必须改`：可谈但签署前要落句（MSDS、包装标识、专库参数、禁配、报备、保险、清污、入库确认单）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级货值、周边敏感受体或个人无限连带且用户拒绝升级：停止“可以签署”建议。

## 版本冲突

正文、安全协议、应急预案、MSDS、货物清单、聊天确认冲突时：

1. 并列 `D#` / `C#`，不选对用户有利的一版。
2. 修改句写明冲突项以哪一份为准，或删除冲突句。品名、UN 号或许可范围冲突不得调和成“两边都对”。
3. 不得在意见里悄悄采用有利版本并称“合同已明确”。
