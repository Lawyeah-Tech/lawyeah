# 铁路运输合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴货票／运单栏目，不证明本约条款已被接受。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》运输章、《铁路货物运输合同实施细则》、《汽车货物运输规则》、《国内水路货物运输规则》、《中国民用航空货物国内运输规则》，或已删除的旅客人身 15 万元／自带行李 2000 元限额当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、限额数字、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **运输合同 / 铁路运输合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「铁路运输合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、把道路／航空／水路／多式联运全程／国际铁路联运整案改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **铁路专法与民法典运输合同衔接**：特别法入口是《铁路法》（2015 修正）及现行铁路旅客、货物运输行政法规、部门规章；一般法是民法典运输合同章。客票、行李票、包裹票和货物运单是合同或组成部分。货物从承运到交付的货损，先走铁路法第 17、18 条，再回链民法典第 832、833 条；旅客人身走民法典第 823 条和客规第 46 条，不走路外人身解释的比例责任表。禁止用公路货规、航空每公斤限额、海商驾驶过失免责或失效实施细则改铁路条款。
2. **限额**：货物、包裹、行李按铁路法第 17 条分保价与未保价。保价按实际损失赔，最高不超过保价额；未保价按实际损失赔，最高不超过国务院铁路主管部门规定的限额。限额具体数字必须运行时核验，不得写入已废止的旅客人身 15 万元／自带行李 2000 元，也不得把未经核验的旧货规每吨数字写成现行法。客货必须分轨：货物保价限额不得覆盖旅客人身。故意或重大过失造成的货损不受限额。不得以任何方式强迫办理保价或货物运输保险。未提供保价选择却主张限额的，对抗力弱。
3. **与公路切开**：核心工具是道路车辆、道路运输经营许可或道路运单，无铁路线路上的位移主给付 → 负触发 `道路运输合同·审查`（道路运输）、`道路乘客运输合同·审查`（道路乘客）或 `道路货物运输合同·审查`（道路货物）。铁路承运人书面承诺门到门、两端汽运短驳纳入其责任的，短驳段可留本类型锁定，不因此改成道路运输整案。不得打开或抄写道路原子 method。
4. **与航空切开**：核心工具是民用航空器、航空运单或《民用航空法》责任期间 → 负触发 `航空运输合同·审查`（航空运输）、`国内航空运输合同·审查`（国内航空）或 `国际航空运输合同·审查`（国际航空）。不得用航空声明价值或每公斤限额改铁路条款。不得打开或抄写航空原子 method。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签铁路运输正文，尚未签署，尚未成争，核心给付是铁路运输企业在铁路线路上将旅客或货物从起运站运至到站并收取票款或运费，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 道路车辆、道路运输经营许可、公路运单为主给付 → `道路运输合同·审查` / `道路乘客运输合同·审查` / `道路货物运输合同·审查`；
- 民用航空器、航空运单、《民用航空法》责任期间为主给付 → `航空运输合同·审查` / `国内航空运输合同·审查` / `国际航空运输合同·审查`；
- 水路或海运区段为主给付 → `水路运输合同·审查` 或对应海事原子；
- 铁路只是区段、用户或文本按多式联运全程经营人负责 → `多式联运合同·审查`；
- 境外到站、国际货协／国际客协运单、国际铁路联运 → `国际运输合同（涉外运输合同）·审查`；
- 只有客运或货运的一般运输、无法识别是否铁路 → `客运合同·审查` 或 `货运合同·审查`，或转引擎重新定性；
- 无文本、本类型条件已谈妥、要出己方稿 → `铁路运输合同·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

无铁路运输企业资格从事经营性铁路客货运输、危险品按普通货物填报、伪造倒签：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（旅客／托运人／收货人侧或铁路运输企业侧择一）；相对方；全文及货票／客票／运单／专用线协议版本；客货是否混订；是否保价及限额是否提示；交接是货场、专用铁路还是铁路专用线；接取送达是否纳入铁路承运人责任；国内还是国际联运；缔约承运人与实际运送区段；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的运费、保价额、期限用 `【待填】`，不编造。未核验的限额数字不得写入 `L#`。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验《铁路法》第 2、11、16、17、18、58 条，《铁路旅客运输规程》（2022）第 3、46 条，铁路运输损害赔偿解释（2020 修正），铁路运输人身损害解释（2021 修正）第 1 条，民法典第 809、811、814、818、819、820、822、823、824、832、833、496–498、153、506 条；`search_practiced` 只补审查反例；`search_template` 只借货票／运单栏目。不虚构案件系统。

`search_law` 对上述法律结论及现行限额、索赔期为 required 级：不可用时不拒绝执行，只停止效力与限额数字字段。返回已失效《合同法》运输章、失效公路／水路／航空货规、已删除的 15 万元旅客限额、1994 年解释已删第 11／13／15 条、海商驾驶过失免责或民用航空法第 124／130 条时记为噪声，不得写入 `L#`。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`框架.md` 高风险词“汽车货物运输规则”必须删除。旅客人身不得引用已废止的 15 万元限额。客运合同履行中的旅客人身不得套用路外人身解释的比例责任表。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `铁路运输合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有铁路运输文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。道路、航空、水路、多式联运全程、国际铁路联运负触发。

### 2. 主体、缔约承运人与铁路法第 2 条分类

签约名、履行名、付款名、发票名分列。国家铁路、地方铁路、专用铁路、铁路专用线分列。国铁、地方铁路、合资铁路分段清算的，对外仍须锁定缔约承运人。无铁路运输企业资格经营性承运：停笔告知。

### 3. 客货分轨、标的与单据

旅客写车次、席别、日期；货物写品名、包装、件数、重量、车种。客货混订必须分章。货票与合同到站、收货人冲突并列。客运合同人身与路外人身解释分轨。

### 4. 保价与限额

提示保价选择，不得强迫。未保价限额回链现行规定。人身条款独立。失效限额删除。

### 5. 交接、门到门、专用线与逾期三十日

货场、专用铁路还是铁路专用线；检斤、铅封、篷布。接取送达是否纳入必须明示。逾期三十日未交付按灭失索赔的路径不得被合同删掉。

### 6. 格式条款、强制规范与禁运

无核验引文则法律结论字段停止。危险品匿报或人身伤害免责停笔。

### 7. 迟延、索赔期、争议

机车故障、调度延误通常不得写成不可抗力。索赔期不得短于法定最短期限。注意铁路运输法院实践，不排除货物所在站保全。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、用失效公路／航空货规或已废止限额计算铁路赔偿、把货物限额覆盖人身、或把道路／航空主轴改成可履行本类型。
- `字段停止`：法域、现行未保价限额具体数字、索赔期具体日数、专用线掌管事实、国际联运是否构成未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
