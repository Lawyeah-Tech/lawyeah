# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、货物必然完好、仓单必然对抗第三人或对方接受；编造未给出的费率、数量、入库日；把已失效《合同法》仓储章或《仓储保管合同实施细则》写入结论；把买卖检验视为合格、货交承运人风险、所有权保留或房屋租赁维修规则硬套本类型。

## 1. 触发、单方立场与成果状态

立场（存货人／保管人）、授权、签署状态、主要目标。保管稿、租仓稿、危化／易腐仓、动产买卖稿或其他负触发写路由，不启动实体审查。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》仓储章、《仓储保管合同实施细则》时记噪声，不得写入 `L#`。返回买卖检验／风险或租赁维修专属规则时标明“不适用本类型”，不得写入默认法。

## 3. 类型与加载路径

父级 `仓储合同`，子级 `普通货物仓储合同`。写定性理由和与保管／租仓／危化仓／易腐仓／动产买卖的切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。违禁品或无许可危化写停笔告知，不填可履行规避结构。

## 4. 主体、授权、资质与文本版本

主体表：签约名、履行名（仓库经营人）、存货人名、付款名、发票名、授权签字人、授权提货人。保管人写经营范围是否含仓储服务；触及危化或保税写许可名义人。版本表：正文、货物清单、仓单／入库单样张、授权提货人名单、聊天确认；冲突并列，不选对用户有利的一版。

## 5. 给付闭环（本类型必填）

固定检查并回链文本：

- 仓储物品种、规格、数量、包装、是否普通货（非危化、非易腐温控主给付）；
- 储存场所、条件（常温通风防潮防雨即可时写清；出现温控／危化专库则按节点 1 转出）；
- 入库验收范围（外包装／开箱）、程序、异议期；未约定标准必须改；
- 仓单／入库单：是否给付、一物一单、记载事项、背书须保管人签章、挂失／分割约定；禁止无单放货；
- 在库巡检、盘点、变质通知与紧急处置；
- 提取凭证、逾期加收仓储费、催告后提存（不是直接变卖）；
- 仓储费计费（面积／体积／重量／件数）、装卸搬运是否另计、结算节点、发票；
- 欠费留置范围、催告期、变价清算；禁止无关债权扣货；
- 免责范围：保管不善赔偿 vs 自然性质／包装不符／超有效储存期；主张免责的举证安排。

缺口标 `G#`，不补商业数字。许可、消防、保税批准写成义务或条件，不写成已经完成。

## 6. 格式条款与强制规范

是否构成格式条款（含保管人制式仓储文本）；提示说明痕迹。重点盯“任何货损概不负责”、无单放货、单方最终解释权。强制规范只区分是否导致民事行为无效与是否仅造成履行障碍（危化许可、保税、消防）。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。硬闸六项若文本触及或存货人立场下原文沉默，必须各有至少一行，不得用色块代替。

## 8. 修改句

按框架六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点、不接受时的红线。未给出的商业数字用 `【待填】`。禁止只给原则、不给句子。禁止输出买卖“签收视为质量合格”、货交承运人风险、所有权保留百分之七十五，或租赁维修／返还房屋句充当修改句。

## 9. 谈判与签署提醒

谈判顺序：先红线（货性管制、无许可危化、口头无单放货、概不负责、不催告变卖没收），再必须改（验收标准、仓单记载、催告期与留置范围、免责举证），最后可优化。签署提醒：授权与用印、骑缝、日期不得倒签、附件清单（货物清单、仓单样张、授权提货人名单）、仓库权属或消防材料不写成已经验收通过。不指导倒签或补假许可。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本原子只审查，不交付整份起草终稿。出己方稿转配对 ·起草 原子。不是出入库履约交底、货损诉讼文书、报关保税代办或效力保证。
