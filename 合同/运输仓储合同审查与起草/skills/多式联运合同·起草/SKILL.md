# 多式联运合同·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、1997 年《国际集装箱多式联运管理规则》、2000 年《国内水路货物运输规则》或 1999 年《汽车货物运输规则》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **运输合同 / 多式联运合同**，输出可编辑草稿和未决项，并用本类型硬闸自审后给出风险表和修改句。待签评改转 `多式联运合同·审查`。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「多式联运合同·起草」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证限额一定成立、保证海商法单位责任限制必然适用。

## 本类型硬闸

1. **与单式运输切开**：正像是经营人以**两种以上不同运输方式**负责将货物从接收地运至目的地并收取全程运费。只有公路、只有铁路、只有航空、只有水路或只有海运 → 对应单式原子，不得用本技能改完。两个以上承运人用**同一运输方式**相继运送（两段公路、两段铁路、水水联运）走民法典第八百三十四条，不是多式联运，不要套第八百四十二条网状责任。禁止打开或复制 `货运合同·审查`、`道路货物运输合同·审查` 的 method，禁止把一般货运三项免责或道路许可／治超当作本类型主路径。
2. **区段责任**：经营人对货方承担全程承运人义务。第八百三十九条允许与区段承运人约定内部分摊，该约定**不影响**经营人对全程的义务；删除“货损由实际承运人直接负责、经营人仅协助索赔”。第八百四十二条：能确定区段则经营人的赔偿责任和限额适用该区段法律；不能确定则依照民法典运输合同章（第八百三十二、八百三十三条）。禁止把“货方应证明损坏区段”写成索赔受理条件。禁止约定一律适用对经营人最有利或限额最低的区段法。无海上运输不得引用海商法第一百零六条或第五十六条；含海运且符合海商法第一百零二条的，区段不能确定时可补充适用海商法第四章限额，但不在本任务做单位责任限制精算。
3. **单据**：第八百四十条，经营人收到货物应当签发多式联运单据，按托运人要求做成可转让或不可转让。只签各区段运单／提单却对外自称全程负责，必须改签发规则或重新定性。以自己名义签发多式联运提单或运单的货代，按经营人掌握，不得再主张“仅代理订舱”。可转让单据凭正本放货；电放须收回全套正本或书面声明作废。第八百四十一条：托运人托运过错不因单据转让而消灭。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签多式联运正文，尚未签署，尚未成争，核心给付是两种以上不同方式的全程位移且经营人收取全程运费，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 仅一种运输方式，通篇货运节 → `货运合同·审查`；
- 道路运政许可、车辆营运证、治超为主路径且只有公路 → `道路货物运输合同·审查` 或 `道路运输合同·审查`；
- 同一运输方式分段相继运送 → 第八百三十四条路径，转 `货运合同·审查` 或对应单式原子；
- 铁路／航空／水路／海上货物单式本约 → `铁路运输合同·审查`、`航空运输合同·审查`（或 `国内航空运输合同·审查`／`国际航空运输合同·审查`）、`水路运输合同·审查`／`水路货物运输合同·审查`、`海上运输合同·审查`／`海上货物运输合同·审查`；
- 只撮合订舱、不以自己名义签发多式联运单据 → `货运代理合同·审查`；
- 网络货运平台入驻规则 → `网络货运平台模式下的运输合同·审查`；
- 客运 → `客运合同·审查` 或对应乘客原子；
- 保管、仓单为主给付 → `普通货物仓储合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁或货损／无单放货已立案 → `或对应专项领域。` 或争议／海商专项。

以运输为名运送依法禁止流通物、走私或无相应资质的危险货物：只出告知，不改写成可履行路径。挂靠出借许可证、伪造单据：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及单据样张／背面条款／区段名录版本；运输方式组合是否≥两种且互不相同；是否含海上运输；经营人是否签发多式联运单据及可转让性、正本份数；接收地、换装地、目的地、接管与交付条件；责任条款是网状、统一还是就低；电放安排；保险或保价；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的运费、限额、日期用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典第八百三十四、八百三十八至八百四十二条，第八百三十二、八百三十三条，含海运时海商法第一百零二至一百零六条，以及第四百九十六条、第五百零六条、第一百五十三条；`search_practiced` 只补审查反例；`search_template` 只借栏目结构，水水联运／零担／铁路单式范本不得当本约。不虚构案件系统。

`search_law` 对上述法律结论为 required 级：不可用时不拒绝执行，只停止效力字段。返回已失效《合同法》、1997 年多式联运管理规则、水路货规、汽车货规时记为噪声，不得写入 `L#`。海商法被标“已被修改”但第一百零二至一百零六条文字仍命中的，按条文适用，不得写成专节废止。合同编通则解释第十六条可解释无区段许可不当然整约无效，不得用来放行走私或禁运结构。


## 起草模式

本原子只承担本类型起草。待签评改转 `多式联运合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`，不编造。

### 起草必写

- 经营人以两种以上不同运输方式负责将货物从接收地运至目的地并收取全程运费。方式组合、接收地、换装地、目的地、接管与交付条件须落句。
- 区段责任：经营人对货方承担全程承运人义务。与区段承运人的内部分摊不影响经营人对全程的义务。能确定区段则赔偿责任和限额适用该区段法律；不能确定则依照民法典运输合同章。
- 单据：经营人收到货物应当签发多式联运单据，按托运人要求做成可转让或不可转让。抬头、签单章、合同主体三统一。可转让单据凭正本放货；电放须收回全套正本或书面声明作废。托运人托运过错不因单据转让而消灭。
- 有无海运分流：无海上运输不得引用海商法第一百零六条或第五十六条；含海运且符合海商法第一百零二条的，区段不能确定时可补充适用海商法第四章限额，但不做单位责任限制精算。

### 附件必附

- 多式联运单据样张（含可转让性、正本份数）、区段承运人名录、箱封记录。
- 保险、价格表。样张背面条款若减责，须与正文冲突规则一致，并单独提示。

### 禁止出现

- “货损由实际承运人直接负责、经营人仅协助索赔”。
- 把“货方应证明损坏区段”写成索赔受理条件；一律适用对经营人最有利或限额最低的区段法。
- 只签各区段运单／提单却对外自称全程负责；正本在外电放。
- 同一运输方式相继运送（两段公路、两段铁路、水水联运）套第八百四十二条网状责任。
- 无海运套海商法限额。一般货运三项免责或道路许可／治超不得当本类型主路径。

出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

### 0. 签署状态与成果分流

本类型条件已谈妥、要出己方稿 → 本任务起草并自审；有完整待签文本要评改 → 配对审查原子；已签履约 → 本套导航履约步骤；已成争 → 合同争议或海商／货运专项。未签且目标是评改已有多式联运文本。评改待签文本转配对审查原子，不在本任务评改。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。单式运输、同一方式联运、货代只撮合、网络货运、客运、仓储负触发。货代以自己名义签发多式联运单据的，留本任务。

### 2. 单据与经营人身份

第八百四十条签单；可转让性由托运人选择；抬头、签单章、合同主体三统一。

### 3. 区段责任与民法典／海商法分流

第八百三十九条不可下沉；第八百四十二条网状规则；有无海运决定第一百零六条是否可写。

### 4. 接管、换装、交付与电放

责任期间自接管至交付；换装记录；凭单或电放回收正本。

### 5. 运费、留置、保险

全程运费与目的地费用分列；留置限于掌管下有牵连的货物；保价覆盖未写清的区段标缺口。

### 6. 格式条款与强制规范

无核验引文则法律结论字段停止。就低限额、无单放货、禁运结构不得改成可履行。

### 7. 违约、时效与争议论坛

一个论坛解决全程纠纷。对外时效不得短于对货方最不利区段的法定期间而不作提示。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。经营人责任区段硬闸至少落一组：全程义务不可下沉、网状责任／区段不明回运输章、有无海运分流、签发多式联运单据。禁止只打红黄绿。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、无海运套海商法限额并放行、把货方证明区段写成受理条件并放行、正本在外电放并放行、把走私或禁运危货改成可运。
- `字段停止`：法域、动态规则、有无海运、单据可转让性、区段法精确限额未核验。
- `目标停止`：主目标已变为待签评改、履约交底、争议文书，或已锁他类。
