# 水路乘客运输合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》运输章、2014 年《水路旅客运输规则》（即使检索标“现行有效”）、2008 年《国内水路运输经营资质管理规定》、1986 年内河交通安全管理条例或合同法解释（二）第 14 条当作现行规则。不得把一般客运跨方式客票、水路货运货损／留置或海商法旅客限额主路径硬套本类型。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **运输合同／水路乘客运输合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「水路乘客运输合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、开航后履约交底、落水伤亡争议文书、有效性或人身必赔保证。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **旅客人身伤亡底板不得票价或海商法限额封顶**：承运人对运输过程中旅客伤亡承担责任，旅客自身健康或承运人证明旅客故意、重大过失的除外；免票、优待票、经许可搭乘的无票旅客同样适用。尽力救助不得排除。造成对方人身损害的免责条款无效。禁止“人身意外概不负责”“自愿冒险”“最高赔票价 N 倍”“适用海商法单位责任限额”“港口间海上旅客每名四万元”。承运人责任险不替代法定人身赔偿。
2. **对象是旅客及随身／托运行李，与货运切开**：货损三项免责、运费留置不得写进客票约束人身伤亡。对象是货物、运单、货损、留置 → `水路货物运输合同·审查` 或 `货运合同·审查`。禁止打开水路货运或一般货运 method。
3. **与海上客运切开**：海商法第五章适用于“经海路”将旅客从一港运至另一港。内河客渡、库区游船、运河班轮、江海交界但合同明确只走内河航段的，一般不适用海商法第四章、第五章。航线走海路 → `海上乘客运输合同·审查`。吃不准时先查航线批复、港口性质，字段停止，不套限额。
4. **国内水路客运许可、适航客船与配员**：经营性国内水路客运须取得相应许可和适航客船，按许可证经营范围经营；客运船舶须投保承运人责任保险或取得相应财务担保。许可未核：经营能力字段停止，不写“可以营运”。无证农用船、渔船载客、货船载客仍要放行：红线。
5. **超载、超额售票、救生不足“自愿”无效**：必须写船舶核定载客定额。严禁超定额载客。书面同意超载、视同自愿冒险不能覆盖。未持乘客定额证书或未按规定配备救生设施：红线。
6. **停航退改、行李双轨、实名**：迟延或不能正常运输须及时告知、安置，并按旅客要求改乘或退票。船舶故障、配员不足、燃料不够不得列入不可抗力。“风浪自负”不能排除停航退票和救助。随身物品按过错责任；托运行李适用货运规则。禁止“上船即自管、概不负责”。实名制航线人证不一致可拒载，实名船票不得擅自转让。
7. **挂靠对外仍是许可经营者；与租赁／旅游／一般客运／水路总类切开**：挂靠或承包舱位对外仍由取得许可的水路运输经营者作为承运人。光船或期租由包船人自己组织游客 → `承租人决定线路并自负运输对象风险的带驾租赁→`。景区含讲解上岸的整体旅游 → 本套导航的类型切开步骤。方式未定或铁路／公路／航空客票主路径 → `客运合同·审查`。水路尚未落入客运或货运 → `水路运输合同·审查`。禁止复制一般客运 method。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签渡运、内河班轮、库区客船或内河客运包船正文，尚未签署，尚未成争，核心给付是使用船舶在非经海路水域把旅客运到到达港，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 方式未定的一般客运，或铁路、公路、航空客票与改退签是主路径 → `客运合同·审查`；
- 对象是货物、运单、货损、留置 → `水路货物运输合同·审查` 或 `货运合同·审查`；
- 水路运输尚未落入客运或货运 → `水路运输合同·审查`；P1 未装则 `unavailable`；
- 航线经海路、适用海商法第五章 → `海上乘客运输合同·审查`；P1 未装则 `unavailable`；
- 海上运输总类或海上货物 → `海上运输合同·审查`／`海上货物运输合同·审查`；
- 光船或期租，承租人自行组织游客并自负运输对象风险 → `承租人决定线路并自负运输对象风险的带驾租赁→`；
- 景区整体旅游（讲解、上岸观光是主给付） → 本套导航的类型切开步骤；
- 道路／铁路／航空乘客特别规则为主路径 → `道路乘客运输合同·审查`／`铁路运输合同·审查`／`航空运输合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `水路乘客运输合同·起草`；
- 已签只问开航、在航、到港留痕 → 本套导航的履约步骤；
- 已催告、落水伤亡索赔、解除、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

无证农用船、渔船载客、货船载客、超载开航：只出告知，不改写成可履行营运结构。

## 建立审查坐标

确认：使用者与授权；单方立场（旅客侧、包船人侧或水路客运经营者侧择一）；相对方；全文及客票／电子订单／包船合同／航线批复版本；核心给付是船上旅客安全位移还是载货／租船／经海路；航区是内河、库区还是经海路；许可、船名、乘客定额、配员与检验是否覆盖本合同；人身限额或“自愿”条款；挂靠或实际承运人；票款与停航退改；实名制是否适用；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。知识稿与硬闸冲突时，以 method 为准。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `水路乘客运输合同·起草`；已签履约 → 本套导航履约步骤；已成争落水伤亡索赔 → 合同争议。未签且目标是评改已有内河／库区旅客运送文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。货运、经海路海上客运、一般客运、光船租赁、水路总类负触发。

### 2. 航区与许可

先判断是否经海路。再对照国内水路运输经营许可、船舶营运证、检验与配员、乘客定额、承运人责任险。未核：字段停止。

### 3. 航线、定额与票款

锁定起讫港口、船名或班期、舱位、开航与预计抵达。必须写核定载客定额。停航退改必须可执行。

### 4. 人身、救助与保险

823 底板；822 救助；506 人身免责无效。不得写入海商法限额。保险金不替代法定赔偿。

### 5. 迟延、停航、绕航

820 告知、改乘、退票。机械故障、配员不足不是不可抗力。绕航须有安全或主管部门指令。

### 6. 行李双轨、实名与格式条款

824 分轨。实名制航线人证一致。无核验引文则法律结论字段停止。

### 7. 挂靠、附件与生效

对外承运人锁定许可企业。定金不得超过价款百分之二十，且不能替代许可与适航条件。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、补假许可、无证开航、渔船或货船载客、超载发航、人身自负或票价／海商法限额封顶、排除救助、保证人身必赔。
- `字段停止`：法域、航区是否经海路、许可是否覆盖、承运人责任险覆盖区间未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类（含一般客运、水路货运、海上客运）。

生存级人身风险或个人无限连带且用户拒绝升级：停止“可以签署”建议。
