# 边界与路由

本技能只审查 **运输合同／水路乘客运输合同** 的待签文本。中文展示名是「审查水路乘客运输合同（运输合同）」。航区限于内河、湖泊、水库及合同明确不走海路的水域。形态包括渡运、内河班轮、库区客船、内河客运包船。对象是旅客及随身／托运行李，不是货物。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 方式未定的一般客运，或铁路／公路／航空客票、改退签、跨方式通用客运是主路径 | `客运合同·审查`。不得用本技能把一般客运改完 |
| 对象是货物、运单、货损、运费留置 | `水路货物运输合同·审查` 或 `货运合同·审查`。不得把货损三项免责或运费留置写进客票约束人身伤亡 |
| 水路运输尚未写明载客还是载货 | `水路运输合同·审查`。P1；未装则 `unavailable` |
| 航线经海路，或正文并入海商法第五章、港口间海上旅客限额 | `海上乘客运输合同·审查`。P1；未装则 `unavailable`。不得在本技能改完海上客运限额结构 |
| 海上运输总类尚未落入客运或货运 | `海上运输合同·审查`。P1；未装则 `unavailable` |
| 海上货物、提单、航海过失或火灾免责是主路径 | `海上货物运输合同·审查`。P1；未装则 `unavailable` |
| 光船或期租，承租人自行组织游客并自负运输对象风险 | `承租人决定线路并自负运输对象风险的带驾租赁→` |
| 景区整体旅游（讲解、上岸观光、行程安排是主给付） | 本套导航的类型切开步骤。码头到码头的单纯渡运仍留本技能 |
| 道路乘客特别规则为主路径 | `道路乘客运输合同·审查` |
| 铁路旅客特别规则为主路径 | `铁路运输合同·审查`。P1；未装则 `unavailable` |
| 航空客票、民用航空法限额为主路径 | `航空运输合同·审查`。P1；未装则 `unavailable` |
| 无文本、本类型条件已谈妥、要出己方稿 | `水路乘客运输合同·起草` |
| 已签未争、只问开航在航到港留痕 | 本套导航的履约步骤 |
| 已成争，或用户要落水伤亡索赔诉讼策略 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

旅游合同夹带运送段：运送段留在本技能，按客运强制规则审；行程安排、导游服务不在本任务展开。用户坚持本技能把一般客运、水路货运或海上客运整案改完：`目标停止`。
