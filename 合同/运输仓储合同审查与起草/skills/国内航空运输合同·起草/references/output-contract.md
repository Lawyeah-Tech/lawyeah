# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的运价、航班号、限额调整文本；把已失效《合同法》、1996 年国内客规／货规、1993 年旅客身体损害赔偿暂行规定、蒙特利尔公约／SDR 限额写入国内结论；保证航线许可一定办成；把国际航空、父级航空、国内运输总类或货代文本当成已完成的本类型审查；写“适用蒙特利尔公约”；写“人身伤害最高赔票价可接受”；写“已提供餐饮即不得索赔”。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查国内航空运输合同（运输合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、1995 年未修正民用航空法单独条号、1996 客规／货规、1993 暂行规定、国际货规、公路货规、海商法旅客限额或蒙特利尔／SDR 时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `运输合同`，子级 `国内航空运输合同`。定性理由、易混切开结果（国际航空 / 父级航空 / 国内运输总类 / 客运或货运总类 / 铁路道路水路海上 / 货代）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。未打开 `航空运输合同·审查`、`国际航空运输合同·审查` 的 method。

## 4. 主体、许可、代码共享与文本版本

主体表：签约名、出票承运人、实际承运人、销售代理人、地面服务代理、托运人、收货人、授权签字人。许可表：国内航线经营许可是否被提及（未提不得写成已持有，无许可只告知行政违法，不宣告合同当然无效）。版本表：正文、运输总条件版本号、客票或货运单样本、代码共享披露页、声明价值申请表、危险品清单、聊天确认；冲突并列。

## 5. 连结点、客货分轨、限额与声明价值、延误超售

出发／经停／到达机场三字代码是否均在境内；客或货；旅客人身、随身物品、托运行李、货物限额是否分项并提示；是否提供声明价值；延误、取消、超售的告知、签转、食宿、退款是否与法定赔偿责任分开；货运单是否记载件数、重量、品名，是否写成“仅供结算”。缺口标 `G#`。不输出公约限额口径，不输出公路、水路货规口径，不把货邮航班套用《航班正常管理规定》餐宿条款。

## 6. 格式条款与强制规范

是否构成格式条款；限额、免责、管辖是否有可感知提示。压低法定限额、排除人身伤害赔偿、把延误一律归入不可抗力、排除声明价值不得写成可放行。强制规范只按民用航空法第一百三十条和民法典第四百九十七条处理，不用失效口诀。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把蒙特利尔公约或 SDR 直接写成“国内限额类型”。

## 9. 谈判与签署提醒

谈判顺序：先红线（境外连结点、公约并入、人身赔票价、压低每公斤限额、排除声明价值、危险品瞒报），再必须改（限额分项提示、实际承运人披露、延误与食宿分开、异议期按民用航空法、货运单记载），最后可优化。签署提醒：出票或签发货运单即成立；电子客票／电子运单保存期限；运输总条件版本号、国内限额规定文本、危险品清单、声明价值申请表作为附件。不指导倒签出票日或把无许可改成可履行经营。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本原子只起草并自审，不评改对方来稿。待签评改转配对 ·审查 原子。草稿必须落入本类型三闸。不是履约交底、争议文书或效力保证，也不是国际航空、父级航空、国内运输总类或货运代理安排。
