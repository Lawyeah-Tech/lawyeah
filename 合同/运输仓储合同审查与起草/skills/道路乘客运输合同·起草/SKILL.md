# 道路乘客运输合同·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **运输合同 / 道路乘客运输合同**，输出可编辑草稿和未决项，并用本类型硬闸自审后给出风险表和修改句。待签评改转 `道路乘客运输合同·审查`。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。中文名必须是「道路乘客运输合同·起草」。

`depends-on` 为空。不要求先跑导航。

不交付：待签文本签前评改、他类起草、在途履约交底、事故争议文书、有效性或人身必赔保证。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **道路客运许可匹配**：经营性道路客运须取得道路运输经营许可，投入客车配发道路运输证，驾驶员具备相应从业资格。班线许可须覆盖合同线路、站点、班次；包车须持包车客运标志牌和书面包车合同。许可未核：经营能力字段停止，不写“可以营运”。无许可、证照失效或超范围仍要放行：红线。不得转让、出租道路运输经营许可证件。
2. **与一般客运切开**：对象虽是旅客，但运输方式未定，或主路径是铁路、航空、水路客票与改退签，只走民法典客运节、不锁定公路客车许可 → `客运合同·审查`。本技能不把跨方式通用客运改完。
3. **与网约车/巡游出租切开**：网络预约出租汽车经营许可证、运输证、驾驶员证，或巡游出租、城市公共汽车是主路径 → 负触发。平台仅撮合信息、不收运费、不开运输发票 → `一般信息中介平台模式下的合同·审查`。网约车/巡游承运主路径 → 本套导航的类型切开步骤。不得用班线或包车许可硬套网约车三证。知识双文件虽写出租与网约车，运行时仍按本闸切开。
4. **人身底板不得票价封顶**：承运人对运输过程中旅客伤亡承担责任，旅客自身健康或承运人证明旅客故意、重大过失的除外；免票、优待票、经许可搭乘的无票旅客同样适用。尽力救助不得排除。造成对方人身损害的免责条款无效。禁止“自愿冒险”“人身意外自负”“最高赔票价 N 倍”。承运人责任险不替代法定人身赔偿。
5. **核定载客与超载“自愿”无效**：包车合同必须写车辆核定载客人数。严禁营运客车超载；载客已满仅允许再搭不超过核定人数 10% 的免票儿童。书面同意超载不能覆盖。
6. **挂靠对外仍是客运企业**：挂靠车主可列履行辅助人，对外承运人仍是取得许可的企业；内部承包、管理费不能对抗旅客。禁止“仅提供技术服务”却收取运费、开具运输发票。
7. **迟延甩客、移交无资质、行李双轨**：迟延或不能正常运输须及时告知、安置，并按旅客要求改乘或退票。禁止甩客、将旅客交给他人运输、途中擅自换车。随身物品按过错责任；托运行李适用货运规则。禁止“自理概不负责”一笔勾销。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿。不是评改对方来稿。核心给付是使用客车在道路上把旅客运到约定地点。有完整待签文本要评改时转 `道路乘客运输合同·审查`。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 方式未定的一般客运，或铁路、航空、水路客票与改退签是主路径 → `客运合同·审查`；
- 网约车平台用户协议、仅撮合出行信息、不收运费不开运输发票 → `一般信息中介平台模式下的合同·审查`；P1 未装则 `unavailable`；
- 网约车或巡游出租承运、三证核验是主路径 → 本套导航的类型切开步骤，不得用本技能硬套；
- 道路运输尚未落入客运或货运 → `道路运输合同·审查`；P1 未装则 `unavailable`；
- 对象是货物、货损、运单、留置 → `道路货物运输合同·审查` 或 `货运合同·审查`；
- 承租人决定线路并自负运输对象风险的带驾租赁 → `承租人决定线路并自负运输对象风险的带驾租赁→`；
- 只派司机、车属用工单位 → `类派遣长期运输·审查`；P1 未装则 `unavailable`；
- 铁路/航空/水路/海上乘客特别法主路径 → `铁路运输合同·审查` / `航空运输合同·审查` / `水路乘客运输合同·审查` / `海上乘客运输合同·审查`；未装则 `unavailable`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问发车、在途、到站留痕 → 本套导航的履约步骤；
- 已催告、事故索赔、解除、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

无道路客运许可仍要“改到能跑”、用非营运车辆经营性载客、超载发车：只出告知，不改写成可履行营运结构。

## 建立起草坐标

确认：使用者与授权；单方立场（旅客侧、包车人侧或客运企业侧择一）；相对方；全文及客票/包车任务书/线路批文版本；核心给付是公路客车运送旅客还是租车/载货/网约派单；形态是班线、包车还是旅游；许可与车辆、驾驶员是否覆盖合同线路；核定人数；人身限额或“自愿”条款；挂靠或实际承运人；票款或包车价与退改；不可接受事项；法域与拟签署日。缺立场或本类型条件未谈妥则不启动起草。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的票价、人数、期限用 `【待填】`，不编造。

## 起草模式

本原子只承担本类型起草。待签评改转 `道路乘客运输合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`，不编造。

只起草班车、包车或旅游客运。方式未定的一般客运、网约车／巡游出租、货运：负触发，不在本任务出他类稿。

### 起草必写

- 道路客运许可匹配：经营性道路客运须取得道路运输经营许可，投入客车配发道路运输证，驾驶员具备相应从业资格。班线许可须覆盖合同线路、站点、班次；包车须持包车客运标志牌和书面包车合同。
- 形态锁定：班线写线路牌、站点、班次；包车写行程、停靠点并禁止沿途揽客；旅游客运写景区或景区间接送。
- 必须写车辆核定载客人数。载客已满仅允许再搭不超过核定人数 10% 的免票儿童。
- 人身底板不得票价封顶：承运人对运输过程中旅客伤亡承担责任；旅客自身健康或承运人证明旅客故意、重大过失的除外；免票、优待票、经许可搭乘的无票旅客同样适用。尽力救助不得排除。承运人责任险不替代法定人身赔偿。
- 迟延或不能正常运输须及时告知、安置，并按旅客要求改乘或退票。
- 随身物品按过错责任；托运行李适用货运规则。
- 挂靠车主可列履行辅助人，对外承运人仍是取得许可的企业。

### 附件必附

- 线路批文或包车任务书、保险单、旅客名单、车辆例检记录。

### 禁止出现

- 海商法第四章免责、提单、航海过失、单位责任限制或沿海货运限额写进公路客运稿。
- 转让、出租道路运输经营许可证件；无许可、证照失效或超范围仍要放行。
- “自愿冒险”“人身意外自负”“最高赔票价 N 倍”。
- 书面同意超载；甩客、将旅客交给他人运输、途中擅自换车。
- “仅提供技术服务”却收取运费、开具运输发票。
- “自理概不负责”一笔勾销行李。
- 用班线或包车许可硬套网约车三证；把货运货损／留置写进客票。非营运车辆经营性载客：只告知，不起可履行稿。

出稿后必须用「本类型硬闸」和 [自审方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

## 判断节点

执行顺序和停止条件以 [自审方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`基本面.md`、`框架.md` 把出租与网约车写成经营形态的，运行时按硬闸 3 切开，不得按知识稿把网约车三证审完。

### 0. 签署状态与成果分流

有完整待签文本要评改 → `道路乘客运输合同·审查`；已签履约 → 本套导航履约步骤；已成争事故索赔 → 合同争议。本类型条件已谈妥、要出己方稿，才进入本任务起草。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。一般客运、网约车、货运、租车、道路运输总类负触发。

### 2. 许可匹配

道路运输经营许可、班线许可或包车牌、车辆道路运输证、驾驶员从业资格与合同线路对照。未核：字段停止。

### 3. 形态、定额与票款

班线锁定线路牌、站点、班次；包车锁定行程、停靠点、禁止沿途揽客；旅游客运锁定景区或景区间接送。必须写核定载客人数。

### 4. 人身、救助与保险

823 底板；822 救助；506 人身免责无效。保险金不替代法定赔偿。

### 5. 迟延、甩客、移交

820 告知、改乘、退票。甩客或移交无资质车辆属根本违约方向，必须改。

### 6. 行李双轨与格式条款

824 随身物品过错责任，托运行李走货运规则。无核验引文则法律结论字段停止。

### 7. 挂靠、附件与生效

对外承运人锁定许可企业。定金不得超过价款百分之二十，且不能替代许可与车辆条件。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。框架中“网约车身份摇摆”的改法不在本任务展开，负触发转出。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；条件未谈妥仍要出完整稿；用户坚持倒签、补假许可、无证营运、超载发车、人身自负或票价封顶、把旅客移交无资质车辆、保证人身必赔。
- `字段停止`：法域、许可是否覆盖线路、承运人责任险限额数字未核验。
- `目标停止`：主目标已变为待签评改、履约交底、争议文书，或已锁他类（含一般客运、网约车）。

生存级人身风险或个人无限连带且用户拒绝升级：停止“可以签署”建议。

## 交付

交付可编辑草稿、未决项、自审风险表和自审后修改句。草稿必须落入本类型三闸。严格按 [输出合同](references/output-contract.md) 组织自审十节。边界见 [路由](references/routing.md)。
