# 边界与路由

本技能只按已谈妥条件起草 **运输合同 / 道路乘客运输合同**，出稿后用本类型硬闸自审。中文展示名是「道路乘客运输合同·起草」。形态限于班车（加班车）客运、包车客运、旅游客运。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 方式未定的一般客运，或铁路/航空/水路客票、改退签、跨方式通用客运是主路径 | `客运合同·审查`。不得用本技能把一般客运改完 |
| 网约车平台用户协议，仅撮合出行信息，不收运费、不开运输发票 | `一般信息中介平台模式下的合同·审查`。P1：专业版未装则 `unavailable`，提示，不得用班线/包车许可硬套 |
| 网约车或巡游出租承运、三证核验、点到点即时订单是主路径 | 本套导航的类型切开步骤。客规第 105 条：出租汽车客运按国家有关规定执行，不是本原子 |
| 道路运输尚未落入客运或货运 | `道路运输合同·审查`。P1；未装则 `unavailable` |
| 对象是货物、货损、运单、留置 | `道路货物运输合同·审查` 或 `货运合同·审查`。不得把货损三项免责写进客票 |
| 承租人决定线路并自负运输对象风险，或只租车不负责旅客安全 | `承租人决定线路并自负运输对象风险的带驾租赁→` |
| 只派司机、车属用工单位 | `类派遣长期运输·审查`。P1；未装则 `unavailable` |
| 铁路旅客特别规则为主路径 | `铁路运输合同·审查`。P1；未装则 `unavailable` |
| 航空客票、声明价值、民用航空法限额为主路径 | `航空运输合同·审查`。P1；未装则 `unavailable` |
| 水路乘客特别规则为主路径 | `水路乘客运输合同·审查`。P1；未装则 `unavailable` |
| 海上乘客特别规则为主路径 | `海上乘客运输合同·审查`。P1；未装则 `unavailable` |
| 有完整待签文本要评改 | `道路乘客运输合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、只问发车在途到站留痕 | 本套导航的履约步骤 |
| 已成争，或用户要事故索赔诉讼策略 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

旅游合同夹带运送段：运送段留在本技能，按客运强制规则审；行程安排、导游服务不在本任务展开。用户坚持本技能把一般客运、网约车三证或货运整案改完：`目标停止`。
