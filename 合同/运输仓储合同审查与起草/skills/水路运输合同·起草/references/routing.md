# 边界与路由

本技能只审查 **运输合同 / 水路运输合同** 的待签文本。中文展示名是「审查水路运输合同（运输合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或复制 `水路乘客运输合同·审查`、`水路货物运输合同·审查`、`海上运输合同·审查`、`海上货物运输合同·审查`、`海上乘客运输合同·审查`、`多式联运合同·审查`、`客运合同·审查`、`货运合同·审查`、`道路运输合同·审查`、`道路乘客运输合同·审查`、`道路货物运输合同·审查` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 对象已锁旅客，凭证是客票或客运运输条件，航区无争议 | `水路乘客运输合同·审查` |
| 对象已锁货物，凭证是国内水路运单，航区无争议且无海商法第四章主轴 | `水路货物运输合同·审查` |
| 经海路、海上运输总类未再细分 | `海上运输合同·审查` |
| 国际海上货物，或可转让提单／航海过失／货物章一年时效／单位限制为主轴 | `海上货物运输合同·审查` |
| 经海路的海上旅客运输 | `海上乘客运输合同·审查` |
| 两种以上不同运输方式由经营人组织全程 | `多式联运合同·审查` |
| 一般客运且无水路航区问题 | `客运合同·审查` |
| 一般货运且无水路航区问题 | `货运合同·审查` |
| 道路运输总类、道路乘客或道路货物监管主轴 | `道路运输合同·审查`／`道路乘客运输合同·审查`／`道路货物运输合同·审查` |
| 铁路或航空监管主轴 | `铁路运输合同·审查`／`航空运输合同·审查` |
| 只代理订舱、报关、换单，不以自己名义承运 | `货运代理合同·审查` |
| 平台只撮合、不调度船舶、不以自己名义承诺送达 | `一般信息中介平台模式下的合同·审查` |
| 有完整待签文本要评改 | `水路运输合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、只问开航／待闸／到港节点 | 本套导航的履约步骤 |
| 已成争（催告、解除、货损或人身索赔、立案、开庭、仲裁） | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

本约夹带一小段港口作业或保险安排：专章可审其对放行的影响。若用户要把海上运输、多式联运、道路运输或已锁客／货子类型整案改完：`目标停止`。

江海直达：内河段可留在本任务做识别与分段条款；海段交接给 `海上运输合同·审查` 及其子类型，不在本任务展开海商法第四章方法。两条船都走水路的接运留在本总类识别，不适用 `多式联运合同·审查`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
