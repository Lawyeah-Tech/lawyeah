## **第一步：合同类型（法律性质）分析**

* **法律定性**：国内运输合同不是又一种货运或客运产品，而是**法律适用切片**：运输的起点、约定经停点和终点**均在中华人民共和国境内**的运输合同。它解决的是“适用哪一国法、适用哪一部特别法、能否约定排除中国强制规范”，而不是再写一遍如何运货。对象仍可能是旅客、货物或多式联运，方式仍可能是道路、铁路、航空、水路或沿海。
* **适用规范的国内强制结构**：
  * 民事一般法：《民法典》运输合同章。
  * 方式特别法：《铁路法》《民用航空法》（国内航空运输部分）《道路运输条例》《国内水路运输管理条例》等。
  * 沿海港口之间的海上**货物**运输：走海路，但**不适用**《海商法》第四章。
  * 沿海海上**旅客**运输：仍可适用《海商法》第五章。
* **与国际/涉外运输的识别**：出发地、目的地或约定经停地任一在境外，或当事人、履行有其他涉外因素且构成国际运输的，进入国际运输合同审查。国内运输不得通过约定“视为国际运输”“适用外国法”来逃避中国关于许可、安全、责任下限和消费者保护的强制规定。
* **效力认定**：选择外国法或境外仲裁，不当然使合同无效，但涉及在中国履行的道路、铁路、国内航空、内河运输时，中国强制规范和行政管理仍适用。格式条款排除人身伤害责任、不合理减轻货损责任的，按中国法审查效力。

## **第二步：合同主体（交易对手）分析**

* **承运人**：必须具备**中国法下对应方式的经营资格**。国内道路、水路、铁路、航空、网络货运的许可体系互不替代。外国承运人未依法取得在华经营资格的，不能仅凭境外执照承接纯国内段经营性运输。
* **托运人 / 旅客**：均为境内履行。跨境电商的国内段揽收、国际货的国内集港，若本份合同只覆盖境内点到点，仍按国内运输识别，不要误用国际公约。
* **实际承运人与缔约承运人**：国内转包常见。对外责任按中国法锁定缔约承运人，内部追偿另约。
* **关联主体**：国内保险公司、国内港口/车站/机场。保单适用法和管辖应与运输合同国内属性匹配。

## **第三步：合同标的（交易对象）分析**

* **本切片的标的是“连结点”**：起运地、经停地、目的地的行政区划必须写全。任何境外经停，哪怕只是技术经停，都可能把航空等类型拖入国际运输。
* **运送对象仍要定性**：旅客或货物、普通货或危险货物。定性后进入相应国内特别法，而不是停在“国内运输”四个字。
* **单据**：国内客票、铁路货票、航空货运单、水路运单、道路运单。不要默认签发可转让海运提单。国内航空货运单、铁路货票的记载事项按中国规则，不能用国外提单栏位替代。
* **禁止流通与管制**：国内禁运品、危货许可、野生动植物、烟草等按中国管制法，与进出口许可证不是同一套。

## **第四步：合同程序（交易步骤）分析**

* **识别程序**：签约前确认三点都在境内，并确认有无“境外段由本合同一并负责”。一并负责境外段的，本合同不再是纯国内运输。
* **订立**：适用中国法关于成立、格式条款、电子合同的规定。公共运输不得拒绝通常、合理要求。
* **履行监管**：安检、实名、路政、海事、民航安全检查均为强制程序，合同不能约定免除。
* **索赔程序**：时效、通知期限按中国对应特别法。国内航空、铁路有自身索赔期；国内公路、内河货运原则上走民法典和民事诉讼法，不要写入海牙规则一年时效或蒙特利尔公约期限。

## **第五步：交易结构设计（风险规避方案）**

* **法律适用条款**：直接写“适用中华人民共和国法律”。方式特别法按实际运输方式列明。禁止“适用承运人主营业地法”来架空中国强制规范。
* **责任结构**：人身伤亡按中国客运/航空/铁路/海商法旅客规则；货损按中国对应方式的赔偿和限额。国内公路、内河普通货运无特别限额的，按实际损失，不得偷运国际海运或国际航空限额。
* **争议解决**：中国法院或中国仲裁机构最为契合。选择境外仲裁并非当然无效，但执行和保全成本高，且不能排除中国行政机关、公安机关对安全事故的管辖。
* **保险**：投保中国境内有效的承运人责任险或货运险；境外保单可能不覆盖纯国内段。
* **拆段**：国际运输的国内集疏运应另签国内运输合同，避免整单适用公约或外国法。

## **第六步：宏观风险预警与尽调指引**

* **高频争议点**：国内运输合同却约定适用海商法第四章或蒙特利尔公约；国内段被国际货代提单“并入”外国法；网络货运、信息中介的国内平台责任被写成“仅提供信息”。
* **尽职调查清单**：
  * [ ] 起点、经停点、终点是否均在中国境内
  * [ ] 运输方式及对应中国许可
  * [ ] 适用法是否写成中国法，有无偷换公约
  * [ ] 责任限额是否属于该方式在中国的现行规则
  * [ ] 单据是国内运单/客票还是国际提单
  * [ ] 争议解决地是否可执行、是否妨碍国内保全
* **重大风险红旗**：纯国内公路货运约定“按海牙规则每件666.67SDR”；国内航空客票约定排除《民用航空法》；引用已失效的汽车货物运输规则或国内水路货物运输规则。
