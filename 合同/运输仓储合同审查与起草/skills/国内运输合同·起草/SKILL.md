# 国内运输合同·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把已失效《汽车货物运输规则》《国内水路货物运输规则》、海牙规则／蒙特利尔公约期限、海商法第四章适用于中国港口之间货运当作现行规则。2004 年《道路运输条例》旧第十条、旧第二十四条不得当作 2023 修订本条文写入结论。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **运输合同 / 国内运输合同**：运输的起点、约定经停点和终点均在中华人民共和国境内，核心问题是适用哪一国法、适用哪一部中国特别法、能否约定排除中国关于许可、安全、责任下限和消费者保护的强制规范，而不是再写一遍如何运货或载客。输出可编辑草稿和未决项，并用本类型硬闸自审后给出风险表和修改句。待签评改转 `国内运输合同·审查`。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「国内运输合同·起草」。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查、从零起草、履约交底、争议文书、合同或许可有效性保证、把本约改成可强制履行的国际运输或某一方式营运细则、货运代理／平台／信息中介整案、无证经营或规避许可的可履行改写。

## 工作边界

正触发：已有可读待签文本要评改（审查模式），或本类型条件已谈妥要出己方稿（起草模式）；尚未签署，尚未成争；标题或外壳是国内运输、国内货物／旅客运输或境内点到点运输；**且**核心给付是连结点、适用法、中国强制规范和单据选择，而不是单一方式的营运操作细则，也不是跨境段运输。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 起运地、约定经停地或目的地任一在境外，或本合同一并负责境外段 → `国际运输合同（涉外运输合同）·审查`；
- 用户锁定公路／铁路／航空（或水路、海上、多式联运、客运、货运产品），只要该方式营运细则，且无公约／外国法／提单偷换 → 对应方式原子（道路 `道路运输合同·审查`／`道路乘客运输合同·审查`／`道路货物运输合同·审查`，铁路 `铁路运输合同·审查`，航空 `航空运输合同·审查`／`国内航空运输合同·审查`，水路 `水路运输合同·审查`／`水路乘客运输合同·审查`／`水路货物运输合同·审查`，海上 `海上运输合同·审查`／`海上货物运输合同·审查`／`海上乘客运输合同·审查`，多式联运 `多式联运合同·审查`，客运 `客运合同·审查`，货运 `货运合同·审查`）；
- 国际航空连结点 → `国际航空运输合同·审查`；
- 订舱、报关、不签发承运人单据，受托人不是承运人 → `货运代理合同·审查`；
- 网络货运平台以承运人身份缔约的平台本约 → `网络货运平台模式下的运输合同·审查`；
- 平台只提供信息撮合、明文“仅提供信息” → `一般信息中介平台模式下的合同·审查`；
- 长期派司机派车、人格从属像用工 → `类派遣长期运输·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问发运日、到站日、运单留痕 → 本套导航的履约步骤；
- 已成争（催告货损、解除、索赔、诉讼仲裁）→ 合同争议或对应专项领域。

挂靠、无证经营、规避许可、用假运单包装承运人资格：只出告知，不改写成可履行结构。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成。每一闸必须给出修改句或明确转出口径，禁止只打红黄绿。

1. **国内运输总括 vs 涉外运输**。标题写运输、货运或物流不决定类型。必须同时读出三组事实：起运地、约定经停地、目的地的省市区和场站；有无境外技术经停；本合同是否一并负责境外段。任一境外点或一并负责境外段的，负触发 `国际运输合同（涉外运输合同）·审查`。修改句必须把连结点改成：本合同项下运输的起点、约定经停点和终点均在中华人民共和国境内，分别为【待填】、【待填】、【待填】；出现境外点的，该票运输不适用本合同的国内规则，双方应改签或分签境外段。禁止打开 `国际运输合同（涉外运输合同）·审查` method。禁止用约定“视为国际运输”改变连结点。
2. **国内运输总括 vs 单一方式专项**。本任务不写成又一篇货运、客运或某一方式营运审查。必须读出运输方式与对象，并指向对应中国特别法，但不打开该方式专档 method，也不把包装、配载、运价、货损操作做成主路径。用户锁定公路／铁路／航空并只要营运细则、且无切片争点的，负触发对应方式原子。禁止用 `客运合同·审查`、`货运合同·审查` 或任一方式专档换皮。禁止把各具体运输方式并进本原子。

附加必落句（有事实则单列，无事实在缺口节说明）：

- **适用法**：直接写适用中华人民共和国法律及对应运输方式的现行法律、行政法规。删除“国际惯例优先于中国法”“适用承运人主营业地法”用来架空中国强制规范的句子。
- **限额与公约**：国内公路、内河普通货运无特别限额的，按实际损失，不得偷运海牙规则每件 666.67 SDR 或国际航空限额。国内港口之间海上**货物**运输不适用海商法第四章。三点都在境内的航空是国内航空，不得“按国际航空运输办理”。有法定限额的只能书面提高，不能随意压低到不合理程度。
- **单据**：国内运单、货票、客票。禁止无必要地签发可转让提单。附件不得夹带国际公约全套条款。
- **承运人许可**：必须具备中国法下对应方式的经营资格。道路、水路、铁路、航空、网络货运许可互不替代。外国承运人未依法取得在华经营资格的，不能仅凭境外执照承接纯国内段经营性运输。
- **强制程序**：国内强制安检、实名、危货申报不得约定“托运人要求免除检查”。车辆故障、配员不足、未订到舱位不是不可抗力。
- **争议解决**：优先中国大陆法院或仲裁机构；至少保留中国法院对货物所在地的保全管辖。国内安全事故的行政、刑事管辖不能用仲裁条款排除。纯国内履行不要选择外国法。
- **失效规则**：删除《汽车货物运输规则》《国内水路货物运输规则》。

必须有修改句。每个风险回链文本位置。禁止复制 `国际运输合同（涉外运输合同）·审查` 或任何方式专档 method。

## 建立审查坐标

确认：使用者与授权；单方立场（托运人／旅客，或承运人，择一）；相对方；全文及运单／客票／价目／许可证附件版本；起运地、经停地、目的地；运输方式与对象；适用法与限额；单据种类；承运人中国许可是否被材料提及；境外段是否由本合同一并负责；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的金额、地点、期限用 `【待填】`，不编造。

知识库若写“本类型就是又一种货运产品”“口头一律无效”“选外国法或境外仲裁当然使合同无效”“未取得许可则整约当然无效”，或以失效汽车货物运输规则、国内水路货物运输规则为现行依据，以本文件和 `method.md` 纠正为准，不回写知识正文。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law`（法律结论 required）：核验连结点识别、海商法第二条文本、民用航空法国内／国际航空定义、公共运输强制缔约、货损与人身赔偿、格式条款免责、强制规范是否导致无效、外国承运人国内经营限制。
- `search_practiced`（optional）：补国内段误用公约、无涉外因素境外仲裁争点。返回“国内合同选境外仲裁当然有效”“海牙规则当然适用于国内公路”“公约当然优先于国内法”时记噪声。
- `search_template`（optional）：只借栏目结构。范本引用失效《合同法》或《水路货物运输规则》、或只有国际货代提单栏目的，不得当规则。

不虚构案件系统。`search_law` 返回已失效《合同法》及其解释、汽车货物运输规则、国内水路货物运输规则、2004 年未修订道路运输条例旧条号时记为噪声，不得写入 `L#`。民用航空法第一百零七条、铁路法第十一条、国内水路运输管理条例第十一条本次优先命中旧文本且效力字段为“已被修改”的，识别口径可用，该条号不写入稳定 `L#`。


## 起草模式

本原子只承担本类型起草。待签评改转 `国内运输合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。本约是连结点与中国强制规范切片，不写成又一篇货运、客运或某一方式营运细则。

1. 先按框架六步落稿：首部锁境内三点连结点与运输方式；交易条款写适用法、单据、承运人中国许可；配套写限额不得偷运公约、强制安检实名危货申报；尾部写中国大陆争议解决与保全；正说反说后按下述必写与禁忌落句。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿。自审至少核对：三点是否均在境内、有无“视为国际运输”、有无公约限额或失效货规、单据是否国内运单／货票／客票。输出风险表和修改句。不得只交白稿。
3. 涉外运输、单一方式营运专档、货代、网货平台、信息中介出稿、已签履约、已成争：仍负触发。

**起草必写**：本合同项下运输的起点、约定经停点和终点均在中华人民共和国境内，分别为【待填】、【待填】、【待填】；出现境外点的，该票不适用本合同的国内规则，应改签或分签境外段。直接写适用中华人民共和国法律及对应运输方式的现行法律、行政法规。国内公路、内河普通货运无特别限额的，按实际损失。国内港口之间海上货物运输不适用海商法第四章。三点都在境内的航空是国内航空。有法定限额的只能书面提高。单据用国内运单、货票、客票。承运人必须具备中国法下对应方式的经营资格；道路、水路、铁路、航空、网络货运许可互不替代。国内强制安检、实名、危货申报不得免除。争议解决优先中国大陆法院或仲裁机构，至少保留中国法院对货物所在地的保全管辖。

**附件必附**：国内运单、货票或客票样张；对应方式中国经营资格材料（外国承运人未依法取得在华经营资格的，不能仅凭境外执照承接纯国内段）。

**禁止出现**：视为国际运输；国际惯例优先于中国法；适用承运人主营业地法架空中国强制规范；偷运海牙规则每件 666.67 SDR 或国际航空限额；国内港口之间海上货物运输适用海商法第四章；三点境内航空按国际航空运输办理；无必要地签发可转让提单；附件夹带国际公约全套条款；托运人要求免除检查；车辆故障、配员不足、未订到舱位写成不可抗力；纯国内履行选择外国法；引用《汽车货物运输规则》《国内水路货物运输规则》。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口，不代替节点。

0. 签署状态与成果分流
1. 类型识别与单目录加载（连结点全在境内；切开国际运输／方式专档／货代／平台）
2. 连结点、适用法与强制规范切片
3. 主体、许可、缔约承运人与实际承运人
4. 对象、单据与管制
5. 责任、限额、时效与保险
6. 争议解决、保全与解除
7. 格式条款与强制规范
8. 按框架六步出修改句

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签运单或许可、把无中国许可的境外承运人改成可履行纯国内经营、把挂靠或规避许可改成可履行结构、保证必然有效或限额必然按某公约执行、按国际运输或某一方式专档改完且拒绝切开。
- `字段停止`：连结点行政区划、适用法核验、某一方式法定限额精确数字、承运人许可真伪、无涉外因素时境外仲裁效力。
- `目标停止`：主目标已变为待签评改、履约交底、货损诉讼文书，或用户要把本约改成国际运输或某一方式营运细则以便请求实际履行。

生存级货值或个人无限连带且用户拒绝升级：停止“可以签署”建议。
