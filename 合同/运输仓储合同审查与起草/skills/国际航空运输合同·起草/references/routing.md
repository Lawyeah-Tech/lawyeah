# 边界与路由

本技能只审查 **运输合同 / 国际航空运输合同** 的待签文本。中文展示名是「审查国际航空运输合同（运输合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开 `航空运输合同·审查`、`国内航空运输合同·审查`、`国际运输合同（涉外运输合同）·审查`、`客运合同·审查`、`货运合同·审查` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 出发、约定经停、目的三点均在中华人民共和国境内 | `国内航空运输合同·审查`。禁止用本技能把国内航空改成国际航空，也禁止把国内四十万元／每公斤一百元写入国际文本 |
| 无连结点事实，来稿只定性为“航空运输”而不切开国内／国际 | `航空运输合同·审查`。P1：专业版未装则 `unavailable`，提示，不得用本技能硬套 |
| 跨境运输但主路径不是航空方式（海运、铁路、公路跨境或未指明方式） | `国际运输合同（涉外运输合同）·审查`。P1；未装则 `unavailable`。禁止把海运、铁路写进航空公约 |
| 两种以上不同运输方式，经营人负责全程 | `多式联运合同·审查`。P1；未装则 `unavailable` |
| 提单、海牙／维斯比规则、海商法单位责任限制为主路径 | `海上货物运输合同·审查`。P1；未装则 `unavailable`。空运单不是提单 |
| 铁路运单、铁路保价与限额为主路径 | `铁路运输合同·审查`。P1；未装则 `unavailable` |
| 只撮合订舱或车位，不承运，不以自己名义签发航空货运单 | `货运代理合同·审查`。P1；未装则 `unavailable`。纯媒介也可交 `房屋买卖或租赁中介→` |
| 货代以自己名义签发航空货运单并收取运费，或不能证明授权而以承运人代理人名义签发 | **不转出装切开**。按本类型缔约承运人义务审查，或同时提示货代原子只处理代理段 |
| 非航空的一般客运客票、改退签 | `客运合同·审查` |
| 非航空、无航空票证的一般货运 | `货运合同·审查` |
| 有完整待签文本要评改 | `国际航空运输合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、只问值机在途提货留痕 | 本套导航的履约步骤 |
| 已成争，或用户要伤亡／货损索赔诉讼策略 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

国际航空正文里夹带一小段地面短驳或机场仓储：航空区段仍先按本类型审；独立计价且以海运提单或铁路运单为主的区段可交接对应原子。用户坚持本技能把国内航空、航空总类、国际运输总类、海运提单、铁路或只撮合货代整案改完，或坚持按国内四十万元／每公斤一百元改完国际文本：`目标停止`。
