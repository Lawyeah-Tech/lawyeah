# 水路运输合同·审查

## 任务目标

在单一立场下，只审查 **运输合同 / 水路运输合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「水路运输合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、把海上货物／海上旅客整案改完、把多式联运整案改完、用水路乘客或水路货物子类型 method 替代本总类。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **航区第一刀：内河／国内沿海 ≠ 海商货物专章**。国内水路指始发港、挂靠港和目的港均在中华人民共和国管辖通航水域内的经营性旅客或货物运输，含内河、湖泊、水库、运河及国内沿海；监管走《国内水路运输管理条例》。海商法上的海上运输是海上货物或海上旅客运输，并包括江海直达的海段。《海商法》第四章不适用于中国港口之间的海上货物运输，更不得用来处理纯内河货运。
2. **客货必须分流**。本总类解决航区识别、经营许可和适用规范选择，不替代人身伤亡规则或货损规则。正文必须立刻标明客运或货运。对象确定后分别落入 `水路乘客运输合同·审查` 或 `水路货物运输合同·审查`。禁止一份水运协议混用客货免责。
3. **内河／水路总括 ≠ 海上货物／海上旅客**。经海路、海上旅客、国际海上货物，或以可转让海运提单、航海过失、火灾免责、货物章一年时效、单位责任限制、海牙／维斯比／汉堡规则为主轴 → 负触发 `海上运输合同·审查`／`海上货物运输合同·审查`／`海上乘客运输合同·审查`。禁止打开或复制其 method。江海直达：内河段按本总类，海段按海上运输；区段不明时的归责单独写，不得默认适用第四章。
4. **内河／水路总括 ≠ 多式联运**。一份合同组织两种以上不同运输方式（水路＋公路／铁路／航空等）并由经营人对全程负责 → 负触发 `多式联运合同·审查`。禁止打开其 method。两条船、两段都是水路的接运适用民法典第八百三十四条，不得误标为多式联运。
5. **禁止并入海商法第四章免责、限额与时效**。未识别为适用第四章的国际海上货运航次，删除航海过失、承运人火灾免责、货物单位限制和货物章一年时效。不得把“视为海运”“一律适用海商法及国际惯例”写进内河或国内沿海总类。
6. **禁止引用失效《国内水路货物运输规则》**。2016 年已废止。出现“按国内水路货规办理”或 1997 年示范文本把货规当准据法的，一律删除，改引民法典第八百三十二条、第八百三十三条及现行条例。
7. **货船载客、超载与无许可**。不得超载或使用货船载运旅客。无国内水路运输经营许可是行政违法，合同不当然无效，但不减轻适航、配员和法定赔偿，也不得写成“无证可以放行”。挂靠、承包对外仍由许可持有人承担责任。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签水路运输总类文本（含水运服务、包船、渡运框架），尚未签署，尚未成争，航区落在国内水路且客货或航区尚未锁成子类型或海上主轴，也未变成两种以上运输方式的多式联运，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 对象已锁旅客、凭证是客票、主文走客运节，航区无争议 → `水路乘客运输合同·审查`；
- 对象已锁货物、凭证是国内水路运单、主文走货损交付，航区无争议且无海商法第四章主轴 → `水路货物运输合同·审查`；
- 经海路、海上旅客、国际海上货物，或海运提单／航海过失／货物章一年时效／单位限制为主轴 → `海上运输合同·审查`／`海上乘客运输合同·审查`／`海上货物运输合同·审查`；
- 两种以上不同运输方式由经营人组织全程 → `多式联运合同·审查`；
- 公路班线、道路运单或道路运输许可为主轴 → `道路运输合同·审查`／`道路乘客运输合同·审查`／`道路货物运输合同·审查`；
- 铁路或航空监管主轴 → `铁路运输合同·审查`／`航空运输合同·审查`；
- 一般客运或一般货运且无水路航区问题 → `客运合同·审查`／`货运合同·审查`；
- 只代理订舱、不以自己名义承运 → `货运代理合同·审查`；只撮合信息不调度船舶 → `一般信息中介平台模式下的合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `水路运输合同·起草`；
- 已签只问开航、待闸、到港节点 → 本套导航的履约步骤；
- 已催告、解除、货损或人身索赔、立案、开庭或仲裁 → `或对应专项领域。` 或对应专项。

挂靠、货船载客、超载“自愿”、伪造许可或倒签开航：只出告知，不改写成可履行结构。用户坚持保留“一律适用海商法及国际惯例”、把失效货规当现行法、把货船载客改成可履行、或把多式联运当本总类改完：整体停止。

## 建立审查坐标

确认：使用者与授权；单方立场（承运人侧或旅客／包船人／托运人侧择一）；相对方；全文及许可／船舶证书／航线图／客票或运单样张／危货说明版本；航区是内河、国内沿海还是经海路；对象是旅客还是货物；起讫港、是否过闸、是否进入感潮河段或海域；是否江海直达；是否夹带公路／铁路／航空区段；单据种类；是否引用海商法第四章或失效货规；不可接受事项；法域与拟签署或开航日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)

禁止打开其他类型目录。禁止打开或复制 `水路乘客运输合同·审查`、`水路货物运输合同·审查`、`海上运输合同·审查`、`多式联运合同·审查`、`客运合同·审查`、`货运合同·审查` 的 method。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `水路运输合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议或专项。未签且目标是评改已有本类型文本，才进入本任务。

### 1. 航区、客货、海上与多式联运切开

先定航区，再定客货，再看是否夹带其他运输方式。经海路或海商法第四章主轴负触发海上原子；两种以上运输方式负触发多式联运；已锁乘客或货物专用文本负触发对应子类型。

### 2. 主体、许可与船舶航区等级

许可覆盖航区和客货种类；船舶航区等级不得低于合同航线；挂靠对外仍由许可持有人负责。

### 3. 分流条款、单据与江海直达分段

客运用客票，货运用国内水路运单（通常不可转让）。江海直达分段适用。

### 4. 责任分轨与失效法规

人身走第八百二十三条，货损走第八百三十二条、第八百三十三条。删除第四章免责和失效货规。

### 5. 对价、停航与退出

预付或到付须唯一；水位、封航、船闸检修应可核验并衔接退改或改走其他方式。

### 6. 格式条款、强制规范与货船载客

人身免责、货船载客、超载自愿：删除或整体停止。无许可不当然无效。

### 7. 违约、留置与争议

货运留置限于相应货物；客运不发生货物留置。不要排除货物或船舶所在地保全。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签或补假许可、保证必然有效、保留一律适用海商法及国际惯例、把失效货规当现行法、把货船载客或超载自愿改成可履行、把多式联运当本总类改完。
- `字段停止`：法域、许可原件、船舶航区等级、江海直达区段、是否构成多式联运、海事赔偿限制数字未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁水路乘客、水路货物、海上运输或多式联运。
