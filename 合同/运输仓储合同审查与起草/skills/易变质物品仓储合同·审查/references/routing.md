# 边界与路由

本技能只审查 **仓储合同 / 易变质物品仓储合同**。中文展示名是「审查易变质物品仓储合同（仓储合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 常温通风防潮即可；温控只是附带“注意防潮”；工业品／建材／普通包装件 | `普通货物仓储合同·审查`。不得用冷链测温句改普通仓 |
| 危化品、易燃易爆、剧毒、腐蚀、放射性；要求危化经营／储存许可、MSDS、安全评价、防爆专库 | `危险物品仓储合同·审查`。专业版未装 P1：`unavailable`，不得用冷链硬套，也不得改成可履行危化结构 |
| 仅出租冷库面积／货位，无验收、无仓单、明确货损自负、不对温控失败负责 | `仅出租库房／货位，保管人对货损和事故不负责→`。吉林省等冷藏冷冻食品仓库**租赁**示范文本按租赁走，不按本仓储审 |
| 无偿保管，或明确自交付才成立、无商业仓储费 | 保管合同；转引擎重新定性。不得用第 890 条改本约成立 |
| 核心给付是位移：冷藏车、运单／提单、只对运输区段负责 | `货运合同·审查` 或对应货运原子。仓储与运输交接的“断链”可在本约写分界，但不把本约改成运输合同 |
| 转移货物所有权换价款；买卖检验、货交承运人、所有权保留是主路径 | `核心给付是转移货物所有权换价款→` |
| 保税仓、海关特殊监管仓为主给付且无许可材料 | 许可字段停止或转引擎；不改可履行无证保税操作 |
| 无文本、本类型条件已谈妥、要出己方稿 | `易变质物品仓储合同·起草` |
| 已签未争、入库测温／巡检／出库留痕 | 本套导航的履约步骤 |
| 已成争（货已腐索赔、催告、解除、立案、仲裁） | `或对应专项领域。` 或对应专项 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

正文是冷链仓储、夹带一小段危化溶剂或一段冷藏运输：危化专章交接 `危险物品仓储合同·审查`；运输专章交接货运原子；易变质仓储条款可继续审。用户坚持本技能把危险品仓、普通仓、租空库或运输整案改完：`目标停止`。

专业版未收录的其他 P1 场景不会安装对应原子。若用户拿危险品仓文本来找未装的 `危险物品仓储合同·审查`：输出 `unavailable`，提示，不得用本冷链原子硬套。
