# 易变质物品仓储合同·审查

## 任务目标

在单一立场下，只审查 **仓储合同 / 易变质物品仓储合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「易变质物品仓储合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查、从零起草、出入库履约交底、变质索赔争议文书、有效性保证、保证货必不腐或仓单必然对抗第三人。

## 本类型硬闸

审查过程必须逐项点名。禁止用普通仓防潮、危化专库、租仓维修或买卖验收清单代替：

1. **温控／保质期书面量化**：保管人核心给付是持续性环境维持，不是只提供库位。存货人须书面告知储存温度区间、湿度、保质期限、避光及入库初始品质。禁止“适宜温度”“低温保存”等空词。修改句落到具体区间、允许日波动、入库中心温度、24 小时监测与调取、备用电源／启动时限、先进先出。未量化：必须改，不编造 ℃ 数字充作已约定。
2. **变质风险分担**：拆开自然损耗／货物自身内在缺陷／入库前已变质，与制冷故障、断电、擅自改温、断链、串味等非正常变质。第 917 条免责仅三项（自然性质、包装不符、超过有效储存期），主张免责须证明已按约温控与验收。市政停电不当然构成不可抗力；未配备用电源或未及时补救不得写成免责。缺连续温控记录：合同可推定保管期间过错，但不得把“举证责任倒置”写成未经核验的法定结论。
3. **验收与通知**：入库须测中心温度、查包装与感官，超温可拒收或加收预冷费并书面注明。第 907 条：按约验收；验收后品种、数量、质量不符由保管人赔。第 912 条：发现变质或其他损坏须及时通知。第 913 条：危及其他仓储物须催告处置；紧急可必要处置，事后通知。第 906 条第 1、2 款：存货人须说明易变质性质并提供资料，未说明可拒收或采取措施，费用由存货人负担。禁止“保管人全权处理、事后不必通知”。
4. **与危险品仓储切开**：主给付是易燃、易爆、有毒、腐蚀性、放射性等危险物品，或文本要求危化经营／储存许可、MSDS、安全评价、防爆专库 → `危险物品仓储合同·审查`。未装 P1 则 `unavailable`。不得删掉危化条款后当冷链审，也不得把冷链文本改写成可履行危化仓。第 906 条第 3 款“具备相应保管条件”针对危险物品，不把本类型改成危化审查。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签文本要评改，；尚未签署，尚未成争，核心给付是保管人对易腐、鲜活、需持续温湿度控制的仓储物提供储存保管与环境维持，存货人支付仓储费（含冷链仓、温控仓、冷藏冷冻仓）。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 常温通风防潮即可、温控只是附带一句“注意防潮” → `普通货物仓储合同·审查`；
- 危化品、易燃易爆、剧毒、管制化学品仓储为主给付 → `危险物品仓储合同·审查`；专业版未装 P1 则 `unavailable`，不得用本类型硬套；
- 仅出租冷库面积／货位，保管人对货损不负责、无环境维持劳务 → `仅出租库房／货位，保管人对货损和事故不负责→`；
- 无偿保管，或明确自交付才成立、无商业仓储费 → 保管合同，转 本套导航的类型切开步骤 重新定性；
- 核心给付是位移、冷藏车承运、运单／提单，不对在库持续温控负责 → `货运合同·审查` 或对应货运原子；
- 核心给付是转移货物所有权换价款 → `核心给付是转移货物所有权换价款→`；
- 无文本、本类型条件已谈妥、要出己方稿 → `易变质物品仓储合同·起草`；
- 已签只问入库测温、巡检、出库留痕 → 本套导航的履约步骤；
- 已成争（货已腐索赔、催告、解除、诉讼仲裁）→ `或对应专项领域。` 或对应专项。

以冷链为名接管制危化、走私货，或把已过期／已霉变货改成可入库：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；存货人或保管人单一立场；相对方；正文、附件、《货物温控要求清单》、应急联络名单、仓单／入库单样张版本；货种（果蔬／冻肉／乳品／疫苗血液等）；书面温湿度与保质期；入库中心温度与验收程序；监测与备用电源；食品贮存是许可还是备案；不可接受事项；法域与拟签时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的费率、温度、保质期、损耗率用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验第 904–918 条（重点 906、907、912、913、917）、第 453 条鲜活易腐留置例外、第 180／590 条不可抗力、第 496／506 条格式免责、食安法实施条例第 24／25 条及食品经营许可和备案管理办法第 65 条；`search_practiced` 补冷链断链／缺温控记录争点；`search_template` 只借栏目结构，冷库租赁示范文本不得当作本仓储本约。不虚构案件系统。

`search_law` 对法律结论为 required 级节点：不可用时不拒绝执行，只停止法律结论字段。返回已失效《合同法》仓储章、《仓储保管合同实施细则》、担保法解释时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准。

知识稿把紧急处置写成第 906 条、把食品冷链一律写成须取得食品经营许可：以本技能 method 纠正为准，不回写双文件。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `易变质物品仓储合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有易变质仓储文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。普通仓、危险品仓、租空库、保管、冷链运输、买卖负触发。

### 2. 温控／保质期

量化区间、入库中心温度、24 小时记录、备用电源、FIFO。空词必须改。

### 3. 验收与通知

入库测温／感官／包装；第 907、912、913、906 条程序句。

### 4. 变质风险分担

自然损耗 vs 非正常变质；断电豁免限制；缺记录合同推定；第 917 条三项免责须举证。

### 5. 主体与食安／药品资质

食品：区分自身经营许可与非食品生产经营者备案。疫苗／血液／药品：字段停止或升级，不按普通生鲜放行。

### 6. 串味、超期入库、仓单与鲜活留置

禁止混放串味；超期／已霉变禁入；逾期提取催告后提存；鲜活易腐留置不受六十日下限。

### 7. 格式条款与强制规范

无核验引文则法律结论字段停止。停电免责、货损概不负责须提示说明。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持倒签、把无资质危化或已霉变／超期货改成可入库、保证货必不腐、把市政停电写成当然不可抗力并放行无备用电源结构。
- `字段停止`：温控参数未量化；货性是否危化未核验；食品贮存许可／备案未核验；疫苗／血液监管条件未核验；留置宽限期法定口径待核。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁普通仓／危险品仓／租仓／运输。

生存级货值或个人无限连带且用户拒绝升级：停止“可以签署”建议。
