# 普通货物仓储合同·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **仓储合同 / 普通货物仓储合同**，输出可编辑草稿和未决项，并用本类型硬闸自审后给出风险表和修改句。待签评改转 `普通货物仓储合同·审查`。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。`depends-on` 为空。不要求先跑导航。

不交付：他类审查、从零起草、出入库履约交底、货损争议文书、有效性或货物必然完好／仓单必然对抗第三人的保证。

## 工作边界

正触发：已有可读待签文本要评改（审查模式），或本类型条件已谈妥要出己方稿（起草模式）；尚未签署，尚未成争，核心给付是保管人储存存货人交付的**普通货物**、存货人支付仓储费（储存保管劳务，不是卖货，也不是只租空库）。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 无偿保管、或明确自交付才成立、无商业仓储费主给付 → 保管合同，转 本套导航的类型切开步骤 重新定性；
- 仅出租库房／货位，保管人对货损不负责、无储存保管劳务 → `仅出租库房／货位，保管人对货损和事故不负责→`；
- 危化品、易燃易爆、剧毒、管制化学品仓储为主给付 → `危险物品仓储合同·审查`；专业版未装 P1 则 `unavailable`，不得用本类型硬套；
- 易腐、冷链、温控是主给付 → `易变质物品仓储合同·审查`；未装则 `unavailable`；
- 核心给付是转移货物所有权换价款 → `核心给付是转移货物所有权换价款→`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问入库、盘点、出库留痕 → 本套导航的履约步骤；
- 已成争（货损索赔、催告、解除、诉讼仲裁）→ `或对应专项领域。` 或对应专项领域。

普通仓存放管制危化、走私货或无许可硬接危化：只出告知，不改写成可履行入库结构。

## 建立审查坐标

确认：使用者与授权；存货人或保管人单一立场；相对方；正文、附件、仓单／入库单样张、货物清单版本；仓储物品种／数量／包装；仓库地点与储存条件；不可接受事项；法域与拟签时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的费率、数量、日期用 `【待填】`，不编造。

## 本类型硬闸

审查过程必须逐项点名，不得用买卖检验／风险或租赁维修清单代替：

1. **仓储 ≠ 保管 ≠ 租仓 ≠ 危险品仓／易腐仓**：仓储是有偿诺成的商业储存劳务。保管可无偿且常自交付成立。仅出租库房、保管人不对货损负责 → 租赁。危化／易燃易爆／剧毒 → `危险物品仓储合同·审查`。易腐需温控主给付 → `易变质物品仓储合同·审查`。
2. **仓单**：存货人交付仓储物后保管人应给付仓单、入库单等凭证。仓单是提取凭证，背书转让须保管人签名或盖章。修改句写清一物一单、记载事项、挂失／分割约定。禁止“口头入库即凭手机指令任意放货且无交接记录”。
3. **入库验收**：保管人应按约验收；验收后发现品种、数量、质量不符，保管人承担损害赔偿。未约定验收标准：必须改。存货人隐瞒危险或瑕疵：告知义务。
4. **保管义务与免责**：妥善保管，不得擅自翻倒使用。自然性质、包装不符、超过有效储存期可免责，但主张免责须证明；不可抗力走通则并须证明。禁止“任何货损概不负责”格式条款吞没。
5. **提取、逾期与留置**：逾期不提取：催告后可**提存**（不是不催告直接变卖）。仓储费未付可留置仓储物。修改句写催告期、提存或留置变价清算、留置范围。
6. **违禁品／无许可**：普通仓存放管制危化或走私货：停笔，不改成可履行。普通仓储企业无危化许可却接危化：红线转 `危险物品仓储合同·审查` 或停止。


## 起草模式

本原子只承担本类型起草。待签评改转 `普通货物仓储合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。本约是有偿诺成的普通货物储存保管劳务，不是租空库，不是危化仓或易腐仓。

1. 先按框架六步落稿：首部锁存货人／保管人与普通货性；交易条款写仓单、入库验收、保管义务；配套写提取催告后提存、欠费留置；尾部写免责须举证；正说反说后按下述必写与禁忌落句。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿。自审至少核对：是否给付仓单、验收标准是否落句、逾期提取是否先催告再提存、有无“任何货损概不负责”。输出风险表和修改句。不得只交白稿。
3. 保管、租仓、危化仓、易腐仓、动产买卖出稿、已签履约、已成争：仍负触发。

**起草必写**：保管人储存存货人交付的普通货物，存货人支付仓储费。存货人交付仓储物后保管人应给付仓单、入库单等凭证；一物一单、记载事项、背书转让须保管人签名或盖章、挂失／分割约定。保管人应按约验收；验收标准必须写明；验收后发现品种、数量、质量不符，保管人承担损害赔偿。妥善保管，不得擅自翻倒使用。自然性质、包装不符、超过有效储存期可免责，但主张免责须证明。逾期不提取：催告后可提存。仓储费未付可留置仓储物；催告期、提存或留置变价清算、留置范围必须落句。

**附件必附**：仓单或入库单样张（一物一单、记载事项、背书签章栏）；货物清单。

**禁止出现**：口头入库即凭手机指令任意放货且无交接记录；任何货损概不负责；不催告直接变卖；普通仓存放管制危化或走私货；无危化许可却接危化。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验仓储成立、仓单、入库验收、危险告知、保管义务、催告提取与提存、留置、格式条款；`search_practiced` 补审查反例；`search_template` 只借修改句结构。不虚构案件系统。

`search_law` 对法律结论为 required 级节点：不可用时不拒绝执行，只停止法律结论字段。返回已失效《合同法》仓储章、《仓储保管合同实施细则》时记为噪声，不得写入 `L#`。返回买卖检验视为合格、货交承运人风险或房屋租赁维修专属规则时，不得当作本类型默认法。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、把无许可危化或违禁品改成可入库、保证货物必然完好或仓单必然对抗第三人。
- `字段停止`：货性是否危化／易腐未核验；验收标准缺失；仓单挂失法定程序未核验；留置宽限期法定下限未核验。
- `目标停止`：主目标已变为他类型起草、履约交底或争议文书。

生存级货值或个人无限连带且用户拒绝升级：停止“可以签署”建议。
