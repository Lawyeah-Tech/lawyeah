# 边界与路由

本技能只审查 **仓储合同 / 普通货物仓储合同**。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 无偿保管、自交付成立、无商业仓储费，核心是保管并返还 | 保管合同；转引擎重新定性。不得用本方法出仓储实体结论 |
| 仅出租库房／货位，无储存保管劳务，货损自负 | `仅出租库房／货位，保管人对货损和事故不负责→` |
| 危化品、易燃易爆、剧毒、管制化学品仓储为主给付 | `危险物品仓储合同·审查`。专业版未装 P1：`unavailable`，不得用普通仓硬套 |
| 易腐、冷链、温湿度控制是主给付 | `易变质物品仓储合同·审查`。未装则 `unavailable` |
| 转移货物所有权换价款、买卖检验／风险／所有权保留主路径 | `核心给付是转移货物所有权换价款→` |
| 保税仓、海关特殊监管仓为主给付且无许可材料 | 许可字段停止或转引擎；不在本类型改可履行保税操作 |
| 有完整待签文本要评改 | `普通货物仓储合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、入库／盘点／出库留痕 | 本套导航的履约步骤 |
| 已成争（货损索赔、催告、解除、立案、仲裁） | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 危化仓或易腐仓文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。

本技能不得转去加载买卖、租赁或保管双文件完成本类型审查。危化、易腐、只租空库或卖货文本一旦构成主给付，立即负触发，不得删掉该部分后继续当普通仓储审。
