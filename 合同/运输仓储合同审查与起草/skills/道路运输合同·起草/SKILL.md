# 道路运输合同·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **运输合同 / 道路运输合同**：以道路为路径、使用机动车辆完成旅客或货物位移，且客货尚未排他拆开，或客货混写在同一份总类合同中。输出可编辑草稿和未决项，并用本类型硬闸自审后给出风险表和修改句。待签评改转 `道路运输合同·审查`。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「道路运输合同·起草」。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查、从零起草、履约交底、争议文书、合同有效性或必然无效保证、道路乘客运输专项整案、道路货物运输专项整案、一般客运或一般货运整案、铁路／航空／水路／海上／多式联运专项、劳务派遣或劳动关系整案、网络货运平台规则整案、把挂靠改成可履行结构。

## 工作边界

正触发：已有可读待签文本要评改（审查模式），或本类型条件已谈妥要出己方稿（起草模式）；尚未签署，尚未成争；核心给付是公路机动运输，**且客货尚未排他拆开**——标题或结构为道路运输总类，或同一份合同同时写载客与载货。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 已能排他识别为仅道路乘客运输（班线、包车、旅游、出租、网约载客，无货运主给付） → `道路乘客运输合同·审查`；专业版未收录时输出 `unavailable`，不得用本技能做班线／包车牌专项；
- 已能排他识别为仅道路货物运输（运单、货类、货损为主，无载客主给付） → `道路货物运输合同·审查`；
- 客运但未锁定公路机动车 → `客运合同·审查`；禁止打开其 method；
- 货运但未锁定公路机动车 → `货运合同·审查`；禁止打开其 method；
- 两种以上运输方式衔接、总承运人就全程负责 → `多式联运合同·审查`；禁止打开其 method；道路段只是其中一截时，本技能不审全程；
- 铁路主结构 → `铁路运输合同·审查`；禁止打开其 method；
- 航空／水路／海上主结构 → `航空运输合同·审查`／`水路运输合同·审查`／`海上运输合同·审查` 或其客货子类；
- 货运代理、不以自己名义承运 → `货运代理合同·审查`；禁止打开其 method；
- 深度调度、统一定价、以平台自己名义承运且道路许可已不是放行关键 → `网络货运平台模式下的运输合同·审查`；禁止打开其 method；不得按网货平台改完；
- 仅发布信息、不收运费、不以自己名义承运 → `一般信息中介平台模式下的合同·审查`；
- 长期驻场司机、用工外观主导、与劳务派遣易混 → `类派遣长期运输·审查`；禁止打开其 method；不得按劳务派遣改完；
- 出租人提供车辆甚至司机，但承租人决定线路并承担运输对象风险 → `承租人决定线路并自负运输对象风险的带驾租赁→`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问发车、运单、到站节点 → 本套导航的履约步骤；
- 已成争（货损索赔、人身伤害起诉、催告解除、立案仲裁）→ 合同争议或对应专项领域。

挂靠、用普通货车运危货、客运班线假包车、伪造许可、货运车辆载客：只出告知，不改写成可履行结构。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成。每一闸必须给出修改句或明确转出口径，禁止只打红黄绿。

1. **道路运输资质闭环**。经营性道路客运、货运原则上应取得《道路运输经营许可证》，车辆配发道路运输证或车辆营运证。许可证经营范围必须覆盖合同线路或货类，不得转让、出租许可证件。总质量 4500 千克及以下普通货运车辆从事普通货运经营的，无需申请许可证及道路运输证（已核验正文：货规 2023 第 15 条）。豁免不适用于危险货物、旅客运输；不等于无驾驶证、行驶证、保险；不改变承运人身份。总质量明显超过 4.5 吨仍主张免许可 → 红线。挂靠只告知：主体必须是许可企业，“挂靠人自负”不能对抗相对人，不改写成可履行挂靠。
2. **货损限额**。原文出现《汽车货物运输规则》《公路运输管理暂行条例》或旧大型物件办法：必须删除。货损回到民法典第 832、833 条；有保价从保价；无约定按到达地市价。不得按失效规则出赔偿结论。人身伤亡走第 823 条，禁止用一套“损坏照价、人身协商／最高赔三倍运费”打发两类风险。造成对方人身损害的免责条款不得写成有效。
3. **不得按劳务派遣或网货平台改完**。长期驻场、考勤指挥、报酬像工资 → 负触发 `类派遣长期运输·审查`。深度调度、统一定价、以平台自己名义承运且道路许可已不是放行关键 → 负触发 `网络货运平台模式下的运输合同·审查`。禁止打开上述 method。禁止把本约改写成派遣协议或网货平台规则后当作本技能完成。用户要求“改成派遣／网货就不用办道路运输证”→ 整体停止。

附加必落句（有事实则单列，无事实在缺口节说明）：

- **客货选定或分章**：仅写“道路运输合同”的，正文第一段必须选定客或货；客货一并承包的，用两个责任章或两份合同。已排他道路乘客 → `道路乘客运输合同·审查`；已排他道路货物 → `道路货物运输合同·审查`。
- **无证经营不当然无效**：行政违法另案；民事效力按民法典第 153 条与合同编通则解释第 16 条判断。不得写成“无证即合同无效”或“无证也可以放心签”。
- **保险分列**：营运客车承运人责任险、货车第三者责任险和货运险分开投保；保险人拒赔不影响承运人对相对人的赔偿。
- **转包不免责**：允许转包的，转包对象须具备同等许可；对外责任不转移。禁止“转包后本合同自动终止”。
- **超载扣车不是不可抗力**：因超载、超限被路政、治超扣车导致迟延，不得写成不可抗力。货运车辆不得载客。

必须有修改句。每个风险回链文本位置。禁止套用买卖验收、定金百分之二十或建设工程挂靠改写节点。禁止复制一般客运、一般货运、多式联运、铁路、货代、网货、派遣 method。

## 建立审查坐标

确认：使用者与授权；单方立场（承运人／许可企业、挂靠车主、旅客或包车方、托运人、收货人）；相对方；全文及车辆／许可／保险附件版本；运输对象是人、货还是混业；车辆总质量与货类；是否出现驻场用工或平台调度外观；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

## 使用 Lawyeah MCP

- `search_law`（法律结论 required）：核验道路运输资质与 4.5 吨豁免、货损第 832／833 条、客运人身第 823 条、无证民事效力、失效汽货规、挂靠对外、超载与不可抗力。

## 起草模式

本原子只承担本类型起草。待签评改转 `道路运输合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`，不编造。

本总类只在客货尚未排他拆开时出稿。已排他道路乘客或道路货物的，负触发对应子类型，不在本任务出专项终稿。

### 起草必写

- 客货选定或分章：正文第一段必须选定客或货；客货一并承包的，用两个责任章或两份合同。
- 道路运输资质闭环：经营性道路客运、货运原则上应取得《道路运输经营许可证》，车辆配发道路运输证或车辆营运证；许可证经营范围必须覆盖合同线路或货类。总质量 4500 千克及以下普通货运车辆从事普通货运经营的，无需申请许可证及道路运输证；豁免不适用于危险货物、旅客运输，不等于无驾驶证、行驶证、保险，不改变承运人身份。
- 货损回到民法典第 832、833 条；有保价从保价；无约定按到达地市价。人身伤亡走第 823 条，与货损分列。
- 无证经营不当然无效：行政违法另案；民事效力按民法典第 153 条与合同编通则解释第 16 条判断。不写“无证即合同无效”，也不写“无证也可以放心签”。
- 保险分列：营运客车承运人责任险、货车第三者责任险和货运险分开投保；保险人拒赔不影响承运人对相对人的赔偿。
- 允许转包的，转包对象须具备同等许可；对外责任不转移。

### 附件必附

- 许可证复印件、车辆清单及行驶证、保险单。
- 主张 4.5 吨豁免时：车辆合格证或登记信息及总质量事实。
- 安全管理制度目录。

### 禁止出现

- 转让、出租许可证件；“挂靠人自负”对抗相对人。
- 《汽车货物运输规则》《公路运输管理暂行条例》或旧大型物件办法。
- 一套“损坏照价、人身协商／最高赔三倍运费”打发两类风险；造成对方人身损害的免责条款写成有效。
- “转包后本合同自动终止”。
- 超载、超限被路政、治超扣车写成不可抗力；货运车辆载客。
- 改成派遣协议或网货平台规则以规避道路运输证。普通货车运危货、客运班线假包车、伪造许可：只告知，不起可履行稿。

出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造许可或倒签办证日、用普通货车运危货并改成可履行、把客运班线改成假包车发班、把挂靠改成可履行、保证合同有效或必然无效、要求按失效汽货规出赔偿结论、要求按劳务派遣或网货平台改完以规避道路运输许可。
- `字段停止`：法域未核验；客货无法判断且用户拒绝对话；车辆总质量未给出却主张 4.5 吨豁免；许可真伪或经营范围无法识别。
- `目标停止`：主目标已变为待签评改、履约交底、货损或人身伤害诉讼文书，或用户要把本约改成已排他的道路客运／道路货运专项、派遣协议或网货平台规则却拒绝转出。

生存级人身安排被一套货损限额打发且用户拒绝升级：停止“可以签署”建议。
