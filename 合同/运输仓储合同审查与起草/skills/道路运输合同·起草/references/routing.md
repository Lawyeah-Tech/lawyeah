# 边界与路由

本技能只审查 **运输合同 / 道路运输合同**。

必须同时读出：运输路径是公路、城市道路或允许行驶的路段；工具是机动客车或货车；客货尚未排他拆开，或同一份总类合同混写载客与载货。标题叫“道路运输”但已经只载客或只载货的，不得留在本技能做专项实体结论。标题叫“道路运输”但给付是驻场用工或网货平台规则的，不得按本技能改完。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或标题道路运输、核心给付明显不是公路机动运输 | 本套导航的类型切开步骤 |
| 已排他道路乘客：班线、包车、旅游、出租、网约载客，无货运主给付 | `道路乘客运输合同·审查`；专业版未收录该原子时输出 `unavailable`，不得硬套本技能做班线／包车牌专项 |
| 已排他道路货物：运单、货类、货损为主，无载客主给付 | `道路货物运输合同·审查` |
| 客运但未锁定公路机动车 | `客运合同·审查`；禁止打开其 method |
| 货运但未锁定公路机动车 | `货运合同·审查`；禁止打开其 method |
| 两种以上运输方式衔接、总承运人就全程负责 | `多式联运合同·审查`；禁止打开其 method；公路区段资质只作交接提示，不审全程 |
| 铁路主结构 | `铁路运输合同·审查`；禁止打开其 method |
| 航空／水路／海上主结构 | `航空运输合同·审查`／`水路运输合同·审查`／`海上运输合同·审查` 或其客货子类 |
| 国内或国际运输总类、未锁定道路 | `国内运输合同·审查` 或 `国际运输合同（涉外运输合同）·审查` |
| 货运代理、不以自己名义承运 | `货运代理合同·审查`；禁止打开其 method |
| 深度调度、统一定价、以平台自己名义承运且道路许可已不是放行关键 | `网络货运平台模式下的运输合同·审查`；禁止打开其 method；不得按网货平台改完 |
| 仅发布信息、不收运费 | `一般信息中介平台模式下的合同·审查` |
| 长期驻场司机、用工外观主导、与劳务派遣易混 | `类派遣长期运输·审查`；禁止打开其 method；不得按劳务派遣改完 |
| 出租人提供车辆甚至司机，承租人决定线路并承担运输对象风险 | `承租人决定线路并自负运输对象风险的带驾租赁→` |
| 有完整待签文本要评改 | `道路运输合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、问发车、运单、到站 | 本套导航的履约步骤 |
| 已成争 | 合同争议领域或对应专项；不写货损起诉状、人身伤害诉状 |
| C 端大众快检 | 只分流，不回改 |

同一文本既写“道路运输总承包”又写清只运货或只载客：按核心给付切开。只载客 → `道路乘客运输合同·审查`。只运货 → `道路货物运输合同·审查`。客货都要履约且责任章未拆 → 留本技能，先逼拆。两可且无法判断：负触发引擎，不灌两套知识。

标题是网货／平台，但正文仍是公路机动车承运、客货未拆、放行关键仍是道路许可：可留本技能走资质与货损限额闸，平台条款只作附件提示。标题是运输，正文却是驻场司机派遣：负触发 `类派遣长期运输·审查`。

挂靠、用普通货车运危货、客运班线假包车、伪造许可、货运车辆载客：停笔告知，不改写成可履行文本。

禁止在正文写半截 Skill ID。转出时必须写完整 ID，例如 `道路乘客运输合同·审查`、`道路货物运输合同·审查`、`客运合同·审查`、`网络货运平台模式下的运输合同·审查`、`类派遣长期运输·审查`。
