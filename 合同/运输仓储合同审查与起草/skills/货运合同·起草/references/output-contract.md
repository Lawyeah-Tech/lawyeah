# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受、货必无损或必然可执行；编造未给出的运费、货值、期限；把已失效《合同法》运输章、《汽车货物运输规则》写入结论；把运单写成仅供内部；把已保险写成承运人免责；把 835 写成运费概不退还；把留置扩到任何财产；把 837 写成擅自变卖；把仓储仓单/入库验收或客运改退票当成已完成的本类型审查。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查货运合同（运输合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》运输章、《汽车货物运输规则》、《国内水路货物运输规则》时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `运输合同`，子级 `货运合同`。定性理由、易混切开结果（客运、仓储、货代、多式联运、道路专项、铁路/航空/海商、网络货运）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。货代签发运单的，写明未假装切开承运责任。

## 4. 主体、许可与文本版本

主体表：托运人、承运人、实际承运人、收货人、付款名、发票名、授权签字人。许可表：道路运输经营许可或“4500 千克及以下普通货运例外”、危货许可。版本表：正文、运单样张、货物清单、危货说明书、保险单、聊天确认；冲突并列。未核许可：该经营能力字段停止。

## 5. 货物、运单、货损、运费与留置

货物是否特定化；运单是否合同组成部分；货损期间与 833 市价或保价；835 不可抗力灭失运费；836 留置是否限于本票货物；837 拒领是否走提存；829 变更时点与费用。缺口标 `G#`。不输出仓储仓单流转或客运改退票主路径。

## 6. 危货、格式条款与强制规范

828 书面说明与包装标志；826 审批文件。是否构成格式条款。强制规范只按第 153 条和解释第 16 条区分，不用失效口诀。走私/无许可危化只保留识别与停笔。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把框架里的“视同完好交付”写成丧失全部索赔权。

## 9. 谈判与签署提醒

谈判顺序：先红线（类型错位、货损概不负责、已保险即免责、运费概不退还、留置任何财产、擅自变卖、无许可危化、走私禁运），再必须改（运单记载、833、829 时点费用、830 通知提货），最后可优化。签署提醒：框架合同盖章；运单司机签字是否视为承运人接收须写授权；电子运单签章与保存期限；货物清单、危货说明书、保险单、运单样张入附件。不指导倒签或补假许可。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本原子只起草并自审，不评改对方来稿。待签评改转配对 ·审查 原子。草稿必须落入本类型三闸。不是履约交底、争议文书或效力保证，也不是仓储、客运、货代或特别法专项审查。
