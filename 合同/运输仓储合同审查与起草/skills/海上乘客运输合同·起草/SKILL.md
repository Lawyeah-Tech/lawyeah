# 海上乘客运输合同·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、失效《国内水路货物运输规则》、旧汽车货规、《海商法》第四章货物规则、民用航空法旅客责任条文，或《水路旅客运输规则》当作经海路人身条款的现行主依据。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **运输合同 / 海上乘客运输合同**，输出可编辑草稿和未决项，并用本类型硬闸自审后给出风险表和修改句。待签评改转 `海上乘客运输合同·审查`。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「海上乘客运输合同·起草」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证人身必赔、保证无证船舶可以营运。

## 本类型硬闸

1. **海上旅客运输专章**。《海商法》第五章是特别法，《民法典》客运节是一般法。核心给付是承运人以适合运送旅客的船舶，**经海路**将旅客及其行李从一港运至另一港。沿海旅客运输也走第五章；不得因为“两端都在中国港口”就改走内河规则或货物规则。不得按水路旅客或航空旅客规则改完。
2. **与货运切开**。禁止写入第四章航海过失、火灾、管货免责、货物单位限制、货物一年时效。客票背面印刷货物免责、或写“视同海上货物运输”的，整段删除。禁止打开或复制 `海上货物运输合同·审查` 的 method。
3. **与内河／水路乘客及航空乘客切开**。内河、库区、运河、合同明确只走内河航段 → `水路乘客运输合同·审查`。航空客票或“上下航空器事件” → 航空乘客原子。禁止打开或复制 `水路乘客运输合同·审查`、`客运合同·审查`、`货运合同·审查` 的 method，禁止用《水路旅客运输规则》或民用航空法替代第五章作为海路主路径。未落入客货的海上总类 → `海上运输合同·审查`。
4. **人身底板与无效条款**。免责限于法定事由，由承运人举证。禁止“风浪自负”“登船即自愿承担一切风险”“最高赔一倍票价”。免除法定责任、降低第五章限额、倒置举证责任、限制求偿权的条款无效。造成对方人身损害的免责无效。尽力救助不得排除。
5. **行李与车辆分轨**。自带行李、托运行李、随船车辆分列责任和限额。车辆轮渡：驾驶员和乘客按旅客，车辆按行李或单独保管。禁止“随身物品自理”一笔勾销。贵重物品须有交付保管和申报程序。
6. **邮轮运送段不得被旅游条款掏空**。岸上产品可分项解除；海上运送仍须适航、救助、取消／甩港退改安置。不得用“旅游产品一经售出不退”覆盖不适航或取消航次。
7. **限额现行核验与承运人身份**。港口间引用现行港口间限额规定；国际航线引用第五章计算单位。事故总额走第二百一十一条或港口间规定第四条，不得把第二百一十条吨位限制写成每名旅客限额。只可书面约定更高限额，不得手写过时数字或压到票价倍数。缔约承运人对全程负责；实际承运人可识别；挂靠、承包不能对抗旅客。许可或客船证书未核：经营能力字段停止。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签海上旅客运输正文、客票运输条件、海峡轮渡合同或邮轮运送条款，尚未签署，尚未成争，核心给付是经海路运送旅客及其行李，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 内河、库区、非经海路的渡运或班轮 → `水路乘客运输合同·审查`；
- 运送对象是货物、签发提单、管货或货损为主 → `海上货物运输合同·审查`；
- 海上运输总类未拆客货、未锁定经海路旅客运送 → `海上运输合同·审查`；
- 方式未定的一般客运，或铁路／航空／道路客票主路径 → `客运合同·审查` / `铁路运输合同·审查` / `航空运输合同·审查` / `道路乘客运输合同·审查`；
- 一般货运 → `货运合同·审查`；
- 光船出租且出租人不对旅客售票、不负责安全 → 转引擎或租赁原子，不按本类型改完；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问开航、登船、退改窗口 → 本套导航的履约步骤；
- 已催告、索赔、海事调查、诉讼或仲裁 → `或对应专项领域。` 或海事专项。

渔船、货船载客，或无客船证书仍要“改到能跑”：只出告知，不改写成可营运结构。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及客票／运输条件／邮轮合同／团体名单版本；航线是否经海路、沿海还是国际；船名、客船证书、载客定额、客运许可；人身限额或自负条款；是否写入第四章；行李与车辆是否分列；邮轮是否拆运输与岸上产品；实际承运人或挂靠；票款与退改；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 起草模式

本原子只承担本类型起草。待签评改转 `海上乘客运输合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。本约只锁以适合运送旅客的船舶经海路运送旅客及其行李，沿海旅客也走海商法第五章。

1. 先按框架六步落稿：首部锁经海路、沿海或国际、客船与许可；交易条款写客票、舱位、行李与车辆分轨、人身底板；配套写邮轮运送段与岸上产品拆分、限额双轨；尾部写索赔时限；正说反说后按下述必写与禁忌落句。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿。自审至少核对：是否写入第四章货物免责、人身免责是否越出法定事由、行李车辆是否分列、限额是否压到票价倍数。输出风险表和修改句。不得只交白稿。
3. 内河客运、海上货运、海上总类、一般客运或航空客票出稿、已签履约、已成争：仍负触发。

**起草必写**：经海路将旅客及其行李从一港运至另一港；沿海或国际锁定。免责限于法定事由，由承运人举证。自带行李、托运行李、随船车辆分列责任和限额；车辆轮渡：驾驶员和乘客按旅客，车辆按行李或单独保管；贵重物品须有交付保管和申报程序。邮轮：岸上产品可分项解除，海上运送仍须适航、救助、取消／甩港退改安置。港口间引用现行港口间限额规定，国际航线引用第五章计算单位；事故总额走第二百一十一条或港口间规定第四条。只可书面约定更高限额。缔约承运人对全程负责，实际承运人可识别。

**附件必附**：客票或运输条件；客船证书与载客定额、客运许可（未核则经营能力字段停止，不写可以营运）。

**禁止出现**：第四章航海过失、火灾、管货免责、货物单位限制、货物一年时效；视同海上货物运输；风浪自负；登船即自愿承担一切风险；最高赔一倍票价；降低第五章限额；倒置举证责任；限制求偿权；随身物品自理一笔勾销；旅游产品一经售出不退覆盖不适航或取消航次；把第二百一十条吨位限制写成每名旅客限额；挂靠、承包对抗旅客。

### 0. 签署状态与成果分流

本类型条件已谈妥、要出己方稿 → 本任务起草并自审；有完整待签文本要评改 → 配对审查原子；已签履约 → 本套导航履约步骤；已成争 → 合同争议或海事专项。未签且目标是评改已有海上旅客运输文本。评改待签文本转配对审查原子，不在本任务评改。

### 1. 类型锁死：专章与货运切开

标题、核心给付与“经海路运送旅客”一致才继续。内河客运、海上货运、海上总类、航空客票负触发。

### 2. 主体、许可、客船与实际承运人

承运人可识别；客船证书与定额；实际承运人对外不免责。

### 3. 航线、客票、舱位、行李与车辆

经海路写明；沿海或国际锁定；行李车辆分轨。

### 4. 登离船、在航、延误甩港与索赔时限

救助与适航不得排除；船舶故障不是不可抗力；时效不得改成货运一年。

### 5. 票款、退改、保险与定金

运输部分与岸上产品拆开；保险金不替代法定赔偿。

### 6. 格式条款与强制规范

无核验引文则法律结论字段停止。货物章免责、票价封顶不得改成可履行。

### 7. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、渔船货船载客可营运、货物章免责约束人身、票价封顶或风浪自负拒改。
- `字段停止`：法域、航区是否经海路、许可与客船证书、限额现行文本、国际公约接点未核验。
- `目标停止`：主目标已变为待签评改、履约交底、争议文书，或已锁他类。
