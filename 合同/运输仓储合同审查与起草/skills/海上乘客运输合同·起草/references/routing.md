# 边界与路由

本技能只审查 **运输合同 / 海上乘客运输合同** 的待签、经海路运送旅客及其行李的文本。中文展示名是「审查海上乘客运输合同（运输合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或复制 `水路乘客运输合同·审查`、`海上货物运输合同·审查`、`海上运输合同·审查`、`客运合同·审查`、`货运合同·审查` 的 method。不得按水路旅客或航空旅客规则改完本类型。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 内河、库区、运河、非经海路的渡运或班轮 | `水路乘客运输合同·审查` |
| 水路运输总类尚未落入客运或货运 | `水路运输合同·审查` |
| 运送货物、提单、管货、货损为主；写“视同海上货物运输” | `海上货物运输合同·审查` |
| 海上运输总类未拆客货、未锁定经海路旅客运送 | `海上运输合同·审查` |
| 方式未定的一般客运 | `客运合同·审查` |
| 一般货运 | `货运合同·审查` |
| 道路乘客运输 | `道路乘客运输合同·审查` |
| 铁路运输 | `铁路运输合同·审查` |
| 航空运输、上下航空器事件、航空限额 | `航空运输合同·审查` |
| 光船出租且出租人不对旅客售票、不负责安全 | 转引擎或租赁原子，不按本类型改完 |
| 有完整待签文本要评改 | `海上乘客运输合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、只问开航、登船、退改窗口 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或对应专项领域。` 或对应专项领域 |
| 海事调查、人身伤亡或行李索赔已立案 | 海事或争议专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

邮轮正文里夹带岸上观光或旅游任意解除：运送段留本类型审；旅游产品专章交接旅游合同或分条改写。用户坚持本技能把内河客运、海上货运、航空客票或海上总类整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿本类型文本来找专业版：输出 `unavailable`，提示，不得用 `水路乘客运输合同·审查`、`海上货物运输合同·审查` 或航空原子硬套。
