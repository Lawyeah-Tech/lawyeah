# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受、公约必然适用或外国裁决必然可执行；编造未给出的港口、机场、币种、限额数字；把已失效《合同法》《涉外经济合同法》、法释〔2007〕14 号或国内水路／汽车货运规则写入结论；把国内运输、一般客运、一般货运、国际航空限额本约、多式联运限额或货代文本当成已完成的本类型审查；写“排除一切国际公约即可执行”；写“人身伤害概不赔偿”；把三点境内改成可主张公约限额的国际运输；按纯国内运输或单一国际航空改完本约。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查国际运输合同（涉外运输合同）（运输合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》《涉外经济合同法》、法释〔2007〕14 号、2000 年国际航空货运规则、1997 年国际旅客行李规则或国内水路／汽车货运规则时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `运输合同`，子级 `国际运输合同（涉外运输合同）`。定性理由、易混切开结果（国内运输 / 一般客运 / 一般货运 / 国际航空限额本约 / 海运限额本约 / 多式联运限额 / 货代 / 平台）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型，未打开 `国内运输合同·审查`、`国际航空运输合同·审查`、`海上货物运输合同·审查`、`多式联运合同·审查`、`客运合同·审查`、`货运合同·审查` 的 method。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、连结点、单据与文本版本

主体表：签约名、履行名、付款名、发票名、授权签字人、境外承运人在华代理人。连结点表：出发地、约定经停地、目的地的国家与港口／机场／车站。方式表：海／空／铁／多式，不得默认航空。单据表：提单／空运单／国际货协运单／多式联运提单是否可转让、是否满足信用证。版本表：正文、单证样张、信用证、贸易术语确认、聊天确认；冲突并列。

## 5. 准据法、公约、强制规范与拆段

是否明示准据法；是否明示某公约适用或优先；国际航空强制公约是否被排除；海商法第四章与并入规则的关系；进出口、制裁、外汇、人身保护是否被外国法抹掉；国际干线与境内集疏运是否分合同；时效是否短于强制期限。缺口标 `G#`。不输出国际航空、海运或多式联运限额公式，不输出国内货运货损计价主路径。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹。排除一切公约、视为国内运输、人身伤害概不赔偿、选择外国法规避管制不得写成可放行。强制规范只按法律适用法第四条、第五条和民法典第一百五十三条区分是否导致民事行为无效，不用失效口诀。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。条款重心必须落在连结点、公约、准据法、单证和争议解决，不得改成国内货运清单，也不得改成单一国际航空限额表。

## 9. 谈判与签署提醒

谈判顺序：先红线（假国际、排除强制公约、人身伤害免责、规避管制、租约仲裁持单人拿不到文本），再必须改（准据法与公约关系、拆段、制裁责任人、时效、作准文本），最后可优化。签署提醒：中外双方全称与送达地址、境外承运人在华代理人、双语文本、单证样张、制裁合规声明。不指导倒签装船／起飞日或无单放货。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本原子只审查，不交付整份起草终稿。出己方稿转配对 ·起草 原子。不是履约交底、争议文书或效力保证，也不是国内运输、一般客运、一般货运、国际航空限额、多式联运限额或货代安排。
