## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、连结点和用户陈述定性，不用标题单独定性。名实不符时按核心给付和连结点归类，标题冲突写入 `C#`。

支持切开的规范（法律结论须运行时复核）：

- 民法典第八百零九条：运输合同是承运人将旅客或货物从起运地点运到约定地点，对方支付票款或运费。本切片在此之上再切**跨境连结点**。
- 海商法第二条第二款：第四章海上货物运输合同的规定，**不适用于**中华人民共和国港口之间的海上货物运输。
- 民用航空法（2021 修正）第一百零七条：国内航空运输指出发地点、约定经停地点和目的地点**均在**中国境内；国际航空运输指出发地点、目的地点或约定经停地点**之一不在**中国境内，无论有无间断或转运。
- 民用航空法（2021 修正）第一百零八条：几个连续航空运输承运人办理的运输被各方视为一项单一业务的，无论一份或数份合同，视为一项不可分割的运输。用于判断是否整体落入国际航空入口。
- 海上货运代理规定（2020 修正）第二条、第三条：货代与委托人可能形成代理、运输、仓储等不同关系；是否成立货代合同看法定义务、报酬名义、发票和履行，不看标题。
- 国际海运条例实施细则（2023 修正）第三条方向：无船承运业务包括以承运人身份订约、收交货、签发提单。签发自己为承运人的提单，才进入承运人责任。

## 节点 2　准据法与公约识别（硬闸）

先定适用法，再定履行步骤。本节点未闭合，不得进入货损免责句。不得先套国内市价公式，也不得先套单一航空 SDR 表。

### 2.3 责任只锁定入口，不算限额

- 国际海运数字 → 指出应转 `海上货物运输合同·审查`；
- 多式联运区段数字 → 指出应转 `多式联运合同·审查`；
- 国内货损公式套在跨境段 → 必须改，删除国内公式。

民用航空法第一百三十条：旨在免除本法承运人责任或降低赔偿责任限额的条款无效，但不影响合同其他部分。海商法第四十四条：海上货物运输合同和提单条款违反第四章的无效，其余条款效力不受影响；将货物保险利益转让给承运人的条款无效。海商法第一百二十六条：海上旅客运输免除法定责任、降低限额、倒置举证或限制索赔权的条款无效。

## 节点 3　主体、单据、信用证与连结点特定化

### 3.1 主体表

建表：签约名、履行名、付款名、发票名、授权签字人。境外承运人写明在华代理人及送达地址。名称不一致不自动合并。

核验材料是否提及：装港／卸港所在国经营资格、无船承运人备案或资格、缔约承运人与实际承运人。未提及不得写成“资格完备”，只能写 `依据不足`。

口头“我们境外总部同意了”不得写成已授权。

### 3.2 连结点必须表态

逐项：出发地、约定经停地、目的地的国家、港口／机场／车站。航空接续运输是否构成单一国际运输，必须在意见里表态。

| 文本写法 | 动作 |
| --- | --- |
| 只写“上海至海外”或“国际航线” | 必须改：国家与港站落到【待填】 |
| 主单覆盖“门到门”，境内集卡未另签 | 必须改：拆国际干线合同与境内配送合同，或专章写境内段适用中国法、不适用公约限额 |
| 鉴于写了跨境，正文三点却都在境内 | 负触发 `国内运输合同·审查` 或红线删除假国际 |

### 3.3 单据与贸易术语

单据类型：海运提单、海运单、空运单、国际铁路运单、多式联运提单。写明是否可转让、凭谁放货。

Incoterms 的交接点和风险划分只约束买卖双方，不当然减少承运人对货方的责任。修改句必须分写：贸易术语下买卖双方的交付；承运人对货方的责任仍按适用法／公约。

信用证要求的提单条款必须与运输合同一致。冲突并列 `C#`，修改句要求二者对齐，不选对用户有利的一版。

跨境无单放货：只锁定“须凭正本提单或符合约定的电放指示；无单放货的追索和管辖权成本显著高于国内”，不在本任务作出已放货结论。

### 3.4 货代切入（硬闸）

相对方只收代理费、代订舱、代报关、不签自己的承运人提单：负触发 `货运代理合同·审查`。

相对方签发自己为承运人的提单或无船承运人提单：可留在本任务审准据法／公约／仲裁并入；货代事务专章建议分合同。

## 节点 4　进出口程序、制裁、支付与保险

### 4.1 管制责任必须落到条款

许可证、报关、报检、原产地、制裁名单筛查：写清由谁办、以谁名义、延误责任。不得只写在鉴于或合规政策。

承运人通常不对申报内容的真实性负责，但明知违法仍承运的除外。发现疑似禁运品的停运权应写入。

出口管制法方向、两用物项出口管制条例第三十六条：不得为管制违法行为提供货运服务。合同写“承运人无审查义务且对一切管制后果免责”：必须改，保留合理审查与停运，删除对明知违法承运的免责。

### 4.2 支付与外汇

运费币种、汇率、到付风险、境外附加费清单。解释（一）第八条把外汇管制等金融安全列为直接适用的强制性规定。制裁或冻结导致不能付款时的替代路径可写，但普通商业不能付款不是不可抗力。

### 4.3 保险

按贸易术语确定投保义务（CIF／CIP 与 FCA／FOB 不同）。写明是否覆盖战争、罢工、拒收。不得把“货方已投保”写成承运人责任已转移。海商法第四十四条禁止把货物保险利益转让给承运人。

## 节点 5　争议解决与时效

### 5.1 仲裁或诉讼单选

法律适用法第十八条：当事人可协议选择仲裁协议适用的法律；没有选择的，适用仲裁机构所在地法律或仲裁地法律。解释（一）第十二条：没有选择仲裁协议准据法，也没有约定机构或仲裁地或约定不明的，法院可以适用中国法律认定仲裁协议效力。法释〔2017〕22 号第十三条：仅约定合同适用的法律，不能作为确认合同中仲裁条款效力适用的法律。主合同准据法与仲裁协议准据法必须分写。

2025 年修订仲裁法公布生效日为 2026-03-01。检索库若仍标“尚未施行”，记为库时效滞后，不把 2017 年文本写成唯一现行依据。第七十八条（涉外运输、海事仲裁适用专章）、第八十一条（书面约定仲裁地；程序适用法与司法管辖以仲裁地为原则）方向写入修改句，条号运行时再核。

| 文本写法 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 既仲裁又诉讼 | 必须改：单选 | 或裁或诉一定有效 |
| 货代提单并入“一切争议按租约”但持单人拿不到租约 | 红线或必须改：单独写仲裁机构、仲裁地、语言；或并入须使持单人能合理获得租约，并在提单正面明确记载租约当事人及订立日期 | 并入一句就约束持单人 |
| 诉讼条款不考虑海事法院、铁路运输法院或专门管辖 | 标红旗；修改句提示专门管辖可能，不选定唯一法院充作法律意见 | 普通法院一定有管辖权 |
| 未评估境外判决／裁决在中国承认执行和保全可行性 | 必须改：补仲裁地／法院地与财产所在地匹配说明；执行可能标 `G#` | 外国裁决必然可在中国执行 |

海事强制令不受诉讼管辖协议或仲裁协议约束（海事诉讼特别程序法第五十三条方向）：保全地可另写，不与仲裁条款互相否定。

### 5.2 时效不得短于强制期限

海商法第二百五十七条方向：海上货物运输向承运人索赔时效一年，自交付或应当交付之日起；追偿九十日。检索返回“已被修改”，条号不写入 `L#`，但合同把索赔期改成三十日且逾期弃权：必须改，改为“不低于适用法或强制公约规定的异议期和诉讼时效”。不得把沿海、内河一年时效批复套到跨境国际段当唯一依据。

民用航空法第一百三十五条：航空运输诉讼时效二年，自到达、应当到达或运输终止之日起。合同写“七日不提视为无索赔”：必须改。

公约书面异议期优先于合同自拟期限。本任务不代算起算日是否已经届满。

## 节点 6　格式条款、语言与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 高风险词

| 用语 | 动作 |
| --- | --- |
| “排除一切国际公约” | 红线。国际航空等情形做不到 |
| “承运人可随时单方变更适用法” | 红线 |
| “视为国内运输” | 红线。连结点跨境不能用约定抹掉公约 |
| “按国际惯例”且未指明规则 | 必须改 |
| “人身伤害概不赔偿” | 红线。第五百零六条；旅客运输另受特别法强制保护 |
| 英文免责架空中文强制保护 | 必须改：作准文本规则须规定涉及人身、安全、强制责任时以保护力更高的文本解释 |

### 6.2 格式条款

民法典第四百九十六条、第一百五十三条。承运人单方格式选择“承运人所在国法＋排除公约＋外国仲裁”：相对方立场要求加黑提示、单独确认或删除；提供方立场评估不成为合同内容的风险。勾选弹窗不当然等于已尽提示。强制规范不一律导致整约无效，不用失效“效力性／管理性”口诀。

### 6.3 双语与尾部

跨境电子签署的效力约定；是否需要双语文本。中英文不一致时以哪一文本为准。涉及中国强制规范的，中文文本不得被英文免责条款架空。附件可附公约摘录、运输条件、单证样张、制裁合规声明，不得夹带失效国内运输规则。

- `红线`：不改则建议不签或整体停止（假国际、排除强制公约、人身伤害免责、规避管制、明知禁运仍承运、持单人无法获得的租约仲裁拒改）；
