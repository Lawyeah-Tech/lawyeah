# 边界与路由

本技能只审查 **运输合同 / 国际运输合同（涉外运输合同）** 的待签、连结点跨境或具有涉外因素的运输主文件。中文展示名是「审查国际运输合同（涉外运输合同）（运输合同）」。审查重心是准据法、公约、单证与争议解决，不是货损或伤亡限额公式，也不是纯国内运输或单一国际航空专档。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或复制 `国内运输合同·审查`、`国际航空运输合同·审查`、`海上货物运输合同·审查`、`多式联运合同·审查`、`客运合同·审查`、`货运合同·审查` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 出发地、约定经停地、目的地均在中国境内；国际货的国内集港或国内派送单独签约 | `国内运输合同·审查` |
| 未跨境的一般客运本约 | `客运合同·审查` |
| 未跨境的一般货运本约 | `货运合同·审查` |
| 主目标是多式联运网状责任、区段限额或“哪一段按哪部方式法赔多少” | `多式联运合同·审查` |
| 主目标是国际航空货损、旅客伤亡限额、SDR 或华沙／蒙特利尔责任限额计算 | `国际航空运输合同·审查` |
| 国内航空（三点均在境内的航空运输） | `国内航空运输合同·审查` |
| 未区分国内／国际的一般航空运输本约 | `航空运输合同·审查` |
| 主目标是国际海上货物运输责任基础、单位责任限额或海牙／维斯比式公式 | `海上货物运输合同·审查` |
| 海上或水路旅客运输本约 | `海上乘客运输合同·审查` 或 `水路乘客运输合同·审查` |
| 海上运输未拆国际／国内、未拆货／客 | `海上运输合同·审查` |
| 只代办订舱、报关、单证，不签发自己为承运人的提单／运单 | `货运代理合同·审查` |
| 网络货运平台模式下的运输 | `网络货运平台模式下的运输合同·审查` |
| 一般信息中介平台撮合运力 | `一般信息中介平台模式下的合同·审查` |
| 铁路运输本约（国内铁路区段责任） | `铁路运输合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `国际运输合同（涉外运输合同）·起草` |
| 已签未争、只问履约节点、放货日、滞港费 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或对应专项领域。` 或对应专项领域 |
| 货损索赔、无单放货、海事保全、海关或出口管制已立案 | 海事海商、涉外贸易或争议专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

国际运输正文里夹带一小段国内派送或货代订舱：专章交接对应原子或建议分合同；跨境干线的准据法／公约条款可继续审。用户坚持本技能把国内运输、一般客运、一般货运、国际航空限额本约、海运限额本约、多式联运限额本约或货代整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
