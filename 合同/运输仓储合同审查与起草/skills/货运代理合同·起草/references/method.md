## 节点 1　身份三角（硬闸 1）：委托 / 中介 / 承运

### 1.1 本类型默认定性

货运代理合同的默认法律性质是《民法典》委托合同：委托人与货代约定，由货代处理货物运输及相关事务（订舱、报关、报检、拖车、仓储、单证、保险代办），委托人支付代理费。核心给付是**处理事务**，不是把货运到目的地。有偿委托因过错致损，委托人可请求赔偿（第 919、929 条）。

用户口头说“委托/中介”时，先切开三种外观，禁止用口语“中介”把货代审成纯信息撮合，也禁止用标题“代理”把承运审成过错责任。

| 外观 | 规范入口 | 本任务动作 |
| --- | --- | --- |
| 代为订舱、报关、对外缔约或转交承运人单证，对价是代理费或代垫实报实销，不以自己名义签发承运人单据 | 第 919、929 条；海上货运代理规定第 2、3 条 | 正触发。本类型 |
| 只报告车源/舱位机会或提供媒介，不代订舱、不收运费、不开运费发票、不对外缔约 | 第 961、962 条 | 负触发 `一般信息中介平台模式下的合同·审查`。P1 未装则 `unavailable`。不得改走房屋中介 `房屋买卖或租赁中介→` |
| 承诺运达、自己调度运力、收全程运费、掌管期间货损自负 | 第 809、832 条 | 负触发对应承运原子；本技能仍须写出“这已不是货代”的识别句 |
| 标题代理，但以自己名义签提单/运单，或 as agent 无授权 | 海上货运代理规定第 4 条识别规则 | **留下本技能**。进入节点 2。不假装已切开 |

支持切开的规范（法律结论须运行时复核）：

- 第 919 条：委托是处理委托人事务。
- 第 929 条：有偿委托因受托人过错致损可请求赔偿。
- 第 961 条：中介是报告订约机会或提供媒介服务。
- 第 809 条：运输合同是承运人将货物运到约定地点，对方支付运输费用。
- 第 832 条：承运人对运输过程货损负责（例外自证）。只在身份转换后点名交接，不在本技能展开限额。
- 海上货运代理规定第 2 条：因处理货代事务形成代理、运输、仓储等不同关系的，分别适用。
- 同上第 3 条：综合书面权利义务、报酬名义和方式、发票种类、交易习惯认定关系。

国内道路运单、航空货运单比照第 4 条识别方法处理外观，不得把失效汽货规第 72 条写入 `L#`。

### 1.2 加载协议

本技能已锁定 **运输合同 / 货运代理合同**。只打开 `references/基本面.md` 与 `references/框架.md`。禁止读其他子目录，禁止为对照再开承运、网络货运或信息中介 method。

### 1.3 委托 vs 承运（硬闸 1 主轴）

| 文本写法 | 本任务动作 | 修改句方向 |
| --- | --- | --- |
| 乙方按指示代为订舱/报关/转交承运人提单，不以承运人身份签发运输单证，对价为代理费 | 正触发 | 首部写明“货运代理人，核心给付是处理运输事务，不构成运输合同” |
| “负责运至……”“门到门责任”“安全运达并赔偿一切货损”且无“代为安排” | 按承运承诺 | 改为“代为安排运输”并删除运达保证；用户坚持运达保证则接受承运人责任，交接对应承运原子 |
| 自己调度车辆或舱位、对托运人承诺运到时限、收取全程运费 | 整体识别为缔约承运人 | 负触发 `道路货物运输合同·审查` / `海上货物运输合同·审查` 等对应承运原子；本技能仍输出身份转换句 |
| 鉴于写“货代不承担任何运输责任”，附件却授权签发提单 | 版本冲突；按签单外观 | 删除自相矛盾；二选一 |

最强反方：相对方主张标题已写代理，货损只按过错赔。签单外观或运达承诺与标题冲突时，现有依据不支持把标题单独写成已切开。

修改句（纯代理锁定）：

「乙方仅作为甲方的货运代理人，处理本合同及每票《委托书》列明的订舱、报关、单证及代垫事务。乙方的法律地位是受托人，不是承运人，也不是仅提供订约机会的中介人。乙方不以承运人身份签发提单、运单或其他运输单证，不承诺货物运达时限，不对运输期间货物毁损、灭失承担承运人责任。乙方因过错给甲方造成损失的，按民法典委托合同规则承担相应赔偿责任。」

### 1.4 委托 vs 纯中介

货代通常以委托人名义或自己名义对外缔约，核心是办事，不是只撮合。只抽佣、不代订舱、不开运费发票、不持有单证的，才走中介合同。不得把“货运代理”四个字改成“信息中介”来逃避过错责任，也不得把纯信息平台按本类型改完。

### 1.6 走私 / 骗税 / 夹藏 / 出借资质停笔

出现为走私、骗取出口退税提供代理，夹藏、伪报品名，出借国际货代备案或无船承运单证，或把无单放货写成履约安排：

1. 告知可能因违法或违背公序良俗无效（第 153、154 条）；备案办法第 13 条禁止出借、转让《备案表》。
2. 不写可履行的伪报路径、假品名、套汇或无单放货结构。
3. 风险表只保留识别依据和删除/转出口径。
4. 用户坚持“改到能签且仍做这些事”：整体停止。

## 节点 2　无船承运 / 自己名义签单（硬闸 2）

本节点是本类型与承运原子的切开点。标题写“代理”、正文写“只是代理，货损概不负责”，**不得假装已经交到承运技能审完**。必须先在本技能落身份转换句。

### 2.1 签单外观

支持依据：海上货运代理规定第 4 条识别规则（2020 文本运行时复核）；国际海运条例实施细则（2023 修正）第 3 条第（四）项（无船承运业务：以承运人身份订约、签单、收运费）。国际海运条例 2001 年第 7 条文本标注“已被修改”，不得写入 `L#`。2023 修订本对应条号本次未返回全文，运行时复核后再写条例条号。

| 文本写法 | 动作 |
| --- | --- |
| 禁止签发 House B/L / 自己的运单，签单样本为承运人提单且显示委托人或实际承运人 | 可保留纯代理 |
| 授权或事实上签发 House B/L、货代运单，抬头是货代 | 必须改：明示“作为承运人”，责任条款切换为运输合同；代理限额不再覆盖该票货损 |
| “视为承运人代理人”却不显示被代理人、不能证明授权 | 等于自己承运。修改句要求显示被代理人并附授权，否则按承运人责任 |
| “只是代理，货损概不负责”同时保留签单权 | 红线。不得假装已切开到承运原子 |
| 无签单样本 | 字段停止；修改句要求签单样本作为附件且与身份条款一致 |

House B/L 与 Master B/L 必须写清：纯代理应转交承运人提单或披露实际承运人；只给货主一张货代提单且不披露船东提单的，按缔约承运人处理。

修改句（身份转换，二选一，禁止含糊）：

「乙方不以承运人身份签发提单、海运单、道路运单或其他运输单证。一旦乙方以自己名义签发上述单证，或以承运人代理人名义签发但不能证明已取得该承运人书面授权，则就该票货物承担承运人责任，不得再主张仅负货运代理过错责任；该票代理责任限额自动失效。选择作为承运人（含无船承运）的，应在委托书上勾选“作为承运人”，披露无船承运业务备案情况，并投保与货值匹配的承运人责任保险，保险条件见附件【待填】。」

用户坚持“继续签自己的运单，同时写货损概不负责”：整体停止，不改成可履行免责。

承运责任的保价、单位限额、掌管期间计算不在本技能展开；交接对应承运原子，本技能只锁转换条件。

### 2.2 无船承运是承运人，不是货代外衣

无船承运业务的法定外观：以承运人身份与托运人订国际货物运输合同、接收和交付货物、签发提单或其他运输单证、收取运费（2023 细则第 3 条第（四）项）。在中国境内承揽货物、签发提单或其他运输单证、收取运费的，须办理无船承运业务备案（2023 细则第 10 条）。经营无船承运业务，应自开业之日起 15 日内向注册所在地或业务主要发生地省级交通运输主管部门备案（2023 修改决定新增第 9 条）。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 合同授权签发自己的提单，但声称“仍是货代、只负过错” | 按硬闸 2 改定性 | 签了 House 单仍只是代理 |
| 无船承运备案未出示 | 字段停止；修改句要求作为附件 | 可以签单展业；合同当然无效 |
| 货代代未登记无船承运人签单 | 提示第 12 条连带风险；选任未登记无船承运人有第 11 条谨慎义务 | 代签即免责 |
| 国内纯代理、不签自己的运输单证 | 不编造无船承运许可要求 | 国内订舱代理必须有无船承运备案 |

承运段限额、海牙/汉堡规则、海商法第四章不在本技能展开。

修改句：

## 节点 4　委托事项、指示与签单样本

### 4.1 事务必须逐项勾选

审查清单，缺一项则该字段不得写成已闭环：

1. 订舱、报关报检、内装、拖车、仓储、保险代办、签发/转交提单、目的港换单，逐项勾选。
2. 货类、口岸、是否危货/冷链/管制物。禁止流通物不能“代为通关”。
3. 最迟指示时点；倒签、预借、改单、电放必须书面。货代无书面指示不得操作（第 922 条：变更指示须经同意）。
4. 信用证或单证一致性要求，如有。

禁止只写“提供全程物流服务”或“门到门”而无代为安排的限定。

修改句：

「委托事项以每票《委托书》勾选为准，可包括：订舱、报关、报检、拖车、仓储、代办保险、转交承运人单证、目的港换单。未勾选事项乙方无权实施。出现“负责运至【目的地】”且未写明“代为安排”的，视为承运承诺，适用身份转换条款。倒签、预借、改港、电放须有甲方书面指示；无书面指示不得操作。」

### 4.2 名义与签单样本

| 文本写法 | 动作 |
| --- | --- |
| 以委托人名义订舱，取得承运人提单，提单托运人为货主或依指示 | 代理属性强。实务上第三人提单记载托运人为货主，可支持代理外观，但不写成必然结果 |
| 签发 House B/L 且未显示仅作为代理 | 交易对象已变成运输服务；走硬闸 2 |
| 无签单样本，或样本 as carrier 与正文“仅代理”冲突 | 必须改样本或改正文，冲突并列 |

## 节点 5　费用：代理费、代垫、包干差价

支持依据：第 921 条；海上货运代理规定第 3 条（报酬名义、发票种类）；第 9 条（概括委托可请求合理费用）。

| 文本写法 | 动作 |
| --- | --- |
| 代理费单独开票；代垫运费凭承运人账单实报实销 | 代理属性强 |
| 只给一张包干报价，不披露是否包含承运人运费，不开承运人发票 | 必须改。吃差价却主张过错责任：现有依据不支持 |
| 商业上必须吃差价 | 同时接受承运人责任和相应保险，不得再主张纯代理限额 |
| 费用项目混写、发票名与签约名不一致 | 分列代理费 / 代垫 / 包干；名称不一致不自动合并 |

修改句：

「甲方应向乙方支付的报酬为货运代理费人民币【待填】元/票（或按附件费率），乙方就该代理费单独开具发票。代垫的承运人运费、港杂及报关规费凭实际承运人或主管机关账单实报实销，乙方应向甲方转交对应发票或费用清单。采用包干费且乙方不向甲方披露实际承运人名称及承运人运费的，就该票货物按承运人承担责任，不适用纯代理过错责任和代理责任限额。」

禁止编造费率。包干费只是商业安排，不是已锁定的法定身份。

## 节点 6　转委托、扣单与时效协助

### 6.1 转委托

支持依据：第 923 条；海上货运代理规定第 5 条（2012 本全文已核，2020 文本运行时复核）。

未约定转委托权限的，不得仅以委托人“知道而未反对”写成已同意，除非委托人行为明确接受。转委托后货代对选任和指示负责。实际承运人、报关行、车队应向委托人披露；隐名处理适用第 925、926 条，但签出自己为承运人的提单后，不得再向货主主张只是代理人。

### 6.2 扣单范围（不得扩到运输单证）

支持依据：海上货运代理规定（2020 修正）第 7 条、第 8 条。

第 7 条：约定以支付费用为交单条件的，未付费可拒交单证；未约定或约定不明时，未付费可拒交，但提单、海运单或其他运输单证除外。第 8 条：同时接受契约托运人订舱与实际托运人交货的，实际托运人请求交付其取得的运输单证，应予支持。

| 文本写法 | 动作 |
| --- | --- |
| 未付代理费可扣留报关底单、费用清单，且合同有明确约定 | 可保留，但范围仅限因本委托产生的费用对应的非运输单证 |
| 未付费即可扣留提单、海运单、道路运单或其他运输单证 | 必须改 |
| 扣留与本票无关的核销、退税资料，或扣留其他客户货物 | 红线删除 |

修改句：

「甲方未支付因本票委托产生的到期代理费或代垫费用的，乙方可暂缓交付与该费用直接对应的报关底单、费用清单，但不得扣留提单、海运单、运单或其他运输单证，不得扣留与本票无关的退税、核销资料，也不得扣留其他票货物或单证。合法暂缓交付前应书面催告，宽限期不少于【待填】日。」

实务材料称货代扣单多被当作同时履行抗辩而非留置权，不得把承运人货物留置权（第 836 条口径）直接写给纯代理人。该口径只作审查反例，非法源。

### 6.3 时效协助

货代作为代理人时，应及时转交货损通知、索赔文件并告知已知时效。因迟延转达致委托人超时效的，按过错承担相应损失，不当然按货损全额赔付。不得写成“货代对货损概不负责且无转达义务”。

修改句：

「乙方收到承运人、保险人、口岸或目的港代理关于货损、灭失、迟延或索赔时限的通知后，应在【待填】小时内书面转达甲方。因乙方迟延转达导致甲方超过向承运人或保险人索赔的时效或除斥期间的，乙方按过错承担甲方因此未能获偿的相应损失，但甲方不能证明通知已到达乙方的除外。本条不使乙方当然按承运人就货损全额赔付。」

## 节点 7　格式条款、强制规范、违约与争议

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 7.1 格式条款

为重复使用而预先拟定、订立时未与对方协商（第 496 条）。依据示范文本制作，不当然排除格式条款。解释第 10 条：须有足以引起注意的标识；仅有网络勾选或弹窗，现有依据不支持写成已尽提示或说明义务；提供方对已尽提示或说明承担举证责任。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在费率表背面 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |
| “一切损失概不负责”“货损概不赔偿” | 作为格式条款，现有依据支持按第 497 条检视；人身损害及故意/重大过失免责无效（第 506 条） |

### 7.2 强制规范

违反法律、行政法规强制性规定不一律无效（第 153 条；解释第 16 条）。禁止用已失效“效力性/管理性”口诀。国际货代未备案、无船承运未备案主要是监管后果。走私、骗税、出借单证、无单放货安排：不改写成有效履行。

纯代理人不得写入承运人法定免责（航海过失等）。被认定为承运人后，代理限额自动失效；承运免责与限额交承运原子。

### 7.3 违约、解除、争议

1. 货代订不到舱、选任不合格次受托人、擅自签单、迟延交单：可约定减酬、解除、赔偿直接损失。只有“依法承担违约责任”视为必须改。
2. 委托人取消订舱：可约定已发生费用和亏舱费转嫁，数字用 `【待填】`；货代无法订到舱位须在【待填】小时内通知并给替代方案，“尽力订舱”不得单独放行。
3. 有偿委托解除适用第 933 条：解除方应赔偿对方直接损失和合同履行后可以获得的利益。不得写成“随时解除且无需付费”，也不得把第 933 条写成货代可随意甩柜而不承担责任。
4. 违约金不是必得金额。修改句避免“不得调整”或“按货值 30% 必得”。
5. 争议解决：与可能出现的运输纠纷管辖分开写，避免货主告承运人时被代理合同的约定管辖绊住。或裁或诉、机构不明：标待核。海事专门管辖可能：只标红旗，不选定唯一法院充作法律意见。
6. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。
