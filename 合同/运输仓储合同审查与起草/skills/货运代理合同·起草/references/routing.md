# 边界与路由

本技能只审查 **运输合同 / 货运代理合同** 的待签文本。中文展示名是「审查货运代理合同（运输合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。签单混写或无船承运外观不得因转出而假装承运责任已审完。禁止打开 `多式联运合同·审查`、`道路运输合同·审查`、`网络货运平台模式下的运输合同·审查`、`一般信息中介平台模式下的合同·审查`、`客运合同·审查`、`货运合同·审查` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 核心给付是承运位移、收运费、掌管期间货损自负，无代理事务主轴 | 道路特别法主路径 `道路货物运输合同·审查`；铁路 `铁路运输合同·审查`；航空 `航空运输合同·审查`；海上货物/提单限额 `海上货物运输合同·审查` |
| 标题代理，但以自己名义签发运单/提单，或 as agent 无授权，或无船承运外观 | **不转出装切开**。本技能落身份转换句；承运段交接对应承运原子 |
| 网络货运经营者、无车承运平台、入驻规则、平台统一定价调度 | `网络货运平台模式下的运输合同·审查`。P1：专业版未装则 `unavailable`，提示，不得用本技能硬套，也不得改名货代规避承运人责任 |
| 只撮合车源/舱位信息，不代订舱、不收运费、不开运费发票 | `一般信息中介平台模式下的合同·审查`。P1；未装则 `unavailable`。不得改走房屋中介 `房屋买卖或租赁中介→` |
| 两种以上运输方式，经营人签发多式联运单据并对全程负责 | `多式联运合同·审查`。P1；未装则 `unavailable` |
| 只储存保管、出具仓单、不对位移负责 | `普通货物仓储合同·审查` |
| 旅客、客票、人身伤亡 | `客运合同·审查` |
| 无运输事务的概括委托 | `无运输事务的一般委托贸易行纪→` |
| 以自己名义买入再转卖货物 | `以自己名义买入再转卖货物` |
| 有完整待签文本要评改 | `货运代理合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、只问订舱/交单/代垫节点 | 本套导航的履约步骤 |
| 已成争，或用户要货损、无单放货诉讼策略 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

货代正文里夹带一小段仓储暂存或短驳：仍先按代理事务审；独立计价且以保管为主的仓储专条可交接 `普通货物仓储合同·审查`。用户坚持本技能把承运全程、网络货运平台或信息中介整案改完：`目标停止`。
