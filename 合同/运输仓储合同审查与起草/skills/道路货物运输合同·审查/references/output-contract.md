# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受、货必无损或必然可执行；编造未给出的运费、货值、车辆总质量、许可文号；把已失效《合同法》运输章、《汽车货物运输规则》写入结论；把一般货运原子当道路特别法全部；要求所有货车必须有道路运输证，或未核总质量就默认 4.5 吨豁免；把已保险写成承运人免责；把留置扩到任何财产；把拒领写成擅自变卖；把挂靠或违法超载改成可履行结构。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查道路货物运输合同（运输合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》运输章、《汽车货物运输规则》、1997 年《道路货物运单使用和管理办法》、2004 年未经 2019／2023 修订的《道路运输条例》文本时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `运输合同`，子级 `道路货物运输合同`。定性理由、易混切开结果（一般货运、货代、网络货运平台、客运、仓储、多式联运、铁路／航空／海商）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。货代签发道路运单的，写明未假装切开承运责任。来稿若只是一般货运，写明已转 `货运合同·审查`，不得继续用本技能十节充数。

## 4. 主体、道路运输经营许可与文本版本

主体表：托运人、承运人、实际承运人、收货人、付款名、发票名、授权签字人。许可表：货类（普通／专用／大件／危货）、《道路运输经营许可证》范围、车辆《道路运输证》、车辆总质量是否落入 4500 千克普通货运豁免、危货许可与从业资格。版本表：正文、道路运单样张、货物清单、危货说明书、保险单、聊天确认；冲突并列。未核许可或未核总质量：该经营能力字段停止，不写“可以经营”，也不写“已豁免”。

## 5. 车辆、超限、运单、货损与放货

车型与货类是否匹配；超限超载约定能否对抗行政处罚；冷链温度与记录仪；道路运单是否合同组成部分；货损期间与 833 市价或保价；是否引用失效汽车货规；835 不可抗力灭失运费；836 留置是否限于本票货物；无单放货规则；829 变更时点与费用。缺口标 `G#`。不输出一般货运“无特别法主路径”、货代佣金或仓单流转主路径。

## 6. 危货、格式条款与强制规范

道路危货许可、从业资格、第 828 条书面说明与包装标志、限运凭证查验。是否构成格式条款。强制规范只按第 153 条和解释第 16 条区分：无许可不当然导致合同无效，但不得把无许可危化或挂靠改成可履行。走私／无许可危化／违法超载／出借许可证只保留识别与停笔。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字和许可文号用 `【待填】`。必须出现道路运输经营许可或 4.5 吨豁免事实句，不得只复述一般货运 832／835／836。不得把框架里的“视同完好交付”写成丧失全部索赔权。

## 9. 谈判与签署提醒

谈判顺序：先红线（类型错位到一般货运或货代、无许可危货当普货、挂靠出借许可证、约定违法超载、货损概不负责、已保险即免责、引用失效汽车货规拒删、走私禁运），再必须改（许可范围与车辆总质量、运单效力、833、超限责任内部分配、829 时点费用、无单放货凭证），最后可优化。签署提醒：框架合同盖章；许可复印件或 4.5 吨车辆行驶证总质量页入附件；运单司机签字是否视为承运人接收须写授权；电子运单签章与保存期限；货物清单、危货说明书、保险单、运单样张入附件。不指导倒签或补假许可。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本原子只审查，不交付整份起草终稿。出己方稿转配对 ·起草 原子。不是履约交底、争议文书或效力保证，也不是一般货运、货代、网络货运平台或铁路／航空／海商专项审查。
