# 道路货物运输合同·审查

## 任务目标

在单一立场下，只审查 **运输合同 / 道路货物运输合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。中文名必须是「道路货物运输合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、在途履约交底、货损争议文书、有效性或货必无损保证、把一般货运或货代文本改成可履行道路专项。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。道路特别法是本技能主路径，民法典货运节只作一般法底板，禁止把一般货运七闸原样粘贴后换标题交差。

1. **道路货物专项 ≠ 一般货运 ≠ 货代 ≠ 网络货运平台**：核心给付是承运人使用机动车经道路完成公路货移与完好交付，且来稿以道路运输经营许可、车辆道路运输证、货类与许可范围、路政超限或道路危货资质为主路径。标题只写“货运/物流”但通篇不出现道路运政、车辆营运证、治超或危货道路许可的，转 `货运合同·审查`。只撮合车源、不签发以自己为承运人的道路运单、不收运费 → `货运代理合同·审查`。网络货运平台入驻、无车承运人平台规则为主路径 → `网络货运平台模式下的运输合同·审查`。货代以自己名义签发道路运单并收取运费的，按本类型承运人审，**不得假装已经切开**。
2. **道路运输经营许可（本技能第一硬闸）**：经营性道路货运原则上应有《道路运输经营许可证》和车辆《道路运输证》，并按许可证核定范围经营（普通货运、专用货运、大型物件、危险货物）。使用**总质量 4500 千克及以下普通货运车辆**从事**普通货运**经营的，无需申请上述两证；该豁免不适用于危险货物、客运，也不等于可以无驾驶证、行驶证和保险。禁止写成“所有货车必须有道路运输证”，也禁止在未核车辆总质量时默认已豁免。无应许可而未许可：合同不当然无效，经营能力字段停止，不写“可以经营”。不得转让、出租许可证件。
3. **货类、车辆与超限超载**：货类决定许可和车型。冷链须有温度区间和记录装置。超限超载受公路安全保护条例和《超限运输车辆行驶公路管理规定》约束；约定“可以超载运输／罚款由对方包干即放行”不能对抗行政处罚，事故责任加重。任何单位不得指使、强令驾驶人违法超限。
4. **道路运单是合同组成部分**：运单记载货物状况、收货人、运费，是合同组成部分。禁止“运单仅供内部结算、不作为合同”。未签正式合同但已签发道路运单并接收货物的，合同成立。框架合同与运单冲突必须选定规则。
5. **删除失效汽车货规；货损按掌管期间与到达地市价**：禁止引用已失效《汽车货物运输规则》作赔偿、时效或批注依据。道路普通货运无法定单位责任限额，按到达地市场价格赔实际损失。格式“货损概不负责／已保险即免责／只赔运费 N 倍”必须改。第 831 条未异议只是初步证据，不得写成丧失全部索赔权。
6. **危货道路许可、从业资格与书面说明**：未取得道路危险货物运输许可不得承运危货；4.5 吨豁免不扩到危货。托运人须书面说明品名、数量、危害、应急措施并包装标志。危货当普货、匿报危货、走私或禁运：红线或停笔。危货车辆禁止挂靠经营。
7. **挂靠／无资质过车／无单放货**：挂靠、出借资质、擅自过车给无相应许可车辆，只出告知，不改写成可履行结构。缔约承运人不得以“已外派司机”免责。必须凭约定凭证放货。留置仅限相应运输货物；拒领走提存；交付前变更须保留并写费用。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签道路货物运输正文，尚未签署，尚未成争，核心给付是机动车公路货移与完好交付，且道路运政许可、车辆道路运输证、货类许可范围、路政超限或道路危货资质构成审查主路径；用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 通篇只走民法典货运节、无道路运政许可／车辆营运证／治超／道路危货资质主路径 → `货运合同·审查`；
- 只撮合车源或订舱、不承运、不以自己名义签发道路运单 → `货运代理合同·审查`；专业版未装则 `unavailable`。纯报告订约机会也可交 `房屋买卖或租赁中介→`；
- 网络货运平台入驻规则、无车承运人平台规则是主路径 → `网络货运平台模式下的运输合同·审查`；未装则 `unavailable`；
- 对象是旅客、客票、改退签、人身伤亡主路径 → `客运合同·审查`；
- 两种以上不同运输方式且由经营人负责全程 → `多式联运合同·审查`；未装则 `unavailable`；
- 只储存保管、不负责位移 → `普通货物仓储合同·审查`；
- 铁路运单、铁路保价与限额是主路径 → `铁路运输合同·审查`；未装则 `unavailable`；
- 航空货运单、声明价值、民用航空法限额是主路径 → `航空运输合同·审查`；未装则 `unavailable`；
- 提单、海牙/海商法单位责任限制是主路径 → `海上货物运输合同·审查`；未装则 `unavailable`；
- 无文本、本类型条件已谈妥、要出己方稿 → `道路货物运输合同·起草`；
- 已签只问发运、在途、签收留痕 → 本套导航的履约步骤；
- 已催告、货损索赔、解除、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

走私、禁运、无许可危化当普通货、挂靠出借资质、约定违法超载：只出告知，不改写成可履行承运结构。

## 建立审查坐标

确认：使用者与授权；单方立场（托运人侧或承运人侧择一）；相对方；全文及道路运单／货物清单版本；核心给付是公路承运还是撮合／平台／一般货运；货类属于普通／专用／大件／危货哪一类；车辆总质量是否可能落入 4500 千克豁免；道路运输经营许可证与车辆道路运输证痕迹；是否超限超载或需通行证；冷链温度安排；是否危货及从业资格；运费预付或到付；货损限额或保价；留置范围；变更与放货凭证；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的运费、货值、车辆总质量、许可文号用 `【待填】`，不编造。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `道路货物运输合同·起草`；已签履约 → 本套导航履约步骤；已成争货损索赔 → 合同争议。未签且目标是评改已有道路货物运输文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与道路特别法主路径一致才继续。一般货运、只撮合货代、网络货运平台、客运、仓储、多式联运、铁路／航空／海商负触发。货代签发道路运单的，留下承运责任审查。

### 2. 道路运输经营许可

货类与许可证范围、车辆道路运输证、4500 千克豁免的车辆总质量事实分列。未核许可：字段停止。不得默认全部豁免，也不得要求全部持证。

### 3. 车辆、超限、冷链与路线

车型匹配货类。超限约定不能对抗行政处罚。冷链温度与记录仪。限行、通行证、进市区证件的办理义务。

### 4. 道路运单、货损与失效货规

运单是组成部分。删除《汽车货物运输规则》。掌管期间归责；833 市价；已保险不免责。

### 5. 危货许可与从业资格

无道路危货许可当普货：红线。书面说明、包装标志、押运与从业资格。4.5 吨豁免不扩危货。

### 6. 挂靠、过车、无单放货、835／836／829

挂靠和违法过车停笔告知。凭约定凭证放货。灭失运费返还、本票留置、交付前变更须落句。

### 7. 格式条款与强制规范

无核验引文则法律结论字段停止。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证货必无损、把走私／禁运或无许可危化改成可承运、把挂靠或出借许可证改成可履行、约定违法超载仍要放行、坚持货损概不负责／运费概不退还／留置任何财产／擅自变卖。
- `字段停止`：法域、车辆总质量、许可文号、危货属性、超限许可窗口未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类（含一般货运、货代、网络货运平台）。

生存级货值或个人无限连带且用户拒绝升级：停止“可以签署”建议。
