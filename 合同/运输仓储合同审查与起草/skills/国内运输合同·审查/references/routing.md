# 边界与路由

本技能只审查 **运输合同 / 国内运输合同**。中文成果名称必须是「审查国内运输合同（运输合同）」。

负触发只输出 `触发判定：负触发，未启动本任务`、路由全 ID 和最小交接，不填十节实体结论。禁止半截 ID。禁止打开邻类 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 起运、约定经停或目的任一在境外，或本合同一并负责境外段 | `国际运输合同（涉外运输合同）·审查` |
| 国际航空连结点（出发、目的或约定经停之一在境外） | `国际航空运输合同·审查` |
| 用户锁定公路且只要营运细则、无切片争点 | `道路运输合同·审查`；道路客运 `道路乘客运输合同·审查`；道路货运 `道路货物运输合同·审查` |
| 用户锁定铁路且只要营运细则、无切片争点 | `铁路运输合同·审查` |
| 用户锁定航空且只要营运细则、无切片争点 | `航空运输合同·审查`；国内航空营运细则 `国内航空运输合同·审查` |
| 已锁死水路运输且只要营运细则、无切片争点 | `水路运输合同·审查`；水路客运 `水路乘客运输合同·审查`；水路货运 `水路货物运输合同·审查` |
| 已锁死海上运输且只要营运细则、无切片争点 | `海上运输合同·审查`；海上货运 `海上货物运输合同·审查`；海上客运 `海上乘客运输合同·审查` |
| 已锁死多式联运且只要区段责任营运细则、无切片争点 | `多式联运合同·审查` |
| 已锁死客运或货运产品且只要营运细则、无切片争点 | 客运 `客运合同·审查`；货运 `货运合同·审查` |
| 订舱、报关、不承运 | `货运代理合同·审查` |
| 网络货运平台以承运人身份缔约 | `网络货运平台模式下的运输合同·审查` |
| 一般信息中介、明文仅提供信息 | `一般信息中介平台模式下的合同·审查` |
| 长期派司机派车、像劳务派遣 | `类派遣长期运输·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `国内运输合同·起草` |
| 已签未争、问发运日或运单节点 | 本套导航的履约步骤 |
| 已成争 | `或对应专项领域。` 或对应专项领域 |
| C 端普通商业审查 | 只分流，不回改 |

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。

夹带专章：

- 一小段公路或航空营运细则：可摘录后提示对应方式原子，连结点与适用法条款留在本任务。
- 一小段国内集疏运之外的境外段：提示 `国际运输合同（涉外运输合同）·审查`，不得把境外段改成可履行的国内规则。
- 用户要求本任务把国际运输或某一方式营运细则整案改完：目标停止。
- 标题国际、三点境内、要主张公约限额：本任务按假国际红线处理；用户坚持按国际运输改完则负触发 `国际运输合同（涉外运输合同）·审查`。
