# 审查方法（锁定 运输合同 / 国内运输合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止打开 `国际运输合同（涉外运输合同）·审查`、`客运合同·审查`、`货运合同·审查`、`道路运输合同·审查`、`道路乘客运输合同·审查`、`道路货物运输合同·审查`、`铁路运输合同·审查`、`航空运输合同·审查` 以及水路／海上／多式联运／货代／平台／信息中介／派遣外壳原子的 method。

禁止把本任务做成又一篇货运或客运审查：不把包装、配载、运价、货损操作四栏当主路径。禁止把本任务做成国际运输审查：不把公约并入、可转让提单、SDR 限额表、外国法选择当主路径。禁止把各具体运输方式并进本原子。

定性校验：外壳是国内运输或境内点到点运输，并且起运地、约定经停地、目的地均在中华人民共和国境内，核心问题是准据法切片，才继续。明显他类则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、许可必然办成或限额必然按某公约执行。

`search_law` 返回已失效《合同法》及其解释、《汽车货物运输规则》、《国内水路货物运输规则》、2004 年未修订《道路运输条例》旧条号时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

示范文本只参考结构。摘要引用失效《合同法》《水路货物运输规则》，或只有国际货代提单栏目的范本，不得当本约规则。

## 节点 1　类型识别与单目录加载

### 1.1 本类型识别（不用标题单独定性）

同时满足才正触发：

1. **外壳**：标题、鉴于或项目描述使用国内运输、国内货物／旅客运输、境内点到点运输，或连结点全部写在中国境内场站。
2. **连结点闭合**：起运地、约定经停地、目的地均可定位在中华人民共和国境内；无境外技术经停；本合同不负责境外段。
3. **切片交换**：审查重心是适用哪一国法、哪一部中国特别法、单据选择和能否排除中国强制规范，而不是单一方式的包装、配载、运价或货损操作细则。

辅助红旗（单项不足认定，两项以上应写入风险表）：出现“视为国际运输”“适用海商法第四章”“按海牙规则／蒙特利尔公约”“FIATA 提单”“汽车货物运输规则”“国内水路货物运输规则”；附件有国内运单或客票样张却夹带国际公约；承运人只有境外执照。

标题写成《国际运输合同》但三点都在境内、且要主张公约限额：留在本任务按假国际处理，红线删除公约限额，不得改成可履行的“视为国际运输”。用户坚持按国际运输改完：负触发 `国际运输合同（涉外运输合同）·审查`。

### 1.2 必须切开（禁止两可时灌入两套知识）

硬闸一：**国内运输总括 vs 涉外运输**。起运、约定经停或目的任一在境外，或正文写境外段由本合同一并负责 → 负触发 `国际运输合同（涉外运输合同）·审查`。航空出发、目的或约定经停之一在境外 → `国际航空运输合同·审查`。禁止打开其 method。不得删掉境外点后硬套本技能。

硬闸二：**国内运输总括 vs 单一方式专项**。用户已经锁定公路／铁路／航空（或水路、海上、多式联运、客运、货运产品），并且只要该方式营运细则，且无公约／外国法／提单偷换 → 负触发对应原子，不打开其 method。禁止把各具体运输方式并进本原子改完。

本节点是类型硬闸，必须填表后才能出修改句。本切片的标的是连结点，不是再写一遍如何运货。

| 观察项 | 不得写成 | 本任务动作 |

| 适用“承运人主营业地法”或外国法，履行全在境内 | 外国法当然有效或当然无效 | 改成适用中华人民共和国法律；中国强制规范仍适用；不宣布整约无效 |

| 附件并入 FIATA 提单、海牙规则、蒙特利尔公约期限 | 国际惯例优先于中国法 | 国内段另签中国法运单；删除公约并入 |
| 用户要求把境外点改写成境内点或倒签国内运单 | 完善手续即可放行 | 整体停止 |

识别路径：国内航空运输是出发地点、约定经停地点和目的地点均在中国境内的运输；任一不在境内的，是国际航空运输。公路、铁路、水路、沿海货运的国内识别同样以三点是否均在境内为准。民用航空法第一百零七条本次优先命中 1995 文本且效力字段为“已被修改”，2021 修正本该条号未单独返回；识别口径可用，条号不写入稳定 `L#`。

国内水路运输：始发港、挂靠港和目的港均在中华人民共和国管辖的通航水域内（国内水路运输管理条例 2023 修订第二条，现行有效）。

纯国内合同不是涉外民事关系。涉外民事关系法律适用法第三条、第四十一条的选法空间不以本约自动打开。修改句写适用中国法，不把选外国法改成可履行的准据法安排。中国强制规范仍约束境内段。

无核验引文：适用法与限额法律结论字段停止，事实摘录和条件句继续。

修改纪律：

- 不得写“双方同意视为国际运输”。
- 不得写“国际惯例优先于中国法”。
- 方式特别法按实际运输方式列明，缺方式则字段停止，不编造“当然适用公路规则”。
- 不得把方式营运细则整案并进本切片。

## 节点 3　主体、许可、缔约承运人与实际承运人

1. 建主体表：签约名、缔约承运人、实际承运人、付款名、发票名、授权签字人。名称不一致不自动合并。
2. 承运人必须具备中国法下**对应方式**的经营资格。道路、水路、铁路、航空、网络货运许可互不替代。材料未提及许可：签署能力字段停止，不得写成“可以承运”。
3. 道路客运：运行时核验道路运输条例（2023 修订）第八条条件路径，不得把 2004 年第十条旧文本写入 `L#`。道路货运：核验 2023 修订第二十一条条件、第二十二条驾驶员条件。使用总质量 4500 千克及以下普通货运车辆从事普通货运经营的，道路货物运输及站场管理规定（2023 修正）第十五条无需按该规定申请道路运输经营许可证及道路运输证；不得一律写成必须持证。2023 年条例第二十四条本次未单独命中现行文本，不得把 2004 年第二十四条危货条件旧文本写成现行货运许可条款。
4. 外国承运人承接纯国内段：禁止外国国际道路运输经营者从事我国国内道路旅客和货物运输经营（国际道路运输管理规定 2023 第二十四条）。外国民用航空器的经营人不得经营中华人民共和国境内两点之间的航空运输（民用航空法 2021 修正第一百七十七条）。外国国际船舶运输经营者不得经营中国港口之间的船舶运输业务，也不得租用中国籍船舶或舱位变相经营（国际海运条例 2023 修订第十九条）。国内水路：外国的企业、其他经济组织和个人经营或以租用中国籍船舶或舱位等方式变相经营水路运输业务，2023 修订第三十五条设有责令停止经营和罚款；2012 年第十一条文本本次显示“已被修改”，禁止口径可用，该旧条号不写入稳定 `L#`。仅凭境外执照承接纯国内段：红线停笔，不改写成可履行结构。
5. 国内转包常见。对外责任按中国法锁定缔约承运人，内部追偿另约。不得把实际承运人写成托运人唯一相对方以架空缔约承运人。
6. 跨境电商国内段揽收、国际货国内集港：若本份合同只覆盖境内点到点，仍按国内运输识别，不要误用国际公约。
7. 口头“我们有证”不得写成已许可。

不足：字段停止，列出待补材料，不补主体，不补已经取得许可。

## 节点 4　对象、单据与管制

1. 运送对象定性：旅客或货物；普通货、冷藏或危险货物。定性后指向对应中国特别法，但不打开方式专档 method，也不把该方式营运细则做成主路径。
2. 单据：国内客票、铁路货票、航空货运单、水路运单、道路运单。不要默认签发可转让海运提单。铁路旅客车票、行李票、包裹票和货物运单是合同或组成部分（铁路法第十一条文本本次命中，文件状态“已被修改”，条号不写入稳定 `L#`）。国内航空货运单、铁路货票的记载事项按中国规则，不能用国外提单栏位替代。
3. 禁止流通与管制按中国禁运、危货、野生动植物、烟草规则，与进出口许可证不是同一套。未见危货资质却承运危货：红线停笔。
4. 对价：人民币计价与国内发票。到付、预付按中国法运费规则。未给出的数字写 `【待填】`。
5. 公共运输不得拒绝通常、合理要求（民法典第八百一十条）。修改句删除“承运人可随时拒绝承运且无需说明”的无条件拒运句；合理拒运（禁运、超限、未申报危货）可以保留并写清条件。

修改纪律：

- 不得把国内运单改成可转让提单“方便转让”。
- 不得把进出口许可证条款整段贴进纯国内合同充作管制依据。
- 用户要求改成货运代理：负触发 `货运代理合同·审查`。

## 节点 5　责任、限额、时效与保险

1. 人身伤亡：承运人应当对运输过程中旅客的伤亡承担赔偿责任，旅客自身健康原因或承运人证明旅客故意、重大过失的除外（民法典第八百二十三条）。格式条款排除人身伤害责任：按第五百零六条审查，不得放行。
2. 货损：承运人对运输过程中货物的毁损、灭失承担赔偿责任；不可抗力、货物自然性质或合理损耗、托运人／收货人过错除外（第八百三十二条）。赔偿额有约定从约定，无约定按到达地市场价格；法律、行政法规另有限额的，依照其规定（第八百三十三条）。
3. 国内公路、内河普通货运无特别限额的，按实际损失，不得偷运国际海运或国际航空限额。出现“每件 666.67 SDR”“海牙规则一年时效”“蒙特利尔公约期限”：红线删除。实务资料把“中国已加入公约则公约优先于国内法”写成普遍规则的，对本切片记噪声：三点境内不得用公约架空中国强制规范。
4. 国内港口之间海上**货物**运输不适用海商法第四章。沿海海上**旅客**运输可以指向海商法第五章识别；海商法第一百二十六条（免除法定责任、降低限额的条款无效）现行有效。精确旅客限额运行时再核，不把第一百零七条或未核验数字写入 `L#`。
5. 国内航空：任何旨在免除民用航空法规定的承运人责任或降低其赔偿责任限额的条款无效，但不影响整个航空运输合同效力（民用航空法 2021 修正第一百三十条）。不得约定排除民用航空法。国内航空限额精确数字未核验则字段停止，不得写入蒙特利尔公约数字。
6. 有法定限额的，只能书面提高，不能随意压低到不合理程度。无核验引文：限额数字字段停止。
7. 保险：投保中国境内有效的承运人责任险或货运险。境外保单可能不覆盖纯国内段，标缺口，不保证理赔。
8. 时效与通知按中国对应特别法。国内公路、内河货运原则上走民法典和民事诉讼法，不要写入海牙规则一年时效。

## 节点 6　争议解决、保全与解除

1. 优先写中国大陆法院或中国仲裁机构。选择境外仲裁并非当然使合同无效，但纯国内履行无涉外因素时，境外裁决承认执行风险高，标红旗；不保证有效，也不保证无效。实务“不轻易否定仲裁协议”不得用来放行排除国内保全或安全管辖。
2. 至少保留中国法院对货物所在地的保全管辖。修改句不得排除货物所在地保全。
3. 国内安全事故的行政、刑事管辖不能用仲裁条款排除。
4. 解除：无国内许可、禁运、不可抗力按中国法定义。车辆故障、配员不足、未订到舱位不是不可抗力。修改句把这三项从不可抗力清单删除，改列承运人违约。
5. 生效：可约定以首票境内运单签发为准。不得把未取得许可写成“签字即有权经营”。

## 节点 7　格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 7.1 是否格式条款

为重复使用而预先拟定、订立时未与对方协商。承运人标准运单、网约车或网络货运勾选文本，不当然排除格式条款。最终解释权、单方调限额、单方认定已交付，按异常条款审查提示说明。

### 7.2 提示说明

提供方对其已尽提示或说明承担举证责任。小字、夹在提单背面、仅网络勾选：不得写成已尽义务。相对方立场：修改句要求加黑提示或删除异常条款。提供方立场：补提示痕迹，并评估该条被主张不成为合同内容的风险。

第四百九十七条、第五百零六条：排除人身伤害、故意或重大过失财产损失的免责无效。禁止写“最终解释权当然无效”而不审是否格式条款、是否排除主要权利。

### 7.3 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的是否仅行政管理、是否只规制履行行为。禁止用已失效“效力性／管理性”口诀代替合同编通则解释第十六条。合同法解释（二）第十四条失效，记噪声。

运输许可、外商经营限制、强制安检：

- 必须提示行政约束和停笔结构；
- 不得单独据此宣布本约无效；
- 也不得宣布未许可不影响本约履行。

挂靠、无证经营、免除强制检查、伪造运单：不改写成有效履行结构。
