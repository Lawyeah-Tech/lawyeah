# 国际运输合同（涉外运输合同）·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **运输合同 / 国际运输合同（涉外运输合同）**，输出可编辑草稿和未决项，并用本类型硬闸自审后给出风险表和修改句。待签评改转 `国际运输合同（涉外运输合同）·审查`。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「国际运输合同（涉外运输合同）·起草」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证外国判决或裁决必然获承认、保证某项公约必然适用、国内运输整案、一般客运或一般货运整案、多式联运网状限额整案、国际航空货损或伤亡限额公式、国际海上货物运输责任限额公式、纯货运代理事务整案。

## 本类型硬闸

1. **准据法／公约先行**：本切片是**法律适用切片**，不是又一篇货运合同，也不是单一方式的限额专档。识别标准是运输的起点、约定经停点或终点跨越国境，或运输关系具有涉外因素并构成国际旅客／货物运输。审查任务是：哪一部中国特别法被触发、哪一项国际公约自动适用或可约定适用、意思自治的边界在哪里。未完成法律选择和公约识别，不得先填货损免责或国内市价赔偿公式。
2. **不得按纯国内运输改完**：出发地、约定经停地、目的地均在中国境内 → `国内运输合同·审查`。国际货的国内集港、国内派送若单独签约，仍是国内运输。三点境内却标题写成国际运输以主张公约限额：红线，不得改成可履行的“假国际”。禁止打开或复制 `国内运输合同·审查` 的 method。
3. **不得按单一国际航空改完**：具体货损、旅客伤亡限额、SDR 公式、华沙／蒙特利尔责任限额计算 → `国际航空运输合同·审查`。本切片只锁适用法、公约是否强制适用、争议解决。用户主目标是“算出每公斤／每名旅客赔多少”：负触发，不在本任务套限额表。禁止打开或复制 `国际航空运输合同·审查` 的 method。国际海运货损限额公式 → `海上货物运输合同·审查`；禁止打开其 method。
4. **公约与强制规范不可任意排除**：中国与另一缔约国之间的国际航空客运／货运，通常不能用合同排除强制适用的公约；写“公约优先，公约未规定的适用约定法”。海运可约定并入某规则，但海商法第四章适用时不得低于强制规定。许可、安全、外汇、进出口管制、反垄断和消费者人身保护，不因选择外国法而消灭。格式选择“承运人单方所在国法＋排除一切公约”标红线。
5. **一般客运／一般货运／多式联运切开**：三点境内或未跨境的一般客运 → `客运合同·审查`；一般货运 → `货运合同·审查`；用户主目标是多式联运网状／区段限额公式 → `多式联运合同·审查`。禁止打开或复制上述三份 method。本切片可识别门到门跨境主单的准据法／公约入口，但不代算区段限额。
6. **货代 ≠ 承运人；拆段、单据与时效**：代办订舱、报关、单证，主给付是处理事务 → `货运代理合同·审查`。只有签发自己为承运人的提单／运单，才同时进入国际运输承运人责任。国际干线与境内集疏运分合同、分限额、分适用法。提单并入租约仲裁须使持单人能合理获得租约文本。双语冲突时，涉及人身、安全、强制责任的条款不得被英文免责架空。公约或特别法的书面异议期、诉讼时效优先于合同自拟期限。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签国际／涉外运输正文，尚未签署，尚未成争，连结点跨境或运输关系具有涉外因素，用户问能否签、准据法和公约怎么写、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 出发地、约定经停地、目的地均在中国境内 → `国内运输合同·审查`；
- 未跨境的一般客运本约 → `客运合同·审查`；未跨境的一般货运本约 → `货运合同·审查`；
- 主目标是多式联运网状责任或区段限额公式 → `多式联运合同·审查`；
- 主目标是国际航空货损、旅客伤亡限额或 SDR 计算公式 → `国际航空运输合同·审查`；
- 国内航空（三点均在境内的航空） → `国内航空运输合同·审查`；未区分国内／国际的一般航空运输本约 → `航空运输合同·审查`；
- 主目标是国际海上货物运输责任基础与限额公式 → `海上货物运输合同·审查`；海上旅客运输本约 → `海上乘客运输合同·审查`；
- 只代办订舱、报关、单证，不签发自己为承运人的提单／运单 → `货运代理合同·审查`；
- 网络货运平台撮合或信息中介 → `网络货运平台模式下的运输合同·审查` 或 `一般信息中介平台模式下的合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点、放货日、滞港费 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁或海关／出口管制已立案 → `或对应专项领域。` 或海事／涉外专项。

以国际运输为名规避进出口、海关或制裁，或把明知禁运品改成可承运：只出告知，不改写成可履行路径。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及提单／运单／信用证版本；出发地、约定经停地、目的地所属国家；运输方式（海／空／铁／多式，须表态，不得默认航空）；旅客或货物；拟选准据法与公约；单据能否转让及是否满足信用证；进出口许可与制裁筛查责任人；仲裁或诉讼地、语言、送达；境内段是否另签；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的港口、机场、币种、期限用 `【待填】`，不编造。不输出未经核验的域外实体法结论。

## 起草模式

本原子只承担本类型起草。待签评改转 `国际运输合同（涉外运输合同）·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。本约是准据法／公约切片，不填货损免责公式，不算国际航空或海运限额表。

1. 先按框架六步落稿：首部锁跨境连结点与运输方式；交易条款先写适用法与公约是否强制适用，再写单据与信用证；配套写进出口管制、制裁、拆段；尾部写仲裁或诉讼单选与强制时效；正说反说后按下述必写与禁忌落句。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿。自审至少核对：三点是否跨境、强制公约是否被排除、货代与承运人是否切开、索赔期是否短于强制期限。输出风险表和修改句。不得只交白稿。
3. 纯国内运输、一般客运／货运、国际航空限额、海运限额、多式联运限额、纯货代出稿、已签履约、已成争：仍负触发。

**起草必写**：起点、约定经停点或终点跨越国境，或运输关系具有涉外因素。先写适用哪一部中国特别法、哪一项国际公约自动适用或可约定适用，再写意思自治边界。中国与另一缔约国之间的国际航空客运／货运写“公约优先，公约未规定的适用约定法”。海运可约定并入某规则，但海商法第四章适用时不得低于强制规定。许可、安全、外汇、进出口管制、反垄断和消费者人身保护，不因选择外国法而消灭。只有签发自己为承运人的提单／运单，才同时进入国际运输承运人责任。国际干线与境内集疏运分合同、分限额、分适用法。提单并入租约仲裁须使持单人能合理获得租约文本。双语冲突时，人身、安全、强制责任不得被英文免责架空。公约或特别法的书面异议期、诉讼时效优先于合同自拟期限。

**附件必附**：拟签发的提单或运单样张；信用证要求（如有）；租约文本（提单并入租约仲裁时须使持单人能合理获得）。

**禁止出现**：三点境内写成假国际以主张公约限额；承运人单方所在国法并排除一切公约；按纯国内运输改完；在本切片填货损免责或国内市价赔偿公式；套算国际航空或国际海运限额；视为国内运输；按国际惯例排除强制规范；短于强制期限的索赔期。

### 0. 签署状态与成果分流

本类型条件已谈妥、要出己方稿 → 本任务起草并自审；有完整待签文本要评改 → 配对审查原子；已签履约 → 本套导航履约步骤；已成争 → 合同争议或海事／涉外专项。未签且目标是评改已有国际／涉外运输文本。评改待签文本转配对审查原子，不在本任务评改。

### 1. 类型锁死与连结点

标题、核心给付与连结点一致才继续。三点境内、一般客运、一般货运、国际航空限额本约、海运限额本约、多式联运限额本约、纯货代负触发。不得把跨境多方式文本按国内运输或单一国际航空改完。

### 2. 准据法与公约识别

先写适用法，再写是否适用某项公约。按海／空／铁／多式分别锁中国特别法入口。强制公约不得排除。海商法第四章与并入规则的关系必须表态。

### 3. 主体、单据与信用证

境外承运人在华代理人；缔约承运人与实际承运人；单据可否转让；信用证要求与运输合同是否打架。

### 4. 强制规范、管制与拆段

进出口、制裁、外汇、人身保护不因选外国法消灭。国际干线与境内集疏运分签。

### 5. 争议解决与时效

仲裁或诉讼单选；仲裁协议准据法与主合同准据法切开；短于强制期限的索赔期删除。

### 6. 格式条款与语言

“排除一切公约”“视为国内运输”“按国际惯例”不得放行。双语作准文本须保住强制保护。

### 7. 按框架六步出修改句

必须有可回给对方的修改句或红线。条款重心放在连结点、公约、准据法、单证和争议解决。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把三点境内改成假国际、排除强制公约、人身伤害概不赔偿、把禁运品改成可承运。
- `字段停止`：法域、动态规则、公约是否对航线强制适用、境外裁决执行可能、管制物项归类未核验。
- `目标停止`：主目标已变为待签评改、履约交底、争议文书，或已锁国内运输、一般客运、一般货运、国际航空限额、海运限额、多式联运限额或货代。
