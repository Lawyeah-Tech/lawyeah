## **第一步：合同类型（法律性质）分析**

* **法律定性**：国际运输合同（涉外运输合同）同样是**法律适用切片**，不是又一篇货运合同。识别标准是运输的起点、约定经停点或终点**跨越国境**，或运输关系具有涉外因素并构成国际旅客/货物运输。审查任务是：哪一部中国特别法被触发、哪一项国际公约自动适用或可约定适用、意思自治的边界在哪里。
* **规范图层**：
  * **冲突规范**：《涉外民事关系法律适用法》。当事人可协议选择合同适用的法律；未选择的，适用履行义务最能体现该合同特征的一方经常居所地法或其他最密切联系的法律。
  * **中国特别法**：国际海上货物运输优先考虑《海商法》第四章；国际航空运输优先考虑《民用航空法》国际航空部分及中国已参加的国际航空公约；国际铁路有国际客货联运协定等安排。
  * **国际公约**：国际航空常见《蒙特利尔公约》（中国已参加）；国际海运公约是否并入取决于航线和提单记载，不能假定中国已全部加入并自动适用每一票货。
  * **强制规范与公共秩序**：许可、安全、外汇、进出口管制、反垄断和消费者人身保护，不因选择外国法而消灭。
* **易混淆辨析**：
  * **国内运输**：三点都在中国境内。国际货的国内集港、国内派送若单独签约，仍是国内运输。
  * **国际货运代理**：代办订舱、报关、单证，主给付是处理事务；只有签发自己为承运人的提单/运单，才同时进入国际运输承运人责任。
  * **国际航空 / 国际海上子类型**：本切片管适用法和争议解决；具体货损、伤亡限额进入对应方式合同。
* **效力认定**：选择外国法规避中国进出口、海关、制裁合规的，相关条款不能执行。格式选择“承运人单方所在国法+排除一切公约”可能被认定不合理。仲裁条款本身的效力，依仲裁地或约定的准据法单独判断。

## **第二步：合同主体（交易对手）分析**

* **承运人**：境外承运人、中国承运人、无船承运人、缔约承运人与实际承运人。核查其在装港、卸港所在国的经营资格，以及能否在中国被送达和执行。
* **托运人 / 旅客**：跨境货的卖方、买方、货代谁是订约托运人，决定提单控制和索赔权。旅客国际运输还涉及护照、签证与承运人拒载权。
* **收货人 / 提单或运单持有人**：跨境流转后，持单人可能不受原始运输合同仲裁条款约束，除非并入有效。
* **关联主体**：报关行、境外代理、保险公司、银行（信用证）。信用证要求的提单条款必须与运输合同一致，否则“单证相符”和“合法交货”会打架。

## **第三步：合同标的（交易对象）分析**

* **连结点**：出发地、目的地、约定经停地的国家（地区）。航空“几个接续运输构成一项单一业务”的，即使分签几份合同，仍可能整体构成国际航空运输。
* **货物或旅客**：进出口管制、两用物项、濒危物种、个人行李申报。标的不合法，运输合同不能使之合法。
* **单据**：海运提单、空运单、国际铁路运单、多式联运提单。单据是否可转让、是否满足信用证，属于本切片必须锁定的交易对象属性。
* **责任限额的计量单位**：国际运输常用SDR或公约限额，国内市价条款不能直接覆盖境外交付地的估价规则，须写清估价地和币种。

## **第四步：合同程序（交易步骤）分析**

* **先定适用法，再定履行步骤**。未完成法律选择和公约识别，不要先填货损免责。
* **进出口程序**：许可证、报关、报检、原产地、制裁名单筛查。合同应写清由谁办、以谁名义、延误责任。承运人通常不对申报内容的真实性负责，但明知违法仍承运的除外。
* **单证流转**：提单签发、电放、海运单、空运单放货。跨境无单放货的追索和管辖权成本显著高于国内。
* **索赔程序**：公约或特别法的书面异议期、诉讼时效优先于合同自拟期限。合同约定期限短于强制期限的，不能执行。

## **第五步：交易结构设计（风险规避方案）**

* **法律适用条款要可执行**：写明适用法，并写明是否适用某项公约。国际航空客运/货运，中国与另一缔约国之间通常不能用合同排除公约强制适用。国际海运可约定并入某规则，但不得低于海商法强制规定（当海商法适用时）。
* **争议解决**：仲裁地、仲裁机构、语言、送达地址。诉讼则考虑海事法院、铁路运输法院或普通法院的专属/专门管辖。同时评估境外判决/裁决在中国承认执行的可能性。
* **拆段结构**：国际干线+国内集疏运分开签约、分开适用法，避免国内公路段被整单公约限额覆盖或反过来。
* **支付与外汇**：运费币种、汇率、税务和代扣。制裁、冻结导致不能付款时的替代路径。
* **保险**：按贸易术语确定投保义务（如 CIF/CIP 与 FCA/FOB 不同），并写明保险条款是否覆盖战争、罢工、拒收。

## **第六步：宏观风险预警与尽调指引**

* **高频争议点**：该适用蒙特利尔公约却写成国内航空限额；该适用海商法第四章却选择与强制规定冲突的外国法；货代提单并入外国仲裁对抗国内货主；国内段被国际单证“吸收”。
* **尽职调查清单**：
  * [ ] 出发地、经停地、目的地分属哪些国家
  * [ ] 运输方式及可能自动适用的公约
  * [ ] 当事人选择的准据法是否与强制规范和公约冲突
  * [ ] 单据类型能否满足信用证和提货
  * [ ] 进出口许可、管制物项、制裁筛查责任人
  * [ ] 仲裁/诉讼地的可执行性与保全可行性
* **重大风险红旗**：三点都在境内却标题写成国际运输以主张公约限额；国际旅客运输约定“人身伤害概不赔偿”；选择的适用法与签单承运人、履行地毫无联系。
