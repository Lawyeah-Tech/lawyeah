# 边界与路由

本技能只审查 **运输合同 / 客运合同** 的待签文本。中文展示名是「审查客运合同（运输合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 货物位移、运单、货损货差、运费留置、收货人提货 | `货运合同·审查`。不得删掉货损句后按客运审完，也不得把第 832 条三项免责写进客票 |
| 公路客车班线、包车、旅游客运或网约车，监管主轴是道路运输许可／班线／包车牌／网约三证 | `道路乘客运输合同·审查`。一般客运节人身、迟延、行李闸不得代替道路许可清单 |
| 道路货物运输 | `道路货物运输合同·审查` |
| 只出租车辆及驾驶员，承租人决定线路并对乘员自担风险 | 动产租赁或带驾租赁对应原子。标题是租车但由对方负责将旅客运达的，仍按本类型定性 |
| 主给付是行程与导游，运送只是手段 | 旅游服务对应原子。运送段人身条款可专条交接本技能，不把旅游整案改完 |
| 只代售、候车或信息撮合，不调度运力、不以自己名义承诺送达 | 中介或站务。不得写成“平台免责即可放行” |
| 无文本、本类型条件已谈妥、要出己方稿 | `客运合同·起草` |
| 已签未争、只问发车、退改或保险理赔节点 | 本套导航的履约步骤 |
| 已成争，或用户要人身伤亡、行李灭失索赔、起诉应诉 | `或对应专项领域。` 或旅客运输伤亡行李索赔专项 |
| 纯航空、铁路或海上旅客运输特别限额、责任期间需单独适用特别法 | 本类型可审民法典客运节条款；特别限额与期间字段停止并运行时另核，不把已废止限额写成默认 |
| C 端大众快检或索赔准备 | 只分流，不回改 |

客运正文里夹带一小段托运行李：可审第 824 条第 2 款的分轨和声明价值，不展开货运整案。夹带一小段公路包车许可编号：专条交接 `道路乘客运输合同·审查`，人身、迟延、随身物品条款可继续审。用户坚持本技能把货运或道路客运整案改完：`目标停止`。
