# 审查方法（锁定 运输合同 / 客运合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制货运合同的运单／货损三项免责／留置／收货人提货主路径，也禁止复制道路乘客运输合同的班线许可／包车牌／网约三证主路径。

定性校验：标题、核心给付与本类型一致才继续；货物位移、公路监管主轴、纯租赁自担或旅游主给付明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、旅客必然获赔或唯一必得金额。

`search_law` 返回已失效《合同法》客运节（含原第三百零二条）、2012 年《道路旅客运输及客运站管理规定》第五十四条、已删除的铁路旅客十五万元限额、《国内航空运输旅客身体损害赔偿暂行规定》、1988 年《汽车旅客运输规则》、1996 年《中国民用航空旅客、行李国内运输规则》或合同法解释（二）“效力性强制性规定”口诀时，记为噪声，不得写入 `L#`。

示范文本和官网“最新运输条件”只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受；未单独签收的官网规则不得单方变更已成立合同。

知识库纠正（不回写双文件）：

- 责任期间因运输方式而异：铁路常见自持有效车票进站至出站，航空自登机至下机过程，道路常见实际上车至到达下车。这是识别口径，合同不得把责任起点无理由后移到“车辆启动后”；本任务不作出已进入某期间的事实认定。
- 不得把已删除的铁路旅客十五万元人身限额、已失效 2012 年道路客运第五十四条“参照港口间海上或铁路限额”、已废止《国内航空运输旅客身体损害赔偿暂行规定》写成现行默认。航空、铁路、海商特别限额运行时另核。
- 法释〔2021〕19 号路外伤亡比例表不得套到客运合同之诉。铁路旅客运送期间主张违约人身赔偿的，运行时核验后走民法典第八百一十一条、第八百二十二条、第八百二十三条，不走路外比例。
- “经营性客运无许可，合同不当然无效”：行政违法与保险、履约能力硬伤必须告知；不得写成“无证也可以放行”。
- 客运没有货物交付。到达义务是安全送达旅客并允许其下车出站，不得用买卖或货运的“交付／签收＝验收”句。

先于类型识别。命中任一项则本任务不填十节实体结论，只交付分流理由和最小交接。

| 已能支持的事实 | 走向 | 不得写成 |
| --- | --- | --- |
| 无可读正文、运输条件或客票记载，只有口头行程 | `客运合同·起草` | 已经完成审查；可以签 |
| 未签或尚未出票，目标是评改已有客运文本／运输条件 | 进入节点 1 | 已签署或已生效 |

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。标题写成“租车协议”“信息服务协议”“出行服务”但正文由对方负责将旅客运达并收款的，按本类型审，避免被导向租赁或中介。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 承运人将旅客从起运地安全、按时运到约定地点，旅客支付票款；凭证是客票、电子客票或包车客运合同 | 本类型 | 正触发 |
| 对象是货物；运单、货损货差、运费、留置、收货人提货 | 货运合同 | 负触发 `货运合同·审查` |
| 公路上用客车按班线、包车、旅游客运或网约车监管框架运送，须核道路客运许可、班线许可、包车牌或网约三证 | 道路乘客运输合同 | 负触发 `道路乘客运输合同·审查` |
| 道路上运货，危货许可或道路运单为主轴 | 道路货物运输合同 | 负触发 `道路货物运输合同·审查` |
| 只出租车辆及驾驶员，承租人决定线路并对乘员自担风险，不售客票、不对旅客安全运送负责 | 租赁／带驾租赁 | 负触发对应租赁原子 |
| 主给付是行程、导游、景点，运输出行只是手段 | 旅游服务 | 负触发旅游原子；运送段人身条款可点名交接 |
| 只代售客票、组织候车，不承担运送 | 客运站／售票代理／中介 | 不得写成承运人免责即可放行 |
| 搬家、快递、物品位移 | 货运或搬家专项 | 负触发 `货运合同·审查` 或对应专项 |

支持切开的规范（法律结论须运行时复核）：

- 民法典第 809 条：运输合同是承运人将旅客或货物运到约定地点，旅客、托运人或收货人支付票款或运费。
- 客运节第 814–824 条：成立、持票、迟延改退、救助、人身伤亡、随身与托运分轨。
- 货运节第 832、836 条：货损严格责任加三项免责、对相应货物的留置。这两条不是本类型主路径。
- 《道路运输条例》（2023 修订）及道路旅客运输监管规则：公路班线／包车／出租／网约的许可主轴，交给 `道路乘客运输合同·审查`。

### 1.2 加载协议（硬闸）

本技能已锁定 **运输合同 / 客运合同**。只打开 `references/基本面.md` 与 `references/框架.md`。禁止读其他子目录，禁止为对照再开货运或道路客运双文件。

### 1.3 与货运、道路客运切开（硬闸）

| 文本写法 | 本任务动作 | 修改句方向 |
| --- | --- | --- |
| 客票或包车合同载明起讫、班次／时刻、座席，对价称票款；对象是旅客 | 正触发，留下本类型 | 首部写明“旅客运输，不适用货运货损与留置规则” |
| 运单、货名件数、收货人、货损按第 832 条或“货损一律按运费倍数赔” | 负触发 `货运合同·审查` | 不按客运改完 |
| 班线许可编号、包车牌、网约车三证、道路运输证作为履约主轴 | 负触发 `道路乘客运输合同·审查` | 不把公路监管清单改成一般客运条款后硬套 |
| 同一文本既送人又运货，货损、留置与人身条款缠在一起无法拆条 | 负触发或红线拆分；用户坚持一票到底按货运审 | 不得用货损三项免责吸收旅客人身 |
| “旅客自愿超载／自担伤亡，承运人只对货物负责” | 红线删除；人身走本类型硬闸 | 不得改成可履行的超载自愿 |

最强反方：相对方主张“出行服务不是客运”“平台只是信息撮合所以无人身责任”，或主张“行李按货运三项免责、人按自甘风险”。修改句必须写清：核心给付是旅客安全运送。用户坚持按货运或道路客运监管整案放行：负触发，不填本类型十节实体结论。

### 1.4 挂靠、超载、假许可停笔

加载后或定性中出现：借用客运资质挂靠、超载写“旅客自愿”、使用报废或非载客工具、伪造许可或倒签出票、要求把人身免责改成可履行。

动作：

1. 交付告知：挂靠内部协议不能对抗旅客；超载“自愿”不能排除安全保障义务；免除人身伤害的条款无效。不得改写成可履行的假许可或超载结构。
2. 不写可履行的挂靠管理费路径、假包车牌或“自愿放弃索赔”。
3. 风险表只保留识别依据和删除／转出口径。
4. 用户坚持“改到能签且仍做这些事”：整体停止。

合规改道（真实承运人出面、真实减少载客、补办许可）只点名，不在本任务代办许可。

## 节点 2　主体、客票与承运人身份

### 2.1 主体表

建表：签约名、履行名、收款名、发票名、授权签字人。名称不一致不自动合并。承运人填写全称、统一社会信用代码；旅客姓名与有效身份证件一致。单位包车须同时列出乘车人范围或附名单。

售票代理、平台、客运站若不是承运人，不得写在“甲方（承运人）”位置。口头“我们挂靠在某某公司”不得写成旅客只能向挂靠车主索赔。

未附许可、保险或客票记载的承运人名称：该身份字段停止，不写“承运人资质齐全”。

### 2.2 成立与客票（第 814、815 条）

客运合同自承运人向旅客出具客票时成立，另有约定或交易习惯的除外。扫码进站、电子客票、先上车后补票、网约即时成交，应按交易习惯认定已成立，不得以“未打印纸质票”否定合同。

旅客应按有效客票记载的时间、班次和座位号乘坐。无票、超程、越级或不符合减价条件的，应补交票款，承运人可按规定加收；不支付的，可以拒绝运输。实名制客运丢失客票，旅客可请求挂失补办，承运人不得再次收取票款和其他不合理费用。

| 文本写法 | 动作 |
| --- | --- |
| 出票或电子订单载明承运人、班次／航班／船次、时间、座位、票价、退改入口 | 可继续；冲突写入版本表 |
| “未打印纸质票合同不成立／不生效” | 必须改。回归第 814 条及交易习惯 |
| 实名制丢失客票须重新购票 | 必须改。挂失补办，不得再收票款和不合理费用 |
| 客票承运人与实际运送人不一致且未披露 | 必须改：对外锁定缔约承运人；代码共享、联合售票披露实际运送人 |

修改句：

「本合同自承运人向旅客出具纸质或电子客票（含订单行程单）时成立，双方另有书面约定或另有交易习惯的除外。不得以未打印纸质票否定合同成立。客票或订单应载明缔约承运人全称、班次或航班／船次、时间、座位或舱位、票价和退改入口。实名制旅客丢失客票的，有权请求挂失补办，承运人不得再次收取票款或其他不合理费用。售票代理、平台或客运站不是承运人的，不得记载为甲方（承运人）；挂靠、承包、代码共享只约束内部追偿，不减轻缔约承运人对旅客的义务。」

公共运输承运人不得拒绝旅客通常、合理的运输要求（第 810 条）。格式“本公司有权随时拒载且不说明理由”：必须改。

## 节点 3　人身伤亡与救助（硬闸）

支持依据：民法典第 823、822、506、497 条。航空运输另核《民用航空法》第 124、130 条；铁路旅客合同之诉另核第 811、822、823 条，不套路外比例。

| 文本写法 | 动作 |
| --- | --- |
| 重申承运人对运输过程中旅客伤亡承担责任；自身健康或承运人证明的故意、重大过失除外；免票／优待／经许可无票同样适用 | 可保留；补保险与垫付流程，不得减等 |
| “伤亡自负”“旅客自甘风险”“仅对承运人有过错的事故负责” | 红线删除，回归第 823 条 |
| “只在保险额度内赔偿”“保险赔付后承运人不再承担” | 红线。保险不得替换法定赔偿 |
| 免票儿童、优待票、经许可搭乘无票旅客被排除在保护外 | 必须改。第 823 条第 2 款同样适用 |
| 把救助完全推给旅客自行处理或“承运人不负责急病分娩” | 必须改。第 822 条尽力救助 |
| 引用已删除的铁路十五万限额、2012 年道路客运第五十四条或 1993 年航空暂行规定 | 红线删除。特别限额运行时另核现行法 |
| 把法释〔2021〕19 号路外伤亡比例写进客票 | 红线删除。旅客合同之诉不走该表 |

修改句：

「承运人应当对运输过程中旅客的伤亡承担赔偿责任。伤亡是旅客自身健康原因造成的，或承运人证明伤亡是旅客故意、重大过失造成的，承运人不承担本条赔偿责任。本条适用于按照规定免票、持优待票或者经承运人许可搭乘的无票旅客。任何“伤亡自负”“只在保险额度内赔偿”“承运人仅对有过错的事故负责”的约定不发生效力。承运人投保的承运人责任险、旅客意外险与本条赔偿责任并行，保险金不得当然冲抵法定赔偿。承运人在运输过程中应当尽力救助患有急病、分娩、遇险的旅客，不得约定由旅客自行处理上述情形。」

最强反方：承运人主张已购意外险即已转移风险，或主张免票旅客不是合同当事人。两说均不得写成可放行。用户坚持保留人身免责或保险内封顶：整体停止。

## 节点 4　迟延、改退与变更工具（硬闸）

### 4.1 承运人原因：第 820、821 条

承运人应当按照有效客票记载的时间、班次和座位号运输旅客。迟延运输或有其他不能正常运输情形的，应当及时告知和提醒旅客，采取必要的安置措施，并根据旅客的要求安排改乘其他班次或者退票；由此造成旅客损失的，应当赔偿，不可归责于承运人的除外。

擅自降低服务标准的，应当根据旅客请求退票或者减收票款；提高服务标准的，不得加收票款。未经许可变更运输工具或降低标准，旅客可拒绝或解除并要求退票。

| 文本写法 | 动作 |
| --- | --- |
| 写清告知时限、安置标准（食宿、转运）、改乘或全额退票选择权，以及可归责时的直接损失范围 | 可继续；缺数字用 `【待填】` |
| 只有“原则上正点／尽量准点”而无迟延后果 | 必须改。没有后果等于没有正点义务 |
| “任何晚点只退票、不赔偿任何损失” | 必须改。区分不可归责与可归责；可归责时列住宿、转运、已购衔接票等直接损失 |
| 车检、司乘不足、普通拥堵、运力调配失败写入不可抗力 | 红线删除。天气须达到不能安全运行的程度并证明已采取合理措施 |
| 降舱、换车无差价返还和解除权 | 必须改。第 821 条 |
| 提高标准后强制加收 | 必须改。不得加收 |

修改句：

「承运人应当按照有效客票记载的时间、班次和座位号运输旅客。迟延运输或者有其他不能正常运输情形的，承运人应当在【待填】分钟内通过订单预留手机和【待填】渠道告知并提醒旅客，采取必要安置措施（含【待填】标准的食宿或转运），并根据旅客的要求安排改乘其他班次或者全额退票。由此造成旅客损失且不可归责于承运人的除外，承运人应当赔偿旅客因此发生的必要住宿、转运和已购衔接交通的直接损失，计算方式和上限为【待填】，不得以“只退票”排除本条。车检、司乘不足、普通道路拥堵、运力调配失败不构成不可抗力。承运人擅自降低服务标准或变更运输工具的，旅客有权拒绝、解除并要求退票或减收票款；提高服务标准的，不得加收票款。」

### 4.2 旅客自身原因：第 816 条

旅客因自己的原因不能按照客票记载的时间乘坐的，应当在约定的期限内办理退票或者变更手续；逾期办理的，承运人可以不退票款，并不再承担运输义务。手续费上限须可核对，不得用“概不退票”覆盖承运人原因的取消或严重延误。

承运人取消班次或严重延误时，旅客应有无偿退票或改乘选择，已发生的必要安置费用不得再向旅客转嫁。

## 节点 5　随身物品、托运行李与禁运品（硬闸）

支持依据：第 817、818、824 条。托运行李适用货运有关规定，本任务只拆分责任基础，不展开货运整案。

| 文本写法 | 动作 |
| --- | --- |
| 分列免费随身额度、托运条件；随身物品按过错责任；托运行李指向货运规则并可声明价值 | 可继续 |
| “行李概不负责”“自理行包丢失一律免责”覆盖随身与托运 | 红线拆分。随身＝过错责任，不得预先免除；托运≠随身 |
| 把第 832 条三项免责或货物留置写进客票主文 | 红线删除或负触发 `货运合同·审查` |
| 超过限量仍按随身且声明“承运人无义务” | 必须改。超限量或违反品类应办理托运 |
| 概括放弃安检权，或禁止承运人拒绝夹带危险品 | 红线。第 818 条：可卸下、销毁或送交有关部门；旅客坚持携带的，应当拒绝运输 |
| 航空、铁路行李特别限额未核验却写成全国统一数字 | 字段停止，不编造限额 |

修改句：

「旅客随身携带行李应当符合本合同附件【待填】载明的限量和品类；超过限量或违反品类的，应当办理托运。运输过程中旅客随身携带物品毁损、灭失，承运人有过错的，应当承担赔偿责任，不得约定“一律免责”。旅客托运的行李毁损、灭失的，适用货物运输的有关规定，双方可另行书面约定声明价值；本条不使客运合同整体改按货运合同履行，也不产生对旅客人身的留置。旅客不得随身携带或在行李中夹带易燃、易爆、有毒、有腐蚀性、有放射性以及可能危及运输工具上人身和财产安全的危险物品或违禁物品。旅客违反的，承运人可以将该物品卸下、销毁或送交有关部门；旅客坚持携带或夹带的，承运人应当拒绝运输。承运人不得在合同中概括放弃安检权。」

## 节点 6　格式条款、不可抗力、许可与保险

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 格式条款

客票背面、运输条件、APP 勾选多为重复使用预先拟定。审查人身、迟延、退改、行李、管辖等异常条款是否有足以引起注意的标识，以及是否按要求说明（第 496、497 条；合同编通则解释第 10 条）。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在未单独签收的官网规则 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

提供方对其已尽提示或说明承担举证责任。相对方立场：修改句要求加黑提示、单独确认退改和人身条款，或删除异常条款。

### 6.2 强制规范与许可

违反法律、行政法规强制性规定不一律无效（第 153 条；解释第 16 条）。经营性客运无法定许可，合同不当然无效，但行政处罚、保险覆盖和过错评价会明显加重。禁止用已失效“效力性／管理性”口诀。运送禁止乘运对象、超载、使用报废或不符合安全标准的载客工具，相关约定不能排除安全保障义务。

### 6.3 保险

可约定高于法定标准的赔偿或购买足额承运人责任险，但不得约定低于法律强制的保险，也不得写“保险范围内赔偿即完毕”。

## 节点 7　对价、争议与通知

1. 票价、儿童票／优待票条件、是否含过路燃油、改签差价必须写清。公共运输政府指导价不得由格式条款再加“服务费”架空。未给出的数字写 `【待填】`。
2. 定金极少用于散客售票。包车预付款应写明是预付款还是定金；必须使用“定金”二字才讨论罚则；超过主合同标的额百分之二十的部分不产生定金效力。无核验引文不得把 20% 写成现行法结论。
3. 只有“依法承担违约责任”视为必须改。不在本任务做第 585 条精算。修改句避免“不得调整”或“按总价 30% 必得”。
4. 构成违约不等于当然解除。法定解除只点名催告或目的不能实现，不在本任务作出已解除结论。
5. 争议解决：消费性客运的管辖、仲裁条款不得利用格式条款给旅客造成不便。公共运输可约定承运人住所地，但不得排除侵权行为地、旅客住所地等合法连结点。出现仲裁条款，不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核。专属管辖可能：只标红旗，不选定唯一法院充作法律意见。
6. 电子客票以订单预留手机、邮箱为送达地址；航班／班次变动的短信、APP 推送是否构成有效告知，应写明补强方式。微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`
