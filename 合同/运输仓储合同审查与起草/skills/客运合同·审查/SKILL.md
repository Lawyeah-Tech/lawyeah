# 客运合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》客运节（含原第三百零二条）、2012 年《道路旅客运输及客运站管理规定》第五十四条、已删除的铁路旅客十五万元限额、《国内航空运输旅客身体损害赔偿暂行规定》、1988 年《汽车旅客运输规则》或 1996 年《中国民用航空旅客、行李国内运输规则》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **运输合同 / 客运合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文名必须是「客运合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议或索赔文书、有效性保证、把货运或道路客运监管主轴改成本类型、把人身伤亡改成过错责任或保险内封顶。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **旅客人身伤亡不得减等**：承运人对运输过程中旅客伤亡承担责任；仅当伤亡是旅客自身健康原因，或承运人证明是旅客故意、重大过失造成时免责。免票、优待票、经许可无票搭乘的旅客同样适用。禁止“伤亡自负”“只在保险额度内赔偿”“承运人仅对有过错的事故负责”。造成对方人身损害的免责条款无效。保险是承运人风险分散工具，不能替换法定赔偿。
2. **迟延改退必须闭环**：承运人应按有效客票记载的时间、班次和座位号运输。迟延或不能正常运输时，应及时告知和提醒、采取必要安置措施，并根据旅客要求安排改乘其他班次或退票；由此造成损失的应赔偿，不可归责于承运人的除外。旅客自身原因未乘的，按约定期限办理退票或变更，逾期可不退票并不再承担运输义务。禁止把车检、司乘不足、普通拥堵、运力调配失败写入不可抗力，禁止只退票不谈可归责损失。
3. **随身物品与托运行李分轨**：随身携带物品毁损灭失，承运人有过错才赔。托运行李适用货物运输规定。禁止用一条“行李概不负责”覆盖两类标的，也不得把货运三项免责或货物留置写进客票主给付。
4. **与货运、道路客运切开**：对象是旅客本人，不是货物位移。货损货差、运单记载、运费留置、收货人提货 → 负触发 `货运合同·审查`。监管主轴是公路客车班线／包车／旅游客运／网约车，须对照道路运输许可和《道路运输条例》 → 负触发 `道路乘客运输合同·审查`。不得删掉货损或班线许可句后按一般客运审完。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签客运正文或“客票＋运输条件”，尚未签署，尚未成争，核心给付是承运人将旅客从起运地点安全、按时运到约定地点并由旅客支付票款，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主给付是货物空间位移、运单、货损货差、运费留置或收货人提货 → `货运合同·审查`；
- 主给付是公路上用客车按班线、包车、旅游客运或网约车监管框架运送，须核道路客运许可／班线／包车牌／网约三证 → `道路乘客运输合同·审查`；
- 道路货物运输 → `道路货物运输合同·审查`；
- 只出租车辆及驾驶员、承租人决定线路并对运输对象自担风险 → 动产租赁或带驾租赁对应原子；不得删掉“承租人自担伤亡”后按客运放行；
- 主给付是行程安排与导游服务，运送只是履行手段 → 旅游服务对应原子；运送段人身条款可点名交接，不把旅游整案改完；
- 售票代理、客运站或平台只撮合、不调度运力、不以自己名义收款承诺送达 → 中介或站务，不得写成承运人免责即可放行；
- 无文本、本类型条件已谈妥、要出己方稿 → `客运合同·起草`；
- 已签只问发车日、退改进度、保险理赔节点 → 本套导航的履约步骤；
- 已催告、解除、人身伤亡或行李索赔、立案、开庭或仲裁 → `或对应专项领域。` 或旅客运输伤亡行李索赔专项。

挂靠、超载“自愿”、伪造许可或倒签出票：只出告知，不改写成可履行结构。用户坚持保留人身免责、把迟延一律称不可抗力、或把货运三项免责写进客票：整体停止。

## 建立审查坐标

确认：使用者与授权；单方立场（承运人侧或旅客／包车人侧择一）；相对方；全文及运输条件／退改规则／包车行程／保险单版本；承运人名称是否与客票一致；起讫地点、班次或时刻、座席等级；人身条款、迟延改退、随身与托运分轨是否可见；不可接受事项；法域与拟签署或出票日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的票价、人数、时限用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典第八百零九条至第八百二十四条、第五百零六条、第四百九十六条、第四百九十七条、第五百八十六条、第一百五十三条；`search_practiced` 只补审查反例；`search_template` 只借栏目结构。不虚构案件系统。

`search_law` 对人身伤亡、迟延改退、随身物品与格式免责的法律结论为 required 级：不可用时不拒绝执行，只停止效力字段。返回已失效《合同法》客运节、2012 年道路客运第五十四条、已删除铁路十五万限额、1993 年国内航空旅客身体损害暂行规定、1988 年汽车客规或 1996 年民航国内客规时记为噪声，不得写入 `L#`。不得把货运第八百三十二条三项免责或法释〔2021〕19 号路外伤亡比例表套到本类型。

航空、铁路、海商特别法有限额或期间规则的，运行时另核后字段写入，不得把已废止限额写成现行默认。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`基本面.md` 中责任期间因运输方式而异的表述是识别口径，不是已完成的期间认定。不得把知识库未点名的铁路／航空限额写成法定封顶。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `客运合同·起草`；已签履约 → 本套导航履约步骤；已成争或伤亡／行李索赔 → 合同争议或专项。未签且目标是评改已有客运文本，才进入本任务。

### 1. 类型锁死与货运／道路客运切开

标题、核心给付与对价方式一致才继续。货物位移、公路班线／包车／网约监管主轴、租赁自担、旅游主给付负触发。

### 2. 主体、客票与承运人身份

锁定与旅客订立合同的一方。售票代理、平台不得写在承运人位置。挂靠、承包只约束内部追偿。无纸质票不否定已成立。

### 3. 人身伤亡与救助

回归第八百二十三条；救助义务不得推给旅客自行处理。保险不得替换法定赔偿。

### 4. 迟延、改退与变更工具

告知、安置、改乘或退票、可归责损失分列。旅客自身原因走第八百一十六条。擅自降低标准走第八百二十一条。

### 5. 随身物品与托运行李

过错责任与货运规则分列。禁运品按第八百一十八条处理，不得概括放弃安检权。

### 6. 格式条款、不可抗力与强制规范

人身免责、排除法定退改、迟延一律不可抗力：删除或整体停止。无许可经营不当然使合同无效。

### 7. 对价、争议与通知

票价与退改手续费、包车定金上限。消费性客运管辖不得利用格式条款给旅客造成不便。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签或补假客票、保证必然有效、保留人身免责或保险内封顶、把迟延一律称不可抗力、把货运三项免责或货物留置写进客票。
- `字段停止`：法域、特别法限额、航空／铁路／海商期间规则、动态退改规章未核验。
- `目标停止`：主目标已变为从零起草、履约交底、伤亡或行李索赔文书，或已锁货运／道路客运／租赁／旅游。
