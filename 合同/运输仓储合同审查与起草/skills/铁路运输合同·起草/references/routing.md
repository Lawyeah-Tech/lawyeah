# 边界与路由

本技能只审查 **运输合同 / 铁路运输合同** 的待签文本。中文展示名是「审查铁路运输合同（运输合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或抄写道路、航空、水路、一般客运／货运原子的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 道路车辆、道路运输经营许可、公路运单为主给付 | `道路运输合同·审查`；乘客为主 `道路乘客运输合同·审查`；道路货物为主 `道路货物运输合同·审查` |
| 民用航空器、航空运单、《民用航空法》责任期间为主给付 | `航空运输合同·审查`；能分国内／国际时 `国内航空运输合同·审查` 或 `国际航空运输合同·审查` |
| 水路或内河船舶为主给付 | `水路运输合同·审查` |
| 铁路只是区段，全程由多式联运经营人负责 | `多式联运合同·审查` |
| 境外到站、国际货协／国际客协运单、国际铁路联运 | `国际运输合同（涉外运输合同）·审查` |
| 只有客运或货运的一般运输、无法识别是否铁路 | `客运合同·审查` 或 `货运合同·审查`，或引擎重新定性 |
| 有完整待签文本要评改 | `铁路运输合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争 | `或对应专项领域。` 或对应专项领域 |
| 路外行车事故人身已成争，不是待签客运条款 | 专项人身损害或争议领域；本任务只审待签文本里的人身条款 |
| C 端大众快检 | 只分流，不回改 |

铁路货物框架协议里夹带一小段两端汽运短驳：若铁路承运人书面纳入门到门，短驳责任可留本类型锁定；道路许可与车辆专条交接 `道路货物运输合同·审查`。用户坚持本技能把道路、航空、多式联运全程或国际联运整案改完：`目标停止`。
