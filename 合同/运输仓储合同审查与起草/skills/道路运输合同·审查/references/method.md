# 审查方法（锁定 运输合同 / 道路运输合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止打开或复制 `客运合同·审查`、`货运合同·审查`、`多式联运合同·审查`、`铁路运输合同·审查`、`货运代理合同·审查`、`网络货运平台模式下的运输合同·审查`、`类派遣长期运输·审查` 的 method。也禁止打开道路乘客或道路货物专项 method 后换标题交差。

定性校验：核心给付是公路机动运输，且客货尚未排他拆开或混写在同一份总类合同中，才继续；明显他类则负触发，不填十节实体结论。

本文件是可执行判断节点，不是栏目说明书。每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、无证即未成立，或唯一必得赔偿额。

三项成果闸，缺一不得宣称审查完成：

1. **道路运输资质**：许可、证号、经营范围、4.5 吨边界、车辆与驾驶员条件必须落句或字段停止。
2. **货损限额**：删除失效汽货规；货损回到民法典第 832、833 条；人身不得套货损限额。
3. **不得按劳务派遣或网货平台改完**：用工外观主导转 `类派遣长期运输·审查`；深度调度、统一定价、以平台自己名义承运且道路许可已不是放行关键转 `网络货运平台模式下的运输合同·审查`。禁止把本约改写成派遣协议或网货平台规则后当作本技能完成。

开发窗口 2026-08-18 已核验、可供对照但不得代替运行时核验的规则：

- 民法典第 153 条：违反法律、行政法规强制性规定的民事法律行为无效；该强制性规定不导致民事法律行为无效的除外。
- 民法典第 180、590 条：不可抗力是不能预见、不能避免且不能克服的客观情况；迟延履行后发生不可抗力不免除违约责任。
- 民法典第 506 条：造成对方人身损害的免责条款无效；因故意或重大过失造成对方财产损失的免责条款无效。
- 民法典第 809 条：运输合同是承运人将旅客或者货物从起运地点运输到约定地点，旅客、托运人或者收货人支付票款或者运输费用的合同。
- 民法典第 823 条：承运人对运输过程中旅客伤亡承担赔偿责任，旅客自身健康原因或承运人证明旅客故意、重大过失除外；适用于免票、优待票和经许可搭乘的无票旅客。
- 民法典第 832、833 条：承运人对运输过程中货物毁损、灭失赔偿；不可抗力、货物自身性质或合理损耗、托运人或收货人过错除外。赔偿额有约定从约定；约定不明依第 510 条仍不能确定的，按到达地市场价格；法律、行政法规另有规定的除外。
- 民法典第 836 条：托运人或收货人不支付运费、保管费或其他费用的，承运人对相应运输货物享有留置权，当事人另有约定除外。
- 民法典第 1211 条：以挂靠形式从事道路运输经营活动的机动车发生交通事故造成损害，属于该机动车一方责任的，由挂靠人和被挂靠人承担连带责任。此条是侵权路径，不能替代合同主体应写成许可企业。
- 合同编通则解释第 16 条（法释〔2023〕13 号）：违反强制性规定不一律无效；规范目的仅行政管理、仅规制履行行为等情形可以认定不因此无效。禁止用已失效“效力性/管理性”口诀代替本条。
- 《道路运输条例》（2023 修订，国务院令第 764 号）第 8 条：申请从事客运经营应当具备检测合格车辆、符合条件的驾驶人员、健全安全生产管理制度；班线客运还应当有明确线路和站点方案。
- 同条例第 33 条：道路运输车辆应当随车携带车辆营运证，不得转让、出租。
- 《道路货物运输及站场管理规定》（2023 修正）第 15 条：使用总质量 4500 千克及以下普通货运车辆从事普通货运经营的，无需按照本规定申请取得《道路运输经营许可证》及《道路运输证》。此为本次已返回的现行 4.5 吨豁免正文。
- 同规定第 20 条：道路货物运输经营者应当按照《道路运输经营许可证》核定的经营范围从事货物运输经营，不得转让、出租道路运输经营许可证件。
- 同规定第 26 条：运输货物应当符合核定载质量；禁止货运车辆违反规定超限、超载；禁止使用货运车辆运输旅客。
- 同规定第 61 条（2023 修正决定改写）：未按规定取得道路货物运输经营许可擅自从事道路普通货物运输经营、使用失效伪造变造被注销证件、超越许可事项从事普通货运的，责令停止经营并处罚款。此为行政处罚，不得直接写成合同无效。
- 《道路危险货物运输管理规定》（2023 修正）第 22 条：禁止使用报废、擅自改装、检测不合格、技术等级达不到一级和其他不符合国家规定的车辆从事道路危险货物运输。
- 同规定第 29 条：不得使用罐式专用车辆或者运输有毒、感染性、腐蚀性危险货物的专用车辆运输普通货物；不得将危险货物与普通货物混装运输。
- 同规定第 33 条：不得运输法律、行政法规禁止运输的货物；限运、凭证运输须办手续。
- 《汽车货物运输规则》（1999）：MCP 效力字段为失效。废止文书为交通运输部令 2016 年第 57 号《关于废止 20 件交通运输规章的决定》，不得作为现行归责或许可依据。

## 节点 1　类型识别、派遣／网货硬闸与单目录加载

### 1.1 定性

用路径、工具、运输对象和给付外观定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须同时满足才正触发：

1. 运输路径是公路、城市道路或允许行驶的路段；工具是机动客车或货车，不是轨道车辆或船舶。
2. 客货尚未排他拆开，或同一份总类合同混写载客与载货。出租人向旅客售票或向托运人揽货并负责运达的，仍是道路运输，不是租赁。

## 节点 2　道路运输资质闭环（硬闸）

本节点是三项成果闸的第一闸。没有资质表和对应修改句，不得宣称审查完成。

1. 建主体表：承运人／许可企业、挂靠车主或实际控制人、旅客或包车方、托运人、收货人、付款人。名称不一致不自动合并。
2. 经营性道路客运、货运原则上应取得《道路运输经营许可证》，车辆配发道路运输证或车辆营运证。许可证经营范围必须覆盖合同线路或货类。货规 2023 第 20 条：按核定经营范围经营，不得转让、出租许可证件。条例 2023 第 33 条：车辆营运证随车携带，不得转让、出租。
3. 4.5 吨豁免（核验后可引用货规 2023 第 15 条）：仅当同时满足“总质量 4500 千克及以下”且“普通货运”时，无需申请许可证及道路运输证。客运、危险货物不得套用。豁免不等于无驾驶证、行驶证、交强险，也不等于不是承运人。总质量未给出却主张豁免：该字段停止，不写成已豁免。总质量明显超过 4.5 吨仍主张免许可：红线。条例 2023 对应条号本次未返回正文，法律结论以货规第 15 条落句，条例条号标待核。
4. 驾驶员：经营性客货驾驶员一般需从业资格；4.5 吨以下普通货运驾驶员除外。危货驾驶、装卸、押运人员须单独从业资格——本技能只标红旗并转危货专项或 `道路货物运输合同·审查`，不展开类别表。
5. 挂靠：对外仍以许可持有人为承运人。合同主体应写企业并盖公章。只写挂靠车主个人：必须改。写“挂靠人自负、公司免责”：红线，不能对抗旅客或托运人。挂靠只告知，不改写成可履行挂靠结构。交通事故损害另有民法典第 1211 条挂靠人与被挂靠人连带责任，不得写成合同免责可以排除。
6. 相对人单位长期用车：核内部授权，但不减轻承运人资质瑕疵。口头“我们老板同意了”不得写成已授权。
7. 许可被吊销、停业、过期未年审：修改句写成当然解除或暂停新运单，不写成已经办妥续期。

不足：字段停止，列出待补材料，不补主体、不补已办证、不补总质量。

本节点最低修改句（缺事实用 `【待填】`）：

`定位（首部／主体栏）｜原文：乙方赵某（车主）｜建议改为：乙方为【待填】运输有限公司（道路运输经营许可证号【待填】，经营范围【待填】）；赵某仅作为经办人签字，不替代企业盖章。车辆总质量【待填】千克；仅当总质量≤4500千克且货类为普通货运时，可注明无需申请道路运输经营许可证及道路运输证，但不因此改变乙方承运人身份。｜理由：资质闭环；货规2023第15、20条｜可退让点：证号可在附件清单补录，但主体不得只留个人｜不接受时的红线：只签个人且公司拒认则停止可履行改写`

## 节点 3　客货分流结构

本类型最常见缺陷是总类合同不拆客货。人身伤亡与货损不是同一套规则。货规 2023 第 26 条禁止使用货运车辆运输旅客，客货混装用车本身就是资质／工具错位。

核验后可引用的判断点（须 `search_law` 写入 `L#` 再落法律结论）：

- 运输合同定义同时覆盖旅客和货物。
- 旅客伤亡适用第 823 条。
- 货损适用第 832、833 条；运费未付可有第 836 条留置。
- 本技能只写分叉结构，不代做道路乘客或道路货物专项审查。

| 文本写法 | 本任务动作 |
| --- | --- |
| 标题仅“道路运输合同”，正文第一段未选定客或货 | 必须改。首部改为道路旅客运输或道路货物运输；不能选定则追问，用户拒绝则字段停止 |
| 同一份合同既包通勤载客又包物资配送，只有一套“损坏照价、人身协商” | 红线或必须改。分两个责任章或拆成两份合同；人身不得按货损限额，货损不得按客运过错一口价 |
| 已能排他识别为只载客 | 负触发 `道路乘客运输合同·审查`，不在本技能填乘客专项十节 |
| 已能排他识别为只运货 | 负触发 `道路货物运输合同·审查`，不在本技能填货物专项十节 |
| 旅客运输混装危险品，或危货用普通货车，或货运车辆载客 | 红线。停笔，不改成可履行混装 |
| 用户要求保留一套限额以便“好谈” | 生存级人身被货损限额打发：停止“可以签署”建议 |

分章最低要素：许可与保险分列；人身责任指向客运规则；货损责任指向货运规则并写保价或约定计算方式；禁止互相套用。本技能出分章修改句后，乘客章深度审转 `道路乘客运输合同·审查`，货物章深度审转 `道路货物运输合同·审查`。

## 节点 4　货损限额与失效规范（硬闸）

本节点是三项成果闸的第二闸。没有删除失效依据的修改句，或仍按汽货规／海铁限额出赔偿数字，不得宣称审查完成。

货损计算顺序（核验后可引用第 833 条）：

1. 当事人有约定的，按照约定。
2. 没有约定或约定不明，依据民法典第 510 条仍不能确定的，按照交付或应当交付时货物到达地的市场价格。
3. 法律、行政法规对赔偿额计算方法和赔偿限额另有规定的，依照其规定。已失效部门规章不是“法律、行政法规另有规定”。

| 文本写法 | 本任务动作 |
| --- | --- |
| “货损按《汽车货物运输规则》第八十三条限额赔偿”或“按原公路条例／汽货规三倍运费” | 红线删除。改回第 832、833 条；有保价从保价。废止依据是交通运输部令 2016 年第 57 号 |
| “未保价最多赔三倍运费”且依据是失效汽货规或未核验的部门规章 | 法律结论字段停止；修改句删除该依据，改为约定赔偿额或到达地市价，并标明待核验 |
| “人身伤亡参照港口间海上旅客运输和铁路旅客运输限额” | 噪声。2012 年客规第 54 条已失效。本技能只改成适用客运人身规则，不编造限额数字 |
| 只写货损不写人身，或相反，且合同可能涉及另一类风险 | 必须改。补另一套责任章或拆合同 |
| “损坏照价、人身双方协商／最高按运费三倍”一套打发 | 红线。人身适用第 823 条；造成对方人身损害的免责条款依第 506 条无效 |
| 用户要求按汽货规出“合法赔偿标准” | 整体停止该结论 |

货损有约定从约定；无约定不得编造单价。保价声明价格可写，但不得与失效规则混用。保险人拒赔不影响承运人对相对人的赔偿。

本节点最低修改句：

`定位（责任章第【待填】条）｜原文：货损按《汽车货物运输规则》限额赔偿，未保价最高赔三倍运费；人身伤亡双方协商｜建议改为：货物毁损、灭失的赔偿责任适用《中华人民共和国民法典》第八百三十二条、第八百三十三条；有保价的按保价声明价格【待填】；无保价且无约定的，按交付或应当交付时到达地市场价格计算。删除一切以已失效《汽车货物运输规则》或《公路运输管理暂行条例》为计算依据的表述。旅客人身伤亡适用民法典第八百二十三条，不得按货损限额或运费倍数折抵。｜理由：货损限额硬闸；2016年第57号废止汽货规｜可退让点：双方可另行书面约定货损计算方式，但不得引用失效规章｜不接受时的红线：坚持按汽货规出合法标准则停止该结论`

## 节点 5　车辆、人员、保险与许可范围

1. 调用车辆须检测合格、投保有效；驾驶员具备对应从业资格（豁免情形写清）。替换车辆不得降低许可条件。
2. 客运班线许可事项（起讫地、停靠站点、日发班次下限、车辆数量、经营期限）和包车牌：本技能只检查合同线路是否超出许可范围。超出则属于程序硬伤，修改句把许可办妥设为生效条件或改合同范围。班线／包车细则不在本技能展开。
3. 货运按货类核定经营范围。许可证是“普通货运”、合同写冷藏危化或班线客运：要么变更许可，要么改合同货类／业态，否则把许可办妥设为生效条件。
4. 保险：营运客车承运人责任险、货车第三者责任险和货运险分开投保。4.5 吨以下车辆常被忽略投保承运人责任，结构里必须补民事承运人责任安排。保险人拒赔不影响承运人对相对人的赔偿。
5. 4.5 吨以下普通货车虽免营运证，仍须交强险、检验合格。
6. 材料未提及不得写成“许可有效、保险足额、车辆合格”。

## 节点 6　转包、超载迟延与管辖

1. 允许转包的，转包对象须具备同等许可；对旅客或托运人，缔约承运人负责。禁止“转包后本合同自动终止”。对内书面保留追偿和保险受益，不在本任务起草内部追偿整稿。
2. 因超载、超限被路政或治超扣车导致迟延：原则上不能作为不可抗力。货规 2023 第 26 条禁止违法超限超载。修改句删除该拟制。不可抗力必须符合民法典第 180 条“不能预见、不能避免且不能克服”；核验失败则该法律结论停止，仍可要求删除“超载扣车视为不可抗力”。迟延后发生的不可抗力依第 590 条不免除违约责任。
3. 交通事故人身伤害常可在侵权行为地诉讼。合同管辖不得试图排除人身伤害的法定连结点。只标红旗，不选定唯一法院充作法律意见。或裁或诉、机构不明：标待核。
4. 政府指导价的班线客运不得在合同中加收许可外费用——点名即可，票价专项不在本技能展开。

## 节点 7　格式条款与无证民事效力

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 7.1 格式条款

为重复使用而预先拟定、订立时未与对方协商的免责、限责、管辖、单方调价：审查提示说明痕迹。小字、夹在附件、仅网络勾选不得写成已尽提示义务。造成对方人身损害的免责条款，核验后可引用第 506 条，不得写成“协商即可免除”。

### 7.2 无证与强制规范

无道路运输经营许可从事经营性道路客货运输：行政上违法（普通货运可对照货规 2023 第 61 条；客运处罚条号运行时重核）。民事合同效力结合民法典第 153 条与合同编通则解释第 16 条判断。实践中常认定合同有效但承运人承担行政责任和更重过错评价——这是争点，不得写成必然有效或必然无效。

危货无资质、客运无班线许可：履约风险高于普通货运，红旗告知，仍不得保证无效。

禁止用已失效“效力性／管理性”口诀代替解释第 16 条。
