# 国际航空运输合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点，以及《民用航空法》国际航空运输规则；实务只用来发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。华沙公约、蒙特利尔公约的适用条件、缔约情况和现行特别提款权限额必须运行时核验后再写限额、时效和管辖结论。不得把已失效《合同法》、《中国民用航空旅客、行李国际运输规则》（1997）、《中国民用航空货物国际运输规则》（2000）当作现行规则。不得把《国内航空运输承运人赔偿责任限额规定》第四十条万元、每公斤一百元写成国际运输限额。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、公约适用、限额、期限或管辖效力保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **运输合同 / 国际航空运输合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「国际航空运输合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、在途履约交底、伤亡或货损争议文书、有效性或必赔保证、把国内航空或海运提单文本改成可履行国际航空、按国内航空限额改完国际文本。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。本类型是**公约适用条件驱动的责任体制**，不是把国内航空限额换成外币后交差。禁止打开 `航空运输合同·审查`、`国内航空运输合同·审查`、`国际运输合同（涉外运输合同）·审查`、`客运合同·审查`、`货运合同·审查` 的 method。

1. **国际航空公约适用条件（第一硬闸）**：先填出发地点、约定经停地点、目的地点所属国。按《民用航空法》第一百零七条，三者之一不在中华人民共和国境内，才是国际航空运输。再核蒙特利尔公约适用条件：出发地与目的地在两个缔约国，或在一个缔约国但约定经停另一国。不符合蒙特利尔的，再核华沙／海牙体系。均不适用或公约未覆盖的事项，才回到第一百二十九条计算单位接口。条约与本法不同时，按第一百八十四条和法释〔2023〕15 号适用条约。强制适用情形下，合同不能排除或降低公约责任。未核缔约国和现行特别提款权：公约适用与限额字段停止。禁止手写过时金法郎或记忆中的特别提款权数字。
2. **不得按国内航空限额改完**：国际客票写“人身按国内四十万元”、国际货物写“每公斤一百元且不得声明价值”、或“只适用总部地法并排除公约”，必须改或红线。《国内航空运输承运人赔偿责任限额规定》第二条只适用于国内航空运输。禁止把国内限额改成等值外币后交差。三点均在境内 → `国内航空运输合同·审查`。无连结点切开 → `航空运输合同·审查`。跨境但不是航空方式 → `国际运输合同（涉外运输合同）·审查`。
3. **接续运输作为一项单一业务不得拆成国内段**：各方认为几个连续航空承运人办理的运输是一项单一业务的，视为一项不可分割的运输。禁止“国内段按国内限额、国际段另说”。
4. **缔约承运人与实际承运人；货代签主单不得装切开**：出票或签发航空货运单的人是缔约承运人，实际运营航段的人是实际承运人。旅客或货主可向双方主张。货代以自己名义签发主单并收取运费的，按缔约承运人审，不得因标题写“代理”假装已切开。
5. **空运单不是物权凭证；国际货运单须作公约声明**：航空货运单是合同订立、运输条件和收货的初步证据，不能套用凭正本提单放货。国际运输未填单或未按第一百一十五条第三项声明的，承运人无权援用第一百二十九条限额。
6. **管辖、异议、时效不得窄于强制规则；延误服务不消灭公约请求权**：管辖不得剥夺公约连结法院。行李七日、货物十四日、延误二十一日书面异议与二年诉讼时效不得擅自缩短。食宿签转履行不消灭公约延误请求权。机械故障通常不能当然免责。必须保留声明价值或特别协议通道。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签国际航空运输正文、国际运输条件、国际客票或航空货运单样张，尚未签署，尚未成争，核心给付是民用航空器运送旅客、行李或货物，且出发地、目的地或约定经停地至少一点不在中国领域内；用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 出发、约定经停、目的三点均在中华人民共和国境内 → `国内航空运输合同·审查`；
- 无连结点事实、来稿只定性为“航空运输”而不切开国内／国际 → `航空运输合同·审查`；未装则 `unavailable`；
- 跨境运输但主路径不是航空方式 → `国际运输合同（涉外运输合同）·审查`；未装则 `unavailable`；
- 两种以上不同运输方式且由经营人负责全程 → `多式联运合同·审查`；未装则 `unavailable`；
- 提单、海牙／海商法单位责任限制是主路径 → `海上货物运输合同·审查`；未装则 `unavailable`；
- 铁路运单、铁路保价与限额是主路径 → `铁路运输合同·审查`；未装则 `unavailable`；
- 只撮合订舱、不签发以自己为承运人的航空货运单、不收运费 → `货运代理合同·审查`；专业版未装则 `unavailable`；
- 对象是非航空的一般客运或一般货运，且无航空票证 → `客运合同·审查` 或 `货运合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `国际航空运输合同·起草`；
- 已签只问值机、在途、提货留痕 → 本套导航的履约步骤；
- 已催告、伤亡或货损索赔、解除、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

走私、禁运、未申报航空危险品、排除公约、用国内限额替代公约：只出告知，不改写成可履行承运结构。

## 建立审查坐标

确认：使用者与授权；单方立场（旅客／托运人侧或承运人侧择一）；相对方；全文及国际客票／航空货运单／运输总条件版本；出发地、约定经停地、目的地的城市和国家；是否作为一项单一国际运输；旅客、行李还是货物；代码共享与实际承运人；声明价值或特别协议；管辖与仲裁；异议与时效写法；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的运价、声明价值、特别提款权折算额用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验《民用航空法》第 106–108、115–118、124、126、128–137、139–143、184、188 条，民法典第 496、497、506、153、809 条，法释〔2023〕15 号第 1、2 条，以及《国内航空运输承运人赔偿责任限额规定》第 2、3 条的适用范围；`search_practiced` 只补审查反例；`search_template` 只借栏目结构。不虚构案件系统。

`search_law` 对公约适用条件、国际限额、排除公约条款效力和管辖／时效为 required 级：不可用时不拒绝执行，只停止效力字段。返回已失效《合同法》、1997 年国际旅客行李规则、2000 年国际货物规则、国内每公斤二十元货规，或把《国内航空运输承运人赔偿责任限额规定》当作本国际运输限额时记为噪声，不得写入 `L#`。

蒙特利尔公约、华沙公约正文若检索工具未返回全文：记录 `partial`，连结点与票证事实审查继续，现行特别提款权限额和公约条号结论字段停止，提示用官方条约文本核验缔约国与适用条件。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。禁止为对照打开 `航空运输合同·审查`、`国内航空运输合同·审查`、`国际运输合同（涉外运输合同）·审查`、`客运合同·审查`、`货运合同·审查` 的 method 或双文件。`基本面.md` 中“中国与多数国家之间优先适用蒙特利尔公约”不得写成未经核验的必然适用；须先核公约适用条件。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `国际航空运输合同·起草`；已签履约 → 本套导航履约步骤；已成争伤亡或货损索赔 → 合同争议。未签且目标是评改已有国际航空运输文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与国际连结点一致才继续。国内航空、航空总类、国际运输总类、多式联运、海运提单、铁路、只撮合货代负触发。货代签发航空货运单的，留下缔约承运人责任审查。

### 2. 公约适用条件核验

连结点国家 → 蒙特利尔适用条件 → 华沙／海牙 → 第一百二十九条接口。未核验不得写限额结论，也不得按国内限额改完。

### 3. 国内限额禁入、声明价值与责任项目

按人身、延误、行李、货物分列。删除国内四十万元和每公斤一百元。保留声明价值通道。

### 4. 接续运输、缔约与实际承运人

单一业务全程国际规则。代码共享披露。货代签主单按承运人审。

### 5. 票证、空运单与放货

公约声明。空运单非物权凭证。电子票证须识别承运人和连结点。

### 6. 管辖、异议、时效、延误接口

不得窄于强制规则。服务承诺不消灭公约请求权。

### 7. 格式条款与强制规范

无核验引文则法律结论字段停止。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、排除公约、用国内限额替代公约、把接续运输拆成国内段逃避公约、把走私／禁运或未申报航空危险品改成可承运、保证限额必然有效或对方必然全额赔。
- `字段停止`：法域、连结点国家、公约适用条件、缔约情况、现行特别提款权限额未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类（含国内航空、航空总类、国际运输总类、海运提单）。

生存级人身或货值或个人无限连带且用户拒绝升级：停止“可以签署”建议。
