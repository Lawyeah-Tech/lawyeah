# 边界与路由

本技能只审查 **运输合同 / 与劳务派遣合同易混淆的长期运输服务合同** 的待签文本。中文展示名是「审查与劳务派遣合同易混淆的长期运输服务合同（运输合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开下表邻类 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 公路机动运输、客货尚未拆开，无驻场供人、无员工手册、无人头月费 | `道路运输合同·审查`。禁止打开其 method；不审治超或 4.5 吨豁免专章 |
| 专项技术培训费用 + 服务期 + 按未履行期间分摊违约金 | `与培训服务期及派遣劳动原子切开：专项培训服务期→负触发`。禁止打开其 method |
| 旅客、客票、改退签、人身伤亡主路径，无驻场供人 | `客运合同·审查`。禁止打开其 method |
| 单票或一般货运、货损 / 运单 / 留置是主路径，无长期驻场供人混淆 | `货运合同·审查`。禁止打开其 method。本任务不复制货运留置 / 835 主路径 |
| 劳务派遣协议：持证派遣单位派人，用工单位指挥监督，按人头 / 工时结算 | `真实劳务派遣→`。禁止打开其 method。本任务不写三性、10%、派遣许可证放行路径 |
| 标题运输或司机外包，人完全服从委托方指挥和考勤、车属委托方、按人头结算 | 留本任务；点名供人 / 派遣外观；禁止只改标题；禁止改成可履行规避用工；用户改口要派遣合规 → `真实劳务派遣→` |
| 全日制劳动合同、用人单位与劳动者两方签约 | `全日制劳动合同→`。禁止打开其 method |
| 非全日制、小时工 | `非全日制→`。禁止打开其 method |
| 平等主体个人劳务、雇佣协议 | `个人劳务→`。禁止打开其 method |
| 两个组织之间承包非运输业务（保洁、保安、生产、销售），按成果或工作包交付 | `非运输业务外包→`。禁止打开其 method |
| 自然人包工头组织班组、按完成量结算 | `个人劳务承包→`。禁止打开其 method |
| 平台与从业人员接单、算法管理、注册 / 众包 / 新就业形态协议 | `或`。禁止打开其 method |
| 托运人与网络货运经营者、平台以承运人身份收运费开运输票 | `网络货运平台模式下的运输合同·审查`；专业版未装则 `unavailable` |
| 货源 / 运力信息撮合、平台不承运不收运费 | `一般信息中介平台模式下的合同·审查`；专业版未装则 `unavailable` |
| 承租人决定线路并自负运输对象风险，或只租车 | `承租人决定线路并自负运输对象风险的带驾租赁→` |
| 有完整待签文本要评改 | `类派遣长期运输·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、只问派车、运单、结算日履约 | 本套导航的履约步骤 |
| 已申请或拟申请劳动仲裁、要证据或应诉策略 | `已申请或拟申请劳动仲裁要证据或应诉策略` / `劳动仲裁证据整理`。本技能不审仲裁策略 |
| 工伤索赔整案 | `工伤索赔整案` 或劳动领域对应原子。本约只审工伤归属与内部追偿写法 |
| 已成争的普通合同路径 | `或对应专项领域。` 或劳动领域，不继续签前审查 |
| C 端大众快检 | 只分流，不回改 |

本约夹带劳动者劳动合同或派遣协议附件：附件整段交接 `全日制劳动合同→` 或 `真实劳务派遣→`；运输正文继续审。用户坚持本技能给出派遣三性 / 10% 放行、道路运输总类治超整案、货运留置整案、培训费分摊、仲裁胜率或工伤赔付终值：`目标停止`。

禁止在正文写半截 Skill ID。转出时必须写完整 ID，例如 `道路运输合同·审查`、`与培训服务期及派遣劳动原子切开：专项培训服务期→负触发`、`客运合同·审查`、`货运合同·审查`、`真实劳务派遣→`。
