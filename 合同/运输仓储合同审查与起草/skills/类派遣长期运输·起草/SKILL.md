# 类派遣长期运输·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。引用劳动合同法第五十七、六十六、九十二条时，使用 2012 年修正、2013-07-01 施行文本；2007 年第五十七条“注册资本五十万元”不得写入结论。不得把货运货损 / 留置主路径、道路运输总类治超、派遣三性 / 10%、培训服务期分摊硬套本类型。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **运输合同 / 与劳务派遣合同易混淆的长期运输服务合同**，输出可编辑草稿和未决项，并用本类型硬闸自审后给出风险表和修改句。待签评改转 `类派遣长期运输·审查`。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「类派遣长期运输·起草」。

`depends-on` 为空。不要求先跑导航。

不交付：道路运输总类审查、培训服务期审查、客运或货运整案、劳务派遣及相关劳动原子审查、他类文本审查、从零起草、履约交底、劳动仲裁或工伤索赔策略、有效性保证、把无证派遣或只供人结构改写成可履行规避用工结构。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **长期运输服务 vs 劳务派遣 / 劳动关系**：标的是完成旅客或货物位移，不是劳动力本身。承运人自备或租赁运力、自担运输风险、按运次 / 运量 / 台班取酬的，按《民法典》第八百零九条运输合同审查。人员接受委托方考勤奖惩、车辆属委托方、纯人头结算、对方无运输许可的，点名用工 / 派遣外观；《劳务派遣暂行规定》第二十七条：以承揽、外包等名义按劳务派遣用工形式使用劳动者的，按照该规定处理。禁止只改标题。禁止把三性、10%、派遣许可证写成**本类型**放行条件。禁止把供人结构改成可履行规避用工。
2. **人员管理权**：承运人享有对驾驶员的劳动管理权；委托方只下达运输计划（时间、地点、货量或班次）。禁止“驾驶员须遵守甲方员工手册并接受甲方处罚”、对个人打卡、按个人扣工资、要求穿着委托方工号。进厂安全交底和门禁可以接受。承运人可更换符合标准的驾驶员和车辆，委托方无正当理由不得指定固定自然人。
3. **人车油捆绑**：车辆由承运人提供或承租，燃油、维修、年检、保险由承运人负责。委托方提供车辆、只供人的，须重新评估是否还是运输合同；补车辆权属和运输计价，否则停止按运输放行。
4. **与道路运输总类、客运、货运切开**：客货尚未拆开、无驻场供人外观 → 负触发 `道路运输合同·审查`。一般客运且无用工外观 → 负触发 `客运合同·审查`。单票或一般货运且无长期驻场供人混淆 → 负触发 `货运合同·审查`。禁止打开上述 method。
5. **与培训服务期及派遣劳动原子切开**：专项培训服务期 → 负触发 `与培训服务期及派遣劳动原子切开：专项培训服务期→负触发`。真实劳务派遣 → `真实劳务派遣→`。全日制劳动合同 → `全日制劳动合同→`。非全日制 → `非全日制→`。个人劳务 → `个人劳务→`。非运输业务外包 → `非运输业务外包→`。个人劳务承包 → `个人劳务承包→`。平台接单 → `或`。禁止打开上述 method。
6. **计价与发票**：按运次、里程、运量或台班 + 油价联动。纯人头月费应改为包车运输包月价，并写最低出车次数和车辆台数。发票开运输服务，不得开劳务派遣或人头费。
7. **承运人责任与用工隔离**：货损按第八百三十二、八百三十三条，旅客伤亡按第八百二十三条；不得写成“由驾驶员个人赔偿”。工伤、社保、工资由与驾驶员有劳动关系的承运人承担。内部负担约定不得对抗劳动者。安全生产法第五十二条禁止免除或减轻对从业人员因生产安全事故伤亡的责任。本约运输争议走民事诉讼，劳动争议由驾驶员与用人单位依法处理。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。禁止把甲方员工手册、对个人考勤和纯人头费写成行业惯例可放行。

## 工作边界

正触发：已有可读待签长期运输或包车运输正文，尚未签署，尚未成争，核心给付是承运人在较长时期内持续提供车辆、驾驶员和运输组织并完成位移，用户问能否签、哪里必须改、怎么回对方。标题写成派遣 / 外包 / 司机租赁但给付仍是运输任务的，留本任务，点名易混红旗，按硬闸改人车油、管理权和计价。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 公路机动运输、客货尚未拆开，无驻场供人外观 → `道路运输合同·审查`；禁止打开其 method；
- 专项技术培训费用 + 服务期 + 分摊违约金 → `与培训服务期及派遣劳动原子切开：专项培训服务期→负触发`；禁止打开其 method；
- 旅客、客票、改退签主路径且无用工外观 → `客运合同·审查`；禁止打开其 method；
- 单票或一般货运、货损 / 运单 / 留置是主路径且无长期驻场供人混淆 → `货运合同·审查`；禁止打开其 method；
- 真实劳务派遣：持《劳务派遣经营许可证》、用工单位指挥、按人头 → `真实劳务派遣→`；禁止打开其 method；
- 用人单位与劳动者两方劳动合同 → `全日制劳动合同→`；禁止打开其 method；
- 非全日制 → `非全日制→`；个人劳务 → `个人劳务→`；非运输业务外包 → `非运输业务外包→`；个人劳务承包 → `个人劳务承包→`；平台接单 → `或`；均禁止打开其 method；
- 承租人决定线路并自负运输对象风险 → `承租人决定线路并自负运输对象风险的带驾租赁→`；
- 网络货运以承运人身份收运费 → `网络货运平台模式下的运输合同·审查`；仅信息撮合 → `一般信息中介平台模式下的合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问派车、运单、结算日履约 → 本套导航的履约步骤；
- 已申请劳动仲裁、工伤索赔、立案、开庭 → 劳动领域或 `或对应专项领域。`，不审仲裁或工伤策略。

用户改口要一份派遣协议 → 整段交接 `真实劳务派遣→`，本任务不写三性 / 10% 放行路径，不打开其 method。无证派人、只供人仍要按运输放行：只出告知与红线，不改写成可履行规避用工结构。

## 建立审查坐标

确认：使用者与授权；单方立场（委托方或承运人择一）；相对方；全文及附件、运单 / 派车单样张版本；核心给付是运输位移还是供人；车辆权属、油费和保险在谁名下；计价是运次 / 运量还是纯人头；现场谁考勤、谁有权处分驾驶员；承运人道路运输许可是否被提及；驾驶员劳动合同与社保缴纳单位；发票品目；争议条款；不可接受事项；法域与拟签署日。缺立场或无可读书面文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 起草模式

本原子只承担本类型起草。待签评改转 `类派遣长期运输·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。本约标的是完成旅客或货物位移，不是劳动力本身；不把供人结构改成可履行规避用工。

1. 先按框架六步落稿：首部锁承运人自备运力与运输许可；交易条款写人车油捆绑、委托方只下达运输计划、按运次／运量／台班计价；配套写承运人责任与工伤隔离、运输服务发票；尾部写本约走民事诉讼；正说反说后按下述必写与禁忌落句。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿。自审至少核对：有无甲方员工手册／对个人考勤／纯人头费、车辆是否承运人提供、发票是否开运输服务。输出风险表和修改句。不得只交白稿。
3. 道路运输总类、一般客运／货运、培训服务期、真实派遣或劳动合同出稿、已签履约、已成争：仍负触发。

**起草必写**：标的是完成旅客或货物位移。承运人自备或租赁运力、自担运输风险、按运次／运量／台班取酬。承运人享有对驾驶员的劳动管理权；委托方只下达运输计划（时间、地点、货量或班次）。车辆由承运人提供或承租，燃油、维修、年检、保险由承运人负责；承运人可更换符合标准的驾驶员和车辆，委托方无正当理由不得指定固定自然人。计价按运次、里程、运量或台班＋油价联动；纯人头月费应改为包车运输包月价，并写最低出车次数和车辆台数。发票开运输服务。货损按第八百三十二条、第八百三十三条，旅客伤亡按第八百二十三条；工伤、社保、工资由与驾驶员有劳动关系的承运人承担。本约运输争议走民事诉讼，劳动争议由驾驶员与用人单位依法处理。

**附件必附**：车辆权属或承租及油料、维修、年检、保险归属材料（人车油捆绑）；运单或派车单样张。

**禁止出现**：驾驶员须遵守甲方员工手册并接受甲方处罚；对个人打卡、按个人扣工资、要求穿着委托方工号；委托方提供车辆、只供人仍按运输放行；发票开劳务派遣或人头费；货损或人身由驾驶员个人赔偿；内部负担约定对抗劳动者；免除或减轻对从业人员因生产安全事故伤亡的责任；把三性、10%、派遣许可证写成本类型放行条件。

### 0. 签署状态与成果分流

无书面文本 → 起草；已签履约 → 本套导航履约步骤；已成争或工伤索赔 → 劳动领域或争议原子。未签且目标是评改已有长期运输 / 派遣易混文本。评改待签文本转配对审查原子，不在本任务评改。

### 1. 类型锁死与邻类切开

标题、核心给付与对价方式一致才继续。道路运输总类、客运、货运、培训服务期、真实派遣、劳动合同负触发。标题运输但供人外观主导：留本任务并点名。

### 2. 主体与运输许可

签约名、履行名、付款名、发票名分列。驾驶员不得列为与委托方的劳动合同主体。经营性运输未见匹配许可：字段停止，不写“可以营运”。

### 3. 人车油与管理权

车辆权属、油料维修保险、谁调度、谁考勤、谁有权处分驾驶员。

### 4. 运输任务与运单

客运或货运、线路或区域、响应时效、车辆类型和数量、是否含装卸。每班派车单 / 运单作为合同组成部分。

### 5. 计价与发票

计费依据、最低出车或运量、油价联动、发票品名。

### 6. 承运人责任、工伤与追偿

货损 / 人身落到承运人；工伤由承运人作为用人单位承担；内部追偿不得对抗劳动者。

### 7. 解除、争议与附件

承运人丧失许可或车辆；委托方长期不给运输任务却按人头要人。本约走民事诉讼。附件：车辆清单、驾驶员名单（注明系承运人员工）、许可证、保险。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持保留甲方员工手册 / 对个人考勤 / 纯人头费仍按运输放行、把无证派遣改成运输外壳、保证有效、倒签或补假运单 / 许可、要求把供人改成可履行规避用工。
- `字段停止`：法域、运输许可真伪、车辆权属、社保缴纳单位未核验。
- `目标停止`：主目标已变为待签评改、履约交底、道路运输总类审查、客运 / 货运整案、培训服务期审查、派遣协议审查、劳动仲裁或工伤策略。

生存级工伤或人身风险且用户拒绝升级：停止“可以签署”建议。
