# 航空运输合同·审查

## 任务目标

在单一立场下，只审查 **运输合同 / 航空运输合同** 的待签文本，输出连结点识别表、风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「航空运输合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、已签履约交底、伤亡或货损争议文书、有效性或航班必准点／货必无损保证、把国内限额规定与华沙／蒙特利尔写成同一主路径、把挂靠或无许可经营性公共航空运输改成可履行结构。

## 本类型硬闸

每闸必须出修改句或明确停笔／转出口径，禁止只打红黄绿。民用航空法是本技能特别法，民法典运输合同章只作一般法底板。禁止把国内航空与国际航空并进本原子，禁止把任一子级限额表粘贴后换标题交差。

1. **总括航空运输 ≠ 国内航空 ≠ 国际航空（分装硬闸）**：先填出发地点、约定经停地点、目的地点。三点均在中华人民共和国境内的**单一国内运输** → `国内航空运输合同·审查`；未装则 `unavailable`，本技能不得展开《国内航空运输承运人赔偿责任限额规定》精算。出发地点、目的地点或约定经停地点之一不在中国境内，或几个连续承运人办理的运输作为一项单一国际业务的 → `国际航空运输合同·审查`；未装则 `unavailable`，本技能不得展开华沙公约、蒙特利尔公约或民用航空法第 129 条精算。一份文本同时覆盖国内与国际、连结点空白或冲突、或写“按民航规定／视同国内／排除公约”的，**留本技能强制分流**：必须加连结点识别表，客货分项，国内段与国际段分文本；禁止共用一段限额、异议期或管辖。
2. **华沙／蒙特利尔不得误套国内**：1929 年华沙公约、1955 年海牙议定书、1999 年蒙特利尔公约只可能作用于第 107 条意义上的国际航空运输。三点均在境内的国内运输印刷“适用华沙／蒙特利尔”、华沙金法郎或蒙特利尔特别提款权：红线。国际航段用国内每公斤人民币限额或“视同国内”排除公约：红线。华沙与蒙特利尔选哪一部，交 `国际航空运输合同·审查`。
3. **航空运输 ≠ 包机湿租 ≠ 地面／售票代理 ≠ 多式联运 ≠ 公路／铁路／海商**：出具客票或航空货运单并负责运达的，才是本类型。只提供航空器与机组、由对方决定航线任务的，转租赁／包机路径或引擎重新定性。只做值机、装卸或代售客票、不承运的，不是承运人。两种以上不同运输方式且经营人负责全程 → `多式联运合同·审查`。公路运政／铁路运单／海商法提单为主路径，分别转对应原子。货代以自己名义签发航空货运单并收取运费的，按本类型承运人审，**不得假装已经切开**。
4. **公共航空运输经营许可**：企业从事公共航空运输，应当向国务院民用航空主管部门申请领取经营许可证，并按许可证载明的经营范围经营。无许可：行政违法，合同不当然无效，经营能力字段停止，不写“可以经营”。不得转让、出租、挂靠许可证。
5. **客票／行李票／航空货运单；客货分轨**：客票、行李票、航空货运单是合同订立和运输条件的初步证据。未出示或不符规定不影响合同存在。国内运输不出票或不填货运单，承运人可能无权援用第 128 条；国际运输不出票、不填单或未按第 110／115 条声明的，可能无权援用第 129 条。航空货运单通常不可转让，禁止写成海运提单。旅客人身、随身物品、托运行李、货物必须分项，不得共用一段责任条款。
6. **禁止一句“按民航规定”；禁止混用国内限额与公约**：国内运输指向民用航空法国内部分及《国内航空运输承运人赔偿责任限额规定》；国际运输指向民用航空法国际部分及中国参加的国际航空公约。任何旨在免除法定责任或降低法定限额的条款无效，但不影响合同其余部分。国内航线印刷蒙特利尔或华沙、国际航线改走国内每公斤人民币限额、“排除公约”“视同国内”“人身最高赔一倍票价”：红线。限额数字精算分别交给子级，本技能只出分流句。
7. **代码共享／缔约承运人与实际承运人／连续运输**：出票或签发货运单时披露实际承运人。缔约承运人对合同约定的全部运输负责；实际承运人对其履行的运输负责。连续运输是否一项不可分割的单一业务必须写明。内部代码共享协议不得对抗旅客或货主。
8. **延误超售、声明价值、危险品、运输总条件、失效客货规**：告知、签转、食宿与法定赔偿责任分开写。机务维护、航班调配、机组调配属于承运人原因，通常不得写成不可抗力。已提供餐饮不当然消灭法定请求权。超售按承运人超售处置规定赔偿，不得写成旅客违约。行李和货物须提供声明价值并支付附加费的入口。锂电池、活体、冷链按航空危险品规则，不是普通包装问题。运输总条件须可保存文本和版本号，不能只写“见网站”；国内、国际运输总条件应分文本。删除已失效 1996 年国内客规／货规、1997 年国际客规、2000 年国际货规、1989／1993 年旅客身体损害赔偿暂行规定。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签航空运输正文，尚未签署，尚未成争，核心给付是使用民用航空器运送旅客或货物并收取票款或运费，且民用航空法、客票或航空货运单、公共航空运输经营许可、代码共享或国内／国际连结点识别构成审查主路径；来稿是父级总类、连结点混合或空白，或用户问国内国际能不能写在一段里，或问华沙／蒙特利尔能不能印到国内航段。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 出发地、约定经停地、目的地均在中国境内，全文只走国内航空限额主路径 → `国内航空运输合同·审查`；未装则 `unavailable`，不得用本技能把国内限额精算做完；
- 任一点不在中国境内，或接续运输作为一项单一国际业务，全文只走华沙、蒙特利尔或第 129 条主路径 → `国际航空运输合同·审查`；未装则 `unavailable`，不得用本技能把公约精算做完；
- 通篇只走民法典客运或货运节、无航空特别法主路径 → `客运合同·审查` 或 `货运合同·审查`；
- 只撮合舱位或车源、不承运、不以自己名义签发客票或航空货运单 → `货运代理合同·审查` 或 `房屋买卖或租赁中介→`；P1 未装则 `unavailable`；
- 只提供航空器与机组、由对方决定航线任务、不出具客票或货运单 → 引擎重新定性或动产租赁路径，不按本类型承运人限额审；
- 两种以上不同运输方式且由经营人负责全程 → `多式联运合同·审查`；未装则 `unavailable`；
- 道路运政许可、车辆道路运输证、治超或道路危货资质是主路径 → `道路货物运输合同·审查`；
- 铁路运单、铁路保价与限额是主路径 → `铁路运输合同·审查`；未装则 `unavailable`；
- 提单、海商法单位责任限制是主路径 → `海上货物运输合同·审查`；未装则 `unavailable`；
- 无文本、本类型条件已谈妥、要出己方稿 → `航空运输合同·起草`；
- 已签只问值机、在途、签收留痕 → 本套导航的履约步骤；
- 已催告、伤亡或货损索赔、解除、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

走私、禁运、无许可经营性公共航空运输、挂靠出借许可证、排除人身伤害、排除公约、国内航段套用华沙或蒙特利尔：只出告知，不改写成可履行承运结构。

## 建立审查坐标

确认：使用者与授权；单方立场（旅客／托运人侧或承运人侧择一）；相对方；全文及客票／航空货运单／运输总条件版本；核心给付是航空承运还是包机湿租／代理／多式联运；出发地、约定经停地、目的地；是否接续运输作为一项单一业务；对象是旅客、行李还是货物；缔约承运人与实际承运人；公共航空运输经营许可痕迹；是否代码共享；是否声明价值；是否危险品；延误／超售条款；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的票价、运费、货值、许可文号、限额数字用 `【待填】`，不编造。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》运输章、1996 年《中国民用航空旅客、行李国内运输规则》、1996 年《中国民用航空货物国内运输规则》、1997 年《中国民用航空旅客、行李国际运输规则》、2000 年《中国民用航空货物国际运输规则》、1989／1993 年《国内航空运输旅客身体损害赔偿暂行规定》、1995 年《民用航空法》第 92 条原文当作现行规则。不得把国内航空限额精算或华沙／蒙特利尔特别提款权精算硬套为本技能同一主路径。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `航空运输合同·起草`；已签履约 → 本套导航履约步骤；已成争伤亡或货损索赔 → 合同争议。未签且目标是评改已有航空运输文本，才进入本任务。

### 1. 类型锁死与国内／国际分装

标题、核心给付与航空特别法主路径一致才继续。单一国内 → `国内航空运输合同·审查`。单一国际 → `国际航空运输合同·审查`。包机湿租、只撮合货代、一般客运／货运、多式联运、公路／铁路／海商负触发。货代签发航空货运单的，留下承运责任审查。

### 2. 华沙／蒙特利尔误套检查

国内段出现华沙、海牙议定书或蒙特利尔：红线删除。国际段出现“视同国内”或国内每公斤人民币限额：红线改回公约路径并转出子级。本技能不选公约、不算特别提款权。

### 3. 公共航空运输经营许可

许可范围与航线、主运营基地分列。未核许可：字段停止。不得默认可以经营，也不得写成合同当然无效。

### 4. 客票、货运单与客货分轨

客票／货运单是初步证据。空运单不可按提单写。旅客、行李、货物分项。

### 5. 分流条款、代码共享、连续运输

删除“按民航规定／视同国内／排除公约”。披露实际承运人。连续运输是否单一业务落句。

### 6. 延误超售、声明价值、危险品、运输总条件

承运人原因不得写成不可抗力。声明价值入口。航空危险品单独成条。运输总条件可保存、分国内国际文本。删除失效客货规。

### 7. 格式条款与强制规范

无核验引文则法律结论字段停止。第 130 条降低限额条款无效。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证航班必准点或货必无损、把走私／禁运或无许可经营性公共航空运输改成可承运、把挂靠或出借许可证改成可履行、坚持排除人身伤害／排除公约／视同国内／人身只赔一倍票价、坚持国内国际共用一段限额、坚持把华沙或蒙特利尔印到国内航段。
- `字段停止`：法域、连结点、许可文号、货性是否危险品、公约是否强制适用未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类（含单一国内航空、单一国际航空、一般客运／货运、包机湿租、多式联运）。

生存级人身或货值或个人无限连带且用户拒绝升级：停止“可以签署”建议。
