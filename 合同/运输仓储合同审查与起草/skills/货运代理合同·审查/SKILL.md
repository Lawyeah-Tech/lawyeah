# 货运代理合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、已失效《汽车货物运输规则》、已失效《国内水路货物运输规则》、已失效 1997 年《道路货物运单使用和管理办法》、国际海运条例 2001 年第 7 条“已被修改”文本当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **运输合同 / 货运代理合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。中文名必须是「货运代理合同·审查」。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。

`depends-on` 为空。不要求先跑导航。

不交付：他类合同审查；从零起草；履约交底；争议文书或货损索赔策略；有效性保证；把承运合同、网络货运平台运输合同或信息中介合同按本类型改完；把无船承运或自己名义签单假装已经切开；把走私、骗税、夹藏或无单放货改成可履行结构。禁止抄写一般货运、道路货物、海上货物的保价、限额、掌管期间或道路许可主路径。禁止打开 `多式联运合同·审查`、`道路运输合同·审查`、`网络货运平台模式下的运输合同·审查`、`一般信息中介平台模式下的合同·审查`、`客运合同·审查`、`货运合同·审查` 的 method。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **货代是委托，不是承运人；也不是纯信息中介**。默认法律性质是委托合同：核心给付是处理运输事务（订舱、报关、报检、拖车、仓储、保险代办、单证），委托人支付代理费，一般适用过错责任。不是亲自把货运到目的地。出现“负责运至”“门到门责任”“安全运达”，或自己调度车辆/舱位并收全程承运对价的，按承运承诺修改或接受承运人责任。只报告订约机会、不代订舱、不收运费、不开运费发票的，是中介合同，负触发 `一般信息中介平台模式下的合同·审查`。不得用口语“中介”把货代审成纯撮合，也不得用标题“代理”把承运放行。
2. **无船承运 / 以自己名义签发提单：定性切开**。货代以自己名义签发提单、海运单、道路运单或其他运输单证，或以承运人代理人名义签发但不能证明取得承运人授权的，委托人主张其承担承运人责任，现有依据支持。无船承运是以承运人身份订约、签单、收运费的国际海上运输经营活动，不是货代外衣。标题写“代理”、正文写“只是代理，货损概不负责”，不得假装已切开到承运原子。必须二选一：禁止以承运人身份签单，或就该票按承运人承担责任并同步备案与保险。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签货运代理正文，尚未签署，尚未成争，核心给付是处理货物运输及相关事务，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 核心给付是承运位移、自己签发承运人运单并收运费、承诺运达 → 对应承运原子：道路货物特别法主路径 `道路货物运输合同·审查`，海上货物/提单限额 `海上货物运输合同·审查`。**签单混写不得因负触发而假装承运责任已审完**；本技能仍须写出身份转换句再交接；
- 网络货运平台与托运人的运输合同、平台入驻/调度规则 → `网络货运平台模式下的运输合同·审查`。P1：专业版未装则 `unavailable`；
- 只提供车源/舱位信息撮合，不代订舱、不收运费、不开运费发票 → `一般信息中介平台模式下的合同·审查`。P1：未装则 `unavailable`。不得改走房屋中介 `房屋买卖或租赁中介→`；
- 两种以上运输方式且经营人签发多式联运单据、对全程负责 → `多式联运合同·审查`；
- 只存货、出仓单、不对位移负责 → `普通货物仓储合同·审查`；
- 旅客、客票 → `客运合同·审查`；
- 无运输事务的一般委托、贸易行纪 → `无运输事务的一般委托贸易行纪→` / `以自己名义买入再转卖货物`；
- 无文本、本类型条件已谈妥、要出己方稿 → `货运代理合同·起草`；
- 已签只问订舱日、交单日、代垫结算 → 本套导航的履约步骤；
- 已催告、解除、货损索赔、无单放货诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

走私、骗取退税、夹藏伪报、出借国际货代备案或无船承运资格：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（委托人侧或货代侧择一）；相对方；全文及委托书/签单样本/费率附件版本；核心给付是代为办理、纯信息撮合还是承诺运达；签单抬头与 as carrier / as agent 栏；是否无船承运外观；费用是代理费、代垫还是包干差价；是否网络货运平台外观；国际货代备案或无船承运备案痕迹；转委托与实际承运人披露；不可接受事项；法域、口岸或起运地与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。禁止为对照打开承运、网络货运或信息中介原子的 method。`框架.md` 中的“航海过失”等承运人法定免责不得写给纯代理人；“门到门责任”“全程负责”按改定性处理。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `货运代理合同·起草`；已签履约 → 本套导航履约步骤；已成争或货损/无单放货诉讼策略 → 合同争议。未签且目标是评改已有货代文本，才进入本任务。

### 1. 身份三角：委托 / 中介 / 承运

标题、核心给付与对价方式一致才继续。纯信息撮合、真承运、网络货运、多式联运、仓储负触发。签单混写：不假装已切开。

### 2. 无船承运与自己名义签单

House B/L / 自己的运单必须与身份条款一致。无船承运按承运人处理。备案未核：字段停止。

### 3. 主体、备案与签单抬头

签约名、履行名、开票名、签单抬头分列。国际货代备案、无船承运备案未核：不写“可以签单展业”，不宣告民事合同当然无效。

### 4. 委托事项、指示与签单样本

逐项勾选。倒签、预借须书面。无书面指示不得操作。

### 5. 费用性质：代理费、代垫、包干差价

包干且不披露实际承运人运费的，按缔约承运人设计责任与保险，不得享受纯代理过错原则。

### 6. 转委托、转交单证与扣单

运输单证原则上不得因未付费扣留。留置范围不得扩到无关货物或退税资料。

### 7. 格式条款、强制规范与违法通关

“一切损失概不负责”作为格式条款易无效。走私、骗税、夹藏：停笔。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、预借、伪造签单授权；保证有效或保证货必无损；把走私/骗税/夹藏改成可履行；把签单承运外观改回“只负过错且货损概不负责”仍要放行。
- `字段停止`：法域、动态规则、国际货代备案、无船承运备案、网络货运许可、地方口岸操作未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁承运/网络货运/中介他类整案。
