# 边界与路由

本技能只审查 **运输合同 / 水路货物运输合同** 的待签、内河／湖泊／国内封闭或半封闭水域货运文本。中文展示名是「审查水路货物运输合同（运输合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或复制 `水路运输合同·审查`、`水路乘客运输合同·审查`、`海上货物运输合同·审查`、`多式联运合同·审查`、`客运合同·审查`、`货运合同·审查` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 售票载客；人身伤亡、客票、行李主路径 | `水路乘客运输合同·审查` |
| 只写“水运协议／水路运输合同”，未标明客运或货运 | `水路运输合同·审查` |
| 经海路、指示提单、国际航线、海牙／维斯比、海商法第四章免责或单位责任限制为主路径 | `海上货物运输合同·审查` |
| 海上运输总类，尚未落入货物或旅客 | `海上运输合同·审查` |
| 海上旅客运输 | `海上乘客运输合同·审查` |
| 公路车辆、道路运输经营许可、路政超限、4500 千克豁免为主路径 | `道路货物运输合同·审查` |
| 未锁定水路区段的一般货运框架 | `货运合同·审查` |
| 只撮合订舱、报港、转运，不签发以本人为承运人的运单 | `货运代理合同·审查` |
| 两种以上运输方式且经营人负责全程 | `多式联运合同·审查` |
| 只存货不位移 | `普通货物仓储合同·审查` |
| 网络货运平台、无车／无船承运平台规则 | `网络货运平台模式下的运输合同·审查` |
| 铁路运单、铁路保价与限额主路径 | `铁路运输合同·审查` |
| 航空货运单、民用航空法限额主路径 | `航空运输合同·审查` |
| 有完整待签文本要评改 | `水路货物运输合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、只问装船日、到港通知、滞期起算 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或对应专项领域。` 或对应专项领域 |
| 货损索赔、无单放货、海事诉讼或仲裁已立案 | 海事或争议专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

内河货运正文里夹带一小段海商法免责或道路运政许可：专章删除或交接对应原子；水路区段位移条款可继续审。用户坚持本技能把海上货运、道路货运、水路客运或货代整案改完：`目标停止`。

货代标题、却以自己名义签发水路运单并收取运费：留本技能，按承运人认定，不得转出后假装已切开。

专业版未收录的 P1 场景不会安装本原子。若用户拿本类型文本来找专业版：输出 `unavailable`，提示，不得用 `海上货物运输合同·审查` 或 `货运合同·审查` 硬套。
