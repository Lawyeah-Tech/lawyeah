# 水路货物运输合同·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **运输合同 / 水路货物运输合同**，输出可编辑草稿和未决项，并用本类型硬闸自审后给出风险表和修改句。待签评改转 `水路货物运输合同·审查`。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「水路货物运输合同·起草」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证货必无损或限额必然有效。

## 本类型硬闸

1. **运单是合同组成部分，国内水路运单 ≠ 海运提单**。长期协议＋航次运单是常态。运单记载货物状况、收货人、运费。未签框架合同但已签收运单并装船的，合同成立。禁止“运单仅供结算／仅供内部使用”。国内水路运单通常不可转让，不得按海运提单设计“凭指示、可背书、凭正本提单放货”。与框架冲突时必须选定：货物状况、收货人、到达港以运单为准，责任限制、管辖以框架为准（或相反，必须写明）。标题或正文以指示提单、海牙／维斯比、海商法第四章为主路径的，负触发 `海上货物运输合同·审查`，不得删提单句后硬套本技能。
2. **货损走第八百三十二、八百三十三条；禁止海商法免责搬家和失效货规**。承运人掌管期间毁损灭失承担（法定免责除外）。不得把航海过失、管船过失、火灾免责或海商法单位责任限制搬进内河合同当当然规则。无特别法限额的，按到达地市场价格赔实际损失。约定限额须合理并单独确认。禁止“货损只赔运费／概按运费赔偿／已保险即承运人免责”。禁止引用已失效的《国内水路货物运输规则》或《水路货物运输合同实施细则》。到港检验走第八百三十一条：未异议只是按运输单证记载交付的初步证据，不得写成最终免责。
3. **不得按海商法海上货物运输改完**。纯内河、湖泊及国内封闭或半封闭水域走本类型。海商法第二条：第四章不适用于中华人民共和国港口之间的海上货物运输，更不适用于纯内河。江海直达先拆航区。禁止打开或复制 `水路运输合同·审查`、`水路乘客运输合同·审查`、`海上货物运输合同·审查`、`多式联运合同·审查`、`客运合同·审查`、`货运合同·审查` 的 method。
4. **甲板货必须书面同意**。须书面记载“同意装于甲板”及水湿、浪损风险分配。口头同意视为未约定。
5. **危险货物书面说明＋包装标志**（第八百二十八条）。匿报、普货夹带危货：承运人可拒运。走私／禁运：停笔。无许可危化当普通货：红线。
6. **运费、留置、提存、变更闭环**。不可抗力致货物灭失：未收运费不得再要，已收应返还（第八百三十五条）。留置限于相应运输货物（第八百三十六条）。拒领或收货人不明走提存（第八百三十七条），不是擅自变卖。交付收货人前托运人可中止／返还／变更到达港或收货人，但应赔偿承运人损失（第八百二十九条）。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签内河／湖泊／国内封闭水域货运正文或运单样张，尚未签署，尚未成争，核心给付是货物在水路区段的完好位移与到港交付，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 售票载客、人身伤亡规则主路径 → `水路乘客运输合同·审查`；
- 只写“水运协议”未分流客货 → `水路运输合同·审查`；
- 经海路、指示提单、国际航线、海牙／维斯比或海商法第四章主路径 → `海上货物运输合同·审查`；海上运输总类未落入货物或旅客 → `海上运输合同·审查`；
- 公路车辆、道路运输经营许可、路政超限主路径 → `道路货物运输合同·审查`；
- 未锁定水路区段的一般货运框架 → `货运合同·审查`；
- 只撮合订舱、不签发以本人为承运人的运单 → `货运代理合同·审查`；货代以自己名义签发水路运单的，**不得假装已经切开**，按承运人审本约；
- 两种以上运输方式且经营人全程负责 → `多式联运合同·审查`；
- 只存货不位移 → `普通货物仓储合同·审查`；港口作业另约且本约不含掌管期间位移的，不按本类型改完；
- 网络货运平台、无船承运平台规则主路径 → `网络货运平台模式下的运输合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问装船日、到港通知、滞期起算 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁 → `或对应专项领域。` 或海事／争议专项。

挂靠船舶、无船倒运单、违法转包给无许可人：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及运单／货物清单／危货说明／保险单版本；装港、卸港、是否过闸、是否经海路；货物品名件数重量包装收货人；是否危货／甲板货／冷藏／散货；运费预付或到付；货损限额或保价；留置范围；变更指令；承运人许可与船舶营运证痕迹；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 起草模式

本原子只承担本类型起草。待签评改转 `水路货物运输合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`，不编造。

只起草内河、湖泊及国内封闭或半封闭水域货运。经海路、指示提单、海商法第四章为主路径的，负触发海上货运。不得按海商法海上货物运输改完。

### 起草必写

- 运单是合同组成部分。运单记载货物状况、收货人、运费。未签框架合同但已签收运单并装船的，合同成立。国内水路运单通常不可转让。与框架冲突时必须选定：货物状况、收货人、到达港以运单为准，责任限制、管辖以框架为准（或相反，必须写明）。
- 货损走民法典第八百三十二、八百三十三条。承运人掌管期间毁损灭失承担（法定免责除外）。无特别法限额的，按到达地市场价格赔实际损失。约定限额须合理并单独确认。到港检验走第八百三十一条：未异议只是按运输单证记载交付的初步证据。
- 甲板货必须书面记载“同意装于甲板”及水湿、浪损风险分配。
- 危险货物书面说明＋包装标志。
- 运费、留置、提存、变更闭环：不可抗力致货物灭失，未收运费不得再要，已收应返还。留置限于相应运输货物。拒领或收货人不明走提存。交付收货人前托运人可中止／返还／变更到达港或收货人，但应赔偿承运人损失。

### 附件必附

- 货物清单、运价表、运单样张、保险单。
- 危货时：危货说明。甲板货时：书面甲板货确认。解释顺序写清。

### 禁止出现

- “运单仅供结算／仅供内部使用”。按海运提单设计“凭指示、可背书、凭正本提单放货”。
- 航海过失、管船过失、火灾免责或海商法单位责任限制搬进内河合同。
- “货损只赔运费／概按运费赔偿／已保险即承运人免责”。引用已失效《国内水路货物运输规则》或《水路货物运输合同实施细则》。
- 未异议写成最终免责。口头同意甲板货。
- 走私／禁运；无许可危化当普通货。拒领后擅自变卖。挂靠船舶、无船倒运单、违法转包给无许可人：只告知，不起可履行稿。

出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

### 0. 签署状态与成果分流

本类型条件已谈妥、要出己方稿 → 本任务起草并自审；有完整待签文本要评改 → 配对审查原子；已签履约 → 本套导航履约步骤；已成争 → 合同争议或海事专项。未签且目标是评改已有内河货运文本。评改待签文本转配对审查原子，不在本任务评改。

### 1. 类型锁死与航区切开

标题、核心给付与对价方式一致才继续。海上货运、道路货运、水路客运、货代只撮合、多式联运负触发。不得按海商法海上货物运输改完。

### 2. 主体、许可与船舶

缔约承运人对全程水路段负责。许可与船舶营运证未核则字段停止，不减轻货损义务。

### 3. 货物特定化与甲板货／危货

品名件数重量包装收货人；散货计重方式；甲板货书面同意；危货书面说明。

### 4. 运单效力：国内水路运单 ≠ 海运提单

运单是合同组成部分。禁止仅供结算。国内运单通常不可转让。

### 5. 货损、限额与失效货规

832／833／831；删除海商法免责搬家；删除国内水路货规。

### 6. 运费、滞期、留置、提存、变更

835／836／837／829。待闸滞期须有起算点，禁止“按港口习惯”空转。

### 7. 格式条款与强制规范

无核验引文则法律结论字段停止。走私／禁运／无许可危化不得改成可履行。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、走私禁运仍运、无许可危化当普货、把本约改成海上货运或道路货运外壳仍放行。
- `字段停止`：法域、动态规则、许可编号、航区是否经海路、到达地市价、待闸免费时间未核验。
- `目标停止`：主目标已变为待签评改、履约交底、争议文书，或已锁他类。
