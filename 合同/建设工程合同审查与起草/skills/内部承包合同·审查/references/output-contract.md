# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的上缴比例、保证金、奖金；把已失效《合同法》及其解释、1997 年建筑法未修正文本、建市〔2014〕118 号或 2002 年安全生产法第 49 条旧编号写入结论；输出争议胜率或对外免责终局；把本约改成挂靠协议、施工总包本约或劳务分包正文；把假社保、假任命写成可履行路径。

## 1. 触发、单方立场与成果状态

立场（建筑企业或内部承包职工）、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查内部承包合同（建设工程）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、1997 年建筑法未修正文本、建市〔2014〕118 号、2002 年安全生产法第 49 条旧编号时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `建设工程`，子级 `内部承包合同`。定性理由、易混切开结果（尤其与 `建设工程施工合同·审查` 施工总包、`劳务分包合同·审查` 劳务分包、`挂靠合同（借用资质合同）·审查` 挂靠的切开）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。假内部承包写明留本任务并点名，不转成 `挂靠合同（借用资质合同）·审查` 实体审查，除非用户改口要挂靠文本——即便改口也只告知，不出可履行挂靠稿。

## 4. 主体、职工身份、资质与文本版本

主体表：企业签约名（须具备建筑业资质）、承包人姓名/职务、是否在册职工、劳动合同/社保/工资是否被提及、关键岗位五类人员、付款账户名、授权签字人。版本表：正文、项目目标责任书、保证金缴纳证明、主合同摘要、资金/用印制度、聊天确认；冲突并列。口头“他马上办社保”不得写成已具备真实劳动关系。资质或职工身份未见则该签署能力字段停止。

## 5. 管理从属、资金账户与印章闭环

技术/质量/安全/进度/财务是否由企业统一负责；资金是否进公司账户；大额支出审批；项目章保管与对外授权；结算是上缴包干还是目标奖金。缺口标 `G#`。不输出亏损填补或连带金额终值。

## 6. 挂靠红旗、对外责任与强制规范

非职工承包；只收管理费；关键岗位非本单位人员；承包人自主对外采购主材并支配资金；项目章外放；“公司不负责结算/对外概不负责”；本约争议误走劳动仲裁。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和删除句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得输出假社保入职路径；不得把本约改写成挂靠、施工总包或劳务分包条款；不得把对外免责写成已切断法定责任。

## 9. 谈判与签署提醒

谈判顺序：先红线（非职工承包拒改、只收管理费拒改、对外免责切断法定责任、账户和印章外放、要求改成可履行挂靠），再必须改（职工身份附件沉默、关键岗位未写本单位人员、资金审批沉默、项目章范围过宽、民工工资路径、安全巡检），最后可优化。签署提醒：劳动合同/社保/工资流水复印件、项目目标责任书、保证金缴纳证明、主合同摘要、资金与用印制度、关键岗位任命书作为附件；企业盖公章，承包人亲笔签署。不指导倒签、补假社保或伪造任命痕迹。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本技能只出审查意见和修改句，不出整份起草终稿；出稿转 `内部承包合同·起草`。不是履约交底、挂靠协议审查、施工总包审查、劳务分包审查、争议文书、效力保证。
