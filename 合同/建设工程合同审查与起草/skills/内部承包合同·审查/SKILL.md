# 内部承包合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构，内部承包无统一示范文本。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、法释〔2004〕14 号、法释〔2018〕20 号、建市〔2014〕118 号或 1997 年建筑法未修正文本当作现行规则。
- 建筑法条号引用 2019 修正。律页若先返回 1997 文本并标“已被修改”，改引 2019 修正第 26、28 条，不把旧令号写入 `L#`。安全生产法条号引用 2021 修正；律页若先返回 2002 年第 49 条（从业人员佩戴防护用品），记噪声，不得当作发包统一协调条款。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。

## 任务目标

在单一立场下，只审查 **建设工程 / 内部承包合同** 的待签企业内部经营管理文本（签署方为具备建筑业资质的企业与其内部职能部门、分支机构或在册职工），输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。显示名为「内部承包合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：挂靠合同审查、施工总承包本约审查、劳务分包审查、专业分包审查、劳动者劳动合同专项审查、他类文本审查、从零起草、履约交底、建设或劳动争议策略、有效性保证、把挂靠或出借资质改写成可履行内部承包。

## 本类型硬闸

1. **内部承包 vs 挂靠**：本约是企业内部管理文件，不是平等主体间对外施工合同。承包人须为本企业职工，企业须对技术、质量、安全、进度、财务、劳务、材料、设备实施实质性统一管理。仅收管理费、承包人非职工、关键岗位非本单位人员、承包人自主对外采购主材并支配资金：点名挂靠或转包红旗。建市规〔2019〕1 号第 9、10 条；分包管理办法（2019 修正）第 11、15 条。禁止只改标题。
2. **对外仍由资质企业担责**：对外施工、采购、用工、质量、安全的责任主体仍是取得资质的建筑企业。内部“亏损自担、对外免责、公司不负责结算”不得对抗业主、材料商、农民工或受害人。解释一第 7 条；民法典第 172 条；工资条例第 30 条。
3. **只告知不改可履行挂靠**：名为内部承包、实为出借资质或只收管理费：只出告知与改道，不写假社保、假任命、可履行挂靠稿。用户坚持“改到能签/能过检查仍由外部人自主施工”：整体停止。不在本任务起草 `挂靠合同（借用资质合同）·审查`。
4. **职工身份与关键岗位本单位人员**：项目负责人、技术负责人、项目核算负责人、质量管理人、安全管理人本单位人员（合法人事或劳动合同、工资及社会保险）。临时补缴社保不能单独证明劳动关系真实。分包管理办法第 11 条。
5. **资金进公司账户、印章公司管控**：项目资金必须进入企业账户，支出经公司财务审批直付供应商/工人；项目章仅限现场技术往来，对外签约、举债、债权确认须法人授权。禁止承包人私设账户或自管公章。
6. **与施工总包、劳务分包、挂靠切开**：业主与施工企业的按图施工本约 → `建设工程施工合同·审查`。平等主体劳务作业分包 → `劳务分包合同·审查`。承认借用资质、无真实隶属 → 告知后点名 `挂靠合同（借用资质合同）·审查`。禁止抄施工总包或挂靠 method。
7. **必须出修改句**：禁止只打红黄绿。每个风险回链文本位置。

禁止把“改个标题就不是挂靠”“公司不负责结算即可免责”写成行业惯例可放行。

## 工作边界

正触发：已有可读待签内部承包或项目目标责任正文，尚未签署，尚未成争，签署方是资质企业与其内部机构或在册职工，核心给付是授予特定项目经营管理权并约定内部考核与盈亏，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 业主与施工企业的按图施工本约 → `建设工程施工合同·审查`；
- 设计+施工一体对发包人 → `工程总承包合同·审查`；
- 人+材+机+专业技术管理的专业分包 → `专业分包合同·审查`；
- 平等主体劳务作业换劳务报酬 → `劳务分包合同·审查`；
- 用户主文本是挂靠/借用资质协议，或明确要求审查如何把挂靠做成可履行 → 告知后点名 `挂靠合同（借用资质合同）·审查`，本任务不代做挂靠审查；
- 用人单位与劳动者两方劳动合同专项 → `用人单位与劳动者两方劳动合同专项→`；
- 无文本、本类型条件已谈妥、要出己方稿 → `内部承包合同·起草`；
- 已签只问进场、拨付日、审计日履约 → 本套导航的履约步骤；
- 已申请确认无效、实际施工人追索、欠薪群体事件、工伤立案 → 建设或劳动争议对应原子，不审争议策略。

标题内部承包但承包人非职工、企业只收管理费、关键岗位非本单位人员：留本任务，点名挂靠红旗，按硬闸改身份、资金、印章与管理从属；用户拒绝改正仍要“能签/能过检查”：整体停止。用户改口要一份挂靠协议：只告知违法，不在本任务出可履行挂靠稿。

## 建立审查坐标

确认：使用者与授权；单方立场（企业或内部承包职工择一）；相对方；全文及附件版本；承包人是否在册职工及劳动合同/社保/工资是否被提及；关键岗位是否本单位人员；资金账户与审批；项目章保管；对外采购/举债授权；主合同信息；结算是上缴包干还是目标奖金；民工工资发放路径；不可接受事项；法域与拟签署日。缺立场或无可读书面文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `内部承包合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 建设或劳动争议原子。未签且目标是评改已有企业内部承包文本，才进入本任务审查模式。实为挂靠：只告知，不起可履行内部承包外壳。

### 1. 类型锁死与邻类切开

标题、签署方与核心给付一致才继续。施工总包本约、劳务分包、专业分包负触发。承认借用资质、无真实隶属：告知后点名 `挂靠合同（借用资质合同）·审查`。假内部承包留本任务并点名。

### 2. 职工身份与关键岗位

劳动合同、工资、社保；项目负责人等五类人员是否本单位人员。

### 3. 实质性统一管理

技术、质量、安全、进度、财务、劳务、材料、设备是否由企业统一负责。

### 4. 资金账户与财务审批

资金是否进公司账户；大额支出是否公司审批直付。

### 5. 印章与对外授权

项目章范围；对外签约、举债是否须法人授权。

### 6. 对外责任与内部追偿

内部亏损分担不得对抗第三人；表见代理与出借资质连带。

### 7. 民工工资、安全、解除与劳动关系交织

专户/代发；安全统一管理；解除承包不等于当然解除劳动关系。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持非职工承包、只收管理费、项目章和账户外放、对外免责切断法定责任仍按真内部承包放行，或要求把挂靠改成可履行内部承包、保证有效、倒签或补假社保。
- `字段停止`：法域、劳动关系真实性终局、社保真伪、关键岗位是否真实委派未核验。
- `目标停止`：主目标已变为从零起草、履约交底、挂靠协议审查、施工总包审查、劳务分包审查、争议策略。
