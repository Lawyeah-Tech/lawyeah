# 独立发包合同（平行发包）·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **建设工程 / 独立发包合同（平行发包）**：发包人把施工总包范围之外的专项工程，直接发包给具备相应专业承包资质的承包人，双方直接签约、发包人直接付款；直接承包人与现场施工总承包人无合同关系，仅存在现场配合。输出可编辑草稿、未决项，并用本类型硬闸自审后给出风险表和修改句。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。显示名为「独立发包合同（平行发包）·起草」。待签评改转 `独立发包合同（平行发包）·审查`。

`depends-on` 为空。不要求先跑导航。

不交付：他类型起草；待签文本签前审查；履约交底；争议文书；有效性或对方接受的保证；把肢解发包、挂靠、无资质或必须招标未招改成可履行、可进场或可过验收结构；把本约改成甲指分包或 EPC 总包文本。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿；尚未签署，尚未成争；核心给付是发包人就**非主体、可独立完成的专项工程**与承包人直接建立施工承包关系，价款由发包人直接支付，现场另有或拟有施工总承包人负责主体工程，本约承包人只对专项范围负责。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 有完整待签文本要评改 → `独立发包合同（平行发包）·审查`；
- 签约主体是施工总承包人与分包人，或价款经总包转付、总包开票、总包结算 → `指定分包合同（甲指分包）·审查`；禁止打开其 method，禁止按甲指“指定权+总包签约”主路径改完；
- 设计+采购+施工或设计+施工一体、发包人要求主导、总价包干对质量安全工期造价负总责 → `工程总承包合同·审查`；禁止打开其 method，禁止套双资质/限额设计/单一责任主路径；
- 业主发包、承包人按图施工交付合格工程，且本约就是施工总承包本约 → `建设工程施工合同·审查`；禁止抄其黑白合同、先定后招、解释二固定价主路径来完成本任务；
- 总承包人经发包人同意把专业工程分包出去，总包与专业分包人签约 → `专业分包合同·审查`；
- 只出人工、不含主材、大型机械和技术管理 → `劳务分包合同·审查`；
- 出借资质、只收管理费、无真实隶属 → `挂靠合同（借用资质合同）·审查`；本任务只出告知并停笔，不改成可履行挂靠；
- 承包企业内部经营层或项目经理内部承包 → `内部承包合同·审查`；
- 勘察 / 设计 / 监理 / 咨询本约 → `建设工程勘察合同·审查` / `建设工程设计合同·审查` / `建设工程监理合同·审查` / `建设工程咨询服务合同·审查`；
- 无可读文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问进场、配合费支付、验收节点 → 本套导航的履约步骤；
- 已成争（催告、解除、索赔、鉴定、诉讼仲裁）→ `或` 或 `或`。

挂靠、肢解发包、无资质、必须招标未招：只出告知，不改写成可履行结构。用户坚持“改到能进场/能过检查/能拆成几家总包”：整体停止。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成。每一闸必须给出修改句或明确停笔/转出口径，禁止只打红黄绿。禁止抄施工总承包 `建设工程施工合同·审查` 或指定分包 `指定分包合同（甲指分包）·审查` 的 method 后换标题。

1. **界面与配合**。平行发包最大缺口是“三不管”地带。必须同时锁定：物理界面（预埋件、交接面、管线点位、谁收口）；时间界面（场地交付条件、与总体进度计划的嵌入、窝工调整）；成品保护；水电/垂直运输/脚手架等施工条件由谁提供；配合费金额、包含范围、承担主体（发包人代付或独立承包人自理）和“代收”定性。缺界面划分清单或缺交叉施工配合协议：必须改，不得用“服从现场管理”四个字放行。修改句方向：附件增加界面划分表和配合协议；写明总包切断水电或拒供垂直运输时的发包人裁决义务与时限；配合费未包含的事项不得另行加价卡进场。

2. **多总包风险**。同一建设项目上同时存在两家以上施工总承包或“准总包”，或把应当由一个承包人完成的单位工程、主体结构拆给数家承包人，属于肢解发包风险，不是“多家总包更省事”。发包人承担总协调，一家延误会触发后续全部索赔。不得把主体结构、框架梁柱或本应一家完成的单位工程改成可履行的平行发包。行政责任按建筑法 2019 修正第 24、65 条和质量管理条例 2019 修订第 7、55、78 条核验；民事上不得写成“肢解即合同必然无效”——解释一第 1 条未把肢解发包单列为无效事由，效力字段无核验则停止。修改句方向：主体结构收回施工总承包范围；多总包并存时补唯一现场总协调人、交叉索赔穿透和统保；用户坚持把主体拆成数家总包：停笔，不给出可进场结构。

3. **与甲指 / EPC 切开**。甲指：总包与分包签约，款项经总包转付。EPC：设计+采购+施工一体，承包人对质量安全工期造价负总责。本约必须是发包人与专项承包人直接盖章、发包人直接付款至独立承包人账户。标题写“独立发包”但正文是总包签约或总包代付结算 → 负触发 `指定分包合同（甲指分包）·审查`。标题写专项但正文要求承包人出图、采购并负总责 → 负触发 `工程总承包合同·审查`。禁止打开或复制上述 method，禁止把本约改成指定分包或总价包干 EPC。修改句方向：签约栏改为发包人—独立承包人；付款路径改为发包人直付；删除“总包有权代发包人解除本约/克扣专项工程款”的垂直合同权；出现设计+施工一体总责则整案转出。

附加必落句（有事实则单列，无事实在缺口节说明）：

- **直接支付闭环**：账户、节点、发票抬头均为独立承包人；总包代收配合费必须写“代收”，不得写成总包对专项工程款有结算权。
- **专项资质**：电子与智能化、消防、电梯/特种设备、幕墙、装修装饰等须对应专业承包资质或特种许可。无资质或超资质：红线，不写“签了再补证”。
- **三方现场关系**：独立承包人与总包无合同关系，但须接受总包在安全、文明施工上的统一调度；发包人是平行单位争议的最高裁决者。不得写成总包对本约享有合同解除权或价款决定权。
- **工期连锁**：因本约延误导致其他平行承包人或总包损失，发包人可从本约款项扣除并转付；因总包滞后导致本约窝工，须有补偿标准和工期顺延。
- **挂靠停笔**：出借资质、只收管理费，只告知，不改成可履行。

必须有修改句。每个风险回链文本位置。

## 建立起草坐标

确认：使用者与授权；单方立场（发包人或独立承包人，不得同时服务）；相对方；全文、专项范围、界面划分、总包合同中预留平行发包权利的条款、配合费约定、招标投标文件与附件版本；专项工程名称与是否触及主体结构；独立承包人专业资质是否被提及；现场是否已有或拟有施工总承包人、是否还有其他平行承包人；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 起草模式

本原子只承担本类型起草。有完整待签文本要评改时，转 `独立发包合同（平行发包）·审查`。本类型条件已谈妥、要出己方稿时，留在本任务按三闸落稿并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。按框架六步落稿。商业数字未给用 `【待填】`。出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。主体结构肢解、挂靠、甲指或 EPC 外观：停止包装成可履行平行发包。

**起草必写**

- 签约栏是发包人与专项承包人直接盖章；价款由发包人直接支付至独立承包人账户。
- 标的是非主体、可独立完成的专项工程；专项资质或特种许可证号与专业对应。
- 同时锁定物理界面、时间界面、成品保护、水电/垂直运输/脚手架由谁提供。
- 配合费金额、包含范围、承担主体和“代收”定性；总包切断水电或拒供垂直运输时的发包人裁决义务与时限。
- 独立承包人与总包无合同关系，但接受总包在安全、文明施工上的统一调度；发包人是平行单位争议的最高裁决者。
- 因本约延误导致其他平行承包人或总包损失，发包人可从本约款项扣除并转付；因总包滞后导致本约窝工，须有补偿标准和工期顺延。

**附件必附**

- 界面划分表与交叉施工配合协议。
- 专项资质或特种许可复印件。
- 总包合同中预留平行发包权利的条款或总包知情确认。
- 直接支付账户、节点与发票抬头安排。

**禁止出现**

- 把主体结构、框架梁柱或本应一家完成的单位工程拆成数家总包的可履行结构。
- 总包签约、总包代付、总包开票结算（那是甲指，负触发）。
- 要求承包人出图、采购并负总责（那是 EPC，负触发）。
- “总包有权代发包人解除本约/克扣专项工程款”。
- 用“服从现场管理”四个字代替界面清单。
- 把肢解发包、挂靠、无资质或必须招标未招包装成可进场。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、把肢解发包或挂靠或无资质或必须招标未招改成可履行/可进场/可过验收、把主体结构拆给数家总包、保证有效。
- `字段停止`：必须招标事实、专项资质等级、是否触及主体结构、现场总包是否存在、动态规则未核验；界面、配合费或工期关键事实缺失。
- `目标停止`：主目标已变为待签评改、履约交底、争议文书，或来稿实为甲指、EPC 或施工总承包本约。

生存级金额或个人无限连带且用户拒绝升级：停止放行建议。
