# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的回购基数、利率、工期；把已失效《合同法》及其解释、2015 年特许经营第 25 号令写入结论；把融资利息或投资回报写成当然优先受偿；把施工进度款、代建管理费或 DBO 运营考核当本类型主路径。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明是否切开施工 / EPC / DBO / 代建 / 特许经营。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、2015 年特许经营第 25 号令时记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级、子级、定性理由、易混切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读其他类型。挂靠、政府投资垫资、机关担保或把 BT 伪装成购买服务/特许经营，写停笔告知，不填可履行结构。

## 4. 主体、授权、资质与文本版本

主体表：签约名、履行名、付款名、发票名、投资人/施工资质、授权签字人、回购授权机关或决议。版本表：正文、附件、招标投标文件、中标通知书、融资计划、回购计划、移交清单；冲突并列，不选对用户有利的一版。

## 5. 给付闭环

融资义务、建设范围、移交确认书、回购价款分账（建安 / 利息 / 回报）、起算日、利率与调整、审计与合同价冲突规则、增信与登记、预算或规划证明。缺口标 `G#`，不补商业数字。批准、招标、预算、登记写成生效条件或期限，不写成已经完成。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹；异常条款（政府担保、购买服务支付回购、建成即移交视为特许、利息优先受偿、审计单方终局）。强制规范只区分是否导致民事行为无效。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔/转出口径。禁止输出无修改句的色块表。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`，不编造。禁止只给原则、不给句子。

## 9. 谈判与签署提醒

谈判顺序：先红线（举债/垫资/未招标/机关担保/伪装特许或购买服务），再必须改（移交确认书、分账、预算证明、增信登记），最后可优化。签署提醒：授权、用印、日期、附件清单、条件成就凭证。不指导倒签或补假预算、假招标、假担保。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本技能交付可编辑草稿、未决项、自审风险表和自审后修改句。草稿必须覆盖本类型起草必写、附件必附与禁止出现。待签评改转 `BT合同·审查`。不是履约交底、争议文书或效力保证。
