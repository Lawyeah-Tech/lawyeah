# 边界与路由

本技能只起草 **建设工程 / BT 合同**（投资人融资建设，竣工后移交，回购方分期支付回购价款的待签文本）。

| 主要目标 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 按图施工、建设期进度付款、无融资回购 | `建设工程施工合同·审查` |
| 编制岩土、水文地质等勘察文件 | `建设工程勘察合同·审查` |
| 编制方案、初步或施工图设计文件 | `建设工程设计合同·审查` |
| 设计+采购+施工或设计+施工一体，发包人出资、无移交后回购 | `工程总承包合同·审查` |
| 专业分包施工本约 | `专业分包合同·审查` |
| 纯劳务分包 | `劳务分包合同·审查` |
| 联合体成员之间的内部分工 | `联合体协议·审查` |
| 监理酬金换独立监督管理 | `建设工程监理合同·审查` |
| 造价、招标代理或工程咨询混签、主给付分不清 | `建设工程咨询服务合同·审查` 或引擎重新定性 |
| 设计+建造+长期运营，业主融资，不以回购收回投资 | `DBO合同·审查` |
| 政府将建设管理职责委托代建人，对价是代建管理费 | `切开` |
| 商业/资本/股权代建或代建+配资 | 对应委托合同代建原子；不得用本技能吞并 |
| 特许经营期内运营、使用者付费或可行性缺口补助、期满移交 | 引擎重新定性（特许/PPP）；不得把建成即移交改成特许经营外观 |
| 有完整待签文本要评改 | `BT合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审；与施工总包、DBO、代建切开 |
| 已签未争、履约节点（融资到位、移交、催回购款） | 本套导航的履约步骤 |
| 已成争（效力、回购款、优先受偿、隐性债务认定） | `或` 或 `或` |
| C 端大众快检 | 只分流，不回改 |

挂靠、必须招标未招、政府投资垫资、机关违规担保、把工程或融资包装成政府购买服务、把建成即移交包装成特许经营：留在本技能只出告知并停笔，不转去“改成可履行稿”，也不转争议原子充作签前修改。

专业版未收录的 P1 场景不会安装对应原子。若用户拿这些文本来找专业版：输出 `unavailable`，提示或回引擎，不得用本 BT 原子硬套。
