### **建设工程施工合同宏观交易结构知识库**

#### **第一步：合同类型（法律性质）分析**

1. **法律定性**
* **定义与构成**：建设工程施工合同是承包人进行工程建设施工，发包人支付工程价款的合同。属于《民法典》有名合同，该章未规定之事项，适用承揽合同有关规定。
* **本质特征**：属于双务、有偿、诺成、要式合同。其核心要素包括工程范围、建设工期、开工与竣工时间、工程质量标准、工程价款、技术资料交付及竣工验收等。


2. **易混淆辨析**
* **承揽与施工**：建设工程施工合同是特殊的承揽合同，但在资质要求、工程款优先受偿权、强制性招投标等方面受建设工程专门法律法规（如《建筑法》、《招投标法》）的严格规范，其强制性程度远高于普通承揽合同。
* **BT/BOT与施工总承包**：BT（建造—移交）模式实质上是带有融资性质（垫资）的施工合同；DBO（设计—建造—运营）模式下承包人不负责融资，而BOT（建造—运营—移交）中项目公司需负责融资，其合同性质具有投资属性。


3. **效力认定（高风险）**
* **违法无效情形**：
1. 承包人未取得建筑业企业资质或超越资质等级。
2. 没有资质的单位或个人借用（挂靠）有资质的建筑施工企业名义。
3. 建设工程必须进行招标而未招标或中标无效。
4. 承包人非法转包、违法分包建设工程。
5. 未取得建设工程规划许可证即签订施工合同（但在起诉前取得的除外）。


* **黑白合同**：依法必须招标的项目，当事人另行签订的与中标合同实质性内容（价款、工期、质量）不一致的协议（阴合同）无效，应以经过备案的中标合同（阳合同）作为结算依据。


4. **适用场景**
* 涵盖房屋建筑、土木工程、设备安装、管网铺设、装修装饰等各类新建、改建、扩建项目。



#### **第二步：合同主体（交易对手）分析**

1. **主体适格性**
* **资质等级**：承包人必须具备与工程规模、类型相匹配的资质类别（如总承包、专业承包、施工劳务）及等级。
* **安全生产许可**：承包人必须持有有效的《安全生产许可证》，否则可能被认定为不具备安全生产条件。


2. **特殊限制**
* **政府投资项目**：禁止由施工单位垫资建设。
* **跨区域施工**：需注意异地施工的企业备案和税务登记要求。


3. **高频风险**
* **挂靠风险**：挂靠人（实际施工人）与被挂靠企业之间的管理协议无效。发包人明知挂靠的，可能面临合同无效及连带赔偿风险。
* **项目经理授权**：需锁定项目经理身份及其授权范围，防范其违规签署签证、结算文件或对外借款导致企业承担表见代理责任。


4. **关联主体（重要）**
* **实际施工人**：在违法转包/分包链条末端的人员。根据司法解释，实际施工人可在特定条件下起诉发包人，在欠付工程价款范围内承担责任。
* **优先权人**：施工总承包人享有建设工程价款优先受偿权。通常认为分包人、勘察人、设计人不享有此项权利。



#### **第三步：合同标的（交易对象）分析**

1. **标的适格性**
* **合法报建**：标的物工程必须取得立项、规划、土地使用权证等前期批文。
* **严禁违法标的**：严禁针对违章建筑、禁止流通的特定敏感设施进行施工承包。


2. **权属与权利限制**
* **土地属性**：核查土地是否为划拨地或集体土地，这直接影响工程建成后能否办理产权证及优先受偿权的实现。
* **抵押/查封**：签约前需核实土地及在建工程是否存在抵押或法院查封，这会影响承包人工程款回收的安全性。


3. **风险转移规则**
* **法定节点**：建设工程风险在竣工验收合格之日移交给发包人。
* **擅自使用风险**：发包人未经竣工验收擅自使用的，以转移占有之日为风险转移及实际竣工日期。



#### **第四步：合同程序（交易步骤）分析**

1. **法定前置程序**
* **强制招投标**：关系社会公共利益、公众安全的设施及使用国有资金投资的项目（单项合同估算价  万元以上或施工单项  万元以上）必须招标。
* **施工许可**：开工前必须申领《施工许可证》。


2. **内部决策程序**
* **国企项目**：需履行“三重一大”决策程序、预算审批及上级备案。
* **上市公司**：涉及重大关联交易或达到披露标准的合同，需履行董事会/股东大会决议并公告。


3. **特殊交易程序**
* **竣工验收程序**：包括承包人提交竣工报告、发包人组织“五方主体”验收、质量监督机构监督、消防/规划验收及备案。
* **结算程序**：约定明确的结算书递交、审核期限及“逾期不回复视为认可”条款。



#### **第五步：交易结构设计（风险规避方案）**

1. **计价与支付设计**
* **模式选择**：固定单价合同（适用于工程量变化大）、固定总价合同（适用于设计深度足够、工期短的项目）、成本加酬金合同（适用于抢险救灾或新技术项目）。
* **款项构成**：设计预付款、进度款（按月或按节点）、竣工结算款、质量保证金（不得超过工程价款结算总额的 ）。


2. **担保措施**
* **双向担保**：发包人提供工程款支付担保；承包人提供履约担保、预付款保函、质量保函。
* **第三方监管**：在大型项目中，可引入银行对建设资金进行专项监管，确保专款专用。


3. **风险隔离设计**
* **分包安排**：通过合规的专业分包将特定风险转移给分包人，但在合同中需明确总承包人的管理责任与连带责任。
* **甲供材模式**：发包人自行采购大宗材料，以控制成本和质量，但需明确保管责任和损耗补偿机制。


4. **文本形态设计**
* **标准文本**：建议优先采用国家住建部发布的《建设工程施工合同（示范文本）》（GF-2017-0201）。
* **复杂合同群**：主协议 + 专用条款 + 工程量清单 + 技术规范 + 廉政协议 + 安全生产协议。



#### **第六步：宏观风险预警与尽调指引**

1. **高频争议点**
* **工程量与价款争议**：因设计变更、签证确认不及时导致的造价纠纷。
* **工期延误责任**：发包人未按时提供场地、图纸，或承包人施工组织不力导致的工期违约金争议。
* **质量缺陷责任**：保修期内质量问题的修复责任及对损失的赔偿。


2. **尽职调查清单**
* **发包人侧**：土地证、规划许可证、资金到位证明、企业信用记录。
* **承包人侧**：营业执照、资质证书、安全生产许可证、类似业绩证明、社保缴纳记录（核实人员真实性）。


3. **宏观风险预警**
* **项目停工风险**：发包人资金链断裂导致工程烂尾，承包人应及时行使停工权并固定证据。
* **合规风险**：警惕“名为联营实为挂靠”、“名为借款实为垫资”等规避监管的结构。
* **优先受偿权行使期限**：权利行使期限为  个月，自发包人应当支付工程价款之日起算。
