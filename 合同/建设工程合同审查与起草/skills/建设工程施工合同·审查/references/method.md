# 审查方法（锁定 建设工程 / 建设工程施工合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。

本文件是可执行判断节点。每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受或唯一必得金额。

`search_law` 返回已失效《合同法》及其解释、法释〔2004〕14 号、法释〔2018〕20 号、法释〔2002〕16 号（六个月优先受偿）时记为噪声，不得写入 `L#`。解释二条号以最高人民法院官网法释〔2026〕12 号为准；MCP 与官网冲突时以官网施行文本为准并记录冲突。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性。名实不符按核心给付归类，标题冲突写入 `C#`。

本类型成立条件：发包人发包施工；承包人按图施工、组织现场、交付合格工程；发包人支付工程价款；通常含主材或大型机械或技术管理中至少一项。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 只交出勘察报告、地质水文资料 | 建设工程勘察合同 | 负触发 → `建设工程勘察合同·审查` |
| 只交出施工图、方案设计，无现场施工组织 | 建设工程设计合同 | 负触发 → `建设工程设计合同·审查` |
| 只出人工，明确不含主材、大型机械和技术管理 | 劳务分包合同 | 负触发 → `劳务分包合同·审查` |
| 设计+采购+施工一体，或发包人要求主导 | 工程总承包合同 | 负触发 → `工程总承包合同·审查` |
| 经发包人同意的专业工程分包，主体结构仍由总包自施 | 专业分包合同 | 负触发 → `专业分包合同·审查`；本任务不把专业分包改写成施工总包 |
| 农村低层自建、私人室内装修，不受建筑法强制监管 | 项目承揽 | 负触发 → 引擎重新定性 |
| 出借资质、只收管理费、无真实隶属 | 挂靠 | 本任务停笔告知，不改可履行，不转去“包装成内部承包” |
| BT/融资回购、运营分成 | BT 或投资类 | 负触发 → 引擎；不按纯施工出稿 |

勘察、设计或纯劳务分包文本：**负触发**。不得用本技能硬套施工合同修改句。

### 1.2 加载协议（硬闸）

本技能已锁定 **建设工程 / 建设工程施工合同**。只打开 `references/基本面.md` 与 `references/框架.md`。禁止读其他子类型，禁止为对照再开第二类。

### 1.3 挂靠 / 违法分包停笔

加载后或定性中出现：借用资质、挂靠、违法分包、伪造内部承包、主体结构再分包、资金体外循环换管理费。

动作：

1. 交付告知：该结构违反建筑法、民法典第 791 条及解释一第 1 条、解释二第 3 条，不得改写成可履行文本。
2. 不写项目经理假任命、假社保、管理费结算、印章外借、可履行资金路径。
3. 风险表只保留识别依据和转出/改道提示。
4. 用户坚持“改到能签”：整体停止。

合规改道（真实专业分包、真实劳动关系）只点名，不在本任务起草。

## 节点 2　主体、资质、安全生产许可

1. 建主体表：签约名、履行名、付款名、发票名、项目经理、授权签字人。名称不一致不自动合并。
2. 承包人：建筑业企业资质类别与等级是否覆盖承包范围；安全生产许可证是否被文本或材料提及。项目经理个人无注册 ≠ 企业无资质，但项目经理必须锁定姓名、身份证号、注册建造师证号。
3. 发包人：土地使用权人与发包人不一致的，权利人签署或出具同意建设函；国资、政府投资、上市公司决议未附则签署能力字段停止。
4. 仅盖项目部章、未授权人员收款、收款进个人卡：标必须改或红线。
5. 口头“我们老板同意了”不得写成已授权。

不足：字段停止，列出待补材料，不补主体、不编造资质证号。

## 节点 3　招标、先定后招、黑白合同

运行时核验后再落效力结论。核验失败：摘录条款继续，效力字段停止。

### 3.1 必须招标

必须招标事实来自法律和项目资金来源、规模，不来自用户口头“应该招标”。依据不足则 `INV-招标` 标待核，不编造万元门槛。

| 已有事实 | 本任务动作 |
| --- | --- |
| 依法必须招标，文本无中标通知书、招标文件或投标文件 | 红线：补齐招标程序或停止放行 |
| 签约日早于中标通知书，或先签实质合同再补招标 | 解释二第 2 条：先定后招，中标合同无效。只告知，不改成“倒签至中标后即有效” |
| 中标前以意向书、会议纪要、补充协议谈工程范围或价款，且该投标人中标 | 同上，红线停笔 |
| 中标通知书发出超过三十日仍未按招标投标文件订书面合同 | 招标投标法第 46 条：标必须改；不指导倒签 |

### 3.2 禁止黑白合同

解释一第 2 条、第 22 条；招标投标法第 46 条。

- 另行协议改工程范围、工期、质量、价款，或让利、无偿配套、高价回购房产：阴合同不得作为结算依据，修改句删除或改为与中标合同一致。
- 不得建议“阳合同备案、阴合同履行”。备案不是结算要件。
- 用户要求保留两套价款：整体停止该部分，不给合法外观。

### 3.3 规划许可

解释一第 3 条：未取得建设工程规划许可证等规划审批手续，合同效力原则上受阻，但起诉前取得的除外。签前文本把规划许可写成生效条件或开工先决，不写成已经取得。发包人能够办理而未办理并以未办理主张无效，签前只点名该抗辩风险，不作出诉后效力终局。

## 节点 4　标的、权利负担、交付验收

1. 工程名称、地点、规模、承包范围必须落到附件《承包人承揽工程项目一览表》。只有“等”“有关工程”则标缺口。
2. 主体结构必须由承包人自行完成（民法典第 791 条）。文本允许主体结构分包：红线，按节点 1.3 停笔。
3. 权利负担：抵押、查封。材料未提及不得写成“无权利负担”。
4. 交付标准用文件说话：竣工验收合格报告、质量监督备案、约定的专项验收。禁止只写“综合验收合格”“具备使用条件”。
5. 签收、付款、擅自使用不当然等于验收。发包人未经竣工验收擅自使用的风险转移与实际竣工日，按解释一口径在修改句中点名，不在本任务认定已经竣工。
6. 缺陷责任期与保修期分列。保修期执行《建设工程质量管理条例》最低期限，不与质保金期限混写。

## 节点 5　价款、固定价、审计、质保金

1. 计价三选一并写死：单价 / 总价 / 成本加酬金。协议书与专用条款冲突则并列 `C#`，修改句统一，不选对用户有利的一版。未给出的数字写 `【待填】`。
2. **固定价（解释二第 9 条）**：约定固定价格结算的，建设工期内人工费、主要建筑材料价格重大变化原则上不调；另有约定或符合民法典第 533 条情势变更的除外。修改句：要么接受固定价并写明风险范围，要么另设调价公式或情势变更程序。不得把“原则上不调”写成绝对封死且预先排除第 533 条。
3. **审计（解释二第 13 条）**：约定以审计或财政评审为结算依据的，必须写合理出具期限；未约定时法院综合确定，但最长不超过承包人提交竣工结算文件之日起**一年**。逾期或明显不符，允许造价鉴定。未约定以审计为准的，发包人不得单方要求以审计结果结算。禁止放行“以财政审计为唯一依据且无期限”。
4. **质保金 3%**：预留比例不得高于工程价款结算总额的 3%，依据《建设工程质量保证金管理办法》第 7 条（建质〔2017〕138 号）。可用银行保函替代。  
   - **禁止**把 3% 上限写成解释二第 14 条。  
   - 解释二第 14 条只管：合同解除或无效未完工时，质保金以应得价款或折价补偿款为基数；返还期限从承包人退场之日起算，退场后才解除的从解除之日起算。
5. 账户：工程款进合同载明的承包人基本户或监管户；农民工工资进工资专户。禁止收款至项目经理个人卡。
6. 定金：必须使用“定金”二字才讨论罚则；超过主合同标的额百分之二十的部分不产生定金效力。无核验引文不得把 20% 写成现行法结论。
7. 政府投资项目写垫资建设：红线告知，不改成可履行垫资结构。

## 节点 6　格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 格式条款

为重复使用而预先拟定、订立时未与对方协商。采用 GF-2017-0201 不当然排除格式条款。提示说明按民法典第 496 条及合同编通则解释第 10 条。仅有勾选或弹窗，不得写成已尽提示。

### 6.2 强制规范

民法典第 153 条、合同编通则解释第 16 条。违反法律、行政法规强制性规定不一律无效。但本类型下列结构不得改写成可履行：

- 无资质、超资质、借用资质（解释一第 1 条、解释二第 3 条）；
- 必须招标未招或中标无效、先定后招（解释一第 1 条、解释二第 2 条）；
- 转包、违法分包、主体结构分包（民法典第 791 条）。

禁止用已失效“效力性/管理性”口诀或合同法解释（二）第 14 条代替解释第 16 条。

## 节点 7　优先受偿、违约、解除、争议解决

1. **优先受偿**：民法典第 807 条；解释一第 35、40、41 条；解释二第 17、21 条。  
   - 与发包人订立施工合同的承包人，就合格工程折价或拍卖价款优先受偿；最长十八个月，自发包人应当给付工程价款之日起算。  
   - **停工、窝工等损失不得计入优先受偿本金**（解释二第 17 条第二款）。修改句把停窝工损失列普通债权，不写入优先权范围。  
   - 应付日因工期顺延等客观原因变更的，期限自变更后的应付日起算（解释二第 21 条）。  
   - 放弃或限制优先受偿且损害建筑工人利益：解释一第 42 条，不得放行该弃权。  
   - 不得把优先受偿期限写成六个月。
2. 逾期付款与逾期竣工应对等：日违约金比率对称；超过同一天数可书面解除。解除后质量合格部分的结算，固定总价可走解释二第 10 条比例法，签前只预埋规则，不算定案金额。
3. 质量不合格：先通知承包人修复（解释二第 16 条），不得径直主张预付修复费。
4. 构成违约不等于当然解除。法定解除只点名催告或目的不能实现。
5. 争议解决：建设工程施工合同纠纷按不动产纠纷确定管辖。约定其他法院可能被认定无效。出现仲裁条款不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核。

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

打开已加载的 `框架.md`，按下列六步逐段对照正文。`基本面.md` 用于校验类型、主体、标的、程序、结构和红旗，不代替本节点出句。

| 步 | 动作 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题名实；发包人/承包人全称；资质与安许证号；项目经理三证；鉴于只写立项、规划许可、中标通知书编号 | 标题或主体修改句 |
| 交易条款 | 承包范围附件；价格形式与固定价风险；开工认定；验收文件名称；预付款/进度款/结算；农民工工资专户；审计一年出口；质保金≤3% | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 对等逾期违约；禁止转包挂靠；优先受偿催告与停窝工排除；保险担保；解除退场结算 | 可执行后果句 |
| 尾部 | 中标后三十日内签署；禁止项目部章；规划许可作生效条件；附件清单及解释顺序 | 生效与附件修改句 |
| 语言 | 正说还要有反说；盯死尽快支付、综合验收、原则上不调价、以审计为唯一依据且无期限、结算后再无任何权利 | 替换空词的句子 |
| 常见问题 | 协议书与专用条款价格形式冲突；黑白合同；审计无限拖延；质保金超 3% 或把 3% 写成解释二第 14 条 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

级别：

- `红线`：不改则建议不签或整体停止（无资质、先定后招、黑白合同、挂靠、主体结构分包、政府投资垫资）；
- `必须改`：可谈但签署前要落句（审计无一年上限、质保金超 3%、停窝工写入优先权、固定价无例外出口）；
- `可接受可优化`：仍要给句子，不得只标绿。
