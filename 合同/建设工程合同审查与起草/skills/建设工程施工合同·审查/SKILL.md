# 建设工程施工合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构，不证明本约条款已被接受。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、法释〔2004〕14 号、法释〔2018〕20 号或法释〔2002〕16 号当作现行规则。
- 解释二条号以最高人民法院官网公布的法释〔2026〕12 号为准。律页已收录时仍须与官网条号核对；官网与 MCP 冲突时以官网施行文本为准并记录冲突。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **建设工程 / 建设工程施工合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。`depends-on` 为空。

不交付：他类合同审查；从零起草；履约交底；争议文书；有效性或对方接受的保证；把挂靠、违法分包或先定后招改成可履行结构。

## 工作边界

正触发：已有可读待签正文及附件，尚未签署，尚未成争，核心给付是发包人发包施工、承包人按图施工并交付合格工程、发包人支付工程价款。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 核心给付是勘察或设计，或标题虽写施工但正文只交出地质/图纸成果 → `建设工程勘察合同·审查` 或 `建设工程设计合同·审查`；
- 纯劳务分包：只出人工、不含主材、大型机械和技术管理 → `劳务分包合同·审查`；
- 设计采购施工一体或发包人要求（Employer's Requirements）主导 → `工程总承包合同·审查`；
- 农村低层自建、私人室内装修等不受建筑法强制监管的承揽 → 引擎 本套导航的类型切开步骤 或项目承揽原子；
- 无可读文本、本类型条件已谈妥、要出己方稿 → `建设工程施工合同·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已成争（催告、解除、索赔、诉讼仲裁）→ `或` 或 `或`。

挂靠、违法分包、伪造内部承包、规避招标或先定后招：只出告知，不改写成可履行结构。用户坚持“改到能签”：整体停止。

## 本类型硬闸

执行时必须同时守住，不得用通用买卖/承揽口径替换：

1. **资质与招标**：承包人建筑业企业资质、安全生产许可、规划许可、依法必须招标事实先核。无资质、超资质、必须招标未招或中标无效，标红线；不写成“签了再补证就有效”。
2. **禁止黑白合同**：不得保留或起草背离中标合同工程范围、工期、质量、价款的让利、无偿配套、高价回购协议。结算依据是中标合同，不是“备案阳合同”。
3. **挂靠只告知**：出借资质、只收管理费、无真实隶属，只告知违法并停笔，不写项目经理假社保、印章外借或可履行资金路径。
4. **2026 解释二（法释〔2026〕12 号）**：先定后招或中标前实质性谈判 → 中标合同无效（第 2 条）；固定价期内人工主材涨跌原则上不调（第 9 条）；约定审计的合理期限最长不超过提交结算文件之日起一年（第 13 条）；停窝工损失不进入优先受偿本金（第 17 条）。
5. **质保金 3%**：预留上限挂住房城乡建设部、财政部《建设工程质量保证金管理办法》（建质〔2017〕138 号）第 7 条，不挂解释二第 14 条。第 14 条只管解除/无效未完工时的返还起算和计取基数。
6. **勘察、设计或纯劳务分包负触发**：不得用本技能硬套出施工合同修改句。

## 建立审查坐标

确认：使用者与授权；单方立场（发包人或承包人，不得同时服务）；相对方；全文、专用条款、招标投标文件、中标通知书与附件版本；工程名称地点承包范围；资质与许可材料是否被提及；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价格、工期、数量用 `【待填】`，不编造。

`基本面.md` 中的空白门槛、备案结算口径和未写入解释二的节点，以本技能 `method.md` 与运行时核验为准，不把知识库空白或过时表述写成现行法。

## 使用 Lawyeah MCP

宿主可调用时优先：

- `search_law`：民法典第 791、793、807 条；解释一（法释〔2020〕25 号）第 1、2、3、22、35、40、41 条；解释二（法释〔2026〕12 号）第 2、9、13、14、17、21 条；招标投标法第 43、46 条。质保金 3% 若律页未收录管理办法，改核官方文本，不得改挂解释二第 14 条。
- `search_practiced`：黑白合同、先定后招、挂靠识别的审查反例。
- `search_template`：只借 GF-2017-0201 栏目结构。

`search_law` 对法律结论为 required。不可用时不拒跑，只停止法律结论字段。返回失效合同法、2004/2018 建工解释或六个月优先受偿时记噪声，不得写入 `L#`。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、先定后招包装、黑白合同、把挂靠或违法分包改成可履行结构、保证有效。
- `字段停止`：必须招标事实、资质等级、规划许可、动态规则未核验；价款或工期关键事实缺失。
- `目标停止`：主目标已变为他类型起草、履约交底或争议文书。

生存级金额或个人无限连带且用户拒绝升级：停止放行建议。


无完整待签文本、本类型条件已谈妥、要出己方稿时，转 `建设工程施工合同·起草`，不在本审查原子起草。
