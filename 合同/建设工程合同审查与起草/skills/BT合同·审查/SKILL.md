# BT 合同·审查

## 任务目标

在单一立场下，只审查 **建设工程 / BT 合同** 的待签文本：核心给付是投资人融资并建设，竣工验收后移交，回购方按约定分期支付回购价款（建安工程费 + 融资利息 + 投资回报）。输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。显示名为「BT 合同·审查」。

`depends-on` 为空。不要求先跑导航。

主线是**建设—移交—回购**，不是按图进度付款，不是政府出资的代建管理费，也不是业主融资后的长期运营服务。

不交付：他类合同审查；从零起草；履约交底；争议文书；有效性或对方接受的保证；把纯政府付费 BT、政府投资垫资、必须招标未招、机关违规担保、挂靠或把 BT 伪装成特许经营/政府购买服务改成可履行结构。

## 工作边界

正触发：已有可读待签正文及附件，尚未签署，尚未成争；核心给付同时具备：（1）投资人承担建设期融资并组织建设；（2）竣工验收后向回购方移交项目；（3）回购方以回购价款（而非建设期进度款、代建管理费或运营分成）分期偿付投资。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 核心给付是按图施工、建设期按进度付款、无融资回购 → `建设工程施工合同·审查`；
- 设计+采购+施工或设计+施工一体、发包人出资、无移交后回购 → `工程总承包合同·审查`；
- 设计+建造+长期运营，业主通常负责融资，承包人不以回购收回投资 → `DBO合同·审查`；
- 政府将建设管理职责委托代建人，对价是代建管理费，政府为投资主体 → `切开`；
- 含特许经营期内运营并向使用者收费或可行性缺口补助、期满移交，且以运营收益回收投资 → 引擎重新定性（特许/PPP），不得用本技能把“建成即移交、政府纯付费回购”改成特许经营外观；
- 商业代建、资本代建、股权代建或“代建+贷款配资” → 对应委托合同代建原子，不得用本技能吞并；
- 编制勘察报告 → `建设工程勘察合同·审查`；出施工图 → `建设工程设计合同·审查`；监理 → `建设工程监理合同·审查`；咨询混签 → `建设工程咨询服务合同·审查` 或引擎；
- 联合体成员之间的内部分工文本 → `联合体协议·审查`；
- 无可读文本、本类型条件已谈妥、要出己方稿 → `BT合同·起草`；
- 已签只问融资到位日、移交日、回购款哪天催 → 本套导航的履约步骤；
- 已成争（催告回购、确认无效、优先受偿诉讼、隐性债务认定、立案仲裁）→ `或` 或 `或`。

挂靠、违法分包、必须招标未招、政府投资垫资、机关违规担保、把工程建设或融资包装成政府购买服务、把建成即移交包装成特许经营：只出告知，不改写成可履行结构。用户坚持“改到能签/先建后补招/机关出担保函就能放款”：整体停止。

## 本类型硬闸

执行时必须同时守住。每闸必须能落到修改句或明确停笔，不得用施工进度款、代建管理费或 DBO 运营考核替换。

1. **建设—移交—回购**  
   本类型成立必须同时读出三条链：投资人融资建设；竣工验收合格后签署《移交确认书》并转移占有/权属；回购价款自移交确认之日起算并按附件计划分期支付。回购价分账为建安工程费、融资利息、投资回报，三者不得混写成“工程款”。缺移交确认书、缺回购起算日、建设期仍按月进度付款且无融资义务：按核心给付负触发施工或总承包原子，不得硬套回购结构。  
   修改句方向：标题改为“建设工程 BT 投资建设合同”或“项目投融资建设移交协议”；标的写融资、建设、移交、回购全过程；增列附件《移交标准及清单》《回购款支付计划表》《融资计划书》；移交确认书签署日=回购起算日。

2. **特许 / 采购程序**  
   BT 含施工，落入依法必须招标范围的，须履行投融资与施工招标程序（可合一，但不得以“投资人直接指定”规避施工招标）。不得把工程建设或融资行为写成政府购买服务（财政部令第 102 号第 10 条明确排除货物、工程、工程与服务打包、融资行为）。不得把“建成即移交、政府纯付费回购”包装成基础设施特许经营：2024 年《基础设施和公用事业特许经营管理办法》第 7 条禁止在建设工程完成后直接将项目移交政府，或通过提前终止逃避运营义务；第 4 条将特许经营限定为基于使用者付费的合作。2015 年第 25 号令已失效。  
   修改句方向：鉴于条款锁定立项批复、招标文件、中标通知书；生效条件写明依法必须招标的已完成招标且合同与中标文件一致；删除“以政府购买服务预算安排支付回购款”“本合同即为特许经营协议、建成即移交”。未招标或先定后招：只告知，不改成倒签可履行。

3. **与 DBO `DBO合同·审查` / 政府代建 `切开` 切开**  
   DBO：业主融资，承包人设计+建造+长期运营，回收靠运营服务费或考核付费，不是移交后回购投资本息。政府代建：政府是投资主体并支付代建管理费，代建人不承担项目融资，也不得把“全额垫资+分期回购”改成代建外观。本技能禁止输出运营绩效考核表、使用者付费调价公式、代建管理费费率或“三方使用人接收”作为主路径，禁止打开其 method。  
   修改句方向：删除运营期分成、可用性付费绑定运营、代建管理费；恢复融资义务、移交确认书和回购计划。来稿主给付是运营或代建管理：负触发对应原子。

附加必落句（有事实则单列，无事实在缺口节说明）：

- **变相举债 / 政府投资垫资**：政府投资项目不得由施工单位垫资建设（《政府投资条例》第 22 条；《保障农民工工资支付条例》第 23 条）。地方政府及其所属部门不得以任何方式违法举债或对外担保（《预算法》（2018 修正）第 35 条）。纯政府付费、未纳入预算/中期规划的回购，合规高风险；不得改成可履行的规避结构。修改句要求出具纳入年度预算或中期财政规划、人大决议的证明作为生效附件；不能出具则字段停止或红线停笔。
- **回购价款分账与优先受偿切开**：建安工程费与解释一第 40 条工程价款范围对应后，才讨论第 807 条优先受偿；融资利息、投资回报、逾期利息、违约金不得写成当然优先受偿。放弃或限制优先受偿若损害建筑工人利益，不得按发包人主张认定承包人已丧失该权（解释一第 42 条）。
- **机关 / 政府不得担保**：机关法人不得为保证人（民法典第 683 条）；地方政府及其所属部门不得违法提供担保。修改句删除政府、财政局、机关出具的回购担保函、安慰函充作保证；改由适格平台公司以合法财产抵押、质押或金融机构保函增信，并完成登记。
- **利息口径**：普通施工垫资利息以解释一第 25 条为核验上限（同类贷款利率或同期 LPR），不得默认套用民间借贷 LPR 四倍。持牌金融机构资金成本另核，字段可停止。禁止默写 24%/36%。

必须有修改句。每个风险回链文本位置。禁止复制 `建设工程施工合同·审查`、`切开`、`DBO合同·审查` method。禁止半截 Skill ID。

## 建立审查坐标

确认：使用者与授权；单方立场（回购方/发包人、投资人/承包人，不得同时服务）；相对方；全文、专用条款、招标投标文件、中标通知书、融资计划书、回购款支付计划、移交标准、政府授权/批复、预算或人大决议附件版本；项目是否政府投资；是否主张特许经营或政府购买服务；投资人是否具备施工资质或合格联合体；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、先定后招、把政府投资垫资或纯政府付费未入预算的 BT 改成可履行、把工程或融资改成政府购买服务、把建成即移交改成特许经营外观、机关出具担保函、保证合同有效或保证利息优先受偿、挂靠出章。
- `字段停止`：必须招标事实、是否政府投资、预算/人大决议、资质、利率上限、解释二条号未核验；回购基数或利率关键事实缺失。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或来稿实为施工进度付款、DBO 运营或政府代建。

生存级回购金额、个人无限连带且用户拒绝升级：停止“可以签署”建议。


无完整待签文本、本类型条件已谈妥、要出己方稿时，转 `BT合同·起草`，不在本审查原子起草。
