# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的份额、金额、工期；把已失效《合同法》及其解释、民法通则联营条款、法释〔2004〕14 号、法释〔2018〕20 号写入结论；把对发包人的法定连带改成按份；把内部分工写成可对抗发包人；用民法典第 786 条排除建设工程联合体连带；把工程总承包对外文本、施工/分包主合同或无项目合伙当本类型审。

## 1. 触发、单方立场与成果状态

立场（牵头人、成员方或招标人/发包人审投标附件）、授权、签署状态、主要目标、项目名称与招标编号。负触发写路由，不启动实体审查。总承包对外文本、施工/分包主合同、无项目合伙、已成争必须在本节写明负触发，不得进入第 5–8 节。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、民法通则联营条款、2004/2018 建工解释或六个月优先受偿时记噪声，不得写入 `L#`。建筑法若返回 1997 文本改引 2019 修正。招标投标法若返回 1999 文本改引 2017 修正。实施条例若返回 2011 未修订文本改引 2019 修订。解释二条号与最高人民法院官网法释〔2026〕12 号不一致时记 `conflict`，以官网为准，并注明无联合体专条。

## 3. 类型与加载路径

父级、子级、定性理由、易混切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读总承包、施工或合伙目录。挂靠或出借资质写停笔告知，不填可履行结构。

必须写明已切开：总承包对外文本 / 施工主合同 / 专业分包 / 劳务分包 / 无项目合伙 / 挂靠。

## 4. 主体、授权、资质与文本版本

主体表：各成员签约名、拟履行专业、收款名、发票名、牵头人、授权签字人。各方资质类别、等级是否覆盖拟承担工作；同一专业是否已按较低等级确定联合体资质；不同等级联合是否落入较低一方许可范围。版本表：联合体协议正文、分工附件、授权委托书、资质复印件、招标文件资格条件、投标文件、对外主合同草稿、聊天确认；冲突并列，不选对用户有利的一版。

## 5. 给付闭环

拟共同投标或联合承包的项目与招标编号、牵头人职权、内部分工与资源投入、内部分成与资金通道（牵头人收付或共管账户）、内部保证金、决策机构与表决、中标后共同签约安排。缺口标 `G#`，不补商业数字。批准、备案、中标写成条件或期限，不写成已经完成。

必须单独回答：内部分工条款是否被写成可对抗发包人；对外主合同给付是否误入本协议。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹。强制规范只区分管理性与是否导致民事行为无效。本节点必须单独回答：对发包人连带是否被排除；内部分工是否被写成对抗发包人；就低不就高；书面协议是否随投标提交；是否禁止重复投标与资格预审后换员；是否共同签约。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

本类型风险表至少覆盖（有文本才填，无对应条款标缺口）：

- 是否真是成员间联合体协议（≠总承包对外文本 / 施工或分包主合同 / 无项目合伙）；
- 对发包人法定连带是否被改成按份或“另有约定除外”；
- 内部分工、份额、追偿是否被写成可对抗发包人；
- 各方资质与就低不就高；是否挂靠伪装；
- 书面协议随投标提交、共同签约、牵头人授权书；
- 重复投标禁令、资格预审后不得换员；
- 资金通道与截留风险；内部追偿是否可执行；
- 成员丧失资质或破产时的接管（须经发包人同意）；
- 擅自退出投标有效期或履约期。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。禁止输出无修改句的色块表。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`，不编造。禁止只给原则、不给句子。

连带修改句必须写明向发包人/招标人承担连带责任，并写“内部约定不得对抗发包人”。禁止输出“各方按分工各自向发包人负责”。

资金通道修改句不得只写“汇入牵头人账户”，须补分拨时限、查询权和截留后果。

## 9. 谈判与签署提醒

谈判顺序：先红线（类型切开、排除对外连带、内部分工对抗发包人、挂靠、重复投标/换员、仅牵头人对外签约），再必须改（牵头人授权书、分工附件、资金通道与追偿、丧失资质接管），最后可优化。签署提醒：全体成员法定代表人或授权代表签字并加盖单位公章；授权委托书原件随投标提交；日期不得晚于递交投标文件之日；不得指导倒签投标日或补假资质。招标人立场：中标后要求全体成员共同作为承包人一方签署对外合同。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本技能交付可编辑草稿、未决项、自审风险表和自审后修改句。草稿必须覆盖本类型起草必写、附件必附与禁止出现。待签评改转 `联合体协议·审查`。不是履约交底、争议文书、对外主合同审查或效力保证。排除连带/挂靠/换员已停笔的，本节重复告知一次。对外主合同另案走对应原子。
