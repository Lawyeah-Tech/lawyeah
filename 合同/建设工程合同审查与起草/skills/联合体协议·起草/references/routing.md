# 边界与路由

本技能只起草 **建设工程 / 联合体协议**（两家以上为同一建设工程共同投标或联合共同承包而订立的成员间待签文本）。

| 主要目标 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 联合体或承包人与发包人之间的设计+采购+施工、设计+施工一体主合同（发包人要求、总价包干、里程碑、缺陷责任期） | `工程总承包合同·审查` |
| 按图施工、交付合格工程的施工主合同 | `建设工程施工合同·审查` |
| 专业工程分包主合同 | `专业分包合同·审查` |
| 劳务作业分包主合同 | `劳务分包合同·审查` |
| 勘察 / 设计 / 监理主合同 | `建设工程勘察合同·审查` / `建设工程设计合同·审查` / `建设工程监理合同·审查` |
| 无建设工程项目背景的个人合伙 | `无建设工程项目背景的个人合伙普通合伙企业或联营→` |
| 无建设工程项目背景的普通合伙企业协议 | `或引擎重新定性；` |
| 无项目联营、合作经营，或只共同投资不投标不承包 | 引擎重新定性；不得用本技能套建筑法第 27 条 |
| 有完整待签文本要评改 | `联合体协议·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、履约节点（分拨日、共管账户对账、指挥部排班） | 本套导航的履约步骤 |
| 已成争（投标无效、对外连带追偿、成员互诉、解除索赔） | `或` 或 `或` |
| C 端大众快检 | 只分流，不回改 |

挂靠、出借资质、围标串标、资格预审后更换成员、排除对发包人连带、必须招标未招：留在本技能只出告知并停笔，不转去“改成可履行稿”，也不转争议原子充作签前修改。

中标后与发包人的对外主合同另案审查：施工走 `建设工程施工合同·审查`，总承包走 `工程总承包合同·审查`，不得在本任务改写对外文本。

专业版未收录的 P1 场景不会安装对应原子。若用户拿这些文本来找专业版：输出 `unavailable`，提示或回引擎，不得用本联合体原子硬套。
