# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给停笔告知句；保证挂靠有效或可以做成有效挂靠；保证法院必然判决无效；编造未给出的管理费、工程款、工期；把已失效《合同法》及其解释或法释〔2004〕14 号收缴条款写入结论；把本约改成可履行挂靠；把真实内部承包或合法分包留在本技能按挂靠改完；把知识库风控方案写成可签署条款。

## 1. 触发、单方立场与成果状态

立场（挂靠人/实际施工人、被挂靠人/名义承包人、拟签字项目负责人）、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明是否同时存在借用或出借名义、管理费或自负盈亏、无真实隶属。

用户目标若是“改到能签、做成可履行挂靠”：本节即写整体停止，后续只保留最小告知，不填可履行结构。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、法释〔2004〕14 号收缴条款时记噪声，不得写入 `L#`。借用资质效力、第 16 条是否被专条排除、质量连带、折价补偿、用工主体责任无 `verified-result` 时，对应法律结论字段停止。建筑法第 26、66 条若未核验 2019 修正文本，这两条不写入 `L#`。

## 3. 类型与加载路径

父级 `建设工程`，子级 `挂靠合同（借用资质合同）`。定性理由必须同时满足：借用或出借施工企业名义；管理费或自负盈亏或无真实隶属。易混切开：真实内部承包、专业分包、劳务分包、施工本约、联合体。

加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读其他类型、未打开 `内部承包合同·审查` 或施工/分包 method。借用资质写停笔告知，不填可履行结构。

## 4. 主体、授权、资质与文本版本

主体表：挂靠人、被挂靠人、对外签约名、付款名、发票名、授权签字人、项目负责人。自然人写姓名与证件号是否与文本一致；法人写名称与统一社会信用代码。资质证书是否被材料提及，未出示不得写成已核验。

版本表：挂靠或内部承包正文、授权委托、项目经理任命、劳动合同或社保材料、与发包人施工合同、聊天确认。冲突并列，不选对用户有利的一版。口头“已经是员工”“社保在办”不得写成已有真实劳动关系。

## 5. 识别信号与不得履行的给付闭环

分列并回链文本位置：

- 名义：谁出借资质、营业执照、企业名称、项目章。
- 对价：管理费、牌照费、固定上缴的比例或定额。
- 资金：是否自筹；工程款进入谁的账户。
- 经营：是否自负盈亏、自行组织施工、自行承揽项目。
- 隶属：劳动合同、社保、工资发放是否真实连续。
- 现场：五大员是否本单位人员。
- 对外：是否已与或拟与发包人签订施工合同。

缺口标 `G#`，不补商业数字，不补已是职工。批准、招投标、中标写成未完成事实，不写成已经合法中标。

本节不输出可履行的管理费结算、印章使用或走账安排。

## 6. 强制规范与本类型效力红旗

强制规范与效力红旗只在核验后落法律结论：借用资质施工合同依第 153 条第一款及法释〔2020〕25 号第 1 条认定无效；第 16 条但书不救该专条；自身超越资质补正规则不适用借用他人名义；质量连带；挂靠用工主体责任。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

不得把“收缴非法所得为现行必然后果”或“整组关系因内部协议有效而有效”写成已核验结论。不得用格式条款审查把挂靠改成可履行。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有停笔告知句或明确停笔/转出口径。禁止输出无告知句的色块表。禁止在“修改句或红线”列填写可履行挂靠条款。

本类型至少检查：借用名义；管理费或牌照费；自负盈亏或自筹资金；无真实劳动关系或临时包装；现场五大员非本单位人员；保证本约有效；印章外借；体外循环；内部追偿对抗第三人；假任命或假社保。

## 8. 停笔告知句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`，不编造。禁止只给原则、不给句子。框架与硬闸冲突时按硬闸出句。

建议句必须覆盖本类型硬闸：识别后建议不签署；删除保证有效；不提供管理费/印章/走账可履行替代；合规改道只点名。可退让点写“无；用户坚持可履行则整体停止”。

## 9. 谈判与签署提醒

谈判顺序：先红线（不签署本约、停止出借名义、停止假材料），再必须改（删除保证有效句、停止体外走账安排），最后才点名合规改道。不存在“把挂靠谈到可接受”的优化项。

签署提醒：建议不签署本约。不指导倒签、补假社保、假任命或假中标。被挂靠人立场必须提示：质量连带、用工主体责任、表见代理、行政处罚。挂靠人立场必须提示：协议无效不保护管理费期待，也不免除质量与安全责任。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本技能只出审查意见和修改句，不出整份起草终稿；出稿转 `挂靠合同（借用资质合同）·起草`。不是履约交底、管理费诉讼文书、工程款精算终局或效力保证。合规改道点名后写明应转的完整 Skill ID。
