# 审查方法（锁定 建设工程 / 挂靠合同（借用资质合同））

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止打开或复制 `内部承包合同·审查` method。禁止套用真实内部承包的五统一改写、合法专业分包资质、劳务分包、施工本约验收工期或联合体连带主路径。禁止把本技能写成可履行挂靠或内部承包换标题。

定性校验：核心给付是借用或出借建筑施工企业资质、营业执照或企业名义承揽工程，才继续；明显他类则负触发，不填十节实体结论。

本文件是可执行判断节点，不是栏目说明书。每个会改变放行、停笔告知句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、可以做成有效挂靠、对方必然接受、法院必然判决无效，或唯一必得管理费、工程款。

`search_law` 返回已失效《合同法》及其解释、法释〔2004〕14 号收缴非法所得、民法通则收缴条款时记为噪声，不得写入 `L#`。`search_practiced` 仍写“补社保即可合法”“派驻管理人员即可把挂靠改成内部承包”“发包人不知情则对外施工合同有效”“收缴为现行必然后果”的，同样记噪声。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

示范文本只参考结构。写“自主经营、独立核算、自负盈亏、甲方出借资质、乙方上缴管理费”的范本与禁止出借资质冲突，不得当规则，不得抄进建议句。

知识库口径冲突以本方法为准，不回写知识正文：

- `基本面.md` 第五步“派驻真管理、财务统收统支，向合法内部承包靠拢”以及 `框架.md`“最佳实践”收支两条线、强制意外险、全过程痕迹化：纠正为识别信号或风险告知，**不是**本任务应当交付的可履行改写。按该方案出句视为未通过硬闸。
- `基本面.md` 把已收管理费写成“可能被视为非法所得予以没收或追缴”：纠正为法释〔2004〕14 号第 4 条已失效；现行法无自动收缴专条。管理费约定不发生借用资质所追求的履行效力；是否返还须另审不当得利与实际管理事实，无核验不得写必然没收或必然可留。
- `基本面.md` 更新提醒称农民工工资条例已明确规定挂靠拖欠由被挂靠人清偿：纠正为本次核验到的是条例第 43 条查处挂靠、第 30 条规范转包/分包先行清偿；挂靠用工主体责任见劳动争议解释（二）第 2 条。不得把知识库那句写成已核验专条。
- 知识库“绝对无效”“必然无效”：纠正为核验后写“现有依据支持……认定无效”，并声明不保证个案裁判。
- 法释〔2020〕25 号第 4 条“竣工前取得资质可不按无效处理”只适用于承包人**自身**超越资质后补正，不适用于借用他人名义。

开发窗口 2026-08-18 已核验、可供对照但不得代替运行时核验的规则：

- 民法典第 153 条：违反法律、行政法规的强制性规定的民事法律行为无效；但该强制性规定不导致该民事法律行为无效的除外。违背公序良俗的民事法律行为无效。
- 民法典第 791 条：禁止转包、支解后以分包名义转包；禁止分包给不具备相应资质条件的单位；禁止再分包；主体结构必须由承包人自行完成。
- 民法典第 793 条：施工合同无效但工程验收合格，可参照合同关于工程价款的约定折价补偿；验收不合格按修复结果处理。
- 法释〔2020〕25 号第 1 条：没有资质的实际施工人借用有资质的建筑施工企业名义的，应当依据民法典第 153 条第一款认定无效。转包、违法分包另依第 153 条第一款及第 791 条第二款、第三款认定无效。
- 同解释第 7 条：发包人请求出借方与借用方对建设工程质量不合格等因出借资质造成的损失承担连带赔偿责任的，应予支持。
- 同解释第 24 条：数份施工合同均无效但质量合格，可参照实际履行的合同折价补偿。
- 合同编通则解释第 15 条：不拘泥合同名称，根据内容、缔约背景、交易目的和履行行为认定实际关系。
- 合同编通则解释第 16 条：若干情形可不因违反强制性规定而无效，但法律、司法解释另有规定或合同履行必然导致违反强制性规定的除外。法释〔2020〕25 号第 1 条即“另有规定”，不得用本条救挂靠施工合同。
- 建设工程质量管理条例第 25 条：禁止以其他施工单位名义承揽工程；禁止允许其他单位或者个人以本单位名义承揽工程。
- 房屋建筑和市政基础设施工程施工分包管理办法第 15 条：禁止转让、出借企业资质证书；现场项目负责人、技术负责人、项目核算负责人、质量管理人员、安全管理人员不是本单位人员的，视同允许他人以本企业名义承揽工程。
- 保障农民工工资支付条例第 30 条：分包拖欠由施工总承包先行清偿后再追偿；转包拖欠由施工总承包先行清偿后再追偿。第 43 条：主管部门查处挂靠等并制止导致拖欠工资的违法行为。
- 劳动争议解释（二）第 2 条：不具备合法经营资格者挂靠有经营资格单位对外经营，其招用的劳动者请求确认被挂靠单位为用工主体责任单位，承担劳动报酬和工伤保险待遇的，应予支持。
- 民诉法解释第 54 条：挂靠人与被挂靠人可为共同诉讼人。

本次检索未返回可写入 `L#` 的正文，运行时必须重核、不得凭记忆落法律结论：建筑法 2019 修正第 26 条、第 66 条；法释〔2026〕12 号是否新增挂靠专条。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用核心给付定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须同时满足才正触发：

1. 一方不具备承揽该工程所需的相应建筑业企业资质，或虽有较低资质但要以另一方更高资质或名义对外承揽。
2. 另一方提供资质证书、营业执照、企业名义、授权或项目章，供前者对外签约或报建。
3. 对价或运行方式是管理费、牌照费、固定上缴，或前者自筹资金、自行组织施工、自负盈亏，后者不实施与其名义相符的实质管理。

必须切开，禁止两可时灌入两套知识：

| 信号 | 归入 | 本技能动作 |
| --- | --- | --- |
| 无真实隶属 + 借用名义 + 管理费或自负盈亏 | 本类型 | 加载本目录双文件 |
| 标题内部承包/目标管理，但自筹资金、现场五大员非本单位人员、企业只收固定管理费 | 本类型（名为内部承包实为挂靠） | 留本技能；标题冲突写入 `C#` |
| 承包人是在册职工，真实连续劳动合同、社保、工资，企业统一技术质量安全财务劳务 | `内部承包合同·审查` | 负触发；不按挂靠无效审完 |

## 节点 2　主体、识别信号与劳动关系

1. 建主体表：挂靠人/实际施工人、被挂靠人/名义承包人、对外签约名、付款名、发票名、授权签字人、项目负责人。名称不一致不自动合并。
2. 核验营业执照与签约名是否同一；建筑业企业资质是否被文本或用户材料提及。口头“我们有资质”不得写成已核验证书。
3. 识别信号（满足多项则 `现有依据支持` 定性挂靠；仅一项且用户主张内部承包则 `依据不足`，字段停止）：

| 信号 | 指向挂靠 | 不得写成 |
| --- | --- | --- |
| 鉴于或正文写自行承揽、自带项目、自筹资金 | 强 | 企业真实经营 |
| 自负盈亏，除管理费外利润归对方 | 强 | 内部绩效考核 |
| 固定比例或定额管理费、牌照费 | 强 | 合法分包对价 |
| 现场五大员不是被挂靠人本单位人员 | 强（管理办法第 15 条） | 已经合法内部承包 |
| 无劳动合同，或合同签订日紧贴投标日、社保从当月起缴 | 强 | 劳动关系真实 |
| 工程款进入个人账户或对方控制的空壳公司 | 强 | 正常财务 |
| 被挂靠人出具空白授权、项目章外借 | 强 | 普通项目管理 |
| 将所得写成“绩效奖金”“工资”以掩盖上缴 | 中 | 真实劳动报酬 |

4. 真实内部承包反信号：承包人在册已久；社保与工资连续且由企业发放；材料、劳务、机械由企业统一采购或调度；企业派驻并实际指挥质量安全；财务进出企业监管账户。反信号充分 → 负触发 `内部承包合同·审查`。
5. 口头“已经是我们员工了”“社保在办”不得写成已有真实劳动关系。
6. 共有、担保、配偶与本类型无关的，不展开。国资或上市公司出借资质：红旗并升级，不写可履行路径。

不足：字段停止，列出待补材料，不补主体，不补已是职工。

## 节点 3　无效风险告知（硬闸）

核验后可引用的判断点（须 `search_law` 写入 `L#` 再落法律结论）：

- 没有资质的实际施工人借用有资质建筑施工企业名义的，应当依据民法典第 153 条第一款认定无效。
- 合同编通则解释第 16 条的例外，因司法解释另有规定，不适用于该借用资质施工合同。
- 施工合同无效但验收合格的，可以参照约定折价补偿；这不是把挂靠改成有效履行。
- 自身超越资质且竣工前取得相应资质的补正规则，不适用于借用他人名义。

| 文本写法 | 本任务动作 |
| --- | --- |
| “本协议合法有效，双方不得以挂靠或无效抗辩” | 红线。告知现有依据支持无效；删除该保证句 |
| “管理费按约支付，否则按日计违约金” | 停笔告知。不改成更可执行的催收句 |
| “本合同属于内部承包，不适用挂靠规定”但识别信号成立 | 留本技能。告知名称不决定效力 |
| “竣工前乙方将取得自身资质，本合同自动有效” | 红线。告知补正规则不适用借用他人名义 |
| 用户要求改成“有效的资质合作/牌照许可” | 整体停止 |

告知句最低要素：识别依据回链 `C#`；核验后的无效依据回链 `L#`；对内管理费约定不发生借用资质的履行效力；对外施工合同通常亦无效；折价补偿只点名；不保证裁判结果。

## 节点 4　质量、用工、表见代理与税收（告知）

1. 质量：发包人请求出借方与借用方对因出借资质造成的质量不合格等损失连带赔偿的，现有依据支持。内部“一切责任由挂靠人承担”不能对抗发包人。
2. 用工：挂靠人招用的劳动者可能请求确认被挂靠单位为用工主体责任单位，承担劳动报酬和工伤保险待遇。条例第 30 条是转包/分包先行清偿，不得直接写成挂靠专条；条例第 43 条是行政查处。内部协议不能规避。
3. 表见代理：授权委托书、介绍信、项目章在挂靠人处的，对外采购、借款、用工意思表示极易归到被挂靠人。只告知，不写“如何把章借得更安全”。
4. 税收：以被挂靠人名义开票、由挂靠人提供进项的，提示虚开风险。不指导开票路径。
5. 行政与刑事：出借资质面临责令改正、没收违法所得、罚款、停业整顿、降低或吊销资质；质量安全事故可能触发刑事责任。条号未核验则只标红旗。

## 节点 5　禁止可履行挂靠路径（硬闸）

下列原文若出现，动作为删除或停笔告知，**禁止**改成更隐蔽、更可执行的同结构条款：

| 原文类型 | 禁止改成 | 允许的产出 |
| --- | --- | --- |
| 管理费比例、支付日、逾期违约金 | 更清晰的催收与抵扣句 | 告知该对价不发生借用资质履行效力 |
| 项目章使用范围、备案印鉴 | 总部监章但仍供挂靠人对外签署 | 告知外借印章的表见代理风险；建议不签署本约 |
| 工程款进入挂靠人账户或指定私人账户 | 共管账户但仍服务挂靠结算 | 告知体外循环是识别与监管红旗 |
| 临时劳动合同、补缴当月社保、任命项目经理 | 把包装写得更像职工 | 告知临时包装不能把挂靠改成内部承包 |
| 反担保、房产抵押、高额保证金为出借资质提供保障 | 更完善的担保条款使出借更“安全” | 告知担保不能使借用资质变成可履行 |
| 知识库“派驻真质安员、统收统支” | 按该方案改句 | 若事实已是企业实质管理 → 转 `内部承包合同·审查`；否则只告知 |

用户要求保留上述任一项并“改到能签”：整体停止。

## 节点 6　合规改道只点名

仅在用户询问“那怎么办”或识别完成后的缺口节点名，每项不超过两句，不起草：

- 挂靠人具备相应专业或劳务资质，且发包人同意：可另行评估真实专业分包或劳务分包，走 `专业分包合同·审查` 或 `劳务分包合同·审查`。
- 双方愿意建立真实劳动关系并由企业实施统一管理：可另行评估内部承包，走 `内部承包合同·审查`。本任务不指导如何补办社保以通过检查。
- 长期合作团队：可另行评估设立子公司或股权纳入。本任务不出股权文件。

点名后必须写：本任务不起草改道文本；改道是否成立取决于真实资质、真实隶属和真实管理，不取决于换标题。

---

## 节点 7　格式条款、倒签与越权

1. 被挂靠人预先拟定、重复使用的挂靠文本，可按格式条款审查提示说明，但不因此改成可履行。异常免责句：标红旗并建议不签署。
2. 用户要求倒签签约日、中标日、劳动合同或社保起始日：整体停止。
3. 用户要求保证有效、保证管理费可收、保证对外施工合同有效、保证行政处罚可避免：拒绝保证。
4. 强制规范审查禁止用已失效“效力性/管理性”口诀代替合同编通则解释第 16 条；对借用资质，优先适用法释〔2020〕25 号第 1 条。

## 节点 8　按框架六步出停笔告知句

本节点是成果闸。没有停笔告知句或红线，不得宣称审查完成。禁止只打红黄绿。禁止输出可履行挂靠修改句冒充“必须改”。

打开已加载的 `框架.md`，按下列六步逐段对照正文。`基本面.md` 用于校验类型、主体、标的、程序、结构和红旗，不代替本节点出句。框架与本方法冲突时，以本方法为准出句。

| 步 | 动作 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题名实；主体是否无资质方 + 出借名义方；鉴于是否出现自带项目、自筹资金 | 识别句；建议不签署本约 |
| 交易条款 | 管理费、自负盈亏、出借证件、资金走账、权利剥离 | 停笔告知：删除或不得改成可履行结算/走账 |
| 配套 | 内部追偿、保证金、行政查处解除、管辖 | 告知内部追偿不能对抗第三人；不完善追偿句 |
| 尾部 | 本人签、指纹、反担保附件 | 告知签署本约不能使其有效；拒绝指导假签 |
| 语言 | 项目负责人/内部管理人员、绩效奖金、独立经营、风险自担 | 点出掩饰词；不得改成更隐蔽的同义词 |
| 常见问题 | 结构性无效、外部债务、工伤、知识库风控方案 | 结构级红线：不签署；合规改道只点名 |

每条告知句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

本类型“建议改为”只能是下列之一：

- 删除该借用资质安排，建议不签署本约；
- 停笔告知无效与责任，不提供可履行替代句；
- 合规改道点名 + 本任务不起草。

“可退让点”：无。用户不接受停笔、坚持可履行：整体停止。

风险表每一行必须能指回上述某条告知句。级别：

- `红线`：不改则建议不签或整体停止；借用资质本身即为红线；
- `必须改`：仅用于删除保证有效、删除假材料安排、删除可履行走账句，不得用于把挂靠改得更能执行；
- `可接受可优化`：本类型原则上不用此级放行任何借用资质条款。

用户不可接受事项优先写成红线。生存级工程款或重大安全风险且用户拒绝升级：停止“可以签署”建议。

争议解决：即使约定被挂靠人所在地法院，也不把管辖写成可控制无效风险的工具。或裁或诉、机构不明：标待核，仍不把本约改成可履行。
