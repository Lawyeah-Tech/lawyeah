# 边界与路由

本技能只审查 **建设工程 / 挂靠合同（借用资质合同）**。

必须读出借用或出借建筑施工企业资质、营业执照或企业名义承揽工程，且对价或运行方式是管理费、牌照费、固定上缴，或挂靠人自筹资金、自行组织施工、自负盈亏。标题叫“挂靠”但事实是真实内部承包或合法分包的，不得留在本技能做无效停笔结论。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或标题挂靠、核心给付明显不是出借或借用施工名义 | 本套导航的类型切开步骤 |
| 承包人是在册职工，真实连续劳动合同、社保与工资，企业统一技术、质量、安全、财务、劳务管理 | `内部承包合同·审查`；专业版未收录该 P1 时输出 `unavailable`，不得硬套本技能按挂靠宣告无效，也不得把挂靠包装成内部承包后代审 |
| 分包人有相应专业资质，发包人书面同意，按专业工程计价 | `专业分包合同·审查` |
| 仅分包劳务作业且分包人有劳务作业资质 | `劳务分包合同·审查` |
| 送审主文件是发包人与承包人施工本约，工期、验收、进度款主导 | `建设工程施工合同·审查` |
| 两个以上承包单位联合共同承包 | `联合体协议·审查` |
| 工程总承包本约主导 | `工程总承包合同·审查` |
| 指定分包或平行发包外观主导，且无出借总包名义换管理费 | `指定分包合同（甲指分包）·审查` 或 `独立发包合同（平行发包）·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `挂靠合同（借用资质合同）·起草`；只出停笔告知，不按挂靠范本出可履行稿 |
| 已签未争、问进度款、现场移交、管理费催收节点 | 本套导航的履约步骤 |
| 已成争 | 合同争议或建设工程争议领域；不写退还管理费起诉状、讨薪应诉状 |
| 用户只要管理费或工程款终局数字 | 测算技能或人工精算；本技能只做识别与告知 |
| C 端大众快检 | 只分流，不回改 |

同一文本既写“内部承包”又写“自筹资金、上缴管理费、出借资质”：按核心结构留本技能，标题冲突写入 `C#`。真实隶属与实质管理已能支持 → `内部承包合同·审查`。两可且无法判断：负触发引擎，不灌两套知识。

假社保包装、假任命、规避招投标、把挂靠改成可履行：停笔告知，不改写成可履行文本。用户坚持可履行：整体停止。

禁止在正文写半截 Skill ID。转出时必须写完整 ID，例如 `内部承包合同·审查`、`专业分包合同·审查`、`建设工程施工合同·审查`。
