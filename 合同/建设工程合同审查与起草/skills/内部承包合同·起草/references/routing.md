# 边界与路由

本技能只起草 **建设工程 / 内部承包合同** 的待签企业内部经营管理文本。签署方是具备建筑业资质的企业与其内部职能部门、分支机构或在册职工。中文展示名是「审查内部承包合同（建设工程）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 业主与施工企业的按图施工本约、中标后施工合同 | `建设工程施工合同·审查`。本任务不写黑白合同、优先受偿主路径 |
| 设计+采购+施工或设计+施工一体对发包人 | `工程总承包合同·审查` |
| 人+材+机+专业技术管理的专业分包 | `专业分包合同·审查` |
| 平等主体劳务作业换劳务报酬 | `劳务分包合同·审查` |
| 甲指分包 | `指定分包合同（甲指分包）·审查`；专业版未装则 `unavailable` |
| 平行发包 | `独立发包合同（平行发包）·审查`；专业版未装则 `unavailable` |
| 用户主文本是挂靠/借用资质协议，或明确要求把出借资质做成可履行 | 告知违法后点名 `挂靠合同（借用资质合同）·审查`；本任务不代做挂靠审查、不出可履行挂靠稿 |
| 标题内部承包，承包人非职工、只交管理费、关键岗位非本单位人员 | 留本任务；点名挂靠红旗；禁止只改标题；拒改则整体停止 |
| 联合体内部分工 | `联合体协议·审查` |
| 监理 | `建设工程监理合同·审查` |
| 用人单位与劳动者两方劳动合同专项 | `用人单位与劳动者两方劳动合同专项→` |
| 有完整待签文本要评改 | `内部承包合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审；实为挂靠则只告知，不起可履行内部承包外壳 |
| 已签未争、只问进场、拨付日、审计日履约 | 本套导航的履约步骤 |
| 已成争：挂靠效力确认、实际施工人追索、欠薪群体事件、工伤立案 | `或` 或劳动/建设争议对应原子。本技能不审争议策略 |
| C 端大众快检 | 只分流，不回改 |

本约夹带对外施工合同或劳务分包附件：附件整段交接对应邻类；内部承包正文继续审。用户坚持本技能给出可履行挂靠稿、施工总包中标路径、劳动仲裁胜率或对外免责终局：`目标停止`。
