# 建设工程监理合同·审查

## 任务目标

在单一立场下，只审查 **建设工程 / 建设工程监理合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。`depends-on` 为空。

主线是**委托人委托具备相应监理资质的监理人，对工程建设实施独立监督管理**（三控两管一协调及法定安全生产监理职责），不是按图施工，也不是编制勘察报告或施工图。

不交付：他类合同审查；从零起草；履约交底；争议文书；有效性或对方接受的保证；把无监理资质、越级、挂靠、转让监理业务、与施工或材料设备供应单位存在利害关系、必须招标未招或影子监理改成可履行监理文本。

## 工作边界

正触发：已有可读待签正文及附件，尚未签署，尚未成争，核心给付是监理人根据委托人委托，对确定的建设工程项目实施质量控制、造价控制、进度控制、合同与信息管理、组织协调，并履行法定安全生产监理职责，委托人支付监理酬金。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 核心给付是按图施工、组织现场、交付合格工程 → `建设工程施工合同·审查`；
- 核心给付是编制岩土、水文地质等勘察文件 → `建设工程勘察合同·审查`；
- 核心给付是编制方案、初步设计或施工图设计文件 → `建设工程设计合同·审查`；
- 设计+采购+施工或设计+施工一体 → `工程总承包合同·审查`；
- 专业分包施工本约 → `专业分包合同·审查`；
- 纯劳务分包 → `劳务分包合同·审查`；
- 全过程咨询、项目管理、造价咨询或招标代理与监理混签一份、主给付分不清 → 本套导航的类型切开步骤 重新定性，不得用本技能吞并造价、招标代理或项目管理；
- 仅提供技术建议、不具备现场指令权 → 引擎或咨询原子；
- 无可读文本、本类型条件已谈妥、要出己方稿 → `建设工程监理合同·起草`；
- 已签只问履约节点（进场日、总监排班、月报提交日） → 本套导航的履约步骤；
- 已成争（催告、解除、索赔、监理失职鉴定、质量安全事故调查、诉讼仲裁）→ `或` 或 `或`。

挂靠、转让监理业务、与施工或供应单位存在利害关系仍要承接、影子总监、必须招标未招：只出告知，不改写成可履行结构。用户坚持“改到能签/先挂靠后补证/监理兼施工”：整体停止。

## 本类型硬闸

执行时必须同时守住。每闸必须能落到修改句或明确停笔，不得用施工、设计、勘察或普通咨询口径替换。

1. **监理 ≠ 施工 ≠ 设计 ≠ 勘察 ≠ EPC ≠ 项目管理咨询**  
   成果是监理规划、实施细则、旁站与巡视记录、监理日志与月报、指令与签认、工程质量评估报告。监理人不承包施工、不编制施工图、不出岩土参数。按图施工 → `建设工程施工合同·审查`。出施工图 → `建设工程设计合同·审查`。出勘察报告 → `建设工程勘察合同·审查`。设计+施工一体 → `工程总承包合同·审查`。  
   修改句方向：标题与标的改成“对××工程实施施工阶段（或约定阶段）监理并提交监理文件”；删除包工包料、竣工交付、出图盖章或钻孔出报告义务。全过程咨询混签负触发或切回引擎，不出施工/设计修改句。

2. **监理资质覆盖专业与等级**  
   工程监理综合资质、相应专业甲/乙/丙级或事务所资质须覆盖本工程专业类别与规模。综合资质可承担各专业；专业乙级限二级及以下；专业丙级限三级；事务所资质不得承担国家规定必须实行强制监理的工程。无资质或越级：效力高风险，不得改成可履行无资质监理。挂靠、允许他人以本单位名义承揽、转让监理业务停笔。总监须为国家注册监理工程师，锁定姓名与注册号，须为监理人聘用人员并现场履职；禁止挂证、影子总监。  
   修改句方向：主体栏写监理资质证书类别、等级、证号及与本工程专业规模的对应关系；附件锁定总监及专业监理工程师名单、注册证书与社保关系；删除“先签后补证”“总监可长期不在场由他人代签”。挂靠/转让只出告知，不写假社保、出借印章或可履行资金路径。

3. **独立性**  
   监理人根据法律、法规、技术标准、设计文件和施工承包合同，**客观、公正**执行监理任务，对施工质量承担**监理责任**，不是施工质量的承包责任人，也不是委托人的传声筒。发包人不得越过监理人直接向承包人下达关于工程质量和造价的实质性指令。监理人发现施工不符合设计、标准或合同的，有权要求改正；发现设计不符合质量标准或合同约定的，应当报告委托人要求设计人改正，不得擅自改图。  
   修改句方向：写明独立行职权、停工令/复工令/拒绝签认权及必须报批事项；增列“委托人不得越过监理人向承包人下达质量或造价实质性指令；委托人径行指令的，监理人书面记录并就该指令部分免于监理责任”。删除“监理人须按委托人临时口头指示签认”或“监理人仅提供建议、无指令权”。

4. **不得与施工利益冲突**  
   监理单位不得与被监理工程的**施工承包单位**以及**建筑材料、建筑构配件和设备供应单位**有隶属关系或者其他利害关系。不得与承包单位串通为承包单位谋取非法利益。同一法定代表人、交叉持股、母子公司、人员交叉任职、合伙经营、接受施工方或供应商报酬，一律按利害关系停笔，不改成可履行“关联监理”。设计单位担任监理的，须另具相应监理资质，且与施工承包单位无利害关系。  
   修改句方向：主体声明无利害关系，并作为生效条件；发现利害关系立即书面披露并解除、移交档案；廉政协议作为附件。出现关联或串通条款：只告知，不写隔离协议充作合法外观。用户坚持监理兼施工或接受施工方分成：整体停止。

## 建立审查坐标

确认：使用者与授权；单方立场（委托人或监理人，不得同时服务）；相对方；全文、专用条款、监理大纲或投标文件、人员名单、廉政协议、招标投标文件、中标通知书与附件版本；工程名称、地点、标段与专业范围（含/不含人防、精装、绿化）；监理阶段（施工期+竣工验收期是否覆盖）；总监是否被点名；施工承包人是否已定及是否与监理人存在关联线索；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价格、工期、人员数量用 `【待填】`，不编造。

`基本面.md` 中的“无资质即合同无效”、强制监理未委托即无法开工验收、结清款 5%–10%、设计单位不得监理等表述，以本技能 `method.md` 与运行时核验为准。不把知识库过时、过宽或空白表述写成现行法终局。

- `search_practiced`：名为监理实为施工或项目管理、关联监理、影子总监、越权经济签证、无限质量连带、赔偿以酬金为限覆盖故意或重大过失的审查反例。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。

本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。交付按 [输出合同](references/output-contract.md)。边界见 [路由](references/routing.md)。

0. 签署状态与成果分流  
1. 类型识别：监理≠施工≠设计≠勘察≠EPC≠项目管理咨询；挂靠/转让停笔  
2. 主体、监理资质专业与等级、总监注册与现场履职  
3. 独立性与不得与施工、供应单位利益冲突  
4. 招标程序、强制监理范围、书面授权告知施工企业  
5. 范围与“三控两管一协调一安全”、旁站与巡视、授权签证闭环、期限与延期费  
6. 酬金、结清款、格式条款与强制规范  
7. 监理责任≠施工全部连带、限额不得覆盖故意或重大过失、档案移交  
8. 按框架六步出修改句  

必须有修改句。禁止只打红黄绿。每个风险回链文本位置。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、先定后招包装、把无资质或挂靠或转让监理业务或必须招标未招或与施工/供应单位关联监理或影子总监改成可履行结构、保证有效、监理兼施工或按委托人口头指示签认合格。
- `字段停止`：必须招标事实、监理资质专业与等级、总监注册与劳动关系、利害关系线索、动态规则未核验；酬金或期限关键事实缺失。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或来稿实为施工/设计/勘察/EPC/全过程咨询混签。

生存级金额、人身伤害或个人无限连带且用户拒绝升级：停止放行建议。


无完整待签文本、本类型条件已谈妥、要出己方稿时，转 `建设工程监理合同·起草`，不在本审查原子起草。
