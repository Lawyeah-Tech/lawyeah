# 边界与路由

本技能只审查 **建设工程 / 建设工程监理合同**（委托人委托监理人对确定工程项目实施独立监督管理的待签文本）。

| 主要目标 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 按图施工、交付合格工程 | `建设工程施工合同·审查` |
| 编制岩土、水文地质等勘察文件 | `建设工程勘察合同·审查` |
| 编制方案、初步或施工图设计文件 | `建设工程设计合同·审查` |
| 设计+采购+施工或设计+施工一体 | `工程总承包合同·审查` |
| 专业分包施工本约 | `专业分包合同·审查` |
| 纯劳务分包 | `劳务分包合同·审查` |
| 全过程咨询、项目管理、造价咨询或招标代理与监理混签、主给付分不清 | 引擎重新定性；不得用本技能吞并造价、招标代理或项目管理，也不得把施工/设计义务写进监理修改句 |
| 仅技术建议、无现场指令权 | 引擎或咨询原子 |
| 无文本、本类型条件已谈妥、要出己方稿 | `建设工程监理合同·起草` |
| 已签未争、履约节点（进场、总监排班、月报） | 本套导航的履约步骤 |
| 已成争（效力、监理费、失职鉴定、质量安全事故索赔） | `或` 或 `或` |
| C 端大众快检 | 只分流，不回改 |

挂靠、转让监理业务、必须招标未招、无资质/越级、与施工或供应单位存在利害关系仍要承接、影子总监：留在本技能只出告知并停笔，不转去“改成可履行稿”，也不转争议原子充作签前修改。

专业版未收录的 P1 场景不会安装对应原子。若用户拿这些文本来找专业版：输出 `unavailable`，提示或回引擎，不得用本监理原子硬套。
