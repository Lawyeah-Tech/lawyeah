# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的价格、工期、面积、限额；把已失效《合同法》及其解释、1983 年勘察设计合同条例、法释〔2004〕14 号、法释〔2018〕20 号写入结论；把质保金 3% 上限写成解释二第 14 条；把设计费写成当然享有优先受偿；出图即视为审批通过；境外可独立出图盖章；一律归发包人且设计人无署名；把勘察、施工、EPC、可研咨询或无项目委托设计当本类型审。

## 1. 触发、单方立场与成果状态

立场（发包人或设计人）、授权、签署状态、主要目标、设计阶段。负触发写路由，不启动实体审查。勘察、施工、EPC、监理、可研咨询、无项目委托设计、已成争必须在本节写明负触发，不得进入第 5–8 节。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、1983 条例、2004/2018 建工解释或六个月优先受偿时记噪声，不得写入 `L#`。解释二条号与最高人民法院官网法释〔2026〕12 号不一致时记 `conflict`，以官网为准，并注明无设计专条。条例若返回 2000 未修订文本改引 2017 修订。图审办法若返回 2004 令第 134 号改引 2018 修正。质保金管理办法漏检时改核官方文本并记来源。

## 3. 类型与加载路径

父级、子级、定性理由、易混切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读勘察、施工或总承包。挂靠或违法分包写停笔告知，不填可履行结构。

必须写明已切开：勘察 / 施工 / 总承包 / 监理 / 可研咨询 / 无项目委托设计 / 挂靠。

## 4. 主体、授权、设计资质与文本版本

主体表：签约名、履行名、付款名、发票名、项目负责人（注册建筑师/工程师）、授权签字人。设计资质类别、等级是否覆盖本工程行业与规模。境外文本：中方合作单位是否入约、合作设计协议是否附件化。版本表：协议书、专用条款、通用条款、设计任务书、限额指标、报价清单、招标文件、投标文件、中标通知书、聊天确认；冲突并列，不选对用户有利的一版。

## 5. 给付闭环

设计阶段、任务书是否附件化（专业范围、二次深化、深度、份数）、图审合格是否作为施工图交付节点、发包人资料与勘察成果清单、各阶段确认与付款、限额与变更、发票。缺口标 `G#`，不补商业数字。立项/规划/初设批复写成资料义务或下一阶段生效条件，不写成已经完成。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹。强制规范只区分管理性与是否导致民事行为无效。本节点必须单独回答：设计资质覆盖、必须招标、挂靠转包、出图是否视为审批通过、境外是否独立出图、著作权是否剥夺署名。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

本类型风险表至少覆盖（有文本才填，无对应条款标缺口）：

- 是否真是可供施工/报审的设计文件给付（≠勘察/施工/EPC/可研咨询/无项目委托设计）；
- 设计资质行业与等级覆盖；境外合作与出图签章；
- 招标 / 先定后招 / 中标无效；
- 阶段拆分、任务书附件、图审合格节点（禁止出图即过审）；
- 基础资料与必须依据勘察成果设计；
- 限额设计与变更费用工期；
- 第 800 条责任与免责/限额是否过宽；
- 擅自改图的责任切回；
- 著作权归属、本项目使用许可与署名；
- 若出现质保金：比例挂管理办法 3%，返还起算不写成 3% 依据；
- 设计费不得写成当然优先受偿；转包挂靠停笔。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。禁止输出无修改句的色块表。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`，不编造。禁止只给原则、不给句子。

质保金修改句必须引用管理办法第 7 条；返还起算若需对照解释二第 14 条，须写明该条是施工合同专条、仅作对照。禁止在同一句里把 3% 写成解释二第 14 条。

著作权修改句不得写成“全部权利归发包人，设计人不得署名”。

图审修改句不得写成“交付施工图即视为审查通过”。

## 9. 谈判与签署提醒

谈判顺序：先红线（类型切开、资质、招标、挂靠转包、境外独立出图、出图即过审、全面免责、剥夺署名），再必须改（任务书与阶段、图审合格节点、限额与变更、擅自改图、合理限额、质保金 3%），最后可优化。签署提醒：中标后三十日内按招标投标文件签约；授权与单位公章（禁止只盖设计专用章充作合同签署）；日期不得早于中标通知书；任务书、限额表、报价清单、合作设计协议一并装订。不指导倒签或补假招标、假资质、假图审。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本技能交付可编辑草稿、未决项、自审风险表和自审后修改句。草稿必须覆盖本类型起草必写、附件必附与禁止出现。待签评改转 `建设工程设计合同·审查`。不是履约交底、争议文书或效力保证。挂靠/先定后招/必须招标未招/无资质/境外独立出图已停笔的，本节重复告知一次。
