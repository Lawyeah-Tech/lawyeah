# 建设工程咨询服务合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、已失效《工程咨询单位资格认定办法》、已失效招标代理资格认定、1999 年招标投标法第十四条第一款旧文当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **建设工程 / 建设工程咨询服务合同** 的待签工程咨询文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。显示名为「建设工程咨询服务合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、施工进度款或竣工验收安排、招投标中介佣金安排。

## 本类型硬闸

1. **咨询成果 vs 施工**：交付物是可研、投资估算、概预算审核、造价咨询报告、项目管理顾问意见、全过程咨询建议书等智力成果。工期、工程价款、质量、竣工验收、进度款、保修为主给付 → 负触发 `建设工程施工合同·审查`，不按本类型改完。
2. **资质/备案切开**：工程咨询（投资）实行告知性备案，订立合同应与备案专业和服务范围一致。不得要求持已失效资格证书。夹带监理、设计、勘察须有对应专项资质，否则该部分字段停止或转出；造价咨询须造价咨询企业资质。挂靠只告知，不改成可履行。
3. **与施工、招投标中介切开**：施工本约 → `建设工程施工合同·审查`。投标人委托报告招标机会或媒介撮合、报酬绑中标 → `的method。`。禁止删掉施工或中介条款后硬套本技能。禁止抄 `建设工程施工合同·审查` 或 `的method。` 的 method。
4. **建议非决策、不得代拨付款**：咨询人提出建议，委托人决策。授权咨询人拨付工程款、指令财务付款或单独批准工程进度款 → 必须改，不得改写成代建可履行结构。保证绝对节约固定金额 → 红线删除或改成可核验过程/奖励基准。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签工程咨询正文，尚未签署，尚未成争，核心给付是工程咨询劳务过程及约定咨询文件，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 工期、价款、质量、竣工验收、进度款、保修为主给付 → `建设工程施工合同·审查`；
- 投标人委托报告招标机会、媒介撮合、报酬绑中标 → `的method。`；
- 招标人委托编制招标文件、组织开评标、发中标通知书为主轴 → 本套导航的类型切开步骤（无独立招标代理场景原子）；
- 监理本约 → `建设工程监理合同·审查`；设计出图本约 → `建设工程设计合同·审查`；勘察本约 → `建设工程勘察合同·审查`；
- 不绑工程投资决策的商务管理咨询 → `或`；
- 特定技术项目可行性、工艺评价、FTO，且不是工程咨询（投资）备案范围 → `或` 或 `或`；
- 无文本、本类型条件已谈妥、要出己方稿 → `建设工程咨询服务合同·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `或建设工程争议领域。` 或对应专项领域。

以咨询为名提供虚假可研骗取批准或国家资金、串通投标、造价回扣、挂靠：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及任务清单/人员表版本；专项或全过程；交付物形态；是否夹带监理/设计/勘察/招标代理；备案专业与范围；是否保证节约或授予拨付款；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的费用、人天、误差率用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验咨询与施工切开、备案范围、专项资质、格式条款、定金上限、免责除外、招标代理资格取消；`search_practiced` 只补审查反例，不得把施工挂靠口径写入本类型主路径；`search_template` 只借栏目结构。不虚构案件系统。

`search_law` 对上述法律结论为 required 级：不可用时不拒绝执行，只停止效力字段。返回已失效《合同法》或其解释、已失效《工程咨询单位资格认定办法》、已失效招标代理资格认定、1999 年招标投标法第十四条第一款旧文时记为噪声，不得写入 `L#`。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `建设工程咨询服务合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有工程咨询文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。施工、招投标中介、招标代理、监理/设计/勘察本约负触发。

### 2. 主体、备案与专项资质

签约名、履行名、付款名、发票名分列。工程咨询（投资）核备案范围。夹带监理、设计、勘察、造价核对应资质。不得引用失效资格证书。

### 3. 成果性质、决策闭环与范围

咨询文件可验收；禁止绝对节约保证；权限不含代拨工程款；任务清单菜单化。

### 4. 程序与验收

资料逾期顺延；变更书面化；验收不得以“委托人满意”为唯一标准；报审批复写成配合义务，不写成咨询人担保获批。

### 5. 对价与奖励

基本酬金与节约奖励分列；奖励须有可核验基准线与上限；定金不得超过标的额百分之二十。

### 6. 责任限额、格式条款与强制规范

限额可谈，人身损害、故意或重大过失、侵权、泄密不得排除。无核验引文则法律结论字段停止。

### 7. 独立性、知识产权、解除与争议

利益回避；未约定则报告著作权一般归受托人；解除补偿公式写明。不选定唯一法院充作意见。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把挂靠/串标/虚假可研/代拨工程款改成可履行结构、坚持保留绝对节约保证。
- `字段停止`：法域、动态规则、备案文号、专项资质、采购是否必须招标未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
