知识库纠正（不回写双文件）：

- `基本面.md` “属于委托合同”：先看核心给付。单纯出具咨询意见，适用合同编通则（第 467 条），可否参照委托须看是否处理事务；不得默认写入第 933 条任意解除并放行。夹带监理的，书面监理部分另受第 796 条约束。夹带勘察、设计的模块按第 788 条切开，不在本任务当施工审。

- `基本面.md` “招标代理必须符合专家库资格”：2017 年修改决定删去招标投标法第十四条第一款资格认定。招标人委托组织招标为主轴，转引擎；不得要求持失效招标代理资格证书。
- `框架.md` “全过程通常要求一项或多项甲级资质”：工程咨询（投资）现行规则是告知性备案且范围一致（管理办法第六、九条），不是资格证书。造价咨询仍须造价咨询企业资质（造价咨询企业管理办法第四条）。监理、设计、勘察仍须对应专项资质（管理办法第八条后段）。
- `框架.md` “误差率 ±5%”：实务建议，不是法源；可作修改句备选，须标 `【待填】` 或经用户确认。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。依据解释第 15 条：不拘泥于合同名称。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |

| 工期、工程价款、质量、竣工验收、进度款、保修、承包施工 | 施工合同 | 负触发 `建设工程施工合同·审查` |
| 投标人委托报告招标机会或媒介撮合；报酬绑中标通知书或签署施工合同 | 招投标中介 | 负触发 `的method。` |

支持切开的规范（法律结论须运行时复核）：

- 第 788 条：建设工程合同是承包人进行工程建设，包括勘察、设计、施工。工程咨询智力成果不是施工承包。
- 管理办法第八条：工程咨询服务范围含规划咨询、项目咨询、评估咨询、全过程工程咨询；全过程中的工程设计、工程造价、工程监理等资格，由国务院有关主管部门认定。
- 第 796 条：实行监理的，发包人应与监理人书面订立委托监理合同。监理主轴不在本任务展开。
- 第 961 条：中介以报告机会或媒介为给付。报酬绑促成中标或签署施工合同，转 `的method。`。
- 招标投标法（2017 修正）第十三条：招标代理机构应有营业场所、相应资金和编制招标文件、组织评标的专业力量。资格认定条款已删。

### 1.2 加载协议（硬闸）

本技能已锁定 **建设工程 / 建设工程咨询服务合同**。只打开 `references/基本面.md` 与 `框架.md`。禁止读其他子目录，禁止为对照再开第二类。禁止打开 `建设工程施工合同·审查`、`的method。` 的 method。

### 1.3 违法结构停笔

加载后或定性中出现：以咨询为名出具虚假可研或评估、帮助骗取批准文件或国家资金；与投标人串通、泄露标底、保证中标；造价审核收受回扣；出借备案或资信评价等级；要求咨询人在报告中作虚假陈述。

动作：

1. 交付告知：该结构可能因违法或违背公序良俗无效（第 153、154 条），管理办法第三十条亦禁止违背独立公正原则帮助骗取批准和国家资金、弄虚作假。不得改写成可履行文本。
2. 不写可履行的疏通路径、虚假可研口径或资金体外循环。
3. 风险表只保留识别依据和转出/删除提示。
4. 用户坚持“改到能签且仍做这些事”：整体停止。

挂靠或出借备案名义：只告知行政与民事风险，不改成可履行的“内部合作”或“联合体空壳”。用户要保留挂靠：整体停止。

## 节点 2　主体、备案与专项资质

### 2.1 主体表

建表：签约名、履行名、付款名、发票名、总咨询师/项目负责人。名称不一致不自动合并。集团委托、项目公司使用的，修改句把使用主体列为享受服务的关联方或加入确认，不编造主体。

口头“指挥长同意了”不得写成已授权。国资、政府投资项目内部决议或采购程序未附：该签署能力字段停止，不写成“可以盖章”。

### 2.2 备案与专项资质（硬闸）

工程咨询（投资）现行管理是告知性备案，不是资格证书。

| 文本或事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 要求持《工程咨询单位资格等级证书》或甲乙级资格证书作为生效条件 | 必须改：改为核验全国投资项目在线审批监管平台备案专业与服务范围 | 必须持失效证书才能签 |
| 合同服务超出备案专业或服务范围 | 字段停止或必须改范围；管理办法第九条：订立服务合同应与备案专业和范围一致 | 超范围也可以先签 |
| 备案信息未附、用户说“应该备过” | 备案字段停止；修改句把备案截图或公示页列为附件 | 已经完成备案 |
| 夹带工程监理且无监理资质痕迹 | 该模块字段停止或负触发 `建设工程监理合同·审查`；质量管理条例第三十六条、建筑法第三十五条约束监理责任 | 咨询备案可以替代监理资质 |
| 夹带设计出图或勘察外业且无对应资质 | 该模块转 `建设工程设计合同·审查` / `建设工程勘察合同·审查`；不得在本任务放行出图或外业 | 全过程咨询当然含出图 |
| 造价估算、概预结算、清单标底编制 | 核验工程造价咨询企业资质（造价咨询企业管理办法第四、二十一条）；无痕迹则该模块字段停止 | 普通咨询公司当然可以做造价 |
| 招标代理作为主轴 | 转引擎；不得要求持失效招标代理资格证书 | 2017 年前的资格认定仍有效 |
| 联合体承接全过程咨询 | 审查联合体协议分工与连带责任；无协议标 `G#`。不把空壳联合体改成可履行挂靠 | 联合体当然有效 |

咨询成果文件应加盖工程咨询单位公章和咨询工程师（投资）执业专用章（管理办法第十四条）。修改句要求附件锁定主持人员登记证书与执业章样本。准许他人以本人名义执业：告知管理办法第三十一条，不改成可履行借章。

个人以工作室签约出具工程咨询（投资）成果：标主体不适格风险（管理办法第三条要求独立法人），不在本任务认定已合法执业。

### 2.3 建议非决策、不得代拨付款（硬闸）

咨询意见是建议，不是资金指令，也不是代建。

| 文本写法 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 咨询人有权直接向承包人拨付工程款、指令委托人财务付款、单独批准进度款 | 红线删除。付款义务主体必须是委托人自己的有权机关。知识库“名为咨询实为代建”在此落地 | 咨询人可以代拨工程款 |
| 咨询意见视为已完成内部决策，或“咨询人确认后委托人必须执行、必须付款” | 必须改：闭环写成“咨询建议—委托人书面确认—再下达指令” | 已经完成内部决议 |
| 咨询人有权代表委托人对外签署施工、采购或分包合同 | 必须改或负触发委托/他类；本类型不保留对外签约权 | 已有合法代理权 |
| 授予项目管理“全权”，含账户共管或资金调度 | 必须改：删除资金调度；保留建议、审核、报送 | 已构成合法代建 |

最强反方：相对方主张咨询人已构成代建或职务代理，对外付款约束委托人。修改句必须把拨付款和决策权收回委托人。

## 节点 3　成果性质、范围与数据

### 3.1 成果是咨询智力成果（硬闸）

支持依据：第 467 条；第 509 条全面履行；管理办法第八条服务范围。本类型核心给付是咨询文件和管理建议，不是工程实体。

审查清单，缺一项则该字段不得写成已闭环：

1. 项目名称、建设规模或投资额量级、服务阶段（决策／设计准备／实施／运营后评价）。
2. 任务清单菜单：每一项的产出物名称（可研、估算、审核表、建议书），不是一句“提供全过程咨询”。
3. 使用目的：供委托人决策或按约配合报审。未经书面同意不得对外披露为“独立审批意见”，不得用于骗取批准。
4. 全过程与项目管理的深度：全过程含经济分析和设计优化建议时，须在清单中勾选；未勾选不得事后扩张。

出现施工承包、竣工验收、进度款结算为主给付：回到节点 1 负触发 `建设工程施工合同·审查`，不在本节点改成“咨询+施工”。

### 3.2 不得保证绝对节约（硬闸）

| 文本写法 | 动作 |
| --- | --- |
| 保证绝对节约固定金额、投资下降 X%、工期必然提前 | 红线；改成过程义务（按期提交符合任务清单的咨询文件） |
| 节约奖励但无基准线、无核定方法、无上限 | 必须改：基准线、核定主体、上限用 `【待填】`；奖励在阶段确认书之后计算 |
| 报酬完全取决于节约额或中标 | 现有依据支持滑向结果之债或中介；必须改成功标准，或负触发 `的method。` |
| 鉴于条款写“保证降本 XX 万元” | 首部必须改；鉴于不得充当承诺 |

咨询人立场：删除结果保证，降低结果之债。委托人立场：若商业上要绑定激励，只能附加，且成功事件必须是阶段成果书面确认后的可核验节约额，不得写成“绝对节约”。不得把“尽力节约 200 万”充作已合规。

### 3.3 数据来源、报审与知识产权预告

委托人提供数据不实导致结论错误：修改句排除咨询人责任，但咨询人对伪造样本、隐瞒明显矛盾负责任。咨询人自行采集的，须标来源可溯。

报审：咨询人配合报送项目建议书、可研等；审批未获批若因政策或委托人决策，不得写成咨询人担保获批。因咨询文件存在重大事实错误导致未获批，另按职业责任处理。

未约定时，报告作为委托创作作品，著作权一般归受托人（著作权法（2020 修正）第十九条）。委托人需项目内免费使用、二次分发或署名控制：必须书面约定归属或许可范围。解释第十二条仍写“第十七条”，运行时引用第十九条，解释第十二条只借“特定目的范围内使用”的争点。咨询人保留方法论、指标数据库和通用模板，除非另有约定移交。

## 节点 4　程序、协助与验收

1. 启动日应早于拟服务的决策节点。签订日晚于已开始的咨询工作：标倒签红旗；用户要求倒签或补假批准：整体停止。
2. 资料清单、对接人。委托人逾期不提供资料：工期顺延，咨询人不承担该延误。
3. 沟通闭环：咨询建议须经委托人书面确认后再向参建方转发。咨询人不得绕开委托人直接向承包人下达有资金效果的指令。
4. 验收标准写“结构符合任务清单、引用可溯源、已按书面意见修改、按规定加盖单位公章和咨询工程师（投资）执业章”。禁止单独以“委托人满意”为唯一标准。
5. 异议期须有天数和书面异议形式。天数用 `【待填】`。造价咨询若约定估算与决算误差范围，数字用 `【待填】`，不得把框架 ±5% 写成法定误差。
6. “无偿修改直至满意，否则不付尾款”：必须改。不满意须指出与任务清单不符的具体项；超出约定轮次按人天另计。
7. 非咨询人原因停工或服务期延长：约定待工费或延长服务期费用公式，缺数字用 `【待填】`。
8. 人员到位：锁定总咨询师及专业负责人，擅自更换设违约金。挂名不出场：委托人可要求更换或解除。

## 节点 5　对价、定金与奖励

1. 基本酬金、节约奖励、差旅、专家评审费分列。未给出的数字写 `【待填】`。预付款性质写明为服务费；除非确需定金罚则。
2. 计价可按人工单价、成本加酬金或固定总价。按工程造价百分比计取的，写明取费基数和是否含设备购置。禁止编造费率。
3. 定金：必须使用“定金”二字才讨论罚则。“订金、保证金”无定金性质约定的，不得写成定金。约定或推算超过主合同标的额百分之二十：超过部分不产生定金效力（第 586 条）。无核验引文不得把 20% 写成现行法结论。
4. 节约奖励只能作为附加，且须有基准线、核定方法和上限。禁止把中标或施工合同签署写成咨询成功事件。
5. 退出：约定通知期、已完成阶段按进度付款、已发生差旅据实结算、预期利益或固定解约金公式。禁止只写“双方协商解除”而无清理。不得把第 933 条任意解除直接写成双方已有的法定权利，除非节点 1 已认定构成委托并已另作说明；即使参照委托，解除仍须赔偿有偿委托下的直接损失和履行后可得利益。

## 节点 6　责任限额、格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 责任限额与除外

咨询失误的赔偿可约定上限（如已收酬金总额或【待填】倍）。间接损失、预期利润可排除。

下列不得排除，排除则必须改或标红线：

- 造成对方人身损害；
- 因故意或者重大过失造成对方财产损失（第 506 条）；
- 侵犯知识产权；
- 泄露商业秘密或违反保密约定；
- 虚假陈述、帮助骗取批准或国家资金。

“咨询人对报告使用后果不承担任何责任”且无除外：必须改。可写：委托人按符合约定的咨询意见自行决策的商业后果原则上自行承担，但咨询人存在故意、重大过失、虚假陈述、侵权或泄密的除外。不得把技术咨询第 881 条第 3 款写成工程咨询的法定免责。不得把施工质量责任转嫁为咨询监督的无限责任。

最强反方：限额过低或排除主要权利，相对方可主张格式条款无效（第 497 条）或不成为合同内容（第 496 条）。管理办法第十四条咨询质量终身负责是行业监管追溯，不自动等于民事无限赔偿，也不得用限额条款约定“放弃终身负责”。

### 6.2 格式条款

为重复使用而预先拟定、订立时未与对方协商。依据示范文本制作，不当然排除格式条款。

审查：免责、限责、排除对方权利、管辖/仲裁、自动续期、单方调价等异常条款是否有足以引起注意的标识，以及是否按要求说明（第 496 条；解释第 10 条）。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在附件 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

提供方对其已尽提示或说明承担举证责任。

### 6.3 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的、是否仅行政管理、是否只规制履行行为（第 153 条；解释第 16 条）。禁止用已失效“效力性/管理性”口诀代替解释第 16 条。备案不符首先是行政管理问题，不在本任务径行宣告整个合同无效。虚假可研、串标、回扣结构：不改写成有效履行。

必须招标：仅当项目落入必须招标的工程项目规定第二条至第四条范围，且采购对象属于第五条所列勘察、设计、监理等服务并达到 100 万元，或依法必须招标的其他规则，才讨论未招标风险。普通工程咨询不得直接套“100 万元必须招标”。未核验项目资金来源：该字段停止。

## 节点 7　配套：违约、独立性、解除、争议

1. 逾期交付按日计违约金；成果实质性不符合任务清单的，应修改或减少报酬，再不能实现目的的可解除并退还未履行部分费用。委托人逾期付款的，咨询人可中止后续工作。只有“依法承担违约责任”视为必须改。
2. 构成违约不等于当然解除。法定解除路径只点名催告或目的不能实现，不在本任务作出已解除结论。违约金不是必得金额；修改句避免“不得调整”或“按总价 30% 必得”。
3. 利益回避（红线）：咨询人及其关联方不得与本项目施工单位、材料设备供应商存在股权、实际控制或账外利益往来。项目期内不得为投标人就同一招标提供对立咨询。出现关联：披露或退出，不改成可履行的“既咨询又供应”。
4. 核心报告由锁定人员主持；辅助测绘、检测可在委托人同意下分包，咨询人对最终成果负责（管理办法第十四条质量总责）。未经同意更换总咨询师：委托人可要求更换或解除。
5. 职业责任保险：鼓励约定投保及保额 `【待填】`。未投保不得写成已经转移全部职业风险。
6. 争议解决：出现仲裁条款，不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核。专属管辖可能：只标红旗，不选定唯一法院充作法律意见。
7. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

打开已加载的 `框架.md`，按六步逐段对照正文。`基本面.md` 用于校验类型、主体、成果性质、备案和红旗，不代替本节点出句。

| 步 | 动作 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题用建设工程咨询或专项名称（造价/可研/全过程），不用施工承包/招标中介混称；主体全称；鉴于不写保证节约或保证获批 | 标题或主体修改句 |
| 交易条款 | 任务清单可验收；成果是咨询文件；禁止绝对节约保证；权限不含拨付款；备案范围一致；费用与节点 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 责任限额与除外；独立性；人员锁定；解除补偿公式；知识产权；职业责任保险 | 可执行后果句或删除句 |
| 尾部 | 签署权限、总咨询师会签、预付款到账是否生效、附件（任务清单、人员表、备案/资质、保险） | 生效与附件修改句 |
| 语言 | 正说加反说；盯死建议/指令、全过程/项目管理、误差率、报酬 vs 奖励 | 替换空词的句子 |
| 常见问题 | 无任务清单；验收绝对满意；结果保证；代拨付款；施工或中介条款混入；限额排除故意重大过失 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（成果是施工或中介、无备案超范围拒改、代拨工程款拒删、绝对节约保证拒删、违法结构、倒签）；
- `必须改`：可谈但签署前要落句（限额除外、任务清单、决策闭环、人员锁定、独立性）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级金额或个人无限连带且用户拒绝升级：停止“可以签署”建议。
