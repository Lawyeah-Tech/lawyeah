# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的费用、人天、误差率；把已失效《合同法》及其解释、已失效工程咨询资格认定、已失效招标代理资格认定写入结论；保证绝对节约；把咨询人写成可代拨工程款；把施工或招投标中介文本当成已完成的本类型审查。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查建设工程咨询服务合同（建设工程）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、已失效《工程咨询单位资格认定办法》、已失效招标代理资格认定、1999 年招标投标法第十四条第一款旧文时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `建设工程`，子级 `建设工程咨询服务合同`。定性理由、易混切开结果（施工 / 招投标中介 / 招标代理 / 监理 / 设计 / 勘察 / 商务咨询）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、备案资质与文本版本

主体表：签约名、履行名、付款名、发票名、总咨询师/项目负责人。资质表：工程咨询备案专业与范围；夹带监理/设计/勘察/造价的对应资质；招标代理不得要求持失效资格证书。版本表：正文、任务清单、人员表、报价、聊天确认；冲突并列。

## 5. 成果性质、范围、对价与验收

交付物是否咨询智力成果；是否出现施工验收或进度款主轴；是否保证绝对节约；是否授予拨付款；任务清单模块；基本酬金与节约奖励；验收标准与异议期。缺口标 `G#`。不输出施工竣工验收或进度款口径。

## 6. 责任限额、格式条款与强制规范

限额数字与除外是否完整（人身损害、故意或重大过失、侵权、泄密不得排除）。是否构成格式条款；提示说明痕迹。强制规范只按第 153 条和解释第 16 条区分，不用失效口诀。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把框架里的“±5%”或“甲级资质”写成法定义务。

## 9. 谈判与签署提醒

谈判顺序：先红线（成果是施工或中介、无备案超范围仍要放行、代拨工程款、绝对节约保证、违法结构），再必须改（限额除外、任务清单、决策闭环、人员锁定、独立性），最后可优化。签署提醒：授权、用印、日期、任务清单与人员表、备案/资质附件、预付款到账是否作为生效条件。不指导倒签或补假批准。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本技能只出审查意见和修改句，不出整份起草终稿；出稿转 `建设工程咨询服务合同·起草`。不是履约交底、争议文书或效力保证，也不是施工、招投标中介或监理/设计/勘察本约审查。
