# 专业分包合同·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **建设工程 / 专业分包合同**，输出可编辑草稿、未决项，并用本类型硬闸自审后给出风险表和修改句。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。`depends-on` 为空。

主线是**专业工程（人工+主材+机械+专业技术管理）依法分包**，不是业主按图发包施工，也不是只出人工的劳务作业。

不交付：他类型起草；待签文本签前审查；履约交底；争议文书；有效性或对方接受的保证；把无资质、越级、挂靠、转包、再分包、主体结构分包、未经发包人同意的专业分包或必须招标未招改成可履行文本。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿；尚未签署，尚未成争；核心给付是施工总承包人或工程总承包人将其承包范围内的专业工程发包给具有相应专业承包资质的单位完成，总包支付分包价款。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 有完整待签文本要评改 → `专业分包合同·审查`；
- 核心给付是业主发包、承包人按图施工并交付合格工程 → `建设工程施工合同·审查`；
- 纯劳务分包：只出人工及小型机具，明确不含主材、大型机械和技术管理 → `劳务分包合同·审查`；
- 设计+采购+施工或设计+施工一体对业主 → `工程总承包合同·审查`；
- 单独勘察或设计发包 → `建设工程勘察合同·审查` 或 `建设工程设计合同·审查`；
- 监理合同 → `建设工程监理合同·审查`；
- 无可读文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点（进场日、进度款日、隐蔽验收排班） → 本套导航的履约步骤；
- 已成争（催告、解除、索赔、违法分包效力确认、实际施工人追索、诉讼仲裁）→ `或`、`或` 或 `或`。

挂靠、转包、再分包、主体结构分包、未经发包人同意的专业分包：只出告知，不改写成可履行结构。用户坚持“改到能签/先分后补同意”：整体停止。

## 本类型硬闸

执行时必须同时守住。每闸必须能落到修改句或明确停笔，不得用施工总包、劳务分包或通用买卖/承揽口径替换。

1. **专业分包 ≠ 劳务分包 ≠ 施工总包 ≠ EPC**  
   成果是某一专业工程的人+材+机+技术管理。只出人工不含主材 → `劳务分包合同·审查`。业主按图发包施工 → `建设工程施工合同·审查`。设计+施工一体对业主 → `工程总承包合同·审查`。  
   修改句方向：标题与标的改成“××工程××专业工程分包”；范围附件列专业作业面、主材、机械和技术管理人员。劳务或施工本约负触发，不出专业分包修改句。

2. **合法专业分包 vs 违法分包 / 转包：停笔**  
   下列结构不得改成可履行：分包给无相应专业承包资质的单位；主合同未约定又未经建设单位认可；将主体结构施工分包；分包人再分包专业工程；总包不派驻管理机构、只收管理费、把承包范围内工程全部或肢解后以分包名义交出（转包）。挂靠出借资质同样停笔。  
   修改句方向：停笔告知，不写假项目部、假社保、出借印章、可履行资金路径或“先分后补业主同意即有效”。合规改道（更换有资质单位、取得书面同意、真实派驻）只点名，不在本任务起草。

3. **专业承包资质对口，禁止自然人**  
   分包人须持与本专业工程对应的专业承包资质及安全生产许可证，并在等级许可范围内承揽。施工劳务资质不能替代消防、机电、幕墙、钢结构、防水等专业承包资质。严禁个人或无法人资格的班组承揽专业分包。  
   修改句方向：主体栏写专业承包资质类别、等级、证号及与本专业工程的对应关系；删除“先签后补证”；自然人签约红线更换合格企业。

4. **发包人书面同意**  
   专业工程分包除施工总承包合同中已约定外，必须经建设单位认可。同意函或主合同分包条款须附件化。不得写成“进场后补同意即有效”。  
   修改句方向：附件列主合同允许分包条款或发包人书面同意函编号、日期与专业范围；范围超出同意函的部分删除或另取同意。

5. **背靠背不得卡死付款**  
   大型企业与中小企业约定“收到业主款项后再付”作为付款前提的，条款无效（法释〔2024〕11 号；2025 修订《保障中小企业款项支付条例》第 9 条）。双方划型不明：标 `G#`，仍须写出独立最迟付款日。农民工工资不得因工程款争议停发。知识库“民营企业间背靠背有效”不得写成现行法。  
   修改句方向：总包在业主付款后【待填】日内向分包付款；无论业主是否付款，最迟不晚于分包工程【验收/节点】后【待填】日；工资走总包代发，不得以未收到业主款为由停发。

6. **专业分包人不当然享有优先受偿**  
   第 807 条优先受偿原则上由与发包人有施工合同关系的承包人行使。禁止写成“分包人就分包价款当然享有建设工程价款优先受偿权”。  
   修改句方向：删除该句；改为到期未付的普通债权催告、逾期利息，以及支付担保（保函或共管账户）。不把解释二第 17 条写成专业分包默认。

## 建立起草坐标

确认：使用者与授权；单方立场（总承包人或专业分包人，不得同时服务）；相对方；全文、专用条款、专业工程范围一览表、主合同分包条款或发包人同意函、招标投标文件、中标通知书与附件版本；专业类别；资质是否被提及；是否再分包或包主体结构；背靠背怎么写；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价格、工期、数量用 `【待填】`，不编造。

## 起草模式

本原子只承担本类型起草。有完整待签文本要评改时，转 `专业分包合同·审查`。本类型条件已谈妥、要出己方稿时，留在本任务按三闸落稿并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。按框架六步落稿。商业数字未给用 `【待填】`。出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。来稿实为施工总包、纯劳务或 EPC：负触发。无资质、再分包、主体结构分包、未经发包人同意、转包或挂靠：停止包装成可履行，只告知，不写假项目部或可过关资金路径。

**起草必写**

- 标题与标的写成“××工程××专业工程分包”；范围写清专业作业面、主材、机械和技术管理人员。
- 分包人专业承包资质类别、等级、证号及安全生产许可证号，且与本专业工程对应；必须是法人。
- 主合同允许分包条款或发包人书面同意函的编号、日期与专业范围；范围超出同意函的部分删除或另取同意。
- 总包在业主付款后【待填】日内向分包付款；无论业主是否付款，最迟不晚于分包工程验收/节点后【待填】日。
- 农民工工资走总包代发，不得以未收到业主款为由停发。
- 到期未付按普通债权催告、逾期利息或支付担保处理，不得写成分包人当然享有优先受偿。

**附件必附**

- 专业工程范围一览表（人+材+机+技术管理界面）。
- 主合同允许分包条款或发包人书面同意函。
- 专业承包资质、安全生产许可证复印件。
- 安全生产协议；甲供材清单（如有）。

**禁止出现**

- 把无相应专业承包资质、主体结构分包、再分包、未经发包人同意、转包或挂靠包装成可履行。
- “先分后补业主同意即有效”。
- 施工劳务资质替代消防、机电、幕墙、钢结构、防水等专业承包资质。
- 个人或无法人资格的班组承揽专业分包。
- “分包人就分包价款当然享有建设工程价款优先受偿权”。
- 大型企业对中小企业以“收到业主款项后再付”作为付款前提且无独立最迟付款日。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、先定后招包装、把无资质或挂靠或转包或再分包或主体结构分包或未经发包人同意或必须招标未招改成可履行结构、保证有效。
- `字段停止`：必须招标事实、专业承包资质类别与等级、发包人同意痕迹、大型/中小划型、动态规则未核验；价款或工期关键事实缺失。
- `目标停止`：主目标已变为待签评改、履约交底、争议文书，或来稿实为施工总包/纯劳务分包/EPC。

生存级金额或个人无限连带且用户拒绝升级：停止放行建议。
