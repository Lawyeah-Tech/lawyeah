# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的价格、费率、证号；把已失效《合同法》及其解释、法释〔2004〕14 号、法释〔2018〕20 号写入结论；写成“业主指定则总包免除管理责任或质量安全连带”；把无资质或挂靠改成可进场；把平行发包改成甲指可履行；写“民营企业之间背靠背有效”。

## 1. 触发、单方立场与成果状态

立场（总承包人、指定分包人、或发包人作为指定方／拟见证方）、授权、签署状态、主要目标、指定专业。负触发写路由，不启动实体审查。平行发包、挂靠、施工总承包、总包自主专业分包、把主体结构以甲指交出必须在本节写明负触发或停笔，不得进入第 5–8 节充当可履行修改。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、2004／2018 建工解释或 1997 年建筑法未修正文本时记噪声，不得写入 `L#`。建筑法与 2019 修正冲突时以 2019 修正为准。解释二只写法释〔2026〕12 号已核条文，无甲指专条须明示。2025 年修订《保障中小企业款项支付条例》漏检时改核官方文本并记来源。

## 3. 类型与加载路径

父级、子级、定性理由、易混切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读平行发包、挂靠、施工总包或其他类型。挂靠、无资质指定或主体结构甲指写停笔告知，不填可履行结构。

必须写明已切开：平行发包 / 挂靠 / 总包自主专业分包 / 施工总承包 / 劳务分包 / 内部承包。

## 4. 主体、授权、资质与文本版本

主体表：发包人（指定方）、总承包人、指定分包人、付款名、发票名、授权签字人、拟见证盖章人。专业承包资质与安全生产许可证是否被材料提及。总包异议权是否落句。版本表：正文、指定函、界面清单、价款确认、总包合同指定条款、聊天确认；冲突并列，不选对用户有利的一版。

## 5. 给付闭环

指定专业、界面、指令链、总包调度权是否保留；价款形成权；总包服务费；转付路径；发票。缺口标 `G#`，不补商业数字。指定函、招标、备案写成生效条件或期限，不写成已经完成。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹。强制规范只区分管理性与是否导致民事行为无效。本节点必须单独回答：专业承包资质、个人承揽、总包管理权是否被掏空、业主指定能否免除连带、是否房屋市政直接指定、是否必须招标未招、挂靠或主体结构甲指、背靠背是否落入法释〔2024〕11 号。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

本类型风险表至少覆盖（有文本才填，无对应条款标缺口）：

- 指定事实与指定函；指定 vs 推荐；
- 专业承包资质 + 安全生产许可证 + 是否法人 + 总包异议权；
- 总包现场管理权是否被掏空；指令链是否三方确认；
- 是否实为平行发包（业主直签）；
- 挂靠、无资质、主体结构甲指、再分包；
- 价款形成权、差额承担、总包服务费；
- 转付 vs 业主直付；背靠背是否绑住工资或工程款；
- 质量安全连带与追偿；发包人见证盖章。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。禁止输出无修改句的色块表。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`，不编造。禁止只给原则、不给句子。

停笔项（无资质、挂靠、主体结构甲指、平行发包冒充甲指）只给告知句，不给“改完就能签”的可履行句。

## 9. 谈判与签署提醒

谈判顺序：先红线（资质、管理权免责、挂靠、平行发包切开、主体结构），再必须改（异议权、界面、转付、服务费、指令链、见证盖章），最后可优化。签署提醒：公章与资质证书名称一致；建议发包人作为指定方／见证方盖章；附件装订指定函、界面划分、价款确认、资质复印件；日期不得伪造早于实际协商日。不指导倒签指定函或补假招标、假资质。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本技能交付可编辑草稿、未决项、自审风险表和自审后修改句。草稿必须覆盖本类型起草必写、附件必附与禁止出现。待签评改转 `指定分包合同（甲指分包）·审查`。不是履约交底、争议文书或效力保证。挂靠／主体结构甲指／无资质已停笔的，本节重复告知一次。
