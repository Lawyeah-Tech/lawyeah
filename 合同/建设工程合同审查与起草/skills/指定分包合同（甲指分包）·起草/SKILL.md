# 指定分包合同（甲指分包）·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **建设工程 / 指定分包合同（甲指分包）**，输出可编辑草稿、未决项，并用本类型硬闸自审后给出风险表和修改句。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。`depends-on` 为空。显示名为「指定分包合同（甲指分包）·起草」。待签评改转 `指定分包合同（甲指分包）·审查`。

不交付：他类型起草；待签文本签前审查；履约交底；争议文书；有效性或对方接受的保证；把无专业承包资质、挂靠、主体结构肢解、业主直接发包的平行发包改成可履行甲指结构；写成“业主指定则总包免除管理责任或质量安全连带”。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿；尚未签署，尚未成争；核心给付是**发包人指定、推荐或确认**专业分包人，**总承包人与该分包人签署分包合同**，指定工程纳入总包现场管理。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 有完整待签文本要评改 → `指定分包合同（甲指分包）·审查`；
- 发包人自己与专业承包人签约，总包只收配合费、不签分包合同 → `独立发包合同（平行发包）·审查`；
- 出借资质、只收管理费、无真实隶属 → 本任务停笔告知，不转去写成可履行挂靠，也不打开 `挂靠合同（借用资质合同）·审查` 当审查整案；
- 总包自主选择专业分包人、无指定函或指定事实 → `专业分包合同·审查`；
- 业主直接发包、按图施工的施工总承包本约 → `建设工程施工合同·审查`；
- 对价是劳务报酬、范围只含人工／小型机具／辅材 → `劳务分包合同·审查`；
- 企业内部承包经营 → `内部承包合同·审查`；
- 设计+采购+施工或设计+施工一体对发包人 → `工程总承包合同·审查`；
- 单独勘察或单独设计发包 → `建设工程勘察合同·审查` 或 `建设工程设计合同·审查`；
- 监理 → `建设工程监理合同·审查`；
- 无可读文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问转付日、进场节点、配合记录 → 本套导航的履约步骤；
- 已成争（质量索赔立案、指定分包效力确认、实际施工人追索、停工围堵）→ `或` 或建设争议对应原子。

挂靠、无资质指定、把主体结构以甲指肢解、把平行发包改成总分包外观：只出告知，不改写成可履行结构。用户坚持“改到能签／能过检查”：整体停止。

## 本类型硬闸

执行时必须同时守住。每闸必须能落到修改句或明确停笔，不得用施工总包、违法分包换皮或平行发包口径替换。

1. **甲指不免除总包管理责任**  
   指定改变的是**选择权归属**，不改变总分包法律结构。总包仍须现场调度、质量安全监管、成品保护统筹；指定分包人须服从总包指挥。民法典第 791 条、建筑法 2019 修正第 29 条：第三人就其完成的工作成果与总承包人向发包人承担连带责任。解释一第 13 条：发包人直接指定分包人分包专业工程造成质量缺陷的，发包人承担过错责任；**承包人有过错的，也应当承担相应的过错责任**。不得写成“业主钦点则总包免连带／免监管”。知识库“履行合理提醒义务后可免除部分连带”不得当作现行默认。  
   修改句方向：写明总包对指定分包工程的现场管理权、技术变更须三方确认、分包人不服从指挥的罚款／报请更换；删除“因系发包人指定，总承包人对分包工程质量、安全、工期不承担责任”一类免责句。

2. **指定分包人资质与总包异议权**  
   指定分包人须具备相应**专业承包资质**和安全生产许可证，且为法人。分包管理办法第 8 条：必须具有相应资质，严禁个人承揽。未见资质或许可证：签署能力字段停止，不得写“业主点了就可以进场”。总包对不具备资质、无安全生产许可或有严重不良记录的指定对象，应书面异议并拒绝签约；未异议不得写成“已免责”。  
   修改句方向：主体栏写入专业承包资质类别等级、证号、安全生产许可证号；增设总包书面异议权与拒绝签约权；删除个人、班组或无证组织作为指定分包人的写法。

3. **与平行发包切开**  
   业主直接与专业承包人签订承包合同、总包不是分包合同当事人、通常只收配合费：负触发 `独立发包合同（平行发包）·审查`。标题写“甲指”但签约主体是发包人与专业单位、总包只在配合协议上签字：按平行发包分流，不在本任务硬改成总分包。本类型必须能读出：**总包是分包合同当事人**。  
   修改句方向：首部写明“发包人指定、总承包人与指定分包人订立本合同”；若来稿实为业主直签，分流，不在本任务补总包章冒充甲指。

4. **与挂靠切开，只告知**  
   借用资质、只收管理费、无真实隶属、指定对象实际是无资质团队挂名：只告知，不改成可履行。解释一第 1 条、解释二（法释〔2026〕12 号）第 5 条是挂靠／表见代理接口，不是“甲指有效专条”。用户坚持“改成内部承包／指定就能过”：整体停止。  
   修改句方向：停笔告知。不写假任命、假社保、印章外借、可履行资金路径。合法专业分包走 `专业分包合同·审查`，平行发包走 `独立发包合同（平行发包）·审查`，只点名不代起草。

附加必落句（有事实则单列，无事实在缺口节说明）：

- **指定事实书面化**：鉴于写明指定函／确认函日期与文号，并作为附件。区分“指定”与“推荐”。房屋市政项目点名分包管理办法第 7 条（建设单位不得直接指定分包工程承包人），不把指定写成当然合法。
- **界面与指令链**：微观交接界面；技术变更须发包人、总包、监理确认；禁止发包人越过总包直接改图改期而不留书面。
- **价款与转付**：价格形成方式（通常发包人与指定分包人议定）写死；总包服务费／配合费比例用 `【待填】`，不把知识库“3%–5%”写成法定。支付用“转付”而非“代付”；总包仅在收到发包人专项款项后转付的约定，不得绑死农民工工资，也不得在大型企业对中小企业结构下写成有效背靠背。
- **主体结构**：不得把施工总承包范围内主体结构施工以甲指交出。命中则停笔，不改成可履行指定分包。
- **发包人见证盖章**：建议发包人作为指定方／见证方在尾部盖章，确认价格、配合费和协调责任。未盖章标缺口，不写成已经免责。

必须有修改句。每个风险回链文本位置。禁止套用施工总承包的按图施工节点，禁止套用劳务分包的工种／专户默认给付，禁止复制 `建设工程施工合同·审查` 或违法分包 method。

## 建立起草坐标

确认：使用者与授权；单方立场（总承包人、指定分包人、发包人作为指定方或拟见证方，不得同时服务冲突双方）；相对方；全文、指定函、界面清单、价款确认、总包合同指定条款版本；指定分包人专业承包资质与安全生产许可证是否被提及；价款由谁议定、支付路径；总包是否保留调度权；是否触及主体结构；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。

## 起草模式

本原子只承担本类型起草。有完整待签文本要评改时，转 `指定分包合同（甲指分包）·审查`。本类型条件已谈妥、要出己方稿时，留在本任务按三闸落稿并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。按框架六步落稿。商业数字未给用 `【待填】`。出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。业主直签平行发包、挂靠或主体结构肢解：停止包装成可履行甲指，不补总包章冒充。

**起草必写**

- 首部写明“发包人指定、总承包人与指定分包人订立本合同”；总包是分包合同当事人。
- 总包对指定分包工程的现场管理权、技术变更须三方确认；指定不免除总包质量安全监管与对发包人的连带。
- 指定分包人专业承包资质类别等级、证号、安全生产许可证号；总包对不具备资质、无安全生产许可或有严重不良记录的对象有书面异议权与拒绝签约权。
- 鉴于写明指定函/确认函日期与文号；区分“指定”与“推荐”。房屋市政项目点名分包管理办法第 7 条，不把指定写成当然合法。
- 价格形成方式写死；总包服务费/配合费用 `【待填】`；支付用“转付”而非“代付”。
- 转付约定不得绑死农民工工资，也不得在大型企业对中小企业结构下写成有效背靠背。

**附件必附**

- 指定函或确认函。
- 微观交接界面清单。
- 价款确认；总包合同指定条款。
- 专业承包资质、安全生产许可证复印件。
- 建议发包人作为指定方/见证方在尾部盖章。

**禁止出现**

- “因系发包人指定，总承包人对分包工程质量、安全、工期不承担责任”。
- 个人、班组或无证组织作为指定分包人；“业主点了就可以进场”。
- 把业主直签、总包只收配合费的平行发包补总包章冒充甲指。
- 把挂靠或主体结构施工以甲指交出包装成可履行。
- 把知识库“3%–5%”写成法定服务费；把“发包人不付则总包不支”写成可默认防火墙。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持无资质仍“可以进场”、把挂靠或平行发包或主体结构肢解改成可履行甲指、写“业主指定则总包免责”、保证有效。
- `字段停止`：资质真伪、是否必须招标、企业规模是否落入法释〔2024〕11 号、总包合同是否允许指定、动态规则未核验。
- `目标停止`：主目标已变为待签评改、履约交底、争议文书，或来稿实为平行发包、挂靠、施工总承包、劳务分包。

生存级金额或个人无限连带且用户拒绝升级：停止放行建议。
