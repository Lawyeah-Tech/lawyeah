# 边界与路由

本技能只起草 **建设工程 / 建设工程咨询服务合同** 的待签工程咨询文本。中文展示名是「审查建设工程咨询服务合同（建设工程）」。场景分层为 P1。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或复制 `建设工程施工合同·审查`、`的method。` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 工期、价款、质量、竣工验收、进度款、保修为主给付 | `建设工程施工合同·审查` |
| 投标人委托报告招标机会、媒介撮合、报酬绑中标 | `的method。` |
| 招标人委托编制招标文件、组织开评标、发中标通知书 | 本套导航的类型切开步骤（无独立招标代理场景原子） |
| 监理旁站、平行检验、签发监理通知为主给付 | `建设工程监理合同·审查` |
| 施工图、初步设计出图盖章为主给付 | `建设工程设计合同·审查` |
| 勘察外业与勘察文件为主给付 | `建设工程勘察合同·审查` |
| 工程总承包、专业分包、劳务分包 | `工程总承包合同·审查` / `专业分包合同·审查` / `劳务分包合同·审查` |
| 不绑工程投资决策的商务管理咨询 | `或` |
| 特定技术项目可行性、工艺评价、FTO，且非工程咨询（投资） | `或`；文本落在委托技术咨询目录下则 `或` |
| 有完整待签文本要评改 | `建设工程咨询服务合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或建设工程争议领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

本约正文夹带一小段监理、设计或招标代理：专章交接对应原子或引擎；咨询意见条款可继续审。用户坚持本技能把施工、招投标中介、监理、设计或勘察整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿本类型文本来找未装本原子的专业版：输出 `unavailable`，提示，不得用邻类硬套。
