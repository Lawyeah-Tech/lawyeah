# 建设工程设计合同·审查

## 任务目标

在单一立场下，只审查 **建设工程 / 建设工程设计合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。`depends-on` 为空。

主线是**编制可供施工或报审的设计文件**，不是出岩土参数、不是按图施工、也不是只给可研建议。

不交付：他类合同审查；从零起草；履约交底；争议文书；有效性或对方接受的保证；把无资质、越级、挂靠、转包、违法分包、必须招标未招或境外独立出图盖章改成可履行设计文本。

## 工作边界

正触发：已有可读待签正文及附件，尚未签署，尚未成争，核心给付是设计人根据发包人委托，编制方案设计、初步设计或施工图设计文件（含约定范围内的施工配合），供报审或施工使用，发包人支付设计费。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 核心给付是编制岩土、水文地质等勘察文件 → `建设工程勘察合同·审查`；
- 核心给付是按图施工、组织现场、交付合格工程 → `建设工程施工合同·审查`；
- 设计+采购+施工或设计+施工一体 → `工程总承包合同·审查`；
- 监理合同 → `建设工程监理合同·审查`；
- 仅可研、规划建议或技术咨询，成果不供施工、不报施工图审查 → `或` 或 `或`；
- 无建设工程项目背景的平面、VI、软装、产品外观等委托设计服务 → `无建设工程项目背景的平面VI软装产品外观等委托设计服务→`；
- 抢险救灾、临时性建筑、农民自建两层以下住宅的设计（条例第 44 条不适用本条例）→ 引擎重新定性；
- 无可读文本、本类型条件已谈妥、要出己方稿 → `建设工程设计合同·起草`；
- 已签只问履约节点（交底日、现场配合排班） → 本套导航的履约步骤；
- 已成争（催告、解除、索赔、设计质量鉴定、诉讼仲裁）→ `或` 或 `或`。

挂靠、转包、违法分包、境外独立出图盖章：只出告知，不改写成可履行结构。用户坚持“改到能签/出图即过审”：整体停止。

## 本类型硬闸

执行时必须同时守住。每闸必须能落到修改句或明确停笔，不得用勘察、施工、EPC 或普通技术咨询口径替换。

1. **设计 ≠ 勘察 ≠ 施工 ≠ EPC ≠ 技术咨询**  
   成果是方案、初步设计或施工图，供报审或施工。岩土报告 → `建设工程勘察合同·审查`。按图施工 → `建设工程施工合同·审查`。设计+施工一体 → `工程总承包合同·审查`。仅可研建议不供施工 → `或` / `或`。无建设项目背景的委托设计 → `无建设工程项目背景的平面VI软装产品外观等委托设计服务→`。  
   修改句方向：标题与标的改成“编制并提交××阶段设计文件及附件”；删除钻孔出报告、按图施工、竣工验收或总价包干建设义务。可研咨询负触发，不出建工设计修改句。

2. **设计资质覆盖行业与等级**  
   工程设计综合、行业、专业或专项资质须覆盖本项目所属行业与规模。无资质或越级：合同效力高风险，不得改成可履行无资质设计。挂靠、转包、违法分包停笔。境外设计企业承担初设或施工图，必须选择至少一家持有境内设计资质的中方单位合作设计；施工图须由取得中国注册执业资格的人员审核签字并加盖中方设计企业公章后方为有效。禁止写成境外企业可独立出图盖章。方案设计阶段不适用建市〔2004〕78 号，但进入初设/施工图仍须补合作设计。  
   修改句方向：主体栏写设计资质证书类别、等级、证号及与本工程行业规模的对应关系；删除“先签后补证”。境外文本增列中方合作单位、合作设计协议和出图签章安排。挂靠/转包只出告知，不写假社保、出借印章或可履行资金路径。

3. **阶段与图审**  
   方案、初步设计、施工图分阶段交付和付款。施工图交付节点是**图审合格**，不是“出图”。禁止“出图即视为审批通过”或“双方签收即视为审查合格”。因设计原因未通过审查，设计人无偿修改至合格。  
   修改句方向：列各阶段交付物、深度（对照条例第 26 条）、份数与介质；施工图款与图审合格书挂钩；因设计原因审查不合格，设计人在【待填】日内无偿修改并承担自身原因造成的延误。

4. **著作权**  
   工程设计图是图形作品。须约定本项目使用许可、权属和署名。不得默认“一律归发包人且设计人无署名”。署名权不因财产权转让而消灭。发包人未经同意不得将图纸用于本项目以外工程或转让第三方。  
   修改句方向：财产权可约定归发包人或由发包人在本项目范围内独占使用；设计人及主要设计人员保留署名权；禁止删除图签署名；本项目以外使用须书面许可并另议费用。

5. **限额设计与变更**  
   限额指标必须附件化。超限由设计人无偿优化至约定误差范围。设计变更引起的费用和工期须分因：发包人改任务书、资料错误或擅自改图，责任切回发包人并增付费用、顺延周期（对照民法典第 805 条、条例第 28 条）。禁止“设计人任何情况下不承担责任”。  
   修改句方向：附件列投资限额与允许误差；超限无偿修改。未经原设计人书面同意，发包人、施工人、监理人不得改图；擅自修改的后果由修改方承担。故意或重大过失不得免责。

6. **必须招标**  
   依法必须招标项目未招标：不写成可履行签约路径。  
   修改句方向：补齐招标程序或停止放行；拒绝倒签中标日期；删除背离中标内容的另约。

## 建立审查坐标

确认：使用者与授权；单方立场（发包人或设计人，不得同时服务）；相对方；全文、专用条款、设计任务书、限额指标、报价清单、招标投标文件、中标通知书与附件版本；设计阶段；专业范围与二次深化是否纳入；资质是否被提及；境外合作是否已配中方；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价格、工期、面积、限额用 `【待填】`，不编造。

`基本面.md` 中的强制招标 100 万元门槛、著作权“通常归发包人”、收费标准已被取消强制等表述，以本技能 `method.md` 与运行时核验为准。不把知识库过时或空白表述写成现行法。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、先定后招包装、把无资质或挂靠或转包或违法分包或必须招标未招或境外独立出图盖章改成可履行结构、保证有效、出图即视为审批通过。
- `字段停止`：必须招标事实、设计资质行业与等级、任务书关键指标、图审义务、动态规则未核验；价款或限额关键事实缺失。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或来稿实为勘察/施工/EPC/可研咨询/无项目委托设计。

生存级金额或个人无限连带且用户拒绝升级：停止放行建议。


无完整待签文本、本类型条件已谈妥、要出己方稿时，转 `建设工程设计合同·起草`，不在本审查原子起草。
