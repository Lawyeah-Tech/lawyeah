# 边界与路由

本技能只审查 **建设工程 / 建设工程设计合同**（编制可供施工或报审的方案/初步/施工图设计文件的待签文本）。

| 主要目标 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 编制岩土、水文地质等勘察文件 | `建设工程勘察合同·审查` |
| 按图施工、交付合格工程 | `建设工程施工合同·审查` |
| 设计+采购+施工或设计+施工一体 | `工程总承包合同·审查` |
| 监理 | `建设工程监理合同·审查` |
| 仅可研、规划建议或技术咨询，成果不供施工、不报施工图审查 | `或` 或 `或` |
| 无建设项目背景的平面、VI、软装、产品外观等委托设计服务 | `无建设工程项目背景的平面VI软装产品外观等委托设计服务→` |
| 农民自建两层以下、抢险救灾、临时性建筑的设计 | 引擎重新定性（条例第 44 条不适用本条例） |
| 全过程工程咨询且设计只是其中一块、造价/监理/招标代理混签一份 | 引擎重新定性；不得用本技能吞并监理或造价主给付 |
| 无文本、本类型条件已谈妥、要出己方稿 | `建设工程设计合同·起草` |
| 已签未争、履约节点（交底、现场配合排班） | 本套导航的履约步骤 |
| 已成争（效力、设计费、图纸错误鉴定、索赔） | `或` 或 `或` |
| C 端大众快检 | 只分流，不回改 |

挂靠、转包、违法分包、必须招标未招、无资质/越级、境外独立出图盖章：留在本技能只出告知并停笔，不转去“改成可履行稿”，也不转争议原子充作签前修改。

专业版未收录的 P1 场景不会安装对应原子。若用户拿这些文本来找专业版：输出 `unavailable`，提示或回引擎，不得用本设计原子硬套。
