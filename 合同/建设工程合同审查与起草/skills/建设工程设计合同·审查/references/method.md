# 审查方法（锁定 建设工程 / 建设工程设计合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。

本文件是可执行判断节点。每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受或唯一必得金额。

`search_law` 返回已失效《合同法》及其解释、1983 年《建设工程勘察设计合同条例》、法释〔2004〕14 号、法释〔2018〕20 号、法释〔2002〕16 号时记为噪声，不得写入 `L#`。解释二条号以最高人民法院官网法释〔2026〕12 号为准；MCP 与官网冲突时以官网施行文本为准并记录冲突。解释二标题限于施工合同纠纷，**无设计专条**，不得把第 2、3、14、17 条写成设计合同专用依据。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。

禁止把勘察、施工或工程总承包合同的审查节点换标题套用：不得把钻孔纲要、管线停钻、农民工工资专户、主体结构自施、双资质、发包人要求、总价包干建设、优先受偿十八个月写成设计默认。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性。名实不符按核心给付归类，标题冲突写入 `C#`。

本类型成立条件：存在或可识别的建设工程项目；给付是对技术、经济、资源、环境等条件综合分析论证，编制方案、初步设计或施工图设计文件，供报审或施工；对价是设计费。可以只含一个阶段，也可以多阶段连签。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 主给付是岩土参数、水文地质评价、钻孔试验、勘察报告 | 建设工程勘察合同 | 负触发 → `建设工程勘察合同·审查` |
| 按已出施工图组织现场、交付合格工程 | 建设工程施工合同 | 负触发 → `建设工程施工合同·审查` |
| 设计+采购+施工或设计+施工一体 | 工程总承包合同 | 负触发 → `工程总承包合同·审查` |
| 对施工过程旁站、平行检验 | 监理合同 | 负触发 → `建设工程监理合同·审查` |
| 仅可研报告、产业规划或技术建议，不编制可供施工/报审图纸 | 技术咨询 / 可研 | 负触发 → `或` 或 `或` |
| 无建设项目背景的平面、VI、软装、产品外观、网页视觉 | 委托设计服务 | 负触发 → `无建设工程项目背景的平面VI软装产品外观等委托设计服务→` |
| 全过程咨询且设计、造价、监理、招标代理混在一份主给付不清 | 引擎重新定性 | 不得用本技能吞并监理或造价 |
| 抢险救灾、临时性建筑、农民自建两层以下住宅 | 条例第 44 条不适用 | 负触发 → 引擎 |
| 出借资质、只收管理费、无真实隶属 | 挂靠 | 本任务停笔告知，不改可履行 |

勘察、施工、EPC、监理、可研咨询或无项目委托设计文本：**负触发**。不得用本技能硬套设计合同修改句。

### 1.2 加载协议（硬闸）

本技能已锁定 **建设工程 / 建设工程设计合同**。只打开 `references/基本面.md` 与 `references/框架.md`。禁止读其他子类型，禁止为对照再开勘察、施工或总承包目录。

### 1.3 挂靠 / 转包 / 违法分包停笔

加载后或定性中出现：借用设计资质、挂靠出章、个人承接单位盖章、将全部设计转包、主体部分设计再分包、无资质外委充作承包、资金体外循环换管理费。

动作：

1. 交付告知：该结构违反建筑法、民法典第 791 条、《建设工程勘察设计管理条例》第 8、19、20 条，不得改写成可履行文本。
2. 不写项目负责人假任命、假社保、管理费结算、印章外借、可履行资金路径。
3. 风险表只保留识别依据和转出/改道提示。
4. 用户坚持“改到能签/出图即过审”：整体停止。

专项分包（幕墙、室内、景观、智能化等二次深化）给具备相应设计资质的单位：须发包人书面同意、不得把主体建筑设计整体甩出，且设计人对分包成果与分包人向发包人连带负责（民法典第 791 条第 2 款）。修改句必须写明连带，不得写成“深化单位自行担责即免责”。把全部施工图甩给另一家且本单位不组织、不审图、不盖章：按转包停笔。

合规改道（真实劳动关系、经书面同意的非主体部分再分包给有资质单位）只点名，不在本任务起草。

## 节点 2　主体、设计资质、境外合作

1. 建主体表：签约名、履行名、付款名、发票名、项目负责人、授权签字人。名称不一致不自动合并。
2. 设计人：工程设计资质类别与等级是否覆盖本工程所属行业和规模（综合资质、行业资质、专业资质或专项资质）。只有风景园林专项去接高层公共建筑施工图：红线/字段停止，不写成“有设计资质就能出施工图”。
3. 项目负责人应锁定姓名并具备相应注册执业资格（一级注册建筑师、注册结构工程师等，按专业匹配）。个人无注册 ≠ 企业无资质，但项目负责人空白或“挂名”不得写成已配置。主要图纸须由主持该项设计的注册人员签字并加盖执业印章。
4. **境外设计**：外国企业以跨境交付方式承担境内建设工程**初步设计或施工图设计**，必须选择至少一家持有建设行政主管部门颁发的设计资质的中方企业合作设计，且在中方资质许可范围内承接（建市〔2004〕78 号第 3、4、11 条）。施工图图签须注明合作各方；须由取得中国注册执业资格的人员审核签字并加盖中方设计企业公章后方为有效设计文件。禁止写成境外企业可独立出图盖章。方案设计阶段该规定不适用，但合同若覆盖初设/施工图，仍须预埋合作设计。保密工程、抢险救灾和未承诺对外开放工程禁止外国企业参与。
5. 发包人：建设单位与项目批准文件权利人不一致的，权利人签署或出具委托；国资、政府投资、上市公司决议未附则签署能力字段停止。
6. 仅盖设计专用章签署合同、未授权人员收款、收款进个人卡：标必须改或红线。合同签署建议加盖单位公章。
7. 口头“我们老板同意了”不得写成已授权。

不足：字段停止，列出待补材料，不补主体、不编造资质证号。无资质或越级：效力字段高风险，修改句要求更换合格设计人或停止签约；禁止“先签后补证即有效”。

## 节点 3　招标、先定后招

运行时核验后再落效力结论。核验失败：摘录条款继续，效力字段停止。

### 3.1 必须招标

必须招标事实来自法律、项目资金来源、规模和发改委令第 16 号，不来自用户口头“应该招标”。设计服务单项合同估算价 100 万元以上只是第 5 条门槛之一，还须项目落入第 2–4 条范围。依据不足则 `INV-招标` 标待核，不编造万元门槛，也不把知识库“大型公建”写成已经满足全部要件。

条例第 16 条（特定专利、造型特殊等经批准直接发包）是招标例外，必须有主管部门批准痕迹。不得把“我们想直接发包”写成已落入第 16 条。

| 已有事实 | 本任务动作 |
| --- | --- |
| 依法必须招标，文本无中标通知书、招标文件或投标文件 | 红线：补齐招标程序或停止放行。不写成可履行直接签约 |
| 签约日早于中标通知书，或先签实质合同再补招标 | 按招标投标法第 43、46 条告知中标前实质性谈判与先定后招的无效风险。解释二第 2 条是施工合同专条，可作对照，不得写成设计专条。只告知，不改成“倒签至中标后即有效” |
| 中标通知书发出超过三十日仍未按招标投标文件订书面合同 | 招标投标法第 46 条：标必须改；不指导倒签 |
| 另行协议改设计范围、周期、质量、价款 | 阴合同不得作为结算依据，修改句删除或改为与中标文件一致。用户要求保留两套价款：整体停止该部分 |

### 3.2 立项、规划与先勘察后设计

条例第 4 条：先勘察、后设计、再施工。第 25 条：编制设计文件应依据项目批准文件、城乡规划、强制性标准和深度要求。签前把立项/规划批准、勘察报告写成发包人资料义务或下一阶段生效条件，不写成已经完成。禁止“未取得勘察报告即可出施工图并视为有效”。解释一第 3 条是施工合同规划许可诉讼补正规则，不得据此写成“可以先无证出图，起诉前补证就有效”。

## 节点 4　阶段、任务书、图审、资料

本节点是本类型给付闭环，不是勘察合同的“纲要+钻孔”，也不是施工合同的“承包范围+竣工验收”。

### 4.1 阶段必须拆开

下列事项未落入经双方签认的设计任务书或阶段清单，视为范围不确定，**不得以“按规范设计”放行**：

- 设计阶段（方案 / 初步设计 / 施工图 / 施工配合）及是否连签；
- 专业范围（建筑、结构、给排水、暖通、电气、园林等）以及幕墙、精装、消防、智能化等**二次深化**是否纳入；
- 各阶段深度（对照条例第 26 条：方案须满足初设和控概；初设须满足招标、订货和施工图；施工图须满足采购、非标制作和施工，并注明合理使用年限）；
- 交付物清单、份数、介质、签章（注册师签字盖执业章）；
- 限额设计指标（建安造价或单方指标）及允许误差；
- 施工配合：技术交底、现场解决图纸问题、参加竣工验收的次数与差旅是否含在合同价内。

修改句：增列附件《设计任务书》并写“范围以附件为准；发包人增加专业或阶段须书面签证另行计价”。缺数字用 `【待填】`，不编造面积或限额。未确认上一阶段成果即要求进入下一阶段：修改句写成“书面确认或逾期未提书面异议视为确认，但不免除设计人按强制性标准设计的责任”。

### 4.2 图审合格才是施工图交付节点

条例第 33 条、质量管理条例第 11 条：施工图设计文件未经审查批准，不得使用。图审管理办法（2018 修正）第 13 条：合格出具审查合格书并盖审查专用章；不合格退回由原设计企业修改后复审。第 14 条：任何单位或者个人不得擅自修改审查合格的施工图；涉及审查内容的修改须送原审查机构。第 18 条：未经审查合格不得颁发施工许可证。

| 文本写法 | 本任务动作 |
| --- | --- |
| “设计人交付施工图即视为审批通过/审查合格” | 红线删除。施工图款、尾款与**图审合格书**挂钩 |
| “双方签收即验收合格，不得再提异议” | 必须改。签收 ≠ 图审合格 ≠ 放弃隐蔽错误索赔 |
| 因设计原因未通过审查 | 设计人无偿修改至合格，并承担自身原因造成的延误；图审费、专家评审费是否含在合同价内写清 |
| 因发包人变更任务书、资料错误或规划调整导致复审 | 发包人承担增加工作量费用，周期顺延 |
| 用户要求“先出图施工，图审以后再补” | 整体停止该部分。不得写成可履行未图审施工路径 |

MCP 若返回 2004 年建设部令第 134 号：记噪声，改引 2018 修正后再写入 `L#`。

### 4.3 发包人资料与必须依据勘察成果

发包人按时提供真实、准确的设计基础资料：立项/规划批准、红线图、勘察报告、设计任务书、设备资料。资料错误导致返工、停工或修改设计：发包人按实际消耗工作量增付费用（民法典第 805 条）。

条例第 41 条：设计单位未根据勘察成果文件进行工程设计的，依法处罚。修改句：施工图设计以经确认的勘察报告为依据；勘察报告未到或与现场严重不符时，设计人书面通知并中止相应专业出图，不得冒险出图。禁止“勘察未完成也可先出施工图”。

### 4.4 交付、确认与施工配合

交付物是各阶段设计文件及约定的概预算、材料设备清单，不是竣工工程。验收程序：提交 → 发包人书面确认或送审 → 异议期 → 施工图另走图审。付款、使用不当然等于验收合格。

施工配合包括交底、现场解决图纸问题、参加竣工验收，不是“随叫随到的免费咨询”。修改句把次数、驻场、差旅是否含价写清。

设计人不得指定建筑材料、构配件、设备的生产厂、供应商（条例第 27 条），除非有特殊要求并写明技术指标。修改句删除指定品牌句，改为性能指标。

## 节点 5　价款、限额、变更、质保金

1. 计价三选一并写死：按建筑面积单价 / 按工程造价比例 / 固定总价。协议书与专用条款冲突则并列 `C#`，修改句统一。未给出的数字写 `【待填】`。费用构成写明是否包含图审费、专家评审费、晒图费、差旅、二次深化、现场配合。
2. 支付节点建议对应阶段，不得只绑“出图”：预付款 → 方案确认 → 初设批复或确认 → **施工图图审合格** → 施工配合尾款。禁止“出图后付清全部费用且不得异议”。
3. **限额设计**：限额数字、口径（含税/不含税、是否含装修）和允许误差必须附件化。施工图预算或概算超出限额约定比例：设计人无偿优化。限额因发包人变更功能、标准或规划调整而突破：另行计价，不得强迫无偿改到新标准。
4. **设计变更**：分因处理。设计人错漏碰缺：无偿改图并按第 800 条担责。发包人改任务书、资料错误或擅自改图：增付费用、顺延周期，责任切回发包人。变更图纸同样报审（图审管理办法第 14 条）。
5. **质保金**：设计文本未约定质保金，不硬套施工质保金结构。若出现预留：  
   - 比例不得高于结算总额 3%，依据《建设工程质量保证金管理办法》第 7 条（建质〔2017〕138 号）。可用银行保函替代。  
   - **禁止**把 3% 上限写成解释二第 14 条。  
   - 解释二第 14 条是施工合同解除/无效未完工时的返还起算和基数，可作对照，不得写成设计专条。
6. 定金：必须使用“定金”二字才讨论罚则；超过主合同标的额百分之二十的部分不产生定金效力（民法典第 586 条）。不得回引 1983 条例“设计定金 20%”充作现行唯一依据——20% 上限走民法典，不走失效条例。无核验引文不得把 20% 写成现行法结论。
7. 政府投资项目写垫资设计至全部图审通过：红线告知，不改成可履行垫资结构。

## 节点 6　格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 格式条款

为重复使用而预先拟定、订立时未与对方协商。采用 GF-2015-0209 / GF-2015-0210 不当然排除格式条款。提示说明按民法典第 496 条及合同编通则解释第 10 条。仅有勾选或弹窗，不得写成已尽提示。异常条款包括：设计人任何情况下免责、限额过低、出图即视为审批通过、发包人可自行改图、一律归发包人且设计人无署名、默示认可结算。

### 6.2 强制规范

民法典第 153 条、合同编通则解释第 16 条。违反法律、行政法规强制性规定不一律无效。但本类型下列结构不得改写成可履行：

- 无设计资质、超越资质等级、借用资质（条例第 8、17、21、35 条）；
- 必须招标未招或中标无效（招标投标法；解释一第 1 条对施工合同的对照，效力结论仍须核验）；
- 转包、主体部分设计未经书面同意再分包、分包给无资质单位（民法典第 791 条；条例第 19、20 条）；
- 境外企业独立承担初设/施工图并单独盖章出图（建市〔2004〕78 号第 4、11 条）；
- 施工图未经审查批准即约定“可以使用/视为合格”（条例第 33 条；质量管理条例第 11 条）。

禁止用已失效“效力性/管理性”口诀或合同法解释（二）第 14 条代替合同编通则解释第 16 条。禁止把解释二第 3 条（建筑施工企业出借资质）直接写成设计专条；挂靠停笔依据是条例第 8 条。

## 节点 7　第 800 条、擅自改图、著作权、争议解决

### 7.1 设计质量与逾期（民法典第 800 条）

设计质量不符合要求或未按照期限提交设计文件拖延工期，造成发包人损失：继续完善设计，减收或者免收设计费并赔偿损失。

| 文本写法 | 本任务动作 |
| --- | --- |
| “设计人任何情况下不承担责任”或赔偿以象征性金额为限 | 红线删除。限额若保留，不得覆盖故意或重大过失，且应与合同价、可预见的返工和延误损失相称 |
| “图纸仅供参考，施工人自行判断” | 必须改。施工图须满足采购、非标制作和施工需要，并注明合理使用年限（条例第 26 条） |
| 发包人立场要求无限连带、不设上限 | 可谈合理上限；生存级工程事故风险且用户拒绝升级：停止放行建议 |
| 设计人立场要求免责 | 不得协助免责。修改句回到第 800 条三件套 |
| 因发包人变更计划、资料不准或未按期提供工作条件造成返工、停工或修改 | 发包人按实际消耗工作量增付费用（第 805 条），不得写成设计人自负 |

### 7.2 擅自修改设计文件

条例第 28 条：建设单位、施工单位、监理单位不得修改设计文件；确需修改由原设计单位修改，或经原设计单位书面同意委托其他有资质单位修改，修改单位担责。重大修改须报原审批机关。注册建筑师条例（2019 修订）第 27 条：任何单位和个人修改注册建筑师的设计图纸，应当征得该注册建筑师同意（特殊情况不能征得同意的除外）。图审合格后的修改，涉及审查内容的须送原审查机构（图审管理办法第 14 条）。

修改句：禁止发包人、施工人、监理人擅自改图；擅自修改导致的质量、安全、造价和工期后果由修改方承担；原设计人对未被改动的原件仍负责，对篡改部分不负责。

### 7.3 著作权与本项目使用许可

工程设计图、产品设计图属于图形作品（著作权法实施条例第 4 条第十二项）。建筑作品指以建筑物或者构筑物形式表现的有审美意义的作品，不等于施工图本身。

- 委托作品：归属由合同约定；未约定或约定不明，著作权属于受托人（著作权法 2020 修正第 19 条）。
- 署名权是人身权，不得约定“设计人不得署名”或从施工图图签中抹去设计人、注册人员姓名。
- 发包人即使受让财产权或取得本项目独占许可，使用范围以本项目为限；用于其他工程或转让第三方须设计人书面同意并另议费用。
- 设计人保证成果不侵犯第三方著作权、专利权；因抄袭导致停工或索赔的，设计人负责抗辩并赔偿。发包人提供的资料侵权，由发包人担责。

修改句禁止输出“全部知识产权归发包人所有，设计人放弃署名”。可退让：财产权归发包人 + 本项目独占使用 + 设计人保留署名和作品汇编、评奖、申报奖项的权利。

### 7.4 优先受偿

不得把设计费写成当然享有民法典第 807 条优先受偿。该字段默认 `依据不足，无法形成结论`。修改句：删除“享有工程价款优先受偿权”；改为到期未付的普通债权催告、逾期利息，以及支付担保（保函或共管账户）。不把解释二第 17 条停窝工排除优先权写成设计默认节点。

### 7.5 违约、解除、管辖

1. 逾期交图与逾期付款应对等：日违约金比率对称；超过同一天数可书面解除。解除后按已完阶段成果结算，移交已付款对应的设计文件，并约定未付款部分的使用授权是否终止。
2. 构成违约不等于当然解除。法定解除只点名催告或目的不能实现。规划变更或项目停建：按已完工作量结算并补偿合理损失，不得只写“双方协商”。
3. 争议解决：与建设工程不动产相关的诉讼，约定其他法院可能被认定无效。出现仲裁条款不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核。可研咨询或无项目委托设计若被误送本技能，应已在节点 1 负触发，不在本节点选管辖。
