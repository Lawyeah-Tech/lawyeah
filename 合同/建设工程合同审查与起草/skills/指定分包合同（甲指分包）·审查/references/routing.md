# 边界与路由

本技能只审查 **建设工程 / 指定分包合同（甲指分包）**（发包人指定专业分包人，总承包人与其签署分包合同，纳入总包管理）。

| 主要目标 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 发包人直接与专业承包人签约，总包不签分包合同 | `独立发包合同（平行发包）·审查` |
| 出借资质、只收管理费、无真实隶属 | 本技能停笔告知；不打开挂靠原子改成可履行稿 |
| 总包自主选择专业分包人、无指定事实 | `专业分包合同·审查` |
| 业主直接发包、按图施工的施工总承包本约 | `建设工程施工合同·审查` |
| 劳务作业换劳务报酬，不含主材和专业技术管理 | `劳务分包合同·审查` |
| 企业内部承包经营 | `内部承包合同·审查` |
| 设计+采购+施工或设计+施工一体 | `工程总承包合同·审查` |
| 核心给付是勘察 | `建设工程勘察合同·审查` |
| 单独设计发包，无采购施工组织 | `建设工程设计合同·审查` |
| 联合体成员之间的内部分工、损益、退出 | `联合体协议·审查` |
| 监理 | `建设工程监理合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `指定分包合同（甲指分包）·起草` |
| 已签未争、履约节点 | 本套导航的履约步骤 |
| 已成争（效力、质量索赔、实际施工人、停工围堵） | `或` 或建设争议对应原子 |
| C 端大众快检 | 只分流，不回改 |

挂靠、无资质指定、把主体结构以甲指肢解、把平行发包改成总分包外观：留在本技能只出告知并停笔，不转去“改成可履行稿”，也不转争议原子充作签前修改。

专业版未收录的 P1 场景不会安装本原子。若用户拿本类型文本来找专业版：输出 `unavailable`，提示或回引擎，不得用施工总包或专业分包原子硬套。
