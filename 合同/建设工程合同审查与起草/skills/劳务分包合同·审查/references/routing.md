# 边界与路由

本技能只审查 **建设工程 / 劳务分包合同**（劳务作业分包，对价为劳务报酬）。

| 主要目标 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 人+材+机+专业技术管理的专业工程分包 | `专业分包合同·审查` |
| 工人由用工单位直接指挥的劳务派遣 | `对象是劳动力工人完全服从总包或用工单位指挥派遣单位只出人→` |
| 业主直接发包、按图施工的施工总承包本约 | `建设工程施工合同·审查` |
| 设计+采购+施工或设计+施工一体 | `工程总承包合同·审查` |
| 核心给付是勘察 | `建设工程勘察合同·审查` |
| 单独设计发包，无采购施工组织 | `建设工程设计合同·审查` |
| 联合体成员之间的内部分工、损益、退出 | `联合体协议·审查` |
| 监理 | `建设工程监理合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `劳务分包合同·起草` |
| 已签未争、履约节点 | 本套导航的履约步骤 |
| 已成争（效力、欠薪群体事件、实际施工人、工伤立案） | `或` 或劳动/建设争议对应原子 |
| C 端大众快检 | 只分流，不回改 |

挂靠、转包、把主体工程当劳务、无资质或个人承揽、再分包：留在本技能只出告知并停笔，不转去“改成可履行稿”，也不转争议原子充作签前修改。

专业版未收录的 P1 场景不会安装对应原子。若用户拿这些文本来找专业版：输出 `unavailable`，提示或回引擎，不得用本劳务分包原子硬套。
