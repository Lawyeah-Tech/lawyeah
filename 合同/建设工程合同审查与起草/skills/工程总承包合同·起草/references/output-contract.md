# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的价格、工期、数量；把已失效《合同法》及其解释、法释〔2004〕14 号、法释〔2018〕20 号写入结论；把质保金 3% 上限写成解释二第 14 条；删掉设计义务后当施工审；写“可以先开工后补证”；把整份 EPC 总价写成优先受偿本金。

## 1. 触发、单方立场与成果状态

立场（发包人或承包人）、授权、签署状态、主要目标、模式（EPC 或 DB）。负触发写路由，不启动实体审查。仅按图施工、单独勘察/设计、BT/DBO、联合体内协必须在本节写明负触发，不得进入第 5–8 节。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、2004/2018 建工解释或六个月优先受偿时记噪声，不得写入 `L#`。解释二条号与最高人民法院官网法释〔2026〕12 号不一致时记 `conflict`，以官网为准。总承包管理办法或质保金管理办法漏检时改核官方文本并记来源。

## 3. 类型与加载路径

父级、子级、定性理由、易混切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读施工合同或其他类型。挂靠或违法分包写停笔告知，不填可履行结构。

必须写明已切开：施工总承包 / 勘察 / 单独设计 / 专业分包 / 劳务分包 / 联合体内协 / 监理 / BT / DBO / 挂靠。

## 4. 主体、授权、双资质与文本版本

主体表：签约名、履行名、付款名、发票名、工程总承包项目经理、设计负责人、施工负责人、授权签字人。承包人设计资质与施工资质是否同时具备，或联合体各方资质与连带签署是否被材料提及。版本表：协议书、专用条款、通用条款、发包人要求、承包人建议书、招标文件、投标文件、中标通知书、价格清单、聊天确认；冲突并列，不选对用户有利的一版。

## 5. 给付闭环

设计/采购/施工界线、发包人要求是否可执行、性能保证与试运行指标、价金形式（是否总价包干）、包干范围与书面变更、物价/地质风险归谁、暂估价程序、里程碑支付、发票。缺口标 `G#`，不补商业数字。规划许可写成生效条件，施工许可写成开工先决，不写成已经完成，不写先开工后补证。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹。强制规范只区分管理性与是否导致民事行为无效。本节点必须单独回答：双资质或联合体、必须招标、先定后招、挂靠转包。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

本类型风险表至少覆盖（有文本才填，无对应条款标缺口）：

- 是否真有设计义务（EPC ≠ 施工）；
- 双资质或联合体连带；
- 招标 / 先定后招 / 中标无效；
- 发包人要求是否可执行；
- 总价包干范围、书面变更、物价/地质、暂估价；
- 单一责任（审图不免责）；
- 质保金比例（管理办法 3%）与返还起算（解释二第 14 条只写起算，不写 3%）；
- 优先受偿限于施工部分，设计费另列；
- 规划许可生效、施工许可开工；转包挂靠停笔。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。禁止输出无修改句的色块表。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`，不编造。禁止只给原则、不给句子。

质保金修改句必须引用管理办法第 7 条；返还起算才引用解释二第 14 条。禁止在同一句里把 3% 写成解释二第 14 条。

## 9. 谈判与签署提醒

谈判顺序：先红线（设计义务、双资质/联合体、招标、挂靠转包、无证开工），再必须改（包干与变更切开、单一责任、质保金 3%、暂估价程序），最后可优化。签署提醒：联合体全员签章；中标后三十日内按招标投标文件签约；授权与公章（禁止只盖项目部章）；日期不得早于中标通知书；发包人要求与价格清单一并装订。不指导倒签或补假招标、假资质、假联合体。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本技能交付可编辑草稿、未决项、自审风险表和自审后修改句。草稿必须覆盖本类型起草必写、附件必附与禁止出现。待签评改转 `工程总承包合同·审查`。不是履约交底、争议文书或效力保证。挂靠/先定后招/必须招标未招已停笔的，本节重复告知一次。
