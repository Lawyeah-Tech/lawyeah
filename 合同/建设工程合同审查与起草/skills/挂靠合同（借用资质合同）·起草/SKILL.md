# 挂靠合同（借用资质合同）·起草

## 任务目标

在单一立场下，只对 **建设工程 / 挂靠合同（借用资质合同）** 出停笔告知：核心给付是不具备相应资质的单位或个人借用有资质建筑施工企业的名义承揽工程，并对价为管理费、牌照费或固定上缴。不得写成可履行挂靠。

本技能的核心成果是**识别并停笔**。输出识别依据、无效与责任告知、可回链文本位置的停笔告知句或红线、合规改道点名。不得把本约改成可履行挂靠。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。显示名为「挂靠合同（借用资质合同）·起草」。待签评改转 `挂靠合同（借用资质合同）·审查`。

`depends-on` 为空。不要求先跑导航。

不交付：他类型起草、待签文本签前审查、履约交底、争议文书、效力保证、可履行挂靠文本、真实内部承包整案、真实专业分包或劳务分包整案、施工本约整案、管理费或工程款终局数字。

## 工作边界

正触发：用户要按已谈妥事实出挂靠或借用资质安排；尚未签署，尚未成争；核心给付是借用或出借建筑业企业资质、营业执照或企业名义承揽建设工程，且对价是管理费、牌照费或固定上缴，或挂靠人自筹资金、自行组织施工、自负盈亏。本任务只出停笔告知，不出可履行挂靠正文。标题伪装为内部承包、联营、合作、项目目标管理责任书的，按核心给付留在本技能。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 有完整待签文本要评改 → `挂靠合同（借用资质合同）·审查`；
- 承包人是发包企业在册职工，存在真实连续劳动合同、社保与工资，且企业统一技术、质量、安全、财务、劳务管理 → `内部承包合同·审查`；专业版未收录该原子时输出 `unavailable`，不得用本技能把真实内部承包改写成挂靠停笔结论，也不得把挂靠包装成内部承包后代审；
- 分包人具备相应专业资质，发包人书面同意，按专业工程计价而非出借总包名义 → `专业分包合同·审查`；
- 分包人具备相应劳务作业资质，仅分包劳务作业 → `劳务分包合同·审查`；
- 送审主文件是发包人与承包人之间的施工本约 → `建设工程施工合同·审查`；
- 两个以上承包单位联合共同承包 → `联合体协议·审查`；
- 工程总承包本约主导 → `工程总承包合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务出停笔告知；
- 已签只问进度款、移交现场、管理费催收节点 → 本套导航的履约步骤；
- 已成争（催告退还管理费、质量索赔、讨薪、立案仲裁）→ 合同争议或建设工程争议领域。

假社保包装、假任命、规避招投标或资质监管、把挂靠改成可履行：只出告知，不改写成可履行结构。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成。每一闸必须给出停笔告知句或明确转出口径，禁止只打红黄绿。

1. **借用资质无效风险只告知**。核验后可写：现有依据支持，没有资质的实际施工人借用有资质建筑施工企业名义签订的施工合同，应当依据民法典第 153 条第一款认定无效；挂靠人与被挂靠人之间的借用名义、管理费约定亦不发生借用资质所追求的履行效力。不得保证法院“必然判决无效”。不得写成“可以做成有效挂靠”。验收合格时的折价补偿只点名民法典第 793 条，不把无效合同改成可履行。
2. **与内部承包切开**。真实劳动关系 + 企业实质管理 → 负触发 `内部承包合同·审查`。仅有内部承包标题、临时社保、任命书，但自筹资金、自负盈亏、企业只收固定管理费、现场五大员不是本单位人员 → 留本技能。禁止打开其 method，禁止输出把挂靠改成内部承包的整套可签署条款。
3. **用户坚持可履行则整体停止**。用户要求改到能签、保留管理费和体外走账、补假社保即可过关、派驻安全员就算合法：停止策略输出，不再给可履行修改句。
4. **禁止可履行挂靠路径**。不写：项目经理假任命、临时假劳动合同或假社保路径、管理费催收与违约金可执行结算、项目章外借使用范围、工程款进入个人账户或空壳公司的走账句。
5. **与专业分包、劳务分包、施工本约、联合体切开**。见工作边界。禁止套用施工验收、进度款、合法分包资质或联合体连带作为本类型主路径。
6. **合规改道只点名**。可点名：真实劳动关系内部承包、真实专业分包、真实劳务分包、将团队纳入子公司或股权。本任务不起草这些文本，不把知识库“风控方案”写成挂靠可签署条款。

附加必落告知（有事实则单列，无事实在缺口节说明）：

- **对外施工合同**：被挂靠人与发包人签署的施工合同通常亦因借用资质而无效。发包人是否明知只影响过错分担，不救挂靠协议。
- **质量与用工**：出借方与借用方对因出借资质造成的质量损失连带；挂靠招用劳动者时，被挂靠单位可能被请求承担用工主体责任。内部追偿约定不能对抗受害人、农民工或发包人。
- **管理费**：不得写成被挂靠人必然可收。不得把已失效的“收缴非法所得”写成现行必然后果。已付管理费是否返还：依据不足则字段停止。
- **超越资质可补正 ≠ 挂靠可补正**：竣工前取得自身相应资质，不适用于借用他人名义。

必须有停笔告知句。每个风险回链文本位置。禁止复制 `内部承包合同·审查` 或施工/分包 method。禁止半截 Skill ID。

## 建立起草坐标

确认：使用者与授权；单方立场（挂靠人/实际施工人、被挂靠人/名义承包人、拟签字项目负责人）；相对方；全文及任命/授权/社保/与发包人合同附件版本；工程名称；管理费安排；资金与印章安排；是否主张本企业职工；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的管理费比例、工程名称、期限用 `【待填】`，不编造。

不得输出“必然有效”“可以做成有效挂靠”“对方必然接受”“唯一必得管理费或工程款”。无效结论必须回链已核验 `L#`，并表述为“现有依据支持……认定无效”，同时声明不保证个案裁判。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law`（法律结论 required）：核验借用资质施工合同无效、强制性规定例外是否被专条排除、质量连带、折价补偿、挂靠用工主体责任、禁止出借名义。
- `search_practiced`（optional）：补名为内部承包实为挂靠、管理费主张等争点。返回“补社保即可合法”“发包人不知情则对外合同有效”“收缴非法所得为现行规则”时记噪声。
- `search_template`（optional）：只借栏目结构。范本写“自主经营、独立核算、自负盈亏 + 出借资质 + 管理费”不得当规则，不得抄进建议句。

不虚构案件系统。`search_law` 返回已失效《合同法》及其解释、法释〔2004〕14 号收缴条款时记为噪声，不得写入 `L#`。建筑法第 26、66 条若只返回 1997 文本并标“已被修改”，该两条法律结论字段停止，改用已核验的质量管理条例第 25 条、法释〔2020〕25 号第 1 条，并提示运行时重核 2019 修正文本。


## 起草模式

本原子只承担本类型起草。有完整待签文本要评改时，转 `挂靠合同（借用资质合同）·审查`。本类型条件已谈妥、要出己方稿时，留在本任务出停笔告知并自审，停止包装成可履行。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。本模式的“起草”是停笔告知书，不是可履行挂靠正文。商业数字未给用 `【待填】`。出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿。不得只交白稿，更不得交可履行挂靠稿。他类型出稿、已签履约、已成争：仍负触发。真实内部承包或合法分包：负触发对应原子，不在本任务包装。

**起草必写**

- **停止包装成可履行。** 只交识别依据、无效与责任告知、合规改道点名，不开篇写成履约合同。
- 写明：现有依据支持，没有资质的实际施工人借用有资质建筑施工企业名义签订的施工合同，应当依据民法典第 153 条第一款认定无效；挂靠人与被挂靠人之间的借用名义、管理费约定亦不发生借用资质所追求的履行效力。不得保证法院必然判决无效。
- 出借方与借用方对因出借资质造成的质量损失连带；挂靠招用劳动者时，被挂靠单位可能被请求承担用工主体责任。内部追偿约定不能对抗受害人、农民工或发包人。
- 验收合格时的折价补偿只点名民法典第 793 条，不把无效合同改成可履行。
- 合规改道只点名：真实劳动关系内部承包、真实专业分包、真实劳务分包、将团队纳入子公司或股权。本任务不起草这些文本。

**附件必附**

- 识别摘录表：名义、管理费或牌照费、自筹自负、有无真实隶属、五大员是否本单位人员。
- 不附管理费结算、印章使用范围、体外走账或假任命/假社保安排。

**禁止出现**

- 可履行挂靠正文，或“可以做成有效挂靠”。
- 项目经理假任命、临时假劳动合同、假社保路径。
- 管理费催收与违约金可执行结算。
- 项目章外借使用范围；工程款进入个人账户或空壳公司的走账句。
- “补社保即可把挂靠做成有效内部承包”“派驻安全员即可合法履行”。
- 把超越资质可补正写成挂靠可补正。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口，不代替节点。

0. 签署状态与成果分流
1. 类型识别与单目录加载（切开内部承包 / 专业分包 / 劳务分包 / 施工本约 / 联合体）
2. 挂靠识别信号与劳动关系真实性
3. 无效风险告知（专条优先，不用但书救挂靠）
4. 质量、用工、表见代理、税收责任告知
5. 禁止可履行挂靠路径
6. 合规改道只点名
7. 倒签、假材料、越权保证
8. 按框架六步出停笔告知并自审

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、假社保、假任命、假中标；用户坚持把本约改成可履行挂靠；保证挂靠有效或管理费必然可收。
- `字段停止`：法域未核验；劳动关系真实性无法识别且用户主张内部承包；建筑法第 26、66 条 2019 文本未核验时，这两条不写入 `L#`；管理费返还或收缴无现行专条。
- `目标停止`：主目标已变为待签评改、履约交底、管理费诉讼文书，或用户要把本约改成真实内部承包/分包整稿。

生存级工程款、重大质量安全或行政处罚风险且用户拒绝升级：停止“可以签署”建议。
