# 边界与路由

本技能只审查 **建设工程 / 专业分包合同**（总承包人将承包范围内专业工程依法发包给持相应专业承包资质单位的待签文本）。

| 主要目标 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 业主发包、按图施工、交付合格工程 | `建设工程施工合同·审查` |
| 纯劳务分包：只出人工及小型机具，不含主材、大型机械和技术管理 | `劳务分包合同·审查` |
| 设计+采购+施工或设计+施工一体对业主 | `工程总承包合同·审查` |
| 编制岩土、水文地质等勘察文件 | `建设工程勘察合同·审查` |
| 编制方案/初步/施工图设计文件 | `建设工程设计合同·审查` |
| 监理 | `建设工程监理合同·审查` |
| 联合体成员之间的内部分工 | `联合体协议·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `专业分包合同·起草` |
| 已签未争、履约节点（进场、进度款、隐蔽验收排班） | 本套导航的履约步骤 |
| 已成争（效力、违法分包定性、实际施工人追索、索赔） | `或`、`或` 或 `或` |
| C 端大众快检 | 只分流，不回改 |

挂靠、转包、再分包、主体结构分包、未经发包人同意、必须招标未招、无资质/越级、个人承揽：留在本技能只出告知并停笔，不转去“改成可履行稿”，也不转争议原子充作签前修改。

专业版未收录的 P1 场景不会安装对应原子。若用户拿这些文本来找专业版：输出 `unavailable`，提示或回引擎，不得用本专业分包原子硬套。
