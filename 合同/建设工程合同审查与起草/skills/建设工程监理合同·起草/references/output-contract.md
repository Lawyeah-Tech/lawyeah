# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的价格、工期、人员数量；把已失效《合同法》及其解释、法释〔2004〕14 号、法释〔2018〕20 号写入结论；把解释一或解释二施工专条写成监理专条；把监理费写成当然享有优先受偿；把监理人对全部质量瑕疵写成无限连带；把无资质、挂靠、关联监理或影子总监改成可履行；把施工、设计、勘察或 EPC 当本类型审。

## 1. 触发、单方立场与成果状态

立场（委托人或监理人）、授权、签署状态、主要目标、监理阶段。负触发写路由，不启动实体审查。施工、设计、勘察、EPC、分包、全过程咨询混签、已成争必须在本节写明负触发，不得进入第 5–8 节。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、2004/2018 建工解释或六个月优先受偿时记噪声，不得写入 `L#`。解释二条号与最高人民法院官网法释〔2026〕12 号不一致时记 `conflict`，以官网为准，并注明无监理专条。建筑法若返回 1997 文本改引 2019 修正。质量管理条例若返回 2000 未修订文本改引 2019 修订。

## 3. 类型与加载路径

父级、子级、定性理由、易混切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读施工、设计或勘察。挂靠、转让监理业务或关联监理写停笔告知，不填可履行结构。

必须写明已切开：施工 / 设计 / 勘察 / 总承包 / 分包 / 全过程咨询或项目管理 / 挂靠。

## 4. 主体、授权、监理资质与文本版本

主体表：签约名、履行名、付款名、发票名、总监理工程师（姓名、注册号）、授权签字人。监理资质类别、等级是否覆盖本工程专业与规模；事务所资质是否误接强制监理工程。施工承包人、主要材料设备供应商是否已定，与监理人有无利害关系线索。版本表：协议书、专用条款、通用条款、监理大纲或投标文件、人员名单、廉政协议、招标文件、投标文件、中标通知书、聊天确认；冲突并列，不选对用户有利的一版。

## 5. 给付闭环

监理标段与专业范围（含/不含人防、精装、绿化）、阶段是否覆盖施工期+竣工验收期、三控两管一协调及安全监理职责是否落到可执行动作、旁站部位与巡视频次、授权界限（自由裁量 vs 必须报批）、签证闭环、书面通知施工企业、进场与第一次工地会议、设施提供、非监理人原因延期服务费、酬金与节点、发票。缺口标 `G#`，不补商业数字。批准、招标、施工许可写成生效条件或期限，不写成已经完成。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹。强制规范只区分管理性与是否导致民事行为无效。本节点必须单独回答：监理资质覆盖、必须招标、挂靠或转让、与施工/供应单位有无利害关系、独立性是否被掏空、总监是否挂证、赔偿限额是否覆盖故意或重大过失。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

本类型风险表至少覆盖（有文本才填，无对应条款标缺口）：

- 是否真是独立监理给付（≠施工/设计/勘察/EPC/项目管理咨询）；
- 监理资质专业与等级覆盖；总监注册、劳动关系与现场履职；
- 与施工承包单位、材料设备供应单位有无隶属或其他利害关系；
- 独立性：委托人不得越过监理下达质量或造价实质性指令；监理人不得仅作建议而无指令权；
- 招标 / 先定后招 / 中标无效；强制监理范围是否被文本否认；
- 书面通知施工企业监理单位、内容和权限；
- 范围、旁站与巡视、授权签证闭环、期限与延期费；
- 监理责任≠施工全部质量连带；限额不得覆盖故意或重大过失；串通或合格签字不合格的法定连带不得约定排除；
- 监理费不得写成当然优先受偿；挂靠、转让、影子总监停笔。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。禁止输出无修改句的色块表。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`，不编造。禁止只给原则、不给句子。

责任修改句不得写成“监理人对工程全部质量瑕疵承担连带责任”，也不得写成“监理人任何情况下不承担责任”或“赔偿以监理酬金为限、含故意或重大过失”。

独立性修改句不得写成“监理人须按委托人临时口头指示签认合格”。

利益冲突修改句不得写成“虽有关联但设置隔离即可承接”。

## 9. 谈判与签署提醒

谈判顺序：先红线（类型切开、资质、关联监理、挂靠转让、必须招标未招、影子总监、无限质量连带或全面免责、独立性被掏空），再必须改（范围与阶段、旁站巡视、授权签证闭环、书面通知施工企业、延期费、合理限额），最后可优化。签署提醒：中标后三十日内按招标投标文件签约；授权与单位公章；日期不得早于中标通知书；人员名单、廉政协议、监理大纲一并装订；签署后按建筑法第 33 条书面通知施工企业。不指导倒签或补假招标、假资质、假总监到岗。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本技能交付可编辑草稿、未决项、自审风险表和自审后修改句。草稿必须覆盖本类型起草必写、附件必附与禁止出现。待签评改转 `建设工程监理合同·审查`。不是履约交底、争议文书或效力保证。挂靠/先定后招/必须招标未招/无资质/关联监理/影子总监已停笔的，本节重复告知一次。
