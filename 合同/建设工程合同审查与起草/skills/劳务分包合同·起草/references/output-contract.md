# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的价格、人数、面积；把已失效《合同法》及其解释、法释〔2004〕14 号、法释〔2018〕20 号写入结论；把无资质或包工头改成可进场；把主体工程当劳务改成可履行；把派遣改写成劳务分包以规避许可；写“民营企业之间背靠背有效”。

## 1. 触发、单方立场与成果状态

立场（劳务作业发包人或劳务作业承包人）、授权、签署状态、主要目标、作业工种。负触发写路由，不启动实体审查。专业分包、派遣、施工总承包、把主体工程当劳务必须在本节写明负触发或停笔，不得进入第 5–8 节充当可履行修改。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、2004/2018 建工解释或 1997 年建筑法未修正文本时记噪声，不得写入 `L#`。建筑法与 2019 修正冲突时以 2019 修正为准。建市规〔2019〕1 号或 2025 年修订《保障中小企业款项支付条例》漏检时改核官方文本并记来源。

## 3. 类型与加载路径

父级、子级、定性理由、易混切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读专业分包、派遣或其他类型。挂靠、把主体工程当劳务或无资质个人承揽写停笔告知，不填可履行结构。

必须写明已切开：专业分包 / 劳务派遣 / 施工总承包 / 工程总承包 / 勘察 / 设计 / 挂靠 / 包工头。

## 4. 主体、授权、劳务资质与文本版本

主体表：签约名、履行名、付款名、发票名、工资专户名、现场负责人、专职安全员、授权签字人。施工劳务资质与安全生产许可证是否被材料提及。版本表：正文、工种/部位清单、单价表、安全生产协议、工资支付承诺、总包合同中的分包限制、聊天确认；冲突并列，不选对用户有利的一版。

## 5. 给付闭环

工种、部位、作业量；供应边界（人工 / 小型机具 / 辅材 vs 主材 / 大中型机械 / 周转材 / 技术管理）；是否触及主体结构施工责任；劳务报酬构成与节点；专户代发；发票。缺口标 `G#`，不补商业数字。实名制、专户开立写成履行期限，不写成已经完成。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹。强制规范只区分管理性与是否导致民事行为无效。本节点必须单独回答：施工劳务资质、个人承揽、主体结构是否被当作劳务、主材/大型机械是否由劳务方计取、挂靠或再分包、背靠背是否落入法释〔2024〕11 号。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

本类型风险表至少覆盖（有文本才填，无对应条款标缺口）：

- 施工劳务资质 + 安全生产许可证 + 是否法人；
- 是否把主体工程/主体结构施工当劳务；
- 供应边界是否滑向专业分包（主材、大型机械、周转材、技术管理）；
- 是否实为劳务派遣（谁指挥工人）；
- 挂靠、转包、再分包、包工头；
- 农民工工资专户、按月代发、实名制；
- 背靠背是否绑住工资或劳务报酬；
- 欠薪先行清偿与追偿；
- 工伤保险 / 用工主体责任预埋。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。禁止输出无修改句的色块表。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`，不编造。禁止只给原则、不给句子。

停笔项（无资质、包工头、挂靠、主体工程当劳务、再分包）只给告知句，不给“改完就能进场”的可履行句。

## 9. 谈判与签署提醒

谈判顺序：先红线（资质、主体工程、挂靠、派遣切开、主材/大型机械），再必须改（专户代发、背靠背、实名制、现场管理人员），最后可优化。签署提醒：公章与资质证书名称一致；禁止只盖项目部章或个人名章充任承包人；附件装订安全生产协议、单价表、拟进场花名册；日期不得伪造早于实际协商日。不指导倒签进场或补假资质、假劳动合同。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本技能交付可编辑草稿、未决项、自审风险表和自审后修改句。草稿必须覆盖本类型起草必写、附件必附与禁止出现。待签评改转 `劳务分包合同·审查`。主体工程当劳务、包工头、挂靠、再分包：停止包装成可履行，只告知。不是履约交底、争议文书或效力保证。挂靠/主体工程当劳务/无资质已停笔的，本节重复告知一次。
