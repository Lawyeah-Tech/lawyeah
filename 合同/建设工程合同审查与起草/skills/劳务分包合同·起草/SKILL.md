# 劳务分包合同·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构，不证明本约条款已被接受。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、法释〔2004〕14 号、法释〔2018〕20 号、建市〔2014〕118 号或 1997 年建筑法未修正文本当作现行规则。
- 建筑法条号引用 2019 修正。律页若先返回 1997 文本并标“已被修改”，改引 2019 修正第 26、29 条，不把旧令号写入 `L#`。建市规〔2019〕1 号第 12 条与分包管理办法第 14 条并存时，认定“名为劳务、实为主体结构分包或计取主材/大型机械”优先核验建市规第 8、12 条。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **建设工程 / 劳务分包合同**，输出可编辑草稿、未决项，并用本类型硬闸自审后给出风险表和修改句。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。`depends-on` 为空。显示名为「劳务分包合同·起草」。待签评改转 `劳务分包合同·审查`。

不交付：他类型起草；待签文本签前审查；履约交底；争议文书；有效性或对方接受的保证；把无施工劳务资质、包工头、挂靠、把主体工程当劳务、假派遣或再分包改成可履行结构。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿；尚未签署，尚未成争；核心给付是施工总承包人或专业承包人将其承包工程中的**劳务作业**发包给劳务作业承包人，对价是**劳务报酬**，范围原则上只含人工、小型机具和辅助材料。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 有完整待签文本要评改 → `劳务分包合同·审查`；
- 人+材+机+专业技术管理、持专业承包资质、通常需建设单位认可 → `专业分包合同·审查`；
- 对象是劳动力、工人完全服从总包或用工单位指挥、派遣单位只出人 → `对象是劳动力工人完全服从总包或用工单位指挥派遣单位只出人→`；
- 业主直接发包、按图施工的施工总承包本约 → `建设工程施工合同·审查`；
- 设计+采购+施工或设计+施工一体对发包人 → `工程总承包合同·审查`；
- 单独勘察或单独设计发包 → `建设工程勘察合同·审查` 或 `建设工程设计合同·审查`；
- 监理 → `建设工程监理合同·审查`；
- 联合体成员之间的内部分工 → `联合体协议·审查`；
- 无可读文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问进场人数、专户拨付日、考勤留痕 → 本套导航的履约步骤；
- 已成争（欠薪群体事件、违法分包效力确认、实际施工人追索、工伤索赔立案）→ `或` 或劳动/建设争议对应原子。

挂靠、转包、把主体工程当劳务、无资质或个人承揽：只出告知，不改写成可履行结构。用户坚持“改到能进场/能过检查”：整体停止。

## 本类型硬闸

执行时必须同时守住。每闸必须能落到修改句或明确停笔，不得用专业分包、劳务派遣或施工总承包口径替换。

1. **劳务作业分包资质**  
   劳务作业承包人须具备施工劳务资质（不分类别与等级）并持有安全生产许可证；必须是法人单位。未见资质或许可证：签署能力字段停止，不得写“可以进场”。个人、包工头或无资质组织承揽：红线停笔。地方“取消劳务资质、改为备案”未核验前标 `G#`，不编造全国已取消。  
   修改句方向：主体栏写入施工劳务资质证号、安全生产许可证号和法人全称；删除个人签字承揽或“班组承包”作为合同相对方的写法。

2. **不得把主体工程当劳务**  
   施工总承包范围内工程**主体结构的施工**必须由承包人自行完成。标题或范围写成“主体工程/主体结构劳务总包”、把整栋主体连同技术管理交出去，或专业作业承包人承包全部工程、只上缴管理费：按转包或违法分包停笔，不改成可履行劳务稿。钢结构除外只排除该项行政认定的特例，不得据此把钢结构主体连同主材、大型机械写成劳务。  
   修改句方向：停笔告知；若来稿其实只是主体部位上的钢筋绑扎、模板、砌筑等纯作业，把范围改回工种+部位+作业量，并写明不含主体结构施工责任。

3. **与专业分包切开**  
   劳务作业只出人工、小型机具和辅材。还计取主要建筑材料款、大中型施工机械或主要周转材料费用，或承担专业技术管理：负触发 `专业分包合同·审查`，或在本任务点名“名为劳务、实为专业分包/违法分包”后停笔。纯劳务一般无需建设单位书面同意；总包合同另有约定的，按约定补同意或备案，不得把“无需同意”抄成专业分包也能免同意。  
   修改句方向：供应边界写死“仅含人工费、手持机具及辅材；主材、周转材和大中型机械由劳务作业发包人供应并保留所有权”。名实已是专业工程则分流，不在本任务改资质类别。

4. **与劳务派遣切开**  
   劳务分包交付的是作业成果，承包人自行招用、管理工人并承担作业安全。工人花名册由总包直接指挥、承包人只按人头收费、无现场管理人员：按派遣或假外包审，负触发 `对象是劳动力工人完全服从总包或用工单位指挥派遣单位只出人→`。禁止把无《劳务派遣经营许可证》的供人安排改写成劳务分包以规避许可。  
   修改句方向：写明承包人派驻现场负责人、专职安全员，工人与承包人订立劳动合同，作业安排由承包人组织；删除“人员服从发包人任意调遣、按人头包干、发包人直接退回工人”的派遣句。

5. **挂靠 / 转包 / 再分包停笔**  
   借用资质、只收管理费、无真实隶属、劳务再分包：只告知，不改成可履行。用户坚持“改成内部承包/班组承包就能进场”：整体停止。  
   修改句方向：停笔告知。不写假社保、印章外借、管理费结算或可履行资金路径。合法专业分包走 `专业分包合同·审查`，真实派遣走 `对象是劳动力工人完全服从总包或用工单位指挥派遣单位只出人→`，只点名不代起草。

6. **农民工工资专户与背靠背**  
   劳务报酬与工资支付必须切开：工资走农民工工资专用账户、按月考核代发；不得以“业主未付总包、总包不付劳务”对抗工资专户拨付。大型企业对中小企业的第三方付款前提，按法释〔2024〕11 号和 2025 年修订《保障中小企业款项支付条例》第 9 条处理，不得写成“民营企业之间背靠背有效”。  
   修改句方向：删除以业主付款为劳务报酬支付前提的句子；工资部分改为专户代发；企业间劳务管理费另列，且不得把工资绑在第三方付款上。

## 建立起草坐标

确认：使用者与授权；单方立场（劳务作业发包人或劳务作业承包人，不得同时服务）；相对方；全文、工种/部位清单、单价表、安全生产协议、工资支付承诺、实名制附件版本；施工劳务资质与安全生产许可证是否被提及；作业是否触及主体结构；是否含主材或大型机械；现场谁指挥工人；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的单价、人数、面积用 `【待填】`，不编造。

`基本面.md` 把背靠背写成“实践中极难支持”、把总包对工人的责任写成“欠付劳务费范围内直接支付”、或把地方备案写成全国前置的，以本技能 `method.md` 与运行时核验为准，不把知识库过时表述写成现行法。

## 起草模式

本原子只承担本类型起草。有完整待签文本要评改时，转 `劳务分包合同·审查`。本类型条件已谈妥、要出己方稿时，留在本任务按三闸落稿并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。按框架六步落稿。商业数字未给用 `【待填】`。出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。把主体工程当劳务、包工头、挂靠、再分包或无证派遣改写成劳务分包：停止包装成可履行，只告知。

**起草必写**

- 劳务作业承包人须是法人；主体栏写入施工劳务资质证号、安全生产许可证号和法人全称。
- 范围写成工种+部位+作业量；供应边界写死“仅含人工费、手持机具及辅材；主材、周转材和大中型机械由劳务作业发包人供应并保留所有权”。
- 承包人派驻现场负责人、专职安全员；工人与承包人订立劳动合同，作业由承包人组织。
- 工资走农民工工资专用账户、按月考核代发；企业间劳务管理费另列，不得把工资绑在第三方付款上。
- 写明不含主体结构施工责任。

**附件必附**

- 工种/部位/作业量清单与单价表。
- 安全生产协议、工资支付承诺、拟进场花名册。
- 施工劳务资质、安全生产许可证复印件。

**禁止出现**

- 个人、包工头或“班组承包”作为合同相对方。
- “主体工程/主体结构劳务总包”、整栋主体连同技术管理交出、只上缴管理费。
- 计取主要建筑材料款、大中型机械或专业技术管理（名实已是专业工程则分流，不在本任务改资质类别）。
- “人员服从发包人任意调遣、按人头包干、发包人直接退回工人”。
- 把挂靠、再分包或无《劳务派遣经营许可证》的供人安排包装成可进场劳务分包。
- 以“业主未付总包、总包不付劳务”对抗工资专户拨付。

0. 签署状态与成果分流

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持无资质或包工头仍“可以进场”、把主体工程或挂靠或再分包改成可履行劳务稿、把无证派遣改写成劳务分包、保证有效。
- `字段停止`：资质真伪、地方取消劳务资质试点、总包合同是否禁止劳务分包、企业规模是否落入法释〔2024〕11 号、动态规则未核验。
- `目标停止`：主目标已变为待签评改、履约交底、争议文书，或来稿实为专业分包、派遣、施工总承包。

生存级金额或个人无限连带且用户拒绝升级：停止放行建议。
