# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的价格、工期、数量；把已失效《合同法》及其解释、法释〔2004〕14 号、法释〔2018〕20 号写入结论；把质保金 3% 上限写成解释二第 14 条；把备案合同写成结算依据。

## 1. 触发、单方立场与成果状态

立场（发包人或承包人）、授权、签署状态、主要目标。负触发写路由，不启动实体审查。勘察、设计、纯劳务分包必须在本节写明负触发，不得进入第 5–8 节。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、2004/2018 建工解释或六个月优先受偿时记噪声，不得写入 `L#`。解释二条号与最高人民法院官网法释〔2026〕12 号不一致时记 `conflict`，以官网为准。

## 3. 类型与加载路径

父级、子级、定性理由、易混切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读其他类型。挂靠或违法分包写停笔告知，不填可履行结构。

必须写明已切开：勘察 / 设计 / 劳务分包 / 工程总承包 / 专业分包 / 承揽 / 挂靠。

## 4. 主体、授权、资质与文本版本

主体表：签约名、履行名、付款名、发票名、项目经理、授权签字人。承包人资质类别等级、安全生产许可是否被材料提及。版本表：协议书、专用条款、通用条款、招标文件、投标文件、中标通知书、附件、聊天确认；冲突并列，不选对用户有利的一版。

## 5. 给付闭环

工程范围、质量标准、开工竣工认定、验收文件名称、价金形式（单价/总价/成本加酬金）、固定价风险范围、预付款/进度款/结算、农民工工资专户、发票、变更签证。缺口标 `G#`，不补商业数字。规划许可、施工许可、招标程序写成生效条件或期限，不写成已经完成。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹。强制规范只区分管理性与是否导致民事行为无效。本节点必须单独回答：资质、必须招标、先定后招、黑白合同。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

本类型风险表至少覆盖（有文本才填，无对应条款标缺口）：

- 资质与安全生产许可；
- 招标 / 先定后招 / 黑白合同；
- 固定价调差与情势变更出口；
- 审计期限与一年上限；
- 质保金比例（管理办法 3%）与返还起算（解释二第 14 条只写起算，不写 3%）；
- 优先受偿范围（停窝工不进本金）与十八个月起算；
- 转包、违法分包、主体结构自施。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。禁止输出无修改句的色块表。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`，不编造。禁止只给原则、不给句子。

质保金修改句必须引用管理办法第 7 条；返还起算才引用解释二第 14 条。禁止在同一句里把 3% 写成解释二第 14 条。

## 9. 谈判与签署提醒

谈判顺序：先红线（资质、招标、黑白合同、挂靠），再必须改（审计一年、质保金 3%、优先受偿范围、固定价出口），最后可优化。签署提醒：中标后三十日内按招标投标文件签约；授权与公章（禁止只盖项目部章）；日期不得早于中标通知书；附件清单与中标通知书一并装订。不指导倒签或补假招标、假资质。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本技能交付可编辑草稿、未决项、自审风险表和自审后修改句。草稿必须覆盖本类型起草必写、附件必附与禁止出现。待签评改转 `建设工程施工合同·审查`。不是履约交底、争议文书或效力保证。挂靠/先定后招已停笔的，本节重复告知一次。

## 起草模式交付

正触发时先交可编辑草稿和未决项，再交自审风险表与自审后修改句。三闸未落入正文或附件的，不得宣称起草完成。挂靠、违法分包、先定后招：停止包装成可履行。
