### **建设工程勘察合同宏观交易结构知识库**

#### **第一步：合同类型（法律性质）分析**

1. **法律定性**
* 
**定义与构成**：建设工程勘察合同是承包人进行工程建设前期勘察，发包人支付价款的合同 。它是建设工程合同的有名类型之一，与设计、施工合同共同构成建设工程合同体系 。


* 
**有名合同关系**：受《民法典》建设工程合同章规制，该章未作规定的，适用承揽合同的有关规定 。




2. **易混淆辨析**
* 
**勘察与测绘承揽**：建设工程勘察是在设计、施工前编制勘察文件的活动 。实务中常将一般的测绘活动承揽（如单纯的地形测量）误按建设工程勘察合同处理 。


* 
**名为合作实为发包**：需识别是否存在名为“联合开发”实为勘察发包的情形，以明确责任主体 。




3. **效力认定（高风险）**
* 
**强制性规定**：勘察人未取得相应资质或超越资质等级签订的合同无效 。


* 
**违法支解发包**：发包人不得将应当由一个承包人完成的建设工程支解成若干部分发包给数个承包人，但可以将勘察、设计、施工等一项或多项发包给一个工程总承包单位 。




4. **适用场景**
* 
**应用阶段**：主要适用于工程建设项目的设计、施工之前，通过对水文、地质等情况进行调查，为后续设计提供基础资料 。





#### **第二步：合同主体（交易对手）分析**

1. **主体适格性**
* 
**基本要求**：发包人通常为建设单位，承包人必须是具备法人资格的专业勘察单位 。


* 
**资质许可**：从事建筑活动的勘察单位，必须按照拥有的注册资本、专业技术人员等资质条件，取得相应等级的资质证书，并在许可范围内从事活动 。




2. **高频风险**
* 
**资质挂靠**：禁止借用他人资质承接勘察业务，挂靠签订的合同无效 。


* 
**代理授权**：需核实发包人代表或项目负责人的授权范围，避免因无权代理导致签证或结算文件效力争议 。




3. **关联主体**
* 
**联合体**：在大型或复杂项目中，常由具备勘察、设计资质的单位组成联合体 。联合体各方对发包人承担连带责任 。





#### **第三步：合同标的（交易对象）分析**

1. **标的适格性**
* 
**法定要求**：勘察标的必须符合国家规定的建设程序，严禁在未取得合法立项或规划审批的前提下进行实质性勘察活动（违法建筑除外）。




2. **特殊标的属性**
* 
**交付成果**：勘察合同的标的不是物质实体，而是具有技术含量的勘察报告、图纸及相关数据文件 。


* 
**质量要求**：勘察成果必须真实、准确，符合国家及行业技术标准，能够满足后续设计和施工的需要 。




3. **风险转移**
* 
**资料毁损**：勘察人交付成果前，相关技术资料毁损灭失的风险通常由勘察人承担 。





#### **第四步：合同程序（交易步骤）分析**

1. **法定前置程序**
* 
**招投标程序**：对于关系社会公共利益、公众安全的大型基础设施等项目，当勘察服务单项合同估算价在100万元人民币以上时，必须进行招标 。


* 
**中标备案**：依法必须招标的项目，其合同签署需遵循中标通知书的实质性内容，并在规定时间内签署书面合同 。




2. **内部决策程序**
* 
**发包人审批**：需确认发包人已完成项目立项和初步设计批复（若是总承包模式下的勘察）。




3. **附加程序**
* 
**后期配合**：勘察人需参与施工过程中的验槽、竣工验收等程序，并根据实际情况调整或补充勘察资料 。





#### **第五步：交易结构设计（风险规避方案）**

1. **计价与结算设计**
* 
**计价方式**：可选择固定总价、单价合同或成本加酬金 。针对地下地质条件的复杂性，建议在合同中明确“重大地下差异”的调价触发机制 。


* 
**送审价条款**：可约定逾期不审核视为认可结算的条款，以加快费用回笼 。




2. **担保措施**
* 
**支付担保**：勘察人应要求发包人提供支付担保，以防范工程款拖欠风险 。


* 
**履约保函**：发包人可要求勘察人提供银行见索即付保函作为履约担保 。




3. **结构选择**
* 
**发包模式**：发包人可选择将勘察独立发包，或纳入工程总承包（EPC/DB）模式中，由总承包人一并负责勘察、设计与施工 。




4. **文本形态设计**
* 
**合同构成**：通常由合同协议书、专用合同条款、通用合同条款及勘察任务书（附件）组成 。





#### **第六步：宏观风险预警与尽调指引**

1. **高频争议点**
* 
**勘察资料不实**：因勘察数据错误导致后续施工塌方、地基不稳等重大事故，勘察人需承担折价补偿或赔偿损失责任 。


* 
**优先受偿权争议**：通常认为勘察人不享有法律规定的建设工程价款优先受偿权，需通过其他担保手段加强债权保护 。




2. **尽职调查清单**
* 
**核查资质**：核实勘察单位的资质证书有效期及许可范围 。


* 
**核查程序**：对于必招项目，检查是否履行了合法的招投标程序 。


* 
**核查授权**：确认双方签字人员是否具备合法的授权委托书 。




3. **宏观风险预警**
* 
**“阴阳合同”风险**：严禁在招投标合同之外另行签订背离实质性内容的补充协议，否则面临以中标合同为准的裁判风险 。


* **垫资风险**：虽然法律原则上认可垫资，但需注意利息约定不得超过法定标准（LPR），且政府投资项目严禁垫资。
