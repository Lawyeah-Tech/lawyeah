# 建设工程勘察合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构，不证明本约条款已被接受。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、1983 年《建设工程勘察设计合同条例》、法释〔2004〕14 号、法释〔2018〕20 号或法释〔2002〕16 号当作现行规则。
- 解释二条号以最高人民法院官网公布的法释〔2026〕12 号为准。律页已收录时仍须与官网条号核对；官网与 MCP 冲突时以官网施行文本为准并记录冲突。律页对解释二或《建设工程勘察设计管理条例》（2017 修订）漏检时，改核官方公开文本，不得假装未颁布。解释二是施工合同纠纷解释，**无勘察专条**，不得把第 2、3、14、17 条写成勘察专条。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **建设工程 / 建设工程勘察合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。`depends-on` 为空。

不交付：他类合同审查；从零起草；履约交底；争议文书；有效性或对方接受的保证；把无资质、越级、挂靠、转包、违法分包或必须招标未招改成可履行勘察文本。

## 工作边界

正触发：已有可读待签正文及附件，尚未签署，尚未成争，核心给付是在建设工程**设计、施工前**，勘察人编制岩土、水文地质等**勘察文件**（参数、评价、建议），供后续设计使用，发包人支付勘察费。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 核心给付是出方案、初步设计或施工图 → `建设工程设计合同·审查`；
- 核心给付是按图施工、组织现场、交付合格工程 → `建设工程施工合同·审查`；
- 设计+采购+施工或设计+施工一体 → `工程总承包合同·审查`；
- 监理合同 → `建设工程监理合同·审查`；
- 无建设工程项目背景的单纯地形测量、房产测绘、地籍测绘等承揽 → 引擎 本套导航的类型切开步骤 或承揽原子，不按建工勘察审；
- 抢险救灾、临时性建筑、农民自建两层以下住宅的勘察（条例第 44 条不适用本条例）→ 引擎重新定性；
- 无可读文本、本类型条件已谈妥、要出己方稿 → `建设工程勘察合同·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已成争（催告、解除、索赔、勘察质量鉴定、诉讼仲裁）→ `或` 或 `或`。

挂靠、转包、违法分包：只出告知，不改写成可履行结构。用户坚持“改到能签/能过审图”：整体停止。

## 本类型硬闸

执行时必须同时守住。每闸必须能落到修改句或明确停笔，不得用施工、EPC 或普通测绘/承揽口径替换。

1. **勘察 ≠ 设计 ≠ 施工 ≠ EPC ≠ 普通测绘**  
   成果是勘察文件（岩土参数、地质建议），供设计使用。出施工图 → `建设工程设计合同·审查`。按图施工 → `建设工程施工合同·审查`。设计+施工一体 → `工程总承包合同·审查`。无建设项目背景的地形测量 → 承揽。  
   修改句方向：标题与标的改成“编制并提交××阶段岩土工程勘察报告及附件”；删除施工图出图、按图施工、竣工验收或总价包干建设义务。测绘承揽负触发，不出建工勘察修改句。

2. **资质**  
   勘察资质等级覆盖工程规模与专业（岩土/水文/工程测量等）。无资质或越级：合同效力高风险，不得改成可履行无资质勘察。挂靠、转包、违法分包停笔。  
   修改句方向：主体栏写勘察资质证书类别、等级、证号及与本工程规模的对应关系；删除“先签后补证”。挂靠/转包只出告知，不写假社保、出借印章或可履行资金路径。

3. **勘察纲要与范围**  
   钻孔数量深度、原位测试、室内试验、报告份数、场地四至必须附件化。禁止“按规范勘察”无纲要仍放行。  
   修改句方向：增列附件《勘察纲要/任务书》，写明阶段、孔数、孔深、取样、原位测试、室内试验、报告份数与介质、场地四至；正文写“范围以经双方签认的纲要为准，纲要未载明的增补须书面签证”。

4. **资料与现场**  
   发包人提供地形、管线、红线并保证真实；地下管线损毁责任划分。勘察人发现异常必须通知。  
   修改句方向：列《发包人应提供资料清单》及交付日；资料错误导致返工或损毁由发包人承担费用；勘察人作业前复核并保护已知管线，发现未标明管线、洞穴、文物或与纲要严重不符时立即停钻书面通知，未通知不得继续冒险作业。

5. **报告质量与使用**  
   报告错误导致设计变更或工程事故的责任限额须合理，禁止“勘察人任何情况下不承担责任”。发包人擅自修改报告：责任切回发包人。  
   修改句方向：质量不符时按民法典第 800 条继续完善、减收或免收费用并赔偿损失；限额不得覆盖故意或重大过失。写明未经原勘察人书面同意，发包人、设计人、施工人不得修改勘察文件；擅自修改的后果由修改方承担。

6. **必须招标**  
   依法必须招标项目未招标：不写成可履行签约路径。  
   修改句方向：补齐招标程序或停止放行；拒绝倒签中标日期；删除背离中标内容的另约。

## 建立审查坐标

确认：使用者与授权；单方立场（发包人或勘察人，不得同时服务）；相对方；全文、专用条款、勘察任务书/纲要、报价清单、招标投标文件、中标通知书与附件版本；勘察阶段（可研/初勘/详勘）；资质是否被提及；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价格、工期、孔数、孔深用 `【待填】`，不编造。

`基本面.md` 中的优先受偿“通常不享有”、强制招标 100 万元门槛，以本技能 `method.md` 与运行时核验为准：100 万元仍须核项目是否落入必须招标范围；优先受偿不得写成勘察人当然享有或当然排除。不把知识库过时或空白表述写成现行法。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、先定后招包装、把无资质或挂靠或转包或违法分包或必须招标未招改成可履行结构、保证有效。
- `字段停止`：必须招标事实、勘察资质等级与专业、纲要关键指标、动态规则未核验；价款或孔数关键事实缺失。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或来稿实为设计/施工/EPC/测绘承揽。

生存级金额或个人无限连带且用户拒绝升级：停止放行建议。


无完整待签文本、本类型条件已谈妥、要出己方稿时，转 `建设工程勘察合同·起草`，不在本审查原子起草。
