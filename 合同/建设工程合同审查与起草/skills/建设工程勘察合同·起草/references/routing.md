# 边界与路由

本技能只起草 **建设工程 / 建设工程勘察合同**（设计、施工前编制岩土/水文等勘察文件的待签文本）。

| 主要目标 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 出方案、初步设计或施工图 | `建设工程设计合同·审查` |
| 按图施工、交付合格工程 | `建设工程施工合同·审查` |
| 设计+采购+施工或设计+施工一体 | `工程总承包合同·审查` |
| 监理 | `建设工程监理合同·审查` |
| 无建设项目背景的单纯地形/房产/地籍测绘承揽 | 引擎重新定性，或承揽原子；不按本技能出建工勘察修改句 |
| 农民自建两层以下、抢险救灾、临时性建筑的勘察 | 引擎重新定性（条例第 44 条不适用本条例） |
| 有完整待签文本要评改 | `建设工程勘察合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、履约节点（交底、验槽配合） | 本套导航的履约步骤 |
| 已成争（效力、勘察费、报告错误鉴定、索赔） | `或` 或 `或` |
| C 端大众快检 | 只分流，不回改 |

挂靠、转包、违法分包、必须招标未招、无资质/越级：留在本技能只出告知并停笔，不转去“改成可履行稿”，也不转争议原子充作签前修改。

专业版未收录的 P1 场景不会安装对应原子。若用户拿这些文本来找专业版：输出 `unavailable`，提示或回引擎，不得用本勘察原子硬套。
