# 边界与路由

本技能只审查 **建设工程 / 工程总承包合同**（EPC 或 DB，对发包人的总包文本）。

| 主要目标 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 仅按图施工、无设计义务 | `建设工程施工合同·审查` |
| 核心给付是勘察 | `建设工程勘察合同·审查` |
| 单独设计发包，无采购施工组织 | `建设工程设计合同·审查` |
| 经发包人同意的专业工程分包 | `专业分包合同·审查` |
| 纯劳务分包（只出人工） | `劳务分包合同·审查` |
| 联合体成员之间的内部分工、损益、退出 | `联合体协议·审查` |
| 监理 | `建设工程监理合同·审查` |
| BT / 融资回购 | `BT合同·审查` |
| DBO / 投资运营 | `DBO合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `工程总承包合同·起草` |
| 已签未争、履约节点 | 本套导航的履约步骤 |
| 已成争（效力、价款、优先受偿、索赔、鉴定） | `或` 或 `或` |
| C 端大众快检 | 只分流，不回改 |

挂靠、转包、违法分包、必须招标未招、中标无效：留在本技能只出告知并停笔，不转去“改成可履行/可中标稿”，也不转争议原子充作签前修改。

专业版未收录的 P1 场景不会安装对应原子。若用户拿这些文本来找专业版：输出 `unavailable`，提示或回引擎，不得用本总承包原子硬套。
