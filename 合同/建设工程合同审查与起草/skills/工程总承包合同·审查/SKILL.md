# 工程总承包合同·审查

## 任务目标

在单一立场下，只审查 **建设工程 / 工程总承包合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。`depends-on` 为空。

不交付：他类合同审查；从零起草；履约交底；争议文书；有效性或对方接受的保证；把挂靠、转包、违法分包或必须招标未招改成可履行、可中标或可过验收的结构。

## 工作边界

正触发：已有可读待签正文及附件，尚未签署，尚未成争，核心给付是发包人将**设计+采购+施工**或**设计+施工**一体发包，承包人对质量、安全、工期、造价负总责。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 来稿仅按图施工、无设计义务 → `建设工程施工合同·审查`；
- 核心给付是勘察或单独设计发包 → `建设工程勘察合同·审查` 或 `建设工程设计合同·审查`；
- 经发包人同意的专业工程分包 → `专业分包合同·审查`；
- 纯劳务分包：只出人工、不含主材、大型机械和技术管理 → `劳务分包合同·审查`；
- 联合体成员之间的内部分工、损益或退出协议 → `联合体协议·审查`；本任务只审对发包人的总包文本；
- 监理合同 → `建设工程监理合同·审查`；
- 含融资、投资回购或运营分成（BT/BOT/DBO）→ `BT合同·审查` 或 `DBO合同·审查`；
- 无可读文本、本类型条件已谈妥、要出己方稿 → `工程总承包合同·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已成争（催告、解除、索赔、鉴定、诉讼仲裁）→ `或` 或 `或`。

挂靠、转包、违法分包：只出告知，不改写成可履行结构。用户坚持“改到能中标/能过验收”：整体停止。

## 本类型硬闸

执行时必须同时守住。每闸必须能落到修改句或明确停笔，不得用施工总承包口径或通用买卖/承揽口径替换。

1. **EPC ≠ 施工总承包**  
   承包人负责设计+采购+施工（或设计+施工），并对质量、安全、工期、造价负总责。来稿仅按图施工、无设计义务：负触发 `建设工程施工合同·审查`。不得删掉设计义务后当施工审，也不得把施工稿硬套总价包干。  
   修改句方向：写明承包范围含设计、采购、施工及竣工前试验；不得以“已出施工图、按图施工即可”替换设计义务。

2. **资质双持或联合体**  
   同时具备相应设计+施工资质，或合格联合体（内部约定不对抗发包人连带）。仅单一资质独立承接：红线/字段停止。联合体内部协议转 `联合体协议·审查`。  
   修改句方向：主体栏写双资质证号，或联合体各方共同签署并对发包人连带；删除“内部协议优先于总包合同”的对抗句。

3. **挂靠/转包/违法分包停笔**  
   只告知，不改成可履行。用户坚持“改到能中标/能过验收”：整体停止。合法专业分包走 `专业分包合同·审查`，劳务分包走 `劳务分包合同·审查`。  
   修改句方向：停笔告知，不写假联合体、假社保、印章外借或可履行资金路径。

4. **必须招标而未招 / 中标无效**  
   依法必须招标项目未招标或中标无效：不写成可履行签约路径。  
   修改句方向：补齐招标程序或停止放行；拒绝倒签中标日期。

5. **总价包干与变更切开**  
   EPC 常限额设计，除发包人要求变更外不调价。必须写清包干范围、物价/地质风险归谁、暂估价程序。禁止“总价包干但变更口头算”。  
   修改句方向：发包人要求变更书面签发并调价；承包人优化设计不调增；暂估价依法招标或按约定程序；口头变更不计价。

6. **单一责任**  
   设计/采购/施工任一环节缺陷，总包对发包人先行负责。不得把设计错误全部推回发包人“已审图”。  
   修改句方向：审图、确认承包人建议书或监理审核，不减免承包人设计错误责任；发包人要求与建议书冲突时以发包人要求为准。

7. **BT/BOT/DBO 切开**  
   含融资/投资运营 → `BT合同·审查` / `DBO合同·审查`，不按纯承包出融资结构。  
   修改句方向：负触发分流，不出融资回购或运营分成条款。

8. **质保金**  
   预留不超过结算总额 3%，依据《建设工程质量保证金管理办法》（建质〔2017〕138 号）第 7 条。禁止写成解释二第 14 条。  
   修改句方向：比例改≤3% 并挂管理办法第 7 条；返还起算才引用解释二第 14 条。

规划许可、施工许可未取得：生效/开工字段停止，不写“可以先开工后补证”的可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（发包人或承包人，不得同时服务）；相对方；全文、专用条款、发包人要求、承包人建议书、招标投标文件、中标通知书与附件版本；模式（EPC/DB）；双资质或联合体是否被提及；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价格、工期、数量用 `【待填】`，不编造。

`基本面.md` 中的空白保函比例、把地质/物价风险一律推给承包人、未写入解释二或管理办法的节点，以本技能 `method.md` 与运行时核验为准，不把知识库空白或过时表述写成现行法。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。

本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。交付按 [输出合同](references/output-contract.md)。边界见 [路由](references/routing.md)。

0. 签署状态与成果分流  
1. 类型识别：EPC≠施工；BT/DBO 切开；挂靠停笔  
2. 主体、双资质或联合体连带  
3. 招标程序、先定后招、中标无效  
4. 发包人要求、设计采购施工界线、规划/施工许可  
5. 总价包干与变更切开、暂估价、质保金 3%  
6. 格式条款与强制规范  
7. 单一责任、优先受偿（施工部分）、违约解除  
8. 按框架六步出修改句  

必须有修改句。禁止只打红黄绿。每个风险回链文本位置。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、先定后招包装、把挂靠或转包或违法分包或必须招标未招改成可履行/可中标/可过验收结构、保证有效。
- `字段停止`：必须招标事实、双资质或联合体、规划许可、施工许可、动态规则未核验；包干范围或暂估价关键事实缺失。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或来稿实为施工/单独设计/BT/DBO。

生存级金额或个人无限连带且用户拒绝升级：停止放行建议。


无完整待签文本、本类型条件已谈妥、要出己方稿时，转 `工程总承包合同·起草`，不在本审查原子起草。
