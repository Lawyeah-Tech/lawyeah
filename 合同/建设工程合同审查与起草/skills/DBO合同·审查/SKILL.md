# DBO 合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构，不证明本约条款已被接受。不得把 FIDIC 金皮书写成中国大陆强制法。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、法释〔2004〕14 号、法释〔2018〕20 号、法释〔2002〕16 号，或 1999 年未经 2017 修正核对的《招标投标法》文本，当作现行规则。不得把 BT 回购／垫资回收清单或 EPC 竣工即终止清单硬套本类型。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **建设工程 / DBO 合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。`depends-on` 为空。不要求先跑导航。

不交付：他类审查、从零起草、履约交底、争议文书、有效性或对方接受／运营必然达标／财政必然拨款的保证；把 BT、EPC、纯施工、纯设计改成本类型；把挂靠、违法分包、规避招标、政府投资项目垫资或名为 DBO 实为违法借贷改成可履行结构。

## 工作边界

正触发：已有可读待签文本要评改，；尚未签署，尚未成争，核心给付是**同一承包人（或联合体）在一份合同里完成设计、建造，并在竣工后继续承担长期运营维护**；**业主负责项目融资**，承包人输出技术与管理，设施所有权自始归业主，承包人只有经营权／管理权。典型信号：污水处理、垃圾处理、供水、公路养护等公用设施；建设费与运营绩效费分列；试运行后进入 KPI 付费；期满移交（Handback）而不是竣工即终止。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 承包人负责融资、建造后移交以回收垫资或形成政府隐性债务，运营不是核心给付或只有短期移交 → `BT合同·审查`；
- 设计采购施工一体或发包人要求主导，**竣工验收合格即交付业主、无长期运营期作为合同主给付** → `工程总承包合同·审查`；
- 只按图施工、无设计责任、无运营期 → `建设工程施工合同·审查`；
- 只交出勘察或设计成果 → `建设工程勘察合同·审查` 或 `建设工程设计合同·审查`；
- 只做咨询、可研、全过程工程咨询，不承包设计建造运营 → `建设工程咨询服务合同·审查`；
- 文本只是联合体成员内部分工，没有对业主的 DBO 主给付 → `联合体协议·审查`；
- 承包人投资建设运营并取得收益的特许经营／BOT，且以使用者付费回收投资为主 → 引擎重新定性，不在本技能按业主融资 DBO 改完，也不打开 BT method；
- 无文本、本类型条件已谈妥、要出己方稿 → `DBO合同·起草`；
- 已签只问节点留痕 → 本套导航的履约步骤；
- 已成争（催告、解除、索赔、诉讼仲裁）→ `或建设工程争议领域。` 或建设工程争议领域。

挂靠、违法分包、伪造内部承包、规避招标、先定后招、政府投资项目由施工单位垫资、名为 DBO 实为违法借贷：只出告知，不改写成可履行结构。用户坚持“改到能签”：整体停止。

## 建立审查坐标

确认：使用者与授权；发包人（业主／政府或公用事业企业）或承包人（含联合体）单一立场；相对方；正文、设计施工专用条款、运营维护专用条款、绩效考核办法、移交标准、招标投标文件与中标通知书版本；项目是否业主融资；建设工期与运营期限；建设费／运营费是否分列；不可接受事项；法域与拟签时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价格、工期、运营年限、KPI 用 `【待填】`，不编造。

知识双文件把“设计／建造期遵循 EPC 管理流程”写成程序描述的，只当建造阶段管理线索，**不得据此加载或改写成** `工程总承包合同·审查` 的竣工即终止路径。知识稿提到 FIDIC 金皮书的，只借栏目，不上升为强制法。知识稿“须关注民法典对服务合同期限的合规性”不得写成已核验的统一法定期限上限；运行时核验前字段停止。

## 本类型硬闸

审查过程必须逐项点名。禁止用 BT 垫资回收／回购清单或 EPC 竣工移交清单代替：

1. **设计建造运营一体，且与 BT／EPC 切开**：正像必须同时有设计、建造和长期运营。缺运营期主给付 → `工程总承包合同·审查`。承包人融资或建造后移交回收垫资 → `BT合同·审查`。不得删掉融资条款或补写空洞运营句以便留下。
2. **业主融资、所有权归业主**：承包人不得被写成项目融资义务人。设施所有权自始归业主；承包人只有经营权与管理权。要求承包人实质性垫资、替政府举债或固定回报回购的，按硬闸 G 停笔。
3. **双重产出必须附件化**：建设范围（设计边界、采购、施工）与运营范围（处理量、出水／排放标准、设施完好率、大修重置）及 KPI 计分规则必须作为合同组成部分。无运营手册、无绩效考核办法、无移交技术标准：字段停止，不得放行。
4. **建设费与运营费分列，运营费须可调**：建设费通常固定总价或模拟清单，按进度支付；运营费为固定底薪＋绩效变动，先考核后付款，并锁定电费、人工、药剂等调价系数。禁止运营期十年以上仍写死固定运营费且无调价、无中期评估。
5. **竣工交付 ≠ 期满移交**：试运行达标才进入正式运营；期满前进入移交准备期，恢复性大修、剩余使用寿命和移交维修保证金必须落句。不得用“竣工移交业主”一句话吞没运营期。
6. **双重保函与联合体锁定**：建造履约保函在进入运营期后更换为运营履约保函；不得建造结束即放空担保。联合体中施工成员不得在竣工后退出而留下无运营能力的空壳；运营责任人须锁定到期满。
7. **名为 DBO 实为垫资或违法借贷、挂靠、规避招标：停笔**。政府投资项目不得由施工单位垫资；跨年度财政支付须有预算安排。无资质、必须招标未招、先定后招、出借资质：只告知，不改成可履行。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验建设工程定义与总承包／转包分包、竣工验收、必须招标与中标后不得背离实质性内容、建筑业及设计资质与联合体连带、政府投资不得垫资与地方政府不得违法举债、情势变更、特许经营是否真正适用；`search_practiced` 补 DBO／BT／EPC 切开、绩效付费和移交争点；`search_template` 只借设计施工专用条款＋运营维护专用条款的栏目结构。不虚构案件系统。

`search_law` 对法律结论为 required 级节点：不可用时不拒绝执行，只停止法律结论字段。返回已失效《合同法》、建工旧解释或 2002 年优先受偿批复时记为噪声，不得写入 `L#`。返回 BT 回购、EPC 竣工即终止或特许经营投资建设运营定义时，不得当作本类型默认法；本类型默认是业主融资、所有权归业主、运营期在竣工之后继续。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、先定后招包装、黑白合同、把挂靠或违法分包改成可履行、把政府投资垫资或固定回报回购改成可履行、无运营 KPI／无移交标准仍要求放行、保证有效或财政必然拨款。
- `字段停止`：必须招标事实、设计／施工／运营能力、财政跨年预算、调价系数、KPI 附件、移交剩余寿命未核验。
- `目标停止`：主目标已变为他类型起草、履约交底或争议文书。

生存级垫资、个人无限连带或用户拒绝升级：停止“可以签署”建议。
