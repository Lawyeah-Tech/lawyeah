# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受、运营必然达标或财政必然拨款；编造未给出的建设费、运营费、工期、运营年限、KPI；把已失效《合同法》及其解释写入结论；把 BT 回购句或 EPC 竣工即终止句当作本类型默认修改句。

## 1. 触发、单方立场与成果状态

立场（业主／发包人或承包人／联合体）、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明是否同时具备设计、建造、长期运营，以及融资义务是否在业主侧。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、法释〔2004〕14 号、法释〔2018〕20 号、法释〔2002〕16 号或未经 2017 修正核对的招标投标法 1999 文本时记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级建设工程、子级 DBO 合同、定性理由、与 BT／EPC／施工／设计／咨询／联合体／特许经营的切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读其他类型、未打开邻类 method。挂靠、违法分包、政府投资垫资或名为 DBO 实为违法借贷写停笔告知，不填可履行结构。

## 4. 主体、授权、资质与文本版本

主体表：签约名、履行名、设计责任人、施工责任人、**运营责任人**、付款名、发票名、授权签字人、联合体成员。版本表：正文、设计施工专用条款、运营维护专用条款、KPI 附件、移交标准、招标投标文件、中标通知书；冲突并列，不选对用户有利的一版。设计资质、施工资质、运营能力／特许授权（若涉及公共服务）分列；口头“有证”不得写成已具备。

## 5. 给付闭环

必须同时覆盖：

- 建设期：设计边界、采购、施工、试运行达标参数；
- 运营期：服务内容、KPI、大修／重置、环保达标；
- 权属：所有权归业主，承包人经营权／管理权；
- 对价：建设费（CAPEX）节点；运营费（OPEX）公式、考核后付款、调价系数；
- 担保：建造履约保函 → 运营履约保函；移交维修保证金；
- 移交：期满前准备期、恢复性大修、剩余使用寿命。

缺口标 `G#`，不补商业数字。批准、招标、施工许可、财政预算写成生效条件或期限，不写成已经完成。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹；异常条款（单方调价、最终解释权、概括免责、运营期任意解除无补偿）。强制规范只区分管理性与是否导致民事行为无效。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。必须招标未招、无资质、转包、政府投资垫资：停笔告知，不改成可履行。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔／转出口径。禁止输出无修改句的色块表。本类型至少点名：一体切开、业主融资与权属、KPI／移交附件、建设费与运营费分列及调价、交付≠移交、双重保函与联合体锁定、垫资／挂靠／招标停笔。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`，不编造。禁止只给原则、不给句子。禁止粘贴 BT 回购公式或 EPC 竣工终止句充作本约。

## 9. 谈判与签署提醒

谈判顺序：先红线（类型错误、垫资违法借贷、无 KPI／无移交、挂靠规避招标），再必须改（调价、双重保函、联合体锁定、提前终止公式），最后可优化（能效分享、中期评估、数据权属）。签署提醒：授权、用印、日期、设计施工专用条款＋运营维护专用条款＋绩效考核办法＋移交标准、财政预算或资金安排凭证。不指导倒签、补假中标或假预算。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本技能只出审查意见和修改句，不出整份起草终稿；出稿转 `DBO合同·起草`。不是履约交底、争议文书或效力保证。
