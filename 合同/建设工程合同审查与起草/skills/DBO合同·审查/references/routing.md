# 边界与路由

本技能只审查 **建设工程 / DBO 合同**。核心给付是同一承包人（或联合体）在一份合同里完成设计、建造并继续长期运营；业主负责融资，设施所有权归业主。不是 BT 垫资移交，也不是竣工即终止的 EPC。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 承包人融资、建造后移交以回收垫资或形成回购／隐性债务，运营不是主给付 | `BT合同·审查` |
| 设计采购施工一体，竣工验收合格即交付业主，无长期运营期主给付 | `工程总承包合同·审查` |
| 只按图施工、无设计责任、无运营期 | `建设工程施工合同·审查` |
| 只交出勘察或设计成果 | `建设工程勘察合同·审查` 或 `建设工程设计合同·审查` |
| 只做咨询、可研、全过程工程咨询 | `建设工程咨询服务合同·审查` |
| 文本只是联合体成员内部分工，没有对业主的 DBO 主给付 | `联合体协议·审查` |
| 只做监理 | `建设工程监理合同·审查` |
| 承包人投资建设运营并以使用者付费回收投资的特许经营／BOT | 引擎重新定性；不按本类型业主融资路径改完 |
| 无文本、本类型条件已谈妥、要出己方稿 | `DBO合同·起草`；与 BT、EPC 切开 |
| 已签未争、节点／考核／付款留痕 | 本套导航的履约步骤 |
| 已成争（催告、解除、索赔、立案、仲裁） | `或建设工程争议领域。` 或建设工程争议领域 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

专业版未收录的 P1 场景不会安装本原子。若用户拿本类型文本来找专业版：输出 `unavailable`，提示，不得用施工或总承包邻类硬套。

本技能不得转去加载 BT 或 EPC 双文件完成本类型审查。禁止打开 `BT合同·审查`、`工程总承包合同·审查` 的 method。一旦核心给付是承包人融资移交或竣工即终止，立即负触发，不得删掉融资／回购条款或补写空洞运营句后继续当 DBO 审。
