# 审查方法（锁定 公司相关合同 / 公司分立合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止打开或复制 `公司合并合同·审查` 的合并协议、换股对价、经营者集中申报主路径。禁止打开或复制 `定向减资合同·审查` 的定向减资、退股对价、债权人清偿／担保请求权主路径。

定性校验：标题、核心给付与本类型一致才继续；明显是合并、减资、资产收购、债务转移或单纯股权转让则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、保证工商一定办成、保证内部债务安排已对外免责或唯一必得金额。

`search_law` 返回已失效《合同法》及其解释（含第九十条）、1993 年《公司法》第六十六条国有独资授权旧义、2005／2018 年分立旧条号、已失效《公司登记管理条例》减资登记旧条时记为噪声，不得写入 `L#`。

示范文本只参考结构。检索到的“公司分立协议”摘要常列财产分割、债务承继、职工安置：栏目可借；不得把范本内部“各自承担债务”写成已对外免责。

知识库纠正（不回写双文件）：

- `基本面.md` 程序节写债权人“自接到通知之日起三十日内（未接到通知的自公告之日起四十五日内），有权要求公司清偿债务或者提供相应的担保”：这是《公司法》（2023 修订）**第二百二十条**（合并）和**第二百二十四条**（减资）的权利，**不是**第二百二十二条、第二百二十三条的分立主路径。内资公司分立的法定保护是：编制资产负债表及财产清单、十日通知、三十日公告，以及分立前债务由分立后公司连带（另有书面约定除外）。意见不得把三十日／四十五日清偿担保请求权写成内资分立的普遍权利。
- `框架.md` 生效节“自各方签署并经股东会作出有效分立决议之日起生效”：方向采用。登记、公告完成不是合同成立的默示要件，应写成双方义务和登记申请期限。
- `基本面.md` 把标的写成“全部财产和债务”：解散分立才必须分割全部；存续分立只分割列明部分，未列入清单的默认留在存续公司。不得把派生分立改成必须掏空原公司。
- 外商投资企业另有 2015 年《外商投资企业合并与分立规定》第三十条／九十日期限的，只在主体确为外商投资企业时运行时复核，不得写成内资普遍规则。
- 特殊性税务处理：只标条件与缺口，不保证获准，不把“避税关键”写入可放行结构。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

支持切开的规范（法律结论须运行时复核）：

- 公司法第二百二十二条：公司分立，其财产作相应的分割；应当编制资产负债表及财产清单；自分立决议之日起十日内通知债权人，三十日内在报纸或国家企业信用信息公示系统公告。
- 公司法第二百二十三条：分立前的债务由分立后的公司承担连带责任；分立前与债权人书面另约的除外。
- 民法典第六十七条第二款：法人分立的，由分立后的法人享有连带债权、承担连带债务，债权人和债务人另有约定的除外。
- 公司法第二百二十条：这是**合并**的通知、公告和债权人清偿／担保请求权。出现“合并各方”“吸收／新设合并”“换股”时负触发，不把该条权利粘进本约。
- 公司法第二百二十四条：这是**减少注册资本**的通知、公告和债权人清偿／担保请求权，以及原则上按出资或持股比例减资。主体不裂变、只减注册资本或定向退股时负触发。
- 公司法第五十九条：股东会职权包括对公司合并、分立、解散、清算或者变更公司形式作出决议；全体股东书面一致同意的，可以不召开会议直接决定。
- 公司法第一百一十六条第三款：股份有限公司对合并、分立等决议，应当经出席会议的股东所持表决权的三分之二以上通过。
- 公司法第八十九条第一款第二项：对股东会分立决议投反对票的有限责任公司股东，可以请求公司按合理价格收购其股权。

必须切开后再加载，禁止两可时灌入两套知识：

## 节点 2　派生／新设与人的／物的分立（硬闸）

| 文本写法 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 只写“对公司进行分立／业务剥离／重组” | 必须改：点名存续分立（派生）或解散分立（新设）。默认提问倾向存续分立，但不得在意见里替用户选定后假装合同已写明 | 未点名也可以交割 |
| “解散分立，原公司继续经营原品牌” | 必须改：解散分立须注销被分立公司；继续存续只能改成派生分立 | 解散后原主体仍在 |
| 新设公司股权全部由被分立公司持有（物的分立） | 可接受结构：写明被分立公司是新设公司股东、持股比例、是否构成转投资；并提示这更接近资产划转，须防被定性为普通投资或资产收购 | 物的分立＝已完成资产收购 |
| 新设公司股权直接登记到原股东名下（人的分立） | 可接受结构：写明各股东在存续公司与新设公司的持股是否按原比例平移，或哪些股东退出存续、进入新设 | 未写股权归属也能办设立 |
| 解散分立却未列两家以上新公司名称、资本和全部财产去向 | 红线：补全新设主体和全部财产归属，否则不签 | 解散后财产“另行协商” |

示范修改句（派生未点名）：

`定位（第×条）｜原文：各方同意对被分立公司进行分立｜建议改为：各方确认本次分立为存续分立（派生分立）。被分立公司【名称】继续存续并办理变更登记；新设公司【名称／备选名称】承接附件一所列资产、业务与人员。被分立公司不因本次分立解散或注销。｜理由（回链 C# / L# 第二百二十二条）｜可退让点：若商业目的确是解散分立，整条改写为注销被分立公司并新设两家以上公司，同时改登记与债务条款｜不接受时的红线：拒绝签署未点名派生或新设的文本`

最强反方：相对方主张“工商会自己判断存续还是解散，合同不必写”。回应：财产分割范围、是否注销、登记种类和债务主体都取决于这一选择；不写则无法交割，也无法判断是否误走合并或减资。

## 节点 3　主体、特别决议与异议股东

### 3.1 主体表

建表：被分立公司、拟存续公司、拟新设公司（尚未成立的写“拟设立”，不得写成已有统一社会信用代码）、全体股东、授权签字人。名称不一致不自动合并。新设公司尚未成立时，由拟担任其股东的各方在本约中为设立行为作出不可撤销的同意。

框架要求被分立公司及**全体股东**签署。缺少任一股东签章：字段停止或红线补签，不得写成“公司盖章即可完成股东权益再配置”。

口头“我们老板同意了”不得写成已授权。国资、集体、上市公司内部决议或主管部门批准未附：该签署能力字段停止。

### 3.2 特别决议

分立属于股东会职权（第五十九条）。股份有限公司须经出席会议股东所持表决权三分之二以上通过（第一百一十六条）。有限责任公司知识库写“代表三分之二以上表决权”；2023 年有限责任公司对应表决条号本次若未稳定命中全文，法律结论字段标待核，修改句仍要求达到特别决议门槛，不得写成过半数即可。1993 年第六十六条国有独资授权旧义不得引用。

| 文本或事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 无决议，约定“签字后立即生效并办理登记” | 必须改：本协议自各方签署且被分立公司股东会作出有效分立决议之日起生效；决议作为附件 | 签字代替特别决议 |
| 决议可见但表决比例空白 | 字段停止；列出待补的表决权统计 | 推定已达三分之二 |
| 全体股东书面一致同意不召开会议 | 可接受：引用第五十九条书面一致路径，仍须全体签名或盖章的决定文件入附件 | 口头一致视为书面 |

### 3.3 异议股东

第八十九条：对分立决议投反对票的有限责任公司股东可请求公司按合理价格收购股权；六十日内不能达成协议的，可自决议之日起九十日内起诉。文本完全不提异议股东：必须改或可优化，补收购价款确定方式、付款日和与工商变更的顺序。用户立场是控股股东且拒绝任何回购安排：标红旗，不在本任务认定决议有效。

股份有限公司异议股东收购的具体条号本次若未单独核验，字段停止，不把第八十九条直接写成股份公司规则。

## 节点 5　债务连带与债权人通知（硬闸）

### 5.1 对外连带，对内追偿

第二百二十三条；民法典第六十七条第二款。

| 文本写法 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| “按资产比例各自承担，互不连带”“债务随资产走，新公司对旧债免责” | 红线：删除对外免责。改为：内部第一清偿义务人 + 对外连带 + 清偿后追偿。只有分立前与该债权人的书面另约才能排除对该债权人的连带 | 内部分割已对抗债权人 |
| 有内部比例，但无追偿、无或有负债 | 必须改：已知债务入附件二；或有负债、担保、未决诉讼的承担和追偿单列 | 未写的负债视为不存在 |
| 已出示某债权人书面另约 | 只对该笔债务标“可能对外另约”；核验是否签署在分立前、是否覆盖本金利息和担保 | 一份协议消灭全部连带 |
| 用户要本任务保证“签了就不会被追” | 拒绝保证；生存级债务且用户拒绝升级：停止“可以签署” | 必然隔离 |

示范修改句：

`定位（第×条）｜原文：分立后各方按划转资产比例承担债务，互不承担连带责任｜建议改为：附件二所列已知债务由【存续公司／新设公司】作为第一清偿义务人负责清偿。对公司分立前的债务，分立后的公司承担连带责任；公司在分立前与债权人就债务清偿达成书面协议另有约定的除外。第一清偿义务人清偿超出内部份额的，有权按本条向另一方追偿。本条内部安排不得对抗未另约的债权人。｜理由（回链 L# 第二百二十三条、民法典第六十七条）｜可退让点：可对大额债权人逐户谈判书面另约，另约文本作附件｜不接受时的红线：拒绝保留“互不连带／对外免责”句`

### 5.2 通知与公告，切开减资／合并请求权

第二百二十二条第二款：决议之日起十日通知、三十日公告。市场主体登记管理条例实施细则第二十一条：公司分立可通过国家企业信用信息公示系统公告，公告期四十五日，应当于公告期届满后申请办理登记。公司法第二百五十五条：合并、分立、减资或清算时不依法通知或公告债权人的，责令改正并处罚款。

| 文本写法 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 无通知、无公告，或写“双方同意无需通知债权人” | 红线：补谁通知、起算、渠道、已知债权人名单附件、公告媒介、留痕 | 约定可以取消法定通知 |
| “本协议签字盖章后立即办理工商登记” | 必须改：登记申请在通知、公告程序完成且实施细则要求的公告期满后提出 | 签字日＝可登记日 |
| 整段粘贴“债权人三十日内／四十五日内有权要求清偿或提供担保” | 必须改：删除或降为“如适用合并或减资程序则另案处理”。内资分立主路径不是该请求权。主体若是外商投资企业，运行时复核 2015 年规定，不写成内资规则 | 知识库误植＝现行分立权利 |
| 用户立场要“先过户再补公告” | 整体停止或红线：拒绝指导补假程序 | 事后公告视为已履行 |

与 `定向减资合同·审查` 的切开句（文本实为减资）：

`定位（标题／第×条）｜原文：公司减少注册资本并定向退还甲股东出资，不新设公司｜建议改为：本任务停止实体审查。该核心给付是定向减资，不是公司分立。请改用审查定向减资合同技能。｜理由：第二百二十四条；主体不裂变｜可退让点：无｜不接受时的红线：拒绝按分立放行减资文本`

## 节点 6　人员、对价、登记、税与过渡期

### 6.1 职工

劳动合同由承继权利和义务的用人单位继续履行。劳动争议解释（一）第二十六条：分立前劳动争议由分立后的实际用人单位为当事人；承受单位不明确的，分立后的单位均为当事人。2012 年《劳动合同法》第三十四条全文若本次只命中 2007 年对应条义，条号运行时复核，方向仍采用。

必须有《职工安置方案》附件：谁承继哪些劳动合同、是否协商变更、经济补偿是否发生、社保公积金转移。禁止写成“职工自动解雇”或“新公司无条件不接收”。

### 6.2 股东对价

同一控制、按原比例平移：通常无现金，仍须写明各主体持股。非同一控制或股东退出：必须写现金或资产对价、估值依据、支付节点，建议与工商变更挂钩。未给出的数字用 `【待填】`。

定金：必须出现“定金”二字才讨论罚则。民法典第五百八十六条：不得超过主合同标的额百分之二十。无核验引文不得把 20% 写成现行法结论。

### 6.3 登记不是合同成立默示要件

存续公司变更登记、解散公司注销登记、新设公司设立登记，写成各方义务、申请期限和未完成的解除或中止。市场主体登记管理条例实施细则第二十一条的四十五日公告期，写成登记申请的程序条件，不写成“未登记则本协议未成立”。

用户要求“未完成登记则合同无效，所以必须先倒签再报”：拒绝倒签。

### 6.4 税

一般性处理与特殊性税务处理只作风险提示。不得保证“合理商业目的一定被认可”。税负精确额标 `G#` 或字段停止。税收征管法第四十八条：分立未缴清税款的，分立后纳税人连带——写入提醒，不在本任务做税务清算。

### 6.5 过渡期

基准日至交割日：损益归属、维持正常经营、禁止重大处置、对外担保、利润分配。未写则必须改，不编造归谁。

## 节点 7　违约、解除、争议与强制规范

逾期不交资产、不配合登记、陈述严重失实、违反过渡期、拒不履行通知公告：必须分别有可执行后果。只有“依法承担违约责任”视为必须改。

先决条件（决议未通过、批准未获、清单无法编制）失败：约定终止和已发生审计评估费分摊。构成违约不等于当然解除。

违约金不是必得金额；禁止写“不得调整”。第五百八十五条全文若未稳定核验，调整机制法律结论字段停止，修改句仍删除“不得调整”。

争议解决：公司分立纠纷属公司类争议。出现仲裁条款，不得改写成“应向某法院起诉”。或裁或诉、机构不明：标待核，改成单一机构或单一法院连结点。不保证所选机构一定受理全部分立效力争议。

格式条款：第四百九十六条、第四百九十七条。强制规范：第一百五十三条。内部免除连带的条款因不能对抗债权人而必须改写，不当然导致整份分立协议无效。禁止用已失效“效力性／管理性”口诀。

`定位（条／款／附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`
