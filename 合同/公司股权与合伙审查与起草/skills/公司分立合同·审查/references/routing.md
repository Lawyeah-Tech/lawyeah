# 边界与路由

本技能只审查 **公司相关合同 / 公司分立合同** 的待签、一个公司财产分割并派生或新设公司的文本。中文展示名是「审查公司分立合同（公司相关合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或复制 `公司合并合同·审查` 的 method 后换“分立”。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 两个以上公司合为一个；吸收合并／新设合并；合并协议；权利义务由合并后的法人概括承受；债权人三十日／四十五日要求清偿或担保作为合并主路径 | `公司合并合同·审查` |
| 同一公司减少注册资本；定向减资；注销特定股东出资；主体不裂变；减资对价退股 | `定向减资合同·审查` |
| 买卖特定资产或业务包；卖方法人继续；买方选债；不对卖方全部旧债当然连带 | `资产收购合同·审查` |
| 单项、非核心资产转让 | `非核心资产转让·审查` |
| 单笔或数笔债务经债权人同意转移；公司本身不分割 | `债务转移三方协议·审查` |
| 只转让股权，公司主体与注册资本结构不因本约裂变 | `公司股权转让·审查` |
| 以取得控制权为目的的股权收购，目标公司不分立 | `股权收购合同（含控制权转移）·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、只问公告窗口、登记日、资产过户日 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `已出现催告解除函索赔立案开庭仲裁` 或对应专项领域 |
| 债权人已起诉分立后公司连带清偿、决议效力之诉、异议股东回购之诉已立案 | 公司或争议专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

分立正文里夹带一小段资产买卖或单笔债务转移：专章交接对应原子或分条改写；财产分割与公司裂变条款可继续审。用户坚持本技能把合并、减资、资产收购或债务转移整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
