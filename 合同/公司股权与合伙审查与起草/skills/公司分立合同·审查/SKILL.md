# 公司分立合同·审查

## 任务目标

在单一立场下，只审查 **公司相关合同 / 公司分立合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查公司分立合同（公司相关合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证工商一定办成、保证内部债务分割必然隔离债权人、保证特殊性税务处理一定获准。

## 本类型硬闸

1. **派生／新设必须点名**：正像是一个公司将其财产作相应分割。存续分立（派生分立）＝被分立公司继续存在，分出部分财产设立一家或多家新公司；解散分立（新设分立）＝被分立公司解散，全部财产归入两家或以上新公司。文本只写“分立”“重组”“业务剥离”而未点名哪一种的，必须改。禁止把吸收合并、新设合并口径改成“反过来的分立”。
2. **债务承继默认连带**：分立前的债务由分立后的公司承担连带责任；唯一对外例外是分立前与债权人就清偿达成书面另约。协议内部“按资产比例各自承担、互不连带”“债务随资产走即对外免责”，未经债权人书面同意的，不得写成已隔离。必须同时写内部第一清偿义务人、追偿和对债权人的反说。
3. **债权人通知与公告**：自分立决议作出之日起十日内通知已知债权人，并于三十日内在报纸或国家企业信用信息公示系统公告。缺义务主体、起算日、渠道和留痕的，必须改。不得把签字日、交割日或“双方同意视为已通知”写成已完成法定程序。
4. **财产分割清单闭合**：应当编制资产负债表及财产清单，并以附件逐项列明划转资产、债权、知识产权、权利负担和划入主体。只写“厂房、设备及相关资产”视为未特定。未列入清单的资产归属必须有默认规则。
5. **与定向减资切开**：同一法人减少注册资本、注销特定股东出资、主体不裂变 → `定向减资合同·审查`。债权人在减资程序中有权要求清偿或提供担保；该权利**不是**内资公司分立的法定主路径。文本把分立写成“减资后新设壳公司承接优质资产”或把三十日／四十五日清偿担保请求权整段粘进分立协议的，先切开再审，禁止当已完成的本类型放行。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。禁止打开或复制 `公司合并合同·审查` 的 method。

## 工作边界

正触发：已有可读待签公司分立协议或分立方案文本，尚未签署，尚未成争，核心给付是一个公司财产分割并派生或新设公司，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 两个以上公司合为一个；吸收合并或新设合并；权利义务由合并后的法人概括承受 → `公司合并合同·审查`；
- 同一公司减少注册资本、定向退出股东、主体不裂变 → `定向减资合同·审查`；
- 买卖特定资产或业务包，卖方法人继续，买方不当然连带卖方全部旧债 → `资产收购合同·审查` 或 `非核心资产转让·审查`；
- 就单笔或数笔债务做债权人同意的债务转移，公司不分割 → `债务转移三方协议·审查`；
- 只转让股权、控制权不裂变公司 → `公司股权转让·审查` 或 `股权收购合同（含控制权转移）·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `公司分立合同·起草`；
- 已签只问登记日、公告窗口、资产过户日 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁，或债权人已起诉分立后公司连带清偿 → `已出现催告解除函索赔立案开庭仲裁` 或公司／争议专项。

以分立为名转移优质资产逃废债务、掏空被分立公司、伪造债权人通知或倒签决议：只出告知，不改写成可履行逃债路径。

## 建立审查坐标

确认：使用者与授权；单方立场（被分立公司／拟存续公司／拟新设公司发起人／特定股东／拟承接业务的一方）；相对方；全文及附件／资产清单／债务清单／职工安置／决议版本；派生还是新设；人的分立还是物的分立；基准日；股东会是否已作或待作特别决议；债权人通知与公告如何写；内部债务安排是否冒充对外免责；财产清单是否逐项；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的基准日、评估值、对价、通知渠道用 `【待填】`，不编造。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。禁止打开 `公司合并合同·审查`、`定向减资合同·审查` 的 method。`基本面.md` 把“债权人三十日／四十五日要求清偿或提供担保”写成内资公司分立的普遍权利时，以 method 纠正为准。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `公司分立合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议或公司专项。未签且目标是评改已有分立文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。合并、减资、资产收购、债务转移、单纯股权转让负触发。

### 2. 派生／新设与人的／物的分立

未点名存续或解散、未写新设公司股权给原股东还是留给被分立公司的，必须改。

### 3. 主体、特别决议与异议股东

被分立公司与全体股东签署能力；股东会特别决议；投反对票股东的合理价格收购请求。未闭合则字段停止。

### 4. 财产分割清单

资产负债表及财产清单作为分割基础；权属负担不得写成“无”除非有材料。

### 5. 债务连带与债权人通知

内部安排加反说；书面另约才可能对外免责；十日通知、三十日公告。不得粘贴减资／合并的清偿担保请求权当分立主路径。

### 6. 人员、对价、登记与税

劳动合同由承继单位继续履行；登记写成义务与期限，不写成合同未登记未成立；税不保证特殊性处理。

### 7. 格式条款与强制规范

无核验引文则法律结论字段停止。逃债结构不得改成可履行。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签决议或通知、保证有效、把减资或合并改成分立外壳仍放行、把内部分割写成已对外免责、把逃废债务改成可履行。
- `字段停止`：法域、动态规则、决议是否达到特别多数、财产清单真伪、债权人名单、外商投资特别程序、税负精确额未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
