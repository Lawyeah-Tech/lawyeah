# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、获批、对方接受或必然完成登记对抗；编造未给出的价格、比例、期限；把已失效《合同法》或其解释、已失效 3 号令写入结论；把未批准写成当然无效；把公开挂牌或资产转让的评估值 90% 写成协议转让底价；把口头知情写成已放弃优先购买；把应进场改成可履行场外协议；把普通转股或资产转让当成已完成的本类型审查。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查国有股权转让合同（协议转让）（公司相关合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》或其解释、已失效 3 号令、1993／2018 年公司法同条号时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `公司相关合同`，子级 `国有股权转让合同（协议转让）`。定性理由、易混切开结果（普通股权转让、国有资产协议转让、进场挂牌、增资、控制权收购、上市公司股份）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、国资身份、批准与文本版本

主体表：签约名、履行名、付款名、发票名、授权签字人、目标公司、批准或决策主体。国资表：转让方国资层级、是否导致不再控股、例外情形主张、批文或决策文件痕迹。版本表：正文、评估及核准/备案、批文、放弃声明、内部决议、工商简易稿、聊天确认；冲突并列。未核批准或例外情形：该生效能力字段停止。

## 5. 给付闭环

标的比例与国有股权属性；权利负担；评估文号与价款是否低于评估结果；例外情形与报批义务；付款节点是否挂在批准之后；名册记载与工商递件；过渡期限制。缺口标 `G#`。批准、登记写成生效条件或期限，不写成已经完成。不输出资产交割或上市股份操作主路径。

## 6. 优先购买、格式条款与强制规范

第八十四条书面通知与三十日；章程另定；口头不得写成已放弃。是否构成格式条款。强制规范只按第一百五十三条和解释第十六条区分，不用失效口诀。应进场而场外、低于评估值、阴阳价只保留识别与停笔。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把框架里的“未经批准无效”写成当然无效。

## 9. 谈判与签署提醒

谈判顺序：先红线（签字即生效、应进场而场外、价款低于评估、假批文、查封股），再必须改（例外情形落条、批准生效、书面优先购买、名册/工商与付款挂钩），最后可优化。签署提醒：法定代表人或授权委托书；批文/决策、评估核准或备案、放弃声明、内部决议入附件；工商简易稿价款与正文一致。不指导倒签或补假批准。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书、国资报批代办或效力保证，也不是普通转股、资产转让或进场挂牌审查。
