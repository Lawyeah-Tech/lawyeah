# 边界与路由

本技能只审查 **合伙合同相关 / 股权激励型合伙合同**。主线是员工以有限合伙人财产份额间接持有目标公司股权，并约定授予、成熟与离职回购。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 无目标公司间接持股、无授予／成熟／激励回购；主线是 GP 无限／LP 认缴／不执行事务的经营或基金 LPA | `有限合伙企业合同·审查` |
| 用户只要公司相关货架的有限合伙协议整审 | `合伙协议（有限合伙）·审查`（不两套灌入） |
| 上市公司直接授予限制性股票、解禁、回购注销 | `上市公司限制性股票激励协议·审查`。禁止打开其 method |
| 主给付是工资、奖金、提成、经济补偿，或要把份额折现写成劳动报酬 | `人格从属＋工资社保→劳动合同` |
| 只拿固定劳务报酬、不认缴、无合伙人身份 | `只拿固定报酬不分担亏损无合伙人决策权→个人劳务（雇佣）` |
| 以劳务折出资且无持股平台激励闭环 | `劳务出资型合伙合同·审查` |
| 不显名、不登记的隐名合伙 | `隐名合伙合同·审查` |
| 不领执照的自然人共同事业 | `个人合伙合同·审查` |
| 全体普通合伙人、无 GP／LP 分档 | `普通合伙企业合同·审查` |
| 主文件是公司股东协议：股权比例、否决权、随售拖售、章程 | `公司股东协议·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式（出稿后自审） |
| 已签未争、问缴资日／工商日／分配留痕 | 本套导航的履约步骤 |
| 已成争：劳动仲裁追份额或工资、民事回购之诉、除名、立案仲裁 | 合同争议或劳动争议领域；不填签前十节 |
| 未登记代持要求改成可履行；份额改成可仲裁劳动报酬；按管理办法分期 50% 或回购价上限改合伙份额 | 停笔告知，不改写成可履行规避结构；用户坚持则整体停止 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

专业版未收录的邻类不会作为本原子的实体审查对象。若用户拿这些文本来找本技能：输出 `unavailable` 或负触发路由，不得用本类型硬套。

本技能不得转去加载普通有限合伙企业合同、上市公司限制性股票激励协议或劳动合同双文件完成本类型审查，也不得把管理办法第二十六条回购上限、每期解禁不超过 50%、或劳动经济补偿 N／N+1 写成持股平台默认主路径。
