# 边界与路由

本技能只审查 **公司相关合同 / 社会团体负责人变更合同**。主线是依法登记的社会团体法人，依据章程和会员（代表）大会或理事会决议办理负责人任免、交接，并向民政申请变更登记。不是买卖社团，不是民办学校转让，也不是公司工商法定代表人变更。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 办学许可、举办者变更、学校法人财产、师生权益作为主给付 | `民办学校转让协议·审查` |
| 公司股权对价、股东名册过户、注册资本不因本约以外原因变动的存量买卖 | `公司股权转让·审查` |
| 收购公司股权并转移控制权 | `股权收购合同（含控制权转移）·审查` |
| 资产包、核心经营资产交割 | `资产收购合同·审查` |
| 公司法定代表人变更（市场监管／企业登记，主体是公司不是社会团体） | 本套导航的类型切开步骤 |
| 基金会、社会服务机构、民办非企业单位整案 | 本套导航的类型切开步骤 重新定性 |
| 主文是劳动合同、岗位聘用、工资社保 | `人格从属＋工资社保→劳动合同` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式（出稿后自审） |
| 已签未争、问递件日／交接日／公告日 | 本套导航的履约步骤 |
| 交章、决议效力、侵占挪用已被催告、立案、开庭或仲裁 | `已出现催告解除函索赔立案开庭仲裁` 或对应专项；不填签前十节 |
| 把社团写成股权出售、分配利润或无决议即视为已登记 | 留本任务只出红线；用户坚持改成可履行则整体停止 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

专业版未收录的邻接场景不会作为本原子的实体审查对象。若用户拿这些文本来找本技能：输出 `unavailable` 或负触发路由，不得用本类型硬套。

本技能不得转去加载民办学校转让、股权转让、资产收购或劳动合同双文件完成本类型审查，也不得把举办者变更、股权交割包或劳动岗位变更写成社团负责人默认主路径。
