# 审查方法（锁定 公司相关合同 / 社会团体负责人变更合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型，禁止打开民办学校转让、股权转让、资产收购或劳动合同双文件“对照一下”。

本文件是**社会团体负责人任免、交接与民政变更登记配合**的签前判断节点，不是栏目说明书，也不是公司法定代表人工商变更清单或民办学校举办者变更清单。禁止把股权交割包、办学许可转让或劳动岗位变更写入本类型默认结论。

每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、必然完成民政登记、对方必然交章或唯一必得金额。

`search_law` 返回已失效《合同法》及其解释、1989 年《社会团体登记管理条例》、1998 年条例已被修改文本、已失效《公司登记管理条例》第三十条公司法定代表人三十日条款、担保法解释或物权法时记为噪声，不得写入 `L#`。民法典第八十五条是**营利法人**出资人撤销决议，不得写成社会团体默认 `L#`。党政干部兼职的中央文件、地方示范章程“须由内地居民担任”未核验原文前不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突。

示范文本只参考结构。物业交接、公司法定代表人辞任、员工离职交接表不证明本约条款已被接受。

### 双文件使用（标题与文件名不完全对应时不拒跑）

同目录两份知识文件按标题语义使用，不回改正文，不因文件名拒跑：

- 含“首部 / 交易条款 / 配套 / 尾部 / 语言”的当框架级条款清单，供节点 8 出句；

## 节点 1　类型识别与负触发

### 1.1 本类型正像

同时满足才继续：

- 主体是**已经依法登记**的社会团体法人（不是公司、不是未登记的“协会筹备组”冒充）；
- 标的是负责人职权、责任及对外登记状态，以及印章、证书、账户、资料的交接；
- 核心给付是按章程完成任免并配合向民政办理变更登记或备案，而不是出售社团本身。

标题写成“负责人变更合同”“变更交接协议”“法定代表人变更确认书”只是线索。名实不符按核心给付归类，标题冲突写入 `C#`。

### 1.2 必须切开（禁止两套知识）

| 信号 | 归入 | 本技能动作 |
| --- | --- | --- |
| 办学许可、举办者变更、学校法人财产不得被掏空、师生权益 | 民办学校转让协议 | **负触发** → `民办学校转让协议·审查`。不得当社团换届审 |
| 价款进原股东、股权比例、股东名册、公司章程修正、注册资本 | 股权转让／股权收购 | **负触发** → `公司股权转让·审查` 或 `股权收购合同（含控制权转移）·审查` |
| 资产包、核心经营资产、存货与债权债务整体交割 | 资产收购 | **负触发** → `资产收购合同·审查` |

| 基金会、社会服务机构、民办非企业单位，不是社会团体 | 其他非营利法人 | **负触发** → 引擎。不把社团条例直接套用 |

民办学校转让、股权买卖误入是硬闸：一旦核心给付滑入上述结构，立即停笔转出。不得删掉办学许可或股权对价后继续当本类型审。

### 1.3 加载协议

只打开本目录 `基本面.md` 与 `框架.md`。禁止读 `types/` 或其他场景原子目录。

### 1.4 违法结构停笔

出现下列任一结构，只出告知，不改写成可履行文本：

- “甲方将本社会团体全部权益／控制权／会员资格作价人民币【金额】转让给乙方”；
- 向出资人、设立人或会员分配利润、剩余财产或“股权对价”；
- “双方签字即视为民政变更完成，无需章程决议、无需业务主管单位同意”；
- 出租、出借《社会团体法人登记证书》或印章换取管理费；
- 倒签决议或批复日期以赶三十日期限或掩盖程序瑕疵。

用户坚持“改到能签／先当股权卖再补决议／保证民政一定办下来”：整体停止。合规改道（先完章程程序和批复，再签交接、再递件）只点名并出修改句，不在本任务起草规避方案。

## 硬闸 A　章程／会员大会是变更依据

本闸改变能不能留在本任务并启动登记配合句。

1. **先找章程，再谈协议**  
   社会团体法人应当依法制定章程，设会员大会或会员代表大会等权力机构、理事会等执行机构；理事长或会长等负责人按照章程担任法定代表人。依据：民法典第九十一条。  
   文本必须回链：经登记管理机关核准的现行章程条款、作出任免的机构（会员大会／会员代表大会／理事会／常务理事会）、会议时间届次、出席人数、表决比例。章程未附或条款与正文冲突：并列 `C#`，决议字段停止。  
   **修改句**：`各方确认：【原负责人】辞去／被免去【职务】、【新任负责人】担任【职务】【是否同时担任法定代表人】，以【社会团体名称】经核准的现行章程第【待填】条，以及【会议名称、届次、日期】作出的有效决议为依据。本协议是执行该决议并办理交接与变更登记的文件，不代替章程规定的选举、罢免或聘任程序，也不因本协议签署而视为决议已经作出。`

2. **决议程序可核验**  
   对照章程核对：召集权人、通知期限与方式、出席定足数、表决比例、书面纪要和出席人员签字。知识稿举例“代表大会须三分之二出席、选举过半数、罢免理事长须理事会三分之二”只是常见写法，**以该社团核准章程为准**，禁止编造比例。通知、签到、表决票均未见：字段停止，不写“口头都同意了即有效”。  
   **修改句**：`社会团体应在签署本协议前向各方提供并作为附件：（1）现行核准章程；（2）本次会议通知、签到表、表决记录和会议纪要。纪要应载明出席人数符合章程第【待填】条、表决结果符合章程第【待填】条。缺失任一项的，新任负责人有权中止交接，社会团体应在【待填】日内补正；逾期未补正的，任何一方不得要求对方按已完成变更履行。`

3. **不得直接套用营利法人决议撤销专条**  
   民法典第八十五条规范营利法人出资人撤销决议。社会团体会员或理事就程序瑕疵如何救济，运行时再核，不得写成“依第八十五条必然可撤销／必然有效”。内部程序严重缺失时：建议暂缓签署和递件，不宣布决议无效。

4. **最强反方**  
   相对人可能主张：有交接协议就不必开会；或反过来主张程序稍有瑕疵则整份交接无效。签前两极都不写。只写：协议不能补造决议；程序缺口先补正再递件。

## 硬闸 B　民政登记闭合

本闸是本类型对外生效级闸。

1. **登记事项与机关**  
   社会团体登记事项包括名称、住所、宗旨、业务范围、活动地域、法定代表人、活动资金和业务主管单位。成立社会团体应经业务主管单位审查同意并登记。变更登记事项，应当自业务主管单位审查同意之日起**三十日内**向登记管理机关申请变更登记；修改章程，应当自审查同意之日起三十日内报登记管理机关核准。变更名称、住所、法定代表人由登记管理机关公告。依据：条例第三条、第十二条第二款、第十八条、第二十三条；民法典第六十四条。  
   **修改句**：`社会团体应在取得业务主管单位就本次负责人／法定代表人变更的书面同意之日起三十日内，向登记管理机关申请变更登记；涉及修改章程的，同步报请核准。新任负责人应配合签署申请表并提供身份证明。原负责人应在收到书面通知后【待填】日内配合提供变更所需的本人签字文件，但原负责人拒不配合的，不阻止社会团体依据有效决议和业务主管单位书面同意申请变更。本协议生效不等于变更登记完成。`

2. **协议生效 ≠ 登记完成**  
   法人实际情况与登记事项不一致的，不得对抗善意相对人。依据：民法典第六十五条。合同生效后，当事人不得因法定代表人、负责人变动而不履行已订立合同。依据：民法典第五百三十二条。  
   禁止：“签字即视为对外已变更”“未登记则本协议未生效且互不负责”“变更后已签合同自动解除”。  
   **修改句**：`本协议自社会团体盖章且原负责人、新任负责人签字之日起在当事人之间生效，约束交接、配合登记和责任划分。法定代表人等登记事项的对外公示，以登记管理机关准予变更并公告为准。变更前后，社会团体已订立合同的履行不受负责人变动影响；任何一方不得以负责人为由拒绝履行或主张合同自动解除。`

3. **三十日与行政处罚**  
   不按照规定办理变更登记的，登记管理机关可警告、责令改正、限期停止活动、责令撤换直接负责的主管人员；情节严重的撤销登记。依据：条例第三十条第一款第（四）项。修改句把三十日写成**义务和起算点**（业务主管单位书面同意之日），不编造“过期合同无效”。未见主管单位、且章程或历史材料显示有主管单位：字段停止。条例第三条第三款免于登记的团体：不按本类型强行套登记句，标 `G#` 或转引擎。

4. **最强反方**  
   相对人可能主张未登记则新负责人无权签协议；或主张内部决议已够、不必登记。签前：新任可以在决议后作为协议丙方签字；对外代表权以登记和善意相对人为限；不保证窗口必然受理。

核验失败：三十日条号和法律结论字段停止，事实摘录和“不得视为已登记”的修改句草稿继续。

## 硬闸 C　不得把社团当公司股权买卖

本闸是本类型生存级闸。

1. **非营利定性**  
   社会团体是中国公民自愿组成、按章程开展活动的非营利性社会组织，不得从事营利性经营活动。为非营利目的成立、不向出资人、设立人或会员分配利润的法人为非营利法人，包括社会团体。依据：条例第二条、第四条；民法典第八十七条。社会团体法人的不动产和动产依法受保护。依据：民法典第二百七十条。

2. **禁止的写法**  
   “转让本会 100% 权益”“购买会长职位”“会员资格作价”“剩余财产归新负责人”“控制权对价人民币【金额】”。出现上述表述：红线。不得改成可履行买卖，不得当 `公司股权转让·审查` 的股权交割来写。  
   **修改句（仅告知／删除）**：`删除将社会团体本身、会员资格、负责人职位或剩余财产作为买卖标的并支付对价的条款。各方确认：社会团体是非营利法人，不得向出资人、设立人或会员分配利润，不得从事营利性经营活动。本协议项下不产生股权、份额或控制权转让。印章、登记证书、银行账户和资料归社会团体法人所有，原负责人仅负交接义务，无权处分。`

3. **对价只能是费用或离任安排**  
   可谈：离任审计费、变更规费由社团承担；章程或合法决议项下的离任补偿（须可核验，不得写成剩余财产分配）。把“补偿”写成购买职位的价款：红线。

4. **最强反方**  
   买方可能主张“实际控制了协会就等于买下”；卖方可能主张“非营利所以交接协议全部无效”。签前：禁售条款删除后，交接和登记配合仍可谈；不保证整份协议因出现买卖句而当然全部无效。

## 硬闸 D　与 `民办学校转让协议·审查` 及公司买卖切开

本闸改变能否留在本任务。

1. **民办学校转让**  
   主文是办学许可证、举办者变更、学校法人财产不得被转让掏空、师生权益、教育行政部门审批：负触发 `民办学校转让协议·审查`。协会下设培训学校被“打包卖掉”：学校部分转出，社团负责人部分仅在可单独评改时留本任务，办学许可不代审。  
   **修改句（仅告知）**：`删除或以附件剥离以民办学校举办者变更、办学许可或学校法人财产转让为主给付的条款。本协议仅约定社会团体负责人的任免执行、交接与民政变更登记配合。`

2. **公司股权／资产**  
   社团所办企业的股权转让、资产收购：分别转 `公司股权转让·审查`／`股权收购合同（含控制权转移）·审查`／`资产收购合同·审查`。本任务只审社团负责人，不把企业股权交割写成换会长的默认路径。

3. **劳动合同**  
   秘书长同时是聘用人员：劳动条款转 `人格从属＋工资社保→劳动合同`。任免是治理行为，不等于协商变更劳动合同。修改句点名“职务任免不当然解除或变更劳动关系，劳动事项另议”，不代写解除协议。

4. **最强反方**  
   标题写“社团变更”但附件是《民办学校转让协议》或《股权转让协议》，相对方可主张按学校或股权交易履行。签前按核心给付分流，不两套都审。

## 硬闸 E　交接清单、归属与拒交

1. **清单必须特定化**  
   至少分列：公章、财务章、合同章、发票章；社会团体法人登记证书正副本；银行开户文件、U 盾与密码；交接基准日财务报表、账簿凭证、发票；在履重大合同；固定资产与租赁。只有“有关资料”：必须改。监交人可约定监事会或监事。异议期用 `【待填】` 日，不得用“视为完好无损”单方卸责。  
   **修改句**：`原负责人应于交接基准日【待填】后【待填】日内，按附件《交接清单》向新任负责人移交全部印章、证照、账户介质、财务资料和业务文件，由【监事／监交人】监交并三方签字。印章、证照和银行账户归社会团体法人，原负责人不得占有、出租、出借或处分。新任负责人应在接收后【待填】日内书面提出异议；逾期未提出的，仅视为对清单列明且已点交物品的表面接收，不免除原负责人对隐瞒、伪造、毁损的责任。`

2. **资格与兼任**  
   社会团体的法定代表人不得同时担任其他社会团体的法定代表人。发起人、拟任负责人正在或曾经受到剥夺政治权利的刑事处罚，或不具有完全民事行为能力的，登记管理机关可不予登记。依据：条例第十二条第三款、第十三条第一款第（三）项。  
   **修改句**：`新任负责人陈述并保证：具有完全民事行为能力；未正在或曾经因犯罪被剥夺政治权利；未同时担任其他社会团体的法定代表人。上述陈述不实，或登记管理机关因此驳回变更申请的，社会团体有权中止交接并要求其配合另行选举，原负责人的交接义务不因此免除。`

3. **拒交与重刻**  
   不得写“原负责人不交章则买卖作废并退款”（那是股权交易语言）。应写继续履行、逾期日违约金、社会团体可凭有效决议和主管单位同意申请变更，并按地方规定申请作废原章、重新刻制。不保证法院必然行为保全或强制执行任免决议。出租、出借证书或印章：条例第三十条第一款第（一）项，只告知，不改成可履行外借。

4. **换届前审计**  
   实务常见：更换法定代表人前由登记管理机关和业务主管单位组织财务审计。文本完全不提财务交接和或有负债披露：必须改。不编造必须由哪一家事务所审计。

5. **最强反方**  
   原负责人可能主张“章在我手里所以我仍是法定代表人”；新负责人可能主张“决议一出即可对外代表”。签前：内部决议约束当事人；对外不得对抗善意相对人；拒交不使决议自动消失，也不使未登记的新负责人当然取得全部对外代表外观。

## 节点 2　主体、授权、章程

1. 建主体表：社会团体全称与统一社会信用代码、原负责人、新任负责人、监交人、业务主管单位。名称不一致不自动合并。
2. 社会团体必须作为一方盖章。仅新旧负责人私签、社团未盖章：登记配合和法人义务字段停止。
3. 章程对任免机构、任期、连任、罢免另有规定的，先读章程，与正文冲突并列 `C#`。
4. 新任是否党政机关干部、是否已在其他社团任法定代表人、是否丧失行为能力：材料未提及不得写成“无问题”，只能写 `依据不足`。干部兼职审批未核验：字段停止。
5. 口头“理事会都同意了”不得写成已决议。

---

## 节点 3　标的、交接物、权利负担

1. 职务确定到法定代表人／会长／副会长／秘书长，是否一人兼任写清。
2. 交接物归社团。材料未提及银行 U 盾或发票不得写成“无遗漏”，只能写 `依据不足`。
3. 不得把签收清单写成已经完成民政登记对抗。
4. 原负责人任职期间借款、担保、诉讼：要求披露，不在本任务做债务重组。

---

## 节点 4　程序与生效

把章程决议、主管单位书面同意、三十日递件、登记公告、银行预留印鉴变更写成**义务和期限**，不写成已经完成。

| 文本写法 | 本任务动作 |
| --- | --- |
| “本合同签字即视为负责人变更完成、新负责人立即对外代表” | 拆成协议生效 vs 内部决议 vs 登记公示 vs 善意相对人 |
| “民政变更后本协议才生效”且无谁负责、几日内、未完成后果 | 补主体、期限；保留递件义务；删除“未登记则互不负责” |
| “双方同意视为已开会／已批复” | 红线；改为书面附件和先决条件 |
| 用户要求倒签决议或补假批复 | 整体停止 |
| 设置任意解除权使任免可逆 | 必须改：本协议不宜约定任意解除；终止不影响任职期间责任和保密 |

不得把“双方同意视为已批准”写成可放行结构。

## 节点 5　格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

重复使用的交接模板仍可能构成格式条款。审查单方“视为无异议”、不得调整的高额违约金、管辖、最终解释权是否有显著提示。

违反法律、行政法规强制性规定不一律无效。未办变更登记主要对应行政义务和对抗，不轻易写“未递件则整份交接协议无效”。从事营利性经营、分配利润、出租出借印章证书：只告知，不写假架构。禁止用已失效“效力性／管理性”口诀。

法定代表人越权订立的合同，除相对人知道或应当知道外对法人有效。依据：民法典第五百零四条。本任务不在签前宣布历史合同无效。

## 节点 6　违约、解除、争议解决

1. 逾期移交印章、隐瞒重大债务或账册、拒不配合登记、新负责人无正当理由拒收，必须分别有日违约金或固定金额。只有“依法承担违约责任”视为必须改。
2. 本协议目的是执行已作出的任免，不宜约定任意解除使治理行为可逆。法定解除只点名催告或目的不能实现，不在本任务作出已解除结论。
3. 违约金避免“不得调整”或“按所谓转让款百分之三十必得”。不存在合法转让款时，不得发明一个转让总额来计算违约金。
4. 争议解决：已有仲裁条款，不得改成“应向某法院起诉”并假装已选定诉讼；或裁或诉、机构不明：改成单一机构或单一法院连结点；社团住所地可作为约定连结点，不得写成“负责人变更依法专属管辖”。
5. 微信已读不写成已经送达，除非合同把该渠道定为送达。

## 节点 7　跨境、分支与其他结构

1. 涉外主体或境外非政府组织代表机构：不适用本类型默认路径；条例第十八条不得直接改写成境外法结论。字段停止或转引擎。
2. 分支机构、代表机构不具有法人资格，不得再设分支，不得设地域性分支。依据：条例第十七条。本任务不把分支负责人任免写成社团法定代表人变更。
3. 宗教团体等特别法有额外任职限制：只标红旗和字段停止，不整份代审。
4. 不竞争、不招揽可作可优化，不得写成限制会员依法结社的惩罚性条款。

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

对照已加载框架级文件和本方法硬闸，按六步逐段出句。框架中的学校、股权、劳动清单：仅在文本确实出现时用于转出，不写入本类型默认主路径。

| 步 | 本类型必须盯的点 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题用交接／确认，避免“转让”“收购”；三方主体；鉴于回链章程条款和决议届次，不把登记写成已完成 | 主体与鉴于修改句 |
| 交易条款 | 职务特定化；决议附件；三十日递件；交接基准日；清单分列；资格与兼任 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 逾期交章／拒不配合登记的分别后果；删除股权化对价；任职期间责任不因交接免除；保密 | 可执行后果句 |
| 尾部 | 社团盖章；新任以丙方签字；原负责人亲笔；附件：章程、决议、批复、清单 | 生效与附件修改句 |
| 语言 | 正说加反说；任免 ≠ 买卖；协议生效 ≠ 登记完成；交接 ≠ 验收无瑕疵 | 替换空词的句子 |
| 常见问题 | 无决议、视为已登记、股权化出售、清单缺失、任意解除 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（股权化出售、利润分配、无决议即视为登记、出租出借印章证书、倒签）；
- `必须改`：可谈但签署前要落句（章程回链、决议附件、三十日递件、清单、资格兼任、协议生效与登记拆分）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级交接僵局或个人无限连带且用户拒绝升级：停止“可以签署”建议。
