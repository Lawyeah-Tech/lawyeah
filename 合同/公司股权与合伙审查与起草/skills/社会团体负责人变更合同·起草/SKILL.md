# 社会团体负责人变更合同·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **公司相关合同 / 社会团体负责人变更合同** 己方稿，出稿后用本类型硬闸自审。交付草稿、未决项、自审风险表和自审后修改句。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「审查社会团体负责人变更合同（公司相关合同）」。`depends-on` 为空。不要求先跑导航。

主线是**依法登记的社会团体法人**，依据经核准章程和会员（代表）大会或理事会有效决议，对法定代表人、会长、副会长、秘书长等负责人办理任免、交接，并向民政登记管理机关申请变更登记或备案。不是买卖社团控制权，不是民办学校举办者变更，也不是公司工商法定代表人变更。

不交付：他类审查、从零起草、履约交底、争议文书、有效性或必然完成民政登记保证、民办学校转让／股权转让／股权收购／资产收购／劳动合同／公司章程整份代审。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **章程／会员大会是变更依据**：负责人任免由经核准章程指定的会员（代表）大会或理事会（常务理事会）按召集程序和表决比例作出。交接协议、确认书只执行已作出的决议，**不产生**变更本身。未见现行核准章程、会议通知／签到／纪要或章程规定的出席与表决比例：决议与登记配合字段停止。不得把民法典第八十五条营利法人决议撤销规则直接写成社团默认。
2. **民政登记闭合**：登记事项（含法定代表人）变更，应当自**业务主管单位审查同意之日起三十日内**向登记管理机关（民政）申请变更登记；修改章程同步报核准。协议签字生效 ≠ 负责人对外公示完成。未完成登记不得对抗善意相对人。禁止“双方签字即视为已完成民政变更、无需批复”。
3. **不得把社团当公司股权买卖**：社会团体是非营利法人，不得向出资人、设立人或会员分配利润，不得从事营利性经营活动。禁止把会长／法定代表人变更写成转让“社团股权、控制权、会员资格或剩余财产”并收对价。印章、证照、账户归社团法人，原负责人仅为代管。
4. **与民办学校转让 `民办学校转让协议·审查` 切开**：核心给付是办学许可、举办者变更、学校法人财产与师生权益 → `民办学校转让协议·审查`。存量公司股权买卖 → `公司股权转让·审查`；含控制权转移的股权收购 → `股权收购合同（含控制权转移）·审查`；资产收购包 → `资产收购合同·审查`。不得删掉学校转让或股权对价条款后硬套本技能。
5. **交接清单与拒交应对**：必须附件列明印章、登记证书、银行账户与 U 盾、财务账册、在履合同。原负责人拒不移交：继续履行、逾期日违约金、凭有效决议和主管单位批复申请变更或申请作废重刻；不得写成私自转卖公章或把证照当交易标的。

## 工作边界

正触发：已有可读待签《社会团体负责人变更交接协议》《负责人变更确认书》或同等交接文本，尚未签署，尚未成争；主体是依法登记的社会团体法人；核心给付是负责人职权、责任及对外登记状态的交接与配合登记。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 办学许可、举办者变更、学校法人财产转让作为主给付 → `民办学校转让协议·审查`；
- 公司股权对价、股东名册过户、注册资本变动 → `公司股权转让·审查` 或 `股权收购合同（含控制权转移）·审查`；
- 资产包买卖、核心经营资产交割 → `资产收购合同·审查`；
- 公司法定代表人变更（市场监管／企业登记，不是民政社团）→ 本套导航的类型切开步骤；
- 基金会、社会服务机构、民办非企业单位整案且不是社会团体 → 引擎重新定性；
- 主文是劳动合同、岗位聘用或工资社保 → `人格从属＋工资社保→劳动合同`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问递件日、交接日、公告日 → 本套导航的履约步骤；
- 已成争（催告交章、决议效力之诉、侵占挪用、立案、开庭、仲裁）→ `已出现催告解除函索赔立案开庭仲裁` 或对应专项，不填签前十节。

把社团当股权出售、分配非营利利润、无决议即办理登记、出租出借印章证书、倒签决议：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；代表社会团体（新理事会）、新任负责人还是原负责人；是否已依法登记为社会团体法人；正文、核准章程、会员（代表）大会或理事会决议、业务主管单位批复版本；拟变更职务是否含法定代表人；不可接受事项；法域与拟签时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密时，先停止策略输出。

## 起草模式

本原子只承担本类型起草。待签评改转 `社会团体负责人变更合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `社会团体负责人变更合同·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。

### 起草必写

- 负责人任免由经核准章程指定的会员（代表）大会或理事会（常务理事会）按召集程序和表决比例作出。交接协议、确认书只执行已作出的决议，不产生变更本身。
- 登记事项（含法定代表人）变更，应当自业务主管单位审查同意之日起三十日内向民政申请变更登记；修改章程同步报核准。协议签字生效 ≠ 负责人对外公示完成。未完成登记不得对抗善意相对人。
- 社会团体是非营利法人，不得向出资人、设立人或会员分配利润，不得从事营利性经营活动。印章、证照、账户归社团法人，原负责人仅为代管。
- 必须附件列明印章、登记证书、银行账户与 U 盾、财务账册、在履合同。原负责人拒不移交：继续履行、逾期日违约金、凭有效决议和主管单位批复申请变更或申请作废重刻。

### 附件必附

- 现行核准章程；会员（代表）大会或理事会决议（含通知／签到／纪要或章程规定的出席与表决比例）。
- 业务主管单位审查同意文件（章程或条例要求时）。
- 交接清单：印章、登记证书、银行账户与 U 盾、财务账册、在履合同。

### 禁止出现

- “双方签字即视为已完成民政变更、无需批复”。
- 把会长／法定代表人变更写成转让“社团股权、控制权、会员资格或剩余财产”并收对价。
- 分配非营利利润；无章程决议即办理登记；出租出借印章证书；倒签决议。
- 私自转卖公章或把证照当交易标的。不得把民法典第八十五条营利法人决议撤销规则写成社团默认。

出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、把社团改成股权出售或利润分配、无章程决议却要求写成已完成民政登记、出租出借登记证书或印章、保证有效或必然完成变更登记。
- `字段停止`：未见核准章程或有效决议；未见业务主管单位书面同意（章程或条例要求时）；新任负责人资格或兼任其他社团法定代表人未核；交接清单缺失；党政干部兼职审批未核。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或文本已滑入民办学校转让／公司股权买卖／劳动合同。

生存级交接僵局、涉嫌侵占挪用或个人无限连带且用户拒绝升级：停止“可以签署”建议。
