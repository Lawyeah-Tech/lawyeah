# 审查方法（锁定 公司相关合同 / 股权托管协议）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型，禁止打开代持显名路径、转让优先购买交割包或股东协议治理清单“对照一下”。

本文件是**登记股东把特定股东权利的行使委托给受托人**的签前判断节点，不是栏目说明书，也不是隐名出资清单或股权过户清单。禁止把解释三第二十四条显名要件、优先购买三十日交割包写入本类型默认结论。

每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、不可撤销必然排除任意解除、对方必然接受或唯一必得金额。

`search_law` 返回已失效《合同法》及其第四百一十条、1993 年《公司法》第三十四条抽回出资或第五十六条工会旧义、2011 年解释三第二十四条旧义、担保法第七十八条或商业银行／信托公司股权集中托管规章充当本类型主依据时记为噪声，不得写入 `L#`。2023 年第五十六条本次优先命中 1993 年旧义，有限公司名册以第五十五条、第三十四条、第一百零二条同向吸收，运行时再核第五十六条。合同编通则解释第十六条未核验原文前不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突。

示范文本只参考结构。市场常见《表决权委托协议》《股权托管协议》不证明本约条款已被接受。范本里的“全权行使并办理股份过户”只作负向切开。

### 双文件使用（标题与文件名不完全对应时不拒跑）

同目录两份知识文件按标题语义使用，不回改正文，不因文件名拒跑：

- 含“首部 / 交易条款 / 配套 / 尾部 / 语言”的当框架级条款清单，供节点 8 出句；
- 宏观的类型切开、行权边界、返还与任意解除、监管红旗由本方法节点承担。知识稿把“为受托人利益则委托人不得任意解除”写成法条的，**降级**：第九百三十三条仍可解除；不可撤销、有偿和主合同利益只提高解除成本。知识稿把股份过户、受托人成为登记股东写成托管结果的，**降级**：那是转让或代持，按节点 1.2 转出。
- 文件不可用（空、代码块、与本类型明显无关）：记 `G#`，用本方法节点继续，不得改去加载代持或转让双文件，不得编造授权期限或违约金。

## 节点 1　类型识别与负触发

### 1.1 本类型正像

同时满足才继续：

- 目标公司是**已经依法设立并有效存续**的公司法人；
- 委托人是该股权的**名册或登记股东**，不是躲在登记股东背后的实际出资人；
- 核心给付是约定期限内，由受托人行使表决、分红、提案、召集或知情等**股东权利**，工商登记股东和出资归属不因本约改变。

标题写成“股权托管协议”“表决权委托协议”“过渡期管理协议”只是线索。名实不符按核心给付归类，标题冲突写入 `C#`。

### 1.2 必须切开（禁止两套知识）

| 信号 | 归入 | 本技能动作 |
| --- | --- | --- |
| 实际出资人出钱、名义股东登记、投资权益归隐名方、请求显名或变更登记 | 股权代持 | **负触发** → 投资侧 `股权代持合同·审查`，公司相关 `股权代持协议·审查`。见硬闸 D |
| 价款换股权、办理变更登记、注册资本因本约在当事人之间转让 | 股权转让合同 | **负触发** → `公司股权转让·审查`。不得当托管审 |
| 主文是否决权、随售／拖售、董事会席位，托管只是背景一句 | 股东协议 | **负触发** → `公司股东协议·审查` |
| 主文是条件成就时购回已发行股权 | 股权回购协议 | **负触发** → `股权回购协议·审查` |
| 主给付是出质登记、质权设立 | 股权质押 | 转引擎。本任务只审托管与在先质权冲突，不代写质押本约 |
| 银行、信托公司把股权集中存管到登记机构、维护股东名册 | 监管集中托管 | 转引擎。不得用第九百三十三条委托闸硬套 |
| 信托财产转移、受托人以自己名义为受益人管理股权 | 股权信托 | 转引擎。本约是委托，不是信托法上的财产权转移 |

代持、转让误入是硬闸：一旦核心给付滑入上述结构，立即停笔转出。不得删掉隐名出资或过户条款后继续当托管审。

### 1.3 加载协议

只打开本目录 `基本面.md` 与 `框架.md`。禁止读 `types/` 或其他场景原子目录。

### 1.4 违法结构停笔

出现下列任一结构，只出告知，不改写成可履行文本：

- 用托管把外资限制、特定行业准入或公务员等身份限制绕开，真实安排是隐名持股；
- 抽屉协议：对外一套“无一致行动／未取得控制”，对内把表决权全部交给收购方以规避要约、短线交易或股东承诺；
- 把违法代持上市公司股票改称托管，规避 2023 年第一百四十条；
- 两套授权：提交给公司的授权书范围窄，内部协议范围宽到可处分股权；
- 倒签授权日期以改变某次股东会的表决时点。

用户坚持“改到能签／就写不可撤销全权／对外别披露”：整体停止。合规改道（真委托行权、依法披露、另立定性正确的代持或转让）只点名并出修改句，不在本任务起草规避方案。

## 硬闸 A　托管 ≠ 代持 ≠ 转让

本闸改变能否留在本任务。

1. **有没有“权利行使、身份不变”**  
   文本须能指出：谁作为登记股东，把哪些股东权利在多长期限内交给谁行使。只有“甲方将股权转让给乙方并办理变更登记”→ `公司股权转让·审查`。只有“甲方实际出资、乙方出名”→ 硬闸 D。  
   **修改句（留在本任务时）**：`各方确认：本协议项下安排是【委托人】将其持有的目标公司【待填】%股权（对应认缴／实缴出资额人民币【待填】元）所附【表决权／分红权／提案权／召集权／知情权，择一或多选】的行使，在托管期限内委托【受托人】办理。股权所有权、出资义务和公司登记机关记载的股东仍为委托人。本协议不构成股权转让，也不构成隐名出资或名义持股。`

2. **禁止的滑词**  
   “托管即视同过户”“受托人有权将股权登记到自己名下”“委托人仅为代持人”。出现任一句：按核心给付转出或红线删除。  
   **修改句（仅告知）**：`删除将股权变更登记至受托人名下、将委托人写成隐名出资人或将本协议作为过户依据的条款。若各方真实意思是转让或代持，应终止本托管文本并改走对应协议，不在本协议保留股权外壳。`

3. **最强反方**  
   相对人可能主张：标题写托管，附件是转让或代持，应按过户或显名履行。签前按核心给付分流，不两套都审。

## 硬闸 B　表决权／分红权行使边界

本闸改变受托人能不能被写成“去开会、收钱”。

1. **授权三要素**  
   2023 年第一百一十八条：委托代理人出席股东会，应当明确代理的事项、权限和期限；代理人向公司提交授权委托书，并在授权范围内行使表决权。缺任一要素：行权对抗公司字段停止。  
   **修改句**：`委托人应于本协议生效后【待填】日内，向目标公司提交与本协议附件一一致的《授权委托书》，载明：代理事项（出席股东会并就附件二所列议案投票）、权限（指示委托／列明可自主决定的日常事项）和期限（自【日期】至【日期】或至主交易交割日，以较早者为准）。公司未签收该授权委托书前，受托人不得向公司主张其已取得表决权代理。授权范围以提交给公司的文本为准；内部协议与授权书不一致的，对公司和其他股东以授权书为准，对内按本协议承担违约责任。`

2. **积极列表与消极列表**  
   积极：日常经营事项表决、按书面指示投票、代收已宣告股利并在【待填】日内划入委托人账户。  
   消极（默认不得行使，除非正文逐项点名并经委托人书面同意）：转让或质押标的股权、同意公司合并分立解散清算、修改章程中与股权比例或表决机制有关的条款、放弃优先认缴、对关联交易投赞成票、对外提供担保、查阅后向第三人披露财务资料。  
   **修改句**：`受托人仅有权行使附件二积极列表中的权利。未经委托人事先书面同意，受托人不得行使消极列表中的权利，也不得以托管为由处分股权、收取股权转让款或将分红留在受托人账户超过【待填】日。知情权的行使不得实质性剥夺委托人依据公司法自行查阅、复制的权利。`

3. **全权还是指示**  
   全权：写明自主决定的议案类别，并保留消极列表。指示：受托人必须按委托人在会议召开前【待填】日送达的书面指示投票；逾期未指示的，写明“弃权”或“按上次同类议案”之一，不得留空。  
   “全权处理一切股东事务、包括法律未列明的权利”：必须改。

4. **分红**  
   分红权托管不等于分红归属改到受托人。写清：公司分配时的收款户名、是否允许受托人代收、划转时限、税负承担、未分配利润仍归委托人。  
   **修改句**：`标的股权对应的利润分配请求权仍归委托人。若公司将分红支付至受托人指定账户，受托人应在到账后【待填】日内全额划至委托人账户【户名、账号待填】，不得抵销、留置或挪作主债权清偿，除非各方另签书面抵销协议。因代收产生的税费由【待填】承担。`

5. **最强反方**  
   公司或其他股东可能主张授权不明、未提交授权书或超出范围，拒绝受托人签到。签前把授权书和公司签收写成行权先决条件，不写“协议一签就能对抗公司”。

核验失败：第一百一十八条的法律结论字段停止，事实摘录和“必须写事项／权限／期限”的修改句草稿继续。

## 硬闸 C　返还与违约

本闸改变期限结束后权利回到谁手里，以及中途撕毁的成本。

1. **返还清单必须可执行**  
   触发：约定期限届满、主交易交割完成、协议解除或授权被依法终止。动作：交回授权委托书原件、向公司送达《终止授权通知》、返还代收款项和印章／U 钥／会议资料、书面报告任期内投票和收付款。逾期按日计违约金，达到【待填】日委托人可登报或书面声明授权失效并自行出席。  
   **修改句**：`托管期限于下列较早之日终止：（1）【起止日期】届满；（2）主交易交割完成；（3）本协议依约解除。终止当日，受托人应向委托人交回授权委托书原件及全部代收款项、公司资料，并与委托人共同向目标公司送达终止授权通知。逾期未交回的，每逾期一日支付人民币【待填】元；逾期超过【待填】日的，委托人有权单方书面宣布授权失效，公司应以该书面通知为准停止承认受托人。`

2. **任意解除：写成本，不写废除法条**  
   第九百三十三条：委托人或受托人可以随时解除；有偿委托的解除方应赔偿直接损失和合同履行后可以获得的利益。知识稿所谓“为受托人利益则不得解除”不是该条原文。实务上，商事委托、不可撤销约定、高额违约金和主合同交叉违约可能提高解除成本，法院态度并不统一。  
   **禁止的写法**：`任何一方放弃民法典规定的任意解除权，该放弃不可撤销，解除行为当然无效。`  
   **修改句**：`本委托为有偿委托，托管费人民币【待填】元。本委托系为保障受托人在【主合同名称及编号】项下的交易利益而设，托管期限与该主合同履行期限挂钩。任何一方依第九百三十三条解除的，应提前【待填】日书面通知，并赔偿对方因此遭受的直接损失和合同履行后可以获得的利益；委托人无正当理由解除的，另须按人民币【待填】元支付约定违约金。各方理解：上述约定不保证解除行为当然无效，也不免除依法应承担的赔偿责任。受托人因委托人解除而丧失过渡期表决安排的，可依主合同主张交叉违约，但不得在本协议写成“解除后股权自动归受托人所有”。`

3. **越权与不作为的分别后果**  
   第九百二十九条：越权造成损失应当赔偿。第九百二十二条：变更指示须经同意。必须分别写：未按指示投票、擅自投赞成关联交易、擅自转委托、拒不交回授权。只有“依法承担违约责任”视为必须改。违约金避免“不得调整”或“按股权估值百分之三十必得”。

4. **最强反方**  
   解除方会主张法定任意解除不得预先放弃；相对方会主张商事委托应维持稳定。签前两极都不写死。只写：解除可能发生，成本要可计算，权利要能还回去。

核验失败：第九百三十三条效力字段停止；返还清单和禁止“解除当然无效”的修改句草稿继续。

## 硬闸 D　与代持 `股权代持合同·审查` 切开

本闸专门挡住“标题托管、结构代持”。

1. **识别**  
   同时出现或可推知：出资来自未登记的一方；登记股东承认自己“只是挂名”；投资权益、分红最终归未登记一方；目标是将来办理显名或变更登记。无论标题是否写托管，核心给付是代持。  
   - 股权投资相关合同语境（PE／VC、增资一并安排、投资权益归属）→ `股权代持合同·审查`  
   - 公司相关合同语境的独立代持本约 → `股权代持协议·审查`  
   本任务不展开解释三第二十四条的半数以上同意显名路径，不代写名义股东处分后的善意取得分析。

2. **上市公司**  
   2023 年第一百四十条禁止违反法律、行政法规代持上市公司股票。把违法代持改称托管：红线停笔，不改成可履行。通过接受委托持有 5% 以上股份的，信披办法要求告知委托人情况——这是披露义务，不能反过来证明代持合法。

3. **修改句（仅告知）**  
   `停止以股权托管协议承载隐名出资、名义股东和投资权益归属。该等安排属于股权代持，应改用对应代持协议审查，不在本协议写成可履行的“先托管后过户／先托管后显名”。禁止以托管名义规避法律、行政法规对股东身份、外资准入或上市公司持股的限制。`

4. **最强反方**  
   相对人可能主张“反正都是把权利给对方，代持和托管不必分”。签前必须分：外观股东是谁，决定债权人追谁、公司认谁、能不能对抗善意第三人。

---

## 节点 2　主体、授权、章程、权利负担

1. 建主体表：目标公司、委托人、受托人、主交易相对人、质权人、配偶、授权签字人。名称不一致不自动合并。
2. 委托人必须是名册或登记可核对的股东。口头“股份其实是我的”不得写成已具备委托资格。
3. 章程对表决权委托、代理人出席另有规定的，先读章程，与正文冲突并列 `C#`。章程禁止委托的，修改句要求先改章程或把本约效力绑在章程修订完成之后。
4. 已出质：质权自出质登记设立；未经质权人同意将表决或分红交给第三人，不得写成可对抗质权人。已查封／冻结：行权字段停止。
5. 国资／外资／上市公司：审批或信息披露未核则字段停止，不写场外可履行。
6. 不足：字段停止，列出待补材料，不补主体。

---

## 节点 3　标的、通知公司、交割式履行

1. 标的确定到公司名称、股权比例或股份数量、对应出资额。只有“有关股权”则标缺口。
2. 托管不产生股东变更登记。不得把“签字即视为过户完成”写成可放行。
3. 通知：书面通知目标公司董事会或指定联系人，附授权委托书；宜在名册备注“表决权已委托”，备注不是法定登记事项，未备注不得写成协议未生效。
4. 材料未提及质押、查封时，不得写成“无权利负担”，只能写 `依据不足`。

---

## 节点 4　程序与生效

把内部决议、授权书签收、质权人同意、国资批准、权益变动披露写成**义务和期限**，不写成已经完成。

| 文本写法 | 本任务动作 |
| --- | --- |
| “本合同签字即受托人可行使全部股东权利” | 拆成合同生效 vs 向公司提交授权书 vs 公司签收 vs 对第三人 |
| “无需通知公司” | 必须改；否则对抗公司字段停止 |
| “双方同意视为已披露／已获国资批准／已获质权人同意” | 红线；改为书面附件和先决条件 |
| 用户要求倒签授权日或补假决议 | 整体停止 |

不得把“双方同意视为已批准”写成可放行结构。

---

## 节点 5　格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

收购方重复使用的托管模板仍可能构成格式条款。审查单方不可撤销、放弃法定解除赔偿、最终解释权、管辖是否有显著提示。

违反法律、行政法规强制性规定不一律无效。委托行权安排主要受第一百一十八条和章程约束，不轻易写“未通知公司则整份协议无效”。规避准入、违法代持上市股票、恶意串通损害他人：只告知，不写假架构。禁止用已失效“效力性／管理性”口诀。

---

## 节点 6　违约、解除、争议解决

1. 越权投票、不按指示、擅自转委托、逾期不返还、逾期不支付托管费，必须分别有日违约金或固定金额，以及达到【待填】日的解除权。
2. 构成违约不等于当然解除。法定解除只点名催告或目的不能实现，不在本任务作出已解除结论。
3. 争议解决：已有仲裁条款，不得改成“应向某法院起诉”并假装已选定诉讼；或裁或诉、机构不明：改成单一机构或单一法院连结点；公司住所地可作为约定连结点，不得写成“托管依法专属管辖”。
4. 微信已读不写成已经送达，除非合同把该渠道定为送达。

---

## 节点 7　上市、跨境与组合结构

1. 涉外主体或境外付款：准据法不明则停止外国法结论；负面清单与安全审查未核验则准入字段停止。
2. 上市公司或挂牌公司：表决权委托可能构成拥有权益或一致行动。触及 5% 或实控人变化：字段停止，点名报告、公告和改正前不得行使表决权的监管后果，不整份代审权益变动报告书。
3. 过渡托管常与股权收购主合同或股权质押组合。本任务只写交叉违约和“质押不在本约设立”的边界，不代审转让本约或质押本约。
4. 有偿征集不特定多数股东表决权：上市场景红旗，不写成可履行买票。

---

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

对照已加载框架级文件和本方法硬闸，按六步逐段出句。框架中的过户、代持、信托清单：仅在文本确实出现时使用；主给付滑入代持或转让则按节点 1.2 转出。

| 步 | 本类型必须盯的点 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题名实（托管／表决权委托，避免写成代持或转让）；委托人是登记股东；鉴于不把过户或显名写成已完成 | 主体与鉴于修改句 |
| 交易条款 | 股权特定化；权利清单；全权或指示；积极／消极列表；分红账户；期限挂钩；通知公司；授权书三要素 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 越权／不作为／不返还的分别后果；任意解除的赔偿与违约金；转委托限制；行权报告 | 可执行后果句 |
| 尾部 | 授权签字；附件：授权委托书、行权指引、致公司通知、终止通知、主合同摘录、质权人同意 | 生效与附件修改句 |
| 语言 | 正说加反说；托管 ≠ 代持 ≠ 转让；授权书 ≠ 内部协议；合同生效 ≠ 公司必须接受投票；不得写“股权归受托人” | 替换空词的句子 |
| 常见问题 | 全权无边界、无返还、保证排除任意解除、阴阳授权、规避信披 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（名为代持、规避监管、受托人可处分股权、阴阳授权、保证解除当然无效）；
- `必须改`：可谈但签署前要落句（权利清单、指示规则、授权书、通知公司、返还、分红账户、任意解除成本）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级控制权或个人无限连带且用户拒绝升级：停止“可以签署”建议。

## 版本冲突

正文、授权委托书、主合同、章程、决议、聊天确认冲突时：

1. 并列 `D#` / `C#`，不选对用户有利的一版。
2. 修改句写明冲突项以哪一份为准，或删除冲突句。对公司的授权范围以提交给公司的授权书为准，不得调和成“两套都有效”。
3. 不得在意见里悄悄采用有利版本并称“合同已明确”。
