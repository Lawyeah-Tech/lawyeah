# 边界与路由

本技能只审查 **公司相关合同 / 股权托管协议**。主线是登记股东把特定股东权利的行使委托给受托人，股权归属和工商登记股东不变。不是隐名持股，不是存量买卖，也不是登记机构集中存管。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 实际出资人隐名、名义股东登记、投资权益归属、请求显名 | `股权代持合同·审查`（股权投资相关代持）或 `股权代持协议·审查`（公司相关代持） |
| 价款进原股东、办理股权变更登记、无委托行权结构 | `公司股权转让·审查` |
| 主文件是股东协议：投后治理、否决权、随售／拖售 | `公司股东协议·审查` |
| 主文件是已发行股权由公司或股东购回 | `股权回购协议·审查` |
| 主给付是设定质权、办理出质登记 | 转引擎重新定性；本任务只审托管与在先质权的冲突 |
| 商业银行／信托公司股权集中存管到登记机构 | 转引擎；不得用本类型委托行权闸硬套 |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、问开会日／交回授权书日／通知留痕 | 本套导航的履约步骤 |
| 越权表决、解除托管、控制权争夺已催告、立案、开庭或仲裁 | 公司争议领域；不填签前十节 |
| 名为托管、实为代持或规避准入／要约 | 留本任务只出红线；用户坚持改成可履行则整体停止 |
| 全权授权无事项／权限／期限，或无返还句 | 留本任务出必须改／红线；不写成已经可以开会 |
| 国资未审批或外资负面清单未核 | 字段停止；不写场外可履行 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

专业版未收录的 P1 场景不会作为本原子的安装对象。若用户拿这些文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。

本技能不得转去加载代持、转让或股东协议双文件完成本类型审查，也不得把解释三显名路径、优先购买三十日交割包或治理清单写成托管默认主路径。
