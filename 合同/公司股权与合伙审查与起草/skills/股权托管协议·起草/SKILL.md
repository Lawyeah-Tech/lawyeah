# 股权托管协议·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **公司相关合同 / 股权托管协议** 己方稿，出稿后用本类型硬闸自审。交付草稿、未决项、自审风险表和自审后修改句。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「审查股权托管协议（公司相关合同）」。`depends-on` 为空。不要求先跑导航。

主线是**登记股东把特定股东权利的行使委托给受托人，股权归属和工商登记股东不变**。不是隐名持股，不是存量买卖，也不是登记机构集中存管名册。

不交付：他类起草、待签文本签前审查、履约交底、争议文书、有效性或“不可撤销必然排除任意解除”保证、代持／转让／股东协议／回购整份代审。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **托管 ≠ 代持 ≠ 转让**：本约只移转表决、分红、提案、召集或知情等权利的**行使**。名册／登记股东改成受托人、实际出资人隐名 → `股权代持合同·审查` 或 `股权代持协议·审查`。价款换过户、注册资本因本约变动 → `公司股权转让·审查`。不得删掉隐名或过户条款后继续当托管审。
2. **表决权／分红权行使边界**：拆积极列表与消极列表；写明全权或指示；授权须载明事项、权限和期限，并向目标公司提交授权委托书。分红写收款账户、税负和未分配利润归属。禁止“全权处理一切股东事务”而无负面清单。处分股权、设定质押、同意合并分立默认留在委托人。
3. **返还与违约**：期限届满、主交易交割或解除时，交回授权书、书面通知公司停止承认受托人、返还代收分红和资料。越权投票、不按指示行权、拒不交回分别有可执行后果。任意解除按民法典第九百三十三条处理：可写不可撤销、有偿、挂钩主合同利益和高额违约金，**不得保证必然排除法定任意解除**。
4. **与代持 `股权代持合同·审查` 切开**：投资侧隐名／显名、实际出资人请求记载于名册并办理登记，走 `股权代持合同·审查`；公司相关代持本约走 `股权代持协议·审查`。禁止用托管包装违法代持上市公司股票。

## 工作边界

正触发：已有可读待签托管正文或可单独评改的托管／表决权委托专章，尚未签署，尚未成争；目标公司已依法设立；委托人是登记在册股东；核心给付是约定期限内由受托人行使特定股东权利，不办理股东变更登记。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 实际出资人隐名、名义股东登记、请求显名或投资权益归属 → `股权代持合同·审查`（股权投资相关）或 `股权代持协议·审查`（公司相关）；
- 价款进原股东、办理股权变更登记、无托管／委托行权结构 → `公司股权转让·审查`；
- 主文件是股东协议（投后治理、否决权、随售拖售）→ `公司股东协议·审查`；
- 主文件是已发行股权由公司或股东购回 → `股权回购协议·审查`；
- 主给付是设定股权质权、办理出质登记 → 转引擎重新定性，不按本类型出可履行质权结构；
- 商业银行、信托公司把股权集中存管到登记机构 → 转引擎，不套用本类型委托行权闸；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问开会日、交回授权书日、通知留痕 → 本套导航的履约步骤；
- 已成争（催告解除、越权表决之诉、控制权争夺立案、开庭、仲裁）→ **公司争议领域**，不填签前十节。

规避外资准入、要约收购、短线交易、股东承诺或违法代持上市股票：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；代表委托人／登记股东还是受托人／过渡期买方；目标公司是否已设立；正文、授权委托书、章程、名册、主交易版本；托管的是哪些权利；全权还是指示；期限是否挂钩交割；不可接受事项；法域与拟签时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的托管费、违约金、期限用 `【待填】`，不编造。

## 起草模式

本原子只承担本类型起草。待签评改转 `股权托管协议·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `股权托管协议·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 本约只移转表决、分红、提案、召集或知情等权利的行使；股权归属和工商登记股东不变。
- 拆积极列表与消极列表；写明全权或指示；授权须载明事项、权限和期限，并向目标公司提交授权委托书。
- 分红写收款账户、税负和未分配利润归属。处分股权、设定质押、同意合并分立默认留在委托人。
- 期限届满、主交易交割或解除时，交回授权书、书面通知公司停止承认受托人、返还代收分红和资料。越权投票、不按指示行权、拒不交回分别有可执行后果。
- 任意解除按民法典第九百三十三条处理：可写不可撤销、有偿、挂钩主合同利益和高额违约金，不得保证必然排除法定任意解除。

### 附件必附

- 授权委托书
- 章程与名册
- 挂钩交割时的主交易文本
- 已出质时的质押人书面同意

### 禁止出现

- “全权处理一切股东事务”而无负面清单
- 名册／登记股东改成受托人
- 保证不可撤销必然排除法定任意解除
- 用托管包装违法代持上市公司股票
- 规避外资准入、要约收购、短线交易或股东承诺的可履行结构

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录，禁止为对照打开代持显名路径、转让优先购买交割包或股东协议治理清单。`基本面.md` 中“为受托人利益则委托人不得任意解除”不得写成法条结论；改为：第九百三十三条仍可解除，商事委托可用不可撤销、有偿和主合同利益提高解除成本，稳定性不能保证。知识稿把股份过户写成托管默认结果的，**降级**：过户是转让，负触发。

必须有修改句。禁止只打红黄绿。每个风险回链文本位置。交付按 [输出合同](references/output-contract.md)。边界见 [路由](references/routing.md)。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、把违法代持或规避要约／准入改成可履行托管外壳、保证不可撤销必然有效或保证受托人必然能对抗公司投票。
- `字段停止`：未见授权事项／权限／期限；未见分红账户；未见通知公司安排；未见质押人同意而已出质；上市权益变动或实控人变更未核验；任意解除与主合同关系不明。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或文本已滑入代持／转让／股东协议／回购。

生存级控制权安排或个人无限连带且用户拒绝升级：停止“可以签署”建议。
