# 边界与路由

本技能只审查 **公司相关合同 / 债权收购合同** 的待签、公司并购／重组或公司间存量／不良债权处置语境下的债权收购文本。中文展示名是「审查债权收购合同（公司相关合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开邻类 method 对照完成本类型审查。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 债务人换人、免原债务人、须债权人同意、并存或免责的债务承担 | `债务转移三方协议·审查` |
| 第三人不加入债务，只按指示代为付款 | `代付款三方协议·审查` |
| 无并购／目标公司／公司收购外壳；普通商事单笔货款、借款返还或判决确定金钱债权让与 | `主给付是债权让与通知债务人为轴→` |
| 转让股权、股东资格、出资额 | `公司股权转让·审查` |
| 收购目标公司股权并以取得控制权为目的 | `股权收购合同（含控制权转移）·审查` |
| 一揽子资产足以构成业务线或营业 | `资产收购合同·审查` |
| 单项非核心资产，不按债权收购 | `非核心资产转让·审查` |
| 国有资产进场、评估挂牌协议转让为主轴 | `国有资产转让合同（协议转让）·审查`（P1；专业版未装则 `unavailable`） |
| 保理、有追索／无追索融资、将有应收账款管理或付款担保为主结构 | 引擎或保理专项；不得用本类型硬套融资条款 |
| 主体不变，只改期限、利率、本金的债务重组 | 引擎；不按债权收购放行 |
| 新债务人加入、与原债务人共同承担 | 引擎（债务加入）；不按本类型放行 |
| 主文件是一般保证／连带保证 | `主文件是保证或抵押借款→` 或 `或` |
| 主文件是抵押借款 | `主文件是抵押借款` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、只问催收、通知留痕、回款节点 | 本套导航的履约步骤 |
| 已成争：追索诉讼策略、催告索赔立案仲裁 | `已出现催告解除函索赔立案开庭仲裁` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

债权收购正文里夹带一小段代付款或后续以债抵股安排：专章交接对应原子或分条改写；收购让与条款可继续审。用户坚持本技能把债务转移、普通债权让与、保理或股权收购整案改完：`目标停止`。

专业版未收录的 P1 邻接场景不会安装对应原子。若用户拿这些文本来找专业版：输出 `unavailable`，提示，不得用本类型硬套。
