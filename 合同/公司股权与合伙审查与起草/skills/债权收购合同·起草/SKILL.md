# 债权收购合同·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》第七十九条至第八十三条及其解释、已失效《物权法》《担保法》及其解释、法释〔2001〕12 号报纸公告通知规则当作现行依据。不得把禁止转让特约一律写成收购协议当然无效，也不得写成普通贸易债权必须持有金融资产管理公司牌照。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **公司相关合同 / 债权收购合同** 己方稿，出稿后用本类型硬闸自审。交付草稿、未决项、自审风险表和自审后修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查债权收购合同（公司相关合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约催收交底、争议追索文书、有效性或必然收款保证、普通商事单笔债权让与整案、债务转移三方整案、整份保证／抵押主文件审查。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。禁止打开或复制 `主给付是债权让与通知债务人为轴→`、`债务转移三方协议·审查` 的 method。

1. **通知债务人**：债权人转让债权，未通知债务人的，该转让对债务人不发生效力。公司收购语境下债务人通常是目标公司。通知约束的是目标公司向谁履行，不是出让人与收购方之间协议是否成立。修改句把书面通知、送达回证写成收购价款先决。禁止“签字即视为已通知”“未通知则本协议无效”“先全款后通知”。
2. **从权利随同**：收购方取得与债权有关的从权利，专属于出让人自身的除外；未办理转移登记或未转移占有，不影响取得。抵押权随主债权一并转让，另有约定除外。未通知保证人的，转让对保证人不发生效力；保证合同禁止转让且未经保证人书面同意的，保证人对受让人不再承担保证责任。禁止只买主债权而丢掉担保，禁止写成“未登记则抵押权未转移”。
3. **禁止转让特约**：必须核验原债权合同和担保合同。性质不得转、法律禁止转、约定不得转分别处理。当事人约定非金钱债权不得转让的，不得对抗善意第三人；约定金钱债权不得转让的，不得对抗第三人。不得把特约写成收购协议当然无效，也不得隐瞒特约放行。
4. **不良资产资质**：先区分普通公司经营性债权与金融机构不良／金融企业资产包。前者不因标题含“收购”而要求金融资产管理公司资质。后者受让主体未核验则字段停止；超出《金融资产管理公司条例》确定范围或额度的收购须按该条例处理。禁止无资质场外买断银行不良包，禁止名为收购实为放贷。
5. **与债务转移切开**：债务人将债务转移给第三人，应当经债权人同意 → `债务转移三方协议·审查`。本类型是债权人变更为收购方，目标公司仍是债务人。禁止把第五百五十一条的同意写成收购生效条件，禁止用本技能把债务转移改完。无并购／目标公司／公司收购外壳的普通商事让与 → `主给付是债权让与通知债务人为轴→`。

## 工作边界

正触发：已有可读待签债权收购正文，尚未签署，尚未成争；核心给付是收购方或其 SPV／关联方以对价取得对目标公司（或目标公司群）的已成立债权及从权利，服务于公司并购、重组、以债抵股铺垫或公司间存量／不良债权处置；用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 债务人换人、免原债务人、须债权人同意 → `债务转移三方协议·审查`；
- 第三人不加入债务，只按指示付款 → `代付款三方协议·审查`；
- 无公司收购／并购／目标公司外壳的普通商事单笔债权让与 → `主给付是债权让与通知债务人为轴→`；
- 买股权、股东资格 → `公司股权转让·审查`；以取得控制权为目的收购目标公司股权 → `股权收购合同（含控制权转移）·审查`；
- 一揽子营业资产或单项非核心资产，不按债权收购 → `资产收购合同·审查` 或 `非核心资产转让·审查`；
- 国有资产进场、评估挂牌协议转让为主轴 → `国有资产转让合同（协议转让）·审查`（专业版未装则 `unavailable`）；
- 保理（融资 + 应收账款管理／催收／付款担保）为主结构 → 引擎或保理专项；不得删掉融资条款后继续当本类型审；
- 主文件是保证或抵押借款 → `主文件是保证或抵押借款→`／`或`／`主文件是抵押借款`；本约若另有收购正文，担保只作从权利红旗；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问催收、通知留痕、回款节点 → 本套导航的履约步骤；
- 已催告、追索起诉策略、立案、开庭、仲裁 → `已出现催告解除函索赔立案开庭仲裁` 或对应专项领域。

虚构基础交易构造债权再收购、通谋逃债或洗钱、场外规避国资进场或金融不良资质、名为收购实为放贷：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；出让或收购单一立场；目标公司是否列为债务人；收购主体是并购主体还是 SPV；全文及债权清单、基础合同、担保合同、通知书版本；是否金融不良或银行资产包；原合同有无禁止转让；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 起草模式

本原子只承担本类型起草。待签评改转 `债权收购合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `债权收购合同·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 书面通知债务人、送达回证写成收购价款先决。通知约束的是目标公司向谁履行，不是出让人与收购方之间协议是否成立。
- 收购方取得与债权有关的从权利，专属于出让人自身的除外。未办理转移登记或未转移占有，不影响取得。未通知保证人的，转让对保证人不发生效力；保证合同禁止转让且未经保证人书面同意的，保证人对受让人不再承担保证责任。
- 必须核验原债权合同和担保合同的禁止转让特约。约定非金钱债权不得转让的，不得对抗善意第三人；约定金钱债权不得转让的，不得对抗第三人。
- 先区分普通公司经营性债权与金融机构不良／金融企业资产包。前者不因标题含“收购”而要求金融资产管理公司资质。
- 本类型是债权人变更为收购方，目标公司仍是债务人。不得把民法典第五百五十一条的债权人同意写成收购生效条件。

### 附件必附

- 债权清单
- 基础合同
- 担保合同
- 通知书
- 内部决议；国资进场或金融不良受让资格文件（如适用）

### 禁止出现

- “签字即视为已通知”“未通知则本协议无效”“先全款后通知”
- “未登记则抵押权未转移”
- 把禁止转让特约写成收购协议当然无效
- 把第五百五十一条债权人同意写成收购生效条件
- 无资质场外买断银行不良包；名为收购实为放贷
- 虚构基础交易构造债权再收购、通谋逃债或洗钱

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 本任务起草模式；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有债权收购文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。债务转移、普通债权让与、代付款、股权／营业收购、保理负触发。

### 2. 五项硬闸

通知债务人；从权利随同；禁止转让特约；不良资产资质；与 `债务转移三方协议·审查` 切开。每闸出修改句。

### 3. 主体、并购结构与授权

出让人须是债权人。收购方、目标公司、保证人、抵押人分列。内部决议、国资进场未附：字段停止。

### 4. 标的特定、抗辩抵销与价款挂钩

债权清单可核验。目标公司对出让人的抗辩、抵销不得用条款抹掉。价款与通知回证、担保变更登记挂钩。

### 5. 格式条款与强制规范

无核验引文则法律结论字段停止。违法结构停笔。

### 6. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签通知、保证有效或必然收款、把债务转移改成通知即可免原债务人、虚构债权或通谋逃债、无资质场外买断银行不良包、把人身性或法律禁止转让债权改成可履行收款。
- `字段停止`：法域、动态规则、禁止转让特约原文、通知回证、担保登记、金融不良受让资格、国资是否重大资产未核验。
- `目标停止`：主目标已变为从零起草、履约催收、争议追索，或文本已滑入债务转移／普通让与／代付款／保理。

生存级价款或个人无限回购／连带且用户拒绝升级：停止“可以签署”建议。
