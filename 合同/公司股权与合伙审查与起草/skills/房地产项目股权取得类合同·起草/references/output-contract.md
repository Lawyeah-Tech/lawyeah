# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、必然能开发或过户、对方接受或必然可执行；编造未给出的价格、比例、证号、欠款余额；把已失效《合同法》及其解释写入结论；把“买股权等于土地已过户”或“走股权即可合法绕过转让条件”放行；把土地使用权转让或一方出地联建写成同一套方法。

## 1. 触发、单方立场与成果状态

立场（投资人／受让人、转让方／老股东、项目公司鉴证方）、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明目标公司是否绑定特定地块或项目，以及核心给付是取得控制权变相拿地／拿项目，还是直接土地过户、一方出地联建或无项目财务投资。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、1993 年公司法旧编号、1994 年房管法或预售办法未修正文本时记噪声，不得写入 `L#`。城市房地产管理法第 38／39 条、民法典第 153／502／807 条、通则解释第 16 条、公司法第 84／86 条、企业国有资产法第 54 条无 `verified-result` 时，对应法律结论字段停止。

## 3. 类型与加载路径

父级 `股权投资相关合同`，子级 `房地产项目股权取得类合同`。定性理由必须同时满足：核心给付为通过股权或增资取得项目公司控制权；商业目的为变相拿地或拿项目；土地使用权仍登记在目标公司名下，文本不以不动产变更登记为履行轴。

易混切开必须写明结果：直接土地使用权转让 → `转让人是土地使用权人，对价是地价款，履行轴是不动产变更登记或土地二级市场网签→`；一方出地联建 → `一方出地一方出钱，共同报建共担开发风险，不发生控股权转移→`；共担风险不转控制权 → `共同出资报建共担风险，不转移控股权的合作开发→`；出资合同 → `出资合同·审查`；无项目普通转股 → `PE股权转让·审查`；代持 → `股权代持合同·审查`；意向书 → `投资意向书·审查`；股东协议 → `PE股东协议·审查`；不以拿项目为目的的增资 → `增资协议·审查`。

加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读其他类型。规避土地转让限制、挂靠、名股实债写停笔告知，不填可履行结构。

## 4. 主体、授权、资质与文本版本

主体表：转让人（老股东）、受让人／投资人、项目公司、指定共管或收款账户名。开发资质、贷款人、施工总包、已网签购房人单列是否被提及。国资转让方单列评估进场是否被提及，不得写成已经完成进场。多股东时单列优先购买权书面通知或放弃是否被提及。

版本表：正文、土地证或出让合同、债务清单、尽调备忘、共管协议、开发贷控制权变更页、聊天确认。冲突并列，不选对用户有利的一版。口头“地是干净的”“银行没意见”不得写成已核验。

## 5. 变相拿地／拿项目给付闭环

分列并回链文本位置：

- 股权标的：比例、对应出资、实缴、质押或冻结。
- 控制权：董事会席位、印鉴、银行账户、开发报建权是否同步移交。
- 项目绑定：宗地证号、用途、容积率、出让金、在建工程、证照。
- 鉴于与目的：是否写明通过取得控制权开发或接盘该地块／项目。
- 土地权利负担：抵押、查封、闲置、开竣工违约、规划调整。
- 项目负债：已披露债务是否进附件；工程款、农民工工资专户、开发贷加速到期、预售监管（如已进入销售）。
- 对价拆解：股权价款、股东借款、后续出资；是否存在低股权价高股东借款。
- 付款与交割：是否绑地块或项目节点；工商变更、证照印章、现场是否分列；共管与保证金。
- 重大不利变化：土地收回、闲置认定、规划调整、贷款加速到期时的解除和返还。

缺口标 `G#`，不补商业数字。批准、登记、内部决议、贷款人同意写成条件或双方义务期限，不写成已经完成。

## 6. 格式条款、强制规范与本类型效力红旗

重复使用的并购模板按格式条款审查提示说明。单方认定项目无瑕疵、送达拟制、无限责任未显著提示的，标必须改。

强制规范与效力红旗只在核验后落法律结论：无资质开发；国资未评估进场；以股权形式转让集体土地私下开发；挪用预售监管资金支付股权价款；项目公司无条件回购违反资本维持。不得用已失效“效力性／管理性”口诀代替合同编通则解释第 16 条。不得把房管法第三十九条直接写成“股权合同必然无效”或“走股权必然有效”。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔／转出口径。禁止输出无修改句的色块表。

本类型至少检查：是否误入土地使用权转让或一方出地联建；股权与地块／项目是否双锁定；控制权是否落地；土地权利负担是否写成交割条件；付款是否绑节点；是否出现“净地交付”“过户即土地转让完成”“固定收益不担风险”“走股权即可绕开转让条件”。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`，不编造。禁止只给原则、不给句子。框架与硬闸冲突时按硬闸出句。

建议句必须覆盖本类型硬闸：标题或鉴于点名通过取得控制权拿地／拿项目；股权与地块／项目双锁定；控制权与印鉴同步；交割前不得新设抵押或擅自处分项目；土地权利负担与未披露债务进附件；付款绑节点并设共管与保证金；删除“净地交付”“过户即视为土地使用权转让完成”。

## 9. 谈判与签署提醒

谈判顺序：先红线（规避土地转让限制、签署即付清、倒签、保证有效、名股实债保底、无负担安排），再必须改（项目绑定、控制权落地、对价拆解、节点付款、贷款人同意、原股东离场、税费补偿），最后可优化。

签署提醒：转让人、受让人公章加法定代表人或授权人；项目公司如作鉴证方须盖章；自然人股东配偶同意是否需另纸视事实而定，不得写成已经同意；日期真实；附件含土地证或登记查询、出让合同、债务清单、优先购买权放弃、决议、共管协议、证照移交清单。不指导倒签或补假投资进度。

受让人立场可建议：地块或项目节点未成就不放尾款；交割前共管印章和土地证；保证金覆盖交割前债务、闲置和税务穿透；贷款人未同意则中止或解除。转让人立场必须提示：不正当隐瞒抵押查封、闲置或开发贷加速到期可能导致解除和赔偿争点；不得把“股权路径当然免税”写进文本。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书、效力保证或税务筹划方案。
