# 公司合并合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构，不证明本约条款已被接受。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释（含第九十条）、2004／2018 年《公司法》合并旧程序（报纸公告三次、九十日、不清偿不得合并、股份公司须省级政府批准）、1993 年同条号旧义、2008 年经营者集中申报门槛数字当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **公司相关合同 / 公司合并合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。`depends-on` 为空。不要求先跑导航。

不交付：他类审查、从零起草、履约交底、争议文书、有效性或必然获准登记／经营者集中批准保证。

## 工作边界

正触发：已有可读待签文本要评改，；尚未签署，尚未成争；核心给付是两个以上公司之间的**吸收合并或新设合并**——一方或各方解散，存续或新设公司概括承继债权债务、合同、资质和职工劳动关系。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 买目标公司股权、目标公司继续存续、交割包是名册／印章／董事会改组 → `股权收购合同（含控制权转移）·审查`；
- 一个公司将其财产分割、存续或新设多个公司，债务按内部方案切割或法定连带 → `公司分立合同·审查`；
- 价款进原股东、存量股权让与、注册资本不变且无解散 → `公司股权转让·审查`；
- 买特定资产或营业、原主体不因本协议解散 → `资产收购合同·审查` 或 `非核心资产转让·审查`；
- 主文件是股东协议治理、投资人否决权或清算事件／回购 → `公司股东协议·审查` 或 `出资合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `公司合并合同·起草`；
- 已签只问债权人公告日、换照日、税务注销日 → 本套导航的履约步骤；
- 已成争（债权人起诉提前清偿、决议效力之诉、职工集体争议、催告解除索赔）→ **公司或劳动争议领域**，不填签前十节。

用内部债务互免对抗债权人、倒签公告日压缩债权人期间、把合并改成假股权收购以规避法定程序：只出告知，不改写成可履行规避结构。

## 建立审查坐标

确认：使用者与授权；代表存续公司、被吸收方还是新设合并的哪一方；吸收还是新设；正文、资产负债表及财产清单、决议、职工安置方案、债权人清单版本；不可接受事项；法域与拟签时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的换股比例、对价、职工人数、营业额用 `【待填】`，不编造。

## 本类型硬闸

审查过程必须逐项点名，每闸必须有修改句，不得用股权名册／优先购买、分立连带切割或出资认缴清单代替：

1. **吸收／新设必须写死，三日期分开，全部债权债务概括承继**：2023 年《公司法》第二百一十八条区分吸收合并（被吸收方解散、一方存续）与新设合并（各方解散、设立新公司）。合并基准日、协议生效日、交割日（合并生效日）必须三分。第二百二十一条、民法典第六十七条：债权债务由存续或新设公司承继，不得写成“或有负债由原股东自行消化即可对抗债权人”。
2. **债权人通知与公告**：第二百二十条——合并各方签订合并协议并编制资产负债表及财产清单；自作出合并决议之日起十日内通知债权人，三十日内在报纸上**或者**国家企业信用信息公示系统公告；债权人三十日／四十五日内可要求清偿或提供担保。禁止套用 2004 年“公告三次、九十日、不清偿不得合并”。
3. **股东会特别决议（简化合并为例外）与异议股东**：有限公司须经代表三分之二以上表决权的股东通过（第六十六条）；股份公司须经出席会议股东所持表决权三分之二以上通过（第一百一十六条）。董事会只制订方案（第六十七条），不得写成已经批准。第二百一十九条的百分之九十子公司合并或价款不超过净资产百分之十，是例外且须董事会决议并通知其他股东。股份公司异议股东收购股份见第一百六十二条第一款第四项。
4. **职工安置是劳动合同承继，不是一律解除重签**：《劳动合同法》第三十四条——原劳动合同继续有效，由承继单位继续履行。修改句写全体职工、工龄／补偿年限连续计算口径、待遇总体不降低的过渡安排。裁员必须另走协商解除或经济性裁员程序，不得把合并本身写成全体终止条件。
5. **与分立 `公司分立合同·审查`、股权收购 `股权收购合同（含控制权转移）·审查` 切开**：目标公司存续、买股权换价款 → 负触发股权收购；一个公司拆成两个以上、分立前债务连带或内部切割 → 负触发分立。不得删掉解散或承继条款后硬套本技能。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验 2023 年《公司法》第二百一十八条至第二百二十一条、第二百一十九条、第六十六条、第一百一十六条、第五十九条、第六十七条、第一百六十二条，以及《劳动合同法》第三十四条、《民法典》第六十七条；经营者集中触及申报时核 2022 年《反垄断法》和 2024 年申报标准。`search_practiced` 补审查反例；`search_template` 只借修改句结构。不虚构案件系统。

`search_law` 对法律结论为 required 级节点：不可用时不拒绝执行，只停止法律结论字段。返回 1993／2004／2018 年《公司法》同条号、已失效《合同法》或其解释、2004 年“公告三次／九十日／不得合并”、2008 年申报门槛数字时记为噪声，不得写入 `L#`。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签决议或公告日、用内部互免对抗债权人、达到申报标准仍先交割再申报、把合并改成假股权收购以规避债权人或职工程序、保证必然获准登记或经营者集中批准。
- `字段停止`：合并方式、决议文本、债权人清单、职工安置方案、地方国资或集中申报规则未核验；关键换股或对价缺失。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或文本已滑入股权收购／分立／资产收购。

生存级或有负债或大规模裁员且用户拒绝升级：停止“可以签署”建议。
