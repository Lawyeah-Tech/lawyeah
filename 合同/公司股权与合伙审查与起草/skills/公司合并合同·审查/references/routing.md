# 边界与路由

本技能只审查 **公司相关合同 / 公司合并合同**。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 买目标公司股权或控制权；目标公司继续存续；交割包为名册、印章、董事会改组 | `股权收购合同（含控制权转移）·审查` |
| 一个公司财产分割，存续或新设两个以上公司；分立前债务连带或内部切割 | `公司分立合同·审查` |
| 价款进原股东，存量股权让与，无解散 | `公司股权转让·审查` |
| 买特定资产或营业，原主体不解散 | `资产收购合同·审查` 或 `非核心资产转让·审查` |
| 成立后的股东协议、否决权、清算事件、对赌回购 | `公司股东协议·审查` 或 `出资合同·审查` |
| 拟设有限公司出资、价款进公司 | `出资合同（有限责任公司）·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、公告或换照履约节点 | 本套导航的履约步骤 |
| 合并登记完成或债权人／职工／决议效力已成争 | 公司或劳动争议领域；不填签前十节 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

专业版未收录的场景不会作为本原子的实体审查对象。若用户拿股权收购或分立主文件来找本技能：输出负触发路由，不得用本类型硬套。

本技能不得转去加载股权收购、公司分立或有限出资双文件完成本类型审查。
