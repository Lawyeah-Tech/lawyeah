# 边界与路由

本技能只审查 **公司相关合同 / 代付款三方协议**。主线：第三人不加入、不取代原债务人，只按约定向债权人付款；收妥前原债务仍在。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 债务人换人、签署即免原债务人、须债权人同意 | `债务转移三方协议·审查` |
| 第三人加入并与债务人连带承担，或向债权人作出独立承担承诺为主结构 | 引擎或债务加入专项；不得删掉连带句后当本类型审 |
| 债权人退出、第三人取得债权 | `主给付是债权让与通知债务人为轴→` |
| 保理、有追索／无追索融资、将有应收账款管理或付款担保为主结构 | 引擎或保理专项 |
| 买的是股权，用户要审股权主文件 | `公司股权转让·审查`；代付附件可留本任务 |
| 买特定资产、不按代付 | `非核心资产转让·审查` |
| 主文件是一般保证／连带保证 | `主文件是保证或抵押借款→` 或 `或` |
| 主文件是抵押借款 | `主文件是抵押借款` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、付款核对、注销留痕 | 本套导航的履约步骤 |
| 已成争：催告索赔立案仲裁、追索策略 | 合同争议领域；不填签前十节 |
| 虚构原债、循环走账、掩饰资金来源 | 停笔告知；不改写成可履行过账 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

专业版未收录本 P1 原子。若用户拿本类型文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。

本技能不得转去加载债务转移、债权转让或保证双文件完成本类型审查。
