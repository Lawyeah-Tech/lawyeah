# 审查方法（锁定 公司相关合同 / 代付款三方协议）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型，禁止打开债务转移、债权转让或保证双文件“对照一下”。

本文件是**第三人不加入、不取代原债务人，只按约定向债权人付款**的签前判断节点，不是栏目说明书，也不是免责债务承担、债务加入或债权让与审查清单。禁止把“签署即免原债务人”“代付方成为新债务人”或“债权人退出、代付方取得债权”写入本类型默认结论。

每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、签字即债消灭、必然追回、对方必然接受或唯一必得金额。

`search_law` 返回已失效《合同法》第六十五条、第八十四条及其解释、担保法解释、物权法或涉外经济合同法时记为噪声，不得写入 `L#`。返回《合同法》第六十五条而无第五百二十三条、第五百二十四条分层时，改走民法典。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突。

示范文本只参考结构。收购附件或中介填充稿不证明本约条款已被接受；符合格式条款定义的，仍按格式条款审查。

### 双文件使用（标题与文件名不完全对应时不拒跑）

同目录两份知识文件按标题语义使用，不回改正文，不因文件名拒跑：

- 含“首部 / 交易条款 / 配套 / 尾部 / 语言”的当框架级条款清单，供节点 8 出句；
- 宏观的类型切开、清偿时点、追偿路径、洗钱停笔由本方法节点承担。
- `基本面.md` 若正文是动产买卖、验收、风险转移、所有权保留或其他与代付明显无关的内容：**降级**。不按买卖出句，不改去加载买卖双文件，记 `G#`。可吸收的仅限与本类型重合的抽象项：主体适格、内部决议、国资程序、恶意串通／虚假意思表示、阴阳合同。
- 框架把代付方写成“受让方”、把债务人写成“转让方／目标公司”：按**角色语义**读（代付方／债务人），禁止按债权让与理解。框架把代付默认写成股东借款：作为股权收购场景的约定路径，不是一切代付的法定效果。
- 文件不可用（空、代码块、与本类型明显无关）：记 `G#`，用本方法节点继续，不得编造到账或追偿已完成。

## 节点 1　类型识别与负触发

### 1.1 本类型正像

同时满足才继续：

- 存在已成立的原债务（货款、借款、服务费等），债权人与债务人主体可识别；
- 核心给付是**代付方向债权人支付约定款项**，不是新设一笔独立债务让代付方成为主债务人；
- 在债权人足额收妥前，原债务人仍是债务人；代付方不因签署当然成为新债务人或连带债务人；
- 交易不是以债务人换人、债权让与或保理融资为主结构。

标题写成“代付款协议”“三方清偿协议”只是线索。名实不符按核心给付归类，标题冲突写入 `C#`。框架建议标题不要写成债务转移或债权转让——标题用错本身要出修改句，但不单独决定定性。

### 1.2 必须切开（禁止两套知识）

| 信号 | 归入 | 本技能动作 |
| --- | --- | --- |
| 原债务人退出，新债务人加入，须债权人同意；签署即免责 | 债务转移三方协议 | **负触发** → `债务转移三方协议·审查`。不得当代付审 |
| 第三人向债权人表示愿意承担，或约定与债务人连带 | 债务加入 | **负触发** → 引擎或专项。不得删掉连带句后继续当本类型审 |
| 原债权人退出，第三人取得对债务人的债权 | 债权转让 | **负触发** → `主给付是债权让与通知债务人为轴→` |
| 保理人提供融资、应收账款管理或催收、付款担保 | 保理 | **负触发** → 引擎或专项 |
| 权利义务一并转让、合同主体概括承受 | 概括转移 | 负触发 → 引擎。点名须对方同意 |
| 买股权、注册资本不变，用户要审股权主文件 | 股权转让 | 主文件 → `公司股权转让·审查`；代付附件可留本任务 |
| 主文是保证或抵押借款 | 保证／抵押主文件 | 负触发 → `主文件是保证或抵押借款→`／`或`／`主文件是抵押借款`；本约若另有代付正文，担保只作注销红旗 |
| 虚构原债、循环走账、个人卡过账掩饰来源 | 违法结构 | 停笔，不改写成可履行过账 |

债务转移、债务加入、债权转让误入是硬闸：一旦核心给付滑入上述结构，立即停笔转出。后半段才发现的，回到本表，不“顺便改完”。

### 1.3 加载协议

只打开本目录 `基本面.md` 与 `框架.md`。禁止读 `types/` 或其他场景原子目录。

### 1.4 违法结构停笔（本类型）

出现下列任一结构，只出告知，不改写成可履行文本：

- 虚构基础交易或虚设债权债务，利用本协议过账、循环资金或掩饰资金来源、性质（反洗钱法第二条、第十条；洗钱刑案解释第五条第三项）；
- 以虚假意思表示掩盖另一交易（146），或恶意串通损害他人（154）；
- 通谋逃债、对抗查封冻结或向债权人出具假结清；
- 倒签到账日或补假银行回单，以制造“已经清偿”。

用户坚持“改到能过账／能假装已结清／能让原债务人没付款就脱责”：整体停止。合规改道（披露真实原因、真实账户、真实原债后再签）只点名，不在本任务起草规避方案。

## 硬闸 A　代付≠债务转移

本闸改变能否留在本类型。材料未写清“谁在收妥前仍是债务人”的，不得写成“已经不是转移”，只能写 `依据不足`。

1. **三条结构，不得混写**  
   - **代付（523）**：当事人约定由第三人向债权人履行。第三人不履行或履行不符合约定的，**债务人**向债权人承担违约责任。代付方对债权人一般不因本协议成为主债务人。  
   - **免责转移（551）**：债务全部或部分转给第三人，须债权人同意；催告后未表示视为不同意。原债务人退出。  
   - **加入（552）**：第三人加入后，债权人可在其愿意承担的范围内请求其与债务人承担连带债务。

2. **禁止写法**  
   - “自本协议签署之日起，原债务人不再承担任何责任，债务转由代付方承担”；  
   - “代付方成为新的唯一债务人”；  
   - “债权人同意债务转移”却把标题留作代付款，企图两头解释。

3. **修改句（仍属代付、仅用语滑入转移时）**  
   `定位｜原文“自本协议签署之日起甲方不再承担原债务，改由丙方承担”｜建议改为：丙方仅按本协议向乙方指定账户支付代付款项人民币【待填】元。在乙方足额收妥该款项前，原债务仍由甲方承担；丙方不因签署本协议成为新债务人或连带债务人。丙方未按约支付的，甲方仍应就原债务向乙方承担违约责任。本协议不构成民法典第五百五十一条的债务转移，也不构成第五百五十二条的债务加入。｜理由 L# 523｜可退让：就丙方未付部分，乙方有权同时催告甲方，但不把丙方写成主债务人｜红线：签署即免甲方，或把丙方写成唯一新债务人`

4. **已滑入转移或加入**  
   核心给付就是换债务人、免责或连带承担：负触发，走节点 1.2。不得用上款修改句把转移“改回”代付来迁就想脱责的一方。

5. **最强反方**  
   债权人可能主张：第三人既已在协议上承诺付款，就是加入或转移。签前必须用正说加反说把 523 结构钉死；否则定性 `依据不足`，字段停止。

核验失败：转移／代付的法律定性字段停止，事实摘录和修改句草稿继续。

## 硬闸 B　清偿效果

签署、盖章、出具收据草稿，都不等于原债务消灭。

1. **终止事由**  
   第 557 条：债务已经履行、抵销、提存、债权人免除、混同或约定的其他终止情形。代付场景默认走**已经履行**：以债权人指定账户**足额收妥**对应款项为准。免除必须由债权人单独、明确作出，不得用“双方同意视为已付”代替。

2. **部分代付**  
   只消灭对应部分。剩余本金、利息、违约金由谁承担必须写清。禁止“支付任意一笔即全部结清”，除非债权人明示免除余额。

3. **禁止写法**  
   - “本协议生效后原债务即告结清，无须实际到账”；  
   - “出具本协议视为债权人已收款”；  
   - 未列指定账户却写“付至甲方任何账户均有效”。

4. **必须落到句上的要素**  
   唯一收款账户（户名与债权人一致）、支付时点、币种、是否含税、到账回证、结清或部分结清证明出具期限、已收妥部分不得再向债务人主张。  
   修改句：  
   `定位｜原文“本协议签字后原债务即告结清”｜建议改为：乙方指定唯一收款账户：户名【待填】，账号【待填】，开户行【待填】。丙方应于本协议生效后【待填】个工作日内将人民币【待填】元一次付至该账户。该账户足额收妥之日，原债务中对应的本金、利息、违约金【待填】部分因已经履行而终止；乙方应于收妥后【待填】个工作日内向甲方和丙方出具《结清证明》。签署本协议本身不导致原债务消灭。未收妥前，乙方仍可依原债务向甲方主张。｜理由 L# 557｜可退让：先付【待填】%，余款到账后再出全部结清证明｜红线：签字即结清，或未到账即要求出具结清证明`

5. **担保配套（框架核心，不得漏）**  
   对应主债权消灭，担保物权消灭（393）；债权债务终止时从权利原则上同时消灭（559）。这不等于登记已清。修改句必须锁定：收妥后【待填】个工作日内，债权人签署并提交注销抵押／质押登记全套文件、返还权证和保证合同原件；逾期按日支付【待填】违约金，并赔偿因此不能解押、不能交割的损失。  
   **禁止**只写“担保合同自动终止”而不写注销动作。不动产按登记细则第七十条申请注销；动产和权利担保按统一登记办法第十六条办理注销。本任务不整份代审保证／抵押主文件。

6. **最强反方**  
   债权人可能主张：协议已约定终止，即使未到账也不得再要。这正是本闸要挡住的。未收妥而出具结清，对代付方和债务人都是红线。

## 硬闸 C　追偿

代付方付完钱以后向谁、凭什么要回来，必须在签署前锁定**一条**路径。

1. **可选路径（择一，写入正文）**  
   - **约定返还／代垫**：债务人确认代付款构成对其负债，于【待填】日前偿还，利率或无息写明。  
   - **股东借款（股权收购常见）**：代付款视为代付方对目标公司（债务人）的股东借款，目标公司入账为对代付方的负债。这是框架场景，不是一切代付的默认。  
   - **524 法定移转**：仅当债务人不履行、代付方对履行有合法利益（合同编通则解释第 30 条：担保人、出资人／设立人等），且债权人已接受履行。此时债权在已履行范围内转让给第三人，**但是债务人和第三人另有约定的除外**。  
   - **赠与或视为对价**：明确放弃追偿，或计入股权收购价款。放弃必须点名，不得事后再主张 524。

2. **禁止双重主张**  
   同一笔款项不得同时写成“法定取得对债务人的债权”和“股东借款／代垫”。另有约定的，524 第二款让位给约定。  
   修改句（股权收购、约定股东借款）：  
   `定位｜原文“代付款自动构成债权转让，同时视为股东借款”｜建议改为：丙方足额支付后，该款项在丙方与甲方之间仅视为丙方向甲方提供的股东借款人民币【待填】元，甲方应于收妥结清证明后【待填】日内入账为对丙方的负债。双方确认不适用民法典第五百二十四条第二款的法定债权移转，丙方不得就同一笔款项再向甲方主张受让原债权。借款利率【待填／无息】，还款日【待填】。｜理由 L# 524｜可退让：改走单一法定移转，删除股东借款｜红线：两条路径并行，或追偿完全沉默却要求保证能追回`

3. **524 不是自动档**  
   商事主体之间单纯“帮忙付款”、看不出合法利益的，先走 523＋约定追偿，不得把 524 写成已经发生。出资人代目标公司清偿，可讨论解释第 30 条第五项，仍须事实支持，不得在意见里直接认定“依法已移转”。

4. **985 第三项**  
   明知无给付义务而清偿的，不得依不当得利请求返还。用户承认“就是帮忙、不要回来”却又要可追偿条款：点明冲突，要求改成赠与或改成有因代垫。用户要隐瞒无义务事实、做成可追偿：整体停止。

5. **加入后的追偿不是本类型主路径**  
   解释第 51 条适用于债务加入。文本若已是加入，负触发，不在本任务展开 51 条放行结构。

6. **最强反方**  
   债务人会说：你自愿付的，985 排除返还；或：你已经按 524 拿走债权，不能再要股东借款。签前用单一路径堵住这两面。

核验失败：追偿的法律定性字段停止，仍须出“择一填写”的修改句草稿。

## 硬闸 D　与 `债务转移三方协议·审查` 切开

本闸是路由闸。与硬闸 A 的区别：A 处理**仍属代付**的错误用语；D 处理**已经不是代付**的文本，禁止本技能代做转移审查。

1. **切到 `债务转移三方协议·审查` 的信号**  
   原债务人退出；新债务人承接原合同义务；债权人的同意被写成转移生效要件；担保人被要求为新债务人继续担保。  
   动作：`触发判定：负触发，未启动本任务`，路由 `债务转移三方协议·审查`。只交接口径：谁退出、谁加入、债权人是否签字。不填本类型十节，不出“免责转移”修改句。

2. **切到债权转让**  
   债权人把对债务人的债权卖给代付方，代付方向债权人付的是转让价款而非“代债务人清偿”：`主给付是债权让与通知债务人为轴→`。

3. **修改句（仅用于标题或鉴于写错、正文仍是代付）**  
   `定位｜原文标题“债务转移三方协议”或鉴于“甲方将债务转让给丙方”｜建议改为：标题改为“代付款三方协议”。鉴于改为：乙方与甲方之间存在原债务人民币【待填】元（合同【编号】）。丙方同意代甲方将该款项付至乙方指定账户。三方确认本协议不是债务转移，也不是债权转让。｜理由 I# 切开｜可退让：无｜红线：正文同时写免责转移仍要本技能审完`

4. **最强反方**  
   “反正三方都签字了，审哪个原子都行。” 551 与 523 的违约主体、追偿和担保命运不同，硬套会写错修改句。

---

## 硬闸 E　禁止洗钱／走账放行

1. **识别**  
   原债务无合同、无发票、无对账单，或各方承认“做个通道”“走一圈”“帮忙过账”；付款人、收款人、原因循环对倒；金额整数对倒；要求付到法定代表人／员工／无关个人账户且说不清原因；阴阳金额。

2. **动作**  
   只出告知：该结构可能涉及虚假意思表示、恶意串通、虚设债权债务转移资金，不得改写成可履行过账文本。风险表只保留识别依据和转出／停止。不写项目化资金路径、假收据、假结清、可对抗银行问询的话术。

3. **修改句（停笔口径，不是可履行改写）**  
   `定位｜原文“丙方将款项付至甲方指定的个人账户，仅用于资金周转，乙方出具结清证明”｜建议改为：不提供可履行改写。请各方改用与债权人同名的对公账户，并提交原债务合同、履行凭证和资金来源说明后再审。在真实原债和合法来源闭合前，本任务停止。｜理由 L# 146／154；反洗钱法 10｜可退让：无｜红线：补假回单、假原债或个人卡过账仍要求放行`

4. **最强反方**  
   “民事上代付自由，银行的事不用管。” 民事代付以真实债务为前提。来源和原因说不清时，本任务不给过账结构。

---

## 节点 2　主体、授权、原债务真实性

1. 建主体表：代付方、债务人、债权人、担保人、付款名、收款名、发票名、授权签字人。名称不一致不自动合并。
2. 原债务须有合同名称编号、形成原因、基准日未偿额。债权人与债务人应共同确认。口头“大概三百万”不得写成已确认。
3. 代付方付款名、债权人收款名应与签约名一致。付到个人卡或无关第三方：硬闸 E，除非有可核验的法定原因（如债权人是自然人本人）。
4. 国资、上市公司、集体决议未附：签署能力字段停止。公司为他人付款或大额对外付款，提示内部决议，不编造已经批准。
5. 担保人只记录注销影响，不展开担保整案。

不足：字段停止，列出待补材料，不补主体，不编造未偿额。

---

## 节点 3　程序与生效

把到账、结清证明、担保注销、内部决议写成**义务和期限**，不写成已经完成。

| 文本写法 | 本任务动作 |
| --- | --- |
| “签字后原债务消灭” | 硬闸 B；拆成协议生效 vs 收妥后对应部分终止 |
| “担保自动终止，无须登记” | 承认 393／559 的从权利消灭，补注销登记义务 |
| “付至任何账户均可” | 改成唯一与债权人同名账户 |
| 用户要求倒签到账日或补假回单 | 整体停止 |
| 国企大额对外代付无决议 | 签署能力字段停止 |

不得把“双方同意视为已到账／已注销／已批准”写成可放行结构。

---

## 节点 4　格式条款、强制规范与退出

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

审查“签字即结清”“不得再主张”“最终解释权”。违反法律、行政法规强制性规定不一律无效（153；解释第 16 条）。洗钱、虚假意思、恶意串通：不改写成有效履行结构。禁止用已失效“效力性／管理性”口诀。禁止用《合同法》第六十五条、第八十四条代替 523／524／551。

退出：未在最终截止日前到账、真实性不实、注销不能，应有解除、返还和已付款清理。禁止只写“双方协商解除”。代付方未付的，不得写成原债务已消灭。

---

## 节点 5　违约、解除、争议解决

1. 代付方逾期付款、债权人逾期出具结清证明或配合注销、债务人陈述不实，必须分别有日违约金或固定金额，以及达到【待填】日的解除权。只有“依法承担违约责任”视为必须改。
2. 构成违约不等于当然解除。法定解除只点名催告或目的不能实现，不在本任务作出已解除结论。
3. 违约金避免“不得调整”或“按总价百分之三十必得”。
4. 争议解决：已有仲裁条款，不得改成假装已选定诉讼；或裁或诉、机构不明，改成单一机构或单一法院连结点。原债务合同的管辖不自动覆盖本协议，除非写明。
5. 微信转账截图不写成已经到账，除非与银行回单勾稽且合同承认该渠道。

---

## 节点 6　跨境、税务与其他结构

1. 涉外主体或境外付款：准据法不明则停止外国法结论。外汇与跨境人民币安排字段停止，不编造可以付。
2. 发票：债权人是否就代付款开票、开给谁，标 `G#`，不给税务筹划。股东借款入账是会计事实，本任务只要求文本与入账口径一致。
3. 代付与股权收购价款轧差：必须与主交易合同勾稽，禁止两份文件对同一笔钱各写一次对价。冲突并列，不选有利版。

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

对照已加载框架级文件和本方法硬闸，按六步逐段出句。基本面若已降级，本节点仍按本表出句。

| 步 | 本类型必须盯的点 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题是代付款／三方清偿，不是转移或债权转让；三方名称与角色；鉴于只描述原债务和代付原因，不把到账写成已完成 | 标题、主体、鉴于修改句 |
| 交易条款 | 原债务确认；代付金额；523 定性；指定账户；收妥才消灭对应部分；单一追偿路径 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 结清证明；担保注销动作与违约金；陈述保证原债真实；逾期付款／逾期注销 | 可执行后果句 |
| 尾部 | 三方签字盖章生效；附件：原债务合同、担保合同、账户信息、结清证明格式 | 生效与附件修改句 |
| 语言 | 正说加反说；收妥≠签署；代付≠转移≠加入；结清≠自动注销登记；定金／订金不混用 | 替换空词的句子 |
| 常见问题 | 签署即免责、签字即结清、追偿双重主张、个人卡过账、担保只写自动终止 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（转移伪装、签字即结清、洗钱走账、追偿双重主张、未到账出结清）；
- `必须改`：可谈但签署前要落句（523 定性、指定账户、单一追偿、注销期限、原债务确认）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级金额或个人无限连带且用户拒绝升级：停止“可以签署”建议。
