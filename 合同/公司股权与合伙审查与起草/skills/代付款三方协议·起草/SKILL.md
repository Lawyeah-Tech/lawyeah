# 代付款三方协议·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构，不证明本约条款已被接受。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》第六十五条、第八十四条及其解释、已失效《物权法》《担保法》及其解释当作现行规则。不得把签署本身写成原债务消灭，也不得把一切代付都写成民法典第五百二十四条的法定债权移转。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **公司相关合同 / 代付款三方协议** 己方稿，出稿后用本类型硬闸自审。交付草稿、未决项、自审风险表和自审后修改句。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。`depends-on` 为空。不要求先跑导航。

不交付：他类审查、从零起草、履约交底、争议追索文书、有效性或必然追回保证、整份保证／抵押主文件审查、把债务转移或走账改写成可履行代付。

## 工作边界

正触发：已有可读待签文本要评改（审查模式），或本类型条件已谈妥要出己方稿（起草模式）；尚未签署，尚未成争；核心给付是**代付方按约定向债权人支付款项**；在债权人指定账户足额收妥前，原债务仍由原债务人承担；代付方不因签署本协议当然成为新债务人或连带债务人。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 原债务人签署即退出、债务转由第三人承担、须债权人同意才对债权人生效 → `债务转移三方协议·审查`；
- 第三人加入并与债务人连带承担，或向债权人作出独立的承担承诺为主结构 → 引擎或债务加入专项，不得删掉连带句后继续当本类型审；
- 债权人退出、第三人取得对债务人的债权为主结构 → `主给付是债权让与通知债务人为轴→`；
- 保理（有追索／无追索融资、将有应收账款管理或付款担保为主结构）→ 引擎或保理专项；
- 买的是股权或特定资产，本文件只是主交易附件且用户要审主文件 → `公司股权转让·审查` 或 `非核心资产转让·审查`；代付附件仍可在本任务审，但不得把股权交割条件改写成代付主给付；
- 主文件是保证或抵押借款 → `主文件是保证或抵押借款→`／`或`／`主文件是抵押借款`；本约若另有代付正文，担保只作注销红旗；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问付款日、到账核对、注销留痕 → 本套导航的履约步骤；
- 已成争（催告、追索起诉策略、立案、开庭、仲裁）→ 合同争议领域，不填签前十节。

虚构原债务、循环走账、掩饰资金来源或通谋逃债：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；代付方／债务人／债权人单一立场；正文、原债务合同、账户信息、担保文件版本；代付金额与原债务是否对应；不可接受事项；法域与拟签时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的金额、账户、日期用 `【待填】`，不编造。

## 本类型硬闸

审查过程必须逐项点名，不得用债权让与通知清单或债务转移“原债务人免责”清单代替：

1. **代付≠债务转移**：代付方只履行付款动作。签署不使原债务人退出，也不使代付方成为新债务人。第三人不履行时，债务人仍向债权人承担违约责任（523）。出现“签署之日起债务转由代付方承担／原债务人免责”：先判断是否已滑入 `债务转移三方协议·审查`；若其余结构仍是代付，必须改句删掉免责转移。
2. **清偿效果**：对应部分原债务只在债权人指定账户足额收妥后终止（557）。禁止“签字即结清”“无须到账”。部分代付不得写成全部消灭。债权人应出具结清或部分结清证明，并承诺不得就已收妥部分再向债务人主张。
3. **追偿**：必须锁定**一条**路径：约定返还／股东借款，或符合 524 时的法定移转，或明示赠与。禁止沉默，禁止对同一笔款项同时主张法定移转和股东借款。另有约定的，优先按约定，524 第二款的法定移转让位。明知无给付义务的，不得改成可追偿结构（985 第三项）。
4. **与债务转移切开**：债务人换人、须债权人同意、原债务人免责 → `债务转移三方协议·审查`。不得“顺便改完”。债权人把债权卖掉 → `主给付是债权让与通知债务人为轴→`。连带加入不是本类型。
5. **禁止洗钱／走账放行**：虚构原债、循环资金、个人卡过账掩饰来源、阴阳金额：只告知，不改写成可履行过账。用户坚持“改到能过账”：整体停止。

担保注销是清偿效果的配套：主债权对应部分消灭后担保物权消灭（393、559），但登记和权证必须写成有期限的配合义务，不得以“自动终止”代替注销动作。


## 起草模式

本原子只承担本类型起草。待签评改转 `代付款三方协议·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `代付款三方协议·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 代付方只履行付款动作。签署不使原债务人退出，也不使代付方成为新债务人或连带债务人。
- 对应部分原债务只在债权人指定账户足额收妥后终止。部分代付不得写成全部消灭。债权人应出具结清或部分结清证明，并承诺不得就已收妥部分再向债务人主张。
- 追偿必须锁定一条路径：约定返还／股东借款，或符合民法典第五百二十四条时的法定移转，或明示赠与。另有约定的，优先按约定。
- 主债权对应部分消灭后担保物权消灭，但登记和权证必须写成有期限的配合注销义务。

### 附件必附

- 原债务合同
- 债权人指定账户信息
- 担保文件（如需注销）

### 禁止出现

- “签署之日起债务转由代付方承担／原债务人免责”
- “签字即结清”“无须到账”
- 对同一笔款项同时主张法定移转和股东借款
- 虚构原债、循环走账、个人卡过账掩饰来源、阴阳金额的可履行过账
- 以“自动终止”代替担保注销动作

执行顺序和停止条件以 [审查方法](references/method.md) 为准。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录，禁止为对照打开债务转移或债权转让双文件。交付按 [输出合同](references/output-contract.md)。边界见 [路由](references/routing.md)。

同目录 `基本面.md` 若正文是动产买卖或其他无关类型，记 `G#` 并降级，用本方法节点继续，不改去加载买卖双文件。`框架.md` 中的“受让方／转让方”按代付方／债务人角色读，不按债权让与理解。

必须有修改句。禁止只打红黄绿。每个风险回链文本位置。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典第五百二十三条、第五百二十四条、第五百五十一条、第五百五十二条、第五百五十七条、第一百四十六条、第一百五十三条、第一百五十四条，以及《合同编通则解释》第三十条；`search_practiced` 补代偿与转移／加入的切开反例；`search_template` 只借修改句结构。不虚构案件系统。

`search_law` 对法律结论为 required 级节点：不可用时不拒绝执行，只停止法律结论字段。返回已失效《合同法》第六十五条、第八十四条或其解释时记为噪声，不得写入 `L#`。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、虚构原债、循环走账或洗钱、把债务转移伪装成代付以骗取债权人免责、保证签字即债消灭或必然追回。
- `字段停止`：原债务合同与未偿额、指定账户、追偿路径、资金来源、担保登记未核验；关键代付金额缺失。
- `目标停止`：主目标已变为从零起草、履约核对、争议追索，或文本已滑入债务转移／债务加入／债权转让。

生存级金额或个人无限连带且用户拒绝升级：停止“可以签署”建议。
