# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受、一定解禁或监管不叫停；编造未给出的授予价、股数、日期；把已失效《合同法》、2016 年未修正或 2018 年已被修改的管理办法写入结论；把计划未批写成可以先授股；把未达标写成可以递延；把无偿收回写成可放行；把大宗交易、合伙激励或股票期权文本当成已完成的本类型审查。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查上市公司限制性股票激励协议（公司相关合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、2016 年未修正或 2018 年已被修改的管理办法时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `公司相关合同`，子级 `上市公司限制性股票激励协议`。定性理由、易混切开结果（大宗交易 / 合伙激励 / 股票期权 / 附条件股份认购 / 普通股权转让）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、计划批准、对象资格与文本版本

主体表：签约名、履行名、付款名、发票名、授权签字人。计划表：计划名称、董事会草案、公示公告、股东会决议日期或【待填】、薪酬与考核委员会名单核实。对象表：职务、是否独立董事、是否 5% 股东或实控人近亲属、资金是否自筹。版本表：正文、激励计划、考核办法、授予通知、决议或公告、聊天确认；冲突并列。

## 5. 授予、限售、考核与回购闭环

股票来源、授予日是否交易日、数量与价格、限售起算、12 个月间隔、分期及各期比例、未达标是否被写成递延、公司与个人考核是否可量化、回购触发是否穷尽、回购价是否突破第二十六条、董事会／股东会程序是否写清、60 日授出是否闭合。缺口标 `G#`。不输出大宗减持额度口径，不输出合伙份额回购口径，不输出期权行权价口径。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹。财务资助、未批准先授股、伪造决议不得写成可放行。强制规范只按第一百五十三条区分是否导致民事行为无效，不用失效口诀。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把大宗过户或合伙入伙直接写成“授予方式”而不问是否限制性股票。

## 9. 谈判与签署提醒

谈判顺序：先红线（计划未批仍授股、一次解禁或未达标递延、无偿收回或破回购上限、财务资助、实为大宗或合伙），再必须改（价格公式、考核口径、回购程序、60 日授出、返还承诺、名单核实），最后可优化。签署提醒：上市公司公章与法定代表人或授权代表、激励对象本人签署、计划及考核办法作附件、股东会决议或公告、薪酬与考核委员会意见、授予通知。不指导倒签或先签再补决议。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书或效力保证，也不是大宗交易、合伙激励或股票期权安排。
