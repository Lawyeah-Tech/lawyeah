# 边界与路由

本技能只审查 **公司相关合同 / 上市公司限制性股票激励协议** 的待签、上市公司按激励计划授予本公司限制性股票并约定限售、考核、解除限售与回购注销的文本。中文展示名是「审查上市公司限制性股票激励协议（公司相关合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 交易所大宗交易系统申报；盘后固定价格；减持预披露；受让方 6 个月锁定；连续 90 日 2% 额度；流通股过户即可卖出 | `上市公司股票大宗交易协议·审查` |
| 有限合伙持股平台；LP 入伙／退伙；合伙份额 Vesting；间接持有目标公司股权 | `股权激励型合伙合同·审查` |
| 普通有限合伙协议，无激励计划项下限制性股票授予 | `合伙协议（有限合伙）·审查` |
| 附生效条件的股份认购、战略配售或定增认购 | `附条件生效股份认购协议·审查` |
| 股票期权、行权价格、可行权日、期权注销 | 本套导航的类型切开步骤 重新定性 |
| 非上市公司限制性股权／期权 | 转引擎，不套本办法主板口径 |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式（出稿后自审） |
| 已签未争、只问缴款日、解禁日、回购通知 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `已出现催告解除函索赔立案开庭仲裁` 或对应专项领域 |
| 劳动仲裁、证券监管立案、内幕交易调查已启动 | 劳动或证券专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

限制性股票协议里夹带一小段大宗过户或合伙平台安排：专章交接对应原子；授予、限售、回购条款可继续审。用户坚持本技能把大宗交易、合伙激励或期权整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
