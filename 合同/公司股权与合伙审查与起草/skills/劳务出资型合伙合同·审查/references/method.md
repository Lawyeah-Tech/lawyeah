# 审查方法（锁定 合伙合同相关 / 劳务出资型合伙合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制普通合伙企业执照主路径、有限合伙 LP 避风港、劳动合同试用期/违约金白名单、承揽验收主路径或股东协议治理节点后换“劳务出资”交差。

定性校验：标题、核心给付与本类型一致才继续；无人以劳务作价取得份额、有限合伙主文件、劳动合同、个人劳务、承揽、技术权利入股、股权激励或隐名合伙明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、必然不被认定为劳动关系、对方必然接受或对外已经免责。

`search_law` 返回 1997 年《合伙企业法》同号条文、已失效《民法通则》个人合伙章、已失效《合同法》及其解释、已失效《合伙企业登记管理办法》或已失效《外商投资合伙企业登记管理规定》时记为噪声，不得写入 `L#`。2006 修订第 16 条（劳务出资评估办法）常被 1997 年第 16 条（登记期限）抢先命中：排除后再引，未独立核验全文则该条号不得标成已核验。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。普通合伙无劳务栏目的范本、有限合伙范本、劳动合同范本只证明是另一类型。

知识库纠正（不回写双文件）：

- `框架.md` “载明劳务出资已视为履行完毕”：劳务出资标的是合伙人后续行为。持续劳务尚未提供时，不得写成一次性履行完毕并立即取得不可回转的全部份额。拆成交付标准、考核与分期归属。
- `框架.md` “股权分期解锁”：本类型是合伙财产份额，禁止写成公司股权或注册资本。
- `基本面.md` “个人家庭财产均在执行范围内”：不得写成已核验。自然人普通合伙人的个人财产可被追索；夫妻共同财产、其他家庭成员个人财产另受民法典婚姻家庭编与物权规则约束。
- `基本面.md` LP 劳务出资“无效且可能被视为普通合伙人”：第 64 条禁止有限合伙人以劳务出资。是否整份无效或身份升为普通合伙人不是必然结果。修改句删除该出资或改缴货币/改身份为普通合伙人并明示无限连带，不保证升格。
- `基本面.md` 若出现“效力性强制性规定”口诀：改走民法典第 153 条和合同编通则解释第 16 条。
- `框架.md` 建议自“开始入场提供劳务”生效：实务偏好，不是法定。协议成立与企业成立（执照签发日）必须分列。
- `框架.md` 禁用“工资”：民法典第 971 条允许合伙合同另约执行事务报酬。可以约定“执行合伙事务报酬”或“基本劳务费”，必须与劳动法上工资、加班费、社会保险用人单位义务切开。
- 技术入股：标的是知识产权权利本身，不是后续劳务行为。负触发，不按本类型审完。

### 1.1 定性

支持切开的规范（法律结论须运行时复核）：

- 《合伙企业法》第 64 条：有限合伙人不得以劳务出资。本次已核 2006 修订全文。
- 《合伙企业法》第 16 条制度：普通合伙人可以用劳务出资，评估办法由全体合伙人协商确定并在合伙协议中载明。本次 MCP 未完整返回 2006 修订第 16 条正文，运行时复核后再写入 `L#`。
- 民法典第 967、968 条：合伙合同共享利益、共担风险；合伙人按约定出资方式、数额和缴付期限履行。
- 民法典第 770 条：承揽是完成工作、交付工作成果、支付报酬。
- 劳动合同法实施条例第 3 条：会计师事务所、律师事务所等合伙组织可以是用人单位——合伙人本人提供劳务出资，不当然成立对该人的劳动关系。
- 市场主体登记管理条例第 13 条第 2 款：公司股东、非公司企业法人出资人、农民专业合作社成员不得以劳务作价出资。

## 节点 2　主体、显名、资质与双重身份

### 2.1 主体表与显名

建表：签约名、劳务出资人姓名、资金/实物合伙人、授权签字人、是否拟领合伙企业执照。名称不一致不自动合并。

劳务出资者必须作为合伙人明确列入。写成“技术人员”“顾问”“雇员”且无份额：按节点 1.3 负触发或必须改。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 国有独资公司、国有企业、上市公司、公益性事业单位或社会团体被列为普通合伙人 | 红线删除或改道；第 3 条禁止 | 补内部决议即可登记 |
| 劳务出资人技能证书、职称或成功案例未附 | 字段停止；修改句要求作为附件 | 已经具备所称技能 |
| 劳务出资人另有全日制劳动关系或在先竞业限制 | 字段停止；审查产出权属和履约时间冲突 | 可以同时全职两处 |
| 口头“我们老板同意了” | 不得写成已授权 | 已获内部批准 |

修改句：

「乙方作为劳务出资合伙人列入本协议当事人。乙方承诺：具备附件所列【资格证书名称及编号／待填】；签约时未对任何第三方负有使其无法按本协议提供劳务的竞业限制或全职义务；因隐瞒兼职或在先义务导致合伙损失的，乙方赔偿并【按本协议退伙结算／待填】。证书复印件作为附件。各方不得将乙方仅写作雇员或顾问。」

### 2.2 拟领执照与书面事项

拟设立合伙企业的：协议应覆盖《合伙企业法》第 18 条事项。缺一项则该字段不得写成已闭环。未领执照不得以合伙企业名义经营（市场主体登记管理条例第 3 条）。协议生效日与执照签发日分列。

不领执照的个人合伙：主法是民法典合伙合同章；仍须有出资方式、数额、份额和共担风险。不得用企业除名、清算、执照专条继续审——若用户只要个人合伙且无人劳务作价，应已在节点 1 负触发 `个人合伙合同·审查`。

### 2.3 丧失劳务能力预埋

劳务高度依附特定个人。未约定伤病、死亡、丧失民事行为能力时的退出：必须改，不写成可以继续用其名义占份额。

民法典第 977 条：合伙人死亡、丧失民事行为能力或终止的，合伙合同终止，另有约定或事务性质不宜终止的除外。企业合伙另核《合伙企业法》当然退伙与继承人入伙规则，条号运行时复核。

## 节点 3　劳务出资评估与份额（硬闸）

审查清单，缺一项则该字段不得写成已闭环：

1. 评估办法：全体合伙人协商，或委托评估机构。必须载明于协议或全体签署的《出资确认书》。
2. 作价金额或折算比例，以及对应财产份额（百分比或份额数）。
3. 劳务内容、频率、时长或阶段性成果（可核验的交付标准）。
4. 服务年限或分期归属：防止拿走份额后短期闪离。未给年限不编造“四年每年 25%”，用 `【待填】`。
5. 权属：劳务产出的技术成果、客户名单归合伙财产还是个人，须点名。
6. 劳务本身不是可强制执行的物权。未按约提供劳务：其他合伙人可主张违约、减记份额、除名，不得写成法院必然强制其亲自提供劳务。

| 文本写法 | 动作 |
| --- | --- |
| “乙方以技术入伙，份额另议”或只有“技术股 30%”无评估办法 | 必须改。评估办法和份额未载明不得写成已履行出资 |
| “劳务出资已全部履行完毕，份额立即归乙方所有，不可回转” | 必须改。持续劳务不得视为一次性履行完毕 |
| 作价显著空洞或各方陈述冲突 | 并列 `C#`/`S#`；字段停止；不编评估值 |
| 把劳务份额写成可随时抽回的货币出资 | 红线。清算前原则上不得请求分割企业财产；劳务不可折现撤资 |
| 国资或高额交易未提评估 | 可优化：建议第三方模拟评估；不写成无法定评估则合同无效 |

修改句：

「乙方以【待填技能／岗位】劳务出资。评估办法：由全体合伙人协商确定，作价人民币【待填】元，折算财产份额【待填】%。该评估办法和份额记载于本协议及附件《出资确认书》，经全体合伙人签字确认。乙方应按附件《劳务说明书》提供劳务：内容【待填】，频率／时长【待填】，阶段性成果【待填】。乙方财产份额按服务期分期归属：自开始提供劳务之日起每满【待填】个月归属【待填】%，服务期届满前未归属部分不享有对应财产分配。未按说明书提供劳务的，已归属份额按【实际服务时长折算／待填】确认，未归属份额注销或由其他合伙人按【待填】回购；各方不得请求法院强制乙方继续亲自提供劳务，但不影响违约金、减记和除名。」

禁止编造作价和比例。框架或示范文本中的 30%、6000 元只是栏目，不是法源。

最强反方：资金方事后主张作价过高要求稀释。现有依据支持把评估办法和一致确认写进协议，不支持本任务宣告作价“过高无效”。反方二：劳务方主张“已写 30% 就是已实缴”。持续劳务未提供完毕的，不得把份额写成不可回转的实缴货币。

## 节点 4　利润、亏损与执行事务报酬

### 4.1 没出钱仍对外担责（硬闸）

支持依据：拟登记普通合伙企业适用《合伙企业法》第 2 条——普通合伙人对合伙企业债务无限连带。个人合伙适用民法典第 973 条——合伙人对合伙债务承担连带责任，超出自己份额的有权追偿。执行解释（2020 修正）第 14 条：合伙企业不能清偿时，申请执行人可申请变更、追加普通合伙人为被执行人。

| 文本写法 | 动作 |
| --- | --- |
| “乙方未投入货币，故对外不承担责任 / 只分红不担亏损” | 红线删除。对内分担可另约，对外不得免责 |
| 全部利润给资金方，或全部亏损由劳务方承担 | 拟登记普通合伙：红线（第 33 条制度，运行时复核条文）。个人合伙：必须改，按第 972 条约定或协商、实缴、平均顺序重写，并明示对外连带 |
| 未约定分配分担 | 必须改：先约定；无约定则协商；协商不成按实缴；无法确定则平均。劳务作价视为确定出资比例的依据之一，须回链评估条款 |

修改句：

「乙方虽以劳务出资、未缴付货币，仍对合伙债务与其他普通合伙人／合伙人承担【无限连带／连带】责任。任何‘未投入货币即不对外负责’‘只分红不担责’的约定不约束债权人。对内亏损按附件【待填】分担，该比例仅用于合伙人相互追偿。」

### 4.2 执行事务报酬与“工资”

民法典第 971 条：合伙人不得因执行合伙事务请求支付报酬，但是合伙合同另有约定的除外。本次已核全文。

未另约报酬：劳务合伙人默认只按份额分红，不得再主张劳动法工资。另约报酬：写明性质是执行合伙事务报酬或基本劳务费、是否在分红中抵扣、列入成本的时点。禁止在本协议写入加班费、未签劳动合同二倍工资、社会保险用人单位义务——除非各方承认另成立劳动关系并另签劳动合同（升级，本任务不起草劳动合同）。

有限合伙企业执行事务合伙人可在协议中确定报酬（第 67 条）。若文本已是有限合伙主文件，应已在节点 1 负触发 `有限合伙企业合同·审查`。

## 节点 5　事务执行、成果权属与竞业

合伙人对执行合伙事务享有同等权利，除非委托一人或数人执行。内部对代表权的限制，拟登记企业不得对抗善意第三人（第 37 条制度，运行时复核）。

劳务产出的技术方案、客户资源、作品：默认归入合伙财产（《合伙企业法》第 20 条：出资、以企业名义取得的收益和其他财产均为企业财产）。个人合伙则点名归入合伙财产，清算前不得分割。未写权属：必须改。

竞业：合伙期间不得自营或与他人合作经营同类业务。退伙后竞业年限、范围、地域须特定化。框架“2–3 年”是实务偏好，不是法定上限；未给出数字用 `【待填】`。在先竞业或兼职未披露：回节点 2.1。

不得把劳动法上的竞业限制补偿、违约金白名单搬进本协议当作已审查的劳动合同条款。

## 节点 6　退伙、丧失能力与格式条款（硬闸）

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 退伙结算：劳务不可折现退回

支持依据：拟登记企业——《合伙企业法》第 52 条，退伙人财产份额的退还办法由协议约定或全体决定，可以退还货币，也可以退还实物。第 54 条，财产少于债务时退伙人按利润亏损规则分担亏损。第 51、53 条制度（结算时点、退伙前债务仍无限连带）运行时复核条号后再写入 `L#`。个人合伙——民法典第 978 条，终止后剩余财产按第 972 条分配。

| 文本写法 | 动作 |
| --- | --- |
| “退伙时按劳务作价原额加利息返还现金” | 红线。劳务本身不可折现退回；只结算名下财产份额对应的现金或实物 |
| “任何情形永远不得退伙” | 必须改。未约定期限的，不给事务执行造成不利影响时可退伙，但应提前三十日通知（第 46 条，已核） |
| 中途无故停止提供劳务，份额如何处置空白 | 必须改：按已服务时长折算、未归属清零或折价回购 |
| 退伙后对退伙前债务免责 | 红线删除对外豁免。对内可另约追偿 |
| 丧失劳务能力、死亡后仍由家属继续占份额且无结算 | 必须改。约定继承人是否入伙（须一致同意，另有约定除外）或按退伙结算 |
| 除名无书面通知、无异议起诉期间 | 必须补第 49 条：未履行出资义务、故意或重过失造成损失、执行事务不正当、约定事由；书面通知到达生效；三十日内可起诉 |

修改句：

「乙方退伙或被除名时，劳务本身不予折现返还。其他合伙人应与乙方按照退伙时的财产状况结算其已归属财产份额，退还货币或实物，办法由本协议约定或全体合伙人决定。未归属份额【注销／按待填折价由其他合伙人受让】。因乙方无故停止提供劳务导致退伙的，已归属份额按实际服务时长占约定服务期的比例确认，其余注销。因伤病等不能继续提供劳务的，按上款结算，互不主张继续占用未提供劳务对应的份额。乙方对基于退伙前原因发生的合伙债务，仍承担【无限连带／连带】责任，该责任不得以本协议对外免除。」

最强反方：劳务方主张“我的技术值 30 万，退伙应退 30 万现金”。现有依据不支持把劳务作价当成可抽回的货币出资。反方二：资金方主张“人一走份额直接清零且旧债一概不管”。已归属财产份额仍应结算；对外旧债不能协议免除。

### 6.2 格式条款

为重复使用而预先拟定、订立时未与对方协商。依据示范文本制作，不当然排除格式条款。

审查：无限连带、份额清零、永远不得退伙、管辖/仲裁等异常条款是否有足以引起注意的标识，以及是否按要求说明（民法典第 496 条；解释第 10 条）。小字、网络勾选、对方未异议，不得写成已尽提示义务。

### 6.3 强制规范

违反法律、行政法规强制性规定不一律无效（第 153 条；解释第 16 条）。禁止用已失效“效力性/管理性”口诀。LP 劳务出资、公司股东劳务出资、对外豁免无限连带、规避劳动法：不改写成有效履行。

## 节点 7　违约、解散清算与争议

1. 劳务不达标、擅自离岗、质量低劣：须有可核验标准和可执行后果（减记份额、违约金、除名条件）。只有“依法承担违约责任”视为必须改。
2. 除名决议须书面通知；被除名人三十日内可向人民法院起诉。不得写成“通知即不得异议”。
3. 违约金不是必得金额。修改句避免“不得调整”。
4. 拟登记企业解散必须清算。解散不等于合同立即终止。第 85 条解散情形应点名；第 91 条注销后原普通合伙人仍承担无限连带；第 92 条破产后仍承担无限连带。
5. 争议解决：出现仲裁条款，不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核，修改句改成单一仲裁机构或单一法院连结点。劳动争议仲裁条款若出现在本合伙协议中：标红旗——本任务不审劳动仲裁策略，提示身份冲突。
6. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。
