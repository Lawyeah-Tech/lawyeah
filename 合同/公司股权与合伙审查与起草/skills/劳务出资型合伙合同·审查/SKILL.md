# 劳务出资型合伙合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》、已失效《民法通则》个人合伙章、1997 年《合伙企业法》原文、已失效《合伙企业登记管理办法》或已失效《外商投资合伙企业登记管理规定》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **合伙合同相关 / 劳务出资型合伙合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查劳务出资型合伙合同（合伙合同相关）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、劳动仲裁策略、有效性保证、把普通合伙或有限合伙整案改完、把劳务出资人改成可履行的纯雇员或纯承揽人、把有限合伙人或公司股东的劳务出资改成可履行结构。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。每个风险回链文本位置。

1. **劳务出资评估与份额**：劳务折算的评估办法、作价金额或折算比例、对应财产份额，必须由全体合伙人协商确定并载明于协议或附件《出资确认书》。缺评估办法或缺份额：该字段不得写成已闭环。
2. **退伙**：劳务本身不可折现退回。退伙只结算其名下现金收益或实物财产份额；须写明中途停止提供劳务时份额如何折算、回购或注销，以及丧失劳务能力时的退出。退伙人对退伙前原因债务的对外责任不得协议免除。
3. **与劳动 / 承揽切开**：核心给付是以专业技能劳务作价取得合伙人身份并共担风险，不是人格从属换工资，也不是按定作要求交付工作成果换报酬。劳动合同、个人劳务雇佣、个人承揽文本负触发。协议里堆“工资、加班费、劳动合同、雇佣”而不持份额、不担亏损：负触发，不按本类型改完。
4. **仅普通合伙人或个人合伙人可以劳务出资**：已登记或拟登记有限合伙里的有限合伙人不得以劳务出资。公司股东不得以劳务出资。出现 LP 劳务出资：负触发 `有限合伙企业合同·审查` 或对该条停笔，不改成可履行。出现公司章程/股权：负触发公司类原子。
5. **没出钱仍对外担责**：劳务出资的普通合伙人对合伙企业债务承担无限连带责任；未领执照的个人合伙适用民法典第 973 条连带责任。严禁“只分红、不担责”或“没出钱就不对外负责”。
6. **劳务是后续行为，不是一次性财产**：技术入股标的是知识产权权利，负触发技术/知识产权出资路径。劳务交付须有内容、频率、时长或成果标准；不得在持续劳务尚未提供时写成“劳务出资已全部履行完毕”并立即取得不可回转的全部份额。

禁止只打红黄绿。必须有修改句。

## 工作边界

正触发：已有可读待签文本要评改，；尚未签署，尚未成争，核心给付是部分合伙人以专业技术、知识或技能性劳务作价取得合伙财产份额，且该人是共有权人/风险承担者，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 全体只出货币/实物/知识产权，没有任何劳务作价取得份额 → `普通合伙企业合同·审查`（领执照普通合伙企业）或 `个人合伙合同·审查`（不领执照个人合伙）；
- 出现有限合伙人、认缴为限，且争议轴是 LP 劳务出资或 LP 治理 → `有限合伙企业合同·审查`；
- 执业过错切割其他合伙人责任、名称标“特殊普通合伙” → `特殊的普通合伙企业合同·审查`（P1；专业版未装则 `unavailable`）；
- 隐名、不显名、只分利不执行 → `隐名合伙合同·审查`（P1；未装则 `unavailable`）；
- 员工以未来服务换份额、本质是激励而非合伙人出资作价 → `股权激励型合伙合同·审查`（P1；未装则 `unavailable`）；
- 人格从属、考勤管理、社保工资、劳动合同文本 → `人格从属＋工资社保→劳动合同`；
- 只拿固定报酬、不持财产份额、不担亏损 → `只拿固定报酬不分担亏损无合伙人决策权→个人劳务（雇佣）`；
- 按定作要求完成并交付工作成果换报酬，无合伙份额 → `按定作要求完成并交付工作成果换报酬，无合伙份额→`；
- 标的是专利权、软件著作权等权利本身作价 → 技术出资或知识产权路径，转引擎重新定性；
- 公司股东协议、注册资本、章程一揽子 → `公司股东协议·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `劳务出资型合伙合同·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁，或要散伙/讨薪策略 → `已出现催告解除函索赔立案开庭仲裁` 或劳动/合同争议专项。

挂靠、违法分包、规避限购、把 LP 或公司股东劳务出资改成可履行、把纯雇佣包装成合伙以规避劳动法：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（拟劳务出资合伙人或拟资金/实物合伙人择一）；相对方；全文及附件版本；是否领取或拟领取合伙企业营业执照；劳务出资人是否列为合伙人；评估办法与份额；劳务交付标准与服务年限；是否夹带工资/劳动合同用语；退伙与丧失能力安排；亏损与对外责任；不可接受事项；法域、拟登记地与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的作价、份额、年限、报酬用 `【待填】`，不编造。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `劳务出资型合伙合同·起草`；已签履约 → 本套导航履约步骤；已成争或讨薪/散伙诉讼策略 → 争议领域。未签且目标是评改已有劳务出资型合伙文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。无劳务作价、有限合伙主文件、劳动合同、个人劳务、承揽、技术入股、股权激励型合伙、隐名合伙负触发。

### 2. 主体、显名与双重身份

劳务出资人必须列为合伙人。技能证书、兼职与在先竞业未闭合：字段停止。国有企业等禁入主体担任普通合伙人：红线。

### 3. 劳务评估与份额

评估办法、作价、份额、交付标准、服务年限或分期归属必须落句。

### 4. 利润、亏损与执行事务报酬

对内可约定报酬，默认不得另主张劳动工资。对外不得免责。禁止只分红不担责。

### 5. 劳动 / 承揽切开

名实按履行判断。确认函不能单独排除劳动法。用户要把纯雇佣改成合伙以避社保：停笔。

### 6. 退伙、丧失能力与格式条款

劳务不可折现退回。中途退出与丧失能力必须有结算句。对外责任不可豁免。

### 7. 违约、竞业与争议

偷懒/离岗须有可执行后果。不选定唯一法院充作意见。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把 LP 或公司股东劳务出资改成可履行、把“只分红不担责”改成可履行、把纯雇佣包装成合伙以规避劳动法，或要求保证不可能被认定为劳动关系。
- `字段停止`：法域、动态规则、评估作价、证书与在先竞业、登记材料未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书、劳动仲裁策略，或已锁他类。
