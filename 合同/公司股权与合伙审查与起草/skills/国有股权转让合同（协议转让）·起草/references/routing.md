# 边界与路由

本技能只审查 **公司相关合同 / 国有股权转让合同（协议转让）** 的待签文本。中文展示名是「审查国有股权转让合同（协议转让）（公司相关合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 转让方无国有股东身份；普通有限公司存量转股，无评估/国资批准/协议例外主程序 | `公司股权转让·审查`。不得把本技能的国资批准和进场例外硬套给民营转股 |
| 标的是生产设备、房产、在建工程、土地使用权、债权、知识产权等资产 | `国有资产转让合同（协议转让）·审查`（国有资产协议转让）。非国有资产走 `资产收购合同·审查` 或 `非核心资产转让·审查`。不得删掉资产清单后按股权审 |
| 主文件是产权交易所挂牌公告、竞价记录或成交确认书 | 本套导航的类型切开步骤。本原子只审协议转让例外路径，不得把进场文本改成场外协议 |
| 资金进目标公司、注册资本增加、新发行权益 | `增资合同·审查` |
| 控制权转移打包：印章证照账户交接、董事会改组、拖售 | `股权收购合同（含控制权转移）·审查` |
| 业绩对赌、估值调整、公司或控股股东回购承诺为主给付 | `对赌协议（盈利预测补偿协议）·审查` |
| 上市公司股份协议转让、大宗交易、集中竞价 | `上市公司股票大宗交易协议·审查`。适用 36 号令，不得用 32 号令非上市产权路径硬套 |
| 股权投资相关合同项下同名转让：secondary、估值保护、随售／拖售 | `PE股权转让·审查` |
| 主文件是代持安排 | `股权代持协议·审查` |
| 主文件是公司回购股权 | `股权回购协议·审查` |
| 主文件是股东协议、出资合同 | `公司股东协议·审查` 或 `出资合同（有限责任公司）·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争，或已完成名册／登记后要“改合同把股权要回” | `已出现催告解除函索赔立案开庭仲裁` 或公司／投资并购争议领域 |
| C 端大众快检 | 只分流，不回改 |

金融企业国有股权：财政部令第 54 号路径，本原子不按 32 号令改完；字段停止并提示专项复核，用户坚持用本技能放行则 `目标停止`。

股权正文里夹带一小段资产交割清单：资产专条交接 `国有资产转让合同（协议转让）·审查`；股权批准、例外情形、评估底价、优先购买、工商条款可继续审。用户坚持本技能把资产转让、普通转股或进场挂牌整案改完：`目标停止`。

专业版未收录本 P1 原子。若用户拿本类型文本来找专业版：输出 `unavailable`，提示，不得用 `公司股权转让·审查` 或 `国有资产转让合同（协议转让）·审查` 硬套。
