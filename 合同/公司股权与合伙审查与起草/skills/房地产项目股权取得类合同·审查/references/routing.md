# 边界与路由

本技能只审查 **股权投资相关合同 / 房地产项目股权取得类合同**。

目标公司必须绑定特定地块或房地产项目，核心给付必须是通过股权或增资取得项目公司控制权，从而变相拿地或拿项目。标题叫“股权转让协议”但实际是土地使用权人直接过户、一方出地联建，或与地块／项目无关的财务投资的，不得留在本技能做实体结论，也不得改写成“视同项目股权”。

本类型与直接土地使用权转让、一方出地联建、无项目绑定的股权投资文本不是同一方法。土地使用权转让路径处理不动产变更登记、契税和土地增值税申报。联建路径处理出地出钱、共同报建和风险共担。普通转股、出资、增资、代持、意向书、股东协议处理财务投资栏目，不审地块负担和控制权落地。本技能不打开那些 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或标题股权、核心给付明显不是拿地／拿项目 | 本套导航的类型切开步骤 |
| 转让人是土地使用权人；对价是地价款；履行轴是不动产变更登记或土地二级市场网签 | `转让人是土地使用权人，对价是地价款，履行轴是不动产变更登记或土地二级市场网签→`；禁止用本技能审土地过户、契税过户或带押过户 |
| 一方出地、一方出钱，共同报建、共担开发风险，不转移控股权 | `一方出地一方出钱，共同报建共担开发风险，不发生控股权转移→`；禁止用本技能写联建分成或共同报建主路径 |
| 共同出资报建、共担风险，不发生控股权转移 | `共同出资报建共担风险，不转移控股权的合作开发→` |
| 拟设立尚未成立的公司，资金进入拟设公司 | `出资合同·审查` |
| 无地块或项目绑定，只审股权比例、对价、优先购买权和工商变更 | `PE股权转让·审查` |
| 显名代持、隐名投资人享有收益 | `股权代持合同·审查` |
| 投资意向书或条款清单，尚未构成转股或增资本约 | `投资意向书·审查` |
| 交割后投资人保护、优先清算、随售拖售为主文件 | `PE股东协议·审查` |
| 向已设公司认购新增资本、资金进入公司，且不以取得项目控制权为目的 | `增资协议·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式（出稿后自审） |
| 已签未争、问工商变更日、共管放款、证照移交 | 本套导航的履约步骤 |
| 已成争、催告、诉讼仲裁 | 合同争议领域；不写催告函、起诉状 |
| 用户只要“一定有效”或“买股权等于土地已过户” | 停止该结论；本技能只审条款并点名土地权利负担 |
| C 端大众快检 | 只分流，不回改 |

用户明确只要审土地使用权父级下“以土地获取为目的的股权取得”的投资开发条件／闲置／锁股主路径，且不以项目公司控制权与投资结构为主：分流到对应土地使用权原子，不得打开其 method。用户拿本类型标题或投资结构来审“买公司拿地／拿项目”的，即使目标公司目前仅持生地，也留本技能，不得因只有生地就自动转出。

附带股东借款承债、共管账户或税费补偿时：本技能只审对本约放行的影响（是否列入附件、付款节点是否冲突、未落实能否交割），不展开借贷或税务专项整案。

规避土地转让限制、挂靠、违法分包、隐名代持、名股实债、项目公司无条件回购：停笔告知，不改写成可履行结构。
