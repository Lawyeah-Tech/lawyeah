# 公司章程_章程修正案·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **公司相关合同 / 公司章程_章程修正案** 己方稿，出稿后用本类型硬闸自审。交付草稿、未决项、自审风险表和自审后修改句。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。`depends-on` 为空。不要求先跑导航。

主线是**公司组织文件及其修正案**：对公司、股东、董监高有约束力，并有登记公示面向。不是股东之间的个性化契约，也不是出资或存量转让本约。

不交付：他类起草、待签文本签前审查、履约交底、争议文书、有效性或必然完成登记对抗保证、股东协议／出资／增资／转让／代持／投资侧章程的整份代审。

## 工作边界

正触发：已有可读待签文本，尚未签署或尚未完成修订决议，尚未成争；核心给付是制定或修改公司章程（含章程修正案），用以规范组织、机构、股东权利义务和公示记载。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主文件是股东协议（投后治理、对赌、随售拖售、竞业）→ `公司股东协议·审查`；
- 价款／财产进公司的出资本约 → `出资合同（有限责任公司）·审查`；
- 已设立公司新增资本作为主文件 → `增资合同·审查`；
- 存量股权让与、价款进原股东 → `公司股权转让·审查`；
- 代持本约为审改对象 → `股权代持协议·审查`；
- 投资人保护清单驱动的投后章程整包、股权投资相关合同项下章程安排 → `PE股东协议·审查` 或投资并购侧；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问备案递件、换照进度 → 本套导航的履约步骤；
- 已成争（决议无效／撤销／不成立之诉、催告、立案、开庭、仲裁）→ **公司争议领域**，不填签前十节。

伪造决议、把隐名股东直接写入可对抗公司的条款、特许经营无许可却要求写成可先经营：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；代表公司、哪一方股东还是拟任董监高；有限公司还是股份公司；设立稿还是修正案；正文、旧章程、决议、执照版本；不可接受事项；法域与拟签时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的资本额、住所、表决比例用 `【待填】`，不编造。

## 本类型硬闸

审查过程必须逐项点名，每闸必须有修改句，不得用五年认缴清单或优先购买／名册路径代替：

1. **章程 ≠ 股东协议 ≠ 出资／转让本约**：章程约束公司、股东、董监高，有登记公示面向。高度个性化对赌、复杂退出留在股东协议。出资本约 → `出资合同（有限责任公司）·审查`；存量转让 → `公司股权转让·审查`。强行写入导致无法登记的必须改或切开，不写“一律无效”。
2. **强制规范不可删**：完全剥夺分红权／表决权、股东承担无限责任、取消法定机构选项：该条无效／必须改。通知方式、议事方式等可约定事项与不可约定事项分层。禁止照抄“效力性强制性规定”口诀。
3. **修改程序**：设立时全体股东制定并签名或盖章；修订须法定／章程规定的表决权比例并形成决议。有限公司修改章程以持有三分之二以上表决权的股东为基数；股份公司以出席会议股东所持表决权的三分之二以上为基数。未见决议原件：修正案签署能力字段停止。未经登记不得对抗善意相对人，**不得写成“未登记则章程未生效”**。
4. **记载与营业执照一致**：名称、住所、资本、股东、经营范围冲突并列。特许行业经营范围无许可：字段停止，不写“可以先经营后办证”。
5. **隐名／代持**：章程只约束显名股东。代持主文件 → `股权代持协议·审查`。不得把隐名股东直接写入可对抗公司的章程条款而不走显名程序。
6. **强制规范分层**：按现行“违反法律、行政法规强制性规定”分层核验后再写。违反强制性规定不一律无效。


## 起草模式

本原子只承担本类型起草。待签评改转 `公司章程_章程修正案·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `公司章程_章程修正案·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 设立时全体股东制定并签名或盖章；修订须法定／章程规定的表决权比例并形成决议。有限公司修改章程以持有三分之二以上表决权的股东为基数；股份公司以出席会议股东所持表决权的三分之二以上为基数。
- 未经登记不得对抗善意相对人，不得写成“未登记则章程未生效”。工商变更不是章程生效的唯一条件。
- 名称、住所、资本、股东、经营范围与营业执照冲突须并列。特许行业经营范围无许可：不写“可以先经营后办证”。
- 章程只约束显名股东。高度个性化对赌、复杂退出留在股东协议，不硬塞导致无法登记。

### 附件必附

- 修正案对应的决议原件（修订时）
- 旧章程
- 营业执照
- 特许行业许可批文（如适用）

### 禁止出现

- “未登记则章程未生效”
- 完全剥夺分红权／表决权、股东承担无限责任、取消法定机构选项
- 把隐名股东直接写入可对抗公司的章程条款而不走显名程序
- 特许经营“可以先经营后办证”
- 把对赌或否决条款写成自动无效
- 伪造决议

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录，禁止为对照打开 `出资合同（有限责任公司）·审查` 的五年认缴路径或 `公司股权转让·审查` 的优先购买／名册路径。交付按 [输出合同](references/output-contract.md)。边界见 [路由](references/routing.md)。

必须有修改句。禁止只打红黄绿。每个风险回链文本位置。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签或补假决议、把隐名股东写成可对抗公司的股东、把特许经营写成可以先经营后办证、保证有效或必然完成登记对抗。
- `字段停止`：修正案未见决议原件；执照对照未核验；许可批文未附；地方登记或外资规则未核验；关键记载事项缺失。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或文本已滑入股东协议／出资／转让／投资侧章程。

生存级控制权安排或个人无限连带且用户拒绝升级：停止“可以签署”建议。
