# 边界与路由

本技能只审查 **公司相关合同 / 公司章程_章程修正案**。主线是公司组织文件及其修正案，对公司、股东、董监高有约束力，并有登记公示面向。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 主文件是股东协议：投后治理、对赌、随售／拖售、竞业 | `公司股东协议·审查` |
| 价款／财产进公司、新设认缴本约 | `出资合同（有限责任公司）·审查` |
| 已设立公司新增资本、增资协议／新股认购为主文件 | `增资合同·审查` |
| 存量股权让与、价款进原股东、优先购买／名册登记为主给付 | `公司股权转让·审查` |
| 代持、隐名显名安排作为主文件 | `股权代持协议·审查` |
| 投资人保护清单驱动的投后章程整包，或股权投资相关合同项下章程安排 | `PE股东协议·审查` 或投资并购侧 |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、问备案递件／换照进度 | 本套导航的履约步骤 |
| 股东会决议效力／撤销／不成立之诉，或已立案仲裁 | 公司争议领域；不填签前十节 |
| 对赌／一票否决强行入章导致窗口无法收件 | 切开到股东协议；不写一律无效；用户坚持伪造可登记文本则整体停止 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

专业版未收录的投资侧 P1 场景不会作为本原子的实体审查对象。若用户拿这些文本来找本技能：输出 `unavailable` 或负触发路由，不得用本类型硬套。

本技能不得转去加载出资、转让或股东协议双文件完成本类型审查，也不得把五年认缴或优先购买写成章程默认主路径。
