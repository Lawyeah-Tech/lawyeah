# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受、必然设立或实缴认定；编造未给出的认缴额、实缴额、估值、截止日期；把已失效《合同法》及其解释、1993／2005／2018 年公司法同条号、2005 年“设立必须验资”写入结论；把已设增资、存量转股或公司侧纯出资文本当成已完成的本类型审查；写“取得营业执照即为交割完成”；写尚未成立的公司保证回购且可强制执行；把出资款打入个人账户改成可履行。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查出资合同（股权投资相关合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、1993／2005／2018 年公司法同条号、2005 年“设立必须验资”、担保法解释时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `股权投资相关合同`，子级 `出资合同`。定性理由、易混切开结果（已设增资 / 存量转股 / 公司侧出资 / 股东协议 / 对赌 / 代持 / 发起人协议）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。未打开 `出资合同（有限责任公司）·审查`、`增资协议·审查`、`PE股权转让·审查` 的 method。

## 4. 主体、拟设公司、授权与文本版本

主体表：签约名、履行名、付款名、发票名、授权签字人。拟设公司只标“交割后加入”，不得列入成立前回购／担保义务人。版本表：正文、资本表、章程草案、评估报告、出资财产清单、配偶同意、股东协议、聊天确认；冲突并列。

## 5. 资本表、实缴／验资与交割闭环

注册资本、认缴、实缴、注册资本／资本公积拆分、投前投后或每 1 元对价、ESOP 稀释。货币账户与非货币评估过户。交割是否同时具备登记、资金或过户到位、名册／章程记载。登记强制验资与投资交易实缴证据是否分列。缺口标 `G#`。不输出增资优先认缴或转让第八十八条主路径。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹。固定回报保本、禁止财产出资、规避准入、个人账户收款不得写成可放行。强制规范按民法典第一百五十三条和合同编通则解释第十六条区分是否导致民事行为无效，不用失效口诀。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把“取得执照即交割”或“公司盖章生效”直接放行。

## 9. 谈判与签署提醒

谈判顺序：先红线（实为已设增资或存量转股、固定回报保本、个人账户、未成立公司强制回购、禁止财产当成已实缴、执照即交割），再必须改（实缴日历日与账户、交割三件套、评估过户、章程同步、设立失败返还、失权程序），最后可优化。签署提醒：全体出资人签署、机构授权含出资、章程草案与资本表一致、银行回单或共管安排、评估与权属文件、配偶同意。不指导倒签或补假验资。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书或效力保证，也不是增资、转股、公司侧出资、股东协议或对赌安排。
