# 边界与路由

本技能只审查 **股权投资相关合同 / 出资合同** 的待签、公司尚未成立、资金进入拟设公司、注册资本自零生成的设立阶段投资文本。中文展示名是「审查出资合同（股权投资相关合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或复制 `出资合同（有限责任公司）·审查`、`增资协议·审查`、`PE股权转让·审查` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 公司已存续；认购新增注册资本；投前估值、老股稀释、原股东优先认缴 | `增资协议·审查` |
| 公司相关货架下的已设公司增资主文件 | `增资合同·审查` |
| 价款进原股东；资本不变；存量股权让与 | `PE股权转让·审查` |
| 公司相关货架下的存量转让、优先购买程序 | `公司股权转让·审查` |
| 无财务投资人、无估值／每 1 元对价、无 ESOP、无投资人保护，只是有限公司股东按资本规则设立出资 | `出资合同（有限责任公司）·审查` |
| 股份公司发起人协议、公开或发起设立股份公司为主文件 | `发起人协议（股份公司）·审查` |
| 主轴是交割后治理、优先权、随售拖售、退出 | `PE股东协议·审查` 或 `公司股东协议·审查` |
| 对赌／盈利预测补偿已成主文件 | `对赌协议（盈利预测补偿协议）·审查` |
| 隐名出资、名义股东、显名程序 | `股权代持合同·审查` 或 `股权代持协议·审查` |
| 买项目公司股权拿地，或规避土增税／25% 投资额 | `房地产项目股权取得类合同·审查`；只告知，不改成可履行筹划 |
| 只有 Term Sheet／投资意向，且不构成约束性本约 | `投资意向书·审查` |
| 用户要整份代审章程或章程修正案 | `公司章程_章程修正案·审查`；本任务只并列与资本条款的冲突 |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式（出稿后自审） |
| 已签未争、只问缴资、开户、登记窗口 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `已出现催告解除函索赔立案开庭仲裁` 或对应专项领域 |
| 催告补缴、失权、抽逃、设立不能索赔已立案 | 公司或投资并购争议专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

出资合同正文里夹带一小段股东协议治理或一条对赌：专章交接对应原子；设立资本、实缴、交割条款可继续审。用户坚持本技能把已设增资、存量转股、公司侧纯出资、股东协议或对赌整案改完：`目标停止`。

本原子为 **P1**。专业版未收录的 P1 场景不会安装本原子。若用户拿本类型文本来找专业版：输出 `unavailable`，提示，不得用 `出资合同（有限责任公司）·审查` 或增资／转股邻类硬套。
