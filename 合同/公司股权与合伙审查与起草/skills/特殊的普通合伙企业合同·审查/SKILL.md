# 特殊的普通合伙企业合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、1997 年《合伙企业法》同号条、已失效《合伙企业登记管理办法》或 1993 年合伙会计师审批办法当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **合伙合同相关 / 特殊的普通合伙企业合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查特殊的普通合伙企业合同（合伙合同相关）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性或许可保证、把普通合伙或有限合伙改完、把律师事务所合伙协议改完、把执业切割写成对债权人一律免责。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **专业服务机构专属**：仅以专业知识和专门技能为客户提供有偿服务的专业服务机构可设特殊的普通合伙。贸易、投资、普通劳务不得套用。律师事务所＋司法行政许可主线 → `律师事务所合伙协议·审查`。
2. **名称标明“特殊普通合伙”**：企业名称组织形式后应当标明“（特殊普通合伙）”。标题冲突改标题，不因标题单独改分流。
3. **执业过错有限责任**：执业活动中因故意或者重大过失造成的债务，过错合伙人无限责任或无限连带责任，其他合伙人以在合伙企业中的财产份额为限；非因故意或者重大过失的执业债务以及合伙企业的其他债务，全体无限连带。必须使用“故意或者重大过失”。禁止对债权人一律免责。禁止把一般过失写成已经切割。企业先赔，再向过错合伙人追偿。
4. **全部合伙人均为普通合伙人，均有权执行事务**：不得设 LP、认缴为限的财务投资人。出现 GP/LP → `有限合伙企业合同·审查` 或 `合伙协议（有限合伙）·审查`。
5. **与普通合伙 / 有限合伙切开**：无执业切割、名称只标普通合伙 → `普通合伙企业合同·审查`。LP 认缴为限、不执行事务 → `有限合伙企业合同·审查` 或 `合伙协议（有限合伙）·审查`。不领执照 → `个人合伙合同·审查`。禁止打开或复制 `合伙协议（有限合伙）·审查` 的 method。
6. **执业风险基金与职业保险强制**：应当同时建立执业风险基金并办理职业保险，基金单独立户、专用于偿付执业债务。框架写“基金或保险”时以本法条为准。不得把“未建基金则切割必然失效”写成已核验法效果。
7. **行业执业许可与资格；禁入主体**：先取得行业主管部门执业许可，再办工商登记。协议成立、企业成立、执业许可分开写。国有独资公司、国有企业、上市公司以及公益性的事业单位、社会团体不得成为普通合伙人。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签特殊普通合伙企业协议正文，尚未签署，尚未成争，核心给付是专业服务机构依《合伙企业法》设立特殊的普通合伙、名称标明特殊普通合伙、执业过错责任分层，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 全员无限连带、无执业切割、名称只标“普通合伙” → `普通合伙企业合同·审查`；
- 出现有限合伙人、认缴为限、LP 不得执行事务 → `有限合伙企业合同·审查`；公司相关基金／GP/LP 主文件 → `合伙协议（有限合伙）·审查`；
- 律师事务所章程化合伙协议、列律师执业证、报司法行政机关许可 → `律师事务所合伙协议·审查`；
- 不领执照、不以合伙企业名义登记 → `个人合伙合同·审查`；
- 不显名、不登记企业、约定不参与经营且不承担合伙债务 → `隐名合伙合同·审查`；
- 股东会、股权治理、注册资本一揽子 → `公司股东协议·审查`；
- 不参与经营、不承担亏损、到期固定本息 → `或企业间借款` 或 `不参与经营不承担亏损到期固定本息→自然人之间借款`；
- 只拿固定报酬不担风险 → `只拿固定报酬不分担亏损无合伙人决策权→个人劳务（雇佣）`；人格从属加工资社保 → `人格从属＋工资社保→劳动合同`；
- 无文本、本类型条件已谈妥、要出己方稿 → `特殊的普通合伙企业合同·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁，或吊证听证、散伙清算诉讼策略 → `已出现催告解除函索赔立案开庭仲裁` 或对应专项领域。

挂靠执业、出借许可证、未获许可先以专业所名义执业：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（拟入伙合伙人或拟执行事务合伙人择一）；相对方；全文及附件版本；专业服务类型与拟报许可机关；名称是否含“特殊普通合伙”；是否夹带 LP 或全员无限而无切割；执业责任是否区分故意或者重大过失；风险基金与职业保险；各合伙人执业资格；禁入主体；出资与利润亏损；入伙退伙对外责任；不可接受事项；法域、拟登记地与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的出资额、基金比例、保险限额用 `【待填】`，不编造。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `特殊的普通合伙企业合同·起草`；已签履约 → 本套导航履约步骤；已成争或吊证听证 → 合同争议。未签且目标是评改已有特殊普通合伙企业协议，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。普通合伙、有限合伙、律所、个人合伙、隐名合伙、股东协议、借贷负触发。

### 2. 名称、专业服务所、许可与主体

名称标明特殊普通合伙。确认专业服务类型与许可机关。禁入主体红线。签字、企业成立、执业许可拆开。

### 3. 执业过错责任分层

故意或者重大过失 vs 一般过失 vs 非执业债务。企业先赔再追偿。不得对债权人一律免责。

### 4. 风险基金与职业保险

二者均须；单独立户；专用于执业债务。提取比例用 `【待填】`。

### 5. 出资、利润亏损与执行事务

商誉、客户资源、实务经验不是法定出资。禁止全部利润或全部亏损。内部限权不得对抗善意第三人。

### 6. 入伙退伙、吊销证照、格式条款与强制规范

对外连带不可豁免切割范围外的债务。吊销证照约定当然退伙或除名。无核验引文则法律结论字段停止。

### 7. 违约、追偿、解散清算与争议

追偿程序可执行。解散必须清算。不选定唯一法院充作意见。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把执业切割改成对债权人一律免责、把 LP 或无资格者改成可许可、或把未获许可对外执业改成可履行。
- `字段停止`：法域、动态规则、行业人数门槛、处罚记录、评估作价、许可材料未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。

生存级个人无限连带且用户拒绝升级：停止“可以签署”建议。
