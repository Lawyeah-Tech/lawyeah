# 边界与路由

本技能只审查 **合伙合同相关 / 特殊的普通合伙企业合同** 的待签文本。中文展示名是「审查特殊的普通合伙企业合同（合伙合同相关）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或复制 `合伙协议（有限合伙）·审查` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 全员无限连带、无执业故意或重大过失切割、名称只标“普通合伙” | `普通合伙企业合同·审查`。不得用执业切割专条继续当普通合伙审 |
| 出现有限合伙人、认缴为限、LP 不得执行事务、禁止劳务出资的 LP | `有限合伙企业合同·审查`。不得删掉 LP 后硬套本技能 |
| 公司相关合同项下有限合伙、私募基金、GP/LP 出资避风港 | `合伙协议（有限合伙）·审查`。P1；未装则 `unavailable`。**不得打开其 method** |
| 律师事务所合伙协议主文件；列律师执业证；报司法行政机关许可 | `律师事务所合伙协议·审查`。P1；未装则 `unavailable` |
| 不领执照、不以合伙企业名义登记、只适用民法典合伙合同 | `个人合伙合同·审查` |
| 不显名、不登记企业、约定不参与经营且不承担合伙债务 | `隐名合伙合同·审查`。P1；未装则 `unavailable` |
| 公司股东协议、股权治理、注册资本一揽子 | `公司股东协议·审查` |
| 不参与经营、不承担亏损、到期固定本息；双方均为企业 | `或企业间借款` |
| 不参与经营、不承担亏损、到期固定本息；双方为自然人 | `不参与经营不承担亏损到期固定本息→自然人之间借款` |
| 只拿固定报酬、不担亏损、无合伙财产份额 | `只拿固定报酬不分担亏损无合伙人决策权→个人劳务（雇佣）` |
| 人格从属、工资社保、劳动合同文本 | `人格从属＋工资社保→劳动合同` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式（出稿后自审） |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争，或吊证、停业整顿听证，或用户要散伙清算诉讼策略 | `已出现催告解除函索赔立案开庭仲裁` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

特殊普通合伙协议里夹带一小段借款或劳务报酬：专条交接对应原子；名称、执业责任分层、风险基金、职业保险、行业许可条款可继续审。用户坚持本技能把普通合伙、有限合伙或律师事务所整案改完：`目标停止`。
