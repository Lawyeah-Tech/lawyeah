# 审查方法（锁定 合伙合同相关 / 特殊的普通合伙企业合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止打开或复制 `合伙协议（有限合伙）·审查` method，禁止复制普通合伙全员无限主路径、有限合伙 LP 避风港、律师事务所管理办法专条或股东协议治理节点。

定性校验：标题、核心给付与本类型一致才继续；普通合伙、有限合伙、律师事务所、个人合伙、隐名合伙、保底借贷明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、必然获许可、对方必然接受、对外已经隔离或重大过失必然被认定。

知识库纠正（不回写双文件）：

- `基本面.md` “未建风险基金或未买保险，法院可能判令风险隔离失效”：第 59 条课以建立基金并办理保险的义务，**未规定**未建则第 57 条切割失效。只作风险预警，不得写成已核验法效果。
- `框架.md` “执业风险基金**或**职业保险”：第 59 条是“应当建立执业风险基金、办理职业保险”，二者均须，不是选一。
- `框架.md` “知识产权、实务经验等无形资产作价”：货币、实物、知识产权、土地使用权、劳务可以约定作价；个人商誉、客户资源、实务经验不是法定出资形式，只能通过分红比例体现。
- `框架.md` “法人或其他组织通常不能作为合伙人”：第 3 条只禁止国独／国企／上市公司／公益事业社团担任普通合伙人。行业规范常要求具有相应执业资格的自然人；行业规则未核则字段停止，不得把无资格法人改成可许可合伙人。
- `基本面.md` 把律师列为专业服务示例：律师事务所＋司法行政许可主线转 `律师事务所合伙协议·审查`，不在本任务套管理办法第 10、17、53 条。
- `框架.md` “加盖指印”：不是法定签署要件，标可优化。
- `框架.md` “Right to Audit”：内控安排可谈，不得写成法定义务或英文条款已生效。
- “财产份额为限”指在合伙企业中的财产份额，不得改写成“账面权益”作为法定用语。

- 《合伙企业法》第 2 条：普通合伙人对债务无限连带，但对普通合伙人承担责任的形式有特别规定的，从其规定。第 55 条就是该特别规定的入口。

标题写成“普通合伙企业协议”但正文有执业故意或重大过失切割、名称标特殊普通合伙：按核心给付留本技能，标题冲突写入 `C#`，修改句改标题。

## 节点 3　执业过错责任分层（核心硬闸）

支持依据：第 55 条第 2 款（合伙人依照第 57 条承担责任）；第 58 条（企业财产对外承担责任后，过错合伙人按协议赔偿企业损失）。第 57 条原文运行时复核后再写入 `L#`。制度口径不得用 1997 年第 57 条解散事由替代。

三档必须同时写清：

| 档 | 债务类型 | 对外责任 | 不得写成 |
| --- | --- | --- | --- |
| 甲 | 执业活动中因**故意或者重大过失**造成的合伙企业债务 | 该合伙人或该数个合伙人承担无限责任或无限连带责任；**其他合伙人以其在合伙企业中的财产份额为限** | 其他合伙人责任为零；对债权人免责；企业财产也不赔 |
| 乙 | 执业活动中**非因**故意或者重大过失造成的合伙企业债务 | 全体合伙人无限连带 | 一般过失也按甲档切割 |
| 丙 | 合伙企业的**其他债务**（办公租赁、装修、行政借款、劳动债务等） | 全体合伙人无限连带 | 非执业债务也适用过错隔离 |

### 3.1 法定用语

必须使用“故意或者重大过失”。协议可列举典型情形（故意出具虚假报告、严重违反执业准则、伪造工作底稿），但：

- 不得把列举写成穷尽清单而排除行业执业准则下仍可能构成的重大过失；
- 不得把“重大过失”改成“过失”“过错”“未尽合理注意”从而扩大切割；
- 不得把“故意或者重大过失”改成“经管委会认定”作为对外生效条件。

无法认定为故意或者重大过失的，回归乙档或丙档，全体无限连带。本任务不得预判某笔债务“法院将认定重大过失”。

### 3.2 企业先赔、再追偿

第 58 条：执业故意或重大过失债务，以合伙企业财产对外承担责任后，该合伙人应当按照合伙协议的约定对给合伙企业造成的损失承担赔偿责任。

修改句必须包含：对外先由企业财产（含执业风险基金、保险赔付）承担；不足部分按甲档向过错合伙人追索；企业对过错合伙人的追偿程序、通知和期限。

### 3.3 禁止对债权人一律免责

| 文本写法 | 动作 |
| --- | --- |
| “任何合伙人对外仅以出资为限”“债权人不得向非签字合伙人主张” | 红线删除。切割只发生在甲档的其他合伙人，且仍以财产份额为限 |
| “办公租金、银行贷款同样适用执业隔离” | 红线删除。丙档全体无限连带 |
| 只写甲档，不写乙档、丙档 | 必须补两档，否则默示回归全体无限连带的说明要写进意见 |
| 把切割写成已经对抗善意债权人的绝对免责 | 必须改。内部追偿比例不得写成对外免责 |

修改句：

「一个或数个合伙人在执业活动中因故意或者重大过失造成的本企业债务，该合伙人或该数个合伙人承担无限责任或者无限连带责任，其他合伙人以其在本企业中的财产份额为限承担责任。合伙人在执业活动中非因故意或者重大过失造成的本企业债务，以及本企业的其他债务（包括但不限于租赁、借款、劳动债务），由全体合伙人承担无限连带责任。前款执业债务，以本企业财产对外承担责任后，有故意或者重大过失的合伙人应当在【待填】日内按本协议向本企业赔偿相应损失。‘故意或者重大过失’包括【待填：违反执业准则的典型情形】，但不排除行业主管部门或司法机关依据执业准则认定的其他情形。本条不构成对债权人的免责承诺。」

最强反方：相对方主张“特殊普通合伙就是全体有限责任”。第 55 条明确它仍是普通合伙企业，只是第 57 条对执业过错作特别规定。现有依据不支持把丙档或乙档改成有限责任。

## 节点 4　执业风险基金与职业保险（硬闸）

支持依据：第 59 条。会计师所另见 2019 年执业许可办法第 24 条、注册会计师法第 28 条——仅在文本是会计师所时点名，不写成一切专业所的人数或提取比例。

| 文本写法 | 动作 |
| --- | --- |
| 同时约定建立执业风险基金并办理职业保险，基金单独立户，用途限于执业债务 | 核提取比例、账户、保险限额、续保义务；缺数字用 `【待填】` |
| 只买保险或只提基金 | 必须改：二者均须 |
| 基金可挪作分红、差旅或对外投资 | 红线限制用途 |
| 未写单独立户 | 必须改 |
| “未投保则切割失效／合同无效” | 删除该效果句。未投保是必须改的合规缺口，不是已核验的切割失效 |

1993 年试行办法“每年提取业务收入百分之十”已失效，不得写入 `L#`，也不得当成现行提取下限。

修改句：

「本企业应当建立执业风险基金，并办理职业保险。执业风险基金用于偿付合伙人执业活动造成的债务，不得挪作他用，并应当在【待填】银行单独立户管理。提取比例为年度利润（或业务收入）的【待填】％，于每会计年度结束后【待填】日内提取。职业保险的投保人、险种、责任限额、免赔额和续保义务见附件。未按本条提取或投保的，执行事务合伙人应在【待填】日内补正，并按【待填】向其他合伙人承担违约责任；本条不解释为执业责任切割因此当然失效。」

## 节点 5　出资、利润亏损与执行事务

### 5.1 出资

审查清单，缺一项则该字段不得写成已闭环：

1. 各合伙人认缴额、实缴期限、缴付账户或交付方式。
2. 货币以外出资：评估办法及权属转移义务。知识产权可以作价；商誉、客户资源、实务经验不得写成法定出资，可约定分红系数。
3. 劳务出资：特殊普通合伙的合伙人是普通合伙人，可以用劳务出资，评估办法须载明。若出现“有限合伙人劳务出资”，负触发 `有限合伙企业合同·审查`。
4. 企业财产：适用第 20 条。清算前原则上不得请求分割。
5. 财产份额转让：受让人须具备同等执业资格或符合行业准入；未经一致同意不得对外转让（协议另有约定的除外，但行业准入不得协议放弃）。

### 5.2 利润亏损（补充适用普通合伙规则）

第 55 条第 3 款：本节未规定的适用第一节至第五节。全部利润给部分合伙人或由部分合伙人承担全部亏损：红线删除。第 69 条是有限合伙的例外，**不得搬进**本类型。

一方不参与经营、不承担亏损、到期固定本息：负触发借款原子，或红线删除保底。

修改句：

「利润分配、亏损分担按照附件【待填】办理。合伙协议不得约定将全部利润分配给部分合伙人，或者由部分合伙人承担全部亏损。对内分担比例仅用于合伙人相互追偿，不改变本协议第【待填】条的执业责任分层，也不改变非执业债务的无限连带责任。」

### 5.3 执行事务与内部限制

全体普通合伙人对执行合伙事务享有同等权利。可以设立管委会处理行政事务，但：

- 不得把管委会写成有限合伙的执行事务合伙人排他结构；
- 对执行事务或对外代表权的限制，不得对抗善意第三人（第 37 条）；
- 未登记的内部限权不得写成已经对外生效。

竞业不得写成可以内部豁免。自我交易可依协议或全体一致同意。

## 节点 6　入伙退伙、格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 入伙退伙与吊销证照

第 44、53 条制度运行时复核条号后再写入 `L#`。处理口径：

| 文本写法 | 动作 |
| --- | --- |
| 新合伙人不承担入伙前任何债务 | 红线删除对外豁免。入伙前甲档执业过错债务：新入伙人作为“其他合伙人”以财产份额为限；乙档、丙档不得对外免除 |
| 退伙后对退伙前原因债务一律免责 | 红线删除对外豁免。切割范围仍按三档，不写成退伙即免责 |
| 吊销执业证、停止执业处罚后仍保留合伙人资格 | 必须改：约定当然退伙或除名，并处理未结业务与潜在执业债务 |
| 除名无书面通知、无三十日异议起诉 | 必须补第 49 条 |
| “永远不得退伙” | 必须改 |

修改句：

「新合伙人入伙，除本协议另有约定外，应当经全体合伙人一致同意并订立书面入伙协议。原合伙人应当向新合伙人如实告知经营状况、未决执业索赔和保险／基金情况。新合伙人对入伙前本企业债务，在本协议执业责任分层范围内承担责任：属于执业活动中因故意或者重大过失造成的债务的，新合伙人以入伙后在本企业中的财产份额为限；其余债务，新合伙人承担无限连带责任。该责任不得以本协议对外免除。合伙人被吊销执业证书、丧失本企业所从事专业服务执业资格的，当然退伙。退伙人对基于其退伙前的原因发生的本企业债务，仍按本协议执业责任分层承担责任。」

### 6.2 格式条款

为重复使用而预先拟定、订立时未与对方协商。依据示范文本制作，不当然排除格式条款。

审查：执业切割、除名、永远不得退伙、管辖／仲裁等异常条款是否有足以引起注意的标识，以及是否按要求说明（第 496 条；解释第 10 条）。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在附件 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

第 497 条、第 506 条：造成人身损害或因故意／重大过失造成对方财产损失的免责条款无效。不得把执业切割改写成对客户人身损害或故意／重大过失财产损失的免责。

### 6.3 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的、是否仅行政管理、是否只规制履行行为（第 153 条）。禁止用已失效“效力性／管理性”口诀。合同编通则解释第 16 条本次未核验原文，细分运行时再核，不写入 `L#`。对债权人一律免责、未获许可对外执业、禁入主体、夹带 LP：不改写成有效履行。

## 节点 7　违约、追偿、解散清算与争议

1. 逾期出资、违反执业准则、擅自对外承揽、挪用风险基金：须分别有可执行后果。只有“依法承担违约责任”视为必须改。
2. 企业对过错合伙人的追偿：通知、期限、抵扣分红、未清偿不得再执行事务。
3. 重大执业索赔发生时，执行事务合伙人应书面通报其他合伙人，便于其核对保险和财产份额。通报不是对外免责条件。
4. 违约金不是必得金额。修改句避免“不得调整”。
5. 解散必须清算。注销后原普通合伙人仍按存续期间债务的责任分层承担责任（第 91 条）；破产后普通合伙人仍承担相应无限连带（第 92 条）。不得写成注销即全部免责。
6. 争议解决：出现仲裁条款，不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核。专属管辖可能：只标红旗。
7. 客户信息保密可约定存续期间及退伙后继续有效；期限和违约金用 `【待填】`，不得把“永久”写成唯一合法选择。

| 常见问题 | 对债权人免责；租金误隔离；一般过失切割；只买保险；未建基金写成切割失效；夹带 LP | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（对债权人一律免责、夹带 LP、禁入主体、未获许可对外执业、全部利润／亏损、保底借贷、倒签）；

- `可接受可优化`：仍要给句子，不得只标绿（管委会、复核流程、保密期限、指印）。
