# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、必然完成设立或实缴认定、对方必然接受；编造未给出的认缴额、实缴额、评估值、截止日期；把已失效《合同法》、1993／2018 年《公司法》同条号、2005 年“两年缴足／首次 20%”写入结论；把优先购买／名册登记对抗或对赌条款硬套本类型；输出可履行避税结构。

## 1. 触发、单方立场与成果状态

立场（哪一方出资人／筹办方）、授权、签署状态、主要目标。存量转让、增资主文件、股份发起、股东协议、投资侧同名、已成争或其他负触发写路由，不启动实体审查。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》、1993／2005／2018 年《公司法》同条号或 2005 年两年缴足旧义时记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `公司相关合同`，子级 `出资合同（有限责任公司）`。写定性理由和与股权转让、增资、股份发起、股东协议、投资侧出资的切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识稿中的地产避税／25% 投资额筹划写停笔告知，不填可履行规避结构。

## 4. 主体、授权、出资人与文本版本

主体表：各出资人（自然人／法人）、拟设公司（如已列为一方）、评估机构（如已选定）、共有人、质权人、授权签字人。版本表：正文、附件、章程草案、评估稿、聊天确认；冲突并列，不选对用户有利的一版。

## 5. 给付闭环（本类型必填）

固定检查并回链文本：

- 拟设公司名称（最终以登记为准）、注册资本、经营范围；
- 出资人表：认缴额、实缴额、出资方式、占注册资本比例、缴足截止日期（原则上自成立之日起五年内）；
- 货币：收款账户须为公司（或设立中明确转入公司的专户），不得付给其他出资人；
- 非货币：财产特定化、评估报告、过户／登记义务与日期；不得写“双方认可即实缴”；
- 禁止财产：劳务、信用、姓名、商誉、特许经营权、已设定担保的财产；
- 权属负担：质押、查封、冻结、共有、职务发明；
- 设立费用与设立失败时的债务分担；
- 与章程草案的冲突项及以哪份为准。

缺口标 `G#`，不补商业数字。评估、过户、设立登记写成义务或条件，不写成已经完成。

## 6. 格式条款与强制规范

是否构成格式条款（含示范文本填充版）；提示说明痕迹。强制规范只区分是否导致民事行为无效与是否仅造成履行障碍（未评估、未过户、认缴超五年、设立不能）。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。硬闸六项若文本或事实触及或沉默，必须各有至少一行，不得用色块代替。

## 8. 修改句

按框架六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点、不接受时的红线。未给出的商业数字用 `【待填】`。禁止只给原则、不给句子。禁止输出“双方认可作价视为实缴”“认缴无期限”“互免后债权人不得追索”充当可放行修改句。

## 9. 谈判与签署提醒

谈判顺序：先红线（禁止财产、避税结构、已质押／查封当实缴、互免对抗债权人），再必须改（五年截止日期、评估与过户、认缴／实缴分列、章程同步），最后可优化。签署提醒：评估报告、权属查询时点、公司收款账户、章程草案对照、日期不得倒签、附件清单。不指导倒签或补假评估。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书、代办设立登记、章程整审或效力保证。
