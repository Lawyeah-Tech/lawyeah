# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、必然完成登记对抗、对方必然接受；编造未给出的资本额、住所、表决比例；把已失效《合同法》、1993／2018 年《公司法》同条号、“效力性强制性规定”口诀写入结论；把五年认缴或优先购买硬套本类型；把未登记写成章程未生效；把对赌／一票否决写成一律无效或一律必须入章；写“可以先经营后办证”。

## 1. 触发、单方立场与成果状态

立场（公司／哪一方股东／拟任董监高）、授权、签署状态、主要目标。股东协议、出资本约、增资、存量转让、代持、投资侧章程、已成争或其他负触发写路由，不启动实体审查。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》、1993／2018 年《公司法》同条号或“效力性强制性规定”口诀时记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `公司相关合同`，子级 `公司章程_章程修正案`。写定性理由和与股东协议、出资、增资、股权转让、代持、投资侧章程的切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识稿中的失效口诀、2018 年过半数同意、未登记则未生效，写降级处理，不填可履行规避结构。

## 4. 主体、授权、公司类型与文本版本

主体表：公司、各显名股东（自然人／法人）、拟任法定代表人／董事／监事、授权签字人、隐名出资人（如被提及，不得自动升格为股东）。写明有限公司或股份公司。版本表：设立稿或修正案、旧章程、股东会决议、营业执照、股东协议、聊天确认；冲突并列，不选对用户有利的一版。

## 5. 给付闭环（本类型必填）

固定检查并回链文本：

- 标题名实：设立章程还是修正案；有限公司还是股份公司；
- 法定记载事项是否齐：有限公司按第四十六条；股份公司按第九十五条；法定代表人须写产生和变更办法；
- 名称、住所、注册资本、股东／发起人、经营范围与执照是否一致；
- 设立稿：全体股东签名或盖章；修正案：法定代表人签字盖章 **且** 附决议原件；
- 修改表决基数：有限公司为持有三分之二以上表决权的股东；股份公司为出席会议股东所持表决权的三分之二以上；章程提高但不低于法定门槛；
- 登记对抗：未经登记不得对抗善意相对人，不写未登记则未生效；
- 对赌／一票否决／复杂退出：评估登记障碍，能切开的改留股东协议；
- 隐名／代持：不得直接入章对抗公司；
- 特许许可：无批文则经营范围字段停止。

缺口标 `G#`，不补商业数字。批准、登记写成义务或条件，不写成已经完成。

## 6. 格式条款与强制规范

是否构成格式条款（含登记机关示范文本填充版）；提示说明痕迹。强制规范按民法典第一百五十三条及合同编通则解释第十六条分层，只区分是否导致民事行为无效与是否仅造成登记／履行障碍。禁止使用“效力性／管理性”口诀。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。硬闸六项若文本或事实触及或沉默，必须各有至少一行，不得用色块代替。

## 8. 修改句

按框架六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点、不接受时的红线。未给出的商业数字用 `【待填】`。禁止只给原则、不给句子。禁止输出“未登记则未生效”“对赌一律无效”“可以先经营后办证”“隐名股东即为公司股东”充当可放行修改句。

## 9. 谈判与签署提醒

谈判顺序：先红线（强制规范被删、假决议、隐名直接入章、无许可先经营），再必须改（决议附件、表决基数、执照对照、对赌切开、登记对抗表述），最后可优化。签署提醒：设立稿全体股东签署；修正案决议原件＋法定代表人签字盖章；执照对照表；日期不得倒签；附件清单。不指导倒签或补假决议。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书、代办登记、股东协议／出资／转让整审或效力保证。
