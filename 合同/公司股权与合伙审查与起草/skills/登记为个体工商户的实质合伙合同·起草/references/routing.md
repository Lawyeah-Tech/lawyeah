# 边界与路由

本技能只审查 **合伙合同相关 / 登记为个体工商户的实质合伙合同** 的待签文本。中文展示名是「审查登记为个体工商户的实质合伙合同（合伙合同相关）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 一方出资不显名、不参与经营、不承担合伙债务或仅以出资为限 | `隐名合伙合同·审查`。不得把“不经营不担债”改成可履行后留在本技能 |
| 不登记个体工商户、不以个体户字号对外、只适用民法典合伙合同 | `个人合伙合同·审查`。不得用个体户执照、变更经营者专条继续当个人合伙审 |
| 拟领取普通合伙企业执照、名称标明“普通合伙” | `普通合伙企业合同·审查` |
| 出现有限合伙人、认缴为限 | `有限合伙企业合同·审查` |
| 执业故意或重过失切割其他合伙人责任、名称标“特殊普通合伙” | `特殊的普通合伙企业合同·审查`。P1：专业版未装则 `unavailable`，提示，不得用本技能硬套 |
| 劳务出资已成主轴且无个体户登记外观 | `劳务出资型合伙合同·审查`。P1；未装则 `unavailable` |
| 股权激励型合伙主文件 | `股权激励型合伙合同·审查`。P1；未装则 `unavailable` |
| 不参与经营、不承担亏损、到期固定本息；双方均为企业 | `或企业间借款` |
| 不参与经营、不承担亏损、到期固定本息；双方为自然人 | `不参与经营不承担亏损到期固定本息→自然人之间借款` |
| 只拿固定报酬、不担亏损、无合伙财产份额 | `只拿固定报酬不分担亏损无合伙人决策权→个人劳务（雇佣）` |
| 人格从属、工资社保、劳动合同文本 | `人格从属＋工资社保→劳动合同` |
| 律师事务所合伙协议主文件 | `律师事务所合伙协议·审查`。P1；未装则 `unavailable` |
| 公司股东协议、股权治理、注册资本一揽子 | `公司股东协议·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式（出稿后自审） |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争，或用户要散伙清算诉讼策略 | `已出现催告解除函索赔立案开庭仲裁` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

标题写成“隐名合伙”但正文是以个体工商户登记为外观、内部共同经营共担风险：留本技能，标题冲突写入 `C#`，修改句改标题。用户坚持本技能把隐名合伙、个人合伙、合伙企业或借款整案改完：`目标停止`。

本约里夹带一小段借款或劳务报酬：专条交接对应原子；名实分离、对外责任、财产锁定、证照共管条款可继续审。

专业版未收录的 P1 场景不会安装本原子。若用户拿本类型文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
