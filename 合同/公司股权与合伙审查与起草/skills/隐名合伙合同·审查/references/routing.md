# 边界与路由

本技能只审查 **合伙合同相关 / 隐名合伙合同** 的待签文本。中文展示名是「审查隐名合伙合同（合伙合同相关）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止抄 `股权代持合同·审查` method，禁止按有限合伙第 68 条安全港改完。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 有限公司股权挂名、实际出资人与名义股东、显名变更股东 | `股权代持协议·审查`。不得用解释三显名程序继续当隐名合伙审 |
| 股权投资货架代持主文件 | `股权代持合同·审查`。P1；专业版未装则 `unavailable` |
| 拟领取执照、名称标明“有限合伙”、分列 GP/LP（合伙合同相关货架） | `有限合伙企业合同·审查`。不得把未登记隐名改成可履行 LP |
| 同上但用户明确要公司相关合同货架的有限合伙协议 | `合伙协议（有限合伙）·审查`。P1；未装则 `unavailable`。正触发本类型后不两套灌入 |
| 全体显名、共同经营、不领执照 | `个人合伙合同·审查` |
| 普通合伙企业、全员无限连带、无隐名安排 | `普通合伙企业合同·审查` |
| 名称标“特殊普通合伙”，或执业过错切割其他合伙人责任 | `特殊的普通合伙企业合同·审查`。P1；未装则 `unavailable` |
| 主文件是个体户牌照下的实质合伙 | `登记为个体工商户的实质合伙合同·审查`。P1；未装则 `unavailable` |
| 劳务出资作为多名显名合伙人的主给付 | `劳务出资型合伙合同·审查`。P1；未装则 `unavailable` |
| 不承担经营风险、到期固定本息；双方为企业 | `或企业间借款` |
| 同上；双方为自然人 | `不参与经营不承担亏损到期固定本息→自然人之间借款` |
| 公司股东协议、股权治理一揽子 | `公司股东协议·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式（出稿后自审） |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争，或用户要追索／排除执行／散伙诉讼策略 | `已出现催告解除函索赔立案开庭仲裁` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

隐名合伙文本里夹带一小段借款或保证：专条交接对应原子；对外责任、不参与经营、查阅、追偿条款可继续审。用户坚持本技能把代持、有限合伙、个人合伙或借款整案改完：`目标停止`。
