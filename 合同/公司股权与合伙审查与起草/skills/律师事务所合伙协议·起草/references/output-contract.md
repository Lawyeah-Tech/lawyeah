# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受、必然获许可或必然可执行；编造未给出的出资、基金、期限；把已失效 1996/2004《合伙律师事务所管理办法》或 1996 年《律师法》写入结论；把对内追偿写成对债权人免责；把签字写成已经获得执业许可证；把有限合伙或非律所特殊普通合伙当成已完成的本类型审查。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查律师事务所合伙协议（公司相关合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回 1996/2004《合伙律师事务所管理办法》、1996 年《律师法》原文或 1997 年《合伙企业法》时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `公司相关合同`，子级 `律师事务所合伙协议`。定性理由、易混切开结果（有限合伙、非律所特殊普通合伙、普通合伙企业、个人所、国资所、股东协议、借款）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、资格、许可与文本版本

主体表：姓名、执业证号、专职或兼职、执业年限、处罚记录、拟任负责人。资格表：是否均为执业律师自然人、是否出现法人/非律师/LP/挂名。许可表：普通合伙所或特殊的普通合伙所、拟申请机关、名称检索。版本表：正文、出资清单、合伙人名册、章程草案、聊天确认；冲突并列。未核执业许可或处罚：该签署能力字段停止。

## 5. 执业责任、出资、利润亏损与入伙退伙

组织形式锁定结果；故意或重大过失是否定义；律所先赔再追偿是否写明；出资与缴付；利润亏损是否禁止全部归一方；风险基金与职业保险；入伙退伙报批；案卷交接。缺口标 `G#`。不输出有限合伙 LP 避风港或普通合伙企业执照主路径。

## 6. 格式条款与强制规范

是否构成格式条款。强制规范只按第 153 条和解释第 16 条区分，不用失效“效力性/管理性”口诀。未获许可执业、非律师当合伙人、LP 结构、对债权人一律免责只保留识别与停笔。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把框架里“签字盖章后生效”“以市场监管登记为准”写成已核验口径。

## 9. 谈判与签署提醒

谈判顺序：先红线（LP、非律师/法人/挂名、未许可执业、对债权人一律免责、全部利润/亏损、保底借贷），再必须改（执业责任按组织形式、定义故意或重大过失、第十七条事项、许可日起生效、变更报批、风险基金、案卷交接），最后可优化。签署提醒：全体合伙人签名；合伙人名册与执业证痕迹、出资确认、风险基金/保险、负责人产生办法入附件；设立申请义务主体、期限。不指导倒签或补假许可。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书、吊证听证策略或效力保证，也不是有限合伙或非律所特殊普通合伙审查。
