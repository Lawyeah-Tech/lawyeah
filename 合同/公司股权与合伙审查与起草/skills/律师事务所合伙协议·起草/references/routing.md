# 边界与路由

本技能只审查 **公司相关合同 / 律师事务所合伙协议** 的待签文本。中文展示名是「审查律师事务所合伙协议（公司相关合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 公司相关合同项下有限合伙；GP/LP；私募认缴为限；财务投资人避风港 | `合伙协议（有限合伙）·审查`。P1：专业版未装则 `unavailable`，提示，不得用律所专条硬套 |
| 会计师、建筑师等非律师专业所特殊普通合伙；无律师执业证、无司法行政许可主线 | `特殊的普通合伙企业合同·审查`。P1；未装则 `unavailable` |
| 领取普通合伙企业营业执照、名称标明“普通合伙”、无律所许可 | `普通合伙企业合同·审查` |
| 有限合伙企业主文件（合伙合同相关货架） | `有限合伙企业合同·审查` |
| 不领执照、不以企业或律所名义登记、只适用民法典合伙合同 | `个人合伙合同·审查` |
| 个人律师事务所（一人设立、设立人无限责任）或国家出资设立的律师事务所 | 负触发；提示不是本任务，不按合伙所资格和执业切割改完 |
| 公司股东协议、股权治理、注册资本一揽子 | `公司股东协议·审查` |
| 不参与经营、不承担亏损、到期固定本息；双方均为企业 | `或企业间借款` |
| 不参与经营、不承担亏损、到期固定本息；双方为自然人 | `不参与经营不承担亏损到期固定本息→自然人之间借款` |
| 只拿固定报酬、不担亏损、无合伙财产份额 | `只拿固定报酬不分担亏损无合伙人决策权→个人劳务（雇佣）` |
| 人格从属、工资社保、劳动合同文本 | `人格从属＋工资社保→劳动合同` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式（出稿后自审） |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争，或吊证、停业整顿听证，或用户要散伙清算诉讼策略 | `已出现催告解除函索赔立案开庭仲裁` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

律师事务所合伙协议里夹带一小段借款或劳务报酬：专条交接对应原子；设立许可、合伙人资格、执业责任、禁止 LP 条款可继续审。用户坚持本技能把有限合伙、非律所特殊普通合伙或普通合伙企业整案改完：`目标停止`。
