# 非核心资产转让·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《物权法》《担保法》及其解释、1984 年《专利法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **公司相关合同 / 资产转让合同（单项_非核心资产）** 己方稿，出稿后用本类型硬闸自审。交付草稿、未决项、自审风险表和自审后修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文名必须是「审查资产转让合同（单项_非核心资产）（公司相关合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类起草、待签文本签前审查、履约交底、争议文书、有效性保证、把股权转让/控制权收购/营业资产收购改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **买资产不承继主体债务**：买方只取得清单内特定资产。除书面列明且经债权人同意的特定负债外，卖方公司借款、税款、劳动、诉讼、或有负债仍由卖方承担。禁止“乙方概括承受甲方全部债权债务/员工/资质”。
2. **与股权转让 / 控制权 / 资产收购切开**：转让股权或股东资格 → `公司股权转让·审查`。收购足以取得控制权的目标公司股权 → `股权收购合同（含控制权转移）·审查`。收购构成业务线或营业的一揽子资产、假定债务、员工安置 → `资产收购合同·审查`。不得删掉股权或营业条款后硬套。
3. **交割清单**：必须有《标的资产清单》和《交割确认单》：名称、规格或权属证号、数量、现状、权属证明、交付或登记节点、风险转移。禁止“相关资产一并转让”或“以现场为准”。
4. **权属与权利负担**：抵押、质押、查封、租赁、居住权、共有、在先独占许可未核，不得写成洁净产权。
5. **合同生效 ≠ 权利变动**：签字不当然等于不动产过户、专利权登记生效、商标核准公告或机动车登记对抗。
6. **名为转让实为借贷 / 逃废债 / 阴阳 / 规避限购**：回购+过户作担保、明显不合理低价掏空、两套价款、借名或规避限购：只告知。用户坚持：整体停止。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签正文，尚未签署，尚未成争，核心给付是公司处置单台设备、单项知识产权、单套不构成业务的房屋或土地使用权，买方不取得卖方股权、控制权或营业，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 转让股权、股东资格、出资额 → `公司股权转让·审查`；
- 收购目标公司股权并以取得控制权为目的 → `股权收购合同（含控制权转移）·审查`；
- 一揽子资产足以构成业务线或营业，夹带员工、客户合同、资质、假定债务 → `资产收购合同·审查`（P1；专业版未装则 `unavailable`）；
- 国有资产进场、评估挂牌协议转让为主轴 → `国有资产转让合同（协议转让）·审查`（P1；未装则 `unavailable`）；
- 打包收购债权或不良资产包 → `债权收购合同·审查`（P1；未装则 `unavailable`）；
- 主给付是债权让与、通知债务人为轴 → `主给付是债权让与通知债务人为轴→`；
- 商家之间常规存货或标准设备购销、无公司处置语境 → `商家之间常规存货或标准设备购销无公司处置语境→`；
- 主文件是存量房买卖本约（户口/网签过户主路径） → `主文件是存量房买卖本约（户口网签过户主路径）→`；
- 整份文本只是专利权转让本约 → `整份文本只是专利权转让本约→`；
- 整份文本只是注册商标转让本约 → `整份文本只是注册商标转让本约→`；
- 过户+回购担保借款 → `过户+回购担保借款→`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `已出现催告解除函索赔立案开庭仲裁` 或对应专项领域。

逃废债、阴阳价款、规避限购、让与担保流押：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（转让方或受让方择一）；相对方；全文及清单/权属件/交割确认单版本；标的是否单项且不构成业务；是否写买方承受卖方债务、员工或资质；权利负担查询痕迹；价款与节点；内部决议；不可接受事项；法域、标的所在地与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价款、期限、证号用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验买卖定义、债务转移须同意、物权变动、权利瑕疵、格式条款、定金上限、专利/商标登记；`search_practiced` 只补审查反例；`search_template` 只借清单/交割栏目。不虚构案件系统。

`search_law` 对上述法律结论为 required 级：不可用时不拒绝执行，只停止效力字段。返回已失效《合同法》《物权法》《担保法》或其解释、1984 年《专利法》、2003 年《企业国有产权转让管理暂行办法》时记为噪声，不得写入 `L#`。


## 起草模式

本原子只承担本类型起草。待签评改转 `非核心资产转让·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `非核心资产转让·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 买方只取得清单内特定资产。除书面列明且经债权人同意的特定负债外，卖方公司借款、税款、劳动、诉讼、或有负债仍由卖方承担。
- 《标的资产清单》和《交割确认单》须写名称、规格或权属证号、数量、现状、权属证明、交付或登记节点、风险转移。
- 合同生效 ≠ 权利变动：签字不当然等于不动产过户、专利权登记生效、商标核准公告或机动车登记对抗。

### 附件必附

- 标的资产清单
- 交割确认单
- 内部决议
- 权属证明

### 禁止出现

- “乙方概括承受甲方全部债权债务／员工／资质”
- “相关资产一并转让”或“以现场为准”
- 抵押、质押、查封、租赁、居住权、共有、在先独占许可未核却写成洁净产权
- 回购＋过户作担保、明显不合理低价掏空、两套价款、借名或规避限购的可履行结构

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`基本面.md` 把股权转让写成资产转让子类时，子公司股权负触发 `公司股权转让·审查`。`基本面.md` 写专利权/商标权登记“仅对抗第三人”时，按专利法（2020 修正）第 10 条、商标法（2019 修正）第 42 条纠正：专利转让自登记之日起生效，商标专用权自核准公告之日起由受让人享有。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 本任务起草模式；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有单项非核心资产文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。股权、控制权、营业收购、国资进场、债权包、专项知产本约负触发。

### 2. 主体、决议与资质

签约名、履行名、付款名、发票名分列。内部决议未附：该签署能力字段停止。国资/划拨/特许未核：字段停止。

### 3. 标的、负担与交割清单

清单可核验；负担未核不得写成无负担。

### 4. 债务隔离与对价

买方不概括承债。价款与交割节点绑定。

### 5. 合同生效与权利变动

批准、登记写成义务和条件，不写成已经完成。

### 6. 格式条款、强制规范与停笔结构

让与担保、逃废债、阴阳、限购停笔。无核验引文则法律结论字段停止。

### 7. 违约、解除与争议

逾期交付、逾期付款、权属不能转移分别有后果。不选定唯一法院充作意见。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把概括承债、逃废债、阴阳、规避限购或让与担保改成可履行结构。
- `字段停止`：法域、动态规则、国资进场、划拨批准、权属查询未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
