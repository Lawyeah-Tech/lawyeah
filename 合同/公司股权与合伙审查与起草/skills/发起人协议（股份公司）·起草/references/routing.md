# 边界与路由

本技能只审查 **公司相关合同 / 发起人协议（股份公司）**。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 拟设有限责任公司；出资／设立协议；五年认缴、无股份面值 | `出资合同（有限责任公司）·审查` |
| 已设立公司新增资本、资金进公司、新发行权益换投资款 | `增资合同·审查` |
| 主文件是公司章程或章程修正案整份评改 | `公司章程_章程修正案·审查` |
| 成立后的股东协议、治理一揽子 | `公司股东协议·审查` |
| 估值调整、对赌、未来股份公司无条件回购 | `出资合同·审查` |
| 向社会公开募集、招股、承销、保荐、发行核准主文件 | 证券发行专项；本技能不填招股实体结论 |
| 买特定资产、不承继原公司主体 | `非核心资产转让·审查` 或 `资产收购合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、缴款或递件履约节点 | 本套导航的履约步骤 |
| 设立登记完成或设立失败后追缴款、分担费用、催告解除索赔立案仲裁 | 公司争议领域；不填签前十节 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

专业版未收录的 P1 场景不会作为本原子的实体审查对象。若用户拿公开募集招股或对赌主文件来找本技能：输出 `unavailable` 或负触发路由，不得用本类型硬套。

本技能不得转去加载有限出资、增资或章程双文件完成本类型审查。
