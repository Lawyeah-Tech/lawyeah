# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、必然获准设立或上市、对方必然接受；编造未给出的股份数、净资产、折股比例；把已失效《合同法》、1993／2018 年《公司法》同条号、有限公司五年认缴、2018 年创立大会＋验资必经程序写入结论；把增资或章程整审条款硬套本类型。

## 1. 触发、单方立场与成果状态

立场（某一发起人／牵头发起人／原公司控股股东）、授权、签署状态、新设或整体变更、主要目标。有限出资、增资、章程整审、公开募集、对赌、已成争或其他负触发写路由，不启动实体审查。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》、1993／2018 年《公司法》同条号、2005 年“两年缴足”或 2018 年创立大会旧程序时记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `公司相关合同`，子级 `发起人协议（股份公司）`。写定性理由和与有限出资、增资、章程整审、股东协议、对赌、公开募集的切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。违法折股或劳务出资写停笔告知，不填可履行规避结构。

## 4. 主体、授权、发起人与文本版本

主体表：各发起人（姓名或名称、证照、境内住所、认购股份、出资方式）、授权签字人、整体变更场景的原公司与原股东是否全体到齐、国资或外资审批主体。版本表：正文、认购清单、审计／评估报告、折股表、章程草案、股东会决议、聊天确认；数字冲突并列，不选对用户有利的一版。

## 5. 给付闭环（本类型必填）

固定检查并回链文本：

- 拟设股份公司名称、设立方式（发起／定向募集／整体变更）；
- 发起人人数、半数以上境内住所、书面协议是否覆盖全体；
- 认购股份数、面值或股本、出资方式、缴款账户、**成立前全额缴足**日期；
- 非货币评估与权属转移是否早于登记申请；
- 整体变更：基准日、净资产口径、折股本、资本公积、持股对照、概括承继、过渡期禁令；
- 设立费用成功／失败分担与对外连带；
- 成立大会（或发起设立下由本协议规定的会议）通知、出席、表决、董事会三十日内申请登记。

缺口标 `G#`，不补商业数字。缴足、过户、登记写成义务或条件，不写成已经完成。

## 6. 格式条款与强制规范

是否构成格式条款（含示范文本或中介填充版）；提示说明痕迹。强制规范只区分是否导致民事行为无效与是否仅造成履行障碍（未缴足不能登记、折股超净资产、人数住所不符）。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。硬闸五项若文本或事实触及或沉默，必须各有至少一行，不得用色块代替。

## 8. 修改句

按框架六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点、不接受时的红线。未给出的商业数字用 `【待填】`。禁止只给原则、不给句子。禁止输出“自公司成立之日起五年内缴足”充当本类型默认修改句。

## 9. 谈判与签署提醒

谈判顺序：先红线（股本高于净资产、成立前不缴足、劳务或担保财产出资、漏签拟上市主体股东、公司对赌付款），再必须改（认购表、住所、成立大会程序、失败费用连带、过渡期），最后可优化。签署提醒：全体发起人亲签或盖章、决议与审计附件、缴款账户、日期不得倒签。不指导倒签或补假决议。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书、代办设立登记、章程整审或效力保证。
