# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、未签股东当然受约束、公司回购一定能划付、对方必然接受；编造未给出的比例、定价、期限；把已失效《合同法》、1993／2018 年《公司法》同条号、“效力性强制性规定”口诀写入结论；把章程修改程序、五年认缴或优先购买交割硬套本类型；把股东保底或“公司无条件回购且无需减资”写成可履行；写“本协议已解散公司”。

## 1. 触发、单方立场与成果状态

立场（哪一方股东／是否同时代表公司）、授权、签署状态、主要目标。章程整审、出资本约、增资、存量转让、对赌主文件、投资侧同名、已成争或其他负触发写路由，不启动实体审查。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》、1993／2018 年《公司法》同条号或“效力性强制性规定”口诀时记噪声，不得写入 `L#`。九民纪要无核验原文时记待核，不得默写。

## 3. 类型与加载路径

父级 `公司相关合同`，子级 `股东协议`。写定性理由和与章程、出资、增资、股权转让、对赌主文件、投资侧同名的切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识稿中的失效口诀、PE 优先清算／反稀释默认清单、与公司对赌一律无效，写降级处理，不填可履行规避结构。

## 4. 主体、授权、签署范围与文本版本

主体表：各签署股东（自然人／法人）、未签署股东（单列，不得升格为受约束方）、目标公司（是否盖章）、授权签字人、隐名出资人或配偶（如被提及）。版本表：股东协议正文、章程、名册、执照、聊天确认；冲突并列，不选对用户有利的一版。

## 5. 给付闭环（本类型必填）

固定检查并回链文本：

- 标题名实：股东之间的治理契约，不是章程、出资本约或转让本约；
- 签署范围：名册股东是否全部签署；未签股东点名不受约束；
- 公司是否列为一方：公司义务（配合入章、提供信息、履行回购）缺盖章则字段停止；
- 与章程冲突：对内违约救济 vs 对外不得对抗善意相对人；可入章事项与不可入章事项切开；
- 固有权利：知情权、表决权、利润分配请求权不得完全取消；
- 保底／固定回报：不承担经营风险＋到期本息则红线，不改成可履行股东保底；
- 公司回购／现金补偿：须减资或依法分配利润；禁止无条件划付公司资金；
- 与股东回购：触发、定价、期限、付款责任人须特定化；
- 一致行动／一票否决：事项清单＋僵局出口；解散请求只点名法定条件；
- 转让限制：可执行通知；不得永久禁转且无退出；不展开转让本约交割。

缺口标 `G#`，不补商业数字。批准、减资、入章写成义务或条件，不写成已经完成。

## 6. 格式条款与强制规范

是否构成格式条款（含投资机构重复使用的股东协议填充版）；提示说明痕迹。强制规范按民法典第一百五十三条及合同编通则解释第十六条分层，只区分是否导致民事行为无效与是否仅造成履行／登记障碍。禁止使用“效力性／管理性”口诀。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。硬闸六项若文本或事实触及或沉默，必须各有至少一行，不得用色块代替。

## 8. 修改句

按框架六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点、不接受时的红线。未给出的商业数字用 `【待填】`。禁止只给原则、不给句子。禁止输出“未签股东当然受约束”“公司无条件回购无需减资”“股东保底可强制划付”“本协议已解散公司”充当可放行修改句。

## 9. 谈判与签署提醒

谈判顺序：先红线（剥夺固有权利、股东保底、公司无条件回购、未签股东冒充已约束、永久禁转无退出），再必须改（签署范围、章程切开、否决事项清单、僵局出口、股东回购特定化），最后可优化。签署提醒：签署页与名册对照；公司盖章须有内部决议；章程同步义务有期限；日期不得倒签；附件清单。不指导倒签或补假签署。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本任务只出审查意见和修改句，不出整份起草终稿。不是履约交底、争议文书、代办减资或入章、章程／出资／转让／投资侧整审或效力保证。
