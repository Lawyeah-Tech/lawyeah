# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然完成减资／登记；编造未给出的价格、年化、期限；把已失效《合同法》或其解释写入结论；写“公司无条件现金回购无需减资”；写公司回购当然无效或股东回购当然无效；把未登记写成协议未生效；把存量转让或对赌主文件当成已完成的本类型审查。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查股权回购协议（公司相关合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、1993／2018 年《公司法》同条号旧义、2014 年注册资本登记管理规定时记噪声，不得写入 `L#`。九民纪要第五条、2023 年第八十九条未核验原文前不得写入 `L#`。

## 3. 类型与加载路径

父级 `公司相关合同`，子级 `股权回购协议`。定性理由、易混切开结果（存量转让、对赌主文件、股东协议、增资、代持）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准：公司回购不写成当然无效；对赌主场景转出。挂靠、抽逃、流质、规避准入写停笔告知，不填可履行结构。

## 4. 主体、授权、义务人与文本版本

主体表：目标公司、回购权利人、回购义务人（公司／创始人／其他股东分列）、担保人或配偶、授权签字人。义务人定性：公司付款还是股东付款，是否连带或补充。版本表：正文、增资／投资协议、章程、决议、放弃优先购买声明、聊天确认；冲突并列。未见公司盖章而公司被写成付款人：配合义务字段停止。

## 5. 给付闭环

标的股权数量或比例、触发条件及核验标准、价格公式、付款义务人、公司付款是否绑定减资或可分配利润、股东回购的通知与优先购买、交割与名册／登记、发票与税负。缺口标 `G#`，不补商业数字。批准、减资、登记写成生效条件或期限，不写成已经完成。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹；异常条款。强制规范只按民法典第一百五十三条和合同编通则解释第十六条区分，不用失效“效力性／管理性”口诀。资本维持、减资、利润分配、禁止流质只作为修改理由，不代替修改句。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。禁止输出无修改句的色块表。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。禁止只给原则、不给句子。禁止写出“公司应在【待填】日内无条件支付且无需减资或利润分配”。

## 9. 谈判与签署提醒

谈判顺序：先红线（公司无条件划付、流质、名股实债、抽逃），再必须改（义务人拆分、减资／利润分配绑定、触发可核验、价格公式、优先购买闭合），最后可优化（配偶同意、股权质押担保、拖售替代救济）。签署提醒：目标公司是否盖章、股东会或书面一致决定、减资方案或利润分配决议附件、优先购买放弃声明、日期与附件清单。不指导倒签或补假决议。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书、效力保证，也不是存量转让本约或对赌主文件审查。
