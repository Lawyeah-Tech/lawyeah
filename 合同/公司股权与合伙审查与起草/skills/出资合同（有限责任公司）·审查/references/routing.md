# 边界与路由

本技能只审查 **公司相关合同 / 出资合同（有限责任公司）**。主线是向公司投入资本换股权，价款／财产进公司。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 价款进原股东、存量股权让与、优先购买／名册登记为主给付 | `公司股权转让·审查` |
| 已设立公司新增资本、稀释原股东、增资协议／新股认购为主文件 | `增资合同·审查` |
| 股份有限公司发起、股款、创立大会 | `发起人协议（股份公司）·审查` |
| 主文件是股东协议：投后治理、否决权、随售／拖售、竞业 | `公司股东协议·审查` |
| 用户要整份代审章程或章程修正案 | `公司章程_章程修正案·审查`；本任务只并列出资条款冲突 |
| PE／估值调整／对赌／回购一揽子，或投资侧同名《出资合同》 | `出资合同·审查` 或投资并购侧 |
| 无文本、本类型条件已谈妥、要出己方稿 | `出资合同（有限责任公司）·起草` |
| 已签未争、问缴资日／催缴留痕 | 本套导航的履约步骤 |
| 已设立后追缴、失权、抽逃索赔、立案仲裁 | 公司争议领域；不填签前十节 |
| 地产项目买股权规避土增税或 25% 投资额 | 停笔告知，不改写成可履行结构；用户坚持则整体停止 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

专业版未收录的投资侧 P1 场景不会作为本原子的实体审查对象。若用户拿这些文本来找本技能：输出 `unavailable` 或负触发路由，不得用本类型硬套。

本技能不得转去加载股权转让、增资或投资侧双文件完成本类型审查，也不得把优先购买／名册登记对抗写成出资默认主路径。
