# 出资合同（有限责任公司）·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构，不证明本约条款已被接受。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、1993／2005／2018 年《公司法》同条号旧义（董事任期、监事任期、经理职权、两年缴足／首次 20%）当作现行规则。不得把第八十八条股权转让出资责任写成出资合同的默认主路径。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **公司相关合同 / 出资合同（有限责任公司）** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。`depends-on` 为空。不要求先跑导航。

主线是**向公司投入资本换股权**，不是存量股权买卖。

不交付：他类审查、从零起草、履约交底、争议文书、有效性或必然设立／实缴认定保证、章程整份代审。

## 工作边界

正触发：已有可读待签文本要评改，；尚未签署，尚未成争；核心给付是出资人将货币或依法可估价、可转让的非货币财产投入拟设立有限责任公司（或新设认缴路径），**价款／财产进公司**，换取股权，注册资本因认缴而形成。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 价款进原股东、存量股权让与 → `公司股权转让·审查`；
- 已设立公司新增资本作为主文件 → `增资合同·审查`；
- 股份有限公司发起人协议 → `发起人协议（股份公司）·审查`；
- 主文件是股东协议（投后治理、否决权、随售拖售）→ `公司股东协议·审查`；
- 用户要整份代审章程或章程修正案 → `公司章程_章程修正案·审查`（本任务只处理与出资条款的冲突并列）；
- PE／估值调整／对赌／回购一揽子或投资侧同名《出资合同》 → `出资合同·审查` 或投资并购侧；
- 无文本、本类型条件已谈妥、要出己方稿 → `出资合同（有限责任公司）·起草`；
- 已签只问缴资日、催缴留痕 → 本套导航的履约步骤；
- 已成争（催告补缴、失权、抽逃索赔、诉讼仲裁）→ **公司争议领域**，不填签前十节。

地产项目“买股权规避土增税或 25% 投资额限制”、劳务／信用／姓名／特许经营权出资、内部互免对抗债权人：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；代表哪一方出资人（或拟设公司筹办方）；相对方与是否列拟设公司；正文、附件、章程草案版本；认缴／实缴／方式／截止日期；不可接受事项；法域与拟签时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的认缴额、实缴额、评估值、截止日期用 `【待填】`，不编造。

## 本类型硬闸

审查过程必须逐项点名，每闸必须有修改句，不得用优先购买／名册登记对抗或投资人保护清单代替：

1. **出资 ≠ 股权转让 ≠ 增资 ≠ 投资侧同名**：价款／财产进公司、新设认缴 → 本类型；价款进原股东 → `公司股权转让·审查`；已设公司增资主文件 → `增资合同·审查`；股份公司发起 → `发起人协议（股份公司）·审查`；PE／估值／对赌 → `出资合同·审查`。不得把地产“买股权规避土增税”改成可履行筹划。
2. **出资财产可估价可转让**：货币、实物、知识产权、土地使用权、股权、债权等。劳务、信用、自然人姓名、商誉、特许经营权、已设定担保的财产不得出资。非货币必须评估作价，不得“双方认可作价即实缴完毕”。
3. **五年认缴**：有限公司全体股东认缴原则上自成立之日起五年内缴足。修改句写清认缴额、实缴额、截止日期。不得默认“认缴无期限”。
4. **未出资／抽逃责任**：对公司补足并赔偿损失；对其他股东违约；对债权人在未出资本息范围内补充赔偿。内部“互免出资”不能对抗公司／债权人。
5. **权属与负担**：用于出资的财产须可过户至公司名下。已质押／查封或职务发明权属不清：该出资字段停止，不写“已经实缴”。
6. **章程与股东协议衔接**：出资合同与章程冲突须并列，修改句指定以哪份为准并同步改章程。`公司章程_章程修正案·审查` 不在本任务整份代审。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验 2023 年《公司法》第四十七条至第五十四条（五年认缴、非货币评估、按期缴纳、催缴失权、抽逃、加速到期），公司登记管理实施办法第五条、第八条，市场主体登记管理条例第十三条；第八十八条仅用于与转让切开。`search_practiced` 补审查反例；`search_template` 只借修改句结构。不虚构案件系统。

`search_law` 对法律结论为 required 级节点：不可用时不拒绝执行，只停止法律结论字段。返回 1993／2005／2018 年《公司法》同条号、已失效《合同法》或其解释、2005 年“两年缴足／首次 20%”时记为噪声，不得写入 `L#`。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、设计买股权规避土增税或 25% 投资额、把劳务／信用／姓名／特许经营权写成可出资、把已质押／查封财产改成已经实缴、用内部互免对抗公司／债权人、保证有效或必然完成设立登记。
- `字段停止`：评估报告、权属／负担查询、认缴实缴截止日期、章程草案、地方登记或外资规则未核验；关键出资额缺失。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或文本已滑入存量转让／增资／股份发起／对赌。

生存级出资额或个人无限连带且用户拒绝升级：停止“可以签署”建议。
