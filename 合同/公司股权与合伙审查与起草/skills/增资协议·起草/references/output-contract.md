# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受、登记或减资必然办成；编造未给出的估值、认购额、补偿公式；把已失效《合同法》及其解释、1993／2018 年公司法同条号旧义写入结论；把公司无条件回购改成可履行；把股权转让、出资认缴单独、Term Sheet 或对赌本约按本技能改完。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。成果名称写「审查增资协议（股权投资相关合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、1993／2018 年公司法同条号、2014 年注册资本登记管理规定时记噪声，不得写入 `L#`。第六十六条、第五十三条、股东名册条号、九民纪要对赌专节未核验的，不写入 `L#`。

## 3. 类型与加载路径

父级、子级、定性理由、易混切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读其他类型，未打开 `出资合同·审查`、`房地产项目股权取得类合同·审查`、`PE股权转让·审查`、`股权代持合同·审查`、`投资意向书·审查`、`PE股东协议·审查`、`对赌协议（盈利预测补偿协议）·审查` 或 `增资合同·审查` 的 method。明股实债、打给创始人再“借回公司”写停笔告知，不填可履行结构。

## 4. 主体、授权、决议与文本版本

主体表：签约名、履行名、收款名（须为目标公司）、发票名、授权签字人、创始人／原股东、ESOP 平台、基金执行事务合伙人。版本表：正文、资本表、发行决议、弃权声明、股东协议草本、披露函、聊天确认；冲突并列，不选对用户有利的一版。投委会或董事会纪要不得写成已形成发行决议。

## 5. 给付闭环与三类分型

必须显式写出三个类型码：

- 优先认购：`PRE-LLC-DEFAULT` / `PRE-LLC-WAIVER` / `PRE-LLC-NOTICE` / `PRE-CO-NONE` / `PRE-CO-GRANT`；
- 估值调整：`VA-INTERFACE` / `VA-STANDALONE` / `VA-FOUNDER-CASH` / `VA-EQUITY` / `VA-COMPANY` / `VA-AND-OR`；
- 交割条件：`CP-RES` / `CP-PRE` / `CP-REG` / `CP-REP` / `CP-DOC` 及交割动作。

并写清：投前／投后估值（发行在外／完全稀释）、计入注册资本与资本公积、期权池由谁稀释、增资款进公司账户、是否同步拆开老股价款。缺口标 `G#`，不补商业数字。批准、登记写成生效条件或双方义务期限，不写成已经完成。`VA-STANDALONE` 不得在本任务填补偿精算。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹；异常条款。强制规范只区分是否导致民事行为无效。与公司对赌不当然无效；无利润、未减资则对公司付款字段停止。无 `search_law` 引文则其他效力字段停止，事实摘录继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔／转出口径。禁止输出无修改句的色块表。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`，不编造。禁止只给原则、不给句子。优先认购、估值调整、交割条件三类必须各至少有一句对应该类型码。

## 9. 谈判与签署提醒

谈判顺序：先红线（无发行决议、增资款打给个人、公司无条件回购、夹带未拆开的转股／出资／Term Sheet／独立对赌），再必须改，最后可优化。签署提醒：公司公章与法定代表人、基金授权页、决议与弃权附件、资本表、股东协议、披露函、公司收款账户、日期不得倒签。不指导补假决议或假弃权。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书或效力保证。复核清单至少包括：是否已有新股发行决议；优先认购属于哪一类且是否已关闭；增资款是否进公司；估值与期权池口径；估值调整属于哪一类及减资／利润路径；交割条件五类是否分列；股东协议是否同日签署；是否夹带未拆开的老股转让、出资认缴或 Term Sheet。
