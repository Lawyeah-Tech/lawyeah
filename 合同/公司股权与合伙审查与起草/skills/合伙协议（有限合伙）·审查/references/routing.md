# 边界与路由

本技能只审查 **公司相关合同 / 合伙协议（有限合伙）** 的待签文本。中文展示名是「审查合伙协议（有限合伙）（公司相关合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 不领执照、不以合伙企业名义登记、只适用民法典合伙合同 | `个人合伙合同·审查`。不得用企业除名、执照专条继续当个人合伙审 |
| 全员普通合伙人、无 LP、名称标“普通合伙” | `普通合伙企业合同·审查`。不得删掉 LP 后硬套，也不得把本类型改成普通合伙 |
| 用户明确只要合伙合同相关货架的有限合伙企业合同审查 | `有限合伙企业合同·审查`。本技能锁定公司相关合同货架；同一 GP/LP 文本正触发后不互踢、不两套灌入 |
| 名称标“特殊普通合伙”，或执业故意／重过失切割其他合伙人责任 | `特殊的普通合伙企业合同·审查`。P1：专业版未装则 `unavailable`，提示，不得用本技能硬套 |
| 隐名合伙、不显名、不登记却要有限责任 | `隐名合伙合同·审查`。P1；未装则 `unavailable` |
| 律师事务所合伙协议主文件 | `律师事务所合伙协议·审查`。P1；未装则 `unavailable` |
| 公司股东协议、股权治理、注册资本一揽子 | `公司股东协议·审查` |
| 主文件是限制性股票激励授予本约 | `上市公司限制性股票激励协议·审查`。持股平台主文件是有限合伙协议则留本任务 |
| 不参与经营、不承担亏损、到期固定本息；双方均为企业 | `或企业间借款` |
| 不参与经营、不承担亏损、到期固定本息；双方为自然人 | `不参与经营不承担亏损到期固定本息→自然人之间借款` |
| 人格从属、工资社保、劳动合同文本 | `人格从属＋工资社保→劳动合同` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式（出稿后自审） |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争，或用户要除名／解散清算诉讼策略 | `已出现催告解除函索赔立案开庭仲裁` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

有限合伙协议里夹带一小段借款或激励授予：专条交接对应原子；GP/LP 身份、执行事务、出资分配、入伙退伙条款可继续审。用户坚持本技能把特殊普通合伙、隐名合伙、普通合伙、个人合伙或股东协议整案改完：`目标停止`。
