# 合伙协议（有限合伙）·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效 1997 年《合伙企业法》条号、已失效《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **公司相关合同 / 合伙协议（有限合伙）** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查合伙协议（有限合伙）（公司相关合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、把普通合伙／特殊普通合伙／隐名合伙改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **GP 无限连带 / LP 认缴为限**：普通合伙人对合伙企业债务承担无限连带责任，协议不得对外改成有限责任或“以出资为限”。有限合伙人以**认缴**出资额为限。对内亏损分担不得写成对外免责。
2. **执行事务**：由普通合伙人执行合伙事务；有限合伙人不执行、不得对外代表。第 68 条八项安全港不视为执行。投决会实质性表决、对外签字或使第三人有理由相信其为 GP：就该笔交易可能承担与 GP 同样的责任。不得把安全港写成“LP 怎么决策都没事”。
3. **出资与分配**：LP **不得**以劳务出资。认缴与实缴分列。有限合伙**可以另约**将全部利润分配给部分合伙人；**不得**约定由部分合伙人承担全部亏损。约定不明按实缴，再平均。
4. **与特殊普通合伙 / 隐名合伙切开**：名称标“特殊普通合伙”、执业故意或重过失切割其他合伙人责任 → `特殊的普通合伙企业合同·审查`。不显名、不登记有限合伙、约定不参与经营且不承担合伙债务 → `隐名合伙合同·审查`。禁止按普通合伙或隐名合伙 method 改完。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签有限合伙协议正文，尚未签署，尚未成争，核心给付是拟设立或变更有限合伙企业并区分 GP/LP，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 不领执照、只适用民法典合伙合同 → `个人合伙合同·审查`；
- 全员无限连带、无 LP 的普通合伙企业 → `普通合伙企业合同·审查`；不得删掉 LP 后硬套，也不得把本类型改成普通合伙；
- 用户明确只要合伙合同相关货架的有限合伙企业合同审查 → `有限合伙企业合同·审查`；本技能锁定公司相关合同货架，正触发后不互踢；
- 名称标“特殊普通合伙”，或执业故意／重过失由过错合伙人无限责任、其他合伙人以财产份额为限 → `特殊的普通合伙企业合同·审查`（P1；专业版未装则 `unavailable`）；
- 隐名合伙、不显名、不登记却要有限责任 → `隐名合伙合同·审查`（P1；未装则 `unavailable`）；
- 律师事务所合伙协议主文件 → `律师事务所合伙协议·审查`（P1；未装则 `unavailable`）；
- 公司股东协议、股权治理、注册资本一揽子 → `公司股东协议·审查`；
- 主文件是限制性股票激励授予本约 → `上市公司限制性股票激励协议·审查`；持股平台若主文件是有限合伙协议则留本任务；
- 不参与经营、不承担亏损、到期固定本息 → `或企业间借款` 或 `不参与经营不承担亏损到期固定本息→自然人之间借款`；
- 无文本、本类型条件已谈妥、要出己方稿 → `合伙协议（有限合伙）·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、除名诉讼、解散清算诉讼或仲裁 → `已出现催告解除函索赔立案开庭仲裁` 或对应专项领域。

向非合格投资者公开募集、承诺保本保收益、倒签或补假登记：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（GP 侧或 LP 侧择一）；相对方；全文及出资表版本；每名合伙人身份；认缴／实缴／出资方式／缴付期限；利润与亏损安排；执行事务与投决会；是否固定回报或保底；拟名称是否标明“有限合伙”；不可接受事项；法域、拟登记地与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的出资额、比例、期限用 `【待填】`，不编造。

宿主可调用时：`search_law` 核验合伙企业法（2006 修订）GP/LP 责任、禁入主体、执行事务与安全港、LP 不得劳务出资、利润另约与亏损禁全担、除名、身份转换；核验格式条款与强制规范；私募基金另核募集与保本禁止。`search_practiced` 只补审查反例。`search_template` 只借栏目结构。不虚构案件系统。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `合伙协议（有限合伙）·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有有限合伙协议，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。特殊普通合伙、隐名合伙、个人合伙、普通合伙企业、股东协议负触发。

### 2. 主体、禁入与人数

签约名与 GP/LP 身份分列。国有独资公司、国有企业、上市公司、公益性事业单位社会团体不得为 GP。人数 2–50，至少一名 GP。

### 3. 执行事务与安全港

写清由谁执行、LP 不得对外代表、第 68 条安全港与投决会实控的分界。

### 4. 出资、认缴实缴与分配

LP 无劳务出资；认缴／实缴分列；全部利润可另约，全部亏损不得由部分合伙人承担。

### 5. 份额变动、除名与身份转换

LP 转让提前通知；除名须其他合伙人一致同意；GP↔LP 转换除另有约定外须全体同意。

### 6. 保底、私募、格式条款与强制规范

固定回报＋不担风险标借贷红旗。公开募集或保本承诺停笔。无核验引文则法律结论字段停止。

### 7. 违约、解散与争议

未出资补缴与除名分列。仅剩 LP 应解散、仅剩 GP 转为普通合伙。不选定唯一法院充作意见。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把禁入主体改成可登记 GP、把 LP 劳务出资／公开募集／保本承诺改成可履行结构。
- `字段停止`：法域、动态规则、登记窗口、私募备案、国资审批、评估作价未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
