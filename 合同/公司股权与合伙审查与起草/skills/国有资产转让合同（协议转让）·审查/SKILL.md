# 国有资产转让合同（协议转让）·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、已失效《企业国有产权转让管理暂行办法》（3 号令）、《物权法》或《担保法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **公司相关合同 / 国有资产转让合同（协议转让）** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查国有资产转让合同（协议转让）（公司相关合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证批准或备案一定办成、保证受让人必然取得可对抗一切第三人的权属。

## 本类型硬闸

1. **评估＋备案／核准**：企业国有资产评估管理暂行办法第六条第六项，资产转让、置换应当评估；第四条走核准或备案。企业国有资产法第四十七条，转让重大财产应当评估。合同必须写评估机构、报告编号、基准日、经核准或备案的评估值。禁止用“估值报告／双方议价／账面净值”替代。
2. **进场为原则，协议转让须适格**：32 号令第二条、第四十八条第一款，一定金额以上生产设备、房产、在建工程、土地使用权、债权、知识产权等对外转让，原则上在产权交易机构公开进行。第四十八条第二款：仅国家出资企业内部或特定行业、确需在国有及国有控股／国有实际控制企业之间非公开转让的，转让方逐级报国家出资企业审核批准。第四十九条金额标准看国家出资企业内部制度。第五十条：公开路径须有底价和公告期。禁止把“双方谈妥”写成已获进场豁免。不得把 32 号令第三十一条产权非公开两情形当成本技能主路径。
3. **批准权限闭合**：企业国有资产法第三十条、第三十二条、第三十三条，重大财产转让按章程和出资人规则决策。非公开还须第四十八条第二款的国家出资企业书面批准。评估核准／备案机关按 12 号令第四条对号。批准文件须核层级、范围、受让方、价格、是否允许非公开。子公司章或口头“集团同意了”不得写成已获有权批准。
4. **与国有股权 `国有股权转让合同（协议转让）·审查` 切开**：32 号令第三条第一项是企业产权转让（出资权益）；第三项才是企业资产转让。企业国有资产法第五十一条“国有资产转让”指出资权益转移，不是本技能主定义。标题写资产、正文是股权／股东资格／工商变更股东 → `国有股权转让合同（协议转让）·审查`。禁止打开或复制 `国有股权转让合同（协议转让）·审查` 的 method。
5. **定价红线**：12 号令第二十二条，成交价以经核准或备案的评估结果为作价参考；低于评估结果 90% 应当暂停，获得原经济行为批准机构同意后方可继续。企业国有资产法第五十五条，最低价以依法评估并经认可或核准的价格为依据。禁止写成“双方同意即可低于 90%”，也禁止写成“低于 90% 一律无效”。
6. **成立 ≠ 生效**：民法典第五百零二条。严禁“签字盖章即生效”。内部决议、有权批准、评估核准或备案应写成生效或交割前提。未办理批准不影响报批义务条款。
7. **禁止规避结构**：名为承包、租赁、合作、抵债实为低价转出国有资产；阴阳合同或抽屉协议；划拨土地使用权未报有批准权人民政府审批、未补出让金或未上缴土地收益即转让（城市房地产管理法第四十条）。只出告知，不改成可履行规避路径。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签国有资产协议／非公开转让正文，尚未签署，尚未成争，核心给付是国有及国有控股、国有实际控制企业的生产设备、房产、在建工程、土地使用权、债权、知识产权等资产或资产包让与，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 核心给付是对企业出资所形成权益、股权、股东资格、产权登记或工商股东变更 → `国有股权转让合同（协议转让）·审查`；
- 普通非国有股权转让 → `公司股权转让·审查`；
- 收购方视角一揽子营业资产、员工安置、客户合同、假定债务 → `资产收购合同·审查`；
- 非国有主体之间单项非核心资产、无国资程序主轴 → `非核心资产转让·审查`；
- 商家之间常规存货或标准设备购销 → `商家之间常规存货或标准设备购销无公司处置语境→`；
- 主给付是打包收购债权 → `债权收购合同·审查`；单纯债权让与、核心是通知债务人 → `主给付是债权让与通知债务人为轴→`；
- 金融企业国有资产 → 财政部令第 54 号路径，本任务不代审；
- 上市公司国有股权 → 不启动本任务；
- 无偿划转 → 不启动本任务；
- 无文本、本类型条件已谈妥、要出己方稿 → `国有资产转让合同（协议转让）·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁或国资流失调查已立案 → `已出现催告解除函索赔立案开庭仲裁` 或对应专项。

以转让为名规避评估、进场或批准，或把明知无权处分、禁止流通物改成可履行交割：只出告知，不改写成可履行路径。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及附件／资产清单／评估／批准版本；标的是资产还是股权；转让方是否国有及国有控股／实际控制企业；拟协议／非公开还是进场；评估报告及核准或备案；内部决议与国家出资企业／国资监管批准；受让方是否国有体系内；价格与评估值；权利负担、租赁优先购买、划拨地或资质资产；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `国有资产转让合同（协议转让）·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有国有资产协议转让文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。国有股权、普通股权、非国有资产买卖、资产收购营业、金融企业国资负触发。

### 2. 评估与备案／核准

报告、基准日、核准或备案文件闭合。估值报告不是评估报告。

### 3. 进场或协议适格

对外原则上进场。非公开须落在第四十八条第二款，并有国家出资企业批准。

### 4. 批准权限与成立生效

内部决议、有权批准、评估备案分列。签字成立，条件成就生效。

### 5. 标的、负担、划拨地与对价

资产清单特定化；抵押查封租赁；划拨地报批；价格与 90% 暂停规则。

### 6. 格式条款与强制规范

无核验引文则法律结论字段停止。规避结构不得改成可履行。

### 7. 违约、解除与争议

审批失败解除、逾期付款、拒绝配合过户分别有后果。或裁或诉改单一。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把应进场改成协议外壳、把国有股权当资产放行、把未评估／未获 90% 同意／阴阳合同／划拨地未报批改成可履行。
- `字段停止`：法域、动态规则、批准层级、进场金额标准、评估真伪、金融企业或军工资质未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
