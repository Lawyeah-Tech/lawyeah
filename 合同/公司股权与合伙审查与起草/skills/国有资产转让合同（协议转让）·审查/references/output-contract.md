# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的价款、评估值、文号；把已失效《合同法》、3 号令、《物权法》《担保法》写入结论；保证批准或备案一定办成；把国有股权、普通股权或非国有资产买卖当成已完成的本类型审查；写“签字盖章即生效可放行”；写“双方同意即可不过场”；写“低于评估值 90% 一律无效”或“双方同意即可低于 90%”。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查国有资产转让合同（协议转让）（公司相关合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、3 号令、《物权法》《担保法》时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `公司相关合同`，子级 `国有资产转让合同（协议转让）`。定性理由、易混切开结果（国有股权 / 普通股权 / 资产收购 / 单项非核心资产 / 动产买卖 / 金融企业国资）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型、未打开 `国有股权转让合同（协议转让）·审查` 的 method。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、批准链条与文本版本

主体表：签约名、履行名、付款名、发票名、授权签字人。国资表：转让方是否国有及国有控股／实际控制企业；受让方是否国有体系内；内部决议；国家出资企业或国资监管批准文号与范围；评估核准或备案机关。版本表：正文、资产清单、评估报告、核准／备案表、批准文件、弃权声明、聊天确认；冲突并列。

## 5. 评估备案、进场／协议适格、给付与成立生效

评估报告与核准／备案是否闭合；协议／非公开是否落在 32 号令第四十八条第二款；公开路径底价与公告期；价格与评估值及 90% 暂停；资产清单是否特定；划拨地是否报批；成立与生效是否拆开；价款是否与批准、负担解除、权属变更挂钩。缺口标 `G#`。不输出股东优先购买或工商变更股东作为主给付。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹。未评估、应进场拒进场、无权批准、阴阳合同、划拨地未报批不得写成可放行。强制规范只按第一百五十三条和合同编通则解释第十六条区分是否导致民事行为无效，不用失效口诀。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把产权非公开两情形直接写成资产协议类型。

## 9. 谈判与签署提醒

谈判顺序：先红线（应进场拒改、无评估、无有权批准、低于 90% 拒暂停、实为股权、规避结构、签字即生效拒拆），再必须改（备案文号、公告期、负担解除、划拨地报批、价款节点、审批失败返还），最后可优化。签署提醒：有权公章与法定代表人或授权代表、内部决议、国家出资企业批准原件核验、评估报告及核准／备案表、资产清单、权利负担查询、优先权人书面放弃。不指导倒签或先签后补手续。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书或效力保证，也不是国有股权、普通股权或非国有资产买卖安排。
