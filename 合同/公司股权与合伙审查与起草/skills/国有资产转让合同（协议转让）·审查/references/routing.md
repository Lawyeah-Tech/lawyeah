# 边界与路由

本技能只审查 **公司相关合同 / 国有资产转让合同（协议转让）** 的待签、国有及国有控股或国有实际控制企业资产协议／非公开转让文本。中文展示名是「审查国有资产转让合同（协议转让）（公司相关合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 对企业出资所形成权益、股权、股东资格、产权登记、工商变更股东；32 号令第三条第一项产权转让 | `国有股权转让合同（协议转让）·审查` |
| 普通非国有股权转让、股东名册变更 | `公司股权转让·审查` |
| 收购目标公司股权并以取得控制权为目的 | `股权收购合同（含控制权转移）·审查` |
| 一揽子营业资产、员工安置、客户合同、资质、假定债务 | `资产收购合同·审查` |
| 非国有主体之间单项非核心资产，无国资评估进场主轴 | `非核心资产转让·审查` |
| 商家之间常规存货或标准设备购销 | `商家之间常规存货或标准设备购销无公司处置语境→` |
| 打包收购债权或不良资产包 | `债权收购合同·审查` |
| 主给付是债权让与，核心是通知债务人 | `主给付是债权让与通知债务人为轴→` |
| 整份文本只是专利权转让本约 | `整份文本只是专利权转让本约→` |
| 整份文本只是注册商标转让本约 | `整份文本只是注册商标转让本约→` |
| 金融企业国有资产转让 | 不代审；提示财政部令第 54 号路径或升级 |
| 上市公司国有股权 | 不启动本任务 |
| 无偿划转 | 不启动本任务 |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `已出现催告解除函索赔立案开庭仲裁` 或对应专项领域 |
| 国资流失调查、刑事或行政诉讼已立案 | 对应专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

资产协议转让正文里夹带一小段债权通知或房屋坐落：可在本类型交割清单里审交付与登记义务；用户坚持本技能把国有股权、普通股权或营业收购整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
