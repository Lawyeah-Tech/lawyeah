# 边界与路由

本技能只审查 **公司相关合同 / 股权代持协议**。主线是实际出资人与名义股东之间的隐名持股本约，约束签署双方，不当然约束公司或其他股东。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 存量股权让与、价款进原股东、优先购买／名册交割为主给付 | `公司股权转让·审查` |
| 价款／财产进公司、新设认缴本约 | `出资合同（有限责任公司）·审查` |
| 已设立公司新增资本、增资协议／新股认购为主文件 | `增资合同·审查` |
| 主文件是章程或章程修正案 | `公司章程_章程修正案·审查` |
| 主文件是股东协议：投后治理、对赌、随售／拖售、竞业 | `公司股东协议·审查` |
| 主文件是股权回购 | `股权回购协议·审查` |
| PE 估值、随售／拖售、投资人保护一揽子包装的代持 | `股权代持合同·审查` 或投资并购侧 |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、问分红转付日／指示留痕 | 本套导航的履约步骤 |
| 确认股东资格、显名之诉、排除执行，或已立案仲裁 | 公司争议领域；不填签前十节 |
| C 端代持退出评估 | 只分流，不回改、不引用其目录 |
| 用代持规避外资／公职人员／上市／特许准入 | 停笔告知；用户坚持可履行规避则整体停止 |

专业版未收录的投资侧 P1 场景不会作为本原子的实体审查对象。若用户拿这些文本来找本技能：输出 `unavailable` 或负触发路由，不得用本类型硬套。

本技能不得转去加载转让、出资或章程双文件完成本类型审查，也不得把优先购买、名册交割或认缴未届写成代持默认主路径。
