# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、必然显名、必然对抗公司或其他股东、对方必然接受；编造未给出的出资额、比例、期限；把已失效《合同法》、2011 年解释三同条号、物权法第一百零六条、2018 年对外转让过半数同意写入结论；把优先购买或名册交割硬套本类型；把隐名股东写成公司股东；写“可以先代持再补办准入”。

## 1. 触发、单方立场与成果状态

立场（实际出资人／名义股东）、授权、签署状态、主要目标。转让本约、出资、增资、章程、股东协议、回购、投资侧代持、已成争或其他负触发写路由，不启动实体审查。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》、2011 年解释三同条号、物权法第一百零六条或 1993／2018 年《公司法》同条号时记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `公司相关合同`，子级 `股权代持协议`。写定性理由和与股权转让、出资、增资、章程、股东协议、回购、投资侧代持的切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识稿中的“上市公司代持一律无效”、质押必然对抗执行，写降级处理，不填可履行规避结构。

## 4. 主体、授权、隐名显名与文本版本

主体表：实际出资人、名义股东、目标公司（非当然签约方）、其他股东（知情与否单列，不得自动升格为协议当事人）、授权签字人。写明有限公司。版本表：代持正文、出资凭证、知情同意函、质押合同、指示函、聊天确认；冲突并列，不选对用户有利的一版。

## 5. 给付闭环（本类型必填）

固定检查并回链文本：

- 标题名实：代持／委托持股，不是转让、出资或托管；
- 隐名／显名身份是否分列，禁止写成双方都是“股东”且可对抗公司；
- 标的：目标公司全称、出资额或股权比例；
- 出资路径、备注、付款凭证原件持有；
- 投资权益归属与分红转付方式、期限；
- 表决／知情权的书面指示机制，名义股东不得擅自对外表态；
- 票证原件（出资证明书、章程、名册摘录）由谁持有；
- 显名条件、其他股东半数以上同意、公司配合义务仅约束名义股东；
- 名义股东不得擅自转让、质押、赠与；处分发生时的索赔，不写当然无效；
- 名义股东死亡、离婚、被执行时的通知与配合，不保证排除执行；
- 准入身份：外资、公职人员、上市／拟上市、特许——命中则停笔。

缺口标 `G#`，不补商业数字。批准、登记、显名写成义务或条件，不写成已经完成。

## 6. 格式条款与强制规范

是否构成格式条款。强制规范按民法典第一百五十三条及合同编通则解释第十六条分层，只区分是否导致民事行为无效与是否仅造成登记／履行障碍。禁止使用“效力性／管理性”口诀。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。硬闸五项若文本或事实触及或沉默，必须各有至少一行，不得用色块代替。

## 8. 修改句

按框架六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点、不接受时的红线。未给出的商业数字用 `【待填】`。禁止只给原则、不给句子。禁止输出“隐名股东即为公司股东”“本协议对公司当然有效”“处分当然无效”“先代持再补办准入”“质押后必然排除执行”充当可放行修改句。

## 9. 谈判与签署提醒

谈判顺序：先红线（规避准入、对抗公司条款、假出资、保证显名），再必须改（出资路径、知情同意、指示与票证、擅自处分索赔、显名程序），最后可优化。签署提醒：双方亲签；出资凭证原件与备注；其他股东知情同意函；日期不得倒签；附件清单。不指导倒签或补假凭证。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书、代办显名登记、转让本约整审或效力保证。
