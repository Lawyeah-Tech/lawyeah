# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、必然赢利、债权人必然不追个人、对方必然接受；编造未给出的出资金额、损益比例、通知期；把已失效《合同法》、民法通则第三十一条、1990 年联营解答写入结论；把合伙企业法治理或借款利率上限硬套本类型；输出可履行保底股东或公职隐名规避结构。

## 1. 触发、单方立场与成果状态

立场（哪一方合伙人）、授权、签署状态、主要目标。合伙企业执照、股东协议、固定本息借贷、固定报酬雇佣、已成争或其他负触发写路由，不启动实体审查。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》、民法通则第三十一条、1990 年联营解答或 1997 年《合伙企业法》同条号时记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `合伙合同相关`，子级 `个人合伙合同`。写定性理由和与普通／有限合伙企业、股东协议、借贷、劳务／雇佣的切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识稿中的“必须书面否则无效”写降级说明：民法典未强制书面。公职禁止经营、挂靠个体户写停笔告知，不填可履行规避结构。

## 4. 主体、授权与文本版本

主体表：各合伙人（须为完全民事行为能力自然人）、是否公职、执行人、未签字但对外经营的人、配偶（如已提及）、授权签字人。版本表：正文、附件、出资清单、聊天确认；冲突并列，不选对用户有利的一版。

## 5. 给付闭环（本类型必填）

固定检查并回链文本：

- 共同事业目的（项目／档口／合作范围），不得写成已完成赢利；
- 合伙人表：出资方式（货币／实物／劳务）、数额或作价、缴付期限、合伙份额；
- 利润分配与亏损分担是否对称；有无保底、固定本息、只分红不亏损；
- 对外连带告知；内部追偿比例；禁止写成债权人不得追索未签字方；
- 执行人、日常权限、重大事项表决（一致决或约定多数决）、监督与异议暂停；
- 合伙财产账户或共管、与个人财产分账、终止前不得分割；
- 退出：定期／不定期、通知期、结算办法、退伙后债务与竞业；
- 解散事由与清算顺序（终止费用 → 合伙债务 → 按 972 分配剩余）。

缺口标 `G#`，不补商业数字。批准、登记、个体户挂名写成义务或告知，不写成已经完成或可履行规避。

## 6. 格式条款与强制规范

是否构成格式条款（含示范文本填充版）；提示说明痕迹。强制规范只区分是否导致民事行为无效与是否仅造成履行障碍或行政管理（公职营利禁止、未设账册）。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。保底、内部免责对抗债权人：用 967／973 与名实认定处理，不引用失效联营解答。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。硬闸六项若文本或事实触及或沉默，必须各有至少一行，不得用色块代替。

## 8. 修改句

按框架六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点、不接受时的红线。未给出的商业数字用 `【待填】`。禁止只给原则、不给句子。禁止输出“只分红不承担亏损”“内部按份后债权人不得追索”“永远不得退伙且无结算”“公职人员隐名由亲属代持”充当可放行修改句。

## 9. 谈判与签署提醒

谈判顺序：先红线（保底、对抗债权人、永远不得退伙、公职规避、执照已办仍当个人合伙），再必须改（损益对称、对外连带告知、执行权限、出资作价、退出通知与清算），最后可优化（配偶知情、共管账户、竞业期限）。签署提醒：身份与行为能力、合伙财产账户、附件出资清单、日期不得倒签。不指导倒签或补假授权。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书、代办合伙企业登记或效力保证。
