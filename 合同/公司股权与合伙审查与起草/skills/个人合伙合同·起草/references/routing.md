# 边界与路由

本技能只审查 **合伙合同相关 / 个人合伙合同**。主线是无法人资格、不领取合伙企业执照的自然人共同事业，适用《民法典》合伙合同章。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 已领取或拟领取普通合伙企业营业执照、企业名称带“普通合伙” | `普通合伙企业合同·审查` |
| 有限合伙、普通／有限合伙人分档、有限合伙人以认缴为限 | `有限合伙企业合同·审查` |
| 主文件是公司股东协议：股权、否决权、随售／拖售、章程治理 | `公司股东协议·审查` |
| 不参与经营、不承担亏损、到期固定本息（自然人） | `不参与经营不承担亏损到期固定本息→自然人之间借款` |
| 同上但双方为企业或其他组织 | `或企业间借款` |
| 只拿固定报酬、不分担亏损、无合伙人决策权 | `只拿固定报酬不分担亏损无合伙人决策权→个人劳务（雇佣）` |
| 人格从属＋工资社保的劳动关系 | `人格从属＋工资社保→劳动合同` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式（出稿后自审） |
| 已签未争、问出资日／分账留痕 | 本套导航的履约步骤 |
| 已成争：催告散伙、清算诉讼、索赔立案仲裁 | 合同争议领域；不填签前十节 |
| 公务员等禁止营利经营、挂靠个体户资质 | 停笔告知，不改写成可履行规避结构；用户坚持则整体停止 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

专业版未收录的邻类不会作为本原子的实体审查对象。若用户拿这些文本来找本技能：输出 `unavailable` 或负触发路由，不得用本类型硬套。

本技能不得转去加载合伙企业、股东协议或借款双文件完成本类型审查，也不得把《合伙企业法》除名、优先购买或董事会写成个人合伙默认主路径。
