# 股权代持合同·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **股权投资相关合同 / 股权代持合同** 己方稿，出稿后用本类型硬闸自审。交付草稿、未决项、自审风险表和自审后修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查股权代持合同（股权投资相关合同）」。

`depends-on` 为空。不要求先跑导航。

主线是**投资交割里的名义登记与受益分离**：员工期权／持股平台、联合投资通道、不便出面的财务投资人。不是公司内部普通挂名，不是托管，不是隐名合伙，也不是把股权卖掉或无偿送给登记方。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证必然显名、保证必然排除执行、保证还原过户免税、精确税额核定、公司侧代持／托管／隐名合伙／投资侧转让或赠与／增资的整份代审。

## 本类型硬闸

1. **代持显名／隐名**：隐名侧只约束双方。无法律规定的无效情形时，实际出资人与名义股东之间的合同应认定有效；已实际履行出资的，名义股东不得以名册或登记否认其投资权益。这不等于已经是公司股东。显名侧是请求公司变更股东、签发出资证明书、记载名册和章程并办理登记，须其他股东半数以上同意。知情同意函缺失则显名字段停止。禁止写“签字即股东”或“保证一定能过户”。无出资用途证据的，按借贷或赠与嫌疑切开，不按隐名投资放行。
2. **处分限制**：未经实际出资人事先书面同意，名义股东不得转让、质押、赠与代持股权或设立表决权委托。擅自处分参照民法典第三百一十一条，不得写“处分当然无效”；必须有继续履行、违约金和按估值计算的赔偿。出质登记只补强对抗善意受让／质押，**不保证**排除名义股东债权人的强制执行。
3. **税务与代持无效风险**：登记外观下，公司向名义股东支付股息、红利时按支付对象扣缴；名义股东再转付给实际出资人、显名过户或退出转让，可能再被核财产转让所得。不得保证还原过户免税，不得编造税率或税额。税负由谁承担、谁配合申报必须落句。规避商品房限购、外资负面清单、公职人员禁业、上市公司股票代持禁令或持牌股东资质的，只出告知，不改写成可履行结构。用户坚持“改到能绕过去”或“写成一定免税”：整体停止。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。禁止打开或复制投资侧邻类 `出资合同·审查`、`房地产项目股权取得类合同·审查`、`PE股权转让·审查`、`投资意向书·审查`、`PE股东协议·审查`、`增资协议·审查` 的 method，也禁止打开公司侧代持、托管或隐名合伙 method 对照出句。不得按股权转让或赠与改完。

## 工作边界

正触发：已有可读待签代持正文，尚未签署，尚未成争，核心给付是股权投资场景下的名义登记与投资权益分离，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 无投资交割包、无持股平台／通道／后续轮次安排的公司侧普通隐名出资 → `股权代持协议·审查`；
- 登记股东不变，只托管表决、分红或证照 → `股权托管协议·审查`；
- 不登记为公司股东，出资给显名经营人并分享经营利润 → `隐名合伙合同·审查`；
- 价款进原股东、存量股权买卖为主给付 → `PE股权转让·审查`；
- 无偿过户、无对价、无出资证据却把登记方写成真实股东 → 赠与嫌疑，不按本类型放行；
- 价款进公司、新增注册资本为主文件 → `增资协议·审查`；
- 主文件是股东协议（投后治理、随售拖售、否决权） → `PE股东协议·审查`；
- 主文件是条款清单／Term Sheet → `投资意向书·审查`；
- 新设出资本约 → `出资合同·审查`；
- 房地产项目股权取得为主给付 → `房地产项目股权取得类合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、立案、开庭、仲裁，或确认股东资格／显名／排除执行已起诉 → `已出现催告解除函索赔立案开庭仲裁` 或公司／投资专项。

以代持为名规避限购、外资、公职或上市监管：只出告知，不改写成可履行路径。

## 建立审查坐标

确认：使用者与授权；代表实际出资人（隐名）还是名义股东／持股平台（显名）；目标公司是否有限公司、是否上市或持牌；全文及附件／回单／确认函／资本表版本；代持原因；出资从哪到哪、备注；处分限制是否闭合；税负由谁承担；后续轮次经济成果是否纳入；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

## 起草模式

本原子只承担本类型起草。待签评改转 `股权代持合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `股权代持合同·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。

### 起草必写

- 隐名侧只约束双方。无法律规定的无效情形时，实际出资人与名义股东之间的合同应认定有效；已实际履行出资的，名义股东不得以名册或登记否认其投资权益。这不等于已经是公司股东。
- 显名侧是请求公司变更股东、签发出资证明书、记载名册和章程并办理登记，须其他股东半数以上同意。知情同意函缺失则显名字段停止。
- 未经实际出资人事先书面同意，名义股东不得转让、质押、赠与代持股权或设立表决权委托。擅自处分参照民法典第三百一十一条，不得写“处分当然无效”；必须有继续履行、违约金和按估值计算的赔偿。出质登记只补强对抗善意受让／质押，不保证排除名义股东债权人的强制执行。
- 税负由谁承担、谁配合申报必须落句。登记外观下公司向名义股东支付股息、红利时按支付对象扣缴；再转付、显名过户或退出转让可能再被核财产转让所得。
- 分红、转让价款、清算剩余、对赌补偿、回购款、反稀释调股默认归实际出资人。资金尽量直达公司。

### 附件必附

- 出资用途证据／回单。
- 其他股东半数以上知情同意函（显名安排时）。

### 禁止出现

- “签字即股东”或“保证一定能过户”；保证还原过户免税或编造税率税额。
- “处分当然无效”；把出质写成必然排除强制执行。
- 规避商品房限购、外资负面清单、公职人员禁业、上市公司股票代持禁令或持牌股东资质改成可履行。
- 无出资用途证据仍按隐名投资放行；按股权转让或赠与改完。

出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)

禁止打开其他类型目录。知识稿把“出质必然对抗执行”“保证一定能过户”“上市公司股份代持一律无效”“解释三第二十六条已核验”写成已核验规则时，以 method 纠正为准。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 本任务起草模式；已签履约 → 本套导航履约步骤；已成争 → 合同争议或公司／投资专项。未签且目标是评改已有投资侧代持文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与资金流向一致才继续。公司侧挂名、托管、隐名合伙、转让、赠与、增资、股东协议、条款清单负触发。禁止删掉转让价款或赠与句后硬套本技能。

### 2. 代持显名／隐名

先拆对内投资权益与对公司的股东资格。出资证据链是隐名权益的前提。显名必须其他股东半数以上书面同意。

### 3. 处分限制

禁止自行转让、质押、赠与、表决权委托。处分不当然无效。执行按登记。出质是补强。

### 4. 税务与代持无效风险

税负分担与申报配合必须落句。不定税额。规避结构只告知。上市股票另核第一百四十条第二款。

### 5. 投资交割与后续轮次

资金尽量直达公司；分红、转让价款、清算剩余、对赌补偿、回购款、反稀释调股默认归实际出资人。

### 6. 格式条款与强制规范

无核验引文则法律结论字段停止。规避结构和保证免税不得改成可履行。

### 7. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效或必然显名、保证还原过户免税、把规避限购／外资改成可履行、把本约改成转让或赠与外壳仍放行。
- `字段停止`：法域、动态规则、出资路径、其他股东同意、准入身份、名义股东负债、税目与税率未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
