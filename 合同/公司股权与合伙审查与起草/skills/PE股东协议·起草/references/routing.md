# 边界与路由

本技能只起草 **PE股东协议**，出稿后用本类型硬闸自审。中文显示名为「PE股东协议·起草」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开邻类 method 后换标题交差。

硬闸路由：

- 股东协议 ≠ 章程替代 → 整份章程／章程修正案走 `公司章程_章程修正案·审查`
- 股东协议 ≠ 股权转让本约 → 存量价款进原股东走 `PE股权转让·审查` 或 `公司股权转让·审查`
- 股东协议 ≠ 增资本约 → 认缴／出资到位／增资工商走 `增资协议·审查` 或 `增资合同·审查`

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 整份代审章程、章程修正案、组织文件记载与修改程序 | `公司章程_章程修正案·审查` |
| 已设公司增资、认缴、出资到位、增资工商变更为主给付 | `增资协议·审查` 或 `增资合同·审查` |
| 存量股权让与、价款进原股东、交割／名册／登记为主给付 | `PE股权转让·审查` 或 `公司股权转让·审查` |
| 无优先清算、反稀释、随售拖售；只是股东之间内部治理契约 | `公司股东协议·审查` |
| 价款进公司的出资本约 | `出资合同·审查` 或 `出资合同（有限责任公司）·审查` |
| 投资意向书、条款清单、Term Sheet，多数条款无约束力 | `投资意向书·审查` |
| 实际出资人与名义股东、显名 | `股权代持合同·审查` |
| 房地产项目公司股权取得绑定开发权或实施主体 | `房地产项目股权取得类合同·审查` |
| 业绩对赌、估值调整作为主文件 | `对赌协议（盈利预测补偿协议）·审查` |
| 已有可读待签文本要评改 | `PE股东协议·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、只问履约节点或入章进度 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `已出现催告解除函索赔立案开庭仲裁` 或对应专项领域 |
| 决议效力、解散之诉、投资人索赔已立案 | 公司或投资争议专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

股东协议正文里夹带一小段增资交割或单笔转股：专章交接对应原子或分条改写；治理与退出条款可继续审。用户坚持本技能把章程、增资或转股整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
