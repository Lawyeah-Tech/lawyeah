# 债务转移三方协议·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **公司相关合同 / 债务转移三方协议** 己方稿，出稿后用本类型硬闸自审。交付草稿、未决项、自审风险表和自审后修改句。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「审查债务转移三方协议（公司相关合同）」。`depends-on` 为空。不要求先跑导航。

主线是**债务人将已特定债务的全部或部分转移给第三人，须经债权人同意**。不是第三人代为付款而原债务人不退出，不是债权人把债权卖给收购方，也不是只通知债务人即可的债权让与。

不交付：他类审查、从零起草、履约交底、争议文书、有效性或必然免责／必然担保存续保证、代付款／债权收购／债权转让／保证或抵押主文件的整份代审。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **债权人书面同意（对债权人生效的绝对要件）**：债务人将债务全部或部分转移给第三人，应当经债权人同意；催告后未作表示的，视为不同意。业务员在《告知函》《对账单》上签字、仅通知债权人、债权人未在本协议签章，均不得写成已经同意。缺少债权人作为签约主体的，对债权人不发生效力，不得写成已经完成转移。
2. **免责的债务承担 ≠ 并存的债务承担（债务加入）**：本协议通常旨在让原债务人退出。仅写“由新债务人负责偿还”而未写“债权人不再向原债务人主张”，不得写成已经免责。约定不明按保护债权人方向处理：不得推定原债务人已经脱责。若各方真实意思是债务加入，必须改成并存口径，并点明保证责任不受加入影响。
3. **担保是否存续**：债权人未经保证人书面同意允许债务转移的，保证人对未经其同意转移的债务不再承担保证责任，另有约定除外。第三人提供抵押／质押的，未经其书面同意不再承担相应担保责任。债务人自己提供的物保通常继续，但须办理债务人变更及登记。禁止写“担保当然随同转移”或“口头打过招呼即可”。
4. **与代付款、债权收购、债权转让切开**：第三人只付款、原债务人不换人 → `代付款三方协议·审查`。债权人把债权卖给收购方、债务人不变 → `债权收购合同·审查` 或 `主给付是债权让与通知债务人为轴→`。不得删掉代付或让与条款后硬套本技能。
5. **原债务范围可核验，从债务随转但专属除外**：本金、利息、违约金、损害赔偿、实现债权费用和履行状态必须落到清单。新债务人承担与主债务有关的从债务，专属于原债务人自身的除外。新债务人可主张原债务人对债权人的抗辩，但不得主张原债务人对债权人的抵销。
6. **三方主体与公司决议**：必须由债权人、原债务人、新债务人签署。公司承接或豁免重大债务，应有股东会或董事会决议；法定代表人以公司名义加入债务的，决议程序参照公司为他人提供担保的规则。未见决议：该方签署能力字段停止。

## 工作边界

正触发：已有可读待签三方协议或可单独评改的债务转移专章，尚未签署，尚未成争；核心给付是原债务人将已特定债务转移给新债务人，并寻求债权人同意。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 第三人只向债权人付款，原债务人不退出、债权人仍可向原债务人追索 → `代付款三方协议·审查`；
- 债权人将其对债务人的债权出让给收购方，债务人主体不变 → `债权收购合同·审查`；
- 不改变债之内容的债权让与、通知债务人生效 → `主给付是债权让与通知债务人为轴→`；
- 主文件是保证、抵押、质押，债务转移只是背景一句 → `主文件是保证或抵押借款→`／`或`／`主文件是抵押借款`；
- 主文件是股权转让、资产转让，债务转移只是交割附件一句且用户只要审主文件 → `公司股权转让·审查` 或 `非核心资产转让·审查`；债务转移专章可单独评改时，本任务只审该专章，主文件标转出；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问付款日、交接日、通知留痕 → 本套导航的履约步骤；
- 已成争（催告、追索、确认转移无效、保证责任诉讼、立案、开庭、仲裁）→ 合同争议或对应专项领域，不填签前十节。

通谋逃债、虚构债务、倒签同意日、把未同意写成已同意：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；代表债权人、原债务人还是新债务人；正文、原合同、担保合同、决议版本；债权人是否已作为协议一方；原债务人是否明确退出；保证人／第三人物保是否书面同意；不可接受事项；法域与拟签时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的金额、利率、日期用 `【待填】`，不编造。

## 起草模式

本原子只承担本类型起草。待签评改转 `债务转移三方协议·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `债务转移三方协议·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 必须由债权人、原债务人、新债务人三方签署。债务人将债务全部或部分转移给第三人，应当经债权人书面同意。
- 免责的债务承担还是并存的债务承担必须落句。仅写“由新债务人负责偿还”而未写“债权人不再向原债务人主张”，不得写成已经免责。约定不明按保护债权人方向处理。
- 债权人未经保证人书面同意允许债务转移的，保证人对未经其同意转移的债务不再承担保证责任，另有约定除外。第三人提供抵押／质押的，未经其书面同意不再承担相应担保责任。
- 本金、利息、违约金、损害赔偿、实现债权费用和履行状态必须落到清单。新债务人可主张原债务人对债权人的抗辩，但不得主张原债务人对债权人的抵销。
- 公司承接或豁免重大债务，应有股东会或董事会决议。

### 附件必附

- 原债务合同
- 债务清单
- 担保合同
- 保证人／第三人物保书面同意
- 公司股东会或董事会决议

### 禁止出现

- 业务员在《告知函》《对账单》上签字或仅通知债权人写成已经同意
- 缺少债权人签章却写成已经完成转移
- 约定不明推定原债务人已经脱责
- “担保当然随同转移”或“口头打过招呼即可”
- 通谋逃债、虚构债务、倒签同意日

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录，禁止为对照打开代付款、债权收购或债权转让双文件。`基本面.md` 中“未盖章即不同意”降级为：对债权人可能不发生效力，但不把双方之间的约定写成当然无效。`框架.md` 中“本协议通常指免责”不得在约定不明时写成已经免责。

必须有修改句。禁止只打红黄绿。每个风险回链文本位置。交付按 [输出合同](references/output-contract.md)。边界见 [路由](references/routing.md)。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、把业务员签字写成债权人已同意、把通谋逃债或虚构债务改成可履行转移、保证原债务人必然免责或担保必然存续。
- `字段停止`：未见债权人签章或书面同意；免责或并存未落句；存在保证／第三人物保但未见书面同意；原债务清单缺金额或原合同编号；公司承接或豁免重大债务未见决议。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或文本已滑入代付款、债权收购或债权转让。

生存级债务额或个人无限连带且用户拒绝升级：停止“可以签署”建议。
