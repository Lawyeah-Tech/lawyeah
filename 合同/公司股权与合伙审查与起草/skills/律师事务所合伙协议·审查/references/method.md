# 审查方法（锁定 公司相关合同 / 律师事务所合伙协议）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制普通公司有限合伙 LP 避风港、普通合伙企业执照主路径、非律所专业所节点、股东协议治理节点或施工挂靠节点。

定性校验：标题、核心给付与本类型一致才继续；公司有限合伙、非律所特殊普通合伙、普通合伙企业、个人律师事务所、国资所、股东协议、保底借贷或固定报酬雇佣明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、必然获许可、对方必然接受或对债权人已经免责。

`search_law` 返回 1996/2004《合伙律师事务所管理办法》、1996 年《律师法》原文、1997 年《合伙企业法》、已失效《合同法》及其解释时记为噪声，不得写入 `L#`。

示范文本只参考结构。含“有限责任合伙人”的律所范本只证明邻类污染，不得当作本类型范本。

知识库纠正（不回写双文件）：

- `基本面.md` 写合伙人可以是“自然人、法人和其他组织”，并展开有限合伙结构：本类型不适用。合伙人必须是执业律师自然人，全部为普通合伙人。
- `基本面.md` “违反效力性强制性规定”：禁止用失效“效力性/管理性”口诀。改走民法典第 153 条和合同编通则解释第 16 条。
- `框架.md` 把律所一律写成特殊的普通合伙企业：管理办法第 7 条允许普通合伙或特殊的普通合伙。先锁定组织形式，再落责任句。不得把普通合伙所偷换成第 57 条切割，也不得把特殊普通合伙所写成全体对外无切割。
- `框架.md` “以市场监管部门登记信息为准”：律所名称、住所、经营范围以司法行政机关许可为准；市场主体登记如需办理，只作为后续义务，不得替代执业许可证。
- `框架.md` “本协议经全体合伙人签名、盖章后生效”：管理办法第 17 条是自省级司法行政机关作出准予设立决定之日起生效。修改句拆成“签名成立”与“许可生效”。
- 律师法（2017 修正）第 15、54 条本次 MCP 可能被 1996 同号条劫持：制度用管理办法第 7、9、53 条落句，运行时复核后再写入 `L#`。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 《XX律师事务所合伙协议》，列律师执业证号，拟向司法行政机关申请设立或变更普通合伙或特殊的普通合伙律师事务所 | 本类型 | 正触发 |
| GP/LP、认缴为限、私募基金、财务投资人不执业 | 公司相关合同 / 合伙协议（有限合伙） | 负触发 `合伙协议（有限合伙）·审查` |

| 领取普通合伙企业营业执照，名称标明“普通合伙”，无律所许可 | 普通合伙企业合同 | 负触发 `普通合伙企业合同·审查` |

| 股东会、股权比例、注册资本、公司章程一揽子 | 股东协议 | 负触发 `公司股东协议·审查` |
| 不参与经营、不承担亏损、到期回收固定本息 | 借款 | 负触发 `或企业间借款` 或 `不参与经营不承担亏损到期固定本息→自然人之间借款` |
| 只拿固定报酬、不持有财产份额、不担亏损 | 劳务/雇佣 | 负触发 `只拿固定报酬不分担亏损无合伙人决策权→个人劳务（雇佣）` 或 `人格从属＋工资社保→劳动合同` |

支持切开的规范（法律结论须运行时复核）：

- 管理办法第 7 条：律师事务所可以由律师合伙设立、律师个人设立或者由国家出资设立；合伙律师事务所可以采用普通合伙或者特殊的普通合伙形式设立。
- 管理办法第 53 条：普通合伙所与特殊普通合伙所责任形式不同；个人所、国资所另有专条。
- 合伙企业法第 55、57 条：特殊普通合伙是专业服务机构的责任形式；非律所专业所走 `特殊的普通合伙企业合同·审查`。
- 律师法第 16 条：个人所不是本任务。

| 文本写法 | 本任务动作 | 修改句方向 |

| 名称、住所、经营范围只写“以市场监管登记为准” | 必须改：以司法行政机关许可为准 | 许可与登记分列 |

修改句：

「各方确认：本协议是为依照《中华人民共和国律师法》《律师事务所管理办法》在中国大陆设立【普通合伙 / 特殊的普通合伙】律师事务所而订立。本所名称、住所和经营范围以省、自治区、直辖市司法行政机关准予设立决定及律师事务所执业许可证记载为准。本协议由全体合伙人签名后成立，自省级司法行政机关作出准予设立本所决定之日起生效。领取执业许可证前，任何一方不得以本所名义接受委托、出具法律文书或对外签署合同。」

最强反方：相对方主张内部协议已成立，未获许可也可先用字号接案。现有依据不支持把未获许可写成可以律所名义执业。用户坚持保留未许可执业：整体停止。

### 1.4 与 `合伙协议（有限合伙）·审查` / `特殊的普通合伙企业合同·审查` 切开（硬闸）

标题写成“特殊普通合伙企业协议”但正文是律师所、列执业证号、要报司法局：按核心给付留本技能，标题冲突写入 `C#`，修改句改标题为《XX律师事务所合伙协议》。

正文是 GP/LP 基金或公司有限合伙：负触发 `合伙协议（有限合伙）·审查`。不得删掉 LP 条款后继续当律所审。

正文是会计师、建筑师等专业所、许可机关不是司法行政机关：负触发 `特殊的普通合伙企业合同·审查`。不得把管理办法第 53 条写进他类专业所。

### 1.5 挂靠 / 未许可执业 / 出借许可证停笔

加载后或定性中出现：挂靠执业、出借或出租执业许可证、非律师以合伙人名义执业、未获许可先以律所名义接案、把非律师或法人改成可许可合伙人。

动作：

1. 交付告知：可能违反《律师法》和《律师事务所管理办法》。不得改写成可履行的规避结构。
2. 不写可履行的未许可接案路径、假挂名或对外一律免责。
3. 风险表只保留识别依据和删除/转出口径。
4. 用户坚持“改到能签且仍做这些事”：整体停止。

## 节点 2　合伙人资格与司法行政许可

### 2.1 主体表与资格（硬闸）

建表：姓名、身份证号、住所、律师执业证号、专职或兼职、执业年限、近三年是否受停止执业处罚、拟任负责人。名称不一致不自动合并。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 非律师、律师助理、公司法务、投资公司、法人或其他组织被列为合伙人 | 红线删除或改道 | 补一纸委托即可入伙 |
| 兼职律师、不在本所专职执业、挂名不坐班 | 红线。新合伙人须从专职执业律师中产生 | 挂名分红即可 |
| 申请前三年内受过停止执业处罚；或受六个月以上停止执业处罚期满未逾三年 | 红线。不得担任合伙人 | 处罚期满即可马上当合伙人 |
| 普通合伙所设立人不足三名，或特殊普通合伙所设立人不足二十名 | 红线。人数条件未满足不得写成可许可 | 先签后补人 |
| 民事行为能力或执业证有效期未闭合 | 字段停止 | 可以签署 |
| 口头“司法局的人说没问题” | 不得写成已获许可 | 已获内部批准 |

修改句：

「本所合伙人均为具有完全民事行为能力、能够在本所专职执业的律师，全部为普通合伙人。各合伙人姓名、居住地、身份证号、律师执业证号及执业经历见附件合伙人名册。设立人应当具有三年以上执业经历，且在申请设立前三年内未受过停止执业处罚。新合伙人应当从专职执业的律师中产生，并具有三年以上执业经历，但司法部另有规定的除外。受到六个月以上停止执业处罚的律师，处罚期满未逾三年的，不得担任合伙人。本所不得吸收非律师、法人、其他组织或有限合伙人。」

最强反方：相对方主张投资人只出钱、不执业、不对外代表。现有依据不支持把非律师或法人改成可许可合伙人。

### 2.2 书面协议与第十七条事项

合伙协议应当载明：合伙人姓名、居住地、身份证号、律师执业经历；出资额及出资方式；权利义务；负责人职责及产生、变更程序；合伙人会议职责和议事规则；收益分配及债务承担方式；入伙、退伙及除名条件和程序；争议解决和违约责任；协议解释、修改程序；其他需要载明的事项。缺一项则该字段不得写成已闭环，修改句补栏，数字用 `【待填】`。

协议由全体合伙人协商一致并签名。修改后的合伙协议因合伙人变更的，须报司法行政机关批准。

### 2.3 设立许可与生效时点

把司法行政许可写成**双方义务和生效条件**，不写成已经完成。

| 文本写法 | 本任务动作 |
| --- | --- |
| “本协议签字盖章后立即生效，本所即成立” | 必须改：协议成立 vs 许可生效 |
| 无谁负责申请许可、几日内、未获准的后果 | 补义务主体、期限、未获准时解除或中止 |
| 资产证明、名称检索、住所证明未附 | 字段停止；修改句要求作为附件 |
| 用户要求倒签或补假许可 | 整体停止 |

修改句：

「本协议自全体合伙人签名之日起成立。本协议自省、自治区、直辖市司法行政机关作出准予设立本所决定之日起生效。甲方应于本协议签署后【待填】日内备齐设立申请书、章程、合伙协议、设立人执业证书、住所证明和资产证明，向所在地设区的市级或者直辖市的区（县）司法行政机关提出设立申请；各方应在【待填】日内配合签署申请材料。因不可归责于申请方的原因【待填】日内未获准予设立决定的，任何一方可书面通知解除本协议，已缴出资按【待填】退还，互不主张本所已成立或已取得执业许可。」

部门规章或地方窗口材料未核：字段停止，不写“可以许可”。未获许可不等于内部协议当然无效（解释第 16 条），本任务只停止“所已成立”和“可以以律所名义执业”表述。

## 节点 3　执业责任与故意或重大过失（硬闸）

先锁定组织形式，再落责任句。法律结论须运行时复核管理办法第 53 条、合伙企业法第 57、58 条。

| 组织形式 | 必须写出的结构 | 禁止写成 |
| --- | --- | --- |
| 普通合伙律师事务所 | 全体合伙人对本所债务承担无限连带责任；本所赔偿后，可向有故意或者重大过失的律师追偿 | 偷换成特殊普通合伙切割；对债权人按份或免责 |
| 特殊的普通合伙律师事务所 | 一个或数个合伙人因故意或者重大过失造成的执业债务，该合伙人无限（连带），其他合伙人以在本所财产份额为限；非因故意或者重大过失的执业债务及其他债务，全体无限连带；本所财产对外承担责任后，过错合伙人按协议赔偿 | 任何执业债务其他合伙人均不负责；对债权人一律免责 |
| 未写明组织形式 | 必须改：在首部锁定普通合伙或特殊的普通合伙，再套上表 | 两可并存 |

“故意或者重大过失”必须定义，不得只写四个字。修改句至少覆盖：明知违法违规仍办理；严重不负责任导致当事人重大损失；被生效裁判或行政处罚认定存在故意或重大过失。定义不得缩小到“仅以刑事判决为限”。

修改句（特殊的普通合伙所）：

「一个合伙人或者数个合伙人在执业活动中因故意或者重大过失造成本所债务的，应当承担无限责任或者无限连带责任，其他合伙人以其在本所中的财产份额为限承担责任。合伙人在执业活动中非因故意或者重大过失造成的本所债务以及本所的其他债务，由全体合伙人承担无限连带责任。律师违法执业或者因过错给当事人造成损失的，由本所承担赔偿责任；本所赔偿后，可以向有故意或者重大过失行为的律师追偿。本款所称故意或者重大过失，包括但不限于：明知违反法律、法规、规章或执业规范仍予办理；严重不负责任导致委托人重大损失；被生效裁判、仲裁裁决或行政处罚认定存在故意或者重大过失。本协议对内追偿比例的约定，不改变本所或合伙人依照法律对债权人、委托人承担的责任。」

最强反方：相对方主张特殊普通合伙就是“别人办砸案子与我无关”。现有依据不支持把非故意或重大过失债务和其他债务写成其他合伙人不负责，更不支持对债权人一律免责。

特殊的普通合伙应当建立执业风险基金、办理职业保险，基金单独立户。缺条款：必须改，账户和保额用 `【待填】`。

## 节点 4　出资、利润亏损与禁止 LP

审查清单，缺一项则该字段不得写成已闭环：

1. 各合伙人认缴额、出资方式、缴付期限。
2. 货币以外出资：评估办法及权属转移义务。
3. 禁止出现有限合伙人、认缴为限的财务投资人、不担亏损的保底投资。
4. 利润分配和亏损分担按约定；未约定则协商，协商不成按实缴，无法确定则平均。
5. 不得约定将全部利润分配给部分合伙人或由部分合伙人承担全部亏损。

| 文本写法 | 动作 |
| --- | --- |
| 设有限合伙人、认缴为限、不执行事务的财务投资人 | 红线删除。若核心给付已是有限合伙：负触发 `合伙协议（有限合伙）·审查` |
| 全部利润分配给部分合伙人，或由部分合伙人承担全部亏损 | 红线删除 |
| 一方不参与经营、不承担亏损、到期收回固定本息 | 负触发借款原子，或红线删除保底 |
| “对内按份、对外也按份”或“对债权人一律免责” | 必须改：对内追偿可以按份；对外按节点 3 |

修改句：

「本所不得设置有限合伙人或任何仅以认缴出资为限对外承担责任的合伙人。本所利润分配、亏损分担按照附件【待填】办理。合伙协议不得约定将全部利润分配给部分合伙人，或者由部分合伙人承担全部亏损。任何保底收益、固定本息或不承担亏损的约定不构成本协议的利润分配条款。对内分担比例仅用于合伙人相互追偿，不改变各合伙人依照本协议第三部分和《律师事务所管理办法》第五十三条对委托人、债权人承担的责任。」

禁止编造出资额。框架或示范文本中的比例只是栏目，不是法源。

## 节点 5　事务执行、负责人与竞业

### 5.1 执行事务与负责人

约定全体共同执行，或委托一名或数名合伙人（管理合伙人）执行。不执行事务的合伙人有监督权和查阅权。更换条件（丧失执业许可、损害本所利益、丧失民事行为能力）和交接必须可执行。

负责人职责以及产生、变更程序是管理办法第 17 条必载事项。缺程序：必须改。

除协议另有约定外，改变名称、经营范围、处分不动产、以本所名义为他人担保等重大事项，应当经全体合伙人一致同意。内部对执行事务或对外代表权的限制，不得对抗善意第三人。

修改句：

「合伙事务由【共同执行 / 委托【姓名】作为管理合伙人执行】。委托执行的，其他合伙人有权监督执行情况并查阅账簿。本所负责人由合伙人会议以【待填】程序选举产生，职责为【待填】；更换须经【待填】并按本办法报司法行政机关。改变本所名称、经营范围，处分不动产，以本所名义为他人提供担保，除本协议另有约定外，应当经全体合伙人一致同意。本协议对执行事务或对外代表权的限制，不得对抗善意第三人。」

### 5.2 竞业与自我交易

普通合伙人（律师）不得自营或者同他人合作经营与本所相竞争的业务。除协议另有约定或经全体一致同意外，不得同本所进行交易。竞业不得写成可以内部豁免。自我交易可以约定或全体同意。

## 节点 6　入伙退伙报批、格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 入伙退伙与报批

| 文本写法 | 动作 |
| --- | --- |
| 新合伙人不具备专职执业律师资格或三年以上经历 | 红线。受让财产份额的人须具备合伙人资格 |
| 新合伙人不承担入伙前债务 | 红线删除对外豁免。对内可另约追偿 |
| 退伙后对退伙前执业债务免责 | 红线删除对外豁免 |
| 入伙、退伙、除名、修改协议不报司法行政机关 | 必须改：变更合伙人含吸收、退伙、除名；修改协议须报批 |
| 除名无书面通知、无异议起诉期间 | 必须补：书面通知到达生效；三十日内可起诉 |
| 丧失执业许可、受到不得担任合伙人的处罚仍保留合伙人资格 | 必须改：当然退伙 |

修改句：

「新合伙人入伙，除本协议另有约定外，应当经全体合伙人一致同意并订立书面入伙协议。新合伙人必须是能够在本所专职执业、具有三年以上执业经历的律师。原合伙人应当向新合伙人如实告知经营状况、财务状况和已知执业债务。新合伙人对入伙前本所债务承担的责任，不得以本协议对外免除。合伙人退伙、被除名或因丧失律师执业许可当然退伙的，本所应当依照法律、本所章程和本协议处理财产权益和债务承担，并在【待填】日内办理合伙人变更和合伙协议修改的报批。退伙律师不得擅自带走案卷、客户预收款和本所印章；交接清单和客户知情安排见附件。」

最强反方：入伙人主张不知情故不承担旧债。对内可追偿，对外不得写成已经免责。

### 6.2 格式条款

为重复使用而预先拟定、订立时未与对方协商。依据示范文本制作，不当然排除格式条款。

审查：无限连带、执业责任切割、除名、永远不得退伙、管辖/仲裁等异常条款是否有足以引起注意的标识，以及是否按要求说明（第 496 条；解释第 10 条）。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在附件 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

### 6.3 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的、是否仅行政管理、是否只规制履行行为（第 153 条；解释第 16 条）。禁止用已失效“效力性/管理性”口诀。未获许可执业、非律师当合伙人、LP 结构、对债权人一律免责：不改写成有效履行。

## 节点 7　违约、解散、案卷与争议

1. 逾期出资、擅自处分所内财产、违反竞业、擅自带走案卷：须分别有可执行后果（补缴、违约金、除名条件、赔偿）。只有“依法承担违约责任”视为必须改。
2. 除名决议须书面通知；被除名人三十日内可向人民法院起诉。不得写成“通知即不得异议”。
3. 违约金不是必得金额。修改句避免“不得调整”。
4. 解散必须清算。解散不等于合同立即终止。合伙人不足法定人数且未在约定期限内补齐，应作为解散或整改事由，数字以运行时核验的现行条件为准，不写失效“三人/十万元”旧口径。
5. 案源、品牌、档案属律所，不是个人资产。退伙不得擅自带走案卷和客户预收款。
6. 争议解决：出现仲裁条款，不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核，修改句改成单一仲裁机构或单一法院连结点。专属管辖可能：只标红旗。
7. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。

修改句：

「本所解散的，应当依法清算。清算完毕并办理注销登记、缴回执业许可证前，本协议关于清算组、财产分配、债务清偿、案卷和客户预收款移交的条款继续有效。剩余财产按【实缴出资比例 / 附件绩点规则】分配。合伙人退伙或本所解散时，任何一方不得擅自带走案卷、客户预收款和本所印章。」
