# 律师事务所合伙协议·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》、1996/2004《合伙律师事务所管理办法》、1996 年《律师法》原文或 1997 年《合伙企业法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **公司相关合同 / 律师事务所合伙协议** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查律师事务所合伙协议（公司相关合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性或许可保证、把有限合伙或非律所特殊普通合伙改完、把非律师或法人改成可许可合伙人。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **律师法 / 合伙所规范主线**：核心给付是设立或变更合伙律师事务所。主法是《律师法》和《律师事务所管理办法》。书面合伙协议是司法行政许可材料。不得把民法典合伙合同章或普通公司有限合伙当默认主法。名称、住所、经营范围以司法行政机关许可为准。
2. **合伙人资格**：合伙人必须是具有完全民事行为能力、能够专职执业的律师自然人，全部为普通合伙人。设立人须有一定执业经历，申请前三年内未受停止执业处罚。普通合伙所不少于三名设立人、三年以上专职执业、资产不少于三十万元；特殊的普通合伙所不少于二十名设立人、三年以上专职执业、资产不少于一千万元。法人、非律师、挂名、有限合伙人：红线。
3. **执业责任**：普通合伙所全体无限连带。特殊的普通合伙所：故意或者重大过失造成的执业债务，过错合伙人无限（连带），其他合伙人以财产份额为限；非故意或者重大过失的执业债务及其他债务，全体无限连带。律所先赔，再向故意或者重大过失的律师追偿。必须定义“故意或者重大过失”。不得写成对债权人一律免责。
4. **不得设有限合伙人**：出现 LP、认缴为限的财务投资人：红线删除或负触发 `合伙协议（有限合伙）·审查`。
5. **与 `合伙协议（有限合伙）·审查` / `特殊的普通合伙企业合同·审查` 切开**：公司相关合同项下有限合伙 → `合伙协议（有限合伙）·审查`。会计师、建筑师等非律师专业所特殊普通合伙 → `特殊的普通合伙企业合同·审查`。普通合伙企业无律所许可 → `普通合伙企业合同·审查`。个人律师事务所、国家出资设立的律师事务所不是本任务。
6. **书面协议应载事项与许可日起生效**：管理办法第十七条事项须齐。全体合伙人签名。自省级司法行政机关作出准予设立决定之日起生效。变更合伙人、修改协议须报批。丧失执业许可即当然退伙。
7. **禁止全部利润或全部亏损；特殊普通合伙须执业风险基金与职业保险**。保底固定本息转借款原子。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签律师事务所合伙协议正文，尚未签署，尚未成争，核心给付是设立或变更合伙律师事务所、合伙人是执业律师、报司法行政机关许可，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 公司相关合同项下有限合伙、GP/LP、私募认缴为限 → `合伙协议（有限合伙）·审查`（P1；专业版未装则 `unavailable`）；
- 会计师、建筑师等非律师专业所，无律师执业许可与司法行政许可主线 → `特殊的普通合伙企业合同·审查`（P1；未装则 `unavailable`）；
- 领取普通合伙企业营业执照、名称标明“普通合伙”、无律所许可 → `普通合伙企业合同·审查`；
- 出现有限合伙人且核心给付是有限合伙企业 → `有限合伙企业合同·审查`；
- 不领执照、只适用民法典合伙合同 → `个人合伙合同·审查`；
- 个人律师事务所（设立人一人、五年以上执业经历、设立人无限责任）或国家出资设立的律师事务所 → 负触发，提示不是本任务；
- 公司股东会、股权治理、注册资本一揽子 → `公司股东协议·审查`；
- 不参与经营、不承担亏损、到期固定本息 → `或企业间借款` 或 `不参与经营不承担亏损到期固定本息→自然人之间借款`；
- 只拿固定报酬不担风险 → `只拿固定报酬不分担亏损无合伙人决策权→个人劳务（雇佣）`；人格从属加工资社保 → `人格从属＋工资社保→劳动合同`；
- 无文本、本类型条件已谈妥、要出己方稿 → `律师事务所合伙协议·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼仲裁，或吊证、停业整顿听证 → `已出现催告解除函索赔立案开庭仲裁` 或对应专项领域。

挂靠执业、出借许可证、未获许可以律所名义接案：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（拟入伙合伙人或拟任负责人择一）；相对方；全文及附件版本；普通合伙所还是特殊的普通合伙所；各合伙人执业证号、专职/兼职、执业年限、近三年停止执业处罚；是否夹带非律师、法人或 LP；出资；利润亏损；执业责任是否区分故意或重大过失；风险基金与职业保险；负责人产生办法；入伙退伙报批；不可接受事项；法域、拟申请地与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的出资额、期限、基金账户用 `【待填】`，不编造。

宿主可调用时：`search_law` 核验律师法、管理办法设立与许可、合伙人资格、执业责任、禁止 LP、协议生效时点、格式条款；`search_practiced` 只补审查反例；`search_template` 只借栏目结构。含“有限责任合伙人”的范本只作负向切开。不虚构案件系统。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `律师事务所合伙协议·起草`；已签履约 → 本套导航履约步骤；已成争或吊证听证 → 合同争议或行政处罚。未签且目标是评改已有律师事务所合伙协议，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。有限合伙、非律所特殊普通合伙、普通合伙企业、个人所、国资所、股东协议、借贷、雇佣负触发。

### 2. 合伙人资格与司法行政许可

非律师、法人、挂名、处罚禁入红线。书面协议齐第十七条事项。未获许可不得以律所名义执业。

### 3. 执业责任与故意或重大过失

按普通合伙所或特殊普通合伙所分别落句。对债权人不得一律免责。

### 4. 出资、利润亏损与禁止 LP

禁止全部利润或全部亏损。出现 LP 红线或转出。

### 5. 事务执行、负责人与竞业

内部限权不得对抗善意第三人。负责人产生、变更须可执行。

### 6. 入伙退伙报批、格式条款与强制规范

变更须报批。无核验引文则法律结论字段停止。

### 7. 违约、解散、案卷与争议

退伙不得擅自带走案卷和客户预收款。解散必须清算。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效或许可、把非律师或法人改成可许可合伙人、把 LP 改成可许可、或把未获许可先以律所名义执业改成可履行。
- `字段停止`：法域、动态规则、执业许可或处罚未核验、资产证明、地方窗口材料未核。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
