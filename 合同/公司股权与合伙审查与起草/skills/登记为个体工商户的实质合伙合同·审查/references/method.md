# 审查方法（锁定 合伙合同相关 / 登记为个体工商户的实质合伙合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制隐名合伙“不经营不担债”主路径、个人合伙无个体户执照主路径、普通合伙企业执照专条、有限合伙 LP 避风港、股东协议治理节点、借款 method 或施工挂靠可履行节点。

定性校验：标题、核心给付与本类型一致才继续；隐名合伙、不领个体户执照的个人合伙、合伙企业、保底借贷或固定报酬雇佣明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、必然完成登记、对方必然接受、对外已经免责、法院必然追加或内部协议已经击败善意第三人。

`search_law` 返回已失效《民法通则》个人合伙章、已失效《城乡个体工商户管理暂行条例》、已失效《个体工商户登记管理办法》、已失效《个体工商户名称登记管理办法》、已失效《合同法》及其解释时记为噪声，不得写入 `L#`。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。隐名合伙、个人合伙或合伙企业范本只证明是另一类型，不得当作本类型范本。

知识库纠正（不回写双文件）：

- `基本面.md` “无名合同”：内部关系适用民法典合伙合同章，合伙合同是有名合同。“名为个体工商户、实为合伙”只描述登记外观与内部关系的落差，不得把本约本身写成无名合同已核验结论。
- `基本面.md` “内部效力优于登记”“实质重于形式”：内部协议约束合伙人；登记公示和善意相对人仍受保护。不得写成内部协议已经击败工商登记或善意第三人。
- `基本面.md` “登记名义人需首先承担责任”：不是法定清偿顺序。登记经营者对外承担责任；登记经营者与实际经营者不一致的，诉讼上可为共同诉讼人。不得写成“先登记人、后隐名人”的法定顺序。
- `基本面.md` “执行实务中法院会依据合伙事实直接追加隐名合伙人为被执行人”：执行风险，不是必然结果。修改句标风险，不得写成“法院必然追加”或“隐名方对外绝对免责”。
- `基本面.md` “合伙财产按份共有或共同共有”：现行口径先走民法典第 969 条“属于合伙财产”。共有形态未约定则字段停止，不补写成共同共有已核验。
- `框架.md` “本协议在内部具有最高法律效力，显名合伙人不得以工商登记为由主张所有权”：对内可写不得以登记否认合伙；不得写成已经对抗善意第三人。
- `框架.md` 质押、公司化过渡、“三方见证”：可优化设计，不是法定义务。点名即可，不出抵押整稿、不出有限公司设立整稿。
- 避税或规避行业准入：停笔，不改成可履行。

- 民法典第 54 条：自然人从事工商业经营，经依法登记，为个体工商户；可以起字号。
- 民法典第 967 条：合伙合同是共享利益、共担风险的协议。
- 民法典第 973 条：合伙人对合伙债务承担连带责任；超额清偿可追偿。
- 《合伙企业法》第 2 条：领取合伙企业执照的走企业原子，不留本技能。
- 市场主体登记管理条例第 2、3 条：个体工商户是市场主体；未经登记不得以市场主体名义经营。

| 文本写法 | 动作 |
| --- | --- |
| 非登记方出资、参与经营管理、按约定分担亏损 | 本类型 |
| 非登记方不参与经营、不承担亏损、仅分享收益或仅以出资为限 | 负触发 `隐名合伙合同·审查`。不得改成可履行的“有限责任隐名合伙人”后留在本技能 |
| 不参与经营、到期固定本息 | 负触发借款原子 |

修改句（留在本类型时）：

「乙方作为不出现在工商登记中的实质合伙人，有权参与经营管理并按本协议分担亏损。任何一方不得将本协议解释为隐名投资、借贷或仅以出资为限的安排。」

最强反方：非登记方主张自己只是财务投资、对外不应被追。若其确实不经营、不担亏损：转 `隐名合伙合同·审查`，不在本任务改成可履行免责。若其共同经营：现有依据不支持对外绝对免责。

### 1.5 挂靠 / 规避准入 / 避税停笔

加载后或定性中出现：出借或挂靠个体户资质、借用烟草/餐饮等特许许可、规避行业准入或限购、为避税虚构合伙或资金体外循环。

动作：

1. 交付告知：可能违反行业强制规范和民法典第 153 条指向的规范。不得改写成可履行的规避结构。
2. 不写可履行的挂靠路径、假共同经营或避税分账。
3. 风险表只保留识别依据和删除/转出口径。
4. 用户坚持“改到能签且仍做这些事”：整体停止。

合规改道（真实专业许可、真实公司化）只点名，不在本任务起草。

## 节点 2　主体、登记外观与组成形式

### 2.1 主体表

建表：登记名义人（执照经营者）、非登记实质合伙人、签约名、出资名、付款名、授权签字人。名称不一致不自动合并。口头“我们老板同意了”不得写成已授权。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 组成形式未写个人经营或家庭经营 | 必须改；未闭合则字段停止 | 可以盖章对外 |
| 以家庭财产出资或家庭成员共同经营 | 必须写明家庭经营风险；配偶或家庭成员知情未闭合则字段停止 | 债务仅限登记人个人 |
| 公务员等禁止营利经营 | 只告知，不改成隐名规避 | 改成可履行隐名经营 |
| 特许许可记在登记人个人名下 | 必须写内部共有及不得单方转让；行业禁止挂靠则停笔 | 许可已属全体且可对外对抗 |

修改句：

「甲方为字号【待填】个体工商户营业执照上登记的经营者，对外签署合同、办理税务和行政管理事项。乙方为不出现在该登记中的实质合伙人。本个体工商户组成形式为【个人经营 / 家庭经营】。以家庭财产出资或由家庭成员共同经营的，经营债务可能由家庭财产承担；甲方应于签署前书面告知其配偶或共同生活的家庭成员，告知回执作为附件。」

### 2.2 书面合伙与证据栏

认定内部合伙关系的基石是书面利益分配和风险承担约定。缺出资、分配、亏损分担、执行权限任一项：该字段不得写成已闭环，修改句补栏，数字用 `【待填】`。

建议附件：营业执照复印件或名称预先核准、初始资产清单、初始投入资金凭证。未附则列为 `G#`，不补写成已核实出资。

## 节点 3　出资、字号与财产锁定

审查清单，缺一项则该字段不得写成已闭环：

1. 各方出资数额、形式、缴付账户或交付方式。
2. 字号、经营场所租赁权、设备、存货、商标或特许许可是否写明属于合伙财产。
3. 经营账户是共管还是登记人个人账户；混同必须改。
4. 清算前不得请求分割合伙财产，除非另有约定或法律另有规定。

| 文本写法 | 动作 |
| --- | --- |
| “店内全部财产归登记名义人个人所有” | 红线删除；改为合伙财产 |
| 账户用登记人个人卡，无共管或流水核对 | 必须改：共管或定期对账 |
| “内部协议可追回已出售给不知情第三人的设备” | 红线删除对外追及；改为内部追偿和违约金 |
| 未给出出资额或估值办法 | `【待填】`；不编造 |

修改句：

「各方出资数额、形式和缴付期限见附件出资清单。字号【待填】、经营场所租赁权、店内设备、存货、账户余额、特许经营许可及因合伙事务取得的其他财产，属于合伙财产。登记在甲方名下的上述财产，甲方不得作为个人财产处分、抵押或用于清偿与本合伙无关的个人债务。经营资金应进入【共管账户名称及账号待填】；未经全体合伙人书面同意，任何一方不得将合伙资金转入个人账户。本协议终止前，合伙人不得请求分割合伙财产，本协议另有约定或法律另有规定的除外。登记名义人擅自将合伙财产转让给不知情的第三人的，非登记方通常不能向该第三人追回，只能按本协议向登记名义人追偿。」

禁止编造出资额。框架中的净资产法或营业额倍数法只是栏目，不是法定估值。

## 节点 4　对外责任与内部追偿（硬闸）

支持依据：民法典第 56、973 条；民诉法解释第 59 条。第 104 条非法人组织无限责任仅在定性闭合后作为补充，不替代第 56 条。

| 文本写法 | 动作 |
| --- | --- |
| “经营债务由登记名义人一人承担，其他合伙人对外免责” | 红线删除对外免责 |
| “债权人不得向非登记方主张” | 红线删除 |
| 对内按份、对外也按份 | 必须改：对内追偿可以按份；对外连带不因内部约定消灭 |
| 未写家庭经营或家庭财产 | 必须补第 56 条分层；事实未闭合则字段停止 |
| “法院不会追加非登记方” | 删除保证。改为风险提示：登记与实际经营者不一致的，可为共同诉讼人；执行中存在追加风险 |
| 未写登记人超额清偿后的追偿 | 必须补 |

修改句：

「本个体工商户因经营产生的债务，个人经营的，以登记经营者的个人财产承担；家庭经营或者无法区分个人经营与家庭经营的，以家庭财产承担。合伙人对合伙债务承担连带责任。本协议关于亏损分担、出资比例或“由登记名义人对外清偿”的约定，仅用于合伙人内部追偿，不得对抗债权人，也不得解释为非登记方对外免责。甲方因经营债务对外清偿超过其按照本协议应当承担的份额的，有权在超额范围内向其他合伙人追偿。营业执照上登记的经营者与实际经营者不一致的，登记经营者和实际经营者可能被列为共同诉讼人。」

最强反方：非登记方主张自己不在执照上，对外不应被追。现有依据不支持把内部免责写成已经消灭对外连带。用户坚持保留“债权人不得向非登记方主张”：整体停止。

## 节点 5　事务执行、证照共管与表见代理

### 5.1 执行与重大事项

除另有约定外，合伙事务决定应当经全体合伙人一致同意；可以委托一个或数个合伙人执行，其他合伙人有权监督。登记名义人对外是经营者，不等于内部可以单方贷款、抵押、大额采购、转让经营权或注销执照。

| 文本写法 | 动作 |
| --- | --- |
| “未经内部书面同意的对外合同一律无效” | 必须改。内部限制不得对抗善意相对人 |
| 公章、执照原件、税务 UKey、网银全部由登记人持有，无交接或共管 | 必须改 |
| 未写重大事项清单 | 必须补：贷款、抵押、大额采购、转让经营权、变更或注销登记 |

修改句：

「日常经营由【共同执行 / 委托甲方对外执行】。下列事项须经全体合伙人书面一致同意：以本个体工商户名义借款或提供担保；抵押、质押或处分合伙财产；单笔超过人民币【待填】元的采购或处分；变更字号、经营场所、经营范围或组成形式；转让经营权；申请变更经营者或注销登记。甲方持有的营业执照原件、公章、财务章、税务 UKey 和网银介质，按附件保管清单由【待填】保管或共管。本协议对对外代表权的限制，不得对抗不知晓本协议的善意相对人；越权对外发生的债务，内部仍按本协议追偿。」

### 5.2 身份否认与经营权夺取

盈利时否认合伙、亏损时主张对方是合伙人：修改句同时写分红权和亏损分担，禁止单边“只分红不亏损”。登记人利用证照把非登记方踢出经营现场：须有排除妨碍、强制变更或注销配合义务和高额违约金。

## 节点 6　格式条款、挂靠与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 格式条款

为重复使用而预先拟定、订立时未与对方协商。依据示范文本制作，不当然排除格式条款。

审查：对外免责、永远不得退伙、单方注销、管辖/仲裁等异常条款是否有足以引起注意的标识，以及是否按要求说明（第 496 条；解释第 10 条）。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在附件 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

### 6.2 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的、是否仅行政管理、是否只规制履行行为（第 153 条；解释第 16 条）。禁止用已失效“效力性/管理性”口诀。挂靠、出借执照、规避准入、对外豁免连带：不改写成有效履行。

未登记即以该字号对外经营：告知市场主体登记管理条例第 3 条风险，不改成可履行的无照经营过渡。

## 节点 7　违约、退伙变更与争议

1. 擅自处分合伙财产、单方注销或变更登记、把非登记方踢出经营现场、拒绝分红或拒绝分担亏损：须分别有可执行后果（违约金、配合变更或注销、排除妨碍、赔偿）。只有“依法承担违约责任”视为必须改。
2. 退伙必须写：通知期、估值办法（净资产或营业额倍数等栏目，数字 `【待填】`）、是注销还是变更经营者、执照和许可交接。禁止“永远不得退伙且无结算”。
3. 变更经营者：促进个体工商户发展条例第 13 条，可申请变更登记；应结清税款并对原有债权债务作出妥善处理，不得损害他人合法权益。修改句写成双方义务和条件，不写成已经完成变更。
4. 公司化过渡可点名为可优化，达到约定营业额后配合改制；不出有限公司整稿，不写成已经隔离全部个人责任。
5. 违约金不是必得金额。修改句避免“不得调整”。
6. 争议解决：出现仲裁条款，不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核，修改句改成单一仲裁机构或单一法院连结点。专属管辖可能：只标红旗。
7. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。

修改句：

「一方退伙的，应提前【待填】日书面通知。退伙结算按【净资产法 / 营业额倍数法 / 待填】，以退伙通知到达之日前【待填】个月的账册和库存盘点为准。退伙时各方应选择：办理经营者变更登记，或注销该个体工商户。变更经营者的，应当结清税款并对原有债权债务作出书面安排，不得损害债权人合法权益。登记名义人擅自转让经营权、抵押合伙财产或申请注销的，应向其他合伙人支付违约金人民币【待填】元，并配合办理变更或恢复登记；因此不能追回的财产，由登记名义人按本协议赔偿。」

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

打开已加载的 `框架.md`，按六步逐段对照正文。`基本面.md` 用于校验类型、主体、登记外观、对外责任和红旗，不代替本节点出句。

| 步 | 动作 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题用合作经营协议或合伙经营合同；主体分列登记名义人与实质合伙人；鉴于写名实分离，不写对外免责 | 标题或主体修改句 |
| 交易条款 | 出资与财产锁定；共同经营；利润亏损；对外连带与内部追偿分行 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 证照共管；擅自处分违约；退伙注销或变更经营者；家庭财产告知 | 可执行后果句或删除句 |

| 常见问题 | 对外免责；登记即所有权；善意第三人追及；避税；财产被登记人个人债权人查封 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（对外免责、内部协议对抗任何第三人、挂靠规避、保底借贷、倒签、只分红不亏损）；
- `必须改`：可谈但签署前要落句（名实分离鉴于、对外连带明示、财产锁定、证照共管、退伙变更、家庭经营分层）；
- `可接受可优化`：仍要给句子，不得只标绿（共管账户细节、公司化过渡、见证、质押点名）。

用户不可接受事项优先写成红线。生存级个人或家庭财产可能被追索且用户拒绝升级：停止“可以签署”建议。
