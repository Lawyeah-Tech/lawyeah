# 登记为个体工商户的实质合伙合同·审查

## 任务目标

在单一立场下，只审查 **合伙合同相关 / 登记为个体工商户的实质合伙合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查登记为个体工商户的实质合伙合同（合伙合同相关）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、把隐名合伙或不领个体户执照的个人合伙改完、把内部按份写成对外免责、把挂靠或规避准入改成可履行结构。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **登记外观 vs 实质合伙**：核心给付是以一人名义登记为个体工商户，内部由数个自然人共同出资、共同经营、共享利益、共担风险。鉴于条款必须写明“名为个体工商户、实为合伙”。内部书面协议约束合伙人；执照登记不是唯一权属证明。内部协议不得对抗善意第三人。不得把“内部效力优于登记”写成已经击败公示和善意相对人。
2. **对外责任**：个体工商户债务，个人经营以个人财产承担，家庭经营或以家庭财产出资、无法区分的，以家庭财产承担。登记经营者对外承担责任；登记经营者与实际经营者不一致的，诉讼上可为共同诉讼人。内部按份分担或“债权人不得向非登记方主张”不得写成对外免责。登记名义人超额清偿后可按约定向其他合伙人追偿。执行中可能追加实际合伙人：标风险，不得写成“隐名方对外绝对免责”，也不得写成“法院必然追加”。
3. **与隐名合伙切开**：本类型非登记方必须共同经营、共担风险。一方不参与经营、不承担亏损、仅出资隐名 → `隐名合伙合同·审查`；到期固定本息 → `或企业间借款` 或 `不参与经营不承担亏损到期固定本息→自然人之间借款`。禁止把隐名合伙的“不经营、不担债、仅以出资为限”改成个体工商户实质合伙的可履行结构。禁止抄 `隐名合伙合同·审查` method。标题写“隐名合伙”但正文是共同经营个体工商户：按核心给付留本技能，标题冲突写入 `C#`。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签合作经营协议或合伙经营合同，尚未签署，尚未成争；外观将登记或已拟登记为个体工商户；内部共同出资、共同经营、共担风险；用户问能不能签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 一方出资不显名、不参与经营、不承担合伙债务或仅以出资为限 → `隐名合伙合同·审查`；
- 不登记个体工商户、不以个体户字号对外、只适用民法典合伙合同 → `个人合伙合同·审查`；
- 拟领取普通合伙企业执照、名称标明“普通合伙” → `普通合伙企业合同·审查`；
- 出现有限合伙人或认缴为限 → `有限合伙企业合同·审查`；
- 执业故意或重过失切割其他合伙人责任 → `特殊的普通合伙企业合同·审查`；
- 劳务出资已成主轴且无个体户登记外观 → `劳务出资型合伙合同·审查`；
- 股权激励型合伙主文件 → `股权激励型合伙合同·审查`；
- 不参与经营、不承担亏损、到期固定本息 → `或企业间借款` 或 `不参与经营不承担亏损到期固定本息→自然人之间借款`；
- 只拿固定报酬不担风险 → `只拿固定报酬不分担亏损无合伙人决策权→个人劳务（雇佣）`；人格从属加工资社保 → `人格从属＋工资社保→劳动合同`；
- 无文本、本类型条件已谈妥、要出己方稿 → `登记为个体工商户的实质合伙合同·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁，或要散伙清算诉讼策略 → `已出现催告解除函索赔立案开庭仲裁` 或对应专项领域。

挂靠、出借个体户资质、规避行业准入或限购、为避税而虚构合伙：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（登记名义人或非登记实质合伙人择一）；相对方；全文及附件版本；拟用字号与个体工商户执照路径；组成形式是个人经营还是家庭经营；各方是否共同经营、共担风险；出资、账户、证照与公章保管；利润亏损与对外责任写法；退伙时注销或变更经营者；不可接受事项；法域、拟登记地与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `登记为个体工商户的实质合伙合同·起草`；已签履约 → 本套导航履约步骤；已成争或清算诉讼策略 → 合同争议。未签且目标是评改已有本类型文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。隐名合伙、不领个体户执照的个人合伙、合伙企业、雇佣、借贷负触发。标题写隐名合伙但正文共同经营个体工商户：留本技能。

### 2. 主体、登记外观与组成形式

登记名义人与非登记实质合伙人分列。家庭经营、家庭财产出资未闭合：字段停止。鉴于必须写名实分离。

### 3. 出资、字号与财产锁定

字号、租赁权、设备、存货、特许许可锁定为合伙财产。账户混同必须改。善意第三人取得不得用内部协议追回，只能内部追偿。

### 4. 对外责任与内部追偿

对外不得免责。第 56 条个人/家庭经营分列。登记与实际经营者不一致时提示共同诉讼风险。对内追偿分行。

### 5. 事务执行、证照共管与表见代理

重大事项一致决。公章、执照、税务 UKey、网银分管。内部限权不得对抗善意相对人。

### 6. 格式条款、挂靠与强制规范

挂靠、规避准入、避税停笔。无核验引文则法律结论字段停止。

### 7. 违约、退伙变更与争议

擅自处分、单方注销须有可执行后果。退伙写清注销或变更经营者及估值办法。变更经营者须结清税款并处理债权债务。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把内部按份改成对外免责、把“不经营不担债”硬套本类型、把挂靠或规避准入改成可履行。
- `字段停止`：法域、执照路径、组成形式、家庭财产、特许许可、估值办法未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。

生存级个人或家庭财产可能被追索且用户拒绝升级：停止“可以签署”建议。
