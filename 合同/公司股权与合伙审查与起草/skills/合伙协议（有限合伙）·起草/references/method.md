# 审查方法（锁定 公司相关合同 / 合伙协议（有限合伙））

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制普通合伙民法典主路径、隐名合伙或特殊普通合伙执业责任节点。

定性校验：标题、核心给付与本类型一致才继续；特殊普通合伙、隐名合伙、个人合伙、无 LP 的普通合伙企业或其他主文件明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、必然可登记、LP 有限责任必然不被刺破、对方必然接受或唯一必得金额。

`search_law` 返回 1997 年《合伙企业法》或其条号、已失效《合同法》及其解释、已失效《合伙企业登记管理办法》、已失效外商投资合伙企业登记管理规定时记为噪声，不得写入 `L#`。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。普通合伙、隐名合伙或律所合伙范本只证明是另一类型，不得当作本类型范本。

知识库纠正（不回写双文件）：

- `基本面.md` “合伙合同并非民法典规定的典型合同”：民法典第 967 条已规定合伙合同。本类型是**拟登记有限合伙企业**的合伙协议，主法是《合伙企业法》（2006 修订）；民法典合伙合同章不替代 GP/LP 规则，也不把本任务改成个人合伙审查。
- `基本面.md` “LP 参与投决会并享有实质性投票权即突破有限责任”：第 68 条安全港含“对企业的经营管理提出建议”。建议权 ≠ 对外代表或最终投资决定。只有实质性决策、对外签字或使第三人有理由相信其为 GP，才讨论第 76 条该笔交易同等责任。不得写成“进了投决会就必然变 GP”。
- `框架.md` “LP 出质必须经全体合伙人一致同意”：有限合伙人出质以第 72 条为准（可以，除非协议另有约定）。全体同意是普通合伙人出质的默认规则，运行时核验第 25 条后再写入 `L#`，不得套到 LP。
- `框架.md` “不定期合伙可随时解除”：登记有限合伙企业退伙走企业法，未约定合伙期限的，须不给事务执行造成不利影响并提前通知，不是民法典个人合伙的随时解除。
- 第 69 条是“原则不得将全部利润分配给部分合伙人，另有约定除外”，不是“应当把全部利润分给部分合伙人”。
- 外籍 GP“必须约定国际仲裁”只是执行便利建议，不是法定义务。
- 1997 年法条号与 2019 年《合伙企业登记管理办法》（MCP 标失效）不得写入 `L#`。

先于类型识别。命中任一项则本任务不填十节实体结论，只交付分流理由和最小交接。

| 已能支持的事实 | 走向 | 不得写成 |
| --- | --- | --- |

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 拟设立或变更有限合伙企业，文本分列 GP 与 LP，名称拟标明“有限合伙”，拟领取执照 | 本类型 | 正触发 |
| 不领执照、不以企业名义登记 | 个人合伙 | 负触发 `个人合伙合同·审查` |
| 全员普通合伙人、无 LP、名称标“普通合伙” | 普通合伙企业 | 负触发 `普通合伙企业合同·审查` |
| 用户明确只要合伙合同相关货架的有限合伙企业合同审查 | 货架平行原子 | 转 `有限合伙企业合同·审查`；正触发本货架后不互踢 |
| 名称标“特殊普通合伙”，或执业故意／重过失切割其他合伙人责任 | 特殊普通合伙 | 负触发 `特殊的普通合伙企业合同·审查` |
| 不显名、不登记、约定不参与经营且不承担合伙债务 | 隐名合伙 | 负触发 `隐名合伙合同·审查` |
| 律师事务所合伙协议主文件 | 律所合伙 | 负触发 `律师事务所合伙协议·审查` |
| 股东会／董事会治理、注册资本、股权比例一揽子 | 股东协议 | 负触发 `公司股东协议·审查` |
| 主给付是限制性股票授予、限售与回购 | 激励本约 | 负触发 `上市公司限制性股票激励协议·审查`；持股平台主文件是本协议则留下 |

支持切开的规范（法律结论须运行时复核）：

- 合伙企业法（2006 修订）第 2 条：有限合伙企业由普通合伙人和有限合伙人组成。
- 第 55、56 条：专业服务机构可设特殊的普通合伙企业，名称标明“特殊普通合伙”。
- 民法典第 967、973 条：个人合伙合同共享利益共担风险，合伙人对外连带——无企业执照时走 `个人合伙合同·审查`，不得写成已有 LP 避风港。

### 1.2 加载协议（硬闸）

本技能已锁定 **公司相关合同 / 合伙协议（有限合伙）**。只打开 `references/基本面.md` 与 `references/框架.md`。禁止读其他子目录，禁止为对照再开第二类。禁止打开普通合伙或隐名合伙 method。

### 1.3 与特殊普通合伙 / 隐名合伙切开（硬闸）

| 文本写法 | 本任务动作 | 修改句方向 |
| --- | --- | --- |
| 名称拟用“××合伙企业（有限合伙）”，列明至少一名 GP 与一名 LP | 正触发 | 首部写明身份类别与责任形式 |
| 名称标“特殊普通合伙”，或执业过错由该合伙人无限责任、其他合伙人以财产份额为限 | 负触发 `特殊的普通合伙企业合同·审查` | 不按 GP/LP 改完 |
| 一方“隐名出资、不登记、不担债、固定回报” | 负触发 `隐名合伙合同·审查`，或红线改为显名 LP | 不把隐名安排改成可履行有限责任 |
| 无 LP、全体无限连带 | 负触发 `普通合伙企业合同·审查` | 不得删 LP 后硬套，也不得把本类型改成普通合伙 |

最强反方：相对方主张“有限合伙”只是名称，实质是全体普通合伙或隐名借贷。修改句必须在正文反复分列 GP/LP 权利义务。用户坚持隐名或不登记仍要有限责任：负触发，不填本类型十节实体结论。

### 1.4 公开募集 / 保本承诺 / 倒签停笔

加载后或定性中出现：向不特定对象公开宣传推介；向非合格投资者募集；承诺投资本金不受损失或最低收益；倒签或补假登记材料。

动作：

1. 交付告知：私募投资基金监督管理条例第 18、20 条禁止向合格投资者以外募集、公开宣传和保本保收益承诺；可能触碰非法吸收公众存款等刑事红线。不得改写成可履行募集或保本结构。
2. 不写可履行的公开推介话术、代持拆分或假备案路径。
3. 风险表只保留识别依据和删除/转出口径。
4. 用户坚持“改到能签且仍做这些事”：整体停止。

## 节点 2　主体、禁入与人数

### 2.1 主体表

建表：签约名、GP/LP 身份、认缴额、出资方式、缴付期限、授权签字人。名称不一致不自动合并。自然人须具备完全民事行为能力。口头“我们老板同意了”不得写成已授权。

协议必须写明谁是普通合伙人、谁是有限合伙人。身份空白：必须改，不写成“可以按出资额自行推定”。

### 2.2 GP 禁入与人数（硬闸）

支持依据：第 3、61 条。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| GP 为国有独资公司、国有企业、上市公司，或公益性事业单位、社会团体 | 红线。不改成可登记 GP；可点名改为 LP 或退出主体，不在本任务出他类整稿 | 内部同意即可担任 GP |
| 合伙人不足 2 人或超过 50 人（法律另有规定除外） | 红线；修改句删减或拆分结构，不编造合规人数 | 先登记再调整人数即可 |
| 无普通合伙人 | 红线。至少保留一名适格 GP | 全体改为 LP 仍可设立 |
| 未核主体营业执照或公益属性 | 字段停止 | 可以登记 |

修改句：

「第【待填】条合伙人身份表应分列普通合伙人与有限合伙人。国有独资公司、国有企业、上市公司以及公益性的事业单位、社会团体不得担任普通合伙人。本有限合伙企业合伙人人数为【待填】名，其中普通合伙人不少于一名，合计不超过五十名（法律另有规定的除外）。」

部门或登记窗口的材料清单未核：只停止“可以登记”，不宣告协议当然无效。

## 节点 3　执行事务与安全港（硬闸）

支持依据：第 67、68、76、37 条。

### 3.1 执行主体

必须写明：有限合伙企业由普通合伙人执行合伙事务；有限合伙人不执行合伙事务，不得对外代表有限合伙企业。执行事务合伙人的确定、权限、报酬、除名与更换按第 63 条载明。

| 文本写法 | 动作 |
| --- | --- |
| 约定“全体合伙人均可对外代表”或“LP 有权以企业名义签约” | 红线删除。LP 对外代表触发第 76 条 |
| 仅约定 GP 执行，并列出第 68 条八项不视为执行 | 可保留；检查投决会是否突破建议权 |
| 对执行事务合伙人的内部限权 | 可保留，但须提示第 37 条：内部限制不得对抗善意第三人 |

第 68 条不视为执行事务：（一）参与决定普通合伙人入伙、退伙；（二）对企业的经营管理提出建议；（三）参与选择承办审计的会计师事务所；（四）获取经审计的财务会计报告；（五）对涉及自身利益的情况查阅财务会计账簿等；（六）利益受侵害时主张权利或提起诉讼；（七）执行事务合伙人怠于行使权利时督促或为了本企业利益以自己名义起诉；（八）依法为本企业提供担保。

### 3.2 投决会与表见执行

| 文本写法 | 动作 |
| --- | --- |
| LP 仅列席投决会、无表决，或仅有第 68 条建议／查阅／一票否决保护性权利且不得对外代表 | 可接受可优化：写清“不构成执行合伙事务” |
| LP 在投决会对投资项目有决定性多数表决，或可单独批准对外签约 | 必须改。收回最终决定权和对外代表权；保留建议、查阅、督促起诉 |
| “任何内部限制均不得影响已签署合同”却同时授权 LP 对外 | 红线。删除 LP 对外授权 |

修改句：

「有限合伙企业由普通合伙人【姓名／名称】执行合伙事务。有限合伙人不执行合伙事务，不得对外代表本企业。有限合伙人行使下列权利，不视为执行合伙事务：【按第 68 条八项列明】。投资决策委员会中有限合伙人委派委员仅有建议权或针对【待填】保护性事项的否决权，不得形成对外投资或对外签约的最终决定。第三人有理由相信有限合伙人为普通合伙人并与其交易的，该有限合伙人对该笔交易承担与普通合伙人同样的责任。」

最强反方：LP 主张查阅账簿或保护性否决已被当成执行事务。现有依据支持第 68 条所列行为不视为执行。GP 主张“给了建议权就会被刺破”：现有依据不支持把建议权单独写成已突破有限责任。

## 节点 4　出资、认缴实缴与分配（硬闸）

### 4.1 出资形式

支持依据：第 64、65、66 条。GP 劳务出资以第 16 条为准，运行时核验全文后再写入 `L#`。

| 文本写法 | 动作 |
| --- | --- |
| LP 以劳务、管理、技术服务作价出资 | 红线。改为货币、实物、知识产权、土地使用权或其他财产权利；劳务只可记为 GP 出资或另行劳务／顾问合同 |
| 认缴额、缴付期限空白 | 必须改。未按期足额缴纳的，补缴并对其他合伙人承担违约责任 |
| 非货币出资无财产权转移手续 | 必须改。未过户不得写成已属于合伙企业财产 |
| 只写实缴、不写认缴 | 必须改。LP 责任上限是认缴；登记事项应载明认缴数额 |

修改句：

「各合伙人认缴出资额、出资方式、缴付期限和财产份额见附件一。有限合伙人不得以劳务出资。以非货币财产出资的，应于【待填】日前依法办理财产权转移手续；未完成转移前，不得对抗该财产上的合伙人个人债权人。有限合伙人未按期足额缴纳的，应当补缴，并向其他合伙人承担违约责任。」

禁止编造认缴数字。

### 4.2 利润与亏损

支持依据：第 69 条；第 60 条转介的普通合伙分配规则（第 33 条全文运行时核验后再写入 `L#`）；民法典第 972 条仅作个人合伙对照，不替代企业法。

| 文本写法 | 动作 |
| --- | --- |
| 有限合伙另约将全部利润分配给部分合伙人 | 可保留，但须加黑提示；不得写成法定义务 |
| 约定由 GP 或某一方承担全部亏损，其他合伙人不担亏损 | 红线删除。现有依据不支持该约定 |
| 对内亏损按实缴分担，同时写“LP 对外亦不承担责任” | 必须改。对外 LP 以认缴为限，GP 无限连带；对内分担不得对抗债权人 |
| 分配标准空白 | 必须改：先约定；未约定则协商；不成按实缴；无法确定则平均 |
| LP 固定年化回报、不担经营风险，并有 GP 担保本息 | 红旗：名为合伙实为借贷。不改成可履行保底；提示可能被认定为借贷。用户坚持保底：整体停止 |

修改句：

「利润分配按本协议第【待填】条约定办理；本协议可以约定将全部利润分配给部分合伙人。亏损分担按第【待填】条办理，不得约定由部分合伙人承担全部亏损。未约定或约定不明确的，由合伙人协商决定；协商不成的，按照实缴出资比例分配、分担；无法确定出资比例的，平均分配、分担。普通合伙人对合伙企业债务承担无限连带责任；有限合伙人以其认缴的出资额为限承担责任。本条对内分担不得对抗合伙企业的债权人。」

认缴是责任上限，实缴是默认分配基数。二者不得混用。

## 节点 5　份额变动、除名与身份转换

### 5.1 转让与出质

| 身份 | 默认规则 | 修改句方向 |
| --- | --- | --- |
| LP 向合伙人以外的人转让 | 可按协议约定转让，应提前三十日通知其他合伙人 | 补通知期限 `【待填】` 日，不少于三十日 |
| GP 向合伙人以外的人转让 | 除协议另有约定外，须其他合伙人一致同意，其他合伙人有优先购买权 | 不得把 GP 对外转让写成通知即可 |
| LP 出质 | 可以，除非协议另有约定 | 不要套“必须全体同意” |
| GP 出质 | 运行时核验第 25 条：须其他合伙人一致同意 | 未核验不写当然无效 |

流质（到期未偿份额归债权人）不得写成可履行。抵债须尊重人合性，不得绕开其他合伙人。

### 5.2 入伙、退伙、除名

支持依据：第 43、48、49、78、81 条。

- 新合伙人入伙，除协议另有约定外，须全体合伙人一致同意并订立书面入伙协议。私募实务可另约新 LP 入伙由执行事务合伙人决定——须明文，不得默示。
- 除名：未履行出资义务；故意或重大过失造成损失；执行事务有不正当行为；协议约定的其他事由。决议须**其他合伙人一致同意**，书面通知；接到通知之日生效；异议须自接到通知之日起三十日内起诉。
- 协议把除名改为“三分之二多数同意”：必须改回其他合伙人一致同意。不在本任务用失效口诀宣告条款当然无效；现有依据不支持把该门槛降低后仍按已生效除名放行。
- LP 当然退伙不适用“个人丧失偿债能力”（第 78 条）。LP 退伙后，对基于退伙前原因发生的债务，以其取回财产为限（第 81 条）。

持股平台：可将“与目标公司解除劳动关系”约定为退伙或除名事由。未写则标必须改，不补具体补偿数字。

### 5.3 身份转换

除协议另有约定外，GP 转变为 LP 或 LP 转变为 GP，应当经全体合伙人一致同意（第 82 条）。GP 转为 LP 的，对其作为 GP 期间债务仍承担无限连带责任（第 84 条）。LP 转为 GP 的对外责任，运行时核验第 83 条后再写入 `L#`。仅剩 LP 应当解散；仅剩 GP 转为普通合伙企业（第 75 条）。

## 节点 6　格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 格式条款

为重复使用而预先拟定、订立时未与对方协商。基金管理人提供的基金有限合伙协议常构成格式条款。审查：执行事务报酬、全部利润另约、免责、管辖／仲裁等异常条款是否有足以引起注意的标识，以及是否按要求说明（第 496 条；解释第 10 条）。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在附件 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

### 6.2 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的、是否仅行政管理、是否只规制履行行为（第 153 条；解释第 16 条）。禁止用已失效“效力性／管理性”口诀代替解释第 16 条。

现有依据不支持放行：协议免除 GP 对外无限连带；LP 劳务出资；部分合伙人承担全部亏损；禁入主体担任 GP。公开募集、保本承诺：不改写成有效履行。

## 节点 7　违约、解散与争议

1. 未按期出资：补缴、违约金、经其他合伙人一致同意除名。只有“依法承担违约责任”视为必须改。
2. GP 不正当执行、故意或重大过失、违反竞业或自我交易：可取消执行资格、赔偿。GP 竞业为禁止（第 32 条）；LP 可以竞业、可以与本企业交易，除非协议另有约定（第 70、71 条；第 70 条运行时核验）。
3. 构成违约不等于当然解除或当然除名。除名异议三十日是除斥期间，只点名，不在本任务认定已除名或已逾期。
4. 违约金不是必得金额。修改句避免“不得调整”。
5. 解散：可约定项目完成等特定事由。合伙期限应明确；未约定不得写成可随时无条件散伙。
6. 争议解决：出现仲裁条款，不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核。外籍 GP：可建议仲裁作为执行便利，不写成法定义务。
7. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。
