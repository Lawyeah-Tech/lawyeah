# 边界与路由

本技能只审查 **公司相关合同 / 增资合同**。主线是已设立公司新增注册资本，价款进公司。不是新设认缴，不是存量股权买卖，也不是 PE 增资一揽子。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 公司尚未成立、新设认缴、设立出资进拟设公司 | `出资合同（有限责任公司）·审查` |
| 价款进原股东、存量股权让与、注册资本不因本约增加 | `公司股权转让·审查` |
| 主文件是股东协议：投后治理、否决权、随售／拖售 | `公司股东协议·审查` |
| 业绩对赌、估值调整作为主文件 | `对赌协议（盈利预测补偿协议）·审查` |
| 投资侧增资、估值调整、优先清算、反稀释一揽子 | `增资协议·审查` 或 `PE股东协议·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、问缴资日／递件日／催缴留痕 | 本套导航的履约步骤 |
| 决议效力／撤销／不成立之诉，或优先认缴侵权已立案仲裁 | 公司争议领域；不填签前十节 |
| 明股实债（不参与经营、不担风险、到期固定本息） | 留本任务只出红线告知；用户坚持改成可履行股权则整体停止。可点名转借贷，不在本任务起草借款 |
| 国资未评估挂牌或外资负面清单未核 | 字段停止；不写场外可履行 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

专业版未收录的投资侧场景不会作为本原子的实体审查对象。若用户拿这些文本来找本技能：输出 `unavailable` 或负触发路由，不得用本类型硬套。

本技能不得转去加载出资、转让或投资侧双文件完成本类型审查，也不得把成立之日起五年认缴、优先购买三十日或名册登记对抗写成增资默认主路径。
