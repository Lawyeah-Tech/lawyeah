# 边界与路由

本技能只审查 **公司相关合同 / 定向减资合同**。主线是公司收回特定股东股权并注销，注册资本减少，对价由公司支付。不是存量买卖，也不是回购主文件。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 价款进原股东、存量股权让与、注册资本不因本约减少 | `公司股权转让·审查` |
| 已发行股权按约定条件由公司或股东购回；行权、上市失败、对赌触发为主给付；减资只是履约附件 | `股权回购协议·审查` |
| 价款进公司换新增注册资本 | `增资合同·审查` |
| 业绩对赌、盈利预测补偿、估值调整作为主文件 | `对赌协议（盈利预测补偿协议）·审查` |
| 主文件是股东协议：投后治理、否决权、随售／拖售 | `公司股东协议·审查` |
| 用户要整份代审章程或章程修正案 | `公司章程_章程修正案·审查`；本任务只并列减资条款冲突 |
| 主文件是股权代持 | `股权代持协议·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、问公告日／付款日／递件留痕 | 本套导航的履约步骤 |
| 债权人异议、减资无效／恢复、抽逃索赔、决议撤销已催告、立案、开庭或仲裁 | 公司争议领域；不填签前十节 |
| 公司被写成签字后立即现金划付且无需通知债权人 | 留本任务只出红线；用户坚持改成可履行则整体停止 |
| 用弥补亏损简易减资向股东分配或免除出资 | 留本任务只出红线；用户坚持则整体停止 |
| 国资未评估／未进场或外资／特许最低资本未核 | 字段停止；不写场外可履行 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。

本技能不得转去加载转让、回购、增资或对赌双文件完成本类型审查，也不得把优先购买三十日交割包、“股东回购可谈／公司付款绑定利润”或五年认缴清单写成定向减资默认主路径。
