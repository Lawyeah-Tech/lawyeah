# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、必然显名、必然排除执行、还原过户免税或对方接受；编造未给出的出资额、比例、估值、税率或税额；把已失效《合同法》、2011 年解释三同条号、物权法第一百零六条或 1980 年个税法写入结论；把规避限购／外资改成可履行；把托管、隐名合伙、公司侧挂名、股权转让或赠与当成已完成的本类型审查。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查股权代持合同（股权投资相关合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、2011 年解释三同条号、物权法第一百零六条、1993／2018 年公司法同条号或 1980 年个税法时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `股权投资相关合同`，子级 `股权代持合同`。定性理由、易混切开结果（公司侧代持 / 托管 / 隐名合伙 / 转让 / 赠与 / 增资 / 股东协议 / 借贷）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。规避限购或外资写停笔告知，不填可履行结构。

## 4. 主体、准入、出资路径与文本版本

主体表：实际出资人（隐名）、名义股东／持股平台（显名）、目标公司（非当然签约方）、其他股东、授权签字人。准入表：外资、限购、公职、上市、持牌。出资表：付款人、收款账户、备注、回单持有人。版本表：正文、回单、确认函、资本表、质押合同、聊天确认；冲突并列。

## 5. 显名／隐名、处分限制、税务与无效

隐名对内投资权益是否以实际出资为前提；显名是否具备其他股东半数以上同意；处分限制是否闭合、是否误写当然无效；税负分担是否落句、是否保证免税；执行风险是否被写成可对抗。缺口标 `G#`。不输出“签字即股东”，不输出“质押后必然挡执行”，不输出“还原过户免税”。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹。规避限购／外资／公职／上市代持不得写成可放行。强制规范只按第一百五十三条区分是否导致民事行为无效，不用失效口诀。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把托管、隐名合伙、转让或赠与程序直接写成“代持类型”。

## 9. 谈判与签署提醒

谈判顺序：先红线（规避限购／外资、保证显名、保证免税、固定回报或赠与外壳、对抗执行），再必须改（出资路径与备注、半数同意函、处分限制、税负分担、后续轮次经济成果、指示与票证），最后可优化（出质登记、配偶知情）。签署提醒：双方亲签、配偶确认、其他股东确认页、回单原件、指示函模板。不指导倒签、补假同意函或出具免税承诺。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书、效力保证或税务核定，也不是托管、隐名合伙、公司侧挂名或投资侧转让／赠与／增资安排。
