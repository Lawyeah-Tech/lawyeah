# 边界与路由

本技能只审查 **股权投资相关合同 / 股权代持合同** 的待签、投资场景下名义登记与投资权益分离文本。中文展示名是「审查股权代持合同（股权投资相关合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或复制 `出资合同·审查`、`房地产项目股权取得类合同·审查`、`PE股权转让·审查`、`投资意向书·审查`、`PE股东协议·审查`、`增资协议·审查` 的 method。禁止按股权转让或赠与改完。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 无投资交割包、无持股平台／通道／后续轮次安排的公司侧普通隐名出资 | `股权代持协议·审查` |
| 登记股东不变；只托管表决、分红、证照或股权凭证 | `股权托管协议·审查` |
| 不登记为公司股东；出资给显名经营人；按经营利润分成 | `隐名合伙合同·审查` |
| 价款进原股东；存量股权买卖、优先购买／交割为主给付 | `PE股权转让·审查` |
| 无偿过户、无对价、无出资证据；登记方被写成真实股东、对方仅分红 | 赠与嫌疑：不按本类型放行，不填十节 |
| 价款进公司、新增注册资本、增资协议为主文件 | `增资协议·审查` |
| 主轴是投后治理、否决权、随售／拖售、竞业 | `PE股东协议·审查` |
| 主文件是条款清单／Term Sheet | `投资意向书·审查` |
| 新设出资本约 | `出资合同·审查` |
| 房地产项目公司股权取得为主给付 | `房地产项目股权取得类合同·审查` |
| 到期固定本息、不承担经营风险 | 借贷嫌疑：字段停止或转借款原子；不按本类型放行 |
| 不改登记、只委托表决 | 表决权委托，不启动本任务 |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式（出稿后自审） |
| 已签未争、只问转付日／指示留痕／报税窗口 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `已出现催告解除函索赔立案开庭仲裁` 或对应专项领域 |
| 确认股东资格、显名之诉、排除执行已立案 | 公司或投资争议专项，不在本任务评改 |
| 用代持规避限购／外资／公职／上市／牌照 | 停笔告知；用户坚持可履行规避则整体停止 |
| C 端大众快检或代持退出评估 | 只分流，不回改 |

投资侧代持正文里夹带一小段增资交割或股东协议：专章交接对应原子；代持条款可继续审。用户坚持本技能把托管、隐名合伙、公司侧挂名、转让或赠与整案改完：`目标停止`。

本原子为 P1。专业版未收录时：输出 `unavailable`，提示，不得用邻类硬套。
