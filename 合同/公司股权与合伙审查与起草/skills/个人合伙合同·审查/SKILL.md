# 个人合伙合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构，不证明本约条款已被接受。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、民法通则第三十一条书面强制、1990 年联营解答保底条款当作现行规则。不得把《合伙企业法》普通／有限合伙治理写成个人合伙默认路径。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **合伙合同相关 / 个人合伙合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。`depends-on` 为空。不要求先跑导航。

主线是**无法人资格、不领取合伙企业执照的自然人共同事业**，适用《民法典》合伙合同章。不是合伙企业、不是公司股东协议、不是借贷、不是雇佣。

不交付：他类审查、从零起草、履约交底、争议文书、有效性或必然赢利保证、把保底改成可履行股东、把公职禁止经营改成隐名规避。

## 工作边界

正触发：已有可读待签文本要评改，；尚未签署，尚未成争；核心给付是两个以上自然人为共同事业目的共享利益、共担风险；不设立或承接已领取营业执照的合伙企业。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 已领取或文本以领取普通合伙企业执照为主给付 → `普通合伙企业合同·审查`；
- 有限合伙、普通／有限合伙人分档、认缴为限 → `有限合伙企业合同·审查`；
- 主文件是公司股东协议（股权比例、否决权、随售拖售、章程治理）→ `公司股东协议·审查`；
- 不参与经营、不承担亏损、到期固定本息 → 自然人之间借款 `不参与经营不承担亏损到期固定本息→自然人之间借款`，或企业间借款 `或企业间借款`；
- 只拿固定报酬、不分担亏损、无合伙人决策权 → 个人劳务（雇佣）`只拿固定报酬不分担亏损无合伙人决策权→个人劳务（雇佣）`；人格从属＋工资社保 → 劳动合同 `人格从属＋工资社保→劳动合同`；
- 无文本、本类型条件已谈妥、要出己方稿 → `个人合伙合同·起草`；
- 已签只问出资日、分账留痕 → 本套导航的履约步骤；
- 已成争（催告散伙、清算诉讼、索赔、立案仲裁）→ **合同争议领域**，不填签前十节。

公务员等禁止营利经营、挂靠个体户资质：只出告知，不改写成可履行规避结构。

## 建立审查坐标

确认：使用者与授权；代表哪一方合伙人；相对方；正文与附件版本；出资／损益／执行／退出安排；不可接受事项；法域与拟签时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的出资金额、损益比例、通知期用 `【待填】`，不编造。

## 本类型硬闸

审查过程必须逐项点名，每闸必须有修改句，不得用股东优先购买、合伙企业除名程序或借款利率上限代替：

1. **个人合伙 ≠ 合伙企业 ≠ 借贷 ≠ 雇佣**：无法人资格、不领执照，适用民法典。已登记或拟领普通／有限合伙企业执照 → `普通合伙企业合同·审查`／`有限合伙企业合同·审查`。不参与经营、不承担亏损、到期固定本息 → 负触发借款。只拿固定报酬不担风险 → `只拿固定报酬不分担亏损无合伙人决策权→个人劳务（雇佣）`。
2. **共享利益共担风险**：保底“只分红不亏损”可能导致定性被否定。修改句删除保底或改为亏损分担＋补偿谈判，不得写成可履行保底股东。
3. **对外责任**：合伙人对合伙债务通常承担连带。修改句必须提示对外连带，内部按份分担不得对抗债权人。
4. **事务执行与代表**：执行人权限、重大事项一致决或多数决、表见合伙（未签字但以合伙人名义经营）。
5. **出资与财产**：货币／实物／劳务出资写清；合伙财产与个人财产分离记账。配偶同意作为可优化（出资可能是夫妻共同财产）。
6. **退出与解散**：声明退出通知期、结算、竞业；解散事由与清算。禁止“永远不得退伙且无结算”。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验《民法典》第九百六十七条至第九百七十八条（定义、出资、财产、事务执行、报酬、损益、对外连带、份额转让、代位、期限与退伙、死亡终止、清算分配）；《合伙企业法》第二条、第十四条仅用于与企业切开；民间借贷规定与合同编通则解释第十五条仅用于与借贷切开；公务员法第五十九条第十六项、政务处分法第三十六条仅用于公职告知。`search_practiced` 补审查反例；`search_template` 只借修改句结构。不虚构案件系统。

`search_law` 对法律结论为 required 级节点：不可用时不拒绝执行，只停止法律结论字段。返回民法通则第三十一条、1990 年联营解答、已失效《合同法》或其解释、1997 年《合伙企业法》同条号时记为噪声，不得写入 `L#`。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、把公职禁止经营改成隐名可履行、把“只分红不亏损”写成可履行保底股东、把内部按份改成债权人不得追索、约定永远不得退伙且无结算、保证有效或必然不被追债。
- `字段停止`：损益比例、执行权限、对外署名、出资权属、退出结算未写清；公职身份未核验；关键出资金额缺失。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或文本已滑入合伙企业／股东协议／借贷／雇佣。

生存级个人财产可能被连带执行且用户拒绝升级：停止“可以签署”建议。
