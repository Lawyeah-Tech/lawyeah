# 审查方法（锁定 合伙合同相关 / 个人合伙合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型，禁止打开普通／有限合伙企业、股东协议、借款或劳务双文件“对照一下”。

本文件是**无法人资格、不领取合伙企业执照**的自然人共同事业签前判断节点，不是栏目说明书，也不是《合伙企业法》企业治理清单或借款审查清单。禁止把普通／有限合伙人分档、合伙企业除名三十日起诉、股东优先购买、董事会改组、借款利率上限写入本类型默认结论。

每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、必然赢利、债权人必然不追个人、对方必然接受或唯一必得金额。

`search_law` 返回已失效《合同法》及其解释、民法通则第三十一条／第三十二条／第三十四条、1990 年《关于审理联营合同纠纷案件若干问题的解答》、1997 年《合伙企业法》第二条／第三条、2005 年《公务员法》第四十四条职务晋升或第五十九条处分解除旧义时记为噪声，不得写入 `L#`。书面形式：民法典合伙合同章未强制书面；民法通则第三十一条已失效。书面仍是举证与履行最佳实践，不得写“无书面则合伙当然不成立”。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突。

示范文本只参考结构。市场监管或行业合伙示范文本不证明本约条款已被接受；符合格式条款定义的，仍按格式条款审查。

### 双文件使用（标题与文件名不完全对应时不拒跑）

同目录两份知识文件按标题语义使用，不回改正文，不因文件名拒跑：

- 含“首部 / 交易条款 / 配套 / 尾部 / 语言”的当框架级条款清单，供节点 8 出句；
- 宏观的类型切开、主体、出资财产、程序顺序、结构红旗由本方法节点承担。知识稿把“法律要求书面形式”写成成立要件的，**降级为证据最佳实践**。知识稿把合伙企业法入伙／除名程序、联营保底专条写成个人合伙默认路径的，**降级为红旗或噪声**：不得照抄为可履行结构。
- 文件不可用（空、代码块、与本类型明显无关）：记 `G#`，用本方法节点继续，不得改去加载企业或借款双文件，不得编造损益比例或通知期。

先于类型识别。命中任一项则本任务不填十节实体结论，只交付分流理由和最小交接。

| 已能支持的事实 | 走向 | 不得写成 |
| --- | --- | --- |
| 无可读正文和附件，或只有口头合作意向 | `个人合伙合同·起草` | 已经完成审查 |
| 未签，目标是评改已有个人合伙／合伙协议 | 进入节点 1 | 已签署或合伙已成立完毕 |

## 节点 1　类型识别与负触发

### 1.1 本类型正像

同时满足才继续：

- 两个以上合伙人（默认自然人、完全民事行为能力）为**共同事业目的**订立协议；
- 核心给付是共享利益、共担风险，而不是到期还本付息或只领固定报酬；
- **无法人资格**，文本不以领取普通／有限合伙企业营业执照、企业名称带“普通合伙／有限合伙”为主结构。

标题写成“合伙协议”“合作经营协议”“入伙协议”只是线索。名实不符按核心给付归类，标题冲突写入 `C#`。合同编通则解释第十五条：不拘泥名称，结合内容、背景、目的、结构、履行认定实际关系。

### 1.2 必须切开（禁止两套知识）

| 信号 | 归入 | 本技能动作 |
| --- | --- | --- |
| 已领或拟领普通合伙企业执照、名称含“普通合伙”、按《合伙企业法》设立 | 普通合伙企业合同 | **负触发** → `普通合伙企业合同·审查`。不得当个人合伙审，不得把企业除名／清算专条写成默认 |
| 有限合伙人、认缴为限、普通／有限分档 | 有限合伙企业合同 | **负触发** → `有限合伙企业合同·审查` |
| 主文是公司股权、否决权、随售／拖售、章程，合伙只是口语 | 股东协议 | **负触发** → `公司股东协议·审查` |
| 不参与经营、不承担亏损、到期收回固定本息或固定收益 | 民间／企业间借款 | **负触发** → `不参与经营不承担亏损到期固定本息→自然人之间借款` 或 `或企业间借款`。民间借贷规定只作切开，不在本任务做利率精算 |
| 只拿固定报酬、不分担亏损、听从安排提供劳务 | 个人劳务（雇佣） | **负触发** → `只拿固定报酬不分担亏损无合伙人决策权→个人劳务（雇佣）` |
| 人格从属、工资社保、规章制度 | 劳动合同 | **负触发** → `人格从属＋工资社保→劳动合同` |
| 名为合伙、实为让与担保或垫资抽回 | 不适用本类型 | 字段停止并转出，不按真实合伙写“已共担风险” |

合伙企业、股东协议、借贷、雇佣误入是硬闸：一旦核心给付滑入上述结构，立即停笔转出。不得删掉执照条款或保底本息后继续当个人合伙审。

### 1.3 加载协议

只打开本目录 `基本面.md` 与 `框架.md`。禁止读 `types/` 或其他场景原子目录。

### 1.4 违法或监管结构停笔（本类型，不是施工挂靠）

出现下列任一结构，只出告知，不改写成可履行文本：

- 公务员、参公或其他公职人员从事或参与营利性合伙，要求改成亲属代持、隐名合伙以规避公务员法第五十九条第十六项或政务处分法第三十六条；
- 出借个体工商户执照、只收管理费、无真实共同经营；
- 两套账或阴阳出资：对外一份、对内一份；
- 内部约定“债权人不得向某合伙人追索”；
- 倒签合同日期以改变退伙通知或债务归属时点。

用户坚持“改到能签／能规避公职限制／能让债权人追不到”：整体停止。合规改道（真实退出公职后再签、依法登记为企业、真实借款改走借款合同）只点名，不在本任务起草规避方案。

## 硬闸 A　个人合伙 ≠ 合伙企业 ≠ 借贷 ≠ 雇佣

本闸改变能否留在本任务。

1. **组织形态**  
   个人合伙无法人资格，不领取合伙企业执照，适用民法典第九百六十七条以下。文本出现“执行事务合伙人”“普通／有限合伙人”“合伙企业营业执照”：按节点 1.2 转 `普通合伙企业合同·审查` 或 `有限合伙企业合同·审查`。  
   **修改句**：`各方确认：本协议项下合伙为民法典规定的个人合伙，不设立合伙企业，不领取合伙企业营业执照，无法人资格。任何一方不得以本协议主张已设立普通合伙企业或有限合伙企业。如后续决定依法登记为合伙企业或公司，应另行签署相应协议并办理登记；本协议不构成该等设立文件。`

2. **与借贷切开**  
   一方不参与经营、不承担亏损，到期收回本金并收取固定收益：按借贷转出，不在本任务改利率。民间借贷规定仅作切开依据。  
   **修改句（仅在仍主张合伙、尚未转出时用于逼清定性）**：`删除“无论盈亏均于【待填】日前返还本金并按年【待填】% 支付收益”的约定。若甲方仍作为合伙人，应参与【经营决策／监督】并按本协议第【待填】条分担亏损；若甲方不参与经营且不承担亏损，各方应改签借款合同，本任务停止按合伙审查。`

3. **与雇佣切开**  
   只领固定报酬、不分担亏损、无合伙决策权：转 `只拿固定报酬不分担亏损无合伙人决策权→个人劳务（雇佣）`。第九百七十一条：合伙人不得因执行事务请求报酬，另有约定除外——执行津贴须与“只当员工”区分。  
   **修改句**：`丙方以劳务出资，折算合伙份额【待填】%，并按该份额分配利润、分担亏损。丙方对重大事项享有表决权。各方不得将丙方仅写作按月领取固定报酬、不承担亏损的雇员。如丙方实际只提供劳务、不担风险，应改签劳务或劳动合同，本协议对其合伙人身份的约定删除。`

4. **最强反方**  
   标题写“合伙”但履行是还本付息，相对方可主张借贷；未办执照不当然使共同经营关系不存在。签前按核心给付分流，不两套都审。

## 硬闸 B　共享利益共担风险

1. **法定特征**  
   第九百六十七条：共享利益、共担风险。第九百七十二条：利润分配和亏损分担有约定从约定；无约定或约定不明则协商；协商不成按实缴出资比例；无法确定出资比例则平均。  
   **修改句**：`合伙利润分配与亏损分担比例如下：甲方【待填】%、乙方【待填】%、丙方【待填】%。未约定或约定不明的，由合伙人协商；协商不成的，按实缴出资比例；无法确定出资比例的，平均分配、分担。任何一方不得只参与利润分配而免除亏损分担。`

2. **保底条款**  
   “只分红不亏损”“保本保收益”“亏损由其他合伙人全包”：可能导致合伙定性被否定（结合通则解释第十五条看实际关系）。**不得**改写成可履行的保底股东或“保底条款有效、对方必须兑付”。1990 年联营解答已失效，不得引用为现行无效专条。  
   修改路径只有两条：删除保底，或改为真实亏损分担，另就超额贡献约定**可谈判的补偿**（补偿不得写成无论盈亏的固定本息）。  
   **修改句**：`删除甲方“只分红不承担亏损、三年后无论盈亏退还本金并支付固定收益”的条款。甲方按【待填】% 分配利润并按同一比例分担亏损。若各方认可甲方额外投入或执行贡献，可在年度结算后另行书面协商一次性补偿，补偿金额以当年可分配利润为限，不得约定无论盈亏的固定本息。用户要求保留可履行保底的，该字段停止；坚持写成“保底股东”的，整体停止。`

3. **全部利润归一方或全部亏损归一方**  
   与共担风险冲突。修改句拉回对称或明示差额对应的劳务／执行作价，且亏损仍须分担。  
   **修改句**：`删除“全部利润归甲方、全部亏损由乙方承担”。利润与亏损均按甲方【待填】%、乙方【待填】% 分配、分担。`

4. **最强反方**  
   损益比例可以与出资比例不一致（972 允许约定）；执行报酬可另约（971）。不等于可以取消亏损分担。签前不得以“意思自治所以保底有效”放行。

## 硬闸 C　对外责任

1. **对外连带**  
   第九百七十三条：合伙人对合伙债务承担连带责任。清偿超过自己应当承担份额的，有权向其他合伙人追偿。个人合伙无法人资格，责任不以出资额为限。条文用语是“连带责任”，不要把《合伙企业法》“无限连带责任”原文硬套进本类型修改句，但必须向当事人说明：债权人可向任一合伙人主张全部合伙债务，个人其他财产可能被执行。  
   **修改句**：`各方知悉并确认：合伙人对合伙债务承担连带责任。任一合伙人对外清偿超过其按照本协议应当承担份额的，有权向其他合伙人追偿。本协议关于内部分担比例的约定仅约束合伙人之间的追偿，不得对抗合伙债权人。任何一方不得向相对方或第三人陈述“未签字／未出资／只分红的合伙人不对外负责”。`

2. **内部按份不得对抗债权人**  
   文本写“债权人不得向丙追索”“丙只以出资为限”：红线。有限责任以认缴为限是有限合伙企业路径，本类型没有。  
   **修改句**：`删除“债权人不得向丙方追索”及“丙方只以其出资额为限承担责任”。丙方作为合伙人，对合伙债务与其他合伙人承担连带责任；丙方对外清偿后，可按本协议第【待填】条向其他合伙人追偿。如丙方要求责任以出资为限，应依法设立有限合伙企业并改签相应协议，本任务不提供该规避结构。`

3. **入伙前债务与退伙后债务**  
   新加入的合伙人通过一致同意受让份额或加入合同的，修改句须提示：对加入前已发生、仍属合伙债务的部分，对外仍可能被债权人一并主张，内部再追偿。退伙结算完毕不当然切断退伙前债务的对外责任。材料未写：必须改，用 `【待填】` 补内部追偿时点，不编造“退伙即免责”。  
   **修改句**：`新合伙人自加入之日起对加入后发生的合伙债务承担连带责任；对加入前已发生的合伙债务，对外不因内部约定而当然免责，内部由原合伙人按加入前份额向其补偿。合伙人退伙的，退伙前发生的合伙债务仍应按连带规则对外负责，退伙结算不得约定“债权人不得再向退伙人主张”。`

4. **最强反方**  
   内部追偿约定有效约束签署方；未参与某笔越权债务的合伙人可能对内主张该笔不应由其分担。签前仍须把对外连带作成必须告知，不得写成“写了按份对外就按份”。

核验失败：对外连带的法律结论字段停止；“不得写债权人不得追索”的修改句草稿继续。

## 硬闸 D　事务执行与代表

1. **默认与委托**  
   第九百七十条：除合同另有约定外，合伙事务决定应当经全体合伙人一致同意；事务由全体合伙人共同执行；可委托一个或数个合伙人执行，其他合伙人不再执行但有权监督；分别执行的，执行人可提出异议，提出后应当暂停该项事务。  
   **修改句**：`除本协议另有约定外，合伙事务决定应当经全体合伙人一致同意。日常经营（单笔不超过人民币【待填】元的采购、用工和收款）委托【乙方】执行；改变事业目的、处分合伙不动产或其他主要财产、以全体合伙人名义为他人提供担保、对外借款、吸收新合伙人、超过上述限额的支出，须全体合伙人一致同意。非执行合伙人有权查阅账目并监督执行情况。合伙人分别执行的，其他执行人对该项事务提出书面异议后，应当暂停执行直至按本条表决。`

2. **一致决与多数决**  
   970 允许“合同另有约定”。多数决必须写清计票基数（人数或份额）和事项清单。不得只写“必要时协商”。  
   **修改句**：`下列事项须全体一致同意：【改变事业目的／处分主要财产／对外担保／吸收或除名合伙人／解散】。其余事项按实缴出资比例【或：一人一票】过半数通过。未达约定比例的，不得对外实施。`

3. **表见合伙**  
   未签署本协议但长期以合伙人名义经营、其他合伙人未异议的，第三人可能依据表见代理（第一百七十二条方向）向其或向全体主张。不得虚构“表见合伙”专条号。  
   **修改句**：`未在本协议签字的任何人不得以合伙人名义对外经营、收款或举债。任何一方发现上述情形，应在【待填】日内书面制止并通知其他合伙人。其他合伙人知道或应当知道而未异议的，不得仅以“其未签字”对抗善意相对人；内部责任按本协议追偿条款处理。本条不认定某第三人已经构成合伙人。`

4. **执行报酬**  
   971：不得因执行事务请求报酬，另有约定除外。执行津贴须定额或与考核挂钩，并与劳务出资、雇佣切开。  
   **修改句**：`受委托执行合伙事务的合伙人可按月领取执行津贴人民币【待填】元，列入合伙费用，不替代其亏损分担义务，也不构成劳动关系。`

5. **最强反方**  
   执行人越权，善意相对人仍可能主张对全体发生效力。签前必须把权限和异议暂停写成必须改，不得写成“未授权则对外当然无效”。

---

## 硬闸 E　出资与财产

1. **出资写清**  
   第九百六十八条：按照约定的出资方式、数额和缴付期限履行。个人合伙可以用货币、实物、知识产权、使用权或**劳务**出资——这与公司不得以劳务出资不同，禁止照搬市场主体登记管理条例第十三条。劳务必须作价或折算份额，并与固定工资切开。  
   **修改句**：`各合伙人出资如下：甲方以货币人民币【待填】元，于【待填】日前缴入本协议第【待填】条约定的合伙财产账户；乙方以【门面使用权／设备，特定化描述】作价人民币【待填】元，于【待填】日前交付并列入附件清单；丙方以【厨师／运营】劳务出资，折算份额【待填】%。逾期未缴付的，每逾期一日按应缴金额的【待填】向其他合伙人支付违约金；逾期超过【待填】日，其他合伙人可一致同意其退出并结算。`

2. **合伙财产与个人财产分离**  
   第九百六十九条：出资、因合伙事务取得的收益和其他财产属于合伙财产；终止前不得请求分割。修改句要求专用账户或共管、独立记账。材料未提及账户不得写成“财产已经独立”。  
   **修改句**：`合伙财产（含出资、经营收益和其他以合伙名义取得的财产）与各合伙人个人财产分开记账。货币收支使用账户名【待填】、账号【待填】的合伙专用／共管账户，预留印鉴为【待填】。合伙合同终止前，任何一方不得请求分割合伙财产，不得将合伙账户资金转入个人账户用于与合伙无关的开支。`

3. **配偶同意（可优化）**  
   出资可能来自夫妻共同财产，合伙债务可能被主张为夫妻共同债务。配偶知情或同意作成可优化，**不得**写成“无配偶签字则合伙合同无效”。  
   **修改句**：`建议各合伙人在签署前向其配偶告知本协议项下出资来源及对外连带风险，并可将配偶签署的《知情确认》作为附件。未取得配偶确认的，不影响本协议在签署合伙人之间成立，但该出资来源与夫妻债务风险标为缺口，不因此认定合同无效。`

4. **权属**  
   实物、使用权须可交付且权属无争议。已抵押、查封的财产：该出资字段停止，不写“视为已出资”。共有财产未取得其他共有人同意：字段停止。  
   **修改句**：`乙方保证对用于出资的【财产】享有合法处分权；如为共有或已设定抵押、查封，应在【待填】日前解除负担或取得书面同意并作为附件，否则改以货币人民币【待填】元替换，不得记载为已出资。`

5. **最强反方**  
   未设独立账户不当然否定合伙关系；账目不清会导致盈余无法证明。签前仍须把分账作成必须改。无书面合同但已实际出资并执行事务的，法院仍可能认定合伙关系——这是证据问题，不能倒过来放行无账。

## 硬闸 F　退出与解散

1. **期限与通知**  
   第九百七十六条：期限没有约定或约定不明，依第五百一十条仍不能确定的，视为不定期合伙；期限届满继续执行且其他合伙人未异议的，转为不定期；不定期合伙人可以随时解除，但应当在合理期限之前通知其他合伙人。  
   **修改句**：`本合伙期限为【待填】年，自【待填】日起算。期限没有约定或约定不明且无法确定的，视为不定期合伙。不定期合伙的任何一方解除的，应当至少提前【待填】日书面通知其他合伙人。期限届满后各方继续执行合伙事务且无人提出书面异议的，原合同继续有效，期限转为不定期。`

2. **禁止“永远不得退伙且无结算”**  
   该约定压缩法定解除并剥夺清算，红线。定期合伙可约定擅自退出的违约责任，但必须保留结算。  
   **修改句**：`删除“任何一方永远不得退伙，退伙不结算”。定期合伙期限内无约定或法定事由擅自退出的，退出方应赔偿因此造成的直接损失，但仍须按本协议第【待填】条进行退伙结算。不定期合伙按前条通知解除后，应在通知期满后【待填】日内完成结算。`

3. **结算与竞业**  
   退伙结算：财产退还办法（货币或实物）、未了结事务、退伙前债务的内部追偿、客户与资料交还。竞业可约定期限和范围，不得无限期、全国全行业。  
   **修改句**：`合伙人退出时，应当：〔1〕在【待填】日内交还合伙资料、印章和客户名单；〔2〕按退出日的账面净资产及未了结债权债务结算，退还方式为货币，另有书面约定的除外；〔3〕对退出前发生的合伙债务仍对外承担连带责任，内部按退出前份额追偿。退出方在退出后【待填】个月内，不得在【待填】区域内从事与本合伙相同的【待填】业务；该限制以保护商业秘密和客户为限。`

4. **解散与清算**  
   第九百七十七条：合伙人死亡、丧失民事行为能力或终止的，合同终止；另有约定或事务性质不宜终止的除外。第九百七十八条：终止后先支付因终止产生的费用并清偿合伙债务，剩余按第九百七十二条分配。禁止未清算直接返还出资。不要把《合伙企业法》第八十五条企业解散清单整段抄进本类型。  
   **修改句**：`出现下列情形之一，本协议终止：〔1〕期限届满且各方决定不再继续；〔2〕全体合伙人书面同意解散；〔3〕共同事业目的已经实现或确定无法实现；〔4〕合伙人只剩一人；〔5〕合伙人死亡、丧失民事行为能力或终止，且本协议未约定由其余合伙人继续。终止后，执行人应在【待填】日内编制财产清单，先支付终止费用并清偿合伙债务，剩余财产按本协议损益比例分配。未完成清算前，任何一方不得请求返还出资或分配利润。`

5. **份额对外转让**  
   第九百七十四条：除另有约定外，向合伙人以外的人转让全部或部分财产份额须其他合伙人一致同意。  
   **修改句**：`除本协议另有约定外，合伙人向合伙人以外的人转让其财产份额的，须经其他合伙人一致同意并书面修改本协议。未经一致同意的转让，不得对抗其他合伙人。`

6. **最强反方**  
   未通知即退出可能构成违约，但不当然使合伙财产归剩余方无偿取得。签前不得放行无结算退出，也不得宣告某人已经合法退伙。

## 节点 2　主体、授权、公职

1. 建主体表：各合伙人签约名、证件号、住所、是否公职、执行人、未签字但对外经营的人、配偶（如已提及）。名称不一致不自动合并。遗漏任一拟合伙人：协议对其不当然约束，标必须改。
2. 合伙人须具备完全民事行为能力。限制或无民事行为能力人：该主体字段停止，不得写成监护人代签即可成为合伙人。
3. 公职人员：2018 年公务员法第五十九条第十六项、政务处分法第三十六条。只告知监管风险（处分、没收违法所得），**不**改成亲属代持。用户坚持规避：整体停止。
4. 口头“我们老板同意了”不得写成已授权。

不足：字段停止，列出待补材料，不补主体。

---

## 节点 3　对价、账户、竞业

1. 出资、作价、执行津贴、利润分配分列。禁止编造数字。
2. 定金：必须使用“定金”二字才讨论罚则；超过主合同标的额百分之二十的部分不产生定金效力。无核验引文不得把 20% 写成已核验结论。个人合伙通常无定金；出现则按该口径处理。
3. 合伙财产账户见硬闸 E。禁止“盈利用个人微信收取、亏损用合伙账”。
4. 竞业与保密见硬闸 F。禁止无限期、无地域的竞业。

---

## 节点 4　程序与生效

把出资缴付、财产交付、账户开立、个体户登记（如有）写成**义务和期限**，不写成已经完成。

| 文本写法 | 本任务动作 |
| --- | --- |
| “本合同签字即视为各方已出资完毕／已共担风险” | 拆成合同生效 vs 货币入账／实物交付／劳务开始；删除“视为已出资” |
| “以个体户名义经营即成立合伙企业” | 纠正：个体户挂名不是合伙企业；挂靠只告知 |
| 把未清算写成可以起诉返还出资 | 纠正：先清算；已成争则转出 |
| 用户要求倒签或补假账、假出资 | 整体停止 |

民法典未强制书面。已有书面文本的本任务，仍应要求签字页、附件清单完整，作为证据而不是成立要件。

## 节点 5　格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 5.1 格式条款

中介、园区或网上下载的重复使用合伙模板，仍可能构成格式条款。审查单方全责、永远不得退伙、内部免责对抗债权人、管辖、最终解释权是否有显著提示。

### 5.2 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的是否导致民事行为无效、是否只规制履行或行政管理。禁止用已失效“效力性／管理性”口诀。公职营利禁止：行政管理与政务处分为主，不轻易写“公务员签字则合伙合同当然无效”，同时不得输出规避结构。保底：用 967 与名实认定，不用失效联营解答。

---

## 节点 6　违约、解除、争议解决

1. 逾期出资、越权对外签约、擅自分割合伙财产、违反竞业必须分别有可执行后果。只有“依法承担违约责任”视为必须改。
2. 构成违约不等于当然解除或当然除名。本类型不套用《合伙企业法》除名三十日起诉。修改句写约定退出条件、通知和结算，不在本任务宣告某人已经除名。
3. 违约金避免“不得调整”或“按合伙财产百分之三十必得”。
4. 争议解决：  
   - 已有仲裁条款，不得改成“应向某法院起诉”并假装已选定诉讼；  
   - 或裁或诉、机构不明：改成单一仲裁机构或单一法院连结点；  
   - 合伙主要经营地可作为约定连结点，须写成约定。
5. 微信已读不写成已经送达，除非合同把该渠道定为送达。

---

## 节点 7　跨境、夫妻财产与其他结构

1. 涉外主体或境外付款：准据法不明则停止外国法结论。本类型只审中国大陆个人合伙和人民币结算安排。
2. 夫妻财产见硬闸 E.3。配偶明确反对且出资来自共同财产：该出资字段停止，不写已经缴清。
3. 未成年人：不得成为本类型合伙人。

---

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

对照已加载框架级文件和本方法硬闸，按六步逐段出句。

| 步 | 本类型必须盯的点 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题名实（个人合伙，避免写成合伙企业或股东协议）；全体合伙人均签署；鉴于只描述共同事业，不把赢利或已出资写成已完成 | 主体与鉴于修改句 |
| 交易条款 | 出资方式／数额／期限／份额；劳务作价；损益对称；禁止保底；合伙财产账户；执行权限与重大事项表决 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 对外连带告知；内部追偿不得对抗债权人；表见合伙制止；退出通知与结算；解散清算顺序；违约与竞业 | 可执行后果句 |
| 尾部 | 授权签字；附件：出资清单、账户信息、配偶知情（可优化）；生效与终止清算 | 生效与附件修改句 |
| 语言 | 正说加反说；合伙 ≠ 合伙企业 ≠ 借贷 ≠ 雇佣；连带 ≠ 内部按份对外；不得写“视为已出资”“永远不得退伙” | 替换空词的句子 |
| 常见问题 | 保底、内部免责对抗债权人、无结算退出、公职隐名、执照条款误入、账目混同 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（保底可履行、对抗债权人、永远不得退伙无结算、公职规避、已办企业执照仍当个人合伙）；
- `必须改`：可谈但签署前要落句（损益比例、对外连带告知、执行权限、出资作价与账户、退出通知与清算）；
- `可接受可优化`：仍要给句子，不得只标绿（配偶知情、竞业细化、共管印鉴）。

用户不可接受事项优先写成红线。生存级个人财产可能被连带执行且用户拒绝升级：停止“可以签署”建议。
