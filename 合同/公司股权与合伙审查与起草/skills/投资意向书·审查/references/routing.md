# 边界与路由

本技能只审查 **股权投资相关合同 / 投资意向书（条款清单_TermSheet）** 的待签、股权融资初步合意／谈判提纲文本。中文展示名是「审查投资意向书（条款清单_TermSheet）（股权投资相关合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或复制 `出资合同·审查`、`房地产项目股权取得类合同·审查`、`PE股权转让·审查`、`股权代持合同·审查`、`PE股东协议·审查`、`增资协议·审查` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 设立出资、缴付注册资本为主给付，公司尚未成立 | `出资合同·审查` |
| 房地产项目公司股权取得、土储或开发资质捆绑 | `房地产项目股权取得类合同·审查` |
| 老股价款、过户、优先购买放弃为可立即履行的转让 | `PE股权转让·审查` |
| 名义股东与隐名股东、代持安排 | `股权代持合同·审查` |
| 股东权利、董事会、保护性否决、随售／拖售自本文件生效；长式股东协议正文 | `PE股东协议·审查` |
| 已写认缴出资、付款账户、验资、章程修正案、交割先决条件为可履行义务；无“将来另行签署增资协议” | `增资协议·审查` |
| 对赌补偿、业绩承诺或回购是主给付 | `对赌协议（盈利预测补偿协议）·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式（出稿后自审） |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `已出现催告解除函索赔立案开庭仲裁` 或对应专项领域 |
| 排他违约、投资款返还、对赌回购已立案 | 投资并购或争议专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

条款清单正文里夹带一小段增资交割或股东权利专章：专章交接对应原子或改为“以正式协议为准”；提纲部分可继续审。用户坚持本技能把增资、股东协议或转股本约整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
