# 边界与路由

本技能只审查 **公司相关合同 / 上市公司股票大宗交易协议** 的待签、已存在流通股经证券交易所大宗交易系统申报成交文本。中文展示名是「审查上市公司股票大宗交易协议（公司相关合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 认购上市公司非公开发行新增股份；附董事会／股东会／交易所审核／证监会注册或核准生效；对价称认购款 | `附条件生效股份认购协议·审查` |
| 上市公司向激励对象授予限制性股票；解锁、归属、考核、公司回购；对价绑在职身份 | `上市公司限制性股票激励协议·审查` |
| 不经大宗系统的国有股权协议转让；单笔受让通常不低于 5% 或控制权转移；产交所挂牌 | `国有股权转让合同（协议转让）·审查` |
| 国有资产（非上市公司股权）协议转让 | `国有资产转让合同（协议转让）·审查` |
| 只委托券商集中竞价减持，无对手方大宗协议 | 转引擎重新定性，不启动本任务 |
| 询价转让、配售减持首发前股份 | 减持办法第十九条；不按本类型大宗路径改完 |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式（出稿后自审） |
| 已签未争、只问 T 日申报、保证金释放或过户节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `已出现催告解除函索赔立案开庭仲裁` 或对应专项领域 |
| 证监会调查、交易所纪律处分、内幕交易或操纵已立案 | 证券监管或争议专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

大宗交易正文里夹带一小段认购生效条件或激励解锁：专章交接对应原子或分条改写；大宗申报条款可继续审。用户坚持本技能把认购、激励或国有股权协议转让整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
