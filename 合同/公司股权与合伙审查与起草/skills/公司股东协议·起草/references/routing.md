# 边界与路由

本技能只起草 **公司股东协议**，出稿后用本类型硬闸自审。主线是有限责任公司股东之间的治理契约，仅约束签署方。不是组织文件，不是缴资本约或存量买卖本约，也不是 PE 投资人保护清单。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 用户要整份代审章程或章程修正案 | `公司章程_章程修正案·审查` |
| 价款／财产进公司、新设认缴本约 | `出资合同（有限责任公司）·审查` |
| 已设立公司新增资本、增资协议／新股认购为主文件 | `增资合同·审查` |
| 存量股权让与、价款进原股东、交割／名册／登记为主给付 | `公司股权转让·审查` |
| 业绩对赌、估值调整作为主文件 | `对赌协议（盈利预测补偿协议）·审查` |
| 投资人保护清单：估值调整、优先清算、反稀释一揽子，或股权投资相关合同项下同名股东协议 | `PE股东协议·审查` 或投资并购侧 |
| 已有可读待签文本要评改 | `公司股东协议·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、问履约节点／配合入章进度 | 本套导航的履约步骤 |
| 决议效力／撤销／不成立之诉，或解散之诉已立案仲裁 | 公司争议领域；不填签前十节 |
| 股东协议含公司回购条款，但仍是治理契约而非对赌主文件 | 留本任务，走硬闸 D；禁止改成无需减资的可履行结构 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

专业版未收录的投资侧 P1 场景不会作为本原子的实体审查对象。若用户拿这些文本来找本技能：输出 `unavailable` 或负触发路由，不得用本类型硬套。

本技能不得转去加载章程、出资、转让或投资侧双文件完成本类型审查，也不得把记载清单、五年认缴或优先购买交割写成股东协议默认主路径。
