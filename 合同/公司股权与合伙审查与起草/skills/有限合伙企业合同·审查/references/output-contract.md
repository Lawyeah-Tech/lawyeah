# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、必然节税、普通合伙人必然不被追个人、有限合伙人越位也必然不被穿透、对方必然接受；编造未给出的认缴额、管理费、收益率；把已失效《合同法》、1997 年《合伙企业法》同条号、失效登记办法写入结论；把个人合伙或普通合伙治理硬套本类型；输出可履行隐名 GP、影子执行或保本回购结构。

## 1. 触发、单方立场与成果状态

立场（普通合伙人或有限合伙人）、授权、签署状态、主要目标。普通合伙企业、个人合伙、股东协议、固定本息／无条件回购借贷、已成争或其他负触发写路由，不启动实体审查。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》、1997 年《合伙企业法》同条号、失效登记办法或民法通则时记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `合伙合同相关`，子级 `有限合伙企业合同`。写定性理由和与普通合伙企业、个人合伙、股东协议、借贷的切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识稿中的“以出资额为限”写降级说明：以认缴出资额为限。“先分后税”不得写成已核验节税。第三条主体禁入、公开募集写停笔告知，不填可履行规避结构。

## 4. 主体、授权与文本版本

主体表：各合伙人、GP／LP 档、是否第三条禁入主体、执行事务合伙人及委派代表、管理人、授权签字人。版本表：正文、附件、出资确认书、委派书、侧函、聊天确认；冲突并列，不选对用户有利的一版。

## 5. 给付闭环（本类型必填）

固定检查并回链文本：

- 企业名称是否标明“（有限合伙）”，设立目的不得写成已完成赢利或已领执照；
- 合伙人表：GP／LP 分档、人数 2–50、至少一名普通合伙人；
- 认缴额、实缴额、缴付期限；有限合伙人不得劳务出资；
- 普通合伙人无限连带、有限合伙人以认缴为限；禁止对调责任档；
- 执行事务合伙人、LP 不执行、安全港八项、禁止共管公章；
- 利润分配（可约定全部利润归部分合伙人）与亏损分担（不得全部归部分合伙人）；有无固定收益＋无条件回购；
- 身份转换、仅剩一类合伙人后果、入伙告知与退伙结算；
- 设立登记义务；募集目的下的备案红旗（不整审基金合规）。

缺口标 `G#`，不补商业数字。批准、登记、备案写成义务或告知，不写成已经完成或可履行规避。

## 6. 格式条款与强制规范

是否构成格式条款（含示范文本或管理人标准 LPA）；提示说明痕迹。强制规范只区分是否导致民事行为无效与是否仅造成登记障碍或行政管理（第三条主体、未标明组织形式、未备案）。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。保本回购、LP 越位：用第二条／第六十八条／第七十六条与名实认定处理，不引用失效联营解答。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。硬闸三项及配套闸若文本或事实触及或沉默，必须各有至少一行，不得用色块代替。

## 8. 修改句

按框架六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点、不接受时的红线。未给出的商业数字用 `【待填】`。禁止只给原则、不给句子。禁止输出“普通合伙人仅以出资为限”“有限合伙人与普通合伙人共同管理且仍享有限责任”“有限合伙人以劳务折资”“无论盈亏无条件回购并支付固定收益”“国有企业隐名担任普通合伙人”充当可放行修改句。

## 9. 谈判与签署提醒

谈判顺序：先红线（GP 改有限责任、LP 越位可履行、LP 劳务、保本回购、第三条主体任 GP），再必须改（认缴表、安全港、责任分档告知、转换与仅剩一类、登记义务），最后可优化（管理费、侧函、咨询委员会）。签署提醒：身份档与登记一致、出资确认书、委派书、日期不得倒签。不指导倒签或补假缴资。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书、代办设立登记或基金备案、效力或节税保证。
