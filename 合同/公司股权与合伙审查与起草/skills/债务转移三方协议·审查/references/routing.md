# 边界与路由

本技能只审查 **公司相关合同 / 债务转移三方协议**。主线是债务人将已特定债务转移给第三人，须经债权人同意。不是第三人代为付款，不是债权人出售债权，也不是只通知债务人的债权让与。

本原子为 **P1**，仅安装。专业版未收录本场景；若专业版环境误载本 ID，输出 `unavailable` 并提示，不得用债权转让或代付款硬套。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 第三人只付款，原债务人不退出，第三人不履行则原债务人仍向债权人担责 | `代付款三方协议·审查` |
| 债权人把对债务人的债权卖给收购方，债务人主体不变 | `债权收购合同·审查` |
| 不改变债之内容的债权让与，通知债务人对债务人生效 | `主给付是债权让与通知债务人为轴→` |
| 主文件是保证、抵押或质押，转移只是背景一句 | `主文件是保证或抵押借款→`／`或`／`主文件是抵押借款` |
| 主文件是股权转让或资产转让，用户只要审主文件 | `公司股权转让·审查` 或 `非核心资产转让·审查`；债务转移专章可单独评改时留本任务只审专章 |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、问付款日／交接日／通知留痕 | 本套导航的履约步骤 |
| 追索、确认转移无效、保证责任或逃债已催告、立案、开庭或仲裁 | 合同争议领域；不填签前十节 |
| 只有双方（原债务人与新债务人）约定转移、债权人未作为一方 | 留本任务只出红线：对债权人不发生效力；用户坚持写成已转移则整体停止 |
| 约定不明，看不出免责还是并存 | 留本任务；不得写成已经免责；修改句逼出正说反说 |
| 通谋逃债、虚构债务、倒签同意日 | 留本任务只出告知；用户坚持改成可履行则整体停止 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

本技能不得转去加载代付款、债权收购或债权转让双文件完成本类型审查，也不得把“通知债务人即可”“从权利随同转让”“禁止转让特约对抗”写成债务转移默认主路径。
