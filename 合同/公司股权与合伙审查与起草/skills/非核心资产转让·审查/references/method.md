# 审查方法（锁定 公司相关合同 / 资产转让合同（单项_非核心资产））

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制股权转让优先购买/股东名册/工商变更主路径，禁止复制资产收购员工安置/假定债务清单/反垄断/过渡期服务主路径，禁止复制二手房户口/网签过户主路径。

定性校验：标题、核心给付与本类型一致才继续；股权、控制权、营业收购、国资进场、债权包或专项知产本约明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、买方必然隔离一切历史责任、对方必然接受或唯一必得金额。

`search_law` 返回已失效《合同法》《物权法》《担保法》及其解释、1984 年《专利法》、1982 年《商标法》、2003 年《企业国有产权转让管理暂行办法》、2018 年《公司法》已被修改文本时记为噪声，不得写入 `L#`。

示范文本只参考结构。资产清单范本只借栏目。股权转让或小型资产收购（营业）范本只证明是另一类型，不得当作本类型范本。

知识库纠正（不回写双文件）：

- `基本面.md` 把股权转让写成资产转让子类：子公司股权或股东资格变动 → 负触发 `公司股权转让·审查`，本任务不审名册和工商股东变更。
- `基本面.md` 写专利权、商标权登记“具有对抗第三人的效力”：专利法（2020 修正）第 10 条为转让自登记之日起生效；商标法（2019 修正）第 42 条为核准公告之日起受让人享有专用权。不得写成“合同一签权利已转移，登记可有可无”。
- `框架.md` 引《物权法》精神或已失效《合同法》第 61 条：改走民法典第 406、510、511 条。
- `框架.md` 商品房“不超过已付购房款一倍”惩罚：本类型不是商品房预售，不得当默认救济。
- `框架.md` 开发区管委会出让合同：那是土地使用权出让，不是公司处置单项非核心资产。
- 企业改制司法解释“出售企业”后买受人在公告期内申报债权范围内的责任：不得套到单台设备或单项专利。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 公司处置单台设备、单辆机动车、单项专利或商标、单套不构成独立业务的房屋，换价款 | 本类型 | 正触发 |

| 存量房买卖本约，户口/网签过户为主轴 | 二手房本约 | 负触发 `主文件是存量房买卖本约（户口网签过户主路径）→` |
| 整份只是专利权或商标权转让本约 | 知产专项 | 负触发 `整份文本只是专利权转让本约→` 或 `整份文本只是注册商标转让本约→` |
| 过户+回购担保借款 | 让与担保型借款 | 负触发 `过户+回购担保借款→` |

支持切开的规范（法律结论须运行时复核）：

- 第 595 条：买卖是转移标的物所有权换价款，不是概括承受卖方主体。
- 第 551 条：债务转移须经债权人同意；未同意不得写成买方已承受卖方债务。
- 第 545、546 条：债权让与以通知债务人为轴 → 走 `主给付是债权让与通知债务人为轴→`。
- 外国投资者并购境内企业规定第 13 条（资产并购语境）：出售资产的境内企业承担其原有债权债务。不得把该条写成境内普通买卖的唯一法源，只作“资产买卖原则上债务留在卖方”的对照。

### 1.4 让与担保 / 逃废债 / 阴阳 / 限购停笔（硬闸）

加载后或定性中出现：过户后卖方按本金加溢价回购、流押“到期不还财产归买方”；明显不合理低价把主要财产转给关联方且隐瞒债权人；网签价与真实价款两套文本；借名或规避限购。

动作：

1. 交付告知：担保制度解释第 68 条不支持“财产直接归债权人所有”；第 538、539 条及合同编通则解释第 43 条下，明显不合理低价且相对人知道的，债权人可请求撤销。第 153、154 条下，违法或通谋虚假可能无效。不得改写成可履行逃债或套贷结构。
2. 不写可履行的阴阳价差、假回购路径或体外循环。
3. 风险表只保留识别依据和删除/转出口径。

## 节点 2　主体、决议与资质

### 2.1 主体表

建表：签约名、履行名、付款名、发票名、授权签字人。名称不一致不自动合并。共有、配偶、抵押权人未闭合：该签署能力字段停止，不写成“可以盖章”。

口头“我们老板同意了”不得写成已授权。卖方被吊销、注销或进入破产：字段停止，不编造管理人权限。

### 2.2 内部决议

转让方/受让方为公司：按章程核对股东会或董事会。上市公司一年内出售重大资产金额超过资产总额百分之三十：公司法（2023 修订）第 135 条要求股东会并经出席股东表决权三分之二以上通过。非上市公司无章程依据时，不得写成“依法必须开股东会”；未见决议则字段停止。

修改句：

「甲方应于签署前向乙方交付加盖公章的内部决策文件（按甲方章程为股东会或董事会决议），确认本项资产转让已获授权。决议未作为附件或授权范围与清单不一致的，乙方有权中止付款，且本合同不视为甲方已具备处分授权。」

2018 年公司法股东大会条已修改，不得写入 `L#`。

### 2.3 国资、划拨、特许

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 转让方为国有或国有控股，文本无评估/进场痕迹 | 字段停止；达到办法第 48 条情形可能须进场。主轴已是国资协议转让 → `国有资产转让合同（协议转让）·审查` | 可以场外直接过户 |
| 划拨土地使用权 | 字段停止；修改句要求批准和出让手续作为生效或交割条件 | 签字即可过户 |

部门规章进场义务不当然导致民事合同无效（解释第 16 条）。本任务只停止“可以场外交割”，不宣告当然无效。

## 节点 3　标的、负担与交割清单（硬闸）

### 3.1 交割清单必须可核验

审查清单，缺一项则该字段不得写成已闭环：

1. 资产名称、规格型号或权利证号（不动产单元号、专利号、商标注册号、车架号）。
2. 数量、存放或登记地点、现状（闲置/在用/已出租）。
3. 权属证明名称及编号；共有份额。
4. 交付方式：实物交付、权利凭证、电子资料、登记申请材料。
5. 风险转移时点：与第 604 条对齐，默认交付时转移，另有约定须写清。
6. 明确排除项：现金、应收账款、合同权益、员工、资质、未列备件。

禁止只写“甲方名下与该业务有关的全部资产”。禁止“以现场清点为准，清单仅供参考”。

修改句：

「标的资产以附件一《标的资产清单》为准，逐项列明名称、规格或权利证号、数量、存放/登记地、权属证明及现状。未列入清单的资产、合同权益、员工、资质、许可和债权债务均不在本次转让范围。双方应于【待填】年【待填】月【待填】日在【待填】地点办理交割，共同签署附件二《交割确认单》；确认单应记载实交数量、外观或运行状态、移交的证书/钥匙/密码/技术资料页数，并由双方授权代表签字。签收单据不等于验收合格，隐蔽瑕疵仍按本合同质量条款处理。未签署交割确认单的，不得视为交付完成，标的物毁损灭失风险不转移。」

最强反方：卖方主张“现场看过就是清单”。现有依据不支持把口头指认单独写成标的已确定（第 596 条要求名称、数量等条款）。

### 3.2 权属与权利负担（硬闸）

支持依据：第 612、613、597 条；第 406 条；第 725、728 条；合同编通则解释第 19 条。

| 文本写法 | 动作 |
| --- | --- |
| “甲方保证无任何权利负担，乙方不得再查”且无查询件 | 必须改。材料未提及不得写成无负担 |
| 已知抵押仍写买方取得无负担所有权，且无涤除安排 | 必须改：通知抵押权人、价款优先清偿或提存，或抵押权人书面同意 |
| 已出租仍写可空房交付 | 必须改：买卖不破租赁；房屋承租人优先购买未处理则补通知与放弃声明 |
| 查封、违建、小产权、禁止流通物仍要过户 | 红线；不改成可履行过户 |
| 无权处分导致不能转移 | 现有依据支持买受人解除并请求违约责任；合同不因缔约时无权处分当然无效 |

修改句：

「甲方保证其为清单资产的合法权利人。签署前甲方应向乙方交付：权属证书复印件、不动产登记信息或动产融资统一登记查询结果、知识产权官方状态查询页（权利人、质押、许可、无效宣告、年费）。交割日前甲方应解除清单资产上的抵押、质押、查封，或取得权利人书面同意并作为附件。房屋或设备已出租的，适用买卖不破租赁；甲方应在签署前【待填】日书面通知房屋承租人，并交付放弃优先购买权的书面声明，否则乙方有权中止付款。查询日之后新发生的负担，甲方应在【待填】日内书面补充；故意隐瞒或提供虚假权属的，乙方可解除合同并要求赔偿已付款利息及直接损失。」

不得把“已看过设备”写成已完成权利瑕疵审查。第 613 条：买受人订立时知道或应当知道第三人权利的，出卖人可不承担第 612 条义务——相对方知道负担时，修改句改为价格扣减或涤除，而不是继续写“保证无负担”。

本节点不展开户口迁移、网签操作手册或员工三方协议。

## 节点 4　对价、定金与支付节点

1. 总价、分项价、币种、是否含税、发票种类分列。未给出的数字写 `【待填】`。
2. 支付与交割绑定：首付款 → 交割确认 → 登记申请或过户完成 → 尾款。禁止“全款先付、交割时间卖方另行通知”。
3. 定金必须使用“定金”二字才讨论罚则。约定或推算超过主合同标的额百分之二十：超过部分不产生定金效力（第 586 条）。无核验引文不得把 20% 写成现行法结论。订金、保证金无定金性质的，不得写成罚则。
4. 开具发票是从给付义务。买受人不得仅以未开发票拒绝支付已到期价款，除非另有可识别约定。
5. 动产可约定所有权保留（第 641 条）；未经登记不得对抗善意第三人。不得把所有权保留写到不动产上（买卖合同解释第 25 条）。买受人已付总价款百分之七十五以上的，现有依据不支持出卖人取回。
6. 禁止编造评估值或市场价。

修改句：

「转让价款人民币【待填】元（含税/不含税：【待填】）。乙方于本合同生效后【待填】日内支付【待填】%；甲方备齐交割资料并双方签署《交割确认单》后【待填】日内支付【待填】%；不动产过户登记完成 / 专利权变更登记完成 / 机动车登记完成后【待填】日内支付尾款【待填】%。任何一期付款前，若发现清单资产被查封或权属与附件不符，乙方有权中止该期付款直至障碍消除或双方书面变更清单。」

## 节点 5　合同生效与权利变动（硬闸）

| 文本写法 | 本任务动作 |
| --- | --- |
| “本合同签字盖章后立即生效，标的所有权同时转移” | 拆开：合同可成立生效（第 215 条）；不动产须登记才发生物权效力（第 209 条）；动产原则上交付时变动（第 224 条）；机动车未经登记不得对抗善意第三人（第 225 条）；专利权转让自登记之日起生效（专利法 2020 第 10 条）；商标专用权自核准公告之日起由受让人享有（商标法 2019 第 42 条） |
| “网签或登记后生效”但无谁负责、几日内、未完成的后果 | 补义务主体、期限、未完成时中止付款或解除 |
| 卖方继续占有设备（占有改定）未写明 | 必须写第 228 条约定，否则交付时点不清 |
| 用户要求倒签或补假登记 | 整体停止 |

修改句：

「本合同自双方法定代表人或授权代表签字并加盖公章之日起成立并生效，但标的资产的物权或知识产权变动按下列规则另计：（1）动产自交付并签署《交割确认单》时起转移；（2）不动产自记载于不动产登记簿时发生所有权转移，甲方应在收齐约定价款后【待填】日内配合提交过户申请；（3）专利权自国务院专利行政部门登记之日起转移，双方应在交割后【待填】日内提交登记申请；（4）注册商标自商标局核准公告之日起由乙方享有专用权。未完成上述登记或公告的，不得对抗依法应登记或公告后才能对抗的第三人，乙方有权暂扣相应尾款。」

不得把“双方同意视为已批准或已登记”写成可放行结构。

## 节点 6　格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 格式条款

为重复使用而预先拟定、订立时未与对方协商。从事经营活动的一方不得仅以“这次没用过第二次”否认。依据示范文本制作，不当然排除格式条款。

审查：免责、限责、排除对方权利、管辖/仲裁、单方确定清单等异常条款是否有足以引起注意的标识，以及是否按要求说明（第 496 条；解释第 10 条）。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在附件 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

提供方对其已尽提示或说明承担举证责任。

### 6.2 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的、是否仅行政管理、是否只规制履行行为（第 153 条；解释第 16、18 条）。禁止用已失效“效力性/管理性”口诀代替解释第 16 条。国资进场多为监管后果，不得单独写成民事合同当然无效。逃废债、阴阳、禁止流通物、让与担保流押：不改写成有效履行。

## 节点 7　违约、解除与争议

1. 逾期交付、逾期办理登记、权属不能转移、逾期付款必须分别有可执行后果。只有“依法承担违约责任”视为必须改。
2. 构成违约不等于当然解除。法定解除路径只点名催告或目的不能实现（第 597 条：未取得处分权致使所有权不能转移，买受人可以解除并请求违约责任），不在本任务作出已解除结论。
3. 违约金不是必得金额；不在本任务做第 585 条精算。修改句避免“不得调整”或“按总价 30% 必得”。
4. 争议解决：出现仲裁条款，不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核。不动产纠纷可能专属管辖：只标红旗，不选定唯一法院充作法律意见。
5. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

打开已加载的 `框架.md`，按六步逐段对照正文。`基本面.md` 用于校验类型、主体、标的、程序和红旗，不代替本节点出句。

| 步 | 动作 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题用资产转让或设备/专利/房屋转让，不用股权转让/资产收购/营业转让混称；主体全称；鉴于不写“保证无任何或有负债由买方承担”或“保证避税” | 标题或主体修改句 |
| 交易条款 | 单项标的；债务隔离；清单与交割确认单；价款与节点；负担涤除 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 权属不能转移的解除与违约金；逾期登记；通知抵押权人/承租人 | 可执行后果句或删除句 |
| 尾部 | 决议附件、清单、确认单、查询页；生效与权利变动分列 | 生效与附件修改句 |
| 语言 | 正说加反说；盯死交付 vs 登记、定金 vs 订金、概括承受、相关资产、洁净产权 | 替换空词的句子 |
| 常见问题 | 概括承债；无清单；签字即过户；让与担保；逃废债 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（概括承债、股权/营业错位、无清单拒补、逃废债/阴阳/让与担保、倒签、查封物强行过户）；
- `必须改`：可谈但签署前要落句（债务隔离、交割确认单、负担查询、合同与登记分列、决议附件）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级预付款且资产不能特定、用户拒绝升级：停止“可以签署”建议。
