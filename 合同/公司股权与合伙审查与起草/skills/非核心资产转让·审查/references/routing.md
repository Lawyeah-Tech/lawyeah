# 边界与路由

本技能只审查 **公司相关合同 / 资产转让合同（单项_非核心资产）** 的待签文本。中文展示名是「审查资产转让合同（单项_非核心资产）（公司相关合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 转让股权、股东资格、出资额；要股东名册或工商股东变更 | `公司股权转让·审查`。不得删掉股权条款后当资产买卖审 |
| 收购目标公司股权并以取得控制权为目的 | `股权收购合同（含控制权转移）·审查`（P1；专业版未装则 `unavailable`） |
| 一揽子资产构成业务线或营业；夹带员工安置、客户合同、资质、假定债务 | `资产收购合同·审查`（P1；未装则 `unavailable`） |
| 国有资产评估、进场、挂牌协议转让为主轴 | `国有资产转让合同（协议转让）·审查`（P1；未装则 `unavailable`） |
| 打包收购债权或不良资产包 | `债权收购合同·审查`（P1；未装则 `unavailable`） |
| 主给付是债权让与，核心是通知债务人 | `主给付是债权让与通知债务人为轴→` |
| 商家之间常规存货或标准设备购销，无公司处置语境 | `商家之间常规存货或标准设备购销无公司处置语境→` |
| 主文件是存量房买卖本约，户口/网签过户为主路径 | `主文件是存量房买卖本约（户口网签过户主路径）→` |
| 整份文本只是专利权转让本约 | `整份文本只是专利权转让本约→` |
| 整份文本只是注册商标转让本约 | `整份文本只是注册商标转让本约→` |
| 过户或让与加回购，担保借款 | `过户+回购担保借款→` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争 | `已出现催告解除函索赔立案开庭仲裁` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

单项设备正文里夹带一小段专利号或房屋坐落：可在本类型交割清单里审交付与登记义务；用户坚持本技能把股权、控制权或营业收购整案改完：`目标停止`。
