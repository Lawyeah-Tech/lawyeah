# 民办学校转让协议·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构，不证明本约条款已被接受。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、2004 年《民办教育促进法实施条例》、2013 年《民办教育促进法》第五十一条“合理回报”专条当作本类型默认规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **公司相关合同 / 民办学校转让协议** 己方稿，出稿后用本类型硬闸自审。交付草稿、未决项、自审风险表和自审后修改句。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「审查民办学校转让协议（公司相关合同）」。`depends-on` 为空。不要求先跑导航。

主线是**原举办者退出、新举办者加入并取得办学控制／管理权**。不是普通公司股权买卖，不是校舍设备商品出让，也不是社会团体换负责人。

不交付：他类审查、从零起草、履约交底、争议文书、有效性或必然核准／换证保证、股权转让／资产转让／资产收购／社团负责人变更的整份代审。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **举办者变更 ≠ 普通股权转让 ≠ 普通资产转让**：已持证民办学校的举办者身份与办学控制权交接 → 本类型。无办学许可证的公司股权让与 → `公司股权转让·审查`。土地／校舍／设备当商品出让、不改举办者 → `非核心资产转让·审查` 或 `资产收购合同·审查`。不得删掉股权交割包或资产买卖条款后继续当本类型审。
2. **举办者变更须审批**：举办者提出，财务清算，理事会／董事会三分之二以上同意，报审批机关核准。协议成立 ≠ 变更生效。报批义务条款独立有效。**禁止“签字即生效、签字即交章交证交管理权、双方同意视为已批准”。** 核准前不得把移交办学许可证、印章和主要价款写成可立即履行。
3. **先分营利／非营利**：义务教育不得设为或改成营利性。非营利举办者不得取得办学收益，办学结余全部用于办学；变更协议不得涉及学校法人财产，不得按净资产溢价买卖学校。营利性可按公司法等处理办学结余，但仍须办许可证与举办者／实控人变更。禁止把 2013 年“合理回报”专条写成现行默认权利。禁止设计由学校向原举办者划付补偿。
4. **办学许可证**：许可证须在有效期内，记载的举办者与转让方一致。禁止买卖、出租、出借、伪造许可证。无许可证的培训主体不按本类型审。

## 工作边界

正触发：已有可读待签举办者变更／民办学校转让正文或可单独评改的专章，尚未签署，尚未成争；学校已依法设立并持有或材料表明应持有办学许可证；核心给付是举办者身份与办学控制权交接。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 无办学许可证，只是普通公司股权让与 → `公司股权转让·审查`；
- 土地／校舍／设备当商品出让，不改举办者 → `非核心资产转让·审查` 或 `资产收购合同·审查`；
- 主文件是股权收购控制权且无办学许可／举办者变更叠加 → `股权收购合同（含控制权转移）·审查`；
- 国有股权或国有资产进场转让 → `国有股权转让合同（协议转让）·审查` 或 `国有资产转让合同（协议转让）·审查`；
- 社会团体换法定代表人／理事长，不是学校举办者 → `社会团体负责人变更合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问报批日、换证日、交章留痕 → 本套导航的履约步骤；
- 已成争（催告、审批复议、转让款诉讼、立案、开庭、仲裁）→ **教育／公司争议领域**，不填签前十节。

买卖非营利学校资产、学校划付补偿、买卖办学许可证、规避审批、义务教育改营利：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；代表原举办者还是新举办者；学校营利／非营利及是否义务教育；办学许可证记载；正文、章程、理事会决议、清算报告版本；价款是否挂钩净资产或由学校划付；不可接受事项；法域与拟签时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价款、比例、期限用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验《民办教育促进法（2018 修正）》第十九条、第二十条、第三十六条、第五十四条、第六十二条，《民办教育促进法实施条例（2021 修订）》第十条、第十二条、第二十二条、第二十六条，民法典第一百五十三条、第五百零二条，合同编通则解释第十二条、第十六条。`search_practiced` 补审查反例；`search_template` 只借修改句结构。不虚构案件系统。

`search_law` 对法律结论为 required 级：不可用时不拒绝执行，只停止法律结论字段。返回 2004 年实施条例、2013 年第五十一条合理回报、已失效《合同法》或其解释时记为噪声，不得写入 `L#`。2018 年文本第五十四条回执若只命中 2002 年同文，可同向吸收“举办者提出、财务清算、理事会同意、报审批机关核准”，并在运行时再核 2018 条号。民办非企业单位登记条例与社会组织登记条例交替未核验前，不得把登记机关条号写成 `L#`。


## 起草模式

本原子只承担本类型起草。待签评改转 `民办学校转让协议·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `民办学校转让协议·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。

### 起草必写

- 核心给付是原举办者退出、新举办者加入并取得办学控制／管理权，不是普通股权买卖或校舍设备出让。
- 举办者提出，财务清算，理事会／董事会三分之二以上同意，报审批机关核准。协议成立 ≠ 变更生效。报批义务条款独立有效。核准前不得把移交办学许可证、印章和主要价款写成可立即履行。
- 先分营利／非营利。义务教育不得设为或改成营利性。非营利举办者不得取得办学收益，办学结余全部用于办学；变更协议不得涉及学校法人财产，不得按净资产溢价买卖学校。营利性可按公司法等处理办学结余，但仍须办许可证与举办者／实控人变更。
- 办学许可证须在有效期内，记载的举办者与转让方一致。

### 附件必附

- 有效办学许可证。
- 学校章程、理事会／董事会三分之二同意决议、财务清算报告。

### 禁止出现

- “签字即生效、签字即交章交证交管理权、双方同意视为已批准”。
- 买卖非营利学校资产、由学校向原举办者划付补偿、买卖／出租／出借／伪造办学许可证。
- 把 2013 年“合理回报”专条写成非营利学校现行默认权利；义务教育改营利。
- 删掉股权交割包或资产买卖条款后继续当本类型起草。

出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签或补假批复、把买卖非营利学校资产或学校划付补偿改成可履行、把买卖办学许可证或义务教育改营利改成可履行、保证有效或必然核准。
- `字段停止`：未见营利／非营利分类或是否义务教育；未见有效办学许可证或记载不一致；未见理事会三分之二决议或财务清算；价款是否涉及法人财产不明；国资进场或外资规则未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或文本已滑入普通股权转让／资产买卖／社团负责人变更。

生存级金额或个人无限连带且用户拒绝升级：停止“可以签署”建议。
