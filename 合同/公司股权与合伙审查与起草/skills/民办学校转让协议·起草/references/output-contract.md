# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然核准／换证；编造未给出的价款、评估值、核准日；把已失效《合同法》或其解释、2013 年合理回报专条写入结论；写“签字即生效且可交章交证”；写“学校应当向原举办者支付补偿”；写非营利可按净资产买卖；把普通股权转让或资产买卖当成已完成的本类型审查。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查民办学校转让协议（公司相关合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、2004 年实施条例、2013 年第五十一条合理回报时记噪声，不得写入 `L#`。2018 年第五十四条未核验 2018 文本前，可同向吸收 2002 年同文程序，但须标注运行时再核。

## 3. 类型与加载路径

父级 `公司相关合同`，子级 `民办学校转让协议`。定性理由、易混切开结果（普通股权转让、资产转让／收购、社团负责人变更）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准：未经核准不写成协议当然无效；合理回报不写成非营利默认权利；学校划付补偿不写成合规路径。挂靠、买卖许可证、规避审批写停笔告知，不填可履行结构。

## 4. 主体、授权、分类与文本版本

主体表：原举办者、新举办者、学校（确认方）、理事会／董事会、审批机关、登记机关、授权签字人。分类：营利／非营利、是否义务教育、办学层次。版本表：正文、许可证、法人登记证、章程、理事会决议、清算／审计、土地证、聊天确认；冲突并列。未见学校盖章而学校被写成付款人或交割义务人：该字段停止。

## 5. 给付闭环

举办者权益特定化、许可证记载、审批与理事会／清算路径、价款／变更收益口径、付款是否挂钩核准、交割（证照印章账册，不得写成出售法人财产）、过渡期、职工与学生稳定、发票与税负。缺口标 `G#`，不补商业数字。批准、登记、换证写成生效条件或期限，不写成已经完成。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹；异常条款。强制规范只按民法典第一百五十三条和合同编通则解释第十六条区分，不用失效“效力性／管理性”口诀。分类管理、法人财产、擅自改变举办者、禁止买卖许可证只作为修改理由，不代替修改句。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。禁止输出无修改句的色块表。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。禁止只给原则、不给句子。禁止写出“自签字之日起生效并立即移交办学许可证和印章”“学校应向原举办者支付净资产对价”“非营利学校举办者有权取得合理回报”。

## 9. 谈判与签署提醒

谈判顺序：先红线（签字即交章、净资产买卖非营利学校、学校划付、买卖许可证、义务教育改营利），再必须改（成立与核准拆分、付款挂钩批复、理事会三分之二、清算附件、许可证记载），最后可优化（共管账户、过渡期知情权、学校所在地管辖）。签署提醒：许可证复印件、章程、理事会决议、清算／审计、土地性质、日期与附件清单。不指导倒签或补假批复。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书、效力保证，也不是普通股权转让本约或资产买卖审查。
