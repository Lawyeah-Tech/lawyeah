# 资产收购合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《物权法》《担保法》及其解释、1984 年《专利法》、2018 年《公司法》已被修改文本当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **公司相关合同 / 资产收购合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查资产收购合同（公司相关合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、把股权收购/控制权交割或单项非核心资产整案改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **资产清单与排除资产**：一揽子营业资产必须以附件《标的资产清单》和《排除资产清单》逐项特定。禁止“与该业务有关的全部资产一并转让”或“以现场为准”。
2. **负债是否承继（假定债务穷尽）**：除《假定债务清单》逐笔列明且经债权人书面同意的负债外，卖方主体债务仍由卖方承担。禁止“买方概括承受卖方全部债权债务”。
3. **重大资产决议**：按章程核股东会或董事会。上市公司一年内买卖重大资产超过资产总额百分之三十须股东会三分之二（公司法 2023 第 135 条）。未见决议：该签署能力字段停止。不得把 2018 年公司法第 104 条写成现行法；非上市无章程依据不得写“依法必须开股东会”。
4. **权属过户分项**：签字不当然等于不动产过户、专利权登记生效、商标核准公告、机动车登记对抗或合同权益对相对人生效。
5. **与股权收购 / 单项资产转让切开**：买股权或控制权 → `股权收购合同（含控制权转移）·审查`。单台设备、单项专利、单套不构成业务的房屋且不随员工/订单/资质 → `非核心资产转让·审查`。不得删条款后硬套。
6. **员工安置与资质不自动转移；逃废债停笔**：劳动合同不因资产交割当然转移。与主体绑定的许可通常不可随资产转让。低价掏空、阴阳价款、规避资质：只告知。用户坚持：整体停止。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签正文，尚未签署，尚未成争，核心给付是收购足以构成业务线或营业的一揽子资产（产线、客户合同、存货、知识产权、假定债务、员工安置或过渡期服务），买方不取得卖方股权或对卖方公司的控制权，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 收购目标公司股权或以取得控制权为目的 → `股权收购合同（含控制权转移）·审查`；
- 公司处置单台设备、单项知识产权、单套不构成业务的房屋，不随员工/订单/资质 → `非核心资产转让·审查`；
- 转让股权、股东资格、出资额 → `公司股权转让·审查`；
- 国有资产进场、评估挂牌协议转让为主轴 → `国有资产转让合同（协议转让）·审查`（P1；未装则 `unavailable`）；
- 打包收购债权或不良资产包 → `债权收购合同·审查`（P1；未装则 `unavailable`）；
- 主给付是债权让与、通知债务人为轴 → `主给付是债权让与通知债务人为轴→`；
- 商家之间常规存货或标准设备购销、无营业收购语境 → `商家之间常规存货或标准设备购销无公司处置语境→`；
- 主文件是存量房买卖本约（户口/网签过户主路径） → `主文件是存量房买卖本约（户口网签过户主路径）→`；
- 整份文本只是专利权转让本约 → `整份文本只是专利权转让本约→`；
- 整份文本只是注册商标转让本约 → `整份文本只是注册商标转让本约→`；
- 过户+回购担保借款 → `过户+回购担保借款→`；
- 无文本、本类型条件已谈妥、要出己方稿 → `资产收购合同·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `已出现催告解除函索赔立案开庭仲裁` 或对应专项领域。

逃废债、阴阳价款、规避资质、让与担保流押：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（转让方或收购方择一）；相对方；全文及资产清单/排除资产/假定债务/员工安置/权属件版本；标的是否构成业务线；是否写买方承受卖方全部债务、员工或资质；权利负担查询痕迹；内部决议；价款与节点；不可接受事项；法域、标的所在地与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价款、期限、证号用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验买卖定义、债务转移须同意、物权变动分项、重大资产决议、权利瑕疵、格式条款、专利/商标登记、经营者集中申报；`search_practiced` 只补审查反例；`search_template` 只借清单/假定债务/员工安置栏目。不虚构案件系统。

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)

禁止打开其他类型目录。`基本面.md` 把专利/商标登记写成“仅对抗第三人”时，按专利法（2020 修正）第 10 条、商标法（2019 修正）第 42 条纠正。`基本面.md` 写“出售核心资产通常必须开股东会”时，按公司法（2023 修订）第 59、135 条纠正：非上市以章程为准，上市达百分之三十阈值才法定须股东会特别决议。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `资产收购合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有营业资产收购文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。股权/控制权、单项非核心资产、国资进场、债权包、专项知产本约负触发。

### 2. 主体与重大资产决议

签约名、履行名、付款名、发票名分列。内部决议未附：该签署能力字段停止。国资/划拨/特许未核：字段停止。

### 3. 资产清单、负债承继与过户分项

清单与排除资产可核验；假定债务穷尽；负担未核不得写成无负担；不动产/专利/商标/动产/合同权益分项写变动时点。

### 4. 员工、资质、过渡期与对价

劳动关系不当然转移。许可不随资产自动转移。价款与交割、过户分项绑定。

### 5. 合同生效、批准与集中申报

批准、登记、经营者集中申报写成义务和条件，不写成已经完成。

### 6. 格式条款、强制规范与停笔结构

逃废债、阴阳、让与担保停笔。无核验引文则法律结论字段停止。

### 7. 违约、解除与争议

逾期交付、逾期过户、权属不能转移、逾期付款分别有后果。不动产专属管辖只标红旗。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把概括承债、逃废债、阴阳、规避资质或让与担保改成可履行结构。
- `字段停止`：法域、动态规则、国资进场、划拨批准、经营者集中营业额、权属查询、内部决议未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
