## **一、 首部 要素审查**

1.  **合同标题**：
    * 标准命名应为“资产转让合同”、“资产收购协议”或“业务转让合同”。
    * **核心风险**：标题必须明确是“资产”收购，以区别于“股权收购”。

2.  **合同主体**：
    * 转让方（卖方）与收购方（买方）的主体信息（名称、统一社会信用代码、法定代表人、住所、联系方式）必须完整、准确。
    * **核心风险**：审查转让方是否为拟转让资产的合法所有权人（或有权处分人）。如资产分散在多个关联公司名下，需确保签约主体有权处置全部资产，或由各资产持有人共同作为转让方。

3.  **鉴于条款**：
    * 应清晰陈述交易背景：转让方意图转让特定业务线相关的核心资产，收购方意图收购该等资产以运营业务。
    * **核心风险**：避免在鉴于条款中写入实质性的权利义务（如付款前提、陈述保证等），鉴于条款通常仅用于合同解释，不具备独立的法律约束力。

## **二、 交易条款 审查**

1.  **标的条款（资产范围）**：
    * **描述**：这是资产收购合同的**绝对核心**。
    * **最佳实践**：必须采用“**附件：标的资产清单**”的方式详细定义。
    * **清单内容**：
        1.  **固定资产**：包括但不限于房屋、建筑物、机器设备、运输工具等。需详细列明资产名称、规格型号、数量、存放地点、账面原值、净值及产权证书编号（如房产证）。
        2.  **土地使用权**：明确地块位置、面积、用途（工业、商业等）、权利类型（出让或划拨）及剩余年限。**核心风险**：划拨土地使用权的转让涉及政府审批和补缴土地出让金，必须明确约定办理程序和费用承担。
        3.  **无形资产**：
            * **知识产权**：详细列明专利、商标、软件著作权的名称、类别、注册号/申请号、法律状态。
            * **技术秘密**：如涉及，应明确其范围和交付载体。
        4.  **债权**：如收购业务线包含应收账款，需列明债务人名称、金额、账龄。
        5.  **其他资产**：如存货、原材料、在产品等。
    * **排除的资产与负债**：
        * 必须明确约定“**排除的资产**”（如转让方的现金、特定合同、印章证照等）不属于转让范围。
        * **核心风险（债务承担）**：必须明确约定“**承继的负债**”（如有）和“**排除的负债**”。资产收购的原则是买方不承继卖方的债务（尤其是历史税务、劳动、侵权债务），除非合同明确约定承继特定负债（如与业务相关的已披露负债）。

2.  **价款条款**：
    * **构成**：明确约定总收购价款。
    * **最佳实践**：建议对不同类别的资产（如不动产、设备、知识产权）进行**价格分摊**，这直接影响双方的税务处理（尤其是土地增值税和资产转售时的成本认定）。
    * **支付**：
        1.  **支付节点**：明确约定付款节奏，通常与交割挂钩。例如：
            * 签约后支付**定金**或预付款。
            * **交割日**支付大部分款项。
            * 预留一定比例的**尾款**（质保金），待交割后资产过渡期满或特定义务（如协助过户）完成后支付。
        2.  **支付前提**：明确约定付款（尤其是交割款）的前提条件，即“交割前提条件”已全部满足。
    * **发票与税务**：
        * **核心风险（税务）**：资产收购涉及高额税负，如增值税、土地增值税、企业所得税等。
        * **约定模式**：必须明确约定各项税费由哪一方承担，通常约定转让方承担其因转让资产产生的全部税费。
        * **发票**：明确约定转让方在收到款项后N日内，必须开具合法合规的**增值税专用发票**。

3.  **履行条款（交割与过户）**：
    * **交割日（Closing Date）**：明确约定一个具体的日期或一个在前提条件满足后触发的日期。
    * **交割前提条件**：约定交割必须满足的前提条件，是收购方的核心保护机制。例如：
        1.  转让方的陈述与保证在交割日真实准确。
        2.  转让方已履行交割前的所有义务。
        3.  转让方已取得转让所需的所有内部授权（股东会决议）和外部批准（如政府对划拨土地转让的批准、债权人对核心合同转让的同意）。
        4.  标的资产未发生重大不利变化。
    * **交割动作（Closing Actions）**：约定在交割日，双方需同时完成的动作：
        1.  转让方交付标的资产的实物（如钥匙、设备、存货）和文件（如房产证、土地证、专利证书原件、重要合同原件）。
        2.  收购方支付交割日应付的收购款项。
        3.  双方签署交割确认书。
    * **过户（Title Transfer）**：
        1.  **核心风险**：不动产、土地使用权、专利、商标等权利的转移，**不以实物交付为准，而以行政登记（过户）为准**。
        2.  **约定**：必须明确约定双方在交割日后N日内，共同前往相关登记机关（不动产登记中心、知识产权局）办理权属变更登记手续。
        3.  **义务分配**：明确约定由转让方负责准备和提交材料，收购方予以配合；或反之。并明确办理过户产生的相关费用（如登记费、测绘费）由谁承担。
    * **风险转移**：约定标的资产毁损、灭失的风险在**交割日**（而非合同签订日）从转让方转移至收购方。

## **三、 配套条款 审查**

1.  **陈述与保证**：
    * **转让方保证（核心）**：
        1.  **主体资格**：转让方是合法设立并有效存续的企业，有权签署和履行本合同。
        2.  **资产权属**：转让方对标的资产拥有合法、完整、清晰的所有权（或处分权），资产上**未设置任何抵押、质押、留置**或其他第三方权利（担保物权）。
        3.  **合规性**：资产的运营和维护符合所有法律法规（如环保、劳动、税务）。
        4.  **知识产权**：转让的知识产权合法有效，**不侵犯任何第三方知识产权**，且转让方未收到任何侵权指控。
        5.  **诉讼**：标的资产未涉及任何未决诉讼、仲裁或行政调查。
        6.  **信息披露**：转让方为收购目的披露的所有文件和信息均真实、准确、完整。
    * **收购方保证**：保证主体合法有效存续；有权签署和履行合同；具备支付收购款的能力。

2.  **交割前义务（过渡期条款）**：
    * 约定自合同签订日至交割日期间，转让方必须履行的义务：
        1.  **维持运营**：必须以正常、审慎的方式继续运营业务，保护资产完好。
        2.  **禁止处置**：**不得**对标的资产进行出售、抵押、转让或设置任何权利负担。
        3.  **禁止异常**：不得异常解雇核心员工、不得销毁业务记录。
        4.  **配合尽调**：允许收购方及其顾问（律师、会计师）继续进行尽职调查。

3.  **人员安置**：
    * **核心风险**：资产收购不等于劳动关系自动转移。
    * **方案一（不接收员工）**：明确约定所有员工（包括管理层）的劳动关系均不转移至收购方，由转让方自行负责安置（如协商解除），并承担全部经济补偿金和相关责任。
    * **方案二（接收员工）**：明确约定收购方“**愿意要**”的员工名单。被选中的员工，必须先与转让方**依法解除劳动合同**（由转让方支付经济补偿金），再由收购方**重新建立劳动关系**（签订新劳动合同）。

4.  **债权债务处理**：
    * **核心原则**：明确重申，除合同明确约定的“承继负债”外，转让方在交割日之前的所有债务（包括但不限于税务、贷款、劳动、侵权、违约债务）**均由转让方自行承担**，与收购方无关。
    * **应收账款**：如应收账款一并转让，必须约定转让方应在交割后N日内**通知债务人**该债权转让的事实（债权转让通知是债权转让对债务人生效的法定要件）。

5.  **违约责任条款**：
    * **主要违约情形**：
        1.  收购方逾期支付价款。
        2.  转让方逾期交付资产或不配合办理过户。
        3.  **转让方的陈述与保证不真实、不准确（最核心的违约）**。
    * **救济措施**：
        1.  **违约金**：约定逾期付款或逾期交割的违约金计算方式（如按日万分之五）。
        2.  **赔偿损失**：明确约定因转让方违反陈述与保证（如资产存在隐藏抵押、知识产权侵权）导致收购方遭受的一切损失（包括但不限于直接损失、可得利益损失、律师费、诉讼费），转让方均应予以赔偿。

6.  **解除与终止条款**：
    * **约定解除**：
        1.  一方发生重大违约（如转让方资产存在重大瑕疵、收购方逾期付款超过N日），经催告后仍未纠正的，守约方有权**单方解除合同**。
        2.  交割前提条件在约定日期（Long-stop Date）前仍未满足的，任一方（或收购方）有权解除合同。
    * **善后处理**：合同解除后，转让方应立即返还已收购房款及利息；涉及资产已交付的应予返还。

7.  **争议解决条款**：
    * 选择**仲裁**或**诉讼**。
    * 如选择诉讼，应约定由**被告住所地、合同履行地、合同签订地**等与争议有实际联系的地点的人民法院管辖。**核心风险**：不动产（房屋、土地）转让引起的纠纷，属于不动产专属管辖，必须约定由**不动产所在地**法院管辖。由于资产包可能涉及多地不动产，此条款需谨慎设计。

8.  **保密与不竞争**：
    * **保密**：双方应对交易谈判内容和尽调信息保密。
    * **不竞争**：为保护收购业务的商誉，应约定转让方及其关联方在交割后N年内，不得在特定地域内从事与转让业务相竞争的业务。

## **四、 尾部 要素审查**

1.  **签名盖章**：
    * 必须由双方的**法定代表人**或**授权代表**签字，并加盖**公章**或**合同专用章**。
    * **核心风险**：资产收购（尤其是涉及土地、不动产）属于重大交易，必须审查双方是否已履行内部决策程序（如股东会决议、董事会决议），建议将相关决议文件作为合同附件。

2.  **日期与地点**：
    * **合同签订地点**：可能影响管辖权，应明确约定。
    * **合同签订日期**：涉及倒签风险，应真实填写。

3.  **生效条款**：
    * 标准约定：“本合同自双方签字盖章之日起生效。”
    * **附条件生效**：如资产转让（特别是涉及国有资产或划拨土地）需要**政府主管部门批准**，应约定：“本合同自双方签字盖章，并取得XX政府部门批准后生效。”

4.  **附件**：
    * 必须明确约定：“本合同附件（包括但不限于《标的资产清单》等）为本合同不可分割的组成部分，与本合同具有同等法律效力。”
    * **核心风险**：附件与主合同冲突时，应明确约定以主合同为准（或以附件为准）。

## **五、 合同语言审查**

1.  **准确性（“正说反说+概括列举”）**：
    * **标的资产**：必须使用“包括但不限于……”的列举方式，并辅以“资产清单”作为兜底。
    * **排除的负债**：必须使用“反说”（不得）和“概括”（一切、任何）来界定：“收购方不承继转让方在交割日前的**任何**债务，无论该等债务是否已披露、是否到期”。

2.  **逻辑性（金字塔结构）**：
    * 条款结构应清晰，特别是“交割”条款，应按“交割前提”、“交割日”、“交割动作”、“交割后义务”的逻辑顺序排列。
    * **“和”与“或”**：在罗列交割前提条件时，必须使用“**和**”，表明所有条件均需满足。

3.  **重点词语（高风险词）**：
    * **“重大不利变化”**：必须在定义条款中予以量化，例如“导致资产价值减损超过XX万元”或“导致业务收入下降超过XX%”。
    * **“现状”**：约定“按现状交付”时，必须明确“现状”是以“签约日”还是“交割日”为准，并应以尽职调查报告为基础，防止转让方在过渡期内怠于维护资产。
    * **“定金”与“订金”**：明确区分，若为“定金”，则适用定金罚则（买方违约不退，卖方违约双倍返还）。
    * **“交钥匙”**：明确“交钥匙”不等于不动产所有权和风险的转移，风险转移在“交割日”，所有权转移在“登记完成日”。
