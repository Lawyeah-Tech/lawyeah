# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的价格、工期、数量；把已失效《合同法》《物权法》或 2018 年公司法已被修改文本写入结论；把买方写成概括承继卖方全部主体债务；把签字写成不动产、专利、商标已一并过户；把未见清单写成可以交割；把股权收购或单项非核心资产当成已完成的本类型审查；把劳动合同或行政许可写成已随资产自动转移。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查资产收购合同（公司相关合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》《物权法》《担保法》或其解释、1984 年《专利法》、2018 年《公司法》已被修改文本时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `公司相关合同`，子级 `资产收购合同`。定性理由、易混切开结果（股权收购/控制权、单项非核心资产、股权转让、国资进场、债权、动产买卖、二手房本约、专利/商标专项）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、授权、重大资产决议与文本版本

主体表：签约名、履行名、付款名、发票名、授权签字人、共有人或担保人。决议表：章程要求的股东会或董事会；上市公司是否触及第 135 条。版本表：正文、标的资产清单、排除资产清单、假定债务清单、员工安置方案、权属件、交割确认单、聊天确认；冲突并列。未核决议：该签署能力字段停止。

## 5. 给付闭环

是否构成业务线；资产清单与排除资产；假定债务穷尽及债权人同意；权利负担；权属过户分项（不动产/动产/机动车/专利/商标/合同权益）；员工安置与资质路径；价金与节点；发票；过渡期服务。缺口标 `G#`。不输出股东名册、工商股东变更或控制权交割主路径。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹。强制规范只按第 153 条和解释第 16 条区分，不用失效口诀。逃废债、阴阳、让与担保、规避资质只保留识别与停笔。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把框架里的商品房惩罚性赔偿写成默认路径。不得把“交钥匙”写成不动产或知识产权已转移。

## 9. 谈判与签署提醒

谈判顺序：先红线（概括承债、股权/单项资产错位、无清单仍交割、逃废债/让与担保），再必须改（假定债务穷尽、资产清单与排除资产、重大资产决议、过户分项、员工安置与资质），最后可优化。签署提醒：决议入附件；清单、假定债务与正文冲突时以哪一份为准；分项过户申请与付款节点对齐。不指导倒签或补假权属。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书或效力保证，也不是股权收购、控制权交割或单项非核心资产审查。
