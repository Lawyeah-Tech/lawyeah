# 边界与路由

本技能只审查 **公司相关合同 / 股权收购合同（含控制权转移）**。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 存量股权换价款、注册资本不增加，交割不以印章／董事会／账户移交或实际支配为主结构 | `公司股权转让·审查` |
| 买特定资产、营业包或业务线，不买公司股权主体 | `资产收购合同·审查`；单项非核心资产 → `非核心资产转让·审查` |
| 资金进公司、注册资本增加，且目的不是取得控制 | `增资合同·审查` |
| PE／VC secondary、估值保护、随售拖售、反稀释、投资人股东协议一并买入，且不移交控制 | `PE股权转让·审查` |
| 业绩对赌、估值调整、公司或控股股东回购承诺为主给付 | `对赌协议（盈利预测补偿协议）·审查` |
| 国有股东、评估备案、进场挂牌、产权交易机构成交确认 | `国有股权转让合同（协议转让）·审查`。不得设计场外协议规避进场 |
| 上市公司要约收购、权益变动披露、强制要约 | 转引擎重新定性或对应上市公司收购原子；不得用有限公司交割包硬套 |
| 主文件是代持安排 | `股权代持协议·审查` |
| 主文件是公司回购股权 | `股权回购协议·审查` |
| 主文件是股东协议整审、出资合同、章程整份代审 | `公司股东协议·审查`、`出资合同（有限责任公司）·审查` 或 `公司章程_章程修正案·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、履约节点 | 本套导航的履约步骤 |
| 已记载名册、已变更登记、已接管印章后再要解除或把控制权要回；催告、索赔、立案、仲裁 | 公司／投资并购争议领域；不填签前十节 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

专业版未收录的 P1 场景不会作为邻类原子的替代审查对象。若用户拿普通转股或资产收购文本来找本技能：输出负触发路由，不得用控制权交割包硬套。

本技能不得转去加载普通转股、资产收购、投资侧或对赌双文件完成本类型审查。不得把“买股权改成买资产”写成可履行避债结构。
