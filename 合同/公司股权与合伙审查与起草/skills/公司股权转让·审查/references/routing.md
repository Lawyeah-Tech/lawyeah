# 边界与路由

本技能只审查 **公司股权转让**。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 股权投资相关合同项下同名转让：secondary 投资、估值保护、随售／拖售、投资人股东协议一并买入 | `PE股权转让·审查` |
| 资金进公司、注册资本增加、新发行权益 | `增资合同·审查` |
| 控制权转移：印章证照账户交接、董事会改组、拖售、交割以治理权移交为核心 | `股权收购合同（含控制权转移）·审查` |
| 业绩对赌、估值调整、公司或控股股东回购承诺为主给付 | `对赌协议（盈利预测补偿协议）·审查` |
| 国有股权、评估、进场挂牌、产权交易机构成交确认 | `国有股权转让合同（协议转让）·审查` |
| 买特定资产、不承继公司主体 | `非核心资产转让·审查` 或 `资产收购合同·审查` |
| 主文件是代持安排 | `股权代持协议·审查` |
| 主文件是公司回购股权 | `股权回购协议·审查` |
| 主文件是股东协议、出资合同 | `公司股东协议·审查` 或 `出资合同（有限责任公司）·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `公司股权转让·起草` |
| 已签未争、履约节点 | 本套导航的履约步骤 |
| 已记载名册或已变更登记后仍要“改合同把股权要回”、催告解除索赔立案仲裁 | 公司／投资并购争议领域；不填签前十节 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

专业版未收录的 P1 场景（含控制权收购、对赌、国有进场、投资侧同名转让）不会作为本原子的实体审查对象。若用户拿这些文本来找本技能：输出 `unavailable` 或负触发路由，不得用本类型硬套。

本技能不得转去加载投资侧、收购侧或对赌双文件完成本类型审查。
