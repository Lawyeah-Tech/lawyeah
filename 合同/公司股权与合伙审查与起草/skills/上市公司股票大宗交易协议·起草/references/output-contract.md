# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受、必然成交或必然过户；编造未给出的价格、数量、T 日；把已失效《合同法》、2017《若干规定》或 2007 国有股东转让暂行办法写入结论；保证未预披露也可先签后补；写“受让后即可再卖”；把认购、激励或协议转让文本当成已完成的本类型审查；把 T 日申报成功写成已经过户。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查上市公司股票大宗交易协议（公司相关合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、2017《若干规定》或 2007 国有股东转让暂行办法时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `公司相关合同`，子级 `上市公司股票大宗交易协议`。定性理由、易混切开结果（认购 / 激励 / 国有股权协议转让 / 集中竞价委托）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、减持资格、权利负担与文本版本

主体表：签约名、证券账户、券商会员、授权签字人。身份表：是否大股东、控股股东、实际控制人、董事、监事、高级管理人员、一致行动人、国有股东。负担表：限售、质押、冻结、公开承诺。版本表：正文、减持计划公告、持股证明、国资批复、聊天确认；冲突并列。

## 5. 预披露、价格数量、锁定、申报过户与保证金

预披露是否完成及是否写成先决；约定价格是否可能落在涨跌幅外；数量与三个月 2%；受让方六个月锁定是否落句；T 日、申报要素、过户时点是否以登记完成之日为准；保证金比例与国资 30%；缺口标 `G#`。不输出激励解锁口径，不输出定增注册生效口径。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹。规避锁定、过桥、禁止减持期内申报不得写成可放行。强制规范只按第一百五十三条及合同编通则解释第十六条区分是否导致民事行为无效，不用失效口诀。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把专有／非专有激励方式或认购生效条件直接写成“大宗类型”。

## 9. 谈判与签署提醒

谈判顺序：先红线（实为认购或激励、禁止减持期、拒写六个月锁定、未预披露拒补、价格必然无法申报、过桥），再必须改（预披露先决、价格区间、三个月 2%、保证金、申报要素、过户时点），最后可优化。签署提醒：授权书、证券账户与券商一致、减持计划公告作为附件、国资批复（如适用）、T 日前资金到位凭证。不指导倒签或先签后补预披露。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书或效力保证，也不是认购、激励或国有股权协议转让安排。
