# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、必然完成登记对抗或对方接受；编造未给出的价款、估值、比例、税负；把已失效《合同法》或 1993／2018 年《公司法》同条号旧义写入结论；把增资、代持、设立出资或零元赠与硬套本类型。

## 1. 触发、单方立场与成果状态

立场（投资人／受让方或老股东／转让方）、授权、签署状态、主要目标。增资、代持、出资、零元赠与或其他负触发写路由，不启动实体审查。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》、1993／2018 年《公司法》同条号或解释（四）第十七条过半数同意旧程序时记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `股权投资相关合同`，子级 `股权转让合同`。写定性理由和与增资／代持／出资／零元赠与／公司相关转股／项目公司／条款清单／股东协议的切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。阴阳合同、先付款再通知或规避准入写停笔告知，不填可履行规避结构。

## 4. 主体、授权、权属人与文本版本

主体表：转让方、受让方、目标公司、付款名、名册记载名、隐名／显名（如有）、授权签字人。版本表：正文、资本表、股东协议、优先购买通知、工商简易稿、聊天确认；价格冲突按阴阳合同处理，不选对用户有利的一版。

## 5. 给付闭环（本类型必填）

固定检查并回链文本：

- 标的：公司名称、转让比例、对应注册资本、完全稀释口径；
- 资金终点：价款进转让方，注册资本不因本约增加；
- 对价是否为零（为零则本任务不应进入本节实体）；
- 权利负担：质押、冻结、查封、表决权委托、代持；
- 认缴、实缴、出资期限与第八十八条安排；
- 优先购买通知四要素或全体书面放弃；
- 单一真实价款；估值口径；锁定箱或完成账；
- 先决条件 → 付款 → 名册记载 → 登记递件的顺序及未完成后果；
- 股东协议或加入函是否与交割同时生效；
- 公司回购是否绑定减资。

缺口标 `G#`，不补商业数字。名册、登记写成义务或条件，不写成已经完成。

## 6. 格式条款与强制规范

是否构成格式条款（含示范文本填充）；提示说明痕迹。强制规范只区分是否导致民事行为无效与是否仅造成履行障碍（登记、批准、外资或集中申报）。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。四项硬闸若文本或事实触及，必须各有至少一行，不得用色块代替。

## 8. 修改句

按框架六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点、不接受时的红线。未给出的商业数字用 `【待填】`。禁止只给原则、不给句子。禁止输出增资认缴、赠与任意撤销或设立验资公式充当本类型修改句。

## 9. 谈判与签署提醒

谈判顺序：先红线（实为增资／代持／出资／赠与、先付款再通知、阴阳价、查封质押），再必须改（估值、交割顺序、未届期出资、股东协议加入、优先购买四要素），最后可优化。签署提醒：授权与决议、自然人卖方婚姻状况、用印、日期不得倒签、附件清单、名册与登记查询时点、监管开户凭证。不指导倒签或补假优先购买放弃。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本任务只出审查意见和修改句，不出整份起草终稿。不是履约交底、争议文书、登记代办或效力保证。
