# 有限合伙企业合同·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构，不证明本约条款已被接受。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、1997 年《合伙企业法》同条号、已失效《合伙企业登记管理办法》或民法通则合伙条文当作现行规则。不得把民法典个人合伙章或普通合伙企业“全体无限连带”写成有限合伙默认路径。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **合伙合同相关 / 有限合伙企业合同** 己方稿，出稿后用本类型硬闸自审。交付草稿、未决项、自审风险表和自审后修改句。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。`depends-on` 为空。不要求先跑导航。

主线是**普通合伙人执行事务并承担无限连带责任、有限合伙人以认缴出资额为限、有限合伙人不执行合伙事务**的企业合伙协议。不是普通合伙企业，不是不领执照的个人合伙，不是公司股东协议，不是保本借贷。

不交付：他类审查、从零起草、履约交底、争议文书、有效性或节税保证、把 LP 越位改成可履行共同管理、把禁止担任 GP 的主体改成隐名 GP、把固定收益无条件回购改成可履行保本份额。

## 工作边界

正触发：已有可读待签文本要评改（审查模式），或本类型条件已谈妥要出己方稿（起草模式）；尚未签署，尚未成争；核心给付是设立或承接有限合伙企业，正文区分普通合伙人与有限合伙人；拟领取或名称带“有限合伙”。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 全体普通合伙人、无 GP／LP 分档、名称带“普通合伙”或“特殊普通合伙” → `普通合伙企业合同·审查`；
- 无法人、不领取合伙企业执照的自然人共同事业 → `个人合伙合同·审查`；
- 主文件是公司股东协议（股权比例、否决权、随售拖售、章程治理）→ `公司股东协议·审查`；
- 不承担经营风险、到期固定本息或无条件回购本金 → 自然人之间借款 `不参与经营不承担亏损到期固定本息→自然人之间借款`，或企业间借款 `或企业间借款`；
- 只拿固定报酬、不认缴、无合伙人身份 → 个人劳务 `只拿固定报酬不分担亏损无合伙人决策权→个人劳务（雇佣）`；人格从属＋工资社保 → 劳动合同 `人格从属＋工资社保→劳动合同`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问缴资日、分配留痕 → 本套导航的履约步骤；
- 已成争（催告解散、清算诉讼、出资追缴、申请追加普通合伙人为被执行人、立案仲裁）→ **合同争议领域**，不填签前十节。

国有独资公司、国有企业、上市公司、公益性事业单位或社会团体拟任普通合伙人：只出告知，不改写成隐名可履行 GP。向不特定对象公开募集：只告知，不改成可履行规避结构。

## 建立审查坐标

确认：使用者与授权；代表普通合伙人还是有限合伙人；相对方；正文与附件、侧函版本；认缴／执行／分配／转换安排；不可接受事项；法域与拟签、拟登记时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的认缴额、缴付日、管理费、通知期用 `【待填】`，不编造。

## 本类型硬闸

审查过程必须逐项点名，每闸必须有修改句，不得用个人合伙对外连带、普通合伙全体执行或股东优先购买代替：

1. **有限合伙企业 ≠ 普通合伙企业 ≠ 个人合伙**：必须同时有 GP 与 LP，名称标明“（有限合伙）”，适用《合伙企业法》有限合伙章。全体无限连带或无分档 → `普通合伙企业合同·审查`。不领执照的自然人共同事业 → `个人合伙合同·审查`。
2. **GP 无限连带／LP 以认缴为限**：不得把普通合伙人改成“只以出资为限”，也不得把有限合伙人改成对外无限连带或“责任为零”。未缴出资的有限合伙人在未缴范围内仍可能被追加。
3. **LP 不得执行合伙事务**：不得对外代表企业。第六十八条列明的监督、建议、查阅、诉讼、提供担保等不视为执行。共同管理、共管公章、投决一票拍板超出安全港：必须改，并提示表见普通合伙人风险。

配套闸（文本触及或沉默均须点名）：LP 不得以劳务出资；可以约定全部利润归部分合伙人，但不得约定全部亏损由部分合伙人承担；固定收益＋无条件回购按名实切开，不得写成可履行保本；身份转换须一致同意（另有约定除外）并提示转换前后债务档；仅剩有限合伙人应当解散；第三条主体不得任 GP。


## 起草模式

本原子只承担本类型起草。待签评改转 `有限合伙企业合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `有限合伙企业合同·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。

### 起草必写

- 必须同时有 GP 与 LP，名称标明“（有限合伙）”，适用《合伙企业法》有限合伙章。
- GP 无限连带，LP 以认缴为限。不得把普通合伙人改成“只以出资为限”，也不得把有限合伙人改成对外无限连带或“责任为零”。未缴出资的有限合伙人在未缴范围内仍可能被追加。
- LP 不得执行合伙事务、不得对外代表企业。第六十八条列明的监督、建议、查阅、诉讼、提供担保等不视为执行。
- LP 不得以劳务出资。可以约定全部利润归部分合伙人，但不得约定全部亏损由部分合伙人承担。
- 身份转换须一致同意（另有约定除外）并提示转换前后债务档；仅剩有限合伙人应当解散。第三条主体不得任 GP。

### 附件必附

- GP／LP 分档表：认缴额、缴付日、执行权限。
- 安全港与投决边界安排。

### 禁止出现

- LP 共同管理、共管公章、投决一票拍板超出安全港仍写成“有限责任共管”。
- “债权人不得向 GP 追索”；固定收益＋无条件回购写成可履行保本。
- 禁止担任 GP 的主体改成隐名可履行 GP；向不特定对象公开募集。
- 按个人合伙对外连带或普通合伙全体执行起草。

出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录，禁止为对照打开普通合伙企业、个人合伙、股东协议或借款双文件。交付按 [输出合同](references/output-contract.md)。边界见 [路由](references/routing.md)。

必须有修改句。禁止只打红黄绿。每个风险回链文本位置。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验《合伙企业法》（2006 修订）第二条、第三条、第六十条至第六十九条、第七十五条、第七十六条、第八十二条、第八十四条、第九十二条；执行变更追加规定第十四条；企业名称登记管理规定实施办法第十二条。`search_practiced` 补审查反例；`search_template` 只借修改句结构。不虚构案件系统。

`search_law` 对法律结论为 required 级节点：不可用时不拒绝执行，只停止法律结论字段。返回 1997 年《合伙企业法》同条号、已失效登记办法、民法通则、已失效《合同法》或其解释时记为噪声，不得写入 `L#`。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签或假缴资、把禁止担任 GP 的主体改成隐名可履行、把 LP 共同执行改成可履行“有限责任共管”、把“债权人不得向 GP 追索”写成可履行、把固定收益无条件回购写成可履行保本、向不特定对象公开募集并要求规避结构、保证有效或 GP 必然不被追债。
- `字段停止`：GP／LP 分档、认缴额、执行权限、安全港、GP 主体适格、人数、身份转换、仅剩一类合伙人后果未写清。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或文本已滑入普通合伙企业／个人合伙／股东协议／借贷。

普通合伙人生存级个人财产可能被无限追索且用户拒绝升级：停止“可以签署”建议。
