# 边界与路由

本技能只审查 **合伙合同相关 / 有限合伙企业合同**。主线是普通合伙人无限连带、有限合伙人以认缴为限、有限合伙人不执行合伙事务的企业协议。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 全体普通合伙人、无 GP／LP 分档、名称带“普通合伙”或“特殊普通合伙” | `普通合伙企业合同·审查` |
| 无法人、不领取合伙企业执照的自然人共同事业 | `个人合伙合同·审查` |
| 主文件是公司股东协议：股权、否决权、随售／拖售、章程治理 | `公司股东协议·审查` |
| 不承担经营风险、到期固定本息或无条件回购（自然人） | `不参与经营不承担亏损到期固定本息→自然人之间借款` |
| 同上但双方为企业或其他组织 | `或企业间借款` |
| 只拿固定报酬、不认缴、无合伙人身份 | `只拿固定报酬不分担亏损无合伙人决策权→个人劳务（雇佣）` |
| 人格从属＋工资社保的劳动关系 | `人格从属＋工资社保→劳动合同` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式（出稿后自审） |
| 已签未争、问缴资日／分配留痕 | 本套导航的履约步骤 |
| 已成争：催告解散、清算诉讼、出资追缴、追加普通合伙人为被执行人、立案仲裁 | 合同争议领域；不填签前十节 |
| 第三条主体拟任 GP、公开募集规避、LP 越位要求可履行共管 | 停笔告知，不改写成可履行规避结构；用户坚持则整体停止 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

专业版未收录的邻类不会作为本原子的实体审查对象。若用户拿这些文本来找本技能：输出 `unavailable` 或负触发路由，不得用本类型硬套。

本技能不得转去加载普通合伙企业、个人合伙、股东协议或借款双文件完成本类型审查，也不得把民法典个人合伙连带、个人合伙劳务可出资或股东优先购买写成有限合伙默认主路径。
