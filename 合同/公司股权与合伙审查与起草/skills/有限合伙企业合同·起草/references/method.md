# 审查方法（锁定 合伙合同相关 / 有限合伙企业合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型，禁止打开普通合伙企业、个人合伙、股东协议或借款双文件“对照一下”。

本文件是**普通合伙人无限连带、有限合伙人以认缴为限、有限合伙人不执行合伙事务**的企业协议签前判断节点，不是栏目说明书，也不是民法典个人合伙清单或普通合伙“全体执行”清单。禁止把第九百七十三条个人连带、个人合伙劳务可出资、股东优先购买、董事会改组写入本类型默认结论。

每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、必然节税、普通合伙人必然不被追个人、有限合伙人越位也必然不被穿透、对方必然接受或唯一必得金额。

`search_law` 返回已失效《合同法》及其解释、1997 年《合伙企业法》任何同条号、已失效《合伙企业登记管理办法》（2019 修订）、已失效《外商投资合伙企业登记管理规定》、民法通则第三十一条至第三十五条、1990 年联营解答时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突。

示范文本只参考结构。市场监管合伙协议示范文本或基金业协会参考文本不证明本约条款已被接受；符合格式条款定义的，仍按格式条款审查。

### 双文件使用（标题与文件名不完全对应时不拒跑）

同目录两份知识文件按标题语义使用，不回改正文，不因文件名拒跑：

- 含“首部 / 交易条款 / 配套 / 尾部 / 语言”的当框架级条款清单，供节点 8 出句；
- 宏观的类型切开、GP／LP 分档、执行隔离、出资责任、登记程序、结构红旗由本方法节点承担。
- 知识稿把 LP 责任写成“以出资额为限”的，**降级为以认缴出资额为限**（第二条第三款）。知识稿把“GP 绝对经营管理权”写成无边界的，**降级为**：GP 执行事务，LP 仍享有第六十八条安全港监督，且重大事项可另约一致决或多数决。知识稿“先分后税、避免双重征税”**不得写成已核验节税结论**。知识稿“LP 转让通常提前 30 日通知”：本次检索未回传第七十三条全文，作出法律结论前须再核；未核验则该条号字段停止，修改句仍按“通知其他合伙人并办理变更登记”出草稿。
- 文件不可用（空、代码块、与本类型明显无关）：记 `G#`，用本方法节点继续，不得改去加载普通合伙或个人合伙双文件，不得编造认缴额。

## 节点 1　类型识别与负触发

### 1.1 本类型正像

同时满足才继续：

- 文本区分**普通合伙人**与**有限合伙人**，或企业名称／登记事项拟标明“（有限合伙）”；
- 核心给付是依《合伙企业法》设立或承接有限合伙企业，而不是全体无限连带、也不是不领执照的个人共同事业；
- 至少拟有一名普通合伙人和一名有限合伙人。

标题写成“合伙协议”“LPA”“有限合伙合同”只是线索。名实不符按核心给付归类，标题冲突写入 `C#`。合同编通则解释第十五条：不拘泥名称，结合内容、背景、目的、结构、履行认定实际关系。

### 1.2 必须切开（禁止两套知识）

| 信号 | 归入 | 本技能动作 |
| --- | --- | --- |
| 全体普通合伙人、无 GP／LP 分档、名称带“普通合伙”或“特殊普通合伙” | 普通合伙企业合同 | **负触发** → `普通合伙企业合同·审查`。不得删掉分档后继续当有限合伙审，不得抄普通合伙模板主路径 |
| 无法人、不领取合伙企业执照、自然人共同事业、适用民法典合伙合同章 | 个人合伙合同 | **负触发** → `个人合伙合同·审查`。不得把第九百七十三条个人连带或劳务可出资写成有限合伙 LP 默认 |
| 主文是公司股权、否决权、随售／拖售、章程，有限合伙只是口语 | 股东协议 | **负触发** → `公司股东协议·审查` |
| 不承担经营风险、到期收回本金并收取固定收益，或 GP 无条件回购＋固定利率 | 民间／企业间借款 | **负触发** → `不参与经营不承担亏损到期固定本息→自然人之间借款` 或 `或企业间借款`。民间借贷规定只作切开，不在本任务做利率精算 |
| 只拿固定报酬、不认缴、无合伙人身份 | 劳务／劳动合同 | **负触发** → `只拿固定报酬不分担亏损无合伙人决策权→个人劳务（雇佣）` 或 `人格从属＋工资社保→劳动合同` |

普通合伙、个人合伙、股东协议、借贷误入是硬闸：一旦核心给付滑入上述结构，立即停笔转出。不得删掉执照条款或保本回购后继续当有限合伙审。

### 1.3 加载协议

只打开本目录 `基本面.md` 与 `框架.md`。禁止读 `types/` 或其他场景原子目录。

### 1.4 违法或监管结构停笔（本类型，不是施工挂靠）

出现下列任一结构，只出告知，不改写成可履行文本：

- 国有独资公司、国有企业、上市公司、公益性事业单位或社会团体担任或拟任普通合伙人，要求改成子公司代持、自然人挂名以规避第三条；
- 有限合伙人通过共管公章、共同签批、投决一票拍板实际执行事务，要求写成“对外仍是有限责任、对内共同管理且可履行”；
- 向不特定对象公开募集资金，要求改成可履行的规避备案结构；
- 两套协议：报登一份、对内一份责任档或回购安排互相矛盾；
- 倒签签署日或缴资日以改变责任档、入伙债务或执行追加时点。

用户坚持“改到能签／能瞒过登记／能让债权人追不到 GP／能让越位 LP 不被穿透”：整体停止。合规改道（改任有限合伙人、依法转普通合伙、真实借款改走借款合同、依法私募备案）只点名，不在本任务起草规避方案。

## 硬闸 A　有限合伙企业 ≠ 普通合伙企业 ≠ 个人合伙

本闸改变能否留在本任务。

1. **组织形态**  
   第二条：合伙企业包括普通合伙企业与有限合伙企业。有限合伙企业由普通合伙人和有限合伙人组成。第六十一条：二人以上五十人以下（法律另有规定除外），且至少应当有一个普通合伙人。名称：现行《企业名称登记管理规定实施办法》第十二条要求合伙企业标明“（有限合伙）”字样。2019 年登记办法已失效，不得引用。  
   **修改句**：`各方确认：本协议项下企业为依照《中华人民共和国合伙企业法》设立的有限合伙企业，名称应当标明“（有限合伙）”。本协议不是普通合伙企业合伙协议，也不是不领取合伙企业营业执照的个人合伙合同。任何一方不得以本协议主张全体合伙人均承担无限连带责任，或主张各方仅成立民法典项下个人合伙。如后续改为普通合伙企业或解散后改个人合伙，应另行签署相应协议并办理登记或清算；本协议不构成该等文件。`

2. **人数与二元结构**  
   缺普通合伙人或缺有限合伙人：不能当本类型放行。超过五十人且无法定例外：字段停止。  
   **修改句**：`本企业合伙人共计【待填】名，其中普通合伙人【待填】名、有限合伙人【待填】名。合伙人总数须在二人以上五十人以下（法律另有规定除外），且至少有一名普通合伙人。任何变更导致本企业仅剩有限合伙人的，本企业应当解散；仅剩普通合伙人的，应当转为普通合伙企业并改签相应协议。`

3. **最强反方**  
   未办执照不当然使当事人内部约定无效；标题写“有限合伙”但全体无限连带、无分档的，相对方可主张普通合伙或个人合伙。签前按核心给付分流，不两套都审。

## 硬闸 B　GP 无限连带／LP 以认缴为限

1. **法定分档**  
   第二条第三款：普通合伙人对合伙企业债务承担无限连带责任；有限合伙人以其**认缴的出资额**为限对合伙企业债务承担责任。第九十二条：合伙企业不能清偿到期债务的，债权人可以依法申请破产清算，也可以要求普通合伙人清偿；被宣告破产的，普通合伙人仍承担无限连带责任。执行变更追加规定第十四条：可追加普通合伙人；对未按期足额缴纳出资的有限合伙人，可在未足额缴纳范围内追加。  
   **修改句**：`普通合伙人对本企业债务承担无限连带责任。有限合伙人以其认缴的出资额为限对本企业债务承担责任。删除“普通合伙人仅以其出资额为限承担责任”“债权人不得向普通合伙人追索”及“有限合伙人对本企业全部债务与普通合伙人连带”的约定。本协议关于内部分担的约定仅约束合伙人之间的追偿，不得对抗企业债权人。`

2. **认缴不是“责任为零”**  
   第六十五条：有限合伙人应当按期足额缴纳；未按期足额缴纳的，应当补缴，并对其他合伙人承担违约责任。第六十六条：登记事项应当载明有限合伙人的姓名或名称及认缴出资数额。  
   **修改句**：`有限合伙人【名称】认缴出资人民币【待填】元，缴付期限为【待填】，缴入本企业账户【待填】。未按期足额缴纳的，应当补缴，并按逾期金额每日【待填】向其他合伙人承担违约责任；逾期超过【待填】日，普通合伙人可按本协议除名或削减其财产份额。有限合伙人未缴出资范围内，不因本协议内部约定而当然免于被债权人主张。`

3. **禁止对调责任档**  
   把 GP 改成有限责任，或把 LP 改成“自愿对外无限”却仍写有限合伙：红线。真实要全体无限连带，应转 `普通合伙企业合同·审查`。  
   **修改句**：`删除甲方“自愿对有限合伙人债务承担有限责任”及丙方“自愿放弃有限责任、与普通合伙人同等连带”且仍使用“（有限合伙）”名称的条款。责任档必须与登记身份一致。如各方要求全体无限连带，应改设普通合伙企业并停止本任务。`

4. **最强反方**  
   有限责任保护以身份真实且未越位为前提；未出资的有限合伙人不能主张“认缴为零所以无责”。内部追偿约定约束签署方。签前不得写成“写了有限责任债权人就追不到 GP”。

核验失败：责任分档的法律结论字段停止；“不得写 GP 只以出资为限”的修改句草稿继续。

## 硬闸 C　LP 不得执行合伙事务

1. **执行归属**  
   第六十七条：有限合伙企业由普通合伙人执行合伙事务；执行事务合伙人可以要求在协议中确定报酬及提取方式。第六十八条第一款：有限合伙人不执行合伙事务，不得对外代表有限合伙企业。第三十七条：对执行事务及对外代表权利的限制，不得对抗善意第三人。  
   **修改句**：`本企业合伙事务由普通合伙人【名称】执行，委派代表为【待填】。执行事务报酬为【待填】，提取方式【待填】。有限合伙人不执行合伙事务，不得对外代表本企业，不得保管或单独使用本企业公章、法定名称印章和银行预留印鉴，不得单独签署投资、借款、担保或处分主要财产的文件。`

2. **安全港（必须列举，禁止只写“依法监督”）**  
   第六十八条第二款八项不视为执行合伙事务。修改句应落到文本，不得缩成“LP 可以适当参与管理”。  
   **修改句**：`有限合伙人的下列行为不视为执行合伙事务：（一）参与决定普通合伙人入伙、退伙；（二）对本企业经营管理工作提出建议；（三）参与选择承办本企业审计业务的会计师事务所；（四）获取经审计的财务会计报告；（五）对涉及自身利益的情况，查阅本企业财务会计账簿等财务资料；（六）在本企业中的利益受到侵害时，向有责任的合伙人主张权利或者提起诉讼；（七）执行事务合伙人怠于行使权利时，督促其行使权利或者为了本企业的利益以自己的名义提起诉讼；（八）依法为本企业提供担保。超出本条的签批、保管印鉴、对外缔约或对具体项目作出具有执行效力的决定，视为执行合伙事务，应按本协议纠正并承担相应责任。`

3. **越位与表见普通合伙人**  
   第七十六条：第三人有理由相信有限合伙人为普通合伙人并与其交易的，该有限合伙人对该笔交易承担与普通合伙人同样的责任；未经授权以企业名义交易造成损失的，应当赔偿。第九十八条：不具有事务执行权的合伙人擅自执行造成损失的，依法赔偿。  
   **修改句**：`删除“全体合伙人共同管理”“有限合伙人与普通合伙人共同签署公章”“有限合伙人对每笔投资享有一票决定权”等表述。投资决策委员会或咨询委员会的职责以建议、审议或第六十八条所列事项为限，不得写成有限合伙人对外代表本企业。任何有限合伙人对外表明自己是普通合伙人或执行事务合伙人的，本企业对内可向其追偿；对该笔交易，该有限合伙人可能承担与普通合伙人同样的责任。本条不预先认定某笔交易已经构成表见。`

4. **最强反方**  
   安全港内的查阅、建议、更换 GP 表决不当然等于执行事务。签前不得以“我们只是投决委员”放行共管公章。也不得写成“越位条款当然无效所以 LP 无风险”。

## 硬闸 D　出资：LP 不得劳务；认缴与实缴分开

1. **LP 禁止劳务出资**  
   第六十四条（已核验）：有限合伙人可以用货币、实物、知识产权、土地使用权或者其他财产权利作价出资；**有限合伙人不得以劳务出资**。普通合伙人可以劳务出资的口径来自知识稿与第二章准用，本次检索未回传第十六条全文：写入 `L#` 前须再核；未核验则只写“普通合伙人劳务出资须再核并办理登记”，不得把个人合伙劳务规则直接套用。  
   **修改句**：`有限合伙人【名称】不得以劳务出资。其认缴出资为【货币／实物／知识产权／土地使用权／其他财产权利】，作价人民币【待填】元，缴付期限【待填】。删除有限合伙人以“管理劳务／投研劳务／客户资源劳务”折算认缴额的条款。普通合伙人如以劳务出资，应单独列明作价人民币【待填】元、对应财产份额及评估或协商依据，并办理登记；该字段在第十六条未核验前保持待核，不得记载为已实缴货币。`

2. **认缴是责任上限，实缴是分配与违约基数**  
   框架要求区分认缴与实缴。未给数字用 `【待填】`。  
   **修改句**：`各合伙人认缴出资、实缴出资、缴付期限和财产份额见附件《出资确认书》。利润分配在本协议另有约定前，以实缴出资为计算基数之一；有限合伙人的对外责任上限为其认缴出资额，不因其尚未实缴而改为零，也不因实缴超过认缴而当然扩大。`

3. **财产独立**  
   第二十条：出资、以企业名义取得的收益和依法取得的其他财产，均为合伙企业财产。存续期间不得请求分割。  
   **修改句**：`本企业财产（含出资、以本企业名义取得的收益和其他依法取得的财产）与各合伙人自有财产分开记账。货币收支使用本企业账户【待填】。企业解散并清算完结前，任何一方不得请求分割企业财产，不得将企业资金转入个人账户用于与本企业无关的开支。`

4. **最强反方**  
   劳务折价写入报登文件可能被登记机关拒绝，不等于内部协议“自动改成货币出资”。签前必须删除 LP 劳务折资，不得写成“先登记再补钱就算劳务出资有效”。

## 硬闸 E　损益、全部亏损禁令和名实借贷

1. **全部利润可另约，全部亏损不可**  
   第六十九条（已核验）：有限合伙企业不得将全部利润分配给部分合伙人；**但是，合伙协议另有约定的除外**。第八十九条将剩余财产分配回链第三十三条第一款；第三十三条全文本次未回传，知识稿与第六十条准用关系支持：不得约定由部分合伙人承担全部亏损。法律结论写入 `L#` 前须再核第三十三条；未核验则亏损禁令字段停止，修改句仍删除“全部亏损由某一方承担”。  
   **修改句**：`本企业可以约定将全部利润分配给部分合伙人。现约定分配顺序为：【待填：还本／门槛收益／超额分成】。删除“由普通合伙人（或某一有限合伙人）承担全部亏损”的条款。亏损分担比例为【待填】，该比例只约束合伙人内部；有限合伙人对外仍以其认缴出资额为限。`

2. **固定收益＋无条件回购**  
   知识稿红旗＋实务争点：LP 不承担经营风险、到期由 GP 无条件回购并支付固定收益，可能被认定为借贷，有限合伙人地位和税收安排可能落空。1990 年联营解答已失效，不得当现行无效专条。走合同编通则解释第十五条名实认定。用户仍主张合伙：删除保本；用户承认不担风险：转借款。  
   **修改句**：`删除“无论盈亏，普通合伙人应于【待填】日前无条件回购有限合伙人财产份额并按年【待填】% 支付固定收益”的约定。有限合伙人按本协议参与分配并按约定比例分担亏损，对外责任以其认缴出资额为限。若该方不承担任何经营风险且只收取固定回报，各方应改签借款合同，本任务停止按有限合伙审查。禁止改写成可履行的保本份额或刚兑条款。`

3. **管理费与关联交易**  
   第六十七条允许约定执行报酬。知识稿要求锁定管理人与 GP 是否同一主体。关联投资未披露：必须改。  
   **修改句**：`执行事务合伙人按【认缴／实缴／项目】规模的【待填】% 按【年／季】提取管理费，列入企业费用，不替代其亏损内部份额，也不将其身份改成雇员。普通合伙人拟将企业资金投向其关联方的，应事先书面告知全体有限合伙人并按本协议第【待填】条表决；未履行告知或表决的，不得实施。`

4. **最强反方**  
   第六十九条允许全部利润归部分合伙人，不等于可以取消亏损分担或做成固定本息。门槛收益若以可分配利润为限，仍可能是合伙；若无论盈亏必须兑付，签前按借贷切开。

## 硬闸 F　身份转换、GP 适格与组织存续

1. **转换**  
   第八十二条（已核验）：除合伙协议另有约定外，普通合伙人与有限合伙人相互转变，应当经全体合伙人一致同意。第八十四条（已核验）：普通合伙人转变为有限合伙人的，对其作为普通合伙人期间发生的债务承担无限连带责任。第八十三条本次未回传全文，实务与知识稿载明：有限合伙人转变为普通合伙人的，对其作为有限合伙人期间发生的债务承担无限连带责任。未核验则该条号字段停止，修改句仍作风险告知草稿。  
   **修改句**：`除本协议另有约定外，普通合伙人转变为有限合伙人或有限合伙人转变为普通合伙人，应当经全体合伙人一致同意，并在【待填】日内办理变更登记。普通合伙人转变为有限合伙人的，对其作为普通合伙人期间本企业发生的债务承担无限连带责任。有限合伙人转变为普通合伙人的，应知悉其可能对转变前本企业已发生的债务承担无限连带责任（第八十三条未核验前，本句为告知草稿，不写成已核验结论）。未经一致同意并登记的，不得对外主张身份已经转换。`

2. **仅剩一类合伙人**  
   第七十五条：仅剩有限合伙人的，应当解散；仅剩普通合伙人的，转为普通合伙企业。  
   **修改句**：`本企业仅剩有限合伙人的，应当解散并按本协议清算条款办理，不得继续以有限合伙企业名义经营。本企业仅剩普通合伙人的，应当转为普通合伙企业，另行签署普通合伙企业协议并办理变更登记；在完成转换前，不得继续使用“（有限合伙）”名称对外缔约。`

3. **GP 主体禁入**  
   第三条（已核验）：国有独资公司、国有企业、上市公司以及公益性的事业单位、社会团体不得成为普通合伙人。  
   **修改句**：`各方确认：普通合伙人【名称】不属于国有独资公司、国有企业、上市公司或公益性事业单位、社会团体。如普通合伙人嗣后变成上述主体，应在【待填】日内转为有限合伙人或退伙，并按本协议补选普通合伙人；无法补选的，按仅剩有限合伙人解散。禁止以代持、挂名或协议控制把上述主体写成可履行的隐名普通合伙人。`

4. **最强反方**  
   双层公司 GP 可以把无限责任留在公司层面，不消灭该公司作为普通合伙人的无限连带，也不是自然人股东当然免责的保证。签前可点名该结构，不得承诺“设了公司 GP 个人就追不到”。

## 节点 2　主体、授权、人数

1. 建主体表：各合伙人签约名、证件或统一社会信用代码、GP／LP 档、是否第三条禁入主体、执行事务合伙人及委派代表、管理人（如有）、授权签字人。名称不一致不自动合并。遗漏任一拟合伙人：协议对其不当然约束，标必须改。
2. 自然人普通合伙人须具备完全民事行为能力。限制或无民事行为能力人不得任普通合伙人；第四十八条第二款方向：经一致同意可依法转为有限合伙人，否则退伙——本任务不宣告已经转换。
3. 公职人员担任合伙人：只告知公务员不得违规从事营利性活动，不改成亲属代持。用户坚持规避：整体停止。
4. 口头“集团已内部批准”不得写成已授权。国资或上市公司内部决议未附：该签署能力字段停止。

不足：字段停止，列出待补材料，不补主体。

## 节点 3　份额转让、入伙退伙、管理费

1. 有限合伙人对外转让：知识稿为提前三十日通知（协议另有约定除外）。第七十三条全文未回传则条号字段停止；修改句仍要求书面通知、变更协议与登记，不得套用民法典第九百七十四条“须其他合伙人一致同意”作为本类型 LP 默认（那是个人合伙规则）。
2. 普通合伙人对外转让财产份额：准用普通合伙规则，通常须其他合伙人一致同意。不得把 LP 的通知制直接套到 GP。
3. 新合伙人入伙：第四十三条，除另有约定外应当全体一致并订立书面入伙协议；原合伙人应如实告知经营和财务状况。新普通合伙人对入伙前债务的无限连带（第四十四条）须告知，不得写成“入伙协议免责即可对抗债权人”。
4. 有限合伙人退伙后，知识稿：以其退伙时从企业取回的财产为限承担责任。未核验第七十九条／第八十一条则字段停止，修改句仍禁止写成“退伙后对退伙前债务零责任”。
5. 禁止编造认缴额、管理费率、门槛收益率。

## 节点 4　程序与生效

把设立登记、名称核准、变更登记、（如属募集）基金备案写成**义务和期限**，不写成已经完成。

| 文本写法 | 本任务动作 |
| --- | --- |
| “本协议签字即视为有限合伙企业已经成立／已取得执照” | 拆成协议成立 vs 执照签发之日为企业成立日 |
| “网签／备案后自动生效”但无谁负责、几日内、未完成的后果 | 补义务主体、期限、未完成时的解除或中止 |
| 国资／上市公司决议未附 | 字段停止；修改句要求作为附件且未获批准不生效 |
| 以投资为目的并向特定合格投资者募集，但只字不提备案 | 标程序红旗；不在本任务做整案基金合规，也不编造备案时限 |
| 用户要求倒签、补假缴资或假批准 | 整体停止 |

第六十三条应载事项（已核验）沉默时必须改：GP／LP 姓名或名称与住所；执行事务合伙人条件与选择程序；权限与违约处理；除名与更换；有限合伙人入伙退伙条件、程序及责任；相互转变程序。

## 节点 5　格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 5.1 格式条款

管理人、园区或基金文件重复使用的 LPA，仍可能构成格式条款。审查单方解释权、GP 单方决定争议结果、永远不得退伙、LP 共管却仍写有限责任、管辖是否有显著提示。

### 5.2 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的是否导致民事行为无效、是否只规制登记或行政管理。禁止用已失效“效力性／管理性”口诀。第三条主体禁入、第六十四条劳务禁止、第六十八条不执行事务：签前必须改文本，不得输出规避结构，也不轻易写“整份协议当然无效”。

## 节点 6　违约、解散、争议解决

1. 逾期出资、LP 越权代表、GP 擅自关联交易、违反竞业必须分别有可执行后果。只有“依法承担违约责任”视为必须改。
2. 除名：第四十九条书面通知、接到通知之日生效、异议可在三十日内起诉。修改句写条件、通知和登记，不在本任务宣告某人已经除名。
3. 违约金避免“不得调整”或“按认缴总额百分之三十必得”。
4. 争议解决：已有仲裁条款，不得改成“应向某法院起诉”并假装已选定诉讼；或裁或诉、机构不明：改成单一机构或单一法院连结点；禁止“由普通合伙人单方决定争议处理结果”。
5. 微信已读不写成已经送达，除非合同把该渠道定为送达。

## 节点 7　基金、侧函、税负与跨境

1. 经营目的为募集并投资：标私募监管与协会备案红旗，列 `G#`，不编写可履行的公开募集结构，也不把本任务做成基金合规整审。
2. 侧函与正文冲突：并列，不选对用户有利的一版；最惠国条款如存在，须回链对其他有限合伙人的影响。
3. 税负：“先分后税”不得写成已核验、已落地的节税意见。财政返还、核定征收字段停止。
4. 涉外主体或境外缴资：准据法不明则停止外国法结论。本类型只审中国大陆有限合伙企业协议和人民币登记安排。

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

对照已加载框架级文件和本方法硬闸，按六步逐段出句。

| 步 | 本类型必须盯的点 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题含“有限合伙”；GP／LP 分档点名；人数 2–50 且至少一名 GP；第三条主体；鉴于不把执照或缴资写成已完成 | 主体与名称修改句 |
| 交易条款 | 认缴／实缴／期限；LP 不得劳务；GP 执行、LP 不执行、安全港八项；责任分档；分配瀑布；禁止全部亏损归一方；禁止固定收益无条件回购 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 表见普通合伙人；入伙告知；LP 转让通知与 GP 转让同意；身份转换；仅剩一类合伙人；除名通知；违约与争议 | 可执行后果句 |
| 尾部 | 签署权限；附件：出资确认书、委派书、侧函清单；协议成立 vs 执照签发；登记义务 | 生效与附件修改句 |
| 语言 | 认缴 ≠ 实缴；无限连带 ≠ 有限责任；不执行 ≠ 无权监督；共同管理／共同签章为高风险词 | 替换空词的句子 |
| 常见问题 | LP 越位、GP 改有限责任、劳务折资、保本回购、隐名 GP、仅剩 LP 不解散、税负承诺 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（GP 改有限责任、LP 共同执行可履行、LP 劳务出资、固定收益无条件回购、第三条主体任 GP、隐名 GP、已成争仍当签前）；
- `必须改`：可谈但签署前要落句（认缴表、安全港列举、责任分档告知、转换与仅剩一类、第六十三条应载事项、设立登记义务）；
- `可接受可优化`：仍要给句子，不得只标绿（管理费细化、侧函清单、竞业、咨询委员会）。

用户不可接受事项优先写成红线。普通合伙人生存级财产可能被无限追索且用户拒绝升级：停止“可以签署”建议。
