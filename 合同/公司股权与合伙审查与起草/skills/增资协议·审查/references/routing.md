# 边界与路由

本技能只审查 **股权投资相关合同 / 增资协议** 的待签、已存续公司本轮投资人认购新增注册资本、资金进入公司、并锁定估值／交割条件／股东协议接口的文本。中文展示名是「审查增资协议（股权投资相关合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开下列 method：`出资合同·审查`、`房地产项目股权取得类合同·审查`、`PE股权转让·审查`、`股权代持合同·审查`、`投资意向书·审查`、`PE股东协议·审查`、`对赌协议（盈利预测补偿协议）·审查`、`增资合同·审查`。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 公司尚未成立；发起人认缴；设立失败责任为主给付 | `出资合同·审查`；不打开其 method |
| 买项目公司股权主要为控制地块或开发项目 | `房地产项目股权取得类合同·审查` |
| 价款进原股东；注册资本不因本约增加；标的是已发行股权 | `PE股权转让·审查`；不打开其 method |
| 股权代持、隐名持股本约 | `股权代持合同·审查` |
| 只有条款清单／投资意向书，本约尚未形成 | `投资意向书·审查` |
| 主文是投后治理、否决权、随售、拖售、董事会席位整案 | `PE股东协议·审查` |
| 主文件是业绩承诺、盈利预测补偿或独立估值调整本约；增资只是背景 | `对赌协议（盈利预测补偿协议）·审查`；不打开其 method |
| 无估值、无股东协议接口、无投资人保护清单的公司内部增资 | `增资合同·审查`；不打开其 method |
| 公司侧存量股权买卖且无投资一揽子 | `公司股权转让·审查`（只分流，不打开 method） |
| 固定收益、到期还本、不参与经营 | 明股实债告知；整体停止或转借贷专项，不改成可履行股权 |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式（出稿后自审） |
| 已签未争、只问缴资日或递件日 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `已出现催告解除函索赔立案开庭仲裁` 或对应专项领域 |
| 决议效力之诉、优先认缴侵权之诉、回购款诉讼已立案 | 公司／投资争议专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

增资正文里夹带一小段老股转让：专章交接 `PE股权转让·审查`；新增资本、公司收款和本轮估值条款可继续审。夹带可单独评改的业绩补偿专章：专章交接 `对赌协议（盈利预测补偿协议）·审查`；本轮认购与交割包可继续审。用户坚持本技能把对赌、转股、出资认缴、Term Sheet 或公司侧增资整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
