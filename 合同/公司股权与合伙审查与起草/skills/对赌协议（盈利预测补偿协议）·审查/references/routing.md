# 边界与路由

本技能只审查 **公司相关合同 / 对赌协议（盈利预测补偿协议）**。主线是业绩承诺、估值调整或盈利预测补偿。不是普通存量买卖，不是回购本约整审，也不是投后治理整审。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 价款进原股东、存量股权让与、无业绩承诺／估值调整结构 | `公司股权转让·审查` |
| 已发行股权按条件购回作为主文件，补偿只是并列一句 | `股权回购协议·审查` |
| 价款进公司换新增注册资本，补偿只是背景 | `增资合同·审查` |
| 主文件是股东协议：投后治理、否决权、随售／拖售 | `公司股东协议·审查` |
| 主文件是股权代持 | `股权代持协议·审查` |
| 国有进场、挂牌转让为主文件 | `国有股权转让合同（协议转让）·审查` |
| 投资侧增资、优先清算、反稀释一揽子 | `增资协议·审查` 或 `PE股东协议·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式 |
| 已签未争、问审计日／付款日／递件留痕 | 本套导航的履约步骤 |
| 补偿款／回购款／减资／审计争议已催告、立案、开庭或仲裁 | 公司争议领域；不填签前十节 |
| 公司被写成无条件现金补偿或回购且无需利润或减资 | 留本任务只出红线；用户坚持改成可履行则整体停止 |
| 拟上市抽屉对赌、对监管隐瞒对内有效 | 留本任务只出告知；用户坚持改成可隐瞒结构则整体停止 |
| 国资未审批或外资负面清单未核 | 字段停止；不写场外可履行 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

专业版未收录的投资侧场景不会作为本原子的实体审查对象。若用户拿这些文本来找本技能：输出 `unavailable` 或负触发路由，不得用本类型硬套。

本技能不得转去加载转让、回购本约、股东协议或增资双文件完成本类型审查，也不得把优先购买三十日交割包、减资公告日程或治理清单写成对赌默认主路径。
