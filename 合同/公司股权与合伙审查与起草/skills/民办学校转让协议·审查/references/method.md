# 审查方法（锁定 公司相关合同 / 民办学校转让协议）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型，禁止打开股权转让、资产转让或社团负责人双文件“对照一下”。

本文件是**已持证民办学校举办者变更**的签前判断节点，不是栏目说明书，也不是股权过户清单或资产买卖清单。禁止把优先购买三十日交割包、货交承运人风险或所有权保留写入本类型默认结论。

每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、必然核准或换证、对方必然接受或唯一必得金额。

`search_law` 返回已失效《合同法》及其解释、2004 年《民办教育促进法实施条例》、2013 年《民办教育促进法》第五十一条合理回报专条、失效教育行政处罚办法时记为噪声，不得写入 `L#`。2018 年文本第五十四条若只命中 2002 年同文，可同向吸收“举办者提出、财务清算、理事会或者董事会同意、报审批机关核准”，并标注运行时再核 2018 条号；2016／2018 修改决定未改该条文字。民办非企业单位登记条例与社会组织登记条例交替未核验前，不得把登记机关条号写成 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突。

示范文本只参考结构。命中股权转让或资产买卖范本：只作负向切开，不得粘贴充作本约。

### 双文件使用（标题与文件名不完全对应时不拒跑）

同目录两份知识文件按标题语义使用，不回改正文，不因文件名拒跑：

- 含“首部 / 交易条款 / 配套 / 尾部 / 语言”的当框架级条款清单，供节点 8 出句；
- 宏观的类型切开、审批、营利／非营利、许可证由本方法节点承担。知识稿把“未经核准则协议当然无效”一笔写死的，**降级**：变更行为未经核准不发生效力，报批义务条款仍可独立主张，不写成整份协议自始无效。知识稿把“由学校向老举办者支付补偿”写成合规路径的，**降级为红线**：变更协议不得涉及学校法人财产。知识稿把“取得合理回报”写成核心权益的，**降级**：2016 年已删去合理回报专条；非营利不得取得办学收益；现有学校仅可按实施条例第十二条协议“依法享有的合法权益”项下变更收益。知识稿写“一律不受公司法约束”的，**降级**：先分营利／非营利；营利性结余可按公司法等处理，但仍须办许可证与举办者变更。
- 文件不可用（空、代码块、与本类型明显无关）：记 `G#`，用本方法节点继续，不得改去加载股权或资产双文件，不得编造补偿额或核准日。

## 节点 1　类型识别与负触发

### 1.1 本类型正像

同时满足才继续：

- 标的学校是面向社会举办的民办学校或其他教育机构，材料表明已有或依法应有**办学许可证**；
- 核心给付是**原举办者退出、新举办者加入**，并交接办学控制／管理权；
- 交易围绕举办者身份、办学许可证记载和审批核准，而不是单纯的公司股权过户或校舍设备买卖。

标题写成“民办学校转让协议”“举办者变更协议”“举办者权益转让协议”只是线索。名实不符按核心给付归类，标题冲突写入 `C#`。标题用《股权转让协议》或《资产转让协议》但正文是举办者变更的，留本任务改标题，不因此改走股权或资产原子。

### 1.2 必须切开（禁止两套知识）

| 信号 | 归入 | 本技能动作 |
| --- | --- | --- |
| 无办学许可证；标的是普通公司股权；优先购买、名册、市场主体登记是主路径 | 股权转让合同 | **负触发** → `公司股权转让·审查`。不得当举办者变更审，不得复制其交割主路径 |
| 主文是取得公司控制权的股权收购，且无办学许可／举办者变更叠加 | 股权收购合同 | **负触发** → `股权收购合同（含控制权转移）·审查` |
| 土地、校舍、设备当商品出让，不改举办者、不换许可证记载 | 资产转让／资产收购 | **负触发** → `非核心资产转让·审查` 或 `资产收购合同·审查` |
| 国有股权或国有资产须评估挂牌 | 国有进场类型 | **负触发** → `国有股权转让合同（协议转让）·审查` 或 `国有资产转让合同（协议转让）·审查` |
| 社团换法定代表人／理事长，不是学校举办者 | 社会团体负责人变更合同 | **负触发** → `社会团体负责人变更合同·审查` |
| 营利性学校的公司股权让与**同时**导致举办者或法人举办者的控股股东／实控人变更 | 本类型叠加 | **留本任务**。股权程序只点名，不展开 `公司股权转让·审查` 主路径；举办者／实控人变更仍走审批或备案公示 |

股权、资产误入是硬闸：一旦核心给付滑入上述无许可证或纯资产结构，立即停笔转出。不得删掉股权对价或资产过户条款后继续当本类型审。

### 1.3 加载协议

只打开本目录 `基本面.md` 与 `框架.md`。禁止读 `types/` 或其他场景原子目录。

### 1.4 违法结构停笔

出现下列任一结构，只出告知，不改写成可履行文本：

- “本合同自签字盖章之日起生效，甲方应于当日移交办学许可证、印章和全部管理权，无需审批机关核准”；
- 按学校净资产或评估溢价买卖非营利学校，或约定“转让学校全部资产／转让出资额”；
- 由学校向原举办者划付转让款、补偿款或合理回报，资金来自学费、办学结余或学校账户；
- 买卖、出租、出借、抵押办学许可证；
- 实施义务教育的学校改登记为营利性，或新举办者计划把义务教育做成营利；
- 倒签合同或补假批复、假理事会决议、假清算报告。

用户坚持“改到能签／先交章再报批／学校先把钱打出来”：整体停止。合规改道（变更收益由继任举办者自有资金支付、核准后交割、理事会三分之二、清算附件）只点名并出修改句，不在本任务起草规避方案。

## 硬闸 A　举办者变更 ≠ 普通股权转让 ≠ 普通资产转让

本闸改变能否留在本任务。

1. **有没有举办者变更结构**  
   文本须能指出：哪一所已持证民办学校，谁是登记在册的举办者，谁拟变更为新举办者。只有“甲方将某公司股权转让给乙方”、学校只是该公司的资产或业务、不见许可证和审批 → `公司股权转让·审查`。只有“甲方将校舍及设备出售给乙方”、举办者和许可证不变 → `非核心资产转让·审查`／`资产收购合同·审查`。  
   **修改句（留在本任务时）**：`各方确认：本协议项下交易是【学校全名】的举办者由【原举办者】变更为【新举办者】，标的是举办者身份及依法可享有的举办者权益，不是【学校全名】法人财产的买卖，也不是无办学许可叠加的普通公司股权转让。学校对举办者投入的资产、国有资产、受赠财产和办学积累享有法人财产权。`

2. **标题禁用股权／资产买卖**  
   标题写成《股权转让协议》《资产转让协议》：必须改。  
   **修改句**：`将标题改为《【学校全名】举办者变更协议》。删除正文中的“股权”“股东”“股利”“分红”“买卖学校资产”等表述，改用“举办者”“举办者权益”“变更收益”。`

3. **最强反方**  
   标题写“转让”但附件是股权转让合同，相对方可主张按公司法股权转让履行，或主张在卖学校资产。签前按核心给付分流，不两套都审。

## 硬闸 B　举办者变更须审批

本闸是本类型生存级闸。改变能不能把交章、交证、主款写成立即履行。

1. **法定程序四件套**  
   - 举办者提出变更；  
   - 财务清算（通常委托双方认可的审计机构，基准日写清）；  
   - 理事会、董事会或其他决策机构讨论变更举办者，经组成人员三分之二以上同意；  
   - 报审批机关核准。  
   依据：民促法第五十四条（2018 文本运行时再核；2002 年同文可同向吸收）；2021 年实施条例第十二条、第二十六条；民促法第六十二条擅自改变举办者的行政处罚。  
   **修改句**：`本次举办者变更由原举办者提出。双方应在签署后【待填】个工作日内共同委托【待填】对学校进行财务清算，清算报告作为附件。学校理事会／董事会应就变更举办者作出决议，须经组成人员三分之二以上同意。双方应在决议作出后【待填】个工作日内，共同向【审批机关全称】提交变更申请。本协议自各方签署之日成立；举办者变更自【审批机关全称】书面核准之日起发生效力。报批义务条款、保密条款和因报批产生的责任条款，自签署之日起有效。`

2. **成立 ≠ 变更生效 ≠ 报批义务**  
   民法典第五百零二条：依法成立的合同自成立时生效，但法律另有规定或当事人另有约定的除外；应当办理批准等手续的，依照其规定；未办理批准影响合同生效的，不影响报批义务条款。合同编通则解释第十二条：批准前起诉请求履行主要义务，经释明拒不变更的，应驳回；机关决定不予批准，对方请求赔偿的，一般不予支持，但迟延报批可归责的除外。  
   **禁止的写法**：“本合同自签字盖章之日起生效并立即履行。”“双方同意视为审批机关已经批准。”“先移交许可证和印章，后补办手续。”  
   **修改句**：`在【审批机关全称】出具同意变更举办者的书面批复前，任何一方不得请求对方移交办学许可证、印章、银行账户控制权或支付除立约定金／共管保证金以外的主要款项，也不得对外以新举办者名义办学。任何一方不得约定“双方同意视为已批准”。`

3. **付款与交割挂钩核准**  
   严禁签约即付全款或交接即付全款。  
   **修改句**：`款项支付与交割节点：（1）签署本协议后【待填】日内支付立约定金人民币【待填】元，定金不超过约定变更收益的百分之二十；（2）双方备齐材料并正式向审批机关递交申请后支付【待填】%；（3）审批机关出具书面核准文件后支付【待填】%；（4）办结办学许可证变更、法人登记变更，并完成印章、证照、账册书面交接后支付尾款。审批未获核准且不可归责于任何一方的，任何一方有权解除本协议，原举办者应在【待填】日内全额退还已付款项（包括定金）。`

4. **法人举办者的控股股东／实控人**  
   实施条例第十二条第三款：举办者为法人的，其控股股东和实际控制人应当符合举办条件；变更应当报主管部门备案并公示。文本只改公司股权、不提备案公示：必须改，不得写成“改完股权就等于已变更举办者”。

5. **最强反方**  
   相对人可能主张：合同自由，签字了就该交章付钱；或反过来主张未核准则整份协议自始无效、定金不必退。签前两极都不写。只写：变更未经核准不发生效力；报批义务可独立主张；不可归责的不予批准应退款解除。

核验失败：审批效力的法律结论字段停止，事实摘录和“核准前不得交章交证、主款挂钩批复”的修改句草稿继续。

## 硬闸 C　先分营利／非营利

本闸改变价款能不能放行、能不能写成买卖学校。

1. **分类先于价款**  
   民促法第十九条：举办者可选择非营利或营利；**不得设立实施义务教育的营利性民办学校**；非营利举办者不得取得办学收益，办学结余全部用于办学；营利性举办者可以取得办学收益，办学结余依照公司法等有关法律、行政法规的规定处理。未见分类或是否义务教育：分类字段停止，不写可签署。  
   **修改句**：`各方确认：【学校全名】登记为【非营利性／营利性】民办学校，办学层次为【待填】，【实施／不实施】义务教育。任何一方不得通过本协议将实施义务教育的学校变更为营利性民办学校。`

2. **非营利：不得买卖法人财产，不得分配结余**  
   民促法第三十六条：学校对举办者投入的资产、国有资产、受赠财产以及办学积累享有法人财产权。实施条例第十条：存续期间举办者不得抽逃出资，不得挪用办学经费。实施条例第十二条：变更协议不得涉及学校的法人财产，不得影响学校发展，不得损害师生权益；现有学校可以根据依法享有的合法权益与继任举办者协议约定变更收益。  
   **禁止的写法**：价款＝学校净资产或评估值；“转让学校全部资产”；由学校账户向原举办者支付；把学费、办学结余当对价来源。知识稿建议的“新举办者先捐给学校、再由学校支付补偿”：**红线**，不写成合规路径。  
   **修改句**：`如学校为非营利性，新举办者向原举办者支付的款项仅为双方根据原举办者依法享有的合法权益约定的变更收益，计算依据为【原始出资／章程记载的其他合法权益／【待填】】，金额人民币【待填】元，资金来源为新举办者自有合法资金。该等款项不得表述为学校净资产对价或股权对价，不得由学校支付，不得从学费、办学结余或学校账户划付。学校法人财产不因本协议发生权属转移。`

3. **营利性：可谈收益，仍须办证**  
   营利性学校的办学结余可按公司法等处理，价款可以谈，但仍须许可证变更和举办者／实控人审批或备案。不得因为“是公司”就改走 `公司股权转让·审查` 并删掉审批。义务教育写成转营利：红线停笔。

4. **合理回报旧义**  
   2016 年修改决定删去原第五十一条。框架中“从办学结余中取得合理回报”不得写成非营利学校现行默认权利。2017-09-01 前已设学校的终止补偿／奖励，只在分类改革过渡语境点名，不写成转让对价公式。  
   **修改句（删除旧义）**：`删除“出资人有权从办学结余中取得合理回报”的表述。非营利性民办学校的举办者不得取得办学收益。`

5. **最强反方**  
   原举办者可能主张：没有溢价就等于无偿退出。新举办者可能主张：付了钱就买下学校资产。签前两极都不写。只写：非营利退出对价不得写成法人财产买卖；变更收益须能回链“依法享有的合法权益”。

## 硬闸 D　办学许可证

1. **许可证是准入核心**  
   实施条例第二十二条：对批准正式设立的民办学校，审批机关颁发办学许可证。民促法第十九条：取得办学许可证后进行法人登记。高校管理规定第八条：不得出租、出借办学许可证。民促法第六十二条：伪造、变造、买卖、出租、出借办学许可证可停招、吊证直至刑事责任。  
   必须核验：证载学校名称、举办者、校长、地址、层次、有效期是否与正文一致。材料未附许可证原件或复印件：许可证字段停止。证载举办者与签约转让方不一致：字段停止，不写成可以签。

2. **禁止把许可证当商品**  
   **修改句**：`【学校全名】持有的办学许可证编号【待填】，有效期至【待填】，记载举办者为【待填】。该许可证不得买卖、出租、出借、抵押或作为担保物。审批机关核准本次举办者变更后【待填】个工作日内，双方配合办理许可证记载事项变更；变更完成前，新举办者不得持原证对外招生或办学。`

3. **无许可证**  
   主体只是培训公司、咨询公司，从未取得办学许可证：负触发 `公司股权转让·审查` 或引擎，不按本类型审。

4. **最强反方**  
   相对人可能主张“证还没过期、先用着”。签前不得写成未变更记载也可对外办学。

---

## 节点 2　主体、授权、理事会

1. 建主体表：原举办者、新举办者、学校、共同举办者、授权签字人。名称不一致不自动合并。
2. 新举办者须符合举办条件（信用状况、资金来源、义务教育场景下的国籍／外资限制）。口头“我们老板同意了”不得写成已授权或已决议。
3. 多个举办者：部分举办者擅自转让，签署能力字段停止。
4. 章程对举办者变更、理事会表决另有规定的，先读章程，与正文冲突并列 `C#`。实施条例第二十六条是底线：变更举办者须三分之二以上组成人员同意。
5. 国资／外资／外方实控／义务教育：准入未核则字段停止。实施条例第五条：外商投资企业以及外方为实际控制人的社会组织不得举办、参与举办或实际控制实施义务教育的民办学校。
6. 不足：字段停止，列出待补材料，不补主体。

---

## 节点 3　标的、法人财产、土地与负担

1. 标的确定到学校全名、许可证号、举办者身份。只有“有关学校”则标缺口。
2. 法人财产权属学校。交接的是管理权、印章、证照、账册和资产**清单的占有／管理**，不是把法人财产卖给新举办者。
3. 土地：划拨、出让、租赁、集体土地必须分列。划拨教育用地不得写成可随意改用途或转营利。材料未提及不得写成“无权利负担”，只能写 `依据不足`。
4. 抵押、查封、长期租赁（以租代售）：标红旗。不得把未解除查封的校舍写成可过户。
5. 实施义务教育的民办学校与利益关联方不得交易（实施条例第四十五条）。其他学校关联交易须公开公允，不得损害学校和师生。

## 节点 4　程序与生效

把理事会决议、财务清算、审批核准、许可证变更、法人登记写成**义务和期限**，不写成已经完成。

| 文本写法 | 本任务动作 |
| --- | --- |
| “本合同签字即生效并立即移交管理权” | 拆成成立 vs 变更生效 vs 交割；核准前不得交章交证 |
| “工商／民政变更后生效”且无谁负责、几日内、未完成后果 | 补主体、期限；先核准，再登记／换证 |
| “双方同意视为已批准／已决议／已清算” | 红线；改为书面附件和先决条件 |
| 用户要求倒签或补假批复、假决议、假清算 | 整体停止 |

不得把“双方同意视为已批准”写成可放行结构。

---

## 节点 5　格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

重复使用的学校转让模板仍可能构成格式条款。审查单方解约、签字即交章、不得调整的高额违约金、管辖、最终解释权是否有显著提示。

违反法律、行政法规强制性规定不一律无效。审批、理事会程序主要约束**变更效力和履行**，不轻易写“未开会则整份协议自始无效”。买卖非营利法人财产、买卖许可证、义务教育改营利、抽逃：只告知，不写假架构。禁止用已失效“效力性／管理性”口诀。

---

## 节点 6　违约、解除、争议解决

1. 不配合报批、过渡期违规处置资产或新增重大债务、陈述保证不实、逾期付款，必须分别有日违约金或固定金额，以及达到【待填】日的解除权。只有“依法承担违约责任”视为必须改。
2. 审批未获核准且不可归责：双方均有权解除，已付款（含定金）应退。因迟延报批等可归责原因导致未获批准：可谈赔偿，不写成“未批准也必须付钱交章”。
3. 构成违约不等于当然解除。法定解除只点名催告或目的不能实现，不在本任务作出已解除结论。违约金避免“不得调整”或“按总价百分之三十必得”。
4. 争议解决：已有仲裁条款，不得改成“应向某法院起诉”并假装已选定诉讼；或裁或诉、机构不明：改成单一机构或单一法院连结点；学校所在地可作为约定连结点，不得写成“依法专属管辖”。
5. 微信已读不写成已经送达，除非合同把该渠道定为送达。

---

## 节点 7　过渡期、职工学生与其他结构

1. 签约后至核准前：原举办者维持正常办学，不得重大资产处置、对外担保、新增重大债务或突击变更人事。新举办者有权知情，但核准前不得接管。
2. 举办者变更不影响劳动合同继续履行。教职工工资、社保、学生学费预收是清算重点，不是新举办者可抛弃的负担。
3. 联合举办须有联合办学协议。部分举办者退出：其余举办者同意未闭合则字段停止。
4. 校外培训处罚办法只在文本确是学科类培训时点名，不把本类型改成培训行政处罚整案。

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

对照已加载框架级文件和本方法硬闸，按六步逐段出句。框架中的“合理回报”“学校支付补偿”：仅用于识别应删除或应改写的旧义，不得照抄成建议句。主给付滑入股权或资产则按节点 1.2 转出。

| 步 | 本类型必须盯的点 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题不得用股权／资产转让；主体含举办者并可列学校为确认方；鉴于只描述许可证、分类、土地性质和共同报批，不写“转让学校全部资产” | 标题与鉴于修改句 |
| 交易条款 | 标的是举办者权益；分类闭合；价款是变更收益而非净资产对价；付款挂钩核准；交割是管理权与证照，不是出售法人财产 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 不配合报批的分别后果；审批失败解除退款；陈述保证含许可证、分类、土地、无未披露债务 | 可执行后果句 |
| 尾部 | 附条件：签署成立、核准后变更生效；附件含许可证、章程、理事会决议、清算／审计、土地证、资产负债清单 | 生效与附件修改句 |
| 语言 | 正说加反说；举办者 ≠ 股东；变更收益 ≠ 股权对价；成立 ≠ 核准生效；学校资产归学校、不得抽逃、不得私分结余 | 替换空词的句子 |
| 常见问题 | 签字即交章、未见审批、非营利按净资产买卖、学校划付、许可证当商品、合理回报旧义 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（签字即交章、买卖非营利法人财产、学校划付、买卖许可证、义务教育改营利）；
- `必须改`：可谈但签署前要落句（成立与核准拆分、付款挂钩批复、理事会三分之二、清算附件、许可证记载、删除合理回报旧义）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级金额或个人无限连带且用户拒绝升级：停止“可以签署”建议。
