# 边界与路由

本技能只审查 **公司相关合同 / 民办学校转让协议**。主线是已持证民办学校的举办者身份与办学控制权交接。不是普通公司股权买卖，不是校舍设备商品出让，也不是社会团体换负责人。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 无办学许可证，只是普通公司股权让与、优先购买、工商过户 | `公司股权转让·审查` |
| 主文件是股权收购控制权，且无办学许可／举办者变更叠加 | `股权收购合同（含控制权转移）·审查` |
| 土地／校舍／设备当商品出让，不改举办者 | `非核心资产转让·审查` 或 `资产收购合同·审查` |
| 国有股权协议转让、须进场 | `国有股权转让合同（协议转让）·审查` |
| 国有资产协议转让、须进场 | `国有资产转让合同（协议转让）·审查` |
| 社会团体换法定代表人／理事长，不是学校举办者 | `社会团体负责人变更合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草模式（出稿后自审） |
| 已签未争、问报批日／换证日／交章留痕 | 本套导航的履约步骤 |
| 转让款／审批／许可证已被起诉、复议、立案、开庭或仲裁 | 教育／公司争议领域；不填签前十节 |
| 签字即交章交证、按净资产买卖非营利学校、学校划付补偿 | 留本任务只出红线；用户坚持改成可履行则整体停止 |
| 买卖、出租、出借办学许可证 | 留本任务只出告知；不改成可履行许可交易 |
| 义务教育写成转营利 | 红线停笔；不设计可履行转制 |
| 国资未评估挂牌或外资／外方实控未核 | 字段停止；不写场外可履行 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

专业版未收录的 P1 场景不会作为专业版安装对象。若用户拿这些文本来找专业版：输出 `unavailable` 或负触发路由，不得用邻类硬套。

本技能不得转去加载股权转让、资产转让或社团负责人双文件完成本类型审查，也不得把优先购买三十日交割包或资产风险转移写成举办者变更默认主路径。
