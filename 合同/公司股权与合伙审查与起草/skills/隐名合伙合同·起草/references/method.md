# 审查方法（锁定 合伙合同相关 / 隐名合伙合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制股权代持解释三显名节点，禁止复制有限合伙第 68 条安全港、GP/LP 分档或认缴责任主路径。

定性校验：标题、核心给付与本类型一致才继续；股权代持、有限合伙、全体显名个人合伙、普通合伙企业、固定本息借款或其他主文件明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、债权人必然追不到、必然已是或不构成合伙人、对方必然接受或唯一必得金额。

`search_law` 返回 1997 年《合伙企业法》或其条号、已失效《合同法》及其解释、民法通则及其意见、2011 年《公司法解释（三）》同条号旧义时记为噪声，不得写入 `L#`。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。有限合伙协议或股权代持范本只证明是另一类型，不得当作本类型范本。

知识库纠正（不回写双文件）：

- `基本面.md` “债权化改造：固定回报＋额外浮动收益更偏债权”：该写法是名为合伙实为借贷的红旗，不是可履行优化。要借贷则负触发借款原子；要合伙则删除保本付息。
- 实务资料或比较法“隐名合伙人仅以出资额为限对外承担责任”：不是中国大陆现行规则。大陆隐名合伙无法定责任隔离；被认定为合伙人时走民法典第 973 条。
- `基本面.md` “转化为有限合伙企业以获得法定有限责任”：只作改道点名，转 `有限合伙企业合同·审查` 或 `合伙协议（有限合伙）·审查`，本任务不出有限合伙整稿，也不把未登记文本改成可履行 LP 避风港。
- `框架.md` “我国法律不承认个人隐名合伙”：精确口径是——不是法定商事组织形式；内部合同作为分配和违约依据通常可约束签署方；不因此取得对外有限责任。
- 担保增信只审对本约放行的影响，不展开保证或抵押专项整案。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 隐名方向显名经营者出资，不对外公示，不领有限合伙执照，约定不执行日常事务并分享经营收益 | 本类型 | 正触发 |
| 有限公司股权挂在名义股东名下，实际出资人享投资权益、谈显名变更股东 | 股权代持 | 负触发 `股权代持协议·审查`；投资侧代持主文件 → `股权代持合同·审查` |
| 拟领取执照，名称标明“有限合伙”，正文分列 GP 与 LP | 有限合伙 | 负触发 `有限合伙企业合同·审查` 或 `合伙协议（有限合伙）·审查` |
| 全体显名、共同经营、不领执照 | 个人合伙 | 负触发 `个人合伙合同·审查` |
| 名称标普通合伙或全员无限连带企业协议 | 普通合伙企业 | 负触发 `普通合伙企业合同·审查` |
| 名称标“特殊普通合伙”，执业过错切割其他合伙人 | 特殊普通合伙 | 负触发 `特殊的普通合伙企业合同·审查` |
| 对外是个体户经营者，对内多人合伙为主文件 | 个体户实质合伙 | 负触发 `登记为个体工商户的实质合伙合同·审查` |
| 不担风险、到期固定本息或保本付息是主给付 | 借贷 | 负触发 `或企业间借款` 或 `不参与经营不承担亏损到期固定本息→自然人之间借款` |

支持切开的规范（法律结论须运行时复核）：

- 民法典第 967 条：合伙合同是共享利益、共担风险。无风险、固定本息则不是本类型。
- 第 973 条：合伙人对合伙债务连带；内部追偿另言。无企业法上的 LP 认缴上限。
- 合伙企业法（2006 修订）第 2、67、68 条：有限合伙须依法设立，LP 不执行事务的安全港只适用于已登记有限合伙企业。
- 公司法解释三（2020 修正）第 24、25 条：实际出资人与名义股东、投资权益与显名，只适用于有限公司股权，不适用于本类型经营体。

### 1.3 与代持 / 有限合伙切开（硬闸）

| 文本写法 | 本任务动作 | 修改句方向 |
| --- | --- | --- |
| 隐名出资给个人或未登记经营体，分享经营利润，不谈公司股权和执照 | 正触发 | 首部分列显名／隐名，写清不是 LP、不是公司股东 |
| “代持××有限公司股权”“名义股东／实际出资人／显名变更股东” | 负触发 `股权代持协议·审查` 或 `股权代持合同·审查` | 不按解释三半数同意显名改完 |

### 1.4 保本、公开募集、规避准入、倒签停笔

加载后或定性中出现：保本付息、到期还本、向不特定对象公开募集；鉴于条款写明为规避公职禁业、外资负面清单或特许准入；倒签或补假出资凭证。

动作：

1. 交付告知：保本付息可能被认定为借贷；公开募集或保本承诺触及私募条例第 20 条和非法集资红线；规避准入可能因第 153 条或公序良俗而无效。不得改写成可履行结构。
2. 不写可履行的公开推介话术、假显名、假备案或“先隐名再补办准入”。
3. 风险表只保留识别依据和删除／转出口径。
4. 用户坚持“改到能签且仍做这些事”：整体停止。

## 节点 2　主体、知情同意与挂名财产

### 2.1 主体表

建表：签约名、显名／隐名身份、出资形式与金额、缴付期限、谁对外经营、授权签字人。名称不一致不自动合并。自然人须具备完全民事行为能力。口头“我们老板同意了”不得写成已授权。

协议必须写明谁是显名合伙人（出面经营）、谁是隐名合伙人（内部出资）。身份空白：必须改，不写成“可以按谁出钱自行推定”。

### 2.2 其他合伙人与资质

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 经营体另有未签署的合伙人 | 必须改。补全体知情同意或写明本约仅约束签署方、不得对抗未签署合伙人 | 两人私约当然约束合伙整体 |
| 显名方从事须许可行业，文本未提许可 | 字段停止 | 可以先经营 |
| 隐名方为公职人员或禁业主体 | 红线停笔，不改成可履行隐名 | 配偶出面即可放行 |

### 2.3 出资挂名与执行风险

隐名出资通常登记或存放在显名方名下。必须提示：显名方个人债权人可能把该财产当作显名方责任财产申请查封、执行。材料未提及显名方负债的，写 `依据不足`，不得写成“财产安全”。

修改句：

「甲方为显名合伙人，对外执行合伙事务并代表本经营体。乙方为隐名合伙人，仅在本协议内部记载，不对外公示为合伙人，不因此成为有限合伙企业的有限合伙人或公司股东。本协议仅约束签署方；对未签署的其他合伙人不当然发生效力。双方确认，乙方出资及以该出资形成的财产虽可登记或存放于甲方名下，但内部确认按第【待填】条属于合伙财产或按份共有；甲方不得将其作为个人财产处分。甲方应于【待填】日前开立专户核算，不得与个人资金混同。」

不足：字段停止，列出待补材料，不补主体。

## 节点 3　对外责任与对内追偿（硬闸）

支持依据：民法典第 973、972 条。有限合伙认缴上限和第 68 条安全港不得套用。

### 3.1 对外

| 文本写法 | 动作 |
| --- | --- |
| “隐名合伙人不承担任何合伙债务”“债权人不得向乙方追索”“乙方仅以出资为限对抗第三人” | 红线删除对外免责。改为：内部限额不得对抗债权人；被认定为合伙人的，依第 973 条连带 |
| 写明对外责任不可协议免除，对内按约定分担 | 可保留；须加黑提示 |
| “本协议约定后乙方对外当然免责，因为隐名” | 红线。隐名本身不产生法定有限责任 |
| 同时写“乙方可对外签约”又写“乙方不担债” | 红线。对外代表与免责互相冲突 |

不得输出“债权人一定追得到”或“一定追不到”。已有事实若只有内部合同、无参与经营、无对外表明身份：现有依据支持警示连带风险，依据不足认定第三人已经或必然把隐名方当作合伙人。

### 3.2 对内

内部亏损分担按第 972 条：有约定从约定；未约定协商；不成按实缴；无法确定则平均。内部可以约定隐名方分担不超过出资额，但必须紧跟：该约定只约束签署方。

超过内部份额对外清偿的，清偿方可向另一方追偿。框架所称追偿句是内部救济，不是对外挡箭牌。

修改句：

「双方确认：本协议关于亏损分担的约定仅对签署方内部具有约束力，不得对抗合伙债权人或其他第三人。如因外部债权人主张权利，导致一方承担超过本协议约定份额的责任，该方可就超出部分向另一方全额追偿。任何一方被认定为合伙人的，对合伙债务依照法律规定承担连带责任，本协议不得解释为对外免除或限制该责任。」

最强反方：隐名方主张“没露面就不可能被追”。现有依据不支持把未露面写成法定免责；参与经营或对外表明身份会显著提高被认定为合伙人的可能。

## 节点 4　不参与经营、知情权与身份穿透

支持依据：第 970 条（事务执行与监督）；第 967 条（共担风险）。第 68 条八项安全港只属于已登记有限合伙企业的 LP，禁止照抄为本类型“怎么监督都没事”。

### 4.1 执行与知情

必须同时具备：

1. 日常经营管理、对外代表由显名方行使；隐名方无对外代表权。
2. 隐名方保留查阅账目、定期知悉经营状况的权利。删掉知情权且只拿固定回报：借贷红旗。

| 文本写法 | 动作 |
| --- | --- |
| 隐名方不执行日常事务，但可按季查阅账册、委托审计 | 可接受；写清查阅不等于对外代表 |
| 完全无权查账，只到期领固定收益 | 必须改或负触发借贷 |
| 隐名方有权以经营体名义签约、掌握公章或对外收款 | 红线删除对外代表 |

重大事项（改变经营范围、单笔负债超过【待填】、处分核心资产）的事先同意权可以保留，须写明：同意权用于内部约束显名方，不授权隐名方向第三人作出意思表示。

### 4.2 穿透行为

| 文本或用户承认的事实 | 动作 |
| --- | --- |
| 隐名方在业务合同上签批、在客户微信群指挥、对外自称老板或合伙人 | 红线。删除对外行为授权；警示可能被认定为合伙人并适用第 973 条 |
| 仅内部查阅、质询，不对外表态 | 可保留 |
| “若因隐名方干预经营导致身份被穿透，后果自负”单独出现、无行为边界 | 必须改：先限制行为，再写内部责任；不得把该句当成对外免责 |

修改句：

「乙方不执行日常合伙事务，不得对外代表本经营体，不得在业务文件、对外账户或客户沟通中表明其为合伙人或经营者。乙方有权于每【待填】查阅经营账目、银行流水和主要合同，并有权委托会计师审计一次。改变经营范围、单笔负债超过人民币【待填】元或处分核心资产，甲方应事先取得乙方书面同意；该同意仅产生内部效力，不构成对第三人的授权。乙方违反本条对外作出意思表示或表明合伙人身份的，应自行承担因此扩大的内部份额，但不影响法律规定的对外责任。」

## 节点 5　出资、分配语言与保底

### 5.1 出资

支持依据：第 968、969 条。出资方式、数额、缴付期限须写清。通常为货币或实物；劳务作为隐名出资极易被主张未出资或实为雇佣，必须改。

未完成缴付不得写成已形成合伙财产份额。禁止编造金额。

### 5.2 利润与亏损语言

| 文本写法 | 动作 |
| --- | --- |
| 共享利润、共担风险、按实际经营结算 | 可保留；补分配时点与对账程序 |
| 保本付息、固定回报、到期还本、不承担任何亏损 | 红旗名为合伙实为借贷。不改成可履行保底。用户坚持：整体停止或负触发借款原子 |
| 部分固定、部分浮动，但固定部分到期必还 | 同样按借贷红旗处理，禁止按知识库“债权化改造”放行 |
| 分配标准空白 | 必须改：先约定；未约定走第 972 条默认 |

修改句：

「双方共享经营利润、共担经营风险，按实际经营情况结算。利润分配和亏损分担按第【待填】条办理。双方不得将本协议解释为借款、保本保收益或到期还本付息。分配以对账确认的可分配利润为准，对账周期为每【待填】。」

## 节点 6　格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 格式条款

为重复使用而预先拟定、订立时未与对方协商。审查：对外免责、放弃查阅、单方解释、管辖／仲裁等异常条款是否有足以引起注意的标识，以及是否按要求说明（第 496 条；解释第 10 条）。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在附件 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

### 6.2 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的、是否仅行政管理、是否只规制履行行为（第 153 条；解释第 16 条）。禁止用已失效“效力性／管理性”口诀代替解释第 16 条。

现有依据不支持放行：对外免责对抗债权人；保本公开募集；规避公职、外资或特许准入的隐名安排。

## 节点 7　违约、退出与争议

1. 显名方擅自处分合伙财产、改变经营方向、隐瞒利润：须有可执行后果（赔偿、解除、结算）。只有“依法承担违约责任”视为必须改。
2. 因显名方原因导致隐名身份被迫公开并引发追索：内部损失分担和追偿须写清，不得写成对外免责。
3. 退出：连续亏损、显名方重大违约等条件，加上份额结算、通知和专户清理。禁止“永远不得退出且无结算”。
4. 未约定合伙期限：第 976 条视为不定期，可随时解除但应在合理期限前通知。须补通知期 `【待填】`，不得写成无需通知立即散伙。
5. 向合伙人以外的人转让内部份额：除另有约定外须其他合伙人一致同意（第 974 条）。本约若只有两方，写清禁止单方转让或须书面同意。
6. 争议解决：此类协议常涉及内部账务，可建议仲裁以降低公开诉讼导致隐名丧失；这是私密性建议，不是法定义务。已有仲裁条款不得改成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核。
7. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。
8. 尾部：签署生效；出资流转凭证、账簿确认方式入附件，作为合伙而非借贷的证据。倒签或补假流水：整体停止。

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

打开已加载的 `框架.md`，按六步逐段对照正文。`基本面.md` 用于校验类型、主体、对外责任和红旗，不代替本节点出句。

| 步 | 动作 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题可用隐名合伙／合作投资；分列显名／隐名；鉴于不写规避准入、不保证对外免责、不自称 LP 或公司股东 | 标题或主体修改句 |
| 交易条款 | 出资形式与缴付；挂名财产与专户；不执行日常事务但保留查阅；利润共享亏损共担；对外连带警示与对内追偿 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 擅自处分／隐瞒利润违约；身份暴露内部分担；退出结算；其他合伙人同意 | 可执行后果句 |
| 尾部 | 签署生效；出资凭证与账簿确认入附件；生效 ≠ 已登记有限合伙或已是公司股东 | 生效与附件修改句 |
| 语言 | 正说加反说；盯死保本付息、固定回报、到期还本、对外免责、安全港、显名股东 | 替换空词的句子 |
| 常见问题 | 对外免责；参与经营穿透；保底；把本约写成代持或 LP；债权化改造 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（对外免责、保本付息、公开募集、规避准入、倒签、代持／LP 主轴）；
- `必须改`：可谈但签署前要落句（追偿句、查阅权、专户、其他合伙人同意、行为边界）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级个人连带且用户拒绝升级：停止“可以签署”建议。
