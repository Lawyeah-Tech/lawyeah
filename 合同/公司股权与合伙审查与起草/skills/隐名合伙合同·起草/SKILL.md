# 隐名合伙合同·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、民法通则及其意见、1997 年《合伙企业法》条号当作现行规则。不得把比较法上的“隐名合伙人以出资为限对外免责”或台湾／德国隐名合伙制度写成中国大陆现行法。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **合伙合同相关 / 隐名合伙合同** 己方稿，出稿后用本类型硬闸自审。交付草稿、未决项、自审风险表和自审后修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查隐名合伙合同（合伙合同相关）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、把股权代持或有限合伙改完、把对外免责或保本付息改成可履行。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **隐名合伙对外责任**：隐名合伙不是法定商事组织形式。对内可以约定亏损分担；对外不得写成“隐名合伙人不承担合伙债务”“债权人不得追索”或“仅以出资为限对抗第三人”。被认定为合伙人时，适用民法典第 973 条连带责任；内部限额不能对抗债权人。参与经营、对外签批、在经营场所指挥或使第三人有理由相信其为合伙人的，不得写成必然不被追索。对内追偿可以写，但不能代替对外责任警示。
2. **与代持 / 有限合伙切开**：标的是有限公司股权、名义股东登记、投资权益与显名程序 → `股权代持协议·审查` 或 `股权代持合同·审查`。拟领取执照、名称标明“有限合伙”、分列普通合伙人与有限合伙人 → `有限合伙企业合同·审查` 或 `合伙协议（有限合伙）·审查`。禁止抄股权代持解释三显名 method，禁止按有限合伙第 68 条安全港改完。点名“可考虑转为登记有限合伙”只作改道，不在本任务出有限合伙整稿。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签隐名合伙或合作投资正文，尚未签署，尚未成争；核心给付是隐名方向显名方出资，不对外公示为合伙人，不登记有限合伙，约定不执行日常事务并分享经营收益；用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 有限公司实际出资人与名义股东、投资权益归属、显名变更股东 → `股权代持协议·审查`；股权投资货架代持主文件 → `股权代持合同·审查`；
- 拟设立或变更有限合伙企业，名称标明“有限合伙”，分列 GP/LP → 合伙合同相关货架走 `有限合伙企业合同·审查`，公司相关合同货架走 `合伙协议（有限合伙）·审查`；
- 全体显名、共同经营、不领执照的自然人共同事业 → `个人合伙合同·审查`；
- 已领或拟领普通合伙企业执照、全员无限连带、无隐名安排 → `普通合伙企业合同·审查`；
- 名称标“特殊普通合伙”或执业过错切割其他合伙人责任 → `特殊的普通合伙企业合同·审查`（P1；专业版未装则 `unavailable`）；
- 主文件是个体户登记牌照下的实质合伙 → `登记为个体工商户的实质合伙合同·审查`（P1；未装则 `unavailable`）；
- 不承担经营风险、到期固定本息或保本付息为主给付 → `或企业间借款` 或 `不参与经营不承担亏损到期固定本息→自然人之间借款`；
- 公司股东协议、股权治理一揽子 → `公司股东协议·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问分账日、查阅留痕 → 本套导航的履约步骤；
- 已催告、追索、排除执行、散伙清算诉讼或仲裁 → `已出现催告解除函索赔立案开庭仲裁` 或对应专项领域。

用隐名规避公职禁业、外资负面清单、特许准入，或向不特定对象募集、承诺保本保收益：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（隐名侧或显名侧择一）；相对方；全文及出资凭证版本；谁对外经营、谁出资；是否实际参与经营或对外签字；利润与亏损是否含保本付息；其他合伙人是否知情同意；出资是否挂在显名方名下；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 起草模式

本原子只承担本类型起草。待签评改转 `隐名合伙合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `隐名合伙合同·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。

### 起草必写

- 隐名合伙不是法定商事组织形式。对内可以约定亏损分担；必须写明被认定为合伙人时适用民法典第 973 条连带责任，内部限额不能对抗债权人。
- 对内追偿可以写，但不能代替对外责任警示。参与经营、对外签批、在经营场所指挥或使第三人有理由相信其为合伙人的，不得写成必然不被追索。
- 隐名方无对外代表；必须保留查阅账目。共享利润、共担风险。
- 点名“可考虑转为登记有限合伙”只作改道，不在本任务出有限合伙整稿。

### 附件必附

- 出资凭证；出资是否挂在显名方名下的说明。
- 其他合伙人知情同意（如有其他合伙人）。

### 禁止出现

- “隐名合伙人不承担合伙债务”“债权人不得追索”“仅以出资为限对抗第三人”。
- 把比较法上的隐名合伙人以出资为限对外免责写成中国大陆现行法。
- 保本付息、固定回报、到期还本改成可履行保底；“债权化改造”当作可履行建议。
- 抄股权代持解释三显名程序或有限合伙第 68 条安全港；用隐名规避公职禁业、外资负面清单、特许准入或向不特定对象募集。

出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 本任务起草模式；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有隐名合伙文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。股权代持、有限合伙、全体显名个人合伙、普通合伙企业、固定本息借款负触发。

### 2. 主体、知情与挂名财产

签约名与显名／隐名身份分列。仅部分合伙人签署则标对其他合伙人不当然约束。出资挂在显名方名下的执行风险必须点名。

### 3. 对外责任与对内追偿

写清第 973 条对外连带；内部限额不得对抗债权人；超过内部份额的清偿可向对方追偿。禁止对外免责句。

### 4. 不参与经营、知情权与穿透

隐名方无对外代表；必须保留查阅账目。签批、指挥业务或对外表明身份：红线并警示可能被认定为合伙人。

### 5. 分配语言与保底

共享利润、共担风险。出现保本付息、固定回报、到期还本：借贷红旗，不改成可履行保底。

### 6. 格式条款、强制规范与规避停笔

无核验引文则法律结论字段停止。规避准入或公开募集停笔。

### 7. 违约、退出与争议

身份暴露、擅自处分、隐瞒利润须有可执行后果。建议仲裁以降低公开诉讼导致隐名丧失，不写成法定义务。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把对外免责改成可对抗债权人、把保本付息／公开募集／规避准入改成可履行结构。
- `字段停止`：法域、动态规则、是否已被第三人识别、显名方负债与查封、其他合伙人同意未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁代持／有限合伙／借贷。
