知识库纠正（不回写双文件）：

- `基本面.md` “违反效力性强制性规定”：禁止用失效“效力性/管理性”口诀。改走民法典第 153 条和合同编通则解释第 16 条。

支持切开的规范（法律结论须运行时复核）：

- 《合伙企业法》第 2 条：普通合伙企业由普通合伙人组成，合伙人对合伙企业债务承担无限连带责任；有限合伙企业另有 LP。
- 《合伙企业法》第 55 条：特殊的普通合伙企业是专业服务机构依第 57 条承担责任的普通合伙企业。
- 民法典第 967 条：合伙合同是共享利益、共担风险的协议——无执照个人合伙走 `个人合伙合同·审查`，本任务不以该章当默认主法。
- 市场主体登记管理条例第 3 条：未经登记，不得以市场主体名义从事经营活动。

### 1.3 领取执照适用合伙企业法（硬闸）

修改句：

「各方确认：本协议是为依照《中华人民共和国合伙企业法》在中国大陆设立普通合伙企业而订立。合伙企业名称组织形式后标明‘普通合伙’。营业执照签发日期为合伙企业成立日期。领取营业执照前，任何一方不得以本合伙企业名义从事经营活动或对外签署合同。」

最强反方：相对方主张内部协议已成立，未领照也可先用字号。现有依据不支持把未领执照写成可以合伙企业名义经营。用户坚持保留未领照对外经营：整体停止。

### 1.4 与个人合伙 / 有限合伙切开（硬闸）

标题写成“个人合伙”但正文要领普通合伙执照、名称带“普通合伙”：按核心给付留本技能，标题冲突写入 `C#`，修改句改标题为合伙协议。

正文出现有限合伙人、认缴为限、LP 不得执行事务：负触发 `有限合伙企业合同·审查`。不得删掉 LP 条款后继续当普通合伙审。

正文把执业故意或重过失写成其他合伙人不负无限责任：负触发 `特殊的普通合伙企业合同·审查`。普通合伙企业不得偷换特殊普通合伙责任形式。

### 1.5 挂靠 / 未领照对外 / 规避监管停笔

加载后或定性中出现：借用资质挂靠、未领执照以合伙企业名义对外经营、把禁入主体改成可登记普通合伙人、设计对外免责以规避债权人。

动作：

1. 交付告知：可能违反《合伙企业法》第 2、3 条和市场主体登记管理条例第 3 条。不得改写成可履行的规避结构。
2. 不写可履行的未领照经营路径、假委派或对外免责。
3. 风险表只保留识别依据和删除/转出口径。
4. 用户坚持“改到能签且仍做这些事”：整体停止。

## 节点 2　主体、书面协议与设立登记

### 2.1 主体表与禁入（硬闸）

建表：签约名、履行名、出资名、授权签字人、法人或其他组织的委派代表。名称不一致不自动合并。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 国有独资公司、国有企业、上市公司、公益性事业单位或社会团体被列为普通合伙人 | 红线删除或改道；第 3 条禁止 | 补内部决议即可登记 |
| 自然人为合伙人，民事行为能力未闭合 | 字段停止 | 可以签署 |
| 法人作为普通合伙人，无委派代表 | 必须改：由其委派的代表执行 | 公章一盖即可执行事务 |
| 口头“我们老板同意了” | 不得写成已授权 | 已获内部批准 |

修改句：

「合伙人仅限于具有完全民事行为能力的自然人，以及法律未禁止担任普通合伙人的法人或其他组织。国有独资公司、国有企业、上市公司以及公益性的事业单位、社会团体不得成为本企业普通合伙人。法人或其他组织担任合伙人的，应当书面委派一名自然人代表执行合伙事务，委派书作为附件。」

最强反方：相对方主张该国企只是“财务投资、不执行事务”。现有依据不支持把禁入主体改成可登记普通合伙人。

### 2.2 书面协议与第十八条事项

合伙协议应当载明：名称和主要经营场所、合伙目的和经营范围、合伙人姓名或名称及住所、出资方式数额和缴付期限、利润分配与亏损分担、事务执行、入伙与退伙、争议解决、解散与清算、违约责任。缺一项则该字段不得写成已闭环，修改句补栏，数字用 `【待填】`。

协议经全体合伙人签名、盖章后生效。修改或补充除另有约定外应当全体一致同意。

### 2.3 设立登记与前置许可

把批准、设立登记写成**双方义务和生效/成立条件**，不写成已经完成。

| 文本写法 | 本任务动作 |
| --- | --- |
| “本协议签字后企业即成立” | 必须改：协议生效 vs 企业成立（执照签发日） |
| 无谁负责申请登记、几日内、未完成的后果 | 补义务主体、期限、未完成时解除或中止 |
| 经营范围含须批准项目，无批准附件 | 字段停止；修改句要求批准文件作为附件 |
| 用户要求倒签或补假批准 | 整体停止 |

修改句：

「本协议自全体合伙人签名、盖章之日起成立。合伙企业的成立日期为市场监督管理部门签发营业执照之日。甲方应于本协议签署后【待填】日内备齐设立登记材料并提交登记机关；各方应在【待填】日内配合签署申请书、出资确认书和委派书。因不可归责于申请方的原因【待填】日内未取得营业执照的，任何一方可书面通知解除本协议，已缴出资按【待填】退还，互不主张企业已成立。」

部门规章或地方窗口材料未核：字段停止，不写“可以登记”。未登记不等于内部协议当然无效（解释第 16 条），本任务只停止“企业已成立”和“可以对外经营”表述。

## 节点 3　出资、企业财产与劳务评估

审查清单，缺一项则该字段不得写成已闭环：

1. 各合伙人认缴额、实缴期限、缴付账户或交付方式。
2. 货币以外出资：评估办法（全体协商或委托评估机构）及权属转移义务。
3. 劳务出资：普通合伙人可以用劳务出资，评估办法由全体合伙人协商确定并载明于协议。有限合伙人不得劳务出资——若出现 LP 劳务出资，负触发 `有限合伙企业合同·审查`。
4. 企业财产：合伙人的出资、以合伙企业名义取得的收益和依法取得的其他财产，均为合伙企业的财产。清算前原则上不得请求分割。

修改句：

「各合伙人认缴出资额、出资方式和缴付期限见附件出资清单。合伙人以劳务出资的，评估办法为【待填】，折价金额人民币【待填】元，并记载于本协议。以实物、知识产权、土地使用权或其他财产权利出资的，应于【待填】日前办理权属转移至本企业或完成全体合伙人签署的作价确认。合伙人的出资、以本企业名义取得的收益和依法取得的其他财产，均为合伙企业财产；清算前，合伙人不得请求分割，本协议另有约定或法律另有规定的除外。」

禁止编造出资额。框架或示范文本中的比例只是栏目，不是法源。

## 节点 4　利润亏损与保底（硬闸）

支持依据：《合伙企业法》第 33 条制度（本次 MCP 未完整返回 2006 修订第 33 条正文，运行时复核后再写入 `L#`）；第 69 条仅适用于有限合伙且允许协议另有约定——不得搬进普通合伙。

| 文本写法 | 动作 |
| --- | --- |
| 全部利润分配给部分合伙人，或由部分合伙人承担全部亏损 | 红线删除。普通合伙不得作此约定 |
| 一方不参与经营、不承担亏损、到期收回固定本息或固定收益 | 负触发借款原子，或红线删除保底 |
| 未约定分配分担 | 必须改：先约定；无约定则协商；协商不成按实缴；无法确定则平均 |
| “对内按份、对外也按份” | 必须改：对内追偿可以按份；对外仍无限连带 |

修改句：

「本企业利润分配、亏损分担按照附件【待填】办理。合伙协议不得约定将全部利润分配给部分合伙人，或者由部分合伙人承担全部亏损。任何保底收益、固定本息或不承担亏损的约定不构成本协议的利润分配条款。对内分担比例仅用于合伙人相互追偿，不改变各普通合伙人对合伙企业债务的无限连带责任。」

最强反方：相对方主张意思自治可以保底。现有依据不支持把普通合伙的全部利润/全部亏损安排写成可放行。

## 节点 5　事务执行、内部限权与竞业

### 5.1 执行事务与内部限制（硬闸）

合伙人对执行合伙事务享有同等权利。可以委托一个或数个合伙人对外代表企业。法人或其他组织执行事务的，由其委派的代表执行。

除协议另有约定外，改变名称、经营范围或主要经营场所、处分不动产、转让或处分知识产权和其他财产权利、以企业名义为他人担保、聘任合伙人以外的人担任经营管理人员，应当经全体合伙人一致同意。

《合伙企业法》第 37 条：合伙企业对合伙人执行合伙事务以及对外代表合伙企业权利的限制，不得对抗善意第三人。

| 文本写法 | 动作 |
| --- | --- |
| “未经内部书面同意的对外合同一律无效” | 必须改。内部限制不得对抗善意第三人 |
| 委托执行但未写撤销条件和监督查阅 | 必须补 |
| 未拟办理执行事务合伙人登记 | 必须改：登记事项应包括执行事务合伙人；未登记不得写成已对外限制 |

修改句：

「合伙事务由【共同执行 / 委托【姓名】执行】。委托执行的，其他合伙人有权监督执行情况并查阅账簿。改变企业名称、经营范围、主要经营场所，处分不动产，转让或处分知识产权和其他财产权利，以企业名义为他人提供担保，聘任合伙人以外的人担任经营管理人员，除本协议另有约定外，应当经全体合伙人一致同意。本协议对执行事务或对外代表权的限制，不得对抗善意第三人；各方应于设立或变更登记时将执行事务合伙人及其权限可公示事项办理登记。」

### 5.2 竞业与自我交易

合伙人不得自营或者同他人合作经营与本合伙企业相竞争的业务。除协议另有约定或经全体一致同意外，合伙人不得同本合伙企业进行交易。合伙人不得从事损害本合伙企业利益的活动。

竞业不得写成可以内部豁免。自我交易可以约定或全体同意。

## 节点 6　入伙退伙、格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 入伙退伙对外连带（硬闸）

支持依据：第 43、44、48、49、51 条；第 45、46、53 条制度运行时复核条号。

| 文本写法 | 动作 |
| --- | --- |
| 新合伙人不承担入伙前债务 | 红线删除对外豁免。对内可另约追偿 |
| 退伙后对退伙前债务免责 | 红线删除对外豁免 |
| “任何情形下永远不得退伙” | 必须改。未约定期限的，不给事务执行造成不利影响时可退伙，但应提前三十日通知 |
| 除名无书面通知、无异议起诉期间 | 必须补第 49 条：书面通知到达生效；三十日内可起诉 |
| 当然退伙情形空白 | 必须补第 48 条列示，并约定死亡后继承人取得合伙人资格须经一致同意 |

修改句：

「新合伙人入伙，除本协议另有约定外，应当经全体合伙人一致同意并订立书面入伙协议。原合伙人应当向新合伙人如实告知经营状况和财务状况。新合伙人对入伙前本企业债务承担无限连带责任；该责任不得以本协议或入伙协议对外免除。合伙人退伙的，其他合伙人应当与该退伙人按照退伙时的企业财产状况结算。退伙人对基于其退伙前的原因发生的本企业债务，承担无限连带责任。本协议未约定合伙期限的，合伙人在不给合伙事务执行造成不利影响的情况下可以退伙，但应当提前三十日书面通知其他合伙人。」

最强反方：入伙人主张不知情故不承担旧债。第 44 条第 2 款不因内部不知情而对外消灭。修改句把“如实告知”落成原合伙人义务和内部追偿，不写成对外免责。

### 6.2 格式条款

为重复使用而预先拟定、订立时未与对方协商。依据示范文本制作，不当然排除格式条款。

审查：无限连带、除名、永远不得退伙、管辖/仲裁等异常条款是否有足以引起注意的标识，以及是否按要求说明（第 496 条；解释第 10 条）。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在附件 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

### 6.3 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的、是否仅行政管理、是否只规制履行行为（第 153 条；解释第 16 条）。禁止用已失效“效力性/管理性”口诀。未领执照对外经营、禁入主体、对外豁免无限连带：不改写成有效履行。

## 节点 7　违约、解散清算与争议

1. 逾期出资、擅自处分企业财产、违反竞业：须分别有可执行后果（补缴、违约金、除名条件、赔偿）。只有“依法承担违约责任”视为必须改。
2. 除名决议须书面通知；被除名人三十日内可向人民法院起诉。不得写成“通知即不得异议”。
3. 违约金不是必得金额。修改句避免“不得调整”。
4. 解散必须清算。解散不等于合同立即终止。第 85 条解散情形应点名；第 91 条注销后原普通合伙人仍承担无限连带；第 92 条破产后仍承担无限连带。
5. 争议解决：出现仲裁条款，不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核，修改句改成单一仲裁机构或单一法院连结点。专属管辖可能：只标红旗。
6. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。

修改句：

「合伙企业解散的，应当依法清算。清算完毕并办理注销登记前，本协议关于清算组、财产分配和债务清偿的条款继续有效。本企业注销后，原普通合伙人对本企业存续期间的债务仍应承担无限连带责任。本企业不能清偿到期债务的，债权人可以依法申请破产清算，也可以要求普通合伙人清偿。」

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

打开已加载的 `框架.md`，按六步逐段对照正文。`基本面.md` 用于校验类型、主体、执照、责任和红旗，不代替本节点出句。

| 步 | 动作 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题用普通合伙企业合伙协议；名称标明普通合伙；主体无禁入；鉴于不写对外免责或先无照经营 | 标题或主体修改句 |
| 交易条款 | 书面协议第十八条事项；出资与劳务评估；利润亏损禁全部；执行事务与登记 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 入伙退伙对外连带；竞业；除名书面通知；解散清算 | 可执行后果句或删除句 |
| 尾部 | 全体签名盖章；委派代表；出资确认、评估、委派书附件；执照申请义务 | 生效与附件修改句 |
| 语言 | 正说加反说；盯死成立 vs 企业成立、出资 vs 借款、解散 vs 终止、对内分担 vs 对外连带 | 替换空词的句子 |
| 常见问题 | 对外免责；全部利润/亏损；永远不得退伙；未领照对外；解散不清算 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（对外免责、禁入主体、未领照对外经营、全部利润/亏损、保底借贷、倒签）；
- `必须改`：可谈但签署前要落句（无限连带明示、入伙退伙对外责任、执行限制登记、劳务评估、退伙通知、解散清算）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级个人无限连带且用户拒绝升级：停止“可以签署”建议。
