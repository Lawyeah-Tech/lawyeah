# 普通合伙企业合同·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》、已失效《民法通则》个人合伙章、1997 年《合伙企业法》原文或已失效《合伙企业登记管理办法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **合伙合同相关 / 普通合伙企业合同** 己方稿，出稿后用本类型硬闸自审。交付草稿、未决项、自审风险表和自审后修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文名必须是「审查普通合伙企业合同（合伙合同相关）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、把个人合伙或有限合伙改完、把对外无限连带改成对外免责。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **领取执照适用合伙企业法**：核心给付是依照《合伙企业法》设立普通合伙企业并领取营业执照，名称标明“普通合伙”。不得把民法典合伙合同章当默认主法。
2. **普通合伙人无限连带**：合伙人对合伙企业债务承担无限连带责任。内部亏损分担不得写成对外免责。注销或破产后原普通合伙人仍承担无限连带。
3. **与个人合伙 / 有限合伙切开**：不领执照 → `个人合伙合同·审查`。出现有限合伙人或认缴为限 → `有限合伙企业合同·审查`。执业过错切割其他合伙人责任 → `特殊的普通合伙企业合同·审查`。股东协议主文件 → `公司股东协议·审查`。
4. **禁入主体**：国有独资公司、国有企业、上市公司以及公益性的事业单位、社会团体不得成为普通合伙人。
5. **全部利润或全部亏损禁止**：不得约定将全部利润分配给部分合伙人或由部分合伙人承担全部亏损。保底固定本息转借款原子。
6. **入伙退伙对外连带不可豁免**：新合伙人对入伙前债务承担无限连带；退伙人对退伙前原因债务仍承担无限连带。
7. **内部执行限制不得对抗善意第三人**：对执行事务或对外代表权的限制，不得对抗善意第三人。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签普通合伙企业协议正文，尚未签署，尚未成争，核心给付是设立普通合伙企业、领取执照、普通合伙人无限连带，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 不领执照、不以合伙企业名义登记、只适用民法典合伙合同 → `个人合伙合同·审查`；
- 出现有限合伙人、认缴出资为限、禁止劳务出资的 LP → `有限合伙企业合同·审查`；
- 律师、会计师等专业所，执业故意或重过失切割其他合伙人责任 → `特殊的普通合伙企业合同·审查`（P1；专业版未装则 `unavailable`）；
- 律师事务所合伙协议主文件 → `律师事务所合伙协议·审查`（P1；未装则 `unavailable`）；
- 公司股东会、股权治理、注册资本一揽子 → `公司股东协议·审查`；
- 不参与经营、不承担亏损、到期固定本息 → `或企业间借款` 或 `不参与经营不承担亏损到期固定本息→自然人之间借款`；
- 只拿固定报酬不担风险 → `只拿固定报酬不分担亏损无合伙人决策权→个人劳务（雇佣）`；人格从属加工资社保 → `人格从属＋工资社保→劳动合同`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁，或要散伙清算诉讼策略 → `已出现催告解除函索赔立案开庭仲裁` 或对应专项领域。

挂靠、违法分包、规避限购、未领执照以合伙企业名义对外经营：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（拟入伙普通合伙人或拟执行事务合伙人择一）；相对方；全文及附件版本；是否领取或拟领取普通合伙企业营业执照；名称是否含“普通合伙”；合伙人主体类型；是否夹带 LP 或执业过错切割；出资与劳务评估；利润亏损；执行事务委托；入伙退伙对外责任；不可接受事项；法域、拟登记地与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 起草模式

本原子只承担本类型起草。待签评改转 `普通合伙企业合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `普通合伙企业合同·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。

### 起草必写

- 核心给付是依照《合伙企业法》设立普通合伙企业并领取营业执照，名称标明“普通合伙”。不得把民法典合伙合同章当默认主法。
- 合伙人对合伙企业债务承担无限连带责任。内部亏损分担不得写成对外免责。注销或破产后原普通合伙人仍承担无限连带。
- 书面协议齐第十八条事项。国有独资公司、国有企业、上市公司以及公益性的事业单位、社会团体不得成为普通合伙人。
- 不得约定将全部利润分配给部分合伙人或由部分合伙人承担全部亏损。
- 新合伙人对入伙前债务承担无限连带；退伙人对退伙前原因债务仍承担无限连带。对执行事务或对外代表权的限制，不得对抗善意第三人。

### 附件必附

- 载明合伙企业法第十八条事项的书面协议正文。
- 出资安排；劳务出资须载明评估办法。

### 禁止出现

- 对外无限连带改成对外免责；全部利润或全部亏损归部分合伙人。
- 禁入主体担任普通合伙人；未领执照以合伙企业名义对外经营。
- 内部限权写成对抗善意第三人；永远不得退伙。
- 保底固定本息；按个人合伙或有限合伙改完。

出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 本任务起草模式；已签履约 → 本套导航履约步骤；已成争或清算诉讼策略 → 合同争议。未签且目标是评改已有普通合伙企业协议，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。个人合伙、有限合伙、特殊普通合伙、股东协议、借贷、雇佣负触发。

### 2. 主体、书面协议与设立登记

禁入主体红线。书面协议齐第十八条事项。未领执照不得以合伙企业名义经营。

### 3. 出资、企业财产与劳务评估

劳务出资须载明评估办法。非货币出资评估或权属转移未闭合：字段停止。

### 4. 利润亏损与保底

禁止全部利润或全部亏损。保底固定本息转借款。

### 5. 事务执行、内部限权与竞业

内部限权不得对抗善意第三人。竞业不得豁免。

### 6. 入伙退伙、格式条款与强制规范

对外连带不可豁免。永远不得退伙必须改。无核验引文则法律结论字段停止。

### 7. 违约、解散清算与争议

解散必须清算。不选定唯一法院充作意见。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把对外无限连带改成对外免责、把禁入主体改成可登记、或把未领执照对外经营改成可履行。
- `字段停止`：法域、动态规则、前置许可、评估作价、登记材料未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
