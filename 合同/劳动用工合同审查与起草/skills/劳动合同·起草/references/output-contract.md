# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的工资、期限、工时；把已失效《合同法》及其解释写入结论；输出劳动仲裁请求、举证策略或胜率；把劳务/承揽/派遣文本当成已完成的劳动合同审查。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动本类型起草。写明中文成果名称是「劳动合同·起草」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、1994 年每周 44 小时旧文、或把 2007 年劳动合同法未改动条文标成失效时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `劳动关系类合同`，子级 `劳动合同`。定性理由、易混切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、书面合同与文本版本

主体表：签约名、用工名、发薪名、社保缴费名、授权签字人。书面合同闸：是否有完整书面文本、是否约定各执一份、落款日与拟用工日。版本表：正文、附件、offer、员工手册确认页、聊天确认；冲突并列。

## 5. 期限、试用期、报酬与工时

合同期限类型；试用期对照表（合同期限 → 法定上限 → 文本约定 → 判断）；工资构成、支付节点、是否先票后款或离职后迟发；工时种类、日/周工时、休息办法、加班费安排、特殊工时审批痕迹。缺口标 `G#`。不输出加班费或二倍工资终值。

## 6. 违约金、押金与强制规范

劳动者违约金是否落在服务期或竞业两处；押金、证件、保证金；免除法定责任或排除劳动者权利的条款。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和删除句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。框架里的“扩大工作地点”“单方调岗”“降薪续签无固定期限”不得直接当作建议句。

## 9. 谈判与签署提醒

谈判顺序：先红线（书面文本、超期试用、违法违约金、弃加班权/弃社保、押金证件），再必须改，最后可优化。签署提醒：双方签字或盖章、各执一份、日期与用工日、附件清单、特殊工时批复复印件。不指导倒签或补假审批。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本技能交付可编辑草稿、未决项、自审风险表和自审后修改句。草稿必须覆盖本类型起草必写、附件必附与禁止出现。待签评改转 `劳动合同·审查`。不是履约交底、劳动仲裁文书、解除方案或效力保证。

## 起草模式交付

正触发时先交可编辑草稿和未决项，再交自审风险表与自审后修改句。三闸未落入正文或附件的，不得宣称起草完成。
