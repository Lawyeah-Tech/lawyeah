## 节点 3　期限与试用期法定期限

### 3.1 期限类型

固定期限、无固定期限、以完成一定工作任务为期限。文本未选类型或互相冲突：必须改，不擅自选定。

连续订立二次固定期限后的选择权、连续工作满十年：只标红旗并提示核对历次合同，不在本任务决定必须改签无固定期限。法释〔2025〕12 号第十条所列规避续订次数的安排（累计延长期满、自动续延期满、变换签约主体继续管理等）只作告知，不展开续签整案。

### 3.2 试用期对照表（硬闸）

支持依据：劳动合同法第十九条至第二十一条、第八十三条；实施条例第十五条。劳动法第二十一条“最长六个月”不得单独用来放行分档超期。

| 合同期限 | 法定上限 | 不得约定试用期 |
| --- | --- | --- |
| 三个月以上不满一年 | 一个月 | — |
| 一年以上不满三年 | 二个月 | — |
| 三年以上固定期限或无固定期限 | 六个月 | — |
| 不满三个月，或以完成一定工作任务为期限 | — | 是 |
| 同一用人单位与同一劳动者已约定过试用期 | — | 再次约定 |

规则：试用期包含在劳动合同期限内；仅约定试用期的，试用期不成立，该期限为劳动合同期限。

试用期工资：不得低于本单位相同岗位最低档工资或约定工资的百分之八十，并不得低于履行地最低工资。最低工资数字未核验则 `G#`，不编造。

用人单位试用期内解除：除第三十九条和第四十条第一项、第二项外不得解除，并应当说明理由。文本写成“试用期可随时无理由辞退”：必须改。劳动者试用期解除提前三日通知：可保留，不得改成禁止辞职或收违约金。

录用条件未作为附件或未列可核验标准：单位立场标必须改（补录用条件确认书）；劳动者立场标必须改（要求书面、可核验、不得事后补充）。不编造录用条件。

“试用期中止/顺延”：病假、拘留等导致无法考核时，只允许按实际无法考核的期间顺延，且累计仍受法定上限约束。写成任意中止或中止后重新起算：必须改。

超期已履行：告知第八十三条按超过法定试用期的期间支付赔偿金的风险，不算金额。

## 节点 4　工作内容、报酬、工时与加班可核验

### 4.1 必备条款

对照劳动合同法第十七条。缺用人单位名称住所及负责人、劳动者姓名住址及证件号码、期限、工作内容与地点、工作时间和休息休假、劳动报酬、社会保险、劳动保护劳动条件及职业危害防护：列为必须改，给出补句，不编造内容。

工作地点只写“全国”“服从安排”或“单位有权根据经营需要调整岗位及地点”而无范围、条件、补偿和书面变更：必须改。不得把框架里的“扩大化约定”直接写成建议句。变更走第三十五条：协商一致并书面变更。解释（一）第四十三条关于口头变更履行超过一个月的规则，只作履行阶段争点提示，不能用来放行签前的单方任意调岗授权。

### 4.2 劳动报酬

构成、计算基数、支付周期、支付方式、是否含税、代扣代缴分列。未给出的数字写 `【待填】`。

禁止放行：先票后款；离职后若干月才付清工资；以未完成交接拒付应付工资；低于履行地最低工资。工资支付依据运行时核验《工资支付暂行规定》（劳部发〔1994〕489 号，现行有效）及履行地规定。

社会保险不得约定放弃。约定“工资已包含社保、自愿不缴”：红线，删除。

### 4.3 工时与加班（硬闸）

支持依据：劳动合同法第三十一条；劳动法第三十六条、第四十一条、第四十四条；《国务院关于职工工作时间的规定（1995修订）》；劳部发〔1994〕503 号。

审查清单，缺一项则该字段不得写成已合法：

1. 工时种类：标准工时 / 综合计算工时 / 不定时，三者择一写明。
2. 标准工时须写每日、每周时数和休息日；建议对标每日 8 小时、每周 40 小时，并点名劳动法第三十六条与 1995 修订的口径差异。
3. 综合计算工时或不定时：文本或用户材料是否出现劳动行政部门审批、岗位范围、周期或有效期。无审批：现有依据不支持“已实行特殊工时”；修改句改回标准工时，或把特殊工时写成“以届时有效批复载明的岗位和期限为准，批复未覆盖期间按标准工时和法定加班费执行”。
4. 加班：须写延长工时、休息日、法定休假日的安排和对应报酬口径（不低于 150% / 200% / 300%）。劳动法第四十一条的每日一般不超过 1 小时、特殊不超过 3 小时且每月不超过 36 小时，只作文本约束，不算历史加班。
5. “自愿加班不支付加班费”“加班费已包含在工资中且无法拆出正常工时工资”“未事先审批视为放弃加班费”：单位立场可谈审批程序，但不得写成放弃法定加班费；劳动者立场列为红线删除。包干工资须能拆出正常工时工资且不低于最低工资，否则必须改。
6. 本任务不测算加班费终值。用户要算账 → `本任务不测算加班费终值。用户要算账→`。

实务反例（`search_practiced`，非法源）：未依法履行特殊工时审批的，审查和裁判中原则上不按特殊工时减免加班费。该观点只支持“合同不能自创特殊工时”，不写成必然败诉。

## 节点 5　违约金白名单、押金、竞业与培训夹带

### 5.1 劳动者违约金（硬闸）

支持依据：劳动合同法第二十二条至第二十五条；实施条例第十七条、第二十六条。

除第二十二条（专项培训服务期）和第二十三条（竞业限制）外，用人单位不得与劳动者约定由劳动者承担违约金。

| 文本写法 | 动作 |
| --- | --- |
| 提前离职、辞职未提前通知、违反劳动纪律、泄密、损坏设备、未能转正、未能完成业绩而支付违约金或罚款 | 红线；修改句删除；造成损失可另写依法赔偿，不得用违约金替代 |
| 从工资、奖金中直接扣除上述款项 | 红线；删除 |
| 专项培训：有专项培训费用、专业技术培训、服务期、违约金不超过尚未分摊的培训费 | 可留在本合同或剥离到 `培训服务期协议·审查`；费用、发票、分摊方法未写清则必须改，数字用 `【待填】` |
| 入职培训、岗前培训、规章制度学习而收违约金 | 现有依据不支持属于第二十二条；按白名单外删除 |
| 竞业：人员范围、地域、期限不超过二年、解除或终止后按月补偿 | 整段交接 `竞业限制协议·审查` 或 `C端大众竞业风险快检只要不定效力的风险提示`，本任务不判效力；无补偿或对象明显是普通无保密义务岗位：标红旗并建议删除或剥离，仍不写“当然无效” |
| 脱密期限制离职后就业 | 按竞业专章剥离，不采用框架“最长六个月脱密期”当建议 |

劳动者依第三十八条解除的，实施条例第二十六条第一款：不属于违反服务期，单位不得要违约金。本任务只在服务期条款里加除外提示，不判断是否已具备第三十八条。

### 5.2 押金与证件

劳动合同法第九条：不得扣押居民身份证和其他证件，不得要求提供担保或以其他名义收取财物。定金、订金、保证金、服装押金、工牌押金：红线删除。劳动合同不是民事定金场景，不适用民法典定金罚则。

### 5.3 保密

可约定保密事项。普通保密条款出现劳动者违约金：按 5.1 删除。未付保密费不等于保密义务不成立，不得写成“没给保密费所以无效，可以随便签”。

## 节点 6　变更、解除、终止与强制规范

### 6.1 变更

第三十五条：协商一致，书面变更，变更后文本各执一份。单方“有权随时调岗、调薪、调地点”：必须改。解释（一）第四十三条不代替签前书面变更纪律。

实施条例第十三条：不得在第四十四条规定的终止情形之外约定其他终止条件。“自动离职视为解除且不支付任何工资或补偿”：红线。框架“因劳动者原因解除并由其提交辞职书”可作单位侧优化句，不得写成逼签辞职。

### 6.2 解除条款

法定路径只点名，不在本任务作出已解除结论，不设计解除方案。

- 过错解除：可列严重违反规章制度的具体、可核验情形，并回链已公示制度；不得用空白授权“以公司认定为准”。
- 无过失解除、经济性裁员：不得改成比第四十条、第四十一条更宽松的单位任意解除。
- 交接可写流程，不得写成“未交接完可不发已提供劳动的工资”。
- “降薪续签无固定期限以降低解除成本”：禁止作为本任务建议。

### 6.3 强制规范与部分无效

劳动合同法第二十六条、第二十七条：欺诈胁迫或乘人之危；用人单位免除自己法定责任、排除劳动者权利；违反法律、行政法规强制性规定。部分无效不影响其他部分。无效或部分无效有争议的，由劳动争议仲裁机构或人民法院确认——本任务只给修改句，不宣告整份无效。

就业服务与就业管理规定（2022 修订）第十六条：不得约定限制女职工结婚、生育。出现结婚、怀孕即解雇或退还培训费：红线删除。

## 起草模式与自审

本任务是起草。有完整待签文本要评改时转 `劳动合同·审查`。
按框架六步落稿，必须写入下列三闸。出稿后按上文审查节点自审自己的稿，未过不得宣称完成。

### 起草必写

- 标题用「劳动合同」；用人单位名称、住所、负责人与劳动者姓名、住址、证件号码写全。
- 正文必须是双方签字或盖章的书面合同，载明各执一份；落款日与拟用工日对照，不得倒签。
- 合同期限写明固定期限、无固定期限或以完成一定工作任务为期限；未选类型不得出稿。
- 试用期按合同期限分档写入法定上限，并写明包含在合同期限内、同一用人单位与同一劳动者只约定一次；不满三个月或任务制合同不写试用期。
- 工作内容与地点写到可核验范围；变更走书面协商，不得写成单位有权随时任意调岗调地点。
- 工资构成、计算基数、支付周期与方式写清；未给数字用 `【待填】`；不得低于履行地最低工资。
- 工时种类（标准 / 综合计算 / 不定时）择一写明；标准工时写每日、每周时数和休息办法；延长工时、休息日、法定休假日加班费口径分别落句。
- 社会保险必须写用人单位依法缴纳，不得写成放弃或工资已包含。
- 劳动保护、劳动条件及职业危害防护按第十七条必备项补句。
- 争议条款只写依法申请劳动争议仲裁，恢复履行地或用人单位所在地法定连结点。

### 附件必附

- 约定试用期的，附可核验的录用条件确认书。
- 职位说明书。
- 正文引用规章制度的，附员工手册确认页。
- 约定综合计算工时或不定时的，附届时有效批复复印件；无批复则改回标准工时，或写明批复未覆盖期间按标准工时和法定加班费执行。

### 禁止出现

- 白名单外由劳动者承担的违约金、罚款或从工资直接扣除（提前离职、保密、迟到、损坏、入职培训等）。
- 扣押证件、收取定金、订金、保证金或入职押金。
- 「自愿加班不支付加班费」「加班费已包含且无法拆出正常工时工资」或放弃法定加班费。
- 试用期可随时无理由辞退；仅约定试用期；已约定过试用期再写一次。
- 阴阳两份工资、弃社保、先票后款、离职后若干月才付清已提供劳动的工资。
- 商事仲裁、国际仲裁或「排除劳动仲裁直接起诉」。
- 把本约写成劳务、承揽或派遣外观。
