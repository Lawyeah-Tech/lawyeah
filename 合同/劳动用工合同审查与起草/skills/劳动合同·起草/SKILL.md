# 劳动合同·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **劳动关系类合同 / 劳动合同**，输出可编辑草稿、未决项，并用本类型硬闸自审后给出风险表和修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。显示名为「劳动合同·起草」。待签评改转 `劳动合同·审查`，以区别劳动争议套件。

`depends-on` 为空。不要求先跑导航。

不交付：他类型起草、待签文本签前审查、履约交底、劳动仲裁策略或争议文书、解除补偿或加班费终值、有效性保证。

## 本类型硬闸

1. **书面合同**：建立劳动关系应当订立书面劳动合同。必须落成双方签字或盖章的书面文本；条件未齐用 `【待填】`，不得倒签出可签署终稿。
2. **试用期法定期限**：按合同期限分档核对；同一用人单位与同一劳动者只能约定一次；不满三个月或以完成一定工作任务为期限的，不得约定试用期；仅约定试用期的，试用期不成立。
3. **违约金白名单**：劳动者承担违约金仅限专项培训服务期与竞业限制。提前离职、保密、迟到、损坏、培训以外的“违约金/罚款/从工资扣除”列为红线并给出删除句。
4. **加班与工时制度可核验**：必须写明工时种类、日/周工时、休息办法和加班费安排。综合计算工时或不定时须有审批痕迹，否则不得写成已合法实行；“自愿加班不支付加班费”不得放行。
5. **不审劳动仲裁策略**：争议条款只改法定管辖写法。不写请求、举证、时效计算、应诉策略或“怎么赢”。
6. **已解除或已成争**转劳动领域，不继续当签前审查。
7. **劳务 / 承揽 / 派遣**文本负触发，不按本类型改完。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿；尚未签署，尚未成争；核心给付是劳动力给付并接受用工管理；用户要一份可签署草稿。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 有完整待签文本要评改 → `劳动合同·审查`；
- 核心给付是平等劳务、成果承揽、派遣或外包派人 → `个人劳务（雇佣）合同·审查` / `个人劳务（雇佣）合同·起草` / `承揽合同（个人劳务）·审查` / `承揽合同（个人劳务）·起草` / `劳务派遣协议·审查` / `劳务派遣协议·起草` / `业务外包（派遣型）合同·审查` / `业务外包（派遣型）合同·起草`，或回 本套导航的类型切开步骤 重新定性；
- 非全日制、退休返聘、学生实习、平台用工 → `非全日制劳动合同·审查` / `非全日制劳动合同·起草` / `退休返聘合同·审查` / `退休返聘合同·起草` / `学生实习协议·审查` / `学生实习协议·起草` / `平台用工相关协议·审查` / `平台用工相关协议·起草`；
- 主轴是单独的培训服务期或竞业限制协议 → `培训服务期协议·审查` / `培训服务期协议·起草` / `竞业限制协议·审查` / `竞业限制协议·起草`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已解除、已催告、已索赔、已申请仲裁或起诉 → 劳动领域对应原子，不审仲裁策略。

阴阳合同、扣押证件、收取押金或保证金、弃社保：只出告知与删除/改正句，不改写成可履行规避结构。

## 建立起草坐标

确认：使用者与授权；单方立场；相对方；已谈妥的期限与试用期、工时制度、工资构成；不可接受事项；法域与拟签署日。缺立场不启动。条件未谈妥的商业数字用 `【待填】`，不编造。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的工资、期限、工时用 `【待填】`，不编造。

## 起草模式

本原子只承担本类型起草。有完整待签文本要评改时，转 `劳动合同·审查`。本类型条件已谈妥、要出己方稿时，留在本任务按三闸落稿并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。按下文明示清单把本类型硬闸写成正文必写、附件必附或禁止出现。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 标题用「劳动合同」；用人单位名称、住所、负责人与劳动者姓名、住址、证件号码写全。
- 正文必须是双方签字或盖章的书面合同，载明各执一份；落款日与拟用工日对照，不得倒签。
- 合同期限写明固定期限、无固定期限或以完成一定工作任务为期限；未选类型不得出稿。
- 试用期按合同期限分档写入法定上限，并写明包含在合同期限内、同一用人单位与同一劳动者只约定一次；不满三个月或任务制合同不写试用期。
- 工作内容与地点写到可核验范围；变更走书面协商，不得写成单位有权随时任意调岗调地点。
- 工资构成、计算基数、支付周期与方式写清；未给数字用 `【待填】`；不得低于履行地最低工资。
- 工时种类（标准 / 综合计算 / 不定时）择一写明；标准工时写每日、每周时数和休息办法；延长工时、休息日、法定休假日加班费口径分别落句。
- 社会保险必须写用人单位依法缴纳，不得写成放弃或工资已包含。
- 劳动保护、劳动条件及职业危害防护按第十七条必备项补句。
- 争议条款只写依法申请劳动争议仲裁，恢复履行地或用人单位所在地法定连结点。

### 附件必附

- 约定试用期的，附可核验的录用条件确认书。
- 职位说明书。
- 正文引用规章制度的，附员工手册确认页。
- 约定综合计算工时或不定时的，附届时有效批复复印件；无批复则改回标准工时，或写明批复未覆盖期间按标准工时和法定加班费执行。

### 禁止出现

- 白名单外由劳动者承担的违约金、罚款或从工资直接扣除（提前离职、保密、迟到、损坏、入职培训等）。
- 扣押证件、收取定金、订金、保证金或入职押金。
- 「自愿加班不支付加班费」「加班费已包含且无法拆出正常工时工资」或放弃法定加班费。
- 试用期可随时无理由辞退；仅约定试用期；已约定过试用期再写一次。
- 阴阳两份工资、弃社保、先票后款、离职后若干月才付清已提供劳动的工资。
- 商事仲裁、国际仲裁或「排除劳动仲裁直接起诉」。
- 把本约写成劳务、承揽或派遣外观。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`基本面.md` 中“适用非全日制”及劳务派遣主体段落不作为本技能正触发依据。`框架.md` 中扩大工作地点、单方调岗、降薪续签无固定期限、脱密期，按 method 当作审查风险或禁止建议，不当作默认改法。

### 0. 签署状态与成果分流

本类型条件已谈妥、要出己方稿 → 留本任务按三闸落稿并自审；有完整待签文本要评改 → `劳动合同·审查`；已签履约 → 本套导航的履约步骤；已成争 → 劳动领域。

### 1. 类型锁死

标题、核心给付与从属信号一致才继续。劳务、承揽、派遣负触发。

### 2. 主体与书面合同

签约名、用工名、发薪名分列。书面订立、文本各执一份、日期与用工日对照。

### 3. 期限与试用期

固定 / 无固定 / 完成一定任务；试用期分档、一次性和包含在期限内。

### 4. 报酬、工时、加班

工资构成与支付节点；工时种类可核验；特殊工时看审批；加班费安排不得弃权。

### 5. 违约金、押金、竞业与培训夹带

白名单外删除；押金证件红线；竞业或专项培训专章可剥离到对应原子，本任务不判竞业效力。

### 6. 变更、解除、强制规范

单方任意调岗降薪、自动离职、排除法定权利：必须改或红线。不把约定终止条件扩出法定情形。

### 7. 争议条款

劳动仲裁法定管辖。出现商事仲裁或排除劳动仲裁：必须改。不写仲裁策略。

### 8. 按框架六步落稿并自审

必须先出草稿，再出自我审查的风险表和修改句。不得只交白稿。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；条件未谈妥仍要编造数字出可签署终稿；用户坚持倒签、阴阳合同、弃社保、把违法违约金或弃加班权改成可履行结构、保证有效。
- `字段停止`：法域、动态规则、特殊工时审批、历史试用次数或连续合同次数未核验。
- `目标停止`：主目标已变为待签评改、履约交底、劳动仲裁策略或解除整案。
