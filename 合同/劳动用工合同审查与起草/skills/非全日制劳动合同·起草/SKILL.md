# 非全日制劳动合同·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。引用劳动合同法第六十八至七十二条时，使用 2012 年修正、2013-07-01 施行文本；2012 年修正未改这些条文文字的，不得把 2007 文本标成失效。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **劳动关系类合同 / 非全日制劳动合同**，输出可编辑草稿、未决项，并用本类型硬闸自审后给出风险表和修改句。签署方为用人单位与劳动者。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。显示名为「非全日制劳动合同·起草」。待签评改转 `非全日制劳动合同·审查`。本技能不代替起草或审查全日制劳动合同（那是 `劳动合同·起草` / `劳动合同·审查`），也不代替起草或审查个人劳务（那是 `个人劳务（雇佣）合同·起草` / `个人劳务（雇佣）合同·审查`）。

`depends-on` 为空。不要求先跑导航。

不交付：全日制劳动合同起草或审查、个人劳务起草或审查、他类型起草、待签文本签前审查、履约交底、劳动仲裁或工伤索赔策略、解除补偿终值、有效性保证、把超工时非全改写成可履行全日制结构。

## 本类型硬闸

1. **每日平均≤4 小时**：同一用人单位一般平均每日工作时间不超过四小时。出现“视生产需要加班”“排满上午下午”“日均 6/8 小时”：必须改或红线。
2. **每周累计≤24 小时**：每周工作时间累计不超过二十四小时。周工时沉默、可被排满或与日工时相乘已超 24：必须改。
3. **小时工资**：以小时计酬为主；必须写明元/小时；不得低于用人单位所在地人民政府规定的最低小时工资标准；结算支付周期最长不得超过十五日。禁止月薪主路径，禁止按月发放。
4. **终止**：任何一方均可随时通知对方终止用工；终止用工用人单位不支付经济补偿。禁止套用全日制“提前三十日通知 / N+1 / 违法解除 2N”。通知建议留书面或电子痕迹，但不把“随时”改成必须预告期满才生效。
5. **与全日制 `劳动合同·审查` / 劳务 `个人劳务（雇佣）合同·审查` 切开**：日 8 / 周 40、月薪、试用期按第十九条分档 → 负触发 `劳动合同·审查`。平等主体、按件或按项目验收、不接受劳动规章 → 负触发 `个人劳务（雇佣）合同·审查`。标题非全但工时或管理已是全日制：留本任务点名假非全；**禁止**把第十九条试用期分档写成主路径；**禁止**在本任务改成全日制劳动合同正文。

配套约束：非全日制不得约定试用期——出现试用期只删除，不按合同期限分档核对。各用人单位应为非全日制从业人员缴纳工伤保险。劳务派遣单位不得以非全日制招用被派遣劳动者。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。禁止把日 4 / 周 24 / 15 日结算写成倡导性可忽略。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿；尚未签署，尚未成争；核心给付是小时计酬的非全日制劳动；用户要一份可签署草稿。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 有完整待签文本要评改 → `非全日制劳动合同·审查`；
- 核心给付是全日制从属劳动（日 8 / 周 40、月薪、试用期分档）→ `劳动合同·审查` / `劳动合同·起草`；
- 平等主体个人劳务、按件验收、不接受劳动规章 → `个人劳务（雇佣）合同·审查` / `个人劳务（雇佣）合同·起草`；
- 劳务派遣单位与用工单位的商事派遣协议 → `劳务派遣协议·审查` / `劳务派遣协议·起草`；
- 个人承揽、按成果交付 → `承揽合同（个人劳务）·审查` / `承揽合同（个人劳务）·起草`；
- 已享受养老保险待遇或达到法定退休年龄的返聘 → `退休返聘合同·审查` / `退休返聘合同·起草`；
- 在校学生实习 → `学生实习协议·审查` / `学生实习协议·起草`；
- 平台用工、网约协议 → `平台用工相关协议·审查` / `平台用工相关协议·起草`；专业版未装则 `unavailable`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问排班、打卡、发薪日履约 → 本套导航的履约步骤；
- 已申请劳动仲裁、工伤索赔、立案、开庭 → 劳动领域对应原子，不审仲裁或工伤策略。

假非全（标题非全，正文日 8 / 月薪 / 全日制考勤）：留本任务，点名红旗，按本类型硬闸改工时、计酬和终止；用户改口要一份全日制劳动合同 → 整段交接 `劳动合同·审查`，本任务不写第十九条分档。

派遣单位以非全日制招用被派遣劳动者：红线告知实施条例第三十条，不改成可履行派遣非全。

## 建立起草坐标

确认：使用者与授权；单方立场（用人单位或劳动者择一）；相对方；已谈妥的岗位与排班、日均/周累计工时、小时工资与履行地、结算周期、终止条款、工伤安排；不可接受事项；法域与拟签署日。缺立场不启动。条件未谈妥的商业数字用 `【待填】`，不编造。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 起草模式

本原子只承担本类型起草。有完整待签文本要评改时，转 `非全日制劳动合同·审查`。本类型条件已谈妥、要出己方稿时，留在本任务按三闸落稿并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。按下文明示清单把本类型硬闸写成正文必写、附件必附或禁止出现。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 标题用「非全日制劳动合同」；签署方为用人单位与劳动者。
- 正文写明同一用人单位一般平均每日工作时间不超过四小时。
- 正文写明每周工作时间累计不超过二十四小时；排班与日工时乘积不得突破该上限。
- 以小时计酬，写明元/小时，不得低于用人单位所在地最低小时工资；结算支付周期最长不超过十五日。
- 任何一方可随时通知对方终止用工；终止用工用人单位不支付经济补偿。通知建议留书面或电子痕迹，但不把「随时」改成必须预告期满才生效。
- 各用人单位为非全日制从业人员缴纳工伤保险。
- 后订立的非全日制合同不得影响先订立合同的履行。

### 附件必附

- 工作时间确认表或排班表，用以核对日均四小时与周累计二十四小时。
- 工伤参保安排说明或凭证栏目。
- 履行地最低小时工资未核验时，小时工资用 `【待填】` 并在未决项标明待核。

### 禁止出现

- 试用期；不得按劳动合同法第十九条分档核对或改写。
- 月薪主路径、按月发放工资。
- 「视生产需要加班」「排满上午下午」或日均六/八小时、日八/周四十的全日制工时。
- 提前三十日通知、N+1、违法解除 2N 等全日制解除结构。
- 劳务派遣单位以非全日制招用被派遣劳动者。
- 把本约改成全日制劳动合同正文或个人劳务协议。

### 0. 签署状态与成果分流

本类型条件已谈妥、要出己方稿 → 留本任务按三闸落稿并自审；有完整待签文本要评改 → `非全日制劳动合同·审查`；已签履约 → 本套导航的履约步骤；已成争 → 劳动领域。法律允许口头协议，不等于可以跳过书面落稿和自审。

### 1. 类型锁死与切开

标题、签署方与核心给付一致才继续。全日制劳动合同负触发 `劳动合同·审查`。个人劳务负触发 `个人劳务（雇佣）合同·审查`。假非全留本任务并点名。

### 2. 日均工时≤4 小时

写明一般平均每日不超过四小时。加班开口或日 6/8 必须改或红线。

### 3. 每周累计≤24 小时

写明每周累计不超过二十四小时。与日工时乘积或排班已超则必须改。

### 4. 小时工资与十五日结算

元/小时；对照履行地最低小时工资；结算周期≤15 日。月薪主路径必须改。

### 5. 终止用工

随时通知终止；不支付经济补偿。删除 30 日预告和 N+1。

### 6. 试用期只删除、工伤与多重关系

出现试用期一律删除，不套第十九条。工伤各单位缴纳。后订立合同不得影响先订立合同。

### 7. 争议条款

劳动争议依法仲裁。不审策略。

### 8. 按框架六步落稿并自审

必须先出草稿，再出自我审查的风险表和修改句。不得只交白稿。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；条件未谈妥仍要编造数字出可签署终稿；用户坚持超日 4 / 周 24 仍按非全放行、把假非全改成可履行全日制并套第十九条、弃工伤、保证有效、倒签或伪造工时确认表。
- `字段停止`：法域、履行地最低小时工资数字、工伤参保凭证、他单位合同是否影响先合同未核验。
- `目标停止`：主目标已变为待签评改、履约交底、全日制劳动合同审查、个人劳务审查、劳动仲裁或工伤策略。
