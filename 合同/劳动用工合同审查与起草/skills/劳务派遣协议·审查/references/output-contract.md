# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的人数、费率、期限；把已失效《合同法》及其解释或 2007 年第五十七条五十万写入结论；输出劳动仲裁请求、工伤索赔策略或胜率；把本协议改成劳动合同正文；把无证派遣改写成劳务外包；把三性或 10% 写成倡导性可忽略。

## 1. 触发、单方立场与成果状态

立场（派遣单位或用工单位）、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「劳务派遣协议·审查」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、2007 年第五十七条五十万旧文、或把 2012 年未改动的第六十二、六十五条标成失效时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `劳动关系类合同`，子级 `劳务派遣协议`。定性理由、易混切开结果（尤其与 `劳动合同·审查` 劳动合同的切开）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、许可证与文本版本

主体表：派遣单位签约名、用工单位签约名、付款名、发票名、授权签字人。许可证闸：编号、发证机关、有效期、注册资本是否≥200 万元、是否见到许可证记载。版本表：正文、岗位说明书、费用清单、被派遣劳动者名册、许可证复印件、职代会/公示材料；冲突并列。未见许可证：签署能力字段停止，不得写“可以派”。

## 5. 岗位、比例、费用与退回

岗位名称与三性定性；辅助性民主程序痕迹；拟派人数与用工总量、10% 对照；工资/社保/管理费是否分列；同工同酬安排；退回情形是否限于法定或约定合法事由；告知与二年期劳动合同义务是否写入。缺口标 `G#`。不输出罚款或赔偿终值。

## 6. 强制规范与内部追偿

无证、超三性、超 10%、再派遣、自我派遣、向劳动者收费、克扣工资、随时退回。协议中“责任自负、与对方无关”不得写成已切断对劳动者的法定连带。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和删除句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把框架“先款后薪”写成可放行克扣；不得把本协议改写成劳动合同条款。

## 9. 谈判与签署提醒

谈判顺序：先红线（无证、超三性、随时退回、包干克扣、假外包规避），再必须改（10% 陈述、费用分列、告知与二年合同、辅助性程序），最后可优化。签署提醒：许可证复印件作为附件、岗位三性与辅助性公示材料、10% 计算底稿、费用清单、双方盖章及授权代表签字。不指导倒签、补假许可证或补假职代会纪要。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本技能只出审查意见和修改句，不出整份起草终稿；出稿转 `劳务派遣协议·起草`。不是履约交底、劳动者劳动合同审查、劳动仲裁或工伤文书、效力保证。
