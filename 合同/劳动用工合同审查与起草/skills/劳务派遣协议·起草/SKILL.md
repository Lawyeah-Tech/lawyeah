# 劳务派遣协议·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。引用劳动合同法第五十七至六十七、九十二条时，使用 2012 年修正、2013-07-01 施行文本；2007 年第五十七条“注册资本五十万元”不得写入结论。2012 年修正未改第六十二、六十五条文字的，不得把 2007 文本标成失效。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **劳动关系类合同 / 劳务派遣协议**，输出可编辑草稿、未决项，并用本类型硬闸自审后给出风险表和修改句。签署方为劳务派遣单位与用工单位。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。显示名为「劳务派遣协议·起草」。待签评改转 `劳务派遣协议·审查`。本技能不代替起草或审查劳动者劳动合同（那是 `劳动合同·起草` / `劳动合同·审查`）。

`depends-on` 为空。不要求先跑导航。

不交付：劳动者劳动合同起草或审查、他类型起草、待签文本签前审查、履约交底、劳动仲裁或工伤索赔策略、解除补偿终值、有效性保证、无证派遣或假外包可履行结构。

## 本类型硬闸

1. **许可证**：派遣单位须《劳务派遣经营许可证》+ 注册资本≥200 万元。未见许可证：签署能力字段停止，不得写“可以派”。无证经营派遣：红线/告知，不改成可履行无证派遣。
2. **三性岗位**：仅临时性（存续不超过 6 个月）、辅助性、替代性。超范围岗位：必须改或红线。辅助性须职代会或全体职工讨论并公示——口头“都是辅助岗”不得写成已履行民主程序。
3. **10% 比例**：被派遣劳动者不得超过用工总量 10%。文本沉默：用工单位侧必须改，写入陈述与超比例责任。
4. **假外包真派遣**：外包方不管理业务、人完全服从用工单位指挥：按派遣审，或负触发后仍点名该红旗。禁止把无证派遣改写成“劳务外包”以规避许可。
5. **同工同酬 + 费用拆分**：工资、社会保险费、管理费分列。禁止“管理费包干、工资随便发”。克扣工资造成损害时派遣单位与用工单位连带（劳动合同法第九十二条）。
6. **退回限制**：只能依法定或约定合法情形退回。禁止“用工单位随时退回且不承担费用”。非法退回导致违法解除的连带风险必须上风险表。
7. **告知与二年合同**：派遣单位应告知协议内容；与劳动者订立二年以上固定期限劳动合同。本技能不审劳动者劳动合同正文，但本协议若与该项冲突必须改。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。禁止把三性、10% 写成倡导性可忽略。禁止把本协议改成劳动合同正文。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿；尚未签署，尚未成争；核心给付是派遣单位派人、用工单位指挥监督；用户要一份可签署草稿。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 有完整待签文本要评改 → `劳务派遣协议·审查`；
- 核心给付是劳动者与用人单位的全日制劳动合同 → `劳动合同·审查` / `劳动合同·起草`；
- 非全日制、小时工 → `非全日制劳动合同·审查` / `非全日制劳动合同·起草`；
- 平等主体个人劳务 → `个人劳务（雇佣）合同·审查` / `个人劳务（雇佣）合同·起草`；
- 个人承揽、按成果交付 → `承揽合同（个人劳务）·审查` / `承揽合同（个人劳务）·起草`；
- 长期运输供人、承运人派司机随车 → `长期运输供人承运人派司机随车→`；专业版未装则 `unavailable`；
- 标题外包但外包方实际管理业务、按成果验收 → 转 本套导航的类型切开步骤 或 `业务外包（派遣型）合同·审查` / `业务外包（派遣型）合同·起草`（未装则 `unavailable`）；标题外包但人完全服从用工单位指挥 → 留本任务并点名假外包红旗；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问排班、付款日、人员名册履约 → 本套导航的履约步骤；
- 已申请劳动仲裁、工伤索赔、立案、开庭 → 劳动领域对应原子，不审仲裁或工伤策略。

无证派遣、出租出借许可证、向所属单位自我派遣、再派遣：只出告知与红线，不改写成可履行规避结构。

## 建立起草坐标

确认：使用者与授权；单方立场（派遣单位或用工单位择一）；相对方；已谈妥的许可证编号与有效期、注册资本、岗位与拟派人数、用工总量、费用分列、退回条款；不可接受事项；法域与拟签署日。缺立场不启动。条件未谈妥的商业数字用 `【待填】`，不编造。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的人数、费率、期限用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验许可证与注册资本、三性、10%、退回、同工同酬、第九十二条连带；`search_practiced` 只补审查反例，不写办案策略；`search_template` 只借派遣单位与用工单位协议的栏目结构，不得粘贴劳动者劳动合同范本。不虚构案件系统。

`search_law` 对上述法律结论为 required 级：不可用时不拒绝执行，只停止效力字段。返回已失效《合同法》或其解释、2007 年第五十七条五十万旧文时记为噪声，不得写入 `L#`。


## 起草模式

本原子只承担本类型起草。有完整待签文本要评改时，转 `劳务派遣协议·审查`。本类型条件已谈妥、要出己方稿时，留在本任务按三闸落稿并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。按下文明示清单把本类型硬闸写成正文必写、附件必附或禁止出现。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 标题用「劳务派遣协议」；签署方只写劳务派遣单位与用工单位，不写成劳动者劳动合同。
- 派遣单位《劳务派遣经营许可证》编号、发证机关、有效期和注册资本不少于二百万元写入首部或鉴于；未见许可证不得出可派稿。
- 岗位逐一写明临时性（存续不超过六个月）、辅助性或替代性；辅助性必须写职代会或全体职工讨论并公示；替代性写被替代事由。
- 拟派人数、用工总量口径和被派遣劳动者不超过用工总量百分之十写入正文，并写超比例责任。
- 工资、社会保险费、管理费分列；同工同酬安排落句。
- 退回仅限法定或约定合法情形；写明非法退回导致违法解除时的内部费用与连带风险，不得切断对劳动者的法定连带。
- 派遣单位告知本协议内容的义务，以及与被派遣劳动者订立二年以上固定期限劳动合同的陈述。
- 用工单位不得再派遣；克扣工资造成损害时派遣单位与用工单位连带，内部追偿不得对抗劳动者。

### 附件必附

- 《劳务派遣经营许可证》复印件。
- 《岗位说明书》（含三性定性）。
- 《劳务费清单》或费用分列清单。
- 《被派遣劳动者名册》。
- 辅助性岗位的职代会或公示材料；无材料则不得把该岗写成已履行民主程序。

### 禁止出现

- 无证经营派遣、出租出借许可证、向所属单位自我派遣或再派遣的可履行结构。
- 把无证派遣改写成「劳务外包」以规避许可。
- 超三性岗位、口头「都是辅助岗」充作民主程序。
- 「用工单位随时退回且不承担费用」。
- 「管理费包干、工资随便发」或把三性、百分之十写成倡导性可忽略。
- 把本协议改成劳动合同正文。

### 0. 签署状态与成果分流

本类型条件已谈妥、要出己方稿 → 留本任务按三闸落稿并自审；有完整待签文本要评改 → `劳务派遣协议·审查`；已签履约 → 本套导航的履约步骤；已成争 → 劳动领域。

### 1. 类型锁死

标题、签署方与核心给付一致才继续。劳动者劳动合同、非全日制、个人劳务、承揽、运输供人负触发。假外包按派遣审并点名红旗。

### 2. 主体与许可证

签约名、派遣名、用工名分列。许可证编号、有效期、注册资本。未见许可证不得写“可以派”。

### 3. 岗位三性与民主程序

临时性不超过 6 个月；辅助性须程序痕迹；替代性须被替代事由。超范围必须改或红线。

### 4. 10% 比例

用工总量口径；文本沉默则用工单位侧必须改。

### 5. 费用拆分、同工同酬与连带

工资、社保、管理费分列；禁止包干克扣；内部追偿不得对抗劳动者。

### 6. 退回、再派遣与工伤费用

合法退回情形；随时退回红线；用工单位不得再派遣；工伤申报与内部补偿。

### 7. 告知、二年合同与争议条款

协议须写告知义务和二年期劳动合同陈述；与该项冲突必须改。争议条款改写法，不审策略。

### 8. 按框架六步落稿并自审

必须先出草稿，再出自我审查的风险表和修改句。不得只交白稿。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；条件未谈妥仍要编造数字出可签署终稿；用户坚持无证仍“可以派”、把无证派遣改成外包、伪造许可证、把随时退回或包干克扣改成可履行结构、保证有效。
- `字段停止`：法域、许可证真伪、辅助性民主程序、用工总量或动态规则未核验。
- `目标停止`：主目标已变为待签评改、履约交底、劳动者劳动合同审查、劳动仲裁或工伤策略。
