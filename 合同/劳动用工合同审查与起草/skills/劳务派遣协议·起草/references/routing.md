# 边界与路由

本技能只起草 **劳动关系类合同 / 劳务派遣协议**。签署方是劳务派遣单位与用工单位。显示名是「劳务派遣协议·起草」。待签评改转 `劳务派遣协议·审查`。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 全日制劳动合同、用人单位与劳动者两方签约 | `劳动合同·审查`。本任务不审试用期、第十九条分档或劳动者劳动合同正文 |
| 非全日制、小时工、每日平均不超过四小时 | `非全日制劳动合同·审查` |
| 个人劳务、雇佣协议、平等提供劳务 | `个人劳务（雇佣）合同·审查` |
| 个人承揽、按成果交付、不接受考勤管理 | `承揽合同（个人劳务）·审查` |
| 长期运输供人、承运人派司机随车 | `长期运输供人承运人派司机随车→`；专业版未装则 `unavailable` |
| 标题外包且外包方实际管理业务、按成果验收 | `业务外包（派遣型）合同·审查` 或回引擎重新定性；专业版未装则 `unavailable`，不得用本技能硬套成可履行外包 |
| 标题外包但外包方不管理业务、人完全服从用工单位指挥 | 留本任务；点名假外包红旗；禁止改写成外包以规避许可 |
| 向本单位或所属单位自我派遣、转派遣 | 本任务红线告知，不改写成可履行结构 |
| 有完整待签文本要评改 | `劳务派遣协议·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、只问排班、付款日、名册履约 | 本套导航的履约步骤 |
| 已申请或拟申请劳动仲裁、要证据或应诉策略 | `已申请或拟申请劳动仲裁要证据或应诉策略` / `劳动仲裁证据整理` / `继续当签前审查；输出仲裁策略`。本技能不审仲裁策略 |
| 工伤索赔整案 | `工伤索赔整案` 或劳动领域对应原子。本协议只审工伤申报与内部费用约定 |
| 已成争的普通合同路径 | `已成争的普通合同路径` 或劳动领域，不继续签前审查 |
| C 端大众快检 | 只分流，不回改 |

本协议夹带劳动者劳动合同附件：附件整段交接 `劳动合同·审查`；协议正文继续审。用户坚持本技能给出劳动者合同效力、仲裁胜率或工伤赔付终值：`目标停止`。
