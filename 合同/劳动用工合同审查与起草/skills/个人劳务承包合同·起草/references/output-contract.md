# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的承包款、人数、保单号；把已失效《合同法》及其解释写入结论；把建筑或强制准入作业发包给个人写成已经可履行；把伤亡或欠薪绝对免责改成可履行。

## 1. 触发、单方立场与成果状态

立场（发包企业／承包自然人择一）、授权、签署状态、主要目标。负触发写完整 Skill ID 路由，不启动实体审查。P1 未装写 `unavailable`。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、2003 年人身损害解释第十一条、1997 年建筑法未对照 2019 修正时记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级劳动关系类合同、子级个人劳务承包合同、定性理由、与劳动合同／个人劳务／个人承揽／企业外包／派遣的切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读其他类型。建筑分包、挂靠、强制准入发包给个人写停笔告知，不填可履行结构。

## 4. 主体、选任、授权与文本版本

主体表：发包企业、承包自然人（包工头）、班组劳务人员（非本约相对方）、签约名、付款名、授权签字人。选任表：技能与经验审核记录是否被要求、有无冒用单位名义、作业是否强制准入。版本表：正文、工作量清单、花名册、安全交底、保险安排；冲突并列，不选对用户有利的一版。

## 5. 给付闭环

作业范围与计量单位、管理界面（只对包工头发令）、自备小型工具、固定单价／总价、验收与结算节点、代发是否写成受托支付、工资／劳务费保证金。缺口标 `G#`，不补商业数字。选任审核、安全交底、保险投保写成生效或进场条件，不写成已经完成。

## 6. 强制规范与格式条款

作业是否落入建筑施工或强制准入；伤亡绝对免责是否出现；法定连带／清偿是否被合同排除；是否构成格式条款；提示说明痕迹。强制规范只区分行政管理后果、民事无效与对外仍可能连带。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔／转出口径。禁止输出无修改句的色块表。定性切开、资质／安全、隔离墙或欠薪三类至少各有一行可回链，除非该事实确定不存在并写明依据。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`，不编造。禁止只给原则、不给句子。定性句、伤亡分层句、隔离墙句不得用“建议注意合规”代替。

## 9. 谈判与签署提醒

谈判顺序：先红线（建筑／强制准入、伤亡绝对免责、劳动或个人承揽结构），再必须改，最后可优化。签署提醒：身份证复印件与指印、花名册、计价单、安全生产责任书、知情确认书、保险凭证、选任记录、日期真实。不指导倒签或补假资质。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本技能交付可编辑草稿、未决项、自审风险表和自审后修改句。草稿必须覆盖本类型起草必写、附件必附与禁止出现。待签评改转 `个人劳务承包合同·审查`。不是履约交底、争议文书、工伤或欠薪诉讼策略或效力保证。

## 起草模式交付

正触发时先交可编辑草稿和未决项，再交自审风险表与自审后修改句。三闸未落入正文或附件的，不得宣称起草完成。
