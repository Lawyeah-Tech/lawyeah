# 边界与路由

本技能只起草 **劳动关系类合同 / 个人劳务承包合同**。显示名是「个人劳务承包合同·起草」。待签评改转 `个人劳务承包合同·审查`。场景分层为 P1：专业版未装则 `unavailable`，提示，不得用邻类硬套。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 企业直接考勤奖惩、固定月薪、入职试用、人格组织经济从属 | `劳动合同·审查` |
| 自然人亲自提供劳务过程，无班组招用 | `个人劳务（雇佣）合同·审查` |
| 个人独立完成并交付特定工作成果（设计、加工、软件、宣传片） | `承揽合同（个人劳务）·审查`。P1：未装则 `unavailable` |
| 承包方是独立法人或组织，按项目整体外包 | `业务外包（派遣型）合同·审查`。P1：未装则 `unavailable` |
| 按人头派驻、三方派遣、需要或持有《劳务派遣经营许可证》 | `劳务派遣协议·审查` |
| 平台派单、算法管理、按单计酬、新就业形态 | `平台用工相关协议·审查`。P1：未装则 `unavailable` |
| 房屋建筑、市政基础设施专业分包或劳务分包；严禁个人承揽的工程作业 | 建设工程类审查原子；本任务只告知违法分包，不改成可履行个人承包 |
| 有完整待签文本要评改 | `个人劳务承包合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、只问进场、验收、保险续保或结算日历 | 本套导航的履约步骤 |
| 已催告、索赔、立案、开庭，或主问工伤、欠薪、劳动仲裁怎么打 | `已成争的普通合同路径` 或劳动争议专项 |
| C 端大众快检 | 只分流，不回改 |

标题写“个人劳务承包”或“班组承包”，正文却是发包方对劳务人员打卡发月薪：不在本任务补隔离墙后放行。负触发 `劳动合同·审查`。

标题写“个人劳务承包”，正文是个人交付设计稿／加工件、自备工具独立完成、无班组：负触发 `承揽合同（个人劳务）·审查`。

标题写“个人劳务承包”，承包方却是公司、按项目整体外包并派人到场：负触发 `业务外包（派遣型）合同·审查`。人员另接受发包方直接排班的，仍走 `业务外包（派遣型）合同·审查` 或 `劳务派遣协议·审查`，不在本任务改残。

仅缺一般或连带式的验收节点、保险限额、保证金比例，但给付仍是包工头组织班组、按量结算，且作业不属于强制准入：留在本任务，必须出显化句。

建筑施工或强制准入作业发包给自然人：不按本类型放行。要求改由有资质企业承接后重审，不转成“个人承揽”来挽救无资质发包。
