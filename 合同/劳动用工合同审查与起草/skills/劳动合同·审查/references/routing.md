# 边界与路由

本技能只审查 **劳动关系类合同 / 劳动合同** 的待签全日制书面文本。显示名是「劳动合同·审查」，不要简称成劳动争议套件里的任何商品。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 个人劳务、雇佣协议、平等提供劳务 | `个人劳务（雇佣）合同·审查` |
| 个人承揽、按成果交付、不接受考勤管理 | `承揽合同（个人劳务）·审查` |
| 劳务派遣协议、派遣单位与用工单位 | `劳务派遣协议·审查` |
| 业务外包但派人接受用工单位直接指挥 | `业务外包（派遣型）合同·审查`；专业版未装则 `unavailable`，提示，不得用本技能硬套 |
| 个人劳务承包 | `个人劳务承包合同·审查`；专业版未装则 `unavailable` |
| 非全日制、小时工、每日平均不超过四小时 | `非全日制劳动合同·审查` |
| 已享受养老保险待遇或达到法定退休年龄的返聘 | `退休返聘合同·审查` |
| 在校学生实习 | `学生实习协议·审查` |
| 平台用工、网约配送或类似协议 | `平台用工相关协议·审查`；专业版未装则 `unavailable` |
| 主文件是专项培训服务期协议 | `培训服务期协议·审查` |
| 主文件是竞业限制协议，或劳动合同中离职后禁业专章需判效力 | `竞业限制协议·审查` 或 `C端大众竞业风险快检只要不定效力的风险提示`；本任务只剥离，不判效力 |
| 无文本、本类型条件已谈妥、要出己方稿 | `劳动合同·起草` |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 劳动关系主体不明、多公司混同要定性 | `劳动关系主体不明多公司混同要定性`；本任务只标主体冲突 |
| 已解除、劝退、降薪逼走 | `已解除劝退降薪逼走` 或 `或` |
| 要算 N/N+1/2N 或加班费终值 | `要算NN+12N或加班费终值` / `本任务不测算加班费终值。用户要算账→` |
| 已申请或拟申请劳动仲裁、要证据或应诉策略 | `已申请或拟申请劳动仲裁要证据或应诉策略` / `劳动仲裁证据整理` / `继续当签前审查；输出仲裁策略`。本技能不审仲裁策略 |
| 已成争的普通合同路径 | `已成争的普通合同路径` 或劳动领域，不继续签前审查 |
| C 端大众快检 | 只分流，不回改 |

劳动合同正文里夹带竞业或专项培训专章：专章交接对应原子；其余条款继续审。用户坚持本技能给出竞业效力或仲裁胜率：`目标停止`。
