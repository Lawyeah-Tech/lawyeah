# 边界与路由

本技能只审查 **劳动关系类合同 / 培训服务期协议** 的待签文本。主线是专项技术培训费用 + 服务期 + 违约金按未履行期间分摊。显示名是「培训服务期协议·审查」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 全日制劳动合同正文、试用期、工时工资社保整案 | `劳动合同·审查`。本任务不审试用期、第十九条分档或劳动合同必备条款 |
| 离职后不竞争 + 按月补偿、竞业违约金 | `竞业限制协议·审查`。劳动合同法第二十三条仅负向 |
| 劳务派遣协议、派遣单位与用工单位 | `劳务派遣协议·审查`。本任务不审三性或 10% |
| 只有入职培训、安全教育、岗前考核或手册签到 | 不按本类型出十节；删除服务期和违约金，不改成可履行 |
| 学历资助、购房、落户等特殊待遇且无专业技术培训 | 切开；解释（二）第十二条仅负向，不在本任务设计赔偿损失方案 |
| 劳动合同中夹带专项培训服务期专章 | 专章留本任务；其余正文交对应原子 |
| 无文本、本类型条件已谈妥、要出己方稿 | `培训服务期协议·起草` |
| 已签未争、只问怎么追培训费、发票归档、已履行月数怎么算 | 本套导航的履约步骤 |
| 已申请或拟申请劳动仲裁追偿培训违约金、要证据或应诉策略 | `已申请或拟申请劳动仲裁要证据或应诉策略` / `劳动仲裁证据整理` / `继续当签前审查；输出仲裁策略`。本技能不审仲裁策略 |
| 已成争的普通合同路径 | `已成争的普通合同路径` 或劳动领域，不继续签前审查 |
| C 端大众快检 | 只分流，不回改 |

劳动合同夹带竞业：竞业段交 `竞业限制协议·审查`。用户坚持本技能给出整份劳动合同效力、竞业是否有效、培训费终值或仲裁胜率：`目标停止`。
