# 审查方法（锁定 劳动关系类合同 / 退休返聘合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止把劳动争议套件原子正文抄进本任务。禁止把 `劳动合同·审查` 的试用期或第十九条分档正文当作本类型主路径。

定性校验：标题、身份与核心给付与本类型一致才继续；劳动合同、未退休个人劳务、派遣、非全日制、实习或他类明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、一定是劳务关系、一定不是工伤、对方必然接受、劳动仲裁必然胜诉或唯一必得金额。

`search_law` 返回已失效《合同法》及其解释、解释（一）第三十二条第一款当作现行有效、或把 2012 年未改动的劳动合同法第四十四条标成失效时记为噪声，不得写入 `L#`。2012 年劳动合同法修正未改动第四十四条文字的，引用 2012 修正，不得因 2007 文本带“已被修改”标签写成失效。

示范文本只参考退休返聘协议或劳务协议（返聘）的栏目。命中“返聘劳动合同”或依据已失效《合同法》《民法通则》拟定的范本，不得粘贴充作本约。

知识库纠正（不回写双文件）：

- `基本面.md` 写“最高人民法院司法解释明确规定……应当按劳务关系处理”：指向法释〔2020〕26 号第三十二条第一款。该款自 2025-09-01 起不得作为现行依据（MCP 标注该条“部分失效”）。身份闸通过后本类型**按劳务关系审查文本**，表述为“一般为劳务”，禁止写成“领养老金一定是劳务关系”。
- `基本面.md` / `框架.md` 写死“男 60 周岁，女干部 55 / 女工人 50”：自 2025-01-01 施行《国务院关于渐进式延迟法定退休年龄的办法》。男职工和原 55 周岁女职工每四个月延迟一个月，逐步至 63 / 58 周岁；原 50 周岁女职工每两个月延迟一个月，逐步至 55 周岁。当次按出生年月核验，禁止用旧周岁口号放行。
- `框架.md` “乙方在劳务过程中受伤不认定为工伤”：只能作为劳务关系下的路径提示，不能写成合同已消灭工伤认定权。超龄未办退休、未享受养老待遇而继续工作的，不得写“一定不是工伤”。
- `框架.md` “赔偿限额以保险理赔金额为准，甲方不再承担额外赔偿责任”以及 `基本面.md` “自身基础疾病导致现场意外甲方不承担”：不得用来排除民法典第一千一百九十二条的过错责任。修改句必须保留保险外按过错分担。
- `框架.md` “一年一签”“任务导向”：可作聘用单位侧优化，不得用来掩盖全日制从属劳动或把未退休人员改成返聘。
- 条款“养老金从劳务费中扣除”：红线删除。

## 节点 2　主体与身份闸（硬闸）

支持依据：劳动合同法（2012 修正）第四十四条第二项；劳动合同法实施条例第二十一条；社会保险法（2018 修正）第十六条；《全国人民代表大会常务委员会关于实施渐进式延迟法定退休年龄的决定》及《国务院关于渐进式延迟法定退休年龄的办法》（2025-01-01 施行）。解释（一）第三十二条第一款不得写入 `L#`。

### 2.1 主体表

建表：聘用单位签约名、受聘人姓名、付款名、发票名、授权签字人。名称不一致不自动合并。口头“我们老板同意了”不得写成已授权。

受聘人是否与原退休单位签有排他返聘：未核验标 `G#`，修改句要求书面陈述，不编造“无排他”。

### 2.2 退休年龄与养老待遇

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 见到退休证或最近一期养老金领取记录，且出生年月按延迟办法已达现行法定退休年龄或已开始领取基本养老金/退休金 | 继续；修改句把凭证列为附件 | 关系必然是劳务；凭证必然真实 |
| 文本未附凭证，用户也未提供 | **签署能力字段停止**；列出待补：身份证、退休证或退休审批、最近一期养老金发放记录 | **已经是劳务**；先签后补证 |
| 用户承认未办退休、未领养老金，或按延迟办法尚未达到现行法定退休年龄 | **不按本类型放行**；转 `劳动合同·审查` 或 `个人劳务（雇佣）合同·审查`；若用户仍要“按返聘规避”→ 红线，整体停止 | 男满 60 / 女满 50 或 55 就一定退休；改成返聘即可规避劳动法 |
| 已达年龄但因缴费年限不足尚未领取养老金 | 字段停止或升级；不得按清洁返聘放行；提示可能仍按劳动关系处理 | 超龄一律劳务；一定不是工伤 |

修改句（未见凭证，聘用单位立场）：

`定位（首部/鉴于）｜原文：乙方为退休返聘人员｜建议改为：乙方确认并承诺：其已按国家现行规定达到法定退休年龄，且已依法享受基本养老保险待遇或领取退休金；签署前向甲方出示并交付《退休证》或退休审批材料，以及最近一期养老金领取记录复印件作为附件。甲方未见上述材料前，本协议不生效，甲方无义务接受劳务。｜理由：劳动合同法第四十四条；实施条例第二十一条；社会保险法第十六条；延迟退休办法｜可退让点：可给【待填】个工作日补正，补正前不得上岗｜不接受时的红线：不签署；不得写成先上岗后补证`

修改句（未退休仍要返聘）：

`定位（全文）｜原文：双方同意按退休返聘处理，不适用劳动法｜建议改为：删除该安排。受聘人未达到现行法定退休年龄且未依法享受基本养老保险待遇的，不得以本协议规避劳动法律。｜理由：身份闸；实施条例第二十一条｜可退让点：无｜不接受时的红线：整体停止，不设计假返聘`

不得把知识库旧周岁写成放行条件。可写：法定退休年龄按国务院延迟办法及受聘人出生年月当次核对。

## 节点 3　一般为劳务，禁止口号（硬闸）

支持依据：劳动合同法第四十四条第二项；实施条例第二十一条；民法典合同编对平等主体劳务约定的任意性。解释（一）第三十二条第一款：噪声。

身份闸通过后，本类型按劳务关系评改：

- 不适用经济补偿、二倍工资、试用期、带薪年休假、医疗期等劳动合同法规则，除非双方书面特别给予且不与强制规范冲突。
- 文本必须写清：双方建立劳务关系，不适用劳动合同法关于经济补偿金、二倍工资等规定。这是**文本安排**，不是对本案关系定性的保证。
- 用户要求“保证一定是劳务关系”“依法必为劳务”：拒绝保证；可写“现有材料支持按劳务关系文本审查，最终定性以有权机关认定为准”。

| 文本或用户主张 | 动作 |
| --- | --- |
| 引用解释（一）第三十二条第一款主张“法院应当按劳务关系处理” | 标噪声；不得写入 `L#`；改为“一般为劳务，禁止一定是劳务” |
| 协议已写劳务关系且身份凭证齐 | 继续；仍不保证定性 |
| 协议写“双方确认构成劳动关系”或套用劳动合同必备条款 | 必须改或负触发 `劳动合同·审查` |

修改句（鉴于/关系条款）：

`定位（鉴于/第一条）｜原文：双方建立劳动关系 / 乙方入职甲方｜建议改为：鉴于乙方已达到国家现行法定退休年龄并已依法享受基本养老保险待遇（或领取退休金），双方在平等、自愿基础上建立劳务关系。本协议项下权利义务适用《中华人民共和国民法典》等民事法律，不适用《中华人民共和国劳动合同法》关于经济补偿金、二倍工资、试用期等规定。本条约定不构成对用工关系的终局定性。｜理由：第四十四条；实施条例第二十一条；解释（一）第三十二条第一款不得再引｜可退让点：可保留“如有权机关认定为劳动关系，双方另行依法处理”｜不接受时的红线：坚持写成劳动合同或要求保证一定是劳务则停止保证`

## 节点 4　去劳动化、劳务内容、劳务费与个税（硬闸）

### 4.1 标题、称谓与用语

标题用“退休返聘协议”或“劳务协议（返聘）”。严禁直接命名“劳动合同”。主体称谓用“聘用方/受聘人”或“甲方/乙方”，避免“用人单位/劳动者”单独充当定性。

禁止保留：入职、试用、转正、工资、辞退、开除、赔偿金、经济补偿、二倍工资。替换为：提供劳务、咨询、指导、劳务费、协议终止、通知解除。

修改句（标题与试用期）：

`定位（标题及试用条款）｜原文：劳动合同；试用期两个月，转正后发放工资｜建议改为：标题改为《退休返聘协议》。删除试用期、转正和工资表述。改为：乙方自【待填】起至【待填】止为甲方提供【待填：工艺指导/顾问/带教】劳务；甲方按月支付劳务费人民币【待填】元，不含员工福利、住房公积金和带薪年休假，除非双方另有书面特别约定。｜理由：与劳动合同切开；框架去劳动化｜可退让点：可约定【待填】日磨合期，但不得称试用期，不得约定试用期工资折扣｜不接受时的红线：保留劳动合同标题和试用期则建议不按本类型签`

### 4.2 劳务内容

列明职责，优先“咨询、指导、带教、评审”等任务导向表述。全日制坐班、接受劳动规章考勤、与在职员工混岗且无任务边界：标必须改，提示从属劳动穿透风险，不在本任务改成劳动合同。

### 4.3 劳务费、个税与养老金扣除

报酬称“劳务费”或“咨询费”。写明是否包含差旅、通讯。甲方代扣代缴个人所得税，税目按“劳务报酬所得”处理；税目选择不代替关系定性。

| 文本写法 | 动作 |
| --- | --- |
| 月工资、基本工资、绩效工资 | 必须改为劳务费 |
| 养老金从劳务费中扣除、税后养老金由单位补差 | **红线删除** |
| 长期按工资薪金发放、与在职员工同一薪酬体系 | 必须改发放科目与台账，提示税务合规风险 |
| 只写“依法纳税” | 必须改：写明代扣义务和税目，金额用 `【待填】` |

修改句（养老金扣除）：

`定位（报酬条款）｜原文：甲方有权从劳务费中扣除乙方已领取的养老金｜建议改为：删除该句。甲方按约定足额支付劳务费人民币【待填】元/月，并依法按劳务报酬所得代扣代缴个人所得税。乙方依法领取的养老金与本协议劳务费分列，互不抵扣。｜理由：养老金扣除条款不得作为放行结构｜可退让点：无｜不接受时的红线：保留扣除则建议不签`

## 节点 5　工伤与意外切开（硬闸）

支持依据：民法典第一千一百九十二条；工伤保险条例（2010 修订）第二条（职工/雇工参加工伤保险的范围）。已享受养老的返聘人员通常难以继续缴纳工伤保险。超龄未享受养老待遇而继续工作的伤害路径，地方和部门口径不一，本任务不得写成“一定不是工伤”。

### 5.1 已享受养老的返聘

- 协议应写：在岗伤害不按本协议自行“认定或不认定”工伤；双方理解本安排一般走民事劳务损害路径。
- 聘用单位必须为受聘人投保商业意外伤害保险或雇主责任险，并约定**附加超龄人员条款**、保险期间覆盖劳务期限、受益/索赔协助义务。
- 保险是风险对冲，不是法定免责。

### 5.2 禁止条款

| 文本写法 | 动作 |
| --- | --- |
| 乙方受伤一律不认定为工伤，不得向任何机关提出工伤申请 | 必须改：合同不能消灭法定认定权；已享受养老的，改为路径陈述 + 投保义务 |
| 保险理赔后甲方不再承担任何责任 / 概不负责 | **红线**；删除绝对免责；保留第一千一百九十二条按过错分担 |
| 自身基础疾病在现场发作甲方不承担任何责任 | 必须改：不得排除甲方过错；可写乙方健康告知义务和保险优先 |
| 上下班交通事故一律与甲方无关 | 必须改：第三人侵权时受聘人可请求第三人，也可请求接受劳务一方补偿（第一千一百九十二条第三款） |
| 无任何保险安排 | 聘用单位侧必须改 |

修改句（概不负责）：

`定位（伤害/保险条款）｜原文：乙方在劳务过程中受伤不认定为工伤；保险公司赔付后甲方不再承担任何赔偿责任｜建议改为：双方理解，在乙方已依法享受基本养老保险待遇的前提下，本协议项下在岗伤害一般不按工伤保险关系处理，但不限制有权机关依法作出的认定。甲方应于本协议生效前为乙方投保【待填：雇主责任险/商业意外伤害保险】，附加超龄人员条款，保险期间覆盖本协议期限，保额不低于人民币【待填】元，并将保单复印件作为附件。因劳务受到损害的，先走保险理赔；保险不足部分，根据双方各自的过错承担相应责任。甲方不得以本协议排除其过错范围内的责任。因第三人造成损害的，乙方有权请求第三人承担侵权责任，也有权请求甲方给予补偿；甲方补偿后可向第三人追偿。｜理由：民法典第一千一百九十二条；工伤与意外切开｜可退让点：保额和险种可谈；不得删过错分担｜不接受时的红线：保留概不负责则建议不签`

超龄未领待遇：本条法律结论字段停止或升级，提示可能适用工伤保险责任，转 `工伤索赔整案` 评估，不在本任务写成清洁返聘免工伤。

## 节点 6　解除、体检、知识产权与争议条款

### 6.1 解除与终止

可约定双方提前【待填】日书面通知解除，聘用单位无需支付经济补偿金。可约定因身体健康不能继续提供劳务时协议终止。

禁止：把“无需补偿”写成受聘人放弃被有权机关认定为劳动关系后的全部法定权利；约定随时口头解除且无需交接。

修改句：

`定位（解除条款）｜原文：甲方可随时辞退乙方，乙方不得主张任何补偿｜建议改为：任何一方提前【待填】日书面通知对方，可以解除本协议，甲方无需支付经济补偿金。解除后双方于【待填】日内完成资料、设备和未结劳务费清算。若有权机关认定双方存在劳动关系，补偿或赔偿事项依法另行处理，本条不视为预先放弃法定权利。｜理由：劳务任意解除可约定；不得预先放弃被穿透后的法定权利｜可退让点：通知期 7–15 日可谈｜不接受时的红线：保留“随时辞退且不得主张任何权利”则必须改`

### 6.2 体检与健康告知

附件应有近期体检报告或《身体健康告知书》。口头“身体没问题”不得写成已体检。不得指导补假体检。职业病史标 `G#`，高危岗位升级。

### 6.3 成果与保密

返聘期间形成的职务技术成果、文件、客户信息归聘用单位或按约定；可另签保密条款。竞业限制整段交接 `竞业限制协议·审查`，本任务不判竞业效力。

### 6.4 争议条款：改写法，不审策略

两民事主体之间的劳务报酬、损害争议可约定诉讼或仲裁，须单一、明确。不得约定商事仲裁排除劳动仲裁预受理。用户追问请求、证据、时效、胜率：目标停止。

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（未达身份闸仍要返聘、伪造凭证、劳动合同标题加试用期拒改、概不负责、养老金扣除、保证一定是劳务）；

- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。身份闸未过且用户拒绝改正：停止“可以签署”建议。
