# 边界与路由

本技能只审查 **劳动关系类合同 / 退休返聘合同** 的待签文本。签署方是聘用单位与已达现行法定退休年龄或已依法享受基本养老保险待遇/领取退休金的人员。显示名是「退休返聘合同·审查」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 全日制劳动合同、用人单位与未退休劳动者两方签约、试用期/工资/社保 | `劳动合同·审查`。本任务不审试用期、第十九条分档或劳动者劳动合同正文 |
| 未退休人员的平等个人劳务、雇佣协议 | `个人劳务（雇佣）合同·审查` |
| 派遣单位与用工单位之间的商事派遣协议 | `劳务派遣协议·审查` |
| 非全日制、小时工、每日平均不超过四小时 | `非全日制劳动合同·审查` |
| 专项出资培训与服务期 | `培训服务期协议·审查` |
| 离职后不到同类业务任职或自营 | `竞业限制协议·审查` |
| 在校学生实习 | `学生实习协议·审查` |
| 把未达退休且未享受养老的人员改写成返聘以规避劳动法 | 本任务红线告知，不改写成可履行规避结构；需要劳动关系文本则转 `劳动合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `退休返聘合同·起草` |
| 已签未争、只问到岗、付款日、续聘留痕 | 本套导航的履约步骤 |
| 已申请或拟申请劳动仲裁、要证据或应诉策略 | `已申请或拟申请劳动仲裁要证据或应诉策略` / `劳动仲裁证据整理` / `继续当签前审查；输出仲裁策略`。本技能不审仲裁策略 |
| 工伤认定或工伤待遇整案 | `工伤索赔整案`。本协议只审伤害路径陈述与商业保险约定 |
| 劳务过程受伤的民事索赔整案 | `劳务过程受伤的民事索赔整案` 或人身损害对应原子。本技能不算定损 |
| 已成争的普通合同路径 | `已成争的普通合同路径` 或劳动/侵权领域，不继续签前审查 |
| C 端大众快检 | 只分流，不回改 |

本协议夹带未终止的原劳动合同或新的劳动合同附件：附件整段交接 `劳动合同·审查`；返聘正文继续审。用户坚持本技能给出劳动关系效力、仲裁胜率、工伤赔付终值或“一定是劳务”：`目标停止`。
