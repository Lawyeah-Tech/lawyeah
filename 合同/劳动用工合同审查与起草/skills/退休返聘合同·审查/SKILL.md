# 退休返聘合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把《最高人民法院关于审理劳动争议案件适用法律问题的解释（一）》第三十二条第一款当作 2025-09-01 后的现行依据。引用劳动合同法第四十四条时，使用 2012 年修正、2013-07-01 施行文本；2012 年修正未改第四十四条文字的，不得把 2007 文本标成失效。法定退休年龄按 2025-01-01 起施行的渐进式延迟办法当次核验，禁止写死“男 60 / 女 50/55”。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **劳动关系类合同 / 退休返聘合同** 的待签文本（聘用单位与已达现行法定退休年龄或已依法享受基本养老保险待遇/领取退休金的人员），输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。显示名为「退休返聘合同·审查」。本技能不代替审查全日制劳动合同（那是 `劳动合同·审查`），也不代替审查未退休人员的普通个人劳务（那是 `个人劳务（雇佣）合同·审查`）。

`depends-on` 为空。不要求先跑导航。

不交付：劳动合同审查、普通个人劳务审查、他类文本审查、从零起草、履约交底、劳动仲裁或工伤/人身损害索赔策略、解除补偿终值、关系定性保证、未退休人员的返聘规避结构。

## 本类型硬闸

1. **身份闸**：受聘人须达到现行法定退休年龄，或已依法享受基本养老保险待遇、领取退休金。法定退休年龄按延迟办法当次核验，禁止写死旧口径周岁。未见退休证或养老金领取记录：签署能力字段停止，不得写“已经是劳务”。未达退休且未享受养老：不按本类型放行。
2. **一般为劳务**：身份闸通过后按劳务关系审查文本，不适用经济补偿、二倍工资、试用期等劳动合同法规则。禁止引用已废止的解释（一）第三十二条第一款写成“领养老金一定是劳务关系”。不得保证关系定性。
3. **工伤与意外切开**：已享受养老的返聘，一般不按工伤保险路径设计条款；必须约定商业意外险或雇主责任险（附加超龄人员条款）。禁止“保险赔完概不负责”排除民法典第一千一百九十二条过错责任。超龄未领待遇：不得写“一定不是工伤”。
4. **与劳动合同切开**：标题或核心给付是全日制劳动合同 → `劳动合同·审查`。删除入职、试用、工资、辞退、经济补偿、赔偿金、二倍工资。禁止把本协议改成劳动合同正文。
5. **去劳动化与劳务费**：标题用“退休返聘协议”或“劳务协议（返聘）”；报酬称劳务费或咨询费；个税按劳务报酬所得代扣。禁止从劳务费中扣除养老金。
6. **解除与体检**：可约定提前通知解除且无需支付经济补偿，但不得写成放弃被穿透后的法定权利。体检报告、身体健康告知书作为附件；不得伪造体检结论。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。禁止把“一定是劳务”“一定不是工伤”写成法律结论。

## 工作边界

正触发：已有可读待签返聘协议正文，尚未签署，尚未成争，受聘人已达现行法定退休年龄或已享受基本养老保险待遇/领取退休金，核心给付是任务导向的咨询、指导、带教或轻体力辅助劳务，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 核心给付是用人单位与未退休劳动者的全日制劳动合同 → `劳动合同·审查`；
- 未退休人员的平等个人劳务 → `个人劳务（雇佣）合同·审查`；
- 劳务派遣单位与用工单位之间的派遣协议 → `劳务派遣协议·审查`；
- 非全日制、小时工 → `非全日制劳动合同·审查`；
- 培训服务期 → `培训服务期协议·审查`；
- 竞业限制 → `竞业限制协议·审查`；
- 在校学生实习 → `学生实习协议·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `退休返聘合同·起草`；
- 已签只问排班、付款日、到岗履约 → 本套导航的履约步骤；
- 已申请劳动仲裁、工伤认定、人身损害赔偿立案或开庭 → 劳动或侵权领域对应原子，不审索赔策略。

把未退休人员改写成返聘以规避劳动法：只出告知与红线，不改写成可履行规避结构。

## 建立审查坐标

确认：使用者与授权；单方立场（聘用单位或受聘人择一）；相对方；全文及附件版本；受聘人出生日期、性别与原法定退休口径；是否已办退休、是否已领取养老金及凭证；工作内容；劳务费与税目；伤害与保险；解除通知；体检材料；不可接受事项；法域与拟签署日。缺立场或无可读书面文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的年龄、金额、期限、保额用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验劳动合同法第四十四条、实施条例第二十一条、解释（一）第三十二条不得再引、民法典第一千一百九十二条、社会保险法第十六条、延迟退休办法；`search_practiced` 只补审查反例，不写办案策略；`search_template` 只借返聘/劳务协议栏目结构，不得粘贴“返聘劳动合同”或引用已失效《合同法》《民法通则》的范本正文。不虚构案件系统。

`search_law` 对上述法律结论为 required 级：不可用时不拒绝执行，只停止效力字段。返回已失效《合同法》或其解释、解释（一）第三十二条第一款当作现行有效、或把 2012 年未改动的第四十四条标成失效时记为噪声，不得写入 `L#`。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`基本面.md` 把解释（一）第三十二条第一款写成现行“应当按劳务关系处理”、把法定退休年龄写死为男 60 / 女 50/55 的，按 method 纠正，不回写双文件。`框架.md` 的“受伤不认定为工伤”“保险限额内甲方不再承担额外赔偿责任”“自身基础疾病概不负责”只作风险识别，不得用来放行排除过错责任或排除工伤认定权。

### 0. 签署状态与成果分流

无书面文本 → `退休返聘合同·起草`；已签履约 → 本套导航履约步骤；已成争或工伤/人身损害索赔 → 劳动或侵权领域。未签且目标是评改已有返聘协议，才进入本任务。

### 1. 类型锁死

标题、身份与核心给付一致才继续。劳动合同、普通个人劳务、派遣、非全日制、实习负触发。

### 2. 身份闸

出生日期、现行法定退休年龄、退休证、养老金领取记录。未见凭证不得写“已经是劳务”。

### 3. 一般为劳务，禁止口号

身份闸通过后按劳务文本审。不得引用废止条款写成一定是劳务。不得保证定性。

### 4. 去劳动化、劳务费与个税

标题、称谓、报酬名称、税目。禁止试用期、工资、经济补偿、养老金扣除。

### 5. 工伤与意外

保险险种、超龄附加、投保义务、民法典第一千一百九十二条不得排除。超龄未领待遇不得写一定不是工伤。

### 6. 解除、体检与争议条款

通知解除；健康终止；体检附件。争议条款改写法，不审策略。

### 7. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持把未退休人员改成返聘、伪造退休/养老金凭证、保证“一定是劳务/一定不是工伤”、把概不负责改成可履行免责。
- `字段停止`：法域、现行法定退休年龄是否已达、养老金是否已实际领取、地方超龄工伤专项未核验。
- `目标停止`：主目标已变为从零起草、履约交底、劳动合同审查、劳动仲裁或工伤/人身损害策略。
