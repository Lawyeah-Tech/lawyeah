# 承揽合同（个人劳务）·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **劳动关系类合同 / 承揽合同（个人劳务）**，输出可编辑草稿、未决项，并用本类型硬闸自审后给出风险表和修改句。承揽人是自然人，核心给付是独立完成并交付特定成果。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。显示名为「承揽合同（个人劳务）·起草」。待签评改转 `承揽合同（个人劳务）·审查`。本技能不代替起草或审查劳动合同、个人劳务、业务外包或平台用工对应成对原子，也不代替审查加工合同（那是 `的method当本类型主路径。`）。

`depends-on` 为空。不要求先跑导航。

不交付：劳动合同起草或审查、个人劳务起草或审查、民事加工承揽审查、外包或平台用工整案、他类型起草、待签文本签前审查、履约交底、劳动仲裁或工伤索赔策略、有效性保证、避社保或挂靠可履行结构。

## 本类型硬闸

1. **劳动关系 vs 承揽（1191 / 1192 / 1193）**：人格从属、组织从属、经济从属，或文本安排缴纳社会保险、把社保费包进承揽报酬的，不得按个人承揽改完。负触发 `劳动合同·审查`。考勤打卡、员工手册、固定月薪加绩效年终奖、工位编制、服从奖惩，视为从属信号。核心给付是提供劳务过程、不交付特定成果的，负触发 `个人劳务（雇佣）合同·审查`。真承揽才走第一千一百九十三条；假承揽不能用来吞掉第一千一百九十一条或第一千一百九十二条。
2. **1193 不是定作人绝对免责**：承揽人完成工作造成第三人损害或自己损害，定作人原则上不承担责任，但对定作、指示或者选任有过错的，仍承担相应责任。禁止“承揽人自行承担全部人身或第三人损害、定作人概不负责”。商业意外险只是增信，不能写成已免除法定过错责任。
3. **与外包、平台用工切开**：相对方是公司、派人到定作人现场接受指挥考核 → `业务外包（派遣型）合同·审查`。平台规则、派单抽成、评分封号、诱导注册个体户 → `平台用工相关协议·审查`。禁止把个人承揽改成外包或平台协议，也禁止把外包/平台文本硬套本技能。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。禁止把“改成承揽就能不缴社保”写成可放行结构。禁止把本约改成劳动合同正文。禁止打开 `劳动合同·审查` 或 `的method当本类型主路径。` 的 method 当本类型主路径。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿；尚未签署，尚未成争；核心给付是独立完成并交付特定工作成果并领取承揽报酬；用户要一份可签署草稿。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 有完整待签文本要评改 → `承揽合同（个人劳务）·审查`；
- 人格从属、组织从属、经济从属，或安排社会保险、工资表发放 → `劳动合同·审查` / `劳动合同·起草`；
- 平等提供劳务过程、按次按时计酬、不交付特定成果 → `个人劳务（雇佣）合同·审查` / `个人劳务（雇佣）合同·起草`；
- 企业间加工、定作人供主材按图加工、非劳动风险主轴 → `的method当本类型主路径。`；
- 相对方是外包公司、派人接受定作人现场指挥考核 → `业务外包（派遣型）合同·审查` / `业务外包（派遣型）合同·起草`；
- 平台派单、抽成、评分封号、注册个体户接单 → `平台用工相关协议·审查` / `平台用工相关协议·起草`；
- 派遣单位与用工单位签约、派人接受用工单位指挥 → `劳务派遣协议·审查` / `劳务派遣协议·起草`；
- 非全日制、小时工、适用劳动基准 → `非全日制劳动合同·审查` / `非全日制劳动合同·起草`；
- 标题或主结构是学生实习协议 → `学生实习协议·审查` / `学生实习协议·起草`；
- 标题或主结构是退休返聘合同 → `退休返聘合同·审查` / `退休返聘合同·起草`；
- 工地建筑活动、承包资质、竣工验收 → `或对应工程原子；` 或对应工程原子；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问付款日、验收日、交接留痕 → 本套导航的履约步骤；
- 已申请劳动仲裁、工伤索赔、立案、开庭 → 劳动领域或合同争议对应原子，不审仲裁、工伤或侵权诉讼策略。

全职改签承揽以省社保、诱导承揽人注册个体户以切断劳动关系、个人挂靠有资质单位、虚开发票：只出告知与红线，不改写成可履行规避结构。

## 建立起草坐标

确认：使用者与授权；单方立场（定作人或承揽人择一）；相对方；已谈妥的成果名称与规格、材料与工具、是否亲自完成、个税与发票；不可接受事项；法域与拟签署日。缺立场不启动。条件未谈妥的商业数字用 `【待填】`，不编造。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的金额、期限、保额用 `【待填】`，不编造。

## 起草模式

本原子只承担本类型起草。有完整待签文本要评改时，转 `承揽合同（个人劳务）·审查`。本类型条件已谈妥、要出己方稿时，留在本任务按三闸落稿并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。按下文明示清单把本类型硬闸写成正文必写、附件必附或禁止出现。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 标题用「承揽合同」或「个人承揽协议」；承揽人是自然人，核心给付是独立完成并交付特定工作成果。
- 成果名称、规格、材料与工具由谁提供、主要工作是否亲自完成、验收期与视为合格写清。
- 定作人对定作、指示或者选任有过错的，仍承担相应责任；商业意外险只作增信，不免除该过错责任。
- 监督不得写成考勤；定作人任意解除走民法典第七百八十七条并写赔偿，不得写成第七百九十三条。
- 留置可约定排除但须明示；未约定著作权归属的，提示归受托人。
- 报酬称承揽报酬；个税与发票合法路径落句。

### 附件必附

- 《工作成果验收标准》。
- 《原材料交接清单》（定作人供材时）。
- 《知识产权归属确认书》。
- 特种作业资格证明；未见资格则签署能力字段停止。

### 禁止出现

- 人格、组织、经济从属，或把社保费包进承揽报酬。
- 「承揽人自行承担全部人身或第三人损害、定作人概不负责」。
- 「改成承揽就能不缴社保」、诱导注册个体户、个人挂靠有资质单位、虚开发票。
- 把本约改成劳动合同、个人劳务、业务外包或平台协议。
- 把公司派人到现场接受指挥考核写成个人承揽。

### 0. 签署状态与成果分流

本类型条件已谈妥、要出己方稿 → 留本任务按三闸落稿并自审；有完整待签文本要评改 → `承揽合同（个人劳务）·审查`；已签履约 → 本套导航的履约步骤；已成争 → 劳动或争议领域。

### 1. 类型锁死

标题、签署方与核心给付一致才继续。劳动合同、个人劳务、加工承揽、外包、平台用工、派遣、工程主结构负触发。从属或社保安排按劳动合同转出。

### 2. 劳动关系 vs 承揽

从属信号对照。命中则负触发 `劳动合同·审查`，不把本约改成“去劳动化外观仍按承揽履行”。

### 3. 1192 vs 1193

过程劳务走 `个人劳务（雇佣）合同·审查`。真承揽才适用 1193，且必须保留定作、指示、选任过错。

### 4. 外包 / 平台切开

公司派人、现场指挥 → `业务外包（派遣型）合同·审查`。平台派单抽成 → `平台用工相关协议·审查`。

### 5. 主体、挂靠与资质

签约名分列。个人挂靠、依法须企业资质却发包给个人：停笔告知。特种作业未见资格：签署能力字段停止。

### 6. 成果、独立性、验收、787、留置、知识产权

成果特定化；主要工作亲自完成；监督不得写成考勤；验收期与视为合格；任意解除走第七百八十七条并写赔偿；留置可约定排除但须明示；未约定则著作权属受托人。

### 7. 按框架六步落稿并自审

必须先出草稿，再出自我审查的风险表和修改句。不得只交白稿。框架与硬闸冲突时，以 method 为准。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；条件未谈妥仍要编造数字出可签署终稿；用户坚持从属用工仍按承揽签、把 1193 改成定作人绝对免责、设计避社保或挂靠或虚开发票、保证有效。
- `字段停止`：法域、特种资质、1193 过错事实、保单真实性、个税预扣率未核验。
- `目标停止`：主目标已变为待签评改、履约交底、劳动合同审查、加工承揽审查、外包或平台整案、劳动仲裁或工伤策略。
