# 边界与路由

本技能只审查 **劳动关系类合同 / 学生实习协议** 的待签文本。签署方是学生与接收单位，或职业学校、实习单位与学生三方。显示名是「学生实习协议·审查」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 全日制劳动合同、用人单位与劳动者两方签约、已毕业按劳动者管理 | `劳动合同·审查`。本任务不审试用期、第十九条分档或劳动者劳动合同正文 |
| 非全日制、小时工、每日平均不超过四小时 | `非全日制劳动合同·审查` |
| 个人劳务、雇佣协议、平等提供劳务且无教学实习安排 | `个人劳务（雇佣）合同·审查` |
| 个人承揽、按成果交付、不接受考勤管理 | `承揽合同（个人劳务）·审查` |
| 派遣单位与用工单位之间的商事派遣协议 | `劳务派遣协议·审查`。本任务只禁止用派遣组织职校学生实习，不审派遣许可证或三性 |
| 退休返聘 | `退休返聘合同·审查` |
| 离校未就业见习、政府见习补贴 | 回引擎重新定性；不得当本类型硬套 |
| 普通高校毕业生就业协议书、报到派遣 | 回引擎重新定性；不得当实习协议改 |
| 无文本、本类型条件已谈妥、要出己方稿 | `学生实习协议·起草` |
| 已签未争、只问津贴发放日、鉴定表、保险续保 | 本套导航的履约步骤 |
| 已申请或拟申请劳动仲裁、要证据或应诉策略 | `已申请或拟申请劳动仲裁要证据或应诉策略` / `劳动仲裁证据整理` / `继续当签前审查；输出仲裁策略`。本技能不审仲裁策略 |
| 工伤认定或工伤索赔整案 | `工伤索赔整案` 或劳动领域对应原子 |
| 人身损害赔偿已立案 | `已成争的普通合同路径` 或侵权对应原子，不继续签前审查 |
| C 端大众快检 | 只分流，不回改 |

本协议夹带劳动合同或录用通知附件：附件整段交接 `劳动合同·审查`；实习协议正文继续审。用户坚持本技能给出劳动合同效力、仲裁胜率、工伤或人身损害赔付终值：`目标停止`。
