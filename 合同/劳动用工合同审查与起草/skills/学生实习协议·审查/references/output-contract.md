# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的津贴、保额、期限；把已失效《合同法》及其解释、1991 年童工规定或 1996 年工伤试行办法第六十一条写入结论；输出劳动仲裁请求、工伤或人身损害索赔策略或胜率；把本协议改成劳动合同正文；把已毕业用工改成可履行实习；把“实习生一律不是劳动者”或“学校当然连带”写成现行规则。

## 1. 触发、单方立场与成果状态

立场（实习单位、学生或学校）、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「学生实习协议·审查」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、1991 年童工规定、1996 年工伤试行办法第六十一条，或把 2012 年未改动的第十条、第八十二条标成失效时，记噪声，不得写入 `L#`。教职成〔2021〕4 号若来自教育部公开文本，标明官方源。

## 3. 类型与加载路径

父级 `劳动关系类合同`，子级 `学生实习协议`。定性理由、易混切开结果（尤其与 `劳动合同·审查` 劳动合同、`劳务派遣协议·审查` 劳务派遣协议的切开）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、在籍与文本版本

主体表：接收单位签约名、学生姓名、学校名称、学号、预计毕业日、是否已满 16/18 周岁、监护人、津贴发放名、授权签字人。版本表：正文、校方介绍信、学生证复印件、保险方案、安全告知书、岗位说明；冲突并列。未见在籍材料：身份字段停止，不得写“不是劳动关系所以可以签”。未见已满 16 周岁证明：年龄字段停止。

## 5. 三方结构、津贴、保险与毕业终止

是否职校岗位实习及是否三方签署；监护人签字；岗位与专业是否相关、每日时间与加班夜班；津贴名称、标准、直接支付路径、是否向学生收费；保险险种、投保人、保额、岗前培训；毕业或离校自动终止；是否夹带试用期或社保豁免。缺口标 `G#`。不输出罚款或赔偿终值。

## 6. 强制规范与规避结构

未满 16 周岁；已毕业假实习；职校两方拒补学校；无保险或单位概不负责；派遣/中介组织职校实习；向学生收费。协议中“声明不建立劳动关系”不得写成已切断嗣后依法认定。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和删除句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把框架“严禁使用岗位、考核”写成删除实习岗位和鉴定；不得把本协议改写成劳动合同条款。

## 9. 谈判与签署提醒

谈判顺序：先红线（童工、已毕业假实习、职校拒三方、无保险或概不负责、派遣中介），再必须改（在籍材料、监护人、津贴直付、毕业终止、培训），最后可优化。签署提醒：学生证与介绍信、保单、安全告知书、未成年监护人签字、职校学校盖章、单位公章及学生亲笔签名。不指导倒签、补假在校证明或假保单。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本技能只出审查意见和修改句，不出整份起草终稿；出稿转 `学生实习协议·起草`。不是履约交底、劳动合同审查、劳动仲裁或伤害索赔文书、效力保证。
