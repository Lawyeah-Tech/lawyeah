# 学生实习协议·审查

## 任务目标

在单一立场下，只审查 **劳动关系类合同 / 学生实习协议** 的待签文本（学生与接收单位两方，或职业学校、实习单位与学生三方），输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。显示名为「学生实习协议·审查」。本技能不代替审查劳动者劳动合同（那是 `劳动合同·审查`）。

`depends-on` 为空。不要求先跑导航。

不交付：劳动合同审查、他类文本审查、从零起草、履约交底、劳动仲裁或工伤/人身损害索赔策略、双倍工资或补偿终值、有效性保证、已毕业继续实习的可履行结构、童工或派遣中介输送结构。

## 本类型硬闸

1. **在校生实习≠劳动关系**：真实在校、以完成学业或教学安排为目的的实习，通常不建立劳动关系。劳部发〔1995〕309 号第 12 条只覆盖在校生业余勤工助学，不得写成“凡实习生一律不是劳动者”。已毕业或名为实习、实为用工的，按硬闸 4 处理，不在本任务改成劳动合同正文。未满 16 周岁：红线，不改成可履行实习。
2. **学校三方**：职业学校岗位实习必须以学校、实习单位、学生三方协议为基础。两方文本且属于职校岗位实习：必须改或红线。未满 18 周岁须监护人签字。普通高校自行实习缺校方身份核验材料：字段停止，不得写成可以不核在籍。
3. **伤害与报酬**：真实实习一般不走工伤统筹（地方试点标 `G#`）。必须约定实习责任保险或人身意外伤害保险、岗前安全培训、保险外民事赔偿分担。禁止“单位概不负责”。职校岗位实习独立顶岗原则上不低于同岗位工资标准的 80% 或最低档工资标准，货币按月直接支付；禁止第三方代发、物品代金券、向学生收费。
4. **不得用实习规避用工**：毕业或离校之日协议自动终止；继续用工须另订劳动合同。禁止用本协议约定试用期、社保豁免、经济补偿豁免覆盖已毕业用工。禁止通过劳务派遣单位、人力资源服务机构或有偿中介组织、安排、管理职业学校学生实习。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。禁止把“不是劳动关系”写成可以免保险、免赔偿。禁止把本协议改成劳动合同正文。

## 工作边界

正触发：已有可读待签学生实习协议或职校岗位实习三方协议正文，尚未签署，尚未成争，核心给付是在校学生到单位实践学习并可能领取津贴，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 核心给付是用人单位与劳动者的全日制劳动合同 → `劳动合同·审查`；
- 非全日制、小时工 → `非全日制劳动合同·审查`；
- 平等主体个人劳务 → `个人劳务（雇佣）合同·审查`；
- 个人承揽、按成果交付 → `承揽合同（个人劳务）·审查`；
- 派遣单位与用工单位之间的商事派遣协议 → `劳务派遣协议·审查`；
- 退休返聘 → `退休返聘合同·审查`；
- 离校未就业见习、普通高校毕业生就业三方协议 → 本套导航的类型切开步骤 重新定性；
- 无文本、本类型条件已谈妥、要出己方稿 → `学生实习协议·起草`；
- 已签只问津贴发放日、鉴定表、保险续保履约 → 本套导航的履约步骤；
- 已申请劳动仲裁、工伤认定、人身损害赔偿立案或开庭 → 劳动或侵权领域对应原子，不审仲裁或索赔策略。

招用未满 16 周岁、伪造在校证明、通过派遣/中介组织职校实习、用实习覆盖已毕业用工：只出告知与红线，不改写成可履行规避结构。

## 建立审查坐标

确认：使用者与授权；单方立场（实习单位、学生或学校择一）；相对方；全文及附件版本；学生是否在校在籍、学号、学校、预计毕业日、是否已满 16/18 周岁；是否职业学校岗位实习；岗位与专业；每日时间与加班夜班；津贴名称与支付路径；保险种类与投保人；不可接受事项；法域与拟签署日。缺立场或无可读书面文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的津贴、期限、保额用 `【待填】`，不编造。

### 0. 签署状态与成果分流

无书面文本 → `学生实习协议·起草`；已签履约 → 本套导航履约步骤；已成争或伤害索赔 → 劳动或侵权领域。未签且目标是评改已有实习协议，才进入本任务。

### 1. 类型锁死

标题、签署方与核心给付一致才继续。劳动合同、非全日制、个人劳务、派遣商事协议、退休返聘、见习或就业三方协议负触发。

### 2. 在籍、年龄与定性

学生证/在校证明、学号、预计毕业日。未满 16 周岁红线。口头“还是学生”不得写成已核在籍。

### 3. 学校三方

职校岗位实习必须三方；未成年监护人签字；普校缺校方核验则字段停止。

### 4. 报酬

津贴或生活补助，禁止工资化表述覆盖劳动关系。职校独立顶岗对照 80% 或最低档；禁止第三方代发和向学生收费。

### 5. 伤害与保险

保险、培训、保险外民事分担。禁止单位概不负责。不算定损，不写工伤怎么赢。

### 6. 规避用工与派遣中介

毕业自动终止；禁止转试用期；禁止派遣/中介组织职校实习。

### 7. 解除、保密与争议条款

改写法，不审策略。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持招用未满 16 周岁、已毕业仍“保证不是劳动关系”、通过派遣/中介输送职校学生、把概不负责改成可履行免责、伪造在校证明或假保单、保证有效。
- `字段停止`：法域、在籍真伪、职校/普校定性、地方工伤试点或地方津贴标准未核验。
- `目标停止`：主目标已变为从零起草、履约交底、劳动合同审查、劳动仲裁或伤害索赔策略。
