# 培训服务期协议·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。引用劳动合同法第二十二、二十五、二十六、二十七、三十八、三十九条时，使用 2012 年修正、2013-07-01 施行文本；2012 年修正未改这些条文文字的，不得把 2007 文本标成失效。培训费用构成、合同续延、第三十八条免责，引用《劳动合同法实施条例》第十六、十七、二十六条。特殊待遇与服务期不是本类型正触发，解释（二）第十二条只作负向切开。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **劳动关系类合同 / 培训服务期协议**，输出可编辑草稿、未决项，并用本类型硬闸自审后给出风险表和修改句。主线仍是**专项技术培训费用 + 服务期 + 违约金按未履行期间分摊**，不是岗前培训，不是竞业补偿，也不是整份劳动合同。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。显示名为「培训服务期协议·起草」。待签评改转 `培训服务期协议·审查`。

`depends-on` 为空。不要求先跑导航。

不交付：整份劳动合同起草或审查、竞业限制起草或审查、派遣协议起草或审查、岗前培训整案、待签文本签前审查、已签后怎么追培训费、劳动仲裁追偿培训违约金或胜诉策略、有效性保证。

## 本类型硬闸

1. **专项技术培训 ≠ 岗前培训 ≠ 竞业 ≠ 整份劳动合同**：入职培训、安全教育、业务熟悉、学历资助且无专业技术培训，不得设服务期或第二十二条违约金。竞业 → `竞业限制协议·审查`。整份劳动 → `劳动合同·审查`。派遣 → `劳务派遣协议·审查`。
2. **费用可举证**：发票抬头须为用人单位；须能回链培训内容、期间和费用构成清单。无票据、抬头为个人或无关关联公司：违约金字段停止，不得编造金额，不得写成“先签后补发票即可主张全额”。
3. **违约金 ≤ 培训费用且按未履行期间分摊**：约定数额不得超过用人单位提供的培训费用；用人单位要求支付的违约金不得超过服务期尚未履行部分所应分摊的培训费用。超过部分必须改。禁止“离职即全额退还+赔偿年薪三倍”。
4. **服务期长度合理**：法律未立法定年数上限，但须与费用数额和培训时间相适应。畸长服务期必须改，不得用“法无上限所以十年也可以”放行。
5. **单位违法解除 / 被迫离职**：劳动者依照劳动合同法第三十八条解除的，不属于违反服务期约定，用人单位不得要求支付违约金。单位违法解除的，不得写成劳动者仍须赔。修改句保留该抗辩，禁止“任何离职都要赔”。
6. **与劳动合同衔接**：劳动合同期满但服务期尚未到期的，劳动合同应当续延至服务期满；双方另有约定的，从其约定。本任务只改服务期协议中的衔接句，不改写整份劳动合同。

第二十二条第三款：约定服务期，不影响按照正常的工资调整机制提高服务期期间的劳动报酬。冻结调薪或把服务期当降薪理由：必须改。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿；尚未签署，尚未成争；核心给付是专项技术培训费用 + 服务期 + 分摊违约金；用户要一份可签署草稿。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 有完整待签文本要评改 → `培训服务期协议·审查`；
- 核心给付是全日制劳动合同正文（期限、试用期、工时工资社保）→ `劳动合同·审查` / `劳动合同·起草`；
- 主轴是离职后不竞争 + 按月补偿 → `竞业限制协议·审查` / `竞业限制协议·起草`；
- 签署方是派遣单位与用工单位的派遣协议 → `劳务派遣协议·审查` / `劳务派遣协议·起草`；
- 只有入职培训、安全教育、岗前考核或手册签到，无专项技术培训费用 → 切开，不按本类型出稿；
- 学历资助、购房补助、落户奖励等特殊待遇且无专业技术培训 → 切开；解释（二）第十二条只作负向，不在本任务设计赔偿损失方案；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问怎么追培训费、发票怎么归档、已履行月数怎么算 → 本套导航的履约步骤；
- 已申请劳动仲裁追偿培训违约金、已催告、已立案或开庭 → 劳动领域对应原子，不审仲裁策略。

对岗前培训设违约金、离职即全额退还、用服务期限制依法解除劳动合同：只出告知与删除/改正句，不改写成可履行规避结构。

## 建立起草坐标

确认：使用者与授权；单方立场（用人单位或劳动者择一）；相对方；已谈妥的培训项目、机构、时间、形式、发票抬头与费用构成、服务期起止、违约金公式、劳动合同期限；不可接受事项；法域与拟签署日。缺立场不启动。条件未谈妥的商业数字用 `【待填】`，不编造。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 起草模式

本原子只承担本类型起草。有完整待签文本要评改时，转 `培训服务期协议·审查`。本类型条件已谈妥、要出己方稿时，留在本任务按三闸落稿并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。按下文明示清单把本类型硬闸写成正文必写、附件必附或禁止出现。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 标题用「培训服务期协议」；主线只写专项技术培训费用、服务期和按未履行期间分摊的违约金。
- 培训项目、机构、期间、形式写到可回链；费用构成按实施条例第十六条写有凭证的培训费用、培训期间差旅和因培训产生的直接费用。
- 发票抬头必须是实际支付专项培训费用的用人单位。
- 服务期起止可回链，长度与费用数额和培训时间相适应；长于劳动合同期限时写劳动合同续延至服务期满，双方另有约定的从其约定。
- 违约金不得超过培训费用，且按服务期尚未履行部分分摊；公式写清，数字未给用 `【待填】`。
- 劳动者依照劳动合同法第三十八条解除，或用人单位违法解除的，不属于违反服务期，用人单位不得要求支付违约金。
- 约定服务期不影响按照正常工资调整机制提高服务期期间的劳动报酬。

### 附件必附

- 培训费用原始发票复印件或双方确认的费用明细单。
- 培训内容、期间、形式确认材料。
- 与劳动合同期限衔接的续延说明（服务期长于劳动合同期限时）。

### 禁止出现

- 入职培训、安全教育、业务熟悉或无专业技术培训的学历资助设服务期或第二十二条违约金。
- 「离职即全额退还」叠加年薪倍数，或「任何离职都要赔」。
- 「先签后补发票即可主张全额」。
- 冻结调薪或把服务期当降薪理由。
- 把本约写成竞业限制协议或整份劳动合同。
- 培训期间工资默认计入培训费用。

### 0. 签署状态与成果分流

本类型条件已谈妥、要出己方稿 → 留本任务按三闸落稿并自审；有完整待签文本要评改 → `培训服务期协议·审查`；已签履约 → 本套导航的履约步骤；已成争 → 劳动领域。

### 1. 类型锁死

标题、核心给付与专项技术培训费用 + 服务期 + 分摊违约金一致才继续。劳动合同、竞业、派遣、岗前培训、特殊待遇负触发或切开。

### 2. 主体与发票抬头

签约名、付款名、发票名分列。发票抬头须为实际支付专项培训费用的用人单位。

### 3. 专项技术培训定性

必须能回链培训内容、机构、期间、形式。入职、安全、岗前不得设服务期。

### 4. 费用可举证与构成

构成按实施条例第十六条：有凭证的培训费用、培训期间差旅、因培训产生的用于该劳动者的其他直接费用。无票据则违约金字段停止。工资默认不计入。

### 5. 服务期合理与劳动合同续延

起止日可回链。畸长必须改。长于劳动合同期限时写续延，不改写整份劳动合同。

### 6. 违约金上限与分摊

不得超过培训费用，且按尚未履行部分分摊。禁止全额退还叠加年薪倍数。

### 7. 谁赔、谁不赔

第三十八条和单位违法解除：劳动者不付违约金。实施条例第二十六条所列过错解除：仍可按约定分摊。禁止“任何离职都要赔”。第二十五条白名单外的劳动者违约金删除。

### 8. 按框架六步落稿并自审

必须先出草稿，再出自我审查的风险表和修改句。不得只交白稿。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；条件未谈妥仍要编造数字出可签署终稿；用户坚持把岗前培训改成可履行第二十二条违约金、补假发票、离职即全额退还且不得分摊、任何离职都要赔、保证有效。
- `字段停止`：法域、发票与费用构成未核验、工资是否计入未核、动态规则未核验。
- `目标停止`：主目标已变为待签评改、履约交底、整份劳动合同或竞业审查、劳动仲裁策略。
