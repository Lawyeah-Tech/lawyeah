主线只审**专项技术培训费用 + 服务期 + 违约金按未履行期间分摊**。不是岗前培训，不是离职竞业，不是整份劳动合同。

定性校验：标题、核心给付与本类型一致才继续；劳动合同、竞业、派遣、岗前培训或纯特殊待遇明显则负触发或切开，不填十节实体结论。

## 节点 3　专项技术培训定性

支持依据：劳动合同法（2012 修正）第二十二条第一款；劳动法（2018 修正）第六十八条；职业教育法（2022 修订）第二十四条。

第二十二条同时要求两件事，缺一不可：

1. 用人单位提供**专项培训费用**；
2. 对劳动者进行**专业技术培训**。

法定义务培训不是专业技术培训。劳动法第六十八条、职业教育法第二十四条下的职业培训制度、技术工种上岗前培训、安全生产教育，不得据此约定服务期或第二十二条违约金。

审查四件套，缺一件则必须改或字段停止：

1. **培训内容**：能回链特定专业技能（工艺、资质、封闭课程、脱产进修），不是“熟悉公司制度/产品介绍/安全告知”。
2. **培训机构或实施主体**：外部机构名称，或可证明支付给第三方的专项咨询/授权。纯内部讲师且无第三方费用：现有依据通常不支持把内部人力成本当成培训费用。
3. **培训期间与形式**：起止日、地点、脱产/半脱产。
4. **与岗位的专业提升关系**：能说明为何超出上岗所必须的法定义务培训。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 出国工艺封闭培训、行业高端资格脱产班、外部专家核心技术教学，大纲和期间可回链 | 继续审费用和服务期 | 已经有效 |
| 入职一周制度讲解、消防安全、岗前操作、新员工手册签到 | 红线。删除服务期和违约金，或整份不按本类型签 | 补一份费用确认就能约束 |
| 学历进修、在职研究生、MBA 学费资助，无专业技术培训内容 | 切开特殊待遇；不得写成第二十二条违约金 | 学历资助 = 专项技术培训 |
| 标题写“专项技术培训”，正文是“业务技能培训/入职培训” | 名实冲突写入 `C#`；按正文切开，要求改术语或删除服务期 | 标题已写专项所以适格 |
| 用户承认就是岗前，但仍要“改成能收违约金” | 整体停止 | 改写成可履行规避 |

内部转化：公司内部讲师、内部会议室、无第三方发票——标必须改或字段停止。除非能回链支付给第三方的专项咨询、授权或场地费用，不得把内部讲师工资当成培训费用。

## 节点 4　费用可举证与构成

支持依据：劳动合同法第二十二条第二款；实施条例第十六条。

### 4.1 可计入的构成

培训费用仅包括：

- 用人单位为专业技术培训支付的**有凭证的培训费用**；
- **培训期间的差旅费用**（交通、住宿；须能与该次培训期间对应，不是日常因公出差）；
- **因培训产生的用于该劳动者的其他直接费用**（教材、资料、考试报名等，须有凭证且专用于该劳动者）。

因公出差费、与本次培训无关的差旅、团队建设、福利旅游：不得列入。

### 4.2 不得默认计入

| 分项 | 动作 |
| --- | --- |
| 培训期间工资、奖金、社保 | 默认不计入。文本计入：该分项停止，修改句剥离出基数 |
| 内部讲师工资、占用工时折算 | 通常不支持。无第三方凭证则删除 |
| 学历学费、购房、落户、安家费 | 不是本条培训费用；切开特殊待遇 |
| 无明细的“综合培训成本”“人均摊销” | 必须改：改为逐项清单 + 发票附件 |

### 4.3 无票据：违约金字段停止

用人单位主张违约金的前提，是能够证明实际支出。无发票、无对公转账、无双方签署的费用确认书：

1. 违约金金额字段停止，标 `G#`。
2. 不得编造 `【8 万元】` 以外用户未给出的数字；用户未给数字时用 `【待填】`。
3. 修改句可要求：培训结束后双方签署《培训费用确认书》，以发票和转账凭证载明的实际支出为准；确认前任何一方不得按预算数主张违约金。
4. 禁止写“先签一个大概数，以后再补票”。

两阶段安排只作为审查建议：培训前可锁定项目、服务期意向和分摊公式；金额以培训结束后的实际凭证为准。本任务不起草整份两阶段合同。

## 节点 5　服务期长度与劳动合同续延

### 5.1 服务期合理（硬闸）

支持依据：劳动合同法第二十二条（未规定 3 年或 5 年上限）；须与费用数额、培训时间和专业提升程度相适应。

审查：起始日、到期日、起算点（通常为培训结束日或双方确认完成日，文本须写清）。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 期限未写或只写“按公司通知” | 必须改：写明起算点和日历到期日 | 已经起算 |
| 数周脱产外部技术培训，服务期 2–3 年，费用与期间可回链 | 可接受或可优化；仍要写递减 | 必然有效 |
| 1–3 天入职或安全课，服务期 3 年以上 | 红线：定性已不是专项培训；删除服务期 | 法无上限所以可签 |
| 费用较低或培训很短，服务期 8 年、10 年或“至退休” | 必须改：缩至与费用和培训时间相适应的期间；修改句给出可回链的月数，未给定用 `【待填】` | “法无上限，十年也可以” |
| 起算点为入职日、签字日，培训尚未发生 | 必须改：起算点改到培训完成或双方确认完成之日；未完成培训不得起算全部服务期 | 先锁十年再决定训不训 |

不得发明“法定最长三年”或“法定最长五年”。合理性是审查判断，不是另造上限。

### 5.2 与劳动合同期限衔接（硬闸）

支持依据：实施条例第十七条；解释（二）第八条第二项。

劳动合同期满但依照第二十二条约定的服务期尚未到期的，劳动合同**应当续延至服务期满**；双方另有约定的，从其约定。该续延不属于未订立书面劳动合同。

| 文本写法 | 动作 |
| --- | --- |
| 服务期长于劳动合同期限，未写续延 | 必须改：写明劳动合同期限续延至服务期满；另有约定须单独写清 |
| 写“服务期随劳动合同终止而终止”且无双方另有约定的提示 | 提示第十七条缺省是续延；若双方确要提前结束服务期，须明示另有约定，不得假装这是法定缺省 |
| 用户要求本任务改写整份劳动合同的期限、试用期、工时 | 目标停止该部分；交接 `劳动合同·审查`。本任务只改本协议衔接句 |
| 写“期满不续延视为未签书面合同，须付二倍工资” | 必须改。解释（二）第八条：服务期未到期的续延不属于未订立书面劳动合同 |

本任务不改写整份劳动合同正文。

### 5.3 服务期期间的劳动报酬

第二十二条第三款：约定服务期，不影响按照正常的工资调整机制提高劳动者在服务期期间的劳动报酬。文本冻结调薪、排除调薪或把服务期当降薪理由：必须改。

## 节点 6　违约金上限与未履行期间分摊

支持依据：劳动合同法（2012 修正）第二十二条第二款。劳动者违反服务期约定的，应当按照约定支付违约金。两道上限同时适用：

1. 违约金的数额**不得超过**用人单位提供的培训费用；
2. 用人单位要求劳动者支付的违约金**不得超过**服务期**尚未履行部分所应分摊**的培训费用。

建议句固定结构（数字用文本或 `【待填】`）：

`应付违约金 = 可举证的专项培训费用 ×（剩余未履行服务月数 ÷ 总服务期月数）`

| 文本写法 | 动作 |
| --- | --- |
| 已写上述分摊公式，基数限于可举证费用 | 可接受；检查是否排除工资、是否有确认书 |
| “提前离职须全额退还培训费，已服务年限不予扣减” | 红线或必须改。现有依据不支持不分摊的全额 |
| “除退还培训费外，另赔偿最近一年年薪的三倍 / 十倍” | 红线。超过培训费用的部分必须删除。不得用民法典第五百八十五条把超过费用的部分救活 |
| 固定高额违约金，不随已履行期间递减 | 必须改成按未履行期间分摊 |
| 写“违约金不得调整、不得减少” | 删除该句。第二十二条上限不可约定排除 |
| 无费用数字 | 公式可先写入；金额用 `【待填】`；无票据则金额字段停止 |

本任务不输出必得额，不做精算。已履行月数在签署前通常尚未发生，意见里只给公式，不预判离职当月应赔多少。

第二十五条：除第二十二条和第二十三条外，用人单位不得与劳动者约定由劳动者承担违约金。本协议夹带迟到罚款、保密违约金、提前离职违约金（培训分摊之外）、损坏赔偿定额：红线删除。竞业段交 `竞业限制协议·审查`。

## 节点 7　谁赔、谁不赔；强制规范

### 7.1 劳动者不支付违约金的情形（硬闸）

支持依据：实施条例第二十六条第一款；劳动合同法第三十八条。

劳动者依照第三十八条解除劳动合同的，**不属于违反服务期约定**，用人单位**不得要求**支付违约金。第三十八条包括：未按约定提供劳动保护或劳动条件；未及时足额支付劳动报酬；未依法缴纳社会保险；规章制度违法损害权益；因第二十六条第一款致使合同无效；暴力威胁或强迫劳动、违章指挥危及人身安全等。

单位违法解除、违法终止：不得写成劳动者仍须支付服务期违约金。修改句保留抗辩，本任务**不认定**已经构成第三十八条或已经违法解除。

| 文本写法 | 动作 |
| --- | --- |
| “无论因何种原因离职，均须全额支付违约金” | 红线。改为：仅劳动者违反服务期约定时，按未履行期间分摊；依第三十八条解除或因用人单位违法解除、终止的，劳动者无需支付 |
| “单位解除的，劳动者一律支付违约金” | 必须改。仅实施条例第二十六条第二款所列过错解除，才可按约定支付 |
| 未写第三十八条抗辩 | 必须补入。劳动者立场：不接受删除抗辩；单位立场：补入后仍可保留过错解除下的分摊 |
| 用户要本任务确认“已经是被迫离职，不用赔” | 字段停止。只给抗辩条款，转劳动领域，不作出已经解除或已经免责的结论 |

### 7.2 劳动者仍应按约定支付的情形

支持依据：实施条例第二十六条第二款（与劳动合同法第三十九条过错解除对应）：

- 严重违反规章制度；
- 严重失职、营私舞弊，造成重大损害；
- 同时与其他用人单位建立劳动关系，严重影响工作或拒不改正；
- 以欺诈、胁迫或乘人之危使单位违背真实意思订立或变更劳动合同；
- 被依法追究刑事责任。

上述情形下，劳动者仍应按约定支付违约金，且受节点 6 的费用上限和分摊约束。不得扩成“协商解除、不能胜任、经济性裁员也要赔”。协商解除未就返还作出约定：不得在本任务写成当然要赔。

劳动者无正当理由提前辞职（第三十七条预告解除），且不属于第三十八条：属于违反服务期约定的典型情形，可按分摊公式支付。修改句写清这一区分，禁止把第三十七条和第三十八条写成同一后果。

### 7.3 不得限制依法解除劳动合同

不得约定：签署本协议后不得依第三十七条或第三十八条解除；辞职须先经单位批准才生效；依法解除视为根本违约且全额退还。出现上述写法：红线删除。

劳动合同法第二十六条、第二十七条：免除单位法定责任、排除劳动者权利或违反强制规定的部分无效，其余可独立生效。无效有争议的，由仲裁机构或人民法院确认——本任务只给修改句，不宣告整份无效。

### 7.4 与竞业切开

同一文本夹带离职竞业：竞业段交 `竞业限制协议·审查`。服务期违约金与竞业补偿、竞业违约金分别处理，不得互相抵销或打包成一笔“离职总赔付”。第二十三条只作负向识别，不在本任务审竞业补偿是否按月。

### 7.5 争议条款：改写法，不审策略

支持依据：劳动争议调解仲裁法第二十一条。

约定商事仲裁、排除劳动仲裁、只由某地仲裁委管辖而排除履行地：必须改回依法申请劳动争议仲裁。用户追问请求、证据、胜率：目标停止。

## 起草模式与自审

本任务是起草。有完整待签文本要评改时转 `培训服务期协议·审查`。
按框架六步落稿，必须写入下列三闸。出稿后按上文审查节点自审自己的稿，未过不得宣称完成。

### 起草必写

- 标题用「培训服务期协议」；主线只写专项技术培训费用、服务期和按未履行期间分摊的违约金。
- 培训项目、机构、期间、形式写到可回链；费用构成按实施条例第十六条写有凭证的培训费用、培训期间差旅和因培训产生的直接费用。
- 发票抬头必须是实际支付专项培训费用的用人单位。
- 服务期起止可回链，长度与费用数额和培训时间相适应；长于劳动合同期限时写劳动合同续延至服务期满，双方另有约定的从其约定。
- 违约金不得超过培训费用，且按服务期尚未履行部分分摊；公式写清，数字未给用 `【待填】`。
- 劳动者依照劳动合同法第三十八条解除，或用人单位违法解除的，不属于违反服务期，用人单位不得要求支付违约金。
- 约定服务期不影响按照正常工资调整机制提高服务期期间的劳动报酬。

### 附件必附

- 培训费用原始发票复印件或双方确认的费用明细单。
- 培训内容、期间、形式确认材料。
- 与劳动合同期限衔接的续延说明（服务期长于劳动合同期限时）。

### 禁止出现

- 入职培训、安全教育、业务熟悉或无专业技术培训的学历资助设服务期或第二十二条违约金。
- 「离职即全额退还」叠加年薪倍数，或「任何离职都要赔」。
- 「先签后补发票即可主张全额」。
- 冻结调薪或把服务期当降薪理由。
- 把本约写成竞业限制协议或整份劳动合同。
- 培训期间工资默认计入培训费用。
