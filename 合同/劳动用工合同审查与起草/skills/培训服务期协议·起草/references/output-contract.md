# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的培训费、服务期月数；把已失效《合同法》及其解释或劳部发〔1996〕370 号写入结论；输出劳动仲裁请求、举证策略或胜率；把岗前培训写成可履行的第二十二条违约金；把“离职即全额退还+年薪三倍”改成可履行；写成“任何离职都要赔”；把整份劳动合同或竞业当成已完成的本类型审查。

## 1. 触发、单方立场与成果状态

立场（用人单位或劳动者）、授权、签署状态、主要目标。负触发写路由，不启动本类型起草。写明中文成果名称是「培训服务期协议·起草」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、劳部发〔1996〕370 号、法释〔2013〕4 号解释（四），或把 2012 年未改动的第二十二、二十五、三十八条标成失效时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `劳动关系类合同`，子级 `培训服务期协议`。定性理由、易混切开结果（尤其与岗前培训、特殊待遇、`劳动合同·审查` 劳动合同、`竞业限制协议·审查` 竞业的切开）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、发票抬头与文本版本

主体表：用人单位签约名、劳动者姓名、岗位、培训项目、付款名、发票名、授权签字人。发票抬头是否为用人单位。版本表：正文、培训合同、大纲、发票或费用确认书、劳动合同期限页、聊天确认；冲突并列。抬头为个人或无关关联公司、尚无票据：违约金字段停止。

## 5. 培训性质、费用构成与服务期

是否专项技术培训（对照岗前/安全/学历资助）；费用构成是否限于有凭证培训费、培训差旅、其他直接费用；工资是否被不当计入；服务期起止是否与费用和培训时间相适应；服务期是否长于劳动合同期限及是否写续延。缺口标 `G#`。不输出违约金必得额。

## 6. 分摊公式、免责抗辩与强制规范

违约金是否超过培训费用、是否按尚未履行部分分摊；是否写成全额退还或叠加年薪倍数；是否保留第三十八条和单位违法解除免责；过错解除是否被扩成任何离职；是否限制依法解除；是否夹带第二十五条白名单外的劳动者违约金。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把框架“培训期间工资可按地方实践列入”“不愿顺延则服务期随合同终止”直接当作建议句。

## 9. 谈判与签署提醒

谈判顺序：先红线（岗前培训收违约金、无票据仍主张全额、离职全额退还+年薪倍数、任何离职都要赔、限制依法解除），再必须改（分摊公式、费用清单与确认书、服务期缩至相适应、第三十八条抗辩、劳动合同续延），最后可优化。签署提醒：双方签字或盖章、各执一份、发票复印件或费用明细、培训费用确认书、培训大纲、劳动合同期限页、送达地址。不指导倒签或补假发票。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本技能交付可编辑草稿、未决项、自审风险表和自审后修改句。草稿必须覆盖本类型起草必写、附件必附与禁止出现。待签评改转 `培训服务期协议·审查`。不是履约交底、劳动合同或竞业审查、劳动仲裁文书或效力保证。

## 起草模式交付

正触发时先交可编辑草稿和未决项，再交自审风险表与自审后修改句。三闸未落入正文或附件的，不得宣称起草完成。
