# 审查方法（锁定 劳动关系类合同 / 业务外包（派遣型）合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止把劳动争议套件原子正文抄进本任务。禁止把 `劳务派遣协议·审查` 的三性、10%、派遣许可证正文当作本类型主路径。禁止把 `承揽合同（个人劳务）·审查` 的个人承揽验收或 `平台用工相关协议·审查` 的接单自主正文当作本类型主路径。

定性校验：标题、签署方与核心给付与本类型一致才继续；劳务派遣、个人承揽、平台用工、个人劳务承包、劳动合同或他类明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、劳动仲裁必然胜诉或唯一必得金额。

`search_law` 返回已失效《合同法》及其解释、2007 年劳动合同法第五十七条“注册资本不得少于五十万元”时记为噪声，不得写入 `L#`。2012 年修正未改动而本次只命中 2007 文本的条文，引用 2012 修正，不得标失效。本次未完整返回的 2012 年第五十七条、第九十二条全文，法律结论字段运行时再核；许可条件以《劳务派遣行政许可实施办法》第六条、第七条吸收，不得把五十万旧文写入结论。

示范文本只参考组织对组织业务外包/服务外包栏目。命中劳务派遣协议或建设工程劳务分包范本不得粘贴充作本约。

知识库纠正（不回写双文件）：

- `基本面.md` 把民法典第一千一百九十一条写成真外包“场地、设备过错仍须比例责任”的主口径：真外包第三人损害与承揽人自身损害走第一千一百九十三条（定作、指示或选任过错）及侵权责任编解释（一）第十八条。第一千一百九十一条第二款只在被穿透为劳务派遣时适用。场地、设备过错可构成第一千一百九十三条的定作/指示过错，或触发安全生产法第四十九条的统一协调、管理义务，不得写成发包方必然按派遣用工单位担全责。
- `基本面.md` “发包方不承担任何劳动法项下的义务”：只能作为内部追偿安排。被认定为假外包真派遣、或转包给无用工主体资格的组织/自然人时，法定用工主体责任不因该句消失（暂行规定第二十七条；法释〔2014〕9 号第三条；法释〔2025〕12 号第一条）。
- `框架.md` “乙方无需《劳务派遣经营许可证》”：仅说明真外包不以该证为签署前置。假外包不得用这句话放行。不得反过来要求真外包必须持派遣证。
- `基本面.md` 《人力资源服务许可证》“虽非强制”：采纳；不得写成签署能力要件，也不得写成已证明管理独立。
- `框架.md` 争议“严禁使用劳动仲裁程序”：指本约两组织之间的商事争议。承包方与其员工之间的劳动争议依法仲裁，本任务不审该策略。

先于类型识别。命中任一项则本任务不填十节实体结论，只交付分流理由和最小交接。

| 已能支持的事实 | 走向 | 不得写成 |
| --- | --- | --- |
| 无可读正文和附件，或只有口头“找家公司派人”要点 | `业务外包（派遣型）合同·起草` | 已经完成审查；可以按外包签 |
| 未签，目标是评改两个组织之间的已有外包/服务外包文本 | 进入节点 1 | 已签署或已生效 |

### 1.3 规避结构停笔

动作：

1. 交付告知：该结构可能落入暂行规定第二十七条，不得改写成可履行规避文本。

3. 风险表只保留识别依据和红线/改正句。

## 节点 2　主体与行业资质

支持依据：民法典第七百七十条；安全生产法（2021 修正）第四十九条；保安服务管理条例（2022 修订）第四十一条；法释〔2014〕9 号第三条；法释〔2025〕12 号第一条。

### 2.1 主体表

建表：发包方签约名、承包方签约名、付款名、发票名、现场管理人员姓名/职务、授权签字人。名称不一致不自动合并。口头“我们老板同意了”不得写成已授权。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 承包方是企业法人或其他组织，经营范围覆盖拟外包业务 | 继续 | 经营范围等于已具备行业许可 |
| 承包方是自然人，或“某某（身份证号）承包甲方车间” | 负触发 `承揽合同（个人劳务）·审查` 或 `个人劳务承包合同·审查` | 在本任务改成可履行组织外包 |
| 承包方将业务转包给无用工主体资格的组织或自然人 | **红线**；告知用工主体责任风险 | 加一句“责任自负”即可放行 |
| 只见到承包方持有《劳务派遣经营许可证》 | 标红旗：持证不等于本约是派遣，也不等于本约已隔离；按管理权和结算再定性 | 有派遣证所以一定是真外包；有派遣证所以必须按派遣审完（除非核心给付已是派遣） |

### 2.2 行业许可

真外包**不要求**《劳务派遣经营许可证》。特许业务必须核行业许可。

| 业务 | 未见许可时的动作 |
| --- | --- |
| 保安服务 | 红线；保安服务管理条例第四十一条：未经许可擅自从事保安服务 | 不得改成可履行无证保安外包 |
| 危化装卸、特种设备作业、医疗废物、配电维保等 | 签署能力字段停止；列出待补许可名称、编号、有效期；用户承认无证则红线 |
| 普通保洁、普通呼叫、一般 IT 运维 | 不把派遣证或人力资源服务许可证写成必须附件 |

修改句（保安无许可）：

`定位（主体/资质条款）｜原文：乙方负责甲方厂区保安服务｜建议改为：乙方须持有有效期内的保安服务许可证（编号【待填】，有效期至【待填】），并在签署前向甲方出示正本、交付复印件作为附件。未见有效许可前，本协议不生效，甲方无义务接收服务。｜理由：保安服务管理条例第四十一条｜可退让点：可给【待填】个工作日补正，补正前不得上岗｜不接受时的红线：不签署；不得改成“劳务派遣”或“个人雇佣保安”规避`

修改句（发包给无安全生产条件主体）：

`定位（主体/转包条款）｜原文：乙方可将人员或业务转包给第三方｜建议改为：未经甲方书面同意，乙方不得将本协议项下业务转包或分包给不具备相应资质或用工主体资格的组织、个人。违反本款的，甲方有权解除并按本协议追偿；因此依法由甲方承担用工主体责任或安全生产责任的，乙方应全额补偿，该约定不对抗劳动者或第三人。｜理由：安全生产法第四十九条；法释〔2014〕9 号第三条；法释〔2025〕12 号第一条｜可退让点：辅助性工作转包须事先书面同意并附资质｜不接受时的红线：保留任意转包则建议不签`

## 节点 3　真外包 vs 假派遣（用工管理权，硬闸）

支持依据：《劳务派遣暂行规定》第二十七条；劳动合同法 2012 修正第六十六条（仅作穿透后的对照，不在本任务写三性放行路径）；民法典第七百七十条。

核心测试：以事为标的，还是以人为标的。

| 文本或已承认事实 | 判断形状 | 动作 |
| --- | --- | --- |
| 承包方自行招聘、培训、考勤、考核、奖惩；发包方只按 SLA 验收；指令只发给现场管理人员 | 现有依据支持按本类型继续 | 仍须检查结算、标的独立性 |
| 发包方有权面试、筛选、否决派驻人员 | 假外包红旗 | 必须改：改为“乙方指派人员应符合附件技能资质，甲方仅核对证件与资质，不参与录用决定” |
| 发包方直接考勤、打卡、排班、批准请假、安排加班 | 假外包红旗 | 必须改或红线 |
| 发包方对承包方员工直接奖惩、调岗、扣钱、开除 | 假外包红旗 | 红线删除；改由乙方按自有制度处理 |
| 发包方主管直接给外包员工开会分派具体任务，无现场管理人员 | 指挥链混同 | 必须改：指定乙方现场负责人；指令走《业务指令单》 |
| 用户承认实际就是派人到岗接受甲方车间主任管理，合同只是叫外包 | 假外包真派遣 | 点名暂行规定第二十七条；不保证外包外壳有效；拒改则整体停止 |

修改句（面试权）：

`定位（人员条款）｜原文：甲方有权面试并决定乙方派驻人员｜建议改为：乙方自主招聘、录用并指派完成本协议业务的人员。乙方保证指派人员具备附件列明的技能与资质证书。甲方仅有权核对证件与资质是否符合附件标准；不符合的，甲方可书面通知乙方在【待填】日内更换，不得对具体人员进行录用面试、试用或淘汰决定。｜理由：暂行规定第二十七条；框架“技能资质≠录用决定”｜可退让点：可约定岗位技能清单作为附件｜不接受时的红线：保留甲方面试决定权则建议不按真外包签署`

修改句（越级指挥）：

`定位（管理条款）｜原文：甲方可直接安排乙方人员加班、调岗并考核｜建议改为：乙方员工的考勤、考核、奖惩、岗位调整、加班安排和请假审批由乙方自行实施。甲方仅通过乙方委派的现场负责人（姓名【待填】，职务【待填】）以《业务指令单》提出业务需求。甲方不得向乙方员工个人下达用工指令。｜理由：暂行规定第二十七条；基本面“防火墙”｜可退让点：紧急安全制止权可单列，但不等于日常用工指挥｜不接受时的红线：保留越级用工指挥则建议不签，或改口走 `劳务派遣协议·审查` |

禁止：把“甲方面试一下更放心”写成可优化惯例。禁止在本任务输出“改成临时性/辅助性/替代性即可放行”的派遣合规路径。

## 节点 4　标的独立性与 SLA

支持依据：民法典第七百七十条；基本面“以事为标的”。

外包标的必须是可独立核算、有明确交付标准的业务或工段，而不是“劳动力小时”。

| 文本写法 | 动作 |
| --- | --- |
| 写明业务范围、产出、响应时间、合格率，并附 SLA | 继续；缺数字用 `【待填】` |
| 只写“派驻 XX 人到甲方车间听从安排” | 必须改：改写业务产出与验收标准；人数只能作为乙方内部编制，不得当标的 |
| “等有关服务”“按甲方随时要求派人” | 标缺口；必须改成封闭业务包 |
| 无验收标准，签收或付款视为验收 | 必须改：验收与付款分列 |

修改句（派人充标的）：

`定位（标的条款）｜原文：乙方派驻 30 人到甲方包装车间听从甲方安排｜建议改为：乙方承包甲方【待填厂区】成品包装业务，月度完成包装量【待填】件，破损率不超过【待填】%，按附件《业务质量考核标准（SLA）》验收。乙方自行决定完成该业务所需的人员编制与班次。｜理由：民法典第七百七十条；基本面业务独立性｜可退让点：可写预估编制但不作为结算依据｜不接受时的红线：标的仍是“派多少人”则不得按真外包放行`

## 节点 5　去人头化结算与发票（硬闸）

支持依据：基本面/框架去人头化；暂行规定第二十七条（按人头结算是派遣用工形式的典型信号）。

| 文本写法 | 动作 |
| --- | --- |
| 单价×业务量，或总包费+质量绩效；报酬含劳务、社保、管理、税费 | 继续；数字 `【待填】` |
| 人数×单价，或“基本工资+五险一金+管理费”为唯一计费 | **必须改或红线** |
| 发票品名为劳务费、人头费，或开个人抬头 | 必须改：服务费/外包费增值税发票 |
| 发包方直接给外包员工发工资、报销、发福利 | 红线；切断真外包外观 |

修改句（人头费）：

`定位（价款条款）｜原文：甲方按每人每月【待填】元向乙方支付服务费｜建议改为：甲方按附件计价规则向乙方支付外包服务费：【待填业务量单位】×单价【待填】元，并按 SLA 考核上下浮【待填】%。该费用已包含乙方完成业务所需的人工、社会保险、管理及税费。双方不得按出勤人头另行结算。｜理由：暂行规定第二十七条；框架去人头化｜可退让点：可约定业务量上下限，但计费基数不得改回人头｜不接受时的红线：坚持人头单价则建议不按真外包签署`

修改句（发票）：

`定位（发票条款）｜原文：乙方开具劳务费发票 / 个人收据｜建议改为：乙方在结算后【待填】日内向甲方开具品名为“服务费”或“外包服务费”的增值税发票，抬头为甲方全称。不得开具“劳务费”“人头费”或个人抬头发票。｜理由：框架发票合规；去派遣化表达｜可退让点：专票/普票可谈｜不接受时的红线：坚持开劳务费或个人收据则必须改`

## 节点 6　工伤、第三人损害与内部追偿

支持依据：民法典第一千一百九十一条、第一千一百九十二条、第一千一百九十三条；侵权责任编解释（一）第十五条、第十六条、第十八条；法释〔2014〕9 号第三条；法释〔2025〕12 号第一条。

| 场景 | 本任务口径 | 不得写成 |
| --- | --- | --- |
| 真外包，承包方员工在场受伤 | 由与其建立劳动关系的承包方申报工伤并承担责任；可约定雇主责任险及内部补偿 | 发包方已免责；商业险已替代工伤保险 |
| 真外包，承包方员工致第三人损害 | 第一千一百九十三条：原则上承揽人担责；发包方仅在定作、指示或选任过错范围内共同担责 | 约定“责任自负”即对外免责；直接套用第一千一百九十一条第二款由用工单位担全责 |
| 被穿透为派遣 | 才讨论第一千一百九十一条第二款及解释（一）第十六条 | 在未穿透时把发包方写成派遣用工单位 |
| 个人之间劳务 | 第一千一百九十二条；本类型不应出现。命中则负触发 `个人劳务（雇佣）合同·审查` / `承揽合同（个人劳务）·审查` | 用个人劳务规则审组织外包 |
| 发包给无用工主体资格者 | 法释〔2014〕9 号第三条、法释〔2025〕12 号第一条：可能由发包方承担用工主体责任 | 加免责句即可切断 |

修改句（工伤与保险）：

`定位（工伤/保险条款）｜原文：外包人员在甲方场地受伤与甲方无关｜建议改为：乙方员工与乙方建立唯一劳动关系。乙方应为全部相关人员缴纳工伤保险，并投保保额不低于【待填】元/人的雇主责任险，可将甲方列为共同被保险人或附加放弃对甲方追偿。乙方员工因工受伤的，由乙方依法申报并承担工伤保险责任。因乙方未参保、欠缴或选任不当导致甲方被依法追索的，乙方应在【待填】日内全额补偿甲方已付费用；该约定不对抗劳动者。｜理由：第一千一百九十三条；法释〔2014〕9 号第三条｜可退让点：保额数字可谈；共同被保险可改为附加放弃追偿｜不接受时的红线：弃工伤或写成受伤自负则不签`

修改句（第三人损害）：

`定位（侵权条款）｜原文：乙方人员造成任何损害均与甲方无关，甲方不承担任何责任｜建议改为：乙方人员执行本协议业务造成第三人损害的，由乙方依法承担。甲方仅在对定作、指示或选任有过错的范围内依法承担相应责任。甲方对外承担责任后，有权就超出自身过错的部分向乙方追偿。双方约定不得对抗第三人。｜理由：第一千一百九十三条；解释（一）第十八条｜可退让点：内部追偿比例可谈｜不接受时的红线：对外“概不负责”且拒改则建议不签`

## 节点 7　安全生产、数据、语言与争议条款

### 7.1 进场与安全生产

支持依据：安全生产法第四十九条。

生产经营项目、场所发包的，应签订专门安全生产管理协议或在本合同中约定各自安全职责；发包方对承包方安全生产工作统一协调、管理，定期检查并督促整改。该“统一协调”**不等于**用工指挥权，修改句须把安全检查与考勤奖惩分开。

不得将项目、场所、设备发包给不具备安全生产条件或相应资质的单位或个人。

### 7.2 数据与保密

涉及发包方数据、场所的，约定数据所有权、最小权限、离场删除和泄密后果。不得把外包员工写成“甲方员工”。

### 7.3 语言去派遣化

| 禁用或高风险用语 | 改为 |
| --- | --- |
| 派遣、派遣工、外包工、人头费、月薪、加班费（作为本约结算项） | 乙方员工/乙方指派人员；外包服务费/业务费 |
| 甲方批准请假、甲方安排加班 | 乙方现场负责人按乙方制度处理；甲方只提业务需求 |
| 本协议适用劳动仲裁 | 本约两组织争议由被告住所地或合同履行地人民法院管辖，或单一商事仲裁机构 |

### 7.4 争议条款：改写法，不审策略

本约是普通民事/商事合同。写成“双方劳动争议提交劳动仲裁”：必须改。承包方与其员工的劳动争议依法仲裁，本任务不写请求、证据或胜率。用户追问：目标停止，转劳动领域。

修改句（误用劳动仲裁）：

`定位（争议解决）｜原文：因本合同引起的争议提交甲方所在地劳动争议仲裁委员会｜建议改为：因本协议引起的发包方与承包方之间的争议，由【待填：被告住所地或合同履行地】人民法院管辖。乙方与其员工之间的劳动争议由乙方依法另行处理，不适用本条。｜理由：本约属民事合同；框架禁止两组织之间走劳动仲裁｜可退让点：可改成单一商事仲裁机构，不得或裁或诉｜不接受时的红线：坚持劳动仲裁管辖本约则必须改`

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

打开已加载的 `框架.md`，按六步逐段对照正文。`基本面.md` 用于校验类型、主体、管理权、结算、结构和红旗，不代替本节点出句。

| 步 | 动作 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题用“业务外包协议”或“服务外包合同”；禁用派遣/人头费；主体称发包方/承包方；鉴于写乙方技术、设备与管理能力，写明民事承揽或服务关系 | 标题、主体或鉴于修改句 |
| 交易条款 | 业务产出与 SLA；乙方自主用工；去人头化结算；设备自备或约定借用/租赁 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 质量违约扣款；劳动争议隔离与内部追偿；工伤与雇主责任险；安全生产协议；数据保密 | 可执行后果句或删除句 |
| 尾部 | 双方公章；附件：SLA、人员名单及社保证明（仅备案）、安全生产管理协议、现场管理人员任命 | 生效与附件修改句 |
| 语言 | 乙方员工≠外包工；外包服务费≠人头费；合同管理权≠用工指挥权 | 替换派遣化用语 |
| 常见问题 | 面试权；越级指挥；人头结算；无现场管理人员；争议走劳动仲裁 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（假外包拒改、人头费拒改、无证特许、无证派遣改外包、自然人承包充组织外包、本约走劳动仲裁、弃工伤）；
- `必须改`：可谈但签署前要落句（管理权沉默、无现场管理人员、无 SLA、发票品名、内部追偿、安全生产协议）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。假外包且用户拒绝改正管理权与结算：停止“可以签署”建议。
