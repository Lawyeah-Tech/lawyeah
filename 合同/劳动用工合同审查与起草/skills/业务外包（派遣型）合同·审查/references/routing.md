# 边界与路由

本技能只审查 **劳动关系类合同 / 业务外包（派遣型）合同** 的待签商事文本。签署方是发包单位与承包单位两个组织。显示名是「业务外包（派遣型）合同·审查」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 劳务派遣协议：持证派遣单位派人，用工单位指挥监督，按人头/工时结算 | `劳务派遣协议·审查`。本任务不写三性、10%、派遣许可证放行路径 |
| 标题外包，外包方不管理业务、人完全服从发包方指挥和考勤、按人头结算 | 留本任务；点名假外包红旗；禁止只改标题；用户改口要派遣合规 → `劳务派遣协议·审查` |
| 自然人承揽、按件/按项目交付、自备工具 | `承揽合同（个人劳务）·审查` |
| 平台用工、网约配送、接单协议 | `平台用工相关协议·审查`；专业版未装则 `unavailable` |
| 个人劳务承包、包工头式自然人组织劳动力 | `个人劳务承包合同·审查`；专业版未装则 `unavailable` |
| 全日制劳动合同、用人单位与劳动者两方签约 | `劳动合同·审查` |
| 平等主体个人劳务、雇佣协议 | `个人劳务（雇佣）合同·审查` |
| 非全日制、小时工 | `非全日制劳动合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `业务外包（派遣型）合同·起草` |
| 已签未争、只问进场、验收日、付款日履约 | 本套导航的履约步骤 |
| 已申请或拟申请劳动仲裁、要证据或应诉策略 | `已申请或拟申请劳动仲裁要证据或应诉策略` / `劳动仲裁证据整理` / `继续当签前审查；输出仲裁策略`。本技能不审仲裁策略 |
| 工伤索赔整案 | `工伤索赔整案` 或劳动领域对应原子。本约只审工伤归属与内部追偿写法 |
| 已成争的普通合同路径 | `已成争的普通合同路径` 或劳动领域，不继续签前审查 |
| C 端大众快检 | 只分流，不回改 |

本约夹带劳动者劳动合同或派遣协议附件：附件整段交接 `劳动合同·审查` 或 `劳务派遣协议·审查`；外包正文继续审。用户坚持本技能给出派遣三性/10% 放行、个人承揽验收整案、平台接单规则、仲裁胜率或工伤赔付终值：`目标停止`。
