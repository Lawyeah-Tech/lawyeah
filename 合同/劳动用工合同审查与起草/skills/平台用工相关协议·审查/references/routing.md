# 边界与路由

本技能只审查 **劳动关系类合同 / 平台用工相关协议** 的待签文本。显示名是「平台用工相关协议·审查」。场景分层为 P1：专业版未装则 `unavailable`，提示，不得用邻类硬套。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 全日制书面劳动合同，工时工资社保岗位齐全，无平台派单主轴 | `劳动合同·审查` |
| 按人头派驻、三方派遣、需要或持有《劳务派遣经营许可证》作为主给付 | `劳务派遣协议·审查` |
| 职业介绍、猎头、岗位撮合，中介不派单 | `职业介绍／猎头撮合双方建立劳动关系，中介自己不派单→`。P1：未装则 `unavailable` |
| 假外包真派遣、人员接受发包方直接管理 | `业务外包（派遣型）合同·审查`。P1：未装则 `unavailable` |
| 个人劳务承包，无平台算法 | `个人劳务承包合同·审查`。P1：未装则 `unavailable` |
| 个人劳务雇佣，无平台算法 | `个人劳务（雇佣）合同·审查` |
| 个人承揽，无平台算法 | `承揽合同（个人劳务）·审查`。P1：未装则 `unavailable` |
| 托运人与网络货运平台的货物运输，平台以承运人身份收运费、开运输票 | `合作文本。托运人与网络货运经营者之间以承运人身份揽货并收运费开运输票的，负触发`。P1：未装则 `unavailable` |
| 货源／运力信息撮合，平台不承运、不收运费、不开运输票 | `仅为货源／运力信息撮合不承运不收运费的运输中介文本，负触发`。P1：未装则 `unavailable` |
| 无文本、本类型条件已谈妥、要出己方稿 | `平台用工相关协议·起草` |
| 已签未争、只问结算、职业伤害申报或规则改版日历 | 本套导航的履约步骤 |
| 已催告、索赔、立案、开庭，或主问确认劳动关系、劳动仲裁怎么打 | `已成争的普通合同路径` 或劳动争议专项 |
| C 端大众快检 | 只分流，不回改 |

标题写“平台服务协议”或“信息技术服务协议”，正文却是托运人下单、平台承运、运费发票：不在本任务补接单自主性后放行。负触发 `合作文本。托运人与网络货运经营者之间以承运人身份揽货并收运费开运输票的，负触发`。

标题写“运输合作”，正文却是骑手／司机注册、算法派单、按单抽成、封号：留在本任务，按三分法和算法闸审查，不转运输原子。

标题写“众包合作”，正文强制排班、实时考勤、不能拒单：三分法归入劳动关系，不按民事改完；劳动本约细节转 `劳动合同·审查`，本任务不审试用期或加班费精算。

仅缺抽成数字、结算周期或保额，但给付仍是平台—从业人员：留在本任务，必须出显化句。

用户要把实质劳动管理改成可履行民事合作：不按本类型放行。要求按用工事实改订或转 `劳动合同·审查`，不把去劳动化话术写成修改句。
