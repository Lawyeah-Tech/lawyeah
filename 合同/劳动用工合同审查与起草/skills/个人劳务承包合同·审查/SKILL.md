# 个人劳务承包合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把 2003 年人身损害解释第十一条当作现行默认。劳动合同法第九十四条引用 2012 年修正文本；2012 年修正未改该条文字的，不得把 2007 文本标成失效。不得把“伤亡概由乙方负责”或“建筑活先包给个人再补资质”写成已经可履行。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **劳动关系类合同 / 个人劳务承包合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。显示名为「个人劳务承包合同·审查」。专业版未装本原子时输出 `unavailable`，提示，不得用邻类硬套。

`depends-on` 为空。不要求先跑导航。

不交付：他类合同审查；从零起草；履约交底；争议文书或行权策略；有效性保证；把建筑工程或强制准入作业发包给个人改成可履行结构；把伤亡或欠薪绝对免责改成可履行。

## 本类型硬闸

1. **承包 ≠ 劳动 ≠ 个人承揽**。本类型给付是：企业把特定工段或劳务作业发包给**自然人包工头**，包工头**自行招用并组织班组**，企业按**完成量**向包工头结算。企业直接指挥劳务人员、提供主要生产工具、考勤奖惩、发固定月薪、写“入职／试用” → `劳动合同·审查`。自然人亲自提供劳务过程、无班组招用 → `个人劳务（雇佣）合同·审查`。个人独立完成并交付特定工作成果（设计稿、加工件、软件、宣传片） → `承揽合同（个人劳务）·审查`。禁止把 `承揽合同（个人劳务）·审查` 的成果交付、留置权、随时解除套进本任务后换“承包”交差。
2. **资质与安全责任**。房屋建筑和市政基础设施工程**严禁个人承揽分包**。高空、电工维保、特种设备等强制准入作业发包给无资质个人：停笔告知，不改成可履行。选任、指示、定作过错，以及劳动合同法第九十四条、安全生产法第一百零三条、农民工工资条例第三十六条的法定清偿／连带，不得用“伤亡／欠薪概由乙方负责”抹掉。雇主责任险或意外险是进场前置，不是免责对价。
3. **与企业外包／派遣切开**。承包方是独立法人、按项目整体外包 → `业务外包（派遣型）合同·审查`。按人头派驻、接受用工单位直接管理 → `劳务派遣协议·审查`。管理隔离墙必须写清（指令只对包工头），但隔离墙不能写成已经消灭法定连带。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

禁止表述：建筑活也可以先包给个人再补资质；伤亡概不负责已经有效；写了“民事承揽”就不会被认定为劳动；个人承包就是企业业务外包；先签再改；合同一定有效或全部无效。

## 工作边界

正触发：已有可读待签文本要评改；尚未签署，尚未成争，核心给付是自然人包工头组织班组、按完成量结算的普通民事劳务作业；用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 人格、组织、经济从属可回链，企业直接管理个人 → `劳动合同·审查`；
- 自然人亲自提供劳务过程，无班组招用 → `个人劳务（雇佣）合同·审查`；
- 个人独立完成并交付特定工作成果 → `承揽合同（个人劳务）·审查`（P1 未装则 `unavailable`）；
- 承包方是法人或组织，按项目整体外包 → `业务外包（派遣型）合同·审查`（P1 未装则 `unavailable`）；
- 按人头派驻、三方派遣、需要或持有《劳务派遣经营许可证》 → `劳务派遣协议·审查`；
- 平台派单、算法管理、按单计酬 → `平台用工相关协议·审查`（P1 未装则 `unavailable`）；
- 房屋建筑、市政基础设施的专业分包或劳务分包，或任何“严禁个人承揽”的工程作业 → 建设工程类审查原子或引擎重新定性；本任务只出告知，不改成可履行个人承包；
- 无文本、本类型条件已谈妥、要出己方稿 → `个人劳务承包合同·起草`；
- 已签只问进场、结算、保险续保节点 → 本套导航的履约步骤；
- 已催告、索赔、立案、开庭、仲裁，或主问工伤／欠薪怎么打 → `已成争的普通合同路径` 或劳动争议专项。

挂靠出借资质、违法分包、把强制准入作业发包给个人：只出告知，不改写成可履行结构。用户坚持“改到能做”：整体停止。

## 建立审查坐标

确认：使用者与授权；单方立场（发包企业／承包自然人择一）；相对方；全文及附件版本；承包方是否自然人；是否自行招用班组；作业内容是否属于建筑施工或强制准入；发包方是否直接考勤指挥劳务人员；工具由谁提供；结算是完成量还是人头／月薪；有无安全交底、选任记录、强制保险；有无代发或工资清单；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

### 0. 签署状态与成果分流

无书面文本 → `个人劳务承包合同·起草`；已签履约 → 本套导航履约步骤；已成争或主问工伤／欠薪胜率 → 争议或劳动专项。未签且目标是评改已有个人劳务承包合同，才进入本任务。

### 1. 类型锁死（班组承包 ≠ 劳动 ≠ 个人承揽 ≠ 企业外包）

标题、核心给付与“包工头自行招用班组、按完成量结算”一致才继续。劳动本约、个人亲自劳务、个人成果承揽、企业外包、派遣、建筑分包负触发。

### 2. 主体、选任与资质红线

发包方是否企业；承包方是否自然人；有无冒用单位名义；作业是否强制准入。建筑或强制准入：停笔。普通民事劳务：必须留下选任审核记录要求。

### 3. 管理隔离墙与从属信号

指令只对包工头。出现跨级考勤、直接发薪且无受托支付、入职试用：先判断是否已滑向 `劳动合同·审查`。仍属本类型的，必须改句。

### 4. 安全交底、强制保险、伤亡条款

进场前安全教育与确认书；雇主责任险或高额意外险作为入场前置。伤亡条款只可写内部追偿，不得写发包方对外绝对免责。

### 5. 量价闭环与欠薪支付管控

固定单价／总价按完成量结算。先完工、后验收、再结算。代发必须写成受托支付。工资保证金可留，不得写成已经消灭条例第三十六条的清偿。

### 6. 程序、附件、语言

花名册、计价单、安全生产责任书、知情确认书。去劳动化表述不得抹掉班组人员工资清单。

### 7. 争议改写法

或裁或诉改单一连结点。不审工伤、欠薪或劳动仲裁策略。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。定性切开句、资质／安全句、隔离墙与欠薪句不得省略。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、挂靠补假资质、把建筑或强制准入作业发包给个人改成可履行、把伤亡或欠薪绝对免责改成可履行、把劳动／个人承揽／企业外包结构按本类型放行、保证有效。
- `字段停止`：法域、动态规则、选任记录、保单真伪或地方保证金比例未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或把本合同改成劳动合同／个人承揽／企业外包。

班组人员生存级欠薪或工亡线索且用户拒绝升级：停止放行建议，只列风险与转介。
