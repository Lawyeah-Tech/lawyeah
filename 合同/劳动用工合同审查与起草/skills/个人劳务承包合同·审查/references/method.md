# 审查方法（锁定 劳动关系类合同 / 个人劳务承包合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止把 `承揽合同（个人劳务）·审查`（个人成果承揽）或 `业务外包（派遣型）合同·审查`（企业业务外包）的 method 拼贴后换“承包”当作本文件。禁止套用成果留置权、定作人随时解除、企业外包 SLA／去人头化结算正文。

本文件的主线是 **自然人包工头组织班组、按完成量结算的三层民事承包**：发包企业不直接管理劳务人员，包工头自行招用并计酬。三道硬闸必须走完：承包≠劳动≠个人承揽、资质与安全责任、与企业外包／派遣切开。缺一闸不得宣称审查完成。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受，或“写了民事承揽就不会被穿透”。

`search_law` 返回已失效《合同法》及其解释、2003 年人身损害解释第十一条、1997 年建筑法未对照 2019 修正、劳动合同法 2007 文本被单独标失效时记为噪声，不得写入 `L#`。把伤亡绝对免责或“先包给个人再补资质”写成已经合法的，同样记噪声。

示范文本只参考结构。检索到的《砼班组劳务合同》《模板工程承包合同》或企业间《劳务分包合同》常是建筑工程分包，**不是本类型建议句**。

知识库纠正（不回写双文件）：

- `基本面.md` “属于民事承揽合同或非典型的商事外包合同”：外观可参照承揽的量价结构，但本类型灵魂是**班组招用**，不是个人独立交付成果，也不是企业间项目外包。不得据此按 `承揽合同（个人劳务）·审查` 或 `业务外包（派遣型）合同·审查` 出十节。
- `基本面.md` “明确约定包工头对其招用人员的工资发放及人身安全负有全部管理和法律责任”：内部管理与追偿可以写；**不得写成发包方对外已经免责**。劳动合同法第九十四条、安全生产法第一百零三条、农民工工资条例第三十六条、工伤保险行政案件规定第三条第四项仍可能对外追及发包组织。
- `框架.md` “本协议为民事承揽法律关系……招用人员不享有甲方的劳动待遇”：标签不能阻止从属穿透。有跨级考勤、直接发月薪、入职试用的，按核心给付切开，不在本任务用标签挽救。
- `框架.md` 严禁使用“工资”、改用“承包款、劳务费”：甲乙之间的结算用承包款／劳务费；班组人员领取的款项在农民工工资条例语境下仍是工资。受托支付清单、无拖欠声明可以出现“工资”，不得机械删除。
- `框架.md` “劳务人员在工作中发生伤亡，由乙方作为雇主承担赔偿责任”：须加选任／指示／定作过错及法定连带分层。造成人身损害的免责条款依民法典第五百零六条无效。
- 2003 年人身损害解释第十一条（发包人知道雇主无资质则连带）MCP 标**已被修改**。现行默认用民法典第一千一百九十二条、第一千一百九十三条，安全生产法第一百零三条，劳动合同法第九十四条，法释〔2014〕9 号第三条，法释〔2025〕12 号第一条。不得把旧第十一条写成现行条文。

## 节点 1　类型识别与单目录加载

### 1.1 定性（本类型灵魂闸）

用标题、核心给付和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须同时满足才正触发：

1. **承包方是自然人**（包工头／班组组织者），不是法人或非法人组织。
2. **自行招用并组织班组**：劳务人员由承包方招用、计酬、管理；存在或将存在花名册意义上的第三人。
3. **按完成量向包工头结算**：搬运吨数、加工件数、作业面工程量，而不是按人头月薪或按件向每个劳务人员直接发固定工资。
4. **作业属于普通民事劳务**：临时装卸、季节采摘、非核心手工加工、简单装配等。不是房屋建筑或市政基础设施施工，也不是依法必须由有资质单位实施的特种作业。

缺第 1 或第 2 项：不是本类型。缺第 4 项：停笔，不按本类型放行。禁止用邻类知识把缺项补成“完整个人承包”后宣称审完。

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 《个人劳务承包协议》《班组劳务承包合同》，写明乙方自行招用人员、按完成量结算、甲方只对乙方发令 | 本类型 | 正触发；三道硬闸都审 |
| 标题普通承包，正文是自然人组织装卸班组按吨结算 | 本类型 | 正触发；标题改成个人劳务承包／班组劳务承包 |
| 甲方对劳务人员打卡、奖惩、发月薪、写试用期或入职 | 劳动合同 | 负触发 `劳动合同·审查` |
| 自然人亲自搬运／保洁／咨询，无招用他人 | 个人劳务（雇佣） | 负触发 `个人劳务（雇佣）合同·审查` |
| 个人交付设计稿、加工件、软件、宣传片，自备工具独立完成，无班组 | 承揽合同（个人劳务） | 负触发 `承揽合同（个人劳务）·审查` |
| 承包方是公司，按项目整体外包，派人到场 | 业务外包（派遣型） | 负触发 `业务外包（派遣型）合同·审查`（未装则 `unavailable`） |
| 按月按人头派驻，接受用工单位管理 | 劳务派遣 | 负触发 `劳务派遣协议·审查` |
| 平台派单、按单计酬 | 平台用工 | 负触发 `平台用工相关协议·审查` |
| 土建主体、砌筑、模板、混凝土、市政管网等工程作业包给个人 | 违法分包／建设工程 | 停笔告知；不改成可履行个人承包 |

### 1.2 加载协议（硬闸）

本技能已锁定 **劳动关系类合同 / 个人劳务承包合同**。只打开 `references/基本面.md` 与 `框架.md`。禁止读其他类型目录，禁止为对照再开第二类。禁止打开 `承揽合同（个人劳务）` 或 `业务外包（派遣型）合同` 的双文件来“补全”本任务。

### 1.3 违法结构停笔

加载后或定性中出现：把房屋建筑或市政基础设施工程发包或分包给个人；把必须由有资质单位实施的高空、电工、特种设备作业发包给无资质个人；挂靠或出借建筑业企业资质；倒签进场日期或补假选任／保险材料；把伤亡或欠薪绝对免责改成可履行；把劳动、个人承揽或企业外包结构改写成班组承包以规避劳动法或派遣许可。

动作：

1. 交付告知：房屋建筑和市政基础设施工程施工分包管理办法第八条“严禁个人承揽分包工程业务”；建工解释（一）第一条无资质、借用资质、违法分包合同无效；安全生产法第一百零三条发包给无资质或无安全生产条件的单位或个人，事故损害连带。不得改写成可履行规避文本。
2. 不写假资质模板、倒签步骤、可履行的无资质进场路径、可履行的“工伤概不负责”。
3. 风险表只保留识别依据和删除／转出口径。
4. 用户坚持“改到能签且仍发包给个人做建筑活／仍绝对免责”：整体停止。

## 节点 2　主体、选任与资质（硬闸）

### 2.1 主体表

建表：发包企业、承包自然人、班组劳务人员（非本约相对方）、签约名、履行名、付款名、授权签字人。名称不一致不自动合并。包工头本人也在班组作业：标从属加重信号，隔离墙必须更严，不得假装只有“纯组织者”。

支持依据（运行时核验）：民法典第七百七十条（承揽定义，仅作外观参照）；第七百七十二条（主要工作交由第三人须约定或同意）；劳动合同法 2012 修正第九十四条；法释〔2025〕12 号第一条；建工解释（一）第一条、第七条；施工分包管理办法第八条、第十四条。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 承包方是自然人，作业是装卸、采摘、简单装配 | 正触发后进入选任与安全闸 | 已经排除劳动关系 |
| 承包方是公司或个体工商户字号作为组织签约 | 负触发 `业务外包（派遣型）合同·审查` 或回引擎 | 个人承包也包括公司 |
| 作业是砌筑、模板、土建、市政管网 | 红线停笔。不按本类型放行 | 改成班组承包就能做 |
| 高空、电工作业、特种设备，承包方无相应资格 | 红线停笔 | 买份意外险就能做 |
| 包工头冒用其他单位名义，或附件是借来的资质证书 | 挂靠停笔。建工解释（一）第七条出借与借用连带 | 借资质更安全 |
| 口头“他手下有一帮人，名单下周补” | 花名册字段停止。不得写成班组已特定 | 已经组织完毕 |
| 发包方要把业务再转包给另一个包工头 | 标层层发包风险；强制准入则停笔 | 转包更灵活 |

口头“老板同意了”不得写成已授权。承包自然人必须亲笔签名并按指印，附身份证复印件。

### 2.2 选任记录

普通民事劳务：文本必须要求发包方保留对包工头技能、经验和过往履约的审核记录，作为无选任过错的表面证据。未见该义务：必须改。不得把“选任记录”写成已经完成审核。

支持依据：民法典第一千一百九十三条（定作、指示、选任有过错则定作人担相应责任）；侵权责任编解释（一）第十八条（定作人在过错范围内与承揽人共同承担责任）。

## 节点 3　管理隔离墙与从属信号（硬闸）

本节点同时服务硬闸 1 与硬闸 3。隔离墙是本类型得以成立的事实条件，不是规避劳动法的话术。

| 文本或事实写法 | 动作 | 不得写成 |
| --- | --- | --- |
| 甲方只对乙方发出工作面交底；乙方对劳务人员做技术和安全交底 | 可接受；补交底确认书附件 | 已经不会被认定为劳动 |
| 甲方直接给劳务人员排班、打卡、罚款、调岗 | 已滑向劳动或假外包。负触发 `劳动合同·审查` 或 `业务外包（派遣型）合同·审查` | 加一句“不建立劳动关系”就能留考勤 |
| 甲方把劳务人员写进自己的花名册或考勤系统 | 同上 | 只是门禁需要 |
| 工具、工作服、主要设备全部由甲方提供且禁止乙方自备 | 从属加重。必须改成乙方自备小型机具和劳保；大型固定设施可提供但不得搭配考勤管理 | 提供工具=已经合法 |
| 出现“入职、试用、转正、员工手册、旷工开除” | 劳动用语。判断是否已是 `劳动合同·审查`；仍属本类型则替换为组织、承包、交付、撤场 | 用了这些词也还是承包 |
| 包工头本人接受甲方考勤并领月薪，同时又代管班组 | 主体重叠。必须拆开：要么他是劳动者走 `劳动合同·审查`，要么他是独立承包且不得领甲方工资 | 一身二任更省事 |

知情确认书（劳务人员知晓雇主为乙方、与甲方无劳动关系）可作附件，**不能单独否定从属事实**。

## 节点 4　安全交底、强制保险、伤亡条款（硬闸）

支持依据（当次 `search_law` 写入 `L#`）：民法典第五百零六条、第一千一百九十二条、第一千一百九十三条；安全生产法 2021 修正第一百零三条；劳动合同法第九十四条；法释〔2014〕9 号第三条第四项、第五项；侵权责任编解释（一）第十八条。

### 4.1 进场安全与协议

| 事项 | 文本要求 | 不得写成 |
| --- | --- | --- |
| 安全技术交底 | 进场前甲方对包工头及全体人员做现场安全教育，签署确认书 | 已交底（材料未见不得写已经完成） |
| 安全生产管理职责 | 合同或专门协议写明各自安全生产管理职责；甲方对承包作业统一协调、检查 | 约定“甲方不管安全”即可免责 |
| 劳保用品 | 乙方自备必要劳保；特种作业人员资格标 `G#` | 没有劳保也能进场 |

安全生产法第一百零三条第二款：未签订专门安全生产管理协议、未在合同中明确各自职责、或未统一协调管理的，行政责任独立存在。修改句必须补协议或职责条款，不得用“乙方全权负责安全”代替。

### 4.2 强制保险

框架要求雇主责任险或高额人身意外伤害险作为入场前置。修改句：未提交有效保单（险种、被保险人范围覆盖花名册、保险期间覆盖作业期、限额【待填】）不得进场；保费可约定由承包款扣付。

保险**不是**选任过错或法定连带的对价。不得写“已投保则甲方不再承担任何责任”。

### 4.3 伤亡条款：分层，禁止绝对免责

三层关系不得混写成一条“乙方自负”：

1. **包工头与劳务人员**：个人之间劳务，适用民法典第一千一百九十二条。提供劳务一方因劳务受伤，按双方过错分担；造成第三人损害，由接受劳务一方（包工头）承担，有故意或重大过失可追偿。
2. **发包企业与包工头**：外观接近定作与承揽，适用第一千一百九十三条。无定作、指示、选任过错，定作人可不承担侵权责任；有过错则在过错范围内共同承担。
3. **法定对外追及**（合同改不掉）：
   - 劳动合同法第九十四条：个人承包经营违反该法招用劳动者造成损害，发包组织与个人承包经营者连带。
   - 安全生产法第一百零三条：发包给不具备安全生产条件或相应资质的单位或个人，事故损害连带。
   - 法释〔2014〕9 号第三条第四项：违法将承包业务转包给无用工主体资格的组织或自然人，职工因工伤亡的，用工单位为承担工伤保险责任的单位。
   - 法释〔2025〕12 号第一条：有合法经营资格的承包人再转包／分包给无资格组织或个人，劳动者可请求确认该承包人为用工主体责任单位。

示范分层句：

`定位风险分担条款｜原文：劳务人员伤亡一律由乙方负责，与甲方无关｜建议改为：乙方作为其自行招用人员的雇主，对劳务人员在提供劳务中的损害，依照民法典第一千一百九十二条处理。甲方对定作、指示或者选任有过错的，依照民法典第一千一百九十三条承担相应责任。法律、行政法规规定甲方与乙方承担连带责任或者清偿责任的，本合同不得排除。甲方依前述规定对外承担责任后，有权就超过自己责任的部分向乙方追偿。乙方须在进场前为花名册全部人员投保雇主责任险或人身意外伤害险（限额【待填】），保单作为附件。｜理由：L# 民法典 506／1192／1193，劳动合同法 94，安全生产法 103｜可退让点：追偿范围和保险限额可谈｜不接受时的红线：拒删绝对免责仍要放行`

民法典第五百零六条：造成对方人身损害的免责条款无效。出现“工伤概不负责”“伤亡自负”：红线删除。

## 节点 5　量价闭环与欠薪支付管控

支持依据：保障农民工工资支付条例第二十九条、第三十六条；框架量价与公示支付要求。

审查清单，缺一项则结算字段不得写成已闭环：

1. **标的**：具体工段或劳务项目 + 计量单位（吨、件、作业面）。只有“等劳务”则标缺口。
2. **计费**：固定单价或总价，结算依据是完成并验收的量，不是出勤人天。缺数字用 `【待填】`。
3. **节点**：先完工、后验收、再结算。预付款须写清性质，不得写成已赚取的包干费且人员工资可拖。
4. **代发**：甲方代乙方发放班组款项，必须写成“受托支付”，不改变用工关系，且须有劳务人员签字的发放清单。甲方直接发薪且无乙方确认：从属加重，回节点 3。
5. **保证金**：可扣留一定比例劳务保证金／农民工工资保证金，完工且乙方出具无拖欠声明后返还。比例用 `【待填】`，不编地方强制比例。
6. **条例第三十六条**：建设单位或施工总承包将建设工程发包或分包给个人导致拖欠的，由该建设单位或施工总承包清偿。普通民事劳务不是该条典型场景，但文本若把作业写成“工程”又包给个人，先回节点 1.3 停笔。修改句不得写“甲方对班组人员工资永不承担责任”。

动态追偿可写：因乙方拖欠导致甲方被投诉或依法对外清偿的，甲方有权向乙方追偿并约定违约金。违约金可谈，不得写成“按总价必得、不得调整”，不得搭配扣押劳务人员证件或向其收取押金。

## 节点 7　争议改写法，不审策略

或裁或诉、机构不明：标待核，改成单一仲裁机构或单一法院连结点。出现仲裁条款：不得改写成“应向某法院起诉”并假装已选定诉讼。用户追问工伤认定、欠薪仲裁请求、连带胜率：目标停止。本技能不写起诉或仲裁策略。

通知送达：可约定邮寄至载明地址第 X 日视为送达。不得把微信已读写成已经送达的唯一充分条件。

班组人员与包工头的雇佣争议、班组人员与发包企业的劳动争议，不是本约的准据法默认。不得把劳动法写成甲乙之间承包合同的准据法；也不得写“本协议不适用任何劳动法律”来排除第九十四条。
