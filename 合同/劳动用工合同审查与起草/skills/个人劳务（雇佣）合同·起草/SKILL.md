# 个人劳务（雇佣）合同·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **劳动关系类合同 / 个人劳务（雇佣）合同**，输出可编辑草稿、未决项，并用本类型硬闸自审后给出风险表和修改句。提供方是自然人，接受方支付劳务费，双方地位平等。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。显示名为「个人劳务（雇佣）合同·起草」。待签评改转 `个人劳务（雇佣）合同·审查`。本技能不代替起草或审查劳动合同（那是 `劳动合同·起草` / `劳动合同·审查`），不代替起草或审查劳务派遣协议（那是 `劳务派遣协议·起草` / `劳务派遣协议·审查`），不代替审查承揽合同（那是 `的method当本类型主路径。`）。

`depends-on` 为空。不要求先跑导航。

不交付：劳动合同起草或审查、派遣协议起草或审查、承揽审查、他类型起草、待签文本签前审查、履约交底、劳动仲裁或工伤索赔策略、解除补偿终值、有效性保证、避社保或虚开发票可履行结构。

## 本类型硬闸

1. **劳务≠劳动**：人格从属、组织从属、经济从属，或文本安排缴纳社会保险、把社保费包进劳务费的，不得按劳务改完。负触发 `劳动合同·审查`。考勤打卡、员工手册、固定月薪加绩效年终奖、工位编制、服从奖惩，视为从属信号。
2. **风险负担**：提供劳务造成第三人损害的，由接受劳务一方承担侵权责任，再向有故意或重大过失的提供方追偿；提供方自身因劳务受损，按双方过错分担。禁止“提供方自行承担全部人身或第三人损害、接受方概不负责”。商业意外险或雇主责任险只是增信，不能写成已免除法定负担。
3. **与承揽、派遣切开**：核心给付是完成并交付工作成果、承揽人独立完成 → `的method当本类型主路径。`。三方派遣、派人接受用工单位指挥 → `劳务派遣协议·审查`。禁止把劳务改成承揽以甩开风险负担，也禁止把个人劳务改成派遣协议。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。禁止把“改成劳务就能不缴社保”写成可放行结构。禁止把本约改成劳动合同正文。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿；尚未签署，尚未成争；核心给付是平等提供特定劳务并领取劳务费；用户要一份可签署草稿。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 有完整待签文本要评改 → `个人劳务（雇佣）合同·审查`；
- 人格从属、组织从属、经济从属，或安排社会保险、工资表发放 → `劳动合同·审查` / `劳动合同·起草`；
- 非全日制、小时工、每日平均不超过四小时且按小时计酬、适用劳动基准 → `非全日制劳动合同·审查` / `非全日制劳动合同·起草`；
- 派遣单位与用工单位签约、派人接受用工单位指挥 → `劳务派遣协议·审查` / `劳务派遣协议·起草`；
- 完成并交付工作成果、承揽人自备设备独立完成、风险主要落在成果质量 → `的method当本类型主路径。`；个人承揽专名且已安装则 `承揽合同（个人劳务）·审查` / `承揽合同（个人劳务）·起草`，未装则 `unavailable`，不得用本技能硬套；
- 标题或主结构是学生实习协议 → `学生实习协议·审查` / `学生实习协议·起草`；
- 标题或主结构是退休返聘合同 → `退休返聘合同·审查` / `退休返聘合同·起草`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问付款日、验收日、交接留痕 → 本套导航的履约步骤；
- 已申请劳动仲裁、工伤索赔、立案、开庭 → 劳动领域或合同争议对应原子，不审仲裁、工伤或侵权诉讼策略。

全职改签劳务以省社保、诱导提供方注册个体户以切断劳动关系、虚开发票：只出告知与红线，不改写成可履行规避结构。

## 建立起草坐标

确认：使用者与授权；单方立场（接受劳务一方或提供劳务一方择一）；相对方；已谈妥的提供方身份、劳务内容与地点、计酬方式、工具与场地、保险、个税与发票；不可接受事项；法域与拟签署日。缺立场不启动。条件未谈妥的商业数字用 `【待填】`，不编造。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的金额、期限、保额用 `【待填】`，不编造。

## 起草模式

本原子只承担本类型起草。有完整待签文本要评改时，转 `个人劳务（雇佣）合同·审查`。本类型条件已谈妥、要出己方稿时，留在本任务按三闸落稿并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。按下文明示清单把本类型硬闸写成正文必写、附件必附或禁止出现。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 标题用「劳务协议」或「劳务服务合同」；提供方是自然人，核心给付是平等提供特定劳务并领取劳务费。
- 劳务内容、地点、期限写到可履行；报酬称劳务费，与工资表分离；个税按劳务报酬代扣代缴。
- 提供劳务造成第三人损害的，由接受劳务一方承担侵权责任，再向有故意或重大过失的提供方追偿。
- 提供方自身因劳务受损，按双方过错分担。
- 商业意外险或雇主责任险只作增信，正文须写明不免除法定负担。
- 真劳务可约定提前通知解除且不套经济补偿；争议走法院或明确单一商事仲裁，不得把劳动仲裁写成必经前置。

### 附件必附

- 提供方身份证明复印件。
- 劳务成果验收单范本（如按次验收）。
- 约定保险的，附保单或投保安排，并标明只是增信。
- 特定劳务需执业资格的，附资格证明；未见资格则签署能力字段停止。

### 禁止出现

- 「劳动合同」字样、社会保险安排、把社保费包进劳务费。
- 考勤打卡、员工手册、固定月薪加绩效年终奖、工位编制、服从奖惩等从属结构。
- 「提供方自行承担全部人身或第三人损害、接受方概不负责」。
- 「改成劳务就能不缴社保」或诱导注册个体户、虚开发票的可履行结构。
- 把本约改成劳动合同、承揽或派遣协议正文。

### 0. 签署状态与成果分流

本类型条件已谈妥、要出己方稿 → 留本任务按三闸落稿并自审；有完整待签文本要评改 → `个人劳务（雇佣）合同·审查`；已签履约 → 本套导航的履约步骤；已成争 → 劳动领域。

### 1. 类型锁死

标题、签署方与核心给付一致才继续。劳动合同、派遣、承揽、非全日制、实习、退休返聘主结构负触发。从属或社保安排按劳动合同转出。

### 2. 主体、资格与特殊身份

签约名、履行名、付款名、发票名分列。提供方须为有行为能力的自然人。违法标的停笔。特定劳务未见执业资格：签署能力字段停止。退休或在校作为附属事实可留本任务并标 `G#`；主结构是返聘或实习协议则转出。

### 3. 劳务≠劳动

从属信号对照。命中则负触发 `劳动合同·审查`，不把本约改成“去劳动化外观仍按劳务履行”。

### 4. 风险负担

第三人损害、自身损害、第三人致害补偿分列。免责句删除。保险只作增信附件。

### 5. 劳务内容、报酬、税票与成果

内容确定到可履行；劳务费与工资表分离；代扣代缴个税；发票合法；成果知识产权未约定则提示归受托人。

### 6. 解除、违约与争议路径

真劳务可约定提前通知解除且不套经济补偿；违约按合同编写可执行后果。争议走法院或明确商事仲裁，不得把劳动仲裁写成真劳务的必经前置。从属一旦成立，争议路径整段交接劳动领域。

### 7. 按框架六步落稿并自审

必须先出草稿，再出自我审查的风险表和修改句。不得只交白稿。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；条件未谈妥仍要编造数字出可签署终稿；用户坚持从属用工仍按劳务签、把法定风险负担改成提供方全部自担、设计避社保或虚开发票、保证有效。
- `字段停止`：法域、执业资格、1192 对企业用个人的射程、退休替代规则、保单真实性未核验。
- `目标停止`：主目标已变为待签评改、履约交底、劳动合同审查、劳动仲裁或工伤策略。
