# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的金额、期限、保额；把已失效《合同法》及其解释或 2003 年人身损害赔偿解释第十一条写入结论；输出劳动仲裁请求、工伤索赔策略或胜率；把本约改成劳动合同正文；把从属用工改成可履行避社保结构；把 1192 对外责任写成已被约定免除。

## 1. 触发、单方立场与成果状态

立场（接受劳务一方或提供劳务一方）、授权、签署状态、主要目标。负触发写路由，不启动本类型起草。写明中文成果名称是「个人劳务（雇佣）合同·起草」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、2003 年人身损害赔偿解释第十一条旧文、或把法释〔2020〕26 号第三十二条第一款写成现行唯一口径时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `劳动关系类合同`，子级 `个人劳务（雇佣）合同`。定性理由、易混切开结果（尤其与 `劳动合同·审查` 劳动合同、`劳务派遣协议·审查` 派遣、`的method当本类型主路径。` 承揽的切开）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、资格与文本版本

主体表：接受方签约名、提供方姓名、付款名、发票名、授权签字人。资格闸：特定劳务是否见到执业资格。身份附件：退休证、在校证明仅作家属事实，不写成“只能是劳务”的现行必然。版本表：正文、报价单、验收单范本、保险方案、聊天确认；冲突并列。

## 5. 给付闭环与风险负担

劳务内容、自主性、工具场地、劳务费与节点、个税扣缴、发票、知识产权。风险负担三列：第三人损害、自身损害、第三人致害补偿。保险只记增信，不记已免责。缺口标 `G#`。不输出赔偿终值。

## 6. 强制规范与规避结构

从属用工、避社保、虚开发票、违法标的、概括免责、改承揽甩责。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和删除句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把框架“第三人损害由提供方自担”写成可放行；不得把本约改写成劳动合同条款。

## 9. 谈判与签署提醒

谈判顺序：先红线（从属仍要按劳务、概括免责、避社保、虚开），再必须改（1192 分列、个税扣缴、去劳动化称谓、保险附件），最后可优化。签署提醒：自然人签名按印、身份与资格复印件、保单、验收单范本。不指导倒签、补假退休证或补假发票。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本技能交付可编辑草稿、未决项、自审风险表和自审后修改句。草稿必须覆盖本类型起草必写、附件必附与禁止出现。待签评改转 `个人劳务（雇佣）合同·审查`。不是履约交底、劳动合同审查、劳动仲裁或工伤文书、效力保证。

## 起草模式交付

正触发时先交可编辑草稿和未决项，再交自审风险表与自审后修改句。三闸未落入正文或附件的，不得宣称起草完成。
