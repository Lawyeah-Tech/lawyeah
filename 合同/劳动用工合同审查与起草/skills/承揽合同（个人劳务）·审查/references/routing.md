# 边界与路由

本技能只审查 **劳动关系类合同 / 承揽合同（个人劳务）** 的待签民事文本。承揽人是自然人。显示名是「承揽合同（个人劳务）·审查」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 人格从属、组织从属、经济从属，或安排社会保险、工资表、员工手册、考勤 | `劳动合同·审查`。本任务不审试用期、第十九条分档或劳动合同正文 |
| 平等提供劳务过程，按次按时计酬，不交付特定成果 | `个人劳务（雇佣）合同·审查`。本任务不把 1192 写成真承揽默认负担 |
| 企业间加工、定作人供主材按图加工、劳动风险不是主轴 | `的method当本类型主路径。`。禁止打开其 method 当本类型主路径 |
| 相对方是外包公司，派人到现场接受定作人指挥、考核、排班 | `业务外包（派遣型）合同·审查` |
| 平台规则、派单、抽成、评分封号、诱导注册个体户接单 | `平台用工相关协议·审查` |
| 派遣单位与用工单位签约，派人接受用工单位指挥 | `劳务派遣协议·审查` |
| 非全日制、小时工、每日平均不超过四小时 | `非全日制劳动合同·审查` |
| 学生实习协议、学校三方实习 | `学生实习协议·审查` |
| 退休返聘合同为主结构 | `退休返聘合同·审查` |
| 工地施工、建筑业资质、竣工验收 | `或对应工程原子；` 或对应工程原子 |
| 无文本、本类型条件已谈妥、要出己方稿 | `承揽合同（个人劳务）·起草` |
| 已签未争、只问付款日、验收日、交接履约 | 本套导航的履约步骤 |
| 已申请或拟申请劳动仲裁、要证据或应诉策略 | `已申请或拟申请劳动仲裁要证据或应诉策略` / `劳动仲裁证据整理` / `继续当签前审查；输出仲裁策略`。本技能不审仲裁策略 |
| 工伤索赔整案 | `工伤索赔整案` 或劳动领域对应原子 |
| 已成争的普通民事路径 | `已成争的普通合同路径`，不继续签前审查 |
| C 端大众快检 | 只分流，不回改 |

本协议夹带劳动合同、劳务协议、外包协议或平台用户协议附件：附件整段交接对应完整 Skill ID；若正文仍是自然人成果承揽，正文可继续审。用户坚持本技能给出劳动关系效力、仲裁胜率或工伤赔付终值：`目标停止`。
