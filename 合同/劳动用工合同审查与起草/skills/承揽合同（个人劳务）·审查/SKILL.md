# 承揽合同（个人劳务）·审查

## 任务目标

在单一立场下，只审查 **劳动关系类合同 / 承揽合同（个人劳务）** 的待签民事文本（自然人承揽人按照定作人要求完成工作并交付特定成果，定作人支付承揽报酬），输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。显示名为「承揽合同（个人劳务）·审查」。本技能不代替审查劳动合同（那是 `劳动合同·审查`），不代替审查个人劳务（雇佣）合同（那是 `个人劳务（雇佣）合同·审查`），不代替审查加工合同（那是 `的method当本类型主路径。`），不代替审查业务外包（派遣型）合同（那是 `业务外包（派遣型）合同·审查`），不代替审查平台用工相关协议（那是 `平台用工相关协议·审查`）。

`depends-on` 为空。不要求先跑导航。

不交付：劳动合同审查、个人劳务审查、民事加工承揽审查、外包或平台用工整案、他类文本审查、从零起草、履约交底、劳动仲裁或工伤索赔策略、有效性保证、避社保或挂靠可履行结构。

## 本类型硬闸

1. **劳动关系 vs 承揽（1191 / 1192 / 1193）**：人格从属、组织从属、经济从属，或文本安排缴纳社会保险、把社保费包进承揽报酬的，不得按个人承揽改完。负触发 `劳动合同·审查`。考勤打卡、员工手册、固定月薪加绩效年终奖、工位编制、服从奖惩，视为从属信号。核心给付是提供劳务过程、不交付特定成果的，负触发 `个人劳务（雇佣）合同·审查`。真承揽才走第一千一百九十三条；假承揽不能用来吞掉第一千一百九十一条或第一千一百九十二条。
2. **1193 不是定作人绝对免责**：承揽人完成工作造成第三人损害或自己损害，定作人原则上不承担责任，但对定作、指示或者选任有过错的，仍承担相应责任。禁止“承揽人自行承担全部人身或第三人损害、定作人概不负责”。商业意外险只是增信，不能写成已免除法定过错责任。
3. **与外包、平台用工切开**：相对方是公司、派人到定作人现场接受指挥考核 → `业务外包（派遣型）合同·审查`。平台规则、派单抽成、评分封号、诱导注册个体户 → `平台用工相关协议·审查`。禁止把个人承揽改成外包或平台协议，也禁止把外包/平台文本硬套本技能。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。禁止把“改成承揽就能不缴社保”写成可放行结构。禁止把本约改成劳动合同正文。禁止打开 `劳动合同·审查` 或 `的method当本类型主路径。` 的 method 当本类型主路径。

## 工作边界

正触发：已有可读待签个人承揽协议正文，尚未签署，尚未成争，承揽人是自然人，核心给付是独立完成并交付特定工作成果并领取承揽报酬，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 人格从属、组织从属、经济从属，或安排社会保险、工资表发放 → `劳动合同·审查`；
- 平等提供劳务过程、按次按时计酬、不交付特定成果 → `个人劳务（雇佣）合同·审查`；
- 企业间加工、定作人供主材按图加工、非劳动风险主轴 → `的method当本类型主路径。`；
- 相对方是外包公司、派人接受定作人现场指挥考核 → `业务外包（派遣型）合同·审查`；
- 平台派单、抽成、评分封号、注册个体户接单 → `平台用工相关协议·审查`；
- 派遣单位与用工单位签约、派人接受用工单位指挥 → `劳务派遣协议·审查`；
- 非全日制、小时工、适用劳动基准 → `非全日制劳动合同·审查`；
- 标题或主结构是学生实习协议 → `学生实习协议·审查`；
- 标题或主结构是退休返聘合同 → `退休返聘合同·审查`；
- 工地建筑活动、承包资质、竣工验收 → `或对应工程原子；` 或对应工程原子；
- 无文本、本类型条件已谈妥、要出己方稿 → `承揽合同（个人劳务）·起草`；
- 已签只问付款日、验收日、交接留痕 → 本套导航的履约步骤；
- 已申请劳动仲裁、工伤索赔、立案、开庭 → 劳动领域或合同争议对应原子，不审仲裁、工伤或侵权诉讼策略。

全职改签承揽以省社保、诱导承揽人注册个体户以切断劳动关系、个人挂靠有资质单位、虚开发票：只出告知与红线，不改写成可履行规避结构。

## 建立审查坐标

确认：使用者与授权；单方立场（定作人或承揽人择一）；相对方；全文及附件版本；承揽人身份、是否在职、是否领取养老金；成果名称与规格；材料与工具由谁提供；主要工作是否允许转交；考勤或规章痕迹；社保安排；人身与第三人损害条款；定作、指示、选任安排；个税与发票；不可接受事项；法域与拟签署日。缺立场或无可读书面文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

### 0. 签署状态与成果分流

无书面文本 → `承揽合同（个人劳务）·起草`；已签履约 → 本套导航履约步骤；已成争或工伤索赔 → 劳动或争议领域。未签且目标是评改已有个人承揽协议，才进入本任务。

### 1. 类型锁死

标题、签署方与核心给付一致才继续。劳动合同、个人劳务、加工承揽、外包、平台用工、派遣、工程主结构负触发。从属或社保安排按劳动合同转出。

### 2. 劳动关系 vs 承揽

从属信号对照。命中则负触发 `劳动合同·审查`，不把本约改成“去劳动化外观仍按承揽履行”。

### 3. 1192 vs 1193

过程劳务走 `个人劳务（雇佣）合同·审查`。真承揽才适用 1193，且必须保留定作、指示、选任过错。

### 4. 外包 / 平台切开

公司派人、现场指挥 → `业务外包（派遣型）合同·审查`。平台派单抽成 → `平台用工相关协议·审查`。

### 5. 主体、挂靠与资质

签约名分列。个人挂靠、依法须企业资质却发包给个人：停笔告知。特种作业未见资格：签署能力字段停止。

### 6. 成果、独立性、验收、787、留置、知识产权

成果特定化；主要工作亲自完成；监督不得写成考勤；验收期与视为合格；任意解除走第七百八十七条并写赔偿；留置可约定排除但须明示；未约定则著作权属受托人。

### 7. 按框架六步出修改句

必须有可回给对方的修改句或红线。框架与硬闸冲突时，以 method 为准。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持从属用工仍按承揽签、把 1193 改成定作人绝对免责、设计避社保或挂靠或虚开发票、保证有效。
- `字段停止`：法域、特种资质、1193 过错事实、保单真实性、个税预扣率未核验。
- `目标停止`：主目标已变为从零起草、履约交底、劳动合同审查、加工承揽审查、外包或平台整案、劳动仲裁或工伤策略。
