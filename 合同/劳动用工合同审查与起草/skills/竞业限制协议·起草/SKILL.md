# 竞业限制协议·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **劳动关系类合同 / 竞业限制协议**，输出可编辑草稿、未决项，并用本类型硬闸自审后给出风险表和修改句。主线仍是**离职后择业限制 + 按月补偿**，不是保密义务，也不是整份劳动合同。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。显示名为「竞业限制协议·起草」。待签评改转 `竞业限制协议·审查`。

`depends-on` 为空。不要求先跑导航。

不交付：整份劳动合同起草或审查、培训服务期起草或审查、派遣协议起草或审查、纯保密文本整案、待签文本签前审查、已签后每月怎么发补偿、劳动仲裁追偿竞业或胜诉策略、有效性保证。

## 本类型硬闸

1. **主体限于三类**：高级管理人员、高级技术人员、其他负有保密义务的人员。对保洁、前台、无秘密普通岗位设离职竞业：红线，不得写成可履行。
2. **期限 ≤ 2 年**：超过部分无效，必须改。起算点为劳动合同解除或终止。
3. **范围可执行**：竞争业务、地域、竞争单位须与用人单位实际经营相适应。禁止“全球所有互联网/所有行业”。
4. **按月补偿是对价**：离职后履行期内按月支付。未约定补偿：不当然整份无效，但劳动者履行后可请求按司法解释补充标准支付。不得编造“无补偿则无效”或“无补偿也必须履行且无请求权”。百分之三十且不低于最低工资是法释〔2020〕26 号第三十六条的补充请求权标准，不是约定缺省，也不是劳动合同法条文本。
5. **单位解除/放弃**：竞业限制期限内用人单位请求解除的，须额外支付三个月补偿。禁止“单位可随时无偿取消，已履行月份也不结”。
6. **劳动者解除**：因用人单位原因三个月未支付补偿，劳动者可请求解除竞业义务。修改句给出催告与解除通知程序，不在本任务认定已经解除。
7. **保密 ≠ 竞业**：保密可无额外补偿、可长期；竞业必须补偿、最长两年。来稿把保密协议写成竞业，或把在职忠实义务写成离职两年全球禁业：切开或必须改。培训服务期 → `培训服务期协议·审查`。整份劳动合同 → `劳动合同·审查`。

违约金可约定，但避免“天价且不得调整”。禁止用竞业协议设计限制劳动者依法解除劳动合同。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿；尚未签署，尚未成争；核心给付是离职后不竞争 + 按月补偿；用户要一份可签署草稿。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 有完整待签文本要评改 → `竞业限制协议·审查`；
- 核心给付是全日制劳动合同正文 → `劳动合同·审查` / `劳动合同·起草`；
- 主轴是专项培训费用与服务期 → `培训服务期协议·审查` / `培训服务期协议·起草`；
- 签署方是派遣单位与用工单位的派遣协议 → `劳务派遣协议·审查` / `劳务派遣协议·起草`；
- 纯保密、无离职择业限制 → 按保密切开，不按本类型出稿；需要建设性保密体系可提示 `纯保密无离职择业限制→按保密切开，不按本类型出稿；需要建设性保密体系可提示`，不在本任务代做；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问每月怎么发补偿、报备新雇主、账户留痕 → 本套导航的履约步骤；
- 已申请劳动仲裁追偿竞业、已催告解除、已立案或开庭 → 劳动领域对应原子，不审仲裁策略。

对无秘密普通岗位设离职竞业、用竞业限制依法解除劳动合同：只出告知与删除/改正句，不改写成可履行规避结构。

## 建立起草坐标

确认：使用者与授权；单方立场（用人单位或劳动者择一）；相对方；已谈妥的岗位与是否接触秘密、限制业务、地域、竞争单位、期限与起算点、补偿金额、支付时点与账户、单位解除与三个月未付条款；不可接受事项；法域与拟签署日。缺立场不启动。条件未谈妥的商业数字用 `【待填】`，不编造。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的补偿额、期限、名单用 `【待填】`，不编造。

## 起草模式

本原子只承担本类型起草。有完整待签文本要评改时，转 `竞业限制协议·审查`。本类型条件已谈妥、要出己方稿时，留在本任务按三闸落稿并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。按下文明示清单把本类型硬闸写成正文必写、附件必附或禁止出现。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 标题用「竞业限制协议」；主线是离职后不竞争加按月补偿，不是保密义务，也不是整份劳动合同。
- 主体限于高级管理人员、高级技术人员或其他负有保密义务的人员；岗位、职责和是否接触商业秘密或与知识产权相关的保密事项必须落句。
- 限制期限不超过二年，起算点为劳动合同解除或终止。
- 竞争业务、地域、竞争单位写到与用人单位实际经营相适应，可执行。
- 离职后履行期内按月支付竞业补偿；金额、支付时点与账户写清，数字未给用 `【待填】`。未约定补偿不得写成整份无效，也不得写成无请求权。
- 用人单位在竞业限制期限内请求解除的，须额外支付三个月补偿。
- 因用人单位原因三个月未支付补偿的，劳动者可请求解除竞业义务；修改句写催告与书面通知程序，不认定已经解除。
- 违约金可约定，但须可调，避免「天价且不得调整」。

### 附件必附

- 岗位与接触秘密的陈述附件。
- 竞争业务、地域和竞争单位清单。
- 补偿账户与首次发放日安排。

### 禁止出现

- 对保洁、前台、无秘密普通岗位设离职竞业。
- 期限超过二年；「全球所有互联网」或「所有行业」。
- 「单位可随时无偿取消，已履行月份也不结」。
- 「无补偿则整份无效」或「无补偿也必须履行且无请求权」。
- 把工资中的保密费写成离职竞业补偿。
- 把保密协议或在职忠实义务写成离职两年全球禁业。
- 用竞业协议限制劳动者依法解除劳动合同。

### 0. 签署状态与成果分流

本类型条件已谈妥、要出己方稿 → 留本任务按三闸落稿并自审；有完整待签文本要评改 → `竞业限制协议·审查`；已签履约 → 本套导航的履约步骤；已成争 → 劳动领域。

### 1. 类型锁死

标题、核心给付与离职后不竞争 + 按月补偿一致才继续。劳动合同、培训服务期、派遣、纯保密负触发或切开。

### 2. 三类人员

岗位、职责、是否接触秘密分列。保洁/前台/无秘密普通岗位红线。未接触秘密：解释（二）第十三条可请求确认不生效，不得写成可履行。

### 3. 期限 ≤ 2 年

起算点为劳动合同解除或终止。超过二年部分必须改。

### 4. 范围可执行

业务、地域、竞争单位与实际经营相适应。禁止全球所有行业。超过合理比例部分按解释（二）第十三条处理。

### 5. 按月补偿对价

离职后履行期内按月支付。未约定不当然整份无效；履行后可请求解释（一）第三十六条标准。工资中的保密费不是离职竞业补偿。

### 6. 单位解除与劳动者解除

单位解除额外三个月；三个月未付劳动者可请求解除。修改句写催告与通知，不认定已经解除。

### 7. 保密切开、违约金与强制规范

保密≠竞业。违约金可约定但不得“天价且不得调整”。不得限制依法解除劳动合同。第二十二条培训服务期负向转出。

### 8. 按框架六步落稿并自审

必须先出草稿，再出自我审查的风险表和修改句。不得只交白稿。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；条件未谈妥仍要编造数字出可签署终稿；用户坚持对无秘密普通岗位放行离职竞业、把无补偿写成整份无效或无请求权、单位随时无偿取消且已履行月份不结、用竞业限制依法解除劳动合同、保证有效。
- `字段停止`：法域、是否接触秘密、地方最低工资、动态规则未核验。
- `目标停止`：主目标已变为待签评改、履约交底、整份劳动合同或培训服务期审查、劳动仲裁策略。
