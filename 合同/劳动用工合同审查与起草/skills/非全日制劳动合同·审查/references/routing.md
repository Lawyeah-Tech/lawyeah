# 边界与路由

本技能只审查 **劳动关系类合同 / 非全日制劳动合同** 的待签文本。签署方是用人单位与劳动者。显示名是「非全日制劳动合同·审查」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 全日制劳动合同：日 8 / 周 40、月薪、试用期按第十九条分档 | `劳动合同·审查`。本任务不审试用期分档，不打开第十九条对照表 |
| 个人劳务、雇佣协议、按件验收、不接受劳动规章 | `个人劳务（雇佣）合同·审查` |
| 劳务派遣协议、派遣单位与用工单位 | `劳务派遣协议·审查` |
| 派遣单位以非全日制招用被派遣劳动者 | 本任务红线告知实施条例第三十条；商事派遣协议交 `劳务派遣协议·审查`；不改成可履行派遣非全 |
| 个人承揽、按成果交付 | `承揽合同（个人劳务）·审查` |
| 已享受养老保险待遇或达到法定退休年龄的返聘 | `退休返聘合同·审查` |
| 在校学生实习 | `学生实习协议·审查` |
| 平台用工、网约协议 | `平台用工相关协议·审查`；专业版未装则 `unavailable` |
| 标题非全但正文日 8 / 月薪 / 全日制考勤 | 留本任务；点名假非全；按日 4 / 周 24 / 小时工资 / 终止硬闸改。用户改口要全日制劳动合同 → `劳动合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `非全日制劳动合同·起草` |
| 已签未争、只问排班、打卡、发薪日履约 | 本套导航的履约步骤 |
| 已申请或拟申请劳动仲裁、要证据或应诉策略 | `已申请或拟申请劳动仲裁要证据或应诉策略` / `劳动仲裁证据整理` / `继续当签前审查；输出仲裁策略`。本技能不审仲裁策略 |
| 工伤索赔整案 | `工伤索赔整案` 或劳动领域对应原子。本约只审工伤参保约定 |
| 已成争的普通合同路径 | `已成争的普通合同路径` 或劳动领域，不继续签前审查 |
| C 端大众快检 | 只分流，不回改 |

本约夹带全日制劳动合同附件：附件整段交接 `劳动合同·审查`；非全正文继续审。用户坚持本技能给出全日制试用期分档、仲裁胜率或工伤赔付终值：`目标停止`。
