# 非全日制劳动合同·审查

## 任务目标

在单一立场下，只审查 **劳动关系类合同 / 非全日制劳动合同** 的待签文本（签署方为用人单位与劳动者），输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。显示名为「非全日制劳动合同·审查」。本技能不代替审查全日制劳动合同（那是 `劳动合同·审查`），也不代替审查个人劳务（那是 `个人劳务（雇佣）合同·审查`）。

`depends-on` 为空。不要求先跑导航。

不交付：全日制劳动合同审查、个人劳务审查、他类文本审查、从零起草、履约交底、劳动仲裁或工伤索赔策略、解除补偿终值、有效性保证、把超工时非全改写成可履行全日制结构。

## 本类型硬闸

1. **每日平均≤4 小时**：同一用人单位一般平均每日工作时间不超过四小时。出现“视生产需要加班”“排满上午下午”“日均 6/8 小时”：必须改或红线。
2. **每周累计≤24 小时**：每周工作时间累计不超过二十四小时。周工时沉默、可被排满或与日工时相乘已超 24：必须改。
3. **小时工资**：以小时计酬为主；必须写明元/小时；不得低于用人单位所在地人民政府规定的最低小时工资标准；结算支付周期最长不得超过十五日。禁止月薪主路径，禁止按月发放。
4. **终止**：任何一方均可随时通知对方终止用工；终止用工用人单位不支付经济补偿。禁止套用全日制“提前三十日通知 / N+1 / 违法解除 2N”。通知建议留书面或电子痕迹，但不把“随时”改成必须预告期满才生效。
5. **与全日制 `劳动合同·审查` / 劳务 `个人劳务（雇佣）合同·审查` 切开**：日 8 / 周 40、月薪、试用期按第十九条分档 → 负触发 `劳动合同·审查`。平等主体、按件或按项目验收、不接受劳动规章 → 负触发 `个人劳务（雇佣）合同·审查`。标题非全但工时或管理已是全日制：留本任务点名假非全；**禁止**把第十九条试用期分档写成主路径；**禁止**在本任务改成全日制劳动合同正文。

配套约束：非全日制不得约定试用期——出现试用期只删除，不按合同期限分档核对。各用人单位应为非全日制从业人员缴纳工伤保险。劳务派遣单位不得以非全日制招用被派遣劳动者。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。禁止把日 4 / 周 24 / 15 日结算写成倡导性可忽略。

## 工作边界

正触发：已有可读待签非全日制劳动合同正文，尚未签署，尚未成争，签署方是用人单位与劳动者，核心给付是小时计酬的非全日制劳动，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 核心给付是全日制从属劳动（日 8 / 周 40、月薪、试用期分档）→ `劳动合同·审查`；
- 平等主体个人劳务、按件验收、不接受劳动规章 → `个人劳务（雇佣）合同·审查`；
- 劳务派遣单位与用工单位的商事派遣协议 → `劳务派遣协议·审查`；
- 个人承揽、按成果交付 → `承揽合同（个人劳务）·审查`；
- 已享受养老保险待遇或达到法定退休年龄的返聘 → `退休返聘合同·审查`；
- 在校学生实习 → `学生实习协议·审查`；
- 平台用工、网约协议 → `平台用工相关协议·审查`；专业版未装则 `unavailable`；
- 无文本、本类型条件已谈妥、要出己方稿 → `非全日制劳动合同·起草`；
- 已签只问排班、打卡、发薪日履约 → 本套导航的履约步骤；
- 已申请劳动仲裁、工伤索赔、立案、开庭 → 劳动领域对应原子，不审仲裁或工伤策略。

假非全（标题非全，正文日 8 / 月薪 / 全日制考勤）：留本任务，点名红旗，按本类型硬闸改工时、计酬和终止；用户改口要一份全日制劳动合同 → 整段交接 `劳动合同·审查`，本任务不写第十九条分档。

派遣单位以非全日制招用被派遣劳动者：红线告知实施条例第三十条，不改成可履行派遣非全。

## 建立审查坐标

确认：使用者与授权；单方立场（用人单位或劳动者择一）；相对方；全文及附件版本；岗位与排班；日均/周累计工时；小时工资与履行地；结算周期；终止条款；是否约定试用期；工伤安排；不可接受事项；法域与拟签署日。缺立场或无可读书面文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的小时工资、工时、最低标准用 `【待填】`，不编造。

### 0. 签署状态与成果分流

无书面文本 → `非全日制劳动合同·起草`；已签履约 → 本套导航履约步骤；已成争或工伤索赔 → 劳动领域。未签且目标是评改已有非全日制劳动合同，才进入本任务。法律允许口头协议，不等于本任务可在无文本时出可签署意见。

### 1. 类型锁死与切开

标题、签署方与核心给付一致才继续。全日制劳动合同负触发 `劳动合同·审查`。个人劳务负触发 `个人劳务（雇佣）合同·审查`。假非全留本任务并点名。

### 2. 日均工时≤4 小时

写明一般平均每日不超过四小时。加班开口或日 6/8 必须改或红线。

### 3. 每周累计≤24 小时

写明每周累计不超过二十四小时。与日工时乘积或排班已超则必须改。

### 4. 小时工资与十五日结算

元/小时；对照履行地最低小时工资；结算周期≤15 日。月薪主路径必须改。

### 5. 终止用工

随时通知终止；不支付经济补偿。删除 30 日预告和 N+1。

### 6. 试用期只删除、工伤与多重关系

出现试用期一律删除，不套第十九条。工伤各单位缴纳。后订立合同不得影响先订立合同。

### 7. 争议条款

劳动争议依法仲裁。不审策略。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持超日 4 / 周 24 仍按非全放行、把假非全改成可履行全日制并套第十九条、弃工伤、保证有效、倒签或伪造工时确认表。
- `字段停止`：法域、履行地最低小时工资数字、工伤参保凭证、他单位合同是否影响先合同未核验。
- `目标停止`：主目标已变为从零起草、履约交底、全日制劳动合同审查、个人劳务审查、劳动仲裁或工伤策略。
