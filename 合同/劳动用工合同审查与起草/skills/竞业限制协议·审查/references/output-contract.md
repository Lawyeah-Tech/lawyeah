# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的补偿额、期限、名单；把已失效《合同法》及其解释或法释〔2013〕4 号解释（四）写入结论；输出劳动仲裁请求、举证策略或胜率；把无补偿写成整份无效或无请求权；把三个月未付写成已经自动解除；把保密协议或整份劳动合同当成已完成的竞业审查。

## 1. 触发、单方立场与成果状态

立场（用人单位或劳动者）、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「竞业限制协议·审查」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、法释〔2013〕4 号解释（四）、1997 年“限制期不超过三年”行业旧文、或把 2012 年未改动的第二十三至二十五条标成失效时，记噪声，不得写入 `L#`。解释（一）“部分失效”不得用来弃用第三十六至四十条。

## 3. 类型与加载路径

父级 `劳动关系类合同`，子级 `竞业限制协议`。定性理由、易混切开结果（尤其与保密、在职忠实、`劳动合同·审查` 劳动合同、`培训服务期协议·审查` 培训服务期的切开）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、三类人员与文本版本

主体表：用人单位签约名、劳动者姓名、岗位、是否接触商业秘密或与知识产权相关的保密事项、授权签字人。三类人员闸：高管 / 高级技术人员 / 其他负有保密义务人员 / 均不符合。版本表：正文、附件清单、劳动合同竞业专章、保密协议、聊天确认；冲突并列。保洁、前台、无秘密普通岗位：红线，不得写成可履行。

## 5. 期限、范围与按月补偿

期限与起算点（劳动合同解除或终止）；是否超过二年；竞争业务、地域、竞争单位是否与实际经营相适应；补偿金额、支付时点、账户、是否离职后按月。未约定补偿：写明不当然整份无效，劳动者履行后可请求解释（一）第三十六条标准；标明 30% 是司法解释补充请求权标准，不是约定缺省。缺口标 `G#`。不输出补偿终值或违约金必得额。

## 6. 解除程序、违约金与强制规范

单位解除是否写额外三个月；三个月未付是否写成劳动者可请求解除（催告与书面通知，不认定已经解除）；违约金是否“天价且不得调整”；是否限制依法解除劳动合同；保密条款是否被写成竞业。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把框架“自动失效”“视各地区司法口径”“脱密期”“跟踪取证”直接当作建议句。

## 9. 谈判与签署提醒

谈判顺序：先红线（无秘密普通岗位、超二年拒改、全球所有行业、单位无偿取消已履行月份不结、限制依法解除劳动合同），再必须改（按月补偿、范围收窄、催告解除程序、违约金可调），最后可优化。签署提醒：双方签字或盖章、各执一份、岗位与接触秘密的陈述附件、竞争单位清单、补偿账户与首次发放日、送达地址。不指导倒签或补假秘密接触事实。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本技能只出审查意见和修改句，不出整份起草终稿；出稿转 `竞业限制协议·起草`。不是履约交底、劳动合同或培训服务期审查、劳动仲裁文书或效力保证。
