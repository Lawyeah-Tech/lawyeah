# 边界与路由

本技能只审查 **劳动关系类合同 / 竞业限制协议** 的待签文本。主线是离职后择业限制 + 按月补偿。显示名是「竞业限制协议·审查」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 全日制劳动合同正文、试用期、工时工资社保整案 | `劳动合同·审查`。本任务不审试用期、第十九条分档或劳动合同必备条款 |
| 专项培训费用、服务期、培训费分摊违约金 | `培训服务期协议·审查`。劳动合同法第二十二条仅负向 |
| 劳务派遣协议、派遣单位与用工单位 | `劳务派遣协议·审查`。本任务不审三性或 10% |
| 纯保密协议，无离职后不竞争 + 按月补偿 | 不按本类型出十节；建设性保密体系可提示 `纯保密无离职择业限制→按保密切开，不按本类型出稿；需要建设性保密体系可提示`，不代做 |
| 劳动合同或保密协议中夹带离职竞业专章 | 专章留本任务；其余正文交对应原子 |
| 无文本、本类型条件已谈妥、要出己方稿 | `竞业限制协议·起草` |
| 已签未争、只问每月怎么发补偿、报备新雇主、账户留痕 | 本套导航的履约步骤 |
| C 端大众竞业风险快检、只要不定效力的风险提示 | `C端大众竞业风险快检只要不定效力的风险提示`；本任务是律师签前评改，不回改 C 端 |
| 已申请或拟申请劳动仲裁追偿竞业、要证据或应诉策略 | `已申请或拟申请劳动仲裁要证据或应诉策略` / `劳动仲裁证据整理` / `继续当签前审查；输出仲裁策略`。本技能不审仲裁策略 |
| 已成争的普通合同路径 | `已成争的普通合同路径` 或劳动领域，不继续签前审查 |
| C 端大众快检 | 只分流，不回改 |

劳动合同或保密协议夹带培训服务期：培训段交 `培训服务期协议·审查`。用户坚持本技能给出整份劳动合同效力、培训费终值或仲裁胜率：`目标停止`。
