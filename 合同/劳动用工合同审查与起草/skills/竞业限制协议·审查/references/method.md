# 审查方法（锁定 劳动关系类合同 / 竞业限制协议）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止把劳动争议套件原子正文抄进本任务。禁止把劳动合同试用期第十九条分档或劳务派遣三性、10% 当本类型主路径。

主线只审**离职后择业限制 + 按月补偿**。不是保密义务，不是在职忠实义务，不是整份劳动合同。

定性校验：标题、核心给付与本类型一致才继续；劳动合同、培训服务期、派遣或纯保密明显则负触发或切开，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、劳动仲裁必然胜诉、三个月未付已经解除，或唯一必得金额。

`search_law` 返回已失效《合同法》及其解释、法释〔2013〕4 号《最高人民法院关于审理劳动争议案件适用法律若干问题的解释（四）》、1997 年行业文件“限制期不应超过三年”时记为噪声，不得写入 `L#`。2012 年劳动合同法修正未改动的第二十二至二十五条，引用 2012 修正，不得因 2007 文本带“已被修改”标签写成失效。法释〔2020〕26 号解释（一）因法释〔2025〕12 号解释（二）第二十一条废止第三十二条第一款而“部分失效”；第三十六至四十条未被废止，不得整段弃用。解释（二）与解释（一）不一致时，以解释（二）为准。

示范文本只参考结构。范本写“停止支付补偿即自动失效”不得粘贴为本约建议句。

知识库纠正（不回写双文件）：

- `基本面.md` 把 30% 写成补偿金计算模型：纠正为——仅当**未约定**离职后补偿且劳动者**已履行**时，解释（一）第三十六条才支持按离职前十二个月平均工资 30% 按月请求，且不低于履行地最低工资。这是司法解释补充请求权标准，不是约定缺省，也不是劳动合同法条文本。约定补偿可以高于或低于 30%，但明显过低标必须改。
- `基本面.md` 高管列举“董事会秘书”：纠正为公司法（2023 修订）第二百六十五条——经理、副经理、财务负责人，**上市公司**董事会秘书和章程规定的其他人员。章程未出示则该字段 `G#`。
- `基本面.md` “其他负有保密义务的普通员工”：须有可回链的接触秘密事实。未接触则解释（二）第十三条可请求确认不生效，不得仅凭岗位名称放行。
- `框架.md` 把三个月未付写成“自动失效”：纠正为解释（一）第三十八条——劳动者**可请求解除**，本任务不认定已经解除。
- `框架.md` 把单位解除额外三个月写成“视各地区司法口径”：纠正为解释（一）第三十九条是全国规则。
- `框架.md` “工资中已包含”或“离职时一次性结清”：按月支付是第二十三条的法定对价方式。工资中的保密费或在职补贴不是离职竞业补偿。一次性结清偏离按月，必须改；已实际足额支付的事实不在本任务认定。
- `框架.md` 脱密期、跟踪取证、提起劳动仲裁：脱密期不得用来限制依法解除劳动合同；取证与仲裁策略不写。
- `基本面.md` 第四步“提起劳动仲裁主张违约金”：本任务只改文本，不写怎么赢。

## 节点 2　主体与三类人员闸

### 2.1 主体表

建表：用人单位签约名、劳动者姓名、岗位名称、职责摘要、是否接触商业秘密或与知识产权相关的保密事项、授权签字人。名称不一致不自动合并。口头“我们老板同意了”不得写成已授权。

劳动者在入职时是否仍受前单位竞业约束：只标叠加风险，不调查前单位，不写怎么规避前约。

### 2.2 三类人员（硬闸）

支持依据：劳动合同法（2012 修正）第二十四条第一款；公司法（2023 修订）第二百六十五条；解释（二）第十三条、第十四条。

竞业限制的人员限于：

1. **高级管理人员**：经理、副经理、财务负责人，上市公司董事会秘书，以及章程规定的其他人员。文本自称“高管”但无章程或任职文件：`G#`，不得写成已构成高管。
2. **高级技术人员**：职责须能回链核心研发、工艺、算法、关键技术岗位。职称或“工程师”头衔单独不够。
3. **其他负有保密义务的人员**：必须有可回链的接触事实（客户名单、底价、未公开配方、未公开财务或技术信息等）。“全体员工均负有保密义务”不得单独用来放行离职竞业。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 岗位是保洁、前台、收发、无秘密普通操作，材料不能支持接触秘密 | 红线；删除离职竞业或整份不签；不得改成可履行 | 补一份补偿就能约束；先签再补秘密目录 |
| 销售高管、核心研发、财务负责人，接触事实可回链 | 继续审期限、范围、补偿 | 已经有效 |
| 普通岗位但用户主张接触客户底价，无目录或陈述附件 | 字段停止；修改句要求书面陈述接触范围，接触事实不足则删除竞业 | 口头“肯定知道”即适格 |
| 劳动者未接触商业秘密和与知识产权相关的保密事项 | 现有依据支持解释（二）第十三条：可请求确认竞业条款不生效。修改句删除或改为纯保密 | 写成可履行离职竞业 |

解释（二）第十四条：对三类人员约定**在职期间**竞业，劳动者仅以“不得约定在职竞业”或“未支付经济补偿”请求确认无效的，人民法院不予支持。本任务采纳该条只用于：不要把在职忠实写成当然无效。本任务主线仍是离职后 + 按月补偿；来稿把在职不得兼职扩成离职两年全球禁业：必须改，切开在职忠实与离职竞业。

## 节点 3　期限 ≤ 2 年

支持依据：劳动合同法（2012 修正）第二十四条第二款。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 期限未写或只写“按公司通知” | 必须改：写明自劳动合同解除或终止之日起不超过二年 | 已起算 |
| 期限 ≤ 2 年，起算点为解除或终止 | 可接受；建议写末日日历日 | 必然有效 |
| 期限 3 年、5 年或“永久” | 必须改：超过二年部分无效；修改句缩至二年并加“超过法定上限的部分不发生效力” | 建议缩短但不改；行业旧文三年可放行 |
| 起算点为入职日、签字日或“脱密期满” | 必须改：起算点改回劳动合同解除或终止 | 脱密期替代二年上限 |

修改句示例结构（数字用文本或 `【待填】`）：

`第X条｜原文“离职后五年内……”｜建议改为“竞业限制期限自劳动合同解除或终止之日起计算，至满二十四个月之日止。约定超过二十四个月的部分不发生效力。”｜理由：第二十四条第二款｜可退让：改为十二或十八个月｜不接受时的红线：超过二年仍要签署则建议不签`

## 节点 4　范围可执行

支持依据：劳动合同法第二十四条第一款；解释（二）第十三条第二款。

审查三件套，缺一件则必须改：

1. **竞争业务**：细化到与用人单位实际经营同类的产品或业务，能回链经营范围或实际产品线。
2. **地域**：与实际业务覆盖相适应。无业务覆盖的“全国/全球”必须收窄。
3. **竞争单位**：列举与实际经营有竞争关系的单位及其明确约定的关联方，或给出可核验的“经营同类产品且有竞争关系”标准。

| 文本写法 | 动作 |
| --- | --- |
| “全球所有互联网公司”“任何行业”“一切相关领域” | 红线或必须改。现有依据不支持与实际经营相适应 |
| 范围、地域、期限与劳动者接触的秘密不相适应 | 解释（二）第十三条：超过合理比例部分可被确认无效。修改句按接触范围收窄，不编造名单 |
| 只有“包括但不限于以下企业”而无具体名单且无适应标准 | 必须改：补清单或可核验标准 |
| 限制到非竞争的生活服务业、无关地域 | 必须删除超出部分 |

不得把框架“关联方全覆盖”扩成无限关联。关联方须有定义或清单。

## 节点 5　按月补偿是对价

支持依据：劳动合同法（2012 修正）第二十三条第二款；解释（一）第三十六条、第三十七条。

补偿是离职后履行期内的对价，不是在职工资的一部分。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 约定离职后按月支付确定金额或可核验计算基数，账户和首次发放日可填 | 继续；数字未给用 `【待填】` | 已经足额 |
| 未约定补偿 | **不当然整份无效**。劳动者履行后可请求按解释（一）第三十六条：解除或终止前十二个月平均工资的 30% 按月支付；该数低于履行地最低工资的，按最低工资。修改句补约定金额、按月时点和账户，并可写“未约定或约定不明时，劳动者在履行义务后有权依法请求支付，不得解释为无请求权” | “无补偿则整份无效，可以随便去对家”；“没写也必须履行且不能要钱” |
| 写“工资已包含竞业补偿”“在职保密费即为竞业补偿” | 必须改。在职款项不是第二十三条的离职后按月补偿 | 已履行对价 |
| 写“离职时一次性结清，此后不再按月” | 必须改回履行期内按月支付。一次性是否视为已付不在本任务认定 | 一次性已合法替代按月 |
| 约定补偿明显无法维持基本生活，或为零、象征性 1 元 | 必须改。过低不自动等于整份无效，但现有依据不支持可放行的对价 | 1 元也有效所以能签 |

解释（一）第三十七条：已约定竞业和经济补偿，解除劳动合同时，除另有约定外，单位要求履行或劳动者履行后要求支付补偿，应予支持。修改句不要写“劳动合同一解除竞业就作废”，除非双方另有可回链的放弃约定，且放弃仍受节点 6 约束。

30% 的定位（必须在意见里写明）：

- 是司法解释对**未约定补偿且已履行**情形的补充请求权标准；
- 不是劳动合同法条文；
- 不是必须写入合同的约定缺省；
- 约定时可作为谈判参考，不得写成“法定必须 30% 才能有效”。

地方最低工资数字未核验则 `G#`，不编造。

## 节点 6　单位解除与劳动者解除

### 6.1 单位解除 / 放弃（硬闸）

支持依据：解释（一）第三十九条。

在竞业限制期限内，用人单位请求解除竞业限制协议的，应予支持；解除时劳动者请求额外支付三个月竞业限制经济补偿的，应予支持。

| 文本写法 | 动作 |
| --- | --- |
| “单位可随时无偿取消，已履行月份也不结算” | 红线。修改句：已履行月份按约定或依法结算；单位在期限内解除的，额外支付三个月补偿 |
| “离职时单位单方通知放弃即无需任何补偿” | 若劳动者尚未开始履行且通知发生在解除或终止前，可谈放弃起算；若已进入履行期或劳动者已按约限制择业，必须保留已履行月份结算 + 额外三个月。不得写成全国“离职前放弃一律零补偿” |
| 未写单位解除权 | 单位立场可补解除权，但必须同时写额外三个月和已履行月份结算；劳动者立场可接受补入或保持沉默并提示解释（一）第三十九条仍可能适用 |
| “视各地区司法口径决定是否付三个月” | 必须改。第三十九条是全国规则，地方加码只可提高保护，不得用来取消三个月 |

### 6.2 劳动者解除（硬闸）

支持依据：解释（一）第三十八条。

劳动合同解除或终止后，因用人单位的原因导致三个月未支付经济补偿，劳动者请求解除竞业限制约定的，应予支持。

本任务**不认定已经解除**。修改句只给程序，不写“满三个月自动失效”或“本意见确认已解除”。

必须写入的程序句：

1. 补偿应付而未付满三个月（因用人单位原因）；
2. 劳动者书面催告，指定合理宽限期和支付账户；
3. 宽限期届满仍未付的，劳动者书面通知请求解除竞业限制约定，并保留已履行期间的补偿请求权；
4. 是否已经解除，由劳动争议仲裁机构或人民法院确认。

| 文本写法 | 动作 |
| --- | --- |
| “三个月未付自动失效/视为从未约定” | 必须改：改为劳动者可请求解除 + 催告通知程序，不写自动解除 |
| “未付补偿时劳动者仍须履行，仅能另诉违约金” | 必须改。另行约定不得剥夺第三十八条请求权 |
| “未付满一个月即可解除” | 可保留（更有利于劳动者）；不得改成比三个月更苛刻 |
| 用户要本任务确认“已经解除，可以去对家” | 字段停止。只给催告解除通知要点，转劳动领域，不作出已解除结论 |

## 节点 7　保密 ≠ 竞业、违约金与强制规范

### 7.1 保密与竞业切开（硬闸）

支持依据：劳动合同法第二十三条第一款与第二款；劳动法（2018 修正）第二十二条（可约定保密事项）。

| 文本 | 动作 |
| --- | --- |
| 标题保密，正文只有保密义务，无离职择业限制 | 负触发或切开；不按本类型出十节 |
| 标题保密，正文把保密写成离职两年不得入职任何同行 | 必须改：拆成（1）无额外补偿、可至秘密公开的保密义务；（2）有按月补偿、不超过二年、范围可执行的离职竞业 |
| 在职不得兼职/自营被写成离职两年全球禁业 | 必须改：在职忠实留在劳动合同；离职竞业按本类型硬闸重写 |
| 未付保密费 | 不得写成“没给保密费所以保密无效，可以随便签竞业” |

培训服务期条款、培训费发票、分摊违约金：整段交 `培训服务期协议·审查`。第二十二条只作负向识别，不在本任务审培训费是否实际发生。

### 7.2 违约金

支持依据：劳动合同法第二十三条第二款、第二十五条；解释（一）第四十条；解释（二）第十五条；民法典第五百八十五条；法释〔2023〕13 号第六十四、六十五条。

- 竞业违约金属于第二十五条白名单，可约定。
- 禁止“天价且不得调整”。修改句删除“不得调整/不得减少”；可写“如过分高于损失，一方有权请求依法调整”。
- 解释（二）第十五条：劳动者违反**有效**竞业约定，单位可请求按约定返还已经支付的补偿并支付违约金。修改句不要把返还补偿写成在无效竞业上也能主张。
- 解释（一）第四十条：支付违约金后，单位要求按约定继续履行的，应予支持。可保留“支付违约金后仍应继续履行剩余期限”，但不得写成惩罚性叠加且不得调整。
- 本任务不精算违约金，不输出必得额。

### 7.3 不得限制依法解除劳动合同

不得约定：签署本协议后不得依劳动合同法第三十七条或第三十八条解除劳动合同；辞职视为竞业违约；依法解除须先经单位批准或支付竞业违约金。出现上述写法：红线删除。

劳动合同法第二十六条、第二十七条：免除单位法定责任、排除劳动者权利或违反强制规定的部分无效，其余可独立生效。无效有争议的，由仲裁机构或人民法院确认——本任务只给修改句，不宣告整份无效。

### 7.4 争议条款：改写法，不审策略

支持依据：劳动争议调解仲裁法第二十一条。

约定商事仲裁、排除劳动仲裁、只由某地仲裁委管辖而排除履行地：必须改回依法申请劳动争议仲裁。用户追问请求、证据、胜率：目标停止。
