# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受、许可一定办成或必然可执行；编造未给出的造价、租金、抵扣额、工期；把已失效《合同法》、1995 年《城市房屋租赁管理办法》、1989 年《城市规划法》、1997 年未修正《建筑法》写入结论；把融资租赁或施工文本当成已完成的本类型审查；写“抵租所以不受二十年限制”；写“未备案则本合同未生效”；写“未占有也已对抗买受人”；写“建成违法建筑仍强制起租”。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查定向建设租赁合同（租赁合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、1995 年《城市房屋租赁管理办法》、1989 年《城市规划法》、1997 年未修正《建筑法》、融资租赁解释或施工合同司法解释当作本类型主规则时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `租赁合同`，子级 `定向建设租赁合同`。定性理由、易混切开结果（融资租赁 / 施工 / 总承包 / BT / 已建成房产租赁 / 售后回租 / 以租代售）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。禁止打开邻类 method。

## 4. 主体、土地权利人、资金定性与文本版本

主体表：签约名、土地使用权人、履行名、付款名、发票名、授权签字人。资金定性：预付租金 / 借款＋租赁 / 共有登记，三选一结果。版本表：正文、图纸、任务书、抵租表、施工合同关键页、保函、聊天确认；冲突并列。

## 5. 未来物、许可生命线、给付与二十年／占有

图纸和验收标准是否落地；规划／施工许可责任主体和时点；资金监管与抵租表；交付起租条件；租期是否自交付起不超过二十年；买卖不破租赁是否以占有为前提。缺口标 `G#`。不输出融资租赁还租本息口径，不输出施工发包承包或工程价款优先受偿口径。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹。违法建筑强制起租、农用地建生产设施、地未拿到收全额建设款、挂靠规避出让不得写成可放行。强制规范只按第一百五十三条区分是否导致民事行为无效，不用失效口诀。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把施工进度款条款直接写成“租金”，也不得把融资租赁还租表直接写成抵租表。

## 9. 谈判与签署提醒

谈判顺序：先红线（实为融资租赁或施工、超二十年、违法建筑强制起租、地未拿到收全额、资金定性拒锁、无监管打款），再必须改（图纸验收、许可时点、抵租表、交付起租、抵押同意函），最后可优化。签署提醒：土地使用权人签章、国资／上市决议、监管开户、图纸和抵租表作为附件、施工合同关键页。不指导倒签或先使用后办证。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本任务先出草稿，再按本类型硬闸自审；不得只交白稿。不是履约交底、争议文书或效力保证，也不是融资租赁、施工或售后回租安排。
