# 边界与路由

本技能只起草 **租赁合同 / 定向建设租赁合同** 的待签、未建成物按承租人要求建设再租文本。中文展示名是「定向建设租赁合同·起草」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或复制 `融资租赁合同·审查`、`的method。`、`的method。` 的 method。

厂房定向建设正文里夹带一小段设备融资租赁或施工发包专章：专章交接对应原子；建设再租条款可继续审。一张还租表把厂房建设款和设备本息混在一起：必须拆表，设备段不得在本任务改完。

用户坚持本技能把融资租赁、施工或总承包整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
