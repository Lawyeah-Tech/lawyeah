## 节点 1　类型识别与负触发

### 1.1 本类型正像

同时满足才继续：

- 出租人是已依法取得家庭承包经营权的承包农户，不是村委会以所有权人身份出租未发包地；
- 核心给付是约定期限内的占有、使用、收益，对价是租金，承租人**不取得**承包经营权主体资格；
- 标的是承包地（耕地／林地／草地等农业用地），不是集体经营性建设用地或宅基地房屋。

标题写成「农村土地承包经营权租赁合同」「承包地出租协议」只是线索。名实不符按核心给付归类，标题冲突写入 `C#`。

## 硬闸 A　成员与备案

本闸是本类型签署能力级闸。

1. **谁是出租人**  
   农村集体经济组织的成员，依法取得农村土地承包经营权，从事家庭承包经营的，为农村承包经营户。依据：民法典第五十五条。家庭承包的承包方是本集体经济组织的农户；农户内家庭成员依法平等享有承包土地的各项权益。依据：2018 年修改决定将第十五条改为第十六条并增加第二款。  
   发包方（村集体经济组织或村民委员会）**不是**本合同出租人。不要把村委会写成甲方出租人，除非集体尚未发包或依法收回后再出租——那是另一类型，本任务负触发。  
   **修改句**：`甲方是持有【待填：承包合同／土地承包经营权证／不动产权证】的承包农户，由承包方代表【待填】与下列成年家庭成员共同签署：【待填】。发包方【待填：村集体经济组织／村民委员会名称】不是本合同出租人，仅依本合同配合备案。`

2. **户内同意**  
   个别成员单独对外出租大额、长期土地：签署能力字段停止，必须补家庭书面同意。口头「家里人都知道」不得写成已授权。  
   最强反方：相对人可能主张户主签字即代表全家。签前：不宣布一人签字必然无效，也不写成已经约束未签字成员。  
   **修改句**：`本合同须由户内全体成年家庭成员签字捺印，或作为附件出具《户内同意书》。未签字成员事后主张无权处分的，任何一方不得以「户主已代表全家」对抗补正要求。妇女与男子享有平等的土地承包权益，不得以出嫁、丧偶或户无男性为由漏签。`

3. **承租人成员身份**  
   本集体经济组织成员承租：用于内部调剂时，仍是出租不是转让；转让才变更承包权主体。  
   非本集体经济组织成员：不得通过本类型「取得」家庭承包的土地承包经营权。文本写「承包权归乙方、永久耕种、可继承承包权」：必须改定性。外部经营主体、工商资本进入的，知识稿建议改为经营权流转——本任务只分流 `土地经营权流转合同（出租类）·审查`，不改写成流转本约。  
   **修改句**：`乙方确认：其取得的是本合同约定期间内的占有、使用、收益，不取得土地承包经营权主体资格，不替代甲方与发包方的承包关系。乙方【是／不是】本集体经济组织成员：【待填】。任何条款不得写成乙方成为承包户或承包权过户至乙方。`

4. **向发包方备案，不是批准生效**  
   承包方流转土地经营权，应当与受让方签订书面流转合同，并向发包方备案；代耕不超过一年的可以不签书面合同。依据：农村土地经营权流转管理办法第十七条。承包方依法采取出租、入股或者其他方式流转土地经营权，发包方仅以未报其备案为由请求确认合同无效的，不予支持。依据：承包纠纷解释（2020 修正）第十四条。当事人未依照法律、行政法规规定办理租赁合同登记备案手续的，不影响合同的效力。依据：民法典第七百零六条。  
   2018 年承包法第三十六条全文未核验前，不得把记忆中的「出租应向发包方备案」条号写成已核验 `L#`；备案结论用第十七条和解释第十四条。  
   禁止：「未经发包方批准本合同不生效」「未备案则本合同未成立且互不负责」「经全体村民代表大会批准后生效」。村民会议三分之二是发包方案程序，不是农户出租承包地的法定条件。  
   **修改句**：`本合同自甲乙双方及户内成年成员签字（或捺印）之日起在当事人之间生效。甲方应在签署后【待填】日内将本合同向发包方备案，乙方应配合提供身份及经营材料。未备案不影响本合同效力，但任何一方不得以未备案为由拒绝交地、付租或配合备案。本合同生效不以发包方批准或村民代表大会决议为条件。`

5. **再流转**  
   受让方将流转取得的土地经营权再流转以及向金融机构融资担保的，应当事先取得承包方书面同意，并向发包方备案。依据：流转管理办法第十二条。经承包方书面同意，并向本集体经济组织备案，受让方可以再流转土地经营权。依据：2018 年修改决定第四十六条。  
   **修改句**：`未经甲方事先书面同意并向发包方备案，乙方不得再出租、转包、交他人使用，不得以本合同项下权利设定融资担保。擅自再流转的，甲方可以解除本合同。`

6. **最强反方**  
   承租人可能主张有合同就不必备案、户主签字即可；未签字成员可能主张整约无效。签前两极都不写。只写：协议不能补造户内同意；备案是义务不是生效要件。

核验失败：备案是否影响效力的法律结论字段停止；仍须标出文本是否把备案写成生效条件，修改句草稿改为备案义务。

## 硬闸 B　期限不得超过剩余承包期

本闸改变能不能按本类型放行。

1. **锁在权利存续期内**  
   耕地的承包期为三十年。草地的承包期为三十年至五十年。林地的承包期为三十年至七十年。届满由土地承包经营权人依照农村土地承包的法律规定继续承包。依据：民法典第三百三十二条。家庭承包的耕地的承包期为三十年，届满后再延长三十年。依据：土地管理法（2019 修正）第十三条。承包方在承包期限内有权依法自主决定流转对象、方式、期限。依据：流转管理办法第六条。承包方采取出租（转包）、入股或者其他方式流转的，承包方与发包方的承包关系不变。依据：流转管理办法第十五条。  
   用益物权项下的出租不能超过权利自身存续期。文本必须写清起算日、届满日和二轮承包到期日。只有「长期租赁」「随乙方经营需要」「永久」：红线。缺数字用 `【待填】`。  
   2018 年承包法第三十八条「流转期限不得超过承包期的剩余期限」全文本次未核验，不写入 `L#`；方法层仍锁死不超过剩余承包期，运行时再核。  
   **修改句**：`租赁期限自【待填：交地日／约定起算日】起，至【待填：不晚于甲方本幅承包地二轮承包到期日____年__月__日】止，共计【待填】年，不得超过甲方土地承包经营权的剩余期限。任何一方不得以本合同已签署为由主张租期延至延包后的新一轮承包期。`

2. **禁止预锁延包后的权利**  
   「二轮到期后再自动续二十年」「延包后乙方当然继续承包」「租期至乙方经营结束」。红线。延包完成前继续占有：到期终止，延包后再签，不得写成自动取得新一轮承包权。  
   **修改句**：`删除永久、自动续至延包后或随乙方经营需要确定租期的条款。本合同于甲方本幅承包地承包期届满之日终止。届满前【待填】日，双方可书面协商是否在甲方依法完成延包后另签新合同；新合同不因本合同而产生，乙方不因本合同取得新一轮土地承包经营权。未另签的，乙方应在届满日交回土地并按约定恢复耕种条件。`

3. **普通租赁理解时的二十年截断**  
   租赁期限不得超过二十年。超过二十年的，超过部分无效。届满可以续订，但约定的租赁期限自续订之日起不得超过二十年。依据：民法典第七百零五条。  
   本类型强调用益物权项下出租，主锁剩余承包期。若标题或结构已被识别为普通债权租赁，或用户主张按租赁合同编处理：超过二十年的部分无效；同时评估是否应负触发 `农村土地租赁合同·审查`。禁止把「剩余承包期还有二十五年」写成可以一次锁死二十五年普通租赁且全部有效。  
   **修改句（仅当按租赁合同编理解时）**：`如本合同被认定为租赁合同，租赁期限适用民法典第七百零五条，不得超过二十年，超过部分无效。双方同意将届满日调整为【待填：不超过二十年且不超过剩余承包期的较早者】。`

4. **期限不明**  
   当事人对出租地流转期限没有约定或约定不明的，参照民法典第七百三十条处理。除另有约定或属于林地外，承包地交回时间应当在农作物收获期结束后或下一耕种期开始前。依据：承包纠纷解释（2020 修正）第十六条。对期限没有约定或约定不明，依法仍不能确定的，视为不定期租赁，当事人可以随时解除，但应当在合理期限之前通知。依据：民法典第七百三十条。  
   修改句补书面起止日；禁止用「随时可解除」掩盖本应定期的耕地出租。

5. **最强反方**  
   承租人可能主张延包后当然续租，或主张剩余承包期二十五年即可一次锁死。出租人可能主张超过一天都导致整约无效。签前：只写超过剩余承包期（及按租赁理解时超过二十年）的部分不能放行；不保证延包后必然续订；不把整约因超期写成全部无效。

核验失败：第三百三十二条、第七百零五条法律结论字段停止；仍须标出文本年限与二轮到期日，修改句草稿把届满日改到不超过剩余承包期。

## 硬闸 C　与土地经营权流转、普通农地租赁、转让切开

本闸改变能否留在本任务。

1. **本类型 ≠ 土地经营权流转**  
   承包方承包土地后，享有土地承包经营权，可以自己经营，也可以保留土地承包权，流转其承包地的土地经营权，由他人经营。依据：2018 年修改决定第九条。土地承包经营权人可以自主决定依法采取出租、入股或者其他方式向他人流转土地经营权。依据：民法典第三百三十九条。流转期限为五年以上的土地经营权，自流转合同生效时设立；当事人可以向登记机构申请土地经营权登记；未经登记，不得对抗善意第三人。依据：民法典第三百四十一条。出租（转包），是指承包方将部分或者全部土地经营权，租赁给他人从事农业生产经营。依据：流转管理办法第十四条。  
   出现「保留承包权、流转经营权」「五年以上办土地经营权登记」「登记后对抗第三人」：负触发 `土地经营权流转合同（出租类）·审查`。禁止在本任务把上述条款改成「有效的承包经营权出租」。禁止打开其 method。  
   **修改句（仅告知／删除）**：`删除「土地经营权登记对抗第三人」「乙方取得土地经营权并申请登记」等与本类型不一致的效力语言。各方确认：本合同是承包农户出租承包经营权项下的使用收益，乙方不取得承包户资格。如双方本意是承包方保留承包权、流转土地经营权并办理五年以上登记，应另行签订土地经营权流转合同并转相应审查，不在本合同改写。`

2. **本类型 ≠ 普通农村土地租赁**  
   承租人是非本集体经济组织成员，且交易不设立、不流转用益物权，只成立普通债权租赁、强调二十年截断：负触发 `农村土地租赁合同·审查`。禁止把本类型改成「普通债权不超过二十年且无物权效力」与「登记对抗」两套语言并存。  
   **修改句（三类混贴时）**：`本合同只保留与「承包经营权项下出租使用」一致的一套效力语言。删除「登记对抗第三人」与「普通债权不超过二十年且无物权效力」互相粘贴的条款。`

3. **本类型 ≠ 承包经营权转让**  
   土地承包经营权人有权依法互换、转让。依据：民法典第三百三十四条。经承包方申请和发包方同意，承包方可以将土地承包经营权转让给本集体经济组织的其他农户；未经发包方同意的，转让合同无效；受让方须为本集体农户，转让后期限不超过剩余期限；转让后受让方与发包方签订承包合同，原承包关系终止。依据：农村土地承包合同管理办法第二十条。任何组织和个人强迫进行土地承包经营权互换、转让或者土地经营权流转的，该互换、转让或者流转无效。依据：农村土地承包法（2018 修正）第六十条。  
   「转让、过户、更名到乙方」「乙方成为承包户」：删除。外部资本买断：红线，不改写成可履行转让。  
   **修改句**：`删除「承包权归乙方」「过户、更名」「乙方成为承包户」「可继承承包权」条款。甲方仍是承包方，继续对发包方承担承包义务。`

4. **最强反方**  
   标题写「租赁」但附件是《土地经营权流转合同》或《承包经营权转让合同》，相对方可主张按流转或转让履行。签前按核心给付分流，不两套都审。

## 硬闸 D　用途、地块与耕地保护

1. **地块特定**  
   证载面积与实测、四至、附图、土地用途（耕地／林地）、是否永久基本农田必须写清。只有「村东那块地」：必须改。

2. **不得改变农业用途**  
   土地经营权流转不得改变承包土地的所有权性质及其农业用途，制止耕地「非农化」、防止耕地「非粮化」。依据：流转管理办法第三条。受让方禁止改变土地的农业用途；禁止闲置、荒芜耕地；禁止占用耕地建窑、建坟或擅自在耕地上建房、挖砂、采石、采矿、取土等；禁止占用永久基本农田发展林果业和挖塘养鱼。依据：流转管理办法第十一条。禁止占用耕地建窑、建坟或擅自在耕地上建房、挖砂、采石、采矿、取土等；禁止占用永久基本农田发展林果业和挖塘养鱼。依据：土地管理法实施条例（2021 修订）第十二条。未经依法批准，不得将承包地用于非农建设。依据：民法典第三百三十四条。承包方违反规定将承包地用于非农建设或造成永久性损害，发包方可请求停止侵害、恢复原状或赔偿损失。依据：承包纠纷解释第八条。  
   设施农用地若涉及，须另走设施农用地程序，不在租赁条款里「视为同意建房」。  
   **修改句**：`乙方仅得按【待填：粮食种植／约定农业用途】使用土地，不得改变农业用途，不得破坏耕作层，不得占用永久基本农田发展林果业或挖塘养鱼，不得建设厂房、农家乐硬化或住宅。涉及设施农用地的，双方另按当时有效的设施农用地程序办理，本合同任何条款不视为已经同意非农建设。`

3. **改变用途、撂荒的解除**  
   受让方擅自改变农业用途、弃耕抛荒连续两年以上、给土地造成严重损害或严重破坏土地生态环境的，承包方可单方解除；承包方合理期限内不解除的，发包方有权要求终止。依据：流转管理办法第二十条。收回土地的程序不得暴力。  
   **修改句**：`乙方有下列情形之一的，甲方可书面通知解除本合同：擅自改变农业用途；弃耕抛荒连续两年以上；严重损害土地或破坏生态环境；欠付租金超过【待填】日。解除后乙方应在【待填】日内交回土地并恢复耕种条件。甲方收回土地不得采取暴力或毁损青苗以外的违法方式。`

4. **最强反方**  
   承租人可能主张「村里口头答应可以建农家乐」。签前：用途以承包证和合同为准；口头变更用途不放行。

## 硬闸 E　征收、对价、交付与语言

1. **征收与补贴**  
   承包地被依法征收、征用、占用的，承包方有权依法获得相应补偿。依据：2018 年修改决定第十七条。禁止约定「所有补偿归承租人」。土地补偿归集体／承包方依法应得部分；青苗和投入归实际投入人。耕地地力补贴归实际耕种者还是承包方，按当年政策与合同约定，不编造全国统一归属。  
   **修改句**：`因依法征收、征用本幅土地的，土地补偿费、安置补助费归【甲方／依法应得的集体或承包方】；青苗和乙方实际投入的地上附着物补偿归实际投入人。任何一方不得约定全部征收补偿一律归乙方。甲方应在知悉征收事项后【待填】日内书面通知乙方。`

2. **租金**  
   标准、支付日、调整、青苗期不足年的折算必须落句。预付超长期租金要防承包方花光后主张合同无效：修改句要求分期或监管，不编造比例。未给出的数字写 `【待填】`。「定金」二字才讨论定金罚则。无核验引文不得把百分之二十写成现行法结论。

3. **交付与返还**  
   交地标准、到期恢复耕种条件、附着物拆除或折价必须分列。签收、付租、进场不当然等于四至验收。

4. **担保**  
   本类型下承租人未取得承包经营权的，不能用承包经营权去抵押。符合条件的土地经营权融资担保走经营权流转结构，分流 `土地经营权流转合同（出租类）·审查`，本任务不写可履行抵押路径。

5. **语言**  
   承包经营权／土地经营权／土地使用权三词不得混用。本类型只描述承包经营权项下的出租使用。删除房屋承租人优先购买、城镇租赁备案三十日、买卖不破租赁的商品房表述。本集体成员在流转价款、流转期限等主要内容相同的条件下主张优先权的，应予支持，但书面公示合理期限内未主张、或未经书面公示且外部人开始使用两个月内未主张的除外。依据：承包纠纷解释第十一条。房屋承租人届满优先承租不得直接写成农地法定权。  
   正说＋反说：写可种植，须写改变用途可解除；写租期至承包期满，须写延包后是否优先协商续租（不是自动取得新一轮承包权）。自然灾害可减免当年租金，不当然永久解除，除非不能再农用。

6. **最强反方**  
   承租人可能主张征收后全部补偿归实际经营人；出租人可能主张未备案可以拒付租金。签前：补偿靠分层约定；备案不影响效力。

## 节点 4　程序与生效

把户内同意、书面合同、向发包方备案、延包、经营权登记写成**义务和期限**，不写成已经完成。

| 文本写法 | 本任务动作 |
| --- | --- |
| 「本合同签字即生效，承包权归乙方，永久耕种」 | 红线；切开出租／转让／买断 |
| 「双方同意视为户内全体已同意，无需其他成员签字」 | 红线；改为书面同意附件 |

## 节点 5　对价、保证金、退出

1. 租金构成、币种、支付节点、青苗折算、保证金分列。禁止编造单价或总价。
2. 退出：约定解除条件、通知、剩余租金、恢复耕种。禁止只写「双方协商解除」而无通知和清理。
3. 强迫流转无效。依据：农村土地承包法（2018 修正）第六十条。修改句不得写成「村里要求必须租给指定公司」。

## 节点 6　格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

重复使用的合作社／公司承租模板仍可能构成格式条款。审查单方「视为无异议」、不得调整的高额违约金、管辖、最终解释权是否有显著提示。

违反强制规范不一律无效。未办备案主要对应管理义务，不轻易写「未备案则整份出租无效」。改变农业用途、破坏耕作层、永久买断承包权给外部资本：只告知，不写假架构。禁止用已失效「效力性／管理性」口诀。

## 节点 7　违约、解除、争议解决

1. 欠租、改变用途、撂荒、擅自转租、逾期交地必须分别有可执行后果。只有「依法承担违约责任」视为必须改。
2. 构成违约不等于当然解除。法定解除只点名催告或目的不能实现，不在本任务作出已解除结论。
3. 违约金避免「不得调整」或「按永久租期总租金百分之三十必得」。不得用无效后段租期计算违约金基数。
4. 争议解决：已有仲裁条款，不得改成「应向某法院起诉」并假装已选定诉讼；或裁或诉、机构不明：改成单一机构或单一法院连结点。土地承包经营纠纷可能走仲裁前置的，只标红旗，不选定唯一路径充作法律意见。
5. 微信已读不写成已经送达，除非合同把该渠道定为送达。

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`
