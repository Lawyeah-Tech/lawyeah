# 农村土地承包经营权租赁合同·审查

## 任务目标

在单一立场下，只审查 **农村土地承包经营权租赁合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文显示名为「农村土地承包经营权租赁合同·审查」。`depends-on` 为空。不要求先跑导航。

主线是已依法取得土地承包经营权的承包农户，把该用益物权项下土地交给他人占有、使用、收益，对方支付租金。承租人**不取得**承包经营权主体资格，不替代承包方与发包方的承包关系。本类型不是「三权分置」后单独设立土地经营权的标准文本，也不是对农用地成立的普通债权租赁。

不交付：他类审查、从零起草、履约交底、争议文书、有效性或必然完成备案保证、土地经营权流转整案、普通农村土地租赁整案、承包经营权转让整案、集体建设用地或宅基地房屋整案。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **成员／备案硬闸**：家庭承包以户为单位；农户内家庭成员依法平等享有承包土地的各项权益。承包方代表签字外，应取得其他成年家庭成员书面同意。承租人是否本集体经济组织成员必须入表。出租、转包应向发包方备案；当事人未备案，发包方仅以未备案请求确认无效的，不予支持。备案不是生效要件。禁止把村委会写成出租人（集体尚未发包或收回后再出租除外）。禁止「经全体村民代表大会批准才生效」。再流转须承包方书面同意并向发包方／本集体备案。
2. **期限硬闸**：起止日不得超过承包期的剩余期限；二轮承包到期日必须写明。禁止「永久」「随乙方经营需要」。耕地承包期三十年，届满依法再延长；本约不得预先写成已经取得延包后的新一轮承包权。若文本按普通租赁理解，租赁期限不得超过二十年，超过部分无效；续订自续订之日起仍不得超过二十年。延包完成前占有应到期终止，再签新约。
3. **与经营权流转切开**：正文是承包方保留承包权、流转土地经营权，或约定五年以上办土地经营权登记、未经登记不得对抗善意第三人 → **负触发** `土地经营权流转合同（出租类）·审查`。对农用地成立普通债权租赁、不设承包权或经营权、强调二十年截断且无用益物权语言 → **负触发** `农村土地租赁合同·审查`。名为租赁、实为承包权永久转让／过户给外部资本：红线或转转让规则，不在本任务改写成可履行买断。禁止打开 `土地经营权流转合同（出租类）·审查` 或 `农村土地租赁合同·审查` 的 method「对照一下」。
4. **承租人不取得承包户资格**：删除「乙方成为承包户」「承包权归乙方」「过户、更名到乙方」。转让才导致承包权主体变更，且须发包方同意、受让方原则上为本集体经济组织其他农户。
5. **用途与耕地保护**：禁止改变农业用途、破坏耕作层、撂荒、占用永久基本农田发展林果业或挖塘养鱼。设施农用地另走程序，不在租赁条款里「视为同意建房」。
6. **征收与语言**：土地补偿、安置归集体／承包方依法应得部分；青苗和投入归实际投入人。禁止「所有补偿一律归承租人」。三词不得混用：承包经营权／土地经营权／土地使用权。不套城镇房屋租赁的优先购买、三十日备案、买卖不破租赁。

## 工作边界

正触发：已有可读待签《农村土地承包经营权租赁合同》或同等出租文本，尚未签署，尚未成争；出租人是已取得家庭承包经营权的承包农户；核心给付是约定期限内的农业使用、收益；对价是租金；承租人未写成新的承包户。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 承包方保留承包权、流转土地经营权、五年以上登记对抗 → `土地经营权流转合同（出租类）·审查`；
- 对农用地成立普通债权租赁、不设承包权或经营权 → `农村土地租赁合同·审查`；
- 标的是已登记集体经营性建设用地出租 → `标的是已登记集体经营性建设用地出租→`；
- 宅基地上房屋出租或委托运营 → `宅基地上房屋出租或委托运营→`；
- 无文本、本类型条件已谈妥、要出己方稿 → `农村土地承包经营权租赁合同·起草`；
- 已签只问交地日、付租日、备案日 → 本套导航的履约步骤；
- 已成争（催告交地、户内要地、改变用途查处、立案、开庭、仲裁）→ `或对应专项领域。` 或对应专项，不填签前十节。

改变耕地用途、永久买断承包权、倒签户内同意：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；代表承包农户还是承租人；承租人是否本集体经济组织成员；正文、承包证、户内同意书、地块示意图、备案表版本；拟租年限与二轮到期日；是否出现经营权登记、买断或过户表述；不可接受事项；法域与拟签时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密时，先停止策略输出。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签户内同意、把农用地改成可履行非农建设、把永久买断承包权写成有效出租、把本约改成经营权流转或普通农地租赁外壳、保证有效或必然完成备案。
- `字段停止`：未见承包证或四至；未见户内书面同意；承租人成员身份不明；剩余承包期或二轮到期日不明。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或文本已滑入经营权流转、普通农地租赁、转让、集体建设用地或宅基地房屋。

生存级预付租金或个人无限连带且用户拒绝升级：停止「可以签署」建议。
