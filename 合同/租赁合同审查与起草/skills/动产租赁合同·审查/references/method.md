# 审查方法（锁定 租赁合同 / 动产租赁合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制房产租赁备案/优先购买/一房数租主路径、融资租赁还租表/全额加速/第 750 条维修、建筑设备进退场检尺或湿租工伤节点。禁止抄 `房产租赁合同·审查` 的 method。

定性校验：标题、核心给付与本类型一致才继续；指定购买+融物、房屋或不动产、工地设备湿租或包成果、买卖过户明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受或唯一必得租金/重置价。

`search_law` 返回已失效《合同法》租赁章及其解释、已失效《经济合同法》、已失效担保法解释、已失效《城市房屋租赁管理办法》时记为噪声，不得写入 `L#`。城镇房屋租赁解释、商品房屋租赁管理办法只证明是另一类型，不得当作本类型主路径。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。汽车融资租赁或房屋租赁范本只证明是另一类型。

知识库纠正（不回写双文件）：

- `基本面.md` “包括……以及设备租赁”：办公设备、模具、集装箱、乘用车、一般生产设备可留本类型。工地塔吊、钢管、脚手架为中心并可能附带操作人员或包施工成果 → 负触发 `建筑设备租赁合同·审查`。
- `框架.md` “日常保养归承租人，大修/设计缺陷归出租人”：这是建议分列，不是第 712 条已被改写。维修条款沉默时，现有依据支持出租人承担维修义务。
- `框架.md` “经营性租赁写成承租人包修并已体现在租金里”：属于第 712 条“另有约定”。须书面逐项，且租金对价可识别；不得口头或格式小字完成改写。
- 实务中汽车租赁常由承租人承担维修：商业惯例不是法源。要改默认，必须落成书面另约，并加黑提示。
- 普通动产租赁没有房屋备案生效程序（第 706 条：未办登记备案不影响效力）。不得把房产租赁备案、优先购买写成动产条件。
- 融资租赁第 750 条（承租人占有期间维修）、第 752 条（催告后可请求全部租金）不得当作普通租赁默认。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 出租人将已有动产交付占有使用，承租人付租，到期返还 | 本类型 | 正触发 |
| 出租人根据承租人对出卖人、租赁物的选择去购买；融资+融物；租金覆盖大部分购价 | 融资租赁 | 负触发 `融资租赁合同·审查` |
| 承租人先卖自有物再租回 | 售后回租 | 负触发 `售后回租合同·审查` |
| 主给付是房屋使用权换租金 | 房产租赁 | 负触发 `房产租赁合同·审查` |
| 主给付是土地或其他不动产 | 不动产租赁 | 负触发 `不动产租赁合同·审查` |
| 工地塔吊/钢管/脚手架/升降机为中心，附带司机、安拆或包成果 | 建筑设备租赁 | 负触发 `建筑设备租赁合同·审查` |
| 移转所有权换价款，或租期覆盖寿命且到期无偿归属 | 动产买卖或须改识别 | 负触发 `到期必买租金冲抵购机款`，或红线改返还/单列留购价后重新定性 |
| 无偿使用 | 借用 | 负触发引擎重新定性 |
| 以保管为目的、不产生使用收益 | 保管/仓储 | 负触发对应仓储原子或引擎 |

支持切开的规范（法律结论须运行时复核）：

- 第 703 条：租赁是交付使用、收益，承租人付租——核心是占有使用权，不是所有权。
- 第 735 条：融资租赁是出租人根据承租人指定购买并提供使用。
- 融资租赁解释（2020 修正）第 1 条：结合标的性质、价值、租金构成和权利义务认定；名不副实按实际关系处理。
- 第 595 条：买卖是转移所有权换价款——走 `到期必买租金冲抵购机款`。

### 1.3 与融资租赁 / 房产租赁 / 建筑设备租赁切开（硬闸）

## 节点 2　主体、处分权与特殊动产资质

### 2.1 主体表

建表：签约名、履行名、付款名、发票名、登记所有人、授权签字人、实际使用人。名称不一致不自动合并。出租人须对动产有所有权或合法处分权；共有、夫妻大额设备未闭合：该签署能力字段停止，不写成“可以盖章”。

口头“我们老板同意了”不得写成已授权。项目部、工地签章而无企业主体：必须改补企业相对人。

### 2.2 特殊动产与许可

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 经营性道路客运/货运车辆、船舶光租、航空器，无许可痕迹 | 字段停止；修改句要求许可/登记/适航或检验件作为附件 | 可以营运；合同有效即无行政责任 |
| 特种设备出租，无使用登记或检验合格标志 | 字段停止；特种设备安全法第 29 条：出租期间使用管理和维护保养原则上由出租单位承担，另有约定除外 | 按现状交付即可免责 |
| 私家车长期对外出租 | 标行政风险；不宣告当然无效，也不写成已可网约或非法营运合法化 | 已具备营运条件 |
| 只有营业执照 | 执照不等于营运许可或特种设备登记 | 已完成许可 |

部门规章或许可义务不当然导致民事合同无效（解释第 16 条）。本任务只停止“可以营运/可以出租特种设备”表述。

## 节点 3　标的特定化与权利负担

审查清单，缺一项则该字段不得写成已闭环：

1. 名称、品牌、型号、数量、附属配件。
2. 出厂编号、车架号/VIN、船体识别号或发动机号。种类物（“同型号挖机一台”）必须约定交付时补编号并写入交接单，否则返还和损坏索赔无法对应。
3. 消耗物（燃油、试剂、一次性耗材）不得写成到期原物返还。
4. 权利负担：抵押、质押、留置、融资租赁登记、所有权保留、查封。材料未提及不得写成“无权利负担”，只能写 `依据不足`。第三人主张权利致不能使用、收益：承租人可减租或不付租，并应及时通知（第 723 条）。
5. 适租：交付时应适于约定用途。隐藏瑕疵致人损害，出租人不能以“按现状交付”免除安全强制规范责任。

修改句：

「租赁物以附件《设备清单》为准，列明名称、型号、出厂编号/VIN【待填】、数量及附属配件。种类物应在交付时补编唯一识别号并记入《交接单》，未补编号前不得起租。燃油、试剂等消耗物由承租人自行采购或按实结算，不列入到期原物返还范围。」

## 节点 4　动产交付（硬闸）

支持依据：第 703、708 条。动产租赁以**交付占有**为履行节点，并在租赁期限内保持符合约定用途。

| 文本写法 | 动作 |
| --- | --- |
| “出库即视为交付”“装车即风险转移”“运单签收不得再提表面瑕疵” | 红线。改为占有移转+点验+交接单 |
| 无交接单、无损伤记录、无运行测试 | 必须改。否则进场已有损伤事后无法区分 |
| 签收、付款或开机视为验收合格 | 必须改。表面异议期届满只约束表面状况，不免除隐藏瑕疵 |
| 经承运人运送但未写风险转移时点 | 必须改。不能默认出库即交付 |
| “按现状交付，出租人不再保证适租”且未书面披露瑕疵 | 必须改。第 708 条保持用途；安全强制规范不得事先免除（第 506 条） |

修改句：

「双方应于【待填】年【待填】月【待填】日在【待填】地点当面点验。出租人将租赁物置于承租人实际控制并共同签署《交接单》之时视为交付占有，并自该时起租。承运人出库、装车或运单签收不视为已交付。《交接单》须核对附件清单的编号与配件，记录仪表读数或公里数、已有损伤，并完成约定的运行测试。承租人接收后【待填】日内未书面提出表面瑕疵异议的，仅视为表面状况符合约定，不免除出租人对交付时已存在的隐藏瑕疵及租期内保持约定用途的义务。」

最强反方：出租人主张“出库即完成给付，承租人已付款即验收”。现有依据不支持把出库或付款单独写成第 708 条已履行。

本节点不展开房屋交房验收、工地进退场检尺过磅——那是邻类路径。

## 节点 5　维修（硬闸）

支持依据：第 704、712、713、714 条。负向对照：第 750 条仅适用于融资租赁，不得静默套用。

| 文本写法 | 动作 |
| --- | --- |
| 维修条款沉默 | 必须补句。现有依据支持出租人承担维修义务 |
| “租赁期间一切维修保养均由承租人承担，停机仍计全额租金”且未体现在租金对价、无加黑提示 | 红线或必须改。整锅转移须书面另约、分列项目，并约定出租人逾期不修时的自修、减租或延展 |
| 直接引用或套用“承租人应当履行占有期间的维修义务” | 必须删除第 750 条口径。普通租赁不是融资租赁 |
| 日常保养与大修、设计缺陷、隐藏瑕疵混写 | 必须分列。承租人过错造成的损坏，出租人不承担该次维修（第 713 条第 2 款） |
| 特种设备出租，把使用管理和维护保养整锅转给承租人且无另约痕迹 | 必须改。特种设备安全法第 29 条原则上由出租单位承担，另有约定除外 |

修改句：

「除因承租人过错造成的损坏外，租赁物维修义务由出租人承担。日常清洁、润滑、更换合同列明的易耗件由承租人负责并自行承担费用；大修、安全附件更换、设计缺陷及交付时已存在的隐藏瑕疵，由出租人在收到书面通知后【待填】日内维修。出租人逾期未修的，承租人可自行维修，费用由出租人负担，并相应减少租金或延长租期。未以书面逐项约定并在租金中可识别对价的，不得将维修义务整体转给承租人，也不得适用融资租赁项下承租人占有期间的维修规则。承租人应妥善保管租赁物；因保管不善致毁损、灭失的，承租人承担赔偿责任。」

可退让：经营性租赁可约定承租人包修，但须加黑提示、单独确认，并写明已计入租金的范围；停机是否计租须另条，不得与包修捆绑成“坏了还全额付”。

最强反方：出租人主张汽车租赁行业惯例由承租人维修，或主张“另有约定”已成立。现有依据不支持把惯例或格式小字单独写成第 712 条但书已满足。

## 节点 6　租金、押金、留购、格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 租金与租期

计费单位（台班/日/月/公里）必须唯一；台班定义（8 小时或仪表）写死。进出场、天气停工、维修停机是否计租分列。禁止编造单价。

租期超过二十年的部分无效（第 705 条）。六个月以上应当书面；未采用书面形式且无法确定期限的，视为不定期，解除须合理期限前通知（第 707、730 条）。不定期形态仍留本任务，不因期限形态改走 `定期租赁合同·审查`/`不定期租赁合同·审查`。

### 6.2 押金不是定金

预收履约保证金用于抵扣损坏和欠租，不作定金。必须使用“定金”二字才讨论罚则。约定或推算超过主合同标的额百分之二十：超过部分不产生定金效力（第 586 条）。无核验引文不得把 20% 写成现行法结论。

修改句：

「甲方支付的人民币【待填】元为履约保证金，用于抵扣到期未付租金和交接单记载范围以外的损坏，不作定金，不适用定金罚则。租赁物按约返还并结清费用后【待填】日内无息退还余额。」

### 6.3 留购与租满即送

禁止“租满即送”却无购买价款。如确有留购，单列留购价和过户时点，并重新审查是否实为融资租赁或分期买卖。租金接近新购价且到期归属、出租人并未依指定购买：不得写成普通租赁已闭合。

### 6.4 格式条款

为重复使用而预先拟定、订立时未与对方协商。从事经营活动的出租人不得仅以“这次没用过第二次”否认。依据示范文本制作，不当然排除格式条款。

审查：出库即验收、整锅包修、私力取回、免责、管辖/仲裁、自动续期等是否有足以引起注意的标识，以及是否按要求说明（第 496 条；解释第 10 条）。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在附件 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

提供方对其已尽提示或说明承担举证责任。

### 6.5 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的、是否仅行政管理、是否只规制履行行为（第 153 条；解释第 16 条）。禁止用已失效“效力性/管理性”口诀代替解释第 16 条。造成对方人身损害或因故意/重大过失造成财产损失的免责条款无效（第 506 条）。禁止流通、查封交付、虚假租赁：不改写成有效履行。

## 节点 7　取回、返还、解除与争议

1. 欠租：出租人可请求在合理期限内支付；逾期不支付的，可以解除（第 722 条）。禁止把第 752 条“请求支付全部租金”写成普通租赁默认。普通租赁加速到期应限于实际损失，避免融资租赁式全额加速。
2. 构成违约不等于当然解除。法定解除只点名催告或目的不能实现，不在本任务作出已解除结论。租赁物危及安全或健康的，即使订立时明知不合格，承租人仍可随时解除（第 731 条）。
3. 返还：原物+正常损耗（第 733 条）。不能返还时的赔偿公式预先约定：重置价－折旧，或单价表；时点用 `【待填】`（丢失当日/起诉日/重置日）。逾期未还，可按原租金标准计占用费并主张取回，二者不得重复填满同一损失。
4. 取回：可约定协商取回、公证取回或诉讼保全。禁止“随时强行开走并不负任何责任”。私力冲击、扣人质：红线删除。
5. 转租须书面同意；未经同意转租，出租人可以解除（第 716 条）。承租人不得将租赁物抵押、质押、出资。
6. 第三人损害：机动车、工程机械致害，合同不得约定“一律由承租人对外担责”来排除强制保险和侵权法上的责任主体审查；对内追偿可以约定。
7. 违约金不是必得金额；不在本任务做第 585 条精算。修改句避免“不得调整”或“按总价 30% 必得”。
8. 争议解决：出现仲裁条款，不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核，修改句改成单一仲裁机构或单一法院连结点。专属管辖可能：只标红旗，不选定唯一法院充作法律意见。
9. 通知送达：设备在工地流动，送达地址不能只写工地彩钢房。微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。

修改句（取回）：

「承租人欠付租金经书面催告后【待填】日仍未支付，或擅自处分、停止投保、下落不明的，出租人可解除本合同并取回租赁物。取回应通过双方到场交接、公证机关证据保全或人民法院保全/执行程序进行。禁止在未完成前述程序时强行开走、扣留人员或毁损现场。取回费用由违约方承担。出租人不得请求支付尚未发生的全部剩余租期租金，但可就实际损失和逾期占用使用费主张权利，二者不得重复计算。」
