# 边界与路由

本技能只审查 **租赁合同 / 动产租赁合同** 的待签文本。中文展示名是「动产租赁合同·审查」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 出租人依承租人指定向出卖人购买；融资+融物；还租表覆盖购价；到期象征性价款留购 | `融资租赁合同·审查`。P1：专业版未装则 `unavailable`，提示，不得用本技能硬套 |
| 承租人先把自有物卖给对方再租回 | `售后回租合同·审查`。P1；未装则 `unavailable` |
| 主给付是住宅、商铺或其他房屋使用权换租金 | `房产租赁合同·审查`。不得删掉房屋条款后继续当动产审；不得把房屋备案、优先购买做成动产主路径 |
| 主给付是土地、建设用地或其他不动产占有使用 | `不动产租赁合同·审查` |
| 工地塔吊、钢管、扣件、脚手架、施工升降机为中心，并附带司机、安拆或包施工成果 | `建筑设备租赁合同·审查` |
| 移转动产所有权换价款，或分期付款到期当然归属 | `到期必买租金冲抵购机款` |
| 临时建筑 | `临时建筑租赁合同·审查` |
| 产权式商铺、定向建设、农地三类 | `产权式商铺租赁合同·审查` / `定向建设租赁合同·审查` / `农村土地承包经营权租赁合同·审查`–`农村土地租赁合同·审查`。P1 未装则 `unavailable` |
| 标题仅为定期或不定期，且标的不是动产 | `定期租赁合同·审查` / `不定期租赁合同·审查`。动产租赁本身可以是定期或不定期，期限形态不单独转出 |
| 无文本、本类型条件已谈妥、要出己方稿 | `动产租赁合同·起草` |
| 已签未争、只问交接、收租、退场节点 | 本套导航的履约步骤 |
| 已成争 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

动产租赁正文里夹带一小段房屋场地或一次安拆：专条交接对应原子；交付占有、维修分列、租金返还条款可继续审。用户坚持本技能把融资租赁、房产本约或工地湿租整案改完：`目标停止`。
