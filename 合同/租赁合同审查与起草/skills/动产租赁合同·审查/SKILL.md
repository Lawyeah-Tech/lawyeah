# 动产租赁合同·审查

## 任务目标

在单一立场下，只审查 **动产租赁合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文显示名为「动产租赁合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、把融资租赁/房产租赁/建筑设备湿租/动产买卖整案改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **动产交付**：出租人须按约定把租赁物**交付占有**，并在租期内保持适于约定用途（第 708 条）。修改句落到当面点验、编号核对、运行测试、已有损伤记录和《交接单》。承运人出库、装车或运单签收不视为已交付；风险转移时点须另写。签收、付款、开机不当然等于验收。
2. **维修**：默认出租人履行维修义务（第 712 条）；承租人可请求合理期限内维修，逾期可自修、费用由出租人负担，并减租或延展（第 713 条）。日常保养与大修/设计缺陷必须分列。承租人包修须书面另有约定，并已体现在租金里。禁止静默套用融资租赁第 750 条。因承租人过错造成的损坏，出租人不承担该次维修。
3. **与融资租赁 / 房产租赁 / 建筑设备租赁切开**：出租人依承租人指定向出卖人购买、融资+融物、租金覆盖购价或到期归属承租人 → 负触发 `融资租赁合同·审查`（P1；专业版未装则 `unavailable`）。主给付是房屋使用权 → `房产租赁合同·审查`；土地或其他不动产 → `不动产租赁合同·审查`。工地塔吊、钢管、脚手架、施工升降机为中心，并可能附带操作人员、安拆或包施工成果 → `建筑设备租赁合同·审查`。不得把房屋备案、优先购买、一房数租顺序或融资租赁全额加速写进本类型主路径。

配套必须改：清单编号特定化；押金不作定金；取回不得私力冲击；物不存在或不交付按借贷/虚假交易停笔；租满即送无留购价则改识别。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签动产租赁正文，尚未签署，尚未成争，核心给付是出租人将**已有动产**交付占有使用、承租人付租并到期返还，用户问能否签、哪里必须改、怎么回对方。设备本身出租、不包施工成果。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 指定出卖人/租赁物购买、融资+融物、还租表覆盖购价 → `融资租赁合同·审查`。P1：专业版未装则 `unavailable`，提示，不得用本技能硬套；
- 承租人先卖后租回同一物 → `售后回租合同·审查`（P1；未装则 `unavailable`）；
- 主文件是住宅、商铺或其他房屋租赁 → `房产租赁合同·审查`；不得删掉房屋条款后继续当动产审；
- 主给付是土地、建设用地或其他不动产占有使用 → `不动产租赁合同·审查`；
- 工地设备为中心并附带司机、安拆班组或包吊装/搭设成果 → `建筑设备租赁合同·审查`；
- 移转所有权换价款、分期留购无租赁返还 → `到期必买租金冲抵购机款`；
- 临时建筑、农地、产权式商铺 → 对应 `临时建筑租赁合同·审查` / `农村土地承包经营权租赁合同·审查`–`农村土地租赁合同·审查` / `产权式商铺租赁合同·审查`（P1 未装则 `unavailable`）；
- 无文本、本类型条件已谈妥、要出己方稿 → `动产租赁合同·起草`；
- 已签只问交接日、收租日、退场 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

禁止流通物、查封扣押物、租赁物不存在或不交付只走资金：只出告知，不改写成可履行租赁。

动产租赁可以是定期或不定期。期限形态不单独改走 `定期租赁合同·审查` 或 `不定期租赁合同·审查`。六个月以上未采用书面形式且期限无法确定的，按不定期处理（第 707、730 条），仍留在本任务出修改句。

## 建立审查坐标

确认：使用者与授权；单方立场（出租人侧或承租人侧择一）；相对方；全文及清单/交接单/保险版本；出租人是否本就有物；是否房屋或工地湿租；交付地点与是否经承运人；维修条款是否沉默或整锅转给承租人；租金是否接近新购价且到期归属；押金/定金用词；取回条款；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的租金、编号、期限、账号用 `【待填】`，不编造。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `动产租赁合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有动产租赁文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。融资租赁、房产/不动产、建筑设备湿租、动产买卖、售后回租负触发。

### 2. 主体、处分权与特殊动产资质

签约名、履行名、付款名、发票名、登记所有人分列。营运许可、特种设备登记未核：字段停止。禁止流通物或查封物：停笔。

### 3. 标的特定化与权利负担

无出厂编号/VIN 的种类物必须在交付时补编号。材料未提及不得写成无权利负担。

### 4. 动产交付（硬闸）

交付占有+交接单+运行测试。禁止出库即交付。

### 5. 维修（硬闸）

默认出租人修；另约须书面分列并对价可见。禁止套用第 750 条。

### 6. 租金、押金、留购、格式条款与强制规范

押金不作定金。租满即送无留购价则改识别。无核验引文则法律结论字段停止。

### 7. 取回、返还、解除与争议

欠租先合理期限催告（第 722 条），不得默认融资租赁式请求全部租金。取回不得私力冲击。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把禁止流通物/查封物/不存在的物、出库即交付不得异议、整锅承租人维修且拒书面另约、或私力取回免责改成可履行结构。
- `字段停止`：法域、动态规则、特种设备登记、营运许可、中登网负担、重置价时点未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
