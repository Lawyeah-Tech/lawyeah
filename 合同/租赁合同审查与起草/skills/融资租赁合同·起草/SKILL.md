# 融资租赁合同·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **融资租赁合同** 己方稿，出稿后用本类型硬闸自审。交付草稿、未决项、自审风险表和自审后修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文显示名为「融资租赁合同·起草」。

`depends-on` 为空。不要求先跑导航。

不交付：他类起草、待签文本签前审查、履约交底、争议文书、有效性保证、保证登记一定办成、保证一定能对抗善意第三人。

## 本类型硬闸

1. **必须同时具备融物与融资**：出租人根据承租人对出卖人、租赁物的选择购买并出租，承租人付租（民法典第七百三十五条）。租赁物须真实、可特定、可转让。仅有资金空转、现场无物或虚构租赁物，不得按融资租赁放行。
2. **直租三方与两合同**：正文或交易结构必须能指认出卖人（可在买卖合同中出现）。买卖合同与融资租赁合同的标的、价款、交付闭合。出租人向出卖人付购货款；把“购货款”打给承租人任其挪用的，不是本类型直租。
3. **直租 ≠ 售后回租 ≠ 普通租赁**：承租人与出卖人为同一人、先卖后租 → `售后回租合同·审查`。无购买安排、出租人将自有闲置设备出租、维修风险按普通租赁分配 → `动产租赁合同·审查` 或 `建筑设备租赁合同·审查`。禁止打开或复制 `动产租赁合同·审查` 及买卖原子 method。
4. **名租实贷不得硬套**：结合标的物性质、价值、租金构成和权利义务认定（2020 解释第一条）。租赁物不存在、低值高买、租金严重偏离成本与合理利润、出租人从未取得所有权 → `租赁物不存在低值高买租金严重偏离成本与合理利润出租人从未取得所有权→`。虚构租赁物合同无效（第七百三十七条），只出告知，不改写成可履行直租。
5. **索赔与付租分轨**：可约定由承租人向出卖人索赔，出租人协助（第七百四十一条）。索赔原则上不影响付租；承租人依赖出租人技能或出租人干预选择的，可以请求减免相应租金（第七百四十二条）。绝对“不得抗辩、绝对支付”须保留租赁物不存在、合同无效、出租人根本违约等出口。
6. **取回须清算；登记对抗不是生效**：逾期付租经催告后，出租人可请求支付全部租金，或解除并收回租赁物（第七百五十二条），二者择一（2020 解释第十条）。取回后按未付租金及其他费用与收回物价值的差额清算（2020 解释第十一条、担保制度解释第六十五条、第七百五十八条）。未经登记不得对抗善意第三人（第七百四十五条），不得写成“登记才产生所有权或合同才生效”。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿，尚未签署，尚未成争，核心给付是向第三人购买并出租，用户要出己方稿。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 已有可读待签文本要评改 → `融资租赁合同·审查`；
- 承租人即出卖人、先卖后租、转让价款付给承租人 → `售后回租合同·审查`；
- 无购买安排、自有设备出租、经营性租赁或干租 → `动产租赁合同·审查`；建筑设备台班／进退场干租 → `建筑设备租赁合同·审查`；
- 不动产或房产出租且无购货融资 → `不动产租赁合同·审查` 或 `房产租赁合同·审查`；
- 无物、虚构、低值高买、资金空转，核心是借贷 → `租赁物不存在低值高买租金严重偏离成本与合理利润出租人从未取得所有权→`；虚构物另告知第七百三十七条；
- 仅买卖设备、无出租付租 → 买卖原子或 本套导航的类型切开步骤；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、取回、索赔、诉讼、仲裁 → `或对应专项领域。` 或争议／金融专项。

以融资租赁为名包装资金空转、虚构租赁物或把售后回租／普通租赁整案改完：只出告知或负触发，不改写成可履行直租。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及买卖合同／清单／还租表版本；出卖人是否第三人；租赁物是否可特定；购货款付给谁；还租表与购买价款是否匹配；索赔权是否让与；维修保险税费由谁承担；登记安排；期满归属；不可接受事项；法域与拟签署日。缺立场或本类型条件未谈妥则不启动起草。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价款、期数、利率用 `【待填】`，不编造。

## 起草模式

本原子只承担本类型起草。待签评改转 `融资租赁合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 同时具备融物与融资：出租人根据承租人对出卖人、租赁物的选择购买并出租，承租人付租。
- 直租三方可指认出卖人；买卖合同与融资租赁合同的标的、价款、交付闭合；出租人向出卖人付购货款。
- 租赁物真实、可特定、可转让。
- 索赔与付租分轨：可约定由承租人向出卖人索赔、出租人协助；索赔原则上不影响付租；承租人依赖出租人技能或出租人干预选择的，可以请求减免相应租金。
- 逾期付租经催告后，出租人可请求支付全部租金，或解除并收回租赁物，二者择一。
- 取回后按未付租金及其他费用与收回物价值的差额清算。
- 未经登记不得对抗善意第三人；登记不是所有权产生或合同生效要件。

### 附件必附

- 买卖合同（与融资租赁合同标的、价款、交付闭合）。
- 租赁物特定化清单。
- 出租人向出卖人付款安排。

### 禁止出现

- 仅有资金空转、现场无物或虚构租赁物仍按融资租赁放行。
- 把“购货款”打给承租人任其挪用。
- 承租人与出卖人为同一人、先卖后租。
- 无购买安排、出租人将自有闲置设备按普通租赁出稿。
- 低值高买、租金严重偏离成本与合理利润、出租人从未取得所有权仍硬套本类型。
- 虚构租赁物改成可履行直租。
- 绝对“不得抗辩、绝对支付”且无租赁物不存在、合同无效、出租人根本违约等出口。
- 取回后既保留物又主张全额租金且不清算。
- “登记才产生所有权或合同才生效”。

### 0. 签署状态与成果分流

有完整待签文本要评改 → `融资租赁合同·审查`；本类型条件已谈妥要出己方稿 → 本任务起草并自审；已签履约 → 本套导航履约步骤；已成争 → 合同争议或金融专项。本类型条件已谈妥要出己方稿，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。售后回租、普通租赁、建筑设备干租、买卖本约、名租实贷负触发。

### 2. 融物真实性与价值匹配

清单、编号、现场、发票、付款闭环。无物或低值高买不得放行。

### 3. 三方、付款与两合同闭合

出卖人须第三人。购货款付出卖人。买卖无效则融物基础动摇。

### 4. 索赔、交付、维修与风险

索赔让与并通知出卖人；验收拟制交付；维修保险由承租人承担；毁损原则上不免除付租。不得套普通租赁第七百二十九条。

### 5. 租金、还租表与期满归属

租金按成本与合理利润还原（第七百四十六条）。还租表与大写金额一致。期满留购、返还或续租须明示。不得用第七百零五条二十年上限否定本约。

### 6. 登记、处分限制与担保

登记对抗；禁止承租人擅自转租、抵押、转让。保证范围覆盖被识别为融资租赁或借贷的主债权。

### 7. 加速到期、取回清算与格式条款

第七百五十二条择一；取回必须评估—抵债—多退少补。无核验引文则法律结论字段停止。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；条件未谈妥仍要出整稿；用户坚持倒签、保证有效、把虚构租赁物或空转改成可履行、把售后回租或普通租赁按本类型放行。
- `字段停止`：法域、动态规则、现场是否有物、评估值、中登网现状、牌照监管后果未核验。
- `目标停止`：主目标已变为评改待签文本（转 `融资租赁合同·审查`）、履约交底、争议文书，或已锁他类。
