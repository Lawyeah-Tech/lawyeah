# 定期租赁合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》租赁章及其解释、已失效《城市房屋租赁管理办法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **定期租赁合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文显示名为「定期租赁合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、不定期整案、房产/不动产/动产/建筑设备/临时建筑专论。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **约定期限**：正触发必须读出固定届满点——起止日期、明确月数/年数，或“自交付之日起满×年”。只写“长期”“永久”“租期三年”却无起算点，或期限栏空白：不得写成已锁定定期。能依第 510 条确定的，补写成可确定期间；不能确定的，负触发 `不定期租赁合同·审查`。
2. **超二十年超过部分无效**：届满日减去起算日超过二十年的，超过部分无效，二十年以内有效，不是整份合同无效。续订是新的定期，自续订之日起仍不得超过二十年，不是“两期累计不超过二十年”。修改句截断至满二十年之日，并写明超过部分无效。
3. **与不定期切开**：未约定期限、约定不明且不能依第 510 条确定 → `不定期租赁合同·审查`。六个月以上未采用书面形式且无法确定期限 → 视为不定期，转 `不定期租赁合同·审查`。届满继续使用且对方未异议 = 转为不定期，不是自动按原期限再续一期。约定“双方可随时解除”会消解定期性：必须改或转不定期原子。不得把本技能做成房产租赁专论，也不得抄房屋优先购买/网签/户口主路径。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签定期租赁正文，尚未签署，尚未成争，核心给付是出租人交付租赁物供使用收益、承租人支付租金，且期限可确定为固定届满点，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 未约定期限、约定不明且不能确定，或随时解除为主轴 → `不定期租赁合同·审查`；
- 用户主目标是房屋优先购买、共同居住、网签备案专论 → `房产租赁合同·审查`；
- 用户主目标是不动产交付返还、权属负担专论而非期限结构 → `不动产租赁合同·审查`；
- 用户主目标是动产进退场、损耗而非固定租期 → `动产租赁合同·审查`；
- 建筑设备进出场、安拆损坏为主轴 → `建筑设备租赁合同·审查`；
- 临时建筑批准使用期、拆除为主轴 → `临时建筑租赁合同·审查`；
- 租金覆盖本金并留购、虚构租赁物 → 转 本套导航的类型切开步骤 重新定性；
- 无文本、本类型条件已谈妥、要出己方稿 → `定期租赁合同·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

挂靠、违法分包、规避限购、倒签超长租期对抗查封：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（出租人侧或承租人侧择一）；相对方；全文及附件/交付确认书版本；起算点与届满点或可确定期间；是否书面、是否满六个月；是否超过二十年；标的剩余寿命是否短于租期；续订是协商还是单方自动续期；是否约定随时解除；是否出现倒签或覆盖已查封财产；不可接受事项；法域、租赁物所在地与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的租期、租金、占用费用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验第 705、707、734、730 条、格式条款、定金上限；`search_practiced` 只补审查反例；`search_template` 只借栏目结构。不虚构案件系统。

`search_law` 对上述法律结论为 required 级：不可用时不拒绝执行，只停止效力字段。返回已失效《合同法》租赁章或其解释、已失效《城市房屋租赁管理办法》时记为噪声，不得写入 `L#`。

实务中“续订后总期限仍不得超过二十年”“未采用书面形式即视为不定期”与现行第 705、707 条冲突，记噪声。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`框架.md` 中“到期自动续期”不得写成法定按原期限再续一期；“双方可随时解除”不得当成定期仍锁定。知识与硬闸冲突时，以 method 硬闸为准。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `定期租赁合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有定期租赁文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。期限不能确定、随时解除为主轴、房产/物的专论、融资租赁负触发。

### 2. 主体与约定期限权限

签约名、履行名、付款名、发票名分列。有权锁定该期限的人签字。共有/国资/集体未闭合：字段停止。

### 3. 标的存续须覆盖租期

土地/临建/检验/报废短于约定租期：截断至较早日。不得写成可永久占用。

### 4. 约定期限、二十年与书面

必须同时有起算点和届满点。超过二十年截断。六个月以上书面；未书面且无法确定期限则转不定期。

### 5. 续订、默示更新与随时解除

续订重新合意，自续订日起不超过二十年。届满继续使用未异议 = 不定期。随时解除必须改或转出。

### 6. 格式条款与强制规范

自动续期、随时解除、单方调价须提示说明。无核验引文则法律结论字段停止。

### 7. 解除、转租期限与剩余租期承继

定期解除须列举法定或约定事由。转租截止日期不超过主合同届满日。受让人承继剩余租期，不得重新起算二十年。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把超二十年改成全部有效、把永久租赁或查封财产改成可履行对抗结构。
- `字段停止`：法域、动态规则、地方备案对抗、标的剩余寿命未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类（不定期、房产专论、融资租赁）。
