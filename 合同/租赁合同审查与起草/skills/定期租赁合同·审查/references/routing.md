# 边界与路由

本技能只审查 **租赁合同 / 定期租赁合同** 的待签文本。中文展示名是「定期租赁合同·审查」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 未约定期限、约定不明且不能依第 510 条确定；六个月以上未书面且无法确定期限；随时解除为主轴 | `不定期租赁合同·审查` |
| 用户主目标是房屋优先购买、共同居住、网签备案专论 | `房产租赁合同·审查`。不得把定期租赁做成房产专论 |
| 用户主目标是不动产交付返还、权属负担专论而非期限结构 | `不动产租赁合同·审查` |
| 用户主目标是动产进退场、损耗、一天一结 | `动产租赁合同·审查` |
| 建筑设备进出场、安拆损坏 | `建筑设备租赁合同·审查` |
| 临时建筑批准使用期、拆除 | `临时建筑租赁合同·审查` |
| 租金覆盖本金并留购、虚构租赁物 | 本套导航的类型切开步骤 重新定性 |
| 无文本、本类型条件已谈妥、要出己方稿 | `定期租赁合同·起草` |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

定期租赁正文里夹带一小段房屋优先购买或临建批准期：专条交接对应原子；期限、二十年截断、续订、默示更新条款可继续审。用户坚持本技能把不定期、房产专论或融资租赁整案改完：`目标停止`。
