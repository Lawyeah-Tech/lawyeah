# 审查方法（锁定 租赁合同 / 定期租赁合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制房产租赁优先购买/网签/户口主路径、不动产权属专论、动产进退场专论、施工挂靠或不定期任意解除主路径。

定性校验：标题、核心给付与本类型一致才继续；期限不能确定、随时解除为主轴、房产/物的专论或融资租赁明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、整份超二十年合同当然无效或剩余租期必然对抗第三人。

`search_law` 返回已失效《合同法》租赁章及其解释、已失效《城市房屋租赁管理办法》、已失效《城市公有房屋管理规定》时记为噪声，不得写入 `L#`。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。引用失效合同法的财产租赁示范文本、房屋租赁示范文本只证明栏目，不得当作本类型已接受条款，也不得把房屋专论正文灌入本任务。

知识库纠正（不回写双文件）：

- `框架.md` “到期自动续期”：第 734 条是转为不定期，不是法定按原期限再续一期。修改句必须改成协商续订或排除默示更新。
- `框架.md` “双方可随时解除”：定期没有第 730 条那种任意解除。保留该句会消解定期性。
- 实务“续订后总期限仍不得超过二十年”：与第 705 条“自续订之日起”冲突，记噪声。
- 实务“未采用书面形式即视为不定期”：与第 707 条冲突。须同时满足无法确定期限。
- 未办理租赁登记备案：第 706 条明确不影响合同效力。不得写成未备案即无效。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 交付租赁物供使用收益，支付租金，且有可确定届满点 | 本类型 | 正触发 |
| 未约定期限、约定不明且不能依第 510 条确定；随时解除为主轴 | 不定期租赁 | 负触发 `不定期租赁合同·审查` |
| 六个月以上未书面，且无法确定期限 | 视为不定期 | 负触发 `不定期租赁合同·审查` |
| 用户主目标是优先购买、共同居住、网签备案 | 房产租赁专论 | 负触发 `房产租赁合同·审查` |
| 用户主目标是不动产交付返还、权属负担而非期限 | 不动产租赁 | 负触发 `不动产租赁合同·审查` |
| 用户主目标是动产进退场、损耗、一天一结 | 动产租赁 | 负触发 `动产租赁合同·审查` |
| 建筑设备进出场、安拆损坏 | 建筑设备租赁 | 负触发 `建筑设备租赁合同·审查` |
| 临时建筑批准期、拆除 | 临时建筑租赁 | 负触发 `临时建筑租赁合同·审查` |
| 租金覆盖本金并留购，或虚构租赁物 | 融资租赁或其他 | 负触发引擎重新定性 |

支持切开的规范（法律结论须运行时复核）：

- 第 703 条：租赁是交付使用收益、支付租金。
- 第 705 条：期限不得超过二十年；超过部分无效。
- 第 707 条：六个月以上应当书面；未书面且无法确定期限视为不定期。
- 第 730 条：期限不能确定视为不定期，可随时解除但须合理期限前通知。
- 第 734 条：届满继续使用且未异议，转为不定期。

本技能已锁定 **租赁合同 / 定期租赁合同**。只打开 `references/基本面.md` 与 `框架.md`。禁止读其他子目录，禁止为对照再开第二类。

### 1.3 约定期限与不定期切开（硬闸）

| 文本写法 | 本任务动作 | 修改句方向 |
| --- | --- | --- |
| 有起止公历日，或“自实际交付之日起满【待填】个月” | 正触发，留下本类型 | 起算绑定交付；写明是否含届满当日 |
| 只写“租期三年”“长期”“永久”“直至拆迁”且不能依第 510 条确定届满点 | 不得写成已锁定定期；能补写成可确定期间则必须改；不能确定则负触发 `不定期租赁合同·审查` | 「租期自实际交付之日起满【待填】个月，届满日为第【待填】个月对应日的前一日。」 |
| “双方可随时解除”“任何一方提前 30 日通知即可解除”作为退出主轴 | 必须改删除，或转 `不定期租赁合同·审查` | 见节点 5.3 |
| 标题是定期，正文期限栏空白 | 负触发不定期，或红线补可确定期间 | 不补造具体日历日充作已约定 |

最强反方：相对方主张“长期合作”或“直至拆迁”已构成定期。现有依据不支持把无届满点的表述单独写成第 704 条已约定租赁期限。

### 1.4 倒签 / 查封对抗停笔（硬闸）

加载后或定性中出现：倒签起租日以覆盖查封、抵押或执行；无实际占有却把租期写成二十年对抗买受人或执行债权人；伪造交付确认。

动作：

1. 交付告知：虚假意思表示可能无效（第 146 条）；出租前已查封的，现有依据不支持以定期租赁对抗执行债权人（房屋租赁解释第 14 条只作为房屋场景的审查反例，不展开房产专论）。
2. 不写可履行的倒签路径、假交付或“补收据即可对抗”。
3. 风险表只保留识别依据和删除/转出口径。
4. 用户坚持“改到能对抗”：整体停止。

挂靠、违法分包、规避限购：只告知，不改写成可履行结构。

## 节点 2　主体与约定期限权限

### 2.1 主体表

建表：签约名、履行名、付款名、发票名、授权签字人。名称不一致不自动合并。定期把租赁物长期锁定，对共有人、抵押权人、国资监管、集体决议的影响大于不定期。

口头“我们老板同意了”不得写成已授权。代理人授权书未注明可签署的最长期限：该权限字段停止，修改句要求授权范围覆盖拟签租期。

### 2.2 有权锁定该期限

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 共有、配偶、国资、集体决议未附 | 字段停止；修改句要求作为附件且未获同意不生效 | 可以盖章 |
| 法定代表人签出 10 年、20 年，相对人无审查痕迹 | 标红旗；相对人须证明合理审查 | 当然约束该法人 |
| 房屋承租人死亡后的共同居住人/共同经营人 | 只点名：可按原合同继续承租至期限届满（第 732 条），不得按不定期随时赶走 | 展开共同居住专论 |

共同居住、优先购买的展开审查交 `房产租赁合同·审查`。

## 节点 3　标的存续须覆盖租期

1. 租赁物是否确定到可履行：名称、位置或规格、用途。只有“等”“有关场地”则标缺口。
2. 标的剩余寿命与租期匹配：土地出让到期日、临时建筑批准使用期、船舶检验有效期、特种设备报废日若短于约定租期，超过部分构成履行不能。修改句取较早届满日，或约定替代物。不得写成“还没到届满日即可继续占有”。
3. 权利负担：抵押、查封、居住权、在先租赁。材料未提及不得写成“无权利负担”，只能写 `依据不足`。用定期覆盖已查封财产：走节点 1.4。
4. 规划调整、征收、租赁物灭失使定期提前终止，不能因未到届满日主张继续占有。
5. 本节点不展开不动产测绘、动产损耗清单或临建报批手册。

修改句：

「租期届满日为下列日期中的最早者：（一）自实际交付之日起满【待填】个月的对应日的前一日；（二）租赁物占用范围内建设用地使用权到期日；（三）临时建筑/检验/强制报废批准使用期届满日。任何一项先届满的，双方权利义务于该日终止，甲方应于【待填】日内返还租赁物。」

## 节点 4　约定期限、二十年与书面（硬闸）

### 4.1 约定期限必须可确定

必须同时有起算点和届满点，或起算点+明确期间。推荐写法回链框架：租期自实际交付之日起满【待填】个月。禁止只写“租期三年”却不写从何时起算。

签署日期与起租日期分开。迟延交付时租期是否顺延必须写明；若不顺延，承租人应有租金减免或解除权。

| 文本写法 | 动作 |
| --- | --- |
| 有交付日起满×个月，或起止公历日 | 可接受；优化是否含当日、节假日只影响返还办理 |
| “租期三年”无起算 | 必须改，数字用 `【待填】`，不补造日历日 |
| 期限栏空白、“长期”“永久” | 红线；不能确定则转 `不定期租赁合同·审查` |
| 起算绑签约日，交付可能晚于签约 | 必须改绑交付日，或写明迟延交付的租金减免/租期顺延 |

修改句：

「租期自甲方将租赁物实际交付乙方之日（以《交付确认书》记载日期为准）起满【待填】个月。届满日为第【待填】个月对应日的前一日。签署日不等于起租日。因甲方原因迟延交付的，租期相应顺延，且乙方免付迟延期间租金。」

### 4.2 超二十年超过部分无效（硬闸）

条文：租赁期限不得超过二十年。超过二十年的，超过部分无效。续订的租赁期限自续订之日起不得超过二十年。

| 文本写法 | 动作 |
| --- | --- |
| 届满减起算超过 20 年 | 必须改截断，并写明超过部分无效、满二十年之日终止 |
| “永久租赁”“直到土地证到期”“直至拆迁”以逃避 20 年 | 超出部分仍无效；“直到拆迁”若被解释为不定期，转 `不定期租赁合同·审查` |
| 用户要整份无效或全部有效 | 现有依据不支持。第 156 条：部分无效不影响其他部分 |
| “两期累计不得超过 20 年” | 噪声。每期自续订日起算 |

修改句：

「租赁期限不得超过二十年。双方确认：自起租日起满二十年之日，本合同权利义务终止；超过二十年的部分无效，任何一方不得请求该超过部分的租金或占用。续订须另行签订书面合同，续订期限自续订之日起不得超过二十年。」

最强反方：相对方主张意思自治或“拆迁前必须有效”。现有依据不支持把超过二十年的部分写成有效定期。

### 4.3 书面六个月（硬闸）

六个月以上应当采用书面形式。未采用书面形式，无法确定租赁期限的，视为不定期。

| 已有事实 | 动作 | 不得写成 |
| --- | --- | --- |
| 仅有口头或微信“就租一年”，起止无法确定 | 视为不定期，转 `不定期租赁合同·审查` | 到期自然终止已锁定 |
| 微信已写明起止日，无合同书 | 修改句要求补书面；期限字段可部分形成；对抗第三人字段停止 | 未书面即当然不定期；已可对抗买受人 |
| 租期短于六个月且无书面 | 不因此单独打成不定期；仍建议书面 | 六个月以下口头当然无效 |

## 节点 5　续订、默示更新、租金捆绑与随时解除

### 5.1 续订

续订是新的定期租赁，须重新合意。不得用“到期前未书面反对即再续×年”单独约束一方，除非双方确有形成权安排且不规避二十年限制。优先续租权要约定视为拒绝的沉默期。

修改句：

「租期届满前【待填】日，任何一方可以书面提出续订。续订须另行签订书面合同，租金按【待填】方式确定。未在该期限内达成书面续订的，本合同于届满日终止。续订期限自续订之日起不得超过二十年。一方沉默不构成再续一个相同期限。」

### 5.2 默示更新（硬闸）

届满后承租人继续使用、出租人没有提出异议的，原合同继续有效，但是租赁期限为不定期。不是自动按原期限再续一期。

排除默示更新须同时具备：届满必须返还；继续占用视为违约并计占用费；出租人及时提出书面异议。一旦收租且不提异议，仍可能被认定为不定期。

修改句：

「租期届满，乙方应于届满当日返还租赁物。乙方逾期占用的，甲方有权按原日租金的【待填】倍收取占用费，该收款不构成续租或同意延期。甲方应于届满当日同步发出书面异议；未发出书面异议而继续按原租金科目收款的，不得再主张对方构成到期不续约违约。」

最强反方：相对方主张继续付租即再续一期。现有依据不支持该拟制。第 734 条第 1 款的推定可被相反证据推翻，但不在本任务认定已经推翻。

### 5.3 随时解除消解定期（硬闸）

定期没有不定期那种任意解除权。要提前退出，只能法定解除（租赁物毁损不能实现目的、擅自转租、欠租经催告等）或明确列举的约定解除。

| 文本写法 | 动作 |
| --- | --- |
| “任何一方提前 30 日通知即可解除” | 必须改删除。用户坚持则转 `不定期租赁合同·审查`，不得再称已锁定定期 |
| 与装修投入、租金优惠并存的随时解除 | 红线。与装修摊销冲突 |
| 仅出租人或仅承租人在特定节点（如续期年）解除 | 可谈，须加黑提示，并处理摊销余额 |

### 5.4 租金与期限捆绑

支付周期不得长于剩余租期。最后一期按实际天数折算。免租期计入或不计入必须二选一。提前解除时的摊销余额、优惠返还要有公式，数字用 `【待填】`。禁止既收全部剩余租金又收回房屋使用（应择一或扣除未发生成本）。

定金必须使用“定金”二字才讨论罚则。约定或推算超过主合同标的额百分之二十：超过部分不产生定金效力。无核验引文不得把 20% 写成现行法结论。押金、保证金无定金性质的，不得写成定金。

## 节点 6　格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 格式条款

为重复使用而预先拟定、订立时未与对方协商。从事经营活动的一方不得仅以“这次没用过第二次”否认。依据示范文本制作，不当然排除格式条款。

审查：自动续期、随时解除、单方调价、免责、管辖/仲裁等异常条款是否有足以引起注意的标识，以及是否按要求说明（第 496 条；解释第 10 条）。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在附件 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

提供方对其已尽提示或说明承担举证责任。

### 6.2 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的、是否仅行政管理、是否只规制履行行为（第 153 条；解释第 16 条）。禁止用已失效“效力性/管理性”口诀代替解释第 16 条。

第 705 条超过部分无效是法律明文的部分无效，不是整份无效。第 706 条未备案不影响效力。倒签、规避限购、用定期覆盖查封：不改写成有效履行。

## 节点 7　解除、转租期限、剩余租期与争议

1. 定期解除必须列举：欠租催告期满（第 722 条）、改变用途或未按约定使用（第 711 条）、未经同意转租（第 716 条）、租赁物灭失、征收、权利瑕疵不能实现目的（第 724 条）。只有“依法承担违约责任”视为必须改。
2. 构成违约不等于当然解除。法定解除路径只点名催告或目的不能实现，不在本任务作出已解除结论。
3. 转租截止日期不超过主合同届满日。主合同是定期、转租写成“自动续期至主合同永远续展”的，超出部分对出租人无效。
4. 买卖不破租赁：受让人承继**剩余**租期（第 725 条），合同不得写“转让后租期重新起算二十年”。需要对抗买受人、抵押权人的，审查真实定期合意、书面、已交付占有、租金是否明显不合理；不能只靠把租期写成二十年。对抗效力字段在交付证据不足时停止。
5. 房屋优先购买、优先承租只点名第 726、734 条第 2 款，不展开专论。
6. 违约金不是必得金额；不在本任务做第 585 条精算。修改句避免“不得调整”或“按剩余租期全额租金必得”。
7. 争议解决：出现仲裁条款，不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核，修改句改成单一仲裁机构或单一法院连结点。专属管辖可能：只标红旗，不选定唯一法院充作法律意见。
8. 通知送达：续租意向、到期撤离、默示更新异议必须有送达条款。微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。
