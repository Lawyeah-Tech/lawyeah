# 边界与路由

本技能只起草 **租赁合同 / 产权式商铺租赁合同** 的待签统一租赁、委托经营或商业管理文本。中文展示名是「产权式商铺租赁合同·起草」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 普通住房或独立四至商铺租赁，承租人自己经营 | `房产租赁合同·审查`。不得删掉自营条款后继续当产权式商铺审 |
| 主给付是酒店客房买卖过户并强制委托经营、买受人不得自住 | `益，不是客房所有权转移换价款。用户交来买卖+酒店委托经营客房过户不得自住→`。不得用租赁二十年上限回写酒店经营期限，也不得用过户与经营权同步的买卖主路径改本约 |
| 可独立居住的商品房预售或现售，无强制统一经营 | `可独立居住的商品房预售或现售，无强制统一经营→` |
| 融物+融资，出租人取得所有权再出租 | `融资租赁合同·审查` |
| 卖后再租回、本息表 | `售后回租合同·审查` |
| 主给付为居间、带看、独家委托 | `主给付是居间报酬或带看成交→` |
| 已有可读待签文本要评改 | `产权式商铺租赁合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争，或保底停付、运营方撤场要争议策略 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

封面写投资协议或委托经营、正文是业主让渡占有经营权、运营方支付租金或分配收益：按核心给付留在本技能，标题必须补租赁要素，不转普通投资或普通委托。

统一经营正文里夹带一小段中介佣金或购房过户手续：佣金专条可交接 `主给付是居间报酬或带看成交→`；过户手续只核对业主与购房人是否一致，不把本约改成买卖。用户坚持本技能把普通租赁或酒店买卖整案改完：`目标停止`。

专业版未收录的其他 P1 场景不会安装本原子。若用户拿他类 P1 文本来找本原子：输出 `unavailable` 或按上表负触发，不得用邻类硬套。
