# 农村土地租赁合同·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **农村土地租赁合同** 己方稿，出稿后用本类型硬闸自审。交付草稿、未决项、自审风险表和自审后修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文显示名为「农村土地租赁合同·起草」。

`depends-on` 为空。不要求先跑导航。

不交付：他类起草、待签文本签前审查、履约交底、争议文书、有效性保证、保证登记或办证一定办成、保证承租人取得可对抗一切第三人的用益物权。

## 本类型硬闸

每闸必须出修改句或明确停笔口径。禁止只打红黄绿。

1. **标的是哪一层权利**。本约只成立普通债权租赁：出租人交付农村土地供使用、承租人支付租金。承租人不取得集体土地所有权，不设立土地承包经营权，不流转土地经营权。权利专条必须写：仅取得债权性使用权；不得请求登记为土地承包经营权人或土地经营权人；不得以本租赁对抗依法登记的用益物权人。
2. **集体决议走现行法，不走 2018 年第二十四条**。集体作为出租人时，先民主议定后签约。2026-01-01 起，村民委员会组织法（2025 修正）第二十八条不再单列“以租赁方式处分村集体财产”；村委会依法代行农村集体经济组织职能的，讨论集体财产和成员权益事项参照适用农村集体经济组织法。已设立农村集体经济组织的，走该法第二十六至二十八条、第六十四条。村委会或合作社公章不等于决议。决议的地块、期限、价格须与合同一致；租金进集体账户。缺决议的集体合同不建议签署。
3. **与承包／经营权切开**。文本出现承包权保留、经营权流转、剩余承包期对接、五年以上经营权登记对抗 → `土地经营权流转合同（出租类）·审查`。强调成员把承包经营权作为用益物权出租、办承包经营权证 → `农村土地承包经营权租赁合同·审查`。禁止打开或复制上述两份 method。不得删掉流转或承包条款后硬套本技能。
4. **租期最长二十年**。适用民法典第七百零五条，超过部分无效。不得以“到承包期满”“自动续期二十年”规避。续租须新决议、新合同，租金重定；同等条件优先协商权可以写，不得写成自动续一个用益物权周期。
5. **用途锁死，且不得按国有出让或宅基地改完**。不得擅自将农用地用于非农建设。耕地、永久基本农田上的租赁只能农业使用。农地建房、建厂、挖砂取土、以租代征不得改成可履行。宅基地长租并约定可继承、可转卖：拒绝。集体经营性建设用地入市不得用本普通租赁绕过法定出让／出租方案，也不得把国有建设用地出让规则套到集体农地普通租赁。
6. **无用益物权登记**。删除“五年登记对抗”“协助过户、办证、成为承包户”。需要对抗第三人的，应改走经营权流转并具备承包关系前提，而不是在本类型里补登记句。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿，尚未签署，尚未成争，核心给付是农村土地上的债权性占用与租金，当事人不创设用益物权，用户要出己方稿。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 已有可读待签文本要评改 → `农村土地租赁合同·审查`；
- 承包权保留、经营权流转、五年登记、剩余承包期、经营权证、向发包方备案的流转合同 → `土地经营权流转合同（出租类）·审查`；
- 把家庭承包经营权当作用益物权出租、办承包经营权证、成员内部承包经营权租赁主轴 → `农村土地承包经营权租赁合同·审查`；
- 已竣工验收的城镇或永久房屋、产权证、优先购买、户口／居住证／入学主轴 → `房产租赁合同·审查`；
- 无任何建筑的城镇建设用地或国有／出让光地占用 → `不动产租赁合同·审查`；
- 设备、车辆等动产特定化租赁 → `动产租赁合同·审查`；
- 争点只是定期或不定期形态，标的不是农村土地债权租赁 → `定期租赁合同·审查`／`不定期租赁合同·审查`；
- 工地塔吊、钢管、脚手架或附带司机安拆 → `建筑设备租赁合同·审查`；
- 融资租赁、售后回租、产权式商铺、定向建设后回租 → `融资租赁合同·审查`／`售后回租合同·审查`／`产权式商铺租赁合同·审查`／`定向建设租赁合同·审查`；
- 临时售楼处、工棚、展棚等临时建筑 → `临时建筑租赁合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问交租、腾地、续期 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁或村民代表已起诉否定合同 → `或对应专项领域。` 或农地／征收专项。

以租赁之名转让集体土地、以租代征、宅基地变相买卖、明知无决议仍要对外长租并写“盖章即有效”：只出告知，不改写成可履行路径。挂靠、违法分包、规避限购不是本类型主路径；文本里偶然出现时只告知并转工程或对应原子，不据此定性本约。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及附件／决议／宗地图／证照版本；出租人是集体还是农户；地块是否已发包、是否已有承包证或经营权登记；承租人是否本集体成员；拟租的是哪一层权利；租期起止是否超过二十年；地类与约定用途；决议与公示；租金账户；不可接受事项；法域与拟签署日。缺立场或本类型条件未谈妥则不启动起草。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 起草模式

本原子只承担本类型起草。待签评改转 `农村土地租赁合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 权利专条：本约只成立普通债权租赁；承租人仅取得债权性使用权，不得请求登记为土地承包经营权人或土地经营权人，不得以本租赁对抗依法登记的用益物权人。
- 集体作为出租人时，先民主议定后签约；决议的地块、期限、价格与合同一致；租金进集体账户。
- 租期最长二十年；超过部分无效；续租须新决议、新合同，租金重定。
- 六个月以上应当书面。
- 用途锁死为农业使用。

### 附件必附

- 集体出租时的民主议定决议。
- 地块四至／宗地图。
- 农户出租时的承包方及户内同意，并明示不流转经营权、不设立承包经营权。

### 禁止出现

- 设立土地承包经营权或流转土地经营权。
- 村委会或合作社公章代替决议；2018 年村民委员会组织法第二十四条旧口径。
- “到承包期满”“自动续期二十年”。
- “五年登记对抗”“协助过户、办证、成为承包户”。
- 擅自将农用地用于非农建设；农地建房、建厂、挖砂取土、以租代征。
- 宅基地长租并约定可继承、可转卖。
- 用本普通租赁绕过集体经营性建设用地入市法定出让／出租方案。
- 承包权保留、经营权流转、五年以上登记对抗条款硬套本类型。

### 0. 签署状态与成果分流

有完整待签文本要评改 → `农村土地租赁合同·审查`；本类型条件已谈妥要出己方稿 → 本任务起草并自审；已签履约 → 本套导航履约步骤；已成争 → 合同争议或农地专项。本类型条件已谈妥要出己方稿，才进入本任务。

### 1. 权利层次与类型锁死

先问租的是哪一层权利。所有权、承包经营权、经营权用益物权、普通债权租赁必须切开。承包／经营权负触发，不灌两套知识。集体地农地不得按国有出让或宅基地改完。

### 2. 主体与集体决议

集体出租：决议作附件，章与权利主体一致；现行法源见硬闸 2。农户出租：须是承包方，户内同意，并明示不流转经营权、不设立承包经营权。

### 3. 地块、地类与负担

四至、面积、地类与国土空间／土地调查一致。已发包、已有经营权登记则不能再做本类型。宅基地、公益用地、权属争议地不得当普通租赁硬做。

### 4. 二十年、书面、不登记

起止日 ≤ 二十年；超过六个月应当书面；删除五年登记对抗。

### 5. 用途、租金账户、交付返还

农业用途写细；租金进集体账户；无合法用地手续的地上物到期拆除，不得套城镇房屋装修补偿。

### 6. 格式条款与强制规范

无核验引文则法律结论字段停止。违法用途、以租代征不得改成可履行。

### 7. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；条件未谈妥仍要出整稿；用户坚持倒签、补假决议、保证有效、把承包／经营权改成普通租赁外壳仍按本类型放行、把以租代征或宅基地变相买卖改成可履行。
- `字段停止`：法域、动态规则、决议真伪、地块是否已发包或已登记、地类未核验。
- `目标停止`：主目标已变为评改待签文本（转 `农村土地租赁合同·审查`）、履约交底、争议文书，或已锁他类。
