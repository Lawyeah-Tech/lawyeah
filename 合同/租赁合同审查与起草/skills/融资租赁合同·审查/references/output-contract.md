# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的价款、期数、利率；把已失效《合同法》、2014 年融资租赁司法解释旧文本写入结论；保证登记一定办成或一定能对抗善意第三人；把售后回租、普通租赁、买卖本约或名租实贷文本当成已完成的本类型审查；写“未登记则本合同未生效／出租人未取得所有权”；写“取回后仍可收取全部未到期租金且不必扣减设备价值”；用第七百零五条二十年上限或第七百二十九条普通租赁风险负担覆盖本约。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查融资租赁合同（租赁合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、2014 年融资租赁司法解释旧文本时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `租赁合同`，子级 `融资租赁合同`。定性理由、易混切开结果（售后回租 / 普通动产租赁 / 建筑设备干租 / 名租实贷 / 买卖）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、三方、付款流向与文本版本

主体表：出租人、承租人、出卖人；签约名、履行名、付款名、发票名、授权签字人。付款表：购货款付给谁、还租付给谁。版本表：正文、买卖合同、租赁物清单、还租表、验收单、担保／回购、保险、聊天确认；冲突并列。

## 5. 融物、索赔分轨、租金归属与登记

租赁物是否可特定、现场是否有物、价值是否匹配；索赔权是否让与；维修保险是否由承租人承担；还租表是否还原成本与合理利润；期满归属是否明示；登记是否被误写成生效要件；取回是否清算。缺口标 `G#`。不输出普通租赁维修／20 年上限口径，不输出买卖本约交付主路径。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹。虚构租赁物、空转、取回不清算不得写成可放行。强制规范只按第七百三十七条和第一百五十三条区分是否导致民事行为无效，不用失效口诀。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把普通租赁维修或 20 年上限直接写成“融资租赁类型”而不问是否有购买安排。

## 9. 谈判与签署提醒

谈判顺序：先红线（虚构物或空转、实为回租或普通租赁、取回不清算、无清单仍放款），再必须改（三方与两合同闭合、购货款付出卖人、索赔让与、还租表、登记配合、期满归属），最后可优化。签署提醒：法定代表人、大额融资内部决议、担保人同步签署、买卖合同、清单、还租表、验收单、保险、登记回执安排。不指导倒签或把未登记写成合同无效。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本任务只出审查意见和修改句，不出整份起草终稿。出稿转 `融资租赁合同·起草`。不是履约交底、争议文书或效力保证，也不是售后回租、普通租赁、买卖或借款安排。
