# 边界与路由

本技能只审查 **租赁合同 / 融资租赁合同** 的待签、直租文本。中文展示名是「融资租赁合同·审查」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或复制 `动产租赁合同·审查`、买卖原子或 `售后回租合同·审查` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符且无法在本类型内定性 | 本套导航的类型切开步骤 |
| 承租人与出卖人为同一人；先将自有物卖给出租人再租回；购货款／转让价款打给承租人 | `售后回租合同·审查` |
| 无购买安排；出租人将自有闲置设备出租；维修、风险按普通租赁由出租人承担；标题是经营性租赁／干租且无出卖人 | `动产租赁合同·审查` |
| 建筑设备现场干租、台班、进退场，无购货融资结构 | `建筑设备租赁合同·审查` |
| 不动产或房产出租，无购货融资 | `不动产租赁合同·审查` 或 `房产租赁合同·审查` |
| 租赁物不存在、虚构、低值高买、租金严重偏离成本与合理利润、出租人从未取得所有权，核心是资金空转 | `租赁物不存在低值高买租金严重偏离成本与合理利润出租人从未取得所有权→`；虚构物另告知第七百三十七条，不改成可履行直租 |
| 仅买卖设备、无出租付租结构 | 对应买卖原子或 本套导航的类型切开步骤；本任务不代审买卖本约 |
| 金融机构或民间借款本约，无租赁物载体 | `金融机构或民间借款本约，无租赁物载体` 或 `或` |
| 无文本、本类型条件已谈妥、要出己方稿 | `融资租赁合同·起草` |
| 已签未争、只问放款日、验收日、登记窗口 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或对应专项领域。` 或对应专项领域 |
| 已催告解除、取回诉讼、执行或刑民交叉 | 争议或金融专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

直租正文里夹带一小段售后回租或普通转租：专章交接对应原子；直租条款可继续审。用户坚持本技能把售后回租、普通租赁、买卖本约或借款整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿本 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
