# 审查方法（锁定 租赁合同 / 土地经营权流转合同（出租类））

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止打开或复制 `农村土地承包经营权租赁合同·审查` 的承包经营权租赁 method，禁止复制普通农地租赁“最长二十年、不产生用益物权、不得登记”主路径。

定性校验：标题、核心给付与本类型一致才继续；承包权租赁、普通农地租赁、入股、互换或转让承包权明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、保证备案或登记一定办成或唯一必得金额。

`search_law` 返回 2002／2009 年《农村土地承包法》同号旧义、2005 年《农村土地承包经营权流转管理办法》、已失效《合同法》及其解释、已失效《物权法》时记为噪声，不得写入 `L#`。2002 年旧第三十七条把转包、出租、互换、转让混成一类“土地承包经营权流转”；2018 年后出租（转包）、入股走土地经营权流转并向发包方备案，互换、转让土地承包经营权另有规则。

示范文本只参考结构。2021 年农业农村部、市场监管总局《农村土地经营权出租合同》示范文本可借栏目。2016 年及更早“土地承包经营权流转合同”示范文本常混用旧口径，不得当成本约生效规则。不得把范本当成地块、期限、用途已被法律拟制列全。

知识库纠正（不回写双文件）：

- `基本面.md` “流转未向发包方备案，原则上不影响合同效力”：采用。依据已核验的承包纠纷司法解释（2020 修正）第十四条。仍须把未备案列为缺口。
- `基本面.md` “流转期限 5 年以上的土地经营权可以登记，登记后对抗善意第三人”：采用。依据已核验的民法典第三百四十一条。未登记不等于合同无效。
- `基本面.md` “流转期限不得超过承包期的剩余期限”：作为本任务硬闸采用。2018 年承包法对应条号本次检索被 2002 年同号旧义抢占，**不把该条号写成已核验 `L#`**；修改句仍截到剩余承包期。超期对发包方的约束力，林地可参照森林资源解释第十二条；耕地不得把该解释写成已核验普遍规则。
- `框架.md` “不要抄二十年作为本类型的主标题规则（可仅作风险提示：若未被识别为经营权则可能回退）”：采用。第七百零五条只作回退提示，不是本约主尺度。
- 实务材料“五年以上应当登记”：登记是权利人可申请事项，不是合同成立要件。写成“不登记合同无效”的，必须改。
- 2005 年旧流转办法已废止（管理办法第三十六条）。不得引用农业部令第 47 号或已失效的《农村土地承包经营权证管理办法》作为现行唯一颁证规则。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

支持切开的规范（法律结论须运行时复核）：

- 农村土地承包法（2018 修正）第九条（修改决定增加）：承包方可以自己经营，也可以保留土地承包权，流转其承包地的土地经营权，由他人经营。
- 民法典第三百三十九条：土地承包经营权人可以自主决定依法采取出租、入股或者其他方式向他人流转土地经营权。
- 民法典第三百四十条：土地经营权人有权在合同约定的期限内占有农村土地，自主开展农业生产经营并取得收益。
- 民法典第三百四十一条：流转期限为五年以上的土地经营权，自流转合同生效时设立；可以向登记机构申请登记；未经登记，不得对抗善意第三人。
- 民法典第三百三十四条、第三百三十五条：**负向切开**。互换、转让的是土地承包经营权本身，登记对抗规则也针对互换、转让，不是本约主路径。
- 管理办法第十四条：出租（转包）是承包方将部分或者全部土地经营权租赁给他人从事农业生产经营。入股是作价出资成为股东或成员。
- 管理办法第十五条、第三十四条：流转后承包方与发包方的承包关系不变。
- 管理办法第二条、第三条：集体所有、农户家庭承包经营稳定；不得改变所有权性质和农业用途。
- 第七百零五条：普通租赁不得超过二十年。本类型主尺度是剩余承包期；仅当文本自我否定经营权、被识别为普通债权租赁时，作为回退风险提示。

## 节点 2　三权分置、主体与工商审核

### 2.1 三权声明（硬闸）

每份合同首页或鉴于必须写清：土地所有权归农民集体，承包权留在流出农户，本次流转的是土地经营权。

| 文本写法 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| “乙方取得承包经营权／承包权转让给公司” | 红线：改为取得约定地块上、约定期限内的土地经营权；承包权仍归甲方农户 | 受让人已成为承包经营权人 |
| “本合同系买卖农村土地” | 红线删除。集体土地所有权不得买卖 | 买卖合同可以改到能过户 |
| 发包方列在出租人栏并收取流转价款 | 必须改：发包方只在备案栏；价款归承包方（机动地除外） | 村委会当然是出租人 |
| 未写三权，只写“出租土地” | 必须改：补三权声明，并核是否实为 `农村土地租赁合同·审查` | 未写就是普通租赁 |

最强反方：流入方主张“不写承包经营权就贷不到款、登不了记”。回应：登记对象是土地经营权，不是承包权。融资担保另走承包方书面同意和备案。

### 2.2 主体表

建表：签约名、履行名、付款名、发票名、授权签字人。名称不一致不自动合并。

- **流出方**：家庭承包的农户。签字人应为承包方代表并获户内同意。口头“家里都同意了”不得写成已授权。
- **流入方**：农户、合作社、农业企业、家庭农场。须有农业经营能力或资质（管理办法第九条）。同等条件下本集体经济组织成员享有优先权（管理办法第九条；司法解释第十一条）。
- **发包方**：备案和监督管理，不是流转价款权利人（除非集体机动地）。
- **四荒等其他方式承包**：流出方是该承包经营权人；出租类仍须保留其承包关系（管理办法第三十五条参照）。不得按家庭承包成员身份规则改写成“非成员不得流入”。

### 2.3 户内同意与委托

家庭承包户内成员未列、未签、无书面同意：该签署能力字段停止。委托发包方、中介或他人代为流转的，须有承包方出具的委托书，载明事项、权限和期限（管理办法第八条）。没有书面委托，任何组织和个人无权决定流转。

### 2.4 工商企业等社会资本（硬闸）

管理办法第二十九条：县级以上地方人民政府对工商企业等社会资本流转土地经营权依法建立分级资格审查和项目审核。未按规定提交申请或审查审核未通过的，不得开展土地经营权流转活动。涉及未承包到户集体土地的，还须依法定程序经成员会议或成员代表三分之二同意。

| 文本或事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 公司整村流转、超面积流转，无审核意见 | 红线：审核通过作为交地和大额付款条件；未过审不得交地 | 签字就能种 |
| 把审核未通过写成“合同无效，农户已收定金不退” | 必须改：审核是开展流转活动的前置；已收款项按未开展流转清理，不写成农户单方违约 | 未过审＝农户吞定金 |
| 审核通过作为农户签字部分的任意无效开关 | 必须改：已签字条款不因“村委会随时可宣布未审核”而任意失效；未过审则不交地、不付大额 | 审核是随意废约按钮 |

## 节点 3　地块特定化与农地农用

### 3.1 地块必须特定

对照管理办法第十九条逐项：地块名称、四至、面积、质量等级、土地类型、地块代码；承包合同编号或承包证号；是否永久基本农田。禁止只写“某村东边地一块”“相关耕地”。

权属争议地、承包方无权处分的地、已整户消灭承包权的地、须改用途才能使用的建设用地需求：不得作为本约标的。材料未提及在先经营权或担保的，不得写成“无权利负担”，只能写 `依据不足`。

一地两份流转：查经营权登记和现场耕种人。交地前未清场的，必须改或红线。

### 3.2 用途锁定（硬闸）

管理办法第三条、第十一条：不得改变农业用途；禁止闲置、荒芜耕地；禁止占用耕地建窑、建坟或擅自建房、挖砂、采石、采矿、取土；禁止占用永久基本农田发展林果业和挖塘养鱼。优先用于粮食生产。

| 文本写法 | 动作 |
| --- | --- |
| “承租人可自主改变用途，包括观光园、停车场、厂房” | 红线：删除。改为约定农业用途／粮食作物；破坏耕作层即解除并恢复 |
| 永久基本农田上写苗木、挖塘 | 红线：违反第十一条 |
| 设施农用地未另办手续 | 必须改：设施农用地另办；未获批不得硬化 |
| 无用途条款 | 必须改：锁粮食或约定作物，并写非农化、撂荒解除 |

承包地上的合法农业设施不是城镇房屋，不适用房屋优先购买。出现优先购买句：删除。

### 3.3 附着投资

流入方建设的农业生产设施、土壤改良，到期归属和补偿必须预先安排。否则标必须改，防止“投入绑架续期”。管理办法第二十条、司法解释第十六条第二款：对提高土地生产能力的投入，对方请求相应补偿的，应予支持。补偿数字用 `【待填】`，不编造。

## 节点 4　流转期限、剩余承包期与五年登记

### 4.1 期限不得超过剩余承包期（硬闸）

本类型主尺度是剩余承包期，不是二十年。

1. 列出承包合同或承包证记载的承包起止日、拟流转起止日、剩余天数。缺任一数字：字段停止，修改句用 `【待填】`。
2. 流转期限长于剩余承包期：必须改，截到剩余承包期届满日。禁止永久流转、自动顺延至“政策允许的最长期限”。
3. 二轮延包未落地：约定期限不得想当然越过证载到期日。可写“若依法延包，双方可在剩余延包期限内协商续期，续期仍须书面且不超过新的剩余期限”。
4. 再流转期限不得超过原流转剩余期限。
5. 第七百零五条不得作为本约主标题规则。仅当登记不能完成、文本自我否定经营权、存在被认定为普通债权租赁的风险时，提示可能回退到二十年；提示不等于把本约改成 `农村土地租赁合同·审查`。

最强反方：相对方主张“二轮要延包，先写三十年省得再签”。回应：延包未落地前，超证载到期日的部分不得写成对发包方当然有约束力；林地超期规则见森林资源解释第十二条，耕地不得直接写成已核验同一效果。

### 4.2 五年以上登记（硬闸）

民法典第三百四十一条：流转期限为五年以上的土地经营权，自流转合同生效时设立；当事人可以向登记机构申请土地经营权登记；未经登记，不得对抗善意第三人。

| 文本写法 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 期限 ≥ 五年，无登记条款 | 必须改：流入方申请，承包方协助；登记作为付款或权利保全节点 | 五年以上自动对抗第三人 |
| “不登记本合同无效／未生效” | 必须改：删除。登记解决对抗，不解决成立 | 未登记未生效 |
| 期限不足五年却写“本经营权已经设立并可对抗第三人” | 必须改：五年以下不走第三百四十一条设立／登记对抗结构 | 短期出租也有登记对抗 |
| 声明“本租赁无任何物权效力、不得登记”且期限 ≥ 五年 | 按普通租赁切开，负触发 `农村土地租赁合同·审查` | 删掉无物权句后假装已是经营权 |

工商资本大规模流转更应登记。付款前办登记可作为流入方权利保全手段。

## 节点 5　书面、备案与生效切开

### 5.1 书面

管理办法第十七条：承包方流转土地经营权，应当与受让方签订书面流转合同，并向发包方备案。代耕不超过一年的，可以不签订书面合同。

第十九条必备栏目缺一项补一项：双方身份与联系方式；地块名称、四至、面积、质量等级、类型、地块代码；期限和起止；流转方式；用途；权利义务；价款或分红及支付；到期附着物；征收征用占用时补偿费归属；违约责任。

缺一项不当然整约未成立。民法典第四百九十条：未书面但一方已履行主要义务且对方接受的，仍可能成立；成立不等于地块、期限、用途已经特定。不得写成“口头一律无效”，也不得保证微信一句即成立。

### 5.2 备案不是生效要件（硬闸）

司法解释第十四条：发包方仅以土地经营权流转合同未报其备案为由请求确认合同无效的，不予支持。管理办法第二十一条：发包方对流转、再流转、融资担保应当办理备案，并报告乡（镇）农村土地承包管理部门。

| 文本写法 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| “未向发包方备案则本合同无效／未生效” | 必须改：删除生效挂钩。双方应在【待填】日内配合备案；逾期不配合视为违约 | 未备案未生效 |
| 一方把不备案当作阻止合同的开关 | 必须改：备案是义务，不是任意废约权 | 村委会不盖章合同就不存在 |
| 无备案配合义务 | 可接受可优化：补谁主办、谁提交、期限、不配合的后果 | 不用备案 |

未备案仍列入 `G#`，影响管理、补贴和再流转合规。不得写成“司法解释说了所以不用备案”。

### 5.3 优先权公示

司法解释第十一条：本集体经济组织成员在流转价款、流转期限等主要内容相同的条件下主张优先权的，应予支持；书面公示合理期限内未主张，或未经书面公示、在本集体以外的人开始使用承包地两个月内未主张的除外。对外流转未写公示安排：必须改或标缺口，不编造已公示。

## 节点 6　再流转、担保、征收、价款与退出

### 6.1 再流转与融资担保（硬闸）

管理办法第十二条：受让方将流转取得的土地经营权再流转以及向金融机构融资担保的，应当事先取得承包方书面同意，并向发包方备案。承包法第四十七条：受让方经承包方书面同意并向发包方备案，可以向金融机构融资担保；担保物权自融资担保合同生效时设立；未经登记不得对抗善意第三人。

| 文本写法 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 空白授权“乙方可任意再流转、抵押” | 红线：改为一次一授权，写明相对人、期限、额度 | 概括授权等于已经同意 |
| 未写再流转／担保限制 | 必须改：正说（经书面同意可再流转／担保）+ 反说（未经同意对承包方不发生效力并可解除） | 未写就可以转 |
| 流入方自行抵押融资 | 红线补同意与备案；同意范围限于本次经营权、本期限 | 经营权人当然可以抵押 |

### 6.2 提前收回与解除

管理办法第二十条：承包方不得单方解除，但受让方擅自改变农业用途、弃耕抛荒连续两年以上、给土地造成严重损害或严重破坏生态环境、其他严重违约的除外。有上述情形承包方合理期限内不解除的，发包方有权要求终止。农户不得随意收回。

只有“依法承担违约责任”视为必须改。构成违约不等于当然解除。

### 6.3 征收与补贴

司法解释第二十二条：承包地被依法征收，承包方请求发包方给付已经收到的地上附着物和青苗补偿费的，应予支持；已流转给第三人的，除当事人另有约定外，青苗补偿费归实际投入人，地上附着物补偿费归附着物所有人。

修改句必须分项：青苗、附着物、承包地补偿中经营权人与承包权人的相应部分。禁止一刀切给一方。补贴是否随经营权转移：必须写明，不编造法定唯一方案。

### 6.4 价款与定金

年租金或实物、支付日、调整机制、是否含补贴转移。一次性付清剩余承包期租金的，建议按年支付或监管账户，户内成员签收，防止农户反悔和资金挪用。

定金必须使用“定金”二字才讨论罚则。民法典第五百八十六条全文本次若未稳定核验，20% 法律结论字段停止，修改句仍避免超额定金空转。订金、保证金无定金性质约定的，不得写成定金。

发包方或其他组织擅自截留流转收益：司法解释第十八条，承包方请求返还应予支持，主张抵销不予支持。合同不得把价款直接付给无权利的第三方而不经承包方。

## 节点 7　格式条款、免责与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 7.1 免责与限额

可约定除故意或重大过失、改变用途、破坏耕作层外的赔偿上限。下列不得排除：造成对方人身损害；因故意或者重大过失造成对方财产损失。本次若未核验第五百零六条全文，免责无效的法律结论字段停止，修改句仍删除“对土地损害不负任何责任”。

### 7.2 格式条款

为重复使用而预先拟定、订立时未与对方协商。公司制流入方提供的制式流转合同，不得仅以“这次没用过第二次”否认。小字、夹在附件、仅有网络勾选：不得写成已尽提示义务。第四百九十六条、第四百九十七条本次若未核验全文，格式条款是否不成为内容的法律结论字段停止。

### 7.3 强制规范

第一百五十三条：违反法律、行政法规强制性规定的民事法律行为无效，但该规定不导致无效的除外。改变农业用途、强迫流转、买卖集体土地所有权：删除或改写相应条款，不当然导致整份经营权出租无效。禁止用已失效“效力性／管理性”口诀。未备案不导致无效（司法解释第十四条）。合同编通则解释第十六条全文本次未核验，细分路径运行时再核。
