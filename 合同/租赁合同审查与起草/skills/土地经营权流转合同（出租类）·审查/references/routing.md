# 边界与路由

本技能只审查 **租赁合同 / 土地经营权流转合同（出租类）** 的待签、保留承包权而流转土地经营权的出租或转包文本。中文展示名是「土地经营权流转合同（出租类）·审查」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或复制 `农村土地承包经营权租赁合同·审查` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 用益物权（承包经营权）本身出租；强调成员身份；写“非本集体成员不得承租／不得取得承包经营权” | `农村土地承包经营权租赁合同·审查` |
| 普通农地债权租赁；主尺度二十年；声明不产生用益物权、不得登记、无任何物权效力 | `农村土地租赁合同·审查` |
| 入股作价出资成为股东或成员；对价是股权或分红，不是租金 | 转引擎重新定性；不按本出租类改完 |
| 互换或转让土地承包经营权；终止原承包关系；须发包方同意的转让 | 转引擎；司法解释第十三条是转让规则，不是本约主路径 |
| 集体经营性建设用地出租 | `标的是已登记集体经营性建设用地出租→` |
| 集体经营性建设用地出让 | `集体经营性建设用地出让` |
| 宅基地房屋租赁 | `宅基地上房屋出租或委托运营→` |
| 城镇房屋租赁 | `房产租赁合同·审查` |
| 光地或不动产租赁共性 | `不动产租赁合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `土地经营权流转合同（出租类）·起草` |
| 已签未争、只问交地日、租金日、备案或登记窗口 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或对应专项领域。` 或对应专项领域 |
| 土地承包仲裁、经营权侵权或征收补偿分配已立案 | 土地或争议专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

经营权出租正文里夹带一小段入股或普通二十年租赁声明：专章交接对应原子或分条改写；保留承包权的出租／转包条款可继续审。用户坚持本技能把承包权租赁、普通农地租赁、入股或承包权转让整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿本类型文本来找专业版：输出 `unavailable`，提示，不得用 `农村土地承包经营权租赁合同·审查` 或 `农村土地租赁合同·审查` 硬套。
