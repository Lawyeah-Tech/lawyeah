# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的租金、面积、剩余承包期；把已失效《合同法》、2002／2009 年承包法同号旧义、2005 年旧流转办法或已失效《物权法》写入结论；保证备案或经营权登记一定办成；把承包权租赁或普通二十年农地租赁当成已完成的本类型审查；写“未备案则本合同未生效”；写“受让人已取得承包经营权”；把二十年当作本类型主标题规则；写城镇房屋优先购买。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查土地经营权流转合同（出租类）（租赁合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、2002／2009 年承包法同号旧义、2005 年旧流转办法或已失效《物权法》时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `租赁合同`，子级 `土地经营权流转合同（出租类）`。定性理由、易混切开结果（承包权租赁 / 普通农地租赁 / 入股 / 互换转让承包权 / 集体建设用地 / 宅基地房屋）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型、未打开 `农村土地承包经营权租赁合同·审查` method。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、三权声明、户内同意、工商审核与文本版本

主体表：签约名、履行名、付款名、发票名、授权签字人。三权表：所有权人（集体）、承包权人（农户）、经营权受让人。户内成员是否签署或书面同意。流入方是否工商资本及资格审查／项目审核文件。版本表：正文、地块清单、承包合同或承包证、户内同意、审核意见、在先流转或担保、聊天确认；冲突并列。

## 5. 地块、期限、登记、书面／备案、用途与对价

地块是否特定到四至、面积、承包合同号、是否永久基本农田；流转方式是出租或转包而不是入股；期限是否不超过剩余承包期；满五年是否单列登记；书面是否具备；备案是否被误写成生效要件；用途是否锁农业／粮食；价款与交地／登记／审核是否挂钩。缺口标 `G#`。不输出承包权租赁的成员封闭口径，不输出普通租赁二十年作为本约主规则。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹。卖承包权、改非农用途、未过审整村流转不得写成可放行。强制规范只按第一百五十三条区分是否导致民事行为无效，不用失效口诀。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把承包权出租或普通二十年租赁直接改成“经营权类型”而不问核心给付。

## 9. 谈判与签署提醒

谈判顺序：先红线（实为承包权租赁或普通二十年租赁、卖承包权、改非农用途、超剩余承包期拒改、未过审整村流转），再必须改（三权声明、户内同意、五年登记、备案义务、再流转一次一授权、征收分项、用途锁定），最后可优化。签署提醒：农户家庭成员签字按手印、流入方法定代表人、承包证与地块图、户内同意、资格审查／项目审核（如需）、备案表、五年以上登记申请。不指导倒签或把未备案写成合同无效。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本任务只出审查意见和修改句，不出整份起草终稿。出稿转 `土地经营权流转合同（出租类）·起草`。不是履约交底、争议文书或效力保证，也不是承包权租赁、普通农地租赁、入股或承包权转让安排。
