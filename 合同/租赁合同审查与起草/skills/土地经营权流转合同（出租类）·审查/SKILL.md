# 土地经营权流转合同（出租类）·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、2002/2009 年《农村土地承包法》同号旧义、2005 年《农村土地承包经营权流转管理办法》或已失效《物权法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **土地经营权流转合同（出租类）** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文显示名为「土地经营权流转合同（出租类）·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证备案或经营权登记一定办成、保证受让人必然取得可对抗一切第三人的经营权。

## 本类型硬闸

1. **三权分置**：集体所有权、农户承包权、土地经营权分开写。本约只流转**经营权**。承包权留在流出农户，所有权仍归集体。写成“承包权转让给公司／受让人取得承包经营权／买卖土地”的部分不得放行。受让方可为本集体成员或外部经营主体，取得的是经营权，不是承包权。
2. **流转期限**：主尺度是**剩余承包期**，不是二十年。约定期限不得超过承包期剩余期限；二轮延包未落地的，不得想当然越过到期日。满五年的，单列经营权登记条款：流转期限五年以上的土地经营权自流转合同生效时设立，未经登记不得对抗善意第三人。未登记不等于合同无效。禁止永久流转。
3. **与承包权租赁／农村土地租赁切开**：文本重心是用益物权（承包经营权）本身出租、强调成员身份、写“非本集体成员不得承租／不得取得承包经营权” → `农村土地承包经营权租赁合同·审查`。承租人非本集体成员、不设立不流转用益物权、主尺度二十年、声明“无任何物权效力／不得登记” → `农村土地租赁合同·审查`。禁止打开或复制 `农村土地承包经营权租赁合同·审查` 的 method，禁止把本约改成普通二十年债权租赁后按本类型放行。
4. **备案不是生效要件**：应当向发包方备案。发包方仅以未备案请求确认土地经营权流转合同无效的，司法解释不予支持。不得写成“未备案则未生效／无效”。未备案仍列入缺口，提示补报。
5. **再流转与融资担保**：须事先取得承包方书面同意并向发包方备案。同意书限定相对人、期限、担保额度，禁止空白授权。未经同意的再流转对承包方不发生效力并可解除。
6. **农地农用**：不得改变土地所有权性质和农业用途，不得破坏耕作层、弃耕撂荒、非农化或违规非粮化。永久基本农田禁止发展林果业和挖塘养鱼。改用途条款只出告知，不改写成可履行非农建设。
7. **工商资本审核**：工商企业等社会资本流转土地经营权，须走地方资格审查和项目审核。未按规定申请或未通过的，不得开展流转活动。审核通过可作为大规模付款或交地条件，不得写成农户已签字部分的任意无效开关。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签土地经营权流转（出租／转包）正文，尚未签署，尚未成争，核心给付是承包方**保留承包权**、在约定期限内把土地经营权交给受让方从事农业生产经营并收取租金或流转价款，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 用益物权（承包经营权）本身出租、强调成员身份、禁止非成员取得承包经营权 → `农村土地承包经营权租赁合同·审查`；
- 普通农地债权租赁、主尺度二十年、声明不产生用益物权、不得登记 → `农村土地租赁合同·审查`；
- 入股作价出资成为股东或成员、对价是股权／分红而不是租金 → 不按本出租类改完，转引擎重新定性；
- 互换或转让土地承包经营权、终止原承包关系 → 转引擎；转让未经发包方同意可能无效，不在本任务改成经营权出租外壳；
- 集体经营性建设用地出租／出让 → `标的是已登记集体经营性建设用地出租→`／`集体经营性建设用地出让`；
- 宅基地房屋租赁 → `宅基地上房屋出租或委托运营→`；城镇房屋或光地不动产租赁 → `房产租赁合同·审查`／`不动产租赁合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `土地经营权流转合同（出租类）·起草`；
- 已签只问交地日、租金日、备案窗口 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁或土地承包仲裁已立案 → `或对应专项领域。` 或土地／争议专项。

以流转为名改变农地用途、挖田造景、硬化停车场，或把承包权卖给公司：只出告知，不改写成可履行路径。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及附件／地块清单／承包证／户内同意版本；是否保留承包权；流转方式是出租或转包而不是入股；拟定期限与剩余承包期；是否满五年及登记安排；流入方是否工商资本及审核文件；地块是否永久基本农田；是否已有在先经营权或担保；再流转或融资担保如何写；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `土地经营权流转合同（出租类）·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议或土地专项。未签且目标是评改已有经营权出租／转包文本，才进入本任务。

### 1. 类型锁死与三权分置

标题、核心给付与对价方式一致才继续。承包权租赁、普通农地租赁、入股、互换转让承包权负触发。

### 2. 主体、户内同意与工商审核

流出方为承包农户；签字人须获户内同意。发包方在备案栏，不在出租人栏。工商资本未过审不得交地。

### 3. 地块特定化与农地农用

地块清单齐；永久基本农田锁用途；禁止非农化条款缺失仍放行。

### 4. 流转期限、剩余承包期与五年登记

期限 ≤ 剩余承包期；满五年单列登记；不得以二十年为主尺度。

### 5. 书面、备案与登记切开

书面成立；备案是义务不是生效条件；登记解决对抗，不解决合同是否成立。

### 6. 再流转、担保、征收与投入

一次一授权；征收分项；到期附着物预先安排。

### 7. 格式条款与强制规范

无核验引文则法律结论字段停止。改用途、卖承包权不得改成可履行。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把承包权卖给公司、把农地改成可履行非农建设、把本约改成承包权租赁或普通二十年租赁外壳仍放行。
- `字段停止`：法域、动态规则、剩余承包期、户内成员名单、工商审核、在先经营权登记未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
