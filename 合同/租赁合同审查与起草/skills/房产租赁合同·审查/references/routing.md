# 边界与路由

本技能只审查 **房产租赁合同** 的待签文本。中文展示名是「房产租赁合同·审查」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止把买卖商品房审查方法套到本任务。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 融物+融资、三方买卖+租赁、租金本息表、出租人向出卖人付款 | `融资租赁合同·审查`；专业版未装则 `unavailable`，提示，不得用本技能硬套 |
| 先卖后租、承租人与出卖人同一、留购/本息清算 | `售后回租合同·审查`；未装则 `unavailable` |
| 土地经营权流转、出租类农地流转、三权分置登记 | `土地经营权流转合同（出租类）·审查`；未装则 `unavailable` |
| 农村土地承包经营权租赁 | `农村土地承包经营权租赁合同·审查`；未装则 `unavailable` |
| 农村土地普通租赁、非成员租集体土地、无房屋 | `农村土地租赁合同·审查`；未装则 `unavailable` |
| 无地上房屋的光地、建设用地使用权单独出租 | `不动产租赁合同·审查` |
| 设备、车辆等动产租赁 | `动产租赁合同·审查` |
| 建筑设备、塔吊脚手架干租 | `建筑设备租赁合同·审查` |
| 仅约定期限共性、标的不是特定房屋 | `定期租赁合同·审查` 或回引擎重定性 |
| 不定期、随时解除为主轴且无特定房屋条款 | `不定期租赁合同·审查` |
| 临时建筑、临建批准或使用期限绑效力 | `临时建筑租赁合同·审查` |
| 产权式商铺、固定或保底回报、经营权上交统一运营 | `产权式商铺租赁合同·审查`；未装则 `unavailable` |
| 定向建设后回租 | `定向建设租赁合同·审查`；未装则 `unavailable` |
| 到期必买、租金冲抵购房款、以租代售 | `可独立居住的商品房预售或现售，无强制统一经营→` / `或` / `或`，按买卖或让与担保切开；本任务不审过户 |
| 居间、中介主文件 | `主给付是居间报酬或带看成交→`；本约只对照版本，不审佣金主给付 |
| 无文本、本类型条件已谈妥、要出己方稿 | `房产租赁合同·起草` |
| 已签未争、只问交房日、租金支付留痕 | 本套导航的履约步骤 |
| 已催告、解除、索赔、立案或要解约策略 | `或对应专项领域。`；C 端房屋租赁解约只分流，不回改 |
| C 端大众快检 | 只分流，不回改 |

房屋租赁正文里夹带居间佣金专条：专条交接 `主给付是居间报酬或带看成交→`；其余租赁条款继续审。用户坚持本技能给出融资租赁或农地效力意见：`目标停止`。
