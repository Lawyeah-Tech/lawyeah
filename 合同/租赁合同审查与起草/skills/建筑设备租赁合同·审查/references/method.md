# 审查方法（锁定 租赁合同 / 建筑设备租赁合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制动产租赁或施工合同原子的 method。

定性校验：标题、核心给付与本类型一致才继续；施工承包、融资租赁、非工地动产或房屋明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、事故后必然由一方单独担责或唯一必得金额。

`search_law` 返回已失效《合同法》及其解释、1991/2006《起重机械安全监察规定》、1995《城市房屋租赁管理办法》、担保法解释时记为噪声，不得写入 `L#`。融资租赁第 749、751 条不得当作本类型损坏或第三人责任规则。

示范文本只参考结构。摘要仍引用《合同法》的塔吊范本不证明本约条款已被接受。

知识库纠正（不回写双文件）：

- `基本面.md` 把一般家具家电、乘用车、指定购买融资写进本类型边界：本技能不审，分别转 `动产租赁合同·审查`、`融资租赁合同·审查`。
- `基本面.md`“未登记、超检验设备出租，合同不当然无效”：采纳；按违法履行处理，承租人可拒收停租，不写成已经可以进场。
- `框架.md`“包租到工程竣工”“损坏按新品赔偿”“一切安全责任由承租人承担”：必须改或红线。
- 双文件未禁止套用融资租赁毁损继续付租：本方法禁止。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须先拆两类结构，再与邻类切开：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 只交塔吊、升降机、钢管、扣件、模板、脚手架，操作和安拆由承租人或其总包负责，按日/月/台班收租 | 本类型·干租 | 正触发 |
| 出租人派司机、信号工、司索工或安拆班组，不包施工部位成果，仍按台班或日历日收租 | 本类型·湿租 | 正触发；进入人员硬闸 |
| 包安拆、包顶升、包完成吊装或某部位工程量，按形象进度、竣工验收或工程量计价 | 施工/专业分包 | 负触发 `的method。`；无资质则以租代包停笔 |
| 出租人按承租人指定向出卖人购买设备，租金覆盖购价，到期留购或归属承租人 | 融资租赁 | 负触发 `融资租赁合同·审查`（未装则 `unavailable`） |
| 先卖后租，承租人与出卖人同一 | 售后回租 | 负触发 `售后回租合同·审查`（未装则 `unavailable`） |
| 家具家电、乘用车、办公电脑、与工地无关的集装箱 | 动产租赁 | 负触发 `动产租赁合同·审查` |
| 房屋、商铺、厂房占有使用 | 房产租赁 | 负触发 `房产租赁合同·审查` |
| 无地上房屋的光地 | 不动产租赁 | 负触发 `不动产租赁合同·审查` |
| 到期必买、租金冲抵购机款、配合过户给承租人但无三方购销 | 买卖或让与担保 | 负触发 `到期必买租金冲抵购机款`；禁止出过户修改句冒充租赁 |

禁止两可时灌入施工或融资租赁知识。禁止打开邻类 method 对照。

### 1.2 加载协议（硬闸）

本技能已锁定 **租赁合同 / 建筑设备租赁合同**。只打开 `references/基本面.md` 与 `框架.md`。禁止读其他子目录，禁止为对照再开第二类。

### 1.3 以租代包停笔

加载后或定性中出现：无安拆资质却承包安拆顶升；以租赁合同完成某分部工程；出借资质、只收管理费；伪造内部承包包装。

动作：

1. 交付告知：该结构可能构成违法分包或无资质承揽，依据民法典第 153 条、第 791 条及施工合同解释（一）第一条处理，不得改写成可履行分包文本。
2. 不写可履行的专业分包价款、质保金、竣工验收或假资质路径。
3. 风险表只保留识别依据和转出/改道提示。
4. 用户坚持“改到能签且仍无资质进场施工”：整体停止。

合规改道（另签有资质安拆合同、真实专业分包）只点名，不在本任务起草。

## 节点 2　主体、产权、安拆资质

### 2.1 主体表

建表：签约名、工地项目公司、付款名、发票名、授权签字人。名称不一致不自动合并。总包、专业分包、劳务分包、业主经常不是同一人：合同相对人须有支付能力；视情况把付款承诺人写成加入履行的第三人，不展开保证专项。

项目经理签字须有授权。口头“工地随便谁都能签进场单”不得写成已授权。

### 2.2 出租人与设备权源

核营业执照经营范围痕迹、设备产权或合法转租权。同一塔吊编号出现在两份待签合同：标不能交付，红线。材料未提及中登网融资租赁登记：不得写成“无权利负担”，只能写 `依据不足`。

国资或共有设备、已被其他工地留置：签署或交付能力字段停止。

### 2.3 安拆单位

塔吊、升降机的安装拆卸单位必须具备建设主管部门相应资质和建筑施工企业安全生产许可证，并在许可范围内承揽。光租出租人不得“顺便派人安拆”。安拆另签合同的，本约只审与租赁的衔接（窗口、停工配合、验收），不把安拆合同改成施工总包。

不足：字段停止，列出待补资质页栏，不补主体。

## 节点 3　设备特定化与适租

### 3.1 特定化

塔吊：名称、型号、出厂编号、备案编号、吨位/臂长/力矩。升降机：备案号。周转材料：规格、计量单位（吨/米/件）、合理损耗率、丢失赔偿单价。清单作为附件，进场单可变更数量。设备编号全无：必须改。

钢管扣件须符合国家标准。禁止把地条钢、废旧开裂件写成“按现状交验即合格”。

### 3.2 适租与禁止出租（硬闸辅助）

支持依据：特种设备安全法第二十八条；建设工程安全生产管理条例第十六条；建筑起重机械安全监督管理规定第四条至第八条、第十六条。

出租特种设备不得属于：未取得许可生产、国家明令淘汰或报废、超过使用年限、检验不合格、无完整安全技术档案、无齐全有效安全保护装置。签约时应出具制造许可证、产品合格证、制造监督检验证明、备案证明、自检合格证明和安装使用说明书。安装完毕须验收合格方可使用；未验收不得开机。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 本证、检验、备案可回链且在有效期内 | 可接受；补进场出示义务 | 已经适租并已登记 |
| 检验过期、禁止使用、淘汰报废 | 红线：不得出租使用；承租人有权拒收并停租 | 先开后补证；合同未生效所以无责 |
| 无检测合格证明 | 必须改：作为进场条件附件 | 口头说合格即可 |
| 使用登记挂总包、合同承租人是分包 | 必须改：配合登记，写明登记使用单位与合同相对人关系 | 登记谁就是合同谁 |

未经验收投入使用，双方都有过错：修改句要求验收签字前不得使用，不得只责一方。

### 3.3 基础与附着

塔吊基础、附着预埋件往往由承租人施工。倾覆不得默认全在出租人。按设计、施工、验收划分：未按方案施工造成的事故由责任方承担，另一方可追偿。

## 节点 4　进退场计量（硬闸）

支持依据：民法典第七百零四条、第七百零八条；本类型基本面第四步、框架进退场计量。

进退场程序比租金数字更重要。周转材料高频争点是“进场少计、退场多扣”。

审查清单：

1. 是否有进场单：日期、工地、设备编号或材料规格、数量、计量方法（检尺/过磅）、照片或监理见证。
2. 是否共同计量、书面签认；异议期是否量化（文本可写三日，数字用 `【待填】`）。
3. 指定签收人名单；禁止“工地任何人签字事后不认”却无授权名单。
4. 退场提前报停、拆卸窗口、运输风险、不能退场时的停置安排。
5. 租期起算是否绑进场签认，截止是否绑退场验收。

| 文本写法 | 动作 |
| --- | --- |
| “数量以出租人现场目测/单方结算单为准” | 红线删除；改为共同检尺或过磅，异议期内书面提出否则视为确认 |
| “包租到工程竣工/停用后仍计至竣工” | 必须改：租至退场签认日；工期延误不自动延长，除非另有停置条款 |
| 只有框架合同、不签进场单 | 必须改：每台设备或每批次材料一份进场单，作为变更数量的唯一依据 |
| 台班与日历日混用 | 必须改：单一计费口径；风力超限或指令停机是否计租单列 |
| 工地停工但不能退场，继续按运营租金计 | 必须改：停置费、封顶日或超过 N 日必须退场 |

未给出的吨数、件数、损耗率写 `【待填】`。不得编造过磅数据。

## 节点 5　操作人员与安全责任（硬闸）

### 5.1 干租 / 湿租必须落句

未标明租型：必须改。湿租列工种、持证要求、工作时间、加班费。指挥、司索由承租人配备的，指挥失误归承租人；设备固有缺陷归出租人。

### 5.2 劳动关系与持证

支持依据：建筑起重机械安全监督管理规定第二十四条、第二十五条；安全生产法第五十二条。

建筑起重机械安装拆卸工、起重信号工、起重司机、司索工须经建设主管部门考核合格并取得特种作业操作资格证书后上岗。房屋建筑和市政工地此类人员不改走市场监管《特种设备作业人员证》充数。

湿租人员应与出租人建立劳动合同或依法用工，由用人单位缴纳工伤保险。禁止写成“由承租人自行招用但挂出租人牌子”。商业意外险不得替代法定工伤。

人员有权拒绝违章指挥和强令冒险作业。任何一方不得要求对方违章开机。

### 5.3 安全责任不得一揽子转嫁

支持依据：建筑起重机械安全监督管理规定第六条、第十一条、第十八条；民法典第五百零六条。

租赁合同须明确双方安全责任，不能用“一切安全责任由承租人/出租人承担”代替。使用单位的现场防护、应急预案、专职管理人员、故障停用等法定义务不因租赁条款消失。造成对方人身损害的免责条款无效；因故意或重大过失造成对方财产损失的免责条款无效。

| 文本写法 | 动作 |
| --- | --- |
| “一切安全/工伤/第三人责任由承租人承担” | 红线：改为按过错+法定义务划分；人身免责删除 |
| 湿租司机无合同、无工伤、无操作证 | 红线：补劳动关系、工伤、证书附件；承租人可拒收无证人员 |
| 干租却要求出租人承担全部指挥失误 | 必须改：指挥归使用方，固有缺陷归出租人 |
| 未验收或检验过期仍要求开机 | 红线：任何一方有权拒绝；强令构成违约 |

保险：设备财产险、第三者责任险、安责险分列投保义务和保额 `【待填】`。湿租人员工伤由用人单位缴纳。

## 节点 6　损坏、维修与减租（硬闸）

支持依据：民法典第七百一十条、第七百一十一条、第七百一十二条至第七百一十四条、第七百二十九条、第七百三十三条。

分配规则：

1. 按约定方法或租赁物性质使用造成的损耗：不承担赔偿责任。
2. 未按约定或性质使用致损：出租人可解除并请求赔偿。
3. 保管不善致毁损灭失：承租人赔偿。
4. 不可归责于承租人的事由致部分或全部毁损灭失：承租人可请求减少租金或不支付租金；不能实现合同目的的，可以解除。
5. 维修默认出租人，另有约定除外；因承租人过错需要维修的，出租人不承担该次维修。故障停机超过约定小时：停租或换机。

鉴定程序：共同选定检测机构；争议期间可先退场保全设备。赔偿以修复费或约定单价为限，扣除折旧和残值。禁止同时收取全额新机价款和占用期间全额租金。

| 文本写法 | 动作 |
| --- | --- |
| “损坏按新品赔偿，租金照付，以出租人单方认定为准” | 红线：改为鉴定+残值+正常损耗不赔；不可归责事由减租或停租 |
| 把民法典第七百五十一条“占有期间毁损仍付租”写入普通租赁 | 红线删除；该条是融资租赁规则 |
| 把第七百四十九条“造成第三人损害出租人不承担责任”写入湿租 | 红线删除或限缩：出租人对自有人员、固有缺陷和未尽适租义务不免责 |
| 合理损耗率、丢失单价缺失 | 必须补附件单价表；单价数倍于市场价标红旗，不编造市场价 |
| “原状返还”无损耗定义 | 必须改：符合按性质使用后的状态；列报废标准 |

无核验引文不得把第 710/729 条写成已核验法律结论；修改句草稿仍可按内置方法给出。

## 节点 7　租金、停置、转场、格式条款

### 7.1 计费

进场费、安拆费、租金、辅助工时、停置费、超高/超载附加、丢失赔偿单价表分列。支付节点避免完全背靠背。大型企业与中小企业约定以业主付款为唯一付款前提的，标法释〔2024〕11 号审查点：主体身份未核则字段停止，修改句仍要求加付款期限上限或删除无限背靠背。

押金按押金处理，列扣除项目和退场验收后返还日。未约定定金性质的，不得适用定金罚则。真定金才核百分之二十上限。

### 7.2 转场转租

未经同意不得转到其他工地或转租。擅自转场视同第七百一十六条第二款，出租人可解除。

### 7.3 解除

欠租、无证强行要求开机、长期停工不退场：可约定解除。解除后的安拆配合义务继续。构成违约不等于当然解除；法定解除只点名，不在本任务作出已解除结论。

计量争议可先第三方检测再付争议部分；不得把所有争议都暂停全部付款。

### 7.4 格式条款与强制规范

出租人制式文本按民法典第四百九十六条、第四百九十七条审查提示说明。无核验引文则法律结论字段停止。违反法律、行政法规强制性规定不一律无效，按解释第十六条区分；禁止用已失效“效力性/管理性”口诀。挂靠、违法分包、以合法形式掩盖非法目的：不改写成有效履行结构。

争议解决：或裁或诉、机构不明标待核。不动产所在地不是本类型专属连结点；只标约定，不选定唯一法院充作意见。

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

打开已加载的 `框架.md`，按六步逐段对照正文。`基本面.md` 用于校验类型、主体、设备、程序、结构和红旗，不代替本节点出句。

| 步 | 动作 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题用建筑设备/周转材料/起重机械租赁，不用施工承包或融资租赁混称；主体与产权人/安拆资质一致；鉴于可写工地，不写包工期 | 标题或主体修改句 |
| 交易条款 | 设备编号；干湿租；进退场共同计量；租期绑进场/退场签认；租金口径 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 人员劳动关系与持证；损坏鉴定与残值；安全责任按过错+法定义务；保险 | 可执行后果句 |
| 尾部 | 指定签收人；生效可约定进场签认后起租；附件（资质、检验、操作证、进场单、单价表、安全协议） | 生效与附件修改句 |
| 语言 | 盯死竣工/退场、新品/折旧、一切安全责任、交付/所有权、雨雪当不可抗力 | 替换空词的句子 |
| 常见问题 | 进场不计量；湿租非法用工；以租代包；停工高额计租；同一设备两工地 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（无证/淘汰设备、以租代包拒改、目测扣量拒改、挂牌招用、人身免责、新品全额且不鉴定且继续全额计租、倒签进场）；
- `必须改`：可谈但签署前要落句；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级预付租金或个人无限连带且用户拒绝升级：停止“可以签署”建议。

## 版本冲突

正文、设备清单、进场单、赔偿单价表、安全协议、聊天确认冲突时：

1. 并列 `D#` / `C#` / `S#`，不选对用户有利的一版。
2. 修改句写明数量以进场单为准，安全协议不得与正文冲突且不得成为唯一文本。
3. 不得在意见里悄悄采用有利版本并称“合同已明确”。
