# 边界与路由

本技能只审查 **租赁合同 / 建筑设备租赁合同** 的待签文本。中文展示名是「建筑设备租赁合同·审查」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止把动产租赁或施工合同审查方法套到本任务。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 包安拆包使用包工期、按工程量或形象进度计酬、专业分包或施工总承包 | `的method。`；不得删工程量后硬套本技能 |
| 融物+融资、三方买卖+租赁、租金本息表、出租人向出卖人付款、到期留购 | `融资租赁合同·审查`；专业版未装则 `unavailable`，提示，不得用本技能硬套 |
| 先卖后租、承租人与出卖人同一、留购/本息清算 | `售后回租合同·审查`；未装则 `unavailable` |
| 家具家电、乘用车、办公设备等非工地动产 | `动产租赁合同·审查` |
| 已建成房屋占有使用 | `房产租赁合同·审查` |
| 无地上房屋的光地或建设用地使用权单独出租 | `不动产租赁合同·审查` |
| 临时建筑、临建批准期限绑效力 | `临时建筑租赁合同·审查` |
| 仅约定期限共性、标的不是特定建筑设备 | `定期租赁合同·审查` 或回引擎重定性 |
| 不定期、随时解除为主轴且无设备进退场条款 | `不定期租赁合同·审查` |
| 到期必买、租金冲抵购机款 | `到期必买租金冲抵购机款`；本任务不审过户 |
| 无文本、本类型条件已谈妥、要出己方稿 | `建筑设备租赁合同·起草` |
| 已签未争、只问进场日、对账、退场留痕 | 本套导航的履约步骤 |
| 已催告、解除、倒塌索赔、立案或要解约策略 | `或对应专项领域。`；建设工程争议只分流，不回改 |
| C 端大众快检 | 只分流，不回改 |

建筑设备租赁正文里夹带安拆专项且安拆单位有资质：安拆专条交接施工或另行安拆合同审查；其余租赁条款继续审。用户坚持本技能给出施工效力或融资租赁留购意见：`目标停止`。
