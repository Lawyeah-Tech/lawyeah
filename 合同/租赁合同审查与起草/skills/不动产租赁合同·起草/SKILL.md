# 不动产租赁合同·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、1995 年《城市房屋租赁管理办法》、1992 年《划拨土地使用权管理暂行办法》、2004 年《土地管理法》旧第六十三条、担保法解释当作现行规则。不得把城镇房屋租赁解释的户口/居住证/入学路径，或商品房买卖司法解释，写成全部不动产的默认主路径。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **不动产租赁合同** 己方稿，出稿后用本类型硬闸自审。交付草稿、未决项、自审风险表和自审后修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文显示名为「不动产租赁合同·起草」。

`depends-on` 为空。不要求先跑导航。

不交付：他类起草、待签文本签前审查、履约交底、争议文书、有效性保证、把户口/住宅专档当全部不动产默认、把施工挂靠或买卖/承揽定性表当成本类型主路径、商品房买卖规则套用。

## 本类型硬闸

每闸必须出修改句或明确停笔口径。禁止只打红黄绿。

1. **不动产租赁 ≠ 房产住宅租赁 ≠ 动产租赁 ≠ 融资租赁**。正触发是土地、厂房、商铺、写字楼等非“住房承租”主路径。住宅+户口/居住证/入学/共同居住人 → `房产租赁合同·审查`。设备、车辆按件/台班计租 → `动产租赁合同·审查`。出租人按承租人指定购买、租金含本息 → `融资租赁合同·审查`（未装则 `unavailable`）。修改句：标题与鉴于改为“不动产租赁/土地使用权租赁/厂房（商铺、写字楼）租赁，不构成住房承租、融资租赁或买卖”；用户交来住房专档或动产/融资文本的，只出负触发全 ID，不删条款后硬套。
2. **第七百零五条：最长期间二十年，超过部分无效**。不得把整份合同写成当然无效。签约时即约定“二十年后再自动续二十年”的，续约约定不得当作本条第二款的有效续订。修改句：截到二十年届满日；删除自动再续二十年；可改为届满前协商续订，自续订日起仍不得超过二十年。
3. **第七百零六条：登记备案不是生效要件**。未办理租赁登记备案，不影响合同效力。土地使用权出租应当办理登记，写成双方配合义务，禁止“未登记不生效”且可由一方卡死。修改句：改为签字盖章成立生效；双方于签字后三十日内配合办理出租登记/备案；一方拒不配合构成违约，不得据此主张合同未生效。
4. **维修第七百一十二/七百一十三条；转租第七百一十六条；押金≠定金第五百八十六条**。默认出租人维修并保持适租；另有约定须分列主体结构/屋面/场地基础设施与日常损耗，并留代修、减租或延展。转租须同意；擅自转租可解除；转租期超过剩余租期的部分对出租人无约束力。押金、保证金、订金未约定定金性质的，不得适用定金罚则。修改句：补维修清单与报修时限；转租改为事先书面同意并写擅自解除；押金改为扣除清单+交还验收后返还日，删除“违约即没收并适用定金罚则”。
5. **第七百二十五条：买卖不破租赁**。所有权或使用权变动不影响租赁，以承租人按照租赁合同**占有期限内**发生变动为前提。未交付占有不得承诺已取得对抗效力。出租前已抵押或已查封的，不得写成当然对抗。修改句：对抗以按合同占有为前提；补看地/看房配合时段；先抵实现或先查封标例外，禁止倒签。
6. **临时建筑 → `临时建筑租赁合同·审查`；建筑设备 → `建筑设备租赁合同·审查`**。临建批准期限绑效力、工地售楼处临建，不得按普通不动产租赁改完。塔吊、钢管、脚手架、施工升降机为中心并可能附带司机或安拆，不得按厂房场地改完。修改句：负触发只出判定和全 ID 路由；不把临建延期或湿租进退场写成普通场地交接。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿，尚未签署，尚未成争，核心给付是土地、厂房、商铺、写字楼占有使用换租金，用户要出己方稿。不是住房承租路径。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 已有可读待签文本要评改 → `不动产租赁合同·审查`；
- 已建成住宅作住房承租，主目标是户口、居住证、入学、共同居住人或房屋备案平台 → `房产租赁合同·审查`；不得删户口条款后当不动产共性审完；
- 设备、车辆、机器等动产特定化租赁 → `动产租赁合同·审查`；
- 工地塔吊、钢管、脚手架、施工升降机为中心，或附带司机、安拆 → `建筑设备租赁合同·审查`；
- 出租人按承租人对出卖人、租赁物的选择购买并出租，租金含本息 → `融资租赁合同·审查`（专业版未装则 `unavailable`，提示，不得用本技能硬套）；
- 先卖后租、承租人与出卖人同一、还租计划表 → `售后回租合同·审查`（未装则 `unavailable`）；
- 土地经营权流转、承包经营权出租、农村土地对外租赁 → `土地经营权流转合同（出租类）·审查` / `农村土地承包经营权租赁合同·审查` / `农村土地租赁合同·审查`（未装则 `unavailable`）；
- 临时建筑、临建批准或使用期限绑效力 → `临时建筑租赁合同·审查`；
- 产权式商铺、固定或保底回报、统一运营权上交 → `产权式商铺租赁合同·审查`（未装则 `unavailable`）；
- 核心给付是房屋或土地使用权过户换价款、到期必买、租金冲抵地价 → `可独立居住的商品房预售或现售，无强制统一经营→` 或 `或`，禁止用本技能或商品房 method 反过来审租赁；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已成争（催告、解除、索赔、诉讼仲裁）→ `或对应专项领域。`，不代做争议文书。

倒签对抗查封、以租赁名义转让集体土地或宅基地、农用地擅自非农建设、未批准划拨对外长租：只出告知，不改写成可履行结构。施工挂靠、违法分包、规避限购不是本类型主路径；文本里偶然出现时只告知并转工程或对应原子，不据此定性本约。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及附件版本；标的是光地、厂房、商铺还是写字楼；坐落与宗地号/不动产单元号；出让或划拨及剩余年限；规划用途与合同用途；租期与租金、押金性质；维修与转租安排；抵押查封在先租赁；交付/占有安排；不可接受事项；法域与拟签署日。缺立场或本类型条件未谈妥则不启动起草。同时掌握双方秘密或潜在冲突时，先停止策略输出。

不问户口迁入、居住证积分或入学学位——那是 `房产租赁合同·审查` 的住宅专档，不得当作全部不动产默认字段。

## 起草模式

本原子只承担本类型起草。待签评改转 `不动产租赁合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 标题与鉴于写明不动产／土地使用权／厂房／商铺／写字楼租赁，不构成住房承租、融资租赁或买卖。
- 租期起止截到二十年届满日，且不超过本宗地使用权剩余年限；届满前可协商续订，自续订日起仍不得超过二十年。
- 合同自签字盖章成立生效；双方于签字后三十日内配合办理出租登记／备案，一方拒不配合构成违约，不得据此主张未生效。
- 维修分列主体结构／屋面／场地基础设施与日常损耗，写报修时限、代修、减租或延展。
- 转租须事先书面同意；擅自转租可解除；转租期末日不得晚于主合同到期日及土地剩余年限。
- 押金写扣除清单与交还验收后返还日，不适用定金罚则。
- 买卖不破租赁以按合同占有为前提；先抵实现或先查封为例外；补看地／看房配合时段。

### 附件必附

- 权证或宗地号／不动产单元号对应材料、宗地图／平面图。
- 出让合同或划拨批准（如适用）。
- 交付占有交接单。

### 禁止出现

- 户口／居住证／入学／共同居住人主路径，或按住房承租专档出稿。
- 设备、车辆按件／台班计租，或出租人按承租人指定购买、租金含本息。
- 临建批准期限绑效力，或塔吊、钢管、脚手架、施工升降机湿租进退场。
- 签约时自动再续二十年；未登记／未备案不生效；整锅包修无代修；押金适用定金罚则。
- 未交付占有即承诺已取得对抗效力；倒签对抗查封。
- 以租赁名义转让集体土地或宅基地、农用地擅自非农建设、未批准划拨对外长租。

### 0. 签署状态与成果分流

有完整待签文本要评改 → `不动产租赁合同·审查`；本类型条件已谈妥要出己方稿 → 本任务起草并自审；已签履约 → 本套导航履约步骤；已成争 → 争议分流。本类型条件已谈妥要出己方稿，才进入本任务。

### 1. 类型锁死（硬闸 1、硬闸 6）

标题、核心给付与土地/厂房/商铺/写字楼占有使用一致才继续。住房承租、动产、融资租赁、临建、建筑设备、农地、买卖负触发。禁止施工挂靠定性表，禁止买卖/承揽定性表。

### 2. 主体、权属与标的特定化

签约名与登记权利人一致；宗地号或幢号层号；规划用途。不问户口与共同居住人。

### 3. 租期二十年（硬闸 2）

起止日期截到二十年；自动续二十年必须改；核对土地剩余年限。

### 4. 登记备案非生效（硬闸 3）

登记/备案是义务不是生效条件。

### 5. 维修、转租、押金（硬闸 4）

维修清单与代修；转租书面同意；押金非定金。

### 6. 买卖不破租赁（硬闸 5）

占有条件与先抵/先查封例外。

### 7. 用途、优先购买范围、解除

规划用途不得擅自改变；光地删除房屋优先购买；厂房/商铺/写字楼优先购买按出卖房屋审，不上升为户口路径。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；条件未谈妥仍要出整稿；用户坚持倒签对抗查封、以租赁名义转让集体土地或宅基地、把未批准划拨或农用地非农改成可履行结构、保证有效或必然对抗买受人。
- `字段停止`：法域、地方登记窗口、权属、出让剩余年限或划拨/集体程序未核验。
- `目标停止`：主目标已变为评改待签文本（转 `不动产租赁合同·审查`）、履约交底、争议文书，或住房承租/动产/融资租赁/临建/建筑设备/买卖整案。

生存级预付租金或个人无限连带且用户拒绝升级：停止“可以签署”建议。
