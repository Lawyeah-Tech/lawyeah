# 边界与路由

本技能只起草 **租赁合同 / 不动产租赁合同** 的待签文本。中文展示名是「不动产租赁合同·起草」。

正触发是土地、厂房、商铺、写字楼等非住房承租路径。负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止把 `房产租赁合同·审查` 户口/住宅专档抄成全部不动产默认。禁止把买卖商品房审查方法或施工挂靠/买卖承揽定性表套到本任务。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 已建成住宅，主目标是住房承租、户口、居住证、入学、共同居住人、房屋备案平台 | `房产租赁合同·审查` |
| 设备、车辆、机器等动产特定化租赁 | `动产租赁合同·审查` |
| 建筑设备、塔吊脚手架、施工升降机，或附带司机安拆 | `建筑设备租赁合同·审查` |
| 融物+融资、三方买卖+租赁、租金本息表、出租人向出卖人付款 | `融资租赁合同·审查`；专业版未装则 `unavailable`，提示，不得用本技能硬套 |
| 先卖后租、承租人与出卖人同一、留购/本息清算 | `售后回租合同·审查`；未装则 `unavailable` |
| 土地经营权流转、出租类农地流转、三权分置登记 | `土地经营权流转合同（出租类）·审查`；未装则 `unavailable` |
| 农村土地承包经营权租赁 | `农村土地承包经营权租赁合同·审查`；未装则 `unavailable` |
| 农村土地普通租赁、非成员租集体农地、种粮养殖 | `农村土地租赁合同·审查`；未装则 `unavailable` |
| 仅约定期限共性、标的不是特定不动产 | `定期租赁合同·审查` 或回引擎重定性 |
| 不定期、随时解除为主轴且无特定不动产条款 | `不定期租赁合同·审查` |
| 临时建筑、临建批准或使用期限绑效力 | `临时建筑租赁合同·审查` |
| 产权式商铺、固定或保底回报、经营权上交统一运营 | `产权式商铺租赁合同·审查`；未装则 `unavailable` |
| 定向建设后回租 | `定向建设租赁合同·审查`；未装则 `unavailable` |
| 到期必买、租金冲抵购房款或地价、配合过户 | `可独立居住的商品房预售或现售，无强制统一经营→` / `或` / `或`，按买卖或让与担保切开；本任务不审过户 |
| 施工挂靠、违法分包、资质出借为主给付 | 转工程原子或引擎重定性；不是本类型主路径 |
| 已有可读待签文本要评改 | `不动产租赁合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、只问交地/交铺日、租金支付留痕 | 本套导航的履约步骤 |
| 已催告、解除、索赔、立案或要解约策略 | `或对应专项领域。`；C 端房屋租赁解约只分流，不回改 |
| C 端大众快检 | 只分流，不回改 |

不动产租赁正文里夹带住宅户口或居间佣金专条：户口/居住证专条交接 `房产租赁合同·审查`；居间专条交接 `主给付是居间报酬或带看成交→`；土地/厂房/商铺/写字楼条款可继续审。用户坚持本技能给出住房承租、动产、融资租赁、临建或建筑设备效力意见：`目标停止`。
