# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受、必然对抗买受人或必然可执行；编造未给出的租金、面积、租期；把已失效《合同法》及其解释、1995 年《城市房屋租赁管理办法》、1992 年《划拨土地使用权管理暂行办法》写入结论；把户口/居住证/入学或 `房产租赁合同·审查` 住宅专档主路径套到土地、厂房、商铺、写字楼；把施工挂靠或买卖/承揽定性表当成本类型主路径；把住房承租、动产、融资租赁、临建、建筑设备、农地文本当成已完成的本类型审查。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查不动产租赁合同（租赁合同）」。点名标的是光地、厂房、商铺还是写字楼，并写明未走住房承租路径。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、1995 年《城市房屋租赁管理办法》、1992 年《划拨土地使用权管理暂行办法》、2004 年土地管理法旧第六十三条、担保法解释或商品房买卖司法解释时记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `租赁合同`，子级 `不动产租赁合同`。定性理由、易混切开结果（房产住宅租赁 / 动产 / 融资租赁 / 临建 / 建筑设备 / 农地 / 买卖）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、权属与文本版本

主体表：签约名、登记权利人名、付款名、发票名、授权签字人、共有人或集体/国资决策主体。权属与负担：宗地号或幢号层号、出让或划拨、剩余年限、规划用途、抵押、查封。版本表：正文、附件、出让合同、登记稿、宗地图/平面图、聊天确认；冲突并列。不问户口与共同居住人。

## 5. 标的、租期、登记与交付占有

标的特定化（坐落、宗地号/铺号/房号、四至、面积、附图）；租期起止是否超过二十年，是否长于土地使用权剩余年限；六个月以上是否书面；登记/备案条款是义务还是被写成生效条件；交付与占有（围墙、钥匙、场地或铺面现状图）是否足以支撑买卖不破租赁。缺口标 `G#`。

## 6. 维修、转租、押金与强制规范

维修清单是否按光地/厂房/商铺/写字楼分列，有无代修路径；转租是否须书面同意；押金金额、扣除清单、返还日；是否误用定金罚则；合同用途是否违背规划或出让合同。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。框架里把备案当生效条件、或把户口路径写进厂房/商铺/写字楼、或把房屋优先购买写进光地的写法不得直接当作建议句。

## 9. 谈判与签署提醒

谈判顺序：先红线（类型错位拒转、超二十年拒改、登记卡死生效、整锅包修、押金当定金罚没、未占有仍对抗、划拨未批准、倒签），再必须改（标的特定化、维修清单、转租同意、买卖不破租赁占有条件），最后可优化。签署提醒：登记权利人签署、出让合同或划拨批准附件、交付/占有凭证、登记配合义务、日期与拟交付日。不指导倒签或补假批准。不把户口、居住证、入学列入本类型签署清单。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本任务先出草稿，再按本类型硬闸自审；不得只交白稿。不是履约交底、争议文书或效力保证。
