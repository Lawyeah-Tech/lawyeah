# 建筑设备租赁合同·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **建筑设备租赁合同** 己方稿，出稿后用本类型硬闸自审。交付草稿、未决项、自审风险表和自审后修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文显示名为「建筑设备租赁合同·起草」。

`depends-on` 为空。不要求先跑导航。

不交付：他类起草、待签文本签前审查、履约交底、争议文书、有效性保证、把施工/融资租赁/一般动产/房屋整案改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **塔吊等设备进退场**：进场单、共同检尺或过磅、影像、指定签收人、异议期。禁止出租人单方目测扣量。租期自进场签认起至退场验收止，不得写成“包租到工程竣工”。
2. **操作人员**：先标明干租或湿租。湿租须写人员工种、建设主管部门特种作业资格、劳动关系归属和工伤保险用人单位。禁止“由承租人自行招用但挂出租人牌子”。法定安全生产责任不得一揽子转给对方。
3. **损坏**：正常损耗不赔；违章或保管不善才赔。须共同选定检测机构并扣除残值。禁止“按新品全额赔偿且赔偿期间租金照付且不鉴定”。不可归责于承租人的毁损灭失，不得套用融资租赁“仍须继续付租”。
4. **与施工/融资租赁切开**：指定购买+租金覆盖购价+到期归属或留购 → 负触发 `融资租赁合同·审查`（未装则 `unavailable`）。包安拆、包顶升、包吊装或某部位工程量、按形象进度或竣工验收计酬 → 负触发 `的method。`；无资质以租赁包装施工的，只告知、不改写成可履行分包。不得把招标黑白合同、质保金比例或房屋备案/优先购买当作本类型主路径。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿，尚未签署，尚未成争，核心给付是交付工地设备或周转材料供使用并收取租金（可附带操作人员但不包施工部位成果）。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 已有可读待签文本要评改 → `建筑设备租赁合同·审查`；
- 包安拆包使用包工期、按工程量或形象进度计酬 → `的method。`；不得删工程量后硬套本技能；
- 出租人按承租人指定向出卖人购买设备、租金含购价本息、到期留购或归属承租人 → `融资租赁合同·审查`（未装则 `unavailable`）；
- 先卖后租、承租人与出卖人同一 → `售后回租合同·审查`（未装则 `unavailable`）；
- 家具家电、乘用车、办公设备等非工地动产 → `动产租赁合同·审查`；
- 房屋、商铺、厂房出租 → `房产租赁合同·审查`；光地 → `不动产租赁合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问进场日、对账、退场留痕 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁（含倒塌索赔） → `或对应专项领域。` 或建设工程争议领域。

无证、淘汰、超期未检设备出租，或以租赁之名做无资质安拆/专业分包：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（出租人侧或承租人侧择一）；相对方；全文及设备清单/进场单/赔偿单价表/安全协议版本；干租或湿租；设备名称、出厂编号、备案与检验痕迹；安拆主体与资质；操作人员劳动关系与持证；进退场计量方法；损坏鉴定安排；付款人是否与签约承租人一致；是否包工程量或指定购买留购；不可接受事项；法域与拟签署日。缺立场或本类型条件未谈妥则不启动起草。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的租金、数量、单价、期限用 `【待填】`，不编造。

## 起草模式

本原子只承担本类型起草。待签评改转 `建筑设备租赁合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 进场单：共同检尺或过磅、影像、指定签收人、异议期。
- 租期自进场签认起至退场验收止。
- 先标明干租或湿租；湿租写人员工种、建设主管部门特种作业资格、劳动关系归属和工伤保险用人单位。
- 损坏：正常损耗不赔；违章或保管不善才赔；共同选定检测机构并扣除残值。

### 附件必附

- 进场单、检尺／过磅记录、影像。
- 湿租时特种作业资格与工伤保险用人单位材料。

### 禁止出现

- 出租人单方目测扣量。
- “包租到工程竣工”。
- “由承租人自行招用但挂出租人牌子”。
- 法定安全生产责任一揽子转给对方。
- “按新品全额赔偿且赔偿期间租金照付且不鉴定”。
- 不可归责于承租人的毁损灭失仍须继续付租。
- 指定购买＋租金覆盖购价＋到期归属或留购。
- 包安拆、包顶升、包吊装或按形象进度／竣工验收计酬；无资质以租赁包装施工。
- 招标黑白合同、质保金比例或房屋备案／优先购买主路径。

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

### 0. 签署状态与成果分流

有完整待签文本要评改 → `建筑设备租赁合同·审查`；本类型条件已谈妥要出己方稿 → 本任务起草并自审；已签履约 → 本套导航履约步骤；已成争 → 合同争议。本类型条件已谈妥要出己方稿，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。施工成果承包、融资租赁、非工地动产、房屋负触发。

### 2. 主体、产权与安拆资质

签约名、项目公司、付款名、发票名分列。安拆单位须有相应资质和安全生产许可证。中登网负担未核：字段停止。

### 3. 设备特定化与适租

编号、备案、检验、禁止出租情形。无证或检验不合格：停笔或红线拒收。

### 4. 进退场计量

共同计量、书面签认、异议期。禁止单方目测。

### 5. 操作人员与安全责任

湿租劳动关系、持证、工伤；不得一揽子转嫁法定义务。

### 6. 损坏、维修与停租

鉴定、残值、正常损耗不赔；不可归责事由减租；不得套融资租赁继续付租。

### 7. 租金、停置、背靠背与格式条款

台班与日历日不得混用；停置费封顶；无限背靠背必须改。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；条件未谈妥仍要出整稿；用户坚持倒签进场日、保证有效、把无证/淘汰设备、以租代包、人身免责或新品全额且不鉴定改成可履行结构。
- `字段停止`：法域、动态规则、检验/备案文号、安拆资质、中登网负担、大型/中小企业身份未核验。
- `目标停止`：主目标已变为评改待签文本（转 `建筑设备租赁合同·审查`）、履约交底、争议文书，或已锁他类。
