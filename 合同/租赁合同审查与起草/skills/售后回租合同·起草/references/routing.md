# 边界与路由

本技能只起草 **租赁合同 / 售后回租合同**。

必须同时读出：卖方与承租人是同一人、买方与出租人是同一人；存在转让价款付给承租人的买卖／转让安排；承租人在转让后继续占有使用并支付租金。标题叫“售后回租”但正文是出租人向第三人采购，或只是普通卖房后再按月租住、并无融物融资架构的，不得留在本技能做实体结论。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或标题回租、核心给付明显不是先卖后租 | 本套导航的类型切开步骤 |
| 出租人按承租人指定向第三人购买；购货款付给厂商／出卖人；承租人验收即拟制出租人交付；质量索赔权转让给承租人 | `融资租赁合同·审查` |
| 已有动产占有使用换租金，无转让价款、无主体重合买卖 | `动产租赁合同·审查` |
| 房屋或场地占有使用换租金，无融资转让闭环 | `房产租赁合同·审查` 或 `不动产租赁合同·审查` |
| 个人住房卖给机构或个人后再按月租回居住，无还租表本息、无融物融资架构 | `可独立居住的商品房预售或现售，无强制统一经营→`／`或` 与 `房产租赁合同·审查` 分别处理；适用 20 年、优先购买、买卖不破租赁，不套融资租赁加速到期 |
| 产权式商铺固定或保底回报、售后包租经营 | `产权式商铺租赁合同·审查` |
| 出租人按指定建设后再出租 | 定向建设租赁对应原子；专业版未装则 `unavailable` |
| 真实意思只是担保借款，财产形式上过户并回购；合同写所有权仅作担保 | `或` 或 `或` |
| 不转移所有权，只办抵押 | `不转移所有权的抵押→` |
| 名为投资、联营、咨询但无先卖后租结构 | `租赁物不存在低值高买租金严重偏离成本与合理利润出租人从未取得所有权→` |
| 只卖设备或房屋、不租回 | `到期必买租金冲抵购机款` 或对应买卖原子 |
| 已有可读待签文本要评改 | `售后回租合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、问起租、还租、登记、回购日 | 本套导航的履约步骤 |
| 已成争 | 合同争议专项；不写起诉状或仲裁申请 |
| 用户只要利率或税额终局数字 | 测算技能或人工精算；本技能只审条款 |
| C 端大众材料整理 | 只分流，不回改 |

专业版未收录的 P1 场景不会安装本原子。若用户拿本类型文本来找专业版：输出 `unavailable`，提示，不得用直租或普通租赁硬套。

同一文本既有承租人自有设备的转让回租，又夹带向第三人新购一批设备的直租：回租专章可继续审，直租专章交接 `融资租赁合同·审查`；用户坚持整案按本技能改完则目标停止。不得删掉第三人买卖条款后硬套。标题写“融资租赁”、正文全是自有物出售并租回：留本技能并记录标题冲突。

挂靠、伪造评估或清单、倒签过户或登记、把无物／查封物／禁止流通物改成可履行、把流质改成可归己：停笔告知，不改写成可履行文本。

禁止在正文写半截 Skill ID。转出时必须写完整 ID，例如 `融资租赁合同·审查`、`房产租赁合同·审查`、`动产租赁合同·审查`、`或`、`不转移所有权的抵押→`。
