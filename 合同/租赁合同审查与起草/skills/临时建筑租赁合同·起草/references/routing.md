# 边界与路由

本技能只起草 **租赁合同 / 临时建筑租赁合同** 的待签文本。中文展示名是「临时建筑租赁合同·起草」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 已竣工验收的永久房屋，产权证／优先购买／住宅或商业房产租赁主轴 | `房产租赁合同·审查`。不得删掉永久房屋条款后按临建审完，也不得把本技能改成房产租赁审查 |
| 无任何建筑的光地、建设用地占用 | `不动产租赁合同·审查` |
| 农地承包、流转、种植养殖用地 | `农村土地承包经营权租赁合同·审查`／`土地经营权流转合同（出租类）·审查`／`农村土地租赁合同·审查`。专业版未装则 `unavailable`，不得硬套本技能 |
| 塔吊、脚手架、发电机等建筑设备进退场 | `建筑设备租赁合同·审查` |
| 一般动产租赁 | `动产租赁合同·审查` |
| 争点只是定期或不定期形态，标的不是临建 | `定期租赁合同·审查`／`不定期租赁合同·审查` |
| 融资租赁、售后回租、产权式商铺 | `融资租赁合同·审查`／`售后回租合同·审查`／`产权式商铺租赁合同·审查`。专业版未装则 `unavailable` |
| 只撮合租赁或买卖、收中介费 | `主给付是居间报酬或带看成交→` |
| 房屋买卖本约 | `可独立居住的商品房预售或现售，无强制统一经营→` 或 `或` |
| 已有可读待签文本要评改 | `临时建筑租赁合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、只问交租、续期或拆除进度 | 本套导航的履约步骤 |
| 已成争，或用户要强制拆除／腾退诉讼策略 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

临建正文里夹带一小段可拆除装修或房屋租赁备案：可审“备案≠规划批准、装修可拆除”；永久房屋产权过户或优先购买成为主给付则交接 `房产租赁合同·审查`。夹带一小段光地占用：专条交接 `不动产租赁合同·审查`，批准、租期、拆除条款可继续审。用户坚持本技能把房产租赁、光地或设备整案改完：`目标停止`。
