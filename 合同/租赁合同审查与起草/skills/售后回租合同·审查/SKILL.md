# 售后回租合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其融资租赁章、2014 年融资租赁解释未修正文本、《物权法》《担保法》及其解释、1991 年利率旧四倍、2015 年 24%／36% 当作现行规则。不得把本约写成必然构成融资租赁、必然是借贷、必然有效或必然可取回。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、利率上限或对抗效力保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **售后回租合同** 的待签文本：承租人将自有物出售给出租人，再租回占有使用并支付租金。输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文显示名为「售后回租合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查、从零起草、履约交底、争议文书、有效性或必然取回保证、直租融资租赁整案、普通房屋买卖+租住整案、让与担保或抵押贷整案、可履行无物或流质归己结构。

## 工作边界

正触发：已有可读待签文本要评改，；尚未签署，尚未成争；核心给付是先卖后租——卖方与承租人同一、买方与出租人同一，转让价款付给承租人，物不移动或占有改定后继续由承租人使用。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 出租人按承租人指定向**第三人**购买租赁物，购货款付给第三人 → `融资租赁合同·审查`；
- 已有动产占有使用换租金、无转让价款闭环 → `动产租赁合同·审查`；
- 房屋或场地占有使用换租金、无融资转让闭环 → `房产租赁合同·审查` 或 `不动产租赁合同·审查`；
- 个人住房卖给对方后再按月租住，无融物融资架构、无还租表本息结构 → 买卖 `可独立居住的商品房预售或现售，无强制统一经营→`／`或` 与房产租赁 `房产租赁合同·审查` 分别处理；
- 产权式商铺固定／保底回报 → `产权式商铺租赁合同·审查`；
- 真实意思只是担保借款，财产形式上过户并回购 → `或` 或 `或`；不转移所有权的抵押 → `不转移所有权的抵押→`；
- 类型未定或名实两可 → 本套导航的类型切开步骤；
- 无文本、本类型条件已谈妥、要出己方稿 → `售后回租合同·起草`；
- 已签只问起租日、还租日、登记日 → 本套导航的履约步骤；
- 已成争（催告、解除、取回、索赔、诉讼仲裁）→ 合同争议专项。

挂靠、违法分包、规避限购、伪造评估或清单、把无物／查封物／禁止流通物改成可履行：只出告知，不改写成可履行结构。

专业版未收录本 P1 原子时：输出 `unavailable`，提示，不得用直租或普通租赁硬套。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成。每一闸必须给出修改句或明确转出口径，禁止只打红黄绿。

1. **先卖后租**。首部用括号标明卖方＝承租人、买方＝出租人。鉴于写明“为盘活存量资产，承租人将其自有租赁物出售给出租人并租回使用”。必须同时有转让条款（标的、转让价款、支付日、所有权转移时点、占有改定、瑕疵担保）和回租条款（起租日、租期、还租表）。付款对象是承租人自己。修改句补身份重合、占有改定和“登记或过户完成作为支付转让价款的条件”。把付款写成付给第三人厂商：负触发 `融资租赁合同·审查`，不在本任务改完。
2. **名买卖实借贷**。对照标的性质、价值、租金构成和权利义务综合判断，不得只因主体重合否定融资租赁，也不得只因标题肯定。出现无物、无法特定、低值高买、租金只反映本息且出租人从未取得所有权、资金空转、合同写“本买卖不真实／所有权仅作担保”：红旗。虚构租赁物不得改成可履行回租。删除自我定性担保句。被穿透后按实际关系清算，保证范围必须覆盖“无论主合同被认定为融资租赁或借款”。利率上限运行时核验，禁止默写 24%／36%／旧四倍。
3. **与融资租赁切开**。正像是承租人自有物先卖后租。对价绑第三人买卖合同、指定厂商、购货款付给出卖人、承租人验收即视为出租人交付、质量索赔权转让给承租人行使 → `融资租赁合同·审查`。禁止打开或复制该原子 method，禁止把直租三方结构改写成售后回租，也禁止把售后回租改写成向第三人采购。

附加必落句（有事实则单列，无事实在缺口节说明）：

- **占有改定**：自转让价款支付或登记完成时出租人取得所有权，承租人改为基于融资租赁占有；删除“不转移所有权”。
- **登记／过户**：不动产写产权证号和过户义务；特殊动产和中登网／动产和权利担保统一登记由谁申请、费用、完成前是否放款。建议登记完成作为放款条件。未登记不得写成已可对抗善意第三人，也不得写成合同未生效。
- **价款勾稽**：还租表本金合计对上转让价款（扣保证金的要勾稽）。两套价值（评估 10 万、对价 100 万）无解释：红旗。
- **期满回购**：名义价款、回转登记时限、税费；提前回购按剩余本金＋利息＋约定违约金，避免重复计算。付清后不办回转：必须改。
- **取回清算**：因占有不变动，写现场控制与停产配合；取回后评估、抵债、多退少补。禁止既保留物又主张全额租金且不清算。
- **保证覆盖**：保证范围包含被认定为借款时的本息；主合同被识别为借贷后不得当然脱保。

必须有修改句。每个风险回链文本位置。禁止复制 `融资租赁合同·审查`、`房产租赁合同·审查`、`或` method。

## 建立审查坐标

确认：使用者与授权；单方立场（出租人／买受人或承租人／出卖人，或保证人）；相对方；转让合同与融资租赁合同及还租表／评估／清单／决议附件版本；租赁物种类与权属；付款对象；拟办理的登记种类；回购安排；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口，不代替节点。

0. 签署状态与成果分流
1. 类型识别与单目录加载（先卖后租；切开直租）
2. 主体重合、权属与处分权
3. 租赁物特定化、评估与转让价款（名实）
4. 两合同、占有改定与过户／登记
5. 租金、还租表与期满回购清算
6. 名实改判、让与担保自我定性与保证覆盖
7. 取回、第三人善意取得与强制规范
8. 按框架六步出修改句

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造评估、假清单、倒签过户或登记日；把无物、查封物、禁止流通物改成可履行；把“所有权仅作担保”改成可过户归己且不清算；保证必然有效或必然取回；坚持用 24%／36%／旧四倍出利率结论且拒绝核验。
- `字段停止`：法域、权属、评估匹配、登记／过户、名实定性、利率上限未核验。
- `目标停止`：主目标已变为从零起草、履约交底或起诉状，或用户要把本约改成直租、普通租赁、真实买卖或抵押贷本约。

生存级生产设备不过户即放款且用户拒绝升级：停止“可以签署”建议。
