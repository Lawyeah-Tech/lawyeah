# 审查方法（锁定 租赁合同 / 售后回租合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止打开或复制 `融资租赁合同·审查` 的直租三方采购、向出卖人付款、承租人验收=出租人交付、质量索赔权转让主路径，禁止复制 `房产租赁合同·审查` 的备案／优先购买／20 年主路径，禁止复制 `或` 的让与担保买卖户口／网签主路径。

定性校验：核心给付是承租人将自有物出售给出租人并租回使用，卖方与承租人同一、买方与出租人同一，才继续；明显他类则负触发，不填十节实体结论。

本文件是可执行判断节点，不是栏目说明书。每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然构成融资租赁、必然是借贷、必然有效或必然可取回。

`search_law` 返回已失效《合同法》及其融资租赁章、2014 年《最高人民法院关于审理融资租赁合同纠纷案件适用法律问题的解释》未修正文本、《物权法》《担保法》及其解释、1991 年利率旧四倍、2015 年 24%／36%、失效外商投资租赁业管理办法时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。2014 年《金融租赁公司管理办法》对金融租赁公司应以 2024 年同名办法为准，不得与 2024 办法并列当现行。

示范文本只参考结构。写“所有权仅作担保”“本买卖不真实，仅为融资”“到期不回购则财产归出租人且不再清算”的范本与本类型硬闸冲突，不得当规则。回租式融资租赁范本、汽车售后回租范本只借栏目（转让、租回、还租表、回购），不粘贴充作本约。

知识库口径冲突以本方法为准，不回写知识正文：

- `基本面.md` 写售后回租“是融资租赁的特殊形式”：法律性质上可以这样说，但本技能仍与直租原子切开；不得据此打开 `融资租赁合同·审查` method，也不得把向第三人采购改成本类型。
- `基本面.md` 写“不能因主体重合就否定融物”：正确方向；同时禁止走到另一极端，把无物、低值高买、不过户资金空转也写成当然融资租赁。
- `基本面.md` 写普通租赁 20 年上限不是售后回租的核心尺度：正确；租期仍应匹配融资期限和资产剩余寿命，不得改成可任意 40 年且不解释。
- `框架.md` 写“保险、维修、风险与直租相同，由承租人承担”：回租项下承租人作为原所有权人／出卖人，维修和瑕疵首先是其自己的物；不得据此复制直租的“出租人对第三人出卖人不承担责任＋索赔权转让”主句。
- `框架.md` 允许保留“放款／借款”融资表述：可以，但必须对应“支付转让价款”，不得只剩借款而无物。

开发窗口 2026-08-18 已核验、可供对照但不得代替运行时核验的规则：

- 民法典第七百三十五条：融资租赁合同是出租人根据承租人对出卖人、租赁物的选择，向出卖人购买租赁物，提供给承租人使用，承租人支付租金的合同。
- 民法典第七百三十六条：内容一般包括租赁物名称数量规格、租期、租金构成与支付、届满归属等；应当采用书面形式。
- 民法典第七百三十七条：当事人以虚构租赁物方式订立的融资租赁合同无效。
- 民法典第七百四十五条：出租人对租赁物享有的所有权，未经登记，不得对抗善意第三人。
- 民法典第七百四十七条：租赁物不符合约定或使用目的的，出租人原则上不承担责任，但承租人依赖出租人技能确定或出租人干预选择的除外。回租项下承租人即出卖人，本条通常不是主路径。
- 民法典第七百四十八条：出租人应保证承租人对租赁物的占有和使用；无正当理由收回或妨碍占有的，承租人可请求赔偿。
- 民法典第七百五十一条：承租人占有期间租赁物毁损、灭失的，出租人有权请求继续支付租金，但法律另有规定或当事人另有约定的除外。不得套用普通租赁第七百二十九条当然减租。
- 民法典第七百五十二条：承租人经催告后在合理期限内仍不支付租金的，出租人可以请求支付全部租金，也可以解除合同、收回租赁物。二者择一。仅在名实通过、构成融资租赁时适用；被改判借贷后不得再套本条全额加速。
- 民法典第七百五十三条：承租人未经同意转让、抵押、质押、投资入股或以其他方式处分租赁物的，出租人可以解除合同。
- 民法典第七百五十七条：可约定届满归属；约定不明依法仍不能确定的，所有权归出租人。
- 民法典第七百五十八条：约定归承租人且已付大部分租金但无力付剩余、出租人解除收回的，超过欠付租金及其他费用的价值应相应返还。
- 民法典第七百五十九条：届满仅支付象征性价款的，视为租金义务履行完毕后所有权归承租人。
- 民法典第七百六十条：合同无效时租赁物归属有约定从约定；无约定原则上返还出租人，但因承租人原因致使无效且返还会显著降低效用的，可归承租人并合理补偿。
- 民法典第一百四十六条：虚假意思表示实施的民事法律行为无效；隐藏行为依照有关法律规定处理。
- 民法典第一百五十七条：无效、被撤销或确定不发生效力后返还或折价补偿，按过错赔偿。
- 民法典第二百二十八条：动产物权转让时当事人又约定由出让人继续占有的，物权自该约定生效时发生效力（占有改定）。
- 融资租赁司法解释（2020 修正）第一条：根据第七百三十五条，结合标的物性质、价值、租金构成及合同权利义务认定是否构成融资租赁；名不副实的按实际关系处理。
- 同解释第二条：承租人将自有物出卖给出租人再租回的，人民法院不应仅以承租人和出卖人系同一人为由认定不构成融资租赁法律关系。
- 同解释第八条：出租人决定或干预选定出卖人、租赁物时，承租人可依第七百四十四条、第七百四十七条要求出租人担责。回租项下少见，不得当主路径。
- 同解释第九条：逾期租金或迟延付款，可依约请求逾期利息和相应违约金。
- 同解释第十一条：解除并收回租赁物时，损失范围为全部未付租金及其他费用与收回物价值的差额；约定届满归出租人的，还包括到期残值。汇编条号运行时重核。
- 担保制度解释第六十五条：未按约付租经催告后，可请求全部剩余租金并以拍卖、变卖所得受偿；解除收回时承租人主张物的价值超过欠付的，应一并处理。
- 担保制度解释第六十七条：融资租赁出租人所有权未经登记不得对抗的“善意第三人”范围，参照该解释第五十四条。
- 担保制度解释第六十八条：财产形式上转移至债权人名下、到期不履行则归债权人所有的约定无效，但不影响提供担保的意思；已完成公示的，只能参照担保物权清算；约定本金加溢价回购、到期不回购则归债权人的，参照该款。回购对象自始不存在的，按第一百四十六条第二款处理实际关系。
- 金融租赁公司管理办法（2024）第四条：售后回租指承租人和出卖人为同一人，承租人将自有资产出卖给出租人，同时签订融资租赁合同再租回。
- 同办法第五十二条：租赁物须权属清晰、特定化、可处置、有经济价值并能产生使用收益；不得以低值易耗品、小微型载客汽车之外的消费品，或已抵押、权属争议、查封扣押、所有权瑕疵财产作为租赁物。
- 同办法第五十三条：应合法取得所有权；依法应登记的须登记；其余应在国务院指定的动产和权利担保统一登记机构办理融资租赁登记。
- 同办法第五十六条：售后回租业务的租赁物必须由承租人真实拥有并有权处分。
- 同办法第五十七条：评购分离；建立健全价值评估；不得低值高买。
- 汽车金融公司管理办法（2023）第五十二条：汽车售后回租须真实拥有并有权处分，不得接受已抵押、争议、查封或权属瑕疵物；买入价格须有合理定价依据，不得低值高买。仅汽车金融公司回租适用。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用核心给付和对价方式定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须同时满足才正触发：

1. 一方同时是出卖人和承租人，相对方同时是买受人和出租人。
2. 存在把承租人**已有**之物转让给出租人的安排，转让价款付给该承租人。
3. 转让后承租人继续占有使用，并按还租表或租金条款支付租金。
4. 本约不是出租人向第三人采购的直租，也不是无融资架构的普通卖房再租住。

必须切开，禁止两可时灌入两套知识：

| 信号 | 归入 | 本技能动作 |
| --- | --- | --- |
| 自有设备／厂房／车辆先卖给租赁公司再租回，有转让价款和还租表 | 本类型 | 加载本目录双文件 |
| 出租人向厂商／第三人购买，购货款付给第三人 | `融资租赁合同·审查` | 负触发；不打开其 method；不按直租索赔权改回租 |
| 已有动产或房屋占有使用换租金，无转让 | `动产租赁合同·审查`／`房产租赁合同·审查`／`不动产租赁合同·审查` | 负触发 |
| 住房卖掉后再按月租回住，无本息还租表、无融物 | 买卖+房产租赁 | 负触发对应全 ID；可提示 20 年、优先购买，但不在本任务展开 |
| 所有权仅作担保、到期不还则归债权人、回购价=本金+固定利息且自始约定买卖不真实 | `或`／`或` 或本节点 6 红旗 | 若主文件仍是回租外观且用户要保留融物，留本技能做名实红旗；若用户承认只是担保借款，负触发让与担保原子 |

### 1.2 加载协议（硬闸）

本技能已锁定 **租赁合同 / 售后回租合同**。只打开 `references/基本面.md` 与 `框架.md`。禁止读其他类型目录，禁止为对照再开第二类。禁止打开 `融资租赁合同·审查`、`房产租赁合同·审查`、`或` 的 method。

### 1.3 违法结构停笔

加载后或定性中出现：指导伪造评估、假清单、复印他案设备编号、倒签过户或登记日；把不存在、已灭失、查封、禁止流通或他人之物改成可卖可租；把“所有权仅作担保、到期不还则归出租人且不清算”改成可履行归己；挂靠、出借金融牌照。

动作：

1. 交付告知：该结构可能违反强制性规定或公序良俗，不得改写成可履行文本。
2. 不写假评估、假过户、可履行无物回租或流质归己路径。
3. 风险表只保留识别依据和转出／改道提示。
4. 用户坚持“改到能放款、能不过户、能直接拿房／拿设备”：整体停止。

合规改道（补真实评估和现场盘点、先过户再放款、改抵押贷、承认借贷并核利率）只点名，不在本任务起草。

## 节点 2　主体重合、权属与处分权

1. 建主体表：承租人／出卖人、出租人／买受人、担保人、登记名义人、实际占有／使用人、评估机构、通道方、付款名、授权签字人。名称不一致不自动合并。
2. 首部必须能读出身份重合。未用括号标明的：必须改。两套主体各签各的、无法重合：字段停止或负触发引擎。
3. 承租人须对标的享有可转让的所有权。查原始发票、进口证明、产权证、机动车登记。抵押物出售须抵押权人同意并清偿或置换；材料未提及不得写成“无权利负担”。
4. 国有资产出售回租：评估、批准；上市公司重大资产出售：披露、决议。无决议：签署能力字段停止，不补假决议。
5. 出租人多为金融租赁或融资租赁公司。无牌不当然使合同无效，但监管处罚和资金来源合法性要提示；不保证有效。关联方互售互租、通道方“过一手”：并列谁出资、谁记资产，不得自动把通道方写成真正出租人。
6. 回租后占有不发生物理变化，外人更难识别所有权已转移。主体表必须分开“登记权利人”和“实际占有人”。
7. 口头“老板说已经是我们的了”不得写成已取得所有权。用户要求补假权属或假抵押权人同意：整体停止。

不足：字段停止，列出待补材料，不补已有权处分、不补已批准。

反方常见抗辩：实务中回租本来就不搬设备，不必看权属。本任务仍要求处分权和登记／占有改定可回链；解释第二条保护的是“真实回租”，不是无物空转。

## 节点 3　租赁物特定化、评估与转让价款（硬闸）

本类型对价是“转让价款换所有权 + 租金换继续使用”，不是普通租金，也不是付给第三人的购货款。

| 文本写法 | 本任务动作 |
| --- | --- |
| 无清单、无编号、无存放地，或清单复印他案 | 红旗。修改句要求现场盘点、拍照、编号拓印；未特定不得起租、不得放款 |
| 在建工程、无证违法建筑、他人财产、已设定未涤除的融资租赁物 | 不得作为干净回租物。红线改道或停止 |
| 低值易耗品、小微型载客汽车之外的消费品（金融租赁公司） | 监管红旗。修改句要求更换适格租赁物；不宣告当然无效 |
| 已抵押、权属争议、查封扣押、所有权瑕疵 | 红线。不得改成可卖 |
| 转让价款远超评估值或账面合理区间，无解释 | 低值高买红旗。调整本金或承认借贷并审查利率；不得两套价值并列不解释 |
| 无评估、出租人仅凭承租人自报价确定本金 | 必须改。独立评估；金融租赁公司还应对评购分离 |
| 软件、收费权、应收账款、不动产收益权当“租赁物” | 融物属性字段停止。提示可能被改判借贷，不在本任务改成可履行权利融资 |

禁止编造评估值、市值和成新率。材料未提及不得写成“评估已经完成”或“价款与价值匹配”。

不动产售后回租：房屋所有权应过户到出租人名下再签租回。不过户只签“所有权转让协议”的，融物弱，常被看成抵押贷款。能过户才按本类型改；不能过户：红线建议改抵押贷并交接 `不转移所有权的抵押→`，不在本任务把不过户不动产改成可履行回租。

## 节点 4　两合同、占有改定与过户／登记

顺序对照：权属调查 → 评估 → 决议 → 签约 → 付款（转让价款付给承租人）→ 登记／过户 → 起租。付款对象是承租人自己，这是与直租的关键差别。

| 文本写法 | 本任务动作 |
| --- | --- |
| 只有融资租赁合同，没有转让条款或转让合同 | 必须改。补转让标的、价款、支付日、所有权时点 |
| 只有买卖／转让，没有租回 | 负触发买卖原子，或要求补租回后重新定性 |
| 未写占有改定，只写“设备仍由承租人保管” | 必须改。明示：价款支付或登记完成时出租人取得所有权，承租人改为基于融资租赁占有 |
| “双方确认不转移所有权” | 红线删除。否则自我否定融物 |
| 不动产“视同过户／倒签过户日／先放款后视情况过户” | 红线。能过户才做；先放款后过户须把过户作成放款条件，不能拟制 |
| 动产不办统一登记、特殊动产不办登记即放款 | 必须改。登记完成作为放款条件。未登记：不得对抗善意第三人，但不因此当然无效 |
| 税会与合同不一致（不开买卖发票、出租人不记资产或应收融资租赁款） | 定性证据。修改句要求发票与会计处理与合同一致；不代做税务结论 |
| 两合同关系未写一份无效时如何返还价款、恢复登记 | 必须改 |

把批准、评估、登记写成**生效条件或放款前提**，不写成已经完成。用户要求倒签登记日：整体停止。

不得把直租的“出租人向出卖人付购货款”“承租人验收即视为出租人交付”写进本类型主句。回租没有独立第三人出卖人。

## 节点 5　租金、还租表与期满回购清算

1. 转让价款对应本金；租金＝本金摊还＋利息＋费用。还租表本金合计应能对上转让价款；扣预留保证金的，要勾稽。对不上：必须改。
2. 提前结束按剩余本金清算，并办理回转登记。只写“按未付租金全额收取”且不区分剩余本金：必须改，避免重复。
3. 期满留购／回购是回租常见闭环，不等于虚假买卖。自始约定转让无效、必定原价购回且不计使用：更像让与担保或抵押，转入节点 6。
4. 回购价＝转让价＋固定利息：可以是融资租赁，也可以是借贷，差别在物是否真实转移。用登记、评估、占有改定证明融物，不在本节点单独改判。
5. 回购价付清后的回转登记时限和逾期违约金必须落句。出租人既收齐全部分期又继续登记为所有权人：必须改。
6. 租期应匹配融资期限和资产剩余寿命。不得用普通租赁 20 年上限替代本类型；也不得无理由写成远超剩余寿命。
7. 真回租项下，经催告仍不付租，出租人可在全部租金与解除取回之间择一，不得两项同时主张。被改判借贷后本条停止。

禁止编造利率、IRR 和留购价。材料未给利率：用 `【待填】`。利率合法性字段无核验则停止。

## 节点 6　名实改判、让与担保自我定性与保证覆盖（硬闸）

综合判断，四要素：标的物性质、价值、租金构成、合同权利义务。结论只能是 `现有依据支持`／`不支持`／`依据不足`。

| 文本或事实信号 | 本任务动作 |
| --- | --- |
| 仅主体重合，但有真实物、评估匹配、占有改定、登记安排 | 不得改判借贷。修改句补强融物，不改标题粉饰 |
| 租赁物不存在、已灭失、无法特定 | 虚构租赁物红线。不改成可履行；提示可能无效，法律结论须核验 |
| 低值高买＋无评估 | 红旗。调整本金或承认借贷并核利率 |
| 租金只反映本息，完全脱离物的使用，且出租人从未取得所有权 | 红旗。按实际借贷关系提示清算，不套第七百五十二条 |
| 无交付、无过户、无登记，资金空转 | 红旗。停笔或改抵押贷／借款 |
| “本买卖不真实，仅为融资”“所有权仅作担保” | 红线删除。否则自我定性为让与担保。用户坚持保留归己且不清算：整体停止 |
| 保证合同只担保“融资租赁项下租金”，未覆盖改判借贷 | 必须改。保证范围写成“无论主合同被认定为融资租赁或借款，本息、违约金、实现债权费用均在保证范围” |
| 同一物再抵押给已经是所有权人的出租人 | 指出无意义；可改用他物抵押或保证 |

被认定为让与担保的：按担保物权规则清算，多退少补，不能既保留物又主张全额租金。本任务只改条款和转出口径，不在本技能打开让与担保买卖 method。

被改判民间借贷时：利率司法保护上限运行时核验。禁止默写银行同类贷款利率四倍、年利率 24%、年利率 36%。持牌机构不得套用民间借贷上限。核验失败则利率法律结论字段停止。

反方常见抗辩：保证人主张名为租赁实为借贷、保证范围不明。本任务把该抗辩写成必须改的保证覆盖句，不保证不会脱保。

## 节点 7　取回、第三人善意取得与强制规范

1. 因占有不变动，取回须明确现场控制、停产配合、评估机构、多退少补。只写“可自行扣押／强行拖走，损失概不负责”：红线改协商、公证或诉讼保全。
2. 取回后与全部未付租金不得重复受偿。对照解释第十一条和担保制度解释第六十五条：差额清算。无核验引文则清算法律结论字段停止，修改句草稿仍写多退少补。
3. 设备仍在承租人车间，被其卖给或抵押给他人：占有改定公示不足。对策：放款当日完成统一登记及特殊动产登记；合同写明占有改定和禁止再处分。未登记不得写成已可对抗善意第三人。
4. 保险：占有期间灭失不当然免除租金（第七百五十一条）；保险金优先清偿出租人。不得套普通租赁不可抗力减租。
5. 税费：过户税费、增值税、契税由谁承担，不动产回租必须写明，否则履行不能。不输出免税结论。
6. 一物多融：放款前日查询＋当日登记。同一设备短期内多次回租给不同出租人：红旗。
7. 强制规范：违反法律、行政法规强制性规定不一律无效。禁止用已失效“效力性／管理性”口诀。虚构租赁物、禁止流通物、伪造评估：不改写成有效履行结构。
8. 破产隔离：出租人取回权依赖所有权真实和登记。未登记时面对承租人其他债权人，取回权可能失败。不得写成“破产中必然取回”。
