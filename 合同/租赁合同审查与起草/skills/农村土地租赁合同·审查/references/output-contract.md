# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的价格、面积、期限；把已失效《合同法》及其解释、2004 年土地管理法第六十三条旧义、2018 年村民委员会组织法第二十四条写入结论；把承租人写成已取得承包权或经营权；把集体农地普通租赁按国有出让或宅基地改完。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。成果名称写「审查农村土地租赁合同（租赁合同）」。点名租的是债权性占用，不是承包经营权或土地经营权。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、2004 年土地管理法第六十三条旧义、2002 年农村土地承包法第十六条旧义、2005 年流转办法、2018 年村民委员会组织法第二十四条时记噪声，不得写入 `L#`。集体决议现行条号写 2025 年修正第二十八条和农集经组织法第二十六、六十四条。

## 3. 类型与加载路径

父级、子级、定性理由、权利层次切开结果、易混切开结果（经营权流转 / 承包经营权租赁 / 普通房屋租赁 / 国有出让光地 / 宅基地 / 入市）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读其他类型、未打开 `农村土地承包经营权租赁合同·审查`／`土地经营权流转合同（出租类）·审查` 的 method。以租代征或宅基地变相买卖写停笔告知，不填可履行结构。

## 4. 主体、授权、决议与文本版本

主体表：签约名、履行名、收款名、开票名、授权签字人、集体决议机关。决议表：会议类型（成员大会／成员代表大会／村民会议／村民代表会议／村委会代行）、时间、到会、表决比例、地块／期限／价格是否与合同一致、是否先经党组织研究讨论。版本表：正文、决议、宗地图、证照、聊天确认；冲突并列，不选对用户有利的一版。

## 5. 给付闭环

权利层次专条、地块四至地类、是否已发包或已登记、租期是否截断在二十年、用途与地类、租金与集体账户、交付／腾地、地上物、征收归属。缺口标 `G#`，不补商业数字。决议、批准写成生效条件或期限，不写成已经完成。五年登记不得写成双方义务。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹；异常条款（自动续期、个人账户、改变用途免责）。强制规范只区分是否导致民事行为无效。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔／转出口径。禁止输出无修改句的色块表。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`，不编造。禁止只给原则、不给句子。框架或基本面仍写 2018 年第二十四条时，修改句理由改引 2025 年修正第二十八条和农集经组织法。

## 9. 谈判与签署提醒

谈判顺序：先红线（权利层次、决议、二十年、用途、宅基地／入市），再必须改，最后可优化。签署提醒：决议原件、到会签名、集体印章与权利主体一致、日期、附件清单。不指导倒签或补假决议。不把国有出让审批或宅基地过户列入本类型签署清单。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本任务只出审查意见和修改句，不出整份起草终稿。出稿转 `农村土地租赁合同·起草`。不是履约交底、争议文书或效力保证。
