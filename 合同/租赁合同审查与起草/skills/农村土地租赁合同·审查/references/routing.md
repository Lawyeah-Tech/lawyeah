# 边界与路由

本技能只审查 **租赁合同 / 农村土地租赁合同** 的待签、农村土地上债权性占用文本。中文展示名是「农村土地租赁合同·审查」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或复制 `农村土地承包经营权租赁合同·审查`、`土地经营权流转合同（出租类）·审查` 的 method。集体地农地普通租赁不得按国有出让或宅基地改完。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 承包权保留、土地经营权流转、剩余承包期对接、五年以上经营权登记对抗、经营权证、向发包方备案的流转合同 | `土地经营权流转合同（出租类）·审查` |
| 把家庭承包经营权当作用益物权出租、办承包经营权证、成员内部承包经营权租赁主轴 | `农村土地承包经营权租赁合同·审查` |
| 已竣工验收的永久房屋，产权证／优先购买／户口／居住证／入学或住宅、商业房产租赁主轴 | `房产租赁合同·审查` |
| 无任何建筑的城镇建设用地或国有出让光地占用 | `不动产租赁合同·审查` |
| 设备、车辆、机器等动产特定化租赁 | `动产租赁合同·审查` |
| 争点只是定期或不定期形态，标的不是农村土地债权租赁 | `定期租赁合同·审查`／`不定期租赁合同·审查` |

| 产权式商铺、固定或保底回报、统一运营权上交 | `产权式商铺租赁合同·审查` |
| 定向建设后回租 | `定向建设租赁合同·审查` |
| 先卖后租、售后回租、承租人与出卖人同一 | `售后回租合同·审查` |
| 临时售楼处、工棚、展棚等临时建筑 | `临时建筑租赁合同·审查` |
| 集体经营性建设用地按入市方案出让或出租 | 不按本类型硬做；点名土地管理法第六十三条和土地管理法实施条例第四十一条，不代做方案 |
| 只撮合租赁、收中介费 | `主给付是居间报酬或带看成交→` |
| 施工挂靠、违法分包、资质出借为主给付 | 转工程原子或引擎重定性；只告知，不改成可履行 |
| 规避限购夹带 | 只告知并转对应原子，不据此定性本约 |
| 无文本、本类型条件已谈妥、要出己方稿 | `农村土地租赁合同·起草` |
| 已签未争、只问交租、腾地或续期 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或对应专项领域。` 或对应专项领域 |
| 村民代表诉讼否定合同、征收补偿分配、承包经营纠纷仲裁已立案 | 农地／征收／争议专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

农村土地租赁正文里夹带一小段农业用途或交租节点：可继续审。用户坚持本技能把承包经营权租赁、经营权流转、房产租赁、国有出让光地或入市方案整案改完：`目标停止`。
