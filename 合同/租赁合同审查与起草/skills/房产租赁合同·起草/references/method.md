本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制买卖商品房或二手房买卖原子的 method。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、必然对抗买受人或唯一必得金额。

`search_law` 返回已失效《合同法》及其解释、1995 年《城市房屋租赁管理办法》、担保法解释或商品房买卖司法解释时记为噪声，不得写入 `L#`。城镇房屋租赁解释引用 2020 修正、2021-01-01 施行文本；2009 年原文整份标记“已被修改”，已删除条文（含原第二十四条优先购买排除）不得当作现行法源。

示范文本只参考结构。住建或市场监管部门示范文本不证明本约条款已被接受。

知识库纠正（不回写双文件）：

- `基本面.md` 把临时建筑、产权式商铺、以租代售写进本类型辨析：本技能不审，分别转 `临时建筑租赁合同·审查`、`产权式商铺租赁合同·审查`、买卖或融资原子。

## 节点 2　主体、权属与二房东

### 2.1 主体表

建表：签约名、产权登记名、付款名、发票名、授权签字人。名称不一致不自动合并。

出租人应为不动产登记权利人或其授权人。共有：共同共有看全体同意；按份共有长期排他出租标红旗并要求同意文件。口头“配偶知道了”不得写成已授权。

国资、集体、学校医院场地：决议、评估、公开竞价未附则签署能力字段停止，不写成“可以盖章”。

### 2.2 二房东与转租链条

经纪机构、物业、资产管理公司代签必须有授权。转租人作出租：必须见到原租赁合同许可条款或单独书面同意函，否则出租人可依第七百一十六条第二款解除主合同。未见同意仍要放行装修款支付：红线。

住房租赁企业预收多期租金：标地方资金监管 `G#`，不编造监管账户。

### 2.3 承租人与证照

住房承租人资格一般不限。商铺、餐饮、旅馆、教育、医疗：合同主体须与拟办证主体一致；“保证可办任何执照”必须改成具体业态，并写办不出时的解除和费用分担。未成年人或多人合租：写明租金连带责任人。

## 节点 3　房屋特定化、用途与权利负担

### 3.1 特定化

坐落、楼层房号、建筑面积/套内面积、不动产单元号、附属储藏室/车位、平面图。只租隔间或摊位无附图：必须改。面积与权证冲突：并列，不选有利数字。

### 3.2 规划用途与安全

证载住宅/商业/办公/工业与合同用途对照。住改商须有利害关系业主同意路径，否则标履行不能风险，不保证能办营业执照。工业厂房按商场招商：必须改用途或解除条件。

支持依据：商品房屋租赁管理办法第六条——违法建筑、不符合安全防灾强制标准、违反规定改变使用性质的房屋不得出租。危房、鉴定为危险房屋：不得改成可履行放行。隔断改变消防分区：禁止建议，红线删除群租结构。

违法建筑：城镇房屋租赁解释（2020修正）第二条——未取得或未按建设工程规划许可证建设的房屋，租赁合同无效；一审法庭辩论终结前取得许可或批准的除外。本任务只告知并停止放行，不设计“先签后补证”步骤，不宣告整份无效的终局判决。

### 3.3 权利负担

抵押、查封、居住权、在先租赁、违章搭建部分。材料未提及不得写成“无权利负担”，只能写 `依据不足`。查封后新设租赁：告知执行异议规定中“查封前已签书面合同并占有”的条件，不得承诺能阻止移交占有。屋顶、外墙、广告位未点名：不视为随房出租。

## 节点 4　租期二十年截断与备案非生效

### 4.1 租期（硬闸）

支持依据：民法典第七百零五条。租赁期限不得超过二十年；超过二十年的，超过部分无效。期限届满可以续订，但续订之日起仍不得超过二十年。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 起止明确且跨度 ≤ 20 年 | 可接受或核对起算日 | 已生效 |
| 跨度 21–50 年，或写“永久租赁” | 必须改或红线：截到二十年；超过部分不计入可主张租期 | 整份当然无效；全额二十年以外租金可强制执行 |
| 签约时即约定 20 年到期后再自动续 20 年 | 续约约定必须改或删除；点名这不属于第七百零五条第二款的有效续订 | 已锁定 40 年 |
| 六个月以上无书面，或书面无法确定期限 | 第七百零七条：视为不定期；双方可随时解除但应合理期限前通知 | 已是二十年定期 |
| 租期超过土地使用权剩余年限 | 标履行不能；修改句把租期截到剩余年限或加提前终止清理 | 土地到期后租赁当然延续 |

未采用书面形式但能确定期限的，不当然视为不定期；无法确定期限才转不定期。不定期文本若用户目标是定期房屋租赁，给出改成定期且不超过二十年的修改句。

### 4.2 备案不是生效要件（硬闸）

支持依据：民法典第七百零六条；商品房屋租赁管理办法第十四条（订立后三十日内到房屋所在地建设/房地产主管部门备案，行政义务）。

| 文本写法 | 动作 |
| --- | --- |
| “本合同自登记备案之日起生效”，且无谁负责、几日内、一方拒不配合的后果 | 必须改：签字盖章后成立生效；双方应在三十日内配合备案；一方拒不配合构成违约，不得据此主张合同未生效 |
| “未备案合同无效” | 红线删除；现有依据不支持 |
| 备案信息与合同不一致时“以备案系统为准” | 必须改：对内以本合同为准；备案稿与正文冲突并列 |
| 只约定备案、不写交付占有 | 备案不代替交付；补交付条款 |

地方居住证、入学、租金贷以备案为前提的，标 `G#` 作行政后果，不上升为民事生效要件。

## 节点 5　租金、押金与定金切开

### 5.1 租金与费用

房租、物业费、水电燃气、供暖、税费、中介费分项。支付日、递增、免租期、发票分列。未给出的数字写 `【待填】`。住房租金贷、商业租金保理须披露，不得让承租人在不知情时被债权转让。

### 5.2 押金不是定金（硬闸）

支持依据：民法典第五百八十六条；合同编通则解释第六十七条。当事人交付押金、保证金、订金等但没有约定定金性质的，一方主张适用第五百八十七条定金罚则，不予支持。必须使用“定金”二字或明确丧失/双倍返还，才讨论罚则。约定或推算超过主合同标的额百分之二十的，超过部分不产生定金效力。

| 文本写法 | 动作 |
| --- | --- |
| “押金/保证金，违约即全部没收”且无定金二字 | 必须改：改为押金；列扣除项目（欠租、损坏、欠费）和搬离验收后返还日；禁止不分情节没收 |
| 收的是押金却写定金罚则或双倍返还 | 红线：删除罚则或把名称和性质改成押金 |
| 明确“定金”且金额超过租期租金总额 20% | 必须改：截到不超过 20%，或改成押金/预付租金并写明不适用罚则 |
| 高额押金（超过两至三个月）无扣除清单 | 必须改清单和返还日；承租人立场可要求降低 |

无核验引文不得把 20% 写成已核验法律结论；修改句草稿仍可按内置方法给出。

## 节点 6　维修义务与转租同意

### 6.1 维修（硬闸）

支持依据：民法典第七百零八条（保持符合约定用途）、第七百一十二条（出租人维修，另有约定除外）、第七百一十三条（合理期限维修；出租人未履行的，承租人可自行维修由出租人负担；因维修影响使用的，减少租金或延长租期；承租人过错造成的，出租人不承担）；商品房屋租赁管理办法第九条。

审查清单：

1. 是否写明主体结构、屋面、外墙、上下水主管、电梯、消防由谁负责。
2. 日常损耗（灯具、门锁、洁具）由谁负责。
3. 报修渠道、响应和完成时限是否量化。
4. 出租人未修时承租人代修、费用抵扣租金的路径。

“房屋及设施全部维修概由承租人负责”且不分结构/日常：必须改。双方约定承租人承担日常维修可以保留，但主体结构和法定适租义务不得借约定全部推脱而不留代修救济。因承租人过错或擅自拆改造成的损坏，可约定由承租人承担。

### 6.2 转租（硬闸）

支持依据：民法典第七百一十六条、第七百一十七条。经同意可转租，原租赁继续有效；第三人造成损失的，承租人赔偿。未经同意转租，出租人可以解除。转租期限超过剩余租赁期限的部分对出租人不具有约束力，另有约定除外。

| 文本写法 | 动作 |
| --- | --- |
| 禁止转租但未写擅自转租的解除权 | 必须补解除权或保持禁止并写后果 |
| “承租人可自行转租/分租/群租”且出租人未书面同意 | 出租人立场：改为须事先书面同意；承租人立场：争取书面预同意并限定人数与用途 |
| 转租期长于主租期 | 必须改：转租期末日不得晚于主合同到期日，除非出租人另行书面同意 |
| 允许床位/工位分租或改变隔间 | 住房：禁止改变承重和消防分区；群租受治安消防管制，不得改成可履行群租结构 |
| 二房东文本无原出租人同意 | 见节点 2.2；红线 |

### 6.3 装修

商铺、厂房：方案书面同意、消防报建主体、到期拆除或折价。住房：严禁承重墙改动。解释（2020修正）第六条（现行编号以当次核验为准，MCP 亦返回擅自变动承重/扩建可解除）：合理期限不恢复原状的，出租人可解除。不得把“原状返还”留成空词，须定义拆除范围和残值。

## 节点 7　买卖不破租赁、优先购买、解除与格式条款

### 7.1 买卖不破租赁条件（硬闸）

支持依据：民法典第七百二十五条——租赁物在承租人按照租赁合同**占有期限内**发生所有权变动的，不影响租赁合同的效力。城镇房屋租赁解释（2020修正）第十四条——承租人请求受让人继续履行的，应予支持，但下列情形或另有约定除外：（一）出租前已设立抵押权，因实现抵押权发生所有权变动；（二）出租前已被人民法院依法查封。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 先租后卖，且安排交付占有 | 可写受让人承继；补看房配合时段、次数 | 未交付也已对抗买受人 |
| 尚未交付即声称“买卖不破租赁” | 必须改：对抗以按合同占有为前提 | 签字当日已取得对抗效力 |
| 出租前已抵押，实现抵押权将变卖 | 标例外；不得承诺承租人当然继续占有 | 抵押权人必须保持租赁 |
| 出租前已查封 | 标例外；禁止倒签 | 查封后新租可阻却执行 |
| 允许看房、挂牌的义务缺失 | 必须补：减少履行僵局 | — |

虚假租赁、明显不合理低价或伪造租金凭证：执行异议规定第三十一条第二款作告知，不指导造假。

### 7.2 优先购买

支持依据：民法典第七百二十六至七百二十八条。出卖前合理期限通知；按份共有人行使优先购买或出卖给近亲属除外；通知后十五日内未明确表示购买视为放弃。拍卖的，拍卖五日前通知；未参加视为放弃。未通知或妨害优先购买的，承租人可请求赔偿，**买卖合同效力不受影响**。

修改句：送达地址、通知方式、同等条件定义（总价、支付期限、担保）。侵害优先购买权的救济是赔偿，不得写成“买卖当然无效”。共有人购买、近亲属、拍卖已依法通知等排除情形写清。

### 7.3 欠租解除与通知

构成违约不等于当然解除。欠租须有催告期（文本可量化十五至三十日）和解除通知送达。改变用途、违法隔断、利用房屋违法犯罪：可约定解除。出租人逾期交房、隐瞒危房、无法办理约定经营手续：对等解除。法定解除只点名，不在本任务作出已解除结论。

违约金避免“剩十一个月罚十一个月”或“不得调整”。不在本任务做第五百八十五条精算。

### 7.4 格式条款与强制规范

为重复使用而预先拟定的中介或住房租赁企业文本，按民法典第四百九十六条至第四百九十八条审查提示说明。无核验引文则法律结论字段停止。违反法律、行政法规强制性规定不一律无效，区分规范目的；禁止用已失效“效力性/管理性”口诀代替合同编通则解释第十六条。挂靠、违法分包、以合法形式掩盖非法目的：不改写成有效履行结构。

争议解决：或裁或诉、机构不明标待核。房屋租赁诉讼可能涉及不动产所在地，只标连结点，不选定唯一法院充作意见。
