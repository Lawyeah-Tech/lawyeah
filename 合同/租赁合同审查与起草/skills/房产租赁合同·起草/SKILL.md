# 房产租赁合同·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **房产租赁合同** 己方稿，出稿后用本类型硬闸自审。交付草稿、未决项、自审风险表和自审后修改句。中文显示名为「房产租赁合同·起草」。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。

`depends-on` 为空。不要求先跑导航。

不交付：他类起草、待签文本签前审查、履约交底、争议文书、有效性保证、商品房买卖规则套用。

## 本类型硬闸

1. **租期二十年截断**：租赁期限不得超过二十年；超过部分无效。修改句截到二十年，不把整份合同写成当然无效。签约时即约定“二十年后再自动续二十年”以规避上限的，续约约定不得当作第七百零五条第二款的有效续订。
2. **登记备案不是生效要件**：未办理租赁登记备案，不影响合同效力。备案写成双方在三十日内配合办理的义务；禁止“未备案合同不生效”且可由一方拒绝配合卡死生效。
3. **维修义务**：默认出租人维修并保持适租；另有约定须列出主体结构、屋面、上下水主管、电梯与日常损耗的分担和报修时限。空白“全部维修由承租人负责”必须改。
4. **转租须同意**：未经出租人同意转租的，出租人可以解除。允许转租须写同意形式；转租期限超过剩余租期的部分对出租人无约束力。
5. **押金与定金切开**：押金、保证金、订金未约定定金性质的，不得适用定金罚则，不得写“违约即没收全部押金”。真定金才核主合同标的额百分之二十。
6. **买卖不破租赁条件**：所有权变动不影响租赁，以承租人按照租赁合同**占有期限内**发生变动为前提。出租前已设立抵押权并因实现抵押权发生变动，或出租前已被查封的，不得写成当然对抗受让人或执行。未交付占有不得承诺已取得对抗效力。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿，尚未签署，尚未成争，核心给付是房屋占有使用换租金，用户要出己方稿。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 已有可读待签文本要评改 → `房产租赁合同·审查`；
- 出租人按承租人对出卖人、租赁物的选择购买并出租，租金含本息融资 → `融资租赁合同·审查`（专业版未装则 `unavailable`，提示，不得用本技能硬套）；
- 先卖后租、承租人与出卖人同一、还租计划表 → `售后回租合同·审查`（未装则 `unavailable`）；
- 土地经营权流转、承包经营权出租、农村土地对外租赁 → `土地经营权流转合同（出租类）·审查` / `农村土地承包经营权租赁合同·审查` / `农村土地租赁合同·审查`（未装则 `unavailable`）；
- 无房屋的光地、建设用地使用权单独出租 → `不动产租赁合同·审查`；
- 临时建筑、临建批准或使用期限绑效力 → `临时建筑租赁合同·审查`；
- 产权式商铺、固定或保底回报、统一运营权上交 → `产权式商铺租赁合同·审查`（未装则 `unavailable`）；
- 核心给付是房屋所有权过户换价款 → `可独立居住的商品房预售或现售，无强制统一经营→` 或 `或`，禁止用本技能或商品房 method 反过来审租赁；
- 主文件是居间/中介 → `主给付是居间报酬或带看成交→`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已成争（催告、解除、索赔、诉讼仲裁）→ `或对应专项领域。` 或 C 端房屋租赁解约分流，不代做争议文书。

挂靠、违法分包、规避限购、售后包租固定回报、查封后倒签租约：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及附件版本；房屋坐落与权证；租期与租金、押金性质；维修与转租安排；抵押查封居住权；不可接受事项；法域与拟签署日。缺立场或本类型条件未谈妥则不启动起草。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的租金、面积、租期用 `【待填】`，不编造。

## 起草模式

本原子只承担本类型起草。待签评改转 `房产租赁合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 租期起止截到二十年；届满可协商续订，自续订日起仍不得超过二十年。
- 六个月以上须书面。
- 备案为签字后三十日内双方配合办理的义务；合同不因未备案而不生效。
- 维修默认出租人；主体结构、屋面、上下水主管、电梯与日常损耗分列，写报修时限。
- 转租须同意及同意形式；转租期限超过剩余租期的部分对出租人无约束力。
- 押金写扣除清单与返还日；未约定定金性质的，不适用定金罚则。
- 买卖不破租赁以承租人按合同占有为前提；出租前已抵押实现或已查封的，不得写成当然对抗。

### 附件必附

- 产权证或房屋权属材料。
- 交付占有交接。
- 二房东转租时的原出租人书面同意或原合同许可。

### 禁止出现

- 签约时即约定“二十年后再自动续二十年”。
- “未备案合同不生效”且可由一方拒绝配合卡死。
- 空白“全部维修由承租人负责”。
- 未经同意转租却无解除权；转租超剩余租期仍约束出租人。
- “违约即没收全部押金”；未写定金二字却套定金罚则。
- 未交付占有即承诺已取得对抗效力。
- 融资租赁、售后回租、农地、光地、临建、产权式商铺或房屋买卖过户主路径。
- 倒签对抗查封、阴阳备案避税、违建／群租／售后包租固定回报。

### 0. 签署状态与成果分流

有完整待签文本要评改 → `房产租赁合同·审查`；本类型条件已谈妥要出己方稿 → 本任务起草并自审；已签履约 → 本套导航履约步骤；已成争 → 争议或租赁解约分流。本类型条件已谈妥要出己方稿，才进入本任务。

### 1. 类型锁死

标题、核心给付与房屋占有使用一致才继续。融资租赁、售后回租、农地、光地、临建、产权式商铺、买卖负触发。

### 2. 主体、权属与二房东

签约名与产权证一致；共有/配偶；转租须有原出租人书面同意或原合同明确许可。

### 3. 房屋特定化与权利负担

坐落、房号、面积、规划用途；抵押、查封、居住权、在先租赁；违法建筑与危房不得改成可履行放行。

### 4. 租期二十年与备案非生效

起止日期截断到二十年；六个月以上须书面；备案是义务不是生效条件。

### 5. 租金、押金与定金

分项列明；押金写扣除清单和返还日；未写定金二字不得套罚则。

### 6. 维修与转租

维修清单与报修时限；转租同意形式、群租隔断禁止。

### 7. 买卖不破租赁、优先购买、解除

占有条件与先抵/先查封例外；优先购买通知与十五日；侵害优先购买不否定买卖效力。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；条件未谈妥仍要出整稿；用户坚持倒签对抗查封、阴阳备案避税、把违建/群租/售后包租改成可履行结构、保证有效或必然对抗买受人。
- `字段停止`：法域、地方备案或资金监管细则、权属或转租同意未核验。
- `目标停止`：主目标已变为评改待签文本（转 `房产租赁合同·审查`）、履约交底、争议文书或买卖/融资租赁整案。

生存级预付租金或个人无限连带且用户拒绝升级：停止“可以签署”建议。
