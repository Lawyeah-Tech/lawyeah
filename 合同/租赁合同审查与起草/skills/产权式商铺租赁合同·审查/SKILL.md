# 产权式商铺租赁合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《物权法》《担保法》及其解释当作现行规则。不得把住房租赁的备案生效、居住/学区、押金定金或房屋承租人优先购买全盘当作本类型默认法。不得把客房过户与经营权同步交割的买卖路径当作本类型默认法。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **产权式商铺租赁合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文显示名为「产权式商铺租赁合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性或保底兑付保证、把普通房产租赁或产权式酒店买卖改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **统一运营**：合同必须写清业主让渡占有经营权、运营方统一占有整场/整层；业主不得自行圈占、自行招租或指定本编号铺位必须摆自己的货。交付写成「交付运营方统一占有」，禁止「先交业主再视为自营」。图纸有号、现场无隔墙的，按建筑面积份额分享整场租赁收益，不得假装独立租赁物。租期写统一经营起止日，不超过二十年；禁止「随商场永续」或签约时预约定自动续期规避二十年。超过二十年的部分无效，不得把整份合同写成当然无效。
2. **保底回报**：必须点名固定租金、保底+分成或纯分成；可分配收入、出租率、空置是否仍付、扣除项、支付日、统一收银账户须落句。删除「稳赚 / 保本 / 年化固定回报」。保底如保留，只能写成运营方的合同给付义务，不得写成投资保本；保底下调须三方书面同意。售楼补贴期必须披露来源、截止日和开发商保证期间。开发商对未竣工商铺承诺固定租金、返本或强制溢价回购：红线停笔，不改成可履行集资结构。
3. **与产权式酒店买卖切开**：核心给付是把已有或将有商铺交给运营方占有并收租金或收益，不是客房所有权转移换价款。用户交来买卖+酒店委托经营、客房过户、不得自住 → `益，不是客房所有权转移换价款。用户交来买卖+酒店委托经营客房过户不得自住→`。不得用过户与经营权同步的买卖主路径改本约，也不得把本类型租期写成不受民法典第 705 条限制。
4. **与普通房产 / 商铺租赁切开**：承租人自己经营、有明确四至、独立优先购买的住房或普通商铺租赁 → `房产租赁合同·审查` 或引擎。不得把未备案写成未生效，不得把居住、学区、押金定金做成主路径，不得把房屋承租人优先购买套给全体小业主。买卖不破租赁保护的是按租赁合同占有整场的运营方，不是每位虚拟摊位业主。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签统一租赁、委托经营或商业管理正文，尚未签署，尚未成争，核心给付是业主将分割商铺交给统一运营方占有经营并取得租金或收益，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 普通住房或独立四至商铺租赁，承租人自己经营 → `房产租赁合同·审查`；
- 主给付是酒店客房买卖过户并强制委托经营、买受人不得自住 → `益，不是客房所有权转移换价款。用户交来买卖+酒店委托经营客房过户不得自住→`；
- 可独立居住的商品房预售或现售，无强制统一经营 → `可独立居住的商品房预售或现售，无强制统一经营→`；
- 融物+融资、出租人取得所有权再出租 → `融资租赁合同·审查`；
- 卖后再租回本息表 → `售后回租合同·审查`；
- 主给付是居间报酬或带看成交 → `主给付是居间报酬或带看成交→`；
- 无文本、本类型条件已谈妥、要出己方稿 → `产权式商铺租赁合同·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁，或保底停付要争议策略 → `或对应专项领域。` 或对应专项领域。

未竣工售后包租、返本销售、强制溢价回购、公开承诺保本吸收不特定对象资金、规避限购：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（小业主侧、开发商侧或运营方侧择一）；相对方；统一租赁/委托经营及购房合同、平面图、收费标准、保证函、业主公约、收益模型版本；标的是否开放式卖场铺位；铺位能否特定；业主是否已取得或将取得产权；是否竣工；收益模式；开发商是否承诺包租或强制回购；运营方是否作为当事人签章；统一经营起止日；不可接受事项；法域、项目所在地与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验租赁期限二十年、备案非生效、房屋承租人优先购买主体、格式条款、定金上限、强制规范、售后包租禁令、广告投资回报、非法集资定义；`search_practiced` 只补审查反例；`search_template` 只借统一租赁/委托经营栏目结构。不虚构案件系统。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `产权式商铺租赁合同·起草`；已签履约 → 本套导航履约步骤；已成争或保底停付争议策略 → 合同争议。未签且目标是评改已有产权式商铺统一租赁/委托经营文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。普通自营租赁、酒店客房买卖、商品房个卖、融资租赁、售后回租、中介负触发。

### 2. 统一运营与铺位特定

让渡占有经营权、交付运营方、业主不得自营、虚拟铺位按份额分收益、租期不超过二十年。

### 3. 三方主体与运营方

业主（应与购房人/产权人一致）、开发商、运营方分列。预售阶段产权人仍是开发商的，三方签署。缺运营方签章：字段停止。

### 4. 保底回报与售后包租

固定/保底/分成切开；未竣工包租或返本/强制回购停笔。

### 5. 转让承继与优先购买

受让人必须加入本合同；优先购买只给依法应享有的人，不得写成全体小业主互为承租人；运营方如需优先须单独对价约定。

### 6. 格式条款与强制规范

强制统一经营、放弃自营、单方调降保底、管辖等异常条款须提示说明。无核验引文则法律结论字段停止。

### 7. 违约、解除与争议

运营方停业、连续未分配、抽逃须有可执行后果。单个业主原则上无任意解除权。不选定唯一法院充作意见。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效或保证兑付、把未竣工售后包租/返本/强制溢价回购/公开保本集资或规避限购改成可履行结构。
- `字段停止`：法域、竣工状态、铺位能否特定、运营方资质、地方备案规则、收益公式未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。

生存级金额或个人无限连带且用户拒绝升级：停止“可以签署”建议。
