# 审查方法（锁定 租赁合同 / 产权式商铺租赁合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。

本文件是可执行判断节点，不是栏目说明书。每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、必然兑付保底、对方必然接受或唯一必得金额。

`search_law` 返回已失效《合同法》《物权法》《担保法》及其解释、合同法解释（二）第 14 条时记为噪声，不得写入 `L#`。不得把住房居住、学区、押金定金主路径或酒店客房过户路径当作本类型默认法。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突。

示范文本只参考结构。民法典允许参照示范文本，不证明本约条款已被接受；依据示范文本拟定且符合格式条款定义的，仍按格式条款审查。柜台租赁示范文本适用于独立柜台自营，只作负向切开。

## 节点 1　类型识别：只留产权式商铺统一经营

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。两可时禁止同时加载普通租赁或酒店买卖双文件。

| 信号 | 归入 | 排除 |
| --- | --- | --- |
| 业主已取得或将取得分割商铺所有权，把铺位交给统一运营方占有经营，自己拿租金或收益；开放式卖场、不得自行招租 | 本类型 | 普通租赁、酒店买卖 |
| 承租人自己经营、有明确四至，住房或独立商铺租赁 | `房产租赁合同·审查` 或引擎 | 不得用统一经营/虚拟铺位闸硬套 |
| 开发企业出售酒店客房并转移所有权，买受人必须把占有使用权交给酒店经营、不得自住 | `益，不是客房所有权转移换价款。用户交来买卖+酒店委托经营客房过户不得自住→` | 不得用本技能的二十年租期回写酒店经营期限 |
| 可独立居住商品房预售或现售，无强制统一经营 | `可独立居住的商品房预售或现售，无强制统一经营→` | 本类型 |
| 融物+融资，出租人取得所有权再出租 | `融资租赁合同·审查` | 本类型 |
| 卖后再租回、本息表 | `售后回租合同·审查` | 本类型 |
| 主给付为居间报酬 | `主给付是居间报酬或带看成交→` | 本类型 |
| 投资者只是承租人、并不持有也不将持有产权 | 普通商铺租赁，转 `房产租赁合同·审查` 或引擎 | 不得按产权式统一经营改完 |

封面写《投资协议》或《委托经营协议》、正文是业主让渡占有经营权、运营方支付租金或分配收益：按核心给付留本任务，标题必须补租赁要素或改为「产权式商铺统一租赁/委托经营协议」，不转普通投资或普通委托。

切开闸修改句（命中负触发则只分流，不填本句；命中名实不符但核心给付仍是本类型时必出）：

- 对 `房产租赁合同·审查`：`定位（标题/标的条）｜原文写成普通房屋租赁且允许业主自营或有独立四至自用｜建议改为：本合同为产权式商铺统一租赁/委托经营协议。标的为开放式卖场内编号铺位，业主不得单独圈占、不得自行招租。删除居住、学区、先验房自用、房屋承租人优先购买通知全体业主等表述。｜不接受则负触发普通租赁原子，不得两套知识并行`
- 对 `益，不是客房所有权转移换价款。用户交来买卖+酒店委托经营客房过户不得自住→`：`定位（给付条）｜原文写成客房买卖过户或套用酒店委托经营｜建议改为：本约核心给付为业主将已有或将有商铺交付运营方统一占有并收取租金或收益，不转移客房所有权。若当事人真实交易为酒店客房买卖并强制交经营，停止本任务，转 益，不是客房所有权转移换价款。用户交来买卖+酒店委托经营客房过户不得自住→。本约租赁期限适用民法典第七百零五条，超过二十年的部分无效。`

加载协议：只打开 `references/基本面.md` 与 `references/框架.md`。禁止为对照再开第二类。文件不可用（空、与类型明显无关）：记 `G#`，用本方法节点 2–8 继续，不编造铺号、回报率或回购溢价。

## 节点 2　统一运营与铺位特定（硬闸 1）

本节点是本类型第一道实体闸。未切开统一占有与业主自营，不得进入收益和包租审查。

### 2.1 必须分列的三件事

| 事项 | 文本必须写清 | 不得写成 |
| --- | --- | --- |
| 让渡占有经营权 | 业主将本铺位的占有、使用、招租权交付运营方统一经营；业主不得自行占有、圈占或另租他人 | 业主可自己开门做生意；铺位由业主随意收回 |
| 交付对象 | 房屋或卖场交付之日视为交付运营方统一占有的起始日 | 先交付业主再视为自营；交钥匙给业主即完成出租 |
| 铺位特定或份额化 | 产权证号或预售房号、建筑面积、附图能落地；不能落地的，按面积份额分享整场租赁收益 | 只有“概念铺”“编号自选”却按独立租赁物收租 |

效力口径（须 `search_law` 后写入 `L#`）：租赁合同是出租人将租赁物交付承租人使用、收益，承租人支付租金的合同。租赁期限不得超过二十年，超过部分无效；届满可续订，但续订之日起仍不得超过二十年。未办理租赁登记备案不影响合同效力。修改句不得用“随商场永续”或“二十年后续二十年已预先同意”代替续订。

### 2.2 经营权范围

运营方取得的是整层/整场的占有使用权：品牌引进、铺位调整、租金定价、转租、装修。业主知情权不等于否决权，但改变商业规划用途应设同意阈值。铺位调整须保留面积不减少、收益核算不受调整损害。

### 2.3 租期

统一经营起止日必须落句，并写清与购房交付日、开业日的关系。禁止「随商场永续」。`20 年+自动续期` 改为到期协商，业主大会或多数决续聘；续订期限自续订之日起仍不得超过二十年。知识里的“10–20 年”不是法定期限，数字用 `【待填】`。

期限没有约定或约定不明，依第 510 条仍不能确定的，视为不定期租赁，当事人可随时解除但应合理期限前通知。长期统一经营原则上必须写成定期，避免被识别为不定期后被单个业主随时解除。

### 2.4 修改句（本闸必出）

`定位（标的/交付/期限条）｜原文｜建议改为：甲方（业主）将本卖场内编号【待填】、建筑面积【待填】平方米的铺位（以购房合同及附图为准；若现场无永久隔墙，则按该面积占整场可出租建筑面积的份额分享整场租赁收益）的占有、使用、招租权交付乙方（运营方）统一经营。交付运营方统一占有之日为【待填，可与开业日挂钩】。未经甲乙及开发商书面同意，甲方不得自行占有、圈占、另租他人或要求在本编号铺位摆放自有货物。统一经营期限自【待填】起至【待填】止，不超过二十年；期限届满后双方协商续聘，不得预约定自动续期。铺位调整不得减少甲方面积份额，也不得降低甲方依本合同可核算的收益基数。｜理由（回链 C# / L#）｜可退让点：起算日可与竣工验收或开业日挂钩，面积份额公式可谈｜不接受时的红线：坚持业主可自行招租，或坚持永续/预约定自动续期规避二十年`

正说必须有反说。语言禁用“公寓”“可独立居住”“业主自行经营”“住房租赁备案后生效”。必须使用“开放式卖场”“统一占有”“面积份额”。

### 2.5 最强反方

- “编号在图纸上就够特定了。” → 现场无隔墙或与厕所/电梯重叠的，必须改成份额收益，不得标绿。
- “统一经营要灵活，别写死二十年。” → 超过部分无效是现行法；永续或预约定续期是红旗，不是灵活性。

## 节点 3　三方主体、产权与授权

1. 建主体表：业主（应与购房人/产权人一致）、运营方、开发商（是否保证）。签约名、产权名、购房款收款名、租金/收益付款名、发票名不一致，不自动合并。
2. 预售阶段产权人仍是开发商的，必须三方签署。过户前的“出租”是对未来权利的处分，要与购房合同联动；缺三方：字段停止。
3. 运营方必须作为本约当事人签章。仅在备注出现名称：字段停止。修改句要求披露与开发商是否关联。
4. 运营方更迭：必须预置概括转移条件，以及投资者是否有权拒绝新的保底下调。不得写成运营方可任意换壳并单方调降保底。
5. 业主立场必须改：若运营方未能按约支付保底或撤场，开发商就应付未付收益在保证期间内承担连带或差额补足。不得写成“运营方独立负责，开发商免责”且无保证期间。
6. 口头“我们老板同意了”不得写成已授权。共有业主未闭合则签署能力字段停止。

不足：字段停止，列出待补，不补主体或证号。

## 节点 4　保底回报与售后包租（硬闸 2）

### 4.1 收益模式必须点名

先识别文本采用哪一种，禁止混写“固定回报或分红，以公司通知为准”：

| 模式 | 审查动作 | 修改句重心 |
| --- | --- | --- |
| 纯分成 | 定义整场租赁总收入、可分配净利润、面积占比、审计和披露周期 | 扣除项列附件，禁止运营方单方调账；风险在业主 |
| 保底+分成 | 保底金额 `【待填】`、触发条件、空置是否仍付；保底下调须三方书面同意 | 保底是运营方合同义务，不是投资保本承诺 |
| 固定租金 | 出租人是谁、是否开发商、房屋是否竣工、是否脱离实际出租水平 | 开发商对未竣工房屋承诺固定租金 → 节点 4.2 红线 |

费用：物业、推广、能耗从租金中列支还是另收，必须点名。防止“保底 8%”被费用吃成负数还不披露。

广告、销讲、沙盘中的“年化 X%、稳赚、保本”：即使未入合同，具体确定且影响订约的，必须改写入附件或删除。房地产广告不得含投资回报承诺。修改句删除保本宣传，不得把广告回报率写成合同收益标准。

资金：租金或收益进独立账户，先税、先物业、再分配，禁止混入开发商工程款账户。发票结构（业主出租开票还是运营方代扣）未写清：标必须改，不编税负。

### 4.2 售后包租与返本（未竣工红线）

同时满足或文本支持以下结构时，按售后包租 / 返本识别：

- 开发企业以在一定期限内承租或代为出租买受人所购该企业商品房并给付固定租金的方式销售；
- 房屋尚未竣工验收（预售、在建、未取得竣工验收备案），或产权未真正分割过户即收投资款；
- 或开发企业定期向买受人返还购房款（返本销售），或约定期满强制溢价回购。

动作：

1. 风险表标 `红线`。判断：`现有依据支持` 存在销售管理办法第 11 条禁止的销售方式（部门规章；民事效力走第 153 条与解释第 16 条，不得写成“合同当然无效”）。
2. 交付告知：该结构不得改写成可履行的“换子公司签字继续包租”。产权未分割完成即收投资款的，重点转向非法集资和预售监管，而不是租赁备案。
3. 用户坚持“改到能签、先收投资款再补竣工”：整体停止。
4. 业主立场修改句不是包装合规，而是：`建议改为停止签署本约；如双方改走现售后由独立运营方按实际经营结果分配收益，须待房屋竣工验收合格、产权分割可办理并重新谈判，不得保留开发商固定租金承诺。`

已竣工：第 11 条“未竣工”禁令范围收窄，但开发商仍承诺固定租金或返本的，继续按 4.3 集资红旗审查，不自动标绿。

### 4.3 强制溢价回购与集资红旗

原文“满【待填】年按原价【待填】% 强制回购 / 无条件赎回 / 保本退出 / 随时赎回”：

- 识别为返本或约定回购外观，可能同时满足非法集资行政定义中的“销售商品活动中承诺给付货币回报”。
- 刑事四要件（未许可或借用合法形式、公开宣传、承诺回报、面向不特定对象）只作告知，本任务不认定罪名。
- 修改句：删除强制回购、保本退出和随时赎回；改为开发商或运营方在业主拟对外转让时享有同等条件优先受让权，行权期限自收到书面通知起【待填】日，逾期视为放弃。受让价按【市场评估价 / 约定公式，待填】，不得写成固定溢价必买。
- 用户要求保留强制溢价回购并面向不特定买受人公开销售：整体停止。

两年高回报后降为零：必须查补贴是否写入合同、是否有开发商保证、保证人是否还有资产。未写入的，修改句要求把补贴来源、截止日和保证期间写入附件，否则删除售楼期高回报表述。

### 4.4 修改句（回报闸必出）

`定位（对价/收益条 / 宣传附件）｜原文｜建议改为：删除“年化【X】% 固定回报 / 稳赚 / 保本 / 随时赎回”。经营收益按本卖场可分配租赁收入×本铺位面积份额计算，扣除项以附件《收益分配计算模型》列明（物业、推广、能耗不得在保底之外另扣成负数还不披露）。如保留保底，保底为乙方在【待填】日前支付【待填】元的合同义务，空置仍须支付；保底下调须甲乙及开发商书面同意。开发商对乙方应付未付款项在【待填】保证期间内承担连带或差额补足。广告及销讲中的投资回报承诺不作为本合同收益标准。收银进入【待填】独立账户，不得汇入开发商工程款账户。｜理由｜可退让点：保底金额、披露周期和保证期间可谈｜不接受时的红线：坚持开发商对未竣工房屋给付固定租金，或公开保本销售`

### 4.5 最强反方

- “已竣工，售后包租合法。” → 行政禁令收窄不等于民事无风险，更不等于无集资审查；开发商固定租金承诺仍须切开到独立运营方+保证期间。
- “解释第 16 条说部门规章不管效力，可以签。” → 可以不写“合同当然无效”，但不能改成可履行包租，也不能删掉停笔告知。
- “保底写进合同就一定能拿到。” → 保底是合同义务，不是投资保本，更不保证兑付。

## 节点 5　转让承继、抵押与优先购买（硬闸 4 的程序面）

1. 业主出售、赠与、继承商铺的，受让人必须加入本合同。未加入不得要求自营。过户或变更申请应附《统一经营承继确认书》。
2. 业主抵押须通知运营方；抵押权实现时买受人仍受统一经营约束。材料未提及抵押、查封的，不得写成“无权利负担”，只能写 `依据不足`。
3. 优先购买：
   - 房屋承租人优先购买权的权利人是按租赁合同占有房屋的承租人。本类型中真正占有整场的是运营方，不是每位虚拟摊位业主。
   - 禁止写成“全体业主互为承租人享有优先购买”。通知数百业主会导致无法处置。
   - 运营方或品牌商如需优先，必须单独约定同等条件和对价，不得冒充法定房屋承租人优先购买。
   - 出租人未通知承租人或妨害优先购买的，承租人可请求赔偿，但不影响出租人与第三人买卖合同效力。
4. 买卖不破租赁：租赁物在承租人按照租赁合同占有期限内发生所有权变动的，不影响租赁合同效力。保护对象是实际占有经营的统一运营方。出租前已抵押且因实现抵押权变卖，或出租前已查封的，不得写成当然对抗。
5. 修改句：`甲方转让本铺位的，应提前【待填】日书面通知乙方和开发商。受让人须签署《统一经营承继确认书》后，始得请求配合办理转移登记；未加入本合同的，不得自行占有或自行招租。同等条件下的优先受让如需给予乙方，行权期限为收到书面通知后【待填】日，逾期视为放弃。删除“全体业主作为承租人享有优先购买权”的表述。`

## 节点 6　格式条款、强制规范、委托任意解除

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 格式条款

开发企业或运营方重复使用的售楼附签文本、委托经营协议，订立时未与对方协商的，是格式条款。不得仅以“用了示范文本”否认。柜台租赁 2013 示范文本适用于独立柜台自营，不能证明本约不是格式条款。

强制统一经营、放弃自营、单方调降保底、铺位由甲方随意调整、收益“以公司解释为准”、最终解释权、管辖/仲裁等异常条款，须有足以引起注意的标识并按要求说明。小字、夹在附件、仅网络勾选或弹窗：不得写成已尽提示或说明义务。提供方对提示说明承担举证责任。

### 6.2 强制规范

违反法律、行政法规强制性规定不一律无效。销售管理办法第 11 条、商品房屋租赁管理办法第 6、14 条是部门规章；民事效力不得用失效“效力性/管理性”口诀代替解释第 16 条。未竣工售后包租、返本、强制溢价回购、规避限购：不改写成有效履行结构。违法建筑、不符合安全防灾强制标准的房屋不得出租：只告知，不改成可履行出租。

### 6.3 不得套用普通委托任意解除

不得把民法典第 933 条写成单个业主可随时收回铺位且无需补偿。整体经营下，单个业主原则上无任意解除权，否则卖场解体。业主任意收回须按剩余期限内可分配收益或约定标准补偿，并构成违约。解除后的铺位腾退在开放式卖场几乎无法物理实现，救济应以结算和更换运营方为主。运营方停业、连续未分配或抽逃：业主可主张解除本约并结算，开发商在保证期间内连带。

## 节点 7　违约、解除、争议解决

1. 运营方停付保底或分成、擅自调降保底、撤场、业主自行招租、一铺二租必须分别有可执行后果。只有“依法承担违约责任”视为必须改。业主自行招租：物业配合拒绝单独开门，并约定违约金 `【待填】`。
2. 构成违约不等于当然解除。本任务不作出已经解除的结论，不做违约金精算。修改句避免“不得调整”或“按总价 30% 必得”。
3. 争议解决：众多业主分散，可考虑代表诉讼或统一仲裁地，但格式条款选定须公平。不动产纠纷可能专属管辖，约定其他法院只标红旗，不假装已经选定唯一合法法院。或裁或诉、机构不明：改成单一机构或单一法院连结点。
4. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。
5. 不可抗力：商场停业用租金减免或顺延开业，不得用来永久取消保底却继续占用。
