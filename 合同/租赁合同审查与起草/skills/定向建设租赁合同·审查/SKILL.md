# 定向建设租赁合同·审查

## 任务目标

在单一立场下，只审查 **定向建设租赁合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文显示名为「定向建设租赁合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证规划或施工许可一定办成、保证预付款在业主破产时优先受偿、保证建成后必然对抗买受人或抵押权人。不交付融资租赁认定、施工发包承包整案或工程价款优先受偿安排。

## 本类型硬闸

1. **按承租人要求建设再租**：正像是签约时厂房、仓库或特种设施**尚未建成或未竣工**，土地和规划许可通常在出租人（业主）名下，按承租人工艺、荷载、层高、净化等级等要求建造，建成后按约定租金承租使用。只有“按甲方需要建设”而未落到图纸编号和验收标准的，建设段无法履行，租赁段标的不确定，必须改。承租人出资不等于成为业主，除非另约合作开发并完成土地或房屋权利变更。
2. **与融资租赁切开**：出租人根据承租人对出卖人、租赁物的选择去**购买**设备或物并融资，租金含本息 → `融资租赁合同·审查`。厂房定向建设、设备融资租赁不得混在一张还租表。禁止打开或复制 `融资租赁合同·审查` 的 method。
3. **与施工／总承包切开**：正文只有施工内容、没有未来租期和租金 → `的method。`；工程总承包主文件 → `的method。`；BT／投资建设、重点是回购移交 → `投资建设重点是回购移交→`。本约不能替代施工合同的质量、工期、保修。承租人不是当然的发包人。禁止打开或复制 `的method。`、`的method。` 的 method。
4. **租期二十年截断**：未来租赁仍受民法典第七百零五条限制，超过部分无效。预付建设资金抵租金、投资回收期写成二十五年，都不改变上限。修改句把租期自交付起截到二十年；不把整份写成当然无效。签约时预约定“二十年后再自动续二十年”不得当作有效续订。
5. **资金定性三选一并写死**：预付租金、借款＋租赁、共有或约定物权，只能锁一种。禁止“全部预付款视情况抵租金”。共有须能完成登记，否则仍是债权。未抵完如何退还、折算与抵扣顺序必须有公式。
6. **规划／施工许可生命线；违法建筑不得强制起租**：土地用途、建设工程规划许可、施工许可、竣工验收是建设段履行的生命线。未取得建设工程规划许可证的房屋，租赁按城镇房屋租赁解释（2020 修正）第二条处理；不得约定“建成即强制起租”。地还没拿到就收全额建设款：红旗，整体停止放行。
7. **交付起租＋买卖不破租赁以占有为前提**：租期自竣工验收合格＋达到约定工艺条件＋移交钥匙和竣工资料之日起算，试生产期是否计租单列。民法典第七百二十五条以承租人按合同**占有期限内**发生所有权变动为条件。只付钱不占有，不得承诺已对抗买受人或抵押权人。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签定向建设／定制厂房租赁正文，尚未签署，尚未成争，核心给付是**未建成物按承租人要求建设、建成后再出租使用换租金**，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 出租人按承租人对出卖人、租赁物的选择购买并出租，租金含本息融资 → `融资租赁合同·审查`（专业版未装则 `unavailable`，提示，不得用本技能硬套）；
- 正文只有施工、发包承包、工程价款、质量保修，没有未来租期租金 → `的method。`；工程总承包主文件 → `的method。`；
- 投资人建设完毕移交并收回投资、回购为主轴 → `投资建设重点是回购移交→`；
- 租赁物已存在，承租人只出装修款或普通占有使用 → `房产租赁合同·审查`；
- 承租人拿地建设、建成后卖给出租人再租回 → `售后回租合同·审查`（未装则 `unavailable`）；
- 建设资金接近售价且到期过户、以租代售 → `可独立居住的商品房预售或现售，无强制统一经营→` 或 `或`，本任务不审过户；
- 无地上房屋的光地单独出租 → `不动产租赁合同·审查`；临时建筑 → `临时建筑租赁合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `定向建设租赁合同·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已成争（催告、解除、索赔、诉讼仲裁）→ `或对应专项领域。` 或对应专项领域。

挂靠、违法分包、规避土地出让和规划、名为租赁实为合作开发、在农用地或科研用地上定向建生产设施、倒签对抗在建工程抵押或查封：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及附件／图纸／抵租表版本；租赁物是否尚未建成；是否按承租人要求定制；土地权利人是否为出租／业主方；资金是预付租金、借款还是投资；租期如何起算；规划／施工许可状态；在建工程抵押或查封；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `定向建设租赁合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有定向建设租赁文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与“未建成物按承租人要求建设再租”一致才继续。融资租赁、施工／总承包、BT、已建成普通房产租赁、售后回租、以租代售负触发。

### 2. 主体、土地权利人与出资定性

土地使用权人必须是出租／业主方。承租人与实际使用工厂的关联公司不是同一人的，一并列为承租人或保证人。资金定性三选一。

### 3. 未来物特定化与许可生命线

地块、规划指标、图纸、工艺验收标准；规划许可、施工许可责任主体和时点。空词“按承租人要求建设”必须改。

### 4. 资金监管、抵租与二十年

专户、形象进度、监理确认；抵租表；租期自交付起不超过二十年。一次性无监管打给业主必须改。

### 5. 验收交付、起租与试生产

竣工、消防、环保、专项工艺验收顺序；未达标准不得起租。

### 6. 权属、在建工程抵押与买卖不破租赁

建成后登记权利人；抵押须经承租人同意或抵押权人出具承认租赁与抵租资金的函；对抗以占有为前提。

### 7. 失败退出、格式条款与强制规范

许可无法取得、停建、严重质量问题的解除、返还、已完工程处置。违法建筑强制起租、农用地建生产设施、规避土地出让：停笔。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签对抗抵押或查封、地未拿到仍收全额建设款、把违法建筑写成强制起租、把二十年以上占用写成全额有效、把施工或融资租赁整案改完、保证有效或保证许可一定办成。
- `字段停止`：法域、地方预租登记或资金监管细则、许可文号、在建工程抵押时点、资金定性未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁融资租赁／施工／售后回租／普通房产租赁。

生存级预付建设款或个人无限连带且用户拒绝升级：停止“可以签署”建议。
