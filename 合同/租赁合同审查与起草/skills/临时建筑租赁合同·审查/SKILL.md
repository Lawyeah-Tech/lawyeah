# 临时建筑租赁合同·审查

## 任务目标

在单一立场下，只审查 **临时建筑租赁合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文显示名为「临时建筑租赁合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、拆除或腾退诉讼策略、有效性保证、把本约改成永久房屋／房产租赁或把无证违建改成可履行临建。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **临建许可**：标的必须是经城乡规划等主管部门批准建设的临时建筑。未经批准或未按批准内容建设的，现有依据支持认定租赁合同无效。批准文件（文号、机关、用途、面积、层数、位置、使用期限）必须入附件并与现场一致。超批准范围的夹层、罩棚按未经批准处理。房屋租赁备案不能代替规划批准。不得把“一审法庭辩论终结前补证”写成签约履行方案。
2. **期限与拆除**：租期起算不得早于批准起始，届满不得晚于批准使用期限，且不得超过二十年。超过批准使用期限的部分无效，租金只按有效期间结算。批准到期、未获延期或被责令拆除的，必须写清拆除义务人、腾退日、清运复原和逾期占用费。规划到期或合法拆除不是普通违约，也不是不可抗力。
3. **不得改成永久建筑租赁**：禁止“视同永久房屋”“补办手续后自动转为永久建筑”“办理产权证后按房产租赁履行”“20 年自动续期”。标的若已是正式规划验收房屋，负触发 `房产租赁合同·审查`。不得删掉永久化主轴后硬套本技能，也不得用本技能把房产租赁改完。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签临时建筑／临时设施租赁正文，尚未签署，尚未成争，核心给付是把经批准的临时建筑交付使用并收取租金，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 标的是已取得正式建设工程规划许可并竣工验收的房屋，或主轴是住宅／商业房产租赁（产权证、优先购买、房屋备案对抗）→ `房产租赁合同·审查`；
- 标的是无任何建筑的光地、建设用地或农地，临建尚未存在且主给付是土地占用 → `不动产租赁合同·审查` 或 `农村土地承包经营权租赁合同·审查`／`土地经营权流转合同（出租类）·审查`／`农村土地租赁合同·审查`（农地三类；专业版未装则 `unavailable`）；
- 标的是塔吊、脚手架、活动板房作为设备交付、所有权不随土地走 → `建筑设备租赁合同·审查` 或 `动产租赁合同·审查`；
- 融资租赁、售后回租、产权式商铺 → `融资租赁合同·审查`／`售后回租合同·审查`／`产权式商铺租赁合同·审查`（专业版未装则 `unavailable`）；
- 只撮合签约、收中介费 → `主给付是居间报酬或带看成交→`；
- 房屋买卖本约 → `可独立居住的商品房预售或现售，无强制统一经营→` 或 `或`；
- 无文本、本类型条件已谈妥、要出己方稿 → `临时建筑租赁合同·起草`；
- 已签只问交租日、拆除日、续期申请进度 → 本套导航的履约步骤；
- 已催告、解除、索赔、强制拆除、腾退诉讼或仲裁策略 → `或对应专项领域。` 或对应专项领域。

规划部门已明确不可补办的违建、伪造批准、规避规划：只出告知与停笔，不改成可履行出租结构。用户坚持保留：整体停止。

## 建立审查坐标

确认：使用者与授权；单方立场（出租人侧或承租人侧择一）；相对方；全文及批准文件／附图／用地批准版本；批准文号与使用期限是否可见；租期是否短于批准到期日；土地权利人与建设人是否同一；拆除义务人；是否夹带转永久或办产权证；是否已被责令拆除；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的租金、面积、期限用 `【待填】`，不编造。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`基本面.md` 中“一审法庭辩论终结前取得批准可认定有效”只是裁判规则，不得写成签约履行方案。`框架.md` 中“视同永久房屋”“补办手续后自动延长”不得写成可放行默认。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `临时建筑租赁合同·起草`；已签履约 → 本套导航履约步骤；已成争或拆除／腾退诉讼策略 → 合同争议。未签且目标是评改已有临建租赁文本，才进入本任务。

### 1. 类型锁死与永久房屋切开

标题、核心给付与对价方式一致才继续。永久房屋、光地、设备、融资租赁、中介负触发。

### 2. 主体、土地权利人与批准名义人

出租人须是批准文件上的建设人，或持有土地权利人书面同意。两分离且一方未签：该签署能力字段停止。

### 3. 临建许可、范围与安全

批准文号、用途、面积、层数、位置与现场一致。无证、超建、已被责令拆除：红线。消防与强制性标准未闭合：不得写“可以出租”。

### 4. 期限、续期与拆除

租期截在批准使用期内且≤20 年。预留腾退拆除时间。不得自动续期。拆除是预定风险。

### 5. 租金、装修与押金

预收不超过剩余合法使用期。只允许可拆除临时装修。临建短租用押金，不用定金覆盖效力风险。

### 6. 无效提示、备案与格式条款

可提示解释第三条，不得约定“未批准也有效”。备案是订立后 30 日的行政管理，不是规划批准。

### 7. 转租、所有权变动与争议

转租受批准期约束。买卖不破租赁不能对抗合法拆除。不选定唯一法院充作意见。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签或补假批准、保证必然转永久、把违建当临建放行、把诉讼补证改成可履行结构。
- `字段停止`：法域、批准文件、使用期限、土地权利人同意、地方延期细则未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书、拆除行政诉讼策略，或已锁他类。
