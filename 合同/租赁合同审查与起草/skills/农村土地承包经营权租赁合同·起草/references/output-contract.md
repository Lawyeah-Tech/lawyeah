# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然完成备案；编造未给出的租期、租金、面积、二轮到期日；把已失效《合同法》、2002／2009 年承包法同条号、2005 年流转管理办法写入结论；写「户主一人签字必然约束全体」；写「未备案则未成立」；写「乙方成为承包户」；把本约写成土地经营权流转或普通农地租赁；把城镇房屋优先购买写成农地规则。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查农村土地承包经营权租赁合同（租赁合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、2002／2009 年承包法同条号、2005 年流转管理办法时记噪声，不得写入 `L#`。2018 年承包法第三十六条、第三十八条全文未核验前不得写入 `L#`。

## 3. 类型与加载路径

父级 `租赁合同`，子级 `农村土地承包经营权租赁合同`。定性理由、易混切开结果（经营权流转、普通农地租赁、转让、集体建设用地、宅基地房屋）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准：备案不影响效力；一人签字不当然整约无效但必须补签；外部买断不在本任务改成经营权流转本约。改变用途、永久买断写停笔告知，不填可履行结构。

## 4. 主体、授权、户内同意与文本版本

主体表：承包户户主及成年家庭成员、承租人及是否本集体经济组织成员、发包方（只作备案对象，不是本约出租人）、授权签字人。地块表：承包证号或不动产权证号、坐落、四至、面积、用途、是否基本农田／永久基本农田、二轮承包到期日。版本表：正文、户内同意书、承包证、地块示意图、发包方备案表、聊天确认；冲突并列。未见户内书面同意：签署能力字段停止。

## 5. 给付闭环

租期与起算日（不得超过剩余承包期；普通租赁理解时另受二十年限制）、租金构成与青苗期折算、用途、交地与返还、再流转限制、征收与补贴归属、向发包方备案义务。缺口标 `G#`，不补年限或金额。备案、延包、登记写成义务和期限，不写成已经完成。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹；异常条款。强制规范只按民法典第一百五十三条分层，不用失效「效力性／管理性」口诀。第七百零五条超过部分无效、解释第十四条未备案不影响效力、改变农业用途，只作为修改理由，不代替修改句。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。禁止输出无修改句的色块表。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的日期和金额用 `【待填】`。禁止只给原则、不给句子。禁止写出「乙方取得承包经营权并成为承包户，租期永久，未经备案本合同未成立」。

## 9. 谈判与签署提醒

谈判顺序：先红线（永久买断、改变用途、经营权登记条款混贴、户内拒绝补签），再必须改（租期锁在剩余承包期、户内成年成员签字、备案义务、征收分配、再流转书面同意），最后可优化（租金调整、青苗折算、延包后优先协商续租）。签署提醒：户主＋成年家庭成员签字捺印；承租人是公司的由法定代表人签字；承包证复印件、户内同意书、地块示意图、发包方备案表作附件。不指导倒签或补假同意。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本任务先出草稿，再按本类型硬闸自审；不得只交白稿。不是履约交底、争议文书、效力保证，也不是土地经营权流转或普通农村土地租赁审查。
