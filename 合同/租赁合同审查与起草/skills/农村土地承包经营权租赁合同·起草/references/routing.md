# 边界与路由

本技能只起草 **租赁合同 / 农村土地承包经营权租赁合同**。主线是已取得家庭承包经营权的农户，将该用益物权项下土地出租给他人农业使用、收益。承租人不成为新的承包户。不是土地经营权流转，不是普通农地债权租赁，也不是承包权转让。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 保留承包权、流转土地经营权；五年以上办经营权登记对抗第三人 | `土地经营权流转合同（出租类）·审查` |
| 对农用地成立普通债权租赁，不设承包权或经营权 | `农村土地租赁合同·审查` |
| 承包经营权转让、过户、受让方成为新承包户 | 引擎重新定性；适用发包方同意＋本集体其他农户规则。禁止当本类型出租放行 |
| 承包地互换 | 引擎重新定性；互换双方须同集体农户并向发包方备案 |
| 已登记集体经营性建设用地出租 | `标的是已登记集体经营性建设用地出租→` |
| 宅基地上房屋出租、委托运营 | `宅基地上房屋出租或委托运营→` |
| 不动产／光地或城镇房屋租赁 | `不动产租赁合同·审查` 或对应房产租赁原子 |
| 已有可读待签文本要评改 | `农村土地承包经营权租赁合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、问交地日／付租日／备案日 | 本套导航的履约步骤 |
| 户内要地、改变用途查处、腾退已被催告、立案、开庭或仲裁 | `或对应专项领域。` 或对应专项；不填签前十节 |
| 外部主体进入、正文却写保留承包权并办经营权登记 | 负触发 `土地经营权流转合同（出租类）·审查`，不在本任务改写成流转本约 |
| 永久出租、承包权归公司、户内一人签字且拒绝补签、改变耕地用途 | 留本任务只出红线；用户坚持改成可履行则整体停止 |
| C 端大众快检或 `只分流，不回改不引用其目录` | 只分流，不回改、不引用其目录 |

专业版未收录的邻接场景不会作为本原子的实体审查对象。若用户拿这些文本来找本技能：输出 `unavailable` 或负触发路由，不得用本类型硬套。

本技能不得转去加载 `土地经营权流转合同（出租类）·审查`、`农村土地租赁合同·审查`、集体建设用地或宅基地房屋双文件完成本类型审查，也不得把经营权五年登记对抗、普通债权二十年或村民代表大会批准写成承包经营权出租的默认主路径。
