# 审查方法（锁定 租赁合同 / 不定期租赁合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制定期租赁二十年剩余租期、期满违约金、优先承租专章，禁止复制房产备案/一房数租专章，禁止复制动产点验或融资租赁第 750、752 条主路径。禁止抄 `定期租赁合同·审查` 的 method。

定性校验：标题、核心给付与期限形态一致才继续；已写清起止日、融资融物、售后回租明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、通知必然已到达，或唯一必得违约金。

`search_law` 返回已失效《合同法》租赁章（含原第 215、232、236 条）、已失效《城市房屋租赁管理办法》、已失效《经济合同法》时记为噪声，不得写入 `L#`。实务材料把第 707 条写成“口头超过六个月即不定期”、不写“无法确定租赁期限”的，记为不完整口径。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。

知识库纠正（不回写双文件）：

- `基本面.md` 尽调清单写“610 条”：规范条次是 **第 510 条**（协议补充、相关条款或交易习惯）。
- `框架.md` 把住房 30 日、厂房 60 日、设备 7 日列为通知期数字化：那是**约定示例**，不是法定固定天数。修改句用 `【待填】` 日，并写“短到无法搬离的，按合理期限认定解除生效日后移”。
- `框架.md` “视为自动续租一年”：这是定期续订拟制，与不定期互相排斥，二者只能留一个。
- 不定期本身有效。超过二十年的定期约定超过部分无效（第 705 条）；不定期项下不要虚构“剩余租期”。

## 节点 1　类型识别、三种入口与单目录加载

### 1.1 定性

用标题、核心给付、期限栏和用户陈述定性，不用标题单独定性。名实不符时按核心给付和期限可否确定归类，标题冲突写入 `C#`。标题写“定期租赁”但正文无届满日、依第 510 条仍不能确定的，以正文为准，留在本类型。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 期限空白、“长期/随时/先住着再说”，或依第 510 条仍不能确定 | 本类型（成立时不定期） | 正触发，标明入口 A |
| 拟租或已履行六个月以上，无书面也无数据电文起止日，期限无法确定 | 本类型（第 707 条拟制） | 正触发，标明入口 B |
| 原定期已届满，承租人继续使用，出租人未提出异议并继续按原标准收款 | 本类型（第 734 条默示更新） | 正触发，标明入口 C |
| 正文或微信已写清起止日，期限可以确定 | 定期租赁 | 负触发 `定期租赁合同·审查` |
| 指定出卖人/租赁物购买、融资+融物、租金覆盖购价 | 融资租赁 | 负触发 `融资租赁合同·审查`（P1 未装则 `unavailable`） |
| 同一物先卖后租回 | 售后回租 | 负触发 `售后回租合同·审查`（P1 未装则 `unavailable`） |
| 用户主轴是房屋备案、一房数租、优先购买整章 | 房产租赁 | 负触发 `房产租赁合同·审查`；期限条款可点名交接 |
| 用户主轴是动产编号点验或工地湿租 | 动产 / 建筑设备 | 负触发 `动产租赁合同·审查` / `建筑设备租赁合同·审查` |

支持切开的规范（法律结论须运行时复核）：

- 第 703 条：租赁是交付使用、收益，承租人支付租金。
- 第 730 条：期限没有约定或约定不明确，依第 510 条仍不能确定的，视为不定期；当事人可以随时解除，但应当在合理期限之前通知对方。
- 第 707 条：期限六个月以上应当书面；未采用书面且无法确定期限的，视为不定期。
- 第 469 条：数据电文视为书面形式。
- 第 734 条第一款：届满后继续使用、出租人未异议，原合同继续有效，期限为不定期。
- 第 735 条：融资租赁是根据承租人对出卖人、租赁物的选择购买后提供使用。

1. 交付告知：融资安排不适用第 730 条双方随时解除；虚假租赁不得改写成可履行收租/取回。
2. 不写可履行的随时终止融物结构、假占有路径。

## 节点 2　主体、送达与文本版本

### 2.1 主体表

建表：签约名、履行名、收款名、发票名、授权签字人、解除通知接收人。名称不一致不自动合并。共同承租时，通知应覆盖全体承租人。共同居住人不是合同当事人，但房屋搬离宽限期要写入通知期是否足够。口头“发给中介/物业就行”不得写成已到达。

### 2.2 送达（支撑硬闸 1）

解除通知必须可送达。变更地址未通知的，原地址视为有效。微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。

修改句：

「任何一方解除本合同，应向本合同载明的地址、指定邮箱或指定即时通讯账号发出书面通知。通知自【到达被通知方上述地址或进入指定系统 / 被通知方书面签收】之日为到达日。一方变更送达信息的，应在变更后【待填】日内书面通知对方；未通知的，原送达信息仍视为有效。仅向中介、物业或非合同载明接收人转述，不构成到达。」

## 节点 3　随时解除须通知（硬闸）

支持依据（运行时复核）：第 730 条；第 565 条；合同编通则解释第 53 条。

条文要点：不定期租赁双方均可随时解除，但须在合理期限之前通知。合同自通知到达时发生解除意思，解除效力时点按约定的通知期满日确定；未预留合理期限的，解除生效日后移，而不是当然认定解除权不存在。对方异议不自动消灭解除权，但须审查是否享有解除权。

| 文本写法 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| “双方可随时解除，应提前【待填】日书面通知，通知期满合同终止” | 可保留；核天数是否短到无法搬离 | 该天数是法定期限 |
| “出租人可随时收回，承租人必须租满一年不得退” | 必须改：双方均有任意解除，或改成定期 | 单方随时、对方锁死可履行 |
| “无需理由当场收回/明天搬走” | **红线** | 解除当日生效且无需通知 |
| “永久承租，任何一方不得解除” | **红线**：删除或改回第 730 条 | 该条可阻却法定解除 |
| “解除后仍须付满一年租金/优惠须退还全部已享折扣且不得调整” | 红线或必须改。合理搬迁期内租金可留；通知期满后租金不是违约金 | 通知期满终止＝违约 |
| 只给一方随时解除，另一方用天价解约金锁死，且无对价说明 | 必须改。实质上剥夺随时解除的，标强制规范风险 | 已用违约金合法取消第 730 条 |

修改句（完整随时解除）：

「本合同为不定期租赁。任何一方均可解除，但应当在合理期限之前书面通知对方。除双方另书面约定更长天数外，通知期不少于【待填】日，自通知到达之日起算。通知期内本合同继续有效，租金按原标准支付，双方仍负维修、保管和不得擅自转租等义务。通知期满日为合同终止日和租赁物应返还日。任何一方在通知期满后终止，不构成违约，任何一方不得据此主张提前退租违约金或没收全部押金。通知期短到对方无法合理搬离或取回设备的，终止日顺延至合理期限届满之日。」

对冲任意解除（合理补偿，不得取消解除权）：

「因一方依前款解除，导致对方已书面同意并实际投入的固定装修或搬家费用尚未摊完的，解除方应按附件公式补偿未摊销残值：残值＝经双方确认的投入额 ×（未使用月数 / 约定摊销月数）。该补偿不构成放弃随时解除权的对价，也不得解释为最短租期违约金。」

最强反方：解除方主张“法律写了随时，所以今天说了明天就能清场”。现有依据不支持把“随时”理解成免除通知。相对方主张“没留满约定 30 日所以解除无效”。更稳妥的审查口径是生效日后移，而不是当然无效。

## 节点 4　未采用书面超六个月视为不定期（硬闸）

支持依据（运行时复核）：第 707 条；第 469 条；第 510 条。

第 707 条是两要件，不是一句话：

1. 租赁期限六个月以上，应当采用书面形式；
2. 未采用书面形式，**并且**无法确定租赁期限的，视为不定期。

书面形式包括合同书、信件，以及能够有形表现所载内容并随时调取查用的数据电文。微信、邮件、平台确认页写清“自某日起至某日止”的，期限可以确定：现有依据不支持再按不定期维持。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 口头按月住了八个月，各方说法不一，没有任何起止日记载 | 视为不定期；修改句补书面或补起止日 | 合同无效；租赁关系不成立 |
| 微信写明“2026-03-01 至 2027-02-28，月租【待填】” | 期限可以确定。负触发 `定期租赁合同·审查`，或在本任务只出“应改走定期”的分流 | 仍按不定期赋予双方随时解除 |
| 只有口头“租一年”，无任何可调取记录 | 一年无法被第 510 条固定时，按第 707 条视为不定期；优先补书面定期 | 口头一年必然有效且不得解除 |
| 用户要求写成“口头也算定期一年，谁退谁违约”又拒绝补书面 | 必须改。维持不定期 + 通知解除，或补书面起止日 | 无书面却锁死定期违约金 |

修改句（补书面或明确拟制）：

「双方拟履行的租赁超过六个月的，应签署书面合同或保存可调取的数据电文，载明起租日和届满日。在补正之前，因未采用书面形式且无法确定租赁期限，本合同按不定期租赁履行，解除适用通知条款。任何一方不得仅以“口头说过租一年”主张对方提前退租构成违约，也不得主张本合同因未签署纸质文本而无效。」

最强反方：出租人主张“法律要求书面，所以口头租赁不成立，已收租金是不当得利”。第 707 条的法律效果是视为不定期，不是否定租赁关系。承租人主张“住过六个月就自动变成定期一年”。现有依据不支持该自动升格。

## 节点 5　租金、押金、装修、默示更新后的调价

1. **租金**  
   按月或按日写死。不定期最常见按月预付。出租人单方大幅涨租，对方不同意的，应走通知解除，不得强制新价格。继续占有并按原租金付款的，推定原标准仍适用。

2. **押金**  
   押金不作定金，除非使用“定金”二字并受第 586 条 20% 限制。押金在腾退验收后返还，不得以“你先提出解除”为由没收。通知期内可继续抵扣到期租金。

3. **装修**  
   不鼓励在不定期项下投入固定装修。已发生或必然发生的，必须有任意解除时的残值公式。否则承租人只能走损失赔偿，举证困难——标必须改。

4. **默示更新（入口 C）**  
   出租人若不愿转入不定期，必须在届满时或届满后合理时间内提出异议（拒绝继续使用、要求返还、明确收款为占用费）。继续按原标准开票收款且无异议，再主张对方逾期返还违约，难以成立。修改句删除“自动续租一年”或与不定期二选一。

修改句（调租与押金）：

「不定期履行期间，租金标准以本合同约定或最近一次双方书面确认为准。一方要求调整租金的，应书面协商；未达成一致的，任何一方可按通知条款解除，但在解除生效前，对方按原标准支付即不构成欠租。押金人民币【待填】元为履约保证金，不是定金。合同终止且承租人按约定返还、结清应付租金后【待填】日内，出租人无息返还剩余押金。一方依通知条款解除的，不得没收押金。」

## 节点 6　格式条款、强制规范、买卖不破租赁

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 格式条款

为重复使用而预先拟定、订立时未与对方协商。审查：当场收回、禁止解除、单方调价、自动续租一年、最终解释权、管辖是否有显著提示。仅电子勾选不足（解释第 10 条）。

### 6.2 强制规范

违反法律、行政法规强制性规定不一律无效（第 153 条；解释第 16 条）。禁止用已失效“效力性/管理性”口诀。剥夺第 730 条通知义务或双方任意解除的条款，不能阻却法定解除；修改句删除或改回法定结构，不在本任务宣告整份合同无效。

### 6.3 受让人与优先购买（只点期限形态，不写房产专章）

不定期租赁同样适用买卖不破租赁（第 725 条）。买受人和抵押权实现后的受让人承继的是不定期租赁，他们也可以在合理期限前通知解除，不能被原合同“不得解除”绑死，也不得“过户当日清场”。房屋出卖通知（第 726 条，十五日答复）与解除通知不要混用。优先购买、一房数租顺序的全套展开交 `房产租赁合同·审查`。

修改句（受让人）：

「租赁物所有权变动的，不影响本合同在变动前已成立的租赁关系。受让人承继的是不定期租赁，行使解除权仍须按本合同通知条款提前通知，不得以过户日或抵押权实现日作为腾退日。」

| --- | --- | --- |
| 首部 | 标题按不定期或按拟制入口写清；鉴于不写“保证租满三年”；主体与送达地址 | 标题或主体修改句 |
| 交易条款 | 入口类型；能补定期则补起止日；租金计费；押金绑腾退；交付证据；装修残值 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 双方任意解除+通知期+到达；通知期满不是违约；转租须披露主合同可随时解除；争议解决 | 可执行后果句或删除句 |
| 尾部 | 送达地址变更；签字或交付即生效，禁止“租满一年才生效”；收据/解除通知模板入附件 | 生效与附件修改句 |
| 语言 | “随时”必须带合理期限前通知；“临时/暂定”点明就是不定期；正说加反说 | 替换空词的句子 |
| 常见问题 | 把不定期当定期收一年优惠后三个月解约；通知未留期限；默示更新后主张到期违约；受让人立刻清场；融资误用随时解除 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（无需通知当场清场、永久不得解除、融资/售后回租随时终止、口头超六个月写成无效仍要放行、倒签假占有）；
- `必须改`：可谈但签署前要落句（通知期与送达、707 两要件、入口标明、押金结算、装修残值、单方调价、自动续租一年与不定期二选一）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级押金或个人无限连带且用户拒绝升级：停止“可以签署”建议。

## 版本冲突

正文、微信确认、租金收据、原定期合同、口头陈述冲突时：

1. 并列 `D#` / `C#` / `S#`，不选对用户有利的一版。
2. 修改句写明冲突项以哪一份为准，或删除冲突句。微信已写清起止日的，不得在意见里改称“双方都承认没有期限”。
3. 不得在意见里悄悄采用有利版本并称“合同已明确”。
