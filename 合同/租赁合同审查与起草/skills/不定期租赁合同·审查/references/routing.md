# 边界与路由

本技能只审查 **租赁合同 / 不定期租赁合同** 的待签文本。中文展示名是「不定期租赁合同·审查」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 正文或可调取数据电文已写清起止日，期限可以确定 | `定期租赁合同·审查`。不得删掉届满日后继续当不定期审 |
| 指定出卖人/租赁物购买、融资+融物、租金覆盖购价 | `融资租赁合同·审查`。P1：专业版未装则 `unavailable`，提示，不得用本技能硬套随时解除 |
| 同一物先卖后租回 | `售后回租合同·审查`。P1 未装则 `unavailable` |
| 用户主轴是房屋备案、一房数租、优先购买整章 | `房产租赁合同·审查`。不定期文本上的解除/通知条款可点名交接，不在本任务展开房产专章 |
| 土地或其他不动产占有使用整章 | `不动产租赁合同·审查` |
| 已有动产点验、编号、维修分列整章 | `动产租赁合同·审查` |
| 工地塔吊/钢管/脚手架并可能附带操作人员或包成果 | `建筑设备租赁合同·审查` |
| 产权式商铺、农地三类、临时建筑 | `产权式商铺租赁合同·审查` / `农村土地承包经营权租赁合同·审查` / `土地经营权流转合同（出租类）·审查` / `农村土地租赁合同·审查` / `临时建筑租赁合同·审查`（P1 未装则 `unavailable`） |
| 无文本、本类型条件已谈妥、要出己方稿 | `不定期租赁合同·起草` |
| 已签未争、只问收租/腾退/通知留痕 | 本套导航的履约步骤 |
| 已成争 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

房屋或动产上的不定期文本：期限形态、任意解除、通知期、默示更新后的结算可继续审；备案、一房数租、点验、湿租专条交接对应物的原子。用户坚持本技能把定期租约、融资租赁或售后回租整案改完：`目标停止`。
