# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、必然可强制加名、对方接受或债权人不能再追；编造未给出的金额、份额、账号、期限；把已失效《合同法》赠与章或失效婚姻法解释写入结论；写成加名即共有；把空写不可撤销当成已关闭解释（一）第 32 条；把生效离婚安排再开第 658 条；把财产制约定按赠与给任意撤销开口；把忠诚罚则改成可履行赠与；把第 658 条写成全家事给予的默认出口；把受赠人善意写成可对抗第 538 条；代填离婚诉讼房屋归属或补偿额；输出整份新协议充作审查成果。

## 1. 触发、单方立场与成果状态

立场（赠与人或受赠人或其代理人）、授权、签署状态、婚姻阶段、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查婚姻家庭中的赠与合同（赠与合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》赠与章、失效婚姻法解释，或与解释（一）第 32 条、第 69 条、解释（二）第 5 条、第 209 条冲突的口径时记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `赠与合同`，子级 `婚姻家庭中的赠与合同`。写明时间节点与给付原因定性结果，以及与忠诚协议、财产约定、离婚协议、分居协议、一般赠与的切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读其他类型、未打开邻类 method。假离婚、逃债或忠诚监控写停笔告知，不填可履行的违法结构。

## 4. 主体、共同财产、子女与文本版本

主体表：赠与人、受赠人、未签字配偶、作为受赠人的子女、代签人。处分的是个人财产还是共同财产。子女是否列为受赠人。版本表：正文、加名条款、财产约定附件、同意书、聊天确认；冲突并列，不选对用户有利的一版。本类型不造“付款名／发票名”空表充数。共有或子女主体未闭合：该字段停止。

## 5. 第 32 条窗口、加名登记与离婚生效闭环

必须分列并回链原文位置：

1. **给付原因**：个人财产赠配偶、加名共有、离婚给予、对子女给予、父母资助。
2. **解释（一）第 32 条窗口**：是否婚前或婚内一方房产赠另一方或共有；是否公证；是否已变更登记；未公证未登记则通常不能强制加名。本条不是全家事总开关。
3. **婚内加名**：拟登记权利人及份额是否数字化；加名 ≠ 已经共有。
4. **离婚安排**：是否绑定离婚登记或裁判生效；未离婚是否仍要求先过户；已生效是否误留第 658 条。
5. **解释（二）第 5 条**：只提醒离婚诉讼综合裁量，不代填归属或补偿额。
6. **逃债红旗**：大额是否上表；已知执行则停笔。

缺口标 `G#`，不补商业数字。登记、公证写成义务或期限，不写成已经完成。忠诚／财产制／离婚三块只标负触发，不输出邻类主表。

## 6. 法定撤销、穷困、身份条件与强制规范

真正赠与段落：第 663 条一年、第 664 条六个月、第 665 条返还、第 666 条仅未履行部分。已纳入生效离婚安排的，不套穷困取消或任意撤销。身份捆绑条件拆开审。强制规范只区分是否导致该条款不发生效力，不宣告整份合同有效或无效。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔／转出口径。禁止输出无修改句的色块表。

第 32 条窗口、加名登记分层、给付原因定性至少各有一行；大额必须有第 538 条行；涉及离婚给予的必须有生效条件行。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款（给付原因／第 32 条／加名份额／离婚生效／子女主体）、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`，不编造。禁止只给原则、不给句子。禁止用整份范本替换本节。禁止用忠诚罚则表、离婚三块表或一般赠与任意撤销默认表替换本节。

## 9. 谈判与签署提醒

谈判顺序：先红线（假离婚真过户、逃债、空文不可撤销却要强制加名、共同财产单方处分、给子女却登记对方、把整份改成忠诚罚则），再必须改（第 32 条窗口或公证／登记路径、加名份额、离婚生效绑定、子女列名、第 663／664／666 条通知返还），最后可优化。

签署提醒：夫妻双方签字；受赠子女或法定代理人；共有人同意书入附件；签署日、结婚／离婚日、申请登记日分开；要锁定加名则办公证或即时申请登记，不要只写不可撤销；离婚给予放进离婚协议并绑定登记；大额先做债务摸底。不指导倒签、补假公证或假离婚。不把签字写成已经取得物权。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书、效力保证，也不是忠诚协议、夫妻财产约定、离婚协议、分居协议或一般赠与审查。
