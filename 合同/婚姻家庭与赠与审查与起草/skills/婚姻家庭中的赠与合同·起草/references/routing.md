# 边界与路由

本技能只起草 **赠与合同 / 婚姻家庭中的赠与合同**。中文展示名必须是「审查婚姻家庭中的赠与合同（赠与合同）」。禁止在正文写半截场景编号。

主线：夫妻、拟婚双方或父母子女等近亲属之间对特定财产的无偿给予；先切开忠诚协议、离婚财产约定、普通赠与任意撤销主线；再逐段判断哪一段还能用第 658 条。禁止打开邻类 method。

## 正触发

已有可读待签书面文本，尚未签署，尚未成争，核心给付是婚姻家庭背景下对特定财产的无偿转移，且主文件不是忠诚协议、不是财产制约定、不是整份离婚协议、不是分居协议、不是一般赠与任意撤销主线。

典型信号：婚前把一方房产或存款赠给拟配偶；婚内加名或改为共有；婚内把一方个人财产给予另一方；对子女的给予；父母对小家庭的现金或普通动产资助写成赠与。

## 负触发

| 主要目标或文本信号 | 路由 | 不得代做 |
| --- | --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 | 不硬套本类型十节 |
| 约定婚前或婚后财产归各自／共同所有，无特定物无偿转移 | `夫妻财产约定·审查` | 不给财产制开口径任意撤销；不输出分别／共同默认表 |
| 整份自愿离婚＋子女抚养＋财产债务 | `离婚协议·审查` | 不把离婚三块改成赠与；不输出三块齐审表 |
| 分开居住、婚姻仍存续，主给付不是特定物无偿转移 | `分居协议·审查` | 不把分居安排改成赠与加名 |

## 本类型内转出（仍可先标风险再停）

- 家事赠与中夹带忠诚罚则：该块负触发 `夫妻忠诚协议·审查`，真正无偿给予块可继续；不得输出可执行忠诚罚则。
- 夹带财产制整段或离婚三块：该块负触发 `夫妻财产约定·审查` 或 `离婚协议·审查`，特定物赠与块可继续。
- 大额且存在已知债权人或执行案件：告知第 538 条，不设计逃债履行结构。
- 配偶／共有人未同意、子女未列为受赠人：签署能力或主体字段停止。
- 用户要保证有效、保证加名后不得撤销、或离婚时房屋必然归某一方：停止保证，只保留事实摘录与修改句草稿。
- 假离婚真过户：停笔，不改可履行时间表。
