# 婚姻家庭中的赠与合同·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构，不证明本约条款已被接受，也不代替本任务出整稿。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》赠与章及其解释、已失效婚姻法解释、已失效《物权法》、已失效《房屋登记办法》当作现行规则。`search_law` 或实务返回“加名即共有”“未公证放弃撤销权当然排除第 658 条”“家里写的一律可任意撤销”“家里写的一律不得反悔”“离婚诉讼必然按第 658 条撤销或必然归受赠方”一类口径时，与解释（一）第 32 条、解释（一）第 69 条、解释（二）第 5 条、民法典第 209 条冲突，记噪声，不得写入 `L#`。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **赠与合同 / 婚姻家庭中的赠与合同**，输出可编辑草稿、未决项，并在出稿后用本类型硬闸自审。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「审查婚姻家庭中的赠与合同（赠与合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类整案代审；从零起草；履约交底；争议文书；有效性或必然可强制加名的保证；忠诚罚则、离婚三块或分别财产制默认表；一般赠与“任意撤销是默认”的主路径；可履行的假离婚、逃债或包养结构；离婚诉讼房屋归属或补偿额。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **夫妻／亲属赠与 ≠ 忠诚协议**。核心给付是以违反忠实义务为触发的财产惩罚、净身出户、出轨罚款、人身监控或放弃抚养探望 → 负触发 `夫妻忠诚协议·审查`。本任务不把赠与改写成可执行的出轨罚则，也不把忠诚罚金改写成“自愿赠与”。夹带一句“出轨则收回赠与”的，身份条件可能无效，财产条款拆开审；用户坚持把整份做成忠诚协议：目标停止。
2. **夫妻／亲属赠与 ≠ 离婚财产约定**。只约定婚前或婚后所得归各自／共同／部分共同、无特定物无偿转移 → 负触发 `夫妻财产约定·审查`。整份自愿离婚＋子女抚养＋财产债务 → 负触发 `离婚协议·审查`。核心是分开居住、婚姻仍存续 → 负触发 `分居协议·审查`。已生效离婚给付不宜再开第 658 条任意撤销口；未办离婚登记或裁判未生效的，财产条款可能尚未生效（解释（一）第 69 条），不得先过户。禁止把离婚财产约定改成可反悔赠与，也禁止用赠与合同替代尚未生效的离婚安排。
3. **夫妻／亲属赠与 ≠ 普通赠与任意撤销主线**。同事、朋友之间金钱或普通动产、无婚姻家庭时间节点 → 负触发 `一般赠与合同·审查`。本技能不得把第 658 条写成一切家事给予的默认出口。只有婚前或婚内将一方房产赠与另一方或共有、且未公证、未变更登记的段落，才走解释（一）第 32 条指向第 658 条。公益、道德义务已锁定 → `公益道德义务性质的赠与合同·审查`；受赠人负担对待义务为主轴 → `附义务的赠与合同·审查`；不正当关系对价 → `涉及不正当男女关系的赠与合同·审查`；股权零元转让 → `零对价股权赠与·审查`。
4. **解释（一）第 32 条是房产加名／赠配偶的窗口，不是全家事总开关**。空写“永不反悔”“自愿放弃撤销权”通常挡不住该条。要锁定履行：公证赠与合同，或完成变更登记。禁止写成“签字即不得撤销”“签字即已经共有”。装修入住、共同还贷不当然消灭该窗口。离婚诉讼中的归属／补偿走解释（二）第 5 条综合裁量，签前不得代填。
5. **共同财产须双方签署；给子女须子女为受赠人**。处分夫妻共同财产或共同共有物须全体共同共有人同意。一方单独承诺把共同房产给对方或第三人：签署能力字段停止。受赠人是子女，不是“对方代持”。禁止把过户当作探望筹码。
6. **逃债、假离婚与法定撤销分层**。无偿转移影响债权实现的，债权人可依第 538 条撤销，不问受赠人善意。用赠与合同替代离婚协议却未办离婚、或“假离婚真过户”：停笔或整体停止。真正赠与段落保留第 663 条一年、第 664 条六个月、第 666 条穷困抗辩；已纳入生效离婚安排的给付，改走离婚后财产纠纷或执行，不走任意撤销。

## 工作边界

正触发：已有可读待签正文，尚未签署，尚未成争，核心给付是夫妻、拟婚双方或父母子女等近亲属之间对**特定财产**的无偿转移（婚前赠与配偶、婚内加名或赠与共有、对子女给予、父母对小家庭的现金或普通动产资助），用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 无忠实义务触发、只改财产制 → `夫妻财产约定·审查`；
- 整份离婚协议（自愿离婚＋子女＋财产债务）→ `离婚协议·审查`；
- 分开居住、婚姻仍存续，主给付不是特定物无偿转移 → `分居协议·审查`；
- 以出轨／不忠为触发的财产惩罚 → `夫妻忠诚协议·审查`；
- 无家事时间节点的一般金钱或普通动产赠与 → `一般赠与合同·审查`；
- 救灾扶贫助残等公益、道德义务已锁定 → `公益道德义务性质的赠与合同·审查`；
- 受赠人负担对待义务为主轴 → `附义务的赠与合同·审查`；
- 不正当关系、包养对价 → `涉及不正当男女关系的赠与合同·审查`；
- 股权零元转让、股东名册／变更登记为主给付 → `零对价股权赠与·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问过户日、转账日 → 本套导航的履约步骤；
- 已催告、撤销通知已发、索赔、诉讼或仲裁 → `已催告解除索赔诉讼或仲裁→` 或对应家事争议领域。

挂靠、违法分包、规避限购、逃债过户、假离婚真过户：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（赠与人或受赠人，或其代理人）；相对方；全文及附件版本；结婚／拟婚／拟离婚／已诉讼阶段；给付原因（个人财产赠配偶、共同财产份额调整、离婚给予、对子女给予、父母资助）；标的权属（个人／共同／按份）；是否已公证或拟公证；是否已变更登记或交付；加名拟登记权利人及份额；子女是否列为受赠人；是否夹带忠诚罚则或离婚三块；按揭或抵押；对外负债、诉讼、执行；不可接受事项；法域与拟签署日。

缺立场、同时掌握双方秘密、或无可读文本：不启动实体审查。

来源编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不选对用户有利的一版。未给出的金额、份额、账号、期限用 `【待填】`，不编造。

## 起草模式

本原子只承担本类型起草。待签评改转 `婚姻家庭中的赠与合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`，不编造。出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 写清时间节点与给付原因：婚前或婚内将一方房产赠与另一方或共有、特定物赠配偶、对子女给予。不得把第 658 条写成一切家事给予的默认出口。
- 解释（一）第 32 条只覆盖婚前或婚内将一方房产赠与另一方或共有、且未公证、未变更登记的段落。要锁定履行：公证赠与合同，或完成变更登记。
- 共同财产须双方签署；给子女须子女为受赠人，不是“对方代持”。
- 真正赠与段落保留第 663 条一年、第 664 条六个月、第 666 条穷困抗辩。已纳入生效离婚安排的给付，不走任意撤销。未办离婚登记或裁判未生效的财产条款可能尚未生效（解释（一）第 69 条），不得先过户。

### 附件必附

- 处分夫妻共同财产或共同共有物：全体共同共有人签署。
- 拟锁定第 32 条窗口：公证安排或变更登记申请安排。缺金额、份额、账号、期限用 `【待填】`。

### 禁止出现

- 把赠与改写成可执行的出轨罚则，或把忠诚罚金改写成“自愿赠与”。
- 把离婚财产约定改成可反悔赠与；用赠与合同替代尚未生效的离婚安排。
- “签字即不得撤销”“签字即已经共有”；空写“永不反悔”“自愿放弃撤销权”充当已关闭第 32 条窗口。
- 把过户当作探望筹码。
- 逃债过户、假离婚真过户的可履行结构。

8. 按框架六步出修改句：首部、交易条款（给付原因＋第 32 条＋加名份额＋离婚生效＋子女主体）、配套、尾部、语言、常见问题。

必须有修改句。禁止只打红黄绿。每个风险回链文本位置。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、保证有效或必然强制加名、把逃债过户或假离婚改成可履行文本、把共同财产单方处分改到能签、把整份改成可执行忠诚罚则。
- `字段停止`：法域、处分权、共有同意、负债全貌、公证是否办成、婚姻登记是否完成、已履行比例未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议策略，或已锁他类（忠诚协议、财产约定、整份离婚、分居、一般赠与等）。

生存级住房或已知执行案件且用户拒绝升级：停止“可以签署”建议，只列风险与转介。
