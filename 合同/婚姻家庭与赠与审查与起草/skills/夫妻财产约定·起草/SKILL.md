# 夫妻财产约定·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **婚姻家庭 / 夫妻财产约定**，输出可编辑草稿、未决项，并在出稿后用本类型硬闸自审。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。中文名必须是「夫妻财产约定（婚姻家庭）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类型起草、履约交底、争议文书、离婚诉讼策略、有效性或必然对抗第三人的保证、可履行的逃债或限制离婚结构。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **书面 + 身份**。必须书面；口头极难认定。仅合法夫妻或即将登记双方。代理代签原则上禁止。无婚姻且不准备登记 → 不是本类型。已在办离婚、文本是解除+子女+分割一揽子 → `离婚协议·审查`。修改句：口头改书面全文；即将登记写成“自完成结婚登记之日起发生本约定效力，未登记则不发生夫妻财产约定效力”；代签改为双方本人签署。
2. **对内生效 ≠ 物权变动 ≠ 对抗债权人**。约定对双方有约束力，不以过户为对内生效要件。不动产/股权对外仍须登记才对抗第三人。债权人不知道约定的，不对抗该债权人（第 1065 条第 3 款；“相对人知道”由主张一方举证）。逃债把全部财产归非债务人一方：红线/停止，可与第 538 条债权人撤销衔接。修改句必须拆成三层，禁止写成“签字即对外取得所有权”或“债权人不得再追另一方”。
3. **加名/转归一方 vs 赠与**。核心是一方把个人房产无偿给对方且无财产制安排，可能滑向赠与 `一般赠与合同·审查`/`房产赠与合同·审查`。财产制整体安排（分别/共同/部分共同）留在本类型。解释（一）第 32 条：被定性为将一方房产**赠与**另一方或共有，变更登记前对方请求继续履行的，法院**可以**按第 658 条处理——不是一律可任意撤销。解释（二）第 5 条：离婚诉讼中房屋约定转移或加名，走给予目的、婚龄、共同生活、子女、过错、贡献、房价等综合因素，已登记且婚龄较短、给予方无重大过错时可能判归给予方；欺诈胁迫、严重侵害、不履行扶养可撤销。禁止把“加名未过户一律可任意撤销”或“一律不可撤销”写成未核验结论。本任务不判决离婚时房屋归属。
4. **不得限制离婚自由、免除抚养赡养**。净身出户若捆绑“不准离婚”，限制离婚部分无效，须删除。抚养费、扶养费、赡养法定义务不得用约定免除。修改句删除人身限制，保留可分的财产制；家庭开支分担可以写，但须写明不免除法定义务。
5. **标的特定**。房产坐落证号、股权公司及比例、账户。仅写“全部财产归女方”而无清单：必须改。已抵押/查封：归属约定不得对抗抵押权人/执行。修改句补概括+列举+附件清单，并写权利负担与同意配合义务。
6. **胁迫欺诈**。可撤销（第 148、150 条）。本人签署与录像/律师见证为**可优化**，不写成法定必须。修改句提示签署场景留痕；不得把未见证写成约定未成立。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿，尚未签署，尚未成争，核心给付是夫妻或即将登记双方就婚前财产及婚后所得约定分别所有、共同所有或部分共同，对内优于法定财产制；用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 已在办离婚，或文本是解除婚姻+子女抚养+财产债务一揽子 → `离婚协议·审查`；
- 核心给付是分居不同居、未一并安排财产制 → `分居协议·审查`；
- 核心是一方把个人金钱或普通动产无偿给对方，无财产制安排 → `一般赠与合同·审查`；
- 核心是一方把个人房产无偿过户/加名给对方，无财产制安排 → `房产赠与合同·审查`；亲属之间房屋且主体不是夫妻财产制 → `亲属间房屋赠与合同·审查`；
- 隐名持股、代持分红为主给付 → `隐名持股代持分红为主给付→`；
- 类型未定或名实明显不符 → 本套导航的类型切开步骤；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签，只问过户、交割、告知债权人的履行节点 → 本套导航的履约步骤；
- 已成争（离婚诉讼财产、债权人撤销、执行异议）且要诉讼策略 → 转婚家或争议领域，不写诉讼策略；
- 文本处分子女名下财产 → 停笔，不改写成可履行处分。

挂靠、违法分包、规避限购、借约定逃债或转移执行财产：只出告知，不改写成可履行的逃债结构。

## 建立审查坐标

确认：使用者与授权；单方立场（夫或妻一方，或即将登记的一方及其代理人）；相对方；全文及附件版本；是否已在中国内地登记结婚或拟登记时点；双方行为能力；拟采用的财产制模式；既有财产与权利负担；已知对外债务；是否夹带离婚、赠与、代持条款；不可接受事项；法域与拟签署日。

缺立场、同时掌握双方秘密、或无可读文本：不启动实体审查。

来源编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不选对用户有利的一版。未给出的金额、账号、产证号、份额用 `【待填】`，不编造。

## 起草模式

本原子只承担本类型起草。待签评改转 `夫妻财产约定·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。缺数字用 `【待填】`，不编造。出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 书面全文；双方本人签署。即将登记写成“自完成结婚登记之日起发生本约定效力，未登记则不发生夫妻财产约定效力”。
- 财产制模式落句：分别所有、共同所有或部分共同。
- 对内约束、物权登记、不对抗不知情债权人三层分写；登记、加名写成配合义务和期限，不写成已经完成。
- 标的概括+列举：房产坐落证号、股权公司及比例、账户；权利负担与同意配合义务。
- 家庭开支分担可以写，但须写明不免除抚养、扶养、赡养法定义务。
- 加名或转归一方须先落财产制安排；禁止两极口诀。

### 附件必附

- 财产清单（概括+列举，与正文冲突时写明以哪一份为准）。
- 结婚证摘录，或拟登记机关与拟登记日说明。
- 权属证明复印件；已抵押/查封的，写出现状，不得写成无权利负担。
- 双方本人签署页；见证、录像只作可优化，不写成法定必须。

### 禁止出现

- 口头或代签文本当作第 1065 条书面约定。
- “签字即对外取得所有权”“债权人不得再追另一方”。
- “加名未过户一律可任意撤销”或“一律不可撤销”。
- 不准离婚、以不准离婚捆绑净身出户，或把限制离婚改成可履行惩罚。
- 免除抚养费、扶养费、赡养；处分子女名下财产。
- 逃债把全部财产归非债务人一方，或倒签早于已知债务。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口，不代替节点。

本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。交付按 [输出合同](references/output-contract.md)。边界见 [路由](references/routing.md)。知识双文件与 method 冲突时，以 method 核验口径为准。

0. 签署状态与成果分流：有完整待签文本要评改 → `夫妻财产约定·审查`；本类型条件已谈妥要出己方稿 → 本任务起草并自审；已签只问履行→履约；已成争要策略→婚家或争议领域。
1. 类型识别：切开离婚协议、分居、单笔赠与、股权代持、忠诚惩罚。只加载本类型双文件。
2. 书面与身份：合法夫妻或即将登记；本人签署；口头必须改。
3. 对内 / 物权 / 债权人三层：1065 对内约束；209/215 登记对抗；不知情债权人不对抗。
4. 加名或转归一方：先看有无财产制安排；禁止两极口诀。
5. 标的特定与权利负担：清单、证号、抵押查封。
6. 强制规范：离婚自由、抚养赡养扶养、子女名下财产、逃债。
7. 胁迫欺诈与签署留痕：可撤销；见证只作可优化。
8. 按框架六步出修改句：首部、交易条款（财产制+三层效力+清单）、配套、尾部、语言、常见问题。

必须有修改句。禁止只打红黄绿。每个风险回链文本位置。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、保证有效或必然对抗债权人、把逃债或限制离婚或处分子女名下财产改成可履行文本、家暴胁迫下优化逼签。
- `字段停止`：法域、婚姻登记状态、行为能力、权利负担、债权人知情、加名条款定性所需事实未核验。
- `目标停止`：主目标已变为从零起草、履约交底、离婚登记文件或诉讼策略。

生存级房产或已知执行案件且用户拒绝升级：停止“可以签署”建议，只列风险与转介。
