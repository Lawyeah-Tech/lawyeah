# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受、必然可过户或债权人不能再追；编造未给出的产证号、账号、份额；把已失效《合同法》《婚姻法》写入结论；把对内约束写成已完成物权变动；把内部 AA 制写成对外免责；把“加名未过户一律可任意撤销”或“加名一律不可撤销”写成结论；输出整份新财产约定充作审查成果；输出离婚三块或赠与任意撤销默认表。

## 1. 触发、单方立场与成果状态

立场（夫或妻一方，或即将登记的一方或其代理人）、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查夫妻财产约定（婚姻家庭）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》《婚姻法》及其解释、《物权法》，或“必须公证才生效”、两极加名口诀时记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `婚姻家庭`，子级 `夫妻财产约定`。写明财产制定性结果，以及与离婚协议、分居、一般赠与、房产赠与、股权代持、忠诚协议的切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读其他类型。知识双文件与 method 冲突时采用 method 核验口径。逃债或处分子女名下财产写停笔告知，不填可履行的违法结构。

## 4. 主体、身份、书面形式与文本版本

主体表：双方姓名、证件号是否可见、结婚证字号或拟登记说明、行为能力、是否本人签署。本类型不造“付款名/发票名”空表充数。版本表：正文、财产清单、聊天确认；冲突并列，不选对用户有利的一版。无婚姻且不准备登记：负触发。代签或仅口头：书面/签署字段停止或红线。

## 5. 财产制与三层效力闭环

必须分列并回链原文位置：

1. **财产制模式**：分别所有 / 共同所有 / 部分各自、部分共同；约定不明是否回第 1062、1063 条。
2. **对内约束**：是否写成以过户为对内生效要件；应改为对双方有约束力、不以登记为对内生效条件。
3. **物权与登记**：不动产/股权/特殊动产的配合登记期限；未登记不得对抗第三人。
4. **债权人**：分别所有时相对人知道才以一方财产清偿个人债务；知情举证；共同债务不因内部约定自动消灭。
5. **清单与负担**：坐落证号、公司及比例、账户；抵押/查封不得对抗。
6. **加名/转归块**：按 method 节点 4 定性；禁止两极口诀。

缺口标 `G#`，不补商业数字。登记、告知债权人、结婚登记写成条件或期限，不写成已经完成。

## 6. 强制规范与人身条款

限制离婚自由、以不准离婚捆绑净身出户、免除抚养扶养赡养、处分子女名下财产、倒签、逃债。强制规范只区分是否导致该条款不发生效力，不宣告整份约定有效或无效。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。见证/录像只标可优化。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔/转出口径。禁止输出无修改句的色块表。

书面或身份、三层效力、标的特定至少各有一行；出现加名/转归必须有定性行；出现对外免责或逃债必须有债权人行。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款（财产制 / 三层效力 / 清单 / 加名定性 / 债务告知）、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`，不编造。禁止只给原则、不给句子。禁止用整份范本替换本节。禁止用离婚三块或赠与 658 默认表替换本节。

## 9. 谈判与签署提醒

谈判顺序：先红线（代签、对外免责已成就、限制离婚、免除法定义务、处分子女名下、逃债），再必须改（书面、清单、三层切开、加名定性、登记期限），最后可优化（公证、见证、录像、清单更新周期）。

签署提醒：双方本人签署并签署日期；结婚证或拟登记说明入附件；清单与权属证明复印件由双方签认；过户/加名写成义务期限，不把签字日写成已经取得物权。不指导倒签或补假授权。不把公证写成第 1065 条法定生效要件。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本起草原子交付草稿、未决项、自审风险表、自审后修改句。未过三闸不得宣称完成。不是履约交底、争议文书、离婚诉讼策略或效力保证，也不是赠与或离婚协议审查。
