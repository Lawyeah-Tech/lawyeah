# 边界与路由

本技能只审查 **婚姻家庭 / 分手协议**。

必须同时读出：双方终止或即将终止共同生活；以及对已形成财产、债务、非婚生子女抚养的结算。标题叫“分手协议”但核心是离婚登记、存续同居安排、忠诚惩罚或维持不正当关系赠与的，不得留在本技能做实体结论。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或标题分手、核心给付明显不是终止同居后的清算 | 本套导航的类型切开步骤 |
| 双方仍共同生活，约定存续期归属、共同账户、加名或终止标准，无退出结算 | `同居财产约定·审查`；专业版未收录该 P1 时输出 `unavailable`，不得硬套本技能改成存续期财产制 |
| 给付目的是维持或巩固不正当关系、包养、以性或持续同居为对价 | `涉及不正当男女关系的赠与合同·审查`；不得设计可履行包养时间表 |
| 已登记结婚，解除婚姻、冷静期、离婚登记后生效 | `离婚协议·审查` |
| 已登记夫妻，忠诚义务、出轨惩罚、净身出户罚则 | `夫妻忠诚协议·审查` |
| 婚姻存续，分居居住和分居开支 | `分居协议·审查` |
| 1994 年 2 月 1 日前已符合结婚实质要件，当事人要按事实婚姻离婚 | 引擎或离婚路径；不按本技能解除身份 |
| 无文本、本类型条件已谈妥、要出己方稿 | `分手协议·起草` |
| 已签未争、问付款、搬离、过户、探望执行 | 本套导航的履约步骤 |
| 已成争 | 合同争议领域或家事专项；不写解除同居起诉状、不写抚养纠纷整案文书 |
| 用户只要补偿或抚养费终局数字 | 测算技能或人工精算；本技能只审条款 |
| C 端大众快检 | 只分流，不回改 |

一方有配偶且文本同时出现大额无偿给予、以继续同居为条件：按核心给付切开。已终止共同生活、给付能回链到共同出资折价 → 留本技能并走解释（二）第七条红旗。给付目的是维持不正当关系 → `涉及不正当男女关系的赠与合同·审查`。两可且无法判断：负触发引擎，不灌两套知识。

人身限制、放弃报警、子女买卖、逃债过户、借名规避限购：停笔告知，不改写成可履行文本。

禁止在正文写半截 Skill ID。转出时必须写完整 ID，例如 `同居财产约定·审查`、`涉及不正当男女关系的赠与合同·审查`、`离婚协议·审查`、`夫妻忠诚协议·审查`。
