# 分居协议·审查

## 任务目标

在单一立场下，只审查 **婚姻家庭 / 分居协议** 的待签文本，输出可决策意见：婚姻存续核验；**分居安排不等于解除婚姻**；两个不同住所、起始日与实际搬离；**子女临时安排**（不是离婚后直接抚养终局）；分居期财产按第 1065 条写成所有权而非“各自生活”；债务相对性；风险表；可回给对方的修改句或红线；谈判与签署提醒；停止或转介。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。中文名必须是「审查分居协议（婚姻家庭）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类型起草、履约交底、争议文书、离婚诉讼策略、必然准予离婚或必然认定分居的保证、可履行的自动离婚、限制离婚或放弃监护结构。不输出离婚协议的自愿解除+子女+财产债务三块齐审表。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **分居安排 ≠ 解除婚姻**。完成离婚登记，或者离婚判决书、调解书生效，才解除婚姻关系（第 1080 条）。本协议只安排分开居住和生活。文本写“签字即离婚”“分居满×月自动解除婚姻”“本协议代替离婚证”：红线删除，改为婚姻关系存续，解除须另行登记或裁判。第 1079 条“因感情不和分居满二年”是诉讼离婚、调解无效后的裁判条件之一，不是协议预定离婚，也不保证法院必然准予离婚。
2. **空间分居必须可识别**。写明甲方住 A 址、乙方住 B 址，门牌或租约编号不同；写清最后共同生活日、搬离日、分居起始日。同一套内分房（分床不分家）极难被认定为法律意义上的分居：必须改，不得用本协议包装。公证可固定起始日，不是离婚生效要件。
3. **子女只做临时安排**。写分居期间由谁实际照料、探视时间地点、费用账户。本安排仅适用于婚姻存续且双方分居期间，不构成离婚后直接抚养、抚养费和探望的终局安排。不得写成“监护权归一方单独所有”“另一方不再是监护人”。抢夺、藏匿子女不得改成可履行结构。已满八周岁子女意愿：材料未提不得编造。
4. **与离婚协议、夫妻财产约定切开**。已在办离婚，或核心给付是自愿解除婚姻+子女+财产债务一揽子 → `离婚协议·审查`，不在本任务补自愿离婚句、不按三块齐审。不分居、只改财产制 → `夫妻财产约定·审查`。本协议里的财产块只处理：既有共同财产清单固化且暂不分割（或写明维持共同、禁止擅自处分）；分居期所得按第 1065 条写成归各自或仍共同。禁止只写“各自生活”代替所有权。
5. **债务不能对抗不知情债权人**。分居期债务对内可各自承担；相对人不知道该约定的，不得对抗该相对人（第 1065 条第 3 款；解释（一）第 37 条）。禁止写成“债权人不得再追另一方”。
6. **人身罚则与假分居**。不得与异性往来否则天价赔偿、禁止再婚：红线删除或降格为无强制履行的意愿。签署后仍共用账户、共同出游、未实际搬离：提示证据效力被削弱，修改句限制混同并要求真实搬离。不得把“假分居”改成更能骗过法院的履行脚本。

## 工作边界

正触发：已有可读待签书面分居协议，尚未签署，尚未成争，核心给付是合法夫妻在**不解除婚姻**的前提下分开居住，并安排分居期间住所、生活费或津贴、子女临时照料、分居期财产与债务；用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 已在办离婚，或文本是解除婚姻+子女抚养+财产债务一揽子 → `离婚协议·审查`；
- 核心给付是婚前或婚内财产制，**没有**不同住所或搬离安排 → `夫妻财产约定·审查`；
- 核心是忠实义务、出轨罚款、忠诚保证金，主给付不是分居生活安排 → `夫妻忠诚协议·审查`；
- 未登记同居者分手财产 → 转引擎重新定性，不按分居协议审；
- 类型未定或名实明显不符 → 本套导航的类型切开步骤；
- 无文本、本类型条件已谈妥、要出己方稿 → `分居协议·起草`；
- 已签，只问搬离、津贴支付、账户分立的履行节点 → 本套导航的履约步骤；
- 已成争（起诉离婚、抢夺藏匿子女、债权人追索）且要诉讼策略 → 转婚家或争议领域，不写诉讼策略；
- 文本处分子女名下财产，或授权藏匿子女 → 停笔，不改写成可履行处分。

挂靠、违法分包、规避限购、借分居逃债或转移执行财产：只出告知，不改写成可履行的逃债结构。

## 建立审查坐标

确认：使用者与授权；单方立场（夫或妻一方及其代理人）；相对方；全文及附件版本；是否已在中国内地登记结婚；双方行为能力；拟住的两个住所是否不同；最后共同生活日、搬离日、分居起始日是否对齐；有无未成年子女及临时照料安排；分居时点既有财产清单；分居期所得归属用语；已知对外债务；是否夹带自动离婚、人身罚则、一次性离婚分割；不可接受事项；法域与拟签署日。

缺立场、同时掌握双方秘密、或无可读文本：不启动实体审查。

来源编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不选对用户有利的一版。未给出的金额、门牌、账号、产证号用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典第 1079、1080、1076、1065、1062–1064、1060、1042、1058、1084、1085、27、35、153、154、148、150 条，婚姻家庭编解释（一）第 37、69 条，解释（二）第 12、13 条，总则编解释第 8 条，家庭教育促进法第 20 条。`search_practiced` 只补审查反例（分居须因感情不和、满二年不是绝对准离条件）。不调用范本充作本约。不虚构案件系统。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口，不代替节点。

本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。交付按 [输出合同](references/output-contract.md)。边界见 [路由](references/routing.md)。知识双文件与 method 冲突时，以 method 核验口径为准。

0. 签署状态与成果分流：无文本且本类型条件已谈妥 → `分居协议·起草`；已签只问履行→履约；已成争要策略→婚家或争议领域；未签且目标是评改已有分居协议，才进入。
1. 类型识别：切开离婚协议、夫妻财产约定、忠诚协议、同居分手。只加载本类型双文件。
2. 书面、合法夫妻、婚姻存续明示：本人签署；口头必须改；不得写成已离婚。
3. 空间分居闸：两个不同住所、起始日、实际搬离；同一套分房必须改。
4. 子女临时安排：分居期照料/探视/费用；不写成离婚后终局直接抚养；不得放弃监护。
5. 分居期财产与债务：1065 所有权用语；既有财产暂不分割；不对抗不知情债权人。
6. 强制规范：自动离婚、限制离婚、人身罚则、处分子女名下、逃债。
7. 证据效力与假分居：1079 是裁判条件之一，须与生活状态一致；不保证必然准离。
8. 按框架六步出修改句：首部、交易条款（住所+临时子女+分居期财产债务）、配套、尾部、语言、常见问题。

必须有修改句。禁止只打红黄绿。每个风险回链文本位置。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签起始日、保证签字即离婚或满二年必然准离、把自动离婚/放弃监护/藏匿子女/逃债改成可履行文本、家暴胁迫下优化逼签。
- `字段停止`：法域、婚姻登记状态、行为能力、两个住所是否真实不同、权利负担、债权人知情、子女意愿所需事实未核验。
- `目标停止`：主目标已变为从零起草、履约交底、离婚登记文件或诉讼策略。

生存级住所、已知执行案件或子女安全风险且用户拒绝升级：停止“可以签署”建议，只列风险与转介。
