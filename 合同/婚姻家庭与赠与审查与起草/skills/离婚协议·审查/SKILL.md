# 离婚协议·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构，不证明本约条款已被接受，也不代替本任务出整稿。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《婚姻法》及其解释当作现行规则。`search_law` 同时返回《婚姻登记条例》2024 修订与 2025 修订时，以国务院令第 804 号（2025-05-10 施行）为准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **婚姻家庭 / 离婚协议** 的待签文本，输出可决策意见：版本与主体核验；**身份解除、财产债务、子女安排** 三块风险表；可回给对方的修改句或红线；谈判与登记签署提醒；停止或转介。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。`depends-on` 为空。不要求先跑导航。

不交付：他类型起草、履约交底、争议文书、诉讼策略、有效性或必然可登记的保证。

## 工作边界

正触发：已有可读待签离婚协议及附件，尚未在婚姻登记员面前签署并完成登记，尚未成争，核心给付是双方拟协议解除婚姻关系，并一次性安排子女抚养、财产和债务。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 核心给付是婚前或婚内财产制约定、不解除婚姻 → `夫妻财产约定·审查`；
- 核心给付是分居不同居、未一并解除婚姻 → `分居协议·审查`；
- 核心给付是忠诚惩罚金、出轨净身出户，而不解除婚姻 → `夫妻忠诚协议·审查`；
- 类型未定或名实明显不符 → 本套导航的类型切开步骤；
- 无文本、本类型条件已谈妥、要出己方稿 → `离婚协议·起草`；
- 已签、已登记，只问过户、给付、探望履行 → 本套导航的履约步骤；
- 已起诉离婚，或用户要立案请求、举证策略、开庭口径 → `已起诉离婚，或用户要立案请求举证策略开庭口径→`，具体评估走 `具体评估走`，立案材料走 `立案材料走`；
- 家暴或儿童即时危险尚未处置 → 先安全分流，不优化逼签条款。

挂靠、违法分包、规避限购、借离婚逃债或转移执行财产：只出告知，不改写成可履行的逃债结构。

## 本类型硬闸

1. **三块齐审**。身份解除、财产债务、子女安排缺一，不得宣称审查完成或“可以去登记”。无子女必须在文本中明示“双方无子女”，该块仍要核对并出句。
2. **协议离婚须登记才发生离婚效力**。完成离婚登记、发给离婚证前，不得写成婚姻关系已经解除。签字、公证、律师见证都不替代登记。
3. **不得私下处分法定监护**。可以直接约定由谁直接抚养、抚养费和探望；不得约定一方“放弃监护权”、取消另一方法定监护、或把监护转让给第三人。
4. **债务约定不得对抗债权人**。对内谁清偿、谁追偿可以写；不得写成债权人不能再向另一方主张。
5. **必须有修改句**。禁止只打红黄绿。每个风险回链条款或附件位置。
6. **只加载本类型双文件**：`references/基本面.md` 与 `references/框架.md`。禁止打开其他类型目录。

## 建立审查坐标

确认：使用者与授权；单方立场（夫或妻一方，或仅一方的代理人）；相对方；全文及附件版本；结婚登记时间和机关是否在中国内地；双方行为能力；是否已申请离婚登记或已立案；有无未成年子女；不可接受事项；法域与拟登记时点。

缺立场、同时掌握双方秘密、或无可读文本：不启动实体审查。

来源编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不选对用户有利的一版。未给出的金额、账号、产证号、抚养费用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典第 1076–1080、1062–1065、1084–1089、1092、26–27、1058 条，婚姻家庭编解释（一）（二），2025 年婚姻登记条例，总则编解释第 8 条；`search_practiced` 只补审查反例。不调用范本充作本约。不虚构案件系统。

`search_law` 对法律结论为 required。不可用时不拒绝执行，只停止法律结论字段。返回已失效《合同法》《婚姻法》及其解释时记为噪声，不得写入 `L#`。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口，不代替节点。

0. 签署状态与成果分流：无文本且本类型条件已谈妥 → `离婚协议·起草`；已登记只问履行→履约；已起诉要策略→婚家领域；未签且目标是评改已有离婚协议，才进入。
1. 类型识别：切开夫妻财产约定、分居协议、忠诚协议、诉讼调解方案。只加载本类型双文件。
2. 三块齐备闸：身份解除、财产债务、子女安排均须对照原文。
3. 主体与意愿：合法婚姻双方、完全行为能力、亲自、无代签；结婚登记是否在中国内地。
4. 身份解除与登记程序：自愿离婚意思表示、冷静期、领证前可撤回；登记写成生效条件，不写成已经完成。
5. 子女安排：直接抚养、抚养费、探望；禁止处分法定监护、禁止以再婚剥夺抚养或探望。
6. 财产债务：清单、权利负担、过户期限、对内追偿；对外不得免责；显著倾斜标逃债红旗。
7. 强制规范与异常人身条款：限制离婚/再婚自由、永久放弃抚养费请求、伪造倒签。
8. 按框架六步出修改句：首部、交易条款（三块）、配套、尾部、语言、常见问题。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、保证有效或必然可登记、把放弃监护或逃债结构改成可履行文本、家暴胁迫下优化逼签。
- `字段停止`：法域、结婚登记地、行为能力、批准/过户/银行同意路径未核验；三块中关键事实缺失。
- `目标停止`：主目标已变为从零起草、履约交底或诉讼策略。

生存级房产或个人无限对外担责且用户拒绝升级：停止“可以签署去登记”建议，只列风险与转介。
