# 审查方法（锁定 婚姻家庭 / 离婚协议）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。`基本面.md` 用于校验类型、主体、标的、程序、结构和红旗；`框架.md` 用于按六步出修改句。两文件与本方法冲突时，以本方法已核验口径为准，不回写知识库。

本文件是可执行判断节点，不是栏目说明书。每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、必然可登记、对方必然接受或债权人不能再追。

`search_law` 返回已失效《合同法》及其解释、《婚姻法》及其解释、1993 年财产分割意见或 1994 年婚姻登记管理条例时记为噪声，不得写入 `L#`。同时命中《婚姻登记条例》2024 修订与 2025 修订时，以国务院令第 804 号（2025-05-10 施行）为准，2024 文本记 `conflict`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

示范文本只参考结构。不得把民政示范文本或网上模板粘贴为本约，不得完成本任务项下的整份起草。

## 节点 0　签署状态与成果分流

先于类型识别。命中任一项则本任务不填十节实体结论，只交付分流理由和最小交接。

| 已能支持的事实 | 走向 | 不得写成 |
| --- | --- | --- |
| 无可读正文和附件，或只有“想离婚、房子归谁”的口头要点 | `离婚协议·起草` | 已经完成审查；已经出整稿 |
| 未签，目标是评改已有《离婚协议》 | 进入节点 1 | 已签署、已生效、已离婚 |
| 残缺模板，用户要按己方条件重写整份 | 起草引擎 | 本任务出整稿 |
| 已完成离婚登记，只问过户、给付抚养费、配合探望 | 本套导航的履约步骤 | 签前意见 |
| 已起诉离婚，或要立案请求、举证、开庭、保全策略 | `已起诉离婚，或用户要立案请求举证策略开庭口径→`；评估 `具体评估走`；立案 `立案材料走` | 继续当登记用协议审查并给诉讼策略 |
| 家暴、胁迫、儿童藏匿或即时危险未先处置 | 安全分流；不优化见面逼签条款 | 已经可以安排对方签字 |
| 劳动/工程/金融/股权文本，或家事但核心给付不是离婚协议 | 节点 1 负触发 | 因“家事”整案拒绝或整案硬审 |

缺立场或同时掌握双方秘密：整体停止策略输出，澄清代表哪一方。缺文本仍要“给个能不能去民政局”：不启动实体审查。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付和用户陈述定性，不用标题单独定性。名实不符按核心给付归类，标题冲突写入 `C#`。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 双方拟自愿解除婚姻，并一次性写子女抚养、财产、债务 | **婚姻家庭 / 离婚协议** | 加载本目录双文件 |
| 婚前或婚内约定财产归各自/共同/部分，**不**解除婚姻 | 夫妻财产约定 | 负触发 `夫妻财产约定·审查` |
| 安排分居、生活费、临时照护，**不**解除婚姻；或“分居满一年自动离婚” | 分居协议 | 负触发 `分居协议·审查`；自动转离婚条款只告知不能协议预定离婚效力 |
| 核心是忠实义务、出轨罚款、忠诚保证金，主给付不是解除婚姻 | 夫妻忠诚协议 | 负触发 `夫妻忠诚协议·审查` |
| 未登记同居者分手财产 | 同居财产约定或分手协议 | 转引擎重新定性，不按离婚协议审 |
| 法院调解书底稿、诉讼和解方案 | 已成争 | 转婚家领域 |
| 移转标的物换价款、承揽、劳动、股权收购等 | 他类 | 转 本套导航的类型切开步骤 |

忠诚条款如果只是离婚协议里的附属损害赔偿句，且主给付仍是解除婚姻+三块安排：留本任务，把该句按节点 7 审，不整案改去 `夫妻忠诚协议·审查`。

### 1.2 加载协议（硬闸）

本技能已锁定 **婚姻家庭 / 离婚协议**。只打开 `references/基本面.md` 与 `references/框架.md`。禁止读其他类型子目录，禁止为对照再开第二类。

### 1.3 违法结构停笔

加载后或定性中出现：借离婚隐匿、转移财产逃债或规避执行；伪造行为能力；规避限购或资质；约定私下消灭法定监护。

动作：

1. 交付告知：该结构不能改写成可对抗债权人、登记机关或监护制度的可履行文本。
2. 不写假债务清单、假“债权人已同意”、假放弃监护路径。
3. 风险表只保留识别依据和转出/改道提示。
4. 用户坚持“改到能签能躲债/能取消对方监护”：整体停止。

合规改道（真实披露债务、对内追偿、直接抚养安排）只出修改句，不在本任务起草逃债替代方案。

## 节点 2　三块齐备闸

民法典第 1076 条、第 1078 条和 2025 年婚姻登记条例第 13 条要求：书面协议载明双方自愿离婚的意思表示，以及对子女抚养、财产以及债务处理等事项协商一致的意见。登记机关查明这三项一致才发证。

对照正文和附件，三块都必须审：

| 块 | 最低可见内容 | 缺失时 |
| --- | --- | --- |
| 身份解除 | 双方自愿解除婚姻关系的明确表述；结婚登记事实 | `必须改`；无自愿离婚句则标可能无法登记 |
| 财产债务 | 已知财产如何分、已知债务对内谁还；或明示“除列明外无其他已知共同财产/债务”且清单与用户陈述不冲突 | 缺块不得宣称可登记 |
| 子女安排 | 逐一子女的直接抚养、抚养费、探望；无子女则书面写明“双方无婚生或养子女” | 有子女却整块缺失：红线 |

“财产谈拢了，子女回去再口头说”不得写成可以先登记。无子女不是跳过该块，而是核对否定表述是否写清。

本节点不补写未给出的子女姓名、抚养费数字或房产证号。

## 节点 3　主体、意愿、能力、版本

对照 `基本面.md` 第二节。

1. 主体表：双方姓名、身份证号摘录（去标识）、结婚登记日期、结婚证字号、登记机关。名称与证件不一致不自动合并。
2. 必须是合法婚姻关系的夫妻双方，且文本或用户材料未显示无/限制民事行为能力。2025 年婚姻登记条例第 14 条：无/限制行为能力、结婚登记不是在中国内地办理、未达成离婚协议的，协议离婚不予受理。命中则字段停止并转诉讼路径，不在本任务设计“如何让民政局收下”。
3. 自愿、亲自。禁止代签、预签后由一方代交、或“授权律师代为离婚登记”。框架要求在婚姻登记员面前亲笔签名。
4. 欺诈、胁迫迹象：对方控制通讯、家暴后当场要签字、执笔方只持有一方印章。停止优化逼签，转安全或婚家领域。
5. 版本表：正文、财产清单附件、聊天确认稿、律师改稿。冲突并列，不选对用户有利的一版。修改句写明以哪一份为准。

口头“我们都同意了”不得写成已达成第 1076 条书面协议。

## 节点 4　身份解除与登记程序

对照 `基本面.md` 第一、四节与 `框架.md` 首部、解除条款。

1. 自愿离婚意思表示必须可被登记机关识别。仅有“财产分割协议”“双方同意分开过”不够。
2. **离婚效力**：完成离婚登记、发给离婚证，才解除婚姻关系（第 1080、1078 条）。文本写“签字之日起离婚/本协议生效即解除婚姻”必须改：协议中财产债务条款的约束力，与婚姻关系解除，分层书写。
3. **冷静期**：自婚姻登记机关收到申请之日起三十日内可撤回；届满后三十日内须双方亲自申请发证，未申请视为撤回（第 1077 条；条例第 16 条）。修改句应提示领证前任一方可撤回，不得写成“签字后不得反悔且已离婚”。
4. 解释（一）第 69 条：以协议离婚为条件的财产及债务处理协议，离婚未成且一方在诉讼中反悔的，该财产债务协议没有生效；但依照第 1076 条签订的离婚协议中财产债务条款，对男女双方具有法律约束力，登记离婚后可诉请履行。禁止两种绝对化：  
   - “没领证，整份纸永远作废”；  
   - “签了字，没登记也已经离婚、财产已经变动”。
5. 批准、过户、银行变更借款人、股权变更登记写成**双方义务和期限**，不写成已经完成，也不写成离婚登记的替代。

用户要求倒签申请日或补假冷静期经过：整体停止。

## 节点 5　子女安排（直接抚养 ≠ 法定监护）

对照 `框架.md` 交易条款第 1 点、`基本面.md` 子女利益。

1. 逐一子女写明：由谁直接抚养；另一方抚养费的构成、金额、支付频率、支付至何时；探望时间、地点、交接。多个子女不得用“子女由双方抚养”一笔带过。
2. **法定监护硬闸**。父母是未成年子女的监护人（第 27 条）。父母与他人约定免除有监护能力父母的监护职责，法院不予支持（总则编解释第 8 条）。离婚后父母子女关系不消除，父母仍有抚养、教育、保护的权利和义务（第 1084 条）；夫妻双方平等享有并共同承担该义务（第 1058 条）。  
   出现下列原文，级别为 `红线`，修改句删除或改成“直接抚养/协助探望”，不得改写成可履行的弃权结构：  
   - 一方放弃监护权、不再是监护人、监护权归对方单独所有；  
   - 监护转给祖父母或其他第三人并免除父母；  
   - 不与子女共同生活即不承担监护职责或致害责任。
3. 抚养费使用“抚养费”而非单一“生活费”（解释（一）第 42 条）。保留子女在必要时请求增加的空间（第 1085 条第 2 款）。写死“永不再主张增加且子女不得请求”为必须改。
4. 探望权不得被协议永久剥夺。中止探望须由人民法院依法决定（第 1086 条）。一方阻碍另一方实施家庭教育：标违法风险（家庭教育促进法第 20 条）。
5. “再婚即失去直接抚养/不得再婚否则失去探望”：限制婚姻自由，红线删除（见节点 7）。
6. 已满八周岁子女意愿：材料未提不得编造子女已同意。轮流直接抚养仅在有利于子女时可谈（解释（一）第 48 条），须写清交接和学校稳定，不写成默认最优。
7. 本任务不定谁必然获得直接抚养，不测算唯一抚养费金额。缺数字用 `【待填】`。

## 节点 6　财产与债务

对照 `基本面.md` 第三、五、六节与 `框架.md` 财产、债务条款。

### 6.1 财产闭环

1. 标的是否确定到可履行：坐落与产证号、车牌与车架号、账号与开户行、公司名称与出资额、公积金、保险现金价值。只有“家里东西归各自”或“净身出户”：必须改，要求逐项列举。
2. 权利负担：抵押、查封、居住权、租赁。材料未提及不得写成“无权利负担”，只能写 `依据不足`。
3. 协议分割不当然发生物权变动。未办理不动产登记前，不得写成已取得对抗效力。过户配合义务、期限、违约金必须落句。
4. 按揭：内部可约定归属和谁还款；银行作为债权人不受内部约定当然约束。修改句增加：变更借款人须银行同意；未变更前谁对内偿还、谁在对外被追后追偿。
5. 股权：内部归属与公司变更登记、其他股东优先权分开写。不在本任务完成公司法专项。
6. 约定将财产给予子女：解释（二）第 20 条，离婚后一方在权利转移前请求任意撤销，一般不予支持；欺诈胁迫除外。修改句可写明是否允许子女直接主张，不保证不可撤销。
7. 隐瞒、转移、伪造债务：保留再分割和少分或不分的约定空间（第 1092 条；解释（一）第 83 条）。“双方再无任何财产纠纷”不能消灭未列入的共同财产，修改句改为“就本协议已列明财产”+隐瞒再分割。

### 6.2 债务内外切开（硬闸）

1. 共同债务应当共同偿还；内部可协议谁清偿（第 1089、1064 条）。
2. 解释（一）第 35 条：离婚协议已处理财产分割的，债权人仍有权就夫妻共同债务向双方主张；一方清偿后可按协议向另一方追偿。
3. 解释（二）第 3 条：债权人证明财产分割影响债权实现的，可请求参照第 538 或 539 条撤销相关条款。财产显著倾斜、一方拿走全部资产另一方只背债：标逃债红旗，只告知，不改成更隐蔽的转移结构。
4. 禁止修改句出现：“乙方对任何债权人不再承担责任”“本协议对银行和债权人当然有效”。应改为对内承担+被追后等额追偿+不对抗不知情债权人。

未给出的债务余额、利率用 `【待填】`。不在本任务认定某笔债是否共同债务。

## 节点 7　强制规范、人身限制与格式条款

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 7.1 人身与身份强制规范

违反法律、行政法规强制性规定不一律无效（第 153 条）。本类型高频应删或改：

| 原文类型 | 动作 |
| --- | --- |
| 不准离婚、离婚须对方书面批准、悔婚罚没全部财产以阻止离婚 | 红线；限制离婚自由 |
| 不准再婚、再婚即失去直接抚养或财产 | 红线 |
| 放弃法定监护、把监护卖给第三人 | 红线（节点 5） |
| 永久剥夺探望、禁止另一方实施家庭教育 | 必须改或红线 |
| 伪造倒签、补假冷静期、代签 | 整体停止 |
| 借协议逃债或规避执行 | 停笔告知，不改可履行逃债结构 |

不得用已失效“效力性/管理性”口诀代替核验。无 `search_law` 引文则本节点法律结论字段停止。

### 7.2 是否格式条款

离婚协议通常是双方协商文本，不是经营者重复使用的格式条款。一方律师单方制式且异常剥夺对方权利时，仍审查提示说明痕迹，但不把第 496 条生搬成“未加黑就不成为离婚协议内容”。示范文本不证明本约已被接受。

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。禁止输出整份新协议充作审查成果。

打开已加载的 `框架.md`，按下列六步逐段对照正文。

| 步 | 本类型动作 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题用离婚协议书，避免财产分割协议/分居协议；主体身份与结婚登记信息；鉴于只写自愿离婚，不把过户写成已完成 | 标题或自愿离婚修改句 |
| 交易条款 | **三块**：身份解除；子女直接抚养/抚养费/探望；财产清单+债务对内清偿与追偿 | 三块闭环修改句；缺数字用 `【待填】` |
| 配套 | 过户/给付/迁户违约金；隐瞒财产再分割；领证前撤回；争议解决 | 可执行后果句；不写对外免责 |
| 尾部 | 登记员面前亲笔签；一式三份；自完成离婚登记领取离婚证之日起发生离婚效力 | 生效与附件修改句 |
| 语言 | 正说加反说；抚养费≠生活费；独立生活≠仅满十八周岁；清结限已列明财产 | 替换空词的句子 |
| 常见问题 | 无过户期限；漏公积金保险；净身出户空词；再婚罚则；放弃监护 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签、不递交登记或整体停止；
- `必须改`：可谈但签署或递交前要落句；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级房产或对外无限债务且用户拒绝升级：停止“可以签署去登记”建议。
