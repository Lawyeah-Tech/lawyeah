# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、必然可登记、对方接受或债权人不能再追；编造未给出的金额、产证号、抚养费；把已失效《合同法》《婚姻法》及其解释写入结论；输出整份新离婚协议充作审查成果。

## 1. 触发、单方立场与成果状态

立场（夫或妻一方或其代理人）、授权、签署与登记状态、主要目标。负触发写路由，不启动实体审查。已起诉且目标是诉讼策略：负触发，不填本十节。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》《婚姻法》及其解释时记噪声，不得写入 `L#`。2024 与 2025 婚姻登记条例并行命中记 `conflict`，结论以 804 号为准。

## 3. 类型与加载路径

父级 `婚姻家庭`，子级 `离婚协议`。写明与夫妻财产约定、分居协议、忠诚协议的切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读其他类型。逃债或私下处分监护写停笔告知，不填可履行的违法结构。

## 4. 主体、意愿、能力与文本版本

主体表：双方姓名（去标识）、结婚登记日期与机关、结婚证字号、是否中国内地登记、行为能力迹象、是否亲自签署。禁止代签。版本表：正文、财产清单、聊天确认；冲突并列，不选对用户有利的一版。本类型不造“付款名/发票名”空表充数。

## 5. 三块给付闭环

必须分列并回链原文位置：

1. **身份解除**：自愿离婚意思表示；登记才解除婚姻；冷静期与领证前撤回。
2. **子女安排**：直接抚养、抚养费、探望；明示未处分法定监护。无子女须有否定句。
3. **财产债务**：清单与权利负担；过户/给付期限；对内清偿与追偿；对外不对抗债权人。

缺口标 `G#`，不补商业数字。登记、过户、银行同意写成条件或双方义务，不写成已经完成。缺任一块不得把成果状态写成“已形成且可去登记”。

## 6. 强制规范与异常人身条款

审查：限制离婚或再婚自由；放弃或转让法定监护；永久剥夺探望；对外免责对抗债权人；倒签冷静期。强制规范只区分是否导致该条款不发生效力，不宣告整份协议有效或无效。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。离婚协议原则上不当经营者格式条款处理。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔/转出口径。禁止输出无修改句的色块表。

三块至少各有一行（无子女则子女块写否定表述是否完备）。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款（身份/子女/财产债务）、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`，不编造。禁止只给原则、不给句子。禁止用整份范本替换本节。

## 9. 谈判与签署提醒

谈判顺序：先红线（监护处分、对外免责、倒签、逃债包装），再必须改（三块缺口、过户期限、抚养费构成），最后可优化。

签署提醒：双方亲自到婚姻登记机关；冷静期与领证窗口；在登记员面前签名；一式三份；领证前可撤回；过户与银行变更另办。不指导倒签或补假授权。不把公证或见证写成已替代登记。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本审查原子成果不是整份起草终稿。出稿转 `离婚协议·起草`。不是履约交底、争议文书、诉讼策略或效力保证。
