# 收养协议·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《收养法》《合同法》及其解释、1992 年《中国公民办理收养登记的若干规定》、1984 年民事政策意见中的“亲友群众公认即事实收养”当作现行规则。不得把“公证之日起成立”或“签字即成立拟制血亲”写成现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **婚姻家庭 / 收养协议** 的待签文本：核心给付是拟依法建立养父母与养子女关系。输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「审查收养协议（婚姻家庭）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查、从零起草、履约交底、争议文书、登记或有效性保证、解除已成立收养整案、监护权私下转让整案、把不符合法定准入或买卖未成年人改成可履行结构。

## 工作边界

正触发：已有可读待签文本要评改，；尚未签署，尚未成争；核心给付是拟向县级以上人民政府民政部门登记以成立收养关系。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主文件是终止已经成立的收养关系、办理解除登记、处理解除后生活费或抚养费补偿 → `解除收养协议·审查`；
- 监护资格私下转让、指定或放弃 → `监护权协议·审查`；专业版未收录时输出 `unavailable`，不得用本技能改成可履行监护买卖；
- 意定监护 → `意定监护协议·审查`；
- 已有直接抚养安排之上只变更直接抚养人 → `抚养权变更协议·审查`；
- 只约定扶养或抚养给付、不建立拟制血亲 → `扶养抚养协议·审查`；
- 离婚一揽子财产债务子女安排 → `离婚协议·审查`；
- 明文只做亲属、朋友抚养且不适用收养章 → 转引擎或抚养类原子，不得灌本类型成立节点；
- 家庭寄养文本 → 转引擎，不按收养登记成立审完；
- 外国人来华收养且审查重点是省级登记、认证链和其所在国同意 → 字段停止并升级，不在本任务输出可履行涉外路径；
- 无文本、本类型条件已谈妥、要出己方稿 → `收养协议·起草`；
- 已签只问登记预约、评估进度、户口迁移 → 本套导航的履约步骤；
- 已成争（抢夺藏匿、确认收养无效、解除诉讼、刑事立案）→ 家事争议或对应专项领域。

买卖未成年人、不符合法定送养或收养条件仍要接走、伪造无力抚养或无犯罪材料、指导规避公告或倒签登记：只出告知，不改写成可履行结构。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成。每一闸必须给出修改句或明确转出口径，禁止只打红黄绿。

1. **登记生效**。必须写明：本协议自县级以上人民政府民政部门办理收养登记之日起，收养关系成立。未经登记，不产生养父母与养子女的权利义务。签字、交接、公证、共同生活均不得写成已经成立。公证仅在当事人要求时作为办理事项，不得替代登记。
2. **送养条件**。被收养人须落入三类：丧失父母的孤儿；查找不到生父母的未成年人；生父母有特殊困难无力抚养的子女。送养人须落入：孤儿的监护人；儿童福利机构；有特殊困难无力抚养子女的生父母。生父母送养应当双方共同送养，一方不明或查找不到才可单方送养。监护人送养孤儿应当征得有抚养义务的人同意。材料不能支持上述类型：该成立路径字段停止，不得改成可履行送养。
3. **与 `解除收养协议·审查` 切开**。主文件是解除已成立收养 → 负触发该原子。本任务禁止输出解除登记整案、解除后生活费请求权表、成年养子女关系恶化诉讼路径作为主线。禁止打开其 method。成立协议中预埋的将来解除条件，只改到“解除同样须办理解除登记、不得私下终止”，不把整份解除协议留在本技能。
4. **不得改成可履行非法送养**。出现转让、售出、抵债、买断抚养权、按人计价、大额感谢费且无合理必要费用外观：红线并停笔。不得改成“改用途名称即可登记”。用户坚持改到能签、能先接走、能对外以养父母子女申报：整体停止。
5. **收养人法定条件不得协议放宽**。同时审查：无子女或只有一名子女；抚养教育和保护能力；未患医学上认为不应当收养子女的疾病；无不利于被收养人健康成长的违法犯罪记录；年满三十周岁。有配偶者应当夫妻共同收养。无配偶者收养异性子女，年龄相差四十周岁以上。知识库若写“无犯罪记录”，纠正为“无不利于被收养人健康成长的违法犯罪记录”，不回写知识正文。法定例外只在事实能支持时点名，不自行扩写。
6. **八周岁同意与强制性准入**。被收养人已满八周岁：须本人签署或另附独立意愿记录，口头转述不得写成已同意。协议不得约定排除评估、排除公告、排除共同送养或降低年龄门槛。未成年人不得成为对价或违约金义务人。

附加必落句（有事实则单列，无事实在缺口节说明）：

- **评估与公告**：县级以上人民政府民政部门应当依法进行收养评估；查找不到生父母的，登记前应当公告。修改句写成双方配合义务，不写成已经评估合格或已经公告完毕。
- **身份效果时点**：自登记成立之日起，养父母与养子女适用父母子女规定；与生父母及其他近亲属的权利义务因成立而消除。不得把该效果提前到签字日。
- **户籍**：登记后再凭收养登记证办理户口登记或迁移，不写成签字即可迁户。
- **费用**：可约定必要、合理、可证明用途的前期抚养或医疗支出补偿；禁止对价化。

必须有修改句。每个风险回链文本位置。禁止套用买卖验收、定金百分之二十、挂靠改写节点。禁止复制 `解除收养协议·审查` method。

## 建立审查坐标

确认：使用者与授权；单方立场（拟收养人、拟送养人、儿童福利机构经办人、拟签字的配偶或有抚养义务的人）；相对方；全文及附件版本；被收养人出生日期；送养法定类型；是否拟办民政登记；有无费用；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law`（法律结论 required）：核验收养登记成立、送养人与被收养人范围、共同送养、收养人五项条件、夫妻共同收养、无配偶者收养异性年龄差、八周岁同意、禁止买卖未成年人、收养无效、解除与成立的程序分界。
- `search_practiced`（optional）：补未登记不成立、评估、私下收养争点。返回“亲友群众公认即成立”“公证之日起生效”“签字即可事实收养”时记噪声。
- `search_template`（optional）：只借栏目结构。范本写“自公证之日起生效”或仍引用《收养法》不得当规则。

不虚构案件系统。`search_law` 返回已失效《收养法》《合同法》、1992 年登记规定、1984 年民事政策意见事实收养口径时记为噪声，不得写入 `L#`。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口，不代替节点。

0. 签署状态与成果分流
1. 类型识别与单目录加载（成立收养；切开解除、监护、抚养、寄养）
2. 主体：被收养人、送养人、收养人、配偶、有抚养义务的人
3. 送养条件与共同送养
4. 收养人法定条件与法定例外
5. 登记生效、评估、公告、公证不得替代登记
6. 对价与非法送养停笔；八周岁同意
7. 身份效果时点、户籍、预埋解除句
8. 按框架六步出修改句

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签或假材料、把买卖或非法送养改成可履行、把未登记写成已经成立、把不符合法定条件改成可登记、保证民政必然登记。
- `字段停止`：法域不明；送养类型无法识别；收养人年龄、婚姻、子女数、疾病或违法犯罪记录未核；被收养人是否满八周岁未核；是否拟办登记无法识别。
- `目标停止`：主目标已变为从零起草、登记窗口代办、解除整案、监护转让或涉外认证链。

被收养人人身安全或疑似拐卖、藏匿：停止“可以签署”建议，只保留识别与转介。
