# 边界与路由

本技能只起草 **赠与合同 / 一般赠与合同**。中文展示名必须是「审查一般赠与合同（赠与合同）」。禁止在正文写半截场景编号。

主线：无偿转移财产权利；任意撤销为默认。不输出房屋网签过户五证主清单，不复制买卖价金/定金路径，不复制离婚三块。

## 正触发

已有可读待签书面赠与合同，尚未签署，尚未成争，核心给付是赠与人将自己的金钱或普通动产等财产无偿给予受赠人、受赠人表示接受，且主标的不是房屋、不是股权零元转让、不是附义务主轴、不是死后生效。

## 负触发

| 主要目标或文本信号 | 路由 | 不得代做 |
| --- | --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 | 不硬套本类型十节 |
| 存在价款、象征性 1 元、感谢费、互易对价 | `或相应买卖），不得直接当赠与。以物抵债让与担保→转本套导航的类型切开步骤重新定性。离婚分割→` 或相应买卖原子 | 不一边收钱一边套第 658 条 |
| 以物抵债、让与担保、名赠实卖 | 本套导航的类型切开步骤 | 不按无偿赠与放行 |
| 离婚财产分割、解除婚姻 | `离婚协议·审查` | 不把分割改成赠与任意撤销 |

| 已签，只问转账、交付、登记履行 | 本套导航的履约步骤 | 不回写签前意见充作成交 |

| C 端大众快检或 C 端赠与起草 | 只分流，不回改 | 不复制起草模板 |

## 本类型内转出（仍可先标风险再停）

- 金钱/动产主给付中夹带房屋条款：房屋块负触发 `房产赠与合同·审查`/`亲属间房屋赠与合同·审查`，金钱/动产块可继续；不得用房屋过户清单覆盖整案。
- 大额且存在已知债权人或执行案件：告知第 538 条，不设计逃债履行结构。
- 配偶/共有人未同意、监护人对外重大赠与难证有利于被监护人：签署能力字段停止。
- 用户要保证有效、保证必然过户或强制交付：停止保证，只保留事实摘录与修改句草稿。
