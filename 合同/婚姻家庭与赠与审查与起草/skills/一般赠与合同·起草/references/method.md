# 审查方法（锁定 赠与合同 / 一般赠与合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。`基本面.md` 用于校验类型、主体、标的、程序、结构和红旗；`框架.md` 用于按六步出修改句。两文件与本方法冲突时，以本方法已核验口径为准，不回写知识库。

本文件是可执行判断节点，不是栏目说明书。每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、必然可强制交付、对方必然接受或债权人不能再追。

`search_law` 返回已失效《合同法》赠与章及其解释、已失效《物权法》、已失效《房屋登记办法》时记为噪声，不得写入 `L#`。返回“公证后未过户仍可凭声明书任意撤销”与第 658 条第 2 款冲突，记噪声。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

示范文本只参考结构。不得把网上赠与模板粘贴为本约，不得完成本任务项下的整份起草。禁止把商品房五证、网签、限购规避、买卖定金或离婚三块写进本方法主路径。

## 节点 0　签署状态与成果分流

先于类型识别。命中任一项则本任务不填十节实体结论，只交付分流理由和最小交接。

| 已能支持的事实 | 走向 | 不得写成 |
| --- | --- | --- |
| 无可读正文和附件，或只有“想把钱给对方”的口头要点 | `一般赠与合同·起草` | 已经完成审查；已经出整稿；可以签 |
| 未签，目标是评改已有《赠与合同》《赠与协议》 | 进入节点 1 | 已签署、已生效、权利已转移 |
| 残缺模板，用户要按己方条件重写整份 | `一般赠与合同·起草` | 已经完成审查；转通用起草引擎出本类型终稿 |
| 已签，只问何时转账、如何交付、如何办登记 | 本套导航的履约步骤 | 签前意见 |
| 已发撤销/返还通知，或催告、索赔、立案、开庭、仲裁 | `已催告解除索赔诉讼或仲裁→` | 继续当签前审查并给诉讼策略 |
| 劳动/工程/金融/股权/家事文本，或家事但核心给付不是一般赠与 | 节点 1 负触发 | 因“赠与”二字整案硬审或整案拒绝 |

缺立场或同时掌握双方秘密：整体停止策略输出，澄清代表哪一方。缺文本仍要“给个能不能签”：不启动实体审查。

用户要求倒签签署日、补假公证、补假交付回单：整体停止。

## 节点 1　类型识别、无偿定性闸与邻类切开

### 1.1 定性

用标题、核心给付、有无对价和用户陈述定性，不用标题单独定性。名实不符按核心给付归类，标题冲突写入 `C#`。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |

| 任何价款、象征性 1 元、感谢费、互易财产 | 买卖或有偿 | 负触发 `或相应买卖），不得直接当赠与。以物抵债让与担保→转本套导航的类型切开步骤重新定性。离婚分割→` 或相应买卖 |
| 以物抵旧债、过户为担保、回购 | 抵债或让与担保 | 负触发引擎重新定性 |

| 救灾、扶贫、助残等公益或道德义务已写死用途，用户要按不得任意撤销审 | 公益、道德义务赠与 | 负触发 `公益道德义务性质的赠与合同·审查` 或点名 658 例外；P1 未装则 `unavailable` |
| 股权零元、股东名册、公司变更登记为主给付 | 股权赠与 | 负触发 `零对价股权赠与·审查` |

| 包养、以金钱换同居或不正当关系维持 | 不正当关系赠与 | 负触发 `涉及不正当男女关系的赠与合同·审查`；只告知，不设计可履行结构 |
| 仅移转占有、不转移所有权 | 借用/保管 | 转引擎，不按赠与审 |

借用、保管未转移所有权：不是本类型。人身权、身份权本身不能作为赠与标的。

### 1.2 无偿定性闸（硬闸）

第 657 条：赠与是将自己的财产**无偿**给予受赠人。对价判断看正文、附件和用户承认，不看标题。

| 已有事实 | 动作 | 修改句方向 |
| --- | --- | --- |
| 写明无需支付价款或其他财产对价，材料未见对价 | 留本任务 | 首部或标的条补无偿声明 |
| “象征性 1 元”“手续费以外的补偿”“感谢费” | 先按有偿切开 | 删除对价并书面确认无偿，或整案转买卖；禁止保留 1 元仍套 658 |
| 以赠与之名清偿旧债或抵担保 | 转引擎 | 不按任意撤销赠与放行 |
| 离婚分割条款混在赠与标题下 | 转 `离婚协议·审查` | 不把分割改成赠与 |

最强反方：相对方主张 1 元只是形式、实质仍无偿。回应：有财产对价即应先按有偿审查；是否“名为买卖实为赠与”依据不足时不在本任务改定性结论，字段停止。

### 1.3 加载协议（硬闸）

本技能已锁定 **赠与合同 / 一般赠与合同**。只打开 `references/基本面.md` 与 `references/框架.md`。禁止读其他类型子目录，禁止为对照再开第二类。禁止打开房产赠与或离婚协议知识来拼过户清单。

### 1.4 违法结构停笔

加载后或定性中出现：先过户再躲债或规避执行；伪造处分权或假配偶同意；规避限购；设计可履行包养；监护人掏空被监护人财产。

动作：

1. 交付告知：该结构不能改写成可对抗债权人、登记机关、监护制度或公序良俗的可履行文本。
2. 不写假债务清单、假“债权人已同意”、假限购路径、包养履行时间表。
3. 风险表只保留识别依据和转出/改道提示。
4. 用户坚持“改到能签能躲债/能包养/能过限购”：整体停止。

合规改道（真实披露债务、取得共有人同意、办理公证锁定履行）只出修改句，不在本任务起草逃债或包养替代方案。

## 节点 2　主体、处分权、共有、监护

对照 `基本面.md` 第二节。

1. 主体表：赠与人、受赠人姓名或名称（去标识）、证件类型、住所。名称与证件不一致不自动合并。本类型不造“付款名/发票名”空表充数；有税费约定时单列承担方即可。
2. 赠与人须对标的有处分权或事后能取得处分权。材料未显示处分权：字段停止，不写“可以交付”。
3. 限制民事行为能力人作为**受赠人**的纯获益，一般可有效；作为**赠与人**须法定代理人同意或追认。角色反了不得混写。
4. **共有/配偶**。夫妻共同财产或共同共有物，须全体共同共有人同意（第 301 条）。一方擅自赠与第三人：签署能力字段停止。修改句要求配偶或共有人书面同意作为附件；未闭合不得写成可以签署。
5. **无权处分与善意取得**。合同效力与物权分层，不在本任务宣告合同当然无效或当然有效。赠与无偿，欠缺第 311 条“合理的价格”，原则上不构成善意取得。禁止修改句出现“受赠人善意即可取得所有权”。
6. **监护**。监护人除为维护被监护人利益外，不得处分被监护人财产（第 35 条）。代被监护人对外重大赠与：要求说明如何最有利于被监护人；不能说明则停笔，不改可履行掏空结构。
7. 法人、合伙对外赠与：查章程或决议痕迹。国有、集体、慈善财产另受监管：字段停止并升级，不在本任务设计可履行对外赠与。
8. 代签必须附授权书。口头“家里都同意了”不得写成已授权或已同意。

版本表：正文、财产清单、配偶同意书、聊天确认。冲突并列，不选对用户有利的一版。

## 节点 3　任意撤销默认与公证/公益例外（658）

对照 `基本面.md` 第一、四节与 `框架.md` 任意撤销窗口。

第 658 条第 1 款：赠与人在赠与财产的**权利转移之前**可以撤销赠与。这是默认规则，不是例外。

第 658 条第 2 款：经过公证的赠与合同，或依法不得撤销的具有救灾、扶贫、助残等公益、道德义务性质的赠与合同，不适用前款。第 660 条：仅上述两类，赠与人不交付时受赠人可以请求交付。

| 文本/事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 未公证，也非公益、道德义务；权利未转移 | 默认可任意撤销。受赠人立场：修改句改为签署后日内办理公证，或接受“通常不能强制交付”。赠与人立场：保留窗口，不预先交付、不公证 | 合同成立就必须交付/过户；起诉必能强制履行 |
| 正文反复“永久不可撤销”“不得反悔”，但无公证条款、无公益用途 | `必须改`。删除空文，改为“双方应于签署后【待填】日内办理赠与合同公证；公证完成前，第 658 条第 1 款仍适用” | 空写不可撤销即已关闭任意撤销 |
| 已公证，或用途固定为救灾扶贫助残等 | 不得任意撤销。点名例外；用户要按公益整案审则转 `公益道德义务性质的赠与合同·审查` | 公证后未过户仍可凭声明书任意撤销 |
| 用户要本任务保证公证后对方绝对不能反悔 | 停止保证。公证关闭的是任意撤销，不关闭第 663、664、666 条 | 公证后赠与人再无任何退出 |

修改句必须写清：**未公证且权利未转移的，受赠人通常不能强制交付。**

最强反方：受赠人已装修、已辞职、已发生费用，主张不得撤销。回应：信赖支出可能另循缔约过失等路径主张赔偿，但不因此把未公证赠与改写成必须交付；本任务不认定赔偿金额。

## 节点 4　合同成立 ≠ 物权变动，部分履行拆分

对照 `基本面.md` 第三、四节。

1. 第 657 条合同是诺成、原则上不要式：双方意思表示一致即可成立。第 215 条：设立、变更、转让、消灭不动产物权的合同，未办理物权登记的，不影响合同效力。不得把“未过户”写成“合同不成立”。
2. 权利转移另算：金钱以转至受赠人本人账户为准；动产自交付（第 224 条）；依法应登记的，办理第 659 条手续且不动产登记完成（第 209 条）后物权才变。钥匙、占有、过户三者分开写，禁止用一个“交付”混用。
3. **未办第 659 条手续，任意撤销窗口仍在。** 不得写成“合同生效即取得物权或股东资格”。
4. **部分履行拆分（硬闸）**。已交付或已登记部分，不得再依第 658 条任意撤销；未交付、未登记部分仍可。按标的、批次、金额分行，禁止整份一刀切。
5. 房产或股权若只是夹带：该块负触发邻类，本任务不为房屋出具网签、五证、限购主清单。
6. 权利负担：抵押、质押、查封、冻结、居住权、租赁不因赠与当然消灭。材料未提及不得写成“无权利负担”，只能写 `依据不足`。
7. 批准、登记写成双方义务和期限，不写成已经完成。用户要求把登记写成已经完成：整体停止。

修改句示例方向：

- 正说：赠与人应于【待填】日前将【待填】交付至受赠人。
- 反说：该部分权利转移前，未经公证且非公益、道德义务的，赠与人有权就**未转移部分**撤销；已转移部分不得依第 658 条撤销。

## 节点 5　逃债赠与（538）

第 538 条：债务人以无偿转让财产等方式无偿处分财产权益，影响债权人的债权实现的，债权人可以请求人民法院撤销。无偿处分不问受赠人是否善意。第 541 条：自债权人知道或应当知道撤销事由之日起一年；自行为发生之日起五年内未行使的，撤销权消灭。第 542 条：被撤销的行为自始没有法律约束力。

| 已有事实 | 动作 |
| --- | --- |
| 大额赠与，材料未披露负债 | 风险表必须有一行：建议债务摸底；判断用 `依据不足，无法形成结论` 是否构成第 538 条 |
| 用户或文本显示诉讼、执行、即将判决仍无偿转移 | 红线告知债权人可撤销，不问受赠人善意 |
| 用户要“先过户再躲债”“先转到亲戚名下躲执行” | **整体停止**。不改可履行时间表，不写假“无债务声明”充作对抗 |
| 受赠人主张自己不知情、已善意 | 不得写成可以对抗第 538 条 |

最强反方：赠与人主张“个人财产与债务无关”或“金额不大”。回应：是否影响债权实现是事实问题，本任务不替债权人作生效裁判；大额必须上表，已知执行仍转移则停笔。

禁止修改句出现：“本赠与对任何债权人当然有效”“受赠人善意故不可撤销”。

## 节点 6　法定撤销、穷困抗辩、瑕疵担保

对照 `框架.md` 配套条款。公证或公益关闭的是任意撤销，不是本节点。

### 6.1 法定撤销（663、665）

受赠人有下列情形之一，赠与人可以撤销：（一）严重侵害赠与人或其近亲属合法权益；（二）对赠与人有扶养义务而不履行；（三）不履行赠与合同约定的义务。期间：知道或应当知道撤销事由之日起**一年**。撤销后可请求返还赠与财产（第 665 条）。

修改句必须：列明三项事由；写书面通知送达即发生撤销意思表示；返还范围；已消耗、已混同标的约定折价方法与计价时点。禁止只引条号无通知地址。

### 6.2 继承人、法定代理人（664）

因受赠人违法行为致使赠与人死亡或丧失民事行为能力的，继承人、法定代理人自知道或应当知道之日起**六个月**内撤销。修改句单列该期间，不得与一年混写。

### 6.3 穷困抗辩（666）

赠与人经济状况显著恶化，严重影响生产经营或家庭生活的，可以不再履行赠与义务。对象是**尚未履行部分**。已交付部分不因此自动返还。修改句写触发事实、证明材料、通知方式；禁止写成“生活变差即可追回已给财产”。

### 6.4 瑕疵担保（662）

一般赠与人原则上不对瑕疵承担责任。故意不告知或保证无瑕疵造成损失的，应当赔偿。附义务赠与在附义务限度内才与出卖人相同——若已是附义务主轴，应已在节点 1 转出。

审查有无把赠与人写成“如同出卖人”的过重保证：赠与人立场必须改；受赠人立场可保留故意不告知/保证无瑕疵的赔偿，但不得把一般赠与改成买卖品质担保而不转买卖。

赠与无对价，不得出现定金罚则。高额违约金与单务无偿不匹配：未公证且可任意撤销的，不宜用违约金强迫交付；公证或依法不得任意撤销的，可约定逾期交付违约金或继续履行。

## 节点 7　强制规范、公序良俗与格式条款

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

| 原文类型 | 动作 |
| --- | --- |
| 先过户再躲债、规避执行 | 停笔告知第 538 条；用户坚持则整体停止 |
| 包养、以金钱维持不正当关系 | 告知第 153 条公序良俗风险；转 `涉及不正当男女关系的赠与合同·审查`；不设计可履行时间表 |
| 规避限购、伪造资格 | 只告知，不改可履行规避 |
| 倒签、补假公证、补假交付 | 整体停止 |
| 监护人掏空被监护人 | 停笔 |
| 禁止流通物 | 不得赠与；红线 |

违反法律、行政法规强制性规定不一律无效（第 153 条）。禁止用已失效“效力性/管理性”口诀代替核验。无 `search_law` 引文则本节点法律结论字段停止。

一般赠与通常不是经营者重复使用的格式条款。一方制式且异常剥夺对方任意撤销或法定撤销的，仍审查提示痕迹，但不把第 496 条生搬成“未加黑就不成为赠与内容”。

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。禁止输出整份新合同充作审查成果。禁止输出房屋五证/网签过户主清单。

打开已加载的 `框架.md`，按下列六步逐段对照正文。

| 步 | 本类型动作 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题用赠与合同/协议；核对无偿；有“转让/补偿/交割”则重核对价；鉴于不写“已不可撤销”“已支付对价” | 标题或无偿声明修改句 |
| 交易条款 | **无偿声明**；标的清单（金钱账户/动产序列号）；接受赠与；**658 窗口或公证路径**；交付与权利转移分层；已交/未交拆分 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 663/664 通知与返还、666 穷困、662 瑕疵、税费承担、争议、送达 | 可执行通知/返还句；不写对外对抗债权人 |
| 尾部 | 本人签署；签署日与交付日、申请登记日分开；公证生效 vs 成立即可任意撤销必须选一条写死；附件清单 | 生效与附件修改句 |
| 语言 | 正说加反说；交付≠占有≠过户；不可撤销须有公证或公益支撑；禁止定金；禁止“尽快/适当”当期限 | 替换空词的句子 |
| 常见问题 | 只有承诺没有转移安排；用不可撤销代替公证；部分履行未拆分 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止；
- `必须改`：可谈但签署前要落句；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级财产或已知执行案件且用户拒绝升级：停止“可以签署”建议。
