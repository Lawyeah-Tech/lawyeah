# 一般赠与合同·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构，不证明本约条款已被接受，也不代替本任务出整稿。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》赠与章及其解释、已失效《物权法》当作现行规则。`search_law` 返回“公证后未过户仍可凭声明书任意撤销”一类口径时，与第 658 条第 2 款冲突，记噪声，不得写入 `L#`。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **赠与合同 / 一般赠与合同**，输出可编辑草稿、未决项，并在出稿后用本类型硬闸自审。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。中文名必须是「一般赠与合同（赠与合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类型起草、履约交底、争议文书、效力或必然可强制交付的保证、房屋网签过户五证主清单、可履行的逃债或包养结构。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **无偿是定性闸**。存在金钱或其他财产对价，即使“象征性 1 元”“感谢费”，先按有偿/买卖切开（`或相应买卖），不得直接当赠与。以物抵债让与担保→转本套导航的类型切开步骤重新定性。离婚分割→` 或相应买卖），不得直接当赠与。以物抵债、让与担保 → 转 本套导航的类型切开步骤 重新定性。离婚分割 → `离婚协议·审查`。修改句删除对价并书面确认无偿，或整案转出；禁止一边收钱一边套第 658 条。
2. **任意撤销是默认（658）**。权利转移前赠与人可以撤销。经过公证，或救灾、扶贫、助残等公益、道德义务性质 → 不得任意撤销；转 `公益道德义务性质的赠与合同·审查`，或在本类型点名该例外。修改句必须写清：未公证、权利未转移的，受赠人通常不能强制交付。禁止写成“赠与合同成立就必须过户/交付”。合同空写“永久不可撤销”不够，要改为办理公证或删除空文并保留窗口。
3. **合同成立 ≠ 物权变动**。动产自交付、依法应登记的自登记完成时权利转移（第 659、209、215、224 条）。未办第 659 条手续，任意撤销窗口仍在。已交付部分不得任意撤销，未交付部分仍可——按标的拆分，禁止整份一刀切。
4. **逃债赠与（538）**。影响债权人实现债权的无偿处分，债权人可请求撤销，不问受赠人是否善意。大额赠与必须上风险表。用户要“先过户再躲债”：整体停止，不改可履行转移结构。
5. **无权处分/共有**。擅自赠与共有物或他人财产：合同效力与物权分层；赠与欠缺“合理价格”，原则上不构成善意取得（第 311 条）。配偶/共有人未同意：签署能力字段停止。监护人代被监护人对外重大赠与：须最有利于被监护人（第 35 条），否则停笔。
6. **法定撤销与穷困**。第 663 条三项事由，自知道或应当知道之日起一年；第 664 条继承人/法定代理人六个月；第 666 条经济状况显著恶化可不再履行尚未履行部分。修改句必须写通知送达、返还范围；已消耗标的约定折价。不得用第 666 条追回已交付部分。
7. **邻类切开**。附义务主轴 → `附义务的赠与合同·审查`；房产主标的 → `房产赠与合同·审查`；亲属间房屋 → `亲属间房屋赠与合同·审查`；股权零元转让 → `零对价股权赠与·审查`；遗赠/死因 → `生前类赠与协议·审查`/`类赠与遗赠扶养协议·审查`；不正当关系赠与 → `涉及不正当男女关系的赠与合同·审查`（只告知公序良俗风险，不设计可履行包养结构）。禁止把房屋过户五证、限购规避写成一般赠与可履行路径。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿，尚未签署，尚未成争，核心给付是生前无偿转移金钱或普通动产等财产权利，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 存在价款或其他财产对价（含象征性 1 元）→ `或相应买卖），不得直接当赠与。以物抵债让与担保→转本套导航的类型切开步骤重新定性。离婚分割→` 或相应买卖原子；
- 主标的是房屋、不动产过户 → `房产赠与合同·审查`；亲属之间房屋 → `亲属间房屋赠与合同·审查`；
- 主轴是受赠人负担对待义务 → `附义务的赠与合同·审查`；
- 救灾扶贫助残等公益、道德义务已锁定，用户要按不得任意撤销整案审 → `公益道德义务性质的赠与合同·审查`（P1；专业版未装则 `unavailable`，本类型只点名 658 例外）；
- 股权零元转让 → `零对价股权赠与·审查`（P1；未装则 `unavailable`）；
- 死后生效、遗赠、遗赠扶养 → `生前类赠与协议·审查`/`类赠与遗赠扶养协议·审查`（P1；未装则 `unavailable`）；
- 不正当关系、包养对价 → `涉及不正当男女关系的赠与合同·审查`（P1；未装则只告知，不设计可履行结构）；
- 离婚财产分割、解除婚姻安排 → `离婚协议·审查`；
- 以物抵债、让与担保、名赠实卖 → 本套导航的类型切开步骤；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问转账、交付、登记节点 → 本套导航的履约步骤；
- 已催告、撤销通知已发、索赔、诉讼或仲裁 → `已催告解除索赔诉讼或仲裁→` 或对应专项领域。

挂靠、违法分包、规避限购、逃债过户：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（赠与人或受赠人，或其代理人）；相对方；全文及附件版本；有无任何对价或基础债务；标的种类（金钱/动产 vs 房屋/股权）；是否已公证或拟公证；是否已交付或部分交付；赠与人婚姻与共有；对外负债、诉讼、执行；监护或代签；不可接受事项；法域与拟签署日。

缺立场、同时掌握双方秘密、或无可读文本：不启动实体审查。

来源编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不选对用户有利的一版。未给出的金额、账号、期限用 `【待填】`，不编造。

## 起草模式

本原子只承担本类型起草。待签评改转 `一般赠与合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`，不编造。出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 无偿声明：无需支付价款或其他财产对价。存在任何对价（含象征性 1 元、感谢费）不得当赠与起草，转买卖或重新定性。
- 任意撤销是默认（第 658 条）。未公证、权利未转移的，必须写清受赠人通常不能强制交付。关闭窗口须办理公证，或点名救灾、扶贫、助残等公益、道德义务例外。
- 合同成立 ≠ 物权变动。动产自交付、依法应登记的自登记完成时权利转移。已交付部分不得任意撤销，未交付部分仍可，按标的拆分。
- 法定撤销与穷困必须可操作：第 663 条一年、第 664 条六个月、第 666 条只停尚未履行部分；写通知送达、返还范围；已消耗标的约定折价。

### 附件必附

硬闸未单列独立附件清单。配偶或共有人未同意：不得写成可以签署。缺金额、账号、期限用 `【待填】`。

### 禁止出现

- 一边收钱一边套第 658 条。
- “赠与合同成立就必须过户/交付”；空写“永久不可撤销”而无公证或公益、道德义务支撑。
- 整份一刀切撤销，不拆已交/未交。
- 用第 666 条追回已交付部分。
- “受赠人善意即可取得所有权”（赠与欠缺合理价格，原则上不构成善意取得）。
- 逃债过户、规避限购、包养的可履行结构；房屋过户五证、限购规避路径。

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

0. 签署状态与成果分流：有完整待签文本要评改 → `一般赠与合同·审查`；本类型条件已谈妥要出己方稿 → 本任务起草并自审；已签只问履行→履约；已成争→争议。
1. 类型识别：无偿定性闸；切开买卖、抵债、离婚分割、房产、亲属房屋、附义务、股权、遗赠、不正当关系。只加载本类型双文件。
2. 主体、处分权、共有、监护：签署能力未闭合则字段停止。
3. 任意撤销默认与公证/公益例外：未公证未转移则受赠人通常不能强制交付。
4. 合同成立 vs 物权变动：交付/登记分层；已交/未交按标的拆分。
5. 逃债赠与：大额上风险表；躲债整体停止。
6. 法定撤销、继承人撤销、穷困抗辩、瑕疵担保：通知、返还、折价必须可操作。
7. 强制规范与公序良俗：包养、逃债、倒签停笔。
8. 按框架六步出修改句：首部、交易条款（无偿+撤销窗口+交付分层）、配套、尾部、语言、常见问题。

必须有修改句。禁止只打红黄绿。每个风险回链文本位置。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、保证有效或必然强制交付、把逃债过户或包养改成可履行文本、把监护人不利被监护人的重大赠与改到能签。
- `字段停止`：法域、处分权、共有同意、负债全貌、公证是否办成、已履行比例未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议策略，或已锁他类（房屋、股权、买卖、附义务等）。

生存级财产或已知执行案件且用户拒绝升级：停止“可以签署”建议，只列风险与转介。
