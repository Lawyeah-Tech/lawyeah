# 边界与路由

本技能只审查 **婚姻家庭 / 扶养_抚养协议**。先切开抚养轨与扶养轨，再与邻类切开。

| 主要目标 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 成年子女供养父母，或孙子女供养祖辈 | `赡养协议·审查` |
| 解除婚姻 + 财产债务 + 直接抚养安排的一揽子文本 | `离婚协议·审查` |
| 主轴是变更直接抚养人或监护 | `抚养权变更协议·审查` |
| 主轴是分居居住和家事安排 | `分居协议·审查` |
| 主轴是婚内财产归属 | `夫妻财产约定·审查` |
| 继承人以外的人生养死葬并取得遗产 | 引擎重新定性，或继承领域遗赠扶养 |
| 无可读正文，本类型条件已谈妥，要出己方稿 | `扶养抚养协议·起草` |
| 已签未争、履约节点 | 本套导航的履约步骤 |
| 已成争（追索、变更、执行） | `或对应家事争议原子。` 或对应家事争议原子 |
| C 端大众测算或路径评估 | 只分流，不回改 |

买断法定义务、探望挂钩、转嫁无能力第三方、私人文本自我授予司法确认：留在本技能只出告知并停笔，不转去“改成可履行稿”，也不转争议原子充作签前修改。

专业版未收录的 P1 家事变体不会安装对应原子。若用户拿这些文本来找专业版：输出 `unavailable`，提示或回引擎，不得用本抚养/扶养原子硬套。
