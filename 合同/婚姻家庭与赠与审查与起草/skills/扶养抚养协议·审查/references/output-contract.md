# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受、必然可执行或以后不会被追加；编造未给出的金额、收入、学费；把已失效《婚姻法》及其解释、《合同法》及其解释写入结论；把大学毕业写成法定抚养终点；把私人协议司法确认写成与判决同等执行力；把公证写成探望或人身照料也可强制执行。

## 1. 触发、单方立场与成果状态

立场（给付义务人或受领方/直接抚养方）、授权、签署状态、主要目标。负触发写路由，不启动实体审查。赡养、离婚一揽子、抚养权变更、遗赠扶养必须在本节写明负触发，不得进入第 5–8 节。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效婚姻法、婚姻法解释或合同法及其解释时记噪声，不得写入 `L#`。解释（一）与法释〔2020〕22 号、解释（二）与法释〔2025〕1 号条号不一致时记 `conflict`，以有权机关施行文本为准。

## 3. 类型与加载路径

父级、子级、定性理由、抚养轨或扶养轨、易混切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读其他类型。买断、探望挂钩或转嫁第三方写停笔告知，不填可履行结构。

必须写明已切开：抚养 / 扶养 / 赡养 / 离婚一揽子 / 抚养权变更 / 分居 / 夫妻财产约定 / 遗赠扶养。

## 4. 主体、授权、监护与文本版本

主体表：法定义务人、受领方、被抚养/被扶养人、代签监护人、付款名、收款名。亲属方向与第一千零七十五条条件是否被材料提及。版本表：正文、附件、此前离婚调解书或判决中的费用条款、聊天确认；冲突并列，不选对用户有利的一版。

## 5. 给付闭环

抚养三费或扶养生活护理、大额分担、账户与日期、一次性或分期、期限、以财产折抵是否另层处理。缺口标 `G#`，不补商业数字。公证、见证、司法确认写成程序选项或生效条件，不写成已经取得执行名义。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹。强制规范只区分是否导致民事行为无效。本节点必须单独回答：买断开口、探望是否脱钩、法定义务人是否被替换、解释（一）第四十一条期限。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

本类型风险表至少覆盖（有文本才填，无对应条款标缺口）：

- 标题与亲属方向（抚 / 扶）是否一致；
- 法定义务人是否被替换或转嫁；
- 抚养三费或扶养生活护理是否分列；
- 一次性给付是否封闭追加开口；
- 一方负担全部时直接抚养方能力；
- 探望与给付是否挂钩；
- 期限是否把大学毕业写成法定终点；
- 司法确认自我授权或公证范围过宽；
- 调整开口与不得排除起诉。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。禁止输出无修改句的色块表。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`，不编造。禁止只给原则、不给句子。

买断条款的修改句必须保留第一千零八十五条第二款或解释（一）第五十八条开口。探望条款必须与给付脱钩。司法确认句必须改成调解组织路径或删除。公证句必须限定金钱给付和接受强制执行承诺。禁止把大学毕业写成法定抚养终点。

## 9. 谈判与签署提醒

谈判顺序：先红线（买断、探望挂钩、转嫁第三方、自我授予司法确认），再必须改（三费分列、追加开口、公证范围、调整出口、一方负担全部），最后可优化。签署提醒：适格代理人到场；被抚养/被扶养人身份证件复印件附卷；账户页与收入、学费、诊断材料作为附件；日期如实，不倒签。不指导补假调解组织印章或保证不再被追加。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本审查原子成果不是整份起草终稿。出稿转 `扶养抚养协议·起草`。不是履约交底、离婚诉讼文书、追索起诉状或效力保证。买断或探望挂钩已停笔的，本节重复告知一次。
