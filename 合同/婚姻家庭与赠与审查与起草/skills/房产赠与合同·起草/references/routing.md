# 边界与路由

本技能只起草 **赠与合同 / 房产赠与合同** 的待签、无偿转移房屋权利文本。中文展示名是「审查房产赠与合同（赠与合同）」。覆盖非亲属、远亲、朋友、法人与个人；亲属身份带来的税率和家庭伦理不是本类型主线。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 近亲属或家庭内部给房；主线是赡养、只赠一方、亲属税率、婚内加名 | `亲属间房屋赠与合同·审查`；婚内财产制度安排走 `夫妻财产约定·审查` 或 `婚姻家庭中的赠与合同·审查` |
| 有房款、补偿款、装修折价、债务抵销作为取得房屋的对价 | `或` 或 `真实房屋买卖，买受人取得所有权` |
| 标的是现金、动产或权利，不是房屋物权 | `一般赠与合同·审查` |
| 受赠人须持续履行义务才给房，义务是主给付 | `附义务的赠与合同·审查` |
| 救灾、扶贫、助残等公益、道德义务赠与是主文件 | `公益道德义务性质的赠与合同·审查` |
| 解除婚姻并分割夫妻共同财产 | `离婚协议·审查` |
| 家庭共有财产分割、分家析产 | `分家析产协议·审查` |
| 死后生效、遗嘱或遗赠过户 | `生前类赠与协议·审查` 或 `遗嘱·审查` |
| 股权零元转让 | `零对价股权赠与·审查` |
| 仅设立居住权、不过户所有权 | `居住权设立合同·审查` |
| 购房合同相对人一开始就是受赠人，审查出资与撤销 | 转引擎重新定性，不在本任务当赠与本约改完 |
| 无可读正文，本类型条件已谈妥，要出己方稿 | 本任务起草并自审 |
| 已签未争、只问过户日、完税日、腾空日 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `已催告解除索赔诉讼或仲裁→` 或对应专项领域 |
| 债权人已提起撤销、执行异议或逃债刑事立案 | 争议或执行专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

房产赠与正文里夹带一小段居住权或动产清单：专章可继续审；居住权设立合同整案交接 `居住权设立合同·审查`。用户坚持本技能把亲属房屋、买卖、一般赠与或遗赠整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
