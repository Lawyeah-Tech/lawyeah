# 扶养/抚养协议·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构，不证明本约条款已被接受。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《婚姻法》及其解释、《合同法》及其解释当作现行规则。
- 婚姻家庭编解释（一）条号以法释〔2020〕22 号为准；解释（二）条号以法释〔2025〕1 号为准。律页已收录时仍须与有权机关公布文本核对；冲突时以施行文本为准并记录冲突。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **婚姻家庭 / 扶养/抚养协议**，输出可编辑草稿、未决项，并在出稿后用本类型硬闸自审。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。`depends-on` 为空。

不交付：他类合同审查；待签文本签前审查（转 `扶养抚养协议·审查`）；履约交底；争议文书；有效性或对方接受的保证；把买断法定义务、探望挂钩给付、转嫁无能力第三方或私人文本“司法确认即判决”改成可履行结构。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿，尚未签署，尚未成争，核心给付是把**已经存在的法定抚养义务或法定扶养义务**量化为金额、支付路径、大额分担和调整开口。本技能先切开再审：

- **抚养轨**：父母（含非婚生父母）对未成年子女或不能独立生活的成年子女，或符合条件的祖父母、外祖父母对孙子女、外孙子女，量化生活费、教育费、医疗费及大额分担。
- **扶养轨**：夫妻相互扶养，或符合民法典第一千零七十五条条件的兄姐与弟妹相互扶养，量化生活费、护理费、居所和照料。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 核心给付是成年子女供养父母或孙子女供养祖父母、外祖父母 → `赡养协议·审查`；
- 文本是离婚一揽子：解除婚姻 + 共同财产债务 + 直接抚养安排 + 户口/探视为同一套对价 → `离婚协议·审查`；
- 核心给付是变更直接抚养人或监护，费用只是附属 → `抚养权变更协议·审查`；
- 核心给付是分居期间居住、家事分工、共同财产使用，扶养只是其中一章 → `分居协议·审查`；
- 核心给付是婚内财产归属或债务分担，扶养/抚养费只是附带一句 → `夫妻财产约定·审查`；
- 继承人以外的人承担生养死葬、死后取得遗产 → 遗赠扶养，转引擎或继承领域，不按本类型改；
- 有完整待签文本要评改 → `扶养抚养协议·审查`；
- 无可读文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问付款日、账户留痕 → 本套导航的履约步骤；
- 已成争（催告、立案、追索抚养费/扶养费、变更之诉）→ `或对应家事争议原子。` 或对应家事争议原子。

规避监管、伪造倒签、把买断或探望挂钩改成可履行：只出告知，不改写成可履行结构。用户坚持“改到能签”：整体停止。

## 本类型硬闸

执行时必须同时守住，不得用通用买卖/承揽口径或邻类家事口径替换：

1. **先切开扶养与抚养，再出句。** 标题、亲属方向和费用名必须一致。抚养用生活费、教育费、医疗费；扶养用生活费、护理费、居所。禁止把“抚”“扶”混写，也禁止把向上供养写成扶养。
2. **与赡养切开。** 供养父母或向上供养祖辈，整份负触发，转 `赡养协议·审查`。不得用本技能改赡养稿。
3. **与离婚一揽子切开。** 解除婚姻、分割共同财产、直接抚养人、户口迁移捆在同一文本，整份负触发，转 `离婚协议·审查`。本技能只吃已经分居、尚未离婚或离婚后单独量化费用的文本。
4. **法定义务不可买断。** “一次付清、永不再付、不得追加、不得起诉”必须改出救济开口。子女必要时仍可请求超过原定数额（民法典第一千零八十五条第二款；解释（一）第五十八条）。一方负担全部费用若直接抚养方明显无力保障子女所需，解释（一）第五十二条不予支持。
5. **探望与给付脱钩。** 不得把付费多少、是否按时付款写成探望条件；不得把不让看孩子写成停付条件。探望只因不利于身心健康由法院中止，不能对子女人身强制执行。
6. **司法确认与公证分账。** 私人协议加“共同申请司法确认即与判决同等执行力”不得放行。司法确认只吃调解组织主持的调解协议，且不受理身份关系确认。公证强制执行只覆盖给付明确且载明接受强制执行承诺的金钱债务，覆盖不了探望、亲自照顾或身份安排。
7. **“大学毕业”不是法定独立生活。** 解释（一）第四十一条只覆盖高中及其以下学历教育，或非因主观原因丧失、部分丧失劳动能力。把本科、研究生写成当然继续给付，必须改成另行协商或另案，不得写成法定义务已延至毕业。

## 建立审查坐标

确认：使用者与授权；单方立场（给付义务人或受领方/直接抚养方，不得同时服务双方）；相对方；被抚养人或被扶养人姓名、出生日期、劳动能力；亲属方向（向下抚养 / 平行扶养）；全文与附件版本；账户与收入材料是否被提及；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。

## 起草模式

本原子只承担本类型起草。待签评改转 `扶养抚养协议·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`，不编造。出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 先切开扶养与抚养，再落句。标题、亲属方向和费用名必须一致：抚养写生活费、教育费、医疗费；扶养写生活费、护理费、居所。
- 法定义务不可买断。一次付清只解决已约定区间的履行方式，必须保留救济开口：子女必要时仍可请求超过原定数额（民法典第一千零八十五条第二款；解释（一）第五十八条）。一方负担全部费用时，须能写明直接抚养方负担能力，否则改回按比例分担。
- 探望与给付脱钩。探望只因不利于身心健康由法院中止，不能对子女人身强制执行。
- “大学毕业”不是法定独立生活。解释（一）第四十一条只覆盖高中及其以下学历教育，或非因主观原因丧失、部分丧失劳动能力。本科、研究生只可写成另行协商或另案。
- 司法确认与公证分账。公证强制执行只覆盖给付明确且载明接受强制执行承诺的金钱债务。

### 附件必附

硬闸未单列独立附件清单。缺金额、比例、日期用 `【待填】`；账户、收入、诊断材料未给则标未决项，不编造。

### 禁止出现

- 把“抚”“扶”混写，或把向上供养写成扶养；不得起草赡养稿或离婚一揽子。
- “一次付清、永不再付、不得追加、不得起诉”。
- 付费多少、是否按时付款写成探望条件，或不让看孩子写成停付条件。
- 私人协议加“共同申请司法确认即与判决同等执行力”。
- 公证强制执行覆盖探望、亲自照顾或身份安排。
- 把本科、研究生写成当然继续给付的法定义务。
- 把买断、探望挂钩、转嫁无能力第三方改成可履行结构。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、买断法定义务、探望与给付互为条件、把无能力第三方写成新的法定义务人、保证有效或保证不再被追加。
- `字段停止`：亲属方向不明；被抚养/被扶养人年龄或劳动能力不明；动态规则未核验；金额关键事实缺失。
- `目标停止`：主目标已变为待签评改、履约交底、离婚整案或追索之诉。

生存级费用缺口或个人无限连带且用户拒绝升级：停止放行建议。
