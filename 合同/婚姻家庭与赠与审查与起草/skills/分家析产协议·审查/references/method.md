# 审查方法（锁定 婚姻家庭 / 分家析产协议）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止打开或复制 `夫妻财产约定·审查`、`离婚协议·审查` 的审查路径。禁止复制离婚冷静期、夫妻约定对外效力主路径、赠与任意撤销主路径、买卖户口/网签过户手册或施工挂靠节点。

定性校验：标题、核心给付与本类型一致才继续；离婚财产、夫妻二人约定、个人财产赠与、死后遗产安排或其他家事明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、签字即过户、未登记可对抗查封、对方必然接受或唯一必得份额。

`search_law` 返回已失效《物权法》《婚姻法》《合同法》第 74 条及其解释、《继承法》意见时记为噪声，不得写入 `L#`。

示范文本只参考结构。把已故配偶遗产或“百年后由某子女继承”写进分家的范本，只证明应切开继承，不得当作本类型已完成遗产安排。

知识库纠正（不回写双文件）：

- `框架.md` “签署日期是判定财产所有权转移的时间点”：合同可自签字对签字人生效；不动产自记载于登记簿时发生物权变动。修改句必须拆开。
- `框架.md` “受赠人/父母有权撤销该部分析产”：真家庭共有析产不适用赠与任意撤销。赡养不履行应写成约定解除或返还，禁止使用“受赠人”标签。
- `基本面.md` “认定为分家则任意撤销权通常受限”：只作倾向，不得写成必然不可撤销。
- 实务材料称“分家也可处分长辈个人财产”：个人财产条块切开后移交赠与原子，不在本类型按析产放行。

## 节点 0　签署状态与成果分流

先于类型识别。命中任一项则本任务不填十节实体结论，只交付分流理由和最小交接。

| 已能支持的事实 | 走向 | 不得写成 |
| --- | --- | --- |
| 无可读正文和附件，或只有口头“明天按手印” | `分家析产协议·起草` | 已经完成审查；可以签 |
| 未签，目标是评改已有分家析产或家庭财产分割文本 | 进入节点 1 | 已签署或已生效 |
| 残缺模板，用户要按己方条件重写整稿 | `分家析产协议·起草` | 已经完成审查；转通用起草引擎出本类型终稿 |
| 已签，问过户预约日、补偿款转账日、腾房 | 本套导航的履约步骤 | 签前意见 |
| 已出现催告、解除、索赔、立案、开庭、仲裁，或用户要撤销权/执行异议诉状 | `已催告解除索赔诉讼或仲裁→` 或家事、执行专项 | 继续当签前审查 |

缺立场或同时掌握互斥多方秘密：整体停止策略输出。缺书面文本仍要“给个能不能签”：不启动实体审查。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 父母健在或家庭共同生活基础仍在；分割家庭成员共同创造或共同持有的财产；折价补偿其他成员 | 本类型 | 正触发 |
| 双方解除婚姻，并处理夫妻共同财产、子女抚养或夫妻债务 | 离婚协议 | 负触发 `离婚协议·审查` |
| 仅夫妻二人书面约定婚内所得或婚前财产归各自/共同 | 夫妻财产约定 | 负触发 `夫妻财产约定·审查` |
| 登记在个人名下，材料不能支持其他家庭成员共有，无偿给予晚辈 | 赠与 | 负触发 `亲属间房屋赠与合同·审查`、`一般赠与合同·审查`、`附义务的赠与合同·审查` 或 `房产赠与合同·审查` |
| 被继承人已死亡，或文本主轴是死后按某份安排过户 | 遗嘱或遗产整理 | 负触发 `遗嘱·审查`（P1 未装则 `unavailable`） |
| 继承人以外的人负责生养死葬，死后取得财产 | 遗赠扶养 | 负触发 `遗赠扶养协议·审查` |
| 只约定赡养费、照料、医疗，无共有财产清单 | 赡养协议 | 负触发 `赡养协议·审查` |
| 分居期间居住开支，婚姻未解除，无家庭共有分割 | 分居协议 | 负触发 `分居协议·审查` |

支持切开的规范（法律结论须运行时复核）：

- 第 301、303、304 条：共同共有处分与协议分割——本类型主干。
- 第 1065、1087 条：夫妻财产约定与离婚时协议分割——转 `夫妻财产约定·审查` 或 `离婚协议·审查`。
- 第 657、658 条：把自己的财产无偿给予——转赠与原子。
- 第 1121、1153、1158 条：继承自死亡开始；遗产在家庭共有中应先分出他人财产；遗赠扶养是继承人以外的人——死后安排转出。

### 1.2 加载协议（硬闸）

本技能已锁定 **婚姻家庭 / 分家析产协议**。只打开 `references/基本面.md` 与 `references/框架.md`。禁止读其他子目录，禁止为对照再开第二类。

### 1.3 与离婚财产 / 赠与切开（硬闸）

| 文本写法 | 本任务动作 | 修改句方向 |
| --- | --- | --- |
| 家庭成员对共建老宅、共同经营积累做分割，父母仍在世 | 正触发，留下本类型 | 首部写明“家庭共有财产分割，不是离婚财产分割，也不是赠与” |
| 标题写分家，正文是“双方自愿离婚，房产归女方，债务归男方” | 负触发 `离婚协议·审查` | 不按析产改完 |
| 仅夫妻二人，无子女或其他共有人，约定婚后工资各自所有 | 负触发 `夫妻财产约定·审查` | 不按家庭共有改完 |
| 父亲婚前全款、登记个人、无子女出资的房屋“分给”幼子，并写不得撤销 | 负触发赠与原子；或必须改：该条整段移出本协议 | 不得在本类型写成析产且任意撤销权消灭 |
| 真家庭共有，但条款使用“赠与人/受赠人/任意撤销” | 必须改：删除赠与术语，改回析产 | 「本条是对家庭共有财产的分割，不是赠与。任何一方不得依照赠与合同任意撤销本条。」 |

最强反方：未分得财产的子女主张案涉房屋是父母个人财产，应按赠与撤销；或配偶主张案涉房屋是夫妻共同财产，应走离婚分割。修改句必须让清单自证形成过程，不能靠标题自称。用户坚持把离婚或赠与主轴留在本技能放行：负触发，不填本类型十节实体结论。

### 1.4 逃债 / 规避限购 / 宅基地对外流转停笔（硬闸）

加载后或定性中出现：把唯一责任财产转到非债务人名下且目的是躲避已有或高度确定的执行；伪造购房资格或借分家规避限购；把宅基地住房协议过户给非本集体经济组织成员并要求写成可履行过户。

动作：

1. 交付告知：无偿处分影响债权实现的，债权人可请求撤销（第 538 条）；撤销后自始无约束力（第 542 条）。宅基地转让适用土地管理法律（第 363 条）；一户一宅，出卖、出租、赠与住宅后再申请不予批准（土地管理法第 62 条）。不得改写成可履行的逃债或对外流转结构。
2. 不写可履行的“债权人不得主张”、假资格路径或对外过户时间表。
3. 风险表只保留识别依据和删除/转出口径。
4. 用户坚持“改到能签且仍做这些事”：整体停止。

## 节点 2　家庭共有分割与主体闭合

### 2.1 财产定性表（硬闸）

为每一项标的建表，缺一列则该项不得写成已可分割：

| 列 | 必须看见 | 不得写成 |
| --- | --- | --- |
| 名称与识别信息 | 地址+证号，或车辆识别号，或账户后四位 | “家里的房子”“存款若干”已确定 |
| 登记或持有名义 | 登记簿、宅基地证、存折户名 | 口头“大家都知道是公家的” |
| 形成过程 | 出资、共建、共同经营、共同继承或受赠的现有依据 | 标题写了分家即已是家庭共有 |
| 本次归属 | 归谁所有，或仍保留共有及份额 | “适当照顾”而无对象 |

分类动作：

- 能支持家庭共有 → 留下本协议分割。
- 能支持夫妻共同、且当事人正在或即将解除婚姻 → 整项交接 `离婚协议·审查`。
- 能支持个人财产无偿给予 → 整项交接赠与原子。
- 依据不足 → `G#`，字段停止，不补写成共有。

修改句：

「附件一《家庭共有财产清单》只列入各方一致确认、且有出资、共建或登记依据的家庭共有财产。下列财产不纳入本次分割：【待填】的个人财产；【待填】与【待填】的夫妻共同财产；【待填】未成年子女单独受赠或继承的财产。任何一方主张某项财产属于家庭共有但未列入附件一的，应在签署前书面补充依据，否则不得在签署后以本协议未列为由请求重新分割该部分。」

### 2.2 全体共同共有人（硬闸）

建主体表：签字人姓名、身份关系、是否共有人、是否监护代理、是否配偶需一并处分其夫妻共同份额。名称不一致不自动合并。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 户口或共建凭证显示还有女儿、继子女、儿媳对标的有贡献，文本未列 | 字段停止；修改句要求补列或书面放弃该份额 | 外嫁即当然无份；协议对未签字人当然有效 |
| 未成年人名下有财产或作为共有人 | 监护人代理须为被监护人利益（第 35 条）；利益相反则另选代理人或字段停止 | 父母一句话即可划走未成年人份额 |
| 共有人下落不明或能力存疑 | 该份额停止；不编造“视为同意” | 可以先签后补 |

修改句：

「附件二为家庭共有财产权利人名单。处分共同共有的不动产，须由全体共同共有人签字按指印；由监护人代签的，须书面说明符合被监护人利益，并不得使监护人单独取得该被监护人份额。未列入附件二且事后能证明对标的享有共有份额的人，本协议对其份额不发生处分效力。漏列权利人补签或出具经核验的书面放弃文件前，各方不得申请办理转移登记。」

口头“家里都同意了”不得写成已授权。

## 节点 3　标的、权利负担与宅基地

1. 房屋须落到坐落、证号或“待登记自建房+四至+示意图”。只有文字“东屋归长子”而无边界：必须改，要求附图。
2. 权利负担：抵押、查封、居住权、租赁。材料未提及不得写成“无权利负担”，只能写 `依据不足`。
3. 未取得产证的自建房：协议仅可能产生内部债权安排，不得写成已经取得可对外主张的所有权。
4. 宅基地房屋：受让方是否仍具本集体经济组织成员身份未核：过户字段停止。不得把对外流转改成可履行过户。非成员方权益用折价补偿句，不写“先过户再想办法落户”。

修改句：

「【地址/证号】房屋的地上建筑物按附件三示意图由【待填】占有使用。宅基地使用权的变动以土地管理法律和房屋所在地当时规则为准；【待填】如不具备本集体经济组织成员身份，不就宅基地使用权办理转移登记，由取得房屋占有的一方于【待填】日前向其支付折价补偿人民币【待填】元。各方确认：本条不构成向本集体经济组织以外的人转让宅基地。」

## 节点 4　登记对抗与居住权（硬闸）

支持依据：第 209、214、215、225、368 条；物权编解释（一）第 7 条（民间分家协议不是第 229 条法律文书）。

| 文本写法 | 动作 |
| --- | --- |
| “本协议签字之日，房屋所有权即归某某，无须过户也可对抗任何人” | 红线删除。拆成合同生效 vs 物权变动 |
| 只写“各方协助过户”无谁负责、几日内、税费、不成的后果 | 必须补义务主体、期限、违约金或解除+返还 |
| 为父母保留“继续居住”但未提居住权登记 | 必须改：居住权自登记时设立；未登记不得写成已有对抗效力的居住权 |
| 机动车只写“归次子使用” | 必须改：未经登记不得对抗善意第三人 |

修改句：

「本协议自全体共同共有人签字按指印之日起对签字方发生合同效力。不动产所有权的设立、变更自记载于不动产登记簿时发生效力；机动车物权未经登记不得对抗善意第三人。任何一方不得以本协议已经签字为由，对外宣称已取得可对抗债权人或善意第三人的物权。各方应于签字后【待填】日内共同向不动产登记机构申请转移登记，登记税费由【待填】负担；逾期未申请的，守约方可书面催告，催告期满【待填】日仍不配合的，按每日人民币【待填】元支付违约金，并有权中止支付尚未到期的折价补偿。」

居住权配套句：

「【待填】对【地址】房屋享有终身居住权，各方应于转移登记同时申请居住权登记。居住权自登记时设立。未完成居住权登记前，取得所有权登记的一方不得请求居住权人迁出，也不得将该住宅出租，但居住权人书面同意的除外。」

不得把“双方同意视为已登记”写成可放行结构。用户要求倒签或补假批准：整体停止。

## 节点 5　债权人与共同债务（硬闸）

支持依据：第 307、538、539、541、542 条；查封扣押冻结规定第 12 条；婚姻家庭编解释（一）第 35 条（共同债务不因内部协议对债权人消灭）。

| 文本写法 | 动作 |
| --- | --- |
| 无债务条款，或只写“各方再无债务” | 必须改：列分家前家庭共同债务，或书面确认经查询无已知债务 |
| “某笔经营贷今后只由长子偿还，债权人不得再向其他人主张” | 红线删除对债权人发生效力的部分。内部分担可留，对外连带须保留 |
| 将唯一住房过户到无债务子女名下，用户承认是为了躲执行 | 停笔。不写出可履行过户时间表 |
| 财产已被查封，文本写“分割后查封自动解除” | 现有依据不支持。须经债权人认可或通过析产/执行程序 |

修改句：

「附件四为分家前家庭共同债务清单，列明债权人、余额量级和担保情况。因共有财产或家庭共同生活、共同经营产生的债务，在对外关系上由相关共有人承担连带责任；本协议的内部分担仅在签字方之间有效，不构成对债权人的债务转移，也不消灭债权人依法主张的权利。任何一方得知有未列入附件四的到期或未到期债权可能受到本协议影响的，应在签署前书面告知其他各方。各方不得利用本协议将责任财产转移至非债务人名下以影响债权实现。」

逃债识别句（告知，不改成履行结构）：

「现有材料显示【待填】名下存在【未结诉讼/执行/大额负债】，而本协议将其责任财产转至【待填】名下且无对价或对价明显不足。债权人可依法请求撤销无偿处分（第 538 条）。本任务不提供可履行的规避执行安排。删除该转移或恢复足额对价前，不给出“可以签署”建议。」

最强反方：分得财产方主张“这是分割自己的份额，不是无偿转让”。现有依据是否支持无偿，取决于形成过程是否真是家庭共有；依据不足时不得帮其写成“债权人必败”。

## 节点 6　赡养挂钩、格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 分家不消灭法定赡养

支持依据：老年人权益保障法第 16、19 条；继承编解释（一）第 32 条。

| 文本写法 | 动作 |
| --- | --- |
| “分得房屋的一方负责养老，其他子女不再承担赡养” | 必须改。内部分担可以，对外不得免除法定义务 |
| 以放弃继承或不分财产为由拒绝赡养 | 红线删除 |
| 分产给子女后父母无处住 | 必须改：保留住房、设立居住权或给付住房保障费用 |
| 不履行赡养则“赠与人撤销析产” | 必须改：改成约定解除或返还，删除赠与术语 |

修改句：

「取得主要财产的【待填】应负担父母的日常生活费、医疗费和居住保障，具体标准为每月人民币【待填】元，于每月【待填】日前支付。本条约定不免除其他子女的法定赡养义务。任何一方不得以未分得财产、放弃继承或其他理由拒绝履行赡养。严重不履行前款，经书面催告后【待填】日仍不改正的，父母或其他履行了赡养义务的子女可依据本条请求解除对应财产归属安排并返还已交付但尚未完成登记的财产，或就已登记财产请求折价补偿；本条不是赠与撤销。」

### 6.2 歧视性条件与监护

“只有生男丁才能分房”、剥夺缺乏劳动能力成员基本生活保障：不得改成可履行条件。触及第 153 条或公序良俗：删除该条件，保留其余可分部分或字段停止。

监护人把被监护人财产划到自己名下：红线。修改句要求另选代理人或将该项移出。

### 6.3 格式与强制规范

村委或律所重复使用的模板，对免责、放弃权利、管辖等异常条款仍审查提示说明。小字、夹在附件、仅有口头宣读：不得写成已尽提示。强制规范按第 153 条和解释第 16 条区分，不用失效口诀。部门规章或地方宅基地窗口要求不当然导致民事协议无效。

## 节点 7　违约、协助过户与争议

1. 不配合登记、不腾交、不支付折价、侵占老人住房：须分别有违约金、中止对待给付或解除+返还。只有“依法承担违约责任”视为必须改。
2. 构成违约不等于当然解除。法定解除只点名催告或目的不能实现，不在本任务作出已解除结论。
3. 违约金不是必得金额。修改句避免“不得调整”或“按房屋总价 30% 必得”。
4. 争议解决：出现仲裁条款，不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核，改成单一仲裁机构或单一法院连结点。涉及不动产的专属管辖可能：只标红旗，不选定唯一法院充作法律意见。
5. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。
6. 建议公证或基层组织见证：可写进签署提醒，不得写成“公证后物权已经变动”。
