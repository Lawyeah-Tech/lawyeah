# 边界与路由

本技能只审查 **婚姻家庭 / 分家析产协议** 的待签文本。中文展示名是「审查分家析产协议（婚姻家庭）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 解除婚姻，并处理夫妻共同财产、子女抚养或夫妻债务 | `离婚协议·审查`。不得删掉离婚意思后继续当析产审 |
| 仅夫妻二人约定婚内所得或婚前财产归属，无其他家庭成员共有分割 | `夫妻财产约定·审查` |
| 分居期间居住、开支，婚姻未解除，无家庭共有分割主轴 | `分居协议·审查` |
| 登记在个人名下、无家庭共有形成过程的财产无偿给晚辈 | `亲属间房屋赠与合同·审查`（亲属间房屋）、`房产赠与合同·审查`（房产赠与）、`一般赠与合同·审查`（一般赠与）或 `附义务的赠与合同·审查`（附义务赠与） |
| 被继承人已死亡后的遗产分割，或单方死后处分个人财产 | `遗嘱·审查`。P1：专业版未装则 `unavailable`，提示，不得用本技能硬套 |
| 继承人以外的人承担生养死葬、死后取得财产 | `遗赠扶养协议·审查`。P1；未装则 `unavailable` |
| 主给付是赡养费、照料、医疗分担，无析产清单 | `赡养协议·审查` |
| 主给付是扶养或未成年子女抚养费 | `扶养抚养协议·审查` |
| 主文件只设立居住权 | `居住权设立合同·审查`。P1；未装则 `unavailable` |
| 无配偶同居期间财产分割 | `同居财产约定·审查`。P1；未装则 `unavailable` |
| 无可读正文，本类型条件已谈妥，要出己方稿 | `分家析产协议·起草` |
| 已签未争、只问过户日或补偿款支付 | 本套导航的履约步骤 |
| 已成争，或用户要撤销权/执行异议诉讼策略 | `已催告解除索赔诉讼或仲裁→` 或对应家事、执行专项 |
| C 端大众快检 | 只分流，不回改 |

分家正文里夹带一小段赡养标准或为父母保留居住：赡养费精算可交接 `赡养协议·审查`，居住权登记专条可点名 `居住权设立合同·审查`；家庭共有清单、登记对抗、债务和债权人条款继续审。用户坚持本技能把离婚协议、赠与或遗嘱整案改完：`目标停止`。
