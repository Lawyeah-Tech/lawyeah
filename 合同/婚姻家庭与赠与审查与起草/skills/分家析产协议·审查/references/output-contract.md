# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的份额、补偿额、期限；把已失效《物权法》《婚姻法》《合同法》撤销权规定写入结论；把签字日写成已经取得物权；把未登记写成可对抗查封或善意第三人；把真析产改成赠与任意撤销；把内部分担写成对外债务消灭；把离婚协议或赠与当成已完成的本类型审查。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查分家析产协议（婚姻家庭）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《物权法》《婚姻法》《合同法》撤销权规定或其解释、《继承法》意见时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `婚姻家庭`，子级 `分家析产协议`。定性理由、易混切开结果（离婚协议、夫妻财产约定、赠与、遗嘱、遗赠扶养、赡养、分居）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、共有人与文本版本

主体表：签字人、身份关系、是否共同共有人、监护代理、需一并签字的配偶。资格表：行为能力痕迹、未成年人利益说明。版本表：正文、财产清单、示意图、户口或亲属关系材料、聊天确认；冲突并列。漏列共有人或未核成员身份：该处分或过户字段停止。

## 5. 家庭共有清单、登记对抗与债务

核心给付是否仅为分割家庭共有；是否夹带离婚财产或个人财产赠与；每项财产的形成过程；登记现状与抵押查封；合同生效与物权变动是否拆开；折价补偿节点；家庭共同债务清单及对外连带。缺口标 `G#`。不输出离婚冷静期、赠与任意撤销或遗嘱形式主路径。

## 6. 债权人、强制规范与赡养

是否存在逃债或查封；第 538–542 条只作告知与停笔，不认定撤销之诉必然成立。是否构成格式条款。强制规范只按第 153 条和解释第 16 条区分。赡养法定义务是否被文本免除。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的数字用 `【待填】`。不得把框架里的“签字日即所有权转移”或“受赠人撤销”写成建议句。

## 9. 谈判与签署提醒

谈判顺序：先红线（离婚/赠与错位、逃债、签字即对抗第三人、对外流转宅基地），再必须改（共有人补列、登记期限、债务对外连带、居住权登记、赡养不免除），最后可优化。签署提醒：全体共同共有人亲笔签名按指印；财产清单、权利人名单、示意图、债务清单入附件；建议公证或基层见证但不写成物权已变动。不指导倒签或补假放弃声明。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书、撤销权诉讼策略或效力保证，也不是离婚协议、夫妻财产约定或赠与审查。
