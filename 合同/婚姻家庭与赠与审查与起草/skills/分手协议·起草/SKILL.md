# 分手协议·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **婚姻家庭 / 分手协议**，输出可编辑草稿、未决项，并在出稿后用本类型硬闸自审。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「审查分手协议（婚姻家庭）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查、从零起草、履约交底、争议文书、效力或必然可执行保证、把人身限制改成可履行、把子女抚养费改成可放弃、离婚协议／忠诚协议／分居协议本约整案、存续期同居财产约定整案、不正当关系赠与或包养结构整案。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿；尚未签署，尚未成争；核心给付是终止共同生活之后的清算——财产分割、债务承担、非婚生子女抚养，以及可改写成折价款或贡献补偿的给付。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 双方仍共同生活，文本安排存续期财产归属、共同账户、加名或终止标准，尚未结算退出 → `同居财产约定·审查`；专业版未收录该原子时输出 `unavailable`，不得用本技能改成存续期财产制；
- 核心给付是维持或巩固不正当关系的赠与、包养费、以性或持续同居为对价，或把大额财产无偿给第三者且目的不是清算已形成共有 → `涉及不正当男女关系的赠与合同·审查`；不得设计可履行包养时间表；
- 双方已办理结婚登记，核心是解除婚姻、离婚冷静期或离婚登记后生效 → `离婚协议·审查`；
- 已登记夫妻约定忠诚义务、出轨净身出户或惩罚性违约 → `夫妻忠诚协议·审查`；
- 婚姻仍存续，核心是分居居住、分居期间开支 → `分居协议·审查`；
- 1994 年 2 月 1 日前双方已符合结婚实质要件，当事人要按事实婚姻离婚 → 转引擎或离婚路径，不按本技能解除身份；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问付款日、搬离日、过户进度 → 本套导航的履约步骤；
- 已成争（催告、撤销、析产诉讼、抚养诉讼、立案仲裁）→ 合同争议或家事专项领域。

规避限购、借名过户、伪造同意、以协议逃债、把限制报警或限制结婚改成可履行：只出告知，不改写成可履行结构。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成。每一闸必须给出修改句或明确转出口径，禁止只打红黄绿。

1. **人身限制无效**。原文“不得再婚／不得恋爱／不得生育／必须终止妊娠／不得报警／不得起诉／限制人身自由／支付青春损失费、名誉损失费、精神损失费且无独立侵权事实”：红线。修改句删除人身约束和对价，保留可分离的搬离、保密、禁止跟踪骚扰、财产与子女条款。人身条款无效，**不因此**否定财产清算和法定抚养安排。不得把人身限制改成可强制履行，也不得把整份协议写成必然全部无效。
2. **财产分割可分**。必须列清：同居起止；个人财产（同居前取得、各自工资奖金劳务报酬、知识产权收益、各自继承或受赠、单独经营投资）；共同出资购置或共同生产经营投资及其他无法区分的财产。有约定从约定。无约定按婚姻家庭编解释（二）第四条，以出资比例为基础并综合考虑共同生活、有无共同子女、贡献大小。禁止写成“没结婚所以不能分”。禁止套用民法典第一千零六十二条的夫妻共同财产推定。缺清单、出资或证号用 `【待填】`，不补数字。
3. **与 `同居财产约定·审查`／`涉及不正当男女关系的赠与合同·审查` 切开**。存续期安排 → 负触发前者。维持不正当关系的赠与或包养 → 负触发后者。本任务禁止输出“共同生活基金／每月定额存入”的存续期主路径，禁止输出可履行包养时间表。禁止打开其 method。禁止抄 `离婚协议·审查` 的离婚登记生效、冷静期、离婚损害赔偿主路径。禁止抄 `夫妻忠诚协议·审查` 的忠诚义务惩罚主路径。

附加必落句（有事实则单列，无事实在缺口节说明）：

- **补偿措辞**：把“分手费／青春损失费／精神损失费”改成“共有财产折价款”“同居期间贡献补偿”或“生活帮助款”，并写给付节点。一方有配偶且款项可能来自夫妻共同财产：红旗，提示婚姻家庭编解释（二）第七条，不改成可履行买断。
- **子女不得减损**：非婚生子女与婚生子女权利同等。抚养费写金额、周期、方式、生活费教育费医疗费；探望写时间、频率、地点和配合义务。禁止“子女归一方所有”“放弃抚养费不得再主张”。
- **债务内外分层**：内部分担对双方有约束；不得写成对抗外部债权人。被追偿一方有向内部责任人求偿的条款。
- **生效与受案**：协议通常自双方签字之日起对财产和子女安排发生约束力，**不以离婚登记为前提**。修改句不得写“法院判决解除同居”。仅请求解除同居，法院不予受理；财产分割和子女抚养纠纷应当受理。
- **部分无效可分离**：人身限制或青春损失费删除后，财产清单、过户期限、抚养探望继续有效，适用部分无效规则。

必须有修改句。每个风险回链文本位置。禁止套用买卖验收、定金百分之二十或挂靠改写节点。禁止复制离婚协议或忠诚协议 method。

## 建立审查坐标

确认：使用者与授权；单方立场（拟付款方、拟收款方、直接抚养一方、不直接抚养一方）；相对方；全文及财产清单／出生证明／婚姻状况附件版本；双方是否均无配偶；同居起止；拟分割财产；是否有非婚生子女；补偿表述；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的金额、证号、日期、比例用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law`（法律结论 required）：核验公序良俗与部分无效、人身自由与婚姻自由、同居析产分层、仅请求解除同居不予受理、非婚生子女同等权利与抚养费、配偶共同财产因重婚或与他人同居而赠与他人无效、胁迫与显失公平撤销。
- `search_practiced`（optional）：补青春损失费不被支持、析产看出资、解除同居协议在真实意思下可约束等争点。返回“没结婚一律不能分”“青春损失费可执行”“法院会判决解除同居”时记噪声。
- `search_template`（optional）：只借栏目结构。范本写“子女归一方所有”“不得再婚”“青春赔偿”不得当规则。

不虚构案件系统。`search_law` 返回已失效《合同法》《婚姻法》及其解释、1989 年未办结婚登记同居意见、民法通则时记为噪声，不得写入 `L#`。


## 起草模式

本原子只承担本类型起草。待签评改转 `分手协议·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。缺数字用 `【待填】`，不编造。出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 列清同居起止；个人财产与共同出资购置或共同生产经营投资分层。有约定从约定；无约定按解释（二）第四条，以出资比例为基础并综合考虑共同生活、有无共同子女、贡献大小。
- “分手费／青春损失费／精神损失费”改成“共有财产折价款”“同居期间贡献补偿”或“生活帮助款”，并写给付节点。
- 非婚生子女与婚生子女权利同等。抚养费写金额、周期、方式；探望写时间、频率、地点和配合义务。
- 债务内部分担对双方有约束；不得写成对抗外部债权人；被追偿一方有向内部责任人求偿的条款。
- 协议通常自双方签字之日起对财产和子女安排发生约束力，不以离婚登记为前提。人身限制删除后，财产清单、过户期限、抚养探望继续有效。

### 附件必附

- 财产清单。
- 出生证明（有子女时）。
- 婚姻状况附件。

### 禁止出现

- 不得再婚／不得恋爱／不得生育／必须终止妊娠／不得报警／不得起诉／限制人身自由。
- 青春损失费、名誉损失费、精神损失费且无独立侵权事实。
- “没结婚所以不能分”；套用第 1062 条夫妻共同财产推定。
- “子女归一方所有”“放弃抚养费不得再主张”。
- “法院判决解除同居”。
- 可履行包养时间表；一方有配偶且款项可能来自夫妻共同财产时改成可履行买断。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口，不代替节点。

0. 签署状态与成果分流
1. 类型识别与单目录加载（终止共同生活后的清算；切开 `同居财产约定·审查`／`涉及不正当男女关系的赠与合同·审查`／离婚／忠诚／分居）
2. 主体、婚姻状况、子女、债权人
3. 人身限制无效
4. 财产分割可分（解释（二）第四条）
5. 补偿措辞、一方有配偶、公序良俗
6. 非婚生子女抚养与探望
7. 债务内外分层、互不干扰、生效与过户
8. 按框架六步出修改句

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签或假同意、把人身限制改成可履行、把子女写成可买卖或放弃法定抚养、把夫妻共同财产包装成可履行买断第三者、保证必然有效或必然可强制执行。
- `字段停止`：法域、双方婚姻状况、财产权属或出资、子女身份未核验；补偿是否过公序良俗关无法识别。
- `目标停止`：主目标已变为从零起草、履约交底、析产或抚养诉讼文书，或用户要把本约改成离婚协议、忠诚协议、存续同居约定或包养合同。

生存级住房被低价处分或存在家暴、限制人身自由，且用户拒绝升级：停止“可以签署”建议。
