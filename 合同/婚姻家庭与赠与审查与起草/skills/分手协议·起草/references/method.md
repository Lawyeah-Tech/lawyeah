用核心给付定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须同时满足才正触发：

1. 双方将终止或已经决定终止共同生活，文本是退出结算，不是安排继续同居。
2. 结算对象是已形成的财产、债务、非婚生子女抚养，以及可改写成折价款或贡献补偿的给付。
3. 双方之间不存在“办理离婚登记后本协议生效”的婚姻解除结构。

## 节点 2　主体、婚姻状况、子女与债权人

1. 建主体表：甲方、乙方、非婚生子女（如有）、一方的配偶（如有）、共同债权人、共同出资的父母。名称不一致不自动合并。
2. 民事行为能力：双方须完全民事行为能力。限制民事行为能力人处分重大财产：该签署能力字段停止。
3. **婚姻状况（必问）**：双方是否均无配偶。材料未闭合：字段停止，不得写成“可以放心签”。一方有配偶：进入节点 5，不当然负触发；但补偿或过户可能落入解释（二）第七条。
4. 同居起止时间必须写进首部，用于划定清算范围。只有“谈过恋爱”没有共同生活事实：追问是否属于本类型；若只是恋爱赠与或青春损失费，财产清算节点停止或转出。
5. 非婚生子女：姓名、出生日期、随何方生活、户口与出生证明是否可见。身份未闭合：子女条款字段停止，不补“孩子已确认亲子”。
6. 债权人：内部债务分担不得写成对抗外部债权人。出现“净身出户以逃避债务”：红旗，提示债权人可主张撤销或确认相对无效。
7. 口头“配偶同意了”“孩子不是我的”不得写成已同意或已否认亲子。

不足：字段停止，列出待补材料，不补主体、不补已离婚、不补已同意。

## 节点 3　人身限制无效（硬闸）

婚姻自由、人身自由和人格尊严不得用协议买断。无独立侵权事实的青春损失费、名誉损失费，实务上通常不被支持，审查端按违背公序良俗或欠缺法律基础处理，不改成可执行金钱债。

| 文本写法 | 本任务动作 |
| --- | --- |
| “乙方不得再婚／不得恋爱／三年内不得结婚，否则退还全部补偿” | 红线。删除限制及与之挂钩的返还；补偿改写为已形成财产的折价或贡献补偿 |
| “乙方不得生育／必须终止妊娠／不得把孩子户口迁出” | 红线。生育和人身不得作为对价 |
| “乙方不得报警、不得起诉、不得向配偶或单位披露，否则支付【待填】” | 红线删除放弃公力救济。保密可保留为不散布隐私、不诽谤，但不得封死报案和起诉 |
| “跟踪、住在对方门口、到单位闹事视为违约，但不得报警” | 禁止跟踪骚扰可留；“不得报警”必须删 |
| “青春损失费／青春补偿／精神损失费／名誉损失费【待填】元” | 红线改写。无独立侵权事实不得保留该名目。改为折价款、贡献补偿或生活帮助，并写计算基础 |
| “给付的前提是乙方不得再婚／不得恋爱” | 红线。附人身限制的赠与条件无效，不把整份财产清算一并打掉 |
| 用户要求保留人身限制以便“管住对方” | 整体停止 |

可保留的清净条款：搬离期限；不得跟踪、骚扰、侮辱；不得在社交媒体散布对方隐私或虚假事实；互不泄露同居期间获知的隐私。此类条款必须有可执行的行为描述，违约金不得写成天文数字且“不得调整”。

部分无效：人身限制或青春损失费删除后，财产清单、过户、抚养探望继续审，适用第 156 条。不得输出“整份协议因有分手二字当然无效”。

## 节点 4　财产分割可分（硬闸）

双方均无配偶的同居析产**可以分割**。有约定从约定；没有约定且协商不成的，按解释（二）第四条分层。禁止“没结婚所以不能分”，禁止直接套用第一千零六十二条。

核验后可引用的判断点（须 `search_law` 写入 `L#` 再落法律结论）：

- 解释（二）第四条分层规则。
- 解释（一）第三条：财产分割和子女抚养纠纷应当受理。
- 合同效力与物权变动分离：协议约束双方，不动产权利变动仍取决于登记。

| 文本写法 | 本任务动作 |
| --- | --- |
| 无财产清单，只写“各自名下归各自，互不追究” | 必须改。列不动产、车辆、存款、共同经营、贵重动产；标出资和登记名义 |
| “双方同居财产按夫妻共同财产平均分割” | 必须改。删除夫妻共同财产推定；改为约定或按第四条分层 |
| “没结婚，乙方对登记在甲方名下的房屋无权主张” | 不得放行该结论。若有共同出资或无法区分，修改句保留按出资比例和贡献分割或折价的请求基础 |
| 房产登记一人、另一方有出资流水 | 必须改：写折价款、过户或更名期限、逾期违约金；未过户不得写成已经取得物权 |
| “自愿净身出户，放弃一切财产” | 红旗。审查是否显失公平、是否逃债、是否以人身限制为对价。生存级住房被掏空且用户拒绝升级：停止“可以签署” |
| 共同财产与个人工资、继承、单独经营混写 | 必须拆分。各自所得归各自；共同出资和无法区分的按出资比例并综合贡献 |

清算句最低要素：财产特定化（证号或识别信息用 `【待填】`）；归属方；折价补偿金额与支付日；谁在几日内配合过户；未完成的后果。缺一项补一项。

一方有配偶：本节点仍摘录共同生活期间双方之间的出资，但处分可能落入节点 5，不得写成配偶无权过问。

## 节点 5　补偿措辞、一方有配偶与公序良俗

补偿必须能回链到已形成财产的折价、同居期间贡献或生活帮助，而不能回链到性关系、保密婚外情或限制再婚。

| 文本写法 | 本任务动作 |
| --- | --- |
| “因同居／感情付出支付分手费”且无财产或贡献基础 | 必须改成折价款或贡献补偿，并补计算基础；不能补基础则标依据不足，不保证可执行 |
| 一方现有配偶，补偿或过户来自工资、共同存款、变卖夫妻房屋 | 红旗。提示解释（二）第七条：为与他人同居等目的处分夫妻共同财产，配偶主张违背公序良俗无效的，应予支持。修改句要求披露财产性质；不写成“配偶无权主张” |

反方常见抗辩：双方自愿签署，分手费就应全额支持。本任务不得把该抗辩写成可放行的青春损失费结构。

## 节点 6　非婚生子女抚养与探望

非婚生子女享有与婚生子女同等的权利。抚养费是法定义务，不是可买卖的合同标的。

| 文本写法 | 本任务动作 |
| --- | --- |
| “子女归男方所有，女方不得探望” | 红线。子女不是财产。改为直接抚养方、探望时间和协助义务 |
| “一次性买断抚养费，以后不得再主张” | 红线或必须改。可约定一段时期的数额，但不得封死子女依法请求增加或支付的权利 |
| 抚养费只写“适当支付” | 必须改：金额、支付日、支付方式；范围含生活费、教育费、医疗费 |
| 探望无时间、地点、交接人 | 必须改。补频率、时长、地点、对方配合义务 |
| 亲子关系有争议 | 字段停止。不在本任务确认或否认亲子；提示第 1073 条路径，不写成已确认 |
| 把抚养条款写成“离婚后由母亲抚养” | 必须改。本约不是离婚；用“不直接抚养的生父／生母应当负担抚养费” |

八周岁以上子女的意愿：材料未提及不得编造。修改句可写“双方确认已听取【待填】的真实意愿”，不把未核实的意愿写成事实。

禁止把第 1084 条“离婚后不满两周岁原则上由母亲直接抚养”原句搬进本约充当离婚规则。需要参照最有利于未成年子女原则时，只作为修改理由，并运行时重核条号。

## 节点 7　债务、互不干扰、生效、过户与违约

1. **债务**：列明已知个人债务与共同生活所负债务。内部分担比例对双方有约束，对债权人不当然有效。必须有被追偿后的内部求偿。不得写成“债权人只能向对方主张”。
2. **互不干扰**：只保留行为标准（搬离日、禁止跟踪骚扰、禁止散布隐私）。不得回写人身限制。
3. **生效**：通常自双方签字之日起对已约定的财产和子女安排发生约束力。不得写成须经离婚登记或法院判决解除同居后生效。不得写成法院将判决解除同居关系。
4. **过户与交付**：动产尽量即时清结并出具收据。不动产、车辆写谁在几日内申请登记、费用承担、未完成的解除或违约金。批准、登记写成义务期限，不写成已经完成。
5. **公证或见证**：可作为降低胁迫抗辩的增信，不写成必然不可撤销，不能救人身限制条款。
6. **违约金**：逾期支付折价款或抚养费可设逾期利息或比例违约金；行为违约可约定差旅费、合理维权费用。禁止“不得调整”或按总财产 30% 必得。
7. **管辖**：可约定一方现居住地法院。或裁或诉、机构不明：标待核。不动产权利争议可能触发专属管辖，条号运行时核验，不选定唯一法院充作法律意见。
8. **倒签**：用户要求把签署日改成已搬离或已过户之日：整体停止。
