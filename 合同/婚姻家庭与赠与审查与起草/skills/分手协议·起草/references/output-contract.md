# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证协议有效、法院将判决解除同居、子女已卖断或对方接受；编造未给出的金额、证号、日期、出资比例；把已失效《合同法》《婚姻法》及其解释写入结论；把青春损失费写成可强制执行；把没结婚写成财产不能分；把人身限制改成可履行；把离婚协议、忠诚协议、存续同居约定或不正当关系赠与留在本技能改完。

## 1. 触发、单方立场与成果状态

立场（拟付款方、拟收款方、直接抚养一方、不直接抚养一方）、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明是否终止共同生活，以及双方是否均无配偶、有无非婚生子女。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》《婚姻法》及其解释、1989 年同居意见时记噪声，不得写入 `L#`。人身限制与公序良俗、解释（二）第四条、解释（一）第三条、解释（二）第七条、第 1071 条无 `verified-result` 时，对应法律结论字段停止。

## 3. 类型与加载路径

父级 `婚姻家庭`，子级 `分手协议`。定性理由必须同时满足：终止共同生活；结算已形成的财产、债务或非婚生子女安排。易混切开：存续期同居财产约定、不正当关系赠与、离婚协议、忠诚协议、分居协议、事实婚姻离婚。

加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读其他类型、未打开 `离婚协议·审查`、`夫妻忠诚协议·审查`、`同居财产约定·审查` 或 `涉及不正当男女关系的赠与合同·审查` method。人身买断、子女买卖、逃债过户或包养结构写停笔告知，不填可履行结构。

## 4. 主体、授权、资质与文本版本

主体表：双方姓名与证件号、同居起止、一方配偶（如有）、非婚生子女、共同债权人、共同出资父母。自然人写姓名与证件号是否与文本一致。

版本表：正文、财产清单、出生证明或户籍材料、婚姻状况材料、已付款凭证草稿、聊天确认。冲突并列，不选对用户有利的一版。口头“已经离婚了”“配偶同意了”不得写成已离婚或已同意。

## 5. 清算给付闭环

分列并回链文本位置：

- 关系终结：是否写明自愿终止共同生活、搬离期限。
- 人身限制：是否存在不得结婚、不得恋爱、不得报警、青春损失费。
- 财产：个人财产与共同出资／无法区分财产是否分层；清单、证号、出资。
- 补偿：名目是折价款／贡献补偿／生活帮助，还是分手费／青春损失费；给付节点。
- 一方有配偶：补偿或过户是否可能来自夫妻共同财产。
- 子女：直接抚养、抚养费构成与周期、探望时间和协助义务；是否出现放弃或“归一方所有”。
- 债务：内部分担与对债权人不对抗、内部求偿。
- 过户与交付：谁在几日内办理；未完成的后果。
- 生效：是否误写成离婚登记后生效或法院判决解除同居后生效。

缺口标 `G#`，不补商业数字、证号或已过户事实。批准、登记写成条件或双方义务期限，不写成已经完成。

## 6. 格式条款、强制规范与本类型效力红旗

自然人偶发分手协议通常不是格式条款。一方事先打印、对方只能签字的，按格式条款审查提示说明。

强制规范与效力红旗只在核验后落法律结论：人身限制与公序良俗；青春损失费；解释（二）第四条分层；解释（二）第七条配偶共同财产；放弃法定抚养；恶意串通逃债。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

不得把“整份协议因有分手二字当然无效”或“没结婚所以财产不能分”写成已核验结论。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔／转出口径。禁止输出无修改句的色块表。

本类型至少检查：人身限制或青春损失费；财产未分层或写成不能分；补偿名目违法或一方有配偶；子女归一方所有或放弃抚养；债务写成对抗债权人；无搬离或过户期限；误套离婚登记生效；与 `同居财产约定·审查`／`涉及不正当男女关系的赠与合同·审查` 边界不清。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字、证号用 `【待填】`，不编造。禁止只给原则、不给句子。框架与硬闸冲突时按硬闸出句。

建议句必须覆盖本类型硬闸：删除人身限制并保留可分离清算；财产按可分规则列清；补偿离开青春损失费；与存续约定或不正当关系赠与切开后的转出口径（若已切开则本节不填实体句）。

## 9. 谈判与签署提醒

谈判顺序：先红线（人身限制、青春损失费、子女买卖或放弃抚养、夫妻共同财产买断第三者、伪造同意），再必须改（财产清单分层、折价款、抚养探望闭环、债务内外分层、过户期限），最后可优化。

签署提醒：双方本人签并按指印；注明签署地点；财产清单、出生证明、已付款凭证作附件；日期真实。建议公证或律师见证以降低胁迫抗辩，不保证不可撤销。不指导倒签或补假同意。

拟付款方立场必须提示：人身限制救不了协议，天文数字补偿可能被调减，一方有配偶时存在被追索风险。拟收款方立场必须提示：青春损失费名目可能不受保护，未过户不等于已经取得物权，内部债务约定挡不住债权人。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、解除同居诉讼文书、抚养费精算终局或效力保证。
