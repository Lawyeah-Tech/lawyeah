# 遗嘱·审查

## 任务目标

在单一立场下，只审查 **婚姻家庭 / 遗嘱** 的待签文本，输出风险表、可回给起草人、公证员或家属的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查遗嘱（婚姻家庭）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、把遗赠扶养协议或生前赠与改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **形式要件**：先锁拟采用的法定形式，再按该形式逐项核验。自书须遗嘱人亲笔书写、签名并注明年月日；代书须两名以上见证人在场，其中一人代书，遗嘱人、代书人和其他见证人签名并注明年月日；打印须两名以上见证人在场，遗嘱人和见证人在**每一页**签名并注明年月日；录音录像须两名以上见证人在场，并记录姓名或肖像及年月日；口头仅危急情况可用，危急消除且能改用书面或录音录像的，口头遗嘱无效；公证由公证机构办理。代书、打印、录音录像、口头的见证人不得是无/限制民事行为能力人、继承人、受遗赠人及其利害关系人。形式缺口未补：不得写“可以签署”或“法院一般会认”。
2. **必留份**：遗嘱应当为缺乏劳动能力又没有生活来源的继承人保留必要的遗产份额。是否双缺，按**遗嘱生效时**（继承开始时）该继承人的情况确定，不得按立遗嘱当日一锤定音。未保留：修改句先留出必要份额，剩余部分才按遗嘱分配；不得写成整份必然无效，也不得编造“不超过应继份二分之一”的法定上限。用户坚持零保留且现有材料已能支持双缺：整体停止“可以签署”。
3. **与遗赠 / 生前赠与切开**：继承人以外的人承担生养死葬、死后取得财产 → `遗赠扶养协议·审查`。权利拟在生前转移的无偿给予 → `一般赠与合同·审查`、`附义务的赠与合同·审查`、`亲属间房屋赠与合同·审查` 或 `房产赠与合同·审查`。双方在生前约定死后过户、互有承诺、但不是单方死后处分 → `生前类赠与协议·审查`。遗嘱内把财产给法定继承人以外的人：留在本类型，按**遗赠**审，写清六十日明示接受，不得改称“继承”，也不得整案转出。不得打开或抄写 `遗赠扶养协议·审查` 或任何赠与原子的 method。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签遗嘱、遗嘱暨遗嘱信托设立书或拟公证遗嘱草稿，遗嘱人仍在世，尚未按该稿完成有效设立，尚未成争，核心给付是单方死后处分个人财产，用户问能否按此稿设立、哪里必须改、怎么改句。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 继承人以外的人承担生养死葬、死后取得财产 → `遗赠扶养协议·审查`（P1；专业版未装则 `unavailable`）；
- 权利拟在生前转移的无偿给予 → `一般赠与合同·审查`、`附义务的赠与合同·审查`、`亲属间房屋赠与合同·审查` 或 `房产赠与合同·审查`；
- 双方约定死后过户的类赠与，主轴不是单方遗嘱 → `生前类赠与协议·审查`（P1；未装则 `unavailable`）；
- 父母健在、分割家庭共有财产 → `分家析产协议·审查`；
- 解除婚姻并处理夫妻共同财产、子女抚养 → `离婚协议·审查`；
- 仅夫妻二人约定婚内或婚前财产归属 → `夫妻财产约定·审查`；
- 主文件只设立居住权、无死后处分主轴 → `居住权设立合同·审查`（P1；未装则 `unavailable`）；
- 主给付是赡养费、照料 → `赡养协议·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `遗嘱·起草`；
- 已按该稿完成设立，只问保管、变更、执行或过户预约 → 本套导航的履约步骤；
- 已催告、立案、开庭、仲裁，或用户要确认遗嘱无效/有效之诉状 → `已催告解除索赔诉讼或仲裁→` 或对应家事专项。

伪造签名、补假见证人、倒签、用遗嘱规避限购或逃债：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（遗嘱人 / 拟取得主要财产的继承人或受遗赠人 / 可能仅得必留份或被排除的法定继承人 / 配偶共有份额被处分方择一）；全文及附件版本；拟采用的法定形式；遗嘱人立遗嘱时行为能力痕迹；法定继承人名单及是否可能双缺；财产是个人还是夫妻共同或家庭共有；见证人与继承人、受遗赠人的关系；是否已有在先遗嘱、遗赠扶养协议或生前赠与；不可接受事项；法域与拟设立日。缺立场或无可读文本则不启动实体审查。同时掌握互斥多方秘密时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 文本条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的份额、日期、财产识别信息用 `【待填】`，不编造。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《继承法》及其意见、《婚姻法》《物权法》《合同法》当作现行规则。不得把“公证遗嘱效力最高”写成现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验遗嘱形式、见证人、必留份、撤回与最后遗嘱、继承与遗赠切开、夫妻共同财产先分出；`search_practiced` 只补审查反例；`search_template` 只借栏目结构。不虚构案件系统。

`search_law` 对上述法律结论为 required 级：不可用时不拒绝执行，只停止效力字段。返回已失效《继承法》及其意见、《婚姻法》《物权法》《合同法》时记为噪声，不得写入 `L#`。“公证遗嘱效力最高”“必留份法定上限为应继份二分之一”记为噪声。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`框架.md` 把代书与打印一并写成“每一页签名”时，仅打印遗嘱适用逐页签名。`框架.md` 把抵押房产写成处分无效时，不得照抄。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `遗嘱·起草`；已按该稿完成设立且只问保管或执行 → 本套导航履约步骤；已成争 → 合同争议或家事专项。未完成有效设立且目标是评改已有遗嘱文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与单方死后处分一致才继续。遗赠扶养、生前赠与、双边死后过户类赠与、分家析产、离婚财产负触发。

### 2. 形式要件与见证人

锁形式；核签名、日期、见证资格与在场；能力痕迹不足则字段停止。

### 3. 标的范围

只处分死亡时个人合法财产。配偶份额、他人财产该部分停止。材料未提及负担不得写成无负担。

### 4. 必留份

列可能双缺的继承人；按生效时点预留必要份额。

### 5. 撤回、数份与在先安排

废止前嘱；数份冲突以最后为准；与遗赠扶养协议冲突的部分不得写成优先于协议。

### 6. 继承 / 遗赠用语、执行人与信托

给法定继承人用“继承”；给其他人用“受遗赠”并写六十日；指定执行人；遗嘱信托须符合信托书面要件。

### 7. 争议解释与强制规范

执行人解释不得写成可排除法院审查。无核验引文则法律结论字段停止。

### 8. 按框架六步出修改句

必须有可回给起草人、公证员或家属的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、补假见证人、保证有效、不保留已能支持的双缺继承人必要份额、把遗赠扶养或生前赠与主轴留在本技能放行。
- `字段停止`：法域、形式要件未闭合、行为能力未核、财产权属未核、双缺事实不足。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
