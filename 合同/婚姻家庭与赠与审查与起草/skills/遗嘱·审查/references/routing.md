# 边界与路由

本技能只审查 **婚姻家庭 / 遗嘱** 的待签文本。中文展示名是「审查遗嘱（婚姻家庭）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 继承人以外的人承担生养死葬，死后取得财产 | `遗赠扶养协议·审查`。P1：专业版未装则 `unavailable`，提示，不得用本技能硬套 |
| 权利拟在生前转移的无偿给予 | `亲属间房屋赠与合同·审查`（亲属间房屋）、`房产赠与合同·审查`（房产赠与）、`一般赠与合同·审查`（一般赠与）或 `附义务的赠与合同·审查`（附义务赠与） |
| 双方约定死后过户的类赠与，主轴不是单方遗嘱 | `生前类赠与协议·审查`。P1；未装则 `unavailable` |
| 父母健在，分割家庭共有财产 | `分家析产协议·审查` |
| 解除婚姻，并处理夫妻共同财产、子女抚养 | `离婚协议·审查` |
| 仅夫妻二人约定婚内或婚前财产归属 | `夫妻财产约定·审查` |
| 分居期间居住、开支，无死后处分主轴 | `分居协议·审查` |
| 主给付是赡养费、照料 | `赡养协议·审查` |
| 主给付是扶养或未成年子女抚养费 | `扶养抚养协议·审查` |
| 主文件只设立居住权 | `居住权设立合同·审查`。P1；未装则 `unavailable` |
| 无配偶同居期间财产分割 | `同居财产约定·审查`。P1；未装则 `unavailable` |
| 无文本、本类型条件已谈妥、要出己方稿 | `遗嘱·起草` |
| 已按该稿完成设立，只问保管、变更预约或死亡后过户 | 本套导航的履约步骤 |
| 已成争，或用户要确认遗嘱有效/无效诉讼策略 | `已催告解除索赔诉讼或仲裁→` 或对应家事专项 |
| C 端大众快检 | 只分流，不回改 |

遗嘱正文里夹带一小段居住权或信托：居住权登记专条可点名 `居住权设立合同·审查`，信托要件继续在本类型审。遗嘱内对法定继承人以外的人处分，按遗赠留在本类型，不转 `遗赠扶养协议·审查` 或 `生前类赠与协议·审查`。用户坚持本技能把遗赠扶养协议、生前赠与或双边死后过户整案改完：`目标停止`。
