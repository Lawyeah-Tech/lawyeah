# 边界与路由

本技能只起草 **婚姻家庭 / 离婚协议**。中文展示名必须是「审查离婚协议（婚姻家庭）」。禁止在正文写半截场景编号。

## 正触发

已有可读待签书面离婚协议，尚未完成离婚登记，尚未成争，核心给付是双方自愿解除婚姻关系并一次性安排子女抚养、财产和债务。

## 负触发

| 主要目标或文本信号 | 路由 | 不得代做 |
| --- | --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 | 不硬套本类型十节 |
| 婚前/婚内财产制约定，不解除婚姻 | `夫妻财产约定·审查` | 不补自愿离婚句把文本改成离婚协议 |
| 分居、临时照护，不解除婚姻 | `分居协议·审查` | 不把分居写成已离婚 |
| 忠诚惩罚、出轨罚金为主给付，不解除婚姻 | `夫妻忠诚协议·审查` | 不按离婚三块齐审交差 |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 | 已经完成审查；转通用起草引擎出本类型终稿 |
| 已登记，只问过户、给付、探望履行 | 本套导航的履约步骤 | 不回写签前意见充作成交 |
| 已起诉离婚，或只要诉讼请求、举证、开庭策略 | `已起诉离婚，或用户要立案请求举证策略开庭口径→`；`具体评估走`；`立案材料走` | 不写诉讼策略，不把起诉材料改成登记协议交差 |
| 家暴或儿童即时危险 | 先安全处置；必要时 `家暴或儿童即时危险` | 不优化逼签 |
| 私下放弃或转让法定监护为主诉求 | `私下放弃或转让法定监护为主诉求` | 不改写成可履行弃权 |
| C 端大众快检或 C 端离婚协议起草 | 只分流，不回改 | 不复制起草模板 |

## 本类型内转出（仍可先标风险再停）

- 结婚登记不在中国内地、一方无/限制行为能力：协议离婚可能不予受理，转婚家领域评估诉讼路径。
- 财产显著倾斜且存在已知债权人或执行案件：告知撤销与对抗风险，不设计逃债履行结构。
- 用户要保证有效、保证民政局必然受理、保证银行变更借款人：停止保证，只保留事实摘录与修改句草稿。
