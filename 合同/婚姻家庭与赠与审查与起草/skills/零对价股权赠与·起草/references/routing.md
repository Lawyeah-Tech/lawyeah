# 边界与路由

本技能只起草 **赠与合同 / 股权赠与合同（零元转让股权相关）** 的待签、确无财产对价转移有限公司股权文本。中文展示名是「审查股权赠与合同（零元转让股权相关）（赠与合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 真实价款、一块钱、日后视经营补偿、以股抵债 | `或` 或 `或` |
| 注册资本增加、认缴新出资、以财产向公司出资换股 | `或` 或 `或` |
| 含控制权转移的收购对价包 | `含控制权收购对价包→` |
| 零元从名义股东转回实际出资人；正文主写代持还原 | `隐名持股代持分红为主给付→` 或 `或` |
| 服务期、期权、限制性股权、公司回购 | `或转引擎重新定性；`；激励结构不明则转引擎 |
| 国有股权须评估、进场的协议转让 | `国有股权须评估进场的协议转让→` |
| 主给付是现金、动产或权利，不是股权 | `一般赠与合同·审查` |
| 正文主写救灾、扶贫、助残等公益或道德义务以锁死任意撤销 | `公益道德义务性质的赠与合同·审查` |
| 正文主写离婚分割、夫妻财产约定、忠诚赔偿或家庭共同财产安排 | `婚姻家庭中的赠与合同·审查` |
| 房屋物权无偿转移 | `房产赠与合同·审查` 或 `亲属间房屋赠与合同·审查` |
| 死后生效、遗嘱或遗赠 | `生前类赠与协议·审查` |
| 股东协议整案（锁定期、一致行动为主文件） | `股东协议整案（锁定期一致行动为主文件）` |
| 无可读正文，本类型条件已谈妥，要出己方稿 | 本任务起草并自审 |
| 已签未争、只问名册记载日、市监申请日、完税日 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `已催告解除索赔诉讼或仲裁→` 或对应专项领域 |
| 债权人已提起撤销、执行异议或逃债刑事立案 | 争议或执行专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

股权赠与正文里夹带一小段股东协议修订：专章可继续审；股东协议整案交接 `股东协议整案（锁定期一致行动为主文件）`。用户坚持本技能把转股、出资、代持、激励、一般赠与、公益赠与或家事赠与整案改完：`目标停止`。
