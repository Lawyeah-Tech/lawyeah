# 零对价股权赠与·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、已被修改的 1993／2004／2005／2018《公司法》条文当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **赠与合同 / 股权赠与合同（零元转让股权相关）**，输出可编辑草稿、未决项，并在出稿后用本类型硬闸自审。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查股权赠与合同（零元转让股权相关）（赠与合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证必然办成变更登记、保证免税或任意撤销必然消灭。

## 本类型硬闸

1. **零元／赠与外观 ≠ 有偿股权转让**：第 657 条看有无财产对价，不看标题把价款写成“0”。确无财产对价，内部适用赠与规则，外部仍须过公司法转让程序。标题是转让、正文无价款的，定义条款必须写明“转让价款为零，受赠人无需支付财产对价，本次为无偿赠与”。
2. **真赠与 vs 名为赠与实为转让**：出现真实价款、一块钱、日后视经营补偿、以股抵债 → `或` 或 `或`。不得删对价句后硬套本技能。
3. **优先购买**：向股东以外的人赠与有限公司股权，须按现行公司法第八十四条书面通知数量、对价情况、支付方式和期限；其他股东在同等条件下有优先购买权。零元无法提供可操作的“同等价格”时，约定评估机构确定公平合理价格供其行权；行权则本次赠与对相应股权终止履行。禁止无送达证据写“视为其他股东已放弃”。
4. **同意权**：2024-07-01 后对外转让不再以“其他股东过半数同意”为法定强制步骤，除非章程仍保留同意或决议。配偶无偿处分共同财产、质权人、外资／国资批准（如适用）必须单独核验。无送达不得“视为已同意”。
5. **税费**：无偿受赠股权可能产生所得税；印花税、评估费、公证费须列承担方。精确税率字段停止。不得约定“不申报”，不得写“零元即无税”。完税可作成交割先决，不得写成合同成立要件。
6. **与邻类切开**：禁止打开或复制 `或`、`或`、`或`、`一般赠与合同·审查`、`公益道德义务性质的赠与合同·审查`、`婚姻家庭中的赠与合同·审查` 的 method。不要用股权买卖模板只把价款改成零，也不要把普通股权赠与改写成公益赠与来关闭第 658 条。

配套闸：

- **任意撤销**：股东名册记载及依法应办的变更登记完成前，赠与人可依第 658 条撤销；公证或公益、道德义务除外。空写“零元转让不可撤销”通常挡不住第 658 条。
- **出资随股**：零元不等于无出资义务。未届期出资由受赠人缴纳、赠与人补充责任；瑕疵出资范围内可能连带。不得写“零元即无任何义务”。
- **第 538 条**：零元本身不等于当然恶意逃债。出现躲债、规避执行：只告知，不改可履行结构，不写“不属于恶意逃债”。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签股权赠与或零元转让正文，尚未签署，尚未成争，核心给付是确无财产对价地转移特定有限公司股权，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 出现真实价款、一块钱、日后补偿、以股抵债 → `或` 或 `或`；
- 注册资本增加、认缴新出资、以财产向公司出资换股 → `或` 或 `或`；
- 含控制权收购对价包 → `含控制权收购对价包→`；
- 零元从名义股东转回实际出资人，或正文主写代持还原 → `隐名持股代持分红为主给付→` 或 `或`；
- 服务期、期权、限制性股权、公司回购绑定劳动 → `或转引擎重新定性；` 或转引擎重新定性；
- 国有股权须评估进场的协议转让 → `国有股权须评估进场的协议转让→`；
- 主给付是现金、动产，股权只是顺便一提 → `一般赠与合同·审查`；
- 正文主写救灾、扶贫、助残等公益或道德义务以锁死任意撤销 → `公益道德义务性质的赠与合同·审查`；
- 正文主写离婚分割、夫妻财产约定、忠诚赔偿或家庭共同财产安排 → `婚姻家庭中的赠与合同·审查`；
- 房屋物权无偿转移 → `房产赠与合同·审查` 或 `亲属间房屋赠与合同·审查`；
- 死后生效、遗嘱处分 → `生前类赠与协议·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁或债权人已提起撤销 → `已催告解除索赔诉讼或仲裁→` 或对应专项。

挂靠、违法分包、规避限购、逃避债务或执行：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及章程／名册／登记／股东协议／通知送达／配偶同意版本；股权是否特定化；有无任何财产对价；受赠人是否已是股东；是否书面通知其他股东；章程有无同意程序；认缴实缴；质押冻结代持；是否公证；赠与人负债与诉讼；受赠人股东资格；税费安排；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 起草模式

本原子只承担本类型起草。待签评改转 `零对价股权赠与·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`，不编造。出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

出现真实价款、一块钱、日后视经营补偿、以股抵债：负触发有偿股权转让，不得删对价句后硬套本技能。国有股权须评估进场的，不在本任务改成可履行零元稿。

### 起草必写

- 定义条款必须写明“转让价款为零，受赠人无需支付财产对价，本次为无偿赠与”。内部适用赠与规则，外部仍须过公司法转让程序。
- 向股东以外的人赠与有限公司股权，须按现行公司法第八十四条书面通知数量、对价情况、支付方式和期限。零元无法提供可操作的“同等价格”时，约定评估机构确定公平合理价格供其行权；行权则本次赠与对相应股权终止履行。
- 2024-07-01 后对外转让不再以“其他股东过半数同意”为法定强制步骤，除非章程仍保留同意或决议。配偶无偿处分共同财产、质权人、外资／国资批准（如适用）必须单独核验。
- 无偿受赠股权可能产生所得税；印花税、评估费、公证费须列承担方。完税可作成交割先决，不得写成合同成立要件。精确税率字段停止。
- 股东名册记载及依法应办的变更登记完成前，赠与人可依第 658 条撤销；公证或公益、道德义务除外。
- 零元不等于无出资义务。未届期出资由受赠人缴纳、赠与人补充责任；瑕疵出资范围内可能连带。

### 附件必附

- 书面通知其他股东及送达安排；优先购买放弃或公平合理价格行权机制。
- 章程／名册；共同财产须配偶书面同意；质权人、外资／国资批准（如适用）。缺比例、出资额、期限用 `【待填】`。

### 禁止出现

- 无送达证据写“视为其他股东已放弃”或“视为已同意”。
- 约定“不申报”；写“零元即无税”。
- 用股权买卖模板只把价款改成零；把普通股权赠与改写成公益赠与来关闭第 658 条。
- 空写“零元转让不可撤销”。
- “零元即无任何义务”。
- 出现躲债、规避执行时写“不属于恶意逃债”，或改成可履行逃债结构。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 本任务起草模式；已签履约 → 本套导航履约步骤；已成争 → 合同争议或公司／执行专项。未签且目标是评改已有股权赠与／零元转让文本，才进入本任务。

### 1. 真赠与还是名为赠与实为转让

标题、核心给付与对价方式一致才继续。有偿转股、出资、代持还原、激励回购、一般赠与、公益道德赠与、婚姻家庭赠与、房产赠与负触发。

### 2. 主体、处分权与资格

赠与人须是名册或登记股东，或已经确权的实际权利人。隐名股东直接对外赠与：受赠人无法完成登记。公司处分子公司股权另走机关决议。

### 3. 标的特定化与出资负担

公司名称、统一社会信用代码、出资额、实缴、比例。禁止只写“部分股权”。未实缴、质押、冻结必须披露。

### 4. 优先购买

对外赠与：通知 + 放弃优先购买或公平合理价格行权机制。无送达不得“视为放弃”。

### 5. 同意权

章程同意或决议、配偶书面同意、质权人、外资／国资。2024-07-01 后不以过半数同意为法定强制，除非章程保留。

### 6. 名册、登记与任意撤销

记载于股东名册时起可向公司主张股东权利；未经变更登记不得对抗善意相对人。658 窗口按是否公证、是否公益道德义务处理。不要把公司登记写成合同成立要件。

### 7. 税费、538 与出资

税种承担可约定，不得约定不申报。538 只告知。出资承继与追偿不得用零元排除。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把有对价当赠与放行、把逃债改成可履行、无送达却保证其他股东已放弃或已同意、未公证却保证 658 消灭、约定不申报税款。
- `字段停止`：法域、动态规则、评估终值、税负精确额、通知是否收悉、处分权未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
