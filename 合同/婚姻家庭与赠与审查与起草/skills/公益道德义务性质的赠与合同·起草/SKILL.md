# 公益、道德义务性质的赠与合同·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **赠与合同 / 公益、道德义务性质的赠与合同**，输出可编辑草稿、未决项，并在出稿后用本类型硬闸自审。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「审查公益、道德义务性质的赠与合同（赠与合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类合同审查；从零起草；履约交底；争议文书；有效性或税前扣除保证；一般赠与、附义务赠与、商业赞助、房产或亲属房屋赠与、婚内赠与、股权零元转让、遗赠或遗赠扶养本约的实体代审；把虚假公益、个人账户收款或无资格公募改成可履行结构。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成。每一闸必须给出修改句或明确转出口径。禁止只打红黄绿。禁止按普通赠与或遗赠改完。

1. **第 658 / 660 / 663 分轨**。第 658 条第 2 款只关闭第 1 款任意撤销，且**不依赖公证**。同一事实激活第 660 条请求交付。第 663 条法定撤销（一年除斥）和第 666 条穷困抗辩仍在。禁止写成“没公证所以一定还能任意撤销”，禁止写成“写了公益所以任何撤销权都没了”。
2. **第 2 款有事实门槛**。救灾、扶贫、助残等公益用途，或可回链的道德义务（侵权补救、公开认捐、法定扶养之外的补偿），必须能指回正文或附件。空喊“本捐赠具有公益性质、永久不可撤销”而用途写成“由受赠人自行决定”，第 2 款字段停止，不得放行关闭任意撤销。
3. **与一般赠与切开**。未达门槛的人情往来、亲属日常资助 → `一般赠与合同·审查`。亲属身份本身不等于道德义务。禁止打开或抄写该原子 method，禁止把“权利转移前默认仍可任意撤销”写成公益主路径。
4. **与附义务切开**。看护、居住、供养、对赠与人给付劳务，义务使赠与人本人受益 → `附义务的赠与合同·审查`。本技能只审用途限制、专款专用、监督审计。禁止打开或抄写该原子 method，禁止把公益用途改写成对价劳务。
5. **与遗赠切开**。死后才过户、遗嘱处分 → `生前类赠与协议·审查` 或 `类赠与遗赠扶养协议·审查`。本类型走合同编赠与章，不走继承编。禁止用第 658、660、663、666 条去锁定一份死因处分。
6. **穷困加慈善法要件**。第 666 条只及于尚未履行部分。公开承诺或书面慈善捐赠还须向公开承诺地或书面协议签订地**县级以上人民政府**民政部门报告并向社会公开说明后，才可不再履行。不得私下毁诺，也不得删掉穷困路径做成绝对不可解除的单边枷锁。
7. **无偿性与对公交付**。赞助回报、冠名保底、投资收益、采购捆绑 → 负触发广告/服务或拆分。向个人账户支付却称为公益捐赠、无资格自行公开募捐、指定捐赠人利害关系人为受益人：只告知，不改成可履行。不得把“资金到账后生效”写成生效条件。

必须有修改句。每个风险回链文本位置。

## 工作边界

正触发：已有可读待签捐赠协议或公益、道德义务赠与正文，尚未签署，尚未成争，核心给付是无偿给予财产且用途锁定救灾、扶贫、助残等公益或可陈述的道德义务，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 未达公益或道德义务门槛，只是普通无偿给予 → `一般赠与合同·审查`；
- 受赠人向赠与人负担看护、居住、供养等使赠与人本人受益的义务 → `附义务的赠与合同·审查`；
- 标题或正文写“赞助”“合作”，换取冠名、广告档期、采购配额或保底回报 → 转引擎重新定性；
- 房屋过户是主轴且无公益用途 → `房产赠与合同·审查` 或 `亲属间房屋赠与合同·审查`；
- 婚前或婚内把一方财产赠与配偶或约定共有 → `婚姻家庭中的赠与合同·审查`；婚姻家庭编解释（一）第三十二条指向第 658 条的，是家事赠与主线，不是本类型；
- 以维持不正当关系为给付原因 → `涉及不正当男女关系的赠与合同·审查`；只告知违法，不设计可履行结构；
- 股权零元转让、股东名册变更是主轴 → `零对价股权赠与·审查`；
- 死后生效、遗嘱处分 → `生前类赠与协议·审查` 或 `类赠与遗赠扶养协议·审查`；
- 以他人名称购房并支付房款 → `借名购房型赠与·审查`；
- 无对价财产转移但不是公益用途 → `无对价财产转移赠与·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问入账日、票据、审计节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、支付令、诉讼、仲裁 → `已催告解除索赔诉讼或仲裁→` 或对应专项。

挂靠、违法分包、规避限购、擅自公开募捐、向受制裁或恐怖活动组织捐赠、以公益掩盖关联输送：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（赠与人 / 受赠人 / 受益人，择一）；相对方；全文及公开承诺、物资清单、项目方案、账户证明、内部决议版本；是否无偿；用途是否特定到可监督；受赠人是慈善组织、政府、受益人本人还是临时筹款群；是否公开承诺或书面慈善捐赠；对公账户与票据；赠与人内部决议、国资或上市程序；标的质量与权属；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

## 起草模式

本原子只承担本类型起草。待签评改转 `公益道德义务性质的赠与合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`，不编造。出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 第 658 条第 2 款只关闭任意撤销，且不依赖公证；同一事实激活第 660 条请求交付。第 663 条法定撤销（一年除斥）和第 666 条穷困抗辩仍须保留。
- 第 2 款有事实门槛。救灾、扶贫、助残等公益用途，或可回链的道德义务（侵权补救、公开认捐、法定扶养之外的补偿），必须写进正文并能指回附件。
- 穷困加慈善法要件：第 666 条只及于尚未履行部分；公开承诺或书面慈善捐赠不再履行，须向公开承诺地或书面协议签订地县级以上人民政府民政部门报告并向社会公开说明。
- 无偿性与对公交付。用途限制、专款专用、监督审计必须可检验。

### 附件必附

- 用途能指回的项目方案、物资清单或公开承诺。空喊“本捐赠具有公益性质、永久不可撤销”而用途写成“由受赠人自行决定”：不得关闭任意撤销。
- 对公账户与票据安排。缺金额、批次、账户、期限用 `【待填】`。

### 禁止出现

- “没公证所以一定还能任意撤销”；“写了公益所以任何撤销权都没了”。
- 把亲属身份本身写成道德义务；把“权利转移前默认仍可任意撤销”写成公益主路径。
- 把公益用途改写成对赠与人本人受益的看护、居住、供养对价劳务。
- 用第 658、660、663、666 条锁定死因处分。
- 私下毁诺；删掉穷困路径做成绝对不可解除的单边枷锁。
- 赞助回报、冠名保底、投资收益、采购捆绑；向个人账户支付却称为公益捐赠；无资格自行公开募捐；指定捐赠人利害关系人为受益人。
- “资金到账后生效”写成生效条件。
- 把虚假公益、个人账户收款或无资格公募改成可履行结构。

8. 按框架六步出修改句

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把未达门槛的文本写成已关闭第 658 条、把看护供养改成公益外壳、把遗赠按赠与章改完、把虚假公益或个人账户收款或无资格公募改成可履行、保证税前扣除一定办成。
- `字段停止`：法域、公开募捐资格真伪、税前扣除资格与精确税额、国资或上市程序窗口、用途能否被认定为第 658 条第 2 款。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
