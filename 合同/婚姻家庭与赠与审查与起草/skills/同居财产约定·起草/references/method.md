# 审查方法（锁定 婚姻家庭 / 同居财产约定）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止打开或复制 `夫妻财产约定·审查` 的审查路径。禁止复制夫妻财产约定对外效力主路径、离婚冷静期、赠与任意撤销主路径、买卖户口/网签过户手册或施工挂靠节点。

定性校验：标题、核心给付与本类型一致才继续；夫妻财产制、终止时一次性分手结算、无偿给予或其他家事明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、视同夫妻共同财产、签字即过户、未登记可对抗善意第三人、分手费必然可强制执行、对方必然接受或唯一必得份额。

`search_law` 返回已失效《婚姻法》及其解释、《合同法》《物权法》、1989 年《关于人民法院审理未办结婚登记而以夫妻名义同居生活案件的若干意见》时记为噪声，不得写入 `L#`。

示范文本只参考结构。标题写成“分手协议”“青春补偿协议”或婚前财产协议的范本，只证明应切开，不得当作本类型已完成他类安排。

知识库纠正（不回写双文件）：

- `基本面.md` “法律适用主要依据总则编及合同编”：有约定从约定；无约定且协商不成时，2025-02-01 起施行的婚姻家庭编解释（二）第 4 条是专项分割规则。拟签署日在该日前的，该条法律结论字段停止，待核当时规则。
- `基本面.md` “合法配偶行使撤销权”：解释（二）第 7 条路径是违背公序良俗无效并依第 157 条处理，不是一口径的债权人撤销。不得写成配偶必然胜诉。
- `框架.md` “登记结婚后本协议自动转化为夫妻财产约定”：转化句可以谈，但不得写成已经取得第 1065 条对相对人的对外效力。结婚后对外债务改走夫妻共同债务规则。

- 解释（一）第 22 条只适用于被确认无效或被撤销的婚姻同居期间财产，不得套到普通未婚同居。

### 1.1 定性

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 双方未办结婚登记；约定同居期间财产归属、开支分担，以及解除时按该规则清算 | 本类型 | 正触发 |
| 已领结婚证，或 1994 年 2 月 1 日前符合结婚实质要件；约定婚内所得或婚前财产 | 夫妻财产约定 | 负触发 `夫妻财产约定·审查` |

| 父母健在，家庭成员分割共建老宅或其他家庭共有 | 分家析产 | 负触发 `分家析产协议·审查` |

支持切开的规范（法律结论须运行时复核）：

- 解释（二）第 4 条：双方均无配偶的同居析产，有约定从约定；无约定则各自所得归各自，共同出资或共同经营按出资比例并综合考虑共同生活、子女和贡献。本类型主干。
- 第 1062、1065 条：夫妻共同财产和夫妻书面财产约定——转 `夫妻财产约定·审查`。
- 解释（一）第 3、7、8 条：仅请求解除同居关系不受理；1994 年 2 月 1 日后未补办登记的不按事实婚姻；不得以配偶身份主张继承。
- 第 657、658 条：把自己的财产无偿给予——转赠与原子。
- 解释（一）第 22 条：无效或被撤销婚姻同居期间财产，除证明一方所有外按共同共有——不得套到普通未婚同居。

### 1.3 与分手协议 / 赠与切开（硬闸）

| 文本写法 | 本任务动作 | 修改句方向 |
| --- | --- | --- |
| 标题为同居财产协议，正文约定各自工资归各自、共同购房按出资比例、每月生活费分摊 | 正触发，留下本类型 | 首部写明“同居期间财产权属约定，不是夫妻财产约定，也不是分手协议或赠与” |
| 标题写同居协议，正文是“即日起分手，甲方付给乙方青春补偿五十万，双方互不纠缠” | 负触发 `分手协议·审查` | 不按存续期归属改完 |
| 甲方把登记在自己名下、单独出资的房屋“赠与乙方并不得撤销” | 负触发赠与原子；或必须改：该条整段移出本协议 | 不得在本类型写成同居共有且任意撤销权消灭 |

最强反方：相对方主张案涉房屋是一方个人财产，应按赠与撤销；或主张双方已构成婚姻，应走夫妻共同财产。修改句必须让清单自证出资和婚姻状况，不能靠标题自称。用户坚持把分手结算或赠与主轴留在本技能放行：负触发，不填本类型十节实体结论。

### 1.4 婚外同居 / 规避限购停笔（硬闸）

加载后或定性中出现：一方或双方有配偶，以补偿、分手费、青春损失费或转移夫妻共同财产作为共同生活对价；借用对方购房资格规避限购。

动作：

1. 交付告知：违背公序良俗的民事法律行为无效（第 153 条）。合同背离家庭伦理的，依合同编通则解释第 17 条可认定无效。夫妻一方为与他人同居等目的将夫妻共同财产赠与他人或以明显不合理价格处分的，另一方主张无效的，人民法院应予支持（解释（二）第 7 条），并依第 157 条处理。不得改写成可履行的婚外补偿或假资格路径。
2. 不写可履行的补偿时间表、“合法配偶不得主张”或假资格加名步骤。
3. 风险表只保留识别依据和删除/转出口径。
4. 用户坚持“改到能签且仍做这些事”：整体停止。

## 节点 3　财产分层、钱款性质与共有模式

### 3.1 三层财产表（硬闸：非婚姻财产制）

为每一项标的建表，缺一列则该项不得写成已可共有或已可分割：

| 列 | 必须看见 | 不得写成 |
| --- | --- | --- |
| 名称与识别信息 | 地址+证号，或车辆识别号，或账户后四位 | “以后挣的都算共同的”已确定 |
| 取得时点 | 同居前 / 同居期间 | 同居一段时间后个人财产自动转化 |
| 出资或形成过程 | 工资奖金等各自所得，或共同出资/共同经营凭证 | 标题写了同居即已共同共有 |
| 本次归属 | 各自所有，或按份共有及比例，或共同共有 | “视同夫妻共同财产各半” |

分类动作：

- 同居前个人财产、同居期间各自工资奖金劳务报酬知识产权收益、各自继承或受赠、单独生产经营投资收益 → 原则上各自所有。修改句禁止写成共同财产。
- 能支持共同出资购置或共同生产经营投资 → 留下本协议，优先写成按份共有并写清比例。
- 无法区分又无约定 → 标 `G#`，提示解释（二）第 4 条第二项综合考虑因素，不在本任务径行对半分。
- 一方无偿给予 → 整项交接赠与原子。

修改句：

「附件一《同居前个人财产清单》列明签署前各自名下财产，不因同居关系或共同生活时间延续而转化为共有。附件二《同居期间财产归属表》按下列规则填写：（1）各自所得的工资、奖金、劳务报酬、知识产权收益，各自继承或者受赠的财产以及单独生产、经营、投资的收益，归各自所有；（2）共同出资购置或共同生产、经营、投资的财产，按附件载明的出资比例按份共有；比例未填的，以可核对的出资额确定，不能确定的标【待核】，不得推定各半。双方确认：本协议不是夫妻财产约定，不适用法定夫妻共同财产制。」

### 3.2 钱款性质（资助 / 借款 / 赠与 / 共同投资）

同居期间一方给另一方的钱必须在清单中定性。摘要含糊或双方说法冲突：并列 `S#`/`D#`，该项定性字段停止。

| 文本写法 | 动作 |
| --- | --- |
| “资助”“生活费”无返还约定 | 可留为消耗性开支，不得事后改写成借款必还 |
| “借款”无金额、期限、利率 | 必须改：补本金、是否计息、还款日；不编造利率 |
| “赠与”但未过户或未交付 | 标任意撤销；建议公证或整段移交赠与原子 |
| 转账备注“购房款”但登记只在一方名下 | 必须改：写成按份共有出资确认，并约定加名期限 |

修改句：

「双方确认：【年/月/日】甲方通过【账户后四位】向乙方支付人民币【待填】元，性质为【共同购房出资 / 借款 / 生活费资助 / 赠与】四选一，不得事后改口。定性为共同购房出资的，计入附件二对应房产的甲方份额；定性为借款的，乙方应于【待填】日前返还本金，是否计息以本条书面记载为准；定性为生活费资助的，属于消耗性开支，解除同居时不予返还；定性为赠与的，适用赠与规则，权利转移前赠与人可以撤销，但经过公证的除外。」

### 3.3 共有模式

建议使用按份共有并写清比例。约定共同共有的，必须写明基础关系仅是同居约定而非婚姻，避免被误读成夫妻共同共有。未约定或约定不明：同居双方通常不具有第 308 条所称家庭关系，倾向视为按份共有；法律结论须运行时复核，不得写成必然。

一方长期承担家务或照料：可约定解除时给付劳务补偿或经济帮助，金额挂钩可描述的贡献，不得写成离婚经济补偿已经适用。

## 节点 4　登记对抗与加名

支持依据：第 209、214、215、216 条。

| 文本写法 | 动作 |
| --- | --- |
| “本协议签字之日，房屋即归双方共有，无须过户也可对抗任何人” | 红线删除。拆成合同生效 vs 物权变动 |
| 共同出资但产证只登记一人，无加名期限和不成的后果 | 必须补义务主体、期限、违约金或解除+返还出资 |
| 机动车只写“归双方使用” | 必须改：未经登记不得对抗善意第三人 |
| 用户要求倒签或补假批准、假无配偶证明 | 整体停止 |

修改句：

「本协议自双方签字按指印之日起对签字方发生合同效力。不动产所有权的设立、变更自记载于不动产登记簿时发生效力；未办理物权登记的，不影响本协议作为合同的效力，但未登记一方不得对外宣称已取得可对抗善意第三人或登记权利人的债权人的物权。双方应于签字后【待填】日内共同申请将【地址/证号】按附件二载明的份额办理转移或更正登记，税费由【待填】负担；逾期未申请的，守约方可书面催告，催告期满【待填】日仍不配合的，按每日人民币【待填】元支付违约金，并有权中止共同生活基金投入。」

不得把“双方同意视为已登记”写成可放行结构。

## 节点 5　开支分担与债务防火墙

1. 共同生活开支：房租或房贷、伙食、宠物、共同娱乐须列范围和分担比例。消耗性开支原则上不形成可分割财产。
2. 共同生活基金：可约定专户，户内按约定共有，户外各自所有。未给出月投入额用 `【待填】`。
3. 个人债务：同居期间一方以个人名义所负债务，原则上由其独立承担。不存在夫妻共同债务推定。
4. 联名贷款、共同经营负债、一方为另一方担保：单独列表，不得写进“各自债务各自承担”一句话里消灭。
5. 因共有物产生的债：对内按约定或份额，对外可能连带（第 307 条）。内部分担不当然消灭对外责任。

修改句：

「除双方联名贷款、共同生产经营所负债务以及一方经另一方书面同意提供的担保外，任何一方在同居期间以个人名义所负债务由该方独立承担，另一方不承担清偿责任。双方确认：本协议当事人之间不成立夫妻共同债务。一方因个人债务导致另一方名下财产被保全、执行或被诉的，应在【待填】日内消除妨碍，并赔偿因此产生的直接损失。」

规避限购或把已婚一方的夫妻共同财产转入本协议对方名下：停笔，不写出可履行过户时间表。

## 节点 6　公序良俗、格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 标题、分手费与排除诉权

| 文本写法 | 动作 |
| --- | --- |
| 标题为“分手协议”“青春补偿协议” | 必须改标题；若正文主轴已是终止结算，负触发 `分手协议·审查` |
| 无实际损失或劳务贡献的“分手费”“青春损失费” | 红线改写为“经济帮助款”或“共有财产差价补偿”，并挂钩可核对基数；无法挂钩则删除或转出 |
| “无论发生何种情况均不得起诉” | 红线删除。排除诉权的条款不具有该效力 |
| 以结婚为生效条件，但把婚后财产也提前写死 | 必须拆开：同居期间条款签署生效；以结婚为条件的婚后部分在登记前不生效 |

修改句：

「本协议名称为《同居期间财产权属约定》。任何一方不得要求对方支付与实际经济损失、共同财产差价或书面约定的劳务补偿无关的分手费、青春损失费。解除同居时，仅按附件二清算共有财产差价，并按第【待填】条给付劳务补偿人民币【待填】元。本协议任何条款不限制双方依法向人民法院提起诉讼的权利。」

### 6.2 格式与强制规范

一方重复使用的模板，对免责、放弃权利、管辖等异常条款仍审查提示说明。小字、夹在附件、仅有口头宣读：不得写成已尽提示。强制规范按第 153 条和解释第 16、17 条区分，不用失效口诀。

## 节点 7　解除清算、结婚转化与争议

1. 解除认定：一方书面通知、实际搬离满【待填】日、双方签署解除确认，择一或并列。未写解除时点：清算截止日无法确定，必须改。
2. 清算程序：搬离期限、共有财产分割方式、共同账户销户、钥匙与证件交还。只有“双方协商解除”而无通知和清理：必须改。
3. 结婚转化：可写“若双方登记结婚，应于登记后【待填】日内另行签署书面夫妻财产约定；在新约定生效前，本协议仅约束结婚前已形成的财产关系”。禁止写成“自动转化为夫妻财产约定且对第三人发生第 1065 条效力”。
4. 管辖：可约定被告住所地或共有不动产所在地人民法院。出现仲裁条款，不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核。不动产专属管辖可能：只标红旗，不选定唯一法院充作法律意见。民诉解释第 34 条允许同居财产争议约定管辖，法律结论须运行时复核。
5. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。
6. 建议见证或公证：可写进签署提醒。公证限制的是赠与任意撤销，不得写成“公证后物权已经变动”。

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

打开已加载的 `框架.md`，按六步逐段对照正文。`基本面.md` 用于校验类型、主体、标的、程序、结构和红旗，不代替本节点出句。

| 步 | 动作 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题用同居财产协议或同居期间财产权属约定，不用分手/青春补偿/夫妻财产约定混称；列双方身份与无配偶声明；鉴于写共同生活事实，不写保证有效、保证过户 | 标题或主体修改句 |
| 交易条款 | 三层财产清单；钱款性质；按份共有比例；开支分担；债务个人承担；登记与加名义务 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 删除婚外补偿；分手费改差价或劳务补偿；不配合登记的违约金；排除诉权删除；通知 | 可执行后果句或删除句 |
| 尾部 | 双方签字按指印；见证人；附件清单（初始财产、归属表、出资凭证）；合同生效≠物权变动 | 生效与附件修改句 |
| 语言 | 正说加反说；盯死各自所有 vs 夫妻共同、按份 vs 共同共有、资助 vs 借款 vs 赠与、签字 vs 登记 | 替换空词的句子 |
| 常见问题 | 未写结婚后是否另签；排除诉权；无解除时点；年度核算缺失 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（婚姻财产制错位、分手/赠与主轴、婚外补偿、签字即对抗第三人拒改、倒签、排除诉权）；
- `必须改`：可谈但签署前要落句（财产分层、钱款性质、加名期限、债务个人承担、解除认定、结婚后另签）；
- `可接受可优化`：仍要给句子，不得只标绿（年度核算、共同生活基金、见证人）。

用户不可接受事项优先写成红线。生存级住房只登记对方且拒写份额和加名、个人无限连带且用户拒绝升级：停止“可以签署”建议。
