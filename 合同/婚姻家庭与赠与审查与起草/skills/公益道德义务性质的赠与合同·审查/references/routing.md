# 边界与路由

本技能只审查 **赠与合同 / 公益、道德义务性质的赠与合同** 的待签文本。中文展示名是「审查公益、道德义务性质的赠与合同（赠与合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止按普通赠与或遗赠改完本约。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 无可读正文，本类型条件已谈妥，要出己方稿 | `公益道德义务性质的赠与合同·起草` |
| 已签未争、入账/票据/审计节点 | 本套导航的履约步骤 |
| 已成争 | `已催告解除索赔诉讼或仲裁→` 或对应专项领域 |
| 无偿给予但未达公益或道德义务门槛 | `一般赠与合同·审查`。不得按第 658 条第 2 款改完 |
| 受赠人向赠与人负担看护、居住、供养等本人受益义务 | `附义务的赠与合同·审查`。不得把对价劳务改成公益用途 |
| 房屋过户是主轴，无公益用途 | `房产赠与合同·审查` 或 `亲属间房屋赠与合同·审查` |
| 婚前或婚内把一方财产赠与配偶或约定共有 | `婚姻家庭中的赠与合同·审查`。婚姻家庭编解释（一）第三十二条不是本类型入口 |
| 以维持不正当关系为给付原因 | `涉及不正当男女关系的赠与合同·审查`。未装则只告知违法，不设计可履行结构 |
| 股权零元转让 | `零对价股权赠与·审查`。未装则 `unavailable` |
| 死后按某份安排过户、遗嘱处分 | `生前类赠与协议·审查` 或 `类赠与遗赠扶养协议·审查`。不得用赠与章锁定死因处分 |
| 以他人名称购房并支付房款 | `借名购房型赠与·审查`。未装则 `unavailable` |
| 不直接支付对价的财产转移且无公益用途 | `无对价财产转移赠与·审查`。未装则 `unavailable` |
| 换取冠名、广告、采购配额 | 转引擎重新定性；不得用本技能硬套 |
| C 端 029 | 只分流，不回改 |

公益捐赠正文里夹带一小段冠名或采购：专章交接对应原子或拆分改写；无偿捐赠条款可继续审。用户坚持本技能把一般赠与、附义务看护、赞助或遗赠整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿本类型文本来找未装本原子的专业版：输出 `unavailable`，提示，不得用一般赠与或附义务硬套。
