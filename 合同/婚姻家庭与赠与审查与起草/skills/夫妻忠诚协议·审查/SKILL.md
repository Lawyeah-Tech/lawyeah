# 夫妻忠诚协议·审查

## 任务目标

在单一立场下，只审查 **婚姻家庭 / 夫妻忠诚协议** 的待签文本，输出可决策意见：**人身自由限制无效**；**财产惩罚可分**（人身条款无效不等于整份无效）；**与夫妻财产约定、分手协议切开**；触发行为微观化与合法证据；风险表；可回给对方的修改句或红线；谈判与签署提醒；停止或转介。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「夫妻忠诚协议·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类型起草、履约交底、争议文书、离婚诉讼策略、整份必然有效或必然无效的保证、可履行的人身监控、放弃监护、限制再婚或非法取证结构。不输出夫妻财产约定的分别/共同/部分共同默认表，也不输出未婚分手清算表。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **人身自由限制无效。** 不得约定：不得再婚、不得与异性正常往来、上交手机或社交账号、强制定位或跟踪、不得单独出门或工作、出轨则放弃抚养或监护、剥夺探望、强制同意离婚。此类条款因限制人身自由、干涉婚姻自由或处分法定监护、探望，不能强制履行（第 153、1041、1042、1084、1086 条；家庭教育促进法第 20 条）。修改句：**删除**或降格为无强制履行的意愿声明，不得改写成可执行的监控、弃权或逼离结构。
2. **财产惩罚可分性。** 人身条款无效，不影响能够独立存在的财产处分（第 156 条）。禁止整份按“全有效”或“全无效”处理。财产后果必须：指向清单内特定财产或固定金额；保留违约方基本居住和生存所需；允许依法调减，禁止写“不得调整”“法院不得减少”。空词“净身出户”必须改为自愿处分列明财产，并写明不处分唯一住房中维持基本生活所需份额。过高定额金只标可调减风险，不输出唯一必得金额。
3. **与财产约定、分手协议切开。** 无忠实义务触发、只约定婚前或婚后所得归各自/共同/部分共同 → `夫妻财产约定·审查`，不在本任务补忠诚罚则，不套分别财产制默认表。双方未登记结婚、核心是结束同居并清算 → `分手协议·审查` 或 `同居财产约定·审查`，不把未婚双方写成夫妻忠实义务。知识库“去惩罚化、改名为婚姻财产约定”只是标题或结构建议：若删掉忠诚触发、改成存续期财产制，该块负触发财产约定场景，本任务不代做。

## 工作边界

正触发：已有可读待签书面忠诚协议或双方签署的忠诚保证，尚未签署，尚未成争，核心给付是合法夫妻以违反忠实义务为**触发条件**，预先安排财产处分、固定数额赔偿或分割比例；用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 无忠实义务触发，只改财产制 → `夫妻财产约定·审查`；
- 未登记双方结束同居并清算财产 → `分手协议·审查`；同居期间财产归属而无分手安排 → `同居财产约定·审查`；
- 已在办离婚，或文本是解除婚姻+子女+财产债务一揽子 → `离婚协议·审查`；
- 核心给付是分开居住及分居期间安排，忠诚罚金只是附属句或根本没有 → `分居协议·审查`；
- 类型未定或名实明显不符 → 本套导航的类型切开步骤；
- 无文本、本类型条件已谈妥、要出己方稿 → `夫妻忠诚协议·起草`；
- 已签，只问赔偿支付、过户节点 → 本套导航的履约步骤；
- 已成争（起诉离婚、索赔、债权人撤销）且要诉讼策略 → 转婚家或争议领域，不写诉讼策略；
- 文本处分子女名下财产，或授权藏匿子女、非法取证 → 停笔，不改写成可履行处分。

挂靠、违法分包、规避限购、借忠诚协议逃债或转移执行财产：只出告知，不改写成可履行的逃债结构。

## 建立审查坐标

确认：使用者与授权；单方立场（夫或妻一方及其代理人）；相对方；全文及附件版本；是否已在中国内地登记结婚；双方行为能力；触发行为是否微观；财产后果是否特定；是否夹带人身限制、放弃抚养探望、限制再婚、净身出户、非法取证授权；签署场景是否可能胁迫或抓奸当场；已知对外债务；不可接受事项；法域与拟签署日。

缺立场、同时掌握双方秘密、或无可读文本：不启动实体审查。

来源编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不选对用户有利的一版。未给出的金额、账号、产证号用 `【待填】`，不编造。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构，不证明本约条款已被接受，也不代替本任务出整稿。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《婚姻法》及其解释、《民法通则》《民法总则》当作现行规则。`search_law` 或实务返回“忠诚协议一律有效”“忠诚协议一律无效”“仅依忠实义务条款即可单独起诉并必胜”“净身出户必然执行”“人身限制可以强制履行”时，与解释（一）第 4 条、第 153、156、1084、1086 条冲突，记噪声，不得写入 `L#`。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典第 1043、464、1065、1091、153、156、1084、1086、1042、1041、148、150、151、585、209、215、658 条，婚姻家庭编解释（一）第 4、32、37、86、88 条，解释（二）第 7 条，合同编通则解释第 16、17、64、65 条。`search_practiced` 只补审查反例（人身条款与财产条款分判、效力地区差异）。不调用范本充作本约。不虚构案件系统。

`search_law` 对法律结论为 required。不可用时不拒绝执行，只停止法律结论字段。返回已失效《合同法》《婚姻法》及其解释、《民法通则》《民法总则》，或“一律有效/一律无效”“仅依 1043 即可单独起诉必胜”“净身出户必然执行”口诀时记为噪声，不得写入 `L#`。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口，不代替节点。

本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。交付按 [输出合同](references/output-contract.md)。边界见 [路由](references/routing.md)。知识双文件与 method 冲突时，以 method 核验口径为准。

0. 签署状态与成果分流：无文本且本类型条件已谈妥 → `夫妻忠诚协议·起草`；已签只问履行→履约；已成争要策略→婚家或争议领域；未签且目标是评改已有忠诚协议，才进入。
1. 类型识别：切开夫妻财产约定、分手协议、同居财产约定、离婚协议、分居协议。只加载本类型双文件。
2. 书面、合法夫妻、双方协议还是单方保证书。
3. 人身自由限制闸：删除再婚限制、抚养探望弃权、监控与禁足。
4. 触发行为微观化与合法证据：禁止空词“出轨/背叛”，禁止“任何证据均可”。
5. 财产惩罚可分性：特定财产或固定金额；保留生存份额；可调减；人身无效≠整份无效。
6. 强制规范：仅依 1043 不可诉；1091 与约定赔偿分层；赠与撤销；债权人。
7. 胁迫、欺诈、非法取证、逃债停笔。
8. 按框架六步出修改句：首部、交易条款（触发+可分财产后果）、配套、尾部、语言、常见问题。

必须有修改句。禁止只打红黄绿。每个风险回链文本位置。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、保证整份必然有效或净身出户必然执行、把人身监控/放弃监护/限制再婚/非法取证/逃债改成可履行文本、家暴或抓奸当场胁迫下优化逼签。
- `字段停止`：法域、婚姻登记状态、行为能力、财产特定性、权利负担、债权人知情、签署自愿性所需事实未核验。
- `目标停止`：主目标已变为从零起草、履约交底、离婚登记文件或诉讼策略，或用户要把本约改成无忠诚触发的财产制整案。

生存级住房被全部罚没、已知执行案件或人身安全风险且用户拒绝升级：停止“可以签署”建议，只列风险与转介。
