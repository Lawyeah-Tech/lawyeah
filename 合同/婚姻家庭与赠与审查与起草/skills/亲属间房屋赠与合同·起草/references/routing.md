# 边界与路由

本技能只起草 **赠与合同 / 亲属间房屋赠与合同** 的待签文本。中文展示名是「审查亲属间房屋赠与合同（赠与合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 现金、动产、股权或其他非房屋主轴 | `一般赠与合同·审查` |
| 非亲属、远亲、朋友、法人与个人之间的房产赠与 | `房产赠与合同·审查` |
| 商品房买卖、预售、五证、购房款 | `真实房屋买卖，买受人取得所有权`。不得删掉五证条款后继续当赠与审 |
| 存量房买卖、真实价款或“1 元／不必支付” | `或` |
| 分割已有家庭共有财产 | `分家析产协议·审查` |
| 仅夫妻财产归属约定 | `夫妻财产约定·审查` |
| 解除婚姻并分割财产 | `离婚协议·审查` |
| 附义务赠与为主轴 | `附义务的赠与合同·审查` |
| 公益、道德义务赠与已锁定，要按不得任意撤销整案审 | `公益道德义务性质的赠与合同·审查`。P1：专业版未装则 `unavailable`，提示，不得用本技能硬套 |
| 婚姻家庭中的非房屋赠与，或用户指定该原子 | `婚姻家庭中的赠与合同·审查`。P1；未装则 `unavailable` |
| 不正当关系包养结构 | `涉及不正当男女关系的赠与合同·审查`。P1；只告知不设计可履行包养 |
| 股权零元转让 | `零对价股权赠与·审查`。P1 |
| 只设居住权、不转移所有权 | `居住权设立合同·审查`。P1；未装则居住权专条可在本任务改句 |
| 纯赡养协议、房屋不是赠与标的 | `赡养协议·审查` |
| 死后生效或遗赠扶养 | `生前类赠与协议·审查` / `类赠与遗赠扶养协议·审查`。P1；未装则 `unavailable` |
| 无可读正文，本类型条件已谈妥，要出己方稿 | 本任务起草并自审 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争，或用户要撤销/确认无效诉讼策略 | `已催告解除索赔诉讼或仲裁→` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

赠与正文里夹带一小段居住权：居住权专条可在本任务改句；用户坚持把主文件改成只设居住权：`目标停止` 并交接 `居住权设立合同·审查`。夹带真实价款：交接买卖原子，不得因亲戚留在本技能。
