# 亲属间房屋赠与合同·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **赠与合同 / 亲属间房屋赠与合同**，输出可编辑草稿、未决项，并在出稿后用本类型硬闸自审。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文名必须是「审查亲属间房屋赠与合同（赠与合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、把一般赠与/非亲属房产赠与/买卖本约改完、把商品房五证或买卖网签做成主路径。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **房屋过户**：核心履行是向不动产登记机构申请赠与转移登记。修改句写清申请责任方、亲属关系证明与完税材料、期限。交钥匙、迁户口、口头“以后房子就是你的”不等于物权变动。禁止把商品房预售五证、买卖网签过户手册做成主路径。
2. **共有人**：签约主体必须覆盖登记簿全部权利人及有权同意的配偶。一方擅自把夫妻共有或家庭共有房屋赠给某一子女：该签署能力字段停止；受赠人无偿，现有依据不支持写成善意取得。未签字的其他子女或共有人，不受“不得有异议”约束。
3. **658 / 公证**：房屋记载于登记簿之前，赠与人可依第 658 条撤销。经过公证，或依法不得撤销的公益、道德义务性质赠与除外。父母子女、兄弟姐妹关系本身不等于道德义务。未公证却写“不可撤销”“已经赠与完成”：必须改。受赠人要锁定过户的，走公证以激活第 660 条请求交付。
4. **与一般赠与 / 房产赠与 / 买卖切开**：非房屋主轴 → `一般赠与合同·审查`；非亲属、远亲、朋友、法人与个人之间的房产赠与 → `房产赠与合同·审查`；有真实价款或“象征性 1 元 / 余款不必支付” → `或` 或 `真实房屋买卖，买受人取得所有权`，不得因亲戚改定性为赠与。假买卖冲税、假赠与避债、规避限购：只告知，不改成可履行结构。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签亲属间房屋赠与正文，尚未签署，尚未成争，核心给付是近亲属或家庭关系当事人无偿转移房屋所有权（及对应土地使用权），用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 现金、动产、股权或其他非房屋主轴 → `一般赠与合同·审查`；
- 非亲属、远亲、朋友、法人与个人之间的房产赠与 → `房产赠与合同·审查`；
- 主文件是商品房买卖、出现五证/预售/购房款 → `真实房屋买卖，买受人取得所有权`；不得删五证后硬套；
- 主文件是存量房买卖、出现真实价款或网签买卖条款 → `或`；
- 分割已有家庭共有财产 → `分家析产协议·审查`；
- 仅夫妻财产归属约定、无赠与过户主轴 → `夫妻财产约定·审查`；
- 解除婚姻并分割财产 → `离婚协议·审查`；
- 附义务为主轴（过户换长期对价给付） → `附义务的赠与合同·审查`；
- 公益、道德义务赠与已锁定且要按不得任意撤销整案审 → `公益道德义务性质的赠与合同·审查`（P1；专业版未装则 `unavailable`）；
- 婚姻家庭中的非房屋赠与，或用户明确要走该 P1 原子 → `婚姻家庭中的赠与合同·审查`（未装则 `unavailable`）；
- 只设居住权、不转移所有权 → `居住权设立合同·审查`（P1；未装则居住权专条可在本任务改句，但不改成居住权整案）；
- 死后生效或遗赠扶养 → `生前类赠与协议·审查` / `类赠与遗赠扶养协议·审查`（P1；未装则 `unavailable`）；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问递件日、完税日 → 本套导航的履约步骤；
- 已催告、撤销诉讼、确认无效、立案或仲裁 → `已催告解除索赔诉讼或仲裁→` 或对应专项领域。

假买卖冲税、无偿过户避债、规避限购：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（赠与人侧或受赠人侧择一）；相对方与亲属关系；全文及附件/权属证版本；登记权利人与共有/配偶是否全部出现；房屋坐落与单元号；抵押、查封、租赁、居住权；是否公证、是否已递件；过户期限与完税协助；是否唯一住房及老人是否继续居住；赠与人负债与意思能力；是否夹带价款；不可接受事项；法域、房屋所在地与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

## 起草模式

本原子只承担本类型起草。待签评改转 `亲属间房屋赠与合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`，不编造。出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 核心履行是向不动产登记机构申请赠与转移登记。写清申请责任方、亲属关系证明与完税材料、期限。
- 签约主体必须覆盖登记簿全部权利人及有权同意的配偶。受赠人无偿，不得写成善意取得。
- 房屋记载于登记簿之前，赠与人可依第 658 条撤销。父母子女、兄弟姐妹关系本身不等于道德义务。受赠人要锁定过户的，走公证以激活第 660 条请求交付。
- 登记完成，该套房屋任意撤销权消灭；占有交付不消灭第 658 条。

### 附件必附

- 亲属关系证明与完税材料安排。
- 权属证及全部登记权利人、配偶签署页。缺期限、份额、税费承担用 `【待填】`。

### 禁止出现

- 交钥匙、迁户口、口头“以后房子就是你的”写成物权变动。
- 商品房预售五证、买卖网签过户手册做成主路径。
- 未公证却写“不可撤销”“已经赠与完成”。
- “其他子女不得有异议”约束未签字人。
- 有真实价款或“象征性 1 元 / 余款不必支付”仍定性为赠与。
- 假买卖冲税、假赠与避债、规避限购的可履行结构。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`基本面.md` 中“亲属身份本身不等于道德义务”必须执行：不得把父母子女关系写成当然关闭第 658 条。`框架.md` 中“公证后生效”须向当事人说明未公证可能连合同请求权都没有；不得把“其他子女不得有异议”写成已约束未签字人。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 本任务起草模式；已签履约 → 本套导航履约步骤；已成争或撤销诉讼策略 → 合同争议。未签且目标是评改已有亲属房屋赠与文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。买卖、一般赠与、非亲属房产赠与、析产、遗赠负触发。

### 2. 主体、共有人与意思能力

全部登记权利人、配偶、受赠人分列。共有未闭合：字段停止。高龄处分人意思能力存疑：升级，不写“可以签”。

### 3. 房屋特定化与权利负担

坐落、单元号、面积、用途、土地使用权。抵押、查封、租赁、居住权未核不得写成无负担。不出商品房五证清单。

### 4. 过户、公证与占有交付

登记完成，该套房屋任意撤销权消灭。占有交付不消灭第 658 条。未公证却排除任意撤销：必须改。

### 5. 无偿性、税费与停笔结构

出现价款或“不必支付”：重新定性或停笔。假买卖/避债/规避限购不改成可履行。契税法第六条不免父母赠子女。

### 6. 撤销、居住权、格式条款与强制规范

任意撤销、法定撤销、继承人撤销、穷困抗辩分列。唯一住房无居住权：红线或必须改。无核验引文则法律结论字段停止。

### 7. 违约、解除与争议

拒不协助过户须有可执行后果。房屋物权争议标不动产所在地专属管辖红旗，不选定唯一法院充作意见。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把假买卖冲税、规避限购或无偿避债改成可履行结构。
- `字段停止`：法域、动态规则、共有签署、登记簿、宅基地/保障房资格、地方税负未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
