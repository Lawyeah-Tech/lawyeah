# 赡养协议·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构，不证明本约条款已被接受。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、1996／2009 年《老年人权益保障法》同条号、1992 年赡养协议公证细则、1985 年继承法意见当作现行规则。不得把婚姻家庭编解释（一）第四十九条抚养费比例写成赡养法定标准。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **婚姻家庭 / 赡养协议** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。`depends-on` 为空。不要求先跑导航。

主线是**成年子女等法定义务人对老年人履行赡养义务的具体分工、方式和费用标准**。协议只能量化履行，不能免除法定义务。不是配偶或兄弟姐妹扶养，不是父母对未成年子女的抚养，不是离婚一揽子协议，不是分家析产，不是继承人以外的遗赠扶养。

不交付：他类审查、从零起草、履约交底、争议文书、有效性保证、把弃产／断绝关系改成可履行免责、把不得再婚改成可履行、把子女“生养死葬换房产”改成可履行遗赠扶养。

## 工作边界

正触发：已有可读待签文本要评改，；尚未签署，尚未成争；核心给付是对父母或其他依法应受赡养的老年人落实经济供养、生活照料和精神慰藉；经老年人同意。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主给付是配偶互扶、兄弟姐妹扶养，或父母对未成年／不能独立生活子女的抚养 → `扶养抚养协议·审查`；
- 主文是解除婚姻、子女直接抚养和夫妻财产分割的离婚协议 → `离婚协议·审查`（本技能不沿用其登记生效主路径）；
- 主给付是分割现有家庭财产、宅基地或共有房产 → `分家析产协议·审查`；
- 变更直接抚养方或探视安排为主 → `抚养权变更协议·审查`；
- 夫妻分居安排为主 → `分居协议·审查`；
- 夫妻财产制约定为主 → `夫妻财产约定·审查`；
- 扶养人是继承人以外的组织或个人，对价是死后财产 → 本套导航的类型切开步骤 重新定性为遗赠扶养，不在本任务硬套；
- 无文本、本类型条件已谈妥、要出己方稿 → `赡养协议·起草`；
- 已签只问打款日、轮住交接 → 本套导航的履约步骤；
- 已成争（催告给付赡养费、起诉、立案、虐待遗弃刑案）→ **家事或合同争议领域**，不填签前十节。

伪造老人同意、倒签、把法定义务改成可履行免除、把限制再婚写成可履行：只出告知，不改写成可履行规避结构。

## 建立审查坐标

确认：使用者与授权；代表被赡养人、哪一名赡养人还是协助履行的配偶；相对方；正文与附件版本；费用／居住／护理／探望安排；不可接受事项；法域与拟签时限。缺立场或无可读文本则不启动实体审查。同时掌握双方或多方互冲突密时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的金额、日期、比例用 `【待填】`，不编造。

## 本类型硬闸

审查过程必须逐项点名，每闸必须有修改句，不得用抚养费比例、离婚登记生效或遗赠扶养优先效力代替：

1. **赡养法定义务不得免除**：放弃继承、断绝关系、父母偏心、老人再婚、未签字子女，均不能消灭法定义务。修改句删除免责，改回分工。
2. **费用标准**：生活费、医疗自费、护理／护工费分列；写支付日与账户；约定调整机制。禁止一次性买断且不得再请求。禁止套用抚养费月收入百分之二十至三十。
3. **与扶养／抚养切开**：对象是老年人、义务人是晚辈直系或依法应赡养的人。配偶、兄弟姐妹、未成年子女主给付 → `扶养抚养协议·审查`。
4. **人身与婚姻自由不得限制**：不得再婚、不得离开某地、不得探望某子女，不得改成可履行。
5. **经济供养／生活照料／精神慰藉三分列**：只写“负责养老”视为必须改。
6. **死后余财与遗赠扶养不得混入**：本约不处分遗产；子女不能用房产换免责。
7. **老人意愿与行为能力**：赡养人之间的协议须经老年人同意；能力不明则该同意字段停止，不得代签充作已同意。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验《民法典》第二十六条、第一千零六十七条、第一千零六十九条、第一千零七十二条、第一千零七十四条、第一千一百二十五条、第一千一百三十条、第一千一百五十八条、第八条、第一百五十三条；《老年人权益保障法》（2018 修正）第十四条至第二十三条；继承编解释（一）第三十二条；民诉解释第九条、第二百一十八条。第一千零五十九条、第一千零七十五条和婚姻家庭编解释（一）第四十九条仅用于与扶养／抚养切开。`search_practiced` 补审查反例；`search_template` 只借修改句结构。不虚构案件系统。

`search_law` 对法律结论为 required 级节点：不可用时不拒绝执行，只停止法律结论字段。返回已失效《合同法》、1996／2009 年《老年人权益保障法》同条号、1992 年公证细则、1985 年继承法意见时记为噪声，不得写入 `L#`。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签或伪造老人同意、把弃产／断绝关系写成可履行免责、把不得再婚写成可履行、把子女改成遗赠扶养以规避法定义务、保证协议必然有效或费用永远不得再调整。
- `字段停止`：老人行为能力未核、同意痕迹缺失、费用数字或调整机制未写清、未列名的法定义务人、继子女抚养教育事实不明。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或文本已滑入扶养／抚养、离婚、分家析产或遗赠扶养。

生存级医疗或长期护理费用且用户拒绝升级：停止“可以签署”建议。
