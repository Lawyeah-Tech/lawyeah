# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方必然接受、一次性费用永远不得再诉；编造未给出的赡养费、医疗比例、探望频率；把已失效《合同法》、1996／2009 年老年人权益保障法同条号、1992 年公证细则写入结论；把抚养费百分之二十至三十或离婚登记生效硬套本类型；输出可履行免责、可履行限婚或子女遗赠扶养规避结构。

## 1. 触发、单方立场与成果状态

立场（被赡养人／哪一名赡养人／协助履行的配偶）、授权、签署状态、主要目标。扶养／抚养、离婚一揽子、分家析产、遗赠扶养、已成争或其他负触发写路由，不启动实体审查。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》、1996／2009 年《老年人权益保障法》同条号、1992 年公证细则或 1985 年继承法意见时记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `婚姻家庭`，子级 `赡养协议`。写定性理由和与扶养／抚养、离婚协议、分家析产、遗赠扶养的切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识稿中的“公证最高证据效力”写降级说明：公证是证据补强。知识稿“配偶有辅助赡养义务”写降级说明：配偶协助履行，原则上不是独立法定义务人。伪造同意或可履行免责写停笔告知，不填可履行规避结构。

## 4. 主体、授权与文本版本

主体表：被赡养人（姓名、证件、行为能力、是否亲自同意）、各法定赡养义务人（亲生／收养／继子女及抚养教育事实、隔代条件）、协助履行的配偶、未签字子女、授权签字人。版本表：正文、附件、费用表、聊天确认；冲突并列，不选对用户有利的一版。

## 5. 给付闭环（本类型必填）

固定检查并回链文本：

- 被赡养人与义务人亲属关系，不得写成已断绝亲属关系即免责；
- 经济供养：月／季金额、支付日、账户、生活费是否含水电物业；
- 医疗与大病：报销后自费、护理费、营养费、护工费是否分列及分担比例；
- 生活照料与居住：轮住／固定居住／机构，紧急联络人，失能期护理；
- 精神慰藉：探望或问候频率，重大节日；
- 调整机制：物价、失能、收入重大变化时如何协商或再议，禁止“永远不得再要”；
- 禁止条款盘点：弃产免责、限婚限人身、死后余财归签字方、只给钱不照料。

缺口标 `G#`，不补费用数字。公证、基层见证、司法确认写成建议或条件，不写成已经完成或已获强制执行力。

## 6. 格式条款与强制规范

是否构成打印店／村委重复使用模板。审查免责、限婚、死后财产处分、管辖是否显著。强制规范只区分是否导致该条款或该行为无效与是否仅造成履行障碍。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。免责、限婚：用第二十六条、第一千零六十七条、第一千零六十九条、老年人权益保障法第十九条至第二十一条与第一百五十三条处理，不引用失效合同法。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。硬闸七项若文本或事实触及或沉默，必须各有至少一行，不得用色块代替。

## 8. 修改句

按框架六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点、不接受时的红线。未给出的数字用 `【待填】`。禁止只给原则、不给句子。禁止输出“放弃继承后不再赡养”“一次性付清后永远不得再要”“母亲不得再婚”“丙负责生养死葬故房屋归丙且乙免除义务”充当可放行修改句。

## 9. 谈判与签署提醒

谈判顺序：先红线（免责、限婚限人身、买断终局、子女遗赠扶养规避、伪造同意），再必须改（费用三项分列与调整、居住护理、探望、未列名义务人、紧急联络人），最后可优化（专项账户、基层见证、公证、配偶协助签署）。签署提醒：老人亲自签字或见证下面签；义务人列全；日期不得倒签。不指导倒签或补假同意。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书、代办公证或效力保证。
