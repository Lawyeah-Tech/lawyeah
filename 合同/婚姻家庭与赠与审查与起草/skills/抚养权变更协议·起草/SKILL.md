# 抚养权变更协议·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《婚姻法》及其解释、已失效《关于人民法院审理离婚案件处理子女抚养问题的若干具体意见》（法发〔1993〕30 号）或已失效《合同法》当作现行规则。现行年龄门槛是已满八周岁，不是十周岁。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **婚姻家庭 / 抚养权变更协议**，输出可编辑草稿、未决项，并在出稿后用本类型硬闸自审。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文名必须是「审查抚养权变更协议（婚姻家庭）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、把离婚财产债务改完、把监护资格私下转让改成可履行结构。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **最有利于未成年子女**：变更直接抚养安排，必须能回链子女生活、就学、照料、安全与稳定。父母方便、再婚条件、房产对价或“谁出钱谁带走”不得压过子女利益。现有依据不支持把“双方签字即当然符合子女最佳利益”写成已成立。
2. **不得私下处分监护核心**：父母是未成年子女的监护人。本协议只能安排谁直接抚养、谁给付抚养费、如何探望。出现“监护权归一方”“永久放弃监护”“另一方不得过问教育医疗”“把孩子过继/送给祖父母或第三人当监护人”：红线删除。有监护能力的父母不得用协议免除自己的监护职责。撤销或指定监护走法院，不在本任务改成可履行私下转让。
3. **与离婚协议切开**：主文件同时处理自愿离婚、夫妻共同财产、共同债务或离婚损害赔偿的，负触发 `离婚协议·审查`。不得删掉离婚/财产条款后硬套本技能。本协议只改原已确定的直接抚养安排及与之配套的抚养费、探望；原离婚文书未变更部分继续有效。
4. **已满八周岁须尊重真实意愿**：子女已满八周岁的，口头“孩子说跟我”不得写成已尊重。修改句要求独立、不受在场父母胁迫的意愿痕迹。不得把未成年人写成合同义务人或违约金债务人。
5. **抚养费与探望不得挂钩**：禁止“不付抚养费即不得探望”“不让看孩子即停付抚养费”。两套权利义务分列。免除抚养费换取直接抚养的，须提示子女仍可另行请求合理抚养费。
6. **私下协议不等于当然可强制执行**：双方签字通常只在父母之间发生合同约束力。户籍、学籍、出国办证、强制执行，现有依据不支持写成“签字当日对外已经变更完毕”。司法确认以依法设立的调解组织调解为前提，不是私人协议的自动升级。
7. **原抚养依据必须锁定**：鉴于条款写明原离婚协议、民政登记材料或法院判决/调解书文号、原直接抚养人、原抚养费与探望。原依据缺失：字段停止，不写成“以本协议为准覆盖全部家事安排”。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签正文，尚未签署，尚未成争；父母双方在原已确定的直接抚养安排之上，拟变更为另一方直接抚养或轮流直接抚养，并重写配套抚养费与探望；用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主文件同时处理自愿离婚、夫妻共同财产或共同债务 → `离婚协议·审查`；不得删财产条款后继续当本类型审；
- 婚姻仍存续，文本是分居期间的临时居住与生活安排，不变更已生效的离婚后抚养依据 → `分居协议·审查`；
- 不变更直接抚养人，只重订抚养费数额或支付方式 → `扶养抚养协议·审查`；
- 成年子女与父母之间的赡养 → `赡养协议·审查`；
- 夫妻财产归属、婚内财产约定 → `夫妻财产约定·审查`；
- 大家庭房产、宅基地或共同财产分割为主轴 → `分家析产协议·审查`；
- 主轴是把监护资格转给祖父母、其他个人或组织，或免除仍有监护能力的父母 → 不按本类型放行；告知须按监护规范走法院路径，需要意定监护文本则转 `意定监护协议·起草`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问给付日、交接日、户口办理节点 → 本套导航的履约步骤；
- 已催告、抢夺藏匿子女、立案、开庭、申请人身安全保护令或强制执行 → `已催告解除索赔诉讼或仲裁→` 或 `handle-family-succession`；C 端已成争评估只分流，不回改。

抢夺藏匿子女后逼签、以子女人身换房产或逃债、伪造子女意愿、倒签：只出告知，不改写成可履行结构。用户坚持：整体停止。

## 建立审查坐标

确认：使用者与授权；单方立场（现直接抚养一方，或拟接收直接抚养一方，择一）；相对方；全文及附件版本；子女姓名、出生日期、是否已满八周岁；原抚养依据文号与原直接抚养人；拟变更后的经常居住地、就学与主要照料人；抚养费构成与账户；探望时间方式；是否夹带监护放弃、离婚财产或再婚条件；不可接受事项；法域、子女现住地与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的金额、日期、账户、文号用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典第 1084、1085、1086、26、27、30、34、35、36、150 条，婚姻家庭编解释（一）第 48、49、55、56、57 条，解释（二）第 16 条，未成年人保护法相关条，以及司法确认条件；`search_practiced` 只补审查反例；`search_template` 只借栏目结构。不虚构案件系统。离婚协议范本、监护变更申请书、抚养权起诉状只作负向切开。

`search_law` 对上述法律结论为 required 级：不可用时不拒绝执行，只停止效力字段。返回已失效婚姻法解释、1993 年子女抚养意见或已失效合同法时记为噪声，不得写入 `L#`。


## 起草模式

本原子只承担本类型起草。待签评改转 `抚养权变更协议·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。缺数字用 `【待填】`，不编造。出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 变更理由必须回链子女生活、就学、照料、安全与稳定；父母方便、再婚条件、房产对价或“谁出钱谁带走”不得压过子女利益。
- 只安排谁直接抚养、谁给付抚养费、如何探望。
- 子女已满八周岁的，须有独立、不受在场父母胁迫的意愿痕迹。
- 抚养费与探望分列；禁止互相挂钩。
- 鉴于写明原离婚协议、民政登记材料或法院判决/调解书文号、原直接抚养人、原抚养费与探望。
- 写清生效时点、居住地、户口学籍配合义务；不把签字写成对外已经变更完毕。

### 附件必附

- 原抚养依据（离婚协议、民政登记材料或法院判决/调解书）。
- 子女出生日期材料。
- 已满八周岁独立意愿痕迹。
- 拟变更后居住就学说明。

### 禁止出现

- “监护权归一方”“永久放弃监护”“另一方不得过问教育医疗”。
- 把孩子过继/送给祖父母或第三人当监护人。
- “不付抚养费即不得探望”“不让看孩子即停付抚养费”。
- 未成年人写成合同义务人或违约金债务人。
- “双方签字即当然符合子女最佳利益”；“签字当日对外已经变更完毕”。
- 以子女人身换房产或逃债、伪造子女意愿、抢夺藏匿后逼签。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`基本面.md` 中“十周岁（现为八周岁）”按现行八周岁执行；“司法确认”“民政备案”不得写成私人协议的自动对外效力。`框架.md` 中“子女在结尾签名”不得写成未成年人成为合同义务人；“免除抚养费换取抚养权”不得写成子女请求权已经消灭。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 本任务起草模式；已签履约 → 本套导航履约步骤；已成争或人身安全事项 → 家事/争议专项。未签且目标是评改已有抚养安排变更文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与原抚养依据一致才继续。离婚一揽子、分居临时安排、只改抚养费、处分监护主轴负触发。

### 2. 主体、原依据与子女身份

父母双方亲签；子女身份与年龄；原离婚/判决/调解文书号。原依据未闭合：字段停止。

### 3. 最有利于未成年子女与八周岁意愿

变更理由须能回链子女利益。已满八周岁须独立意愿痕迹。

### 4. 监护核心不得私下处分

删除放弃监护、永久禁足教育医疗、把监护转给第三人。

### 5. 直接抚养移转、居住就学与对外程序

写清生效时点、居住地、户口学籍配合义务。不把签字写成对外已经变更完毕。

### 6. 抚养费、探望与强制规范

两套义务分列。逃债、胁迫、抢夺藏匿停笔。无核验引文则法律结论字段停止。

### 7. 违约、再协商与争议

户口学籍不配合、阻挠探望可约定可执行后果。不选定唯一法院充作意见。探望人身不得强制执行。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、保证法院必然确认、伪造子女意愿、把监护资格私下转让、以子女人身换房产或逃债、把抢夺藏匿后的逼签改成可履行。
- `字段停止`：法域、原抚养文书真实性、子女是否满八周岁、地方户籍/学籍窗口、司法确认受理条件未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书、离婚财产整案或监护指定诉讼，或已锁他类。
