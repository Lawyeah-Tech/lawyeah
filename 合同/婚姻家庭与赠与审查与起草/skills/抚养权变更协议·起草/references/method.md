# 审查方法（锁定 婚姻家庭 / 抚养权变更协议）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制离婚财产分割、冷静期、分居临时居住、赡养轮流、分家析产或意定监护主路径。

定性校验：标题、核心给付与本类型一致才继续；离婚一揽子、只改抚养费、分居临时安排或处分监护明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、法院必然确认、对方必然接受或唯一必得抚养费。

`search_law` 返回已失效《婚姻法》及其解释、已失效法发〔1993〕30 号《关于人民法院审理离婚案件处理子女抚养问题的若干具体意见》、已失效《合同法》及其解释时记为噪声，不得写入 `L#`。1993 年意见中的“十周岁”不得当作现行门槛。

示范文本只参考结构。变更抚养权合同、离婚协议书、抚养权起诉状范本不证明本约条款已被接受。离婚协议范本、监护申请书只作负向切开。

知识库纠正（不回写双文件）：

- `基本面.md` “十周岁（现为八周岁）”：运行时只写已满八周岁。十周岁是失效 1993 年意见口径。
- `基本面.md` “司法确认（法院裁定）”：私下协议本身通常不能直接申请司法确认。民事诉讼法第 205 条要求经依法设立的调解组织调解，双方自生效之日起三十日内共同申请。更稳妥的对外路径是起诉或诉前调解后由法院出具调解书。不得写成“签字即已获司法确认”。
- `基本面.md` “民政备案路径”：离婚后变更直接抚养，并非全国统一的民政补正程序。地方窗口能否受理标 `G#`，字段停止，不写成已经可办。
- `基本面.md` “对价关联结构”把房产份额与抚养移交挂钩：现有依据不支持把直接抚养写成可买卖标的。财产给付可另条记载，但不得作为子女人身交付的对价；疑似逃债或覆盖离婚财产整案则切开或停笔。
- `框架.md` “让年满八周岁的子女在协议结尾处签署”：意愿确认可作附件。不得把未成年人写成合同当事人、保证人或违约金债务人。
- `框架.md` “免除抚养费换取抚养权”：解释（二）第 16 条说明该类约定对父母双方有约束力，但不消灭子女在必要时另行请求合理抚养费的权利。
- `框架.md` “自双方签字之日起生效”且“对外变更登记”：私法约束力与户籍、学籍、强制执行力必须拆开写。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

支持切开的规范（法律结论须运行时复核）：

- 第 1084 条：离婚后仍是双方子女；协议不成按最有利于未成年子女判决；已满八周岁应当尊重真实意愿。
- 解释（一）第 55 条：离婚后一方要求变更子女抚养关系，应当另行提起诉讼。
- 解释（一）第 57 条：父母双方协议变更子女抚养关系的，人民法院应予支持——支持的是协议变更这一路径，不是私人签字对外当然完成变更。
- 第 27、34、35 条及总则编解释第 8 条：父母是监护人；有监护能力的父母不得协议免除监护职责。

### 1.4 胁迫、抢夺藏匿、逃债停笔

加载后或定性中出现：一方已强行带走子女再逼签；伪造子女意愿录音；以高额抚养费或房产过户转移责任财产逃债；约定再婚则自动丧失直接抚养。

动作：

1. 交付告知：未成年人保护法第 24 条禁止以抢夺、藏匿未成年子女争夺抚养；解释（二）第 12 条对抢夺藏匿可申请人身安全保护令或人格权禁令；第 150 条胁迫可撤销；解释（二）第 3 条对影响债权实现的财产安排可参照第 538、539 条撤销。不得改写成可履行逼签或逃债结构。
2. 不写“先把孩子交过来再补协议即不可反悔”、假意愿确认步骤或体外逃债路径。
3. 风险表只保留识别依据和删除/转出口径。
4. 用户坚持“改到能签且仍做这些事”：整体停止。

## 节点 2　主体、原抚养依据与子女身份

### 2.1 主体表

建表：父方签约名、母方签约名、被抚养子女姓名与证件号、原直接抚养人、拟直接抚养人、抚养费付款名与收款账户名。名称不一致不自动合并。

必须由子女的父母双方签署。一方死亡、已被撤销监护或明显丧失监护能力：本任务不把它写成普通双方变更；字段停止并点名监护/抚养专项。继父母、祖父母、新配偶不是本协议适格处分方，除非另有法定地位且材料可见。

口头“孩子爷爷同意了”不得写成已授权。不得把未成年人列为甲方/乙方。

### 2.2 原抚养依据必须锁定（硬闸）

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 无原离婚协议、无判决书/调解书文号、无民政登记痕迹 | 字段停止；修改句要求作为附件 | 以本协议覆盖全部家事安排 |
| 原文书写子女由甲直接抚养，本协议不引用即改由乙直接抚养 | 必须改：鉴于条款回链原文书 | 原安排已经自动失效 |
| 原判决尚未生效或二审进行中 | 目标停止或转争议 | 签前变更已经可对抗原判决 |

修改句：

「鉴于：双方于【待填】年【待填】月【待填】日经【民政登记 / 【待填】人民法院（【待填】）【民初/民终】【待填】号民事【判决书/调解书】】确定由【甲方】直接抚养子女【姓名、出生日期】。本协议仅变更上述直接抚养安排及与之配套的抚养费、探望事项。原文书中未在本协议中明示变更的条款继续有效。」

### 2.3 子女身份与年龄

写清姓名、性别、出生日期、证件号。由出生日期计算审查当日是否已满八周岁、是否不满两周岁。年龄不明：该意愿字段停止，不把“看起来挺大”写成已满八周岁。

不满两周岁：第 1084 条以母亲直接抚养为原则。协议改由父亲直接抚养的，须写明对子女健康成长无不利影响的具体事实，不得只写“双方同意”。

## 节点 3　最有利于未成年子女与八周岁意愿

### 3.1 最有利于未成年子女（硬闸）

支持依据：第 1084 条；未成年人保护法第 107 条；解释（一）第 46、56 条。

审查清单，缺一项则该字段不得写成已闭环：

1. 变更后经常居住地、主要照料人、就学是否可衔接。
2. 拟直接抚养一方是否有基本抚养能力与居住条件（材料未给则 `G#`，不编收入）。
3. 变更是否打断即将进行的学期、医疗或即将成年前的稳定环境。实务反例：原安排未发生重大变化时随意变更，可能不利于子女。
4. 禁止把父母再婚、迁居方便、房产归属写成唯一理由。

| 文本写法 | 动作 |
| --- | --- |
| “双方协商一致即视为最有利于子女” | 必须改。合意不等于已满足第 1084 条 |
| “谁出钱多谁直接抚养” | 红线。直接抚养不是拍卖 |
| 无居住地、无就学安排、无交接时间 | 必须补可履行安排，数字用 `【待填】` |
| 约定“若乙方再婚则子女自动改回甲方” | 必须删。再婚条件可能限制人身自由且未必符合子女利益 |

修改句：

「双方确认：变更直接抚养安排的目的是更有利于子女【姓名】的生活稳定、就学连续和身心健康，而非方便任何一方再婚、迁居或取得财产。自【待填】年【待填】月【待填】日起，子女由【乙方】直接抚养，经常居住地为【待填】，就读【待填】学校【待填】年级；甲方应于该日前在【待填】地点完成生活物品与证件交接。本条约定不构成对子女人身的处分或买卖。」

最强反方：相对方主张“有协议法院就应一律准许”。解释（一）第 57 条支持协议变更，但第 1084 条仍要求最有利于未成年子女；实务上附条件或理解分歧的协议，法院不宜直接据此变更。本任务不输出“法院必然支持”。

### 3.2 已满八周岁的真实意愿（硬闸）

支持依据：第 1084 条第 3 款；解释（一）第 56 条第（三）项；未成年人保护法第 24、107 条。

| 已有事实 | 不得写成 |
| --- | --- |
| 一方转述“孩子说愿意跟我” | 已尊重真实意愿 |
| 子女在父母共同在场、被许诺礼物或被威胁后签字 | 独立真实意愿 |
| 把子女列为协议当事人并约定违约金 | 未成年人已同意并受合同约束 |

修改句：

「双方确认：子女【姓名】已满八周岁。签署前应由与双方无利害冲突的【待填：律师见证 / 人民调解员 / 学校或社区工作人员】在父母回避的情况下单独询问其随何方生活的意愿，并将书面记录或视听资料作为附件【待填】。该附件仅用于证明已听取意愿，不使子女成为本协议当事人，也不使子女承担付款、违约或保证义务。若子女明确反对本次变更，双方不得仅凭本协议主张变更已经完成。」

未满八周岁：不要求子女签名。已满八周岁但用户拒绝任何独立询问：该字段停止，并在风险表标必须改；用户要求伪造意愿：整体停止。

## 节点 4　监护核心不得私下处分（硬闸）

支持依据：第 26、27、30、34、35、36、37 条；总则编解释第 8 条；未成年人保护法第 16、17、108 条。

| 文本写法 | 动作 | 修改句方向 |
| --- | --- | --- |
| 仅写“改由乙方直接抚养”，未写放弃监护 | 正触发可留下 | 用语改为“直接抚养”，避免“抚养权归乙方独自所有” |
| “监护权归乙方，甲方永久放弃监护/亲权” | 红线删除 | 见下方标准句 |
| “甲方不得过问子女教育、就医、户籍、出境” | 红线限制过苛部分 | 重大教育医疗协商；日常照料由直接抚养方实施 |
| 约定祖父母、继父或朋友为监护人，父母仍有监护能力 | 不改成可履行私下指定 | 告知：总则编解释第 8 条对免除有监护能力父母的协议，人民法院不予支持 |
| 一方已被判决撤销监护 | 本任务不恢复监护，不写成普通变更 | 转监护/家事专项 |

修改句：

「本协议变更的是子女的直接抚养安排，即与谁共同生活、由谁实施日常照料。父母双方仍是子女的监护人，依法继续履行抚养、教育和保护义务。任何一方不因本协议丧失监护资格，也不得请求对方永久放弃监护。涉及子女重大教育方向、手术等重大医疗、出境或处分子女名下财产的，双方应事先协商；意见不一致时，按照最有利于子女的原则处理，任何一方不得擅自处分子女财产。」

用户坚持保留“永久放弃监护”或把监护转给第三人：整体停止，不改成“加一句备案即可放行”。

## 节点 5　直接抚养移转、居住就学与对外程序

### 5.1 移转须可履行

审查：生效或交接日、居住地、户口迁移配合、学籍档案转移、证件（户口簿、护照、医保卡）交接清单。禁止只写“抚养权即日起归乙方”。

轮流直接抚养：解释（一）第 48 条以有利于保护子女利益为前提。必须写切换日期、交接地点、各自期间的费用和就学不中断安排。假期各半不是当然的轮流直接抚养。

### 5.2 私下协议不等于当然可强制执行（硬闸）

| 文本写法 | 动作 |
| --- | --- |
| “本协议签字当日，子女抚养关系对外已经变更，学校、派出所必须配合，否则构成拒不执行” | 红线。私人协议不能给行政机关设定义务，也不能自成执行名义 |
| “双方同意视为已完成司法确认” | 红线删除。司法确认以依法设立的调解组织调解为前提 |
| 完全不提对外路径 | 必须改：分写对内生效与可选的调解书/司法确认路径；地方民政能否补正当字段停止 |

修改句：

「本协议自父母双方签字之日起，对双方发生合同约束力。双方应于签字后【待填】日内共同向【待填】人民法院申请调解，或经依法设立的调解组织调解后三十日内共同申请司法确认，争取由人民法院出具调解书或确认裁定。未经前述程序，任何一方不得向学校、公安机关或其他单位声称子女直接抚养关系已对外确定并要求强制配合。户籍、学籍迁移由【乙方】负责申请，【甲方】在【待填】日内提供必要证件并到场；具体能否办成，以有权机关当时规则为准。」

不得把“民政局一定给补正离婚协议”写成已核验路径。

## 节点 6　抚养费、探望、格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 抚养费

支持依据：第 1085 条；解释（一）第 42、49、55 条；解释（二）第 16 条。

抚养费包括生活费、教育费、医疗费等。写清金额或计算基数、支付日、支付至何时、收款账户、大额支出分担。禁止编造收入或当地标准金额。解释（一）第 49 条的 20%–30% 是裁判参考，不是本协议必须采用的法定费率。

“至独立生活”必须改成可识别时点：一般至十八周岁；仍在接受高中及以下学历教育，或因非因主观原因无法维持正常生活的成年子女，可另约。不得只写“大学毕业”却不处理中途辍学或已就业。

一次性给付：可约定，但须写明涵盖范围和不因一次性给付剥夺子女另行提出合理要求的权利。

### 6.2 抚养费与探望不得挂钩（硬闸）

支持依据：第 1085、1086 条；未成年人保护法第 24 条。实务反例：探望与抚养义务是两套法律关系，不得因欠费剥夺探望。

| 文本写法 | 动作 |
| --- | --- |
| 不付抚养费即不得探望 | 红线删除挂钩 |
| 不让探望即停付抚养费 | 红线删除挂钩 |
| 探望时间空白，或“随时看，直接抚养方说了算” | 必须改：频率、时段、接送地点、寒暑假、提前通知时限 |
| 直接抚养方保证“保证孩子一定愿意被探望” | 删除保证；改为协助义务，中止探望须依法 |

修改句：

「不直接抚养的一方应于每月【待填】日前向【待填】账户支付抚养费人民币【待填】元。任何一方不得以对方未支付抚养费为由拒绝协助探望，也不得以对方未协助探望为由拒绝支付抚养费。一方逾期支付的，按逾期金额每日【待填】‰支付违约金，但不停止探望。探望不利于子女身心健康的，另一方应依法请求人民法院中止探望，不得自行永久取消。」

探望安排示例句须可执行：隔周周末、寒暑假起止日、接送地点。中止探望只能由法院依法决定。

免除抚养费换直接抚养：可记载对父母双方有约束力，但须加：

「本条约定不妨碍子女在必要时依照民法典第一千零八十五条向父母任何一方提出超过本协议原定数额的合理要求。」

### 6.3 格式条款与强制规范

父母双方就单一子女拟定的变更协议，通常不构成经营者面向不特定相对人的格式条款。若一方使用律师馆模板且异常剥夺探望或监护，仍按第 496、497 条审查提示与无效可能。

强制规范：违反法律、行政法规强制性规定不一律无效（第 153 条；合同编通则解释第 16 条）。私下放弃监护、以子女人身换财产逃债、胁迫签字：不改写成有效履行。禁止用已失效“效力性/管理性”口诀代替解释第 16 条。

## 节点 7　违约、再协商与争议

1. 不配合户口、学籍、证件交接：可约定限期、违约金和再次请求变更直接抚养的合同权利。不得写成已经构成拒不执行判决。
2. 阻挠探望、藏匿子女：可约定违约金并保留依法申请人身安全保护令或变更安排的权利。不在本任务认定已构成侵权。
3. 只有“依法承担违约责任”视为必须改。
4. 违约金不是必得金额；修改句避免“不得调整”或“按房产总价必得”。
5. 重大教育、医疗决策：先协商，期限用 `【待填】` 日；协商不成可请求有关部门或法院处理，不写成一方最终解释权。
6. 争议解决：出现仲裁条款，须提示身份关系争议仲裁可受理性待核，不得假装仲裁必然可处理抚养关系。或裁或诉、机构不明：标待核，修改句改成单一法院连结点。子女经常居住地、一方住所地是常见连结点，不选定唯一法院充作法律意见。
7. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。
8. 不得对子女人身或探望行为设计强制执行条款。
