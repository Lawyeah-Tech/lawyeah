# 边界与路由

本技能只起草 **婚姻家庭 / 抚养权变更协议**。中文名必须是「审查抚养权变更协议（婚姻家庭）」。

负触发只写触发判定、完整 Skill ID 和最小交接，不填十节实体结论。禁止在正文写半截 ID。

| 主要目标 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 主文件同时处理自愿离婚、夫妻共同财产、共同债务或离婚损害赔偿 | `离婚协议·审查`。不得删财产或离婚条款后硬套本技能 |
| 婚姻仍存续，文本是分居期间的临时居住与生活安排 | `分居协议·审查` |
| 不变更直接抚养人，只重订抚养费或大额分担 | `扶养抚养协议·审查` |
| 成年子女与父母之间的赡养 | `赡养协议·审查` |
| 夫妻财产归属、婚内财产约定 | `夫妻财产约定·审查` |
| 大家庭共同财产、宅基地、分家 | `分家析产协议·审查` |
| 主轴是免除仍有监护能力的父母，或把监护资格私下转给祖父母、其他个人或组织 | 不按本类型放行。告知须按民法典第 27、30、36 条及总则编解释第 8 条走法院路径；意定监护文本转 `意定监护协议·起草` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、问给付日/交接日/户口办理节点 | 本套导航的履约步骤 |
| 已成争、抢夺藏匿、人身安全保护令、起诉应诉或强制执行 | `已催告解除索赔诉讼或仲裁→` 或 `handle-family-succession` |
| C 端评估变更抚养、探望规划、抚养费测算或离婚协议起草 | 只分流，不回改 C 端目录，不引用本包研发路径 |

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。

夹带事项的交接：离婚财产整段交出 `离婚协议·审查`；纯财产约定交出 `夫妻财产约定·审查`；监护指定诉讼只点名家事专项，本任务不写可履行监护转让句。
