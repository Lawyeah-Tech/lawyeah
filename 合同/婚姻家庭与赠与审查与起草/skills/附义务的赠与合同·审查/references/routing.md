# 边界与路由

本技能只审查 **赠与合同 / 附义务的赠与合同** 的待签文本。中文展示名是「审查附义务的赠与合同（赠与合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 无偿给予但无负担，或只有感恩、不得转卖等附言 | `一般赠与合同·审查`。不得按第 663 条第 3 项改完 |
| 用途限于救灾、扶贫、助残等公益或道德义务，关闭的是任意撤销权 | `公益道德义务性质的赠与合同·审查`。P1：专业版未装则 `unavailable`，提示，不得用本技能硬套 |
| 房屋过户是主轴，正文无照料或其他可强制负担 | `房产赠与合同·审查` 或 `亲属间房屋赠与合同·审查` |
| 婚前或婚内把一方房产赠与配偶或约定共有 | `婚姻家庭中的赠与合同·审查`。P1；未装则 `unavailable`。解释（一）第 32 条只作交接，不在本类型展开 |
| 股权零元转让 | `零对价股权赠与·审查`。P1；未装则 `unavailable` |
| 以维持不正当关系为给付原因或义务 | `涉及不正当男女关系的赠与合同·审查`。P1；未装则只告知违法，不设计可履行结构 |
| 继承人以外的人承担生养死葬，死后取得财产 | `遗赠扶养协议·审查`。P1；未装则 `unavailable` |
| 死后按某份安排过户，无生前负担+生前给予 | `生前类赠与协议·审查` 或 `类赠与遗赠扶养协议·审查`。P1；未装则 `unavailable` |
| 主给付是赡养费、照料，无财产赠与 | `赡养协议·审查` |
| 家庭共有财产分割，不是把自己的财产无偿给予 | `分家析产协议·审查` |
| 义务价值接近标的，或写成“视同已付购房款” | 本套导航的类型切开步骤 按买卖或服务重定 |
| 主文件只设立居住权 | `居住权设立合同·审查`。P1；未装则 `unavailable` |
| 无可读正文，本类型条件已谈妥，要出己方稿 | `附义务的赠与合同·起草` |
| 已签未争、只问过户日或生活费支付 | 本套导航的履约步骤 |
| 已成争，或用户要撤销权诉讼策略 | `已催告解除索赔诉讼或仲裁→` |
| C 端大众快检 | 只分流，不回改 |

附义务赠与正文里夹带一小段居住权或赡养标准：居住权登记专条可点名 `居住权设立合同·审查`，法定赡养精算可点名 `赡养协议·审查`；财产无偿给予、义务量化、第 658 条窗口和第 663 条第 3 项继续审。用户坚持本技能把一般赠与、公益赠与或遗赠扶养整案改完：`目标停止`。
