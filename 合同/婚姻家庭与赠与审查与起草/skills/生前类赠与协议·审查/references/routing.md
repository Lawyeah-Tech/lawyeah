# 边界与路由

本技能只审查 **赠与合同 / 遗赠协议（生前约定死后过户财产的 “类赠与” 情形）** 的待签文本。中文展示名是「审查遗赠协议（生前约定死后过户财产的 “类赠与” 情形）（赠与合同）」。

类赠与只描述经济效果：死后无偿给财产。法律性质是单方死因处分，不是生前赠与合同，不是标准遗嘱继承，也不是遗赠扶养协议。签字不是物权变动。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 现在过户、已交钥匙并办赠与登记、已办公证赠与要立即转移 | `一般赠与合同·审查`；房屋且非亲属主线走 `房产赠与合同·审查`；近亲属房屋走 `亲属间房屋赠与合同·审查` |
| 公益、道德义务赠与是主文件 | `公益道德义务性质的赠与合同·审查` |
| 受赠人须持续履行义务才给财产，且给的时点是生前 | `附义务的赠与合同·审查` |
| 婚姻家庭中的赠与、婚内加名 | `婚姻家庭中的赠与合同·审查` 或 `夫妻财产约定·审查` |
| 股权零元转让且生前过户 | `零对价股权赠与·审查` |
| 生养死葬、养老送终、持续照料换死后财产 | `遗赠扶养协议·审查` 或 `类赠与遗赠扶养协议·审查` |
| 标准遗嘱形式，受益人是配偶、子女、父母等法定继承人 | `遗嘱·审查` |
| 家庭共有财产分割、分家析产 | `分家析产协议·审查` |
| 无可读正文，本类型条件已谈妥，要出己方稿 | `生前类赠与协议·起草` |
| 遗嘱人已死亡，只问六十日接受、完税、转移登记日 | 本套导航的履约步骤 或继承过户专项 |
| 已成争的普通合同路径 | `已催告解除索赔诉讼或仲裁→` 或对应专项领域 |
| 继承人已起诉、债权人撤销或逃债刑事立案 | 争议或执行专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

死后过户正文里夹带一小段生前已完成赠与清单：只标隔离，不把该清单当本类型标的改完。用户坚持本技能把生前赠与、遗赠扶养或标准遗嘱整案改完：`目标停止`。

禁止打开 `遗嘱·审查`、`遗赠扶养协议·审查`、`类赠与遗赠扶养协议·审查`、`房产赠与合同·审查`、`一般赠与合同·审查` 的 method。

专业版未收录的 P1 场景不会安装本原子。若用户拿本类型文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
