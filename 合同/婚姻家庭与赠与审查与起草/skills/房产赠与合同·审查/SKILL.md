# 房产赠与合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、已失效《物权法》、已失效契税暂行条例当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **赠与合同 / 房产赠与合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文名必须是「审查房产赠与合同（赠与合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证必然过户或任意撤销必然消灭。

## 本类型硬闸

1. **登记才物权变动**：房屋所有权及占用范围内土地使用权，自记载于不动产登记簿时发生效力。合同成立只产生债之效力。禁止把交钥匙、入住、装修、支付物业费写成“赠与已完成”或“受赠人已取得所有权”。未办理物权登记，不影响合同效力，但不发生物权效力。
2. **任意撤销窗口**：变更登记完成前，赠与人可依第 658 条撤销。经过公证，或依法不得撤销的救灾、扶贫、助残等公益、道德义务性质除外。合同写“不可撤销”“永不反悔”但未公证、也不具备公益道德义务性质的，通常挡不住第 658 条。受赠人要锁死：先公证再递件，或签署当日递件。赠与人要保留窗口：不过户、不公证。
3. **逃债第 538 条**：债务人以无偿转让财产等方式处分财产权益，影响债权人债权实现的，债权人可以请求人民法院撤销。合同或用户陈述出现躲避债务、规避执行、先过户再转回：只出告知，不改写成可履行逃债、代持或回购结构。不在本任务宣告行为已被撤销或必然被撤销。
4. **与亲属房屋赠与 / 买卖切开**：近亲属或家庭内部、主线是税率、赡养、只赠一方或婚内加名 → `亲属间房屋赠与合同·审查` 或 `婚姻家庭中的赠与合同·审查` / `夫妻财产约定·审查`。出现房款、补偿款、装修折价、债务抵销作为取得房屋的对价 → `或` 或 `真实房屋买卖，买受人取得所有权`。以赠与通道规避限购、信贷或税收：只告知名实不符和行政风险，不为该目的改成可履行假结构。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签房产赠与正文，尚未签署，尚未成争，核心给付是无偿转移特定房屋权利，当事人不是以近亲属家庭伦理或税率为审查主线，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 父母子女、配偶、兄弟姐妹等近亲属，主线是家庭伦理、亲属税率、只赠一方或婚内加名 → `亲属间房屋赠与合同·审查` 或 `婚姻家庭中的赠与合同·审查` / `夫妻财产约定·审查`；
- 出现房款或其他财产对价，或“名为赠与、实为买卖” → `或` 或 `真实房屋买卖，买受人取得所有权`；
- 标的不是房屋而是现金、动产或权利，房屋只是顺便一提 → `一般赠与合同·审查`；
- 主给付是受赠人负担持续义务才给房 → `附义务的赠与合同·审查`；
- 救灾、扶贫、助残等公益、道德义务赠与是主文件 → `公益道德义务性质的赠与合同·审查`；
- 解除婚姻并分割共同财产 → `离婚协议·审查`；家庭共有财产分割 → `分家析产协议·审查`；
- 死后生效、遗嘱处分 → `生前类赠与协议·审查` 或 `遗嘱·审查`；
- 股权零元转让 → `零对价股权赠与·审查`；
- 购房合同相对人一开始就是受赠人、审查出资与撤销 → 转引擎重新定性；
- 无文本、本类型条件已谈妥、要出己方稿 → `房产赠与合同·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁或债权人已提起撤销 → `已催告解除索赔诉讼或仲裁→` 或对应专项。

挂靠、违法分包、规避限购、规避经适房封闭期、逃避债务或执行：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及权属证/共有人同意/决议/租赁/居住权版本；房屋是否特定化；是否无偿；是否近亲属及主线；是否书面、公证、已递件；登记簿权利人是否全部签字；抵押查封租赁居住权户口；受赠人限购或身份资格；赠与人负债与诉讼；税费安排；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的面积、期限、税负用 `【待填】`，不编造。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `房产赠与合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议或家事/执行专项。未签且目标是评改已有房产赠与文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。亲属房屋、买卖、一般赠与、附义务、遗赠、析产负触发。

### 2. 主体、共有与资格

登记簿全部权利人为赠与人。共有人、配偶、公司决议未闭合则签署能力字段停止。受赠人限购、境外个人、农村宅基地身份未核验则履行字段停止。

### 3. 标的特定化与权利负担

坐落、单元号、面积、用途、土地使用权。抵押、查封、租赁、居住权、封闭期。未登记附属物不得“顺便赠与”完成物权。

### 4. 登记、占有与任意撤销

申请登记的责任方、期限、材料。交付占有与物权变动分列。658 窗口按是否公证、是否公益道德义务处理。

### 5. 税费、538 与限购

税种承担表必备。538 与规避限购只告知。资格不成就约定解除，不强制过户。

### 6. 格式条款与强制规范

无核验引文则法律结论字段停止。

### 7. 法定撤销、穷困、居住权、违约

663 一年、664 六个月、666 仅未过户部分。未经公证不宜设高额逾期过户违约金与任意撤销并存。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把交钥匙写成已取得物权、把逃债或规避限购改成可履行、未公证却保证 658 消灭。
- `字段停止`：法域、动态规则、限购细则、税负精确额、共有或决议未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
