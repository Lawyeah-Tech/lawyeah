# 生前类赠与协议·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **赠与合同 / 遗赠协议（生前约定死后过户财产的 “类赠与” 情形）**，输出可编辑草稿、未决项，并在出稿后用本类型硬闸自审。

本技能类型锁死。不扫描其他类型。中文名必须是「审查遗赠协议（生前约定死后过户财产的 “类赠与” 情形）（赠与合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证死后必然过户或本文件不可撤回。

## 本类型硬闸

1. **死后生效，签字不是物权变动**：继承从被继承人死亡时开始。本文件在遗嘱人生存期间不转移财产权利。受遗赠人无权凭签字、交钥匙或“协议生效”请求过户或占有。禁止写“签字即生效并办理过户”“先过户后算遗赠”。一份文件既有生前过户段又有死后段：生前段转出对应生前赠与原子，死后段才留本任务。
2. **生前约定死后过户 ≠ 生前赠与**：现在就要过户、已交付或已办赠与公证 → `一般赠与合同·审查` / `房产赠与合同·审查` / `亲属间房屋赠与合同·审查` / `公益道德义务性质的赠与合同·审查` / `附义务的赠与合同·审查` / `婚姻家庭中的赠与合同·审查` / `零对价股权赠与·审查`。本类型走继承编，不走赠与章。禁止用第 658、660、663、666 条描述、锁定或撤销本文件。赠与公证不得写成已经锁死死因处分。
3. **生前约定死后过户 ≠ 遗嘱继承、≠ 遗赠扶养**：标准遗嘱且受益人是法定继承人 → `遗嘱·审查`。出现生养死葬、养老送终、持续照料作为取得财产的对价 → `遗赠扶养协议·审查` 或 `类赠与遗赠扶养协议·审查`。不得删掉扶养句或把子女改称“受遗赠人”后硬套本技能。与遗赠扶养协议冲突时，协议优先。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿；尚未签署，尚未成争，核心安排是遗嘱人死亡后才把个人财产无偿给法定继承人以外的人；文本常叫遗赠协议、死后过户协议，或误写成赠与合同；用户问能不能签、哪里必须改、怎么回对方。类赠与只描述经济效果像无偿，法律上按单方死因处分审。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 现在过户、已交付或权利在生前转移 → 对应生前赠与原子（`一般赠与合同·审查` / `房产赠与合同·审查` / `亲属间房屋赠与合同·审查` 等）；
- 生养死葬或持续扶养是取得财产的对价 → `遗赠扶养协议·审查` 或 `类赠与遗赠扶养协议·审查`；
- 标准遗嘱形式，受益人是配偶、子女、父母等法定继承人 → `遗嘱·审查`；
- 家庭共有分割、分家析产 → `分家析产协议·审查`；
- 夫妻财产制度安排 → `夫妻财产约定·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 遗嘱人已死亡，只问接受表示日、完税日、转移登记日 → 本套导航的履约步骤 或继承过户专项，不在本任务当签前评改；
- 已催告、继承诉讼、债权人撤销或刑事立案 → `已催告解除索赔诉讼或仲裁→` 或家事/执行专项。

挂靠、违法分包、规避限购、逃避债务或执行：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及旧遗嘱/扶养协议/权属证版本；遗嘱人是否在世、行为能力；受遗赠人是否法定继承人；有无扶养对价；过户时点；所选形式与见证人；标的是否个人份额及负担；通知与六十日安排；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

先问四句再定性：**人还在不在、过户是现在还是死后、有没有扶养对价、受益人是不是法定继承人。**

## 起草模式

本原子只承担本类型起草。待签评改转 `生前类赠与协议·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`，不编造。出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

本类型走继承编，不走赠与章。现在就要过户、已交付或已办赠与公证：负触发对应生前赠与原子。出现生养死葬对价：负触发遗赠扶养。受益人是法定继承人：负触发遗嘱。

### 起草必写

- 死后生效。继承从被继承人死亡时开始。本文件在遗嘱人生存期间不转移财产权利。受遗赠人无权凭签字、交钥匙或“协议生效”请求过户或占有。
- 只处分死亡时仍属遗嘱人的个人合法财产。共有房屋只写个人份额。已完成生前赠与的财产不再遗赠。
- 受遗赠人须在法定继承人以外。撤回走第 1142 条，不走第 658 条。数份抵触以最后的遗嘱为准。
- 知道受遗赠后六十日内书面接受，否则视为放弃。登记原因是继承/受遗赠，不是赠与。
- 为双缺继承人留必要份额。执行遗赠不得妨碍清偿税款和债务。与遗赠扶养协议冲突时，协议优先。
- 须符合所选遗嘱形式。双方签字的“协议”若不符合遗嘱形式，可能两头不靠。

### 附件必附

- 所选形式要求的见证人或其他形式要件安排。不存在“按赠与合同补正”。
- 标的权属与个人份额说明。缺份额、期限、税负用 `【待填】`。

### 禁止出现

- “签字即生效并办理过户”“先过户后算遗赠”。
- 用第 658、660、663、666 条描述、锁定或撤销本文件。赠与公证写成已经锁死死因处分。
- 赠与人/受赠人、违约金、任意撤销权、第 660 条请求交付、第 666 条穷困抗辩。
- 删掉扶养句或把子女、配偶改称“受遗赠人”后硬套本类型。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 本任务起草模式；人已死只问过户日 → 履约或继承过户专项；已成争 → 争议或家事专项。未签且目标是评改已有死后过户类赠与文本，才进入本任务。

### 1. 四问锁类型

人在不在、现在还是死后、有无扶养对价、是不是法定继承人。生前赠与、遗赠扶养、遗嘱继承负触发。不得删句后硬套。

### 2. 主体、行为能力与受益人范围

遗嘱人须有完全民事行为能力。受遗赠人须在法定继承人以外。子女、配偶写成“受遗赠人”的，转 `遗嘱·审查`。

### 3. 标的特定化与遗产范围

只处分死亡时仍属遗嘱人的个人合法财产。已完成生前赠与的财产不再遗赠。共有房屋只写个人份额。

### 4. 死后生效：签字不是物权变动

生存期间不得请求过户。交钥匙、入住、双方盖章都不产生物权。不动产仍须登记。

### 5. 协议外壳与遗嘱形式

双方签字的“协议”若不符合遗嘱形式，可能两头不靠。不存在“按赠与合同补正”。

### 6. 撤回走第 1142 条，不走第 658 条

赠与公证不得锁死死因处分。数份抵触以最后的遗嘱为准。

### 7. 六十日接受、执行人与登记原因

知道受遗赠后六十日内书面接受，否则视为放弃。登记原因是继承/受遗赠，不是赠与。

### 8. 必留份、债务与扶养协议优先

为双缺继承人留必要份额。执行遗赠不得妨碍清偿税款和债务。与遗赠扶养协议抵触则协议优先。

### 9. 禁止套用赠与章

删除赠与人/受赠人、违约金、任意撤销权、第 660 条请求交付、第 666 条穷困抗辩。

### 10. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、签字即过户、先过户躲债、用赠与公证保证不可撤回。
- `字段停止`：法域、动态规则、形式要件未核验、必留份是否成就、税负精确额。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
