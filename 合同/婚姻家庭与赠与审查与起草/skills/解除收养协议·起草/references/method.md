# 审查方法（锁定 婚姻家庭 / 解除收养协议）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止打开或复制 `收养协议·审查` method。禁止套用成立收养的被收养人条件、收养人无子女/年龄差、送养人资格、收养评估、查找生父母公告主线。禁止套用离婚财产分割、抚养权变更或监护指定主线。禁止把本技能写成成立收养换“解除”。

定性校验：核心给付是协议终止**已经依法成立**的拟制父母子女关系，才继续；明显他类则负触发，不填十节实体结论。

本文件是可执行判断节点，不是栏目说明书。每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然办成登记、签字即身份消灭、对方必然接受或唯一必得补偿额。

`search_law` 返回已失效《收养法》、1992 年《中国公民办理收养登记的若干规定》、已失效《合同法》或其解释时记为噪声，不得写入 `L#`。`search_practiced` 仍写“公证即可解除”“签字即生效”“第一千一百一十七条是登记条文”“收养法仍现行”的，同样记噪声。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

示范文本只参考结构。写“本协议自签字之日起解除收养关系”“养父母有权随时要求补偿全部生活费和教育费”“双方从此再无任何经济义务”的范本，与登记要求和第一千一百一十八条冲突，不得当规则。

知识库口径冲突以本方法为准，不回写知识正文：

- `基本面.md` 把“登记生效”挂在第一千一百一十七条：纠正为第一千一百一十六条只写协议解除应当到民政部门办理解除登记；第一千一百一十七条是解除后的身份后果，不是登记条文。身份关系不因签字而终止。
- `基本面.md` 写解除登记后民政“通知公安机关办理户籍变更”：本次核验《中国公民收养子女登记办法》（2023 修订）第十一条仅规定收回收养登记证、发给解除收养关系证明；第九条是**成立**收养后由收养人持证到户口登记机关办理。解除后的迁户写成当事人持解除证明自行配合办理，不得写成民政必然通知公安。
- `框架.md` 写“除协议约定补偿外双方未来不再负有抚养、赡养、继承”：纠正为继承与法定抚养赡养随身份消除而消灭，但第一千一百一十八条的生活费、抚养费补偿是解除后的独立请求权，具备法定条件时不得用“再无义务”抹掉。
- `框架.md` 把“本协议自双方前往民政部门办理解除收养登记之日起生效”当作整份协议唯一生效点：纠正为**身份关系**自办理解除登记之日起终止；补偿、迁户、财产移交可以与身份解除分列，但不得早于或脱离登记去宣布身份已断。
- 实务把公证写成登记替代：纠正为公证不是协议解除的法定形式要件，不能替代县级民政解除登记。
- 不得把成立收养的评估、公告、无子女限制当作本类型放行条件。

开发窗口 2026-08-18 已核验、可供对照但不得代替运行时核验的规则：

- 民法典第一千一百一十四条：收养人在被收养人成年以前不得解除收养关系，但是收养人、送养人双方协议解除的除外。养子女八周岁以上的，应当征得本人同意。收养人不履行抚养义务，有虐待、遗弃等侵害未成年养子女合法权益行为的，送养人有权要求解除。不能达成协议的，可以向人民法院提起诉讼。
- 民法典第一千一百一十五条：养父母与成年养子女关系恶化、无法共同生活的，可以协议解除。不能达成协议的，可以向人民法院提起诉讼。
- 民法典第一千一百一十六条：当事人协议解除收养关系的，应当到民政部门办理解除收养关系登记。
- 民法典第一千一百一十七条：解除后，养子女与养父母以及其他近亲属间的权利义务关系即行消除，与生父母以及其他近亲属间的权利义务关系自行恢复。但是，成年养子女与生父母以及其他近亲属间的权利义务关系是否恢复，可以协商确定。
- 民法典第一千一百一十八条：经养父母抚养的成年养子女，对缺乏劳动能力又缺乏生活来源的养父母，应当给付生活费。因养子女成年后虐待、遗弃养父母而解除的，养父母可以要求养子女补偿收养期间支出的抚养费。生父母要求解除的，养父母可以要求生父母适当补偿收养期间支出的抚养费；因养父母虐待、遗弃养子女而解除的除外。
- 民法典第一千零四十四条：收养应当遵循最有利于被收养人的原则；禁止借收养名义买卖未成年人。
- 民法典第十九条：八周岁以上未成年人为限制民事行为能力人。
- 民法典第三十五条：监护人应当按照最有利于被监护人的原则履行监护职责；与未成年人利益有关的决定应尊重其真实意愿。
- 民法典第一千二百六十条：《收养法》自 2021-01-01 废止。
- 《中国公民收养子女登记办法》（2023 修订）第二条：中国公民在中国境内协议解除收养关系应当依本办法登记；登记机关是县级人民政府民政部门。
- 同办法第十条：持户口簿、居民身份证、收养登记证和书面协议，共同到被收养人常住户口所在地的收养登记机关办理解除登记。
- 同办法第十一条：自次日起三十日内审查；符合民法典规定的，办理解除登记，收回收养登记证，发给解除收养关系证明。
- 同办法第三条：收养登记工作遵循最有利于被收养人的原则。
- 未成年人保护法（2024 修正）第四条：处理涉及未成年人事项坚持最有利于未成年人原则，并听取未成年人意见。
- 同法第五十四条：禁止非法收养未成年人。

本次检索未把“民政办理解除后必然通知公安机关迁户”写入可核验条文。迁户只作双方配合义务，条号运行时重核，不得凭记忆写成民政职责。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用核心给付定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须同时满足才正触发：

1. 当事人之间已经存在拟终止的收养关系（通常以《收养登记证》为表面证据）。
2. 本文件的主给付是协议终止该拟制父母子女关系，并可附带登记配合、监护回归、姓氏户口与补偿。

本技能已锁定 **婚姻家庭 / 解除收养协议**。只打开 `references/基本面.md` 与 `框架.md`。禁止读其他类型目录，禁止为对照再开第二类。禁止打开 `收养协议·审查` method。

### 1.3 违法结构停笔

加载后或定性中出现：借解除或收养名义买卖未成年人；以解除转移财产规避执行或逃避赡养；胁迫、欺诈八周岁以上未成年人或对方签字；伪造、变造收养登记证；指导倒签登记日或补假同意。

1. 交付告知：该结构可能违反强制性规定或刑事规范，不得改写成可履行、可办证的文本。
2. 不写假登记证路径、假同意栏、假监护接收人。
3. 风险表只保留识别依据和转出/改道提示。
4. 用户坚持“改到能签、保证民政一定办、保证身份当天断”：整体停止。

## 节点 2　主体分轨与原收养登记闭环

先按被收养人是否成年分轨，再建主体表。年龄未给出：该分轨字段停止，不猜测。

### 2.1 未成年被收养人

签约主体是**收养人与送养人**。夫妻共同收养的，收养人一侧须双方亲签；只签一方：字段停止。已满八周岁的被收养人在意见栏签署本人同意，**不是**协议当事人，不得设违约金、补偿给付或迁户义务由其承担。

社会福利机构作为送养人的，须有机构法定代表人身份与授权痕迹；口头“院长同意了”不得写成已授权。

### 2.2 成年被收养人

签约主体是**收养人与成年被收养人**。送养人不是必要主体；正文把生父母列为必须签字否则不生效：必须改或标冲突。收养人夫妻是否双方都要签，回链原登记记载的收养人；原证是夫妻共同收养而只签一方：字段停止。

### 2.3 原登记

必须摘录：原《收养登记证》编号、登记机关、登记日期、被收养人常住户口所在地。材料未出示原件或复印件、证号空白、主体与证面不一致：原登记字段停止，不得写成“可以去民政解除”。

无登记证、只有过继单、族谱、村委会证明或长期共同生活：告知协议解除登记以持有收养登记证为前提（办法第十条）。不写“先补办收养登记再办理解除”的可履行双步路径。用户坚持按本协议去民政办：整体停止该结论，点名诉讼确认或解除。

不足：字段停止，列出待补材料，不补主体、不补证号、不补已同意。

## 节点 3　协议解除条件（硬闸）

核验后可引用的判断点（须 `search_law` 写入 `L#` 再落法律结论）：

- 未成年：原则上不得解除，双方协议除外；八周岁以上须本人同意；不能达成协议则诉讼。
- 成年：关系恶化、无法共同生活才协议解除；不能达成协议则诉讼。

| 文本写法 | 本任务动作 |
| --- | --- |
| 未成年文本只有收养人与被收养人签字，送养人未参与 | 红线。补送养人为协议主体，或转诉讼 |
| “收养人单方决定解除，送养人必须配合登记” | 红线。协议解除必须双方合意 |
| 送养人因虐待要求解除，收养人明确拒绝，用户仍要本协议“改到能逼对方去登记” | 目标停止。告知第一千一百一十四条诉讼路径，不写可履行强迫登记句 |
| 成年文本只写“性格不合”，读不出无法共同生活 | 必须改。补关系恶化、无法共同生活的事实陈述，或标依据不足 |
| 成年文本把“养子女不给钱就要解除”写成唯一条件，且双方其实同意 | 可留本技能，但条件句改成双方协议 + 恶化/无法共同生活；金钱争议单独写补偿，不代替法定条件 |
| 一方聊天明确“我不同意解除”，正文仍写双方自愿 | 并列冲突；不选有利版；不具备协议解除条件则转出 |

反方常见抗辩：有书面协议就可以去民政强办。本任务不得把该抗辩写成可放行结构。登记机关审查的是是否符合民法典，不是只看有没有签字页。

## 节点 4　未成年利益、八周岁意愿与监护回归（硬闸）

最有利于被收养人约束的是解除决定本身，不是事后一句“双方自愿”。父母方便、再婚、补偿高低、逃避抚养不得压过未成年人的生活、就学、照料与安全。

| 文本写法 | 本任务动作 |
| --- | --- |
| 已满八周岁，只有父母转述“孩子也答应了” | 必须改。要求独立、不受在场成年人胁迫的意见栏亲签；不得写成已同意 |
| 把未成年被收养人列为丙方，约定其支付补偿、承担违约金或必须在某日自行迁户 | 红线删除义务。意见栏只保留同意解除的意思 |
| 解除后不写谁接收、住哪里、上哪所学校、医疗谁决定 | 必须改。写接收人、交接时点、居住就学与证件移交 |
| 生父母死亡、失联或明显不能接收，正文写“监护自然回归生父母” | 红线或字段停止。不得假装监护已经落地；升级家事专项 |
| “谁给的补偿多谁带走孩子” | 红线。解除不是买卖未成年人 |
| 未满八周岁被要求在意见栏承担“同意并保证不再来往” | 删除保证。未满八周岁不是法定必须同意的主体；仍须审查最有利于其利益 |

不得把未成年人写成合同义务人。尊重意愿不等于把孩子当成违约债务人。

生存级：解除后未成年无处可去或接收人有虐待风险，用户拒绝升级：停止“可以签署”建议。

## 节点 5　登记程序（硬闸）

协议解除的法定形式是到民政部门办理解除收养关系登记。合同效力可以分列，但**身份关系**不因签字、公证、村居见证或律师见证而终止。

| 文本写法 | 本任务动作 |
| --- | --- |
| “本协议签字之日起收养关系解除/中止” | 红线。改为：身份关系自县级民政办理解除登记之日起终止；本协议中的登记配合义务自签署之日起约束双方 |
| “经公证后即发生解除效力，无需再办登记” | 红线。公证不得替代登记 |
| 未写共同到哪个机关、持哪些材料 | 必须改。写明被收养人常住户口所在地的县级民政；材料为户口簿、身份证、收养登记证和本协议 |
| “甲方可持本协议单独申请登记，乙方不到场视为同意” | 红线。办法第十条要求共同到场 |
| 把登记管辖写成原收养登记机关，与被收养人现户口地冲突 | 标 `C#`。现行办法写的是被收养人常住户口所在地；未核验不得保证原机关仍有管辖权 |
| “登记机关必须在三日内办完，逾期视为已解除” | 红线删除拟制解除。办法是自次日起三十日内审查；符合规定才登记 |
| 用户要求把签署日或登记日倒签成上周已解除 | 整体停止 |

不得把第一千一百一十七条当作登记依据。第一千一百一十六条才是协议解除应当登记的条文。

批准、登记、发证写成双方义务期限或身份生效条件，不写成已经完成。材料未提及不得写成“窗口一定收件、一定发证”。

## 节点 6　身份后果与补偿分轨

### 6.1 身份用语

使用“消除”，禁止“中止”“暂停”“冻结”。未成年被收养人与生父母及其他近亲属的权利义务自行恢复，协议不得写成“须生父母另行同意才恢复”。成年养子女与生父母是否恢复必须单独协商条款；未协商不得写死“自动恢复”或“永远不得恢复”。

### 6.2 补偿三轨

先定性请求权基础，再写金额。无基础不得编造。

| 基础 | 权利人 | 义务人 | 本任务动作 |
| --- | --- | --- | --- |
| 养父母缺乏劳动能力又缺乏生活来源，且养子女由其抚养成年 | 养父母 | 成年养子女 | 应当约定生活费。一次性或分期均可；可谈担保或居住权，但不保证结果。删除“再无任何经济义务” |
| 因成年养子女虐待、遗弃而解除 | 养父母 | 成年养子女 | 可约定补偿收养期间抚养费。须有可回链事实；无事实不得写成当然成立 |
| 生父母要求解除 | 养父母 | 生父母 | 可约定适当补偿抚养费。因养父母虐待、遗弃养子女而解除的：删除该补偿 |
| 双方自愿补偿但无法定基础 | 约定权利人 | 约定义务人 | 可保留为普通债权，须写清性质不是法定抚养费，并与身份解除分列 |

补偿额度畸高或带惩罚性：标必须改或可优化，提示诉讼中可能调减，不输出“一定能全额执行”。正说必须有反说：付款期限、账户、逾期违约金；收养人拒不交证或不配合迁户的对等后果。

共同财产须列清单。不得把解除设计成把未成年名下财产或逃避执行财产转到一方。出现逃债信号：停笔告知，债权人可主张撤销财产处分部分。

### 6.3 姓氏与户口

姓氏是否恢复或另改，写成配合义务，不写成签字即已改姓。户口迁移写成取得《解除收养关系证明》后【待填】日内双方配合到户口登记机关办理。不得写成民政已经通知公安，也不得写成未登记也可先迁户。

## 节点 7　违法结构、对外效力与争议

1. 私下协议通常只约束签署方的配合义务。现有依据不支持写成“签字当日对外已经解除、继承已经切断、户籍已经变更”。
2. 一方不履行登记配合：可约定违约金和可起诉履行配合义务，但不得约定“视为已经解除”。
3. 争议解决：身份关系解除本身不得改成可仲裁事项充作已选定路径。或裁或诉、机构不明：标待核。不选定唯一法院充作法律意见。
4. 华侨、港澳台居民参与的境内解除：管辖与材料可能适用专项规定，字段停止，运行时核验，不按外国人办法整案处理，也不按普通内地材料清单保证能收件。

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

打开已加载的 `框架.md`，按下列六步逐段对照正文。`基本面.md` 用于校验类型、主体、标的、程序、结构和红旗，不代替本节点出句。框架与本方法冲突时，以本方法为准出句。

| 交易条款 | 身份自解除登记之日起消除；未成年自行恢复、成年协商恢复；生活费/抚养费分轨；监护回归；姓氏户口配合 | 闭环修改句；缺证号、金额、日期用 `【待填】` |

| 尾部 | 收养人夫妻、送养人或成年被收养人亲签；八周岁以上意见栏；签署日真实；附件含登记证复印件 | 生效与附件修改句 |
| 语言 | 消除/中止；恢复/须再同意；生活费/抚养费/赡养费；登记/公证/签字 | 替换歧义句 |
| 常见问题 | 不登记当已解除、补偿畸高、忽略八周岁意愿、无监护回归、用成立收养条文审解除 | 结构级改法或红线 |

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

- `必须改`：可谈但签署前要落句；

用户不可接受事项优先写成红线。未成年解除后无合法接收监护且用户拒绝升级：停止“可以签署”建议。
