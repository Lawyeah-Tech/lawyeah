# 解除收养协议·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行解除条件、登记程序、身份后果和补偿请求权；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《收养法》及其配套旧登记规定、《合同法》及其解释当作现行规则。不得把民法典第一千一百一十七条写成登记条文。不得把公证写成可以替代民政解除登记。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、登记窗口或补偿请求权字段保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **婚姻家庭 / 解除收养协议**，输出可编辑草稿、未决项，并在出稿后用本类型硬闸自审。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「审查解除收养协议（婚姻家庭）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查、从零起草、履约交底、争议文书、有效性或必然办成登记的保证、把成立收养要件改完、把监护资格私下转让、把一方不同意改成可单方强制解除、把涉外收养整案改完。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿；尚未签署，尚未成争；核心给付是**协议终止已成立的收养关系**，不是设立收养、不是离婚后改直接抚养、不是遗赠换扶养。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主文件是拟向民政**成立**收养，审查被收养人/收养人/送养人条件、评估或公告 → `收养协议·审查`；禁止打开其 method，禁止用本技能改成立要件；
- 主轴是父母之间变更直接抚养、抚养费或探望，收养关系不拟终止 → `抚养权变更协议·审查` 或 `扶养抚养协议·审查`；
- 主轴是私下指定、转移或放弃监护，不终止收养 → `监护权协议·审查`；专业版未收录时输出 `unavailable`，不得改成可履行监护转让；
- 成年人意定监护 → `意定监护协议·审查`；
- 遗赠换生养死葬 → `遗赠扶养协议·审查`；
- 遗嘱处分财产 → `遗嘱·审查`；
- 继父母与继子女关系退出、无合法收养登记 → 不按本类型放行；点名家事专项，不套解除收养登记；
- 家庭寄养、临时照料或福利机构委托抚养，无收养登记 → 不按本类型放行；
- 外国人、一方为外国人，或适用《外国人在中华人民共和国收养子女登记办法》 → 负触发引擎或涉外路径；本技能不写省级民政涉外解除整案；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问登记预约、交证、户口迁移节点 → 本套导航的履约步骤；
- 已成争（一方拒绝登记、起诉解除、确认无效、人身安全保护令、执行）→ 家事或争议专项，不写起诉状。

借收养或解除收养名义买卖未成年人、以解除逃避赡养或执行、胁迫八周岁以上未成年人签字、伪造收养登记证、倒签登记日：只出告知，不改写成可履行结构。用户坚持：整体停止。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成。每一闸必须给出修改句或明确转出口径，禁止只打红黄绿。禁止把本技能写成 `收养协议·审查` 换“解除”。

1. **协议解除条件分轨**。未成年被收养人：收养人在其成年以前原则上不得解除，只有**收养人与送养人双方协议**才走本技能；已满八周岁必须本人同意。送养人因收养人虐待、遗弃或不履行抚养义务要求解除，但收养人不同意的，不得改成可单方强制的协议，转诉讼。成年被收养人：主体是收养人与成年被收养人，无需送养人；须能读出**关系恶化、无法共同生活**，不能达协议同样转诉讼。缺条件或一方不同意：不填“可以签字解除”的十节放行结论。
2. **登记**。当事人协议解除，应当到县级人民政府民政部门办理解除收养关系登记。身份关系不因签字、公证或村居见证而终止。修改句必须写：共同持户口簿、居民身份证、收养登记证和本协议，到**被收养人常住户口所在地**收养登记机关申请；机关自次日起三十日内审查，符合民法典规定的收回《收养登记证》、发给《解除收养关系证明》。不得写成“签字即解除”“公证即可代替登记”“未登记也已消灭继承和赡养”。不得把登记条文写成第一千一百一十七条。
3. **未成年利益**。解除必须回链最有利于被收养人，而不是收养人方便、补偿对价或再婚安排。已满八周岁的同意必须独立、不受在场成年人胁迫；口头转述不得写成已同意。未成年人不得成为补偿、违约金或迁户的合同义务人。解除后必须写清监护回归：未成年情形下与生父母权利义务自行恢复的，写接收人、交接时点、居住就学与安全；生父母死亡、下落不明或明显不能接收的，不得假装监护已经落地，字段停止或升级。禁止借解除买卖未成年人。

附加必落句（有事实则单列，无事实在缺口节说明）：

- **与成立收养切开**：禁止输出无子女、年龄差、收养评估、查找生父母公告、被收养人条件等成立要件主路径。禁止打开 `收养协议·审查` method。
- **身份后果分轨**：解除后养子女与养父母及其他近亲属权利义务即行**消除**，不得写“中止”。未成年被收养人与生父母及其他近亲属权利义务**自行恢复**；成年养子女是否恢复须协商确定，未协商不得写成已经恢复或已经不恢复。
- **补偿分轨**：生活费 ≠ 抚养费。经养父母抚养的成年养子女，对缺乏劳动能力又缺乏生活来源的养父母，应当给付生活费，不得用“再无任何经济义务”抹掉。因成年养子女虐待、遗弃而解除的，养父母可要求补偿收养期间抚养费。生父母要求解除的，养父母可要求生父母适当补偿抚养费，但因养父母虐待、遗弃养子女而解除的除外。无对应事实不得编造请求权。
- **原收养登记必须锁定**：写明原《收养登记证》编号、登记机关、登记日期。无证、证号与主体对不上、或只有“事实收养/过继单”：协议解除登记字段停止，不写“先补办收养再解除”的可履行路径。

必须有修改句。每个风险回链文本位置。

## 建立审查坐标

确认：使用者与授权；单方立场（收养人、送养人、成年被收养人，择一；夫妻共同收养须标清是否双方都签）；相对方；全文及附件版本；被收养人出生日期与是否已满八周岁/是否成年；原收养登记证编号与机关；拟解除理由；是否有八周岁以上本人意见痕迹；监护回归接收人；补偿请求权基础（生活困难 / 虐待遗弃 / 生父母要求解除）；不可接受事项；法域、被收养人常住户口所在地与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law`（法律结论 required）：核验民法典第一千一百一十四条至第一千一百一十八条、第一千零四十四条、第十九条、第三十五条、第一千二百六十条；《中国公民收养子女登记办法》（2023 修订）第二条、第十条、第十一条；未成年人保护法第四条、第五十四条。补偿请求权、登记管辖、八周岁同意无核验引文则对应字段停止。
- `search_practiced`（optional）：补未登记不消灭身份、八周岁意愿被忽略、补偿举证等争点。返回“公证即可解除”“签字即生效”“收养法仍现行”“第一千一百一十七条是登记条文”时记噪声。
- `search_template`（optional）：只借栏目。范本写“自签字之日起解除收养关系”“养父母可随时要求补偿全部生活费和教育费”不得当规则。

不虚构案件系统。`search_law` 返回已失效《收养法》《合同法》或 1992 年《中国公民办理收养登记的若干规定》时记为噪声，不得写入 `L#`。


## 起草模式

本原子只承担本类型起草。待签评改转 `解除收养协议·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。缺数字用 `【待填】`，不编造。出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 协议解除条件分轨：未成年被收养人须收养人与送养人双方协议，已满八周岁必须本人同意；成年被收养人主体是收养人与成年被收养人，须能读出关系恶化、无法共同生活。
- 共同持户口簿、居民身份证、收养登记证和本协议，到被收养人常住户口所在地收养登记机关申请；机关自次日起三十日内审查，符合规定收回《收养登记证》、发给《解除收养关系证明》。
- 解除必须回链最有利于被收养人。解除后必须写清监护回归：未成年情形下与生父母权利义务自行恢复的，写接收人、交接时点、居住就学与安全。
- 身份后果分轨：解除后养子女与养父母及其他近亲属权利义务即行消除；未成年被收养人与生父母及其他近亲属权利义务自行恢复；成年养子女是否恢复须协商确定。
- 补偿分轨：生活费 ≠ 抚养费。经养父母抚养的成年养子女，对缺乏劳动能力又缺乏生活来源的养父母，应当给付生活费。无对应事实不得编造请求权。
- 写明原《收养登记证》编号、登记机关、登记日期。

### 附件必附

- 原《收养登记证》。
- 户口簿、居民身份证。
- 已满八周岁本人同意痕迹。
- 监护回归接收人说明（未成年情形）。

### 禁止出现

- “签字即解除”“公证即可代替登记”“未登记也已消灭继承和赡养”。
- 把登记条文写成第一千一百一十七条。
- 未成年人成为补偿、违约金或迁户的合同义务人；借解除买卖未成年人。
- 用“中止”代替“消除”。
- “再无任何经济义务”抹掉成年养子女对缺乏劳动能力又缺乏生活来源养父母的生活费。
- 输出成立收养要件主路径；一方不同意时改成可单方强制的协议。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口，不代替节点。

0. 签署状态与成果分流
1. 类型识别与单目录加载（解除已成立收养；切开成立收养、抚养变更、监护、遗赠扶养、继父母、寄养、涉外）
2. 主体分轨与原收养登记闭环
3. 协议解除条件（未成年双方协议 / 成年关系恶化）
4. 未成年利益、八周岁意愿与监护回归
5. 登记程序：共同申请、管辖、三十日审查、交证发证
6. 身份后果与补偿分轨
7. 违法结构停笔
8. 按框架六步出修改句

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造登记证或倒签登记日、胁迫未成年人签字、借解除买卖未成年人、把一方不同意改成可强制解除、保证签字即身份消灭或保证民政必然登记、把无证事实收养改成可履行补办再解除。
- `字段停止`：法域、被收养人是否成年/已满八周岁、原收养登记真实性、登记管辖地、监护回归接收能力、生活费/抚养费请求权基础未核验。
- `目标停止`：主目标已变为从零起草、履约交底、起诉解除、成立收养整案、监护指定诉讼或涉外收养。

未成年被收养人解除后无合法接收监护人，且用户拒绝升级：停止“可以签署”建议。
