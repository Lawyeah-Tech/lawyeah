知识库口径冲突以本方法为准，不回写知识正文：

- `框架.md` 把共有写成“须全体共有人同意否则设立可能无效”：纠正为共同共有原则上须全体同意；按份共有原则上经占份额三分之二以上同意，另有约定除外。未达同意门槛的，物权不设立；合同效力另论，不得一律写成整约无效。
- 把未登记写成合同未生效：纠正为设立居住权的合同原则上成立即生效；未办理居住权登记不影响合同效力，但居住权尚未设立。
- 把“纸上权利”写成毫无约束：纠正为未登记仍可能有债权请求权，但不得写成用益物权或可对抗第三人。
- 旧案以离婚协议未登记仍保护居住：那是签前新文本不得援引的时间效力例外，不能用来放行“可不登记”。

## 节点 2　主体、住宅、共有人与在先负担

1. 建主体表：设立人（所有权人）、居住权人、共有人、配偶、在先抵押权人、现承租人。名称不一致不自动合并。角色不得写成出租人/承租人或赠与人/受赠人，除非正在做负触发。
2. 权属：设立人须对住宅有所有权。材料未出示产证或与坐落、证号不一致：该处分能力字段停止，不得写成“可以登记”。
3. 标的必须是住宅。商办、工业、车位、仓库：红线，告知无法设立法定居住权，不写可履行登记路径。
4. 空间：整套还是特定房间。部分房间必须附平面图或房间标识。未特定化：必须改。
5. 共有与配偶：夫妻共同财产或其他共同共有，须有共有人本人书面同意并签字。按份共有，核验是否达到三分之二以上份额或另有约定。口头“配偶同意了”、合同打印共有人栏但未签：不得写成已同意。代签、伪造：整体停止。
6. 在先负担：已抵押的，居住权不能当然对抗在先抵押权；抵押权实现可能导致居住权落空。已查封或权属争议：红线，告知可能不予登记。已出租：提示占有冲突，不得写成无负担。材料未提及不得写成“无抵押、查封、租赁或在先居住权”。
7. 预告登记：未经预告登记权利人同意设立居住权，不发生物权效力。未核预告登记：字段停止。

不足：字段停止，列出待补材料，不补主体、不补权属、不补已同意。

## 节点 3　登记设立与合同效力分离（硬闸）

居住权自登记时设立。合同成立生效与物权设立是两个事实。未办理居住权登记，不影响合同作为债权协议的效力，也不等于已经享有用益物权，更不能对抗买受人、后手抵押权人或排除强制执行。

核验后可引用的判断点（须 `search_law` 写入 `L#` 再落法律结论）：

- 设立居住权应当采用书面形式。
- 应当向登记机构申请居住权登记；居住权自登记时设立。
- 未办理物权登记，不影响合同效力。

| 文本写法 | 本任务动作 |
| --- | --- |
| “本合同签字之日起居住权设立/生效即享有物权” | 红线或必须改。拆成：合同成立生效；居住权自登记时设立 |
| “双方签字即视为已登记、可对抗任何第三人” | 红线。禁止拟制公示 |
| 未写谁在几日内共同申请登记、未完成的后果 | 必须改。补义务主体、期限、材料、逾期违约金或解除 |
| 仅有协议，明确不办登记 | 可以留本技能，但物权设立结论字段停止；修改句写明仅普通债权，不能对抗买受人 |
| 房屋已被查封或存在权属争议 | 红线。告知可能不予登记，结构失败，不写可履行办证 |
| 用户要求把日期写成已经登记或补假回单 | 整体停止 |
| “未登记本合同未生效” | 必须改。删除该句，改回第 215 条结构 |

批准、登记写成生效条件或双方义务期限，不写成已经完成。修改句建议写明：本合同即为办理居住权登记所需法律文书。

登记完成前必须限制设立人处分：不得抵押、出售或为第三人再设居住权；违反则赔偿，并不得把未完成的物权写成已经对抗。已登记后，修改句可写所有权转移不影响居住权行使；未登记不得写这句话已有物权效力。

## 节点 4　期限与无偿／有偿显名（硬闸）

1. 期限必须约定为“至居住权人死亡时止（终身）”或“至【待填】年【待填】月【待填】日止”。第 367 条将居住权期限列为合同一般条款。缺期限：必须改，不编造年限。
2. 禁止把民法典第 705 条“租赁期限不得超过二十年”写进本约。终身居住或超过二十年的固定期限，在居住权路径下不是当然无效。
3. 居住权原则上无偿设立。文本未写对价：修改句显名“无偿设立”，不要改成租金。
4. 若有对价：必须显名“有偿设立”，写清金额、支付节点、逾期是否构成解除并配合注销。用“租金、押金、租期、续租”表述对价：先判断核心给付。对价是使用费且无物权登记意思 → 负触发租赁。确有设立居住权意思 → 必须改掉租赁用语，不得保留押金罚则或二十年续租。
5. 有偿不改变登记设立、不得转让继承。不得把有偿写成买卖或赠与过户。
6. 期限届满或居住权人死亡：居住权消灭，应及时注销登记。修改句补消灭事由和配合注销义务。

反方常见抗辩：有偿就是租赁；无偿就是赠与，过户前可反悔。本任务不得把该抗辩写成可放行结构。有偿居住权仍是用益物权；无偿居住权不是把房屋赠与对方。

## 节点 5　不得转让继承、出租须显名、使用限制

1. 居住权不得转让、不得继承。原文“可随房屋过户给子女”“作为遗产由继承人继续居住”“居住权人可转让给第三人”：红线。删除，改为不得转让、不得继承；居住权人死亡则消灭并注销。
2. 未经另有约定，设立居住权的住宅不得出租。要保留出租权，必须显名写清：是否可出租、谁收取租金、是否须设立人书面同意。只写“依法使用”“自行管理”视为未约定出租，按禁止处理。
3. 使用限于生活居住。改商业、破坏结构、改变规划用途：设立人可解除并请求注销。正说必须有反说。
4. 共同居住人：可约定居住权人的配偶、需要扶养的近亲属可同住；未约定不得写成已允许任意带人入住。
5. 居住权人不享有法定优先购买权。出售时的告知义务可谈，但不得把未约定的优先购买写成法定权利。

## 节点 6　消灭、注销与登记完成前处分限制

1. 消灭事由至少覆盖：期限届满、居住权人死亡、房屋灭失、居住权人书面放弃。不得把“设立人单方通知即可收回”写成已登记居住权的任意撤销——那是赠与路径，禁止套用。
2. 注销：权利消灭后，居住权人或其继承人应在【待填】日内配合注销登记；逾期按【待填】付违约金。
3. 登记完成前的处分限制见节点 3。已登记后，设立人仍可转让所有权，但不得损害居住权；修改句写清买受人继受负担。
4. 在先抵押实现：提示拍卖可能导致居住权被涤除或无法对抗抵押权人。不得保证“先抵押后设居住权仍能住到终身”。
5. 遗嘱设立只作参照提示。用户送来的是遗嘱不是合同：负触发 `遗嘱·审查`。

## 节点 7　费用、违约与配合办证

1. 费用默认结构：居住权人承担物业费、水电气暖、日常维修；设立人承担房屋大修和房产税（如有）。未写则必须改，不编造金额。
2. 设立人违约：不配合登记、阻挠入住、擅自抵押或出售致居住权受损。必须有可执行后果（按日违约金、赔偿、继续履行登记），不得只写“依法承担违约责任”。
3. 居住权人违约：改变用途、破坏结构、未经约定出租、连续【待填】日不实际居住。可约定解除并配合注销，不得写成设立人可随时收回已登记居住权。
4. 争议解决：不动产所在地可能涉及专属管辖，条号运行时核验，不选定唯一法院充作法律意见。或裁或诉、机构不明：标待核。
5. 不得把定金罚则、租金滞纳、赠与撤销期间塞进本类型。

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

打开已加载的 `框架.md`，按下列六步逐段对照正文。`基本面.md` 用于校验类型、主体、标的、程序、结构和红旗，不代替本节点出句。框架与本方法冲突时，以本方法为准出句。

| 步 | 动作 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题为居住权设立合同或居住权协议；主体为设立人/居住权人；鉴于写明设立背景和房屋权属、无查封声明 | 标题或鉴于修改句 |
| 交易条款 | 住宅特定化；占有、使用；期限终身或截止日；无偿或显名有偿；登记设立；不得转让继承；出租须显名 | 闭环修改句；缺证号、日期、金额用 `【待填】` |
| 配套 | 登记完成前处分限制；不配合办证的违约金；消灭与注销；费用分担；所有权转移不影响已登记居住权 | 可执行后果句 |
| 尾部 | 本人签、共有人签、产证与平面图附件；合同生效与登记设立分列；禁止倒签登记日 | 生效与附件修改句 |
| 语言 | 设立/享有；占有、使用；无偿设立/有偿设立；登记设立/合同生效；不得写成出租、赠与、过户 | 替换歧义句，尤其删除“签字即设立”“租金”“赠与过户” |
| 常见问题 | 未约定登记、共有人未签、期限缺失、用租赁或赠与条款伪装 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止；
- `必须改`：可谈但签署前要落句；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级唯一住房拟设终身居住权且设立人拒绝升级：停止“可以签署”建议。
