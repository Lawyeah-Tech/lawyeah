# 审查方法（锁定 婚姻家庭 / 遗嘱）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止打开或复制 `遗赠扶养协议·审查` 或任何赠与原子（`一般赠与合同·审查`、`附义务的赠与合同·审查`、`亲属间房屋赠与合同·审查`、`房产赠与合同·审查`、`生前类赠与协议·审查`）的审查路径。禁止复制遗赠扶养对价/生养死葬主路径、赠与任意撤销主路径、分家共有分割主路径或施工挂靠节点。

定性校验：标题、核心给付与本类型一致才继续；遗赠扶养、生前赠与、双边死后过户类赠与、分家析产或其他家事明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、法院必然认定、对方必然接受或唯一必得份额。

`search_law` 返回已失效《继承法》及其意见、《婚姻法》《物权法》《合同法》时记为噪声，不得写入 `L#`。

示范文本只参考结构。写“经过公证的遗嘱不得变更、数份以最后公证为准”的公证书栏目，只证明应切开失效口径，不得当作现行规则。

知识库纠正（不回写双文件）：

- `框架.md` 把代书与打印一并写成“遗嘱人、见证人应当在每一页签名”：仅打印遗嘱适用第 1136 条逐页签名。代书按第 1135 条：两名以上见证人在场，其中一人代书，遗嘱人、代书人和其他见证人签名并注明年月日。
- `框架.md` “越权处分处于抵押状态的房产”：有抵押、质押或查封不等于该部分遗嘱当然无效。继承人在遗产价值范围内承受负担。修改句写清负担随财产走，不写成处分无效。
- `基本面.md` / 实务材料称“公证遗嘱与其他形式冲突以公证为准”：与第 1142 条及时间效力规定第 23 条冲突。数份内容抵触以**最后的遗嘱**为准。
- 实务材料称“必留份最高不超过法定应继份二分之一”：法律只写“必要的遗产份额”。不得把该比例写成法定上限。
- 范本称“订立时具备完全民事行为能力即一劳永逸”：能力以立该份遗嘱时为准（解释（一）第 28 条）；立后丧失能力不影响该份，但新立须重新具备能力。

## 节点 0　签署状态与成果分流

先于类型识别。命中任一项则本任务不填十节实体结论，只交付分流理由和最小交接。

| 已能支持的事实 | 走向 | 不得写成 |
| --- | --- | --- |
| 无可读正文和附件，或只有口头“明天立一份” | `遗嘱·起草` | 已经完成审查；可以签 |
| 未完成有效设立，目标是评改已有遗嘱或拟公证草稿 | 进入节点 1 | 已签署或已生效 |
| 残缺模板，用户要按己方条件重写整稿 | 起草 | 本任务出整稿 |
| 已按该稿完成自书/代书/打印/公证设立，只问保管、变更预约、死亡后过户 | 本套导航的履约步骤 | 签前意见 |
| 已出现催告、立案、开庭、仲裁，或用户要确认遗嘱有效/无效诉状 | `已催告解除索赔诉讼或仲裁→` 或家事专项 | 继续当签前审查 |

缺立场或同时掌握互斥多方秘密：整体停止策略输出。缺书面文本仍要“给个能不能签”：不启动实体审查。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 自然人单方处分死后个人财产；遗嘱人仍在世；无对价、无生养死葬主给付 | 本类型 | 正触发 |
| 继承人以外的人承担生养死葬，死后取得财产 | 遗赠扶养协议 | 负触发 `遗赠扶养协议·审查`（P1 未装则 `unavailable`） |
| 权利拟在生前转移的无偿给予，受赠人现时承诺接受 | 生前赠与 | 负触发 `一般赠与合同·审查`、`附义务的赠与合同·审查`、`亲属间房屋赠与合同·审查` 或 `房产赠与合同·审查` |
| 双方在生前约定死后过户，互有签字承诺，但不是单方遗嘱 | 遗赠协议（类赠与） | 负触发 `生前类赠与协议·审查`（P1 未装则 `unavailable`） |
| 父母健在，分割家庭共有财产，折价补偿其他成员 | 分家析产 | 负触发 `分家析产协议·审查` |
| 双方解除婚姻并处理夫妻共同财产、子女抚养 | 离婚协议 | 负触发 `离婚协议·审查` |
| 仅夫妻二人约定婚内或婚前财产归属 | 夫妻财产约定 | 负触发 `夫妻财产约定·审查` |
| 只约定赡养费、照料，无死后处分主轴 | 赡养协议 | 负触发 `赡养协议·审查` |

支持切开的规范（法律结论须运行时复核）：

- 第 1133 条：自然人可立遗嘱处分个人财产、指定执行人、对法定继承人设立遗嘱继承、对国家/集体/法定继承人以外的人遗赠、设立遗嘱信托——本类型主干。
- 第 1123 条、解释（一）第 3 条：有遗赠扶养协议的按协议办理；协议与遗嘱抵触的，抵触部分按协议——转 `遗赠扶养协议·审查`。
- 第 657 条：把自己的财产无偿给予且对方表示接受——转赠与原子。
- 第 1121、1122 条：继承自死亡开始；遗产是死亡时遗留的个人合法财产——生前过户不是本类型。

### 1.3 与遗赠 / 生前赠与切开（硬闸）

| 文本写法 | 本任务动作 | 修改句方向 |
| --- | --- | --- |
| “我死后，下列个人财产由长子继承” | 正触发，留下本类型 | 首部写明单方遗嘱，不是赠与，也不是遗赠扶养 |
| 邻居承担生养死葬，甲方死后房屋归邻居，双方签字 | 负触发 `遗赠扶养协议·审查` | 不按遗嘱改完 |
| “现在把房屋赠与幼子，本协议签字后即办理过户” | 负触发赠与原子 | 不按遗嘱消灭任意撤销 |
| 甲乙双方约定“甲方去世后房屋过户给乙方，乙方签字接受”，无生养死葬 | 负触发 `生前类赠与协议·审查` | 不按单方遗嘱改完 |
| 遗嘱内把存款给保姆或某基金会，用了“由XX继承” | 留在本类型；必须改用语 | 改为“受遗赠”，并写知道后六十日内明示接受 |
| 真遗嘱，但条款使用“赠与人/受赠人/任意撤销” | 必须改：删除赠与术语 | 「本文件是遗嘱，不是赠与合同。任何一方不得依照赠与合同任意撤销本文件。」 |

最强反方：相对方主张名为遗嘱、实为遗赠扶养或生前赠与，应适用协议优先或任意撤销。修改句必须让文本自证“单方、死后生效、无对价”，不能靠标题自称。用户坚持把遗赠扶养或生前赠与主轴留在本技能放行：负触发，不填本类型十节实体结论。

### 1.4 伪造 / 规避限购 / 逃债停笔

加载后或定性中出现：要求补假见证人、代签或倒签；用遗嘱把限购房转到无购房资格人名下并写成可履行过户；承认立遗嘱是为把唯一责任财产在死后立刻转出以躲避已有执行。

动作：

1. 交付告知：伪造、篡改的遗嘱无效（第 1143 条）。遗赠不得妨碍清偿税款和债务（第 1162 条）。不得改写成可履行的伪造或逃债结构。
2. 不写假见证人名单、倒签步骤或“债权人不得主张”句。
3. 风险表只保留识别依据和删除/转出口径。
4. 用户坚持“改到能签且仍做这些事”：整体停止。

## 节点 2　形式要件与主体（硬闸）

### 2.1 先锁形式

未声明形式则先追问，不得默认“按自书处理”。电脑打印稿不得按自书审。

| 拟采用形式 | 必须看见 | 不得写成 |
| --- | --- | --- |
| 自书（第 1134 条） | 遗嘱人亲笔通篇书写；本人签名；年、月、日齐全 | 打印后签名即自书；印章或他人代签可代替亲笔签名 |
| 代书（第 1135 条） | 两名以上见证人在场；其中一人代书；遗嘱人、代书人和其他见证人签名；年月日 | 代书人一人既代书又充当唯一见证人；打印稿冒充代书却不按打印审 |
| 打印（第 1136 条） | 两名以上见证人在场；遗嘱人和见证人在**每一页**签名；年月日 | 只在末页签名；见证人未全程在场；漏写年份 |
| 录音录像（第 1137 条） | 两名以上见证人在场；记录姓名或肖像以及年月日 | 只有画面没有日期；见证人事后补镜 |
| 口头（第 1138 条） | 确属危急；两名以上见证人在场 | 非危急的“先口头说一声”；危急已消除仍用口头 |
| 公证（第 1139 条；运行时复核全文） | 由公证机构办理；遗嘱人亲自申请 | 律师见证写成已经公证；共同遗嘱未经分别引导 |

修改句（打印）：

「本稿定为打印遗嘱。立遗嘱人与见证人【待填】、【待填】须在每一页签名，并在每一页注明年、月、日。任何一页缺少立遗嘱人或任一见证人签名、日期的，该页不得作为本遗嘱内容。见证人须全程在场见证打印、宣读和签署，不得事后补签。」

修改句（自书）：

「本稿定为自书遗嘱。全文须由立遗嘱人【待填】亲笔书写，不得打印或由他人代书；末尾由立遗嘱人亲笔签名，并写明【待填】年【待填】月【待填】日。不得以印章、指纹或他人代签代替签名。」

口头遗嘱：危急情况不能支持，或用户承认危急已消除：红线改为自书、代书、打印、录音录像或公证，不把口头稿改成可放行文本。

### 2.2 见证人资格

支持依据：第 1140 条（运行时复核全文）；解释（一）第 24 条。

不得担任见证人：无民事行为能力人、限制民事行为能力人以及其他不具有见证能力的人；继承人、受遗赠人；与继承人、受遗赠人有利害关系的人（含其债权人、债务人、共同经营的合伙人，以及配偶、近亲属等）。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 见证人是长子配偶、受遗赠人子女、继承人的合伙人 | 红线更换见证人 | 亲属见证“实务上一般也认” |
| 只有一名见证人，或第二人未在场 | 形式字段停止 | 一人见证加录像即可代替第二人 |
| 见证人与继承人关系未核 | `G#`，资格字段停止 | 默认无利害关系 |

修改句：

「见证人须为与继承人、受遗赠人无利害关系的完全民事行为能力人。下列人员不得担任见证人：继承人、受遗赠人及其配偶、近亲属、债权人、债务人、共同经营的合伙人。现列见证人【待填】与【待填】存在【待填】关系，应在设立前更换为【待填】、【待填】。更换前不设立本遗嘱。」

### 2.3 遗嘱人能力与意思真实

支持依据：第 1143 条；解释（一）第 28 条。

建主体表：遗嘱人姓名与身份证件、立遗嘱时年龄与健康痕迹、继承人/受遗赠人姓名与关系、见证人、执行人。名称不一致不自动合并。

高龄、重病、认知障碍痕迹：能力字段停止，修改句要求同步录像、病历或专业评估，不补写成“神志清醒”。无/限制民事行为能力人所立遗嘱：现有依据不支持有效；立后恢复能力不使该份复活。

口头“家里都同意了”不得写成已授权。他人代签或按手印代替签名：形式红线。

## 节点 3　标的范围与权利负担

遗产是自然人死亡时遗留的个人合法财产（第 1122 条）。夫妻共同财产应先分出配偶一半，其余才是遗产（第 1153 条）。处分国家、集体或他人财产的部分无效（解释（一）第 26 条）。

| 文本写法 | 动作 |
| --- | --- |
| “名下房产全部由长子继承”，产证为夫妻共有或材料不能排除配偶份额 | 必须改：只处分属于本人的份额；配偶份额不纳入 |
| 清单只有“家里的房子、存款若干” | 必须改：落到证号、地址、账号后四位或【待填】 |
| 材料未提及抵押、查封、居住权 | 不得写成“无权利负担”，写 `依据不足` |
| 处分已抵押房产并写“抵押权消灭” | 红线删除消灭句。写清负担随财产在遗产价值范围内承受 |
| 把人身保险金列入遗产，受益人并非“法定”或“遗产” | 必须改：保险金原则上不列入，除非指定情形 |
| 处分股权/合伙份额，未核章程或合伙协议 | 资格继受字段停止；可写财产利益归属，不写“当然成为股东” |

修改句：

「本遗嘱只处分立遗嘱人死亡时遗留的个人合法财产。登记在【待填】与配偶【待填】名下的【地址/证号】房屋，先按夫妻共同财产处理：属于配偶的一半不在本遗嘱处分范围内；本遗嘱仅就属于立遗嘱人的份额，由【待填】继承。本条不处分他人财产。」

兜底句：

「除本遗嘱已列明的财产外，立遗嘱人死亡时名下的其他个人合法财产和财产性权益，由【待填】继承 / 受遗赠。本句不覆盖依法不得继承的财产，也不覆盖配偶、其他共有人的财产。」

身故后才产生的赔偿金、未发放奖金：可写意定分配倾向，但须标明“以届时是否属于遗产为准”，不得写成必然是遗产。

## 节点 4　必留份（硬闸）

支持依据：第 1141、1159 条；解释（一）第 25 条。

动作顺序：

1. 列出第一、第二顺序法定继承人（第 1127 条），标出谁可能在继承开始时缺乏劳动能力又没有生活来源。
2. 双缺事实不足：字段停止，修改句要求保留机动必要份额或授权执行人在遗产处理时依法预留。
3. 现有材料已能支持双缺（未成年且无独立收入、重度残疾无收入、高龄无养老金且无其他来源等）：文本仍零保留或“取消继承权”→ 红线。
4. 未保留时的法律效果：遗产处理时应当先留下必要遗产，剩余部分才参照遗嘱分配。不得写成整份遗嘱必然无效。
5. 双缺判断时点是**遗嘱生效时**该继承人的情况，不是立遗嘱当日。立遗嘱日“有工作”不得写成永久不必留。
6. 不得把“不超过应继份二分之一”写成法定上限。具体数额用 `【待填】` 或“维持当地基本生活所需”。

修改句：

「立遗嘱人为可能缺乏劳动能力又没有生活来源的继承人【待填】保留必要的遗产份额。该份额按本遗嘱生效时（继承开始时）【待填】的劳动能力与生活来源确定，不少于维持其基本生活所需的【待填】（存款人民币【待填】元 / 【地址】房屋的居住使用 / 其他【待填】）。其余财产再按本遗嘱其他条款分配。本条不得解释为取消【待填】的法定必留份。」

最强反方：被排除的子女主张自己双缺，要求抽回大部分遗产；拟取得全部财产的一方主张立遗嘱时对方“还能干活”。依据不足时不得帮任何一方写成“必留份不成立”或“整份无效”。

用户坚持对已能支持双缺的继承人不留必要份额：整体停止“可以签署”。

## 节点 5　撤回、数份与在先安排

支持依据：第 1142 条；时间效力规定第 23 条；第 1123 条；解释（一）第 3 条。

| 文本写法 | 动作 |
| --- | --- |
| 未写废止前嘱 | 必须改：声明此前遗嘱、处分与本遗嘱抵触的部分撤回 |
| “此后不得再立遗嘱 / 公证遗嘱不可撤回” | 红线删除。遗嘱人可随时撤回、变更 |
| “与公证遗嘱冲突时仍以旧公证为准” | 红线删除。内容抵触以最后的遗嘱为准 |
| 立遗嘱后又实施相反行为（如已把标的过户给他人） | 告知：相反行为视为对相关内容的撤回。本任务不认定已经撤回 |
| 已有遗赠扶养协议，本遗嘱处分同一标的 | 字段停止或整项移交 `遗赠扶养协议·审查`。抵触部分不得写成优先于协议 |

修改句：

「立遗嘱人撤回此前就本遗嘱所涉财产作出的全部遗嘱和相反处分。立有数份遗嘱且内容抵触的，以最后所立的遗嘱为准。本条不使立遗嘱人丧失日后依法撤回或变更的权利。如立遗嘱人生前已与他人订立遗赠扶养协议，与该协议抵触的部分依协议办理。」

不得把“双方同意视为已公证”写成可放行结构。用户要求倒签设立日以压过在先遗嘱：整体停止。

## 节点 6　继承 / 遗赠用语、执行人、附义务与信托

### 6.1 继承还是遗赠

支持依据：第 1133、1124、1127 条。

- 财产给配偶、子女、父母等法定继承人：用“继承”。未表示放弃的，视为接受。
- 财产给法定继承人以外的个人、组织、国家或集体：用“受遗赠”。须在知道受遗赠后六十日内明示接受或放弃；到期没有表示的，视为放弃。
- 首选继承人/受遗赠人先于遗嘱人死亡：该部分按法定继承，除非指定了候补。

修改句：

「【待填】（身份证号【待填】，与立遗嘱人关系：保姆 / 基金会 / 其他非法定继承人）就【待填】财产为受遗赠人，而非继承人。受遗赠人应当在知道受遗赠后六十日内作出接受或者放弃的表示；到期没有表示的，视为放弃受遗赠。为防首选受遗赠人先于立遗嘱人死亡或放弃，指定候补受遗赠人【待填】。」

### 6.2 执行人与遗产管理人

支持依据：第 1133、1145 条。

未指定执行人：必须改，指定一人或数人，或写明未指定时由继承人推选。执行人清理财产、通知继承人、协助过户，不写成可排除法院指定遗产管理人。

### 6.3 附义务

支持依据：解释（一）第 29 条；第 1144 条运行时复核全文。

义务须可识别。无正当理由不履行的，经请求法院可取消其接受附义务部分的权利。修改句写请求权人，不在本任务取消权利。

「【待填】继承 / 受遗赠【待填】财产，同时承担【待填】义务。无正当理由不履行的，受益人【待填】或其他继承人可请求人民法院取消其接受附义务部分遗产的权利。本条不是赠与撤销。」

### 6.4 遗嘱信托与居住权

信托：目的、财产、受托人、受益人、给付条件须可识别，并符合《信托法》书面与承诺要件。缺一项：字段停止，不写成信托已经设立。

居住权：遗嘱中可为特定人设立居住权；物权自登记时设立。修改句要求死亡后及时申请居住权登记，不得写成“遗嘱一生效即已对外对抗”。

### 6.5 格式与强制规范

律所或公证处重复使用的模板，对放弃必留份、排除见证人资格、最终解释权等异常条款仍审查是否足以引起遗嘱人注意。强制规范按第 153 条区分，不用失效口诀。部门规章或公证窗口要求不当然导致遗嘱无效。

## 节点 7　解释、争议与通知

1. “由遗嘱执行人最终解释且排除法院”：红线删除排除句。执行人解释仅作参照。
2. 出现仲裁条款：遗嘱效力、必留份、继承权确认常涉及身份与物权，不选定唯一仲裁并假装已排除法院。
3. 不动产继承可能涉及专属管辖：只标红旗，不选定唯一法院充作法律意见。
4. 通知送达：微信已读不写成已经到达，除非文本把该渠道写成送达且用户要保留。
5. 建议全程录像、律师见证或公证：可写进签署提醒，不得写成“录像后必然有效”或“公证后不得再撤回”。

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不设立或整体停止（形式未闭合、不适格见证人拒换、已能支持的双缺零保留、遗赠扶养/生前赠与主轴、倒签、补假见证、保证有效）；

用户不可接受事项优先写成红线。生存级住房被全部指定给他人且配偶或双缺继承人无处住：停止“可以设立”建议。
