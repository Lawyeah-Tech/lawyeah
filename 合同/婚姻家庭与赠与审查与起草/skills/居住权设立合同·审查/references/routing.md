# 边界与路由

本技能只审查 **婚姻家庭 / 居住权设立合同**。

必须读出：在他人住宅上为满足生活居住需要设立占有、使用的用益物权，且不转移房屋所有权。标题叫“居住权”但正文是租金换使用、或主给付是过户赠与的，不得留在本技能做实体结论。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或标题居住权、核心给付明显不是设立用益物权 | 本套导航的类型切开步骤 |
| 月/年租金、押金、租期、转租、优先承租；住房/房产/不动产租赁主文件 | `或` 或 `或`；不得硬套本技能改成无偿终身居住权 |
| 不定期或定期租赁外观，随时解除或二十年上限主导 | `不定期或定期租赁外观，随时解除或二十年上限主导` 或对应租赁原子 |
| 无偿转移房屋所有权、受赠人、任意撤销、赠与过户 | `房产赠与合同·审查`、`亲属间房屋赠与合同·审查`、`婚姻家庭中的赠与合同·审查` 或 `一般赠与合同·审查` |
| 主文件是离婚协议，居住只是财产分割附带一句 | `离婚协议·审查`；独立《居住权设立合同》且核心给付是设居住权则留本技能 |
| 以遗嘱设立居住权，无合同文本 | `遗嘱·审查`；专业版未收录时 `unavailable` |
| 遗赠或遗赠扶养，死后过户财产 | `生前类赠与协议·审查` 或 `遗赠扶养协议·审查` |
| 赡养、扶养主给付，住房只是履行方式 | `赡养协议·审查` 或 `扶养抚养协议·审查` |
| 分家析产或夫妻财产约定为主 | `分家析产协议·审查` 或 `夫妻财产约定·审查` |
| 真实房屋买卖，买受人取得所有权 | `真实房屋买卖，买受人取得所有权` 或 `或` |
| 无文本、本类型条件已谈妥、要出己方稿 | `居住权设立合同·起草` |
| 已签未争、问登记预约、入住、费用 | 本套导航的履约步骤 |
| 已成争 | 合同争议领域或对应专项；不写确认居住权诉状、排除执行申请 |
| 用户只要登记能否办成的终局保证 | 人工核对登记窗口；本技能只审条款 |
| C 端大众快检 | 只分流，不回改 |

同一文本既写“出租收租金”又写“设立居住权”：按核心给付切开。对价是租金、权利是债权使用 → 租赁原子。对价缺省无偿或显名有偿设立用益物权、拟办居住权登记 → 留本技能。两可且无法判断：负触发引擎，不灌两套知识。

同一文本既写“过户给子女”又写“自己留住”：所有权转移是主给付 → 赠与原子，可在交接里提示受赠人另签居住权合同；本技能不代做赠与审查。仅保留居住、所有权不转移 → 留本技能。

伪造登记、查封房包装、规避限购、把居住权改成可转让继承：停笔告知，不改写成可履行文本。

禁止在正文写半截 Skill ID。转出时必须写完整 ID，例如 `或`、`房产赠与合同·审查`。
