# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证合同有效、已经设立物权、必然对抗买受人或对方接受；编造未给出的证号、期限、对价；把已失效《合同法》《物权法》《房屋登记办法》写入结论；把签字写成已设立居住权；把未登记写成合同未生效；把租赁二十年上限或赠与任意撤销套到本约；把租赁或赠与留在本技能改完。

## 1. 触发、单方立场与成果状态

立场（设立人/所有权人、居住权人、拟签字共有人）、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明是否在他人住宅上设立占有、使用的用益物权，是否拟办理居住权登记，以及不转移所有权。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》《物权法》《房屋登记办法》及其解释时记噪声，不得写入 `L#`。登记设立、无偿推定、不得转让继承、未经约定不得出租、合同效力分离、租赁/赠与定性无 `verified-result` 时，对应法律结论字段停止。

## 3. 类型与加载路径

父级 `婚姻家庭`，子级 `居住权设立合同`。定性理由必须同时满足：他人住宅；为生活居住需要设立占有、使用的用益物权；不转移所有权。易混切开：房产/不动产租赁、房产/亲属/家事赠与、离婚协议、遗嘱、赡养、分家析产。

加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读其他类型、未打开租赁或赠与 method。查封房、非住宅、伪造登记或把居住权改成可转让写停笔告知，不填可履行结构。

## 4. 主体、授权、资质与文本版本

主体表：设立人（所有权人）、居住权人、共有人、配偶、在先抵押权人、现承租人（如有）。自然人写姓名与证件号是否与文本一致。

版本表：居住权合同正文、产证、平面图、共有人/配偶同意、抵押或租赁材料、聊天确认。冲突并列，不选对用户有利的一版。口头“已经登记了”“配偶同意了”不得写成已设立或已同意。

## 5. 住宅与居住权给付闭环

分列并回链文本位置：

- 权利性质：是否写明占有、使用的用益物权；设立人/居住权人角色是否反了。
- 标的：是否住宅；坐落、产证编号、面积；整套还是特定房间；有无平面图。
- 期限：终身或截止日期；消灭是否与死亡或届满挂钩。
- 对价：无偿，或显名有偿设立及给付。
- 登记：谁在几日内共同申请居住权登记；本合同是否作为登记文书；未完成的后果。
- 合同效力与物权：是否把登记写成合同生效或把签字写成已经设立。
- 处分限制：登记完成前不得抵押、出售或再设居住权；已登记后所有权转移不影响居住权。
- 使用限制：不得转让、继承；出租是否显名；改变用途、破坏结构、长期不住的后果。
- 费用：物业、水电气暖、日常维修与大修、房产税如何分担。
- 消灭与注销：届满、死亡、灭失、放弃后谁配合注销。

缺口标 `G#`，不补商业数字、证号或已登记事实。批准、登记写成条件或双方义务期限，不写成已经完成。

## 6. 格式条款、强制规范与本类型效力红旗

一方预先拟定且未协商的，按格式条款审查提示说明。亲属偶发安排通常不是格式条款。

强制规范与效力红旗只在核验后落法律结论：未登记不得产生物权效力；居住权不得转让、继承；未经约定不得出租；非住宅、查封、权属争议可能不予登记；共有处分未达同意门槛。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

不得把“未登记则合同未生效”或“未登记也能对抗买受人”写成已核验结论。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔/转出口径。禁止输出无修改句的色块表。

本类型至少检查：未约定登记或拟制已设立；把未登记写成可对抗第三人；缺期限；无偿/有偿未显名或用租金伪装；可转让/可继承；默认可出租；共有人未签；非住宅或查封；在先抵押未披露；登记完成前无处分限制；租赁或赠与主给付误留。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的证号、日期、金额用 `【待填】`，不编造。禁止只给原则、不给句子。框架与硬闸冲突时按硬闸出句。

建议句必须覆盖本类型硬闸：合同生效与登记设立分列；共同申请登记及逾期后果；期限终身或截止日；无偿或显名有偿；不得转让继承；出租须显名；与租赁/赠与切开后不得用对方主路径出句。

## 9. 谈判与签署提醒

谈判顺序：先红线（拟制已登记、查封/非住宅可办证、可转让继承、把本约改租赁或赠与、伪造登记），再必须改（登记义务、期限、无偿/有偿显名、共有人签、登记前处分限制），最后可优化（费用分担、告知出售、平面图附件）。

签署提醒：设立人、居住权人与共有人本人签并按指印；产证与平面图作附件；日期真实；约定签署后共同申请登记。不指导倒签、补假登记或假同意。

居住权人立场必须提示：未完成登记只有债权，设立人反悔或卖给第三人时难以主张物权。设立人立场必须提示：一旦登记，变现和抵押能力显著下降，期限届满或居住权人死亡前通常难以单方撤销。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、确认居住权诉讼文书或效力保证。
