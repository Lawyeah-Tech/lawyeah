# 居住权设立合同·审查

## 任务目标

在单一立场下，只审查 **婚姻家庭 / 居住权设立合同** 的待签文本：所有权人与居住权人约定，在他人住宅上为满足生活居住需要设立占有、使用的用益物权。输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「审查居住权设立合同（婚姻家庭）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查、从零起草、履约交底、争议文书、物权已设立或必然对抗第三人保证、房屋租赁整案、房屋或亲属赠与整案、离婚财产分割整案、遗嘱设立居住权整案、过户归己路径。

## 工作边界

正触发：已有可读待签文本要评改，；尚未签署，尚未成争；核心给付是在他人住宅上设立居住权，拟向不动产登记机构申请居住权登记；不转移房屋所有权。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 核心给付是支付租金换取债权性使用，或主文件是住房/房产/不动产租赁 → `或` 或 `或`；
- 核心给付是把房屋所有权无偿给予对方并办理转移登记 → `房产赠与合同·审查`、`亲属间房屋赠与合同·审查`、`婚姻家庭中的赠与合同·审查` 或 `一般赠与合同·审查`；
- 主文件是离婚协议，居住安排只是财产分割附带一句 → `离婚协议·审查`；
- 以遗嘱单独设立居住权、尚无合同文本 → `遗嘱·审查`；专业版未收录该原子时输出 `unavailable`，不得用本技能改成遗嘱；
- 主给付是赡养、扶养、分家析产或夫妻财产约定 → `赡养协议·审查`、`扶养抚养协议·审查`、`分家析产协议·审查` 或 `夫妻财产约定·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `居住权设立合同·起草`；
- 已签只问登记预约、交房入住、费用缴纳 → 本套导航的履约步骤；
- 已成争（催告腾房、请求确认居住权、排除执行、立案仲裁）→ 合同争议或对应专项领域。

规避限购、伪造登记、把查封/违章/小产权/非住宅改成可办理居住权登记：只出告知，不改写成可履行结构。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成。每一闸必须给出修改句或明确转出口径，禁止只打红黄绿。

1. **登记设立**。居住权自登记时设立。修改句必须拆成：本合同自双方签字之日起成立生效；居住权自不动产登记机构办理居住权登记时设立。补双方在签署后【待填】日内共同申请登记、谁准备材料、逾期按【待填】付违约金或可解除、登记完成前设立人不得抵押、出售或为第三人再设居住权。原文“签字即视为已设立/已登记/可对抗任何第三人”：红线。未登记不得写现有依据支持已享有用益物权或可排除执行。
2. **期限 / 无偿**。期限必须写成“至居住权人死亡时止”或“至【待填】年【待填】月【待填】日止”。缺期限必须改。原则上无偿；有对价必须显名“有偿设立”，写清金额、支付方式和逾期是否导致解除并配合注销。禁止用租金、押金、租期届满续租改写本约。禁止把租赁期限不得超过二十年写进本类型。
3. **与租赁切开**。月/年租金、押金、租期、转租、优先承租或买卖不破租赁是主结构 → 负触发 `或` 或 `或`。禁止打开其 method。禁止输出押金罚则、二十年续租、优先购买作为本类型主路径。
4. **与赠与切开**。过户所有权、受赠人、任意撤销、赠与房产变更登记是主结构 → 负触发 `房产赠与合同·审查`、`亲属间房屋赠与合同·审查`、`婚姻家庭中的赠与合同·审查` 或 `一般赠与合同·审查`。禁止打开其 method。禁止把本约改成可过户归居住权人所有，也禁止把赠与任意撤销套到居住权合同。

附加必落句（有事实则单列，无事实在缺口节说明）：

- **不得转让、继承**：居住权不得转让、不得继承。原文允许随房屋过户给子女或作为遗产：红线。
- **出租须显名**：未经合同显名约定，居住权人不得出租该住宅。只写“依法使用”视为禁止出租，若双方要保留出租权必须另写一句。
- **权利性质**：写明对他人住宅享有占有、使用的用益物权，以满足生活居住需要；设立人是设立居住权，居住权人是享有居住权。
- **所有权转移不消灭已登记居住权**：已登记的，设立人出售或继承人不影响居住权行使。未登记的，不得写这句话已经产生物权效力。
- **合同组**：本合同即为办理居住权登记所需法律文书；产证复印件与部分房间平面图作附件。

必须有修改句。每个风险回链文本位置。禁止套用租赁的租金、押金、二十年、转租、优先购买节点。禁止套用赠与的任意撤销、过户所有权、道德义务不可撤销节点。禁止复制租赁或赠与 method。

## 建立审查坐标

确认：使用者与授权；单方立场（设立人/所有权人、居住权人、拟签字共有人）；相对方；全文及产证/平面图/共有人同意附件版本；住宅坐落与证号；整套或特定房间；期限；无偿或有偿；是否拟共同登记；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的证号、期限、对价用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law`（法律结论 required）：核验居住权书面、自登记设立、无偿推定、不得转让继承、未经约定不得出租、期限届满或居住权人死亡消灭、合同效力与物权变动分离、共有处分、租赁与赠与定性条文。
- `search_practiced`（optional）：补未登记仅有债权、与租赁/家庭成员法定居住的区分等争点。返回“签字即设立”“未登记合同未生效”“租赁二十年适用于居住权”“赠与撤销适用于居住权”时记噪声。
- `search_template`（optional）：只借栏目结构。范本写“本合同签订之日起居住权设立”或按租金/押金结构的，不得当规则。

不虚构案件系统。`search_law` 返回已失效《合同法》《物权法》《房屋登记办法》及其解释时记为噪声，不得写入 `L#`。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口，不代替节点。

0. 签署状态与成果分流
1. 类型识别与单目录加载（居住权用益物权；切开租赁 / 赠与 / 离婚 / 遗嘱）
2. 主体、住宅权属、共有人、在先负担
3. 登记设立与合同效力分离
4. 期限与无偿／有偿显名
5. 不得转让继承、出租须显名、使用限制
6. 消灭、注销与登记完成前处分限制
7. 费用分担、违约与配合办证
8. 按框架六步出修改句

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签登记、补假登记回单、伪造共有人同意、把查封/违章/小产权/非住宅改成可登记、把居住权改成可转让继承、把本约改成租赁或赠与以绕开登记、保证未登记也能对抗买受人或排除执行。
- `字段停止`：法域、权属/共有、是否住宅、期限、无偿或有偿、是否拟办理登记未核验。
- `目标停止`：主目标已变为从零起草、履约交底、确认居住权诉讼文书，或用户要把本约改成租赁/赠与/买卖。

生存级唯一住房拟设终身居住权且所有权人拒绝理解变现冻结、或居住权人拒绝升级登记安排：停止“可以签署”建议。
