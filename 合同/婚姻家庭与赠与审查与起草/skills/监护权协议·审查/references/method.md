# 审查方法（锁定 婚姻家庭 / 监护权协议）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型，禁止打开意定监护、抚养权变更、扶养／抚养或离婚协议双文件“对照一下”。

本文件是**资格人之间协议确定监护人**的签前判断节点，不是栏目说明书，也不是意定监护预授清单或直接抚养测算表。禁止把第三十三条本人预授、第一千零八十四条直接抚养、抚养费月收入比例写入本类型默认结论。

每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、基层组织必然备案或唯一必得金额。

`search_law` 返回已失效《民法通则》及其意见、已失效《婚姻法》及其解释、已失效《合同法》及其解释、2012 年《预防未成年人犯罪法》同条号时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突。

示范文本只参考结构。司法行政或基层监护示范文本不证明本约条款已被接受。

### 双文件使用（标题与文件名不完全对应时不拒跑）

同目录两份知识文件按标题语义使用，不回改正文，不因文件名拒跑：

- 含“首部 / 交易条款 / 配套 / 尾部 / 语言”的当框架级条款清单，供节点 8 出句；
- 宏观的类型切开、主体顺位、标的职责、程序顺序、结构红旗由本方法节点承担。知识稿把“八周岁以上未同意可能无效”写满的，**降级**：应当尊重真实意愿，明确反对则人选必须改，不当然宣告整份协议无效。知识稿把“父母离异后协商履行监护职责”写满的，**降级**：离婚后父母仍是未成年子女的监护人；主文是直接抚养则转出，不得写成一方独占并免除另一方。知识稿把“顺序不得违反法定顺位除非先顺位书面放弃”写满的，**按总则编解释第八条第二款纠正**：资格人可以约定后顺位或共同担任；不能免除有监护能力的父母。知识稿把公证、司法确认写成“顺畅施行关键／强制执行力文书”的，**降级为证据补强或另走特别程序**，不是成立要件，也不是签字当日已有执行名义。
- 文件不可用（空、代码块、与本类型明显无关）：记 `G#`，用本方法节点继续，不得改去加载意定监护或抚养双文件，不得编造意愿或费用。

## 节点 1　类型识别与负触发

### 1.1 本类型正像

同时满足才继续：

- 协议人属于《民法典》第二十七条或第二十八条规定的依法具有监护资格的人；
- 核心给付是**确定谁担任监护人**并分配人身、财产职责，而不是本人给自己预授、不是只改直接抚养或抚养费；
- 被监护人是未成年人（通常因父母死亡、丧失监护能力、被撤销或依法应重新确定）或无／限制民事行为能力成年人。

标题写成“监护协议”“监护权转让协议”“确定监护人协议书”只是线索。名实不符按核心给付归类，标题冲突写入 `C#`。合同编通则解释第十五条：不拘泥名称。

### 1.2 必须切开（禁止两套知识）

| 信号 | 归入 | 本技能动作 |
| --- | --- | --- |
| 本人现有完全民事行为能力，为自己将来失能预选近亲属或其他愿意担任的人 | 意定监护协议 | **负触发** → `意定监护协议·审查`。不得把第三十三条书面预授改写成第三十条资格人互约 |
| 父母均在且有监护能力，主文是谁直接抚养、抚养费、探望 | 抚养权变更／离婚协议 | **负触发** → `抚养权变更协议·审查`；夹带解除婚姻和夫妻财产 → `离婚协议·审查`。不得把“监护权归一方”当直接抚养放行 |
| 不变更监护人选，只重订抚养费、扶养费或探望 | 扶养＿抚养协议 | **负触发** → `扶养抚养协议·审查`。不得把抚养费比例带进本任务 |
| 成年子女落实对老年人的供养、照料、慰藉，不争监护人身份 | 赡养协议 | **负触发** → `赡养协议·审查` |
| 解除收养、消灭拟制父母子女关系 | 解除收养协议 | **负触发** → `解除收养协议·审查` |
| 现在就分房、分地、分存款，监护只是附带一句 | 分家析产协议 | **负触发** → `分家析产协议·审查` |

意定监护误入是硬闸：一旦核心是本人预授，立即停笔转出。不得删掉“我指定某某将来照顾我”后继续当资格人互约审。

### 1.3 加载协议

只打开本目录 `基本面.md` 与 `框架.md`。禁止读 `types/` 或其他场景原子目录。

### 1.4 违法或侵害结构停笔（本类型，不是施工挂靠）

出现下列任一结构，只出告知，不改写成可履行文本：

- 伪造被监护人意愿、代无／限制民事行为能力人“同意”，或倒签日期以假装监护早已交接；
- 把仍有监护能力的父母写成签字之日起不再是监护人、永远不得过问教育医疗；
- 把监护资格有偿转让、买卖、抵债，或“谁出钱谁买断监护权”；
- 约定监护人可全权自由出售、抵押被监护人房产或支取全部存款，且不以被监护人利益为限；
- 把“谁当监护人谁继承全部遗产”写成对价；
- 抢夺、藏匿被监护人后逼签。

用户坚持“改到能签／能让父母彻底不管／能把房子过到监护人名下”：整体停止。合规改道（父母丧失能力时的候补、另走指定或撤销、另立遗嘱）只点名，不在本任务起草规避方案。

## 硬闸 A　法定监护不可任意约定放弃

本闸改变能否放行。

1. **父母是未成年子女的监护人**  
   第二十七条第一款：父母是未成年子女的监护人。第二十六条第一款：父母对未成年子女负有抚养、教育和保护的义务。第一千零八十四条：父母与子女间的关系不因离婚而消除；离婚后仍有抚养、教育和保护的权利义务。总则编解释第八条第一款：未成年人的父母与其他依法具有监护资格的人订立协议，约定免除具有监护能力的父母的监护职责的，人民法院不予支持。  
   **修改句**：`删除“甲方（父／母）自愿永久放弃监护权，自本协议签字之日起不再是监护人，不得过问教育、医疗和财产”。各方确认：在【父／母姓名】仍具有监护能力期间，其法定监护职责不因本协议减免。如拟在其丧失监护能力时由【资格人姓名】担任监护人，改为：仅当人民法院、医疗机构或依法确认【父／母姓名】丧失监护能力时，由【资格人姓名】依第三十条担任监护人。本条不构成监护权转让或买卖。`

2. **解释第八条允许的空间**  
   第八条第一款后段：约定在父母丧失监护能力时由该资格人担任的，人民法院依法予以支持。第八条第二款：资格人可以约定由不同顺位的人共同担任，或由顺序在后的人担任。知识稿“不得突破法定顺位除非先顺位书面放弃”不得照抄为放行条件。  
   **修改句**：`本协议依据第三十条，由【列名资格人】协商确定【姓名】担任监护人（或【甲】与【乙】共同担任）。该约定不免除仍有监护能力的父母的法定职责。顺序在后的【姓名】担任监护人，以其他资格人书面同意且符合最有利于被监护人为前提，不写成“先顺位已放弃全部法定义务”。`

3. **撤销后仍须负担费用**  
   第三十七条、未成年人保护法第一百零八条第二款：被撤销监护人资格的父母等，应当继续负担抚养费等法定义务。  
   **修改句**：`删除“被撤销或退出后不再支付任何费用”。即使监护职责改由他人履行，依法应当负担抚养费、赡养费或扶养费的一方，仍按第【待填】条支付。`

4. **最强反方**  
   父母可主张长期外出、再婚不便或对方更有钱。签前只允许委托照护或丧失能力时的候补，不得把免责写成可履行。负担能力只影响费用字段，不影响父母是否仍是监护人。

核验失败：免除条款的效力法律结论字段停止；删除免责、改回候补的修改句草稿继续。

## 硬闸 B　最有利于被监护人（儿童利益）

1. **法定原则**  
   第三十五条第一款：监护人应当按照最有利于被监护人的原则履行监护职责。未成年人保护法第四条：处理涉及未成年人事项应当坚持最有利于未成年人的原则，并听取未成年人的意见。人选、居住、就学、医疗、财产处分必须能回链被监护人生活稳定和安全，不得写成“双方签字即当然符合最佳利益”。  
   **修改句**：`确定【姓名】担任监护人的理由限于被监护人利益：经常居住地【待填】、就学／康复安排【待填】、主要照料人【待填】、与被监护人生活情感联系【待填】。删除“谁出生活费谁带走”“财产多的一方当然担任”“为了方便再婚把孩子交给祖父母并断绝往来”。任何一方不得主张本协议签字即视为已符合最有利于被监护人。`

2. **夺权与推诿**  
   财产丰厚时争夺、负担沉重时互推，是本类型高频红旗。总则编解释第六条：认定监护能力看年龄、身心健康、经济条件等，不是看谁先签字。  
   **修改句**：`拟任监护人应具备与履职匹配的监护能力。各方不得以“先签字者得权”或“不愿负担费用者自动退出”确定人选。若【姓名】仅因被监护人名下有房产而争任，或仅因照料成本高而拒绝列名，该人选／退出条款必须改，改前不得签署。`

3. **最强反方**  
   某资格人可主张自己与被监护人更亲、对方有违法犯罪或虐待史。签前把不利于履职的违法犯罪、吸毒酗酒、长期怠于履行写成不得担任或不得委托的核对项（未成年人保护法第二十二条第三款可参照用于委托场景），不在本任务认定犯罪。

核验失败：是否“当然符合儿童利益”的法律结论字段停止；删除有害对价、补利益回链的修改句草稿继续。

## 硬闸 C　与意定监护切开

本闸改变能否留在本任务。

1. **两条制度**  
   第三十条：依法具有监护资格的人**之间**协议确定监护人，须尊重被监护人真实意愿。第三十三条：具有完全民事行为能力的**成年人**，可以与近亲属、其他愿意担任的个人或组织事先协商，以书面形式确定**自己的**监护人，在自己丧失或部分丧失民事行为能力时由该人履职。  
   **修改句（误入一句、其余确为资格人互约时）**：`删除“本人【被监护人】指定某某为将来的监护人，自失能之日起生效”及任何本人预授句。本协议仅由【资格人名单】就【被监护人】的现行监护人人选达成合意。如【某人】现有完全民事行为能力、要为自己将来失能预选监护人，应另签意定监护协议，本任务停止该部分并转出。`

2. **不得把本约手续误标成意定监护已完成**  
   知识稿强调公证、书面、本人签字。这些痕迹不能把资格人互约“升级”成第三十三条意定监护，也不能把意定监护“降级”成本任务继续整审。  
   **修改句**：`各方确认：本协议不是意定监护协议，不产生第三十三条预授效力。公证或基层见证只作为本协议签署和意愿的证据，不视为已办理意定监护。`

3. **最强反方**  
   用户可主张“反正都是监护协议、一套做完”。签前按设立主体切开：本人给自己预授走 `意定监护协议·审查`；资格人互约走本任务。禁止灌入两套知识。

核心给付已是本人预授：负触发，不在本任务删改预授句后继续。

## 硬闸 D　确定 vs 委托

1. **委托不产生监护人身份**  
   总则编解释第十三条：监护人因患病、外出务工等原因在一定期限内不能完全履行监护职责，将全部或者部分监护职责委托给他人，当事人主张受托人因此成为监护人的，人民法院不予支持。未成年人保护法第二十二条：因外出务工等在一定期限内不能完全履行的，应当委托具有照护能力的完全民事行为能力人代为照护；无正当理由不得委托；确定被委托人应综合考虑品行、家庭、身心、情感联系并听取有表达意愿能力未成年人的意见。  
   **修改句**：`如【父母姓名】仍具有监护能力，仅因【外出务工／住院等，待填】在【待填】期限内不能完全履职，本条改为委托照护：受托人【姓名】代为日常照料和就学联络，期限自【待填】至【待填】。委托不使受托人成为监护人，不转移法定监护责任。被委托人不得具有性侵害、虐待、遗弃、吸毒酗酒赌博或长期怠于履行等不适宜情形。删除“受托之日起监护权归受托人”。`

2. **语言盯死“确定”与“委托”**  
   框架要求：本协议是“确定”监护人，不是暂时的委托监护。标题或正文混用时，按是否仍存在有能力的法定监护人切开。  
   **修改句**：`合同标题改为《协议确定监护人协议书》或《监护权协议》。正文凡写“转让监护权”“委托即视为变更监护人”的，一律改为“确定”或按本闸改为有期限的委托照护。代理民事法律行为用“代理”；保管财物用“代管”。`

3. **最强反方**  
   受托人可主张已经长期共同生活、对外都以家长身份行事。签前仍不得把事实照料写成监护资格已经转移。

用户坚持把委托改成可履行的资格转移、而父母仍有监护能力：整体停止，落入硬闸 A。

## 硬闸 E　尊重被监护人真实意愿

1. **协议要件**  
   第三十条第二句：协议确定监护人应当尊重被监护人的真实意愿。第三十五条：对未成年人，根据年龄和智力状况尊重真实意愿；对成年人，最大程度尊重真实意愿，有能力独立处理的事务监护人不得干涉。  
   **修改句**：`确定【姓名】担任监护人前，应单独听取被监护人【姓名】的意见，制作谈话笔录或录音录像作为附件【待填】，询问时资格人不得在场施压。被监护人明确反对该人选的，各方应重新协商人选，不得把“少数服从多数”写成已尊重意愿。`

2. **满八周岁**  
   知识稿要求八周岁以上签署“本人同意由某某担任我的监护人”。意愿痕迹必须有；不得把未成年人写成合同义务人、违约金债务人或财产处分共同卖方。口头“孩子说跟我”不得写成已尊重。  
   **修改句**：`被监护人已满八周岁（或成年人仍能表达）的，应在本协议意愿页签署：“本人同意由【姓名】担任我的监护人”，签署时间【待填】。该签署只证明意愿，不使被监护人承担本协议项下金钱给付或违约金。不得由监护人代签充作本人同意。`

3. **最强反方**  
   资格人可主张孩子年幼、说不清或已被对方教唆。无独立痕迹则意愿字段 `依据不足`，不补写成已同意。明确反对时人选必须改，不当然在签前宣告整份协议无效。

---

## 硬闸 F　财产处分须为被监护人利益，不得捆绑继承

1. **处分限制**  
   第三十五条第一款：除为维护被监护人利益外，不得处分被监护人的财产。框架要求重大事项核准制。  
   **修改句**：`删除“监护人可全权自由处分被监护人名下房产、存款和股权”。监护人代管被监护人财产，仅可为被监护人的生活、治疗、教育或必要债务清偿而处分。出售、抵押被监护人不动产或单笔超过人民币【待填】元的，须取得其他协议人一致书面同意，并书面说明该处分如何维护被监护人利益。监护人不得将代管财产与自有财产混同。`

2. **禁止继承捆绑**  
   框架陷阱：谁当监护人谁继承全部遗产，易诱发谋产。本约不处分遗产。第二十九条遗嘱指定监护人是父母另立遗嘱的路径，不是本协议对价。  
   **修改句**：`删除“担任监护人的一方继承被监护人全部遗产，其他资格人放弃继承”及“监护报酬以房产抵顶”。本协议不处分被监护人遗产，不构成遗赠或遗赠扶养。被监护人的父母如需以遗嘱指定监护人，应另立遗嘱，适用第二十九条和总则编解释第七条，不在本协议预判遗嘱效力。`

3. **费用与劳务补偿**  
   生活费、教育费、医疗费可从被监护人财产支出或由资格人分担；对成年被监护人可约定合理劳务报酬。不得把报酬写成抽成房产。  
   **修改句**：`被监护人的生活、教育、医疗费用来源：〔1〕从被监护人账户【待填】列支；不足部分由【甲】【乙】按【待填】分担，于每月【待填】日前转入【待填】。监护人劳务报酬为每月人民币【待填】元／无，仅可从被监护人财产合理支付，不得以不动产过户抵顶。费用数字未定时填【待填】，不编造。`

4. **最强反方**  
   拟任监护人可主张卖房是为治病。修改句要求先书面说明利益用途并走核准，不在签前批准某一笔过户。

用户坚持保留可自由卖房或继承捆绑：整体停止。

## 硬闸 G　资格人参与与对外效力

1. **主体遗漏**  
   知识稿：未取得同顺位资格人同意的，未签字人可请求重新确定。第三十一条：对确定有争议的，由住所地居民委员会、村民委员会或民政部门指定，也可直接申请法院指定。指定前无人保护的，由基层组织或民政临时监护。  
   **修改句**：`本协议列明的同顺位资格人：【名单及与被监护人关系】。已知未签字的【姓名】仍具有监护资格。签字方应在【待填】日前书面通知并邀请其补签。未补签不影响签字方内部的照料分工，但任何一方不得主张本协议已经排除【姓名】申请指定或重新确定监护人的权利。`

2. **签字 ≠ 对外指定完毕**  
   第三十一条第四款：监护人被指定后，不得擅自变更；擅自变更的，不免除被指定的监护人的责任。总则编解释第十二条第二款：被依法指定的监护人与其他资格人协议变更的，法院按意愿和最有利于被监护人裁判。私下协议不能写成已经完成指定或已经有执行名义。  
   **修改句**：`删除“本协议签字当日监护关系对外已经变更完毕，学校、医院、银行、登记机关必须配合，并可直接强制执行”。各方应在签署后【待填】日内向被监护人住所地居民委员会／村民委员会／民政部门报备。报备、公证或申请认定行为能力／确认监护人，是各方义务，完成本协议成立的条件或对外对抗的时间，以有权机关实际办理为准。已被指定的监护人不得以本协议擅自更换；需要变更的，另依法申请。`

3. **见证与公证**  
   框架强烈建议基层盖章或公证。降级：证据补强和办事便利，不是法定成立要件，也不是“最高证据效力”。  
   **修改句**：`建议在村（居）民委员会见证下签署，或办理公证，作为资格人合意和被监护人意愿的证据，不作为本协议成立的法定条件。各方不得把“未公证则无效”或“已公证即不得再申请指定／撤销”写入正文。`

4. **最强反方**  
   拟任监护人可主张“家里就我们几个、外人不会来争”。未列名资格人字段仍须点名；材料不足则 `依据不足`，不补写成已无其他资格人。

## 节点 2　主体、授权、顺位

1. 建主体表：被监护人；父母或其他原监护人现状；拟任监护人；同顺位其他资格人；后顺位或共同监护人；候补；费用分担人。名称不一致不自动合并。
2. 未成年人：核第二十七条顺位。成年人：核第二十八条顺位，并核是否已有或正在申请认定无／限制民事行为能力。能力终局认定本任务不做。
3. 总则编解释第六条：监护能力看年龄、身心、经济条件等。口头“家里都同意了”不得写成已授权或被监护人已同意。
4. 曾被撤销监护资格、有未成年人保护法第二十二条第三款所列不适宜情形：标红旗，不编造已恢复资格。
5. 第二十九条、总则编解释第七条：另有父母遗嘱指定监护人时，本协议不得假装覆盖遗嘱；遗嘱指定人不同意或另一方父母仍有能力的，按解释第七条处理，本任务不代判遗嘱效力。

不足：字段停止，列出待补材料，不补主体。

---

## 节点 3　职责范围、居住与费用

1. 人身监护与财产监护分列。只写“负责监护”视为必须改。
2. 居住地、就学或康复机构、医疗决定人、紧急联络人写到可履行。
3. 费用来源、账户、劳务报酬按硬闸 F 分列。禁止编造数字。
4. 共同监护时，重大决策一致同意；单一监护时，其他资格人保留报告查阅和申请撤销的路径。

---

## 节点 4　程序与生效

把意愿征询、基层报备、公证、认定行为能力、法院确认写成**义务和期限**，不写成已经完成。

| 文本写法 | 本任务动作 |
| --- | --- |
| “签字即视为被监护人同意／已备案／已获司法确认／学校必须变更” | 拆成签字 vs 意愿痕迹 vs 对外程序；删除“视为已完成／已有执行力” |
| “本协议以离婚登记为生效条件” | 按节点 1.2 转出或删除该条件 |
| 把未指定写成可以直接强制执行 | 纠正；已成争则转出 |
| 用户要求倒签或补假意愿、假见证书 | 整体停止 |

成年被监护人尚未经依法认定：同意和代理权限字段停止，点名可另走认定行为能力特别程序，不在本任务出具认定结论。

---

## 节点 5　格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

打印店或网上下载的重复使用监护模板，仍可能构成格式条款。审查免责、监护买卖、自由处分不动产、捆绑继承、单方解释权是否显著。

违反法律、行政法规强制性规定不一律无效（第一百五十三条第一款）。免除有能力父母的监护、监护买卖、损害被监护人的财产处分，就该条款停笔删除，不轻易宣告“整份协议当然全部无效”，除非剩余条款已无法实现确定监护人的目的。禁止用已失效“效力性／管理性”口诀。

---

## 节点 6　监督、违约、变更与争议

1. 框架：定期向其他协议人通报身体与财产变动；其他资格人可查阅账目和医疗记录。未写报告视为必须改。
2. 违约情形重点设为虐待、遗弃、侵占财产、拒不救治。只有“依法承担违约责任”视为必须改。
3. 变更：监护人丧失能力或严重违约时，其他协议人可协商重新确定或向法院申请撤销（第三十六条）。不得约定单方通知即解除全部监护安排。构成违约不等于本任务宣告已经撤销。
4. 第三十六条所列组织未及时申请的，民政部门应当申请。修改句可点名申请路径，不代写起诉状。
5. 争议解决：  
   - 可约定先由村（居）民委员会或民政部门协调；  
   - 已有仲裁条款须标红旗：身份监护能否仲裁运行时核验，不得假装已选定有效仲裁；  
   - 或裁或诉、机构不明：改成单一连结点；  
   - 民诉解释第十条：不服指定监护或变更监护关系，可由被监护人住所地法院管辖。修改句可写被监护人住所地人民法院，须写成约定，不选定唯一法院充法律意见。
6. 微信已读不写成已经送达，除非合同把该渠道定为送达。

---

## 节点 7　跨境、安全与其他结构

1. 被监护人或拟任监护人在境外：准据法不明则停止外国法结论。涉外民事关系法律适用法第三十条仅提示“有利于保护被监护人权益的法律”，不在本任务选定外国法。
2. 疑似虐待、遗弃、性侵害、家庭暴力或抢夺藏匿：停止签前“可以签署”，提示第三十六条、未成年人保护法第一百零八条或公安路径，不在本任务调查定罪。
3. 无任何资格人：点名第三十二条民政或基层组织担任，不在本任务虚构个人监护人。

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

对照已加载框架级文件和本方法硬闸，按六步逐段出句。

| 步 | 本类型必须盯的点 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题用监护权协议／协议确定监护人协议书，避免写成意定监护、委托监护、抚养权变更；资格人与被监护人身份；鉴于写明原监护人现状和“确定不是转让” | 主体与鉴于修改句 |
| 交易条款 | 人选、起止、人身与财产分列、费用来源、重大处分核准、劳务报酬不得抵房 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 删除父母免责与监护买卖；定期报告与查阅；候补监护人；变更走法定路径；基层报备 | 可执行后果句 |
| 尾部 | 资格人亲签；八周岁或可表达被监护人意愿页；附件：关系证明、意愿记录、财产与费用表；生效不绑离婚登记 | 生效与附件修改句 |
| 语言 | 确定 ≠ 委托 ≠ 转让 ≠ 预授；代理 ≠ 代管；签字 ≠ 对外指定完毕 | 替换空词的句子 |
| 常见问题 | 未设候补、继承捆绑、全权卖房、父母放弃、把未成年人写成债务人 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（父母放弃、监护买卖、自由卖房、继承捆绑、伪造意愿、本人预授硬套）；
- `必须改`：可谈但签署前要落句（意愿痕迹、财产核准、费用来源、候补、资格人列全、报告查阅、对外路径）；
- `可接受可优化`：仍要给句子，不得只标绿（基层见证、公证、报告频率、劳务报酬数字）。

用户不可接受事项优先写成红线。被监护人生存级医疗或无人照料且用户拒绝升级：停止“可以签署”建议。
