# 监护权协议·审查

## 任务目标

在单一立场下，只审查 **婚姻家庭 / 监护权协议** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「审查监护权协议（婚姻家庭）」。

`depends-on` 为空。不要求先跑导航。

主线是**依法具有监护资格的人之间，就谁担任监护人、如何分工履职达成书面合意**（《民法典》第三十条）。协议只能在资格人中“确定”监护人，不能把监护当权利转让或买卖，更不能让仍有监护能力的父母用一纸协议甩掉法定职责。

不交付：他类审查、从零起草、履约交底、争议文书、有效性或对外指定保证、把父母放弃监护改成可履行、把本人预授未来监护人改成意定监护整审、把直接抚养／抚养费改完、把委托照护写成监护资格已转移。

## 工作边界

正触发：已有可读待签文本要评改，；尚未签署，尚未成争；核心给付是资格人之间确定监护人人选、职责分工、费用来源、监督与候补；被监护人是未成年人（父母死亡、丧失监护能力或依法应重新确定）或无／限制民事行为能力成年人。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 本人现有完全民事行为能力，为自己将来失能预选监护人 → `意定监护协议·审查`。不得把第三十三条预授改写成第三十条资格人互约；
- 父母均在且有监护能力，主文是谁直接抚养、抚养费、探望 → `抚养权变更协议·审查` 或夹带离婚财产时 `离婚协议·审查`。离婚后父母仍是未成年子女的监护人，不得当“监护权归一方”放行；
- 不变更监护人选，只重订抚养费、扶养费或探望 → `扶养抚养协议·审查`；
- 成年子女对老年人落实供养、照料、慰藉，不争监护人身份 → `赡养协议·审查`；
- 主文解除婚姻并分割夫妻财产 → `离婚协议·审查`；
- 解除收养关系为主 → `解除收养协议·审查`；
- 大家庭现房、宅基地分割为主 → `分家析产协议·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `监护权协议·起草`；
- 已签只问备案日、账户交接、报告节点 → 本套导航的履约步骤；
- 已成争（申请指定／撤销监护、认定行为能力、抢夺藏匿、人身安全保护令、立案）→ 家事或合同争议领域，不填签前十节。

伪造被监护人意愿、倒签、把有监护能力的父母写成永久免责、把监护资格卖给第三人、把被监护人房产写成监护人可自由过户：只出告知，不改写成可履行规避结构。用户坚持：整体停止。

## 建立审查坐标

确认：使用者与授权；单方立场（拟任监护人、其他资格人、或为被监护人利益行事的近亲属，择一）；相对方；正文与附件版本；被监护人身份、年龄或行为能力状态、是否满八周岁或仍能表达；原监护人现状（死亡、丧失能力、被撤销或仍在任）；全体同顺位资格人是否列名；人身照料与财产管理是否分列；有无放弃监护、委托伪装转移、继承捆绑、自由处分房产；不可接受事项；法域与拟签时限。缺立场或无可读文本则不启动实体审查。同时掌握多方互冲突密时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的金额、日期、账户、文号用 `【待填】`，不编造。

## 本类型硬闸

审查过程必须逐项点名，每闸必须有修改句，不得用意定监护预授、直接抚养安排或抚养费比例代替：

1. **法定监护不可任意约定放弃**：有监护能力的父母不得用协议免除自己的监护职责。总则编解释第八条第一款：此类约定人民法院不予支持。可以约定“父母丧失监护能力时由某资格人担任”，不得写成“签字之日起父母不再是监护人／永远不得过问”。监护是职责不是可买卖的权利。
2. **最有利于被监护人（儿童利益）**：人选、居住、教育医疗、财产处分必须能回链被监护人利益。财产丰厚时夺权、负担沉重时互推、谁出钱谁带走、监护人可全权卖房，一律不得压过被监护人。未成年人适用《未成年人保护法》第四条最有利于未成年人原则。
3. **与意定监护切开**：第三十条是资格人之间确定现行监护人；第三十三条是本人在有完全行为能力时书面预授。标题写成监护权协议、正文却是“我指定某某为将来的监护人”，负触发 `意定监护协议·审查`。不得把公证、书面形式或“本人签字”误判成已经办妥意定监护。
4. **确定 vs 委托**：委托照护或委托履行部分职责，不使受托人成为监护人（总则编解释第十三条；未成年人保护法第二十二条）。修改句禁止“委托即转移法定监护责任”。
5. **尊重被监护人真实意愿**：八周岁以上未成年人或仍有表达能力的成年人，须有单独、不受在场资格人胁迫的意愿痕迹。口头“孩子说跟我”不得写成已尊重。被监护人不是合同义务人或违约金债务人。
6. **财产处分须为被监护人利益，不得捆绑继承**：除维护被监护人利益外不得处分其财产。删除“谁当监护人谁继承全部遗产”“监护人可自由出售房产”。重大处分写核准制。
7. **资格人参与与对外效力**：同顺位未签字资格人可请求重新确定。签字不等于居委会／民政指定已经完成，不等于银行、学校、医院、登记机关必须接受，不等于已有强制执行力。指定后擅自变更不免除原被指定人责任。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录，禁止为对照打开意定监护、抚养权变更或扶养／抚养双文件。交付按 [输出合同](references/output-contract.md)。边界见 [路由](references/routing.md)。

`基本面.md` 中“八周岁以上未同意可能无效”降级为：应当尊重意愿，明确反对则人选必须改，不当然宣告整份协议无效。“父母离异后协商履行监护职责”不得写成离婚后一方可独占并免除另一方监护。`框架.md` 中“顺序不得违反法定顺位除非先顺位书面放弃”按总则编解释第八条第二款纠正：资格人可以约定后顺位或共同担任；不能免除有监护能力的父母。“公证／司法确认对接强制执行力”降级为证据补强或另走特别程序，不是签字当日已有执行名义。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `监护权协议·起草`；已签履约 → 本套导航履约步骤；已成争或人身安全事项 → 家事／争议专项。未签且目标是评改已有协议确定监护人文本，才进入本任务。

### 1. 类型锁死

标题、核心给付是资格人互约确定监护人，才继续。意定监护预授、直接抚养主轴、只改抚养费、解除收养、赡养分工负触发。

### 2. 主体、顺位与被监护人身份

资格人是否属于第二十七条或第二十八条；父母是否仍有监护能力；被监护人年龄或能力状态；同顺位是否列全。

### 3. 法定监护不得放弃与儿童利益

删除父母免责、监护买卖、有害人选。人选理由须回链被监护人利益。

### 4. 确定、委托与意定切开

委托不转移资格。本人预授转出。

### 5. 意愿痕迹、财产与费用

八周岁或可表达成年人的独立意愿；财产处分限制；生活教育医疗费用来源。

### 6. 监督、变更与强制规范

定期报告、查阅、候补；变更走第三十一条／第三十六条路径，不得单方撤销。无核验引文则法律结论字段停止。

### 7. 违约、备案与争议

虐待、侵占、拒不救治可约定内部后果。备案、公证写成义务，不写成已经对外生效。不选定唯一法院充作意见。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造被监护人意愿或倒签、把有监护能力的父母写成可履行免责、把监护资格卖给第三人、把被监护人房产写成监护人可自由过户、保证协议必然有效或对外必然被指定／可强制执行。
- `字段停止`：被监护人行为能力或是否满八周岁未核、父母监护能力不明、同顺位资格人未列全、地方户籍／学籍／银行核验口径、指定或认定行为能力的特别程序条件未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或文本已滑入意定监护、抚养权变更、离婚一揽子或扶养／抚养。

疑似虐待、遗弃、性侵害或抢夺藏匿：停止“可以签署”，提示撤销监护、人身安全保护令或公安路径，不在本任务调查定罪。
