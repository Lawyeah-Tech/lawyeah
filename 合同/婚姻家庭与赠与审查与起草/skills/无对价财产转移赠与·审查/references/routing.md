# 边界与路由

本技能只审查 **赠与合同 / “不直接支付对价的财产转移” 型赠与合同** 的待签、无直接价款、且看不到借贷或让与担保叠层的转移 / 交割 / 划转 / 移交文本。中文展示名是「审查“不直接支付对价的财产转移” 型赠与合同（赠与合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开 `一般赠与合同·审查`、`公益道德义务性质的赠与合同·审查`、`零对价股权赠与·审查`、`借名购房型赠与·审查`、`文本写到期还本回购担保债权流质或“先过户再还钱把房拿回”→负触发`、`的method。` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 标题和正文承认无偿赠与、给予，无借贷叠层 | `一般赠与合同·审查` |
| 救灾、扶贫、助残等公益、道德义务赠与是主文件 | `公益道德义务性质的赠与合同·审查` |
| 房产为承认赠与的主标的 | `房产赠与合同·审查` |
| 股权零元赠与主文件 | `零对价股权赠与·审查` |
| 以他人名称购房并支付房款 | `借名购房型赠与·审查` |
| 房产过户外壳 + 借款担保 / 回购 / 流质 | `文本写到期还本回购担保债权流质或“先过户再还钱把房拿回”→负触发` |
| 赠与、划转、交割等其他外壳，真实目的是借贷 | `的method。` |
| 过户到出借人名下、还本付息、到期赎回的借款主文件 | `过户担保还本付息主轴可点名` |
| 有应付价款、定金、发票、按揭 | 对应买卖原子（如 `或相应买卖），不得直接当赠与。以物抵债让与担保→转本套导航的类型切开步骤重新定性。离婚分割→`、`真实房屋买卖，买受人取得所有权`、`或`、`非核心资产转让·审查`、`或`） |
| 借据、判决、结算完整且转移是清偿该债 | 转引擎或对应抵债原子 |
| 受赠人须持续履行义务才给财产 | `附义务的赠与合同·审查` |
| 婚姻家庭中的赠与 | `婚姻家庭中的赠与合同·审查` |
| 近亲属房屋、税率和赡养伦理主线 | `亲属间房屋赠与合同·审查` |
| 不正当关系赠与 | `涉及不正当男女关系的赠与合同·审查` |
| 死后生效、遗赠或遗赠扶养 | `生前类赠与协议·审查` 或 `类赠与遗赠扶养协议·审查` |
| 借用期满返还、保管返还、代持还原 | 转引擎重新定性，不改成赠与 |
| 无可读正文，本类型条件已谈妥，要出己方稿 | `无对价财产转移赠与·起草` |
| 已签未争、只问验收日、过户日、清点日 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `已催告解除索赔诉讼或仲裁→` 或对应专项领域 |
| 债权人已提起撤销、执行异议或逃债刑事立案 | 争议或执行专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

零对价交割正文里夹带一小段有价款资产或一笔典型赠与：专章可继续标拆包；整案买卖、整案典型赠与、整案借贷或整案让与担保交接对应原子。用户坚持本技能把买卖、典型赠与、借贷或让与担保整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿本 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
