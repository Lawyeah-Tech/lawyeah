# 审查方法（锁定 赠与合同 / “不直接支付对价的财产转移” 型赠与合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止打开或复制下列 method：`一般赠与合同·审查`、`公益道德义务性质的赠与合同·审查`、`零对价股权赠与·审查`、`借名购房型赠与·审查`、`文本写到期还本回购担保债权流质或“先过户再还钱把房拿回”→负触发`、`的method。`。

本类型不是“已经承认无偿”的典型赠与改法，也不是借款或让与担保改法。审查主问只有两句：

1. 这份不直接付钱的财产转移，会不会被第 657、658 条当成赠与。
2. 它是不是名赠与、名划转、名交割，实为借贷或让与担保。

### 1.1 定性

支持切开的规范（法律结论须运行时复核）：

- 第 657 条：赠与是将自己的财产**无偿**给予受赠人，受赠人表示接受。
- 第 658 条：权利转移前可任意撤销；公证或依法不得撤销的救灾、扶贫、助残等公益、道德义务除外。

- 民间借贷司法解释（2020 第二次修正）第 23 条：以买卖合同作民间借贷担保的，按民间借贷审理，不按买卖强制过户。名赠与、名划转套同一穿透逻辑。

## 节点 2　无直接对价财产转移的赠与定性（硬闸）

本闸回答：这份文本会不会被第 657 条捕获。不先套任意撤销，先问对价和原因。

### 2.1 对价分层

按材料客观有没有对待给付，不看动机，不看标题。

| 已有事实 | 判断形状 | 本任务动作 |
| --- | --- | --- |
| 价款栏空白、填零，附件无结算、无代偿、无出资，也无借贷叠层 | 可能被 657 捕获 | 按潜在赠与继续；受让人立场必须假设 658 这把刀存在 |
| “对价另议”“友情价零元”“视同已结清”无结算表 | 无偿外观 | 必须改：补原因 + 结算，或改真实价款，或承认赠与 |
| 接收方曾投入资金、代偿贷款、提供劳务、放弃债权、承担债务 | 隐性对价 / 原因 | 必须写成可举证原因条款并附凭证编号，避免被读成“没有任何对价” |
| 有数字价款且拟真实支付 | 有偿 | 负触发买卖原子，不留在本技能改 658 |
| 价款明显偏低但仍有价款 | 有偿 + 539 风险 | 负触发买卖；本任务只告知 539 / 解释第 42 条，不按 658 改 |

第 657 条的“无偿”看有没有对待给付。历史投入、代偿、放弃债权都是原因，不是“再写一句不属于赠与”。

### 2.2 原因条款是防撤销核心

没有原因条款，后文“非赠与”是空话。修改句要求用条目列出：基础关系、发生时间、金额或债务文件、证据编号、本转移是清偿 / 返还 / 出资返还 / 结算后的资产归属中的哪一种。

出让人与原因关系中的债权人、投资人不是同一人：必须解释为什么财产给了非债权人。解释不了：推定赠与风险升高，或主体还原为返还，或回到节点 3 查是不是出借人收走担保物。

### 2.3 定性只能二选一

| 文本写法 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 同时写“本协议为历史投入结算”和“甲方保留任意撤销权” | 红线：二选一 | 既是结算又保留 658 |
| “无偿转让但不属于赠与”无任何事实 | 必须改：补原因或承认赠与 | 否认句已关闭赠与章 |
| 部分资产有历史投入，部分是白送 | 必须拆条款或分协议 | 整包一个定性 |
| 出让人本意就是送，且无借贷叠层 | 承认赠与，保留未转移部分的 658，或去公证 | 继续用转让合同伪装 |

最强反方：出让人主张“合同写了不属于赠与”。回应：法院看资金流和原因，不看否认句。受让人主张“已经结算所以不是赠与”。回应：没有结算表和凭证编号，结算是空话。

## 节点 3　名赠与实借贷 / 让与担保切开（硬闸）

本闸先于 658 改法。命中则本任务不把文本改成“更像赠与”或“更像不可撤销赠与”。

### 3.1 识别信号（满足两项以上，现有依据支持切开）

- 财产零元或“赠与”过户到对方名下，同时存在借款本金、到日期、利率或“占用费 / 资金占用”。
- 约定一定期间后由出让人或其指定人以本金加溢价回购；到期不回购则财产归受让人。
- 出让人过户后仍占有、使用、出租该财产，并向受让人付使用费。
- 另纸借条、收款确认、转账备注“借款”，与零元转移文本并行。
- “先过户作担保，还清再转回”；“风头过了再过回来”。
- 无赠与原因，却约定受让人到期可直接取得所有权，且双方资金流是出借方向出让方。

一项存疑：字段停止，并列赠与推定与借贷 / 让与担保两种形状，不选对用户有利的一版。用户拒绝补资金流：不得写成“现有依据支持纯赠与”。

### 3.2 切开后怎么走

| 已有事实 | 路由 | 本任务不得做 |
| --- | --- | --- |
| 房产买卖或过户合同外壳，价款虚写或零元，真实目的是担保借款 | `文本写到期还本回购担保债权流质或“先过户再还钱把房拿回”→负触发` | 打开其 method；按 658 改任意撤销；把流质改成“赠与完成” |
| 赠与、划转、交割、合作解散等其他外壳，真实目的是借贷 | `的method。` | 删掉借条后按本类型审完 |
| 过户到出借人名下、还本付息、到期赎回的借款主文件 | 点名 `过户担保还本付息主轴可点名`，本任务负触发 | 用赠与公证去“关掉”出借人取回权 |
| 真赠与被对方要求加上回购和利息 | 留本类型；红线删除回购 / 利息，或承认不是赠与并转出 | 把赠与改成可履行让与担保 |

负触发只写判定、完整 Skill ID、最小交接。不填十节实体结论。

### 3.3 为什么不能按赠与改

- 第 146 条：表面赠与 / 无偿划转若是虚假表示，该层无效；隐藏的借贷或担保按借贷、担保规则处理。
- 担保制度解释第 68 条：完成公示的让与担保，债权人请求的是优先受偿，不是赠与项下的终局所有权；流质句无效。
- 第 658 条只管赠与。把担保过户当成赠与，会错误打开或错误关闭任意撤销，也会把清算义务改没。
- 民间借贷司法解释第 23 条：不能请求直接履行“买卖 / 赠与 / 过户”来代替还钱。

最强反方：受让人主张“已经写了赠与，钱是另一笔人情”。回应：资金流、回购、占有使用和到期归属一并看；两份文本冲突必须并列，不能只采赠与页。出让人主张“既然是赠与，我交付前可以随时撤回，不用还钱”。回应：若现有依据支持隐藏借贷，任意撤销不是适格工具。

修改句（仅用于本闸未切出、但文本里误留了借贷词的情况）：删除回购、占用费、到期归对方等句；或承认不是赠与并转出。禁止把流质改写成“双方确认赠与已完成，受让人无需清算”。

## 节点 4　主体、原因关系人、决议与国资

### 4.1 主体表

建表：签约名、登记权利人或占有人、受让人、原因关系中的债权人 / 投资人 / 出借人、授权签字人。名称不一致不自动合并。集团调拨指令不能替代两家公司的机关决议和合同。

代签必须证明其有权放弃对价。口头“我们老板同意了”不得写成已授权。出借人与受让人同一、出让人与借款人同一：回到节点 3。

### 4.2 公司与国资

公司作为出让人的无偿或无账面交易资产转出：必须机关决议；未附则签署能力字段停止。国有资产还须评估、备案或批准程序。

企业国有资产法第 44 条：国有独资企业、国有独资公司、国有资本控股公司不得无偿向关联方提供资金、商品、服务或者其他资产。命中：停笔告知，不改可履行。

关联关系越近，被推定赠与、被认定为让与担保或被债权人攻击的概率越高。修改句要求披露关联关系，不写成“集团内部划转当然有效”。

### 4.3 无权处分与善意取得

物权编解释（一）第 18 条：第 311 条“合理的价格”按标的性质、数量、付款方式和市价综合认定。零对价受让人难以主张善意取得。共有人或登记权利人未全部签署：签署能力字段停止。同意门槛若未核验共有处分全文，字段停止，修改句仍要求权利人全部签署。

## 节点 5　标的清单、负担与权利是否已转移

### 5.1 禁止概括财产

必须清单化：名称、型号、权证、账面价值、评估价值（如有）。业务一揽子交割没有评估或账面净值：既像赠与又像资产买卖漏价，也像把一揽子财产押给债权人，标必须改。撤销范围和返还范围无法确定时，不得宣称审查完成。

### 5.2 权利转移时点

| 标的 | 权利转移 | 未完成时 |
| --- | --- | --- |
| 动产 | 第 208 条要求交付；拟制交付须有约定并完成 | 若被定为赠与，658 窗口打开 |
| 不动产 | 第 209、215 条：记载于登记簿；未登记不影响合同效力 | 交割完成、交钥匙不等于物权变动 |
| 股权、知识产权、需登记权利 | 第 659 条：依法办理手续 | 未登记的“交割完成”只对占有有效 |
| 债权 | 通知债务人 | 未通知不得写成已转移 |

“交割完成”未定义交付或登记：必须改。分批移交：已交部分与未交部分法律效果分开写。受让方审查的第一动作是：如果被当成赠与，权利转移了没有。

`框架.md` 的“验收签署日视为关闭任意撤销”不得直接采用。修改句可写：双方在交付单签字并实际移转占有之日，该部分动产权利转移；仅在验收单签字、货物仍在出让人处的，不视为交付。

若节点 3 已切出让与担保：交付 / 登记只产生担保公示效果，不写成赠与项下所有权终局转移。本任务不代写让与担保清算句，只指出不得按赠与关窗。

### 5.3 负担

抵押、质押、租赁、许可、查封随标的走。材料未提及不得写成“无权利负担”，只能写 `依据不足`。无偿外观加上高负担，更像逃废债或让与担保，回到节点 1.3 / 3 / 6。

## 节点 6　逃债第 538 条

第 538 条：债务人以放弃债权、放弃担保、无偿转让财产等方式无偿处分财产权益，或恶意延长到期债权履行期限，影响债权人债权实现的，债权人可以请求人民法院撤销。一年 / 五年除斥期间运行时核验第 541 条后再写；未核验则期间字段停止。被撤销的效果运行时核验第 542 条；未核验则只写“可能自始无约束力”，不宣告本案已被撤销。

第 539 条与解释第 42、43 条：有价款但明显不合理低价，且相对人知道或应当知道，才走低价撤销；以物抵债也可落入 539。关联关系不受 70% 比例限制。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 用户或文本写明为躲债、规避执行而划转 | 只告知 538；不改可履行结构；用户坚持则整体停止 | 划走后债权人就拿不走；排除 538 |
| 出让人有未了结诉讼或大额负债，文本未披露 | 必须改：声明负债与诉讼；受让人知悉存在被撤销风险 | 未提及就是没有债权人 |
| 受让人问“签了是不是安全” | 判断：依据不足或现有依据不支持“安全” | 无偿受让人善意即可对抗债权人 |
| 有低价但仍有价款 | 切开买卖；告知 539，不按 658 | 低价 = 赠与所以适用任意撤销 |
| 名为赠与、实为过户担保以避开查封 | 节点 3 切开 + 本节点告知；不改可履行规避 | 改成“真实赠与即可对抗执行” |

不得约定排除第 538 条。可约定：若转移被人民法院撤销，双方如何互相返还、分担已发生税费和损失。不在本任务计算一年 / 五年是否届满。

大额无偿转出前做债务声明、通知已知债权人：不消灭第 538 条，但影响过错和时效证据，可写进修改句。

## 节点 7　658 窗口、法定撤销、违约与回转

仅在节点 3 未切出后适用。已被认定为借贷或让与担保的，不要用本节改赠与通知。

### 7.1 一旦可能被认定为赠与

受让人律师必须假设 658 这把刀存在。关闭窗口的合法路径只有：补足原因使交易离开赠与章；改为真实价款走买卖；公证；或尽快完成交付 / 登记。单纯约定不可撤销通常不够。

第 660 条：只有公证或公益道德义务赠与，不交付时才可请求交付。未公证的潜在赠与，不宜用高额逾期移交违约金对抗法定任意撤销。

### 7.2 法定撤销与穷困仅赠与段落适用

第 663 条：严重侵害、不履行扶养、不履行约定义务；知道之日起一年。继承人 / 法定代理人撤销及六个月期间运行时核验第 664 条；未核验则该期间字段停止，修改句仍把该段限定在赠与段落。第 665 条：撤销后可请求返还。第 666 条：经济状况显著恶化可不再履行，仅约束尚未转移部分。

非赠与的违约取回走合同解除和物权返还，不要混用“撤销赠与通知”。真正赠与不要写成买卖式解除。让与担保的取回走债务清偿后返还，不要写成撤销赠与。

### 7.3 违约与争议

非赠与：可约定逾期移交的违约金。赠与且未公证：不宜用高额违约金对抗 658。违约金不是必得金额；禁止“不得调整”。

争议解决：出现仲裁条款，不得改写成“应向某法院起诉”。或裁或诉、机构不明：标待核。只标红旗，不选定唯一法院。

通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。

无价款合同出现“定金”：必须改删除，或改为有真实价款的买卖后另审。出现“定金”同时又有回购 / 借款：回到节点 3。
