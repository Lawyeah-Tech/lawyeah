# 边界与路由

本技能只起草 **婚姻家庭 / 分居协议**。中文展示名必须是「审查分居协议（婚姻家庭）」。禁止在正文写半截场景编号。

主线：合法夫妻在不解除婚姻的前提下分开居住，并安排分居期间住所、生活、子女临时照料和分居期财产债务。不输出离婚协议三块齐审，不以第 1079 条保证必然准离，不把不分居的财产制整案留在本任务。

## 正触发

已有可读待签书面分居协议（或分居期间生活与财产安排协议），尚未签署，尚未成争，核心给付是婚姻存续下的分开居住及分居期间安排，且文本不是解除婚姻一揽子安排。

## 负触发

| 主要目标或文本信号 | 路由 | 不得代做 |
| --- | --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 | 不硬套本类型十节 |
| 已在办离婚，或解除婚姻+子女+财产债务一揽子 | `离婚协议·审查` | 不补自愿离婚句，不按离婚三块齐审，不把本协议改成可登记离婚文件 |
| 婚前或婚内财产制，没有不同住所或搬离安排 | `夫妻财产约定·审查` | 不把分居协议改写成整份 AA 制财产约定交差 |
| 忠诚惩罚金、出轨净身出户为主给付，无分居生活安排 | `夫妻忠诚协议·审查` | 不把惩罚金改成分居津贴交差 |
| 未登记同居者分手财产 | 转引擎重新定性 | 不把同居分手写成第 1079 条分居 |
| 无婚姻关系 | 转引擎；可能是普通共有或分手协议 | 不把无婚同居写成夫妻分居 |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 | 已经完成审查；转通用起草引擎出本类型终稿 |
| 已签，只问搬离、津贴、账户分立 | 本套导航的履约步骤 | 不回写签前意见充作成交 |
| 已起诉离婚、抢夺藏匿子女或债权人追索，且要诉讼策略 | 婚家领域或 `已催告解除索赔诉讼或仲裁→` | 不写诉讼策略，不把起诉材料改成签前分居协议交差 |
| 处分子女名下财产，或授权藏匿子女 | 停笔；监护与儿童保护不得私下处分 | 不改写成可履行划转或藏匿 |
| C 端大众快检或 C 端家事起草 | 只分流，不回改 | 不复制起草模板 |

专业版未收录的 P1 场景不会安装本邻类。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用本类型硬套。

## 本类型内转出（仍可先标风险再停）

- 分居主文中夹带自愿离婚、离婚后直接抚养终局安排、登记离婚程序：离婚块负触发 `离婚协议·审查`，分居块继续。
- 分居主文中夹带整份存续期财产制且住所块缺失：财产制块负触发 `夫妻财产约定·审查`；先补两个住所，否则整案可能被重定性。
- 大额且存在已知债权人或执行案件：告知第 1065 条第 3 款与第 538 条，不设计逃债履行结构。
- 用户要保证签字即离婚、满二年必然准离或债权人不能再追：停止保证，只保留事实摘录与修改句草稿。
- 同一套住宅内分房且用户拒绝改为两个住所：空间闸不能闭合，停止“可以签署为法律分居”建议。
