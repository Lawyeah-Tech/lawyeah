# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受、签字即离婚、分居满二年必然准予离婚或债权人不能再追；编造未给出的门牌、产证号、账号、金额；把已失效《合同法》《婚姻法》《民法通则》《民法总则》写入结论；把分居安排写成已经解除婚姻；把同一套分房写成已经构成法律分居；把子女临时照料写成离婚后终局直接抚养；把“各自生活”写成已完成所有权划分；输出整份新分居协议充作审查成果；输出离婚协议三块齐审表。

## 1. 触发、单方立场与成果状态

立场（夫或妻一方或其代理人）、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查分居协议（婚姻家庭）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》《婚姻法》及其解释、《民法通则》《民法总则》，或“签字即离婚”“满二年必然准离”“分房即分居”口诀时记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `婚姻家庭`，子级 `分居协议`。写明分居安排定性结果，以及与离婚协议、夫妻财产约定、忠诚协议、同居分手的切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读其他类型。知识双文件与 method 冲突时采用 method 核验口径。逃债、放弃监护或藏匿子女写停笔告知，不填可履行的违法结构。

## 4. 主体、婚姻存续、书面形式与文本版本

主体表：双方姓名、证件号是否可见、结婚证字号、行为能力、是否本人签署。必须记录婚姻存续句是否可见。本类型不造“付款名/发票名”空表充数。版本表：正文、住所证明、财产清单、子女临时安排、聊天确认；冲突并列，不选对用户有利的一版。无婚姻：负触发。代签或仅口头：书面/签署字段停止或红线。

## 5. 分居安排闭环

必须分列并回链原文位置。本节不是离婚三块：

1. **婚姻存续**：是否写明不解除婚姻；解除须登记或裁判。
2. **空间**：两个不同门牌或租约号；最后共同生活日、搬离日、分居起始日是否对齐；同一套分房是否被包装。
3. **子女临时安排**：分居期间照料人、探视、费用；是否误写成离婚后终局直接抚养；监护是否被放弃。
4. **既有财产**：分居时点清单；暂不分割或维持共同；禁止擅自处分。
5. **分居期所得**：是否按第 1065 条写成所有权；是否只有“各自生活”。
6. **债务与津贴**：对内承担、告知相对人、不得对抗不知情债权人；津贴金额与账户。

缺口标 `G#`，不补门牌或金额。搬离、公证、登记离婚写成条件或期限，不写成已经完成。

## 6. 强制规范与人身条款

自动离婚、限制离婚、人身交往天价罚则、放弃监护、藏匿子女、倒签起始日、逃债、假分居脚本。强制规范只区分是否导致该条款不发生效力，不宣告整份协议有效或无效。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。公证/见证只标可优化。第 1079 条只作证据与裁判条件告知，不写成必然准离。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔/转出口径。禁止输出无修改句的色块表。

婚姻存续、两个住所、子女临时性至少各有一行（无子女则有否定表述行）；出现自动离婚或对外免责必须有对应行；出现“各自生活”必须有 1065 改写行。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款（住所 / 起始日 / 子女临时 / 既有财产暂不分割 / 分居期 1065 / 债务相对性）、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`，不编造。禁止只给原则、不给句子。禁止用整份范本替换本节。禁止用离婚三块或财产约定加名总表替换本节。

## 9. 谈判与签署提醒

谈判顺序：先红线（自动离婚、同一套冒充分居、放弃监护、藏匿子女、对外免责已成就、人身天价罚则、逃债、代签、倒签），再必须改（两个住所、起始日、子女临时性、1065 所有权用语、清单、债务相对性、搬离期限），最后可优化（公证固定起始日、见证、录像、村居备案）。

签署提醒：双方本人签署并签署日期；结婚证摘录入附件；两个住所证明与清单由双方签认；签署后按约搬离并保留入住或物业记录；公证只固定起始日，不把签字日写成已经离婚。不指导倒签或补假搬离。不把公证写成离婚生效要件。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本起草原子交付草稿、未决项、自审风险表、自审后修改句。未过三闸不得宣称完成。不是履约交底、争议文书、离婚诉讼策略或效力保证，也不是离婚协议或夫妻财产约定审查。
