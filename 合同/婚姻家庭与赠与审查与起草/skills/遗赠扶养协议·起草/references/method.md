本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止打开或复制 `附义务的赠与合同·审查`、`生前类赠与协议·审查` method。禁止套用赠与任意撤销、所附义务法定撤销、遗嘱形式或赡养法定义务免除主线。禁止把本技能写成赠与合同项下“类赠与”或遗赠换标题。

定性校验：核心给付是生养死葬换死后财产，才继续；明显他类则负触发，不填十节实体结论。

本文件是可执行判断节点，不是栏目说明书。每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、房屋必然过户，或唯一必得遗产。

知识库口径冲突以本方法为准，不回写知识正文：

- `基本面.md` 交易结构写“分阶段赠与／生前先行转移部分财产作为奖励”：纠正为本类型不得改成可履行生前过户；滑向赠与则负触发。
- `基本面.md` 写“遗赠人生前有权解除协议”：纠正为非第 658 条任意撤销；须约定或法定／约定事由；解除后果按解释（一）第 40 条分侧。
- 把财产写成“赠与扶养人”：纠正为死后受遗赠，不是赠与。
- “未经公证协议无效”：纠正为公证不是效力要件。
- 第二顺序作扶养人一律无效或一律有效：纠正为字段停止，不得写成必然结论。

开发窗口 2026-08-18 已核验、可供对照但不得代替运行时核验的规则：

- 民法典第 1158 条：自然人可以与继承人以外的组织或者个人签订遗赠扶养协议；对方承担生养死葬，享有受遗赠的权利。
- 民法典第 1123 条：继承开始后，法定继承；有遗嘱按遗嘱或遗赠；有遗赠扶养协议按协议。
- 继承编解释（一）第 3 条：协议与遗嘱无抵触则分别处理；有抵触按协议，抵触的遗嘱全部或部分无效。
- 继承编解释（一）第 40 条：扶养人无正当理由不履行导致解除，不能享有受遗赠权，已付供养费用一般不予补偿；遗赠人无正当理由不履行导致解除，应偿还已付供养费用。
- 民法典第 1122 条：遗产是自然人死亡时遗留的个人合法财产。
- 民法典第 1127 条：第一顺序配偶、子女、父母；第二顺序兄弟姐妹、祖父母、外祖父母。
- 民法典第 1153 条：夫妻共同财产除另有约定外，分割遗产时应先分出配偶一半；家庭共有应先分出他人财产。
- 民法典第 1141 条：遗嘱应为缺乏劳动能力又没有生活来源的继承人保留必要份额。本条是遗嘱规则，不得直接写成协议必然无效或必然击穿。
- 民法典第 1159 条：分割遗产应清偿税款债务，但应为缺乏劳动能力又没有生活来源的继承人保留必要遗产。
- 民法典第 143、144、150、151 条：有效条件；无民事行为能力人实施的行为无效；胁迫可撤销；危困显失公平可撤销。
- 民法典第 657、658 条：赠与是无偿给予；权利转移前可任意撤销（公证或公益道德义务除外）。**仅用于切开，不得适用本协议。**
- 民法典第 1133 条：自然人可立遗嘱处分个人财产或遗赠。单方死因行为，与本协议切开。
- 老年人权益保障法（2018 修正）第 20 条：赡养人之间协议须经老年人同意——用于赡养切开。
- 同法第 22 条：老年人依法处分个人财产；以遗嘱处分应为老年配偶保留必要份额。
- 同法第 36 条：老年人可与集体经济组织、基层群众性自治组织、养老机构等组织或个人签订遗赠扶养协议或其他扶助协议。
- 养老机构管理办法（2020）第 16 条：养老机构应签服务协议。服务合同≠本协议。

本次检索未返回可写入 `L#` 的正文，运行时必须重核、不得凭记忆落法律结论：民法典第 1125 条（受遗赠人丧失受遗赠权）全文；民事诉讼法继承／不动产管辖现行条号。

2. 扶养人身份：
   - 第一顺序：负触发 `赡养协议·审查` 或红线。不得改成可履行本类型。
   - 第二顺序：字段停止。字面“继承人以外”可能排除；有裁判以兄弟姐妹无法定扶养义务为由承认协议。修改句提示该风险，不输出必然有效／无效。
   - 组织：村委会、居委会、养老机构须有决策程序或许可线索。未附决议：字段停止。机构已收全额服务费又主张遗产：红旗双重获利。
3. 遗赠人须本人签署且具有完全民事行为能力。能力不明、病重通知、痴呆线索、隔离签署：该能力字段停止，建议医学评估和录音录像。口头“老人同意了”、子女代签：不得写成已同意。代签、伪造：整体停止。

不足：字段停止，列出待补材料，不补主体、不补已有能力、不补已非继承人。

## 节点 3　对价锁定：生养死葬量化与死后转移（硬闸）

核验后可引用的判断点（须 `search_law` 写入 `L#` 再落法律结论）：

- 扶养人承担生养死葬，享有受遗赠权利。
- 赠与是无偿给予，权利转移前可任意撤销——**不适用于本协议**。
- 财产作为遗产，原则上自死亡时遗留的个人合法财产中转移。

| 文本写法 | 本任务动作 |
| --- | --- |
| 只写“房子归乙方”，无照料、无丧葬 | 必须改。补生养分项和死葬分项，否则对价不足，协议向遗赠或赠与滑动 |
| “照顾好老人”“负责养老”无次数、费用、居住 | 必须改。量化：居住条件、每月生活费【待填】、每周探视【待填】次、小病／大病分担、护理安排 |
| 仅给付金钱、明确不上门 | 红旗。可能是金钱养老或附条件遗赠，不当然无效，但解除和优先效力论证变弱；修改句补照料或改定性分流 |
| “签订之日过户／公证后即转移所有权” | 红线。改回去世后转移；用户坚持即时过户 → 负触发赠与族 |
| “甲方可随时撤销，视同赠与” | 红线。删除第 658 条路径；写明双方不得任意撤销 |
| 用户要求保留即时过户以便“先把房拿到手” | 整体停止该结论 |

死后转移句最低要素：触发时点（死亡）；清算／税款债务；凭协议和死亡证明办理转移登记；登记原因是受遗赠（遗赠扶养）不是赠与。缺一项补一项。

## 节点 4　财产范围、共有先析、生前处分与居住

1. 财产须特定化：房产坐落与证号、存款线索、车辆、其他动产。禁止“全部家产”无清单。
2. 权属：仅处分遗赠人个人合法财产或共有中自己的份额。夫妻共同财产未先析：超出配偶份额的部分不得写成有效处分。材料未出示权属：处分能力字段停止。
3. 抵押、查封、居住权、租赁：材料未提及不得写成“无权利负担”。查封或禁止流通：红线，不写可履行死后过户。
4. 协议期间遗赠人处分限制：可约定不得擅自出售、抵押、赠与清单内重大财产。已完成登记的第三人善意取得，扶养人主要走违约、解除和补偿，不得写成当然对抗。
5. 居住：标的房屋通常为遗赠人保留终身居住或使用，扶养人不得在遗赠人生前驱逐。未写居住：必须改。
6. 签约后新增财产：建议约定除非另有约定不属于遗赠范围。
7. 生前变卖用于医疗：扶养人承担死后无遗产的商业风险。修改句可约定重大处分通知和补偿，不保证仍有房可给。

## 节点 5　优先效力、既有遗嘱与多份协议（硬闸）

继承开始后，有遗赠扶养协议的按协议办理。协议与遗嘱无抵触则分别处理；有抵触按协议，抵触的遗嘱全部或部分无效。这不是“另立公证遗嘱即可推翻协议”。

| 文本写法 | 本任务动作 |
| --- | --- |
| 未声明与既有／嗣后遗嘱的关系 | 必须改。鉴于或专门条款写明：本协议优先；抵触的遗嘱相应无效 |
| 正文允许遗赠人“随时另立遗嘱处分本协议财产” | 红线。与优先效力冲突 |
| 用户材料出现另一份遗赠扶养协议或生前赠与 | 并列 `D#`；多份协议给不同扶养人红旗；不选对用户有利的一版 |
| 把优先效力写成“子女不能起诉” | 必须改。优先不等于禁止起诉；准备履约证据 |

公证能固定意愿和能力，不是优先效力的前提。不得写未经公证则协议劣后于遗嘱。

## 节点 6　解除分侧、履行留痕与必留份红旗

1. 解除须有约定程序（书面通知、异议期）和事由（连续不履行满【待填】日、虐待遗弃、拒绝受领扶养、擅自处分致履行不能）。禁止“任何一方随时解除且互不补偿”。
2. 分侧后果必须写清，并在核验后引用解释（一）第 40 条：
   - 扶养人无正当理由不履行：不能受遗赠，已付费用一般不补偿；
   - 遗赠人无正当理由不履行：偿还已付供养费用；可另约定合理劳务补偿，但不得写成必然法院支持的固定高额。
3. 履行留痕：医疗单据、生活费转账、探视记录、护理日志由扶养人保存；遗赠人可指定监察人。只写“依法履行”视为必须改。
4. 必留份／老年配偶必要份额：有缺乏劳动能力又没有生活来源的继承人，或老年配偶线索：字段停止。1141 是遗嘱规则，1159 是分割遗产时保留，22 条是遗嘱处分应为老年配偶留份。不得写本协议必然全部击穿或必然让路。
5. 扶养人先于遗赠人死亡：组织可约定承继；个人未约定备选则受遗赠权可能落空。修改句补备选或解除清算。

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止；
- `必须改`：可谈但签署前要落句；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级唯一住房被全部遗赠且用户拒绝升级：停止“可以签署”建议。

争议解决：考虑到遗赠人年迈，建议遗赠人住所地或不动产所在地法院。专属管辖条号运行时核验，不选定唯一法院充作法律意见。或裁或诉、机构不明：标待核。

## 版本冲突

正文、财产清单、既有遗嘱、其他扶养协议、权属证书、聊天确认冲突时：

1. 并列 `D#` / `C#`，不选对用户有利的一版。
2. 修改句写明冲突项以哪一份为准，或删除冲突句。
3. 不得在意见里悄悄采用有利版本并称“合同已明确”。
