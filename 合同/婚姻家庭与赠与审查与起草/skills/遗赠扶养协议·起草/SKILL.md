# 遗赠扶养协议·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **婚姻家庭 / 遗赠扶养协议**，输出可编辑草稿、未决项，并在出稿后用本类型硬闸自审。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「审查遗赠扶养协议（婚姻家庭）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查、从零起草、履约交底、争议文书、协议或过户有效性保证、把本约改成可即时过户的生前赠与、把本约改成可随时撤回的遗嘱或遗赠、把子女“生养死葬换房产”改成可履行本类型。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿；尚未签署，尚未成争；核心给付是**生养死葬换死后财产**——扶养人承担生活照料、医疗陪护、精神慰藉和丧葬安葬，财产所有权原则上自遗赠人死亡时起才可能转移。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 签字或公证后即过户、即时转移所有权、按赠与任意撤销，或义务显著轻于财产且生前交付为主 → `附义务的赠与合同·审查`、`房产赠与合同·审查` 或对应赠与原子；专业版未收录时输出 `unavailable`，不得用本技能改成可履行生前赠与；
- 单方死因处分、可另立遗嘱撤回、无扶养对价 → `遗嘱·审查`；赠与合同项下“死后过户类赠与”文本 → `生前类赠与协议·审查`；
- 扶养人是配偶、子女、父母等第一顺序法定继承人，真实结构是落实法定义务 → `赡养协议·审查`；
- 标题写遗赠扶养，但父级被当成赠与合同下的“类赠与”且用户只要赠与编规则 → 转引擎重新定性，不得打开赠与族 method 换皮；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问探视记录、医疗费报销、死后过户预约 → 本套导航的履约步骤；
- 已成争（继承人起诉无效、解除、未尽义务诉讼、立案仲裁）→ 家事或合同争议领域。

伪造能力鉴定、代签、胁迫签署、借名规避限购、把查封/小产权/他人财产改成可死后过户：只出告知，不改写成可履行结构。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成。每一闸必须给出修改句或明确转出口径，禁止只打红黄绿。

1. **生养死葬换死后财产**。必须同时读出：扶养人承担生养（住、食、衣、医、陪护、精神慰藉）和死葬（丧事、安葬、费用）；遗赠财产在遗赠人**去世后**才可能转移。修改句把鉴于改成：因遗赠人需要生养死葬安排，扶养人愿意承担该义务，双方以扶养为对价，约定财产于遗赠人死亡并完成清算后转移，互为对价，不适用赠与任意撤销。只写“照顾好老人”或只写“房子归你”视为未约定对价，必须量化。
2. **与生前赠与切开**。原文“签订之日过户”“公证后即转移所有权”“甲方可随时撤销赠与”“受赠人先办理产权”：负触发赠与族，或红线改回死后转移。禁止打开或复制 `附义务的赠与合同·审查`、`生前类赠与协议·审查` method，禁止套第 658 条任意撤销、第 661 条所附义务、公证关闭撤销权作为本类型主路径。知识库“分阶段赠与／生前先行转移部分财产作奖励”不得改成可履行结构。
3. **与遗嘱／遗赠切开**。单方意思、见证人格式、可另立遗嘱撤回、无扶养对价 → 负触发 `遗嘱·审查` 或 `生前类赠与协议·审查`。修改句写明：本协议是双方法律行为，非经双方同意或约定／法定事由不得单方变更；此后所立遗嘱与本协议抵触的，抵触部分按协议办理。不得把本约改成可随时撤回的遗嘱。
4. **扶养人须为继承人以外**。第一顺序（配偶、子女、父母）作“扶养人”：通常不构成本协议，负触发 `赡养协议·审查` 或红线改主体。第二顺序（兄弟姐妹、祖父母、外祖父母）字面属于法定继承人；有裁判以无法定扶养义务为由承认协议，**不得写成必然有效或必然无效**，该身份字段停止并提示风险。禁止把子女“不签字就不用养”改成可履行免责。
5. **死后转移，严禁即时赠与措辞**。必须写清所有权自遗赠人去世之日起转移；生前保留居住或使用。把“签订后即转移”写成现行规则或可放行结构：红线。
6. **不得按赠与任意撤销；解除分侧处理**。本协议不是第 658 条赠与。扶养人无正当理由不履行导致解除：不能享有受遗赠权，已付供养费用一般不予补偿。遗赠人无正当理由不履行导致解除：应偿还已付供养费用。只写“任何一方可随时解除且互不补偿”视为必须改。

附加必落句（有事实则单列，无事实在缺口节说明）：

- **财产范围**：概括+列举；仅处分个人合法财产或共有中自己的份额；新增财产除非另有约定不属于遗赠范围。
- **必留份红旗**：存在缺乏劳动能力又没有生活来源的继承人，或老年配偶必要份额线索时，字段停止，不得写“协议必然全部击穿保留份”或“协议必然给必留份让路”。
- **履行留痕**：医疗费、生活费、探视、护理记录由谁保存；继承人异议时由谁举证。
- **公证／见证**：公证不是效力要件，但能力与意愿争议高发；不便公证则两名以上无利害关系人见证并录音录像。不得写“未经公证无效”。

必须有修改句。每个风险回链文本位置。禁止套用赠与任意撤销、遗嘱形式、赡养法定义务免除节点。禁止复制 `附义务的赠与合同·审查` 或 `生前类赠与协议·审查` method。

## 建立审查坐标

确认：使用者与授权；单方立场（遗赠人、扶养人个人、扶养组织、拟签字共有人或配偶择一）；相对方；全文及财产清单／扶养标准附件版本；双方亲属关系；遗赠人行为能力与沟通环境；生养死葬具体内容；拟遗赠财产权属、共有、抵押查封；既有遗嘱、赠与、其他扶养协议；必留份或老年配偶线索；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 起草模式

本原子只承担本类型起草。待签评改转 `遗赠扶养协议·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。缺数字用 `【待填】`，不编造。出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 生养（住、食、衣、医、陪护、精神慰藉）和死葬（丧事、安葬、费用）量化；只写“照顾好老人”或只写“房子归你”视为未约定对价。
- 双方以扶养为对价，财产于遗赠人死亡并完成清算后转移；互为对价，不适用赠与任意撤销。
- 本协议是双方法律行为，非经双方同意或约定／法定事由不得单方变更；此后所立遗嘱与本协议抵触的，抵触部分按协议办理。
- 所有权自遗赠人去世之日起转移；生前保留居住或使用。
- 解除分侧：扶养人无正当理由不履行导致解除，不能享有受遗赠权，已付供养费用一般不予补偿；遗赠人无正当理由不履行导致解除，应偿还已付供养费用。
- 财产范围概括+列举；仅处分个人合法财产或共有中自己的份额。

### 附件必附

- 财产清单。
- 扶养标准附件。
- 权属证明；共有先析材料（如有）。
- 能力与意愿留痕：公证不是效力要件；不便公证则两名以上无利害关系人见证并录音录像。

### 禁止出现

- “签订之日过户”“公证后即转移所有权”“甲方可随时撤销赠与”“受赠人先办理产权”。
- 第 658 条任意撤销作为本类型主路径；把本约改成可随时撤回的遗嘱。
- 第一顺序（配偶、子女、父母）作扶养人；子女“不签字就不用养”的可履行免责。
- “任何一方可随时解除且互不补偿”。
- “未经公证无效”；“协议必然全部击穿保留份”或“协议必然给必留份让路”。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口，不代替节点。

0. 签署状态与成果分流
1. 类型识别与单目录加载（生养死葬＋死后财产；切开赠与／遗嘱／遗赠／赡养）
2. 主体、继承人身份、行为能力、组织决议
3. 对价锁定：生养死葬量化与死后转移
4. 财产范围、共有先析、生前处分限制与居住
5. 优先效力、既有遗嘱与多份协议
6. 解除分侧、履行留痕、必留份红旗
7. 按框架六步出修改句

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、代签、伪造能力鉴定或见证人、把第一顺序继承人改成可履行本类型以规避赡养、把签约即过户改成可履行、保证协议必然有效或房屋必然过户。
- `字段停止`：法域未核验；遗赠人行为能力不明；扶养人是否属于法定继承人无法判断；财产是否个人所有无法识别；第二顺序作扶养人；必留份或老年配偶必要份额线索未闭合。
- `目标停止`：主目标已变为从零起草、履约交底、继承诉讼文书，或用户要把本约改成生前赠与或可随时撤回的遗嘱。

生存级唯一住房被全部遗赠且用户拒绝升级：停止“可以签署”建议。
