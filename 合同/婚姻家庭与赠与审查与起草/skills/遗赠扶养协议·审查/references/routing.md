# 边界与路由

本技能只审查 **婚姻家庭 / 遗赠扶养协议**。

必须同时读出生养死葬合意，以及财产在遗赠人死后才可能转移。标题叫“遗赠扶养”但其实是签字即过户的赠与、单方遗嘱，或子女落实法定义务的，不得留在本技能做实体结论。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或标题遗赠扶养、核心给付明显不是生养死葬换死后财产 | 本套导航的类型切开步骤 |
| 签字／公证后即过户，或按赠与任意撤销、所附义务撤销 | `附义务的赠与合同·审查` 或 `房产赠与合同·审查`；专业版未收录时输出 `unavailable`，不得硬套本技能改成生前赠与 |
| 死后给财产但无扶养对价，或赠与合同项下“死后过户类赠与” | `生前类赠与协议·审查` |
| 单方遗嘱、见证人格式、可另立遗嘱撤回 | `遗嘱·审查` |
| 第一顺序继承人落实法定赡养，房产只是背景 | `赡养协议·审查` |
| 赠与合同父级下的“类赠与遗赠扶养”且用户只要赠与编规则 | 转引擎重新定性；不得打开赠与族 method |
| 养老机构格式服务合同，不处分遗产 | 告知服务协议路径；不在本任务改写成遗赠扶养 |
| 无文本、本类型条件已谈妥、要出己方稿 | `遗赠扶养协议·起草` |
| 已签未争、问照料记录或死后过户进度 | 本套导航的履约步骤 |
| 已成争 | 家事或合同争议领域；不写确认协议有效诉状、过户申请书 |
| 用户只要遗产份额终局数字 | 继承整理或过户专项；本技能只审条款 |
| C 端大众快检 | 只分流，不回改 |

同一文本既写“签订后过户”又写“生养死葬”：按核心时点切开。权利转移发生在生前 → 赠与族。权利转移发生在死后且有扶养对价 → 留本技能。两可且无法判断：负触发引擎，不灌两套知识。

第一顺序作扶养人、伪造能力、倒签、借名规避限购：停笔告知，不改写成可履行文本。

禁止在正文写半截 Skill ID。转出时必须写完整 ID，例如 `附义务的赠与合同·审查`、`生前类赠与协议·审查`、`遗嘱·审查`、`赡养协议·审查`。
