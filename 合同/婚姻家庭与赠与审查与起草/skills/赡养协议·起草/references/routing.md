# 边界与路由

本技能只起草 **婚姻家庭 / 赡养协议**。主线是成年子女等法定义务人对老年人就经济供养、生活照料和精神慰藉作具体分工，协议不得免除法定义务。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 配偶互扶、兄弟姐妹扶养、父母对未成年或不能独立生活子女的抚养 | `扶养抚养协议·审查` |
| 解除婚姻＋子女直接抚养＋夫妻财产分割为主文 | `离婚协议·审查` |
| 分割现有家庭财产、宅基地、共有房产为主 | `分家析产协议·审查` |
| 变更直接抚养方或探视安排为主 | `抚养权变更协议·审查` |
| 夫妻分居安排为主 | `分居协议·审查` |
| 夫妻财产制约定为主 | `夫妻财产约定·审查` |
| 继承人以外的组织或个人以生养死葬换死后财产 | 本套导航的类型切开步骤（遗赠扶养，不硬套本原子） |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、问打款日／轮住交接 | 本套导航的履约步骤 |
| 已成争：催告给付赡养费、起诉、立案、虐待遗弃 | 家事或合同争议领域；不填签前十节 |
| 伪造老人同意、倒签、可履行免责、可履行限婚 | 停笔告知，不改写成可履行规避结构；用户坚持则整体停止 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

专业版未收录的邻类不会作为本原子的实体审查对象。若用户拿这些文本来找本技能：输出 `unavailable` 或负触发路由，不得用本类型硬套。

本技能不得转去加载扶养／抚养、离婚协议或分家析产双文件完成本类型审查，也不得把离婚登记生效、抚养费月收入比例或遗赠扶养优先效力写成赡养协议默认主路径。
