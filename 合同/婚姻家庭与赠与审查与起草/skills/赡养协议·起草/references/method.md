# 审查方法（锁定 婚姻家庭 / 赡养协议）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型，禁止打开扶养／抚养、离婚协议、分家析产或遗赠扶养双文件“对照一下”。

本文件是**法定义务人对老年人落实赡养分工**的签前判断节点，不是栏目说明书，也不是离婚登记清单或抚养费测算表。禁止把离婚登记生效、冷静期、夫妻共同财产分割、抚养费月收入百分之二十至三十写入本类型默认结论。

每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、一次性费用永远不得再诉或唯一必得金额。

`search_law` 返回已失效《合同法》及其解释、1996 年《老年人权益保障法》第十五条、2009 年《老年人权益保障法》第十六条、1992 年《批量办理赡养协议公证细则》、1985 年继承法意见时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突。

示范文本只参考结构。司法行政或村委赡养示范文本不证明本约条款已被接受。

### 双文件使用（标题与文件名不完全对应时不拒跑）

同目录两份知识文件按标题语义使用，不回改正文，不因文件名拒跑：

- 含“首部 / 交易条款 / 配套 / 尾部 / 语言”的当框架级条款清单，供节点 8 出句；

## 节点 1　类型识别与负触发

### 1.1 本类型正像

同时满足才继续：

- 被赡养人是父母或其他依法应受赡养的老年人（含子女已死亡或无力赡养时、有负担能力的孙子女对外祖父母／祖父母）；
- 核心给付是把法定赡养义务**具体化**：经济供养、生活照料、精神慰藉的分工和标准，而不是解除婚姻、分割现房或抚养未成年子女；
- 协议空间是履行方式，不是免除义务。

标题写成“养老协议”“子女分担协议”“孝道合同”只是线索。名实不符按核心给付归类，标题冲突写入 `C#`。合同编通则解释第十五条：不拘泥名称。

### 1.2 必须切开（禁止两套知识）

| 信号 | 归入 | 本技能动作 |
| --- | --- | --- |
| 给付对象是未成年或不能独立生活的子女；或配偶互扶；或兄弟姐妹扶养 | 扶养＿抚养协议 | **负触发** → `扶养抚养协议·审查`。不得把抚养费 20%–30% 带进本任务 |
| 主文解除婚姻、直接抚养、夫妻共同财产和债务 | 离婚协议 | **负触发** → `离婚协议·审查`。不得抄登记生效、冷静期主路径；离婚文本里夹带“谁养父母”的句子不构成本任务正触发 |
| 主给付是现在就分房、分地、分存款 | 分家析产协议 | **负触发** → `分家析产协议·审查` |
| 变更直接抚养方或探视 | 抚养权变更协议 | **负触发** → `抚养权变更协议·审查` |
| 夫妻分居后的居住与开销，对象不是老年人赡养 | 分居协议 | **负触发** → `分居协议·审查` |
| 夫妻财产制约定为主 | 夫妻财产约定 | **负触发** → `夫妻财产约定·审查` |
| 扶养人是继承人**以外**的个人或组织，对价是死后财产 | 遗赠扶养 | **负触发** → 本套导航的类型切开步骤。子女对父母“生养死葬换房产”不得改写成可履行遗赠扶养 |

扶养／抚养误入是硬闸：一旦核心给付滑入上述结构，立即停笔转出。不得删掉未成年子女抚养条款后继续当赡养审。

### 1.3 加载协议

只打开本目录 `基本面.md` 与 `框架.md`。禁止读 `types/` 或其他场景原子目录。

### 1.4 违法或侵害结构停笔（本类型，不是施工挂靠）

出现下列任一结构，只出告知，不改写成可履行文本：

- 伪造老人签字、代无／限制民事行为能力老人“同意”，或倒签日期以改变给付起算；
- 把放弃继承、断绝关系、父母偏心、老人再婚写成可履行免责；
- 把“不得再婚／不得离开某地／不得见某子女”写成可履行；
- 把子女改成遗赠扶养人，用死后房产换免除在世赡养；
- 不支付费用、不安排照料，把老人推给福利院或基层组织了事；
- 侵占、过户或抵押老人住房、存款作为签字对价，且老人未独立同意。

用户坚持“改到能签／能让某子女彻底不用养／能拦住老人再婚”：整体停止。合规改道（真实分工、另立遗嘱、另签遗赠扶养须主体适格）只点名，不在本任务起草规避方案。

## 硬闸 A　赡养法定义务不得免除

本闸改变能否放行。

1. **法定性**  
   第二十六条第二款：成年子女对父母负有赡养、扶助和保护的义务。第一千零六十七条第二款：成年子女不履行赡养义务的，缺乏劳动能力或者生活困难的父母，有要求成年子女给付赡养费的权利。老年人权益保障法第十九条：赡养人不得以放弃继承权或者其他理由拒绝履行赡养义务。继承编解释（一）第三十二条：继承人因放弃继承权致其不能履行法定义务的，放弃继承权的行为无效。  
   **修改句**：`删除“乙方放弃继承权后不再承担任何赡养义务”及同类免责。各方确认：赡养是法定义务，不因放弃继承、声明断绝关系、父母过往抚养厚薄或本协议未签字而消灭。本协议只约定履行分工。乙方仍应按第【待填】条支付赡养费人民币【待填】元／月，并按第【待填】条分担照料。未在本协议签字的子女，其法定赡养义务不受本协议减免。`

2. **婚姻关系变化不终止**  
   第一千零六十九条、老年人权益保障法第二十一条：子女对父母的赡养义务，不因父母的婚姻关系变化而终止／消除。  
   **修改句**：`删除“母亲再婚后子女不再赡养”。被赡养人离婚、再婚或婚后生活变化，不减轻或免除任何一方的赡养义务。再婚后新增共同生活费用，由各方按第【待填】条协商追加，协商不成的，不停止原约定给付。`

3. **未签字子女**  
   协议只约束签字方的分工，不能免除未签字子女的法定义务，也不能把未签字人的份额当然转嫁给签字人且不得追偿。  
   **修改句**：`本协议列明的法定赡养义务人：【甲、乙、丙】。已知未签字的【丁】仍负法定赡养义务。签字方内部按第【待填】条分担；任一方为老人垫付超过自己份额的，有权向其他法定义务人追偿，该追偿不得对抗老人的请求权。各方应在【待填】日前书面通知【丁】并邀请其补签。`

4. **最强反方**  
   义务人可主张自己缺乏负担能力、老人有稳定收入暂不需要，或某笔费用已由其他子女付清。签前仍不得把免责写成可履行；负担能力只影响数额字段，不影响义务是否存在。

核验失败：免除条款的效力法律结论字段停止；删除免责、改回分工的修改句草稿继续。

## 硬闸 B　费用标准

1. **必须写到可履行**  
   第一千零六十七条给出的是请求权，不是固定比例。费用应结合老人实际需要、当地生活水平和子女负担能力约定，**不得**把婚姻家庭编解释（一）第四十九条的抚养费百分之二十至三十写成赡养法定标准。  
   **修改句**：`经济供养分项如下，缺项不得用“负责养老”代替：〔1〕生活费（含水电、物业、日常饮食）每人每月人民币【待填】元，于每月【待填】日前转入账户【待填】；〔2〕医保报销后的自费医疗、挂号和检查费，按甲【待填】%、乙【待填】%、丙【待填】% 分担，单笔超过人民币【待填】元的，先由紧急联络人垫付，【待填】日内结算；〔3〕护工费、营养费是否包含在住院费内，以本条列明为准，未列明的另行书面确认。上述金额根据被赡养人实际需要、当地生活水平和各子女负担能力约定，不引用未成年子女抚养费比例。`

2. **禁止一次性买断终局**  
   民诉解释第二百一十八条：三费案件裁判生效后，因新情况、新理由可再诉增减。协议更不能锁死老人请求权。  
   **修改句**：`删除“一次性给付十年赡养费人民币【待填】元后，被赡养人及其继承人永远不得再请求增加或另行给付”。已支付的款项可抵扣对应期间的生活费。出现物价显著上涨、被赡养人失能、重大疾病或义务人收入重大变化的，任何一方可书面要求在【待填】日内重新协商数额；协商不成的，不停止按本协议已约定标准继续履行，也不排除依法另行请求调整。`

3. **医疗与失能阶梯**  
   老年人权益保障法第十五条：及时治疗和护理；对经济困难的老年人应当提供医疗费用；不能亲自照料的，可以按照老年人的意愿委托他人或者养老机构。健康期与失能期应分列。  
   **修改句**：`被赡养人生活能够自理期间，以本条生活费为主。经医疗机构或书面评估确认生活不能自理的，各方应在【待填】日内按被赡养人意愿选定共同居住照料、轮流照料或委托护工／养老机构，费用按甲【待填】%、乙【待填】%、丙【待填】% 分担。委托机构不得免除各方探望和费用义务。`

4. **最强反方**  
   义务人可主张约定数额已明显高于需要与负担能力，或老人有退休金、医保。签前把调整机制写成必须改，不得写成“写了定额就永远不能动”，也不得编造当地低保数字。

核验失败：买断是否“不得再诉”的法律结论字段停止；分项金额和调整句草稿继续。

## 硬闸 C　与扶养／抚养切开

本闸改变能否留在本任务。

1. **对象与方向**  
   赡养：晚辈对老年人。抚养：父母对未成年或不能独立生活的子女（第一千零六十七条第一款）。扶养：夫妻（第一千零五十九条）或符合条件的兄弟姐妹（第一千零七十五条；老年人权益保障法第二十三条）。隔代：第一千零七十四条——孙子女赡养祖父母以“子女已死亡或无力赡养＋孙子女有负担能力”为条件；反过来祖父母抚养孙子女是抚养方向，走 `扶养抚养协议·审查`。  
   **修改句（仅在仍主张本类型、尚未转出时用于逼清定性）**：`本协议仅安排【被赡养人姓名】作为老年人的赡养事项。删除关于未成年【孙子女／子女】抚养费、探视和直接抚养的条款；该部分应改签抚养或扶养协议，本任务不审。删除配偶之间“互相扶养、按月给付扶养费”的主给付；如核心是夫妻扶养，本任务停止并转出。`

2. **离婚文本夹带养父母**  
   离婚协议里写“婚后各自赡养自己父母”而主文仍是解除婚姻和分割财产：负触发 `离婚协议·审查`，不在本任务删改离婚登记条款后继续。  
   **修改句（误入一句、其余确为子女间赡养时）**：`如各方仅就父母赡养单独成篇且不依赖离婚登记生效，则保留本赡养分工，并写明：本协议的成立和履行不以任何一方离婚登记为条件。如本文件同时处理解除婚姻、子女抚养和夫妻财产，应整件转离婚协议审查，本任务停止。`

3. **最强反方**  
   同一家庭可能同时存在赡养父母和抚养未成年子女。签前按主给付分流，两套都要审时先完成本类型能处理的段落，另一套点名转出，禁止灌入两套知识。

## 硬闸 D　人身与婚姻自由不得限制

1. **再婚与婚后生活**  
   第一千零六十九条、第一千零四十一条、第一千零四十二条、老年人权益保障法第二十一条：不得干涉老年人离婚、再婚及婚后生活。第一百五十三条第二款：违背公序良俗的民事法律行为无效。  
   **修改句**：`删除“被赡养人不得再婚，再婚则丧失本协议项下住房和赡养费”及“不得离开【某村／某子女家】”。被赡养人的婚姻自由、居住和出行自由不受本协议限制。再婚或迁居不构成任何一方停止赡养的理由，也不导致已约定住房使用权当然丧失。`

2. **以探视为对价**  
   不得约定“不给钱就不得见老人”或“老人不得见未付钱的子女”。探望和费用都是义务／权利安排，不能互相消灭。  
   **修改句**：`删除“未按月支付赡养费的一方不得探望被赡养人”及“被赡养人不得与【某子女】往来”。费用按硬闸 B 追索；探望按硬闸 E 履行。任何一方不得阻挠被赡养人与其他子女或配偶见面。`

3. **最强反方**  
   家人可主张限制外出是为医疗安全。修改句可写合理陪护和紧急联系，不得写成禁止离开某地。

用户坚持保留可履行限婚或禁足：整体停止。

## 硬闸 E　经济供养／生活照料／精神慰藉三分列

1. **法定三要素**  
   老年人权益保障法第十四条第一款：经济上供养、生活上照料和精神上慰藉，并照顾特殊需要。第十八条：与老年人分开居住的家庭成员应当经常看望或者问候。只给钱不等于已全面履行。  
   **修改句**：`各方义务分列，不得互相替代：〔1〕经济供养见第【待填】条；〔2〕生活照料：被赡养人居住于【地址／轮住顺序及每期【待填】日】，日常起居由【姓名】负责，住院期间值班表见附件；不能亲自照料的，按被赡养人意愿共同出资聘请护工或入住机构；〔3〕精神慰藉：不与被赡养人共同生活的一方，至少每【待填】看望或视频问候一次，春节、中秋和被赡养人生日应当探望，除非被赡养人书面表示不需要。任何一方不得主张“已支付生活费即不再照料、不再探望”。`

2. **住房**  
   第十六条：妥善安排住房，不得强迫居住或迁居条件低劣的房屋；不得侵占或擅自改变老人自有或承租住房的产权、租赁关系；对老人自有住房有维修义务。  
   **修改句**：`被赡养人现住房【地址、产权／承租】由被赡养人继续使用。任何一方不得擅自过户、抵押、转租或更换门锁。需要维修的，费用按第【待填】条分担。不得安排被赡养人迁入【未达当地基本居住条件的处所】。`

3. **紧急联络人**  
   框架常见缺陷：未指定首位响应人。  
   **修改句**：`指定【甲】为紧急联络人和医疗沟通的第一联系人，联系电话【待填】。被赡养人意识清楚时，诊疗方案以被赡养人意愿为准；不能表达时，紧急联络人应在【待填】小时内通知其他子女，费用仍按第【待填】条分担。本指定不授予单方处分被赡养人房产或存款的权限。`

4. **最强反方**  
   远居子女可主张以较高费用替代高频探望。修改句允许协商频率，但不得删除精神慰藉整项。

## 硬闸 F　死后余财与遗赠扶养不得混入

1. **本约不处分遗产**  
   第一千一百五十八条：遗赠扶养的相对方是**继承人以外**的组织或个人。子女对父母的生养死葬是法定义务，通常不构成遗赠扶养。老年人权益保障法第二十二条：老年人对个人财产依法处分，子女不得侵占。  
   **修改句**：`删除“丙负责生养死葬，被赡养人去世后房屋和存款归丙所有，乙不再赡养”及“死后余财归签字方”。本协议不处分被赡养人遗产，不构成遗赠扶养协议。被赡养人可以依法另行订立遗嘱。遗产分配时，对被赡养人尽了主要扶养义务的一方可以依法请求多分，不尽义务的可以少分或不分，但遗产份额不是免除在世赡养的对价。`

2. **遗产倾斜可以提示，不能写成唯一先决条件**  
   第一千一百三十条允许尽主要义务者多分。框架禁止把“履行赡养＝唯一继承条件”。  
   **修改句**：`如被赡养人书面表示愿意在遗嘱中对主要照料方予以倾斜，应另立遗嘱，不在本协议设定“不履行则丧失继承权、履行则独占遗产”。是否丧失继承权依法定事由认定，本协议不作预判。`

3. **最强反方**  
   主要照料方可主张口头答应过房子。签前仍须把死后处分从本约剥离；不认定口头遗赠已成立。

用户坚持把子女写成可履行遗赠扶养以规避法定义务：整体停止。

---

## 硬闸 G　老人意愿与行为能力

1. **同意是协议要件**  
   老年人权益保障法第二十条：经老年人同意，赡养人之间可以就履行赡养义务签订协议；内容不得违反法律的规定和老年人的意愿。只有子女互签、老人不知情或明确反对：该协议对老人的拘束字段停止。  
   **修改句**：`被赡养人【姓名】确认：已阅读本协议全部条款，对居住方式、费用标准和照料安排表示同意，并亲笔签名（或在【见证人／基层组织】见证下面签、按指印）。未经被赡养人同意的条款，不得对被赡养人主张。赡养人之间仍可就内部追偿达成合意，但不减免对被赡养人的法定义务。`

2. **行为能力**  
   材料显示痴呆、无／限制民事行为能力或正在申请认定：同意字段停止，不得写成子女代签即视为老人同意。监护人处分住房、存款另受监护规则约束，本任务不编造已获批准。  
   **修改句**：`签署前应核实被赡养人是否具有相应民事行为能力。如已被认定为无或者限制民事行为能力，本协议中涉及其同意的条款停止签署，应依法由监护人在符合被赡养人利益的范围内表示，并不得借本协议转移其住房或存款。本任务不认定行为能力，也不出具监护许可。`

3. **公证与见证**  
   知识稿“公证最高证据效力”降级：公证或基层见证是证据补强和监督履行（第二十条第二款），不是成立要件，也不是法定最高效力。司法确认以人民调解等法定程序为前提，签前不得写成“本合同已有强制执行力”。  
   **修改句**：`建议在村（居）民委员会见证下签署，或办理公证，作为同意和内容的证据，不作为本协议成立的法定条件。各方不得把“未公证则协议无效”或“已公证即不得再调整赡养费”写入正文。发生争议后如走人民调解并依法申请司法确认，另行办理，本协议签字当日不视为已获执行名义。`

4. **最强反方**  
   子女可主张老人“早就点头”。无书面或视听痕迹则同意字段 `依据不足`，不补写成已同意。

## 节点 2　主体、授权、亲属关系

1. 建主体表：被赡养人；各子女及收养／继子女关系；隔代义务是否具备第一千零七十四条条件；协助履行的配偶；未签字子女；紧急联络人。名称不一致不自动合并。
2. 继子女：须有受继父或继母抚养教育的事实才适用父母子女关系（第一千零七十二条）。事实不明：该义务人字段停止，不写成当然有或当然无。
3. 儿媳、女婿：第十四条第三款为**协助**赡养人履行，原则上不因签字成为独立法定赡养义务人。可请其签署协助条款，不得写成“儿媳独立承担全部赡养并免除子女”。
4. 口头“家里都同意了”不得写成老人已同意或某子女已授权。

不足：字段停止，列出待补材料，不补主体。

## 节点 3　对价、账户、农村收益

1. 生活费、医疗自费、护工费、丧葬费预提分列。禁止编造数字。
2. 建议专项或共管账户，专款专用。材料未提及不得写成“费用已经独立托管”。
3. 第十七条：耕种或委托耕种老人承包田地等，收益归老年人。修改句禁止子女截留。

## 节点 4　程序与生效

把老人同意、基层见证、公证、费用首次到账写成**义务和期限**，不写成已经完成。

| 文本写法 | 本任务动作 |
| --- | --- |
| “子女签字即视为老人同意／已公证／已获司法确认” | 拆成签字生效 vs 老人亲自同意；删除“视为已同意／已有执行力” |
| “本协议以离婚登记为生效条件” | 按硬闸 C 转出或删除该条件 |
| 把未调解写成可以直接强制执行 | 纠正；已成争则转出 |
| 用户要求倒签或补假同意、假见证书 | 整体停止 |

## 节点 5　格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

打印店、村委或网上下载的重复使用赡养模板，仍可能构成格式条款。审查免责、限婚、死后财产归一方、单方解释权是否显著。

违反法律、行政法规强制性规定不一律无效（第一百五十三条第一款）。免除法定赡养、限制婚姻自由，同时触及相关强制规范和公序良俗的，就该条款停笔删除，不轻易宣告“整份协议当然全部无效”，除非剩余条款已无法履行赡养目的。禁止用已失效“效力性／管理性”口诀。

## 节点 6　违约、解除、争议解决

1. 逾期给付、拒绝照料、阻挠探望、侵占住房必须分别有可执行后果。只有“依法承担违约责任”视为必须改。
2. 构成违约不等于当然解除全部赡养安排，更不等于免除违约方的法定义务。修改句写催告、补履行、内部追偿，不在本任务宣告某人已经免除或已经解除。
3. 违约金避免“不得调整”或“按房产价值百分之三十必得”。身份协议的违约金从严，修改句可保留滞纳金或定额违约金并允许依法调整。
4. 争议解决：  
   - 可约定先由村（居）民委员会或人民调解组织调解；  
   - 已有仲裁条款须标红旗：身份义务给付能否仲裁运行时核验，不得假装已选定有效仲裁；  
   - 或裁或诉、机构不明：改成单一连结点；  
   - 民诉解释第九条：数被告住所地不同时，追索赡养费可由原告住所地管辖。修改句可写被赡养人住所地人民法院，须写成约定，不选定唯一法院充法律意见。
5. 微信已读不写成已经送达，除非合同把该渠道定为送达。

## 节点 7　跨境、财产与其他结构

1. 义务人或老人在境外：准据法不明则停止外国法结论。本类型只审中国大陆赡养分工和人民币给付安排。
2. 老人房产、存款的权属未核：不得写“已无负担”。即时过户换赡养：该处分字段停止，并按硬闸 F 从本约剥离。
3. 疑似虐待、遗弃、家庭暴力：停止签前“可以签署”，提示争议或公安／检察路径，不在本任务调查定罪。

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

对照已加载框架级文件和本方法硬闸，按六步逐段出句。

| 步 | 本类型必须盯的点 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题名实（赡养协议，避免写成抚养、离婚、遗赠扶养）；被赡养人亲自列为当事人；鉴于写明法定义务不得免除，不把同意或公证写成已完成 | 主体与鉴于修改句 |
| 交易条款 | 费用三项分列、支付账户、医疗自费、健康期／失能期、居住与护理、探望问候 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 删除免责与限婚；内部追偿不得对抗老人；紧急联络人；基层调解与管辖；遗产不在本约处分 | 可执行后果句 |
| 尾部 | 老人亲签或见证面签；义务人列全；附件：费用表、住址、医保凭证；生效不绑离婚登记 | 生效与附件修改句 |
| 语言 | 正说加反说；供养 ≠ 照料 ≠ 探望；放弃继承 ≠ 免除赡养；住院费 ≠ 自动含护工费 | 替换空词的句子 |
| 常见问题 | 免责、买断终局、限婚、死后余财、只给钱、未指定紧急联络人、配偶被写成独立义务人 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（免责、限婚限人身、买断终局、子女遗赠扶养规避、伪造同意）；
- `必须改`：可谈但签署前要落句（费用分列与调整、居住护理、探望、未列名义务人、紧急联络人、老人同意痕迹）；
- `可接受可优化`：仍要给句子，不得只标绿（专项账户、基层见证、公证、配偶协助签署）。

用户不可接受事项优先写成红线。生存级医疗或长期护理费用且用户拒绝升级：停止“可以签署”建议。
