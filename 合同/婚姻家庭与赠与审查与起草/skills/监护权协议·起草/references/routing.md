# 边界与路由

本技能只起草 **婚姻家庭 / 监护权协议**。中文名必须是「审查监护权协议（婚姻家庭）」。

负触发只写触发判定、完整 Skill ID 和最小交接，不填十节实体结论。禁止在正文写半截 ID。

| 主要目标 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 本人现有完全民事行为能力，为自己将来失能预选监护人 | `意定监护协议·审查`。不得把第三十三条预授硬套本任务 |
| 父母均在且有监护能力，主文是变更直接抚养人、抚养费或探望 | `抚养权变更协议·审查`。离婚后父母仍是监护人，不得写成监护权归一方 |
| 主文件同时处理自愿离婚、夫妻共同财产或共同债务 | `离婚协议·审查`。不得删离婚／财产条款后硬套本技能 |
| 不变更监护人选，只重订抚养费、扶养费或探望 | `扶养抚养协议·审查` |
| 成年子女对老年人落实供养、照料、慰藉，不争监护人身份 | `赡养协议·审查` |
| 解除收养关系为主 | `解除收养协议·审查` |
| 大家庭共同财产、宅基地、分家 | `分家析产协议·审查` |
| 夫妻财产归属、婚内财产约定 | `夫妻财产约定·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、问备案日／账户交接／报告节点 | 本套导航的履约步骤 |
| 已成争、申请指定或撤销监护、认定行为能力、抢夺藏匿、人身安全保护令或强制执行 | `已催告解除索赔诉讼或仲裁→` 或家事专项 |
| C 端评估抚养、探望、离婚路径或意定监护起草 | 只分流，不回改 C 端目录，不引用本包研发路径 |

专业版未收录的 P1 场景不会安装本原子。若用户拿本类型文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。

夹带事项的交接：意定监护预授整段交出 `意定监护协议·审查`；直接抚养整段交出 `抚养权变更协议·审查`；离婚财产整段交出 `离婚协议·审查`。仍有监护能力的父母放弃职责，只告知总则编解释第八条，不写可履行放弃句。
