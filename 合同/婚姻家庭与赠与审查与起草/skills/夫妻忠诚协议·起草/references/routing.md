# 边界与路由

本技能只起草 **婚姻家庭 / 夫妻忠诚协议**。中文展示名必须是「审查夫妻忠诚协议（婚姻家庭）」。禁止在正文写半截场景编号。

主线：合法夫妻以违反忠实义务为触发条件，预先安排可分的财产后果。不输出夫妻财产约定的分别/共同/部分共同默认表，不把未婚分手写成夫妻忠实义务，不把人身限制改成可履行结构。

## 正触发

已有可读待签书面忠诚协议、婚内忠诚保证或出轨赔偿协议，尚未签署，尚未成争，双方已登记结婚（或材料能支持合法婚姻），核心给付是忠实义务触发 + 财产惩罚或条件性财产处分，且文本不是解除婚姻一揽子安排。

## 负触发

| 主要目标或文本信号 | 路由 | 不得代做 |
| --- | --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 | 不硬套本类型十节 |
| 无忠实义务触发，只约定婚前或婚后所得归各自/共同/部分共同 | `夫妻财产约定·审查` | 不补忠诚罚则交差；不套财产制三层总表完成本任务 |
| 未登记双方结束同居并清算财产、补偿或分手安排 | `分手协议·审查` | 不把同居者写成夫妻忠实义务 |
| 未登记双方只安排同居期间财产归属，尚无分手安排 | `同居财产约定·审查` | 不按忠诚惩罚金审 |
| 已在办离婚，或解除婚姻+子女+财产债务一揽子 | `离婚协议·审查` | 不补自愿离婚句，不按离婚三块齐审 |
| 主给付是分开居住及分居期间生活安排 | `分居协议·审查` | 不把惩罚金改成分居津贴交差 |
| 无婚姻关系 | 转引擎；可能是分手协议或同居财产约定 | 不把无婚同居写成夫妻忠诚协议 |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 | 已经完成审查；已经完成起草自审 |
| 已签，只问赔偿支付、过户 | 本套导航的履约步骤 | 不回写签前意见充作成交 |
| 已起诉离婚、索赔或债权人撤销，且要诉讼策略 | 婚家领域或 `已催告解除索赔诉讼或仲裁→` | 不写诉讼策略 |
| 处分子女名下财产，或授权藏匿子女、非法取证、人身监控 | 停笔 | 不改写成可履行划转、藏匿或监控 |
| C 端大众快检或 C 端家事起草 | 只分流，不回改 | 不复制起草模板 |

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。

## 本类型内转出（仍可先标风险再停）

- 忠诚主文中夹带整份存续期财产制且**没有**忠实义务触发：财产制块负触发 `夫妻财产约定·审查`；忠诚块继续。
- 忠诚主文中夹带自愿离婚+三块终局安排：离婚块负触发 `离婚协议·审查`，不把本协议改成可登记离婚文件。
- 知识库建议改名为“婚姻财产约定”：只作标题或鉴于优化；若用户要求删掉忠诚触发、改成无条件财产制，该目标停止并转 `夫妻财产约定·审查`。
- 大额且存在已知债权人或执行案件：告知不得对抗不知情债权人及债权人撤销风险，不设计逃债履行结构。
- 用户要保证整份必然有效、净身出户必然执行或仅依第 1043 条即可单独起诉必胜：停止保证，只保留事实摘录与修改句草稿。
- 用户拒绝删除人身限制、放弃监护或非法取证授权：人身闸不能闭合，停止“可以签署”建议。
