# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证整份有效、整份无效、对方接受、仅依忠实义务条款即可单独起诉并必胜、净身出户必然执行或债权人不能再追；编造未给出的产证号、账号、金额；把已失效《合同法》《婚姻法》《民法通则》《民法总则》写入结论；把人身限制改成可履行监控或弃权；把整份协议按全有或全无处理；把无忠诚触发的财产制或未婚分手审成本类型成果；输出整份新协议充作审查成果；输出夫妻财产约定分别/共同/部分共同默认表。

## 1. 触发、单方立场与成果状态

立场（夫或妻一方或其代理人）、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查夫妻忠诚协议（婚姻家庭）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》《婚姻法》及其解释、《民法通则》《民法总则》，或“一律有效/一律无效”“仅依 1043 即可单独起诉必胜”“净身出户必然执行”口诀时记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `婚姻家庭`，子级 `夫妻忠诚协议`。写明忠实义务触发 + 财产后果的定性结果，以及与夫妻财产约定、分手协议、同居财产约定、离婚协议、分居协议的切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读其他类型。知识双文件与 method 冲突时采用 method 核验口径。人身监控、放弃监护、逃债或非法取证写停笔告知，不填可履行的违法结构。

## 4. 主体、婚姻、书面形式与文本版本

主体表：双方姓名、证件号是否可见、结婚证字号、行为能力、是否本人签署。必须记录是双方协议还是单方保证书。本类型不造“付款名/发票名”空表充数。版本表：正文、财产清单、聊天确认、保证书底稿；冲突并列，不选对用户有利的一版。无婚姻：负触发。代签或仅口头：书面/签署字段停止或红线。

## 5. 忠诚触发与财产后果闭环

必须分列并回链原文位置。本节不是财产制默认表，也不是离婚三块：

1. **触发行为**：是否微观到可识别（不正当性关系、同居、以夫妻名义共同生活、生育非婚生子女等）；是否只有“出轨/背叛/暧昧”。
2. **人身条款**：再婚限制、抚养探望弃权、监控禁足是否出现；是否已删除或降格。
3. **财产后果**：清单或固定金额是否特定；是否空词净身出户；是否保留生存/唯一住房份额；是否写“不得调整”。
4. **可分性**：人身无效后，财产块能否独立存在；是否被写成“任何一条无效则全部无效”。
5. **证据**：是否授权非法监听、定位、私闯；是否写“任何证据均可”。
6. **分层**：对内处分、登记对抗、不知情债权人、第 1091 条法定赔偿不得因本约预先放弃。

缺口标 `G#`，不补金额或证号。过户、公证写成条件或期限，不写成已经完成。

## 6. 强制规范与人身条款

人身自由限制、放弃监护或探望、限制再婚、仅依第 1043 条主张独立诉权、显失公平的生存级罚没、倒签、逃债、非法取证、胁迫逼签。强制规范只区分是否导致**该条款**不发生效力，不宣告整份协议有效或无效。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。公证/见证只标可优化，并提示纯道德约束通常难以公证。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔/转出口径。禁止输出无修改句的色块表。

人身限制、触发行为空词、财产不特定或净身出户至少各有一行（无人身限制则有否定表述行）；出现“不得调整”或对外免责必须有对应行；出现单方保证书必须有双方协议化或效力降格行。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款（触发微观化 / 人身删除 / 可分财产后果 / 合法证据）、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`，不编造。禁止只给原则、不给句子。禁止用整份范本替换本节。禁止用财产约定加名总表或离婚三块替换本节。

## 9. 谈判与签署提醒

谈判顺序：先红线（人身限制、放弃监护或探望、限制再婚、非法取证、逃债、代签、倒签、胁迫逼签），再必须改（触发微观化、财产特定、保留生存份额、删除“不得调整”、保证书改为双方签署、可分性声明），最后可优化（见证、录像、公证财产处分块、阶梯责任）。

签署提醒：双方本人签署并签署日期；结婚证摘录入附件；财产清单由双方签认；核心惩罚条款加粗并单独确认；不得在抓奸或家暴当场逼签。不指导倒签或补假自愿。不把公证写成忠诚协议成立要件。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本起草原子交付草稿、未决项、自审风险表、自审后修改句。未过三闸不得宣称完成。不是履约交底、争议文书、离婚诉讼策略或效力保证，也不是夫妻财产约定或分手协议审查。
