# 审查方法（锁定 赠与合同 / 亲属间房屋赠与合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制一般赠与动产交付主路径、非亲属房产赠与主线、商品房五证清单、买卖网签过户手册、施工挂靠或劳动试用期节点。

定性校验：标题、核心给付与本类型一致才继续；买卖、一般赠与、非亲属房产赠与、析产、遗赠明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、必然过户、对方必然接受或亲属当然不得撤销。

`search_law` 返回已失效《合同法》赠与章及其解释、已失效《物权法》、已失效《房屋登记办法》、已失效《契税暂行条例》时记为噪声，不得写入 `L#`。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。买卖、商品房预售或企业附义务赠与范本只证明是另一类型，不得当作本类型范本。

知识库纠正（不回写双文件）：

- `基本面.md` “亲属身份本身不等于道德义务”：父母子女、祖孙、兄弟姐妹关系，不得单独写成第 658 条第 2 款已经关闭。须有扶养、补偿、履行公开承诺等可核验事实，否则任意撤销窗口仍在。
- `框架.md` “父子之间当然不可反悔”：不得替代公证或登记。未公证且未登记的“不可撤销”条款，现有依据不支持消灭第 658 条。
- `框架.md` “公证后生效”：未公证则可能合同尚未生效，受赠人连第 660 条请求权都没有。须向当事人说明选择后果；若本意是签字即成立，不得再写公证为生效条件。
- `框架.md` “其他子女不得有异议”：约束力不及未签字子女的共有份额或嗣后继承主张。
- 契税法第六条免征范围含夫妻之间变更土地房屋权属、法定继承人继承，不含父母赠子女。不得把“直系亲属赠房免税”写成现行法结论。
- 2008 年《房屋登记办法》已失效。赠与转移登记改走《不动产登记暂行条例实施细则》（2024 修正）第 27 条。

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |

| 解除婚姻并分割共同财产 | 离婚协议 | 负触发 `离婚协议·审查` |
| 过户以受赠人长期对价给付（非赡养附带）为主交换 | 附义务赠与 | 负触发 `附义务的赠与合同·审查` |
| 死后才发生物权变动，或遗赠扶养 | 遗赠 / 遗赠扶养 | 负触发 `生前类赠与协议·审查` / `类赠与遗赠扶养协议·审查` |
| 只设居住权、不转移所有权 | 居住权设立 | 负触发 `居住权设立合同·审查` |

支持切开的规范（法律结论须运行时复核）：

- 第 657 条：赠与是将自己的财产无偿给予，受赠人表示接受。
- 第 595 条：买卖是转移标的物所有权换价款——有价款走买卖原子，本任务不审五证或买卖网签主路径。
- 第 209、214 条：不动产物权经登记发生效力；自记载于登记簿时发生效力。
- 第 215 条：未办理物权登记，不影响合同效力——合同成立≠已经过户。

### 1.4 假买卖 / 避债 / 规避限购停笔（硬闸）

加载后或定性中出现：另签买卖合同冲税且资金回流；合同写买卖价款但备注“不必支付”；濒临债务仍无偿过户给亲属并继续占用；伪造购房资格或规避限购。

动作：

1. 交付告知：名实冲突可能因违法或违背公序良俗无效（第 153、154 条）；无偿处分影响债权实现的，债权人可依第 538 条请求撤销，不问亲属是否知情。不得改写成可履行避税、套贷或避债结构。
2. 不写可履行的阴阳价差处理、假资格路径或“过户后仍由赠与人对外抵押”。
3. 风险表只保留识别依据和删除/转出口径。
4. 用户坚持“改到能签且仍做这些事”：整体停止。

## 节点 2　主体、共有人与意思能力

### 2.1 主体表

建表：赠与人（登记权利人）、受赠人、有权同意的配偶、代签人。名称与权属证不一致不自动合并。受赠人是儿媳、女婿的，写明与产权人的亲属关系，不要默认“给儿子即给儿媳”。

向未成年子女赠与：法定代理人代为接受。赠与人本人不得既当处分人又单独代未成年人作出损害其他继承人利益的安排而不披露。

口头“家里都同意了”不得写成已授权。

### 2.2 共有人（硬闸）

支持依据：第 301 条；第 311 条（善意取得须以合理价格转让）。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 登记为单独所有，婚姻状况未核 | 字段停止；修改句要求结婚证/离婚证或单身声明入附件 | 可以过户 |
| 登记为共同共有，仅一方签字 | 红线。须全体共同共有人签署 | 家里同意即可；受赠人已善意取得 |
| 按份共有，未达约定或三分之二份额同意 | 字段停止；补同意或只赠自己份额 | 单方赠全部 |
| 合同写“其他子女不得有异议”但其他子女未签 | 必须改：该句不约束未签字人 | 已经排除继承争议 |

修改句：

「本合同赠与人为不动产登记簿记载的全部权利人【待填姓名】及有权同意的配偶【待填姓名】。前述人员应在签署页签字并按手印。未列明的共有人未签署前，任何一方不得单方申请将房屋转移登记至受赠人名下，受赠人不得主张已具备过户条件。受赠人未支付对价，不得主张善意取得。」

最强反方：签字一方主张“房子本来就是我的，配偶只是挂名”。未核登记簿与婚姻事实前，现有依据不支持写成已可处分全部。

### 2.3 意思能力

高龄产权人把唯一住房赠给共同生活的一名子女：核意思能力痕迹（公证处核实身份、律师见证或医疗机构意见）。材料不足：字段停止，建议公证核实，不写“可以签”。怀疑受胁迫或排斥其他子女且用户要加速过户：升级。

## 节点 3　房屋特定化与权利负担

### 3.1 标的须可登记

审查清单，缺一项则该字段不得写成已闭环：

1. 坐落、不动产单元号、建筑面积、规划用途、土地使用权类型与剩余年限。只写“家里那套房”无法登记。
2. 多套房屋必须分项。禁止“名下房产全部归某某”。
3. 车位、储藏室是否一并赠与，分列；未登记部分不能“顺便”完成物权。
4. 权属来源（买卖、继承、拆迁）。登记权利人与真实出资人不一致：先确权再赠与，不得直接写成可过户。

宅基地上房屋：非本集体成员的亲属通常无法完成转移登记（土地管理法第 62 条；民法典第 363 条指向土地管理法律）。经济适用房、共有产权房、军产、未取得产权证的房屋：先查封闭期和上市条件，字段停止待核。

禁止展开商品房预售五证、开发商主体资格或买卖网签账号——那是 `真实房屋买卖，买受人取得所有权` 的路径。

### 3.2 权利负担

抵押、查封、预告登记、租赁、居住权。材料未提及不得写成“无权利负担”，只能写 `依据不足`。负担不因亲属赠与消灭。带押过户是否可行看当地登记规则，不得假设“家里过户银行会配合”。

有租约必须披露。“交房”在有租约时不等于空房交付。

修改句：

「甲方应于签署前向乙方交付不动产登记信息查询结果（权利人、共有、抵押、查封、居住权）及租赁/户口情况书面说明。查询日后新发生的负担，甲方应在【待填】日内书面补充。存在抵押或查封的，双方应先行取得抵押权人书面同意或等待查封解除；未解除前，任何一方不得主张对方构成过户迟延。」

## 节点 4　过户、公证与占有交付（硬闸）

支持依据：第 209、214、215、658、659、660 条；不动产登记暂行条例实施细则（2024 修正）第 27 条第（一）项。

### 4.1 房屋过户

| 文本写法 | 动作 |
| --- | --- |
| “钥匙已交即视为赠与完成”“以后房子就是你的” | 红线删除。占有≠登记 |
| 无申请登记责任方、无期限、无材料 | 必须改 |
| “尽快”“等家里商量好再办” | 必须改成可判断期限 |
| 把商品房五证、预售许可、网签作为赠与过户条件 | 删除五证主路径；改为赠与转移登记 |

修改句：

「甲方应于【本合同公证之日 / 签署之日】起【待填】日内，备齐不动产权属证书、身份证明、亲属关系证明及完税所需材料，与乙方共同向房屋所在地不动产登记机构申请将【坐落、不动产单元号】转移登记至乙方名下。占有交付、交钥匙或户口迁入，不视为房屋所有权已转移，也不消灭甲方在登记完成前依第 658 条享有的任意撤销权（本合同已公证或依法不得任意撤销的除外）。甲方无正当理由拒不协助申请登记的，乙方有权依第 660 条请求办理登记（以本合同已经公证或属于依法不得任意撤销的赠与为前提）。」

亲属关系证明（户口簿、结婚证、出生医学证明、公安关系证明）是登记和计税材料，不是合同成立要件，但缺了会卡在程序上。修改句要求作为附件，不写成“没有证明合同就不成立”。

### 4.2 658 / 公证（硬闸）

条文：赠与人在赠与财产的权利转移之前可以撤销赠与。经过公证的赠与合同或者依法不得撤销的具有救灾、扶贫、助残等公益、道德义务性质的赠与合同，不适用前款规定。

| 文本写法 | 动作 |
| --- | --- |
| “父子/母女之间当然不可反悔”“本赠与不得撤销”且未公证、未登记 | 必须改。亲属身份不等于道德义务 |
| 受赠人需要锁定过户，文本既不公证也不约定期限递件 | 必须改：公证或限期递件 |
| “公证后生效”且当事人本意是签字即约束 | 必须说明：未公证可能未生效，受赠人无合同请求权 |
| 婚内一方把个人房产赠配偶或改为共有，过户前撤销 | 按婚姻家庭编解释（一）第 32 条适用第 658 条，不得写成婚内赠与当然不可撤销 |

修改句：

「在本房屋记载于不动产登记簿之前，甲方有权依照民法典第 658 条撤销对本房屋的赠与。本合同已经公证机关公证的，或依法属于不得任意撤销的公益、道德义务性质赠与的，不适用前句。甲乙双方之间的【父母子女 / 其他亲属】关系本身，不构成本款所称道德义务。本合同任何“不可撤销”“视为已经赠与完成”的表述，在未公证且未完成转移登记前，不消灭第 658 条任意撤销权。」

最强反方：受赠人主张长期照料已构成道德义务故不得撤销。现有依据不支持把亲属身份或未经核实的照料叙述单独写成第 658 条第 2 款已经满足。本任务不认定已经构成道德义务。

登记完成，该套房屋的任意撤销权消灭；未登记部分（另一套、尚未分割的份额）仍可撤销。第 666 条穷困抗辩仅停止未过户部分，已登记房屋不因退休、生病自动过回。

## 节点 5　无偿性、税费与停笔结构

### 5.1 无偿性

写明受赠人无需支付房款。出现“象征性 1 元”“过户费以外再补偿差价”：回到节点 1.3 重新定性。选定赠与后，删除付款时间表。

接受赠与：受赠人签字即接受。多名子女中只赠一人的，不强制其他人签字，但审查应提示嗣后继承争议，不得写成已经排除。

### 5.2 税费

约定契税、所得税、印花、登记费由谁缴纳。未约定则按税法；赠与人拒不协助完税导致无法过户的，仍属不履行协助义务。

契税：房屋赠与以税务机关核定价格为计税依据（契税法第 4 条第（三）项）；纳税人是承受方（第 1 条）。第 6 条免征含夫妻之间变更、法定继承人继承，**不含**父母赠子女。地方是否另有减免：字段停止待核，不写“直系亲属赠房免税”。

修改句：

「因本次赠与产生的契税、印花税、登记费由【待填：乙方 / 甲方】承担；个人所得税及其他税款按届时税法确定纳税人。任何一方应按对方合理请求在【待填】日内提供完税申报所需材料并到场协助。双方不得约定不申报或以虚假买卖价格申报。未约定承担方的，不免除任何一方的法定纳税与协助义务。」

精确税额不编造。

## 节点 6　撤销回转、居住权、格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 法定撤销与继承人撤销

第 663 条三项、一年期间：严重侵害赠与人或其近亲属合法权益；对赠与人有扶养义务而不履行；不履行赠与合同约定的义务。已过户后要以本条撤销，不能再喊任意撤销。

第 664 条六个月：因受赠人违法行为致使赠与人死亡或丧失民事行为能力。通知条款要可送达。

修改句把法定期限写成合同权利，不在本任务认定已经发生撤销事由。

### 6.2 居住安排

赠与人或其他亲属继续居住的，设居住权并申请登记（第 366–368 条），写明期限（至去世或固定年限）和费用承担。唯一住房直接过户给一名子女且无居住权：红线或必须改。

居住权专条可在本任务改句。用户要把主文件改成只设居住权、不转移所有权：负触发 `居住权设立合同·审查`。

修改句：

「乙方同意为甲方设立居住权，居住期限至甲方死亡（或至【待填】年【待填】月【待填】日），居住房屋为【坐落】全部 / 【待填】房间。双方应于申请房屋转移登记的同时向不动产登记机构申请居住权登记。居住权设立前，乙方不得要求甲方搬离，也不得以所有权人身份排除甲方占有使用。」

再处分限制：可约定受赠人在赠与人生存期间不得出售、抵押，但要评估能否对抗第三人；更稳妥的是居住权 + 部分份额保留。不得把未登记的“不得出售”写成已可对抗善意第三人。

### 6.3 格式条款

家庭内部手写协议通常不构成格式条款。使用中介或网站下载的重复使用模板，且订立时未协商：按第 496 条和合同编通则解释第 10 条审查提示说明。仅有网络勾选或小字印刷，不得写成已尽提示义务。

### 6.4 强制规范

违反法律、行政法规强制性规定不一律无效（第 153 条；解释第 16 条）。禁止用已失效“效力性/管理性”口诀。宅基地、保障房资格限制主要导致履行不能或登记驳回，不得单独写成民事合同当然无效，也不得改成可履行的规避结构。假买卖、避债、规避限购：不改写成有效履行。

瑕疵担保：一般赠与人原则上不承担瑕疵责任；故意不告知漏水、违建、查封的，依第 662 条赔偿。亲属之间更常见“知道一点但没写”，必须披露。

## 节点 7　违约、解除与争议

1. 赠与人无正当理由拒不协助过户、拒不协助完税：可约定限期催告后请求登记（以已公证或依法不得任意撤销为前提）并赔偿直接损失。只有“依法承担违约责任”视为必须改。
2. 受赠人取得房屋后不履行约定赡养或严重侵害：走第 663 条，不走任意撤销。
3. 构成违约不等于当然解除。不在本任务作出已解除或已撤销结论。
4. 违约金不是必得金额。修改句避免“不得调整”或“按房屋市场价 30% 必得”。
5. 争议解决：房屋物权确认、分割争议标不动产所在地专属管辖红旗（民事诉讼法 2023 修正第 34 条；民诉法解释第 28 条）。合同债权争议（协助过户、税费分担）不当然专属。出现仲裁条款，不得改写成“应向某法院起诉”并假装已选定诉讼。不选定唯一法院充作法律意见。
6. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。
