# 涉及不正当男女关系的赠与合同·审查

## 任务目标

在单一立场下，只审查 **赠与合同 / 涉及不正当男女关系的赠与合同** 的待签文本：赠与人向存在不正当男女关系的第三人（或其指定人、近亲属、控制账户）无偿给予财产，或该第三人死亡后向其近亲属给付。输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「审查涉及不正当男女关系的赠与合同（赠与合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查、从零起草、履约交底、争议文书、效力或必然返还保证、把包养改成可履行、把维持不正当关系改写成生活补助后继续按月给付、把同居改写成第 661 条附义务、分手协议本约整案、一般赠与任意撤销整案。

## 工作边界

正触发：已有可读待签文本要评改，；尚未签署，尚未成争；核心给付是向不正当关系第三人无偿给予，或以该关系结束后的近亲属抚恤／丧葬为名的给付。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 双方已经或即将终止共同生活，结算对象是已形成的财产、债务和非婚生子女抚养，给付能回链到共同出资折价或贡献补偿 → `分手协议·审查`；不得把分手清算做成无效赠与整案；
- 双方仍共同生活，文本安排存续期归属、共同账户、加名，尚未以赠与对价维持关系 → `同居财产约定·审查`；专业版未收录该原子时输出 `unavailable`；
- 双方无婚外性关系或包养安排的普通无偿给予 → `一般赠与合同·审查`；
- 救灾扶贫助残等公益、道德义务主文件，且原因事实与不正当关系无关 → `公益道德义务性质的赠与合同·审查`；专业版未收录时输出 `unavailable`；
- 附义务赠与，义务是扶养、劳务等合法事项，不是维持不正当关系 → `附义务的赠与合同·审查`；
- 婚姻家庭内部赠与为主线 → `婚姻家庭中的赠与合同·审查`；专业版未收录时输出 `unavailable`；
- 股权零元转让且关系不是本类型主线 → `零对价股权赠与·审查`；
- 房屋无偿过户且关系不是本类型主线 → `房产赠与合同·审查` 或亲属房屋 `亲属间房屋赠与合同·审查`；
- 已登记结婚，核心是解除婚姻 → `离婚协议·审查`；
- 已登记夫妻约定忠诚义务或出轨惩罚 → `夫妻忠诚协议·审查`；
- 有真实劳动报酬或真实借贷返还 → 先按基础关系转引擎，不得一律按包养费打掉；
- 无文本、本类型条件已谈妥、要出己方稿 → `涉及不正当男女关系的赠与合同·起草`；
- 已签只问转账日、过户进度 → 本套导航的履约步骤；
- 已成争（催告、确认无效、返还、立案仲裁）→ 合同争议或家事专项领域。

规避限购、借名过户、伪造同意、以协议逃债、把限制报警或限制结婚改成可履行：只出告知，不改写成可履行结构。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成。每一闸必须给出修改句或明确转出口径，禁止只打红黄绿。

1. **公序良俗／无效分层**。不得写成“有第三者即当然全部无效”，也不得写成“双方自愿即当然有效”。按给付目的、财产性质、是否可分离合法部分分层：关系对价或维持不正当关系 → 第 153 条／通则解释第 17 条无效审查路径；夫妻共同财产且为同居或不忠目的处分 → 解释（二）第 7 条，按第 157 条处理；法定抚养、已有独立事实的丧葬抚恤、真实劳务或借贷、小额日常往来 → 第 156 条可分离。认定须综合主观动机、交易目的和社会后果。
2. **不得按普通赠与任意撤销改完**。第一刀是效力分层，不是第 658 条。无效合同没有任意撤销权可设计。第 658／660／663／666 条只作用于已经过分层、现有依据支持有效的部分。公证、已交付、已过户、空写“不可撤销”都不能单独挽救违背公序良俗的给付。
3. **不写可履行的包养结构**。包养费、按月给付以保持同居或性关系、限制结婚、不得向配偶或司法机关陈述事实：红线删除或停笔告知。禁止输出可履行付款时间表、履行担保或“改成生活补助后继续按月给”。禁止把同居改写成第 661 条附义务。用户坚持改到能签、能管住对方继续同居：整体停止。
4. **必须出修改句**。禁止只打红黄绿。每一闸、每一条风险必须落到可回给对方的删除句、拆分句、披露句或明确停笔／转出口径。

附加必落句（有事实则单列，无事实在缺口节说明）：

- **财产性质**：写明资金或房屋属于个人财产或已取得配偶同意。写不清的，按共同财产无权处分准备返还风险。禁止写成“配偶不得追索”“对方一半无权主张”。
- **子女拆分**：对子女的法定抚养、教育支出单列，权利人是子女。不得与给第三者本人的大额财产混在一笔。抚养费不是本类型赠与。
- **独立合法原因**：只有损害填补、法定抚养之外的补充、第三人死亡后的丧葬或生活困难救助等**已有独立事实**时，才讨论第 658 条第 2 款和第 660 条。不得审查员改写目的来制造道德义务。
- **已付与未付**：无效的，已付讨论返还，未付不得设计强制交付。有效且构成道德义务的，未付才可讨论请求交付。
- **保密**：可约定不扩散隐私；不得写成不得向配偶或司法机关陈述事实。

必须有修改句。每个风险回链文本位置。禁止套用买卖验收、定金百分之二十或挂靠改写节点。禁止复制分手协议、一般赠与、附义务赠与或股权赠与 method。

## 建立审查坐标

确认：使用者与授权；单方立场（赠与人、受赠人、赠与人配偶）；相对方；全文及转账／权属／聊天／婚姻状况附件版本；赠与人是否有配偶及财产制；给付目的与对价；是否已交付；有无非婚生子女或死亡抚恤事实；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《婚姻法》及其解释当作现行规则。不得把“公证就有效”“已过户就不能返还”“空写不可撤销就能锁死”“改成生活补助就能按月履行包养”“有第三者就当然全部无效”“双方自愿就当然有效”写成现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law`（法律结论 required）：核验公序良俗无效、无效返还、夫妻共同财产因与他人同居等目的赠与他人、禁止有配偶者与他人同居、赠与定义与任意撤销例外、善意取得须合理价格、债权人撤销无偿处分。
- `search_practiced`（optional）：补不贞赠与、青春损失费、配偶追索争点。返回“改成生活补助就能履行”“公证对抗配偶”“一律只能返还一半”时记噪声。
- `search_template`（optional）：只借栏目结构。范本写“包养”“不得结婚”“公证后生效即不可撤销”不得当规则。

不虚构案件系统。`search_law` 返回已失效《合同法》《婚姻法》及其解释、民法通则时记为噪声，不得写入 `L#`。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口，不代替节点。

0. 签署状态与成果分流
1. 类型识别与单目录加载（切开分手协议／一般赠与／附义务／股权／存续同居约定／离婚／忠诚）
2. 主体、婚姻状况、财产制、子女、债权人
3. 公序良俗与无效分层（硬闸；L1–L4；不改可履行包养）
4. 财产性质、无权处分、解释（二）第七条
5. 标的拆分：给本人、给子女、死亡后道义
6. 效力先于撤销：无效走第 157 条；有效才进入第 658／660／663 条
7. 配套：保密不得封救济、逃债、管辖
8. 按框架六步出修改句

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签或假同意、把包养改成可履行、把限制报警或限制结婚写成可执行、把夫妻共同财产包装成可履行买断第三者、保证当然有效或当然全部无效或必然全额返还。
- `字段停止`：法域、婚姻状况、财产性质、给付目的未核验；道德义务事实无法识别。
- `目标停止`：主目标已变为从零起草、履约交底、确认无效诉讼文书，或用户要把本约改成分手协议、一般赠与或可履行包养合同。

生存级住房被无偿转给第三者或存在家暴、限制人身自由，且用户拒绝升级：停止“可以签署”建议。
