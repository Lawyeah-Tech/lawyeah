# 类赠与类赠与遗赠扶养协议·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、已失效《继承法》、已失效《物权法》、已失效《民法总则》、已失效《养老机构设立许可办法》或 2013《养老机构管理办法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **赠与合同 / 遗赠扶养协议（与赠与合同有区别的 “类赠与” 协议）** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查遗赠扶养协议（与赠与合同有区别的 “类赠与” 协议）（赠与合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证死后必然过户或子女必然败诉。不交付婚家货架遗赠扶养整案。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **不是普通赠与，也不是婚家货架换皮**：遗赠扶养是生养死葬换遗产的继承编双务有偿协议。经济效果像赠与，法律结构跨不过第 657 条无偿门槛。第一句问：有没有生养死葬对价、能不能按赠与任意撤销。答案必须是：有对价、不能按第 658 条撤销。用户或文本明确走婚家/继承编货架，家庭伦理、必留份精算或法定继承安排是主线且不要赠与切开 → `遗赠扶养协议·审查`（未装则 `unavailable`）。禁止打开或抄写 `遗赠扶养协议·审查` method。
2. **生养死葬对价**：扶养人承担可检验的生活照料、饮食起居、医疗陪护、精神慰藉和丧葬，才是第 1158 条的对价。全文只写房子怎么过户 → 滑向遗赠或赠与，负触发 `生前类赠与协议·审查` / `遗嘱·审查` / `一般赠与合同·审查`，或必须改出可检验义务。纯金钱、不上门：不当然无效，但协议优先的论证变弱，必须改。
3. **有偿阻断任意撤销**：删除第 658 条任意撤销、第 660 条请求交付、第 661 条附义务赠与出口、第 666 条穷困抗辩。解除按约定或根本违约，结算按继承编解释（一）第 40 条。不得写成“尚未过户即可归零”。
4. **死后转移、禁止先过户**：财产于遗赠人死亡、丧葬完成并清算税款债务后转移。签署后立即过户、先过户再养老 → 负触发 `附义务的赠与合同·审查`。登记原因写成受遗赠（遗赠扶养），不写成赠与。不要写“死亡后本协议才生效”，否则生前扶养无合同依据。
5. **扶养人须为继承人以外**：第 1158 条限于继承人以外的组织或个人。子女、配偶、父母作扶养人 → `赡养协议·审查` 或夫妻扶养。第二顺序继承人作扶养人：字段停止，不得写成当然构成本协议。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签正文，尚未签署，尚未成争，核心给付是继承人以外的人承担生养死葬、遗赠人死后转移可处分财产；用户从赠与货架进来，问能否签、哪里必须改、怎么删掉赠与工具。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 用户或文本明确只要婚家/继承编审查、不要赠与切开，主线是家庭伦理、必留份精算或法定继承安排 → `遗赠扶养协议·审查`（P1；未装则 `unavailable`）；
- 子女、配偶、父母以“扶养人”换房产 → `赡养协议·审查`；夫妻互养主线 → 转引擎或婚家扶养原子；
- 无偿给予且权利拟在生前转移，或正文保留第 658 条并拟立即过户 → `附义务的赠与合同·审查` / `一般赠与合同·审查` / `房产赠与合同·审查`；
- 死后过户但无生养死葬对价 → `生前类赠与协议·审查` 或 `遗嘱·审查`；
- 单方遗嘱、可另立遗嘱撤回 → `遗嘱·审查`；
- 意定监护、只解决代理不当然取得遗产 → `意定监护协议·审查`；
- 机构收全额服务费、不主张遗产，或主文件是养老服务合同 → 转引擎按服务合同重定；
- 仅设立居住权、不过户所有权 → `居住权设立合同·审查`；
- 救灾、扶贫、助残等公益赠与是主文件 → `公益道德义务性质的赠与合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `类赠与遗赠扶养协议·起草`；
- 已签只问照料打卡日、丧葬日、过户日 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁或继承人已起诉确认无效 → `已催告解除索赔诉讼或仲裁→` 或家事专项。

挂靠、违法分包、规避限购、逃避债务或执行：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（遗赠人 / 扶养人择一）；相对方；全文及财产清单/义务清单/权属证版本；扶养人是否继承人以外；义务是否含生活照料及频次、费用来源、丧葬标准；转移时点是否死后；有无第 658、660、661、666 条或“赠与人/受赠人”；是否拟生前过户；遗赠人行为能力与全部法定继承人；财产是否个人份额及抵押查封租赁居住权；在先遗嘱、赠与、其他扶养协议；机构登记备案与收费；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `类赠与遗赠扶养协议·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议或家事专项。未签且目标是评改已有本类型文本，才进入本任务。

### 1. 赠与检验与货架切开

先问无偿性：有生养死葬对价则不是第 657 条赠与。婚家货架、法定继承人换房、生前过户赠与、无照料遗赠、单方遗嘱负触发。

### 2. 赠与残留扫描

第 658、660、661、666 条及“赠与人/受赠人”出红线删除。公证只固定意思能力，不打开赠与交付请求权。

### 3. 主体：继承人以外、能力、个人份额

扶养人不得是第一顺序法定继承人。遗赠人须有相应行为能力。只能处分个人财产或份额。

### 4. 生养死葬与遗赠财产双标的

照料必须可检验。财产必须特定化。负担未披露不得写成无负担。

### 5. 死后转移、居住、协议立即生效

拆开合同生效与物权变动。禁止先过户。遗赠人生前保留居住。

### 6. 解除结算替代赠与归零

解释（一）第 40 条写入解除后果。不得写未过户即全部归零。

### 7. 协议优先、遗产债务、机构双重获利

解释（一）第 3 条优先于抵触遗嘱。第 1159、1162 条只作清算红旗，不做必留份精算。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、补假能力证明、保证有效、保留第 658 条按赠与放行、先过户再养老拒改、把逃债或规避限购改成可履行。
- `字段停止`：法域、动态规则、扶养人是否第二顺序继承人、行为能力医学意见、机构备案细则、税负精确额、共有或决议未核验；第 144、214、301、563、538、585 条未核验全文时的对应法律结论。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类，或用户只要婚家 `遗赠扶养协议·审查` 整案。
