# 意定监护协议·审查

## 任务目标

在单一立场下，只审查 **婚姻家庭 / 意定监护协议** 的待签文本：具有完全民事行为能力的成年人，事先以书面形式确定自己的监护人，并约定在自己丧失或部分丧失民事行为能力时由该监护人履行监护职责。输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「审查意定监护协议（婚姻家庭）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查、从零起草、履约交底、争议文书、协议或指定结果保证、遗赠扶养整案、监护权协议整案、能力宣告申请书、公证代办。

## 工作边界

正触发：已有可读待签书面文本，尚未签署，尚未成争；核心安排是 **自己给自己预选监护人**，并以丧失或部分丧失民事行为能力为职责触发。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 核心给付是生前扶养（生养死葬）换死后财产归对方 → `遗赠扶养协议·审查`；赠与合同货架同类文本 → `类赠与遗赠扶养协议·审查`；
- 依法具有监护资格的人之间为未成年人或已经失能的成年人协议确定监护人 → `监护权协议·审查`；
- 单方死后处分财产、无监护职责触发 → `遗嘱·审查`；
- 仅一般委托代理、意定代理，不以失能为监护职责触发 → 转引擎重新定性；
- 无文本、本类型条件已谈妥、要出己方稿 → `意定监护协议·起草`；
- 已签只问公证预约、履职节点、向银行出示 → 本套导航的履约步骤；
- 已成争（申请宣告无/限制行为能力并争监护、撤销监护、立案）→ `或对应专项。` 或对应专项。

胁迫、代签、伪造能力或公证材料、把死后财产预先过户给监护人以规避继承或债务：只出告知，不改写成可履行结构。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成。每一闸必须给出修改句或明确转出口径，禁止只打红黄绿。

1. **书面形式法定**。第三十三条要求书面确定自己的监护人。口头、仅聊天记录、仅“家里说好了”：不得写成已成立意定监护。缺书面正文：负触发起草或不启动实体审查。电子签名、数据电文可讨论是否符合书面，但人身关系文书对电子签名有特别限制，不得写成电子签署必然有效；修改句优先纸质合同书并由设立人与监护人亲笔签名。
2. **公证实践分层**。民法典未强制公证。不得写“未公证即无效”，也不得写“未公证则银行、医院、不动产登记窗口必然拒绝”。公证补强签署时意愿与能力，并常作为窗口认可的监护关系材料。修改句建议办理公证，并写明无公证时履职可能受阻。禁止把“视为已公证”或倒签公证日期写成可放行。
3. **监护职责必须落句**。必须分列：生活照料；医疗决策（设立人无法表达时的方案与手术签字）；财产管理（日常开支与重大处分分开）。只写“全权处理一切事务”“自由买卖房产”“监护人可自行认定失能并立即接管”：红线或必须改。重大财产处分须为维护被监护人利益，并建议监督人同意或另设托管。成年人监护须最大程度尊重真实意愿，对被监护人有能力独立处理的事务不得干涉。
4. **触发与能力认定分层**。协议成立时点与职责开始时点必须拆开：可自双方签字之日起成立；监护职责自设立人丧失或部分丧失民事行为能力时开始。医院诊断、专家鉴定是启动材料，不是已经完成的行为能力宣告。法定认定路径是人民法院特别程序。禁止监护人自行宣告失能。签署时能力存疑：字段停止或整体停止，不补“神志清醒”。
5. **与 `遗赠扶养协议·审查` / `类赠与遗赠扶养协议·审查` 切开**。死后财产归对方、生养死葬对价、扶养费用返还是遗赠扶养主线。本任务禁止打开其 method，禁止把本约改成可履行的死后财产转移。
6. **与 `监护权协议·审查` 切开**。资格人之间为他人确定监护、父母离异监护交接、免除有监护能力父母的职责，是监护权协议主线。本任务禁止打开其 method，禁止套用同顺位资格人会签作为成立要件。

附加必落句（有事实则单列，无事实在缺口节说明）：

- **解除分层**：丧失或部分丧失民事行为能力前，任何一方可书面解除；失能后，协议确定的监护人无正当理由不得请求解除。设立人在仍有完全行为能力期间，有权书面撤销或修改。
- **监督与后备**：无监督人时，重大财产处分字段不得放行“可以签”；建议设监督人、定期报告、后备监护人。
- **报酬**：无偿或有偿必须写明；有偿写标准、来源（设立人财产）与监督复核。不得把报酬写成死后遗产必然支付。
- **语言**：使用“丧失或者部分丧失民事行为能力”，不用单独的“失智/失能”替代法律用语；使用“代为行使”“管理及保护”，不用“财产归监护人所有”。

必须有修改句。每个风险回链文本位置。禁止套用买卖验收、定金百分之二十、挂靠改写、生养死葬或资格人会签节点。禁止复制 `遗赠扶养协议·审查` 或 `监护权协议·审查` method。

## 建立审查坐标

确认：使用者与授权；单方立场（设立人/被监护人、拟任监护人、拟任监督人、拟任后备监护人）；相对方；全文及监督确认、医疗预嘱、体检附件版本；是否书面；是否拟公证；职责范围；失能认定方式；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的报酬、资产范围、日期用 `【待填】`，不编造。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《民法总则》《继承法》及其解释当作现行规则。不得把“未公证一律无效”“口头也算意定监护”“医院诊断等于行为能力宣告”“死后财产当然归监护人”写成现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law`（法律结论 required）：核验书面形式、公证是否强制、监护职责与财产处分限制、失能触发、失能前解除与失能后不得无故解除、撤销监护、行为能力认定。
- `search_practiced`（optional）：补签约时能力审查、公证补强、窗口认证书、监督人争点。返回“未公证一律无效”“口头也算”“医院诊断等于宣告”时记噪声。
- `search_template`（optional）：只借栏目结构。范本写“监护人自行认定失能后可处分全部财产”或“死后财产归监护人”不得当规则。

不虚构案件系统。`search_law` 返回已失效《合同法》《民法总则》《继承法》、2002 年《公证程序规则》、2018 年已被修改的《妇女权益保障法》条文时记为噪声，不得写入 `L#`。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口，不代替节点。

0. 签署状态与成果分流
1. 类型识别与单目录加载（自己预选监护人；切开遗赠扶养 / 监护权协议 / 遗嘱）
2. 主体、签署时能力、监护能力
3. 书面形式与公证实践分层
4. 监护职责、医疗决策、财产处分限制
5. 触发条件与行为能力认定
6. 监督、后备、报酬、解除与撤销
7. 强制规范与窗口履职材料
8. 按框架六步出修改句

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；设立人已无完全行为能力仍要签；用户坚持代签、伪造体检或公证、倒签签署日、把死后财产归监护人改成可履行、把监护人自行认定失能并卖房写成可履行、保证法院必然指定或协议必然有效。
- `字段停止`：法域未核验；签署时能力无法判断；是否书面无法识别；重大财产处分无监督且用户拒补；公证状态与窗口收件口径未核验时的“必然配合/必然拒绝”结论。
- `目标停止`：主目标已变为从零起草、履约交底、能力宣告或撤销监护文书，或用户要把本约改成遗赠扶养或监护权协议。

设立人生存级住房或主要养老资金被授权“自由处分”且用户拒绝升级：停止“可以签署”建议。
