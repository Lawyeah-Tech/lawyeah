# 边界与路由

本技能只审查 **婚姻家庭 / 意定监护协议**。

必须同时读出：具有完全民事行为能力的成年人，事先以书面形式确定自己的监护人；监护职责以丧失或者部分丧失民事行为能力为触发。标题叫“意定监护”但核心是生养死葬换死后财产，或资格人之间为他人确定监护的，不得留在本技能做实体结论。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或标题意定监护、核心给付明显不是自己预选监护人 | 本套导航的类型切开步骤 |
| 生前扶养、生养死葬、死后房产存款归对方、扶养费用返还为主给付 | `遗赠扶养协议·审查`；赠与合同货架同类 → `类赠与遗赠扶养协议·审查`。专业版未收录时输出 `unavailable`，不得硬套本技能改成死后财产转移 |
| 父母离异后未成年子女监护交接；多名子女为已失能父母协商谁当监护人；资格人之间协议确定监护人 | `监护权协议·审查` |
| 单方死后处分财产，无失能触发的监护职责 | `遗嘱·审查` |
| 居住权设立、仅安排住房使用权 | `居住权设立合同·审查` |
| 仅一般委托代理、意定代理，不以失能为监护职责触发 | 转引擎重新定性，不灌本类型职责节点 |
| 无文本、本类型条件已谈妥、要出己方稿 | `意定监护协议·起草` |
| 已签未争、问公证预约、向银行医院出示、履职节点 | 本套导航的履约步骤 |
| 已成争：申请宣告无/限制行为能力并争监护、撤销监护、立案 | `或对应专项。` 或对应专项；不写申请书、答辩状 |
| 用户只要“法院会不会指定我”的终局预测 | 不输出必然指定；只审条款 |
| C 端大众快检或 C 端起草商品 | 只分流，不回改 |

同一文本既写意定监护又写“死后全部财产归监护人、对方负责养老送终”：按核心给付切开。死后财产是对价且扶养是主给付 → 负触发遗赠扶养。监护职责是主给付、死后事务仅附带丧葬代理且财产仍按继承处理 → 可留本技能，但必须删除“财产归监护人所有”，并提示遗嘱或遗赠扶养另件处理。两可且无法判断：负触发引擎，不灌两套知识。

胁迫、代签、伪造能力或公证、预先过户规避继承或债务：停笔告知，不改写成可履行文本。

禁止在正文写半截 Skill ID。转出时必须写完整 ID，例如 `遗赠扶养协议·审查`、`监护权协议·审查`。
