# 无对价财产转移赠与·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **赠与合同 / “不直接支付对价的财产转移” 型赠与合同**，输出可编辑草稿、未决项，并在出稿后用本类型硬闸自审。名赠与实借贷或让与担保必须切开，不改成可履行赠与。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查“不直接支付对价的财产转移” 型赠与合同（赠与合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证“必然不是赠与”或 658 必然消灭、把借贷或让与担保改成可履行赠与。

## 本类型硬闸

1. **无直接对价财产转移的赠与定性**。本类型是推定型赠与：合同名称常是转让、交割、重组、分立、交还、调拨。审查第一问是对价和原因，不是先套任意撤销。无直接价款且无其他有偿原因（承担债务、放弃债权、历史出资返还、真实劳务折价）时，按可能被第 657、658 条捕获处理。有真实价款 → 买卖切开。低价但仍有价款 → 走第 539 条，不是第 658 条。空写“不属于赠与、不得撤销”而无结算、代偿、出资等原因事实：约束力弱，法院看资金流和原因。禁止同时写“既是结算又保留任意撤销”。混合原因必须拆包。
2. **名赠与实借贷 / 让与担保必须切开**。零元或“赠与 / 无偿移交”外壳下，若另有借款本金、利息、占用费、还款日、本金加溢价回购、出让人过户后仍占有使用、或“到期不还则财产归受让人”，按第 146 条、担保制度解释第 68 条、民间借贷司法解释第 23 条穿透。房产买卖外壳 → `文本写到期还本回购担保债权流质或“先过户再还钱把房拿回”→负触发`。其他合同外壳的实质借贷 → `的method。`。过户担保还本付息主轴可点名 `过户担保还本付息主轴可点名`。禁止打开或复制上述 method。禁止把流质句改成“赠与已完成、不必清算”。禁止用第 658 条去开关一套担保过户。真赠与被要求加上回购和利息：红线删除或转出，不改成可履行让与担保。
3. **必须出修改句**。禁止只打红黄绿。每个风险回链文本位置。整案已按第 2 闸切出的，只出判定、完整 Skill ID 和最小交接，不填赠与十节。

## 工作边界

正触发：已有可读待签转移 / 交割 / 划转 / 移交 / 零元转让正文，尚未签署，尚未成争，核心给付是接受财产但不直接支付价款，且看不到借贷或让与担保叠层；用户问会不会被当成赠与、658 会不会开刀、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 标题和正文承认“无偿赠与 / 给予”，且无借贷 / 回购叠层 → `一般赠与合同·审查`；房产主标的承认赠与 → `房产赠与合同·审查`；股权零元赠与主文件 → `零对价股权赠与·审查`；救灾、扶贫、助残等公益、道德义务赠与是主文件 → `公益道德义务性质的赠与合同·审查`；
- 以他人名称购房并支付房款 → `借名购房型赠与·审查`；
- 房产过户外壳 + 借款担保 / 回购 / 流质 → `文本写到期还本回购担保债权流质或“先过户再还钱把房拿回”→负触发`；
- 赠与、划转、交割等其他外壳，真实目的是借贷 → `的method。`；
- 过户到出借人名下、还本付息、到期赎回的借款主文件 → 点名 `过户担保还本付息主轴可点名`；
- 出现应付价款、定金、发票、按揭，或“名为无偿、实为买卖” → 对应买卖原子；
- 借据、判决、结算完整且转移是清偿该债 → 转引擎或对应抵债原子；
- 受赠人须持续履行义务才给财产 → `附义务的赠与合同·审查`；
- 婚姻家庭赠与、亲属间房屋、不正当关系赠与 → `婚姻家庭中的赠与合同·审查` / `亲属间房屋赠与合同·审查` / `涉及不正当男女关系的赠与合同·审查`；
- 死后生效、遗赠或遗赠扶养 → `生前类赠与协议·审查` / `类赠与遗赠扶养协议·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁或债权人已提起撤销 → `已催告解除索赔诉讼或仲裁→` 或对应专项。

挂靠、违法分包、规避限购、逃避债务或执行、国有资产违规无偿给关联方、把让与担保写成终局赠与：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及结算 / 代偿 / 出资 / 决议 / 清单 / 借条 / 回购确认版本；标题是否出现转让、交割、划转、移交；价款栏是空白、零元还是“另行结算”；有无隐性对价；有无借款本金、利息、占用费、回购、到期归属；出让人过户后是否仍占有使用；出让人与原因关系中的债权人、投资人、出借人是否同一人；标的是否清单化；权利是否已交付或登记；公司决议与国资程序；出让人负债与诉讼；是否拟公证；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 起草模式

本原子只承担本类型起草。待签评改转 `无对价财产转移赠与·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`，不编造。出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

本类型是推定型赠与：第一问是对价和原因，不是先套任意撤销。名赠与实借贷或让与担保必须切开，不改成可履行赠与，也不用第 658 条去开关一套担保过户。

### 起草必写

- 无直接价款且无其他有偿原因（承担债务、放弃债权、历史出资返还、真实劳务折价）时，按可能被第 657、658 条捕获处理。有真实价款 → 买卖切开。低价但仍有价款 → 走第 539 条，不是第 658 条。
- 原因条款必须落到证据。混合原因必须拆包。定性二选一。
- 若落入赠与：第 658／663／666 条按已交／未交拆分。动产看交付，不动产／股权／知识产权看登记。
- 若非赠与：解除与返还，不混用撤销赠与通知。

### 附件必附

- 能支撑原因事实的结算、代偿、出资、决议或清单。空写“不属于赠与、不得撤销”而无原因事实：不得写成已排除第 658 条。缺金额、期限、税负用 `【待填】`。

### 禁止出现

- 同时写“既是结算又保留任意撤销”。
- 把流质句改成“赠与已完成、不必清算”。
- 用第 658 条去开关一套担保过户。
- 真赠与被要求加上回购和利息后，改成可履行让与担保。
- 把借贷或让与担保改成可履行赠与；把让与担保写成终局赠与。
- 逃债或国有资产违规无偿给关联方的可履行结构。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 本任务起草模式；已签履约 → 本套导航履约步骤；已成争 → 合同争议或执行专项。未签且目标是评改已有零对价转移文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与资金流向一致才继续。典型赠与、公益赠与、股权赠与、借名购房、让与担保房产买卖、名其他实借贷负触发。

### 2. 无直接对价的赠与定性

对价、隐性对价、原因事实、低价与零价分层。原因条款必须落到证据编号。定性二选一。

### 3. 名赠与实借贷 / 让与担保切开

借条、回购、占用费、流质、过户后仍由出让人占有。命中则切出，不按 658 改。

### 4. 主体、原因关系人与决议

出让人与原因关系债权人 / 出借人是否一致。公司无偿转出必须机关决议；国有不得无偿向关联方提供资产。

### 5. 清单、负担与权利是否已转移

动产看交付，不动产 / 股权 / 知识产权看登记。未转移则若被定为赠与，658 窗口打开。已交 / 未交拆分。让与担保公示 ≠ 赠与终局所有权。

### 6. 逃债 538 与不得排除

只告知。不改可履行逃债。低价走 539。

### 7. 若落入赠与：658 / 663 / 666；若非赠与：解除与返还，不混用撤销赠与通知

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、补假结算或假借条、保证必然不是赠与、把逃债或国资违规无偿改成可履行、把流质改成赠与完成、未公证却保证 658 消灭。
- `字段停止`：法域、动态规则、税负精确额、决议或国资程序未核验、债务全貌未披露、资金流不足以区分赠与与借贷。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
