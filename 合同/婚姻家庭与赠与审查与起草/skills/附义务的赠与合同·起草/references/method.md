# 审查方法（锁定 赠与合同 / 附义务的赠与合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止打开或复制 `一般赠与合同·审查` 的审查路径。禁止复制一般赠与无负担主路径、买卖价款/定金主路径或施工挂靠节点。

定性校验：标题、核心给付与本类型一致才继续；无负担、公益用途限制、遗赠扶养、有偿对价或其他明显他类则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、附义务即不可撤销、空义务已可稳妥撤销、对方必然接受或唯一必得返还额。

`search_law` 返回已失效《合同法》赠与章及其解释、《物权法》时记为噪声，不得写入 `L#`。

示范文本只参考结构。仍写《合同法》的附义务范本不得当作现行依据。把“生养死葬、死后过户”写进赠与的范本，只证明应切开遗赠扶养。

知识库纠正（不回写双文件）：

- 空写“因已设义务故不得撤销”：不产生第 658 条第 2 款效果。修改句必须承认公证完成前、权利未转移时任意撤销仍在。
- 义务不履行：走第 663 条第 3 项撤销和第 665 条返还，禁止写成合同当然无效或当然解除。
- 实务材料称“附义务=附条件”：纠正。义务不影响合同成立，只影响可否请求履行或法定撤销。
- 第 666 条穷困：只停止尚未履行的赠与；已过户部分不因此自动回流。

## 节点 0　签署状态与成果分流

先于类型识别。命中任一项则本任务不填十节实体结论，只交付分流理由和最小交接。

| 已能支持的事实 | 走向 | 不得写成 |
| --- | --- | --- |
| 无可读正文和附件，或只有口头“房子给侄子让他养老，明天就签” | `附义务的赠与合同·起草` | 已经完成审查；可以签 |
| 未签，目标是评改已有附义务赠与文本 | 进入节点 1 | 已签署或已生效 |
| 残缺模板，用户要按己方条件重写整稿 | `附义务的赠与合同·起草` | 已经完成审查；转通用起草引擎出本类型终稿 |
| 已签，问过户预约日、生活费转账日、探视留痕 | 本套导航的履约步骤 | 签前意见 |
| 已出现催告、解除、索赔、立案、开庭、仲裁，或用户要撤销权诉状 | `已催告解除索赔诉讼或仲裁→` | 继续当签前审查 |

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 无偿给予财产，同时给受赠人设可请求履行或可据以撤销的负担；财产原则上生前交付或过户 | 本类型 | 正触发 |
| 无偿给予，无负担，或只有感恩、不得转卖等附言 | 一般赠与 | 负触发 `一般赠与合同·审查` |
| 用途限于救灾、扶贫、助残等公益或道德义务，关闭的是任意撤销权 | 公益、道德义务赠与 | 负触发 `公益道德义务性质的赠与合同·审查` |
| 房屋过户是主轴，正文无照料或其他可强制负担 | 房产或亲属间房屋赠与 | 负触发 `房产赠与合同·审查` 或 `亲属间房屋赠与合同·审查` |
| 继承人以外的人负责生养死葬，死后取得财产 | 遗赠扶养 | 负触发 `遗赠扶养协议·审查` |
| 只约定赡养费、照料，无财产赠与 | 赡养协议 | 负触发 `赡养协议·审查` |
| 家庭成员分割共同创造或共同持有的财产 | 分家析产 | 负触发 `分家析产协议·审查` |
| 受赠人给付与财产价值相当，或写成“视同已付购房款” | 买卖或服务 | 负触发引擎按有偿合同重定 |

支持切开的规范（法律结论须运行时复核）：

- 第 657、661 条：无偿给予可以附义务——本类型主干。
- 第 658、660 条：任意撤销与请求交付——公证或公益例外，不是“有义务就关闭”。
- 第 1158 条：遗赠扶养是生养死葬、死后受遗赠——转 `遗赠扶养协议·审查`。
- 婚姻家庭编解释（一）第 32 条：婚内一方房产赠与配偶——转 `婚姻家庭中的赠与合同·审查`。

### 1.3 与一般赠与切开（硬闸）

| 文本写法 | 本任务动作 | 修改句方向 |
| --- | --- | --- |
| 财产无偿给予，并有可量化的照料、供养、居住保障或不作为负担 | 正触发，留下本类型 | 首部写明“附义务赠与，不是无负担的一般赠与，也不是遗赠扶养” |
| 标题写附义务，正文无任何负担，或只有“应心怀感恩” | 负触发 `一般赠与合同·审查` | 不按第 663 条第 3 项改完 |
| 真有负担，但整份只写第 658 条、只字不提义务不履行 | 必须改：补第 663 条第 3 项路径 | 不得因为“也是赠与”就只走任意撤销 |
| 房屋过户为主，义务只是“以后常回来看看” | 负触发房屋赠与原子，或必须改：该附言升格为可判断义务，否则整段移交 | 不得在本类型用空附言冒充第 661 条 |

最强反方：受赠人主张“感恩也是义务”，或赠与人主张“既然写了赠与就只能任意撤销”。修改句必须让义务清单自证可判断性，不能靠标题自称。用户坚持把无负担主轴留在本技能放行：负触发，不填本类型十节实体结论。

### 1.4 义务不履行可撤销（硬闸）

支持依据：第 661 条、第 663 条第 3 项、第 665 条。

| 文本写法 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| “好好照顾”“尽孝”“适当看望”“感恩即可” | 必须改：改成可判断行为（居住天数、就医陪同、生活费数额、不得转租等） | 现有空义务已可稳妥启动第 663 条第 3 项 |
| 有义务但无催告、无书面通知、无返还 | 必须补：书面催告 → 仍不履行 → 通知撤销 → 返还或折价 | 不履行即当然无效、当然解除 |
| 已写撤销但无一年期间、无送达地址 | 必须补除斥期间和可核验送达 | 随时可撤、微信已读即送达 |
| 数人共同受赠、共同负担 | 写清连带还是按份；一人退出是否导致整份可撤销 | 一人停履行即整份当然失效 |

修改句：

「受赠人应按照附件二《义务清单》履行义务，包括：每月在【地址】与赠与人共同居住不少于【待填】日；按赠与人就医需要陪同就诊；于每月【待填】日前向赠与人指定账户支付生活费人民币【待填】元。连续【待填】个自然月未达前述标准的，赠与人有权书面催告；催告到达后【待填】日仍未改正的，赠与人可依据民法典第 663 条第 3 项撤销赠与，并依据第 665 条请求返还已交付财产或办理恢复登记。赠与人的该项撤销权，自其知道或者应当知道撤销事由之日起一年内行使。本条不是宣布合同当然无效。」

最强反方：受赠人主张已请他人代为履行，或主张义务是道德宣示。文本必须写清可否替代履行；未写则标 `G#`，不得帮一方写成“已经违约”或“已经履行”。

### 1.5 第 658 条任意撤销与公益例外（硬闸）

支持依据：第 658、660 条。

| 文本写法 | 本任务动作 |
| --- | --- |
| “因本合同已设义务，赠与人不得任意撤销” | 红线或必须改。删除空文。承认权利转移前第 658 条仍适用，除非已公证或属于救灾、扶贫、助残等公益、道德义务赠与 |
| 需要受赠人强制请求交付，但未公证、亦非公益 | 现有依据不支持第 660 条。修改句把公证写成关闭任意撤销、打开请求交付的条件 |
| 已公证，或用途确属公益、道德义务 | 任意撤销窗口关闭；法定撤销（含第 663 条第 3 项）仍在。不得写成“任何撤销权全部消灭” |
| “本合同公证后生效”，同时又要在未公证时约束双方 | 择一写死：签字成立并生效，公证只关闭第 658 条；或公证为生效条件，并写未公证的后果 |

修改句：

「在赠与财产的权利转移之前，赠与人可以依据民法典第 658 条第 1 款撤销尚未转移部分的赠与。双方拟通过公证关闭该项任意撤销权的，应于签字后【待填】日内共同申请办理公证；公证完成前，第 658 条第 1 款仍然适用。本合同所附义务使赠与人本人受益，不属于第 658 条第 2 款的救灾、扶贫、助残等公益、道德义务赠与。受赠人请求交付尚未转移财产的，以本合同已公证或依法属于前款公益、道德义务赠与为前提。」

用户坚持保留“附义务故不可撤销”且拒绝公证、亦不能证明公益例外：该条红线删除，否则停止“可以签署”建议。

### 1.6 逃债 / 规避限购 / 违法义务停笔

加载后或定性中出现：把责任财产无偿转到非债务人名下躲避执行；伪造购房资格；以继续维持不正当关系、限制结婚或人身自由为义务。

动作：

1. 交付告知：违法或违背公序良俗的义务不得改成可履行负担（第 153 条）。逃债式无偿处分可能被债权人撤销，本任务不提供可履行规避。
2. 不写可履行的包养结构、假资格路径或“债权人不得主张”。
3. 风险表只保留识别依据和删除/转出口径。
4. 用户坚持“改到能签且仍做这些事”：整体停止。

## 节点 2　主体、处分权与履约能力

1. 建主体表：赠与人、受赠人、义务受益人、监督人、签字人。名称不一致不自动合并。
2. 赠与人对标的有无处分权。夫妻共同财产附义务赠与第三人：须配偶书面同意。口头“家里都同意了”不得写成已授权。“已附看护义务”不补正无权处分。
3. 受赠人是否具备履行该义务的能力（年龄、健康、居住地、已有同类负担）。受赠人为未成年人的，不得把法定义务之外的过重劳务设为其负担。
4. 法人受赠并承担看护、安置：查文本是否提及许可或经营范围；公司赠与人大额对外赠与：内部决议未附则签署能力字段停止。
5. 共同受赠：写清义务连带还是按份。

修改句：

「赠与人确认：附件一所列财产属于其有权处分的财产；如属夫妻共同财产，须同时取得配偶【待填】的书面同意并作为附件三。未经有处分权人签字的部分，不因本合同已约定看护义务而补正处分权。受赠人确认有能力按附件二履行义务；受赠人为未成年人的，不得对其设立法定义务以外的劳务负担。」

不足：字段停止，列出待补材料，不补主体。

## 节点 3　财产标的、义务标的与权利负担

财产和义务是两条标的，缺一则第 663 条第 3 项或返还都无法定量。

| 列 | 必须看见 | 不得写成 |
| --- | --- | --- |
| 财产识别 | 坐落+证号，或型号数量，或账户与金额 | “名下财产一并赠与”“适当资助” |
| 义务识别 | 行为、标准、起止、履行地、费用承担、可否替代 | “照顾好”“常来看看” |
| 对应关系 | 义务显著轻于标的；部分财产对应部分义务则拆分 | 义务价值接近房价仍按赠与写任意撤销 |
| 权利负担 | 抵押、查封、居住权、租赁 | 材料未提及却写“无权利负担” |

修改句：

「附件一《财产清单》列明本次赠与的财产名称、数量、权属证号或账户信息。附件二《义务清单》列明义务内容、判断标准、起止时间和费用承担。受赠人无需支付价款。义务不得折算为购房款或其他对价。权利负担以签署前查询件为准；查询件与正文冲突的，以查询件为准并停止‘无抵押无查封’的表述。」

看护至终老而转移唯一住房：必须与遗赠扶养、意定监护、养老服务拆开定性。更接近生养死葬换遗产的，负触发 `遗赠扶养协议·审查`，不要用本类型设计提前过户。

## 节点 4　公证、权利转移与履行顺序

把签字成立、公证、交付/过户、义务起算写成不同时点，不写成已经完成。

| 文本写法 | 本任务动作 |
| --- | --- |
| “签字之日房屋所有权即归受赠人” | 红线拆开。不动产自记载于登记簿时变动（第 209、214 条） |
| 先过户、后履行，无居住权、无阶段交付 | 必须改：公证+居住权登记+部分财产先交、义务达标后再交余部；或改道遗赠扶养，死后才转移 |
| 先履行、后过户，未提示任意撤销 | 必须提示：过户前赠与人仍可能依第 658 条撤销未转移部分；受赠人已付出的义务另案主张，本任务只点名不当得利或无因管理，不写成必得 |
| 需要强制交付却只写“不可撤销” | 改成公证条款，落入第 660 条 |
| 用户要求倒签或补假公证 | 整体停止 |

居住权配套句：

「赠与人就【地址】房屋保留终身居住权。各方应于转移登记同时申请居住权登记。居住权自登记时设立。未完成居住权登记前，受赠人不得请求赠与人迁出，也不得将该住宅出租，但赠与人书面同意的除外。」

不得把“双方同意视为已公证/已登记”写成可放行结构。

## 节点 5　法定撤销、返还、穷困与通知

1. 第 663 条三项都可写，本类型重点落在第 3 项。第 1、2 项（严重侵害、法定扶养不履行）可保留，但不代替约定义务的量化。
2. 一年期间自知道或应当知道撤销事由之日起算。第 664 条六个月适用于受赠人违法致赠与人死亡或丧失行为能力。
3. 撤销通知须可核验送达。微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。
4. 第 665 条：撤销后请求返还财产或恢复登记；不能返还的写折价，金额用 `【待填】`。
5. 第 666 条穷困：只停止尚未履行的赠与。已过户房屋不因经济恶化自动恢复登记。
6. 已履行义务对应的已交付财产，不轻易整体打掉；修改句按标的拆分。

修改句：

「出现民法典第 663 条所列情形之一，尤其是受赠人不履行附件二约定义务的，赠与人有权以书面通知撤销赠与。通知自到达受赠人预留地址【待填】之日起发生撤销效力。撤销权人可请求返还赠与财产、办理恢复登记，或就不能返还的部分请求折价人民币【待填】元，并可请求支付占用使用费人民币【待填】元/月。因受赠人违法行为致使赠与人死亡或者丧失民事行为能力的，其继承人或法定代理人的撤销权适用六个月期间。赠与人经济状况显著恶化、严重影响其家庭生活的，可以不再履行尚未履行的赠与；已完成权利转移的部分不因此自动回流。」

## 节点 6　瑕疵担保、格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 瑕疵担保升格

支持依据：第 662 条。

| 文本写法 | 动作 |
| --- | --- |
| “无偿赠与，赠与人对任何瑕疵不承担责任” | 必须改。附义务赠与在所附义务限度内承担与出卖人相同的责任 |
| 故意不告知或保证无瑕疵 | 不得免责。造成损失应赔偿 |
| 受赠人履行义务后发现房屋不能过户 | 标义务中止、费用返还与瑕疵担保并行，不在本任务认定必得金额 |

修改句：

「赠与财产有瑕疵的，赠与人在受赠人所负义务的限度内承担与出卖人相同的责任。赠与人故意不告知瑕疵或者保证无瑕疵，造成受赠人损失的，应当赔偿。任何“无偿故全部免责”的条款，不排除前两句。」

### 6.2 违法义务与无偿性被击穿

以维持不正当关系、限制结婚或人身自由为义务：删除该义务，不改成可履行。触及第 153 条时，可告知整份可能受影响，不宣告必然全部无效（第 156 条：部分无效不影响其他部分的，可保留可分部分）。

义务经济价值接近或超过标的：定性字段停止或负触发有偿合同。不得继续用第 658 条给“名为赠与、实为买卖”设计任意撤销。

### 6.3 格式与强制规范

律所或养老机构重复使用的模板，对免责、放弃撤销权、管辖等异常条款仍审查提示说明。小字、夹在附件、仅有口头宣读：不得写成已尽提示。强制规范按第 153 条和合同编通则解释第 18 条区分，不用失效“效力性/管理性”口诀。

## 节点 7　违约、通知与争议

1. 不履行义务、不协助登记、过户后驱赶赠与人：须分别有催告、撤销+返还、居住权保护或违约金。只有“依法承担违约责任”视为必须改。
2. 构成违约不等于当然解除，也不等于当然无效。
3. 违约金不是必得金额。赠与侧不宜设置对称高额罚则；可就受赠人不履行约定返还+占用使用费。修改句避免“不得调整”或“按房价 30% 必得”。
4. 争议解决：出现仲裁条款，不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核，改成单一仲裁机构或单一法院连结点。涉及不动产过户、居住权的专属管辖可能：只标红旗，不选定唯一法院充作法律意见。
5. 通知送达地址必须可核验，否则撤销期间起算争议放大。

| 步 | 动作 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题用附义务赠与，不用遗赠扶养/买卖/一般赠与混称；列赠与人、受赠人、义务受益人；鉴于不写“故不得撤销” | 标题或主体修改句 |
| 交易条款 | 财产清单；义务清单；无偿性与义务区分；履行顺序；第 658 条窗口；公证 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 第 663 条第 3 项+一年+返还；第 662 条限度内担保；居住权登记；穷困只停未履行部分 | 可执行后果句或删除句 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（无负担主轴、空喊不可撤销拒改、违法义务、倒签或假公证、唯一住房先过户且拒留居住）；
- `必须改`：可谈但签署前要落句（义务量化、催告+撤销返还、公证条款、第 662 条、阶段交付、配偶同意）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级住房被抽走且无居住安排：停止“可以签署”建议。
