# 附义务的赠与合同·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》赠与章及其解释、《物权法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **赠与合同 / 附义务的赠与合同**，输出可编辑草稿、未决项，并在出稿后用本类型硬闸自审。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文名必须是「审查附义务的赠与合同（赠与合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、把一般赠与或遗赠扶养改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **义务不履行可撤销**：所附义务必须写到可判断的行为、标准、期限和监督方式。空写“好好照顾”“尽孝”“感恩即可”的，第 663 条第 3 项几乎无法启动。不履行达到约定程度的，赠与人可请求继续履行，或依第 663 条第 3 项撤销并依第 665 条请求返还；除斥期间为知道或应当知道之日起一年。不得把不履行写成合同当然无效或当然解除。
2. **第 658 条任意撤销与公益例外**：权利转移前，任意撤销权默认仍在。关闭窗口必须公证，或证明具有救灾、扶贫、助残等公益、道德义务性质。合同空写“因已设义务故不得撤销”不够。第 660 条请求交付权只在公证或公益、道德义务赠与时打开。附义务本身不消灭第 658 条。
3. **与一般赠与切开**：无负担，或只有道德性感谢、不得转卖之类不影响定性的附言 → `一般赠与合同·审查`。本技能只审“财产无偿给予 + 受赠人负担可强制或可撤销之义务”。禁止打开或抄写 `一般赠与合同·审查` 的审查路径，禁止把无负担赠与按第 663 条第 3 项改完。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签附义务赠与正文，尚未签署，尚未成争，核心给付是无偿转移财产并给受赠人设负担，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 无负担，或只有感恩、不得转卖等附言 → `一般赠与合同·审查`；
- 用途限于救灾、扶贫、助残等公益或道德义务，关闭的是任意撤销权而非给赠与人设看护负担 → `公益道德义务性质的赠与合同·审查`（P1；专业版未装则 `unavailable`）；
- 房屋过户是主轴且义务不是审查重心 → `房产赠与合同·审查` 或 `亲属间房屋赠与合同·审查`；
- 继承人以外的人承担生养死葬、死后取得财产 → `遗赠扶养协议·审查`（P1；未装则 `unavailable`）；
- 主给付是赡养费、照料，无财产赠与 → `赡养协议·审查`；
- 家庭共有财产分割，不是把自己的财产无偿给予 → `分家析产协议·审查`；
- 义务价值接近标的或写成“视同已付购房款” → 本套导航的类型切开步骤 按有偿合同重定；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问过户日、生活费支付日 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `已催告解除索赔诉讼或仲裁→`。

维持不正当关系、限制结婚或人身自由、逃债、规避限购：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（赠与人 / 受赠人 / 义务受益人或监督人择一）；相对方；全文及财产清单/义务清单版本；义务内容、标准、期限、费用和可否替代；财产权属、共有、抵押查封、是否唯一住房；是否已公证或拟公证；履行顺序；义务是否合法、是否过重到击穿无偿性；是否更接近遗赠扶养或一般赠与；不可接受事项；法域、财产所在地与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方互斥秘密时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的金额、期限、天数用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验第 661、663、658、660、662、665 条及遗赠扶养、公益赠与切开；`search_practiced` 只补审查反例；`search_template` 只借栏目结构。不虚构案件系统。

`search_law` 对上述法律结论为 required 级：不可用时不拒绝执行，只停止效力字段。返回已失效《合同法》赠与章或其解释、《物权法》时记为噪声，不得写入 `L#`。


## 起草模式

本原子只承担本类型起草。待签评改转 `附义务的赠与合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`，不编造。出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 所附义务必须写到可判断的行为、标准、期限和监督方式。财产无偿给予 + 受赠人负担可强制或可撤销之义务，两条都要闭环。
- 义务不履行可撤销：不履行达到约定程度的，赠与人可请求继续履行，或依第 663 条第 3 项撤销并依第 665 条请求返还；除斥期间为知道或应当知道之日起一年。
- 第 658 条任意撤销默认仍在。关闭窗口必须公证，或证明具有救灾、扶贫、助残等公益、道德义务性质。第 660 条请求交付权只在公证或公益、道德义务赠与时打开。附义务本身不消灭第 658 条。

### 附件必附

- 财产清单，确定到可返还。
- 义务清单，确定到可判断。缺金额、期限、天数用 `【待填】`。

### 禁止出现

- 空写“好好照顾”“尽孝”“感恩即可”。
- 不履行写成合同当然无效或当然解除。
- 合同空写“因已设义务故不得撤销”。
- 把无负担赠与按第 663 条第 3 项起草。
- 维持不正当关系、限制结婚或人身自由、逃债、规避限购的可履行结构。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`框架.md` 中空喊“不可撤销”不得当成第 658 条已经关闭。义务不履行不得写成合同当然无效。禁止打开 `一般赠与合同·审查` 的 method。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 本任务起草模式；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有附义务赠与文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。无负担、公益赠与、遗赠扶养、有偿合同负触发。

### 2. 主体、处分权与履约能力

赠与人处分权、配偶同意、受赠人能否履行该义务。未成年人不得被设过重劳务。

### 3. 财产与义务双标的

财产确定到可返还；义务确定到可判断。材料未提及负担不得写成“无权利负担”。

### 4. 公证、权利转移与履行顺序

拆开合同生效、任意撤销窗口和物权变动。先过户后履行必须配居住权或阶段交付。

### 5. 法定撤销、返还与穷困

第 663 条第 3 项、一年期间、书面通知、第 665 条返还。第 666 条只停尚未履行部分。

### 6. 瑕疵担保、违法义务与强制规范

第 662 条在义务限度内升格。违法或违背公序良俗的义务不得改成可履行。无核验引文则法律结论字段停止。

### 7. 违约、通知与争议

催告、撤销通知送达、专属管辖红旗。不选定唯一法院充作意见。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、假公证、保证有效、把违法义务/逃债/规避限购改成可履行结构。
- `字段停止`：法域、动态规则、登记簿、公证能否办成、义务是否构成对价未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
