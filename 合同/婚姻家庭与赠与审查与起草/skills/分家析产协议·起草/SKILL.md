# 分家析产协议·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **婚姻家庭 / 分家析产协议**，输出可编辑草稿、未决项，并在出稿后用本类型硬闸自审。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文名必须是「审查分家析产协议（婚姻家庭）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、把离婚财产或赠与改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **家庭共有分割**：只分割已能支持属于家庭共有的财产。清单必须切开家庭共有 / 父母个人 / 夫妻共同 / 子女个人。处分共同共有财产须全体共同共有人同意。漏签或漏列共有人：该份额处分字段停止，不得写成已可过户。
2. **登记对抗**：协议对签字方成立，不等于物权已经变动。不动产自记载于登记簿时发生物权变动；机动车未经登记不得对抗善意第三人；居住权自登记时设立。禁止把“签字按指印之日所有权即归某某”写成已经取得可对抗第三人的物权。
3. **债权人**：名为分家、实为把责任财产转到非债务人名下影响债权实现：只告知，不改成可履行转移。家庭共同债务对外连带，不因内部分担而消灭。未登记、未经债权人认可的分割，不得写成已排除查封。用户坚持逃债结构：整体停止。
4. **与离婚财产/赠与切开**：解除婚姻并分割夫妻共同财产为主轴 → `离婚协议·审查`；仅夫妻二人约定婚内或婚前财产归属 → `夫妻财产约定·审查`；把登记在个人名下、无家庭共有形成过程的财产无偿给晚辈为主轴 → `亲属间房屋赠与合同·审查`、`一般赠与合同·审查` 或 `附义务的赠与合同·审查`。不得把真析产改成赠与任意撤销，也不得把离婚财产条款当本类型审完。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签分家析产或家庭财产分割正文，尚未签署，尚未成争，核心给付是分割家庭共有财产，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 解除婚姻并处理夫妻共同财产、子女抚养、债务 → `离婚协议·审查`；
- 仅夫妻二人书面约定婚内或婚前财产归属 → `夫妻财产约定·审查`；
- 分居期间生活安排、尚未解除婚姻且无家庭共有分割主轴 → `分居协议·审查`；
- 登记在个人名下、形成过程无其他家庭成员共有依据的财产无偿给予晚辈 → `亲属间房屋赠与合同·审查`、`一般赠与合同·审查`、`附义务的赠与合同·审查` 或 `房产赠与合同·审查`；
- 被继承人已死亡后的遗产安排，或单方死后处分 → `遗嘱·审查`（P1；专业版未装则 `unavailable`）；
- 继承人以外的人承担生养死葬、死后取得财产 → `遗赠扶养协议·审查`（P1；未装则 `unavailable`）；
- 主给付是给付赡养费、照料，无家庭共有分割 → `赡养协议·审查`；
- 主给付是扶养或抚养费，无家庭共有分割 → `扶养抚养协议·审查`；
- 主文件只设立居住权、无析产清单 → `居住权设立合同·审查`（P1；未装则 `unavailable`）；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问过户日、补偿款支付日 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `已催告解除索赔诉讼或仲裁→` 或对应家事/执行专项。

逃债、规避限购、对外流转宅基地：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（分得主要财产方 / 折价补偿方 / 父母或长辈 / 被漏列共有人择一）；相对方；全文及清单/示意图版本；财产形成过程能否支持家庭共有；全体共同共有人是否到场；不动产、车辆、股权登记与抵押查封；分家前家庭共同债务；是否夹带离婚或赠与主轴；宅基地成员身份；不可接受事项；法域、财产所在地与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方或多方互斥秘密时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的补偿额、期限、份额用 `【待填】`，不编造。

## 起草模式

本原子只承担本类型起草。待签评改转 `分家析产协议·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务起草并自审。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`，不编造。出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 只分割已能支持属于家庭共有的财产。清单必须切开家庭共有 / 父母个人 / 夫妻共同 / 子女个人。
- 处分共同共有财产须全体共同共有人同意。漏签或漏列共有人：该份额不得写成已可过户，标字段停止。
- 协议对签字方成立，不等于物权已经变动。不动产自记载于登记簿时发生物权变动；机动车未经登记不得对抗善意第三人；居住权自登记时设立。过户义务、期限、未完成后果必须落句。
- 家庭共同债务对外连带，不因内部分担而消灭。

### 附件必附

- 财产清单（按上述四类切开，证号、四至或示意图未给用 `【待填】`）。
- 全体共同共有人签署页。漏列则该份额处分不得出可履行过户稿。

### 禁止出现

- “签字按指印之日所有权即归某某”、已经取得可对抗第三人的物权。
- 未登记、未经债权人认可的分割写成已排除查封。
- 名为分家、实为把责任财产转到非债务人名下的可履行转移。
- 把真析产改成赠与任意撤销，或把离婚财产条款当本类型起草。
- 逃债、规避限购、对外流转宅基地的可履行结构。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`框架.md` 中“签署日期是所有权转移时点”不得当成物权已经变动。`框架.md` 中“受赠人有权撤销析产”不得写成第 658 条任意撤销已经适用。

### 0. 签署状态与成果分流

有完整待签文本要评改 → `分家析产协议·审查`；本类型条件已谈妥要出己方稿 → 本任务起草并自审。已签履约 → 履约步骤；已成争 → 争议领域。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。离婚财产、夫妻约定、赠与、遗嘱/遗赠扶养、纯赡养负触发。

### 2. 家庭共有分割与主体闭合

清单切开财产性质。全体共同共有人签字。漏列则该份额停止。

### 3. 标的、负担与宅基地

证号、四至或示意图；抵押查封；农房成员身份。材料未提及负担不得写成“无权利负担”。

### 4. 登记对抗与居住权

拆开合同生效与物权变动。过户义务、期限、未完成后果。居住权须单独登记。

### 5. 债权人与共同债务

债务清单；对外连带；逃债停笔。

### 6. 赡养挂钩、格式与强制规范

分家不消灭法定赡养。生男丁才分房等条件不得改成可履行。无核验引文则法律结论字段停止。

### 7. 违约、协助过户与争议

不配合登记、不支付折价须有可执行后果。不选定唯一法院充作意见。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把逃债/规避限购/对外流转宅基地改成可履行结构。
- `字段停止`：法域、动态规则、登记簿、成员资格、共有形成过程未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
