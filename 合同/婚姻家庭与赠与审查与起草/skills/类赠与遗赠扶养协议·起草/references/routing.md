# 边界与路由

本技能只起草 **赠与合同 / 遗赠扶养协议（与赠与合同有区别的 “类赠与” 协议）** 的待签文本。中文展示名是「审查遗赠扶养协议（与赠与合同有区别的 “类赠与” 协议）（赠与合同）」。

从赠与父级切开：经济效果像赠与，法律结构是继承编双务有偿协议。生养死葬换死后遗产，不是无偿赠与，也不是婚姻家庭货架同名文本的换皮。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开下表邻类的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 用户或文本明确走婚家/继承编货架；主线是家庭伦理、必留份精算或法定继承安排，不要赠与切开 | `遗赠扶养协议·审查`；未装则 `unavailable` |
| 子女、配偶、父母作“扶养人”换房产 | `赡养协议·审查` |
| 无偿给予且拟生前转移；正文保留任意撤销并立即过户 | `附义务的赠与合同·审查`、`一般赠与合同·审查` 或 `房产赠与合同·审查` |
| 死后过户，但无生养死葬、无生活照料对价 | `生前类赠与协议·审查` 或 `遗嘱·审查` |
| 单方遗嘱，可另立遗嘱撤回 | `遗嘱·审查` |
| 意定监护、只解决代理 | `意定监护协议·审查` |
| 机构收费养老，不主张遗产 | 转引擎按服务合同重定 |
| 仅设立居住权、不过户所有权 | `居住权设立合同·审查` |
| 救灾、扶贫、助残等公益赠与是主文件 | `公益道德义务性质的赠与合同·审查` |
| 家庭共有财产分割、分家析产 | `分家析产协议·审查` |
| 无可读正文，本类型条件已谈妥，要出己方稿 | 本任务起草并自审 |
| 已签未争、只问照料打卡日、丧葬日、过户日 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `已催告解除索赔诉讼或仲裁→` 或对应专项领域 |
| 继承人已起诉确认无效、侵占或逃债立案 | 争议或家事/执行专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

遗赠扶养正文里夹带一小段居住保障或费用账册：专章可继续审。用户坚持本技能把婚家遗赠扶养、附义务赠与、遗嘱或赡养整案改完：`目标停止`。禁止打开 `遗赠扶养协议·审查`、`遗嘱·审查`、`生前类赠与协议·审查`、`一般赠与合同·审查`、`公益道德义务性质的赠与合同·审查` 或赠与原子 method。

专业版未收录的 P1 场景不会安装本原子。若用户拿本类型文本来找未收录本原子的专业版：输出 `unavailable`，提示，不得用邻类硬套。
