# 边界与路由

本技能只审查 **婚姻家庭 / 同居财产约定** 的待签文本。中文展示名是「审查同居财产约定（婚姻家庭）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 已办理结婚登记，或 1994 年 2 月 1 日前符合结婚实质要件按事实婚姻处理；约定婚内所得或婚前财产归属 | `夫妻财产约定·审查`。不得删掉婚姻关系后继续当同居约定审 |
| 解除婚姻，并处理夫妻共同财产、子女抚养或夫妻债务 | `离婚协议·审查` |
| 分居期间居住、开支，婚姻未解除 | `分居协议·审查` |
| 主轴是忠诚义务、出轨违约金 | `夫妻忠诚协议·审查` |
| 主轴是终止同居时一次性结算、分手费、青春补偿、互不纠缠、搬离交接 | `分手协议·审查`。不得改个标题后当存续期约定审完 |
| 主给付是一方无偿给予另一方房屋、股权或大额财产 | `一般赠与合同·审查`（一般赠与）、`婚姻家庭中的赠与合同·审查`（婚姻家庭中的赠与）、`涉及不正当男女关系的赠与合同·审查`（涉及不正当男女关系的赠与）或 `房产赠与合同·审查`（房产赠与） |
| 家庭成员分割家庭共有财产，不是同居二人内部约定 | `分家析产协议·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `同居财产约定·起草` |
| 已签未争、只问过户日、搬离日或补偿款支付 | 本套导航的履约步骤 |
| 已成争，或用户要已分手后的析产事实评估、撤销权/无效确认诉讼策略 | `已催告解除索赔诉讼或仲裁→` 或 `或` |
| C 端大众快检 | 只分流，不回改 |
| 专业版未装本 P1 原子 | `unavailable`，提示，不得用邻类硬套 |

同居正文里夹带一小段劳务补偿或经济帮助：可留在本约配套条款审，但金额须挂钩实际开支差额或家务贡献，不得写成无对价分手费。夹带一小段无偿加名：该条交接赠与原子或必须改成按份共有出资确认；其余存续期归属、开支和债务条款继续审。用户坚持本技能把夫妻财产约定、分手协议或赠与整案改完：`目标停止`。
