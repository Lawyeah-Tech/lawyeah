# 同居财产约定·审查

## 任务目标

在单一立场下，只审查 **婚姻家庭 / 同居财产约定** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查同居财产约定（婚姻家庭）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、把夫妻财产约定/分手协议/赠与改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **非婚姻财产制**：未办理结婚登记的，不适用法定夫妻共同财产、夫妻共同债务推定、离婚经济补偿和配偶继承。无约定时，工资、奖金、劳务报酬、知识产权收益、各自继承或受赠以及单独生产经营投资收益归各自所有；共同出资购置或共同生产经营投资及其他无法区分的财产，以出资比例为基础，综合考虑共同生活、有无共同子女和贡献分割。禁止写成“视同夫妻共同财产对半分”。
2. **与分手协议切开**：主轴是终止同居时一次性结算、分手费、青春补偿、互不纠缠 → `分手协议·审查`。本类型只管存续期归属、开支分担和解除时的清算规则。
3. **与赠与切开**：主给付是一方将自己的财产无偿给予另一方 → `一般赠与合同·审查`、`婚姻家庭中的赠与合同·审查`、`涉及不正当男女关系的赠与合同·审查` 或 `房产赠与合同·审查`。夹带赠与条必须标权利转移前可任意撤销；公证或依法不得撤销的除外。不得写成已经取得物权或已经不可撤销。
4. **婚外同居停笔**：一方或双方有配偶，文本以补偿、分手费或转移夫妻共同财产为对价：只告知违背公序良俗和配偶主张无效的风险，不改成可履行的婚外补偿结构。用户坚持：整体停止。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签同居财产协议或同居期间财产权属约定正文，尚未签署，尚未成争，双方主张均无配偶或至少未提交已婚事实，核心给付是约定同居期间财产归属、管理、开支分担及解除时按该规则清算，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 已办理结婚登记，或 1994 年 2 月 1 日前已符合结婚实质要件按事实婚姻处理 → `夫妻财产约定·审查`；
- 解除婚姻并处理夫妻共同财产、子女抚养、债务 → `离婚协议·审查`；
- 分居期间生活安排，婚姻未解除 → `分居协议·审查`；
- 主轴是忠诚义务与违约金 → `夫妻忠诚协议·审查`；
- 主轴是终止同居时一次性结算、分手费、青春补偿、互不纠缠 → `分手协议·审查`；
- 主给付是一方无偿给予另一方房屋、股权或大额财产 → `一般赠与合同·审查`、`婚姻家庭中的赠与合同·审查`、`涉及不正当男女关系的赠与合同·审查` 或 `房产赠与合同·审查`；
- 家庭成员分割家庭共有财产，不是同居二人内部约定 → `分家析产协议·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `同居财产约定·起草`；
- 已签只问过户日、搬离日、补偿款支付日 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁，或用户要已分手后的事实评估 → `已催告解除索赔诉讼或仲裁→` 或 `或`。

婚外补偿、规避限购、把夫妻共同财产转到同居对方名下：只出告知，不改写成可履行结构。

专业版未收录本 P1 原子。若用户拿本类型文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。

## 建立审查坐标

确认：使用者与授权；单方立场（各自所有方 / 共同出资方 / 劳务补偿方择一）；相对方；全文及清单版本；双方婚姻状况；同居开始日与解除认定标准；财产是各自所得、共同出资还是共同经营；登记名义人；钱款摘要性质；父母出资；是否夹带分手费或无偿过户；不可接受事项；法域、财产所在地与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方互斥秘密时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的份额、金额、期限用 `【待填】`，不编造。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`框架.md` 中“自动转化为夫妻财产约定”不得写成已经取得对外效力。`基本面.md` 中“配偶行使撤销权”按解释（二）第 7 条纠正为公序良俗无效路径，不写成必然胜诉。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `同居财产约定·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议或家事专项。未签且目标是评改已有同居财产约定文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。夫妻财产约定、分手协议、赠与、离婚/分居负触发。

### 2. 主体与婚姻状况

双方无配偶才能按解释（二）第 4 条普通同居析产约定审。有配偶：婚外补偿停笔。

### 3. 财产分层与钱款性质

切开同居前个人、同居期间各自所得、共同出资/共同经营。资助、借款、赠与、共同投资必须分列。

### 4. 登记对抗

拆开合同生效与物权变动。产证只登记一人，不得写成已可对抗善意第三人。

### 5. 债务防火墙

无夫妻共同债务推定。个人名义债务原则上个人承担；联名贷款或共同经营之债单独列。

### 6. 公序良俗、格式与强制规范

分手费、青春补偿、排除诉权、婚外对价。无核验引文则法律结论字段停止。

### 7. 解除清算与争议

解除认定标准、搬离、清算时点、管辖。不选定唯一法院充作意见。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把婚外补偿/转移夫妻共同财产/规避限购改成可履行结构。
- `字段停止`：法域、动态规则、婚姻状况、登记簿、出资性质未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
