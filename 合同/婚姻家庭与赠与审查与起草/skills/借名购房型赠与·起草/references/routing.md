# 边界与路由

本技能只起草 **赠与合同 / “以他人名称购房并支付房款” 型赠与合同** 的待签、出资人与名义购房人之间的无偿确认文本。中文展示名是「审查“以他人名称购房并支付房款” 型赠与合同（赠与合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开下表邻类 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 要审的是开发商预售／现售本约、五证、面积误差、按揭放款主路径 | `真实房屋买卖，买受人取得所有权`。禁止打开其 method |
| 名买卖实担保：到期还本、回购、流质、担保债权 | `文本写到期还本回购担保债权流质或“先过户再还钱把房拿回”→负触发`。禁止打开其 method |
| 存量房买卖、卖方是原登记权利人且有房价 | `或` |
| 约定房屋实际归出资人，登记人仅出名；“先用你的名、满年限转回” | 转引擎重新定性（房屋借名）。不按本类型赠与改完 |
| 标的是现金或动产，与名购房结构无关 | `一般赠与合同·审查`。禁止打开其 method |
| 救灾、扶贫、助残等公益、道德义务是主线 | `公益道德义务性质的赠与合同·审查`。禁止打开其 method |
| 近亲属或家庭内部；主线是赡养、只赠一方、婚内加名 | `婚姻家庭中的赠与合同·审查` 或 `亲属间房屋赠与合同·审查`。禁止打开 `婚姻家庭中的赠与合同·审查` method |
| 不直接支付对价的其他财产转移，不是“以他人名称购房并付款” | `无对价财产转移赠与·审查`。禁止打开其 method |
| 出资人已是登记权利人，再过户给对方 | `房产赠与合同·审查` |
| 有限公司实际出资人与名义股东、显名 | `或` |
| 出资人要求返还资金、不主张房屋 | `或` 或 `或` |
| 双方按份出资或约定共有 | 转引擎；共有或合伙购买，不按单方赠与改完 |
| 死后生效、遗嘱或遗赠过户 | `生前类赠与协议·审查` |
| 无可读正文，本类型条件已谈妥，要出己方稿 | 本任务起草并自审 |
| 已签未争、只问网签日、放款日、缴税日 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `已催告解除索赔诉讼或仲裁→` 或对应专项领域 |
| 债权人已提起撤销、执行异议 | 争议或执行专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

本类型确认书附件里夹带一份商品房买卖合同复印件：买卖合同只作标的特定化附件，不在本任务按 `真实房屋买卖，买受人取得所有权` 改完。用户坚持本技能把买卖本约、让与担保或借名留房整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
