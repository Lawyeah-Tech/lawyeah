# 审查方法（锁定 婚姻家庭 / 意定监护协议）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止打开或复制 `遗赠扶养协议·审查`、`类赠与遗赠扶养协议·审查`、`监护权协议·审查` method。禁止套用遗赠扶养的生养死葬、死后财产归属、扶养费用返还、继承人以外身份限制、效力优于遗嘱节点。禁止套用监护权协议的资格人会签、父母离异监护交接、免除有监护能力父母职责节点。禁止把本技能写成遗赠扶养或监护权协议换标题。

定性校验：核心安排是完全行为能力成年人自己预选监护人，并以丧失或部分丧失民事行为能力为职责触发，才继续；明显他类则负触发，不填十节实体结论。

本文件是可执行判断节点，不是栏目说明书。每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、法院必然指定、公证后窗口必然配合，或口头也算意定监护。

`search_law` 返回已失效《合同法》《民法总则》《继承法》及其解释、2002 年《公证程序规则》、2018 年已被修改的《妇女权益保障法》、2009 年已被修改的《老年人权益保障法》条文时记为噪声，不得写入 `L#`。`search_practiced` 仍写“未公证一律无效”“口头也算意定监护”“医院诊断等于行为能力宣告”“意定监护具有最高顺位故法院不得再指定他人”的，同样记噪声。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

示范文本只参考结构。写“监护人自行认定失能后即可处分全部财产”或“死后财产归监护人所有”的范本与职责限制、与遗赠扶养切开冲突，不得当规则。

知识库口径冲突以本方法为准，不回写知识正文：

- `基本面.md` 称公证“准必要”、职能部门通常仅认可公证文本：纠正为民法典未强制公证；未公证不得写成无效；窗口可能另要公证或法院文书，但不得写成必然拒绝。
- `基本面.md` 称意定监护具有最高法律顺位、法院或民政不得再按法定顺序指定他人：纠正为有效且监护人愿意并能履职时，优先于法定顺序；签约时能力被否定、监护人有第三十六条情形或不能履职的，仍可能另指定。不得保证指定结果。
- `框架.md` 把医院评估、医学鉴定与法院司法程序并列成等价触发：纠正为诊断和鉴定是启动材料；行为能力认定的法定路径是人民法院特别程序。不得把医院诊断写成已经完成宣告。
- `框架.md` 要求必须按指印：纠正为书面和亲签是底线；按指印、录音录像是补强，不是民法典强制。
- 以“失智/失能”单独替代法律用语：修改句改为“丧失或者部分丧失民事行为能力”。

开发窗口 2026-08-18 已核验、可供对照但不得代替运行时核验的规则：

- 民法典第 24 条：不能辨认或不能完全辨认自己行为的成年人，利害关系人或有关组织可申请人民法院认定其为无或限制民事行为能力人；也可申请恢复。
- 民法典第 28 条：无或限制民事行为能力成年人的法定监护顺序：配偶；父母、子女；其他近亲属；其他愿意担任者须经住所地居委会、村委会或民政同意。
- 民法典第 30 条：依法具有监护资格的人之间可以协议确定监护人，并应尊重被监护人真实意愿。此条是监护权协议主线，不是本类型成立依据。
- 民法典第 31 条：对监护人确定有争议的，由住所地居委会、村委会或民政指定，也可直接申请法院指定；指定前可安排临时监护；指定后不得擅自变更。
- 民法典第 33 条：具有完全民事行为能力的成年人，可以与近亲属、其他愿意担任监护人的个人或组织事先协商，以书面形式确定自己的监护人，在自己丧失或者部分丧失民事行为能力时，由该监护人履行监护职责。
- 民法典第 34 条：监护职责是代理实施民事法律行为，保护人身、财产及其他合法权益；依法履职产生的权利受保护；不履行或侵害应承担法律责任；紧急情况下住所地基层组织或民政安排临时照料。
- 民法典第 35 条：按最有利于被监护人的原则履职；除为维护被监护人利益外不得处分其财产；成年人监护须最大程度尊重真实意愿，保障并协助其实施与智力、精神健康状况相适应的行为；对有能力独立处理的事务不得干涉。
- 民法典第 36 条：严重损害身心健康、怠于履职致危困、严重侵害合法权益的，法院可撤销监护资格并指定监护人。
- 民法典第 39 条：恢复完全行为能力、监护人丧失监护能力、一方死亡、法院认定的其他情形，监护关系终止。
- 民法典第 135 条：法律、行政法规规定或当事人约定采用特定形式的，应当采用该形式。
- 民法典第 469 条：书面形式包括合同书、信件、电报、电传、传真及可随时调取查用的数据电文。
- 总则编解释第 6 条：认定监护能力应考虑年龄、身心、经济等；组织应考虑资质、信用、财产状况。
- 总则编解释第 8 条：约定免除有监护能力父母职责的，法院不予支持。此条服务监护权协议切开，不写入本约成立要件。
- 总则编解释第 9 条：法院指定监护应尊重意愿并按最有利于原则，参考生活情感联系、顺序、违法犯罪、监护能力等。
- 总则编解释第 11 条：依第三十三条订立书面协议后，该成年人丧失或部分丧失民事行为能力前，任何一方请求解除，法院依法支持；失能后，协议确定的监护人无正当理由请求解除，不予支持。失能后监护人有第三十六条第一款情形的，可申请撤销。
- 公证法第 38 条：法律、行政法规规定未经公证不具有法律效力的，依照其规定。民法典第三十三条未作此规定。
- 公证程序规则（2020 修正）第 36 条：民事法律行为公证须具备资格与相应行为能力、意思真实、内容形式合法。
- 不动产登记暂行条例实施细则（2024 修正）第 11 条：无或限制行为能力人申请不动产登记应由监护人代为申请；处分不动产还须提供为被监护人利益的书面保证；父母之外的监护人处分未成年人不动产时，监护关系材料可以是法院指定文书、经过公证的享有监护权材料或其他材料。成年人意定监护履职时，窗口常类推要求公证或裁判文书。
- 电子签名法（2019 修正）第 3 条：不得仅因采用电子签名、数据电文否定效力的规则，不适用于涉及婚姻、收养、继承等人身关系的文书。意定监护具有身份属性，电子签署不得写成必然有效。

本次检索未返回可写入 `L#` 的正文，运行时必须重核、不得凭记忆落法律结论：《老年人权益保障法》关于老年人协商确定监护人的现行条号；民事诉讼法认定行为能力与指定监护特别程序的现行条号。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用核心给付定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须同时满足才正触发：

1. 设立人是为自己预先确定监护人的成年人，且文本或用户陈述将其定位为签署时具有完全民事行为能力。
2. 安排以书面形式确定监护人，并以丧失或者部分丧失民事行为能力为监护职责触发。

必须切开，禁止两可时灌入两套知识：

| 信号 | 归入 | 本技能动作 |
| --- | --- | --- |
| 标题或正文为意定监护，自己选自己的监护人，失能后履职 | 本类型 | 加载本目录双文件 |
| 生养死葬、死后房产存款归对方、扶养费用、继承人以外身份限制 | `遗赠扶养协议·审查` 或 `类赠与遗赠扶养协议·审查` | 负触发；不写死后财产归监护人主路径 |
| 父母离异未成年子女监护；子女为已失能父母协商谁当监护人；资格人之间协议确定监护 | `监护权协议·审查` | 负触发；不会签资格人作为成立要件 |
| 单方死后处分财产，无失能触发的监护职责 | `遗嘱·审查` | 负触发 |
| 仅一般委托代理，不以失能为监护职责触发 | 引擎重新定性 | 负触发 |
| 居住权、仅住房使用权 | `居住权设立合同·审查` | 负触发 |

### 1.3 违法或越权结构停笔

加载后或定性中出现：设立人已明显无完全行为能力仍要签署；胁迫、隔离、代签；伪造体检、鉴定或公证；指导把住房或主要存款预先过户给监护人以规避继承人、债权人或赡养义务；把监护人自行认定失能并立即卖房写成可履行。

动作：

1. 交付告知：该结构可能违反强制性规定或侵害被监护人及其他权利人，不得改写成可履行文本。
2. 不写假能力、假公证、假过户、可对抗继承人的预先转移路径。
3. 风险表只保留识别依据和转出/改道提示。
4. 用户坚持“改到能签、能直接卖房、能保证法院指定”：整体停止。

合规改道（补书面亲签、补公证、补监督、另件处理遗嘱或遗赠扶养）只点名，不在本任务起草他类文本。

## 节点 2　主体、签署时能力与监护能力

1. 建主体表：设立人、拟任监护人、监督人、后备监护人。名称不一致不自动合并。关系必须写明（子女、朋友、同居者、社会组织等）。
2. 设立人必须是成年人。材料显示未成年人：负触发监护权协议或引擎。
3. 签署时能力：文本应有能力声明。近半年病历、体检、认知筛查未出示：不得写成“现有依据支持签署时具有完全行为能力”，只能写材料不足。出现认知障碍、血管性痴呆、器质性精神障碍等迹象且无足以闭合的反证：字段停止或整体停止，建议先做能力评估，不放行签署。
4. 代签、他人按指印、设立人未到场：整体停止。
5. 监护人可以是近亲属、其他个人或组织。组织须识别名称与履职能力迹象。口头“居委会同意了”不得写成已同意。
6. 总则编解释第 6 条：监护能力应结合年龄、身心、经济；组织结合资质、信用、财产。材料不足则该字段停止，不补“具备监护能力”。
7. 拟任监护人与第一顺位继承人严重对立：标红旗，提示失能后可能被申请撤销或另指定，不得写成可以排除子女一切异议。

不足：字段停止，列出待补材料，不补主体、不补已有能力、不补已同意。

## 节点 3　书面形式与公证实践（硬闸）

第三十三条以书面形式为法定要求。第一百三十五条：法律要求特定形式的，应当采用该形式。第四百六十九条界定书面。公证不是该条的生效要件。公证法第三十八条只在法律、行政法规另有规定时，未经公证才不发生相应效力。

| 文本写法 | 本任务动作 |
| --- | --- |
| 仅口头或聊天“以后你管我” | 不写成已成立。无书面正文则负触发起草 |
| 有书面正文但无亲签栏、由子女代签 | 红线。必须本人签 |
| “双方微信确认即视为书面意定监护” | 必须改。数据电文或可讨论书面，但人身关系对电子签名有限制；修改句改为纸质合同书亲签 |
| “未经公证本协议无效” | 必须改。公证不是法定生效要件；可改为“双方应于签署后【待填】日内共同申请公证，未完成公证不影响协议成立，但监护人持本协议向银行、医院、不动产登记机构办理事务时可能不被接受” |
| “签字即视为已公证” | 红线。禁止拟制公证 |
| 无公证安排 | 可接受可优化或必须改（视用户风险偏好）。给出建议公证句，不写未公证无效 |
| 用户要求把公证日期倒签或补假公证书 | 整体停止 |

反方常见抗辩：未公证所以无效；或反过来，未公证也必然被窗口接受。两句都不得写成已核验结论。

## 节点 4　监护职责、医疗决策与财产处分（硬闸）

第三十四条、第三十五条是职责底线。协议可以细化，不能写到低于或相反。

| 文本写法 | 本任务动作 |
| --- | --- |
| 只写“全权处理甲方一切事务” | 必须改。分列生活照料、医疗决策、财产管理、维权代理 |
| “监护人有权自由出售甲方名下全部房产并自行收款” | 红线。改为：除为维护设立人生活、医疗、养老利益外不得处分重大财产；出售住房等须监督人书面同意，并提供为被监护人利益的说明 |
| 医疗条款空白 | 必须改。写明无法表达时的代理范围；如有医疗预嘱，作为附件且监护人应遵循 |
| “监护人可决定放弃一切治疗且无需记录” | 红线或必须改。重大医疗应尊重预先意愿并留痕；不得写成可任意放弃生存级救治且不受监督 |
| 日常开支与卖房、赠与、担保混在同一句 | 必须改。切开日常管理与重大处分 |
| 不写尊重真实意愿 | 必须改。写入第三十五条第三款表述 |
| 把财产写成“归监护人所有/共同共有” | 红线。删除归己；财产仍为设立人所有，监护人只是管理及保护 |

清算或对价句不属于本类型。不得把扶养费用、死后财产折价、多退少补从遗赠扶养抄进来充当职责条款。

## 节点 5　触发条件与行为能力认定（硬闸）

职责开始以“丧失或者部分丧失民事行为能力”为法定触发，不是签字当日。行为能力认定走人民法院特别程序。诊断和鉴定可以约定为申请材料。

| 文本写法 | 本任务动作 |
| --- | --- |
| “本协议签字后乙方立即开始履行监护职责、接管全部银行卡” | 红线或必须改。拆成：协议自签字之日起成立；职责自设立人丧失或部分丧失民事行为能力时开始 |
| “以乙方自行判断甲方失智为准” | 红线。删除自行认定 |
| “三甲医院一张诊断证明即视为已丧失行为能力，乙方可立即卖房” | 必须改。诊断可作为申请法院认定或启动临时照料的材料，不代替宣告，更不自动授权处分重大财产 |
| 未写如何启动认定 | 必须改。约定申请主体、鉴定配合、必要时申请法院认定；未完成认定前不得按已失能履职，紧急情况走临时照料，不走卖房 |
| 用户要求保证医院诊断后法院必然认定 | 拒绝保证；该字段停止 |

反方常见抗辩：有诊断就是失能。本任务不得把该抗辩写成可放行结构。

---

## 节点 6　监督、后备、报酬、解除与撤销

1. 无监督人：重大财产处分不得放行。修改句增设监督人、报告周期、重大事项同意权。用户拒绝任何监督：停止“可以签署”建议。
2. 后备监护人：首选不能履职时的顺位。正说必须有反说（何种情形启动后备）。
3. 报酬：无偿或有偿必须明确；有偿写标准、支付时间、从设立人财产列支、监督复核。不得写成从遗产中必然优先支付从而架空继承。
4. 解除：失能前任何一方可书面解除（总则编解释第 11 条第一款）。失能后监护人无正当理由不得解除。设立人在仍有完全行为能力期间可书面撤销或修改。
5. 撤销监护：提示第三十六条路径，不得写成协议可以排除法院撤销。
6. 终止：对照第三十九条列恢复能力、丧失监护能力、死亡等，并约定仍需监护时如何启动后备或依法另行确定。

## 节点 7　强制规范、窗口材料与死后事务

1. 非书面、无能力签署、胁迫：效力法律结论须 `search_law` 后落；无核验则字段停止。
2. 窗口履职：银行、医院、不动产登记可能另要公证或裁判文书。修改句建议公证，并准备身份、协议、公证书或指定文书。不得保证某一窗口必然接受。
3. 处分不动产：提示须为被监护人利益的书面保证；父母之外的监护关系证明窗口常要公证或裁判文书。
4. 死后事务：可约定丧葬代理、通知继承人、配合遗产处理。出现“死后财产归监护人”“排除全部继承人”：按节点 1 切开；能剥离则删除该句并提示另件，不能剥离则负触发遗赠扶养。
5. 争议解决：可约定由设立人经常居住地法院管辖。或裁或诉、机构不明：标待核。指定监护、行为能力认定属特别程序，不得改成普通仲裁条款吞并。
6. 民事诉讼法特别程序条号本次不写入 `L#`，运行时重核。

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

打开已加载的 `框架.md`，按下列六步逐段对照正文。`基本面.md` 用于校验类型、主体、标的、程序、结构和红旗，不代替本节点出句。框架与本方法冲突时，以本方法为准出句。

| 步 | 动作 | 必须产出 |

每条修改句固定格式：
