# 边界与路由

本技能只审查 **婚姻家庭 / 夫妻财产约定**。中文展示名必须是「审查夫妻财产约定（婚姻家庭）」。禁止在正文写半截场景编号。

主线：夫妻或即将登记双方的书面财产制安排，对内优于法定财产制。不输出离婚三块，不以第 658 条任意撤销为默认，不写隐名持股结构。

## 正触发

已有可读待签书面夫妻财产约定（含婚前财产约定、婚内财产协议），尚未签署，尚未成争，核心给付是就婚前财产及婚后所得约定归各自所有、共同所有或者部分各自所有、部分共同所有，且文本不是解除婚姻一揽子安排。

## 负触发

| 主要目标或文本信号 | 路由 | 不得代做 |
| --- | --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 | 不硬套本类型十节 |
| 已在办离婚，或解除婚姻+子女+财产债务一揽子 | `离婚协议·审查` | 不补自愿离婚句，不按离婚三块齐审 |
| 分居、临时照护，财产制不是主给付 | `分居协议·审查` | 不把分居写成财产约定已替代法定财产制 |
| 忠诚惩罚金、出轨净身出户为主给付，无财产制 | `夫妻忠诚协议·审查` | 不把惩罚金改成财产制交差 |
| 一方把个人金钱或普通动产无偿给对方，无财产制 | `一般赠与合同·审查` | 不把单笔赠与改写成 AA 制；不以第 658 条为本类型默认 |
| 一方把个人房产无偿过户或加名给对方，无财产制 | `房产赠与合同·审查` | 不在本类型出房屋赠与过户五证主清单 |
| 亲属之间房屋给予，主体不是夫妻财产制双方 | `亲属间房屋赠与合同·审查` | 不按夫妻财产制约束第三人亲属 |
| 隐名持股、代持分红、显名配合为主给付 | `隐名持股代持分红为主给付→` | 不把股权归属约定改成代持可履行结构 |
| 无婚姻关系且双方不准备登记结婚 | 转引擎重新定性；可能是普通共有或赠与 | 不把同居财产约定写成第 1065 条夫妻财产约定 |
| 无文本、本类型条件已谈妥、要出己方稿 | `夫妻财产约定·起草` | 已经完成审查；不在本审查原子起草 |
| 已签，只问过户、交割、告知债权人 | 本套导航的履约步骤 | 不回写签前意见充作成交 |
| 已起诉离婚财产、债权人撤销或执行异议，且要诉讼策略 | 婚家领域或 `已催告解除索赔诉讼或仲裁→` | 不写诉讼策略，不把起诉材料改成签前约定交差 |
| 处分子女名下财产 | 停笔；监护不得私下处分 | 不改写成可履行划转 |
| C 端大众快检或 C 端财产约定起草 | 只分流，不回改 | 不复制起草模板 |

专业版未收录的 P1 场景不会安装本邻类。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用本类型硬套。

## 本类型内转出（仍可先标风险再停）

- 财产制主文中夹带单笔个人房产无偿加名/转归：财产制块继续；加名块按节点 4 判断，若无财产制安排则该块负触发赠与场景，不得用“一律可任意撤销”覆盖整案。
- 财产制主文中夹带自愿离婚、子女直接抚养、登记离婚程序：离婚块负触发 `离婚协议·审查`，不把本约定改成离婚协议。
- 大额且存在已知债权人或执行案件：告知第 1065 条第 3 款与第 538 条，不设计逃债履行结构。
- 即将登记但双方明确不再结婚：本约定失去第 1065 条基础，字段停止或转普通共有/赠与定性。
- 用户要保证有效、保证必然过户或债权人不能再追：停止保证，只保留事实摘录与修改句草稿。
