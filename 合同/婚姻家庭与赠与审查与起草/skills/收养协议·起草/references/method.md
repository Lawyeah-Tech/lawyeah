# 审查方法（锁定 婚姻家庭 / 收养协议）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止打开或复制 `解除收养协议·审查` method。禁止套用解除收养的注销登记、生活费请求权、成年养子女关系恶化诉讼主线。禁止套用监护转让、抚养权变更、离婚财产、买卖验收或委托授权节点。禁止把本技能写成解除收养或监护协议换标题。

定性校验：核心给付是拟依法建立养父母与养子女关系，才继续；明显他类则负触发，不填十节实体结论。

本文件是可执行判断节点，不是栏目说明书。每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、民政必然登记，或未登记已经成立拟制血亲。

`search_law` 返回已失效《收养法》《合同法》及其解释、1992 年《中国公民办理收养登记的若干规定》、1984 年《关于贯彻执行民事政策法律若干问题的意见》中“亲友群众公认即按收养对待”时记为噪声，不得写入 `L#`。`search_practiced` 仍写“未登记也可认定事实收养并补正效力”“公证之日起成立”的，同样记噪声。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

示范文本只参考结构。写“本协议自公证之日起生效即成立收养关系”“签字后无需登记”或仍整篇引用《收养法》的范本与登记成立硬闸冲突，不得当规则。

知识库口径冲突以本方法为准，不回写知识正文：

- `基本面.md` 写收养人须“无犯罪记录”：纠正为无**不利于被收养人健康成长的违法犯罪记录**，不是一切前科当然禁止，也不是可以隐瞒相关记录。
- `基本面.md`/`框架.md` 将送养人写成“社会福利机构”：现行民法典第 1094 条是**儿童福利机构**。登记办法个别条文仍出现社会福利机构用语时，主体定性以第 1094 条为准，材料名称运行时核验，不把旧机构名扩成任何福利单位均可送养。
- 框架或范本把成立时点写成公证日或签字日：纠正为收养关系自县级以上人民政府民政部门登记之日起成立。
- 把协议写成成立的必备条件：纠正为当事人**可以**签订收养协议；协议不是登记的替代物，也不是成立的充分条件。
- 把 1984 年事实收养或“长期共同生活即可承认”用于待签文本：纠正为 2021-01-01 后新发生的收养，未经登记不成立；本任务不得把私下接走改成可履行。
- 框架中的解除条款：只作为成立协议的配套预埋句审查；整份解除协议转 `解除收养协议·审查`。
- 单身男性收养女性：纠正为**无配偶者收养异性子女**，年龄相差四十周岁以上。

开发窗口 2026-08-18 已核验、可供对照但不得代替运行时核验的规则：

- 民法典第 1044 条：收养应当遵循最有利于被收养人的原则；禁止借收养名义买卖未成年人。
- 第 1093 条：可被收养的未成年人限于孤儿、查找不到生父母的未成年人、生父母有特殊困难无力抚养的子女。
- 第 1094 条：送养人为孤儿的监护人、儿童福利机构、有特殊困难无力抚养子女的生父母。
- 第 1095 条：父母均不具备完全民事行为能力且可能严重危害该未成年人的，监护人可以送养。
- 第 1096 条：监护人送养孤儿应当征得有抚养义务的人同意；不同意且监护人不愿继续履行的，另行确定监护人。
- 第 1097 条：生父母送养应当双方共同送养；一方不明或查找不到的，可以单方送养。
- 第 1098 条：收养人须同时具备无子女或只有一名子女，有抚养教育和保护能力，未患医学上认为不应当收养子女的疾病，无不利于被收养人健康成长的违法犯罪记录，年满三十周岁。
- 第 1099 条：收养三代以内旁系同辈血亲的子女，可不受第 1093 条第三项、第 1094 条第三项和第 1102 条限制；华侨还可不受第 1098 条第一项限制。
- 第 1100 条：无子女可收养两名，有子女只能收养一名；收养孤儿、残疾未成年人或儿童福利机构抚养的查找不到生父母的未成年人，可不受前款和第 1098 条第一项限制。
- 第 1101 条：有配偶者收养子女，应当夫妻共同收养。
- 第 1102 条：无配偶者收养异性子女，年龄应当相差四十周岁以上。
- 第 1103 条：继父或继母经继子女的生父母同意，可以收养继子女，并可不受第 1093 条第三项、第 1094 条第三项、第 1098 条和第 1100 条第一款限制。
- 第 1104 条：收养与送养应当双方自愿；收养八周岁以上未成年人的，应当征得被收养人同意。
- 第 1105 条：应当向县级以上人民政府民政部门登记；收养关系自登记之日起成立。查找不到生父母的，登记前应当公告。当事人愿意的可以签订收养协议。一方或各方要求公证的应当办理公证。县级以上人民政府民政部门应当依法进行收养评估。
- 第 1106 条：收养关系成立后，公安机关按规定办理户口登记。
- 第 1107 条：亲属、朋友抚养不适用收养章。
- 第 1109 条：外国人依法可在中国收养子女，须其所在国审查同意、认证材料，并亲自向省级人民政府民政部门登记；本任务不输出可履行涉外路径。
- 第 1111 条：自成立之日起适用父母子女规定；与生父母及其他近亲属权利义务因成立而消除。
- 第 1113 条：有总则编无效情形或违反本编规定的收养行为无效，自始没有法律约束力。
- 第 1114、1116 条：解除路径与协议解除须到民政部门办理解除登记——仅用于与 `解除收养协议·审查` 切开，不在本任务展开解除整案。
- 《中国公民收养子女登记办法（2023 修订）》第 2、5、6、9、10 条：县级人民政府民政部门登记；当事人应当亲自到场；夫妻共同收养原则上共同到场；登记后凭收养登记证办户口；解除登记持收养登记证和书面解除协议——第 10 条只作负向切开。
- 《未成年人保护法（2024 修正）》第 95 条：民政部门评估后可依法将长期监护的未成年人交由符合条件的申请人收养。
- 《刑法（2023 修正）》第 241 条：收买被拐卖的儿童等——只作刑事红旗，本任务不定罪。

本次检索未返回可写入 `L#` 的专门《收养评估办法》全文条号；运行时必须重核评估程序，不得凭记忆落评估合格结论。民法典第 1112 条（姓氏）本次未作为独立检索命中，姓氏条款按框架作可优化修改句，不写成已核验强制规范。

## 节点 2　主体表

1. 建主体表：拟收养人及其配偶、拟送养人、被收养人、有抚养义务的人、儿童福利机构、其他监护人。名称不一致不自动合并。
2. 被收养人必须是未成年人。已满十八周岁：负触发或整体停止成立路径，不得改成可收养成年人。

不足：字段停止，列出待补材料，不补主体、不补已同意、不补已满或未满某年龄。

## 节点 3　送养条件与共同送养（硬闸）

核验后可引用的判断点（须 `search_law` 写入 `L#` 再落法律结论）：

- 可被收养人限于第 1093 条三类。
- 送养人限于第 1094 条三类；第 1095 条是监护人送养的特别情形。
- 生父母原则上共同送养。
- 监护人送养孤儿须征得有抚养义务的人同意。

| 文本写法 | 本任务动作 |
| --- | --- |
| 生父母经济、照料能力未见特殊困难，只写“工作忙/想轻松/再婚不方便” | 送养类型字段停止或红线；不得改成可履行送养 |
| 仅生父或仅生母签字，未说明另一方死亡、不明或查找不到 | 必须改：补共同送养或补单方送养法定事由及证明附件 |
| 祖父母以监护人名义送养，未附有抚养义务的人同意 | 字段停止；修改句要求书面同意，或另行确定监护，不写成监护人可单独卖出抚养权 |
| 普通亲戚、邻居、月嫂作为送养人 | 红线；主体不适格，不改成可履行 |
| 被收养人是健康且父母均在并有抚养能力的儿童 | 现有依据不支持成立路径；停笔，不改成可登记 |
| 继父母收养继子女 | 可留本技能；须有生父母同意；例外条款运行时核验后才写放宽，不默写“什么条件都不用” |
| 用户要求把“特殊困难”空填或编造低保、残疾 | 整体停止 |

反方常见抗辩：孩子已经在收养人家里住，生父母口头说过送给你们。本任务不得把该抗辩写成可放行成立。

## 节点 4　收养人法定条件与例外（硬闸）

收养人五项条件须同时具备，法律另有例外的除外。例外必须回链第 1099、1100 条第二款或第 1103 条的事实，不得概括写成“亲戚就可以放宽全部条件”。

| 文本写法 | 本任务动作 |
| --- | --- |
| 收养人未满三十周岁，且不属于法定例外 | 红线；不得用协议降龄 |
| 有配偶但仅一方作为收养人签字 | 必须改：夫妻共同收养、共同到登记机关；一方因故不能亲自到场须书面委托并按登记办法证明或公证，不得写成“视为单身收养” |
| 无配偶者收养异性、年龄差不足四十周岁，且非第 1099 条例外 | 红线 |
| 已有两名子女仍要再收养普通未成年人 | 红线或字段停止；除非事实落入第 1100 条第二款 |
| 声明“无任何违法犯罪记录”却另有材料显示存在可能不利于未成年人健康成长的记录 | 并列冲突；成立路径停止，不指导隐瞒 |
| 知识库口径“无犯罪记录”被用户拿来要求删除一切前科声明 | 纠正为第 1098 条第四项表述；相关记录仍须如实披露给登记机关 |
| 用户要求写成“未披露视为无疾病、无相关记录” | 红线 |

口头“我们体检没问题”不得写成已具备第 1098 条第三项。修改句要求县级以上医疗机构证明作附件，不保证评估或登记结果。

## 节点 5　登记生效、评估、公告、公证（硬闸）

收养关系自登记之日起成立。协议、公证、交接、共同生活都不是成立时点。

| 文本写法 | 本任务动作 |
| --- | --- |
| “本协议签字盖章后立即生效，双方即形成养父母子女关系” | 必须改。拆成：协议对配合登记等约定自签署时对签署方有约束力；**收养关系**自县级以上人民政府民政部门登记之日起成立 |
| “本协议经公证处公证之日起成立收养关系，无需登记” | 红线。公证不得替代登记 |
| “先接走共同生活满两年即视为事实收养，补办登记只是手续” | 红线。不得用失效事实收养口径放行待签文本 |
| 未写谁在几日内共同到县级民政部门申请登记、未完成的后果 | 必须改。补义务主体、期限、未登记前不得对外以养父母子女名义申报户口或入学 |
| “双方同意视为已评估合格、已公告完毕” | 红线。评估与公告是登记机关职责，协议只能约定配合，不能拟制完成 |
| 查找不到生父母却约定“为尽快接走同意不公告” | 红线；规避公告停笔 |
| 用户要求把日期写成上周已登记或补假收养登记证 | 整体停止 |

批准、登记、评估、公告写成双方配合义务或成立条件，不写成已经完成。材料未提及不得写成“评估已通过、无需公告、户口已可迁移”。

中国公民境内普通路径：办理登记的机关是县级人民政府民政部门。涉外升省级。本任务不保证窗口受理。

## 节点 6　对价、八周岁同意与非法送养（硬闸）

1. 最有利于被收养人。父母方便或财产对价不得压过未成年人利益。
2. 禁止借收养名义买卖未成年人。转让、售出、抵债、买断、按人计价：停笔。
3. 必要、合理、可证明用途的前期抚养费、医疗费、营养补助可以约定数额与用途，并附凭证。用途不明或数额与必要费用明显不成比例：按买卖外观红线，不改成“改个名即可”。
4. 被收养人已满八周岁：须本人同意。修改句要求本人签署协议或独立意愿确认页。父母或收养人代签、聊天转述：不得写成已同意。
5. 未成年人不得成为给付对价、违约金或赔偿的义务人。
6. 送养后干扰、隐瞒重大病史：可约定不实声明的实际损失赔偿，但不得把孩子当作违约标的。

用户要求保留感谢费以便“堵住生父母反悔”：整体停止该对价结构。

## 节点 7　身份效果时点、户籍与预埋解除

1. 自**登记成立**之日起，适用父母子女规定；与生父母及其他近亲属权利义务因成立而消除。不得提前到签字日或接走日。
2. 生父母探视不是法定强制。可协商在不影响被收养人正常生活的前提下是否探视；未约定不得写成必有或必无。
3. 户籍：登记后由收养人持收养登记证办理。修改句写成登记后的配合义务，不写成签字即可迁户。
4. 预埋解除：可写收养人虐待、遗弃时送养人有权要求解除，且解除须办理解除登记。不得写成“通知即解除”“签字即恢复生父母关系”。深度解除补偿、成年后生活费请求权转 `解除收养协议·审查`，本任务只保留不得私下终止的一句。
5. 姓氏是否随收养人：可约定，不编造必须随哪一方。
