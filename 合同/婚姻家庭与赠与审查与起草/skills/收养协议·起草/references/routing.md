# 边界与路由

本技能只起草 **婚姻家庭 / 收养协议**。

必须读出拟依法建立养父母与养子女关系、并准备向县级以上人民政府民政部门办理收养登记的合意。标题叫“收养协议”但核心是终止已成立收养、私下转让监护、只约定抚养费或亲属朋友抚养的，不得留在本技能做实体结论。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或标题收养、核心给付明显不是成立拟制血亲 | 本套导航的类型切开步骤 |
| 已有收养登记证或已成立收养，主文件是解除、终止、注销收养 | `解除收养协议·审查`；专业版未收录该 P1 时输出 `unavailable`，不得硬套本技能改解除整案 |
| 监护资格转让、指定、放弃，不建立收养 | `监护权协议·审查` |
| 意定监护 | `意定监护协议·审查` |
| 只变更直接抚养人，原文书仍是离婚或抚养安排 | `抚养权变更协议·审查` |
| 只约定扶养或抚养给付，不成立拟制血亲 | `扶养抚养协议·审查` |
| 离婚一揽子财产、债务、子女 | `离婚协议·审查` |
| 亲属、朋友抚养，文本写明不适用收养或只帮忙照料 | 转引擎或抚养类原子；点名民法典第 1107 条，不灌登记成立节点 |
| 家庭寄养、儿童福利机构委托照料 | 转引擎；寄养不是收养 |
| 外国人来华收养，重点是省级登记、认证、其所在国同意 | 升级；本技能不输出可履行涉外路径 |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、问评估预约、登记窗口、户口迁移 | 本套导航的履约步骤 |
| 已成争 | 家事争议或对应专项；不写确认收养无效诉状、解救申请书 |
| C 端大众快检 | 只分流，不回改 |

成立协议中仅有一条“将来可协议解除并办解除登记”：留本技能，按配套条款改句，不转 `解除收养协议·审查`。整份主文件已是解除协议：必须转出。

买卖未成年人、不符合法定送养或收养条件、伪造材料、规避公告或倒签登记：停笔告知，不改写成可履行文本。

禁止在正文写半截 Skill ID。转出时必须写完整 ID，例如 `解除收养协议·审查`、`监护权协议·审查`。
