# 边界与路由

本技能只审查 **婚姻家庭 / 解除收养协议**。中文名必须是「审查解除收养协议（婚姻家庭）」。

必须同时读出：已经依法成立的收养关系，以及当事人拟以**书面协议**终止该拟制父母子女关系。标题叫“解除收养”但实际是成立收养、只改抚养、只转监护或继父母退出的，不得留在本技能做实体结论。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或标题解除收养、核心给付明显不是终止已成立收养 | 本套导航的类型切开步骤 |
| 拟向民政成立收养；审查被收养人、收养人、送养人条件、评估、公告 | `收养协议·审查`。禁止打开其 method，禁止套成立要件 |
| 父母之间变更直接抚养人、探望，不终止收养 | `抚养权变更协议·审查` |
| 不变更直接抚养人，只重订抚养费 | `扶养抚养协议·审查` |
| 成年子女与父母之间的赡养，无解除收养意思 | `赡养协议·审查` |
| 私下指定、转移或放弃监护，收养关系拟继续 | `监护权协议·审查`；专业版未收录时 `unavailable` |
| 成年人意定监护 | `意定监护协议·审查` |
| 遗赠换生养死葬 | `遗赠扶养协议·审查` |
| 遗嘱处分财产 | `遗嘱·审查` |
| 离婚一揽子财产与子女安排，收养不是标的 | `离婚协议·审查` |
| 继父母与继子女退出，无《收养登记证》 | 不按本类型放行；点名家事专项，不写解除收养登记路径 |
| 家庭寄养、临时照料、福利机构委托抚养 | 不按本类型放行 |
| 外国人或一方为外国人 | 负触发引擎或涉外路径；不写省级民政涉外解除整案 |
| 无文本、本类型条件已谈妥、要出己方稿 | `解除收养协议·起草` |
| 已签未争、问登记预约、交证、户口迁移 | 本套导航的履约步骤 |
| 已成争、一方拒登、起诉解除或确认无效 | 家事或争议专项；不写起诉状、应诉状 |
| C 端大众评估 | 只分流，不回改 |

专业版未收录本 P1 原子时，邻接转来输出 `unavailable`，不得用成立收养或抚养变更硬套。

一方不同意解除、无收养登记证的事实收养、生父母不能接收未成年被收养人：本任务只告知转诉讼或升级，不改写成可履行协议解除。

禁止在正文写半截 Skill ID。转出时必须写完整 ID，例如 `收养协议·审查`、`抚养权变更协议·审查`、`监护权协议·审查`。
