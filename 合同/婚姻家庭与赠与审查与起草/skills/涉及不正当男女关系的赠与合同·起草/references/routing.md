# 边界与路由

本技能只起草 **赠与合同 / 涉及不正当男女关系的赠与合同**。

必须同时读出：无偿给予；以及给付发生在不正当男女关系之中，或该第三人死亡后向其近亲属。标题叫“赠与”但核心是分手清算、普通馈赠、离婚分割或可履行包养设计的，不得留在本技能做成相反结论。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或标题赠与、核心给付明显不是不正当关系无偿给予 | 本套导航的类型切开步骤 |
| 双方已终止或即将终止共同生活，结算已形成财产、债务、非婚生子女抚养 | `分手协议·审查`；不得把分手清算做成无效赠与整案 |
| 双方仍共同生活，约定存续期归属、共同账户、加名，无赠与对价维持关系 | `同居财产约定·审查`；专业版未收录时输出 `unavailable` |
| 无婚外性关系或包养安排的普通无偿给予 | `一般赠与合同·审查` |
| 救灾扶贫助残等公益、道德义务主文件，原因事实与不正当关系无关 | `公益道德义务性质的赠与合同·审查`；专业版未收录时输出 `unavailable` |
| 附义务赠与，义务是扶养、劳务等合法事项，不是维持不正当关系 | `附义务的赠与合同·审查` |
| 婚姻家庭内部赠与为主线 | `婚姻家庭中的赠与合同·审查`；专业版未收录时输出 `unavailable` |
| 股权零元转让且关系不是本类型主线 | `零对价股权赠与·审查` |
| 房屋无偿过户且关系不是本类型主线 | `房产赠与合同·审查` 或 `亲属间房屋赠与合同·审查` |
| 已登记结婚，解除婚姻、冷静期、离婚登记后生效 | `离婚协议·审查` |
| 已登记夫妻，忠诚义务、出轨惩罚 | `夫妻忠诚协议·审查` |
| 有真实劳动报酬或真实借贷返还 | 引擎按基础关系重新定性；不得一律按包养费打掉 |
| 无可读正文，本类型条件已谈妥，要出己方稿 | 本任务起草并自审 |
| 已签未争、问转账、过户执行 | 本套导航的履约步骤 |
| 已成争 | 合同争议领域或家事专项；不写确认无效起诉状整案 |
| 用户只要唯一返还额 | 测算或人工精算；本技能不输出终局金额 |
| C 端大众快检 | 只分流，不回改 |

一方有配偶且文本同时出现大额无偿给予、以继续同居为条件：按核心给付切开。给付目的是维持不正当关系 → 留本技能，走无效分层，不设计可履行包养。已终止共同生活、给付能回链到共同出资折价 → `分手协议·审查`。标题写附义务但义务是保持同居 → 留本技能，不得转 `附义务的赠与合同·审查`。两可且无法判断：负触发引擎，不灌两套知识。

包养、限制结婚、不得报警、伪造配偶同意、逃债过户、借名规避限购：停笔告知，不改写成可履行文本。

禁止在正文写半截 Skill ID。转出时必须写完整 ID，例如 `分手协议·审查`、`一般赠与合同·审查`、`公益道德义务性质的赠与合同·审查`、`附义务的赠与合同·审查`、`零对价股权赠与·审查`、`夫妻忠诚协议·审查`。
