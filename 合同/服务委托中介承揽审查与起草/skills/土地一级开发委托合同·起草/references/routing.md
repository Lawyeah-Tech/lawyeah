# 边界与路由

本技能只审查 **委托合同 / 土地一级开发委托合同**。

必须同时读出：政府或其授权储备机构委托企业实施一级开发；企业真实筹措资金并组织规划、征拆和市政；对价是核定成本加约定利润或财政开发补偿；本约不绑定二级摘牌。标题叫“土地一级开发”但只出钱收固定回报、只施工按造价取费、或保证后续拿地的，不得留在本技能做实体结论。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或标题一级开发、核心给付明显不是委托实施一级开发 | 本套导航的类型切开步骤 |
| 只出钱不组织实施；固定期限、固定利率、保底年化、差额补足、资金进财政统筹 | `名为一级开发实为借贷·审查` |
| 只做三通一平或市政施工，按审定造价取费，不承担融资与征拆，或 BT 垫资回购 | `名为一级开发实为施工·审查` |
| 一级整理绑定二级优先、定向出让、内定底价、保证摘牌、出让金分成换用地 | `“一二级联动”相关合同·审查` |
| 只受托实施拆迁补偿，不管融资和市政整体 | `拆迁委托协议·审查` |
| 政府投资项目代建、代建管理费 | `政府代建合同·审查` |
| 普通民事委托，无关土地储备 | `一般委托合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 留本任务起草并自审 |
| 已签未争、问拨付、验收、移交 | 本套导航的履约步骤 |
| 已成争 | 合同争议或行政争议专项；不写起诉状或仲裁申请 |
| 用户只要回款或利润的终局数字 | 测算技能或人工精算；本技能只审条款 |
| C 端大众快检 | 只分流，不回改 |

专业版未收录的 P1 场景不会安装本原子。若用户拿本类型文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。

同一文本既有核定成本回收，又夹带固定年化或摘牌承诺：按核心给付切开。固定回报或只出钱是主结构 → `名为一级开发实为借贷·审查`。摘牌／定向出让是主结构 → `“一二级联动”相关合同·审查`。施工取费是主结构 → `名为一级开发实为施工·审查`。两可且无法判断：负触发引擎，不灌两套知识。不得删掉借贷、施工或联动条款后硬套本技能。

挂靠、违法分包、规避招标、伪造授权或储备计划、毛地出让、定向出让、施工单位垫资：停笔告知，不改写成可履行文本。

禁止在正文写半截 Skill ID。转出时必须写完整 ID，例如 `“一二级联动”相关合同·审查`、`名为一级开发实为借贷·审查`、`名为一级开发实为施工·审查`。
