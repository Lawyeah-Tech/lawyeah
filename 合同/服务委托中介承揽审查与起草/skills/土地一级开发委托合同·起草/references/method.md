# 审查方法（锁定 委托合同 / 土地一级开发委托合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止打开或复制 `“一二级联动”相关合同·审查`、`名为一级开发实为借贷·审查`、`名为一级开发实为施工·审查` method。禁止套用民间借贷利率上限、施工优先受偿、竣工五方验收、勾地／预申请保证金或实施主体转化主路径。禁止把本技能写成名开发实借贷、名开发实施工或一二级联动换标题。

定性校验：核心给付是政府或其授权机构委托企业实施一级开发事务，企业真实筹措资金并组织规划、征拆和市政，对价是核定成本加约定利润或财政开发补偿，才继续；明显他类则负触发，不填十节实体结论。

本文件是可执行判断节点，不是栏目说明书。每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、必然回款、必然摘牌，或唯一必得补偿额。

`search_law` 返回已失效《合同法》及其解释、1989 年行政诉讼法第十二条不受理清单、2015 年行政诉讼法解释、2001 年城市房屋拆迁管理条例、1990 年外商投资开发经营成片土地暂行管理办法、2000 年工程建设项目招标范围和规模标准规定时记为噪声，不得写入 `L#`。`search_practiced` 仍写“一律民事合同可仲裁”“未招标一律无效”“注册资本一百万为现行门槛”的，同样记噪声。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

示范文本只参考结构。写“一二级联动”“内定底价”“垫付资金到期还本付息”“承建单位垫资建设”的范本与本类型硬闸冲突，不得当规则。

知识库口径冲突以本方法为准，不回写知识正文：

- `基本面.md` 写“此类合同通常被认定为行政协议”：纠正为按行政协议司法解释第一条三要素个案判断（行政管理或公共服务目标、行政法上权利义务、与行政机关协商订立），不保证一律是行政协议，也不保证一律是民事委托。
- `基本面.md` 写设立房地产开发企业“注册资本不低于一百万元”：纠正为 2015 年住建部已删除该注册资本门槛；现行《房地产开发企业资质管理规定》（2022 修正）第三条仍要求未取得资质证书不得从事房地产开发经营，但不得把一百万写成现行准入。
- `基本面.md` 写“未通过招投标选定可能导致合同被认定为无效”：纠正为违反法律、行政法规强制性规定不一律无效；须核验是否属于必须招标项目及规范是否导致民事／行政协议无效，不得口诀化。
- `框架.md` 写争议“可能涉及行政诉讼或民事仲裁”：纠正为若构成行政协议，约定仲裁的条款原则上无效（法律、行政法规或国际条约另有规定除外）；不得假装已经选定有效仲裁。
- `框架.md` 写“若乙方希望参与二级开发，应在法律允许范围内约定激励或优先机制”：纠正为本技能不得写出可履行的摘牌优先、定向出让或内定底价；该类给付负触发 `“一二级联动”相关合同·审查`。
- 土地出让收益“按比例分成”：不得改写成土地出让金直接返还或绕开收支两条线；支付须走核定开发补偿或经批准的财政预算路径。

开发窗口 2026-08-18 已核验、可供对照但不得代替运行时核验的规则：

- 行政诉讼法（2017 修正）第十二条第一款第十一项：认为行政机关不依法履行、未按照约定履行或者违法变更、解除政府特许经营协议、土地房屋征收补偿协议等协议的，属于受案范围。
- 行政协议司法解释（法释〔2019〕17 号）第一条：行政机关为了实现行政管理或者公共服务目标，与公民、法人或者其他组织协商订立的具有行政法上权利义务内容的协议，属于该第十一项行政协议。
- 同解释第二条：受理范围包括政府特许经营、土地房屋征收征用补偿、矿业权等自然资源出让、保障性住房、符合第一条的政府与社会资本合作及其他行政协议。土地一级开发委托须对照第一条判断，不在第二条逐项点名不等于必然不是行政协议。
- 同解释第四条：因行政协议订立、履行、变更、终止起诉的，行政机关为被告；受委托组织订立的，委托的行政机关是被告。
- 同解释第十一条：对订立、履行、变更、解除做合法性审查；相对人主张未依法或未按约定履行的，审查被告是否具有并履行相应义务。
- 同解释第十二条：存在行政诉讼法第七十五条重大且明显违法情形的，确认行政协议无效；也可适用民事法律规范确认无效。
- 同解释第十六条：为防止严重损害国家利益、社会公共利益，行政机关合法变更、解除的，给原告造成损失应予补偿；行为违法的，可判决继续履行、补救或赔偿。
- 同解释第二十六条：行政协议约定仲裁条款的，该条款无效，但法律、行政法规或我国缔结、参加的国际条约另有规定的除外。
- 政府投资条例第五条：政府及其有关部门不得违法违规举借债务筹措政府投资资金。
- 政府投资条例第二十二条：政府投资项目所需资金应当落实到位；政府投资项目不得由施工单位垫资建设。
- 民法典第九百十九条：委托合同是委托人和受托人约定，由受托人处理委托人事务的合同。
- 民法典第九百二十条：可以特别委托一项或数项事务，也可以概括委托一切事务。
- 民法典第九百二十二条：受托人应当按照委托人的指示处理委托事务；变更指示须经同意，紧急情况除外并事后报告。
- 民法典第九百二十三条：受托人应当亲自处理委托事务；转委托须经同意或追认，否则对转委托第三人的行为承担责任，紧急维护委托人利益除外。
- 民法典第一百四十六条：虚假意思表示实施的民事法律行为无效；隐藏行为另依法认定。
- 民法典第一百五十三条：违反法律、行政法规强制性规定的民事法律行为无效，但该强制性规定不导致无效的除外；违背公序良俗的无效。
- 民法典第四百九十六条、第四百九十七条：格式条款定义、提示说明、无效情形。
- 合同编通则解释第十条：异常条款提示标识；网络勾选不当然尽到提示；提供方负举证责任。
- 合同编通则解释第十五条：不拘泥合同名称，按内容、交易目的和履行行为认定实际法律关系。
- 合同编通则解释第十八条：“应当／必须／不得”不当然导致合同无效。
- 招拍挂规定（国土资源部令第 39 号）第四条：工业、商业、旅游、娱乐和商品住宅等经营性用地以及同一宗地有两个以上意向用地者的，应当以招标、拍卖或者挂牌方式出让。
- 节约集约利用土地规定（2019 修正）第二十二条：经营性用地应当以招拍挂确定使用者和价格；禁止以土地换项目、先征后返、补贴、奖励等形式变相减免土地出让价款。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用核心给付和对价方式定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须同时满足才正触发：

1. 委托方是市、县政府土地主管部门、土地储备机构或经书面授权代表其实施土地储备／一级开发的机关或组织。
2. 受托方被委托实施一级开发事务：筹措并落实开发资金，办理规划与项目核准，组织征地拆迁补偿，组织大市政或达到净地条件。
3. 对价是核定开发成本加约定利润，或政府按财政预算／出让后核定支付开发补偿；企业承担征拆和资金组织风险，而不是只收固定利息或只按造价取费。
4. 本约不把后续经营性用地定向给出受托方，也不保证摘牌。

必须切开，禁止两可时灌入两套知识：

| 信号 | 归入 | 本技能动作 |
| --- | --- | --- |
| 政府或储备机构委托企业做一级开发，含融资、征拆、市政，按核定成本回收 | 本类型 | 加载本目录双文件 |
| 只出钱不组织实施，固定期限、固定利率、保底年化、差额补足、资金进财政统筹 | `名为一级开发实为借贷·审查` | 负触发；不套利率上限表 |

## 节点 2　委托权限、主体、资质与批准（硬闸）

1. 建主体表：委托方（签约名、机关性质）、受托开发企业、项目公司（如有）、付款／发票名、授权签字人、担保人或城投（如有）。名称不一致不自动合并。管委会、指挥部、临时办公室未出示政府授权：签署能力字段停止。
2. 委托权限：文本或附件须能回链市、县政府或自然资源主管部门的职权或书面授权。口头“区领导同意了”不得写成已授权。受委托组织签约的，提示行政协议路径下被告可能是委托的行政机关，不保证签约主体就是适格被告。
3. 储备计划与批准：鉴于或附件须指向土地储备开发计划、土地整理方案或等效政府批准文件，且覆盖合同红线。未纳入或范围不一致：字段停止；修改句要求作为附件且未获批准不生效。不得把“双方同意视为已批准”写成可放行。
4. 受托资质：从事房地产开发经营的，核验文本是否提及房地产开发资质证书。材料未提及不得写成“已具备资质”。不得把“注册资本不低于一百万元”写成现行法定门槛。
5. 国资、城投、上市公司内部决议：未闭合则该签署能力字段停止。机关法人提供担保：红旗，不写成可履行保证。
6. 用户要求补假授权、假会议纪要或倒签批准日：整体停止。

不足：字段停止，列出待补材料，不补主体、不补已授权、不补已纳入计划。

## 节点 3　资金闭环、成本核定与支付路径（硬闸）

本类型对价是开发补偿，不是借款本息，也不是施工造价。

| 文本写法 | 本任务动作 |
| --- | --- |
| 成本构成未列征地补偿、安置补助、附着物、拆迁、市政、税费等主要项 | 必须改。缺项用 `【待填】` 补清单，不编造金额 |
| 未写按实核定或包干，也未写审计主体 | 必须改。建议第三方独立审计为结算依据 |
| “土地出让金直接返还乙方百分之【待填】” | 红线。改为按核定开发成本及约定利润由财政支付或出让后核定支付；禁止先征后返式减免出让价款 |
| “年化收益【待填】％，到期还本付息，无论是否完成整理” | 负触发 `名为一级开发实为借贷·审查`，或红线删除后改回核定成本。不在本技能做利率合法性主审 |
| 支付节点只有“出让后尽快支付”，无预算科目、审核时限、逾期后果 | 必须改。补财政预算安排或核定后【待填】日内支付，逾期利息或违约金覆盖资金成本 |
| 政府侧无预算、无支付来源，要求企业无限垫资 | 红旗。政府投资资金须落实；字段停止或整体停止视用户是否坚持可履行垫资 |
| 利润与成本混写、可任意调减 | 必须改。利润单独列明计算基数与上限 |

禁止编造总投资、利润率和回款日。材料未提及不得写成“预算已经落实”。

反方常见抗辩：分成就是行业惯例。本任务不得把直接返还出让金写成可放行结构。

## 节点 4　标的红线、储备计划与净地

1. 红线须确定到可履行：坐落、四至、面积、坐标或附图。只有“等有关地块”则标缺口。
2. 开发内容分列：资金筹措、规划核准、征收拆迁、市政基础设施、达到净地的具体标准。缺一项补一项。
3. 征收程序：涉及集体土地征收或国有土地上房屋征收的，写清以有权机关征收决定为前提，企业不得被写成“自行强制搬迁”。深度征收争议转出，不在本任务做补偿标准终局。
4. 权利负担：抵押、查封、权属争议未清除前不得写成已达净地。材料未提及不得写成“无权利负担”。
5. 毛地出让：一级开发未完成、未达净地不得进入经营性用地出让。出现“边整理边出让”“毛地挂牌”：红线。
6. 规划指标：容积率、用途与后续出让条件不一致的，标 `C#`，必须改，不得写成企业有权单方调规。

## 节点 5　选定程序、征收与转委托

1. 选定程序：文本是否陈述公开招标、竞争性谈判或其他法定／政策要求的选定方式。未陈述：字段停止，修改句要求补选定文件作为附件。不得补假招标回单。是否属于必须招标项目，运行时核验招标投标法及必须招标的工程项目规定，核验失败则效力字段停止。
2. 转委托：一级开发整体转给第三人须经委托方书面同意。未经同意的概括转包、出借资质：停笔，不写可履行转包结构。
3. 市政工程依法必须施工招标的，一级开发委托不替代施工招标。企业自行施工且按造价取费：按节点 1 切向 `名为一级开发实为施工·审查`。
4. 批准、登记、备案、招投标、内部决议写成生效条件或双方义务期限，不写成已经完成。

| 文本写法 | 本任务动作 |
| --- | --- |
| “本合同签字盖章后立即生效”，但文本同时要求政府常务会批准或纳入预算 | 必须改。拆成签字成立 vs 批准／预算到位后生效 |
| “双方同意视为已完成招投标／已纳入储备计划” | 红线。删除拟制 |
| 用户要求倒签中标日或批准日 | 整体停止 |

## 节点 6　行政协议识别、优益权与争议解决

是否构成行政协议，按已核验的第一条三要素判断，结论只能是 `现有依据支持`／`不支持`／`依据不足`。不得写“土地一级开发委托合同当然是行政协议”或“当然是民事合同”。

| 文本写法 | 本任务动作 |
| --- | --- |
| 政府因规划调整可随时单方解除，且“视为双方同意解除、互不补偿” | 红线。改为合法变更／解除须书面说明公共利益事由，并补偿已核定实际支出及合同已约定的合理预期收益 |
| 争议“提交某仲裁委员会仲裁”且文本具备行政协议三要素 | 必须改。提示解释第二十六条：仲裁条款原则上无效；修改句改为行政诉讼，或在不构成行政协议时尚可保留仲裁但须明示该前提待核 |
| 或裁或诉、机构不明 | 标待核，改成单一路径 |
| “本合同为平等民事主体之间的民事合同，排除行政诉讼” | 不得当成已排除行政协议审查；提示名称不决定性质 |

行政协议路径下，合法变更解除给相对人造成损失应予补偿，违法则可继续履行、补救或赔偿。补偿不是本任务精算的唯一金额。

## 节点 7　垫资角色、挂靠与强制规范

1. 受托方角色必须是委托实施单位或投资实施主体。写成“承建单位垫资建设”“先施工后由财政回购”：红线或负触发 `名为一级开发实为施工·审查`。政府投资项目不得由施工单位垫资建设。
2. 企业筹措开发资金本身不等于违法垫资，但须与施工承包角色切开，并闭合回收路径。
3. 挂靠、出借资质、违法分包、规避必须招标：停笔告知，不改写成可履行。
4. 格式条款：机关或城投重复使用的免责、限责、排除主要权利、单方解释权，按第四百九十六条、第四百九十七条和合同编通则解释第十条审查提示说明。无核验引文则法律结论字段停止。
5. 强制规范：违反法律、行政法规强制性规定不一律无效。禁止用已失效“效力性／管理性”口诀代替合同编通则解释第十八条。隐藏借贷按第一百四十六条和第二十三条路径切开，不在本技能做拆借效力整案。
