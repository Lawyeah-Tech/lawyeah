# 涉外承揽合同·审查

## 任务目标

在单一立场下，只审查 **承揽合同 / 涉外承揽合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「审查涉外承揽合同（承揽合同）」。`depends-on` 为空。不要求先跑导航。

主线是**具有涉外因素的完成工作并跨境交付成果**：一方在境外或标的／法律事实跨境，承揽人按定作要求完成加工或定作，对价主要是报酬（可含料件），须同时闭合准据法和进出口监管。不是无涉外因素的国内加工，不是品牌授权贴牌主给付，也不是不控制过程的国际货物买卖。

不交付：他类审查、从零起草、履约交底、争议文书、有效性或外国法终局保证、把无许可出口管制物项、制裁规避、地下钱庄结算或“选外国法即可不管中国海关”改成可履行结构。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **涉外承揽 ≠ 国内加工 ≠ OEM ≠ 国际货物买卖**：核心给付是完成工作并交付成果，且存在外方主体、境外经常居所、境外标的或境外法律事实 → 本类型。双方、标的、履行均在中国大陆且无跨境交付 → `加工合同·审查`／`定作合同·审查`。主给付是贴委托方商标、品牌授权闭环，跨境只是附带一句 → `定牌加工（OEM）合同·审查`。通用现货、买方不控制过程、对价是货款 → `通用型号现货卖方组织生产买方不控制过程→`。不得删掉 OEM 授权章或买卖条款后继续当本类型审。
2. **准据法必须闭合**：须明示选择适用法律（中国法、对方国法或第三国法）。未选择时按特征性履行（通常是承揽人经常居所地）或最密切联系，**不得默认 CISG**。中国出口管制、海关、外汇、反垄断／反倾销等强制性规定直接适用；选择外国法不能排除。不得输出未核验的外国实体法结论。故意制造连结点规避强制规定：不发生适用外国法的效力。
3. **进出口必须闭合**：须写明进料加工还是来料加工；手册设立／核销、报关、原产地证、Incoterms 版本与代码、装船前检验与到货检验分列。管制物项须出口许可或最终用户和最终用途证明。未见许可：进出口字段停止，不得写成“可以先出后补证”。2022 年已删去对外贸易法第九条备案登记，不得把旧“进出口经营权”写成签约先决；仍须核报关单位备案、手册和许可证件。

## 工作边界

正触发：已有可读待签涉外承揽／国际加工定作正文或可单独评改的跨境加工专章，尚未签署，尚未成争；核心给付是按定作要求完成工作并跨境交付成果。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 无涉外因素，只是境内来料或来件加工 → `加工合同·审查`；
- 无涉外因素，承揽人自备主材按规格制成果 → `定作合同·审查`；
- 主给付是贴委托方商标或品牌授权闭环，跨境只是附带一句 → `定牌加工（OEM）合同·审查`；
- 通用型号现货、买方不控制过程、对价是货款或 CIF／FOB 购销 → `通用型号现货卖方组织生产买方不控制过程→`；
- 修理既存物 → `修理合同·审查`；
- 农村低层自建、私人室内装修等普通项目承揽 → `项目承揽合同·审查`；
- 工地建筑活动、承包资质、竣工验收 → `工地建筑活动承包资质竣工验收→`；
- 医疗器械委托生产目录产品 → `医疗器械委托生产合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `涉外承揽合同·起草`；
- 已签只问装船日、手册核销日、信用证交单日 → 本套导航的履约步骤；
- 已成争（催告、海关扣留、信用证拒付、制裁冻结、解除索赔、立案、开庭、仲裁）→ `或对应专项领域。` 或对应专项领域，不填签前十节。

无许可出口管制物项、制裁名单交易、伪造手册或地下钱庄结算：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；代表定作人／境外买方还是承揽人／境内加工方；正文、附件、规格书、信用证草本、手册草稿版本；哪一项涉外连结点成立；进料还是来料；准据法与仲裁／法院是否已写；是否两用物项或受限技术；国内主体报关单位备案是否可见；不可接受事项；拟签时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的单价、数量、交期、Incoterms 版本、汇率阈值、信用证金额用 `【待填】`，不编造。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构，不证明本约条款已被接受。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、《涉外经济合同法》、《加工承揽合同条例》、《经济合同法》、2007 年《关于审理涉外民事或商事合同纠纷案件法律适用若干问题的规定》、1994 年《对外贸易法》第九条旧义当作本类型默认规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典第七百七十条至第七百八十七条、第一百五十三条、第四百九十六条，法律适用法第三条、第四条、第五条、第四十一条，解释（一）（2020 修正）第八条、第九条，民诉解释第五百二十条，出口管制法第十一条、第十二条，两用物项出口管制条例第二条、第二十四条，海关法第三十三条，加工贸易监管办法第二条、第四十条。`search_practiced` 只比较承揽与买卖切开、特征性履行和 CISG 是否被当作买卖公约，不写成纯承揽默认法。`search_template` 只借中外来料加工合同栏目。不虚构案件系统。

`search_law` 对法律结论为 required 级：不可用时不拒绝执行，只停止法律结论字段。返回已失效《合同法》或其解释、《涉外经济合同法》、《加工承揽合同条例》、《经济合同法》、2007 年涉外合同法律适用规定、1994 年《对外贸易法》第九条旧义时记为噪声，不得写入 `L#`。法律适用法解释（一）（2020 修正）第一条本次未稳定命中：涉外因素以民诉解释第五百二十条为已核验同向依据，运行时再核。民法典第七百七十三条至第七百七十五条本次未单独命中稳定回执，运行时再核，不写入 `L#`。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录，禁止为对照打开 OEM 品牌授权主路径、国内加工供材主路径或买卖货交承运人整案双文件。`基本面.md` 中“CISG 常被参照”不得写成默认准据法。`框架.md` 把 OEM／ODM 写成默认合作模式的，**降级**：品牌授权贴牌成主给付 → 负触发 `定牌加工（OEM）合同·审查`。知识稿“进出口经营权”按 2022 年删去第九条纠正：改核报关单位备案、手册和许可证件。知识稿 30% 预付款、汇率波动 3% 是谈判量级，写入修改句时用 `【待填】`。

必须有修改句。禁止只打红黄绿。每个风险回链文本位置。交付按 [输出合同](references/output-contract.md)。边界见 [路由](references/routing.md)。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造手册或倒签许可、把无许可出口管制物项或制裁名单交易改成可履行、指导地下钱庄收付汇、保证有效或保证外国法结论。
- `字段停止`：未见准据法选择且用户要外国法结论；未见进料／来料模式；未见手册或报关责任；两用物项归类未核验；数据出境评估未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或文本已滑入国内加工／OEM／买卖／施工。

生存级订单额、管制物项或个人无限连带且用户拒绝升级：停止“可以签署”建议。
