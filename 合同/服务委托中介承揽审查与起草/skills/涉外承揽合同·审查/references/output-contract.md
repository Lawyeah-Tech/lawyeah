# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受、外国法必然如何或 CISG 当然适用纯承揽；编造未给出的单价、数量、交期、Incoterms 版本、信用证金额；把已失效《合同法》或其解释、《涉外经济合同法》、《加工承揽合同条例》、2007 年涉外合同法律适用规定写入结论；写“选择外国法即排除中国海关／出口管制／外汇”；写“可以先出后补手册或许可证”；把国内加工、OEM 或买卖当成已完成的本类型审查。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查涉外承揽合同（承揽合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、《涉外经济合同法》、《加工承揽合同条例》、《经济合同法》、2007 年涉外合同法律适用规定、1994 年《对外贸易法》第九条旧义时记噪声，不得写入 `L#`。法律适用法解释（一）（2020 修正）第一条、民法典第七百七十三条至第七百七十五条本次未稳定命中前不得写入 `L#`。

## 3. 类型与加载路径

父级 `承揽合同`，子级 `涉外承揽合同`。定性理由、易混切开结果（国内加工、定作、OEM、买卖、修理、项目承揽、施工）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准：CISG 不写成纯承揽默认法；选择外国法不排除中国强制规范；2022 年后不以旧“进出口经营权”为签约先决。无许可出口、制裁规避、伪造手册写停笔告知，不填可履行结构。

## 4. 主体、授权、涉外连结点与文本版本

主体表：定作人、承揽人、经营企业、加工企业、外发承揽者、报关单位、开证行／受益人、授权签字人。涉外连结点：外方主体、境外经常居所、境外标的、境外法律事实。版本表：正文、附件、订单／PO、规格书、外方注册证明／POA、手册草稿、信用证草本、最终用户声明、聊天确认；冲突并列。未见准据法选择而用户要外国法结论：准据法字段停止。

## 5. 给付闭环

工作成果、技术标准与语种效力、进料／来料、材料提供方、Incoterms 版本与代码、PSI 与到货检验、加工费／料件／币种／银行费用、手册设立与核销、原产地证、管制许可或最终用户声明。缺口标 `G#`，不补商业数字。手册、许可、报关单位备案写成义务和期限，不写成已经完成。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹；异常条款（选择外国法排除中国监管、签收即合格、解除不赔、间接损失排除、最终解释权）。强制规范只按法律适用法第四条、民法典第一百五十三条和合同编通则解释第十六条区分，不用失效“效力性／管理性”口诀。出口管制许可、手册核销、亲自完成只作为修改理由，不代替修改句。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。禁止输出无修改句的色块表。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。禁止只给原则、不给句子。禁止写出“选择外国法即不受中国出口管制／海关／外汇约束”“未约定法律的适用 CISG”“可以先出运后补手册或许可证”。

## 9. 谈判与签署提醒

谈判顺序：先红线（无许可出口、排除强制规范、先出后补证、制裁规避），再必须改（准据法明示、进料／来料、手册责任、PSI／到货检验、Incoterms 版本、772／787／留置、L/C 软条款），最后可优化（汇率阈值、违约金上限、Escrow、仲裁机构）。签署提醒：外方注册证明和 POA 核对、规格书／包装指南／最终用户声明入附件、签署地点与手签职衔、日期与用印。不指导倒签或补假许可。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书、效力保证或外国法意见，也不是国内加工本约、OEM 本约或动产买卖本约审查。
