# 边界与路由

本技能只审查 **承揽合同 / 涉外承揽合同**。主线是具有涉外因素的完成工作并跨境交付成果，且必须闭合准据法和进出口监管。不是无涉外因素的国内加工，不是定牌加工（OEM），也不是不控制过程的国际货物买卖。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 无涉外因素，只完成境内来料或来件加工 | `加工合同·审查` |
| 无涉外因素，承揽人自备主材按规格制成果 | `定作合同·审查` |
| 主给付是贴委托方商标或品牌授权闭环，跨境只是附带一句 | `定牌加工（OEM）合同·审查` |
| 通用型号现货、买方不控制过程、对价是货款或纯购销 Incoterms | `通用型号现货卖方组织生产买方不控制过程→` |
| 修理既存物 | `修理合同·审查` |
| 农村低层自建、私人室内装修等普通项目承揽 | `项目承揽合同·审查` |
| 工地建筑活动、承包资质、竣工验收 | `工地建筑活动承包资质竣工验收→` |
| 医疗器械委托生产目录产品 | `医疗器械委托生产合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `涉外承揽合同·起草` |
| 已签未争、问装船日／手册核销日／信用证交单日 | 本套导航的履约步骤 |
| 海关扣留、信用证拒付、制裁冻结、催告、解除、立案、开庭或仲裁 | `或对应专项领域。` 或对应专项；不填签前十节 |
| 未见出口许可仍要求出运管制物项，或选外国法以排除中国海关／外汇／出口管制 | 留本任务只出红线；用户坚持改成可履行则整体停止 |
| 正文写来料、附件写进料，或准据法中英文冲突 | 留本任务：两源并列，不选有利版 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

专业版未收录的其他 P1 场景不会作为本原子的实体审查对象。若用户拿 OEM 整案、国内加工整案或买卖整案来找本技能：负触发对应全 ID，不得用本类型硬套。

本技能不得转去加载 `定牌加工（OEM）合同·审查` 的品牌授权／反向仿牌主路径、`加工合同·审查` 的境内供材主路径或 `通用型号现货卖方组织生产买方不控制过程→` 的货交承运人买卖主路径完成本类型审查，也不得把 CISG 或旧“进出口经营权”写成涉外承揽默认主路径。
