# 审查方法（锁定 承揽合同 / 涉外承揽合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型，禁止打开 OEM 品牌授权主路径、国内加工供材主路径或买卖货交承运人整案双文件“对照一下”。

本文件是**具有涉外因素、按定作要求完成工作并跨境交付成果**的签前判断节点，不是栏目说明书，也不是商标贴牌清单或境内供材清单。禁止把“出口定牌当然豁免”、CISG 默认适用或“选外国法即可不管中国海关”写入本类型默认结论。

每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、外国法必然如何、对方必然接受或唯一必得金额。

`search_law` 返回已失效《合同法》及其解释、《涉外经济合同法》、《加工承揽合同条例》、《经济合同法》、2007 年涉外合同法律适用规定、1994 年《对外贸易法》第九条旧义时记为噪声，不得写入 `L#`。第七百八十六条是共同承揽连带责任，不得当成“交付前风险”或 Incoterms 条文。法律适用法解释（一）（2020 修正）第一条本次未稳定命中，涉外因素以民诉解释第五百二十条为已核验同向依据，运行时再核。民法典第七百七十三条至第七百七十五条本次未单独命中稳定回执，运行时再核。

示范文本只参考结构。中外来料加工合同、加工承揽示范文本不证明本约条款已被接受。

### 双文件使用（标题与文件名不完全对应时不拒跑）

同目录两份知识文件按标题语义使用，不回改正文，不因文件名拒跑：

- 含“首部 / 交易条款 / 配套 / 尾部 / 语言”的当框架级条款清单，供节点 8 出句；
- 宏观的类型切开、准据法、进出口、进料／来料、制裁与强制规范由本方法节点承担。知识稿把 CISG 写成未约定时的准用默认的，**降级**：纯承揽不默认适用 CISG。知识稿把 OEM／ODM 写成默认合作模式的，**降级**：品牌授权贴牌成主给付 → 负触发 `定牌加工（OEM）合同·审查`。知识稿把“进出口经营权”写成签约先决的，**降级**：2022 年已删去对外贸易法第九条；改核报关单位备案、手册和许可证件。知识稿 30% 预付款、汇率波动 3% 是谈判量级，写入修改句时用 `【待填】`。
- 文件不可用（空、代码块、与本类型明显无关）：记 `G#`，用本方法节点继续，不得改去加载 OEM 或国内加工双文件，不得编造准据法结论或许可证号。

## 节点 1　类型识别与负触发

### 1.1 本类型正像

同时满足才继续：

- 核心工作是**按定作要求完成加工或定作并交付工作成果**，对价主要是报酬（可含料件），定作人对规格、过程或验收有控制力；
- 至少一项涉外连结点可回链：外方主体、一方经常居所在境外、标的在境外、或产生／变更／消灭关系的法律事实在境外（民诉解释第五百二十条；解释（一）第一条运行时再核）；
- 文本必须处理或依事实必须处理**准据法**和**进出口／跨境交付**，而不是把跨境只写成一句“产品出口”。

标题写成“涉外承揽合同”“国际加工定作合同”“中外来料加工合同”只是线索。名实不符按核心给付归类，标题冲突写入 `C#`。

### 1.2 必须切开（禁止两套知识）

| 信号 | 归入 | 本技能动作 |
| --- | --- | --- |
| 双方、标的、履行均在中国大陆，无跨境交付、无外方主体 | 国内加工或定作 | **负触发** → `加工合同·审查` 或 `定作合同·审查`。不得用本任务补一套准据法后硬留 |
| 主给付是贴委托方商标或品牌授权闭环；跨境、FOB、手册只是附带一句 | 定牌加工（OEM） | **负触发** → `定牌加工（OEM）合同·审查`。不得删掉授权章后继续当本类型审，也不得打开其 method |
| 通用型号现货、买方不控制过程、对价是货款，仅有 Incoterms 购销 | 动产买卖／国际货物销售 | **负触发** → `通用型号现货卖方组织生产买方不控制过程→`。Incoterms 出现不等于本类型 |
| 修理既存物 | 修理合同 | **负触发** → `修理合同·审查` |
| 农村低层自建、私人室内装修 | 项目承揽 | **负触发** → `项目承揽合同·审查` |
| 工地建筑活动、承包资质、竣工验收 | 施工／EPC | **负触发** → `工地建筑活动承包资质竣工验收→` |
| 医疗器械委托生产目录产品 | 医疗器械委托生产 | **负触发** → `医疗器械委托生产合同·审查` |

OEM 或买卖误入是硬闸：一旦核心给付滑入上述结构，立即停笔转出。不得删掉品牌授权或购销包后继续当涉外承揽审。

### 1.3 加载协议

只打开本目录 `基本面.md` 与 `框架.md`。禁止读 `types/` 或其他场景原子目录。

### 1.4 违法结构停笔

出现下列任一结构，只出告知，不改写成可履行文本：

- 管制物项、两用物项或军工技术，未见出口许可或最终用户／最终用途证明，仍要求出运或对外提供技术；
- 交易对手、结算银行或最终用户命中联合国、中国管控名单等，仍要求“换壳履约”；
- 指导伪造、倒签加工贸易手册或许可证，或“先出运后补手册”；
- 地下钱庄、拆分收汇或规避外汇监管的结算路径；
- 故意约定与交易无关的外国法连结点，以排除中国出口管制、海关或外汇强制规定。

用户坚持“改到能签／先出后补证／选外国法就不用管中国海关”：整体停止。合规改道（补真实许可、改用合法收汇渠道、明示中国强制规范仍适用）只点名并出修改句，不在本任务起草规避方案。

## 硬闸 A　涉外承揽 ≠ 国内加工 ≠ OEM ≠ 买卖

本闸改变能否留在本任务。

1. **有没有涉外连结点**  
   文本或用户事实须能指出至少一项：外方签约主体、一方经常居所在境外、成果在境外交付、或报关／手册／跨境运输构成履行法律事实。只有“以后可能出口”而无当前连结点 → 转国内加工／定作。  
   **修改句（留在本任务时）**：`各方确认：本合同是具有涉外因素的承揽合同。承揽人按照定作人提供或书面确认的规格和技术文件完成工作，向定作人交付工作成果，定作人支付报酬。本合同项下存在下列涉外连结点：【外方主体全称／境外经常居所／境外交付地／跨境报关事实，待填】。本合同不是境内加工合同，不是定牌加工（OEM）合同，也不是货物买卖合同。`

2. **有没有被写成 OEM**  
   出现商标注册证、品牌授权、VI／吊牌核销、禁止反向仿牌作为主给付：负触发 `定牌加工（OEM）合同·审查`。仅约定不得擅自使用定作人标识、但不构成贴牌授权闭环：可留本任务，标识条款只作保密和权利担保。  
   **修改句（仅告知转出）**：`删除或以附件剥离把品牌授权、商标使用许可、贴牌核销作为主给付的条款。若各方真实交易是定牌加工，应另立 OEM 合同并由相应技能审查；本任务不把 OEM 结构改写成可履行的涉外承揽。`

3. **有没有被写成买卖**  
   买方不控制规格或过程、标的是通用现货、对价是货款、风险按货交承运人一笔转移：负触发 `通用型号现货卖方组织生产买方不控制过程→`。本类型可以引用 Incoterms，但必须同时保留工作要求、验收和报酬结构。  
   **修改句（留在本任务时）**：`各方确认：对价是完成约定工作的报酬，不是买断现货的货款。Incoterms【版本／代码，待填】仅划分运输、保险、报关和货物灭失风险，不改变本合同的承揽性质，也不视为验收合格。`

4. **最强反方**  
   标题写国际加工但附件是购销确认书或 OEM 授权书，相对方可主张按买卖或贴牌履行。签前按核心给付分流，不两套都审。

## 硬闸 B　准据法必须闭合

本闸是本类型生存级闸。改变文本能不能在跨境争议中被执行，以及能不能排除中国强制规范。

1. **先明示选择，再谈特征性履行**  
   法律适用法第三条：当事人可以明示选择。第四十一条：未选择的，适用特征性履行一方经常居所地法律或其他最密切联系的法律。承揽的特征性履行通常是完成工作的一方。  
   材料未提及不得写成“已适用中国法”或“已适用 CISG”，只能写 `依据不足`。  
   **修改句**：`本合同及与本合同有关的非合同义务，适用【中华人民共和国法律／待填】的实体法，不包括其冲突规范。双方未作有效选择时，适用承揽人经常居所地法律。任何一方不得将《联合国国际货物销售合同公约》解释为自动适用于本合同，除非双方另以书面明示并入且不改变本合同的承揽定性。`

2. **强制规定直接适用**  
   法律适用法第四条；解释（一）第八条：涉及外汇管制等金融安全、反垄断／反倾销、食药与公共卫生、环境安全等，当事人不能排除。出口管制法、海关法、外汇管理条例在中国法上构成履行侧强制规范的，选择外国法不能写成“本合同不受中国监管”。解释（一）第九条：故意制造连结点规避强制规定的，不发生适用外国法的效力。  
   **修改句**：`双方选择适用的法律，不影响中华人民共和国法律、行政法规中必须直接适用的强制性规定，包括但不限于出口管制、海关监管、外汇管理、反倾销和反垄断。任何一方不得约定“选择外国法即排除上述规定”，也不得通过改变签约地、仲裁地或壳公司连结点规避上述规定。`

3. **不得输出未核验的外国法**  
   用户要“按越南法／英国法直接给结论”：外国法内容字段停止，建议缓签或另聘该法域律师。法律适用法第五条：适用外国法损害中国社会公共利益的，适用中国法。只点名，不作已认定结论。  
   **修改句**：`若双方选择适用【待填】国法律，该选择仅在不违反前款强制性规定和社会公共利益的范围内有效。任何一方在签署前应自行取得该法域独立法律意见；本合同审查意见不构成对该外国法内容的陈述或保证。`

4. **CISG 降级**  
   知识稿称 CISG 虽不直接适用于纯承揽但常被参照。本任务：不默认适用；当事人明示并入时，仅作为约定条款处理，并提示公约针对货物买卖，与承揽验收、随时解除、留置可能冲突。  
   **禁止的写法**：`未约定法律的，适用 CISG。` `因含跨境货物交付，当然适用 CISG。`

5. **最强反方**  
   相对人可能主张未选择即适用其本国法，或主张 CISG 已自动适用。签前两极都不写。只写：须明示；未明示则特征性履行或最密切联系；强制规范仍适用。

核验失败：准据法是否有效、CISG 是否适用的法律结论字段停止，事实摘录和“须明示选择、不得默认 CISG”的修改句草稿继续。

## 硬闸 C　进出口必须闭合

本闸是本类型另一生存级闸。改变能不能合法跨境交付。

1. **先锁海关模式，再谈 Incoterms**  
   监管办法第四十条：来料加工是境外企业供料、经营企业不付汇进口、只收加工费、成品由境外企业销售；进料加工是经营企业付汇进口料件、成品外销出口。两者手册、付汇、内销征税路径不同，不得混写“进料或来料，以实际为准”而不选。  
   **修改句**：`本合同项下跨境监管模式为【来料加工／进料加工，择一，待填】。来料加工项下，进口料件由【境外定作人全称】提供，经营企业不付汇进口，承揽人只收取加工费，制成品由定作人在境外销售。进料加工项下，进口料件由【经营企业全称】付汇进口，制成品由其外销出口。双方不得在同一订单上混用两种模式，也不得在手册设立前安排料件入境或成品出境。`

2. **手册、报关、核销是义务和期限，不是已完成事实**  
   海关法第三十三条：从事加工贸易应向海关备案；制成品应在规定期限内复出口；保税料件核销或先征后退；内销须征税，限制进口的还须许可证件。监管办法第二条：经营企业、加工企业、承揽者接受海关监管。  
   **修改句**：`【经营企业全称】应在料件入境前完成加工贸易手册设立，并在成品复出口或依法内销后【待填】日内向海关报核。报关、缴税、申领原产地证（C/O 或协定项下证明）的责任方为【待填】。手册、许可证件未取得前，任何一方不得要求装船、报关或收付汇。内销须另行书面同意并依法完税。`

3. **管制物项与最终用户**  
   出口管制法第十一条、第十二条：管制清单或临时管制物项须许可；知道或应当知道存在国家安全、大规模杀伤性武器或恐怖主义风险的，即使未列入清单也须申请许可。2024 年两用物项出口管制条例第二十四条：申请许可应提交最终用户和最终用途证明。  
   **修改句**：`定作人应在投产前书面说明成品、技术资料和料件是否属于出口管制或两用物项，并提交最终用户和最终用途声明。凡须许可的，由【待填】在出运或对外提供技术前取得许可；未经许可，承揽人有权中止履行且不承担逾期责任。任何一方不得约定“先出运后补许可证”或“本合同签署视为已获全部许可”。`

4. **Incoterms、PSI 与验收分列**  
   框架要求写明 Incoterms 版本和代码，并区分装船前检验与到货检验。第七百八十条：交付并提交资料和质量证明，定作人应当验收。Delivery 不等于 Acceptance。  
   **修改句**：`运输、保险、报关和货物灭失风险按 Incoterms【2020／待填】之【FOB／CIF／DDP／待填】【装运港／目的港，待填】划分。装船前，定作人或其指定的【SGS／BV／待填】应在承揽人所在地实施装船前检验（PSI）；PSI 通过是信用证交单或发运的条件之一，但不视为最终验收。定作人应在目的港卸货后【待填】日内完成到货检验；签收、付款、提单签发或货交承运人不视为验收合格，不影响隐蔽缺陷异议。`

5. **外贸备案旧义纠正**  
   2022 年决定删去对外贸易法第九条。不得写“国内主体必须先取得进出口经营权才能签约”。仍应核：海关报关单位备案、是否具备手册经营企业／加工企业身份、管制物项出口经营资格。未见备案：报关字段停止，不写成“没有进出口权所以合同无效”。  
   **修改句**：`在中国境内办理报关的一方应在首次申报前完成海关报关单位备案，并对备案材料真实性负责。双方确认：2022 年对外贸易法已不再将备案登记作为对外贸易经营者的法定许可条件；未完成报关单位备案的，该方应委托已备案报关企业申报，不得据此主张合同未成立。`

6. **最强反方**  
   相对人可能主张：有合同就可以报关；或主张未办手册只是行政问题不影响民事履行。签前不保证“未备案合同无效”，但必须把手册、许可写成投运先决；履行必然导致无许可出口的，按第一百五十三条和解释第十六条提示停止，不改成可履行出运。

核验失败：许可是否成立、合同是否因无证而无效的法律结论字段停止，事实摘录和“未见许可不得出运”的修改句草稿继续。

## 节点 2　主体、授权、报关身份

1. 建主体表：定作人、承揽人、经营企业、加工企业、外发承揽者、报关单位、开证行／受益人、授权签字人。名称不一致不自动合并。
2. 外方主体：注册证明（Certificate of Incorporation）和 POA；需要公证认证的，写成签署或生效条件，不写成已经完成。口头“我们老板同意了”不得写成已授权。
3. 主权豁免：相对方为外国政府部门或享有豁免的实体时，修改句要求书面放弃主权豁免；未见则字段停止，不保证可执行。
4. 最终用户与结算银行：受限技术或大额信用证时列入主体表。材料未提及不得写成“未受制裁”。
5. 不足：字段停止，列出待补材料，不补主体。

## 节点 3　标的、标准、交付与验收

1. 标的确定到名称、规格、数量、技术标准（GB／ASTM／EN／ISO）及冲突优先序。只有“等”“有关产品”则标缺口。多语种文本须约定以何语为准。
2. 技术规格书作为附件。严禁只写“国际先进水平”“客户满意”。  
   **修改句**：`工作成果的技术标准以附件《技术规格书》为准；规格书与正文冲突时以【规格书／正文，待填】为准。中英文文本不一致时，以【中文／英文，待填】为准。任何一方不得以“国际先进水平”或“行业惯例”替代附件指标。`
3. PSI 与到货检验按硬闸 C.4。签收、付款、装船不当然等于验收。
4. 材料由定作人提供的：及时检验，不得擅自更换；保管不善按第七百八十四条。材料由承揽人提供的：按约选用。不把货交承运人写成默认替代保管责任，除非 Incoterms 条款已把该阶段风险明确划出且用户要保留。
5. 跨境包装：防潮、防锈、抗震及唛头／原产地标识必须改。缺失海运／空运特殊包装是框架所列结构性缺陷。

## 节点 4　程序与生效

把手册设立、出口许可、报关单位备案、原产地证、数据出境评估、内部授权写成**义务和期限**，不写成已经完成。

| 文本写法 | 本任务动作 |
| --- | --- |
| “本合同签字即视为已获全部进出口许可、已完成手册” | 红线；拆成合同生效 vs 手册／许可作为投运先决 |
| “适用英国法，不受中国海关和外汇管理约束” | 红线；改为强制规范直接适用 |
| “未约定法律的适用 CISG” | 必须改；改为明示准据法，删除 CISG 默认 |
| 无谁负责手册、几日内、未完成后果 | 补主体、期限、逾期中止出运 |
| 用户要求倒签许可日或补假手册 | 整体停止 |

不得把“双方同意视为已获许可”写成可放行结构。

涉及敏感图纸或技术参数跨境传输：点名数据安全法、个人信息保护法和 2024 年数据跨境流动规定，字段停止，不代做评估。

## 节点 5　对价、信用证、留置、退出

1. 价金构成分列加工费与料件，币种、税、银行费用、支付节点、质保金。未给出的数字写 `【待填】`。不得把知识稿 30% 预付款写成法定义务。
2. 信用证：审查是否把 PSI 报告、原产地证、手册编号写成交单单据；软条款（开证行单方验单、客检证须申请人出具且无期限）标必须改。  
   **修改句**：`定作人应在【待填】日前开立不可撤销信用证，金额【待填】，允许的交单文件以附件《信用证单据清单》为准，其中须包含正本提单、商业发票、装箱单及约定的 PSI 报告。信用证不得含有仅由开证申请人出具且无明确出具期限的客检证等软条款。银行费用由【待填】承担。`
3. 汇率：可约定波动超过【待填】% 时调整单价或协商；禁止把 3% 写成法定阈值。
4. 第七百八十三条：未支付报酬或材料费的，承揽人可留置或拒绝交付，另有约定除外。禁止“提单签发即放弃留置”。
5. 第七百八十七条：定作人在完成工作前可以随时解除，造成损失的应当赔偿。禁止“定作人解除不赔偿”。选择外国法时仍应提示：若最终适用中国法，本条可能强制；不得在意见里写成“已因选择外国法而不存在随时解除”。
6. 禁止编造单价、总价、信用证金额、汇率阈值。

## 节点 6　格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

外方或货代重复使用的国际加工模板仍可能构成格式条款。审查单方排除间接损失且无上限说明、签收即合格、解除不赔、或裁或诉、最终解释权是否有显著提示（第四百九十六条；合同编通则解释第十条）。仅有网络勾选或弹窗：不得写成已尽提示义务。

违反法律、行政法规强制性规定不一律无效。禁止用已失效“效力性／管理性”口诀。无许可出口、制裁规避、伪造手册：只告知，不写假架构。第一百五十三条和解释第十六条用于修改理由，不代替修改句。

## 节点 7　违约、制裁解除、争议解决

1. 逾期交付、规格不符、手册／许可迟延、逾期付款必须分别有可执行后果。只有“依法承担违约责任”视为必须改。间接损失排除和违约金上限可谈，但须提示说明；避免“按总价 30% 必得、不得调整”。
2. 构成违约不等于当然解除。法定解除只点名催告或目的不能实现，不在本任务作出已解除结论。
3. **合规性解除**  
   **修改句**：`任何一方因出口管制、国际制裁、失去必要行政许可或政府禁令导致主要义务在【待填】日内无法履行的，另一方有权书面解除本合同。解除前双方应在合法范围内配合申请许可或变更最终用户；无法变更的，已合法完成的工作按实际结算，任何一方不得要求对方继续实施被禁止的出运或对外提供技术。`
4. 争议解决：已有仲裁条款，不得改成“应向某法院起诉”并假装已选定诉讼；或裁或诉、机构不明：改成单一机构（如 CIETAC／SIAC／HKIAC）或单一法院连结点。框架推荐国际仲裁以便《纽约公约》执行，这是谈判建议，不是法定义务。
5. 不可抗力须列举战争、罢工、海运封锁、疫情、贸易禁令，并写通知和证明期限。不得把“政府未批出口许可”单独写成不可抗力来掩盖签约时已知的管制义务。
6. 微信已读不写成已经送达，除非合同把该渠道定为送达。

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

对照已加载框架级文件和本方法硬闸，按六步逐段出句。框架中的 OEM／ODM、经销或 CISG 默认：仅在文本确实出现时处理；主给付滑入 OEM 或买卖则按节点 1.2 转出。

| 步 | 本类型必须盯的点 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题名实（涉外承揽／国际加工定作，避免购销或 OEM）；进料／来料点名；外方主体与 POA；报关单位备案；鉴于不把许可或手册写成已完成 | 主体与鉴于修改句 |
| 交易条款 | 技术规格与语种效力；Incoterms 版本与代码；PSI 与到货检验；加工费／料件分列；L/C 或 T/T；币种汇率；手册与原产地证 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 准据法明示；强制规范不排除；制裁／许可解除；间接损失与上限；772 亲自完成；787 解除赔偿；留置 | 可执行后果句 |
| 尾部 | 外方手签与职衔；签署地点；附件：规格书、包装指南、原材料清单、最终用户声明、信用证单据清单 | 生效与附件修改句 |
| 语言 | Acceptance ≠ Delivery；Shall ≠ May；选择外国法 ≠ 排除中国强制规范；CISG ≠ 纯承揽默认法 | 替换空词的句子 |
| 常见问题 | 缺失海运包装；定作人图纸侵权担保；Escrow／保函；先出后补证 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（无许可出口、选外国法排除强制规范、先出后补手册、制裁规避、CISG 默认且拒绝改、解除不赔）；
- `必须改`：可谈但签署前要落句（准据法明示、进料／来料、手册责任、PSI／到货检验、Incoterms 版本、772、留置、L/C 软条款）；
- `可接受可优化`：仍要给句子，不得只标绿（汇率阈值、违约金上限、Escrow、仲裁机构选择）。

用户不可接受事项优先写成红线。生存级订单额或个人无限连带且用户拒绝升级：停止“可以签署”建议。

## 版本冲突

正文、附件、订单、规格书、信用证草本、手册草稿、聊天确认冲突时：

1. 并列 `D#` / `C#`，不选对用户有利的一版。
2. 修改句写明冲突项以哪一份为准，或删除冲突句。准据法、进料／来料、是否授予品牌经销权冲突不得调和成“两套都有效”。
3. 不得在意见里悄悄采用有利版本并称“合同已明确”。
