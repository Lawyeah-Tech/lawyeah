# 边界与路由

本技能只审查 **中介合同 / 建设工程招投标中介合同** 的待签、投标人委托的招标信息报告或媒介撮合文本。中文展示名是「审查建设工程招投标中介合同（中介合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或复制 `工地建筑活动承包资质竣工验收→`、`房屋买卖_租赁中介合同·审查` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 委托人是招标人；编制招标文件、组织开评标、发中标通知书 | 本套导航的类型切开步骤（无独立招标代理场景原子） |
| 工期、价款、质量、竣工验收、进度款、保修为主给付 | `工地建筑活动承包资质竣工验收→` |
| 工程咨询意见、可研、造价、项目管理顾问；对价不绑促成订约 | `只出可行性造价或管理咨询意见不交付测绘测试成果→` |
| 房屋买卖或租赁居间、带看、网签、过户 | `房屋买卖_租赁中介合同·审查` |
| 职业介绍 | `职业中介合同·审查` |
| 婚姻介绍 | `婚姻中介合同·审查` |
| 技术转让中介 | `技术转让中介合同·审查` |
| 保险、证券、期货经纪中介 | `保险_证券_期货经纪中介合同·审查` |
| 演艺经纪中介 | `演绎经纪中介合同·审查` |
| 技术类合同项下技术中介本约 | `技术类合同项下技术中介本约→` |
| 勘察本约 | `为工程设计查明地质水文岩土条件并编制勘察文件→` |
| 监理本约 | `或` |
| 无文本、本类型条件已谈妥、要出己方稿 | 留本任务起草并自审 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或对应专项领域。` 或对应专项领域 |
| 串标、行贿、泄露标底已立案或侦查 | 刑事或行政专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

本约正文夹带一小段工程咨询或招标代理：专章交接对应原子或引擎；合法信息撮合条款可继续审。用户坚持本技能把施工、咨询、房屋中介或招标代理整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
