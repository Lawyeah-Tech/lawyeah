## 节点 6　优先受偿误套闸

支持依据：民法典第八百零七条；施工解释（一）第三十九条、第四十条、第四十一条、第四十二条。第三十五、三十六条未完整返回，不得标已核验。

核心测试：本约标题是委托，优先受偿以施工合同定性为前提；市政公共设施常“不宜折价、拍卖”。

| 文本或意见写法 | 动作 |
| --- | --- |
| 写“乙方当然享有建设工程价款优先受偿权”或“放弃优先受偿” | 必须改。当然享有 = 误套；放弃可能损害建筑工人利益（解释（一）第四十二条），不得写成已放弃成功 |
| 写“保留主张优先受偿的权利”且标的是市政道路、管网、公园 | 必须加第八百零七条例外：根据工程性质不宜折价、拍卖的，不能就该工程拍卖受偿。不得写成已可执行 |
| 把利息、违约金、开发利润、出让分成写入优先受偿范围 | 必须改：第四十条排除利息、违约金、损害赔偿金；开发利润/分成本就不是工程价款 |
| 用户要求按 `工地建筑活动承包资质竣工验收→` 输出优先受偿全套行使路径、起算日诉讼策略 | 目标停止或拒绝；本任务只改条款，不审诉讼策略 |
| 定性仍两可（委托 vs 施工） | 优先受偿法律结论字段停止；只给“不得写成当然享有”的修改句 |

修改句（误套当然优先受偿）：

`定位（担保/价款条款）｜原文：乙方对所建工程享有建设工程价款优先受偿权｜建议改为：乙方就本协议项下已完合格工程的工程价款，是否以及在何种范围内可以依据民法典第八百零七条主张优先受偿，取决于本协议被认定为建设工程施工合同、该工程是否属于不宜折价或拍卖的公共基础设施，以及解释（一）第四十条、第四十一条规定的范围与十八个月期限。双方不得在本协议中预先确认“当然享有”或“已放弃”该项权利。市政道路、管网等公共设施不能折价拍卖的，乙方不得将该设施写成可变现担保物。｜理由：第八百零七条；解释（一）第四十、四十一条；硬闸“优先受偿是否误套”｜可退让点：可保留“乙方不放弃依法可主张的权利”之声明句｜不接受时的红线：坚持“当然优先受偿”或把市政设施写成可拍卖担保则建议不按该句签署`

## 节点 7　违约、解除、争议与转包

支持依据：民法典第七百九十一条、第八百零六条；建筑法 2019 修正第二十八条；框架违约情形针对质量、工期、擅自转包。

1. 质量缺陷、工期延误、擅自转包/违法分包须分别有可执行后果。只有“依法承担违约责任”视为必须改。
2. 解除后处理已完工程量、人员设备清场、已完结算。禁止只写“双方协商解除”。
3. 全部转包或肢解发包：红线告知，不改成可履行转包。
4. 本约两组织争议走诉讼或单一商事仲裁。写成劳动仲裁或“工程造价鉴定怎么赢”：必须改条款，不审策略。
5. 农民工工资：可约定乙方依法发放并提供支付担保信息，不在本任务做欠薪刑事案件评估。

修改句（转包）：

`定位（分包条款）｜原文：乙方可将全部开发事务转委托第三方｜建议改为：未经甲方书面同意，乙方不得将本协议项下工程全部转包，不得肢解后以分包名义转包，不得分包给不具备相应资质的单位。主体结构必须由乙方自行完成。违反本款的，甲方有权解除并按已完合格工程量结算；因此造成的质量或拖欠工资损失，乙方应补偿甲方已付费用，该约定不对抗第三人。｜理由：第七百九十一条；建筑法 2019 修正第二十八条｜可退让点：专业分包须事先书面同意并附资质｜不接受时的红线：保留任意转委托则建议不签`
