# 边界与路由

本技能只审查 **承揽合同 / 检验、鉴定合同** 的待签文本。中文展示名是「审查检验、鉴定合同（承揽合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 核心给付是空间数据采集，交付图纸、坐标、比例尺、地籍或房产测绘成果、地图或测绘数据集；出现测绘资质证书、CGCS2000、高程系统 | `测试测绘合同·审查`。P1：专业版未装则 `unavailable`，提示，不得用本技能硬套 |
| 核心给付是对物理/技术指标做定量测试并交付测试数据或曲线，不给出符合性或成因结论 | `测试测绘合同·审查` |
| 复制既有作品或载体 | `复制合同·审查` |
| 印刷 | `印刷合同·审查` |
| 修复已损坏的既有特定物 | `修理合同·审查` |
| 定作人供料制成新物或改变形态 | `加工合同·审查` |
| 按图从无到有制作新物，承揽人备料 | `定作合同·审查` |
| 只出可行性论证、预测、评价，不交付检验报告或鉴定意见 | `委托技术咨询·审查` / `或` / `咨询服务合同·审查` |
| 从无到有研发新成果 | `委托技术开发合同·审查` / `只审委托合同目录下的委托技术开发。用户或材料按技术类合同进入《技术开发合同》→` |
| 施工许可范围内的建设工程 | `工地建筑活动承包资质竣工验收→` |
| 类似建筑工程的简易新建、构筑物施工 | `项目承揽合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `检验鉴定合同·起草` |
| 已签未争、只问送样日、出报告日、余样领取 | 本套导航的履约步骤 |
| 已成争，含催告、重新鉴定诉讼、鉴定费索赔、立案仲裁 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

检验、鉴定正文里夹带一小段现场测量或取样坐标：测量专条可交接 `测试测绘合同·审查`；鉴定事项、资质回避、意见效力、检材与出庭条款可继续审。用户坚持本技能把测绘、咨询或修理整案改完：`目标停止`。
