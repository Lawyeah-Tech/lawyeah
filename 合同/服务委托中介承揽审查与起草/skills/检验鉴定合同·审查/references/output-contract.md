# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受、报告必然被采信或作为定案根据；编造未给出的价格、工期、数量、许可证文号；把已失效《合同法》及其解释、2000 年司法鉴定机构登记管理办法或 2007 年程序通则写入结论。

## 1. 触发、单方立场与成果状态

立场（定作人/委托人或承揽人/检验鉴定机构）、授权、签署状态、主要目标、用途（诉讼 / 监管报送 / 交易条件 / 内控）。负触发写路由，不启动实体审查。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》承揽章、《加工承揽合同条例》、2000 年机构登记办法或 2007 年程序通则时记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级、子级、定性理由、与测绘/测试/咨询切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读其他类型。挂靠、出借司法鉴定许可证或约定按指定结论出报告：写停笔告知，不填可履行结构。

## 4. 主体、授权、资质与文本版本

主体表：签约名、履行名、付款名、发票名、授权签字人、拟署名鉴定人/授权签字人。资质表：司法鉴定许可证及执业类别 / CMA 能力范围 / 签字人执业证；回避声明是否入附件。版本表：正文、委托书、检材清单、技术服务方案、聊天确认；冲突并列，不选对用户有利的一版。

## 5. 给付闭环

鉴定/检验事项、检材身份与封样、标准或方法、成果形式（报告名称、份数、印章种类）、异议与出庭、价金与节点、余样处置。缺口标 `G#`，不补商业数字。批准、登记、名录在册写成生效条件或期限，不写成已经完成。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹；异常条款（保证采信、约定结论、仅对来样负责且无取样责任、责任限额过低）。强制规范只区分管理性与是否导致民事行为无效。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔/转出口径。禁止输出无修改句的色块表。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`，不编造。禁止只给原则、不给句子。

## 9. 谈判与签署提醒

谈判顺序：先红线（资质回避、意见效力、测绘切开、虚假结论），再必须改，最后可优化。签署提醒：授权、用印与资质主体一致、日期、检材清单与回避声明入附件。不指导倒签或补假资质。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书或效力保证，也不保证报告被采信。
