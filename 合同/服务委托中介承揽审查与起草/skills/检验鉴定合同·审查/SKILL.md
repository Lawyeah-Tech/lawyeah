# 检验、鉴定合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》承揽章、《加工承揽合同条例》、2000 年《司法鉴定机构登记管理办法》或 2007 年《司法鉴定程序通则》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **承揽合同 / 检验、鉴定合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查检验、鉴定合同（承揽合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类合同审查、从零起草、履约交底、争议文书、有效性保证、保证报告被采信、把测绘/测试/咨询/修理文本改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **鉴定资质与回避**：先分轨。用途是诉讼、仲裁中的司法鉴定，且事项落入法医、物证、声像资料、环境损害等登记管理类别的，承揽人须持有效《司法鉴定许可证》、拟署名鉴定人须在司法行政机关鉴定人名录并持执业证；合同须书面披露有无利害关系，命中回避事由则不得承揽。用途是向社会出具具有证明作用的检验检测数据或报告的，须持有效 CMA 资质认定证书，且拟检项目落在证书附件能力范围内。CNAS 实验室认可不能代替司法鉴定登记，也不能单独代替 CMA。挂靠、出借许可证、未取得执业证人员署名：只告知，不改成可履行。
2. **意见效力**：工作成果是《检验报告》或《鉴定意见书》，属于证据材料或证明文件。禁止写成“保证法院采信 / 保证作为定案根据 / 保证对方必然接受 / 结果必须符合某标准或必须支持某主张”。修改句只保证程序、方法、签字盖章和出庭配合符合约定与当时规则；采信与否由有权机关审查。经人民法院依法通知拒不出庭的，鉴定意见不得作为认定事实的根据。一方自行委托的意见，对方有证据或理由足以反驳并申请鉴定的，人民法院应予准许。
3. **与测绘切开**：核心给付是完成空间或几何数据采集，交付图纸、坐标、比例尺、地籍/房产测绘成果、地图或测绘数据集，或文本出现测绘资质证书、CGCS2000、高程系统作为主轴 → 负触发 `测试测绘合同·审查`。本类型核心给付是对照已知标准做符合性判断（检验），或对成因、真伪、伤残、责任等争议事实出具结论性意见（鉴定）。禁止删掉测绘主给付后硬套本技能，也禁止把测绘图纸改写成鉴定意见。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签检验或鉴定正文，尚未签署，尚未成争，核心给付是交付检验报告或鉴定意见，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 测绘出图、坐标数据集、地籍或房产测绘、地图编制，或主轴是定量测试数据而不作符合性/成因结论 → `测试测绘合同·审查`；
- 只出可行性论证、预测、评价，不交付检验鉴定意见 → `委托技术咨询·审查` / `或` / `咨询服务合同·审查`；
- 从无到有研发新成果 → `委托技术开发合同·审查` / `只审委托合同目录下的委托技术开发。用户或材料按技术类合同进入《技术开发合同》→`；
- 修复既有损坏物 → `修理合同·审查`；来料制新 → `加工合同·审查`；按图新造 → `定作合同·审查`；
- 复制 → `复制合同·审查`；印刷 → `印刷合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `检验鉴定合同·起草`；
- 已签只问送样日、出报告日、余样领取 → 本套导航的履约步骤；
- 已催告、解除、索赔、重新鉴定诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

挂靠、出借司法鉴定许可证或 CMA 证书、约定按指定结论出具报告、要求出具虚假报告：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（定作人/委托人或承揽人/机构择一）；相对方；全文及委托书、检材清单、技术服务方案版本；用途（诉讼证据、监管报送、交易条件、内控）；鉴定/检验事项是否特定；资质轨与签字人；回避关系；检材来源与封样；是否约定结论方向或保证采信；报酬与初步评估/正式鉴定是否分阶；拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价金、期限、许可证文号用 `【待填】`，不编造。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `检验鉴定合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有检验、鉴定文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。必须先与测绘/测试切开，再确认是检验（对照已知标准）还是鉴定（成因、真伪、争议事实）。

### 2. 主体、资质与回避

签约名、履行名、付款名、发票名、拟署名鉴定人分列。司法鉴定许可证、鉴定人名录、CMA 能力范围、回避声明未核：字段停止。无资质仍要出诉讼鉴定意见或应回避仍承揽：只告知，不改成可履行。

### 3. 检材、事项与方法

检材名称、封样、数量、进场预审；鉴定事项必须特定；标准或方法入附件。口头“看着能检”不得写成已接收检材。

### 4. 意见效力与独立性

删除保证采信、约定结论方向、指定数据。保留异议期、复检/补充鉴定路径、出庭配合与费用。

### 5. 对价、预审止损与验收

初步评估费与正式鉴定费分列；不具备鉴定条件可终止并结算已发生费用。签收报告不当然等于对结论无异议。

### 6. 787、格式条款与强制规范

保留完成工作前的解除与损失赔偿。无核验引文则法律结论字段停止。

### 7. 质量、保管、余样与争议

程序违法或方法不符导致报告不被使用：减酬、重作或解除。784 期间毁损。危险余样立即领回或付处置费。不选定唯一法院充作意见。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证采信、把无资质诉讼鉴定、应回避仍承揽、按指定结论或虚假报告改成可履行结构。
- `字段停止`：法域、动态规则、许可证与名录、CMA 能力范围、回避事实、检材来源合法性未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁测绘/咨询/修理/开发。
