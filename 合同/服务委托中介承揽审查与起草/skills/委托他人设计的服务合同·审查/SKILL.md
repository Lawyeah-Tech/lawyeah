# 委托他人设计的服务合同·审查

## 任务目标

在单一立场下，只审查 **委托合同 / 委托他人设计的服务合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文名必须是「审查委托他人设计的服务合同（委托合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类合同审查；从零起草；履约交底；争议文书；有效性保证；把建设工程出图、广告设计或一般事务委托整案改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。禁止抄 `单独设计发包，无现场简易施工成果` 的资质等级/图审合格/限额设计/必须招标主路径，禁止抄 `广告设计合同·审查` 的广告法内容审查/发布备案主路径，禁止抄 `一般委托合同·审查` 的处理事务/空白授权/隐名披露主路径。

1. **非建设工程出图**：核心给付是无建设项目报审或施工用途的功能性、实用性设计服务（产品包装改版、画册排版、VI/平面、PPT 美化、产品外观草图、办公空间布局初稿、软装效果稿）。出现方案/初步设计/施工图供报审或施工、图审合格、设计资质章、注册建筑师或结构师出图盖章 → 负触发 `单独设计发包，无现场简易施工成果`。不得把本类型改成可履行出图结构，也不得用民法典第 800 条、勘察设计条例资质管理制度当本类型主路径。
2. **非广告设计**：核心不是向公众介绍商品或服务的广告创意、广告制作或广告发布。出现广告主/广告经营者/广告发布者结构、广告法内容审查、媒介投放或发布备案为主轴 → 负触发 `广告设计合同·审查`（夹带发布或代言再分 `广告合同（广义）·审查`/`广告发布合同·审查`/`广告代言服务类合同·审查`）。不得删掉发布条款后硬套本技能。
3. **非一般委托**：核心不是受托人处理委托人对外事务、代签、代付款或隐名订约。出现以委托人名义接洽第三人、授权委托书四要素、第 925/926 条披露为主轴 → 负触发 `一般委托合同·审查`。不得把本类型改成事务处理、空白授权或隐名代理审查。
4. **功能性设计服务 ≠ 高独创创作 ≠ 技术开发 ≠ 实物承揽**：剧本、交响乐等高独创文艺创作 → `委托创作·审查`。委托研发软件或技术方案 → `委托技术开发合同·审查`。只出可行性或管理意见、不交付设计稿 → `咨询服务合同·审查` 或 `委托技术咨询·审查`。按图加工、定作物化成品 → `加工合同·审查`/`定作合同·审查`。修改句须写清设计范围、交付格式和数量，收回出图、投放广告、代办事务或交实物的措辞。
5. **任务书具象化 + 验收闭环**：审美词（美观、高端、大气、高级感）必须落到附件《设计需求清单》和参考样图。列交付物格式、份数、介质；免费修改次数和超次计费；需求冻结后变更须补充协议并调价款；收到稿件后【待填】个工作日内未书面异议视为合格。禁止以“不好看”单独作为拒付条件。
6. **知识产权分层**：未约定或约定不明时，著作权属于受托人（《著作权法》2020 修正第 19 条），委托人仅得在委托目的范围内使用（著作权民事纠纷解释第 12 条，条号按第 19 条读）。约定财产权转移的，须写付清全款才发生、权利种类与地域、源文件移交绑尾款。署名权、修改权、保护作品完整权不得写成随“全部知识产权”转让。受托人自有库、模板、字体、图库仅非独占许可。
7. **素材商用授权**：受托人承诺字体、图库、肖像、商标已获合法商用授权，否则自行承担对第三方的赔偿责任并负责替换。禁止把侵权风险默示转给委托人。抄袭指定竞品标识或伪造授权：停笔。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签设计服务正文及附件（需求清单、参考样图、报价），尚未签署，尚未成争，核心给付是上述功能性设计服务，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 编制方案、初步设计或施工图供报审或施工，或要求设计资质/出图章/图审 → `单独设计发包，无现场简易施工成果`；
- 广告创意、广告制作或广告发布，广告法内容审查或媒介投放为主轴 → `广告设计合同·审查`；不得删投放后硬套；
- 以委托人名义处理对外事务、代签、代付款，或授权书/隐名代理为主轴 → `一般委托合同·审查`；
- 高独创文艺创作 → `委托创作·审查`；代笔 → `委托代笔合同·审查`；
- 委托技术开发或软件研发 → `委托技术开发合同·审查`；
- 只出咨询意见不交付设计稿 → `咨询服务合同·审查` 或 `委托技术咨询·审查`；
- 按图加工或定作物化成品 → `加工合同·审查` 或 `定作合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `委托他人设计的服务合同·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

挂靠出图、伪造设计资质、抄袭商标或指定仿冒、把违法广告改成可履行结构：只出告知，不改写成可履行文本。

## 建立审查坐标

确认：使用者与授权；单方立场（委托方或设计方择一）；相对方；全文、设计需求清单、参考样图、报价单、验收确认书模板版本；设计范围是否触及出图、广告发布或对外代理；交付格式与源文件是否写明；有偿数字；修改次数；权属约定是否区分财产权与人身权、是否写付清条件；字体图库授权痕迹；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价款、修改次数、验收期、权利地域用 `【待填】`，不编造。

`基本面.md` 把“全部知识产权自交付起归委托人”写成默认归属、并把工程设计资质和广告发布当作本类型主体条件：加载时按 method 纠正。不回写双文件。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `委托他人设计的服务合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有本类型文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。建设工程出图、广告设计、一般事务委托、委托创作、技术开发、纯咨询、实物承揽负触发。

### 2. 主体与文本版本

签约名、履行名、付款名、发票名分列。自然人受托人标个税代扣缺口，不写成劳动关系已经排除。工程设计资质未核不得写成“可以出图”。

### 3. 任务书与交付物

范围、格式、份数、介质、参考样图必须列举。审美空词必须改。

### 4. 验收、修改次数与需求冻结

书面异议期、逾期视为合格、免费修改次数、超次计费、冻结后补充协议。

### 5. 报酬、源文件与定金

预付/阶段款/尾款；源文件移交绑尾款；定金二字与 20% 上限。

### 6. 知识产权与素材授权

第 19 条默认归受托人；付清才转移财产权；人身权不随“全部知识产权”走；字体图库商用授权。

### 7. 解除、格式条款与强制规范

可约定阶段止损和 933 赔偿计算；禁止弃权无效句。无核验引文则法律结论字段停止。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把出图盖章或广告发布或一般事务委托硬套本技能改完、把抄袭商标/伪造字体授权改成可履行结构、坚持“双方放弃任意解除权且解除无效”。
- `字段停止`：法域、动态规则、字体图库授权凭证、未约定权属时的使用范围、自然人个税安排未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
