# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的价款、修改次数、验收期；把已失效《合同法》及其解释或 1990 年《著作权法》第 17 条条号写入结论；把建设工程出图、广告设计或一般事务委托当成已完成的本类型审查；把“交付即全部知识产权归甲方”写成法定默认。

## 1. 触发、单方立场与成果状态

立场（委托方侧／设计方侧）、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查委托他人设计的服务合同（委托合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、1990 年《著作权法》第 17 条条号、1983 年勘察设计合同条例、1994 年广告法或加工承揽合同条例时记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `委托合同`，子级 `委托他人设计的服务合同`。定性理由、易混切开结果（建设工程设计出图、广告设计、一般委托、委托创作、技术开发、咨询、实物承揽）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。挂靠出图或仿冒停笔，不填可履行结构。

## 4. 主体、自然人与文本版本

主体表：签约名、履行名、付款名、发票名、授权签字人。自然人受托人标个税代扣缺口。版本表：正文、设计需求清单、参考样图、报价单、聊天确认；冲突并列，不选对用户有利的一版。

## 5. 给付闭环

设计范围、交付格式/份数/介质、源文件、任务书约束、验收期与视为合格、免费修改次数与超次计费、需求冻结与变更调价、报酬节点、发票、财产权付清转移、第三方素材仅许可。缺口标 `G#`，不补商业数字。不输出图审合格、设计资质等级、广告发布备案或授权委托书四要素作为本类型主路径。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹；异常条款（交付即全部知识产权、字体侵权转嫁、无限加需求、审美拒付、弃权解除）。强制规范只区分管理性与是否导致民事行为无效。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔/转出口径。禁止输出无修改句的色块表。硬闸七项若文本触及或用户立场下原文沉默，必须各有至少一行。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`，不编造。禁止只给原则、不给句子。禁止输出可履行的出图盖章、广告发布或仿冒句。

## 9. 谈判与签署提醒

谈判顺序：先红线（类型错位、出图/仿冒/弃权解除无效、字体侵权转嫁），再必须改（任务书、验收、修改次数、付清才转移财产权、源文件、商用授权），最后可优化。签署提醒：授权、用印、日期、需求清单、参考样图、验收确认书模板入附件。不指导倒签或补假授权。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书或效力保证，也不是建设工程设计、广告设计或一般委托审查。
