# 边界与路由

本技能只审查 **承揽合同 / 项目承揽合同** 的待签文本。中文展示名是「审查项目承揽合同（承揽合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 城镇公共建筑、高层或多层主体、大中型工业厂房；建筑业资质、规划许可、施工许可、监理、竣工验收 | `工地建筑活动承包资质竣工验收→`。不得删掉施工条款后继续当项目承揽审 |
| 设计采购施工一体，或发包人要求主导 | `设计采购施工一体→` |
| 经发包人同意从总包切出的专业工程 | `或` |
| 依附建设工程总包、只出人工的劳务分包 | `或` |
| 核心给付是勘察 | `为工程设计查明地质水文岩土条件并编制勘察文件→` |
| 单独设计发包，无现场简易施工成果 | `单独设计发包，无现场简易施工成果` |
| 联合体成员内部分工 | `联合体成员内部分工` |
| 监理 | `或` |
| 工厂内来料加工动产 | `加工合同·审查` |
| 承揽人供主材制成新动产 | `定作合同·审查` |
| 修复既存设备或物品 | `修理合同·审查` |
| 框架合同加订单反复触发，无单一场地项目 | `框架加订单承揽·审查` |
| 人格从属、工资社保 | `与劳动合同个人劳务切开：考勤+固定底薪+人身从属为主轴→负触发` |
| 个人之间提供劳务过程、接受方指挥劳动 | `平等主体个人劳务且无演艺机会媒介→负触发` |
| 无文本、本类型条件已谈妥、要出己方稿 | `项目承揽合同·起草` |
| 已签未争、只问进场／隐蔽验收／进度款留痕 | 本套导航的履约步骤 |
| 已成争（质量、催告、解除、索赔、立案、仲裁） | `或对应专项领域。` 或对应专项 |
| 施工／EPC 已成争（优先受偿、鉴定、黑白合同） | `施工／EPC已成争（优先受偿鉴定黑白合同）` 或 `或` |
| C 端大众快检 | 只分流，不回改 |

项目承揽正文里夹带一小段工厂加工或家具修理：专条交接对应原子；场地项目、隐蔽工程、进度款、转包、保险条款可继续审。用户坚持本技能把施工、EPC、加工或雇佣整案改完：`目标停止`。

占用基本农田、拆承重、无证改燃气、必须领证却拆分规避：留在本技能只出告知并停笔，不转去“改成可履行／可过检稿”。

专业版未收录的 P1 场景不会安装对应原子。若用户拿这些文本来找专业版：输出 `unavailable`，提示或回引擎，不得用本项目承揽原子硬套。
