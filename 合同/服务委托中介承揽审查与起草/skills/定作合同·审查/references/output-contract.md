# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、成果必然合格、留置必然实现或对方接受；编造未给出的单价、数量、工期；把已失效《合同法》《加工承揽合同条例》写入结论；把货交承运人风险、所有权保留百分之七十五取回、买卖检验期间视为合格或施工竣工验收规则硬套本类型；把定作人供主材的收料检验写成定作默认主路径。

## 1. 触发、单方立场与成果状态

立场（定作人／承揽人）、授权、签署状态、主要目标。加工、买卖、修理、OEM、施工、技术开发或其他负触发写路由，不启动实体审查。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释或《加工承揽合同条例》时记噪声，不得写入 `L#`。返回买卖第 595／604／621／641 条或施工第 788／791 条时标明“不适用本类型”，不得写入默认法。

## 3. 类型与加载路径

父级 `承揽合同`，子级 `定作合同`。写定性理由和与加工／买卖／修理／OEM／项目承揽／施工／技术开发的切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。违禁品或无证特种设备写停笔告知，不填可履行结构。

## 4. 主体、授权、资质与文本版本

主体表：签约名、履行名、供材名、收货名、付款名、发票名、授权签字人、技术代表。特种设备写许可名义人。版本表：正文、规格书、图纸／技术协议、封样、订单、聊天确认；冲突并列，不选对用户有利的一版。

## 5. 给付闭环（本类型必填）

固定检查并回链文本：

- 工作成果名称、规格、数量、计量单位是否确定到可履行；
- **规格书、图纸或封样是否已作为合同附件**并写明同等效力；无附件则不得写成标的明确；
- 主要材料由谁提供；承揽人供材的品牌、产地、牌号、检验时点和换材书面同意；
- 过程监督权与指示权的授权代表、书面形式、非授权人指示无效；
- 主要工作与辅助工作清单；转第三人是否须书面同意及责任归属；
- 图纸／技术要求不合理的通知期、答复期和怠于通知的损失分担；
- 交付工作成果、技术资料和质量证明；验收期限、标准、视为合格的范围；签收与验收是否切开；隐蔽瑕疵保证期；
- 价款构成（材料费、劳务费、运输费）、是否固定总价、支付节点、部分交付是否相应支付；
- 未付报酬时的留置或拒绝交付是否被排除；
- 任意解除的通知、已完工结算、剩余材料／模具处理、预期利润是否纳入赔偿；
- 图纸、模具、商业秘密归属与双向侵权担保；不得留存复制品；不得把“当然归定作人／当然归承揽人”写成未核验默认；
- 成果毁损灭失风险是否按交付划分，有无误套货交承运人或买卖所有权保留。

缺口标 `G#`，不补商业数字。许可、批准写成义务或条件，不写成已经完成。

## 6. 格式条款与强制规范

是否构成格式条款（含定作人制式采购或承揽人制式定制文本）；提示说明痕迹。强制规范只区分是否导致民事行为无效与是否仅造成履行障碍（许可、特种设备）。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。硬闸六项加违禁许可若文本触及或本方立场下原文沉默，必须各有至少一行，不得用色块代替。

## 8. 修改句

按框架六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点、不接受时的红线。未给出的商业数字用 `【待填】`。禁止只给原则、不给句子。禁止输出货交承运人默认风险句、买卖百分之七十五取回句、买卖检验期间视为合格句或竣工验收句充当修改句。禁止输出把定作改成来料加工的收料主句。

## 9. 谈判与签署提醒

谈判顺序：先红线（类型错误、无规格附件、违禁／无证、772 空白转包、签收吞没留置、787 解除不赔），再必须改（供材标准与换材、技术代表、验收期、交付前风险、IP 归属），最后可优化。签署提醒：授权与用印、技术代表书面授权、骑缝、日期不得倒签、图纸／规格／封样附件清单及冲突适用顺序。不指导倒签或补假许可。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书、办证代办或效力保证。
