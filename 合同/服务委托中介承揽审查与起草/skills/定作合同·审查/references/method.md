# 审查方法（锁定 承揽合同 / 定作合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型，禁止打开加工、买卖、修理、OEM、施工或其他子目录“对照一下”。

本文件是**定作**签前判断节点。主线只有一条：承揽人**自备主要材料**，按定作人要求制成**特定成果**并交付。不是来料加工审查清单，也不是动产买卖或施工审查清单。

禁止写入本类型默认结论：货交承运人即风险转移、收货检验期间视为符合约定、所有权保留及已付价款百分之七十五不得取回、商品房或竣工验收／承包资质主路径、定作人供主材的收料检验主路径。

每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、成果必然合格、留置必然实现、解除必然赔到预期利润、对方必然接受或唯一必得金额。

`search_law` 返回已失效《合同法》及其解释、1984 年《加工承揽合同条例》、担保法解释或经济合同法时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突。

示范文本只参考结构。定作或加工承揽示范文本不证明本约条款已被接受；符合格式条款定义的，仍按格式条款审查。

### 双文件使用

同目录知识双文件按栏目语义使用，不回改正文，不因标题宽泛拒跑：

- 含“首部／交易条款／配套／尾部／语言／常见问题”六步的，供节点 8 出句；
- 类型切开、规格附件化、亲自完成、承揽人供材与风险、任意解除、验收留置、违禁许可由本方法硬闸承担，双文件只作条款清单，不代替核验。
- 双文件若把定制软件系统、修理、OEM、广告制作写成适用场景：只当线索，正触发仍须满足本方法节点 1.1。软件尚待开发转技术开发；修理、贴牌、来料加工负触发。
- 双文件对任意解除的“限制解除条件”：不得写成可以排除第 787 条，只允许约定赔偿范围和结算程序。
- 双文件称“无约定时知识产权归承揽人”：不得直接写成已核验法定默认。必须按权利类型运行时核验后再落句；空白则必须改，不推定归任何一方。
- 文件不可用（空、乱码、与定作明显无关）：记 `G#`，用本方法节点继续，不得改去加载加工或买卖双文件。

## 节点 1　类型识别与邻类负触发

### 1.1 本类型正像

同时满足才继续：

- 核心给付是承揽人按照定作人的要求**完成工作**，交付**工作成果**，定作人支付报酬（第 770 条；定作是该条列举的承揽形态之一）；
- **主要材料由承揽人采购或自备**，不是定作人送主材上门；
- 成果须符合定作人提出的规格、图纸、样品或性能指标，定作人对过程享有监督、检验或指示空间；
- **不是**转移已经存在的通用货物所有权，**不是**修复既存物，**不是**工地建设工程。

标题写成“定作合同”“定制协议”“非标设备承揽”只是线索。名实不符按核心给付归类，标题冲突写入 `C#`。

第 771 条：内容一般包括承揽的标的、数量、质量、报酬，承揽方式，材料的提供，履行期限，验收标准和方法。缺一项标必须改，不编造。对定作，**材料的提供**必须写成承揽人供主材；**验收标准和方法**必须能指回附件化的规格／图纸／样品。

### 1.2 必须切开（禁止两套知识）

| 信号 | 归入 | 本技能动作 |
| --- | --- | --- |
| 定作人提供铝材、面料、坯件等主要材料，承揽人按图加工 | 加工 | **负触发** → `加工合同·审查`。不得把来料改写成“乙方自备”以便留下 |
| 通用型号现货或卖方自行组织生产，买方不控制过程，对价是货款 | 动产买卖 | **负触发** → `通用型号现货卖方组织生产买方不控制过程→`。不得删掉购销条款后继续当定作审 |
| 标的是把已有设备、车辆、器件修复到可用 | 修理 | **负触发** → `修理合同·审查` |
| 主给付是贴委托方商标、品牌授权、禁止自有渠道销售贴牌品 | 定牌加工（OEM） | **负触发** → `定牌加工（OEM）合同·审查`。普通定作夹带商标使用的，商标条款只标缺口并转 OEM，不在本任务展开品牌授权 |
| 农村低层自建、私人室内装修、小型农田设施 | 项目承揽 | **负触发** → `项目承揽合同·审查` |
| 工地建筑活动、建筑业资质、规划许可、竣工验收、监理 | 建设工程施工 | **负触发** → `工地建筑活动承包资质竣工验收→`。禁止当普通定作 |
| 设计采购施工一体 | EPC | **负触发** → `设计采购施工一体→` |
| 尚待研究开发，不保证成果必然产生 | 技术开发 | 负触发 → 对应技术开发原子或引擎。不得把研发不确定性改成“按图必然交付” |
| 人格从属、考勤管理、工资社保 | 劳动合同 | 负触发 → 劳动领域。不得用定作包装用工 |

材料提供方不明：先追问；仍不明则类型字段停止，列出定作／加工／买卖三种可能，不灌入两套知识。定作人仅提供样品、模具或少量专用件，主材仍由承揽人采购的，可留在本类型，但样品／模具须进附件并写检验与返还。

### 1.3 加载协议

只打开本目录 `基本面.md` 与 `框架.md`。禁止读 `types/` 或其他场景原子目录。

### 1.4 违法结构停笔（本类型）

出现下列任一结构，只出告知，不改写成可履行文本：

- 法律、行政法规禁止生产或流通的物（枪支、管制刀具、毒品容器、走私料、非法出版物等）仍要“改到能定作”；
- 特种设备、医疗器械、危险化学品容器等须许可而未提及有效许可，仍要“先投产再办证”；
- 通谋虚假意思、阴阳两套报酬规避税收；
- 倒签合同日期以改变许可或会计时点。

用户坚持“改到能签／能过检”：整体停止。合规改道（真实取得许可后再签）只点名，不在本任务起草规避方案。

## 硬闸 A　定作 ≠ 加工 ≠ 买卖 ≠ 工程 ≠ OEM

本闸改变技能是否继续。依据第 770 条对照第 595、788 条。买卖第 595 条、工程第 788 条**仅作负向切开**，不得写入本类型默认给付。

1. **与加工**  
   加工：定作人供主材，承揽人完成加工工作。定作：承揽人供主材，按特定要求制成成果。不得把来料加工稿改写成“乙方包料”以便留下，也不得把本类型改成来料加工去借用收料检验主路径。

2. **与买卖**  
   买卖转移标的物所有权换价款；买受人对生产过程通常没有监督、指示权，也没有第 787 条任意解除。定作的目的是完成特定工作成果，标的通常不可替代。预约定货、卖方自备原料，仍可能是买卖——关键看买方是否控制规格过程、成果是否特定。来稿同时写“购销”和“定制”的，按供材、是否按图、是否监督过程定性，不得用标题单独留下。

3. **与工程**  
   建设工程是特殊承揽，受建筑法、招标投标和竣工验收强制规范。出现施工承包、主体结构、竣工验收：负触发。不得用第 772 条“主要工作”去改写第 791 条主体结构自施。

4. **与 OEM**  
   主给付是品牌授权和贴牌渠道控制：负触发。本任务不展开商标许可。

5. **误套买卖默认句必须改**  
   定作稿出现“货交承运人风险转移”“收货 3 日内未异议视为全部合格”“货款付清前所有权保留，已付百分之七十五不得取回”：定作人／承揽人立场均须改回工作成果交付风险和本类型验收／留置结构，或标明该句是特约而非法定默认。不得当本类型主路径放行。

6. **最强反方**  
   相对方会主张“名为定作实为买卖，适用检验期间视为合格，并排除任意解除”。签前必须把供材方、特定规格附件、过程监督和 787 清算写进正文，避免事后被重新定性。

示例修改句（标题名实不符，定作被写成购销）：

`合同名称／第【待填】条｜原文“设备购销合同……货交承运人后风险及所有权按买卖规则处理”｜建议改为“本合同为定作合同。承揽人自备主要材料，按附件【待填】图纸／规格／封样制成工作成果并交付，定作人支付报酬。工作成果毁损、灭失的风险，交付前由承揽人承担；定作人逾期受领的，自逾期之日起由定作人承担。删除货交承运人即转移风险、收货即视为全部合格、所有权保留及已付价款百分之七十五不得取回等买卖默认句”｜理由：硬闸 A；第 770 条对照第 595 条｜可退让：运输区段风险可另作特约，但须写清起止点｜不接受：继续按动产买卖履行`

## 硬闸 B　规格／图纸／样品必须附件化；监督与指示须有授权代表

本闸改变合同能否特定履行，也是定作与通用买卖最容易塌陷的分界。无规格仍放行：禁止。

1. **三件套至少一件成为合同组成部分**  
   技术图纸、规格说明书、封存样品，至少一件作为附件，注明与正文同等效力，并写冲突时以哪一份为准。只有“按甲方要求定制”“质量优良、性能可靠”：标红线，字段停止，不编造型号。

2. **鉴于条款不是技术文件**  
   关键尺寸、材质、性能指标写在鉴于或目的条款中的，必须改落到交易条款或附件。鉴于不构成独立给付标准。

3. **双向封样**  
   精密定作物：双方代表当面封签、各执一份、保存至质保期满。样品有隐蔽瑕疵且定作人不知情的，仍须达到通常标准或书面指标，不得“与样品一致即免责”。

4. **监督权与指示权分开写**  
   第 779 条：工作期间应当接受定作人必要的监督检验；定作人不得因监督检验妨碍承揽人的正常工作。监督是检查进度和材料，不是驻厂考勤。  
   指示是变更规格、确认代料、批准偏离。必须锁定授权代表姓名／职务／联系方式和书面形式（指定邮箱或签章）。非授权人口头指示不构成变更，承揽人按无效指示实施的，自行承担返工。

5. **最强反方**  
   承揽人主张“行业惯例、看样交货即可”；定作人事后拿出未经附件化的聊天截图当验收标准。签前必须把标准锁进附件，把指示锁进授权代表。

示例修改句（无规格仍要签）：

`第【待填】条／附件空缺｜原文“乙方按甲方要求定作一批非标件，质量按国标”｜建议改为“定作物以附件一《规格与图纸》和附件二《封样确认单》为准，载明名称、图号、材质、尺寸公差、数量、执行标准。附件与正文冲突的，以附件一为准，封样用于外观与配合尺寸。关键参数不得仅写在鉴于条款。定作人指定【待填：姓名／职务】为唯一技术代表，其对材料检验、过程监督和书面指示的确认视为定作人行为；非授权人指示不构成变更。无附件一或附件二的，定作人有权拒绝开工并中止预付款”｜理由：硬闸 B；第 771、779 条｜可退让：先锁图号与材质，次要外观可后补封样｜不接受：无规格、无图纸、无封样仍签署`

用户坚持“规格以后再补、先把合同签了”：该特定化字段停止，不得给出“可以签署”建议。

## 硬闸 C　主要工作亲自完成（772／773）

本闸改变定作人是否享有解除权、承揽人能否外协。运行时核验第 772、773 条后再写法律效果。

1. **亲自完成是原则**  
   第 772 条第 1 款：承揽人应当以自己的设备、技术和劳力完成主要工作，但是当事人另有约定的除外。文本无“主要工作”定义：必须改。定作场景下，对成果性能起决定作用的下料、成型、热处理、总装、终检等不得用“生产安排由乙方自行决定”一笔带过。

2. **交第三人**  
   第 772 条第 2 款：将主要工作交第三人完成的，应当就该第三人完成的工作成果向定作人负责；**未经定作人同意的，定作人也可以解除合同**。修改句锁：事先书面同意＋承揽人仍负责＋未经同意可解除。不得只写“可外协”“可分包”。

3. **辅助工作**  
   第 773 条：辅助工作可以交第三人，承揽人就该成果向定作人负责。修改句给辅助工作白名单（包装、运输、表面清洗、外协电镀等），禁止用“辅助工作”偷换成型、总装、终检。

4. **另有约定**  
   当事人可以约定主要工作也可交指定第三人。必须点名第三人范围、资质和承揽人仍负责。空白“双方同意可转包”视为未约定清楚。

5. **最强反方**  
   承揽人主张包工包料就是可以自找工厂、外协是行业习惯。定作人签前必须把主要工作清单写成附件。承揽人立场可谈白名单，但不得接受“全部工作可自行安排第三方”。

示例修改句（定作人，空白外协）：

`第【待填】条｜原文“生产安排由乙方自行决定”｜建议改为“主要工作（【待填：下料、成型、热处理、总装、终检】）须由承揽人使用自有设备、技术和人员亲自完成。未经定作人事先书面同意，承揽人不得将主要工作交第三人。经同意的，承揽人仍就该第三人完成的工作成果向定作人负责。辅助工作（【待填：包装、运输、表面处理】）可交第三人，承揽人就该成果向定作人负责。未经同意将主要工作交第三人的，定作人有权解除本合同并请求赔偿”｜理由：硬闸 C；第 772、773 条｜可退让：列明可外协的辅助工序白名单｜不接受：空白外协或可转包全部工作`

## 硬闸 D　承揽人供材（774）与交付前风险

本闸改变材料质量和灭失风险由谁承担。定作的法定供材条款是第 774 条，不是第 775 条。第 775 条只在定作人另供样品、模具或专用件时作为配套，不得把本类型改写成来料加工。

1. **按约选用并接受检验**  
   第 774 条：承揽人提供材料的，应当按照约定选用材料，并接受定作人检验。修改句写品牌、产地、牌号、规格、执行标准、检验时点（进厂／投产前）和不合格处理（换料、停工、费用分担）。不得只写“乙方自备原材料”。

2. **替换材料须书面同意**  
   知识稿“原材料替代陷阱”：未约定更换须书面同意，成品性能被换掉。修改句：承揽人拟更换品牌、产地、牌号或规格的，须事先书面说明等效性并取得定作人技术代表确认；擅自更换视为质量不符，定作人可要求重作、减少报酬或解除。不得用“同等档次”“性能相当”收口。

3. **定作人检验权不是收货权**  
   材料检验可在承揽人现场进行。定作人未在约定期限检验，不免除承揽人按约选用的义务，也不等于材料已被接受为成果合格。

4. **价款构成**  
   定作价款通常含材料费、劳务费、运输费。修改句分列是否固定总价、材料涨跌是否可调、税和运是否含在总价内。承揽人供主材时对价称“价款”可核对；混称不当然无效，但结算必须能拆开料与工。未给数字用 `【待填】`。

5. **风险以成果交付为原则，不是买卖第 604／607 条**  
   工作成果毁损、灭失的风险，交付前由承揽人承担，交付后由定作人承担；定作人拒绝接收或逾期受领的，自违约之日起由定作人承担。材料在制成成果前的风险，原则上由作为所有人的承揽人负担，另有约定除外。  
   **禁止**把“货交承运人即风险转移”写成默认。运输区段若要特约，必须写清交付地点、承运人由谁指定、保险由谁办理。所有权保留不是定作默认结构；文本未约定不要编造，更不要写入买卖百分之七十五取回。

6. **第 775 条的有限角色**  
   仅当定作人提供样品、模具或少量专用件时，才要求承揽人及时检验、不符通知、不得擅自更换。若该“专用件”实际已是主材：按节点 1.2 负触发加工。

7. **最强反方**  
   承揽人主张材料已进厂即视为定作人认可；定作人主张货已发出风险就在自己身上所以要按买卖处理。签前必须把选用标准、检验记录和交付时点写成程序，而不是口号。

示例修改句（自备材料无标准＋货交承运人风险）：

`第【待填】条｜原文“原材料由乙方自备，货交承运人后风险由甲方承担”｜建议改为“主要材料由承揽人按附件【待填】《材料标准》采购，列明品牌、产地、牌号和执行标准，并在投产前接受定作人检验。承揽人更换材料须经定作人技术代表事先书面同意。工作成果毁损、灭失的风险在【待填：定作人指定地点交付并签署交接单】前由承揽人承担；定作人逾期受领的，自逾期之日起由定作人承担。删除货交承运人即转移风险的表述。承揽人未按约定选用或擅自更换材料的，定作人有权要求换料、停工重作、减少报酬或解除”｜理由：硬闸 D；第 774 条｜可退让：运输险可由定作人加保，但不改变交付前风险归属｜不接受：自备材料无标准，或默认货交承运人风险转移`

## 硬闸 E　定作人任意解除（787）

本闸改变退出成本。运行时核验第 787 条。

1. **法定权利不得删除**  
   定作人在承揽人**完成工作前**可以随时解除合同，造成承揽人损失的，应当赔偿损失。双方不得约定排除该解除权，也不得写成“解除不赔”“互不赔偿”“任何一方可随时解除且无需补偿”。知识稿“限制解除条件”只允许转化成赔偿范围和通知程序，不得写成定作人无权解除。实务观点普遍认为该权利不得约定排除；相反观点仅作反方记录，不作为放行理由。

2. **时点**  
   工作已完成或成果已交付：不再走第 787 条，质量问题走第 781 条。修改句写明分界点。

3. **必须落句的清算项**  
   解除通知的形式与到达；停止工作的时点；已完工部分如何计量和结算；承揽人已购且无法转作他用的材料如何作价或由谁接收；半成品、模具归谁；已付预付款如何冲抵。  
   预期利润是否纳入赔偿：司法实践有争议，必须事先约定“包含／不包含及计算方式”，不得写成必然赔到全部预期利润，也不得默认一律不赔。

4. **最强反方**  
   定作人主张任意解除是形成权、无需理由、赔偿限于直接损失；承揽人主张应包含合同履行后可获得的利润，或主张包工包料已备料所以不能解除。签前用清算公式锁定争点，不在本任务裁判个案比例。

示例修改句（解除不赔）：

`第【待填】条｜原文“任何一方可随时解除，互不赔偿”｜建议改为“定作人可在承揽人完成工作前书面通知解除本合同，但应赔偿承揽人因此受到的损失，包括：①已投入且无法转作他用的材料费和工时费；②已完成部分按进度应付报酬；③双方约定的预期利润【待填：包含／不包含，计算方式】。解除通知到达之日合同解除。承揽人应在【待填】日内停止工作并移交已完成部分、剩余材料和模具。承揽人完成工作后，定作人不得再依本条解除，质量问题按修理、重作、减少报酬处理。双方不得约定‘解除不赔’，也不得删除定作人在完成工作前的法定解除权”｜理由：硬闸 E；第 787、781 条｜可退让：预期利润是否计入及上限｜不接受：删除法定解除权或解除不赔`

## 硬闸 F　验收与留置（780–783）

本闸改变报酬请求和质量救济是否被签收吃掉。

1. **交付内容**  
   第 780 条：完成工作应当向定作人交付工作成果，并提交必要的技术资料和有关质量证明；定作人应当验收。修改句列成果、资料、证明三件套，并回链附件规格／封样。不得只写“交货”。

2. **验收期是约定，不是买卖第 621 条**  
   第 780 条没有“逾期未通知视为符合约定”的法定效果。视为合格必须写成约定，并限定范围：至多覆盖数量与外观，不得消灭隐蔽瑕疵以及第 781 条的修理、重作、减少报酬、赔偿损失。禁止把买卖检验期间规则当定作默认法。知识稿“异议期限”只作约定设计，不上升为法定视为合格。

3. **签收 ≠ 终局合格**  
   签收送货单只确认件数与外观。修改句固定反说。隐蔽瑕疵须另设保证期。

4. **报酬**  
   第 782 条：按约定期限支付；约定不明且依第 510 条仍不能确定的，交付工作成果时支付；部分交付的，相应支付。修改句拆预付、进度、验收、质保尾款，并写付款前提（验收意见、发票）。未给数字用 `【待填】`。

5. **质量不符**  
   第 781 条：定作人可以合理选择修理、重作、减少报酬、赔偿损失。只有“依法承担违约责任”视为必须改。

6. **留置或拒绝交付**  
   第 783 条：未支付报酬或材料费等价款的，承揽人对完成的工作成果享有留置权或者有权拒绝交付，但是当事人另有约定的除外。当事人可以排除留置，但必须单独、清楚；禁止与“签收视为终局合格”捆成一句。留置对象为动产工作成果；丧失占有则留置消灭。宽限期运行时核验，无引文不把“六十日”写成已核验。

7. **最强反方**  
   定作人主张已签收不得再留置、不得再主张质量；承揽人主张未验收也视为合格应付款。签前必须拆开签收、验收、付款、留置四件事。

示例修改句（签收即合格并放弃留置）：

`第【待填】条｜原文“签收即视为合格，乙方放弃留置权”｜建议改为“定作人应在成果交付后【待填】日内按附件【待填】标准和封样验收，并出具书面验收意见。逾期未验收且无正当理由的，仅视为对数量和外观的确认，不消灭隐蔽瑕疵请求权和修理、重作、减少报酬请求权。签收送货单不构成终局合格。定作人未支付到期报酬或材料费的，承揽人有权留置已完成工作成果或拒绝交付，双方另有书面约定的除外。本条不因签收而被视为放弃留置权”｜理由：硬闸 F；第 780、781、783 条｜可退让：外观视为确认的天数；可另条单独、清楚地排除留置｜不接受：签收即终局合格并放弃留置`

## 硬闸 G　违禁品／无许可特种设备

本闸改变是否整体停止。

1. 定作对象或工艺属于法律、行政法规禁止生产、流通的，合同存在效力瑕疵。只出告知，不改成可履行投产结构。
2. 特种设备、医疗器械、危险化学品容器、印刷专控等须许可：文本或用户材料未出示有效许可的，许可字段停止，不写“可以开工”。口头“对方有证”不得写成已许可。
3. 无许可仍要“先签后办、出了问题再补”：整体停止。
4. 违反强制规范不一律无效（第 153 条及通则解释第 16 条方向）。禁止用已失效“效力性／管理性”口诀。无许可多为履行障碍：用停止或改道提示处理，不轻易写“无证则合同无效”，也不得把无证改成可履行定作路径。

无修改句示例。本闸的成果是停笔告知和转介，不是改到能签。

## 节点 2　主体、资质、技术代表、独立承揽

1. 建主体表：签约名、履行名、供材名、收货名、付款名、发票名、授权签字人、**技术代表**。名称不一致不自动合并。
2. 特种设备或管制产品：文本或用户材料未提及许可的，许可字段停止，不写“可以经营”。
3. 共同承揽：第 786 条对定作人连带责任，另有约定除外。多承揽人未写连带或份额：必须改。
4. 口头“我们老板同意了”不得写成已授权。技术代表授权须书面。
5. 独立承揽：定作人监督检查不得写成对承揽人员工的考勤管理。深度介入人员管理的，标名为承揽实为用工的红旗，建议劳动专项，不在本任务改成劳动合同。
6. 承揽过程致第三人损害：原则上承揽人承担责任；定作人仅在定作、指示或选任有过错时相应负责（第 1193 条及侵权编解释（一）第 18 条方向）。修改句可要求承揽人投保，不写成定作人无责保证。

---

## 节点 3　成果特定化、价款、所有权、IP

1. 成果名称、规格、数量、计量单位、图纸编号、封样必须在正文或作为合同组成部分的附件中同时出现。回链硬闸 B。只有“定作一批”“按甲方通知”：标必须改。
2. 质量标准优先国标／行标；无标准则封样或图纸，禁止“供参考”。
3. 价款分列料费、工费、税、运、包装。是否固定总价、材料调差触发条件必须可执行。未给数字用 `【待填】`。
4. 定金：必须使用“定金”二字才讨论罚则；订金、保证金无定金性质不得写成双倍。约定超过主合同标的额百分之二十：超过部分不产生定金效力。无核验引文不得把 20% 写成已核验结论，修改句仍应压到不超过 20% 或改为预付款。
5. 工作成果所有权转移时点（交付时／付清全款时）必须落句。未写不得推定，也不得偷偷套买卖所有权保留。
6. **知识产权必须落句**  
   分三类：定作人背景资料（图纸、规格、样品、商业秘密）；承揽人背景技术与通用工艺；为本合同新产生的改版图纸、工装、模具。每一类写归属或许可范围。不得默认“成果知识产权当然归定作人”。知识稿“无约定归承揽人”不得写成已核验法定默认，须按著作权／专利权类型运行时核验。  
   第 785 条：承揽人应当按照定作人的要求保守秘密，未经定作人许可，不得留存复制品或者技术资料。修改句含归还、销毁和不得用于其他订单。  
   侵权担保双向：因定作人提供的图纸、规格或指定标识侵权，定作人抗辩并赔偿；因承揽人供材、工艺或自备模具侵权，承揽人抗辩并赔偿。
7. 禁止编造单价、税率、工期。

## 节点 4　协助、变更、图纸通知、保管

1. **协助**  
   第 778 条：需要定作人协助的，定作人有协助义务；不履行致使工作不能完成的，承揽人可催告、顺延；逾期仍不履行的，承揽人可以解除。修改句列协助事项（确认图纸、提供检测接口、提供安装条件）。定作场景下，协助通常**不是**供主材。

2. **中途变更**  
   第 777 条：定作人中途变更工作要求造成损失的，应当赔偿。修改句写变更须经技术代表书面确认、报价确认后实施、未确认不得停工或擅自改图。

3. **图纸与技术要求**  
   第 776 条：发现图纸或技术要求不合理的，应当及时通知定作人；因定作人怠于答复等原因造成承揽人损失的，应当赔偿。承揽人怠于通知的，就本可避免的损失自行承担。修改句给通知期、答复期和两种怠于的分担。禁止图纸标注“仅供参考”却作为验收依据。

4. **保管**  
   第 784 条：承揽人应当妥善保管定作人提供的材料以及完成的工作成果，因保管不善造成毁损、灭失的，应当承担赔偿责任。定作人未供主材时，本条仍覆盖已完成成果和定作人提供的样品／模具。

---

## 节点 5　格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

定作人制式采购文本、承揽人制式定制文本、订单背面条款，均可构成格式条款（第 496 条）。审查免责、签收即合格、放弃留置、解除不赔、最终解释权、管辖是否有显著提示。仅电子勾选不足（合同编通则解释第 10 条）。未提示的后果是相对方可主张不成为合同内容，不是本任务直接改判无效。

强制规范见硬闸 G。挂靠施工、违法分包建设：若文本实为工程，按节点 1.2 负触发，不在本技能写建筑法改道稿。

---

## 节点 6　违约、解除、争议解决

1. 逾期完成、质量不符、擅自换材、逾期协助、逾期受领、逾期付款必须分别有可执行后果。只有“依法承担违约责任”视为必须改。
2. 构成违约不等于当然解除。第 772 条未经同意转主要工作、第 778 条协助逾期，只点名法定解除路径，不在本任务作出已解除结论。
3. 第 787 条任意解除见硬闸 E，与违约解除分列。
4. 违约金避免“不得调整”或“按总价百分之三十必得”。
5. 争议解决：已有仲裁条款，不得改成“应向某法院起诉”并假装已选定诉讼；或裁或诉、机构不明：改成单一仲裁机构或单一法院连结点。定作一般不是建设工程专属管辖，也不是不动产专属管辖。
6. 微信已读不写成已经送达，除非合同把该渠道定为送达。
7. 单方送货单、验收单上后加的违约条款：标红旗，修改句禁止以单方文件变更本约。

## 节点 7　与买卖／加工清单的隔离

本类型改变放行结论的争点已由硬闸 A–G 覆盖。不再另设买卖式“单证／所有权保留／货交承运人／检验两段期间”专节，也不另设加工式“定作人供主材收料检验”专节。

- 文本误写买卖句：回硬闸 A 和硬闸 D.5 改掉。
- 文本误写来料收料主路径：回节点 1.2，必要时负触发 `加工合同·审查`。
- 文本只有“相关资料”而无成果技术资料和质量证明：回硬闸 F.1 补三件套，不套买卖单证解释清单。

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

对照已加载框架级文件和本方法硬闸，按六步逐段出句。

| 步 | 定作必须盯的点 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题名实（定作而非购销／加工／修理／施工／贴牌）；主体与许可；鉴于不写验收合格、放弃留置或技术参数 | 标题或主体修改句 |
| 交易条款 | 规格／图纸／封样附件；技术代表；承揽人供材品牌标准与检验；换材书面同意；主要／辅助工作；交付与验收；价款分列料工运；留置是否排除；风险按交付 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 772 解除；787 赔偿清算；781 修理重作减酬；IP 归属与双向担保；保密不得留存 | 可执行后果句 |
| 尾部 | 公章＋授权签字；骑缝；图纸／规格／封样附件及冲突适用顺序 | 生效与附件修改句 |
| 语言 | 正说加反说；价款含料；签收≠验收；交付≠终局合格；不得“仅供参考”“同等档次”“原则上”“尽快” | 替换空词的句子 |
| 常见问题 | 无规格放行、擅自换材、空白外协、签收吞没留置、解除不赔、货交承运人风险残留、无证特种设备 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（类型错误、无规格仍放行、违禁／无证、772 空白转包、签收终局合格并放弃留置、删除 787 或解除不赔）；
- `必须改`：可谈但签署前要落句（材料标准与换材、技术代表、验收期、IP 归属、报酬节点、交付前风险）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级预付款或个人无限连带且用户拒绝升级：停止“可以签署”建议。

## 版本冲突

正文、规格书、图纸、封样、技术协议、订单、聊天确认冲突时：

1. 并列 `D#` / `C#`，不选对用户有利的一版。
2. 修改句写明冲突项以哪一份为准，或删除冲突句。规格、材质牌号或数量冲突不得调和成“两边都对”。
3. 不得在意见里悄悄采用有利版本并称“合同已明确”。
