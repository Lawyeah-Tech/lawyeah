# 边界与路由

本技能只审查 **服务合同 / 广告制作合同** 的待签文本。中文展示名是「审查广告制作合同（服务合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 创意、设计稿、改稿轮次、提案中选，验收对象是方案作品 | `广告设计合同·审查`。不得删改稿条款后继续当制作审 |
| 委托他人设计而无广告成品加工 | `委托他人设计的服务合同·审查` |
| 文学艺术委托创作，不交付广告成片或物料 | `委托创作·审查` |
| 上刊、播出、曝光、CPT/CPM、监测报告 | `广告发布合同·审查` |
| 媒介排期、代理买档期、差价或佣金 | `广告代理合同·审查` |
| 代言许可、拍摄次数与肖像范围为主轴 | `广告代言服务类合同·审查` |
| 互联网投放、信息流买量 | `互联网广告类合同·审查` |
| 设计+制作+发布无法拆开的全案打包 | `广告合同（广义）·审查` 或引擎重新定性 |
| 仅印刷图文，无广告成品加工主张 | `印刷合同·审查` |
| 非广告用途的定作物 | `定作合同·审查` |
| 户外构筑物按施工图、强制标准和施工资质整案发包 | `工地建筑活动承包资质竣工验收→` |
| 咨询意见、不交付成片 | `咨询服务合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 留本任务起草并自审 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

制作正文里夹带一小段设计修改或媒介预订：设计或发布专条交接对应原子；成片/物料交付、确认稿、变更单、审片、按件价款、留置不扣素材条款可继续审。用户坚持本技能把设计、发布、代言或施工整案改完：`目标停止`。
