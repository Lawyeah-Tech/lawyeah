# 广告制作合同·起草

## 任务目标

在单一立场下，只起草 **服务合同 / 广告制作合同** 的待签文本，按已谈妥条件出己方稿，输出可编辑草稿、未决项；出稿后必须用本类型硬闸自审，输出风险表和修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文名必须是「审查广告制作合同（服务合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、待签文本签前审查、履约交底、争议文书、有效性保证、把设计稿/改稿轮次、媒介投放/CPT/CPM、代言许可或施工挂靠整案改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **成片 / 物料交付**：核心给付是把已确认脚本、设计终稿或素材包加工为可发布或可安装的成品（影视成片、音频母带、喷绘灯箱、展示道具等）并交付。必须写清介质、时长/画幅或材料规格、数量、交片日或到货/安装完成日。没有成片或物料交付闭环 → 必须改。货物到场不是安装合格；母带寄出不是审片合格。
2. **与设计切开**：输入须是广告主或设计方已书面确认的脚本、分镜头、设计终稿或封样。制作人原则上不重新决定广告主张、功效表述或忠告语。主轴是出创意、设计稿、改稿轮次或提案中选 → 负触发 `广告设计合同·审查`。夹带设计的，拆出设计条款，不得按设计合同的改稿轮次和源文件权属主路径改完整案。
3. **与发布切开**：制作完成并交付即主给付完成。上刊、播出、曝光、CPT/CPM、监测报告是发布合同的给付 → 负触发 `广告发布合同·审查`。制作按件计酬，不得按曝光量结算。媒介排期、差价采购 → `广告代理合同·审查`；互联网投放主轴 → `互联网广告类合同·审查`。
4. **确认稿起算 + 变更单**：脚本/设计终稿书面确认、预付款到账前不得起算工期。无确认脚本即开机 → 红线。现场改词、加拍、换材料必须当场签变更单；未签不得追加费用，也不得追究未改部分。广告主审片逾期的，后续节点顺延，不得把档期作废转嫁制作方。
5. **不得擅自加减功效断言 + 违法制作停笔**：后期不得增加疗效、收益率等断言，不得删除忠告语；法定审查类广告成片须与批准内容一致。为集资、违禁商品或无证明文件的违法广告提供制作 → 只告知，不改成可履行结构。用户坚持“改到能签仍做这些画面”：整体停止。
6. **风险转移、留置、权属与档期损失**：影视以交付母带并验收为风险转移；实物以安装验收合格为转移。逾期报酬可留置成品或物料，不得扣留广告主自有素材原件。成片中的摄影、音乐、字体、表演者权须写清；未约定时广告主不当然取得全部权利。档期或媒介空置损失仅限订约时可预见、有预订凭证的直接损失，并设上限。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签广告制作、成片承制、喷绘/灯箱制作正文，尚未签署，尚未成争，核心给付是按确认稿加工并交付成片或物料，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主轴是创意、设计稿、改稿轮次、提案中选 → `广告设计合同·审查`；一般委托设计 → `委托他人设计的服务合同·审查`；文学艺术委托创作而无广告成品加工 → `委托创作·审查`；
- 上刊、播出、曝光、CPT/CPM、监测报告为主给付 → `广告发布合同·审查`；
- 媒介排期、代理采购档期或差价 → `广告代理合同·审查`；
- 代言拍摄许可、肖像次数与内容范围为主轴 → `广告代言服务类合同·审查`；
- 互联网投放、信息流买量为主轴 → `互联网广告类合同·审查`；
- 设计+制作+发布无法拆开的全案打包 → `广告合同（广义）·审查` 或 本套导航的类型切开步骤；
- 仅印刷图文、无广告成品加工主张 → `印刷合同·审查`；非广告的定作物加工 → `定作合同·审查`；
- 户外构筑物达到建设工程施工标准、要按施工资质和强制标准整案审 → `工地建筑活动承包资质竣工验收→`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

挂靠施工资质、违法分包户外结构、伪造审查批文、集资或违禁广告制作：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（广告主侧或制作方侧择一）；相对方；全文及附件/确认脚本/设计终稿/色样/配乐清单版本；成品是成片还是实物物料；是否夹带设计或发布；开工条件是否含确认稿和预付款；变更单授权人；审片次数与签字主体；交付介质与安装验收是否分列；价款是按件还是 CPT/CPM；权属与代言许可覆盖；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的时长、单价、色差容许、交片日用 `【待填】`，不编造。

## 起草模式

本原子只承担本类型起草。待签评改转 `广告制作合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `广告制作合同·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 核心给付是把已确认脚本、设计终稿或素材包加工为可发布或可安装的成品并交付。必须写清介质、时长／画幅或材料规格、数量、交片日或到货／安装完成日。货物到场不是安装合格；母带寄出不是审片合格。
- 输入须是广告主或设计方已书面确认的脚本、分镜头、设计终稿或封样。制作人原则上不重新决定广告主张、功效表述或忠告语。
- 脚本／设计终稿书面确认、预付款到账前不得起算工期。现场改词、加拍、换材料必须当场签变更单。
- 按件计酬。影视以交付母带并验收为风险转移；实物以安装验收合格为转移。逾期报酬可留置成品或物料，不得扣留广告主自有素材原件。成片中的摄影、音乐、字体、表演者权须写清。
- 后期不得增加疗效、收益率等断言，不得删除忠告语；法定审查类成片须与批准内容一致。

### 附件必附

- 确认脚本、设计终稿、色样、配乐清单、材料封样、报价。无确认脚本不得起开机稿。

### 禁止出现

- 按曝光量、CPT／CPM 结算，或把上刊、播出、监测报告写成制作主给付。
- 无确认脚本即开机。
- 为集资、违禁商品或无证明文件的违法广告提供制作。
- 挂靠施工资质、违法分包户外结构、伪造审查批文。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`基本面.md` 中“归承揽”不得写成建设工程施工。`框架.md` 中“逾期不审视为合格”是约定拟制，不是法定自动验收；“档期损失”须受第 584 条可预见限制。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 留本任务起草并自审；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有广告制作文本；本任务只起草，评改待签文本转配对 ·审查 原子。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。设计、发布、代理、代言、互联网投放、印刷、定作、施工负触发。

### 2. 主体、制作资质与确认稿

签约名、履行名、付款名、发票名分列。广告制作经营资格、影视制作能力、户外安装施工或特种作业未核：字段停止。无确认脚本不得开机。

### 3. 成片 / 物料特定化与交付验收

介质、时长、分辨率或材料防火等级必须落到附件。到货初验与安装终验、粗剪/精剪/成片分列。

### 4. 变更单、审片顺延与开工条件

条件不成就不得起算工期。临时改剧本视为变更。

### 5. 对价、定金与档期损失

按件计酬。CPT/CPM 负触发发布。定金不得超过标的额百分之二十。档期损失须可预见、有凭证、有上限。

### 6. 广告合规、格式条款与强制规范

不得擅自加减功效断言。集资或违禁制作停笔。无核验引文则法律结论字段停止。

### 7. 权属、留置、风险转移与安全

未约定则广告主不当然取得全部权利。不得扣素材原件。人身损害及故意/重大过失不得免责。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把集资/违禁/无证制作、挂靠施工或“疗效保证画面”改成可履行结构。
- `字段停止`：法域、动态规则、制作/施工/广电许可、行政审查批文、代言许可覆盖未核验。
- `目标停止`：主目标已变为评改待签文本、履约交底、争议文书，或已锁他类。
