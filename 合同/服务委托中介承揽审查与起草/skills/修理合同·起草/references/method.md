# 审查方法（锁定 承揽合同 / 修理合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制定作新物规格书、加工来料定额、动产买卖货交承运人或施工挂靠节点。

定性校验：标题、核心给付与本类型一致才继续；明显是定作、加工、买卖、OEM 或施工则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、必然修好、对方必然接受或唯一必得修理费。

`search_law` 返回已失效《合同法》承揽章、《加工承揽合同条例》、《经济合同法》或其解释时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。定作、加工或买卖范本只证明是另一类型，不得当作本类型范本。

知识库纠正（不回写双文件）：

- `基本面.md` “法律通常支持修理人的法定留置权优先”：第 456 条是同一动产上留置权优先于已经设立的抵押权或质权，不是优先于查封。查封物送修：该负担字段停止，不得写成“留置当然打得过查封”。
- `框架.md` “中途停止只结算已发生工时及已拆封材料”：这是 787 损失范围的约定写法，不是法定穷尽清单。不得据此删掉“赔偿损失”，也不得据此写成无偿解除。
- `框架.md` “旧件通常归定作人”：一般修理物在民法典没有默认归属，必须约定。机动车维修：换下配件、总成应交托修方自行处理，修理厂回收须另约并抵减费用。
- `基本面.md` 适用场景含房屋防水补漏：局部修复既有房屋功能可留本类型；新建、拆改承重或进入施工许可范围 → 负触发项目承揽或施工原子。

## 节点 1　类型识别与单目录加载

### 1.1 修复既有物（硬闸）

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

本类型成立，须同时满足：

1. 标的物在缔约前已经存在，且可用名称、品牌、型号、序列号、发动机号、车架号或其他唯一标识码锁定。
2. 该物已经损坏或功能减损，工作内容是恢复原状、恢复特定功能或达到约定安全运行标准。
3. 对价对应修复行为及其成果，而不是交付一件新物的所有权。

| 文本写法 | 动作 |
| --- | --- |
| 写明某台在用设备/车辆/构件的故障现象，验收标准是恢复功能或安全运行 | 正触发，进入 1.2 |
| 只有“维修服务”“维保套餐”，不见既有物身份和故障 | 字段停止；修改句补身份与损坏现状。补不上则负触发引擎 |
| 正文是按图制造新机、新件、新品 | 不是修复既有物 → 1.2 切开 |
| 无故障，只做例行保养、更换滤芯、巡检 | 修理范围须剔除保养，或转 `面向消费者的服务类合同·审查` / 引擎 |

修改句：

「本合同标的为修复甲方已经所有或合法占有的【设备/车辆名称、品牌、型号、唯一标识码】。双方确认：该物于进场前已存在，当前故障为【待填】；乙方工作成果是使该物恢复【原状 / 约定功能 / 安全运行标准】，不是交付新物所有权。」

最强反方：相对方主张标题写“维修”即可覆盖新造或买卖。现有依据不支持用标题单独定性。

### 1.2 与定作 / 加工 / 买卖切开（硬闸）

必须切开后再加载，禁止两可时灌入两套知识。

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 已有特定物损坏，工作是把它修好 | 本类型 | 正触发 |
| 从无到有按图制作新物，材料主要由承揽人备办 | 定作 | 负触发 `定作合同·审查` |
| 定作人提供原材料，对方制成新物或改变形态后交付 | 加工 | 负触发 `加工合同·审查` |
| 移转通用物所有权换价款；“修理”只是安装或调试附带义务 | 动产买卖 | 负触发 `通用型号现货卖方组织生产买方不控制过程→` |
| 按品牌方规格贴牌批量生产 | OEM | 负触发 `定牌加工（OEM）合同·审查` |
| 新建构筑物、类似建筑工程的简易施工 | 项目承揽 | 负触发 `项目承揽合同·审查` |
| 施工许可范围内的建设工程 | 施工 | 负触发 `工地建筑活动承包资质竣工验收→` |
| 复制、印刷、测试测绘、检验鉴定 | 邻类承揽 | 负触发对应全 ID；P1 未装则 `unavailable` |

支持切开的规范（法律结论须运行时复核）：

- 第 770 条：承揽是完成工作、交付工作成果、支付报酬；修理是承揽的一种，与加工、定作并列，不是互相吸收。
- 第 595 条：买卖是转移标的物所有权换价款——新件买卖主轴走 `通用型号现货卖方组织生产买方不控制过程→`。
- 实务反例：加工与定作常按谁供主材区分；修理的判断轴是“既有损坏物是否被恢复”，不是谁供零件。承揽人提供更换件，并不把修理改成定作。

修理正文夹带更换件采购：新件所有权、验收可专条交接买卖原子；既有物修复、进场、旧件、787 留本任务。用户坚持整案按定作或买卖改完：`目标停止`。

### 1.3 加载协议

本技能已锁定 **承揽合同 / 修理合同**。只打开 `references/基本面.md` 与 `references/框架.md`。禁止读其他子目录，禁止为对照再开第二类。

### 1.4 以修代造 / 无资质 / 非法改装停笔

加载后或定性中出现：承修已报废机动车；利用配件拼装机动车；无许可修理电梯、锅炉、压力容器等特种设备；按约定做违反机动车登记或排放标准的非法改装；出借维修资质、挂靠收取管理费。

动作：

1. 交付告知：特种设备安全法第 2、18、22、23 条及条例第 16、17 条要求许可并书面告知监管部门；机动车维修管理规定第 22 条禁止承修报废车、禁止拼装、禁止擅自改装。可能因违反法律、行政法规强制性规定或违背公序良俗而无效（第 153、154 条）。不得改写成可履行的无资质或拼装结构。
2. 不写假许可路径、报废车“大修复驶”步骤或体外挂靠结算。
3. 风险表只保留识别依据和删除/转出口径。
4. 用户坚持“改到能签且仍做这些事”：整体停止。

部门规章或许可未核：字段停止，不宣告合同当然无效（解释第 16 条）。无许可仍要放行特种设备承修：红线。

## 节点 2　主体、资质与授权

### 2.1 主体表

建表：签约名、履行名、付款名、发票名、授权签字人。名称不一致不自动合并。送修方须是修理物所有权人或取得所有权人、管理人书面授权的占有人。共有、融资租赁出租人、抵押权人未闭合：该签署能力字段停止，不写成“可以盖章”。

口头“我们老板同意了”不得写成已授权。保险公司直付：报酬支付人与签约人分列，不自动把保险人写成合同当事人。

### 2.2 资质与主要工作

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 标的是电梯、锅炉、压力容器等，无许可或制造单位委托痕迹 | 字段停止；修改句要求许可/委托作为附件 | 可以承修；合同当然无效 |
| 电梯修理非制造单位且无其委托 | 红线补委托或换有许可且经制造单位委托的单位 | 普通机电维修公司即可修电梯 |
| 核心拆解、关键件修复转包第三人，无定作人书面同意 | 必须改。第 772 条：主要工作应交自己完成，未经同意定作人也可解除 | 转包不影响身份 |
| 只有营业执照含“维修” | 执照不等于特种设备许可或机动车维修经营资格 | 已具备全部资质 |

修改句：

「乙方确认其持有与本合同修理项目对应的有效许可或经营资格，并作为附件出示：【特种设备修理许可 / 电梯制造单位书面委托 / 机动车维修经营信息】。主要拆解、关键部件修复和总成装配由乙方以自己的设备、技术和劳力完成；未经甲方书面同意，不得将上述主要工作交第三人。辅助工作交第三人的，乙方就该第三人成果向甲方负责。」

## 节点 3　既有物身份、进场状态与修复目标

审查清单，缺一项则该字段不得写成已闭环：

1. 送修物名称、品牌、型号、唯一标识码。
2. 进场时外观、损坏部位、随机配件、已拆状态的书面确认，并约定影像留存。
3. 初步诊断与修理范围；是否包含例行保养，须单独勾选，默认不包含。
4. 合格标准：原厂技术标准 / 国家强制性安全标准 / 恢复约定功能。禁止只写“尽量修理”“视情况处理”。
5. 上门或送厂；运输费用及在途风险。

| 文本写法 | 动作 |
| --- | --- |
| “设备现状以进厂为准，甲方事后不得异议”且无确认单 | 必须改。口头或单方记载不得写成已共同确认 |
| 无序列号、无故障描述 | 必须补；补不上则既有物身份字段停止 |
| 验收以“签字领回”代替试运行 | 必须改：静态核对零件 + 约定负荷/路试后再签合格 |

修改句：

「双方应在拆解施工前共同签署《进场确认单》，载明送修物唯一标识码、外观、损坏部位、随机配件及已有拆痕，并拍摄编号照片作为附件。未经该确认，不得开始更换部件。合格以书面验收单为准；签收、付款或投入使用不当然构成验收，除非验收单已载明合格结论。」

最强反方：承修方主张“进厂即视为现状无争议”。现有依据不支持把单方收件写成共同确认。期间毁损适用第 784 条，进场状态是区分原损与二次损坏的事实前提。

## 节点 4　材料归属与不得更换不需要修理的零部件（硬闸）

支持依据：第 771、774、775 条；机动车维修时另核管理规定第 30 条。

分列四栏，缺一栏则该栏不得写成已明确：

| 栏 | 必须落到文本 |
| --- | --- |
| 谁供新件 | 定作人供 / 承揽人供 / 分项列明 |
| 新件规格 | 原厂件或同质件、零件编号、全新或翻新；承揽人供料须接受定作人检验 |
| 旧件归属 | 交还定作人，或作价由承揽人回收并抵减修理费 |
| 更换权限 | 仅更换进场确认及书面增项范围内的零部件 |

| 文本写法 | 动作 |
| --- | --- |
| “所需材料由乙方全权决定，旧件归厂方处理” | 红线拆开。机动车：换下配件应交托修方自行处理 |
| 允许使用翻新件、拆车件且无标识 | 必须改：分别标识原厂/同质/修复件，供定作人选择；禁止假冒伪劣 |
| 未写不得更换尚能使用的部件 | 必须补第 775 条第 2 款 |
| 承揽人供料却“定作人不得检验” | 必须改。第 774 条要求按约定选用并接受检验 |
| 定作人供件，承揽人可自行替换 | 必须改。不得擅自更换定作人提供的材料 |

修改句：

「更换件由【甲方提供 / 乙方采购】。乙方采购的，应使用【原厂零件编号 / 同质件】全新件，进场前交甲方检验；未经甲方书面同意，不得使用翻新件、拆车件。乙方不得擅自更换甲方提供的材料，不得更换不需要修理的零部件。拆下的旧件、报废件归甲方；乙方回收的，应在结算单列明抵减金额人民币【待填】元，并按危废或废油规则自行合法处置。施工中发现隐蔽故障需要增项的，须书面报价并经甲方确认后方可实施；擅自增加的项目和零件不予结算。」

最强反方：承修方主张“专业判断即可换件，旧件抵工时是行规”。现有依据不支持把行规写成已取得所有权，也不支持把未确认增项写成已可请求报酬。

## 节点 5　对价、检测费、交付与验收

### 5.1 价金构成

工时费与材料费分列。故障明确可用总价包干；原因不明须先检测再书面报价。禁止编造单价。未给出的数字写 `【待填】`。

| 文本写法 | 动作 |
| --- | --- |
| 只有“修理费若干”，不分工时与材料 | 必须改 |
| 拆解后发现无修理价值或费用超过预估，仍必须修完并付全款 | 红线。约定定作人有权停修，并单列已发生检测/拆解费上限 |
| “检测费无论是否承修均按全额修理费收取” | 必须改：停修时仅付事先书面列明的检测/拆解费，总额不超过人民币【待填】元 |
| 预付款写成定金且超过标的额 20% | 超过部分不产生定金效力（第 586 条）；无核验引文则该法律结论字段停止 |
| 支付与验收脱钩，领回即付清且不得异议 | 必须改：验收合格支付尾款（第 782 条：未约定时，交付工作成果时支付） |

修改句：

「费用由工时费人民币【待填】元与材料费（按经甲方确认的零件清单据实结算）构成。乙方应在拆解后【待填】日内提交书面报价；报价超过人民币【待填】元或判断无修理价值的，甲方有权书面通知停止修理。停止后，甲方仅支付事先书面列明的检测、拆解费用，总额不超过人民币【待填】元，已拆封且无法退货的材料按进价结算，其余预付款【待填】日内退还。尾款于书面验收合格后【待填】日内支付。」

### 5.2 期限、风险与质保

修理期间送修物及定作人提供材料的毁损、灭失，因保管不善由承揽人赔偿（第 784 条）。交付（送回或自取）后风险回归定作人，但质保期内同一故障除外。

质保必须覆盖：同一故障或同一部位因本次修理质量再次出现的，免费再修。禁止只写“依法承担质量责任”。

上门维修的现场安全、人身意外：只要求文本划清生产安全责任和投保义务，不在本任务做工伤整案。

## 节点 6　787、格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 定作人完成工作前的解除（硬闸）

条文：定作人在承揽人完成工作前可以随时解除合同，造成承揽人损失的，应当赔偿损失。

| 文本写法 | 动作 |
| --- | --- |
| “甲方不得以任何理由中途解除/停修” | 红线删除。与 787 冲突 |
| “甲方放弃第七百八十七条权利” | 红线。本任务不把放弃写成可放行；实务上存在“不得约定排除”的审查反例 |
| “甲方可随时解除且无需支付任何费用” | 必须改。解除后仍应赔偿损失 |
| 工作已完成或已交付后仍套“随时解除” | 现有依据不支持再走 787；质量问题走第 781 条 |
| 只写“双方协商解除” | 必须补通知、停工时点、已完工部分与材料清理 |

修改句：

「甲方在乙方完成约定修理工作前，可以书面通知解除本合同。解除后，甲方应赔偿乙方因此受到的损失，包括：截至解除通知到达时已发生且能提供工时记录的报酬、已拆封使用或已订购且无法退货的材料费，以及其他合理直接损失；各项金额以书面凭证为准，不得重复计算。乙方完成工作或交付修复成果后，甲方不得再依据本条解除，但不影响其依据质量条款或法律规定主张减酬、再修或赔偿。」

可退让：把“其他合理直接损失”收窄为 enumeration；不可退让：删除赔偿或写死不得解除。

最强反方：承修方主张已经备料开工，排除 787 才能覆盖成本。现有依据支持赔偿损失，不支持用排除条款代替赔偿。

### 6.2 格式条款

为重复使用而预先拟定、订立时未与对方协商。修理厂格式单不得仅以“这次没用过第二次”否认。依据示范文本制作，不当然排除格式条款。

审查：免责、限责、旧件归厂、排除 787、留置、管辖/仲裁等异常条款是否有足以引起注意的标识，以及是否按要求说明（第 496 条；解释第 10 条）。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在进厂单背面 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

提供方对其已尽提示或说明承担举证责任。

### 6.3 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的、是否仅行政管理、是否只规制履行行为（第 153 条；解释第 16 条）。禁止用已失效“效力性/管理性”口诀代替解释第 16 条。特种设备许可、机动车维修经营多为监管要求：未出示许可主要是监管后果，不得单独写成民事合同当然无效；无许可仍要承修特种设备或拼装报废车：不改写成有效履行。

## 节点 7　质量、保管、留置与争议

1. 工作成果不符合质量要求：定作人可合理选择再修、减少报酬、赔偿损失（第 781 条）。多次无法修复：约定可解除并处理已付款和旧件返还。只有“依法承担违约责任”视为必须改。
2. 二次损坏、零件丢失：回链进场确认单和 784 条，约定按重置价或约定单价赔偿，数字用 `【待填】`。
3. 逾期交付：按日违约金，并可约定替代设备租用费上限；不得写成按总价必得高额且不得调整。
4. 留置：未付报酬或材料费时，承揽人对完成的工作成果可留置或拒绝交付，当事人另有约定除外（第 783 条）。变价前：有约定履行期限从约定，未约定应给债务人六十日以上期限，鲜活易腐除外（第 453 条）。修改句不得把催告写成“三日后即可变卖”。同一动产上已有抵押或质权的，留置权人优先受偿（第 456 条）；不得写成优先于查封。
5. 构成违约不等于当然解除。法定解除只点名催告或目的不能实现，不在本任务作出已解除结论。
6. 争议解决：出现仲裁条款，不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核，修改句改成单一仲裁机构或单一法院连结点。不选定唯一法院充作法律意见。
7. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。

修改句（留置）：

「甲方逾期未支付到期修理费或经确认的材料费的，乙方对已完成的工作成果可以留置或拒绝交付。乙方行使变价权前，应书面催告甲方在不少于六十日的期限内履行；期限届满仍未履行的，方可依法折价、拍卖或变卖并就所得优先受偿。双方不得以三日或更短期限代替前款催告。乙方不得以留置为由毁损送修物或拒绝甲方取回与债权显失相当的可分附件。」
