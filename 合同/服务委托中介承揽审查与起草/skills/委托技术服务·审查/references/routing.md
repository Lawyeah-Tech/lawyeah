# 边界与路由

本技能只审查 **委托合同 / 技术服务合同** 的待签文本。中文展示名是「审查技术服务合同（委托合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开技术类合同/技术服务合同双文件，禁止把本任务做成 `或` 的换名副本。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 处理普通事务、费用由委托人预付、双方可随时任意解除，无特定技术问题 | `一般委托合同·审查`。不得把第 921、933 条当本类型默认主路径继续审 |
| 只提供可行性论证、技术预测、专题调查或分析评价，不保证动手解决问题 | `委托技术咨询·审查` |
| 技术类货架下的技术咨询 | `或` |
| 普通经营、管理咨询，无特定技术问题 | `咨询服务合同·审查` |
| 委托研发新技术、新产品、新工艺 | `委托技术开发合同·审查` |
| 技术类委托开发 / 技术开发 | `的method。` / `只审委托合同目录下的委托技术开发。用户或材料按技术类合同进入《技术开发合同》→` |
| 用户明确按技术类合同专章、与开发/转让/许可并列审查“技术服务合同” | `或` |
| 狭义技术服务、技术培训、技术中介 | `狭义技术服务培训中介→` / `指定学员做特定项目专业技术训练` / `技术类合同项下技术中介本约→` |
| 常规加工、定作、修理 | `加工合同·审查` / `定作合同·审查` / `修理合同·审查` |
| 常规测试、测绘或检验、鉴定 | `测试测绘合同·审查` / `检验鉴定合同·审查` |
| 房屋建筑或土木工程的勘察、设计、施工 | `工地建筑活动承包资质竣工验收→` |
| 驻场人员由甲方指挥、发工资社保，核心是人员租赁 | `用人单位。按人头派驻接受用工单位考勤奖惩中介发薪或自己与劳动者签劳动合同→` |
| 高额服务费无对应技术问题，实为融资或套取资金 | 本套导航的类型切开步骤 重新定性。不得按本类型改完付款路径 |
| 无文本、本类型条件已谈妥、要出己方稿 | `委托技术服务·起草` |
| 已签未争、只问进场/验收/付款留痕 | 本套导航的履约步骤 |
| 已成争 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

委托技术服务正文里夹带一笔已锁定规格的设备安装施工或常规修理附件：专条交接 `工地建筑活动承包资质竣工验收→` 或 `修理合同·审查` 审该笔标的；特定技术问题、费用负担、配合验收、成果归属可继续审。用户坚持本技能把一般委托、咨询、开发、承揽、施工或技术类同名整案改完：`目标停止`。
