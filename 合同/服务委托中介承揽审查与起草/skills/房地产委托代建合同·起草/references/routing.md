# 边界与路由

本技能只审查 **委托合同 / 房地产委托代建合同** 的待签、市场化房地产全过程开发管理、对价为代建管理费的文本。中文展示名是「审查房地产委托代建合同（委托合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或复制 `或`、`工地建筑活动承包资质竣工验收→` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 共同投资、共享利润、共担风险；代建方取得剩余收益并承担全部投资风险；固定套数分房作为对价 | `房地产合作开发联合拿地` |
| 土地使用权父级下的委托代建；土地一级开发管理为主轴 | `或` |
| 工程价款、竣工结算、承包范围、按图纸施工为主给付 | `工地建筑活动承包资质竣工验收→` |
| 名为土地一级开发，实为施工 | `名为一级开发实为施工·审查` |
| 政府投资、财政资金、使用单位三方、代建名录库、行政协议 | `政府代建合同·审查` |
| 标题或用户锁定品牌输出型商业代建产品包、险资／纾困操盘整包 | `商业代建合同·审查` |
| 资本方以债权回收、投资收益或现金流分配权为主轴 | `资本代建合同·审查` |
| 代建方入股项目公司、跟投、固定价退股 | `股权代建合同·审查` |
| 代建与贷款、配资、出借、固定利息联立 | `商业代建配资·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 留本任务起草并自审 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或对应专项领域。` 或对应专项领域 |
| 施工、合作开发或预售质量已立案 | 建设工程或房地产争议专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

房地产委托代建正文里夹带一小段品牌许可或资金监管：专章交接或分条改写；管理委托条款可继续审。用户坚持本技能把合作开发、施工、政府代建、股权跟投或配资整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
