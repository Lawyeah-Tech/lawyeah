# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的管理费、面积、工期；把已失效《合同法》、2004 年施工合同解释、2005 年土地使用权解释旧条号写入结论；保证预售或竣工备案一定办成；把合作开发、施工、政府／商业／资本／股权代建或配资文本当成已完成的本类型审查；写“无开发一级资质则代建合同当然无效”；写“代建方仅在故意或重大过失时负责”；写“赔偿不得超过管理费是法定上限”；把首笔管理费支付写成法定生效要件。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查房地产委托代建合同（委托合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、2004 年施工合同解释、2005 年土地使用权解释旧条号、1997 年未修正建筑法或 1999 年招标投标法单行本时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `委托合同`，子级 `房地产委托代建合同`。定性理由、易混切开结果（合作开发 / 施工 / 政府代建 / 商业代建 / 资本代建 / 股权代建 / 配资 / 土地使用权委托代建）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、土地权属、资金来源与文本版本

主体表：签约名、履行名、付款名、发票名、授权签字人、项目负责人。权源表：土地使用权或项目开发权归属；建设资金由谁落实；是否政府投资或必须招标。版本表：正文、管理目标责任书、资金需求计划、管理费支付节点表、品牌许可、资金监管、聊天确认；冲突并列。

## 5. 代建费切割、产权、管理界面与给付

对价是管理费还是共担共享／固定回报／分房；建设成本是否由委托方承担；产权是否始终归委托方；重大事项决定权与日常管理权是否切开；品牌许可是否独立；管理费构成与支付节点；资金共管。缺口标 `G#`。不输出施工竣工结算口径，不输出政府投资代建或股权跟投口径。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹。挂靠、违法分包、规避招标、全部建设垫资加固定回报不得写成可放行。强制规范只按第一百五十三条区分是否导致民事行为无效，不用失效口诀。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把利润分成直接写成“代建费”而不问是否共担风险。

## 9. 谈判与签署提醒

谈判顺序：先红线（实为合作开发或施工、全部垫资加固定回报、无限质量连带、规避招标），再必须改（资金共管、决定权界面、产权声明、管理费节点、品牌许可独立、解除清理），最后可优化。签署提醒：授权代表委派书须含开发管理权限、土地权属附件、资金需求计划、管理费支付节点表、品牌许可与资金监管（如有）。不指导倒签或把首笔管理费支付写成法定生效。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书或效力保证，也不是合作开发、施工、政府代建、股权跟投或配资安排。
