# 边界与路由

本技能只审查 **委托合同 / 委托技术开发合同** 的待签文本。中文展示名是「审查委托技术开发合同（委托合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或抄写 `只审委托合同目录下的委托技术开发。用户或材料按技术类合同进入《技术开发合同》→`、`的method。` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 用户、封面或材料目录指向技术类合同项下《技术开发合同》 | `只审委托合同目录下的委托技术开发。用户或材料按技术类合同进入《技术开发合同》→`。同名不同父级，不得用本原子代审 |
| 用户、封面或材料目录指向技术类合同项下《委托开发合同》 | `的method。`。同名不同父级，不得用本原子代审 |
| 双方分工参与设计、工艺、试验、试制 | `双方按约定计划和分工共同或分别承担设计工艺试验试制→` |
| 用户或材料锁定技术类合同项下软件委托开发 | `可运行软件或系统交付→`。委托合同父级下的软件/系统定制开发可留在本任务 |
| 只解决特定技术问题，不产出新方案 | `委托技术服务·审查`；用户锁定技术类父级则 `或` |
| 只提供意见，不交付研发成果 | `委托技术咨询·审查`；用户锁定技术类父级则 `或` |
| 处理一般事务，核心是对外代理或随时解除 | `一般委托合同·审查`。不得把任意解除当本类型默认 |
| 现成技术转让 | `或对应许可原子；` |
| 无文本、本类型条件已谈妥、要出己方稿 | 留本任务起草并自审 |
| 已签未争、只问拨款/验收/登记留痕 | 本套导航的履约步骤 |
| 已成争 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

委托技术开发正文里夹带一笔已锁定规格的现成模块采购或单纯安装调试：专条交接引擎或对应服务/买卖原子审该笔；开发范围、归属、技术风险、验收尾款条款可继续审。用户坚持本技能把技术类同名、合作开发、技术服务或一般委托整案改完：`目标停止`。
