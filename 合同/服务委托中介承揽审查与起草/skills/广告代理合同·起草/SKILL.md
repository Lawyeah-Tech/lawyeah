# 广告代理合同·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》委托章、行纪章及其解释，1994 年《广告法》同号旧义，《广告管理条例施行细则》，《广告发布登记管理规定》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只起草 **服务合同 / 广告代理合同** 的待签文本，按已谈妥条件出己方稿，输出可编辑草稿、未决项；出稿后必须用本类型硬闸自审，输出风险表和修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文名必须是「审查广告代理合同（服务合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、待签文本签前审查、履约交底、争议文书、有效性保证、把发布或行纪改完、把审核义务“一包了之”改成可履行。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **代理媒介采购**：核心给付是受托人就媒介资源办理招揽客户、销售档期、洽谈发布条件或按指令采购档期。必须先锁委托人是发布者还是广告主。一般代理收佣金，库存和刊播风险不转嫁。禁止只写“全权代理广告事务”而不列媒介清单。
2. **与发布切开**：代理不控制刊播开关，不对漏播承担发布者责任。一旦以自己名义向广告主承诺档期交付、保证“台里一定上”，或主给付是刊播本身 → 负触发 `广告发布合同·审查`。不得把漏播、监播不能、素材终审写成代理人的发布者责任。
3. **与行纪切开**：以自己名义为委托人从事媒介买卖，并对相对人直接享有权利、承担义务 → 负触发 `行纪合同·审查`。授权书宽于合同、以自己名义出具发布承诺且发布者不掌握客户，是行纪或转售红旗，不得按一般代理改完。
4. **权限拆分与档期确认**：对外权限拆成签约、收款、折扣三项；授权书与主合同必须一致。询价后须经发布者确认档期，再对外承诺。跳过确认直接锁档：必须改。
5. **媒介采购款不进代理私户**：广告主媒介费直付发布者或共管；代收设 T+N 并专款专用。全年预算或媒介费进入代理人个人卡、个人收款码或长期留存在代理人一般户：红线。佣金与媒介费分户。
6. **审核义务不可放弃**：发布者对任何订单保留最终审核和拒登权。承包费不得解释为买断审核权。不得承诺发布违法或未经审核广告。内容不符或证明文件不全，不得因“已承包”而提供代理或放行上刊。
7. **名代理实买断**：实质包下库存再销售的，库存和售不出风险必须写明由谁承担，或点名改签资源采购/转售，不要再用“代理”逃避库存风险。不得在本任务把买断改成可履行的“假代理”。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签广告代理或媒介销售代理正文，尚未签署，尚未成争，核心给付是代理媒介采购或销售档期，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主给付是刊播、上刊、漏播补偿、监播作为发布者义务 → `广告发布合同·审查`；
- 以自己名义买入媒介再转售，自担对广告主的交付义务 → `行纪合同·审查`；
- 主给付是创意设计交付 → `广告设计合同·审查`；
- 主给付是成片、物料制作 → `广告制作合同·审查`；
- 主给付是自然人/法人出镜推荐证明 → `广告代言服务类合同·审查`；
- 主给付是互联网平台投放系统、程序化购买接口本身，而不是媒体销售代理 → `互联网广告类合同·审查`；
- 标题“广告合同”但设计、制作、发布、代理混在一处无法拆出代理主轴 → `广告合同（广义）·审查` 或 本套导航的类型切开步骤；
- 仅报告媒介机会、促成签约，不处理销售或采购事务 → 本套导航的类型切开步骤 重新定性为中介，不得按代理任意解除和佣金改完；
- 概括处理非媒介事务、与广告经营无关的一般委托 → `一般委托合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问排期、回款、发票 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

承诺发布违法广告、承包后不再审核、把媒介费改入个人卡仍要放行：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（发布者侧或代理人侧择一；若委托人是广告主，先标反向采购并反转权利义务）；相对方；全文及附件/授权书/媒介清单/价目/订单样张版本；核心给付是代理媒介采购还是刊播/以自己名义买卖；独家或非独家；佣金或价差；收款账户；是否承包买断；审核和拒登权是否被放弃；广告经营资格痕迹；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的佣金比例、账户、档期、期限用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验委托定义与任意解除、行纪切开、广告主体定义、书面合同、经营资格、查验证明与不得代理违法内容、格式条款、定金上限；`search_practiced` 只补审查反例；`search_template` 只借栏目结构。广告发布或行纪范本只作负向切开。不虚构案件系统。

`search_law` 对上述法律结论为 required 级：不可用时不拒绝执行，只停止效力字段。返回已失效《合同法》委托/行纪章、1994 年《广告法》同号旧义、《广告发布登记管理规定》时记为噪声，不得写入 `L#`。


## 起草模式

本原子只承担本类型起草。待签评改转 `广告代理合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `广告代理合同·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 先锁委托人是发布者还是广告主。核心给付是受托人就媒介资源办理招揽客户、销售档期、洽谈发布条件或按指令采购档期。一般代理收佣金，库存和刊播风险不转嫁。
- 对外权限拆成签约、收款、折扣三项；授权书与主合同必须一致。询价后须经发布者确认档期，再对外承诺。
- 广告主媒介费直付发布者或共管；代收设 T+N 并专款专用。佣金与媒介费分户。
- 发布者对任何订单保留最终审核和拒登权。承包费不得解释为买断审核权。内容不符或证明文件不全，不得因“已承包”而提供代理或放行上刊。

### 附件必附

- 媒介清单、价目、费率表、授权书、订单样张。授权书有效期不长于主合同。缺媒介清单不得只写“全权代理广告事务”。

### 禁止出现

- 以自己名义向广告主承诺档期交付、保证“台里一定上”，或把漏播、监播不能、素材终审写成代理人的发布者责任。
- 以自己名义为委托人从事媒介买卖并对相对人直接享有权利、承担义务（那是行纪，不按本类型起稿）。
- 媒介费进入代理人个人卡、个人收款码或长期留存在代理人一般户。
- 承诺发布违法或未经审核广告；放弃审核仍上刊。
- 把实质包下库存再销售写成可履行的“假代理”。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`基本面.md` 中“自己代理、双方代理可撤销或无效”不得写成未经同意即当然无效。`框架.md` 中“承包即买断媒体”不得写成发布者已出卖审核义务和媒介许可主体身份。2021 年修正已删广告发布登记，不得把“出示发布登记证”写成现行必附件。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 留本任务起草并自审；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有广告代理文本；本任务只起草，评改待签文本转配对 ·审查 原子。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。发布、行纪、设计、制作、代言、互联网投放主轴、广义混同、中介、一般委托负触发。

### 2. 主体、资格与授权书

签约名、履行名、付款名、发票名分列。广告经营资格未核：字段停止。授权书与合同权限不一致：必须改。

### 3. 媒介清单、权限拆分与订单

列媒介、区域、行业、是否独家、可否分包。询价后发布者确认档期再对外承诺。

### 4. 资金与报酬

媒介费直付或共管；佣金与价差写清；暗返披露。

### 5. 审核、承包与强制规范

拒登权不可买断。名代理实买断点名改道。无核验引文则法律结论字段停止。

### 6. 格式条款

免责、自动续期、单方调价、管辖异常条款须提示说明。

### 7. 违约、解除与争议

截留款项、超权折扣、隐匿客户、介绍违法广告须有可执行后果。有偿委托解除须处理已锁档损失，不得写成无偿随时走人。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把媒介费改入个人卡、放弃审核仍发布违法或未审广告、把行纪/发布主轴按本类型放行。
- `字段停止`：法域、动态规则、广告经营资格、媒介权属、地方刊播许可未核验。
- `目标停止`：主目标已变为评改待签文本、履约交底、争议文书，或已锁发布/行纪/设计/制作/代言。
