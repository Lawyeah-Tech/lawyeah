# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受、必然不侵权或出口定牌当然豁免；编造未给出的单价、数量、交期、AQL；把已失效《合同法》或其解释、《加工承揽合同条例》写入结论；写“授权即转让”；写“工厂可自行销售带标尾货”；把普通加工或经销买卖当成已完成的本类型审查。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查定牌加工（OEM）合同（承揽合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、《加工承揽合同条例》、《经济合同法》、1993 年《产品质量法》第二十七条旧义、1993 年《反不正当竞争法》第九条虚假广告旧义时记噪声，不得写入 `L#`。2019 年《反不正当竞争法》第九条商业秘密正文本次未稳定命中前不得写入 `L#`。

## 3. 类型与加载路径

父级 `承揽合同`，子级 `定牌加工（OEM）合同`。定性理由、易混切开结果（加工、定作、经销、单独商标许可、买卖、修理、项目承揽、施工、委托开发）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准：出口定牌不写成当然豁免；授权不等于转让。假授权、仿冒、带标自销写停笔告知，不填可履行结构。

## 4. 主体、授权、商标权与文本版本

主体表：委托方／品牌方、加工方／承揽人、商标注册人（若不是签约委托方）、再许可链条、授权签字人。品牌权属：注册证号、类别、核定商品、有效期、再许可是否允许委托加工。版本表：正文、订单／PO、商标注册证、授权委托书、VI 手册、签样确认、包材核销表、聊天确认；冲突并列。未见注册证或再许可而要求贴牌：品牌字段停止。

## 5. 给付闭环

贴牌标的、商标图样与标注位置、规格／BOM／签样、材料由谁提供、交期、AQL／验收、价款（材料费＋加工费分列）、标识物领用与核销、尾货与废次品处理、模具／图纸权属、衍生工艺归属。缺口标 `G#`，不补商业数字。许可备案、海关知识产权备案写成义务和期限，不写成已经完成。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹；异常条款（单方免知识产权担保、签收即合格、解除不赔、最终解释权）。强制规范只按民法典第一百五十三条和合同编通则解释区分，不用失效“效力性／管理性”口诀。商标侵权、禁止擅自制造标识、主要工作亲自完成只作为修改理由，不代替修改句。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。禁止输出无修改句的色块表。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。禁止只给原则、不给句子。禁止写出“承揽人有权自行销售带有委托方商标的库存或尾货”“本授权构成商标转让”“出口定牌当然不侵权”。

## 9. 谈判与签署提醒

谈判顺序：先红线（假授权、反向仿牌、带标自销、影子工厂），再必须改（许可范围、备案对抗、签样／AQL、标识核销、772／787／留置），最后可优化（质保金比例、驻厂、第三方验货、价格调整触发）。签署提醒：商标注册证和授权书原件核对、VI／签样／核销表入附件、日期与用印。不指导倒签或补假授权。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书、效力保证，也不是普通加工本约、经销本约或注册商标许可本约审查。
