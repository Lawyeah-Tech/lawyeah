# 边界与路由

本技能只审查 **委托合同 / “商业代建 + 贷款配资” 合同**。

必须同时读出商业代建管理合意，以及配资（直接出借、协助引资或把融资到位写成对价）。标题叫“代建加配资”但没有任何资金条款，或主文件其实是纯品牌代建、政府代建、资本投资代建、股权换代建的，不得留在本技能做实体结论。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或标题含代建/配资、核心给付明显不是开发管理加资金支持 | 本套导航的类型切开步骤 |
| 品牌输出、VIS、去化率、代建费主导，无出借/引资/共管还本 | `商业代建合同·审查` |
| 仅房地产委托代建，融资只是背景一句且无可审资金条款 | `房地产委托代建合同·审查` |
| 政府投资、财政资金、委托人/代建人/使用人三方 | `政府代建合同·审查` |
| 保险资金、产业基金等资本方出资并实施或安排代建，审查重点是投资/收益权而非借款本息 | `资本代建合同·审查` |
| 以取得项目公司股权为对价换代建，股权是主给付 | `股权代建合同·审查` |
| 共同出地出资、共担亏损、分配开发利润 | `房地产合作开发联合拿地` |
| 施工总承包、按图施工、工程价款、竣工验收主导 | `工地建筑活动承包资质竣工验收→` |
| 无代建管理主给付，企业之间拆借本息 | `无代建管理主给付，只是企业拆借→` |
| 无代建，土地或在建工程抵押是主结构 | `抵押质押保证是主结构且无代建→` |
| 无代建，股权或应收账款出质是主结构 | `无代建，股权或应收账款出质是主结构` |
| 无代建，保证是主增信 | `无代建，保证是主增信` |
| 名为代建或顾问，固定回报，代建义务被抽空且无真实开发管理 | 若仍能读出代建外壳加配资，留本技能按明代建实借贷审；若连代建外壳都没有 → `用户坚持固定保本保收益且不担风险：不得化妆成股权代建放行；明显无代建服务则负触发` 或 `无代建管理主给付，只是企业拆借→` |
| 无文本、本类型条件已谈妥、要出己方稿 | 留本任务起草并自审 |
| 已签未争、问放款、共管划扣、节点验收 | 本套导航的履约步骤 |
| 已成争 | 合同争议领域或对应专项；不写停工通知书、还款诉状 |
| 用户只要利息、覆盖率或优先受偿额的终局数字 | 测算技能或人工精算；本技能只审条款 |
| C 端大众快检 | 只分流，不回改 |

附带保证、抵押、股权质押时：本技能只审对本约放行的影响，不展开保证、抵押或股权专项整案。深度保证文本转 `无代建，保证是主增信`；深度抵押借款转 `抵押质押保证是主结构且无代建→`。

同一文本既写“纯代建管理”又写“乙方必须到位配资”：按对价切开。资金支持构成签约原因或交叉违约 → 留本技能。资金条款被整段删除后只剩品牌代建 → 负触发 `商业代建合同·审查`。两可且无法判断：负触发引擎，不灌两套知识。

职业放贷、转贷、违法用途、禁止抵押财产包装、流质改直接接管、挂靠施工：停笔告知，不改写成可履行文本。

禁止在正文写半截 Skill ID。转出时必须写完整 ID，例如 `商业代建合同·审查`、`资本代建合同·审查`。
