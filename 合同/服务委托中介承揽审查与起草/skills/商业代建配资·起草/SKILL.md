# 商业代建配资·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《担保法》《物权法》及其解释当作现行规则。不得把年利率 24%/36% 两线、1991 年银行利率旧四倍当作现行上限。不得把《贷款通则》对企业间借贷的处罚或“三道红线”监管口径写成民事合同必然无效。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只起草 **委托合同 / “商业代建 + 贷款配资” 合同** 的待签文本：核心给付必须同时读出房地产开发管理委托，以及贷款配资（直接出借、协助引资或承诺到位）。按已谈妥条件出己方稿，输出可编辑草稿、未决项；出稿后必须用本类型硬闸自审，输出风险表和修改句。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「审查“商业代建 + 贷款配资” 合同（委托合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查、待签文本签前审查、履约交底、争议文书、合同或放款有效性保证、纯商业代建整案、政府/资本/股权代建整案、无代建主给付的拆借整案、施工总包整案、利息或货值覆盖率终局数字。

## 工作边界

正触发：已有可读待签文本要评改（审查模式），或本类型条件已谈妥要出己方稿（起草模式）；尚未签署，尚未成争；**必须同时满足**：

1. 一方受托处理报建、营造、营销等开发管理事务（商业代建，而非政府投资代建）。
2. 同一交易出现配资：自有资金出借、关联资方放款，或把融资到位写成对价/生效条件/交叉违约。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只有品牌输出、VIS、去化率、代建费和开发管理，没有出借、引资、共管还本或融资顾问对价 → `商业代建合同·审查`；
- 政府投资、财政资金、使用人三方代建 → `政府代建合同·审查`；
- 保险资金、产业基金等资本方出资找项目并实施代建，审查重点是投资回报而非借款本息 → `资本代建合同·审查`；
- 以取得项目公司股权为对价换代建，股权是主给付而非从担保 → `股权代建合同·审查`；
- 仅有房地产委托代建、配资只是背景一句且无可审查的资金条款 → `房地产委托代建合同·审查`；
- 共同出资、共担亏损、分配开发利润 → `房地产合作开发联合拿地`；
- 施工总承包、按图施工、工程价款结算主导 → `工地建筑活动承包资质竣工验收→`；
- 无代建管理主给付，只是企业拆借 → `无代建管理主给付，只是企业拆借→`；抵押/质押/保证是主结构且无代建 → `抵押质押保证是主结构且无代建→` / `无代建，股权或应收账款出质是主结构` / `无代建，保证是主增信`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问放款日、共管划扣、节点验收 → 本套导航的履约步骤；
- 已成争（催告还款、停工索赔、解除、立案仲裁）→ 合同争议或对应专项领域。

挂靠、违法分包、规避限购、包装职业放贷、套取金融机构贷款转贷、把查封地或违法建筑改成可抵押：只出告知，不改写成可履行结构。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成。每一闸必须给出修改句或明确转出口径，禁止只打红黄绿。

1. **配资定性**。标题写“代建”“开发管理”“融资顾问”不决定类型。必须读出资金角色并写入鉴于：直接出借 / 协助引资（尽力撮合）/ 承诺贷款到位（给付义务）。代建义务被抽空、对价只剩固定本息或“保底回报”：锁定为明代建实借贷，修改句补真实借款主合同，或转 `用户坚持固定保本保收益且不担风险：不得化妆成股权代建放行；明显无代建服务则负触发`/`无代建管理主给付，只是企业拆借→`（无代建主给付时负触发）。双实联立：代建与配资交叉引用、账目分列；借款无效不当然写成代建整约无效，只标目的落空与解除清理。
2. **利率与费用并表，运行时核验**。把书面利率、代建费相对市场的溢价、融资顾问费、通道费、咨询费、逾期利息、违约金放进同一张年化表。民间借贷路径：超过合同成立时一年期 LPR 四倍的部分改到上限内或标明不受司法保护。预扣利息、先扣顾问费再放款：按实际到账额计本金。出借人是持牌机构或法释〔2020〕27 号七类地方金融组织：利率法律结论停止，不套四倍。禁止默写 24%/36%/银行利率旧四倍。
3. **担保包：权利人一致，禁止暴力清算**。土地或在建工程抵押、项目公司股权质押、销售回款/收益权质押、实控人保证、差额补足必须逐项提取。抵押权人、质权人必须与真实出借人一致；登记在关联信托/基金名下的，补三方监管或委托关系，否则优先受偿结论停止。期前“违约即接管”“1 元或评估折扣收购全部股权”“停工后项目归乙方所有”：红线，改为折价或拍卖、变卖后优先受偿，多退少补。公司为他人担保或为股东/实控人担保：决议作附件。未完成登记不得写成已有担保物权。保证方式不明按一般保证，不得默写成连带。
4. **与 `商业代建合同·审查` 切开**。无配资/出借/引资对价 → 负触发该原子。本任务禁止输出品牌许可清单、VIS 手册、去化率考核、样板区标准作为主路径。禁止打开 `商业代建合同·审查` 或 `资本代建合同·审查` 的 method。禁止用资本代建的基金投资条款、股权代建的股权对价条款换皮完成本任务。

附加必落句（有事实则单列，无事实在缺口节说明）：

- **资金闭环**：提款前提（四证、抵押登记、人员进场）写成条件，不写成已经完成；销售回款进共管账户后的清偿顺序默认先约定本息、后代建管理费，冲突并列不选边。
- **协助 vs 承诺**：出现“确保贷款到位”“担保获批”“不到位视为乙方违约并按全额配资赔偿”时，必须改成：要么写成自有资金出借的给付义务和放款日，要么改回尽力撮合并删除结果罚则。
- **交叉违约**：代建延误是否构成配资展期事由；配资逾期是否赋予停工权或撤品牌权。停工/撤品牌必须有宽限期、通知和已完工作结算，不得写成单方毁标。
- **提前还款不当然解除代建**：修改句写明提前还清配资后，代建是否继续、管理费如何调整。
- **管理酬金与债务本息分列**：禁止用“综合收益”“融资顾问费”把利息藏进代建费。

必须有修改句。每个风险回链文本位置。禁止套用纯商业代建的品牌/VIS/去化节点。禁止套用施工合同无效公式。禁止复制 `商业代建合同·审查` 或 `资本代建合同·审查` method。

## 建立审查坐标

确认：使用者与授权；单方立场（委托方/借款人、代建方/出借人或引资人、第三方资方、保证人、拟签字的项目公司）；相对方；全文及借款/担保/现金流附件版本；配资金额与方式；代建费计价；担保财产；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的本金、费率、证号、期限用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law`（法律结论 required）：核验企业间生产经营借贷效力、职业放贷/转贷无效事由、利率上限与砍头息、流押/流质只能优先受偿、公司对外担保决议、委托任意解除、强制规范是否导致无效。
- `search_practiced`（optional）：补管理费冲抵利息、抵押权人与债权人分离、固定回报被认定为借贷等争点。返回“企业间借贷一律无效”“24%/银行利率旧四倍”“政府代建示范文本适用于商业配资”时记噪声。
- `search_template`（optional）：只借栏目结构。北京市政府投资代建示范文本、联合开发协议、纯融资顾问协议不得当本约规则。

不虚构案件系统。`search_law` 返回已失效《合同法》《担保法》《物权法》及其解释、1991 年借贷意见、2015 年 24%/36% 条文、民法通则/民法总则已被替代条文时记为噪声，不得写入 `L#`。


## 起草模式

本原子只承担本类型起草。待签评改转 `商业代建配资·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `商业代建配资·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`，不编造。

### 起草必写

- 核心给付同时写房地产开发管理委托，以及配资角色：直接出借 / 协助引资（尽力撮合）/ 承诺贷款到位（给付义务），写入鉴于。
- 代建与配资交叉引用、账目分列；借款无效不当然写成代建整约无效，只标目的落空与解除清理。
- 书面利率、代建费相对市场的溢价、融资顾问费、通道费、咨询费、逾期利息、违约金放进同一张年化表；预扣利息或先扣顾问费再放款，按实际到账额计本金。
- 担保包逐项提取；抵押权人、质权人必须与真实出借人一致；保证方式不明按一般保证。
- 提款前提（四证、抵押登记、人员进场）写成条件，不写成已经完成；销售回款进共管账户后的清偿顺序分列本息与代建管理费。
- “确保贷款到位”要么写成自有资金出借的给付义务和放款日，要么改回尽力撮合并删除结果罚则。
- 交叉违约写宽限期、通知和已完工作结算；提前还清配资后，代建是否继续、管理费如何调整必须写明。
- 管理酬金与债务本息分列。

### 附件必附

- 借款、担保、现金流附件。
- 公司为他人担保或为股东/实控人担保：决议作附件。
- 登记在关联信托/基金名下的：三方监管或委托关系。

### 禁止出现

- 期前“违约即接管”“1 元或评估折扣收购全部股权”“停工后项目归乙方所有”。
- 用“综合收益”“融资顾问费”把利息藏进代建费。
- 未完成登记写成已有担保物权；抵押权人与真实出借人不一致却写成已有优先受偿。
- 默写 24%/36%/银行利率旧四倍。
- 职业放贷、套取金融机构贷款转贷、把查封地或违法建筑改成可抵押、伪造倒签或假放款：只告知，不起可履行稿。
- 无配资的纯商业代建品牌/VIS/去化主路径，或无代建管理的纯拆借。

出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口，不代替节点。

0. 签署状态与成果分流
1. 类型识别与单目录加载（代建 + 配资同时成立；切开纯代建/政府/资本/股权代建/合作开发/施工/纯借款）
2. 主体、项目公司、土地使用权人、第三方资方
3. 配资定性：直接出借 / 协助引资 / 承诺到位；明代建实借贷 vs 双实联立
4. 利率与代建费、顾问费并表（运行时核验）
5. 担保包：权利人一致、公示、决议、禁止暴力清算
6. 资金闭环、回款顺序、交叉违约、任意解除与配资锁定
7. 效力红旗：职业放贷、转贷、非法金融、抽逃出资外观、监管规避
8. 按框架六步出修改句

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、补假放款或假抵押、把流质改成可直接接管、把禁止抵押财产改成可抵押、包装职业放贷或转贷、保证必然放款或利率必然合法。
- `字段停止`：法域、利率上限、配资角色、担保权利人、公司决议、土地使用权归属未核验。
- `目标停止`：主目标已变为评改待签文本、履约交底、停工/还款诉讼文书，或用户要把本约改成纯代建/纯借款以便绕开本类型硬闸。

项目公司唯一土地被设定“违约即平仓”且用户拒绝升级：停止“可以签署”建议。
