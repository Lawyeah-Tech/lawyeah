# 边界与路由

本技能只审查 **中介合同 / 技术转让中介合同** 的待签文本。中文展示名是「审查技术转让中介合同（中介合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 技术类合同项下概括技术中介；主给付是对第三人技术合同履行提供专门服务；同时撮合开发、许可、转让 | `技术类合同项下技术中介本约→`。P1：专业版未装则 `unavailable`，提示，不得用本技能硬套，不得打开其 method |
| 主文件是技术转让本约，或中介人自己让与技术 | `或对应许可原子；`。不得删掉让与条款后继续当中介审 |
| 单独成册的专利权转让 | `单独成册则` |
| 单独成册的专利申请权转让 | `单独成册的专利申请权转让` |
| 单独成册的技术秘密转让 | `单独成册的技术秘密转让` |
| 技术许可、专利实施许可、技术秘密使用许可本约 | `主文件是技术许可专利实施许可技术秘密使用许可→` / `专利实施许可合同·审查` / `技术秘密使用许可合同·审查` |
| 技术开发本约 | `只审委托合同目录下的委托技术开发。用户或材料按技术类合同进入《技术开发合同》→` |
| 技术咨询（可行性论证、分析预测，不绑促成） | `或` |
| 技术服务（解决特定技术问题） | `或` |
| 房屋买卖或租赁居间 | `房屋买卖_租赁中介合同·审查` |
| 求职、招聘、劳务介绍 | `职业中介合同·审查` |
| 婚介、相亲、征婚服务 | `婚姻中介合同·审查` |
| 代签技术转让本约、处理缔约事务、概括授权 | `一般委托合同·审查` |
| 以自己名义受让技术再转出 | `行纪合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `技术转让中介合同·起草` |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争，或用户要跳单诉讼策略 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

中介正文里夹带一小段本约价款、专利号或许可范围：专条交接对应本约原子；中介报酬、跳单、如实报告、保密条款可继续审。用户坚持本技能把技术转让本约、技术许可本约或 `技术类合同项下技术中介本约→` 整案改完：`目标停止`。
