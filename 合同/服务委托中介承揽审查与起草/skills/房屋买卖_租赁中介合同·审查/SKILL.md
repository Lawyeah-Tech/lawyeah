# 房屋买卖_租赁中介合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》居间章及其解释、已失效《城市房地产中介服务管理规定》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **中介合同 / 房屋买卖_租赁中介合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文名必须是「审查房屋买卖_租赁中介合同（中介合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、跳单诉讼策略、有效性保证、把买卖/租赁本约改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **中介不是委托/行纪**：核心给付是报告订约机会或提供媒介，通常不代签本约。出现代签本约、以自己名义买卖/出租 → 负触发 `一般委托合同·审查`、`行纪合同·审查` 或 `房地产销售代理合同·审查`。修改句须收回代签和以自己名义成交的权限。
2. **跳单（965）**：委托人接受服务后利用中介提供的信息绕开签约，仍应支付报酬。修改句写清“接受服务后绕开仍付费”的范围，并写入自行合法获知、成交对象非介绍对象的例外。不得把 965 写成中介必胜，也不得写成跳单约定当然无效。
3. **报酬节点**：写明促成与否、网签/过户/交房哪一步付费、未成是否退。禁止“签约即全额中介费且无论是否过户”。
4. **成交款不进中介私户**：买卖价款/租金进监管户、出卖人/出租人账户，或经纪机构银行客户交易结算资金专用存款账户。中介个人账户、个人收款码或公司一般户代收房款：红线。
5. **阴阳合同/协助骗贷/规避限购**：只告知，不改成可履行避税或套贷结构。用户坚持：整体停止。
6. **产调与如实报告（962）**：中介故意隐瞒抵押/查封/共有：委托人可拒付报酬并请求赔偿。不得把“中介已口头说没事”写成已产调。
7. **备案/人员资格**：经纪机构备案与承办人员资格未核则字段停止，不写“可以展业”。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签房屋买卖或租赁中介正文，尚未签署，尚未成争，核心给付是报告订约机会或提供媒介，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 求职介绍、劳务派遣中介 → `职业中介合同·审查`（P1；专业版未装则 `unavailable`）；
- 婚介、相亲服务 → `婚姻中介合同·审查`（P1；未装则 `unavailable`）；
- 技术转让、专利许可撮合 → `技术转让中介合同·审查`（P1；未装则 `unavailable`）；
- 代签买卖/租赁本约、处理缔约事务为主轴 → `一般委托合同·审查`；
- 以自己名义买入再转卖或出租 → `行纪合同·审查`；
- 房地产开发企业销售代理、全案代理销售 → `房地产销售代理合同·审查`；
- 主文件是二手房买卖本约 → `主文件是二手房买卖本约→`；不得删掉本约条款后继续当中介审；
- 主文件是房产租赁本约 → `主文件是房产租赁本约→`；不得把中介合同审成租赁本约；
- 无文本、本类型条件已谈妥、要出己方稿 → `房屋买卖_租赁中介合同·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁，或要跳单诉讼策略 → `或对应专项领域。` 或对应专项领域。

阴阳低价、协助骗贷、规避限购：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（委托人侧或中介机构侧择一）；相对方；全文及附件/带看确认单版本；核心给付是媒介还是代签；独家或非独家；报酬比例与节点；成交款账户；是否要求阴阳网签价；产调书面件；备案与人员资格痕迹；不可接受事项；法域、房屋所在地与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的佣金比例、账户、期限用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验中介定义与报酬、跳单 965、如实报告 962、格式条款、定金上限、经纪备案与禁止行为；`search_practiced` 只补审查反例；`search_template` 只借栏目结构。不虚构案件系统。

`search_law` 对上述法律结论为 required 级：不可用时不拒绝执行，只停止效力字段。返回已失效《合同法》居间章或其解释、已失效《城市房地产中介服务管理规定》时记为噪声，不得写入 `L#`。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`基本面.md` 中“中介人以委托人名义促成交易”不得当成已有代签权。`框架.md` 中“委托人可随时解除”不得写成无偿任意解除；“终止后 6–12 个月仍付佣金”是约定延展，须受 965 因果关系约束。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `房屋买卖_租赁中介合同·起草`；已签履约 → 本套导航履约步骤；已成争或跳单诉讼策略 → 合同争议。未签且目标是评改已有中介文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。委托代签、行纪、销售代理、本约、其他中介负触发。

### 2. 主体、备案与人员资格

签约名、履行名、付款名、发票名分列。备案与承办人员资格未核：字段停止。

### 3. 中介事务、产调与如实报告

写清报告机会还是媒介；书面产调；不得把口头说没事写成已产调。

### 4. 报酬节点与未成退费

禁止签约即全额且无论过户。

### 5. 成交款账户、定金与意向金

房款/租金不进中介私户。意向金转卖方前不具备定金罚则。

### 6. 跳单范围、格式条款与强制规范

965 写范围与例外。阴阳/套贷停笔。无核验引文则法律结论字段停止。

### 7. 违约、解除与争议

未促成不得请求报酬。不选定唯一法院充作意见。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把阴阳/骗贷/规避限购或房款进私户改成可履行结构。
- `字段停止`：法域、动态规则、备案、人员资格、地方资金监管未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书、跳单诉讼策略，或已锁他类。
