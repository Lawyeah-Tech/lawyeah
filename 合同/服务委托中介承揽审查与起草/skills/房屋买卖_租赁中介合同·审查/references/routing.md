# 边界与路由

本技能只审查 **中介合同 / 房屋买卖_租赁中介合同** 的待签文本。中文展示名是「审查房屋买卖_租赁中介合同（中介合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 求职、招聘、劳务介绍 | `职业中介合同·审查`。P1：专业版未装则 `unavailable`，提示，不得用本技能硬套 |
| 婚介、相亲、征婚服务 | `婚姻中介合同·审查`。P1；未装则 `unavailable` |
| 技术转让、专利许可撮合 | `技术转让中介合同·审查`。P1；未装则 `unavailable` |
| 代签买卖/租赁本约、处理缔约事务、概括授权 | `一般委托合同·审查` |
| 以自己名义买入再转卖或出租 | `行纪合同·审查` |
| 房地产开发企业销售代理、全案代理销售 | `房地产销售代理合同·审查` |
| 主文件是二手房（存量房）买卖本约 | `主文件是二手房买卖本约→`。不得删掉本约条款后继续当中介审 |
| 主文件是房产租赁本约 | `主文件是房产租赁本约→`。不得把中介合同审成租赁本约 |
| 无文本、本类型条件已谈妥、要出己方稿 | `房屋买卖_租赁中介合同·起草` |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争，或用户要跳单诉讼策略 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

中介正文里夹带一小段本约价款或租期：专条交接对应本约原子；中介报酬、跳单、产调、成交款账户条款可继续审。用户坚持本技能把买卖/租赁本约或委托/行纪整案改完：`目标停止`。
