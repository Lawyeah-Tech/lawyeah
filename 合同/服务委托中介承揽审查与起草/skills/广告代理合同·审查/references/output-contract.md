# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的佣金、账户、档期、期限；把已失效《合同法》委托章或行纪章写入结论；把 1994 年《广告法》同号旧义写成现行审核条款；把漏播写成代理人的发布者责任；把以自己名义买卖媒介当成已完成的本类型审查；把媒介费改入代理私户；把审核义务改成可买断；把口头“台里一定上”写成已锁档。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查广告代理合同（服务合同）」。先写委托人是发布者还是广告主。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》委托/行纪章、1994 年《广告法》同号旧义、《广告发布登记管理规定》时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `服务合同`，子级 `广告代理合同`。定性理由、易混切开结果（发布、行纪、设计、制作、代言、互联网投放、广义混同、中介、一般委托）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、资格、授权与文本版本

主体表：签约名、履行名、付款名、发票名、授权签字人。资格表：广告经营者经营范围或广播电台/电视台/报刊专门广告机构痕迹。授权表：签约、收款、折扣三项是否分列；授权书有效期是否长于主合同。版本表：正文、授权书、媒介清单、价目、订单样张、资金监管协议、聊天确认；冲突并列。未核资格：该签署能力字段停止。

## 5. 媒介采购闭环

媒介清单、区域、行业、独家或非独家、可否分包；价格权限与底价特批；询价→确认档期→签约→素材审核→上刊；佣金或价差基数；媒介费账户与佣金账户；暗返披露。缺口标 `G#`。不输出发布合同的漏播补偿主路径，也不输出行纪人对相对人直接担责的主路径。

## 6. 审核义务、格式条款与强制规范

发布者拒登权是否被放弃；承包是否被写成买断审核。是否构成格式条款。强制规范只按第 153 条和解释第 16 条区分，不用失效口诀。介绍违法广告、无资质代理、媒介费进私户只保留识别与停笔。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把框架里的日万分之五写成法定违约金。

## 9. 谈判与签署提醒

谈判顺序：先红线（发布/行纪错位、媒介费进私户、放弃审核、承诺发布未审或违法广告、名代理实买断拒改），再必须改（权限拆分、档期确认、暗返披露、授权书一致、解除与已锁档清理），最后可优化。签署提醒：授权委托书入附件且有效期不长于主合同；媒介清单、价目、订单样张、资金监管协议齐套；到期书面通知相对媒体或客户。不指导倒签或补假资格。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书或效力保证，也不是广告发布或行纪审查。
