# 边界与路由

本技能只审查 **服务合同 / 广告代理合同** 的待签文本。中文展示名是「审查广告代理合同（服务合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 主给付是刊播、上刊、漏播补偿、以发布者身份向广告主交付档期 | `广告发布合同·审查`。不得删掉刊播条款后继续当代理审 |
| 以自己名义买入媒介再转售，对相对人直接享权利、担义务 | `行纪合同·审查`。不得按一般代理佣金改完 |
| 创意、平面或脚本设计交付 | `广告设计合同·审查` |
| 成片、物料、拍摄制作 | `广告制作合同·审查` |
| 出镜推荐、证明商品或服务 | `广告代言服务类合同·审查` |
| 互联网平台投放系统、程序化接口、信息流刊位本身 | `互联网广告类合同·审查`。广告主委托代理人去采购互联网媒介的，代理条款可留在本技能 |
| 设计、制作、发布、代理混在一份“广告合同”且无法拆出代理主轴 | `广告合同（广义）·审查`；或回引擎重新定性 |
| 仅报告媒介机会、促成签约，不处理销售或采购事务 | 本套导航的类型切开步骤 按中介定性。不得套用本技能任意解除和价差条款 |
| 与媒介采购无关的概括委托 | `一般委托合同·审查` |
| 只提供意见、不保证促成交易或成交档期 | `咨询服务合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `广告代理合同·起草` |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

代理正文里夹带一小段发布订单或设计制作：专条交接对应原子；媒介清单、授权、佣金、资金、审核拒登可继续审。用户坚持本技能把发布、行纪或制作整案改完：`目标停止`。
