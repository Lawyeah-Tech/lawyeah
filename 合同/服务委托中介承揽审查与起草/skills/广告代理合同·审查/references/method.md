# 审查方法（锁定 服务合同 / 广告代理合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制广告发布的漏播补偿/监播主路径、行纪费用自负与对第三人直接担责主路径、房屋中介跳单/产调、施工挂靠节点。

定性校验：标题、核心给付与本类型一致才继续；刊播交付、以自己名义买卖媒介、设计制作代言或中介明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受或唯一必得佣金。

`search_law` 返回已失效《合同法》委托章或行纪章及其解释、1994 年《广告法》同号旧义、《广告管理条例施行细则》、《广告发布登记管理规定》、已失效《互联网广告管理暂行办法》时记为噪声，不得写入 `L#`。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。广告发布委托合同、行纪或商品独家代理范本只证明是另一类型，不得当作本类型范本。

知识库纠正（不回写双文件）：

- `基本面.md` “自己代理、双方代理损害委托人利益的，可撤销或无效”：第 168 条是禁止，但被代理人同意或追认可除外。不得写成未经同意即当然无效；也不得写成同意后仍当然无效。
- `基本面.md` “违反广告法第 32 条”：2021 修正第 32 条约束的是广告主应委托有合法经营资格的经营者、发布者。不得把已删除的广告发布登记证写成现行必附件。广播电台、电视台、报刊出版单位从事发布业务的，另核第 29 条专门机构，不在本任务写成“必须持有发布登记证”。
- `框架.md` “承包即买断媒体”：发布者不能出卖法定审核义务和媒介许可主体身份。承包只及于经营指标。
- `框架.md` 日万分之五：约定违约金，不是法定利率。数字用 `【待填】`。
- 1994 年《广告法》第 34 条是药品等发布前行政审查的旧号，2021 修正后同号旧义不得写入 `L#`。承接登记、查验证明、内容不符不得代理：运行时用 2021 修正本再核对应条；本窗已核验的同旨规则是《互联网广告管理办法》第 14 条。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须先锁**委托人是谁**：

| 委托人 | 本任务动作 |
| --- | --- |
| 广告发布者（本类主形态） | 代理人销售或招揽其媒介档期；权利义务按发布者委托审查 |
| 广告主（反向采购） | 仍可留在本类型，但权利义务相反：代理人按指令采购媒介，不得套用“发布者收佣、代理人卖库存”模板 |
| 无法判断 | 字段停止；修改句要求第一条写明委托人身份和媒介权属 |

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 受托人就媒介资源招揽客户、销售或采购档期、洽谈发布条件，收佣金或约定价差；不控制刊播开关 | 本类型 | 正触发 |
| 主给付是刊播、上刊、漏播补偿、监播作为发布者义务；或以自己名义向广告主保证档期交付 | 广告发布 | 负触发 `广告发布合同·审查` |
| 以自己名义买入媒介再转售，对相对人直接享权利、担义务 | 行纪 | 负触发 `行纪合同·审查` |
| 创意、平面、脚本设计交付 | 广告设计 | 负触发 `广告设计合同·审查` |
| 成片、物料制作 | 广告制作 | 负触发 `广告制作合同·审查` |
| 出镜推荐、证明 | 广告代言 | 负触发 `广告代言服务类合同·审查` |
| 互联网平台投放系统或程序化接口本身 | 互联网广告类 | 负触发 `互联网广告类合同·审查` |
| 设计/制作/发布/代理无法拆出代理主轴 | 广告合同（广义） | 负触发 `广告合同（广义）·审查` 或引擎 |
| 仅报告媒介机会、促成签约 | 中介 | 负触发引擎重新定性 |
| 与媒介无关的概括处理事务 | 一般委托 | 负触发 `一般委托合同·审查` |

支持切开的规范（法律结论须运行时复核）：

- 第 919 条：委托是处理委托人事务。
- 第 951、958 条：行纪是以自己名义从事贸易；行纪人对该合同直接享有权利、承担义务。
- 广告法 2021 修正第 2 条：广告经营者接受委托提供设计、制作、**代理**服务；广告发布者是为广告主或广告主委托的经营者**发布**广告。
- 广告法第 30 条：广告活动应当依法订立书面合同。

### 1.2 加载协议（硬闸）

本技能已锁定 **服务合同 / 广告代理合同**。只打开 `references/基本面.md` 与 `references/框架.md`。禁止读其他子目录，禁止为对照再开第二类。

### 1.3 代理媒介采购（硬闸）

| 文本写法 | 本任务动作 | 修改句方向 |
| --- | --- | --- |
| 乙方按甲方媒介清单招揽客户或按指令采购档期，收佣金，库存和刊播风险不转嫁 | 正触发，留下本类型 | 首部写明“广告代理（委托处理媒介销售/采购事务），不构成发布或行纪” |
| 只写“全权代理甲方一切广告事务”而无媒介清单 | 必须改 | 列出媒介、区域、行业、是否独家、可否分包 |
| 广告主被写成甲方，但正文按发布者收佣模板写 | 必须改或字段停止 | 第一条锁定委托人是广告主还是发布者，并反转付款与交付 |

修改句：

「本合同为广告代理（委托）合同。甲方是【媒介发布者 / 广告主】，乙方是广告经营者。乙方受托办理的事务限于附件一媒介清单范围内的招揽客户、销售档期、洽谈发布条件或按甲方书面指令采购档期，不控制刊播开关，不以自己名义向相对人承诺档期交付，也不以自己名义买入媒介再转售。」

最强反方：相对方主张“代理”已包含发布或转售。修改句必须收回刊播承诺和自买自卖权限。用户坚持保留发布或行纪主轴：负触发，不填本类型十节实体结论。

### 1.4 与发布切开（硬闸）

| 文本写法 | 本任务动作 |
| --- | --- |
| 乙方保证“台里一定上”、对漏播按刊例赔偿、自备监播作为发布者义务 | 负触发 `广告发布合同·审查`，或红线删除后若主轴仍是刊播则转出 |
| 乙方以自己名义向广告主出具发布承诺，发布者不掌握客户 | 负触发发布或行纪；不得按代理改完 |
| 成交后，发布合同文本、素材审核、上刊仍按发布者流程 | 正触发可保留；衔接条款必须写清 |

修改句：

「乙方成交后，发布合同文本、素材审核和上刊仍按甲方作为发布者的流程执行。乙方不得以自己名义向广告主出具档期交付承诺或漏播赔偿承诺。漏播、错播的发布者责任不因本合同转移给乙方，但因乙方越权承诺或未按甲方确认档期对外签约造成的损失，由乙方赔偿。」

不得把发布合同的监播不能、套播、竞品隔离主路径写入本任务默认修改句。

### 1.5 与行纪切开（硬闸）

| 文本写法 | 本任务动作 |
| --- | --- |
| 乙方以自己名义与广告主订立媒介买卖合同，自担收款和交付 | 负触发 `行纪合同·审查` |
| 授权书写“全权以乙方名义采购/销售任何媒介”且宽于主合同 | 必须改：授权书与合同权限一致；越权后的内部追偿写清 |
| 第 925 条式：以自己名义签约但第三人知道代理关系 | 可留在委托框架，但必须写明披露义务和是否直接约束委托人；不得默认为行纪 |

修改句：

「乙方对外应以甲方名义，或出示与本合同权限一致的授权委托书后签约。未经甲方书面确认，乙方不得以自己名义买入、转售或以自己为发布方向广告主收取媒介费。授权书的代理事项、权限和期限不得宽于本合同；授权书与本合同冲突的，以本合同较窄权限为准，且乙方应立即收回或换发授权书。」

最强反方：第三人善意信赖授权书。现有依据支持越权未经追认对被代理人不发生效力（第 171 条），但表见代理是否成立本任务不预判。修改句只能收窄授权书，不能保证对外一定无约束。

### 1.6 承包买断与中介切开

| 文本写法 | 动作 |
| --- | --- |
| 代理人包下档期再销售，库存风险未写 | 必须改：写明售不出由谁承担；或点名改签资源采购/转售，不要再用“代理”逃避库存 |
| 仅报告媒介机会、两边拿佣不披露 | 负触发中介定性；本任务不按委托任意解除改完 |
| 挂靠、出借广告经营资格、资金体外循环换管理费 | 只告知，不改写成可履行结构；用户坚持则整体停止 |

## 节点 2　主体、资格与授权书

### 2.1 主体表

建表：签约名、履行名、付款名、发票名、授权签字人。名称不一致不自动合并。发布者须实际拥有或有权销售相应媒介；权属未闭合：该签署能力字段停止，不写成“可以盖章”。

口头“我们台长同意了”不得写成已授权。媒体或终端客户不是本合同当然当事人。

共同代理同一媒介：对发布者连带，除非约定分区、分品类排他（第 932 条）。

个人代理可能涉及劳动或劳务伪装：只标红旗，不在本任务认定劳动关系。

### 2.2 广告经营资格（硬闸配套）

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 无营业执照、经营范围看不到广告经营或相关服务 | 字段停止；修改句要求作为附件 | 可以展业 |
| 用户要求出示“广告发布登记证”才允许签约 | 不得把已删除的发布登记写成现行必附件；广播电台/电视台/报刊另核第 29 条专门机构 | 必须持有发布登记证 |
| 只有一张过期广告经营许可证复印件 | 字段停止待核 2021 修正后的登记安排 | 许可证有效故合同有效 |

修改句：

「本合同签署前，乙方应向甲方出示并作为附件：营业执照及载明广告经营或广告代理相关服务的经营范围。甲方如为广播电台、电视台或报刊出版单位，应书面确认已设专门广告业务机构。未核验前，任何一方不得主张对方已具备展业与签署条件。本条不把已废止的广告发布登记证件当作生效条件。」

广告法第 32 条未核则不得把“无资格即合同当然无效”写成现行法结论（解释第 16 条）。本任务只停止“可以展业”。

### 2.3 授权书与主合同一致

授权事项、权限、期限单独出具。对外权限必须拆成签约、收款、折扣三项。有效期不长于主合同；到期应书面通知相对媒体或客户。

## 节点 3　媒介清单、权限与订单机制

### 3.1 媒介采购事务须可核验

审查清单，缺一项则该字段不得写成已闭环：

1. 可销售或可采购的媒介名称、位置、档期量级、刊例或结算价附件。
2. 区域、行业、是否独家、可否分包。
3. 是否含设计、制作、监测、差旅；“代理费已含一切”必须拆开。
4. 最低成交价、折扣审批、低于底价的书面特批。
5. 是否允许加价转售、差价归属。

禁止只写“提供全案广告代理”而无媒介和订单标准。

### 3.2 询价后确认档期再对外承诺（硬闸）

支持依据：第 924 条报告委托事务；框架下单确认链。按照委托人指示处理的对应条号运行时复核后再写入 `L#`。

| 文本写法 | 动作 |
| --- | --- |
| 乙方询价后可直接对外锁档、锁价 | 必须改 |
| 仅微信口头下单 | 必须改：书面订单或系统留痕 |
| 框架管原则、每笔投放以订单为准 | 可保留，订单确认方式要写清 |

修改句：

「每笔投放按“询价→甲方书面确认档期、价格和素材审核结论→签约或下单→上刊”执行。未经甲方确认，乙方对外作出的档期、折扣或赠播承诺对甲方不发生效力，由此产生的锁档损失和客户索赔由乙方承担。订单确认方式为【电子邮件 / 加盖印章 / 双方指定系统】，仅微信聊天不构成确认，除非事后【待填】日内补书面确认。」

### 3.3 转委托

委托事务应亲自处理。转委托须委托人同意，否则代理人对转受托人行为负责（第 923、169 条）。媒体执行刊播不视为转委托。

## 节点 4　资金与报酬

### 4.1 媒介采购款不进代理私户（硬闸）

| 文本写法 | 动作 |
| --- | --- |
| 全年预算、媒介费转入代理人个人账户、微信/支付宝个人码 | 红线删除 |
| 长期留存在代理人一般结算户，无 T+N | 红线；改为直付发布者或共管，代收不超过【待填】个工作日 |
| 大额直付发布者，佣金单独结算 | 可保留 |

修改句：

「广告主应支付的媒介采购款仅可转入甲方指定账户或双方共管账户。禁止转入乙方人员个人账户、个人收款码。乙方代收的，应在到账后【待填】个工作日内全额转入甲方账户，逾期按未转金额每日【待填】支付违约金，甲方并可解除独家。佣金与媒介费分户收付，乙方不得以代收媒介费抵扣佣金。」

用户坚持保留私户代收或全年预算打入个人卡：整体停止，不改成“加收据即可放行”。

### 4.2 佣金、价差与暗返

支持依据：第 928、921 条；广告法第 5 条诚实信用、公平竞争。

| 文本写法 | 动作 |
| --- | --- |
| 既收委托人佣金又吃媒体暗返且不披露 | 必须改：每笔书面报告，未披露不得主张该笔报酬 |
| 价差模式未写刊例与结算价 | 必须改，防止对外高开、对内低报 |
| 报酬与必要费用混写 | 必须改。费用预付或垫付偿还（第 921 条）与报酬分列 |

修改句：

「乙方报酬为【净媒介费的待填% / 固定服务费且不拿差价】。刊例价、代理结算价和差价归属以附件价目为准。乙方因本业务从媒体、广告主或任何第三方取得的返点、暗返、搭赠或价差，应在【待填】个工作日内书面报告甲方；未披露的，甲方可扣减等额报酬并有权解除。禁止既向甲方收取佣金又隐瞒向对方收取的利益。」

### 4.3 定金

必须使用“定金”二字才讨论罚则。约定或推算超过主合同标的额百分之二十：超过部分不产生定金效力（第 586 条）。无核验引文不得把 20% 写成现行法结论。

## 节点 5　审核义务、承包与客户归属

### 5.1 审核义务不可放弃（硬闸）

支持依据：广告法 2021 修正第 4、5、30 条；《互联网广告管理办法》第 14 条（查验证明、核对内容，内容不符或证明不全不得提供代理，发布者不得发布）。广告法 2021 对应承接审核条号被 1994 同号旧义占位的，运行时再核后再写 `L#`。

| 文本写法 | 动作 |
| --- | --- |
| “承包后甲方不再审核，乙方保证合法即可上刊” | 红线删除。承包只及于经营指标 |
| 乙方可承诺发布未审或依法应审未审的广告 | 红线。权限项必须为否 |
| 乙方收集证明文件，甲方仍核对并有权拒登 | 可保留 |

修改句：

「甲方对任何订单保留最终审核和拒登权。乙方应向客户收集证明文件并随订单提交，甲方仍须核对。对内容不符、证明文件不全或依法应经广告审查机关审查而未取得批准的广告，乙方不得提供代理，甲方不得发布。承包金、销售任务或独家授权均不得解释为买断或放弃该项审核义务。」

药品、医疗器械、保健食品等发布前审查：已核验《互联网广告管理办法》第 7 条。代理人揽来此类广告而未附批准文件：红线停刊，不改成“先上后补”。

### 5.2 客户归属与报告

代理人处理事务取得的发布合同、预收款、客户名单，应归发布者或按约定交割（第 927 条）。解除后一定期限内成交是否仍计佣，须写明利用乙方开发客户的范围，并保留委托人自行合法获知例外。不竞争范围不得扩到全行业无期限。

周/月报：客户、排期、回款、投诉。承包模式也要报送。

### 5.3 利益冲突

同时代理竞品，或既代理广告主又代理媒体：书面披露并取得豁免（第 168 条）。未经同意的自己代理、双方代理，不得写成已有效约束双方。

## 节点 6　格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 格式条款

为重复使用而预先拟定、订立时未与对方协商。依据示范文本制作，不当然排除格式条款。

审查：佣金、独家、免责、自动续期、单方调价、管辖/仲裁等异常条款是否有足以引起注意的标识，以及是否按要求说明（第 496 条；解释第 10 条）。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在附件 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

提供方对其已尽提示或说明承担举证责任。

### 6.2 强制规范

违反法律、行政法规强制性规定不一律无效（第 153 条；解释第 16 条）。禁止用已失效“效力性/管理性”口诀。无资质代理、放弃审核、介绍违法广告、媒介费进个人卡：不改写成有效履行。人身损害及故意/重大过失财产损失免责无效（第 506 条）。

## 节点 7　违约、解除与争议

1. 截留款项、超权折扣、隐匿客户、介绍违法广告、不披露利益冲突：可约定解除和赔偿。只有“依法承担违约责任”视为必须改。
2. 构成违约不等于当然解除。法定解除路径只点名催告或目的不能实现，不在本任务作出已解除结论。
3. 违约金不是必得金额；不在本任务做第 585 条精算。修改句避免“不得调整”或“按总价 30% 必得”。
4. 第 933 条：委托双方可随时解除。有偿委托解除方应赔偿直接损失和合同履行后可以获得的利益，除非不可归责。须约定通知期；已成交未执行订单继续履行；已锁档损失分担；承包剩余期限补偿公式用 `【待填】`。不得写成“随时解除且无需付费”，也不得删除法定任意解除权。
5. 第 928 条：因不可归责于受托人事由解除或事务不能完成的，应支付相应报酬，另有约定除外。
6. 争议解决：出现仲裁条款，不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核，修改句改成单一仲裁机构或单一法院连结点。发布者所在地便于控制媒介证据，可作连结点建议，不选定唯一法院充作法律意见。
7. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。

修改句：

「任何一方解除本合同，应提前【待填】日书面通知。已成交但未执行的订单继续履行至该档期结束。有偿委托下，解除方应赔偿对方因此发生的直接损失和本合同履行后可以获得的利益，但因对方违约或不可归责于解除方的事由除外。承包期内因甲方原因解除的，双方按附件公式结算剩余期限补偿；因乙方截留款项、超权折扣、隐匿客户或介绍违法广告解除的，乙方无权请求该补偿。」

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

| 步 | 动作 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题用广告代理/媒介销售代理；承包、一般代理、中介型在标题或第一条标明；承包买断应改名；主体全称与资格；鉴于不写销售任务和佣金 | 标题或主体修改句 |
| 交易条款 | 媒介清单；权限三项；询价后确认档期；佣金或价差；资金账户；报告 | 闭环修改句；缺数字用 `【待填】` |

| 语言 | 正说加反说；盯死全权代理、承包即买断、代理费已含一切、尽力拿下档期、报酬 vs 价差 | 替换空词的句子 |
| 常见问题 | 钱进代理账；授权书宽于合同；名代理实买断后不再审核 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（发布/行纪主轴、媒介费进私户、放弃审核、承诺发布未审或违法广告、倒签、名代理实买断拒改）；
- `必须改`：可谈但签署前要落句（权限拆分、档期确认、暗返、授权书一致、解除清理）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级预付款进入个人卡且用户拒绝升级：停止“可以签署”建议。
