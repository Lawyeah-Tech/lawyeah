# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的报酬、预付额、金额上限、期限；把已失效《合同法》委托章写入结论；把费用沉默写成行纪自担；把未约定报酬写成商事当然有偿；把“双方放弃任意解除权且解除无效”写成可放行；把隐名效果一律写成已直接约束委托人；把人身专属或违法事务改成可履行结构；把行纪/中介/咨询/承揽当成已完成的本类型审查。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查一般委托合同（委托合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》委托章或其解释、已失效《关于对外贸易代理制的暂行规定》时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `委托合同`，子级 `一般委托合同`。定性理由、易混切开结果（行纪、中介、咨询、承揽、房地产销售代理、诉讼律师服务）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准：第 933 条补空缺条号；转委托按第 923 条区分同意/紧急；无偿解除赔偿限于解除时间不当的直接损失。

## 4. 主体、资质与文本版本

主体表：签约名、履行名、付款名、发票名、授权签字人、共同受托人。资格表：诉讼/审计/报关等执业许可痕迹。版本表：正文、授权委托书、权限清单、费用预付单、聊天确认；冲突并列。未核执业资质：该事务能力字段停止。

## 5. 事务给付、权限、费用、转委托与隐名条件

核心给付是否处理委托人事务；对外名义；权限是否列举不动产/大额资金；费用是否预付；报酬有无及是否有偿；转委托同意机制与选任责任；共同受托是否连带；隐名时披露与第三人选择权是否按第 925、926 条写条件。缺口标 `G#`。不输出行纪介入权、中介跳单或咨询固定回报主路径。

## 6. 任意解除、格式条款与强制规范

第 933 条随时解除及有偿/无偿赔偿公式；是否出现“放弃解除且解除无效”；是否构成格式条款；空白授权、弃权解除等异常条款是否加黑提示。强制规范只按第 153 条和解释第 16 条区分，不用失效口诀。人身专属/暴力催收/违法事务只保留识别与停笔。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把框架里的实务周期写成法定期限。不得输出“双方放弃任意解除权且解除无效”。

## 9. 谈判与签署提醒

谈判顺序：先红线（类型错位、空白授权、弃权解除无效句、隐名一律直接约束、人身专属或违法事务），再必须改（权限列举、费用预付、转委托同意、共同连带、933 赔偿计算、授权书四要素、报告与财产移交），最后可优化。签署提醒：双方签字盖章；授权委托书、权限清单、费用预付单入附件。不指导倒签或补假授权。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书或效力保证，也不是行纪、中介、咨询或承揽审查。
