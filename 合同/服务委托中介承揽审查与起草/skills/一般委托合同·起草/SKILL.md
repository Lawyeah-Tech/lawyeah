# 一般委托合同·起草

## 任务目标

在单一立场下，只起草 **委托合同 / 一般委托合同** 的待签文本，按已谈妥条件出己方稿，输出可编辑草稿、未决项；出稿后必须用本类型硬闸自审，输出风险表和修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文名必须是「审查一般委托合同（委托合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、待签文本签前审查、履约交底、争议文书、有效性保证、把行纪/中介/咨询/房销代理/诉讼律师服务/承揽整案改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **处理事务 ≠ 行纪 ≠ 中介 ≠ 咨询意见 ≠ 承揽成果**：核心给付是受托人处理委托人事务，通常以委托人名义（或隐名但效果归委托）。自己名义做贸易 → 负触发 `行纪合同·审查`。只撮合、自己不成交一方 → 负触发 `房屋买卖_租赁中介合同·审查`。只出意见不处理事务 → 负触发 `咨询服务合同·审查` 或 `或`。必须交付工作成果 → 承揽原子（如 `加工合同·审查`）或回 本套导航的类型切开步骤。授权代签房屋买卖本约仍是委托，但房屋本约条款转 `主文件是二手房买卖本约→` 或 `或对应买卖原子；`。修改句须写明事务边界、对外名义和效果归属，并收回贸易自营、只撮合或只出意见的措辞。
2. **任意解除（第 933 条）**：委托人或者受托人可以随时解除委托合同。除不可归责于该当事人的事由外，无偿委托的解除方应当赔偿因解除时间不当造成的直接损失；有偿委托的解除方应当赔偿对方的直接损失和合同履行后可以获得的利益。修改句可约定通知期和赔偿计算。**不得写成“双方放弃任意解除权且解除无效”**。
3. **费用默认委托人预付（第 921 条）**：与行纪“费用由行纪人负担”相反。沉默不得写成受托人自担。垫付必要费用应偿还并付利息。未约定报酬：走第 510、511 条补充或交易习惯核验，**不编造商事有偿推定**。
4. **亲自处理与转委托（第 923、932 条）**：转委托须委托人同意或紧急为维护委托人利益。经同意或追认的，受托人仅就第三人的选任及其对第三人的指示负责。未经同意（紧急除外）的，受托人对转委托第三人的行为负责。两个以上受托人共同处理事务的，对委托人承担连带责任。
5. **权限范围**：授权事项、期限、可否处分不动产或大额资金必须列举。授权委托书缺姓名或名称、事项、权限、期限或签名盖章：必须改。空白授权（“处理一切事务”且无金额/不动产勾选）：红线。暴力催收、违法事务、人身专属事项（结婚登记、收养、遗嘱）：停笔。
6. **隐名代理（第 925、926 条）**：以自己名义对外订约时，须写清第三人订立时是否知道代理关系、披露义务和第三人选择权。禁止把效果一律写成已直接约束委托人而不写披露条件。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签委托正文，尚未签署，尚未成争，核心给付是处理委托人事务，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 以自己名义从事买入、卖出、寄售并收取贸易报酬 → `行纪合同·审查`；
- 只报告订约机会或提供媒介，自己不成交一方 → `房屋买卖_租赁中介合同·审查` 或其他中介原子；不得删撮合条款后硬套本技能；
- 只出调研报告、管理建议等意见，不对外处理事务 → `咨询服务合同·审查`；技术项目可行性、工艺评价、FTO → `或` 或 `委托技术咨询·审查`；
- 必须交付加工、定作、修理等物化或可验收工作成果 → 对应承揽原子（如 `加工合同·审查`）或回引擎；
- 房地产开发企业销售代理、全案代理销售 → `房地产销售代理合同·审查`；
- 诉讼出庭、阅卷、风险代理费为主轴的律师服务专项 → 回 本套导航的类型切开步骤，不得按一般事务委托改完；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

人身专属事项、暴力催收、违法事务：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（委托人侧或受托人侧择一）；相对方；全文及附件/授权委托书版本；对外以谁的名义；事务范围与期限；可否处分不动产或大额资金；有偿或无偿及报酬数字；费用是否预付；转委托是否允许；共同受托人人数；隐名时第三人是否可能知情；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的报酬、预付额、金额上限、期限用 `【待填】`，不编造。

## 起草模式

本原子只承担本类型起草。待签评改转 `一般委托合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `一般委托合同·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`，不编造。

### 起草必写

- 核心给付是受托人处理委托人事务；写明事务边界、对外名义和效果归属。
- 任意解除按第 933 条：双方可以随时解除；无偿委托的解除方赔偿因解除时间不当造成的直接损失；有偿委托的解除方赔偿直接损失和合同履行后可以获得的利益。可约定通知期和赔偿计算。
- 费用默认委托人预付（第 921 条）；垫付必要费用应偿还并付利息。未约定报酬走第 510、511 条补充或交易习惯核验，不编造商事有偿推定。
- 转委托须委托人同意或紧急为维护委托人利益；经同意或追认的，受托人仅就第三人的选任及其对第三人的指示负责；未经同意（紧急除外）的，受托人对转委托第三人的行为负责。两个以上受托人共同处理事务的，对委托人承担连带责任。
- 授权事项、期限、可否处分不动产或大额资金必须列举；授权委托书具备姓名或名称、事项、权限、期限和签名盖章。
- 以自己名义对外订约时，写清第三人订立时是否知道代理关系、披露义务和第三人选择权（第 925、926 条）。

### 附件必附

- 授权委托书（姓名或名称、事项、权限、期限、签名盖章）。
- 诉讼、审计、报关等所需执业资质痕迹（事务涉及则附）。

### 禁止出现

- “双方放弃任意解除权且解除无效”。
- 空白授权（“处理一切事务”且无金额/不动产勾选）。
- 把效果一律写成已直接约束委托人而不写披露条件。
- 自己名义做贸易、只撮合自己不成交一方、只出意见不处理事务、必须交付工作成果：负触发行纪/中介/咨询/承揽，不在本任务出稿。
- 暴力催收、违法事务、人身专属事项（结婚登记、收养、遗嘱）：只告知，不起可履行稿。

出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 留本任务起草并自审；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有一般委托文本；本任务只起草，评改待签文本转配对 ·审查 原子。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。行纪贸易、中介撮合、咨询意见、承揽成果、房销代理、诉讼律师服务负触发。

### 2. 主体、资质与共同委托

签约名、履行名、付款名、发票名分列。诉讼、审计、报关等资质未核：字段停止。共同处理事务写连带。

### 3. 权限与授权委托书

事项、期限、不动产/大额资金必须列举。空白授权红线。

### 4. 亲自处理、转委托与报告

转委托同意机制和选任责任。报告周期与结项报告。

### 5. 费用预付与报酬

费用默认委托人预付。报酬有无分开写。未约定报酬不推定有偿。

### 6. 隐名代理、格式条款与强制规范

925/926 披露条件。无核验引文则法律结论字段停止。

### 7. 任意解除、过错责任与争议

933 赔偿公式；禁止弃权无效句。有偿过错/无偿故意或重大过失。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把人身专属/暴力催收/违法事务改成可履行结构、坚持“放弃任意解除权且解除无效”、坚持空白授权对外处分不动产或大额资金。
- `字段停止`：法域、动态规则、执业资质、第三人是否知情、未约定报酬的交易习惯未核验。
- `目标停止`：主目标已变为评改待签文本、履约交底、争议文书，或已锁他类。
