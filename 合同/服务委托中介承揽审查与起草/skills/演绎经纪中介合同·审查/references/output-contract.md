# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的分成、期限、金额；把已失效《合同法》居间章写入结论；把经纪写成买断人身；把口头说已授权写成人身权已归公司；把未核许可证写成可以展业；把代言本约或许可本约当成已完成的本类型审查；把第 933 条写成无偿任意解除。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查演绎经纪中介合同（中介合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》居间章或其解释、1997 年《营业性演出管理条例》、1994 年《广告法》时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `中介合同`，子级 `演绎经纪中介合同`。定性理由、易混切开结果（买断艺人、广告代言、著作权许可/转让、委托创作、劳动合同、个人劳务、金融经纪、其他中介）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、许可证、未成年人与文本版本

主体表：签约名、履行名、收款名、发票名、授权签字人、工作室与艺人个人。资格表：营业性演出许可证痕迹、专职演出经纪人员资格。未成年人表：年龄档、法定代理人签字。版本表：正文、授权书、费用清单、反劣迹协议、聊天确认；冲突并列。未核许可证或未成年人未追认：该签署能力字段停止。

## 5. 经纪事务、佣金对账与授权范围

核心给付是否仅为报告机会、媒介与包装，而非买断人身；是否夹带代言本约或许可本约；独家或项目代理；分成比例、税前或税后、扣除项、结算周期、原始合同与凭证核对权；重大代言是否须本人书面同意。缺口标 `G#`。不输出代言审查或许可审查的主路径。

## 6. 人身条款、格式条款与强制规范

婚育限制、期限过长人身绑定、永久授权、天价违约金。是否构成格式条款及提示说明。强制规范只按第 153 条和解释第 16、17 条区分，不用失效口诀。阴阳片酬、规避审批只保留识别与停笔。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把框架里的 3:7 / 5:5、5–8 年写成法源。

## 9. 谈判与签署提醒

谈判顺序：先红线（买断人身、婚育禁锢、代言/许可错位、无对账先收后分拒改、倒签），再必须改（佣金扣除项与对账、许可证附件、监护人签字、重大代言书面同意、观察期解除、永久授权改有期限），最后可优化。签署提醒：机构公章 + 艺人亲笔签名；未成年人加法定代理人；许可证与资格证、授权书、费用清单、反劣迹协议入附件。不指导倒签或补假许可证。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书、效力保证，也不是代言本约或著作权许可/转让审查。
