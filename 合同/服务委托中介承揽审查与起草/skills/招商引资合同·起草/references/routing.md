# 边界与路由

本技能只审查 **招商引资合同 / 招商引资合同**。

必须同时读出：投资方到该辖区投资落地；政府方或依法授权主体提供依法可兑现的政策支持、要素保障或便利条件。标题叫“投资协议/合作协议/招商合同”但核心给付其实是出让交地、代建管理或特许权经营的，不得留在本技能做实体结论。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或标题招商、核心给付明显不是投资落地加依法可兑现支持 | 本套导航的类型切开步骤 |
| 主文件是《国有土地使用权出让合同》，或核心是出让金、交地、建设用地使用权登记 | `切开。送审主文件是出让合同，或审查重点是出让金交地规划条件土地登记→负触发该原子。本技能禁止打开或复制其method，禁止把本约改成可签署的出让文本，禁止输出出让金分期交地标准土地登记作为本类型主路径。`；专业版未收录该 P1 时输出 `unavailable`，不得硬套本技能改成出让文本 |
| 集体建设用地使用权出让 | `集体建设用地使用权出让` |
| 土地使用权项下委托代建 | `或` |
| 政府或授权机构委托代建财政资金非经营性项目，对价是代建费/建设管理 | `政府代建合同·审查` |
| 商业或房地产委托代建 | `房地产委托代建合同·审查` 或 `商业代建合同·审查` |
| 公共产品供给 + 特许权/PPP，使用者付费或特许经营授权 | 本套导航的类型切开步骤 重新定性；不得用本技能改特许经营履行结构 |
| 与非出让人签订、核心是锁定地块条件以便后续招拍挂 | `或`；联合勾地 → `或` |
| 房地产合作开发、联合拿地 | `房地产合作开发联合拿地` 或 `或` |
| 无文本、本类型条件已谈妥、要出己方稿 | 留本任务起草并自审 |
| 已签未争、问兑现、供地协助进度、奖补拨付 | 本套导航的履约步骤 |
| 已成争 | 合同争议领域，或行政复议与行政诉讼专项；不写起诉状、复议申请书 |
| C 端大众快检 | 只分流，不回改 |

同一文本既写“投资落地、政策支持”又夹带出让合同栏目或代建管理费、概算控制：按核心给付切开。出让金+交地主导 → `切开。送审主文件是出让合同，或审查重点是出让金交地规划条件土地登记→负触发该原子。本技能禁止打开或复制其method，禁止把本约改成可签署的出让文本，禁止输出出让金分期交地标准土地登记作为本类型主路径。`。建设管理委托主导 → `或` 或 `政府代建合同·审查`。投资落地+依法可兑现支持仍是主轴、出让或代建只是后续另签安排 → 留本技能，并写明必须另签、本约不得替代。

两可且无法判断：负触发引擎，不灌两套知识。

规避招拍挂、未供先用、固定回报或回购本息、以政府信用融资保证：停笔告知，不改写成可履行文本。

禁止在正文写半截 Skill ID。转出时必须写完整 ID，例如 `切开。送审主文件是出让合同，或审查重点是出让金交地规划条件土地登记→负触发该原子。本技能禁止打开或复制其method，禁止把本约改成可签署的出让文本，禁止输出出让金分期交地标准土地登记作为本类型主路径。`、`或`、`政府代建合同·审查`。
