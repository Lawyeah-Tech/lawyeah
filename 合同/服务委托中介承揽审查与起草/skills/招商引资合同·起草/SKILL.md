# 招商引资合同·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、2015 年行政诉讼法解释当作现行规则。不得把写进协议的税收返还、低价供地写成一律无效或一律可强制履行。不得把招商文本里的用地承诺写成已经取得建设用地使用权。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只起草 **招商引资合同 / 招商引资合同** 的待签文本：核心给付是投资方投入资金、项目并落地经营，政府方或依法授权主体提供依法可兑现的政策支持、要素保障和便利条件。按已谈妥条件出己方稿，输出可编辑草稿、未决项；出稿后必须用本类型硬闸自审，输出风险表和修改句。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「审查招商引资合同（招商引资合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查、待签文本签前审查、履约交底、争议文书、有效性或必然可兑现保证、把本约改成可强制实际履行的出让合同或代建合同、特许经营/PPP 整案、勾地整案、隐性债务或固定回报包装成可履行结构。

## 工作边界

正触发：已有可读待签文本要评改（审查模式），或本类型条件已谈妥要出己方稿（起草模式）；尚未签署，尚未成争；核心给付是到辖区投资落地，对价是依法可兑现的产业支持、要素协助或财政奖补，而不是出让金交地、建设管理委托或特许权经营。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主文件是《国有土地使用权出让合同》，或核心给付是出让人交地、受让人付出让金并办理建设用地使用权登记 → `切开。送审主文件是出让合同，或审查重点是出让金交地规划条件土地登记→负触发该原子。本技能禁止打开或复制其method，禁止把本约改成可签署的出让文本，禁止输出出让金分期交地标准土地登记作为本类型主路径。`；
- 核心给付是政府或授权机构把财政资金投资项目的建设管理职责委托给代建人，或土地使用权项下委托代建 → `政府代建合同·审查` 或 `或`；
- 核心给付是公共产品供给和特许权，适用《基础设施和公用事业特许经营管理办法》（2024） → 本套导航的类型切开步骤 重新定性，不得用本技能改成特许经营履行结构；
- 与非出让人签订、核心是锁定地块条件以便后续招拍挂的勾地安排 → `或` 或 `或`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问兑现节点、供地进度、奖补拨付 → 本套导航的履约步骤；
- 已成争（催告兑现、解除、索赔、复议、诉讼、仲裁）→ 合同争议或行政复议与行政诉讼专项领域。

规避招拍挂、未供先用、以招商名义包装固定回报或政府隐性债务、以政府信用为投资方融资提供保证：只出告知，不改写成可履行结构。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成。每一闸必须给出修改句或明确转出口径，禁止只打红黄绿。

1. **政府承诺效力分层**。无法律、行政法规依据或超越职权的税收返还、低价供地、固定回报，**不当然一律无效**；常见后果是不能强制实际履行、被清理或改为协助依法申请。地方留成范围内、有预算和规范性文件依据的奖补，不得一刀切写成无效。换届、区划调整、机构或人员更替不得作为不履行**依法作出的政策承诺和依法订立合同**的理由；越权承诺不适用“换届也必须兑现”口径。修改句把越权条款降级为“协助依法申请”，并写未获批时的延期、减投资或无损解除，禁止写成“保证获批、保证兑现”。
2. **税收优惠合法性**。只能承诺协助依法享受法定优惠。约定减免、先征后返、定额包税、擅自退税：红线。地方各级人民政府擅自作出的减税、免税决定无效，税务机关不得执行。修改句删除减免税款条款，改为协助按法律、行政法规申报优惠；地方留成奖补须另有预算和规范性文件依据，写清测算口径、兑现条件和审批路径。
3. **土地优惠合法性**。只能承诺依法供地、协助报批。禁止约定指定地块按某单价成交、流拍后协议出让、未拍即定。工业、商业、旅游、娱乐和商品住宅等经营性用地以及同一宗地有两个以上意向用地者，应当招标、拍卖或挂牌。招商文本里的用地承诺不能替代出让程序，也不能使投资方取得建设用地使用权。交付占有不等于取得使用权。
4. **与出让 `切开。送审主文件是出让合同，或审查重点是出让金交地规划条件土地登记→负触发该原子。本技能禁止打开或复制其method，禁止把本约改成可签署的出让文本，禁止输出出让金分期交地标准土地登记作为本类型主路径。` 切开**。送审主文件是出让合同，或审查重点是出让金、交地、规划条件、土地登记 → 负触发该原子。本技能禁止打开或复制其 method，禁止把本约改成可签署的出让文本，禁止输出出让金分期、交地标准、土地登记作为本类型主路径。
5. **与代建 `或`／`政府代建合同·审查` 切开**。核心给付是建设管理委托、代建费、概算控制、国库支付建设资金 → 负触发对应原子。禁止打开或复制其 method，禁止把招商文本改成可履行代建或垫资回购。
6. **行政协议识别与争议路径**。行政机关为实现行政管理或公共服务目标、与投资方协商订立、具有行政法上权利义务内容的，按行政协议审查争议路径。平台公司单独签约通常不是行政协议，其承诺的税费、土地、规划对政府方无当然拘束。行政协议约定仲裁的，除法律、行政法规或我国缔结参加的国际条约另有规定外，仲裁条款无效；不得改成“应向某法院起诉”并假装已选定诉讼。民事招商才可约定仲裁或诉讼。

附加必落句（有事实则单列，无事实在缺口节说明）：

- **主体适格**：政府方写全机关全称并核职权和地域管辖；管委会须有授权依据；平台公司不得写成“代表人民政府”。投资方写清是集团、项目公司还是境外主体。
- **投资义务确定**：项目内容、投资总额与分年到位、注册资本、开竣工、达产或税收贡献口径可核验。只有“加大投资、尽快投产”视为未约定清楚。
- **禁止固定回报**：删除保底收益、回购本息、最低分红、政府补贴补足收益率。配套和防止不必要同类竞争可以写，但不得排除法定准入。
- **对价挂钩**：奖补、供地协助与投资到位、开竣工、达产纳税挂钩；未达标按比例扣减或暂缓；已兑现严重违约的约定返还。
- **决策与生效**：合法性审查、公平竞争审查、集体决策宜作生效条件。口头纪要、领导批示不能替代合同。

必须有修改句。每个风险回链文本位置。禁止套用出让交地、代建概算或特许经营授权节点。禁止复制 `切开。送审主文件是出让合同，或审查重点是出让金交地规划条件土地登记→负触发该原子。本技能禁止打开或复制其method，禁止把本约改成可签署的出让文本，禁止输出出让金分期交地标准土地登记作为本类型主路径。`、`或` 或 `政府代建合同·审查` method。

## 建立审查坐标

确认：使用者与授权；单方立场（政府机关/管委会、园区平台公司、投资方/项目公司择一）；相对方；全文及支持政策清单、选址示意图、授权文件、合法性审查和公平竞争审查意见版本；签约机关职权；承诺事项是否有上位法和预算依据；拟供地是否须招拍挂；投资额与分年到位；是否含固定回报或回购本息；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

## 起草模式

本原子只承担本类型起草。待签评改转 `招商引资合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `招商引资合同·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。下文「起草必写 / 附件必附 / 禁止出现」即本类型硬闸的落稿口径。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 政府承诺效力分层：无法律、行政法规依据或超越职权的税收返还、低价供地、固定回报，降级为“协助依法申请”，并写未获批时的延期、减投资或无损解除。地方留成范围内、有预算和规范性文件依据的奖补，不得一刀切写成无效。
- 税收：只能承诺协助依法享受法定优惠。地方留成奖补须另有预算和规范性文件依据，写清测算口径、兑现条件和审批路径。
- 土地：只能承诺依法供地、协助报批。招商文本里的用地承诺不能替代出让程序，也不能使投资方取得建设用地使用权。
- 主体适格：政府方写全机关全称并核职权和地域管辖；管委会须有授权依据；平台公司不得写成“代表人民政府”。投资方写清是集团、项目公司还是境外主体。
- 投资义务确定：项目内容、投资总额与分年到位、注册资本、开竣工、达产或税收贡献口径可核验。
- 对价挂钩：奖补、供地协助与投资到位、开竣工、达产纳税挂钩；未达标按比例扣减或暂缓；已兑现严重违约的约定返还。
- 决策与生效：合法性审查、公平竞争审查、集体决策宜作生效条件。
- 行政机关订立、具有行政法上权利义务内容的，按行政协议识别争议路径。行政协议约定仲裁的，除法律、行政法规或我国缔结参加的国际条约另有规定外，仲裁条款无效；不得改成“应向某法院起诉”并假装已选定诉讼。民事招商才可约定仲裁或诉讼。

### 附件必附

- 支持政策清单、授权文件。
- 合法性审查和公平竞争审查意见。

### 禁止出现

- 保证获批、保证兑现。
- 减免、先征后返、定额包税、擅自退税。
- 指定地块按某单价成交、流拍后协议出让、未拍即定。
- 把招商文本里的用地承诺写成已经取得建设用地使用权。
- 保底收益、回购本息、最低分红、政府补贴补足收益率。
- 以政府信用为投资方融资提供保证。
- 把本约改成可强制实际履行的出让合同或代建合同。
- 口头纪要、领导批示替代合同。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口，不代替节点。

0. 签署状态与成果分流
1. 类型识别与单目录加载（投资落地 + 依法可兑现支持；切开出让 / 代建 / 特许经营 / 勾地）
2. 主体、授权、平台公司与文本版本
3. 政府承诺效力分层
4. 税收与土地优惠合法性
5. 投资义务、奖补挂钩、固定回报禁止
6. 行政协议识别、优益权与争议路径
7. 程序、生效与决策附件
8. 按框架六步出修改句

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持倒签、保证有效或必然兑现、把减免税/指定低价供地/固定回报/政府违规担保改成可履行结构、把出让或代建主轴按本类型放行。
- `字段停止`：法域、职权依据、预算和规范性文件、拟供地是否必须招拍挂、公平竞争审查、行政协议定性未核验。
- `目标停止`：主目标已变为评改待签文本、履约交底、复议或诉讼文书，或用户要把本约改成出让合同或代建合同。

生存级财政资金或大额已投入依赖越权承诺且用户拒绝升级：停止“可以签署”建议。
