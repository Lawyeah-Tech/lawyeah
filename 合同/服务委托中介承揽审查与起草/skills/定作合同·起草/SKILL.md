# 定作合同·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构，不证明本约条款已被接受。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、1984 年《加工承揽合同条例》当作现行规则。不得把买卖章货交承运人风险、检验期间视为符合约定、所有权保留百分之七十五取回限制，或建设工程资质／招标／竣工验收，硬套本类型。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只起草 **承揽合同 / 定作合同** 的待签文本，按已谈妥条件出己方稿，输出可编辑草稿、未决项；出稿后必须用本类型硬闸自审，输出风险表和修改句。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。`depends-on` 为空。不要求先跑导航。

不交付：他类审查、待签文本签前审查、履约交底、争议文书、有效性或成果必然合格／留置必然实现／解除必然赔到预期利润的保证。

## 工作边界

正触发：已有可读待签文本要评改（审查模式），或本类型条件已谈妥要出己方稿（起草模式）；尚未签署，尚未成争，核心给付是**承揽人自备主要材料**，按照定作人的特定要求制成**特定工作成果**并交付，定作人支付报酬。典型信号：非标设备、定制家具、企业工服、礼品定制；正文或附件锁定规格／图纸／样品；定作人可对过程和材料行使监督、检验或指示。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 定作人提供主要材料，承揽人只做加工 → `加工合同·审查`；
- 通用型号现货、卖方组织生产、买方不控制过程 → `通用型号现货卖方组织生产买方不控制过程→`；
- 对既存物修复、恢复功能 → `修理合同·审查`；
- 主给付是贴委托方商标／品牌授权代工 → `定牌加工（OEM）合同·审查`；
- 工地建筑活动、承包资质、竣工验收 → `工地建筑活动承包资质竣工验收→`；设计采购施工一体 → `设计采购施工一体→`；
- 尚待研究开发、不保证成果必然产生 → 技术开发场景原子或引擎重新定性；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问投料、验收、付款留痕 → 本套导航的履约步骤；
- 已成争（催告、解除、索赔、诉讼仲裁）→ `或对应专项领域。` 或对应专项领域。

违禁品定作、无许可特种设备、通谋虚假、倒签规避监管：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；定作人或承揽人单一立场；相对方；正文、附件、技术协议、图纸、封样版本；成果名称／规格／数量；**主要材料由谁采购**；过程监督与指示由谁签字；不可接受事项；法域与拟签时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价格、数量、日期用 `【待填】`，不编造。

知识双文件若把定制软件开发、广告制作或修理写成适用场景，以本技能硬闸和路由为准，不把过宽场景写成正触发。

## 本类型硬闸

审查过程必须逐项点名。禁止用加工“来料检验”清单或买卖检验／风险／所有权保留清单代替：

1. **定作 ≠ 加工 ≠ 买卖 ≠ 工程 ≠ OEM**：承揽人供主材＋按特定要求制成果。定作人供主材、承揽人加工 → `加工合同·审查`。通用现货无过程监督 → `通用型号现货卖方组织生产买方不控制过程→`。工地施工资质竣工 → `工地建筑活动承包资质竣工验收→`。品牌贴牌授权主给付 → `定牌加工（OEM）合同·审查`。
2. **规格／图纸／样品必须附件化**：无规格、无图纸、无封样仍放行禁止。关键技术参数不得只写在鉴于条款。过程监督权、指示权必须写清授权代表；非授权人指示不构成变更。
3. **772 亲自完成**：主要工作转第三人须事先同意，否则定作人可解除。承揽人仍就第三人成果负责。辅助工作可转，责任仍在承揽人。
4. **材料与风险**：承揽人供材须按约选用并接受检验（第 774 条）；更换品牌、产地、牌号须书面同意。交付前风险原则上由承揽人承担。禁止把“货交承运人即风险转移”写成默认。
5. **787 任意解除**：完成工作前定作人可随时解除，但赔偿损失。不得删除法定解除权，也不得写成“解除不赔”。修改句锁通知、已完工结算、剩余材料处理和预期利润是否计入。
6. **验收与留置**：验收期、视为合格范围、隐蔽瑕疵保证。未付报酬可留置成果或拒绝交付（另有约定除外）。禁止“签收即终局合格并放弃留置”一句话吞没。违禁品／无许可特种设备：停笔，不改成可履行。


## 起草模式

本原子只承担本类型起草。待签评改转 `定作合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `定作合同·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。下文「起草必写 / 附件必附 / 禁止出现」即本类型硬闸的落稿口径。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 承揽人自备主要材料，按照定作人的特定要求制成特定工作成果并交付。
- 规格／图纸／样品附件化；关键技术参数不得只写在鉴于条款。过程监督权、指示权写清授权代表；非授权人指示不构成变更。
- 第 772 条：主要工作转第三人须事先同意，否则定作人可解除；承揽人仍就第三人成果负责。辅助工作可转，责任仍在承揽人。
- 承揽人供材须按约选用并接受检验（第 774 条）；更换品牌、产地、牌号须书面同意。交付前风险原则上由承揽人承担。
- 第 787 条：完成工作前定作人可随时解除，但赔偿损失。锁通知、已完工结算、剩余材料处理和预期利润是否计入。
- 验收期、视为合格范围、隐蔽瑕疵保证。未付报酬可留置成果或拒绝交付（另有约定除外）。

### 附件必附

- 规格、图纸、封样。三者缺一不得放行。

### 禁止出现

- 无规格、无图纸、无封样仍放行。
- 关键技术参数只写在鉴于条款。
- 货交承运人即风险转移写成默认。
- 删除法定解除权，或写成解除不赔。
- 签收即终局合格并放弃留置。
- 违禁品或无许可特种设备的可履行结构。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验承揽定义、定作与买卖／工程切开、主要工作、承揽人供材、交付验收报酬、留置、任意解除、监督检验、保密留存；`search_practiced` 补定作／买卖／加工切开和 787 赔偿范围等审查反例；`search_template` 只借修改句结构。不虚构案件系统。

`search_law` 对法律结论为 required 级节点：不可用时不拒绝执行，只停止法律结论字段。返回已失效《合同法》《加工承揽合同条例》时记为噪声，不得写入 `L#`。返回买卖第 595／604／621／641 条或施工第 788／791 条时，不得当作本类型默认法。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、把违禁品或无证特种设备改成可履行、删除第 787 条或写成解除不赔、无规格仍要求放行、保证成果必然合格或留置必然实现。
- `字段停止`：成果无法特定化；规格／图纸／样品未附件化；材料品牌标准未写；特种许可未核验；787 赔偿范围法定口径未核验。
- `目标停止`：主目标已变为他类型起草、履约交底或争议文书。

生存级预付款或个人无限连带且用户拒绝升级：停止“可以签署”建议。
