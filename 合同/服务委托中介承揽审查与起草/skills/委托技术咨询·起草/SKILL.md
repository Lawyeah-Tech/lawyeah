# 委托技术咨询·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》技术咨询章、《技术合同法》及其实施条例当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只起草 **委托合同 / 技术咨询合同** 的待签文本，按已谈妥条件出己方稿，输出可编辑草稿、未决项；出稿后必须用本类型硬闸自审，输出风险表和修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文名必须是「委托技术咨询·起草」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、待签文本签前审查、履约交底、争议文书、有效性保证、把技术类技术咨询/咨询服务/技术服务/委托开发/设计出图整案改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **委托父级技术咨询**：委托人聘请外脑，就特定技术项目出具咨询意见或报告。用户或文本明确落在技术类合同目录、主张按四技合同技术咨询原子审 → 负触发 `或`；无特定技术项目的管理/战略/财务/人力/品牌咨询 → 负触发 `咨询服务合同·审查`；对外代理或概括处理事务 → 负触发 `一般委托合同·审查`。禁止抄 `或`、`咨询服务合同·审查` 的审查方法。
2. **意见非施工图**：交付物是可行性论证、技术预测、专题技术调查、分析评价报告等决策参考，不是施工图、初步设计、出图盖章或可据以施工的图纸。出图主轴 → `委托他人设计的服务合同·审查` 或 `单独设计发包，无现场简易施工成果`；建设工程咨询/估算概算/全过程工程咨询 → `只出可行性造价或管理咨询意见不交付测绘测试成果→`。
3. **决策损失默认委托人自负**：委托人按照受托人**符合约定要求**的咨询报告和意见作出决策所造成的损失，由委托人承担，另有约定除外。报告不符约定、数据造假或违反科学常识，不得套用自负条款。
4. **费用默认受托人负担**：与一般委托“委托人预付费用”相反。正常调研、资料、试验测定费用沉默由受托人负担；要报销必须书面逐项。
5. **验收看任务书，不保证成败**：验收核对任务书章节、数据来源、论证深度和约定指标；不得把市场成败、投产成功或保证获利写成验收标准或担保结果。
6. **资料协作、新成果与虚假咨询**：委托人须阐明问题并提供资料；资料明显错误受托人应通知。履行中新的技术成果无约定时按完成方归属，不把咨询报告著作权默认写成归委托人。无实质性技术论证、以咨询套现：停笔。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签委托技术咨询正文，尚未签署，尚未成争，核心给付是就特定技术项目出具意见或报告，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 用户或文本明确按技术类合同/四技合同技术咨询审 → `或`；不得留下本技能对照委托费用或任意解除改完；
- 无特定技术项目的管理、战略、财务、人力、品牌等商务咨询 → `咨询服务合同·审查`；不得把第 881 条第 3 款套到该类文本；
- 维修、测绘、检测、调试、工艺实施等解决特定技术问题 → `委托技术服务·审查`；
- 研究开发新技术、新产品、新工艺并交付开发成果 → `委托技术开发合同·审查` 或 `只审委托合同目录下的委托技术开发。用户或材料按技术类合同进入《技术开发合同》→`；软件开发 → `可运行软件或系统交付→`；
- 施工图、初步设计、出图盖章、可据以施工的图纸 → `委托他人设计的服务合同·审查` 或 `单独设计发包，无现场简易施工成果`；
- 建设工程咨询、估算概算、全过程工程咨询 → `只出可行性造价或管理咨询意见不交付测绘测试成果→`；
- 以委托人名义对外签约、开委托人抬头发票、概括处理事务 → `一般委托合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

无实质性技术论证、以咨询套现或利益输送：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（委托人侧或受托人侧择一）；相对方；全文及任务书/资料清单/验收表版本；是否特定技术项目；交付物是意见报告还是图纸/实施成果/开发成果；费用是否书面逐项；决策损失是否另有约定；核心专家名单与资质痕迹；资料提供与答疑程序；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的报酬、期限、份数用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验第 878–881、885、886、850、委托对照、格式条款、定金上限、强制规范；`search_practiced` 只补审查反例；`search_template` 只借栏目结构。不虚构案件系统。

`search_law` 对上述法律结论为 required 级：不可用时不拒绝执行，只停止效力字段。返回已失效《合同法》技术咨询章、《技术合同法》或其实施条例时记为噪声，不得写入 `L#`。


## 起草模式

本原子只承担本类型起草。待签评改转 `委托技术咨询·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `委托技术咨询·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`，不编造。

### 起草必写

- 核心给付是委托人聘请外脑，就特定技术项目出具咨询意见或报告；交付物是可行性论证、技术预测、专题技术调查、分析评价报告等决策参考。
- 任务书列问题清单、章节、数据来源、论证深度和对比口径。
- 委托人按照受托人符合约定要求的咨询报告和意见作出决策所造成的损失，由委托人承担，另有约定除外；报告不符约定、数据造假或违反科学常识，不得套用自负条款。
- 正常调研、资料、试验测定费用沉默由受托人负担；要报销必须书面逐项。
- 验收核对任务书，不得把市场成败、投产成功或保证获利写成验收标准或担保结果。
- 委托人须阐明问题并提供资料；资料明显错误受托人应通知。
- 履行中新的技术成果无约定时按完成方归属；咨询报告著作权不默认写成归委托人。
- 部分完成应付相应报酬；有偿解除应赔偿。

### 附件必附

- 任务书、资料清单、验收表。
- 核心专家名单与资质痕迹（有事实则附）。

### 禁止出现

- 把施工图、初步设计、出图盖章或可据以施工的图纸当咨询成果。
- 保证获利，或报告不符约定仍由委托人自负。
- 无特定技术项目的管理/战略/财务/人力/品牌咨询，或对外代理、概括处理事务。
- 无实质性技术论证、以咨询套现或利益输送：只告知，不起可履行稿。
- 把技术类合同目录下的技术咨询原子当本任务出稿。

出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)

禁止打开其他类型目录。`基本面.md` 中“版权通常归委托人”不得写成法定默认；`框架.md` 中决策自负必须同时写清“报告符合约定要求”。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 留本任务起草并自审；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有委托技术咨询文本；本任务只起草，评改待签文本转配对 ·审查 原子。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。技术类目录、商务咨询、技术服务、委托开发、出图、一般委托负触发。

### 2. 主体、专家与资质

签约名、履行名、付款名、发票名分列。工程咨询/安评/环评等法定资质未核：字段停止。虚假咨询或无实质论证：停笔。

### 3. 意见给付与任务书

交付物必须是报告或意见。施工图不得当咨询成果。任务书须列问题清单、章节和对比口径。

### 4. 决策损失与报告符合约定

881 自负以报告符合约定为前提。保证获利或报告不符仍自负：红线。

### 5. 费用反转与报酬

费用沉默由受托人负担。部分完成应付相应报酬。

### 6. 资料协作、新成果、格式条款与强制规范

资料缺陷须通知。新成果与报告著作权分列。无核验引文则法律结论字段停止。

### 7. 验收、登记与退出

验收看任务书。登记只作税务配合，不是生效要件。有偿解除应赔偿。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把施工图当咨询意见、保证获利、报告不符仍自负、或把无实质论证的套现改成可履行结构。
- `字段停止`：法域、动态规则、法定资质、技术合同登记优惠、跨境数据评估未核验。
- `目标停止`：主目标已变为评改待签文本、履约交底、争议文书，或已锁他类。
