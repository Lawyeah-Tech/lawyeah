# 审查方法（锁定 委托合同 / 政府代建合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制商业代建的品牌授权/销售分成/资金共管主路径，禁止复制 BT 的融资回购/投资回报主路径，禁止复制 DBO 的长期运营主路径，禁止复制施工的按图结算/工程量清单主路径。

定性校验：标题、核心给付与本类型一致才继续；商业代建、房地产委托代建、资本/股权代建、BT、DBO、施工、全过程咨询明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、必然行政协议、对方必然接受或唯一必得管理费。

`search_law` 返回已失效《合同法》及其解释、《民法通则》、2015 年《最高人民法院关于适用〈中华人民共和国行政诉讼法〉若干问题的解释》、计委 3 号令《工程建设项目招标范围和规模标准规定》、政府购买服务管理办法仍引用合同法的条文时记为噪声，不得写入 `L#`。招标投标法须用 **2017 年修正** 文本；《基本建设财务规则》须用 **2017 年修正** 文本，不得把 2016 年令原文标成未修改。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。北京、深圳等地政府投资代建示范文本只借栏目（三方、概算、代建费、审计），不得把范本中的垫资、签字即生效或资金未落实即开工写成已核验规则。

知识库纠正（不回写双文件）：

- `基本面.md` “实务中常被认定为行政协议”：须对照行政协议规定第 1 条的主体、目的、行政法权利义务。现有依据不支持把所有政府代建写成必然行政协议。争议解决路径标待核。
- `基本面.md` “未经法定程序直接指定企业代建，合同面临撤销风险”：企业代建缺招标或政府采购痕迹是红线或字段停止；现有依据不支持写成必然撤销或必然无效。效力依民法典第 153 条和合同编通则解释第 16 条个案判断。事业性代建不适用企业招标口径。
- `基本面.md` “政府投资项目必须通过招标选定代建单位”：事业性代建走机构设立或授权。企业代建是否必须招标，取决于是否落入《招标投标法》第 3 条、《必须招标的工程项目规定》第 2、5 条或政府采购限额，以及当地代建办法。不得写成一切政府代建一律公开招标。
- `基本面.md` 取费依据写成“财政部关于印发《基本建设财务规则》的通知”：现行文本是财政部令第 81 号，2017 年修正仍有效。节余奖励 10%–30%、履约保函 2%–5% 是实务建议，不是法定比例；缺数字用 `【待填】`。
- `框架.md` “企业代建可约定一定比例的绩效奖励”：财政资金结余应按《政府投资条例》第 25 条缴回国库。绩效奖励须有财政允许依据，不得写成从建设资金中截留。
- 民法典第 921 条允许受托人垫付必要费用并求偿：不得据此把建设资金垫资改成可履行。政府投资项目建设资金垫资受《政府投资条例》第 22 条约束。前期规费可约定甲方设立周转金，不得写成代建方垫付建设资金。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、资金来源和对价方式定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。标题写“项目管理”“全过程咨询”“委托建设”的，先看资金是否预算内政府投资、委托方是否政府或授权机构、给付是否建设管理而非融资回购或按图施工。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 政府或授权机构委托事业性机构或经采购程序选定的企业，管理财政资金投资的非经营性项目建设，对价是代建管理费 | 本类型 | 正触发 |
| 开发商或社会资本委托房企代建经营性房地产；品牌、去化、溢价分成 | 房地产委托代建或商业代建 | 负触发 `房地产委托代建合同·审查` 或 `商业代建合同·审查` |
| 融资或投资安排与代建耦合、固定回报 | 资本代建 | 负触发 `资本代建合同·审查` |
| 代建方入股项目公司 | 股权代建 | 负触发 `股权代建合同·审查` |
| 商业代建叠加借款 | 商业代建+贷款配资 | 负触发 `商业代建配资·审查` |
| 代建方筹资建设，政府分期回购本金和回报 | BT | 负触发 `当事人明确按BT专约交易→` |
| 设计+建造+长期运营，承包人不负责融资 | DBO | 负触发 `承包人设计+建造+长期运营业主融资→` |
| 业主发包、按图施工、交付工程 | 施工 | 负触发 `工地建筑活动承包资质竣工验收→` |
| 设计+采购+施工总承包 | EPC | 负触发 `设计采购施工一体→` |
| 可行性研究、造价、招标代理或全过程咨询智力服务为主，不以代建人身份组织实施 | 建设工程咨询服务 | 负触发 `只出可行性造价或管理咨询意见不交付测绘测试成果→` |

支持切开的规范（法律结论须运行时复核）：

- 《政府投资条例》第 2 条：政府投资是使用预算安排的资金进行固定资产投资建设活动。
- 《政府投资条例》第 22 条：政府投资项目不得由施工单位垫资建设。代建方垫付建设资金并要求回购，按 BT 切开，不按本类型包装。
- 民法典第 919 条：委托是处理委托人事务。本类型的事务是建设管理，不是承包施工，也不是融资建设。
- 行政协议规定第 1 条：行政机关为实现行政管理或公共服务目标，与相对人协商订立、具有行政法上权利义务内容的协议。用于定性辅助，不单独证明必然行政协议。

实务反例（非法源）：招投标贯穿设计、代建、施工等环节，应进公共资源交易中心。不得据此把事业性代建改成必须招标，也不得把未达限额的服务采购写成已经违法。

### 1.3 与商业代建 / BT / DBO 切开（硬闸）

| 文本写法 | 本任务动作 | 修改句方向 |
| --- | --- | --- |
| 财政资金、非经营性公共项目、代建管理费、国库支付、代建方组织实施但不承包施工 | 正触发，留下本类型 | 首部写明“政府投资项目代建管理，不是商业代建、施工承包或 BT” |

修改句（正触发首部）：

「本合同为政府投资项目代建管理合同。甲方将【项目名称】的建设管理职责委托乙方履行。项目资金为预算安排的政府投资资金，实行国库集中支付。乙方提供建设管理服务并收取代建管理费，不承包施工，不承担项目融资或回购义务。本合同不是商业代建、房地产委托代建，也不是 BT、DBO 或施工承包合同。」

动作：

3. 风险表只保留识别依据和转出/改道提示。
4. 用户坚持“改到能签且仍直接指定或挂靠”：整体停止。

## 节点 2　主体、三方界面、资质与文本版本

### 2.1 主体表

建表：签约名、履行名、付款名（财政/国库）、发票名、授权签字人、使用人、代建方类型（事业性机构 / 企业）。名称不一致不自动合并。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 委托方不是行政机关、投资主管部门、使用单位或政府设立的专职机构 | 重新定性；可能负触发商业代建 | 因标题含“政府”即正触发 |
| 代建方为工务署、公建中心、代建局等常设机构 | 事业性代建；管理费按经费划转审 | 强制套用企业招标和营利报酬 |
| 代建方为企业 | 核验资质种类（开发、工程咨询、监理或施工总承包等）及当地代建名录；名录未核则字段停止 | 已进入名录；已具备全部政府项目资格 |
| 使用人未列为一方，正文又让其确定功能需求和接收工程 | 必须改：三方签署或使用人权利义务专条 | 使用人当然受本合同约束 |

口头“我们局长同意了”不得写成已授权。国资、财政内部决议未闭合：该签署能力字段停止。

### 2.2 使用人与监理界面

三方模式须写清：委托人保留概算调整、重大变更和采购方式决定权；使用人提出功能需求并参与竣工接收；代建人组织实施；监理独立履行法定职责，不得写成代建人的内设部门。

修改句：

「使用人有权提出功能需求和参与竣工接收，但不得直接向施工单位下达变更指令。涉及建设规模、标准或概算调整的，须经甲方书面同意并按原审批权限报批。监理单位由【甲方／代建人依法组织招标，甲方确定】委托，独立出具监理意见；代建人不得取代监理签字。」

### 2.3 文本版本

正文、立项批复、可研批复、概算表、采购或招标文件、绩效考核指标、聊天确认冲突时并列，不选有利版。批复未附：字段停止，不写“项目已纳入年度政府投资计划”。

## 节点 3　标的、概算红线与国有资产

### 3.1 管理范围

标的须落到：办理报建、组织依法招标、施工阶段质量/进度/投资控制、竣工验收、档案与实物移交。只有“等代建事宜”则标缺口。使用“组织实施”“协调管理”，禁止改成“承包建设”。

### 3.2 概算、规模与标准

支持依据：《政府投资条例》第 12、21、23 条。

| 文本写法 | 动作 |
| --- | --- |
| 未附概算或未写规模、标准 | 必须改：概算表入附件；规模和标准写死 |
| “代建人可按现场需要调整建设标准” | 红线。较大变更须报原审批部门 |
| “超概由财政追加，代建人不承担责任” | 必须改：区分代建人原因与政策/价格/地质原因；前者扣减管理费或按约定比例赔偿，后者走第 23 条报批 |
| 概算超过可研估算 10% 且无重新报批痕迹 | 字段停止；修改句要求补报 |

修改句：

「投资概算以附件《项目总概算表》载明的人民币【待填】元为控制依据。乙方不得擅自扩大建设规模、提高建设标准或增加建设内容。因乙方原因导致决算超概的，超概部分由乙方在代建管理费范围内承担，并扣减相应管理费；因国家政策调整、价格上涨或地质条件发生重大变化确需调增概算的，由甲方按《政府投资条例》第二十三条报原核定部门核定，涉及预算调整的另行办理。未经核定，任何一方不得以合同约定追加建设资金。」

### 3.3 国有资产

项目形成的土地、在建工程、设备、报废残值属国有资产。代建方不得抵押、质押或为自身融资提供担保。

修改句：

「项目建设过程中形成的资产（含土地使用权、在建工程、设备及残值）属于国有资产，所有权不因代建而转移。未经甲方书面同意并履行国有资产审批程序，乙方不得设定抵押、质押或其他权利负担，不得以本项目资产为自身或第三方融资提供担保。」

材料未提及权利负担：只能写 `依据不足`，不得写成“无权利负担”。

## 节点 4　财政资金、国库支付与采购程序（硬闸）

### 4.1 资金路径

支持依据：《政府投资条例》第 5、19、22 条；《保障农民工工资支付条例》第 23 条。

| 文本写法 | 动作 |
| --- | --- |
| 建设资金由财政按进度直接支付施工/供货方，代建人预审后签字确认 | 可保留；补预审时限和资料清单 |
| 建设资金进入代建人账户，由其转付 | 红线。改为国库集中支付或财政直接支付 |
| 要求代建人垫付建设资金，政府分期返还并计息或给予固定回报 | 负触发 `当事人明确按BT专约交易→`；本任务不改成可履行垫资 |
| “资金未落实也可先行开工，日后财政认账” | 红线。资金落实作为开工或生效条件 |
| 仅要求代建人垫付报建规费 | 必须改：甲方设立前期费周转金；不得写成建设资金垫资 |

修改句（国库支付）：

「本项目建设资金纳入预算管理，由财政部门按照国库集中支付制度拨付。乙方根据工程进度和合同约定提出支付申请并预审，经甲方及财政部门审核后直接支付至施工、供货或其他合同相对方。乙方不得开立建设资金沉淀账户，不得截留、挪用或转付建设资金。代建管理费按本合同专条另行支付，不得从建设资金中坐支。」

修改句（前期费，不是建设资金垫资）：

「甲方应在本合同生效后【待填】日内设立前期工作周转金人民币【待填】元，专用于依法应由建设单位缴纳的报建规费。周转金不足时由甲方追加。乙方垫付建设资金或将周转金用于施工进度款的，甲方有权拒绝确认，并要求立即改正。」

最强反方：代建人主张“不经手资金就管不住现场”或“921 条允许垫付”。现有依据支持代建人预审权，不支持其占有建设资金；921 条不能覆盖第 22 条禁止的建设资金垫资。

### 4.2 采购程序

支持依据：《招标投标法》（2017 修正）第 3、49 条；《必须招标的工程项目规定》第 2、5 条；《政府采购法》第 2 条；《政府采购法实施条例》第 7 条。

企业代建：

1. 核验是否已有公开招标、邀请招标或政府采购文件、中标通知书。
2. 未达必须招标或政府采购限额：标待核，修改句要求写明适用的采购方式及批准文件，不写成已经合法指定。
3. 达到限额却直接指定：红线。修改句把采购完成作为生效条件。用户坚持先签后补招标：整体停止。
4. 不得把地方代建办法单独写成合同必然无效的法源。

事业性代建：核验设立文件或授权文件，不套用企业招标。

修改句（企业代建）：

「乙方确认其已通过【公开招标／政府采购】程序被确定为代建人。甲方应将中标通知书或采购结果确认文件作为附件。前款文件未作为附件且采购程序依法应当完成而未完成的，本合同不生效；任何一方不得要求对方先行履行。甲方不得以直接指定方式要求乙方开始代建工作。」

立项、招标、预算批准写成生效条件或履行期限，不写成已经完成。用户要求倒签或补假批准：整体停止。

## 节点 5　代建费、节余、定金与退出

### 5.1 代建管理费

价金构成、币种、税、发票、节点、是否含前期费分列。事业性代建按经费划转，不写成营利报酬。未给出的数字写 `【待填】`。取费可参照基本建设财务管理规则中的建设单位管理费口径，但不得编造法定比例。

修改句：

「代建管理费总额人民币【待填】元（含／不含税），取费基数为经核定的项目建设成本，不包括建设资金本身。支付节点：本合同生效且建设资金到位后【待填】日内支付【待填】%；主体结构验收后支付【待填】%；竣工验收备案且竣工财务决算审计完成后【待填】日内支付尾款。审计核减管理费计费基数的，按审计结果结算。乙方未完成的部分不得请求该部分管理费。」

一次性预付全部管理费：必须改成分期，但不是违法。

### 5.2 节余

支持依据：《政府投资条例》第 25 条。

财政资金结余缴回国库。企业代建的绩效奖励须单列，且以财政允许的资金渠道为前提，不得写成代建人截留建设结余。

修改句：

「项目竣工财务决算审计确认的财政资金结余，应当按照规定缴回国库。如财政主管部门书面允许从节余中提取绩效奖励，奖励比例不超过【待填】%，并在审计确认后支付；未经书面允许，任何一方不得约定截留或分成建设资金结余。」

知识库 10%–30% 不是法定区间。

### 5.3 定金与履约担保

必须使用“定金”二字才讨论罚则。约定或推算超过主合同标的额（此处为代建管理费，不是工程投资额）百分之二十：超过部分不产生定金效力。履约保函金额用 `【待填】`，2%–5% 工程投资额不是法定。

### 5.4 退出与政策调整

禁止只写“双方协商解除”而无通知、档案移交和已完工作结算。不得把第 933 条写成无偿随时解除。政府因规划或预算调整终止项目：须有补偿计算口径；若可能构成行政协议，另点名行政协议规定第 16 条的补偿/赔偿区分，不在本任务认定已构成行政协议。

修改句：

「因规划调整、预算未安排或公共利益需要，甲方书面通知提前终止的，应按已完成的代建工作支付相应管理费，并补偿乙方为履行本合同已发生且无法收回的直接费用；双方对预期利润另有书面约定的，按约定在【待填】范围内协商。乙方应在通知到达后【待填】日内移交全部工程档案、印章和现场管理权。因乙方舞弊、转包或因乙方原因超概且未在约定期限改正，甲方可书面解除，已付未对应完成工作的管理费应予返还。」

## 节点 6　格式条款、强制规范与行政协议定性

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 是否格式条款

当地住建或发改示范文本为重复使用而预先拟定的，可能构成格式条款。依据示范文本制作，不当然排除格式条款。审查：垫资、资金进代建账户、无限超概免责、单方无偿解除、最终解释权等异常条款是否有提示说明（第 496 条；解释第 10 条）。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在通用条款 | 已尽提示义务 |
| 仅有网上勾选示范文本 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

### 6.2 强制规范

违反法律、行政法规强制性规定不一律无效（第 153 条；解释第 16 条）。禁止用已失效“效力性/管理性”口诀。垫资建设、规避招标、挂靠、以合法形式掩盖违法举债：不改写成有效履行。造成人身损害或因故意、重大过失造成财产损失的免责条款无效（第 506 条）。

《保障中小企业款项支付条例》（2025 修订）第 32 条将“要求施工单位对政府投资项目垫资建设”列为追责情形：用于支持删除垫资条款，不代替修改句。

### 6.3 行政协议定性

对照行政协议规定第 1、2 条。政府代建不在第 2 条明示列举。同时具备行政机关一方、公共服务目标、行政法权利义务的，可能被认定为行政协议；缺一则依据不足。

不得写成：必然行政协议、必然走行政诉讼、民事条款全部无效。争议解决条款保留单一路径，并提示行政协议争议可能受行政诉讼法约束。单方变更解除如被认定为行政协议，补偿/赔偿区分见第 16 条，本任务只出修改句，不作已解除结论。

## 节点 7　超概、廉政、审计、争议与通知

1. 逾期移交、逾期支付管理费、因代建人原因超概、招投标舞弊必须分别有可执行后果。只有“依法承担违约责任”视为必须改。
2. 构成违约不等于当然解除。法定解除路径只点名催告或目的不能实现，不在本任务作出已解除结论。
3. 违约金不是必得金额。修改句避免“不得调整”或“按工程总投资 30% 必得”。
4. 必须约定接受审计机关或财政部门竣工决算审计；代建管理费以审计结果为结算依据。
5. 廉政：招投标或工程款预审中的舞弊可约定解除，但不得写成“监察谈话尚未结束即已构成刑事犯罪”。
6. 争议解决：出现仲裁条款不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核。可能的行政协议管辖只标红旗，不选定唯一法院充作法律意见。
7. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。

修改句（审计）：

「乙方应接受审计机关或财政部门依法实施的审计。竣工财务决算审计完成前，甲方有权暂扣代建管理费尾款【待填】%。审计结论与本合同约定不一致的，以审计结论作为管理费结算依据；乙方有异议的，按审计法律法规提出，不得以异议为由拒绝移交工程和档案。」

修改句（廉政）：

「乙方及其派驻人员在组织招标、预审工程款或推荐供应商过程中存在串通投标、收受回扣或其他舞弊行为，经甲方书面告知并给予【待填】日说明期后仍不能排除的，甲方有权解除本合同，已付未对应完成工作的管理费应予返还。本条不代替监察、审计或司法机关的认定。」

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（垫资回购、建设资金进代建账户、规避采购直接指定、国有资产抵押、挂靠、倒签、商业代建/BT/DBO/施工主轴）；

用户不可接受事项优先写成红线。生存级履约保函或个人无限连带且用户拒绝升级：停止“可以签署”建议。
