# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的管理费、概算、工期、节余比例；把已失效《合同法》及其解释、2015 年行政诉讼法解释或计委 3 号令规模标准写入结论；写成必然行政协议或必然无效。

## 1. 触发、单方立场与成果状态

立场（委托方/使用人侧或代建方侧）、授权、签署状态、主要目标、代建子类型（事业性或企业代建）。负触发写路由，不启动实体审查。成果名称写「审查政府代建合同（委托合同）」。商业代建、BT、DBO、施工必须在本节写明负触发，不得进入第 5–8 节。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、2015 年行政诉讼法解释时记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 **委托合同**、子级 **政府代建合同**、定性理由、与 `房地产委托代建合同·审查` / `商业代建合同·审查` / `当事人明确按BT专约交易→` / `承包人设计+建造+长期运营业主融资→` / `工地建筑活动承包资质竣工验收→` 的切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读其他类型。垫资回购、规避采购或挂靠写停笔告知，不填可履行结构。

## 4. 主体、授权、资质与文本版本

主体表：签约名、履行名、付款名（财政/国库）、发票名、授权签字人、使用人、代建方是事业性机构还是企业。版本表：正文、立项/可研/概算批复、采购或招标文件、绩效考核指标、聊天确认；冲突并列，不选对用户有利的一版。

## 5. 给付闭环

管理范围、建设规模与标准、概算红线、国有资产不得抵押、国库集中支付、代建方不经手建设资金、企业代建采购程序、代建管理费与节点、节余上缴、审计结算、验收移交。缺口标 `G#`，不补财政数字。立项、招标、预算写成生效条件或双方义务期限，不写成已经完成。

## 6. 格式条款与强制规范

是否构成当地示范文本格式条款；提示说明痕迹；异常条款（垫资、回购、资金进代建账户、直接指定、国有资产抵押、无限超概免责）。强制规范只区分是否导致民事行为无效。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。行政协议定性写依据不足或待核，不写成必然。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔/转出口径。禁止输出无修改句的色块表。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业或财政数字用 `【待填】`，不编造。禁止只给原则、不给句子。

## 9. 谈判与签署提醒

谈判顺序：先红线，再必须改，最后可优化。签署提醒：授权与政府印章、日期、立项/概算/采购文件入附件、建设资金到位条件、使用人会签。不指导倒签、补假招标或先签再补预算。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书或效力保证。
