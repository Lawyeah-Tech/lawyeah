# 边界与路由

本技能只审查 **委托合同 / 政府代建合同** 的待签文本。中文展示名是「审查政府代建合同（委托合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或抄写 `商业代建合同·审查`、`当事人明确按BT专约交易→` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 开发商或社会资本委托房企代建经营性房地产；品牌输出、销售指标 | `房地产委托代建合同·审查` 或 `商业代建合同·审查`。不得抄商业代建方法，不得删品牌/销售栏目后硬套本技能 |
| 融资或投资安排与代建耦合、固定回报、不良资产盘活 | `资本代建合同·审查` |
| 代建方入股项目公司、跟投或固定价退股 | `股权代建合同·审查` |
| 商业代建叠加借款配资 | `商业代建配资·审查` |
| 代建方筹资建设、政府分期回购本金和回报 | `当事人明确按BT专约交易→`。不得抄 BT 方法，不得把回购改成“代建费分期”后硬套 |
| 设计+建造+长期运营，承包人不负责融资 | `承包人设计+建造+长期运营业主融资→` |
| 业主发包、按图施工、交付工程 | `工地建筑活动承包资质竣工验收→` |
| 设计+采购+施工总承包 | `设计采购施工一体→` |
| 可行性研究、造价、招标代理或全过程工程咨询智力服务为主 | `只出可行性造价或管理咨询意见不交付测绘测试成果→` |
| 无文本、本类型条件已谈妥、要出己方稿 | `政府代建合同·起草` |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

政府代建正文里夹带一小段施工承包或监理委托：专条交接对应原子；资金路径、采购程序、概算、代建费、审计条款可继续审。用户坚持本技能把商业代建、BT、DBO 或施工整案改完：`目标停止`。
