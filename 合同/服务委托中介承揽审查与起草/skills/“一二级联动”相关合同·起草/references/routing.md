# 边界与路由

本技能只审查 **委托合同 / “一二级联动” 相关合同** 的待签文本。开发主体承担一级整理，文本同时安排后续二级出让的联动。中文展示名是「审查“一二级联动” 相关合同（委托合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 只有一级整理，成本加固定利润，无二级优先、保证摘牌或预申请 | `土地一级开发委托合同·审查`。本任务不审纯一级成本利润主路径 |
| 名为一级开发，只出资、固定回报或保底分成，无真实整理 | `名为一级开发实为借贷·审查`。禁止打开其 method |
| 名为一级，实为垫资施工、竣工验收 | `名为一级开发实为施工·审查` |
| 只有拆迁实施委托，不连二级出让 | `拆迁委托协议·审查` |
| 只有用地预申请、保证金、承诺报价 | `只有用地预申请勾地，没有一级整理委托→` |
| 与非出让人签订勾地 | `或` |
| 企业之间联合勾地 | `或` |
| 待签文本已是国有土地使用权出让合同 | `切开。送审主文件是出让合同，或审查重点是出让金交地规划条件土地登记→负触发该原子。本技能禁止打开或复制其method，禁止把本约改成可签署的出让文本，禁止输出出让金分期交地标准土地登记作为本类型主路径。` |
| 企业之间一级市场联合拿地主结构 | `或` |
| 城市更新前期服务，未写实施主体转化或二级联动 | `城市更新前期服务未写实施主体转化或二级联动→` |
| 村集体与企业合作开发，政府不是联动一方 | `村集体与企业合作开发主结构政府未作为联动一方→` |
| 无文本、本类型条件已谈妥、要出己方稿 | 留本任务起草并自审 |
| 已签未争、只问供地日、审计付款日、交接履约 | 本套导航的履约步骤 |
| 已催告、解除、索赔、复议、诉讼或仲裁 | `或对应专项领域。` 或行政争议路径。本技能不审应诉策略 |
| C 端大众快检 | 只分流，不回改 |

本协议夹带纯一级委托、借贷协议、施工承包、勾地或出让合同附件：附件整段交接对应完整 Skill ID；若正文仍是一级整理加二级联动，正文可继续审。用户坚持本技能给出定向出让方案、排他门槛或胜诉率：`目标停止`。
