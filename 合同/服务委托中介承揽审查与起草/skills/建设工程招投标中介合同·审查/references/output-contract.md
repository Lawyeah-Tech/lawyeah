# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受、必然可执行或必然中标；编造未给出的比例、金额、项目名称；把已失效《合同法》、失效招标代理资格认定办法、1999 年第五十条旧罚则写入结论；把招标代理、施工或工程咨询文本当成已完成的本类型审查；写“必须持工程招标代理资格证书”；写“中标挂钩一律无效”或“中标挂钩一律合法”；把工程款回扣改成可履行支付。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查建设工程招投标中介合同（中介合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、失效资格认定办法或 1999 年第五十条旧罚则时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `中介合同`，子级 `建设工程招投标中介合同`。定性理由、易混切开结果（招标代理 / 施工 / 工程咨询 / 房屋中介 / 其他中介子级）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。挂靠或违法分包写停笔告知，不填可履行结构。

## 4. 主体、经营范围、利益冲突与文本版本

主体表：签约名、履行名、付款名、发票名、授权签字人。资格表：委托人施工／勘察／设计／监理资质与安全生产许可；中介人经营范围；是否夹带招标代理及第十三条两条件；同一项目是否同时服务招标人或其他投标人。版本表：正文、项目清单、廉洁承诺、服务进度考核、聊天确认；冲突并列。

## 5. 服务清单、串标红线、报酬节点与给付

服务是否限于合法信息报告与媒介撮合；是否保证中标或含灰词；完成标准是报告完成还是中标并签施工合同；固定咨询费与成功佣金是否拆开；支付是否绑中标通知书和施工合同；发票与转账；必要费用与报酬是否分列。缺口标 `G#`。不输出施工进度款口径，不输出房屋网签过户口径，不输出招标代理酬金示范文本口径。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹。串标、行贿、买标、回扣、挂靠投标不得写成可放行。强制规范只按第一百五十三条、第一百五十四条区分是否导致民事行为无效，不用失效口诀。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把招标代理工作或施工义务直接改写成“中介服务”而不问核心给付。

## 9. 谈判与签署提醒

谈判顺序：先红线（串标／保证中标／回扣／双边代理／实为施工或咨询或招标代理），再必须改（经营范围、服务清单、报酬拆分与节点、转账发票、排他、廉洁附件），最后可优化。签署提醒：双方法人公章、授权委托书、拟投标项目清单、廉洁承诺、营业执照经营范围、资质与安许复印件。不指导倒签或补假廉洁承诺。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书或效力保证，也不是招标代理、施工、工程咨询或房屋中介安排。
