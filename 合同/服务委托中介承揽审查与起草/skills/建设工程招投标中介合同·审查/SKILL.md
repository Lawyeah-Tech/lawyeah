# 建设工程招投标中介合同·审查

## 任务目标

在单一立场下，只审查 **中介合同 / 建设工程招投标中介合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查建设工程招投标中介合同（中介合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性或中标保证、招标代理整案、施工本约、工程咨询本约、房屋中介本约。

## 本类型硬闸

1. **招标代理资格切开，不是旧证门槛**：正像是**投标人**委托中介人报告招标机会或提供媒介撮合，服务限于合法信息报告与辅助。招标代理是**招标人**委托编制招标文件、组织评标。2017 年修正已删除招标代理资格认定；《工程建设项目招标代理机构资格认定办法》失效。不得写成“必须持住建部门核发的工程招标代理资格证书才能签本约”。文本若是编制招标文件、组织开评标、发中标通知书 → 负触发 本套导航的类型切开步骤。自称或夹带招标代理的，只核《招标投标法》（2017 修正）第十三条两条件（营业场所和相应资金；编制招标文件和组织评标的相应专业力量）及第十四条无隶属，并核实施条例第十一条监管分工；不得打开或复制 `工地建筑活动承包资质竣工验收→`、`房屋买卖_租赁中介合同·审查` 的 method。
2. **不得串标、不得保证中标**：串通投标、围标、行贿、非法获取或泄露标底、买标卖标、权力寻租、接触评标专家、代写商务标核心报价，一律红线删除，不改成可履行结构。灰词“搞定、协调关系、打通渠道、保证中标、内部信息、工程款回扣”必须替换或停笔。招标投标法第三十二条、第二十二条；刑法第二百二十三条。只告知，不写规避路径。
3. **报酬节点必须拆开**：中介报酬 ≠ 必要费用。成功佣金建议同时满足：委托人收到中标通知书，并与建设方正式签署施工合同；余额可再绑首次工程款拨付或实际开工。签字即付清成功佣金、把报酬写成工程款回扣或现金账外支付：必须改或红线。未促成不得请求报酬，可按约定请求必要费用。绕开中介直接订约，走第九百六十五条。比例异常高且无真实劳务轨迹：效力字段停止，不写成合法对价。
4. **与施工、咨询切开**：核心给付是施工、工期、价款、质量、竣工验收 → `工地建筑活动承包资质竣工验收→`。核心给付是工程咨询意见、可研、造价咨询、项目管理顾问，对价是固定或按工时的咨询费、不绑促成订约 → `只出可行性造价或管理咨询意见不交付测绘测试成果→`。房屋买卖或租赁居间 → `房屋买卖_租赁中介合同·审查`。禁止删掉施工或咨询条款后硬套本技能。禁止抄 `工地建筑活动承包资质竣工验收→` 或 `房屋买卖_租赁中介合同·审查` 的 method。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签正文，尚未签署，尚未成争，核心给付是投标人委托的建设工程招标信息报告或媒介撮合，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 委托人是招标人，服务是编制招标文件、组织资格审查、开评标、发中标通知书 → 本套导航的类型切开步骤；
- 工期、价款、质量、竣工验收、进度款为主给付 → `工地建筑活动承包资质竣工验收→`；
- 提供工程咨询意见、不保证促成签约、对价不绑中标 → `只出可行性造价或管理咨询意见不交付测绘测试成果→`；
- 房屋买卖或租赁居间、网签过户带看 → `房屋买卖_租赁中介合同·审查`；
- 职业介绍、婚姻介绍、技术转让中介、保险证券期货经纪、演艺经纪 → `职业中介合同·审查` / `婚姻中介合同·审查` / `技术转让中介合同·审查` / `保险_证券_期货经纪中介合同·审查` / `演绎经纪中介合同·审查`；
- 技术类合同项下技术中介本约 → `技术类合同项下技术中介本约→`；
- 无文本、本类型条件已谈妥、要出己方稿 → `建设工程招投标中介合同·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁，或串标、行贿已立案 → `或对应专项领域。` 或刑事／行政专项。

挂靠、出借施工资质投标、违法分包：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（委托人／投标人或中介人，择一）；相对方；全文及附件／项目清单／廉洁承诺版本；委托人是投标人还是招标人；服务是信息撮合还是招标代理或工程咨询；项目是否依法必须招标；有无保证中标或灰词；报酬是固定咨询费、成功佣金还是回扣；支付是否绑中标通知书和施工合同；是否同时服务同一项目其他投标人或招标人；发票与转账安排；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `建设工程招投标中介合同·起草`；已签履约 → 本套导航履约步骤；已成争或刑事立案 → 争议或专项。未签且目标是评改已有本类型文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。招标代理、施工、工程咨询、房屋中介负触发。

### 2. 主体、经营范围与招标代理条件

投标人资质与安全生产许可；中介人经营范围；同时服务冲突；挂靠停笔。

### 3. 服务正面清单与串标红线

不保证中标；不接触评标专家；不参与报价决策；灰词删除。

### 4. 报酬、必要费用与支付节点

拆固定咨询费与成功佣金；绑中标通知书和施工合同；转账发票；禁止回扣。

### 5. 独立性、保密与信息披露

同一项目排他；信息来源说明；投标策略永久保密。

### 6. 格式条款与强制规范

无核验引文则法律结论字段停止。串标、行贿、买标条款不得改成可履行。

### 7. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证中标、保留串标或回扣结构、把挂靠改成可履行投标、把招标代理或施工本约硬套本技能。
- `字段停止`：法域、动态规则、中介人是否具备第十三条专业力量、项目是否依法必须招标、报酬比例是否异常未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
