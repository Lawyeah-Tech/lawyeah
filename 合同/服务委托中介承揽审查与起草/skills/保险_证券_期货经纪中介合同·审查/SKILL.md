# 保险_证券_期货经纪中介合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》居间章及其解释、已失效保险经纪旧规、已失效期货经纪公司管理办法当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **中介合同 / 保险_证券_期货经纪中介合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查保险_证券_期货经纪中介合同（中介合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、把无牌展业／保证收益／全权委托／场外配资改成可履行结构。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **与普通中介切开**：本类型是特许经营下的法定经纪合同，叠加保险／证券／期货监管。房屋、职业、婚姻、技术、招投标、演绎中介 → 负触发对应原子。保险代理人（受保险公司委托）不是本类型；只提供分析意见、不执行指令 → `咨询服务合同·审查`。
2. **持牌准入**：中介方须持对应金融牌照（经营保险经纪业务许可证；经营证券业务许可证且含证券经纪；期货经纪核准）。营业执照不等于牌照。无牌：效力字段停止，不写“可以展业”。无牌仍要求改成可履行展业：整体停止。
3. **适当性匹配**：须有 KYC、风险承受能力评估和匹配意见。未评估不得写成已匹配。普通投资者坚持购买更高风险产品：特别书面警示并留痕；风险承受能力最低类别不得销售不匹配产品。
4. **禁止承诺收益**：删除保证收益、分担损失、垫资开户、保本、零风险、本金无忧。用户坚持保留：整体停止。
5. **禁止全权委托（证券／期货）**：不得代客户决定买卖品种、数量或价格。改成“仅限执行指令，不代为决策”。依法以自己名义进场仍属本类型，不整案走行纪。
6. **风险揭示书与双录**：须有委托人签署或电子认证的《风险揭示书》及面谈面签录音录像或配套留痕。口头告知不得写成已揭示。
7. **禁止性标的、佣金路径与利益冲突**：严禁场外配资、未经批准离岸产品、内幕交易、违规代持。佣金计算与支付主体明示；不用回扣／返点。保险犹豫期退保不付该单佣金或分期。第三方酬金须披露。客户资金走法定结算／保证金／托管路径，不进从业人员私户。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签保险经纪、证券经纪或期货经纪正文，尚未签署，尚未成争，核心给付是持牌经纪服务，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 房屋买卖或租赁居间 → `房屋买卖_租赁中介合同·审查`；
- 求职、招聘、劳务介绍 → `职业中介合同·审查`；
- 婚介、相亲 → `婚姻中介合同·审查`；
- 技术转让、专利许可撮合 → `技术转让中介合同·审查`；
- 建设工程招投标中介 → `建设工程招投标中介合同·审查`；
- 演艺／明星经纪 → `演绎经纪中介合同·审查`；
- 受保险公司委托代办保险、代表保险人 → 保险代理，转 本套导航的类型切开步骤 重新定性，不得按本类型改完；
- 只提供投资或投保分析意见、不执行指令 → `咨询服务合同·审查`；
- 概括处理事务、与金融经纪无关的一般委托 → `一般委托合同·审查`；
- 普通商事行纪（非持牌证券／期货进场） → `行纪合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `保险_证券_期货经纪中介合同·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

专业版未装本 P1 原子：输出 `unavailable`，提示，不得用邻类硬套。

无牌展业、保证收益、垫资开户、场外配资、全权委托：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（委托人／投保人／投资者侧，或持牌机构侧择一）；相对方；全文及附件版本；险种或交易品种；牌照种类与执业状态；人员登记；适当性类别与评估痕迹；是否有保证收益／全权委托／垫资；风险揭示书与双录；佣金支付主体与客户资金账户；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的佣金比例、账户、期限用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验持牌、适当性、禁止承诺收益、禁止全权委托、中介章、格式条款、第 153 条效力；`search_practiced` 只补审查反例；`search_template` 只借栏目结构。不虚构案件系统。

`search_law` 对上述法律结论为 required 级：不可用时不拒绝执行，只停止效力字段。返回已失效《合同法》居间章或其解释、已失效保险经纪旧规、已失效期货经纪公司管理办法时记为噪声，不得写入 `L#`。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `保险_证券_期货经纪中介合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有本类型文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。普通中介、保险代理、投资咨询、一般委托、普通行纪负触发。证券期货以自己名义进场不改走行纪。

### 2. 主体与持牌

签约名、履行名、付款名、发票名分列。牌照与人员登记未核：字段停止。不写可以展业。

### 3. 适当性、风险揭示与双录

评估、匹配意见、揭示书签署、双录留痕分列。口头不得写成已揭示或已匹配。

### 4. 给付、指令与全权委托

保险经纪写清方案、选择保险人、办理投保、协助索赔。证券／期货写清执行指令、报告、结算。全权委托红线删除。

### 5. 佣金、资金路径与禁止性标的

佣金计算与支付主体明示。客户资金不进私户。场外配资、保证收益、垫资停笔。

### 6. 格式条款与强制规范

无核验引文则法律结论字段停止。无牌／承诺收益／全权委托不改成可履行。

### 7. 违约、解除与争议

误导销售、越权交易须有可执行后果。牌照被撤销可即时解除。不选定唯一法院充作意见。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把无牌展业／保证收益／垫资／配资／全权委托改成可履行结构。
- `字段停止`：法域、动态规则、牌照、人员登记、适当性评估、双录细则未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
