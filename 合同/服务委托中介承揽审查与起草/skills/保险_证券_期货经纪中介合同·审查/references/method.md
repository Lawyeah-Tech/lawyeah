# 审查方法（锁定 中介合同 / 保险_证券_期货经纪中介合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制房屋中介跳单／产调／网签过户主路径、施工挂靠或劳动试用期节点。

定性校验：标题、核心给付与本类型一致才继续；普通中介、保险代理、投资咨询、一般委托、普通商事行纪明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受或唯一必得佣金。

`search_law` 返回已失效《合同法》居间章及其解释、已失效《保险经纪机构监管规定》2015 本、已失效《期货经纪公司管理办法》、已失效《保险经纪人管理规定（试行）》时记为噪声，不得写入 `L#`。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。房屋中介、保险代理或咨询范本只证明是另一类型，不得当作本类型范本。

知识库纠正（不回写双文件）：

- `基本面.md` 写无牌“可能被认定为无效”：不得写成必然无效。法律、行政法规禁止无证经营证券经纪或期货经纪（证券法第一百二十条第四款；期货和衍生品法第六十三条第三款），效力按民法典第一百五十三条和合同编通则解释第十六条核验后再落字段。本任务停止“可以展业”，不宣告整份合同当然无效。
- `基本面.md` 写“银保监会”：保险经纪许可查询走国家金融监督管理总局；证券／期货走证监会。不得把已更名机关写成现行签发机关。
- `基本面.md`／`框架.md` 把证券期货“以自己名义”或“全权委托极易引发纠纷”写成可谈优化：证券法第一百三十四条、期货和衍生品法第六十六条是法律禁止，红线删除，不是可优化。依法以自己名义进场是法定经纪形态，不负触发 `行纪合同·审查`。
- `框架.md` “基于委托人利益最大化推荐产品”：保险经纪可写忠实推荐；证券／期货经纪不得据此改成可代为决策。
- `基本面.md` 写保险经纪“受投保人委托”：监管规定亦称委托合同，核心给付仍是基于投保人利益的保险中介，不因此负触发 `一般委托合同·审查`。
- `基本面.md` “违规承诺无效”：承诺收益、分担损失、垫资开户条款应删除或标红线；整份经纪合同不当然因此全部无效。

| 只提供投资或投保分析意见，不执行投保或交易指令 | 咨询服务 | 负触发 `咨询服务合同·审查` |
| 概括处理与金融经纪无关的事务 | 一般委托 | 负触发 `一般委托合同·审查` |
| 以自己名义从事普通货物或商品贸易，自担本约权利义务，且非持牌证券／期货进场 | 行纪 | 负触发 `行纪合同·审查` |

支持切开的规范（法律结论须运行时复核）：

- 民法典第九百六十一条：中介是报告机会或提供媒介，委托人支付报酬。保险经纪叠加该定义。
- 保险经纪人监管规定第二条：保险经纪人基于投保人利益，为投保人与保险公司订立保险合同提供中介服务并依法收取佣金。
- 保险代理人监管规定第二条：保险代理人根据保险公司的委托，向保险公司收取佣金，在授权范围内代为办理保险业务。
- 证券法第一百二十条：证券经纪须核准；除证券公司外任何人不得从事证券经纪。第一百三十四条禁止全权委托。
- 期货和衍生品法第六十三条：期货经纪须核准。第六十六条：以自己的名义为交易者进行期货交易，交易结果由交易者承担；不得接受全权委托。该“以自己的名义”是法定经纪形态，不是普通行纪转出理由。

3. 风险表只保留识别依据和删除／转出口径。

## 节点 2　主体与持牌

### 2.1 主体表

建表：签约名、履行名、付款名、发票名、授权签字人。名称不一致不自动合并。机构委托人须能识别受益所有人／实控人穿透字段；未闭合标 `G#`，不写成已完成反洗钱。

口头“我们有牌”不得写成已持牌。禁入人员（法律禁止进入证券／期货市场的人员、被限制开户对象）作为委托人：该签署能力字段停止。

### 2.2 持牌准入（硬闸）

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 无许可证、无监管官网查询页 | 字段停止；修改句要求作为附件 | 可以展业 |
| 只有营业执照或普通经纪备案 | 执照／房产经纪备案不等于金融牌照 | 已完成准入 |
| 牌照业务范围与文本给付不符（如只有保险经纪却做证券开户） | 红线；超范围部分停止 | 一张牌照覆盖全部金融经纪 |
| 承办人未执业登记 | 字段停止；保险经纪人监管规定第六十一条禁止委托未登记个人 | 个人签字即可约束机构 |

修改句：

「本合同签署前，乙方应向甲方出示并作为附件一：国务院金融监督管理机构／国务院证券期货监督管理机构颁发的、与本合同业务范围一致的有效许可证或官方查询页（保险经纪为经营保险经纪业务许可证；证券经纪为经营证券业务许可证且业务范围含证券经纪；期货经纪为期货经纪业务核准文件）。附件二：承办本单从业人员的执业登记信息。未核验前，不得主张已具备展业与签署条件。乙方许可证被撤销、注销或被责令停止该业务的，本合同相应业务立即终止，双方按已发生合法服务结算，乙方不得继续接受新指令或新投保委托。」

部门规章持牌义务不当然导致民事合同全部无效（解释第十六条）。证券法、期货和衍生品法的禁止经营条款是法律层规范：无核验引文不得写“必然无效”，也不得写“可以展业”。

## 节点 3　适当性、风险揭示与双录

### 3.1 适当性匹配（硬闸）

支持依据：证券法第八十八条；证券期货投资者适当性管理办法第三条、第十九条；期货交易所管理办法第七十七条（会员适当性督促）。

审查清单，缺一项则该字段不得写成已闭环：

1. 委托人类别：专业投资者或普通投资者。
2. 风险承受能力评估结果与日期。
3. 产品或服务风险等级。
4. 匹配意见：匹配／不匹配／投资者主动要求并已警示。

| 文本写法 | 动作 |
| --- | --- |
| “甲方已充分了解风险，乙方无需评估”且无评估附件 | 必须改。不得写成已匹配 |
| 向风险承受能力最低类别销售更高风险产品 | 红线删除 |
| 普通投资者主动要求购买更高风险产品，但无特别书面警示 | 必须补书面警示和留痕，否则不得提供 |
| 保险经纪文本完全不提投保需求与方案比较 | 必须改：写明基于投保人利益筛选，并披露是否从保险公司取酬 |

修改句：

「乙方应在提供服务前完成对甲方的了解客户程序，形成书面风险承受能力评估和适当性匹配意见，作为附件三。评估结果与本合同项下产品或服务不匹配的，乙方不得主动提供。甲方不属于风险承受能力最低类别、经乙方书面告知不适合后仍书面坚持接受更高风险产品或服务的，乙方须就超出承受能力的风险作特别书面警示并留存甲方确认；甲方拒绝接受评估或提供虚假信息的，乙方应拒绝提供相应服务。未完成评估与匹配前，不得主张甲方已适当。」

最强反方：机构主张“签了揭示书即已适当”。现有依据不支持把签署揭示书单独写成已履行适当性。

《金融机构产品适当性管理办法》施行日为 2026-02-01。拟签署日在施行前，不得把该办法当现行依据。

### 3.2 风险揭示书与双录（硬闸）

支持依据：期货交易管理条例第二十四条（事先出示风险说明书并经客户签字）；适当性管理办法第四十一条指向录音录像或配套留痕。

| 文本写法 | 动作 |
| --- | --- |
| 主协议生效，附件揭示书“以后补签” | 必须改。揭示书未签，生效条件未成就 |
| “乙方已口头说明，甲方不得再主张未揭示” | 必须改。口头不得写成已揭示 |
| 无双录或电子留痕约定 | 必须补面谈、面签、录音录像或配套留痕 |

修改句：

「本合同在甲方签署《风险揭示书》（附件四）且乙方完成面谈、面签及录音录像或监管允许的配套留痕后方可生效。口头说明、网络勾选或弹窗单独不视为已完成风险揭示。揭示书应明示：金融产品收益不确定、可能损失本金、乙方不对收益或损失作出承诺。」

## 节点 4　给付、指令与全权委托

### 4.1 给付须可核验

保险经纪分列：拟定投保方案、选择保险公司、办理投保手续、协助索赔。协助不是代保险公司承保。

证券／期货经纪分列：代理执行交易指令、信息报告、账户管理、结算与资金清算。执行指令不是代为决策。

禁止只写“提供全方位财富管理／保险规划”而无指令方式和授权边界。

### 4.2 禁止全权委托（硬闸）

支持依据：证券法第一百三十四条；期货和衍生品法第六十六条。

| 文本写法 | 动作 |
| --- | --- |
| 甲方授权乙方全权决定买卖品种、数量、价格或交易策略 | 红线删除 |
| “账户交给客户经理操作，收益平分” | 红线；同时触发承诺收益闸 |
| 从业人员私下接受委托 | 红线。期货和衍生品法第六十九条禁止私下接受客户委托 |
| 指令方式空白 | 必须补：书面、电子或录音电话，并设定身份验证；按指令先后顺序执行 |

修改句：

「乙方仅按甲方下达的具体指令执行证券／期货交易或办理投保手续，不得接受全权委托，不得代甲方决定买卖品种、数量、价格或投保方案的最终选择。指令须通过本合同约定的【书面／电子系统／录音电话】下达，并完成身份验证。乙方或其从业人员不得私下接受甲方委托。因市场波动造成的盈亏由甲方承担；因乙方违背指令、擅自交易或从业人员越权操作造成的直接损失，由乙方承担。」

保险经纪可约定代为办理投保手续，但投保方案的最终确认权留在委托人；不得改成保险人代理。

## 节点 5　佣金、资金路径与禁止性标的

### 5.1 佣金路径与利益冲突

支持依据：保险经纪人监管规定第四十八条、第四十九条；框架禁止回扣／返点。

| 文本写法 | 动作 |
| --- | --- |
| 佣金比例、支付主体空白 | 必须改；数字用 `【待填】` |
| 使用回扣、返点、好处费 | 必须改为“佣金”，并列明支付主体 |
| 保险经纪未披露是否从保险公司取酬 | 必须披露 |
| 保单生效即付全额佣金，犹豫期退保不退佣 | 必须改：犹豫期内退保不支付该单佣金，或按已过犹豫期分期 |

修改句：

「乙方因本合同收取的对价称为佣金，计算方式为【保费／成交金额的待填％，或每笔待填元】，由【保险公司／甲方】支付。乙方不得在约定佣金之外索取回扣、返点或其他利益。乙方从保险公司或其他第三方取得报酬的，应在推荐前书面告知甲方。人身保险合同在犹豫期内解除的，乙方就该单不得请求佣金；已收取的应在【待填】日内退还支付方。」

### 5.2 客户资金不进私户

证券客户交易结算资金、期货保证金须走法定存管／结算路径。保费解付按与保险公司的约定时限。禁止转入从业人员个人账户或个人收款码。用户坚持私户代收：整体停止。

修改句：

「甲方交易结算资金、期货保证金或应解付保费仅可转入监管规定的客户交易结算资金账户、期货保证金账户或保险公司指定账户。禁止转入乙方从业人员个人账户、个人收款码或与许可业务无关的一般结算账户。佣金与客户资金分户收付，乙方不得以代收资金抵扣佣金。」

### 5.3 禁止性标的

非法场外配资、未经批准离岸金融产品、内幕交易、违规代持：只告知，不改成可履行结构。用户坚持：整体停止。

## 节点 6　格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 禁止承诺收益（硬闸）

支持依据：证券法第一百三十五条；期货和衍生品法第七十八条；期货交易管理条例第二十四条。

| 文本写法 | 动作 |
| --- | --- |
| 保证收益、保本、零风险、本金无忧、分担亏损、垫资开户 | 红线删除 |
| “预期收益仅供参考”夹在附件小字 | 必须加黑提示；预期不得改成承诺 |
| 抽屉协议或聊天确认保本 | 与正文并列；仍不得改成可履行保本 |

修改句：

「删除任何保证收益、保证本金、零风险、本金无忧、分担损失或垫资开户的表述。乙方不对甲方证券买卖、期货交易或保险产品的收益作出承诺，也不赔偿市场波动造成的损失。本条加黑提示。甲方确认：过往业绩不构成对未来收益的保证。」

用户坚持保留保本或垫资：整体停止。

### 6.2 格式条款

为重复使用而预先拟定、订立时未与对方协商。持牌机构不得仅以“这次没用过第二次”否认。依据示范文本制作，不当然排除格式条款。

审查：免责、全权委托残留、管辖／仲裁、自动续期等异常条款是否有足以引起注意的标识（第四百九十六条）。小字、夹在附件、仅网络勾选：不得写成已尽提示。提供方对其已尽提示或说明承担举证责任。

### 6.3 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的、是否仅行政管理、是否只规制履行行为（第一百五十三条；解释第十六条）。禁止用已失效“效力性／管理性”口诀。无牌展业、保证收益、全权委托、配资：不改写成有效履行。

## 节点 7　违约、解除与争议

1. 误导销售、隐瞒除外责任、虚假陈述、越权交易：可约定免酬、解除并赔偿直接损失。只有“依法承担违约责任”视为必须改。
2. 构成违约不等于当然解除。法定解除路径只点名催告或目的不能实现，不在本任务作出已解除结论。
3. 违约金不是必得金额。修改句避免“不得调整”或“按本金必得”。
4. 乙方许可证被撤销、注销或被责令停业：甲方有权立即解除并要求结算。
5. 争议解决：出现仲裁条款，不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核，修改句改成单一仲裁机构或单一法院连结点。可建议金融行业协会调解作为可选前置，不得写成强制且剥夺起诉或仲裁。专属管辖可能：只标红旗，不选定唯一法院充作法律意见。
6. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

| 步 | 动作 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题用保险经纪服务协议／证券经纪合同／期货经纪协议，不用普通居间或保险代理混称；主体全称与牌照名称一致；鉴于不写保证收益 | 标题或主体修改句 |

| 配套 | 禁止全权委托；禁止承诺收益；误导／越权后果；牌照丧失解除 | 可执行后果句或删除句 |
| 尾部 | 机构公章或备案业务专用章；揭示书、适当性证明、授权委托书、双录确认入附件 | 生效与附件修改句 |

| 常见问题 | 无牌展业；保证收益；全权委托；利益冲突不披露；犹豫期仍吃满佣 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条／款／附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（无牌展业、保证收益、全权委托、配资／垫资、资金进私户、倒签）；
- `必须改`：可谈但签署前要落句（适当性附件、揭示书与双录、佣金支付主体、利益冲突披露、犹豫期退佣）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级资金进入非法定账户且用户拒绝升级：停止“可以签署”建议。
