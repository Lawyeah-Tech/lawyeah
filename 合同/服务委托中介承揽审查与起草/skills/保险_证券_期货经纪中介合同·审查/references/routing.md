# 边界与路由

本技能只审查 **中介合同 / 保险_证券_期货经纪中介合同** 的待签文本。中文展示名是「审查保险_证券_期货经纪中介合同（中介合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 房屋买卖或租赁居间、带看撮合 | `房屋买卖_租赁中介合同·审查` |
| 求职、招聘、劳务介绍 | `职业中介合同·审查`。P1：专业版未装则 `unavailable`，提示，不得用本技能硬套 |
| 婚介、相亲、征婚服务 | `婚姻中介合同·审查`。P1；未装则 `unavailable` |
| 技术转让、专利许可撮合 | `技术转让中介合同·审查`。P1；未装则 `unavailable` |
| 建设工程招投标撮合 | `建设工程招投标中介合同·审查`。P1；未装则 `unavailable` |
| 演艺人员经纪、档期或片酬撮合 | `演绎经纪中介合同·审查`。P1；未装则 `unavailable` |
| 受保险公司委托代办保险、代表保险人 | 保险代理。转 本套导航的类型切开步骤 重新定性，不得按本类型改完 |
| 只提供投资或投保分析意见，不执行指令 | `咨询服务合同·审查` |
| 概括处理与金融经纪无关的事务 | `一般委托合同·审查` |
| 普通商事行纪，非持牌证券／期货进场 | `行纪合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `保险_证券_期货经纪中介合同·起草` |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |
| 专业版未收录本 P1 原子 | `unavailable`，提示，不得用邻类硬套 |

证券／期货经纪正文里夹带一小段投资顾问建议：专条交接 `咨询服务合同·审查`；指令执行、结算、保证金、禁止全权委托和禁止承诺收益条款可继续审。用户坚持本技能把保险代理、投资咨询或普通中介整案改完：`目标停止`。
