# 审查方法（锁定 服务合同 / 行纪合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制中介跳单/产调/经纪备案、委托任意解除主路径或经销买断价保节点。

定性校验：标题、核心给付与本类型一致才继续；以委托人名义代理、只撮合、买断再转售、诉讼代理、纯劳务、广告发布明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受或唯一必得报酬。

`search_law` 返回已失效《合同法》行纪章（第 414–423 条）及其解释、已失效《关于对外贸易代理制的暂行规定》、已失效《经纪人管理办法》时记为噪声，不得写入 `L#`。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。GF—2000—1101 处合同法时代，只借栏目。委托或中介范本只证明是另一类型，不得当作本类型范本。

知识库纠正（不回写双文件）：

- `基本面.md` “任意解除：参照委托”：第 960 条是**参照适用**，不是当然适用第 933 条。不得写成委托人可无偿随时解除。有偿行纪解除应赔偿直接损失和合同履行后可以获得的利益；已与第三人成交的部分不得随意推翻。
- 失效《合同法》第 423 条写“适用”委托合同：现行第 960 条是“参照适用”，不得把旧条号写入 `L#`。
- `框架.md` “排除法定先赔并改由委托人承担”：第 958 条允许另有约定，但排除必须醒目，且必须打通委托人取得债权或取得追索所需文件的路径。禁止“一律由委托人直接向第三人主张、行纪人免责”而无追索路径。
- `框架.md` “货款视为行纪人所有”：与行纪本质冲突，应改为代收后转付。
- 实务称介入权“须尚未处理完毕”或援引瑞士债法主张紧急处分免补差：前者不是第 956 条要件，只作审查提醒；后者不得写成中国现行规则。第 954 条合理处分与第 955 条价格规则分列。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。标题写“代理协议”的，先看是否以自己名义从事贸易：是则按行纪审，不是则切开。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 以自己名义买入或卖出、寄售寄租、商场代销，委托人付酬，货权一般仍归委托人 | 本类型 | 正触发 |
| 以委托人名义对外签约、开委托人抬头发票、概括处理事务 | 一般委托 | 负触发 `一般委托合同·审查` |
| 只报告订约机会或提供媒介，自己不成交一方 | 中介 | 负触发 `房屋买卖_租赁中介合同·审查` 或对应中介原子 |
| 货过户到对方、滞销不退、存货风险归对方、差价归对方 | 经销买卖 | 负触发 `或其他中介原子；买断再转售存货风险归己→负触发` |
| 版面投放、广告发布 | 广告发布 | 负触发 `广告发布合同·审查` |
| 广告代理排期、媒介购买但无商品贸易 | 广告代理 | 负触发 `广告代理合同·审查` |
| 诉讼代理、代为出庭或签署诉讼文书 | 一般委托 | 负触发 `一般委托合同·审查`；不得硬套行纪 |
| 纯劳务、计时服务、无商品贸易 | 劳务或对应服务原子 | 负触发，不得硬套行纪 |

支持切开的规范（法律结论须运行时复核）：

- 第 951 条：行纪是以自己名义为委托人从事贸易活动，委托人支付报酬。
- 第 919 条：委托是处理委托人事务。
- 第 961 条：中介是报告机会或提供媒介。
- 第 595 条：买卖是转移标的物所有权换价款——买断走 `或其他中介原子；买断再转售存货风险归己→负触发`。
- 第 925 条：隐名委托在第三人订立时知道代理关系时，合同可直接约束委托人与第三人——与第 958 条行纪人对第三人自负切开。隐名委托不当然适用行纪的费用自担、介入权、价格规则。

### 1.2 加载协议（硬闸）

本技能已锁定 **服务合同 / 行纪合同**。只打开 `references/基本面.md` 与 `references/框架.md`。禁止读其他子目录，禁止为对照再开第二类。

### 1.3 自己名义 + 贸易 + 报酬（硬闸）

| 文本写法 | 本任务动作 | 修改句方向 |
| --- | --- | --- |
| 乙方以自己名义按限价出售/买入，甲方向乙方付酬，货权售出前归甲方 | 正触发，留下本类型 | 首部写明“行纪，不是委托、中介或经销” |
| 乙方有权以甲方名义签署对外买卖合同、使用甲方合同章或开甲方抬头对外发票 | 负触发委托，或必须改：删除代签 | 「乙方以自己的名义与第三人订立合同，无权以甲方名义签署对外贸易合同。」 |
| 乙方只介绍买家/卖家，本约由甲方与第三人直接签署 | 负触发中介 | 不按行纪改完 |
| 货物过户到乙方、滞销不退、乙方自担存货 | 负触发经销 | 不按行纪减责 |
| 诉讼代理、纯劳务、广告发布而称行纪 | 负触发对应原子 | 不得硬套行纪费用自担和介入权 |

修改句（正触发首部）：

「本合同为行纪合同。乙方以自己的名义，为甲方从事【买入 / 卖出 / 寄售】【品名】的贸易活动。乙方不是甲方的代理人，也不是仅报告订约机会的中介人。乙方与第三人订立的合同，由乙方直接享有权利、承担义务。甲方按本合同向乙方支付报酬。未约定买断的，售出前委托物所有权归甲方。」

最强反方：相对方主张已构成委托、表见代理或买断，从而主张费用由委托人预付、或存货风险已转移。修改句必须收回代签和买断措辞。用户坚持保留代签或买断主轴：负触发，不填本类型十节实体结论。

### 1.4 违禁品 / 无证特许停笔（硬闸）

加载后或定性中出现：走私、禁止流通物；烟酒、药品、粮食收购、拍卖、进出口等须许可而未出示许可；以行纪为名归集资金、许诺刚兑。

动作：

1. 交付告知：行纪事务违法的，合同可能因第 153 条无效。不得改写成可履行的无证特许或资金盘结构。
2. 不写可履行的品类替换伪装、假许可路径或体外资金循环。
3. 风险表只保留识别依据和删除/转出口径。
4. 用户坚持“改到能签且仍做这些事”：整体停止。

## 节点 2　主体、贸易资质与文本版本

### 2.1 主体表

建表：签约名、履行名、付款名、发票名、授权签字人。名称不一致不自动合并。超市代销须把店铺经营公司列为行纪人，不得只写柜台或联营柜组。

委托人须对拟出卖货物有处分权。共有、抵押、涉嫌赃物未闭合：该处分能力字段停止，不写成“可以发货”。口头“我们老板同意了”不得写成已授权。

共同行纪：对委托人的责任写清连带或按份，不得默认按份。

### 2.2 贸易资质

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 进出口而无对外贸易经营者备案/许可痕迹 | 字段停止；修改句要求作为附件 | 可以对外成交 |
| 烟酒、药品、粮食收购、拍卖等特许无证 | 停笔（节点 1.4） | 改成日用品寄售即可放行 |
| 只有营业执照 | 执照不等于该贸易资格 | 已具备全部贸易资质 |

修改句：

「本合同签署前，乙方应向甲方出示并作为附件：从事本次【进出口 / 特许品类】所需的现行有效许可或备案查询页。未核验前，不得主张已具备对外成交条件。」

部门规章或许可管理规范不当然导致民事合同无效（解释第 16 条）。本任务只停止“可以对外成交”表述，不宣告合同当然无效；无证特许贸易本身按节点 1.4 停笔。

## 节点 3　对第三人自负权利义务（硬闸）

支持依据：第 958 条。

条文要点：行纪人与第三人订立合同的，行纪人对该合同直接享有权利、承担义务。第三人不履行义务致使委托人受到损害的，行纪人应当承担赔偿责任，但是行纪人与委托人另有约定的除外。

| 文本写法 | 动作 |
| --- | --- |
| 第三人违约一律由委托人直接向第三人主张，行纪人免责，且不移交合同、单据 | 红线。现有依据不支持在无追索路径时免除第 958 条赔偿 |
| 排除先行赔偿，但约定移交对外合同、发票、物流单据并协助让与债权或共同追索 | 可保留，须加黑提示；修改句把文件清单、时限写死 |
| 约定担保行纪 / 保付 | 可保留；写清保付范围、期限和追偿 |
| 沉默 | 必须改：补先行赔偿再追索，或按上列排除路径闭合 |

修改句（默认路径）：

「乙方与第三人订立的合同，由乙方直接享有权利、承担义务。因第三人不履行致使甲方受到损害的，乙方应在知道或应当知道该不履行后【待填】日内，向甲方赔偿相应货款或差价损失，再由乙方自行向第三人追索。」

修改句（排除路径，须同时具备）：

「双方书面排除乙方对甲方的先行赔偿义务的，必须同时满足：（1）本条以加黑字体由甲方单独签认；（2）乙方于成交后【待填】日内向甲方移交对外合同、发票、物流单据、对账记录及追索所需全部文件；（3）乙方协助甲方取得对第三人的债权或共同追索地位。禁止约定“一律由甲方直接向第三人主张、乙方免责”且不提供追索路径。」

最强反方：行纪人主张第 958 条“另有约定除外”已覆盖免责。现有依据支持另有约定，但现有依据不支持把无追索路径的笼统免责写成已闭合。用户坚持保留免责无追索：整体停止。

进出口“代理”却由国内委托人直接对境外买方负责、又无书面转结构：标红旗；修改句要求对外合同当事人仍是行纪人，或另签可识别的权利义务转移，不得两头落空。

## 节点 4　价格指示（硬闸）

支持依据：第 955 条。

| 文本写法 | 动作 |
| --- | --- |
| 无指定价、无限价、允许“自行定价，差价即报酬” | 红线。补书面限价表；溢价无约定归委托人 |
| 有指定价，但低卖高买无须同意、无须补差 | 必须改。未经同意且未补差，对委托人不发生效力 |
| 有特别指示，又写“市场波动时可自行突破” | 必须改。特别指示不得违背；突破须成交前书面到达 |
| 溢价分成未写清 | 必须改：无约定且依第 510 条不能确定的，利益归委托人；加酬须书面 |

修改句：

「甲方以附件限价表或价格指示函指定卖出最低价 / 买入最高价，变更须在成交前以书面到达乙方。乙方低于指定价卖出或高于指定价买入的，须事先取得甲方书面同意；未经同意且未在交割前补足差额的，该买卖对甲方不发生效力，由此造成的货物或价款损失由乙方承担。乙方高于指定价卖出或低于指定价买入的利益，除书面约定增加报酬外，归甲方所有。甲方作出特别价格指示的，乙方不得违背。」

禁止编造限价数字。指示函作为变更价格的唯一书面形式时，须列入附件并写明到达时点。

最强反方：行纪人主张“市价下跌必须甩货”或“差价习惯上就是佣金”。第 954 条合理处分不等于当然豁免第 955 条；无约定时现有依据不支持把溢价写成行纪人报酬。

## 节点 5　费用默认行纪人负担与报酬（硬闸）

支持依据：第 952、959 条。对照第 921 条（负向）。

### 5.1 费用

| 文本写法 | 动作 |
| --- | --- |
| 费用沉默，或只写“实报实销”“按委托惯例” | 必须改。沉默时现有依据支持由行纪人负担；现有依据不支持按第 921 条要求委托人预付或偿还 |
| 要由委托人承担仓储、运费、关税、保险 | 必须书面逐项列举项目、计算方式和上限；未列项目不得扣货款 |
| 垫付利息未写 | 要报销利息必须另写，数字用 `【待填】` |

修改句：

「除本合同附件《费用清单》逐项列明并由双方签章确认的【仓储 / 运费 / 关税 / 保险】外，乙方处理委托事务支出的费用由乙方自行负担，不得事后向甲方报销，也不得从货款中扣收。未列入该附件的项目，不适用委托合同关于委托人预付或偿还费用的规则。」

### 5.2 报酬

部分完成应付相应报酬。可约定溢价加酬，但无约定时溢价归委托人（回链节点 4）。禁止编造佣金比例。

修改句：

「甲方应就乙方已完成的对应部分向乙方支付报酬：按成交额【待填】% 或每笔人民币【待填】元，于【对账确认 / 货款转入专户】后【待填】日内支付。乙方未完成的部分不得请求该部分报酬。甲方逾期未支付到期报酬的，适用节点 7 留置，不得扩及无关财产。」

## 节点 6　介入权、格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 介入权（硬闸）

支持依据：第 956 条。

| 文本写法 | 动作 |
| --- | --- |
| 允许自买自卖，但商品无公开市场定价 | 红线删除。无市价不得自买自卖 |
| 委托人已写禁止介入，仍保留自买自卖 | 必须改：删除或改为事前书面豁免 |
| 沉默且商品可能有市价 | 必须改：单独勾选允许或禁止；允许的须事后通知并按市场价 |
| 大宗、定制或关联交易未关闭介入权 | 必须改：关闭，或事前披露并按可核验市场价 |

修改句：

「仅当委托商品具有公开市场定价，且甲方未在本合同或事后书面表示反对时，乙方才可以自己作为买受人或出卖人，成交后【待填】日内书面通知甲方，并仍可请求约定报酬。无市场定价、甲方禁止、或属于大宗 / 定制 / 关联交易的，乙方不得自买自卖。未经允许自买自卖的，甲方可拒收该结果并要求返还货物或价款。」

最强反方：行纪人主张第 956 条是形成权，合同沉默即已允许。现有依据支持“除委托人有相反意思外”，但现有依据不支持在无市场定价时行使介入权。本任务不把实务“须尚未处理完毕”写成法定要件，可提醒已对外成交后再自买自卖应先向委托人披露。

### 6.2 格式条款

为重复使用而预先拟定、订立时未与对方协商。从事经营活动的行纪人不得仅以“这次没用过第二次”否认。依据示范文本制作，不当然排除格式条款。

审查：免责、先赔排除、任意定价、介入权、管辖/仲裁等异常条款是否有足以引起注意的标识，以及是否按要求说明（第 496 条；解释第 10 条）。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在附件 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

提供方对其已尽提示或说明承担举证责任。第 497 条无效情形、第 498 条不利解释：只在核验后作为修改理由，不代替修改句。

### 6.3 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的、是否仅行政管理、是否只规制履行行为（第 153 条；解释第 16 条）。禁止用已失效“效力性/管理性”口诀代替解释第 16 条。违禁品、无证特许、资金盘：不改写成有效履行。

## 节点 7　货权、专户、留置与保管（硬闸）

支持依据：第 953、957、959 条。

### 7.1 货权与专户

| 文本写法 | 动作 |
| --- | --- |
| 货物先过户到行纪人名下却不谈买卖价款，仍称行纪 | 红线。不过户，或负触发改走经销并谈清价格与退货 |
| “货款视为行纪人所有” | 红线改为代收后转付 |
| 货款进入纪人一般结算户或个人账户 | 红线改为双方确认的专用结算账户，定期对账 |
| 包装、仓单、保险未标明委托人 | 必须改，降低被行纪人债权人查封的风险 |
| 未约定买断，却写滞销由委托人自负、不得退货 | 必须改：卖不掉应退还委托人；退货运费和残次认定另写 |

修改句：

「寄售期间委托物所有权归甲方。包装、仓单、保险受益人应标明甲方。乙方不得以委托物为自己融资或设定担保。代收货款须进入双方确认的专用结算账户，禁止进入乙方个人账户或与乙方自有资金混同。乙方应于【待填】日内将对账单、对外合同及结算单回传甲方。未约定买断的，超过【待填】日仍未售出的货物应退还甲方。」

用户坚持货款视为行纪人所有或货物空过户仍称行纪：整体停止。

### 7.2 留置、受领与保管

逾期不支付报酬，行纪人对委托物享有留置权，另有约定除外。留置范围限于对应未付报酬（及书面约定的垫付费用）。不得扣留与报酬无关的委托人其他财产。委托人急需取货的，可约定提供其他担保后放货。

买入委托物，委托人应及时受领；拒绝受领或不能卖出/撤回出卖经催告，行纪人可提存。占有期间应妥善保管；交付时有瑕疵或易腐，按第 954 条处分，并及时通知。

修改句：

「甲方逾期未支付到期报酬的，乙方可就占有的相应委托物行使留置权；不得扣留与该未付报酬无关的甲方其他财产。甲方提供相当于未付报酬金额的其他担保后，乙方应在【待填】日内放货。乙方占有委托物期间应妥善保管，除不可归责于乙方的事由外，毁损灭失由乙方承担。」
