# 行纪合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》行纪章及其解释、已失效《关于对外贸易代理制的暂行规定》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **服务合同 / 行纪合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文名必须是「审查行纪合同（服务合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、把中介/委托/经销/广告发布整案改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **自己名义 + 贸易 + 报酬**：行纪人以自己的名义为委托人从事贸易活动，委托人支付报酬。以委托人名义代理 → 负触发 `一般委托合同·审查`；只撮合不成交一方 → 负触发 `房屋买卖_租赁中介合同·审查` 或其他中介原子；买断再转售、存货风险归己 → 负触发 `或其他中介原子；买断再转售存货风险归己→负触发`。诉讼代理、纯劳务、广告发布不是贸易，不得硬套。修改句须写明自己名义、贸易范围和报酬，并收回代签或买断措辞。
2. **对第三人自负权利义务**：行纪人与第三人订立的合同，由行纪人直接享有权利、承担义务。第三人不履行致委托人损害的，行纪人应赔偿，另有约定除外。禁止“一律由委托人直接向第三人主张、行纪人免责”而无追索路径。
3. **价格指示**：低于指定价卖出或高于指定价买入，未经同意且未补差，对委托人不发生效力。溢价利益无约定归委托人。特别指示不得违背。
4. **费用默认行纪人负担**：与委托“委托人预付费用”相反。要报销必须书面逐项约定。费用沉默不得写成可按委托报销。
5. **介入权**：仅市场定价商品且委托人未反对时，行纪人可自买自卖并仍请求报酬。无市价或委托人禁止：不得自买自卖。
6. **留置与货权**：逾期不付报酬可留置委托物。寄售期间所有权一般仍归委托人；货款进专户防挪用。违禁品/无证特许商品：停笔。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签行纪、寄售或代销正文，尚未签署，尚未成争，核心给付是以自己名义从事贸易并收取报酬，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 以委托人名义签署对外合同、开委托人抬头发票、概括处理事务 → `一般委托合同·审查`；
- 只报告订约机会或提供媒介，自己不成交一方 → `房屋买卖_租赁中介合同·审查`（房屋买卖/租赁中介）或对应中介原子；不得删撮合条款后硬套本技能；
- 货过户到对方、滞销不退、存货风险归对方 → `或其他中介原子；买断再转售存货风险归己→负触发`；
- 广告发布、版面投放 → `广告发布合同·审查`；广告代理主轴 → `广告代理合同·审查`；
- 诉讼代理、纯劳务、人事用工 → `一般委托合同·审查` 或劳动/对应服务原子，不得按行纪审；
- 无文本、本类型条件已谈妥、要出己方稿 → `行纪合同·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

违禁品、无证特许商品、以行纪为名做资金盘：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（委托人侧或行纪人侧择一）；相对方；全文及附件/寄售单/限价表版本；是否以自己名义对外成交；贸易品类与是否特许或禁止流通；指定价或限价；费用是否书面逐项；介入权是否禁止；货款账户；货权与过户；贸易资质或进出口权痕迹；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的报酬比例、限价、账户、期限用 `【待填】`，不编造。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`基本面.md` 中“任意解除：参照委托”不得写成无偿任意解除。`框架.md` 中“排除法定先赔”必须同时打通追索路径。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `行纪合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有行纪文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。委托代签、中介撮合、经销买断、广告发布、诉讼代理、纯劳务负触发。

### 2. 主体与贸易资质

签约名、履行名、付款名、发票名分列。进出口权、特许许可未核：字段停止。违禁品或无证特许：停笔。

### 3. 对第三人自负与追索路径

不得写成委托人直接对第三人主张且行纪人免责、又无文件移交。

### 4. 价格指示与溢价归属

低卖高买须同意或补差；溢价无约定归委托人。

### 5. 费用自担与报酬

费用沉默由行纪人负担。部分完成应付相应报酬。

### 6. 介入权、格式条款与强制规范

无市价或委托人禁止不得自买自卖。无核验引文则法律结论字段停止。

### 7. 货权、专户、留置与保管

寄售所有权一般仍归委托人。货款进专户。逾期报酬才可留置委托物。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把违禁品/无证特许、资金盘、货物空过户或“免责无追索”改成可履行结构。
- `字段停止`：法域、动态规则、贸易资质、进出口许可、市场定价是否成立未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
