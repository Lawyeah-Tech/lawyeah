# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、印件必然合格、许可必然办下、留置必然实现或对方接受；编造未给出的单价、印数、档期；把已失效《合同法》《加工承揽合同条例》或 1997 年《印刷业管理条例》写入结论；把复制样品一致性、出版书号发行、货交承运人风险或买卖检验期间视为合格硬套本类型。

## 1. 触发、单方立场与成果状态

立场（定作人／承揽人）、授权、签署状态、主要目标。复制、出版、买卖、广告制作或其他负触发写路由，不启动实体审查。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、《加工承揽合同条例》或 1997 年《印刷业管理条例》时记噪声，不得写入 `L#`。返回复制管理办法专属规则或出版书号发行专属规则时标明“不适用本类型”，不得写入默认法。

## 3. 类型与加载路径

父级 `承揽合同`，子级 `印刷合同`。写定性理由和与复制／出版／买卖／广告制作／加工／定作的切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。违禁出版物、无证跨范围或伪造货币证件写停笔告知，不填可开印结构。

## 4. 主体、授权、资质与文本版本

主体表：签约名、履行名、供纸名、收货名、付款名、发票名、授权签字人、签样代表、印刷经营许可证名义人。版本表：正文、材料规格表、付印样／大样、委印单／准印证／商标证明、订单、聊天确认；冲突并列，不选对用户有利的一版。

## 5. 给付闭环（本类型必填）

固定检查并回链文本：

- 印件名称、种类（出版物／包装装潢／其他印刷品）、成品尺寸、开本、纸张克重、P 数、装订、色数是否确定到可履行；
- **印刷经营许可证种类是否覆盖该印件**；未核则不得写成可以开印；
- **承印验证文件**是否列为开印前提：印刷委托书、准印证、商标证明、广告经营资格证明；
- **付印样／大样**是否书面确认并作为验收标准；色差是否禁止以显示器为准；
- 合同印数、加放数、是否禁止擅自加印和销售尾货；
- 主要印刷工作是否亲自完成；有无向无相应许可的第三方转包；
- 纸张由谁提供、克重公差、换纸是否须书面同意；
- 交付印刷成品、原稿／版材归还或销毁；验收期限、视为合格的范围；签收与验收是否切开；
- 价款构成（制版、纸张、工时、装订、印后、运费）、支付节点；
- 未付报酬时的留置或拒绝交付是否被排除；
- 任意解除的通知、已购纸张和已印半成品结算、预期利润是否纳入赔偿；
- 原稿、商标、排版电子文件归属与双向侵权担保；
- 成品毁损灭失风险是否按交付划分，有无误套货交承运人。

缺口标 `G#`，不补商业数字。许可、准印、备案写成义务或条件，不写成已经完成。

## 6. 格式条款与强制规范

是否构成格式条款（含印刷厂制式承印单或定作人制式采购文本）；提示说明痕迹。强制规范只区分是否导致民事行为无效与是否仅造成履行障碍（许可、准印、备案）。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。禁止用失效“效力性／管理性”口诀。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。硬闸六项若文本触及或本方立场下原文沉默，必须各有至少一行，不得用色块代替。

## 8. 修改句

按框架六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点、不接受时的红线。未给出的商业数字用 `【待填】`。禁止只给原则、不给句子。禁止输出复制样品合格句、出版发行句、货交承运人默认风险句或买卖检验期间视为合格句充当修改句。

## 9. 谈判与签署提醒

谈判顺序：先红线（类型错误、无证／跨范围、违禁出版物、无委托书仍开印、空白加印或无证转包、签收吞没留置、787 解除不赔），再必须改（付印样、色差、克重、验收期、版材销毁、交付前风险），最后可优化。签署提醒：授权与用印、签样代表书面授权、骑缝、日期不得倒签、付印样／规格表／委印单或准印证附件清单。不指导倒签或补假许可、假准印。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书、办证代办或效力保证。
