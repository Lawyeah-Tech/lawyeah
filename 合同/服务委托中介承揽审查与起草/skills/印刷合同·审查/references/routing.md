# 边界与路由

本技能只审查 **承揽合同 / 印刷合同**。核心给付是按原稿／付印样把图文印到承印物上并装订成批成品，不是以原物为蓝本翻制，也不是出版发行、通用现货买卖或广告成片制作。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 以原物为蓝本翻制零部件、艺术品、光盘、样衣、3D 复刻；验收绑在样品一致性 | `复制合同·审查` |
| 书号、编辑、发行、稿酬、出版单位权利义务为主给付 | 引擎重新定性；著作权转让／许可或委托创作：`或`／`或`／`委托创作·审查`／`主给付是委托创作特定作品→` |
| 通用现货选购、买方不控制印制过程 | `通用型号现货卖方组织生产买方不控制过程→` |
| 主给付为广告创意、拍摄、成片制作 | `广告制作合同·审查`；纯设计稿 → `广告设计合同·审查` 或 `委托他人设计的服务合同·审查` |
| 定作人送主材上门、只做机加工 | `加工合同·审查` |
| 承揽人包料制成非印刷特定物 | `定作合同·审查` |
| 对既存物修复 | `修理合同·审查` |
| 主给付为贴牌、品牌授权代工 | `定牌加工（OEM）合同·审查` |
| 用户只要审框架协议＋订单机制本身，印件给付不是争点 | `框架加订单承揽·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `印刷合同·起草` |
| 已签未争、开印／签样／交货留痕 | 本套导航的履约步骤 |
| 已成争（质量异议、催告、解除、索赔、立案、仲裁） | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。

本技能不得转去加载复制、出版、买卖或广告制作双文件完成本类型审查。一旦核心给付是翻制原物、出版发行或通用现货所有权转移，立即负触发，不得删掉复制、书号或购销条款后继续当印刷审。
