# 印刷合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构，不证明本约条款已被接受。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、1984 年《加工承揽合同条例》、1997 年《印刷业管理条例》或 1997 年《内部资料性出版物管理办法》当作现行规则。不得把复制件样品一致性、买卖货交承运人风险或出版书号发行主路径硬套本类型。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **承揽合同 / 印刷合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。`depends-on` 为空。不要求先跑导航。

不交付：他类审查、从零起草、履约交底、争议文书、有效性或印件必然合格／留置必然实现的保证、把无证或违禁印件改成可开印结构。

## 工作边界

正触发：已有可读待签文本要评改，；尚未签署，尚未成争，核心给付是承揽人用印刷设备、工艺和承印材料，按定作人提供的**原稿／电子文档／付印样**，把图文印到纸张或其他承印物上并完成装订等印后加工，交付**批量印刷成品**，定作人支付报酬。典型信号：出版物印刷、包装装潢印刷、其他印刷品印刷；合同写克重、开本、色令、胶订／骑马订、付印样、委印单。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 以原物为蓝本翻制零部件、艺术品、光盘、样衣、3D 复刻，验收绑在样品一致性而非付印样／印刷行标 → `复制合同·审查`；
- 核心给付含书号、编辑、发行、稿酬或出版单位权利义务，而不只是印制加工 → 本套导航的类型切开步骤 重新定性，或著作权／委托创作原子；
- 通用现货笔记本、库存宣传品选购，买方不控制印制过程 → `通用型号现货卖方组织生产买方不控制过程→`；
- 主给付是广告创意、拍摄、成片制作而非纸质或其他材质批量印刷 → `广告制作合同·审查`；创意设计稿本身 → `广告设计合同·审查` 或 `委托他人设计的服务合同·审查`；
- 定作人送主材上门、只做机加工而非印刷 → `加工合同·审查`；承揽人包料制成非印刷特定物 → `定作合同·审查`；
- 修复既存物 → `修理合同·审查`；贴牌代工为主给付 → `定牌加工（OEM）合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `印刷合同·起草`；
- 已签只问开印、签样、交货留痕 → 本套导航的履约步骤；
- 已成争（催告、解除、索赔、诉讼仲裁）→ `或对应专项领域。` 或对应专项领域。

违禁出版物、无证跨范围承印、伪造货币证件、通谋虚假、倒签规避监管：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；定作人或承揽人单一立场；相对方；正文、附件、订单、付印样／大样、委印单／准印证／商标证明版本；印件种类（出版物／包装装潢／其他印刷品）；印刷经营许可证范围是否被文本或材料提及；不可接受事项；法域与拟签时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价格、印数、日期用 `【待填】`，不编造。

知识双文件若把光盘复制、零部件翻制或出版发行写成适用场景，以本技能硬闸和路由为准，不把过宽场景写成正触发。双文件末尾的销售式提问不执行。

## 本类型硬闸

审查过程必须逐项点名，不得用复制样品一致性清单、买卖检验／风险清单或出版书号发行清单代替：

1. **与复制切开**：印刷是按原稿／付印样把图文印到承印物上并装订成批成品。复制是以原物为蓝本翻制，验收绑在样品一致性。图书报刊印刷优先留本类型；零部件、艺术品、光盘、样衣翻制转 `复制合同·审查`。禁止删掉复制条款后硬套本技能，也禁止把印刷稿改成复制留下。
2. **印刷许可**：承揽人必须持与印件种类相符的《印刷经营许可证》（出版物印刷／包装装潢印刷品印刷／其他印刷品印刷）。未出示或跨范围：许可字段停止，不写“可以开印”。口头“对方有证”不得写成已许可。出售、出租、出借许可证：停笔。
3. **违禁出版物停笔**：禁止印刷含反动、淫秽、迷信及国家明令禁止内容的出版物、包装装潢印刷品和其他印刷品；不得印刷国家明令禁止出版的出版物和非出版单位出版的出版物。伪造货币、证件、公章、特种票证：整体停止，不改成可开印。
4. **承印验证**：出版物须验证并收存印刷委托书并按规定备案；内部资料须验证准印证；商标标识须验证商标注册证明及许可文件；广告宣传品须验证营业执照或广告经营资格证明。无件仍要“先开印再补证”：整体停止。
5. **禁止擅自加印、盗印、无资质转包**：印数锁死；不得私自加印、截留尾货；主要印刷工作亲自完成或书面同意且仍负责；不得把出版物或须许可印件转给无相应许可的第三方。
6. **付印样与验收**：大规模开印前须有书面付印样／大样确认；色差以封存样张或行标为准，不得以显示器颜色为准；签收不等于终局合格；不得一句话放弃留置。

风险以印刷成品交付为原则。禁止把“货交承运人风险转移”“收货未异议视为全部合格”当印刷默认规则。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验承揽定义、印刷经营许可与三类范围、禁止印刷内容、印刷委托书与准印证、商标／广告验证、不得擅自加印、主要工作与任意解除、交付验收留置；`search_practiced` 补色差、加印、印刷与复制／出版切开等审查反例；`search_template` 只借修改句结构。不虚构案件系统。

`search_law` 对法律结论为 required 级节点：不可用时不拒绝执行，只停止法律结论字段。返回已失效《合同法》《加工承揽合同条例》或 1997 年《印刷业管理条例》时记为噪声，不得写入 `L#`。返回复制管理办法专属规则或出版书号发行专属规则时，不得当作本类型默认法。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、把违禁出版物或无证跨范围承印改成可开印、把伪造货币证件改成可履行、删除第 787 条或写成解除不赔、保证印件必然合格或许可必然办下。
- `字段停止`：印件种类或许可证范围无法特定化；委托书／准印证／商标证明未核验；付印样未锁定；787 赔偿范围法定口径未核验。
- `目标停止`：主目标已变为他类型起草、履约交底或争议文书。

生存级预付款或个人无限连带且用户拒绝升级：停止“可以签署”建议。
