# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、成果必然合格、业主必然无责或对方接受；编造未给出的面积、价款、工期；把已失效《合同法》《加工承揽合同条例》写入结论；把建筑业资质、必须招标、黑白合同、优先受偿、质保金 3% 或质量管理条例 2 年／5 年硬套本类型；把施工／EPC／雇佣当成已完成的本类型审查。

## 1. 触发、单方立场与成果状态

立场（定作人／承揽人）、授权、签署状态、主要目标。施工、EPC、加工、雇佣或其他负触发写路由，不启动实体审查。写明中文成果名称是「审查项目承揽合同（承揽合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释或《加工承揽合同条例》时记噪声，不得写入 `L#`。返回施工资质／招标／优先受偿／质保金 3% 时标明“不适用本类型”，不得写入默认法。建筑法第 83 条若只命中 1997 年本，记待核 2019 修正本，不得把“已被修改”条单独写成已核验现行法。

## 3. 类型与加载路径

父级 `承揽合同`，子级 `项目承揽合同`。写定性理由和与施工／EPC／专业分包／劳务分包／加工／定作／修理／框架订单／劳动合同／个人劳务的切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。占农田、拆承重、无证改燃气写停笔告知，不填可履行结构。

## 4. 主体、授权、独立承揽与文本版本

主体表：签约名、履行名、付款名、发票名、授权签字人、代签亲属。承揽人写独立承揽人身份，不要求建筑业企业资质。特种作业写证件名义人。版本表：正文、草图、材料清单、工程量报价、进度表、聊天确认；冲突并列，不选对用户有利的一版。

## 5. 给付闭环（本类型必填）

固定检查并回链文本：

- 项目性质（农村低层自建／竣工后室内装修／农田设施／庭院绿化）、地点、层数或部位、草图或说明书是否确定到可履行；
- 是否声明不属于应领施工许可证的建筑工程，或是否出现应负触发施工／EPC 的信号；
- 包工包料或包清工；材料品牌、规格、环保等级；定作人供料的检验通知；
- 主要工作与辅助工作清单；转第三人是否禁止或须书面同意；特种作业持证；
- 隐蔽工程覆盖前核验、拍照留痕；签收／入住与竣工验收是否切开；
- 报酬构成、进度节点、累计付款是否不超过已完合格部分；质保金比例与返还（约定，不是 3% 法定上限）；
- 增项是否必须书面签证；
- 任意解除的通知、已完工程结算、剩余材料处理、预期利润是否纳入赔偿；
- 意外伤害险；选任与指示过错未被写成业主无责保证；
- 交付前风险是否由承揽人承担；相邻损害与文明施工。

缺口标 `G#`，不补商业数字。报建、物业申报、特种作业证写成义务或条件，不写成已经完成。

## 6. 格式条款与强制规范

是否构成格式条款（装修公司制式或手写范本）；提示说明痕迹。强制规范只按第 153 条和解释第 16 条区分，不用失效口诀。占农田、拆承重、规避施工许可只保留识别与停笔。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。硬闸七项若文本触及或本方立场下原文沉默，必须各有至少一行，不得用色块代替。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点、不接受时的红线。未给出的商业数字用 `【待填】`。禁止只给原则、不给句子。禁止输出施工总承包资质句、优先受偿句、质保金 3% 句或“依法保修两年／防水五年”充当本类型法定修改句。

## 9. 谈判与签署提醒

谈判顺序：先红线（实为施工／EPC、占农田／拆承重、空白转包、解除不赔、款超进度拒改），再必须改（隐蔽验收、签证、保险、787 清算、报酬节点），最后可优化。签署提醒：自然人签字按指印并附身份证；授权委托书；草图、材料清单、工程量报价、进度表入附件并写冲突适用顺序；保单复印件。不指导倒签或补假报建。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书、办证代办、施工／EPC 审查或效力保证。
