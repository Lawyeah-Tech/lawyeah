# 项目承揽合同·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构，不证明本约条款已被接受。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、1984 年《加工承揽合同条例》当作现行规则。不得把建筑业企业资质、必须招标、黑白合同、竣工验收备案、建设工程价款优先受偿或质保金 3% 硬套本类型。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只起草 **承揽合同 / 项目承揽合同** 的待签文本，按已谈妥条件出己方稿，输出可编辑草稿、未决项；出稿后必须用本类型硬闸自审，输出风险表和修改句。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。`depends-on` 为空。不要求先跑导航。

不交付：他类审查、待签文本签前审查、履约交底、争议文书、有效性或成果必然合格／业主无责的保证。不交付把简易项目改成施工总承包，也不交付把施工／EPC 稿按本类型改完。

## 工作边界

正触发：已有可读待签文本要评改（审查模式），或本类型条件已谈妥要出己方稿（起草模式）；尚未签署，尚未成争，核心给付是承揽人在特定场地完成简易施工性工作成果并交付，定作人支付报酬。典型信号：农村两层及以下自建住宅、家庭室内装修（住宅竣工验收合格后）、小型农田水利、农业温室大棚、私人庭院绿化。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 城镇公共建筑、高层主体、大中型工业厂房，或要建筑业资质、规划许可、施工许可、竣工验收 → `工地建筑活动承包资质竣工验收→`；
- 设计采购施工一体或发包人要求主导 → `设计采购施工一体→`；
- 专业工程分包或纯劳务分包依附建设工程总包 → `或` 或 `或`；
- 工厂内加工、定作或修理动产 → `加工合同·审查`／`定作合同·审查`／`修理合同·审查`；
- 框架加订单反复触发、无特定场地项目 → `框架加订单承揽·审查`；
- 人格从属、工资社保 → `与劳动合同个人劳务切开：考勤+固定底薪+人身从属为主轴→负触发`；个人之间提供劳务过程、接受方指挥劳动 → `平等主体个人劳务且无演艺机会媒介→负触发`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问进场、隐蔽验收、进度款留痕 → 本套导航的履约步骤；
- 已成争（催告、解除、索赔、诉讼仲裁）→ `或对应专项领域。`；施工已成争 → 施工争议原子。

占用基本农田、拆承重、无证改燃气、通谋虚假、倒签：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；定作人或承揽人单一立场；相对方；正文、草图、材料清单、工程量报价、进度表版本；项目地点、层数或部位、是否已竣工验收、是否应领施工许可证；包工包料或包清工；不可接受事项；法域与拟签时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价格、面积、工期用 `【待填】`，不编造。

知识双文件若把“擅自使用视为验收合格”或装修“依法保修两年／防水五年”写成法定默认，以本技能硬闸为准，不把过时或过宽表述写成现行法。

## 本类型硬闸

审查过程必须逐项点名，不得用施工资质／招标／优先受偿清单代替：

1. **非建设工程项目承揽，与施工／EPC 切开**：监管范围决定类型。农村低层自建、竣工后室内装修、小型农田设施留本技能。要资质、施工许可、竣工验收或 EPC → 负触发 `工地建筑活动承包资质竣工验收→`／`设计采购施工一体→`。禁止把优先受偿、质保金 3%、黑白合同写入本类型。
2. **承揽 vs 雇佣 vs 劳动合同**：自带工具、独立作业、交付成果。考勤指挥、按日计工资 → `平等主体个人劳务且无演艺机会媒介→负触发` 或 `与劳动合同个人劳务切开：考勤+固定底薪+人身从属为主轴→负触发`。
3. **现场项目 vs 加工／定作／修理／框架订单**：工厂动产或订单框架负触发对应原子。
4. **违法建筑／占基本农田／拆承重停笔**：只告知，不改成可履行开工或拆改结构。
5. **主要工作亲自完成**：未经同意转主要工作，定作人可解除。特种作业须持证。空白转包必须改。
6. **选任过错与保险**：第 1193 条定作人仅在定作、指示、选任过错范围内担责。修改句要求意外伤害险，不得写成业主无责保证。
7. **隐蔽工程、款不超进度、书面签证、787 任意解除**：覆盖前核验；累计付款不超过已完合格部分；增项须签证；不得删除任意解除权或写成解除不赔。擅自使用视为合格只能约定，且不得吞没隐蔽瑕疵。


## 起草模式

本原子只承担本类型起草。待签评改转 `项目承揽合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `项目承揽合同·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。下文「起草必写 / 附件必附 / 禁止出现」即本类型硬闸的落稿口径。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 农村低层自建、竣工后室内装修、小型农田设施等简易施工性工作成果。主要工作亲自完成或书面同意；特种作业须持证。
- 第 1193 条：定作人仅在定作、指示、选任过错范围内担责。修改句要求意外伤害险，不得写成业主无责保证。
- 隐蔽工程覆盖前核验；累计付款不超过已完合格部分；增项须书面签证。
- 第 787 条任意解除：不得删除或写成解除不赔。擅自使用视为合格只能约定，且不得吞没隐蔽瑕疵。

### 附件必附

- 项目地点、层数或部位、草图与材料清单。
- 书面签证与隐蔽工程核验记录安排。

### 禁止出现

- 把简易项目改成施工总承包；写入优先受偿、质保金 3%、黑白合同。
- 占用基本农田、拆承重、无证改燃气的可履行开工或拆改结构。
- 空白转包。
- 业主无责保证。
- 删除任意解除权或写成解除不赔。
- 考勤指挥、按日计工资写成项目承揽。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验承揽定义、主要工作、材料与变更、交付验收、任意解除、1192／1193 与选任过错、建筑法适用范围、施工许可限额、装修申报与禁止拆改、土地管理法永久基本农田；`search_practiced` 补 787 赔偿范围、农村建房与室内装修定性反例；`search_template` 只借装修／农村自建栏目结构，不借施工总承包范本。不虚构案件系统。

`search_law` 对法律结论为 required 级节点：不可用时不拒绝执行，只停止法律结论字段。返回已失效《合同法》《加工承揽合同条例》或施工专属规则时记为噪声或“不适用本类型默认法”，不得写入 `L#` 当作本类型默认。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、把占农田／拆承重／无证改燃气改成可履行、删除第 787 条或写成解除不赔、保证有效或保证业主无责。
- `字段停止`：层数、是否应领施工许可证、场地权属或报建未核验；成果无法特定化；特种作业许可未核验；787 赔偿范围法定口径未核验。
- `目标停止`：主目标已变为评改待签文本、履约交底、争议文书，或用户坚持本技能把施工／EPC 整案改完。

生存级预付款或个人无限连带且用户拒绝升级：停止“可以签署”建议。
