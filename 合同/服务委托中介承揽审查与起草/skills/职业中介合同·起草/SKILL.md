# 职业中介合同·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其居间章当作现行规则。职业中介优先适用《就业促进法》《人力资源市场暂行条例》《人力资源服务机构管理规定》；民事报酬、如实报告、跳单，在行政规范未覆盖的范围内才参照民法典中介合同。不得把《人力资源服务许可证》写成《劳务派遣经营许可证》。不得把向劳动者收取押金或扣押证件改成可履行担保。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只起草 **中介合同 / 职业中介合同** 的待签文本，按已谈妥条件出己方稿，输出可编辑草稿、未决项；出稿后必须用本类型硬闸自审，输出风险表和修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查职业中介合同（中介合同）」。专业版未装本原子时输出 `unavailable`，提示，不得用邻类硬套。

`depends-on` 为空。不要求先跑导航。

不交付：他类合同审查；待签文本签前审查；履约交底；争议文书或行权策略；有效性保证；把无证文本改成可履行经营结构；把劳务派遣或平台用工程按本类型放行。

## 本类型硬闸

1. **职业介绍许可**。经营性职业中介活动（为用人单位推荐劳动者、为劳动者介绍用人单位、招聘会、网络招聘、高级人才寻访／猎头）须先完成市场主体登记，再向住所地人力资源社会保障行政部门申请行政许可，取得《人力资源服务许可证》。网络招聘另核电信业务经营许可。境外就业另核专项许可。该证 ≠ 《劳务派遣经营许可证》。未见有效人服许可：不按本类型放行。
2. **禁止扣证件／押金**。职业中介不得扣押劳动者的居民身份证和其他证件，不得向劳动者收取押金，不得以担保等名义变相收取押金。服装费、体检费、培训费、工装押金等向个人收取的明示项目以外费用，同样删除。公共就业服务不得向劳动者收费。不得把民法典第九百六十五条的跳单报酬写成收取押金的正当化理由。
3. **与劳务派遣／平台用工切开**。本类型的给付是撮合双方建立劳动关系，中介不是用人单位。按人头派驻、接受用工单位考勤奖惩、中介发薪或自己与劳动者签劳动合同 → `用人单位。按人头派驻接受用工单位考勤奖惩中介发薪或自己与劳动者签劳动合同→`。平台派单、算法管理、按单计酬、主张不建劳动关系 → `平台派单算法管理按单计酬主张不建劳动关系→`。中介“办理入职、代发工资、缴纳社保” → `与劳动合同个人劳务切开：考勤+固定底薪+人身从属为主轴→负触发`。假外包真派遣 → `假外包真派遣→`。禁止在本任务把上述结构改写成“介绍费协议”后宣称审完。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

禁止表述：无证也可以先做后补；押金可以少收或代为保管证件；职业中介就是劳务派遣；保证入职；职业中介合同一定有效或全部无效；先签再改。

## 工作边界

正触发：已有可读待签文本要评改（审查模式），或本类型条件已谈妥要出己方稿（起草模式）；尚未签署，尚未成争，核心给付是职业介绍／猎头／经营性网络招聘撮合；用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 求职、招聘之外的房屋买卖或租赁居间 → `房屋买卖_租赁中介合同·审查`（P1 未装则 `unavailable`）；
- 婚恋介绍、相亲服务 → `婚姻中介合同·审查`（未装则 `unavailable`）；
- 技术转让、专利许可居间 → `技术转让中介合同·审查`（未装则 `unavailable`）；
- 处理事务或对外代理，报酬不绑促成入职 → `一般委托合同·审查`；
- 以自己名义为委托人从事贸易 → `行纪合同·审查`；
- 中介与劳动者建立劳动关系、发工资上社保 → `与劳动合同个人劳务切开：考勤+固定底薪+人身从属为主轴→负触发`；
- 按人头派驻、三方派遣结构、持或需要《劳务派遣经营许可证》作为主给付 → `用人单位。按人头派驻接受用工单位考勤奖惩中介发薪或自己与劳动者签劳动合同→`；
- 假外包真派遣、按项目外包但人员接受发包方直接管理 → `假外包真派遣→`（P1 未装则 `unavailable`）；
- 平台用工、新就业形态、算法派单 → `平台派单算法管理按单计酬主张不建劳动关系→`（P1 未装则 `unavailable`）；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点、保证期补人日历或台账留痕 → 本套导航的履约步骤；
- 已催告、索赔、立案、开庭、仲裁，或主问怎么退费、怎么打劳动仲裁 → `或对应专项领域。` 或劳动争议专项。

强迫劳动、拐卖人口、非法出境劳务、介绍童工：只出告知，不改写成可履行结构。用户坚持“改到能做”：整体停止。

## 建立审查坐标

确认：使用者与授权；单方立场（劳动者／用人单位／中介机构择一）；相对方；全文及附件版本；《人力资源服务许可证》是否被文本或材料提及；收费对象与节点原句；有无押金、证件留置、保证入职；有无派驻管理或平台派单；境外或外资线索；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的金额、许可证号、岗位数用 `【待填】`，不编造。

## 起草模式

本原子只承担本类型起草。待签评改转 `职业中介合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `职业中介合同·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`，不编造。

### 起草必写

- 核心给付是为用人单位推荐劳动者、为劳动者介绍用人单位、招聘会、网络招聘或猎头寻访，促成双方建立劳动关系；中介不是用人单位。
- 经营性职业中介须先完成市场主体登记，再取得《人力资源服务许可证》；该证 ≠ 《劳务派遣经营许可证》。网络招聘另核电信业务经营许可；境外就业另核专项许可。
- 收费对象、计费方式、支付节点、未促成时的费用分列。
- 中介对岗位信息和人才信息的核实义务要落句。
- 保证期是补人或退部分佣金，不是保证录用结果。
- 悬挂证照、收费明示、服务台账保存不少于 2 年、委托材料审查、简历须书面授权。
- 跳单报酬按核验后的第九百六十五条写；虚假岗位或虚假履历按第九百六十二条处理报酬请求。

### 附件必附

- 《人力资源服务许可证》（网络招聘另附电信业务经营许可；境外就业另附专项许可）。
- 委托材料审查记录；简历书面授权。

### 禁止出现

- 扣押劳动者居民身份证和其他证件；向劳动者收取押金，或以担保等名义变相收取押金；服装费、体检费、培训费、工装押金等向个人收取的明示项目以外费用。
- 把第九百六十五条的跳单报酬写成收取押金的正当化理由。
- “无证也可以先做后补”；保证入职；“中介方为劳动者办理入职、代发工资、缴纳社保”。
- 按人头派驻、接受用工单位考勤奖惩、中介发薪或自己与劳动者签劳动合同（负触发派遣/劳动合同）。
- 介绍童工、强迫劳动、拐卖人口、非法出境劳务：只告知，不起可履行稿。

出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 留本任务起草并自审；已签履约 → 本套导航履约步骤；已成争或主问退费胜率／劳动仲裁策略 → 争议或劳动专项。未签且目标是评改已有职业中介合同；本任务只起草，评改待签文本转配对 ·审查 原子。

### 1. 类型锁死（撮合 ≠ 派遣 ≠ 平台）

标题、核心给付与“促成建立劳动关系的介绍／猎头”一致才继续。派驻管理、平台派单、劳动本约、房产／婚介／技术中介负触发。

### 2. 人服许可与主体

中介是否法人、是否持有效《人力资源服务许可证》；分支机构有无授权；网络招聘有无电信业务许可；境外就业有无专项许可。口头“证在办”不得写成已许可。

### 3. 扣证／押金与向个人收费

出现扣证、押金、保证金、服装费、体检费、培训贷：删除或红线。收费对象、计费方式、支付节点、未促成时的费用分列。

### 4. 标的与核实义务

服务是职位发布、简历初筛、面试安排还是猎头寻访。中介对岗位信息和人才信息的核实义务要落句。禁止介绍童工、禁止职业、无证用人单位。

### 5. 中介不是用人单位；不得保证入职

删除“中介方为劳动者办理入职”等易混表述。保证期是补人或退部分佣金，不是保证录用结果。

### 6. 程序、台账、个人信息

悬挂证照、收费明示、服务台账保存不少于 2 年、委托材料审查、简历须书面授权。

### 7. 防跳单与虚假信息责任

跳单报酬按核验后的第九百六十五条写，不得搭配押金。虚假岗位或虚假履历按第九百六十二条处理报酬请求。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。许可句、扣证／押金删除句、派遣／平台切开句不得省略。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、补假许可证、把无证经营改成可履行、把扣证／押金改成可履行担保、把派遣或平台用工程按本类型放行、保证入职或保证有效、介绍童工／强迫劳动／非法出境劳务。
- `字段停止`：法域、动态规则、许可证真伪、收费数字或境外专项未核验。
- `目标停止`：主目标已变为评改待签文本、履约交底、争议文书，或把本合同改成劳动合同／劳务派遣／平台用工。

劳动者生存级高额预付费且用户拒绝升级：停止放行建议，只列风险与转介。
