# 边界与路由

本技能只审查 **中介合同 / 职业中介合同** 的待签文本。中文展示名是「审查职业中介合同（中介合同）」。场景分层为 P1：专业版未装则 `unavailable`，提示，不得用邻类硬套。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 房源带看、挂牌、买卖或租赁居间、网签、独家售房委托 | `房屋买卖_租赁中介合同·审查`。P1：未装则 `unavailable` |
| 相亲、婚恋会员、介绍结婚对象 | `婚姻中介合同·审查`。P1：未装则 `unavailable` |
| 促成技术转让、专利许可或技术秘密许可 | `技术转让中介合同·审查`。P1：未装则 `unavailable` |
| 处理事务或对外代理，报酬不绑促成入职 | `一般委托合同·审查` |
| 以自己名义为委托人从事贸易 | `行纪合同·审查` |
| 中介与劳动者签劳动合同，发工资、缴社保，劳动者服从中介管理 | `与劳动合同个人劳务切开：考勤+固定底薪+人身从属为主轴→负触发` |
| 按人头派驻、三方派遣、需要或持有《劳务派遣经营许可证》作为主给付 | `用人单位。按人头派驻接受用工单位考勤奖惩中介发薪或自己与劳动者签劳动合同→` |
| 假外包真派遣、人员接受发包方直接管理 | `假外包真派遣→`。P1：未装则 `unavailable` |
| 平台派单、算法管理、按单计酬、新就业形态 | `平台派单算法管理按单计酬主张不建劳动关系→`。P1：未装则 `unavailable` |
| 无文本、本类型条件已谈妥、要出己方稿 | 留本任务起草并自审 |
| 已签未争、只问保证期补人、台账或收费备案日历 | 本套导航的履约步骤 |
| 已催告、索赔、立案、开庭，或主问退费、劳动仲裁怎么打 | `或对应专项领域。` 或劳动争议专项 |
| C 端大众快检 | 只分流，不回改 |

标题写“职业中介”或“猎头”，正文却按月按人头派驻并接受用工单位管理：不在本任务补介绍费后放行。负触发 `用人单位。按人头派驻接受用工单位考勤奖惩中介发薪或自己与劳动者签劳动合同→`。

标题写“职业中介”，正文是平台派单、按单计酬：负触发 `平台派单算法管理按单计酬主张不建劳动关系→`。

仅缺一般或连带式的收费节点、保证期天数，但给付仍是撮合：留在本任务，必须出显化句。

无《人力资源服务许可证》却要本技能出具可签署意见：不按本类型放行。要求补许可后重审，不转成派遣或劳动合同来“挽救”无证介绍。
