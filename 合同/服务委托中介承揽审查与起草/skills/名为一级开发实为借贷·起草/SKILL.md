# 名为一级开发实为借贷·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把年利率 24%/36% 两线、1991 年银行利率旧四倍、法定贷款利率当作现行上限。不得把“企业间借贷一律无效”或“有人大决议即可强制财政付款”写成现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只起草 **委托合同 / 名为土地一级开发，实为 “投资、借贷” 的合同** 的待签文本：外壳是土地一级开发、片区开发或投融资合作，核心给付却是出资方按计划拨付资金、按固定或保底安排收回本息。按已谈妥条件出己方稿，输出可编辑草稿、未决项；出稿后必须用本类型硬闸自审，输出风险表和修改句。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「审查名为土地一级开发，实为 “投资、借贷” 的合同（委托合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查、待签文本签前审查、履约交底、争议文书、合同或财政兑付有效性保证、把本约改成可强制履行的真委托或真施工、真土地一级开发委托整案、名为一级开发实为施工整案、无该外壳的普通借款整案、利息精算终局数字。

## 工作边界

正触发：已有可读待签文本要评改（审查模式），或本类型条件已谈妥要出己方稿（起草模式）；尚未签署，尚未成争；标题或外壳是土地一级开发、片区开发、投融资合作；**且**出资方主要义务是按计划拨付资金，回报呈固定利率、保底、无论出让与否均还本付息，或不参与开发却只收取固定货币。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 受托人真实组织征拆、报批、土地整理，报酬对应委托事务完成，无固定还本付息 → `土地一级开发委托合同·审查`；
- 核心给付是工程建设、工程量、进度款、竣工验收 → `名为一级开发实为施工·审查`；
- 后续用地挂钩、一二级联动、勾地主导 → `“一二级联动”相关合同·审查`；
- 拆迁实施、补偿安置委托为主给付 → `拆迁委托协议·审查`；
- 无一级开发／政府或平台外壳的资金借贷 → `或` 或 `用户坚持固定保本保收益且不担风险：不得化妆成股权代建放行；明显无代建服务则负触发` 或 `或`；
- 财产形式上过户加回购的让与担保借款 → `财产形式上过户加回购的让与担保借款→`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问拨款日、出让进度、回款节点 → 本套导航的履约步骤；
- 已成争（催告还本付息、审计叫停、确认违法融资、诉讼仲裁）→ 合同争议或对应专项领域。

挂靠、违法分包、伪造开发资料套取信贷、面向不特定对象吸收资金、规避法定举债：只出告知，不改写成可履行结构。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成。每一闸必须给出修改句或明确转出口径，禁止只打红黄绿。

1. **固定回报穿透**。标题写委托开发不决定类型。必须同时读出三组事实：出资方是否实际参与征拆、报批、施工组织；是否承担土地出让失败或出让价款低于成本的风险；对价是固定利率／保底／无论出让与否均支付，还是与出让溢价挂钩的风险收益。仅出资、不处理事务、不承担经营风险、只收固定货币或年化回报的，按借贷识别。修改句必须把鉴于改成：双方确认本协议项下甲方拟融入资金【待填】元，乙方的主给付是按【待填】节点拨付资金，不因此取得土地整理事务的受托人地位；所谓“投资回报／开发利润”按资金占用对价审查。不得把本约改成可请求实际履行的真委托或真施工。不得把固定回报改名为“委托报酬”却仍不处理事务。
2. **利率上限运行时核验**。投资收益率、年化回报、保底收益、资金占用费、通道费、顾问费、逾期罚息、加速到期利息，一并折算年化。民间借贷路径不得超过合同成立时一年期贷款市场报价利率四倍（一年期 LPR 四倍）；超额改到上限内或标明不受司法保护。预扣利息、先扣顾问费按实际出借额计本金。出借人是持牌金融机构或七类地方金融组织：利率字段停止，不套四倍。禁止默写 24%/36%/银行利率旧四倍／法定贷款利率。核验失败则利率法律结论字段停止，摘录和修改句草稿继续。
3. **与真委托／施工切开**。正文能支持受托人设立项目部、组织征拆或施工招标、按整理节点取与事务对应的报酬，且无保底还本付息 → 负触发 `土地一级开发委托合同·审查`。正文能支持承包人施工、工程量清单、进度款、竣工验收为主给付 → 负触发 `名为一级开发实为施工·审查`。禁止打开其 method。禁止套委托事务处理、工期进度款、竣工结算作为本任务主路径。禁止用普通借款 method 换皮：本类型必须审一级开发外壳、资金是否进入项目账户、清算是本息还是工程量／事务、有无机关或财政担保。

附加必落句（有事实则单列，无事实在缺口节说明）：

- **遮盖／隐藏分层**：名义一级开发是遮盖行为，资金占用是隐藏行为。遮盖行为无效不等于隐藏借贷当然有效或当然无效。隐藏行为另按强制规范、预算法举债禁止、民间借贷第 10／13 条审查。
- **政府举债与机关担保**：地方政府及其所属部门以开发名义融入资金、机关担保、财政承诺函、人大决议把还本付息纳入预算：红线删除可履行担保结构，告知违法举债／机关不得为保证人的风险。不得改成“完善决议即可强制财政付款”。平台公司担保另审决议与代偿，不得直接写成机关担保无效，也不得写成财政必然兑付。
- **资金路径**：资金不进入项目监管账户、直接进入财政统筹或往来款科目，是实为借贷的程序红旗。修改句要求专户、用途限于约定整理支出，并保留穿透后的资金占用定性，不假装已经变成真开发。
- **清算口径**：解除或到期按“借款本息”清算的，不得改写成已完工工程量结算来掩盖借贷。附件若只有还本付息计划表、没有事务或工程量清单，必须在风险表点名。
- **未取得权证的土地抵押**：一级开发阶段尚未取得建设用地使用权证书的，不得写成抵押权已经设立。

必须有修改句。每个风险回链文本位置。禁止复制 `土地一级开发委托合同·审查` 或借款／施工 method。

## 建立审查坐标

确认：使用者与授权；单方立场（政府／管委会／平台侧，或出资方／名义开发方，择一）；相对方；全文及还本付息表／清单／担保函／会议纪要版本；出资金额与拨付节点；出资方是否驻场或组织招标；回报是固定、保底还是溢价分成；有无机关或财政担保；利率与费用；出借人是否持牌；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的金额、利率、期限用 `【待填】`，不编造。

知识库若写“企业间借贷通常无效”“超出法定贷款利率部分不予支持”“利息折抵本金”，或以失效出让金办法当现行收支两条线，以本文件和 `method.md` 纠正为准，不回写知识正文。

宿主可调用时：

- `search_law`（法律结论 required）：核验虚假意思表示与隐藏行为、强制规范是否导致无效、借款与委托定义、民间借贷原则有效与无效情形、利率上限与预扣本金、机关担保、预算法举债禁止、合作开发只收固定货币应认定为借款。
- `search_practiced`（optional）：补固定回报识别、融资平台争点。返回“企业间借贷一律无效”“投资回报率约定一律有效”“24%/旧四倍”时记噪声。

不虚构案件系统。`search_law` 返回已失效《合同法》及其解释、2015 年 24%/36%、1989／1996 年失效出让金办法、2005 年土地使用权解释旧第 23 条时记为噪声，不得写入 `L#`。


## 起草模式

本原子只承担本类型起草。待签评改转 `名为一级开发实为借贷·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `名为一级开发实为借贷·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。本类型只把一级开发外壳下的资金占用写清楚，不得改成可请求实际履行的真委托或真施工。

### 起草必写

- 鉴于改成：双方确认本协议项下甲方拟融入资金【待填】元，乙方的主给付是按【待填】节点拨付资金，不因此取得土地整理事务的受托人地位；所谓“投资回报／开发利润”按资金占用对价审查。
- 名义一级开发是遮盖行为，资金占用是隐藏行为。遮盖行为无效不等于隐藏借贷当然有效或当然无效。
- 投资收益率、年化回报、保底收益、资金占用费、通道费、顾问费、逾期罚息一并折算年化。民间借贷路径不得超过合同成立时一年期 LPR 四倍；超额改到上限内或标明不受司法保护。预扣利息、先扣顾问费按实际出借额计本金。出借人是持牌金融机构或七类地方金融组织：利率字段停止。
- 资金进入项目监管账户、用途限于约定整理支出，并保留穿透后的资金占用定性。解除或到期按“借款本息”清算。

### 附件必附

- 还本付息计划表。不得用土地开发工程量清单假装已经变成真开发。缺金额、利率、期限用 `【待填】`。

### 禁止出现

- 把本约改成可请求实际履行的真委托或真施工；把固定回报改名为“委托报酬”却仍不处理事务。
- 机关担保、财政承诺函、人大决议把还本付息纳入预算的可履行担保结构；“完善决议即可强制财政付款”。
- 未取得建设用地使用权证书的土地写成抵押权已经设立。
- 默写 24%／36%／银行利率旧四倍／法定贷款利率。
- 面向不特定对象吸收资金、伪造开发资料套取信贷、规避法定举债的可履行结构。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口，不代替节点。

0. 签署状态与成果分流
1. 类型识别与单目录加载（一级开发外壳 + 资金占用；切开 s113／s116／s114／s117／普通借款）
2. 主体：管委会、机关、平台公司、出资人是否持牌
3. 固定回报穿透与资金路径
4. 遮盖／隐藏分层与政府举债、机关担保
5. 利率上限运行时核验
6. 清算口径、附件与未取证土地抵押
7. 格式条款与强制规范
8. 按框架六步出修改句

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、补假预算或人大决议、把机关担保改成可履行、把政府违规融资包装成真委托或真施工、保证财政必然兑付或利息必然受保护、按 24%/36%/旧四倍出合法利率结论且拒绝核验。
- `字段停止`：法域、利率上限、管委会主体资格、出借人是否持牌、是否构成向不特定对象放贷、当次 LPR 未核验。
- `目标停止`：主目标已变为评改待签文本、履约交底、确认违法融资诉讼文书，或用户要把本约改成真委托／真施工以便请求实际履行。

生存级财政兑付或个人无限连带且用户拒绝升级：停止“可以签署”建议。
