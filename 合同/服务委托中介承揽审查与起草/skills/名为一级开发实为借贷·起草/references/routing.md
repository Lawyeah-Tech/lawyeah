# 边界与路由

本技能只审查 **委托合同 / 名为土地一级开发，实为 “投资、借贷” 的合同** 的待签文本。中文展示名是「审查名为土地一级开发，实为 “投资、借贷” 的合同（委托合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或复制 `土地一级开发委托合同·审查`、`名为一级开发实为施工·审查` 或借款原子的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 受托人真实组织征拆、报批、土地整理，报酬对应事务，无保底还本付息 | `土地一级开发委托合同·审查` |
| 工程量、进度款、竣工验收、质量保修为主给付 | `名为一级开发实为施工·审查` |
| 后续用地挂钩、一二级联动、勾地 | `“一二级联动”相关合同·审查` |
| 拆迁实施、补偿安置委托 | `拆迁委托协议·审查` |
| 无一级开发／政府或平台外壳的资金借贷 | `或` 或 `用户坚持固定保本保收益且不担风险：不得化妆成股权代建放行；明显无代建服务则负触发` 或 `或` |
| 财产形式上过户或变更登记加回购 | `财产形式上过户加回购的让与担保借款→` |
| 抵押登记为主结构、不转移所有权 | `抵押质押保证是主结构且无代建→` |
| 标准 PPP／特许经营本约 | 本套导航的类型切开步骤（不在本任务改成特许经营整稿） |
| 无文本、本类型条件已谈妥、要出己方稿 | 留本任务起草并自审 |
| 已签未争、只问拨款或回款节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或对应专项领域。` 或对应专项领域 |
| 审计监察、涉嫌骗取贷款或非法吸收公众存款已立案 | 刑事或行政专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

本约正文夹带一小段真委托事务或一小段施工：专章交接对应原子；资金占用条款可继续审。用户坚持本技能把真委托、真施工或普通借款整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
