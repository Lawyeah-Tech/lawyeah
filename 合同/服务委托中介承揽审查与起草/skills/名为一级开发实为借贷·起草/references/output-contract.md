# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证合同有效、财政必然兑付、利息必然受保护或对方接受；编造未给出的金额、利率、期限；把已失效《合同法》及其解释写入结论；把 24%/36%/银行利率旧四倍／法定贷款利率写成现行上限；把企业间借贷写成一律无效；把本约改成可强制履行的真委托或真施工；把真委托或真施工留在本技能改完。

## 1. 触发、单方立场与成果状态

立场（政府／管委会／平台侧，或出资方／名义开发方）、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明是否同时存在一级开发外壳和资金占用主给付。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、2015 年 24%/36%、1989／1996 年失效出让金办法时记噪声，不得写入 `L#`。名实分层、固定回报识别、利率上限、机关担保、预算法举债禁止无 `verified-result` 时，对应法律结论字段停止。

## 3. 类型与加载路径

父级 `委托合同`，子级 `名为土地一级开发，实为 “投资、借贷” 的合同`。定性理由必须同时满足：一级开发或片区／投融资合作外壳；出资方主给付是资金；回报固定、保底或不担出让失败风险。

易混切开：真土地一级开发委托、名为一级开发实为施工、一二级联动、拆迁委托、无外壳普通借款、让与担保借款、PPP。

加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读其他类型、未打开 `土地一级开发委托合同·审查` 或借款／施工 method。职业放贷、套取信贷、伪造开发资料、机关担保可履行化写停笔告知，不填可履行结构。

## 4. 主体、授权、资质与文本版本

主体表：政府或所属部门、管委会或指挥部、平台公司、出资方、担保人、授权签字人。写明是否具备独立法人资格、出资方是否持牌。

版本表：正文、还本付息计划、事务或工程量清单（或缺失）、担保函或承诺函、会议纪要、资金账户安排、聊天确认。冲突并列，不选对用户有利的一版。口头“已经纳入预算”“已经驻场”不得写成已批准或已处理事务。

## 5. 名实穿透与给付闭环

分列并回链文本位置：

- 外壳：合同名称、项目四至或范围、是否写成委托整理。
- 事务：出资方是否有项目部、征拆、报批、招标等可核验义务。
- 风险：是否承担出让失败或价款低于成本的风险。
- 资金：金额、拨付节点、账户是项目监管户还是财政／往来户。
- 回报：固定利率、保底、分成加补足、费用名目；是否无论出让与否均支付。
- 清算：到期或解除按本息还是按事务／工程量。
- 担保：机关担保、财政承诺、人大决议、平台担保、未取证土地抵押。
- 利率审查状态：已核验／字段停止／持牌不套四倍。

缺口标 `G#`，不补商业数字或已完成审批。批准、备案、出让写成条件或义务期限，不写成已经完成。

## 6. 格式条款、强制规范与本类型效力红旗

出资方预先拟定的利息、罚息、加速到期，按格式条款审查提示说明。

强制规范与效力红旗只在核验后落法律结论：遮盖行为与隐藏行为分层；政府及所属部门违法举债；机关担保；职业放贷或转贷；未取证土地抵押尚未设立。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

不得把“企业间借贷一律无效”或“整组合同因名为开发而全部有效”写成已核验结论。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔／转出口径。禁止输出无修改句的色块表。

本类型至少检查：名实未锁定；固定回报或保底；无论出让与否均还本付息；机关或财政担保；资金不进项目账户；附件只有还本付息表；利率／费用未核验或疑似超过保护上限；未取证土地写成已抵押；加速到期未纳入上限；把本约改成真委托或真施工的夹带条款。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`，不编造。禁止只给原则、不给句子。框架与硬闸冲突时按硬闸出句。

建议句必须覆盖本类型硬闸：鉴于锁定资金占用而非真委托；删除或改写固定回报／保底；利率上限待核表述；删除可履行机关担保或财政兑付；资金专户不洗白定性；清算口径与附件一致。

## 9. 谈判与签署提醒

谈判顺序：先红线（机关担保、财政兜底、伪造开发或决议、职业放贷、超上限却要求保证合法），再必须改（名实锁定、固定回报穿透、资金账户、利率核验、附件），最后可优化。

签署提醒：有权机关或有权代表本人签；平台公司决议作附件；日期真实；先核验当次 LPR 与主体资格再谈放款。不指导倒签、补假驻场或假预算。

政府／平台立场必须提示：签字可能被认定为违法举债或违规担保，存在审计叫停和责任追究风险。出资方立场必须提示：固定回报可能不被保护，机关担保可能无效，本金返还取决于隐藏行为效力和相对方财产，不保证财政兑付。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、确认违法融资诉讼文书、利息精算终局或效力保证。
