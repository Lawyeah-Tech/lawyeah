# 广告合同（广义）·起草

## 任务目标

在单一立场下，只起草 **服务合同 / 广告合同（广义）** 的待签文本，按已谈妥条件出己方稿，输出可编辑草稿、未决项；出稿后必须用本类型硬闸自审，输出风险表和修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文名必须是「审查广告合同（广义）（服务合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类合同审查；待签文本签前审查；履约交底；争议文书；有效性保证；把已能细分的设计、制作、发布、代言、代理或互联网广告整案改完；把广告法禁止内容改成可履行发布结构。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **广告法禁止内容停笔**：待签文本或附件出现第 9 条禁止情形、第 28 条虚假广告、第 15 条禁发药品/戒毒治疗、第 22 条烟草公共场所或向未成年人发送、互联网烟草广告、第 37 条禁产禁售或禁发商品服务、含集资内容宣传、未使用产品或未接受服务作代言、医疗/药品/医疗器械/保健食品使用代言人、不满十周岁未成年人作代言人、伪造变造转让审查批准文件的，只出告知，不改写成可履行的设计、制作、代理或发布结构。用户坚持“改到能发”：整体停止。
2. **与设计 / 制作 / 发布切开**：本类只审无法拆成单一环节的交易结构总览和合规底板。核心给付已能锁定为设计成果 → `广告设计合同·审查`；成片/成品制作 → `广告制作合同·审查`；媒介刊播或排期投放 → `广告发布合同·审查`。代言人格权许可主轴 → `广告代言服务类合同·审查`；媒介购买或代理排期主轴 → `广告代理合同·审查`；互联网媒介主轴 → `互联网广告类合同·审查`。禁止用广义包办分类型深度。
3. **书面合同 + 角色法定**：广告活动各方应依法订立书面合同。主体按广告主、广告经营者、广告发布者、广告代言人分列；身兼数职的分条款写清审核、发布和追偿。广告主应委托具有合法经营资格的经营者和发布者。角色写错导致审核义务和处罚对象错位的，必须改。
4. **法定审核义务不可内部免除**：经营者和发布者应查验证明文件、核对广告内容；内容不符或证明不全的，不得提供设计、制作、代理，不得发布。禁止“仅按甲方提供内容发布、不对合法性负责”而无拒登权。内部约定不能对抗监管，也不能免除对消费者的法定连带或先行赔偿。
5. **法定审查类以批准为发布前提**：医疗、药品、医疗器械、农药、兽药、保健食品，以及法律、行政法规规定应当审查的其他广告，未经审查不得发布；取得审查批准是发布条件，不是合同成立条件。改动已审内容须重新报审。禁止“包过审”。特殊医学用途配方食品按审查管理暂行办法运行时核验，不得把广告法第 46 条写成已单列该类。
6. **对外责任与内部追偿切开**：关系消费者生命健康的虚假广告，经营者、发布者、代言人依法与广告主连带；其他虚假广告在明知应知时连带；不能提供广告主真实名称、地址和有效联系方式的，消费者可要求先行赔偿。合同可约定内部追偿、拒登和撤稿，但不得写成已对外免责。广告费应据实记载刊例价、折扣和成交价，不得故意写低。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签广告服务、广告业务或全案推广正文，尚未签署，尚未成争，核心给付覆盖两个以上广告环节或无法拆成单一子类型，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 核心给付是样稿、创意、平面或脚本交付 → `广告设计合同·审查`；
- 核心给付是成片、物料、喷绘或成品制作 → `广告制作合同·审查`；
- 核心给付是频道、版面、户外位、排期刊播 → `广告发布合同·审查`；
- 核心给付是以自己名义或形象作推荐证明 → `广告代言服务类合同·审查`；
- 核心给付是媒介购买、代理排期而无全案混同 → `广告代理合同·审查`；
- 核心给付是网站、应用程序、信息流或程序化投放 → `互联网广告类合同·审查`；
- 类型未定或名实明显不是广告活动 → 本套导航的类型切开步骤；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

虚假、违禁、未审先发、集资宣传、无资格主体承接：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（广告主侧、经营者侧或发布者侧择一）；相对方；全文及创意脚本、排期单、刊例、监测标准、审查批准文件、资质复印件版本；是否已能拆成单一环节；商品或服务是否属法定审查或禁发类；证明文件清单；角色与经营资格痕迹；样稿签批授权代表；监测与补播安排；广告费记载是否分列刊例/折扣/成交价；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的刊例价、折扣、曝光量、期限用 `【待填】`，不编造。

## 起草模式

本原子只承担本类型起草。待签评改转 `广告合同（广义）·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `广告合同（广义）·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。本类型只写无法拆成单一环节的合规底板，不按设计／制作／发布／代言／代理／互联网投放深度包办。

### 起草必写

- 广告活动各方依法订立书面合同。主体按广告主、广告经营者、广告发布者、广告代言人分列；身兼数职的分条款写清审核、发布和追偿。广告主应委托具有合法经营资格的经营者和发布者。
- 经营者和发布者应查验证明文件、核对广告内容；内容不符或证明不全的，不得提供设计、制作、代理，不得发布。须保留拒登权。
- 医疗、药品、医疗器械、农药、兽药、保健食品及依法应审的其他广告，以审查批准为发布前提，不是合同成立条件；改动已审内容须重新报审。
- 对外责任与内部追偿切开：合同只写内部追偿、拒登和撤稿，不得写成已对外免责。广告费据实记载刊例价、折扣和成交价。

### 附件必附

- 创意脚本或文案画面、审查批准文件、资质复印件、监测标准、报价单；媒介排期单、刊例确认单盖章附后。缺批准文号的法定审查类不得起可发布稿。

### 禁止出现

- 广告法第 9 条禁止情形、第 28 条虚假广告、禁发药品／戒毒治疗、烟草公共场所或向未成年人发送、互联网烟草广告、禁产禁售或禁发商品服务、含集资内容宣传、未使用产品或未接受服务作代言、医疗／药品／医疗器械／保健食品使用代言人、不满十周岁未成年人作代言人、伪造变造转让审查批准文件。
- “包过审”；“仅按甲方提供内容发布、不对合法性负责”且无拒登权。
- 把已能锁定为单一环节的设计、制作、发布、代言、代理或互联网投放整案按广义包办写完。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`基本面.md` 中“发布者不能证明名称地址则承担全部民事责任”按现行先行赔偿口径纠正。`框架.md` 中“广告费一倍以上三倍以下”按现行虚假广告罚款幅度纠正。均不回写双文件。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 留本任务起草并自审；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有、无法细分的广告活动文本；本任务只起草，评改待签文本转配对 ·审查 原子。

### 1. 类型锁死与分类型切开

标题、核心给付与对价方式一致才继续。已能锁定设计、制作、发布、代言、代理或互联网主轴的，负触发对应原子。

### 2. 禁止内容与禁发标的

出现虚假、第 9 条禁止情形、禁发商品服务、烟草违规、集资宣传、违法代言或伪造批件：停笔。

### 3. 主体、角色与经营资格

签约名、履行名、付款名、发票名、角色分列。无资格主体承接：字段停止或停笔。

### 4. 审核义务、证明文件与拒登权

不得把法定审核全部推给广告主。证明不全不得设计制作代理发布。

### 5. 法定审查类与批准文件

未经审查不得发布。批准是发布条件。禁止包过审、禁止伪造转让批件。

### 6. 对外责任、内部追偿、格式条款与强制规范

连带和先行赔偿不能内部免除。无核验引文则法律结论字段停止。

### 7. 样稿签批、监测补播、广告费记载与档案

未经签批不得发布。监测阈值和补播公式写死。广告费据实记载。档案保存期限写明。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、包过审、把禁止内容/未审先发/集资宣传/无资格主体改成可履行结构，或坚持用本技能把已能细分的设计/制作/发布整案改完。
- `字段停止`：法域、动态规则、经营资格、审查批准文号、特医食品是否属应当审查、监测机构资质未核验。
- `目标停止`：主目标已变为评改待签文本、履约交底、争议文书，或已锁他类。
