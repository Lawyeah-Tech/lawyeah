# 房地产委托代建合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、2004 年施工合同解释、2005 年土地使用权解释旧条号、1997 年未修正《建筑法》或 1999 年《招标投标法》单行本当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **委托合同 / 房地产委托代建合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查房地产委托代建合同（委托合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证预售或竣工备案一定办成、保证代建方必然对购房者承担全部质量责任。

## 本类型硬闸

1. **代建费 ≠ 合作开发**：正像是委托方出地、出资并承担投资与市场风险，代建方输出全过程开发管理，对价是基础管理费±绩效，土地及地上建筑物始终归委托方。共同投资、共享利润、共担风险 → `房地产合作开发联合拿地`。不得删掉共担共享句后硬套本技能。
2. **与商业／政府／资本／股权代建切开**：政府投资、财政资金、使用单位三方或代建名录库 → `政府代建合同·审查`。资本方以债权回收、投资收益或现金流分配权为主轴 → `资本代建合同·审查`。代建方入股、跟投或固定价退股 → `股权代建合同·审查`。代建与贷款、配资、出借联立 → `商业代建配资·审查`。标题或用户锁定品牌输出型商业代建产品包 → `商业代建合同·审查`。
3. **代建 ≠ 施工承揽，禁止抄邻类 method**：代建方是管理人，不是按图纸施工的承包人。工程价款、竣工结算、承包范围为主给付 → `工地建筑活动承包资质竣工验收→`。土地使用权父级下的委托代建 → `或`。名为土地一级、实为施工 → `名为一级开发实为施工·审查`。禁止打开或复制上述 method。
4. **建设成本由委托方承担**：民法典第九百二十一条只覆盖处理委托事务的必要费用，不是全部建安垫资。代建方垫付全部建设资金且约定固定利息或固定回报、不承担经营风险的，按土地使用权解释（2020 修正）第二十三条按借款审视，不得改成可履行“代建＋融资”。
5. **产权始终归委托方**：不得把房屋或土地写成代建方所有，也不得用固定套数房屋抵管理费。房屋或土地分成作为对价，按合作开发或买卖切开。
6. **责任以管理过错为限**：有偿委托走第九百二十九条过错责任，不是“仅故意或重大过失”。代建方不得被写成对全部工程质量、销售去化或市场亏损负无限连带，同时只收管理费。投资、市场和政策风险留在委托方。赔偿上限是谈判安排，不是法定限额。
7. **挂靠、违法分包、规避招标只告知**：借用施工资质、把代建改成规避必须招标、政府投资项目用民事代建绕开招标，只出告知，不改成可履行路径。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签房地产委托代建正文，尚未签署，尚未成争，核心给付是市场化项目的全过程开发管理，对价是代建管理费，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 共同投资、共享利润、共担风险，或代建方取得剩余收益并承担全部投资风险 → `房地产合作开发联合拿地`；
- 土地使用权父级下的委托代建、土地一级开发管理为主轴 → `或`；
- 工程价款、竣工结算、承包范围、按图纸施工为主给付 → `工地建筑活动承包资质竣工验收→`；
- 名为土地一级、实为施工 → `名为一级开发实为施工·审查`；
- 政府投资、财政资金、使用单位三方、代建名录库或行政协议 → `政府代建合同·审查`；
- 标题或用户锁定品牌输出型商业代建产品包、险资／纾困操盘整包 → `商业代建合同·审查`；
- 资本方以债权回收、投资收益或现金流分配权为主轴 → `资本代建合同·审查`；
- 代建方入股项目公司、跟投或固定价退股 → `股权代建合同·审查`；
- 代建与贷款、配资、出借、固定利息联立 → `商业代建配资·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `房地产委托代建合同·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁 → `或对应专项领域。` 或建设工程／房地产专项。

以代建为名实施挂靠、违法分包或规避必须招标：只出告知，不改写成可履行路径。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及附件／管理目标责任书／资金需求计划／管理费支付节点表／品牌许可草稿版本；委托方是否持有土地使用权或项目开发权；建设资金由谁承担；对价是管理费、利润分成、固定回报还是股权；代建方是否入股或出借；是否政府投资或必须招标项目；品牌是否输出；重大事项决定权与日常管理权如何切；产权如何写；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `房地产委托代建合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议或建设工程／房地产专项。未签且目标是评改已有房地产委托代建文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。合作开发、施工、政府／商业／资本／股权代建、配资、土地使用权委托代建负触发。

### 2. 代建费与合作开发切割

管理费±绩效可留；共担共享、剩余收益归代建并承担投资风险、固定套数分房，转出或红线。

### 3. 主体、土地权属与资金来源

委托方须有土地使用权或项目开发权；建设资金由委托方落实；政府投资信号转出。

### 4. 管理界面、品牌与产权

重大事项决定权归委托方；日常管理权可授代建方；产权始终归委托方；品牌许可独立成条。

### 5. 对价、垫资与退出

基础管理费与绩效分列；禁止全部建安垫资加固定回报；第九百三十三条随时解除须配清理与已完成工作结算。

### 6. 格式条款与强制规范

无核验引文则法律结论字段停止。挂靠、违法分包、规避招标不得改成可履行。

### 7. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把合作开发或施工改成代建外壳、把挂靠／违法分包／规避招标或全部建设垫资改成可履行。
- `字段停止`：法域、动态规则、土地权属链、资金落实、必须招标边界未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
