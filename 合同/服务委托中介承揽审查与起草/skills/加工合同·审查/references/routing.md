# 边界与路由

本技能只审查 **承揽合同 / 加工合同**。核心给付是完成加工工作并交付工作成果，不是转移通用货物所有权，也不是施工、修理、贴牌或定作人只需收货的制成品买卖。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 通用型号现货、卖方组织生产、买方不控制过程、货交承运人／所有权保留为主路径 | `通用型号现货卖方组织生产买方不控制过程→` |
| 材料多由承揽人、按定作人要求制成新物，定作人不供主材 | `定作合同·审查` |
| 对既存设备、物品修复或恢复功能 | `修理合同·审查` |
| 主给付为贴委托方商标、品牌授权、不得自有品牌转售 | `定牌加工（OEM）合同·审查` |
| 农村低层自建、私人室内装修、小型农田设施等普通项目承揽 | `项目承揽合同·审查` |
| 工地建筑活动、建筑业资质、规划许可、竣工验收 | `工地建筑活动承包资质竣工验收→` |
| 设计采购施工一体或发包人要求主导 | `设计采购施工一体→` |
| 无文本、本类型条件已谈妥、要出己方稿 | `加工合同·起草` |
| 已签未争、投料／验收／付款留痕 | 本套导航的履约步骤 |
| 已成争（质量异议、催告、解除、索赔、立案、仲裁） | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。

本技能不得转去加载买卖或施工双文件完成本类型审查。一旦核心给付是通用货物所有权转移或建设工程施工，立即负触发，不得删掉买卖或施工条款后继续当加工审。
