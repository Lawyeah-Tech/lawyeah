# 加工合同·审查

## 任务目标

在单一立场下，只审查 **承揽合同 / 加工合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。`depends-on` 为空。不要求先跑导航。

不交付：他类审查、从零起草、履约交底、争议文书、有效性或成果必然合格／留置必然实现的保证。

## 工作边界

正触发：已有可读待签文本要评改，；尚未签署，尚未成争，核心给付是承揽人按照定作人要求完成**加工工作**并交付**工作成果**，定作人支付报酬。典型信号：定作人提供主要材料，或按定作人图纸／规格定制并监督过程。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 通用型号现货、卖方组织生产、买方不控制过程 → `通用型号现货卖方组织生产买方不控制过程→`；
- 材料多由承揽人、按定作人要求制成新物 → `定作合同·审查`；
- 对既存物修复、恢复功能 → `修理合同·审查`；
- 主给付是贴委托方商标／品牌授权代工 → `定牌加工（OEM）合同·审查`；
- 农村低层自建、私人室内装修等普通项目承揽 → `项目承揽合同·审查`；
- 工地建筑活动、承包资质、竣工验收 → `工地建筑活动承包资质竣工验收→`；设计采购施工一体 → `设计采购施工一体→`；
- 无文本、本类型条件已谈妥、要出己方稿 → `加工合同·起草`；
- 已签只问投料、验收、付款留痕 → 本套导航的履约步骤；
- 已成争（催告、解除、索赔、诉讼仲裁）→ `或对应专项领域。` 或对应专项领域。

违禁品加工、无许可特种加工、通谋虚假、倒签规避监管：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；定作人或承揽人单一立场；相对方；正文、附件、图纸、材料清单、封样版本；成果名称／规格／数量；主要材料由谁提供；不可接受事项；法域与拟签时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价格、数量、日期用 `【待填】`，不编造。

知识双文件适用场景若混入修理、OEM、软件开发或广告制作，以本技能硬闸和路由为准，不把过宽场景写成正触发。

## 本类型硬闸

审查过程必须逐项点名，不得用买卖检验／风险／所有权保留清单代替：

1. **加工 vs 买卖 vs 定作 vs 工程**：通用现货且买方不控制过程 → `通用型号现货卖方组织生产买方不控制过程→`；定作人供主要材料或按图定制并监督过程 → 本类型；承揽人供主材制成新物 → `定作合同·审查`；工地施工竣工验收 → `工地建筑活动承包资质竣工验收→`／`设计采购施工一体→`。禁止把建设工程当普通加工。
2. **主要工作亲自完成**：未经定作人同意将主要工作交第三人，定作人可解除。修改句锁亲自完成或书面同意，且承揽人仍就第三人成果负责。辅助工作可转，责任仍在承揽人。
3. **材料与图纸**：定作人供材须及时检验、不符即通知；承揽人供材须按约选用并接受检验。发现图纸不合理必须通知，怠于通知的损失分担写清。
4. **验收与留置**：验收期、视为合格条件、报酬支付。未付报酬：承揽人可留置成果或拒绝交付（当事人另有约定除外）。禁止“签收即放弃留置且视为终局合格”一句话吞没。
5. **定作人任意解除（787）**：定作人可在完成工作前随时解除，但赔偿承揽人损失。修改句写清解除通知、已完工部分结算、材料处理、预期利润是否赔。不得删除法定解除权，也不得写成“解除不赔”。
6. **违禁品／无许可特种加工**：枪支、无证危化包装、无证医械等：停笔告知，不改成可履行。
7. **IP**：图纸／模具／商业秘密的归属与侵权担保必须落句。不得默认“成果知识产权当然归定作人”而不写。

风险以工作成果交付为原则（交付前承揽人，逾期受领转定作人）。禁止把“货交承运人风险转移”“所有权保留百分之七十五取回”当加工默认规则。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构，不证明本约条款已被接受。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、1984 年《加工承揽合同条例》当作现行规则。不得把买卖章货交承运人风险、所有权保留百分之七十五取回限制，或建设工程资质／招标／竣工验收，硬套本类型。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验承揽定义、主要工作与辅助工作、材料图纸通知、交付验收报酬、留置、任意解除、保密留存、买卖与建设工程切开；`search_practiced` 补 787 赔偿范围等审查反例；`search_template` 只借修改句结构。不虚构案件系统。

`search_law` 对法律结论为 required 级节点：不可用时不拒绝执行，只停止法律结论字段。返回已失效《合同法》《加工承揽合同条例》时记为噪声，不得写入 `L#`。返回买卖风险／所有权保留或施工资质专属规则时，不得当作本类型默认法。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、把违禁品或无证特种加工改成可履行、删除第 787 条或写成解除不赔、保证成果必然合格或留置必然实现。
- `字段停止`：成果无法特定化；材料提供方或主要工作未定义；特种许可未核验；787 赔偿范围法定口径未核验。
- `目标停止`：主目标已变为他类型起草、履约交底或争议文书。

生存级预付款或个人无限连带且用户拒绝升级：停止“可以签署”建议。
