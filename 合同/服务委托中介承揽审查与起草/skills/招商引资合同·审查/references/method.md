## 节点 2　主体、授权、平台公司与文本版本

1. 建主体表：政府签约机关、未列名但承担审批的财政/自然资源/税务/发改、管委会、平台公司、投资方、拟设立项目公司、授权签字人。名称不一致不自动合并。
2. 政府方适格：核对是否对该项产业支持、用地协助、财政资金、规划调整拥有法定职权和地域管辖。开发区管委会须有授权依据。口头“我们管委会就能定”不得写成已有职权。
3. 平台公司：单独签约须标明民事主体身份，不得写成“代表人民政府”。其承诺的税费、土地、规划，政府方不受当然拘束。修改句要求政府机关作为协议一方，或出具职权内书面政策承诺；平台公司只承担其民事能力范围内的建设、租赁、服务。
4. 投资方：看清是集团、项目公司还是境外主体。集团代签须有授权。外商投资核对外资准入负面清单和安全审查信号；未核验不得写成已可准入。
5. 未加入的机关所作口头承诺不能对抗后续审批。涉及国有资产出资或担保的，另标红旗，不展开国资整案。
6. 口头“领导同意了”“纪要已经定了”不得写成已授权、已完成合法性审查或公平竞争审查。

不足：字段停止，列出待补材料，不补主体、不补授权、不补政府已被拘束。

## 节点 3　政府承诺效力分层（硬闸）

核验后可引用的判断点（须 `search_law` 写入 `L#` 再落法律结论）：

- 起草中的政策措施无法律、行政法规依据或未经国务院批准，不得给予特定经营者税收优惠、选择性财政奖补、要素获取优惠。
- 依法作出的政策承诺和依法订立的合同，不得以换届、区划调整、机构或人员更替为由不履行；因国家利益、社会公共利益依法变更的，公平合理补偿。
- 越权或无依据条款不当然一律无效，但通常不能强制实际履行。

| 文本写法 | 本任务动作 |
| --- | --- |
| “保证税收返还、保证按某价拿地、保证固定收益” | 红线。降级为协助依法申请；写未获批时的退出或替代 |
| 地方留成奖补，附预算科目或规范性文件文号 | 可谈。补兑现条件、测算口径、审批路径和对价挂钩，不得写成必然拨付 |

| 用户要求保证法院会判继续履行全部优惠 | 整体停止该结论 |

反方常见抗辩：签了合同政府就必须兑现。本任务不得把该抗辩写成可放行结构；应区分依法承诺与越权承诺。

## 节点 4　税收与土地优惠合法性（硬闸）

### 4.1 税收

只能承诺协助依法享受法定优惠。约定减免、先征后返、定额包税、擅自退税：红线。地方擅自减免税决定无效，税务机关不得执行。

修改句：删除减免税款条款；改为“政府方协助投资方按法律、行政法规申报可适用的税收优惠，审批结果以有权税务机关决定为准；未获批不构成政府方违约，投资方可按约定延期、减投资或解除”。地方留成范围内的奖补不得写成“退税”，须写成财政奖补并回链预算和文件依据。

无核验引文：税收法律结论字段停止，仍须删除“保证免税”表述。

### 4.2 土地

只能承诺依法供地、协助报批。禁止约定指定地块按某单价成交、流拍后协议出让、未拍即定。工业及经营性用地、同一宗地有两个以上意向用地者，应当招拍挂。

| 文本写法 | 本任务动作 |
| --- | --- |
| “甲方将某某地块按每亩【待填】元出让给乙方，乙方无需参加招拍挂” | 红线。改为依法组织供地，成交价以出让结果为准；本约不替代出让合同 |

## 节点 5　投资义务、奖补挂钩与固定回报禁止

1. 投资义务确定到可判断违约：项目内容、投资总额、分年到位、注册资本实缴、开竣工、达产或税收贡献。约定审计或评估口径，避免“固定资产投资”与“到位资金”混用。只有“加大投资、尽快投产”：必须改。
2. 财政奖补须有预算和规范性文件依据，写清兑现条件、测算口径、审批路径，并与投资到位、开竣工、达产纳税挂钩。未达标按比例扣减或暂缓；已兑现严重违约的，约定返还及利息。禁止预付无条件大额补贴。
3. 禁止固定回报：删除保底收益、回购本息、最低分红、政府补贴补足收益率。政府可承诺配套和防止不必要同类竞争，但不得排除法定准入。命中固定回报或回购本息：红线；用户坚持保留：整体停止。
4. 变更项目内容、选址、投资额重大调整须书面补充协议，并重新履行决策和审查程序。
5. 禁止以政府信用为投资方融资提供保证。建设期履约保函可以谈。财政资金走国库和专项账户。
6. 禁止编造投资额、奖补比例、地价。

## 节点 6　行政协议识别、优益权与争议路径（硬闸）

运行时按三要素核验，不得写成必然行政协议：主体是否行政机关；目的是否行政管理或公共服务；内容是否有行政法上权利义务。平台公司单独签约通常按民事合同审。

| 已有事实 | 不得写成 |
| --- | --- |
| 标题是招商引资协议 | 必然行政协议 |
| 甲方是城投或园区公司 | 政府当然受拘束，或必然行政诉讼 |
| 双方约定仲裁 | 行政协议下仲裁条款有效 |

行政协议：争议走复议或行政诉讼；仲裁条款除法律另有规定外无效。修改句删除仲裁，改为复议、诉讼路径，并写送达地址。不得假装已选定某一法院作为唯一合法结论。

民事招商：可约定与政府所在地或项目地管辖的诉讼或单一仲裁机构。或裁或诉、机构不明：必须改。

优益权：行政机关因严重损害国家利益、社会公共利益变更或解除的，合法则补偿，违法则撤销并赔偿、可判继续履行。修改句把“政府可随时单方解除且不予补偿”改为法定权限、程序和公平合理补偿。政府无故不履行依法承诺和依法订立合同的，投资方可请求继续履行、补救或赔偿；因公共利益依法变更的，转为补偿，避免只堆违约金。

## 节点 7　程序、生效与决策附件

把合法性审查、公平竞争审查、集体决策、批准、招拍挂、供地、外商投资安全审查写成**生效条件或履行期限**，不写成已经完成。

| 文本写法 | 本任务动作 |
| --- | --- |
| “本合同签字盖章后立即生效”，但重大协议依法应完成合法性审查和公平竞争审查 | 必须改。把审查完成或某项批准作为生效条件 |
| 无谁负责、几日内启动供地或申报，无未完成后果 | 补义务主体、期限、未完成时延期或解除 |
| 国资/上市公司/外商投资安全审查未附 | 字段停止；修改句要求作为附件且未获批准不生效 |
| 用户要求倒签或补假审查意见 | 整体停止 |

不得把“双方同意视为已批准、已完成公平竞争审查”写成可放行结构。会议纪要、领导批示转化为书面合同条款前，不得作为履约依据。

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

打开已加载的 `框架.md`，按下列六步逐段对照正文。`基本面.md` 用于校验类型、主体、标的、程序、结构和红旗，不代替本节点出句。框架与本方法冲突时，以本方法为准出句。

| 步 | 动作 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题名实；政府全称与印章；平台公司不得代表政府；鉴于不写保证供地、保证返还、保证固定收益 | 标题或主体修改句 |
| 交易条款 | 投资义务可核验；支持清单纯协助依法申请；土地招拍挂、成交价以出让结果为准、另签出让合同；删除固定回报；奖补挂钩 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 违约与解除可执行；换届不得毁约仅覆盖依法承诺；优益权补偿；行政协议不得仲裁 | 可执行后果句 |
| 尾部 | 政府方用印与授权；签字日/生效日/投资起算日分列；审查意见和授权作附件 | 生效与附件修改句 |
| 语言 | 正说协助报批必须有反说超期后果；删除原则上支持、尽力协调、一事一议；禁止保证获批；交付土地≠出让合同 | 替换空词的句子 |
| 常见问题 | 越权优惠进正文、平台公司绑政府信用 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止；
- `必须改`：可谈但签署前要落句；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。大额投入完全依赖越权承诺且用户拒绝升级：停止“可以签署”建议。
