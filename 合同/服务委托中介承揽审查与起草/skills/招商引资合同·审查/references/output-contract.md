# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证协议有效、税收返还必然兑现、必然拿到指定地块或对方接受；编造未给出的投资额、奖补、地价、期限；把已失效《合同法》及其解释、2015 年行政诉讼法解释写入结论；把越权优惠写成一律无效或一律可强制履行；把招商文本写成已经取得建设用地使用权；把平台公司承诺写成当然拘束政府；把出让或代建主文件留在本技能改完。

## 1. 触发、单方立场与成果状态

立场（政府机关/管委会、园区平台公司、投资方/项目公司）、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明是否同时存在投资落地主给付和依法可兑现支持，以及是否夹带出让、代建或特许经营栏目。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、2015 年行政诉讼法解释、1991 年外资企业所得税法时记噪声，不得写入 `L#`。承诺效力、税收减免、土地招拍挂、行政协议定性与仲裁、换届履约无 `verified-result` 时，对应法律结论字段停止。

## 3. 类型与加载路径

父级 `招商引资合同`，子级 `招商引资合同`。定性理由必须同时满足：投资方到辖区投资落地；对价是依法可兑现的政策支持、要素保障或便利条件，而不是出让金交地、代建管理或特许权。易混切开：国有土地使用权出让、委托代建/政府代建、特许经营/PPP、勾地。

加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读其他类型、未打开 `切开。送审主文件是出让合同，或审查重点是出让金交地规划条件土地登记→负触发该原子。本技能禁止打开或复制其method，禁止把本约改成可签署的出让文本，禁止输出出让金分期交地标准土地登记作为本类型主路径。`、`或` 或 `政府代建合同·审查` method。规避招拍挂、未供先用、固定回报、政府违规担保写停笔告知，不填可履行结构。

## 4. 主体、授权、资质与文本版本

主体表：政府签约机关、实际履约机关（财政/自然资源/税务/发改，若未列签约方须标明）、管委会或平台公司、投资方签约名、项目公司、授权签字人。名称不一致不自动合并。平台公司不得写成人民政府。

版本表：招商正文、支持政策清单、选址示意图、投资计划表、授权文件、合法性审查和公平竞争审查意见、会议纪要、聊天确认。冲突并列，不选对用户有利的一版。口头“领导已经定了”不得写成已授权、已完成决策或已供地。

## 5. 投资与政策支持给付闭环

分列并回链文本位置：

- 项目：名称、建设内容、选址意向。
- 投资义务：总额、分年到位、注册资本实缴、开竣工、达产或税收贡献口径。
- 政府支持清单：类型、金额或计算方式、兑现条件、负责部门、时限。
- 税收：是否仅协助依法申报，还是减免/先征后返/定额包税。
- 土地：拟供地位置、面积、用途、供地方式；是否写明成交价以出让结果为准；是否另签出让合同。
- 财政奖补：预算和规范性文件依据、测算口径、审批路径、与投资到位挂钩。
- 固定回报：有无保底、回购本息、最低分红、补贴补足收益率。
- 考核与回转：中期考核、未达标扣减、严重违约返还。
- 退出：未按期注册、未拿地、未开工的解除与通知。

缺口标 `G#`，不补商业数字。批准、招拍挂、供地、奖补拨付写成条件或双方义务期限，不写成已经完成。

## 6. 格式条款、强制规范与本类型效力红旗

政府方或园区预先拟定、订立时未协商的支持清单和免责条款，按格式条款审查提示说明。

强制规范与效力红旗只在核验后落法律结论：擅自减免税；指定低价协议出让或规避招拍挂；固定投资回报；以政府信用融资保证；行政协议仲裁条款；越权承诺能否强制履行。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

不得把“写进协议的优惠一律无效”或“写进协议就能强制供地、强制退税”写成已核验结论。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔/转出口径。禁止输出无修改句的色块表。

本类型至少检查：越权承诺写成保证兑现；减免税或先征后返；指定地块低价或未拍即定；招商文本替代出让；固定回报或回购本息；平台公司绑定政府信用；行政协议却约定仲裁；投资义务不可核验；奖补无预算依据或不挂钩；会议纪要替代合同；换届可毁约。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`，不编造。禁止只给原则、不给句子。框架与硬闸冲突时按硬闸出句。

建议句必须覆盖本类型硬闸：承诺降级为协助依法申请并写未获批退出；删除减免税和指定低价供地；土地成交价以出让结果为准并另签出让合同；删除固定回报；行政协议删除仲裁或民事招商选定单一路径；平台公司不得代表政府。

## 9. 谈判与签署提醒

谈判顺序：先红线（减免税、指定低价供地、固定回报、政府违规担保、倒签、把出让/代建硬套本类型），再必须改（承诺效力分层、投资口径、奖补挂钩、另签出让、决策附件、争议路径），最后可优化。

签署提醒：政府方加盖行政公章或合同专用章，由法定代表人或载明权限的负责人签；平台公司不得代盖政府章；授权委托书、合法性审查和公平竞争审查意见作附件；日期真实。不指导倒签或补假审查意见。

政府方立场：提示越权条款事后不能强制履行，仍可能引发赔偿或清理风险。投资方立场：提示未完成出让登记不得当成已取得土地使用权；平台公司承诺不能当然向政府主张。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、复议或诉讼文书、出让或代建整案，也不是效力或兑现保证。
