# 审查方法（锁定 中介合同 / 房屋买卖_租赁中介合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制买卖户口/网签过户主路径、施工挂靠、商品房五证清单或劳动试用期节点。

定性校验：标题、核心给付与本类型一致才继续；代签本约、以自己名义成交、销售代理、买卖/租赁本约或其他中介明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、跳单中介必胜、对方必然接受或唯一必得佣金。

`search_law` 返回已失效《合同法》居间章及其解释、已失效《城市房地产中介服务管理规定》、已失效《经纪人管理办法》时记为噪声，不得写入 `L#`。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。职业中介、委托或买卖本约范本只证明是另一类型，不得当作本类型范本。

知识库纠正（不回写双文件）：

- `基本面.md` “中介人是以委托人名义促成交易”：中介通常不以任何一方名义签署买卖/租赁本约。以委托人名义代签 → 负触发 `一般委托合同·审查`；以自己名义成交 → 负触发 `行纪合同·审查`。
- `框架.md` “委托人可随时解除”：第 966 条只是参照适用委托规定，不得写成委托人当然可无偿任意解除且跳单不再付费。解除后仍受第 965 条约束。
- `框架.md` “合同终止后 6 个月至 1 年仍付全额佣金”：约定延展，不是法定期限。须限定利用乙方提供的信息或媒介，并保留自行合法获知例外；天数用 `【待填】`。
- `框架.md` “不买也要付钱”：与第 964 条冲突时，现有依据不支持把未促成写成已可请求报酬。
- 经纪管理办法第 1 条仍引用《合同法》：办法 2016 修正本现行有效，不得把失效合同法写入 `L#`。

必须切开后再加载，禁止两可时灌入两套知识：

- 第 961 条：中介是报告机会或提供媒介，委托人支付报酬。
- 第 919 条：委托是处理委托人事务。
- 第 951 条：行纪是以自己名义从事贸易活动。
- 第 595 条：买卖是转移标的物所有权换价款——本约走 `主文件是二手房买卖本约→`，本任务不审过户主路径。

### 1.3 中介不是委托/行纪（硬闸）

| 文本写法 | 本任务动作 | 修改句方向 |
| --- | --- | --- |
| 乙方仅报告房源/客源、带看、撮合，本约由买卖/租赁双方自行签署 | 正触发，留下本类型 | 首部写明“中介（居间），不构成委托或行纪” |
| 乙方有权代表甲方签署买卖/租赁合同、网签或过户申请 | 负触发委托，或必须改：删除代签 | 「乙方仅提供媒介，无权以甲方或自己名义签署房屋买卖/租赁本约。」 |
| 乙方以自己名义承租/购买后再转给甲方 | 负触发行纪 | 不按中介改完 |
| 开发商委托乙方销售商品房并收销售代理费 | 负触发销售代理 | 不按存量房中介改完 |

最强反方：相对方主张中介已构成委托或表见代理，对外签字约束委托人。修改句必须收回代签和以自己名义成交的权限。用户坚持保留代签主轴：负触发，不填本类型十节实体结论。

### 1.4 阴阳合同 / 骗贷 / 规避限购停笔（硬闸）

加载后或定性中出现：网签价与真实成交价两套文本；协助消费贷、经营贷充首付；伪造购房资格或规避限购；为避税就同一房屋签订不同价款。

动作：

1. 交付告知：经纪管理办法第 25 条第（五）项禁止为规避税费就同一房屋签订不同交易价款提供便利；可能因违法或违背公序良俗无效（第 153、154 条）。不得改写成可履行避税或套贷结构。
2. 不写可履行的阴阳价差处理、假资格路径或体外资金循环。
3. 风险表只保留识别依据和删除/转出口径。
4. 用户坚持“改到能签且仍做这些事”：整体停止。

## 节点 2　主体、备案与人员资格

### 2.1 主体表

建表：签约名、履行名、付款名、发票名、授权签字人。名称不一致不自动合并。委托出售/出租方须是登记权利人或有书面处分权；共有、配偶未闭合：该签署能力字段停止，不写成“可以盖章”。

口头“我们老板同意了”不得写成已授权。卖方委托人未出示权属证书：经纪管理办法第 23 条要求拒绝接受委托，不得改成“先签后补证即可展业”。

### 2.2 备案与人员资格（硬闸）

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 无备案证明、无主管部门查询页 | 字段停止；修改句要求作为附件 | 可以展业 |
| 承办人只有销售名片，无经纪人/协理信息 | 字段停止；第 20 条要求机构印章 + 一名经纪人或两名协理签名 | 个人签字即可约束机构 |
| 只有营业执照 | 执照不等于备案 | 已完成备案 |

修改句：

「本合同签署前，乙方应向甲方出示并作为附件一：所在地建设（房地产）主管部门备案证明或官方查询页；附件二：承办本单的一名房地产经纪人或两名房地产经纪人协理的资格信息。未核验前，不得主张已具备展业与签署条件。」

部门规章备案义务不当然导致民事合同无效（解释第 16 条）。本任务只停止“可以展业”表述，不宣告合同当然无效。

## 节点 3　中介事务、产调与如实报告

### 3.1 中介事务须可核验

审查清单，缺一项则该字段不得写成已闭环：

1. 目标房屋坐落、面积量级、权属证号或“待甲方确认后书面锁定”。
2. 服务内容分列：报告订约机会 / 带看 / 撮合谈判 / 协助准备本约文本 / 协助办理后续手续。协助不是代签。
3. 独家或非独家。独家须加黑提示限制后果；不得写成剥夺委托人自行合法获知后成交的权利。
4. 委托期限起止日。禁止无期限绑定。

禁止只写“提供全程置业服务”而无带看、信息核实和促成标准。

### 3.2 产调与如实报告（硬闸）

支持依据：第 962 条；经纪管理办法第 21、23 条。

| 文本写法 | 动作 |
| --- | --- |
| “乙方已了解房屋情况，甲方知悉后不得异议”且无书面产调 | 必须改。口头不得写成已产调 |
| 中介保证无抵押、无查封、无共有 | 红线删除保证；改为交付查询结果，查询日后新发生负担及时书面补充 |
| 故意隐瞒抵押、查封、共有、居住权、违建或提供虚假房源 | 现有依据支持委托人拒付报酬并请求赔偿。修改句落成合同权利，不在本任务认定已经隐瞒 |

修改句：

「乙方应于首次带看前向甲方交付加盖机构印章的《房屋状况告知书》，并附不动产登记信息查询结果（权利人、共有、抵押、查封、居住权）。口头说明不视为已完成产调，也不视为已尽如实报告义务。乙方故意隐瞒与订立合同有关的重要事实或提供虚假情况，损害甲方利益的，不得请求支付报酬，并应赔偿甲方因此发生的定金损失等直接损失。」

最强反方：中介主张“已带看即已告知”。现有依据不支持把带看或口头陈述单独写成第 962 条已履行。

本节点不展开户口迁移、网签操作手册或过户流程——那是本约审查路径。

## 节点 4　报酬节点与未成退费（硬闸）

支持依据：第 963、964 条。

| 文本写法 | 动作 |
| --- | --- |
| 正式合同签字当日支付全额佣金，无论是否网签、过户、贷款或交房 | 红线。拆成阶段：本约成立 / 网签或租赁备案 / 过户或交房 |
| 未促成也收取“服务费”“看房费”且无必要费用范围 | 必须改。未促成不得请求报酬；必要费用须列明项目与上限 |
| 佣金与必要费用混写 | 必须改：促成后费用由中介负担（第 963 条第 3 款），除非另有可识别约定 |
| 佣金负担方空白 | 媒介促成原则上由本约双方平均负担；可另约由委托方或按当地习惯，数字用 `【待填】` |

修改句：

「甲方应向乙方支付的报酬以乙方促成房屋买卖/租赁合同成立为前提。第一期于【网签完成 / 双方签署书面本约】后【待填】日内支付报酬的【待填】%；第二期于【过户完成 / 交房或租赁备案】后【待填】日内支付【待填】%。乙方未促成合同成立的，不得请求支付报酬，但可请求甲方支付事先书面列明的必要费用，总额不超过人民币【待填】元。因不可归责于甲方的原因本约解除或未能过户/交房的，乙方应于【待填】日内退还尚未对应已完成阶段的报酬。」

禁止编造佣金比例。框架中的买卖 1%–3%、租赁 0.5–1 个月租金只是实务量级，不是法源。

## 节点 5　成交款账户、定金与意向金

### 5.1 成交款不进中介私户（硬闸）

支持依据：经纪管理办法第 24、25 条。

| 文本写法 | 动作 |
| --- | --- |
| 购房款/租金转入经纪人个人账户、微信/支付宝个人码 | 红线删除 |
| 转入经纪机构一般结算户、现金由门店代收 | 红线；改为出卖人/出租人账户、房屋所在地资金监管账户，或经纪机构在银行开立的客户交易结算资金专用存款账户 |
| 约定由经纪机构代收代付且指定专用存款账户、划转须双方签章 | 可保留，但须与佣金账户分列；地方监管规则字段停止待核 |

修改句：

「房屋成交价款及租金仅可转入出卖人/出租人账户，或房屋所在地主管部门/银行资金监管账户，或乙方在商业银行开立的客户交易结算资金专用存款账户。禁止转入经纪人员个人账户、个人收款码或乙方一般结算账户。佣金与成交款分户收付，乙方不得以代收房款抵扣佣金。」

用户坚持保留私户代收：整体停止，不改成“加收据即可放行”。

### 5.2 定金、意向金、订金

必须使用“定金”二字才讨论罚则。中介代收的“意向金”在转给卖方前，现有依据不支持写成已发生定金效力。约定或推算超过主合同标的额百分之二十：超过部分不产生定金效力（第 586 条）。无核验引文不得把 20% 写成现行法结论。

## 节点 6　跳单、格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 跳单（965）（硬闸）

条文：委托人在接受中介人的服务后，利用中介人提供的交易机会或者媒介服务，绕开中介人直接订立合同的，应当向中介人支付报酬。

| 文本写法 | 动作 |
| --- | --- |
| “委托人绕开一律无效且付三倍违约金” | 必须改。绕开不使本约当然无效；违约金不得写成必得倍数 |
| 无“接受服务”“利用该信息”限定 | 必须补范围，否则现有依据不支持无限捆绑 |
| 无自行获知例外 | 必须补。委托人能证明接受服务前已自行合法获知同一对象的，现有依据不支持当然适用 965 |
| 把 965 写成中介必然胜诉 | 禁止。本任务不输出诉讼结果 |

修改句：

「甲方在接受乙方带看、书面房源信息或其他媒介服务后，本人或其配偶、近亲属、控股关联方利用该交易机会或媒介服务，绕开乙方与乙方介绍的相对方订立房屋买卖/租赁合同的，仍应按本合同约定向乙方支付报酬。甲方能够证明其在接受乙方该项服务前已通过政府部门公开查询、权利人直接告知或其他合法途径知悉同一相对方，或成交相对方并非乙方介绍对象的，不适用前款。本条不导致买卖/租赁本约无效。」

终止后延展保护：可约定合理期间 `【待填】` 日，但须重复“利用乙方提供的信息”和自行获知例外。不得把框架的 6–12 个月写成法定期限。

最强反方：委托人主张防跳单是排除主要权利的格式条款。提供方须加黑提示并说明；相对方立场可要求删除过苛倍数或缩短延展期。

### 6.2 格式条款

为重复使用而预先拟定、订立时未与对方协商。从事经营活动的中介不得仅以“这次没用过第二次”否认。依据示范文本制作，不当然排除格式条款。

审查：佣金、跳单、免责、管辖/仲裁等异常条款是否有足以引起注意的标识，以及是否按要求说明（第 496 条；解释第 10 条）。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在附件 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

提供方对其已尽提示或说明承担举证责任。

### 6.3 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的、是否仅行政管理、是否只规制履行行为（第 153 条；解释第 16 条）。禁止用已失效“效力性/管理性”口诀代替解释第 16 条。经纪管理办法多为部门规章：未备案主要是监管后果，不得单独写成民事合同当然无效。阴阳、套贷、侵占房款：不改写成有效履行。

## 节点 7　违约、解除与争议

1. 中介逾期不带看、提供虚假房源、故意隐瞒：可约定减酬、免酬、解除并赔偿直接损失。只有“依法承担违约责任”视为必须改。
2. 委托人无故拒绝带看或拒签确认单：可约定合理催告后视为放弃该次服务，不得直接写成已促成。
3. 构成违约不等于当然解除。法定解除路径只点名催告或目的不能实现，不在本任务作出已解除结论。
4. 违约金不是必得金额；不在本任务做第 585 条精算。修改句避免“不得调整”或“按总价三倍必得”。
5. 第 966 条参照委托：可约定通知解除，但须处理已发生必要费用和第 965 条跳单。不得写成“随时解除且无需付费”。
6. 争议解决：出现仲裁条款，不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核，修改句改成单一仲裁机构或单一法院连结点。专属管辖可能：只标红旗，不选定唯一法院充作法律意见。
7. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。
