# 边界与路由

本技能只审查 **承揽合同 / “合同 + 订单” 模式承揽合同** 的待签文本。中文展示名是「审查“合同 + 订单” 模式承揽合同（承揽合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止把本类型改写成买卖框架订单后继续审。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 库存商品、通用 SKU、转移所有权换价款、无定制工作过程；用户要把检验两段期间或所有权保留当主路径 | `通用型号现货卖方组织生产买方不控制过程→`。不得删掉买卖条款后硬套本技能，也不得抄该原子 method |
| 无框架、无滚动订单的单笔来料加工 | `加工合同·审查` |
| 无框架、无滚动订单的单笔定作 | `定作合同·审查` |
| 修理、修复、更换零部件为主轴 | `修理合同·审查` |
| 复制、翻拍、拷贝成果为主轴 | `复制合同·审查` |
| 单笔或项目制印刷，无 1+N 订单分层 | `印刷合同·审查` |
| 定牌加工、商标授权代工是主给付，而非框架订单规则 | `定牌加工（OEM）合同·审查` |
| 单一项目包干、无滚动任务单 | `项目承揽合同·审查` |
| 建设用地上的建筑安装、施工资质、竣工验收备案 | `工地建筑活动承包资质竣工验收→` 或对应建设工程原子 |
| 无文本、本类型条件已谈妥、要出己方稿 | `框架加订单承揽·起草` |
| 已签未争、只问下单/交货/对账留痕 | 本套导航的履约步骤 |
| 已成争 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

框架正文里夹带一小段库存备件购销：专条交接 `通用型号现货卖方组织生产买方不控制过程→`；框架订单成立、图纸验收、787 解除、对账条款可继续审。用户坚持本技能把买卖框架订单或建设工程整案改完：`目标停止`。
