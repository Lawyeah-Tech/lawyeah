# 审查方法（锁定 中介合同 / 技术转让中介合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制 `技术类合同项下技术中介本约→` 的履行专门服务主路径，禁止复制 `或对应许可原子；` 的资料交接、现场培训、权属变更登记主路径。

定性校验：标题、核心给付与本类型一致才继续；中介人自己让与技术、对履行提供专门服务、许可/开发/咨询本约或其他中介明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、跳单中介必胜、对方必然接受、技术必然产生经济效益或唯一必得佣金。

`search_law` 返回已失效《合同法》居间章及其解释、已失效《技术合同法》及其实施条例、1984 年未修正专利法时记为噪声，不得写入 `L#`。

示范文本只参考结构。专利权转让、技术许可、技术咨询范本只证明是另一类型，不得当作本类型范本。

知识库纠正（不回写双文件）：

- `基本面.md` 「技术交接、现场指导及培训是判定中介服务是否圆满完成的重要节点」：资料交接、现场指导和培训是技术转让本约义务。中介可约定协助办理专利权/申请权转让登记和技术合同认定登记，不得写成中介完成即权利已移转，也不得在本任务把本约交付主路径改完。
- `基本面.md` 「中介人应明确保证已对技术实力和支付能力尽职调查」：第 962 条是如实报告义务，不是保证成交、保证实施或保证经济效益。框架禁止「保证技术能产生经济效益」。
- `基本面.md` 「免征营业税」：营改增后不得写成现行税收优惠。认定登记与增值税/所得税口径运行时复核，字段停止待核。
- `基本面.md` 「专利池许可撮合」：若主文件已是许可本约，负触发对应许可原子；若仍是中介合同且报酬绑促成技术转让（权利让与），许可只作为附属撮合对象时，许可本约专条交接，不把许可范围/使用费当中介主路径。
- `框架.md` 「一定期限内委托人不得无故解除」：第 966 条只是参照适用委托规定，不得写成委托人当然不可解除，也不得写成无偿任意解除且跳单不再付费。解除后仍受第 965 条约束。
- `框架.md` 「保护期 1–2 年」：约定延展，不是法定期限。须限定利用乙方提供的信息或媒介，并保留自行合法获知例外；天数用 `【待填】`。
- 技术合同解释第 38 条对「技术中介合同」的定义（联系介绍以及对履行提供专门服务）只用于负向切开 `技术类合同项下技术中介本约→`，不得当作本技能正触发依据。

4. 用户坚持「改到能签且仍做这些事」：整体停止。

建表：签约名、履行名、付款名、发票名、授权签字人。名称不一致不自动合并。委托人若是拟让与方，须是登记权利人或有书面处分权；若是拟受让方，承接能力只记录文本是否要求，不在本任务做产业可行性结论。

口头「我们单位同意了」不得写成已授权。

### 2.2 职务发明、共有、在先许可（字段停止）

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 发明人个人委托转让其在职期间完成的技术，无单位书面授权 | 字段停止；修改句要求单位权属确认或授权作为附件 | 可以撮合过户 |

「本合同签署前，拟让与方应向甲方和乙方提交并作为附件：专利权/申请权权属证明或技术秘密权属声明；非职务发明或单位书面授权文件；全体共有人同意转让的书面文件；在先许可、质押、无效程序和年费缴纳情况说明。未核验前，乙方不得主张已具备促成让与的条件，甲方亦不得被写成已确认权属洁净。」

## 节点 3　中介事务与如实报告

### 3.1 中介事务须可核验

审查清单，缺一项则该字段不得写成已闭环：

1. 拟转让技术名称、专利号/申请号或技术秘密范围、技术领域、所处阶段（实验室 / 中试 / 产业化；TRL 用 `【待填】`）。
2. 服务内容分列：报告订约机会 / 组织洽谈与考察 / 协助准备本约文本 / 协助办理登记或认定登记。协助不是代签，也不是本约交付。
3. 独家或非独家。独家须加黑提示限制后果；不得写成剥夺委托人自行合法获知后成交的权利。
4. 委托期限起止日。禁止无期限绑定。

禁止只写「提供全程技术转移服务」而无信息核实、促成标准和保密安排。

### 3.2 如实报告技术来源 / 权属 / 成熟度（硬闸）

支持依据：第 962 条。

| 文本写法 | 动作 |
| --- | --- |
| 「乙方已了解技术情况，甲方知悉后不得异议」且无书面报告 | 必须改。口头不得写成已尽调 |
| 中介保证无职务发明、无共有、无许可、专利有效、能够达到约定经济效益 | 红线删除保证；改为交付书面核查结果，查询日后新发生负担及时书面补充。经济效益不得保证 |
| 故意隐瞒权属瑕疵、无效程序、在先独占许可、未中试却写成已产业化，或提供虚假技术参数 | 现有依据支持委托人拒付报酬并请求赔偿。修改句落成合同权利，不在本任务认定已经隐瞒 |

修改句：

「乙方应于向甲方披露潜在交易对象或安排实质洽谈前，向甲方交付加盖机构印章的《技术与交易对象情况报告》，至少载明：技术来源；权属人及是否职务发明、共有；专利法律状态、年费和无效程序；在先许可或质押；已知实验数据、是否中试及 TRL 等级；交易对象的主体资格与公开可核验的支付能力迹象。口头说明不视为已尽如实报告义务。乙方故意隐瞒与订立合同有关的重要事实或提供虚假情况，损害甲方利益的，不得请求支付报酬，并应赔偿甲方因此发生的直接损失。乙方不保证标的技术能够产生任何经济效益。」

最强反方：中介主张「已组织考察即已告知」。现有依据不支持把考察或口头陈述单独写成第 962 条已履行。

第 870 条让与人保证合法拥有、技术完整有效，是技术转让本约义务，不得转写成中介的实施担保。

## 节点 4　报酬节点与未成费用（硬闸）

支持依据：第 963、964 条；技术合同解释第 39 条。

| 文本写法 | 动作 |
| --- | --- |
| 本中介合同签字当日支付全额佣金，无论技术转让本约是否签署、生效、登记或首期款是否支付 | 红线。拆成阶段：本约成立并生效 / 首期款支付 / 专利权或申请权转让登记 |
| 未促成也收取「服务费」且无必要费用范围 | 必须改。未促成不得请求报酬；必要费用须列明项目与上限 |
| 佣金与必要费用混写 | 必须改：促成后费用由中介负担（第 963 条第 3 款），除非另有可识别约定。前期费须标明是成本补偿还是预付报酬 |
| 后续提成未定义净销售额 | 必须改：列明扣除项（税费、包装、运费等用 `【待填】`）及中介查询/审计权限 |
| 佣金负担方空白 | 媒介促成原则上由本约双方平均负担；可另约，数字用 `【待填】` |

修改句：

「甲方应向乙方支付的报酬以乙方促成技术转让合同成立为前提，并按下列阶段支付：第一期于技术转让合同生效且让与人收到首期技术转让价款后【待填】日内支付报酬的【待填】%；第二期于专利权或专利申请权转让登记完成（技术秘密转让则以资料交接确认且不违反保密约定）后【待填】日内支付【待填】%。后续提成以受让方实施标的技术所产生的净销售额为基数，净销售额等于【待填】，扣除【待填】。乙方未促成合同成立的，不得请求支付报酬，但可请求甲方支付事先书面列明的必要费用，总额不超过人民币【待填】元。因不可归责于甲方的原因本约被撤销、被确认无效或未能完成转让登记的，已付但尚未对应已完成阶段的报酬，乙方应于【待填】日内退还。」

技术合同解释第 41 条：中介对技术合同无效或被撤销无过错的，中介条款仍可能支持费用和报酬。修改句保留「中介有过错则不得请求」；不得把本约无效当然写成中介合同无效，也不得把解释第 41 条写成中介必得全额。

禁止编造佣金比例。框架未给出法定比例。

## 节点 5　保密、分级披露与登记协助

### 5.1 保密与分级披露（硬闸）

标的含技术秘密或未公开参数时，本节点优先于任何实质披露安排。

| 文本写法 | 动作 |
| --- | --- |
| 先向多家潜在买家发送完整工艺规程、配方或源代码，成交后再补 NDA | 红线。核心披露前必须签署 NDA |
| 无分级：一次交清全部 Know-how | 必须改：初期仅披露技术概况；深度接触须委托人书面授权并分阶段披露，全程留痕 |
| 合同终止后中介可保留技术底稿和客户名单 | 必须改：交回或销毁，并书面确认 |
| 泄密违约金空白或「依法承担责任」 | 必须改：可执行金额用 `【待填】`，可参考拟促成的技术转让费总额，但不编数字 |

修改句：

「在向任何第三方披露标的技术的核心参数、工艺规程、配方或源代码前，乙方应确保甲方、乙方与该第三方已签署书面保密协议。撮合初期乙方仅可披露技术名称、专利号或公开文本、应用领域和成熟度等级。核心资料的披露须经甲方事先书面授权，并按附件《分级披露清单》分阶段进行。合同终止后【待填】日内，乙方应向甲方交回或销毁全部技术资料和潜在客户清单，不得私自保留复制件。乙方违反本条的，应向甲方支付人民币【待填】元违约金，并赔偿因此发生的直接损失。」

用户坚持无 NDA 向不特定第三方交核心资料：整体停止。

### 5.2 登记与认定登记只可协助

专利权或专利申请权转让自登记之日起生效（专利法 2020 修正第 10 条）。修改句可要求中介在促成后【待填】日内协助准备登记材料，但：

- 不得写成「乙方办完登记即视为中介服务圆满完成且权利已移转」；
- 不得在本任务展开转让登记操作手册或技术资料验收标准——那是本约路径；
- 跨境或限制类技术：把取得进出口许可或国家秘密技术出口审查批准写成中介合同或本约的生效前提，未取得则不得安排出境披露。

## 节点 6　跳单、格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 跳单 / 影子成交（965）（硬闸）

条文：委托人在接受中介人的服务后，利用中介人提供的交易机会或者媒介服务，绕开中介人直接订立合同的，应当向中介人支付报酬。

| 文本写法 | 动作 |
| --- | --- |
| 「委托人绕开一律无效且付三倍违约金，中介必然胜诉」 | 必须改。绕开不使技术转让本约当然无效；违约金不得写成必得倍数 |
| 无「接受服务」「利用该信息」限定 | 必须补范围，否则现有依据不支持无限捆绑 |
| 无自行获知例外 | 必须补。委托人能证明接受服务前已自行合法获知同一对象的，现有依据不支持当然适用 965 |
| 把 965 写成中介必然胜诉 | 禁止。本任务不输出诉讼结果 |

修改句：

「甲方在接受乙方书面技术/交易对象信息、组织洽谈或其他媒介服务后，本人或其控股关联方利用该交易机会或媒介服务，绕开乙方与乙方介绍的相对方订立技术转让合同（含专利权、专利申请权或技术秘密相关权利让与）的，仍应按本合同约定向乙方支付报酬。甲方能够证明其在接受乙方该项服务前已通过专利登记簿公开查询、权利人直接告知或其他合法途径知悉同一相对方，或成交相对方并非乙方介绍对象的，不适用前款。本条不导致技术转让本约无效。」

终止后延展保护：可约定合理期间 `【待填】` 日，但须重复「利用乙方提供的信息」和自行获知例外。不得把框架的 1–2 年写成法定期限。目标方名单应作为附件，否则 965 因果难以回链。

最强反方：委托人主张防跳单是排除主要权利的格式条款。提供方须加黑提示并说明；相对方立场可要求删除过苛倍数或缩短延展期。

### 6.2 格式条款

为重复使用而预先拟定、订立时未与对方协商。从事经营活动的中介不得仅以「这次没用过第二次」否认。依据示范文本制作，不当然排除格式条款。

审查：佣金、跳单、免责、管辖/仲裁、保密罚则等异常条款是否有足以引起注意的标识，以及是否按要求说明（第 496 条；解释第 10 条）。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在附件 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

提供方对其已尽提示或说明承担举证责任。

### 6.3 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的、是否仅行政管理、是否只规制履行行为（第 153 条；解释第 16 条）。禁止用已失效「效力性/管理性」口诀代替解释第 16 条。未核技术经纪资质主要是监管后果，不得单独写成民事合同当然无效。非法垄断、未许可出境、假转让套取资金：不改写成有效履行。

## 节点 7　违约、解除与争议

1. 中介逾期不提交书面报告、提供虚假技术参数、故意隐瞒权属瑕疵、违反保密：可约定减酬、免酬、解除并赔偿直接损失。只有「依法承担违约责任」视为必须改。
2. 委托人无故拒绝接收书面报告或拒不参加已安排的洽谈：可约定合理催告后视为放弃该次服务，不得直接写成已促成。
3. 构成违约不等于当然解除。法定解除路径只点名催告或目的不能实现，不在本任务作出已解除结论。
4. 违约金不是必得金额；不在本任务做第 585 条精算。修改句避免「不得调整」或「按技术转让费三倍必得」。
5. 第 966 条参照委托：可约定通知解除，但须处理已发生必要费用、保密义务和第 965 条跳单。不得写成「随时解除且无需付费」，也不得写成绝对不可撤销。
6. 争议解决：出现仲裁条款，不得改写成「应向某法院起诉」并假装已选定诉讼。或裁或诉、机构不明：标待核，修改句改成单一仲裁机构或单一法院连结点。专属管辖可能：只标红旗，不选定唯一法院充作法律意见。
7. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。

撮合过程中产生的改进方案、市场分析报告的知识产权：通常可约定归委托人；「谁改进谁拥有」不得写成限制对方继续研发或吸收竞争技术。后者落入节点 1.5。

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（自己让与/履行专门服务主轴、签字即全额无论本约成立拒改、无 NDA 披露核心资料、850/未许可出境/假转让、倒签、保证经济效益拒删）；
- `必须改`：可谈但签署前要落句（965 例外、报酬阶段、书面尽调、分级披露、权属/共有/职务发明附件）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级提成基数无法核验且用户拒绝升级：停止「可以签署」建议。
