# 技术转让中介合同·起草

## 任务目标

在单一立场下，只起草 **中介合同 / 技术转让中介合同** 的待签文本，按已谈妥条件出己方稿，输出可编辑草稿、未决项；出稿后必须用本类型硬闸自审，输出风险表和修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查技术转让中介合同（中介合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、待签文本签前审查、履约交底、争议文书、跳单诉讼策略、有效性保证、把技术转让本约或技术许可本约改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **只报告机会，不转让技术**：核心给付是报告订立技术转让合同的机会或提供媒介。中介人自己让与专利权、专利申请权或技术秘密，或主文件是技术转让本约 → 负触发 `或对应许可原子；`（单独成册则 `单独成册则` / `单独成册的专利申请权转让` / `单独成册的技术秘密转让`）。不得把中介合同改成本约，也不得删本约后硬套。
2. **与技术类合同项下技术中介切开**：父级锁死中介合同。文本以知识、技术、经验和信息联系介绍，并对第三人技术合同的履行提供专门服务作为主给付，或同时撮合开发、许可、转让而不限定技术转让本约 → 负触发 `技术类合同项下技术中介本约→`。禁止打开或复制 `技术类合同项下技术中介本约→`、`或对应许可原子；` 的 method。
3. **报酬节点（963 / 964）**：促成技术转让合同成立才可请求报酬。阶梯：固定前期费（成本补偿）+ 签约佣金 + 可选后续提成。支付节点绑本约生效且首期款，或专利权/申请权转让登记完成。禁止「本中介合同签字即全额，无论本约是否签署、生效、登记或首期款是否支付」。未促成不得请求报酬；必要费用须列明上限。提成须定义净销售额扣除项。
4. **跳单 / 影子成交（965）**：接受服务后利用中介提供的机会或媒介绕开签约，仍应付酬。修改句写清范围，并写入自行合法获知、成交对象非介绍对象的例外。不得把 965 写成中介必胜，也不得把 1–2 年保护期写成法定期限。
5. **如实报告技术来源 / 权属 / 成熟度（962）**：书面报告技术来源、所有权合法性、技术实力（实验数据、是否中试、TRL）、权利瑕疵（质押、在先独占/排他许可、无效程序、年费）。不得把「中介口头说权属没问题」写成已尽调。故意隐瞒或虚假：不得请求报酬并应赔偿。中介不得保证技术必然产生经济效益。
6. **保密与分级披露**：披露核心参数、源代码或工艺规程前必须签署 NDA。初期只披露技术概况。中介不得私自保留技术底稿。未分级披露核心 Know-how：必须改。
7. **非法垄断 / 限制出口 / 涉密 / 假转让停笔**：限制改进或限制吸收竞争技术；国家秘密技术或限制进出口技术未经许可；名为技术转让实为资金套取。只告知，不改成可履行违法结构。用户坚持：整体停止。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签技术转让中介正文，尚未签署，尚未成争，核心给付是报告订立技术转让合同的机会或提供媒介，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 技术类合同项下概括技术中介，或主给付是对第三人技术合同履行提供专门服务 → `技术类合同项下技术中介本约→`（P1；专业版未装则 `unavailable`）；
- 主文件是技术转让本约，或中介人自己让与技术 → `或对应许可原子；`；单独成册的专利权/申请权/技术秘密转让 → `单独成册则` / `单独成册的专利申请权转让` / `单独成册的技术秘密转让`；不得删本约后硬套；
- 主文件是技术许可、专利实施许可、技术秘密使用许可 → `主文件是技术许可专利实施许可技术秘密使用许可→` / `专利实施许可合同·审查` / `技术秘密使用许可合同·审查`；
- 主给付是可行性论证、分析预测，报酬不绑促成 → `或`；解决特定技术问题 → `或`；技术开发本约 → `只审委托合同目录下的委托技术开发。用户或材料按技术类合同进入《技术开发合同》→`；
- 求职介绍 → `职业中介合同·审查`；婚介 → `婚姻中介合同·审查`；房屋买卖/租赁居间 → `房屋买卖_租赁中介合同·审查`；
- 代签技术转让本约、概括处理缔约事务 → `一般委托合同·审查`；以自己名义受让再转出 → `行纪合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁，或要跳单诉讼策略 → `或对应专项领域。` 或对应专项领域。

非法垄断、未许可限制出口、涉密出境、假转让套取资金：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（委托人侧或中介机构侧择一）；相对方；全文及附件/保密承诺/技术清单版本；核心给付是媒介还是自己让与/对履行提供专门服务；拟促成的本约是权利让与还是许可或开发；独家或非独家；报酬构成与节点；技术类型与阶段；权属、职务发明、共有人、在先许可痕迹；是否跨境或涉密；NDA 是否已签；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的佣金比例、提成基数、期限用 `【待填】`，不编造。

## 起草模式

本原子只承担本类型起草。待签评改转 `技术转让中介合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `技术转让中介合同·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`，不编造。

### 起草必写

- 核心给付是报告订立技术转让合同的机会或提供媒介，不是自己让与技术。
- 报酬阶梯：固定前期费（成本补偿）+ 签约佣金 + 可选后续提成；促成技术转让合同成立才可请求报酬。
- 支付节点绑本约生效且首期款，或专利权/申请权转让登记完成。
- 未促成不得请求报酬；必要费用须列明上限；提成须定义净销售额扣除项。
- 跳单写清范围，并写入自行合法获知、成交对象非介绍对象的例外；不得把 965 写成中介必胜，也不得把 1–2 年保护期写成法定期限。
- 书面报告技术来源、所有权合法性、技术实力（实验数据、是否中试、TRL）、权利瑕疵（质押、在先独占/排他许可、无效程序、年费）；中介不得保证技术必然产生经济效益。
- 披露核心参数、源代码或工艺规程前必须签署 NDA；初期只披露技术概况；中介不得私自保留技术底稿。
- 专利登记只可约定协助，不得写成中介完成即权利已移转。

### 附件必附

- 技术清单、保密承诺/NDA。
- 书面权属/成熟度/瑕疵报告。
- 职务发明单位授权、共有人全体同意、在先独占/排他许可痕迹（有事实则附）。

### 禁止出现

- 「本中介合同签字即全额，无论本约是否签署、生效、登记或首期款是否支付」。
- 把「中介口头说权属没问题」写成已尽调；保证技术必然产生经济效益。
- 中介人自己让与专利权、专利申请权或技术秘密，或把技术转让本约/许可本约当中介出稿。
- 把「技术交接、现场指导及培训」写成中介完成标准（那是技术转让本约义务）。
- 限制改进或限制吸收竞争技术；国家秘密技术或限制进出口技术未经许可；名为技术转让实为资金套取：只告知，不起可履行稿。

出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)

禁止打开其他类型目录。`基本面.md` 把「技术交接、现场指导及培训」写成中介完成标准时，以 method 纠正为准：那是技术转让本约义务。`框架.md` 把 1–2 年保护期或「不可撤销期不得解除」写成当然规则时，不得放行。`基本面.md` 「免征营业税」不得写成现行优惠。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 留本任务起草并自审；已签履约 → 本套导航履约步骤；已成争或跳单诉讼策略 → 合同争议。未签且目标是评改已有技术转让中介文本；本任务只起草，评改待签文本转配对 ·审查 原子。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。自己让与、对履行提供专门服务、许可/开发/咨询本约、其他中介负触发。

### 2. 主体、职务发明、共有与在先许可

签约名、履行名、付款名、发票名分列。职务发明单位授权、共有人全体同意、在先独占/排他许可未核：字段停止。

### 3. 中介事务与如实报告

写清报告机会还是媒介；书面权属/成熟度/瑕疵报告；不得把口头说没事写成已尽调；不得保证经济效益。

### 4. 报酬节点与未成费用

禁止签字即全额且无论本约成立。提成须定义净销售额。

### 5. 保密、分级披露与登记协助

核心披露前必须 NDA。专利登记只可约定协助，不得写成中介完成即权利已移转。

### 6. 跳单、格式条款与强制规范

965 写范围与例外。850/进出口/假转让停笔。无核验引文则法律结论字段停止。

### 7. 违约、解除与争议

未促成不得请求报酬。不选定唯一法院充作意见。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把未许可出境、非法垄断或假转让套取资金改成可履行结构。
- `字段停止`：法域、动态规则、职务发明/共有/在先许可、进出口目录与许可、技术经纪资质未核验。
- `目标停止`：主目标已变为评改待签文本、履约交底、争议文书、跳单诉讼策略，或已锁他类。
