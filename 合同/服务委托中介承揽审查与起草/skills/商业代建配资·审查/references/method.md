# 审查方法（锁定 委托合同 / “商业代建 + 贷款配资” 合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止打开或复制 `商业代建合同·审查`、`资本代建合同·审查` method。禁止套用纯商业代建的品牌许可、VIS、去化率、样板区节点。禁止套用资本代建的基金投资、优先劣后、退出清算主线。禁止套用施工合同无效公式或第 933 条当作唯一主路径。禁止把本技能写成纯代建或企业拆借换标题。

定性校验：核心给付同时包含商业代建管理和配资支持，才继续；明显他类则负触发，不填十节实体结论。

本文件是可执行判断节点，不是栏目说明书。每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、已经放款、已经设立抵押权，或唯一必得本息。

`search_law` 返回已失效《合同法》《担保法》《物权法》及其解释、1991 年《关于人民法院审理借贷案件的若干意见》、2015 年民间借贷司法解释中 24%/36% 条文、民法通则或民法总则已被替代条文时记为噪声，不得写入 `L#`。`search_practiced` 仍写“企业间借贷一律无效”“政府代建示范文本适用于商业配资”“24%/银行利率旧四倍”的，同样记噪声。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

示范文本只参考结构。北京市政府投资代建示范文本解决的是财政资金代建，不证明本约配资条款合法。联合开发、纯融资顾问范本不得当本约规则。

知识库口径冲突以本方法为准，不回写知识正文：

- `基本面.md` 把“代建是名、配资是实”写成当然定性：纠正为必须先核验代建义务是否真实存在。双实联立按联立合同处理；只有抽空代建、固定本息时才按明代建实借贷。
- 称“借款协议无效往往会直接导致代建合同无效”：纠正为借款无效可能导致代建目的落空或解除清理，不当然使代建条款全部无效。
- 把 LPR 四倍写成“法定利率上限”：纠正为民间借贷司法保护上限；持牌机构及七类地方金融组织不适用。
- 用“三道红线”或《贷款通则》对企业间借贷的处罚宣告民事合同无效：纠正为部门规章或监管政策不当然导致民事无效；企业间为生产经营需要的临时借贷，除民借第 13 条等无效事由外，当事人主张有效的，应予支持。效力仍须按民法典第 153 条和合同编通则解释第 16 条逐项核验。
- “暴力清算”“1 元收购股权”：不得改成可履行接管，只能改清算型优先受偿。
- 抽逃出资外观：只标红旗和分账修改句，不在本任务出具公司资本合规意见。

开发窗口 2026-08-18 已核验、可供对照但不得代替运行时核验的规则：

- 民法典第 153 条：违反法律、行政法规强制性规定的民事法律行为无效，但该强制性规定不导致无效的除外；违背公序良俗的无效。
- 民法典第 394、395 条：抵押不转移占有；建设用地使用权、正在建造的建筑物可以抵押。
- 民法典第 399 条：土地所有权、宅基地等集体土地使用权（法律另有规定除外）、公益设施、权属不明或有争议、查封扣押监管财产不得抵押。
- 民法典第 400 条：抵押合同书面；应有被担保债权、履行期限、抵押财产、担保范围。
- 民法典第 401、428 条：期前约定抵押或质押财产归债权人所有的，只能依法优先受偿。
- 民法典第 667 条：借款合同是借款人向贷款人借款，到期返还借款并支付利息的合同。
- 民法典第 670 条：利息不得预先在本金中扣除；预先扣除的，按实际借款数额返还并计息。
- 民法典第 680 条：禁止高利放贷，利率不得违反国家有关规定；未约定利息视为没有利息。

- 同规定第 25 条：约定利率超过合同成立时一年期 LPR 四倍的部分不予支持。
- 同规定第 26 条：预先在本金中扣除利息的，以实际出借金额为本金。
- 同规定第 29 条：逾期利息、违约金和其他费用可选择或一并主张，总计超过合同成立时一年期 LPR 四倍的部分不予支持。
- 法释〔2020〕28 号第 7、8 条：公司对外担保的决议与善意相对人；特定例外。
- 同解释第 49 条：以违法建筑物抵押的，抵押合同无效，但一审辩论终结前办妥合法手续的除外。
- 同解释第 68 条：形式上转移到债权人名下、到期可折价或拍卖变卖偿债的约定有效；归债权人所有的约定无效，不影响担保意思。

- 公司法（2023 修订）第 15 条：公司为他人担保由董事会或股东会决议；为股东或实际控制人须股东会且关联股东回避。

## 节点 2　主体、项目公司、土地使用权人与第三方资方

1. 建主体表：委托方/借款人、代建方、出借人或引资人、第三方资方、项目公司、土地使用权人、保证人、抵押权人、质权人。名称不一致不自动合并。同一主体兼数职必须逐职标注。
2. 委托方原则上应为土地使用权人或其全资/控股项目公司。材料未出示权属或立项主体与签约名不一致：该签约能力字段停止，不得写成“可以盖章开发”。
3. 代建方直接出借：记录是否自称持牌或“有充足自有资金”。协助引资：记录是否提供差额补足。不得把“头部房企”写成已具备放贷资格。
4. 第三方资方（关联基金、信托、小贷）：必须出现在合同组或三方监管协议。抵押权登记在资方名下、借款人却是代建方的，优先受偿结论停止，修改句要求债权人、抵押权人一致或写明委托持有。
5. 公司以土地、在建工程或股权为配资提供担保：按章程由董事会或股东会决议；为股东或实际控制人须股东会决议，该股东不得表决。未附决议：字段停止，修改句要求作为附件且未获批准不放款、不办理登记。公司法条号用 2023 年修订第十五条。
6. 口头“我们老板同意了”不得写成已授权或已决议。

不足：字段停止，列出待补材料，不补主体、不补权属、不补已同意。

## 节点 3　配资定性与合同组交叉引用（硬闸）

本类型是合同组：开发管理委托与资金支持联立。允许合并一份，也允许主代建 + 借款 + 担保分签；关键是交叉引用和账目分列。

核验后可引用的判断点（须 `search_law` 写入 `L#` 再落法律结论）：

- 企业间为生产经营需要的临时借贷，除法定无效事由外，主张有效的应予支持。
- 未取得放贷资格而向不特定对象经营性放贷，合同应认定无效。
- 协助融资未写成结果义务的，不当然构成必须放款。

| 文本写法 | 本任务动作 |
| --- | --- |
| “乙方协助融资，确保 X 日内贷款到位，否则按全额配资赔偿” | 必须改。要么改成自有资金出借并写放款日，要么删除“确保/到位”和结果罚则，改回尽力撮合 |
| “融资顾问协议”但顾问费按放款额固定比例收取，且无代建义务 | 追问是否还有代建主文件。无代建 → 负触发企业借款或名实借贷。有代建但顾问费实为利息 → 并入节点 4 |
| 代建范围被写成“视乙方便利”，对价却是固定年化回报 | 明代建实借贷。修改句补真实借款要素，或红线要求恢复可核验的代建义务 |
| 代建、借款、担保三份文本目的互相否定 | 必须改。交叉引用：借款支持代建项目建设；代建费与利息分列；担保只担保配资债权 |
| 生效条件写成“双合同签署且首笔配资到账” | 可接受，但须写未到账时已签署文本的清理、已发生代建成本由谁承担 |
| 用户要求保留“顾问费”外壳以便超过保护上限仍能收取 | 整体停止该结论 |

反方常见抗辩：有代建合同所以不是借贷；有顾问协议所以不受利率上限。本任务不得把该抗辩写成可放行结构。

## 节点 4　利率与代建费、顾问费并表（运行时核验）（硬闸）

禁止直接输出下列口径作为现行保护标准：

- 银行同类贷款利率四倍（1991 年意见口径）；
- 年利率 24%、年利率 36%（2015 年司法解释口径）；
- 任何未核验的“四倍”或“法定上限”。

动作：

1. 先判断资金提供方是否为金融监管部门批准的放贷机构，或法释〔2020〕27 号所列七类地方金融组织。是：不得套用民间借贷上限；利率是否合规改走监管规则核验，核验失败则该法律结论停止。
2. 民间借贷路径：调用 `search_law` 查询“民间借贷利率司法保护上限 现行规定”。仅当返回现行有效规则时写入 `L#`，再对照文本利率。
3. 制作费用年化表：书面利率；代建费是否因提供融资而明显高于用户陈述或附件中的市场口径；融资顾问费、通道费、咨询费；逾期利息；违约金。能识别为资金占用对价的，一并计入。市场代建费无法核验时，溢价字段标 `G#`，不得编造“市场标准是 X%”。
4. 预扣利息、先扣顾问费或代建进场费再放款：按实际到账额计本金。
5. 一年期 LPR 当次数值未核验：不编造百分比，用 `【合同成立时一年期 LPR × 核验所得倍数，待填】`。
6. 不得把定金罚则塞进本类型充利息。代建履约保证金不是配资本金。
7. 开发窗口 2026-08-18 核验结果见文首对照表。核验失败或只返回已修改文本：利率法律结论字段停止。仍可摘录文本费率并给出“待核验现行上限后改写”的修改句草稿。

## 节点 5　担保包：权利人、公示、决议、禁止暴力清算（硬闸）

期前约定债务人不履行到期债务时抵押财产、质押股权或项目本身归债权人所有的，只能依法就该财产优先受偿。归己所有、1 元收购、无需评估接管，约定无效，但不因此否定提供担保的意思。

| 文本写法 | 本任务动作 |
| --- | --- |
| 抵押权人是乙方关联信托，借款人条款里的出借人是乙方 | 必须改。统一债权人与抵押权人，或补委托持有/三方监管。否则优先受偿结论停止 |
| “甲方逾期，乙方有权按 1 元或三折收购项目公司全部股权，无需清算” | 红线。改为折价或拍卖、变卖，参照评估价，多退少补；给合理宽限期 |
| “签字即视为已办理抵押/股权质押，可对抗第三人” | 红线。禁止拟制公示。补谁在几日内申请登记、未完成不得放款 |
| 以查封土地、权属争议地块、违法在建工程设定抵押 | 红线。告知不得抵押或抵押合同可能无效，不写可履行登记路径 |
| 保证条款只写“提供担保”未写一般或连带 | 必须改。未改不得写成连带；法律结论按一般保证 |
| 公司担保未附决议，或为股东担保未见回避表决 | 字段停止；修改句要求决议作附件 |
| 销售回款质押与预售资金监管冲突 | 必须改。监管账户内资金不得写成可任由乙方划扣；修改句把划扣范围限于监管解除后的可分配余额 |
| 用户要求保留直接接管以便快速平仓 | 整体停止 |

担保句最低要素：担保债权范围（是否含代建费——默认不含，除非单列）；财产特定化；权利人与债权人一致；登记义务和未完成后果；实现方式为折价或拍卖、变卖；余款返还。缺一项补一项。

未办理抵押或股权出质登记，不影响担保合同原则上成立生效，也不等于已经取得担保物权。材料未提及不得写成“无在先抵押、查封或预售监管”。

## 节点 6　资金闭环、交叉违约与任意解除

1. 提款前提（四证、进场、抵押登记完成）写成生效或放款条件，不写成已经完成。
2. 共管账户：开户行、预留印鉴、支付范围、乙方一票否决的对象（仅建设支出还是全部资金）。一票否决不得写成可挪用到乙方自身账户。
3. 回款顺序：通常先约定本息，后管理费。正文与附件冲突则并列，修改句指定唯一顺序。
4. 代建延误是否构成配资展期：必须有可核验的延误定义和展期天数，不得只写“视情况”。
5. 配资逾期是否赋予停工权或撤品牌权：须有催告、宽限期、已完工作结算和已投入资金清理。不得写成单方毁标且不结算。
6. 提前还清配资：默认不当然解除代建。修改句写明代建是否继续、管理费是否调整为不含融资溢价的口径。
7. 第 933 条任意解除：本类型是有偿委托与借款联立。修改句可以约定解除代建不影响已发生配资债权，解除借款不当然消灭已提供的代建服务报酬请求权；不得写“放弃一切法定解除权且无需赔偿”。
8. 动态授信、按形象进度放款：可接受。必须有可核验里程碑，不得把“乙方满意即可放款”写成已确定义务。

## 节点 7　效力红旗与监管外观

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

本节点只做红旗，不替代节点 3–5 的修改句。

| 已有事实 | 不得写成 |
| --- | --- |
| 乙方以代建加配资为常业、向不特定项目方放贷 | 企业间借贷所以一定有效 |
| 资金来自银行贷款再转借项目公司 | 可以改成可履行转贷 |
| 甲方把配资当作项目公司资本金再以代建费回流乙方 | 已经完成合法出资；本任务只标抽逃外观，要求代建费率可核验、资金闭环可追溯 |
| 为规避房地产开发贷款监管而设计本结构 | 必然因公序良俗整约无效；也不得保证监管零风险 |
| 小字印刷的单方调价、最终解释权、远程管辖 | 已尽格式条款提示义务 |

强制规范是否导致无效，按民法典第 153 条和合同编通则解释第 16 条逐项核验。禁止用已失效“效力性/管理性”口诀代替。

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

打开已加载的 `框架.md`，按下列六步逐段对照正文。`基本面.md` 用于校验类型、主体、标的、程序、结构和红旗，不代替本节点出句。框架与本方法冲突时，以本方法为准出句。

| 步 | 动作 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题体现代建+配资；主体分列委托/借款与代建/出借或引资；鉴于锁定融资需求与代建能力，并写明两笔关系的独立性与关联 | 标题或鉴于修改句 |
| 交易条款 | 代建标的可核验；配资是直接出借还是协助/承诺；本金、利率、代建费分列；提款前提；回款顺序 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 交叉违约有宽限期；删除暴力清算；担保权利人一致；决议作附件；任意解除不影响已发生配资债权 | 可执行后果句 |
| 尾部 | 生效条件（双签、首笔到账）与未到账清理；附件含提款申请、还本付息计划、现金流预测、担保合同、决议 | 生效与附件修改句 |
| 语言 | 协助融资/承诺贷款；管理酬金/债务本息；融资顾问费；本息覆盖率须有动态评估定义 | 替换空词和混用词 |
| 常见问题 | 明代建实借贷、费用藏息、抽逃外观、暴力清算、未登记当优先受偿 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止；
- `必须改`：可谈但签署前要落句；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。唯一土地或项目公司被设定违约即平仓且用户拒绝升级：停止“可以签署”建议。

争议解决：或裁或诉、机构不明标待核。不动产所在地专属管辖只标红旗，不选定唯一法院充作法律意见。
