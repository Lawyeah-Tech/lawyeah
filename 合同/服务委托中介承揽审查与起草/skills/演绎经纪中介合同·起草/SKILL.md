# 演绎经纪中介合同·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》居间章及其解释、1997 年《营业性演出管理条例》、1994 年《广告法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只起草 **中介合同 / 演绎经纪中介合同** 的待签文本，按已谈妥条件出己方稿，输出可编辑草稿、未决项；出稿后必须用本类型硬闸自审，输出风险表和修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查演绎经纪中介合同（中介合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、待签文本签前审查、履约交底、争议文书、有效性保证、把代言本约或著作权许可/转让改完、把买断人身改成可履行结构。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **经纪≠经纪公司买断艺人**：核心给付是报告演艺机会、媒介撮合及包装推广，对价是佣金或分成。艺人仍是独立民事主体。出现“买断全部演艺权利”“艺人成为公司资产”“永久转让艺名/肖像/全部未来作品且无本人同意权”→红线改回经纪，或负触发。人身权不可买断。
2. **佣金/分成与对账**：写清税前或税后、净收益扣除项、结算周期、先收后分后的原始合同与凭证核对权。禁止“全部收入归公司、只发生活费且无对账”。未促成对应项目不得按已促成请求全额报酬。
3. **与代言/许可切开**：主文件是艺人与广告主就特定商品或品牌的代言本约 → 负触发 `广告代言服务类合同·审查`。主文件是特定作品的著作权许可或转让 → 负触发 `或` 或 `或`。经纪主协议可审代言撮合范围与本人书面同意，不得把代言或许可审查做成主路径。
4. **与劳动合同/个人劳务切开**：考勤 + 固定底薪 + 人身从属为主轴 → 负触发 `与劳动合同个人劳务切开：考勤+固定底薪+人身从属为主轴→负触发`。平等主体个人劳务且无演艺机会媒介 → 负触发 `平等主体个人劳务且无演艺机会媒介→负触发`。多用“服务”，不得把“管理/服从安排”写成已排除劳动关系。
5. **人身禁锢、永久授权、天价违约金**：限制婚姻或生育、十余年绝对人身绑定：删除并告知公序良俗风险。肖像或姓名永久归公司：改为有期限许可。违约金不得写成“不得调整”或必然全额。
6. **许可证与双重经纪**：涉及演出经纪须核《营业性演出许可证》与专职演出经纪人员资格。未核则字段停止，不写“可以展业”。在先未解除经纪须书面披露。工作室签约须写清与艺人个人的授权或连带。
7. **未成年人**：艺人为八周岁以上未成年人时，须法定代理人书面同意并签字，否则效力待定，字段停止。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签演绎经纪正文，尚未签署，尚未成争，核心给付是报告演艺机会或提供媒介与包装，对价是佣金或分成，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 艺人与广告主就特定商品或品牌订立代言本约 → `广告代言服务类合同·审查`；
- 主给付是特定作品著作权许可 → `或`；
- 主给付是特定作品著作权转让 → `或`；
- 主给付是委托创作特定作品 → `主给付是委托创作特定作品→`；
- 广告代理整案 → `广告代理合同·审查`；
- 考勤、底薪、人身从属的劳动合同 → `与劳动合同个人劳务切开：考勤+固定底薪+人身从属为主轴→负触发`；
- 平等主体个人劳务且无演艺媒介 → `平等主体个人劳务且无演艺机会媒介→负触发`；
- 保险、证券或期货经纪 → `保险_证券_期货经纪中介合同·审查`（P1；专业版未装则 `unavailable`）；
- 房屋买卖或租赁中介 → `房屋买卖_租赁中介合同·审查`；
- 职业、婚姻或技术转让中介 → `职业中介合同·审查` / `婚姻中介合同·审查` / `技术转让中介合同·审查`；
- 以处理事务或代签本约为整案主轴且无经纪分成结构 → `一般委托合同·审查`；
- 以自己名义自担贸易权利义务为整案主轴 → `行纪合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

买断人身、限制婚育、阴阳片酬、规避文旅审批：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（艺人/工作室侧或经纪机构侧择一）；相对方；全文及附件/授权书版本；核心给付是经纪服务还是买断；是否夹带代言本约或许可本约；独家或项目代理；分成比例、税前税后、扣除项、结算周期、对账权；许可证与经纪人员资格痕迹；艺人是否未成年及监护人是否签字；在先经纪是否解除；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的分成比例、期限、金额用 `【待填】`，不编造。

## 起草模式

本原子只承担本类型起草。待签评改转 `演绎经纪中介合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `演绎经纪中介合同·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。下文「起草必写 / 附件必附 / 禁止出现」即本类型硬闸的落稿口径。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 核心给付是报告演艺机会、媒介撮合及包装推广，对价是佣金或分成；艺人仍是独立民事主体。
- 佣金／分成写清税前或税后、净收益扣除项、结算周期、先收后分后的原始合同与凭证核对权。未促成对应项目不得按已促成请求全额报酬。
- 重大代言须本人书面同意。肖像或姓名许可须有期限。
- 涉及演出经纪：写《营业性演出许可证》与专职演出经纪人员资格。
- 在先未解除经纪须书面披露。工作室签约须写清与艺人个人的授权或连带。
- 艺人为八周岁以上未成年人：法定代理人书面同意并签字。

### 附件必附

- 演出经纪许可证与专职演出经纪人员资格痕迹。
- 艺人为未成年人时：法定代理人书面同意书。
- 有在先经纪时：解除证明或书面披露。

### 禁止出现

- 买断全部演艺权利、艺人成为公司资产、永久转让艺名／肖像／全部未来作品且无本人同意权。
- 全部收入归公司、只发生活费且无对账。
- 限制婚姻或生育、十余年绝对人身绑定。
- 肖像或姓名永久归公司。
- 违约金写成不得调整或必然全额。
- 阴阳片酬、规避文旅审批。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`基本面.md` 中“委任合同任意解除权”不得写成无偿任意解除。`框架.md` 中“永久授权”不得写成人身权已归公司。3:7 / 5:5、5–8 年只是实务量级，不是法源。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 留本任务起草并自审；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有经纪文本；本任务只起草，评改待签文本转配对 ·审查 原子。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。买断艺人、代言本约、许可/转让本约、劳动合同、金融经纪负触发。

### 2. 主体、许可证、双重经纪、未成年人

签约名、履行名、收款名、发票名分列。许可证与经纪人员资格未核：字段停止。未成年人无监护人签字：字段停止。

### 3. 经纪事务与授权范围

写清报告机会、媒介、包装；独家或项目代理；重大代言须本人书面同意。不得把买断人身写成已有经纪授权。

### 4. 佣金、先收后分与对账

禁止全部收入归公司且无对账。净收益扣除项必须列明。

### 5. 人身条款、永久授权与违约金

婚育禁锢删除。永久授权改为有期限许可。违约金可调整。

### 6. 格式条款与强制规范

无核验引文则法律结论字段停止。阴阳片酬停笔。

### 7. 违约、解除与争议

观察期内未提供有效机会可约定解除。不把第 933 条写成无偿任意解除。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把买断人身、婚育禁锢、阴阳片酬或规避审批改成可履行结构。
- `字段停止`：法域、动态规则、许可证、经纪人员资格、未成年人追认、地方审批未核验。
- `目标停止`：主目标已变为评改待签文本、履约交底、争议文书，或已锁他类（含代言本约、许可本约）。
