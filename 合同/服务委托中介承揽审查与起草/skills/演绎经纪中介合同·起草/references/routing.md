# 边界与路由

本技能只审查 **中介合同 / 演绎经纪中介合同** 的待签文本。中文展示名是「审查演绎经纪中介合同（中介合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 艺人与广告主就特定商品或品牌订立代言本约，有广告主、有具体商品或品牌 | `广告代言服务类合同·审查`。不得删掉代言本约条款后继续当经纪审 |
| 主给付是特定作品的著作权许可使用 | `或`。不得把许可审查做成经纪主路径 |
| 主给付是特定作品的著作权转让 | `或` |
| 主给付是委托创作特定作品 | `主给付是委托创作特定作品→` |
| 广告代理整案 | `广告代理合同·审查` |
| 考勤、底薪、人身从属的劳动合同 | `与劳动合同个人劳务切开：考勤+固定底薪+人身从属为主轴→负触发` |
| 平等主体个人劳务，无演艺机会媒介 | `平等主体个人劳务且无演艺机会媒介→负触发` |
| 保险、证券或期货经纪 | `保险_证券_期货经纪中介合同·审查`。P1：专业版未装则 `unavailable`，提示，不得用本技能硬套 |
| 房屋买卖或租赁中介 | `房屋买卖_租赁中介合同·审查` |
| 求职、招聘、劳务介绍 | `职业中介合同·审查`。P1；未装则 `unavailable` |
| 婚介、相亲 | `婚姻中介合同·审查`。P1；未装则 `unavailable` |
| 技术转让、专利许可撮合 | `技术转让中介合同·审查`。P1；未装则 `unavailable` |
| 建设工程招投标中介 | `建设工程招投标中介合同·审查`。P1；未装则 `unavailable` |
| 以处理事务或代签本约为整案主轴，且无经纪分成结构 | `一般委托合同·审查` |
| 以自己名义自担贸易权利义务为整案主轴 | `行纪合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 留本任务起草并自审 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争，或用户要解约索赔策略 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

经纪正文里夹带一小段代言项目清单或作品归属：专条交接对应原子；佣金、对账、独家范围、本人书面同意可继续审。用户坚持本技能把代言本约、许可本约或劳动合同整案改完：`目标停止`。
