# 审查方法（锁定 中介合同 / 演绎经纪中介合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制广告代言审查、著作权许可/转让审查、房屋中介产调/房款私户或劳动试用期节点。

定性校验：标题、核心给付与本类型一致才继续；买断艺人、代言本约、许可/转让本约、劳动合同、金融经纪或其他中介明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受或唯一必得金额。

`search_law` 返回已失效《合同法》居间章及其解释、1997 年《营业性演出管理条例》、1994 年《广告法》、已失效《经纪人管理办法》时记为噪声，不得写入 `L#`。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。代言、许可或“买断艺人”范本只证明是另一结构，不得当作本类型范本。

知识库纠正（不回写双文件）：

- `基本面.md` “演艺经纪属于综合性无名合同，融合中介、委托、行纪及著作权许可/转让”：混合片段可以留在本类型，但**买断艺人不是经纪**。人身权、艺名、肖像不可出售给公司当资产。夹带的具体作品许可或代言本约另走对应原子。
- `基本面.md` “艺人享有委任合同任意解除权”：第 966 条只是参照适用委托规定，不得写成无偿任意解除且无需清算。有偿委托解除方应赔偿直接损失和合同履行后可以获得的利益（第 933 条）。
- `基本面.md` “经纪公司应有至少 3 名专职演出经纪人员并在行业协会备案”：法定门槛是《营业性演出许可证》及 3 名以上专职演出经纪人员（2016 决定并入后的条例第六条口径；2022 实施细则第五条、第八条）。行业协会备案不等于已取得许可证。
- `框架.md` “合同通常期限 5–8 年”“分成 3:7 或 5:5”：实务量级，不是法源。数字用 `【待填】`。
- `框架.md` “永久授权”：人身权不可买断；肖像许可期限不明或永久的，适用第 1022 条解除规则，不得写成人身权已归公司。
- `框架.md` “多使用服务术语，弱化管理”：是劳动切开提示，不是已经排除劳动关系的结论。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 报告演艺、代言、影视、直播等订约机会，或提供媒介与包装，对价是佣金或分成；艺人仍是独立主体 | 本类型 | 正触发 |
| 公司买断艺人全部演艺权利、艺人成为公司资产、永久转让人身权且无本人同意权 | 买断结构 | 红线改回经纪；用户坚持买断主轴则负触发，不按买断放行 |
| 艺人与广告主就特定商品或品牌订立代言本约，有广告主、有具体商品 | 广告代言 | 负触发 `广告代言服务类合同·审查` |
| 主给付是特定作品的著作权许可使用 | 著作权许可 | 负触发 `或` |
| 主给付是特定作品的著作权转让 | 著作权转让 | 负触发 `或` |
| 主给付是委托创作特定作品 | 委托创作 | 负触发 `主给付是委托创作特定作品→` |
| 考勤、固定底薪、人身从属 | 劳动合同 | 负触发 `与劳动合同个人劳务切开：考勤+固定底薪+人身从属为主轴→负触发` |
| 平等主体个人劳务，无演艺机会媒介 | 个人劳务 | 负触发 `平等主体个人劳务且无演艺机会媒介→负触发` |
| 保险、证券或期货经纪 | 金融经纪中介 | 负触发 `保险_证券_期货经纪中介合同·审查` |
| 房屋买卖或租赁居间 | 房屋中介 | 负触发 `房屋买卖_租赁中介合同·审查` |

支持切开的规范（法律结论须运行时复核）：

- 第 961 条：中介是报告机会或提供媒介，委托人支付报酬。
- 第 467 条：无名合同适用通则并参照最相类似合同。演艺经纪常是混合无名合同，不因此变成买断人身。
- 第 993、1019、1022 条：姓名、肖像可许可使用，不可买断；期限不明或有正当理由可解除。
- 第 919 条：委托是处理委托人事务——整案若只剩代签而无经纪分成，转 `一般委托合同·审查`。
- 第 951 条：行纪是以自己名义从事贸易——整案若自担贸易权利义务且无经纪分成，转 `行纪合同·审查`。
- 广告法（2021）第 30、33 条：代言/使用名义形象另有书面合同与书面同意——那是代言本约，不是本任务主路径。
- 著作权法（2020）第 26 条：许可使用合同有权利种类、专有或非专有、地域期间——那是许可本约。

### 1.2 加载协议（硬闸）

本技能已锁定 **中介合同 / 演绎经纪中介合同**。只打开 `references/基本面.md` 与 `references/框架.md`。禁止读其他子目录，禁止为对照再开第二类。禁止打开代言或许可技能的 method。

### 1.3 经纪≠经纪公司买断艺人（硬闸）

《营业性演出管理条例》（2020 修订）第 12 条：演出经纪机构可以从事营业性演出的居间、代理、行纪活动。2022 实施细则第 5 条：演出经纪机构可从事演员签约、推广、代理。混合居间/代理片段可以留在本类型。

买断信号与动作：

| 文本写法 | 本任务动作 | 修改句方向 |
| --- | --- | --- |
| 乙方仅报告机会、媒介撮合、包装推广；对外本约由艺人本人或按单次授权签署；收益按约定分成 | 正触发，留下本类型 | 首部写明“演艺经纪（中介/代理混合），不构成买断艺人” |
| 甲方买断乙方全部演艺权利；乙方成为甲方资产；全部未来作品、艺名、肖像永久归甲方 | 红线。人身权不可买断 | 「本合同不构成对乙方人身、艺名、肖像或未来全部作品的买断。甲方仅在约定期限和范围内提供经纪服务并收取佣金。」 |
| 任何代言、拍摄、直播无需乙方本人同意，甲方可全权处分 | 必须改：重大事项书面同意 | 见节点 3.2 |
| 用户坚持保留买断主轴并要求改到能签 | 负触发或整体停止 | 不按买断放行 |

最强反方：相对方主张经纪本就包含全权处分。现有依据支持经纪机构从事居间、代理、行纪，不支持把艺人本人买断为公司财产。

3. 用户坚持“改到能签且仍做这些事”：整体停止。

## 节点 2　主体、许可证、双重经纪、未成年人

### 2.1 主体表

建表：签约名、履行名、收款名、发票名、授权签字人。名称不一致不自动合并。艺人通过工作室签约：须写清工作室对艺人个人的授权，以及艺人是否对工作室债务或履约承担连带；口头“工作室就是我”不得写成已授权。

### 2.2 许可证与经纪人员（硬闸）

支持依据：2016 年国务院决定并入后的条例第六条口径（演出经纪机构须有 3 名以上专职演出经纪人员及相应资金，经省级文化主管部门批准颁发营业性演出许可证）；2022 实施细则第五条、第八条（申请须提交演出经纪人员资格证）；第 12 条（机构可居间、代理、行纪，个体经纪人只能居间、代理）。检索若优先命中 1997 年条例第六条（主管部门分工），记噪声。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 无许可证复印件或官方查询页 | 字段停止；修改句要求作为附件 | 可以展业 |
| 承办人只有名片，无演出经纪人员资格证 | 字段停止 | 个人签字即可约束机构 |
| 只有营业执照或“已在行业协会备案” | 执照或协会备案不等于许可证 | 已完成许可 |

修改句：

「本合同签署前，甲方应向乙方出示并作为附件一：《营业性演出许可证》或文旅主管部门查询页；附件二：承办本协议的专职演出经纪人员资格证。未核验前，不得主张已具备演出经纪展业与签署条件。」

未取得许可证主要是监管后果。部门规章或行政法规的行政管理义务不当然导致民事合同无效（解释第 16 条）。本任务只停止“可以展业”表述，不宣告合同当然无效。

### 2.3 双重经纪

艺人须书面陈述在先经纪是否已解除或到期。存在在先独家未解除：标红旗，修改句要求出具解除协议或对方豁免；不得写成“可以同时签两家”。新经纪明知仍签：告知可能对在先经纪公司承担侵权或违约牵连，本任务不认定已经构成侵权。

### 2.4 未成年人（硬闸）

支持依据：第 19、23、145 条；总则编解释第 5 条。广告中使用限制民事行为能力人名义或形象，须监护人书面同意（广告法 2021 第 33 条）——只作签署提醒，不展开代言审查。

| 已有事实 | 动作 |
| --- | --- |
| 艺人未满八周岁 | 由法定代理人代理实施；无监护人签字：字段停止，不写成已生效 |
| 艺人八周岁以上不满十八周岁，仅本人签字 | 效力待定。修改句要求法定代理人书面同意并签字；善意相对人可催告三十日内追认 |
| 监护人已签字但未出示监护关系材料 | 字段停止；列出出生证明或户口材料待核 |

经纪期限、分成、独家约束与未成年人年龄、智力明显不相适应：现有依据不支持写成“与年龄相适应故本人可独立签订”。

## 节点 3　经纪事务与授权范围

### 3.1 服务包须可核验

审查清单，缺一项则该字段不得写成已闭环：

1. 服务内容分列：报告订约机会 / 媒介撮合 / 形象包装 / 培训 / 公关 / 社媒代运营。禁止只写“全案打造”“全力捧红”。
2. 独家或项目代理。独家须加黑提示限制私下接活的后果；全球独家须写地域和业务范围，不得写成剥夺艺人日常生活与非演艺劳动。
3. 合同期限起止日。禁止无期限绑定。框架中的 5–8 年不是法定期限；过长且不得解除：按节点 5 处理。
4. 观察期：可约定甲方在 `【待填】` 个月内未提供任何可核验的演艺机会或书面洽谈记录，乙方有权书面解除且无需支付包装违约金。

### 3.2 重大事项本人同意

可能对艺人形象产生重大影响的交易（争议品牌代言、尺度敏感剧本、政治或宗教相关合作）必须经艺人本人书面同意。修改句：

「甲方为乙方撮合代言、影视、直播或其他商业合作的，项目合同由乙方本人签署，或由乙方就该项目出具一次性书面授权。对乙方形象有重大影响的合作，未经乙方事先书面同意，甲方不得以乙方名义承诺或签署。」

本条是经纪范围内的同意权，不是代言本约审查。

### 3.3 肖像、姓名、作品（非买断）

经纪推广所需的艺名、肖像、简介使用：写成有期限、有范围的许可，服务于本合同经纪目的。合同期内新作品的著作财产权归属若只写“一律归公司”：必须改成“项目另议或按创作事实确定，人身权仍归作者”；整案若已是指定作品转让或许可，负触发对应原子。

口头“宣传用一下”不得写成已完成第 1019 条同意。

## 节点 4　佣金、先收后分与对账（硬闸）

支持依据：第 962、963、964、965 条。

| 文本写法 | 动作 |
| --- | --- |
| 全部演艺收入进入公司账户，艺人只领固定生活费，无分成公式、无对账 | 红线。改回分成 + 对账 |
| 先收后分，但艺人不得查阅原始合同、发票或收款凭证 | 必须改。隐瞒真实金额可落入第 962 条 |
| “净收益”未列扣除项 | 必须改：税金、第三方渠道费、约定包装成本分列；未列明的不得扣除 |
| 无论是否促成项目，签约即收全额经纪费或永久抽成 | 必须改。未促成不得请求报酬；必要费用须列明上限 |
| 佣金与艺人应得混在同一账户且可被公司单方抵扣 | 必须改：分户或分科目，抵扣须书面确认 |
| 经纪人与第三方私下返点、阴阳合同 | 红线删除；用户坚持则整体停止 |

修改句：

「乙方因本合同项下演艺、代言、影视、直播等项目取得的收入，可由相对方先支付至甲方指定对公账户。甲方应在收到款项后【待填】日内向乙方交付：项目合同副本或经脱敏的关键商务页、收款凭证、税款与约定成本明细。双方按税【前/后】【待填】分成。未在附件列明的费用不得从乙方应得中扣除。乙方及其授权会计师有权在合理时间核对账册。甲方故意隐瞒项目金额或提供虚假结算的，不得就该项目请求佣金，并应赔偿乙方因此少得的分成。」

禁止编造分成比例。框架中的 3:7、5:5 只是实务量级。

跳单/私下接活：适用第 965 条时，须写“接受经纪服务后利用该机会或媒介绕开签约”。自行合法获知或相对方并非经纪介绍对象：现有依据不支持当然付酬。不得写成私下接活一律无效，也不得写成经纪必然胜诉。

## 节点 5　人身条款、永久授权与违约金（硬闸）

支持依据：第 153 条；解释第 17 条（背离家庭伦理或有损人格尊严可认定违背公序良俗）；第 585 条；解释第 64、65 条；第 993、1021、1022 条。

| 文本写法 | 动作 |
| --- | --- |
| 合同期内不得结婚、生育，违者高额违约金或解除且没收全部收入 | 红线删除。告知可能因违背公序良俗部分无效。不改成“暂缓生育但可履行” |
| 期限十年以上且不得单方解除、不得接任何工作、行踪须报备 | 必须改：缩短期限或加观察期/僵局解除；删除绝对人身禁锢 |
| 艺名、肖像、声音、全部未来作品永久归公司 | 必须改：许可期限与经纪期限一致；到期停止使用；人身权仍归艺人 |
| 违约金为剩余年限预计收入总额的数倍，且“不得调整” | 必须改。当事人仅以约定不得调整主张不予调整的，现有依据不支持。不在本任务做第 585 条精算 |

修改句（永久授权）：

「乙方许可甲方在本合同有效期内，为履行经纪推广义务，在【待填】地域、【待填】媒介使用乙方艺名、肖像及简介。许可期限届满或本合同解除后，甲方应停止新增使用。本合同不构成姓名权、肖像权的转让或买断。对本条理解发生争议的，作出有利于肖像权人的解释。」

修改句（解约成本）：

「任何一方依法或依约解除本合同的，违约方应赔偿对方因此发生的、可书面证明的直接投入及合同履行后可以获得的利益。违约金计算为：已书面确认的包装、培训、宣发费用 ×【待填】倍，加上解除前十二个月平均月分成 × 剩余月数 ×【待填】。任何“不得调整违约金”的约定不排除依法请求适当减少。」

## 节点 6　格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 格式条款

经纪公司为重复使用而预先拟定、订立时未与对方协商的条款，按第 496 条审查。分成、独家、解除、违约金、管辖等异常条款须有足以引起注意的标识，并按要求说明。小字印刷、夹在附件、仅有网络勾选：不得写成已尽提示义务。

### 6.2 强制规范

违反法律、行政法规强制性规定不一律无效（第 153 条；解释第 16 条）。禁止用已失效“效力性/管理性”口诀。未取得许可证主要是监管后果，不得单独写成民事合同当然无效。买断人身、婚育禁锢、阴阳片酬：不改写成有效履行。

## 节点 7　违约、解除与争议

1. 公司逾期不提供任何可核验机会、隐瞒账目、未经同意签署重大代言：可约定减酬、免酬、解除并赔偿直接损失。只有“依法承担违约责任”视为必须改。
2. 艺人无故拒绝合理通告或私下接活：可约定催告后减酬或适用第 965 条范围内的报酬，不得直接写成演艺本约无效。
3. 构成违约不等于当然解除。法定解除路径只点名催告或目的不能实现，不在本任务作出已解除结论。
4. 第 966 条参照委托：可约定通知解除，但须处理已发生必要费用、已促成项目分成和第 965 条。不得写成“随时解除且无需付费”。
5. 劣迹条款须概括 + 列举（刑事犯罪、行政处罚的具体类型），并限定因果关系和可证明损失；不得写成任何负面新闻即没收全部历史分成。
6. 争议解决：出现仲裁条款，不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核。
7. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。
