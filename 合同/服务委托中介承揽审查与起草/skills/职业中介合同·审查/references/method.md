# 审查方法（锁定 中介合同 / 职业中介合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止把 `房屋买卖_租赁中介合同·审查`、劳动合同审查或劳务派遣审查的 method 拼贴后换标题当作本文件。禁止套用房屋居间独家委托、买卖验收或定金比例。

本文件的主线是 **行政许可下的岗位／人才撮合**：中介促成劳动者与用人单位建立劳动关系，自己不成为用人单位。三道硬闸必须走完：人服许可、禁止扣证／押金、与劳务派遣和平台用工切开。缺一闸不得宣称审查完成。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、保证入职，或唯一必得佣金。

`search_law` 返回已失效《合同法》及其解释、1996 年《人才市场管理暂行规定》、1995 年《职业介绍规定》、1992 年《境外就业服务机构管理规定》时记为噪声，不得写入 `L#`。把无证写成“合同当然全部无效”，或把押金写成“可以留作履约保证”的，同样记噪声。

示范文本只参考结构。检索到的猎头范本常含预付佣金留置、保证入职语气或未写人服许可，不得照抄当本约建议句。

知识库纠正（不回写双文件）：

- `基本面.md` “未经许可……合同面临效力瑕疵”：未经许可擅自从事职业中介，行政违法，依照条例第四十二条、管理规定第三十九条处罚。民事上是否导致行为无效，须按民法典第一百五十三条和合同编通则解释第十六条分层，**不得写成整份合同当然无效，也不得写成已经有效可履行**。
- `基本面.md` “违反不得扣证／收押金的条款无效”：就业促进法第四十一条、第六十六条首先是禁止加行政处罚（退还 + 每人五百元以上二千元以下罚款）。该等条款不得改成可履行；整份撮合协议是否因此全部无效，依据不足则字段停止，只删除该条。
- `基本面.md` “营利性中介虽允许向劳动者收费”：管理规定第二十七条只允许明示服务项目内的费用，禁止明示项目以外收费，禁止押金和变相押金，禁止诱导贷款、入股、集资。公共就业服务不得向劳动者收费。不得写成“营利性就可以收服装费、体检费”。
- `基本面.md` 外资“特定股权比例”：中外合资中外合作职业介绍旧规章 MCP 标为已被修改。运行时核验，不把旧股权比例写成现行默认。
- `框架.md` 标题建议“人力资源服务外包协议（中介类）”：外包／派遣用语会把类型锁错。本类型标题用“职业中介服务协议”或“猎头／高级人才寻访服务协议”，禁止用外包、派遣、挂靠人员。
- `框架.md` 争议解决“适用劳动法”：本约一般是民事中介合同。劳动法约束促成之后用人单位与劳动者之间的本约，以及中介若被认定为用人单位时的后果。不得把劳动法写成中介合同自身的准据法默认。
- 现行许可证名称是《人力资源服务许可证》，不是旧“职业中介许可证”。文本仍写旧名称：必须改正。

## 节点 1　类型识别与单目录加载

### 1.1 定性（本类型灵魂闸）

用标题、核心给付和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须同时满足才正触发：

1. **给付是撮合**：为用人单位寻找劳动者，或为劳动者寻找用人单位，或猎头寻访、招聘会、经营性网络招聘撮合。
2. **目标是促成建立劳动关系**：报酬通常绑在推荐、面试、入职或过保证期，而不是完成生产任务或派单收入。
3. **中介不是用人单位**：文本不应让中介发工资、缴社保、直接实施劳动管理。

缺第 1 项或第 3 项：不是本类型。禁止用邻类知识把缺项补成“完整职业中介”后宣称审完。

## 节点 2　职业介绍许可与主体（硬闸）

### 2.1 主体表

建表：中介机构、用人单位、劳动者（若劳动者是签约方）、签约名、履行名、付款名、授权签字人。名称不一致不自动合并。

支持依据（运行时核验）：就业促进法第四十条（2015 修正：先办理工商登记，再向劳动行政部门申请行政许可）；人力资源市场暂行条例第十八条；人力资源服务机构管理规定第五条、第七条、第二十六条、第三十九条。

口头“我们老板同意了”不得写成已授权。

### 2.2 用人单位与劳动者适格

- 用人单位须依法设立。为无合法证照的用人单位提供职业中介：禁止，删除或停止。
- 劳动者须年满 16 周岁并有合法身份证件。介绍未满 16 周岁未成年人：依照禁止使用童工规定，整体停止可履行结构。
- 不得介绍劳动者从事法律、法规禁止的职业。
- 中介明知用人单位无用工资质或从事非法活动仍提供服务：标连带赔偿风险，不写成已经免责。

## 节点 3　禁止扣证件／押金与收费对象（硬闸）

支持依据（当次 `search_law` 写入 `L#`）：就业促进法第四十一条第四项、第六十六条；人力资源服务机构管理规定第二十七条、第四十五条；就业服务与就业管理规定 2022 修订第七十四条转致第五十八条第八项；劳动合同法第九条（用人单位侧平行禁止，防止文本把中介写成用人单位后继续扣证）。

### 3.1 扣证、押金、变相押金：删除

| 文本写法 | 动作 | 不得写成 |
| --- | --- | --- |
| 扣押身份证、学历证、技能证、护照，“代为保管至过试用期” | **红线删除**。不得改成保管协议 | 代为保管更安全；少扣几天即可 |
| 向劳动者收押金、保证金、工装押金、培训押金 | **红线删除**。退还句可写，收取句不可留 | 少收一点合法；可以转为预付服务费而不写明示项目 |
| 以担保、保证人、连坐、扣工资预留名义变相押金 | 视同押金，删除 | 这不是押金是担保 |
| 诱导或强迫个人贷款、入股、集资后才能介绍工作 | 删除。管理规定第二十七条第一款 | 培训贷可以打包进中介费 |
| 公共就业服务向劳动者收费 | 删除 | 公共机构按市场价收费 |

劳动者侧：修改句直接删除并要求返还已交押金／证件的路径写成签约前完成，不写成签约后分期退。用人单位侧：修改句禁止中介向其推荐的劳动者收取上述款项，并约定查实后的解约或扣减佣金。中介侧：删除后改成用人单位付费或明示服务项目内收费。

### 3.2 收费对象、计费、节点、未促成

支持依据：民法典第九百六十三条、第九百六十四条；管理规定第二十六条、第二十七条；就业服务与就业管理规定 2022 修订第三十八条、第六十九条（公共机构）。

审查清单，缺一项则收费字段不得写成已闭环：

1. **收费对象**：用人单位付费，还是向劳动者收取明示服务项目费用。二者同时出现必须分列，禁止一套数字两头收。
2. **计费方式**：按入职人数、年薪比例或固定服务费。缺数字用 `【待填】`。
3. **支付节点**：推荐面试、正式入职、过保证期分列。不得把未促成入职的节点写成“报酬已赚取”。
4. **未促成**：第九百六十四条——未促成合同成立，不得请求报酬；可约定必要费用。猎头分阶段服务费须写清哪一笔是报酬、哪一笔是必要费用。
5. **明示与备案**：服务项目和收费标准应在场所明示；文本应指向可核验的价目。地方是否还要求向人社部门备案，运行时核验，不编文号。

| 文本写法 | 动作 | 不得写成 |
| --- | --- | --- |
| 用人单位在入职后按年薪【待填】% 支付人力资源服务费 | 可接受；补发票、保证期、未入职不付报酬 | 已经是行业强制比例 |
| “无论是否入职，预付佣金不予退还” | 必须改。未促成不得请求报酬；预付款超过必要费用的部分应退 | 预付即报酬 |
| 向劳动者收“报名费”“资料费”却无明示项目 | 必须改或删除 | 资料费当然合法 |
| 保证期（如入职后 3 个月）内离职则免费重荐或退部分佣金 | 可接受；写清离职原因分层（候选人原因／用人单位原因／双方协商） | 保证期=保证入职 |

第九百六十三条第三句“媒介服务促成的由当事人平均负担报酬”是民事缺省。职业中介行政规范更强调不得向劳动者收取押金和明示项目外费用。修改句优先写成用人单位负担报酬；若向劳动者收取明示项目费用，必须列项目、标准和未促成退费，且不得与 963 平均负担混写成“法定各付一半”。

## 节点 4　标的、核实义务、禁止对象

支持依据：管理规定第十五条、第十六条、第二十一条；条例第二十四条、第二十六条；民法典第九百六十二条。

1. 服务内容具体到职位发布、简历初筛、面试安排、背景调查、猎头寻访中的哪几项。只有“等人力资源服务”则标缺口。
2. 中介接受用人单位委托招聘，须审查招聘简章、营业执照或批准文件、经办人身份证件、委托证明，并建档。文本应把审查写成义务，不得写成“甲方资料自行负责、中介免核实”。
3. 招聘信息真实、合法，不得含民族、种族、性别、宗教信仰等歧视性内容，不得违法设置户籍、地域、身份限制。
4. 不得以“信息发布”名义规避职业中介许可（管理规定第二十一条）。
5. 背景调查不得写成绝对保证候选人无竞业限制、无未了劳动关系。可写合理核实 + 虚假陈述的责任分配。
6. 禁止标的：童工、无合法身份证件者、法律禁止从事的职业、强迫劳动或非法出境安排。

## 节点 5　中介不是用人单位；不得保证入职

### 5.1 性质显化

框架要求写明中介不属于劳动法意义上的用人单位，不与劳动者建立劳动关系。修改句必须同时满足：

- 正说：中介提供推荐和媒介，录用决定权在用人单位；劳动关系由用人单位与劳动者依法订立劳动合同。
- 反说：中介不负责办理入职手续、不代发工资、不代缴社会保险、不实施考勤奖惩。

出现“中介方为劳动者办理入职”“人员由中介管理、接受甲方安排”：先判断是否已滑向 `与劳动合同个人劳务切开：考勤+固定底薪+人身从属为主轴→负触发` 或 `用人单位。按人头派驻接受用工单位考勤奖惩中介发薪或自己与劳动者签劳动合同→`。仍属撮合的，必须改句；已经是派驻或用工，负触发，不在本任务改残。

### 5.2 禁止结果保证

录用决定权在用人单位。不得约定“保证入职”“包找到工作”“未入职视为中介违约并按年薪全额赔偿”。可约定：服务流程时限、候选人数量与级别、信息核实标准、保证期内免费重荐或退部分佣金。

## 节点 7　防跳单、虚假信息、争议改写法

### 7.1 跳单

支持依据：民法典第九百六十五条。委托人接受中介服务后，利用其提供的交易机会或媒介服务绕开中介直接订立合同的，应当支付报酬。

修改句可以约定：在服务期内及服务结束后【待填】个月内，用人单位不得绕开中介录用其推荐且中介可举证的候选人，否则支付约定服务费。违约金可谈，不得写成“按总价必得、不得调整”，不得搭配押金或扣证。

防跳单不是房屋中介的独家委托或带看确认书体系。禁止从 `房屋买卖_租赁中介合同·审查` 抄独家、跳单举证责任或网签条款。

### 7.2 虚假信息

第九百六十二条：故意隐瞒重要事实或提供虚假情况，损害委托人利益的，不得请求支付报酬并应赔偿。用人单位提供虚假岗位、中介提供虚假就业信息，应分列责任，不得互相写成“概不负责”。

### 7.3 争议解决：改写法，不审策略

或裁或诉、机构不明：标待核，改成单一仲裁机构或单一法院连结点。出现仲裁条款：不得改写成“应向某法院起诉”并假装已选定诉讼。用户追问劳动仲裁请求、退费胜率：目标停止。本技能不写起诉或仲裁策略。

通知送达：可约定邮寄至载明地址第 X 日视为送达。不得把微信已读写成已经送达的唯一充分条件。

示范删除句（押金）：

`定位收费条款｜原文：劳动者须交纳保证金人民币 3000 元，身份证原件由中介保管至试用期满｜建议改为：任何一方不得扣押劳动者的居民身份证和其他证件，不得向劳动者收取押金或者以担保等名义变相收取押金。已收取的应当于签署前返还。人力资源服务费由用人单位按本条约定向中介支付。｜理由：L# 就业促进法第四十一条、第六十六条，管理规定第二十七条｜可退让点：无｜不接受时的红线：拒删扣证或押金仍要放行`

示范许可句：

`定位主体／附件｜原文：乙方从事人力资源服务｜建议改为：乙方是依法登记的经营性人力资源服务机构，持有住所地人力资源社会保障行政部门颁发的《人力资源服务许可证》（编号【待填】，有效期至【待填】）。许可证副本作为附件。乙方仅在许可有效期内提供职业中介／猎头服务；许可被吊销、撤销或过期的，甲方有权解除本合同。｜理由：L# 就业促进法第四十条，条例第十八条，管理规定第五条｜可退让点：有效期届满前已申请延续的，可约定中止至获准之日｜不接受时的红线：无证仍要可签署意见`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（无证、扣证／押金、派遣或平台结构、童工／禁止职业、强迫劳动、保证入职、假许可）；
- `必须改`：可谈但签署前要落句（收费对象未显化、未促成仍不退、中介被写成办理入职、许可未附、简历无授权）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。劳动者生存级高额预付费且用户拒绝升级：停止“可以签署”建议。
