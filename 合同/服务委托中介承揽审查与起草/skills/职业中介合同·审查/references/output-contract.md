# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、保证入职、对方接受或必然可执行；编造未给出的佣金、人数、许可证号；把已失效《合同法》及其解释写入结论；把无证写成已经可履行；把扣证／押金改成可履行担保。

## 1. 触发、单方立场与成果状态

立场（劳动者／用人单位／中介机构择一）、授权、签署状态、主要目标。负触发写完整 Skill ID 路由，不启动实体审查。P1 未装写 `unavailable`。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、失效人才市场或职业介绍旧规章时记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级中介合同、子级职业中介合同、定性理由、与劳务派遣／平台用工／劳动合同／房屋中介／婚姻中介的切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读其他类型。强迫劳动、童工、非法出境写停笔告知，不填可履行结构。

## 4. 主体、许可、授权与文本版本

主体表：中介、用人单位、劳动者（若签约）、签约名、付款名、授权签字人。许可表：《人力资源服务许可证》编号与有效期、是否另有电信业务许可或境外专项许可、是否误用《劳务派遣经营许可证》。版本表：正文、岗位说明书、价目、许可证副本、聊天确认；冲突并列，不选对用户有利的一版。

## 5. 给付闭环

服务内容、核实义务、收费对象与节点、未促成费用、保证期补人／退费、中介不是用人单位。缺口标 `G#`，不补商业数字。批准、许可写成生效条件或期限，不写成已经完成。

## 6. 强制规范与格式条款

扣证／押金／变相押金是否出现；向个人收取的是否限于明示项目；公共机构是否向劳动者收费。是否构成格式条款；提示说明痕迹；异常条款。强制规范只区分行政管理后果与是否导致民事行为无效。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔／转出口径。禁止输出无修改句的色块表。许可、扣证／押金、派遣或平台切开三类至少各有一行可回链，除非该事实确定不存在并写明依据。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`，不编造。禁止只给原则、不给句子。许可句、扣证／押金删除句不得用“建议注意合规”代替。

## 9. 谈判与签署提醒

谈判顺序：先红线（无证、扣证押金、派遣／平台结构），再必须改，最后可优化。签署提醒：许可证副本、岗位说明书、价目、授权书、日期真实、分支机构授权。不指导倒签或补假许可。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书、劳动仲裁策略或效力保证。
