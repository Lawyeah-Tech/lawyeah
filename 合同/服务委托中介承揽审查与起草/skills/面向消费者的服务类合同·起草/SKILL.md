# 面向消费者的服务类合同·起草

## 任务目标

在单一立场下，只起草 **服务合同 / 面向消费者的服务类合同** 的待签文本，按已谈妥条件出己方稿，输出可编辑草稿、未决项；出稿后必须用本类型硬闸自审，输出风险表和修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文名必须是「审查面向消费者的服务类合同（服务合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、待签文本签前审查、履约交底、争议文书、有效性保证、咨询成果安排、广告投放或内容审查。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。每个风险回链文本位置。

1. **消保法身份**：为生活消费需要接受服务的自然人。单位采购、经营性培训、加盟投资、平等商事服务 → 负触发或回引擎。预付款书面合同、不得降质加价、未按约应履行或退预付款：以实施条例第 22 条、处罚办法第 10 条及运行时核验的 2013 年消保法预收款条为准。1993 年第 53 条玩忽职守旧义不得写入结论。
2. **预付卡切开**：当场或预约一次性服务按当次审；预付卡、次卡、会员卡、名为“办卡赠送”实为预收的，按预付式消费解释审。单用途卡备案/存管未核则字段停止。不得向消费者承诺保本付息。
3. **格式条款**：对照民法典第 496–498 条与预付式消费解释第 9 条。排除退款、不合理限制转让、遗失不补、单方变更实质内容、免除瑕疵或人身责任、争议解决不合理增加维权成本：必须改或红线。
4. **七日/冷静期按核验**：预付式消费解释**第十四条**——消费者自付款之日起七日内请求返还预付款本金，应予支持，但订立时已从该经营者或其他经营者处获得过相同商品或服务的除外；更有利约定优先。禁止把消保法第 25 条远程商品七日写成服务默认冷静期。禁止把解释**第七条**清算写成七日条款。无核验引文则七日法律结论字段停止。
5. **咨询/广告切开**：只出调研报告、管理建议等意见 → `咨询服务合同·审查`。广告创意、成片、发布、代言、代理或互联网投放为主轴 → `广告合同（广义）·审查` / `广告设计合同·审查` / `广告制作合同·审查` / `广告发布合同·审查` / `广告代言服务类合同·审查` / `广告代理合同·审查` / `互联网广告类合同·审查`。不得删掉投放或咨询 SOW 后硬套。

## 工作边界

正触发：已有可读待签消费服务正文或预付卡章程，尚未签署，尚未成争；相对方是为生活消费需要的自然人；核心给付是商家提供一次性或预付式消费服务（健身、美容美发、非学历培训、餐饮住宿、出行、养老、旅游等）。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 调研报告、行业分析、战略或管理建议，不到店兑付消费服务 → `咨询服务合同·审查`；
- 广告设计稿 → `广告设计合同·审查`；广告成片制作 → `广告制作合同·审查`；媒介发布/版面投放 → `广告发布合同·审查`；代言 → `广告代言服务类合同·审查`；广告代理排期 → `广告代理合同·审查`；互联网广告投放 → `互联网广告类合同·审查`；广告主文件无法再分 → `广告合同（广义）·审查`；
- 住宅小区物业费、公共部位、前期物业 → `住宅小区物业费公共部位前期物业→`；
- 以委托人名义处理事务 → `一般委托合同·审查`；自己名义贸易 → `行纪合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问预约、扣次、发票留痕 → 本套导航的履约步骤；
- 已关店、拒退、催告、索赔、诉讼或仲裁 → `或对应专项领域。`；消费者个人已成争退费只分流 `或` 或 `或`，不回改 C 端。

保本付息、无证办学或医美继续收预付款、资金盘：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；代表消费者还是经营者；相对方是否生活消费自然人；全文及章程/价目/课表/赠送说明版本；一次性还是预付；收款名与履约门店是否同一；是否未成年人；口头促销与书面是否冲突；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的预付额、次数、有效期用 `【待填】`，不编造。

## 起草模式

本原子只承担本类型起草。待签评改转 `面向消费者的服务类合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `面向消费者的服务类合同·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 相对方是为生活消费需要的自然人。预付款须书面合同：项目、次数或期限、有效期起算、预约规则、收款名与履约门店；不得降质加价。未按约应履行或退预付款。
- 预付卡、次卡、会员卡、名为“办卡赠送”实为预收的，按预付式消费解释写清书面要素；赠送是否计入退款基数须落句。
- 格式条款对照民法典第 496–498 条与预付式消费解释第 9 条：不得排除退款、不合理限制转让、遗失不补、单方变更实质内容、免除瑕疵或人身责任、不合理增加维权成本。
- 消费者自付款之日起七日内请求返还预付款本金，应予支持，但订立时已从该经营者或其他经营者处获得过相同商品或服务的除外（解释第十四条）；更有利约定优先。例外不得超出法定两项。退款公式、十五日拖延、停业提前 30 日公告须可执行。
- 未成年人大额预付须法定代理人。

### 附件必附

- 价目、课程表或服务项目、赠送说明、预付资金存管说明。单用途卡备案／存管未核则收款字段停止，不得写成已可收款。

### 禁止出现

- 向消费者承诺保本付息。
- 把消保法第二十五条远程商品七日写成服务默认冷静期；把解释第七条清算写成七日条款。
- 最终解释权、人身损害自负、禁止投诉。
- 无证办学或医美继续收预付款、资金盘。
- 把咨询意见或广告投放主轴按消费服务写完。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 留本任务起草并自审；已签履约 → 本套导航履约步骤；已成争退费 → 争议或 C 端分流。未签且目标是评改已有消费服务文本；本任务只起草，评改待签文本转配对 ·审查 原子。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。咨询、广告族、物业、委托、行纪负触发。

### 2. 主体、许可与资金

签约名、履约门店、收款名、发票名分列。未成年人大额预付须法定代理人。未见办学/医美等许可：签署/收款字段停止。

### 3. 一次性或预付

项目、次数或期限、有效期起算、预约规则。预付须书面要素。赠送是否计入退款基数。

### 4. 七日与退款程序

第 14 条七日写入可取证文本；例外不得超出法定两项。退款公式、十五日拖延、停业提前 30 日公告。

### 5. 格式条款与安全保障

逐条对照解释第 9 条。人身损害自负、最终解释权、禁止投诉必须改。

### 6. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把保本付息或无证收预付款改成可履行结构、坚持保留解释第 9 条所列条款。
- `字段停止`：法域、2013 年消保法条正文、单用途卡备案/余额比例、办学/医美许可、第 14 条除外事实未核验。
- `目标停止`：主目标已变为评改待签文本、履约交底、争议文书，或已锁咨询/广告/物业。
