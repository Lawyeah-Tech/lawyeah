# 广告发布合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、1994 年《广告法》同号旧义、《互联网广告管理暂行办法》（2016）、《广告发布登记管理规定》（2016）当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **服务合同 / 广告发布合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文名必须是「审查广告发布合同（服务合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、把设计/制作/代言/代理/纯互联网投放整案改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **媒体刊播是核心给付**：发布者按约定媒介、点位、时段或版面把商业广告刊播出去，广告主支付发布费。验收对象是刊播记录、监播报告或可核验曝光，不是设计稿、成片或代言人到场。设计/制作主轴 → 负触发 `广告设计合同·审查` / `广告制作合同·审查`；代言/肖像许可主轴 → 负触发 `广告代言服务类合同·审查`。夹带制作或代言的，分章或另签，不得用发布费覆盖成果交付或人格权许可争议。
2. **书面合同 + 发布者适格**：广告主、经营者、发布者之间应订书面合同；广告主应委托具有合法经营资格的发布者。广播电台、电视台、报刊出版单位从事发布业务须有专门机构和相适应的场所设备。2021 年修正已删除“办理广告发布登记”，不得把失效发布登记写成现行放行条件。4A 或媒介公司代签必须附发布者授权，无授权却保证上刊的按代理审，转 `广告代理合同·审查`。
3. **广告审查义务不得约定免除**：发布者应查验证明文件、核对广告内容；内容不符或证明不全的不得发布。禁止“内容由广告主自负、发布者概不审核”。广告主对真实性负责，不消灭发布者的法定核对义务。内部约定不能对抗市场监管，也不能免除对消费者的法定连带。
4. **排期媒介必须确定 + 监测对账**：媒体名称、频道/版面/点位、规格或秒数、日期与频次写入附件排期表。只写“投放曝光 100 万”或“黄金时段视情况调整”而无渠道的，无法判断是否履约。刊后须出具刊播证明或监播报告，作为付款条件；效果类不得仅由发布者单方后台说了算。
5. **法定审查类未批不得上刊**：医疗、药品、医疗器械、农药、兽药、保健食品及法律、行政法规规定应审的其他广告，未经审查不得发布；批准文号写入排期单。烟草广告在大众传播媒介、公共场所、公共交通工具、户外禁止发布。含集资内容且无证明文件的，发布者不得发布。教育培训广告受内容限制，不得把“未经行政审查”直接写成与医疗同类的法定先审，除非另有法律、行政法规依据。
6. **行政责任不能转嫁 + 停刊下架**：发布者未查验或明知应知虚假仍发布的，行政罚款和对消费者的连带不能用合同转给广告主单独承担。行政机关责令停止或内容被认定违法的，应立即停刊，费用按已履行部分结算。因发布者原因漏播、错播的，同等资源补刊或退相应发布费。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签广告发布、刊播或认刊正文，尚未签署，尚未成争，核心给付是在约定媒介刊播商业广告并收取发布费，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 核心是交付设计稿、创意方案 → `广告设计合同·审查`；
- 核心是拍摄、制作成片或户外设施承揽安装 → `广告制作合同·审查`；不得删掉制作验收后硬套本技能；
- 核心是姓名、肖像、声音许可或代言人到场推荐 → `广告代言服务类合同·审查`；
- 核心是受委托采购媒介、按佣金或差价代理、自己不控制档期 → `广告代理合同·审查`；
- 核心是信息流、搜索、程序化投放等纯互联网广告，无传统媒介刊播 → `互联网广告类合同·审查`；夹带互联网版位的，互联网专条交接 `互联网广告类合同·审查`，刊播条款可继续审；
- 标题只写“广告合同”且设计、制作、代言、发布并列无法切开 → `广告合同（广义）·审查` 或 本套导航的类型切开步骤；不得删邻类条款后硬套；
- 无文本、本类型条件已谈妥、要出己方稿 → `广告发布合同·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

无资质卖档期、烟草/处方药/集资宣传、要求发布者为违法功效背书：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（广告主侧或发布者侧择一）；相对方；全文及附件/排期表/刊例/素材/审查批文版本；媒介是广播电视、报刊、户外还是夹带互联网；发布者是否实际控制档期或点位；广告主与广告中的商品经营者是否一致；是否属于法定审查类或烟草/集资；监测安排；付款与开票主体；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的刊例、折扣、档期、监测费、期限用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验《广告法》（2021修正）发布条款（书面合同、合法经营资格、查验核对、特殊商品先审、虚假广告责任）、互联网广告发布者规则、非法集资广告禁发、格式条款、定金上限、强制规范；`search_practiced` 只补审查反例；`search_template` 只借栏目结构。不虚构案件系统。

`search_law` 对上述法律结论为 required 级：不可用时不拒绝执行，只停止效力字段。返回 1994 年《广告法》同号旧义、已失效《合同法》及其解释、《互联网广告管理暂行办法》、《广告发布登记管理规定》、《印刷品广告管理办法》时记为噪声，不得写入 `L#`。条号检索若把 1994 年第 34 条（当时的特殊商品审查）或第 46 条（当时的工作人员处分）当成 2021 年同号，必须改走 2021 修正文本再核。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`基本面.md` 中“可与设计、制作打包”不得写成制作或代言主轴可按本类型改完；“刊后 3–7 个工作日”不得写成法定期限。`框架.md` 中“电子数据保存不少于三年”只适用于互联网发布，不得扩到全部媒介。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `广告发布合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有发布/刊播文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。制作、代言、设计、代理、纯互联网投放、广义广告总包负触发。

### 2. 主体与发布资质

签约名、履行名、付款名、发票名分列。无授权代签保证上刊：切开或转代理。未核合法经营资格：字段停止。

### 3. 排期、素材与刊播闭环

媒介、点位、日期、频次、规格入附件。成片作为附件。上刊不等于发布完成。

### 4. 广告审查与拒登

查验时限、退回轮次、拒登不构成违约。删除“内容自负、发布者不审”。

### 5. 法定先审、禁止发布与停笔

未批先刊、烟草、集资宣传：停笔或红线。不把教育培训直接写成法定先审。

### 6. 对价、格式条款与强制规范

刊例与成交价同时入合同。预付款不是定金。无核验引文则法律结论字段停止。

### 7. 监测、补刊、停刊与对外责任

刊播证明作为付款条件。漏播补刊或退费。对外连带不能转嫁。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把无资质卖档期、烟草/集资/未审先发、或“内容自负且发布者不审”改成可履行结构。
- `字段停止`：法域、动态规则、发布者经营资格、户外点位权属、审查批文文号未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
