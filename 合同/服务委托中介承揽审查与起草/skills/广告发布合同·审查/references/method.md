# 审查方法（锁定 服务合同 / 广告发布合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制广告制作的作品验收/成片知识产权主路径、代言的人格权许可主路径、广告代理的佣金采购主路径。

定性校验：标题、核心给付与本类型一致才继续；明显是设计、制作、代言、代理或纯互联网投放则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、必然过审或唯一必得发布费。

`search_law` 返回 1994 年《广告法》同号旧义（当时第 32 条是户外禁设、第 34 条是特殊商品先审、第 46 条是工作人员处分）、已失效《合同法》及其解释、《互联网广告管理暂行办法》（2016）、《广告发布登记管理规定》（2016）、《印刷品广告管理办法》、《烟草广告管理暂行办法》时记为噪声，不得写入 `L#`。2021 年修正已删除广播电台、电视台、报刊“办理广告发布登记”；不得把失效发布登记写成现行放行条件。

示范文本只参考结构。1992 年《广告发布业务合同》和未知权威的认刊书处《广告管理条例》时代，只借媒介、规格、样稿、费用、违约栏目，不取正文，不得把 1987 年《广告管理条例》写成发布合同的现行主依据。

知识库纠正（不回写双文件）：

- `基本面.md` “可与设计、制作打包”：夹带制作只允许分章或另签。制作或代言成为主给付的，负触发对应原子，不得用发布费覆盖成果交付或人格权许可。
- `基本面.md` “刊后 3–7 个工作日出具刊播证明”：实务量级，不是法定期限。修改句用 `【待填】` 日，不得写成法定。
- `基本面.md` “教育等限制类广告未经审查”：教育、培训广告主要是内容限制，不是与医疗、药品同类的法定先审。不得把教育直接写成“未经行政审查不得上刊”，除非另有法律、行政法规依据。
- `框架.md` “互联网相关电子数据自发布终了之日起保存不少于三年”：对应《互联网广告管理办法》第 14 条，只约束互联网发布档案，不得扩到广播电视、报刊、户外的全部媒介。
- 2021 年修正删除广告发布登记：核验发布者时看合法经营资格和专门机构（第 29、32 条），不把已废止的发布登记证当作签署条件。

## 节点 0　签署状态与成果分流

先于类型识别。命中任一项则本任务不填十节实体结论，只交付分流理由和最小交接。

| 已能支持的事实 | 走向 | 不得写成 |
| --- | --- | --- |
| 无可读正文和附件，或只有口头投放要点 | `广告发布合同·起草` | 已经完成审查；可以签 |
| 未签，目标是评改已有发布/刊播/认刊文本 | 进入节点 1 | 已签署或已生效 |
| 残缺模板，用户要按己方条件重写整稿 | 起草 | 本任务出整稿 |
| 已签，问刊期执行、对账日、发票 | 本套导航的履约步骤 | 签前意见 |
| 已出现催告、解除、索赔、立案、开庭、仲裁 | `或对应专项领域。` 或对应专项领域 | 继续当签前审查 |

缺立场或同时掌握双方秘密：整体停止策略输出。缺书面文本仍要“给个能不能签”：不启动实体审查。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。标题写“广告代理”“全案服务”的，先看对方是否实际控制媒介档期或点位并收取发布费：是则按发布审，不是则切开。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 在约定频道、版面、户外点位或时段刊播，对价是发布费，验收看监播/刊播证明 | 本类型 | 正触发 |
| 交付设计稿、创意、文案，验收看作品 | 广告设计 | 负触发 `广告设计合同·审查` |
| 拍摄、成片、包装或户外设施制作安装，验收看成品 | 广告制作 | 负触发 `广告制作合同·审查` |
| 许可姓名、肖像、声音，或代言人到场推荐 | 广告代言 | 负触发 `广告代言服务类合同·审查` |
| 受委托采购媒介、佣金或差价、自己不控制档期 | 广告代理 | 负触发 `广告代理合同·审查` |
| 信息流、搜索、程序化购买，无传统媒介刊播 | 互联网广告 | 负触发 `互联网广告类合同·审查` |
| 设计、制作、代言、发布并列且无法判断主给付 | 广义广告合同 | 负触发 `广告合同（广义）·审查` 或引擎 |
| 仅提供流量入口，不审核、不决定上刊或下架 | 信息服务 | 负触发引擎；一旦决定是否发布、修改或下架，落入发布者义务 |

支持切开的规范（法律结论须运行时复核）：

- 《广告法》（2021修正）第 2 条：广告主自行或委托设计、制作、发布；广告经营者提供设计、制作、代理；广告发布者为广告主或经营者发布；广告代言人另列。
- 第 30 条：广告主、经营者、发布者之间应订书面合同。
- 第 32 条：委托具有合法经营资格的经营者、发布者。
- 《互联网广告管理办法》第 4 条：利用互联网发布的，适用发布者规定；仅提供信息服务的，适用信息服务提供者规定。第 45 条路径的“明知应知应制止”不等于当然成为发布者。

### 1.2 加载协议（硬闸）

本技能已锁定 **服务合同 / 广告发布合同**。只打开 `references/基本面.md` 与 `框架.md`。禁止读其他子目录，禁止为对照再开第二类。

### 1.3 媒体刊播 + 与制作/代言切开（硬闸）

| 文本写法 | 本任务动作 | 修改句方向 |
| --- | --- | --- |
| 乙方按排期表在指定频道/版面/点位刊播，甲方付发布费，验收看监播报告 | 正触发 | 首部写明“广告发布，不是设计、制作或代言” |
| 对价是成片交付、修改轮次、成片知识产权，刊播只是附带一句 | 负触发制作 | 不按发布改完 |
| 对价是肖像授权、到场次数、竞品代言限制 | 负触发代言 | 不按发布改完 |
| 夹带改版、配音或一张代言授权，但主给付仍是档期刊播 | 正触发；夹带专条交接 | 分章或另签，发布费不覆盖成果或人格权争议 |
| 无授权的 4A 保证“一定上××卫视” | 负触发代理，或必须改：出示发布者授权 | 不得预收全额发布费 |

修改句（正触发首部）：

「本合同为广告发布合同。乙方作为广告发布者，按附件排期表在【媒体名称 / 频道或版面 / 点位】刊播甲方指定的商业广告，甲方向乙方支付发布费。本合同不包含广告设计、成片制作或广告代言。夹带的改版或素材技术处理，不改变验收对象为刊播记录和监播报告。乙方无权以发布费覆盖设计稿、成片或代言人人格标识的交付争议。」

最强反方：相对方主张已构成制作承揽或全案代理，从而主张按作品验收或按佣金免档期交付。修改句必须收回制作验收和“保证上刊但无档期控制”。用户坚持保留制作或代言主轴：负触发，不填本类型十节实体结论。

### 1.4 禁止发布 / 无资质卖档期停笔（硬闸）

加载后或定性中出现：无经营资格的主体倒卖广播电视或户外档期；烟草（含电子烟）在大众传播媒介、公共场所、公共交通工具或户外发布；处方药广告（法律、行政法规另有规定除外）；含集资内容且无相关证明文件；要求发布者对违法功效、绝对化用语或未审医疗广告作背书；以发布费名义收取集资宣传费用。

动作：

1. 交付告知：相关发布安排可能因第 153 条或目的违法而不能强制履行。不得改写成可履行的无资质卖档期、烟草刊播或集资广告结构。
2. 不写可履行的品类伪装、假批文路径或“改成品牌形象广告就能发烟草”。
3. 风险表只保留识别依据和删除/转出口径。
4. 用户坚持“改到能签且仍做这些事”：整体停止。

## 节点 2　主体、发布资格与文本版本

### 2.1 主体表

建表：签约名、履行名、付款名、发票名、授权签字人。名称不一致不自动合并。集团品牌部代下属公司签的，付款和发票主体必须一致。

广告主须与广告中的商品经营者一致或取得授权。保健品、医疗、教育、金融等广告主的经营许可未闭合：该广告主适格字段停止，不写成“可以上刊”。

共同发布：写清谁对违法内容承担发布者责任，不得默认按份。

口头“台里已经点头”不得写成已授权。媒介公司代签必须附发布者授权；无授权却承诺保证上刊：按节点 1.3 转代理或红线删除保证。

### 2.2 发布资格

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 广播电台、电视台、报刊无专门广告机构或相适应场所设备的痕迹 | 字段停止；修改句要求作为附件 | 已具备发布条件；已办理发布登记 |
| 户外点位无权属、无设置许可或场地租期盖不住排期 | 字段停止；修改句要求许可编号和租期 | 点位已锁定可上刊 |
| 对方只是媒介采购公司，无发布者授权 | 切开或转 `广告代理合同·审查` | 可以预收全额发布费 |
| 只有营业执照 | 执照不等于发布资格 | 已具备全部发布资质 |

支持依据：第 29 条（专门机构与场所设备）；第 32 条（合法经营资格）。2021 年修正删除发布登记，不得把失效《广告发布登记管理规定》写成签署条件。

修改句：

「本合同签署前，乙方应向甲方出示并作为附件：【广播电视/报刊出版/户外设施权属或设置许可】及专门从事广告业务的机构说明。未核验前，不得主张已具备上刊条件。甲方委托的媒介公司代签的，须同时附具发布者的书面授权；无授权的，乙方不得预收全额发布费，本合同不构成档期交付保证。」

部门规章或许可管理规范不当然导致民事合同无效（解释第 16 条）。本任务只停止“可以上刊”表述，不宣告合同当然无效；无资质卖档期本身按节点 1.4 停笔。

## 节点 3　排期、素材与刊播闭环（硬闸）

### 3.1 媒介与排期必须确定

| 文本写法 | 动作 |
| --- | --- |
| 只写“投放曝光约 100 万”“黄金时段视情况调整” | 红线。补媒体、点位、日期、频次、规格 |
| 有排期表但与正文冲突，未写以哪份为准 | 必须改：附件与正文同等效力，冲突以排期表为准或删除冲突句 |
| 户外未写设置许可编号、场地租期是否覆盖排期 | 必须改 |
| 允许替换竞品但未写品类和通知时点 | 必须改 |

修改句：

「附件《排期表》列明媒体名称、频道或版面或点位、尺寸或秒数、刊播日期、频次及刊例编号，与正文具有同等效力。变更须双方书面确认。附件与正文冲突的，以排期表为准。仅约定曝光量或“黄金时段”而未指定渠道和时点的，不视为已确定给付。」

禁止编造档期数字。未给出的频次、秒数用 `【待填】`。

### 3.2 素材交付与上刊完成

成片或完稿作为附件。送达格式、字幕安全区、响度、截止时点要写死。逾期送达可顺延，但发布者已将该档期转售第三人的，应退还差额而非当然免责。发布者主张空置费的，须先书面催告。

上刊不等于发布完成：设施已安装未点亮、页面已上传未对目标用户展示，均可能不算完成。

修改句：

「甲方应于排期日前【待填】日，按附件《素材技术规范》向乙方指定接口送达成片或完稿。逾期送达的，刊期相应顺延；乙方已将该档期转售第三人的，应在【待填】日内退还相应发布费差额，不得主张当然免责。设施安装完成但未按排期点亮，或素材已上传但未按约定对目标用户展示的，不视为发布完成。」

## 节点 4　广告审查与拒登（硬闸）

支持依据（运行时复核 2021 修正文本，禁止采用 1994 年同号）：发布者应查验证明文件、核对广告内容；内容不符或证明不全的不得发布。《互联网广告管理办法》第 14 条对互联网发布者作了相同安排，并要求档案自发布终了之日起保存不少于三年。第 4 条：广告主对广告内容真实性负责——不消灭发布者的法定核对义务。《防范和处置非法集资条例》第 11 条：对没有相关证明文件且包含集资内容的广告，发布者不得发布。

| 文本写法 | 动作 |
| --- | --- |
| “广告内容由甲方自负，乙方不审核、不承担任何责任” | 红线删除。现有依据不支持用合同免除法定核对义务 |
| 有审核期，但无退回轮次、无拒登权 | 必须改：证明不全或违法时有权拒绝且不构成违约 |
| “按客户要求必须发布” | 红线。内部约定不能对抗监管 |
| 审核时限沉默 | 必须改：补查验时限和书面退回 |

修改句（审查与拒登）：

「乙方应在收到完整素材和证明文件后【待填】日内完成查验。证明文件不全、内容与批文不符、含绝对化用语或依法不得发布的，乙方有权书面退回并拒绝上刊，不构成违约；已收档期费按未发布部分在【待填】日内退还。双方不得约定“内容由甲方自负、乙方概不审核”。甲方对广告内容真实性负责，不免除乙方依法查验证明文件、核对广告内容的义务。」

最强反方：发布者主张第 4 条已把真实性全部推给广告主，或主张格式条款中的免责已经提示。现有依据支持广告主对真实性负责，现有依据不支持因此免除发布者查验核对和不得发布的义务。用户坚持保留“概不审核”：整体停止。

## 节点 5　法定先审、禁止发布与发布条件（硬闸）

支持依据：《互联网广告管理办法》第 7 条（医疗、药品、医疗器械、农药、兽药、保健食品、特殊医学用途配方食品等应审广告，未经审查不得发布；须严格按审定内容发布，改动应重新申请）。《医疗器械监督管理条例》第 60 条：医疗器械广告应取得批准文号，未经审查不得发布。《广告法》第 16、17、22、48、57 条：医疗功效限制、禁止其他广告涉及疾病治疗、禁止特定场所烟草广告、不得伪造变造转让批准文件。教育、培训广告适用内容限制，本任务不把它写成与医疗同类的法定先审，除非运行时核到法律、行政法规另有先审规定。

| 文本写法 | 动作 |
| --- | --- |
| 医疗/药品/器械/保健食品排期，无批准文号，写“先刊后补批文” | 红线。批准作为**发布条件**，不是合同成立条件 |
| 烟草、电子烟户外或电视台刊播 | 停笔（节点 1.4） |
| 集资、理财收益承诺且无证明文件 | 停笔（节点 1.4） |
| 批文有但允许剪辑拼接 | 必须改：须按审定内容发布，改动重新报审 |
| 把教育培训写成“未经教育局审查不得刊”却无法律依据 | 不得虚构先审机关；改为内容限制与不得保证就业/取证 |

修改句：

「属于法律、行政法规规定应当审查的广告的，甲方应在排期锁定前向乙方提交现行有效的广告审查批准文件，批准文号写入《排期表》。未取得批准的，乙方不得上刊，已收未发布部分费用应退还。本合同自签字或预付款到账之日起成立，法定审查批准是发布条件，不是合同成立条件。已审定内容不得剪辑、拼接、修改；需要改动的，甲方应重新申请审查。」

用户要求补假批文或倒签批准日：整体停止。

## 节点 6　对价、格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 对价与定金

刊例价、折扣、净价、监测费分列。写明是否含改版、加急、撤档损失。预付款性质为发布费，除非明确使用“定金”且不超过标的额 20%（第 586 条）。“订金、保证金”无定金性质的，不得写成定金。无核验引文不得把 20% 写成已核验结论。

撤单截止日及取消费要写死。刊例与成交价同时入合同，开票与处罚计算口径一致。

修改句：

「发布费按附件刊例编号【待填】、折扣【待填】确定净价人民币【待填】元，是否包含改版、加急、撤档损失以附件《费用清单》为准。甲方在预定时应支付的款项为发布费预付，不适用定金罚则；双方如约定定金，须使用“定金”二字且不超过发布费总额的百分之二十，超过部分不产生定金效力。」

禁止编造单价。保证点击率或成交量却无监测：红线，改为可核验点位或删除效果保证。

### 6.2 格式条款

为重复使用而预先拟定、订立时未与对方协商。电视台、平台发布者不得仅以“这次没用过第二次”否认。依据示范文本制作，不当然排除格式条款。

审查：“内容自负”、单方后台数据、保证曝光、自动顺延档期、管辖/仲裁等异常条款是否有足以引起注意的标识（第 496 条；解释第 10 条）。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在刊例背面 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

提供方对其已尽提示或说明承担举证责任。第 497 条无效情形、第 498 条不利解释：只在核验后作为修改理由，不代替修改句。

### 6.3 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的、是否仅行政管理、是否只规制履行行为（第 153 条；解释第 16、18 条）。禁止用已失效“效力性/管理性”口诀代替解释第 16 条。未审先发、烟草、集资、无资质卖档期：不改写成有效履行。发布登记被 2021 年修正删除，不得再以“未办发布登记合同无效”作为民事结论。

## 节点 7　监测、补刊、停刊与对外责任（硬闸）

### 7.1 监测与补刊

刊后出具监播报告或播出单，作为付款条件。约定第三方监测或平台导出规则、去重口径、无效曝光（刷量、定向偏差）剔除。数据冲突以约定监测方为准。效果类禁止仅由发布者单方后台说了算。

漏播、错播、遮挡、信号中断写清认定标准（错频道、错时段、缺播次数）及补刊或退费公式。因发布者原因漏播的，同等资源补播；无法补播则退相应费用。因更高价客户挤占档期，不得列入不可抗力。

修改句：

「乙方应在该条排期履行完毕后【待填】日内向甲方出具监播报告或播出单。甲方在收到后【待填】日内提出书面异议，逾期未异议视为该条已按排期履行。因乙方原因漏播、错播、错频道或信号中断的，乙方应在【待填】日内以同等资源补刊；无法补刊的，退还相应发布费。客户更高出价、未提前通知的常规检修，不得视为不可抗力。」

### 7.2 停刊下架与对外责任

行政机关责令停止、内容被认定违法的，发布者应立即停刊，费用按已履行部分结算，不得继续收费。下线时限写成可执行小时数。

发布者明知或应知虚假仍发布的，对消费者的连带和对市场监管的行政责任，内部约定不能免除对外责任。广告主提供虚假证明的，发布者可向广告主追偿，但须先保留对外责任。

修改句：

「市场监督管理部门或其他有权机关责令停止发布，或广告被认定为违法的，乙方应在收到通知后【待填】小时内停刊或下线，已履行部分按排期结算，未履行部分发布费在【待填】日内退还，不得继续收费。因甲方提供虚假证明或违法素材导致处罚的，甲方应赔偿乙方因此支付的罚款和撤稿费用；因乙方未依法查验或明知应知虚假仍发布的，乙方对外承担的行政责任和对消费者的连带责任不因本合同内部约定而免除，乙方承担后可按过错向甲方追偿。」

最强反方：发布者主张“已约定甲方包揽全部罚款”。现有依据支持内部追偿，现有依据不支持把对外法定责任写成已转嫁消灭。

知识产权：素材权利由广告主担保；发布者仅获该次刊播所需许可，不得把广告素材另作自用。

| 首部 | 标题用广告发布/刊播，不写成全案代理或设计制作；主体全称与许可证号；代理代签附授权；鉴于不写保证销量或保证过审 | 标题或主体修改句 |

| 常见问题 | 无监测无刊播证明；代理卖台里资源；无拒登权；未审先发 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（制作/代言/代理主轴、内容自负免审、无资质卖档期、未审先发、烟草/集资、无监测却保证效果、对外连带转嫁、倒签或补假批文）；
- `必须改`：可谈但签署前要落句（排期附件、查验时限与拒登、刊播证明付款、补刊公式、停刊时限、刊例与成交价、授权附件）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级发布费已预付却无档期控制和刊播证明、且用户拒绝升级：停止“可以签署”建议。
