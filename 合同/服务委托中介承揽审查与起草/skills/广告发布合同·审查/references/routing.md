# 边界与路由

本技能只审查 **服务合同 / 广告发布合同** 的待签文本。中文展示名是「审查广告发布合同（服务合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 核心给付是交付广告创意、设计稿、VI 或文案方案 | `广告设计合同·审查` |
| 核心给付是拍摄、制作成片、包装成品，或户外设施承揽安装；验收对象是作品而非刊播记录 | `广告制作合同·审查`。不得删制作验收后继续当发布审 |
| 核心给付是姓名、肖像、声音许可，或代言人到场、口播、直播带货推荐 | `广告代言服务类合同·审查` |
| 受委托采购媒介、按佣金或差价代理，自己不控制档期或点位，却保证上刊 | `广告代理合同·审查` |
| 信息流、搜索、程序化购买、邮件等纯互联网投放，无广播电视/报刊/户外刊播 | `互联网广告类合同·审查` |
| 标题只写“广告合同”，设计、制作、代言、发布并列且无法判断主给付 | `广告合同（广义）·审查` 或引擎。不得删邻类条款后硬套本技能 |
| 无文本、本类型条件已谈妥、要出己方稿 | `广告发布合同·起草` |
| 已签未争、只问刊期、对账、发票 | 本套导航的履约步骤 |
| 已成争 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

发布正文里夹带一小段设计改版、成片修改或互联网版位：专条交接对应原子；媒介、排期、审查、监测、补刊、停刊条款可继续审。用户坚持本技能把制作、代言或代理整案改完：`目标停止`。
