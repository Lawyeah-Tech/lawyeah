# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的刊例、折扣、档期、曝光或期限；把已失效《合同法》、1994 年《广告法》同号旧义或已废止广告发布登记写入结论；把“内容自负、发布者不审”写成已闭合；把无监测的保证点击率或成交量写成可履行；把制作、代言、代理或纯互联网投放当成已完成的本类型审查；把违禁发布改成可履行结构。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查广告发布合同（服务合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回 1994 年《广告法》同号旧义、已失效《合同法》及其解释、《互联网广告管理暂行办法》、《广告发布登记管理规定》时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `服务合同`，子级 `广告发布合同`。定性理由、易混切开结果（广告设计、广告制作、广告代言、广告代理、互联网广告、广义广告合同）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、资质与文本版本

主体表：签约名、履行名、付款名、发票名、授权签字人、共同发布者、代签的媒介公司。资格表：发布者合法经营资格或专门机构痕迹；户外点位权属或设置许可；广告主与广告中商品经营者是否一致。版本表：正文、排期表、刊例、素材清单、审查批文、监测方案、聊天确认；冲突并列。未核发布资格：该上刊能力字段停止。

## 5. 刊播给付、审查、监测与对价

核心给付是否媒介曝光；是否夹带制作、代言或代理；排期是否确定到媒体、点位、日期、频次、规格；成片是否入附件；查验与拒登是否闭合；法定审查批文是否作为发布条件；监测口径与刊播证明是否作为付款条件；刊例与成交价、预付款与定金。缺口标 `G#`。不输出制作验收或代言肖像许可主路径。

## 6. 格式条款与强制规范

是否构成格式条款；“内容自负”、单方后台数据、保证曝光或成交、管辖等异常条款是否加黑提示。强制规范只按第 153 条和解释第 16 条区分，不用失效口诀。未审先发、烟草、集资、无资质卖档期只保留识别与停笔。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把框架里的实务量级（如刊后 3–7 日）写成法定期限。

## 9. 谈判与签署提醒

谈判顺序：先红线（类型错位、内容自负免审、无资质卖档期、未审先发、烟草/集资、无监测却保证效果、对外连带转嫁），再必须改（排期附件、查验时限与拒登、刊播证明付款、补刊公式、停刊时限、刊例与成交价），最后可优化。签署提醒：发布者公章与资质主体一致；排期表、刊例、素材、批文、监测方案入附件；电子排期指定邮箱写入合同。不指导倒签或补假批文。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书或效力保证，也不是广告制作、代言、代理或互联网广告专项审查。
