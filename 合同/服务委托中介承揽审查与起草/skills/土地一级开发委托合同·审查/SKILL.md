# 土地一级开发委托合同·审查

## 任务目标

在单一立场下，只审查 **委托合同 / 土地一级开发委托合同** 的待签文本：政府或其授权土地储备机构委托企业实施毛地变净地，企业真实筹措资金并组织规划、征拆和大市政，对价是核定成本加约定利润或财政安排的开发补偿。输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「审查土地一级开发委托合同（委托合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查、从零起草、履约交底、争议文书、有效性或回款保证、名开发实借贷整案、名开发实施工整案、一二级联动／定向出让整案、征收补偿个案整案。

## 工作边界

正触发：已有可读待签文本要评改，；尚未签署，尚未成争；核心给付是一级开发**委托实施**——企业承担资金筹措和征拆／市政组织，政府侧回收净地后按核定成本支付开发补偿或约定利润，本约不绑定二级摘牌。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 企业只出钱，不组织征拆和市政，固定期限固定利率、保底年化、差额补足或资金直接进财政统筹 → `名为一级开发实为借贷·审查`；
- 企业只做三通一平或市政施工，按审定造价取费，不承担融资与征拆风险，或 BT 垫资回购 → `名为一级开发实为施工·审查`；
- 本约绑定后续招拍挂优先权、定向出让、内定底价、保证摘牌或出让金分成换二级用地 → `“一二级联动”相关合同·审查`；
- 只受托实施拆迁、不管融资和市政整体 → `拆迁委托协议·审查`；
- 政府投资项目代建、按代建管理费结算 → `政府代建合同·审查`；
- 普通民事委托、无关土地储备 → `一般委托合同·审查`；
- 类型未定或名实两可 → 本套导航的类型切开步骤；
- 无文本、本类型条件已谈妥、要出己方稿 → `土地一级开发委托合同·起草`；
- 已签只问拨付日、验收日、移交日 → 本套导航的履约步骤；
- 已成争（催告、解除、索赔、审计问责、诉讼仲裁）→ 合同争议或行政争议专项。

挂靠、违法分包、规避招标、伪造授权或储备计划、把毛地推进出让、把定向出让或施工单位垫资改成可履行：只出告知，不改写成可履行结构。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成。每一闸必须给出修改句或明确转出口径，禁止只打红黄绿。

1. **委托权限与资金**。必须同时闭合：委托方有市、县政府土地储备／一级开发职权或书面授权；项目已纳入土地储备开发计划或等效批准文件；开发资金来源、成本构成、核定办法、支付节点和财政预算／国库路径可回链。修改句把授权文件、储备计划、成本明细和预算安排列为附件，并写“未获批准不生效、未核定不付款”。口头“领导同意了”、管委会或指挥部无授权、计划未覆盖红线：字段停止，不写可以盖章。禁止把“负责融资”写成借款法律关系，禁止把土地出让金直接返还写成可履行支付。
2. **与 `名为一级开发实为借贷·审查` 切开**。只出钱不做事、固定回报、年化、保底、资金回流财政：负触发。本任务禁止输出民间借贷利率上限表或企业间拆借效力主路径。禁止打开其 method。
3. **与 `名为一级开发实为施工·审查` 切开**。按造价取费、不承担征拆和融资、承建单位垫资或 BT 回购：负触发。本任务禁止输出施工优先受偿、竣工五方验收或施工许可证主路径。禁止打开其 method。
4. **与 `“一二级联动”相关合同·审查` 切开**。后续摘牌优先、定向出让、内定底价、保证摘牌：负触发。本任务禁止输出勾地、预申请保证金或实施主体转化主路径。禁止打开其 method。后续出让只允许写：依法招标拍卖挂牌，本约不赋予摘牌优先权。

附加必落句（有事实则单列，无事实在缺口节说明）：

- **角色**：受托方写成“委托实施单位”或“投资实施主体”，不得写成“承建单位垫资建设”。
- **成本**：写清按实核定或包干；第三方审计作为结算依据；利润与成本分列。
- **行政优益权**：规划调整或公共利益解除时，补偿已核定实际支出及合同已约定的合理预期收益；不得写“视为双方一致同意解除且互不补偿”。
- **争议解决**：若按行政协议路径审查，仲裁条款原则上无效，改为行政诉讼；不得假装民事仲裁已经选定。是否构成行政协议须按三要素个案判断，不保证一律是行政协议。
- **净地**：未达到净地标准不得进入出让；毛地出让红线。

必须有修改句。每个风险回链文本位置。禁止复制 `“一二级联动”相关合同·审查`、`名为一级开发实为借贷·审查`、`名为一级开发实为施工·审查` method。

## 建立审查坐标

确认：使用者与授权；单方立场（委托方／政府侧或受托开发企业）；相对方；全文及红线／方案／成本／授权／纪要附件版本；红线范围；是否已纳入储备计划；开发内容是否含融资、征拆、市政；成本与支付来源；有无固定回报或后续拿地；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的面积、金额、期限、文号用 `【待填】`，不编造。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、1989 年行政诉讼法第十二条不受理清单、2001 年城市房屋拆迁管理条例当作现行规则。不得把“注册资本不低于一百万元”写成现行房地产开发准入。不得把土地一级开发委托写成必然有效、必然无效或必然回款。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law`（法律结论 required）：核验行政协议识别与仲裁条款、委托权限、政府投资垫资禁令、招拍挂强制、虚假意思表示、固定回报按借款认定、格式条款与强制规范。
- `search_practiced`（optional）：补行政主体资格、授权委托签约、仲裁条款无效等争点。返回“一律民事合同可仲裁”“未招标一律无效”“注册资本一百万为现行门槛”时记噪声。
- `search_template`（optional）：只借栏目结构。范本写“一二级联动”“垫付资金＋固定投资回报”“到期还本付息”不得当规则。

不虚构案件系统。`search_law` 返回已失效《合同法》及其解释、1989 年行政诉讼法第十二条不受理清单、2001 年拆迁条例、1990 年成片土地开发办法时记为噪声，不得写入 `L#`。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口，不代替节点。

0. 签署状态与成果分流
1. 类型识别与单目录加载（真实一级委托；切开 s114／s115／s116）
2. 委托权限、主体、资质与批准
3. 资金闭环、成本核定与支付路径
4. 标的红线、储备计划与净地
5. 选定程序、征收与转委托
6. 行政协议识别、优益权与争议解决
7. 垫资角色、挂靠与强制规范
8. 按框架六步出修改句

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、补假授权或假储备计划、把无权主体改成可签约、把固定回报借贷或施工单位垫资改成可履行、把定向出让或内定底价改成可履行、保证必然有效或必然回款摘牌。
- `字段停止`：法域、授权文件、储备计划覆盖、预算列支、选定程序是否必须招标、是否构成行政协议未核验。
- `目标停止`：主目标已变为从零起草、履约交底、行政诉讼或民事起诉状，或用户要把本约改成借贷、施工或联动本约。

生存级垫资或个人无限连带且用户拒绝升级：停止“可以签署”建议。
