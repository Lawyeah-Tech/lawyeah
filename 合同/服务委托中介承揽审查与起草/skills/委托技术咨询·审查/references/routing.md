# 边界与路由

本技能只审查 **委托合同 / 技术咨询合同** 的待签文本。中文展示名是「审查技术咨询合同（委托合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止抄 `或`、`咨询服务合同·审查` 的审查方法。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 用户或文本明确落在技术类合同目录、主张按四技合同技术咨询原子审 | `或`。不得留下本技能对照委托费用或任意解除改完 |
| 无特定技术项目的管理、战略、财务、人力、品牌等商务咨询 | `咨询服务合同·审查`。不得把第 881 条第 3 款套到该类文本 |
| 维修、测绘、检测、调试、工艺实施等解决特定技术问题 | `委托技术服务·审查` |
| 研究开发新技术、新产品、新工艺并交付开发成果 | `委托技术开发合同·审查`；技术类开发主轴 `只审委托合同目录下的委托技术开发。用户或材料按技术类合同进入《技术开发合同》→`；软件开发 `可运行软件或系统交付→` |
| 施工图、初步设计、出图盖章、可据以施工的图纸 | `委托他人设计的服务合同·审查`（委托他人设计）或 `单独设计发包，无现场简易施工成果`（建设工程设计） |
| 建设工程咨询、估算概算、全过程工程咨询 | `只出可行性造价或管理咨询意见不交付测绘测试成果→` |
| 以委托人名义对外签约、开委托人抬头发票、概括处理事务 | `一般委托合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `委托技术咨询·起草` |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

委托技术咨询正文里夹带一小段资料保管或差旅报销：专条写清费用逐项后可继续审。用户坚持本技能把技术类技术咨询、咨询服务、出图或开发整案改完：`目标停止`。
