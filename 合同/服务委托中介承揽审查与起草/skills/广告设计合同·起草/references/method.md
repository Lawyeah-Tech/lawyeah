# 审查方法（锁定 服务合同 / 广告设计合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制买卖、施工 method。禁止抄 `广告合同（广义）·审查` 的广义混包主路径，禁止抄 `委托他人设计的服务合同·审查` 的功能性出图主路径。

定性校验：标题、核心给付与本类型一致才继续；制作、发布、广义混包、功能性委托设计、委托创作或他类明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、设计验收即可发布或唯一必得金额。

`search_law` 返回已失效《合同法》及其解释、1994 年《广告法》、1990 年《著作权法》继承条款、已失效广告审查员办法或印刷品广告管理暂行办法时记为噪声，不得写入 `L#`。

示范文本只参考结构。标题写成“广告设计制作”的范本只证明制作是另一给付，不得当作本类型已覆盖制作。

知识库纠正（不回写双文件）：

- `基本面.md` “归承揽”：第 770 条列举未单列设计，本类型按“完成工作并交付设计成果”适用承揽规则，同时受广告法约束。不得因此改成建设工程施工承揽，也不得改成一般委托事务。
- `基本面.md` “未约定时设计作品著作权一般归设计方”：与著作权法（2020 修正）第 19 条一致，禁止改写成默认归广告主。
- `基本面.md` “设计方须有合法广告经营资格”：广告法第三十二条约束的是广告主应委托有资格者。无资格承接是行政与履行风险，不当然导致合同无效；效力须运行时按第 153 条和解释第 16 条区分。
- 著作权民事解释第十二条仍写“著作权法第十七条”：2020 修正委托作品为第十九条。运行时引用第十九条，解释第十二条只借“特定目的范围内使用”的争点，不把旧条号写入 `L#`。
- `框架.md` “买断”：必须展开为许可或转让清单，不得把该二字当作已经完成权属转移。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 创意、文案、视觉方案、KV、分镜、落地页或平面物料的可编辑源文件，按任务书验收设计稿 | 本类型 | 正触发 |
| 成片、拍摄执行、喷绘实物、按已定设计稿加工广告成品 | 广告制作 | 负触发 `广告制作合同·审查` |
| 媒介排期、刊例折扣、曝光量或点击计酬、发布执行 | 广告发布 | 负触发 `广告发布合同·审查` |
| 设计、制作、发布捆在一份文本，无法拆出设计主给付 | 广告合同（广义） | 负触发 `广告合同（广义）·审查` |
| 全案代理、媒介采买、账户代运营 | 广告代理 | 负触发 `广告代理合同·审查` |

| 非广告用途的包装结构、产品外观、工业设计出图 | 委托他人设计 | 负触发 `委托他人设计的服务合同·审查` |
| 一般文学艺术委托创作，无广告用途 | 委托创作 | 负触发 `委托创作·审查` |
| 建设工程施工图、方案设计、图审 | 建设工程设计 | 负触发 `单独设计发包，无现场简易施工成果` |
| 调研建议书、战略意见、无设计稿 | 咨询服务 | 负触发 `咨询服务合同·审查` |

支持切开的规范（法律结论须运行时复核）：

- 第 770 条：承揽是按照定作人要求完成工作并交付工作成果。本类型成果是设计稿和源文件，不是成片或已发布广告。
- 广告法第二条：广告经营者接受委托提供设计、制作、代理；广告发布者负责发布。设计、制作、发布是可分的活动，不得在本任务合并审查。
- 广告法第三十条：广告活动应订立书面合同。本任务审的是设计书面合同，不是发布合同。
- 著作权法（2020 修正）第十九条：委托作品未约定则著作权属于受托人。本类型按广告用途下的委托作品处理权属，不展开功能性产品设计或一般文学委托的专条。

夹带一小段制作执行或发布排期：专章交接对应原子；设计成果、权属、源文件可继续审。用户坚持本技能把制作、发布或广义混包整案改完：`目标停止`。

### 1.2 加载协议（硬闸）

本技能已锁定 **服务合同 / 广告设计合同**。只打开 `references/基本面.md` 与 `references/框架.md`。禁止读其他子目录，禁止为对照再开第二类。

### 1.3 违法结构停笔

加载后或定性中出现：为禁止生产、销售的商品或服务设计广告；为禁止发布的商品或服务提供设计；为没有相关证明文件且包含集资内容的宣传提供设计；出借广告经营资格或要求把无资格主体改成“挂靠有资格公司后可签”。

动作：

1. 交付告知：广告法第三十七条禁止为禁产禁售禁发商品或服务设计广告；非法集资条例第十一条禁止为无证明且含集资内容的广告提供设计。不得改写成可履行文本。
2. 不写出借资格、假审核、可履行的禁发文案或集资宣传口径。
3. 风险表只保留识别依据和转出/删除提示。
4. 用户坚持“改到能签且仍做这些事”：整体停止。

## 节点 2　主体、资格与确认人

### 2.1 主体表

建表：签约名、履行名、付款名、发票名、授权签字人、样稿确认人。名称不一致不自动合并。集团品牌由下属主体使用设计成果的，修改句把使用主体列为被许可人或加入确认，不编造主体。

口头“市场部说就这个”不得写成已确认。国资、上市公司内部决议或采购程序未附：该签署能力字段停止，不写成“可以盖章”。

### 2.2 经营资格

广告法第三十二条：广告主委托设计，应当委托具有合法经营资格的广告经营者。文本或材料未提及经营范围含广告设计：标 `G#`，不得写成“已具备合法资格”。

个人设计师以个人名义签约：审发票能力与著作权归属，不在本任务认定已成立劳动关系。无资格仍要签：告知行政违法与后续发布审核障碍；不改写成挂靠有资格公司的可履行结构。

### 2.3 确认人

样稿确认权必须锁定姓名+职务或指定邮箱、即时通讯账号。多人会签未写顺序的，修改句补“任一指定确认人书面确认即视为该轮意见”，或按用户立场写成“须全部指定确认人一致确认”。

## 节点 3　成果、权属与素材（硬闸）

### 3.1 成果是设计稿，不是成片或投放

审查清单，缺一项则该字段不得写成已闭环：

1. 项目名称、媒介适配（户外、影视分镜、互联网物料尺寸）、语言版本、套数。
2. 交付格式：效果图与可编辑源文件（如 AI / PSD / AE 工程）分列。
3. 任务书作为附件，写明必须出现的许可证号或忠告语位置、禁止比较对象。
4. 禁止只写“全案设计”“视觉全案”而无任务书。

出现成片、喷绘实物或媒介投放为主给付：回到节点 1 负触发，不在本节点改成“设计+制作+发布”。

### 3.2 设计成果著作权必须落句（硬闸）

支持依据：著作权法（2020 修正）第十九条（未约定归受托人）；第十条（人身权与财产权分列，仅第五项至第十七项可许可或转让）；第二十六条（许可合同要素）；第二十七条（转让须书面，含权利种类、地域范围、价金）；第二十九条（未明确许可或转让的权利，另一方不得行使）。

| 文本写法 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 未写权属，或只写“知识产权按法律规定” | 必须改。向双方说明：未约定则著作权属于设计方；广告主要投放使用权，至少写明许可种类、专有或非专有、媒介、地域、期限 | 未约定即归广告主 |
| “买断”“全部知识产权归甲方”“永久独家买断全球权利” | 红线或必须改。删除买断二字；改成著作财产权转让或专有许可清单，并列作品名称、权利种类、媒介、地域、期限、转让/许可价金 | 买断已完成全部权属含人身权 |
| “全部知识产权（含人身权）转让” | 必须改：人身权不转让；可约定设计方在未发布或保密项目中不行使署名，或按广告主品牌规范署名 | 人身权已随合同转移 |
| 只约定交付源文件，未写许可或转让 | 必须改：源文件是有体交付，不是权属条款。可同时约定付清尾款后交付源文件，并另写许可/转让 | 交了源文件就已转让著作权 |
| 权属自签字之日起转移，尾款未付 | 必须改：著作财产权转让或专有许可自【尾款付清之日】起生效；未付清前广告主仅得为验收目的使用 | 未付款已取得可对外投放的专有权 |
| 广告主可转授权关联品牌或第三方 | 必须改：未明确的权利不得行使。转授权须书面列范围，或禁止转授权 | 已当然取得分许可权 |
| 设计方保留作品集展示 | 可接受可优化：排除未发布、保密或广告主书面反对的项目 | 展示权可以覆盖未发布稿 |

解释第十二条规定的“特定目的范围内使用”只作争点提示：即使著作权留在设计方，广告主通常可在委托创作的特定广告目的范围内使用。不得把该解释写成“广告主已取得专有权或转让”，也不得把旧条号“第十七条”写入 `L#`。

转让全部著作财产权应单独作价。设计费与转让价金混写且无法拆分：标必须改，价金用 `【待填】`。

### 3.3 素材与第三方权利

广告主提供的品牌手册、产品参数、商标、肖像：由广告主保证真实且已获许可。设计方外购字体、图库、音乐、插件：由设计方保证具备与本合同许可范围一致的商用授权，授权文件随终稿移交。

被诉侵权时，由提供该素材的一方负责抗辩和赔偿。设计方对自行选用元素负责。不得写成“一方被诉则另一方无条件连带且不得追偿”。

广告法第六十八条：未经同意使用他人名义或者形象的，依法承担民事责任。设计稿含模特、员工或用户肖像而未附许可：标必须改，不得写成“后期再补不影响签约”。

## 节点 4　程序、修改与验收

1. 任务书、竞品禁忌、必须出现的资质与忠告语作为附件，与合同同等效力。
2. 广告主可合理检查进度，但不得妨碍正常设计。发现任务书或指示不合理：设计方应及时通知（第 776 条）；未通知继续作业的，自行承担该部分返工。
3. 免费修改轮次和“一轮”定义必须写死：一轮=广告主在约定期限内一次汇总的书面意见。超出轮次或需求变更导致推倒重来的，工期顺延并按人天或按次加价，数字用 `【待填】`。
4. “修改至甲方满意为止”“不满意可不付尾款”：必须改。异议须指出与任务书不符的具体项，不得仅称“不满意”“不够高级”。
5. 异议期内未书面提出具体不符点的，可约定视为验收。天数用 `【待填】`，不编造法定期限。
6. **设计验收不等于可以发布**。修改句写明：验收仅确认设计稿符合任务书；法定审查类广告须另走发布前审查；未书面确认不得交付第三方发布。口头确认即发布：必须改。
7. 批准、招标、内部决议写成生效条件或双方义务期限，不写成已经完成。用户要求倒签或补假批准：整体停止。

## 节点 5　对价、源文件与定金

1. 设计费是否含摄影、字体授权、差旅，分列。付款节点对应提纲/提案、初稿、终稿+源文件。未给出的数字写 `【待填】`。提案未中选是否收费写死。
2. 源文件与效果图一并列入交付。未付清约定款项前可不交付完整工程文件，但不得对抗已付款部分为验收目的的使用权。付清后【待填】个工作日内交付完整可编辑源文件；逾期未交，广告主可解除并要求返还已付设计费中与未交付源文件对应的部分。
3. 第 783 条：未付报酬，设计方可留置成果或拒绝交付，当事人另有约定除外。电子源文件可以约定与尾款同时交换。排除留置须明示，并评估对设计方的风险。
4. 定金：必须使用“定金”二字才讨论罚则。“订金、保证金”无定金性质约定的，不得写成定金（解释第 67 条）。约定或推算超过主合同标的额百分之二十：超过部分不产生定金效力（第 586 条）。无核验引文不得把 20% 写成现行法结论。
5. 禁止编造单价、总价、轮次费用。
6. 退出：第 787 条定作人完成前可随时解除并赔偿损失。修改句按阶段列出已发生费用+约定比例的预期报酬，禁止只写“双方协商解除”。

## 节点 6　格式条款、强制规范与广告合规提示

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 格式条款

为重复使用而预先拟定、订立时未与对方协商。从事经营活动的一方不得仅以“这次没用过第二次”否认。依据示范文本或“设计制作”连用范本制作，不当然排除格式条款。

审查：免责、限责、排除对方权利、管辖/仲裁、单方解释权、无限改稿、买断空词等异常条款是否有足以引起注意的标识，以及是否按要求说明（第 496 条）。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在附件 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

提供方对其已尽提示或说明承担举证责任。

### 6.2 免责与强制规范

造成对方人身损害，或因故意、重大过失造成对方财产损失的免责条款无效（第 506 条）。设计方“对任何侵权或广告违法不承担任何责任”且无除外：必须改。

违反法律、行政法规强制性规定不一律无效。区分规范目的、是否仅行政管理、是否只规制履行行为（第 153 条；解释第 16 条）。禁止用已失效“效力性/管理性”口诀。禁发、集资、出借资格结构：不改写成有效履行。

### 6.3 广告合规提示（设计阶段，不是发布审查）

设计方应提示违法用语风险；广告主坚持使用的，应书面留痕。留痕**不能**免除设计方明知违法仍提供设计的行政责任（广告法第五十五条第三款：明知或应知虚假仍设计）。

设计阶段对照任务书检查，不代替发布审查整案：

- 医疗、药品、医疗器械广告不得利用代言人，不得写治愈率或有效率（广告法第十六条）。
- 除医疗、药品、医疗器械广告外，禁止其他广告涉及疾病治疗功能（第十七条）。
- 知识红旗“国家级、最高级、第一、治愈率”：作为必须改或删除项；第 9、28、34、46 条运行时核验后再写入 `L#`。
- 法定审查类广告须在设计稿预留忠告语位置。设计验收后另走审查，本任务不写“已可发布”。

报酬按曝光量、点击或刊例结算：现有依据支持滑向发布，回到节点 1。

## 节点 7　转包、违约、解除、留置与争议

1. 主要创意、主视觉须由签约设计方完成。未经广告主书面同意将主要设计工作交第三人：广告主可解除（第 772 条）。辅助描图、套版可分包，设计方对成果负责并书面披露。
2. 逾期交付按日计违约金；设计成果因设计方过错无法用于约定媒介的合法设计用途的，应重作或退还相应费用。广告主逾期反馈视为工期顺延。只有“依法承担违约责任”视为必须改。
3. 构成违约不等于当然解除。法定解除路径只点名催告或目的不能实现，不在本任务作出已解除结论。违约金不是必得金额；不在本任务做第 585 条精算。修改句避免“不得调整”或“按总价 30% 必得”。
4. 未发布创意双方均不得向竞争对手披露。设计方作品集展示受节点 3.2 限制。
5. 争议解决：出现仲裁条款，不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核，修改句改成单一仲裁机构或单一法院连结点。专属管辖可能：只标红旗，不选定唯一法院充作法律意见。框架建议的“设计履行地或被告住所地”只是备选连结点。
6. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。确认样稿的邮箱必须写入合同。

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

- `可接受可优化`：仍要给句子，不得只标绿。
