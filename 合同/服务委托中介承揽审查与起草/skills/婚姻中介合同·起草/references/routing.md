# 边界与路由

本技能只审查 **中介合同 / 婚姻中介合同** 的待签文本。中文展示名是「审查婚姻中介合同（中介合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 核心给付是求职、招聘、岗位推荐、猎头补人，或向劳动者收取押金、扣押证件 | `职业中介合同·审查`。不得删岗位条款后继续当婚介审 |
| 核心给付是房源报告、带看、房屋买卖或租赁佣金，验收看本约、网签或过户 | `房屋买卖_租赁中介合同·审查`。不得用婚介会员费覆盖房屋佣金 |
| 技术转让、专利许可撮合 | `技术转让中介合同·审查` |
| 授权以委托人名义签署文件或概括处理事务 | `一般委托合同·审查` |
| 以自己名义买入再转交，自担本约权利义务 | `行纪合同·审查` |
| 家政上门、陪护、计时劳务，无相亲媒介 | 引擎或对应服务原子 |
| 无文本、本类型条件已谈妥、要出己方稿 | 留本任务起草并自审 |
| 已签未争、只问约见排期、发票、退费催收 | 本套导航的履约步骤 |
| 已成争，或用户要婚托诈骗刑事立案策略 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

婚介正文里夹带一小段岗位推荐或房产咨询：专条交接对应原子；相亲推荐、核实、收费退费、个人信息条款可继续审。用户坚持本技能把职业中介或房屋中介整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
