# 审查方法（锁定 中介合同 / 婚姻中介合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制房屋中介的产调、成交款监管、网签过户或跳单倍数主路径，禁止复制职业中介的人力资源许可证、劳动者押金或保证期补人主路径。

定性校验：标题、核心给付与本类型一致才继续；明显是职业介绍、房屋成交中介、家政劳务、委托或行纪则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、必然结婚、对方必然接受或唯一必得退费金额。

`search_law` 返回已失效《合同法》及其居间章、担保法解释、《中介服务收费管理办法》、1993 年《消费者权益保护法》第 26 条旧义（当时是听取意见，不是格式条款）、已失效《婚姻法》《婚姻登记管理条例》、已失效《城市房地产中介服务管理规定》时记为噪声，不得写入 `L#`。消法格式条款须按 2013 修正文书名再核。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。职业中介、房屋居间或婚宴服务范本只证明是另一类型，不得当作本类型范本。未知权威的《婚姻介绍服务合同》和地区婚介示范文本只借服务项目、期限、费用、约见、信息保护、终止退款栏目。

知识库纠正（不回写双文件）：

- `基本面.md` “报酬通常与中介行为的实施或结果挂钩”：第 964 条未促成不得请求报酬；入会费不得当然写成已可请求全部报酬，除非能识别为已完成的可核验信息服务阶段或事先书面列明的必要费用。
- `基本面.md` “中介人仅承担形式审查，第三人恶意虚假且已尽合理审查则免责”：第 962 条针对故意隐瞒或提供虚假情况。形式审查免责不得对抗婚托、明知已婚仍推荐或中介人自己提供虚假资料。
- `框架.md` “委托人在服务完成前通常享有任意解除权”：第 966 条只是参照适用委托规定。不得写成委托人当然可无偿任意解除，且绕开介绍对象不再付费。解除后仍可能受第 965 条约束。
- `框架.md` “保密期限应约定为永久”：个保法第 17 条要求告知保存期限。合同终止后继续保密可以写；永久保存全部征婚档案不是法定义务，保存期限用 `【待填】`。
- `框架.md` “包成功往往构成虚假宣传，可能被认定无效”：保证结婚条款可能因违背公序良俗或虚假宣传而不可强制履行；不得把整个婚介合同当然写成无效。
- 涉外婚介：本次 MCP 未核到全国统一现行禁令全文。字段停止待核，不得把记忆中的“一律禁止涉外婚介”写入 `L#`。
- 预付式消费解释第 1 条列举零售、住宿、餐饮、健身等，未列婚介。不得把入会费当然适用该解释；若事实是预收款后多次或持续兑付相亲服务，可参照其格式条款无效规则讨论“排除解除或返还预付款”，并标明参照而非必然适用。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。标题写“会员服务”“高端猎婚”“情感顾问”的，先看对价是否绑相亲推荐或约见媒介：是则按本类型审，不是则切开。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 向单身委托人报告缔结婚姻机会，或提供相亲撮合、约见说合，对价是入会费、约见费或成功奖励 | 本类型 | 正触发 |
| 求职、招聘、岗位推荐、猎头补人，或向劳动者收押金、扣证件 | 职业中介 | 负触发 `职业中介合同·审查` |
| 房源、带看、房屋买卖或租赁佣金，验收看本约、网签或过户 | 房屋中介 | 负触发 `房屋买卖_租赁中介合同·审查` |
| 技术转让、专利许可撮合 | 技术转让中介 | 负触发 `技术转让中介合同·审查` |
| 授权以委托人名义签署文件或概括处理事务 | 一般委托 | 负触发 `一般委托合同·审查` |
| 以自己名义成交并自担本约权利义务 | 行纪 | 负触发 `行纪合同·审查` |
| 家政上门、陪护、计时劳务，无相亲媒介 | 劳务/服务 | 负触发引擎或对应服务原子 |

支持切开的规范（法律结论须运行时复核）：

- 第 961 条：中介是报告订立合同的机会或提供媒介，委托人支付报酬。婚介的“机会”是缔结婚姻或建立恋爱关系的媒介，不是房屋本约，也不是劳动合同。
- 第 919 条：委托是处理委托人事务。
- 第 951 条：行纪是以自己名义从事贸易活动。
- 《就业促进法》路径的职业中介许可、不得向劳动者收取押金：属于 `职业中介合同·审查`，本任务不审。

### 1.2 加载协议（硬闸）

本技能已锁定 **中介合同 / 婚姻中介合同**。只打开 `references/基本面.md` 与 `框架.md`。禁止读其他子目录，禁止为对照再开第二类。

### 1.3 婚介不是职业中介、也不是房屋中介（硬闸）

| 文本写法 | 本任务动作 | 修改句方向 |
| --- | --- | --- |
| 乙方按条件推荐单身对象、安排约见，甲方付会员费或约见费 | 正触发，留下本类型 | 首部写明“婚姻中介（居间），不是职业介绍或房屋中介” |
| 对价是岗位入职、年薪比例佣金、保证期补人 | 负触发职业中介 | 不按婚介改完 |
| 对价是房屋成交佣金、带看、网签 | 负触发房屋中介 | 不按婚介改完 |
| 夹带一条“也可介绍工作或看房”，主给付仍是相亲 | 正触发；夹带专条交接 | 分章或另签，婚介费不覆盖岗位或房产争议 |
| 乙方保证办理结婚登记或代领结婚证 | 必须改：删除代办登记；婚姻登记由双方自愿向登记机关申请 | 不得预收“办证成功费” |

修改句（正触发首部）：

「本合同为婚姻中介合同。乙方作为中介人，向甲方报告缔结婚姻的机会或提供相亲媒介服务；甲方支付本合同约定的服务费。本合同不构成职业介绍，不构成房屋买卖或租赁中介，也不构成对甲方或第三人办理结婚登记的代理。夹带的岗位咨询或房产咨询，不改变验收对象为书面推荐、见面确认和如实报告。」

最强反方：相对方主张已构成职业中介或房屋中介，从而主张适用人力资源许可或房屋佣金、跳单规则。修改句必须收回岗位入职验收和房屋本约佣金。用户坚持保留职业介绍或房屋成交主轴：负触发，不填本类型十节实体结论。

### 1.4 买卖婚姻 / 包办 / 婚托停笔（硬闸）

加载后或定性中出现：约定给付价金买人成婚；强制礼金作为中介成功条件；包办特定对象必须结婚；中介人雇佣他人冒充相亲对象并要求写成“演员配合属于服务内容”；要求把有配偶者包装成单身继续推荐。

动作：

1. 交付告知：禁止包办、买卖婚姻和借婚姻索取财物（第 1042 条）；结婚须双方完全自愿（第 1046 条）；违背公序良俗的民事法律行为无效（第 153 条第 2 款；解释第 17 条）。不得改写成可履行的买卖婚姻、包办或婚托结构。
2. 不写可履行的“服务演员”“假离婚再介绍”“出境买婚”路径。
3. 风险表只保留识别依据和删除/转出口径。
4. 用户坚持“改到能签且仍做这些事”：整体停止。

## 节点 2　主体、单身适格与经营范围

### 2.1 主体表

建表：签约名、履行名、付款名、发票名、授权签字人。名称不一致不自动合并。集团品牌店代签的，付款和发票主体必须一致。

口头“我们老板同意了”不得写成已授权。未成年人或限制民事行为能力人作为征婚委托人：红线，不启动可履行结构。

### 2.2 委托人单身与婚龄（硬闸）

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 未出示身份证、离婚证或丧偶证明，也无婚姻登记记录查询痕迹 | 字段停止；修改句要求作为附件 | 已确认单身，可以开始推荐 |
| 文本允许“分居未离婚”“有配偶但感情破裂”的委托人征婚 | 红线删除。现有依据不支持把有配偶者写成适格征婚委托人 | 可以先介绍，登记时再说 |
| 推荐对象或委托人未达男 22 周岁、女 20 周岁 | 红线。第 1047 条；登记条例不予登记 | 成长后补登记即可先撮合 |
| 只有口头自称未婚 | 不得写成已核实婚姻状况 | 口头已尽核验 |

修改句：

「甲方保证签署时处于无配偶状态（未婚、已办理离婚登记或丧偶），并在签署前向乙方出示居民身份证及婚姻状况证明原件，复印件作为附件。乙方应查验原件。甲方或拟推荐对象未达法定婚龄，或一方已有配偶的，乙方不得提供媒介服务，已收未履行部分费用应在【待填】日内退还。口头自称未婚不视为已核实。」

最强反方：中介主张“婚姻状况由委托人自己负责，机构只收材料复印件”。现有依据支持双方均应提交真实身份和婚姻状况；中介人仍负第 962 条如实报告义务。

### 2.3 中介人登记与婚介经营范围

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 无营业执照或经营范围不含婚姻介绍及同类表述 | 字段停止；修改句要求作为附件 | 可以合法展业 |
| 只有加盟品牌授权，无签约主体执照 | 必须改：签约主体与公章主体一致 | 品牌即可约束总部 |
| 文本保证已完成全部行政许可 | 执照不等于当然具备全部地方备案；地方规则字段停止 | 已完成全部许可故合同有效 |
| 无照仍要写成“不影响合同效力且可正常收费” | 不宣告当然无效（解释第 16 条）；停止“可以合法展业”；不得改成已具备许可 | 无照也可保证合法经营 |

修改句：

「本合同签署前，乙方应向甲方出示并作为附件：营业执照，经营范围含婚姻介绍或主管机关认可的同类表述。未核验前，不得主张已具备合法展业条件。缺少行政许可的行政后果由乙方自行承担，甲方有权中止付款并要求退还未履行部分费用；本条不构成对合同效力的终局认定。」

涉外或跨境猎婚：未核到全国统一现行禁令全文则该字段停止；修改句要求列明介绍对象国籍、见面地、是否涉及出境安排，并删除“保证在境外登记结婚”。不得把记忆中的国办通知写成已核验 `L#`。

## 节点 3　服务范围、核实义务与见面确认（硬闸）

### 3.1 服务须可核验

审查清单，缺一项则该字段不得写成已闭环：

1. 服务是“报告缔结机会”（提供人选信息）还是“提供媒介服务”（撮合、约见、说合），或两者并列。
2. 服务期限起止日。禁止终身包办、无期限续费绑定。
3. 推荐人数或约见次数上限，用 `【待填】`。
4. 自动终止：委托人已登记结婚，或达到约定推荐/约见次数。
5. 鉴于条款不写报酬金额，不写保证结婚。

禁止只写“提供高端情感管理服务”而无推荐、核实和约见标准。

### 3.2 核实是义务，不是权利

支持依据：第 962 条。框架正说：中介人应当对推荐对象的婚姻状况进行背调并出具书面证明。反说：不得推荐已婚或未达法定婚龄人员。

| 文本写法 | 动作 |
| --- | --- |
| “乙方有权核实，亦可不核实” | 必须改。核实是义务 |
| “约见后甲方未书面异议，视为全部信息准确” | 红线删除。保留异议权 |
| 中介保证第三人无疾病、无负债、无犯罪记录且无需出示核验材料 | 红线删除保证；改为交付已核验项目清单和未核验项目声明 |
| 故意隐瞒已婚、未离婚、重大疾病或提供婚托、假学历假房产 | 现有依据支持委托人拒付报酬并请求赔偿。修改句落成合同权利，不在本任务认定已经隐瞒 |

修改句：

「乙方负责对拟推荐对象的姓名、性别、出生年月、婚姻状况（初婚/离婚/丧偶）、职业及本合同约定范围内的收入或健康信息做核实，并在推荐前向甲方交付书面《对象信息核实单》。乙方不得推荐已婚、未办理离婚登记或未达法定婚龄的人员。核实是乙方义务，不得表述为“有权核实”。约见后甲方未提出异议，不视为信息准确，甲方仍有权在知悉或应当知悉虚假之日起【待填】日内提出书面异议。」

最强反方：中介主张只做形式审查、原件由第三人提供即已免责。现有依据不支持把“收过复印件”单独写成第 962 条已履行；现有依据也不支持把过失未发现一律写成故意虚假。修改句区分：故意隐瞒或提供虚假 → 免酬并赔偿；已列明未核验项目且无故意 → 不当然免酬，但不得再主张该未核验项“已保证真实”。

### 3.3 见面确认不是促成婚姻

每完成一次推荐或见面，由委托人签署《见面确认书》或《服务反馈单》。确认书只证明该次媒介已实施。不得写成已促成婚姻，也不得写成信息已核实。

修改句：

「乙方每次向甲方推荐对象或安排见面，应在当次结束后【待填】日内请甲方签署《见面确认书》。确认书仅证明该次推荐或见面已经发生，不视为甲方认可对象信息真实，不视为乙方已促成婚姻，也不构成成功奖励的付款条件。」

## 节点 4　禁止包成功与标的边界（硬闸）

婚姻关系本身不能作为交易标的。不得约定保证登记结婚作为付款的唯一绝对条件。

| 文本写法 | 动作 |
| --- | --- |
| “包结婚、包成功、一年内必须领证，否则只退一小部分”但仍收取高额成功奖且不退入会费 | 红线：删除保证结婚；成功奖仅在双方已自愿登记结婚后支付；未登记不得主张成功奖 |
| 强制礼金、彩礼额度作为中介成功条件，由中介代收 | 停笔或红线删除。借婚姻索取财物（第 1042 条） |
| 鉴于条款写“保证甲方当年结婚” | 必须改：鉴于只说明单身与寻求媒介的意愿 |
| 成功奖以“确定恋爱关系”“互加微信”为支付条件且金额接近全额服务费 | 必须改：成功奖条件须可核验且不得替代保证结婚；恋爱定义用双方书面确认，避免中介单方认定 |

修改句：

「乙方的给付是报告机会和媒介服务，不保证甲方与任何第三人登记结婚。任何“包成功、包结婚、包领证”的承诺均不构成本合同义务。成功奖励金仅在甲方与乙方推荐对象办理结婚登记后【待填】日内支付，金额人民币【待填】元；未办理结婚登记的，乙方不得请求成功奖励金。甲方已支付的入会费、约见费按第五节点结算，不因未结婚而当然全部没收。」

用户要求保留“必须结婚否则算甲方违约并没收全部费用”：整体停止。

## 节点 5　收费、退费与绕开付酬（硬闸）

支持依据：第 963、964、965 条；格式条款第 496、497 条。预收款未按约提供服务的退款，可核验《侵害消费者权益行为处罚办法》（2020修订）第 10 条。预付式消费解释第 1 条未列婚介：不得写成当然适用；多次持续兑付相亲服务的预收款，可参照讨论排除解除或返还预付款的条款。

### 5.1 费用分列

入会费或信息服务费、约见进度费、成功奖励金分列。差旅、场地等额外开支未书面约定的，中介人不得另行请求（与第 963 条第 3 款费用负担相呼应：促成后中介活动费用原则上由中介人负担，除非另有可识别约定）。先票后款可写为建议。禁止编造金额。

| 文本写法 | 动作 |
| --- | --- |
| 签约即收全额，含尚未发生的成功奖，且写“一经收取概不退还” | 红线。拆成阶段；删除概不退款 |
| 未约定服务期限或推荐次数，终身会员 | 必须改：期限和次数上限 |
| 未促成也收取“服务费”且无必要费用范围 | 必须改。未促成不得请求报酬；必要费用须列明项目与上限 |
| 入会费、约见费、成功奖混写 | 必须改：分列付款节点和退费公式 |
| 使用“定金”且超过标的额 20% | 超过部分不产生定金效力（第 586 条）。无核验引文不得把 20% 写成已核验结论 |
| “订金、保证金”无定金性质 | 不得写成定金 |

修改句：

「甲方应支付的费用分列：（1）信息服务费人民币【待填】元，于签署后【待填】日内支付，对应乙方在服务期内提供不少于【待填】名书面推荐；（2）约见费每次人民币【待填】元，于该次见面确认后支付；（3）成功奖励金人民币【待填】元，仅在甲方与乙方推荐对象办理结婚登记后支付。乙方未促成双方建立经书面确认的稳定交往、也未达到约定推荐次数的，不得请求成功奖励金，亦不得将信息服务费改称为已赚取的全部报酬。差旅、场地等额外开支以附件《必要费用清单》为限，未列入的，乙方不得另行请求。」

### 5.2 退费公式

禁止概不退款。按已完成推荐人数或已使用服务天数阶梯结算。中介人根本违约、提供虚假资料或婚托：已收费用应退，且不得请求报酬。委托人单方解除：可扣减已完成阶段对应费用和事先列明的必要费用，余额退还。

修改句：

「有下列情形之一的，乙方应在【待填】日内退还相应费用：一、因乙方未按约提供书面推荐或约见，按未履行部分退还信息服务费和预收约见费；二、因乙方故意隐瞒重要事实、提供虚假情况或安排他人假冒相亲对象，退还已收全部费用，且不得请求报酬；三、甲方在服务完成前书面解除本合同的，按已完成书面推荐人数和已发生且事先列明的必要费用结算，余额退还，不得约定概不退款。退款无约定或约定不明的，按有利于甲方的方式折算。」

最强反方：中介主张入会费是开户对价、一经入会即全部赚取；或主张第 964 条允许把全部预收写成必要费用。现有依据不支持把未列明范围的预收一律当成必要费用；现有依据也不支持用格式条款排除解除或返还预付款。

### 5.3 绕开介绍对象

第 965 条：委托人接受中介服务后，利用该交易机会或媒介绕开中介人直接订立合同的，应支付报酬。婚介场景的“订立合同”应限缩为与乙方推荐对象登记结婚，或双方书面确认建立以结婚为目的的稳定关系；不得扩写成“互加微信即付全额成功奖”，也不得写成婚姻无效。

修改句：

「甲方在接受乙方书面推荐或约见后，本人利用该介绍机会，绕开乙方与该推荐对象办理结婚登记，或与该对象书面确认建立以结婚为目的的稳定关系的，仍应按本合同支付尚未结清的成功奖励金或约定媒介报酬。甲方能够证明其在接受该项推荐前已通过亲友介绍或其他合法途径知悉同一对象的，不适用前款。本条不导致婚姻无效，也不使甲方丧失依法解除本合同并结算已履行部分的权利。」

终止后延展保护可约定合理期间 `【待填】` 日，须重复“利用乙方该项介绍”和自行获知例外。不得把未核验的“六个月到一年”写成法定期限。

## 节点 6　个人信息、格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 个人信息（硬闸）

支持依据：个保法第 17、28、29、30、57、69 条。

| 文本写法 | 动作 |
| --- | --- |
| “甲方资料由乙方自由使用、转让、共享，永久有效” | 红线。补目的、种类、方式、保存期限、接收方 |
| 采集病历、基因、生物识别或银行卡信息，无单独同意 | 必须改：单独同意，并告知必要性和影响 |
| 把婚姻状况、学历、房产一律写成敏感个人信息 | 不得扩写。第 28 条列举生物识别、宗教信仰、特定身份、医疗健康、金融账户、行踪轨迹及不满十四周岁未成年人信息 |
| 允许把征婚资料出售给培训、房产或贷款机构 | 红线删除 |
| 发生泄露不通知、不补救 | 必须改：立即补救并通知 |

修改句：

「乙方处理甲方个人信息，仅限于履行本合同项下的对象匹配、约见安排和档案管理。处理目的、方式、种类、保存期限【待填】和对外提供的接收方应在附件《个人信息告知书》中列明。处理医疗健康、生物识别或金融账户等信息的，须取得甲方单独同意，并告知必要性及对个人权益的影响。未经甲方书面同意，乙方不得向与婚介媒介无关的第三方出售、共享或公开甲方资料。合同终止后，乙方对尚未匿名化的个人信息继续承担保密义务；保存期限届满或甲方依法请求删除的，乙方应按告知书处理，但法律法规规定应留存的除外。」

框架“保密期限永久”：继续保密可以写；不得写成法定必须永久保存全部原始档案。

### 6.2 格式条款

为重复使用而预先拟定、订立时未与对方协商。婚介机构不得仅以“这次没用过第二次”否认。依据示范文本制作，不当然排除格式条款。

审查：概不退款、视为信息准确、包成功、单方解释权、管辖/仲裁等异常条款是否有足以引起注意的标识（第 496 条；解释第 10 条）。合同行政监督管理办法（2025修正）第 6、7 条：通知、声明、店堂告示视同格式条款；不得用格式条款免除修理、退货、退费或保密等责任。该办法不对民事效力作认定。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在收费表背面 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

提供方对其已尽提示或说明承担举证责任。第 497 条无效情形、第 498 条不利解释：只在核验后作为修改理由，不代替修改句。

消法第 26 条（2013修正，格式条款）本次条号检索易命中 1993 年同号旧义：运行时按 2013 修正文书名再核，不得把“听取消费者意见”写成现行第 26 条。

### 6.3 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的、是否仅行政管理、是否只规制履行行为（第 153 条；解释第 16、18 条）。禁止用已失效“效力性/管理性”口诀代替解释第 16 条。无照经营、地方备案缺失：主要是监管后果，不得单独写成民事合同当然无效，也不得写成已可合法展业。买卖婚姻、包办、婚托：不改写成有效履行。

## 节点 7　违约、解除与人身安全

1. 中介人逾期不推荐、提供虚假资料、安排婚托：可约定免酬、退费、解除并赔偿直接损失。只有“依法承担违约责任”视为必须改。
2. 委托人提供虚假单身或身份资料：中介人可中止服务并要求更正；因此产生的已发生必要费用可请求，但不得顺便没收全部预收成功奖。
3. 构成违约不等于当然解除。法定解除路径只点名催告或目的不能实现，不在本任务作出已解除结论。
4. 违约金不是必得金额；不在本任务做第 585 条精算。修改句避免“不得调整”或“按总价必得”。
5. 第 966 条参照委托：可约定通知解除，但须处理已完成阶段费用和第 965 条绕开付酬。不得写成“随时解除且全部费用不退”，也不得写成“随时解除且无需支付任何已发生费用”。
6. 人身与财产安全：约会过程中的人身、财产安全由参与人自行承担合理注意；该隔离不消灭中介人因婚托、故意虚假或泄露个人信息产生的责任。
7. 争议解决：出现仲裁条款，不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核。框架建议“原告所在地或合同履行地”只是便利性建议，不是法定唯一连结点。
8. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。

修改句（虚假资料责任）：

「乙方故意隐瞒与订立合同有关的重要事实或提供虚假情况，包括但不限于推荐对象的婚姻状况不实、安排他人假冒相亲对象，损害甲方利益的，不得请求支付报酬，并应在【待填】日内退还已收费用、赔偿甲方因此发生的直接损失。甲方故意提供虚假身份或虚假婚姻状况的，乙方有权中止服务；乙方仍应退还尚未对应已完成服务的费用。」
