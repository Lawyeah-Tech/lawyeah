# 委托技术服务·起草

## 任务目标

在单一立场下，只起草 **委托合同 / 技术服务合同** 的待签文本，按已谈妥条件出己方稿，输出可编辑草稿、未决项；出稿后必须用本类型硬闸自审，输出风险表和修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文名必须是「委托技术服务·起草」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、待签文本签前审查、履约交底、争议文书、有效性保证、把一般委托/技术咨询/委托开发/承揽/建设工程/技术类同名技术服务整案改完、把限制技术改良写成可履行结构。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **委任解决特定技术问题 ≠ 一般委托 ≠ 咨询 ≠ 开发 ≠ 承揽/工程 ≠ 技术类同名**：受托人用现有技术知识动手解决已特定化的技术问题。处理普通事务、费用由委托人预付 → 负触发 `一般委托合同·审查`。只出可行性论证/预测/评价 → 负触发 `委托技术咨询·审查` / `或` / `咨询服务合同·审查`。从无到有研发新成果 → 负触发 `委托技术开发合同·审查` / `只审委托合同目录下的委托技术开发。用户或材料按技术类合同进入《技术开发合同》→` / `的method。`。常规加工修理测绘检验 → 负触发 `加工合同·审查` / `修理合同·审查` / `测试测绘合同·审查` / `检验鉴定合同·审查`。勘察设计施工 → 负触发 `工地建筑活动承包资质竣工验收→`。用户目标是技术类合同货架、要与开发/转让/许可或狭义服务/培训/中介一并扫描 → 负触发 `或` / `狭义技术服务培训中介→` / `指定学员做特定项目专业技术训练` / `技术类合同项下技术中介本约→`。修改句须写明“解决特定技术问题”，收回“研发”“转让费”“随时任意解除”。
2. **费用负担反转**：正常开展工作所需费用约定不明时由受托人负担，不得按一般委托写成委托人必须预付差旅办公费。第三方检测、特种设备租赁等非常规费用必须另约。
3. **委托人配合与报酬不得追回**：委托人提供工作条件、完成配合、接受成果并付酬。因不配合影响进度质量，或不接受、逾期接受工作成果的，已付报酬不得追回，未付应当支付。不得把“未达商业利润”写成可拒付。
4. **受托人完成、解决、保证质量并传授知识**：特定技术问题与技术指标必须写到可验收。未按约完成服务工作的，免收报酬等违约责任须可执行。须有传授解决该问题所需知识的安排。
5. **新技术成果默认归属必须书面改写**：无约定时，受托人利用委托人资料和条件完成的新技术成果归受托人；委托人利用受托人工作成果完成的新技术成果归委托人。高价值项目须排除或改写默认，不得沉默放行。
6. **停笔结构**：非法垄断技术或侵害他人技术成果；安评/环监/特种设备检测等未见许可仍要进场；名为技术服务实为借贷或套取资金；跨境重要数据未评估即出境；挂靠、违法分包、名为服务实为劳务派遣；倒签或补假资质。只告知，不改成可履行结构。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签技术服务或委托技术服务正文，尚未签署，尚未成争，核心给付是委托人委任受托人以其技术知识解决特定技术问题，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 处理普通事务、费用由委托人预付、双方可随时任意解除，而无特定技术问题 → `一般委托合同·审查`；不得把第 921、933 条当本类型默认主路径；
- 只提供可行性论证、技术预测、专题调查或分析评价，不保证动手解决问题 → `委托技术咨询·审查`；技术类货架下的咨询 → `或`；普通经营咨询 → `咨询服务合同·审查`；
- 从无到有研发新技术、新产品、新工艺 → `委托技术开发合同·审查`；技术类委托开发/技术开发 → `的method。` / `只审委托合同目录下的委托技术开发。用户或材料按技术类合同进入《技术开发合同》→`；
- 常规加工、定作、修理、测试、测绘、检验 → `加工合同·审查` / `定作合同·审查` / `修理合同·审查` / `测试测绘合同·审查` / `检验鉴定合同·审查`；
- 房屋建筑、土木工程的勘察、设计、施工 → `工地建筑活动承包资质竣工验收→`；
- 用户明确按技术类合同专章、与开发/转让/许可并列审查“技术服务合同” → `或`；狭义技术服务、培训、中介 → `狭义技术服务培训中介→` / `指定学员做特定项目专业技术训练` / `技术类合同项下技术中介本约→`；
- 驻场人员由甲方指挥、发工资社保，核心是人员租赁 → `用人单位。按人头派驻接受用工单位考勤奖惩中介发薪或自己与劳动者签劳动合同→`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问进场日、验收日、付款留痕 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁 → `或对应专项领域。` 或对应专项领域。

无证特种作业进场、通谋虚假服务费、倒签规避许可、未评估安排重要数据出境：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（委托人侧或受托人侧择一）；相对方；全文及技术服务明细/工作条件清单/验收指标版本；要解决的特定技术问题及量化指标；费用是包干还是实报、差旅与第三方检测谁负担；成果归属有无改写默认；委托人配合事项；是否驻场及指挥权；受托人是否需安评/环监/特种设备等许可；是否跨境传输技术资料；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

## 起草模式

本原子只承担本类型起草。待签评改转 `委托技术服务·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `委托技术服务·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`，不编造。

### 起草必写

- 核心给付是受托人用现有技术知识动手解决已特定化的技术问题；写明问题、指标、地点、期限，并有传授解决该问题所需知识的安排。
- 正常开展工作所需费用约定不明时由受托人负担；第三方检测、特种设备租赁等非常规费用必须另约。
- 委托人提供工作条件、完成配合、接受成果并付酬；因不配合影响进度质量，或不接受、逾期接受工作成果的，已付报酬不得追回，未付应当支付。
- 未按约完成服务工作的，免收报酬等违约责任须可执行。
- 无约定时，受托人利用委托人资料和条件完成的新技术成果归受托人；委托人利用受托人工作成果完成的新技术成果归委托人；要改归对方必须书面改写。
- 驻场指挥权归受托人；工作记录单与阶段性报告可作付款依据。

### 附件必附

- 技术服务明细、工作条件清单、验收指标。
- 安评/环监/特种设备等许可痕迹（进场所需则附）。

### 禁止出现

- 把“研发”“转让费”“随时任意解除”写成主给付；不得把第 921、933 条当本类型默认主路径。
- 把“未达商业利润”写成可拒付。
- 非法垄断技术或侵害他人技术成果；限制技术改良。
- 安评/环监/特种设备检测等未见许可仍要进场；名为技术服务实为借贷或套取资金；跨境重要数据未评估即出境；挂靠、名为服务实为劳务派遣；倒签或补假资质。
- 只出可行性论证、从无到有研发新成果、常规加工修理测绘检验或施工本约：负触发对应原子，不在本任务出稿。

出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 留本任务起草并自审；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有本类型文本；本任务只起草，评改待签文本转配对 ·审查 原子。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。一般委托、咨询、开发、承揽、工程、技术类同名负触发。

### 2. 主体与许可

签约名、履行名、付款名、发票名分列。安评、环监、特种设备检测未见许可：字段停止。无证仍要进场：停笔。

### 3. 特定技术问题与指标

问题、指标、地点、期限、传授知识必须可执行。不得只写“有关技术服务”。

### 4. 费用负担

包干或成本加报酬写清。正常费用默认受托人负担。非常规费用另约。

### 5. 配合、验收与报酬不得追回

工作条件清单、逾期接受、技术指标验收。利润目标不得单独作为拒付条件。

### 6. 成果归属、格式条款与强制规范

885 默认必须点名；要归委托人须书面改写。非法垄断技术不得改成可履行。无核验引文则法律结论字段停止。

### 7. 驻场指挥、保密与终止善后

指挥权归受托人。工作记录单与阶段性报告可作付款依据。认定登记不写成已经完成或生效条件。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把无证特种作业改成可履行进场、把限制技术改良或阻碍他源技术写成可履行、把高额服务费做成融资通道、未评估安排重要数据出境。
- `字段停止`：法域、动态规则、许可文号、数据是否构成重要数据、认定登记窗口、非常规费用金额未核验。
- `目标停止`：主目标已变为评改待签文本、履约交底、争议文书，或已锁他类（含技术类同名）。

生存级预付款或个人无限连带且用户拒绝升级：停止“可以签署”建议。
