# 最终用户协议·起草

## 任务目标

在单一立场下，只起草 **互联网相关合同 / 最终用户协议** 的待签文本，按已谈妥条件出己方稿，输出可编辑草稿、未决项；出稿后必须用本类型硬闸自审，输出风险表和修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查最终用户协议（互联网相关合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、待签文本签前审查、履约交底、争议文书、有效性保证、把隐私政策或软件许可本约改完、把点击勾选写成已尽提示说明、把封号写成可没收全部已付对价。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **格式条款提示（点击即成）**：本约是面向不特定终端用户、预先拟定、订立时未协商的附合合同。生效须有主动确认（勾选、点击同意）。免除或减轻提供方责任、限制用户权利、增加用户义务、管辖／仲裁、自动续费、单方变更等重大利害条款，须以加粗、下划线、单独告知或弹窗等通常足以引起注意的方式提示，并按要求说明。仅设置勾选或弹窗，不得写成已尽提示或说明义务。浏览即同意（Browse-wrap）不得写成重大利害条款已经成立。
2. **账号与虚拟财产**：账号所有权与使用权分写；注册、警告、限权、封号、申诉、注销必须成闭环。注销不得设置不合理条件。封号时账户余额、虚拟币、虚拟道具、未消耗会员期须有清算或救济规则，不得写成“封号即全部没收且不得投诉、起诉或要求返还”。不得写成虚拟财产一律不受法律保护。
3. **与隐私政策切开**：本约只审软件／服务许可、账号规则、虚拟财产、平台责任、内容规范。个人信息处理规则、单独同意、敏感信息、出境、SDK 清单、儿童个人信息专则 → `隐私政策·审查`。用户协议里夹几句“我们会保护您的隐私”：标必须改，要求隐私政策独立成文并可单独阅读同意，不在本任务代写处理规则。
4. **与软件许可切开**：本约是面向终端用户的综合性格式协议（许可＋持续服务＋账号，常含虚拟财产）。主给付是席位／拷贝数／安装台数／并发／CPU、集团统采法人名单、禁止再分发的协商型自用许可 → `的method，禁止把本约改成席位计量或出货提成表。`。主给付是 OEM、预装、转售、向下游再授权 → `主给付是OEM预装转售向下游再授权→`。主给付是软件著作权过户或软著登记变更 → `主给付是软件著作权过户或软著登记变更→`。禁止打开或复制 `的method，禁止把本约改成席位计量或出货提成表。` 的 method，禁止把本约改成席位计量或出货提成表。
5. **最终解释权与概括免责禁止**：删除“本平台享有最终解释权／单方解释权”。删除“对任何损失概不负责”。人身伤害、故意或重大过失致损不得免责。平台依法应承担的责任不得一概转给入驻商或用户。
6. **平台定性、通知删除与未成年人**：交易撮合平台须显著区分自营与信息中介／技术服务，并保留法定核验、安保和通知删除义务。提供信息存储空间的，须写通知—转送—必要措施—反通知路径。面向未成年人的，须有监护人同意、青少年模式和与行为能力相符的消费限制；不得把监护人同意写成已取得儿童个人信息单独同意。
7. **单方变更与自动续费**：电商平台修改服务协议，修改内容至少在实施前七日公示，不接受的相对方应能退出并按修改前规则清理。自动续费须在接受服务前和续费日前以显著方式提醒，并提供显著、简便、随时取消或变更的选项。知识稿“提前五日”未核验为法定日数，不得写入已核验结论。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签《用户协议》《注册协议》《最终用户许可协议》或同等点击即成文本，尚未签署，尚未成争，核心给付是向不特定终端用户提供软件运行／网络服务／账号体系（可含虚拟财产），用户问能否上线或签署、哪里必须改、怎么回给产品／法务／相对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主文是独立《隐私政策》《个人信息处理规则》《儿童个人信息保护规则》 → `隐私政策·审查`；
- 主给付是协商型软件自用许可：席位、拷贝、安装环境、禁止再分发，无面向公众的点击账号体系 → `的method，禁止把本约改成席位计量或出货提成表。`；
- 主给付是分发、预装、OEM、转售或向下游再授权 → `主给付是OEM预装转售向下游再授权→`；
- 主给付是软件著作权权属转移或软著登记变更 → `主给付是软件著作权过户或软著登记变更→`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；C 端大众起草商品只分流，不回改；
- 已签只问上线日、续费日、封号执行日 → 本套导航的履约步骤；
- 已催告、投诉群诉、索赔、诉讼、仲裁或监管立案 → `或对应专项领域。` 或数据／知产／消费争议专项。

把违法内容分发、赌博、未获许可的网游／视听经营改成可上线结构：只出告知，不改写成可履行路径。用户坚持则整体停止。

## 建立审查坐标

确认：使用者与授权；单方立场（平台／权利人侧或用户侧择一）；相对方；全文及点击页／勾选截图／隐私政策链接／会员规则／虚拟财产规则版本；是面向公众的点击协议还是协商许可；是否夹带独立隐私政策正文；是否有账号、虚拟财产、自动续费、单方变更、最终解释权、概括免责；平台是自营还是撮合；是否面向未成年人；敏感行业许可是否被文本提及；不可接受事项；法域与拟上线或签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的费用、期限、限额用 `【待填】`，不编造。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、1993 年未修正《消费者权益保护法》第二十六条旧义、2010 年《网络商品交易及有关服务行为管理暂行办法》、2014 年《网络交易管理办法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典第四百九十六条、第四百九十七条、第五百零六条、第一百二十七条，合同编通则解释第十条，合同行政监督管理办法（2025 修正）第六至八条，网络交易监督管理办法（2025 修正）第十八、二十一条，网络消费司法解释（一）第一条，电子商务法第二十四、三十二至三十四、四十二条，网络数据安全管理条例第二十三、二十四条，未成年人网络保护条例第四十四条；`search_practiced` 只补审查反例；`search_template` 只借栏目结构。不虚构案件系统。

`search_law` 对上述法律结论为 required 级：不可用时不拒绝执行，只停止效力字段。返回已失效《合同法》及其解释、1993 年消保法第二十六条旧义、2010／2014 年已失效网交规章时记为噪声，不得写入 `L#`。不得把软件自用许可的席位／备份口径或隐私政策的单独同意清单套到本类型。


## 起草模式

本原子只承担本类型起草。待签评改转 `最终用户协议·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `最终用户协议·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。下文「起草必写 / 附件必附 / 禁止出现」即本类型硬闸的落稿口径。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 生效须有主动确认（勾选、点击同意）。免除或减轻提供方责任、限制用户权利、增加用户义务、管辖／仲裁、自动续费、单方变更等重大利害条款，须以加粗、下划线、单独告知或弹窗等通常足以引起注意的方式提示，并按要求说明。
- 账号所有权与使用权分写；注册、警告、限权、封号、申诉、注销必须成闭环。注销不得设置不合理条件。封号时账户余额、虚拟币、虚拟道具、未消耗会员期须有清算或救济规则。
- 隐私政策独立成文并可单独阅读同意。本约不代写处理规则。
- 交易撮合平台须显著区分自营与信息中介／技术服务，并保留法定核验、安保和通知删除义务。提供信息存储空间的，须写通知—转送—必要措施—反通知路径。
- 面向未成年人：监护人同意、青少年模式和与行为能力相符的消费限制。
- 电商平台修改服务协议，修改内容至少在实施前七日公示，不接受的相对方应能退出并按修改前规则清理。自动续费须在接受服务前和续费日前以显著方式提醒，并提供显著、简便、随时取消或变更的选项。

### 附件必附

- 点击页／勾选交互与重大利害条款单独提示安排。
- 独立隐私政策链接（不在本任务代写处理规则）。

### 禁止出现

- 仅设置勾选或弹窗即写成已尽提示或说明义务。Browse-wrap 写成重大利害条款已经成立。
- 封号即全部没收且不得投诉、起诉或要求返还。虚拟财产一律不受法律保护。
- “本平台享有最终解释权／单方解释权”；“对任何损失概不负责”。人身伤害、故意或重大过失致损免责。
- 把监护人同意写成已取得儿童个人信息单独同意。
- 知识稿“提前五日”写成法定续费提醒日数。
- 把违法内容分发、赌博、未获许可的网游／视听经营改成可上线。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 留本任务起草并自审；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有最终用户协议；本任务只起草，评改待签文本转配对 ·审查 原子。

### 1. 类型锁死与邻类切开

标题、核心给付与对价方式一致才继续。隐私政策、软件自用／分发许可、软件著作权转让负触发。

### 2. 主体、运营者公示与权源

运营主体全称、联系方式；软著或分发权源；自营与撮合分开。

### 3. 点击生效与格式条款提示

Click-wrap；重大利害条款单独显著提示；勾选不等于已说明。

### 4. 账号、注销与虚拟财产

权属／使用权；封号程序；注销无不合理门槛；虚拟财产清算。

### 5. 许可范围、UGC 与平台责任

非独占、不可转让、可撤销的使用权；UGC 不得强制永久不可撤销无偿全球再许可；通知删除。

### 6. 免责、最终解释权、变更与自动续费

删除最终解释权与概括免责；变更公示；续费显著提醒并可取消。

### 7. 未成年人、行业许可与强制规范

监护人同意与消费限制；版号／视听许可只告知不编造。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面或点击文本仍要实体意见；用户坚持倒签上线日、保证协议必然有效、把隐私政策或软件许可整案改完、把封号没收且剥夺救济改成可履行、把违法内容或无许可经营改成可上线。
- `字段停止`：法域、动态规则、行业许可、虚拟财产性质、续费扣款通道、平台自营／入驻边界未核验。
- `目标停止`：主目标已变为评改待签文本、履约交底、争议文书，或已锁他类。
