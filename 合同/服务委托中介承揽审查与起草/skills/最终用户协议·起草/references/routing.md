# 边界与路由

本技能只审查 **互联网相关合同 / 最终用户协议** 的待签、面向终端用户的点击即成用户协议或 EULA。中文展示名是「审查最终用户协议（互联网相关合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 独立隐私政策、个人信息处理规则、儿童个人信息保护规则、单独同意、出境、SDK 清单 | `隐私政策·审查` |
| 协商型软件自用许可：席位、拷贝数、安装台数、并发、CPU、集团法人名单、禁止再分发，无公众点击账号 | `的method，禁止把本约改成席位计量或出货提成表。` |
| OEM、预装、转售、向下游再授权、按台计提 | `主给付是OEM预装转售向下游再授权→` |
| 软件著作权让与或软著登记变更 | `主给付是软件著作权过户或软著登记变更→` |
| 用户协议夹带隐私专章或链接 | 本约继续审许可／账号／服务；隐私部分交接 `隐私政策·审查`，不代写处理规则 |
| 标题 EULA、正文实为席位自用许可 | 负触发 `的method，禁止把本约改成席位计量或出货提成表。`，不删席位句后硬套 |
| 无文本、本类型条件已谈妥、要出己方稿 | 留本任务起草并自审 |
| C 端网站协议与隐私政策起草商品 | 只分流，不回改 |
| 已签未争、只问上线、续费、封号执行节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或对应专项领域。` 或对应专项领域 |
| 群诉、监管约谈立案、个人信息或知产侵权已立案 | 数据／消费／知产或争议专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

用户协议正文里夹带一小段隐私条款或企业席位表：专章交接对应原子或分条改写；点击即成的许可／账号／虚拟财产条款可继续审。用户坚持本技能把隐私政策或软件许可整案改完：`目标停止`。

禁止打开或复制 `的method，禁止把本约改成席位计量或出货提成表。`、`隐私政策·审查` 的 method。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
