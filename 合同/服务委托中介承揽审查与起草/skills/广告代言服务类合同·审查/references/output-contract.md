# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的签约金、拍摄天数、媒介、期限；把 1994 年《广告法》旧条或已失效《合同法》写入结论；把“无需使用即可推荐”写成可放行；把“对消费者免责”写成已闭合；把永久买断人格权写成有效许可；把禁止代言品类改成可履行代言；把广告发布/制作/代理/劳动当成已完成的本类型审查。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查广告代言服务类合同（服务合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回 1994 年《广告法》旧条、已失效《合同法》或其解释、已失效《广告管理暂行条例》《广告审查标准（试行）》时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `服务合同`，子级 `广告代言服务类合同`。定性理由、易混切开结果（广告发布、制作、设计、代理、互联网投放、单纯肖像许可、劳动/劳务、演绎经纪）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、授权与文本版本

主体表：签约名、履行名、付款名、发票名、艺人本人、经纪公司、授权签字人、监护人。资格表：经纪授权原件、未成年人年龄、三年禁代言处罚痕迹、商品是否禁止代言。版本表：正文、产品清单、许可要素表、经纪授权、样品签收、广告稿、聊天确认；冲突并列。未核经纪授权或艺人未签：该许可能力字段停止。

## 5. 真实使用、肖像许可与连带追偿

核心给付是否以自己名义或形象作推荐证明；是否已使用或安排体验并留存证据；许可要素是否封闭；是否永久买断或无限转授权；成片/推荐用语确认权；到期下架与库存消化期；广告主保证与审核权；追偿是否只在已尽审核且真实使用后成立。缺口标 `G#`。不输出刊播排期或劳动工时主路径。

## 6. 格式条款与强制规范

是否构成格式条款；永久买断、任意转授权、对消费者免责、无需使用等异常条款是否加黑提示。强制规范只按第 153 条和解释第 16 条区分，不用失效口诀。禁止代言品类、未使用即推荐、阴阳合同只保留识别与停笔。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把框架里的实务天数写成法定期限。

## 9. 谈判与签署提醒

谈判顺序：先红线（类型错位、未使用即推荐、禁止代言品类、艺人未签、永久买断、对消费者免责、阴阳合同），再必须改（许可要素表、真实使用记录、审核追偿、确认权、到期下架、定金 20%），最后可优化。签署提醒：艺人亲笔或可靠电子签 + 经纪盖章；未成年人加监护人签署页；经纪授权、产品清单、许可要素表、样品签收单、广告稿入附件。不指导倒签或补假授权。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书或效力保证，也不是广告发布、广告制作、广告代理或劳动合同审查。
