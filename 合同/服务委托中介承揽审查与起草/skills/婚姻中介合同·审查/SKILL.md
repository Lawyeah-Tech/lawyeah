# 婚姻中介合同·审查

## 任务目标

在单一立场下，只审查 **中介合同 / 婚姻中介合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查婚姻中介合同（中介合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类合同审查；从零起草；履约交底；争议文书；有效性保证；把职业介绍、房屋成交中介、家政劳务、保证结婚或买卖婚姻改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **核心给付是婚介机会报告或媒介服务**：中介人向单身委托人报告缔结婚姻的机会，或提供相亲撮合、约见说合。验收对象是书面推荐、见面确认和如实报告，不是保证登记结婚，不是岗位入职，也不是房屋成交。求职招聘、人力资源许可、向劳动者收押金 → 负触发 `职业中介合同·审查`。房源带看、网签过户、佣金绑房屋本约 → 负触发 `房屋买卖_租赁中介合同·审查`。家政上门劳务 → 负触发引擎或对应服务原子。夹带岗位介绍或房产带看的，分章或另签，不得用婚介会员费覆盖劳动中介或房屋佣金争议。
2. **委托人单身适格 + 中介人婚介经营**：委托人须完全民事行为能力，且处于未婚、离异或丧偶的无配偶状态；未达法定婚龄不得作为征婚对象。中介人应是依法登记的企业、非法人组织或个体工商户，经营范围含婚姻介绍或同类表述。无照经营不当然导致民事合同无效，但不得写成“可以合法展业”。涉外婚介限制本次未核到全国统一现行禁令全文：字段停止待核，不得把记忆中的“一律禁止涉外婚介”写成已核验结论，也不得把跨境猎婚改成可履行保证出境结婚结构。
3. **婚姻本身不是交易标的**：禁止包办、买卖婚姻和借婚姻索取财物。不得约定“保证结婚”作为付款的唯一绝对条件，不得写强制礼金、买人成婚或包成功。包成功条款按虚假宣传或违背公序良俗处理：删除保证，不把整个婚介合同当然写成无效。
4. **如实报告与虚假资料**：中介人须如实报告第三人姓名、性别、出生年月、婚姻状况、职业及约定范围内的收入或健康信息。核实是义务，不得写成“有权核实”。故意隐瞒已婚、未离婚、未达婚龄、重大疾病或提供婚托、假学历假房产的，不得请求支付报酬并应赔偿。禁止“约见后未异议即视为信息准确”。
5. **婚介收费与退费必须闭环**：分列入会费或信息服务费、约见进度费、成功奖励金；设定服务期限和推荐次数上限，禁止终身包办。未促成不得请求报酬，但可请求事先书面列明的必要费用。禁止“概不退款”“未约见也收全额成功奖”。委托人解除后仍可能受绕开介绍对象付酬约束，但不得写成无偿任意解除或跳开即婚姻无效。
6. **个人信息采集、使用与保密**：写明采集种类、使用范围、存储地点、保存期限和对外提供条件。医疗健康、生物识别、金融账户等敏感信息须单独同意，并告知必要性和影响。婚姻状况、学历、财产不当然写成敏感个人信息。禁止转卖征婚资料。保密义务可约定合同终止后继续；保存期限用 `【待填】`，不得把“永久保存全部档案”写成法定义务。
7. **书面核实与服务确认**：签约前查验委托人身份和婚姻状况原件。每次推荐或见面由委托人签署《见面确认书》或《服务反馈单》。第三人身份证明复印件入档备查。见面确认只证明该次媒介已实施，不视为信息已核实，也不视为已促成婚姻。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签婚姻中介、婚介服务或居间（婚姻类）正文，尚未签署，尚未成争，核心给付是报告缔结婚姻机会或提供相亲媒介，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 核心是求职、招聘、岗位推荐、猎头补人或向劳动者收押金 → `职业中介合同·审查`；
- 核心是房源、带看、房屋买卖或租赁佣金、网签过户协助 → `房屋买卖_租赁中介合同·审查`；
- 核心是技术转让或专利许可撮合 → `技术转让中介合同·审查`；
- 授权以委托人名义对外签署或概括处理事务 → `一般委托合同·审查`；
- 以自己名义成交、自担本约权利义务 → `行纪合同·审查`；
- 家政上门、陪护或计时劳务，无相亲媒介 → 引擎或对应服务原子；
- 无文本、本类型条件已谈妥、要出己方稿 → `婚姻中介合同·起草`；
- 已签只问约见安排、发票或退费催收日 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁，或用户要婚托诈骗刑事策略 → `或对应专项领域。` 或对应专项领域。

买卖婚姻、包办婚姻、婚托伪装成可履行条款、要求把无配偶改成“已婚也可安排”：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（委托人侧或婚介机构侧择一）；相对方；全文及附件/收费表/诚信承诺书/保密协议/见面确认书版本；服务是线下门店、线上相亲还是高端猎婚；是否夹带涉外或跨境介绍；委托人婚姻状况痕迹；中介人经营范围痕迹；收费是入会费、约见费还是成功奖；个人信息种类；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的费用、次数、期限用 `【待填】`，不编造。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`基本面.md` 中“报酬与中介行为实施或结果挂钩”“中介人仅承担形式审查”不得写成未促成也可收全额报酬，或故意虚假也可免责。`框架.md` 中“委托人通常享有任意解除权”“保密期限永久”不得写成无偿任意解除，或法定必须永久保存全部档案。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `婚姻中介合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有婚介文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。职业中介、房屋中介、家政劳务、委托、行纪负触发。

### 2. 主体与单身、经营范围

签约名、履行名、付款名、发票名分列。委托人婚姻状况未核：字段停止。无经营范围痕迹：不得写成可以合法展业。

### 3. 服务范围、核实与见面确认

报告机会或媒介服务分列。核实义务入正文。推荐和见面须书面确认。

### 4. 禁止包成功与买卖婚姻

保证结婚、强制礼金、买人成婚：红线或停笔。

### 5. 收费、退费与绕开付酬

入会费、约见费、成功奖分列。概不退款红线。未促成不得请求报酬。

### 6. 个人信息、格式条款与强制规范

采集范围、单独同意、对外提供。无核验引文则法律结论字段停止。

### 7. 违约、解除与人身安全隔离

虚假资料免酬并赔偿。约会人身财产由个人负责，不消灭中介人因婚托或故意虚假产生的责任。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把买卖婚姻/包办/婚托、保证结婚或“已婚也可安排”改成可履行结构。
- `字段停止`：法域、动态规则、经营范围、委托人婚姻状况、涉外婚介地方限制、保存期限法定上限未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
