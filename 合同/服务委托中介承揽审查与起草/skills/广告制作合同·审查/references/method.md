# 审查方法（锁定 服务合同 / 广告制作合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制广告设计改稿轮次/提案中选/源文件权属主路径，禁止复制广告发布 CPT/CPM、监测口径或刊播证明主路径。

定性校验：标题、核心给付与本类型一致才继续；创意设计、媒介发布、代理排期、代言许可、纯印刷、非广告定作、建设工程施工明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受或唯一必得档期赔偿。

`search_law` 返回已失效《合同法》承揽章（第 251–268 条）及其解释、已失效《加工承揽合同条例》、已失效《经济合同法》、已失效《互联网广告管理暂行办法》、已失效担保法解释时记为噪声，不得写入 `L#`。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。未知权威的《广告制作合同》、广告牌定做或电视广告片制作范本只借栏目；正文若引用《合同法》记噪声。设计合同或发布合同范本只证明是另一类型。

知识库纠正（不回写双文件）：

- `基本面.md` “素材不足应通知补正”：对应第 775 条材料检验通知和第 776 条图纸/技术要求不合理通知，不得引用失效《加工承揽合同条例》。
- `框架.md` “逾期不审或不提书面异议视为合格”：只是约定拟制验收，不是法定自动合格。修改句可保留拟制，但须给合理异议期和书面不符点要求。
- `框架.md` “档期损失”：受第 584 条可预见限制，并须有媒介预订凭证；广告主审片延误导致错过档期的，不得转嫁制作方。
- `基本面.md` “任意解除须赔已发生成本及约定损失”：第 787 条只写“赔偿损失”。可约定已发生场地/演员/材料成本和约定比例，不得把履行利益写成必然必得，也不得写成无偿随时解除。
- 著作权：委托作品未约定归受托人（著作权法现行第 19 条）。视听作品中电影/电视剧由制作者享有，其他视听作品无约定由制作者享有（现行第 17 条）。不得把司法解释旧条号“第 17 条委托作品”写成现行法。广告主付款不等于当然取得全部著作财产权。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。标题写“广告全案”“影视制作服务”的，先看验收对象是成片/物料还是设计稿或曝光。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 按确认脚本/设计终稿/素材包加工，交付成片、母带、喷绘、灯箱或展示道具，按件计酬 | 本类型 | 正触发 |
| 出创意、设计稿、改稿轮次、提案中选，验收对象是作品方案 | 广告设计 | 负触发 `广告设计合同·审查` |
| 上刊、播出、曝光、CPT/CPM、监测报告 | 广告发布 | 负触发 `广告发布合同·审查` |
| 媒介排期、代理买档期、差价或佣金 | 广告代理 | 负触发 `广告代理合同·审查` |
| 代言人许可、拍摄次数与肖像范围为主给付 | 广告代言 | 负触发 `广告代言服务类合同·审查` |
| 信息流、互联网投放买量 | 互联网广告 | 负触发 `互联网广告类合同·审查` |
| 设计+制作+发布无法拆开的全案 | 广义广告或引擎 | 负触发 `广告合同（广义）·审查` 或 本套导航的类型切开步骤 |
| 只印刷图文，无广告成品加工或确认脚本 | 印刷承揽 | 负触发 `印刷合同·审查` |
| 非广告用途的定作物 | 定作承揽 | 负触发 `定作合同·审查` |
| 户外构筑物按施工图、强制标准和施工资质整案发包 | 建设工程施工 | 负触发 `工地建筑活动承包资质竣工验收→` |
| 委托他人设计而无制作成品 | 委托设计 | 负触发 `委托他人设计的服务合同·审查` |
| 文学艺术委托创作，不交付广告成品 | 委托创作 | 负触发 `委托创作·审查` |

支持切开的规范（法律结论须运行时复核）：

- 第 770、780 条：承揽是完成工作并交付工作成果；制作的工作成果是成片或物料，不是曝光。
- 广告法第 30、32 条：广告活动应书面合同；应委托有合法经营资格的经营者。
- 广告法第 34、37 条：内容不符或证明文件不全的，经营者不得提供制作；禁止商品不得制作广告。
- 《防范和处置非法集资条例》第 11 条：无证明文件且含集资内容的，不得提供制作。

### 1.3 成片 / 物料交付（硬闸）

| 文本写法 | 本任务动作 | 修改句方向 |
| --- | --- | --- |
| 交付 15 秒成片母带 / 指定规格灯箱，附确认脚本或封样 | 正触发 | 首部写明“广告制作承揽，验收对象是成片或物料” |
| 只写“提供制作服务”“配合拍摄”，无成品规格、介质、数量 | 必须改 | 补成品特定化附件 |
| 验收写成“甲方满意即可”或“达到播出标准”而无平台技术规范 | 必须改 | 写明适用哪家平台/电视台的技术规范文本 |
| 货物到场即验收合格，安装、结构安全另说 | 必须改 | 到货初验与安装终验分列 |
| 母带寄出即风险转移，审片尚未完成 | 必须改 | 风险转移绑在验收合格 |

修改句（正触发交易条款）：

「乙方应按附件确认脚本 / 设计终稿 / 封样，完成并交付【影视成片 / 音频母带 / 喷绘灯箱】：规格为【时长、画幅、分辨率、语言字幕 / 材料品牌、尺寸、承重、防火等级】，数量【待填】，交付介质【待填】。影视按粗剪、精剪、成片分节点交付；实物按到货初验和安装终验分别签署。货物到场或母带寄出，不视为验收合格。」

最强反方：制作方主张“行业习惯寄出母带即交付”。现有依据支持第 780 条须交付工作成果并由定作人验收；现有依据不支持把未验收的寄出写成已合格。

### 1.4 与设计 / 发布切开（硬闸）

| 文本写法 | 动作 |
| --- | --- |
| 制作人同时决定广告主张、出创意或多轮改稿，无确认输入稿 | 负触发 `广告设计合同·审查`，或红线拆出设计专条后，制作部分留下本类型 |
| 报酬按 CPT/CPM、曝光、点击、刊播证明结算 | 负触发 `广告发布合同·审查` |
| 主文件是排期采购或媒介差价 | 负触发 `广告代理合同·审查` |
| 用户坚持用本技能把设计或发布整案改完 | `目标停止` |

修改句（切开设计）：

「本合同仅约束广告制作。乙方按甲方或设计方已书面确认的脚本、分镜头和设计终稿加工成品，不得自行决定或改动广告主张、功效表述和忠告语。创意、设计稿和改稿轮次如需一并处理，应另签广告设计合同或作为独立附件，验收对象不得与成片混用。」

修改句（切开发布）：

「制作完成并经验收交付后，乙方主给付完成。上刊、播出、曝光、监测及 CPT/CPM 结算不属于本合同范围，由双方另签广告发布合同。本合同价款按件计酬，不得按曝光量调整。」

用户坚持 CPT/CPM 作为制作主对价：负触发，不填本类型十节实体结论。

### 1.5 违法内容 / 挂靠施工停笔（硬闸）

加载后或定性中出现：为集资、违禁商品或无证明文件的广告提供制作；要求制作“疗效保证”“国家级/最高级”而无依据；户外结构借用施工资质、挂靠、违法分包；伪造行政审查批文。

动作：

1. 交付告知：广告法第 34、37 条及《防范和处置非法集资条例》第 11 条禁止此类制作；挂靠或违法分包不得改写成可履行施工。
2. 不写可履行的画面替换伪装、假批文路径或资质出借结算。
3. 风险表只保留识别依据和删除/转出口径。
4. 用户坚持“改到能签且仍做这些画面或挂靠安装”：整体停止。

户外广告物料仅加工、安装另包给有资质单位：可留本类型制作条款，安装专条交接 `工地建筑活动承包资质竣工验收→` 或要求安装人资质附件。

## 节点 2　主体、制作资质与确认稿

### 2.1 主体表

建表：签约名、履行名、付款名、发票名、授权签字人、现场变更单签字人。名称不一致不自动合并。设计公司与制作公司分立时，定作人须保证设计终稿已定稿并有权交给制作方使用。

口头“市场部说就这个”不得写成已确认脚本或已授权。

### 2.2 资质与许可

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 无广告经营资格痕迹 | 字段停止；修改句要求经营范围或许可查询页作附件 | 可以承接一切广告制作 |
| 影视成片而无广播电视节目制作经营等能力痕迹 | 字段停止；不编造许可证号 | 已具备播出级制作资格 |
| 大型户外结构、高空安装无施工或特种作业资质 | 安装部分停笔或转 `工地建筑活动承包资质竣工验收→` | 普通制作合同即可覆盖结构安全 |
| 拍摄涉及代言肖像，代言合同未覆盖本次次数/用途 | 必须改：制作日程匹配许可范围，超出镜头不得使用 | 拍了就能用 |

修改句：

「本合同签署前，乙方应向甲方出示并作为附件：广告制作经营资格查询页；如含影视成片，另附相应广播电视制作能力证明；如含户外安装，另附施工或特种作业资质。未核验前，不得主张已具备交片或安装条件。涉及代言人出镜的，甲方应提供覆盖本次拍摄次数、内容和媒介的许可；超出许可范围的镜头不得纳入成片。」

## 节点 3　成片 / 物料特定化、素材与验收（硬闸）

支持依据：第 771、775、776、780、781 条。

### 3.1 成品特定化

必须用确认脚本、分镜头、设计终稿或封样界定。影视列时长、画幅、分辨率、语言、字幕、交付介质；实物列材料品牌、工艺、承重、防火等级、安装尺寸。只有“等”“有关制作”则标 `G#`。

“同等材料”必须改为品牌、型号、参数。

### 3.2 素材与通知

广告主提供的素材不足、侵权或技术要求不合理：制作人应及时通知补正或答复。未通知仍制作，导致无法发布或侵权的，制作人自负相应责任。制作人不得擅自更换定作人提供的素材。

修改句：

「甲方应按附件清单提供素材、确认脚本和必要证明文件。乙方应在收到后【待填】日内检验；发现不足、侵权风险或技术要求不合理的，应书面通知甲方更换、补齐或答复。甲方逾期未补正的，交片期顺延，乙方可中止相应制作。乙方未通知仍继续制作，或擅自更换甲方素材的，因此不能发布或构成侵权的责任由乙方承担。」

### 3.3 审片 / 验收

影视：粗剪 → 精剪 → 成片，写明次数、签字主体。实物：到货初验 + 安装终验。异议须书面具体不符点。逾期不审可约定视为合格，但须给合理期限。

修改句：

「影视验收分为粗剪、精剪、成片三次，由合同载明的【姓名/职务】书面签署。实物分到货初验和安装终验，安装验收须留记录。甲方应在收到相应节点成果后【待填】日内提出书面不符点；逾期未提出的，该节点视为符合约定。甲方逾期不审的，后续交片、安装节点顺延，因此错过媒介档期的损失由甲方自行承担。」

最强反方：广告主主张“没签字就永远不算验收”。现有依据支持可以约定拟制验收；本任务不把拟制写成法定义务。

## 节点 4　开工条件、变更单与任意解除（硬闸）

支持依据：第 777、779、787 条。

### 4.1 开工条件

脚本/设计终稿书面确认、预付款到账、场地许可、演员档期不成就，不得起算工期。无确认脚本即开机 → 红线。

修改句：

「同时满足下列条件之次日，工期起算：（1）双方书面确认脚本、分镜头和设计终稿并列为附件；（2）预付款人民币【待填】元到账；（3）拍摄场地许可和演员档期书面确认。任一条件未成就的，乙方不得开机或进场，甲方不得追究逾期。」

### 4.2 变更单

探班、看粗剪不等于可以口头改剧本。现场改词、加拍、换材料必须由合同授权签字人当场签变更单，即时记载费用和工期影响。未签变更单：制作方不得追加费用，广告主不得追究未改部分。

修改句：

「任何偏离确认脚本、设计终稿或封样的指令，须由合同授权的【姓名/职务/指定即时通讯账号】书面或即时通讯确认，并当场记载费用增减和工期影响。未经该程序的口头改词、加拍或换料，乙方不得主张追加费用，甲方也不得以未改部分主张违约。」

### 4.3 任意解除

定作人完成前可解除，须赔偿损失。修改句列已发生场地、演员、材料成本和约定比例，不写无偿，不把履行利益写成必得。

修改句：

「甲方在乙方完成工作前解除本合同的，应在解除通知到达后【待填】日内，向乙方支付已发生且有凭证的场地、演员、材料、差旅费用，并支付约定解除补偿人民币【待填】元或已完成节点价款的【待填】%。已验收节点的价款仍应支付。本条不排除第 787 条，也不把尚未发生的媒介投放利润写成必然赔偿。」

制作方因广告主不提供素材、不审片，经催告仍不履行的，可约定解除并请求已完成部分报酬和损失。

## 节点 5　对价、定金与档期损失

### 5.1 按件计酬

制作费、演员/场地/材料是否单列、加班和加拍单价写清。固定总价须写包含范围。演员和场地建议实报实销并设上限。禁止 CPT/CPM。禁止编造数字。

付款建议节点：预付（锁档期和材料）+ 关机/进场 + 验收尾款。个人账户收取大额制作费 → 红线改对公。

### 5.2 定金

必须使用“定金”二字才讨论罚则。“订金、保证金、预付款”无定金性质的，不得写成定金。约定或推算超过主合同标的额百分之二十：超过部分不产生定金效力。无核验引文不得把 20% 写成现行法结论。

### 5.3 档期损失（硬闸）

| 文本写法 | 动作 |
| --- | --- |
| 制作稍有迟延即承担全部媒介空置、投放预算或预期销售额 | 红线。改为订约时可预见、有预订凭证的直接损失，并设上限 |
| 广告主审片延误导致错过档期仍由制作方赔偿 | 红线删除 |
| 沉默 | 必须改：日违约金与可预见直接损失分列；媒介预订凭证作为索赔前提 |

修改句：

「因乙方逾期交片且可归责于乙方，造成甲方已预订媒介档期空置的，乙方应赔偿甲方订约时已书面告知、并有媒介预订合同或付款凭证证明的直接损失，累计不超过本合同制作费总额的【待填】% 或人民币【待填】元。甲方迟延提供素材、迟延审片或临时变更导致错过档期的，不得向乙方主张该等损失。」

最强反方：广告主主张投放预算全部可预见。第 584 条和解释第 63 条要求按订约时同类主体可预见范围认定；现有依据不支持把未告知、无凭证的全部空置或预期销售写成已闭合。

## 节点 6　广告合规、格式条款与强制规范（硬闸）

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 不得擅自加减功效断言

支持依据：广告法第 9、16、17、34 条；法定审查类广告成片须与批准内容一致。

| 文本写法 | 动作 |
| --- | --- |
| 允许后期“优化话术”“补强功效”“精简忠告语” | 红线删除 |
| 要求制作疗效保证、治愈率、收益率、国家级/最高级画面 | 停笔（节点 1.5） |
| 沉默 | 必须改：正说按确认稿制作，反说擅自增减可拒收、返工或解除 |

修改句：

「乙方应按确认脚本制作成片，不得擅自增加疗效、安全性、收益率等断言，不得使用“国家级”“最高级”“最佳”等用语，不得删除法定忠告语或与批准内容不一致的强制标注。违反的，甲方可拒收、要求返工或解除，并就因此不能发布造成的直接损失依第 5.3 条主张。法定审查类广告的成片内容须与审查通过的内容一致。」

### 6.2 格式条款

为重复使用而预先拟定、订立时未与对方协商。制作公司不得仅以“这次没用过第二次”否认。审查：无限档期转嫁、货物到场即合格、扣留素材原件、人身损害免责、管辖/仲裁等是否加黑提示（第 496 条；解释第 10 条）。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在附件 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

第 497 条无效情形、第 498 条不利解释：只在核验后作为修改理由，不代替修改句。人身损害及故意/重大过失免责：第 506 条，必须改。

### 6.3 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的、是否仅行政管理、是否只规制履行行为（第 153 条；解释第 16 条）。禁止用已失效“效力性/管理性”口诀。集资/违禁制作、挂靠施工：不改写成有效履行。

## 节点 7　权属、留置、风险转移与安全（硬闸）

### 7.1 知识产权与肖像

成片中的摄影、音乐、字体、表演者权归属或许可范围要写清。未约定时，广告主不当然取得全部权利。超出代言许可的镜头不得使用。

修改句：

「成片作为视听作品的权利归属按附件《权属清单》执行。未列明转让或独占许可的摄影、音乐、字体和表演者权，甲方仅取得为本次约定媒介、地域和期限使用该成片的权利，不得再授权给关联品牌。乙方保证自行选用的音乐、字体、图库已获商用授权，并赔偿因该等元素导致的索赔。甲方提供的商标、肖像、产品参数由甲方保证来源合法。超出代言许可范围的镜头不得纳入成片或交付。」

### 7.2 留置与素材原件

逾期不付报酬，制作人对完成的工作成果享有留置权或拒绝交付，另有约定除外（第 783 条）。商事上可约定母带加密或水印版先交、尾款后交无水印母带。

禁止扣留广告主自有素材原件、品牌手册、客户拍摄卡。

修改句：

「甲方逾期未支付到期制作费的，乙方可拒绝交付无水印母带或留置相应成品、物料；甲方提供相当于未付报酬的其他担保后，乙方应在【待填】日内交付。乙方不得扣留甲方提供的素材原件、品牌资料和拍摄存储卡，应在甲方书面索取后【待填】日内返还。」

### 7.3 风险转移与保险

影视：交付母带并验收后风险转移。实物：安装验收合格后转移。运输损坏按交货方式。未约定不得写成货交第一承运人即转移。

拍摄公众责任险、户外安装工程险未投保发生事故的，按过错分担，不得以“承揽”规避安全生产义务。人身损害不得免责。

修改句：

「影视成片毁损灭失风险在成片验收合格并交付约定介质后转移至甲方；实物在安装验收合格后转移。运输区段风险按交货条款【待填】。拍摄现场和高空安装的安全责任，由实际控制现场的一方承担；因故意或重大过失造成人身损害的免责约定无效。」

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

打开已加载的 `框架.md`，按六步逐段对照正文。`基本面.md` 用于校验类型、主体、成品、程序、结构和红旗，不代替本节点出句。

| 步 | 动作 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题用广告制作；输入已是定稿素材的不要写成设计；主体与制作/安装资质；鉴于不写开机条件和档期义务 | 标题或主体修改句 |
| 交易条款 | 确认脚本附件；成品规格；开工条件；粗剪/精剪/成片或到货/安装；按件价款；变更单 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 不得加减功效断言；档期损失上限；任意解除赔偿清单；权属与代言；留置不扣素材；安全环保 | 可执行后果句或删除句 |
| 尾部 | 现场变更单签字人授权；预付款到账且脚本确认后生效；脚本、封样、保险、分包名单入附件 | 生效与附件修改句 |
| 语言 | 正说加反说；盯死交付 vs 安装验收、同等材料、达到播出标准、尽力、原则上 | 替换空词的句子 |
| 常见问题 | 无变更单；档期损失无限转嫁；擅自加减功效；无确认脚本开机 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（设计/发布主轴、无确认脚本开机、CPT/CPM 结算、无限档期转嫁、疗效保证或集资违禁制作、扣留素材原件、挂靠施工、倒签）；
- `必须改`：可谈但签署前要落句（成品特定化、变更单、审片顺延、权属清单、留置范围、资质附件、定金 20%）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级金额或个人无限连带且用户拒绝升级：停止“可以签署”建议。
