# 审查方法（锁定 服务合同 / 互联网广告类合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制传统广告发布的档期/秒数/漏播补刊主路径，禁止复制广告代理的佣金/客户归属主路径，禁止复制设计/制作验收或代言人格许可主路径。

定性校验：标题、核心给付与本类型一致才继续；传统刊播、纯媒介代理、设计/制作承揽、人格代言、广义总览明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受或唯一必得消耗/曝光。

`search_law` 返回已失效《互联网广告管理暂行办法》（2016，总局令第 87 号）、1994 年《广告法》对应旧条、已失效《合同法》及其解释、合同法解释（二）第 14 条时记为噪声，不得写入 `L#`。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。户外或传统发布范本、国家工商局广告发布业务合同只证明是另一类型或栏目参考，不得当作本类型已审完。

知识库纠正（不回写双文件）：

- `基本面.md` 写 2016 暂行办法已失效：现行依据是《互联网广告管理办法》（总局令第 72 号，2023-05-01 施行）。第 32 条废止 2016 办法。合同仍写 2016 办法的，必须改引。
- 程序化购买：不得把已失效 2016 办法第 13 条写成现行规则。现行办法第 4 条按实际行为套发布者/经营者；第 15 条要求算法推荐规则和投放记录记入档案。DSP/SSP 若决定展示内容或赚取广告费差价，不能只按 SaaS 免责。
- `框架.md` “平台不审核内容”“不标广告、保证第一”：不得写入鉴于当免责或承诺。核对义务不能用合同排除。
- 部门规章处罚幅度不当然等于民事合同无效（解释第 16 条）。本任务对禁投和隐藏标识停笔或红线，不宣告合同当然全部无效。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。标题写“技术服务协议”“流量分发”“信息检索服务”的，先看是否通过互联网媒介推销商品或服务：是则按本类型审，不是则切开。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 通过网站、网页、App、小程序、开屏/插屏、信息流、付费搜索、邮件或带购买链接的种草推销商品或服务，按 CPM/CPC/CPA 或消耗结算 | 本类型 | 正触发 |
| 电视台、报刊、户外灯箱按档期、秒数、版面刊播，验收对象是刊播证明 | 传统广告发布 | 负触发 `广告发布合同·审查` |
| 招揽客户、销售媒介档期、收佣金，不控制是否展示 | 广告代理 | 负触发 `广告代理合同·审查` |
| 交付设计稿、创意方案，按件计酬 | 广告设计 | 负触发 `广告设计合同·审查` |
| 交付成片、喷绘、母带，不按曝光点击结算 | 广告制作 | 负触发 `广告制作合同·审查` |
| 许可姓名、肖像并推荐证明 | 广告代言 | 负触发 `广告代言服务类合同·审查` |
| 只有广告活动总览，未落到互联网投放单元 | 广义广告 | 负触发 `广告合同（广义）·审查` |

支持切开的规范（法律结论须运行时复核）：

- 《互联网广告管理办法》第 2 条：境内利用网站、网页、互联网应用程序等互联网媒介，以文字、图片、音频、视频或其他形式直接或间接推销商品或服务的商业广告活动，适用广告法和本办法。
- 《互联网广告管理办法》第 4 条：利用互联网为他人发布广告的，适用广告发布者规定；提供信息服务的，适用互联网信息服务提供者规定；从事设计、制作、代理、发布的，适用经营者/发布者规定。
- 广告法第 14、30、44 条：广告应可识别；广告活动应书面订立；利用互联网从事广告活动适用广告法，弹出广告须一键关闭。
- 传统刊播没有互联网媒介展示界面、落地页核对、弹窗关闭这些给付，不得硬套本类型。

### 1.2 加载协议（硬闸）

本技能已锁定 **服务合同 / 互联网广告类合同**。只打开 `references/基本面.md` 与 `框架.md`。禁止读其他子目录，禁止为对照再开第二类。禁止打开传统广告发布双文件来“顺便把档期也改完”。

### 1.3 与传统发布切开（硬闸）

| 文本写法 | 本任务动作 | 修改句方向 |
| --- | --- | --- |
| 信息流/搜索/开屏/程序化，按消耗或 CPM/CPC 结算，有落地页或跳转 URL | 正触发，留下本类型 | 首部写明互联网广告，不是技术服务，也不是传统刊播 |
| 主给付是某卫视 15 秒广告、某报整版或某路口灯箱，夹带一句“按互联网广告办理” | 负触发 `广告发布合同·审查` | 不按弹窗/落地页改完整案 |
| 互联网投放为主，附件另有一段电视贴片档期 | 本类型继续审互联网部分；档期专条交接 `广告发布合同·审查` | 不得用漏播补刊覆盖信息流消耗 |
| 把付费搜索写成“信息检索服务”，把信息流写成“内容合作” | 正触发但必须改：点明广告 | 见节点 3 |

修改句（正触发首部）：

「本合同为互联网广告投放合同，适用《中华人民共和国广告法》和《互联网广告管理办法》。乙方通过【网站 / App / 小程序 / 信息流 / 付费搜索 / 开屏】向用户展示推销【商品/服务】的商业广告，不是单纯的技术服务、信息检索或流量分发，也不是电视台、报刊或户外媒介的传统刊播。甲乙双方的角色见第【待填】条，不得以合同名称规避广告法上的核对、标识和档案义务。」

最强反方：相对方主张“我们只提供技术接口，不是广告发布者”。现有依据支持按实际是否为他人发布广告、是否从事设计制作代理发布来套角色，现有依据不支持仅凭“技术服务”标题免责。用户坚持按传统刊播或纯代理整案改完：负触发，不填本类型十节实体结论。

### 1.4 禁投 / 未审先投停笔（硬闸）

加载后或定性中出现：利用互联网发布烟草（含电子烟）广告；发布处方药广告（法律、行政法规另有规定除外）；法定审查类广告未经审查即安排发布；以介绍健康养生形式变相发布医疗/药品/器械/保健食品/特医食品并附购物链接；在搜索政务服务网站、网页、应用程序、公众号等结果中插入竞价排名广告；为非法集资作宣传且未查验证明。

动作：

1. 交付告知：办法第 6、7、8、17 条及广告法禁止性规定指向的投放安排，不得改写成可履行的上线路径。
2. 不写可履行的品类伪装、假批文路径或“先上线后补证”。
3. 风险表只保留识别依据和删除/转出口径。
4. 用户坚持“改到能签且仍做这些投放”：整体停止。

## 节点 2　主体、角色、资质与文本版本

### 2.1 主体与角色表

建表：签约名、履行名、付款名、发票名、授权签字人。名称不一致不自动合并。落地页经营者与签约广告主不一致：标 `C#`，不自动合并。

必须写明角色，不得只用“甲方/乙方”：

| 角色 | 文本信号 | 不得写成 |
| --- | --- | --- |
| 广告主 | 对商品服务有权推广；对广告内容真实性负责 | 把落地页实际经营者排除在外 |
| 广告经营者/代理 | 程序化采买、代运营、设计制作代理 | 有发布界面控制却自称“纯代理”以免核对 |
| 广告发布者 | 网站、App、小程序、直播间运营者；为他人发布 | 个人自媒体营利发布却排除发布者规则 |
| 互联网信息服务提供者 / 平台经营者 | 提供存储或搜索、监测制止 | 当然免责 |

达人带货附加购物链接的，发布者身份不能省略。直播间运营者或直播营销人员接受委托提供设计、制作、代理、发布的，按办法第 19 条套经营者/发布者；以自己名义或形象推荐证明的，代言部分交接 `广告代言服务类合同·审查`，投放条款可继续审。

口头“我们老板同意了”不得写成已授权。国资或上市公司广告预算决议未附：该签署能力字段停止。

### 2.2 资格与批文

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 广告主委托无经营资格主体投放 | 必须改：要求资格证明作附件 | 可以上线 |
| 法定审查类无批文或批文与素材不一致 | 停笔（节点 1.4）或字段停止 | 平台审过即可发 |
| 只有营业执照 | 执照不等于广告发布或经营资格，也不等于行政审查 | 已具备全部投放资质 |

修改句：

「本合同签署前，【广告经营者 / 广告发布者】应向对方出示并作为附件：从事本次互联网广告活动所需的合法经营资格证明。涉及医疗、药品、医疗器械、农药、兽药、保健食品、特殊医学用途配方食品等须经审查的广告的，广告主应在上线前提交与素材及落地页一致的广告审查批准文件；未经审查或批文与投放内容不一致的，对方有权拒发，且该部分投放安排不作为可强制履行的内容。」

广告法第 32 条要求委托具有合法经营资格的经营者和发布者。部门规章或许可管理规范不当然导致民事合同无效（解释第 16 条）。本任务只停止“可以上线”表述；禁投本身按节点 1.4 停笔。

## 节点 3　弹出、链接与广告标识（硬闸）

支持依据（运行时复核）：办法第 9、10、17、18 条；广告法第 14、43、44 条。

### 3.1 可识别性与竞价 / 种草链接

| 文本写法 | 动作 |
| --- | --- |
| 约定“不标广告、关闭标识以提高转化”或把付费搜索写成自然排名 | 红线删除。现有依据不支持隐藏标识 |
| 竞价排名未要求显著标明“广告”、未与自然结果区分 | 必须改 |
| 测评、种草、体验分享附加购物链接，却按“内容合作”不标广告 | 必须改：发布者应显著标明“广告” |
| 买断政务关键词或在政务服务搜索结果中插入竞价 | 停笔（节点 1.4） |

修改句：

「互联网广告应当具有可识别性。对于竞价排名的商品或者服务，广告发布者应当显著标明“广告”，并与自然搜索结果明显区分。通过知识介绍、体验分享、消费测评等形式推销商品或者服务并附加购物链接等购买方式的，广告发布者应当显著标明“广告”。任何一方不得约定隐藏、缩小或延迟展示广告标识。付费搜索不得伪装为自然排名，不得在搜索政务服务网站、网页、互联网应用程序、公众号等的结果中插入竞价排名广告。」

### 3.2 弹出 / 开屏关闭

| 文本写法 | 动作 |
| --- | --- |
| 弹窗或开屏无关闭标志、倒计时结束才能关、关闭须两次以上点击、关闭标志难以定位、关闭后同一页面继续弹出 | 红线。现有依据支持办法第 10 条禁止这些情形 |
| 沉默但投放形态含开屏、插屏、弹窗 | 必须改：单独勾选关闭合规 |
| 向交通工具、导航设备、智能家电发送广告，或在用户邮件/即时通讯中附加广告或链接，且无用户同意 | 红线删除或改为取得同意并提供拒绝方式 |

修改句：

「以弹出等形式发布互联网广告，以及启动互联网应用程序时展示的开屏广告，广告主和广告发布者应当显著标明关闭标志，确保一键关闭，不得出现下列情形：没有关闭标志或者计时结束才能关闭；关闭标志虚假、不可清晰辨识或者难以定位；关闭广告须经两次以上点击；在浏览同一页面或同一文档过程中关闭后继续弹出。未经用户同意、请求或者用户明确表示拒绝的，不得向其交通工具、导航设备、智能家电等发送互联网广告，不得在用户发送的电子邮件或者互联网即时通讯信息中附加广告或者广告链接。以电子信息方式发送广告的，应明示发送者真实身份和联系方式，并提供拒绝继续接收的方式。」

### 3.3 下一级链接与落地页

支持依据：办法第 18 条。

| 文本写法 | 动作 |
| --- | --- |
| 只审素材、不审落地页；跳转 URL 变更无须重审 | 红线。现有依据支持核对下一级链接中与前端广告相关的内容 |
| 有落地页清单，但变更权限和存档沉默 | 必须改：变更等于素材变更，按日存档快照 |
| 广告合规、落地页另做违法承诺 | 必须改：审核范围覆盖点击后页面；落地页违法则拒发或立即下线 |

修改句：

「发布含有链接的互联网广告，广告主、广告经营者和广告发布者应当核对下一级链接中与前端广告相关的广告内容，审核范围覆盖点击后的落地页。落地页 URL、关键卖点或证照信息变更的，视为素材变更，须在变更前【待填】小时重新提交审核；未经重新审核不得继续投放。广告发布者应按日保存落地页快照，保存期限适用节点 4 档案规则。仅审核创意素材、不审核落地页的约定无效，双方应删除该约定。」

最强反方：发布者主张“链接内容由广告主随时更换，发布者无法控制”。办法第 28 条允许在已采取措施防止链接被篡改并提供违法主体真实名称、地址和有效联系方式时从轻、减轻或不予处罚，但这是减轻责任安排，现有依据不支持据此免除核对义务。用户坚持只审素材不审落地页：整体停止。

## 节点 4　核对、档案与先证后投（硬闸）

支持依据：办法第 7、13、14、15、16 条；广告法第 32 条。

### 4.1 不得排除核对

| 文本写法 | 动作 |
| --- | --- |
| “技术中立、对内容概不负责、平台不审核” | 红线删除。法定核对不能用合同排除 |
| 广告主保证素材合法，发布者仍有权也有义务查验证明、核对内容、证明不全拒发 | 可保留，须写拒发时限和下线 |
| 平台审核视为已完成行政审查 | 必须改：平台审核不等于广告审查机关审查 |

修改句：

「广告主对互联网广告内容的真实性负责，并保证主体资格、行政许可和引证内容真实、合法、有效。广告经营者、广告发布者应当查验有关证明文件，核对广告内容；对内容不符或者证明文件不全的，经营者不得提供设计、制作、代理服务，发布者不得发布。任何“技术中立”“对内容概不负责”或“平台不审核”的约定，不免除上述义务。平台内部审核不构成法律、行政法规规定的广告审查；须经审查的广告，未经广告审查机关审查通过不得发布，已审查通过的内容不得剪辑、拼接、修改，改动须重新申请审查。」

### 4.2 档案与算法记录

| 文本写法 | 动作 |
| --- | --- |
| 档案保存少于三年，或未约定电子数据保存 | 必须改：自发布行为终了之日起不少于三年 |
| 利用算法推荐投放，未要求把推荐规则和投放记录记入档案 | 必须改 |
| 平台经营者不记录利用其信息服务发布广告的用户真实身份 | 必须改：自信息服务提供行为终了之日起不少于三年 |

修改句：

「广告经营者、广告发布者应当建立互联网广告业务的承接登记、审核、档案管理制度，查验并登记广告主的真实身份、地址和有效联系方式，记录并保存广告活动有关电子数据；相关档案保存时间自广告发布行为终了之日起不少于三年。利用算法推荐等方式发布互联网广告的，应当将算法推荐服务相关规则、广告投放记录记入广告档案。互联网平台经营者应当记录、保存利用其信息服务发布广告的用户真实身份信息，保存时间自信息服务提供行为终了之日起不少于三年，发现违法广告的，应当采取通知改正、删除、屏蔽、断开发布链接等必要措施并保留记录。」

广告主自行发布的，办法第 13 条同样要求建档且不少于三年。修改广告内容须以书面或其他可确认方式通知经营者、发布者。

## 节点 5　计费、预存与监测（硬闸）

### 5.1 预存性质与定金

预存广告费性质为预付款，不是定金。必须使用“定金”二字才讨论罚则。“订金、保证金、预存、充值”无定金性质约定的，不得写成定金。约定或推算超过主合同标的额百分之二十：超过部分不产生定金效力（第 586 条，法律结论须核验）。

修改句：

「甲方预存或充值的广告费属于预付款，不属于定金，不适用定金罚则。未消耗余额按【待填】日对账后【待填】日内原路退回。双方如需约定定金，应单独使用“定金”二字，数额不超过可确定投放价款的百分之二十，超过部分不产生定金效力。」

禁止编造单价、预算。消耗封顶、日预算、总预算未写的，标 `G#`。

### 5.2 口径、作弊与监测

| 文本写法 | 动作 |
| --- | --- |
| 未定义 CPM/CPC/CPA，或 CPA 无有效转化定义 | 必须改 |
| 单方后台数据为唯一结算依据，消耗不可导出 | 必须改：第三方监测优先，差异超约定比例复盘，作弊流量不计费 |
| 保证“稳居自然排名第一”“智能投放包过”“保证成交” | 红线改为按约定口径计费，不保证经营结果 |

修改句：

「计费仅统计有效展示、有效点击或有效转化。无效点击、自点击、机器流量和经双方或第三方监测确认的作弊流量不计费。结算以【待填】第三方监测数据为准；与任一方后台差异超过【待填】% 的，【待填】日内复盘，复盘完成前暂停该部分结算。任何一方后台数据不得作为唯一结算依据。乙方不保证甲方的成交量、自然排名或经营结果。素材上传后台不等于已对用户展示，发布完成以约定监测口径下的实际展示为准。」

## 节点 6　数据、格式条款与强制规范（硬闸）

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 人群包与个人信息

支持依据：个人信息保护法第 6、24 条；办法第 14 条档案义务不构成可违法交付个人数据。

| 文本写法 | 动作 |
| --- | --- |
| “用户数据一次性交付”“可抓取通讯录或精确位置用于广告”而无告知同意 | 红线。改为聚合报表；定向须有合法基础 |
| 购买来源不明人群包 | 红线：书面保证来源合法，不能保证则不得使用 |
| 自动化决策定向，无“不针对个人特征”选项或便捷拒绝方式 | 必须改 |

修改句：

「定向投放使用个人信息的，提供方应保证已取得合法处理基础，并不得提供未经授权的个人信息。禁止约定抓取用户通讯录、精确位置或其他非必要个人数据用于广告。人群包应书面说明来源和授权范围；来源不明或无法证明合法基础的，不得用于本次投放。通过自动化决策进行商业营销的，应同时提供不针对个人特征的选项或便捷拒绝方式。双方仅交换聚合统计报表，不得交付可识别个人的原始数据。」

用户坚持违法交付精准个人数据：整体停止。

### 6.2 格式条款

为重复使用而预先拟定、订立时未与对方协商。从事经营活动的平台不得仅以“这次没用过第二次”否认。依据示范文本制作，不当然排除格式条款。

审查：免核对、隐藏标识、单方调价或单方数据结算、自动续充、管辖/仲裁等异常条款是否有足以引起注意的标识，以及是否按要求说明（第 496 条；解释第 10 条）。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在附件 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

提供方对其已尽提示或说明承担举证责任。第 497 条无效情形、第 498 条不利解释：只在核验后作为修改理由，不代替修改句。电子合同点击同意须能回溯版本，保存哈希或文本快照。

### 6.3 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的、是否仅行政管理、是否只规制履行行为（第 153 条；解释第 16 条）。禁止用已失效“效力性/管理性”口诀代替解释第 16 条。禁投、未审先投、隐藏标识、违法数据：不改写成有效履行。
