# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的单价、预算、时限；把已失效 2016《互联网广告管理暂行办法》或《合同法》写入结论；把隐藏标识、弹窗无法一键关闭或只审素材不审落地页写成已闭合；把技术中立写成已排除核对义务；把预存广告费写成定金；把未审医疗或烟草互联网广告改成可履行结构；把传统刊播、广告代理、设计制作或代言当成已完成的本类型审查。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查互联网广告类合同（服务合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效 2016《互联网广告管理暂行办法》、1994 年广告法对应旧条或已失效《合同法》及其解释时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `服务合同`，子级 `互联网广告类合同`。定性理由、易混切开结果（传统广告发布、广告代理、设计、制作、代言、广义广告）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、角色与文本版本

主体表：签约名、履行名、付款名、发票名、授权签字人。角色表：广告主、经营者/代理、发布者/平台、信息服务提供者。版本表：正文、创意规格、落地页清单、监测对接、数据附录、聊天确认；冲突并列。未核批文或经营资格：该上线能力字段停止。

## 5. 投放给付、标识、落地页、计费与档案

核心给付是否互联网媒介推销；是否夹带传统刊播或纯代理；广告标识与弹窗关闭；下一级链接与落地页核对；计费口径、无效点击、预存性质；档案是否不少于三年；人群包来源。缺口标 `G#`。不输出传统刊播漏播补刊或代理客户归属主路径。

## 6. 格式条款与强制规范

是否构成格式条款；免核对、隐藏标识、单方数据结算、管辖等异常条款是否加黑提示。强制规范只按第 153 条和解释第 16 条区分，不用失效口诀。禁投品类/未审先投/违法数据只保留识别与停笔。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把框架里的实务量级写成法定期限。

## 9. 谈判与签署提醒

谈判顺序：先红线（类型错位、隐藏标识、弹窗关闭障碍、只审素材不审落地页、技术中立免核对、2016 办法、未审先投、烟草/处方药、违法人群包），再必须改（标识位置、落地页重审、档案三年、计费口径、预付款定性、第三方监测、数据最小必要），最后可优化。签署提醒：双方公章或可回溯电子签署；创意规格、落地页清单、监测对接、禁投品类、数据附录、批文入附件。不指导倒签或补假批文。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书或效力保证，也不是传统广告发布、广告代理、设计、制作或代言审查。
