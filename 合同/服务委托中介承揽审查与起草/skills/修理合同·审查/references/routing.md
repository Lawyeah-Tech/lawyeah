# 边界与路由

本技能只审查 **承揽合同 / 修理合同** 的待签文本。中文展示名是「审查修理合同（承揽合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 按图从无到有制作新物，承揽人备料 | `定作合同·审查` |
| 定作人供料，由对方制成新物或改变形态 | `加工合同·审查` |
| 主给付是移转通用物所有权换价款，修理仅为附带 | `通用型号现货卖方组织生产买方不控制过程→` |
| 贴牌、按品牌方规格批量生产 | `定牌加工（OEM）合同·审查` |
| 类似建筑工程的简易新建、构筑物施工 | `项目承揽合同·审查` |
| 施工许可范围内的建设工程、主体结构作业 | `工地建筑活动承包资质竣工验收→` |
| 复制既有作品或载体 | `复制合同·审查` |
| 印刷 | `印刷合同·审查` |
| 测试、测绘 | `测试测绘合同·审查`。P1：专业版未装则 `unavailable`，提示，不得用本技能硬套 |
| 检验、鉴定 | `检验鉴定合同·审查`。P1；未装则 `unavailable` |
| 框架协议下多笔订单、本单不是单件送修 | `框架加订单承揽·审查` |
| 无故障、只卖例行保养套餐且不交付修复成果 | `面向消费者的服务类合同·审查` 或引擎重新定性 |
| 无文本、本类型条件已谈妥、要出己方稿 | `修理合同·起草` |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争，含催告、留置变价、索赔、诉讼仲裁 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

修理正文里夹带一小段新件买卖：新件所有权专条可交接 `通用型号现货卖方组织生产买方不控制过程→`；既有物修复、进场状态、旧件、787 条款可继续审。用户坚持本技能把定作、加工、买卖或施工整案改完：`目标停止`。
