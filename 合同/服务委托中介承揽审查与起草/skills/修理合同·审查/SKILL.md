# 修理合同·审查

## 任务目标

在单一立场下，只审查 **承揽合同 / 修理合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文名必须是「审查修理合同（承揽合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类合同审查、从零起草、履约交底、争议文书、有效性保证、把定作/加工/买卖/OEM/施工文本改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **修复既有物**：核心给付是对已经存在、已经损坏或功能减损的特定物做修复，交付的是“恢复功能的成果”，不是新物创制。送修物必须落到名称、品牌、型号、序列号或唯一标识码，以及进场时损坏现状。没有既有物身份、正文是按图新造 → 不是本类型。
2. **与定作 / 加工 / 买卖切开**：从无到有制作新物且承揽人备料 → `定作合同·审查`（定作）。定作人供料由对方制成新物或改变形态 → `加工合同·审查`（加工）。移转通用物所有权换价款、修理只是附带安装 → `通用型号现货卖方组织生产买方不控制过程→`（动产买卖）。贴牌批量生产 → `定牌加工（OEM）合同·审查`。类似建筑工程的简易新建或结构性施工 → `项目承揽合同·审查` 或 `工地建筑活动承包资质竣工验收→`。禁止删掉邻类主给付后硬套本技能。
3. **787**：定作人在承揽人完成工作前可以随时解除合同，造成承揽人损失的应当赔偿损失。修改句须保留该路径，并写清损失范围（已发生工时、已拆封使用材料、已订购且无法退货的零件），数字用 `【待填】`。禁止写成无偿随时解除，也禁止写死“任何情形不得中途解除”或“放弃第七百八十七条”。工作已经完成的，不得再套 787。
4. **材料归属**：分列谁供新件、规格/品牌/新旧、是否接受定作人检验；更换下来的旧件/报废件归谁；承揽人不得擅自更换定作人材料和不得更换不需要修理的零部件。机动车换下配件应交托修方自行处理。框架里“旧件通常归定作人”只是商业惯例，除机动车维修部门规章外不是民法典默认规则，必须落句。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签修理正文，尚未签署，尚未成争，核心给付是修复既有特定物的功能或使用价值，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 按图从无到有制作新物、承揽人备料 → `定作合同·审查`；
- 定作人供料制成新物或改变形态 → `加工合同·审查`；
- 主给付是移转通用物所有权换价款 → `通用型号现货卖方组织生产买方不控制过程→`；
- 贴牌、按品牌方规格批量生产 → `定牌加工（OEM）合同·审查`；
- 类似建筑工程的简易施工、新建构筑物 → `项目承揽合同·审查`；主体工程、施工许可范围内作业 → `工地建筑活动承包资质竣工验收→`；
- 只做复制、印刷、测试测绘或检验鉴定 → `复制合同·审查` / `印刷合同·审查` / `测试测绘合同·审查` / `检验鉴定合同·审查`（后两类 P1，专业版未装则 `unavailable`）；
- 无故障、只卖保养套餐且不交付修复成果 → `面向消费者的服务类合同·审查` 或引擎重新定性；
- 无文本、本类型条件已谈妥、要出己方稿 → `修理合同·起草`；
- 已签只问进厂日、试车日、付款日 → 本套导航的履约步骤；
- 已催告、解除、索赔、留置变价、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

挂靠、出借维修资质、承修报废机动车、利用配件拼装、非法改装：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（定作人/送修方或承揽人/承修方择一）；相对方；全文及进场确认单、报修清单、零件价目、验收单版本；送修物是否既有且可识别；损坏现状与修复目标；谁供料、旧件怎么处理；报酬是包干还是工时+零件；是否排除 787；特种设备或机动车资质痕迹；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价金、工期、零件编号用 `【待填】`，不编造。

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》承揽章、《加工承揽合同条例》或《经济合同法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `修理合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有修理文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。必须先确认修复既有物，再与定作、加工、买卖切开。

### 2. 主体、资质与授权

签约名、履行名、付款名、发票名分列。特种设备修理许可、机动车维修经营痕迹未核：字段停止。无资质承修特种设备或承修报废车：只告知，不改成可履行。

### 3. 既有物身份与进场状态

序列号、损坏诊断、随机配件书面确认。口头“看着能修”不得写成已进场检验。

### 4. 材料归属与 775

谁供新件、旧件交谁、不得更换不需要修理的零部件。增项须书面确认。

### 5. 对价、检测费与验收

工时与材料分列；拆解后超估或无修理价值怎么停；试运行验收；质保覆盖同一故障。

### 6. 787、格式条款与强制规范

保留完成工作前的解除与损失赔偿。无核验引文则法律结论字段停止。

### 7. 质量、保管、留置与争议

修而不复可减酬、重作或解除；784 期间毁损；783 留置须另约定催告期限，未约定不得短于六十日。不选定唯一法院充作意见。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证修好、把无资质承修特种设备、承修报废车、拼装或非法改装改成可履行结构。
- `字段停止`：法域、动态规则、特种设备许可、机动车维修经营资格、查封/抵押负担未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁定作/加工/买卖/施工。
