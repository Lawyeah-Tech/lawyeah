# “一二级联动” 相关合同·审查

## 任务目标

在单一立场下，只审查 **委托合同 / “一二级联动” 相关合同** 的待签文本：开发主体承担土地一级整理（征收拆迁、熟地标准、大市政），同时文本对后续国有建设用地使用权出让（二级拿地）作出优先权、竞争优势、预申请挂钩或实施主体转化安排。输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查“一二级联动” 相关合同（委托合同）」。本技能不代替审查土地一级开发委托合同（那是 `土地一级开发委托合同·审查`），不代替审查名为土地一级开发、实为投资或借贷的合同（那是 `名为一级开发实为借贷·审查`）。

`depends-on` 为空。不要求先跑导航。

不交付：纯一级开发委托审查、名为一级实为借贷审查、纯勾地/用地预申请审查、纯拆迁委托审查、城市更新前期服务整案、国有土地使用权出让合同审查、他类文本审查、从零起草、履约交底、行政诉讼或仲裁策略、有效性保证、可履行的招拍挂规避或定向出让结构。

## 本类型硬闸

1. **一级整理与二级拿地捆绑风险**：一级整理可以委托；经营性用地及同一宗地有两个以上意向用地者的二级供地，必须走招标拍卖挂牌等公开竞价。文本把“完成一级”与“保证摘牌、定向出让、必须由乙方取得土地使用权”绑死的，标红线。修改句只拆捆绑、补未摘牌退出，不把捆绑改成更能锁地的结构。
2. **招拍挂规避只告知**：保证摘牌、协议定向出让、私下联动与公开出让文件两套文本、设置只有己方能过的排他竞买门槛、以土地换项目或先征后返变相减免出让价款：只出告知与红线，不设计可履行规避路径。用户坚持“改到能锁地”：整体停止。
3. **与 `土地一级开发委托合同·审查`、`名为一级开发实为借贷·审查` 切开**：核心给付只有一级整理、对价是核定成本加固定利润、没有二级优先或摘牌安排 → `土地一级开发委托合同·审查`。企业只出资金、不组织征收拆迁和市政、固定期限固定回报或保底分成 → `名为一级开发实为借贷·审查`。禁止打开二者 method 当本类型主路径。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。禁止把知识库里的“苛刻准入变通”“毛地出让变通”写成可放行结构。

## 工作边界

正触发：已有可读待签正文，尚未签署，尚未成争，核心给付同时包含一级整理事务和对后续二级出让的联动安排（优先参与、预申请挂钩、城市更新实施主体转化、未摘牌成本退出），用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只有一级整理、成本加利润、无二级拿地安排 → `土地一级开发委托合同·审查`；
- 名为一级开发，实为固定回报出资或财政借款 → `名为一级开发实为借贷·审查`；
- 名为一级开发，实为垫资施工、竣工验收 → `名为一级开发实为施工·审查`；
- 只有拆迁实施委托，不连二级出让 → `拆迁委托协议·审查`；
- 只有用地预申请/勾地，没有一级整理委托 → `只有用地预申请勾地，没有一级整理委托→`；与非出让人勾地 → `或`；联合勾地 → `或`；
- 企业之间一级市场联合拿地主结构 → `或`；
- 待签文本已是国有土地使用权出让合同 → `切开。送审主文件是出让合同，或审查重点是出让金交地规划条件土地登记→负触发该原子。本技能禁止打开或复制其method，禁止把本约改成可签署的出让文本，禁止输出出让金分期交地标准土地登记作为本类型主路径。`；
- 城市更新前期服务、未写实施主体转化或二级联动 → `城市更新前期服务未写实施主体转化或二级联动→`；村集体与企业合作开发主结构、政府未作为联动一方 → `村集体与企业合作开发主结构政府未作为联动一方→`；
- 无文本、本类型条件已谈妥、要出己方稿 → `“一二级联动”相关合同·起草`；
- 已签只问付款日、供地日、验收留痕 → 本套导航的履约步骤；
- 已催告、解除、索赔、复议、诉讼仲裁 → `或对应专项领域。` 或行政争议路径，不审应诉策略。

挂靠、违法分包、规避招拍挂、伪造内部决议、阴阳合同：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（行政委托方或开发受托方择一）；相对方是否具备代表政府签约的授权；全文、附件红线图、出让前置条件建议书、政府常务会议纪要、村集体决议版本；一级范围与熟地标准；二级联动语句（优先、保证、预申请、实施主体）；出让金返还或分成；未摘牌退出；争议解决是诉讼还是仲裁；不可接受事项；法域与拟签署日。缺立场或无可读书面文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的金额、期限、容积率用 `【待填】`，不编造。

## 律页能力增强

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、《物权法》、2002 年国土资源部令第 11 号旧文，或 1989 年行政诉讼法第十二条不受理清单，当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

### 0. 签署状态与成果分流

无书面文本 → `“一二级联动”相关合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 争议领域。未签且目标是评改已有联动文本，才进入本任务。

### 1. 类型锁死与邻类切开

标题、签署方与核心给付一致才继续。纯一级、假一级真借贷、假一级真施工、纯勾地、纯拆迁、纯前期服务负触发。禁止两可时灌入 `土地一级开发委托合同·审查` 或 `名为一级开发实为借贷·审查` 知识。

### 2. 一级与二级捆绑闸

拆开一级事务与二级供地。保证摘牌、定向出让必须改或停笔。合法表述限于支持参与公开出让，结果以成交确认书为准。

### 3. 招拍挂规避停笔

排他门槛、阴阳合同、先征后返、以土地换项目：只告知，不设计锁地结构。

### 4. 行政协议、主体授权与村集体决议

政府侧授权、常务会议、村集体民主决策未见则签署能力字段停止。行政协议争议不得改成可执行仲裁。

### 5. 熟地标准、出让金与未摘牌退出

净地条件、成本审计补偿、禁止直接返还出让金、摘牌/未摘牌二元退出。

### 6. 按框架六步出修改句

必须有可回给对方的修改句或红线。框架与硬闸冲突时，以 method 为准。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持保证摘牌、设计排他门槛或阴阳合同、要求先征后返锁地、保证协议有效。
- `字段停止`：法域、政府授权文件、村决议、规划指标、出让金收支路径、地方城市更新政策未核验。
- `目标停止`：主目标已变为从零起草、履约交底、纯一级审查、借贷穿透整案、行政诉讼或仲裁策略。
