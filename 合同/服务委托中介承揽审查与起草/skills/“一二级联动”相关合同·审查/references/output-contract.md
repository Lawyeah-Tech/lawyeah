# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、保证摘牌或必然可执行；编造未给出的金额、期限、容积率；把已失效《合同法》《物权法》或国土资源部令第 11 号旧文写入结论；输出行政诉讼请求或胜率；把本约改成可履行的定向出让或排他门槛；把出让金直接返还改成另一套先征后返口径。

## 1. 触发、单方立场与成果状态

立场（行政委托方或开发受托方）、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查“一二级联动” 相关合同（委托合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》《物权法》、国土资源部令第 11 号旧文，或 1989 年行政诉讼法第十二条时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `委托合同`，子级 `“一二级联动” 相关合同`。定性理由、易混切开结果（尤其与 `土地一级开发委托合同·审查` 纯一级、`名为一级开发实为借贷·审查` 假一级真借贷、`只有用地预申请勾地，没有一级整理委托→` 纯预申请、`城市更新前期服务未写实施主体转化或二级联动→` 前期服务的切开）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、资格与文本版本

主体表：行政方签约名、授权依据、开发方名称、付款名、收款名。资格闸：储备或更新计划、常务会议、村集体决议、房地产开发资质是否见到。版本表：正文、红线图、出让前置条件建议书、公开出让文件草稿、聊天确认；冲突并列，供地条件以依法公布的出让文件为准。

## 5. 给付闭环与风险负担

一级：范围、熟地标准、进度、成本审计。二级：只记录“支持参与公开出让”，不记录已取得土地使用权。对价：审计补偿路径，不得写成出让金直接返还。退出：摘牌成功 / 未摘牌两列。行政协议单方变更走补偿或赔偿，不输出必得违约金。缺口标 `G#`。

## 6. 强制规范与规避结构

保证摘牌、定向出让、排他竞买门槛、阴阳合同、先征后返、毛地出让、行政协议仲裁、无授权管委会签约。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和删除句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把框架仲裁建议写成行政协议可执行管辖；不得把保证摘牌改成排他门槛。

## 9. 谈判与签署提醒

谈判顺序：先红线（保证摘牌、定向出让、排他门槛、阴阳合同、出让金直接返还、行政协议仲裁），再必须改（拆捆绑、未摘牌退出、授权和村决议附件、熟地标准、去总价包干），最后可优化。签署提醒：授权文件、常务会议、村决议、红线图、审计口径。不指导倒签、补假决议或补假招标。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、纯一级审查、借贷穿透整案、出让合同审查、行政诉讼或仲裁文书、效力保证。
