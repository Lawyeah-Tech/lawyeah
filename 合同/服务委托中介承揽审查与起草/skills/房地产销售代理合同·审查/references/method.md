# 审查方法（锁定 委托合同 / 房地产销售代理合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制房屋买卖/租赁中介的跳单或产调节点、全案营销的策划 IP/推广包干/清盘节点、一般委托的任意解除主产品。

定性校验：标题、核心给付与本类型一致才继续；居间撮合、全案营销包、一般事务委托、渠道分销、商品房本约、行纪自营明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受或唯一必得佣金。

`search_law` 返回已失效《合同法》委托章或居间章、已失效《城市房地产中介服务管理规定》、已失效《经纪人管理办法》、已失效《关于对外贸易代理制的暂行规定》时记为噪声，不得写入 `L#`。2011 年《房地产经纪管理办法》第 11 条被标为已被修改：不得单独把 2011 条号写成未经复核的现行依据；备案义务以 2016 修正现行文本及运行时核验为准。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。未知权威的“房地产代理销售合同_独家代理”“商品房代理销售合同”只借栏目。山东省房地产经纪服务合同示范文本、一般委托范本只证明是另一类型，不得当作本类型范本。

知识库纠正（不回写双文件）：

- `基本面.md` “属于房地产中介服务的一种”：这是行政监管口径。《房地产经纪管理办法》可约束展业和现场公示，**民事定性仍是委托销售代理**，不得因此改走 `房屋买卖_租赁中介合同·审查`。
- `基本面.md`/`框架.md` “排除任意解除权”或“限制解除条件”：第 933 条允许随时解除。修改句可约定通知期和有偿赔偿计算。**不得写成“双方放弃任意解除权且解除无效”**。
- `基本面.md` “五证齐全”：材料未出示不得写成已齐。预售看预售许可证；现售看第 7 条条件和第 8 条备案。
- 1997 年物资代理制“佣金原则上 1%–5%”：与商品房销售代理无关，不得写入佣金结论。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。标题写“居间/全案/委托协议”的，先看是不是开发商授权推销本项目并按成交计提代理佣金。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 开发商或本项目售房权利人委托经纪/代理机构，以委托人名义推销指定楼幢房号，按成交付代理佣金 | 本类型 | 正触发 |
| 只介绍买家或承租人，本约由买卖/租赁双方直接签署，自己不成交一方 | 房屋买卖/租赁中介 | 负触发 `房屋买卖_租赁中介合同·审查` |
| 调研、产品建议、媒介推广、驻场销售捆成全案主给付，常有策划成果归属和推广预算 | 全案销售委托代理 | 负触发 `调研+策划+媒介推广+驻场销售捆成全案主轴→负触发` |
| 概括处理事务、代办年报、诉讼代理，卖房只是顺带一句 | 一般委托 | 负触发 `一般委托合同·审查` |
| 只做渠道带客、不驻场、不以开发商销售代理身份对外 | 渠道销售委托代理 | 负触发 `只带客结佣不驻场不以开发商销售代理身份对外→负触发` |
| 主文件约定房屋价款、交房、办证 | 商品房买卖本约 | 负触发 `或对应买卖原子；` 或对应买卖原子 |
| 以自己名义买卖房屋并吃差价 | 行纪或买卖 | 负触发 `行纪合同·审查` 或回引擎 |

支持切开的规范（法律结论须运行时复核）：

- 第 919 条：委托是处理委托人事务。开发商把本盘销售事务交给代理机构，属于委托。
- 商品房销售管理办法第 4、25 条：开发企业可以委托依法设立并取得营业执照的房地产中介服务机构销售；须订立书面委托合同，载明期限、权限和权利义务。
- 条例第 28 条：委托中介机构代理销售的，应当出具委托书；销售时须向买受人出示证明文件和委托书。
- 第 961 条：**负向切开**中介——只报告机会或提供媒介。
- `调研+策划+媒介推广+驻场销售捆成全案主轴→负触发` 的切开不靠法条口号，靠给付宽度：全案主轴是营销包，本类型主轴是销售代理佣金。

### 1.3 开发商委托销售代理（硬闸）

| 文本写法 | 本任务动作 | 修改句方向 |
| --- | --- | --- |
| 甲方为房地产开发企业，乙方以甲方名义推销指定房号，甲方按成交向乙方付代理佣金 | 正触发，留下本类型 | 首部写明“商品房委托销售代理，不是居间、全案营销包或一般事务委托” |
| 乙方只介绍客户，买卖合同由甲方与客户直接签，乙方不驻场、不执行价目、不代办网签 | 负触发中介 | 不按销售代理改完 |
| 工作范围并列市场调研、品牌定位、媒介投放、驻场销售，策划成果和推广费是主条款 | 负触发全案 | 不按本类型只改佣金 |
| 授权“处理甲方一切事务”，销售只是举例 | 负触发一般委托 | 不按本盘销售代理改完 |
| 乙方只从分销端口带客，不进售楼处、不以甲方销售代理身份对外 | 负触发渠道 | 不按驻场销售代理改完 |

修改句（正触发首部）：

「本合同为商品房委托销售代理合同。甲方是【项目名称】的房地产开发企业。甲方委托乙方，在书面授权范围内以甲方名义推销附件《房号清单》列明的房屋及【车位 / 储藏室 / 不包含】，并按本合同向乙方支付销售代理佣金。乙方不是仅报告订约机会的中介人，也不是承接市场调研、品牌定位和媒介投放的全案营销总包方。商品房买卖合同的出卖人是甲方。」

最强反方：相对方主张已构成居间、全案或一般委托，从而主张跳单报酬、策划成果归己或概括授权。修改句必须收回撮合、全案包和空白授权措辞。用户坚持保留居间主轴、全案主轴或概括事务主轴：负触发，不填本类型十节实体结论。

### 1.4 违规促销 / 无证预售停笔（硬闸）

加载后或定性中出现：未取得《商品房预售许可证》仍要对外认购或预售；返本销售或变相返本；未竣工商品房售后包租或变相包租；分割拆零销售商品住宅；为买受人提供首付贷或场外融资；就同一房屋签订不同价款的合同；代理销售不符合销售条件的房屋。

动作：

1. 交付告知：预售许可是法律、行政法规层面的预售条件（城市房地产管理法第 45 条；条例第 22 条；预售管理办法第 6 条）。出卖人未取得预售许可与买受人订立的预售合同，解释第 2 条指向无效（起诉前补证除外）。该解释约束的是开发商与买受人的预售合同，**不得直接写成销售代理合同必然无效**；但委托事务是无证预售的，不得改成可履行的无证预售结构。返本销售、未竣工售后包租、分割拆零：销售办法第 11、42 条禁止，只告知，不改履行结构。
2. 不写可履行的“先认购后补证”伪装、假许可路径或体外首付融资。
3. 风险表只保留识别依据和删除/转出口径。
4. 用户坚持“改到能签且仍做这些事”：整体停止。

## 节点 2　主体、备案与销售许可（硬闸）

### 2.1 主体表

建表：签约名、履行名、房款收款名、佣金付款名、发票名、授权签字人。名称不一致不自动合并。

委托人须是房地产开发企业或对该项目有权委托销售的主体。开发资质、土地使用权未闭合：该委托能力字段停止，不写成“可以开盘”。口头“我们老板同意了”不得写成已授权。

受托人须是依法设立并取得营业执照的房地产中介服务机构。分支机构须以设立该分支机构的经纪机构名义承揽；经纪人员不得以个人名义承接业务并收费。

### 2.2 经纪备案

支持依据：房地产经纪管理办法（2016 修正）第 12、13、15 条。2011 年第 11 条“领照 30 日内备案”已被修改，不得单独写成未经复核的现行条号。现行有效文本要求主管部门公示备案信息，机构须在经营场所公示备案证明，代理销售商品房还须在销售现场明示委托书和批准销售文件。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 无经纪备案证明、无公示查询页 | 字段停止；修改句要求作为附件 | 可以展业；备案不影响签约 |
| 只有营业执照 | 执照不等于经纪备案 | 已具备全部销售代理资格 |
| 有备案证明但销售现场不公示 | 必须改：现场明示 | 已尽公示义务 |

修改句：

「本合同签署前，乙方应向甲方出示并作为附件：营业执照、房地产经纪机构备案证明或主管部门备案公示查询页。销售现场明显位置应同时明示商品房销售委托书和批准销售商品房的有关证明文件。未核验前，不得主张已具备驻场销售代理条件。」

部门规章备案不当然导致民事合同无效（解释第 16 条）。本任务只停止“可以展业”表述，不宣告合同当然无效。

### 2.3 预售许可 / 现售备案

支持依据：城市房地产管理法（2019 修正）第 45 条；条例第 22、26 条；预售管理办法第 6 条；销售办法第 7、8、22、27 条。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 预售项目无预售许可证 | 停笔（节点 1.4） | 改成现房代理即可放行预售认购 |
| 现售未报现售条件证明备案 | 字段停止；修改句要求附件 | 已具备现售条件 |
| 有预售证但未列入附件、未写文号 | 必须改：文号入合同并附查询页 | 证照已经齐备 |
| 用户要求把解释第 2 条写成代理合同必然无效 | 纠正：解释第 2 条约束开发商与买受人的预售合同 | 代理合同必然无效 |

修改句：

「甲方保证：委托范围内预售房屋已取得《商品房预售许可证》（文号【待填】）；现售房屋已具备《商品房销售管理办法》第七条所列条件，并已按第八条将现售证明文件报送主管部门备案。上述许可证或备案查询页作为附件。未取得预售许可的房屋，乙方不得代理认购、预售或收取预订款性质费用。」

## 节点 3　委托书、权限与现场公示

支持依据：销售办法第 25、26 条；条例第 28 条；经纪管理办法（2016 修正）第 14、15 条。

书面委托合同须载明委托期限、委托权限和双方权利义务。另出具给买受人核验的《商品房销售委托书》。权限至少分列：

1. 是否仅接待、带看、认筹；
2. 是否代收意向金或定金（默认禁止，见节点 5）；
3. 是否代甲方签署商品房买卖合同或认购书；
4. 折扣权限是否以附件底价表为上限。

| 文本写法 | 动作 |
| --- | --- |
| “全权代理销售，权限以现场口头为准” | 红线。改成书面列举 |
| 授权代签买卖本约，但无合同范本、无网签账号归属 | 必须改：范本由甲方提供；网签以甲方账户完成；乙方签字不当然约束甲方，除非书面授权该次签署 |
| 销售现场不公示委托书和批准文件 | 必须改 |
| 个人销售顾问以自己名义接单收费 | 红线改为机构统一承接、统一收取佣金 |

修改句：

「甲方另行向乙方出具《商品房销售委托书》，载明项目名称、房号范围、委托期限、是否可代收任何款项、是否可代签认购书或买卖合同。乙方销售时须向买受人出示该委托书和房屋证明文件，并在销售现场明显位置公示。乙方销售人员不得以个人名义承接业务或收取费用。超出书面权限的口头承诺，对甲方不发生效力，由此造成的买受人索赔由乙方承担。」

最强反方：买受人主张表见代理，开发商仍可能对外担责。修改句不能写成“有排除口头承诺条款即对外免责”；对外风险仍须通过现场公示、合同范本控制和人员管理降低。对内追偿可以写清。

## 节点 4　开发商销售代理佣金（硬闸）

支持依据：第 928 条（完成事务支付报酬；不可归责解除或不能完成的，支付相应报酬，另有约定除外）；销售办法第 28 条（代理销售时不得收取佣金以外的其他费用）。

### 4.1 基数

| 文本写法 | 动作 |
| --- | --- |
| 只写“按成交额”或“按总价”，不区分网签合同总价、实际回款、备案价 | 必须改。三选一写死，并写折扣、优惠、车位是否计入 |
| 正文按网签总价，附件结算单按到账金额 | 版本冲突，并列，不选对用户有利的一版 |
| 允许乙方另向买受人收茶水费、咨询费、排队费 | 红线删除。现有依据不支持收取佣金以外费用 |

修改句：

「乙方代理佣金=附件《佣金结算流程》载明的计算基数×【待填】%。计算基数仅指【商品房买卖合同载明的成交总价 / 甲方实际收到的该套房屋购房款 / 该套房屋备案价】，【包含 / 不包含】甲方书面批准的折扣、车位和储藏室价款。乙方不得向买受人收取佣金以外的任何费用。」

### 4.2 节点、退佣与独家自销

| 文本写法 | 动作 |
| --- | --- |
| “协助办妥贷款后一次性结清全部佣金”，无分期 | 必须改：分节点，避免贷款迟延无限期占用佣金 |
| 买受人退房或面积差退款后，已结佣金不退 | 必须改：对应部分退还或从后期佣金扣回 |
| 独家代理，但甲方自行销售、关系户、员工内购是否付佣未写 | 必须改 |
| 非独家，多家代理抢同一客户未写登记规则 | 必须改：来访登记和客户保护期，不套用第 965 条居间跳单作为本类型主条文 |

修改句：

「佣金按套分节点支付：该套房屋【签署商品房买卖合同并完成网签】后支付【待填】%；该套房屋【首付款到达甲方监管账户】后支付【待填】%；【按揭放款到达甲方监管账户 / 全款到账】后支付剩余【待填】%。买受人退房、解除或因面积差退款的，乙方应在【待填】日内按同一口径退还已收取的对应佣金，或从后续应付佣金中扣回。独家代理期间，甲方自行销售、关系户或员工内购成交的，【仍按本条向乙方支付佣金 / 不支付佣金，但须在成交前书面通知乙方并列入对账单】。客户归属以双方盖章的《来访登记表》为准，保护期【待填】日；不得以民法典第 965 条居间跳单规则替代本条约定。」

禁止编造佣金比例和天数。阶梯费率可以保留，但去化率如何计量（认购未网签是否计入）必须写清。

最强反方：开发商主张“没回款就没佣金”；代理机构主张“网签即应付全部佣金”。现有依据支持双方约定；现有依据不支持沉默时按对一方有利的口径推定。

## 节点 5　资金不经手

支持依据：经纪管理办法（2016 修正）第 25 条第 7 项（不得侵占、挪用房地产交易资金）；销售办法第 22 条（不符合销售条件不得收取预订款性质费用）；城市房地产管理法第 45 条第 3 款（预售所得款项必须用于有关工程建设）。

| 文本写法 | 动作 |
| --- | --- |
| 乙方代收定金、房款后转付甲方 | 红线。改为买受人直接汇入甲方监管账户 |
| 房款进入乙方一般结算户或个人账户 | 红线 |
| 乙方可从房款中坐扣佣金 | 红线。佣金由甲方另行支付，不得截留购房款 |
| 仅代收意向金且进入甲方账户、当日对账 | 可谈；须书面授权、限额、当日清分、不得坐扣 |

修改句：

「买受人支付的意向金、定金和购房款，必须直接进入甲方名下的商品房预售资金监管账户或双方书面确认的甲方账户，账号【待填】。乙方不得代收、代持或坐扣上述款项，不得要求买受人向乙方或销售人员个人账户付款。佣金由甲方按节点 4 另行支付。」

用户坚持房款进代理公司账户仍称销售代理：整体停止。

定金：必须使用“定金”二字才讨论罚则。代理合同本身若约定履约保证金，适用第 586 条时不得超过该代理合同所担保债权的 20%，超过部分不产生定金效力。不得把购房定金 20% 上限误套成代理佣金总额的 20%。

## 节点 6　价格、宣传、格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 价格与宣传

支持依据：销售办法第 17 条；广告法第 26 条；房地产广告发布规定第 6、7、10 条；商品房买卖解释第 3 条（销售广告具体确定且对订约和价格有重大影响的，可构成要约）。

| 文本写法 | 动作 |
| --- | --- |
| 乙方可自行定价或突破底价 | 红线。最终定价权归甲方；执行价不得低于附件底价，也不得突破当地已公示备案价/一房一价 |
| 广告、推文、展板无须甲方书面审批 | 必须改 |
| 允许承诺升值、投资回报、学区、赠送面积、以时间表示位置 | 红线删除 |
| “乙方口头承诺对甲方无任何约束”且无审批和范本控制 | 必须改：对内追偿可写，对外不能靠一句免责了事 |

修改句：

「甲方拥有最终定价权。乙方只能在附件《销售底价表》和当地已公示的一房一价/备案价范围内执行，折扣须有甲方书面授权。所有对外宣传资料发布前须经甲方书面盖章审批。禁止在广告或话术中承诺升值或投资回报，禁止以到达某一参照物所需时间表示位置，禁止对规划或在建配套作误导宣传，禁止口头承诺学区、赠送面积或不载入买卖合同的优惠。因乙方或销售人员擅自承诺导致买受人索赔的，乙方应在甲方对外承担责任后【待填】日内向甲方偿付相应损失。」

地方一房一价细则未核：价格合规字段停止，不编造当地文号。

### 6.2 格式条款

为重复使用而预先拟定、订立时未与对方协商。从事经营活动的一方不得仅以“这次没用过第二次”否认。依据示范文本制作，不当然排除格式条款。

审查：免责、口头承诺排除、佣金成就单方解释、任意解除放弃、管辖/仲裁等异常条款是否有足以引起注意的标识，以及是否按要求说明（第 496 条；解释第 10 条）。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在附件 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

提供方对其已尽提示或说明承担举证责任。第 497 条无效情形、第 498 条不利解释：只在核验后作为修改理由，不代替修改句。

### 6.3 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的、是否仅行政管理、是否只规制履行行为（第 153 条；解释第 16、18 条）。禁止用已失效“效力性/管理性”口诀代替解释第 16 条。无证预售、返本销售、售后包租、首付贷、阴阳合同：不改写成有效履行。

## 节点 7　转委托、退出与任意解除

### 7.1 转委托与分销

支持依据：第 923 条。转委托须委托人同意或紧急为维护委托人利益。经同意的，受托人仅就选任和对第三人的指示负责；未经同意（紧急除外）的，受托人对转委托第三人的行为负责。

渠道分销不是默认权利。自行发展二级分销须书面同意，佣金不得因转委托增加买受人或甲方负担，责任不因转委托而消灭。

修改句：

「未经甲方事先书面同意，乙方不得将本项目销售代理转委托给第三人，也不得自行发展二级分销并对外使用甲方名义。经同意的，乙方仍就选任和对分销渠道的指示向甲方负责，且不得因此增加甲方应付佣金或向买受人加收费用。」

### 7.2 退出清算

合同终止后，代理机构须在约定期限内移交客户档案、未签文本、钥匙和现场物料。客户名单不得私自用于其他项目。

修改句：

「本合同终止或解除后【待填】日内，乙方应向甲方移交全部来访登记、客户资料、认购文本、钥匙和甲方提供的物料，并删除己方留存的复制件。乙方不得将客户资料用于其他项目。」

### 7.3 任意解除（配套，不是本类型主产品）

第 933 条：双方可以随时解除；有偿委托的解除方应赔偿对方的直接损失和合同履行后可以获得的利益，除非不可归责。修改句可约定通知期和赔偿计算方式。

**不得写成“双方放弃任意解除权且解除无效”。** 本任务不把一般委托的 933 公式展开成主审查产品；只在出现放弃解除或无偿随时解除时改句。

修改句：

「任何一方解除本合同，应提前【待填】日书面通知。除不可归责于解除方的事由外，解除方应赔偿对方因此受到的直接损失；有偿委托下还应赔偿合同履行后可以获得的利益，已按节点 4 应付的佣金不因解除而消灭。双方不得约定‘放弃任意解除权且解除无效’。」
