# 边界与路由

本技能只审查 **委托合同 / 房地产销售代理合同** 的待签文本。中文展示名是「审查房地产销售代理合同（委托合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 只报告订约机会或提供媒介，自己不成交一方；二手房/租赁带看撮合 | `房屋买卖_租赁中介合同·审查`。不得删撮合条款后继续当销售代理审 |
| 调研、产品定位、媒介投放、驻场销售捆成全案主给付 | `调研+策划+媒介推广+驻场销售捆成全案主轴→负触发`。不得删策划段落后硬套本技能 |
| 概括处理事务、代办年报、诉讼代理，销售只是顺带一句 | `一般委托合同·审查` |
| 只做渠道带客分销，不驻场，不以开发商销售代理身份对外 | `只带客结佣不驻场不以开发商销售代理身份对外→负触发` |
| 主文件是商品房买卖本约（价款、交房、办证） | `或对应买卖原子；` 或对应买卖原子 |
| 以自己名义买卖房屋并吃差价 | `行纪合同·审查` 或回引擎 |
| 无文本、本类型条件已谈妥、要出己方稿 | `房地产销售代理合同·起草` |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

销售代理正文里夹带一小段买卖本约价款、交房或广告投放：专条交接对应原子；开发商委托人、委托书权限、佣金、备案、资金账户条款可继续审。用户坚持本技能把中介、全案、一般委托、渠道或商品房本约整案改完：`目标停止`。
