# 边界与路由

本技能只审查 **互联网相关合同 / 隐私政策** 的待签文本。中文展示名是「审查隐私政策（互联网相关合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 最终用户协议、EULA、软件许可、账号规则、UGC 授权、内容禁令、责任限额 | `最终用户协议·审查`。本任务不审许可或免责限额 |
| 用户协议/服务条款为正文，隐私仅嵌入数句，用户要审整份服务条款 | `最终用户协议·审查`；同时告知隐私须独立成文，独立文本再回本技能 |
| 标题是隐私政策，正文夹带大段许可、封号、UGC 永久授权 | 留本任务审处理规则；许可/UGC 整段交接 `最终用户协议·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 留本任务起草并自审 |
| 用户只要整包网站条款+隐私从零起草 | 点名 `件已谈妥要出己方稿→留本任务起草并自审；需要整包网站条款+隐私起草时只点名`；本任务不代写 |
| 已上线未争、只问弹窗留痕、清单更新、版本公示 | 本套导航的履约步骤 |
| 已向网信/工信投诉、要举报材料或索赔策略 | `或对应争议原子；名誉人肉另转`。本技能不审投诉策略 |
| 人肉、侮辱诽谤、肖像与网络名誉 | `或对应争议原子；名誉人肉另转` |
| 已成争的普通合同路径 | `或对应专项领域。` 或对应领域，不继续签前审查 |
| C 端大众快检 | 只分流，不回改 |

本约夹带 EULA 附件：附件整段交接 `最终用户协议·审查`；隐私正文继续审。用户坚持本技能给出许可条款、投诉胜率、罚款终值或出境评估申报表：`目标停止`。
