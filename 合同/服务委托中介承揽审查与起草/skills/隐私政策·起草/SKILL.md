# 隐私政策·起草

## 任务目标

在单一立场下，只起草 **互联网相关合同 / 隐私政策** 的待签文本（处理者公示的个人信息处理规则，或用户即将同意的同一文本），按已谈妥条件出己方稿，输出可编辑草稿、未决项；出稿后必须用本类型硬闸自审，输出风险表和修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查隐私政策（互联网相关合同）」。本技能不代替审查最终用户协议（那是 `最终用户协议·审查`）。

`depends-on` 为空。不要求先跑导航。

不交付：最终用户协议审查、用户服务协议审查、待签文本签前审查整份政策、履约交底、投诉/举报/公益诉讼策略、行政处罚应对、数据出境安全评估申报材料、有效性保证、把嵌入式隐私句改成可履行的 EULA。

## 本类型硬闸

1. **告知同意**：处理规则须独立、完整、易于访问；处理前以显著方式、清晰易懂语言告知处理者名称与联系方式、目的、方式、种类、保存期限和权利路径。基于同意处理的，同意须在充分知情前提下自愿、明确作出；禁止默认勾选、概括授权、“使用即同意全部可能产生的信息”。不得因个人不同意或撤回非必要处理而拒绝基本功能。
2. **敏感个人信息**：生物识别、宗教信仰、特定身份、医疗健康、金融账户、行踪轨迹，以及不满十四周岁未成年人的个人信息，须单独同意，并告知必要性与对个人权益的影响。不得与注册主同意捆成一次勾选。
3. **出境**：文本声称或可推知向境外提供的，须点名境外接收方、告知目的/方式/种类与行权路径，并取得单独同意；机制上须具备安全评估、保护认证、标准合同或其他法定条件，或落入 2024 年免予申报/订立/认证的情形。禁止写“全球自由传输、无需评估或告知”。
4. **与最终用户协议 `最终用户协议·审查` 切开**：本技能只评改个人信息处理的告知、同意、敏感信息、共享/SDK、出境、保存删除、查阅更正撤回注销。软件许可、账号规则、UGC 授权、内容禁令、服务中断、责任限额走 `最终用户协议·审查`。仅在用户协议里夹几句隐私表述：点名必须独立成文，不在本任务把 EULA 审完。

配套约束：不满十四周岁须有专门处理规则并取得监护人同意。向其他处理者提供须告知接收方并取得单独同意。必须提供便捷撤回同意与账号注销路径。禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签《隐私政策》《个人信息保护政策》或同等独立处理规则，尚未对用户生效或尚未作为本次上线/改版的同意文本，尚未成争，核心给付是告知并规范个人信息处理，用户问能不能公示/同意、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 核心给付是软件许可、账号使用、UGC、内容规则、责任限额 → `最终用户协议·审查`；
- 标题为用户协议/服务条款，隐私只是其中一节且用户要审整份服务条款 → `最终用户协议·审查`，并告知隐私须独立成文后回到本技能；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；需要整包网站条款+隐私起草时只点名 `件已谈妥要出己方稿→留本任务起草并自审；需要整包网站条款+隐私起草时只点名`，本任务不代写；
- 已上线只问版本公示、同意弹窗留痕、清单更新等履约节点 → 本套导航的履约步骤；
- 已向网信/工信投诉、已立案、已发律师函索赔、已提公益诉讼 → `或对应争议原子；名誉人肉另转` 或对应争议原子；名誉/人肉另转 `或对应争议原子；名誉人肉另转`；
- 类型未定 → 本套导航的类型切开步骤。

假独立（标题是隐私政策，正文大量许可、封号、UGC 永久授权）：留本任务审处理规则部分；许可/UGC 整段交接 `最终用户协议·审查`。用户改口要审整份 EULA：目标停止，交接 `最终用户协议·审查`。

规避监管（伪造同意日志、拆分出境规模规避评估、把敏感信息改称“非敏感”仍要放行）：告知并停止改写成可履行规避结构。

## 建立审查坐标

确认：使用者与授权；单方立场（处理者或用户/信息主体择一）；相对方；全文及附件版本（含收集清单、第三方共享/SDK 清单、儿童规则、出境说明）；产品基本功能与扩展功能；是否处理敏感信息；是否出境或跨境存储；同意交互（主动勾选/默认勾选/使用即同意）；不可接受事项；法域与拟生效日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的接收方名称、保存期限、出境规模用 `【待填】`，不编造。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。引用《个人信息保护法》时，使用 2021-08-20 公布、2021-11-01 施行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验个保法第十三至十七、二十三、二十八至三十一、三十八、三十九、四十四至四十七条，以及《网络数据安全管理条例》第二十一、二十二、三十五条和《促进和规范数据跨境流动规定》第五、十条；`search_practiced` 只补审查反例，不写投诉或应诉策略；`search_template` 只借隐私政策栏目结构，不得粘贴电商或中介站点政策正文，不得粘贴 EULA 范本。不虚构案件系统。

`search_law` 对上述法律结论为 required 级：不可用时不拒绝执行，只停止效力字段。返回已失效《合同法》或其解释时记为噪声，不得写入 `L#`。


## 起草模式

本原子只承担本类型起草。待签评改转 `隐私政策·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `隐私政策·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。需要整包网站条款+隐私起草时只点名 `件已谈妥要出己方稿→留本任务起草并自审；需要整包网站条款+隐私起草时只点名`，本任务不代写。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。下文「起草必写 / 附件必附 / 禁止出现」即本类型硬闸的落稿口径。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 处理规则独立、完整、易于访问。处理前以显著方式、清晰易懂语言告知处理者名称与联系方式、目的、方式、种类、保存期限和权利路径。
- 基于同意处理的，同意须在充分知情前提下自愿、明确作出。不得因个人不同意或撤回非必要处理而拒绝基本功能。
- 生物识别、宗教信仰、特定身份、医疗健康、金融账户、行踪轨迹，以及不满十四周岁未成年人的个人信息：单独同意，并告知必要性与对个人权益的影响。
- 文本声称或可推知向境外提供的：点名境外接收方，告知目的／方式／种类与行权路径，并取得单独同意；机制上须具备安全评估、保护认证、标准合同或其他法定条件，或落入 2024 年免予申报／订立／认证的情形。
- 向其他处理者提供须告知接收方并取得单独同意。必须提供便捷撤回同意与账号注销路径。
- 不满十四周岁须有专门处理规则并取得监护人同意。

### 附件必附

- 收集清单、第三方共享／SDK 清单。
- 处理儿童信息时：专门处理规则。
- 声称或可推知出境时：出境说明（接收方、目的／方式／种类、行权路径、机制或豁免）。

### 禁止出现

- 默认勾选、概括授权、“使用即同意全部可能产生的信息”。
- 敏感信息与注册主同意捆成一次勾选。
- “全球自由传输、无需评估或告知”。
- 把敏感信息改称“非敏感”仍要放行；伪造同意日志；拆分出境规模规避评估。
- 把软件许可、账号规则、UGC 授权、内容禁令、服务中断、责任限额写进隐私政策主路径。

### 0. 签署状态与成果分流

无书面文本 → 起草；已上线只问履约留痕 → 本套导航履约步骤；已投诉/立案/索赔 → 投诉或争议原子。未生效或本次改版待同意，且目标是评改已有隐私政策，本任务只起草，评改待签文本转配对 ·审查 原子。

### 1. 类型锁死与切开

标题、核心给付与本类型一致才继续。EULA / 用户协议负触发 `最终用户协议·审查`。假独立留本任务并点名。

### 2. 告知同意

独立成文；告知事项齐；同意自愿明确；禁止默认勾选与概括授权；基本功能与扩展功能分开。

### 3. 敏感个人信息

单独同意；告知必要性与影响；儿童信息按敏感并设专门规则。

### 4. 出境

点名境外接收方；单独同意；机制或豁免可核验；不得保证已通过评估。

### 5. 共享、SDK、权利与注销

第三方清单；查阅复制更正删除撤回注销路径；撤回难度不得高于同意。

### 6. 儿童与重大变更

不满十四周岁专门规则与监护人同意；重大变更须再次显著征求同意。

### 7. 争议条款

管辖可改写法；不审投诉策略。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持默认勾选或概括授权、拒绝敏感/出境单独同意、伪造同意日志、拆分出境规避评估、保证有效或倒签生效日。
- `字段停止`：法域、出境规模与是否属于关键信息基础设施、保存期限数字、SDK 实际收集字段未核验。
- `目标停止`：主目标已变为评改待签文本、履约交底、EULA 审查、投诉或应诉策略、出境评估申报。
