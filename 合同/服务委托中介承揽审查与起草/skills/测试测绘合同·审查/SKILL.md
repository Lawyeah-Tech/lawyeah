# 测试、测绘合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》承揽章、《加工承揽合同条例》、《经济合同法》、1992/2002《测绘法》或《测绘资格审查认证管理规定》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **承揽合同 / 测试、测绘合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查测试、测绘合同（承揽合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类合同审查；从零起草；履约交底；争议文书；有效性保证；把鉴定、施工、勘察、建工咨询或加工文本改完；把无测绘资质、挂靠或涉密未审批改成可履行结构。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **测绘资质**：从事测绘活动须依法取得相应等级《测绘资质证书》，且不得超越资质等级许可范围、不得以其他单位名义或允许他人以本单位名义作业、不得向他人转让测绘项目。证书未出示或专业类别不覆盖本项目：字段停止，不得写“可以施测”。无资质、超范围、挂靠仍要放行：只告知，不改成可履行。软件/产品内部测试不套测绘资质，但对外出具具有证明作用的数据和结果须核验 CMA 范围。
2. **成果交付**：核心给付是交付可核验的工作成果（测试报告、测绘图纸、矢量数据或数据集），不是出咨询意见、不是鉴定意见、不是施工作业。必须落到载体、份数、坐标系/精度或测试指标、交付日、签收与验收、异议期；签收、付款或下游采用不当然等于验收。第 780 条要求交付成果并提交必要技术资料和质量证明。
3. **与鉴定 / 施工切开**：针对诉讼、仲裁或行政执法争议事项出具鉴定意见 → `检验鉴定合同·审查`。施工许可范围内的建设工程作业 → `工地建筑活动承包资质竣工验收→`。为工程设计查明地质、水文、岩土条件并编制勘察文件 → `为工程设计查明地质水文岩土条件并编制勘察文件→`。只出可行性、造价或管理咨询意见、不交付测绘/测试成果 → `只出可行性造价或管理咨询意见不交付测绘测试成果→`。来料制成新物 → `加工合同·审查`。禁止删掉邻类主给付后硬套本技能。禁止抄加工来料定额或建工咨询意见交付主路径。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签测绘合同、检测/测试服务协议或地籍/房产/竣工测绘、软件压力测试正文，尚未签署，尚未成争；核心给付是承揽人用专业设备完成数据采集与分析并交付报告、图纸或数据集。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 针对争议事项出具鉴定意见、司法鉴定委托 → `检验鉴定合同·审查`；
- 施工许可范围内的建设工程、主体结构作业 → `工地建筑活动承包资质竣工验收→`；
- 为工程设计查明地质水文岩土并编制勘察文件 → `为工程设计查明地质水文岩土条件并编制勘察文件→`；
- 只出可行性、造价、全过程或项目管理咨询意见 → `只出可行性造价或管理咨询意见不交付测绘测试成果→`；
- 定作人供料制成新物或改变形态 → `加工合同·审查`；
- 按图从无到有制作新物、承揽人备料 → `定作合同·审查`；
- 修复既有损坏物 → `修理合同·审查`；
- 复制既有作品或载体 → `复制合同·审查`；
- 印刷 → `印刷合同·审查`；
- 只提供可行性论证或预测评价、不保证交付测试/测绘成果 → `委托技术咨询·审查` / `或`；
- 用现有技术解决特定技术问题、不交付测绘图纸或测试数据集 → `委托技术服务·审查` / `或`；
- 无文本、本类型条件已谈妥、要出己方稿 → `测试测绘合同·起草`；
- 已签只问进场日、出图日、汇交日、尾款日 → 本套导航的履约步骤；
- 已催告、解除、索赔、留置变价、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

挂靠测绘资质、出借证书、转让测绘项目、无保密审批从事涉密测绘：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（定作人或承揽人择一）；相对方；全文及技术大纲、测区范围图、样品清单、资质证书复印件版本；是测绘还是测试；测区/样品是否特定；成果载体与精度/指标；测绘资质或 CMA 痕迹；是否涉密或需汇交；报酬是按面积/测点还是包干；是否排除 787；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价金、面积、精度、份数用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验承揽定义与测试种属、780 交付成果、787、质量与报酬、留置与保管、格式条款、定金上限、测绘法第 27/29/33/34 条、测绘成果汇交、CMA 范围、强制规范；`search_practiced` 只补审查反例（测试报告 ≠ 鉴定意见、无成果不得请酬）；`search_template` 只借测绘合同栏目结构。不虚构案件系统。

`search_law` 对上述法律结论为 required 级：不可用时不拒绝执行，只停止效力字段。返回已失效《合同法》承揽章、《加工承揽合同条例》、《经济合同法》、1992/2002《测绘法》或《测绘资格审查认证管理规定》时记为噪声，不得写入 `L#`。

禁止打开其他类型目录。`基本面.md` 中“无测绘资质则合同可能因违反效力性强制性规定而无效”不得写成当然无效；须按民法典第 153 条和合同编通则解释第 16 条区分行政责任与民事效力。`框架.md` 中“甲/乙/丙/丁”含旧分级残留，等级以证书载明及运行时核验为准，不得把丙、丁级写成现行默认可核验档。成果“通常归定作人”不是法定默认，必须落句。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `测试测绘合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有测试、测绘文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。必须先确认交付测试/测绘成果，再与鉴定、施工、勘察、建工咨询、加工切开。

### 2. 主体、测绘资质与授权

签约名、履行名、付款名、发票名分列。测绘资质证书等级与专业类别、CMA 能力范围未核：字段停止。无资质测绘、挂靠、转让项目：只告知，不改成可履行。

### 3. 测区 / 样品与技术指标

测区四至或样品身份、坐标系/精度或测试指标、技术大纲入附件。口头“按国标测一下”不得写成已特定。

### 4. 成果交付

载体、份数、格式、交付日、签收与验收、异议期、坐标转换责任分列。无成果交付闭环不得写成已可履行。

### 5. 对价、汇交与质保

面积/测点或包干分列；尾款与验收挂钩；汇交法定职责不得写成可放弃；下游未采信不得自动视为未验收。

### 6. 787、格式条款与强制规范

保留完成工作前的解除与损失赔偿。无核验引文则法律结论字段停止。

### 7. 质量、保管、留置、保密与争议

精度不达标须无偿补测/重测；784 期间毁损；783 留置须另约定催告期限，未约定不得短于六十日；涉密成果禁止公有云或普通外网传输。不选定唯一法院充作意见。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效或保证成果必然被行政机关采信、把无测绘资质、挂靠、转让测绘项目或未审批涉密测绘改成可履行结构。
- `字段停止`：法域、动态规则、测绘资质/CMA 范围、涉密等级、汇交机关、测区是否进入军事或保密范围未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁鉴定/施工/勘察/建工咨询/加工。
