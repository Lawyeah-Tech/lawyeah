# 边界与路由

本技能只审查 **承揽合同 / 测试、测绘合同** 的待签文本。中文展示名是「审查测试、测绘合同（承揽合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 针对诉讼、仲裁、行政执法争议事项出具鉴定意见或司法鉴定委托 | `检验鉴定合同·审查`。P1：专业版未装则 `unavailable`，提示，不得用本技能把测试报告改成鉴定意见 |
| 施工许可范围内的建设工程、主体结构作业 | `工地建筑活动承包资质竣工验收→` |
| 为工程设计查明地质、水文、岩土条件并编制勘察文件 | `为工程设计查明地质水文岩土条件并编制勘察文件→` |
| 只出可行性、造价、全过程或项目管理咨询意见，不交付测绘/测试成果 | `只出可行性造价或管理咨询意见不交付测绘测试成果→`。禁止用本技能抄建工咨询意见交付主路径 |
| 定作人供料，由对方制成新物或改变形态 | `加工合同·审查`。禁止抄加工来料定额主路径 |
| 按图从无到有制作新物，承揽人备料 | `定作合同·审查` |
| 修复既有损坏物 | `修理合同·审查` |
| 复制既有作品或载体 | `复制合同·审查` |
| 印刷 | `印刷合同·审查` |
| 只提供可行性论证、预测或评价，不保证交付测试/测绘成果 | `委托技术咨询·审查` 或 `或` |
| 用现有技术解决特定技术问题，不交付测绘图纸或测试数据集 | `委托技术服务·审查` 或 `或` |
| 贴牌批量生产 | `定牌加工（OEM）合同·审查` |
| 类似建筑工程的简易新建、构筑物施工 | `项目承揽合同·审查` |
| 框架协议下多笔订单，本单不是单次测试或单测区测绘 | `框架加订单承揽·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `测试测绘合同·起草` |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争，含催告、留置变价、索赔、诉讼仲裁 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

测绘或测试正文里夹带一小段样品采购：样品所有权专条可交接 `通用型号现货卖方组织生产买方不控制过程→`；测区施测、报告交付、资质、787 可继续审。用户坚持本技能把鉴定、施工、勘察、建工咨询或加工整案改完：`目标停止`。
