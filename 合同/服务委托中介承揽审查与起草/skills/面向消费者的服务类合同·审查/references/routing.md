# 边界与路由

本技能只审查 **服务合同 / 面向消费者的服务类合同**。负触发只写判定、完整 Skill ID 和最小交接，不填十节实体结论。专业版未装的 P1 原子输出 `unavailable`，不得用邻类硬套。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 无文本、本类型条件已谈妥、要出己方稿 | `面向消费者的服务类合同·起草` |
| 已签未争、预约/扣次/发票留痕 | 本套导航的履约步骤 |
| 已成争（催告、解除、索赔、诉讼仲裁） | `或对应专项领域。` 或对应专项领域 |
| 消费者个人已关店/拒退、要第一轮追偿 | 只分流 `或`（预付关停）或 `或`（当次服务退费）；不回改 C 端 |
| 调研报告、管理建议、不到店兑付 | `咨询服务合同·审查` |
| 广告合同无法再分 | `广告合同（广义）·审查` |
| 广告创意、设计稿 | `广告设计合同·审查` |
| 广告拍摄、成片制作 | `广告制作合同·审查` |
| 媒介发布、版面投放 | `广告发布合同·审查` |
| 广告代言 | `广告代言服务类合同·审查` |
| 广告代理排期、媒介购买 | `广告代理合同·审查` |
| 互联网广告投放 | `互联网广告类合同·审查` |
| 住宅小区物业费、前期物业 | `住宅小区物业费公共部位前期物业→` |
| 以委托人名义处理事务 | `一般委托合同·审查` |
| 自己名义贸易、寄售 | `行纪合同·审查` |
| 统一经营模式+特许经营费+经营手册（加盟本约） | 回引擎重新定性；预付解释第 5 条仅处理特许体系对**消费者**的兑付，不代审加盟合同 |
| C 端 029／030／032 | 只分流，不回改 |

夹带：消费办卡正文另附咨询报告或广告投放附件的，附件转对应原子；办卡部分可继续审。不得删掉附件后宣称整案已按本类型审完。
