# 边界与路由

本技能只审查 **服务合同 / 广告代言服务类合同** 的待签文本。中文展示名是「审查广告代言服务类合同（服务合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 版面、时段、刊播位置、媒体排期换价款，不以自身名义推荐 | `广告发布合同·审查` |
| 交付设计稿 | `广告设计合同·审查` |
| 交付成片、喷绘、物料制作，不评价商品 | `广告制作合同·审查` |
| 媒介购买、代理发布、佣金按刊例，无人格标识推荐 | `广告代理合同·审查` |
| 信息流、效果广告、平台投放为主轴 | `互联网广告类合同·审查` |
| 多种广告给付并列且代言不是主轴 | `广告合同（广义）·审查` 或引擎重新定性 |
| 无拍摄义务、不评价商品、仅许可使用已有肖像 | 引擎重新定性。作品许可主轴 → `或` |
| 考勤、工资、社保、人格从属 | `与劳动合同个人劳务切开：考勤+固定底薪+人身从属为主轴→负触发` |
| 计时劳务、一场演出劳务、无推荐证明 | `平等主体个人劳务且无演艺机会媒介→负触发` 或引擎；不得按代言审 |
| 艺人与经纪公司之间的独家经纪、分成、档期 | `演绎经纪中介合同·审查`。专业版未收录则 `unavailable`，提示，不得硬套本类 |
| 咨询意见、不推荐商品 | `咨询服务合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 留本任务起草并自审 |
| 已签未争、只问通告/付款/下架节点 | 本套导航的履约步骤 |
| 已成争 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

代言正文里夹带一小段拍摄制作或单一媒介排期：专条交接制作/发布原子；真实使用、连带追偿、肖像许可范围条款可继续审。用户坚持本技能把发布、制作、代理、劳动或单纯肖像整案改完：`目标停止`。
