# 广告代言服务类合同·起草

## 任务目标

在单一立场下，只起草 **服务合同 / 广告代言服务类合同** 的待签文本，按已谈妥条件出己方稿，输出可编辑草稿、未决项；出稿后必须用本类型硬闸自审，输出风险表和修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文名必须是「审查广告代言服务类合同（服务合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类合同审查；待签文本签前审查；履约交底；争议文书；有效性保证；把广告发布、广告制作、广告设计、广告代理、互联网投放、单纯肖像许可、劳动合同或演绎经纪整案改完；把未使用即推荐、禁止代言品类或阴阳合同改成可履行结构。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **代言人真实使用义务**：代言人在广告中以自己的名义或形象作推荐、证明的，必须已经使用过该商品或接受过该服务。合同不得写“无需使用即可推荐”“样品未交付也可口播功效”。拒绝使用却要求推荐的，代言人可拒绝履行推荐义务且不构成违约。医疗、药品、医疗器械、保健食品不得利用代言人作推荐证明：停笔，不改写成可履行代言。不满十周岁不得作为代言人；因虚假广告受行政处罚未满三年的不得再作代言人。
2. **广告法连带**：关系消费者生命健康的商品或服务的虚假广告，代言人可能与广告主连带；其他商品或服务须代言人明知或应知虚假仍推荐才连带。合同可约定广告主保证真实、交付检测/许可文件、代言人有审核权，以及代言人已尽审核且真实使用后被追索可向广告主追偿。禁止约定“代言人对广告内容不负任何责任、消费者一律找广告主”来对抗第三人。明知虚假仍代言的，不得免责。
3. **肖像授权**：使用姓名、肖像、声音须事先取得书面同意；无民事行为能力人或限制民事行为能力人须监护人书面同意。许可须封闭标识类型、商品 SKU、媒介、地域、期限、是否含包装/电商主图、是否可再许可。未列明的权利不得行使。禁止“永久、全球、所有媒介、可再许可、可训练模型”的买断。只有经纪公司盖章、艺人未签或未出具不可撤销授权的，许可效力不足。到期须固定库存消化期并下架，不得“用完为止”。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签广告代言、形象代言正文，尚未签署，尚未成争，核心给付是以自己名义或形象对商品、服务作推荐证明，并许可人格标识在约定期限和媒介上使用，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 版面、时段、刊播位置换价款，不以自身名义推荐 → `广告发布合同·审查`；
- 交付设计稿、成片、喷绘实物，不评价商品 → `广告设计合同·审查` 或 `广告制作合同·审查`；
- 媒介购买、排期、代理发布而无人格标识推荐 → `广告代理合同·审查`；
- 信息流/效果投放、平台刊播为主轴 → `互联网广告类合同·审查`；
- 名实混杂、多种广告给付并列且代言不是主轴 → `广告合同（广义）·审查` 或 本套导航的类型切开步骤；
- 无拍摄义务、不评价商品、仅许可使用已有肖像 → 本套导航的类型切开步骤 重新定性；作品许可主轴 → `或`；
- 考勤管理、只拿工资、人格从属 → `与劳动合同个人劳务切开：考勤+固定底薪+人身从属为主轴→负触发`；计时劳务、无推荐证明 → `平等主体个人劳务且无演艺机会媒介→负触发`；
- 艺人与经纪公司之间的独家经纪、分成、档期管理 → `演绎经纪中介合同·审查`（P1；专业版输出 `unavailable`，提示，不得用本类硬套）；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问通告日、付款日、下架日 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

未使用即推荐、禁止代言品类、阴阳合同逃税、倒签或补假授权：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（广告主侧或代言人/经纪侧择一）；相对方；全文及附件/产品清单/许可要素表/经纪授权/样品签收版本；是否以自己名义或形象作推荐证明；商品或服务品类是否属于禁止代言；是否已真实使用或安排体验；肖像/姓名/声音授权范围；艺人是否亲签；未成年人或三年禁代言痕迹；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的签约金、拍摄天数、媒介清单、期限用 `【待填】`，不编造。

## 起草模式

本原子只承担本类型起草。待签评改转 `广告代言服务类合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `广告代言服务类合同·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 代言人在广告中以自己的名义或形象作推荐、证明的，必须已经使用过该商品或接受过该服务。拒绝使用却要求推荐的，代言人可拒绝履行推荐义务且不构成违约。样品交付、体验记录、发布前使用证据必须可回链。
- 广告主保证真实、交付检测／许可文件；代言人有审核权。关系消费者生命健康的虚假广告，代言人可能与广告主连带；其他商品或服务须明知或应知虚假仍推荐才连带。已尽审核且真实使用后被追索的，可向广告主追偿。
- 使用姓名、肖像、声音须事先取得书面同意；无／限制民事行为能力人须监护人书面同意。许可须封闭标识类型、商品 SKU、媒介、地域、期限、是否含包装／电商主图、是否可再许可。未列明的权利不得行使。艺人须亲签或出具不可撤销授权。
- 到期须固定库存消化期并下架。成片／推荐用语书面确认。

### 附件必附

- 经纪授权、产品清单、许可要素表（商品×媒介×期限）、样品签收单、广告稿、形象照规格。缺艺人亲签或不可撤销授权的，不起可履行许可稿。

### 禁止出现

- “无需使用即可推荐”“样品未交付也可口播功效”。
- 医疗、药品、医疗器械、保健食品利用代言人作推荐证明；不满十周岁作为代言人；因虚假广告受行政处罚未满三年再作代言人。
- “代言人对广告内容不负任何责任、消费者一律找广告主”；明知虚假仍代言的免责。
- “永久、全球、所有媒介、可再许可、可训练模型”的买断；“用完为止”。
- 阴阳合同逃税、倒签或补假授权。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 留本任务起草并自审；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有代言文本；本任务只起草，评改待签文本转配对 ·审查 原子。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。广告发布、制作、设计、代理、互联网投放、单纯肖像许可、劳动/劳务、演绎经纪负触发。

### 2. 主体、经纪授权与未成年人

签约名、履行名、付款名、发票名分列。艺人未签且无不可撤销授权：红线。不满十周岁：停笔。禁止代言品类：停笔。

### 3. 真实使用义务

样品交付、体验记录、发布前使用证据必须可回链。未使用即推荐：红线。

### 4. 肖像授权与许可范围

书面同意、要素封闭、期限明确、禁止永久买断和无限转授权。争议解释有利于肖像权人。

### 5. 广告法连带与审核追偿

广告主保证真实；代言人审核权；已尽审核可追偿；不得以免责对抗消费者。

### 6. 确认权、下架、对价、格式条款与强制规范

成片/推荐用语书面确认。到期下架。定金不超过 20%。无核验引文则法律结论字段停止。

### 7. 违约、道德条款与争议解决

超范围按日计费并立即下架。道德解除须客观可识别。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、未使用即推荐、禁止代言品类、阴阳合同、永久买断人格权或“对消费者免责”。
- `字段停止`：法域、动态规则、商品是否属于禁止代言品类、三年禁代言处罚记录、经纪授权原件未核验。
- `目标停止`：主目标已变为评改待签文本、履约交底、争议文书，或已锁他类。
