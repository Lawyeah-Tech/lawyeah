# 边界与路由

本技能只审查 **服务合同 / 互联网广告类合同** 的待签文本。中文展示名是「审查互联网广告类合同（服务合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 电视台、报刊、户外灯箱等传统媒介按档期/秒数/版面刊播 | `广告发布合同·审查`。不得删“互联网”字样后继续当本类型审，也不得把传统刊播整案改完 |
| 媒介代理招揽客户、销售档期、收佣金，不控制展示界面 | `广告代理合同·审查` |
| 交付设计稿或创意方案，按件计酬，无投放界面 | `广告设计合同·审查` |
| 交付成片、喷绘、母带等制作成品，不按 CPM/CPC 结算 | `广告制作合同·审查` |
| 人格标识许可并推荐、证明 | `广告代言服务类合同·审查` |
| 只有广告活动总览，未落到互联网投放单元 | `广告合同（广义）·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 留本任务起草并自审 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

互联网投放正文里夹带一小段传统刊播档期：专条交接 `广告发布合同·审查`；标识、弹窗、落地页、档案、计费、人群包条款可继续审。用户坚持本技能把传统发布、代理、设计、制作或代言整案改完：`目标停止`。
