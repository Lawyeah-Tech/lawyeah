# 互联网广告类合同·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《互联网广告管理暂行办法》（2016）、《合同法》及其解释当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只起草 **服务合同 / 互联网广告类合同** 的待签文本，按已谈妥条件出己方稿，输出可编辑草稿、未决项；出稿后必须用本类型硬闸自审，输出风险表和修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文名必须是「审查互联网广告类合同（服务合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、待签文本签前审查、履约交底、争议文书、有效性保证、把传统广告发布/广告代理/设计制作/代言整案改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **与传统发布切开**：核心给付是通过网站、网页、互联网应用程序等互联网媒介推销商品或服务。电视台、报刊、户外灯箱按档期/秒数/版面刊播 → 负触发 `广告发布合同·审查`。不得用漏播补刊或频道秒数主路径审信息流、搜索、开屏。
2. **现行《互联网广告管理办法》**：总局令第 72 号，2023-05-01 施行。2016 年暂行办法已废止。不得再引 2016 办法，不得写成“技术服务协议”逃避广告法。
3. **弹出 / 链接标识**：广告应可识别；竞价排名须显著标明“广告”并与自然结果区分；种草带购买链接同样标明；弹出及开屏须显著关闭标志并一键关闭；含链接广告须核对下一级链接与落地页。不得约定隐藏标识、多次点击关闭或只审素材不审落地页。
4. **角色分层与核对档案**：广告主对真实性负责；经营者/发布者查验证明、核对内容，档案自发布终了之日起不少于三年；平台经营者监测制止。不得用“技术中立、概不审核”排除法定义务。平台审核不等于行政审查；法定审查类先证后投。
5. **计费与预存性质**：预存广告费是预付款，不是定金。CPM/CPC/CPA 须定义有效口径和无效点击/作弊剔除。禁止单方后台数据为唯一结算依据。
6. **数据与禁投停笔**：定向人群包须有合法基础，不得约定违法交付个人信息。烟草（含电子烟）、处方药（另有规定除外）、未审医疗/药品/器械/保健食品/特医食品、政务搜索插入竞价：停笔。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签互联网广告投放、信息流、搜索、开屏/插屏、程序化采买或邮件广告正文，尚未签署，尚未成争，核心给付是通过互联网媒介推销商品或服务，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 电视台、报刊、户外灯箱等传统媒介按档期/秒数/版面刊播 → `广告发布合同·审查`；不得删“互联网”字样后硬套本技能，也不得把传统刊播当本类型改完；
- 媒介代理招揽客户、销售档期、收佣金，不控制展示界面 → `广告代理合同·审查`；
- 交付设计稿或创意方案、按件计酬、无投放界面 → `广告设计合同·审查`；
- 交付成片、喷绘、母带等制作成品、不按 CPM/CPC 结算 → `广告制作合同·审查`；
- 人格标识许可并推荐证明 → `广告代言服务类合同·审查`；
- 只有广告活动总览、未落到互联网投放单元 → `广告合同（广义）·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问对账日、消耗导出、下线节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

隐藏标识、未审先投、烟草/处方药互联网广告、违法交付个人数据：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（广告主、经营者/代理、发布者/平台或信息服务提供者择一）；相对方；全文及创意规格/落地页清单/监测对接/数据附录版本；媒介形态；是否标明广告及弹窗关闭；落地页是否纳入审核；档案保存期限；计费口径与预存性质；人群包来源；是否法定审查品类；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的单价、预算、时限用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验《互联网广告管理办法》第 2、4、6–10、13–18 条、广告法第 14、32、43、44 条、格式条款、定金上限、强制规范；`search_practiced` 只补审查反例；`search_template` 只借栏目结构。不虚构案件系统。

`search_law` 对上述法律结论为 required 级：不可用时不拒绝执行，只停止效力字段。返回已失效 2016《互联网广告管理暂行办法》、1994 年广告法对应旧条或已失效《合同法》及其解释时记为噪声，不得写入 `L#`。


## 起草模式

本原子只承担本类型起草。待签评改转 `互联网广告类合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `互联网广告类合同·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 核心给付是通过网站、网页、互联网应用程序等互联网媒介推销商品或服务。写清广告主、经营者、发布者或平台信息服务提供者角色。不得用漏播补刊或频道秒数主路径写信息流、搜索、开屏。
- 广告应可识别；竞价排名须显著标明“广告”并与自然结果区分；种草带购买链接同样标明；弹出及开屏须显著关闭标志并一键关闭；含链接广告须核对下一级链接与落地页。
- 广告主对真实性负责；经营者／发布者查验证明、核对内容，档案自发布终了之日起不少于三年；平台经营者监测制止。法定审查类先证后投。平台审核不等于行政审查。
- 预存广告费是预付款，不是定金。CPM／CPC／CPA 须定义有效口径和无效点击／作弊剔除。不得以单方后台数据为唯一结算依据。
- 定向人群包须有合法基础。

### 附件必附

- 广告法合规清单、禁投品类、监测对接说明、隐私与数据附录、批文。法定审查类缺批文不起投放稿。

### 禁止出现

- 再引 2016 年《互联网广告管理暂行办法》，或写成“技术服务协议”逃避广告法。
- 隐藏标识、多次点击关闭、只审素材不审落地页。
- “技术中立、概不审核”。
- 烟草（含电子烟）、处方药（另有规定除外）、未审医疗／药品／器械／保健食品／特医食品、政务搜索插入竞价。
- 约定违法交付个人信息的人群包。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 留本任务起草并自审；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有互联网广告文本；本任务只起草，评改待签文本转配对 ·审查 原子。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。传统刊播、媒介代理、设计/制作承揽、代言、广义总览负触发。

### 2. 主体、角色与资质

签约名、履行名、付款名、发票名分列。写清广告主、经营者、发布者或平台信息服务提供者。资质/批文未核：字段停止。禁投品类：停笔。

### 3. 弹出、链接与广告标识

可识别性、竞价标明、种草链接标明、弹窗/开屏一键关闭、下一级链接与落地页核对。

### 4. 核对、档案与先证后投

不得排除核对。档案不少于三年。平台审核不等于行政审查。

### 5. 计费、预存与监测

预付款非定金。有效口径与作弊剔除。第三方监测优先。

### 6. 数据、格式条款与强制规范

人群包合法基础。无核验引文则法律结论字段停止。

### 7. 下线、链接篡改与责任分层

监管函/侵权下线时限。防篡改与减轻责任安排不得替代核对。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、隐藏标识、弹窗关闭障碍、未审先投、烟草/处方药互联网广告、违法交付个人数据或“技术中立概不审核”改成可履行结构。
- `字段停止`：法域、动态规则、批文文号、经营资格、人群包合法基础未核验。
- `目标停止`：主目标已变为评改待签文本、履约交底、争议文书，或已锁他类。
