### 首部 要素审查
* **合同标题**：提取的标准命名方式包括“**加工协议**”或“**加工承揽合同**” 。标题必须准确反映业务性质，如涉及修复则应命名为“**修理合同**” 。
* **合同主体**：必须审查签约主体是否具备**经济行为能力**，且合同内容必须与其**经营范围**相符 。例如，仅有修理资质的企业签订设计制造合同可能因超越经营范围被认定无效 。
* **鉴于条款**：在承揽合同中，鉴于条款可用于说明定作背景或特殊技术要求，但应注意其**法律效力**多为辅助解释。核心的质量、技术指标必须写入正式交易条款而非鉴于条款中，以免造成权责模糊 。


### 交易条款 审查
* **标的条款**：
* **描述**：应准确写明品名或项目，必须使用**全称**，严禁使用含混的代号 。
* **数量与规格**：必须明确**法定计量单位** 。
* **原材料提供**：需详列品名、规格、质量、加工技术资料及交付日期 。
* **质量与验收**：
* **标准选择**：优先按国家、部颁或行业标准；无标准时需提供**实样、模型或图纸**，并由双方封样 。
* **验收方法**：必须明确规定验收程序，以确定成果是否达到技术要求 。
* **价款与支付**：
* **构成**：区分“**价款**”（承揽人供料时的总价，含辅材、燃料等）与“**酬金**”（定作人供料时的劳务与智力成果报酬） 。
* **支付节点**：通常约定交付成果时支付，也可商定**定金或预付款** 。
* **履行条款**：
* **期限计算**：承揽人送货的，以**接收戳记日期**为准；代运的，以**承运部门签发日期**为准；定作人自提的，以**承揽人通知的日期**为准 。
* **风险转移**：
1. **原材料风险**：原则上由**所有人**负担 。无约定时，定作人供料则由定作人承担，承揽人供料则由承揽人承担 。
2. **定作物风险**：交付前由**承揽人**承担，交付后由**定作人**承担 。
3. **报酬风险**：履行期内因意外导致成果灭失，承揽人丧失报酬请求权 。但定作人延迟接收期间发生的灭失，定作人仍需支付报酬 。


### 配套条款 审查
* **违约责任条款**：
* **主要违约情形**：包括逾期完成工作、质量低劣、擅自变更材料、未按期接收成果等 。
* **违约救济**：定作人可合理选择要求**修理、重作、减少价款或报酬** 。若债务性质不适于强制履行，定作人可请求由**第三人替代履行**，费用由承揽人负担 。
* **解除与终止条款**：
* **承揽人违约解除**：承揽人未经同意将**主要工作**交由第三方完成的，定作人可以解除合同 。
* **定作人任意解除权**：定作人可以随时解除合同，但需赔偿承揽人因此受到的损失 。
* **争议解决条款**：
* **管辖约定**：需明确约定诉讼管辖法院或仲裁委员会 。
* **知识产权与保密**：
* **合法性审查**：定作行为不得侵害他人的**专利权**，否则合同可能因违法而无效 。


### 尾部 要素审查
* **签名盖章**：合同经双方**签字并加盖公章**后生效 。需注意法定代表人签字与公章的完备性 。
* **日期与份数**：应载明签约日期，并明确合同正本的份数及各方持有情况 。
* **附件效力**：图纸、技术说明、封存样品等附件均应视为合同的**有效组成部分** 。


### 合同语言审查
* **准确性**：
* **品名描述**：严禁使用“大修”等笼统词汇，应具体到“何种系统、何种部位、何种方式” 。
* **质量标准**：避免使用“供参考”等模糊词汇，以免导致质量条款落空 。
* **逻辑性**：
* **“主要工作”与“辅助工作”**：需明确界定对工作成果起决定作用的部分，因其直接关系到能否转包的法律后果 。
* **法律术语辨析**：
* **“价款”vs“酬金”**：需根据原材料供应主体准确选用，以免在成本结算时产生歧义 。


### 常见问题与最佳实践
* **常见陷阱**：
1. **主体资质瑕疵**：承揽方超越经营范围，导致合同无效 。
2. **验收不规范**：定作人接收货物时未严格验收即运走安装，事后发现质量问题难以完全追责 。


* **最佳实践**：
1. **样品先行**：采用**封存样品**方式确定质量指标，作为验收的直接依据 。
2. **费用明细化**：在修理合同中，将**材料费**与**工时费**分开计算，并提供材料明细表 。
3. **技术交底**：定作人提供的技术图纸应明确其约束力，避免标注“仅供参考”等模糊字样 。
