# 边界与路由

本技能只审查 **承揽合同 / 定牌加工（OEM）合同**。主线是委托方授权商标或品牌，承揽人按给定规格完成贴牌生产并交付工作成果。不是无品牌的来料加工，不是买断经销，也不是单独的注册商标许可本约。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 无商标／品牌授权，只完成来料或来件加工 | `加工合同·审查` |
| 承揽人自备主材、按特定规格制成果，无贴牌主给付 | `定作合同·审查` |
| 承揽人取得经销、分销、区域独家销售或可自行向市场销售带标品 | `或其他中介原子；买断再转售存货风险归己→负触发` |
| 主文是注册商标许可、无加工交付 | `主文只许可商标不交付加工成果→` |
| 通用型号现货、买方不控制过程、对价是货款 | `通用型号现货卖方组织生产买方不控制过程→` |
| 修理既存物 | `修理合同·审查` |
| 农村低层自建、私人室内装修等普通项目承揽 | `项目承揽合同·审查` |
| 工地建筑活动、承包资质、竣工验收 | `工地建筑活动承包资质竣工验收→` |
| 主给付是尚待研发的设计／委托开发，贴牌只是附带一句 | `的method。` |
| 无文本、本类型条件已谈妥、要出己方稿 | 留本任务起草并自审 |
| 已签未争、问交期／验货日／标识核销日 | 本套导航的履约步骤 |
| 海关扣留、侵权投诉、催告、解除、立案、开庭或仲裁 | `或对应专项领域。` 或知识产权／合同争议领域；不填签前十节 |
| 委托方无商标权或无再许可，仍要求贴他人注册商标 | 留本任务只出红线；用户坚持改成可履行则整体停止 |
| 允许工厂自销带标尾货、反向测绘后自产或拆标再挂近似标 | 留本任务按反向仿牌红线处理；不改成可履行仿牌 |
| 出口定牌写“当然不侵权／当然豁免” | 留本任务降级：核验境内外权利与是否进入中国市场；不得保证豁免 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

专业版未收录的 P1 场景（医疗器械委托生产、涉外承揽整案）不会作为本原子的实体审查对象。若用户拿这些文本来找本技能：输出 `unavailable` 或负触发路由，不得用本类型硬套。

本技能不得转去加载加工供材主路径、经销区域配额或商标许可备案整案双文件完成本类型审查，也不得把货交承运人风险、买断经销价保或商标转让过户写成 OEM 默认主路径。
