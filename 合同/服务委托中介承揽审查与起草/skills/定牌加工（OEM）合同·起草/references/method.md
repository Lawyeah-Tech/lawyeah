# 审查方法（锁定 承揽合同 / 定牌加工（OEM）合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型，禁止打开加工供材主路径、经销区域配额或注册商标许可备案整案双文件“对照一下”。

本文件是**委托方授权商标或品牌、承揽人按给定规格完成贴牌生产并交付工作成果**的签前判断节点，不是栏目说明书，也不是来料加工清单或经销价保清单。禁止把货交承运人风险、买断经销、商标转让过户或“出口定牌当然豁免”写入本类型默认结论。

每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、必然不侵权、对方必然接受或唯一必得金额。

`search_law` 返回已失效《合同法》及其解释、《加工承揽合同条例》、《经济合同法》、1993 年《产品质量法》第二十七条旧义（销售者掺杂掺假）、1993 年《反不正当竞争法》第九条虚假广告旧义时记为噪声，不得写入 `L#`。第七百八十六条是共同承揽连带责任，不得当成“交付前风险”条文。2019 年《反不正当竞争法》第九条商业秘密正文本次未稳定命中，商业秘密结论以第七百八十五条和商业秘密规定第八条、第九条为已核验同向依据，运行时再核。2025 年修订第十条公布施行日为 2025-10-15；MCP 效力字段若仍标“尚未施行”，以施行日为准并记录冲突，未独立核验前不写入 `L#`。

示范文本只参考结构。OEM 合作协议书、加工承揽示范文本不证明本约条款已被接受。

### 双文件使用（标题与文件名不完全对应时不拒跑）

同目录两份知识文件按标题语义使用，不回改正文，不因文件名拒跑：

- 含“首部 / 交易条款 / 配套 / 尾部 / 语言”的当框架级条款清单，供节点 8 出句；
- 宏观的类型切开、品牌授权、商标许可、反向仿牌、签样与核销由本方法节点承担。知识稿把“仅供出口的 OEM 当然不侵权”一笔写死的，**降级**：实务存在两种路径，须核验委托方境内外权利、产品是否进入中国市场和加工方审查义务。知识稿把经销权、商标转让写成默认主场景的，**降级**：主给付滑入经销或单独许可 → 负触发对应原子。知识稿把第七百八十六条当风险转移的，**降级**：共同承揽连带；交付前保管与毁损走第七百八十四条，不得写成货交承运人默认。
- 文件不可用（空、代码块、与本类型明显无关）：记 `G#`，用本方法节点继续，不得改去加载加工或经销双文件，不得编造商标证号或授权日。

## 节点 1　类型识别与负触发

### 1.1 本类型正像

同时满足才继续：

- 核心工作是**完成生产并交付贴有委托方指定商标或品牌标识的工作成果**，对价主要是加工报酬（可含材料费），不是买断货权后自由转售；
- 文本出现或依事实必须出现**品牌授权／商标使用许可**，且承揽人不得因加工取得商标权；
- 委托方控制规格、签样或品牌规范，承揽人不得把带标产品当作自有存货对外经销。

标题写成“定牌加工合同”“OEM 代工协议”“委托加工（定牌）合同”只是线索。名实不符按核心给付归类，标题冲突写入 `C#`。

### 1.2 必须切开（禁止两套知识）

| 信号 | 归入 | 本技能动作 |
| --- | --- | --- |
| 无商标／品牌授权，只完成来料或来件加工，成果可不贴委托方独有标识 | 加工合同 | **负触发** → `加工合同·审查`。夹带一句“按需印标”但无授权闭环：标缺口并转出，不在本任务展开加工供材主路径 |
| 承揽人自备主材、按特定规格制成果，无贴牌主给付 | 定作合同 | **负触发** → `定作合同·审查` |
| 承揽人取得经销、分销、区域独家销售，或可自行向市场销售带标品 | 经销买卖合同 | **负触发** → `或其他中介原子；买断再转售存货风险归己→负触发`。不得删掉经销条款后继续当 OEM 审 |
| 主文只许可注册商标，不交付加工成果 | 注册商标许可合同 | **负触发** → `主文只许可商标不交付加工成果→`。本约中的许可专章可评改，但不代写许可本约整案 |

| 修理既存物 | 修理合同 | **负触发** → `修理合同·审查` |
| 农村低层自建、私人室内装修 | 项目承揽 | **负触发** → `项目承揽合同·审查` |
| 工地建筑活动、承包资质、竣工验收 | 施工／EPC | **负触发** → `工地建筑活动承包资质竣工验收→` |
| 主给付是尚待研发的设计，贴牌只是附带一句 | 委托开发 | **负触发** → `的method。`。加工方出设计但仍以贴牌交付为主：留本任务，强制写清设计权属，不整份代审开发 |

加工或经销误入是硬闸：一旦核心给付滑入上述结构，立即停笔转出。不得删掉经销权或来料加工包后继续当 OEM 审。

### 1.3 加载协议

只打开本目录 `基本面.md` 与 `框架.md`。禁止读 `types/` 或其他场景原子目录。

### 1.4 违法结构停笔

出现下列任一结构，只出告知，不改写成可履行文本：

- 委托方承认不是商标权人、也没有再许可，仍要求贴他人注册商标；
- “工厂可自行销售带标库存／尾货／次品”“多余标签可外卖”；
- 指导拆除正标后挂近似标、对外称正品或出口规避境内权利人；
- 倒签授权书或伪造商标注册证、海关知识产权备案；
- 无证生产列入工业产品生产许可目录的产品，或把违禁品改成可履行代工。

用户坚持“改到能签／先贴再补证／工厂自己卖一点没关系”：整体停止。合规改道（补真实授权、拆除标识后白牌、另签经销或许可本约）只点名并出修改句，不在本任务起草规避方案。

## 硬闸 A　OEM ≠ 加工 ≠ 经销 ≠ 单独商标许可

本闸改变能否留在本任务。

1. **有没有贴牌主给付**  
   文本须能指出：承揽人按委托方规格，在产品、包装或说明书上使用委托方指定商标，并向委托方交付成果。只有“来料加工、不贴品牌”或“按图定作、无商标授权” → 转 `加工合同·审查` 或 `定作合同·审查`。  
   **修改句（留在本任务时）**：`各方确认：本合同是定牌加工（OEM）承揽合同。承揽人按照委托方提供或书面确认的规格、签样和商标图样完成生产，向委托方交付贴有指定商标的工作成果，委托方支付报酬。承揽人不得因履行本合同取得任何商标、商号或其他品牌权利，也不得将带有该等标识的产品作为自有商品销售、分销或出口。本合同不是普通来料加工，不是经销买卖，也不是商标权转让。`

2. **有没有被写成经销**  
   出现区域独家销售、进货指标、转售加价、库存买断后自由销售：负触发 `或其他中介原子；买断再转售存货风险归己→负触发`。仅禁止为竞争对手代工、但不授予销售权：可留本任务，排他性只约束生产。  
   **修改句（仅告知转出）**：`删除或以附件剥离赋予承揽人经销权、分销权、区域独家销售权或自行向市场销售带标产品的条款。若各方真实交易是经销，应另立经销买卖合同；本任务不把经销结构改写成可履行的 OEM。`

3. **最强反方**  
   标题写 OEM 但附件是购销／经销合同，相对方可主张按买卖或经销履行。签前按核心给付分流，不两套都审。

## 硬闸 B　品牌授权必须闭合

本闸是本类型生存级闸。改变能不能开始贴牌。

1. **先锁商标权人，再谈加工**  
   建权属表：商标图样、注册号、类别、核定商品是否覆盖本产品、有效期、注册人全称是否等于签约委托方。注册人不是委托方：必须见到商标注册人出具的、允许委托方转委托加工的书面再许可，且再许可范围覆盖本订单。  
   材料未提及不得写成“已获授权”，只能写 `依据不足`。  
   **修改句**：`委托方保证：其是第【待填】号注册商标（图样见附件《商标标准图样》）在第【待填】类核定商品【待填】上的注册人；或已取得注册人【全称】于【待填】日出具的书面再许可，该再许可明确允许委托方转委托承揽人为本协议项下订单实施定牌加工。商标注册证复印件（加盖公章）及再许可原件扫描件作为本合同附件。授权范围仅限为本协议订单生产、包装和向委托方交付，不包括销售、分销、再许可或商标转让。委托方未能在签署前提供上述文件的，承揽人有权中止生产且不承担逾期责任。`

2. **禁止的写法**  
   “双方确认委托方拥有全部知识产权，承揽人无需核验。”“授权手续后补，先按订单投产。”“本合同签署即视为已获得商标权人全部授权。”  
   **修改句**：`删除“无需核验”“签署即视为已授权”“手续后补”的表述。品牌授权文件是投产先决条件，不是合同生效后的补正事项。`

3. **加工方审查义务**  
   加工方立场：修改句要求核验证书原件或商标局公开信息，保留核验记录。委托方立场：修改句要求陈述保证真实、不实则赔偿并允许中止／解除。不得写成“加工方已审查即必然不侵权”。

4. **最强反方**  
   境内注册商标权人可能主张未经许可在同一种商品上使用相同商标，构成商标法第五十七条第一项。委托方不是权利人时，合同不能对抗权利人。签前不得保证“有合同就不会被诉”。

核验失败：侵权是否成立的法律结论字段停止，事实摘录和“未见授权不得投产”的修改句草稿继续。

## 硬闸 C　商标许可必须闭合

本闸改变授权条款能不能放行。

1. **使用 ≠ 转让**  
   框架要求使用“授权使用”而非“转让”。文本出现“商标归加工方共有”“加工完成即取得商标权”“许可期满商标自动转让”：红线。  
   **修改句**：`委托方仅向承揽人授予普通、不可转让、不可再许可的商标使用许可，许可目的仅限于履行本合同项下的加工、包装和向委托方交付。许可期限自本订单生效日起至该订单项下工作成果交付或本合同终止之日（以较早者为准）止，期满自动终止。任何一方不得将本条解释为商标转让、排他许可或独占许可，除非另行签署注册商标许可合同并办理转让或备案手续。`

2. **备案对抗**  
   商标法第四十三条：许可人应当报商标局备案；未经备案不得对抗善意第三人。解释第十九条：未备案不影响许可合同效力，当事人另有约定的除外。  
   **修改句**：`委托方应在本合同签署后【待填】日内，将本协议项下商标使用许可报商标局备案并书面通知承揽人。未经备案不得对抗善意第三人。双方另有约定以备案为生效条件的，从其约定；未作此约定的，未备案不使本条当然无效，但委托方逾期未备案的，承揽人有权中止在新订单上使用该商标。`

3. **商品标注**  
   第四十三条第二款：经许可使用他人注册商标的，必须在商品上标明被许可人的名称和商品产地。2018 年《产品质量法》第二十七条：标识须真实，有中文产品名称、生产厂厂名和厂址。商标许可标注与厂名厂址冲突时并列 `C#`，修改句要求同时满足，不得只标品牌、隐去实际生产厂。  
   **修改句**：`承揽人应在使用该注册商标的商品及包装上，按附件 VI 标明被许可人名称和商品产地，并按《产品质量法》第二十七条用中文标明产品名称、生产厂厂名和厂址。不得只标注委托方品牌而省略实际生产厂信息，也不得把承揽人写成商标权人。`

4. **不得整份代审许可本约**  
   许可类型（普通／排他／独占）、备案材料清单、被许可人诉权：只点名。用户要审独立《注册商标许可合同》→ `主文只许可商标不交付加工成果→`。

5. **最强反方**  
   相对人可能主张未备案则许可无效，或主张本约已构成转让。签前两极都不写。只写：未备案原则上不影响许可效力，但不能对抗善意第三人；本约不能代替转让手续。

## 硬闸 D　不得反向仿牌

本闸是本类型另一生存级闸。改变工厂能不能留下品牌资产。

1. **反向仿牌识别**  
   下列任一出现，按反向仿牌处理，不得改成可履行自营：  
   - 超量生产、私自外销或通过电商／外贸公司“顺便出一点”；  
   - 留存、复制、外卖商标标识、防伪标、包装、说明书；  
   - 对委托方提供的图纸、模具、治具、BOM、工艺做测绘、拆解后自产同款或近似款；  
   - 拆除委托方商标后以白牌或近似商标投入市场，或更换商标再投入市场（商标法第五十七条第五项）；  
   - 合同终止后继续使用标识或声称“剩余授权”。  
   **修改句**：`承揽人不得实施下列行为，违者以根本违约论，委托方有权立即解除本合同并要求按该等产品对应订单总额的【待填】倍支付违约金（该金额可依法调整，任何一方不得约定不得调整），并赔偿因此导致的行政查处、民事赔偿和品牌损失：（1）生产超过订单数量的带标产品；（2）向委托方以外的任何人销售、出口、赠与或试用带标产品、废次品或尾货；（3）留存、复制、转让商标标识、防伪标、包装或说明书；（4）对委托方提供或因履行本合同知悉的图纸、模具、治具、BOM、工艺做测绘、拆解、反向工程或允许第三人接触；（5）拆除、更换委托方商标后将商品投入市场。合同终止后，承揽人应在【待填】日内停止一切使用并按本条处理剩余标识物。`

2. **尾货与废次品**  
   框架：缺失尾货约定是结构性缺陷；承揽人不能直接销售带标尾货。  
   **修改句**：`订单取消、拒收、逾期不提或产生废次品、带标余料的，承揽人应在【待填】日内书面通知委托方。委托方应在【待填】日内选择：（甲）按【待填】折价收购；或（乙）在委托方人员监督下销毁全部品牌标识、防伪标和带标包材，拆除后方可对无标识白牌残值另行书面同意处理。未经前款书面选择，承揽人不得以任何方式销售、出口或交第三人处理。`

3. **标识物核销**  
   标识物须由委托方指定供应商提供或委托方直接配给；建立领用台账；剩余或报废必须在委托方监督下销毁。  
   **修改句**：`商标标识、防伪标、包装和说明书仅能由委托方指定供应商供货或由委托方配给。承揽人应建立领用、耗用、结余台账，每周／每订单向委托方提交《包材核销表》。结余和报废标识物应在委托方授权代表监督下于【待填】日内销毁，销毁记录由双方签字。承揽人不得自行印制标识物。`

4. **保密与不得留存**  
   第七百八十五条：承揽人应按定作人要求保密，未经许可不得留存复制品或技术资料。商业秘密规定第九条：对商业秘密修改、改进后使用仍属使用。加工方已接触委托方秘密后，不得以“反向工程合法”抗辩。  
   **修改句**：`承揽人应当对委托方提供的规格、图纸、签样、客户信息和工艺保密，未经书面许可不得留存复制品或技术资料，不得允许与本订单无关的人员接触。承揽人不得以自行开发或反向工程为由，使用、披露或允许他人使用因履行本合同知悉的信息。`

5. **最强反方**  
   加工方可能主张：尾货是自己的物、买断材料后有权处分；或主张通过拆解公开产品获得技术。签前不保证“销毁条款当然排除物权处分”，但必须把带标物的处分权锁回委托方；接触委托方秘密后再主张反向工程，通常不被支持。

## 节点 2　主体、资质、授权签字

1. 建主体表：委托方、承揽人、商标注册人、再许可人、指定包材商、授权签字人。名称不一致不自动合并。
2. 承揽人生产许可、环评、特种设备或化妆品／食品／医疗器械许可：文本或用户材料未提及则资质字段停止，不写成“可以投产”。无证仍要求改成可履行：整体停止。
3. 口头“品牌方口头同意了”不得写成已授权。
4. 不足：字段停止，列出待补材料，不补主体。

---

## 节点 3　标的、签样、交付与验收

1. 标的确定到产品名称、型号、商标图样、标注位置／工艺、数量、交期。只有“等”“有关产品”则标缺口。
2. **签样先于批量**：大规模生产前必须书面签样（金样／首件），签样是验收对照，不是“参考”。未见签样：必须改。  
   **修改句**：`批量生产前，承揽人应向委托方提交首件／金样【待填】套。委托方应在【待填】日内书面签样或提出书面异议。未经书面签样，承揽人不得投产；擅自投产的，委托方有权拒收且不支付该批报酬。签样件封存后作为本订单唯一验收对照，双方各执【待填】套。`
3. 验收用 AQL 或可执行的重缺陷／轻缺陷比例，整批退货条件写清。签收、付款、装船不当然等于验收。  
   **修改句**：`委托方应在到货后【待填】日内按附件 AQL（严重缺陷【待填】、主要缺陷【待填】、轻微缺陷【待填】）验收。签收、付款或货交承运人，不视为验收合格，也不视为放弃质量异议、留置权或拒收权。超过前述期限未提出书面异议的，仅对该批外观和数量视为合格，不影响隐蔽缺陷和品牌标识不符的异议。`
4. 材料由委托方提供的：承揽人及时检验，不得擅自更换（第七百七十五条）；保管不善赔偿（第七百八十四条）。材料由承揽人提供的：按约选用并接受检验（第七百七十四条）。不把货交承运人写成默认风险转移。
5. 模具、治具、图纸：默认归委托方，承揽人仅有本订单使用权；合同终止后返还或按委托方书面指示销毁。

---

## 节点 4　程序与生效

把商标许可备案、海关知识产权备案、生产许可、内部授权写成**义务和期限**，不写成已经完成。

| 文本写法 | 本任务动作 |
| --- | --- |
| “本合同签字即视为已获商标授权、已完成备案” | 红线；拆成合同生效 vs 授权文件作为投产先决 vs 备案对抗 |
| “出口定牌当然不侵权，承揽人无需审查” | 红线；改为核验境内外权利并保留中止权 |
| 无谁负责备案、几日内、未完成后果 | 补主体、期限、逾期中止新订单 |
| 用户要求倒签授权日或补假注册证 | 整体停止 |

不得把“双方同意视为已授权”写成可放行结构。

---

## 节点 5　对价、质保金、留置、退出

1. 价金构成分列材料费与加工费，是否含特种包材、税、发票、支付节点、质保金。未给出的数字写 `【待填】`。
2. 定金必须使用“定金”二字；超过主合同标的额百分之二十的部分不产生定金效力。无核验引文不得把 20% 写成现行法结论。
3. 第七百八十三条：未支付报酬或材料费的，承揽人可留置或拒绝交付，另有约定除外。禁止“签收即放弃留置”。  
   **修改句**：`在委托方未按约支付到期报酬或材料费时，承揽人对已完成的工作成果享有留置权或有权拒绝交付。任何一方不得约定签收、预验收或支付预付款即视为放弃留置权。`
4. 第七百八十七条：定作人在完成工作前可以随时解除，造成损失的应当赔偿。禁止“委托方解除不赔偿”或删除任意解除。  
   **修改句**：`委托方在承揽人完成工作前可以书面通知解除本合同或某一订单，但应赔偿承揽人因此受到的损失，包括已投入的材料费、合理人工和已向指定包材商下单且无法退回的标识物成本。双方不得约定解除后互不赔偿，也不得约定承揽人完成工作后委托方仍可无条件拒收而不支付报酬。`
5. 禁止编造单价、总价、AQL、质保金比例。

---

## 节点 6　格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

品牌方或代工厂重复使用的 OEM 模板仍可能构成格式条款。审查单方免知识产权担保、签收即合格、解除不赔、管辖、最终解释权是否有显著提示（第四百九十六条；合同编通则解释第十条）。仅有网络勾选或弹窗：不得写成已尽提示义务。

违反法律、行政法规强制性规定不一律无效。禁止用已失效“效力性／管理性”口诀。假冒注册商标、伪造标识、无证特种生产：只告知，不写假架构。

---

## 节点 7　违约、解除、争议、跨境

1. 逾期交付、标识不符、私自外销、影子工厂、逾期付款必须分别有可执行后果。只有“依法承担违约责任”视为必须改。季节性订单可约定逾期扣款，但避免“按总价 30% 必得、不得调整”。
2. 构成违约不等于当然解除。法定解除只点名催告或目的不能实现，不在本任务作出已解除结论。
3. 争议解决：已有仲裁条款，不得改成“应向某法院起诉”并假装已选定诉讼；或裁或诉、机构不明：改成单一机构或单一法院连结点。
4. **出口定牌**  
   实务存在两种路径：产品未进入中国市场、加工方已核验境外权利人授权的，有的裁判不认定构成对中国注册商标的侵权；加工方未尽审查、或产品回流／在境内销售的，仍可能构成侵权。  
   **不得写成**：出口定牌当然豁免、当然不侵权、加工方无需审查。  
   **修改句**：`若本协议项下产品约定全部出口至【待填】国家／地区且不在中国境内销售，委托方应在投产前向承揽人提供：（1）其在目的地合法拥有或被许可使用该商标的证明；（2）中国境内就该标识不与第三人注册商标冲突的说明，或冲突时的处理方案。承揽人有权核验上述文件并保留复印件。出现境内销售、回流、目的地权利瑕疵或第三人主张的，承揽人有权中止生产。任何一方不得约定“出口定牌当然不构成商标侵权”或免除委托方的权利担保。`
5. 微信已读不写成已经送达，除非合同把该渠道定为送达。

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

对照已加载框架级文件和本方法硬闸，按六步逐段出句。框架中的经销权、转让商标清单：仅在文本确实出现时使用；主给付滑入经销或单独许可则按节点 1.2 转出。

| 步 | 本类型必须盯的点 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题名实（定牌加工／OEM，避免购销或经销）；鉴于只描述委托方拥有或被许可商标、承揽人仅是生产者；不把授权或备案写成已完成 | 主体与鉴于修改句 |
| 交易条款 | 商标图样与标注；签样；AQL；材料提供方；交期；价税分列；标识物来源 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 授权范围与备案；禁止反向仿牌和外销；尾货销毁或折价；772 亲自完成；787 解除赔偿；留置；知识产权担保 | 可执行后果句 |
| 尾部 | 授权签字；附件：商标注册证、授权书、VI、签样、包材核销表 | 生效与附件修改句 |
| 语言 | 授权使用 ≠ 转让；生产权 ≠ 经销权；签收 ≠ 验收；出口 ≠ 当然不侵权 | 替换空词的句子 |
| 常见问题 | 影子工厂、标识冒用、尾货自销、缺失核销、先贴后补证 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（假授权、反向仿牌、带标自销、影子工厂、出口当然豁免、解除不赔）；
- `必须改`：可谈但签署前要落句（许可范围、备案对抗、签样／AQL、标识核销、772、留置、厂名厂址标注）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级订单额或个人无限连带且用户拒绝升级：停止“可以签署”建议。

## 版本冲突

正文、附件、订单、VI、签样、授权书、聊天确认冲突时：

1. 并列 `D#` / `C#`，不选对用户有利的一版。
2. 修改句写明冲突项以哪一份为准，或删除冲突句。商标图样、是否允许外销、是否授予经销权冲突不得调和成“两套都有效”。
3. 不得在意见里悄悄采用有利版本并称“合同已明确”。
