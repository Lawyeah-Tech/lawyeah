# 定牌加工（OEM）合同·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构，不证明本约条款已被接受。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、《加工承揽合同条例》、《经济合同法》、1993 年《产品质量法》第二十七条旧义、1993 年《反不正当竞争法》第九条虚假广告旧义当作本类型默认规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只起草 **承揽合同 / 定牌加工（OEM）合同** 的待签文本，按已谈妥条件出己方稿，输出可编辑草稿、未决项；出稿后必须用本类型硬闸自审，输出风险表和修改句。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。中文名必须是「审查定牌加工（OEM）合同（承揽合同）」。`depends-on` 为空。不要求先跑导航。

主线是**委托方授权商标或品牌，承揽人按给定规格完成贴牌生产并交付工作成果，承揽人不得取得品牌权利、不得自行经销带标产品**。不是无品牌授权的来料加工，不是买断经销，也不是单独的注册商标许可本约。

不交付：他类审查、待签文本签前审查、履约交底、争议文书、有效性或必然不侵权保证、把假授权贴牌、反向仿牌、带标尾货自销或“出口定牌当然豁免”改成可履行结构。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **OEM ≠ 加工 ≠ 经销 ≠ 单独商标许可**：核心给付是贴委托方商标完成代工并交付成果 → 本类型。无品牌授权、只完成来料加工或定作 → `加工合同·审查`／`定作合同·审查`。承揽人取得经销权、分销权或可自行向市场销售带标品 → `或其他中介原子；买断再转售存货风险归己→负触发`。主文只许可商标、不交付加工成果 → `主文只许可商标不交付加工成果→`。不得删掉经销条款或许可本约后继续当 OEM 审。
2. **品牌授权必须闭合**：委托方须是商标注册人或持有商标注册人书面再许可，且授权覆盖本产品类别、地域、期限和本订单用途。未见注册证、授权书或再许可链条：品牌字段停止，不得写成“可以先贴再补证”。
3. **商标许可必须闭合**：用语是“授权使用”不是“转让”；许可范围仅限本协议项下加工、包装和向委托方交付；期限随合同终止而终止；许可人应报商标局备案，未经备案不得对抗善意第三人；经许可使用的商品须标明被许可人名称和产地。不得把本约改成商标权转让。
4. **不得反向仿牌**：禁止超量生产、私自外销、留存或转售标识物、对委托方图纸／模具／工艺做反向测绘后自产、拆除标识后以白牌或近似标投入市场。尾货只能由委托方折价收购，或拆除全部品牌标识并经书面同意后处理。用户坚持“工厂可以自己卖一点”：红线；坚持改成可履行仿牌：整体停止。

## 工作边界

正触发：已有可读待签定牌加工／OEM 代工正文或可单独评改的贴牌专章，尚未签署，尚未成争；核心给付是按委托方规格和商标授权完成生产并交付贴牌成果。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 无商标／品牌授权、只完成来料或来件加工 → `加工合同·审查`；
- 承揽人自备主材、按特定规格制成果，但无贴牌主给付 → `定作合同·审查`；
- 承揽人取得经销、分销、区域独家销售或可自行向市场销售带标品 → `或其他中介原子；买断再转售存货风险归己→负触发`；
- 主文是注册商标许可、无加工交付 → `主文只许可商标不交付加工成果→`；
- 通用型号现货、买方不控制过程、对价是货款 → `通用型号现货卖方组织生产买方不控制过程→`；
- 修理既存物 → `修理合同·审查`；
- 农村低层自建、私人室内装修等普通项目承揽 → `项目承揽合同·审查`；
- 工地建筑活动、承包资质、竣工验收 → `工地建筑活动承包资质竣工验收→`；
- 主给付是尚待研发的设计／委托开发，贴牌只是附带一句 → `的method。`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问交期、验货日、标识核销日 → 本套导航的履约步骤；
- 已成争（催告、海关扣留、侵权投诉、解除索赔、立案、开庭、仲裁）→ `或对应专项领域。` 或知识产权／合同争议领域，不填签前十节。

假授权贴牌、仿冒他人注册商标、把带标尾货改成可自销、指导规避海关知识产权备案：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；代表委托方／品牌方还是加工方；正文、订单、商标注册证、授权书、VI／签样、包材核销表版本；商标权人是不是签约委托方；授权是使用还是转让；是否允许外销或白牌处理；不可接受事项；法域与拟签时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的单价、数量、交期、AQL、质保金比例用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验民法典第七百七十条至第七百八十七条、第一千一百九十三条，商标法（2019 修正）第四十三条、第五十六条、第五十七条，商标民事纠纷解释第十九条，2018 年《产品质量法》第二十七条，商业秘密规定第八条、第九条。`search_practiced` 只比较出口定牌是否侵权的翻转条件，不写成必然豁免。`search_template` 只借 OEM 合作协议栏目。不虚构案件系统。

`search_law` 对法律结论为 required 级：不可用时不拒绝执行，只停止法律结论字段。返回已失效《合同法》或其解释、《加工承揽合同条例》、《经济合同法》、1993 年《产品质量法》第二十七条旧义、1993 年《反不正当竞争法》第九条虚假广告旧义时记为噪声，不得写入 `L#`。2019 年《反不正当竞争法》第九条商业秘密正文本次未稳定命中：商业秘密结论以民法典第七百八十五条和商业秘密规定为已核验同向依据，运行时再核；2025 年修订第十条以公布施行日为准再核，不得把 MCP“尚未施行”字段与施行日冲突时的记忆条号直接写成 `L#`。


## 起草模式

本原子只承担本类型起草。待签评改转 `定牌加工（OEM）合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `定牌加工（OEM）合同·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。下文「起草必写 / 附件必附 / 禁止出现」即本类型硬闸的落稿口径。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 委托方须是商标注册人或持有商标注册人书面再许可，且授权覆盖本产品类别、地域、期限和本订单用途。
- 用语是“授权使用”不是“转让”。许可范围仅限本协议项下加工、包装和向委托方交付；期限随合同终止而终止。
- 许可人应报商标局备案，未经备案不得对抗善意第三人。经许可使用的商品须标明被许可人名称和产地。
- 尾货只能由委托方折价收购，或拆除全部品牌标识并经书面同意后处理。

### 附件必附

- 商标注册证、授权书或再许可链条。未见则品牌字段停止，不得写成可以先贴再补证。

### 禁止出现

- 可以先贴再补证。
- 把本约改成商标权转让。
- 超量生产、私自外销、留存或转售标识物。
- 对委托方图纸／模具／工艺做反向测绘后自产。
- 拆除标识后以白牌或近似标投入市场；工厂可以自己卖一点。
- 假授权贴牌、反向仿牌、出口定牌当然不侵权。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录，禁止为对照打开加工供材主路径、经销区域配额或商标许可备案整案双文件。`基本面.md` 中“仅供出口的 OEM 当然不侵权”不得写成结论；改为：实务存在两种路径，须核验委托方境内外权利、产品是否进入中国市场和加工方审查义务，不得保证豁免。框架中的经销权、转让商标清单仅在文本确实出现时使用，主给付滑入经销或单独许可则转出。

必须有修改句。禁止只打红黄绿。每个风险回链文本位置。交付按 [输出合同](references/output-contract.md)。边界见 [路由](references/routing.md)。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造授权或倒签、把假冒注册商标改成可履行贴牌、把反向仿牌或带标尾货自销改成可履行、保证有效或必然不侵权。
- `字段停止`：未见商标注册证或再许可链条；许可写成转让；未见签样／VI；未见标识物核销；未见主要工作亲自完成约定；国境外商标冲突未核验。
- `目标停止`：主目标已变为评改待签文本、履约交底、争议文书，或文本已滑入普通加工／经销／单独商标许可／买卖／施工。

生存级订单额、海关扣货风险或个人无限连带且用户拒绝升级：停止“可以签署”建议。
