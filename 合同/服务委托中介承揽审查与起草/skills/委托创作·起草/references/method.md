# 审查方法（锁定 委托合同 / 委托创作合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制一般委托的授权范围/隐名代理/无偿任意解除主路径，禁止复制知产侧委托创作的专有权登记/再许可主路径，禁止复制承揽的材料风险/留置定作物/第 787 条单方随时解除主路径。

定性校验：标题、核心给付与本类型一致才继续；一般委托、知产侧委托创作、承揽定作/加工/复制/印刷、现成作品转让或许可明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受或唯一必得稿酬。

`search_law` 返回已失效《合同法》委托章（第 396–413 条）或承揽章（第 251–268 条）、1990 年《著作权法》第十九条（继承条款）、2010 年《著作权法》第十七条旧条号、已失效《著作权法实施条例》（1991）时记为噪声，不得写入 `L#`。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。未知权威的“委托创作合同”范本常把著作权直接写成归委托方、并允许无限修改：只借栏目，不得把范本正文当已核验规则。

知识库纠正（不回写双文件）：

- `基本面.md` “非典型承揽属性”“定作人/创作人”：本技能锁在委托合同项下委托创作。交付作品不等于应转 `定作合同·审查`。不得把第 787 条定作人随时解除写成唯一退出路径。
- `基本面.md` “受《著作权法》第十九条直接规制”：须核验的是 **2020 年修正、2021-06-01 施行** 的第十九条委托作品规则。1990 年文本第十九条是继承，不是委托作品。
- 著作权民事纠纷解释第 12 条仍写“按照著作权法第十七条规定”：旧条号，对应现行第十九条。写入 `L#` 时同时点明对应关系，不得单独引用第十七条充作现行条号。
- 2013 年《著作权法实施条例》第十一条仍写“著作权法第十六条”职务作品：旧条号，对应现行第十八条。
- `基本面.md` “著作权（除署名权外）归委托方”：现有依据支持约定财产权归属；现有依据不支持把发表权、修改权、保护作品完整权写成已转让。署名权可约定署名方式（不署名、署笔名、署工作室名），不得写成放弃或转让署名权。
- `框架.md` “预付款比例建议不低于 30%”：实务建议，不是法定下限。缺数字用 `【待填】`，不编造 30%。
- `框架.md` “枪手模式”“匿名创作”：不得写成人身权已放弃。可约定对外不署名或署指定名称，但不得约定虚假署他人之名。

先于类型识别。命中任一项则本任务不填十节实体结论，只交付分流理由和最小交接。

| 已能支持的事实 | 走向 | 不得写成 |
| --- | --- | --- |
| 无可读正文和附件，或只有口头交易要点 | `委托创作·起草` | 已经完成审查；可以签 |
| 未签，目标是评改已有委托创作文本 | 进入节点 1 | 已签署或已生效 |

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。标题写“承揽”“设计服务”“代理创作”的，先看是否从无到有创作著作权法意义上的作品并支付稿酬。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 委托人支付稿酬，受托人按需求书从无到有创作文字、美术、音乐、摄影、视听等作品 | 本类型 | 正触发 |
| 处理事务、对外代理、以委托人名义签约，不交付作品 | 一般委托 | 负触发 `一般委托合同·审查` |
| 用户按「知识产权相关合同」审查；主轴是专有权转让、登记过户、许可/再许可、邻接权清单，创作只是取得权属的手段 | 知产侧委托创作 | 负触发 `主给付是委托创作特定作品→` |
| 按样制作、来料加工、定作实物，成果是物 | 承揽 | 负触发 `定作合同·审查` 或 `加工合同·审查` |
| 复制、印刷已有图文，无创作过程 | 承揽 | 负触发 `复制合同·审查` 或 `印刷合同·审查` |
| 标的是已经完成的作品，价款换转让 | 著作权转让 | 负触发 `或` |
| 已有作品许可使用 | 著作权许可 | 负触发 `或` |
| 两方以上共同创作、合作署名 | 合作创作 | 负触发 `多方共同创作→` |
| 设计服务过程为主、不指向作品 | 委托他人设计 | 负触发 `委托他人设计的服务合同·审查` |
| 代笔、枪手主轴 | 委托代笔 | 负触发 `委托代笔合同·审查` |
| 技术方案或软件功能开发 | 委托技术开发 | 负触发 `委托技术开发合同·审查` 或技术类原子 |

支持切开的规范（法律结论须运行时复核）：

- 《著作权法》第 3 条：作品是文学、艺术和科学领域内具有独创性并能以一定形式表现的智力成果。
- 《著作权法》第 19 条：委托作品权属由约定；未明确约定或没有合同的，属于受托人。
- 民法典第 919 条：委托是处理委托人事务——处理事务而不交付作品走 `一般委托合同·审查`。
- 民法典第 770 条：承揽是按照定作人要求完成工作、交付工作成果——物的加工定作复制印刷走承揽原子。
- 《著作权法》第 10 条第 3 款、第 27 条：财产权可转让且应书面；现成作品买卖走 `或`。

实务反例（非法源）：委托合同原则上是行为之债，不保证成果；委托创作却以交付作品为目的。不得据此把本类型改写成一般委托，也不得据此改写成承揽。

### 1.2 加载协议（硬闸）

本技能已锁定 **委托合同 / 委托创作合同**。只打开 `references/基本面.md` 与 `references/框架.md`。禁止读其他子目录，禁止为对照再开第二类，禁止打开 `一般委托合同·审查` 或 `主给付是委托创作特定作品→` 的 method。

### 1.3 与知产侧 / 一般委托 / 承揽切开（硬闸）

| 文本写法 | 本任务动作 | 修改句方向 |
| --- | --- | --- |
| 按需求书创作剧本/插画/LOGO/歌曲/宣传片，付稿酬，谈修改次数和验收 | 正触发，留下本类型 | 首部写明“委托创作，不是一般委托、知产登记交易或承揽定作” |
| 授权乙方以甲方名义对外签约、处理日常事务，无作品交付 | 负触发 `一般委托合同·审查` | 不按本类型改完 |
| 主文是著作权专有权转让、登记过户、再许可、邻接权清单；用户称“按知产侧审” | 负触发 `主给付是委托创作特定作品→` | 不得删登记栏目后硬套本技能 |
| 按甲方样品制作实物、来料加工、印刷装订已有图文 | 负触发承揽原子 | 不得套用第 19 条默认权属去改加工件所有权 |
| 购买乙方已完成的一套插画并过户 | 负触发 `或` | 不按委托创作默认受托人权属改 |

修改句（正触发首部）：

「本合同为委托创作合同。甲方委托乙方按附件《创作需求书》从无到有创作【体裁／名称】作品，并向乙方支付稿酬。本合同不是一般事务委托，不是承揽定作或加工，也不是对已完成作品的著作权转让或许可。作品是否构成著作权法意义上的作品，以具备独创性并能以一定形式表现为准。」

最强反方：相对方主张已构成承揽（因要交付成果）或一般委托（因标题含“委托”）或知产转让（因谈了权属）。修改句必须收回代签、来料加工和现成作品买断措辞。用户坚持保留这些主轴：负触发，不填本类型十节实体结论。

### 1.4 违法内容停笔（硬闸）

加载后或定性中出现：约定创作淫秽、暴力宣扬、侵害英雄烈士权益、危害国家安全或明显违反法律禁止性规定的内容。

动作：

1. 交付告知：违背公序良俗或违反法律、行政法规强制性规定的，民事法律行为可能因民法典第 153 条无效。不得改写成可履行的违法创作结构。
2. 不写题材替换伪装、假备案或体外发布路径。
3. 风险表只保留识别依据和删除/转出口径。
4. 用户坚持“改到能签且仍做这些内容”：整体停止。

## 节点 2　主体、职务作品、素材与文本版本

### 2.1 主体表

建表：签约名、履行名、付款名、发票名、授权签字人、实际执笔人或主创。名称不一致不自动合并。自然人受托人须完全民事行为能力痕迹；法人受托人核对经营范围是否提及设计、制作、文化或相关服务，范围未覆盖不当然无效，但“已具备全部创作资质”字段停止。

口头“我们老板同意了”不得写成已授权。共有创意、在先合作作者未闭合：该权属处分字段停止。

### 2.2 职务作品冲突

支持依据：《著作权法》第 18 条。

受托人若是某单位员工，且创作可能属于完成工作任务：

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 无单位同意或权属切割文件 | 字段停止；修改句要求单位书面确认本次创作不构成职务作品，或由单位作为共同签署方让与其业务范围内权利 | 受托人当然有权单独处分全部著作权 |
| 主要利用单位物质技术条件、由单位承担责任的设计图或软件 | 标红旗；可能适用第 18 条第 2 款，作者仅留署名权 | 按普通委托作品默认归受托人个人 |
| 单位已书面排除职务作品 | 可继续，把该函作为附件 | — |

修改句：

「乙方确认：本次创作不属于乙方与任何第三方之间的职务作品，也未主要利用第三方物质技术条件。如存在任职单位，乙方应在签署前向甲方交付该单位出具的《非职务作品确认函》或由该单位作为共同签署方。未交付前，乙方不得主张其已有权单独约定著作权归属。」

### 2.3 第三方素材与肖像

创作中使用采样音乐、字体、图库、他人肖像或在先作品：须有合法授权范围覆盖本约用途。材料未提及不得写成“无第三方权利负担”，只能写 `依据不足`。

修改句：

「乙方保证交付成果不侵犯第三方著作权、商标权、肖像权或其他合法权益。使用第三方素材的，须在交付时附授权文件，授权范围覆盖甲方按本合同使用作品的方式、地域和期限。因乙方原因导致甲方被第三方主张权利的，乙方应负责解决并赔偿甲方因此支出的合理费用和生效法律文书确定的赔偿。」

影视剧本等需制作许可的：未出示许可痕迹则字段停止，不写“可以投入拍摄”。

## 节点 3　作品、需求书与验收

### 3.1 作品是否可识别

标的须落到：名称或暂定名、体裁、字数/时长/尺寸/分辨率、用途（广告、影视改编、内部使用等）。只有“等相关设计”“视觉升级”则标缺口，出修改句，不编造规格。

完全缺失独创性（纯资料拼接、无智力投入的生成物）：标必须改。不得在签前把某份尚未交付的稿件写成“已不构成作品”或“必然构成作品”。

### 3.2 需求书

《创作需求书》或大纲必须列为附件并写明效力。需求书与正文冲突：并列，不选有利版。

修改句：

「乙方应按附件一《创作需求书》载明的主题、风格、篇幅或规格、禁用元素和用途创作。需求书与正文冲突时，以双方签章的需求书为准；需求书变更须书面到达乙方后生效。未列入需求书的审美偏好，不得单独作为拒收理由。」

### 3.3 交付与验收

初稿—修改稿—定稿分列节点。签收、付款、实际上线不当然等于验收，除非合同有可回链约定且已提示说明。

| 文本写法 | 动作 |
| --- | --- |
| “甲方满意为准” | 必须改：改为符合需求书所列可核验指标 |
| 无异议期 | 必须改：收到后【待填】日内书面提出；逾期未提视为该阶段验收通过 |
| 阶段确认后仍可推倒重来 | 必须改：已确认阶段的思路不得无补偿推翻 |

修改句：

「乙方按节点交付初稿、修改稿和定稿。甲方应在收到该节点成果后【待填】日内，对照附件一提出书面修改意见或签署《阶段确认书》。逾期未书面提出的，该节点视为验收通过。甲方已签署确认的阶段，不得要求推倒重来；如需推翻，按超出免费次数计费或按弃用补偿结算。」

## 节点 4　创作成果归属（硬闸）

支持依据：《著作权法》第 19 条；著作权民事纠纷解释第 12 条（条文仍写旧法第十七条，对应现行第十九条）。

条文要点：受委托创作的作品，著作权的归属由委托人和受托人通过合同约定。合同未作明确约定或者没有订立合同的，著作权属于受托人。委托人在约定使用范围内享有使用作品的权利；双方没有约定使用范围的，委托人可以在委托创作的特定目的范围内免费使用该作品。

| 文本写法 | 动作 |
| --- | --- |
| 权属沉默，或只写“成果归甲方”“项目资料归甲方” | 红线。现有依据支持著作权属于受托人；现有依据不支持把沉默写成归委托方 |
| “全部著作权归甲方，包括署名权、发表权” | 红线。财产权可约定；人身权不得写成已转让 |
| 写明复制、发行、信息网络传播、改编等财产权自定稿且稿酬付清之日起归甲方；署名权留乙方 | 可保留；须点名权利种类、地域、期限和时点 |
| “独占许可”却按“所有权转让”履行，或相反 | 必须改。独占许可乙方仍是著作权人；转让后除人身权外财产权由受让人行使 |
| 废稿、未采用稿、未付清余款时的权属真空 | 必须改：未确认定稿或余款未付清的，财产权不转移；废稿可由乙方另行使用，但不得披露甲方未公开的商业信息 |

修改句（委托人侧，约定财产权归属）：

「双方约定：就定稿作品，除署名权、修改权和保护作品完整权由乙方保留外，《著作权法》第十条第一款第五项至第十七项所列财产权自甲方付清约定稿酬之日起归甲方享有，地域为【待填】，期限为【待填／著作财产权保护期】。合同未列明的权利种类，不因本条而转移。本合同未作上述明确约定的，著作权依法属于乙方；甲方仅有权在附件一载明的特定目的范围内使用该作品，不得擅自许可第三人使用。」

修改句（受托人侧，保持法定默认并写清使用范围）：

「本合同不对著作权归属作转移约定。定稿作品的著作权属于乙方。甲方有权在附件一载明的【用途／媒介／地域／期限】内使用该作品；超出该范围的使用，须另行取得乙方书面许可并支付费用。甲方未付清到期稿酬的，不得行使本条约定的使用权。」

修改句（废稿／权利真空）：

「甲方未在约定期限内确认定稿，或未支付到期稿酬的，已交付稿件的著作财产权不发生转移或独占许可。除附件一中甲方提供且须保密的设定、品牌信息和未公开剧情外，乙方可自行修改后另行使用废稿。甲方已支付的对应节点稿酬不予退还，作为已完成部分的对价。」

最强反方：委托方主张“付了钱成果当然是我的”，或出示将权属一律写成归甲方的网店范本。现有依据不支持以付款或范本习惯改变第 19 条默认规则。用户坚持把沉默写成归委托方、或坚持转让人身权：整体停止“可以签署”建议。

软件委托开发另受《计算机软件保护条例》第 11 条（书面约定；无约定归受托人）约束，但软件功能开发主轴应负触发技术类原子，不在本任务展开。

## 节点 5　稿酬、修改次数、定金与退出

### 5.1 稿酬结构

价金构成、币种、税、发票、预付款、节点款、尾款、是否含后期分成分列。未给出的数字写 `【待填】`。一次性预付全款：必须改成分期，但不是违法，不得写成合同无效。

修改句：

「稿酬总额人民币【待填】元（含／不含税）。支付节点：签署后【待填】日内支付预付款【待填】%；初稿验收后支付【待填】%；定稿且甲方确认后【待填】日内支付尾款。乙方未完成的部分不得请求该部分稿酬。因不可归责于乙方的事由解除或创作不能完成的，甲方应支付与已完成部分相应的报酬。」

后期分成须写计算基数、核对材料和支付时点，禁止“视情况给予奖励”。

### 5.2 定金

必须使用“定金”二字才讨论罚则。“订金、保证金、预付款”无定金性质约定的，不得写成定金。约定或推算超过主合同标的额百分之二十：超过部分不产生定金效力。修改句把定金改到不超过 20%，或改成预付款并写明不适用罚则。

### 5.3 免费修改次数（硬闸配套）

无限修改是本类型高频陷阱。

| 文本写法 | 动作 |
| --- | --- |
| “修改至甲方满意为止”“甲方有权无限制要求修改” | 红线。改为有限次数 + 需求书标准 |
| 有次数但未写超出如何计费 | 必须改 |
| 沉默 | 必须改：写明免费次数、单次深度（不得要求更换主题或体裁） |

修改句：

「就每一节点，甲方可提出不超过【待填】次免费修改，修改不得要求更换附件一已确认的主题、体裁或核心设定。超出次数或超出深度的，按人民币【待填】元／次另计。甲方利用本条循环提出新主题的，视为新委托，须另签补充协议。」

### 5.4 退出与弃用补偿

禁止只写“双方协商解除”而无通知和清理。不得把第 933 条写成无偿随时解除；有偿委托解除应赔偿直接损失和合同履行后可以获得的利益。不得把第 787 条写成委托人可随时解除且只需象征性补偿。

修改句：

「甲方因自身策略调整或审美原因不再采用的，应书面通知解除，并按已完成节点支付稿酬；已确认初稿的，另支付稿酬总额【待填】% 作为弃用补偿。乙方无正当理由逾期【待填】日仍未交付对应节点，或交付成果经【待填】次修改仍不具备需求书所列可核验指标的，甲方可书面解除并要求返还尚未对应完成工作的预付款。任何解除不影响已约定的保密义务和已付清部分的使用权安排。」

## 节点 6　格式条款、强制规范与人身权条款

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 是否格式条款

为重复使用而预先拟定、订立时未与对方协商。从事经营活动的一方不得仅以“这次没用过第二次”否认。网店或平台“委托创作模板”不当然排除格式条款。

审查：权属格式买断、无限修改、甲方满意为准、人身权转让、管辖/仲裁、最终解释权等异常条款是否有足以引起注意的标识，以及是否按要求说明（第 496 条；解释第 10 条）。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在附件 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

提供方对其已尽提示或说明承担举证责任。第 497 条无效情形、第 498 条不利解释：只在核验后作为修改理由，不代替修改句。

### 6.2 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的、是否仅行政管理、是否只规制履行行为（第 153 条；解释第 16 条）。禁止用已失效“效力性/管理性”口诀代替解释第 16 条。违法创作内容、虚假署名：不改写成有效履行。造成对方人身损害或因故意、重大过失造成对方财产损失的免责条款无效（第 506 条）。

### 6.3 人身权与署名方式

支持依据：《著作权法》第 10 条第 1 款第 1–4 项、第 3 款（仅第五项至第十七项可许可或转让）。

修改句：

「乙方享有在定稿作品上署名的权利。署名方式为【真实姓名／笔名／工作室名称／不署名】。甲方不得将他人署名为作者。甲方为使用作品所需的必要改动，不得歪曲、篡改作品损害乙方名誉。发表权由【甲方／乙方】按附件一载明的用途行使；交付作品本身不构成发表。」

## 节点 7　违约、争议与通知

1. 逾期交稿、逾期付款、抄袭侵权、中途弃用必须分别有可执行后果。只有“依法承担违约责任”视为必须改。
2. 构成违约不等于当然解除。法定解除路径只点名催告或目的不能实现，不在本任务作出已解除结论。
3. 违约金不是必得金额；不在本任务做第 585 条精算。修改句避免“不得调整”或“按总价 30% 必得”。
4. 争议解决：出现仲裁条款不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核，修改句改成单一仲裁机构或单一法院连结点。
5. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。

修改句（抄袭）：

「乙方交付成果被生效裁判或双方确认构成侵犯第三方著作权的，甲方有权解除本合同，乙方应返还已收稿酬并赔偿甲方因此支出的合理维权费用和生效法律文书确定的赔偿。甲方不得在未给乙方书面异议期【待填】日的情况下，仅以风格近似为由拒付已验收节点的稿酬。」

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

打开已加载的 `框架.md`，按六步逐段对照正文。`基本面.md` 用于校验类型、主体、权属默认、程序和红旗，不代替本节点出句。

| 步 | 动作 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题用“作品委托创作合同”；区分许可/转让；主体全称；鉴于只写创作意图和用途，不写权属实体义务 | 标题或主体修改句 |
| 交易条款 | 作品定义与需求书；稿酬与节点；初稿—修改稿—定稿；免费修改次数；权属默认或财产权约定 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 署名与人身权；原创与追偿；保密；逾期交稿/付款；弃用补偿 | 可执行后果句 |
| 尾部 | 自然人按指印或身份证复印件；生效可绑首笔预付款；需求书、交付标准、原创性承诺函入附件 | 生效与附件修改句 |
| 语言 | 正说加反说；盯死交付 vs 发表、独占许可 vs 所有权转让、甲方满意为准 | 替换空词的句子 |
| 常见问题 | 权属沉默；无限修改；废稿权利真空；人身权写成已转让 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（权属沉默却写成归委托方、人身权转让、无限修改、违法内容、一般委托/知产侧/承揽主轴、倒签、现成作品冒充创作）；
- `必须改`：可谈但签署前要落句（需求书、修改次数、验收异议期、废稿归属、素材授权、职务作品确认、分期稿酬、定金 20%）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级稿酬一次性预付且用户拒绝升级：停止“可以签署”建议。
