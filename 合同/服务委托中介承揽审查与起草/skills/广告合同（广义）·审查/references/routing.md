# 边界与路由

本技能只审查 **服务合同 / 广告合同（广义）** 的待签文本。中文展示名是「审查广告合同（广义）（服务合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不是广告活动 | 本套导航的类型切开步骤 |
| 核心给付是样稿、创意、平面、脚本，按件或按轮验收 | `广告设计合同·审查` |
| 核心给付是成片、物料、喷绘、成品制作 | `广告制作合同·审查` |
| 核心给付是频道、版面、户外位、排期刊播 | `广告发布合同·审查` |
| 核心给付是以自己名义或形象作推荐、证明 | `广告代言服务类合同·审查` |
| 核心给付是媒介购买、代理排期，无设计制作混同 | `广告代理合同·审查` |
| 核心给付是网站、应用程序、信息流、开屏或程序化投放 | `互联网广告类合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `广告合同（广义）·起草` |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

全案正文里夹带一小段可独立验收的设计或刊播专条：该专条交接对应原子；书面合同、角色、禁止内容、审核拒登、法定审查、对外连带、样稿签批、监测补播、广告费记载条款可继续审。用户坚持本技能把已能细分的设计、制作或发布整案改完：`目标停止`。
