# 审查方法（锁定 服务合同 / 广告合同（广义））

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制设计验收、制作成片、发布排期、代言许可、代理差价或互联网程序化投放的分类型主路径。

定性校验：标题、核心给付与本类型一致才继续；已能锁定单一广告环节则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、包过审或唯一必得曝光量。

`search_law` 返回 1994 年《广告法》条号、已失效《合同法》及其解释、已失效《互联网广告管理暂行办法》、已失效《药品广告审查办法》、已失效《广告管理条例施行细则》时记为噪声，不得写入 `L#`。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。工商局时代《广告发布业务合同》示范文本只借栏目。设计、制作或发布分类型范本只证明是另一类型，不得当作本类型范本。

知识库纠正（不回写双文件）：

- `基本面.md` “发布者不能证明广告主真实名称、地址的，可能对消费者承担全部民事责任”：现行广告法对不能提供真实名称、地址和有效联系方式的处理是先行赔偿，不是 1994 年条文的“全部民事责任”。不得把旧条号写入 `L#`。
- `基本面.md` 把特殊医学用途配方食品与第 46 条列举并列：第 46 条列举为医疗、药品、医疗器械、农药、兽药和保健食品，以及法律、行政法规规定应当审查的其他广告。特医食品按《药品、医疗器械、保健食品、特殊医学用途配方食品广告审查管理暂行办法》运行时核验，不得写成第 46 条已单列。
- `框架.md` “广告费一倍以上三倍以下”：现行虚假广告罚款幅度以广告法（2021 修正）第 55 条为准（广告费用三倍以上五倍以下等；费用无法计算或明显偏低另有定额罚款）。旧幅度不得写入 `L#`。
- “包过审”或“保证通过行政机关审查”：审查权在广告审查机关。合同只能把取得批准写成发布前提。
- 内部“不对合法性负责”：不能对抗经营者和发布者的法定审核义务，也不能免除对消费者的法定连带或先行赔偿。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。标题写“广告服务”“全案推广”“整合营销”的，先看能否拆成单一环节。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 同一份文本同时覆盖设计、制作、代理、发布中两个以上环节，或媒介清单与创意交付混在一笔费用里无法拆开 | 本类型 | 正触发 |
| 只交付样稿、创意、平面或脚本，按件或按轮验收 | 广告设计 | 负触发 `广告设计合同·审查` |
| 只交付成片、物料、喷绘或成品 | 广告制作 | 负触发 `广告制作合同·审查` |
| 只约定频道、版面、户外位、排期刊播 | 广告发布 | 负触发 `广告发布合同·审查` |
| 以自己名义或形象作推荐、证明，人格权许可是主轴 | 广告代言 | 负触发 `广告代言服务类合同·审查` |
| 媒介购买或代理排期，无设计制作混同 | 广告代理 | 负触发 `广告代理合同·审查` |
| 网站、应用程序、信息流、开屏或程序化投放是主轴 | 互联网广告 | 负触发 `互联网广告类合同·审查` |
| 不介绍商品或服务，只做品牌咨询或纯劳务 | 他类服务 | 转引擎重新定性 |

支持切开的规范（法律结论须运行时复核）：

- 广告法（2021 修正）第 2 条：广告主自行或委托设计、制作、发布；经营者接受委托提供设计、制作、代理；发布者为广告主或其委托的经营者发布；代言人在广告中以自己名义或形象作推荐、证明。
- 第 30 条：广告活动各方应当依法订立书面合同。
- 民法典第 770 条：按定作要求完成并交付工作成果的，偏承揽——单一设计或制作走对应原子，不得用广义包办。
- 民法典第 919 条：处理委托人事务偏委托——单一代理走 `广告代理合同·审查`。

本技能已锁定 **服务合同 / 广告合同（广义）**。只打开 `references/基本面.md` 与 `references/框架.md`。禁止读其他子目录，禁止为对照再开第二类。

### 1.3 无法细分才留在本类（硬闸）

| 文本写法 | 本任务动作 | 修改句方向 |
| --- | --- | --- |
| 工作范围同时列创意、成片、媒介排期，一笔全案费，无分项验收 | 正触发；必须拆模块 | 按环节列交付物、验收和付款 |
| 标题“广告服务合同”，正文只约定某卫视频道 15 秒排期 | 负触发发布 | 不按广义改完刊播深度 |
| 标题“全案广告”，正文只约定平面设计三轮修改 | 负触发设计 | 不按广义改完设计深度 |
| 标题“广告业务”，正文只约定成片拍摄与成片交付 | 负触发制作 | 不按广义改完制作深度 |

修改句（正触发首部）：

「本合同为广告活动合同。甲方为广告主，乙方在本合同项下同时承担【广告经营者 / 广告发布者】角色。本合同覆盖【设计 / 制作 / 代理 / 发布】中的【待填】环节；各环节的交付物、验收标准和对应价款见附件《分项清单》。本合同不是单纯的广告设计合同、广告制作合同或广告发布合同。乙方无权以本合同代替依法应另签的代言许可。」

最强反方：相对方主张“全案就是一揽子，不必拆”。现有依据支持书面合同和角色分列，现有依据不支持用一笔费用掩盖无法验收的混同给付。用户坚持把已能锁定的单一环节按本技能改完：负触发，不填本类型十节实体结论。

### 1.4 禁止内容 / 禁发标的停笔（硬闸）

加载后或定性中出现下列任一情形：

- 广告法（2021 修正）第 9 条禁止情形，包括使用或变相使用国旗国歌国徽、国家机关及其工作人员名义形象、“国家级”“最高级”“最佳”等用语，以及其他法定禁止内容；
- 第 28 条虚假广告，含商品或服务不存在、关键信息与实际不符并对购买有实质性影响、伪造或无法验证的证明材料、虚构使用效果；
- 第 15 条麻醉药品、精神药品、医疗用毒性药品、放射性药品、药品类易制毒化学品，以及戒毒治疗的药品、医疗器械和治疗方法作广告；
- 第 16、18 条路径下医疗、药品、医疗器械、保健食品使用代言人；
- 第 22 条在大众传播媒介、公共场所、公共交通工具、户外发布烟草广告，或向未成年人发送烟草广告；互联网发布烟草（含电子烟）广告；
- 第 37 条禁产禁售产品服务，或禁止发布广告的商品服务；
- 《防范和处置非法集资条例》第 11 条含集资内容的广告或集资宣传；
- 为其未使用过的商品或未接受过的服务作推荐、证明；利用不满十周岁未成年人作代言人；对虚假广告推荐证明受罚未满三年的主体再作代言人；
- 伪造、变造或转让广告审查批准文件。

动作：

1. 交付告知：相关给付可能因广告法第 4、9、15、22、28、37、48 条及民法典第 153 条不能作为可履行标的。不得改写成可履行的设计、制作、代理或发布结构。
2. 不写可履行的禁语替换伪装、假批准路径或体外支付广告费。
3. 风险表只保留识别依据和删除/转出口径。
4. 用户坚持“改到能发且仍做这些事”：整体停止。

## 节点 2　主体、角色、经营资格与文本版本

### 2.1 主体与角色表

建表：签约名、履行名、付款名、发票名、授权签字人、法定角色（广告主 / 经营者 / 发布者 / 代言人）。名称不一致不自动合并。一方身兼数职的，分条款写清哪一段给付对应哪一角色。

广告主须对所推销商品或服务有真实经营权；医疗、药品、教育培训、房地产、招商投资回报等另核相应许可痕迹。口头“市场部已经定了”不得写成已授权。样稿签批须指定授权代表。

### 2.2 经营资格

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 广告主委托无合法经营资格的个人或未登记主体设计制作发布 | 红线。第 32 条要求委托具有合法经营资格的经营者和发布者 | 可以展业；改成个人承揽即可 |
| 只有营业执照，无媒介或广告经营痕迹且拟自行发布广播电视或互联网广告 | 字段停止；修改句要求作为附件 | 已具备全部发布资格 |
| 发布者文本不记载广告主真实名称、地址和有效联系方式 | 必须改。不能提供时消费者可要求先行赔偿 | 发布者已对外免责 |

修改句：

「甲方委托乙方从事本合同项下广告活动前，乙方应向甲方出示并作为附件：与本次【设计 / 制作 / 代理 / 发布】相符的合法经营资格证明或媒介资质查询页。未核验前，不得主张已具备承接条件。乙方应登记并保存甲方的真实名称、地址和有效联系方式。」

部门规章或许可管理规范不当然导致民事合同无效（解释第 16 条）。本任务只停止“可以承接/可以发布”表述；无资格主体承接禁发或法定审查类广告，按节点 1.4 停笔。

## 节点 3　审核义务、证明文件与拒登权（硬闸）

支持依据：广告法（2021 修正）第 4、34 条口径（查验证明、核对内容；内容不符或证明不全不得设计制作代理发布）。本窗运行时须用 2021 修正全文核验第 34 条；被 1994 年同条号淹没时，以第 32、37 条及《互联网广告管理办法》第 14 条复述的同一义务支撑修改句，不得把 1994 年第 27 条或第 34 条写入 `L#`。

| 文本写法 | 动作 |
| --- | --- |
| “乙方仅按甲方提供内容发布，不对合法性负责” | 红线删除。补查验、核对和一票拒登 |
| 无证明文件清单，无档案条款 | 必须改：清单入附件；互联网电子数据自发布终了之日起不少于三年 |
| 有拒登权但未写通知时限和费用后果 | 必须改：时限、已发生制作费是否结算写死 |
| 广告主未及时补正导致错过档期，费用是否照付沉默 | 必须改，避免事后各说各话 |

修改句：

「乙方应查验甲方提供的证明文件并核对广告内容。内容不符或者证明文件不全的，乙方不得提供设计、制作、代理服务，也不得发布，并应在发现后【待填】小时内书面通知甲方拒登理由。甲方应在接到通知后【待填】日内补正；逾期未补正导致档期错过的，已锁定且无法退订的媒介成本由【待填】承担，乙方不得因此被强制发布。双方对内的审核分工，不免除任何一方对市场监督管理部门和消费者的法定义务。」

最强反方：经营者主张“内容是广告主的，我们只是通道”。现有依据不支持用内部免责对抗法定审核和明知应知责任。用户坚持保留“不对合法性负责”且无拒登权：整体停止。

## 节点 4　法定审查类与批准文件（硬闸）

支持依据：广告法第 46、47、48 条；医疗药品器械农药兽药保健食品及依法应审的其他广告，未经审查不得发布；不得伪造、变造或转让批准文件。

| 文本写法 | 动作 |
| --- | --- |
| 法定审查类商品广告，合同写“签字后即可投放” | 红线。把取得审查批准写成发布前提，不是合同成立条件 |
| “乙方包过审”“保证取得批准文号” | 红线删除。审查权在行政机关 |
| 允许剪辑、拼接或改写已审画面文案 | 必须改：改动已审内容须重新报审 |
| 特医食品、教育培训、房地产、招商回报未判断是否应审 | 字段停止，运行时核验，不编造批准文号 |

修改句：

「涉及医疗、药品、医疗器械、农药、兽药、保健食品或依法应当审查的其他广告的，取得广告审查机关批准是乙方发布的前提，不是本合同成立的条件。未经审查或批准文件失效的，乙方不得发布。任何一方不得伪造、变造或者转让批准文件。对已审内容的任何改动，须重新报审并取得新的批准后才能发布。任何一方不保证行政机关必然批准。」

最强反方：广告主主张“合同都签了就必须按排期发出去”。现有依据支持未审不得发布。用户坚持未审先发或伪造批件：整体停止。

## 节点 5　样稿签批、监测补播、对价与档案

### 5.1 样稿与授权代表

未经签批发布的，发布方承担内容偏差责任。广告主未及时签批导致错过档期的，费用是否照付必须写明。市场部门口头确认不得写成公司确认。

修改句：

「发布前须完成：样稿提交 → 不超过【待填】轮修改 → 甲方指定授权代表书面签批 → 发布。未经该代表书面签批，乙方不得发布；擅自发布导致与签批稿不一致的，由乙方承担内容偏差引起的撤稿、补发和处罚损失。甲方未在收到样稿后【待填】日内签批或提出书面修改意见的，【费用是否照付 / 档期顺延】按附件约定执行。」

### 5.2 媒介、监测与补播

“同等档次媒体”“最佳位置”必须落到具体频道、版位或价目表编号。监测须写第三方、口径和差异率阈值。未达阈值按补播或退费公式执行。

修改句：

「媒介、位置、尺寸或时长、排期以附件《媒介计划》为准，变更须书面确认。不得以“同等档次”或“最佳位置”代替具体频道、版位或价目表编号。曝光量以双方确认的第三方监测机构【待填】及口径【待填】为准；实际曝光低于约定值【待填】% 的，乙方应在【待填】日内按不足部分补播，或按不足比例退还对应广告费。」

### 5.3 广告费记载

刊例价、折扣、实际成交价、是否含设计制作监测税费分列。支付节点对应样稿确认、发布完成、监测报告。故意写低影响行政处罚计算和所得税风险。

修改句：

「广告费按附件报价单记载刊例价人民币【待填】元、折扣【待填】、实际成交价人民币【待填】元，并分列设计、制作、发布、监测和税费。双方不得另行制作低于实际成交价的结算凭证。预付款与排期锁定对应；监测报告确认后【待填】日内支付尾款。」

定金必须使用“定金”二字才讨论罚则；约定或推算超过主合同标的额百分之二十的，超过部分不产生定金效力。无核验引文不得把 20% 写成现行法结论。

### 5.4 档案

承接登记、审核、档案管理写入合同。互联网广告电子数据自发布终了之日起不少于三年。算法推荐投放的，规则和投放记录记入档案。

## 节点 6　对外责任、内部追偿、格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 对外责任与内部追偿（硬闸）

支持依据：广告法第 55、56、61、68 条口径；食药纠纷规定第 11 条。本窗 MCP 对 2021 年第 56 条被 1994 年同条号淹没的，运行时须用 2021 修正全文核验；不得把 1994 年第 38 条“全部民事责任”写入 `L#`。

| 文本写法 | 动作 |
| --- | --- |
| “任何行政处罚和消费者索赔均由广告主承担，经营者/发布者免责” | 红线。对外连带或先行赔偿不能内部免除；可改内部追偿 |
| 发布者可不登记广告主名称地址 | 红线。补真实名称、地址和有效联系方式 |
| 约定内部追偿但无通知、垫付和凭证移交 | 必须改：时限和文件清单写死 |
| 使用他人名义形象无书面同意 | 必须改。第 33 条事先书面同意；第 68 条民事责任 |

修改句（对外不可免）：

「因虚假广告、违禁内容、未经审查发布或未经同意使用他人名义形象，导致行政处罚、民事赔偿或撤稿的，过错方赔偿罚款、赔偿金、撤稿和消除影响费用。本合同关于费用分担和追偿的约定，只约束甲乙双方，不构成对消费者、市场监督管理部门或其他第三人的免责。」

修改句（内部追偿）：

「一方对外承担法定连带责任或先行赔偿后，有权在非自身过错范围内向另一方追偿。追偿方应在付款后【待填】日内移交处罚决定、和解或裁判文书、付款凭证和消费者信息（依法可移交的部分）。」

最强反方：经营者主张“合同已经约定免责，对外也可以抗辩”。现有依据不支持用内部约定对抗消费者或监管。用户坚持对外免责：整体停止。

监管责令停止发布或内容被认定虚假的，立即撤稿，费用按已履行合法部分结算，并约定消除影响费用负担。紧急撤稿通知须能覆盖实际联系人。

### 6.2 格式条款

为重复使用而预先拟定、订立时未与对方协商。从事经营活动的一方不得仅以“这次没用过第二次”否认。依据示范文本制作，不当然排除格式条款。

审查：审核免责、对外免责、包过审、单方调价、管辖/仲裁、自动续期等异常条款是否有足以引起注意的标识，以及是否按要求说明（民法典第 496 条；解释第 10 条）。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在附件 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

提供方对其已尽提示或说明承担举证责任。第 497 条无效情形、第 498 条不利解释：只在核验后作为修改理由，不代替修改句。

### 6.3 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的、是否仅行政管理、是否只规制履行行为（第 153 条；解释第 16 条）。禁止用已失效“效力性/管理性”口诀代替解释第 16 条。虚假、违禁、未审先发、集资宣传、无资格主体承接禁发广告：不改写成有效履行。

## 节点 7　违约、解除、争议解决与知识产权

1. 擅自改动已审内容、未审发布、曝光未达标、逾期付款必须分别有可执行后果。只有“依法承担违约责任”视为必须改。
2. 监管禁发、媒介停播、未获审查批准时的解除和费用清算必须写。构成违约不等于当然解除。
3. 违约金不是必得金额；不在本任务做第 585 条精算。修改句避免“不得调整”。
4. 争议解决出现仲裁条款：不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核。通知须能覆盖紧急撤稿。
5. 素材来源保证；新创作品权属或许可；未经授权使用他人名义形象按第 33、68 条处理。

修改句：

「乙方擅自改动已审内容或未经签批发布的，甲方可要求立即撤下，并要求乙方赔偿因此产生的处罚、赔偿和消除影响费用。监管机关责令停止发布或媒介停播的，任何一方可书面通知解除尚未履行的发布部分；已完成且内容合法的设计或制作费用按附件结算，预付未履行部分【退还 / 转档】。」

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

打开已加载的 `框架.md`，按六步逐段对照正文。`基本面.md` 用于校验类型、角色、禁止内容、审查程序和红旗，不代替本节点出句。

| 步 | 动作 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题用广告服务/广告业务；能细分的改走对应原子；角色分列；鉴于不写保证过审或保证销售 | 标题或主体修改句 |
| 交易条款 | 分项工作范围；内容附件；媒介排期；对价分列；样稿签批；监测补播 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 审核与拒登；对外连带不可免；内部追偿；解除与撤稿；知识产权；档案 | 可执行后果句或删除句 |
| 尾部 | 公章+授权代表；排期单、刊例、批准文件、资质入附件；批准是发布条件 | 生效与附件修改句 |
| 语言 | 正说加反说；盯死包过审、同等档次、最佳位置、代理与自行发布、广告费写低 | 替换空词的句子 |
| 常见问题 | 混环节无分项验收；审核义务全推广告主；禁止内容仍要发 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（禁止内容/未审先发/集资宣传、对外免责、无拒登权推卸审核、包过审、伪造批件、无资格主体承接、倒签、已能细分仍要本技能包办）；
- `必须改`：可谈但签署前要落句（分项验收、样稿签批、监测补播、广告费分列、档案期限、内部追偿、批准作为发布条件）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级对外免责且用户拒绝升级：停止“可以签署”建议。

正文、创意脚本、媒介计划、刊例确认单、监测标准、审查批准文件、聊天确认冲突时：
