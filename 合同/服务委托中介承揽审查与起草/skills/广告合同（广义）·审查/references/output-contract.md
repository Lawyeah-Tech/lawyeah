# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受、包过审或必然可发布；编造未给出的刊例价、折扣、曝光量、批准文号、期限；把 1994 年《广告法》条号或已失效《合同法》写入结论；把内部免责写成已对抗监管或消费者；把发布者不能提供名称地址写成“全部民事责任”而不写先行赔偿；把第 46 条写成已单列特医食品；把广告费罚款幅度写成一倍以上三倍以下；把已能细分的设计、制作或发布当成已完成的本类型审查；把禁止内容改成可履行结构。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查广告合同（广义）（服务合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回 1994 年《广告法》条号、已失效《合同法》及其解释、已失效《互联网广告管理暂行办法》时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `服务合同`，子级 `广告合同（广义）`。定性理由、易混切开结果（广告设计、广告制作、广告发布、广告代言、广告代理、互联网广告）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、角色、资格与文本版本

主体表：签约名、履行名、付款名、发票名、授权签字人、法定角色。资格表：经营资格或媒介资质痕迹。版本表：正文、创意脚本、媒介计划、刊例确认单、监测标准、审查批准文件、聊天确认；冲突并列。未核经营资格：该承接能力字段停止。

## 5. 给付闭环、审核、审查批准与监测

核心给付是否无法拆成单一环节；是否夹带禁止内容或禁发标的；证明文件与拒登权是否闭合；法定审查类是否以批准为发布前提；样稿签批授权代表；监测口径与补播公式；广告费是否分列刊例/折扣/成交价；档案保存期限。缺口标 `G#`。不输出设计三轮验收、成片技术规格或单一刊播排期的分类型主路径。

## 6. 对外责任、格式条款与强制规范

对外连带或先行赔偿是否被内部条款冒充免除；异常免责是否加黑提示。强制规范只按民法典第 153 条和解释第 16 条区分，不用失效口诀。禁止内容/未审先发/集资宣传只保留识别与停笔。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把框架里的旧罚款幅度写成现行法。

## 9. 谈判与签署提醒

谈判顺序：先红线（禁止内容、未审先发、对外免责、无拒登权、包过审、无资格主体、已能细分却要本技能包办），再必须改（分项验收、样稿签批、监测补播、广告费分列、批准作为发布条件、档案、内部追偿），最后可优化。签署提醒：双方公章；媒介计划、刊例确认单、创意脚本、证明文件清单、批准文件、资质查询页入附件。不指导倒签、补假批准或先发后审。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书或效力保证，也不是广告设计、制作、发布、代言、代理或互联网广告的分类型审查。
