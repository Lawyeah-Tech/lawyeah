# 边界与路由

本技能只审查 **委托合同 / 一般委托合同** 的待签文本。中文展示名是「审查一般委托合同（委托合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 自己名义从事买入、卖出、寄售、代销并收取贸易报酬 | `行纪合同·审查`。不得删自营贸易条款后硬套本技能 |
| 只报告订约机会或提供媒介，自己不成交一方 | `房屋买卖_租赁中介合同·审查`（房屋买卖/租赁中介）或对应中介原子 |
| 只出调研报告、管理建议等意见，不对外处理事务 | `咨询服务合同·审查` |
| 特定技术项目可行性、技术预测、工艺评价、FTO | `或`；文本落在委托技术咨询目录下则 `委托技术咨询·审查` |
| 必须交付加工、定作、修理等工作成果 | 对应承揽原子（如 `加工合同·审查`）或回引擎重新定性 |
| 房地产开发企业销售代理、全案代理销售 | `房地产销售代理合同·审查` |
| 诉讼出庭、阅卷、风险代理费为主轴的律师服务 | 回 本套导航的类型切开步骤；本任务不按一般事务委托改完 |
| 正文夹带房屋买卖本约价款、过户、网签 | 本约条款交接 `主文件是二手房买卖本约→`（二手房）或 `或对应买卖原子；`（商品房）；委托授权条款可继续审 |
| 无文本、本类型条件已谈妥、要出己方稿 | `一般委托合同·起草` |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

委托正文里夹带一小段本约价款或咨询意见：专条交接对应原子；事务范围、费用预付、933 解除、转委托、隐名披露条款可继续审。用户坚持本技能把行纪、中介、咨询、房销代理、诉讼律师服务或承揽整案改完：`目标停止`。
