# 审查方法（锁定 委托合同 / 一般委托合同）

本文件是可执行判断节点，不是栏目说明书。本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制行纪费用自担/介入权/第三人先赔路径，禁止复制中介跳单/产调/备案路径。

每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受或唯一必得金额。

`search_law` 返回已失效《合同法》委托章及其解释、担保法解释或涉外经济合同法时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

知识库口径纠正（不回写双文件）：

| 双文件写法 | 本任务口径 |
| --- | --- |
| 「根据《民法典》第  条」空缺 | 第 933 条 |
| 转委托「后果由受托人承担风险」一刀切 | 经同意或追认：仅就选任及指示负责；未经同意且非紧急：对第三人行为负责 |
| 无偿解除「赔偿直接损失」 | 赔偿因**解除时间不当**造成的直接损失 |
| 「非因法定事由行使解除权的违约金」可对冲 | 可约定通知期和赔偿计算；**不得**写成放弃任意解除权且解除无效 |

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受；依据示范文本拟定且符合格式条款定义的，仍按格式条款审查。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对外名义和对价方式定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 排除 |
| --- | --- | --- |
| 受托人处理委托人事务；通常以委托人名义，或隐名但效果归委托 | 一般委托，留本任务 | 行纪、中介、咨询、承揽 |
| 以自己名义从事买入、卖出、寄售等贸易并收报酬 | `行纪合同·审查` | 不得按第 921 条预付费用或第 933 条无偿解除改完 |
| 只报告订约机会或媒介，自己不成交一方 | `房屋买卖_租赁中介合同·审查` 或对应中介原子 | 不得删撮合后硬套；不写第 965 条跳单 |
| 只出意见、调研或方案，不对外处理事务、不代签、不代付款 | `咨询服务合同·审查` / `或` | 不得按委托权限和任意解除改完 |
| 必须完成工作并交付物化或可验收成果 | 承揽原子（如 `加工合同·审查`）或回引擎 | 处理事务过程不是承揽 |
| 房企委托销售代理、全案代理卖房 | `房地产销售代理合同·审查` | 一般事务委托 |
| 诉讼出庭、阅卷、风险代理费为主轴 | 回 本套导航的类型切开步骤 | 一般事务委托 |
| 授权代签房屋买卖本约 | 委托授权留本任务；本约价款/过户/网签交 `主文件是二手房买卖本约→` 或 `或对应买卖原子；` | 不得把本约审成委托正文 |

2. 不写可履行的催收路径、假授权、本人不到场的结婚/收养/遗嘱安排。
3. 风险表只保留识别依据和转出/改道提示。
4. 用户坚持“改到能签”：整体停止。

## 节点 2　主体、资质、共同委托

1. 建主体表：签约名、履行名、付款名、发票名、授权签字人。名称不一致不自动合并。
2. 核验：营业执照与签约名是否同一；诉讼、审计、报关、进出口等许可是否被文本或用户材料提及。未核：该事务能力字段停止，不写“可以展业”。
3. 两个以上受托人共同处理同一事务：修改句写明对委托人承担连带责任（第 932 条）。分别处理互不交叉的事项：写清分工，不当然连带。
4. 共有、配偶、国资、集体、上市公司内部决议：未闭合则该签署能力或财产处分字段停止，不写成“可以盖章”。
5. 口头“我们老板同意了”不得写成已授权。
6. 自己代理或双方代理（第 168 条）：无书面同意或追认则必须改或红线。

不足：字段停止，列出待补材料，不补主体。

## 节点 3　权限范围与授权委托书

1. 委托事务必须界定到可履行：事项清单、相对方范围、地域、期限、完成或阶段性标准。只有“处理甲方所有对外事务”“全权代理”且无反说：空白授权，红线。
2. 特别授权与一般授权分列。代为签署、代为放弃权利、代为收款、代为起诉或和解，必须逐项勾选。
3. 可否处分不动产、单笔或累计资金上限必须列举。未列：必须改；用户拒绝列举仍要放行：红线并建议不签。
4. 授权委托书（书面授权时）按第 165 条核四要素：代理人姓名或名称、代理事项、权限、期限，并由被代理人签名或盖章。缺一项：必须改，修改句要求作为附件并与正文权限一致。
5. 正文与授权书冲突：并列 `C#`，修改句指定以授权书对外出示、以正文约束内部，或删除冲突句。不得选对用户有利的一版。
6. 房屋买卖本约授权：委托权限可审；本约价款、过户、网签不在本任务改成买卖合同。

## 节点 4　亲自处理、转委托、指示与报告

1. 默认亲自处理。允许转委托的，写清：事前书面同意或事后追认；紧急为维护委托人利益时可转，但事后及时报告。
2. 经同意或追认：委托人可直接指示转委托的第三人；受托人仅就第三人的选任及其对第三人的指示承担责任。修改句必须写出选任标准（资质、无利益冲突）和指示留痕。
3. 未经同意且非紧急：受托人对转委托第三人的行为承担责任。禁止写成“转委托后一律由委托人向第三人主张、受托人免责”。
4. 委托人在受托人之外另委托第三人（第 931 条）：须经受托人同意；因此造成受托人损失的，修改句保留赔偿请求，不写成委托人可任意叠托。
5. 指示变更：须委托人同意；紧急且难联系：妥善处理并事后报告（第 922 条）。口头改指示不得写成已授权。
6. 报告：按要求报告处理情况；终止时报告结果（第 924 条）。无周期、无结项报告格式：必须改。建立“报告—书面指令—执行”闭环作为责任划分证据。
7. 处理事务取得的财产、文件、印鉴、账户余额应转交委托人（第 927 条）。无移交清单：必须改。

## 节点 5　费用预付与报酬

### 5.1 费用（第 921 条）

委托人应当预付处理委托事务的费用。沉默：必须改，写成委托人预付至指定账户、实报实销、多退少补；不得写成受托人自担，也不得引用第 952 条。

受托人垫付必要费用：委托人偿还并支付利息。必要费用限于与事务直接相关、有益且合理注意后发生的开支。修改句要求票据原件和用途说明。

费用与报酬分列。报酬是给受托人的对价；费用是办事务花掉的钱。混写成一笔“服务费含一切”且不列预付：必须改拆开。

委托人拒绝预付或预付不足致使事务无法处理：不得据此单独写成受托人违约。修改句写明预付是处理事务的条件。

### 5.2 报酬（第 928、510、511 条）

有约定：写明金额或计算、支付节点、发票、事务未完成或提前解除时的相应报酬。因不可归责于受托人事由解除或不能完成：应付相应报酬，另有约定除外。

无约定或约定不明：

1. 标 `G#`，修改句要求双方书面确认有偿或无偿。
2. 不得输出“商事委托当然有偿”或编造费率。
3. 法律结论路径：协议补充 → 相关条款或交易习惯（第 510 条）→ 仍不能确定则履行地市价（第 511 条）。习惯与市价未核验：字段停止。

有偿与无偿认定影响第 929 条过错标准和第 933 条赔偿范围，必须先固定再写解除和责任。

定金：必须使用“定金”二字才讨论罚则。超过主合同标的额百分之二十的部分不产生定金效力。无核验引文不得把 20% 写成现行法结论。

## 节点 6　显名、隐名与第三人

1. 以委托人名义、在授权范围内实施的法律行为，对被代理人发生效力（第 162 条）。修改句写明对外出示授权书。
2. 受托人以自己名义、在授权范围内与第三人订立合同：
   - 第三人订立时**知道**代理关系：合同直接约束委托人与第三人；有确切证据证明只约束受托人和第三人的除外（第 925 条）。
   - 第三人订立时**不知道**：受托人因第三人原因对委托人不履行时，应向委托人披露第三人，委托人可行使受托人对第三人的权利（第三人若知道该委托人就不会订立的除外）；受托人因委托人原因对第三人不履行时，应向第三人披露委托人，第三人可选择受托人或委托人作为相对人，选定后不得变更（第 926 条）。
3. 禁止把隐名安排一律写成“效果已直接约束委托人”。修改句必须写：披露时点、知情条件、第三人选择权、抗辩延续。
4. 与行纪切开：行纪人对与第三人的合同直接享有权利、承担义务。出现自己名义+贸易+报酬：回节点 1.1 负触发，不在本节点用 925 条硬套贸易。
5. 知情事实不足：字段停止，不推定第三人知道或不知道。

## 节点 7　任意解除、过错责任、格式条款与强制规范

### 7.1 第 933 条（知识库空缺条号）

委托人或者受托人可以随时解除委托合同。

赔偿（除不可归责于该当事人的事由外）：

- 无偿：解除方赔偿因**解除时间不当**造成的直接损失。
- 有偿：解除方赔偿对方的直接损失和**合同履行后可以获得的利益**。

修改句允许：提前书面通知期；无偿/有偿分别写赔偿范围；有偿可得利益的计算基数（已发生成本、剩余约定期报酬中可证明的部分）用 `【待填】`。

禁止输出或保留：

- “双方放弃任意解除权”
- “任何解除通知无效”
- “不得随时解除，解除不发生效力”

最强反方：相对方主张该弃权是意思自治。本任务口径：任意解除为法定安排；实务材料亦指出不得约定排除或限制。弃权无效句红线删除，改成赔偿计算。不把学说上的“目的性限缩”写成现行法。

框架所谓“非因法定事由行使解除权的违约金”：可改写成约定赔偿金或损失预估，但必须可调整、不得写成“解除无效”。

### 7.2 过错责任（第 929、930 条）

有偿：受托人有过错即应赔偿。无偿：仅故意或重大过失。越权造成损失：不论有偿无偿均应赔偿。

受托人因不可归责于自己的事由受损：可向委托人请求赔偿。修改句保留该请求，不写成委托人无条件承担一切经营损失。

### 7.3 格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

为重复使用而预先拟定、订立时未与对方协商的，按第 496 条。提示说明看弃权解除、空白授权、隐名一律约束、管辖等异常条款是否有足以引起注意的标识。仅有网络勾选或弹窗：不得写成已尽提示（解释第 10 条）。

违反法律、行政法规强制性规定不一律无效（第 153 条；解释第 16 条）。禁止用已失效“效力性/管理性”口诀。人身专属、暴力催收、违法事务：不改写成有效履行结构。

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

打开已加载的 `框架.md`，按下列六步逐段对照正文。`基本面.md` 用于校验类型、主体、标的、程序、结构和红旗，不代替本节点出句。

| 步 | 动作 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题名实（委托协议/事务委托）；主体名称资质；鉴于不写实体义务 | 标题或主体修改句 |
| 交易条款 | 事务边界、对外名义、权限清单、费用预付、报酬有无、转委托、报告 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 933 解除赔偿、929 过错分档、隐名披露、争议、通知、保密、利益冲突 | 可执行后果句；禁止弃权无效句 |
| 尾部 | 签署权限、日期、生效、授权委托书及身份证明入附件 | 生效与附件修改句 |
| 语言 | 报酬 vs 费用；代为 vs 代办；正说还要有反说 | 替换空词的句子 |
| 常见问题 | 事务完成标准不明；单笔金额上限；死亡终止例外 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止；
- `必须改`：可谈但签署前要落句；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级金额或个人无限连带且用户拒绝升级：停止“可以签署”建议。

死亡、丧失民事行为能力或终止：原则终止（第 934 条），另有约定或性质不宜终止除外；损害利益时的继续处理与必要措施按第 935、936 条写，不默认自动延续全部权限。
