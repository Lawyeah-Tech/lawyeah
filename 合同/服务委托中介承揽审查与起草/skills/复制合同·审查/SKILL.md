# 复制合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构，不证明本约条款已被接受。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、1984 年《加工承揽合同条例》、1990 年未修正《著作权法》第 10／52 条、1997 年《印刷业管理条例》当作现行规则。不得把印刷承印验证五项制度、委托作品第 19 条权属默认、买卖检验期间视为合格或货交承运人风险，硬套本类型。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **承揽合同 / 复制合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。`depends-on` 为空。不要求先跑导航。

不交付：他类审查、从零起草、履约交底、争议文书、有效性或复制件必然一致／授权必然覆盖／留置必然实现的保证。

## 工作边界

正触发：已有可读待签文本要评改，；尚未签署，尚未成争，核心给付是承揽人**以定作人提供的已有样品为蓝本**，用自己的技术、设备和材料制成与样品高度一致的**复制件**并交付，定作人支付报酬。典型信号：零部件翻制、艺术品复刻、光盘或数字载体复制、样衣打版后按样批量；正文强调还原、1:1、封样比对。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主给付是图书报刊、内部资料、包装装潢或其他须履行承印验证／准印证／印刷委托书的印刷加工 → `印刷合同·审查`；
- 主给付是创作尚未存在的新作品，争点是著作权归属或使用范围 → `委托创作·审查` 或 `主给付是委托创作特定作品→`；
- 已有作品只做许可或转让、不交付复制工作成果 → `或` 或 `或`；
- 无样品、按新图纸或新方案创制 → `定作合同·审查`；
- 定作人供主材、按图加工，样品不是还原蓝本 → `加工合同·审查`；
- 从承揽人库存通用规格挑选，不按特定样品重做 → `通用型号现货卖方组织生产买方不控制过程→`；
- 向公众发行、书号管理、出版单位编辑校对发行一体 → 引擎重新定性，不得当复制放行；
- 无文本、本类型条件已谈妥、要出己方稿 → `复制合同·起草`；
- 已签只问交样、监产、销毁留痕 → 本套导航的履约步骤；
- 已成争（催告、解除、索赔、诉讼仲裁、诉前禁令已发出）→ `或对应专项领域。` 或知产／承揽专项。

仿制公章、特种证件、货币符号、军工禁仿物、明显盗版山寨仍要“改到能复制”：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；定作人或承揽人单一立场；相对方；正文、附件、样品确认书、封样标签、授权复制声明、权利证书版本；样品名称与权源；复制件数量、缩放、材质、公差；开模／数模安排；监产与销毁；不可接受事项；法域与拟签时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价格、数量、日期用 `【待填】`，不编造。

知识双文件若把图书报刊印刷、委托创作新作品写成适用场景，以本技能硬闸和路由为准，不把过宽场景写成正触发。

## 本类型硬闸

审查过程必须逐项点名。禁止用印刷承印验证清单、委托作品权属清单或买卖检验／风险清单代替：

1. **复制 ≠ 印刷 ≠ 委托创作 ≠ 买卖 ≠ 定作**：已有样品还原。出版物／包装装潢印刷走承印验证 → `印刷合同·审查`。创作新作品、权属按第 19 条 → `委托创作·审查`／`主给付是委托创作特定作品→`。库存现货 → `通用型号现货卖方组织生产买方不控制过程→`。无样品新创制 → `定作合同·审查`。
2. **复制权授权必须附件化**：定作人是样品权利人或持有授权复制声明。写清权利种类、数量、地域、期限；未明确许可的权利不得行使。复制不改变原作品或样品的知识产权归属。空白授权不得放行。
3. **封样＋首件＋一致≠相似**：双向封样记录原始瑕疵；批量前书面确认首件；验收用“一致”加公差，禁止只写“相似”。不得擅自改良样品。
4. **超量复制与不得留存**：数量锁死；禁止私自加产、留存副品、尾货流入市场。次品、边角料、测试品、数字化底稿须监督销毁。未经许可不得留存复制品或技术资料。
5. **模具／菲林／数模归属与样品返还**：开模费、代管、终止后移交或销毁必须落句。原样完好返还；存放期间毁损风险原则上由承揽人承担。
6. **资质、违禁与侵权闭环**：图书印刷、音像复制等须对应许可，缺许可字段停止。公章、证件、货币、军工禁仿停笔。定作人担保样品合法；发现权利瑕疵立即停工并可解除。不得把“名为复制实为山寨”改成可履行。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验承揽定义（含复制）、亲自完成、保密不得留存、复制权与许可范围、委托作品负向切开、印刷／音像许可；`search_practiced` 补复制与印刷／委托创作切开、共同侵权、超量复制争点；`search_template` 只借修改句结构。不虚构案件系统。

`search_law` 对法律结论为 required 级节点：不可用时不拒绝执行，只停止法律结论字段。返回已失效《合同法》《加工承揽合同条例》、1990 年未修正《著作权法》或 1997 年《印刷业管理条例》时记为噪声，不得写入 `L#`。返回印刷承印验证专条或委托作品第 19 条时，不得当作本类型默认给付或默认权属。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、把盗版／山寨／禁仿物改成可履行、无复制权授权仍要求放行、保证复制件必然一致或授权必然覆盖。
- `字段停止`：样品无法特定化；授权范围未写清；封样／首件未附件化；印刷或音像许可未核验；模具归属未写。
- `目标停止`：主目标已变为他类型起草、履约交底或争议文书。

生存级预付款或个人无限连带且用户拒绝升级：停止“可以签署”建议。
