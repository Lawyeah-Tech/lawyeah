# 边界与路由

本技能只审查 **承揽合同 / 复制合同**。核心给付是以已有样品为蓝本制成高度一致的复制件，不是出版物或包装装潢印刷，也不是委托创作新作品。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 图书、报刊、内部资料、包装装潢或其他须验证印刷委托书／准印证／印刷经营许可证的批量印刷 | `印刷合同·审查` |
| 委托创作尚未存在的新作品，主轴是著作权归属、使用目的或源文件 | `委托创作·审查` 或 `主给付是委托创作特定作品→` |
| 已有作品财产权许可，不交付复制工作成果 | `或` |
| 已有作品财产权转让 | `或` |
| 无样品、按新图纸或新方案创制工作成果 | `定作合同·审查` |
| 定作人提供主要材料，按图加工，样品不是还原蓝本 | `加工合同·审查` |
| 从库存通用规格挑选，不按特定样品重做 | `通用型号现货卖方组织生产买方不控制过程→` |
| 贴委托方商标、品牌授权代工为主给付 | `定牌加工（OEM）合同·审查` |
| 向公众发行、书号、出版单位编辑校对发行一体 | 引擎重新定性；不得当本类型放行 |
| 无文本、本类型条件已谈妥、要出己方稿 | `复制合同·起草` |
| 已签未争、交样／监产／销毁／退原样留痕 | 本套导航的履约步骤 |
| 已成争（质量异议、催告、解除、索赔、禁令、立案、仲裁） | `或对应专项领域。` 或知产／承揽专项 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。

本技能不得转去加载印刷、委托创作、定作或加工双文件完成本类型审查。一旦核心给付是承印验证下的印刷、新作品创作或无样品创制，立即负触发，不得删掉印刷委托书、权属条款或新图纸后继续当复制审。
