# 边界与路由

本技能只审查 **委托合同 / 委托他人设计的服务合同** 的待签文本。中文展示名是「审查委托他人设计的服务合同（委托合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 方案、初步设计或施工图供报审或施工；图审；设计资质章；注册建筑师/结构师出图盖章 | `单独设计发包，无现场简易施工成果`。不得按本类型改成可履行出图，不得抄其资质/图审/限额/招标主路径 |
| 广告创意、广告制作或广告发布；广告主/经营者/发布者结构；媒介投放或广告法内容审查为主轴 | `广告设计合同·审查`。夹带广义广告、发布或代言再分 `广告合同（广义）·审查` / `广告发布合同·审查` / `广告代言服务类合同·审查`。不得删投放后硬套 |
| 以委托人名义处理对外事务、代签、代付款；授权委托书或隐名订约为主轴 | `一般委托合同·审查`。不得按空白授权或 925/926 主路径改完本类型 |
| 剧本、交响乐、小说等高独创文艺创作 | `委托创作·审查` |
| 代笔、代写文稿为主轴 | `委托代笔合同·审查` |
| 委托研发软件、技术方案或样品开发 | `委托技术开发合同·审查` |
| 只出可行性、工艺评价、管理建议，不交付设计稿 | `咨询服务合同·审查`；文本落在委托技术咨询目录下则 `委托技术咨询·审查` |
| 按图加工、定作物化成品并验收实物 | `加工合同·审查` 或 `定作合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 留本任务起草并自审 |
| 已签未争、只问交稿日或发票 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

正文里夹带一小段广告投放或对外代办：专条交接对应原子；设计范围、任务书、验收、权属、字体授权、源文件条款可继续审。用户坚持本技能把建设工程出图、广告设计或一般事务委托整案改完：`目标停止`。
