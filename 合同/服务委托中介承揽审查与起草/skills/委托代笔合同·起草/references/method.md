# 审查方法（锁定 委托合同 / 委托代笔合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制 `委托创作·审查` 或 `主给付是委托创作特定作品→` 的 method。货架父级是委托合同，交易结构是隐名执笔：不按普通委托创作审“创作者署名 + 默认权属归受托人”主路径，不按已完成作品转让审登记过户。

定性校验：标题、核心给付与本类型一致才继续；明显普通委托创作、一般委托、著作权转让、设计服务或技术开发则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、放弃署名即委托人必然成为作者、对方必然接受或唯一必得金额。

`search_law` 返回已失效《合同法》及其解释、1990 年著作权法未修正第十条、1991 年著作权法实施条例、担保法解释或涉外经济合同法时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

示范文本只参考结构。委托创作或文案策划范本不证明本约条款已被接受。不调用、不粘贴代写论文模板。

知识库纠正（不回写双文件）：

- `基本面.md`“放弃署名权在民法上通常有效”：过强。第十条可转让的只有第五项至第十七项。可约定自愿不行使署名，但现有依据不支持“放弃即委托人成为作者”，也不支持该约定必然排除行政、出版或平台合规风险。
- `基本面.md`“代建方同意不以任何方式行使署名权”：笔误，按代笔人理解，不回写。
- `框架.md`把发表权、修改权、保护作品完整权与全部财产权一并“独占归甲方”：人身权不在可转让清单。财产权须逐项列明；发表可由委托人决定是否公之于众，修改与保护作品完整不得写成转让。
- `框架.md`“身份重构/机械整理/学术顾问”：仅当事实支持委托人提供口述、大纲或核心素材、受托人整理表达时，可把角色写成文字整理。禁止把独立创作改写成虚假机械整理以制造作者。学位论文、职称论文不得用学术顾问包装。
- `框架.md`标的列举含“学术论文”：资格证明类代写在节点 1.4 停笔，不进入可履行修改。
- `基本面.md`建议标题写成《委托创作合同》：审查时标题可用《文字整理与编辑服务协议》或《文案策划服务协议》降低“枪手”道德审查噪音，但定性仍按核心给付；不得因标题回避“代笔”就转去 `委托创作·审查` 或当普通委托创作放行。

| 已能支持的事实 | 走向 | 不得写成 |

## 节点 1　类型识别、与委托创作切开、资格证明类停笔

### 1.1 定性

用标题、核心给付、对外署名安排和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须切开后再加载，禁止两可时灌入委托创作或转让知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 受托人完成表达，对外隐去执笔人，以委托人名义作为作者发表或使用 | 委托代笔合同 | 正触发；走硬闸 2–6 |
| 从无到有创作作品，受托人可署名或公开作者身份，权属按委托作品约定 | 委托创作 | 负触发 `委托创作·审查`；知识产权货架主文件 → `主给付是委托创作特定作品→` |
| 只搜集素材、校对、咨询，不负责具体表达 | 一般委托 | 负触发 `一般委托合同·审查` |
| 整理已有口述或文稿，保留原作者并标注整理者 | 整理作品，不是代笔 | 负触发引擎或 `委托创作·审查`；本任务不把“双方署名的整理”改成隐名 |
| 已完成作品，处分复制、发行、信息网络传播等财产权 | 著作权转让/许可 | 负触发 `或` / `或` |
| 功能性、技术性设计交付 | 设计服务 | 负触发 `委托他人设计的服务合同·审查` |
| 技术方案、专利或技术秘密 | 委托技术开发 | 负触发 `委托技术开发合同·审查` |
| 学位论文、职称论文、考试答卷、科研申报或论文代写代投 | 资格证明类代写 | 停笔，见 1.4；不转去创作原子改成可履行 |

### 1.2 与委托创作切开（硬闸 1）

| 事实 | 作者对外呈现 | 本任务 | 不得写成 |
| --- | --- | --- | --- |
| 隐名执笔，委托人对外作为作者 | 代笔结构 | 正触发 | 已经与委托创作无差别 |
| 受托人署真名、笔名或“编剧/撰稿”且不要求隐瞒 | 委托创作 | 负触发 `委托创作·审查` | 用本技能改完创作文本 |
| 标题是委托创作，正文要求永不披露执笔身份 | 名实冲突 | 按代笔留本任务；标题冲突写入 `C#` | 因标题转走而漏审隐名 |
| 标题回避“代笔”，正文是独立创作且允许受托人署名 | 委托创作 | 负触发 | 因标题像策划服务就当代笔审完 |

修改句（正触发首部）：`本合同项下，乙方根据甲方提供的【口述记录/大纲/素材清单】完成文字表达，对外不以作者身份署名。甲方可以自己的名义发表和使用本作品。乙方的工作性质为隐名执笔，不同于乙方以作者身份署名的委托创作。`

最强反方“标题都叫委托创作，应按第十九条只约定财产权”：第十九条解决财产权归属，不解决作者是谁，也不消灭署名权。隐名安排必须单独落句。

### 1.3 加载协议（硬闸）

本技能已锁定 **委托合同 / 委托代笔合同**。只打开 `references/基本面.md` 与 `框架.md`。禁止读其他子目录，禁止打开 `委托创作·审查` 或 `主给付是委托创作特定作品→` 的 method。

### 1.4 资格证明类与规避结构停笔

加载后或定性中出现：学位论文、毕业论文、毕业设计、职称评审代表作、职业资格考试答卷、科研项目申报书、学术论文买卖代写代投；或用户要求把上述标的改成“学术顾问/机械整理”以便能签。

支持依据：民法典第一百五十三条第二款；合同编通则解释第十七条；学位法第三十七条；学位论文作假行为处理办法第三条、第七条、第八条；高等学校预防与处理学术不端行为办法第二十七条第（四）（六）项；职称评审管理暂行规定第三十九条；科学技术进步法第一百一十二条。

动作：

1. 交付告知：该结构损害教育评价、职称评价或科研诚信所保护的公共秩序，不得改写成可履行文本。已付款项能否返还：依据不足，不得写成“必然能要回”或“必然要不回”。
2. 不写顾问包装、虚假素材清单、可履行的代写进度款或查重规避步骤。
3. 风险表只保留识别依据和停笔/转出口径。
4. 用户坚持“改到能签”：整体停止。

商业自传、演讲稿、企业宣传文案、文学作品等非资格证明类：继续审查，但仍须过作者身份和署名闸。

挂靠、违法分包、伪造倒签、补假口述记录：同样只告知，不改写成可履行规避。

## 节点 2　主体、作者身份、素材贡献

### 2.1 主体表

建表：委托人签约名、对外署名名、受托人签约名、实际执笔人、付款名、发票名、授权签字人。名称不一致不自动合并。

受托人为工作室或公司：必须指向实际执笔自然人，并处理职务作品或转委托链条。口头“我们团队写”不得写成已锁定作者。知名执笔人与经纪公司的排他创作限制未见：标 `G#`，不编造。

自然人执笔：本人签字并按指印；身份证复印件作附件，只记录已提供，不在意见中抄写证件号。

### 2.2 作者身份不能由合同单独制造（硬闸 2）

支持依据：著作权法第十一条——创作作品的自然人是作者；由法人或非法人组织主持、代表其意志创作、并由其承担责任的，该组织视为作者。第十二条——在作品上署名的视为作者，有相反证明的除外。第十九条——未约定或没有合同的，著作权属于受托人。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 委托人提供口述录音、大纲、笔记或核心事实，受托人按甲方口吻整理表达，并附《原始素材清单》 | 可接受；修改句把贡献方式写入鉴于和附件 | 委托人因此必然是作者 |
| 无任何构思或素材，受托人独立完成，正文却写“甲方为唯一作者” | 必须改或红线：删除“唯一作者”拟制；改为财产权约定 + 自愿不行使署名；提示作者身份仍可能被相反证明 | 合同一签作者就是甲方 |
| 用户要求把独立创作改成“机械整理/资料员”以便主张甲方是作者 | 整体停止该改写；可建议补真实贡献或改走委托创作并让受托人署名 | 用虚假整理制造作者 |
| 自传体，合意以特定人物经历为题材 | 核解释第十四条：有约定从约定，无约定著作权归该特定人物；执笔人可获适当报酬 | 自传一律归执笔人或一律归传主且无需约定 |
| 主张法人作品 | 核主持、代表意志、由该组织承担责任三项；缺一项不得写成视为作者 | 公司盖章即法人作品 |

修改句：`甲方确认已向乙方提供附件所列口述记录、大纲及核心素材，并对作品主题、结构、事实和口吻作出实质性指示。乙方根据上述材料完成文字表达。双方确认：作者身份依照著作权法认定，本合同关于不署名和财产权的约定不改变“创作作品的自然人是作者”的法定标准，也不排除相反证明。`

最强反方“第十九条约定归委托人就等于委托人是作者”：第十九条处理著作权归属，主要覆盖可约定的财产权；作者是创作事实问题。无贡献时，放弃署名也不能把作者身份写死。

### 2.3 共有、职务作品、在先负担

执笔人是其他单位员工且可能构成职务作品：标缺口，修改句要求受托人保证有权处分并取得作者书面确认。改编、续写或使用第三人素材：须有在先授权。材料未提及不得写成“无权利负担”。

## 节点 3　署名安排与财产权

### 3.1 署名权不可转让（硬闸 3）

支持依据：著作权法第十条——署名权是表明作者身份、在作品上署名的权利；著作权人可以许可或转让的是第一款第五项至第十七项。第二十二条——署名权、修改权、保护作品完整权的保护期不受限制。第二十九条——未明确许可或转让的权利，另一方不得行使。

| 文本写法 | 动作 | 不得写成 |
| --- | --- | --- |
| “乙方将署名权转让给甲方”“永久放弃署名权，甲方成为唯一作者” | 必须改：删除转让和作者拟制；改为自愿不行使署名、不以任何方式表明或暗示执笔身份 | 转让有效即作者变更 |
| “全部著作人身权（发表、修改、保护作品完整、署名）归甲方独占” | 必须改：人身权不整包转让；发表可约定由甲方决定是否公之于众；修改须经乙方配合但不写转让；保护作品完整不放弃 | 人身权买断已合法 |
| “乙方自愿不在作品上署名，不以真名或笔名表明作者身份；对外由甲方署名” | 可接受；须补：不消灭作者身份、不替代合规审查；并挂钩确认书和泄密责任 | 该句已保证永远不会被相反证明 |
| 完全不写署名 | 必须改：隐名是本类型核心给付，不能留空 | 未写即默认可隐名 |

修改句：`乙方同意不在本作品及其任何版本、衍生品、宣传物料上署名，不以真实姓名、笔名或其他可识别方式表明或暗示其作者身份或执笔事实。甲方可以自己的名义发表和使用本作品。双方确认：本条约定是乙方对署名权的行使安排，不构成署名权转让，不使甲方当然成为作者，也不免除任何一方在出版、平台或行政管理中的合规义务。`

### 3.2 财产权须逐项约定

支持依据：第十九条；第二十七条权利种类、地域、价金。未约定则著作权属于受托人，委托人仅得在委托目的范围内使用——本类型若要买断商业利用，必须逐项写复制、发行、信息网络传播、改编、翻译、摄制等，并写地域和期限。禁止只写“全部知识产权归甲方”。

回购条款（框架）：可写若嗣后被认定为乙方仍享有某项财产权，甲方有权以约定价款【待填】取得该权利。不得写成回购能补正资格证明类代写的效力。

### 3.3 影子作者（硬闸 6 的主体侧）

工作室未点名执笔人：必须改。修改句：`实际执笔人为【姓名】。未经甲方事先书面同意，乙方不得更换执笔人或转委托。更换后的文风、质量仍由乙方负责，且须重新签署不行使署名与保密确认。`

## 节点 4　程序、验收、质量与任意解除

### 4.1 创作程序

设置：前期沟通 → 大纲确认 → 分章或分稿交付 → 总稿审定。每阶段期限、甲方反馈期限【待填】。签收、付款、发表不当然等于验收，除非合同有可回链约定。

### 4.2 主观质量可核验（硬闸 6）

风格、口吻、“像我写的”属于主观标准。必须有：附件样章或既往文风样本；免费修改【待填】次；超出后按【待填】计费或甲方可终止并按已确认部分结算。禁止只写“直至甲方满意”。

修改句：`乙方应根据附件确认的大纲、口吻样本和甲方书面意见修改。免费修改次数为【待填】次。甲方须在收到稿件后【待填】日内提出书面意见，逾期视为该稿阶段通过。因风格主观分歧且已完成约定修改次数的，甲方可书面终止；已确认章节的报酬按【待填】结算，未确认部分预付款扣除已发生劳务后多退少补。`

### 4.3 任意解除

支持依据：第九百三十三条。双方可随时解除委托合同；有偿委托的解除方应赔偿直接损失和合同履行后可以获得的利益。合同可约定通知期和结算公式，难以彻底剥夺法定解除。写“任何一方不得解除”必须改。

## 节点 5　对价、身份保密、草稿移交

### 5.1 身份保密与对价闭环（硬闸 5）

报酬构成：基本劳务费 + 不行使署名补偿。支付节点：预付款 + 大纲确认款 + 定稿款。尾款【待填】％可作为保密保证金，于作品公开发表后【待填】日且未发生泄密时支付。支付定稿款的前提是乙方签署《不行使署名权确认书》并移交草稿。

保密范围：合同存在的事实、执笔身份、创作过程、甲方私密素材、往来记录。期限：永久，不因履行完毕、解除或无效争议而终止——无效争议中保密条款是否独立：字段待核，修改句仍要求独立存续。

泄密：向任何第三方披露其为实际执笔者，或主张拥有本作品作者身份或财产权（确认书范围外），应支付违约金【待填，通常可高于劳务费】。最强反方“违约金过高”：第五百八十五条、合同编通则解释第六十四条——不得写“不得调整”；可写考虑隐名安排的不可逆声誉损失后协商确定。

修改句：`本合同报酬分为劳务费人民币【待填】元和不行使署名补偿人民币【待填】元。甲方在乙方签署附件《不行使署名权确认书》并移交全部草稿、电子文档和底层素材后支付定稿款。乙方对代笔事实、合作关系及甲方素材承担永久保密义务。乙方违反本条的，应支付违约金人民币【待填】元，并停止披露、配合删除；该金额不影响甲方依法请求调整或追加赔偿的权利，双方不得约定排除人民法院或仲裁机构对违约金的调整。`

### 5.2 草稿移交与查重

交付后签署验收确认书；移交全部创作草稿和底层素材；限制私自留存用于主张权利。签约前及交付后查重，防止洗稿。查重系统名称【待填】。抄袭导致甲方名誉或第三方索赔：乙方承担相应赔偿和消除影响，不写成“全部损失必得且不得调整”。

### 5.3 第三人与素材责任

出版社、平台因作品真实性、原创性追责：合同须切分。素材由甲方提供的事实、隐私、名誉、肖像，甲方保证真实且有权使用；表达抄袭、洗稿由乙方保证。委托人作为对外公示的作者，对第三人可能首先被请求——只提示，不在本任务分配诉讼策略。

涉政、侵害他人隐私或虚构他人犯罪事实：标红旗；内容必然违法的，停笔不改成可发表结构。

## 节点 6　格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 是否格式条款

代笔工作室为重复使用预先拟定的文本，按第四百九十六条审查提示说明。免责、永久放弃权利、高额违约金、管辖或仲裁须有足以引起注意的标识。小字、夹在附件、仅网络勾选：不得写成已尽提示或说明义务。

### 6.2 强制规范

违反法律、行政法规强制性规定不一律无效。区分合同编通则解释第十六条各项。禁止用已失效“效力性/管理性”口诀。资格证明类代写、以合法形式掩盖非法目的：不改写成有效履行结构。

第一百五十三条第二款与解释第十七条：影响社会公共秩序或善良风俗的，可认定无效。学位论文、职称、考试、科研代写属于此类审查重点，不把个别商业自传隐名当然类推为无效，也不把商业隐名当然类推为有效。

## 节点 7　违约、解除、争议解决

逾期交稿、逾期付款、泄密、抄袭必须分别有可执行后果。只有“依法承担违约责任”视为必须改。构成违约不等于当然解除。法定解除只点名催告或目的不能实现，不在本任务作出已解除结论。

争议解决：或裁或诉、机构不明标待核。出现仲裁条款不得改写成“应向某法院起诉”并假装已选定诉讼。

通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。
