# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的佣金、账户、期限；把已失效《合同法》居间章写入结论；把无牌写成可以展业；把口头告知写成已揭示或已适当；把保证收益或全权委托改成可履行；把普通中介、保险代理或投资咨询当成已完成的本类型审查。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查保险_证券_期货经纪中介合同（中介合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》居间章或其解释、已失效保险经纪旧规、已失效期货经纪公司管理办法时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `中介合同`，子级 `保险_证券_期货经纪中介合同`。定性理由、易混切开结果（普通中介、保险代理、投资咨询、一般委托、行纪）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。证券期货依法以自己名义进场，不写成已转行纪。

## 4. 主体、牌照、人员与文本版本

主体表：签约名、履行名、付款名、发票名、授权签字人。资格表：许可证种类与执业状态、承办人员执业登记。版本表：正文、风险揭示书、适当性评估、授权委托书、双录确认、聊天确认；冲突并列。未核牌照或人员：该签署能力字段停止。

## 5. 给付、适当性、指令与资金

核心给付是保险经纪、证券经纪或期货经纪中的哪一种；是否夹带代理或咨询；适当性类别与匹配意见；指令方式与是否残留全权委托；佣金比例、支付主体、犹豫期退佣；客户资金账户是否法定结算／保证金／托管路径。缺口标 `G#`。不输出普通房屋中介或保险理赔争议主路径。

## 6. 承诺收益、格式条款与强制规范

是否出现保证收益、分担损失、垫资、配资。是否构成格式条款。强制规范只按第一百五十三条和解释第十六条区分，不用失效口诀。无牌／承诺收益／全权委托／配资只保留识别与停笔。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把框架里的“利益最大化”写成证券期货可代为决策。

## 9. 谈判与签署提醒

谈判顺序：先红线（无牌、保证收益、全权委托、配资／垫资、资金进私户），再必须改（适当性附件、揭示书与双录、佣金支付主体、利益冲突披露、犹豫期退佣），最后可优化。签署提醒：机构公章或备案业务专用章；揭示书、适当性证明、授权委托书、双录确认入附件；客户资金账户与佣金账户分列。不指导倒签或补假牌照。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书或效力保证，也不是普通中介、保险代理或投资咨询审查。
