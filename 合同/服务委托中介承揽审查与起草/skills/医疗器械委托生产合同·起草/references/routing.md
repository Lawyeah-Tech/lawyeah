# 边界与路由

本技能只审查 **承揽合同 / 医疗器械委托生产合同** 的待签、注册人／备案人委托具备相应条件的企业按核准要求生产已注册或备案医疗器械的文本。中文展示名是「审查医疗器械委托生产合同（承揽合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 定牌、贴牌、品牌授权 + 工厂自有工艺；无注册人委托生产主轴；无质量协议和上市放行 | `定牌加工（OEM）合同·审查` |
| 来料或供图加工通用物，无医疗器械注册／生产监管主轴 | `加工合同·审查` |
| 定作同类，承揽人自备材料制作非监管医疗器械 | `定作合同·审查` |
| 修理、复制、印刷、测试测绘、检验鉴定 | `修理合同·审查`／`复制合同·审查`／`印刷合同·审查`／`测试测绘合同·审查`／`检验鉴定合同·审查` |
| 框架 + 订单高频下单，无器械监管主轴 | `框架加订单承揽·审查` |
| 项目承揽、涉外承揽本约 | `项目承揽合同·审查`／`涉外承揽合同·审查` |
| 采购已放行成品，只移转所有权 | 买卖对应原子或 本套导航的类型切开步骤 |
| 尚未完成的研制、临床、注册检验；对价绑研发里程碑 | `委托技术开发合同·审查` 或 `只审委托合同目录下的委托技术开发。用户或材料按技术类合同进入《技术开发合同》→` |
| 药品委托生产或化妆品委托加工 | 本套导航的类型切开步骤，不按本类型改完 |
| 无文本、本类型条件已谈妥、要出己方稿 | 留本任务起草并自审 |
| 已签未争、只问批次放行或付款节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或对应专项领域。` 或对应专项领域 |
| 药监查处、吊证、召回已立案 | 行政或争议专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

委托生产正文里夹带一小段商标使用或物料采购：专章交接对应原子或分条改写；注册人委托生产条款可继续审。用户坚持本技能把 OEM、普通加工、委托研发、药品或化妆品委托生产整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
