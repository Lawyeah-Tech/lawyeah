# 边界与路由

本技能只审查 **委托合同 / 拆迁委托协议** 的待签、房屋征收部门委托实施单位承担征收与补偿具体工作的文本。中文展示名是「审查拆迁委托协议（委托合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或抄写 `的method，禁止把本约改成对被征收人的补偿安置文本。` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 房屋征收部门或实施单位与被征收人订立补偿方式、金额、产权调换、搬迁期限、停产停业损失 | `的method，禁止把本约改成对被征收人的补偿安置文本。` |
| 土地整理、熟地交付、一级开发投资回报、成本核定 | `土地一级开发委托合同·审查` |
| 一二级联动、土地出让收益分成、熟地与二级开发捆绑 | `“一二级联动”相关合同·审查` |
| 房地产委托代建、出图施工交付 | `房地产委托代建合同·审查` |
| 政府代建 | `政府代建合同·审查` |
| 普通民事事务委托；任意解除、隐名代理为主轴 | `一般委托合同·审查` |
| 房屋拆除、渣土清运、拆净作为工程量结算 | `工地建筑活动承包资质竣工验收→` |
| 开发商、建设单位以“拆迁人”身份委托，依赖拆迁许可证或 2001 年旧条例 | 不按本类型改成可履行；告知改走现行征收实施委托或停笔 |
| 无文本、本类型条件已谈妥、要出己方稿 | `拆迁委托协议·起草` |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或对应专项领域。` 或对应专项领域 |
| 复议、行政诉讼、申请法院强制执行、违法强拆已立案 | 行政或征收专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

拆迁委托正文里夹带一小段补偿标准或拆除工程量：专章交接对应原子或分条改写；委托实施条款可继续审。用户坚持本技能把补偿安置、一级开发、代建或拆除施工整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
