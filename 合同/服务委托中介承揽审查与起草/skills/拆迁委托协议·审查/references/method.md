知识库纠正（不回写双文件）：

- `基本面.md` “行政征收决定权、补偿决定权、强制执行申请权必须由征收部门保留”：方向采用，主体要拆细。征收决定和申请人民法院强制执行在作出征收决定的**市、县级人民政府**（条例第八、十二、二十八条）。补偿协议签约名义在**房屋征收部门**（第二十五条）。补偿决定由征收部门报请市、县级人民政府作出（第二十六条）。实施单位一律不得成为这些职权的权利人。
- `基本面.md` “实施单位与被征收人签订的补偿协议，法律后果由征收部门承担”：对外责任方向正确（第五条第二款；行政诉讼法解释第二十五条）。签署名义仍须是征收部门；实施单位自己盖章或指挥部、项目部章对外冒充征收机关的，本任务红线改写，不放行。
- `框架.md` “乙方组织签订补偿协议”：只允许协助洽谈、草拟；必须出示授权委托书，且协议经甲方审核加盖征收专用章后生效。
- `框架.md` “包干模式……属于无效或违法条款”：包干结余归乙方、按补偿款抽成违反第五条不得营利，必须删除或改固定报酬。是否导致整约无效走第一百五十三条和合同编通则解释第十六条，不在本任务宣告整约无效。
- 民法典第九百三十三条任意解除：民事委托默认规则，不是征收实施委托的审查主路径。本约解除应写违法超权、非法逼迁、弄虚作假、重大安全或信访事故、监督失败，不写成双方可随时甩手且已对外签署的补偿协议一并作废。
- 本委托协议在实务中可能被认定为行政委托或行政协议；**补偿协议**才是行政协议司法解释第二条明确列举的“土地、房屋等征收征用补偿协议”。不得把本约十节写成已经完成对补偿协议的审查。
- 民法典第九百二十五条全文本次未稳定命中，不写入 `L#`。显名代理效果用条例第二十五条、第五条和第二款、行政诉讼法解释第二十五条、行政协议司法解释第四条吸收。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

支持切开的规范（法律结论须运行时复核）：

- 条例第四条：市、县级人民政府负责房屋征收与补偿；房屋征收部门组织实施。
- 条例第五条：征收部门可以委托实施单位承担**具体工作**；实施单位不得以营利为目的；征收部门对委托范围内行为负责监督并承担法律责任。
- 条例第二十五条：补偿协议由**房屋征收部门与被征收人**订立。
- 条例第二十六条：达不成协议或所有权人不明确的，由征收部门报请市、县级人民政府作出补偿决定。
- 行政协议司法解释第二条：土地、房屋等征收征用补偿协议属于行政协议受案范围。第四条：因行政机关委托的组织订立的行政协议发生纠纷，被告是委托的行政机关。
- 民法典第九百一十九条：委托合同是约定受托人处理委托人事务的合同。第九百二十条：可以特别委托一项或数项，也可以概括委托一切事务——**民事任意概括委托不得用来外包征收职权**。

## 节点 3　受托权限封闭（硬闸）

### 3.1 可委托的具体工作

打开 `基本面.md` 第三步与 `框架.md` 标的条款，逐项打钩。可写入受托范围的通常是：

1. 协助调查登记房屋权属、区位、用途、建筑面积（条例第十五条是征收部门的组织职责，实施单位只是受委托具体执行）；
2. 协助拟定或测算补偿方案草稿，供征收部门审定；
3. 政策宣传、解释、入户摸底；
4. 在授权范围内组织洽谈，协助草拟补偿协议文本；
5. 档案整理、分户补偿情况汇总供公布（第二十九条）；
6. 协助安置选房手续、现场秩序和腾空后的移交。

调查结果公布、补偿方案确定、分户补偿公布的名义仍是征收部门。

### 3.2 不得写入受托权限的职权

| 文本写法 | 本任务动作 | 依据 |
| --- | --- | --- |
| “乙方全权作出房屋征收决定” | 红线删除。征收决定由市、县级人民政府作出 | 第八条、第十二条 |
| “乙方有权作出补偿决定并公告” | 红线删除。由征收部门报请市、县级人民政府作出 | 第二十六条 |
| “乙方有权向法院申请强制执行／组织强拆” | 红线删除。由作出征收决定的市、县级人民政府申请人民法院强制执行 | 第二十八条；法释〔2012〕4 号第九条 |
| “概括委托乙方处理本项目一切征收与补偿事宜” | 必须改：改为特别委托清单；第九百二十条的概括委托不得用来填职权真空 | 第五条；第九百二十条 |
| “甲方将征收职权整体移交乙方” | 红线：职权不可转让 | 第四条、第五条 |

钉子户、达不成协议：修改句只写乙方在【待填】日内书面报告甲方，由甲方依法报请补偿决定；不得写乙方“负责拿下”或“有权采取一切必要手段”。

### 3.3 评估、审计不得兼任

条例第二十条：评估机构由被征收人协商选定；协商不成通过多数决定、随机选定等方式确定；任何单位和个人不得干预。第二十九条：审计机关监督补偿费用。

实施单位不得写成评估机构，也不得写成有权指定评估机构或干预评估。评估、审计委托另签，不进本约受托范围。

## 节点 4　不得代签补偿协议冒充征收机关（硬闸）

### 4.1 签约主体

条例第二十五条：补偿协议的双方是房屋征收部门与被征收人。行政协议司法解释第二条把该类协议列为行政协议；第四条明确委托组织订立行政协议时被告仍是委托行政机关。行政诉讼法解释第二十五条：实施单位在委托范围内的行为，被告是房屋征收部门。国家赔偿法第七条：受委托组织行使受委托行政权力致害，赔偿义务机关是委托行政机关。

| 文本写法 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| “乙方与被征收人签订补偿协议，加盖乙方公章或项目部章即生效” | 红线：改为乙方协助洽谈、草拟；协议以甲方为一方，经甲方审核并加盖征收专用章后生效 | 实施单位可以自己当征收机关 |
| “乙方可使用甲方征收专用章，无需再审” | 红线：专用章不得外借；每份协议甲方审核 | 预盖章外带合法 |
| “乙方出具的承诺、补充协议、奖励说明对甲方自动有约束力” | 必须改：超越授权或超出补偿方案的承诺对甲方不生效；造成损失甲方有权追偿 | 超方案承诺当然有效 |
| 仅写“组织签订补偿协议”，未写署名和审核 | 必须改：补授权书出示、甲方审核、征收专用章 | 组织＝代签 |

### 4.2 授权委托书

附件必须有《授权委托书》，写明：

1. 委托人（征收部门全称）；
2. 受托人（实施单位全称及现场负责人）；
3. 具体事项（洽谈、草拟、送达、登记，**不含**作出征收决定、补偿决定、申请强制执行、独立签署补偿协议）；
4. 期限与项目红线；
5. 出示义务：入户和签约现场必须出示原件或盖章复印件。

无授权书：必须改，列为附件生效条件。口头授权不得写成已授权。

### 4.3 与补偿安置切开

本任务不审、不改、不补：补偿方式、补偿金额、产权调换地点面积、搬迁费、临时安置费、停产停业损失、奖励标准。用户要评改这些条款：负触发 `的method，禁止把本约改成对被征收人的补偿安置文本。`。本约只可引用“严格执行已公布的征收补偿方案，不得承诺方案外货币或实物”。

| 文本写法 | 动作 |
| --- | --- |
| 按征收补偿款总额或节余的一定比例计提劳务费 | 红线：改为固定劳务费或固定报酬加考核奖金；考核可绑签约进度、档案完整、平稳度，不绑“少赔多赚” |
| 总补偿额度由乙方包干，结余归乙方 | 红线删除。包干诱发克扣或极端拆迁 |
| 固定户均劳务费＋审计后奖金 | 可接受结构；数字用 `【待填】` |
| 预付款用于启动调查，大头与腾空交付、审计通过挂钩 | 可接受；腾空不得早于先补偿后搬迁 |

抽成或包干条款删除后，其余劳务费条款可继续审。不宣告整约无效。

### 5.2 补偿款专户与代付／垫付

条例第十二条：作出征收决定前，征收补偿费用应当足额到位、专户存储、专款专用。第二十九条：审计监督。

修改句必须分清：

1. 补偿款在甲方或财政指定专户，专款专用；
2. **代支付**：甲方拨入后由乙方按已盖征收专用章的协议代发，当日对账；
3. **代垫付**：乙方先垫付补偿款——标高风险；无财政或甲方书面指令不得放行垫资模式；
4. 禁止截留、挪用、坐支；虚假补偿由乙方承担追偿和移交责任。

不得把补偿款写成乙方经营收入。

### 5.3 入户工作期与征收决定有效期

框架要求区分“入户工作期”与“行政征收决定作出后的搬迁期限”。修改句分列：委托期限自【待填】至【待填】；搬迁期限以补偿协议或补偿决定为准，本约不得另定强制搬迁日。

## 节点 6　禁止逼迁、拆除切开与安全

### 6.1 非法逼迁（硬闸）

条例第二十七条：先补偿、后搬迁；任何单位和个人不得以暴力、威胁或违反规定中断供水、供热、供气、供电和道路通行等非法方式迫使搬迁；禁止建设单位参与搬迁。第三十一条：造成损失的赔偿，并可能刑事、处分、治安处罚。行政强制法第四十三条：行政机关不得对居民生活采取停水停电等方式迫使履行。

| 文本写法 | 动作 |
| --- | --- |
| 考核含“采取必要措施促迁”“可对拒迁户停水停电” | 红线删除；只出告知，不改成可履行替代手段 |
| 建设单位、开发商派人参与搬迁或清场 | 红线：删除参与搬迁；开发商不得当实施单位 |
| 乙方负责强制拆除未签协议房屋 | 红线：强制执行只能由市、县级人民政府申请法院 |

### 6.2 实施单位 ≠ 拆除施工单位

物理拆除、渣土清运是工程施工。本约可写“甲方另行选定拆除施工单位，乙方配合腾空后的现场移交与安全看护”，不得把拆除工程量、质保金、竣工验收写进本委托当主给付。用户坚持评改拆除施工条款：负触发 `工地建筑活动承包资质竣工验收→`。

现场施工安全、消防、看护可约乙方责任，但不得写成乙方有权在未补偿、未腾空时进场拆除。

## 节点 7　违约、解除、争议与强制规范

### 7.1 可执行后果

必须分别有后果：超越授权承诺方案外补偿；弄虚作假骗取补偿款；非法逼迁；截留挪用补偿款；干预评估；拒不配合审计；甲方逾期拨付劳务费或补偿款导致停摆。

只有“依法承担违约责任”视为必须改。甲方因乙方过错对外赔偿、协议被撤销或被确认违法的，修改句写追偿，不写“乙方免责”。

第五百零六条：造成对方人身损害，或因故意、重大过失造成对方财产损失的免责条款无效。“因搬迁发生的一切人身财产损失由被征收人自负、与甲乙无关”必须改。

### 7.2 解除

可约定：重大投诉或安全事故、严重舞弊、非法逼迁、丧失非营利或实施资格时甲方解除。不得把第九百三十三条写成双方可随时解除且已盖章补偿协议自动失效。已依法订立的补偿协议如何承继，本任务只点名须由征收部门另行处理，不在本约里注销。

### 7.3 争议解决

本约可能被认定为行政协议或行政委托。修改句避免“一律商事仲裁排除行政诉讼”。出现仲裁条款：不得偷偷改成某法院并假装已选定诉讼。或裁或诉、机构不明：标待核。项目所在地法院可作为民事或行政管辖的连结点草案，不保证一定受理。

### 7.4 强制规范

第一百五十三条：违反法律、行政法规强制性规定的民事法律行为无效，但该规定不导致无效的除外。合同编通则解释第十六条：若干情形可不因违反强制性规定而无效；旨在规制履行行为的，一般不因此认定合同无效。

本任务对抽成、超权、代签、逼迁的动作是删除或改写条款，不是宣告整约无效。禁止用已失效“效力性／管理性”口诀或合同法解释（二）第十四条代替第一百五十三条和通则解释第十六条。

格式条款：第四百九十六条本次若未单独核验全文，提示说明的法律结论字段停止；小字、夹在附件不得写成已尽提示。勾选弹窗不当然等于已说明。
