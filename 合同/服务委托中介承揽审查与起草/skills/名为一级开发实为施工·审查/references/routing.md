# 边界与路由

本技能只审查 **委托合同 / 名为土地一级开发，实为建设工程施工类合同** 的待签文本。中文展示名是「审查名为土地一级开发，实为建设工程施工类合同（委托合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符且无法归入本类型 | 本套导航的类型切开步骤 |
| 真土地一级开发委托：融资、征拆、净地/熟地、成本加利润或出让分成、土地储备计划 | `土地一级开发委托合同·审查`。本任务不写行政协议或净地分成放行路径 |
| 标题委托，正文只做工程量、按进度款或审定决算支付、不承担融资征拆 | 留本任务；点名一级开发外壳、施工内核；禁止只改标题 |
| 名为开发实为投资借贷：年化回报、投资收益率、回购本息、不实施工程量 | `名为一级开发实为借贷·审查` |
| 一二级联动、后续招拍挂或拿地绑定 | `“一二级联动”相关合同·审查` |
| 拆迁委托、征收实施 | `拆迁委托协议·审查` |
| 房地产委托代建 | `房地产委托代建合同·审查` |
| 政府代建项目管理 | `政府代建合同·审查` |
| 已是建设工程施工合同招标成约文本、施工图/中标通知书/五方责任成套 | `工地建筑活动承包资质竣工验收→`。本任务不抄施工资质矩阵或优先受偿诉讼路径 |
| 工程总承包 / EPC | `设计采购施工一体→` |
| 借用资质、挂靠专约 | `借用资质挂靠专约→`；同时停笔，不改成可履行挂靠 |
| 当事人明确按 BT 专约交易 | `当事人明确按BT专约交易→`。本约夹带垫资回购：留本任务点名红旗，不审 BT 整案 |
| 无文本、本类型条件已谈妥、要出己方稿 | `名为一级开发实为施工·起草` |
| 已签未争、只问进度款、财审、竣工验收履约 | 本套导航的履约步骤 |
| 已成争，或主问工程款诉讼、优先受偿怎么赢 | `或对应专项领域。` 或建设工程争议领域。本技能不审诉讼策略 |
| C 端大众快检 | 只分流，不回改 |

本约夹带真委托分成专章或标准施工合同附件：该专章或附件整段交接 `土地一级开发委托合同·审查` 或 `工地建筑活动承包资质竣工验收→`；施工内核正文继续审。用户坚持本技能给出净地分成放行、施工示范文本整稿、当然优先受偿或应招未招可履行路径：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿本类型文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
