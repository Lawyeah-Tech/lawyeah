# 名为一级开发实为施工·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、2004 年施工解释、2002 年优先受偿批复、计委令第 3 号《工程建设项目招标范围和规模标准规定》当作现行规则。引用招标投标法第三条时，使用 2017 年修正文本；1999 年文本记噪声，不得标失效（2017 年未改该条文字）。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **委托合同 / 名为土地一级开发，实为建设工程施工类合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查名为土地一级开发，实为建设工程施工类合同（委托合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：真土地一级开发委托审查、名为开发实为投资借贷审查、标准建设工程施工合同审查、一二级联动/拆迁委托/代建/BT 专约审查、他类文本审查、从零起草、履约交底、工程款诉讼或优先受偿诉讼策略、有效性保证、把应招未招或政府垫资改写成可履行规避结构、把本约改写成施工示范文本整稿。

## 本类型硬闸

1. **名实识别（一级开发外壳 vs 施工内核）**：标题可写“土地一级开发委托”“片区开发协议”。核心给付是完成特定红线内的工程建设（三通一平、土石方、道路、管网、绿化等），受托方不承担融资压力和征拆风险，收益与土地出让溢价无关，只领取固定或按审定造价计算的建设费用。鉴于条款只强调施工任务、不见投资责任：施工合同特征。禁止只改标题。
2. **施工资质是否误套**：不得把 `工地建筑活动承包资质竣工验收→` 的施工资质矩阵整套拷进本约当放行条件。也不得因标题是委托就写“不需要建筑业企业资质”。实质是施工、文本或材料未见相应建筑业企业资质：点名红旗，提示施工解释（一）第一条的效力风险，字段停止或必须改；仅有房地产开发资质而无施工资质：不得写成已适格。未见证书编号、等级、有效期：不补证，不写“可以承揽”。
3. **优先受偿是否误套**：不得写“当然享有建设工程价款优先受偿权”，不得写“加一句保留即可实现”。民法典第八百零七条以建设工程合同定性为前提，且“根据建设工程的性质不宜折价、拍卖”的，不能就该工程折价拍卖优先受偿；市政道路、管网等公共基础设施常落入该例外。解释（一）第四十条：利息、违约金、损害赔偿金不进范围；第四十一条最长十八个月。知识库“应保留主张空间”只允许写成请求权声明，不得写成已成立的法定优先权。
4. **与真委托 `土地一级开发委托合同·审查` 切开**：受托方筹措资金、组织征收拆迁、按开发成本加利润或出让收益分成、验收标准是净地/熟地、项目纳入土地储备计划 → 负触发 `土地一级开发委托合同·审查`。禁止把真委托改成施工结算，禁止抄一级开发行政协议主路径。
5. **与真施工 `工地建筑活动承包资质竣工验收→` 切开**：标题已是建设工程施工合同，或已有中标通知书、施工图、工程量清单、五方责任主体、按施工示范文本成套填写 → 负触发 `工地建筑活动承包资质竣工验收→`。禁止抄施工 method 的签证索赔、优先受偿主路径。本任务不把委托外壳改写成施工合同整稿。
6. **与投资借贷 `名为一级开发实为借贷·审查` 切开**：核心是出资、固定期限、年化回报、投资收益率、回购款、本息回收，受托方不实施工程量 → 负触发 `名为一级开发实为借贷·审查`。进度款 ≠ 回购款；工程量 ≠ 投资额。
7. **规避招标 / 政府垫资停笔**：以委托一级开发绕过依法必须招标的施工发包，或政府投资项目约定施工单位垫资、建成移交后分期回购：只出告知与红线，不改写成可履行规避结构。用户坚持“改到能签且仍不招标/仍垫资回购”：整体停止。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。禁止把施工资质或优先受偿写成已经锁死的施工合同结论。

## 工作边界

正触发：已有可读待签正文，尚未签署，尚未成争，标题像一级开发委托或片区开发，核心给付是工程建设并按造价或进度结算，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 受托方融资、征拆、净地验收、成本加利润或出让分成 → `土地一级开发委托合同·审查`；
- 年化回报、投资收益率、回购本息、不实施工程量 → `名为一级开发实为借贷·审查`；
- 一二级联动、后续招拍挂绑定 → `“一二级联动”相关合同·审查`；
- 拆迁委托、征收实施 → `拆迁委托协议·审查`；
- 房地产委托代建 → `房地产委托代建合同·审查`；政府代建项目管理 → `政府代建合同·审查`；
- 已是建设工程施工合同招标成约文本 → `工地建筑活动承包资质竣工验收→`；
- 工程总承包 / EPC 专约 → `设计采购施工一体→`；
- 借用资质挂靠专约 → `借用资质挂靠专约→`；
- 当事人明确按 BT 专约交易 → `当事人明确按BT专约交易→`；本任务只处理“一级开发外壳 + 垫资回购”红旗，不审 BT 专约整案；
- 无文本、本类型条件已谈妥、要出己方稿 → `名为一级开发实为施工·起草`；
- 已签只问进度款、验收日、财审留痕 → 本套导航的履约步骤；
- 已催告、解除、索赔、立案、开庭、仲裁 → `或对应专项领域。` 或建设工程争议领域，不审工程款或优先受偿诉讼策略。

标题委托、正文只做工程量且按审定决算支付：留本任务，点名名实红旗，按硬闸改结算、招标、验收和误套条款。用户改口要一份真委托或标准施工合同 → 整段交接对应原子，本任务不写净地分成或施工示范文本放行路径。

挂靠、违法分包、应招未招、政府垫资、规避限购：只出告知，不改写成可履行规避结构。

## 建立审查坐标

确认：使用者与授权；单方立场（政府/平台发包侧或名义开发商/施工企业侧择一）；相对方；全文及附件版本；工作内容是工程量还是融资征拆；对价是进度款/审定决算还是出让分成/年化回报；招标或直接指定痕迹；乙方资质种类（施工 vs 仅房地产开发）；是否垫资或回购；验收是竣工验收还是净地/熟地；立项、环评、预算是否被提及；争议条款；不可接受事项；法域与拟签署日。缺立场或无可读书面文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

### 0. 签署状态与成果分流

无书面文本 → `名为一级开发实为施工·起草`；已签履约 → 本套导航履约步骤；已成争或要工程款/优先受偿诉讼策略 → 争议或建设工程领域。未签且目标是评改已有“一级开发外壳、施工内核”文本，才进入本任务。

### 1. 类型锁死与邻类切开

标题、核心给付与对价方式一致才继续。真委托、投资借贷、标准施工、一二级联动、拆迁委托、代建、BT 专约负触发。施工内核留本任务并点名。

### 2. 主体与资质误套闸

签约名、履行名、付款名、发票名分列。施工资质不自动当放行条件；仅有房地产开发资质不得写成已适格。

### 3. 标的、验收与权属

工程量、红线、竣工验收 vs 净地验收。市政设施所有权通常自始归国家；企业主要是价款请求权。

### 4. 对价与语言闸

进度款 vs 回购款；工程量 vs 投资额；审定决算 vs 出让分成。

### 5. 招标、立项与政府垫资

应招未招红旗；政府投资垫资/BT 回购停笔。

### 6. 优先受偿误套闸

定性未锁定为施工合同前，不写当然优先受偿；市政设施标不宜折价拍卖例外。

### 7. 违约、解除、争议

质量、工期、转包；已完工程量清场结算。本约商事争议走诉讼或商事仲裁，不审工程诉讼策略。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持应招未招仍放行、政府投资垫资或 BT 回购仍要可履行、保证有效、保证当然优先受偿、倒签或补假招标/立项痕迹。
- `字段停止`：法域、资质真伪、是否属于必须招标、财审机关、立项批复未核验。
- `目标停止`：主目标已变为从零起草、履约交底、真委托审查、标准施工审查、投资借贷审查、工程款或优先受偿诉讼策略。
