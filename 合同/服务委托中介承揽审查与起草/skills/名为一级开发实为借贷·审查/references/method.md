## 节点 1　类型识别与单目录加载

### 1.1 本类型识别（不用标题单独定性）

同时满足才正触发：

1. **外壳**：标题、鉴于或项目描述使用土地一级开发、片区开发、土地整理委托、投融资合作等土地开发话语；相对方常为政府、管委会或融资平台。
2. **核心给付**：出资方主义务是按计划拨付资金；回收安排是固定期限、固定利率、保底收益，或“无论土地是否出让、出让价款是否覆盖成本均支付”。
3. **事务空洞**：出资方不实际参与征拆、报批、施工组织，或虽写“配合开发”但没有任何可核验的事务节点；风险条款排除出让失败风险。

辅助红旗（单项不足认定，两项以上应写入风险表）：鉴于强调“政府资金短缺”；附件只有还本付息计划表；出现“还本付息”“年化回报”“加速到期一次性偿还全部投资款”；资金进入财政统筹或往来款而非项目监管账户。

“实为投资”与“实为借贷”都留在本技能：前者不负责开发但按出让金比例分成且承担市场波动；后者固定期限固定利率收回本息。两者都要穿透；分成若仍有“不足补足／保底”，按借贷识别。

## 节点 2　主体、授权、管委会与平台

1. 建主体表：签约名、拨款名、收款名、担保名、授权签字人。名称不一致不自动合并。
2. 政府侧：地方政府、所属部门、管委会、临时指挥部是否具备独立法人资格、是否有法定或授权的签约权限。口头“管委会能代表政府”不得写成已授权。开发区管委会作土地使用权出让方的规则只作主体红旗，不把本约改成出让合同。
3. 平台公司：是否机关法人。是 → 担保走节点 4。否 → 审查公司决议、是否以公益设施或土地预期收益空转担保；未闭合则签署能力字段停止。
4. 出资方：是否持牌金融机构或七类地方金融组织；是否有经常性、面向不特定对象的放贷特征。职业放贷或套取信贷转贷：停笔，不改成可履行放贷结构。
5. 机关法人提供保证或担保：记录对文本的影响，不展开保证期间整案。

不足：字段停止，列出待补材料，不补主体。

## 节点 3　固定回报穿透与资金路径

本节点是类型硬闸，必须填表后才能出修改句。

| 观察项 | 借贷方向 | 真委托／真投资方向 |
| --- | --- | --- |
| 事务 | 只负责按计划拨款 | 组织征拆、报批、招标或驻场管理 |
| 风险 | 无论出让与否、价款是否覆盖成本均支付 | 承担出让失败或溢价不足的商业风险 |
| 对价名称 | 年化、利息、保底、还本付息、固定分成 | 委托报酬或与溢价挂钩且无补足 |
| 时间轴 | 只有资金进入／退出日 | 有开发建设或整理节点 |
| 资金账户 | 财政统筹、往来款、出资方指定账户 | 项目监管账户且用于整理支出 |
| 附件 | 还本付息计划表 | 事务清单或（若误入施工）工程量清单 |

国有土地使用权合同解释（2020 修正）第二十三条：合作开发房地产中提供资金方不承担经营风险、只收取固定数额货币的，应当认定为借款合同。该条对象是合作开发房地产，不是一级开发专用强制规范；一级开发外壳下具备同一实质的，按该识别路径定性，不得把条号写成“一级开发法第 23 条”。

修改纪律：

- 不得把固定回报改名为“委托报酬”却仍不处理事务。
- 不得把“保障资金安全”“不足由财政补足”留在风险共担条款里。
- 用户要求改成真委托或真施工：负触发对应原子，不在本任务出可履行开发或施工结构。
- 分成条款若另有差额补足、保底、最低年化：仍按借贷穿透。

资金路径：修改句可要求专户和用途限制，但必须同时写明：专户不能把借贷外壳洗成真开发；财务凭证若记“往来款／借款”，与“项目进度款”冲突时并列，不选有利科目。

## 节点 4　遮盖／隐藏分层与政府举债、机关担保

1. **分层，禁止一句话效力**：
   - 双方以开发、委托、合作的虚假意思实施的行为，按第一百四十六条无效。
   - 隐藏的资金占用，按合同编通则解释第十四条转第一百五十三条或第五百零二条第二款；再按民间借贷规定第十条、第十三条、预算法第三十五条审查。
   - 不得输出“名为开发实为借贷所以整组合同当然无效”。
   - 不得输出“企业间签了就能要回固定回报”。
2. **政府及所属部门融入资金**：除发行地方政府债券外，不得以任何方式举借债务。把本约改名“委托开发”不消灭该禁止。用户要保留“财政按时还本付息”作为可履行主给付：红线。
3. **机关担保**：机关法人不得为保证人（国务院批准转贷除外）；机关法人提供担保原则上无效。删除担保函、承诺函中“政府无条件兑付”的可履行结构。人大决议、会议纪要、把还款纳入预算：不得写成已经取得可强制执行的财政债务。
4. **平台公司担保**：不自动等同机关担保无效，也不等于财政兑付。审查决议、担保权限、是否以未取证土地设定抵押。
5. **未取证土地抵押**：一级开发阶段尚未取得建设用地使用权证书的，不得写成抵押权已设立；修改句删除“项目土地已抵押给乙方”的既成表述。
6. **无效后果**：只点名第一百五十七条返还或折价补偿；不编造必得利息，不写“利息折抵本金”为唯一算法。行政赔偿或信赖利益只提示可能路径，不保证范围。

## 节点 5　利率上限运行时核验

1. 列出文本中的一切资金占用对价：年化回报、投资收益率、保底、顾问费、通道费、逾期罚息、加速到期利息、违约金。未给出的数字用 `【待填】`。
2. 民间借贷路径：合同成立时一年期贷款市场报价利率四倍（民间借贷规定第二十五条）。无核验引文或无当次 LPR：利率法律结论字段停止。
3. 预扣、先扣费用：以实际出借金额为本金。
4. 逾期利息、违约金、其他费用合计纳入同一上限审查。
5. 持牌金融机构或七类地方金融组织：不套四倍，利率字段停止，提示走金融监管口径。
6. 禁止写入：24%、36%、银行同类贷款利率四倍、法定贷款利率。
7. 用户坚持以上旧口径作为“合法利率”且拒绝核验：整体停止利率结论，不得放行。

## 节点 7　格式条款与强制规范

出资方预先拟定且未协商的利息、罚息、加速到期、单方解释权，按格式条款审查提示说明。无核验引文则法律结论字段停止，摘录继续。

强制规范只区分：是否导致民事行为无效；规范目的是否仅行政管理或税收；是否只规制履行行为。禁止用已失效“效力性／管理性”口诀。政府违法举债、机关担保、职业放贷、虚假项目套取信贷：不改写成有效履行结构。

合同编通则解释第十六条关于“旨在维护土地出让金等国家利益、认定有效不影响规范目的”的例外，不得用来救活预算法第三十五条禁止的政府举债或机关担保。
