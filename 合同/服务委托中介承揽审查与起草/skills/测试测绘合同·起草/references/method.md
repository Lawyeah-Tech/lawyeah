# 审查方法（锁定 承揽合同 / 测试、测绘合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制加工来料定额、建工咨询意见交付、勘察岩土文件或施工挂靠节点。

定性校验：标题、核心给付与本类型一致才继续；明显是鉴定、施工、勘察、建工咨询或加工则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、成果必然被行政机关或下游采信、对方必然接受或唯一必得报酬。

`search_law` 返回已失效《合同法》承揽章、《加工承揽合同条例》、《经济合同法》、1992/2002《测绘法》、《测绘资格审查认证管理规定》或其解释时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。鉴定、勘察、施工或加工范本只证明是另一类型，不得当作本类型范本。国家测绘局/工商局测绘合同示范文本只借栏目（范围、技术标准、成果验收、权属、工期、费用），不把示范文本当已接受条款。

知识库纠正（不回写双文件）：

- `基本面.md` “无测绘资质则合同可能因违反效力性强制性规定而无效”：测绘法第 27、29 条是资质准入和禁止挂靠、禁止转让项目。未取得资质擅自测绘首先是行政责任。民事效力须按民法典第 153 条和合同编通则解释第 16 条判断，不得用已失效“效力性/管理性”口诀写成当然无效，也不得写成“无证也可以先测”。
- `框架.md` “甲/乙/丙/丁”：旧《测绘资格证书》四级划分已失效。运行时以证书载明的等级和专业类别为准；不得把丙、丁级写成现行默认可核验档。
- `基本面.md` “通常定作人拥有成果所有权，承揽人拥有署名权及科研使用权”：这是商业惯例写法，不是民法典或测绘法默认规则。权属必须落句。测绘法第 33 条依法保护测绘成果知识产权，不自动把财产权判给定作人。
- `基本面.md` “严禁任何形式的第三方介入”：过宽。测绘法第 29 条禁止以他人名义作业、禁止允许他人以本单位名义作业、禁止向他人转让测绘项目；民法典第 772 条允许另有约定或经同意把主要工作交第三人，辅助工作可交第三人但承揽人仍负责。修改句禁止转让测绘项目和挂靠，不禁止经书面同意的辅助内业。
- `基本面.md` 把测试报告写成可直接替代鉴定意见：现有依据不支持。测试报告是客观数据记录；鉴定意见由登记鉴定机构和鉴定人作出，走 `检验鉴定合同·审查`。
- 汇交：测绘法第 33 条、测绘成果管理条例第 9 条是法定义务（验收完成后三个月内汇交副本或目录），合同不得写成“双方同意不汇交”。汇交主体按条文是出资人或承担国家投资项目的单位，修改句须点名谁在几日内向哪一级主管部门汇交，不得把汇交写成已经完成。

## 节点 1　类型识别与单目录加载

### 1.1 成果导向的测试 / 测绘承揽

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

本类型成立，须同时满足：

1. 工作内容是用专业设备或方法采集、处理客观数据（测绘空间数据，或产品/环境/软件性能指标）。
2. 对价对应完成该项工作并**交付工作成果**（报告、图纸、矢量数据或数据集），不是出法律评价、不是施工作业、不是制成新物。
3. 成果可用技术指标核验：坐标系、比例尺、精度/误差，或测试标准、样品数量、通过准则。

| 文本写法 | 动作 |
| --- | --- |
| 写明测区四至或样品身份，验收标准是提交符合某规范的图纸/报告/数据集 | 正触发，进入 1.2 |
| 只有“测绘服务”“测试服务”，不见测区/样品和成果载体 | 字段停止；修改句补测区或样品与成果形式。补不上则负触发引擎 |
| 正文要出具“鉴定意见”“司法鉴定书”，用于诉讼或行政执法 | 不是本类型 → 1.2 切开 |
| 正文是岩土勘察、施工图设计或现场施工 | 不是本类型 → 1.2 切开 |

修改句：

「本合同标的为乙方完成【地籍测绘 / 房产测绘 / 竣工测量 / 产品性能测试 / 软件压力测试】并交付工作成果，不是出具鉴定意见，不是建设工程勘察、设计或施工作业。成果为【纸质图纸×【待填】份、电子矢量数据（坐标系【待填】、格式【待填】）/ 测试报告原件×【待填】份及原始记录】，须符合【规范名称及精度或通过准则】。」

最强反方：相对方主张标题写“测绘/检测”即可覆盖鉴定或勘察。现有依据不支持用标题单独定性。民法典第 770 条将测试与检验并列，不把测试吸收为鉴定。

### 1.2 与鉴定 / 施工 / 勘察切开（硬闸）

必须切开后再加载，禁止两可时灌入两套知识。禁止打开鉴定、施工、勘察、建工咨询或加工的 method。

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 采集客观空间或性能数据并交付报告/图纸/数据集 | 本类型 | 正触发 |
| 针对诉讼、仲裁或行政执法中的专门性问题出具鉴定意见；委托人要求按特定结论出具 | 检验、鉴定 | 负触发 `检验鉴定合同·审查` |
| 施工许可范围内的建设工程、主体结构或现场施工作业 | 施工 | 负触发 `工地建筑活动承包资质竣工验收→` |
| 为工程设计查明地质、水文、岩土条件并编制勘察文件 | 勘察 | 负触发 `为工程设计查明地质水文岩土条件并编制勘察文件→` |
| 只出可行性、造价、全过程或项目管理咨询意见，不交付测绘/测试成果 | 建工咨询 | 负触发 `只出可行性造价或管理咨询意见不交付测绘测试成果→` |
| 定作人供料制成新物或改变形态 | 加工 | 负触发 `加工合同·审查` |
| 按图新造、承揽人备料 | 定作 | 负触发 `定作合同·审查` |
| 修复既有损坏物 | 修理 | 负触发 `修理合同·审查` |

支持切开的规范（法律结论须运行时复核）：

- 第 770 条：承揽包括加工、定作、修理、复制、测试、检验等工作——测试与检验并列，不是鉴定的下位。
- 第 788 条：建设工程合同包括工程勘察、设计、施工。勘察质量管理办法第 2 条：勘察是查明、分析、评价建设场地地质地理环境特征和岩土工程条件并编制勘察文件。测绘侧重地表形状、界址、高程与地图编制，受测绘法规制。
- 实务反例：鉴定性报告含主观判断、走鉴定意见规则；测试/监测报告是仪器测定的客观数据，归书证审查，不能写成鉴定意见。

测绘正文夹带一小段工程测量服务于在建项目：若主给付已是编制岩土勘察文件，整案负触发勘察；若仅是独立竣工/地形测量，留本任务。用户坚持整案按鉴定、施工、勘察或建工咨询改完：`目标停止`。

本技能已锁定 **承揽合同 / 测试、测绘合同**。只打开 `references/基本面.md` 与 `references/框架.md`。禁止读其他子目录，禁止为对照再开第二类。

### 1.4 无资质 / 挂靠 / 涉密 / 转让项目停笔

加载后或定性中出现：未取得测绘资质证书从事测绘；超越证书专业类别；以其他测绘单位名义或允许他人以本单位名义作业；中标后向他人转让测绘项目；未履行保密审批从事涉及国家秘密、军事设施或未公开资源分布的测绘；将涉密成果上传公有云或经普通互联网传输出境。

动作：

1. 交付告知：测绘法第 27、29、34 条；测绘成果管理条例第 17 条。可能因违反法律、行政法规强制性规定或违背公序良俗而无效（第 153、154 条）。不得改写成可履行的无资质、挂靠或未审批涉密结构。
2. 不写假证书路径、挂靠管理费结算、涉密成果外传步骤。
3. 风险表只保留识别依据和删除/转出口径。
4. 用户坚持“改到能签且仍做这些事”：整体停止。

软件/产品内部测试、不进入测绘活动：不套测绘资质，但对外出具具有证明作用的数据和结果须核验 CMA 能力范围（检验检测机构资质认定管理办法第 15、19 条；监督管理办法第 2 条）。未核 CMA：该用途字段停止，不得写“本报告可作为司法或行政决定的法定证明”。

部门规章或证书未核：字段停止，不宣告合同当然无效（解释第 16 条）。无资质仍要放行测绘或涉密外传：红线。

## 节点 2　主体、测绘资质与授权（硬闸）

### 2.1 主体表

建表：签约名、履行名、付款名、发票名、授权签字人、项目负责人。名称不一致不自动合并。定作人须对测区有权使用或已取得相邻权人、物业或管理人进入许可。共有、国资、集体、上市公司决议未闭合：该签署能力字段停止，不写成“可以盖章”。

口头“我们老板同意了”不得写成已授权。外国组织或个人来华测绘：另核《外国的组织或者个人来华测绘管理暂行办法》，未核则该主体字段停止，不写成可以单独施测。

### 2.2 资质与主要工作

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 工作是地籍/房产/工程/海洋等测绘，无《测绘资质证书》或专业类别不覆盖 | 字段停止；修改句要求证书作为附件 | 可以施测；合同当然无效 |
| 证书过期、等级或专业类别与项目明显不符 | 红线换有相应资质的单位，或缩范围到证书覆盖部分 | 营业执照含“测绘”即已具备 |
| 核心外业、控制测量、成图交第三人，无定作人书面同意，或属于转让测绘项目 | 必须改。测绘法第 29 条禁止转让测绘项目；第 772 条：主要工作应交自己完成 | 转包不影响身份 |
| 只有营业执照或 ISO | 执照不等于测绘资质或 CMA | 已具备全部资质 |
| 软件压力测试、产品内部性能测试，报告仅供甲方内部 | 不套测绘资质；仍须写清成果不是鉴定意见、不是对外法定证明 | 本报告等于鉴定意见 |
| 测试报告拟提交行政机关、仲裁或司法机关作为证明 | 核验 CMA 能力范围；范围外字段停止 | 未认定机构也可对外出证 |

修改句：

「乙方确认其持有与本合同项目对应的有效【测绘资质证书（等级【待填】、专业类别【待填】、证书编号【待填】）/ 检验检测机构资质认定证书（CMA，能力范围覆盖【待填】）】，复印件作为附件。主要外业施测、控制测量、内业成图或关键测试由乙方以自己的设备、技术和劳力完成；未经甲方书面同意，不得将上述主要工作交第三人，不得向他人转让本测绘项目，不得以其他单位名义或允许其他单位以乙方名义作业。辅助内业交第三人的，乙方就该第三人成果向甲方负责。」

尾部：重大测绘项目可要求项目负责人（注册测绘师或证书载明技术人员）签字。未给出姓名不得编造。

## 节点 3　测区 / 样品与技术指标

审查清单，缺一项则该字段不得写成已闭环：

1. 测绘：测区位置、面积或长度、四至或范围图；测试：样品名称、数量、批次、封存状态。
2. 技术指标：比例尺、坐标系（如 CGCS2000）、高程基准、精度/误差；或测试标准、功能模块、通过/失败准则。禁止只写“质量良好”“按有关规范”。
3. 《测绘/测试技术大纲》作为附件。
4. 定作人应提供控制点、基础资料、样品说明书，并完成现场指界或技术交底。
5. 破坏性测试或不可逆样品：须书面确认损耗范围；正常损耗由定作人承担，超常损耗或灭失由承揽人按第 784 条赔偿。

| 文本写法 | 动作 |
| --- | --- |
| “测区以现场为准，甲方事后不得异议”且无范围图 | 必须改。单方记载不得写成已共同确认 |
| 无坐标系或把“坐标原点”与“控制基准”混用 | 必须改：写清坐标系、高程基准及坐标转换责任 |
| 样品未封存、未记录接收状态 | 必须补接收确认；口头“样品已给”不得写成已确认 |
| 关键破坏性测试禁止旁站 | 必须改：定作人有权派员旁站 |

修改句：

「测绘范围以附件《测绘范围图》为准，面积约【待填】，采用【CGCS2000 / 待填】坐标系、【待填】高程基准、比例尺【待填】，平面/高程中误差不超过【待填】。测试样品为【名称、编号、数量】，乙方接收时须书面确认封存与外观；未经该确认不得开始破坏性测试。坐标转换公式由【甲方提供 / 乙方编制并经甲方书面确认】，转换误差超出【待填】的，乙方无偿重测或重算。」

最强反方：承揽人主张“行业惯例坐标系不必写”。现有依据不支持把未写明的基准当成已约定成果标准。

## 节点 4　成果交付（硬闸）

支持依据：第 770、771、780、781、782 条。

分列六栏，缺一栏则该栏不得写成已明确：

| 栏 | 必须落到文本 |
| --- | --- |
| 成果形式 | 纸质图纸份数、电子格式、测试报告原件、原始记录、元数据 |
| 交付时点 | 外业完成日、内业提交初稿日、最终成果日，分别写清 |
| 交付对象 | 向谁、何种载体、是否同时汇交主管部门 |
| 验收方法 | 外业抽检比例、对比实地、书面验收单；禁止“签收即合格” |
| 异议期 | 起算点与天数；逾期未提出准确性异议的效果 |
| 质量后果 | 精度不达标无偿补测/重测；造成下游工程损失的赔偿上限用 `【待填】` |

| 文本写法 | 动作 |
| --- | --- |
| 只写“提交测绘成果”不见载体和精度 | 必须改 |
| “甲方签收、付款或投入使用视为验收合格” | 必须改。第 780 条：定作人应当验收；签收不等于验收 |
| “成果须待规划/登记机关采信后视为合格，否则不付尾款且不算交付” | 必须拆：合同验收 vs 行政机关采信。后者不得单独作为未交付的唯一理由，除非双方明确把报审通过写成验收条件 |
| 无异议期 | 必须补 |
| 精度缺陷只写“依法承担责任” | 必须改：无偿补测/重测 + 可选减酬或赔偿 |

修改句：

「乙方应于【待填】日前向甲方交付：纸质成果【待填】套、电子数据（格式【待填】、介质【待填】）及质量检查记录。双方按【规范名称】进行验收；甲方可对外业按不少于【待填】％抽检。甲方应在收到最终成果之日起【待填】日内提出书面准确性异议，逾期未提出的，视为合同验收合格，但不视为规划、登记或其他行政机关已经采信。签收、付款或下游使用不当然构成验收。成果精度不符合约定的，乙方应在【待填】日内无偿补测或重测；仍不合格的，甲方可减少报酬或解除合同，并就因此发生的直接损失请求赔偿，单项上限人民币【待填】元。」

最强反方：承揽人主张“交了光盘就是交付，机关不采信是定作人的事”。现有依据支持区分合同交付与行政采信，不支持把无载体、无标准的“提交”写成已履行第 780 条。

涉密成果：验收、传输、备份必须符合保密要求；禁止公有云和普通外网。未核密级：该传输字段停止。

## 节点 5　对价、汇交与变更

### 5.1 价金构成

按面积、测点或工作量计价的，须有单价和超量结算阈值；范围明确的标准化测试可用总价包干。禁止编造单价。未给出的数字写 `【待填】`。

| 文本写法 | 动作 |
| --- | --- |
| 只有“测绘费若干”，不写计价基数 | 必须改 |
| 实测面积增减无单价 | 必须补：超出约定范围【待填】％的部分按实结算 |
| 支付与验收脱钩，交初稿即付清且不得异议 | 必须改：预付款 + 初稿款 + 验收合格尾款（第 782 条：未约定时，交付工作成果时支付） |
| 预付款写成定金且超过标的额 20％ | 超过部分不产生定金效力（第 586 条）；无核验引文则该法律结论字段停止 |
| 质保金绑死“下游设计院或登记机关采信”且无最长期限 | 必须改：设最长保留期【待填】日，到期未提出约定质量异议则支付 |

修改句：

「费用按【面积单价人民币【待填】元／平方米，暂定面积【待填】 / 总价包干人民币【待填】元】计算。实测面积增减超过暂定面积【待填】％的，超出部分按上述单价据实增减。支付节点：合同生效后【待填】日内预付【待填】％；提交符合约定的初稿后【待填】日内支付【待填】％；书面验收合格后【待填】日内支付【待填】％；余【待填】％作为质量保证金，自验收合格之日起满【待填】日且甲方未提出约定精度异议后【待填】日内支付。」

### 5.2 汇交与协作

测绘项目验收完成后三个月内汇交成果副本或目录（测绘法第 33 条；测绘成果管理条例第 9 条）。修改句点名汇交义务人、时限和凭证，不得写成已经汇交，不得约定排除。

定作人协作：提供控制点、基础资料、现场通行许可。未提供导致停工：工期顺延，不得直接写成承揽人违约。野外持续极端天气：顺延规则须可执行，不得只写“不可抗力依法处理”。

## 节点 6　787、格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 定作人完成工作前的解除

条文：定作人在承揽人完成工作前可以随时解除合同，造成承揽人损失的，应当赔偿损失。

| 文本写法 | 动作 |
| --- | --- |
| “甲方不得以任何理由中途解除” | 红线删除。与 787 冲突 |
| “甲方放弃第七百八十七条权利” | 红线。本任务不把放弃写成可放行 |
| “甲方可随时解除且无需支付任何费用” | 必须改。解除后仍应赔偿损失 |
| 工作已完成或已交付后仍套“随时解除” | 现有依据不支持再走 787；质量问题走第 781 条 |
| 只写“双方协商解除” | 必须补通知、停测时点、已完成外业与资料清理 |

修改句：

「甲方在乙方完成约定测试或测绘工作前，可以书面通知解除本合同。解除后，甲方应赔偿乙方因此受到的损失，包括：截至解除通知到达时已发生且能提供记录的外业/测试报酬、已发生且无法收回的差旅与设备调遣费，以及其他合理直接损失；各项金额以书面凭证为准，不得重复计算。乙方完成工作或交付最终成果后，甲方不得再依据本条解除，但不影响其依据质量条款或法律规定主张补测、减酬或赔偿。」

可退让：把“其他合理直接损失”收窄为列举；不可退让：删除赔偿或写死不得解除。

### 6.2 格式条款

为重复使用而预先拟定、订立时未与对方协商。测绘公司或检测机构格式单不得仅以“这次没用过第二次”否认。依据示范文本制作，不当然排除格式条款。

审查：免责、限责、排除 787、成果归承揽人、管辖/仲裁、无限额放弃精度责任等异常条款是否有足以引起注意的标识（第 496 条；解释第 10 条）。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在技术大纲末页 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

### 6.3 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的、是否仅行政管理、是否只规制履行行为（第 153 条；解释第 16 条）。禁止用已失效“效力性/管理性”口诀代替解释第 16 条。测绘资质、CMA 多为监管要求：未出示证书主要是监管后果，不得单独写成民事合同当然无效；无资质仍要测绘、挂靠或未审批传输涉密成果：不改写成有效履行。

## 节点 7　质量、保管、留置、保密与争议

1. 工作成果不符合质量要求：定作人可合理选择补测/重测、减少报酬、赔偿损失（第 781 条）。多次无法达到约定精度：约定可解除并处理已付款和资料返还。只有“依法承担违约责任”视为必须改。
2. 样品、控制点资料、已完成成果在承揽人处毁损灭失：第 784 条。约定按重置或约定单价赔偿，数字用 `【待填】`。
3. 逾期交付：按日违约金；依赖报批的项目可约定更高但仍须可调整，不得写成按总价必得且不得调整。
4. 留置：未付报酬时，承揽人对完成的工作成果可留置或拒绝交付，当事人另有约定除外（第 783 条）。变价前：有约定履行期限从约定，未约定应给债务人六十日以上期限（第 453 条）。修改句不得把催告写成“三日后即可变卖”。不得写成优先于查封。涉密成果不得以留置为由对外披露或上传。
5. 成果权属：须约定所有权、使用权、署名和科研使用范围。未经许可不得向第三方转让、发表或销售数据。
6. 保密：涉密岗位、离线存储、磁盘销毁、禁止外网；备份保管义务。密级未核：传输字段停止。
7. 争议解决：出现仲裁条款，不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核，修改句改成单一仲裁机构或单一法院连结点。不选定唯一法院充作法律意见。
8. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。

修改句（留置与保密）：

「甲方逾期未支付到期报酬的，乙方对已完成的非涉密工作成果可以留置或拒绝交付。乙方行使变价权前，应书面催告甲方在不少于六十日的期限内履行。双方不得以三日或更短期限代替前款催告。属于国家秘密或合同约定保密的测绘成果、测试数据，乙方不得以留置、催收或备份为由上传公有云、经普通互联网传输或向第三人出示。」
