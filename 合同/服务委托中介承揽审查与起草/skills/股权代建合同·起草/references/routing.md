# 边界与路由

本技能只审查 **委托合同 / 股权代建合同**。

必须同时读出：代建方（或指定主体）取得项目公司股权；以及受托操盘或提供全过程/阶段性开发管理并收取代建报酬。标题叫“股权代建”“小股操盘”“项目投资合作及委托代建”但只有其中一翼的，不得留在本技能做实体结论。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或标题股权代建、核心给付明显不是“少数股权 + 代建操盘” | 本套导航的类型切开步骤 |
| 无股权，只有代建费、品牌输出、项目管理；房地产委托代建外观 | `房地产委托代建合同·审查`；专业版未收录该 P1 时输出 `unavailable`，不得硬套本技能补一个假股权 |
| 无股权的商业代建 | `商业代建合同·审查` |
| 土地使用权项下纯委托代建 | `或` |
| 政府投资非经营性代建 | `政府代建合同·审查` |
| 资本主导不良资产、非小股操盘绑定 | `资本代建合同·审查` |
| 代建捆绑贷款配资，出借是主给付 | `商业代建配资·审查` |
| 共同投资、共享利润、共担风险；代建方自负盈亏或对等/控股合作 | `房地产合作开发联合拿地` |
| 主文件股权转让，无代建范围与管理费 | `主文件是股权转让，无代建操盘服务→`；股权投资条线转让本约 → `或` |
| 仅增资扩股，无操盘委托 | `仅增资扩股无代建管理协议或操盘授权→` |
| 固定货币回报、不担风险，且无真实代建服务 | `用户坚持固定保本保收益且不担风险：不得化妆成股权代建放行；明显无代建服务则负触发` |
| 无文本、本类型条件已谈妥、要出己方稿 | 留本任务起草并自审 |
| 已签未争、问工商变更、用印、付款节点 | 本套导航的履约步骤 |
| 已成争 | 合同争议领域或对应专项；不写股东代表诉讼状、抽逃出资起诉状 |
| C 端大众快检 | 只分流，不回改 |

同一文本既写“合作开发共担亏损”又写“小股代建收费”：按核心给付切开。共担共享、自负盈亏或对等持股主导 → `房地产合作开发联合拿地`。少数股权绑定委托操盘、亏损由项目公司和控股股东承担、代建方收管理费并按股分红 → 留本技能。两可且无法判断：负触发引擎，不灌两套知识。

同一文本既是完整股权转让交割清单、又在附件里写一句“可协助管理”：转让是主给付 → `主文件是股权转让，无代建操盘服务→`，不得用本技能改完对价和交割。

挂靠、出借资质、违法分包、规避国资进场、指导假出资或假变更：停笔告知，不改写成可履行文本。

禁止在正文写半截 Skill ID。转出时必须写完整 ID，例如 `房地产合作开发联合拿地`、`主文件是股权转让，无代建操盘服务→`、`商业代建合同·审查`。
