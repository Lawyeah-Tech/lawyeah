# 审查方法（锁定 委托合同 / 资本代建合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止打开或复制 `商业代建合同·审查`、`商业代建配资·审查` 或任何借款 method。禁止套用商业代建的品牌费、小股操盘收购选择权主路径。禁止套用政府代建财政支付或招投标主路径。禁止套用股权代建的股权交割主路径。禁止套用配资放贷、保证期间、流质清算或让与担保过户主路径。禁止把本技能写成商业代建或借贷换标题。

定性校验：核心给付是“资本注入 + 委托代建管理”，才继续；明显他类则负触发，不填十节实体结论。

本文件是可执行判断节点，不是栏目说明书。每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、必然优先受偿，或唯一必得本息/代建费。

`search_law` 返回已失效《合同法》及其解释、1990 年《关于审理联营合同纠纷案件若干问题的解答》收缴利息口径、1991 年借贷意见、2015 年民间借贷司法解释中 24%/36% 条文、已被修改的《城市房地产管理法》1994 年条文时记为噪声，不得写入 `L#`。`search_practiced` 仍写“企业间借贷一律无效”“合同约定共益债务即可对抗抵押”“代建费当然优先于工程款和消费者”的，同样记噪声。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

示范文本只参考结构。写“保底利润、不参与经营、到期无条件退出”“不论盈亏按期付息”的范本与本类型硬闸冲突，不得当规则。

知识库口径冲突以本方法为准，不回写知识正文：

- `基本面.md` 清算顺位写“续建成本 > 代建费 > 金融机构本息 > 原债权人”，`框架.md` 写“税费 > 续建成本 > 甲方本金 > 甲方利息 > 乙方管理费及分成”：两套都只是合同内部约定样本，**不能对抗**商品房消费者价款返还、建设工程价款优先受偿和在先担保物权。建议合同内部分配写成：法定优先权 → 税费 → 续建必要成本 → 代建基础费中属于继续管理所必要的支出 → 资本方本金 → 资本方基础回报 → 超额分成。
- 把代建费或注资写成“共益债务即优先受偿”：纠正为仅在破产申请受理后、符合企业破产法第四十二条或破产法解释（三）第二条时，续建借款才可能参照共益债务，且不得优先于此前已就特定财产享有担保的债权。合同拟制无效。
- 把固定高额回报、不承担经营风险写成可放行的委托报酬：纠正为可能被认定为隐藏借贷，按名实处理，不得留在本技能当代建费放行。
- 把《贷款通则》第六十一条写成企业间借贷一律无效：纠正为法释〔2020〕17 号第十条，法人之间为生产经营需要的民间借贷，除民法典第一百四十六条、第一百五十三条、第一百五十四条及该规定第十三条情形外，主张有效的应予支持。
- 要求必须拆成《投资协议》+《商业代建管理协议》多份才有效：纠正为合并一份或主从分立均可，关键是分列注资、委托事务、出资回报和代建费。

2. 代建方受托处理该项目的续建、开发管理、权属清理、重新入市或销售清算等事务，而不是只提供资金。

### 1.3 违法结构停笔

加载后或定性中出现：要求代建方代持项目公司股权以规避金融监管；以代建外壳发放房地产开发贷款或规避信贷政策；包装刚兑、保本回购且拒绝改为风险分担；指导伪造共管、倒签注资日或补假解封；把合同顺位改成压过商品房消费者或建设工程价款优先受偿。

动作：

1. 交付告知：该结构可能违反强制性规定、公序良俗或被按隐藏行为重新定性，不得改写成可履行、可对抗第三人的文本。
2. 不写代持路径、假共管、假解封、假刚兑。
3. 风险表只保留识别依据和转出/改道提示。
4. 用户坚持“改到能签、能保本、能压过业主和工程款”：整体停止。

合规改道（真实委托管理 + 分列报酬、真实共管、停止代持、改为股权质押公示）只点名，不在本任务起草。

## 节点 2　主体、资质、原债权人与已售未交付业主

1. 建主体表：资本方/委托方、代建方/受托方、项目公司或新设 SPV、原股东、原债权人或债委会、已售未交付业主、施工总承包（如有）。名称不一致不自动合并。
2. 资本方：通常为 AMC、信托、保险资金或私募基金。经营范围或牌照未提及不动产投资、不良资产处置或相应基金管理：该适格字段停止，不得写成“可以出资”。
3. 代建方：从事房地产开发经营的，文本或材料应提及房地产开发资质。未取得资质证书不得从事房地产开发经营业务。材料未出示：字段停止，修改句要求资质证书作附件，未核验不生效或不得以开发商名义对外销售。
4. 原股东/原债权人：烂尾续建须处理印章管领、账务移交、权利放弃或重组支持。未附《重组支持协议》或权利放弃声明：字段停止，不得写成“老债权人已退出”。
5. 已售未交付：须单列原购房合同履行与新代建方责任边界。未处理：红旗；生存级业主权利未处理且用户拒绝升级：停止“可以签署”建议。
6. 破产重整场景：是否有管理人或债权人会议确认。口头“法院同意了”不得写成已批准。
7. 口头“我们投委会过了”不得写成已完成内部审批或监管报备。

不足：字段停止，列出待补材料，不补主体、不补已解封、不补已同意。

## 节点 3　出资回报与代建费分列（硬闸）

本类型有两套必须分开的金钱安排。未分列不得宣称审查完成。

| 科目 | 必须写清 | 禁止写法 |
| --- | --- | --- |
| 资本方出资回报 | 本金、基础回报/利息的计算基数与年化、支付来源（项目回款）、是否承担销售不及或权属不能清理的风险、失败时是否仍要求保本 | “不论盈亏按期支付固定收益”“保本回购”“最低收益率由代建方差额补足且不看项目”且同时抹掉代建费 |
| 代建方代建费 | 基础费计提基数（剩余货值或债权回收额）、节点、项目不能清偿资本方本息时基础费是否仍付；超额分成的触发（须先满足资本方本金+约定基础回报） | 把代建费并入资本方固定回报；按人头或“资金占用费”计费充管理费 |
| 费用 vs 报酬 | 续建成本、垫付费用依第 921 条单独偿还；报酬依第 928 条 | 把垫付工程款、税费、解封成本算进代建费又不给报销 |

核验动作：

1. 在正文和分配模型中分别摘录两套科目。只有一套“综合收益×%”：必须改，拆成出资回报 + 代建基础费 + 超额分成。
2. 资本方不承担任何项目经营或回收风险，且回报固定：点名可能被认定为隐藏借贷。若同时缺乏委托管理事务 → 负触发 `用户坚持固定保本保收益且不担风险：不得化妆成股权代建放行；明显无代建服务则负触发`。若有真实管理事务但保本句未删 → 红线删除保本，改为回款分配且亏损由资本方自行承担超出担保范围的部分。
3. 代建方提供差额补足或劣后出资：允许作为商业安排，但必须单独成条，并提示可能被重新定性；不得用它把资本方回报改成刚兑后再按委托报酬放行。
4. 持牌机构作为资本方：不得把民间借贷 LPR 四倍套到监管利率上。非持牌路径的固定回报若实质是利息，利率法律结论须 `search_law` 后才落；核验失败则该字段停止。
5. 不得把本类型改成借款利息精算表。

反方常见抗辩：有“代建”二字就不是借贷；管理费可以随便写成固定收益。本任务不得把该抗辩写成可放行结构。

## 节点 4　名实：名为代建实为借贷或实为股权转让（硬闸）

核验后可引用的判断点（须 `search_law` 写入 `L#` 再落法律结论）：

- 不拘泥于合同名称，按内容、目的、结构和履行认定实际关系。
- 虚假意思表示无效，隐藏行为另依法认定。
- 到期返还本金并支付利息的，符合借款合同定义。
- 委托的核心是处理委托人事务并支付报酬，不是出借货币。

| 文本写法 | 本任务动作 |
| --- | --- |
| 无委托事务清单，只有“投放【待填】元，【待填】个月后还本付息” | 负触发真借贷原子，不在本技能改成代建 |
| 有续建管理、共管、销售清算，但另条“保本回购、固定年化【待填】%、代建方承担全部经营风险” | 留本技能；红线删除保本；分列回报与代建费；提示隐藏借贷风险 |
| 通过代建协议实质控制项目公司并约定溢价回收股权，目的是规避审批或资质 | 点名名为代建实为股权转让；深度股权交割转 `股权代建合同·审查` 或股权专项；本技能不写可履行规避结构 |
| 商业代建费 + 另行《借款合同》配资 | 负触发 `商业代建配资·审查` |
| 用户要求保留“代建外壳”以便规避放贷或私募监管 | 整体停止 |

反方常见抗辩：有管理费条款就不是借贷。管理费条款不能单独定性；必须同时看见真实委托事务和风险分担。

## 节点 5　管理权、物权隔离与权属清理

1. 标的是特定项目的**管理权**和回款的归集分配权，不是项目所有权转让。代建方被写成共有人、自动取得所有权或“视为项目权利人”：必须改。修改句：代建方对项目不享有物权，仅享有合同约定的管理报酬债权。
2. 权属清理是资本代建的前置任务：无效抵押撤销、司法查封解除、土地出让金补缴、历史施工资料移交。未写清责任主体、费用承担和未完成不得对外销售：必须改。
3. 材料未提及不得写成“无查封、无工程款优先权、无已售未交付”。只能写 `依据不足`。
4. 已建工程须有质量鉴定、加固方案和新旧规范衔接。只写“按现状续建”：必须改。
5. 受托人处理事务取得的财产（销售回款、退税、残值）应转交委托人指定的共管账户，不得截留。
6. 转委托施工总包、销售代理须经资本方同意或合同预先授权，并限定选任责任。
7. 授权矩阵：小额支出可由代建方决策；调规、大宗交易、大幅降价、诉讼和解须资本方终审。未写：必须改。

## 节点 6　资金闭环、清算顺位与法定优先权（硬闸）

1. 所有销售回款、租金、补偿款须进入资本方与代建方（及监管银行，如有）共管专项账户。出现“代建方可先收后结”“可转入集团账户”：红线。
2. 合同内部分配顺序必须声明：**不对抗**法定优先权。至少点名：
   - 房屋不能交付且无实际交付可能时，商品房消费者价款返还请求权；
   - 建设工程价款优先受偿权（范围不含逾期利息、违约金、损害赔偿金）；
   - 在先担保物权。
3. 建工解释（一）第 36 条原文本次未核验：顺位法律结论以法释〔2023〕1 号已核验表述为准，第 36 条条号运行时重核，不把记忆原文写入 `L#`。
4. “代建费作为共益债务优先扣除”：必须改为——仅在人民法院受理破产申请后、符合法定条件的续建借款或继续营业债务，才可能参照共益债务；双方约定不能对抗在先担保物权，也不能对抗消费者和工程款法定优先权。
5. 历史债权交叉污染：必须写资金闭环和法律隔离（新设 SPV 或账户特定化）。未写：必须改。不得保证隔离一定成功。
6. 放弃或限制施工方工程款优先受偿且可能损害建筑工人利益：红线，不得协助写成有效放弃。

## 节点 7　生效条件、共管、退出与监管报备

1. 批准、解封、资质、投委会、监管报备写成生效条件或双方义务期限，不写成已经完成。
2. 框架建议的生效条件“资本方融资款首笔到位且项目公司公章移交完成”可作修改句，但须同时写未成就不生效、已移交印章的共管清单。
3. 用户要求倒签注资日、补假解封或假债委会决议：整体停止。
4. 资本方资金供应中断导致二次烂尾：须有代建方人员待岗费和已发生成本的补偿，有偿委托还须评估第 933 条履行利益，不编造金额。
5. 因管理不当再次被查封，或回款未入共管账户：须有代建方可执行违约后果。
6. 司法强制介入或原债权人强制执行导致无法继续：须有前期成本补偿和品牌撤离机制。
7. 资本方非因代建方违约单方终止：须按约定补偿，不得无偿撤场。框架“按评估预期全额分成补偿”可谈，未评估不得写成已确定金额。
8. 销售方式默认代销。写成包销且历史遗留未清理：必须改回代销，或把包销条件写成权属清洁且可交付之后另议。
9. 尽职调查：明确代建方仅基于资本方和已披露资料判断，对未披露隐性债务不承担保证责任，但已知而不披露除外。
10. 金融机构出资须内部审批及监管报备的，未写：字段停止，修改句要求作为生效或注资先决条件。
