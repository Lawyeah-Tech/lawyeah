# 边界与路由

本技能只审查 **委托合同 / 资本代建合同**。

必须同时读出资本方注入纾困或投资资金，以及代建方受托管理特定不动产项目。标题叫“资本代建”但没有管理事务、或主结构其实是商业代建配资、纯借贷、政府代建、股权代建的，不得留在本技能做实体结论。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或标题资本代建、核心给付明显不是“注资 + 委托管理” | 本套导航的类型切开步骤 |
| 只有品牌/全过程开发管理输出，资本方不向本项目注资，对价是管理费或品牌费 | `商业代建合同·审查` |
| 政府或事业单位委托人，公建或非营利代建 | `政府代建合同·审查` |
| 核心是代建方持股、小股操盘或股权换管理权，不是资本方注资回收 | `股权代建合同·审查` |
| 商业代建捆绑匹配贷款、配资杠杆或“代建 + 放贷还本付息” | `商业代建配资·审查` |
| 标题代建，无管理事务，固定期限固定回报，不承担项目风险 | `用户坚持固定保本保收益且不担风险：不得化妆成股权代建放行；明显无代建服务则负触发` |
| 主文件是持牌机构借款，代建只是背景一句 | `主文件本身是借款→` |
| 主文件是企业拆借，无代建管理主结构 | `无代建管理主给付，只是企业拆借→` |
| 主文件是狭义民间借款 | `或` |
| 父级是土地使用权项下委托代建 | `或` |
| 无资本耦合的一般房地产委托代建 | `房地产委托代建合同·审查` |
| 联建、联合拿地、合作开发为主结构 | 转引擎或对应联建/合作开发原子，不得硬套本技能 |
| 无文本、本类型条件已谈妥、要出己方稿 | `资本代建合同·起草` |
| 已签未争、问注资节奏、共管、复工、销售回款入账 | 本套导航的履约步骤 |
| 已成争 | 合同争议领域或对应专项；不写破产申报、执行异议或催告终稿 |
| 用户只要回收额或代建费终局数字 | 测算技能或人工精算；本技能只审条款 |
| C 端大众快检 | 只分流，不回改 |

同一文本既写“商业代建管理费”又写“资本方注资回收”：按核心结构切开。资本注入且委托管理是主给付 → 留本技能，管理费只作代建费科目。匹配贷款/配资是主结构 → `商业代建配资·审查`。两可且无法判断：负触发引擎，不灌两套知识。

代持规避监管、以代建外壳发放开发贷、包装刚兑、把合同顺位改成压过消费者或工程款：停笔告知，不改写成可履行文本。

禁止在正文写半截 Skill ID。转出时必须写完整 ID，例如 `商业代建配资·审查`、`用户坚持固定保本保收益且不担风险：不得化妆成股权代建放行；明显无代建服务则负触发`、`商业代建合同·审查`。
