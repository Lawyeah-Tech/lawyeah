# 选择方法

按下面顺序只选一个已安装原子。不列出共性技能名。

1. 已成争（催告、解除、索赔、诉讼仲裁）→ 对应争议领域包，不进本套。
2. 先定工作方式：审查 / 起草 / 对改 / 用印 / 补充协议 / 格式条款 / 履约。
3. 类型明显不属于本套（本套父级：服务合同、委托合同、中介合同、承揽合同、互联网相关合同、招商引资合同）→ 转对应领域套件，禁止在本套硬审或硬写。
4. 子类型已明：
   - 有待签文本要评改 → 该类型 `·审查` 原子
   - 按已谈妥条件出己方稿 → 配对的 `·起草` 原子，出稿后必须用本类型硬闸自审
5. 子类型未明、材料属于本套：用本导航切开，只定性，切开后转对应 `·审查` 或 `·起草` 原子，不得在导航里把本类型审完或写完。
6. 对改 / 用印 / 补充协议 / 格式条款 → 读 [工作步骤](engines/README.md)，不要当独立技能名。
7. 已签未争、只要节点留痕 → 本套导航的履约步骤。

混合请求先列出可独立验收的成果，再只问这次先做哪一项。
