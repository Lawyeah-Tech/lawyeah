# 服务委托中介承揽审查与起草入口

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- MCP 未安装或不返回结果时，不拒绝完成本导航的入口定位。
- 不向用户索取密钥、令牌或完整凭证。

## 定位

处理本套已覆盖类型（服务合同、委托合同、中介合同、承揽合同、互联网相关合同、招商引资合同）尚未形成争议的文件工作。子类型已明时：评改进该类型 `·审查` 原子，出稿进配对的 `·起草` 原子。子类型未明时由本导航切开后转成对原子。本套不安装共性技能。

本导航不完成审查意见、合同草稿或履约节点表。具体任务直接使用相应原子。
