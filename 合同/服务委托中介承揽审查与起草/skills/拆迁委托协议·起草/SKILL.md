# 拆迁委托协议·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、2001 年《城市房屋拆迁管理条例》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只起草 **委托合同 / 拆迁委托协议** 的待签文本，按已谈妥条件出己方稿，输出可编辑草稿、未决项；出稿后必须用本类型硬闸自审，输出风险表和修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查拆迁委托协议（委托合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、待签文本签前审查、履约交底、争议文书、有效性保证、保证征收一定完成、保证对被征收人的补偿标准已被本约锁定。

## 本类型硬闸

1. **受托权限封闭**：房屋征收部门只能委托房屋征收实施单位承担调查登记、方案测算、宣传解释、签约洽谈协助、档案整理、现场清场移交等**具体工作**。《国有土地上房屋征收与补偿条例》第五条不授权外包行政职权本身。房屋征收决定（第八条、第十二条）、补偿决定（第二十六条）、申请人民法院强制执行（第二十八条）不得写入受托权限，也不得概括委托“全权处理一切征收事宜”。
2. **不得代签补偿协议冒充征收机关**：补偿协议由房屋征收部门与被征收人订立（第二十五条）。实施单位不得以自己名义、指挥部名义或“代征收机关”名义独立签署并对外冒充征收机关。可以授权协助洽谈、草拟，但须出示授权委托书；补偿协议须经征收部门最终审核并加盖征收专用章后方可对征收部门发生效力。实施单位在委托范围内的行为，对外法律责任由征收部门承担（第五条第二款；行政诉讼法解释第二十五条；行政协议司法解释第四条），不得据此写成实施单位可以自己当征收机关。
3. **与补偿安置切开**：正像是征收部门与实施单位之间的委托服务／行政委托。对价绑被征收人补偿方式、补偿金额、产权调换、搬迁费、停产停业损失 → `的method，禁止把本约改成对被征收人的补偿安置文本。`。禁止打开或复制 `的method，禁止把本约改成对被征收人的补偿安置文本。` 的 method，禁止把本约改成对被征收人的补偿安置文本。

补充闸：

4. **不得以营利为目的**（第五条）：禁止按补偿款比例抽成、包干结余归实施单位。改为固定劳务费或固定报酬加考核奖金。抽成或包干条款删除或改写，不当然宣告整约无效。
5. **禁止非法逼迁**（第二十七条、第三十一条）：不得约定暴力、威胁、中断供水供热供气供电和道路通行，或建设单位参与搬迁。此类条款只出告知，不改成可履行考核。
6. **征收实施不得再转包**：评估机构由被征收人协商或依法选定（第二十条），实施单位不得兼任评估。物理拆除是工程施工，走 `工地建筑活动承包资质竣工验收→`，不得与本委托混成一份可履行包干拆除。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签拆迁委托／房屋征收实施委托正文，尚未签署，尚未成争，核心给付是征收部门把征收与补偿的具体工作委托给实施单位，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 征收部门或实施单位与被征收人订立补偿方式、金额、产权调换、搬迁期限 → `的method，禁止把本约改成对被征收人的补偿安置文本。`；
- 对价绑土地整理、熟地交付、一级开发投资回报 → `土地一级开发委托合同·审查`；夹带一二级联动、土地出让分成 → `“一二级联动”相关合同·审查`；
- 对价绑代建出图、施工管理、交付房屋 → `房地产委托代建合同·审查` 或 `政府代建合同·审查`；
- 普通民事事务委托，主轴是任意解除、隐名代理、处理一般对外签约 → `一般委托合同·审查`；
- 主给付是房屋拆除、渣土清运工程量 → `工地建筑活动承包资质竣工验收→`；
- 开发商、建设单位以“拆迁人”身份委托拆迁事务所，并依赖拆迁许可证／2001 年旧条例 → 不按本类型改成可履行；告知改走现行征收实施委托或停笔；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、复议、诉讼、仲裁或强制拆除已立案 → `或对应专项领域。` 或行政／征收专项。

以委托为名外包征收决定权、强制执行申请权，或把非法强拆、断水断电改成可履行：只出告知，不改写成可履行路径。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及授权委托书／征收决定或批准文号／红线范围／实施方案版本；委托人是否为市、县级人民政府确定的房屋征收部门；受托事项是具体工作还是职权本身；补偿协议由谁署名盖章；费用是固定劳务费、抽成还是包干；是否夹带拆除施工或评估兼任；是否含逼迁手段；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 起草模式

本原子只承担本类型起草。待签评改转 `拆迁委托协议·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `拆迁委托协议·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 委托人须是市、县级人民政府确定的房屋征收部门。受托权限封闭为调查登记、方案测算、宣传解释、签约洽谈协助、档案整理、现场清场移交等具体工作。逐项列举，禁止概括委托。
- 补偿协议由房屋征收部门与被征收人订立。实施单位可以授权协助洽谈、草拟，但须出示授权委托书；补偿协议须经征收部门最终审核并加盖征收专用章后方可对征收部门发生效力。
- 对价改为固定劳务费或固定报酬加考核奖金。补偿款专户专用。
- 评估机构由被征收人协商或依法选定，实施单位不得兼任评估。物理拆除另约工程施工，不得与本委托混成一份可履行包干拆除。

### 附件必附

- 《授权委托书》《征收实施方案》；征收决定或批准文号、红线范围。缺授权委托书不得写实施单位可对外洽谈补偿。

### 禁止出现

- 房屋征收决定、补偿决定、申请人民法院强制执行写入受托权限；概括委托“全权处理一切征收事宜”。
- 实施单位以自己名义、指挥部名义或“代征收机关”名义独立签署并对外冒充征收机关。
- 按补偿款比例抽成、包干结余归实施单位。
- 暴力、威胁、中断供水供热供气供电和道路通行，或建设单位参与搬迁。
- 征收实施再转包；对价绑被征收人补偿方式、补偿金额、产权调换。
- 开发商以“拆迁人”身份依赖 2001 年旧条例的可履行结构。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 留本任务起草并自审；已签履约 → 本套导航履约步骤；已成争 → 合同争议或行政／征收专项。未签且目标是评改已有拆迁委托文本；本任务只起草，评改待签文本转配对 ·审查 原子。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。补偿安置、一级开发、代建、一般委托、拆除施工、2001 年开发商拆迁委托负触发或停笔。

### 2. 主体与授权

委托人须是市、县级人民政府确定的房屋征收部门。指挥部、开发商、临时项目部不得写成合格委托人。实施单位不得以营利为目的。

### 3. 受托权限封闭

逐项列举具体工作。决定权、补偿决定报请权、强制执行申请权必须保留。禁止概括委托。

### 4. 补偿协议署名与授权书

洽谈可委托；签署名义和征收专用章不可外包。禁止冒充征收机关。

### 5. 费用、资金专户与审计

固定劳务费或固定加考核；补偿款专户专用；禁止抽成、包干、垫资不清。

### 6. 禁止逼迁与拆除切开

第二十七条红线。拆除施工单位另约。

### 7. 格式条款与强制规范

无核验引文则法律结论字段停止。超权、代签、抽成、逼迁不得改成可履行。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把征收决定权外包、把实施单位独立代签补偿协议放行、把非法强拆或断水断电改成可履行。
- `字段停止`：法域、动态规则、委托人是否为确定的征收部门、实施单位资格、集体土地规则未核验。
- `目标停止`：主目标已变为评改待签文本、履约交底、争议文书，或已锁他类。
