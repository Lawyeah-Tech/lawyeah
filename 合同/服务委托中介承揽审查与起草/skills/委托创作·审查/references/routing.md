# 边界与路由

本技能只审查 **委托合同 / 委托创作合同** 的待签文本。中文展示名是「审查委托创作合同（委托合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 处理事务、对外代理、以委托人名义签约，不交付作品 | `一般委托合同·审查` |
| 用户或文本按「知识产权相关合同」挂载；主轴是专有权转让、登记过户、许可/再许可、邻接权 | `主给付是委托创作特定作品→`。不得抄该原子方法，不得删权属登记栏目后硬套本技能 |
| 按样制作、来料加工、定作实物 | `定作合同·审查` 或 `加工合同·审查` |
| 复制、印刷已有图文，无创作过程 | `复制合同·审查` 或 `印刷合同·审查` |
| 已完成作品买断或著作权转让 | `或` |
| 已有作品许可使用 | `或` |
| 多方共同创作、合作署名 | `多方共同创作→` |
| 设计服务过程为主、不指向著作权法作品 | `委托他人设计的服务合同·审查` |
| 代笔、枪手主轴 | `委托代笔合同·审查` |
| 技术开发或软件委托开发 | `委托技术开发合同·审查` 或对应技术类原子 |
| 无文本、本类型条件已谈妥、要出己方稿 | `委托创作·起草` |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

委托创作正文里夹带一小段现成素材采购或印刷装订：专条交接对应原子；作品定义、需求书、权属默认、修改次数、稿酬条款可继续审。用户坚持本技能把一般委托、知产侧委托创作或承揽整案改完：`目标停止`。
