# 委托创作·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》委托章或承揽章、1990 年《著作权法》第十九条（继承条款）或 2010 年《著作权法》第十七条旧条号当作现行委托作品规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **委托合同 / 委托创作合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文名必须是「委托创作·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、把一般委托/知产侧委托创作/承揽/现成作品转让整案改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **创作成果归属（著作权法委托作品默认）**：受委托创作的作品，著作权归属由合同约定；合同未作明确约定或没有订立合同的，著作权属于受托人。委托人仅在约定使用范围内，或未约定范围时在委托创作的特定目的范围内，享有使用作品的权利。禁止把权属沉默写成“成果当然归委托方”。财产权可约定归委托方或共有；发表权、署名权、修改权、保护作品完整权不得写成已转让。
2. **与知产侧委托创作切开**：用户或文本把交易挂在「知识产权相关合同」货架，主给付是专有权转让、登记过户、许可/再许可或邻接权清单，创作只是取得权属的手段 → 负触发 `主给付是委托创作特定作品→`。不得打开或抄写该原子方法。
3. **与一般委托切开**：核心给付是处理事务或对外代理，不以交付著作权法意义上的作品为目的 → 负触发 `一般委托合同·审查`。不得把本类型改成授权范围、隐名代理或无偿任意解除主路径。
4. **与承揽切开**：按样制作、来料加工、复制、印刷，交付的是物或复制件，而不是从无到有创作作品 → 负触发 `定作合同·审查`（定作）、`加工合同·审查`（加工）、`复制合同·审查`（复制）或 `印刷合同·审查`（印刷）。不得因知识库写“非典型承揽属性”就按承揽审完，也不得把民法典第 787 条定作人单方随时解除写成唯一退出路径。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签委托创作正文，尚未签署，尚未成争，核心给付是委托人支付稿酬、受托人从无到有按需创作著作权法意义上的作品，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 处理事务、对外代理、以委托人名义签约、不开作品需求书也不交付作品 → `一般委托合同·审查`；
- 用户明确按「知识产权相关合同 / 委托创作」审查，或文本主轴是专有权转让、登记、许可/再许可、邻接权 → `主给付是委托创作特定作品→`；
- 按样加工、定作实物、复制、印刷，无独创性创作过程 → `定作合同·审查` / `加工合同·审查` / `复制合同·审查` / `印刷合同·审查`；
- 标的是已完成作品的买断或转让 → `或`；已有作品许可使用 → `或`；多方共同创作 → `多方共同创作→`；
- 设计服务过程为主、不指向著作权法作品 → `委托他人设计的服务合同·审查`；代笔主轴 → `委托代笔合同·审查`；技术/软件委托开发 → `委托技术开发合同·审查` 或对应技术类原子；
- 无文本、本类型条件已谈妥、要出己方稿 → `委托创作·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

约定创作违法、淫秽、暴力宣扬或损害公共利益的内容：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（委托人侧或受托人/创作者侧择一）；相对方；全文及附件/创作需求书/大纲版本；作品体裁与是否构成作品；权属条款是否写清财产权与人身权；职务作品冲突；第三方素材授权；免费修改次数；稿酬与节点；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的稿酬、字数、次数、期限用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验《著作权法》第 3、10、18、19、27 条，著作权民事纠纷解释第 12 条，民法典第 919、921、928、933、770、787、496–498、153、154、506、586 条，合同编通则解释第 10、16 条；`search_practiced` 只补审查反例；`search_template` 只借栏目结构。不虚构案件系统。

`search_law` 对上述法律结论为 required 级：不可用时不拒绝执行，只停止效力字段。返回 1990 年《著作权法》第十九条继承条款、2010 年《著作权法》第十七条旧条号、已失效《合同法》委托章或承揽章时记为噪声，不得写入 `L#`。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`基本面.md` 中“非典型承揽属性”不得写成应转承揽原子。“著作权（除署名权外）归委托方”必须拆成财产权约定与人身权保留。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `委托创作·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有委托创作文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。一般委托、知产侧委托创作、承揽定作/加工/复制/印刷、现成作品转让或许可、代笔、技术开发负触发。

### 2. 主体、职务作品与素材来源

签约名、履行名、付款名、发票名分列。受托人如为他人员工，核验是否构成职务作品。第三方素材未闭合：字段停止。

### 3. 作品、需求书与验收

标的须落到体裁、规格和《创作需求书》。签收、付款不当然等于验收。

### 4. 创作成果归属

权属沉默按受托人享有著作权处理，不得写成归委托方。约定归属须点名财产权种类、时点、地域，并保留人身权。

### 5. 稿酬、修改次数与退出

阶梯支付；免费修改次数封顶；弃用补偿。一次性预付全款标必须改，但不是违法。

### 6. 格式条款、强制规范与违法内容

无核验引文则法律结论字段停止。违法创作内容停笔。

### 7. 人身权、交付与发表、违约

交付不等于发表。独占许可不等于所有权转让。抄袭须有追偿路径。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把违法内容、权属沉默却写成归委托方、或把一般委托/知产侧/承揽主轴改成可履行本类型。
- `字段停止`：法域、动态规则、职务作品单位同意、第三方素材授权、影视制作许可未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
