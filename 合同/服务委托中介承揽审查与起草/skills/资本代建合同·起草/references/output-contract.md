# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证合同有效、必然回收本息、代建费必然优先或对方接受；编造未给出的注资额、费率、账户、工期；把已失效《合同法》及其解释写入结论；把《贷款通则》第六十一条写成企业间借贷一律无效；把合同内部分配写成已经压过商品房消费者价款返还、建设工程价款优先受偿或在先担保物权；把代建费约定“共益债务”写成破产受理前当然优先；把出资回报与代建费混成一笔固定回报后仍按委托报酬放行；把商业代建、政府代建、股权代建、配资或真借贷留在本技能改完。

## 1. 触发、单方立场与成果状态

立场（资本方/委托方、代建方/受托方、项目公司、原股东或原债权人、管理人或债委会）、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明是否同时存在资本注入和委托代建管理，以及出资回报与代建费是否已经分列。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、1990 年联营解答收缴利息、1991 年借贷意见、2015 年 24%/36% 条文时记噪声，不得写入 `L#`。名实、委托报酬与费用、随时解除、优先受偿顺位、共益债务、资质、利率上限无 `verified-result` 时，对应法律结论字段停止。

## 3. 类型与加载路径

父级 `委托合同`，子级 `资本代建合同`。定性理由必须同时满足：资本方注资；代建方受托管理特定项目。易混切开：商业代建、政府代建、股权代建、商业代建加贷款配资、真借贷、土地使用权委托代建、一般房地产委托代建。

加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读其他类型、未打开 `商业代建合同·审查`、`商业代建配资·审查` 或任何借款 method。代持、刚兑包装、以代建外壳放开发贷写停笔告知，不填可履行结构。

## 4. 主体、授权、资质与文本版本

主体表：资本方、代建方、项目公司或 SPV、原股东、原债权人或债委会、已售未交付业主（如有）、施工总承包（如有）。法人写名称与统一社会信用代码。资本方经营范围是否覆盖不动产投资或不良资产处置；代建方是否被文本或材料提及房地产开发资质。

版本表：资本代建/重组开发正文、投资或融资协议、共管协议、不良资产清册、后续工程概算及资金投放计划、回款分配模型、重组支持或权利放弃声明、管理人或债委会确认。冲突并列，不选对用户有利的一版。口头“债委会已经同意了”“查封已经解了”不得写成已同意或已解除。

## 5. 资本代建给付闭环

分列并回链文本位置：

- 项目标的：坐落、在建或待开发状态、权属、查封抵押、已售未交付范围。
- 委托事务：债权梳理、法律尽调、续建管理、重新入市、销售或代销、清算移交。
- 资本注入：性质（纾困/共益债/投资款）、金额、投放节奏、先决条件。
- 出资回报：本金回收、基础回报/利息、是否承担项目风险、失败时是否仍保本。
- 代建费：基础费计提基数（剩余货值或回收额）、节点、项目不能清偿时是否仍付；超额分成（Carry）触发条件。
- 两套科目是否混成固定回报。
- 物权：代建方是否被写成项目共有人或自动取得所有权。
- 共管：印章、证照、专项账户是否三方或双方共管；回款是否必须入账。
- 清算顺序：是否声明不对抗法定优先权；是否把代建费拟制成共益债务。
- 授权矩阵：小额支出、调规、大宗交易、大幅降价的终审权。
- 退出：强制退出补偿、品牌撤离、司法强制介入时的成本补偿。
- 销售方式：代销还是包销。

缺口标 `G#`，不补商业数字、账户或已解封事实。批准、解封、资质、首笔到位写成条件或双方义务期限，不写成已经完成。

## 6. 格式条款、强制规范与本类型效力红旗

金融机构或代建集团预先拟定且未协商的，按格式条款审查提示说明。

强制规范与效力红旗只在核验后落法律结论：虚假意思表示的表面代建；无资质从事房地产开发经营；以代建外壳规避放贷监管；代持股权规避金融监管；约定放弃或限制建设工程价款优先受偿且损害建筑工人利益；合同顺位压过商品房消费者。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

不得把“企业间借贷一律无效”或“合同写共益债务即优先于抵押”写成已核验结论。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔/转出口径。禁止输出无修改句的色块表。

本类型至少检查：出资回报与代建费未分列或合成固定回报；无管理事务的保本回购；配资或真借贷未转出；代建方被写成物权人；回款未入共管账户；清算顺序对抗消费者或工程款；共益债务拟制；历史债权交叉污染无隔离；代销写成包销；代持规避监管；单方提前终止无补偿；品牌与母公司债务未隔离。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字、账户、证号用 `【待填】`，不编造。禁止只给原则、不给句子。框架与硬闸冲突时按硬闸出句。

建议句必须覆盖本类型硬闸：分列出资回报与代建费；删除保本回购或固定高回报混科目；锁死委托管理与无物权；共管闭环；法定优先权防火墙；单方退出补偿。

## 9. 谈判与签署提醒

谈判顺序：先红线（无管理事务的固定回报、配资/真借贷未切开、代持规避、顺位压过消费者或工程款、伪造共管），再必须改（两套科目分列、共管账户、清算顺序声明、权属清理、生效条件），最后可优化。

签署提醒：资本方、代建方与项目公司本人签；债委会或管理人确认（如有）作附件；清册、概算、分配模型与共管账户资料核对；首笔资金到位与公章移交作为生效条件时，日期真实。不指导倒签、补假解封或假共管。

资本方立场须提示：未完成权属清理和共管前注资，回款可能被老债权人截留。代建方立场须提示：差额补足或劣后出资可能被重新定性；品牌用于烂尾项目存在声誉与产品责任外溢。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、破产申报、争议文书、回收额精算终局或效力保证。
