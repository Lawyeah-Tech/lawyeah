# 资本代建合同·起草

## 任务目标

在单一立场下，只起草 **委托合同 / 资本代建合同** 的待签文本：资本方注入纾困资金或投资资金，委托代建方对特定不动产项目做续建、开发管理、重新入市与销售清算；核心法律关系是委托管理，并耦合资金回收或投资收益实现。按已谈妥条件出己方稿，输出可编辑草稿、未决项；出稿后必须用本类型硬闸自审，输出风险表和修改句。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「审查资本代建合同（委托合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查、待签文本签前审查、履约交底、争议文书、合同或顺位有效性保证、商业代建本约整案、政府代建本约整案、股权代建本约整案、“商业代建 + 贷款配资”整案、真借贷整案、把本约改成可履行规避监管结构、利息或清算额终局数字。

## 工作边界

正触发：已有可读待签文本要评改（审查模式），或本类型条件已谈妥要出己方稿（起草模式）；尚未签署，尚未成争；核心给付同时具备：

1. **资本注入**：资本方（AMC、信托、保险资金、私募基金或同类）向项目或 SPV 投放纾困资金、共益债或投资款，并以项目回款作为回收来源；
2. **委托代建管理**：代建方受托处理续建/开发管理、权属清理、重新定位、销售或清算事务，而不是只出借货币。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只有品牌和管理输出、资本方不注入本项目资金，或对价仅是管理费/品牌费 → `商业代建合同·审查`；
- 政府或事业单位作为委托人的公建、非营利代建 → `政府代建合同·审查`；
- 核心结构是代建方持股/小股操盘换管理权，资金不是资本方注入的纾困或投资款 → `股权代建合同·审查`；
- 商业代建捆绑匹配贷款、配资杠杆或“代建 + 放贷”产品 → `商业代建配资·审查`；
- 标题写代建，但无可识别的管理事务，只有出钱、固定期限、固定回报、不承担项目经营风险 → `用户坚持固定保本保收益且不担风险：不得化妆成股权代建放行；明显无代建服务则负触发`；主文件本身是借款 → `主文件本身是借款→` / `无代建管理主给付，只是企业拆借→` / `或`；
- 父级是土地使用权、不是委托合同项下资本代建 → `或`；
- 无资本耦合的一般房地产委托代建 → `房地产委托代建合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问注资节奏、共管账户、复工节点 → 本套导航的履约步骤；
- 已成争（催告、查封执行、破产债权申报、索赔、立案仲裁）→ 合同争议或对应专项领域。

代持规避金融监管、以代建外壳发放房地产开发贷款、包装刚兑、伪造倒签或假共管：只出告知，不改写成可履行结构。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成。每一闸必须给出修改句或明确转出口径，禁止只打红黄绿。

1. **出资回报 vs 代建费**。资本方回收的本金与基础回报，和代建方的管理报酬，必须分列科目、计提基数、支付时点和失败后果。资本方回报来自项目回款分配，须承担项目经营或回收不能的风险；代建费是处理委托事务的报酬，按剩余货值、回收额或约定节点计提，即使项目不能清偿资本方本息，也要单独写清是否仍付基础费。禁止把两笔钱合成“固定高额回报”“保本回购”“不论盈亏按期付息”。混成一笔固定回报且资本方/代建方均不承担项目风险：按名实切开，不得留在本技能当委托报酬放行。
2. **与配资 `商业代建配资·审查` 切开**。出现匹配贷款、配资杠杆、以商业代建费为壳发放开发贷、或“代建管理 + 另行放贷还本付息”为主结构 → 负触发该原子。本技能禁止打开其 method，禁止把配资利率、放款条件、抵押包写成资本代建主路径。
3. **与真借贷切开**。无续建管理、权属清理、授权矩阵或销售清算等委托事务，只有货币投放与到期返还 → 负触发 `用户坚持固定保本保收益且不担风险：不得化妆成股权代建放行；明显无代建服务则负触发`；主文件是金融机构借款、企业拆借或狭义民间借款 → `主文件本身是借款→` / `无代建管理主给付，只是企业拆借→` / `或`。禁止打开或复制上述借贷 method，禁止套用保证期间、流质清算、让与担保过户主路径完成本任务。

附加必落句（有事实则单列，无事实在缺口节说明）：

- **委托管理锁死**：鉴于写明资本方投资/回收目的 + 代建方受托管理职责；代建方对项目不享有物权，仅享有合同约定的管理报酬债权。
- **资金闭环**：销售回款进入资本方与代建方共管专项账户；禁止体外循环。
- **法定优先权防火墙**：合同内部分配不得对抗商品房消费者价款返还、建设工程价款优先受偿、在先担保物权。不得把代建费或资本本息写成已经优先于上述权利。
- **共益债务不得拟制**：仅在破产受理后、符合法定条件时才可能参照共益债务；合同不得写成“双方同意视为共益债务即优先于抵押”。
- **品牌与债务隔离**：代建品牌仅用于营销展示；项目公司债务不当然由代建方集团母公司承担。
- **单方提前终止补偿**：资本方非因代建方违约提前退出，须按约定补偿已发生管理成本和已满足条件的分成，不得无偿撤场。

必须有修改句。每个风险回链文本位置。禁止套用商业代建的品牌费主线、小股操盘收购选择权主路径或政府代建财政支付主路径。禁止复制 `商业代建合同·审查`、`商业代建配资·审查` 或任何借款 method。

## 建立审查坐标

确认：使用者与授权；单方立场（资本方/委托方、代建方/受托方、项目公司、原股东或原债权人、拟签字的管理人或债委会）；相对方；全文及融资/代建/共管/清册附件版本；项目坐落与权属现状；注入资金性质（纾困、共益债、投资款）；代建事务范围；回报与代建费是否分列；共管账户；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

## 起草模式

本原子只承担本类型起草。待签评改转 `资本代建合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `资本代建合同·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`，不编造。

### 起草必写

- 核心给付同时写资本注入与委托代建管理：资本方投放纾困资金、共益债或投资款，代建方受托续建、权属清理、重新定位、销售或清算。
- 资本方本金与基础回报、代建方管理报酬必须分列科目、计提基数、支付时点和失败后果；代建费即使项目不能清偿资本方本息，也要单独写清是否仍付基础费。
- 鉴于写明资本方投资/回收目的 + 代建方受托管理职责；代建方对项目不享有物权，仅享有合同约定的管理报酬债权。
- 销售回款进入资本方与代建方共管专项账户。
- 合同内部分配不得对抗商品房消费者价款返还、建设工程价款优先受偿、在先担保物权。
- 共益债务仅在破产受理后、符合法定条件时才可能参照；不得写成双方同意即优先于抵押。
- 代建品牌仅用于营销展示；项目公司债务不当然由代建方集团母公司承担。
- 资本方非因代建方违约提前退出，须按约定补偿已发生管理成本和已满足条件的分成。

### 附件必附

- 融资/注资安排、代建事务范围、共管账户与印鉴安排。
- 项目权属/查封/已售未交付清册（有事实则附）。

### 禁止出现

- 把出资回报与代建费合成“固定高额回报”“保本回购”“不论盈亏按期付息”。
- 匹配贷款、配资杠杆、以商业代建费为壳发放开发贷，或“代建管理 + 另行放贷还本付息”为主结构（负触发配资原子）。
- 无续建管理、权属清理、授权矩阵或销售清算等委托事务，只写出钱、固定期限、固定回报。
- 代持规避金融监管、包装刚兑、伪造倒签或假共管：只告知，不起可履行稿。

出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口，不代替节点。

0. 签署状态与成果分流
1. 类型识别与单目录加载（资本注入 + 委托代建；切开商业代建 / 政府代建 / 股权代建 / 配资 / 真借贷）
2. 主体、资质、原债权人与已售未交付业主
3. 出资回报与代建费分列
4. 名实：名为代建实为借贷或实为股权转让
5. 管理权、物权隔离与权属清理
6. 资金闭环、清算顺位与法定优先权
7. 生效条件、共管、退出与监管报备
8. 按框架六步出修改句

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、假共管、代持规避监管、把无管理事务的固定回报改成可履行代建、把合同顺位改成压过消费者或工程款、保证必然优先受偿或必然回收本息。
- `字段停止`：法域、资本方经营范围或代建资质未核验；注入资金与代建费无法分列；项目权属/查封/已售未交付无法识别；共管账户未特定。
- `目标停止`：主目标已变为评改待签文本、履约交底、破产债权申报或诉讼文书，或用户要把本约改成纯借贷、纯配资或可履行规避结构。

生存级已售未交付业主权利未处理且用户拒绝升级：停止“可以签署”建议。
