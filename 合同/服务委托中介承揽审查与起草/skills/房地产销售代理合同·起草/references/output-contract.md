# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的佣金比例、节点、账户、期限；把已失效《合同法》委托章或居间章写入结论；把未备案写成可以展业；把未取预售证写成可以先卖；把佣金基数沉默写成已按对用户有利口径明确；把代理公司代收房款写成已闭合；把口头承诺学区/面积写成对开发商当然无约束；把中介/全案/一般委托当成已完成的本类型审查。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查房地产销售代理合同（委托合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》委托章或居间章、已失效《城市房地产中介服务管理规定》、已失效《经纪人管理办法》时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `委托合同`，子级 `房地产销售代理合同`。定性理由、易混切开结果（房屋买卖/租赁中介、全案销售委托代理、一般委托、渠道销售委托代理、商品房本约、行纪）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、备案、许可与文本版本

主体表：签约名、履行名、房款收款名、佣金付款名、发票名、授权签字人。资格表：开发资质痕迹、经纪机构备案痕迹、预售许可证或现售备案痕迹。版本表：正文、销售底价表、授权委托书、佣金结算流程、房号清单、聊天确认；冲突并列。未核备案或许可：该展业/开盘代理字段停止。

## 5. 委托范围、佣金、资金与宣传

核心给付是否开发商委托推销本项目并付代理佣金；是否夹带居间撮合、全案策划或概括事务；独家或非独家及自行销售是否付佣；佣金基数、节点、退佣；购房款/定金账户是否开发商监管账户；底价与备案价、折扣权限；广告是否书面审批。缺口标 `G#`。不输出中介跳单主路径、全案策划 IP 主路径或一般委托 933 弃权无效句。

## 6. 格式条款与强制规范

是否构成格式条款；免责、口头承诺排除、任意解除放弃、管辖/仲裁等异常条款是否加黑提示。强制规范只按第 153 条和解释第 16、18 条区分，不用失效口诀。无证预售、返本销售、售后包租、首付贷、阴阳合同、分割拆零只保留识别与停笔。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把框架里的实务量级写成法定期限。

## 9. 谈判与签署提醒

谈判顺序：先红线（类型错位、无证预售、代收房款进私户、违规促销、佣金以外收费），再必须改（经纪备案与许可附件、佣金基数/节点/退佣、独家自销、委托书权限、广告审批、现场公示），最后可优化。签署提醒：双方公章；底价表、委托书、结算流程、备案/许可查询页、监管账户信息入附件。不指导倒签或补假许可。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书或效力保证，也不是中介、全案或一般委托审查。
