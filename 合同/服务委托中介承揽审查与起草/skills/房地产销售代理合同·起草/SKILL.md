# 房地产销售代理合同·起草

## 任务目标

在单一立场下，只起草 **委托合同 / 房地产销售代理合同** 的待签文本，按已谈妥条件出己方稿，输出可编辑草稿、未决项；出稿后必须用本类型硬闸自审，输出风险表和修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文名必须是「审查房地产销售代理合同（委托合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、待签文本签前审查、履约交底、争议文书、有效性保证、把中介/全案/一般委托/渠道/商品房本约整案改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **开发商委托销售代理 ≠ 中介撮合 ≠ 全案营销包 ≠ 一般事务委托**：委托人是房地产开发企业或本项目售房权利人，受托人以委托人名义推销指定楼盘，对价是按成交计提的销售代理佣金。只报告订约机会、自己不成交一方 → 负触发 `房屋买卖_租赁中介合同·审查`。调研+策划+媒介推广+驻场销售捆成全案主轴 → 负触发 `调研+策划+媒介推广+驻场销售捆成全案主轴→负触发`。处理非本盘销售的一般事务 → 负触发 `一般委托合同·审查`。只带客结佣、不驻场不以开发商销售代理身份对外 → 负触发 `只带客结佣不驻场不以开发商销售代理身份对外→负触发`。修改句须写明开发商委托人、以委托人名义、房号范围和代理佣金，并收回居间撮合、全案策划包或概括事务措辞。
2. **备案与销售许可**：受托机构须出示房地产经纪机构备案公示或备案证明；预售须有现行有效的《商品房预售许可证》；现售须具备现售条件并完成现售备案。销售执行价不得突破当地已公示的一房一价或备案价。未取预售许可：不得改成可履行的预售代理。备案或许可未核：停止“可以展业/可以开盘代理”，不把部门规章备案写成民事合同当然无效。
3. **开发商销售代理佣金**：必须写清计算基数（网签合同总价 / 实际到账房款 / 备案价）、折扣是否扣减基数、支付节点、买受人退房或面积差是否退还已结佣金、独家代理下开发商自行销售或关系户是否仍付佣。受托人不得收取佣金以外的费用。禁止编造佣金比例。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签销售代理正文，尚未签署，尚未成争，核心给付是开发商委托推销本项目并按成交支付代理佣金，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只报告订约机会或提供媒介，自己不成交一方；二手房或租赁带看撮合 → `房屋买卖_租赁中介合同·审查`；不得删撮合条款后硬套本技能；
- 调研、产品定位、媒介投放、驻场销售捆成全案主给付，或标题与正文均是全案营销 → `调研+策划+媒介推广+驻场销售捆成全案主轴→负触发`；
- 概括处理事务、代办年报、诉讼代理，或销售只是顺带一句 → `一般委托合同·审查`；
- 只做渠道带客分销、不驻场、不以开发商销售代理身份对外 → `只带客结佣不驻场不以开发商销售代理身份对外→负触发`；
- 主文件是商品房买卖本约（价款、交房、办证） → `或对应买卖原子；` 或对应买卖原子；
- 以自己名义买入卖出房屋并吃差价 → `行纪合同·审查` 或回引擎；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

未取预售许可仍要预售、返本销售、售后包租、首付贷、阴阳合同、分割拆零、挪用购房款：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（开发商侧或代理机构侧择一）；相对方；全文及附件/底价表/委托书/结算单版本；委托人是否开发商及项目坐落、楼幢房号；预售证或现售备案痕迹；经纪机构备案痕迹；独家或非独家；佣金基数与节点；是否代收定金或房款；是否代签买卖本约；广告是否须书面审批；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的佣金比例、节点天数、账户、期限用 `【待填】`，不编造。

## 起草模式

本原子只承担本类型起草。待签评改转 `房地产销售代理合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `房地产销售代理合同·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`，不编造。

### 起草必写

- 核心给付是房地产开发企业或本项目售房权利人委托，受托人以委托人名义推销指定楼盘，对价是按成交计提的销售代理佣金。
- 写明开发商委托人、以委托人名义、房号范围和代理佣金。
- 佣金写清计算基数（网签合同总价 / 实际到账房款 / 备案价）、折扣是否扣减基数、支付节点、买受人退房或面积差是否退还已结佣金、独家代理下开发商自行销售或关系户是否仍付佣。
- 受托人不得收取佣金以外的费用。
- 期限、房号范围、是否代签本约、是否代收定金必须列举；销售现场须明示委托书和批准销售文件。
- 购房款和定金进开发商监管账户。
- 销售执行价不得突破当地已公示的一房一价或备案价；广告须书面审批。

### 附件必附

- 受托机构房地产经纪机构备案公示或备案证明。
- 预售：现行有效的《商品房预售许可证》；现售：现售条件及现售备案。
- 委托书、底价表。

### 禁止出现

- 居间撮合、全案策划包或概括事务措辞作为主给付（中介/全案/一般委托/渠道分销负触发）。
- 未取预售许可仍要预售代理。
- 购房款或定金进入代理公司一般户或私户。
- 返本销售、售后包租、首付贷、阴阳合同、分割拆零、挪用购房款：只告知，不起可履行稿。
- 把商品房买卖本约（价款、交房、办证）或行纪自营写进本约。

出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 留本任务起草并自审；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有销售代理文本；本任务只起草，评改待签文本转配对 ·审查 原子。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。中介撮合、全案营销包、一般事务委托、渠道分销、商品房本约、行纪自营负触发。

### 2. 主体、备案与销售许可

签约名、履行名、收款名、发票名分列。经纪备案、预售证或现售备案未核：字段停止。无证预售代理：停笔。

### 3. 委托书、权限与现场公示

期限、房号范围、是否代签本约、是否代收定金必须列举。销售现场须明示委托书和批准销售文件。

### 4. 开发商销售代理佣金

基数、节点、退佣、独家自销是否付佣必须闭环。不得收佣金以外费用。

### 5. 资金账户

购房款和定金进开发商监管账户。代理公司代收进一般户或私户：红线。

### 6. 价格、宣传、格式条款与强制规范

底价与备案价、折扣权限、广告书面审批。无核验引文则法律结论字段停止。

### 7. 违规促销与退出清算

返本销售、售后包租、首付贷、阴阳合同、分割拆零：停笔。终止须移交客户档案和现场。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把无证预售、返本销售、售后包租、首付贷、阴阳合同或代收房款进私户改成可履行结构。
- `字段停止`：法域、动态规则、经纪备案、预售证或现售备案、一房一价细则、监管账户未核验。
- `目标停止`：主目标已变为评改待签文本、履约交底、争议文书，或已锁他类。
