# 边界与路由

本技能只审查 **服务合同 / 行纪合同** 的待签文本。中文展示名是「审查行纪合同（服务合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 以委托人名义对外签约、开委托人抬头发票、概括处理事务、诉讼代理 | `一般委托合同·审查` |
| 只报告订约机会或提供媒介，自己不成交一方；房屋买卖/租赁中介 | `房屋买卖_租赁中介合同·审查`。其他中介走对应中介原子。不得删撮合条款后继续当行纪审 |
| 货过户到对方、滞销不退、存货风险归对方、买断再转售 | `或其他中介原子；买断再转售存货风险归己→负触发` |
| 广告发布、版面投放 | `广告发布合同·审查` |
| 广告代理排期、媒介购买而无商品贸易 | `广告代理合同·审查` |
| 纯劳务、计时服务、无商品贸易 | 对应劳务或服务原子，不得硬套本技能 |
| 无文本、本类型条件已谈妥、要出己方稿 | 留本任务起草并自审 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

行纪正文里夹带一小段对外买卖价格或交货期：专条交接买卖原子；自己名义、报酬、费用、价格指示、介入权、第三人责任、货权专户条款可继续审。用户坚持本技能把委托、中介或经销整案改完：`目标停止`。
