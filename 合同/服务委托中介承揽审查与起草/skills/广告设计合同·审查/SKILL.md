# 广告设计合同·审查

## 任务目标

在单一立场下，只审查 **服务合同 / 广告设计合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文名必须是「审查广告设计合同（服务合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、广告制作排期或媒介发布执行。

## 本类型硬闸

1. **设计成果著作权必须落句**：合同未明确约定时，受委托创作的设计作品著作权属于受托人（设计方）。广告主要取得专有许可或转让著作财产权的，必须书面写明作品名称、权利种类、媒介、地域、期限和价金。禁止只写“买断”“全部知识产权归甲方”。署名权、修改权、保护作品完整权不随财产权转让。交付源文件或效果图，不等于权属已经转移。
2. **与制作、发布切开**：本类型核心给付是创意、文案、视觉方案、分镜和可编辑源文件。成片、拍摄执行、喷绘实物 → `广告制作合同·审查`；媒介排期、刊例、曝光量或点击计酬 → `广告发布合同·审查`；设计、制作、发布捆在一份文本且无法拆出设计主给付 → `广告合同（广义）·审查`。设计验收不等于可以发布，更不等于已经完成法定广告审查。
3. **广告主应委托具有合法经营资格的广告经营者提供设计**。无资格主体承接、或出借资格承接：只告知，不改写成可履行挂靠。
4. **违法广告结构停笔**：为禁止生产、销售的商品或服务，为禁止发布的广告，或为无相关证明文件且包含集资内容的宣传提供设计，不得改成可履行文本。
5. **广告制作、广告发布、广义广告合同、非广告用途的功能性委托设计、一般委托创作负触发**，分别转对应场景原子，不填本类型十节实体结论。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签广告设计正文，尚未签署，尚未成争，核心给付是按广告主要求完成并交付设计成果，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 广告成片、喷绘实物或其他按设计稿加工的成品制作 → `广告制作合同·审查`；
- 媒介投放、发布执行、刊例或曝光量结算 → `广告发布合同·审查`；
- 设计+制作+发布无法拆出设计主给付 → `广告合同（广义）·审查`；
- 全案代理、媒介采买或账户代运营为主 → `广告代理合同·审查`；
- 以自己名义或形象作推荐、证明 → `广告代言服务类合同·审查`；
- 互联网广告发布者或程序化投放责任为主 → `互联网广告类合同·审查`；
- 非广告用途的包装结构、产品外观或工业设计出图 → `委托他人设计的服务合同·审查`；
- 一般文学艺术委托创作、无广告用途 → `委托创作·审查`；
- 建设工程施工图或方案设计 → `单独设计发包，无现场简易施工成果`；
- 调研建议书、无设计稿 → `咨询服务合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `广告设计合同·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

出借广告经营资格、为禁发商品或非法集资宣传提供设计：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及任务书/报价/素材清单版本；交付物是设计稿还是成片/投放；著作权是未约定、许可还是转让；源文件是否列入交付；免费修改轮次与确认人；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的费用、轮次、尺寸用 `【待填】`，不编造。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`基本面.md` 中“未约定时著作权一般归设计方”与现行委托作品规则一致，不得改写成归广告主。`框架.md` 中的“买断”必须展开为许可或转让清单，不得当作已经完成权属转移。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `广告设计合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有广告设计文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。制作、发布、广义混包、功能性委托设计、委托创作负触发。

### 2. 主体、资格与确认人

签约名、履行名、付款名、发票名分列。设计方经营范围是否含广告设计只记录表面；无资格不改成挂靠。样稿确认权锁定具体人员或邮箱。

### 3. 成果、权属与素材

设计成果特定到媒介尺寸和源文件格式。著作权许可或转让必须落句。广告主素材与设计方外购字体、图库、音乐分责。

### 4. 程序与验收

任务书附件化。免费修改轮次和“一轮”定义写死。异议须指向与任务书不符的具体项。设计验收不得写成可以发布。

### 5. 对价、源文件与定金

提案、初稿、终稿分阶段付款。源文件与尾款同时交换。定金不得超过标的额百分之二十。

### 6. 格式条款、强制规范与广告合规提示

无核验引文则法律结论字段停止。明知违法仍提供设计，不能用“甲方坚持”免责。

### 7. 转包、解除、留置与争议

主要创意转包须书面同意。完成前解除须有阶段赔偿表。不选定唯一法院充作意见。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把禁发或集资宣传改成可履行设计、坚持把制作/发布整案按本类型改完、拒绝删除买断空词仍要放行。
- `字段停止`：法域、动态规则、经营资格、广告审查窗口、字体图库授权未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
