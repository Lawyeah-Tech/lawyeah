# 边界与路由

本技能只审查 **服务合同 / 广告设计合同** 的待签设计文本。中文展示名是「审查广告设计合同（服务合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 成片、拍摄执行、喷绘实物、按设计稿加工的广告成品 | `广告制作合同·审查` |
| 媒介排期、刊例、曝光量或点击计酬、发布执行 | `广告发布合同·审查` |
| 设计、制作、发布捆成一份且无法拆出设计主给付 | `广告合同（广义）·审查` |
| 全案代理、媒介采买、账户代运营 | `广告代理合同·审查` |
| 以自己名义或形象作推荐、证明 | `广告代言服务类合同·审查` |
| 互联网广告发布者责任、程序化投放、信息流刊播为主 | `互联网广告类合同·审查` |
| 非广告用途的包装结构、产品外观、工业设计出图 | `委托他人设计的服务合同·审查` |
| 一般文学艺术委托创作，无广告用途 | `委托创作·审查` |
| 建设工程施工图、方案设计、图审 | `单独设计发包，无现场简易施工成果` |
| 调研建议书、战略意见、无设计稿 | `咨询服务合同·审查` |
| 处理事务、对外代理、代为投放操盘但无设计成果 | `一般委托合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `广告设计合同·起草` |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

广告设计正文里夹带一小段制作执行或发布排期：专章交接 `广告制作合同·审查` / `广告发布合同·审查`；设计成果、权属和源文件条款可继续审。用户坚持本技能把制作、发布、广义混包或功能性委托设计整案改完：`目标停止`。

禁止把本类型改写成 `广告合同（广义）·审查` 的混包审查，或改写成 `委托他人设计的服务合同·审查` 的功能性出图审查。
