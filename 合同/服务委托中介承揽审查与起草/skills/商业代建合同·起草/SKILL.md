# 商业代建合同·起草

## 任务目标

在单一立场下，只起草 **委托合同 / 商业代建合同** 的待签文本，按已谈妥条件出己方稿，输出可编辑草稿、未决项；出稿后必须用本类型硬闸自审，输出风险表和修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查商业代建合同（委托合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、待签文本签前审查、履约交底、争议文书、有效性保证、把政府代建/配资代建/股权代建/资本代建/合作开发/施工总包/纯销售代理整案改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **品牌代建边界**：核心给付是商事委托管理服务。代建方输出开发管理体系（工程代建与营销管理）及可选品牌许可；对价是基础代建费、绩效奖金和单独列明的品牌使用费。委托方是投资主体和风险承担主体；土地、在建工程和建成物业产权归委托方。代建方不承担项目融资，不为销售或投资亏损保底或连带。品牌与管理解耦：代建终止则品牌同步撤回。对外施工和采购合同由委托方直接签署，代建方只代为编制。禁止把“代建”写成代建方当发包人或开发商。
2. **与配资代建切开**：贷款、配资、垫资还本付息、固定资金回报、土地或在建工程为配资抵押、预售回款偿债与管理服务联立 → 负触发 `商业代建配资·审查`。不得打开或抄写该原子方法，不得删配资栏目后硬套。
3. **与政府代建切开**：政府投资、财政资金、代建制管理办法、行政机关或事业单位作委托方、行政协议路径 → 负触发 `政府代建合同·审查`。不得按财政审计、隐性债务或政府招标名录主路径改完。
4. **名为代建实为合作开发或转让**：代建方承担主要投资风险并获取剩余收益，或双方共同投资、共享利润、共担风险 → 负触发 `房地产合作开发联合拿地` 或对应联建原子。土地使用权解释（2020）第 12 条用于识别合作开发；第 23 条用于识别“不担风险、只收固定货币”的借款外观。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签商业代建正文，尚未签署，尚未成争，核心给付是委托方自担投资与融资、代建方输出管理体系并可选授权品牌、收取管理费，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 财政资金、政府投资、代建局/公建中心、地方代建制管理办法 → `政府代建合同·审查`；
- 管理服务与贷款、配资、垫资还本、配资抵押联立 → `商业代建配资·审查`；
- AMC/信托/不良资产回收或固定金融回报主轴 → `资本代建合同·审查`；
- 代建方入股项目公司、小股操盘 → `股权代建合同·审查`；
- 无品牌输出、无管理费拆分、只是一般房地产委托代建 → `房地产委托代建合同·审查`；用户按土地使用权货架审查委托代建 → `或`；
- 共同投资、共享利润、共担风险 → `房地产合作开发联合拿地` 或 `或`；
- 代建方自己施工或总承包取费 → `工地建筑活动承包资质竣工验收→` / `设计采购施工一体→`；
- 只做销售代理、不管理报建和工程 → `房地产销售代理合同·审查`；纯事务委托、无项目管理 → `一般委托合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

挂靠、违法分包、规避限购或规避融资监管：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（委托方/投资方或代建方/品牌管理方择一）；相对方；全文及附件/开发计划书/预算表/品牌规范版本；土地使用权与立项归属；是否含品牌授权；是否夹带配资或政府投资；费用是否分列；对外合同签署人；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的费率、节点、面积、金额用 `【待填】`，不编造。

## 起草模式

本原子只承担本类型起草。待签评改转 `商业代建合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `商业代建合同·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 核心给付是商事委托管理服务。代建方输出开发管理体系（工程代建与营销管理）及可选品牌许可；对价是基础代建费、绩效奖金和单独列明的品牌使用费。
- 委托方是投资主体和风险承担主体；土地、在建工程和建成物业产权归委托方。代建方不承担项目融资，不为销售或投资亏损保底或连带。
- 品牌与管理解耦：代建终止则品牌同步撤回。对外施工和采购合同由委托方直接签署，代建方只代为编制。禁止把“代建”写成代建方当发包人或开发商。
- 工程代建与营销管理分列。重大事项决策权留委托方，日常管理权归代建方。绩效须同时满足工期与质量。品牌手册和工艺标准归代建方；项目图纸付费后归委托方。

### 附件必附

- 《项目开发计划书》《项目成本预算表》《品牌授权使用规范》。含品牌输出而无品牌规范的，许可字段停止。

### 禁止出现

- 代建方当发包人或开发商。
- 贷款、配资、垫资还本付息、固定资金回报、土地或在建工程为配资抵押、预售回款偿债与管理服务联立。
- 代建方承担主要投资风险并获取剩余收益，或双方共同投资、共享利润、共担风险。
- 政府投资、财政资金、行政协议路径按本类型写完。
- 代建方自己施工或总承包取费。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 留本任务起草并自审；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有商业代建文本；本任务只起草，评改待签文本转配对 ·审查 原子。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。政府代建、配资代建、股权代建、资本代建、合作开发、施工、纯销售代理负触发。

### 2. 主体、土地手续、资质与授权

签约名、履行名、付款名、发票名分列。土地使用权和立项必须落在委托方或项目公司。口头“现场能签”不得写成已授权。

### 3. 服务范围、三权分立与代签隔离

工程代建与营销管理分列。重大事项决策权留委托方，日常管理权归代建方，监督权可给监理或第三方审计。对外合同甲方直签。

### 4. 费用拆分与品牌使用费

基础代建费、绩效奖金、品牌使用费分列。绩效须同时满足工期与质量。未给出的比例用 `【待填】`。

### 5. 融资隔离与重新定性

代建方不融资、不保底。共担风险或固定资金回报按硬闸 4 或转 `商业代建配资·审查`。

### 6. 品牌许可、摘牌与成果归属

品牌手册和工艺标准归代建方；项目图纸付费后归委托方。许可未备案不得写成已对抗善意第三人。

### 7. 格式条款、强制规范与退出

无核验引文则法律结论字段停止。有偿委托解除按第 933 条赔偿直接损失和履行利益，不得写成无偿随时解除。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把配资或政府投资主轴改成本类型、把挂靠或规避融资监管改成可履行、或把共担风险文本按管理费代建放行。
- `字段停止`：法域、土地使用权、立项规划、品牌权属、商标备案、地方必须招标范围未核验。
- `目标停止`：主目标已变为评改待签文本、履约交底、争议文书，或已锁他类。
