# 边界与路由

本技能只审查 **委托合同 / 商业代建合同** 的待签文本。中文展示名是「审查商业代建合同（委托合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 政府投资、财政资金、代建局/公建中心、地方代建制管理办法、行政协议 | `政府代建合同·审查`。不得抄该原子方法，不得删财政/招标栏目后硬套本技能 |
| 商业代建与贷款、配资、垫资还本、配资抵押、预售回款偿债联立 | `商业代建配资·审查`。不得抄该原子方法，不得删配资栏目后硬套 |
| AMC、信托、不良资产回收、固定金融回报主轴 | `资本代建合同·审查` |
| 代建方入股项目公司、小股操盘、跟投退股 | `股权代建合同·审查` |
| 无品牌输出、无管理费/品牌费拆分的一般房地产委托代建 | `房地产委托代建合同·审查` |
| 用户按「土地使用权」货架审查委托代建 | `或` |
| 共同投资、共享利润、共担风险 | `房地产合作开发联合拿地`；一方操盘联建 → `或` |
| 代建方自己施工、按工程造价取费 | `工地建筑活动承包资质竣工验收→` 或 `设计采购施工一体→` |
| 只做销售代理、不管理报建和工程 | `房地产销售代理合同·审查` |
| 纯事务委托、对外代理、无项目管理交付 | `一般委托合同·审查` |
| 仅工程咨询、无代建管理权 | `只出可行性造价或管理咨询意见不交付测绘测试成果→` |
| 土地一级开发或一二级联动主轴 | `土地一级开发委托合同·审查` 或 `“一二级联动”相关合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `商业代建合同·起草` |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

商业代建正文里夹带一小段销售代理佣金或监理选聘：专条交接 `房地产销售代理合同·审查` 或 `或`；管理费、品牌解耦、融资隔离、对外直签条款可继续审。用户坚持本技能把政府代建、配资代建、合作开发或施工整案改完：`目标停止`。
