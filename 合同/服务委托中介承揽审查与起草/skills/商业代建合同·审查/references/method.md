# 审查方法（锁定 委托合同 / 商业代建合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制政府代建的行政协议/财政审计/隐性债务主路径，禁止复制配资代建的借贷/抵押/利率主路径，禁止复制施工总包的工程价款与工期索赔主路径，禁止复制 `房地产委托代建合同·审查` 的一般房地产委托代建骨架。

定性校验：标题、核心给付与本类型一致才继续；政府代建、配资代建、股权代建、资本代建、合作开发、施工、纯销售代理明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受或唯一必得管理费。

`search_law` 返回已失效《合同法》委托章（第 396–413 条）、承揽章（第 251–268 条）、合同法解释（二）第 14 条、1993 年《房地产开发企业资质管理规定》、1999 年《关于如何确认公民与企业之间借贷行为效力问题的批复》、2005 年土地使用权解释旧条号单独引用时记为噪声，不得写入 `L#`。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。厦门/深圳等地《建设项目代建合同》示范文本和 BT 回购文本属于政府投资或回购结构：只作负向切开，不得把财政审计、招标名录或政府回购栏目写入本类型修改句。未知权威的“房地产项目委托开发管理合同”常把品牌使用与管理绑死、或把对外签约权笼统授给代建方：只借栏目。

知识库纠正（不回写双文件）：

- `基本面.md` “意思自治优先……均为有效”：现有依据不支持把商事合意写成当然有效。须过民法典第 153 条和合同编通则解释第 16 条。
- `基本面.md` “代建方通常具有房地产开发一级资质”：2022 年修正后资质仍分一、二级，不是“必须一级才有效”。一级承担规模不受限制，二级限建筑面积 25 万平方米以下。委托管理服务不等于代建方自己从事房地产开发经营。未取得资质不得从事房地产开发经营，但不当然使委托管理合同按施工合同解释（一）第 1 条无效。缺证书则字段停止，不写“无一级资质合同无效”。
- `基本面.md` 绿城、蓝城、万科等商号：举例，不是签约主体适格条件，不得写入修改句当法定要求。
- `框架.md` “赔偿上限通常不超过已收取的管理费”“查封则主张已完成工作的双倍报酬”：谈判口径，非法源。缺数字用 `【待填】`，不编造上限或双倍。
- `框架.md` “3%—5%” 基础代建费：市场观察，不是法定费率。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。标题写“委托开发”“项目管理咨询”“品牌输出”的，先看：委托方是否自担投资与融资；代建方是否输出管理体系并可选授权品牌；对价是否为管理费而非剩余利润。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 委托方持地并自担投资，代建方输出开发管理及可选品牌，收取基础费/绩效/品牌费 | 本类型 | 正触发 |
| 政府或财政资金、代建制管理办法、公建中心 | 政府代建 | 负触发 `政府代建合同·审查` |
| 管理服务与贷款、配资、垫资还本、土地或在建工程抵押联立 | 配资代建 | 负触发 `商业代建配资·审查` |
| AMC/信托纾困、不良资产回收、固定金融回报 | 资本代建 | 负触发 `资本代建合同·审查` |
| 代建方入股项目公司、小股操盘 | 股权代建 | 负触发 `股权代建合同·审查` |
| 无品牌、无管理费拆分的一般房地产委托代建 | 房地产委托代建 | 负触发 `房地产委托代建合同·审查` |
| 共同投资、共享利润、共担风险 | 合作开发 | 负触发 `房地产合作开发联合拿地` |
| 代建方自己施工或按造价取费 | 施工/总承包 | 负触发 `工地建筑活动承包资质竣工验收→` / `设计采购施工一体→` |
| 只做销售代理 | 销售代理 | 负触发 `房地产销售代理合同·审查` |

支持切开的规范（法律结论须运行时复核）：

- 民法典第 919 条：委托是处理委托人事务。本类型是处理开发管理事务，不是完成施工工作成果。
- 民法典第 770 条：按要求完成工作、交付工作成果走施工或承揽原子。
- 土地使用权解释（2020）第 12 条：共同投资、共享利润、共担风险是合作开发。
- 土地使用权解释（2020）第 23 条：提供资金不承担经营风险、只收取固定数额货币，应认定为借款合同。
- 《政府投资条例》第 5、6 条：政府投资受预算约束；财政资金项目不是本类型。
- 民间借贷规定第 10、13 条：企业间生产经营借贷与未取得放贷资格向社会不特定对象放贷，用于识别夹带配资时是否应整案转出。

### 1.2 加载协议（硬闸）

本技能已锁定 **委托合同 / 商业代建合同**。只打开 `references/基本面.md` 与 `references/框架.md`。禁止读其他子目录，禁止为对照再开第二类，禁止打开 `房地产委托代建合同·审查`、`政府代建合同·审查` 或 `商业代建配资·审查` 的 method。

### 1.3 品牌代建边界与三切开（硬闸）

| 文本写法 | 本任务动作 | 修改句方向 |
| --- | --- | --- |
| 品牌房企输出管理+可选品牌，委托方出地出钱，管理费分列，写明代建方不融资 | 正触发，留下本类型 | 首部写明“商业代建管理服务，不是政府代建、配资代建或合作开发” |
| 发改委/财政/城投作为政府投资委托人，适用代建制管理办法 | 负触发 `政府代建合同·审查` | 不按本类型改完 |
| 代建方向委托方提供建设资金或介绍配资，土地抵押给资方，管理费含资金占用费 | 负触发 `商业代建配资·审查` | 不得删配资条后硬套 |
| 代建方包揽投资并分剩余利润，或共担亏损 | 负触发 `房地产合作开发联合拿地` | 不得改成管理费结构假装仍是委托 |
| 标题“商业代建”但正文是政府投资项目 | 按核心给付转 `政府代建合同·审查` | 标题不单独定性 |

修改句（正触发首部）：

「本合同为商业代建管理服务合同。甲方作为项目投资主体和土地使用权人，委托乙方输出开发管理体系【含／不含】品牌许可，并向乙方支付代建管理费和约定品牌使用费。乙方不承担本项目融资义务，不对本项目销售去化或甲方投资损益承担保底或连带责任。本合同不是政府投资项目代建，不是贷款或配资安排，也不是共同投资、共享利润、共担风险的合作开发。」

最强反方：相对方主张已构成合作开发（因有超额销售分成）、政府代建（因城投出面）或配资（因有启动资金监管）。修改句必须收回共担亏损、财政资金和还本付息措辞。用户坚持保留这些主轴：负触发，不填本类型十节实体结论。

### 1.4 挂靠、违法分包、规避监管停笔（硬闸）

加载后或定性中出现：借用开发或施工资质、把必须招标的施工发包改成“代建内部分包”、以代建名义规避房地产开发贷款或预售资金监管。

动作：

1. 交付告知：挂靠、违法分包、必须招标而未招标的施工合同，可能因民法典第 153 条和施工合同解释（一）第 1 条无效。本任务不改写成可履行的规避结构。
2. 不写资质挂靠、阴阳招标或体外融资路径。
3. 风险表只保留识别依据和删除/转出口径。
4. 用户坚持“改到能签且仍做这些安排”：整体停止。

## 节点 2　主体、土地手续、资质、授权与文本版本

### 2.1 主体表

建表：签约名、履行名、付款名、发票名、土地使用权人、立项主体、授权签字人、派驻项目总经理。名称不一致不自动合并。委托方须有土地使用权或取得土地的确定路径；材料未出示权证则字段停止，不写“可以开工”或“可以预售”。

口头“我们老板同意了”不得写成已授权。项目公司尚未设立：修改句把生效条件绑到项目公司设立且承继本约，或由发起人签署并承诺转承。

### 2.2 开发资质与管理能力

支持依据：资质管理规定（2022）第 3、5、15 条；城市房地产开发经营管理条例；土地使用权解释（2020）第 13 条（合作开发资质，负向对照）。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 委托方作为开发建设单位，未出示资质证书 | 字段停止；修改句要求签署前交付与项目规模匹配的资质证明 | 无资质也可以开发经营且合同当然有效 |
| 代建方未出示管理团队和类似项目业绩 | 必须改：附件列派驻名单和可核验业绩，不把“头部房企”写成法定条件 | 已具备一级资质故必然适格 |
| 文本写“乙方必须具备一级资质否则合同无效” | 必须改：改为与项目规模匹配的有效资质或可核验管理能力；效力判断留待核验 | 一级是本类型法定生效条件 |

修改句：

「甲方确认其是本项目土地使用权人和开发建设单位，应在签署前向乙方出示与项目规模相匹配的房地产开发资质证书及立项、规划许可的取得或办理安排。乙方确认其派驻团队见附件《派驻人员名单》。乙方未取得房地产开发资质的，不得被解释为已获准以自己名义从事本项目的房地产开发经营；甲方不因签署本合同而免除其作为建设单位的法定义务。」

### 2.3 表见代理与书面授权

支持依据：民法典第 172、503、920、923、925 条。

现场项目总经理签署工程签证、材料订单，相对人可能主张表见代理。必须写清：授权范围、金额上限、何种文件必须加盖委托方公章、越权由谁承担内部追偿。

修改句：

「甲方应向乙方出具书面《授权委托书》，列明单笔合同签署和资金拨付限额。限额以内的日常文件，乙方可以代为编制，由甲方直接签署或按授权书指定方式签署。限额以上或涉及土地使用权抵押、预售、融资、对外担保的文件，必须由甲方法定代表人或授权代表签署并加盖甲方公章。乙方人员超越授权签署的，对甲方不发生效力，但相对人有理由相信其有代理权的除外；因此给甲方造成损失的，乙方应赔偿。」

不得写成“内部授权可以对抗任何善意相对人”。

## 节点 3　服务范围、三权分立、代签隔离

### 3.1 服务组合必须可识别

标的须落到：工程代建（报建、招标组织、施工管理、验收移交）与营销管理（定价建议、销售组织、品牌使用）是否包含；是否含拿地建议、集中采购、物业或商业运营。只有“全过程开发”则标缺口，出修改句，不编造范围。

修改句：

「乙方服务范围以附件一《项目开发计划书》所列工作包为准，分为工程代建与营销管理。未列入附件一的拿地、物业运营或商业运营，不构成本合同义务。乙方组织总包或供应商招标的，定标权归甲方。」

### 3.2 三权分立

| 文本写法 | 动作 |
| --- | --- |
| 代建方“全权决策”“甲方不得干预” | 红线：重大事项（调规、超预算、定标、定价、融资、抵押）留甲方 |
| 甲方对日常用工、材料品牌逐笔审批且无小额豁免 | 必须改：设定小额审批豁免，避免管理瘫痪 |
| 无监督安排 | 必须改：监理或第三方成本审计有权查阅 |

修改句：

「甲方享有重大事项决策权，包括规划指标调整、超附件二预算【待填】% 的变更、总包及【待填】万元以上采购定标、开盘价格、融资和抵押。乙方享有附件一范围内的日常管理权。监理单位或甲方聘请的第三方对成本、进度和质量享有查阅和提出书面异议的权利。单笔不超过人民币【待填】元且不改变附件二科目的支出，甲方应在【待填】个工作日内完成审批；逾期未书面否决的，视为同意该笔日常支出。」

### 3.3 代发与代签（硬闸配套）

框架要求盯死“代发 vs 代签”。代建方通常只代为编制对外合同，由委托方直接签署，以隔离发包人身份和施工合同解释下的发包人责任。

修改句：

「乙方负责起草、比选和提交施工、监理、材料采购等对外合同文本，甲方是该等合同的唯一签署方和发包人。未经甲方书面授权，乙方及其派驻人员不得以甲方或项目公司名义签署对外合同。本合同不使乙方成为施工承包人或联合发包人。」

## 节点 4　费用模型、绩效与品牌使用费

### 4.1 三类费用必须拆开

| 文本写法 | 动作 |
| --- | --- |
| 只写“综合管理费 X%”，含品牌、绩效、代收代付 | 必须改：基础代建费、绩效、品牌使用费、代收代付分列 |
| 绩效只挂钩销售额，不挂钩质量和工期 | 必须改：节点奖励须工期与质量同时满足 |
| 品牌使用免费或永久 | 必须改：单独列品牌使用费和授权期限 |
| 代收代付无核对 | 必须改：发票、台账、甲方抽查 |

修改句：

「本合同项下甲方应向乙方支付的费用分为：（1）基础代建费，按【销售额／建筑面积】的【待填】% 或人民币【待填】元／平方米，于【节点】支付；（2）绩效奖金，仅在附件一节点按期完成且质量验收合格时计提，成本节约分成和超额销售分成的计算基数、核对材料见附件二；（3）品牌使用费，按【待填】单独支付，不因基础代建费的支付而视为已经付清。办公费、营销费等代收代付费用不属于乙方报酬，须凭发票实报实销，甲方有权抽查。」

未给出的比例写 `【待填】`。不得把知识库“3%—5%”填进意见。

### 4.2 定金与履约保证金

必须使用“定金”二字才讨论罚则。“订金、保证金、预付款”无定金性质约定的，不得写成定金。约定或推算超过主合同标的额百分之二十：超过部分不产生定金效力。管理费总额未定时，定金字段停止。

### 4.3 资金监管与断供

委托方资金断供是本类型高频甲方违约。修改句要求建设资金按节点到位，并约定断供后的停工、撤场和已完成工作报酬，不得把代建方写成必须垫资续建。

修改句：

「甲方应按附件一节点将建设资金存入双方约定的监管账户。监管账户资金仅用于本项目建设成本，不得挪作他用。甲方逾期【待填】日未按节点足额到位的，乙方有权暂停服务并书面催告；催告后【待填】日仍未到位的，乙方有权撤场，甲方应支付已完成工作对应的基础代建费和已发生的代收代付费用。乙方无义务以自有资金垫付建设成本。」

## 节点 5　融资隔离与重新定性（硬闸）

支持依据：土地使用权解释（2020）第 12、23 条；民间借贷规定第 10、13 条；民法典第 921 条（必要费用垫付 ≠ 项目融资）。

| 文本写法 | 动作 |
| --- | --- |
| 明确乙方不融资、不保底、产权归甲方 | 可保留；补反说 |
| 乙方垫付全部或主要建设资金，按固定利率收回 | 负触发 `商业代建配资·审查`，或红线删除后才能留在本类型 |
| 乙方承担经营亏损并分剩余利润 | 负触发 `房地产合作开发联合拿地` |
| 乙方“协助融资”但无边界 | 必须改：协助限于提供管理资料，不构成放贷、担保或差额补足 |
| 第 921 条垫付必要费用被写成无限垫资 | 必须改：限于经甲方事先书面同意的小额必要费用，并按约定偿还 |

修改句（融资隔离）：

「乙方不是本项目的融资提供方或担保人。除经甲方事先书面同意且单笔不超过人民币【待填】元的必要事务费用外，乙方无义务垫付建设资金。任何贷款、配资、抵押或预售回款偿债安排，须另行签署协议；该等安排不因本合同而成立。甲方不得要求乙方对销售去化、售价或投资回报承担保底、差额补足或连带责任。」

最强反方：相对方主张超额销售分成已构成共担风险。现有依据支持：绩效奖金挂钩不等于共同投资。若分成条款同时要求乙方补亏、锁定剩余收益或把土地权益转给乙方，则已超出本类型，应负触发合作开发或配资原子。

用户坚持保留垫资还本或共担亏损主轴：负触发，不填本类型十节实体结论。

## 节点 6　品牌许可、摘牌、知识产权与移交

### 6.1 品牌与管理解耦（硬闸配套）

支持依据：商标法第 43 条。许可人应监督商品质量；未经备案不得对抗善意第三人。必须在商品上标明被许可人名称和产地。

| 文本写法 | 动作 |
| --- | --- |
| 品牌随管理“永久授权”，解除后仍可用 | 红线：代建终止则品牌同步终止；设摘牌期限和费用 |
| 未写备案、未写质量监督 | 必须改：备案义务、质量标准和违规摘牌 |
| 把品牌手册所有权写成归甲方 | 必须改：手册和工艺标准知识产权归乙方；甲方仅在授权期内按规范使用 |

修改句：

「甲方有权在附件三《品牌授权使用规范》载明的项目名称、物业类型、地域和期限内使用乙方指定品牌标识。该许可随本合同解除或终止而同时终止。甲方应在终止后【待填】日内完成摘牌、撤下销售物料并停止使用近似标识。乙方应按商标法将本许可报商标局备案；未经备案不得对抗善意第三人，但不影响甲乙之间的合同义务。品牌手册、工程工艺标准和培训材料的知识产权归乙方；项目生成的图纸、档案在甲方付清对应费用后归甲方。」

不得写“备案后必然能对抗所有第三人”或“未备案许可无效”。

### 6.2 收购选择权与小股操盘

框架提示商业代建常附带小股操盘或优先收购权。出现股权条款：

- 仅有“将来可协商入股”：标可优化，不得写成已取得股权；
- 已约定持股比例、估值、退出固定价：负触发 `股权代建合同·审查`，本任务只交接股权条款，不按股权代建改完整案；
- 用户要求本技能把入股结构改完：目标停止。

### 6.3 三阶移交

工程竣工验收移交、营销尾盘移交、物业运营移交分列。签收、付款不当然等于验收。

## 节点 7　格式条款、强制规范、违约与退出

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 7.1 格式条款

为重复使用而预先拟定、订立时未与对方协商。品牌房企“代建标准文本”不因“这次只用一次”而排除格式条款。审查：代建方免责、甲方资金无限连带、品牌永久授权、最终解释权、管辖/仲裁等是否有足以引起注意的标识（第 496 条；解释第 10 条）。未提示可主张不成为内容，不是当然无效。

### 7.2 强制规范

违反法律、行政法规强制性规定不一律无效（第 153 条；解释第 16 条）。禁止用已失效“效力性/管理性”口诀。挂靠、必须招标而未招标的施工安排：不改写成有效履行。造成对方人身损害或因故意、重大过失造成对方财产损失的免责条款无效（第 506 条）。建设单位质量责任不因委托代建而当然转移；水利工程质量管理规定第 20 条可作为“代建不替代项目法人质量责任”的同类规范参照，房屋项目仍以建设工程质量管理条例和施工合同解释（一）第 13 条作运行时核验。

### 7.3 解除与有偿委托

禁止只写“双方协商解除”。不得把第 933 条写成无偿随时解除。商业代建是有偿委托：解除方应赔偿直接损失和合同履行后可以获得的利益，除非不可归责。品牌撤回条件须可核验（债务违约、声誉事件的定义和通知）。

修改句：

「甲方因自身原因解除的，应书面通知，并按已完成节点支付基础代建费；已确认节点的绩效按附件二结算。乙方无正当理由暂停服务超过【待填】日，或派驻项目总经理连续【待填】日缺位且未按甲方书面要求更换的，甲方可书面解除，乙方应返还尚未对应完成工作的预收费用，并配合摘牌和资料移交。任何解除导致品牌许可同时终止。因解除造成对方损失的，有偿委托的解除方应赔偿对方的直接损失和合同履行后可以获得的利益，不可归责于该方的除外。」

### 7.4 争议解决

商业代建常约定仲裁。出现仲裁条款不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核，修改句改成单一仲裁机构或单一法院连结点。

每条修改句固定格式：
