# 委托代笔合同·审查

## 任务目标

在单一立场下，只审查 **委托合同 / 委托代笔合同** 的待签文本，输出：与委托创作切开、作者身份与署名安排、风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他合同类型。场景分层为 **P0**。中文 displayName 必须是「审查委托代笔合同（委托合同）」。

禁止写成普通委托创作审查换标题。禁止打开或复制 `委托创作·审查`、`主给付是委托创作特定作品→` 的 method。

`depends-on` 为空。不要求先跑导航。

不交付：普通委托创作审查、已完成作品转让/许可审查、设计或技术开发审查、从零起草、履约交底、争议文书或诉讼策略、有效性保证、可履行的学位论文/职称论文/考试/科研代写代投结构。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成：

1. **代笔 ≠ 委托创作 ≠ 辅助服务 ≠ 整理作品**。本类型核心给付是隐名执笔，对外以委托人名义表明作者身份。受托人仍署名、分成或公开创作贡献 → 负触发 `委托创作·审查` 或 `主给付是委托创作特定作品→`。只做素材搜集、校对或咨询、不负责具体表达 → `一般委托合同·审查`。整理作品保留原作者并标注整理者，不是代笔。已完成作品买断财产权 → `或`。标题写成“委托创作协议”或“文案策划服务协议”只作名实对照，不单独定性。
2. **作者身份不能由合同单独制造**。创作作品的自然人是作者。委托人须有原始构思、口述、大纲或核心素材等实质性贡献；否则受托人即使承诺放弃署名，作者身份仍有极强主张空间。修改句必须挂《原始素材清单》和贡献方式。禁止把独立创作改写成虚假“机械整理”以制造作者。自传体作品另核著作权解释第十四条。
3. **署名权不可转让**。可约定财产权归属或转让；不得写“转让署名权”“永久放弃署名权即甲方成为作者”“全部著作人身权归甲方”。修改句改为：乙方自愿不在作品上署名、不以真名或笔名表明作者身份；该约定不消灭作者身份，也不替代出版、学术或平台合规。发表、修改、保护作品完整权不整包买断。
4. **资格证明类代写停笔**。学位论文、毕业论文、职称评审论文、考试答卷、科研项目申报材料或论文代写代投：只出告知，不改写成可履行文本。用户坚持“改到能签”：整体停止。不得用“学术顾问”包装这类标的。
5. **身份保密与对价闭环**。代笔事实、合作关系、私密素材永久保密，不因履行完毕或解除终止。报酬拆成劳务费与不行使署名补偿；预付、大纲确认款、定稿款分列；尾款可作保密保证金。支付完毕前须签署《不行使署名权确认书》。泄密违约金可高于稿酬，但不得写“不得调整”。
6. **主观质量、影子作者与草稿移交**。作品类型、篇幅、口吻、大纲确认节点、免费修改次数和风格不满时的终止权必须可核验。工作室须锁定核心执笔人。定稿后移交草稿、底层素材并限制私自留存主张权利。原创性保证与查重。自传或纪实素材的真实性、名誉与隐私由提供该素材的一方承担。

必须有修改句。禁止只打红黄绿。每个风险回链文本位置。

## 工作边界

正触发：已有可读待签正文，尚未签署，尚未成争，核心给付是隐名执笔、对外以委托人名义作为作者使用作品，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 核心给付是从无到有创作作品，受托人可以署名或公开作者身份，不要求隐去执笔人 → `委托创作·审查`；知识产权货架下同类主文件 → `主给付是委托创作特定作品→`。禁止用本技能或委托创作 method 反过来硬套；
- 只处理事务、检索、校对或咨询，不负责具体表达 → `一般委托合同·审查`；
- 功能性、技术性设计图纸或方案，独创性不明或重心是设计交付 → `委托他人设计的服务合同·审查`；
- 技术方案、专利或技术秘密开发 → `委托技术开发合同·审查`；技术咨询或技术服务 → `委托技术咨询·审查` / `委托技术服务·审查`；
- 已完成作品的财产权转让或许可 → `或` / `或`；
- 类型未定或名实明显不符 → 本套导航的类型切开步骤；
- 无文本、本类型条件已谈妥、要出己方稿 → `委托代笔合同·起草`；
- 已签只问交稿日、付款日、查重留痕 → 本套导航的履约步骤；
- 已成争（催告、解除、索赔、恢复署名诉讼、仲裁）→ `或对应专项领域。` 或对应专项。不写诉讼策略。

挂靠、违法分包、规避限购、资格证明类代写、伪造素材清单：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（委托人/名义作者，或受托人/执笔人）；相对方；全文及附件版本；作品类型与用途；是否学位、职称、考试或科研申报；委托人贡献方式；对外署名安排；执笔人是自然人还是工作室；报酬是否含不行使署名补偿；保密范围；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的稿酬、字数、修改次数用 `【待填】`，不编造。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `委托代笔合同·起草`；已签履约留痕 → 本套导航履约步骤；已成争 → 争议专项。未签且目标是评改已有代笔文本，才进入本任务。

### 1. 类型锁死与委托创作切开

标题、核心给付与隐名执笔、对外作者身份一致才继续。普通委托创作、一般委托、转让许可、设计或技术开发负触发。资格证明类代写停笔。

### 2. 作者身份与素材贡献

委托人实质性贡献；自传体解释第十四条；法人视为作者的三项条件；工作室实际作者链条。

### 3. 署名安排与财产权

不行使署名 ≠ 转让署名 ≠ 作者变更。财产权按第十九条、第二十七条逐项列明。

### 4. 对价、保密与确认书

劳务费与补偿分列；永久保密；支付挂钩确认书。

### 5. 质量、修改、草稿与第三人

主观标准可核验；锁定执笔人；移交草稿；出版追责切分；素材名誉隐私。

### 6. 格式条款、任意解除与强制规范

提示说明；第九百三十三条可约定赔偿但难以彻底剥夺；第一百五十三条与资格证明类停笔。

### 7. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持学位论文/职称/考试/科研代写代投、伪造素材或口述记录、把独立创作改成虚假机械整理、保证放弃署名即委托人就是作者或合同必然有效。
- `字段停止`：作品用途是否资格证明类未核验；素材贡献方式未见；核心执笔人身份未见；地方出版或平台实名规则未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书或普通委托创作/转让整案。

生存级稿酬或个人无限连带且用户拒绝升级：停止“可以签署”建议。
