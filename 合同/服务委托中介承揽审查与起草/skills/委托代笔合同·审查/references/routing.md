# 边界与路由

本技能只审查 **委托合同 / 委托代笔合同** 的待签文本。中文展示名是「审查委托代笔合同（委托合同）」。

禁止使用半截 ID。禁止把普通委托创作、著作权转让或技术开发审查方法套到本任务。禁止复制 `委托创作·审查` 的 method。

负触发只写触发判定、路由和最小交接，不填十节实体结论。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 从无到有创作，受托人可署名或公开作者身份，不要求隐去执笔人 | `委托创作·审查`；本任务不审“创作者署名 + 默认权属”主路径 |
| 知识产权货架下的委托创作主文件，重心是作品权属与使用范围而非隐名 | `主给付是委托创作特定作品→` |
| 只处理事务、检索、校对或咨询，不负责具体表达 | `一般委托合同·审查` |
| 整理作品保留原作者并标注整理者 | 回引擎或 `委托创作·审查`；不得改成隐名代笔 |
| 已完成作品处分复制、发行、信息网络传播等财产权 | `或` 或 `或` |
| 功能性、技术性设计交付 | `委托他人设计的服务合同·审查` |
| 技术方案、专利或技术秘密开发 | `委托技术开发合同·审查` |
| 技术咨询或技术服务 | `委托技术咨询·审查` 或 `委托技术服务·审查` |
| 标题像委托创作，正文要求永不披露执笔身份 | 留本任务；标题冲突写入版本表 |
| 学位论文、职称论文、考试或科研代写代投 | 停笔告知；不转创作原子改成可履行 |
| 无文本、本类型条件已谈妥、要出己方稿 | `委托代笔合同·起草` |
| 已签未争、只问交稿日、付款或查重留痕 | 本套导航的履约步骤 |
| 已催告、恢复署名、索赔或要诉讼策略 | `或对应专项领域。`；不写诉讼策略 |
| C 端大众快检 | 只分流，不回改 |

专业版未收录的 P1 场景不会安装对应原子。若用户拿该文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。

用户坚持本技能给出普通委托创作整案、转让登记或代写论文可履行意见：`目标停止`。
