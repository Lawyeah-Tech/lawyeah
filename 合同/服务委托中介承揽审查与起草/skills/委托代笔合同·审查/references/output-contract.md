# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、放弃署名即委托人成为作者、对方必然接受；编造未给出的稿酬、字数、修改次数；把已失效《合同法》、1990 年著作权法未修正文本写入结论；把 `委托创作·审查` 的委托创作 method 套到本约；把学位论文或职称论文代写改成可履行结构。

## 1. 触发、单方立场与成果状态

立场（委托人/名义作者 或 受托人/执笔人）、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查委托代笔合同（委托合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》、1990 年著作权法未修正第十条或 1991 年实施条例时记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `委托合同`，子级 `委托代笔合同`。写明核心给付是隐名执笔、对外以委托人名义表明作者身份，不是普通委托创作。定性理由、与委托创作/一般委托/整理作品/转让许可切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型、未打开 `委托创作·审查` method。知识库与硬闸冲突时，以 method 硬闸为准。资格证明类代写、挂靠或伪造素材写停笔告知。

## 4. 主体、作者身份与文本版本

主体表：委托人、对外署名名、受托人、实际执笔人、付款名、发票名、授权签字人。作者身份：委托人贡献方式、素材清单是否存在、是否自传体、是否主张法人作品。版本表：正文、附件、确认书、大纲、聊天确认；冲突并列。

## 5. 给付闭环

作品类型与用途（是否资格证明类）；署名安排；财产权是否逐项；报酬拆分与支付节点；大纲确认与修改次数；保密期限；草稿移交；查重。缺口标 `G#`。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹；高额违约金、永久弃权是否标识。强制规范只区分是否导致民事行为无效。资格证明类代写走第一百五十三条和第二款公序良俗，不改写成可履行。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。禁止输出无修改句的色块表。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。必须覆盖已触发的硬闸。禁止只给原则、不给句子。禁止写出转让署名或“甲方即唯一作者”的放行句。

## 9. 谈判与签署提醒

谈判顺序：先红线（资格证明类代写、虚假机械整理、转让署名并拟制作者、无贡献确认唯一作者），再必须改（不行使署名句、素材清单、财产权逐项、保密与确认书、锁定执笔人），最后可优化。签署提醒：本人签字按印、素材清单、不行使署名确认书、草稿移交清单、日期。不指导倒签或补假口述记录。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书、普通委托创作审查或效力保证。
