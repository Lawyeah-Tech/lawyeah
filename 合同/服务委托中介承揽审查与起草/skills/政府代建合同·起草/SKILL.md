# 政府代建合同·起草

## 任务目标

在单一立场下，只起草 **委托合同 / 政府代建合同** 的待签文本，按已谈妥条件出己方稿，输出可编辑草稿、未决项；出稿后必须用本类型硬闸自审，输出风险表和修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查政府代建合同（委托合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、待签文本签前审查、履约交底、争议文书、有效性保证、把商业代建/房地产委托代建/BT/DBO/施工/全过程咨询整案改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **财政资金与国库集中支付**：政府投资项目所需资金应按预算和国库管理拨付；代建方通常只行使进度审核和签字确认权，不得经手或垫付建设资金。文本要求代建方全额垫资、建设资金进入代建账户体外循环，或财政分期回购本金加回报：红线。已构成建造—移交融资结构 → 负触发 `当事人明确按BT专约交易→`，不得按本类型改成可履行垫资。
2. **采购程序**：企业代建须核验公开招标或政府采购程序痕迹；事业性代建走机构设立或授权，不得套用企业招标口径。无程序痕迹：字段停止，修改句要求把中标通知书或采购文件列为附件且未完成前不生效。用户坚持“直接指定企业就能签”：整体停止，不得改成可履行规避采购结构。
3. **与 BT / DBO 切开**：代建方筹资建设、政府分期回购 → `当事人明确按BT专约交易→`。承包人设计+建造+长期运营、业主融资 → `承包人设计+建造+长期运营业主融资→`。不得打开或抄写这两个原子的方法，不得删掉回购/运营栏目后硬套本技能。
4. **与商业/房地产委托代建切开**：委托方是开发商或社会资本，标的是经营性商品房或商业综合体，对价含品牌输出、销售分成或剩余利润 → `房地产委托代建合同·审查` 或 `商业代建合同·审查`。不得抄商业代建 method。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签政府代建正文，尚未签署，尚未成争，核心给付是政府或授权机构将财政资金投资的非经营性项目建设管理职责委托给事业性机构或经采购程序选定的企业代建人，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 开发商或社会资本委托房企代建经营性房地产，含品牌或销售指标 → `房地产委托代建合同·审查` 或 `商业代建合同·审查`；
- 融资/投资安排与代建耦合、固定回报或不良资产盘活主轴 → `资本代建合同·审查`；代建方入股项目公司 → `股权代建合同·审查`；商业代建叠加借款配资 → `商业代建配资·审查`；
- 代建方垫资建设、政府分期回购本金和回报 → `当事人明确按BT专约交易→`；
- 设计+建造+长期运营维护，承包人不负责融资 → `承包人设计+建造+长期运营业主融资→`；
- 业主发包、承包人按图施工并交付工程 → `工地建筑活动承包资质竣工验收→`；设计+采购+施工总承包 → `设计采购施工一体→`；
- 可行性研究、造价、招标代理或全过程工程咨询智力服务为主，不以代建人身份组织实施政府投资项目 → `只出可行性造价或管理咨询意见不交付测绘测试成果→`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

挂靠、违法分包、伪造招标、规避采购、垫资形成隐性债务：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（委托方/使用人侧或代建方侧择一）；相对方；全文及立项批复/概算/采购文件版本；委托方是否行政机关或授权机构；代建方是事业性还是企业；资金是否预算内财政资金；是否要求垫资或回购；企业代建招标或政府采购痕迹；概算批复；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的管理费、比例、期限、概算数字用 `【待填】`，不编造。

## 起草模式

本原子只承担本类型起草。待签评改转 `政府代建合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `政府代建合同·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`，不编造。

### 起草必写

- 写明委托人是政府或授权机构，标的是财政资金投资的非经营性项目建设管理职责；代建方是事业性机构或经采购程序选定的企业代建人。
- 建设资金按预算和国库集中支付；代建方只行使进度审核和签字确认权，不经手、不垫付建设资金。
- 管理范围落到报建、招标组织、质量/进度/投资控制、验收移交；概算、规模、标准写红线。
- 在建工程和残值属国有资产，禁止抵押质押。
- 管理费与建设资金分列；财政资金结余缴回国库；绩效奖励不得写成截留建设资金。
- 有偿委托解除写通知期和赔偿，不得把第 933 条写成无偿随时解除。
- 事业性代建走机构设立或授权；企业代建写明公开招标或政府采购程序痕迹，未完成前合同不生效。

### 附件必附

- 立项批复、概算批复。
- 企业代建：中标通知书或政府采购文件；未附则正文写明未完成前不生效。
- 绩效考核指标、使用人会签安排（有事实则附）。

### 禁止出现

- 代建方全额垫资、建设资金进入代建账户体外循环、财政分期回购本金加回报（已构成 BT 则负触发，不按本类型改成可履行垫资）。
- “直接指定企业就能签”、伪造招标、规避采购。
- 把商业代建品牌/销售分成、资本代建固定回报、股权代建入股、施工总承包或全过程咨询写进本约主给付。
- 挂靠、违法分包、垫资形成隐性债务：只告知，不起可履行稿。

出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。他类型出稿、已签履约、已成争：仍负触发。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 留本任务起草并自审；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有政府代建文本；本任务只起草，评改待签文本转配对 ·审查 原子。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。商业代建、房地产委托代建、资本/股权代建、BT、DBO、施工、全过程咨询负触发。

### 2. 主体、三方界面与文本版本

签约名、履行名、付款名（财政/国库）、发票名、使用人分列。事业性与企业代建分列。口头“领导已定了”不得写成已授权或已完成采购。

### 3. 标的、概算与国有资产

管理范围落到报建、招标组织、质量/进度/投资控制、验收移交。概算、规模、标准写红线。在建工程和残值属国有资产，禁止抵押质押。

### 4. 财政资金、国库支付与采购程序

建设资金国库集中支付；代建方不经手建设资金。企业代建核验招标或政府采购。垫资回购切到 BT。

### 5. 代建费、节余、定金与退出

管理费与建设资金分列。财政资金结余缴回国库。绩效奖励不得写成截留建设资金。不得把第 933 条写成无偿随时解除。

### 6. 格式条款、强制规范与行政协议定性

无核验引文则法律结论字段停止。不得写成必然行政协议。垫资、规避采购、挂靠不改成可履行。

### 7. 超概、廉政、审计、争议

超概、舞弊、审计结算、档案移交分别有可执行后果。仲裁条款不得改写成“应向某法院起诉”。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把垫资回购或规避采购改成可履行本类型，或把商业代建/BT/DBO/施工主轴按本类型放行。
- `字段停止`：法域、动态规则、立项批复、概算、预算安排、企业代建采购程序、当地代建名录未核验。
- `目标停止`：主目标已变为评改待签文本、履约交底、争议文书，或已锁他类。
