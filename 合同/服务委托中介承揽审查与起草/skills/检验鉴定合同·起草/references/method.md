# 审查方法（锁定 承揽合同 / 检验、鉴定合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制测试测绘的坐标系/测绘资质节点、咨询的“不保证解决问题”主路径或修理的既有物修复节点。

定性校验：标题、核心给付与本类型一致才继续；明显是测绘、测试、咨询、技术开发或修理则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、报告必然被采信、对方必然接受或唯一必得鉴定费。

`search_law` 返回已失效《合同法》承揽章、《加工承揽合同条例》、2000 年《司法鉴定机构登记管理办法》、2007 年《司法鉴定程序通则》或其解释时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。2019 年民事诉讼证据规定与 2023 年民事诉讼法条序互引可能错位，出庭与重新鉴定的条号运行时核验。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。测绘、咨询或修理范本只证明是另一类型，不得当作本类型范本。

知识库纠正（不回写双文件）：

- `基本面.md` “承揽人应保证成果符合法定或行业程序要求，确保其在后续作为证据使用时具有证明力”：只能改成程序、方法、签字盖章和出庭配合义务。不得写成保证法院采信、保证作为定案根据或保证交易成就。
- `框架.md` “结果必须符合 XX 标准”：结果兜底，违反独立性，红线删除。可改成“按约定标准或方法检测并如实记载结果”。
- `基本面.md` 把司法鉴定与 CMA/CNAS 并列：两轨不可互换。司法鉴定走司法行政机关登记与名录；向社会出具证明作用的检验检测走 CMA 能力范围。CNAS 是实验室认可，不是法定许可。
- `基本面.md` “名为鉴定实为虚假证明”指向刑事风险：停笔告知，不把刑法第 229 条扩大写成一切虚假鉴定必然构成本罪（该条列举的是评估、验资、审计、保荐、安全评价、环评、环境监测等中介职责）。
- 民法典第 770 条列举加工、定作、修理、复制、测试、检验，未单列鉴定与测绘。鉴定因交付结论性工作成果，按承揽审查；测绘主轴仍转 `测试测绘合同·审查`，不得用第 770 条把测绘吞进本类型。

## 节点 1　类型识别与单目录加载

### 1.1 与测绘 / 测试切开（硬闸）

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

本类型成立，须同时满足：

1. 工作对象是特定检材、现场或争议事实，而不是一片土地、一栋房屋的空间几何本身。
2. 工作内容是对照已知标准做符合性判断（检验），或对成因、真伪、伤残、责任等作结论性判断（鉴定）。
3. 对价对应出具《检验报告》或《鉴定意见书》，而不是交付测绘图纸、坐标数据集或单纯测试曲线。

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 鉴定事项、符合性评价、合格/不合格、成因、真伪、伤残等级、司法鉴定意见 | 本类型 | 正触发 |
| 测绘资质证书、比例尺、CGCS2000、高程系统、地籍/房产测绘、地图编制、界址点坐标 | 测试、测绘 | 负触发 `测试测绘合同·审查` |
| 只交付性能测试数据、压力曲线、环境监测原始读数，不作符合性或成因结论 | 测试、测绘 | 负触发 `测试测绘合同·审查` |
| 只出可行性论证或建议，不交付检验鉴定意见 | 咨询 | 负触发咨询原子全 ID |
| 从无到有研发检测方法或新装置 | 技术开发 | 负触发开发原子全 ID |
| 修复已损坏设备 | 修理 | 负触发 `修理合同·审查` |

支持切开的规范（法律结论须运行时复核）：

- 第 770 条：检验是承揽的一种，与测试并列，不是测绘的下位概念。
- 测绘法（2017 修订）第 27 条：从事测绘活动须取得测绘资质证书。测绘资质不能代替司法鉴定登记或 CMA。
- 知识库：测试侧重定量数据；鉴定侧重对争议事实的结论；测绘受测绘法规制并出图/数据集。

正文夹带现场取样坐标或房屋尺寸复核：测量专条可交接 `测试测绘合同·审查`；鉴定事项、资质回避、意见效力留本任务。用户坚持整案按测绘改完：`目标停止`。

最强反方：相对方主张“测了也是鉴定”“有 CMA 就能测绘”或“房屋质量鉴定当然含房产测绘”。现有依据不支持用标题或一次进场把两类主给付合并。

### 1.2 检验与鉴定内部分流（不转出）

| 类型 | 判断轴 | 合同必须落到 |
| --- | --- | --- |
| 检验 | 已知标准的定性定额比对 | 指标、标准号、判定规则（含测量不确定度时是否考虑） |
| 鉴定 | 成因、真伪、责任或争议事实 | 鉴定事项、方法顺序、意见书形式、异议与出庭 |

两者都留本技能。事项写“综合评估”“有关鉴定”而不特定：字段停止，修改句补事项清单。

### 1.3 加载协议

本技能已锁定 **承揽合同 / 检验、鉴定合同**。只打开 `references/基本面.md` 与 `references/框架.md`。禁止读其他子目录，禁止为对照再开第二类，禁止打开测绘类型双文件。

### 1.4 虚假结论 / 无资质诉讼鉴定 / 应回避仍承揽停笔

加载后或定性中出现：要求按委托人指定合格结论或指定伤残等级出具报告；要求出具虚假检验检测报告；无司法鉴定资质仍要出具诉讼用鉴定意见；鉴定人与当事人或鉴定事项有利害关系且拒绝回避；出借《司法鉴定许可证》或组织未取得执业证人员署名。

动作：

1. 交付告知：司法鉴定程序通则（2016）第 5 条实行鉴定人负责，鉴定人须独立、客观、公正，不得违反规定会见诉讼当事人；第 15 条对超范围、材料不真实或不合法、用途不合法的委托不得受理；第 20 条命中回避事由应当回避。机构登记管理办法（2005）第 39 条禁止超范围、出借许可证、组织未取得执业证人员从业。不得改写成可履行的指定结论或无资质诉讼鉴定结构。
2. 不写假许可证路径、假名录、体外挂靠结算或“先出报告再补证”。
3. 风险表只保留识别依据和删除/转出口径。
4. 用户坚持“改到能签且仍做这些事”：整体停止。

部门规章或许可未核：字段停止，不宣告合同当然无效（民法典第 153 条；合同编通则解释第 16 条）。无许可仍要出具诉讼鉴定意见：红线。

## 节点 2　主体、资质与回避（硬闸）

### 2.1 主体表

建表：签约名、履行名、付款名、发票名、授权签字人、拟在报告上署名的鉴定人或授权签字人。名称不一致不自动合并。司法鉴定由机构统一接受委托，不得写成个人私自承揽。口头“我们有资质”不得写成已核验证书。

法院已指定机构：合同主体与指定文书并列；程序受法院监督，本任务不改指定结果，只审本约费用、检材、出庭和回避。

### 2.2 两轨资质

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 用途是诉讼/仲裁司法鉴定，无许可证或签字人不在名录 | 字段停止；修改句要求许可证、名录页和执业证作为附件 | 可以出鉴定意见；CMA 就等于司法鉴定资质 |
| 拟检项目不在 CMA 证书附件能力范围 | 红线：超范围不得出具具有证明作用的报告 | 营业执照含“检测”即可 |
| 只有 CNAS 认可证书 | 字段停止。CNAS 不能单独替代 CMA，更不能替代司法鉴定登记 | 已具备全部资质 |
| 核心检验/鉴定交第三人，无书面同意 | 必须改。第 772 条：主要工作应交自己完成 | 转包不影响意见效力 |
| 机构与签字人证书主体不一致 | 必须改；疑似挂靠则走 1.4 停笔 | 自动合并为同一主体 |

修改句：

「乙方确认：本合同【检验 / 司法鉴定】事项属于其【《资质认定证书》（CMA）附件能力范围 / 《司法鉴定许可证》登记的执业类别】，证书编号【待填】，有效期至【待填】；拟署名人员【姓名】持有有效【授权签字 / 司法鉴定人执业证】，证书编号【待填】，并已编入相应名录。上述证书复印件作为附件。超出附件能力范围或登记类别的项目，乙方不得出具报告，甲方有权书面终止并要求退还未发生费用。未经甲方书面同意，乙方不得将取样、检测、分析或意见签发等主要工作交第三人；交第三人完成辅助工作的，乙方就该成果向甲方负责。」

### 2.3 回避

司法鉴定程序通则（2016）第 20 条：鉴定人本人或其近亲属与诉讼当事人、鉴定事项涉及的案件有利害关系，可能影响独立、客观、公正的，应当回避；曾经参加过同一鉴定事项鉴定、曾经作为专家提供过咨询意见、或曾被聘请为有专门知识的人参与过同一鉴定事项法庭质证的，应当回避。

| 文本写法 | 动作 |
| --- | --- |
| 无回避声明、无利害关系披露 | 必须改：签署前书面披露并入附件 |
| 已知利害关系仍写“双方同意不回避” | 红线。诉讼用途不得用约定排除法定回避 |
| 同一鉴定人曾就同一事项出具咨询或参加过质证 | 必须更换鉴定人；更换不了则终止 |
| 只写“依法回避”无具体事由清单 | 必须改：列出通则第 20 条事由并给申请回避期限 |

修改句：

「乙方应在签约前向甲方书面披露：拟派鉴定人及近亲属与甲方、相对方或本鉴定事项有无利害关系，以及是否曾就同一事项鉴定、咨询或出庭质证。存在司法鉴定程序通则第二十条情形的，该鉴定人应当回避，乙方应在【待填】日内更换符合资质的鉴定人；无法更换的，本合同终止，乙方退还尚未发生的费用。甲方有权在知悉回避事由后【待填】日内书面申请回避。不得约定“双方同意不回避”或“甲方放弃申请回避”。」

最强反方：机构主张“商业委托不适用回避”。现有依据不支持在诉讼用途上用商业惯例排除通则第 20 条；非诉讼检验仍应披露可能影响公正性的利害关系，否则意见证明力会被攻击。

## 节点 3　检材、事项、标准与进场预审

审查清单，缺一项则该字段不得写成已闭环：

1. 检材名称、性状、数量、包装、封样状态、唯一性标识。
2. 检材移交方式、进场预审；不足、污染或不具备条件时补充或终止。
3. 鉴定/检验事项清单一事一列，禁止“有关问题一并鉴定”。
4. 技术依据：国家标准、行业标准、规程或双方认可的方法；司法鉴定方法顺序见通则第 23 条（国标 → 行业标准和技术规范 → 多数专家认可的方法）。
5. 破坏性试验损耗比例、残留样退还或销毁；危险、易燃易爆或易腐样品的领回或处置费。

| 文本写法 | 动作 |
| --- | --- |
| “检材现状以收样为准，委托人事后不得异议”且无登记表 | 必须改。单方收样不得写成已共同确认 |
| “仅对来样负责”且取样由承揽人现场抽取 | 必须改：区分实验室来样与承揽人抽样；抽样代表性由抽样方负责 |
| 无事项清单，只写“质量鉴定” | 必须补具体法律/技术事实 |
| 用途写诉讼证据但方法由委托人临时指定且与通则第 23 条冲突 | 必须改：方法入附件，变更须书面 |

修改句：

「双方应在实验或勘验开始前共同签署《样品登记表》，载明检材名称、唯一性标识、封样状态、数量及表观性状，并拍摄编号照片作为附件。乙方预审认为检材不足、污染或不具备检验鉴定条件的，应在【待填】日内书面告知补充；逾期未补或仍不具备条件的，任何一方可书面终止，甲方仅支付事先书面列明的预审费用，总额不超过人民币【待填】元。甲方保证检材来源合法、与委托事项对应；因检材虚假或不合法导致报告不能使用或乙方被追责的，由甲方承担相应责任，但不免除乙方对程序、方法和保管的义务。」

最强反方：承揽人主张“收样即视为检材无争议”。现有依据不支持把单方收样写成共同确认。期间毁损适用第 784 条，进场状态是区分原损与二次损坏的事实前提。通则第 15 条：材料不真实、不完整、不充分或取得方式不合法的，不得受理。

## 节点 4　意见效力与独立性（硬闸）

支持依据：民事诉讼法（2023 修正）第 80、82 条；民事诉讼证据规定（2019 修正）第 36、38、41、79 条；司法鉴定程序通则第 5、32、45 条。出庭对应的民诉法条号以运行时核验为准（2019 证据规定第 79 条仍指向修正前第 78 条）。

### 4.1 不得保证采信，不得约定结论

| 文本写法 | 动作 |
| --- | --- |
| “乙方保证本报告作为法院定案根据 / 保证对方和法院必须采信” | 红线删除。鉴定意见须经质证，法院可不予采信 |
| “结果必须符合 GB/T××或必须支持甲方索赔” | 红线。结果兜底，违反独立性 |
| “鉴定意见出具后不得申请重新鉴定或提出异议” | 红线删除。对方可反驳自行委托意见并申请鉴定 |
| 只写“依法出具意见”无成果形式 | 必须改：报告名称、原件份数、检验检测专用章或司法鉴定专用章、鉴定人签名 |

修改句：

「乙方应按附件《检验项及标准明细表 / 鉴定事项清单》载明的方法独立实施，如实记载数据、分析和意见，不受甲方或任何第三人对具体结论方向的指示。乙方不保证报告被人民法院、仲裁机构或行政机关采信，不保证作为定案根据，不保证实现甲方的交易或索赔目的。甲方不得在合同中指定合格、等级、伤残程度或责任比例。报告应载明委托事项、检材、原理方法、过程、意见，由鉴定人或授权签字人签名，并由乙方加盖【司法鉴定专用章 / 检验检测专用章及资质认定标志】；委托机构鉴定的，从事鉴定的人员须签名。」

可退让：把“不保证采信”收成风险告知页单独签署。不可退让：保留指定结论或保证定案。

最强反方：定作人主张“花了鉴定费就该保证能打赢”。实务反例：鉴定意见不具唯一性，须经形式和实质审查，法院可否定。2019 证据规定第 41 条：一方自行委托的意见，对方有证据或理由足以反驳并申请鉴定的，应予准许。

### 4.2 出庭、异议与重新鉴定

| 文本写法 | 动作 |
| --- | --- |
| “乙方不出庭、不接受质询” | 红线。经通知拒不出庭，鉴定意见不得作为认定事实的根据 |
| 无异议期限 | 必须补收到报告后的书面异议期和答复期 |
| 异议后必须免费重新鉴定 | 必须改：区分笔误更正、补充说明、补充鉴定、重新鉴定；重新鉴定费用与是否更换机构另约 |
| 出庭费用“已包含且不得再收”但诉讼用途 | 可谈：写明出庭次数上限和超出后的差旅/工时，数字用 `【待填】` |

修改句：

「甲方或人民法院、仲裁机构依法通知乙方指派鉴定人出庭说明的，乙方应予配合；委托机构鉴定的，由从事鉴定的人员出庭。因乙方无正当理由拒不出庭，致使报告不能作为认定事实根据的，乙方应【退还已收报酬的【待填】% / 赔偿甲方因此支出的鉴定费和合理直接损失】。甲方对报告有异议的，应在收到报告后【待填】日内书面提出；乙方在【待填】日内书面答复。属于笔误的，乙方应出具书面更正，不得无故撤销报告。需要补充鉴定或重新鉴定的，按当时程序规则办理；重新鉴定原则上委托原机构以外的机构，费用由【提出方先行垫付 / 双方另约】。」

## 节点 5　对价、预审止损与验收

工时/项目费与现场取样费、差旅、对比样本、加急费、余样处置费分列。原因不明或条件不明须先预审再书面报价。禁止编造单价。未给出的数字写 `【待填】`。

| 文本写法 | 动作 |
| --- | --- |
| 只有“鉴定费若干”，不分预审与正式鉴定 | 必须改 |
| 不具备鉴定条件仍须付全额 | 红线。约定可终止，并单列预审费上限 |
| 预付款写成定金且超过标的额 20% | 超过部分不产生定金效力（第 586 条）；无核验引文则该法律结论字段停止 |
| 签收报告即付清且不得异议 | 必须改：异议期内可暂扣约定尾款；签收不等于对结论无异议 |
| “无论结论如何，费用不退”且因乙方程序违法导致报告不能使用 | 必须改：程序违法或方法不符时减酬、重作或解除（第 781 条） |

修改句：

「费用由预审费人民币【待填】元与正式鉴定/检验费人民币【待填】元构成，现场取样、差旅、对比样本、加急和余样处置另行书面确认。乙方预审认为不具备条件的，应书面终止；甲方仅支付预审费，已收其余款项【待填】日内退还。尾款于交付符合第 4 节点形式要求的报告后【待填】日内支付；甲方在异议期内提出书面异议的，可暂扣尾款人民币【待填】元至答复完成。」

## 节点 6　787、格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 定作人完成工作前的解除

条文：定作人在承揽人完成工作前可以随时解除合同，造成承揽人损失的，应当赔偿损失。

| 文本写法 | 动作 |
| --- | --- |
| “甲方不得以任何理由中途解除/撤回委托” | 红线删除 |
| “甲方放弃第七百八十七条” | 红线。本任务不把放弃写成可放行 |
| “甲方可随时解除且无需支付任何费用” | 必须改。解除后仍应赔偿已发生预审、已消耗检材和方法准备的损失 |
| 报告已签发后仍套“随时解除” | 现有依据不支持再走 787；质量或程序问题走第 781 条及异议条款 |

修改句：

「甲方在乙方出具正式报告前，可以书面通知解除本合同。解除后，甲方应赔偿乙方因此受到的损失，包括截至解除通知到达时已发生且能提供记录的预审和检测费用、已破坏性使用的检材成本，以及其他合理直接损失；各项以书面凭证为准，不得重复计算。正式报告签发后，甲方不得再依据本条解除，但不影响其依据质量、程序或法律规定主张减酬、补充或赔偿。」

### 6.2 格式条款

为重复使用而预先拟定、订立时未与对方协商。鉴定机构格式协议不得仅以“这次没用过第二次”否认。

审查：保证采信、约定结论、仅对来样负责、排除出庭、责任限额仅为检测费、管辖/仲裁等是否有足以引起注意的标识（第 496 条；解释第 10 条）。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在委托书背面 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

### 6.3 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的、是否仅行政管理、是否只规制履行行为（第 153 条；解释第 16 条）。禁止用已失效“效力性/管理性”口诀代替解释第 16 条。司法鉴定登记、CMA 多为监管要求：未出示证书主要是监管后果和意见不被使用的风险，不得单独写成民事合同当然无效；无资质仍要出诉讼鉴定意见或出具虚假报告：不改写成有效履行。

## 节点 7　质量、保管、余样与争议

1. 工作成果不符合质量或程序要求：定作人可合理选择补充、重作、减少报酬、赔偿损失（第 781 条）。因取样不规范、实验室条件或方法违反规范，导致报告被撤销或不被使用：必须有可执行后果，不得只写“依法承担违约责任”。
2. 检材丢失、污染、超常损耗：回链样品登记表和第 784 条，约定按重置或约定单价赔偿，数字用 `【待填】`。
3. 责任限额：鉴定错误可能放大交易或判决金额。限额可谈，但因故意或重大过失、虚假报告、应回避而未回避导致的损失，不得预先免除。无核验引文不把限额写成当然有效。
4. 危险、易燃易爆或易腐余样：检验后由定作人立即领回或支付处置费；未约定期限不得写成承揽人无偿无限期保管。
5. 争议解决：出现仲裁条款，不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核。不选定唯一法院充作法律意见。
6. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。

修改句（程序违法）：

「因乙方取样不具代表性、超出能力范围、违反约定或当时有效的技术方法和程序，或应回避而未回避，致使报告被有权机关撤销、不予采信或不予使用的，甲方有权要求退还已付报酬并赔偿因此增加的补充鉴定、重新鉴定和合理直接损失。乙方因故意或重大过失、出具虚假报告导致甲方损失的，不得主张责任限额。」

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

打开已加载的 `框架.md`，按六步逐段对照正文。`基本面.md` 用于校验类型、主体、检材、资质和红旗，不代替本节点出句。

| 步 | 动作 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题用检验合同或鉴定协议，不用测绘、测试、咨询、维修混称；主体与证书一致；鉴于写用途和事项，不写保证采信 | 标题或主体修改句 |
| 交易条款 | 事项清单；检材登记；标准或方法；报告形式与印章；预审止损 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 资质与回避；意见效力与出庭；787；程序违法后果；余样；保密 | 可执行后果句或删除句 |
| 尾部 | 样品登记表、事项及标准明细、回避声明、证书复印件入附件；禁止倒签 | 生效与附件修改句 |
| 语言 | 正说加反说；盯死检验 vs 鉴定、鉴定 vs 测绘、采信 vs 出具、撤销 vs 更正、仅对来样负责 | 替换空词的句子 |
| 常见问题 | 结果兜底；无回避；保证采信；余样风险；排他限制竞争对手检验 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（测绘主轴、无资质诉讼鉴定、应回避仍承揽、约定结论或保证采信、虚假报告、倒签）；
- `必须改`：可谈但签署前要落句（两轨资质附件、回避声明、检材登记、出庭与异议、预审止损、程序违法后果）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级金额或个人无限连带且用户拒绝升级：停止“可以签署”建议。
