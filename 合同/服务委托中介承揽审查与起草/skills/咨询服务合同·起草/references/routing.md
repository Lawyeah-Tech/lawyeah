# 边界与路由

本技能只审查 **服务合同 / 咨询服务合同** 的待签商务咨询文本。中文展示名是「审查咨询服务合同（服务合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 特定技术项目可行性、技术预测、工艺评价、FTO、专利技术尽调 | `或`；文本落在委托技术咨询目录下则 `委托技术咨询·审查` |
| 处理事务、对外代理、授权签约、代收代付为主轴 | `一般委托合同·审查` |
| 广告创意、文案、视觉方案 | `广告设计合同·审查` |
| 广告成片、喷绘实物或其他广告成品制作 | `广告制作合同·审查` |
| 广告发布、代理、代言或广义广告主文件 | `广告发布合同·审查` / `广告代理合同·审查` / `广告代言服务类合同·审查` / `广告合同（广义）·审查` |
| 工程咨询（投资）、造价、招标代理、全过程工程咨询 | `只出可行性造价或管理咨询意见不交付测绘测试成果→`。P1：专业版未装则 `unavailable`，提示，不得用本技能硬套 |
| 可运行软件、系统上线、源代码交付 | `可运行软件或系统交付→` |
| 报酬完全绑在促成签约 | 对应中介原子或回引擎重新定性；本任务不按咨询改完 |
| 法律顾问意见、审计报告为主给付 | 回引擎重新定性，不按本类型放行 |
| 无文本、本类型条件已谈妥、要出己方稿 | 留本任务起草并自审 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

商务咨询正文里夹带一小段技术可行性或广告物料：专章交接对应原子；咨询意见条款可继续审。用户坚持本技能把技术咨询、委托授权或广告设计制作整案改完：`目标停止`。
