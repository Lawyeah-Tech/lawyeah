# 审查方法（锁定 服务合同 / 咨询服务合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制买卖、施工或劳动合同 method。

定性校验：标题、核心给付与本类型一致才继续；技术咨询、委托事务、广告设计制作或他类明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、保证节约或唯一必得金额。

`search_law` 返回已失效《合同法》及其解释、已失效《技术合同法》及其实施条例、已失效《工程咨询单位资格认定办法》时记为噪声，不得写入 `L#`。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。浙江省建设工程咨询服务合同示范文本只证明工程咨询是另一类型，不得当作本类型范本。

知识库纠正（不回写双文件）：

- `基本面.md` “通常参照适用委托合同”：无名服务合同先适用合同编通则（第 467 条），是否参照委托须看核心给付是否处理事务或对外代理。不得默认写入第 933 条任意解除并放行。授权对外签约或拨付款的，负触发 `一般委托合同·审查`。
- `基本面.md` “管理咨询一般无法定行政许可”：证券投资咨询须经证监会核准（证券法第一百六十条）；工程咨询走备案范围一致（工程咨询行业管理办法第九条）且整案转 `只出可行性造价或管理咨询意见不交付测绘测试成果→`。不得引用已失效资格证书口径。
- `框架.md` “异议期 10–15 个工作日”：实务建议，不是法源；可作修改句备选天数，须标 `【待填】` 或经用户确认。
- `框架.md` “成功费须客观可核验”：采纳过程标准（按期验收）；禁止把融资交割、中标、节约额写成成功事件。
- 著作权民事解释第十二条仍写“著作权法第十七条”：2020 修正委托作品为第十九条。运行时引用第十九条，解释第十二条只借“特定目的范围内使用”的争点，不把旧条号写入 `L#`。

| 劳动/工程/金融/股权/家事**已成争** | 对应领域整案转出 | 用本任务做争议评估 |

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 商务信息收集、行业/市场/管理/战略意见，供内部决策参考 | 本类型 | 正触发 |
| 以技术知识就**特定技术项目**做可行性论证、技术预测、专题技术调查、分析评价报告 | 技术咨询合同 | 负触发 `或`；标题写成委托技术咨询则 `委托技术咨询·审查` |
| 处理事务、对外代理、授权签约、代收代付 | 一般委托合同 | 负触发 `一般委托合同·审查` |
| 广告创意、文案、视觉方案或广告成品（成片、喷绘） | 广告设计 / 广告制作 | 负触发 `广告设计合同·审查` / `广告制作合同·审查` |
| 工程可行性、造价、招标代理、全过程工程咨询 | 建设工程咨询服务合同 | 负触发 `只出可行性造价或管理咨询意见不交付测绘测试成果→`（P1；未装则 `unavailable`） |
| 可运行软件、系统上线、源代码交付为主给付 | 软件委托开发 | 负触发 `可运行软件或系统交付→` |
| 报酬完全绑在促成签约或报告交易机会 | 中介 | 负触发引擎或对应中介原子；本任务不按咨询改完 |
| 以通过验收的物化成果为对价、几乎不谈意见过程 | 可能滑向承揽 | 标 `C#`；仍以意见为主可留本任务并提示第 787 条争点；物化工程/广告/软件为主则负触发 |

支持切开的规范（法律结论须运行时复核）：

- 第 878 条：技术咨询是就**特定技术项目**提供可行性论证、技术预测、专题技术调查、分析评价报告。商务管理咨询不是技术咨询专章。
- 第 881 条第 3 款：技术咨询下，委托人按符合约定的咨询报告决策造成的损失原则上由委托人承担。本类型可约定同类决策自负，但不得把第 881 条直接写成“商务咨询已有法定免责”。
- 第 919、922、923、933 条：委托是处理事务；受托人按指示亲自处理；双方可随时解除。本类型不得默认套用。
- 第 961、964 条：中介以报告机会或媒介为给付；未促成不得请求报酬。
- 广告法第三十条：广告活动应订立书面合同。出现广告设计/制作主给付，转广告原子，不在本任务展开广告合规整案。

### 1.2 加载协议（硬闸）

本技能已锁定 **服务合同 / 咨询服务合同**。只打开 `references/基本面.md` 与 `references/框架.md`。禁止读其他子目录，禁止为对照再开第二类。

### 1.3 违法结构停笔

加载后或定性中出现：以咨询为名提供内幕信息、商业贿赂方案、虚假上市或骗贷材料；顾问承诺用“关系资源”疏通机关；要求顾问在报告中作虚假陈述。

动作：

1. 交付告知：该结构可能因违法或违背公序良俗无效（第 153、154 条），不得改写成可履行文本。
2. 不写可履行的疏通路径、虚假陈述口径或资金体外循环。
3. 风险表只保留识别依据和转出/删除提示。
4. 用户坚持“改到能签且仍做这些事”：整体停止。

## 节点 2　主体、资质夹带与权限边界

### 2.1 主体表

建表：签约名、履行名、付款名、发票名、授权签字人。名称不一致不自动合并。集团采购、下属使用的，修改句把使用主体列为享受服务的关联方或加入确认，不编造主体。

口头“我们老板同意了”不得写成已授权。国资、上市公司内部决议或采购程序未附：该签署能力字段停止，不写成“可以盖章”。

### 2.2 资质夹带

管理咨询、行业研究本身一般无法定行政许可。出现下列夹带，不得按普通商务咨询放行：

| 夹带内容 | 动作 |
| --- | --- |
| 证券投资顾问、荐股、为证券交易提供咨询 | 标红旗。证券法第一百六十条：从事证券投资咨询服务业务应当经国务院证券监督管理机构核准。无核准痕迹：不得写成已可开展；建议剥离或停止该部分 |
| 律师法律意见、会计师审计意见 | 标必须持有相应执业资格；否则合同目的可能落空。本任务不审法律顾问或审计合同 |
| 工程咨询（投资）、造价、招标代理 | 负触发 `只出可行性造价或管理咨询意见不交付测绘测试成果→`。现行规则是备案专业与服务范围一致（工程咨询行业管理办法第九条），不是已失效的资格证书 |

个人顾问以工作室签约：标劳动关系伪装与税务风险，不在本任务认定已成立劳动关系。外籍顾问跨境：外汇与常设机构字段停止。

### 2.3 权限不得替代决策或拨付款（硬闸）

咨询意见是建议，不是决策本身，也不是资金指令。

| 文本写法 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 顾问有权代表接受方对外签约、盖章或发出要约 | 负触发委托，或必须改：删除对外代理；意见仅供内部决策 | 已有合法代理权 |
| 顾问有权决定预算、批准付款、指令财务拨付、代管账户 | 红线删除。付款义务主体必须是接受方自己的有权机关 | 顾问可以代付款 |
| 顾问意见视为董事会/股东会决议，或“顾问确认后甲方必须执行” | 必须改：接受方独立决策，顾问不替代内部治理 | 已经完成内部决议 |
| 顾问可在紧急情况下自行变更范围并追加费用 | 必须改：变更须书面；紧急情况也不得自行拨付款 | 已授权 |

最强反方：接受方主张顾问已构成委托或职务代理，对外行为约束本公司。修改句必须把代理、付款和决策权收回接受方。

## 节点 3　成果性质、范围与数据

### 3.1 成果是咨询意见（硬闸）

支持依据：第 467 条（无名合同适用通则并可参照最相类似合同）；第 509 条全面履行。本类型核心给付是意见输出。

审查清单，缺一项则该字段不得写成已闭环：

1. 议题、行业、地域、时间范围、数据截止日。
2. 交付物名称、模块或页数量级、语言、格式（Word/PPT/底稿）。
3. 使用目的：仅供接受方内部决策。未经书面同意不得对外披露为“独立意见”，不得用于监管申报、证券发行或诉讼鉴定。
4. 禁止只写“提供常年管理咨询”而无 SOW。

出现工程实体、施工图、可上线软件、广告作品为主给付：回到节点 1 负触发，不在本节点改成“咨询+交付物”。

### 3.2 不得保证固定节约或固定回报（硬闸）

| 文本写法 | 动作 |
| --- | --- |
| 保证融资成功、估值、中标、并购交割 | 红线；改成过程义务（按期提交符合 SOW 的意见） |
| 保证节约固定金额、成本下降 X%、利润或 ROI 固定数字 | 红线删除保证；可保留“测算假设与敏感性分析”作为报告模块，测算数字用 `【待填】`，并写明不构成业绩承诺 |
| 报酬或成功费完全取决于上述结果 | 现有依据支持滑向中介或结果承揽；必须改成功标准，或负触发中介/他类 |
| 鉴于条款写“保证提升业绩” | 首部必须改；鉴于不得充当承诺 |

顾问立场：删除结果保证，降低结果之债。接受方立场：若商业上要绑定激励，只能附加、且成功事件必须是报告按期验收等客观过程事件，不得绑融资或节约额。

### 3.3 数据来源与知识产权预告

客户提供数据不实导致结论错误：修改句排除顾问责任，但顾问对伪造样本、隐瞒明显矛盾负责任。顾问自行采集的，须标来源可溯。

未约定时，报告作为委托创作作品，著作权一般归受托人（著作权法（2020 修正）第十九条）。接受方需独占使用、二次分发或署名控制：必须书面约定归属或许可范围。解释第十二条“特定目的范围内使用”只作争点提示。顾问保留方法论和通用模板。

涉及国家秘密、未公开内幕信息、批量个人信息：须有合法基础，否则成果不能合法交付。个人信息具体条号运行时核验，本节点不把记忆条号写成 `L#`。

## 节点 4　程序、协助与验收

1. 启动日、资料清单、对接人。客户逾期不提供资料：工期顺延，顾问不承担该延误。
2. 阶段汇报、中期稿确认。重大方向调整须书面变更，否则按原范围验收。
3. 验收标准写“结构符合 SOW、引用可溯源、已按书面意见修改”。禁止单独以“甲方满意”“甲方最终决策”为唯一标准。
4. 异议期须有天数和书面异议形式。逾期未提书面具体不符点，可约定视为通过，作为付款条件。天数用 `【待填】`，框架的 10–15 个工作日只是备选。
5. “无偿修改直至满意，否则不付尾款”：必须改。不满意须指出与 SOW 不符的具体项；超出约定轮次按人天另计。
6. 批准、招标、内部决议写成生效条件或双方义务期限，不写成已经完成。用户要求倒签或补假批准：整体停止。

## 节点 5　对价、定金与成功费

1. 咨询报酬、差旅、数据库、问卷激励分列。未给出的数字写 `【待填】`。预付款性质写明为服务费；除非确需定金罚则。
2. 定金：必须使用“定金”二字才讨论罚则。“订金、保证金”无定金性质约定的，不得写成定金。约定或推算超过主合同标的额百分之二十：超过部分不产生定金效力（第 586 条）。无核验引文不得把 20% 写成现行法结论。
3. 成功费只能作为附加。成功事件禁止绑融资、并购交割、中标、固定节约额。
4. 禁止编造单价、总价、人天。
5. 退出：约定通知期、已完成阶段按进度付款、已发生差旅据实结算、预期利益或固定解约金公式。禁止只写“双方协商解除”而无清理。不得把第 933 条任意解除直接写成双方已有的法定权利，除非节点 1 已认定构成委托并已转出。

## 节点 6　责任限额、格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 责任限额与除外（硬闸）

咨询失误的赔偿可约定上限（如已收费用的【待填】倍）。间接损失、预期利润可排除。

下列不得排除，排除则必须改或标红线：

- 造成对方人身损害；
- 因故意或者重大过失造成对方财产损失（第 506 条）；
- 侵犯知识产权；
- 泄露商业秘密或违反保密约定。

“顾问对报告使用后果不承担任何责任”且无除外：必须改。可写：接受方按符合约定的咨询意见自行决策的商业后果原则上自行承担，但顾问存在故意、重大过失、虚假陈述、侵权或泄密的除外。不得把技术咨询第 881 条第 3 款写成商务咨询的法定免责。

最强反方：限额过低或排除主要权利，相对方可主张格式条款无效（第 497 条）或不成为合同内容（第 496 条）。

### 6.2 格式条款

为重复使用而预先拟定、订立时未与对方协商。从事经营活动的一方不得仅以“这次没用过第二次”否认。依据示范文本制作，不当然排除格式条款。

审查：免责、限责、排除对方权利、管辖/仲裁、自动续期、单方调价等异常条款是否有足以引起注意的标识，以及是否按要求说明（第 496 条；解释第 10 条）。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在附件 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

提供方对其已尽提示或说明承担举证责任。

### 6.3 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的、是否仅行政管理、是否只规制履行行为（第 153 条；解释第 16 条）。禁止用已失效“效力性/管理性”口诀代替解释第 16 条。内幕、贿赂、虚假陈述结构：不改写成有效履行。

## 节点 7　配套：违约、解除、利益冲突、争议

1. 逾期交付按日计违约金；成果实质性不符合 SOW 的，应修改或减少报酬，再不能实现目的的可解除并退还未履行部分费用。接受方逾期付款的，顾问可中止后续工作。只有“依法承担违约责任”视为必须改。
2. 构成违约不等于当然解除。法定解除路径只点名催告或目的不能实现，不在本任务作出已解除结论。违约金不是必得金额；不在本任务做第 585 条精算。修改句避免“不得调整”或“按总价 30% 必得”。
3. 利益冲突：披露现有冲突；项目期内不得为直接竞争方就同一议题提供对立咨询。回避期限须合理、有范围，禁止无限捆绑“独家顾问”。
4. 核心访谈和报告撰写原则上亲自完成；辅助数据整理可分包但顾问对成果负责。未经同意更换核心人员：接受方可要求更换或解除。
5. 争议解决：出现仲裁条款，不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核，修改句改成单一仲裁机构或单一法院连结点。专属管辖可能：只标红旗，不选定唯一法院充作法律意见。
6. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

打开已加载的 `框架.md`，按六步逐段对照正文。`基本面.md` 用于校验类型、主体、成果性质、权限和红旗，不代替本节点出句。

| 步 | 动作 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题用商务咨询或专项名称，不用技术咨询/法律顾问/广告设计混称；主体全称；鉴于不写保证业绩或融资成功 | 标题或主体修改句 |
| 交易条款 | SOW 可验收；成果仅供内部决策；禁止固定节约/回报；权限不含签约或拨付款；费用与节点 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 责任限额与除外；违约可执行后果；解除补偿公式；知识产权；保密；利益冲突 | 可执行后果句或删除句 |
| 尾部 | 签署权限、预付款到账是否生效、附件清单（SOW、资料清单、人员名单、报价） | 生效与附件修改句 |
| 语言 | 正说加反说；盯死尽力/专业标准、独家顾问、报酬 vs 费用、成功费 | 替换空词的句子 |
| 常见问题 | 无 SOW；验收绝对满意；结果保证；代决策/代付款；限额排除故意重大过失 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（成果不是意见、固定回报保证拒删、代决策/代付款权限拒删、违法结构、倒签）；
- `必须改`：可谈但签署前要落句（限额除外、SOW、验收标准、使用目的）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级金额或个人无限连带且用户拒绝升级：停止“可以签署”建议。
