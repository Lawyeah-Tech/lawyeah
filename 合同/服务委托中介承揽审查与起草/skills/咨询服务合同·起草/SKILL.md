# 咨询服务合同·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、已失效《技术合同法》及其实施条例、已失效《工程咨询单位资格认定办法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只起草 **服务合同 / 咨询服务合同** 的待签商务咨询文本，按已谈妥条件出己方稿，输出可编辑草稿、未决项；出稿后必须用本类型硬闸自审，输出风险表和修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文名必须是「审查咨询服务合同（服务合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、待签文本签前审查、履约交底、争议文书、有效性保证、工程/软件/广告成果交付安排。

## 本类型硬闸

1. **成果是咨询意见**：交付物是调研报告、行业分析、战略方案、管理建议等意见。出现工程实体、施工图、可上线软件、广告成片或设计作品为主给付 → 负触发，不按本类型改完。
2. **不得保证固定节约或固定回报**：保证融资成功、估值、中标、节约固定金额、固定收益或投资回报 → 红线删除或改成客观可核验的过程标准（如按期提交符合 SOW 的报告）。
3. **权限不得替代委托人决策或拨付款**：顾问不得对外签约、不得代董事会/股东会作决定、不得代为拨付资金或发出付款指令。出现上述授权 → 必须改或负触发委托合同。
4. **责任限额与除外**：咨询失误可约定上限（如已收费用倍数）；人身损害、故意或重大过失、侵犯知识产权、泄露秘密不得排除。排除上述除外的限额条款必须改。
5. **技术咨询合同、委托合同、广告设计制作负触发**，分别转对应场景原子，不填本类型十节实体结论。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签商务咨询正文，尚未签署，尚未成争，核心给付是咨询劳务过程及约定意见成果，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 特定技术项目可行性、技术预测、工艺评价、FTO 或专利尽调 → `或` 或 `委托技术咨询·审查`；
- 处理事务、对外代理、授权签约或代为拨付款为主轴 → `一般委托合同·审查`；
- 广告创意/设计稿或广告成品制作 → `广告设计合同·审查` / `广告制作合同·审查`；
- 工程咨询（投资）、全过程工程咨询 → `只出可行性造价或管理咨询意见不交付测绘测试成果→`（P1；专业版未装则 `unavailable`）；
- 可运行软件或系统交付 → `可运行软件或系统交付→`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

以咨询为名提供内幕信息、商业贿赂、虚假上市或骗贷材料：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及附件/SOW 版本；咨询议题与交付物形态；是否保证节约或回报；是否含对外签约或拨付款权限；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的费用、页数、人天用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验无名合同参照、技术咨询与委托切开、格式条款、定金上限、免责除外、著作权归属；`search_practiced` 只补审查反例；`search_template` 只借栏目结构。不虚构案件系统。

`search_law` 对上述法律结论为 required 级：不可用时不拒绝执行，只停止效力字段。返回已失效《合同法》或其解释、已失效《技术合同法》或其实施条例、已失效工程咨询资格认定办法时记为噪声，不得写入 `L#`。


## 起草模式

本原子只承担本类型起草。待签评改转 `咨询服务合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `咨询服务合同·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 交付物写成调研报告、行业分析、战略方案、管理建议等咨询意见；使用目的仅供接受方内部决策，未经书面同意不得对外披露为独立意见。
- 议题、行业、地域、时间范围、数据截止日、交付物名称与格式写入正文或 SOW；验收写成结构符合 SOW、引用可溯源、已按书面意见修改，不得以“甲方满意”为唯一标准。
- 权限收回：顾问不得对外签约、不得代董事会／股东会作决定、不得代为拨付资金或发出付款指令。
- 咨询失误可约定赔偿上限（如已收费用【待填】倍）；人身损害、故意或重大过失、侵犯知识产权、泄露秘密不得排除。
- 预付款写明为服务费；成功费若保留，只能绑报告按期验收等客观过程事件。

### 附件必附

- SOW、资料清单、人员名单、报价明细、保密清单。缺则正文列缺口并用 `【待填】`，不得假装已齐。附件与正文冲突时以 SOW 的范围和验收为准。

### 禁止出现

- 工程实体、施工图、可上线软件、广告成片或设计作品作为主给付。
- 保证融资成功、估值、中标、节约固定金额、固定收益或投资回报。
- 顾问确认后甲方必须执行，或顾问可自行变更范围并追加费用。
- 限额排除人身损害、故意或重大过失、侵权或泄密。
- 以内幕信息、商业贿赂、虚假上市或骗贷材料为内容的可履行结构。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`基本面.md` 中“通常参照适用委托合同”不得当成已构成委托或已有任意解除权。`框架.md` 中“10–15 个工作日异议期”是实务建议，不是法源。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 留本任务起草并自审；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有商务咨询文本；本任务只起草，评改待签文本转配对 ·审查 原子。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。技术咨询、委托、广告设计制作负触发。

### 2. 主体、资质夹带与权限

签约名、履行名、付款名、发票名分列。夹带证券投资顾问、法律或审计意见须有相应核准或执业资格。权限不得含代决策或拨付款。

### 3. 成果性质与范围

咨询意见可验收；禁止固定节约或固定回报；客户数据与顾问采集分责。

### 4. 程序与验收

资料逾期顺延；变更书面化；验收不得以“甲方满意”为唯一标准。

### 5. 对价与定金

预付款写明服务费；成功费不得绑融资或节约金额；定金不得超过标的额百分之二十。

### 6. 责任限额、格式条款与强制规范

限额可谈，除外必须保留。无核验引文则法律结论字段停止。

### 7. 知识产权、解除与争议

未约定则报告著作权一般归受托人。解除补偿公式写明。不选定唯一法院充作意见。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把内幕/贿赂/虚假材料改成可履行结构、坚持保留固定回报保证或代决策/代付款权限。
- `字段停止`：法域、动态规则、资质备案、采购审批未核验。
- `目标停止`：主目标已变为评改待签文本、履约交底、争议文书，或已锁他类。
