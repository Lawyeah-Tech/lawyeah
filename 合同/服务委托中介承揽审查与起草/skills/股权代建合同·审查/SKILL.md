# 股权代建合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、1990 年《关于审理联营合同纠纷案件若干问题的解答》、已被修改的《公司法》1993/2018 同条号当作现行规则。不得把“劳务或品牌管理折价计入注册资本”“持股低于百分之十即当然是股权代建”“项目所在地法院必然专属管辖”“固定价格退股一定有效”写成现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **委托合同 / 股权代建合同** 的待签文本：核心给付必须同时具备 **小额股权安排** 与 **代建操盘委托**。输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文名必须是「审查股权代建合同（委托合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查、从零起草、履约交底、争议文书、效力或工商变更保证、把本约改成共担共享的合作开发、把本约改成纯股权转让或纯增资、把本约改成无股权的商业/政府/资本代建、把固定回购改成可履行的抽逃或明股实债、把劳务/品牌/管理服务折价写入注册资本。

## 工作边界

正触发：已有可读待签文本要评改，；尚未签署，尚未成争；核心给付是 **股权安排 + 代建服务**——代建方（或指定主体）以增资或受让取得项目公司通常为少数股权，**同时**受托处理定位、设计、工程、采购、营销或交付等开发管理事务并收取代建报酬。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 无股权安排，只有代建收费、品牌输出或项目管理授权 → `房地产委托代建合同·审查` 或 `商业代建合同·审查`；土地使用权项下纯委托代建 → `或`；
- 政府投资非经营性代建、无营销或弱营销 → `政府代建合同·审查`；
- 资本主导不良资产盘活、代建方不以小股操盘绑定 → `资本代建合同·审查`；
- 代建文本捆绑出借或配资，资金借贷是主结构 → `商业代建配资·审查`；
- 各方以土地、资金等共同投资，共享利润、共担风险，代建方自负盈亏或持股达到控制/对等合作 → `房地产合作开发联合拿地`；
- 主文件是股权转让，无代建操盘服务 → `主文件是股权转让，无代建操盘服务→`；股权投资条线下的转让本约 → `或`；
- 仅增资扩股、无代建管理协议或操盘授权 → `仅增资扩股无代建管理协议或操盘授权→`；
- 无文本、本类型条件已谈妥、要出己方稿 → `股权代建合同·起草`；
- 已签只问工商变更、用印交接、节点付款 → 本套导航的履约步骤；
- 已成争（催告解除、抽逃出资之诉、股东代表诉讼、代建费索赔、立案仲裁）→ 合同争议或对应专项领域。

挂靠、违法分包、出借资质、规避限购或国资进场：只出告知，不改写成可履行结构。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成。每一闸必须给出修改句或明确转出口径，禁止只打红黄绿。

1. **股权安排 vs 代建服务必须分账分权**。本类型是双重法律关系，不是单一委托，也不是单一投资。股权关系走《公司法》：出资、股东名册/工商变更、分红、表决、知情、减资或股东间转让退出。管理关系走《民法典》委托合同编：指示、报告、亲自处理或转委托、代建报酬、过错赔偿、任意解除的限制与赔偿。修改句必须分列：①代建基础管理费、品牌费、KPI 奖金的计取基数、节点、发票和是否可抵注册资本（默认不可抵）；②税后可分配利润项下的分红，须先弥补亏损并提取公积金。禁止把“分红”写成“代建报酬”，禁止把代建费写成“抽回出资”或“固定分红”。无代建服务、只持股 → 负触发转让或增资原子。无股权、只收费操盘 → 负触发商业/委托代建原子。
2. **与合作开发切开**。解释（2020 修正）第十二条：合作开发以共同投资、共享利润、共担风险为基本内容。出现代建方自负盈亏、吃剩余利润、对等或控股持股、双方均以土地/资金共同投资且共担亏损 → 负触发 `房地产合作开发联合拿地`。禁止打开或复制该原子 method，禁止把本约改成可履行的共担共享结构来“补全体系”。知识库主合同清单里的《合作开发框架协议》只是常见标题，不决定类型。
3. **与转股/纯增资切开**。主文件是《股权转让合同》或《增资协议》，正文没有代建范围、操盘授权、管理费和品牌使用 → 负触发 `主文件是股权转让，无代建操盘服务→` / `或` 或 `仅增资扩股无代建管理协议或操盘授权→`。禁止打开或复制其 method，禁止把本任务做成对价、交割、陈述保证、优先购买权专项换皮。本技能只审：入股是代建绑定的一部分，还是另做的财务投资；工商变更与章程修正是否服务操盘。
4. **禁止抄商业代建或股权转让**。禁止输出无股权结构的纯代建工期、进度款、监理、竣工验收主路径。禁止输出无代建服务的对价调整、或有对价、竞业、完整交割条件清单作为主路径。代建工期、验收只作为委托事务完成标准出现，且必须回链操盘授权和费用，不得写成施工总承包或纯买卖股权。
5. **明股实债与抽逃出资**。约定代建方到期按固定价格退股、固定收益、不挂钩经营盈亏，或项目公司/大股东“无论盈亏保证回购本金加固定溢价”：红旗。解释（2020 修正）第二十三条：不承担经营风险、只收取固定货币的，应认定为借款合同；公司法第五十三条禁止抽逃出资；减资须走第二百二十四条通知债权人程序。修改句把退出改成：①大股东或其他股东按届时评估或约定公式受让（不是项目公司违法回购）；或②依法减资；③收益与项目可分配利润挂钩。用户坚持固定保本保收益且不担风险：不得化妆成股权代建放行；明显无代建服务则负触发 `用户坚持固定保本保收益且不担风险：不得化妆成股权代建放行；明显无代建服务则负触发`。
6. **劳务、品牌、管理服务不得计入注册资本**。市场主体登记管理条例第十三条：不得以劳务、信用、自然人姓名、商誉、特许经营权或设定担保的财产作价出资。原文“乙方以品牌授权及管理服务折价入股/劳务出资”：红线。修改句改为：股权对价用货币或依法可估价可转让的非货币财产；品牌授权与管理服务只作为代建服务对价，计入管理费，不计入注册资本。知识库“改为折价入股”的口径以本闸为准，不回写知识正文。

附加必落句（有事实则单列，无事实在缺口节说明）：

- **合同组交叉引用**：主协议锁定“股权绑定 + 委托操盘”；《代建管理协议》《股权转让/增资协议》《股东协议》《章程修正案》互相引用，不得各说各话。
- **章程落地同股不同权**：合同写小股多数表决或一票否决的，必须写入章程并列举事项（预算外开支、供应商选定、融资、担保、资产处置、品牌使用）。只写在代建合同、不改章程：必须改。
- **印章与资金共管**：公章、财务章、证照不得写成代建方单方永久占有；改为共管或分章、用印清单、越权用印无效并赔偿。资金按批准预算经共管账户拨付。
- **任意解除与强制退出**：民法典第九百三十三条允许随时解除委托，但有偿委托须赔偿直接损失和履行后可得利益。修改句限制无正当理由解除操盘，并单列严重失职时大股东按约定公式回购并解除代建。不得写“放弃任意解除权且违约也不赔”。
- **债务隔离**：代建方作为小股东仅以认缴出资为限对项目公司承担责任；不得为委托方或项目公司融资提供连带保证，除非另走公司担保决议并升级。
- **国资与债权人**：委托方或项目公司含国有股东的，入股/增资/转让按企业国有资产交易规则评估、进场或取得豁免文件，未闭合则字段停止。开发贷或信托文件限制股权变更的，修改句把债权人书面同意作成生效或交割条件。

必须有修改句。每个风险回链文本位置。禁止套用商业代建的无股权工期主路径。禁止套用股权转让的交割保证主路径。禁止复制 `商业代建合同·审查`、`主文件是股权转让，无代建操盘服务→`、`房地产合作开发联合拿地` method。

## 建立审查坐标

确认：使用者与授权；单方立场（委托方/原控股股东、代建方/小股操盘手、项目公司、拟派驻董事或财务负责人）；相对方；全文及股权/增资、代建、股东协议、章程修正案、授权手册版本；持股比例与取得方式；代建范围；管理费与分红是否分列；退出与回购主体；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口，不代替节点。

0. 签署状态与成果分流
1. 类型识别与单目录加载（股权 + 代建同时成立；切开合作开发 / 转股 / 商业代建）
2. 主体、资质、国资、债权人同意、隐名股东
3. 股权安排与代建服务分账分权
4. 出资合法性、劳务出资、固定回购与抽逃
5. 章程、表决权、印章资金共管、关联交易
6. 报酬、报告、转委托、任意解除
7. 退出、僵局、债务隔离
8. 按框架六步出修改句

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签或假工商、把劳务折价入股、把固定保本改成项目公司违法减资或抽逃、把挂靠/出借资质改成可履行、保证一定办成变更登记或一定有效。
- `字段停止`：法域未核验；持股取得方式无法识别；国资进场或债权人同意未闭合；章程与合同表决权冲突无法判断以谁为准；是否完成出资无法识别。
- `目标停止`：主目标已变为从零起草、履约交底、股东诉讼文书，或用户要把本约改成合作开发/纯转股/纯商业代建以便走他类履行结构。

代建方母公司被要求为项目全部债务连带担保且用户拒绝升级：停止“可以签署”建议。
