# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证合同有效、工商变更必然办成或对方接受；编造未给出的持股比例、出资金额、管理费率、回购公式、期限；把已失效《合同法》及其解释或 1990 年联营解答写入结论；把劳务/品牌/管理服务写成可计入注册资本；把固定保本回购写成合法抽回出资；把本约改成共担共享的合作开发或无代建的纯转股；把无股权的商业代建或无代建的股权转让留在本技能改完。

## 1. 触发、单方立场与成果状态

立场（委托方/原控股股东、代建方/小股操盘手、项目公司、拟派驻高管）、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明是否同时存在股权安排和代建操盘委托，以及持股拟取得方式（增资或受让）。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、1990 年联营解答、旧公司法同条号时记噪声，不得写入 `L#`。委托与任意解除、出资禁止、抽逃与减资、利润分配、合作开发名实、国资交易无 `verified-result` 时，对应法律结论字段停止。

## 3. 类型与加载路径

父级 `委托合同`，子级 `股权代建合同`。定性理由必须同时满足：项目公司股权安排；代建操盘委托。易混切开：无股权商业/政府/资本代建、合作开发、纯股权转让、纯增资、名实借贷、代建加配资。

加载路径必须写成：`references/基本面.md` 与 `references/框架.md`（本场景已锁定）。写明只读这一对、未通读其他类型、未打开 `商业代建合同·审查`、`主文件是股权转让，无代建操盘服务→` 或 `房地产合作开发联合拿地` method。挂靠、出借资质、假出资或规避国资进场写停笔告知，不填可履行结构。

## 4. 主体、授权、资质与文本版本

主体表：委托方/原控股股东、代建方/小股操盘手、项目公司、拟派驻董事或财务、其他股东、保证人（如有）。法人写名称与统一社会信用代码。

版本表：主协议、代建管理协议、股权转让或增资协议、股东协议、章程及修正案、授权手册、国资/债权人文件、聊天确认。冲突并列，不选对用户有利的一版。口头“已经变更了”“其他股东同意了”不得写成已登记或已放弃优先购买。

## 5. 股权安排与代建给付闭环

分列并回链文本位置：

- 股权：取得方式（增资/受让）、比例、对价、出资形式、实缴期限、股东名册与登记义务。
- 名实：鉴于是否锁定“入股为代建绑定、代建为委托事务”；合同组是否交叉引用。
- 代建：范围、授权、亲自处理/转委托、报告频率、完成标准。
- 对价分账：管理费/品牌费/KPI 奖金 vs 税后分红；发票与是否允许抵注册资本（默认否）。
- 治理：董事席位、一票否决清单、是否写入章程。
- 控制：印章证照共管、资金预算与共管账户、关联交易决议。
- 退出：回购或减资主体、定价公式、工商配合、逾期违约金。
- 解除：任意解除赔偿与严重失职强制退出是否分列。
- 隔离：代建方是否被要求为融资连带担保。
- 外部条件：国资评估进场、债权人同意、开发资质。

缺口标 `G#`，不补商业数字或已完成变更事实。批准、登记、进场写成条件或双方义务期限，不写成已经完成。

## 6. 格式条款、强制规范与本类型效力红旗

重复使用且未协商的代建方模板，按格式条款审查提示说明。

强制规范与效力红旗只在核验后落法律结论：劳务/商誉出资；抽逃出资与违法减资；挂靠或未取得开发资质从事开发经营；规避国资进场；虚假意思表示掩盖借贷或转让。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

不得把“整组合同因标题写合作开发而无效”或“持股低于百分之十即当然有效”写成已核验结论。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔/转出口径。禁止输出无修改句的色块表。

本类型至少检查：股权与代建只具一翼；分红与管理费混同；劳务或品牌折价入股；项目公司固定价格回购或保本收益；未写入章程的一票否决；印章单方占有；无僵局条款；无债权人/国资条件；把本约写成共担共享或纯转股。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`，不编造。禁止只给原则、不给句子。框架与硬闸冲突时按硬闸出句。

建议句必须覆盖本类型硬闸：鉴于锁定股权绑定 + 委托操盘；管理费与分红分列；删除劳务折价入股；删除项目公司违法回购或改为股东受让/依法减资；章程落地表决权；任意解除赔偿。

## 9. 谈判与签署提醒

谈判顺序：先红线（劳务出资、项目公司固定回购、挂靠、伪造变更、保证有效），再必须改（分账分权、章程、共管、退出公式、国资/债权人条件），最后可优化。

签署提醒：合同组与章程同日签；其他股东放弃优先购买或同意增资的书面文件；国资/债权人文件作附件；出资缴付凭证安排；日期真实。不指导倒签工商日或补假评估。

委托方立场必须提示：交出操盘和印章后存在关联交易与控制权被架空的风险。代建方立场必须提示：小股仍可能被大股东通过法定多数事项约束；固定回购可能被认定为借贷或抽逃而不能执行。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、股东诉讼文书、税务筹划终局或效力保证。
