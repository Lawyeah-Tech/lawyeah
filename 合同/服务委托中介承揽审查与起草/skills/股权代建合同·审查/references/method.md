# 审查方法（锁定 委托合同 / 股权代建合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止打开或复制 `商业代建合同·审查`、`主文件是股权转让，无代建操盘服务→`、`房地产合作开发联合拿地` method。禁止套用无股权商业代建的工期、进度款、竣工验收主路径。禁止套用纯股权转让的对价调整、交割条件、完整陈述保证主路径。禁止把本技能写成合作开发、股权转让或商业代建换标题。

定性校验：核心给付同时具备项目公司股权安排与代建操盘委托，才继续；明显他类则负触发，不填十节实体结论。

本文件是可执行判断节点，不是栏目说明书。每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、工商变更必然办成，或唯一必得管理费/分红。

`search_law` 返回已失效《合同法》及其解释、1990 年《关于审理联营合同纠纷案件若干问题的解答》、1993/2005/2018 年《公司法》同条号旧义时记为噪声，不得写入 `L#`。`search_practiced` 仍写“劳务可以折价入股”“固定回购一定有效”“持股低于百分之十即当然股权代建”“年利率 24% 即合法”的，同样记噪声。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

示范文本只参考结构。写成共担亏损的合作开发、劳务/品牌折价入股、或项目公司固定价格回购股权的范本，与本类型硬闸冲突，不得当规则。

知识库口径冲突以本方法为准，不回写知识正文：

- `框架.md` 建议把“劳务出资”改成“以品牌授权及管理服务折价入股”：纠正为品牌与管理服务只能作为代建服务对价；股权对价须用货币或依法可估价并可转让的非货币财产。市场主体登记管理条例第十三条禁止劳务、商誉、特许经营权作价出资。
- `基本面.md` 写“通常小于 10%”：纠正为商业惯例，不是法定定性阈值。比例高低单独不决定类型；自负盈亏、共担共享或取得控制权才切合作开发。
- 主合同清单包含《合作开发框架协议》：纠正为标题不决定类型。实质共担共享则负触发 `房地产合作开发联合拿地`，不得为“体系完整”把本约改成合作开发。
- 建议“由项目所在地法院管辖”因为股东代表诉讼：纠正为股东代表诉讼不是不动产专属管辖的当然理由；管辖条款按约定审查，不选定唯一法院充作法律意见。
- 把项目结束后固定价格退股写成常规退出：纠正为须审查是否构成抽逃出资或明股实债；项目公司违法回购或固定保本不得放行。

## 节点 2　主体、资质、国资、债权人与隐名股东

1. 建主体表：委托方/原控股股东、代建方/小股操盘手、项目公司、拟派驻董事/财务/项目总经理、保证人（如有）。名称不一致不自动合并。角色必须同时标出股东身份和受托人身份。
2. 资质：项目公司从事房地产开发经营的，文本或材料须提及房地产开发资质；未提及不得写成“已具备”。代建方以自己名义报建或销售的，资质字段停止或必须改到以有资质的项目公司名义。
3. 国资：委托方、项目公司或拟出让股权属于国有及国有控股、国有实际控制企业权益的，入股/增资/转让原则上进场并评估。未附批准、评估或进场/豁免文件：该签署能力字段停止，修改句要求作为附件且未获批准不交割。
4. 债权人：开发贷、信托或股东协议限制股权变更或实控人变更的，修改句把书面同意作成交割或生效条件。材料未提及不得写成“无融资限制”。
5. 隐名股东、代持、优先购买权：章程或其他股东同意未闭合则字段停止。口头“其他股东没意见”不得写成已放弃优先购买。
6. 代建方内部跟投若涉及员工持股或非法集资红旗：只标告知，不设计跟投产品。

不足：字段停止，列出待补材料，不补主体、不补已批准、不补已具备资质。

## 节点 3　股权安排与代建服务分账分权（硬闸）

本类型是合同组：股权是绑定和治理工具，代建是委托事务。两套对价必须分列。

核验后可引用的判断点（须 `search_law` 写入 `L#` 再落法律结论）：

- 委托是处理事务；报酬按委托约定支付，垫付费用另还。
- 利润分配须弥补亏损并提取公积金后进行。
- 认定权利义务不拘泥于名称。

| 文本写法 | 本任务动作 |
| --- | --- |
| 只有代建费，没有股权取得方式、比例、对价 | 追问是否漏附件。确认无股权 → 负触发商业/委托代建。确认有股权但未写清 → 必须改 |
| 只有股权比例和对价，没有代建范围、授权、管理费 | 追问。确认无代建 → 负触发转让或增资 |
| “管理费从分红中抵扣/管理费视为抽回出资/管理费计入注册资本” | 红线或必须改。管理费走服务结算和发票；出资保持实缴 |
| 鉴于只写“双方合作开发”或只写“财务投资” | 必须改。鉴于锁定：入股是代建绑定的一部分；代建是委托事务，不是共担共享 |
| 用户要求保留合作开发外壳以便主张剩余利润 | 若实质共担共享 → 负触发 `房地产合作开发联合拿地`。本技能不得改成可履行共担结构 |

反方常见抗辩：有股权就是股东，可拒绝接受委托指示；或只有委托，股权可随时抽回。修改句用章程、股东协议和代建协议交叉约束，不得写成“签了就既能当老板又能随时撤资”。

## 节点 4　出资合法性、固定回购与抽逃（硬闸）

| 文本写法 | 本任务动作 |
| --- | --- |
| “乙方以品牌、管理、劳务折价【待填】万元计入注册资本” | 红线。改为货币或合法非货币财产出资；品牌与管理只计入代建费 |
| “项目结束，项目公司按入股价原价回购乙方股权” | 红线。公司收购本公司股权受限；有限公司违法回购/减资可能构成抽逃。改为其他股东受让，或依法减资并通知债权人 |
| “无论盈亏，甲方保证乙方年化【待填】% 固定收益并回购” | 红旗。收益改为挂钩可分配利润；回购主体改为股东或其他第三方；固定货币且无代建服务 → 考虑 `用户坚持固定保本保收益且不担风险：不得化妆成股权代建放行；明显无代建服务则负触发` |
| 退出估值只写“双方协商”或只写原始入股价、禁止评估 | 必须改。列明触发时点、评估机构选定、净资产/收益法公式、争议时的中立评估 |
| 分期按开盘、封顶解锁股权激励 | 可接受。补解锁条件、未达标是否调减、已登记股权如何回转（股东受让，不是公司直接抹销） |

减资退出必须具备：股东会三分之二以上表决权、编制资产负债表及财产清单、通知债权人并公告。缺一项补一项。不得把“自动注销股权”写成可履行。

---

## 节点 5　章程、表决权、印章资金与关联交易

1. 合同约定与持股比例不一致的表决权、一票否决或董事提名：必须同步写入章程，并列举事项。只写“乙方拥有实质控制权/一票否决”而无清单：必须改。
2. 修改章程、增资减资、合并分立解散：法定三分之二以上表决权不得用普通多数或代建方单方决定架空。可把经营事项（预算内开支、供应商、营销定价）划给董事会或代建授权手册。
3. 印章、证照、U 盾：不得写成代建方单方永久占有。改为共管、用印范围、越权用印的对外效力风险告知（内部约定不能当然对抗善意相对人）及对内赔偿。
4. 资金：共管账户、预算审批、超预算会签。代建方作为受托人和小股东，关联采购必须报告并按公司法第一百八十二条经董事会或股东会决议。
5. 知情权与报告：月度/节点报告、现场检查、审计权。只有“及时沟通”视为必须改。

---

## 节点 6　报酬、转委托、任意解除

1. 代建报酬分列：基础管理费、品牌费、KPI 奖金。计取基数（销售额、成本节约、溢价）用 `【待填】`，不编造。费用预付与垫付走第九百二十一条，不与出资混淆。
2. 转委托：核心操盘（项目总、设计定案、营销定价）原则上亲自处理；专业分包须书面同意并明确选任责任。不得把全部管理转给无资质第三方。
3. 任意解除：承认第九百三十三条，但修改句约定：①无正当理由解除须提前【待填】日通知并赔偿直接损失和可得利益（已发生管理费、品牌投入、达标奖金）；②因代建方严重失职、重大安全事故、严重超期，委托方可解除代建并按约定公式回购股权；③解除代建不等于当然剥夺已合法取得的股权，股权另按退出条款处理。
4. 不得写“双方放弃任意解除权，解除无效”。可以写“解除后的结算和赔偿”。

## 节点 7　退出、僵局、债务隔离

1. 退出路径分列：项目清算后分配、达标后股东回购、违约强制退出、僵局买断/卖出。每条写触发、定价、交割、工商配合义务和逾期违约金。正说必须有反说。
2. 僵局：双方对预算外融资、定价或供应商持续无法形成有效决议超过【待填】日。补强制买断权或指定第三方评估后一方退出，避免“继续友好协商”空转。
3. 债务隔离：代建方母公司不为项目公司或委托方债务提供连带保证；已有担保意向的，提示公司法对外担保决议，并建议升级，不在本任务展开保证整案。
4. 股权质押：是否允许、质权人范围、违约时大股东优先受让是否写入章程。
