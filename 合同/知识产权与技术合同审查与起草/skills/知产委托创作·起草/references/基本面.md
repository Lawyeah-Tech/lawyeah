## **第一步：合同类型（法律性质）分析**

* **法律定性**：委托创作合同是委托人委托受托人创作特定作品，双方就创作要求、成果交付、报酬和**著作权归属**作出约定的合同。本大类审查重心是**作品权属与使用范围**，不是劳务派遣，也不是技术开发。适用《著作权法》（2020修正）第19条、第10条、第29条，《著作权法实施条例》，并受《民法典》合同编（承揽/委托规范可参照）约束。
* **易混淆辨析**：
* **委托创作 vs 承揽**：两者都交付成果。有独创性表达、构成作品的，必须单列著作权条款；只审验收和瑕疵担保、不审权属的，会留下第19条默认规则。
* **委托创作 vs 职务作品**：受托人是委托单位员工、主要利用单位物质技术条件、由单位承担责任的工程设计图等，可能落入职务作品，权属规则不同。签约对象是外部工作室或自然人的，按委托作品审。
* **委托创作 vs 委托开发/技术开发**：本类型交易对象是作品（剧本、文案、摄影、设计、配乐等）的著作权，不是技术方案、专利或技术秘密。即便成果是软件界面美术、宣传片，仍按作品权属写，不按技术成果“使用费+验收指标”写。
* **委托创作 vs 著作权转让/许可**：委托合同解决“将来作品归谁、委托人能用到哪”；转让/许可解决“已有作品财产权如何处分”。先创作后补“买断”的，补签仍受第19条、第29条约束。
* **效力认定**：
* **约定不明或未订立合同的，著作权属于受托人**（《著作权法》第19条）。委托人仅得在**委托创作的特定目的范围内免费使用**，不得推定取得复制、发行、信息网络传播、改编等全部财产权。
* 人身权原则上归作者（通常为受托人侧的创作者）。“著作权全部归委托人、含署名权”中，财产权约定有效，署名权买断通常无效。
* 委托违法内容或侵害第三人在先作品的，合同或相应条款因违法或无权处分出现效力与履行障碍。


## **第二步：合同主体（交易对手）分析**

* **委托人**：真正需要使用作品的主体。集团内A公司签约、B公司使用的，须写入使用主体，否则B公司使用可能构成超范围。
* **受托人**：自然人作者、工作室、公司。公司签署的，须约定实际创作者的职务作品处理，避免公司交稿后作者主张个人著作权。
* **关联主体**：
* **实际作者**：受托人转包、找枪手的，权属须从实际作者接到受托人再接到委托人，缺一环则权属断裂。
* **在先作品权利人**：改编、续写、联名、使用委托人素材或第三人素材时的原权利人。
* **共同委托人**：共同出资委托的，须约定共有份额和对外许可规则。
* **签约能力**：未成年人作者的法定代理；职务创作需单位授权；国资委托大型宣传项目的内部决策。


## **第三步：合同标的（交易对象）分析**

* **标的特定化**：作品类型、主题、篇幅/时长/规格、使用场景（广告投放、图书出版、影视拍摄、包装印刷、信息网络）、交付格式。禁止只写“按甲方要求创作”。
* **权属标的**：写清归委托人的是哪些财产权、是否含改编/续作/角色/标题、地域和期限。未写清的，按第19条归受托人。
* **素材与在先权利**：委托人提供的品牌、肖像、数据、在先作品；受托人自带的模板、字体、图库、音乐。权属条款不能吞掉受托人的通用素材库。
* **可交易性**：创意、思想、风格本身不受保护；保护的是具体表达。要求“不得与市场已有作品相似”须落到抄袭、实质性相似，不能写成保证市场独创第一。


## **第四步：合同程序（交易步骤）分析**

* **创作与交付**：大纲/分镜 → 初稿 → 修改轮次 → 定稿 → 源文件交付。每一节点对应验收和付款，避免“满意为止”无限改稿。
* **权属时点**：约定自交付验收合格（或价款付清）时，约定财产权归委托人。未约定时点且未约定归属的，整条权属落空，适用第19条。
* **登记与备案**：权属归委托人的，由受托人配合办理作品登记，作者栏与著作权人栏分别填写。这是权属对抗和维权举证程序，不是技术验收程序。
* **使用启动**：委托人在权属未约定归己时，仅能在委托目的范围内使用；超目的（如把活动主视觉拿去全球商品化）须另签许可或转让。


## **第五步：交易结构设计（风险规避方案）**

* **权属条款三选一写死**：
* 财产权归委托人，受托人保留人身权；
* 财产权归受托人，委托人取得目的范围内普通或专有许可；
* 共有，并写行使规则。
* **对价**：创作报酬与“权属对价”宜分列，避免只付稿酬却主张买断全球财产权。定金不超过主合同标的额**20%**。
* **修改与人身权**：约定受托人配合修改的次数和期限；必要改动不视为侵犯修改权、保护作品完整权，但歪曲篡改除外。
* **第三人索赔隔离**：受托人保证原创或已获合法授权；委托人保证所供素材合法。各自范围内赔偿。
* **文本形态**：**主合同 + 创作任务书 + 权属与权利清单 + 素材清单 + 作者声明 + 源文件交接单**。


## **第六步：宏观风险预警与尽调指引**

* **高频争议**：口头委托后委托人全网商用，受托人主张权属；权属写“归甲方”但不列权利种类；枪手作者杀出；把委托创作写成技术开发导致验收标准错位。
* **尽调清单**：
* [ ] 受托人是否为实际作者或已取得作者书面权属
* [ ] 有无书面权属条款，是否具体到权利种类和范围
* [ ] 委托人使用场景是否超出委托目的
* [ ] 素材、字体、图库、音乐的授权范围
* [ ] 是否职务作品或合作作品误签成委托
* [ ] 登记证书记载的著作权人与合同是否一致
* **重大风险红旗**：无书面合同却已投放；“版权归甲方所有”一句话；允许无限转包且不追认作者；委托人关联公司全球使用但合同只给单次活动使用权。
