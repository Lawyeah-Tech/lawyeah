# 边界与路由

本技能只审查 **知识产权相关合同 / 合作创作合同** 的待签、两人以上共同创作同一作品并安排共有行使的文本。中文展示名是「审查合作创作合同（知识产权相关合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开 `知产委托创作·审查` 的 method 后换标题交差。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 一方出资一方交稿，无共同创作意图；名称写合作、履行是委托 | `知产委托创作·审查` |
| 用户坚持按委托合同父级审委托创作 | `若用户坚持按委托合同父级审→` |
| 已完成作品财产权让与；转让价金、权利种类、地域范围是主轴 | `著作权转让合同·审查` |
| 已有作品的专有或普通许可使用为主给付 | `著作权许可使用合同·审查` |
| 计算机软件著作权让与、软著登记变更为主给付 | `软件著作权转让合同·审查` |
| 软件分发许可或自用许可为主给付 | `软件许可合同（分发许可模式）·审查` / `软件许可合同（自用许可模式）·审查` |
| 订立时技术方案尚不存在，共同研究开发、专利申请权共有 | `合作开发合同·审查` |
| 个人合伙：共同出资经营、盈亏、入伙退伙，不是作品共有行使 | `合伙经营→` |
| 普通合伙企业协议 | `普通合伙企业协议` |
| 有限合伙企业协议 | `有限合伙企业协议` |
| 电影、电视剧以制作者享有著作权、作者仅署名和获酬为主轴 | 转引擎重新定性；不按第十四条普通共有改完整案 |
| 已有可读待签文本要评改 | `合作创作合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或知产争议专项。` 或对应专项领域 |
| 著作权权属、侵权诉讼或已立案 | 知产或争议专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

合作创作正文里夹带一小段已有作品转让或对外普通许可流程：专章可点名交接 `著作权转让合同·审查` / `著作权许可使用合同·审查`；共有行使条款可继续审。用户坚持本技能把委托创作、技术开发或合伙整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
