# 技术秘密使用许可合同·审查

## 任务目标

在单一立场下，只审查 **技术类合同 / 技术秘密使用许可合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。中文显示名为「技术秘密使用许可合同·审查」。`depends-on` 为空。不要求先跑导航。

主线是**现有、处于保密状态的技术秘密之使用权许可**。许可人保留权属，被许可人在约定范围内使用并付费、保密。不是买断转让，不是专利实施许可，也不是尚待开发。

不交付：他类审查、从零起草、履约交底、争议文书、有效性或秘密永不公开保证、转让／概括许可／专利许可／开发的整份代审。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **许可使用 ≠ 转让**：许可人保留权属，只授权使用。买断、许可人永久停用且不得再处分 → `技术秘密转让合同·审查`。不得删掉买断／停用句后继续当本类型审。
2. **保密义务是生命线**：许可人与被许可人均须承担保密义务。须写秘密范围、载体、接触人员、隔离措施、再披露禁止、期满归还销毁，以及进入公知领域前持续保密。无保密条款不得放行核心资料交付。
3. **与转让 `技术秘密转让合同·审查` 切开**：核心给付滑入权属转移即负触发。不复制转让交割或“许可人停用不再处分”主路径。
4. **技术秘密 ≠ 专利实施许可 ≠ 概括技术许可**：无专利号与权利要求的隐藏工艺／算法／配方才留本任务。专利实施许可 → `专利实施许可合同·审查`。专利与秘密捆成一份未拆分 → `技术许可合同·审查`。尚待开发 → `技术开发合同·审查`。
5. **许可方式与范围可履行**：独占／排他／普通必须落句；地域、领域、生产线、接触人员写清。未约定视为普通许可。期限不明则使用不受期限限制，必须改。
6. **标的须密级附件或载体清单**：禁止只写“有关专有技术”。分段披露；验证期未达标可退还资料并退还已付费用。
7. **非法垄断与进出口**：无偿独占回授、禁止质疑有效性、禁止从他源获得竞争技术红线删除。限制进出口或国家秘密未批：履行字段停止，禁止先披露后补证。

## 工作边界

正触发：已有可读待签正文或可单独评改的技术秘密使用许可专章，尚未签署，尚未成争；标的是现有技术秘密；核心给付是保留权属下的使用授权。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 权属买断、许可人永久停用且不得再处分 → `技术秘密转让合同·审查`；
- 专利与技术秘密捆成一份未拆分的概括许可 → `技术许可合同·审查`；
- 主文是专利号、权利要求、年费、专利实施许可备案 → `专利实施许可合同·审查`；
- 尚待研究开发 → `技术开发合同·审查` 或 `委托开发合同·审查`／`合作开发合同·审查`；
- 纯软件交付、几乎无秘密工艺 → `软件委托开发合同·审查`；
- 仅可行性／FTO／工艺评价 → `知产技术咨询·审查`；已有产线调试指导 → `知产技术服务·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `技术秘密使用许可合同·起草`；
- 已签只问交付日、提成对账日、培训日 → 本套导航的履约步骤；
- 已成争（泄密索赔、许可费诉讼、侵权诉讼、立案、开庭、仲裁）→ 合同争议或知产专项，不填签前十节。

无保密整包披露、无偿独占回授、未批进出口先披露：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；代表许可人还是被许可人；正文、密级附件、载体清单、NDA 版本；是许可还是买断；许可方式；双方保密措施；不可接受事项；法域与拟签时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密时，先停止策略输出。不索取未授权的技术秘密原文。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的入门费、提成比例、地域、期限用 `【待填】`，不编造。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、把无保密整包披露或未批进出口先披露改成可履行、把无偿独占回授改成可履行、保证有效或保证秘密永不公开。
- `字段停止`：未见许可／转让定性所需权属句；未见双方保密义务；未见载体清单；许可方式或范围缺失；共有人同意未见；进出口或国家秘密未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或文本已滑入转让／专利许可／开发。

生存级许可费或个人无限连带且用户拒绝升级：停止“可以签署”建议。
