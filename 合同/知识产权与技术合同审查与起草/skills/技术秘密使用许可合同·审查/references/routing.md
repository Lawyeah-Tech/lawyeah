# 边界与路由

本技能只审查 **技术类合同 / 技术秘密使用许可合同**。主线是现有、处于保密状态的技术秘密之使用权许可，许可人保留权属。不是买断转让，不是专利实施许可，也不是尚待开发。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 权属买断、许可人永久停用且不得再使用／再许可／再处分 | `技术秘密转让合同·审查` |
| 专利与技术秘密捆成一份未拆分的概括许可 | `技术许可合同·审查` |
| 主文是专利号、权利要求、年费、专利实施许可备案 | `专利实施许可合同·审查` |
| 现有专利／技术秘密权利让与、未落到秘密使用许可 | `技术转让合同·审查` |
| 专利权转让 | `专利权转让合同·审查` |
| 专利申请权转让 | `专利申请权转让合同·审查` |
| 订立时尚待研究开发 | `技术开发合同·审查` |
| 已独立成册的委托开发主文件 | `委托开发合同·审查` |
| 已独立成册的合作开发主文件 | `合作开发合同·审查` |
| 可运行软件交付、几乎无秘密工艺 | `软件委托开发合同·审查` |
| 可行性、FTO、工艺评价，不授予实施权 | `知产技术咨询·审查` |
| 已有产线调试、操作指导，不授予秘密使用权 | `知产技术服务·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `技术秘密使用许可合同·起草` |
| 已签未争、问交付日／提成对账日／培训日 | 本套导航的履约步骤 |
| 泄密、许可费或侵权已催告、立案、开庭或仲裁 | 合同争议或知产专项；不填签前十节 |
| 无保密措施仍要一次交付全部核心配方 | 留本任务只出红线；用户坚持改成可履行则整体停止 |
| 无偿独占回授、禁止质疑有效性、禁止从他源获得竞争技术 | 留本任务按第八百五十条删除；不改成可履行独家对价 |
| 限制进出口或国家秘密未批仍要向境外披露 | 字段停止或整体停止；不写先披露后补证 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

专业版未收录的场景不会作为本原子的实体审查对象。若用户拿这些文本来找本技能：输出 `unavailable` 或负触发路由，不得用本类型硬套。

本技能不得转去加载转让、概括技术许可或专利实施许可双文件完成本类型审查，也不得把买断停用、专利备案或开发风险写成许可默认主路径。
