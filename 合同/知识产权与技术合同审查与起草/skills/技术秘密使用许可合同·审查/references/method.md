# 审查方法（锁定 技术类合同 / 技术秘密使用许可合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型，禁止打开技术秘密转让、概括技术许可或专利实施许可双文件“对照一下”。

本文件是**现有技术秘密使用权许可**的签前判断节点，不是栏目说明书，也不是转让买断清单或专利备案清单。禁止把“许可人永久停用不再处分”、专利年费维持或专利实施许可备案写成默认路径。

每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、秘密必然不公开、对方必然接受或唯一必得金额。

`search_law` 返回已失效《合同法》及其解释、《技术合同法》及其实施条例、1990 年《技术合同认定登记管理办法》、1993 年《反不正当竞争法》第九条虚假广告旧义、2004 年未修正技术合同解释单行本时记为噪声，不得写入 `L#`。2025 年《反不正当竞争法》MCP 若仍标“尚未施行”，以 2025-10-15 施行日为准并记录冲突；商业秘密条款走第十条，不把 2019 年第九条写成 2026 年默认条号。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准。

示范文本只参考结构。科学技术部技术转让（技术秘密）示范文本不证明本约是许可，也不证明条款已被接受。

## 节点 1　类型识别与负触发

### 1.1 本类型正像

同时满足才继续：

- 标的是**现有**技术信息，订立时已存在，不是尚待研究开发的方案；
- 该信息处于**保密状态**（不为公众所知悉、具有商业价值、许可人已采取相应保密措施），不是已公开的专利权利要求；
- 核心给付是许可人**保留权属**，将被许可人在约定范围、方式、期限、地域内的**使用权**授予对方，换取使用费；
- 采用书面形式。

标题写成“技术秘密使用许可合同”“专有技术实施许可协议”“Know-how License”只是线索。名实不符按核心给付归类，标题冲突写入 `C#`。

### 1.2 必须切开（禁止两套知识）

### 1.4 违法结构停笔

出现下列任一结构，只出告知，不改写成可履行文本：

- 无任何保密范围、载体控制或人员约束，仍要求一次交付全部核心配方／算法／参数；
- “被许可人对标的技术的任何改进无偿、独占归许可人所有，被许可人不得使用”；
- “被许可人不得对标的技术的有效性提出异议，亦不得从其他来源获得类似或竞争技术”；
- 限制出口或国家秘密技术“先向境外披露核心资料，许可证后补”；
- 明知标的侵害第三人技术秘密仍要“改到能继续用”；
- 倒签合同日期以改变纳税义务或进出口申报时点。

用户坚持“改到能签／先交配方再补保密／先出口再补证”：整体停止。合规改道（补双方保密、改非独占交叉许可、补许可证后再披露）只点名并出修改句，不在本任务起草规避方案。

## 硬闸 A　许可使用 ≠ 转让（切开 `技术秘密转让合同·审查`）

本闸改变能否留在本任务。

1. **权属有没有留下**  
   文本须能指出：许可人仍是技术秘密的权利人；被许可人取得的是约定范围内的使用权，不是全部使用权和转让权的买断。  
   出现“甲方将技术秘密的所有权／使用权和转让权一并转让”“许可人签署后不得再使用、再许可或再处分”“永久买断、一次付清后许可人退出该领域”→ 负触发 `技术秘密转让合同·审查`。  
   **修改句（留在本任务时）**：`各方确认：本协议项下交易是许可人将其合法持有的、附件一列明的技术秘密，按本协议约定的方式、地域、领域和期限许可被许可人使用。技术秘密的权属仍归许可人。本协议不是技术秘密转让，许可人未将使用权和转让权买断给被许可人。`

2. **普通许可下许可人默认可自用、可再许可**  
   未写许可方式：按解释第二十五条参照规则视为普通许可，许可人可自行使用并再许可他人。用户要独占或排他：必须明示，并写许可人是否停用、是否不得再许可第三人。  
   **修改句**：`本许可为【独占／排他／普通】许可。独占许可：在约定范围和期限内，许可人不得自行使用，亦不得再许可任何第三人。排他许可：仅许可人与被许可人可以使用，许可人不得再许可第三人。普通许可：许可人保留自行使用和再许可第三人的权利。未经书面约定，不得将本协议解释为权属转让或许可人永久停用。`

3. **最强反方**  
   相对方可主张：标题写“许可”但附件是转让合同，应按买断履行；或主张“永久独占＋许可人停用”就是转让。签前按核心给付分流，不两套都审。

## 硬闸 B　保密义务是生命线

本闸是本类型生存级闸。改变能不能交付核心资料。

1. **双方都有法定保密义务**  
   - 许可人：按照约定提供技术资料、进行技术指导，保证实用性、可靠性，并承担保密义务；该保密义务不限制许可人申请专利，但当事人另有约定的除外（第八百六十八条）。  
   - 被许可人：按照约定使用技术，支付使用费，承担保密义务（第八百六十九条）；对尚未公开的秘密部分，按约定范围和期限保密（第八百七十一条）。  
   文本只有一方保密、或把保密写成“尽合理努力即可”：必须改。

2. **必须落到可执行措施**  
   至少分列：秘密范围（与载体清单交叉引用）；接触人员名单或岗位；书面保密协议及竞业安排（劳动合同细节不在本任务展开）；物理隔离与电子权限；禁止复制、外发、反向工程（对依本约取得的资料）；许可人检查权；违反时的停止使用、交还资料和违约金。  
   商业秘密成立仍取决于秘密性、价值性和相应保密措施（2025 年《反不正当竞争法》第十条；技术合同解释第一条；商业秘密司法解释第五条）。许可人自身未采取相应措施：标红旗，不得写成“签了许可合同就当然构成商业秘密”。

3. **期满或终止后的持续保密**  
   使用权可以到期停止，保密义务通常持续到该信息因许可人以外的原因进入公知领域。技术进出口场景：保密技术非因自己的原因被公开后，保密义务终止（条例第二十五条），可作修改理由，不代替国内合同落句。  
   **修改句**：`许可人与被许可人及其接触附件一所列技术秘密的人员，应对该等秘密承担保密义务。保密范围以附件一载体清单为准，包括配方、工艺参数、操作手册、实验数据和现场指导中的未公开部分。接触人员应签署单独保密承诺，未经书面同意不得复制、外发、再披露或许可第三人使用。合同期满、解除或无效后，被许可人应在【待填】日内归还或按许可人书面指示销毁全部载体，并出具销毁证明；使用授权终止，但保密义务持续至该信息因不可归责于被许可人的原因进入公知领域之日。许可人亦不得向与履行本协议无关的第三人披露被许可人依本协议提供的经营信息。许可人申请专利的，应事先书面通知被许可人；双方另有约定不得申请专利的，从其约定。`

4. **禁止的写法**  
   “双方对有关技术信息予以保密”而无范围和载体；“核心资料于签约当日一次性交付，保密协议后补”；“被许可人可自由向关联公司、供应商转发全部工艺包”。  
   无保密条款仍要求整包交付核心配方：红线。用户坚持先交后补：整体停止。

5. **最强反方**  
   相对人可能主张：没有采取相应保密措施，标的不构成商业秘密，使用费应停止；或主张员工离职后的使用是独立开发。签前把措施和人员约束写成附件，不写“签了就必然构成商业秘密”。

核验失败：保密义务的法定条号字段停止，事实摘录和“无保密不得交付核心资料”的修改句草稿继续。

## 硬闸 C　许可方式、范围与载体清单

1. **方式**  
   独占：范围内仅被许可人，许可人亦不可用。排他：仅许可人与被许可人。普通：许可人可自用、可再许可。未约定或约定不明：普通许可。再许可除非明示，视为普通再许可。  
   **修改句**：`许可方式为【独占／排他／普通】。地域：【待填】。应用领域／产品线：【待填】。使用方式：【制造／使用／销售／进口，择一或并列】。接触人员限于【岗位／名单，附件二】。被许可人不得超出上述范围使用，不得擅自再许可。`

2. **范围含人员**  
   解释第二十八条：使用技术秘密的范围包括期限、地域、方式以及接触人员。期限没有约定或约定不明：被许可人使用不受期限限制——对许可人极不利，必须改出期限或“直至进入公知领域且使用费同步调整”。  
   **修改句**：`许可期限自【核心资料交付且验证期届满】起【待填】年，或至该技术秘密因不可归责于被许可人的原因进入公知领域之日，以较早者为准。期限届满使用授权终止，被许可人应停止使用。双方未另行书面续期的，不得以“期限约定不明”主张无限期使用。`

3. **载体清单是标的本身**  
   技术秘密不能靠公开说明书特定化。必须有密级附件或载体清单：介质、文件名、版本、页数或哈希、存放位置。只有“等有关专有技术”：标缺口，必须改。  
   **修改句**：`许可标的以附件一《技术秘密载体清单》为准，列明文件名称、版本、页数或校验值、密级和存放介质。未列入附件一的信息，不因本合同自动纳入许可范围。清单与正文冲突时以清单为准，并在签署前双方逐项签收。任何一方不得在意见或谈判中补写未提供的配方原文。`

4. **分段披露与验证期**  
   先签保密与概况 → 付入门费 → 披露核心资料 → 复现验证 → 签署交接确认书。验证期内指标不达标：被许可人有权退还资料并要求退还已付费用（可保留已发生指导成本的合理扣减，数字用 `【待填】`）。  
   **修改句**：`许可人应在收到入门费后【待填】日内，按附件一向被许可人交付技术资料，并在【待填】日内完成现场指导。被许可人应在交付后【待填】日内完成复现验证。验证期内，因资料不完整或无法达到附件三约定指标的，被许可人有权书面通知解除本协议、退还全部已接收载体，许可人应在【待填】日内退还已收取的入门费（扣除双方书面确认的已发生指导成本人民币【待填】元）。签收资料不等于验收合格。`

## 硬闸 D　非法垄断技术、后续改进与权利瑕疵

1. **第八百五十条＋解释第十条**  
   下列条款红线删除，不得改成“独家所以可放行”：  
   - 限制被许可人在标的技术上继续研发，或限制其使用改进技术；  
   - 改进成果无偿提供、非互惠转让、无偿独占或共享给许可人；  
   - 禁止从其他来源获得类似或竞争技术；  
   - 不合理限制产量、价格、销售渠道或出口市场；  
   - 搭售非必需技术、原料、设备或人员；  
   - 禁止对标的技术知识产权的有效性提出异议或附加条件。  
   **修改句（删除／改对等回授）**：`删除禁止被许可人自行或从第三人获得竞争技术、禁止质疑标的技术有效性的条款。一方在标的技术基础上后续改进的，改进成果归完成方。完成方应在【待填】日内书面告知对方改进要点（不得要求披露与标的无关的自有秘密）。对方享有普通的、有偿或互惠的非独占实施许可，许可条件另行书面约定；任何一方不得约定改进成果无偿独占归对方所有。无约定时，一方后续改进，其他方无权分享。`

2. **第八百七十五条**  
   后续改进分享办法可约定；无约定且依第五百一十条仍不能确定的，一方后续改进，其他方无权分享。不得编造“改进一律归许可人”。

3. **权利瑕疵**  
   许可人保证自己是合法拥有者，技术完整、无误、有效，能够达到约定目标（第八百七十条）。被许可人按约使用侵害他人合法权益的，原则上由许可人承担责任，另有约定除外（第八百七十四条）。  
   共有技术未经其他共有人同意的独占或排他许可：解释第二十条，该许可行为无效。字段停止，修改句要求共有人书面同意作附件。  
   侵害他人技术秘密的合同被确认无效后：善意使用人可在取得时范围内继续使用但应支付合理使用费并保密；恶意不得继续使用（解释第十二条）。本任务不作出已无效或可继续使用的结论，只写出保证、通知和应诉分担修改句。

4. **许可人违约／被许可人违约**  
   许可人未按约许可：返还部分或全部使用费并承担违约责任；超范围自用或擅自再许可、违反保密：停止违约并担责（第八百七十二条）。  
   被许可人未付使用费：补交并支付违约金；不补交：停止使用、交还资料；超范围、擅自再许可、泄密：停止违约并担责（第八百七十三条）。只有“依法承担违约责任”视为必须改。

## 硬闸 E　对价、公开后的付费与备案幻觉

1. **对价结构**  
   入门费与提成分列；提成基数（净销售额／产量）可审计；许可人有权按约定检查账簿。支付与核心资料交付、指导达标挂钩。未给数字用 `【待填】`。  
   **修改句**：`使用费＝入门费人民币【待填】元（于附件一核心资料交付前支付）＋提成。提成＝【净销售额／合格产量】×【待填】%，按【季度】结算，被许可人应在每期结束后【待填】日内提交计算表和【发票／报关单】复印件。许可人有权每年不超过【待填】次查阅与提成有关的生产记录和销售账簿，审计费用由【待填】承担；误差超过【待填】%的，由被许可人承担审计费并补足差额。`

2. **标的进入公知领域**  
   以许可或转让名义提供已进入公有领域的技术，或履行中进入公有领域，但许可人仍做指导并解决特定技术问题的，可按技术服务处理，使用费可视为服务报酬；明显不合理的可请求调整（解释第三十四条）。  
   **修改句**：`若附件一所列技术秘密因不可归责于被许可人的原因进入公知领域，被许可人支付提成的义务自进入公知领域之日起终止或按双方书面确认的服务费率继续支付现场指导费用。入门费是否退还，按该信息在交付时是否已丧失秘密性分别处理：交付时已公开的，被许可人有权要求退还尚未对应指导成本的部分；交付后因第三人独立公开的，已付入门费不予退还，除非双方另有约定。本条不免除任何一方对泄密的违约责任。`

3. **影子开发**  
   被许可人掌握秘密后声称独立研发同类技术、企图摆脱付费：修改句要求独立研发须证明未使用本约资料，并实行人员／场地／文档隔离；不能证明的，继续付费并视为使用本许可。不在本任务认定已经影子开发。

4. **备案与认定登记**  
   - 技术秘密许可**不是**专利实施许可，不适用《专利实施许可合同备案办法》三个月备案。文本要求“向国知局办理实施许可备案否则不生效”：必须改，避免把本约锁进专利程序。  
   - 向科技部门办理技术合同认定登记，服务于税收或信贷优惠（2000 年认定登记管理办法第二条列明可登记类型；具体优惠口径运行时再核）。**认定登记不是合同生效要件**。不得写成未登记则合同未生效。  
   - 知识稿“无须任何批准登记备案”不得覆盖进出口：限制进口／出口实行许可证管理；限制出口未经许可不得出口；技术出口合同自技术出口许可证颁发之日起生效（条例第三十条、第三十五条）。限制进口合同自进口许可证颁发之日起生效（第十六条）。未批准：履行和境外披露字段停止。  
   **修改句**：`本合同自双方法定代表人或授权代表签字并加盖公章之日起成立。国内技术秘密使用许可不以专利实施许可备案或技术合同认定登记为生效条件。双方可在签署后【待填】日内共同申请技术合同认定登记，未获登记不影响本合同效力，仅影响税收优惠的主张。若标的属于限制进出口技术，本合同自主管部门颁发相应许可证之日起生效；在此之前任何一方不得向境外披露附件一所列核心资料。`

## 节点 2　主体、授权、共有人

1. 建主体表：许可人、被许可人、付款名、发票名、授权签字人、共有人、分许可权来源。名称不一致不自动合并。
2. 许可人须是合法持有人或经书面授权的分许可人。口头“我们老板同意了”不得写成已授权或已取得共有人同意。
3. 共有技术作独占或排他许可：须其他共有人同意或追认，否则该许可行为无效（解释第二十条）。未见书面同意：签署能力字段停止。
4. 国资／上市公司／集体内部决议未附：字段停止。
5. 不足：列出待补材料，不补主体。

## 节点 3　标的、秘密性、交付标准

1. 标的确定到载体清单，见硬闸 C。只有“有关工艺”则标缺口。
2. 秘密性：许可人应说明已采取的保密措施，并做专利库／期刊检索排除已公知。材料未提及不得写成“已确认构成商业秘密”，只能写 `依据不足`。
3. 许可人申请专利的权利默认不被保密义务限制（第八百六十八条第二款）。用户要禁止申请：必须书面约定，并评估公开后许可基础变化。
4. 交付与验收分列。签收、付款、试产不当然等于验收。
5. 不得在修改句或意见中复述用户未要求写入的配方、参数原文。

## 节点 4　程序与生效

把共有人同意、进出口许可证、内部决议、认定登记写成**义务和期限**，不写成已经完成。

| 文本写法 | 本任务动作 |
| --- | --- |
| “本合同签字即生效，核心资料当场交清，保密以后再补” | 红线；改为保密与清单先闭环，再分段披露 |
| “须办理专利实施许可备案后生效” | 删除备案生效；本类型不是专利许可 |
| “未办认定登记则合同无效” | 改为不影响效力，仅影响优惠 |
| “限制出口技术先交付，许可证后补” | 整体停止或境外披露字段停止 |
| 用户要求倒签 | 整体停止 |

不得把“双方同意视为已批准／已取得共有人同意”写成可放行结构。

## 节点 5　格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

重复使用的许可模板仍可能构成格式条款。审查单方解约、无限期使用、不得调整的高额违约金、禁止质疑有效性、管辖、最终解释权是否有显著提示。

违反法律、行政法规强制性规定不一律无效。850 针对非法垄断技术和侵害他人技术成果。进出口许可证主要约束**履行和跨境披露**，不轻易写“未领证则国内主体之间的许可预约当然全部无效”，但限制进出口合同依法自许可证颁发之日起生效。禁止用已失效“效力性／管理性”口诀。

## 节点 6　违约、解除、争议解决

1. 未按约交付资料或指导、逾期支付入门费或提成、超范围使用、擅自再许可、泄密，必须分别有可执行后果。泄密可约定较高违约金，并保留实际损失（含秘密价值减损）与停止使用、交还资料。避免“不得调整”或“按项目总价值三十倍必得”。
2. 构成违约不等于当然解除。法定解除只点名催告或目的不能实现，不在本任务作出已解除结论。
3. 争议解决：已有仲裁条款，不得改成“应向某法院起诉”并假装已选定诉讼；或裁或诉、机构不明：改成单一机构或单一法院连结点。
4. 微信已读不写成已经送达，除非合同把该渠道定为送达。
5. 反向工程：可禁止被许可人对依本约取得的资料、样品做拆解或还原。不得写成“任何第三人通过公开市场产品所做反向工程一概违约”——公开渠道产品的反向工程，商业秘密司法解释所废止的旧解释曾作不侵权抗辩；本合同只能约束合同相对方，不约束世人或已进入公知领域的信息。

## 节点 7　跨境、申请专利与其他结构

1. 涉外主体或境外披露：准据法不明则停止外国法结论；进出口目录与许可证未核则披露字段停止。
2. 许可期间许可人申请专利：通知被许可人；授权后双方是否改签专利实施许可，点名并可转 `专利实施许可合同·审查`，不在本任务整份代审专利许可。解释第二十九条：就已申请尚未授权的技术订立的许可，公开前适用技术秘密许可规定——若文本已是专利申请中的技术，仍可留本任务，但须披露申请号和公开后的转换安排。
3. 技术指导、培训可作为本约组成部分（第八百六十二条第二款），不单独改成技术服务合同，除非标的已进入公知领域且只剩指导（解释第三十四条）。
4. 挂靠、违法分包、规避监管：只出告知，不改写成可履行。

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

对照已加载框架级文件和本方法硬闸，按六步逐段出句。框架中的转让停用、专利备案清单：仅在文本确实出现时用于转出或删除，不得写成默认主路径。

| 步 | 本类型必须盯的点 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题名实（使用许可，避免写成转让）；许可人／被许可人；鉴于写明秘密性、价值性、已采取保密措施，不把权属转移写成已完成 | 主体与鉴于修改句 |
| 交易条款 | 载体清单；独占／排他／普通；地域领域人员期限；分段披露与验证期；入门费＋提成＋审计 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 双方保密；期满停止使用并销毁；对等回授；权利瑕疵与应诉；泄密／超范围／欠费分别后果 | 可执行后果句 |
| 尾部 | 授权签字；附件：载体清单、人员名单、NDA、交接确认书、共有人同意、许可证 | 生效与附件修改句 |
| 语言 | 正说加反说；许可 ≠ 转让；使用到期 ≠ 保密到期；认定登记 ≠ 生效要件；备案是专利程序不是本约 | 替换空词的句子 |
| 常见问题 | 无保密整包交付、买断停用误入、无偿独占回授、禁止质疑、期限不明视为无限使用、未批先出境 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（无保密整包交付、买断停用却当许可、无偿独占回授、禁止质疑／禁他源、未批先出境）；
- `必须改`：可谈但签署前要落句（许可方式、载体清单、验证期、双方保密措施、提成审计、期满停止使用、认定登记非生效）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级许可费或个人无限连带且用户拒绝升级：停止“可以签署”建议。
