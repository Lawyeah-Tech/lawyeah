# 边界与路由

本技能只审查 **知识产权相关合同 / 注册商标转让合同** 的待签文本。中文展示名是「审查注册商标转让合同（知识产权相关合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止把专利权转让审查方法（登记生效、著录项目变更、专利法第十条）套到本任务。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 永久独家授权、买断使用权、独家许可，未约定共同申请核准转让 | `注册商标许可合同·审查`；不得按权属已转移出过户句 |
| 许可类型、使用费、备案、被许可人名称产地标识为主轴 | `注册商标许可合同·审查` |
| 已授权专利号、著录项目变更、专利权登记生效 | `专利权转让合同·审查`；禁止抄其 method |
| 只有申请号、实审中、未注册商标当专用权作价 | 回引擎重定性；不得写公告之日起享有专用权 |
| 继承、合并、法院裁定等非协议移转 | 告知《商标法实施条例》第三十二条；本任务不审 |
| 著作权、软件著作权让与 | `著作权转让合同·审查` 或对应软件原子 |
| 资产包、营业转让、股权收购夹带商标 | `或相应公司并购原子；` 或相应公司/并购原子 |
| 一份文本同时卖专利、技术秘密和商标 | `技术转让合同·审查`；商标专条可点名交接，不代做专利审查 |
| 特许经营：经营资源 + 持续指导 + 费用 | 回引擎重定性，不按单纯商标转让改完 |
| 无文本、本类型条件已谈妥、要出己方稿 | `注册商标转让合同·起草` |
| 已签未争、只问递交日、补正、缴费留痕 | 本套导航的履约步骤 |
| 已催告、拒不配合申请、索赔、立案或对不予核准起诉 | `或知产争议专项。` 或知产/行政专项；C 端只分流，不回改 |
| C 端大众快检 | 只分流，不回改 |

转让正文里夹带在先许可清理专条：许可效力对照解释第二十条继续审；用户要把整份改成许可合同：`目标停止`，转 `注册商标许可合同·审查`。用户坚持本技能给出专利登记生效意见：`目标停止`。
