# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受、商标局必然核准或必然可执行；编造未给出的价款、注册号；把已失效《合同法》及其解释、1982 年商标法、2002 年实施条例、1998 年集体商标办法写入结论；把专利法第十条或专利权转让 method 套到本约；把许可、移转、申请中商标当成已完成的注册商标转让审查。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查注册商标转让合同（知识产权相关合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、1982 年商标法、2002 年实施条例、1998 年集体商标办法、担保法解释或专利法第十条套用时记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `知识产权相关合同`，子级 `注册商标转让合同`。定性理由、易混切开结果（许可 / 专利 / 申请中 / 移转 / 著作权 / 资产包）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、注册人名义与文本版本

主体表：签约名、注册簿名义、付款名、发票名、授权签字人、共有人或质权人。资格：普通商标质量承诺；集体/证明商标受让人资格文件。版本表：正文、一并转让清单、申请书草本、聊天确认；冲突并列。

## 5. 给付闭环

逐件注册号、图样、类别、核定商品/服务、期限；一并转让封闭清单；质权、许可、无效撤销；共同申请义务与核准公告时点；价金与节点、发票、核准失败返还。缺口标 `G#`。批准、核准、公告写成条件或期限，不写成已经完成。

## 6. 格式条款与强制规范

是否构成格式条款；提示说明痕迹。出质未经同意不得改成可履行过户。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。框架里把“签字即过户”的写法不得直接当作建议句。

## 9. 谈判与签署提醒

谈判顺序：先红线（签字即过户拒改、只转主商标拒补清单、无质权人同意、许可文本硬要当转让、保证核准），再必须改（共同申请期限、公告前使用/维权、核准失败返还、在先许可承继），最后可优化。签署提醒：注册人及共有人签章、质权人同意附件、一并转让清单与申请书草本一致、日期与拟递交日。不指导倒签或补假核准。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书或效力保证。
