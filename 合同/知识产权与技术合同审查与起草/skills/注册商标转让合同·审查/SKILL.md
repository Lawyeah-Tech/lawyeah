# 注册商标转让合同·审查

## 任务目标

在单一立场下，只审查 **知识产权相关合同 / 注册商标转让合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文显示名为「注册商标转让合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证商标局必然核准、专利权转让规则套用。

## 本类型硬闸

1. **商标局核准公告**：转让人和受让人应当签订转让协议并共同向商标局提出申请。合同签字只约束价款、披露和配合申请。**受让人自核准公告之日起才享有商标专用权**。禁止“自签字之日起权属归买方”“交付《商标注册证》即过户”。公告前受让人不得对外宣称已取得专用权，也不得单独维权、再许可或出质。
2. **一并转让近似商标**：商标注册人对其在同一种商品上注册的近似商标，或者在类似商品上注册的相同或者近似商标，应当一并转让。附件必须有封闭注册号清单。只转主商标、留下防御标或拆分类似商品：必须改。未一并转让的，商标局通知限期改正；期满未改正视为放弃该转让申请。不得写成“可事后补转、不影响本次过户”。
3. **与许可切开**：核心给付是专用权主体变更。出现“永久独家授权”“买断使用权”“独家买断使用”且**未约定双方共同申请核准转让**的，负触发 `注册商标许可合同·审查`，不得按权属已转移出过户句。许可走备案、不改变权属；转让走核准公告。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签注册商标转让正文，尚未签署，尚未成争，核心给付是把已经核准注册的商标专用权让与受让人，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 权属不转移，只给使用范围、许可类型、备案 → `注册商标许可合同·审查`；
- 已授权专利权全部所有权让与 → `专利权转让合同·审查`，禁止用本技能或专利 method 反过来审商标；
- 尚在审查、只有申请号 → 回 本套导航的类型切开步骤 重定性，或按申请权转让手续切开，不得写“公告之日起享有专用权”；
- 继承、合并、法院裁定等非协议移转 → 告知走《商标法实施条例》第三十二条，不按本协议转让审；
- 著作权财产权让与 → `著作权转让合同·审查`；
- 公司资产包或股权交易里夹带商标、主轴不是商标本约 → `或相应公司并购原子；` 或相应公司/并购原子；
- 概括技术转让或多标的混装 → `技术转让合同·审查`；
- 特许经营（经营资源 + 持续指导 + 费用）→ 回引擎重定性，不按单纯商标转让改完；
- 无文本、本类型条件已谈妥、要出己方稿 → `注册商标转让合同·起草`；
- 已签只问递交、补正、缴费留痕 → 本套导航的履约步骤；
- 已成争（催告、拒不配合申请、索赔、诉讼仲裁、对不予核准提起行政诉讼）→ `或知产争议专项。` 或知产/行政专项，不代做争议文书。

出质后无质权人书面同意仍要过户、把未注册商标当注册商标作价、倒签对抗查封：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及附件/申请书草本版本；注册号、图样、类别、核定商品/服务、专用权期限；注册簿名义是否与签约名一致；应一并转让的相同/近似商标清单；是否集体/证明商标及受让人资格；质权、查封、在先许可、无效/撤销；谁主办共同申请、价款是否绑受理或公告；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价款、注册号用 `【待填】`，不编造。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `注册商标转让合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 争议或知产/行政。未签且目标是评改已有注册商标转让，才进入本任务。

### 1. 类型锁死

标题、核心给付与已经注册的专用权让与一致才继续。许可、专利、申请中商标、移转、著作权、资产包负触发。

### 2. 主体、注册人名义与资格

签约名与注册簿一致；共有人全体签署；名义变更先办商标变更；集体/证明商标审受让人资格。

### 3. 标的特定化与一并转让清单

逐件注册号、图样、类别、核定商品/服务、期限；封闭一并转让清单；质权、许可、无效撤销不得写成“无负担”。

### 4. 核准公告与共同申请

拆开合同生效与专用权变动；谁主办、谁缴费、补正期限、不得单方撤回；公告前使用/维权安排。

### 5. 对价、定金与核准失败

支付节点绑递交受理或核准公告；定金与首期价款切开；不予核准或视为放弃的返还与责任。

### 6. 在先许可、出质、质量保证

解释第二十条承继；第四百四十四条质权人同意；受让人保证商品质量。

### 7. 违约、解除、争议

拒不共同申请、隐瞒近似商标或质权须有可执行后果。民事争议与核准行政诉讼不要混写成一裁终局解决全部商标事务。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签对抗查封或质权、保证核准、把签字写成已取得专用权、把出质商标在无同意下改成可履行过户、坚持只转主商标并声称不影响核准。
- `字段停止`：法域、注册簿状态、一并转让检索、质权同意、集体/证明资格、马德里指定国手续未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁许可/专利/移转。

生存级全款先付或个人无限连带且用户拒绝升级：停止“可以签署”建议。
