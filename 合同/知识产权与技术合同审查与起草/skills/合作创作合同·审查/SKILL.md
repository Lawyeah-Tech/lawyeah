# 合作创作合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、1990 年著作权法旧条号或 1991 年实施条例当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **知识产权相关合同 / 合作创作合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文显示名为「合作创作合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证挂名作者有效或保证对方接受共有安排。

## 本类型硬闸

1. **合作作品不可分割共有**：不能分割使用的合作作品，著作权由合作作者共同享有。禁止把不可分割整体写成各人可单独带走、单独转让整部，禁止用民法典不动产/动产按份共有分割替代第十四条。可以分割使用的，必须事先书面划清各部分单独著作权与整体著作权的边界，行使部分权利不得侵犯整体。
2. **一方不得不当阻止使用**：合作作品著作权由合作作者协商一致行使；不能协商一致又无正当理由的，任何一方不得阻止他方行使除转让、许可他人专有使用、出质以外的权利，所得收益应当合理分配给所有合作作者。合同不得写成一方对发表、自己使用、普通许可享有无期限否决权。转让、专有许可、出质必须全体书面同意；单方签署对其他作者不发生处分效力。

配套：没有参加创作的人不能成为合作作者。组织工作、咨询意见、物质条件或辅助工作不视为创作。一方出资一方交稿且无共同创作意图 → `知产委托创作·审查`。技术方案合作开发 → `合作开发合同·审查`。合伙经营 → `合伙经营→` / `普通合伙企业协议` / `有限合伙企业协议`。已有作品财产权让与 → `著作权转让合同·审查`。已有作品许可 → `著作权许可使用合同·审查`。署名不得买卖。交稿给统稿人不是财产权转让。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签合作创作正文，尚未签署，尚未成争，核心给付是两人以上共同创作同一作品并安排共有行使，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 一方出资、一方执笔，无共同创作意图，或名称写合作、履行是委托交稿 → `知产委托创作·审查`；若用户坚持按委托合同父级审 → `若用户坚持按委托合同父级审→`；
- 已完成作品的财产权让与、转让价金和权利种类清单为主轴 → `著作权转让合同·审查`；
- 已有作品的专有或普通许可使用为主轴 → `著作权许可使用合同·审查`；
- 计算机软件著作权登记变更或软著让与为主给付 → `软件著作权转让合同·审查`；
- 订立时技术方案尚不存在、专利申请权或技术秘密共有开发 → `合作开发合同·审查`；
- 出资、盈亏、入伙退伙、合伙企业财产为主轴 → `合伙经营→` / `普通合伙企业协议` / `有限合伙企业协议`；
- 电影、电视剧以制作者享有著作权、作者仅署名和获酬为主轴 → 不按第十四条普通共有改完，转引擎重新定性或点名视听条款另审；
- 无文本、本类型条件已谈妥、要出己方稿 → `合作创作合同·起草`；
- 已签只问交稿日、分账日 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁或著作权权属/侵权已立案 → `或知产争议专项。` 或知产/争议专项。

把未参与创作的人改成可履行合作作者，或把单方转让/专有许可/出质改成对全体发生处分效力：只出告知，不改写成可履行路径。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及分工署名表/素材清单/分配表版本；各签署方是否实际贡献独创性表达；作品可否分割；有无单方否决或“全权”；重大处分是否须全体书面同意；登记作者栏是否拟与合同一致；带入素材和职务作品；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `合作创作合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议或知产。未签且目标是评改已有合作创作文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。委托创作、合作开发、合伙、著作权转让、许可、软件转让、视听制作者权主轴负触发。

### 2. 作者身份与金主

仅实际参与独创性表达的人进入作者栏。投资人可享收益或约定取得财产权，不得写成合作作者。

### 3. 不可分割共有

事先定性可分割或不可分割。不可分割整体共有；可分割须划边界。

### 4. 权利行使与不当阻止

普通许可和自己使用不得被无理由锁死。转让、专有许可、出质全体书面同意。

### 5. 署名、收益、素材、登记

署名顺序书面化。单独收款视为代收。带入素材不自动共有。登记作者栏与合同一致。

### 6. 对价、退出、买断份额

买断他方财产权份额用转让价款。退出区分作者身份与财产权份额。

### 7. 格式条款与强制规范

无核验引文则法律结论字段停止。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把未创作人改成作者、把单方永久否决或单方专有授权改成对全体生效。
- `字段停止`：法域、动态规则、可分割性、是否实际创作、职务作品或单位权属未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
