## **第一步：合同类型（法律性质）分析**

* **法律定性**：注册商标转让合同是注册商标专用权人将其**已经核准注册**的商标专用权让与受让人、受让人支付对价的合同。核心给付是**商标专用权主体变更**，不是许可使用权，也不是未注册商标或申请中商标的移转。适用《商标法》（2019修正）第42条、《商标法实施条例》（2014修订）第31条、第32条，并受《民法典》合同编及第444条（知识产权财产权出质）约束。
* **易混淆辨析**：
* **转让 vs 许可**：转让后转让人丧失专用权；许可不改变权属，仅授予约定范围内的使用权。合同写“永久独家授权”“买断使用权”但未约定共同申请核准转让的，应按许可审，不得按权属已转移处理。
* **转让 vs 移转**：继承、合并、法院裁定等非协议转让，走移转手续，规则准用一并移转、公告之日起享有专用权。
* **注册商标 vs 申请中商标**：申请权转让走商标局转让申请手续，但不产生“公告之日起享有专用权”的效果。未注册商标只能让与民事权益，不能产生专用权。
* **效力认定**：
* **合同成立≠专用权移转**。双方签字即对转让价款、配合申请等产生债的约束；**受让人自商标局核准并公告之日起才享有商标专用权**。公告前受让人对外维权、许可、出质均缺权源。
* **一并转让未完成**：注册人在同一种商品上的近似商标，或在类似商品上的相同、近似商标**应当一并转让**。未一并转让的，商标局通知限期改正；期满未改正，**视为放弃该转让申请**。
* **不予核准**：容易导致混淆或者有其他不良影响的转让，商标局不予核准。含地名、企业字号、集体/证明商标主体不适格，是高频驳回原因。
* **出质后擅自转让**：注册商标专用权出质后，未经质权人同意不得转让；擅自转让即使合同有效，也难以完成核准。


## **第二步：合同主体（交易对手）分析**

* **转让人**：须为商标注册簿记载的注册人。共同注册的，须全体共有人一致处分，除非共有协议另有约定。核对注册人名义与营业执照/身份证是否一致；名义变更未办变更登记的，须先变更再转让。
* **受让人**：
* 普通商品/服务商标：自然人、法人、非法人组织均可，但受让人须**保证使用该注册商标的商品质量**。
* **集体商标、证明商标**：受让人须具备相应主体资格（集体组织、检测监督能力等），并符合《集体商标、证明商标注册和管理规定》（2024年2月1日起施行）。地理标志类还须地方政府或主管部门同意。
* **关联主体**：
* **质权人**：已办理商标质权登记的，须书面同意并配合解除或变更。
* **在先被许可人**：独占/排他被许可人可能阻却受让人实际使用；未备案许可不得对抗善意受让人，但已备案许可随商标移转。
* **国资/上市公司**：商标作为重大无形资产转让，可能触发评估、进场交易或信息披露。
* **签约能力**：代理人须持注册人出具的转让授权；跨境转让注意涉外主体身份证明公证认证。


## **第三步：合同标的（交易对象）分析**

* **标的特定化**：逐件列明商标名称、图样、注册号、国际分类、核定商品/服务、注册日、专用权期限、续展状态。不得只写“某某品牌全部商标”。
* **近似商标包**：按注册人名义检索同一种或类似商品上的相同、近似商标，形成**必须一并转让清单**。漏列将导致限期改正或整包失败。
* **权利负担**：
* 质权登记、司法查封、保全、海关知识产权备案、被提无效/撤销三年不使用、异议后续程序。
* 在先许可：许可类型、地域、商品范围、期限、是否可备案对抗。
* **可交易性**：
* 专用权已届满未续展、被宣告无效、被撤销的，标的灭失。
* 仅转让部分核定商品、拆分近似商标，易被认定为导致混淆而不予核准。
* **质量与商誉**：转让不消灭因连续三年不使用被撤的风险；受让后三年起算规则和证据保存要一并安排。


## **第四步：合同程序（交易步骤）分析**

* **法定程序**：转让人与受让人**签订转让协议并共同向商标局提出申请**（《商标法》第42条）。手续由双方共同办理。核准后发给受让人证明并公告；**公告之日为专用权移转日**。
* **内部决策**：公司章程对重大资产处分的股东会/董事会决议；国有商标评估备案；共有人书面同意。
* **价款与交割节点**：建议“签约付定金/首款 → 递交申请 → 核准公告后付尾款”。公告前付清全款的，须配套回转、托管或共管账户。
* **公告前过渡**：约定谁使用、谁维权、谁续展、谁应对无效撤销。未约定时，法律上专用权仍在转让人名下。
* **移转（非协议）**：继承、合并等凭法律文书办理，近似商标同样一并移转，接受人自公告之日起享有专用权。


## **第五步：交易结构设计（风险规避方案）**

* **对价结构**：固定价款 + 核准失败返还；或按商标包分件计价。定金不超过主合同标的额**20%**。
* **核准失败安排**：因未一并转让、主体不适格、混淆/不良影响被驳回的，区分可补正与不可补正；可补正的限期配合，不可补正的解除并返还价款、赔偿直接损失。
* **负担清除**：交割条件包括解除质权、撤销查封、披露并处理在先许可。已备案许可原则随权利移转，须约定受让人是否承继及收益归属。
* **质量与商誉隔离**：受让人书面承诺保证商品质量；对转让前侵权索赔权、许可费尾款作出切割。
* **文本形态**：**主转让协议 + 一并转让商标清单 + 无负担声明 + 质权人/共有人同意书 + 商标局申请书副本**。


## **第六步：宏观风险预警与尽调指引**

* **高频争议**：公告前一方反悔拒不配合申请；漏转近似商标被视放弃；受让后发现在先独占许可；转让人继续使用导致混淆；无效/撤销程序中转让后权属落空。
* **尽调清单**：
* [ ] 中国商标网核对注册人、图样、类别、状态、期限
* [ ] 同一注册人名下相同/近似商标全量检索并列表
* [ ] 质权、许可备案、海关备案、诉讼查封
* [ ] 无效、撤销三年不使用、异议后续案件
* [ ] 集体/证明商标受让人资格与使用管理规则
* [ ] 国资、共有、职务创作/委托设计的权属来源
* **重大风险红旗**：注册人与签约主体不一致；只转主商标不转防御商标；“自签字之日起权属归买方”却不办共同申请；出质或查封未披露；把未注册商标当注册商标作价。
