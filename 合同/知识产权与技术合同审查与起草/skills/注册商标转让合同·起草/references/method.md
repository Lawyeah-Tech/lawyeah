# 审查方法（锁定 知识产权相关合同 / 注册商标转让合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制专利权转让原子的 method，禁止把专利法第十条“登记之日起生效”或著录项目变更套进来。

定性校验：标题、核心给付与本类型一致才继续；许可、专利、申请中商标、移转、著作权或资产包明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、商标局必然核准、对方必然接受或唯一必得金额。

`search_law` 返回 1982 年《商标法》、2002 年《商标法实施条例》、1998 年《集体商标、证明商标注册和管理办法》、已失效《合同法》及其解释或担保法解释时记为噪声，不得写入 `L#`。商标法引用 2019 修正、2019-11-01 施行文本；实施条例引用 2014 修订。集体/证明商标资格引用 2023 年规定、2024-02-01 施行文本。

示范文本和商标局申请书只参考栏目。申请书草本不证明已经核准。

知识库纠正（不回写双文件）：

- `基本面.md` “合同成立≠专用权移转”“受让人自核准并公告之日起享有商标专用权”“应当一并转让”：采纳，作为硬闸。
- `基本面.md` 把继承、合并、裁定写进本类型程序：本技能不审，转实施条例第三十二条移转手续。
- `基本面.md` “已备案许可随商标移转”：纠正为解释第二十条——转让不影响转让前已生效的许可，另有约定除外；须写受让人是否承继及收益归属。未备案许可不得对抗善意受让人（商标法第四十三条）。
- `框架.md` “签字即过户”“本合同生效即商标权归乙方”：当作必须改，不是可保留结构。
- 1998 年“集体商标不得转让”：失效噪声。现行规则是受让人须具备相应主体资格。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 已经核准注册的商标专用权整体让与 + 对价 + 约定共同申请核准转让 | 本类型 | 正触发 |
| 永久独家、买断使用、使用费/许可类型/备案，**未**约定共同申请核准转让 | 注册商标许可 | 负触发 `注册商标许可合同·审查` |
| 已授权专利号、登记生效、著录项目变更 | 专利权转让 | 负触发 `专利权转让合同·审查`；禁止打开其 method |

| 继承、吸收合并、法院裁定过户，无协议对价结构 | 移转 | 告知实施条例第三十二条；不按本约审 |

| 资产清单/股权交割里夹带商标，主轴不是商标本约 | 资产或并购 | 负触发 `或相应公司并购原子；` 等 |
| 经营资源 + 持续指导 + 加盟费 | 特许经营 | 回引擎；不按单纯转让改完 |

## 节点 2　主体、注册人名义与资格

### 2.1 主体表

建表：签约名、注册簿名义、付款名、发票名、授权签字人。名称不一致不自动合并。

转让人须为商标注册簿记载的注册人。共同注册：全体共有人列为转让方并签署，除非已核验的共有协议明确授权其中一人处分。口头“其他共有人同意了”不得写成已授权。

注册人名义与营业执照不一致：先办商标法第四十一条变更，再转让。修改句把变更办结作为递交转让申请的先决条件。

国资、集体、上市公司重大无形资产：决议、评估、进场或披露未附则签署能力字段停止，不写成“可以盖章”。

### 2.2 受让人与集体/证明商标

普通商品或服务商标：自然人、法人、非法人组织均可。必须写下受让人保证使用该注册商标的商品质量（第四十二条第一款）。空词“保证商誉”不够。

集体商标、证明商标：受让人须具备 2023 年规定第十四条的主体资格，并符合使用管理规则。地理标志类另标地方政府或主管部门同意 `G#`。未见资格文件：字段停止，不保证核准。禁止引用 1998 年“集体商标不得转让”。

### 2.3 代理人与跨境

代理人权限须明示“办理商标转让申请并在申请书上签字”。跨境主体身份证明公证认证未附：字段停止，不编造认证路径。

## 节点 3　标的特定化、一并转让与权利负担

### 3.1 特定化

逐件：商标名称、图样、注册号、国际分类、核定商品/服务、注册日、专用权期限、续展状态。不得只写“某某品牌全部商标”“全部相关商标”。缺注册号：必须改，数字用 `【待填】`。

注册证原件交付、图样光盘、品牌手册移交，只是资料交付，**不等于**专用权转移。

已届满未续展、已被宣告无效、已被撤销：标的灭失，停止按有效专用权作价。被提无效、撤三、异议后续：披露并写程序承受，不承诺权属不落空。

### 3.2 一并转让清单（硬闸）

支持依据：商标法第四十二条第二款；实施条例第三十一条第二款。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 附件已列同一注册人名下应一并转让的相同/近似商标，且与申请书草本一致 | 可接受或核对图样/类别 | 已经核准 |
| 只列主商标，防御标、关联类别、类似商品上的相同/近似商标留在出让方 | 红线或必须改：检索后做成封闭清单，漏列视为出让方违约并继续配合补转 | 可事后补转、不影响本次过户 |
| 故意只转部分核定商品或拆分近似商标 | 标不予核准（混淆/不良影响）风险；修改句改为整包或删除拆分 | 拆分后双方可安全共用近似标 |
| 用户拒绝提供检索仍要放行 | 字段停止；受让人立场不建议付清全款 | 已经没有近似商标 |

马德里国际注册或境外注册：单独成表，不把中国核准公告写成已覆盖指定国。当地手续 `G#`。

### 3.3 权利负担

质权登记、司法查封、保全、海关知识产权备案、在先许可、无效/撤销。材料未提及不得写成“无权利负担”，只能写 `依据不足`。无负担声明可作附件，但不能代替检索。

## 节点 4　核准公告时点与共同申请（硬闸）

支持依据：商标法第四十二条第一款、第四款；实施条例第三十一条第一款。

| 文本写法 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| “自双方签字之日起商标权归乙方所有” | 必须改或红线：债的义务自签字发生；专用权自核准公告之日转移 | 签字即过户；未公告仅不得对抗第三人 |
| “交付注册证原件即完成转让” | 必须改：交证是资料义务，权属以公告为准 | 证书交付=物权变动 |
| “本合同生效即商标权归乙方”，不写共同申请 | 必须补：双方应在签约后【待填】日内共同向商标局提交转让申请；主办、缴费、补正、不得单方撤回 | 一方可单独完成过户 |
| “商标局审查周期属于不可抗力” | 必须改：审查、补正、不予核准不是不可抗力 | 核准失败可免责 |
| 保证“【待填】日内核准”或“必然核准” | 红线删除保证；可写配合义务和失败返还 | 已经锁定核准日 |

公告前过渡必须写清：谁使用、谁续展、谁应对无效撤销、收益归属。未约定时，法律上专用权仍在转让人名下。公告前受让人对外维权、再许可、出质：现有依据不支持，必须改或删除。

价款建议绑节点：签约付定金或首款 → 递交并取得受理 → 核准公告后付尾款。公告前付清全款须有共管、托管或核准失败返还。生存级全款先付且拒改：停止“可以签署”。

用户要求把备案写成转让生效要件，或把专利“登记之日起生效”写进商标合同：必须改回核准公告，并禁止套用专利法第十条。

## 节点 5　对价、定金与核准失败

### 5.1 价金

总额、分件价、币种、税、发票、支付节点分列。未给出的数字写 `【待填】`。禁止编造评估价。

### 5.2 定金不是订金

支持依据：民法典第五百八十六条；合同编通则解释第六十七条。必须使用“定金”二字才讨论罚则。“订金、首期转让价款、保证金”无定金性质约定的，不得写成定金。超过主合同标的额百分之二十的部分不产生定金效力。

| 文本写法 | 动作 |
| --- | --- |
| 首期款写成订金却适用双倍返还 | 必须改：改为定金并截到不超过 20%，或改为预付款并写明不适用罚则 |
| 担保的是配合申请义务 | 可用定金，但须写清何种违约触发 |
| 无核验引文 | 20% 法律结论字段停止；修改句草稿仍可按内置方法给出 |

### 5.3 核准失败

区分：未一并转让等可补正，与混淆/不良影响、主体不适格等可能不予核准。可补正：限期配合改正。不可补正或视为放弃：解除、返还已付款、直接损失。禁止“无论是否核准价款不退”。禁止保证复议或行政诉讼必胜。

## 节点 6　在先许可、出质与质量保证

### 6.1 在先许可

支持依据：解释第二十条；商标法第四十三条第三款；解释第十九条。

转让不影响转让前已经生效的许可，许可合同另有约定除外。修改句必须：披露许可类型、地域、商品、期限、是否备案；写明受让人是否承继、许可费尾款归属；独占/排他与本次转让冲突时的解除或补偿。未备案不得对抗善意受让人，但不得把“未备案”写成许可当然无效。

受让人立场：未见披露仍要付清全款——红线，尾款留在公告后并设披露不实违约。

### 6.2 出质

支持依据：民法典第四百四十四条；实施条例第七十条。

已办理质权登记的，未经质权人书面同意不得转让。价款应约定优先清偿或提存。无书面同意：字段停止，不设计“先过户再补同意”。用户坚持改到能核准：整体停止。

查封、保全同理：未解除不得写成可核准。

### 6.3 质量与商誉切割

受让人保证使用该注册商标的商品质量。转让前侵权索赔权、罚款、许可费尾款归属写清。转让不消灭撤三风险；受让后使用证据保存只点名，不在本任务做撤三答辩。

## 节点 7　违约、解除、争议与格式条款

1. 拒不共同申请、逾期不签字、不交证件、擅自再转让、隐瞒近似商标、隐瞒质权/查封，必须分别有日违约金、解除权和已付款返还。只有“依法承担违约责任”视为必须改。
2. 构成违约不等于当然解除。法定解除只点名，不在本任务作出已解除结论。
3. 违约金避免“不得调整”或“按总价 30% 必得”。不在本任务做第五百八十五条精算。
4. 争议解决：商标权属确认常与核准行为交织。禁止“一裁终局解决全部商标事务”把行政诉讼包进去。或裁或诉、机构不明标待核。
5. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。

格式条款：为重复使用而预先拟定的品牌方模板，按民法典第四百九十六条至第四百九十八条审查提示说明。无核验引文则法律结论字段停止。违反法律、行政法规强制性规定不一律无效，区分规范目的；禁止用已失效“效力性/管理性”口诀代替合同编通则解释第十六条。挂靠、以合法形式掩盖非法目的：不改写成有效履行结构。

## 版本冲突

正文、一并转让清单、申请书草本、聊天确认冲突时：

1. 并列 `D#` / `C#` / `S#`，不选对用户有利的一版。
2. 修改句写明冲突项以哪一份为准，或删除冲突句。对内不得默认“以申请书为准”。
3. 不得在意见里悄悄采用有利版本并称“合同已明确”。

| 工具 | 级别 | 不可用时 |

| `search_law` | required（核准公告、一并转让、许可切开、出质限制的法律结论） | 不拒跑；事实、版本、主体、给付摘录和修改句草稿继续；效力字段停止 |

## 起草模式与自审

本任务是起草。有完整待签文本要评改时转 `注册商标转让合同·审查`。
按框架六步落稿，本类型硬闸改成起草必写 / 附件必附 / 禁止出现。出稿后按审查节点自审，未过不得宣称完成。
