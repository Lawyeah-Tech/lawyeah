# 技术许可合同·审查

## 任务目标

在单一立场下，只审查 **技术类合同 / 技术许可合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文显示名为「技术许可合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、把许可改写成权利过户。

## 本类型硬闸

1. **许可 ≠ 转让**：正像是合法拥有人把**现有**特定专利或技术秘密的实施/使用权授出，**所有权不更替**。把专利权、专利申请权或技术秘密权利让与对方 → `技术转让合同·审查` / `专利权转让合同·审查` / `专利申请权转让合同·审查` / `技术秘密转让合同·审查`。禁止输出“许可完成后所有权转归被许可人”的可放行结构。
2. **范围、期限、排他必须落句**：独占 / 排他 / 普通、地域、期限、实施或使用方式、应用领域、接触人员必须可核验。未约定方式不得写成独占。专利部分期限不得超过该专利权存续期。
3. **第八百五十条**：非法垄断技术或者侵害他人技术成果的条款必须改或删除。禁止改进、禁他源技术、不对等回授、不合理搭售、禁止或附条件限制质疑知识产权（含“提出无效即立即终止”）不得放行。认定走技术合同解释第 10 条。现行第 850 条条文本身不再写“妨碍技术进步”。
4. **与专利实施许可切开**：主文件标题和核心给付就是针对已列专利号的《专利实施许可合同》→ `专利实施许可合同·审查`。已独立成册的《技术秘密使用许可合同》→ `技术秘密使用许可合同·审查`。本技能只审父级《技术许可合同》：混合授权、图纸或工艺包使用许可、软件分销许可、科研院所技术秘密有偿共享，或专利与 Know-how 打成一包且未独立成册专件。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签技术许可正文，尚未签署，尚未成争，核心给付是就现有特定专利或技术秘密授出实施或使用权，所有权仍归许可人，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 专利权、专利申请权或技术秘密的权利让与 → `技术转让合同·审查` / `专利权转让合同·审查` / `专利申请权转让合同·审查` / `技术秘密转让合同·审查`；
- 主文件是已独立成册的专利实施许可 → `专利实施许可合同·审查`；
- 主文件是已独立成册的技术秘密使用许可 → `技术秘密使用许可合同·审查`；
- 订立时尚待研究开发 → `技术开发合同·审查`；委托/合作开发细分主文件 → `委托开发合同·审查` / `合作开发合同·审查`；
- 可行性、FTO、工艺评价，不授实施权 → `知产技术咨询·审查`；解决特定技术问题、无授权 → `知产技术服务·审查`；
- 撮合双方订立许可、报酬绑在促成签约 → `撮合专利许可只收中介费不自己实施也不自己许可→`；
- 无文本、本类型条件已谈妥、要出己方稿 → `技术许可合同·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁、侵权或无效程序 → `或知产争议专项。` 或知产/争议专项。

以许可为名买卖国家秘密、未批限制进出口技术，或把 850 垄断条款改成可履行结构：只出告知，不改写成可履行路径。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及附件/范围表/专利清单版本；标的是否现有技术；是许可还是让与；是否专利实施许可专件；方式/地域/期限/领域；分许可；入门费与提成；专利费与秘密费是否分列；850 条款；共有人或在先许可；进出口或国家秘密；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的使用费、地域、期限用 `【待填】`，不编造。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `技术许可合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议或知产。未签且目标是评改已有技术许可文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。让与、专利实施许可专件、技术秘密使用许可专件、尚待开发、咨询/服务、中介负触发。

### 2. 主体、权属与共有人

签约名、履行名、付款名、发票名分列。许可人须合法拥有或有权转许可。共有人未同意：签署能力字段停止。

### 3. 许可≠转让；范围、期限、排他

所有权不更替。方式/地域/期限/领域/人员落句。未约定方式按普通披露。分许可默认禁止。

### 4. 第八百五十条

禁改进、禁他源、不对等回授、搭售、禁质疑或挑战即终止：必须改或删除。

### 5. 对价与失效后分费

入门费、提成、保底、查账分列。专利部分不得在专利权终止后继续收取；与秘密使用费分开核算。

### 6. 交付、保证、保密、后续改进

资料须足以实施。保证合法拥有和约定目标，不保证商业利润。改进谁完成谁享有，交叉许可须对等。

### 7. 格式条款、备案与进出口

备案写成义务，不写成生效或已完成。未批进出口：履行字段停止。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把许可改写成过户、把 850 条款或未批进出口改成可履行结构。
- `字段停止`：法域、动态规则、专利法律状态、共有人同意、进出口目录、国家秘密审批未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
