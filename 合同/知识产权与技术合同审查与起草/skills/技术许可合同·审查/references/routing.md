# 边界与路由

本技能只审查 **技术类合同 / 技术许可合同** 的待签、所有权不更替文本。中文展示名是「审查技术许可合同（技术类合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 现有专利、专利申请或技术秘密的权利让与 | `技术转让合同·审查` |
| 专利权转让、办理权利人变更 | `专利权转让合同·审查` |
| 专利申请权转让 | `专利申请权转让合同·审查` |
| 技术秘密权利让与 | `技术秘密转让合同·审查` |
| 主文件是已独立成册的专利实施许可 | `专利实施许可合同·审查` |
| 主文件是已独立成册的技术秘密使用许可 | `技术秘密使用许可合同·审查` |
| 订立时尚待研究开发 | `技术开发合同·审查` |
| 委托开发作为已独立成册的细分主文件 | `委托开发合同·审查` |
| 双方共同投资并分工参与研究开发 | `合作开发合同·审查` |
| 特定技术项目可行性、技术预测、工艺评价、FTO，不授实施权 | `知产技术咨询·审查` |
| 以技术知识解决特定技术问题，无授权 | `知产技术服务·审查` |
| 撮合双方订立许可或转让，报酬绑在促成签约 | `撮合专利许可只收中介费不自己实施也不自己许可→` |
| 无文本、本类型条件已谈妥、要出己方稿 | `技术许可合同·起草` |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或知产争议专项。` 或对应专项领域 |
| 侵权、无效、权属诉讼已立案 | 知产或争议专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

技术许可正文里夹带一小段尚待开发或咨询评估：专章交接对应原子；许可条款可继续审。用户坚持本技能把转让、专利实施许可专件、技术秘密使用许可专件或开发整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
