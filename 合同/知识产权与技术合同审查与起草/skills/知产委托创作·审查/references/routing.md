# 边界与路由

本技能只审查 **知识产权相关合同 / 委托创作合同** 的待签、将来作品权属与使用范围文本。中文展示名是「审查委托创作合同（知识产权相关合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开 `若用户坚持按委托合同父级审→` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 用户按「委托合同」审查；主轴是事务委托、任意解除、隐名代理、对外签约；无权属清单/登记/再许可/邻接权 | `若用户坚持按委托合同父级审→` |
| 处理事务或对外代理，无作品交付 | `一般委托代签本约→` |
| 已完成作品的财产权过户，无创作过程 | `著作权转让合同·审查` |
| 已有作品的许可使用、使用费、期限届满收回 | `著作权许可使用合同·审查` |
| 双方均为作者的合作创作、共有行使 | `合作创作合同·审查` |
| 隐名执笔、对外以委托人名义表明作者身份 | `隐名执笔对外以委托人名义表明作者身份→` |
| 功能性委托设计、验收指标为主 | `或` |
| 委托技术开发、技术方案或技术秘密尚待开发 | `委托合同目录下的委托技术开发主文件且用户未锁定本类型→` 或 `委托开发合同·审查` |
| 软件委托开发为主给付 | `软件委托开发合同·审查` |
| 计算机软件著作权让与为主给付 | `软件著作权转让合同·审查` |
| 复制件制作、无独创性表达 | `复制印刷定作而无独创性表达→` |
| 印刷 | `印刷` |
| 定作 | `按图定作实物` |
| 无文本、本类型条件已谈妥、要出己方稿 | `知产委托创作·起草` |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或知产争议专项。` 或对应专项领域 |
| 权属诉讼、侵权诉讼或行政处罚已立案 | 知产或争议专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

知产侧委托创作正文里夹带一小段现成作品买断或软件开发：专章交接对应原子；权属与使用范围条款可继续审。用户坚持本技能把委托侧同名、现成转让、许可、合作创作或开发整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
