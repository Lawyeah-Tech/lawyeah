# 知产委托创作·审查

## 任务目标

在单一立场下，只审查 **知识产权相关合同 / 委托创作合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文显示名为「知产委托创作·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证市场独创第一或登记证书必然记载委托人。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **知产父级委托创作**：正像是委托人就**尚未完成的作品**支付稿酬或权属对价，审查主轴是**权属、第 10 条权利清单、委托目的与使用范围、作品登记配合、再许可或邻接权**。不是劳务派遣，也不是技术开发的验收指标合同。标题写“委托开发/技术服务”但成果是作品：仍按本类型审权属，不按技术指标改完。
2. **归属约定（生命线）**：权属必须三选一写死——（甲）约定财产权归委托人，受托人保留人身权；（乙）财产权归受托人，委托人取得委托目的范围内普通或专有许可；（丙）共有，并写份额和对外许可规则。合同未作明确约定或者没有订立合同的，著作权属于受托人。禁止把“版权归甲方所有”“全部知识产权永久买断”一句话当成已取得第 10 条全部财产权。人身权（发表、署名、修改、保护作品完整）不得写成已转让。未列明的权利种类，另一方不得行使。
3. **与委托侧同名切开**：中文子类型同名「委托创作合同」，不得因标题相同就留下。用户明确按「委托合同」审查，或主轴是事务委托、任意解除、隐名代理、对外以委托人名义签约，而无权属清单、登记配合、再许可或邻接权 → 负触发 `若用户坚持按委托合同父级审→`。禁止打开或抄写该原子 method，禁止删掉委托栏目后硬套本技能。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签委托创作正文，尚未签署，尚未成争，父级是知识产权相关合同或用户按该货架审查，核心给付是从无到有创作作品且审查主轴是权属与使用范围，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 用户按「委托合同」审查，或主轴是事务委托、任意解除、隐名代理而无权属/登记/再许可 → `若用户坚持按委托合同父级审→`；
- 处理事务、对外代理、无作品交付 → `一般委托代签本约→`；
- 购买或过户**已经完成**的作品财产权，无创作过程 → `著作权转让合同·审查`；
- 已有作品的许可使用、期限届满收回、按使用费续期 → `著作权许可使用合同·审查`；
- 双方均为作者、共同创作、共有行使规则是主给付 → `合作创作合同·审查`；
- 隐名执笔、对外以委托人名义表明作者身份 → `隐名执笔对外以委托人名义表明作者身份→`；
- 功能性委托设计、工业/UI 验收指标为主，作品权属只是附带一句 → `或`；
- 技术方案、专利或技术秘密的委托开发 → `委托合同目录下的委托技术开发主文件且用户未锁定本类型→` 或 `委托开发合同·审查`；
- 计算机软件委托开发或软著登记变更为主给付 → `软件委托开发合同·审查` 或 `软件著作权转让合同·审查`；
- 复制、印刷、定作而无独创性表达 → `复制印刷定作而无独创性表达→` / `印刷` / `按图定作实物`；
- 无文本、本类型条件已谈妥、要出己方稿 → `知产委托创作·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁或权属诉讼已立案 → `或知产争议专项。` 或知产专项。

委托违法内容、明知侵害在先作品仍要“改到能签”，或把挂靠、规避监管改成可履行结构：只出告知，不改写成可履行路径。

## 建立审查坐标

确认：使用者与授权；单方立场（委托人侧或受托人侧择一）；相对方；全文及任务书/权属清单/作者声明/素材清单版本；用户按知产货架还是委托货架审；作品类型与委托目的；权属三选一是否已写；使用主体是否含关联公司；是否含登记、再许可、邻接权；实际作者是否签字；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的稿酬、权项、期限用 `【待填】`，不编造。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `知产委托创作·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议或知产。未签且目标是评改已有知产侧委托创作文本，才进入本任务。

### 1. 类型锁死与同名切开

标题、核心给付、货架陈述与对价方式一致才继续。委托侧同名、现成转让/许可、合作创作、代笔、设计、开发负触发。

### 2. 主体、实际作者与职务作品

签约名、履行名、使用主体、付款名分列。公司签约须闭合实际作者。名委实雇先识别劳动关系。

### 3. 归属约定与权利清单

三选一写死；第 10 条列举；第 29 条锁定未列明权利；人身权不得转让。

### 4. 权属时点、登记与发表

登记是对抗和举证，不是权利产生或合同生效要件。作者栏不得改成委托人。验收满意不得写成合同成立条件。

### 5. 使用范围、再许可与素材

委托目的写入定义；超目的另签并付费；关联公司须列为使用主体；通用模板不因交付而转让。

### 6. 对价、修改轮次与定金

稿酬与权属对价分列。禁止“直到甲方满意”。定金不超过百分之二十。

### 7. 格式条款、违法内容与争议

无核验引文则法律结论字段停止。违法创作停笔。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把无约定权属写成委托人已取得全部财产权、把署名权买断写成已生效、把违法或明知侵权内容改成可履行、坚持用本技能改完委托侧同名或现成转让整案。
- `字段停止`：法域、动态规则、实际作者权属链条、国资内部决议、登记路径未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。

生存级金额或个人无限连带且用户拒绝升级：停止“可以签署”建议。
