## **第一步：合同类型（法律性质）分析**

* **法律定性**：注册商标许可合同是商标注册人许可他人在约定期间、地域、商品/服务范围内使用其注册商标，被许可人支付使用费的合同。权属不发生移转。适用《商标法》第43条、《商标法实施条例》、《最高人民法院关于审理商标民事纠纷案件适用法律若干问题的解释》（2020修正）。
* **三种许可（必须写清，未写清按条款实质认定）**：
* **独占使用许可**：仅被许可人可使用，注册人自己也不得使用。
* **排他使用许可**：仅被许可人与注册人可使用，注册人不得再许可第三人。
* **普通使用许可**：注册人可自用，也可再许可他人。
* **易混淆辨析**：
* **许可 vs 转让**：许可到期权利回归；无共同申请核准转让程序。出现“永久买断”“权属归被许可人”的，按转让还是许可重新定性。
* **许可 vs 特许经营**：特许经营叠加经营资源、运营指导、费用结构，受《商业特许经营管理条例》规制；单纯商标许可不当然构成特许。
* **许可 vs OEM/贴牌加工**：境内贴牌出口可能不构成商标法意义上的“使用”，但合同仍应按许可范围和商品流向写清。
* **效力**：
* **备案不是生效要件**。未备案不影响合同效力（当事人另有约定除外），但**未经备案不得对抗善意第三人**。
* 许可标的被宣告无效的，专用权视为自始不存在，许可基础动摇；被撤销、期满未续展的，嗣后不能再许可。
* 出质后未经质权人同意不得许可（《民法典》第444条）。


## **第二步：合同主体（交易对手）分析**

* **许可人**：须为注册人或经注册人明确授权且合同允许转许可的人。转许可必须有“允许被许可人再许可”的条款或单独授权书。
* **被许可人**：须具备使用该商标商品的经营资格；特殊商品（药品、食品等）另审生产许可。被许可人必须保证商品质量。
* **集体商标/证明商标**：证明商标许可后**3个月内**报国家知识产权局备案并公告；集体成员变化须变更注册事项。被许可人/使用人还受使用管理规则约束。
* **关联主体**：质权人、在先被许可人、商标共有人、实际使用的关联公司。普通许可若允许子公司使用，须写成转许可或列入被许可主体清单。
* **诉权结构**（审查时就要对齐许可类型）：独占被许可人可单独起诉；排他被许可人可与注册人共同起诉，注册人不起诉时可自行起诉；普通被许可人须经注册人**明确授权**才能起诉。


## **第三步：合同标的（交易对象）分析**

* **商标与商品范围**：注册号、图样、类别、核定商品/服务。许可使用的商品不得超出核定范围，超出部分不产生商标法上的许可效力。
* **使用方式**：生产、销售、广告、互联网展示、店铺招牌、域名/账号名称、包装、进出口。未写明的方式，被许可人不得擅自行使。
* **地域与渠道**：全国/省域/线上特定平台。线上未限制的，默认可能覆盖信息网络；要限制电商渠道须正面列举。
* **期限**：不得超过专用权剩余期限；专用权续展后是否自动顺延必须约定。许可期内注册人有续展义务。
* **权利负担**：在先独占/排他许可与本次许可是否冲突；质押、无效撤销风险；相同近似商标是否一并许可（避免注册人自己或第三人用近似标挖空商誉）。


## **第四步：合同程序（交易步骤）分析**

* **备案**：许可人应当将商标使用许可**报商标局备案并由商标局公告**。备案材料通常包括许可人、被许可人、许可期限、商品/服务范围。独占、排他尤其应备案，否则后手普通许可或转让的善意第三人可以对抗。
* **标识义务**：经许可使用他人注册商标的，必须在商品上标明**被许可人的名称和商品产地**。漏标不仅是合同问题，也是法定义务。
* **质量监督程序**：许可人应当监督被许可人商品质量；被许可人应当保证质量。合同要落到抽检、送样、整改、召回，而不是口号。
* **内部决策**：独占许可接近处分重大资产，公司内部决议、国资评估可能被要求。
* **到期退出**：停止使用、销毁或交回带标包装、变更字号/店铺/账号、注销备案。


## **第五步：交易结构设计（风险规避方案）**

* **对价**：入门费 + 按销售额提成，或固定年费。提成须定义净销售额、审计权、最低提成。
* **排他性对价**：独占/排他应有最低使用量或最低许可费，否则注册人商誉被“占坑不用”，还有三年不使用撤销风险。
* **转许可控制**：默认禁止。确需转许可的，书面事先同意 + 转许可备案 + 质量连带。
* **与转让、出质的协调**：许可期内注册人转让的，已备案许可可对抗受让人；未备案则可能无法对抗善意受让人。独占被许可人应把备案和“转让须通知并承继许可”写成交割条件。
* **文本形态**：**许可合同 + 商标及商品清单 + 图样使用规范 + 质量标准/抽检规则 + 备案授权书**。


## **第六步：宏观风险预警与尽调指引**

* **高频争议**：许可类型约定不明导致再许可；未备案被对抗；超核定商品或超地域使用；质量失控连累注册人被撤三或侵权；许可期覆盖续展空窗；普通许可却起诉维权无授权。
* **尽调清单**：
* [ ] 注册效力、续展、无效撤销案件
* [ ] 已备案许可和质权
* [ ] 近似商标是否由同一主体控制
* [ ] 被许可人生产资质与过往质量处罚
* [ ] 是否构成特许经营（经营资源+指导+费用）
* **重大风险红旗**：许可范围写成“品牌全部权利”；不备案却约定独占；允许转许可但不限制质量；注册人保留任意解除且不退费；被许可人不能标注自己名称产地。
