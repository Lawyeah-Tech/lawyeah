# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的使用费、提成、抽检频次、期限；把已失效《合同法》、1982 年商标法施行条款、1999 年实施细则或 2002 年未修正解释写入结论；把未约定许可方式写成独占；把未备案写成合同未生效或当然无效；把许可备案写成商标法第 42 条核准转让；把“不得标注名称产地”写成可放行；把注册商标转让、特许经营或 OEM 当成已完成的本类型审查。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查注册商标许可合同（知识产权相关合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、1982 年商标法施行条款、1999 年实施细则或 2002 年未修正解释时，记噪声，不得写入 `L#`。1997 年备案办法的“县级存查”和专利备案 3 个月不得写入现行程序。

## 3. 类型与加载路径

父级 `知识产权相关合同`，子级 `注册商标许可合同`。定性理由、易混切开结果（注册商标转让 / 特许经营 / OEM / 经销 / 著作权许可 / 专利实施许可）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。未打开 `注册商标转让合同·审查` method。

## 4. 主体、注册状态、负担与文本版本

主体表：签约名、履行名、付款名、发票名、授权签字人、共有注册人。状态表：注册号、图样、类别、核定商品、续展、无效/撤销、质权、在先独占/排他许可。版本表：正文、商标及商品清单、图样规范、质量标准、备案表草本、聊天确认；冲突并列。未核注册证或共有人签署：该签署能力字段停止。

## 5. 许可方式、范围、备案与品质

核心给付是否仅为使用权而非权属过户；普通 / 排他 / 独占是否点名并与自用、再许可、诉权一致；地域、渠道、使用方式；期限是否截在专用权存续期内；许可人报商标局备案并公告的协作义务和未备案不得对抗善意第三人；抽检/送样/召回；名称与产地标识。缺口标 `G#`。不输出核准转让主路径。

## 6. 格式条款、出质与强制规范

是否构成格式条款；提示说明痕迹。出质后未经质权人同意不得许可。强制规范只按民法典第 153 条和合同编通则解释第 16 条区分，不用失效口诀。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把“独家”未定义就当独占，不得把备案写成权属过户，不得把品质监督停在口号。

## 9. 谈判与签署提醒

谈判顺序：先红线（权属过户错位、许可方式与自用/再许可/诉权打架、不备案却主张独占对抗、禁止标注名称产地、质量条款空洞拒改、出质后无同意仍许可），再必须改（三类点名、备案协作与逾期后果、抽检召回、转许可禁止、续展与库存退出），最后可优化。签署提醒：注册证、图样规范、商品清单、质量标准、备案表草本入附件；签字生效与备案公告分列。不指导倒签或补假备案。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书或效力保证，也不是注册商标转让、特许经营或 OEM 审查。
