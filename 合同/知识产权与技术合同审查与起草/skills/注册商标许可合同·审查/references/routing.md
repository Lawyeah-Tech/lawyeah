# 边界与路由

本技能只审查 **知识产权相关合同 / 注册商标许可合同** 的待签、权属不移转的注册商标使用许可文本。中文展示名是「审查注册商标许可合同（知识产权相关合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或复制 `注册商标转让合同·审查` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 永久买断、权属归被许可人、共同申请核准转让、受让人自公告之日起享有专用权、近似商标一并转让 | `注册商标转让合同·审查`。不得删掉过户句后按许可审完，也不得把许可备案改成核准转让 |
| 经营资源许可 + 统一经营模式 + 特许经营费或经营手册 | 本套导航的类型切开步骤 重新定性。不得当单纯商标许可放行 |
| 按指定商标或图样加工交货，许可只是贴标一句 | `主给付是按定作人图样或指定商标加工交货，许可只是贴标一句→` |
| 买断转售或经销权为主给付，商标许可只随货一句 | `买断转售经销权，商标许可只是随货一句→` |
| 著作权财产权许可或转让为主给付 | `著作权许可使用合同·审查` / `著作权转让合同·审查` |
| 专利实施许可为主给付 | `专利实施许可合同·审查`。不得互套备案规则 |
| 软件分发或自用许可为主给付 | `软件许可合同（分发许可模式）·审查` / `软件许可合同（自用许可模式）·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `注册商标许可合同·起草` |
| 已签未争、只问履约节点或备案进度 | 本套导航的履约步骤 |
| 已成争，或用户要侵权 / 无效诉讼策略 | `或知产争议专项。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

许可正文里夹带一小段“期满可协商转让”：专条交接 `注册商标转让合同·审查`，许可方式、备案对抗、品质监督条款可继续审。夹带一小段经销进货：专条点名 `买断转售经销权，商标许可只是随货一句→`，不代审转售价。用户坚持本技能把转让、特许经营或 OEM 整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
