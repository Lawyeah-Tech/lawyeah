# 植物新品种权转让合同·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **植物新品种权转让合同** 己方稿，出稿后用本类型硬闸自审。交付草稿、未决项、自审风险表和自审后修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文显示名为「植物新品种权转让合同·起草」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性或登记成功保证、保证品种权不被宣告无效或强制许可、保证种子生产经营许可一定核发。

## 本类型硬闸

1. **转让 ≠ 许可**：正像是把**已经授权（或已申请）的特定植物新品种权**全部让与对方。转让后转让人不得再以品种权人身份生产、销售该品种繁殖材料，也不得再许可第三人。仅授权实施、约定独占／排他／普通、许可期限、续期、届满交回繁殖材料或许可人可继续自用并再许可 → `植物新品种权许可合同·审查`。不得删掉许可句后硬套本技能。
2. **书面、对外批准、转让自登记之日起生效**：当事人应当订立书面合同，并向国务院农业农村、林业草原主管部门登记，由该主管部门公告；**转让自登记之日起生效**。合同成立、价款支付、证书复印件交付，都不等于权属已经变动。中国单位或个人就其在境内培育的植物新品种向外国人、外国企业或外国其他组织转让申请权或品种权的，**应当先经**国务院农业农村、林业草原主管部门**批准**。禁止“先交繁殖材料／亲本后补批准或登记”。
3. **禁止抄专利权转让**：不得打开 `专利权转让合同·审查` 的 method。登记机关是国务院农业农村、林业草原主管部门，不是国务院专利行政部门。不得套专利号、权利要求、专利年费或“自专利局登记之日起生效”。保护期限按 2025 年条例：自授权公告之日起，木本、藤本植物 25 年，其他植物 20 年；不得沿用知识库旧口径 20／15 年。
4. **品种身份与名称不可改**：标的须锁定授权品种名称、品种权号、授权日、作物种类、保护期届满日。授权名称经授权后即为通用名称；转让不改变品种名称，受让人销售、推广必须沿用授权名称。
5. **繁殖材料与 DUS／亲本**：权属变更不是唯一给付。必须约定种子、种苗、插条等繁殖材料的数量、纯度、发芽率或成活率，并设田间观察期核对特异性、一致性、稳定性。杂交品种未写清是否移交亲本及选育技术秘密的，标必须改；亲本秘密不得在主文展开。
6. **权属、共有、在先许可与出质**：转让人须是登记册上的品种权人（或申请权人）。职务育种、委托／合作育种、共有人未闭合则签署能力字段停止。已向第三人作独占许可或品种权已出质的，签署前清理或扣减对价，否则红线。共有人之一可单独实施或作普通许可，不等于可以单独卖断全部品种权。
7. **年费、种性、转基因与种质资源**：变更登记完成前须写明年费缴纳主体；欠缴年费可致品种权终止。种性退化须可归因、可验证，不得写成签收即合格。涉及转基因的，须另核农业转基因生物安全证书和生产经营许可。向境外提供繁殖材料须遵守种子法关于向境外提供种质资源的规定；未批出境只告知、不改成可履行路径。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签植物新品种权转让正文，尚未签署，尚未成争，核心给付是特定授权品种（或品种权申请权）的权属让与，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 仅授权实施、独占／排他／普通许可、许可期限、使用费、届满收回 → `植物新品种权许可合同·审查`；
- 已授权专利的权利让与、须向国务院专利行政部门登记才发生权利变动 → `专利权转让合同·审查`；
- 专利申请权让与 → `专利申请权转让合同·审查`；
- 集成电路布图设计专有权让与 → `集成电路布图设计专有权转让合同·审查`；
- 计算机软件著作权让与 → `计算机软件著作权转让合同·审查` 或 `软件著作权转让合同·审查`；
- 笼统技术转让、专利／申请权／技术秘密／品种权混在一章未拆 → `技术转让合同·审查`；
- 现有未公开技术秘密买断、无品种权号 → `技术秘密转让合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁或品种权权属／侵权已立案 → `或知产争议专项。` 或知产／争议专项。

未经批准向境外转让境内培育品种，或未批向境外提供种质资源／繁殖材料：只出告知，不改写成可履行路径。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方是否境外主体；全文及附件／品种权证书副本／繁殖材料移交清单版本；品种名称与品种权号；是买断还是许可；农业类还是林业类；是否转基因；是否杂交及亲本是否一并交；共有、职务育种、在先许可或出质；年费是否缴至当年；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。意见中不得复述亲本配组、选育参数或未公开育种技术，只引用载体编号。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价款、数量、期限用 `【待填】`，不编造。

## 起草模式

本原子只承担本类型起草。待签评改转 `植物新品种权转让合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `植物新品种权转让合同·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。下表把本类型硬闸改成正文必写、附件必附或禁止出现。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 主给付是已经授权（或已申请）的特定植物新品种权全部让与；转让后转让人不得再以品种权人身份生产、销售该品种繁殖材料，也不得再许可第三人。
- 书面合同；向国务院农业农村、林业草原主管部门登记并由该主管部门公告；转让自登记之日起生效。
- 向外国人、外国企业或外国其他组织转让境内培育品种的申请权或品种权，须先经上述主管部门批准。
- 锁定授权品种名称、品种权号、授权日、作物种类、保护期届满日；转让不改变品种名称。
- 约定繁殖材料数量、纯度、发芽率或成活率，并设田间观察期核对特异性、一致性、稳定性。
- 杂交品种写清是否移交亲本及选育技术秘密。
- 变更登记完成前写明年费缴纳主体；种性退化须可归因、可验证。
- 涉及转基因的，另核农业转基因生物安全证书和生产经营许可。

### 附件必附

- 品种权证书副本（名称、品种权号、授权日）。
- 繁殖材料移交清单（数量、纯度、发芽率或成活率）。
- 对外转让时的主管部门批准文件。

### 禁止出现

- 独占／排他／普通许可、许可期限、续期、届满交回繁殖材料作为主给付。
- 合同成立、价款支付或证书复印件交付等于权属已经变动。
- “先交繁殖材料／亲本后补批准或登记”。
- 套专利号、权利要求、专利年费或“自专利局登记之日起生效”。
- 保护期沿用 20／15 年（现行：木本、藤本 25 年，其他 20 年）。
- 改变品种授权名称；亲本秘密在主文展开。
- 共有人之一单独卖断全部品种权。
- 签收即种性合格。
- 未批向境外提供种质资源／繁殖材料写成可履行。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 本任务起草并自审；已签履约 → 本套导航履约步骤；已成争 → 合同争议或知产。未签且目标是评改已有植物新品种权转让文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。许可、专利权转让、申请权转让、布图转让、软件著作权、笼统技术转让、技术秘密买断负触发。

### 2. 主体、权属、共有与在先许可

签约名、履行名、付款名、发票名分列。品种权人、职务／合作育种、共有、出质、在先独占许可必须闭合或字段停止。

### 3. 品种身份、名称与保护期

正式名称、品种权号、授权日、剩余保护期。不得改名。保护期按 25／20 年核算。

### 4. 审批、登记与合同生效切开

民事成立 vs 转让自登记之日起生效。对外转让先批准。禁止先交后补批。

### 5. 繁殖材料、亲本、DUS 与年费

移交清单、观察期、亲本是否在范围内、年费衔接。签收不等于种性合格。

### 6. 对价、后续改进／EDV、转基因与种质资源

支付节点挂钩登记申请、登记完成和田间验证。EDV 分步实施，不得写成“当地尚未采纳所以可忽略”。未批出境停笔。

### 7. 格式条款与强制规范

无核验引文则法律结论字段停止。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效或保证登记一定办成、把许可改成买断外壳、把未批对外转让或未批出境种质改成可履行、坚持把亲本配方写入主文对外传阅。
- `字段停止`：法域、动态规则、农业／林业主管分工、权属或共有未核验、转基因安全证书、种质资源出境审批。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
