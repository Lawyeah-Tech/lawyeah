## 节点 2　主体、专业能力与利益冲突

### 2.1 主体表

建表：签约名、履行名、付款名、发票名、授权签字人。名称不一致不自动合并。课题组、工作室无法人资格：未经所属法人或非法人组织授权或认可的，不得写成已由该组织承担责任。

口头「我们老板同意了」不得写成已授权。国资、高校、上市公司内部决议或成果转化审批未附：该签署能力字段停止，不写成「可以盖章」。

### 2.2 专业能力披露，不是强制持证

技术中介认的是对拟交易技术的评价能力，不是全国统一的「技术经纪人证」。未披露专业领域、既往同类撮合经验或利益冲突声明的，标必须改。

修改句方向：

- 列**专业领域与最低经历**（如项目负责人须具备【待填】年相关工艺或专利交易评价经历），不要假装法律强制持某证。
- 中介人应书面声明：与拟介绍的第三人无可能影响公正性的股权、顾问或共同开发关系；是否同时接受相对方委托（「双头吃」）须事前书面披露并取得同意。
- 隐瞒关联或双边委托：委托人可解除并拒绝支付相应报酬。

不得写成：法律规定必须持技术经纪人资格证合同才生效。文号缺失标 `G#`。

## 节点 3　标的：联系介绍 + 履行专门服务

### 3.1 拟促成的技术合同与工作范围

审查清单，缺一项则该字段不得写成已闭环：

1. 拟促成的第三人技术合同类型：开发、许可或转让，至少写明一种；可同时列候选，但不得用「一切技术交易」代替。
2. 技术项目或成果识别信息：名称、专利号或技术秘密摘要编号、与已有权利的界限。不得在未签保密安排前要求写入核心工艺原文。
3. 联系介绍工作：画像、检索、初步联络、组织洽谈、协助本约条款对接。
4. **对履行提供的专门服务**（本类型身份条款）：交付节点提醒、资料交接见证、验收会议协调、履行障碍联络。写清期限（如本约生效后【待填】个月）和响应时限。
5. 明确**不是**中介人自己实施技术、调试达标或交付工作成果。出现这些作为主给付：回到节点 1，负触发 `知产技术服务·审查`。

专门服务缺位且用户确认只要报告机会：负触发 `撮合专利许可只收中介费不自己实施也不自己许可→`，不要在本任务补一句专门服务充作已改类型。

### 3.2 促成的定义

「促成」是指委托人与第三人签署**具备履行条件的正式技术合同**（书面，标的、对价、交付或许可范围可履行），并按约定完成生效手续（如须登记的权利变动，登记完成可作为后一笔报酬节点，不代替成立）。

| 文本写法 | 动作 |
| --- | --- |
| 未定义促成，或写成「达成合作意向即付全额」 | 必须改：促成=正式技术合同成立（及如有约定的生效） |
| 框架协议、MOU、备忘录、意向书单独触发全额报酬 | 必须改：上述文件至多触发已发生必要费用或【待填】比例筹备费，不得视为已促成 |
| 「谈判满【待填】次即视为促成」 | 必须改：谈判次数不是法定促成 |
| 中介保证第三人签约 | 红线删除保证。可写勤勉义务和介绍家数下限，不保证成交 |

### 3.3 不保证第三人经济效益

技术中介的对价是撮合与专门服务，不是本约实施结果。

| 文本写法 | 动作 |
| --- | --- |
| 保证第三人技术投产、年利润、固定降本或一定拿到专利 | 红线删除。可保留：中介人书面披露已知技术风险，不构成实施担保 |
| 鉴于条款写「保证成功转化」 | 首部必须改；鉴于不得充当承诺 |
| 差价模式（低于心理价的差额分成） | 必须改：写明心理价、计算基数、是否含税、披露义务；不得把未披露差价伪装成固定比例 |

最强反方：委托人主张「不保证转化等于可以随便介绍一项无效专利」。修改句必须保留书面权属与风险报告、隐瞒免酬。

## 节点 4　中介报酬（硬闸）

解释第 39 条把经费和报酬拆开。第 963、964 条管促成与未促成。运行时核验后再落法律结论。

### 4.1 三项分列

必须分项写。缺一项标必须改。

1. **报酬**：促成正式技术合同后支付。建议分阶段：本约成立且首期款到账后付【待填】%；约定的登记或交付见证完成后付【待填】%；专门服务期满无未完联络义务后付尾款。数字用 `【待填】`。
2. **活动经费**：订约前联系介绍的通信、交通、必要调研。无约定或约定不明：由**中介人承担**。约定由委托人承担但无数额或计算方法：只付从事中介活动支出的**必要费用**，并设科目、单据和上限。
3. **未促成时的必要费用**：未促成不得请求报酬；可按约定请求必要费用。未写约定的，修改句补科目和审核标准，不编造「依法必得全部差旅」。

| 文本写法 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 「签字当日支付全额佣金，无论技术合同是否签署或生效」 | 红线删除。改成分阶段，绑正式本约成立（及如有的生效/登记） | 已经合法锁死对价 |
| 报酬、经费、必要费用混在一个总价里 | 必须改：分项 | 已包含所以不必写 |
| 「差旅按惯例实报实销」且无上限 | 必须改：列科目、单据、上限；或改包干 | 惯例=解释第 39 条默认 |
| 用户要求意见写「经费依法由委托人负担」 | 现有依据不支持。解释第 39 条无约定由中介人承担 | 实施条例第 111 条仍有效 |
| 仅在拟签署的第三人技术合同中写中介条款，报酬不明 | 必须改：在本中介合同写清数额或计算；并提示解释第 39 条第 3 款平均负担风险 | 已经由某一方单独付清 |
| 本约无效或被撤销后「中介费一律作为本约损失」 | 必须改：解释第 41 条——中介无过错且中介条款继续有效的，费用和报酬仍可请求；中介费不视为本约一方损失 | 本约无效中介必退 |

定金：必须使用「定金」二字才讨论罚则。约定超过主合同标的额百分之二十：超过部分不产生定金效力。无核验引文不得把 20% 写成现行法结论。

禁止编造比例、总额、差价。解释第 39 条允许报酬无约定时按劳务合理确定，本任务只给出分项修改句，不代算「合理」金额。

## 节点 5　如实报告、跳单与保密

### 5.1 书面如实报告（第 962 条）

中介人应当就与订立技术合同有关的事项向委托人如实报告。至少覆盖：第三人主体资格、已知权属或许可负担、职务发明或共有风险、技术成熟度与已披露的实施限制、是否同时接受相对方委托。

修改句必须要求**书面**报告，并作为报酬节点附件。口头「权属没事」「对方很靠谱」不得写成已尽 962。

故意隐瞒重要事实或提供虚假情况，损害委托人利益：不得请求报酬并应当承担赔偿责任。解释第 40 条（运行时核 2020 修正）口径为未促成不得报酬、可要必要费用；隐瞒则免酬并赔偿。修改句把免酬、返还已收报酬和直接损失写进违约后果。

中介人与第三人串通夸大参数：按第 154 条、第 962 条停笔告知，不改写成「双方知情即可继续」。

### 5.2 跳单（第 965 条）

第 965 条：委托人在接受中介人的服务后，利用中介人提供的交易机会或者媒介服务，绕开中介人直接订立合同的，应当向中介人支付报酬。

这是**报酬请求**，不是交易效力规范。

| 文本写法 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 「绕开中介签署的技术合同一律无效」 | 必须改：删除无效效果；改为仍应支付约定报酬 | 965 已经让本约无效 |
| 「委托人跳单，中介必然胜诉」 | 删除胜诉承诺。写构成要件：接受服务 + 利用本中介提供的机会或媒介 | 法定必胜 |
| 未写受保护名单、期限或「利用」标准 | 必须改：附件列第三方名单及介绍日期；保护期【待填】；须利用本中介信息 | 不写等于无限捆绑一切成交 |
| 委托人自行合法获知同一第三人 | 必须改：写入例外——能证明缔约前已合法知悉且未利用本中介信息的，不构成本条 | 自行检索也算跳单 |
| 独家且禁止委托人自行成交，即使未利用中介信息 | 可谈但须标风险：超出 965 的部分按约定审查，不得写成法定 | 独家=965 |

已成跳单争议：节点 0 转出，本任务不写诉讼策略。

### 5.3 保密与核心信息释放

中介过程会接触委托人需求画像和第三人技术摘要。未约定保密范围、期限、转披露对象的，标必须改。

修改句方向：

- 核心 Know-how、未公开权利要求对照表，须在签署本中介合同及保密安排**之后**、按阶段向经确认的潜在相对方披露。
- 中介人不得把委托人需求或第三人秘密当作其他客户案例。
- 专门服务期内接触的本约履行信息，适用同一保密安排。

未签保密安排即要求「先把全套工艺发给中介」：字段停止，不写可履行的披露路径。

## 节点 6　格式条款、免责与争议

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 免责与限额

可约定赔偿上限（如已收报酬的【待填】倍）。本约实施后的市场变化、预期利润可排除。

下列不得排除，排除则必须改：

- 造成对方人身损害；
- 因故意或者重大过失造成对方财产损失（第 506 条，运行时核验）；
- 隐瞒或虚假陈述；
- 泄露技术秘密或违反保密约定。

「中介人对介绍对象的一切技术与法律风险不承担任何责任」且无书面报告义务、无 506 除外：必须改。

### 6.2 格式条款

为重复使用而预先拟定、订立时未与对方协商。依据示范文本制作，不当然排除格式条款。免责、全额预付、跳单无效、管辖、单方解释权等异常条款须有足以引起注意的标识。小字、夹在附件、仅网络勾选：不得写成已尽提示义务。

### 6.3 违约、解除、争议

逾期支付报酬按日计违约金；隐瞒走免酬并赔偿。只有「依法承担违约责任」视为必须改。构成违约不等于当然解除。违约金不是必得金额。

本类型解除走合同约定和合同编通则，**不得**把委托章任意解除写成技术中介双方的法定权利。用户坚持按委托章解释并代签本约：负触发 `一般委托代签本约→`。

争议解决：出现仲裁条款，不得改写成「应向某法院起诉」。或裁或诉、机构不明：标待核，改成单一机构或单一法院连结点。

通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。

### 6.4 技术进出口与国家秘密

限制进出口技术或国家秘密项目：未取得许可或审查文件的，履行字段停止。修改句把批准作为生效或开始介绍的条件。不得写「先出境或先披露核心技术，许可证后补」。

## 节点 7　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

打开已加载的 `框架.md`，按六步逐段对照正文。`基本面.md` 用于校验类型、主体、标的、报酬红旗，不代替本节点出句。

| 步 | 动作 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题用技术中介或技术经纪；主体全称；鉴于写明联系介绍并对履行提供专门服务，不写保证投产收益 | 标题或鉴于修改句 |
| 交易条款 | 拟促成合同类型；专门服务内容与期限；促成=正式技术合同；报酬分阶段；经费与必要费用分列 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 书面如实报告；965 范围与自行获知例外；隐瞒免酬；保密与分阶段披露；专门服务响应 | 可执行后果句或删除句 |
| 尾部 | 签署权限、附件清单（受保护名单、费用报销标准、诚实信用承诺书、书面报告模板） | 生效与附件修改句 |
| 语言 | 正说加反说；盯死促成 vs MOU、报酬 vs 经费 vs 必要费用、专门服务 vs 动手做技术、定金/预付款 | 替换空词的句子 |
| 常见问题 | 签字即全额；跳单无效；无专门服务却按本类型改完；保证收益；口头尽调 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（不是本类型、签字即全额拒删、收益保证拒删、虚假参数、未批进出口仍要履行、跳单写成交易无效仍要放行）；
- `必须改`：可谈但签署前要落句（促成定义、经费分列、965 例外、书面报告、专门服务内容、保密阶段）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级金额或个人无限连带且用户拒绝升级：停止「可以签署」建议。
