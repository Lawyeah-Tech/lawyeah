# 边界与路由

本技能只审查 **技术类合同 / 技术中介合同** 的待签、以联系介绍并对第三人技术合同履行提供专门服务为核心给付的文本。中文展示名是「审查技术中介合同（技术类合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开 `撮合专利许可只收中介费不自己实施也不自己许可→` 或 `知产技术服务·审查` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 仅报告技术转让订约机会并媒介签约，不对履行提供专门服务；或父级被锁在中介合同货架 | `撮合专利许可只收中介费不自己实施也不自己许可→` |
| 中介人自己让与专利权、专利申请权或技术秘密；主文件是技术转让本约 | `技术转让合同·审查` |
| 已有技术的实施或使用许可本约 | `技术许可合同·审查` |
| 以技术知识解决特定技术问题，调试、改进、排除故障或交付工作成果 | `知产技术服务·审查` |
| 狭义技术服务作为已独立成册的细分主文件 | `技术服务合同（狭义）·审查` |
| 技术培训、教员与学员条件为主给付 | `技术培训合同·审查` |
| 就特定技术项目只出可行性或技术方案意见，不促成第三人签约 | `知产技术咨询·审查` |
| 新技术、新产品、新工艺、新品种或新材料及其系统尚待研究开发 | `技术开发合同·审查` |
| 房屋买卖或租赁中介 | `房屋买卖或租赁中介→` |
| 职业介绍或猎头撮合 | `职业介绍或猎头→` |
| 婚姻介绍 | `婚姻中介→` |
| 建设工程招投标中介 | `建设工程招投标中介→` |
| 一般委托代签本约、费用预付或任意解除主路径 | `一般委托代签本约→` |
| 以自己名义受让再转出 | `以自己名义受让再转出→` |
| 已有可读待签文本要评改 | `技术中介合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径或跳单诉讼 | `或知产争议专项。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

技术中介正文里夹带一小段已有背景技术说明：专章交接对应本约原子；联系介绍与专门服务条款可继续审。用户坚持本技能把仅报告机会、技术服务或本约整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
