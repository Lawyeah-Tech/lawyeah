## 本类型硬闸

1. **转让 ≠ 许可**：正像是把**已经登记**的布图设计专有权全部让与。让与人停用，不得再复制、投入商业利用或再许可第三人。仅授权使用、约定期限、入门费+按晶圆/芯片提成、许可人可自用或再许可 → `集成电路布图设计专有权许可合同·审查`。标题写转让、正文全是许可范围和届满交回：负触发许可，不删许可句后硬套本技能。
2. **登记（权利变动）**：专有权经登记产生；未登记布图不能当专有权卖。转让须书面，双方须向国家知识产权局办理著录项目变更；**专有权转让自登记之日起生效**。合同成立 ≠ 权利已转。受让人正式取得以变更合格通知书或登记簿记载为准。许可备案、科技部门技术合同认定登记，都不是本类型权利变动要件。
3. **专有权范围**：让与的是对受保护布图**全部或者其中任何具有独创性的部分进行复制**，以及将受保护布图、含该布图的集成电路或者含该集成电路的物品**投入商业利用**。保护不延及思想、处理过程、操作方法或者数学概念。必须写清布图名称、登记号、登记日期、类别和剩余保护期。不得把专利权利要求、工艺库授权、软著源码或技术秘密配方写成范围。
4. **剩余保护期与独创性**：保护期十年，自登记申请日或者在世界任何地方首次投入商业利用之日起算，以较前日期为准；无论是否登记或投入商业利用，自创作完成之日起十五年后不再保护。买到即到期为红线。让与人须担保独创性（自己的智力劳动成果，且创作时不是公认常规设计）；撤销视为自始即不存在，须有价款与数据返还安排。
5. **电子数据与验收**：名义过户必须配 GDSII、电路图、逻辑图、设计说明书、掩膜版制造数据等可验证交付；须在约定 EDA 环境打开并达约定指标。对价建议绑签署、提交变更申请、变更合格+GDS 验证。禁止黑盒、禁止拟制签收即合格、禁止恶意修改数据或埋设后门。
6. **共有、在先许可与跨境**：未经其他共有人同意，任一共有人不得转让其所持份额，也不得订立独占或排他许可。在先独占/排他许可、质押或查封未清理，不得写成清洁买断。中国单位或者个人向外国人转让，办理转让登记须提交国务院有关主管部门允许转让的证明；未批不得先交核心数据。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

禁止打开或复制 `专利权转让合同·审查`（专利权转让）、`计算机软件著作权转让合同·审查`（软件著作权转让）、`技术秘密转让合同·审查`（技术秘密转让）的 method。本类型主路径是**布图登记号 + 条例专有权两项 + 著录变更 + GDS 验证**，不是专利年费/无效、不是软著登记对抗、不是秘密性自动解密。

## 工作边界

正触发：已有可读待签布图设计专有权转让正文，尚未签署，尚未成争，核心给付是已登记专有权的权利让与，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 仅授权复制或商业利用、约定期限、许可人可再许可或届满收回 → `集成电路布图设计专有权许可合同·审查`；
- 已授权专利的权利让与、专利号/年费/无效宣告是主轴 → `专利权转让合同·审查`；
- 专利申请权让与 → `专利申请权转让合同·审查`；
- 计算机软件著作权让与为主给付 → `计算机软件著作权转让合同·审查` 或 `软件著作权转让合同·审查`；
- 现有未公开技术以保密维持的权利让与、无布图登记号 → `技术秘密转让合同·审查`；
- 笼统技术转让、专利/布图/秘密混章未拆 → `技术转让合同·审查`；
- 植物新品种权让与 → `植物新品种权转让合同·审查`；
- 订立时尚不存在、须研究开发 → `技术开发合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁或布图专有权撤销/侵权已立案 → `或知产争议专项。` 或知产/争议专项。

以转让为名出卖未登记布图、未批向外国人转让，或把明知常规设计/侵权受让改成可履行买断：只出告知，不改写成可履行路径。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及电子数据清单/证书/变更委托版本；是否已登记及登记号；是买断还是许可；申请日、首次商业利用日、创作完成日；共有与在先许可/质押；GDS 验证；向外国人转让或出口管制；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。意见中不得复述 GDS、网表或掩膜数据，只引用清单编号。

## 起草模式

本原子只承担本类型起草。待签评改转 `集成电路布图设计专有权转让合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `集成电路布图设计专有权转让合同·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。下表把本类型硬闸改成正文必写、附件必附或禁止出现。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 主给付是已经登记的布图设计专有权全部让与；让与人停用，不得再复制、投入商业利用或再许可。
- 转让须书面；双方须向国家知识产权局办理著录项目变更；专有权转让自登记之日起生效。
- 受让人正式取得以变更合格通知书或登记簿记载为准。
- 写清布图名称、登记号、登记日期、类别和剩余保护期。
- 让与范围写全：复制全部或任何具有独创性的部分，以及投入商业利用。
- 独创性担保；撤销视为自始不存在时的价款与数据返还。
- 对价绑签署、提交变更申请、变更合格＋GDS 验证。
- 向外国人转让须先取得国务院有关主管部门允许转让的证明。

### 附件必附

- 布图登记号／登记证书材料。
- GDSII、电路图、逻辑图、设计说明书、掩膜版制造数据等可验证交付清单。
- 向外国人转让时的主管部门允许转让证明。

### 禁止出现

- 许可范围、届满交回、入门费＋按晶圆／芯片提成作为主给付。
- 未登记布图当专有权出卖。
- 合同成立即权利已转；许可备案或技术合同认定登记写成权利变动要件。
- 把思想、处理过程、操作方法、数学概念，或专利权利要求、工艺库、软著源码、技术秘密配方写成范围。
- 买到即到期。
- 黑盒、拟制签收即合格、恶意改数据或后门。
- 未经其他共有人同意转让份额或订独占／排他许可。
- 在先独占／排他许可、质押或查封未清理写成清洁买断。
- 未批先交核心数据。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 本任务起草并自审；已签履约 → 本套导航履约步骤；已成争 → 合同争议或知产。未签且目标是评改已有布图专有权转让文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。许可、专利权转让、软著转让、技术秘密转让、开发负触发。

### 2. 主体、证书权利人、共有

签约名与证书记载权利人是否同一。共有人、职务布图、国资决议未闭合则字段停止。

### 3. 专有权范围与剩余保护期

两项专有权是否写全；是否误写思想/工艺/专利；登记号与起算日是否可算剩余保护期。

### 4. 登记与著录变更

合同生效与权利变动分列。变更申报书、谁提交、几日内、未完成的价款与解除后果。

### 5. 电子数据、验收与后门

清单、EDA 验证、分期节点、恶意改数据条款。

### 6. 独创性、负担、850、跨境

撤销安排、在先许可/质押、禁研回授、向外国人转让证明。

### 7. 格式条款与强制规范

无核验引文则法律结论字段停止。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。框架错配步骤按 method 节点 8 重映射。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把许可改成买断外壳、把未登记卖权或未批向外国人转让改成可履行、坚持在意见中粘贴完整 GDS。
- `字段停止`：法域、动态规则、登记状态、保护期起算日、向外国人转让批准、权属或在先许可未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
