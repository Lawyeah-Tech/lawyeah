# 边界与路由

本技能只审查 **技术类合同 / 集成电路布图设计专有权许可合同** 的待签、已登记布图设计专有权许可文本。中文展示名是「审查集成电路布图设计专有权许可合同（技术类合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或复制 `集成电路布图设计专有权转让合同·审查`、`专利实施许可合同·审查` 的 method。
