# 边界与路由

本技能只审查 **技术类合同 / 技术服务合同（狭义）** 的待签文本。中文展示名是「审查技术服务合同（狭义）（技术类合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开或复制 `知产技术服务·审查`、`技术培训合同·审查`、`技术中介合同·审查`、`知产技术咨询·审查` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 对指定学员做特定项目专业技术训练和技术指导，教员/学员/课时/考核是主给付 | `技术培训合同·审查` |
| 为委托人与第三人订立技术合同做联系、介绍或履行辅助，报酬绑促成签约 | `技术中介合同·审查` |
| 可行性论证、技术预测、专题调查、分析评价报告，不保证把问题做掉 | `知产技术咨询·审查` |
| 用户要走父级笼统技术服务，或驻场运维/人力外包且无已特定化单一问题 | `知产技术服务·审查` |
| 订立时尚未掌握的研究开发，交付新配方、中试批次或新系统 | `技术开发合同·审查` 或 `委托开发合同·审查` / `合作开发合同·审查` |
| 常规加工、定作、修理、复制、测试、检验，不构成解释第 33 条专业技术问题 | `按既有图纸加工定作实物→负触发` |
| 勘察、设计、施工、工程量、竣工验收 | `或对应工程原子；` 或对应工程原子 |
| 人格从属、考勤指挥、按人天结算，无特定技术问题 | `或劳动专项，不改写成可履行派遣。挂靠违法分包未批限制进出口仍要跨境交付：只出告知，不改写成可履行路径。` |
| 用户声明按委托章审，要费用预付或任意解除 | `委托合同货架按处理事务费用预付任意解除起草的同名《技术服务合同》→` |
| 让与或许可已有专利/技术秘密为主给付 | `技术转让合同·审查` 或 `技术许可合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `技术服务合同（狭义）·起草` |
| 已签未争、只问进场、验收或付款节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或知产争议专项。` 或对应专项领域 |
| 破解原厂、侵害技术秘密已立案 | 刑事或知产专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

本约正文夹带一小段传授或一小段咨询备忘：传授按第 883 条附随义务继续审；咨询备忘专章交接 `知产技术咨询·审查`。用户坚持本技能把培训、中介、咨询、父级服务、开发或派遣整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
