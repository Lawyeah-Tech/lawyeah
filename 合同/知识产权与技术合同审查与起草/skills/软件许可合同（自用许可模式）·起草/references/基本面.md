## **第一步：合同类型（法律性质）分析**

* **法律定性**：软件自用许可合同是软件著作权人许可**最终用户在约定安装范围和用途内自行使用**软件、用户支付许可费的合同，多为普通（非专有）许可。核心给付是**内部使用权**，不含向第三人再分发、再许可。适用《著作权法》第29条，《计算机软件保护条例》，《民法典》第876条。电子订单、最终用户许可协议（EULA）与线下主合同，定性相同。
* **易混淆辨析**：
* **自用许可 vs 分发许可**：自用只覆盖最终用户自己的复制、安装、运行；备份通常限于必要份数。分发许可才允许嵌入出货和向终端转授。用户把自用软件预装到对外销售的设备上，或提供SaaS给第三人，属于超范围，按侵权加违约处理。
* **自用许可 vs 转让**：永久授权、一次付清也不等于权属转移。用户不得再转让著作权，通常也不得向集团外转让许可席位，除非合同明示“许可转让”。
* **简单许可 vs 复杂许可**：前者无定制、功能以网页或试用展示为准，条款短；后者部署在用户环境，叠加实施、培训、维保，但**主给付仍是许可**，实施服务应另条计价，避免整份合同被当成技术开发或技术服务。
* **许可 vs SaaS**：纯云端登录、数据在许可人侧的，更接近服务；本类型指标的是把软件复制到用户控制的环境（本地或用户云租户）。混同会导致验收、中断责任和数据返还条款错配。
* **效力认定**：
* **未明确许可的权利不得行使**。未写信息网络向第三人提供、未写修改、未写再许可的，用户不得行使。
* 点击同意、勾选EULA可成立普通许可；B端高额、永久或含定制的，应另有书面主合同，EULA不得与主合同冲突。
* 格式条款限制对方主要权利的，须依法提示说明；免除己方责任、加重对方责任的无效风险按《民法典》评估。


## **第二步：合同主体（交易对手）分析**

* **许可人**：著作权人或经授权的发行商。代理商签约须有再许可授权，否则用户只拿到债权、拿不到对抗权属的许可。
* **被许可人**：最终用户本身。集团公司、分公司、外包商、驻场供应商是否纳入“使用人”，必须点名。未点名的关联公司安装构成超范围。
* **关联主体**：
* **实施方、运维外包**：可接触软件，但不是被许可人，须受同等禁止再分发约束。
* **终端个人用户**：员工账号数量计入席位。
* **支付方与使用方分离**（集团统采）：合同写清被许可主体清单。
* **签约能力**：点击同意的相对人是否为有权账号；线下合同的授权代表。面向消费者时适用消保法格式条款规则。


## **第三步：合同标的（交易对象）分析**

* **许可范围六要素**：软件名称与版本、**许可数量（用户数/并发/CPU/实例/站点）**、安装地点或实例标识、用途（内部生产经营，禁止经营性再提供）、期限、是否可升级。
* **权项**：安装、运行、必要备份；一般不含源码、修改、反向工程（法定互操作例外）、再许可、分发、出租。
* **部署形态**：单机、局域网、用户私有云。跨数据中心灾备是否占用额外许可，须约定。
* **权利负担**：第三方组件、开源、密码模块进出口；行业软件的资质不影响许可效力，但影响合法使用。


## **第四步：合同程序（交易步骤）分析**

* **成立**：电子订单支付完成或线下签字。复杂许可常“主合同 + 订单 + EULA + 服务单”。
* **交付与开通**：介质/下载/许可证密钥；实施上线不是权属交割，只是使用条件。
* **许可管理**：席位增减走订单；审计安装点和账号。
* **期满或解约**：停用、卸载、删除备份、交回密钥；数据导出窗口。许可终止不等于服务商可以扣留用户自有数据。
* **消费者撤回/七天无理由**：面向个人的电子交易可能适用网销规则，B端定制许可通常排除。


## **第五步：交易结构设计（风险规避方案）**

* **对价**：按席位/年的订阅，或买断+年度维保。订阅期满使用权消灭；买断须写清版本范围和是否含升级。定金不超过主合同标的额**20%**。
* **简单许可**：功能以产品说明和试用为准，排除个性化开发承诺。
* **复杂许可**：实施、培训、维保与许可费分列；定制代码权属单写，默认不改变基础软件权属。
* **审计**：许可人可审计安装数量，超额自动形成新订单或按倍数补费。
* **文本形态**：**主许可/EULA + 订单（席位、站点、期限）+ 产品说明 + 服务水平（如有）+ 数据处理/保密**。不要附分发用的OEM出货表。


## **第六步：宏观风险预警与尽调指引**

* **高频争议**：集团统装未买够席位；把自用软件提供给客户远程使用；买断后拒付维保却要求继续升级；EULA与主合同冲突；许可人远程停服与用户数据。
* **尽调清单**：
* [ ] 许可人是否有权发放自用许可
* [ ] 席位/站点/实例的计量方式
* [ ] 使用人是否含关联公司、外包
* [ ] EULA与主合同、订单的效力位阶
* [ ] 是否禁止再分发、再许可、经营性SaaS化
* [ ] 期满卸载与数据导出安排
* **重大风险红旗**：自用合同出现“可预装销售”“可再授权下游客户”；无安装点或席位上限；“永久全部知识产权归用户”；面向消费者却用纯B端免责模板。
