## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

支持切开的规范（法律结论须运行时复核）：

- 商标法（2019 修正）第 43 条：注册人可通过签订商标使用许可合同许可他人使用；许可人监督质量，被许可人保证质量；商品上必须标明被许可人名称和产地；许可人报商标局备案并由商标局公告；未经备案不得对抗善意第三人。
- 商标民事解释（2020 修正）第 3 条：独占 / 排他 / 普通三类定义。
- 同解释第 4 条：独占可单独起诉；排他可共同起诉或注册人不起诉时自行起诉；普通须经注册人明确授权才能起诉。
- 同解释第 19 条：未经备案不影响合同效力，但当事人另有约定的除外。
- 同解释第 20 条：注册商标的转让不影响转让前已经生效的商标使用许可合同的效力，但许可合同另有约定的除外。
- 商标法第 42 条（负向切开）：转让须共同申请核准；近似商标一并转让；受让人自公告之日起享有专用权。本类型无此要件。
- 商业特许经营管理条例第 3 条：经营资源许可 + 统一经营模式 + 特许经营费。第 31 条：特许中的商标许可仍依商标法律办理。
- 民法典第 444 条：知识产权财产权出质后，未经质权人同意不得许可他人使用。

## 节点 2　主体、注册效力与权利负担

### 2.1 主体表

建表：签约名、履行名、付款名、发票名、授权签字人。名称不一致不自动合并。关联公司使用必须列入被许可主体清单或写成经书面同意的转许可，否则构成超范围使用。

许可人须为注册人或经注册人明确授权且本合同允许转许可的人。口头“我们老板同意了”不得写成已授权。国资、上市公司内部决议未附：该签署能力字段停止。共有注册人未全部签署：字段停止，不写成一方可处分全部。

### 2.2 注册效力

未核注册证、图样、类别、核定商品、续展日：不写“权属清洁、可以许可”。许可使用的商品不得超出核定范围；超出部分不产生商标法上的许可效力，修改句删除或改回核定清单。

集体商标、证明商标：还受使用管理规则约束。证明商标准许他人使用的，注册人应在许可后 3 个月内报国家知识产权局备案并公告（2023 年规定第 13 条）。集体成员变化应在 3 个月内申请变更注册事项。

### 2.3 在先许可、质权与近似商标

| 文本写法 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 未披露是否已有独占/排他许可 | 必须改：附件列在先许可的类型、范围、期限、是否备案 | 未提及就是没有 |
| 已有在先独占仍再签独占或排他 | 红线：取得在先被许可人书面放弃或合同终止证明，否则不签 | 后签合同可以覆盖先手 |
| 已出质且无质权人书面同意 | 红线或字段停止：取得同意或解除质权后再许可 | 合同写了就可以用 |
| 注册人保留近似商标自用或另许可第三人 | 必须改：近似商标一并纳入本次许可，或书面承诺不在相同类似商品上使用/再许可近似标 | 主标独占即可不管近似标 |

## 节点 3　许可方式、范围与期限（硬闸）

### 3.1 普通 / 排他 / 独占必须点名

用解释第 3 条原文定义写入合同，不要自造词。

| 文本写法 | 动作 |
| --- | --- |
| 只写“独家授权”“全权许可”“品牌授权” | 必须改：点名独占或排他，并写清注册人能否自用、能否再许可 |
| “独家普通许可” | 必须改：二者互斥。选普通则删除独家；选独占/排他则删除普通 |
| 标题写独占，正文允许许可人再许可关联公司 | 冲突并列；按解释第 3 条重写至一致，否则不得宣称已点名 |
| 未约定类型 | 不得默认独占。必须改出三类之一；谈不拢则字段停止 |

诉权必须同步改：

- 独占：被许可人可以自己的名义起诉。
- 排他：可与注册人共同起诉；注册人接到书面通知后【待填】日内不起诉的，被许可人可自行起诉。
- 普通：被许可人提起诉讼须事先取得注册人的明确书面授权；授权范围、费用和赔偿归属另条。

普通许可却写“自行维权、无需注册人同意”：必须改。要么补单独诉讼授权，要么升级排他/独占。

### 3.2 范围四要素

缺一不可：注册号 + 图样 + 类别；商品/服务必须落在核定范围内；地域/渠道（线下区域、电商平台、进出口）正面列举；期间写起止日，并写明专用权续展后是否自动顺延。

未列明的使用方式，被许可人不得行使。线上未限制的，修改句提示可能覆盖信息网络；要限制电商须正面列举平台。

期限不得超过专用权剩余期限。许可期内注册人有续展义务；续展费承担写清。许可期跨越续展空窗：必须改。

### 3.3 转许可

默认禁止。允许则写：事先书面同意、转许可合同不得低于本合同质量与标识条款、转许可须另行报商标局备案、被许可人对转许可使用人的质量承担连带责任。1997 年备案办法第 8 条只作栏目参考：通过被许可人再许可的，合同中应有允许再许可的内容或单独授权书。

## 节点 4　备案对抗与转让切开（硬闸）

### 4.1 备案不是生效要件

商标法第 43 条第 3 款：许可人应当报商标局备案，由商标局公告；未经备案不得对抗善意第三人。解释第 19 条：未经备案不影响效力，另有约定除外。

| 文本写法 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| “本合同自商标局备案公告之日起生效，未备案未生效” | 必须改：签字盖章后成立生效；备案是许可人在【待填】日内的义务。除非当事人书面选择把备案当作生效条件，并提示在备案完成前双方使用权、付款和备货风险 | 未备案当然无效 |
| “双方同意不备案”且主张独占可对抗后手 | 红线：删除“不备案”；独占/排他必须备案。普通许可也建议备案 | 意思自治可以放弃对抗 |
| 未写谁备案、几日内、费用、逾期后果 | 必须改：许可人主办，被许可人【待填】日内提供身份与授权材料；费用由【待填】承担；逾期未备案的，独占/排他被许可人可中止支付未到期许可费并要求违约金【待填】 | 有第 43 条就够了 |
| 把许可备案写成“办理注册人变更/转让登记” | 负触发 `注册商标转让合同·审查`，或删除过户句后重新定性 | 备案就是过户 |
| 套用“生效之日起 3 个月内向国务院专利行政部门备案” | 必须改：删除专利机关和专利期限。改报商标局；期限用合同约定期日，不把专利办法第 5 条当商标法定期限 | 知产许可都是 3 个月 |

1997 年备案办法第 11 条不予备案情形（许可人不是注册人、图样不一致、超有效期、超核定商品等）只作审查清单：出现这些信号，修改句先改合同范围，不写“备案被拒则合同无效”。

证明商标：许可后 3 个月内报国家知识产权局备案并公告（2023 年规定第 13 条）。集体成员变化：3 个月内变更注册事项。

### 4.2 与转让切开

本类型不产生第 42 条的权属变动。

| 信号 | 动作 |
| --- | --- |
| 主给付是核准转让、公告之日起享有专用权、一并转让近似商标 | 负触发 `注册商标转让合同·审查`。不打开其 method，不按许可改完 |
| 许可期内许可人可自由转让且不通知 | 必须改：转让前书面通知；受让人承继本许可。提示解释第 20 条：转让原则上不影响转让前已生效许可，另有约定除外 |
| 未备案的独占，许可人同时准备转让 | 红线：签约后立即备案；尾款或交标与备案公告挂钩。未备案可能无法对抗善意受让人 |
| “交付商标电子图稿即转移专用权” | 必须改：交付图稿不等于权属转移 |

## 节点 5　品质监督、标识与对价（硬闸）

### 5.1 品质监督

商标法第 43 条第 1 款是法定义务，不是倡导。

必须具备：质量标准附件（国标/行标/企标编号）；抽检频次与送样；不合格下架和整改期限；召回费用承担；许可人现场检查权。只有“甲方有权监督质量，乙方应当保证质量”视为必须改。

独占/排他占坑不用：必须改最低使用量或最低许可费，并约定被许可人的使用记录配合义务，降低连续三年不使用被撤销的风险。授权确权规定（2020 修正）第 26 条：他人经许可使用可认定为商标法第四十九条第二款所称使用；仅有许可行为而无实际使用，不认定为使用。

### 5.2 名称与产地标识

第 43 条第 2 款：必须在使用该注册商标的商品上标明被许可人的名称和商品产地。

| 文本写法 | 动作 |
| --- | --- |
| “被许可人不得标注自己的名称或产地，统一标注许可人” | 红线删除。可另约同时标注许可人商标权属声明，但不得抹掉被许可人名称产地 |
| 未写标识义务 | 必须改：包装、吊牌、电商详情页均须标明被许可人名称和产地 |
| 允许改绘文字图形 | 必须改：图样以附件为准，不得自行改变显著特征 |

### 5.3 对价

入门费、年费、提成基数、开票、审计分列。未给出的数字写 `【待填】`。禁止编造销售额。定金必须使用“定金”二字才讨论罚则；超过主合同标的额百分之二十的部分不产生定金效力。无核验引文不得把 20% 写成现行法结论。

市场销售不佳、平台封店、未获行政许可，不是不可抗力。

## 节点 6　无效、维持、格式条款与维权

### 6.1 无效与撤销

商标法第 47 条：宣告无效的注册商标专用权视为自始即不存在；对已履行的使用许可合同原则上不具追溯力，但注册人恶意造成损失应赔偿；不返还使用费明显违反公平原则的，应当全部或部分返还。修改句必须把这三层写全，不得只写“无效后互不退费”或“无效后一律全额返还”。

被撤销、期满未续展：嗣后不得再许可。许可人续展、应对撤三、不得擅自注销或放弃。

### 6.2 格式条款与免责

为重复使用而预先拟定、订立时未与对方协商。依据示范文本制作，不当然排除格式条款。免责、限责、任意解除不退费、管辖等异常条款须有足以引起注意的标识。小字、夹在附件、仅网络勾选：不得写成已尽提示义务。

“许可人对商标有效性、质量后果不承担任何责任”且无第 43 条监督义务：必须改。人身损害、故意或重大过失财产损失的免责无效（民法典第 506 条）。

### 6.3 违约与争议

超范围使用、擅自再许可、质量事故、不标注名称产地、拖欠许可费必须分别有可执行后果：停止使用、销毁或交回带标包装、违约金【待填】。只有“依法承担违约责任”视为必须改。违约金不是必得金额，禁止写“不得调整”。

争议解决：出现仲裁条款，不得改写成“应向某法院起诉”。或裁或诉、机构不明：标待核，改成单一机构或单一法院连结点。专属管辖可能：只标红旗，不选定唯一法院充作法律意见。

## 节点 7　退出与库存

到期或解除后：立即停止生产带标商品；【待填】日内申报库存；限时售完且不得再生产；更换招牌、店铺名称、账号、域名中的商标元素；配合办理备案变更或注销。未约定库存处理：必须改。到期后继续销售构成侵权风险，不得写成“售完为止、无期限”。

打开已加载的 `框架.md`，按六步逐段对照正文。`基本面.md` 用于校验类型、主体、标的、程序、结构和红旗，不代替本节点出句。

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（实为转让或特许经营、许可方式与自用/再许可打架拒改、不备案却主张独占对抗、禁止标注名称产地、出质后无同意仍许可、质量条款空洞拒改、倒签或补假备案）；
- `必须改`：可谈但签署前要落句（三类点名、备案协作与逾期后果、抽检召回、转许可禁止、续展、库存、普通许可诉讼授权）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级金额或个人无限连带且用户拒绝升级：停止“可以签署”建议。
