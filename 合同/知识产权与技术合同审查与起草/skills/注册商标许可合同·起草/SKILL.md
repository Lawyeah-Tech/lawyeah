# 注册商标许可合同·起草

## 任务目标

在单一立场下，只按已谈妥条件起草 **注册商标许可合同** 己方稿，出稿后用本类型硬闸自审。交付草稿、未决项、自审风险表和自审后修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文显示名为「注册商标许可合同·起草」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、把注册商标转让改成许可或把许可改成核准过户、把特许经营或 OEM 整案改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **普通 / 排他 / 独占必须点名**：标题或首部用司法解释三类定义写清。独占＝约定期间、地域和方式内仅一个被许可人使用，注册人自己也不得使用。排他＝仅许可一个被许可人，注册人可自用但不得再许可第三人。普通＝注册人可自用，也可再许可他人。禁止自造“独家普通许可”“品牌全权授权”。未写清：按条款实质看注册人能否自用、能否再许可；仍无法认定则该字段停止并必须改，不得默认写成独占。诉权必须对齐：独占可单独起诉；排他可与注册人共同起诉，注册人不起诉时可自行起诉；普通须经注册人**明确授权**才能起诉。
2. **备案对抗，不是生效要件**：许可人应当将商标使用许可报商标局备案并由商标局公告。未备案不影响合同效力（当事人另有约定除外），但**未经备案不得对抗善意第三人**。独占、排他尤其应备案，否则后手普通许可或善意受让人可以对抗。修改句写清谁在【待填】日内提交、对方如何配合、逾期违约；独占可将尾款或交标与备案公告挂钩。禁止把备案写成“未备案则合同未生效或当然无效”，除非当事人有意把备案写成生效条件并已提示该选择的风险。禁止把许可备案改写成商标法第 42 条的核准转让、公告之日起权属变动。禁止套用专利实施许可备案办法的 3 个月法定期限。
3. **品质监督与产地标识**：许可人应当监督被许可人使用该注册商标的商品质量；被许可人应当保证质量。合同必须落到抽检频次、送样、不合格下架、整改期限、召回费用，而不是口号。经许可使用他人注册商标的，必须在商品上标明被许可人的名称和商品产地。约定“不得标注被许可人名称产地”或漏标：红线或必须改。图样、颜色、字体不得自行改绘。
4. **许可与转让切开**：本类型只让渡约定范围内的使用权，专用权仍登记在许可人名下，到期权利回归。出现“永久买断”“权属归被许可人”“共同向商标局申请核准转让”“受让人自公告之日起享有专用权”“近似商标一并转让”等权属过户主给付 → 负触发 `注册商标转让合同·审查`。不得删掉过户句后按许可审完，也不得打开或复制该原子 method。许可期内注册人转让的，转让原则上不影响转让前已生效的许可（另有约定除外）；未备案则可能无法对抗善意受让人。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签注册商标使用许可正文，尚未签署，尚未成争，核心给付是注册人或有转许可权的人许可对方在约定期间、地域、商品/服务范围内使用已注册商标并收取使用费，权属不移转，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主给付是注册商标专用权移转、共同申请核准转让、公告之日起权属变动 → `注册商标转让合同·审查`；
- 经营资源许可 + 统一经营模式 + 特许经营费/经营手册，核心是加盟 → 本套导航的类型切开步骤 重新定性，不得当单纯商标许可放行；
- 主给付是按定作人图样或指定商标加工交货，许可只是贴标一句 → `主给付是按定作人图样或指定商标加工交货，许可只是贴标一句→`；
- 主给付是著作权财产权许可或转让 → `著作权许可使用合同·审查` / `著作权转让合同·审查`；
- 主给付是专利实施许可 → `专利实施许可合同·审查`。不得把商标备案对抗规则套到专利，也不得把专利 3 个月备案套回来；
- 买断转售、经销权，商标许可只是随货一句 → `买断转售经销权，商标许可只是随货一句→`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问备案进度、抽检日、续展日 → 本套导航的履约步骤；
- 已催告、解除、索赔、侵权或无效诉讼、仲裁策略 → `或知产争议专项。` 或知识产权争议专项。

出质后未经质权人同意仍要许可、明知无注册专用权仍要对外许可、把特许经营改成可履行加盟：只出告知，不改写成可履行路径。用户坚持保留：整体停止。

## 建立审查坐标

确认：使用者与授权；单方立场（许可人侧或被许可人侧择一）；相对方；全文及商标清单 / 注册证 / 图样规范 / 质量标准版本；注册号、类别、核定商品是否可见；普通 / 排他 / 独占是否点名；地域、渠道、使用方式；许可费结构；备案协作；品质监督与产地标识；转许可；在先许可或质权；是否夹带权属转让或特许三特征；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的使用费、提成、抽检频次、期限用 `【待填】`，不编造。

## 起草模式

本原子只承担本类型起草。待签评改转 `注册商标许可合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `注册商标许可合同·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

起草必写：普通／排他／独占按司法解释三类定义点名，并写清注册人能否自用、能否再许可；诉权对齐——独占可单独起诉，排他可共同起诉或注册人不起诉时自行起诉，普通须经注册人明确授权才能起诉；备案写成许可人报商标局并公告的协作义务，未备案不影响合同效力但不得对抗善意第三人；品质监督落到抽检频次、送样、不合格下架、整改期限、召回费用；商品上标明被许可人名称和产地；专用权仍登记在许可人名下，到期权利回归。
附件必附：注册号、图样、类别、核定商品／服务清单；质量标准或图样规范。
禁止出现：独家普通许可、品牌全权授权；未备案则合同未生效或当然无效（当事人有意把备案写成生效条件的须另提示风险）；许可备案写成核准转让或公告之日起权属变动；永久买断、权属归被许可人、共同向商标局申请核准转让、受让人自公告之日起享有专用权、近似商标一并转让；不得标注被许可人名称产地。许可不得写成权属已转移。出质后未经质权人同意仍要许可、明知无注册专用权仍对外许可：只告知，不起可履行稿。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 本任务起草并自审；已签履约 → 本套导航履约步骤；已成争或侵权/无效诉讼策略 → 合同争议。未签且目标是评改已有许可文本，才进入本任务。

### 1. 类型锁死与转让切开

标题、核心给付与对价方式一致才继续。权属转让、特许经营、OEM、著作权许可或专利实施许可负触发。

### 2. 主体、注册效力与权利负担

许可人须是注册人或有书面转许可权的人。共有注册人未全部签署：该签署能力字段停止。未核注册证或法律状态：不写“权属无争议”。已出质未经质权人同意：停笔或字段停止。

### 3. 许可方式、范围与期限

普通 / 排他 / 独占点名；商标注册号、图样、类别、核定商品四要素可核验；地域和渠道正面列举；期限不得超过专用权剩余期限。

### 4. 备案对抗与转让登记切开

备案写成许可人报商标局并公告的协作义务和对抗安排，不写成合同未备案不生效，也不写成权属变动。

### 5. 品质监督、标识与对价

抽检、送样、召回、名称产地标识。独占/排他设置最低使用费或最低使用量，降低撤三风险。

### 6. 转许可、维权资格、无效与格式条款

默认禁止转许可。普通许可无明确授权不得写成自行起诉。无效后已履行许可费原则上不当然返还，恶意和显失公平例外必须写明。

### 7. 退出、库存与争议

到期停止使用、限时售完、更换招牌账号、配合注销备案。不选定唯一法院充作意见。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证商标必然有效、把权属过户当许可放行、把出质后无同意许可或无专用权对外许可改成可履行、把特许经营改成可先加盟后备案。
- `字段停止`：法域、注册法律状态、共有人签署、质权人同意、证明/集体商标管理规则、动态规则未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书、侵权或无效诉讼策略，或已锁他类。
