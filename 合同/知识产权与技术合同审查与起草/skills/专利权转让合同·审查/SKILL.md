# 专利权转让合同·审查

## 任务目标

在单一立场下，只审查 **技术类合同 / 专利权转让合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文显示名为「专利权转让合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证专利永不被无效。

## 本类型硬闸

1. **登记生效 ≠ 登记对抗**：专利法（2020 修正）第十条第三款，专利权转让自登记之日起生效。禁止写成“签字即权属转移，未登记仅不得对抗善意第三人”。合同债权可成立；未登记，受让人尚未取得专利权。民法典第 335 条土地承包经营权登记对抗结构不得套用。
2. **权属无争议**：转让人须是专利登记簿上的当前专利权人。共有除另有约定外，转让须全体共有人同意（第十条之外的共有行使走第十四条第二款）。职务发明争议、质押/保全、欠缴年费、无效或权属程序未闭合：该字段停止，不写成可以过户。
3. **与专利申请权 / 许可切开**：已授权专利权的全部所有权让与才是本类型。尚在审查、只有申请号 → `专利申请权转让合同·审查`。所有权不转移、只给实施权、走备案 → `专利实施许可合同·审查`。概括技术转让或多标的混装 → `技术转让合同·审查`。
4. **转让不破在先许可**：解释第 24 条，转让不影响成立前已订立的实施许可或技术秘密转让。独占/排他必须披露；普通许可须写清是否继受。成立后让与人继续实施，受让人可要求停止，另有约定除外。
5. **无效不当然退费**：专利法第四十七条，已履行的转让合同原则上无追溯力；恶意或明显违反公平才全部或部分返还。禁止引用失效实施条例“宣布无效应当返还价款”。
6. **向境外转让须办手续**：第十条第二款。中国单位或者个人向外国人、外国企业或者外国其他组织转让，须依照法律、行政法规办理手续。未批不得写成可履行跨境过户。
7. **纸面转让须能实施**：第八百七十条保证合法拥有、完整、无误、有效。须写清著录项目变更配合、年费衔接、证书与实施所必需的配套资料。只改登记名称、不交 know-how：必须改。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签专利权转让正文，尚未签署，尚未成争，核心给付是把已经授权且仍有效的专利权全部所有权让与受让人，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 尚未授权、只有申请号或处于实审/复审 → `专利申请权转让合同·审查`；
- 所有权不转移，只约定实施范围、许可方式、备案 → `专利实施许可合同·审查`；
- 一份文本同时卖专利、申请和技术秘密，或标题就是概括《技术转让合同》 → `技术转让合同·审查`；
- 标的是技术秘密而不是已授权专利 → `技术秘密转让合同·审查`；
- 已有技术的实施或使用许可（非专利） → `技术许可合同·审查`；
- 订立时尚待研究开发 → `技术开发合同·审查`；
- 整份只是商标专用权转让 → `注册商标转让合同·审查`；
- 公司资产包或股权交易里夹带一项专利、主轴不是专利本约 → `或相应公司并购原子；` 或相应公司/并购原子；
- 无文本、本类型条件已谈妥、要出己方稿 → `专利权转让合同·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁、无效宣告或权属诉讼 → `或知产争议专项。` 或知产/争议专项。

以转让为名买卖国家秘密、未批限制出口技术，或把权属争议改成可履行过户：只出告知，不改写成可履行路径。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及附件/登记簿副本版本；专利号、申请日、授权公告日；登记簿权利人是否与签约名一致；是否共有、职务发明、质押、欠费、无效程序；在先许可；谁办著录项目变更；价款是否绑登记；是否向境外主体转让；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价款、期限用 `【待填】`，不编造。

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `专利权转让合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议或知产。未签且目标是评改已有专利权转让文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。申请权、许可、概括转让、技术秘密、开发负触发。

### 2. 权属无争议

登记簿权利人、共有人签章、职务发明、质押/保全、年费。未闭合则字段停止。

### 3. 标的唯一化

专利名称、专利号、申请日、授权公告日、剩余保护期、法律状态。建议附最新登记簿副本。

### 4. 登记生效

著录项目变更的义务人、期限、文件、费用、不配合后果。拆开合同生效与权利变动。禁止登记对抗表述。

### 5. 在先许可、继续实施、侵权追溯

披露许可；登记后让与人停用；转让前后侵权索赔归属。

### 6. 对价、无效、境外、资料

价款绑登记节点；第四十七条退费分轨；境外审批；证书与配套资料、年费衔接。

### 7. 格式条款与强制规范

850 禁质疑有效性必须改。无核验引文则法律结论字段停止。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把未登记写成已取得权属仅不能对抗第三人、把权属争议或未批境外转让改成可履行过户、坚持保留“保证永不无效且一律退费”或 850 禁质疑条款。
- `字段停止`：法域、动态规则、登记簿、共有协议、质押同意、进出口目录、国家秘密审批未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
