# 边界与路由

本技能只审查 **技术类合同 / 专利权转让合同** 的待签、已授权专利权卖断文本。中文展示名是「审查专利权转让合同（技术类合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 尚未授权，只有申请号，处于受理、实审或复审 | `专利申请权转让合同·审查` |
| 所有权不转移，只给实施权，约定独占/排他/普通和备案 | `专利实施许可合同·审查` |
| 一份文本同时卖专利、申请和技术秘密，或标题就是概括技术转让 | `技术转让合同·审查` |
| 标的是技术秘密而不是已授权专利 | `技术秘密转让合同·审查` |
| 已有技术的实施或使用许可（非本专利卖断） | `技术许可合同·审查` |
| 订立时尚待研究开发 | `技术开发合同·审查` |
| 整份只是商标专用权转让 | `注册商标转让合同·审查` |
| 公司资产包或股权交易夹带一项专利，主轴不是专利本约 | `或相应公司并购原子；` 或相应公司/并购原子 |
| 无文本、本类型条件已谈妥、要出己方稿 | `专利权转让合同·起草` |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或知产争议专项。` 或对应专项领域 |
| 无效宣告、权属诉讼或侵权诉讼已立案 | 知产或争议专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

专利权转让正文里夹带一小段配套技术秘密交付或历史普通许可安排：专章可继续审；若核心给付变成许可或申请权，整案转出。用户坚持本技能把申请权、许可或概括技术转让整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
