# 边界与路由

本技能只审查 **技术类合同 / 技术秘密转让合同** 的待签、现有未公开技术秘密权利让与文本。中文展示名是「审查技术秘密转让合同（技术类合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 仅授权使用；让与人可自用并再许可第三人；期限届满收回；对价称使用费且可续期 | `技术秘密使用许可合同·审查` |
| 已授权专利的权利让与；须向国务院专利行政部门登记才发生权利变动 | `专利权转让合同·审查` |
| 专利申请权让与；申请号、申请日是权利变动主轴 | `专利申请权转让合同·审查` |
| 笼统《技术转让合同》，标的未锁定技术秘密载体，或专利/申请权/秘密未拆章 | `技术转让合同·审查` |
| 已有技术的概括实施或使用许可主文件 | `技术许可合同·审查` |
| 专利实施许可为主给付 | `专利实施许可合同·审查` |
| 订立时技术成果尚不存在，须研究开发 | `技术开发合同·审查` |
| 委托开发作为已独立成册的细分主文件 | `委托开发合同·审查` |
| 双方共同投资并分工参与研究开发 | `合作开发合同·审查` |
| 以技术知识解决特定技术问题，不交核心配方/源码 | `知产技术服务·审查` |
| 特定技术项目可行性、技术预测、工艺评价、FTO | `知产技术咨询·审查` |
| 计算机软件著作权让与为主给付 | `计算机软件著作权转让合同·审查` 或 `软件著作权转让合同·审查` |
| 已有可读待签文本要评改 | `技术秘密转让合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或知产争议专项。` 或对应专项领域 |
| 商业秘密侵权、权属诉讼或刑事立案 | 知产或争议专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

技术秘密转让正文里夹带一小段专利实施许可或软件著作权让与：专章交接对应原子；秘密买断条款可继续审。用户坚持本技能把许可、专利转让、开发或服务整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
