## **第一步：合同类型（法律性质）分析**

* **法律定性**：软件分发许可合同是软件著作权人许可被许可人（多为厂家、集成商、渠道）在约定期限和范围内**复制、集成、再分发**软件，由被许可人将软件随自身硬软件销售或以其他方式提供给最终用户，并支付许可费的合同。核心给付是**带再分发权的使用权**，权属不转移。适用《著作权法》第29条，《计算机软件保护条例》，《民法典》第876条。可参照技术转让、许可节，但审查轴是**许可范围与分发链条**，不是开发验收。
* **易混淆辨析**：
* **分发许可 vs 自用许可**：分发许可的必要权项含复制、发行（及约定范围内的信息网络提供），并允许向最终用户转授有限使用权；自用许可通常限定安装点和内部使用，**禁止再许可和再分发**。把自用模板拿来签OEM，或把分发合同写成“仅限被许可人内部使用”，都会导致履约不能或越权分发。
* **分发许可 vs 软件著作权转让**：分发不改变权属；许可人仍可在未授专有的范围内自行或再许可他人。对价按数量/流水提成的，几乎不可能是转让。
* **分发许可 vs 技术开发**：即便附带定制、联调，主给付仍是分发权。定制模块的权属要单列，不能用开发合同的“验收合格知识产权归甲方”吞掉许可人的基础软件。
* **效力认定**：
* **未明确许可的权利不得行使**。未写发行权、再许可、嵌入特定硬件的，被许可人不得出货。
* 专有分发许可宜书面并备案，否则难以对抗许可人另授其他厂家。
* 许可人责任限制、质量担保免责有效，但不得免除故意或重大过失造成人身损害等法定不得排除的责任。


## **第二步：合同主体（交易对手）分析**

* **许可人**：软件著作权人或经其授权可再许可分发的主体。核登记证书、权属链、是否已被专有分发给第三人。
* **被许可人**：通常为硬件厂商、整机厂、软件集成商、渠道。须具备约定渠道的经营资格；向境外分发可能触发技术出口。
* **关联主体**：
* **最终用户**：通过被许可人获得终端许可（EULA），不是本合同当事人，但本合同必须规定EULA必备条款和责任切断。
* **下级渠道、OEM、ODM、经销商**：未经授权不得再分发。
* **开源权利人、第三方组件权利人**：分发闭源产品时的合规义务主体。
* **签约能力**：集团内多家工厂出货的，须把生产主体、销售主体写入被许可人范围。


## **第三步：合同标的（交易对象）分析**

* **许可范围七要素**：被许可人、许可软件（名称+版本）、期限、**授权产品（嵌入的硬件/软件SKU）**、地域、许可模式（专有/排他/普通）、许可用途（预装、捆绑、独立零售、云分发）。缺“授权产品”是分发合同最大漏洞。
* **权项**：复制、发行、必要的修改（适配）、向最终用户授予自用许可。一般不当然包含源代码、再开发、商标、开源双许可。
* **计费标的**：预装量、激活量、出货量、流水。计费对象必须可审计。
* **权利负担**：在先专有分发、开源义务、出口管制、专利交叉许可。软件著作权许可不当然包含实施专利。


## **第四步：合同程序（交易步骤）分析**

* **授权生效**：签字或付首期基础费后交付目标码/密钥/许可证书。
* **出货与报数**：按月/季申报授权产品出货或激活数量，许可人审计。
* **终端授权**：每份拷贝随附EULA；最终用户只获自用，不得再分发。
* **备案与进出口**：专有分发备案；跨境出货办技术出口、加密、行业许可。
* **期满**：停止复制出货，渠道库存处理（售完窗口或销毁），密钥关闭，但已售最终用户的自用许可通常存续——必须写明。


## **第五步：交易结构设计（风险规避方案）**

* **对价**：**基础许可费 + 按实际分发数量/流水提成**是本模式典型结构。最低提成承诺防止占权不出货。定金不超过主合同标的额**20%**。
* **专有分发的对价与收回**：约定最低出货量，未达标降为普通许可或解除专有。
* **审计与密钥**：远程激活、序列号与出货单核对；短交、瞒报的违约金按未报数量的倍数。
* **责任限制**：许可人可限制质量担保和违约金上限，但须保留权属无瑕疵保证；被许可人出货的产品责任与许可人软件缺陷要切割。
* **文本形态**：**主分发许可 + 授权产品清单 + 价格与提成表 + EULA模板 + 开源清单 + 审计条款 + 商标使用规范（如有）**。


## **第六步：宏观风险预警与尽调指引**

* **高频争议**：超出授权SKU预装；向未授权地域出货；瞒报数量；把分发权转给关联工厂；期满后渠道继续铺货；EULA缺失导致最终用户反向主张被许可人已“买断”。
* **尽调清单**：
* [ ] 许可人权属及是否已专有分发给他人
* [ ] 授权产品SKU、版本、预装方式
* [ ] 计费基数（出货/激活/流水）是否可核
* [ ] EULA是否禁止最终用户再分发
* [ ] 开源组件分发义务
* [ ] 跨境出货的技术出口与加密合规
* **重大风险红旗**：合同标题“软件许可”却无再分发权项；无授权产品清单；允许被许可人“任意再许可”；把源码分发权与目标码出货权混写。
