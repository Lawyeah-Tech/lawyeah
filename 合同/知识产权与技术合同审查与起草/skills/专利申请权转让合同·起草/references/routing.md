# 边界与路由

本技能只审查 **技术类合同 / 专利申请权转让合同** 的待签文本。中文展示名是「审查专利申请权转让合同（技术类合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 已授专利、专利号、授权公告日、专利证书、专利权人变更 | `专利权转让合同·审查` |
| 尚未提出申请，仅有技术交底、技术方案或“即将递交” | `技术转让合同·审查`；若主给付是秘密信息移交则 `技术秘密转让合同·审查` |
| 概括技术转让，标的同时含专利、申请与秘密且无法拆出本申请权专章 | `技术转让合同·审查` |
| 不移转申请人地位，只许可实施或使用 | `专利实施许可合同·审查`（专利实施许可）或 `技术许可合同·审查`（技术许可） |
| 仍在委托开发、合作开发，申请权尚未产生或归属未定 | `委托开发合同·审查` / `合作开发合同·审查` / `技术开发合同·审查` |
| 已有可读待签文本要评改 | `专利申请权转让合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、只问官费、答复日、变更进度 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或知产争议专项。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

本申请权转让正文里夹带一小段已授权专利或技术秘密：专章交接对应原子；本申请权条款可继续审。用户坚持本技能把专利权转让、技术秘密转让或实施许可整案改完：`目标停止`。
