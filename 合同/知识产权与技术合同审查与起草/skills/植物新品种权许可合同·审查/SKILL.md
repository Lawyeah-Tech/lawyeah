# 植物新品种权许可合同·审查

## 任务目标

在单一立场下，只审查 **技术类合同 / 植物新品种权许可合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文显示名为「植物新品种权许可合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、无效宣告或侵权诉讼策略、有效性保证、把植物新品种权转让改成许可或把许可改成权属过户、代办审批或许可证申请。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **许可 ≠ 转让**：本类型只让渡约定范围内的实施权（生产、繁殖、为繁殖而处理、许诺销售、销售、进出口、储存）。品种权人仍记载在证书上。出现“品种权归乙方所有”“办理品种权人变更／转让登记后生效”“转让价款”等权属过户主给付 → 负触发 `植物新品种权转让合同·审查`。不得删掉过户句后按许可审完，也不得把许可备案改写成条例第十一条的转让登记。
2. **审批必须点名，不得写成已经完成**：向境外提供繁殖材料，须遵守种子法关于对外提供种质资源的审批，不是“签了就能出境”。被许可人生产经营授权品种，须符合种子管理法律法规，通常应持有与作物类别相符的《种子生产经营许可证》。主要农作物品种对外销售／推广还取决于审定／登记范围。转基因须另核农业转基因生物安全证书。国有科研院所对外许可，转化审批未闭合则该签署能力字段停止。批准、许可证、审定写成条件或双方义务期限，不写成已经办完。
3. **与转让原子切开**：禁止复制 `植物新品种权转让合同·审查` 的登记过户主路径、境外转让批准清单或“转让自登记之日起生效”来完成本类型审查。许可合同原则上成立即生效；备案是农业农村／林草主管部门的行政手续与举证材料，**不是生效要件，也不是权属变动**。未备案不得写成合同未生效或当然无效。

配套必须点名：普通／排他／独占；许可期限不得超过剩余保护期（自授权公告之日起，木本、藤本植物 25 年，其他植物 20 年；知识库 15／20 年不得当现行法）。禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签植物新品种权许可正文，尚未签署，尚未成争，核心给付是品种权人或有分许可权的人许可对方在约定范围实施授权品种并收取使用费，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主给付是品种权或申请权权属转移、办理品种权人变更登记、转让价款 → `植物新品种权转让合同·审查`；
- 主给付是集成电路布图设计专有权许可 → `集成电路布图设计专有权许可合同·审查`；
- 主给付是计算机软件著作权许可 → `计算机软件著作权许可合同·审查`；
- 主给付是已授权专利实施许可 → `专利实施许可合同·审查`；
- 主给付是未公开技术秘密的使用许可 → `技术秘密使用许可合同·审查`；
- 标题是“技术许可”但标的不是已授权品种，或混有多类技术许可且无法拆出品种权实施条款 → `技术许可合同·审查`；
- 撮合品种许可、只收中介费、不自己实施也不自己许可 → `撮合专利许可只收中介费不自己实施也不自己许可→`（P1；专业版未装则 `unavailable`）；
- 尚待研发、不保证成果必然产生 → `技术开发合同·审查` / `委托开发合同·审查` / `合作开发合同·审查`；
- 提供技术意见或劳务性技术服务，不授予实施权 → `知产技术咨询·审查` / `知产技术服务·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `植物新品种权许可合同·起草`；
- 已签只问缴费日、原种交付日、备案进度 → 本套导航的履约步骤；
- 已催告、解除、索赔、无效宣告争讼、侵权诉讼或仲裁策略 → `或知产争议专项。` 或知识产权／种业争议专项。

禁止质疑有效性、无偿独占回授、搭售非必要物料、指导无证生产经营或未经审批向境外交付亲本：只出告知与删除句，不改成可履行违法结构。用户坚持保留：整体停止。

## 建立审查坐标

确认：使用者与授权；单方立场（许可人侧或被许可人侧择一）；相对方；全文及品种权证书／授权公告／繁殖材料清单版本；品种名称、品种权号、作物种类与法律状态是否可见；普通／排他／独占是否点名；地域、期限、行为范围（生产、繁殖、销售、进出口等）；使用费结构；备案协作义务；年费由谁缴纳；被许可人种子生产经营许可；审定／登记范围是否覆盖授权区域；是否向境外提供繁殖材料；是否转基因；是否夹带权属转让；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `植物新品种权许可合同·起草`；已签履约 → 本套导航履约步骤；已成争或无效／侵权诉讼策略 → 合同争议。未签且目标是评改已有许可文本，才进入本任务。

### 1. 类型锁死与转让切开

标题、核心给付与对价方式一致才继续。权属转让、专利实施许可、布图许可、软件许可、技术秘密许可、概括技术许可、开发或咨询服务负触发。

### 2. 主体、证书与种子生产经营许可

许可人须是品种权证书记载的品种权人或有分许可权的人。被许可人生产经营授权品种，须核对应《种子生产经营许可证》。未核证书：不写“权属无争议”。

### 3. 许可方式、范围与保护期

普通／排他／独占点名；地域、行为可核验；期限不得超过剩余保护期（木本、藤本 25 年，其他 20 年）。

### 4. 备案、生效、审批与转让登记切开

备案写成成立生效后的协作义务，不写成合同未备案不生效，也不写成权属变动。向境外提供繁殖材料、审定／登记、转基因安全评价写成审批条件。

### 5. 使用费、繁殖材料交付与年费

入门费、提成、保底分列。原种质量指标与播种季节必须落句。许可人默认维持品种权有效并缴年费，另有约定除外。

### 6. 无效／终止处理、非法垄断与格式条款

保护期届满或品种权终止／被宣告无效后，不得就该品种权继续收取实施使用费。禁止质疑、无偿独占回授、搭售：删除或整体停止。

### 7. 维权资格、扩繁违约、EDV 与亲本回收

独占可单独主张；排他在品种权人不主张时可单独主张；普通须另行授权。到期亲本退回或监管灭活。EDV 商业利用须原品种权人许可，制度分步实施。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证品种权必然有效、把权属过户当许可放行、把禁止质疑或无偿独占回授改成可履行结构、指导无证生产经营或未经审批向境外交付亲本。
- `字段停止`：法域、品种权法律状态、共有人同意、对外提供种质审批、转基因安全评价、EDV 目录、动态规则未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书、无效或侵权诉讼策略，或已锁他类。
