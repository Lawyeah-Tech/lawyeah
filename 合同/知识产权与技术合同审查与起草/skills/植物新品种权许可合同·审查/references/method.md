# 审查方法（锁定 技术类合同 / 植物新品种权许可合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制植物新品种权转让的登记过户主路径、专利实施许可的国知局备案 3 个月主路径、集成电路布图或软件著作权许可扫描，或商标许可“未备案不得对抗善意第三人”。

定性校验：标题、核心给付与本类型一致才继续；权属转让、专利实施许可、布图许可、软件许可、技术秘密许可、概括技术许可、开发或咨询服务明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、品种权必然维持有效、对方必然接受或唯一必得使用费。

`search_law` 返回已失效《合同法》技术合同章、《技术合同法》及其实施条例、2014 年《植物新品种保护条例》旧保护期、1997 年条例原文、专利实施许可合同备案办法时记为噪声，不得写入 `L#`。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。农业农村部／林草局许可合同范本、转让范本、专利实施许可范本不得直接粘成本约。

知识库纠正（不回写双文件）：

## 节点 2　主体、证书与种子生产经营许可

### 2.1 主体表

建表：签约名、履行名、付款名、发票名、授权签字人。名称不一致不自动合并。许可人须是品种权证书上的品种权人，或能出示分许可权来源的被许可人。口头“我们老板同意了”不得写成已授权。

未附最新品种权证书或主管部门法律状态查询页：权属与负担字段停止，不写“权属清晰、无质押查封、无在先独占”。

科研院所、高等学校作许可人：国有资产转化或职务成果对外许可审批未闭合，该签署能力字段停止，不写成“院章一盖即可”。

### 2.2 被许可人资质与种子法衔接（审批硬闸）

支持依据：条例第 6 条；种子法（2021 修正）第 32、38 条。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 被许可人持有与作物类别、生产经营范围相符的《种子生产经营许可证》，文本已附复印件 | 可继续；许可证有效区域须覆盖合同授权区域 | 全国任意销售 |
| 文本授权生产、销售，用户材料未见许可证 | 字段停止；必须改：签约前出示许可证，或把实施范围限缩到依法不需自行持证的书面委托生产／代销并办理备案 | 无证也可合法销售；合同当然无效 |
| 申请领取具有植物新品种权的种子生产经营许可证 | 修改句要求已取得品种权人书面同意（种子法第 32 条第 3 款） | 许可合同本身替代许可证 |
| 授权区域超出审定／登记适宜区域 | 必须改：授权区域截在审定／登记范围内，或删除超范围销售权 | 有品种权就可以全国推 |

无证生产经营主要是种子法监管与行政处罚风险，不得单独写成民事合同当然无效（第 153 条；合同编通则解释第 16 条）。本任务停止“无证也可放行销售”和“无证＝合同无效”两种写法。用户要求把无证生产经营改成可履行结构：整体停止。

### 2.3 共有与在先冲突许可

共有品种权做独占或排他：未取得全体共有人书面同意则该签署能力字段停止，或降为普通许可。一共有人签字不得写成已封锁全部共有人。许可人自称“独家权利人”、证书显示共有：并列 `D#`／`C#`，字段停止。

审查清单，缺一项则该字段不得写成已闭环：

1. 授权品种名称、品种权号、作物种类、授权日、公告日、剩余保护期。
2. 是否处于年费滞纳、无效程序、质押、权属诉讼、强制许可。
3. 是否已存在互相冲突的独占或排他许可。
4. 是否亲本许可、区域代理或再许可。

材料未提及不得写成“无权利负担”，只能写 `依据不足`。强制许可作为主轴：不按自愿双边许可改完，字段停止并点名转出（条例第 13 条：强制许可人不享有独占实施权，也无权再许可）。

## 节点 3　许可方式、范围与保护期（硬闸）

### 3.1 普通／排他／独占必须点名

支持依据：技术合同解释第 25 条（经民法典第 876 条参照适用）。

| 文本写法 | 动作 |
| --- | --- |
| 标题或首部写明普通／排他／独占，且与能否自用、能否再许可第三人的正文一致 | 正触发，留下本类型 |
| “独家授权”“全权许可”“唯一合作”但未写许可人能否自用、能否再许可 | 必须改。点名三选一；未改则现有依据支持按普通实施许可解释 |
| 独占，但保留许可人原种扩繁自用且未限非商业科研 | 名实冲突。改为排他，或把自用限缩到条例允许的科研例外并书面确认 |
| 排他，但许可人可再许可其关联公司 | 必须改：再许可第三人会击穿排他；或改成普通 |
| 空白许可方式 | 必须改。不写“可以先签，以后补类型” |

修改句：

「甲方将品种名称【待填】、品种权号【待填】以【普通实施许可／排他实施许可／独占实施许可】许可乙方实施。若选择独占：在约定范围（地域【待填】、期限【待填】、行为【待填】）内，甲方不得自行实施，也不得再许可任何第三人。若选择排他：甲方可自行实施，但不得再许可第三人。若选择普通：甲方可自行实施并可再许可第三人。未在本合同中点名许可方式的，双方确认按普通实施许可履行，不得事后主张独占或排他。」

分许可：未经点名，被许可人不得再许可（参照民法典第 867 条）。即使允许再许可，除另有约定外认定为普通实施许可。亲本许可必须另条限制繁殖材料流向，禁止私下销售亲本。

### 3.2 范围与保护期

范围包括期限、地域、行为以及接触亲本和育种技术秘密的人员。行为对照条例第 7 条：生产、繁殖、为繁殖而处理、许诺销售、销售、进口、出口、储存。

| 文本写法 | 动作 |
| --- | --- |
| 期限空白，或写“长期”“永久” | 必须改：写起止日；并加“不得超过该品种权剩余保护期” |
| 许可期限超过授权公告载明的届满日 | 红线截断至保护期满；超期部分现有依据不支持继续作为品种权实施许可 |
| 品种权届满、终止或已被宣告无效后仍就该品种权订许可 | 红线。参照民法典第 865 条：不得就该品种权与他人订立实施许可合同 |
| 未约定地域 | 必须改。不得默认全国；主要农作物还须落入审定适宜区域 |
| 未约定行为范围 | 必须改。列明是否包含生产、繁殖、销售、进出口 |
| 文本仍写“木本 20 年、其他 15 年”或按此计算届满日 | 必须改。自 2025 年 6 月 1 日起按条例第 35 条：木本、藤本 25 年，其他 20 年 |

期限未约定且依第 510 条仍不能确定：解释第 28 条第 2 款称不受期限限制——这会与第 865 条参照适用的保护期上限冲突。本任务处理：修改句仍写入保护期上限；不得把“未约定期限＝可实施到品种权失效之后”写成可放行结构。

## 节点 4　备案、生效、审批与转让登记切开（硬闸）

### 4.1 备案不是生效，也不是转让登记

支持依据：民法典第 502 条（依法成立的合同自成立时生效，法律另有规定或当事人另有约定除外）；条例第 11 条（仅转让自登记之日起生效）。本窗未核到“植物新品种权许可未备案则合同不生效”的法律、行政法规。

| 文本写法 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 签字盖章后成立生效；生效后双方配合向农业农村／林草主管部门备案 | 可保留；补谁主办、对方几日内提供身份证明和签章件、逾期责任；窗口日数用 `【待填】` | 已完成备案；3 个月是本类型法定期限 |
| “未经备案合同不生效／未备案不得实施” | 必须改。备案不是法定生效要件 | 未备案＝未成立或无效 |
| “本合同经主管部门登记后，品种权转至乙方” | 红线。这是转让登记，不是许可备案 | 把备案当成第 11 条权利变动 |
| 无备案协作条款 | 必须改：写入成立生效后的办理义务 | “备案可有可无，无所谓” |
| 用户要求倒签生效日或补假备案回执 | 整体停止 | 先签后补假回执即可放行 |

修改句：

「本合同自双方签字盖章之日起成立并生效，不因尚未办理植物新品种权实施许可备案而停止生效。甲方应于生效之日起【待填】日内牵头向【国务院农业农村主管部门／国务院林业草原主管部门，按作物类别归口】办理许可合同备案，乙方应在收到书面通知后【待填】日内提供身份证明、授权委托和需要签章的申请文件。任何一方迟延导致未能按约提交备案的，应按日支付违约金人民币【待填】元，但不因此推定品种权已发生转让，也不因此推定本合同未生效。备案材料仅作为合同存在、许可范围和维权主体资格的证明材料之一。」

农业类归农业农村部，林业／草种类归国家林草局，按品种类别归口，不得写成向国家知识产权局备案。

### 4.2 审批硬闸：境外种质、审定、转基因

把批准、许可证、审定、安全评价写成**生效条件或履行期限**，不写成已经完成。

| 文本写法 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 授权乙方将境内培育品种的繁殖材料运输出境、交给境外主体，或在境外制种 | 必须改：对外提供种质资源须先取得国务院农业农村／林业草原主管部门批准（条例第 27 条；种子法对外提供种质条款；农作物种质资源管理办法第 29 条）。未获批准不得交付 | 许可合同本身等于出境批准；这是条例第 11 条转让批准 |
| 向外国人转让品种权或申请权 | 负触发 `植物新品种权转让合同·审查` | 按本类型许可审批改完 |
| 主要农作物对外销售，未见审定证书或审定区域与授权区域不一致 | 必须改：销售权以有效审定／登记范围为限 | 有品种权即可全国销售 |
| 涉及转基因品种，未见农业转基因生物安全证书 | 字段停止；必须改：取得安全证书并具备相应生产许可前，不得生产、经营 | 许可条款覆盖安全评价 |
| “双方同意视为已批准／已审定” | 红线删除。不得把“双方同意视为已批准”写成可放行结构 | 内部确认可替代审批 |
| 用户要求先出境、后补审批或补假许可证 | 整体停止 | 先发亲本再补手续 |

最强反方：相对方主张“许可给境外公司就是条例第 11 条须批准的转让”。修改句拆开：未转移品种权的，不走第 11 条；一旦交付繁殖材料出境，另走种质资源审批。两者都不是许可备案。

## 节点 5　使用费、繁殖材料交付与年费

### 5.1 使用费闭环

价金构成、币种、税、发票、支付节点分列。入门费、按销售斤数／包装袋数／净销售额的提成、保底分列。未给出的数字写 `【待填】`。禁止编造提成比例。

“销售收入”未定义：必须改成可审计口径（例如扣除增值税、退货后的净额，或以包装袋数×核定单价为准）。许可人核查销售台账和库存的权利可保留，次数、费用负担和异议期写清。

独占或排他可约定最低提成；未达标是否降为普通许可必须点名，不得写成许可人可任意解除且已付入门费不退、同时继续限制被许可人。

定金：必须使用“定金”二字才讨论罚则。约定或推算超过主合同标的额百分之二十：超过部分不产生定金效力。无核验引文不得把 20% 写成现行法结论。

### 5.2 繁殖材料交付与观察期

许可人应按约许可实施、交付亲本／原种／种苗并提供必要技术指导（参照民法典第 866 条）。禁止只写“提供必要协助”。

必须落句：交付时间（对准播种季节）、数量、质量指标（纯度、净度、发芽率、含水量）。过期交付视同违约，不得用不可抗力四个字覆盖季节性迟延。

第一个生长季品种符合性验证（DUS 异常）：取样封存、书面通知、双方确认后再扩繁。签收原种不等于验收合格。种性退化：约定许可人定期提供更新原种或指导提纯复壮；不得只写“种子质量问题由被许可人自行负责”。

### 5.3 年费与有效性维持

支持依据：条例第 36、37 条；参照技术合同解释第 26 条。

许可人在合同有效期内负有维持品种权有效的义务，包括依法缴纳年费和按主管部门要求提供检测材料，但当事人另有约定的除外。缺失年费条款：必须改，不得默示由被许可人承担。

修改句：

「除双方另有书面约定外，甲方应在本合同有效期内按时缴纳品种权年费并维持品种权号【待填】有效，及时将缴费凭证和官方通知书面抄送乙方。甲方拟放弃品种权或不再续缴年费的，应至少提前【待填】日书面通知乙方；乙方有权在同等条件下优先受让该品种权或自行代缴并在应付使用费中抵扣。因甲方未缴费或未按要求提供检测材料导致品种权终止，且无可归责于乙方的原因的，乙方有权解除本合同，并按第【待填】条处理使用费。」

## 节点 6　无效／终止处理、格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 终止或无效后的使用费

支持依据：参照民法典第 865 条（经第 876 条）；条例第 35–37 条。植物新品种权被宣告无效的具体追溯规则，无核验引文不得直接套用专利法第四十七条全文。

| 文本写法 | 动作 |
| --- | --- |
| “无论何种原因终止或无效，已付和应付使用费均不退、仍须继续支付至期限届满” | 必须改。保护期届满、终止或被宣告无效后，不得就该品种权继续收取实施使用费；已履行部分是否返还，区分恶意、显失公平和已交付亲本／技术指导的对价，不得预先一律放弃 |
| “一旦无效，甲方立即全额退还全部使用费及利息” | 可谈，但不得写成法定义务；已交付繁殖材料和技术指导部分可另行作价 |
| 完全不提终止／无效 | 必须补：后续品种权使用费停止；亲本对价拆分；恶意与显失公平例外待核 |

最强反方：被许可人主张无效后合同全部自始无效、应退全部费用；许可人主张“已写不返还即可排除公平例外”。两说均不得写成唯一结论。

### 6.2 格式条款

为重复使用而预先拟定、订立时未与对方协商。依据示范文本制作，不当然排除格式条款。

审查：许可方式、使用费、无效不退、禁异议、管辖／仲裁等异常条款是否有足以引起注意的标识，以及是否按要求说明（第 496 条；解释第 10 条）。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在附件 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

### 6.3 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的、是否仅行政管理、是否只规制履行行为（第 153 条；合同编通则解释第 16 条）。禁止用已失效“效力性／管理性”口诀。未备案、无证生产经营主要是监管与举证后果，不得单独写成民事合同当然无效。非法垄断技术、未经审批向境外提供种质、侵害他人品种权：不改写成有效履行。

## 节点 7　维权、扩繁违约、EDV 与亲本回收

1. 第三方侵权时的起诉资格必须与许可方式匹配。独占被许可人可单独主张；排他被许可人在品种权人不主张时可单独主张；普通被许可人除合同另有约定或品种权人另行授权外不能单独主张。修改句按所选许可方式落权，不得给普通许可人写“当然可独立起诉”。超范围生产、繁殖或销售，品种权人可同时主张违约和侵权（实务反例，非法源）。
2. 扩繁违约：严禁超出约定地域、数量或将亲本私下销售。只有“依法承担违约责任”视为必须改。
3. 逾期支付使用费：补交、违约金、停止实施、交还或灭活剩余繁殖材料。不在本任务做第 585 条精算。修改句避免“不得调整”或“按总价 30% 必得”。
4. 构成违约不等于当然解除。法定解除路径只点名催告或目的不能实现，不在本任务作出已解除结论。
5. EDV：利用授权品种培育实质性派生品种并商业利用，须取得原品种权人许可并约定报酬（条例第 7 条第 3 款）。制度分步实施、以目录为准（第 8 条）。未列入目录：字段停止。无偿独占回授 EDV：按节点 1.4 停笔。
6. 许可到期或解除：剩余亲本、原种须退回或在双方监管下灭活，禁止继续扩繁或流失。修改句必须有回收／销毁条款。
7. 争议解决：出现仲裁条款，不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核。专属管辖可能：只标红旗，不选定唯一法院充作法律意见。
8. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

打开已加载的 `框架.md`，按六步逐段对照正文。`基本面.md` 用于校验类型、主体、许可方式、审批和红旗，不代替本节点出句。

| 步 | 动作 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题用植物新品种权实施许可并点名普通／排他／独占；主体与证书品种权人一致；被许可人许可证；鉴于列品种名称、品种权号、授权日、剩余保护期，不写“保证品种权永不无效” | 标题或主体修改句 |
| 交易条款 | 许可方式与自用／再许可；地域、行为；期限≤剩余保护期；使用费与台账核查；原种质量与播种季节 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 备案协作；年费维持；审批（出境种质、审定、转基因）；维权资格与许可类型匹配；EDV 互利分享；亲本回收／灭活 | 可执行后果句或删除句 |
| 尾部 | 签署权限；生效≠备案≠转让登记；证书、审定／登记文件、许可证、质量标准、区域地图入附件 | 生效与附件修改句 |
| 语言 | 正说加反说；盯死许可 vs 转让、备案 vs 登记、独家 vs 独占／排他、使用费 vs 转让价款、审批 vs 双方确认 | 替换空词的句子 |
| 常见问题 | 许可方式空白；未备案写成未生效；备案写成权属过户；15／20 年旧保护期；无证销售；境外交亲本未审批；无偿独占回授；禁异议；年费缺位；缺亲本回收 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条／款／附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（权属过户主轴、许可方式与自用／再许可互相打架且拒改、超保护期、禁异议／无偿独占回授拒删、倒签或补假备案／假审批、把备案改成转让登记、指导无证生产经营或未经审批出境交付亲本）；
- `必须改`：可谈但签署前要落句（点名三类型、备案协作、年费、审批条件、许可证、审定范围、维权资格、共有人同意、亲本回收）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级入门费且品种权法律状态未核、用户拒绝升级：停止“可以签署”建议。

后续改进：可按互利原则约定分享办法；没有约定或约定不明且依第 510 条仍不能确定的，一方后续改进的技术成果，其他各方无权分享（民法典第 875 条，经第 876 条参照适用）。修改句可写“谁改进谁所有 + 互惠普通许可”，不得写无偿独占回授。EDV 商业利用另须原品种权人许可。
