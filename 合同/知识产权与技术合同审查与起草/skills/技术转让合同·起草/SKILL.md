# 技术转让合同·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》技术转让章、已失效《技术合同法》及其实施条例、已被修改的 1984 年《专利法》第十条当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **技术转让合同** 己方稿，出稿后用本类型硬闸自审。交付草稿、未决项、自审风险表和自审后修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文显示名为「技术转让合同·起草」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证专利一直有效或一定产业化、把尚待开发任务书改成转让、把独占许可改成买断。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **已有技术权利移交**：正像是订立时已经存在、特定的专利、专利申请或技术秘密的相关权利让与。必须落到可核验的专利号/申请号或秘密范围清单。禁止把“等有关技术”“后续研发成果一并转让”写成已特定。
2. **尚待开发不是转让**：就尚待研究开发的技术成果，或不涉及专利、专利申请、技术秘密的知识经验订立的合同，不属于技术转让。标题写转让、正文是立项研发 → 负触发 `技术开发合同·审查`。不得按 858 风险分担把开发任务书改完。
3. **850 非法垄断**：限制受让人在标的技术上继续研发或使用改进技术、不对等回授、限制从他处获得竞争技术、禁质疑知识产权：条款无效，必须改或删除。不得写成“买断所以禁止对方自己研发”的可放行结构。
4. **与许可、专利转让切开**：核心给付只是实施或使用授权、权利归属不改 → `技术许可合同·审查`（专利实施许可 → `专利实施许可合同·审查`）。主文件已是单独成册的专利权转让、只审国知局登记过户 → `专利权转让合同·审查`。仅专利申请权 → `专利申请权转让合同·审查`。仅技术秘密转让且无专利包 → `技术秘密转让合同·审查`。本技能留下的是父级《技术转让合同》，尤其专利/申请/秘密混装、资料移交与指导捆在一起的买断包。
5. **权利担保与在先负担**：让与人须保证合法拥有，技术完整、无误、有效，能达到约定目标。未披露的在先许可不因本次转让消灭。不得把“保证无任何在先许可”在未检索时写成已核验。
6. **共有人与登记**：共有专利申请权或专利权，转让须全体共有人同意。专利或申请权转让自向国务院专利行政部门登记之日起生效；合同签字不等于权利已经过户。未约定谁办登记、几日内、未完成的后果：必须改。
7. **进出口与国家秘密**：限制进出口技术未经许可不得进出口；国家秘密技术未审查不得跨境交付。用户坚持先交后补批：整体停止。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签技术转让正文，尚未签署，尚未成争，核心给付是把订立时已有的特定专利、专利申请或技术秘密相关权利让与对方，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 订立时尚不存在、须研究开发 → `技术开发合同·审查`；
- 阶段性成果再做工业化试验、转化 → `技术转化合同·审查`；
- 仅授权实施或使用、底层权利不改 → `技术许可合同·审查`；专利实施许可 → `专利实施许可合同·审查`；技术秘密使用许可 → `技术秘密使用许可合同·审查`；
- 主文件标题和结构就是单独的专利权转让 → `专利权转让合同·审查`；
- 单独的专利申请权转让 → `专利申请权转让合同·审查`；
- 单独的技术秘密转让、无专利或申请混装 → `技术秘密转让合同·审查`；
- 集成电路布图、植物新品种、软件著作权单独转让 → `集成电路布图设计专有权转让合同·审查` / `植物新品种权转让合同·审查` / `计算机软件著作权转让合同·审查`（P1 未装则 `unavailable`）；
- 撮合双方订技术转让、自己不让与权利 → `撮合专利许可只收中介费不自己实施也不自己许可→`（P1；未装则 `unavailable`）；
- 按既有图纸常规加工、成果必然可复制 → `按既有图纸加工定作实物→负触发`；
- 只出可行性或 FTO、不移交权利 → `知产技术咨询·审查`；以技术知识解决特定问题 → `知产技术服务·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁或权属诉讼 → `或知产争议专项。` 或知产/争议专项。

以转让为名买卖国家秘密、未批限制进出口技术，或把 850 禁研/不对等回授改成可履行结构：只出告知，不改写成可履行路径。

## 建立审查坐标

确认：使用者与授权；单方立场（让与人侧或受让人侧择一）；相对方；全文及附件/技术清单/专利登记簿版本；标的是否订立时已存在且特定；是权利让与还是许可；是否已锁成单独的专利权转让本约；共有人书面同意；在先许可或质押检索痕迹；登记义务人与期限；850 禁研或回授；进出口或国家秘密；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价款、提成比例、人天数、登记日用 `【待填】`，不编造。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验 850 与技术合同解释第 10 条、862–864、解释第 22/24/25/28/34 条、868–875、专利法第十条和第十四条、技术进出口许可；`search_practiced` 只补审查反例；`search_template` 只借栏目结构。不虚构案件系统。

`search_law` 对上述法律结论为 required 级：不可用时不拒绝执行，只停止效力字段。返回已失效《合同法》或其解释、已失效《技术合同法》或其实施条例、1984 年《专利法》第十条时记为噪声，不得写入 `L#`。


## 起草模式

本原子只承担本类型起草。待签评改转 `技术转让合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `技术转让合同·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

起草必写：标的是订立时已经存在、特定的专利、专利申请或技术秘密的相关权利让与，落到可核验的专利号／申请号或秘密范围清单；让与人保证合法拥有，技术完整、无误、有效，能达到约定目标；共有专利申请权或专利权转让须全体共有人同意；专利或申请权转让自向国务院专利行政部门登记之日起生效，合同签字不等于权利已经过户；写清谁办登记、几日内、未完成的后果；未披露的在先许可不因本次转让消灭。专利申请权按申请权作价，不得写成已授权专用权。
附件必附：专利号／申请号或技术秘密范围封闭清单；共有人书面同意；在先许可或质押披露清单。
禁止出现：等有关技术、后续研发成果一并转让写成已特定；尚待开发按转让出稿；买断所以禁止对方自己研发；限制受让人在标的技术上继续研发或使用改进技术、不对等回授、限制从他处获得竞争技术、禁质疑知识产权；签字即权利已经过户；未检索却保证无任何在先许可。非法垄断技术条款只告知并删除，不改成可履行禁研结构。未批限制进出口、国家秘密技术未审查却跨境交付：只告知，不起可履行稿。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`基本面.md` 把“独占许可/排他许可/普通许可”列为权利范围选项时，不得在本任务按许可改完——那是负触发。`框架.md` “免费使用权或优先受让”不得写成法定默认；无约定时一方后续改进，他方无权分享。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 本任务起草并自审；已签履约 → 本套导航履约步骤；已成争 → 合同争议或知产。未签且目标是评改已有技术转让文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。尚待开发、单纯许可、单独专利权/申请权/秘密转让本约负触发。

### 2. 主体、共有人与在先负担

签约名、履行名、付款名、发票名分列。共有人未书面同意：签署能力字段停止。在先许可、质押、诉讼未检索：不得写“无权利负担”。

### 3. 存量标的与 850

技术清单特定化。删除禁研、不对等回授、禁他源技术、禁质疑条款。

### 4. 资料移交、指导与登记

资料须足以独立实施。专利/申请权登记写成权利变动条件，不写成已经过户。

### 5. 对价、担保与后续改进

入门费与提成分列。870 担保落到指标附件。875 谁改进谁享有，禁止无偿独占回授。

### 6. 格式条款、进出口与强制规范

无核验引文则法律结论字段停止。未批进出口：履行字段停止。

### 7. 违约、保密与争议

资料不全、无法达标、隐瞒在先许可分别有后果。不选定唯一法院充作意见。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把禁研/未批进出口/国家秘密改成可履行结构、坚持把开发任务或许可主轴按转让放行。
- `字段停止`：法域、动态规则、专利法律状态、进出口目录、国家秘密审批、共有人同意未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
