# 审查方法（锁定 技术类合同 / 技术转让合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制技术开发“尚待研发、858 风险分担、不保证成功”主路径，禁止复制许可“独占/排他/普通使用费”method，禁止复制单独专利权转让的登记过户专册。

定性校验：标题、核心给付与本类型一致才继续；尚待开发、单纯许可、单独专利权/申请权/秘密转让本约明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、保证专利一直有效或唯一必得金额。

`search_law` 返回已失效《合同法》及其解释、已失效《技术合同法》及其实施条例、1984 年《专利法》第十条（已被修改）时记为噪声，不得写入 `L#`。

示范文本只参考结构。科学技术部《技术转让（专利实施许可）合同》示范文本只证明那是许可，不得当作本类型范本。专利局监制专利权转让合同只借栏目，单独成册的专利权转让本约走 `专利权转让合同·审查`。

知识库纠正（不回写双文件）：

- `基本面.md` “所有权或使用权的转移”“买断式的所有权移交或排他性权利移交”：本技能只审**相关权利让与**（第 862 条第 1 款）。独占/排他/普通许可是使用权授权，底层权利人不改，负触发 `技术许可合同·审查` / `专利实施许可合同·审查`，不得在本任务按许可改完。
- `基本面.md` 标的节把“所有权转让还是独占许可/排他许可/普通许可”并列：许可选项只作切开信号，不是本类型可选项。
- `框架.md` “若仅为使用权，实务中多归类为技术许可”：采用，直接负触发。
- `框架.md` 后续改进“免费使用权或优先受让”：第 875 条无约定则一方改进他方无权分享。免费独占回授落入解释第 10 条第（一）项。可约定对等优先商谈，不得写成法定免费。
- `基本面.md` / `框架.md` “专利权自登记之日起生效”：精确口径是专利法第十条，**专利申请权或专利权的转让**自登记之日起生效，不是合同债权当然自登记才成立。必须拆开合同生效与权利变动。
- `框架.md` “增值税免征及所得税减免”：符合条件才可能，不是签署即可减免。只约定协助办理技术合同认定登记，不保证税款结果。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

支持切开的规范（法律结论须运行时复核）：

- 第 862 条：技术转让是合法拥有技术的权利人，将**现有特定**的专利、专利申请、技术秘密的相关权利**让与**他人；技术许可是将现有特定专利、技术秘密的相关权利**许可他人实施、使用**。专用设备、原材料、咨询或指导约定属于本合同组成部分，不单独改定性。
- 第 863 条：转让包括专利权转让、专利申请权转让、技术秘密转让等；许可包括专利实施许可、技术秘密使用许可等；应当采用书面形式。
- 第 864 条：可以约定实施或使用范围，但不得限制技术竞争和技术发展。
- 解释第 22 条：**就尚待研究开发的技术成果**，或不涉及专利、专利申请或技术秘密的知识、技术、经验和信息所订合同，**不属于**第 862 条的转让或许可。
- 解释第 25 条：独占/排他/普通是**许可方式**。对方式未约定视为普通许可。
- 第 851 条：技术开发是就新技术、新产品、新工艺、新品种、新材料及其系统的**研究开发**。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 订立时标的已存在且特定；对价换的是专利/申请/秘密的权利让与；常混装资料、指导、秘密 | 本类型 | 正触发 |
| 标题《技术转让合同》，正文是立项研发、任务书、尚无专利号或秘密范围 | 技术开发 | 负触发 `技术开发合同·审查` |
| 阶段性成果再约定后续试验以实现工业化 | 技术转化 | 负触发 `技术转化合同·审查` |
| 只授权实施或使用，专利权人/秘密权利人不改；写独占/排他/普通许可 | 技术许可 / 专利实施许可 | 负触发 `技术许可合同·审查` / `专利实施许可合同·审查` |
| 主文件标题和结构就是单独《专利权转让合同》，标的仅为已授权专利过户 | 专利权转让 | 负触发 `专利权转让合同·审查` |
| 单独转让专利申请权 | 专利申请权转让 | 负触发 `专利申请权转让合同·审查` |

| 撮合双方成交，中介不让与权利 | 技术转让中介 | 负触发 `撮合专利许可只收中介费不自己实施也不自己许可→` |
| 按既有图纸加工、复制、测试 | 承揽 | 负触发 `按既有图纸加工定作实物→负触发` |
| 只出可行性或 FTO | 技术咨询 | 负触发 `知产技术咨询·审查` |

混装包：同一份《技术转让合同》同时让与专利（或申请）和技术秘密、并约定资料与指导——留本技能。其中登记过户专条可点名交接 `专利权转让合同·审查`，不得因此整案转走。

用户拿出已经独立成册、只办一件专利权人变更的《专利权转让合同》：转 `专利权转让合同·审查`，不在本任务把国知局表格当技术转让包改完。

### 1.2 加载协议（硬闸）

本技能已锁定 **技术类合同 / 技术转让合同**。只打开 `references/基本面.md` 与 `references/框架.md`。禁止读其他子目录，禁止为对照再开第二类。

### 1.3 违法结构停笔

加载后或定性中出现：以转让为名转移国家秘密；未批限制进出口技术却约定立即跨境交付资料或样机；把他人技术成果当作自己的标的出让；要求先交核心配方再补许可证。

动作：

1. 交付告知：该结构可能因违法、违背公序良俗或侵害他人技术成果而无效（第 153、154、850 条），不得改写成可履行文本。
2. 不写“先交付后补批”、虚假权属或体外循环口径。
3. 风险表只保留识别依据和转出/删除提示。
4. 用户坚持“改到能签且仍做这些事”：整体停止。

## 节点 2　主体、共有人与在先负担

### 2.1 主体表

建表：签约名、履行名、付款名、发票名、授权签字人。名称不一致不自动合并。课题组、工作室无法人资格：未经所属法人或非法人组织授权，不得写成已由该组织出让。

口头“我们老板同意了”不得写成已授权。国资、高校、上市公司内部决议或职务发明处理未附：该签署能力字段停止，不写成“可以盖章”。

### 2.2 共有人（硬闸）

专利法（2020 修正）第十四条：共有人有约定从约定；无约定时共有人可单独实施或以普通许可方式许可他人，许可使用费在共有人之间分配；**除此以外行使共有专利申请权或专利权，须取得全体共有人同意**。转让不是单独实施，也不是普通许可。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 登记簿载明共有，正文只有一名让与人签字 | 字段停止；修改句要求全体共有人签署或出具不可撤销书面同意 | 一名共有人可以单独卖断 |
| 共有人同意书未写清同意让与而非普通许可 | 必须改：写明同意**转让**专利申请权或专利权 | 有一份同意书即可 |
| 技术秘密由多人共同控制，未见其他控制人同意 | 字段停止 | 持有资料的一方即可出让 |

修改句：

「让与人保证：附件所列专利/专利申请的登记权利人为【待填】，共有人为【待填】。本合同签署前，全体共有人已出具不可撤销的书面同意，同意将相关权利让与受让人，而非仅同意普通实施许可。未经全体共有人同意的让与条款不发生权利变动效果。」

### 2.3 在先许可、质押与诉讼

解释第 24 条第 2 款：专利权或专利申请权转让合同，**不影响合同成立前**让与人与他人订立的相关专利实施许可或技术秘密转让合同的效力。

| 文本写法 | 动作 |
| --- | --- |
| “保证无任何在先许可、质押、诉讼”且无登记簿/检索页 | 不得写成已核验。修改句改为交付检索结果，并披露全部在先许可的种类、期限、地域、是否可再许可 |
| 已有长期普通许可却写“受让人获得独占市场” | 必须改：列明在先被许可人在原范围内继续实施；价款是否因此调整用 `【待填】` |
| 专利已出质或被保全 | 红线：质权人或保全解除前不签权利让与，或把解除作为生效条件 |

修改句：

「让与人应于签署前向受让人交付：①国务院专利行政部门专利登记簿副本或法律状态检索页（权利人、共有、质押、保全、许可备案、无效请求）；②全部在先许可或在先技术秘密合同清单（相对方化名可保留，但须写明独占/排他/普通、地域、期限、再许可）。让与人未披露的在先许可不因本合同订立而消灭。受让人有权在披露完成后【待填】日内决定减价、排除该部分标的或解除。」

最强反方：让与人主张“转让后原许可自动终止”。现有依据不支持该主张，除非在先被许可人书面放弃。

## 节点 3　存量标的特定化与非法垄断

### 3.1 已有技术权利移交（硬闸）

审查清单，缺一项则该字段不得写成已闭环：

1. 专利：发明创造名称、专利权人、申请日、申请号、专利号、有效期限（第 845 条第 3 款）。
2. 专利申请：申请人、申请日、申请号、公开或实审状态。
3. 技术秘密：载体、范围边界、与公知信息的区分，不得只写“相关 Know-how”。
4. 成熟度：实验室 / 中试 / 已量产，以及是否做过现场演示或历史生产数据——写事实，不写“保证产业化成功”。

禁止只写“甲方拥有的全部相关技术一并转让”。未特定则标缺口，不编造专利号。

出现订立时尚不存在的研究开发任务、以未来成果为主要对价：回到节点 1，负触发 `技术开发合同·审查`。解释第 22 条不是“可以当转让履行”，不得改成继续按转让放行。

解释第 34 条：以转让名义提供已进入公有领域的技术，或履行中标的进入公有领域，但让与人仍做指导并解决特定技术问题的，按技术服务处理。本任务标红旗，修改句拆出服务报酬，不假装仍在买专利。

### 3.2 尚待开发不是转让（硬闸）

| 文本写法 | 动作 |
| --- | --- |
| 标题技术转让，附件是《研发任务书》，指标尚未实现 | 负触发 `技术开发合同·审查`，不填本类型十节实体结论 |
| 现有专利买断 + 另行为下一代立项 | 现有部分可留本技能；下一代专条交接开发原子，禁止两套知识灌进同一十节 |
| “含后续全部改进和尚未完成的试验数据”当作已转让标的 | 必须改：订立时已有成果入清单；后续改进走第 875 条，不预售未完成成果 |

不得把开发风险、不保证成功、经费包干写成转让条款。那是另一类型的主路径。

### 3.3 非法垄断技术（硬闸）

第 850 条：非法垄断技术或者侵害他人技术成果的技术合同无效。第 864 条：约定范围不得限制技术竞争和技术发展。解释第 10 条下列情形属于非法垄断，必须改或删除：

1. 限制一方在标的技术基础上进行新的研究开发，或限制使用所改进的技术；或交换改进技术的条件不对等（无偿提供、非互惠转让、无偿独占或共享改进技术的知识产权）。
2. 限制一方从其他来源获得类似或竞争技术。
3. 明显不合理地限制实施数量、品种、价格、销售渠道或出口市场。
4. 要求接受并非实施技术必不可少的附带条件。
5. 不合理限制购买原材料、零部件、产品或设备的渠道或来源。
6. 禁止对合同标的技术知识产权的有效性提出异议，或对提出异议附加条件。

| 文本写法 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 买断后受让人不得自行或委托第三方在该技术上继续研发 | 红线删除。可保留：就本合同清单范围内的重复采购须书面告知，但不禁止独立研发或从他处获得竞争技术 | 买断所以合法禁研 |
| 受让人改进技术无偿回授让与人并归其独占 | 必须改：谁改进谁享有；对方仅有约定期限内对等优先商谈 | 回授是买断标配所以有效 |
| 受让人不得质疑专利有效性，质疑则违约 | 删除。可保留：发现无效事由应及时通知，但不限制依法请求宣告无效 | 已经放弃异议权 |
| 受让人必须搭购无关设备或指定唯一原料渠道 | 删除非实施所必需的搭售 | 打包销售所以合法 |

条款无效不等于整份合同当然无效。修改句删除或改写该条，不在本任务宣告整约无效。

解释第 28 条：第 864 条的“范围”包括期限、地域、方式以及接触秘密的人员。对期限没有约定或约定不明的，受让人实施或使用**不受期限限制**。买断式让与不得再写“授权三年到期收回”，那种写法是许可信号，回到节点 1。

## 节点 4　资料移交、指导与登记

### 4.1 资料须足以独立实施

第 868 条（秘密转让参照）：让与人按约定提供技术资料、进行技术指导，保证实用性、可靠性，并承担保密义务。第 870 条：保证技术完整、无误、有效，能够达到约定目标。

必须具备：

1. 附件清单列到图纸、工艺规程、配方、源代码或操作手册等载体，受让人签署《技术资料接收确认书》。
2. 交付后受让人能**不依赖让与人日常在场**独立实施；缺核心配方或源码：必须改。
3. 指导：岗位、人天数、地点、差旅承担，数字用 `【待填】`。
4. 验收对应指标附件，不写“签收即合格且放弃一切缺陷”。

修改句：

「让与人应于本合同生效后【待填】日内，在【待填】地点向受让人交付附件一全部技术资料（含足以使受让人独立实施的工艺配方/源代码及与专利权利要求对应的实施例数据）。受让人签署《技术资料接收确认书》仅确认签收件数，不视为第 870 条所称完整、无误、有效已经满足。让与人应派遣具备【待填】资质的技术人员提供不少于【待填】人·日的现场指导，差旅费由【待填】承担。」

### 4.2 让与人是否继续实施

解释第 24 条第 1 款：订立专利权或专利申请权转让合同前，让与人自己已经实施的，合同生效后受让人要求其停止实施的，应予支持，**当事人另有约定的除外**。

框架“独占性模糊、未明确转让后原权利人是否还能自用”：必须落句。

「自专利申请权或专利权变更登记之日起，除附件披露的在先许可外，让与人不得自行或许可第三人实施清单内专利；让与人在登记前已实施的，应于登记后【待填】日内停止，在制品处理方式为【待填】。技术秘密让与后，让与人不得继续使用或向第三人披露，除非双方书面保留普通使用权。」

### 4.3 行政登记（硬闸）

专利法（2020 修正）第十条：转让专利申请权或专利权，应当订立书面合同，向国务院专利行政部门登记并公告；**转让自登记之日起生效**。向外国人、外国企业或其他组织转让，还须依法办理手续。

| 文本写法 | 动作 |
| --- | --- |
| “本合同签字盖章后专利权即归受让人” | 必须改：拆成合同生效 vs 权利变动 |
| 未写谁负责登记、期限、费用、未完成后果 | 必须补。建议【待填】日内共同提交，费用由【待填】承担；逾期未登记，守约方可中止付款或解除 |
| 把登记写成已经完成 | 禁止。本任务只写义务和条件 |

修改句：

「双方应于本合同生效后【待填】日内，共同向国务院专利行政部门提交专利申请权/专利权转移登记申请。该项权利的转让自登记之日起生效；登记完成前，受让人不得对外主张自己已是专利权人或申请人。因让与人原因逾期未完成登记的，受让人有权中止支付未到期价款，并要求让与人按日支付未登记部分价款【待填】‰的违约金；逾期超过【待填】日的，受让人可以书面通知解除并请求返还已付款。」

许可合同的备案（实施细则第十五条：生效后三个月内备案）不是本类型主路径。出现“只需备案不必过户”：许可信号，回到节点 1。

## 节点 5　对价、权利担保与后续改进

### 5.1 对价

入门费（或一次性总算）与提成分列。提成基数（含税销售额/净利润）、比例、对账资料、审计权写清。未给出的数字写 `【待填】`。禁止编造评估值或税率。

定金：必须使用“定金”二字才讨论罚则。约定超过主合同标的额百分之二十：超过部分不产生定金效力。无核验引文不得把 20% 写成现行法结论。

框架税务提示：只约定让与人协助提供认定登记所需材料，不保证增值税免征或所得税减免。

### 5.2 权利与侵权担保（硬闸）

第 870 条：保证合法拥有，技术完整、无误、有效，能够达到约定目标。第 874 条：受让人按照约定实施专利、使用技术秘密侵害他人合法权益的，由让与人承担责任，但当事人另有约定的除外。

| 文本写法 | 动作 |
| --- | --- |
| 让与人“仅按现状转让，不承担任何权利或技术担保” | 必须改。870 是让与人义务，不得概括放弃 |
| “专利被宣告无效，已收转让费概不退还，受让人不得主张” | 必须改。可区分：无效事由在订立时已存在且未披露 → 返还相应价款；无效发生在登记后因新对比文件 → 已履行部分是否调整另行约定，不得写成让与人概不负责 |
| 实施侵权一律由受让人自负 | 与 874 冲突，除非双方就该部分另有可识别约定且已提示。相对方立场：删除自负，改回让与人承担抗辩和赔偿 |

修改句：

「让与人保证：其是附件清单一所列技术的合法拥有者；该技术于交付时完整、无误、有效，在受让人按附件二操作规程实施时能够达到附件二列明的技术指标。因让与人违反前款，或受让人按照约定实施、使用侵害第三人合法权益的，由让与人负责抗辩并承担赔偿、和解与合理维权费用，但因受让人超出约定范围实施或擅自修改配方导致的除外。专利于登记后被宣告无效的，双方应按无效宣告决定生效之日尚未摊销的转让价款【待填】比例结算；让与人订立时已知或应知无效事由而未披露的，应返还已收价款并赔偿直接损失。」

本任务不认定专利已经无效，也不保证专利一直有效。

### 5.3 后续改进（硬闸）

第 875 条：可按互利原则约定后续改进分享；没有约定或约定不明，依据第 510 条仍不能确定的，**一方后续改进的技术成果，其他各方无权分享**。

解释第 10 条第（一）项：无偿、非互惠、无偿独占或共享改进知识产权，属于非法垄断。

最佳实践修改句：谁改进谁享有；对方在【待填】日内有权按公平条件优先商谈普通许可或受让；不得无偿独占回授。

## 节点 6　格式条款、进出口与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 格式条款

为重复使用而预先拟定、订立时未与对方协商。依据示范文本制作，不当然排除格式条款。免责、850 限制、管辖、单方解释权等异常条款须有足以引起注意的标识。小字、夹在附件、仅网络勾选：不得写成已尽提示义务。

### 6.2 技术进出口与国家秘密

技术进出口管理条例（2020 修订）第二条把专利权转让、专利申请权转让、技术秘密转让列入技术进出口。限制进口须向外经贸主管部门申请（第 11 条）；限制出口实行许可证管理，未经许可不得出口（第 30、31 条）。

| 已有事实 | 动作 |
| --- | --- |
| 跨境交付或外方受让人，未提及目录核查 | 履行字段停止；修改句把许可作为生效或履行条件 |
| 用户要求先交源码/配方，后补出口许可 | 整体停止，不写可履行补批路径 |
| 可能涉及国家秘密技术 | 字段停止；未获出口审查不得签署跨境交付条款 |

### 6.3 强制规范

违反法律、行政法规强制性规定不一律无效（第 153 条；合同编通则解释第 16 条）。禁止用已失效“效力性/管理性”口诀。850 条款无效不等于整约无效。未办认定登记主要影响税收优惠，不得单独写成民事合同当然无效。

## 节点 7　违约、保密与争议

第 872 条：许可人未按约定许可的，返还部分或全部使用费并承担违约责任；超范围实施或擅自许可第三人、违反保密的，停止并承担违约。**让与人承担违约责任，参照适用前款**。

第 873 条：被许可人未付使用费应补交并支付违约金；不补交的应停止实施、交还资料；超范围或擅自再许可、违反保密，承担违约。**受让人参照适用前款**。

第 871 条：受让人对尚未公开的秘密部分，按约定范围和期限保密。

1. 让与人：资料不全、指标不达标、隐瞒在先许可或权利瑕疵，须分别有补交、减价、解除、返还的可执行后果。只有“依法承担违约责任”视为必须改。
2. 受让人：逾期付款、泄密、超范围再转让。未付清前可限制核心载体交付，但不得写成让与人可任意收回已登记的专利权。
3. 构成违约不等于当然解除。不在本任务作出已解除结论。
4. 违约金不是必得金额。修改句避免“不得调整”或“按总价 30% 必得”。
5. 争议解决：出现仲裁条款，不得改写成“应向某法院起诉”。或裁或诉、机构不明：标待核，改成单一机构或单一法院连结点。专属管辖可能：只标红旗，不选定唯一法院充作法律意见。
6. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。

保密修改句方向：秘密清单、接触人员、期限（终止后【待填】年，公开部分自动解除）、泄密的返还资料与损害赔偿；付款前不得复制外发。
