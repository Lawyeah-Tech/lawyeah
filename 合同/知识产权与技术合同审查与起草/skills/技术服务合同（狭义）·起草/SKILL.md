# 技术服务合同（狭义）·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《技术合同法》及其实施条例当作现行规则。不得把 2004 年未修正技术合同解释当作现行文本。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **技术服务合同（狭义）** 己方稿，出稿后用本类型硬闸自审。交付草稿、未决项、自审风险表和自审后修改句。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文显示名为「技术服务合同（狭义）·起草」。

`depends-on` 为空。不要求先跑导航。

不交付：他类审查、从零起草、履约交底、争议文书、有效性保证、技术培训整案、技术中介整案、技术咨询整案、父级一般技术服务整案、技术开发整案、常规承揽或建设工程整案、劳务派遣结构、税收减免或认定登记获批保证。

## 工作边界

正触发：已有可读待签文本要评改（审查模式），或本类型条件已谈妥要出己方稿（起草模式）；尚未签署，尚未成争；标题或外壳是技术服务、特定技术问题解决；**且**核心给付是运用现有专业技术知识动手排除已点名的故障、瓶颈、参数或功能缺陷，使对象达到约定量化指标。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 核心给付是对指定学员做特定项目专业技术训练和技术指导 → `技术培训合同·审查`；
- 核心给付是为委托人与第三人订立技术合同做联系、介绍或履行辅助 → `技术中介合同·审查`；
- 核心给付是可行性论证、技术预测、专题调查、分析评价报告，不保证把问题做掉 → `知产技术咨询·审查`；
- 用户明确要求走父级笼统技术服务货架，或正文是驻场运维/人力外包而没有已特定化的单一技术问题 → `知产技术服务·审查`；
- 订立时尚未掌握的新技术、新产品、新工艺、新品种、新材料及其系统的研究开发 → `技术开发合同·审查` 或对应开发原子；
- 常规加工、定作、修理、复制、测试、检验，不依赖专业技术知识解决解释第 33 条所列问题 → `按既有图纸加工定作实物→负触发`；
- 勘察、设计、施工 → `或对应工程原子；` 或对应工程原子；
- 人格从属、接受考勤指挥、按人天结算且无特定技术问题 → `或劳动专项，不改写成可履行派遣。挂靠违法分包未批限制进出口仍要跨境交付：只出告知，不改写成可履行路径。`；
- 用户坚持按委托章、费用预付或任意解除主路径审 → `委托合同货架按处理事务费用预付任意解除起草的同名《技术服务合同》→`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问进场日、验收日、付款节点 → 本套导航的履约步骤；
- 已成争（催告退费、索赔未修好、诉讼仲裁）→ 合同争议或对应专项领域。

挂靠、违法分包、规避限购、以服务为名破解原厂或侵害他人技术成果：只出告知，不改写成可履行结构。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成。每一闸必须给出修改句或明确转出口径，禁止只打红黄绿。

1. **特定技术问题必须穷尽到可验收**。标题写技术服务不决定类型。必须同时读出：待处理对象（哪台设备、哪套系统、哪条产线）；已显现的技术障碍；解决后的量化指标（故障率、产能、响应时间、连续无故障小时数等）；所用手段是现有知识还是尚未掌握的研发。只有“等”“有关技术服务”“全面运维”则标缺口，不得补写问题清单。修改句必须把标的改成任务书穷尽列表，并写明范围外新增问题另签或按变更计价。
2. **与培训、中介、咨询切开**。正文能支持对指定学员开班、教员/学员条件、考核结业为主给付 → 负触发 `技术培训合同·审查`。正文能支持报酬绑在促成委托人与第三人签约 → 负触发 `技术中介合同·审查`。正文能支持只交报告或意见、验收看报告是否符合约定而不看问题是否消失 → 负触发 `知产技术咨询·审查`。第 883 条传授义务必须落成《故障分析报告》《维护手册》或现场指导记录，但传授是附随义务，不得把本约改写成培训班。禁止打开或复制 `技术培训合同·审查`、`技术中介合同·审查`、`知产技术咨询·审查`、`知产技术服务·审查` 的 method。
3. **884 两款分轨，验收绑指标和观察期**。受托人未按约定完成服务工作：免收报酬、返工或按解决程度阶梯减酬，禁止“已尽力即免责”，也禁止套用开发风险合理分担。委托人因不履行配合、不提供工作条件、不接受或逾期接受而影响进度质量：已付报酬不得追回、未付应当支付；任意中途撤单、双方协商解除或受托人自身未完成，不得直接套该款。验收必须有修复前/修复后对比和观察期（如连续运行【待填】小时无复现）；无正当理由拒绝接受视为已完成并支付报酬。禁止保证永久达标、保证破解原厂或保证认定登记/增值税减免获批。

附加必落句（有事实则单列，无事实在缺口节说明）：

- **工作条件与拟制进度**：列明资料、数据、场地、停机窗口、辅助人员；受托人协作请求后【待填，建议 3】个工作日未答复，视为该阶段进度合格。工作条件不符须在合理期限书面通知，不得默示认可后再索赔。
- **费用与配件**：无约定时，差旅、通用工具、常规耗材由受托人负担。贵重零配件写明甲方自采或乙方代采及价格确认。不得把第 921 条委托人预付写成法定默认。
- **新成果分轨**：履行中受托人利用委托人资料条件完成的新成果，默认归受托人；委托人利用服务成果完成的新成果，默认归委托人。委托人可约定全球、永久、免费、非排他的实施/使用权。禁止一律归属。服务成果本身的合同目的使用权必须书面约定，不得把未核验的“免费使用”写成已核验法条。
- **对象权属与原厂**：委托人须声明对设备、数据、代码拥有所有权或合法处理权。出现破解二进制、绕过原厂锁机、使用侵权工具：停笔，不改成可履行侵权结构。
- **不得派遣化**：针对“事”而非“人”。受托人有技术手段自主权；委托人只验收问题是否按指标解决。出现驻场考勤、加班指挥、按人天结算且无特定问题：负触发派遣或父级服务，不在本任务改成可履行用工。

必须有修改句。每个风险回链文本位置。禁止复制父级技术服务 method 后换“狭义”。

## 建立审查坐标

确认：使用者与授权；单方立场（委托人/受托人择一）；相对方；全文及任务书/协作表/验收单版本；特定技术问题表述；量化指标与观察期；是否其实是培训、中介或咨询；费用与配件；新成果条款；现场安全；不可接受事项；法域与签署时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的金额、指标、期限用 `【待填】`，不编造。

知识库若写“报酬不可追回是强制保障”“改进成果一律归受托人”“委托人依法有权免费使用服务成果”，或以失效技术合同法实施条例当费用规则，以本文件和 `method.md` 纠正为准，不回写知识正文。

## 使用 Lawyeah MCP

宿主可调用时：

- `search_law`（法律结论 required）：核验第 878 条第 2 款定义、882–886、887 与培训/中介转介、850、851、770、788、506、496；技术合同解释（2020 修正）第 33、36、38、10、17、34、42 条。
- `search_practiced`（optional）：补特定技术问题验收、传授义务、与咨询/开发区分的争点。返回“已努力即免责”“任意撤单一律不退费”“咨询决策损失规则适用于服务”时记噪声。
- `search_template`（optional）：只借科技部技术服务栏目结构。范本引用《合同法》、或把培训/中介与狭义服务混订在同一主给付的，不得当规则。

不虚构案件系统。`search_law` 返回已失效《合同法》《技术合同法》及其实施条例、2004 年未修正解释、1990 年认定登记办法时记为噪声，不得写入 `L#`。


## 起草模式

本原子只承担本类型起草。待签评改转 `技术服务合同（狭义）·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `技术服务合同（狭义）·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。下表把本类型硬闸改成正文必写、附件必附或禁止出现。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 同时写清：待处理对象、已显现的技术障碍、解决后的量化指标、所用手段是现有知识。
- 范围外新增问题另签或按变更计价。
- 第 883 条传授义务落成《故障分析报告》《维护手册》或现场指导记录，但传授是附随义务。
- 受托人未按约定完成：免收报酬、返工或按解决程度阶梯减酬。
- 委托人因不履行配合影响进度质量：已付报酬不得追回、未付应当支付；任意中途撤单、协商解除或受托人自身未完成，不得直接套该款。
- 验收须有修复前／修复后对比和观察期。
- 列明资料、数据、场地、停机窗口、辅助人员；工作条件不符须在合理期限书面通知。
- 无约定时差旅、通用工具、常规耗材由受托人负担；贵重零配件写明甲方自采或乙方代采及价格确认。
- 新成果按完成方分轨，禁止一律归属；服务成果本身的合同目的使用权必须书面约定。
- 委托人声明对设备、数据、代码拥有所有权或合法处理权。

### 附件必附

- 任务书穷尽列表（对象、障碍、量化指标）。
- 《故障分析报告》《维护手册》或现场指导记录作为传授交付。

### 禁止出现

- 只有“等”“有关技术服务”“全面运维”。
- 把本约改写成培训班。
- “已尽力即免责”；套用开发风险合理分担。
- 保证永久达标、保证破解原厂或保证认定登记／增值税减免获批。
- 第 921 条委托人预付写成法定默认。
- 新成果一律归属。
- 破解二进制、绕过原厂锁机、使用侵权工具。
- 驻场考勤、加班指挥、按人天结算且无特定问题。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、破解原厂或侵害他人成果、把派遣改成可履行、保证有效、把“已努力免责”或无限永久达标保证留作可履行结构仍要放行。
- `字段停止`：法域、进出口或国家秘密审批、对象合法处理权、配件价格、认定登记编号、特种作业资质未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或用户要把本约改成培训、中介、咨询、开发或派遣以便按邻类请求履行。

生存级人身损害免责或个人无限连带且用户拒绝升级：停止“可以签署”建议。
