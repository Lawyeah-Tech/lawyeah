# 边界与路由

本技能只审查 **技术类合同 / 植物新品种权转让合同** 的待签、特定授权品种（或品种权申请权）权属让与文本。中文展示名是「审查植物新品种权转让合同（技术类合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开 `专利权转让合同·审查` 或 `植物新品种权许可合同·审查` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 仅授权实施；独占／排他／普通许可；许可期限、续期、使用费；届满交回繁殖材料；许可人可自用并再许可 | `植物新品种权许可合同·审查` |
| 已授权专利的权利让与；须向国务院专利行政部门登记才发生权利变动 | `专利权转让合同·审查` |
| 专利申请权让与；申请号、申请日是权利变动主轴 | `专利申请权转让合同·审查` |
| 集成电路布图设计专有权让与 | `集成电路布图设计专有权转让合同·审查` |
| 计算机软件著作权让与为主给付 | `计算机软件著作权转让合同·审查` 或 `软件著作权转让合同·审查` |
| 笼统《技术转让合同》，专利／申请权／秘密／品种权未拆章 | `技术转让合同·审查` |
| 现有未公开技术秘密买断，无品种权号 | `技术秘密转让合同·审查` |
| 已有技术的概括实施或使用许可主文件 | `技术许可合同·审查` |
| 专利实施许可为主给付 | `专利实施许可合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `植物新品种权转让合同·起草` |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或知产争议专项。` 或对应专项领域 |
| 品种权权属、侵权诉讼或无效宣告已立案 | 知产或争议专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

植物新品种权转让正文里夹带一小段实施许可清理或亲本技术秘密交接：专章点名对应原子；品种权买断条款可继续审。用户坚持本技能把许可、专利权转让或软件著作权整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
