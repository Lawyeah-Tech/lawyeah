# 边界与路由

本技能只审查 **知识产权相关合同 / 软件许可合同（分发许可模式）** 的待签文本。中文展示名是「审查软件许可合同（分发许可模式）（知识产权相关合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 仅限内部安装／按席位自用，禁止再许可和再分发；标题为最终用户许可、EULA、软件自用许可 | `软件许可合同（自用许可模式）·审查`。不得删掉“仅限内部使用”后按分发审完，也不得在自用稿里塞出货权 |
| 软件著作权权属转移、办理著作权人变更／转让登记、转让价款 | `软件著作权转让合同·审查`。不得把交 SDK／密钥改写成过户，也不得把分发许可改成转让登记 |
| 一般文字、美术、视听等非软件作品许可使用 | `著作权许可使用合同·审查` |
| 非软件作品著作权转让 | `著作权转让合同·审查` |
| 尚待研发、验收合格知识产权归甲方、不授予出货权 | `软件委托开发合同·审查`，或 `技术开发合同·审查`／`委托开发合同·审查`／`合作开发合同·审查` |
| 技术类“计算机软件著作权许可”，无法拆出再分发／渠道／SKU 出货轴 | `计算机软件著作权许可合同·审查`。P1：专业版未装则 `unavailable`，不得用本技能把邻类许可改完 |
| 无文本、本类型条件已谈妥、要出己方稿 | `软件许可合同（分发许可模式）·起草` |
| 已签未争、只问报数、密钥、备案进度 | 本套导航的履约步骤 |
| 已成争，或用户要侵权／解约诉讼策略 | `或知产争议专项。` 或对应专项领域 |
| 限制／禁止类技术出口或出口管制为主轴 | 字段停止并点名跨境技术进出口／出口管制专项；不在本任务代做目录归类或许可证申请 |
| C 端大众快检 | 只分流，不回改 |

分发正文里夹带一小段被许可人内部测试安装：可审“为预装所必需的内部复制”；内部使用成为主给付、禁止出货则交接 `软件许可合同（自用许可模式）·审查`。夹带一小段“期满可协商转让著作权”：专条交接 `软件著作权转让合同·审查`，再分发权项、SKU、EULA、报数条款可继续审。用户坚持本技能把自用许可、软件著作权转让或软件委托开发整案改完：`目标停止`。
