# 边界与路由

本技能只审查 **知识产权相关合同 / 软件著作权转让合同** 的待签、已完成计算机软件著作财产权让与文本。中文展示名是「审查软件著作权转让合同（知识产权相关合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开 `著作权转让合同·审查` 或 `软件委托开发合同·审查` 的 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 订立时软件尚未完成；对价绑功能清单、开发周期、上线或里程碑验收 | `软件委托开发合同·审查` |
| 分发、OEM、渠道转授权；出让人保留权属并继续向市场供应该软件 | `软件许可合同（分发许可模式）·审查` |
| 仅授权受让人自己使用、不得再分发，权属不移转 | `软件许可合同（自用许可模式）·审查` |
| 一般文字、美术、音乐、视听等作品财产权让与，无软件版本与源程序 | `著作权转让合同·审查` |
| 著作权许可使用为主给付 | `著作权许可使用合同·审查` |
| 委托创作主文件 | `知产委托创作·审查` |
| 合作创作主文件 | `合作创作合同·审查` |
| 技术类目录下「计算机软件著作权转让合同」成册主文件 | `计算机软件著作权转让合同·审查`（P1；专业版未装则 `unavailable`） |
| 技术类目录下「计算机软件著作权许可合同」 | `计算机软件著作权许可合同·审查`（P1；专业版未装则 `unavailable`） |
| 主给付是未公开技术秘密买断，软著登记只是交付物一句 | `技术秘密转让合同·审查` |
| 笼统技术转让，专利/申请权/秘密/软著混章未拆 | `技术转让合同·审查` |
| 尚待研究开发的技术方案 | `技术开发合同·审查` |
| 已有可读待签文本要评改 | `软件著作权转让合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、只问源码交接日或登记窗口日 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或知产争议专项。` 或对应专项领域 |
| 软著权属、侵权诉讼或刑事立案 | 知产或争议专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

软件著作权转让正文里夹带一小段未完成模块开发或源码保密专章：专章交接对应原子；已完成版本的财产权让与条款可继续审。用户坚持本技能把开发、许可或一般作品转让整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子所指向的邻类。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
