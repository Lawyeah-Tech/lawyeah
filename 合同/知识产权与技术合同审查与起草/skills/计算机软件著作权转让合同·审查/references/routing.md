# 边界与路由

本技能只审查 **技术类合同 / 计算机软件著作权转让合同** 的待签、已完成软件著作财产权让与文本。中文展示名是「审查计算机软件著作权转让合同（技术类合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。禁止打开邻类 method。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 封面、目录或用户指定「知识产权相关合同 / 软件著作权转让合同」；要求按知产父级条线审完 | `软件著作权转让合同·审查` |
| 仅授权使用；让与人可继续对外复制发行或再许可第三人；期限届满收回；对价称使用费且可续期 | `计算机软件著作权许可合同·审查` |
| 知产父级软件许可分发模式 | `软件许可合同（分发许可模式）·审查` |
| 知产父级软件许可自用模式 | `软件许可合同（自用许可模式）·审查` |
| 订立时软件尚不存在，或对价绑功能开发、里程碑、上线验收 | `软件委托开发合同·审查` |
| 委托开发作为已独立成册的技术开发细分主文件 | `委托开发合同·审查` |
| 一般文字、美术、视听作品财产权让与，无软件版本与源程序 | `著作权转让合同·审查` |
| 一般作品著作权许可使用 | `著作权许可使用合同·审查` |
| 现有未公开技术秘密买断，主给付不是软著财产权 | `技术秘密转让合同·审查` |
| 笼统《技术转让合同》，专利、申请权、秘密、软件混章未拆 | `技术转让合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `计算机软件著作权转让合同·起草` |
| 已签未争、只问源码交接日、编译验证日、登记窗口日 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或知产争议专项。` 或对应专项领域 |
| 软件著作权权属、侵权诉讼或刑事立案 | 知产或争议专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

技术类软著转让正文里夹带一小段技术秘密或专利实施许可：专章交接对应原子；财产权让与与源码交割条款可继续审。用户坚持本技能把许可、开发、一般作品或知产父级整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿本类型文本来找专业版：输出 `unavailable`，提示，不得用 `软件著作权转让合同·审查` 硬套。
