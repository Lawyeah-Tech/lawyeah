## **第一步：合同类型（法律性质）分析**

* **法律定性**：著作权许可使用合同是著作权人许可他人在约定期间、地域、方式内使用作品，被许可人支付报酬的合同。核心给付是**使用权授予**，权属不发生变更；期限届满或约定事由出现后，使用权回归许可人。适用《著作权法》（2020修正）第26条、第29条、第30条，《著作权法实施条例》，著作权司法解释（2020修正），并受《民法典》合同编约束。
* **易混淆辨析**：
* **许可 vs 转让**：许可不改变著作权主体。合同写“买断”“永久独家”但保留许可人处分权、到期自动终止或按使用量付费的，仍是许可。转让须书面并列明权利种类；许可专有使用亦宜书面。
* **专有 vs 非专有**：专有使用权排除许可人再以同样方式许可他人，是否排除许可人自己使用，依约定；未约定的，按实施条例，专有被许可人有权排除包括著作权人在内的任何人以同样方式使用。非专有（普通）许可不排他。介于二者之间的“排他许可”（许可人可自用、不得再许可第三人）须明文，否则易被解释为普通许可。
* **出版合同、音乐授权、衍生品授权**：均是本类型的场景，不是独立有名合同。图书出版常含专有出版权；音乐常叠加集管组织授权；影视衍生品叠加商品化使用，须把复制、发行、改编、商品类别写死。
* **效力认定**：
* **未明确许可的权利，被许可人不得行使**（《著作权法》第29条）。“等权利”“相关权利”“宣传所需一切权利”不能推出信息网络传播权、改编权、摄制权。
* 专有许可、转让可向著作权行政管理部门备案；**未经备案的专有许可，难以对抗善意第三人**（后许可、后转让的善意受让人）。
* 许可期限超过保护期的，超过部分无效。许可禁止出版传播的作品，合同标的违法。


## **第二步：合同主体（交易对手）分析**

* **许可人**：须对拟授权利有处分权。作者、继受权利人、职务作品单位、视听作品制片者、集管组织（在管理合同范围内）主体不同。集管组织无权超出管理范围发放“一揽子买断”。
* **被许可人**：按使用场景核验出版资质、视听制作资质、信息网络视听许可、游戏版号等**使用侧资质**；无资质不影响许可合同当然无效，但会导致约定使用方式履行不能。
* **关联主体**：
* **合作作者**：专有许可属于须协商一致的处分；普通许可在不能协商且无正当理由时，他方不得阻止，收益合理分配。
* **在先被许可人**：同一权利上的在先专有许可排斥在后许可。
* **下游再许可对象**：出版、平台、代工厂、联名品牌。未授再许可权的，被许可人不得转授。
* **签约能力**：代理人授权须写明许可类型（专有/普通）、权利种类、地域和期限，避免“全权处理版权事宜”被事后扩权。


## **第三步：合同标的（交易对象）分析**

* **标的特定化**：作品名称、版本、作者、登记号、使用的具体权项（复制、发行、表演、广播、信息网络传播、改编等）、使用方式（纸质/电子/舞台/短视频/商品化）。禁止只写“该作品的使用权”。
* **许可范围六要素**：主体（是否含关联公司）、权项、地域、期限、媒体/载体、专有或非专有。缺一项按第29条作对许可人有利的限缩。
* **权利负担**：
* 在先专有许可、集管授权、出质、权属争议。
* 演绎作品须同时拿到原作对应权项。
* 作品中的第三人素材（字体、图片、音乐、肖像）。
* **可交易性**：保护期内的财产权可以许可；人身权不能“许可买断”。合理使用、法定许可范围内的使用本不必取授权，但合同仍可作风险分配，不得写成“放弃法定许可抗辩”而不提示效力风险。


## **第四步：合同程序（交易步骤）分析**

* **形式**：许可合同宜书面；专有许可强烈建议书面并备案。电子点击同意可用于海量用户的非专有许可，但B端专有许可不要只用邮件往来。
* **备案**：专有许可向著作权行政管理部门备案，便于对抗后手和海关备案。
* **内部决策**：单位许可职务作品、国资许可、共有人同意专有许可。
* **履行节点**：交稿/交母带 → 许可生效 → 使用（出版、上线、演出）→ 结算报数 → 期满下架、销毁未发行复制件。
* **期限与续展**：期满使用权消灭；续展须书面，不得靠“双方继续履行视为自动续期”无限扩权。出版合同注意重印、再版是否需另行许可。


## **第五步：交易结构设计（风险规避方案）**

* **对价结构**：一次性许可费、版税（定价×印数×费率或流水分成）、保底+分成。报数、审计、预扣税写清。定金不超过主合同标的额**20%**。
* **专有许可的对价溢价**：专有必须匹配最低使用承诺或较高对价，并禁止被许可人“占权不用”。
* **再许可与分账**：允许再许可的，限定下游类型、备案义务和分成回流。
* **下架与回转**：期满、解除后删除信息网络传播、停止发行、回收授权文件；专有许可解除后及时变更备案。
* **文本形态**：**主许可协议 + 作品与权项清单 + 使用方式说明书 + 在先权利披露 + 专有许可备案草本 + 样稿/成片确认单**。


## **第六步：宏观风险预警与尽调指引**

* **高频争议**：许可范围外上架短视频/电子书；把普通许可当专有对抗第三人；集管授权与作者单独授权冲突；改编、衍生品未单独取权；期满未下架。
* **尽调清单**：
* [ ] 许可人与作者、登记、权属链是否一致
* [ ] 拟授权利是否已被专有许可或纳入集管
* [ ] 合作、职务、委托、视听作品的处分规则
* [ ] 使用方式所需行业资质
* [ ] 保护期与许可期限是否匹配
* [ ] 作品内第三人素材的权利
* **重大风险红旗**：“本协议授予作品全部知识产权”；无期限、无地域、无媒体的“全面授权”；被许可人可自行再许可且无需备案；把转让条款（再转让、出质）写进许可合同却不办权属变更。
