# 边界与路由

本技能只审查 **知识产权相关合同 / 著作权许可使用合同** 的待签、已有作品使用权授予文本。中文展示名是「审查著作权许可使用合同（知识产权相关合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 财产权主体变更；再转让或出质；许可人永久退出且对价按转让价金列项 | `著作权转让合同·审查` |
| 软件拷贝数、终端自用、最终用户许可为主给付 | `软件许可合同（自用许可模式）·审查` |
| 软件分发、预装、渠道再许可为主给付 | `软件许可合同（分发许可模式）·审查` |
| 软件著作权登记变更或让与 | `软件著作权转让合同·审查` 或 `计算机软件著作权转让合同·审查` |
| 尚待创作，对价绑创作过程 | `知产委托创作·审查` 或 `若用户坚持按委托合同父级审→` |
| 双方共同创作并约定共有或署名分工 | `合作创作合同·审查` |
| 注册商标许可为主给付 | `注册商标许可合同·审查` |
| 注册商标转让为主给付 | `注册商标转让合同·审查` |
| 已有可读待签文本要评改 | `著作权许可使用合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、只问履约节点、下架日、结算日 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或知产争议专项。` 或对应专项领域 |
| 著作权侵权、权属诉讼或刑事立案 | 知产或争议专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

著作权许可正文里夹带一小段商标许可或软件终端许可：专章交接对应原子；作品许可条款可继续审。用户坚持本技能把转让、软件许可、委托创作或合作创作整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
