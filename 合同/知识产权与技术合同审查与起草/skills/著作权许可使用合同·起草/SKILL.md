# 著作权许可使用合同·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、1990 年《著作权法》或 1991 年《著作权法实施条例》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **著作权许可使用合同** 己方稿，出稿后用本类型硬闸自审。交付草稿、未决项、自审风险表和自审后修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文显示名为「著作权许可使用合同·起草」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证未备案也能对抗善意第三人、保证未约定专有仍能排除许可人自用。

## 本类型硬闸

1. **许可 ≠ 转让**：正像是对**已有作品**授予约定期限、地域、方式内的**使用权**，著作权主体不变；期限届满或约定事由出现后，使用权回归许可人。权利种类让与、许可人永久退出、被许可人可再转让或出质、对价按转让价金列项 → `著作权转让合同·审查`。标题写“买断”“永久独家”但保留许可人处分权、到期自动终止或按使用量付费的，仍按许可审，不得改成转让外壳放行。禁止打开或复制 `著作权转让合同·审查` 的 method。
2. **专有 / 非专有必须写死**：第 26 条要求写明专有使用权或非专有使用权。专有、排他、普通三选一：是否排除许可人再以同样方式许可他人、是否排除许可人自己使用。介于二者之间的排他许可（许可人可自用、不得再授第三人）须明文。
3. **未约定视为非专有**：未写专有、独家、独占，或仅口头称独家：审查按非专有处理。被许可人不得据此排除许可人自用，不得对抗后手专有或受让。不得用实施条例第 24 条反推“没写就是专有并可排除著作权人”——该条只在**已经成立专有**后解释专有内容。计算机软件另有软件保护条例第 19 条：未书面或未明确专有的，视为非专有权利。
4. **第 29 条未列明不得行使**：权项按第 10 条第五项至第十七项逐项列举。媒体、语种、载体、使用场景分开写。“全部知识产权”“等权利”“宣传所需一切权利”推不出信息网络传播权、改编权、摄制权、翻译权或商品化使用。
5. **范围六要素与期满回归**：主体（是否含关联公司、承印厂、平台）、权项、地域、期限、媒体/载体、专有或非专有。缺一项按第 29 条对许可人限缩。期满、解除后须下架、停售、销毁未发行复制件、删除母带副本。自动续展须书面确认，不得靠继续履行无限扩权。
6. **人身权、集管、合作/职务、出质**：发表、署名、修改、保护作品完整不得写成许可买断。集管合同范围内的表演权、广播权等，作者不得再授；集管组织不得超出管理范围发放一揽子买断。合作作品专有许可须全体财产权人。职务作品完成两年内以与单位相同方式再许可须单位同意。已出质财产权未经质权人同意不得再许可。
7. **备案 ≠ 生效**：专有许可可向著作权主管部门备案，便于对抗后手和海关备案。不得写成未备案则合同未成立或使用真空，除非当事人确有此意。未备案对抗效力运行时再核，不得保证必然对抗善意第三人。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签著作权许可使用正文，尚未签署，尚未成争，核心给付是已有作品的使用权授予，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 财产权主体变更、再转让、出质、许可人永久退出且对价按转让价金列项 → `著作权转让合同·审查`；
- 主给付是软件拷贝数、终端自用或分发许可 → `软件许可合同（自用许可模式）·审查` 或 `软件许可合同（分发许可模式）·审查`；
- 主给付是软件著作权登记变更或让与 → `软件著作权转让合同·审查` 或 `计算机软件著作权转让合同·审查`；
- 尚待创作、对价绑创作过程 → `知产委托创作·审查` 或 `若用户坚持按委托合同父级审→`；双方共同创作并约定共有 → `合作创作合同·审查`；
- 注册商标许可或转让 → `注册商标许可合同·审查` / `注册商标转让合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点、下架日、结算日 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁或著作权侵权/权属已立案 → `或知产争议专项。` 或知产/争议专项。

以许可为名买卖禁止出版传播的作品，或把人身权买断、集管范围外一揽子授权改成可履行结构：只出告知，不改写成可履行路径。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及附件/作品清单/权项表版本；标的是否已有作品；是许可还是转让；专有、排他还是普通；权项是否逐项列举；地域期限媒体；再许可；在先专有、集管或出质；合作/职务/委托权属；使用侧资质；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。意见中不得复述用户材料里未发表作品的全文或完整母带，只引用作品名称、版本或清单编号。

## 起草模式

本原子只承担本类型起草。待签评改转 `著作权许可使用合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `著作权许可使用合同·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

起草必写：对已有作品授予约定期限、地域、方式内的使用权，著作权主体不变；期限届满或约定事由出现后使用权回归许可人；专有、排他、普通三选一写死——是否排除许可人再以同样方式许可他人、是否排除许可人自己使用；权项按第十条第一款第五项至第十七项逐项列举；范围六要素（主体、权项、地域、期限、媒体／载体、专有或非专有）写全；期满、解除后须下架、停售、销毁未发行复制件、删除母带副本。
附件必附：已有作品清单与权项表。
禁止出现：权利种类让与、许可人永久退出、被许可人可再转让或出质且对价按转让价金列项；未写专有却写成可排除许可人自用或可对抗后手；用实施条例第二十四条反推没写就是专有；全部知识产权、等权利、宣传所需一切权利推出未列明权项；人身权买断；集管范围外一揽子授权；未备案则合同未成立或使用真空。许可不得写成权属已转移。职务作品完成两年内以与单位相同方式再许可、合作作品专有许可、已出质财产权再许可：权源未闭合不得写成可履行。以许可为名买卖禁止出版传播作品：只告知，不起可履行稿。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → 本任务起草并自审；已签履约 → 本套导航履约步骤；已成争 → 合同争议或知产。未签且目标是评改已有著作权许可文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。转让、软件许可、委托创作、合作创作、商标本约负触发。

### 2. 主体、权属、集管与在先负担

签约名、履行名、付款名、发票名分列。作者、继受、职务、视听制片者、集管组织必须对得上拟授权项。在先专有、出质、合作共有未闭合则字段停止。

### 3. 专有 / 非专有

必须写死。未约定按非专有。不得用第 24 条反推专有。专有须书面；排他须明文。

### 4. 权项、范围六要素与第 29 条

第 10 条打钩。未列明不得行使。宣传权须限定海报、简介、片断时长。

### 5. 对价、再许可、期满下架

许可费或版税、保底、报数审计。再许可须书面同意。期满下架 SOP。

### 6. 备案、样稿确认、维权资格

备案不是生效条件。普通被许可人一般不得以自己名义起诉，除非特别授权。

### 7. 格式条款与强制规范

无核验引文则法律结论字段停止。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把转让改成许可外壳、把未约定专有改成可对抗第三人的独家、人身权买断、许可禁止出版传播的作品。
- `字段停止`：法域、动态规则、集管范围、备案对抗、权属或在先专有未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
