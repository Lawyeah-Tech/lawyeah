# 专利实施许可合同·审查

## 任务目标

在单一立场下，只审查 **技术类合同 / 专利实施许可合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文显示名为「专利实施许可合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、无效宣告或侵权诉讼策略、有效性保证、把专利权转让改成许可或把许可改成权属过户。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **普通 / 排他 / 独占必须点名**：标题或首部写清许可方式。独占＝约定范围内仅被许可人实施、许可人自己也不得实施；排他＝仅许可一个被许可人、许可人可自行实施；普通＝许可人可再许可他人并自行实施。未约定或约定不明：现有依据支持认定为普通实施许可。禁止用“独家授权”“全权许可”含糊带过。
2. **备案不是生效要件**：合同原则上自成立时生效。当事人应自合同生效之日起 3 个月内向国务院专利行政部门（国家知识产权局）办理备案。备案是行政管理与证明、结汇、补贴、维权举证用途，**不替代权属登记，也不因未备案写成合同未生效或当然无效**。修改句写清谁在几日内提交、对方如何配合、逾期后果；不得把备案写成“登记后专利权转移”。
3. **许可与转让切开**：本类型只让渡约定范围内的实施权，专利权仍登记在许可人名下。出现“专利权归乙方所有”“办理专利权人变更/转让登记后生效”“转让价款”等权属过户主给付 → 负触发 `专利权转让合同·审查`。不得删掉过户句后按许可审完，也不得把许可备案改写成专利法第十条的转让登记。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签专利实施许可正文，尚未签署，尚未成争，核心给付是专利权人或有分许可权的人许可对方在约定范围实施已授权专利并收取使用费，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主给付是专利权权属转移、办理专利权人变更登记 → `专利权转让合同·审查`；
- 主给付是专利申请权转移 → `专利申请权转让合同·审查`；
- 标题或主轴是概括“技术转让”且同时打包专利权转让 → `技术转让合同·审查`；不得把转让条款当许可改完；
- 标题是“技术许可”但标的不是已授权专利，或混有多类技术许可且无法拆出专利实施条款 → `技术许可合同·审查`；
- 主给付是未公开技术秘密的使用许可，或专利申请公开前的许可 → `技术秘密使用许可合同·审查`；
- 撮合专利许可、只收中介费、不自己实施也不自己许可 → `撮合专利许可只收中介费不自己实施也不自己许可→`（P1；专业版未装则 `unavailable`）；
- 尚待研发、不保证成果必然产生 → `技术开发合同·审查` / `委托开发合同·审查` / `合作开发合同·审查`；
- 提供技术意见或劳务性技术服务，不授予实施权 → `知产技术咨询·审查` / `知产技术服务·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `专利实施许可合同·起草`；
- 已签只问缴费日、资料交付日、备案进度 → 本套导航的履约步骤；
- 已催告、解除、索赔、无效宣告争讼、侵权诉讼或仲裁策略 → `或知产争议专项。` 或知识产权争议专项。

禁止质疑有效性、无偿独占回授、搭售非必要物料、明显限制竞争：只出告知与删除句，不改成可履行垄断结构。用户坚持保留：整体停止。

## 建立审查坐标

确认：使用者与授权；单方立场（许可人侧或被许可人侧择一）；相对方；全文及专利清单 / 登记簿副本 / 资料清单版本；专利号与法律状态是否可见；普通 / 排他 / 独占是否点名；地域、期限、实施方式（制造、使用、许诺销售、销售、进口）；使用费结构；备案协作义务；年费由谁缴纳；共有人是否闭合；是否夹带权属转让；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的使用费、提成比例、期限用 `【待填】`，不编造。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `专利实施许可合同·起草`；已签履约 → 本套导航履约步骤；已成争或无效/侵权诉讼策略 → 合同争议。未签且目标是评改已有许可文本，才进入本任务。

### 1. 类型锁死与转让切开

标题、核心给付与对价方式一致才继续。权属转让、申请权转让、技术秘密许可、概括技术许可、开发或咨询服务负触发。

### 2. 主体、共有与专利法律状态

许可人须是登记专利权人或有分许可权的人。共有专利做独占或排他：未取得全体同意则该签署能力字段停止。未核登记簿副本：不写“权属无争议”。

### 3. 许可方式、范围与期限

普通 / 排他 / 独占点名；地域、行为、权利要求范围可核验；期限不得超过专利权存续期。

### 4. 备案、生效与转让登记切开

备案写成生效后 3 个月内的协作义务，不写成合同未备案不生效，也不写成权属变动。

### 5. 使用费、资料交付与年费

入门费、提成、保底分列。许可人默认维持专利权有效并缴年费，另有约定除外。

### 6. 无效处理、非法垄断与格式条款

无效后已付使用费原则上不当然返还，但恶意和显失公平例外必须写明。禁止质疑、无偿独占回授、搭售：删除或整体停止。

### 7. 维权资格、违约与争议

独占可单独主张；排他在专利权人不主张时可单独主张；普通须另行授权。不选定唯一法院充作意见。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证专利必然有效、把权属过户当许可放行、把禁止质疑或无偿独占回授改成可履行结构。
- `字段停止`：法域、专利法律状态、共有人同意、限制/禁止进出口技术、动态规则未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书、无效或侵权诉讼策略，或已锁他类。
