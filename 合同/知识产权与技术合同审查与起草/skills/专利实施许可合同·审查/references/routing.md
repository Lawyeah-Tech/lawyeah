# 边界与路由

本技能只审查 **技术类合同 / 专利实施许可合同** 的待签文本。中文展示名是「审查专利实施许可合同（技术类合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 专利权权属转移、办理专利权人变更登记、转让价款 | `专利权转让合同·审查`。不得删掉过户句后按许可审完，也不得把许可备案改成转让登记 |
| 专利申请权转移 | `专利申请权转让合同·审查` |
| 概括技术转让，同时打包专利权或申请权转让 | `技术转让合同·审查` |
| “技术许可”但标的不是已授权专利，或专利、技术秘密、软件许可缠在一起无法拆条 | `技术许可合同·审查`。不得用本技能把邻类许可改完 |
| 未公开技术秘密使用许可，或专利申请公开前的许可 | `技术秘密使用许可合同·审查` |
| 集成电路布图、植物新品种、软件著作权许可为主给付 | `集成电路布图设计专有权许可合同·审查` / `植物新品种权许可合同·审查` / `计算机软件著作权许可合同·审查`。专业版未装则 `unavailable`，不得硬套本技能 |
| 只撮合专利许可、收中介费 | `撮合专利许可只收中介费不自己实施也不自己许可→`。P1：专业版未装则 `unavailable` |
| 尚待研发、不保证成果必然产生 | `技术开发合同·审查`、`委托开发合同·审查` 或 `合作开发合同·审查` |
| 技术咨询意见或劳务性技术服务，不授予实施权 | `知产技术咨询·审查` / `知产技术服务·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `专利实施许可合同·起草` |
| 已签未争、只问履约节点或备案进度 | 本套导航的履约步骤 |
| 已成争，或用户要无效宣告 / 侵权诉讼策略 | `或知产争议专项。` 或对应专项领域 |
| 限制/禁止类技术进出口审批为主轴 | 字段停止并点名跨境技术进出口专项；不在本任务代做目录归类或许可证申请 |
| C 端大众快检 | 只分流，不回改 |

许可正文里夹带一小段配套技术秘密交付：可审“为实施该专利所必需的资料清单”；秘密点成为主给付则交接 `技术秘密使用许可合同·审查`。夹带一小段“期满可协商转让”：专条交接 `专利权转让合同·审查`，许可方式、备案、使用费条款可继续审。用户坚持本技能把转让、概括技术许可或技术秘密许可整案改完：`目标停止`。
