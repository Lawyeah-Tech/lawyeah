# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的使用费、提成、期限；把已失效《合同法》技术合同章或《技术合同法》写入结论；把未约定许可方式写成独占；把未备案写成合同未生效或无效；把许可备案写成专利法第十条的转让登记；把口头“权属没问题”写成已核登记簿；把禁止质疑或无偿独占回授改成可履行结构；把专利权转让当成已完成的本类型审查。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查专利实施许可合同（技术类合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》技术合同章、《技术合同法》及其实施条例、2001 年备案管理办法或 1984 年专利法原文时，记噪声，不得写入 `L#`。不得把商标许可备案对抗规则写入 `L#`。

## 3. 类型与加载路径

父级 `技术类合同`，子级 `专利实施许可合同`。定性理由、易混切开结果（专利权转让、申请权转让、概括技术转让、概括技术许可、技术秘密使用许可、开发、咨询服务、中介）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、共有、法律状态与文本版本

主体表：签约名、履行名、付款名、发票名、授权签字人、共有专利权人。状态表：专利号、授权日、剩余有效期、年费、无效宣告、质押、在先独占/排他许可。版本表：正文、专利清单、登记簿副本、资料清单、聊天确认；冲突并列。未核登记簿或共有人同意：该签署能力字段停止。

## 5. 许可方式、范围、使用费与备案

核心给付是否仅为实施权而非权属过户；普通 / 排他 / 独占是否点名并与自用、再许可一致；地域、实施方式、权利要求范围；期限是否截在存续期内；入门费 / 提成 / 保底；资料交付；生效后 3 个月内向国家知识产权局备案的协作义务。缺口标 `G#`。不输出专利权转让登记主路径。

## 6. 无效处理、非法垄断与格式条款

第四十七条的不当然追溯、恶意赔偿与显失公平返还是否写全；年费维持；禁止质疑、无偿独占回授、搭售是否删除。是否构成格式条款。强制规范只按第 153 条和解释第 16 条区分，不用失效口诀。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把框架里的 3–5 年 / 5–7 年写成法定期限，不得把“免费回授”写成默认句。

## 9. 谈判与签署提醒

谈判顺序：先红线（权属过户错位、许可方式与自用/再许可打架、超存续期、禁异议/无偿独占回授、把备案改成转让登记），再必须改（点名三类型、3 个月备案协作、年费、无效例外、维权资格、共有人同意），最后可优化。签署提醒：专利清单、登记簿副本、资料清单、共有人同意书入附件；生效日与备案申请日分列。不指导倒签或补假备案。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书、无效或侵权诉讼策略或效力保证，也不是专利权转让审查。
