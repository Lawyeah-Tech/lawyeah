# 审查方法（锁定 技术类合同 / 专利实施许可合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制专利权转让的登记过户主路径、概括技术许可的多标的扫描、技术秘密许可的秘密点清单，或商标许可“未备案不得对抗善意第三人”。

定性校验：标题、核心给付与本类型一致才继续；权属转让、申请权转让、技术秘密许可、概括技术许可、开发或咨询服务明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、专利必然维持有效、对方必然接受或唯一必得使用费。

`search_law` 返回已失效《合同法》技术合同章、《技术合同法》及其实施条例、2001 年《专利实施许可合同备案管理办法》、1984 年专利法原文时记为噪声，不得写入 `L#`。备案办法第 4 条仍引用《合同法》：办法 2011 本现行有效，但不得把失效合同法写入 `L#`。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。国知局许可合同范本、技术转让或技术秘密许可范本不得直接粘成本约。

知识库纠正（不回写双文件）：

- `基本面.md` / `框架.md` 电子类 3–5 年、传统制造 5–7 年：实务量级，不是法定期限。期限闸是“不得超过专利权存续期”。
- `框架.md` “免费回授许可”：无偿提供改进、非互惠转让或无偿独占/共享改进知识产权，属于民法典第 850 条所称非法垄断技术（技术合同解释第 10 条第（一）项）。不得写成可放行默认。
- `基本面.md` “许可费不因专利被宣告无效而返还”：专利法第四十七条的原则是对已履行许可合同不当然追溯，但专利权人恶意造成损失应赔偿；不返还明显违反公平原则的，应全部或部分返还。不得删掉这两条例外。
- `框架.md` “备案虽不具有对抗效力”：正确。禁止套用商标法使用许可备案的对抗规则。
- 破产持续履行条款：可谈，但不保证在企业破产程序中必然排除管理人解除权。不得写成已经可执行的破产豁免。

支持切开的规范（法律结论须运行时复核）：

- 民法典第 863 条：技术转让包括专利权转让、专利申请权转让、技术秘密转让；技术许可包括专利实施许可、技术秘密使用许可。两类均应书面。
- 专利法第 10 条：专利申请权或专利权转让须书面合同，向国务院专利行政部门登记并公告，**转让自登记之日起生效**。
- 专利法第 12 条：实施他人专利应订立实施许可合同并支付使用费；被许可人无权允许合同规定以外的单位或个人实施。
- 技术合同解释第 29 条：申请公开前适用技术秘密许可；公开后授权前参照专利实施许可；授权后即为专利实施许可。不以“尚未授权”单独认定合同无效。

## 节点 2　主体、共有与专利法律状态

### 2.1 主体表

建表：签约名、履行名、付款名、发票名、授权签字人。名称不一致不自动合并。许可人须是专利登记簿上的专利权人，或能出示分许可权来源的被许可人。口头“我们老板同意了”不得写成已授权。

### 2.2 共有专利（硬闸）

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |

### 2.3 法律状态与在先冲突许可

审查清单，缺一项则该字段不得写成已闭环：

1. 专利名称、专利号（ZL+数字）、申请日、授权日、专利类型、剩余有效期。
2. 是否处于年费滞纳、无效宣告、质押、保全、开放许可或强制许可。
3. 是否已存在互相冲突的独占或排他许可。
4. 许可的是全部权利要求还是列明的部分权利要求。

材料未提及不得写成“无权利负担”，只能写 `依据不足`。开放许可期间再给独占或排他：红线（细则第 86 条指向的障碍）。强制许可或开放许可作为主轴：不按自愿双边许可改完，字段停止并点名转出。

## 节点 3　许可方式、范围与期限（硬闸）

### 3.1 普通 / 排他 / 独占必须点名

支持依据：技术合同解释第 25 条。

| 文本写法 | 动作 |
| --- | --- |
| 标题或首部写明普通 / 排他 / 独占，且与能否自用、能否再许可第三人的正文一致 | 正触发，留下本类型 |
| “独家授权”“全权许可”“唯一合作”但未写许可人能否自用、能否再许可 | 必须改。点名三选一；未改则现有依据支持按普通实施许可解释 |
| 独占，但保留许可人生产线自用 | 名实冲突。改为排他，或删除自用保留 |
| 排他，但许可人可再许可其关联公司 | 必须改：再许可第三人会击穿排他；或改成普通 |
| 空白许可方式 | 必须改。不写“可以先签，以后补类型” |

修改句：

「甲方将专利号【待填】以【普通实施许可 / 排他实施许可 / 独占实施许可】许可乙方实施。若选择独占：在约定范围（地域【待填】、期限【待填】、实施方式【待填】）内，甲方不得自行实施，也不得再许可任何第三人。若选择排他：甲方可自行实施，但不得再许可第三人；甲方不具备独立实施条件而以一个普通许可方式许可他人实施的，可视为甲方自己实施，但双方另有书面约定的除外。若选择普通：甲方可自行实施并可再许可第三人。未在本合同中点名许可方式的，双方确认按普通实施许可履行，不得事后主张独占或排他。」

分许可：未经点名，被许可人不得再许可（专利法第 12 条、民法典第 867 条）。即使允许再许可，除另有约定外认定为普通实施许可。

交叉许可：拆成两组对向的许可方式、范围与使用费（或互免范围），不得用“技术互换”四个字代替。

### 3.2 范围与期限

范围包括期限、地域、方式以及接触配套技术秘密的人员（解释第 28 条）。实施方式对照专利法第 11 条：制造、使用、许诺销售、销售、进口（外观设计无“使用”）。

| 文本写法 | 动作 |
| --- | --- |
| 期限空白，或写“长期”“永久” | 必须改：写起止日；并加“不得超过该专利权存续期限” |
| 许可期限超过授权公告载明的届满日 | 红线截断至存续期满；超期部分现有依据不支持继续作为专利实施许可 |
| 专利权届满或已被宣告无效后仍就该专利订许可 | 红线。民法典第 865 条：不得就该专利与他人订立专利实施许可合同 |
| 未约定地域 | 必须改。不得默认全球 |
| 未约定实施方式 | 必须改。列明是否包含制造、使用、许诺销售、销售、进口 |

期限未约定且依第 510 条仍不能确定：解释第 28 条第 2 款称不受期限限制——这会与第 865 条的存续期上限冲突。本任务处理：修改句仍写入存续期上限；不得把“未约定期限＝可实施到专利失效之后”写成可放行结构。

## 节点 5　使用费、资料交付与年费

### 5.1 使用费闭环

价金构成、币种、税、发票、支付节点分列。入门费、运行提成、保底分列。未给出的数字写 `【待填】`。禁止编造提成比例。

“销售收入”未定义：必须改成可审计口径（例如扣除增值税、退货和运费后的净额，或以开票金额为准）。许可人审计权可保留每年不超过一次，费用负担和异议期写清。

独占或排他可约定最低提成；未达标是否降为普通许可必须点名，不得写成许可人可任意解除且已付入门费不退、同时继续限制被许可人。

定金：必须使用“定金”二字才讨论罚则。约定或推算超过主合同标的额百分之二十：超过部分不产生定金效力。无核验引文不得把 20% 写成现行法结论。

### 5.2 资料交付与技术指导

许可人应按约许可实施、交付实施专利有关的技术资料、提供必要技术指导（民法典第 866 条）。禁止只写“提供必要协助”。

专利文本往往不足以投产。配套技术秘密应另列资料清单、交付节点和验收标准。秘密点成为主给付且专利实施只是附带：负触发 `技术秘密使用许可合同·审查`。本类型可审“为实施该专利所必需的配套资料”条款，不展开技术秘密许可整案。

### 5.3 年费与有效性维持

支持依据：技术合同解释第 26 条。

许可人在合同有效期内负有维持专利权有效的义务，包括依法缴纳年费和积极应对无效请求，但当事人另有约定的除外。缺失年费条款：必须改，不得默示由被许可人承担。

修改句：

「除双方另有书面约定外，甲方应在本合同有效期内按时缴纳专利年费并维持专利号【待填】有效，及时将缴费凭证和官方通知书面抄送乙方。甲方拟放弃专利权或不再续缴年费的，应至少提前【待填】日书面通知乙方；乙方有权在同等条件下优先受让该专利权或自行代缴并在应付使用费中抵扣。因甲方未缴费或怠于应对无效请求导致专利权终止或被宣告无效，且无可归责于乙方的原因的，乙方有权解除本合同，并按第【待填】条处理使用费。」

## 节点 6　无效处理、格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 无效后的使用费（硬闸）

支持依据：专利法第四十七条；民法典第 865 条。

| 文本写法 | 动作 |
| --- | --- |
| “无论何种原因宣告无效，已付和应付使用费均不退、仍须继续支付至期限届满” | 必须改。已履行部分原则上不当然追溯，但恶意赔偿和显失公平返还不得预先放弃；宣告无效后不得就该专利继续收取专利使用费 |
| “一旦无效，甲方立即全额退还全部使用费及利息” | 可谈，但不得写成第四十七条的法定义务；知-how 已交付部分可另行作价 |
| 完全不提无效 | 必须补：已履行不当然返还；后续专利使用费停止；知-how 对价拆分；恶意与显失公平例外 |

修改句：

「专利权被宣告无效的，该专利权视为自始即不存在。宣告无效的决定对已经履行的本许可合同不当然具有追溯力；已支付的专利使用费原则上不返还。但因甲方恶意给乙方造成损失的，甲方应当赔偿；不返还明显违反公平原则的，甲方应当全部或部分返还。专利权被宣告无效后，乙方无需继续支付以该专利实施权为对价的使用费；若本合同同时包含技术秘密交付，双方应按附件【待填】列明的知-how 对价继续或终止该部分，不得把知-how 对价与专利使用费混算。本条不妨碍乙方依据民法典第 865 条拒绝就已被宣告无效的专利继续订立或续展许可。」

最强反方：被许可人主张无效后合同全部自始无效、应退全部费用；许可人主张“已写不返还即可排除第四十七条第三款”。两说均不得写成唯一结论。

### 6.2 格式条款

为重复使用而预先拟定、订立时未与对方协商。依据示范文本制作，不当然排除格式条款。

审查：许可方式、使用费、无效不退、禁异议、管辖/仲裁等异常条款是否有足以引起注意的标识，以及是否按要求说明（第 496 条；解释第 10 条）。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在附件 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

### 6.3 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的、是否仅行政管理、是否只规制履行行为（第 153 条；合同编通则解释第 16 条）。禁止用已失效“效力性/管理性”口诀。未备案主要是监管与举证后果，不得单独写成民事合同当然无效。非法垄断技术、侵害他人技术成果：不改写成有效履行。

## 节点 7　维权资格、违约与争议

1. 第三方侵权时的起诉 / 行政裁决资格必须与许可方式匹配（《专利纠纷行政裁决和调解办法》第 12 条，法律结论须复核）：独占被许可人可单独提出；排他被许可人在专利权人不请求时可单独提出；普通被许可人除合同另有约定或专利权人另行授权外不能单独提出。修改句按所选许可方式落权，不得给普通许可人写“当然可独立起诉”。
2. 超范围实施、擅自再许可：停止违约行为并承担违约责任（民法典第 873 条）。只有“依法承担违约责任”视为必须改。
3. 逾期支付使用费：补交、违约金、停止实施、交还资料。不在本任务做第 585 条精算。修改句避免“不得调整”或“按总价 30% 必得”。
4. 构成违约不等于当然解除。法定解除路径只点名催告或目的不能实现，不在本任务作出已解除结论。
5. 争议解决：出现仲裁条款，不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核，修改句改成单一仲裁机构或单一法院连结点。专属管辖可能：只标红旗，不选定唯一法院充作法律意见。
6. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

打开已加载的 `框架.md`，按六步逐段对照正文。`基本面.md` 用于校验类型、主体、许可方式、备案和红旗，不代替本节点出句。

| 步 | 动作 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题用专利实施许可；点名普通/排他/独占；主体与登记专利权人一致；鉴于列专利号、申请日、授权日、剩余有效期，不写“保证专利永不无效” | 标题或主体修改句 |
| 交易条款 | 许可方式与自用/再许可；地域、行为、权利要求；期限≤存续期；使用费与审计；资料清单 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 备案协作；年费维持；无效后使用费与知-how 拆分；维权资格与许可类型匹配；后续改进互利分享 | 可执行后果句或删除句 |
| 尾部 | 签署权限；生效≠备案≠转让登记；专利清单、登记簿副本、资料清单、共有人同意书入附件 | 生效与附件修改句 |
| 语言 | 正说加反说；盯死许可 vs 转让、备案 vs 登记、独家 vs 独占/排他、使用费 vs 转让价款、定金 vs 入门费 | 替换空词的句子 |
| 常见问题 | 许可方式空白；未备案写成未生效；备案写成权属过户；超期许可；无偿独占回授；禁异议；年费缺位 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（权属过户主轴、许可方式与自用/再许可互相打架且拒改、超存续期、禁异议/无偿独占回授拒删、倒签或补假备案、把备案改成转让登记）；
- `必须改`：可谈但签署前要落句（点名三类型、3 个月内备案协作、年费、无效例外、维权资格、共有人同意）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级入门费且专利法律状态未核、用户拒绝升级：停止“可以签署”建议。

后续改进：可按互利原则约定分享办法；没有约定或约定不明且依第 510 条仍不能确定的，一方后续改进的技术成果，其他各方无权分享（民法典第 875 条）。修改句可写“谁改进谁所有 + 互惠普通许可”，不得写无偿独占回授。
