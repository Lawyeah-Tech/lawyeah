# 计算机软件著作权许可合同·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构，不证明本约条款已被接受。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、已失效《技术合同法》及其实施条例、1991 年《计算机软件保护条例》、1992 年《计算机软件著作权登记办法》当作本类型默认规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只按已谈妥条件起草 **计算机软件著作权许可合同** 己方稿，出稿后用本类型硬闸自审。交付草稿、未决项、自审风险表和自审后修改句。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。中文显示名为「计算机软件著作权许可合同·起草」。`depends-on` 为空。不要求先跑导航。

主线是**现有计算机软件著作权财产权利的使用授权**：许可人保留权属，被许可人在约定期限、地域和方式内行使已点名的财产权利并付费。法律路径是民法典第八百七十六条**参照适用**技术合同节，同时受《著作权法》与《计算机软件保护条例》规制。不是知产父级的分发／自用双轨，不是权属转让，也不是委托开发。

不交付：他类审查、从零起草、履约交底、争议文书、有效性或开源合规终局保证、知产分发／自用本约或转让／开发本约的整份代审。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **技术合同节路径**：本技能只走「技术类合同 / 计算机软件著作权许可合同」。第八百七十六条把软件著作权许可参照适用技术合同节；解释第一条将计算机软件列入技术成果。不得改走知产父级「软件许可合同（分发许可模式）／（自用许可模式）」的 SKU／渠道或纯内部安装双轨。
2. **许可使用 ≠ 转让**：许可人保留软件著作权。权属过户、登记权利人变更、一次买断全部财产权 → `计算机软件著作权转让合同·审查`（技术类转让）或 `软件著作权转让合同·审查`（知产转让）。不得删掉买断句后继续当本类型审。
3. **与知产父级许可切开**：用户或引擎已锁定「知识产权相关合同」且核心是渠道／OEM／预装出货 → `软件许可合同（分发许可模式）·审查`；已锁定知产货架且仅内部安装、禁止再分发 → `软件许可合同（自用许可模式）·审查`。不得复制其 method，不得把分发／自用写成技术类默认主路径。
4. **未明确的权利不得行使**：复制、发行、出租、信息网络传播、修改／二次开发必须点名。空写“合法使用／全部授权”视为必须改。未明确专有的，视为非专有／普通许可。
5. **成立即生效，登记不是生效要件**：国内许可合同成立即生效。向中国版权保护中心办理专有许可合同登记是初步证明和举证辅助，不是物权对抗或生效条件。不得用 1992 年失效办法写成“未登记不能对抗第三人”。向外国人许可须遵守技术进出口管理条例。
6. **标的与交付可特定化**：软件名称、版本、登记号（如有）、目标程序还是源码、文档清单、安装限额（终端／CPU／席位／站点）必须落句。只有“有关软件系统”视为必须改。
7. **开源传染、850 与境外交付**：未披露 GPL 等强传染开源仍要二次开发放行 → 红线。无偿独占回授、禁止质疑权利有效性、禁止从他源获得竞争软件 → 参照第八百五十条删除。未批向境外交付限制进出口软件：履行字段停止。

## 工作边界

正触发：已有可读待签正文或可单独评改的软件著作权许可专章，尚未签署，尚未成争；标的是现有计算机软件；核心给付是保留权属下的著作权财产权利许可；父级是技术类合同。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 权属买断、登记权利人变更、许可人永久退出该软件一切财产权 → `计算机软件著作权转让合同·审查` 或 `软件著作权转让合同·审查`；
- 已锁定知识产权相关合同，且核心是 OEM／渠道／预装／再分发出货 → `软件许可合同（分发许可模式）·审查`；
- 已锁定知识产权相关合同，且仅内部安装、禁止再分发 → `软件许可合同（自用许可模式）·审查`；
- 尚待开发或委托交付可运行软件为主给付 → `软件委托开发合同·审查` 或 `技术开发合同·审查`／`委托开发合同·审查`／`合作开发合同·审查`；
- 一般文字／美术／视听作品许可 → `著作权许可使用合同·审查`；
- 主文是技术秘密配方／工艺、软件只是载体 → `技术秘密使用许可合同·审查`；
- 主文是专利号与权利要求 → `专利实施许可合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问激活码交付日、维保响应日、审计日 → 本套导航的履约步骤；
- 已成争（侵权索赔、许可费诉讼、盗版查处、立案、开庭、仲裁）→ 合同争议或知产专项，不填签前十节。

未明确权利推定全授、未披露传染性开源仍要二次开发、未批向境外交付：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；代表许可人还是被许可人；正文、技术规格、开源清单、EULA／维保附件版本；是许可还是转让；独占／排他／普通；点名了哪些权利项；目标码还是源码；安装限额；不可接受事项；法域与拟签时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密时，先停止策略输出。不索取完整源码或完整密钥。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的许可费、席位数、期限用 `【待填】`，不编造。

## 起草模式

本原子只承担本类型起草。待签评改转 `计算机软件著作权许可合同·审查`。无完整待签文本、但本类型条件已谈妥、要出己方稿时，留在本任务，不转 `计算机软件著作权许可合同·起草`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

1. 先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。下表把本类型硬闸改成正文必写、附件必附或禁止出现。商业数字未给用 `【待填】`。
2. 出稿后必须用「本类型硬闸」和 [审查方法](references/method.md) 再审自己的稿，输出风险表和修改句。不得只交白稿。
3. 他类型出稿、已签履约、已成争：仍负触发。

### 起草必写

- 走技术类合同路径；民法典第八百七十六条参照适用技术合同节。
- 许可人保留软件著作权，只授已点名的财产权利。
- 复制、发行、出租、信息网络传播、修改／二次开发必须点名；未明确专有的视为非专有／普通许可。
- 国内许可合同成立即生效；向中国版权保护中心办理专有许可合同登记只作初步证明和举证辅助。
- 软件名称、版本、登记号（如有）、目标程序还是源码、文档清单、安装限额（终端／CPU／席位／站点）必须落句。
- 向外国人许可须遵守技术进出口管理条例。

### 附件必附

- 软件名称、版本、登记号（如有）与文档清单。
- 安装限额表（终端／CPU／席位／站点）。
- 开源披露清单。

### 禁止出现

- 改走知产父级分发／自用双轨。
- 权属过户、登记权利人变更、一次买断全部财产权。许可不得写成权属已转移。
- 空写“合法使用／全部授权”。
- 专有许可合同登记写成物权对抗或生效条件。
- 用 1992 年失效办法写成“未登记不能对抗第三人”。
- 只有“有关软件系统”。
- 未披露 GPL 等强传染开源仍要二次开发放行。
- 无偿独占回授、禁止质疑权利有效性、禁止从他源获得竞争软件。
- 未批向境外交付限制进出口软件。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、把权属买断当许可放行、把未明确权利改成全授、把未批境外交付改成可履行、保证有效或不侵权。
- `字段停止`：未见许可／转让定性所需权属句；未见点名权利项；未见版本与交付物；许可方式或安装限额缺失；共有人或职务作品权属未见；进出口未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或文本已滑入转让／知产分发／知产自用／开发。

生存级许可费或个人无限连带且用户拒绝升级：停止“可以签署”建议。
