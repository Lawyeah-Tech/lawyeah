# 边界与路由

本技能只审查 **技术类合同 / 植物新品种权许可合同** 的待签文本。中文展示名是「审查植物新品种权许可合同（技术类合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 品种权或申请权权属转移、办理品种权人变更登记、转让价款 | `植物新品种权转让合同·审查`。不得删掉过户句后按许可审完，也不得把许可备案改成条例第十一条的转让登记。禁止抄该原子 method |
| 集成电路布图设计专有权许可为主给付 | `集成电路布图设计专有权许可合同·审查`。专业版未装则 `unavailable`，不得硬套本技能 |
| 计算机软件著作权许可为主给付 | `计算机软件著作权许可合同·审查`。专业版未装则 `unavailable`，不得硬套本技能 |
| 已授权专利实施许可、向国家知识产权局备案 | `专利实施许可合同·审查`。不得把国知局 3 个月备案规则套到本类型 |
| 未公开技术秘密使用许可 | `技术秘密使用许可合同·审查` |
| “技术许可”但标的不是已授权品种，或品种权、专利、软件许可缠在一起无法拆条 | `技术许可合同·审查`。不得用本技能把邻类许可改完 |
| 只撮合品种许可、收中介费 | `撮合专利许可只收中介费不自己实施也不自己许可→`。P1：专业版未装则 `unavailable` |
| 尚待研发、不保证成果必然产生 | `技术开发合同·审查`、`委托开发合同·审查` 或 `合作开发合同·审查` |
| 技术咨询意见或劳务性技术服务，不授予实施权 | `知产技术咨询·审查` / `知产技术服务·审查` |
| 已有可读待签文本要评改 | `植物新品种权许可合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、只问履约节点或备案进度 | 本套导航的履约步骤 |
| 已成争，或用户要无效宣告／侵权诉讼策略 | `或知产争议专项。` 或对应专项领域 |
| 对外提供种质资源审批、转基因安全评价为主轴且用户要代办许可 | 字段停止并点名行政审批路径；不在本任务代做目录归类或许可证申请 |
| C 端大众快检 | 只分流，不回改 |

许可正文里夹带一小段配套育种技术秘密交付：可审“为实施该品种所必需的亲本与繁育规程清单”；秘密点成为主给付则交接 `技术秘密使用许可合同·审查`。夹带一小段“期满可协商转让”：专条交接 `植物新品种权转让合同·审查`，许可方式、备案、使用费条款可继续审。用户坚持本技能把转让、专利实施许可或软件许可整案改完：`目标停止`。
