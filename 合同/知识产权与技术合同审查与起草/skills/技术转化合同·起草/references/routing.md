# 边界与路由

本技能只审查 **技术类合同 / 技术转化合同** 的待签文本。中文展示名是「审查技术转化合同（技术类合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 订立时尚不存在技术方案；一方出资，另一方独立研发 | `委托开发合同·审查`；标题或目录落在委托技术开发则 `委托合同目录下的委托技术开发主文件且用户未锁定本类型→` |
| 各方分工参与新技术、新产品研究开发，不是就已有成果做工业化 | `合作开发合同·审查` |
| 未区分委托/合作/转化的《技术开发合同》 | `技术开发合同·审查` 或回引擎重新定性 |
| 可运行软件、系统上线、源码交付且几乎无中试不确定性 | `软件委托开发合同·审查` |
| 让与已有专利、专利申请权或技术秘密，无后续试验、开发、应用 | `技术转让合同·审查` / `专利权转让合同·审查` / `专利申请权转让合同·审查` / `技术秘密转让合同·审查` |
| 许可实施已有专利或使用技术秘密，底层权利不改，亦无工程化任务 | `技术许可合同·审查` / `专利实施许可合同·审查` / `技术秘密使用许可合同·审查` |
| 特定技术项目可行性、技术预测、工艺评价、FTO，不实施转化 | `知产技术咨询·审查`；文本落在委托技术咨询目录则 `委托合同目录下的技术咨询→` |
| 解决特定技术问题、调试、培训，不以工业化应用为目标 | `知产技术服务·审查`；文本落在委托技术服务目录则 `委托合同货架按处理事务费用预付任意解除起草的同名《技术服务合同》→` |
| 技术折价入股、设立或增资合资公司并办理股权变更为主给付 | 回引擎按公司/出资类重新定性；本任务不按转化增量权属改完 |
| 撮合双方订立转化合同，自己不提供成果也不实施 | 回引擎按中介重新定性 |
| 已有可读待签文本要评改 | `技术转化合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或知产争议专项。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

转化正文里夹带一小段已有专利普通许可或咨询评价：专章交接对应原子；阶段性成果、职务授权、失败定性和阶段验收条款可继续审。用户坚持本技能把委托开发、合作开发、技术转让或技术入股整案改完：`目标停止`。
