# 技术培训合同·审查

## 任务目标

在单一立场下，只审查 **技术类合同 / 技术培训合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文显示名为「技术培训合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、把动手解决问题写成培训、把尚待研发写成已可传授、把劳动合同服务期或职业/文化培训写成技术培训。

## 本类型硬闸

1. **传授已有技术（正像）**：正像是受托人把**已经掌握**的特定项目专业技术，对委托人**指定学员**做训练和技术指导。标的是“教人会”。问题未写到可识别的技术项目、学员未指定：必须改。禁止放行“提供有关技术培训”“负责相关培训事项”。
2. **培训 ≠ 开发 ≠ 服务**：订立时尚不存在、当事人尚未掌握的技术方案要研究开发 → `技术开发合同·审查` / `委托开发合同·审查` / `合作开发合同·审查`。主给付是受托人动手解决特定技术问题（调试、排故、改工艺、保证修好）→ `知产技术服务·审查`。开发或转让主文件里夹带培训专章：按主给付走对应原子，不得单独按本类型改完。
3. **解释第 36 条排他**：不包括职业培训、文化学习和按行业、法人或者非法人组织计划进行的职工业余教育。用人单位与劳动者的专项培训服务期 → `法人或者非法人组织计划进行的职工业余教育。用人单位与劳动者的专项培训服务期→`。禁止把劳动合同法第 22 条服务期、违约金上限写成技术培训法定默认。
4. **工作条件默认委托人**：解释第 37 条第 1 款，场地、设施和试验条件无约定或约定不明的，由**委托人**负责提供和管理。禁止把第 886 条“正常费用一律受托人负担”覆盖培训场地。差旅、食宿必须点名，不编法定负担方。
5. **学员 / 教员准入与报酬分轨**：委托人派出的学员不符合约定条件、影响培训质量的，仍按约定支付报酬。受托人配备的教员不符合约定条件影响质量，或未按照计划和项目培训导致不能实现约定培训目标的，应当减收或者免收报酬。
6. **通知改派**：发现对方人员不符须在合理期限通知；未通知，或接到通知未按约改派，由负有履行义务的当事人承担相应民事责任。“3 个工作日”是本类型谈判量级，不是法定期限。
7. **考核客观化，不抄服务质保应急**：结项看教学大纲完成度、约定考核或实操测试。禁止以“学员感觉不好”拒付，也禁止以“上完课即全额”无视教员不合格或未按计划。禁止把技术服务的“保证修好 + 3–6 个月质保 + 4–8 小时应急”当成本类型主路径。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签技术培训正文，尚未签署，尚未成争，核心给付是向指定学员传授**已有**特定项目专业技术，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主给付是动手解决特定技术问题、保证修好或调通 → `知产技术服务·审查`；用户指定狭义服务细分主文件 → `技术服务合同（狭义）·审查`（P1）；
- 尚待研究开发、成果尚不存在 → `技术开发合同·审查`；已独立成册的委托开发 / 合作开发 → `委托开发合同·审查` / `合作开发合同·审查`；
- 只出可行性、技术预测、专题调查、分析评价 → `知产技术咨询·审查`；
- 为与第三人订立技术合同做联系介绍 → `技术中介合同·审查`（P1）；
- 用人单位与劳动者约定专项培训费用、服务期、离职违约金 → `法人或者非法人组织计划进行的职工业余教育。用人单位与劳动者的专项培训服务期→`；
- 职业培训、文化学习、职工业余教育、驾校厨师通识课 → 本套导航的类型切开步骤 重新定性；
- 无文本、本类型条件已谈妥、要出己方稿 → `技术培训合同·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁 → `或知产争议专项。` 或对应专项。

名为培训、实为把人员交给对方考勤指挥的劳动派遣结构：只出告知，转 `或劳动专项，不改写成可履行派遣。挂靠违法分包未批限制进出口仍要跨境交付：只出告知，不改写成可履行路径。` 或劳动专项，不改写成可履行派遣。挂靠、未批限制进出口技术仍要现场传授：只出告知，不改写成可履行路径。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及大纲/学员名单/教员简历/场地清单/考核标准版本；**特定技术项目**名称；学员是否指定及准入条件；教员资格与可否更换；场地设施由谁提供；考核方式；报酬与差旅食宿；教材与新成果归属；实操安全；是否夹带开发或服务主给付；是否其实是劳动者服务期协议；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`框架.md` “本合同参照技术服务合同规定执行”只对应第 887 条残余：解释第 36、37 条已另有规定的，不得再灌入服务的保证修好、886 场地费用或质保应急主路径。“3 个工作日”是谈判量级，不是法定期限。教材“通常归受托人”是约定方向，不是法定默认。认定登记不是合同生效要件。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `技术培训合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有技术培训文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。开发、服务、劳动服务期、职业/文化培训、中介负触发。

### 2. 主体、指定学员、教员与特种作业

签约名、履行名、付款名、发票名分列。学员名单与准入条件必须可见。教员资格写入附件。特种设备或特种作业未提及则资质字段停止。

### 3. 特定项目、大纲与考核

项目名称写到可识别。大纲、课时、地点、考核方式必须有。删除“甲方满意即合格”或“感觉不好即可拒付”。

### 4. 工作条件默认委托人

场地、设施、试验条件无约定则按委托人提供改。差旅食宿点名。设施可用性由负担方担保。

### 5. 学员 / 教员分轨与通知改派

学员不符仍付报酬。教员不符或未按计划则减收或免收。通知期限用 `【待填】` 或双方已谈日数，不写法定期限。

### 6. 教材、新成果、保密与拍摄

885 残余：新成果无约定归完成者。教材归属必须另约。禁止未授权拍摄上传。接触工艺和数据的保密必须改。

### 7. 格式条款、实操安全与强制规范

无核验引文则法律结论字段停止。人身损害、故意或重大过失财产损失不得免责。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把空项目或通识课改成可履行技术培训、把劳动服务期或“保证修好”写成培训法定默认、把未批限制进出口技术改成先传授后补批。
- `字段停止`：法域、动态规则、特种作业许可、进出口目录、认定登记能否免税未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁服务、开发、劳动服务期、职业/文化培训。
