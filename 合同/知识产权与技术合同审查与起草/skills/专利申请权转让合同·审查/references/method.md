# 审查方法（锁定 技术类合同 / 专利申请权转让合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制专利权转让、买卖、施工或许可合同 method。

定性校验：标题、核心给付与本类型一致才继续；已授权专利权、尚未提出申请的权利、技术秘密、实施许可或他类明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、必然授权或唯一必得金额。

`search_law` 返回已失效《合同法》及其解释、已失效《技术合同法》及其实施条例、已失效专利审查指南或已失效专利实施许可备案办法时记为噪声，不得写入 `L#`。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。专利局监制的专利权转让合同范本只证明邻类栏目，不得当本类型正文。

知识库纠正（不回写双文件）：

- `框架.md` “全民所有制单位转让可能涉及上级主管部门审批”：源于已失效技术合同法实施条例第十三条。2020 年修正专利法第十条已删除该要求。不得写成现行签署条件。国资、事业单位内部决议另按主体规则字段停止，不套旧条。
- `基本面.md` “需保证该申请符合授予专利权的基本条件（新颖性、创造性、实用性）”：这是可谈的披露/检索义务，不是法定“包过”。不得把第八百七十条“完整、无误、有效”解释成保证最终授权。
- `框架.md` “通常默认为受让人承担授权风险”：商业惯例，必须书面约定。未约定不得写成法定默认由受让人承担或必然退款。
- 2010/2017 审查指南已失效。著录项目变更的操作细节运行时核验现行指南；本任务以专利法第十条、实施细则第一百零六条为登记规范基础。
- 失效实施条例第五十七条“专利申请被驳回的责任”、第六十三条逾期两月解除：只借争点，不把旧期限写入 `L#`。

| 已能支持的事实 | 走向 | 不得写成 |

| 残缺模板，用户要按己方条件重写整稿 | 起草 | 本任务出整稿 |

| 权属诉讼、发明人争议已立案 | 对应知识产权争议路径 | 用本任务做权属裁决 |

缺立场或同时掌握双方秘密：整体停止策略输出。缺书面文本仍要“给个能不能签”：不启动实体审查。

## 节点 1　类型识别与单目录加载

### 1.1 定性（硬闸：申请权 ≠ 已授权专利；与专利权转让切开）

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 已有申请号，尚未授权，移转申请人地位换价款 | 本类型 | 正触发 |
| 已有专利号、授权公告、专利证书，移转专利权人 | 专利权转让 | 负触发 `专利权转让合同·审查` |
| 尚未向专利行政部门提出申请，仅交底或“拟申请” | 申请专利的权利 / 技术转让 | 负触发 `技术转让合同·审查`；秘密信息为主则 `技术秘密转让合同·审查` |
| 不改申请人，只允许实施或使用 | 专利实施许可 / 技术许可 | 负触发 `专利实施许可合同·审查` / `技术许可合同·审查` |
| 标的混杂已授专利、本申请与秘密，无法拆专章 | 概括技术转让 | 负触发 `技术转让合同·审查` |
| 仍在研发，申请权尚未产生或归属未定 | 技术开发 / 委托开发 / 合作开发 | 负触发 `技术开发合同·审查` / `委托开发合同·审查` / `合作开发合同·审查` |

支持切开的规范（法律结论须运行时复核）：

- 专利法第十条：专利申请权和专利权**可以分别转让**；转让须书面合同并向国务院专利行政部门登记，**转让自登记之日起生效**。
- 民法典第八百六十二条、八百六十三条：技术转让包括专利权转让、专利申请权转让、技术秘密转让；许可是另一类；均须书面。
- 民法典第八百六十五条：专利实施许可只在专利权存续期内有效——证明许可与本申请权转让不是同一给付。
- 基本面：申请专利的权利产生于发明完成时；专利申请权以已经提出申请、具有申请号为前提。

同一文本既写申请号又写专利号：并列 `C#`，问清哪一件是主给付。主给付是已授权专利则整案转出，不在本任务改成年费或无效条款。

### 1.2 加载协议（硬闸）

本技能已锁定 **技术类合同 / 专利申请权转让合同**。只打开 `references/基本面.md` 与 `框架.md`。禁止读其他子目录，禁止为对照再开第二类。

### 1.3 违法结构停笔

加载后或定性中出现：以申请权转让规避禁止或限制出口；伪造申请人或发明人；明知申请已驳回/视撤仍谎称有效；把国防或保密专利申请转给无权主体。

动作：

1. 交付告知：可能因违法、违背公序良俗或侵害他人技术成果无效（第 153、850 条），不得改写成可履行文本。
2. 不写可履行的假登记路径、假发明人声明或绕开许可证的出境安排。
3. 风险表只保留识别依据和转出/删除提示。
4. 用户坚持“改到能签且仍做这些事”：整体停止。

## 节点 2　主体、共有与跨境

### 2.1 主体表

建表：签约名、受理通知书记载的申请人、付款名、发票名、授权签字人。名称不一致不自动合并。转让人必须是当前申请人；不是发明人个人，除非受理通知书上申请人就是该个人。

口头“我们老板同意了”不得写成已授权。国资、上市公司、高校院所内部决议或处置程序未附：该签署能力字段停止，不写成“可以盖章”。

### 2.2 共有处分

专利法第十条之外，第十四条：共有人有约定从约定；无约定时，共有人可单独实施或以普通许可方式许可他人实施并分配使用费；**除此以外行使共有专利申请权须全体同意**。转让不属于单独实施或普通许可。

| 文本写法 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 多名申请人，仅部分人盖章 | 字段停止；修改句要求全体共有人作为转让方或出具书面同意 | 已可办理变更 |
| 合作开发一方转让其份额 | 提示民法典第八百六十条其他各方同等条件优先受让；修改句加入优先权放弃或通知程序 | 份额已自由转让完毕 |
| 委托开发后研发人转让 | 提示第八百五十九条委托人优先受让 | 已无优先权负担 |

最强反方：未同意的共有人主张处分无效，变更登记被驳回。不得把“过半数同意”写成已满足第十四条。

### 2.3 向境外转让

专利法第十条第二款：中国单位或者个人向外国人、外国企业或者外国其他组织转让专利申请权，应当依照有关法律、行政法规办理手续。民法典第八百七十七条：技术进出口或专利、专利申请合同另有规定的，依照其规定。

| 情形 | 动作 |
| --- | --- |
| 限制出口技术 | 技术进出口管理条例（2020 修订）第三十条：许可证管理，未经许可不得出口。修改句把许可证作为登记与付款的先决条件。用户要求绕开许可：整体停止 |
| 自由出口技术 | 对外贸易法（2022 修正）第十四条：办理合同备案登记。备案一般不替代国家知识产权局登记。2001 年条例第三十九条“登记非合同生效条件”条号已改，运行时核验 2020 对应条，不得把记忆旧条写入 `L#` |
| 受让人国籍、经常居所不明 | 跨境字段停止 |

禁止把商务主管部门备案写成“已经完成申请人变更”。两套手续分列：进出口手续 vs 著录项目变更登记。

## 节点 3　标的特定化、法律状态与资料

### 3.1 必须特定到申请号（硬闸）

审查清单，缺一项则该字段不得写成已闭环：

1. 发明创造名称与请求书一致。
2. 申请号、申请日、发明人、当前申请人。
3. 申请类型（发明/实用新型/外观）与审查阶段（初审、公布、实审、复审）。
4. 优先权信息（如有）一并转让。
5. 分案申请权是否随同移转。

只有“等有关专利申请”“公司名下全部在审申请”：标必须改。批量清单用附件，每件一行申请号。

法律状态未检索：不得写成“未被撤回、视为撤回、驳回或转让给第三方”，只能写 `依据不足`。修改句要求附件加入检索页，并约定转让人保证签署日状态与附件一致；隐瞒已下达致命审查意见的，构成违约。

### 3.2 权利负担与在先实施

材料未提及不得写成“无权利负担”。应点名核查：保全/查封、质押（申请权作为财产仍可能被保全）、已对外普通或独占许可、一申多转、权属诉讼。

技术合同解释（2020 修正）第二十四条：订立转让合同前让与人已自行实施的，合同生效后受让人要求停止实施的，应予支持，另有约定除外；不影响合同成立前已订立的专利实施许可或技术秘密转让合同。修改句必须处理：签署前已实施是否停止；已许可合同由谁承继、使用费归谁。

### 3.3 案卷与底层资料

移交清单至少包括：请求书、说明书及附图、权利要求书、受理通知书、历次审查意见与答复稿、实验记录、支撑实施的 Know-how。未公开前的申请内容按保密义务处理。发明人署名权不随申请权转让。

第八百七十条保证的是合法拥有、资料完整无误、能够达到**约定**目标。约定目标写成“获得授权”＝授权承诺，必须改成“资料真实、状态披露真实、配合变更与答辩”。

## 节点 4　登记程序与审查接管（硬闸：登记）

把批准、登记、备案写成**生效条件或履行期限**，不写成已经完成。

| 文本写法 | 本任务动作 |
| --- | --- |
| “本合同签字盖章后受让人即成为申请人/权利人” | 必须拆：合同成立发生债权效力；申请权转让自国务院专利行政部门登记之日起生效。修改句绑定《手续合格通知书》 |
| “双方同意视为已登记/已变更” | 不得放行。登记是法定生效时点，不能合意拟制 |
| 无谁负责、几日内提交著录项目变更申报书、费用谁承担、对方不配合的后果 | 补义务主体、【待填】日、违约金或解除+已付款返还 |
| 用户要求倒签登记日或补假手续合格通知书 | 整体停止 |

实施细则（2023 修订）第一百零六条：专利登记簿登记专利申请权的转移。受让人正式取得申请人地位，以登记完成为准，不是签字日。

审查接管：变更后由受让人委托代理机构答复审查意见、缴纳申请维持费；登记日前已产生的官费由转让人承担，登记日后由受让人承担，另有约定除外。转让人及发明人在授权前负有答辩配合义务，期限与次数用 `【待填】`。

变更完成前的锁定：转让人不得主动撤回、不得再转让、不得放弃优先权、不得故意不缴官费导致视撤。违反则构成根本违约，受让人可解除并要求返还已付款及【待填】违约金。

## 节点 5　对价、定金与授权风险

1. 价款构成、币种、税、发票、节点分列。未给出的数字写 `【待填】`。推荐结构只作修改句备选，不是法源：签约付首款 → 登记合格付中款 → 授权或驳回结算尾款。
2. 授权风险必须明示：

| 文本写法 | 动作 |
| --- | --- |
| 保证授权、包过、授权失败视同未交付专利权 | 红线删除保证。可改为“尽力协助答复，不保证授权” |
| 未写驳回/视撤后价款是否退还 | 必须改。备选：不退、按比例退、仅退尚未支付尾款。数字用 `【待填】` |
| 因转让人隐瞒 OA、伪造发明人、申请日已丧失新颖性 | 不得按“受让人自担授权风险”放行；单列违约与解除 |
| 因受让人逾期不答复或停缴官费导致视撤 | 风险由受让人承担 |

3. 定金：必须使用“定金”二字才讨论罚则。“订金、保证金”无定金性质约定的，不得写成定金。约定或推算超过主合同标的额百分之二十：超过部分不产生定金效力（第 586 条）。无核验引文不得把 20% 写成现行法结论。
4. 禁止编造单价、总价。
5. 退出：登记被驳回、共有人反对、进出口许可未获、申请在登记前被撤回，须有通知、返还和资料交还。禁止只写“双方协商解除”。

## 节点 6　格式条款、强制规范与非法垄断

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 格式条款

为重复使用而预先拟定、订立时未与对方协商。从事经营活动的一方不得仅以“这次没用过第二次”否认。依据示范文本制作，不当然排除格式条款。

审查：免责、限责、排除对方权利、管辖/仲裁、单方认定授权失败责任等异常条款是否有足以引起注意的标识，以及是否按要求说明（第 496 条；解释第 10 条）。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在附件 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

提供方对其已尽提示或说明承担举证责任。

第 506 条：造成人身损害、因故意或重大过失造成财产损失的免责条款无效。不得排除故意隐瞒法律状态、伪造申请人。

### 6.2 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的、是否仅行政管理、是否只规制履行行为（第 153 条；解释第 16 条）。禁止用已失效“效力性/管理性”口诀代替解释第 16 条。

- 专利法第十条登记：主要规制权利变动时点，未登记不当然等于债权合同无效。修改句仍须把登记写成双方义务。
- 限制出口未经许可：不得出口。不改写成“先交割再补证”。
- 第八百五十条及技术合同解释第十条：限制后续研发、不对等回授、搭售、禁止质疑有效性等，标红旗，给出删除或互惠改写，不提供可履行的垄断结构。

## 节点 7　配套：违约、分案、保密、争议

1. 拒绝配合变更、隐瞒驳回或权属纠纷、变更前撤回或一申多转，必须分别有可执行后果。只有“依法承担违约责任”视为必须改。
2. 构成违约不等于当然解除。法定解除路径只点名催告或目的不能实现，不在本任务作出已解除结论。违约金不是必得金额；修改句避免“不得调整”或“按总价 30% 必得”。
3. 分案申请权：未约定视为结构性缺陷。修改句写明受让人有权基于本申请提出分案，分案权益归受让人，转让人配合变更。
4. 后续改进按第八百七十五条：有约定从约定；无约定且依第五百一十条仍不能确定的，改进方自行享有。禁止无偿单方回授。
5. 未公开前的申请内容、交底资料：双方保密至公开或【待填】年。公开后仍对未进入说明书的 Know-how 保密。
6. 争议解决：出现仲裁条款，不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核，修改句改成单一仲裁机构或单一法院连结点。专属管辖可能：只标红旗，不选定唯一法院充作法律意见。
7. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

打开已加载的 `框架.md`，按六步逐段对照正文。`基本面.md` 用于校验类型、主体、标的、登记和红旗，不代替本节点出句。

| 步 | 动作 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题用专利申请权转让，不用专利权转让/专利实施许可混称；列申请号；鉴于不写“保证授权” | 标题或主体修改句 |
| 交易条款 | 申请信息特定化；法律状态保证；价款与登记/授权节点；授权风险承担；案卷移交 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 变更登记义务与禁撤；共有同意；跨境手续；分案；答辩配合；违约可执行后果 | 可执行后果句或删除句 |
| 尾部 | 签署权限、登记完成才发生权利变动、附件清单（受理通知书、法律状态检索、OA、变更委托书、资料包） | 生效与附件修改句 |
| 语言 | 正说加反说；盯死包过、视为已登记、专利权人、专利号、尽力授权 | 替换空词的句子 |
| 常见问题 | 无申请号；签字即取得申请权；保证授权；缺驳回价款；缺分案；隐瞒 OA | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（标的已是专利权或尚无申请号、拟制登记、保证授权拒删、共有未同意仍要放行、禁止/限制出口绕开许可、倒签或假通知书）；
- `必须改`：可谈但签署前要落句（变更期限、驳回价款、OA 披露、分案、禁撤、优先受让程序）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级金额或个人无限连带且用户拒绝升级：停止“可以签署”建议。
