# 专利申请权转让合同·审查

## 任务目标

在单一立场下，只审查 **技术类合同 / 专利申请权转让合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文显示名为「专利申请权转让合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、授权必然获准、著录项目变更代办整案。

## 本类型硬闸

1. **申请权 ≠ 已授权专利**：标的只能是已向国务院专利行政部门提出申请、尚未授权的专利申请权。必须写明发明创造名称、申请号、申请日、发明人、申请人与审查阶段。出现专利号、授权公告日、专利证书或“专利权人”为主给付 → 负触发 `专利权转让合同·审查`。尚无申请号、仅有技术交底或“即将申请” → 属于申请专利的权利，负触发 `技术转让合同·审查` 或回引擎，不按本类型改完。
2. **转让自登记之日起生效**：书面合同成立只产生债权约束。受让人取代转让人成为申请人，须向国务院专利行政部门办理著录项目变更并登记；转让自登记之日起生效。禁止把“签字盖章即取得申请权”写成已放行结构。必须落句：谁在几日内提交《著录项目变更申报书》、费用负担、以《手续合格通知书》为中款/尾款条件。
3. **与专利权转让切开**：专利申请权转让不保证最终授权。禁止按已授权专利权的年费、无效宣告、实施许可备案口径审完。出现“保证授权/包过/授权失败全额退费且视同专利权交付”且拒改 → 红线或整体停止。驳回、视为撤回、主动撤回的价款与资料处置必须另行约定。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签正文，尚未签署，尚未成争，核心给付是移转特定未授权专利申请的申请权换价款，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 已授专利、专利号、专利证书、专利权人变更 → `专利权转让合同·审查`；
- 未提出申请、只有 Know-how 或交底书 → `技术秘密转让合同·审查` 或 `技术转让合同·审查`；
- 许可实施、不移转申请人地位 → `专利实施许可合同·审查` 或 `技术许可合同·审查`；
- 概括“技术转让”且标的混杂专利、申请与秘密，无法拆出本申请权专章 → `技术转让合同·审查`；
- 仍在委托/合作开发、申请权尚未产生或归属未定 → `委托开发合同·审查` / `合作开发合同·审查` / `技术开发合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `专利申请权转让合同·起草`；
- 已签只问缴费日、答复日、变更进度 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `或知产争议专项。` 或对应专项领域。

挂靠、违法分包、规避限购、以申请权转让掩盖禁止/限制出口或虚假权属：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（转让人或受让人择一）；相对方；全文及附件版本；申请号与法律状态；是否共有；是否跨境；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价款、期限、申请号用 `【待填】`，不编造。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `专利申请权转让合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有本申请权转让文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。已授权专利权、未提出申请的权利、技术秘密、实施许可负触发。

### 2. 主体、共有与跨境

转让人须是受理通知书上的申请人。共有处分须全体同意。向外国人、外国企业或其他组织转让须办技术进出口手续。

### 3. 标的特定化与法律状态

申请号、申请日、发明人、审查阶段、官费缴纳、是否已撤回/视撤/驳回、是否已许可或查封。材料未检索不得写成“无负担”。

### 4. 登记与审查接管

著录项目变更义务、期限、未完成的解除或中止。变更后答复审查意见、缴纳维持费的主体。变更完成前禁止撤回或一申多转。

### 5. 对价与授权风险

价款节点与登记、授权/驳回挂钩。不得保证必然授权。定金不得超过标的额百分之二十。

### 6. 格式条款与强制规范

无核验引文则法律结论字段停止。非法垄断技术或侵害他人技术成果不得改成可履行。

### 7. 担保、分案、保密与争议

在先权利担保、分案申请权归属、未公开前保密、发明人署名权不随转让。不选定唯一法院充作意见。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、保证必然授权、把禁止/限制出口或虚假权属改成可履行结构。
- `字段停止`：法域、法律状态检索、共有人名单、进出口目录、地方国资审批未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类（尤其专利权转让）。
