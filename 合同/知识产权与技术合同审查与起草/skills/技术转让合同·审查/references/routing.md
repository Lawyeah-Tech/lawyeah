# 边界与路由

本技能只审查 **技术类合同 / 技术转让合同** 的待签文本。中文展示名是「审查技术转让合同（技术类合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 订立时技术尚不存在，须研究开发；标题转让、正文是任务书立项 | `技术开发合同·审查`。不得按本技能改完，也不得套用开发风险分担 |
| 阶段性成果再做工业化试验、转化 | `技术转化合同·审查` |
| 仅授权实施或使用，底层权利归属不改；独占/排他/普通许可 | `技术许可合同·审查` |
| 专利实施许可（存续期内实施，不改专利权人） | `专利实施许可合同·审查` |
| 技术秘密使用许可 | `技术秘密使用许可合同·审查` |
| 主文件已是单独成册的《专利权转让合同》，标的仅为已授权专利的权利人变更 | `专利权转让合同·审查`。不得删掉登记过户专条后硬套本技能 |
| 单独的专利申请权转让 | `专利申请权转让合同·审查` |
| 单独的技术秘密转让，无专利或申请混装 | `技术秘密转让合同·审查` |
| 集成电路布图设计专有权转让 | `集成电路布图设计专有权转让合同·审查`。P1：专业版未装则 `unavailable` |
| 植物新品种权转让 | `植物新品种权转让合同·审查`。P1；未装则 `unavailable` |
| 计算机软件著作权单独转让 | `计算机软件著作权转让合同·审查`。P1；未装则 `unavailable` |
| 撮合双方订技术转让，中介自己不让与权利 | `撮合专利许可只收中介费不自己实施也不自己许可→`。P1；未装则 `unavailable` |
| 按既有图纸常规加工、复制、测试 | `按既有图纸加工定作实物→负触发` |
| 可行性、FTO、工艺评价，不移交权利 | `知产技术咨询·审查` |
| 以技术知识解决特定技术问题，无权利让与 | `知产技术服务·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `技术转让合同·起草` |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争，或权属/侵权诉讼 | `或知产争议专项。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

技术转让正文里夹带一小段已锁定的专利权过户手续：登记专条可交接 `专利权转让合同·审查`；混装清单、秘密移交、指导、850、在先许可披露仍由本技能审。用户坚持本技能把开发任务书、许可主轴或单独专利权转让本约整案改完：`目标停止`。
