# 边界与路由

本技能只审查 **技术类合同 / 合作开发合同** 的待签联合研发文本。中文展示名是「审查合作开发合同（技术类合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 一方出资提需求，另一方独立研发；出资方只提供资金、设备、材料或辅助协作 | `委托开发合同·审查`；标题或目录落在委托技术开发则 `委托合同目录下的委托技术开发主文件且用户未锁定本类型→` |
| 未区分委托/合作的《技术开发合同》，看不出各方分工参与研究开发 | `技术开发合同·审查` 或回引擎重新定性 |
| 可运行软件、系统上线、源码交付且只有一方开发 | `软件委托开发合同·审查` |
| 就已有实用成果实施转化，不再共同研究新技术 | `技术转化合同·审查`。P1：专业版未装则 `unavailable`，提示，不得用本技能硬套 |
| 让与已有专利、专利申请权或技术秘密 | `技术转让合同·审查` / `专利权转让合同·审查` / `专利申请权转让合同·审查` / `技术秘密转让合同·审查` |
| 许可实施已有专利或使用技术秘密 | `技术许可合同·审查` / `专利实施许可合同·审查` / `技术秘密使用许可合同·审查` |
| 特定技术项目可行性、技术预测、工艺评价、FTO，不共同研发 | `知产技术咨询·审查`；文本落在委托技术咨询目录则 `委托合同目录下的技术咨询→` |
| 解决特定技术问题、调试、培训，无共同创造 | `知产技术服务·审查`；文本落在委托技术服务目录则 `委托合同货架按处理事务费用预付任意解除起草的同名《技术服务合同》→` |
| 以地换房、共同投资房地产、固定回报拿房或利润 | `以地换房共同投资房地产固定回报拿房→`。P1：未装则 `unavailable`。宅基地合作开发转 `宅基地合作开发转`；集体建设用地合作开发转 `集体建设用地合作开发转`。均不得按技术合作开发审 |
| 技术折价入股、设立或增资合资公司并办理股权变更为主给付 | 回引擎按公司/出资类重新定性；本任务不按共有申请权改完 |
| 无文本、本类型条件已谈妥、要出己方稿 | `合作开发合同·起草` |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或知产争议专项。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

合作开发正文里夹带一小段已有专利普通许可或咨询评价：专章交接对应原子；共同投入、860 共有和申请否决条款可继续审。用户坚持本技能把委托开发、软件单方开发、技术转让或房地产合作开发整案改完：`目标停止`。
