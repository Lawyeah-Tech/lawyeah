# 审查方法（锁定 知识产权相关合同 / 著作权转让合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制著作权许可“专有／非专有、期间届满收回、出让人可再许可”主路径，禁止复制委托创作“尚未完成、按需创作、完成后权属约定”主路径，禁止打开或复制 `注册商标转让合同·审查` 的商标核准／近似商标一并转让 method。

定性校验：标题、核心给付与本类型一致才继续；许可、委托创作、合作创作、软件著作权本约、商标转让或单纯原件买卖明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、保证备案一定办成或唯一必得金额。

`search_law` 返回 1990 年未修正《著作权法》、1991 年《著作权法实施条例》、已失效《合同法》及其解释时记为噪声，不得写入 `L#`。

示范文本只参考结构。检索到的“作品著作权转让合同”摘要常写“全世界范围内的全部著作权（人身权利除外）”：人身权除外可采用；“全部著作权”仍须落到第十条财产权逐项。不得把范本当成权利种类已被法律拟制列全。

知识库纠正（不回写双文件）：

- `基本面.md` “备案后便于对抗善意第三人”：备案、权属登记**不是**权利变动或合同生效要件。本次未稳定核验 2013 年实施条例第二十五条全文，不得把“对抗善意第三人”写成已核验法定效果；意见只写便于举证、办理海关知识产权备案和证明维权主体，法律结论字段停止或标待核。
- `基本面.md` “人身权条款写成一并卖断署名／修改权的，该部分通常无效，不影响财产权转让效力”：采用方向。本任务删除或改写人身权卖断句，不宣告整约无效。
- 实务材料“口头或默示一律不具法律效力”：噪声。走司法解释第二十二条 + 民法典第四百九十条：未书面仍可能因履行主要义务且对方接受而成立；成立不等于种类、地域已特定。
- 实务材料“须办理登记手续才保障权利变动公示”：不得写成未登记则未生效，也不得套商标局核准或专利登记生效。
- 司法解释第十二条仍写“著作权法第十七条委托作品”：该解释 2021-01-01 施行，当时对应 2010 年文本第十七条。2020 年修正本自 2021-06-01 施行后，委托作品在第十九条；视听作品在第十七条。运行时换算，不得把委托作品条款写成现行第十七条。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

支持切开的规范（法律结论须运行时复核）：

- 第十条第三款：著作权人可以全部或者部分转让第一款第五项至第十七项，并获得报酬。第一至四项不在可转让清单。
- 第二十六条：使用他人作品应订立**许可使用合同**（依法可不经许可的除外）；许可合同写种类、专有或非专有、地域、期间、付酬、违约。
- 第二十七条：转让第五至十七项应当书面；合同写作品名称、权利种类、地域、价金、支付日期和方式、违约责任。
- 第二十九条：许可或转让合同中未明确许可、转让的权利，未经著作权人同意，另一方不得行使。
- 第十九条：委托创作作品的权属可由合同约定；未约定或无合同的，属于受托人。核心给付是“去创作”时，不是本类型。
- 实施条例（2013 修订）第二十三条：专有使用权许可应当书面（报刊刊登除外）。第二十四条：专有使用权内容由合同约定；约定不明视为被许可人有权排除包括著作权人在内的任何人同样使用；再许可须另经同意。上述两条是**许可**规则，不得写成转让三分法。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 已完成特定作品；对价换财产权主体变更；出让人不再就同一权利自行使用、再许可或再转让（除非书面自用且不冲突） | 本类型 | 正触发 |
| 授权使用、专有／非专有、许可期间、续期、使用费、期满交回、许可人可再许可 | 著作权许可使用 | 负触发 `著作权许可使用合同·审查` |
| 作品尚不存在或未定稿；对价绑创作、修改、验收；权属等完成后归属 | 委托创作 | 负触发 `知产委托创作·审查` 或 `若用户坚持按委托合同父级审→` |

| 主给付是计算机软件财产权或软著登记变更 | 软件著作权转让 | 负触发 `软件著作权转让合同·审查` 或 `计算机软件著作权转让合同·审查` |

| 只买卖画作／手稿／母带，无财产权让与意思 | 原件／动产买卖 | 不启动本任务 |
| 画作买卖夹一句“版权归买方” | 先拆后审 | 原件走第二十条；财产权部分按本类型列权，列不清按第二十九条不得行使 |

标题写“转让”“买断”“版权归买方”，正文全是许可期间、专有使用和届满交回：负触发 `著作权许可使用合同·审查`，不删许可句后硬套本技能。

### 1.2 加载协议（硬闸）

本技能已锁定 **知识产权相关合同 / 著作权转让合同**。只打开 `references/基本面.md` 与 `框架.md`。禁止读其他子目录，禁止为对照再开第二类。禁止打开 `注册商标转让合同·审查`、`著作权许可使用合同·审查`、`知产委托创作·审查` 的 method。

### 1.3 违法或不可交易结构停笔

加载后或定性中出现：以转让为名买卖依法禁止出版、传播的作品；用户或材料显示明知出让人无财产权、系盗版或无权处分，仍要完成买断并写受让人免责。

动作：

1. 交付告知：禁止传播作品不能作为有效交易标的；明知无权处分仍受让，本任务不改成可履行买断。
2. 不写“先受让后补权属”“知情但合同免责”口径。
3. 风险表只保留识别依据和转出／删除提示。
4. 用户坚持“改到能签且仍做这些事”：整体停止。

## 节点 2　人身权切割与处分权闭合

### 2.1 人身权不可转（硬闸）

第十条第一款第一至四项：发表、署名、修改、保护作品完整。第三款只授权转让第五至十七项。

| 文本写法 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| “全部著作权（含署名权、修改权）永久归乙方” | 红线：删除人身权让与。改为：转让第五至十七项中清单列明的权利；署名权仍归作者；署名方式为【待填】 | 人身权可以买断 |
| “乙方有权决定是否署名、署谁的名” | 必须改：可约作者同意不署名或署笔名，不得把署名权主体改成受让人 | 不署名＝放弃且可再卖 |
| “乙方可任意删改，作者不得主张保护作品完整权” | 必须改：作者配合在约定使用目的内作必要改动；歪曲、篡改仍可制止 | 完整权已卖断 |
| “未发表作品原件卖掉即视为同意发表” | 美术、摄影原件可引第二十条第二款：受让人展览该原件不侵犯发表权。其他作品不得写成发表权已转让 | 发表权随原件概括移转 |

最强反方：受让人主张“不买署名就没法改包装、没法维权”。回应：署名方式、维权授权、必要改动配合义务可以合同完成，不必也不许移转人身权。

### 2.2 主体表

建表：签约名、履行名、付款名、发票名、授权签字人。名称不一致不自动合并。代理人授权书必须写明“转让著作财产权”，仅有“签约许可”授权的，不得写成已获转让授权。

口头“我们老板同意了”不得写成已授权。国资、集体、上市公司内部决议未附：该签署能力字段停止。

### 2.3 权源与特殊作品（硬闸）

| 作品类型 | 关键条文 | 本任务动作 |
| --- | --- | --- |
| 合作作品 | 第十四条 | 转让须全体合作作者一致。单方签字：字段停止或仅能讨论该方份额之债的效果，不得写成受让人取得完整财产权。可分割使用的，单独部分可单独转，但不得侵害整体 |
| 职务作品 | 第十八条 | 一般职务作品著作权归作者，单位两年内业务范围优先使用；第二款情形（工程设计图、地图、计算机软件等由单位承担责任，或新闻单位职务作品，或约定归单位）财产权在单位。自然人签字卖单位职务作品：红线补单位处分文件 |
| 委托作品 | 第十九条；解释第十二条（条号换算见开篇） | 未约定则财产权在受托人。委托人持“委托创作合同”来签本转让：先核第十九条是否已把财产权给委托人；若交易本质是去创作，负触发 `知产委托创作·审查` |
| 视听作品 | 第十七条 | 电影、电视剧著作权由制作者享有，编剧等保留署名和获酬；其他视听作品无约定归制作者。自然人主创单独“卖整片版权”：字段停止，除非证明其为制作者或已获制作者处分授权。可单独使用的剧本、音乐另核 |
| 演绎作品 | 第十条、第十二条目（运行时复核） | 转让演绎作品不消灭原作著作权；须另审原作授权链。链缺口标 `G#` |
| 集体管理 | 集管条例第四条等 | 表演、广播、信息网络传播等若已交集体管理，作者无权再单独转让同一权利。未披露集管：必须改，附件声明覆盖范围 |

### 2.4 在先许可、出质与“二手转让”

| 文本写法 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 未披露是否已许可、出版、出质 | 必须改：附件列在先许可／出版／集管／质权的相对方类型、范围、期限、可否撤销 | 未提及就是没有 |
| 已有专有许可仍声称全部财产权让与 | 红线：取得被许可人书面放弃、合同终止或由受让人承继的证明，否则不签完整买断 | 许可可以事后再说 |
| 出让人保留向任意第三人再许可同一权利 | 按许可重新定性，负触发 `著作权许可使用合同·审查` | 普通转让所以可以再卖 |
| 已出质 | 字段停止；质权人书面同意或清偿后注销前，不得写成无负担让与 | 转让自动涤除质权 |

## 节点 3　作品特定化、权利清单与第二十七条

### 3.1 作品必须特定

逐件：名称、类别、作者、完成或首次发表时间、载体（手稿、母带、成片、文件哈希）、登记号（如有）。禁止只写“某 IP 全部版权”“系列作品一切权利”“相关衍生产品”。

系列、未完成续集、角色、标题：未单独特定的，不得写成已转让。续集尚未创作的，创作部分负触发委托或合作原子。

### 3.2 权利种类封闭（硬闸）

按第十条第一款第五至十七项列举：复制、发行、出租、展览、表演、放映、广播、信息网络传播、摄制、改编、翻译、汇编及依法新增的其他财产权。写明地域（中国大陆／含港澳台／全球）、是否含信息网络、是否含改编／摄制等下游权利。

第二十九条：未明确转让的，受让人不得行使。

| 文本写法 | 动作 |
| --- | --- |
| “转让全部版权／IP／品牌资产” | 红线或必须改：改为第十条逐项打钩 + “未列入清单的权利仍归出让人，受让人不得行使” |
| 只列复制、发行，另用“等”“相关传播” | 必须改：信息网络传播、改编、摄制等要单列或明确排除 |
| “自签字起全球永久所有权利”，同时保留出让人自行上架、再授权 | 名转实许：负触发 `著作权许可使用合同·审查`，或删除保留条款并封闭清单 |
| 需要“除人身权外的全部财产权” | 可接受结构：逐项列完，并写“第十条第一款第五项至第十七项及将来法定新增财产权类型（如有）”；人身权明示除外 |

最强反方：相对方主张“市场不可能列全播放终端，未写 IPTV 不等于没转信息网络传播权”。回应：本任务仍要求种类级列举；终端级可用“包括但不限于【待填】，但不突破已列权利种类”。不得用终端未列否定已明确转让的那一项，也不得用“等”补出未列的**另一项**权利。

### 3.3 第二十七条必备项（硬闸）

缺一项则必须改，不要用“详见附件”而附件空白：

1. 作品的名称；
2. 转让的权利种类、地域范围；
3. 转让价金；
4. 交付转让价金的日期和方式；
5. 违约责任；
6. 双方认为需要约定的其他内容（权属声明、在先许可、备案配合、人身权安排等）。

未给出的数字、日期写 `【待填】`。禁止编造评估值。

## 节点 4　书面、生效与备案切开

### 4.1 书面（硬闸）

第二十七条：应当订立书面合同。司法解释第二十二条：未采取书面形式的，依据民法典第四百九十条审查是否成立。第四百九十条：合同书自签名、盖章或按指印成立；签名前一方已履行主要义务且对方接受的，合同成立；法定或约定应书面而未书面，一方履行主要义务且对方接受的，也成立。

| 文本或事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 只有微信“版权十万卖你” | 不启动实体放行；告知应补书面，且种类、地域仍未特定 | 口头买断一定有效；口头一律无效 |
| 有书面但缺第二十七条某项 | 必须改补项；不因缺一项宣告整约未成立 | 缺违约责任所以合同不存在 |
| 用户要求把签署日改到上周已交文件 | 整体停止，拒绝倒签 | 先签再改日期 |

### 4.2 备案／登记不是生效要件（硬闸）

著作权因创作自动产生。第二十七条只要求书面，不要求行政登记才发生权利变动。

| 文本写法 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| “未办理版权中心转让备案则本合同无效／未生效” | 必须改：删除生效挂钩。可约定一方在【待填】日内配合备案、补正；逾期不配合视为根本违约 | 未备案未生效 |
| “本合同自商标局／专利局核准或登记之日起权利转移” | 必须改：删除。本类型不是注册商标转让，也不是专利权转让 | 套用 `注册商标转让合同·审查` 或专利登记 |
| 无备案配合义务 | 可接受可优化：补谁主办、谁缴费、补正期限、不配合的解除或价款返还 | 不备案就不能转让 |

权属登记变更、海关知识产权备案：写成双方义务和证据安排，不写成物权式登记对抗的充分必要条件。实施条例第二十五条全文本次未稳定核验，备案的对抗效果不写入 `L#`。

## 节点 5　原件、载体、对价与交割

### 5.1 原件与载体（硬闸）

第二十条：作品原件所有权的转移，不改变作品著作权的归属；美术、摄影作品原件的展览权由原件所有人享有。作者将未发表的美术、摄影作品原件转让的，受让人展览该原件不构成对发表权的侵犯。

修改句必须分条：

1. 原件／母带／源文件所有权是否一并转移；
2. 约定财产权自【生效／价款付清／载体交付】之日起由受让人享有；
3. 展览权：若原件转移且作品为美术或摄影，写明展览权依法随原件；复制、信息网络传播、改编不随原件；
4. 哈希或交接单只证明物的交付，不视为未列入清单的权利已转让。

禁止放行：

> 乙方签收 U 盘即取得全部版权。

### 5.2 对价与定金

总额或按权利项／地域拆分。支付触发建议绑：交载体、交权属文件、配合提交备案。签字即付清全款的，必须配套无权处分、权属被追夺时的返还与回购。

定金：必须使用“定金”二字才讨论罚则。民法典第五百八十六条：不得超过主合同标的额百分之二十，超过部分不产生定金效力。无核验引文不得把 20% 写成现行法结论。

“订金、保证金”无定金性质约定的，不得写成定金。

### 5.3 过渡期与维权切割

备案完成前谁以谁的名义维权、谁收取交割前已发生许可费、转让前侵权索赔权是否一并让与：必须写明。未写则标必须改，不编造归谁。

跨越交割日的持续侵权：修改句按交割日分割，不在本任务认定已侵权。

## 节点 6　格式条款、免责与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 免责与限额

可约定除无权处分、人身权安排违约、故意或重大过失外的赔偿上限。下列不得排除：

- 造成对方人身损害；
- 因故意或者重大过失造成对方财产损失（第五百零六条）；
- 明知无权处分仍转让。

“出让人对权属、是否侵犯第三人权利不承担任何责任”：必须改。

### 6.2 格式条款

第四百九十六条、第四百九十七条；合同编通则解释第十条：勾选、弹窗不当然等于已尽提示说明。小字、夹在附件：不得写成已尽提示义务。

### 6.3 人身权卖断与第一百五十三条

人身权让与条款因违反著作权法对可转让范围的规定，应删除或改写，不当然导致整份财产权转让无效。禁止用已失效“效力性／管理性”口诀代替第一百五十三条。合同编通则解释第十六条全文本次若未核验，细分路径运行时再核。

## 节点 7　违约、解除与争议

无权处分、隐瞒共有／职务／委托／视听属性、拒不交载体、拒不配合备案、重复转让、受让人逾期付款：必须分别有可执行后果。只有“依法承担违约责任”视为必须改。

构成违约不等于当然解除。违约金不是必得金额；禁止写“不得调整”。民法典第五百八十五条全文本次若未稳定核验，调整机制法律结论字段停止，修改句仍删除“不得调整”。

争议解决：出现仲裁条款，不得改写成“应向某法院起诉”。或裁或诉、机构不明：标待核，改成单一机构或单一法院连结点。权属确认与侵权诉讼可并行，不要写成“一裁终局解决全部版权行政事务”。

通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。

`定位（条／款／附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`
