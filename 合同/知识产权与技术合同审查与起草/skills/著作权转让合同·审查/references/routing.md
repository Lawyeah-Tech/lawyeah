# 边界与路由

本技能只审查 **知识产权相关合同 / 著作权转让合同** 的待签、已存在特定作品上著作财产权让与文本。中文展示名是「审查著作权转让合同（知识产权相关合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 仅授权使用；专有／非专有；许可期间；期满收回；出让人可再许可或继续上架同一权利；对价称许可使用费 | `著作权许可使用合同·审查` |
| 作品尚未完成；对价绑创作过程、修改轮次、初稿／定稿；权属约定在创作完成后归属 | `知产委托创作·审查` |
| 委托合同货架下的委托创作主文件 | `若用户坚持按委托合同父级审→` |
| 双方共同完成尚未存在的作品，主轴是合作作者身份与权利行使 | `合作创作合同·审查` |
| 计算机软件著作权让与或软著登记变更为主给付 | `软件著作权转让合同·审查` 或 `计算机软件著作权转让合同·审查` |
| 注册商标核准转让、近似商标一并移转 | `注册商标转让合同·审查` |
| 注册商标使用许可 | `注册商标许可合同·审查` |
| 只处分原件、手稿、藏品，无财产权让与意思 | 不启动本任务；提示拆物权与著作权 |
| 无文本、本类型条件已谈妥、要出己方稿 | `著作权转让合同·起草` |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或知产争议专项。` 或对应专项领域 |
| 权属确认、侵害著作权诉讼或海关查处已立案 | 知产或争议专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

著作权转让正文里夹带一小段许可或原件买卖：专章交接对应原子或分条改写；财产权让与条款可继续审。用户坚持本技能把许可、委托创作、软件著作权本约或商标转让整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
