## **第一步：合同类型（法律性质）分析**

* **法律定性**：著作权转让合同是著作权人将其作品上的**著作财产权全部或部分让与**受让人、受让人支付对价的合同。核心给付是**财产权主体变更**：受让人在保护期内成为约定权利的著作权主体，可自行使用、再转让或再许可。人身权（发表、署名、修改、保护作品完整）原则上不随转让移转。适用《著作权法》（2020修正）第10条、第27条、第29条，《著作权法实施条例》，著作权司法解释（2020修正），并受《民法典》合同编约束。
* **易混淆辨析**：
* **转让 vs 许可**：转让改变权属；许可只授予约定期限、地域、方式内的使用权，期满权利回归。合同写“永久买断”“独家授权”“版权归买方”但未列权利种类、未排除许可人保留权的，应先按《著作权法》第29条审是否构成转让；**未明确转让的权利，受让人不得行使**。
* **全部转让 vs 部分转让**：全部转让指第10条所列复制、发行、出租、展览、表演、放映、广播、信息网络传播、摄制、改编、翻译、汇编等财产权一次性移转；部分转让只移转其中一项或数项。未列明的权利仍归出让人。
* **转让 vs 原件买卖**：美术、摄影作品原件所有权转移不视为著作权转让；展览权随原件转移是法定例外，不得据此推定复制权、信息网络传播权已卖出。
* **效力认定**：
* **财产权转让应当订立书面合同**（《著作权法》第27条）。未采用书面的，按《民法典》第490条审查合同是否成立；成立不等于权利种类、地域已特定。
* **合同成立≠可对外对抗一切第三人**。著作权因创作自动产生，转让不以登记为生效要件；专有许可、转让**可向著作权行政管理部门备案**，备案后便于对抗善意第三人、办理海关备案和维权主体证明。
* 转让保护期已届满、已进入公有领域、或出让人根本未取得财产权的，标的落空。人身权条款写成“一并卖断署名/修改权”的，该部分通常无效，不影响财产权转让效力。


## **第二步：合同主体（交易对手）分析**

* **出让人**：须为财产权的真实权利人。作者本人、继受取得人、职务作品中依法享有财产权的单位、视听作品中依法享有财产权的制片者，主体不同，权源不同。核对身份证/营业执照与权属证明是否一致。
* **受让人**：自然人、法人、非法人组织均可。受让后拟再许可、再转让、出质的，须确认合同未限制处分。
* **关联主体**：
* **合作作者**：合作作品财产权处分原则上须全体一致；不能协商一致时，任何一方不得阻止他方行使除**转让、许可他人专有使用、出质**以外的权利。单方签署的“转让”可能仅对份额发生债的效果，不能使受让人取得完整权属。
* **职务作品单位 / 视听作品制片者 / 委托创作受托人**：权属依法或依约可能根本不在签约的自然人手里。
* **集体管理组织**：音乐、文字等作品若已签集体管理合同，部分权利由集管组织行使，作者无权再单独转让同一权利。
* **质权人、在先被许可人**：已出质或已授予专有许可的，擅自转让不能消灭在先负担。
* **签约能力**：共有、国资评估、上市公司重大无形资产、跨境主体身份证明。代理人权限须明确包含“转让著作财产权”，不得以“签约许可”授权书签转让。


## **第三步：合同标的（交易对象）分析**

* **标的特定化**：逐件写作品名称、类别（文字/音乐/美术/视听/摄影等）、作者、完成或首次发表时间、载体（手稿、母带、成片、数字文件校验值）、登记号（如有）。禁止只写“某IP全部版权”“系列作品一切权利”。
* **权利种类与范围**：按《著作权法》第10条逐项勾选；写明地域（中国大陆/含港澳台/全球）、期限（保护期内剩余年限或至保护期届满）、媒体和语种。第27条要求合同写明**作品名称、转让的权利种类、地域范围、转让价金、交付价款日期和方式、违约责任**。
* **权利负担**：
* 在先专有/非专有许可、出版合同、信息网络传播授权、改编期权、出质、保全、权属诉讼。
* 职务作品、委托作品、合作作品、视听作品的法定或约定分割。
* 原件、母带、素材中的第三人肖像、商标、音乐、字体。
* **可交易性**：思想、操作方法、事实本身不受保护；依法禁止出版传播的作品不能作为有效交易标的。演绎作品转让不消灭原作品著作权，须另审原作授权链。


## **第四步：合同程序（交易步骤）分析**

* **法定形式**：书面合同；建议同时办理著作权转让合同备案及权属登记变更（中国版权保护中心等）。备案、登记不是生效要件，但是对抗、举证、海关备案的关键程序。
* **内部决策**：单位出让职务作品财产权，走章程规定的董事会/股东会；国有著作权评估、进场；共有人书面一致同意。
* **交割节点**：建议“签约付首款 → 交付作品载体与权属文件 → 办理备案/登记 → 尾款”。签字即付清全款的，须配套权属瑕疵回购和价款返还。
* **载体交付与权属交付分开**：母带、源文件、分层文件交付是物的交付；财产权移转依合同约定时点发生。未约定时，结合价款支付和书面意思确定，不得推定“交U盘即卖断全部权利”。
* **过渡期**：公告或备案完成前谁维权、谁收许可费尾款、谁续展登记，必须写明。


## **第五步：交易结构设计（风险规避方案）**

* **对价结构**：总额或按权利项/地域拆分计价。定金不超过主合同标的额**20%**。备案或权属诉讼失败时的返还与解约。
* **权利清单封闭**：采用“肯定列举 + 未列明不得行使”结构，与第29条对齐；如需“全部财产权”，逐项列完并写“第10条项下除人身权外的全部财产权，含将来法定新增的财产权类型（如有）”。
* **负担清除**：交割先决条件包括解除专有许可或由受让人书面承继、质权人同意、披露集管合同。转让前侵权索赔权、已发生许可费单独切割。
* **人身权安排**：约定出让人/作者配合修改、不得滥用保护作品完整权阻却约定范围内的必要改动；署名方式和“不署名”不得写成买断署名权。
* **文本形态**：**主转让协议 + 作品与权利清单 + 权属来源声明 + 共有人/单位同意书 + 在先许可清单 + 备案申请书草本 + 载体交接单**。


## **第六步：宏观风险预警与尽调指引**

* **高频争议**：口头“买断”后双方对是否转让信息网络传播权、改编权发生争议；合作作者未全体签字；职务/委托作品签约主体无处分权；把原件买卖当成版权买卖；未备案导致受让人维权主体资格受质疑。
* **尽调清单**：
* [ ] 作品底稿、发表记录、登记证书与作者身份核对
* [ ] 职务、委托、合作、视听作品的权属合同与法定归属
* [ ] 在先许可、出版、集管、出质、诉讼、海关备案
* [ ] 保护期起算点（发表/完成）与剩余年限
* [ ] 演绎作品的原作授权链
* [ ] 国资、共有、跨境处分程序
* **重大风险红旗**：合同只写“转让版权”不列权利种类；“自签字起全球永久所有权利”却保留出让人继续发表、上架；作者与署名人不一致且无权属链；把许可合同改标题当转让用。
