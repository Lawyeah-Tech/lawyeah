# 著作权转让合同·审查

## 任务目标

在单一立场下，只审查 **知识产权相关合同 / 著作权转让合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文显示名为「著作权转让合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证登记或备案一定办成、保证受让人必然取得可对抗一切第三人的权属。

## 本类型硬闸

1. **财产权可转，人身权不可转**：可让与的只是《著作权法》（2020 修正）第十条第一款第五项至第十七项。发表、署名、修改、保护作品完整权不随转让移转。写成“买断署名／修改／保护作品完整权”“人身权一并归受让人”的部分不得放行；可约定署名方式、配合修改、不得滥用完整权阻却约定范围内的必要改动，但不得写成人身权主体变更。
2. **应当书面**：转让第十条第一款第五项至第十七项，应当订立书面合同。未采用书面的，按著作权司法解释（2020 修正）第二十二条走民法典第四百九十条审查是否成立；成立不等于权利种类、地域已经特定。不得写成“口头买断也一定有效”，也不得写成“未书面一律未成立”。
3. **转让 ≠ 许可 ≠ 委托创作**：正像是把**已经存在**的特定作品上的约定财产权**让与**受让人，受让人在保护期内成为该部分权利的主体，可自行使用、再转让或再许可（除非合同另限）。期限届满收回、出让人继续自用并再许可、对价称许可使用费、只写专有／非专有 → `著作权许可使用合同·审查`。核心给付是尚未完成的创作、按需交付成果、权属要等作品完成后再归属 → `知产委托创作·审查`（委托合同项下同类主文件 → `若用户坚持按委托合同父级审→`）。双方共同完成尚未存在的作品 → `合作创作合同·审查`。
4. **未明确转让的权利不得行使**：第二十九条。权利清单必须按第十条逐项封闭；只写“全部版权／品牌所有 IP／永久买断”而未列种类、地域的，受让人不得被写成已取得未列明权利。第二十七条必备项：作品名称、转让的权利种类、地域范围、转让价金、交付价金的日期和方式、违约责任——缺一项补一项。
5. **原件买卖 ≠ 著作权转让**：第二十条。美术、摄影作品原件所有权转移不改变著作权归属；展览权随原件转移是法定例外，不得据此推定复制权、信息网络传播权、改编权已卖出。交 U 盘、交手稿、交登记证 ≠ 财产权移转。
6. **处分权闭合**：出让人须为该财产权的真实权利人。合作作品转让须全体合作作者一致（第十四条）；不能协商一致时，任何一方不得阻止他方行使**除转让、许可他人专有使用、出质以外**的权利——单方签字不能写成完整权属买断。职务作品（第十八条）、委托作品（第十九条）、视听作品（第十七条）、集管合同覆盖的权利、已出质或已专有许可的权利，权源未闭合则字段停止。
7. **备案／登记不是生效要件**：著作权自动产生，转让不以行政登记或备案为权利变动要件。不得写成“未备案／未登记则合同无效或未生效”。不得套用注册商标转让核准或专利权登记生效口径，禁止打开或复制 `注册商标转让合同·审查` 的 method。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签著作权转让正文，尚未签署，尚未成争，核心给付是已存在特定作品上著作财产权的让与，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 仅授权使用、专有或非专有、期限届满收回、出让人可再许可或继续上架同一权利 → `著作权许可使用合同·审查`；
- 作品尚未完成，对价绑创作过程、修改轮次、交付初稿／定稿 → `知产委托创作·审查`；委托合同货架下的委托创作主文件 → `若用户坚持按委托合同父级审→`；
- 双方共同创作尚未存在的作品、约定合作作者身份与行使规则 → `合作创作合同·审查`；
- 主给付是计算机软件著作权登记变更或软件财产权让与 → `软件著作权转让合同·审查` 或 `计算机软件著作权转让合同·审查`；
- 注册商标核准转让、近似商标一并移转 → `注册商标转让合同·审查`；
- 只买卖原件／手稿／藏品，正文无财产权让与意思 → 不启动本任务；混写“版权归买方”的，先拆原件与财产权，财产权部分可审；
- 无文本、本类型条件已谈妥、要出己方稿 → `著作权转让合同·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁或权属／侵权已立案 → `或知产争议专项。` 或知产／争议专项。

以转让为名买卖依法禁止出版传播的作品，或把明知无权处分、明知侵权受让改成可履行买断：只出告知，不改写成可履行路径。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及附件／作品清单／权属声明版本；作品是否已经存在；是让与还是许可；拟转的权利种类与地域；人身权条款如何写；出让人是否为作者、单位、制片者或继受人；合作／职务／委托／视听／集管信号；在先许可或出质；原件是否一并处分；备案或登记如何约定；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价款、地域、期限用 `【待填】`，不编造。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`基本面.md` 把备案写成“对抗善意第三人”的法定要件时，以 method 纠正为准。`框架.md` 出现“未备案合同无效”时，不得放行。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `著作权转让合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议或知产。未签且目标是评改已有著作权转让文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。许可、委托创作、合作创作、软件著作权本约、商标转让、单纯原件买卖负触发。

### 2. 人身权与财产权切割

第十条第一至四项不得写成转让标的。署名方式与配合修改可另约。

### 3. 主体、权源与在先负担

合作作者全体、职务／委托／视听权属、集管、出质、在先专有许可必须闭合或字段停止。

### 4. 作品特定化与权利清单

第二十七条必备项 + 第二十九条封闭清单。禁止“全部版权”空词。

### 5. 书面、生效与备案切开

书面成立；备案、权属登记不是生效要件。不得套商标核准或专利登记。

### 6. 原件、载体与对价

原件所有权与财产权分条；展览权法定例外单独写。价款与交载体／交权属文件／配合备案挂钩。

### 7. 格式条款与强制规范

无核验引文则法律结论字段停止。人身权卖断条款不得改成可履行的人身权移转。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把许可改成买断外壳、把人身权写成可转让并放行、把明知无权处分或禁止传播作品改成可履行。
- `字段停止`：法域、动态规则、权属链、合作作者名单、集管覆盖、在先许可未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
