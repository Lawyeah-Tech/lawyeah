# 软件许可合同（自用许可模式）·审查

## 任务目标

在单一立场下，只审查 **知识产权相关合同 / 软件许可合同（自用许可模式）** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文显示名为「软件许可合同（自用许可模式）·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、侵权诉讼策略、有效性保证、把分发许可改成自用或把自用改成出货权、把许可改成权属过户。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **终端自用**：许可只覆盖最终用户在约定席位／并发／CPU／实例／站点内，于指定安装环境自行安装、运行，并制作必要备份。用途限于被许可人内部生产经营。备份份数写死，备份不得提供给他人。未点名的关联公司、分公司、外包商、驻场供应商不得安装。
2. **禁止再分发**：正文必须同时正说和反说。用户不得再许可、不得分发、不得出租、不得嵌入对外销售的产品、不得向任何第三人提供软件使用权或实质等同的在线服务。未明确许可的修改权、信息网络传播权、发行权不得行使。
3. **与分发许可切开**：标题或正文出现“OEM”“预装分发”“转售”“可随产品销售给客户”“可再授权下游”等出货或转授主给付 → 负触发 `软件许可合同（分发许可模式）·审查`。不得删掉出货句后按自用席位审完，也不得在自用合同里补出货提成表。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签软件自用许可正文，尚未签署，尚未成争，核心给付是把软件复制到用户控制的环境供最终用户自行使用并收取许可费，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 主给付是向下游分发、预装出货、再授权客户或按台计提 → `软件许可合同（分发许可模式）·审查`；
- 主给付是软件著作权权属转移、登记变更后对方成为著作权人 → `软件著作权转让合同·审查`；
- 主给付是文字、视听等非计算机软件作品的许可使用 → `著作权许可使用合同·审查`；
- 主给付是非软件作品著作权转让 → `著作权转让合同·审查`；
- 按开发里程碑交付源码、验收后著作权归委托方 → `软件委托开发合同·审查`；尚待研发则 `技术开发合同·审查`／`委托开发合同·审查`；
- 纯云端登录、数据在许可人侧、不把软件复制到用户环境 → 按服务／技术服务定性，转 本套导航的类型切开步骤 或 `知产技术服务·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `软件许可合同（自用许可模式）·起草`；
- 已签只问开通日、审计日、续费日 → 本套导航的履约步骤；
- 已催告、解除、索赔、侵权诉讼或仲裁策略 → `或知产争议专项。` 或知识产权争议专项。

挂靠、违法分包、规避限购：只出告知，不改写成可履行结构。把再分发、预装出货或“全部知识产权归用户”改成可履行：用户坚持则整体停止。

## 建立审查坐标

确认：使用者与授权；单方立场（许可人侧或被许可人／最终用户侧择一）；相对方；全文及订单／EULA／产品说明／被许可主体清单版本；软件名称与版本是否可见；席位或站点是否封闭；安装环境；使用人法人是否点名；订阅还是买断；是否夹带出货权或权属转让；数据导出；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的席位、单价、期限用 `【待填】`，不编造。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、1991 年《计算机软件保护条例》、2009 年《软件产品管理办法》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验著作权法第二十六、二十九条，计算机软件保护条例第十六、十八、十九条，民法典第 876、496、497、586 条，著作权民事纠纷解释第二十一条；`search_practiced` 只补审查反例；`search_template` 只借栏目结构。不虚构案件系统。

`search_law` 对上述法律结论为 required 级：不可用时不拒绝执行，只停止效力字段。返回已失效《合同法》及其解释、1991 年《计算机软件保护条例》、2009 年《软件产品管理办法》时记为噪声，不得写入 `L#`。不得把分发许可出货规则或商标许可备案对抗套到本类型。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`框架.md` 中“集团内通用”“合理数量备份”是空词，必须落到法人名单和备份份数。不得把“永久买断全部知识产权”只写在鉴于或点击页。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `软件许可合同（自用许可模式）·起草`；已签履约 → 本套导航履约步骤；已成争或侵权诉讼策略 → 合同争议。未签且目标是评改已有自用许可文本，才进入本任务。

### 1. 类型锁死与分发／转让切开

标题、核心给付与对价方式一致才继续。分发许可、软件著作权转让、概括著作权许可、委托开发或纯 SaaS 服务负触发。

### 2. 主体、权源与使用人名单

许可人须是著作权人或能出示再许可授权的发行商。被许可人是最终用户本身。集团统采须附表列出有权安装的法人。

### 3. 终端自用与计量

席位／站点／实例封闭；安装环境可核验；用途限于内部生产经营。

### 4. 禁止再分发

正说安装运行和必要备份；反说不得再许可、分发、出租、嵌入出货、经营性向第三人提供。

### 5. 对价、EULA 位阶与数据

订阅期满使用权消灭；买断须写版本且不当然含大版本升级。主合同优于 EULA。用户数据归属用户，终止后须有导出窗口。

### 6. 格式条款、消费者规则与强制规范

点击勾选不当然已尽提示说明。面向消费者再压一档。未明确的权利不得行使。

### 7. 审计、违约与争议

超额补费或卸载；关闭超额实例时保留合规部分。不选定唯一法院充作意见。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证许可必然有效、把再分发或预装出货当自用放行、把“全部知识产权归用户”改成可履行结构。
- `字段停止`：法域、权源、席位计量、使用人名单、限制／禁止进出口、动态规则未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书、侵权诉讼策略，或已锁他类。
