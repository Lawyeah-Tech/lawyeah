# 边界与路由

本技能只审查 **知识产权相关合同 / 软件许可合同（自用许可模式）** 的待签文本。中文展示名是「审查软件许可合同（自用许可模式）（知识产权相关合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| OEM、预装分发、转售、按出货台数计提、向下游客户转授使用权 | `软件许可合同（分发许可模式）·审查`。不得删掉出货句后按自用席位审完，也不得在自用合同里补分发提成表 |
| 软件著作权权属转移、登记变更后对方成为著作权人、转让价款 | `软件著作权转让合同·审查`。不得把永久买断改成过户后硬套 |
| 文字、美术、视听等非计算机软件作品的许可使用 | `著作权许可使用合同·审查` |
| 非软件作品著作权转让 | `著作权转让合同·审查` |
| 按里程碑开发、交付源码、验收后著作权归委托方 | `软件委托开发合同·审查`。夹带少量实施／培训可分条计价，开发成为主给付则整案转出 |
| 尚待研发、不保证成果必然产生 | `技术开发合同·审查` 或 `委托开发合同·审查` |
| 纯云端登录、数据在许可人侧、不把软件复制到用户环境 | 本套导航的类型切开步骤 或 `知产技术服务·审查`。不得用本技能把服务中断责任错配成安装许可 |
| 技术咨询意见，不授予使用权 | `知产技术咨询·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `软件许可合同（自用许可模式）·起草` |
| 已签未争、只问开通、审计、续费或卸载进度 | 本套导航的履约步骤 |
| 已成争，或用户要侵权／解约诉讼策略 | `或知产争议专项。` 或对应专项领域 |
| 限制／禁止类技术进出口审批为主轴 | 字段停止并点名跨境技术进出口专项；不在本任务代做目录归类 |
| C 端大众快检 | 只分流，不回改 |

自用正文里夹带一小段实施、培训或维保：可审“与许可费分列、验收不等于权属交割”；实施成为主给付且不授予复制安装权则交接 `知产技术服务·审查`。夹带一小段“期满可协商转让著作权”：专条交接 `软件著作权转让合同·审查`，席位、禁止再分发、许可费条款可继续审。用户坚持本技能把分发许可、转让或委托开发整案改完：`目标停止`。
