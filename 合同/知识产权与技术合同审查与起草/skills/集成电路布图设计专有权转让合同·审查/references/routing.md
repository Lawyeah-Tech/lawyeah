# 边界与路由

本技能只审查 **技术类合同 / 集成电路布图设计专有权转让合同** 的待签、已登记布图设计专有权权利让与文本。中文展示名是「审查集成电路布图设计专有权转让合同（技术类合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 仅授权复制或商业利用；约定期限；入门费+提成；许可人可自用或再许可；届满交回 | `集成电路布图设计专有权许可合同·审查` |
| 已授权专利的权利让与；专利号、年费、无效宣告是主轴 | `专利权转让合同·审查` |
| 专利申请权让与；申请号、申请日是权利变动主轴 | `专利申请权转让合同·审查` |
| 计算机软件著作权让与为主给付 | `计算机软件著作权转让合同·审查` 或 `软件著作权转让合同·审查` |
| 现有未公开技术以保密维持，无布图登记号 | `技术秘密转让合同·审查` |
| 笼统《技术转让合同》，专利/布图/秘密混章未拆 | `技术转让合同·审查` |
| 植物新品种权让与 | `植物新品种权转让合同·审查` |
| 植物新品种权许可 | `植物新品种权许可合同·审查` |
| 集成电路布图设计专有权许可（即使标题写转让） | `集成电路布图设计专有权许可合同·审查` |
| 订立时布图尚不存在，须研究开发 | `技术开发合同·审查` |
| 以技术知识解决特定问题，不交专有权 | `知产技术服务·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `集成电路布图设计专有权转让合同·起草` |
| 已签未争、只问变更日、GDS 交割日或尾款日 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或知产争议专项。` 或对应专项领域 |
| 布图专有权撤销、侵权或权属诉讼已立案 | 知产或争议专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

布图专有权转让正文里夹带一小段专利实施许可或软著让与：专章交接对应原子；布图买断条款可继续审。用户坚持本技能把许可、专利权转让、软著转让或技术秘密整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
