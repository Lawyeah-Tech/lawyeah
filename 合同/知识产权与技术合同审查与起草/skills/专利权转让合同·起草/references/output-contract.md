# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受或必然可执行；编造未给出的价款、期限；把已失效《合同法》《技术合同法》及其实施条例或 1984 年专利法写入结论；把未登记写成已取得权属仅不能对抗第三人；保证专利永不无效或一律退费；把申请权或许可文本当成已完成的本类型审查；写“先变更后补批”境外路径。

## 1. 触发、单方立场与成果状态

立场、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查专利权转让合同（技术类合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、已失效《技术合同法》或其实施条例、1984 年专利法、已失效 2010 年质押登记办法时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `技术类合同`，子级 `专利权转让合同`。定性理由、易混切开结果（专利申请权 / 专利实施许可 / 概括技术转让 / 技术秘密 / 技术开发）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。

## 4. 主体、权属与文本版本

主体表：签约名、履行名、付款名、发票名、授权签字人、登记簿专利权人、共有人、质权人。权属表：职务发明线索、质押/保全、年费、无效或权属程序。版本表：正文、登记簿副本、许可清单、聊天确认；冲突并列。

## 5. 标的、登记、对价与资料

专利号与授权日；是否被写成登记对抗；著录项目变更义务人与期限；价款是否绑登记节点；在先许可；年费衔接；证书与配套资料；境外审批。缺口标 `G#`。不输出申请权驳回解除口径或许可备案口径。

## 6. 格式条款、强制规范与无效后果

是否构成格式条款；提示说明痕迹。850 禁质疑不得写成可放行。第四十七条退费分轨。强制规范只按第 153 条和解释第 16 条区分，不用失效口诀。向境外转让未批准：履行字段停止。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。不得把登记对抗句改成“尽量及时登记”后放行。

## 9. 谈判与签署提醒

谈判顺序：先红线（登记对抗、权属未闭合、申请权/许可被当卖断、未批境外、850 禁质疑），再必须改（变更义务、价款节点、在先许可、年费、资料、第四十七条分轨），最后可优化。签署提醒：授权、用印、日期、登记簿副本与许可清单、变更授权书、境外批准。不指导倒签或先变更后补批。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。审查模式成果不是整份起草终稿；起草模式见文末。不是履约交底、争议文书或效力保证，也不是专利申请权转让、专利实施许可或概括技术转让安排。
