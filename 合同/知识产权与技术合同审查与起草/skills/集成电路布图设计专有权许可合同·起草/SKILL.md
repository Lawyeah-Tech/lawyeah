## 本类型硬闸

1. **许可 ≠ 转让**：正像是许可人保留布图设计专有权，只在约定期限、地域、方式和接触范围内授权：复制布图设计的全部或任何具有独创性的部分；以及将受保护的布图设计、含该布图设计的集成电路或含该集成电路的物品投入商业利用（为商业目的进口、销售或以其他方式提供）。权属转移、著录项目变更、自登记之日起权利移转、许可人永久停用并不再处分 → `集成电路布图设计专有权转让合同·审查`。不得删掉“永久买断／专有权归被许可人”后继续当本类型审。
2. **备案 ≠ 生效**：现行《集成电路布图设计保护条例》（2001）第二十二条：转让须书面并登记、自登记之日起生效；**许可只需书面合同**。国知局“实施许可合同备案”是配合义务（行政维权、结汇、备案申请表），不是合同或许可生效要件。不得写“未备案则未生效”。不得套用《专利实施许可合同备案办法》。拟签署日若落在 2026-10-15 及以后，运行时核验 2026 年修订条例是否已施行；修订文本如要求合同生效后三个月内备案，仍是备案义务，不是生效条件。
3. **与转让 `集成电路布图设计专有权转让合同·审查` 切开**：标题写“许可”但正文是权属转移、一次买断、向国务院知识产权行政部门办理转让登记，负触发转让原子。禁止打开或复制 `集成电路布图设计专有权转让合同·审查` 的 method。禁止把向外国人转让证明、著录项目变更当本类型主路径。
4. **不得套专利实施许可**：标的是布图设计登记号（如 BS. 数字）、登记申请日、首次商业利用日，不是专利号、权利要求和年费。专利实施许可、年费维持、专利备案办法 → `专利实施许可合同·审查`。专利与布图捆成一份未拆分 → `技术许可合同·审查`。技术秘密工艺包许可 → `技术秘密使用许可合同·审查`。
5. **保护期与权利基础**：专有权经登记产生（条例第八条）；保护期十年，自登记申请日或世界任何地方首次商业利用日起算，以较前日期为准；创作完成起十五年不再受保护（第十二条）。许可期限不得超过剩余保护期。隐瞒首次商业利用日必须改。无登记证书或已过保护期：权利基础字段停止。
6. **许可方式与范围可履行**：必须落成独占、排他或普通，并写清复制／商业利用（含进口）、代工厂、芯片型号或工艺节点、是否允许改版或嵌入 SoC、分许可。未约定方式参照技术合同解释第二十五条视为普通许可。共有人未经其他共有人同意不得订立独占或排他许可（实施细则第十条）。
7. **交付、保密与 850**：交付物须特定到 GDSII、网表、测试向量、DRM 等；交付前须有保密安排。无偿独占回授、禁止质疑专有权有效性、禁止他源技术 → 民法典第八百五十条＋解释第十条，红线删除。限制进出口或国家秘密未批：履行字段停止，禁止先交 GDSII 后补证。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签布图设计专有权许可正文，尚未签署，尚未成争，核心给付是已登记布图设计的复制与商业利用许可，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 权属转移、转让登记、著录项目变更、许可人永久停用并不再处分 → `集成电路布图设计专有权转让合同·审查`；
- 主文是专利号、权利要求、年费维持或专利实施许可备案 → `专利实施许可合同·审查`；
- 专利与布图／秘密捆成一份未拆分的概括许可 → `技术许可合同·审查`；
- 标的是未公开工艺、配方、算法，不以布图登记号为主轴 → `技术秘密使用许可合同·审查`；
- 植物新品种权许可 → `植物新品种权许可合同·审查`；计算机软件著作权许可 → `计算机软件著作权许可合同·审查`；
- 订立时尚不存在、须研究开发 → `技术开发合同·审查`／`委托开发合同·审查`／`合作开发合同·审查`；
- 可行性、FTO、工艺评价 → `知产技术咨询·审查`；只调试、不交布图数据 → `知产技术服务·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁或侵权／撤销登记已立案 → `或知产争议专项。` 或知产／争议专项。

以许可为名买卖国家秘密、未批限制进出口技术，或把无登记证书、明知无权处分改成可履行授权：只出告知，不改写成可履行路径。

### 起草必写

- 许可人保留布图设计专有权，只在约定期限、地域、方式和接触范围内授权复制与商业利用（含进口、销售或其他提供）。

- 标的写布图设计登记号、登记申请日、首次商业利用日。
- 许可期限不得超过剩余保护期（十年，自登记申请日或世界任何地方首次商业利用日起算，以较前日期为准；创作完成起十五年不再受保护）。

- 布图登记证书（登记号、申请日、首次商业利用日）。

### 禁止出现

- 权属转移、著录项目变更、自登记之日起权利移转、许可人永久停用并不再处分。许可不得写成权属已转移。

- 向外国人转让证明、著录项目变更当本类型主路径。
- 专利号、权利要求和年费作为主轴。
