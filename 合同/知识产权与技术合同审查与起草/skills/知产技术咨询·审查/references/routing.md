# 边界与路由

本技能只审查 **技术类合同 / 技术咨询合同** 的待签、以可行性或技术方案意见为核心给付的文本。中文展示名是「审查技术咨询合同（技术类合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 新技术、新产品、新工艺、新品种或新材料及其系统尚待研究开发 | `技术开发合同·审查` |
| 委托开发作为已独立成册的细分主文件 | `委托开发合同·审查` |
| 双方共同投资并分工参与研究开发 | `合作开发合同·审查` |
| 商务管理咨询意见、选址、战略或市场销售额预测 | `或` |
| 落在委托合同货架，或用户要求按委托事务、费用预付、任意解除审 | `委托合同目录下的技术咨询→` |
| 以技术知识解决特定技术问题，调试、改进或操作指导 | `知产技术服务·审查` |
| 施工图、设计说明、出图章为主给付 | `或` 或 `或` |
| 工程造价或投资咨询整案 | `工程造价或投资咨询整案→` |
| 已有成熟专利、专利申请或技术秘密的权利让与 | `技术转让合同·审查` |
| 已有技术的实施或使用许可 | `技术许可合同·审查` |
| 核心是交付可运行软件而非咨询意见 | `软件委托开发合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `知产技术咨询·起草` |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或知产争议专项。` 或对应专项领域 |
| 虚假鉴定、权属诉讼已立案 | 知产或争议专项，不在本任务评改 |
| C 端大众快检 | 只分流，不回改 |

技术咨询正文里夹带一小段已有背景技术说明或商务数据摘录：专章交接对应原子；可行性或技术方案意见条款可继续审。用户坚持本技能把开发、商务咨询、委托货架文本或出图整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
