# 知产技术咨询·审查

## 任务目标

在单一立场下，只审查 **技术类合同 / 技术咨询合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文显示名为「知产技术咨询·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证研发成功、立项获批或固定降本。

## 本类型硬闸

1. **可行性 / 技术方案意见**：正像是就特定技术项目出具可行性论证、技术预测、专题技术调查、分析评价报告或技术方案意见。核心给付是决策参考，不是研发成果，不是动手解决问题，不是商务管理意见，也不是处理对外事务。尚待研究开发 → `技术开发合同·审查`；商务管理咨询 → `或`；用户坚持按委托货架、费用预付或任意解除主路径审 → `委托合同目录下的技术咨询→`；动手解决特定技术问题 → `知产技术服务·审查`。
2. **不保证研发成功**：禁止放行“保证研发成功 / 保证拿到专利 / 保证立项或审批通过 / 保证固定降本或固定收益”。可约定报告覆盖任务书要点、数据可核验、分析逻辑自洽；未达则减酬、补正或解除。
3. **与开发、服务咨询、委托侧切开**：不得套用开发验收、技术风险分担或专利申请权默认；不得套用商务咨询固定节约或代付款权限主路径；不得把委托章费用预付或任意解除写成技术咨询法定主路径。标题“技术咨询”但正文是研发、商务咨询或委托事务：负触发，不按本类型改完。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签技术咨询正文，尚未签署，尚未成争，核心给付是就特定技术项目提供可行性或技术方案意见，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 新技术、新产品、新工艺、新品种或新材料及其系统尚待研究开发 → `技术开发合同·审查`；委托开发细分主文件 → `委托开发合同·审查`；合作开发 → `合作开发合同·审查`；
- 商务管理、选址、战略或市场销售额预测，无特定技术项目 → `或`；
- 落在委托合同货架，或用户明确要求按委托事务、费用预付、任意解除审 → `委托合同目录下的技术咨询→`；
- 以技术知识动手解决特定技术问题、调试或指导 → `知产技术服务·审查`；
- 施工图、设计说明、出图章为主给付 → `或` 或 `或`；
- 工程造价或投资咨询整案 → `工程造价或投资咨询整案→`；
- 已有技术的转让或许可 → `技术转让合同·审查` / `技术许可合同·审查`；
- 核心是交付可运行软件 → `软件委托开发合同·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → `知产技术咨询·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁或虚假鉴定诉讼 → `或知产争议专项。` 或知产/争议专项。

以咨询为名出具虚假可行性、虚假 FTO，或未批限制进出口/国家秘密技术评价：只出告知，不改写成可履行路径。

## 建立审查坐标

确认：使用者与授权；单方立场；相对方；全文及任务大纲/数据清单版本；是否特定技术项目；交付是否仅为意见或报告；是否保证研发成功、保过或固定降本；决策损失是否无条件转给受托人；费用由谁负担；报告使用权与新成果是否分项；验收是否绑投产或盈利；进出口或国家秘密；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的报酬、期限、费用用 `【待填】`，不编造。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释、已失效《技术合同法》及其实施条例当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验第 878、879–881、885、886 条，解释第 30、33、42 条，以及 851/882 切开、506 除外；`search_practiced` 只补审查反例；`search_template` 只借栏目结构。不虚构案件系统。

`search_law` 对上述法律结论为 required 级：不可用时不拒绝执行，只停止效力字段。返回已失效《合同法》或其解释、已失效《技术合同法》或其实施条例时记为噪声，不得写入 `L#`。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`基本面.md` 与 `框架.md` 对咨询报告著作权归属互相冲突：不得写成一律归委托人或一律归受托人，须分项约定。`框架.md` 决策损失自负须补上“报告符合约定要求”前提。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `知产技术咨询·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议或知产。未签且目标是评改已有技术咨询文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。开发、商务咨询、委托货架技术咨询、技术服务、出图负触发。

### 2. 主体、专家与利益冲突

签约名、履行名、付款名、发票名分列。技术评价场景核查与评价对象有无利益关联。Key expert 可锁岗位与资质，不编造法定点名自然人。

### 3. 标的与成功保证

任务大纲写明特定技术项目和咨询形式。删除研发成功、专利、保过、固定降本保证。

### 4. 资料协作与费用

委托人阐明问题并提供资料。费用无约定时不得写成委托人依法预付。

### 5. 881 自负前提、885 分项与验收

决策损失自负以报告符合约定为前提。新成果与报告使用权分项。验收看任务书要点，不以投产成功或商业盈利为唯一标准。

### 6. 格式条款与强制规范

无核验引文则法律结论字段停止。

### 7. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把虚假可行性或未批进出口改成可履行结构、坚持保留研发成功/保过/固定降本保证或无条件决策赔偿。
- `字段停止`：法域、动态规则、进出口目录、国家秘密审批、行业评价等级未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
