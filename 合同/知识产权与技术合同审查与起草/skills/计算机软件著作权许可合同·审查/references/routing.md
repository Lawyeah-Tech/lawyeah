# 边界与路由

本技能只审查 **技术类合同 / 计算机软件著作权许可合同**。主线是现有计算机软件著作权财产权利的使用授权，许可人保留权属，法律路径是民法典第八百七十六条参照适用技术合同节。不是知产父级分发／自用许可，不是权属转让，也不是委托开发。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 权属买断、登记权利人变更、全部财产权一次让与 | `计算机软件著作权转让合同·审查`；用户走知产货架则 `软件著作权转让合同·审查` |
| 已锁定知识产权相关合同，核心是 OEM／渠道／预装／再分发出货 | `软件许可合同（分发许可模式）·审查` |
| 已锁定知识产权相关合同，仅内部安装、禁止再分发 | `软件许可合同（自用许可模式）·审查` |
| 一般文字／美术／视听作品许可使用 | `著作权许可使用合同·审查` |
| 著作权转让（非软件） | `著作权转让合同·审查` |
| 主文是技术秘密配方／工艺，软件只是载体 | `技术秘密使用许可合同·审查` |
| 主文是专利号、权利要求、年费、专利实施许可备案 | `专利实施许可合同·审查` |
| 专利与软件捆成一份未拆分的概括技术许可 | `技术许可合同·审查` |
| 订立时尚待研究开发 | `技术开发合同·审查` |
| 委托开发／合作开发主文件 | `委托开发合同·审查`／`合作开发合同·审查` |
| 可运行软件交付、验收上线为主给付 | `软件委托开发合同·审查` |
| 可行性、FTO、架构评价，不授予著作权 | `知产技术咨询·审查` |
| 已有系统运维调试，不授予著作权许可 | `知产技术服务·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | `计算机软件著作权许可合同·起草` |
| 已签未争、问激活码／维保响应／审计日 | 本套导航的履约步骤 |
| 侵权、许可费或盗版已催告、立案、开庭或仲裁 | 合同争议或知产专项；不填签前十节 |
| 未明确权利却要推定全部授权 | 留本任务只出红线；用户坚持改成全授则整体停止 |
| 未披露传染性开源仍要二次开发放行 | 留本任务红线；不改成可履行开源豁免 |
| 限制进出口软件未批仍要向境外交付 | 字段停止或整体停止；不写先交付后补证 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。

本技能不得转去加载知产分发／自用许可或软件著作权转让双文件完成本类型审查，也不得把 SKU／渠道出货或权属过户写成技术类默认主路径。
