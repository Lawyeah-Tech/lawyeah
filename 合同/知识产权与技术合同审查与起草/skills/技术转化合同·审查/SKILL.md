# 技术转化合同·审查

## 任务目标

在单一立场下，只审查 **技术类合同 / 技术转化合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文显示名为「技术转化合同·审查」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、保证量产或拿到准入证、把从零开发或买断转让整案改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **转化 vs 转让/开发**：正像是订立时已有具有实用价值、尚未实现工业化应用的科技成果（含阶段性成果），核心给付是后续试验、开发和应用，目标是工业化应用。订立时尚不存在、要从零研究新技术新产品 → 负触发 `委托开发合同·审查`；标题只写《技术开发合同》且未独立成册为转化 → 负触发 `技术开发合同·审查`。对价只是让与已有专利、申请权或技术秘密、无后续试验开发 → 负触发 `技术转让合同·审查`。第八百五十一条第四款是**参照适用**开发规定，不是把本合同改成委托开发或合作开发；禁止套第八百五十九条、第八百六十条当本类型默认归属。
2. **职务成果必须闭合**：职务科技成果的使用权、转让权属于法人或非法人组织。供给方若是课题组、完成人、研究生或离职人员，须见单位书面授权或转化法第十九条协议，且不变更权属。个人把职务成果当私产签约：只出告知，不改成可履行。完成人优先受让只在单位对外转让时适用，不得写成完成人当然有权对外转化。
3. **转化失败先定性**：必须拆开“技术本身重大缺陷或成熟度虚高”与“实施方产能、原料或工艺条件不足”。后续工程化部分可参照第八百五十八条约定或合理分担；禁止放行“保证量产成功 / 交钥匙工程 / 失败全额退款”。也禁止把一切未达指标径直写成对方违约。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签转化正文，尚未签署，尚未成争，核心给付是就已有未工业化实用成果做后续试验、中试、工程化或小批量达标，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 订立时尚不存在技术方案、一方出资另一方独立研发 → `委托开发合同·审查`；标题写成委托技术开发则 `委托合同目录下的委托技术开发主文件且用户未锁定本类型→`；
- 各方按计划分工参与新技术研究开发，不是就已有成果做工业化 → `合作开发合同·审查`；
- 标题或主轴是未区分类型的《技术开发合同》 → `技术开发合同·审查` 或回引擎重新定性；
- 可运行软件、系统上线、源码交付且几乎无中试不确定性 → `软件委托开发合同·审查`；
- 让与已有专利、申请权或技术秘密，无后续试验开发 → `技术转让合同·审查` / `专利权转让合同·审查` / `专利申请权转让合同·审查` / `技术秘密转让合同·审查`；
- 仅授权实施或使用、底层权利不改且无工程化任务 → `技术许可合同·审查` / `专利实施许可合同·审查` / `技术秘密使用许可合同·审查`；
- 特定技术项目可行性、预测、评价，不实施转化 → `知产技术咨询·审查` 或 `委托合同目录下的技术咨询→`；
- 解决特定技术问题、调试、培训，不以工业化应用为目标 → `知产技术服务·审查` 或 `委托合同货架按处理事务费用预付任意解除起草的同名《技术服务合同》→`；
- 技术折价入股、设立或增资并办理股权变更为主给付 → 回引擎按公司/出资类重新定性，不按本类型改完；
- 撮合双方转化、自己不提供成果也不实施 → 回引擎按中介重新定性；
- 无文本、本类型条件已谈妥、要出己方稿 → `技术转化合同·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `或知产争议专项。` 或对应专项领域。

以转化为名擅自处分职务成果、未批限制进出口、把限制后续改进或圈占不实施改成可履行垄断：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（成果供给方或转化实施方择一）；相对方；全文及成果清单/资料清单/工艺达标协议/分成办法版本；订立时成果是否已存在及成熟度阶段；是否单位持有的职务成果；失败按风险还是违约；背景权利与转化增量是否拆开；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的入门费、提成比例、达标数值、宽限期用 `【待填】`，不编造。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`基本面.md` “参照技术开发或技术转让”按第八百五十一条第四款纠正为只参照开发；原始权利移交若已成主给付，负触发转让原子。`基本面.md` “未评估公示可能被撤销”按转化法第十八条和事业单位国有资产办法第五十六条纠正：国家设立的高校院所可自主决定转让、许可或作价投资，协议定价须公示名称和拟交易价格，不需报主管部门或财政审批备案；未公示是程序缺口，不得写成当然无效。`框架.md` 三种转化方式若滑成单纯买断或单纯入股，负触发，不在本任务改完。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `技术转化合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有转化文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。从零开发、单纯转让或许可、合作开发新技术、技术入股负触发。

### 2. 主体与职务成果

签约名、履行名、付款名、发票名分列。课题组未经法人授权不得写成可以盖章。个人处分职务成果停笔。

### 3. 阶段性成果、资料与成熟度

成果须特定到可核验清单。TRL 或成熟度阶段写入鉴于和验收，不得暗示已是交钥匙工程。

### 4. 失败定性与分阶段验收

风险与违约拆开。小试—中试—试产分节点，禁止“甲方满意”作唯一标准。

### 5. 背景/增量、后续改进与 850

背景权利不因本合同当然移转。增量工艺归属须明示。禁止无偿独占回授。

### 6. 对价、公示、圈占收回

入门费与提成分列。高校协议定价缺公示：字段停止。约定期限不实施可收回授权。

### 7. 格式条款与强制规范

无核验引文则法律结论字段停止。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效或保证量产、把个人擅自处分职务成果改成可履行、把从零开发或买断转让按本类型放行、把限制后续改进改成可履行垄断。
- `字段停止`：法域、高校公示、出口管制、职务发明内部规章、TRL 第三方评级未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
