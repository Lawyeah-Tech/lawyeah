# 边界与路由

本技能只审查 **技术类合同 / 技术培训合同** 的待签、以传授已有特定项目专业技术为主给付的文本。中文展示名是「审查技术培训合同（技术类合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 主给付是动手解决特定技术问题、调试排故、保证修好 | `知产技术服务·审查` |
| 用户指定狭义技术服务细分主文件 | `技术服务合同（狭义）·审查`（P1） |
| 尚待研究开发、成果订立时尚不存在 | `技术开发合同·审查` |
| 委托开发作为已独立成册的细分主文件 | `委托开发合同·审查` |
| 双方共同投资并分工参与研究开发 | `合作开发合同·审查` |
| 可行性论证、技术预测、专题调查、分析评价 | `知产技术咨询·审查` |
| 为与第三人订立技术合同做联系介绍 | `技术中介合同·审查`（P1） |
| 用人单位与劳动者约定专项培训费用、服务期、离职违约金 | `法人或者非法人组织计划进行的职工业余教育。用人单位与劳动者的专项培训服务期→` |
| 职业培训、文化学习、职工业余教育、驾校厨师通识课 | 本套导航的类型切开步骤 重新定性 |
| 名为培训、实为劳务派遣 | `或劳动专项，不改写成可履行派遣。挂靠违法分包未批限制进出口仍要跨境交付：只出告知，不改写成可履行路径。` 或劳动专项；本任务只告知 |
| 已有可读待签文本要评改 | `技术培训合同·审查` |
| 无文本、本类型条件已谈妥、要出己方稿 | 本任务起草并自审 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争的普通合同路径 | `或知产争议专项。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

开发或转让主文件里夹带一小段操作培训：按主给付走开发/转让原子，不得单独按本类型认定。培训正文里夹带一次课后答疑：答疑专章可注明，传授主给付可继续审。用户坚持本技能把服务、开发、劳动服务期或职业培训整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿本类型文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
