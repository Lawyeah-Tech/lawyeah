# 渠道销售代理·起草

## 任务目标

在单一立场下，只起草 **渠道销售委托代理合同**，并按本类型硬闸自审。交付可编辑草稿、未决项、自审风险表和自审后修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文名必须是「审查渠道销售委托代理合同（买卖合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、佣金诉讼策略、有效性保证、把全案驻场/经销买断/行纪/存量房中介或商品房本约改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **渠道佣金，非买断**：对价是成交佣金，房源或存货所有权仍归委托人，终端本约由委托人（或全案/自销）签署。买断进货、存货风险归渠道、赚差价 → 负触发 `经销买卖合同·审查`。
2. **非全案**：渠道不驻场，不负责案场讲解、催款和网签手续。驻场接待、全案策划销售、去化指标对赌、独家包盘 → 负触发 `房地产全案销售代理·审查`。
3. **非行纪**：渠道不以自己名义与购房人/终端订立本约，也不自负本约权利义务。以自己名义成交或先买后转 → 负触发 `购房人终端订立本约，也不自负本约权利义务。以自己名义成交或先买后转→负触发`。
4. **报备—到访—确认闭环**：写清报备有效期、判重规则、首位报备且到访确认。自然到访或全案/自销已登记客户不得洗成渠道客户。
5. **结佣节点**：通常为签署商品房买卖合同（或网签）且首付款按约到账。仅交定金不视为成交。禁止以按揭尾款未到账无限期拖佣。退房须退已领佣金。
6. **禁止私自返佣 / 截客 / 洗客 / 商业贿赂**：不得向购房人私诺回扣，不得在售楼处门口拦截自然到访并虚假报备，不得与置业顾问串通洗客。只告知，不改成可履行回扣或洗客结构。用户坚持：整体停止。
7. **非独家赛马 + 终止后已报备成交仍结佣**：委托人可同时委托多家渠道并自行销售。因营销策略单方终止的，终止前已有效报备且最终成交的客户仍应结佣。
8. **资质备案与购房款账户**：经纪机构备案或经营范围未核则字段停止，不写“可以展业”。购房款不进渠道个人户或一般结算户。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿；尚未签署，尚未成争，核心给付是引流、推介、报备带看并按确认成交收佣金。有完整待签文本要评改时转配对审查原子。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 驻场接待、全案策划销售、去化对赌、独家包盘 → `房地产全案销售代理·审查`；
- 买断进货、存货风险归渠道、赚差价 → `经销买卖合同·审查`；
- 以自己名义与终端订立本约或先买后转 → `购房人终端订立本约，也不自负本约权利义务。以自己名义成交或先买后转→负触发`；
- 开发商委托驻场销售但不是渠道引流（权限含代销讲解/网签） → `开发商委托驻场销售但不是渠道引流（权限含代销讲解网签）→`；
- 存量房买卖或租赁居间、带看二手房 → `存量房买卖或租赁居间带看二手房→`；
- 代签商品房买卖本约、概括处理缔约事务 → `代签商品房买卖本约概括处理缔约事务→`；
- 主文件是商品房买卖本约 → `一般商品房买卖合同·审查`；不得删本约条款后当渠道审；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁，或要佣金诉讼策略 → `或对应专项领域。` 或对应专项领域。

私自返佣、洗客截客、商业贿赂、规避限购或未达预售条件仍要成交：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（委托人/开发商侧或渠道商侧择一）；相对方；全文及附件/报备流程/佣金表版本；是否买断或赚差价；是否驻场讲解/网签；是否以自己名义与终端签约；独家或非独家；报备有效期与判重；结佣节点；退房退佣；是否允许二级分销；备案与委托书痕迹；购房款账户；不可接受事项；法域、项目所在地与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的佣金、套数、期限用 `【待填】`，不编造。

## 起草模式

本原子只起草本类型。有完整待签文本要评改时，转 `渠道销售代理·审查`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。同一套本类型硬闸，在落稿时写成正文必写、附件必附或禁止出现，不得审完再补。

**起草必写：** 对价是成交佣金，房源或存货所有权仍归委托人，终端本约由委托人签署；渠道不驻场，不负责案场讲解、催款和网签手续；报备有效期、判重规则、首位报备且到访确认；结佣节点为签署商品房买卖合同（或网签）且首付款按约到账，仅交定金不视为成交，退房须退已领佣金；委托人可同时委托多家渠道并自行销售，因营销策略单方终止的，终止前已有效报备且最终成交的客户仍应结佣；购房款不进渠道个人户或一般结算户。

**附件必附：** 《客户报备及带看确认流程》；《各户型佣金结算标准表》；《廉洁自律协议》。

**禁止出现：** 买断进货、存货风险归渠道、赚差价；以自己名义与购房人订立本约；自然到访或全案/自销已登记客户洗成渠道客户；以按揭尾款未到账无限期拖佣；向购房人私诺回扣、售楼处门口拦截自然到访并虚假报备、与置业顾问串通洗客。

出稿后必须用本类型硬闸与 [审查方法](references/method.md) 自审。未过不得宣称起草完成。交付草稿、未决项、自审风险表、自审后修改句。

他类型出稿、已签履约、已成争：仍负触发。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`基本面.md` 中把标题写成“房地产渠道分销”只是命名建议，不是法定名称。`框架.md` 中“居间性质的委托服务合同”不得写成已获得代签权或全案销售权；“CRM 唯一依据”不得写成开发商单方系统不可复核；“随时终止”不得写成无偿甩客且已报备成交不再结佣。

### 0. 签署状态与成果分流

有完整待签文本要评改 → `渠道销售代理·审查`；无文本且本类型条件已谈妥 → 留本任务起草并自审；已签履约 → 本套导航履约步骤；已成争或佣金诉讼策略 → 合同争议。未签且目标是按已谈妥条件出己方稿，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。全案、经销、行纪、存量房中介、销售代理、商品房本约负触发。

### 2. 主体、备案与委托书

签约名、履行名、付款名、发票名分列。备案与委托书未核：字段停止。

### 3. 报备—到访—确认与服务范围

不驻场；报备有效期；判重；自然到访不得洗成渠道客户。

### 4. 结佣节点、阶梯激励与退房退佣

禁止仅交定金即结佣；禁止按揭未放无限拖佣。

### 5. 购房款账户、返佣与商业贿赂

购房款不进渠道私户。返佣/截客/洗客停笔。

### 6. 非独家、终止后结佣、格式条款与强制规范

赛马机制；终止前已报备成交仍结佣。无核验引文则法律结论字段停止。

### 7. 违约、解除与争议

洗客高额违约金可谈但不得写成必得倍数。不选定唯一法院充作意见。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把返佣/洗客/截客/商业贿赂或房款进私户改成可履行结构。
- `字段停止`：法域、动态规则、备案、预售许可、地方网签未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书、佣金诉讼策略，或已锁他类。
