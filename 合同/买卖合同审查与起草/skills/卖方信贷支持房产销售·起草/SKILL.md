# 卖方信贷支持房产销售·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构，不证明本约条款已被接受。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《物权法》及其解释当作现行规则。不得把普通商品房五证清单、面积误差百分之三、先验房或宣传入合同当作本类型主路径。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只起草 **“卖方信贷支持” 房产销售合同**，并按本类型硬闸自审。交付可编辑草稿、未决项、自审风险表和自审后修改句。

本技能类型锁死。不扫描其他类型。场景分层为 **P1**。`depends-on` 为空。不要求先跑导航。

不交付：普通商品房五证／面积误差专项、他类审查、从零起草、履约交底、争议文书、有效性或按揭获批保证。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿；尚未签署，尚未成争，核心给付是房屋所有权转移换价款，**并且**存在出卖人或其关联方、指定第三方对买受人提供信贷、垫资、计息缓交首付、贴息或拆分首付款配合后续按揭的安排。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 文本是普通商品房预售或现售，付款仅为自有资金加银行／公积金按揭，无卖方或关联方融资、垫资、贴息、计息缓交 → `一般商品房买卖合同·审查`；
- 业主出售已办证存量房、无开发商卖方信贷 → `二手房买卖·审查`；
- 买卖加固定价回购、过户为担保 → `让与担保式房产买卖·审查`；
- 以房抵工程款或抵债 → `以房抵债工抵房·审查`；
- 附选择权、转售权为主给付 → `附选择权转售权房产销售·审查`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问还款日、网签日、付款留痕 → 本套导航的履约步骤；
- 已成争（催告、解除、索赔、诉讼仲裁），包括银行已拒贷后要退房评估 → `或对应专项领域。` 或对应专项。

规避限购、出具与实收不符的全额首付收据骗取按揭、把首付贷包装成可履行结构：只出告知，不改写成可履行文本。

## 建立审查坐标

确认：使用者与授权；买受人或出卖人／放贷关联方单一立场；相对方；买卖本约、借款／分期／贴息附件、还款计划、自动扣款授权、收据或发票样本版本；房屋坐落；不可接受事项；法域与拟签时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价格、利率、日期用 `【待填】`，不编造。

## 本类型硬闸

未完成下列切开和落句，不得宣称起草完成。禁止只用普通商品房审查清单交差。

1. **卖方融资／垫资性质**。必须点名结构属于：真实延期支付购房款、出卖人或关联方出借／垫资首付款、持牌机构放贷、贴息促销，或数种叠加。名称为“延期缴纳”“分期支付”“资金周转”不得代替定性。用于向银行谎称首付已齐的垫资或虚假收据：红线，停止改写成可履行结构。
2. **利率与民间借贷上限切开**。利息加手续费、管理费、服务费等全部资金占用成本，与商业银行按揭利率切开。非持牌民间出借适用合同成立时一年期 LPR 四倍上限；预先扣息按实际出借额计本金。持牌机构不得套用四倍口诀，也不得用按揭利率保护卖方私下放贷。
3. **按揭失败**。后续商业／公积金按揭必须区分买受人原因、出卖人原因（含虚假首付凭证、项目或预售条件不符）、不可归责双方，以及因本信贷安排被银行或监管否定。禁止写成“贷不成必须补足全款否则违约并没收已付款”。
4. **与普通商品房切开**。无卖方信贷结构则负触发转 `一般商品房买卖合同·审查`。本技能不把五证、面积百分之三、先验房、宣传入合同当作完成标准；这些缺口只提示并路由，不在本任务展开邻类 method。

必须有修改句。禁止只打红黄绿。每个风险回链文本位置。


## 起草模式

本原子只起草本类型。有完整待签文本要评改时，转 `卖方信贷支持房产销售·审查`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。同一套本类型硬闸，在落稿时写成正文必写、附件必附或禁止出现，不得审完再补。

**起草必写：** 点名结构属于真实延期支付购房款、出卖人或关联方出借/垫资首付款、持牌机构放贷、贴息促销，或数种叠加，名称不得代替定性；利息加手续费、管理费、服务费等全部资金占用成本与商业银行按揭利率切开，非持牌民间出借适用合同成立时一年期 LPR 四倍上限，预先扣息按实际出借额计本金；后续按揭必须区分买受人原因、出卖人原因（含虚假首付凭证、项目或预售条件不符）、不可归责双方，以及因本信贷安排被银行或监管否定。

**附件必附：** 借款/分期/贴息协议；《分期还款计划表》；贴息则附《代垫利息明细表》。

**禁止出现：** 用“延期缴纳”“分期支付”“资金周转”代替定性；用于向银行谎称首付已齐的垫资或虚假收据包装成可履行；“贷不成必须补足全款否则违约并没收已付款”；用按揭利率保护卖方私下放贷；把五证、面积百分之三、先验房、宣传入合同当作本类型完成标准。

出稿后必须用本类型硬闸与 [审查方法](references/method.md) 自审。未过不得宣称起草完成。交付草稿、未决项、自审风险表、自审后修改句。

他类型出稿、已签履约、已成争：仍负触发。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验借款与禁止高利放贷、民间借贷四倍上限及无效情形、虚假意思表示、强制规范与公序良俗、分期付款解除、定金上限、格式条款、商品房担保贷款未能订立时的解除与返还；`search_practiced` 补审查反例；`search_template` 只借修改句结构。不虚构案件系统。

`search_law` 对法律结论为 required 级节点：不可用时不拒绝执行，只停止法律结论字段。返回已失效《合同法》及其解释、已失效 24%/36% 利率口诀时记为噪声，不得写入 `L#`。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、出具与实收不符的首付收据、把首付贷或垫资骗贷改成可履行结构、规避限购、保证合同有效或保证按揭获批。
- `字段停止`：出借人是否持牌、利率与费用未列全、后续按揭是否仍要申请、地方限购或首付比例未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或用户只要普通商品房五证／面积审查。

生存级首付或个人无限连带且用户拒绝升级：停止“可以签署”建议。
