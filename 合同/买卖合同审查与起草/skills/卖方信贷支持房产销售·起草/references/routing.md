# 边界与路由

本技能只审查 **买卖合同 / “卖方信贷支持” 房产销售合同**（房屋买卖本约叠加出卖人或其关联方、指定第三方的信贷、垫资、计息缓交或贴息）。

| 已能支持的事实 | 路由 | 不得写成 |
| --- | --- | --- |
| 待签、存在卖方或关联方信贷／垫资／贴息／计息缓交、目标是评改该结构 | 留本任务 | 已完成签约或已生效；已排除借贷风险 |
| 开发企业售新房，付款仅为自有资金＋银行／公积金按揭，无卖方侧融资 | `一般商品房买卖合同·审查` | 用本技能出五证、面积百分之三、先验房主结论 |
| 业主／自然人出售已办或应办存量房产权 | `二手房买卖·审查` | 用本技能审户口、解押过户 |
| 买卖加固定价回购，过户为担保 | `让与担保式房产买卖·审查` | 改成真实卖方信贷外观 |
| 以房抵工程款或抵债 | `以房抵债工抵房·审查` | 本类型放贷审查 |
| 主给付是选择权、转售权 | `附选择权转售权房产销售·审查` | 本类型 |
| 只有借款、无房屋所有权转移对价 | 引擎重新定性或借款专项 | 假装本类型 |
| 有完整待签文本要评改 | `卖方信贷支持房产销售·审查` | 在本起草原子做签前评改 |
| 无可读正文，本类型条件已谈妥，要出己方稿 | 留本任务起草并自审 | 已经完成起草；在本起草原子做签前评改 |
| 已签，问扣款日、网签日、还款留痕 | 本套导航的履约步骤 | 签前意见 |
| 银行已拒贷、已催告解除、索赔、起诉、仲裁 | `或对应专项领域。` 或专项 | 继续当签前审查出修改句充作解除方案 |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 | 两可时灌入商品房与本类型两套知识 |
| C 端大众快检 | 只分流，不回改 | 降成快检商品 |

规避限购、出具与实收不符的首付凭证骗取按揭、未持牌面向不特定人放贷：只告知违法风险，不改写成可履行文本。用户坚持改到能过银行或能签：整体停止。

专业版未收录的 P1 场景不会安装本原子。若用户拿本类型文本来找专业版：输出 `unavailable`，提示，不得用 `一般商品房买卖合同·审查` 硬套。
