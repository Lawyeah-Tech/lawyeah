# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受、必然获批按揭；编造未给出的价格、利率、LPR；把已失效《合同法》及其解释、24%/36% 利率口诀、商业银行按揭利率保护卖方私下放贷写入结论；用五证或面积百分之三表代替本类型硬闸。

## 1. 触发、单方立场与成果状态

立场（买受人，或出卖人／放贷关联方之一侧）、授权、签署状态、主要目标。必须点名是否存在卖方信贷、垫资、贴息或计息缓交。负触发写路由，不启动实体审查。银行已拒贷后要解除：负触发转争议。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释或 24%/36% 口诀时记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `买卖合同`，子级 `“卖方信贷支持” 房产销售合同`。定性理由必须写清：资金提供方是出卖人、关联方还是指定第三方；是延期支付、借贷、垫资还是贴息。易混切开结果必须点名是否排除普通商品房、存量房、让与担保、以房抵债。

加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。虚假收据、规避限购、无牌放贷写停笔告知，不填可履行结构。

## 4. 主体、授权、出借人与文本版本

主体表：买卖签约名、出借人名、是否持牌 `G#`、履行名、**购房款收款账户名**、信贷放款／还款账户名、发票名、授权签字人、买受人共有方式。名称不一致不自动合并。

版本表：买卖本约、补充协议、借款／分期／贴息、还款计划、扣款授权、收据或发票样本、风险自担声明、销讲或聊天确认。冲突并列，不选对用户有利的一版。

## 5. 给付闭环（本类型必填）

固定回答，缺项标 `G#`，不补商业数字：

- 性质：真实延期支付／卖方或关联方信贷／垫资配合申报／贴息／叠加（硬闸 A）
- 首付现金、延期或信贷款额、拟按揭额是否分列；凭证金额是否等于监管账户实收
- 利率、罚息、手续费、管理费是否列全；是否与银行按揭利率切开；是否按资金占用成本合并（硬闸 B）
- 出借人是否持牌；面向不特定购房人计息放贷是否被点名
- 按揭失败是否区分买受人原因、出卖人原因、不可归责双方、本信贷安排被银行或监管否定（硬闸 C）
- 交叉违约是否需催告；加速到期；解除后已付款退给谁
- 效力独立性是否剥夺因信贷无效或政策否定而产生的退房权
- 买卖与借款管辖是否分离
- 批准、登记、网签、放款写成生效条件或期限，不写成已经完成
- 普通商品房五证／面积百分之三：仅记录是否另需转 `一般商品房买卖合同·审查`，不在本节展开（硬闸 D）

## 6. 格式条款、强制规范与停笔

是否构成格式条款；示范文本不排除格式条款；提示说明痕迹；交叉违约、全部没收、效力独立、管辖分离等异常条款。强制规范只区分是否导致民事行为无效，禁用失效口诀。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

虚假首付凭证、无牌面向不特定人放贷、规避限购：只告知，不给可履行改法。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔／转出口径。禁止输出无修改句的色块表。

本类型默认应出现（有事实则单列，无事实则在缺口节说明未检出）：性质切开、利率与费用上限、按揭失败分岔、虚假凭证／实收一致性、交叉违约与退款路径。与普通商品房的切开结果必须可见。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点、不接受时的红线。未给出的商业数字用 `【待填】`，不编造。

性质声明、利率上限、按揭失败四类分岔的建议句必须写全，不得以“依法处理”收尾。红线事项只出告知和停止，不把违法结构改成可履行句。

## 9. 谈判与签署提醒

谈判顺序：先红线（虚假收据、无牌放贷、贷不成没收全款、协助规避监管），再必须改（性质、利率上限、按揭失败、交叉违约、退款、管辖），最后可优化。

签署提醒：核对出借人与出卖人关系及牌照；凭证与监管账户实收一致后再签字；不倒签放款日；不指导先开全额首付证明再申报按揭；不保证银行放贷。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本任务成果是可编辑草稿、未决项、自审风险表和自审后修改句。有完整待签文本要评改转 `卖方信贷支持房产销售·审查`。草稿必须落入本类型起草必写 / 附件必附 / 禁止出现。不是履约交底、争议文书、效力保证或按揭获批保证。基础五证／面积条款如需审查，转 `一般商品房买卖合同·审查`。
