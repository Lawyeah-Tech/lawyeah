# 审查方法（锁定 买卖合同 / “卖方信贷支持” 房产销售合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型，禁止复制一般商品房审查清单。

本文件是可执行判断节点，不是栏目说明书。每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、必然获批按揭、对方必然接受或唯一必得金额。

`search_law` 返回已失效《合同法》及其解释、担保法解释、民间借贷 24%/36% 两线、或把商业银行按揭利率当成卖方私下放贷保护标准时，记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突。

示范文本只参考结构。民法典允许参照示范文本，不证明本约条款已被接受。补充协议、借款协议、贴息协议符合格式条款定义的，仍按格式条款审查。

`基本面.md` 与 `框架.md` 按各自标题语义使用：前者校验主从结构、主体、红旗；后者按六步出句。两文件栏目有交叉时以本方法节点为准，不回改正文。

## 硬闸专节（未点名不得宣称完成）

### A. 卖方融资／垫资性质

先定性资金关系，再谈条款。标题写“补充协议”“分期付款”“延期缴纳”不得单独定性。

| 已能支持的事实 | 定性 | 本任务动作 |
| --- | --- | --- |
| 买受人尚欠出卖人部分购房款，不计息或只约定逾期违约金，不向银行陈述该款已付清，不另签借款 | 真实延期支付 | 按买卖价款分期审；可留本任务；适用分期付款解除规则，不写成借款 |
| 出卖人或关联小贷／保理／高管个人出借或垫付首付款，买受人按期还本息 | 卖方或关联方信贷 | 按借款＋买卖主从结构审；点名出借人、本金、用途 |
| 买受人未足额支付首付，出卖人开具全额首付收据或发票，用于申报银行／公积金按揭 | 垫资配合申报／虚假凭证 | 红线。告知骗取贷款与监管风险。不改写成可履行结构。用户坚持完善收据口径：整体停止 |
| 出卖人在约定期限内代买受人向贷款银行支付部分利息或返还现金 | 贴息促销 | 锁定期限、金额、提前还款或违约是否退回；与一次性降价切开 |
| 无上述任何安排，付款仅为自有资金＋银行按揭 | 普通商品房 | 负触发，转 `一般商品房买卖合同·审查` |

修改句方向（真实延期，买方立场示例）：

`定位（补充协议鉴于／首付款条）｜原文（为缓解买受人资金周转，首付款分期支付）｜建议改为：本协议项下买受人应付首付款人民币【待填】元，其中签约当日实付【待填】元至【预售资金监管账户】，余款【待填】元按附件《还款计划书》于【待填】日前付至同一监管账户。该余款属于尚未支付的购房款，不构成借款。出卖人不得就该余款收取利息、手续费，不得要求买受人向任何第三方贷款人举债，不得向贷款银行或公积金中心陈述该余款已付清，不得出具与实收金额不符的首付款发票或收据。｜理由（C#／I# 性质切开）｜可退让点：余款期数和日期｜不接受时的红线：出现垫资收据或第三方放贷则不签`

用户要把垫资收据改成“银行看不出来”：整体停止，不给可履行句。

### B. 利率与民间借贷上限切开

卖方或关联方资金占用成本，必须与后续商业银行／公积金按揭利率切开。禁止用“按银行利率”“按揭同期”保护私下放贷。

审查动作：

1. 列出合同载明的利率、罚息、手续费、管理费、服务费、咨询费、贴息收回、提前还款违约金。未列全则费用字段 `依据不足`。
2. 折算年化：全部费用计入资金占用成本。数字未给用 `【待填】`，不估算一个“大概没超”。
3. 出借人识别：
   - 自然人、开发企业、未持牌关联公司：民间借贷。出借人请求的利率超过**合同成立时一年期贷款市场报价利率四倍**的部分，人民法院不予支持。
   - 经金融监管部门批准从事贷款业务的机构：不适用民间借贷司法解释；利率按其监管规则，本任务字段停止，运行时核验，不得用四倍口诀代替，也不得用商业银行住房按揭利率代替。
   - 未依法取得放贷资格、以营利为目的向社会不特定对象提供借款：民间借贷合同应认定无效的情形之一。开发企业批量对不特定购房人计息放贷：红旗，告知无效与行政处罚风险，不写成可履行放贷结构。
4. 预先从本金扣除利息：按实际出借数额返还并计算利息；债权凭证载明金额一般认定为本金，预先扣息以实际出借额为本金。
5. 复利、砍头息、费用转本金：超过四倍保护上限的部分不得计入后期本金。

修改句方向：

`定位（借款／分期利息条）｜原文（年利率 24%，另收放款手续费 3%，逾期按日万分之十）｜建议改为：综合资金占用成本（利息、手续费、管理费、服务费及任何名义费用折算的年利率）不得超过本合同成立时中国人民银行授权全国银行间同业拆借中心公布的一年期贷款市场报价利率的四倍；超过部分买受人不负支付义务，已付超过部分抵作本金。禁止预先从本金中扣除利息；若已扣除，以实际出借金额为本金。逾期付款按【待填，不超过上述上限】计违约金，不得叠加上限之外的罚息。本条不适用于买受人后续与商业银行或公积金中心订立的担保贷款，该贷款利率按贷款合同执行。｜理由（L# 民法典第 680 条；民间借贷规定第 25、26 条）｜可退让点：在上限内的具体数字｜不接受时的红线：费用叠加上限仍强制支付则不签`

最强反方：“双方意思自治，手续费不是利息。” → 审查按资金占用成本合并计算；不合并则标必须改。持牌小贷主张适用自身办法：字段停止，核验牌照与费率上限，不自动改用四倍。

### C. 按揭失败

本类型几乎都叠加后续商业或公积金按揭。必须写清失败分岔，且把**本信贷安排被银行或监管否定**单列，不得并入“买方自行承担融资风险”。

| 失败原因 | 修改句必须有的出路 |
| --- | --- |
| 买受人虚假资料、信用或购房资格 | 出卖人可请求解除并赔偿；范围可谈，禁止“已付房款全部没收” |
| 出卖人原因：项目、预售条件、拒绝配合、出具与实收不符的首付凭证 | 买受人可解除，出卖人返还已付款本息并承担违约金 |
| 政策、银行额度、审批标准变化等不可归责双方 | 任何一方可解除；出卖人返还已收购房款本金及其利息或者定金 |
| 贷款银行或监管部门因本协议项下卖方信贷、垫资、贴息或首付来源不符合自有资金要求而拒贷 | 不得单方归责买受人。买受人有权解除并取回已付款；出卖人不得主张补足全款或没收 |

原文“贷款不成买受人须在×日内补足全部房款，否则视为违约并没收定金／已付款”：必须改。最强反方“商业上买方自担融资”：可以谈买方选择改一次性付款并给予合理宽限期，但不能删掉不可归责双方以及因本信贷安排被否定时的解除＋返还。

商品房买卖合同解释（2020 修正）保留了原 2003 年文本第 23 条规则：因一方原因未能订立担保贷款合同并导致买卖合同不能继续履行的，对方可解除并索赔；因不可归责双方事由未能订立并导致不能继续履行的，可解除，出卖人返还购房款本金及其利息或者定金。运行时 `search_law` 核验 2020 修正后条号再写入 `L#`，不得把 2003 年条号写成现行条号。买卖合同被确认无效、撤销或解除且担保贷款合同也被解除的，出卖人应将收受的购房贷款和购房款本金及利息分别返还担保权人和买受人。

修改句方向：

`定位（付款方式／贷款条）｜原文（按揭不成买受人应于 15 日内补足余款，否则出卖人有权解除并没收已付房款）｜建议改为：除本协议延期／信贷款项外，买受人以【商业银行／公积金】担保贷款支付房价款。因买受人提供虚假资料或信用原因未能订立担保贷款合同的，出卖人应先书面催告并给予不少于【待填】日补正或改选付款方式；逾期仍不能履行的，出卖人可解除并请求赔偿实际损失，已付款扣除该损失后返还，不得全部没收。因出卖人原因（包括出具与实收不符的首付款凭证、项目不符合贷款条件、拒绝配合）导致贷款不能的，买受人有权解除，出卖人返还已付款本息并支付违约金【待填】。因贷款政策、银行额度或审批标准变化等不可归责于双方的事由，或因本协议项下卖方信贷、垫资、贴息安排被贷款银行或监管部门否定，未能订立担保贷款合同并导致买卖合同不能继续履行的，任何一方有权解除，出卖人应返还已收购房款本金及其利息或者定金，不得要求买受人限期补足全部房款。｜理由（解释原第 23 条规则；本类型硬闸 C）｜可退让点：买方原因时的宽限期和赔偿范围｜不接受时的红线：贷不成必须补足并没收已付款则不签`

### D. 与普通商品房切开

本技能不是 `一般商品房买卖合同·审查` 的换标题版。

- 无卖方信贷、垫资、贴息、计息缓交：负触发，不填本类型十节。
- 正触发后，五证、预售证范围、面积误差百分之三、先验房、宣传／学区入合同**不是**本任务完成标准。用户同时要审这些：在缺口节写“基础销售条款转 `一般商品房买卖合同·审查`”，不得在本 method 展开邻类节点，不得用五证表充数。
- 不得把本类型信贷补充协议删掉后再按普通商品房放行。
- 不得把存量房户口、解押过户顺序当成主路径。

## 节点 0　签署状态与成果分流

先于类型识别。命中任一项则本任务不填十节实体结论，只交付分流理由和最小交接。

| 已能支持的事实 | 走向 | 不得写成 |
| --- | --- | --- |
| 无可读正文和附件，或只有口头“开发商帮垫首付” | `卖方信贷支持房产销售·起草` | 已经完成审查 |
| 未签，目标是评改已有买卖本约＋信贷／分期／贴息文本 | 进入节点 1 | 已签署或已生效 |
| 残缺模板，用户要按己方条件重写整套首付贷 | 起草；若目标是可履行骗贷结构则整体停止 | 本任务出整稿 |
| 已签，问哪天扣款、哪天网签、还款留痕 | 本套导航的履约步骤 | 签前意见 |
| 银行已拒贷、已催告、已解除、已立案 | `或对应专项领域。` 或专项 | 继续当签前审查 |
| 已网签后要求解除或退房 | 争议或新房退房专项 | 用修改句冒充解除方案 |

缺立场或同时掌握买卖双方及放贷关联方秘密：整体停止策略输出，澄清代表哪一方。缺文本仍要“给个能不能签”：不启动实体审查。

## 节点 1　类型识别：只留卖方信贷支持

用标题、核心给付、资金提供方和用户陈述定性，不用标题单独定性。实务标题多为《商品房买卖合同补充协议》《分期付款协议》《借款协议》，几乎不会写成“卖方信贷合同”。

| 信号 | 归入 | 排除 |
| --- | --- | --- |
| 房屋买卖本约＋出卖人或关联方／指定第三方提供信贷、垫资、计息缓交或贴息 | 本类型 | 普通商品房、纯借款 |
| 开发企业售新房，付款仅为自有资金＋银行按揭，无卖方侧融资 | `一般商品房买卖合同·审查` | 本类型 |
| 业主出售已办证存量房 | `二手房买卖·审查` | 本类型五证或首付贷口径 |
| 买卖加固定价回购、过户为担保 | `让与担保式房产买卖·审查` | 改成真实买卖外观 |
| 以房抵工程款或抵债 | `以房抵债工抵房·审查` | 本类型 |
| 主给付是选择权、转售权 | `附选择权转售权房产销售·审查` | 本类型 |
| 只有民间借款、无房屋所有权转移 | 借款／金融审查，不在本任务 | 假装本类型 |

名实不符（封面写商品房买卖、附件是关联小贷首付贷）按核心资金关系归入本类型，标题冲突写入 `C#`。两可时禁止同时加载商品房双文件。

加载协议：只打开 `references/基本面.md` 与 `references/框架.md`。文件不可用：记 `G#`，用本方法节点 2–8 继续，不编造利率、牌照或地方首付比例。

规避限购、借名购房、伪造首付已付：只告知，不写可履行结构。用户坚持改到能过银行审查：整体停止。

## 节点 2　主从结构与性质切开（落实硬闸 A）

1. 建文件清单：买卖本约、补充协议、借款协议、分期付款协议、贴息补偿协议、还款计划书、自动转账授权、代垫利息明细、收据／发票样本、风险自担声明。缺件标 `G#`，不补造。
2. 识别贷款主体：出卖人本体、关联小贷／保理、指定金融机构、高管或股东个人。关联关系未披露不得写成“独立第三方金融机构”。
3. 按硬闸 A 表定性。鉴于条款写“资金周转需要”而材料显示开发商促销垫资：写入虚假陈述风险，不把鉴于当事实。
4. “首付分期”与“首付贷”必须切开：前者是价款支付时间；后者是借贷。二者都可能被监管评价为规避首付自有资金要求，但法律结构不同，修改句不同。不得把借贷改写成分期外观以规避审查。
5. 贴息与降价切开：贴息是约定期限内的持续义务，须写起止日、是否可撤销、提前还款或违约是否退回；降价是一次性处分总价。语言含糊：必须改。

不足：性质字段停止，列出待补，不默认“只是分期、没有风险”。

## 节点 3　主体、账户、凭证与资金路径

1. 主体表：买卖签约名、土地使用权人／预售证主体、信贷出借人名、收款账户名、发票名、授权签字人、买受人共有方式。名称不一致不自动合并。
2. 出借人若为小贷、保理或“咨询公司”：核验是否持牌、是否有权对自然人发放购房首付款贷款。材料未提则持牌字段 `依据不足`，不得写“合法金融机构”。
3. 购房款收款账户：商品房预售所得应进入监管账户。信贷本金若直接打入买受人再转回出卖人、或出卖人账内空转后出具已收齐首付证明：红旗。买方立场建议不签；协助设计体外循环：整体停止。
4. 发票与收据：实收金额必须与凭证一致。先票后款或未收齐即开全额首付发票：点名金融诈骗与银行拒贷风险。修改句要求：凭证金额＝监管账户实收；禁止预开全额首付证明。
5. 二次抵押或预告登记限制：出卖人为保障出借款，限制买受人再抵押或处分的，须写明范围、期限、涂销条件；不得写成买受人放弃一切处分权且不影响出卖人继续收款。
6. 口头“财务说可以先开收据”不得写成已授权。

## 节点 4　对价、利率上限、定金（落实硬闸 B）

1. 总房价、首付款法定或政策比例、已付现金、卖方信贷／延期金额、拟按揭金额分列。政策首付比例未核验：字段停止，不编造当地成数。
2. 执行硬闸 B 的费用合并与四倍切开。无核验引文不得把四倍写成已核验法律结论；修改句仍按该结构起草并标“待核验”。
3. 定金：必须使用“定金”二字才讨论罚则。“订金、保证金、诚意金”无定金性质约定的，不得写成定金。数额不得超过主合同标的额百分之二十，超过部分不产生定金效力。修改句把超额改为预付款并写明不适用罚则。
4. 禁止编造房价、利率、LPR 数值。LPR 以合同成立时公布值为准，意见中写 `【待填合同成立时一年期 LPR】`。

## 节点 5　按揭失败、交叉违约与退款（落实硬闸 C）

1. 执行硬闸 C 的四类分岔。缺分岔视为必须改。
2. 交叉违约：借款逾期即视为买卖根本违约并单方解除、没收已付款：必须改。买方立场：借款逾期先催告，达到约定日且经催告仍不履行的，方可解除买卖；已付款扣除实际损失后返还。出卖人立场：可保留解除权，但没收全部已付款标红线。
3. 加速到期：任何一期逾期则全部本息立即到期。若结构被定性为价款分期，还须对照分期付款规则：未支付到期价款达到全部价款五分之一，经催告后在合理期限内仍未支付的，出卖人可以请求支付全部价款或者解除；约定损害买受人利益的，买受人可主张该约定无效。分期指总价款在一定期限内至少分三次支付。借贷结构不适用该条充作放贷合法化。
4. 退款路径：解除后已付款优先偿还关联贷款人、余款才退买受人：买方必须改。修改句：出卖人与贷款主体就内部结算自行处理，对外应在【待填】日内将买受人已付的购房款和信贷款项全部返还买受人指定账户；不得以内部债务抵销对抗买受人。
5. 效力独立性：“即便借款协议无效，买卖合同仍须继续履行、买受人应自行筹措首付”：买方必须改。修改句：若信贷／垫资安排被认定无效、被撤销，或被贷款银行、监管部门否定，买受人有权解除买卖合同并取回已付款，不承担违约责任。出卖人立场可谈继续履行的宽限期，但不得剥夺因政策或无效导致的退出。
6. 风险自担声明：买受人签署“知悉分期并非国家法定贷款、后果自负”不消除出卖人出具虚假凭证或违规放贷的责任。不得写成已免责。

## 节点 6　程序、生效、管辖

把批准、登记、网签、借款发放写成**生效条件或履行期限**，不写成已经完成。

| 文本写法 | 本任务动作 |
| --- | --- |
| 借款协议与买卖合同互为生效前提，但未写谁先签、未成就后果 | 补顺序、期限、未成就时互不生效且已付款返还 |
| 第三方借款未签，买卖已要求付定金 | 补：借款未签成立前买受人有权中止并取回定金／预付款 |
| 用户要求倒签借款日或补假放款流水 | 整体停止 |
| 买卖约定房屋所在地法院，借款约定贷款人所在地法院 | 必须改：争取同一法院或同一仲裁机构，避免平行诉讼。不动产专属管辖限于物权确认、分割、相邻等，普通房屋买卖合同纠纷不当然专属；政策性房屋买卖另核。不得把“房屋所在地专属管辖”写成必然规则 |
| 或裁或诉、机构不明 | 改成单一机构或单一法院连结点 |

网签、预告登记的责任主体、期限、未完成后果应写清。撤销网签作为借款违约救济：须有催告、宽限期和已付款返还，不得写成出卖人可任意撤网签并扣款。

## 节点 7　格式条款、强制规范、停止改写违法结构

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 7.1 格式条款

开发企业重复使用的补充协议、借款、贴息、风险自担声明，订立时未与对方协商的，是格式条款。交叉违约、加速到期、全部没收、效力独立、管辖分离、放弃因政策退房，须有足以引起注意的标识并按要求说明。小字、夹在附件、仅网络勾选：不得写成已尽提示或说明义务。提供方对提示说明承担举证责任。

第 497 条无效情形、第 498 条不利解释：只在核验后作为修改理由，不代替修改句。

### 7.2 强制规范与公序良俗

违反法律、行政法规强制性规定不一律无效。禁止用已失效“效力性／管理性”口诀代替合同编通则解释第 16 条。违背公序良俗可认定无效；认定时综合考虑交易目的、监管强度、频次和社会后果，不得把一切延期支付写成必然无效。

与本类型相关、不得改写成可履行结构的红旗：

- 未取得放贷资格、面向不特定购房人营利性放贷；
- 套取金融机构贷款转贷；
- 以虚假意思表示掩盖首付未付、出具与实收不符的凭证向银行申报按揭；
- 规避限购或信贷政策的借名、假离婚、假流水。

虚假意思表示实施的行为无效；隐藏行为按第 153 条或第 502 条处理。就同一交易多份合同，虚假的无效。

贷款通则仍规定企业之间不得违反国家规定办理借贷或者变相借贷融资业务；开发企业直接对购房人计息放贷叠加监管政策。本任务告知风险，不保证必然无效，也不包装成合法金融产品。

### 7.3 停笔

规避限购、出具与实收不符的首付凭证骗取按揭、未持牌面向不特定购房人放贷：只出告知，不写假流水、假收据、可履行资金路径。用户坚持“改到银行看不出来”或“改到能放贷”：整体停止。

合规改道只点名，不在本任务起草：真实商业折扣（降总价）、不计息的延期支付且凭证与实收一致、买受人通过持牌银行或公积金的合法贷款。点名不等于本任务出整套替代文本。

每条修改句固定格式：

`定位（条／款／附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

- `红线`：不改则建议不签或整体停止（虚假全额首付凭证、无持牌面向不特定人放贷、贷不成没收全部已付款、协助规避监管）

- `可接受可优化`：仍要给句子，不得只标绿

用户不可接受事项优先写成红线。生存级金额且用户拒绝升级：停止“可以签署”建议。

硬闸 A–D 在风险表或修改句中必须逐项点名。原文沉默也要处理，不得因没写“信贷”二字而省略。
