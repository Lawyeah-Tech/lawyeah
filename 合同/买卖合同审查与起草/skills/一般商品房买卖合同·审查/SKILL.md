# 一般商品房买卖合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构，不证明本约条款已被接受。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把已被 2020 年修正删除的商品房买卖合同司法解释原第 14 条当作面积误差现行依据。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **买卖合同 / 一般商品房买卖合同** 的待签文本（预售或现售），输出：预售/现售与五证核验、风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他合同类型。场景分层为 **P0**。

`depends-on` 为空。不要求先跑导航。

不交付：他类型起草、履约交底、争议文书、有效性或学区/过户保证。

## 工作边界

正触发：已有可读待签文本要评改；尚未签署，尚未成争，出卖人是房地产开发企业，标的是该企业开发、向社会销售的商品房。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 文本是业主出售已取得产权的存量房 / 二手房 → 转 `二手房买卖·审查`，若该原子不可用则转 本套导航的类型切开步骤 重新定性；
- 文本明显是经适房、共有产权、工抵房、产权式酒店、定制销售、包销、让与担保式买卖或其他合同类型 → 转本套导航的类型切开步骤或对应场景原子；
- 无文本、本类型条件已谈妥、要出己方稿 → `一般商品房买卖合同·起草`；
- 已签只问交房、办证、付款留痕 → 本套导航的履约步骤；
- 已成争（催告、解除、索赔、诉讼仲裁），**包括已经网签后要求解除或退房** → `或对应专项领域。` 或新房退房/质量专项，不在本任务做解除评估。

挂靠、违法分包、规避限购、无证预售包装成可履行交易：只出告知，不改写成可履行结构。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成：

1. **预售 / 现售切开**。在建=预售，必须核商品房预售许可证及证载范围是否覆盖拟购房源。已竣工验收=现售，核销售管理办法第 7 条七项条件，不得用预售证替代竣工验收。
2. **五证表**。国有土地使用证/不动产证、建设用地规划许可证、建设工程规划许可证、施工许可证、预售许可证（预售）或现售备案证明。证载主体须与签约出卖人一致。缺证或范围不含该房号：红线。
3. **面积 3% 规则写全**。禁止原文或修改句只写“按规定处理”。按面积计价必须写：误差比绝对值≤3% 据实结算；>3% 买受人有权退房；不退房时超出 3% 部分的价款负担（变大出卖人承担，变小双倍返还）及误差比公式。现行依据是《商品房销售管理办法》第 20 条，不是已删除的 2003 解释第 14 条。
4. **监管账户**。预售购房款收款账户必须是主管部门监管的预售资金专户。进开发商一般户、营销户或个人卡：红线。
5. **贷款失败出路**。按揭结构必须区分“因一方原因”与“不可归责双方”，后者买受人可解除并取回已付款本息或定金，不得写成必须自行补足否则违约。
6. **抵押披露**。土地或在建工程抵押未披露、无抵押权人同意销售证明：不得写“无权利负担”，升红线或字段停止。
7. **先验房**。交付程序必须先验房、书面记录异议后再签收；禁止“领钥匙即视为验收合格”。
8. **宣传未入合同**。学区、学位、绿化、会所、地铁距离等具体确定且影响订约或房价的允诺只在广告里：红旗，必须改写入附件或补充协议。

必须有修改句。禁止只打红黄绿。每个风险回链文本位置。

## 判断节点

以 [审查方法](references/method.md) 为准。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。交付按 [输出合同](references/output-contract.md)。边界见 [路由](references/routing.md)。

入口（细节以 method 为准）：

0. 签署状态分流：已网签要解除 → 争议；无文本且本类型条件已谈妥 → `一般商品房买卖合同·起草`；已签履约 → 本套导航履约步骤。
1. 类型切开：开发企业售新房才留本任务；二手房转 `二手房买卖·审查`。
2. 预售/现售 + 五证 + 预售证范围。
3. 主体、限购、授权、抵押权人、监管银行。
4. 房号附图、面积 3% 全规则、土地用途年限、抵押查封。
5. 网签备案、预告登记、先验房、规划变更 10 日/15 日。
6. 监管账户、贷款失败分岔、定金不超过 20%。
7. 格式条款提示说明；示范文本不免审；宣传/学区入合同。
8. 按框架六步出修改句。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；用户坚持伪造倒签、补假预售证、规避限购、把无证预售或非监管户收款改成可履行结构、保证有效或保证学区。
- `字段停止`：五证、预售证范围、监管账户、抵押状态、限购资格、地方监管细则未核验。
- `目标停止`：主目标已变为从零起草（转 `一般商品房买卖合同·起草`）、他类型起草、履约交底或争议/解除文书。

生存级首付或个人无限连带且用户拒绝升级：停止“可以签署”建议。
