# 动产买卖合同·起草

## 任务目标

在单一立场下，只起草 **动产买卖合同**，并按本类型硬闸自审。交付可编辑草稿、未决项、自审风险表和自审后修改句。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。`depends-on` 为空。不要求先跑导航。

不交付：他类审查、从零起草、履约交底、争议文书、有效性或货物必然合格／所有权必然对抗第三人的保证。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿；尚未签署，尚未成争，核心给付是出卖人转移**动产**（含一般货物与机动车、船舶、航空器等特殊动产）所有权、买受人支付价款。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 文本是商品房预售／开发商现售（预售许可证、五证、未建成房屋、出卖人为房地产开发企业销售项目）→ `一般商品房买卖合同·审查`；
- 文本是二手房／存量房买卖（已建成房屋所有权、不动产单元号、网签过户、户口）→ `二手房买卖·审查`；
- 经适房、共有产权、让与担保式房产买卖、以房抵债 → 对应场景原子；
- 主给付是区域经销、独家转售指标或渠道管理费 → `经销买卖合同·审查`；
- 按定作人要求制作、重劳务过程而非通用物交付 → 承揽场景原子或 本套导航的类型切开步骤；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问发货、验收、付款留痕 → 本套导航的履约步骤；
- 已成争（质量异议逾期、催告、解除、索赔、诉讼仲裁）→ `或对应专项领域。` 或对应专项领域。

禁止流通物交易、通谋虚假意思、倒签规避监管：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；买或卖单一立场；相对方；正文、附件、订单、技术规格版本；货物名称／规格／数量；不可接受事项；法域与拟签时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价格、数量、日期用 `【待填】`，不编造。

## 本类型硬闸

审查过程必须逐项点名，不得用商品房或存量房清单代替：

1. **标的特定化**：名称、规格型号、数量及计量单位须确定到可履行。只有“货物一批”“详见双方另行确认”而无附件清单，标必须改。
2. **检验与质量异议期间**：外观检验与隐蔽瑕疵／性能验收分列；异议通知期间、质量保证期与二年补充期间不得混写。签收送货单不当然等于质量合格。
3. **风险转移与交付**：交付地点、方式（送货／自提／代办托运）与风险转移时点写清；未交单证原则上不影响风险转移，但质量根本不符可拒绝受领且风险不转。
4. **单证**：除提取货物的单证外，须列合格证、说明书、保修单、发票、装箱单等随附资料；缺单证的付款抗辩和补交期限要有句子。
5. **所有权保留（如有）**：付清前所有权归属、登记对抗、取回条件、已付价款百分之七十五以上不得取回、回赎与清算必须写清。不得把所有权保留扩到不动产。文本未约定则不编造该结构。
6. **定金不超过主合同标的额百分之二十**：须核验；“订金、保证金”无定金性质不得写成罚则。无核验引文不得把 20% 写成已核验结论，修改句仍应压到不超过 20%。


## 起草模式

本原子只起草本类型。有完整待签文本要评改时，转 `动产买卖合同·审查`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。同一套本类型硬闸，在落稿时写成正文必写、附件必附或禁止出现，不得审完再补。

**起草必写：** 名称、规格型号、数量及计量单位确定到可履行；外观检验与隐蔽瑕疵/性能验收分列，异议通知期间、质量保证期与二年补充期间不得混写；交付地点、方式（送货/自提/代办托运）与风险转移时点，未交单证原则上不影响风险转移，但质量根本不符可拒绝受领且风险不转；除提取货物的单证外，列合格证、说明书、保修单、发票、装箱单等随附资料，缺单证的付款抗辩和补交期限；如有所有权保留则写清付清前所有权归属、登记对抗、取回条件、已付价款百分之七十五以上不得取回、回赎与清算；定金不超过主合同标的额百分之二十。

**附件必附：** 货物清单；技术规格书（如有）。

**禁止出现：** 只有“货物一批”“详见双方另行确认”而无附件清单；签收送货单等于质量合格；把所有权保留扩到不动产；文本未约定却编造所有权保留；“订金、保证金”无定金性质写成罚则；商品房预售许可、五证、面积误差百分之三、户口迁出、网签过户等不动产规则。

出稿后必须用本类型硬闸与 [审查方法](references/method.md) 自审。未过不得宣称起草完成。交付草稿、未决项、自审风险表、自审后修改句。

他类型出稿、已签履约、已成争：仍负触发。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构，不证明本约条款已被接受。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《物权法》及其解释当作现行规则。不得把商品房预售许可、五证、面积误差百分之三、户口迁出、网签过户等不动产销售规则硬套本类型。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验买卖定义与条款、交付与所有权转移、单证、检验异议、风险转移、所有权保留、定金上限、格式条款、禁止或限制流通；`search_practiced` 补审查反例；`search_template` 只借修改句结构。不虚构案件系统。

`search_law` 对法律结论为 required 级节点：不可用时不拒绝执行，只停止法律结论字段。返回已失效《合同法》《物权法》及其解释时记为噪声，不得写入 `L#`。返回商品房预售或存量房过户专属规则时，不得当作本类型默认法。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、把禁止流通物或通谋虚假改成可履行买卖、保证货物必然合格或所有权保留必然对抗第三人。
- `字段停止`：标的无法特定化；特殊动产登记或许可未核验；定金比例、检验期间法定下限未核验。
- `目标停止`：主目标已变为他类型起草、履约交底或争议文书。

生存级预付款或个人无限连带且用户拒绝升级：停止“可以签署”建议。
