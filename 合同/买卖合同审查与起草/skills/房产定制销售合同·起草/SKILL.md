# 房产定制销售合同·起草

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构，不证明本约条款已被接受。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》及其解释当作现行规则。不得把一般商品房预售清单（仅五证、面积误差百分之三、广告视为要约、逾期办证九十日）代替本类型的定制规格、工期和面积闸门。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只起草 **房产定制销售合同**，并按本类型硬闸自审。交付可编辑草稿、未决项、自审风险表和自审后修改句。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。`depends-on` 为空。不要求先跑导航。

本类型是 **买卖 + 承揽** 复合交易：出卖人既要转移房屋所有权，又要按买受人的前置性技术要求完成定向开发或结构／机电定制。禁止只当普通商品房预售审，也禁止改写成施工总承包或纯承揽。

不交付：他类审查、从零起草、履约交底、争议文书、有效性或规划必然获批保证。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿；尚未签署，尚未成争，核心给付是按特定买受人的技术任务书／定制设计方案定向开发或改造房屋并转移所有权换价款。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 标准商品房预售或开发商现售，正文是示范文本或普通网签稿，只有菜单式精装／选装包、无结构荷载／机电容量／户型改造等前置定制 → `一般商品房买卖合同·审查`；
- 整栋打包转让、追求外墙屋顶冠名等整栋控制权，无个性化技术任务书 → `房屋整售合同·审查`；
- 已建成并已办证的存量房、出卖人不是定向开发方 → `二手房买卖·审查`；
- 主给付是施工、总包、监理，不转移房屋所有权 → 工程类场景或引擎重新定性；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已成争（催告、解除、索赔、诉讼仲裁）或已交付仍要改待签条款 → 合同争议或对应专项领域。

出现预售许可证、五证或期房，**不因此负触发**。定向开发的期房定制仍留本技能；预售许可只作为本类型程序闸，不改去加载 `一般商品房买卖合同·审查` 双文件。

挂靠、违法分包、规避限购或伪造规划批准：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；买或卖（或定制需求方／开发方）单一立场；相对方；正文、技术任务书、图纸、封样、规划报批材料版本；坐落与规划用途；不可接受事项（核心荷载、电力、品牌、最迟交付日）；法域与拟签时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价格、工期、面积、荷载、电容量用 `【待填】`，不编造。

## 本类型硬闸

审查过程必须逐项点名，不得用一般商品房预售清单代替：

1. **定制规格**：技术任务书或 TRD、深化图纸、设备材料封样必须作为合同附件；荷载用标准值／设计值（kN/㎡），电力用 kVA，品牌用指定品牌及唯一型号；禁止“参考品牌、同等档次、高档、国内领先”；变更只能走书面补充协议。
2. **工期**：拆开设计确认、变更报建、结构封顶、竣工验收、定制验收、交付；买受人迟延确认可顺延，但不得把逾期不确认写成同意降配；不得编造节点日期。
3. **面积**：规划面积、合同约定面积、实测产权面积、定制引起的面积增减四分开；禁止用面积误差百分之三公式吞掉定制改造或未批规划变更；花园、地下室、夹层单列。
4. **与商品房预售切开**：无前置定制的标准预售／现售负触发到 `一般商品房买卖合同·审查`；本类型即使有预售许可也不加载一般商品房双文件；期房定向销售仍核验预售许可，但不把五证清单当成全部审查。


## 起草模式

本原子只起草本类型。有完整待签文本要评改时，转 `房产定制销售合同·审查`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。同一套本类型硬闸，在落稿时写成正文必写、附件必附或禁止出现，不得审完再补。

**起草必写：** 技术任务书或 TRD、深化图纸、设备材料封样作为合同组成部分，荷载写标准值/设计值（kN/㎡），电力写 kVA，品牌写指定品牌及唯一型号；变更只能走书面补充协议；工期拆开设计确认、变更报建、结构封顶、竣工验收、定制验收、交付，买受人迟延确认可顺延；规划面积、合同约定面积、实测产权面积、定制引起的面积增减四分开，花园、地下室、夹层单列；期房定向销售仍核验预售许可作为程序闸，但不把五证清单当成全部审查。

**附件必附：** 定制技术指标需求书（TRD）；需求方签认的设计方案图纸；材料设备选型封样清单。

**禁止出现：** “参考品牌、同等档次、高档、国内领先”；把逾期不确认写成同意降配；用面积误差百分之三公式吞掉定制改造或未批规划变更；无前置定制的标准预售/现售仍按定制落稿；编造节点日期。

出稿后必须用本类型硬闸与 [审查方法](references/method.md) 自审。未过不得宣称起草完成。交付草稿、未决项、自审风险表、自审后修改句。

他类型出稿、已签履约、已成争：仍负触发。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验买卖与承揽定性、预售许可对期房的效力、规划变更、竣工验收与交付、格式条款、定金上限、定作人中途变更／解除的赔偿边界；`search_practiced` 补审查反例；`search_template` 只借修改句结构。不虚构案件系统。

`search_law` 对法律结论为 required 级节点：不可用时不拒绝执行，只停止法律结论字段。返回已失效《合同法》及其解释时记为噪声，不得写入 `L#`。返回一般商品房预售专属规则时，先判断本约是否真有前置定制，不得整份改走 `一般商品房买卖合同·审查` 方法。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签、补假规划批准、挂靠／违法分包包装、规避限购、保证有效或规划必然获批。
- `字段停止`：技术任务书、规划报批路径、预售许可（期房）、关键面积或工期节点未核验。
- `目标停止`：主目标已变为他类型起草、履约交底或争议文书。

生存级首付款或个人无限连带且用户拒绝升级：停止“可以签署”建议。
