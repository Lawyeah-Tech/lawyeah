# 产权式酒店买卖合同·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《物权法》《担保法》及其解释当作现行规则。不得把商品房五证清单、面积误差百分之三、学区或先验房自用当作本类型默认法。不得把租赁期限二十年当作酒店委托经营的法定上限。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **买卖合同 / 产权式酒店买卖合同** 的待签成套文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查产权式酒店买卖合同（买卖合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性或固定回报兑付保证、把普通商品房或商铺租赁改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **产权过户 vs 经营权上交**：合同必须分列两件事：不动产权登记到买受人名下；房屋交付日即把占有使用权交给经营方，买受人不实际入住。禁止只过户不交经营，或只交经营不过户。买卖合同与《委托经营管理协议》为不可分割整体，同步签署、同步生效。修改句须写同步交割和“不得自住、不得另行委托”的反说。
2. **固定 / 保底回报**：必须写清是固定租金、利润分成还是「保底+分成」；可分配收入定义、扣除项、支付日、统一收银账户须落句。删除「稳赚 / 保本 / 年化固定回报」。保底如保留，只能写成经营方的合同给付义务，不得写成投资保本；数字用 `【待填】`。
3. **售后包租**：开发商以承租或代为出租该商品房并给付固定租金的方式销售**未竣工**房屋，或返本销售、约定期满强制溢价回购：红线停笔，不改成可履行结构。已竣工项目仍须切开开发商包租承诺与第三方经营，并告知非法集资四要件；本任务不定罪。
4. **与产权式商铺租赁切开**：核心给付是客房所有权转移换价款。用户只交租赁/委托经营协议、无买卖过户主给付 → `核心给付是客房所有权转移换价款。用户只交租赁委托经营协议无买卖过户主给付→`。不得用民法典第 705 条二十年租期替代本类型经营期限。
5. **与商品房个卖切开**：可独立居住、无强制统一经营的一般商品房预售或现售 → `一般商品房买卖合同·审查`。酒店式公寓可自住、合同松散 → 不按本类型硬套。不得删掉强制返租后按商品房审，也不得把五证、面积百分之三、学区做成替代本硬闸的主路径。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签产权式酒店买卖正文，通常伴随委托经营协议，尚未签署，尚未成争，核心给付是酒店客房单元所有权转移换价款，且买受人须将占有使用权强制纳入统一经营，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 普通商品房预售或现售，可独立居住，无强制统一经营 → `一般商品房买卖合同·审查`；
- 酒店式公寓，合同允许自住或自行出租 → `一般商品房买卖合同·审查` 或 本套导航的类型切开步骤；
- 主给付是商铺统一租赁/委托经营，投资者已是或将是业主但本约不转移客房所有权 → `核心给付是客房所有权转移换价款。用户只交租赁委托经营协议无买卖过户主给付→`；
- 普通存量商品房二手买卖，出卖人为个人 → `二手房买卖·审查`；
- 名为买卖实为担保回购 → `让与担保式房产买卖·审查`；
- 以房抵债、工抵房 → `以房抵债工抵房·审查`；
- 主给付是居间报酬或带看成交 → `存量房买卖或租赁居间带看二手房→`；
- 无文本、本类型条件已谈妥、要出己方稿 → `产权式酒店买卖合同·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁，或固定回报停付要争议策略 → `或对应专项领域。` 或对应专项领域。

未竣工售后包租、返本销售、强制溢价回购、公开承诺保本吸收不特定对象资金、规避限购：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（买受人侧、出卖人侧或经营方侧择一）；相对方；买卖合同与委托经营协议及装修清单、管理公约、收益模型版本；标的是否酒店客房规划用途；是否竣工；收益模式；开发商是否承诺包租或强制回购；经营方是否作为当事人签章；过户与经营权交割是否同步；不可接受事项；法域、项目所在地与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价款、回报率、经营年限、回购价用 `【待填】`，不编造。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `产权式酒店买卖合同·起草`；已签履约 → 本套导航履约步骤；已成争或回报停付争议策略 → 合同争议。未签且目标是评改已有产权式酒店买卖成套文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。可自住商品房、酒店式公寓、仅租赁/委托经营、担保回购、抵债、中介负触发。

### 2. 产权过户与经营权上交

过户义务、登记主体、交付即交经营、不得自住的反说、两份合同不可分割。

### 3. 三方主体与经营方

出卖人、买受人、经营方分列。缺丙方签章：字段停止。关联关系与出卖人连带须落句。

### 4. 收益模式与售后包租

固定/保底/分成切开；未竣工包租或返本/强制回购停笔。

### 5. 转让限制与优先回购

优先回购须有通知和行权期限；受让人必须承继委托经营；禁止无限期挂起；强制溢价回购按融资红旗处理。

### 6. 格式条款与强制规范

强制返租、放弃自住、收益黑箱、管辖等异常条款须提示说明。无核验引文则法律结论字段停止。

### 7. 违约、解除与争议

擅自收回自用、经营方停付收益、经营方撤场须有可执行后果。不选定唯一法院充作意见。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效或保证兑付、把未竣工售后包租/返本/强制溢价回购/公开保本集资或规避限购改成可履行结构。
- `字段停止`：法域、竣工状态、预售许可、经营方资质、地方监管账户规则、收益公式未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。

生存级房款或个人无限连带且用户拒绝升级：停止“可以签署”建议。
