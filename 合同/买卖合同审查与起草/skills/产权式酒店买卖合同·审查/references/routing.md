# 边界与路由

本技能只审查 **买卖合同 / 产权式酒店买卖合同** 的待签成套文本。中文展示名是「审查产权式酒店买卖合同（买卖合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 普通商品房预售或现售，可独立居住，无强制统一经营 | `一般商品房买卖合同·审查`。不得删掉商品房条款后继续当产权式酒店审 |
| 酒店式公寓，合同允许自住或自行出租，无强制经营权上交 | `一般商品房买卖合同·审查` 或引擎。不得按强制返租改完 |
| 主给付是商铺统一租赁、委托经营或整场招租，本约不转移客房所有权 | `核心给付是客房所有权转移换价款。用户只交租赁委托经营协议无买卖过户主给付→`。不得用租赁二十年上限回写本类型 |
| 普通存量商品房二手买卖，出卖人为个人 | `二手房买卖·审查` |
| 名为买卖实为担保回购 | `让与担保式房产买卖·审查` |
| 以房抵债、工抵房 | `以房抵债工抵房·审查` |
| 主给付为居间、带看、独家委托 | `存量房买卖或租赁居间带看二手房→` |
| 无文本、本类型条件已谈妥，要出己方稿 | `产权式酒店买卖合同·起草`；不得在本审查原子出稿 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争，或固定回报停付、经营方撤场要争议策略 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

封面写商品房、正文强制将客房纳入酒店统一经营且买受人不得自住：按核心给付留在本技能，标题必须改，不转 `一般商品房买卖合同·审查`。

买卖正文里夹带一小段商铺招租或中介佣金：佣金专条可交接 `存量房买卖或租赁居间带看二手房→`；过户、经营权上交、收益模式、售后包租继续审。用户坚持本技能把普通商品房或商铺租赁整案改完：`目标停止`。

专业版未收录的其他 P1 场景不会安装本原子。若用户拿他类 P1 文本来找本原子：输出 `unavailable` 或按上表负触发，不得用邻类硬套。
