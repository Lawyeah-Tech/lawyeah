# 审查方法（锁定 买卖合同 / 产权式酒店买卖合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。

本文件是可执行判断节点，不是栏目说明书。每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、必然过户、必然兑付固定回报、对方必然接受或唯一必得金额。

`search_law` 返回已失效《合同法》《物权法》《担保法》及其解释、合同法解释（二）第 14 条、或商品房买卖合同司法解释（2003）已删除条文时记为噪声，不得写入 `L#`。不得把面积误差百分之三、学区或租赁二十年当作本类型默认法。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突。

示范文本只参考结构。民法典允许参照示范文本，不证明本约条款已被接受；依据示范文本拟定且符合格式条款定义的，仍按格式条款审查。

## 节点 1　类型识别：只留产权式酒店买卖

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。两可时禁止同时加载商品房或商铺租赁双文件。

| 信号 | 归入 | 排除 |
| --- | --- | --- |
| 开发企业出售酒店客房单元并转移所有权，买受人支付价款，且必须把占有使用权交给统一经营，不得独立居住 | 本类型 | 一般商品房、普通租赁 |
| 可独立居住的商品房预售或现售，无强制统一经营 | `一般商品房买卖合同·审查` | 不得用本技能的返租/经营权闸硬套 |
| 酒店式公寓：规划或合同允许自住或自行出租，统一经营为可选项 | `一般商品房买卖合同·审查` 或引擎 | 不得按强制返租改完 |
| 主文件是商铺统一租赁/委托经营/整场招租，本约不转移客房所有权 | `核心给付是客房所有权转移换价款。用户只交租赁委托经营协议无买卖过户主给付→` | 不得用租赁二十年上限回写经营期限 |
| 业主出售已取得产权的存量客房，无开发企业销售关系 | `二手房买卖·审查` 或引擎 | 本类型的开发商包租闸 |
| 买卖到期强制溢价回购、过户实为担保 | `让与担保式房产买卖·审查`，或本节点 4.3 停笔 | 改成普通买卖外观 |
| 以房抵债、工抵房 | `以房抵债工抵房·审查` | 本类型 |
| 主给付为居间报酬 | `存量房买卖或租赁居间带看二手房→` | 本类型 |

封面写《商品房买卖合同》、正文强制返租且限制自住：按核心给付留本任务，标题必须改为「商品房买卖合同（产权式酒店类）」，不转 `一般商品房买卖合同·审查`。

切开闸修改句（命中负触发则只分流，不填本句；命中名实不符但核心给付仍是本类型时必出）：

- 对 `一般商品房买卖合同·审查`：`定位（标题/鉴于）｜原文写商品房且可自住｜建议改为：本合同为商品房买卖合同（产权式酒店类）。标的为酒店客房单元，不具备独立居住功能，买受人知悉并同意同步签署《委托经营管理协议》、交付即交经营。删除可独立居住、学区、先验房自用等表述。｜不接受则负触发商品房原子，不得两套知识并行`
- 对 `核心给付是客房所有权转移换价款。用户只交租赁委托经营协议无买卖过户主给付→`：`定位（期限条）｜原文套用租赁二十年或把本约写成统一招租｜建议改为：本约核心给付为客房所有权转移，经营期限按委托经营约定【待填】年，到期协商续聘，不适用民法典第七百零五条租赁期限上限。若当事人真实交易仅为商铺/客房出租而不转移所有权，停止本任务，转 核心给付是客房所有权转移换价款。用户只交租赁委托经营协议无买卖过户主给付→。`

加载协议：只打开 `references/基本面.md` 与 `references/框架.md`。禁止为对照再开第二类。文件不可用（空、与类型明显无关）：记 `G#`，用本方法节点 2–8 继续，不编造证号、回报率或回购溢价。

## 节点 2　产权过户 vs 经营权上交（硬闸 1）

本节点是本类型第一道实体闸。未切开过户与经营权，不得进入收益和包租审查。

### 2.1 必须分列的两件事

| 事项 | 文本必须写清 | 不得写成 |
| --- | --- | --- |
| 产权过户 | 出卖人在【待填】日前协助将本单元登记至买受人名下；登记簿记载时发生物权效力 | 交付钥匙、交经营或开始分红 = 已经取得所有权 |
| 经营权上交 | 房屋交付之日视为买受人将本单元占有、使用权交付经营方统一经营的起始日；买受人不实际入住 | 过户后买受人可自行占有、自住或另找经营者 |
| 同步 | 过户登记与经营权交割同步办理；任何一方不得只履行其中一项 | “先经营后过户，证办不办不影响分红”且无期限、无解除权 |

效力口径（须 `search_law` 后写入 `L#`）：未办理物权登记不影响买卖合同效力，但未经登记不发生物权效力。出卖人应交付并转移所有权。修改句不得用“经营权交割完毕视为过户完成”代替登记。

### 2.2 成套文本

买卖合同与《委托经营管理协议》必须写成不可分割的整体，同步签署、同步生效。一份不成立、无效或被解除的，另一份随之失效或须同时结算。缺委托经营协议：字段停止，列出待补，不写成“买卖合同可单独签”。

### 2.3 修改句（本闸必出）

`定位（买卖合同交付/权属条＋委托经营协议第×条）｜原文｜建议改为：买受人于【待填】日前取得本单元不动产权证书。房屋交付之日视为买受人将本单元占有、使用权交付丙方统一经营的起始日，买受人不实际入住。未经甲乙丙三方书面同意，买受人不得自行占有、自住或另行委托他人经营。出卖人完成过户登记与买受人完成经营权交割应同步办理；仅办理过户而不交经营，或仅交经营而不过户的，守约方有权中止对待给付或解除两份合同并请求返还已付款。两份合同为不可分割整体，同步签署、同步生效。｜理由（回链 C# / L#）｜可退让点：经营起始日可与竣工验收或开业日挂钩，但不得取消过户期限｜不接受时的红线：拒绝同步交割，或坚持“分红即可、过户另说”`

正说必须有反说。语言禁用“公寓”“可独立居住”“业主自行经营”。必须使用“酒店客房单元”。

### 2.4 最强反方

- “先开业分红、证慢慢办是行业惯例。” → 过户期限和逾期解除仍必须落句；不得标绿。
- “买的就是投资收益权，过不过户无所谓。” → 本类型核心给付含所有权转移；只买收益权按投资/集资审查，不按本类型放行。

## 节点 3　三方主体、经营方与授权

1. 建主体表：出卖人（开发企业）、买受人、经营方（丙方）。签约名、土地使用权人、过户名、购房款收款名、经营收益付款名不一致，不自动合并。
2. 经营方必须作为委托经营协议当事人签章。仅在备注出现名称：字段停止。修改句要求丙方签章并披露与出卖人是否关联。
3. 经营方资质、星级委托、特种行业许可未出示：`G#`，不写“具备酒店管理资格”。
4. 买受人立场必须改：若经营方未能按约支付收益或撤场，出卖人就应付未付收益承担连带责任。不得写成“经营方独立负责，出卖人免责”。
5. 口头“我们老板同意了”不得写成已授权。代理人须附授权委托书。
6. 共有买受人：共有方式写明；未闭合则签署能力字段停止。

不足：字段停止，列出待补，不补主体或证号。

## 节点 4　固定 / 保底回报与售后包租（硬闸 2、3）

### 4.1 收益模式必须点名

先识别文本采用哪一种，禁止混写“固定回报或分红，以公司通知为准”：

| 模式 | 审查动作 | 修改句重心 |
| --- | --- | --- |
| 利润分成 | 定义经营总收入、可分配净利润、面积占比、审计和披露周期 | 扣除项列附件，禁止经营方单方调账 |
| 保底+分成 | 保底金额 `【待填】`、触发条件、空置是否仍付；保底下调须三方书面同意 | 保底是丙方合同义务，不是投资保本承诺 |
| 固定租金 | 出租人是谁、是否开发商、房屋是否竣工 | 开发商对未竣工房屋承诺固定租金 → 节点 4.2 红线 |

广告、销讲、沙盘中的“年化 X%、稳赚、保本”：即使未入合同，具体确定且影响订约或房价的，按要约内容处理，必须改写入附件或删除。房地产广告不得含投资回报承诺。修改句删除保本宣传，不得把广告回报率写成合同收益标准。

### 4.2 售后包租与返本（未竣工红线）

同时满足或文本支持以下结构时，按售后包租 / 返本识别：

- 开发企业以在一定期限内承租或代为出租买受人所购该企业商品房的方式销售；
- 房屋尚未竣工验收（预售、在建、未取得竣工验收备案）；
- 或开发企业定期向买受人返还购房款（返本销售）。

动作：

1. 风险表标 `红线`。判断：`现有依据支持` 存在销售管理办法第 11 条禁止的销售方式（部门规章；民事效力走第 153 条与解释第 16 条，不得写成“合同当然无效”）。
2. 交付告知：该结构不得改写成可履行的“换子公司签字继续包租”。
3. 用户坚持“改到能签、先收房款再补竣工”：整体停止。
4. 买受人立场修改句不是包装合规，而是：`建议改为停止签署本约；如双方改走现售后由独立经营方按实际经营结果分配收益，须待房屋竣工验收合格并重新谈判，不得保留开发商固定租金承诺。`

已竣工：第 11 条“未竣工”禁令范围收窄，但开发商仍承诺固定租金或返本的，继续按 4.3 集资红旗审查，不自动标绿。

### 4.3 强制溢价回购与集资红旗

原文“满【待填】年按原价【待填】% 强制回购 / 无条件赎回 / 保本退出”：

- 识别为返本或约定回购外观，可能同时满足非法集资行政定义中的“销售商品活动中承诺给付货币回报”。
- 刑事四要件（未许可或借用合法形式、公开宣传、承诺回报、面向不特定对象）只作告知，本任务不认定罪名。
- 修改句：删除强制回购和保本退出；改为出卖人或其指定经营方在买受人拟对外转让时享有同等条件优先回购权，行权期限自收到书面通知起【待填，参考 15 日】日，逾期视为放弃。回购价按【市场评估价 / 约定公式，待填】，不得写成固定溢价必买。
- 用户要求保留强制溢价回购并面向不特定买受人公开销售：整体停止。

### 4.4 修改句（回报闸必出）

`定位（委托经营协议收益条 / 宣传附件）｜原文｜建议改为：删除“年化【X】% 固定回报 / 稳赚 / 保本”。经营收益按本酒店可分配净利润×本单元面积占比计算，扣除项以附件《收益分配计算模型》列明，丙方每【待填】日向买受人披露出租率、总收入和扣除明细。如保留保底，保底为丙方在【待填】日前支付【待填】元的合同义务，空置仍须支付；出卖人对丙方应付未付款项承担连带责任。广告及销讲中的投资回报承诺不作为本合同收益标准。｜理由｜可退让点：保底金额和披露周期可谈｜不接受时的红线：坚持开发商对未竣工房屋给付固定租金，或公开保本销售`

### 4.5 最强反方

- “已竣工，售后包租合法。” → 行政禁令收窄不等于民事无风险，更不等于无集资审查；开发商固定租金承诺仍须切开到独立经营方+连带。
- “解释第 16 条说部门规章不管效力，可以签。” → 可以不写“合同当然无效”，但不能改成可履行包租，也不能删掉停笔告知。

## 节点 5　转让限制、优先回购与承继

1. 买受人拟对外转让：须书面通知出卖人及经营方；优先回购权须有同等条件、通知送达和行权期限。权利不得无限期挂起。
2. 受让人必须承继原委托经营协议全部义务。未签署承继文件的，出卖人有权拒绝配合过户。过户申请应附经营方《继续委托经营确认函》。
3. 修改句：`买受人转让本单元的，应提前【待填】日书面通知甲方和丙方。甲方或甲方指定的丙方在同等条件下于收到通知后【待填，参考 15 日】日内书面行权，逾期视为放弃。受让人须签署《委托经营管理协议承继确认书》并由丙方出具《继续委托经营确认函》后，甲方始配合办理转移登记。`
4. 禁止把优先回购改回强制溢价回购（回到 4.3）。
5. 知识里的“15 日”“10–20 年”不是法定期限，一律 `【待填】`。

## 节点 6　格式条款、强制规范、宣传

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 格式条款

开发企业重复使用的网签文本、补充协议、委托经营协议，订立时未与对方协商的，是格式条款。不得仅以“用了示范文本”否认。

强制返租、放弃自住、单方调降保底、收益“以公司解释为准”、最终解释权、管辖/仲裁等异常条款，须有足以引起注意的标识并按要求说明。小字、夹在附件、仅网络勾选或弹窗：不得写成已尽提示或说明义务。提供方对提示说明承担举证责任。

### 6.2 强制规范

违反法律、行政法规强制性规定不一律无效。销售管理办法第 11 条是部门规章，行政处罚见第 42 条；民事效力不得用失效“效力性/管理性”口诀代替解释第 16 条。未竣工售后包租、返本、强制溢价回购、规避限购：不改写成有效履行结构。

### 6.3 委托任意解除

不得把民法典第 933 条写成买受人可随时收回客房且无需补偿。整体经营下，买受人任意收回须按剩余期限内可分配收益或约定标准补偿，并构成违约。经营方任意撤场：买受人可解除两份合同，出卖人连带返还已付款并承担违约金 `【待填】`。

## 节点 7　违约、解除、争议解决

1. 逾期过户、逾期交经营、擅自收回自用、经营方停付收益、经营方撤场必须分别有可执行后果。只有“依法承担违约责任”视为必须改。
2. 构成违约不等于当然解除。本任务不作出已经解除的结论，不做违约金精算。修改句避免“不得调整”或“按总价 30% 必得”。
3. 争议解决：不动产纠纷可能专属管辖，约定其他法院只标红旗并建议改为房屋所在地法院，不假装已经选定唯一合法法院。或裁或诉、机构不明：改成单一机构或单一法院连结点。
4. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。

## 节点 8　按框架六步出修改句

没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

打开已加载的 `框架.md`，按六步逐段对照。`基本面.md` 用于校验类型、主体、标的、程序、结构和红旗，不代替本节点出句。知识与硬闸冲突时，以硬闸为准。

| 步 | 本类型重心 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题改为产权式酒店类；三方列明；鉴于写明不可独立居住、必须统一经营；两份合同不可分割 | 标题/主体/鉴于修改句 |
| 交易条款 | 客房用途与统装标准；过户与经营权同步；收益模式去保本化；交付即交经营 | 闭环修改句；缺数字 `【待填】` |
| 配套 | 优先回购时限；受让人承继；擅自收回与停付收益的后果；出卖人连带 | 可执行后果句 |
| 尾部 | 同步生效；附件（装修封样、管理公约、收益模型、承继确认函）与正文同等效力 | 生效与附件修改句 |
| 语言 | 酒店客房单元≠公寓；过户≠交经营；定金≠订金；统一经营有排他性；删“稳赚”“原则上”“尽力” | 替换空词的句子 |
| 常见问题 | 未竣工售后包租；强制溢价回购；经营方空壳；退出难 | 结构级改法或红线停笔 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（未竣工售后包租、返本、强制溢价回购、公开保本集资、只交经营不过户且拒绝同步、规避限购）
- `必须改`：可谈但签署前要落句（同步交割句、收益公式与扣除项、优先回购时限、受让人承继、出卖人连带、去“公寓”表述）
- `可接受可优化`：仍要给句子，不得只标绿

用户不可接受事项优先写成红线。生存级金额且用户拒绝升级：停止“可以签署”建议。
