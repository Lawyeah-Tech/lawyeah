# 审查方法（锁定 买卖合同 / 经销买卖合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制动产买卖检验两段期间/所有权保留 75% 主路径，禁止复制行纪费用自担/介入权主路径，禁止复制销售代理佣金主路径。

定性校验：标题、核心给付与本类型一致才继续；收佣金代签、寄售行纪、单笔供货、特许经营明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、独家必然挡住供应商自销，或唯一必得窜货金。

`search_law` 返回已失效《合同法》买卖章及其解释、《制止价格垄断行为暂行规定》、2007 年《反垄断法》第 18 条（市场支配地位认定因素）时记为噪声，不得写入 `L#`。现行 RPM 条次是 **2022 年修正后反垄断法第 18 条第一款**，须与第 20 条、禁止垄断协议规定第 14 条、垄断民事解释第 21–24 条交叉核验。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。

知识库纠正（不回写双文件）：

- `基本面.md` 写“RMP”：规范用语是 **RPM／转售价格维持**。
- `基本面.md` “高额窜货补偿金及没收保证金”：只是供应商常见要价，不是可放行结构。必须受第 585 条及通则解释第 64、65 条约束，禁止“不得调整+任意没收全部”。
- `框架.md` 把《区域代理分销合同》列为标准命名：标题含“代理”须先切开；正触发后修改句统一改称经销商，不得把代理当默认标题。
- `框架.md` 把独家写成“即排他”：必须三分。独家＝区域内仅该经销商，且须写清供应商自销与再授权；排他＝供应商可自销但不再指定其他经销商；普通＝可同时指定多家。
- `框架.md` “风险自货交第一承运人时转移”：那是单笔动产买卖常见写法，**不是本类型默认主路径**。本类型先锁买断、经销权、订单成立、转售价和窜货；交付与风险只在框架已成立的订单项下点到可执行，不展开检验期/所有权保留专章。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。标题写“代理协议”的，先看是否买断：货过户、差价归对方、滞销不退，按经销审并改标题；以供应商名义收佣金，负触发代理。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 经销商买入再卖，赚差价，存货与二次销售风险归己，通常带区域/SKU/期限或指标 | 本类型 | 正触发 |
| 无区域、无独家、无年度指标，只是一台设备或一批货的一次性购销 | 动产买卖 | 负触发 `动产买卖合同·审查` |
| 收佣金、以供应商名义向终端签约、存货不归对方 | 销售代理 | 负触发 `渠道销售代理·审查`；房地产全案 → `房地产全案销售代理·审查`；房地产销售代理 → `开发商委托驻场销售但不是渠道引流（权限含代销讲解网签）→` |
| 自己名义贸易、货权仍归委托人、滞销可退、对价是报酬 | 行纪 | 负触发 `购房人终端订立本约，也不自负本约权利义务。以自己名义成交或先买后转→负触发` |
| 经营资源许可 + 统一经营模式 + 特许经营费/经营手册 | 商业特许经营 | 负触发引擎重新定性。不得当普通经销放行 |
| 按定作人图纸制作、重劳务过程 | 承揽 | 负触发引擎或承揽原子 |

支持切开的规范（法律结论须运行时复核）：

- 第 595 条：买卖是转移标的物所有权换价款。
- 第 162 条：代理人以被代理人名义实施的行为，对被代理人发生效力。
- 第 919 条：委托是处理委托人事务。
- 第 951 条：行纪是以自己名义为委托人从事贸易，委托人支付报酬。
- 合同编通则解释第 15 条：不拘泥名称，按内容、结构和履行行为认定。
- 商业特许经营管理条例第 3 条：特许经营＝经营资源许可 + 统一经营模式 + 特许经营费。
- 垄断民事解释第 23 条：代理协议且代理商不承担任何实质性商业或经营风险的，原告依反垄断法第 18 条第一款主张责任不予支持——反证买断承担存货风险的，不能借“代理”逃避 RPM。

### 1.3 买断转售（硬闸）

| 文本写法 | 本任务动作 | 修改句方向 |
| --- | --- | --- |
| 乙方买断甲方产品后转售，差价归乙方，滞销不退，货权自交付时转移 | 正触发，留下本类型 | 首部写明“经销买卖，不是代理、行纪或单笔购销” |
| 乙方有权以甲方名义与终端签约、开甲方抬头发票、收佣金 | 负触发销售代理，或必须改：删除代签 | 「乙方以自己的名义向客户销售已买断的产品，无权以甲方名义签署对外销售合同。」 |
| 货物不过户、卖不掉退还、对价是报酬 | 负触发行纪 | 不按经销改完 |
| 只有一台设备买卖，无区域/独家/指标 | 负触发动产买卖 | 不按经销改完独家和窜货 |
| 加盟费 + 统一经营手册 + 特许资源许可 | 负触发特许经营 | 不按普通经销放行 |

修改句（正触发首部）：

「本合同为产品经销合同。乙方自甲方买断附件所列产品后，以自己的名义向客户转售，赚取购销差价，并独立承担存货、滞销和二次销售风险。乙方不是甲方的代理人，也不是行纪人或仅报告订约机会的中介人。除质量问题或书面约定的调货外，已交付产品不得退回甲方。」

最强反方：相对方主张已构成代理或行纪，从而主张存货风险仍在供应商、或对外合同直接约束供应商。修改句必须收回代签和寄售措辞。用户坚持保留代签或寄售主轴：负触发，不填本类型十节实体结论。

### 1.4 无证特许 / 通谋虚假停笔（硬闸）

加载后或定性中出现：医疗器械、食品、危化等须许可或备案而文本与材料均未见；伪造许可；通谋阴阳价款；倒签以改变许可时点。

动作：

1. 交付告知：无证经营可能触发第 153 条及行业监管。不得改写成可履行的无证出货或“写成普通日用品即可过关”。
2. 不写可履行的品类替换伪装、假许可路径。
3. 风险表只保留识别依据和删除/转出口径。
4. 用户坚持“改到能签且仍做这些事”：整体停止。

部门规章多为管理规范：不轻易写“无许可则经销合同当然无效”，但该签署/履行字段必须停止。

### 2.1 主体表

建表：签约名、履行名、付款名、发票名、授权签字人。名称不一致不自动合并。二级经销须写清是否允许再授权及再授权后的责任归属。口头“我们老板同意了”不得写成已授权。

| 已有事实 | 本任务动作 | 不得写成 |

| 第三类医疗器械经营，无许可证痕迹 | 字段停止；修改句要求作为附件 | 可以经营、可以出货 |

## 节点 3　经销权范围（硬闸）

区域、SKU、期限、独家/排他/普通必须同时可执行。缺一项标必须改。

| 文本写法 | 动作 |
| --- | --- |
| “华东地区独家经销”但无省市区清单，SKU 写“甲方产品”，期限写“长期” | 必须改：地图级区域、附件 SKU、起止日 |
| “独家”但未写供应商可否直销、网上销售、向区域内大客户供货、再指定他人 | 必须改：逐项勾选允许或禁止 |
| “独家”但无最低采购量或连续未达标的降级/解除 | 必须改：独家不作为；连续【待填】个考核期完成率低于【待填】% 的，自动转为普通经销或甲方可解除 |
| 普通经销却限制供应商不得向区域内任何人供货 | 必须改：普通经销不得按独家锁定 |

修改句（独家）：

「甲方授予乙方在附件《经销区域》内、就附件《SKU 清单》所列产品、自【待填】至【待填】止的【独家 / 排他 / 普通】经销权。独家指：甲方不得在该区域内再指定其他经销商；【甲方不得 / 甲方有权】在该区域内向最终用户或指定大客户直接销售；【甲方不得 / 甲方有权】通过甲方自营网店向该区域发货。未经乙方书面同意，甲方不得将该区域再授权第三人。期限届满前【待填】日双方书面确认是否续签，不约定自动续期。」

最强反方：供应商主张“独家只禁止再指定经销商，自己始终可以卖”。签前必须把自销写死，不能事后解释。

## 节点 4　框架+订单与最低采购量（硬闸）

支持依据：第 483 条。承诺生效时合同成立，法律另有规定或当事人另有约定除外。

| 文本写法 | 动作 |
| --- | --- |
| “订单以甲方 ERP 显示为准即成立”，无确认动作 | 必须改。未确认不得写成已经成立 |
| 框架已签即视为全年数量已锁定 | 必须改。框架只约定原则，具体数量以已确认订单为准 |
| 最低采购量只有数字，无考核期、未达标后果 | 必须改：维持独家、降级或解除的条件可执行 |
| 订单与框架冲突未写适用顺序 | 必须改：除非订单明确修改本协议特定条款，否则以本协议为准 |

修改句：

「本协议为框架协议。具体规格、数量、交货期以订单为准。订单须经【双方签章 / 双方指定邮箱书面确认 / 双方指定 ERP 账号按附件流程点击确认】后方成立。仅一方录入系统、尚未按上述方式确认的，订单不成立，任何一方不得主张对方已负供货或付款义务。乙方年度最低采购量为人民币【待填】元或【待填】台，按【自然年 / 季度】考核；连续【待填】个考核期完成率低于【待填】% 的，甲方有权取消独家或书面解除本协议。」

最强反方：供应商主张“系统已生成就是订单”。现有依据不支持在无承诺或无清晰视为承诺条款时把单方录入写成已成立。

## 节点 5　转售价格（硬闸）

支持依据（运行时复核）：反垄断法（2022 修正）第 18 条第一款；禁止垄断协议规定第 14 条；垄断民事解释第 21–24 条。

条文要点：禁止经营者与交易相对人固定向第三人转售商品的价格，或限定向第三人转售商品的最低价格；能证明不具有排除、限制竞争效果的，不予禁止。建议价、价格信息通报本身不当然等于固定转售价。算法或平台规则自动设定转售价，仍按第 18 条审查。

| 文本写法 | 动作 |
| --- | --- |
| “建议零售价／市场指导价，乙方可自行定价” | 可保留；补“不得因未执行建议价追究违约” |
| “必须按甲方公布的零售价销售，否则根本违约／停货／没收保证金” | **红线或必须改**。不得写成可履行违约结构 |
| “不得低于甲方规定的最低限价，违者按差价十倍处罚” | 同上 |
| 用户要求“改成能强制执行的最低零售价” | 整体停止该部分。可改为建议价或品牌形象管理建议 |
| 真代理且对方不承担任何实质性经营风险 | 负触发销售代理；本类型不借“代理例外”放行买断 RPM |

修改句（建议价）：

「甲方可向乙方提供《建议零售价目录》，仅供乙方定价参考，不构成对转售价格的固定或最低限制。乙方有权自主确定对客户的转售价格。甲方不得仅以乙方未执行建议零售价为由认定违约、停货、扣减返利或没收保证金。」

禁止把“能证明无排除限制竞争效果”写成签前可以保留强制最低限价的放行理由。该抗辩属于执法或诉讼中的举证责任，不是本任务的可履行结构。

最强反方：供应商主张建议价体系、品牌形象维护或“行业都这么写”。现有依据支持建议价，现有依据不支持把固定转售价或最低限价写成可履行违约条款。

## 节点 6　窜货、保证金、格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 窜货与保证金（硬闸）

支持依据：第 585 条；通则解释第 64、65 条。当事人仅以约定不得调整违约金为由主张不予调整的，人民法院不予支持。约定违约金超过造成损失百分之三十的，一般可以认定为过分高于造成的损失。

| 文本写法 | 动作 |
| --- | --- |
| 跨区销售按窜货额十倍支付且不得调整，并没收全部保证金 | **红线**。改为可调整、与损失挂钩，保证金只扣对应部分 |
| 有窜货罚则但无认定程序（串货流向、鉴定、异议期） | 必须改：补书面通知、异议期和回购窜货产品选择 |
| 保证金写成“定金”且未限 20% | 按第 586 条压到不超过主合同标的额 20%，或改回履约保证金并写明不适用定金罚则 |

修改句：

「乙方不得在授权区域以外销售本协议产品。甲方主张窜货的，应书面说明货物流向并给予乙方【待填】日异议期。经确认构成跨区销售的，乙方应按该笔窜货销售额的【待填】% 支付违约金；该违约金过分高于甲方实际损失的，任何一方有权请求依法调整，双方不得约定排除调整。保证金仅用于抵扣经确认的对应违约金或货款，剩余部分应在合同终止后【待填】日内无息返还。禁止约定“一经违约即没收全部保证金且不得调整”。」

### 6.2 格式条款

为重复使用而预先拟定、订立时未与对方协商。供应商制式经销文本、经销商制式采购经销文本均可构成格式条款（第 496 条）。审查：强制转售价、天价窜货、任意没收保证金、单方调价、最终解释权、自动续期、管辖是否有显著提示。仅电子勾选不足（解释第 10 条）。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在附件 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

第 497 条无效情形、第 498 条不利解释：只在核验后作为修改理由，不代替修改句。

### 6.3 强制规范

违反法律、行政法规强制性规定不一律无效（第 153 条；解释第 16 条）。禁止用已失效“效力性/管理性”口诀。许可、备案多为管理规范：合同可能仍成立，但无法合法出货构成履行障碍——用中止、解除和责任分担修改句处理，不把无证改成可履行出货路径。垄断条款是否无效，依第 153 条和垄断民事解释第 48 条运行时核验，本任务不宣告已经构成垄断违法。

## 节点 7　库存、商标、终止善后

1. **质量退换与非质量退货**  
   质量问题按买卖品质担保处理，但本类型不把检验两段期间写成默认专章。非质量问题默认不予退换，或仅允许【待填】% 以内库存调剂。清盘回购须写价格、期限和验收。

2. **商标许可**  
   仅授权在经销期限和区域内为推广本协议产品使用标识，不转让商标权。终止后立即停止使用。发现假货应及时通知并配合。

3. **终止善后**  
   停止以品牌名义宣传；剩余合格库存按【原价 / 折价【待填】% / 不回购】处理；授权书交回；保密继续有效。自动续期改为期满前书面确认。

修改句（终止库存）：

「本协议终止后【待填】日内，乙方应停止使用甲方商标、装潢和授权名义，并向甲方交回未使用的授权文件。双方按附件约定处理剩余合格库存：【甲方按【待填】折回购 / 乙方自行消化且甲方不再供货】。存在质量问题的库存按质量条款退换，不得与非质量库存混算。」
