# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受、必然优先受偿或必然过户；编造未给出的本金、利率、房价；把已失效《合同法》《物权法》《担保法》及其解释、2015 年 24%/36% 利率条写入结论；把本约改成可请求实际履行的真实买卖。

## 1. 触发、单方立场与成果状态

立场（债权人/买受人侧，或债务人/出卖人侧）、授权、签署状态、主要目标。负触发写路由，不启动实体审查。已起诉要过户或已违约要清算：负触发转争议。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》《担保法》《物权法》及其解释或 2015 年利率两线时记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `买卖合同`，子级 `让与担保式房产买卖合同`。定性理由必须写清：为何不是真实买卖、不是工抵房、不是借款主文件。易混切开结果必须点名是否排除 `一般商品房买卖合同·审查`、`二手房买卖·审查`、`以房抵债工抵房·审查`、`送审主文件是《借款合同》或借据，买卖过户只是从担保安排→`。

加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。借名规避限购、查封房包装、职业放贷写停笔告知，不填可履行结构。

## 4. 主体、授权、主债权与文本版本

主体表：签约名、实质角色（债务人/债权人）、登记权利人、付款/放款账户名、网签买受人、授权签字人、共有人或担保人、是否持牌金融机构。名称不一致不自动合并。

主债权表（每项一行：项目｜合同记载或`G#`）：

- 借款本金 / 实际放款额
- 借期与还款日
- 利率、资金占用费、回租租金及其是否已折算年化
- 主债权文件名称及是否附于本约

版本表：买卖/回购正文、借款协议、网签稿、回租合同、担保确认书、聊天确认。冲突并列，不选对用户有利的一版。

## 5. 给付闭环（本类型必填）

固定回答，缺项标 `G#`，不补商业数字：

- 房屋是否锁定到坐落与权证/网签房号
- **模式**：不转移产权（网签/预告）还是转移产权（过户＋回购/回租）；动词用回购还是撤销
- 占有与出租：担保期间谁占有、租金归谁、是否与利息叠计
- **购房款是否已改写为借款本金**；价款与市价是否明显偏离（只描述，不编市价）
- **流质**：是否存在归己所有、自动转让、逾期卖断
- **清算**：是否具备折价/拍卖/变卖＋参照市价＋余款返还＋不足续偿
- **回赎**：清偿后几日内配合返还；逾期违约金或租金标准；正说是否有反说
- **公示分层**：仅协议 / 仅网签 / 预告登记 / 已过户，分别能主张什么；不得把网签写成优先受偿；不得写成已经完成
- 买受人担保期间处分限制；出卖人再处分限制
- 两次过户税费分担
- 生效是否与放款到账联动

## 6. 格式条款、强制规范与限购

是否构成格式条款；网签范本不排除格式条款；提示说明痕迹；放弃清算、单方定价、排除回赎等异常条款。强制规范只区分该条无效还是整单无效。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

限购/借名/职业放贷：列出材料中的信号；只告知，不改可履行规避结构。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔/转出口径。禁止输出无修改句的色块表。

本类型默认应出现（有事实则单列，无事实则在缺口节说明未检出）：名实未披露、流质、清算未闭合、回赎无反说、无公示却主张优先、利率超上限、定金实为砍头息、与工抵房或真实买卖误套。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点、不接受时的红线。未给出的商业数字用 `【待填】`，不编造。

流质条款的建议句必须删除归己所有并写入折价或拍卖、变卖。清算建议句必须含余款返还与不足续偿。鉴于建议句必须点明借款担保而非单纯物权交易。禁止用“依法处理”收尾。

## 9. 谈判与签署提醒

谈判顺序：先红线（流质、拒绝清算、借名限购、查封房、无主债权文件），再必须改（名实鉴于、模式动词、回赎反说、公示义务、利率），最后可优化。

签署提醒：先核对放款账户与实际到账；权属与共有人书面同意；网签/预告/过户完成前谨慎放款；预留撤销或回购文件；不倒签；不指导先过户再补借款协议。债权人侧：完成公示仍须清算，不能按真实买卖诉请过户。债务人侧：无回赎反说和高额不配合违约金则房屋可能被锁死。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本任务成果是可编辑草稿、未决项、自审风险表和自审后修改句。有完整待签文本要评改转 `让与担保式房产买卖·审查`。草稿必须落入本类型起草必写 / 附件必附 / 禁止出现。不是履约交底、争议文书、效力保证、优先受偿保证或过户保证。借款主文件整案评改转 `送审主文件是《借款合同》或借据，买卖过户只是从担保安排→`。
