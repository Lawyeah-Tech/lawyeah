# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受、必然整栋过户或税负上限；编造未给出的价格、面积、证号、监管账号；把已失效《合同法》及其解释、已被删除的 2003 年商品房解释第 14 条、已失效的 2003 年国有产权转让办法写入结论；把散售五证清单当作本类型默认主表。

## 1. 触发、单方立场与成果状态

立场（整栋买受人或出卖人）、授权、签署状态、标的是整栋/整层还是可封闭运营的整宗、主要目标。负触发写路由，不启动实体审查。已批量网签后要解除：负触发转争议。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、2003 年商品房解释第 14 条、2003 年国有产权转让办法或 2009 年租赁解释第 24 条时记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `买卖合同`，子级 `房屋整售合同`。定性理由必须写清：买受人是否单一（或其指定主体）、是否以整栋控制权为合同目的、是否资产交易而非股权交易。易混切开结果必须点名是否排除：一般商品房散售（`一般商品房买卖合同·审查`）、二手单套（`二手房买卖·审查`）、团购（`房屋团购合同·审查`）、定制（`房产定制销售合同·审查`）、包销（`房地产包销合同·审查`）、股权收购（`通过收购项目公司股权间接拿房→转`）。

加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。规避限购、改用途、违反自持、体外循环解押写停笔告知，不填可履行结构。

## 4. 主体、授权、国资程序与文本版本

主体表：签约名、土地使用权人、履行名、**监管账户名**、发票名、授权签字人、买受人指定主体名单、抵押权人、施工总包、主要承租人、监管银行。名称不一致不自动合并。

国资/决策表（适用时每项一行：程序｜材料或`G#`｜是否已完成｜是否写成生效条件）：

- 资产评估
- 内部决策（股东会/董事会/党委会）
- 产权交易机构进场或法定协议转让例外

**不要输出散售五证默认表。** 证照只在出卖人为开发企业且材料已提供时作为尽调附件摘录，主闸仍是整体转让权与登记簿负担。

版本表：整体销售专门协议、拟网签标准合同（N 份或模板）、房产明细表、共有部分范围图、土地出让合同及补充协议、租约清单、决议、聊天确认。冲突并列，不选对用户有利的一版。必须回答：主协议与网签冲突时以谁为准。

## 5. 给付闭环（本类型必填）

固定回答，缺项标 `G#`，不补商业数字：

- 买受人是否单一或其指定主体；指定主体名单是否封闭
- 房号是否以附件列尽；共有部分（屋顶、外墙、大堂、管井、避难层）是否有界定图
- 地下车位、人防、机房、冠名权是否随同移转或仅长期使用
- **面积：单套误差规则 + 整栋合计误差解除红线是否都写了**。只写「按规定」或只写散售单套 3% = 未闭合
- 计价是整体包干价还是单价累加；网签拆分价是否声明仅供备案、总和等于包干价
- 抵押、查封、预告登记、工程款优先受偿：已披露 / 未披露 / 依据不足
- 租约：清场或带租约；优先购买通知/弃权；租金与押金划转节点
- 收款账户是否三方监管账户；首笔是否专用于解押；提前解押款有无反担保
- 风险转移是否约定为**整栋移交占有之日**，而非逐套过户之日
- 整体交付是否以整栋竣工验收备案 + 电梯/空调/消防等公共配套联动调试合格为前提
- 大证拆分、批量网签、过户的责任主体、期限、未完成后果
- 批准、登记、进场、网签写成生效条件或期限，不写成已经完成

## 6. 格式条款、强制规范与用途管制

是否构成格式条款；网签示范文本不排除格式条款；提示说明痕迹；放弃整栋解除、按现状交付、宣传仅供参考、部分履行等异常条款。强制规范只区分是否导致民事行为无效。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

规划用途与拟使用用途、自持比例/年限、不得分割转让：列出原文与拟交易是否冲突。冲突：红线，不改写成「双方确认可变更用途」。

税费：土地增值税、契税、增值税及附加的承担主体、计算口径、发票类别是否写明。禁止保证税负上限。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔/转出口径。禁止输出无修改句的色块表。

本类型默认应出现（有事实则单列，无事实则在缺口节说明未检出）：1+N 优先、土地用途/自持、共有部分与冠名权、租约/优先购买、工程款优先受偿、解押封闭监管与反担保、面积双红线、部分不能过户的整体解除、风险转移时点、国资进场（若适用）。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点、不接受时的红线。未给出的商业数字用 `【待填】`，不编造。

主协议优先条款、整体解除条款、三方监管解押路径、共有部分范围必须落成可粘贴句子。禁止以「依法处理」「按规定解押」收尾。

## 9. 谈判与签署提醒

谈判顺序：先红线（改用途/未满自持、解押款进一般户、隐匿抵押或工程欠款、国资未进场、规避限购），再必须改（1+N 优先、共有部分附件、面积双红线、整体解除、租约处理、反担保），最后可优化（冠名权年限、物管撤场细节、排他期长度）。

签署提醒：土地出让合同及补充协议原件；登记簿抵押/查封查询；租约与弃权；工程款结清或弃权；监管账户与解押指令一致后再付首笔；国资进场或批准文件作为生效附件；不倒签；不指导先付款后补解押。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本任务成果是可编辑草稿、未决项、自审风险表和自审后修改句。有完整待签文本要评改转 `房屋整售合同·审查`。草稿必须落入本类型起草必写 / 附件必附 / 禁止出现。不是履约交底、争议文书、效力保证、整栋过户保证或税负测算报告。
