# 边界与路由

本技能只审查 **买卖合同 / 房屋整售合同**（单一买受人或其指定主体打包受让整栋、整层或可独立封闭运营的整宗房屋资产，目的是取得完全控制权）。

| 已能支持的事实 | 路由 | 不得写成 |
| --- | --- | --- |
| 待签、单一买受人打包整栋/整层控制权、目标是评改「1+N」文本 | 留本任务 | 已完成签约或已生效 |
| 开发企业向社会逐套预售或现售，核心是单套房价、五证、预售证范围 | `一般商品房买卖合同·审查` | 用本技能的整栋解除/共有部分控制权条款硬套散售 |
| 业主/自然人出售已办或应办产权的单套存量房；户口迁出、原贷结清 | `二手房买卖·审查`；该原子不可用则 本套导航的类型切开步骤 | 用户口/阴阳房价句当整售修改句 |
| 多名独立买受人集合购买，公有部分仍按份共有；单位组织团购 | `房屋团购合同·审查`；专业版未收录则 `unavailable`，提示 | 删掉多名买受人后继续当整售审 |
| 按买方技术任务书定向开发，价款含定制溢价、报规报建 | `房产定制销售合同·审查` | 把技术任务书改写成整售房号清单后硬套 |
| 包销方代理销售、包销期满强制购买未售存货 | `房地产包销合同·审查`；专业版未收录则 `unavailable` | 把包销义务改写成整栋资产过户 |
| 买项目公司股权间接拿房、交割是股权变更 | `通过收购项目公司股权间接拿房→转` | 按房屋过户、网签拆分价审完股权文本 |
| 不含整栋房屋控制权的单项资产收购 | `不含整栋房屋控制权的单项资产收购→转` | 扩张成整栋整售 |
| 前期物业交接、物业服务本约是主给付 | `物业服务合同·审查` | 只审物业不审整售主给付时留在本任务 |
| 有完整待签文本要评改 | `房屋整售合同·审查` | 在本起草原子做签前评改 |
| 无可读正文，本类型条件已谈妥，要出己方稿 | 留本任务起草并自审 | 已经完成起草；在本起草原子做签前评改 |
| 已签，问交房日、办证日、付款留痕、物业撤场进度 | 本套导航的履约步骤 | 签前意见 |
| 已批量网签或已付款后要求解除、索赔、起诉、仲裁 | `或对应专项领域。` | 继续当签前审查出修改句充作解除方案 |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 | 两可时灌入两套知识 |
| C 端大众快检 | 只分流，不回改 | 降成零售购房快检 |

挂靠、违法分包、规避限购、改变规划用途、违反自持、体外循环解押：只告知违法或无法履行风险，不改写成可履行文本。用户坚持改到能签：整体停止。

专业版未收录的 P1 场景不会安装对应原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
