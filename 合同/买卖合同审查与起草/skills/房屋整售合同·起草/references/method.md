# 审查方法（锁定 买卖合同 / 房屋整售合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。

本文件是可执行判断节点，不是栏目说明书。每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、必然整栋过户、税负不超过某数、对方必然接受或唯一必得金额。

`search_law` 返回已失效《合同法》及其解释、担保法解释、商品房买卖合同司法解释（2003）第 14 条、企业国有产权转让管理暂行办法（2003）、城镇房屋租赁解释（2009）第 24 条或施工合同解释（二）时记为噪声，不得写入 `L#`。面积对照的现行部门规章是《商品房销售管理办法》第 20 条，但**不得把它当成散售默认主闸**；整售必须另写整栋合计误差解除线。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突。

示范文本与网签稿只参考结构。民法典允许参照示范文本，不证明本约条款已被接受；网签空白处填写「按规定处理」视为未约定。依据示范文本拟定且符合格式条款定义的，仍按格式条款审查。

**禁止**把 `一般商品房买卖合同·审查` 的五证表、预售证范围核验、单套 3% 全规则和预售资金监管户，原样搬进本类型当默认动作。

## 节点 0　签署状态与成果分流

先于类型识别。命中任一项则本任务不填十节实体结论，只交付分流理由和最小交接。

| 已能支持的事实 | 走向 | 不得写成 |
| --- | --- | --- |
| 无可读正文和附件，或只有口头交易要点 | `房屋整售合同·起草` | 已经完成审查 |
| 未签，目标是评改已有整售主协议和/或拟网签稿 | 进入节点 1 | 已签署或已生效 |
| 已批量网签或已付解押款，用户要解除、索赔、起诉 | `或对应专项领域。` | 继续当签前审查 |
| 已签，问交房日、办证日、物业撤场、付款留痕 | 本套导航的履约步骤 | 签前意见 |
| 已出现催告、解除通知、立案、开庭、仲裁 | 争议或对应专项 | 用本任务做争议评估 |
| 残缺模板，用户要按己方条件重写整份主协议 | 起草 | 本任务出整稿 |

缺立场或同时掌握买卖双方秘密：整体停止策略输出，澄清代表哪一方。缺文本仍要「给个能不能签」：不启动实体审查。

## 节点 1　类型识别：只留房屋整售

用标题、核心给付、买受人结构和用户陈述定性，不用标题单独定性。

| 信号 | 归入 | 排除 |
| --- | --- | --- |
| 单一买受人或其指定主体打包受让整栋、整层或可独立封闭运营的整宗房屋，目的是完全控制权（外墙、屋顶、大堂、冠名等），对价为整体包干价；文本常称整体销售协议、资产购买协议（整售类） | 本类型 | 散售、团购、股权收购 |
| 开发企业向社会逐套销售，核心是单套房源、五证、预售证范围 | `一般商品房买卖合同·审查` | 不得用本技能整栋解除句去改散售稿 |
| 业主出售已办产权的单套存量房；户口、原贷、居间 | `二手房买卖·审查` | 不得用户口句当整售修改句 |
| 多名互不隶属买受人集合购买，公有部分仍按份共有；单位组织认购 | `房屋团购合同·审查` | 不得删多名买受人后继续当整售审 |
| 按买方技术任务书定向开发，价款含定制溢价 | `房产定制销售合同·审查` | 不得把技术参数表改成房号清单后硬套 |
| 包销方代理销售，期满强制购买未售存货 | `房地产包销合同·审查` | 不得把包销义务改成整栋过户 |
| 交易交割是股权变更、间接拿房 | `通过收购项目公司股权间接拿房→转` | 不得按网签拆分价审股权文本 |
| 单项设备或非整栋房屋的资产收购 | `不含整栋房屋控制权的单项资产收购→转` | 不得扩张成整栋整售 |

名实不符（封面写「整体销售」、正文是十个自然人各自买一套且公摊仍共有）按核心给付归类，标题冲突写入 `C#`。两可时禁止同时加载邻类双文件。

加载协议：只打开 `references/基本面.md` 与 `框架.md`。禁止为对照再开第二类。文件不可用（空、与类型明显无关）：记 `G#`，用本方法节点 2–8 继续，不编造房号、监管账号或税负。

规避限购、借用他人或空壳资格购买住宅、伪造进场或解押：只告知，不写可履行结构。用户坚持改到能过网签或能过户：整体停止。

## 节点 2　整体性、「1+N」与土地用途（本类型第一道实体闸）

未完成整体性切开，不得进入面积和付款审查。**本节点替代散售五证表。**

### 2.1 整体性语言

合同必须能支持「打包购买、不可分割之整体」：

- 合同目的写明：买受人取得整栋（或整层）完全控制权，任何单一专有部分无法过户均可能构成整体合同目的不能实现。
- 禁止「各套独立履行、独立解除、独立结算」且无整体回转机制。
- 标题建议《商品房整体销售协议》或《资产购买协议（整售类）》，并标明「主协议」。

原文只有「购买下列商品房」再附一长串房号、无整体性目的：`必须改`。

商品住宅「按套销售、不得分割拆零」（销售管理办法第 12 条）禁止的是把一套住宅拆成若干份出售，**不是禁止整栋打包**。不得把第 12 条写成「整售违法」。

### 2.2 「1+N」优先效力

整售实务采用 1 份整体销售专门协议 + N 份用于网签过户的标准商品房买卖合同。

审查动作：

1. 两套文本是否都在材料里。只有网签稿、没有主协议：`必须改`，补主协议或把整体条款写入现行文本并声明其优先。
2. 必须有冲突处理句：网签条款系为满足行政备案需要，与主协议不一致的，**以主协议为准**。
3. 网签拆分价总和应等于整体包干价；拆分价声明「仅供网签备案，不改变包干总价及整体交付、整体解除安排」。拆分显著偏低或偏高：提示税务评估风险，不编造「安全」区间。

最强反方「网签系统不允许改优先条款」→ 主协议仍要写优先；网签稿加备注或另行签署效力确认函。不得写成「以网签为准」。

### 2.3 土地出让、自持、规划用途

必须向用户索取或标 `G#`：土地出让合同及补充协议、规划许可证及附图。

| 文本或事实 | 本任务动作 |
| --- | --- |
| 出让合同约定不得分割转让或须整体运营 | 整售方向与政策一致；写入鉴于，作为可履行前提 |
| 存在自持比例或自持年限，期限未满 | 红线。不改写成「双方同意视为已满期」 |
| 拟将整栋住宅改为办公，或相反，改变规划用途 | 红线。出让方可依土地使用权解释第 6 条解除出让合同；整售合同面临无法履行。只告知，不设计「先过户再报商改住」 |
| 划拨土地未补缴出让金 | 字段停止或红线；修改句要求先办出让手续并明确费用承担 |
| 材料未提及出让限制 | 不得写「无转让限制」；修改句要求作为附件并授权查询 |

用户要求把改变用途或未满自持改成可履行外观：整体停止。

### 2.4 整体转让权（不是五证默认表）

核验出卖人是否有权把整栋打包转让：登记权利人是否即签约出卖人；是否已设定禁止转让的抵押或查封；合作开发另一方是否同意。开发企业未散售存货可以把土地证、规划许可、施工许可、竣工备案作为**尽调附件**摘录，但缺某一证不等于自动套用 `一般商品房买卖合同·审查` 的预售无证效力公式——先判断房屋是否已竣工、是否仍属预售存货，再决定是否转引擎或补整体转让权材料。未竣工且向社会预售特征明显、并无整栋控制权安排：转 `一般商品房买卖合同·审查`。

## 节点 3　主体、国资、工程款、承租人

1. 建主体表：签约名、土地使用权人、监管账户名、发票名、授权签字人、买受人指定受让主体。指定主体必须封闭名单+加入程序，禁止「买受人可任意指定第三方」而无连带责任。
2. 买受人为法人且标的含住宅：当地是否允许企业购买住宅标 `G#` 或字段停止，不得写「可以网签」。规避限购只告知。
3. **国资**。任一方为国有企业或国家出资企业：资产评估、内部决策、产权交易机构进场（32 号令第 48 条：一定金额以上房产、在建工程、土地使用权对外转让应决策后进场；内部非公开转让须符合该条例外）。未完成：把评估/决议/进场完成写成**生效条件**，不放行「签字即生效」。应评未评：提示监管机构可诉请确认经济行为无效（评估暂行办法第 27 条），本任务不宣布已无效。
4. **施工方与工程款优先受偿**（民法典第 807 条；施工解释（一）第 39–42 条）。要求披露工程款支付进度、结算、欠款、承包人是否出具放弃或限缩优先受偿的文件。未披露：`依据不足，无法形成无优先受偿负担的结论`。已有欠款或承包人未弃权：红线，修改句要求交房/过户前结清或取得不可撤销弃权，并预留保证金。损害建筑工人利益的弃权可能不被支持（第 42 条），不得把一纸弃权写成风险消灭。整售买受人多为大宗资产收购主体，**不得**自动主张 2023 年批复项下「商品房消费者」价款返还优先权。
5. **承租人**。先切「清场交付」还是「带租约转让」。
   - 买卖不破租赁（第 725 条）：占有期内所有权变动原则上不影响租约；出租前已抵押并因实现抵押权变卖、或出租前已查封的，租赁解释 2020 第 14 条有例外。
   - 优先购买（第 726 条）：出卖前合理期限通知；15 日未表示视为放弃；近亲属或按份共有人行使优先购买除外。未通知：承租人可请求赔偿，**买卖合同效力不受影响**（第 728 条）。签前仍必须改：通知证据或书面弃权，否则买受人可能接手诉讼和赔偿成本，整栋控制权被租赁和优先购买撕裂。
   - 带租约：租金划转时点、押金移交、租约清单作为附件。
   - 清场：交房前清空并注销租赁备案，逾期视为未满足交付条件。
6. 口头「我们老板同意了」不得写成已授权。

不足：字段停止，列出待补，不补主体或金额。

## 节点 4　标的完整性、共有部分、面积双红线、风险转移

### 4.1 物理范围

必须有《房产明细表》（全部房号、面积、网签拆分价）和《共有部分范围界定图》。缺任一份：`必须改`。

共有部分至少覆盖：外墙及广告位、屋顶、公共大堂、管井、避难层、设备层。区分所有权解释第 3 条将外墙、屋顶、大堂、避难层等认定为共有部分——整售若不写使用权与收益权随同移转，买受人拿不到「完全控制权」。

地下空间：车位产权或长租、人防平时使用权、机房设备归属。人防批准文件未核：该字段 `G#`，不保证可经营使用。

冠名权：是否永久或约定期限；外立面广告是否排他。

房地一体（民法典第 356 条）：禁止只转房屋不转对应土地使用权份额。

### 4.2 面积：单套 + 整体双红线

整售对面积准确性要求高于散售。禁止原文或修改句只写「按有关规定处理」。

最低闭合：

1. 按实测面积调整整体包干价的公式或单价。
2. **单套**误差处理：可参照销售管理办法第 20 条结构（≤3% 据实；>3% 可就该套主张调整或纳入整体解除评估）。现行依据是该办法第 20 条，不是已删除的 2003 解释第 14 条。
3. **整栋合计**误差超过约定比例（数字用 `【待填】`，例如双方商定的整体误差比）时，买受人有权**解除整个主协议**并取回已付款。
4. 因规划变更导致面积差异且不解除的，另签补充协议。

只抄散售单套 3%、没有整栋合计解除线：判定未闭合，`必须改`。按套（单元）计价的，还须约定套型/尺寸误差，不得只套建筑面积公式。

### 4.3 权利负担

查询或要求披露：抵押、查封、预告登记、租赁、居住权、工程款优先受偿。材料未提及不得写成「无权利负担」。已查封或无法在过户前解除的在建工程抵押：红线。

### 4.4 风险转移与交付标准

风险转移时间点约定为**整栋建筑整体移交占有之日**，禁止默认「各套过户之日」或「各套签收之日」（民法典第 604 条允许另行约定，整售必须把约定写明）。

整体验收前提：整栋取得竣工验收备案，且电梯、中央空调、消防系统等公共配套**联动调试合格**。交付物含建筑图纸、设备手册、质保书原件、物业管理资料。

慎用「按现状交付」。改为「按本协议约定的技术参数及双方封存的现状清单交付」。区分「物理交付」与「运营权交付」（物业撤场、资料移交、系统账号）。

领钥匙即视为整栋验收合格：必须改。

## 节点 5　程序：大证拆分、批量网签、决议、税费、生效

把批准、登记、备案、进场、网签写成**生效条件或履行期限**，不写成已经完成。

| 文本写法 | 本任务动作 |
| --- | --- |
| 签字即生效，但一方为国企且须进场 | 改为：评估备案、内部决议和进场成交（或法定协议转让批准）全部满足之日生效 |
| 项目仍在大证/初始登记阶段 | 补：出卖人在【待填】日前完成分户登记；这是过户前提；逾期买受人可中止付款或整体解除 |
| 批量网签无谁负责、几日内、系统无法一次导入的后果 | 补义务主体、期限、与当地住建预沟通义务、失败时的中止/解除 |
| 未网签=合同无效 | 纠正：当事人仅以未登记备案请求确认无效的，商品房解释第 6 条不予支持；约定备案为生效条件的从约定 |
| 无预告登记 | 买受人立场：批量网签后【待填】日内申请预告登记；出卖人不得再处分 |
| 税费承担只写「各自依法」 | 必须改：分列土地增值税、增值税及附加、契税、印花税、土地出让金补缴的承担主体、预沟通时点、发票类别。禁止保证清算税额 |
| 用户要求倒签网签日、补假进场或假解押 | 整体停止 |

双方大额资产交易的股东会或董事会决议作为附件。未附：字段停止，不写「可以盖章」。

## 节点 6　对价、三方监管、解押、反担保、定金

### 6.1 整体包干价

写明包干总价、是否含税、网签拆分仅供备案。未给出的数字写 `【待填】`。禁止把土地增值税用「买方包干一切税费」含糊转嫁而不列税种。

付款节点通常挂钩：签署主协议 → 完成批量网签 → 取得解押证明 → 整栋交付占有 → 产权过户至买方（或指定主体）名下。节点与金额缺失：`必须改`。

### 6.2 三方监管与先解押后过户

整售项目通常有大额在建工程抵押。审查动作：

1. 是否开立买方、卖方、监管行三方监管账户，户名/账号/开户行写明。
2. 首笔（或约定的解押专款）是否**仅能**用于清偿对应抵押权并办理注销。监管指令与抵押权人收款账户一致。
3. 后续款项是否在取得解押证明、涂销登记后再释放。
4. 出卖人一般结算户、集团户、个人卡收解押款或购房款：红线。
5. 用户或对方要求「先付一般户再去解押」：告知房财两空；买受人立场建议不付；协助设计体外循环：整体停止。

修改句骨架：买受人将【待填】解押款项付至【监管银行】【待填账号】（本项目整售资金监管账户）。该笔款项仅得向【抵押权人名称及账号】支付并办理对应不动产抵押注销。未取得注销证明前，监管银行不得向出卖人划付任何其他款项。

### 6.3 反担保

买受人提前支付大额解押款的，要求出卖人提供其他资产抵押或集团保证，担保范围覆盖解押款本金、利息、违约金和解除后的返还。无反担保：`必须改`（买受人立场）或至少提示（出卖人立场不得删除对方合理要求而不记录风险）。

### 6.4 定金

必须使用「定金」二字才讨论罚则。数额不得超过主合同标的额 20%，超过部分不产生定金效力。无核验引文不得把 20% 写成已核验法律结论。整售标的额巨大，修改句可把超额改为预付款并写明不适用罚则。

不动产不得约定所有权保留（买卖解释第 25 条）。出现「过户前所有权仍归卖方且排除预告登记」：必须改。

## 节点 7　格式条款、强制规范、税费结构

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 7.1 格式条款

开发企业重复使用的网签文本、补充协议，订立时未与对方协商的，是格式条款。主协议若由一方提供、未逐条商议，同样按格式条款审。不得仅以「用了示范文本」或「大宗交易所以不是格式条款」否认。

异常条款：放弃整栋解除、按现状交付、宣传仅供参考、部分履行、单方变更规划、最终解释权、领钥匙即验收。须有足以引起注意的标识并按要求说明。小字、夹在网签附件、仅勾选：不得写成已尽提示义务。

### 7.2 强制规范

违反法律、行政法规强制性规定不一律无效（通则解释第 16 条）。改变土地用途可能使出让合同被解除、整售无法履行，即使买卖合同本身不当然无效，签前仍是红线。查封、未领证等不得转让（房地产管理法第 38 条）不得用「双方确认无障碍」覆盖。

挂靠、违法分包、规避限购、伪造进场、体外循环解押：不改写成有效履行结构。

讨论「改走股权转让（SPV）避税」：本任务只提示资产交易与股权交易的税负和债务隔离差异，**不**在本技能设计股权收购结构；用户要改路径则转 `通过收购项目公司股权间接拿房→转` 或起草，不把本整售稿改成股权协议。

### 7.3 税费与发票

必须写清土地增值税清算主体、契税缴纳人、发票类型（增值税发票税目）。结构性陷阱：直接整售可能导致出卖人土地增值税极高——记录风险，给出「预沟通 + 承担主体 + 争议时中止过户」修改句，不输出税负测算结论。

## 节点 8　违约联动、排他期、物管与修改句成果闸

### 8.1 部分违约即整体违约

约定：因出卖人原因，任何一套或几套无法办理权属过户，或共有部分/冠名权无法按约移转，买受人有权解除**主协议及全部配套合同**，要求返还已付款及利息，并赔偿融资成本、设计招标费、前期物业介入费等实际损失（项目用 `【待填】` 列范围）。禁止「已过户部分保持有效、其余退款」而无买受人选择权。

逾期交付、逾期解押、逾期拆证、逾期过户须分别有日违约金和达到约定期限的整体解除权。只有「依法承担违约责任」视为必须改。

金融机构或基金买受人：可增加合规性解除——因政策变化无法完成整体收购时的退出与返还，不得写成「买方无条件弃权」。

本任务不作出已经解除的结论。

争议解决：不动产纠纷可能专属管辖，约定其他法院只标红旗并建议改为不动产所在地法院。或裁或诉、机构不明：改成单一机构或单一法院连结点。

### 8.2 排他期与物管

整售周期长，必须约定排他期（No-shop）：谈判或签约后至交割前，出卖人不得将其中部分房产散售、抵押新增负担或与第三方洽谈整售。违反则买方可解除并主张违约金。

物管：原开发商关联物业撤场、资料移交、前期物业合同解除的责任主体和日期。整售常更换物业，不写撤场视为交付未完成。

### 8.3 按框架六步出修改句

没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

打开已加载的 `框架.md`，按六步逐段对照。`基本面.md` 用于校验类型、主体、标的、程序、结构和红旗，不代替本节点出句。

| 步 | 本类型重心 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题定位主协议；整体性目的；资产现状（抵押/在建/租赁）；主体=土地权利人 | 标题/鉴于/主体修改句 |
| 交易条款 | 房号+共有部分+地下人防+冠名；包干价与拆分价；三方监管解押；整栋交付与风险转移 | 闭环修改句；缺数字 `【待填】` |
| 配套 | 部分不能过户=整体解除；租约处理；工程款；物管撤场；排他期 | 可执行后果句 |
| 尾部 | 国资进场/决议为生效条件；附件：明细表、共有部分图、出让合同、租约、决议 | 生效与附件修改句 |
| 语言 | 打包购买、不可分割之整体；物理交付≠运营权交付≠过户；删「按现状」「原则上」「尽力」 | 替换空词的句子 |
| 常见问题 | 土增税承担；先还款解押后分套过户；网签不得否定主协议 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（改变用途/未满自持、解押款进一般户、隐匿抵押或工程欠款、国资未进场仍要先付款、规避限购）
- `必须改`：可谈但签署前要落句（1+N 优先、共有部分附件、面积双红线、整体解除、租约通知或弃权、反担保、风险转移时点）
- `可接受可优化`：仍要给句子，不得只标绿

用户不可接受事项优先写成红线。生存级金额且用户拒绝升级：停止「可以签署」建议。
