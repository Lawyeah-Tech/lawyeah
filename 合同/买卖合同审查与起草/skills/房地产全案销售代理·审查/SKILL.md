# 房地产全案销售代理·审查

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现审查反例；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》委托章或买卖章及其解释、已失效《城市房地产中介服务管理规定》当作现行规则。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 任务目标

在单一立场下，只审查 **买卖合同 / 房地产全案销售委托代理合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文名必须是「审查房地产全案销售委托代理合同（买卖合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、把经销/行纪/一般委托/渠道代理/一般房销代理/商品房本约整案改完、把包销底价余房或无证先卖写成可履行结构。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **代理佣金非买断**：房源所有权不转给代理方，对价是佣金不是购销差价，滞销不构成代理方存货。买断再转售 → 负触发 `经销买卖合同·审查`。底价包死、余房由代理吃进或按包销结算 → 负触发 本套导航的类型切开步骤 重新定性，不得按全案佣金改完。修改句须写明以委托人名义销售、佣金对价、房源仍归委托人，并收回买断、包销和差价措辞。
2. **全案策划销售**：前场（市场调研、产品定位、价格策略、广告策划）+ 后场（驻场接待、带看、网签催款、按揭协助）必须同时可执行。只有引流报备、不驻场 → 负触发 `渠道销售代理·审查`。只有驻场卖房、无策划前场 → 负触发 `开发商委托驻场销售但不是渠道引流（权限含代销讲解网签）→`。概括处理事务、无具体楼盘驻场 → 负触发 `代签商品房买卖本约概括处理缔约事务→`。自己名义贸易、货权仍归委托人 → 负触发 `购房人终端订立本约，也不自负本约权利义务。以自己名义成交或先买后转→负触发`。
3. **与经销 / 行纪 / 一般委托 / 渠道代理切开**：用标题、核心给付和对价方式定性，不用标题单独定性。禁止两可时灌入两套知识。商品房买卖本约 → `一般商品房买卖合同·审查`（只分流，不抄该原子）。房屋买卖/租赁中介撮合 → `存量房买卖或租赁居间带看二手房→`。
4. **佣金闭环**：计取基数（网签总房款 vs 实际回款）与支付节点分列；“成交”须写成买受人签署网签版商品房买卖合同并支付首付款，认购未签约不得默认计为已销售。缺基数或把认购书当成交：必须改。
5. **推广费分离与禁止垫资**：广告投放由委托人直接付给第三方媒体，代理方策划执行、不垫付。文本要求代理垫资推广或大包干却无预算审批与返还：必须改或红线。费用沉默不得写成代理自担。
6. **预售、资质与统一口径**：未见预售许可或现售条件而约定对外销售：字段停止；用户坚持无证先卖、返本销售、售后包租、阴阳合同：停笔。经纪备案未见：字段停止。统一销售口径须经委托方法务书面签认；口头学区、户口、升学、返本不得写成可履行话术。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签全案营销代理、策划及销售代理正文，尚未签署，尚未成争，核心给付是就特定楼盘做策划并驻场销售、以委托人名义向购房人推介并收佣金，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 代理方买断房源或货权过户后再转售、赚差价、滞销不退 → `经销买卖合同·审查`；
- 自己名义对外成交、货权仍归委托人、对价是贸易报酬 → `购房人终端订立本约，也不自负本约权利义务。以自己名义成交或先买后转→负触发`；
- 概括处理事务、无具体楼盘、无驻场销售团队 → `代签商品房买卖本约概括处理缔约事务→`；
- 不驻场、只做渠道引流和客户报备 → `渠道销售代理·审查`；
- 只有驻场销售、无策划前场 → `开发商委托驻场销售但不是渠道引流（权限含代销讲解网签）→`；不得打开或改写该原子；
- 商品房买卖本约价款、面积、交付、过户 → `一般商品房买卖合同·审查`；不得打开或改写该原子；
- 只撮合买卖双方、自己不成交一方 → `存量房买卖或租赁居间带看二手房→`；
- 底价包销、余房吃进 → 本套导航的类型切开步骤 重新定性；
- 无文本、本类型条件已谈妥、要出己方稿 → `房地产全案销售代理·起草`；
- 已签只问结佣、对账、清场留痕 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

无证销售、返本销售、售后包租、阴阳合同、规避限购：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（开发商/委托人侧或全案代理方侧择一）；相对方；全文及底价表/任务书/结算流程/案场规范/委托书版本；对价是佣金还是差价/包销底价；是否含策划前场与驻场；独家及开发商自销是否付佣；佣金基数与成交定义；推广费谁付、是否垫资；预售证/现售条件与经纪备案痕迹；统一口径是否书面签认；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的佣金率、去化率、保护期、期限用 `【待填】`，不编造。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `房地产全案销售代理·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有全案代理文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。经销买断、行纪寄售、一般委托、渠道引流、无策划的一般房销代理、商品房本约、包销负触发。

### 2. 主体、委托书与资质

签约名、履行名、付款名、发票名分列。书面委托合同须载明期限和权限。预售许可或现售条件、经纪备案未见：字段停止。

### 3. 全案范围、独家与驻场

前场+后场清单、项目经理及核心策划团队、独家与自销是否付佣、驻场不混同为委托人用工。

### 4. 佣金闭环

基数、成交定义、结算节点、先票后款、退房扣回。认购未签约不得默认计为已销售。

### 5. 推广费与垫资

委托人直接付媒体；代理不垫资。大代理包干须有预算审批和返还。

### 6. 虚假宣传、格式条款与强制规范

统一口径书面签认。无核验引文则法律结论字段停止。

### 7. 任务考核、解除、保护期与清场

任务不达标可约定解除，但不得写放弃第 933 条且解除无效。保护期佣金与客户档案移交可执行。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把无证先卖/返本销售/售后包租/阴阳合同/包销底价余房改成可履行结构、坚持“放弃任意解除权且解除无效”。
- `字段停止`：法域、动态规则、预售证号、经纪备案、独家是否含自销付佣、佣金基数未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。

生存级预付款或个人无限连带且用户拒绝升级：停止“可以签署”建议。
