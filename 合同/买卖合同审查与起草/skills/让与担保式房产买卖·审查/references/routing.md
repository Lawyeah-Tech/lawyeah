# 边界与路由

本技能只审查 **买卖合同 / 让与担保式房产买卖合同**：以房屋买卖、网签、过户或回购的外观，为借款提供非典型担保的待签文本。

| 已能支持的事实 | 路由 | 不得写成 |
| --- | --- | --- |
| 待签、核心给付是房屋买卖外观＋借款担保、目标是评改该买卖文本 | 留本任务 | 已完成签约、已生效、真实买卖已成立 |
| 开发企业售其开发商品房，无借款/回购/回赎，买受人真实购房 | `一般商品房买卖合同·审查` | 用本技能的流质/清算句改真实预售；用五证/面积 3% 审本类型 |
| 业主出售存量房，价款为真实房价，无借贷担保 | `二手房买卖·审查` | 用户口、资金监管、阴阳网签价当本类型主路径 |
| 工程款抵房；开发商＋施工方/债权人＋买受人 1+N 结算 | `以房抵债工抵房·审查` | 把工程款折算、指定购房人、买受人向施工方付款改成本类型回购 |
| 送审主文件是借款合同/借据，买卖或过户只是从担保 | `送审主文件是《借款合同》或借据，买卖过户只是从担保安排→` | 用本技能把借款主文件当买卖审完 |
| 主轴是抵押权设立、抵押登记、抵押物处分 | `已办或拟办抵押权登记主轴是抵押条款→` | 把让与担保改成“先去办抵押就等同本类型已审完” |
| 真实销售并赋予转售或回购选择权，无借贷本金 | `附选择权转售权房产销售·审查` | 选择权销售当让与担保，或相反 |
| 名为其他合同、实为借贷，但不以特定房屋买卖/过户/网签作担保 | `或引擎；` 或 本套导航的类型切开步骤 | 无房担保的名买卖当本类型 |
| 类型未定或名实两可且缺乏担保信号 | 本套导航的类型切开步骤 | 两可时灌入买卖双文件或借款双文件 |
| 无可读正文，本类型条件已谈妥，要出己方稿 | `让与担保式房产买卖·起草` | 已经完成审查；在本审查原子出整稿 |
| 已签，问放款日、撤销网签日、回过户、租金支付留痕 | 本套导航的履约步骤 | 签前意见 |
| 已催告还款、请求直接过户归债权人、申请拍卖清算、立案、开庭、仲裁 | `或对应专项领域。` 或对应专项 | 继续当签前审查出修改句充作胜诉方案 |
| C 端大众快检 | 只分流，不回改 | 降成大众快检 |

挂靠、违法分包、规避限购、借名过户、查封房包装可过户、职业放贷/非法放贷外观：只告知违法风险，不改写成可履行文本。用户坚持改到能签：整体停止。

专业版未收录的 P1 场景不会安装本原子。若用户拿本类型文本来找专业版：输出 `unavailable`，提示，不得用 `一般商品房买卖合同·审查`、`二手房买卖·审查` 或 `以房抵债工抵房·审查` 硬套。
