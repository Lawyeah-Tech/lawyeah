# 让与担保式房产买卖·审查

## 任务目标

在单一立场下，只审查 **买卖合同 / 让与担保式房产买卖合同** 的待签文本：标题常是买卖，真实意思是为借款提供非典型担保。输出：名实定性、模式切开、风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他合同类型。场景分层为 **P1**。

`depends-on` 为空。不要求先跑导航。

不交付：真实商品房/二手房买卖整案、工抵房三方结算、借款主文件整案、抵押登记方案、从零起草、履约交底、争议文书、有效性或必然优先受偿/必然过户保证。

## 工作边界

正触发：已有可读待签文本要评改；尚未签署，尚未成争；核心给付是以房屋买卖、网签、过户或回购的外观，为已经发生或将要发生的借款提供担保。出卖人实质是债务人/借款人，买受人实质是债权人/出借人。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 房地产开发企业向社会销售其开发商品房，无借款担保意思，无回购/回赎，买受人真实购房 → `一般商品房买卖合同·审查`；
- 业主出售已取得或应取得的存量房产权，价款为真实房价，无借贷担保、无回赎 → `二手房买卖·审查`；
- 以工程款抵房，主体是开发商、施工方/债权人及买受人的 1+N 结算 → `以房抵债工抵房·审查`；
- 送审主文件是《借款合同》或借据，买卖/过户只是从担保安排 → `送审主文件是《借款合同》或借据，买卖过户只是从担保安排→`；
- 已办或拟办抵押权登记、主轴是抵押条款 → `已办或拟办抵押权登记主轴是抵押条款→`；
- 真实销售并赋予转售/回购选择权，无借贷本金 → `附选择权转售权房产销售·审查`；
- 名为其他合同、实为借贷，但不以特定房屋买卖/过户/网签作担保 → `或引擎；` 或引擎；
- 无文本、本类型条件已谈妥、要出己方稿 → `让与担保式房产买卖·起草`；
- 已签只问放款、撤销网签、回过户节点 → 本套导航的履约步骤；
- 已成争（催告还款、请求过户归债权人、拍卖清算诉讼、立案仲裁）→ `或对应专项领域。` 或对应专项。

挂靠、违法分包、规避限购、借名过户、职业放贷包装：只出告知，不改写成可履行结构。

专业版未收录本 P1 原子。专业版环境命中本类型：输出 `unavailable`，提示，不得用 `一般商品房买卖合同·审查` 或 `二手房买卖·审查` 硬套。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成。每一闸必须给出修改句或明确转出口径，禁止只打红黄绿。

1. **名买卖实担保（与真实买卖切开）**。标题写买卖不决定类型。同时出现借款/融资、回购或回赎、出卖人继续占有、价款显著低于市价、购房款实为放款本金中任两项，按本类型审，不得套五证/面积 3%/户口主路径。修改句必须把鉴于改成：因出卖人向买受人借款本金【待填】元，为担保该债权，双方办理网签/过户/预告登记；本安排性质为担保，买受人为名义权利人，不享有完整处分权。购房款改写为借款本金，并附件《借款协议》或借据、转账凭证。无借贷信号、买受人真实购房：负触发 `一般商品房买卖合同·审查` 或 `二手房买卖·审查`。
2. **禁止流质**。原文“债务到期不履行，房产直接归买受人所有”“自动转让”“逾期未回购则所有权确定归买受人”“买受人有权直接过户并不再清算”：红线。修改句删除归己所有，改为：买受人不得请求确认房屋归其所有；仅有权对房屋折价或拍卖、变卖，并就所得价款优先受偿。不得把流质写成整份买卖合同必然无效——流质约定无效，提供担保的意思仍可能有效。
3. **清算义务（多退少补）**。违约处置必须写清：评估后折价或拍卖、变卖；所得扣除约定本息及合理处置费用后余款返还出卖人；不足部分出卖人继续清偿。只写“依法处理/自行处置/直接抵债”视为未约定清算，必须改。债权人请求“直接履行买卖合同过户”的，提示现行规则按民间借贷审理，不得把本约改成可强制实际履行的真实买卖。
4. **与工抵房切开**。基础债是工程款、主体含开发商与施工方、出现三方结算/指定购房人/以房抵工程款：负触发 `以房抵债工抵房·审查`，不把工程款折算句改成借款回购。本类型基础债是借款本金；修改句不得引入施工方结算或买受人向施工方付款。
5. **与普通买卖 `一般商品房买卖合同·审查` / `二手房买卖·审查` 切开**。本任务禁止输出预售证五证表、面积误差 3% 全规则、先验房、学区入合同、户口迁出作为主路径。修改句只服务担保定性、模式、回赎、流质、清算、公示和利率。真实交房验收、学区、户口争议转对应买卖原子。

附加必落句（有事实则单列，无事实在缺口节说明）：

- **模式切开**：不转移产权＝网签/预告登记＋出卖人占有；转移产权＝过户＋回购/回租，买受人为名义所有权人。过户用“回购”，未过户用“撤销网签/注销预告”，不得混用。
- **回赎闭环**：本息清偿后【待填】日内，买受人必须配合撤销网签或过户回出卖人；逾期按【待填】/日或相当于租金的标准付违约金。正说必须有反说。
- **公示分层**：仅有协议＝普通债权，不得写优先受偿。仅网签备案＝管理动作，不写成已取得担保物权。预告登记＝限制再处分，须写 90 日转登记失效风险。过户到债权人名下且完成登记＝才可能参照担保物权优先受偿，仍须清算。修改句按实际模式写义务和未完成后果，不保证结果。
- **利率**：回购价−本金、资金占用费、回租租金折算年化，民间借贷不得超过合同成立时一年期 LPR 四倍；超额改到上限内或标明不受司法保护。出借人是持牌金融机构：利率字段停止，不套四倍。
- **定金**：本类型慎用“定金”。预扣利息、砍头息按实际放款额计本金，不得写成定金罚则。

必须有修改句。每个风险回链文本位置。

## 判断节点

以 [审查方法](references/method.md) 为准。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。交付按 [输出合同](references/output-contract.md)。边界见 [路由](references/routing.md)。

入口（细节以 method 为准）：

0. 签署状态分流：已起诉要过户或已违约清算 → 争议；无文本且本类型条件已谈妥 → `让与担保式房产买卖·起草`；已签只问节点 → 本套导航履约步骤。
1. 类型切开：工抵房、真实商品房/二手房、借款主文件、抵押、选择权销售先转出。
2. 名实：鉴于、主从合同、角色（债务人/债权人）、购房款＝本金。
3. 模式：网签/预告 vs 过户＋回购/回租；占有与出租；词汇回购/撤销。
4. 对价与利率：本金、回购价、租金、LPR 四倍、砍头息、定金。
5. 公示与回赎：网签/预告/过户义务、清偿后返还、逾期配合违约金。
6. 流质删除＋清算多退少补；买受人担保期间不得处分。
7. 格式条款、强制规范、限购/借名/职业放贷只告知。
8. 按框架六步出修改句。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验流质禁止、担保制度解释让与担保、民间借贷买卖担保与利率上限、虚假意思表示、预告登记、定金、格式条款；`search_practiced` 补名实识别反例；`search_template` 只借修改句栏目。不虚构案件系统。

`search_law` 对法律结论为 required 级：不可用时不拒绝执行，只停止效力、优先受偿、利率上限、格式条款是否不成为内容等法律结论字段。返回已失效《合同法》《担保法》《物权法》及其解释、2015 年 24%/36% 利率条时记为噪声，不得写入 `L#`。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；用户坚持伪造倒签、借名规避限购、把流质改成“能直接取得所有权”的可履行结构、把无证/查封房改成可过户担保、保证合同有效或保证优先受偿。
- `字段停止`：主债权金额或放款凭证未核；房屋权属/共有/抵押查封未核；是否完成网签或过户未核；出借人是否持牌金融机构未核；地方限购或网签规则未核。
- `目标停止`：主目标已变为从零起草、履约交底、争议/过户诉讼文书，或用户要把本约改成真实买卖以便请求实际履行。

生存级住房被设定让与担保且用户拒绝升级：停止“可以签署”建议。
