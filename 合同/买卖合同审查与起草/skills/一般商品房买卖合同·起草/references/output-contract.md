# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受、必然过户或必然入学；编造未给出的价格、面积、证号；把已失效《合同法》及其解释、已被删除的 2003 年商品房解释第 14 条写入结论。

## 1. 触发、单方立场与成果状态

立场（买受人或开发企业出卖人）、授权、签署状态、预售或现售、主要目标。负触发写路由，不启动实体审查。已网签后要解除：负触发转争议。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释或 2003 年商品房解释第 14 条时记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `买卖合同`，子级 `一般商品房买卖合同`。定性理由必须写清：出卖人是否房地产开发企业、标的是否该企业开发商品房、预售还是现售。易混切开结果必须点名是否排除二手房、经适房、工抵房。

加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。挂靠、规避限购、无证预售写停笔告知，不填可履行结构。

## 4. 主体、授权、资质、五证与文本版本

主体表：签约名、土地使用权人、预售证载明主体、履行名、**收款账户名**、发票名、授权签字人、买受人共有方式、抵押权人、监管银行。名称不一致不自动合并。

五证表（每证一行：名称｜证号或`G#`｜是否覆盖拟购房源｜与签约主体是否一致）：

- 国有土地使用证 / 不动产权证书
- 建设用地规划许可证
- 建设工程规划许可证
- 建筑工程施工许可证
- 商品房预售许可证（预售）或现售条件备案证明（现售）

版本表：正文、补充协议、附图、装修清单、分摊说明、宣传册/沙盘、聊天确认。冲突并列，不选对用户有利的一版。

## 5. 给付闭环（本类型必填）

固定回答，缺项标 `G#`，不补商业数字：

- 房号是否锁定到栋、单元、层、号并附平面图
- 建筑面积 / 套内面积 / 公摊是否分列
- **面积误差条款是否写全 3% 规则**（≤3% 据实；>3% 可退房；不退房时超出 3% 的价款负担；误差比公式）。只写“按规定”= 未闭合
- 土地用途与使用权终止日期
- 抵押、查封、预告登记：已披露 / 未披露 / 依据不足
- 收款账户是否预售资金监管账户（户名、账号、监管银行）
- 贷款失败是否区分可归责与不可归责双方
- 交付条件是否为竣工验收合格 + 两书，而非“综合验收”
- 是否约定先验房、书面异议后再签收
- 网签备案与预告登记的责任主体、期限、未完成后果
- 批准、登记、网签写成生效条件或期限，不写成已经完成

## 6. 格式条款、强制规范与宣传

是否构成格式条款；示范文本不排除格式条款；提示说明痕迹；免责、弃权、先收房后验、宣传仅供参考等异常条款。强制规范只区分是否导致民事行为无效。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

宣传/学区/配套：列出用户或材料中的具体允诺，标明是否已写入合同或附件。未写入且具体确定、影响订约或房价：必须改，不得只写“注意广告法”。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。级别不是成果：每一行必须有修改句或明确停笔/转出口径。禁止输出无修改句的色块表。

本类型默认应出现（有事实则单列，无事实则在缺口节说明未检出）：预售证/五证、面积 3%、监管账户、贷款失败、抵押披露、先验房、宣传未入合同。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点、不接受时的红线。未给出的商业数字用 `【待填】`，不编造。

面积条款的建议句必须包含 3% 全规则，不得以“依法处理”收尾。监管账户建议句必须写出“主管部门公布的该项目预售资金监管账户”，账号用 `【待填监管账号】`。

## 9. 谈判与签署提醒

谈判顺序：先红线（无证、非监管户、隐匿抵押、规避限购），再必须改（面积全规则、贷款失败、先验房、宣传入合同），最后可优化。

签署提醒：五证原件核对预售证范围；监管账户与预售证项目一致后再付款；授权委托书；网签时限；预告登记；不倒签；不指导先付款后补证。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本任务成果是可编辑草稿、未决项、自审风险表和自审后修改句。有完整待签文本要评改转 `一般商品房买卖合同·审查`。草稿必须落入本类型起草必写 / 附件必附 / 禁止出现。不是履约交底、争议文书、效力保证或学区保证。
