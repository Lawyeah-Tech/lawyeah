# 边界与路由

本技能只审查 **买卖合同 / 一般商品房买卖合同**（房地产开发企业预售或现售其开发的商品房）。

| 已能支持的事实 | 路由 | 不得写成 |
| --- | --- | --- |
| 待签、开发企业出售该项目商品房、目标是评改文本 | 留本任务 | 已完成签约或已生效 |
| 出卖人是业主/自然人，标的已办或应办存量房产权，中介带看，户口/迁出/户口本、原贷款结清过户 | `二手房买卖·审查`；该原子不可用则 本套导航的类型切开步骤 | 用本技能审二手房过户、户口、居间佣金 |
| 经适房、共有产权、工抵房、产权式酒店、定制销售、包销、让与担保式买卖 | 引擎重新定性或对应场景原子 | 硬套本类型五证/预售证 |
| 有完整待签文本要评改 | `一般商品房买卖合同·审查` | 在本起草原子做签前评改 |
| 无可读正文，本类型条件已谈妥，要出己方稿 | 留本任务起草并自审 | 已经完成起草；在本起草原子做签前评改 |
| 已签，问交房日、办证日、付款留痕、整改通知 | 本套导航的履约步骤 | 签前意见 |
| 已网签或已备案后要求解除、退房、索赔、起诉、仲裁 | `或对应专项领域。` 或新房退房/质量专项 | 继续当签前审查出修改句充作解除方案 |
| 只有认购书且用户要评估能否退房/罚定金（已付款成争） | 争议或认购书解除专项 | 在本任务宣布本约成立或定金双倍 |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 | 两可时灌入两套知识 |
| C 端大众快检 | 只分流，不回改 | 降成 029 快检 |

挂靠、违法分包、规避限购、无证预售、售后包租/返本销售：只告知违法风险，不改写成可履行文本。用户坚持改到能签：整体停止。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
