# 边界与路由

本技能只审查 **买卖合同 / 经销买卖合同** 的待签文本。中文展示名是「审查经销买卖合同（买卖合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 无区域、无独家、无年度指标的单笔设备或货物购销 | `动产买卖合同·审查`。不得把检验期、所有权保留当本类型默认主路径继续审 |
| 收佣金、以供应商名义向终端签约、存货不归对方；渠道销售委托代理 | `渠道销售代理·审查` |
| 房地产全案销售委托代理 | `房地产全案销售代理·审查` |
| 房地产销售代理 | `开发商委托驻场销售但不是渠道引流（权限含代销讲解网签）→` |
| 自己名义贸易、货权仍归委托人、滞销可退、对价是报酬 | `购房人终端订立本约，也不自负本约权利义务。以自己名义成交或先买后转→负触发` |
| 统一经营模式 + 特许经营费 + 经营手册，核心是特许资源许可 | 本套导航的类型切开步骤 重新定性。不得当普通经销放行 |
| 无文本、本类型条件已谈妥，要出己方稿 | `经销买卖合同·起草`；不得在本审查原子出稿 |
| 已签未争、只问订货/发货/对账留痕 | 本套导航的履约步骤 |
| 已成争或反垄断立案 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

经销正文里夹带一笔已锁定规格数量的单次供货附件：专条交接 `动产买卖合同·审查` 审该笔标的、交付与检验；买断身份、经销权、订单规则、转售价、窜货与许可条款可继续审。用户坚持本技能把代理、行纪、单笔购销或特许经营整案改完：`目标停止`。
