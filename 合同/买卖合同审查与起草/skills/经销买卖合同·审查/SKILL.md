# 经销买卖合同·审查

## 任务目标

在单一立场下，只审查 **买卖合同 / 经销买卖合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文名必须是「审查经销买卖合同（买卖合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、把销售代理/行纪/单笔动产买卖/特许经营整案改完、把固定转售价写成可履行违约结构。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **买断转售 ≠ 代理 ≠ 行纪 ≠ 单笔供货**：经销商买入再卖，赚差价、存货风险归己。收佣金、以供应商名义卖 → 负触发 `房地产全案销售代理·审查` / `渠道销售代理·审查` / `开发商委托驻场销售但不是渠道引流（权限含代销讲解网签）→`。自己名义贸易、货权仍归委托人 → 负触发 `购房人终端订立本约，也不自负本约权利义务。以自己名义成交或先买后转→负触发`。仅一笔设备购销无区域/独家/指标 → 负触发 `动产买卖合同·审查`。修改句须写明买断、货权转移节点和自负盈亏，并收回代签或寄售措辞。
2. **经销权范围**：区域、SKU、期限、独家/排他/普通必须写清。独家须定义供应商是否可自销、是否可再授权。不得把“独家”写成已经挡住供应商一切销售。
3. **框架+订单**：订单确认方式（签章/指定邮箱/ERP）。未确认订单不得写成已经成立。最低采购量与经销权维持、解除或降级条件可执行。
4. **转售价格**：建议价可以；固定转售价/最低限价触及反垄断 RPM 红线：必须改或红线，不得写成“必须按我方零售价销售否则违约”的可履行结构。
5. **窜货与保证金**：跨区销售违约金须可调整，禁止“天价且不得调整+任意没收全部保证金”。
6. **许可商品**：医疗器械、食品、危化等未见经营许可：签署/履行字段停止。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签经销、特约经销或买断分销正文，尚未签署，尚未成争，核心给付是经销商买断再转售并承担存货风险，通常带区域、SKU、期限或独家/指标，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 无区域、无独家、无年度指标的单笔设备或货物购销 → `动产买卖合同·审查`；不得把检验期、所有权保留当本类型默认主路径；
- 收佣金、以供应商名义向终端签约、存货不归对方 → `渠道销售代理·审查`（渠道销售委托代理）；房地产全案销售委托代理 → `房地产全案销售代理·审查`；房地产销售代理 → `开发商委托驻场销售但不是渠道引流（权限含代销讲解网签）→`；
- 自己名义贸易、货权仍归委托人、滞销可退、对价是报酬 → `购房人终端订立本约，也不自负本约权利义务。以自己名义成交或先买后转→负触发`；
- 统一经营模式 + 特许经营费 + 经营手册，核心是特许资源许可 → 本套导航的类型切开步骤 重新定性，不得当普通经销放行；
- 无文本、本类型条件已谈妥、要出己方稿 → `经销买卖合同·起草`；
- 已签只问订货、发货、对账留痕 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁或反垄断立案 → `或对应专项领域。` 或对应专项领域。

无证特许商品、通谋虚假价款、倒签规避许可：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（供应商侧或经销商侧择一）；相对方；全文及价格清单/SKU/指标/授权书版本；货权是否过户、滞销是否退货、对价是差价还是佣金；区域与独家定义（含供应商自销/再授权）；订单确认方式；转售价是建议还是强制；窜货金与保证金是否可调整；品类是否医疗器械/食品/危化及许可痕迹；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的出厂价、指标、保证金、期限用 `【待填】`，不编造。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`基本面.md` 中“RMP”按 RPM 理解；窜货“高额补偿金及没收保证金”不得写成不可调整。`框架.md` 不得把“区域代理分销”当默认标题，不得把独家写成即排他，不得把“货交第一承运人风险转移”当本类型默认主路径。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `经销买卖合同·起草`；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是评改已有经销文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。销售代理、行纪寄售、单笔供货、特许经营负触发。

### 2. 主体与许可

签约名、履行名、付款名、发票名分列。医疗器械、食品、危化未见许可：字段停止。无证仍要出货：停笔。

### 3. 经销权四要素

区域、SKU、期限、独家/排他/普通。独家补自销与再授权。

### 4. 框架+订单与指标

确认方式写死。未确认订单不成立。最低采购量与维持/解除/降级可执行。

### 5. 转售价、返利与结算

建议价可以。固定转售价/最低限价必须改或红线。

### 6. 窜货、保证金、格式条款与强制规范

违约金可调整。不得任意没收全部保证金。无核验引文则法律结论字段停止。

### 7. 库存、商标与终止善后

非质量退货或回购须书面。终止后停用品牌并处理库存。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把无证特许改成可履行出货、把固定转售价/最低限价写成可履行违约结构、把天价窜货金不得调整且任意没收全部保证金改成可履行。
- `字段停止`：法域、动态规则、许可文号、独家是否含自销、订单确认通道、RPM 安全港份额未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。

生存级预付款或个人无限连带且用户拒绝升级：停止“可以签署”建议。
