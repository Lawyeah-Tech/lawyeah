# 审查方法（锁定 买卖合同 / 物业服务合同（含前期物业服务合同））

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制商品房买卖、二手房买卖或房产租赁原子的 method。货架父级是买卖合同，法律性质是物业服务：不审房价、过户、五证、监管账户、租金或租期。

定性校验：标题、核心给付与本类型一致才继续；明显商品房、二手房、租赁或装饰装修承揽则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、业主必然受约束、盗窃必然全赔或必然免责、对方必然接受或唯一必得金额。

`search_law` 返回已失效《合同法》及其解释、1996 年《城市住宅小区物业管理服务收费暂行办法》、已废止《物业服务企业资质管理办法》、2009 年物业服务纠纷解释已删除条文、商品房买卖司法解释或担保法解释时记为噪声，不得写入 `L#`。物业服务解释引用 2020 修正、法释〔2020〕17 号、2021-01-01 施行文本。

示范文本只参考结构。住建或地方前期物业服务合同示范文本不证明本约条款已被接受。

知识库纠正（不回写双文件）：

- `基本面.md`“审查等级资质”：改为独立法人资格和地方信用信息；2018 年住建部令第 39 号已废止资质管理办法，不得把一级/二级资质证书当现行强制。
- `基本面.md`“物业不得随意辞聘、提前 60 日”：60 日主要对应业主共同决定解聘的通知期（第九百四十六条）；物业不同意续聘是届满前 90 日（第九百四十七条）。不得写成业主不能解聘。
- `框架.md` 招投标文号：住宅前期招标是硬闸；未备案不当然等于合同无效。
- 前期约束业主、服务承诺视为合同内容、公共收益归业主、禁止停水停电：采纳。

### 1.2 前期 / 普通切开（硬闸 1）

| 事实 | 委托方 | 对业主的效力 | 不得写成 |
| --- | --- | --- | --- |
| 建设单位与物业服务人订立 | 建设单位 | 依法订立的，对业主有约束力（第九百三十九条）；业主已入住仍约束至新合同生效（第九百四十条） | 业主未签字即当然无效；业主收房即可单方解除 |

## 节点 2　主体、住宅前期招标、资质改革

### 2.1 主体表

建表：委托方签约名、物业服务人签约名、收款账户名、发票名、授权签字人。名称不一致不自动合并。

前期：委托方应为该项目建设单位，并与销售主体对照；不一致标红旗。普通：业委会须经选举产生并备案，且持有业主大会选聘决议；未见决议：签署能力字段停止，不写“可以盖章”。单个业主不能代表全体签订共有部分物业服务合同。

物业服务人：核独立法人资格（2018 条例第三十二条）。口头“我们老板同意了”不得写成已授权。

### 2.2 资质改革（不得把过期资质当现行强制）

支持依据：住建部令第 39 号（2018-03-08）废止《物业服务企业资质管理办法》；2018 条例第三十二条改为独立法人 + 行业诚信管理。

| 文本写法 | 动作 |
| --- | --- |
| 要求出示一级/二级资质证书否则合同不生效 | 必须改：改为独立法人营业执照；可补充地方信用信息公示查询，不把旧资质等级当生效条件 |
| 完全不写主体资格 | 必须补：乙方为依法设立的企业法人或其他管理人，并提供营业执照复印件作为附件 |
| 用户以“没有物业资质所以必然无效”要求放行拒签以外的效力结论 | 效力字段：依据不足或现有依据不支持“无旧资质证书即当然无效”；另审招标、转委托、格式条款 |

地方仍要求信用备案或项目经理信息公示的，标 `G#`，运行时核验，不编造全国统一备案文号。

### 2.3 住宅前期招标（硬闸延伸）

支持依据：2018 条例第二十四条、第五十六条。住宅物业的建设单位应当通过招投标选聘；投标人少于 3 个或住宅规模较小的，经物业所在地区、县人民政府房地产行政主管部门批准，可以采用协议方式。未招标且未经批准协议选聘：行政机关可责令改正、警告、并处 10 万元以下罚款。

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 已附中标通知、招标备案或批准协议选聘文件，且范围覆盖本项目 | 写入鉴于；可接受或可优化 | 已经行政合法的终局结论 |
| 住宅前期，材料未提及招标或批准 | 字段停止；修改句要求作为附件；不写“可以签” | 未招标不影响，先签后补 |
| 住宅前期，用户或材料支持应招标而未招标、又无批准 | 红线；建议缓签或改走招标/批准后再签 | 改成可履行的私下协议选聘 |
| 非住宅，或规模是否属于“较小”未核 | 地方阈值 `G#`；不编造 | 全国一律免招标 |
| 普通合同（业委会选聘） | 招标闸不适用；改核业主大会决议 | 再要建设单位招标 |

2018 现行第二十四条已无“具有相应资质”。不得引用 2003 旧句把资质证书写成招标前置。

## 节点 3　服务区域、服务内容可核验、秩序≠保管

### 3.1 区域与共有部分

坐落、四至、总建筑面积、物业管理区域图。共用部位、共用设施设备清单作为附件：屋面、外墙、大堂、电梯、供电、给排水、消防、监控、绿化。只有“等物业服务”视为标的不确定，必须改。

专有部分室内维修属于有偿特约服务，不得混入物业费包干范围，除非个别业主另行委托。

### 3.2 服务内容量化（硬闸 2）

支持依据：第九百三十七、九百三十八、九百四十二条。合同一般包括服务事项、质量、费用、维修资金、服务用房、期限、交接。公开有利于业主的服务承诺为合同组成部分。

审查清单：

1. 公共部位与电梯：巡检、维保周期，完好率或故障响应时限。
2. 环境卫生：保洁频次（如楼道【待填】次/日，垃圾清运【待填】次/日）。
3. 绿化、消防、车辆停放：标准和责任边界。
4. 秩序维护：巡逻频次、出入口值守、监控保存期限。
5. 地方服务等级（一级/二级/三级）如采用，须附标准文本，禁止只写“符合国家标准”。

原文“提供物业管理服务”“管家式服务”而无附件：必须改，把可核验频次写入附件，并约定公开承诺（销售案场、公示牌、公众号）高于本合同的部分视为合同内容。

### 3.3 秩序维护 ≠ 保管（硬闸 2）

支持依据：第九百四十二条“合理措施”；条例第三十五条“相应的法律责任”。物业服务人不是业主室内财产的保管人。

| 文本写法 | 动作 | 不得写成 |
| --- | --- | --- |
| “秩序维护、安全防范、门岗巡逻”，无全赔 | 可接受；补量化频次和过错责任 | 已免除一切责任 |
| “业主或使用人财物被盗、车辆损坏，物业全额赔偿” | 必须改或红线：删除结果责任全赔；改为未尽约定秩序维护和合理措施、有过错的，依法承担相应责任 | 保管合同；盗窃即全赔 |
| “任何人身财产损失概不负责” | 红线删除：与第九百四十二条、条例第三十五条冲突的格式免责不得放行 | 已合法免责 |
| 车辆停放写成“保管合同、丢车全赔”或“只提供车位、任何损失免责” | 必须改：区分车位使用与保管；未特别约定保管的，按秩序维护和场地管理的过错责任写 | 当然保管或当然免责 |

修改句：`乙方提供的秩序维护服务不构成对业主专有部分财产的保管。乙方应当按附件约定的巡逻、门岗和监控标准采取合理措施维护基本秩序。因乙方未按约定履行前述义务造成业主损失的，乙方承担相应赔偿责任；非因乙方过错造成的第三人侵权或意外事件，乙方不承担保管人责任。`

最强反方“交了物业费丢了东西当然全赔”：现有依据不支持将秩序维护等同保管；未履约有过错仍应赔，但不是结果责任。

## 节点 4　计费：包干制 / 酬金制、面积、空置、调价

### 4.1 必须选定计费模式（硬闸 3）

支持依据：收费办法第九、十一条（官方公开来源核验；运行时再核）；第九百四十三条。

- **包干制**：业主支付固定物业服务费用，盈亏由物业服务人享有或承担。构成一般包括服务成本、法定税费和利润。
- **酬金制**：在预收的物业服务资金中按约定比例或数额提取酬金，其余用于合同约定支出，结余或不足由业主享有或承担。预收的物业服务支出属于代管性质，为交纳的业主所有，不得用于约定以外支出。应当向业主大会或全体业主公布年度预决算，每年不少于一次公布收支；业主或业主大会质询应及时答复。可以约定聘请专业机构审计。

| 文本写法 | 动作 |
| --- | --- |
| 已写包干或酬金之一，且酬金制有公示审计 | 核面积、标准、调价 |
| 未写包干或酬金，或两种并列未选定 | 必须改：选定一种；缺数字用 `【待填】` |
| 酬金制无代管、公示、审计 | 必须改：补收费办法第十二、十三条结构 |
| “物业有权根据经营需要随时调整收费标准” | 必须改或红线：调价须按政府指导价浮动或经业主共同决定，并书面通知；禁止单方随时调价 |
| 预收三年以上物业费 | 必须改：缩短预收周期；解释（2020修正）第三条——终止后预收未提供期间应退还 |

无核验引文不得把收费办法条号写成已核验 `L#`；修改句草稿仍按上列结构给出。

### 4.2 计费面积与空置

计费面积须写明建筑面积或套内建筑面积，并与测绘或买卖合同口径对照；冲突并列。禁止只写“按有关规定”。

空置/未交付：收费办法第十六条、条例第四十一条——已竣工尚未出售，或因建设单位原因未按时交给买受人的，由建设单位全额交纳。不得把开发商未售房写成“空置一律免收”。已交付未入住的业主空置折扣可约定（如【待填】折），但不得与未交付的建设单位义务混写。

修改句：`物业服务费按【建筑面积/套内建筑面积】【待填】元/月·平方米计收，计费面积以【测绘报告/不动产登记】载明为准。计费方式为【包干制/酬金制】。已竣工尚未出售或因建设单位原因未交付的物业，物业服务费由建设单位全额交纳。已交付但业主未入住的，按【待填】计收。`

### 4.3 日常维修 vs 专项维修资金

共用部位、共用设施设备的大修、中修和更新、改造费用应当通过住宅专项维修资金列支，不得计入物业服务成本或支出（收费办法第十一条；条例第五十三条；维修资金管理办法第九条）。合同须切开：物业费覆盖日常运行维护；维修资金使用按法定程序，物业服务人不得自行挪用。

## 节点 5　期限、前期衔接与业主解聘

### 5.1 前期期限（硬闸 4）

支持依据：第九百四十条；条例第二十六条。前期可以约定期限，但期限未满、业主委员会或业主与新物业服务人订立的合同生效的，前期合同终止。

| 文本写法 | 动作 | 不得写成 |
| --- | --- | --- |
| 至“业委会或业主与新物业服务人订立的合同生效之日”，可另写最长不超过【待填】年 | 可接受 | 已经没有真空风险 |
| 固定截止日期，无新合同衔接 | 必须改：到期日与新合同生效日以先发生为准；到期仍未选聘的，按第九百四十八条不定期+六十日通知，或按第九百五十条交接前继续服务并收费 | 放任真空 |
| “永久有效”“至开发商书面同意终止”“业主不得解聘” | 红线：删除永久和单方锁死；补 940 衔接和 946 解聘 | 前期可以排除业主更换权（与第二百八十四条冲突） |

修改句：`本合同服务期限自【待填】起，至业主委员会或者业主与新物业服务人订立的物业服务合同生效之日终止。如该生效日晚于【待填】，双方可按民法典第九百四十八条处理不定期服务，任何一方解除应提前六十日书面通知。本合同不排除业主依照法定程序共同决定解聘物业服务人。`

### 5.2 业主解除与物业不续聘

支持依据：第九百四十六条、第九百四十七条。业主依法定程序共同决定解聘的，可以解除；提前六十日书面通知，另有约定除外；除不可归责于业主的事由外应赔偿损失。物业不同意续聘：届满前九十日书面通知，另有约定除外。

合同排除业主共同决定解聘、或把解聘赔偿写成“剩余期限全额物业费必得”：必须改。本任务不作出已经解除的结论，不写诉讼策略。

## 节点 6　催费、撤场交接、停水停电

### 6.1 催费路径

支持依据：第九百四十四条。业主应按约支付；已按约定和有关规定提供服务的，业主不得以未接受或无需接受为由拒付。逾期：催告合理期限 → 起诉或申请仲裁。**不得采取停止供电、供水、供热、供燃气等方式催交。**

| 文本写法 | 动作 |
| --- | --- |
| 催告 + 诉讼/仲裁；滞纳金日万分之【待填】 | 可接受或核是否过高；不在本任务精算 |
| “有权停水、停电、停梯、锁门、限制出入直至结清” | 红线删除停水停电停热停气；停梯/锁门限制通行一并删除或改为不得危及基本生活和消防 |
| “业主未在异议期内书面异议即视为服务合格、不得抗辩欠费” | 必须改：保留催告和异议记载；不因沉默视为服务达标 |

修改句：`业主逾期未支付物业费的，乙方应书面催告并给予不少于【待填】日的合理期限；期满仍不支付的，乙方可以依法提起诉讼或者申请仲裁。乙方不得采取停止供电、供水、供热、供燃气或者其他危及业主基本生活、消防安全的方式催交物业费。`

### 6.2 撤场交接（硬闸 5）

支持依据：第九百四十九条、第九百五十条；条例第二十九条、第三十七条、第三十八条。终止后应在约定期限或合理期限退出，交还物业服务用房、相关设施和必需资料，配合新物业交接并如实告知使用管理状况。违反的，不得请求终止后物业费；造成损失应赔偿。接管前应继续处理事项并可请求该期间物业费——这是防止真空，不是拒不撤场的借口。

交接清单至少包括：物业服务用房及钥匙权限；竣工验收及设施设备资料；业主名册及装修登记；公共收益账目及结余；住宅专项维修资金相关材料及配合办理手续；监控等数据移交与删除方案。

| 文本写法 | 动作 |
| --- | --- |
| 有退出期限、资料清单、公共收益和维修资金材料 | 可接受；补违约后果 |
| “业主欠费未结清的，乙方有权拒绝退出并继续管理” | 红线：欠费走催告诉讼；不得以欠费拒绝第九百四十九条退出 |
| 无交接条款 | 必须改：按上列清单补全；退出日【待填，参考 15–30 日】 |

修改句：`本合同终止后，乙方应在【待填】日内退出物业服务区域，向业主委员会、决定自行管理的业主或其指定的人交还物业服务用房、相关设施、本条例第二十九条所列资料、公共收益账目及结余、住宅专项维修资金相关材料，配合新物业服务人交接并书面告知物业使用和管理状况。乙方不得以业主欠交物业费为由拒绝退出。乙方违反本条的，不得请求业主支付合同终止后的物业费，并赔偿因此造成的损失。在新物业服务人或自行管理接管前，乙方应继续处理物业服务事项，并可以请求该期间的物业费。`

## 节点 7　公共收益、格式条款、强制规范

### 7.1 公共收益（硬闸 6）

支持依据：第二百八十二条；收费办法第十八条；区分所有权解释（2020修正）第十四条。利用共有部分产生的收入，扣除合理成本后属于业主共有；主要用于补充专项维修资金，或按业主共同决定使用。成本及其合理性由行为人举证。

| 文本写法 | 动作 |
| --- | --- |
| 广告、场地、车位经营收益归全体业主，扣除成本后入账，每半年（或按 943）公示 | 可接受 |
| “电梯广告、外立面、地面车位收益归物业所有/作为物业经营收入” | 红线或必须改：改为业主共有；物业可计合理成本，不得默认归属物业 |
| 有经营无公示 | 必须改：并入第九百四十三条公开事项 |

修改句：`利用电梯轿厢、外立面、公共场地停车等业主共有部分产生的收入，在扣除合理成本后属于全体业主共有，优先用于补充住宅专项维修资金，或按照业主共同决定使用。乙方应单独建账，按第九百四十三条向业主公开，并在本合同终止时将账目和结余随交接移交。乙方对成本支出及其合理性承担举证责任。`

### 7.2 格式条款与强制规范

为重复使用而预先拟定、订立时未与对方协商的前期或物业企业文本，按民法典第四百九十六条至第四百九十八条审查提示说明。免责、单方调价、排除解聘、停水停电、最终解释权须有足以引起注意的标识。小字、夹在附件、仅网络勾选：不得写成已尽提示或说明义务。无核验引文则法律结论字段停止。

违反法律、行政法规强制性规定不一律无效。禁止用已失效“效力性/管理性”口诀代替合同编通则解释第十六条。全部转委托（第九百四十一条、条例第三十九条）、停水停电催费（第九百四十四条）、伪造招标：不改写成有效履行结构。

2009 解释第二条（全部转委托合同无效、免责条款无效）已被删除：全部转委托改走第九百四十一条禁止 + 修改句删除；免责条款走 496–497，不引用已删除条文。

### 7.3 数据与禁止违法限制业主权利

人脸识别、车辆轨迹：须有目的限制、保存期限、不得对外提供；数据不属于物业所有。禁止无法律或规约依据限制业主出租、特定装修（第九百四十五条是告知，不是禁租）。

争议解决：或裁或诉、机构不明标待核。不动产所在地连结点只标红旗，不选定唯一法院充作意见。
