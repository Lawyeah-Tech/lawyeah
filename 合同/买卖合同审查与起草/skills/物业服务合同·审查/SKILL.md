# 物业服务合同·审查

## 任务目标

在单一立场下，只审查 **买卖合同 / 物业服务合同（含前期物业服务合同）** 的待签文本，输出：前期/普通切开、风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他合同类型。场景分层为 **P0**。中文 display_name 必须是「物业服务合同·审查」。

货架父级在买卖合同下，法律性质是物业服务，不是房屋买卖。禁止写成商品房审查换标题。

`depends-on` 为空。不要求先跑导航。

不交付：商品房/二手房审查、房产租赁审查、装饰装修承揽审查、从零起草、履约交底、争议文书或诉讼策略、有效性保证。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成：

1. **物业服务 ≠ 商品房买卖 ≠ 租赁**。不审房价、过户、五证、监管账户或租金、押金、租期。前期合同委托方是建设单位，对业主有约束力；普通物业合同委托方是业主大会/业委会。业主已入住仍受前期合同约束，直至业主委员会或业主与新物业服务人订立的合同生效。修改句须写明委托方、约束范围和第九百四十条衔接。
2. **服务内容可核验**。公共部位、电梯维保、保洁频次、秩序维护必须量化到附件。禁止把物业写成对业主室内财产的保管人，禁止“区域内失窃全额赔偿”。秩序维护 ≠ 保管。修改句改为共有部分秩序维护和合理措施，并保留未履约时的相应过错责任。
3. **计费必须选定**。包干制或酬金制只能择一写入。酬金制须约定预收资金代管、年度预决算公示、每年不少于一次收支公布和可审计。收费面积口径（建筑面积或套内）与空置/未交付折扣（建设单位未售未交应全额交纳）写清。格式“物业有权随时调价”必须改。
4. **前期期限接到新合同生效之日**。避免服务真空。禁止无限期前期且排除业主依法共同决定解聘。修改句：本合同至业主委员会或业主与新物业服务人订立的物业服务合同生效之日终止；业主依照法定程序共同决定解聘的，提前六十日书面通知后可以解除。
5. **撤场交接**。合同终止后物业服务人应在约定期限或合理期限退出，交还物业服务用房、相关设施、竣工与设施资料、公共收益账目和维修资金相关材料，配合交接。禁止“不结清即拒不撤场并停水停电”。修改句删除停水停电自助，改为催告后依法起诉或申请仲裁；拒不退出不得请求终止后物业费。
6. **公共收益归业主共有**。电梯广告、外立面、地面车位等利用共有部分的经营收入，扣除合理成本后属于业主共有，入账公示，优先用于补充专项维修资金或按业主共同决定使用。不得默认归物业。

住宅前期依法应招标而未招标、又不能出示区县房地产主管部门批准协议选聘文件：红线或字段停止。已成争（欠费诉讼、解聘纠纷）转物业争议，不写诉讼策略。

必须有修改句。禁止只打红黄绿。每个风险回链文本位置。

## 工作边界

正触发：已有可读待签前期物业服务合同或物业服务合同正文，尚未签署，尚未成争，核心给付是共有部分物业服务换物业费，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 核心给付是房地产开发企业出售新房并过户换价款 → `一般商品房买卖合同·审查`，禁止用本技能或商品房 method 反过来审物业，也禁止把本技能改成五证/面积 3%/监管账户审查；
- 核心给付是业主出售存量房过户 → `二手房买卖·审查`；
- 核心给付是房屋占有使用换租金 → `核心给付是房屋占有使用换租金→`，禁止套二十年租期、押金定金、买卖不破租赁；
- 核心给付是室内装饰装修制作过程换工程款 → 装饰装修承揽对应原子；未装则 本套导航的类型切开步骤；
- 无文本、本类型条件已谈妥、要出己方稿 → `物业服务合同·起草`；
- 已签只问催费节点、公示留痕、报修流程 → 本套导航的履约步骤；
- 已成争（催告、解除、欠费诉讼、解聘纠纷、索赔、仲裁）→ `或对应专项领域。` 或 C 端 `或C端`；维修资金使用已成争 → `维修资金使用已成争→`。不写诉讼策略。

挂靠、全部转委托、伪造招投标、规避业主共同决定：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（建设单位 / 业委会或业主大会 / 单个业主 / 物业服务人）；相对方；全文及附件版本；前期还是普通；住宅还是非住宅；招标或批准协议；计费模式与面积口径；服务内容与频次；公共收益；期限与交接；不可接受事项；法域与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的单价、面积、酬金比例用 `【待填】`，不编造。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。禁止打开商品房或房产租赁 method。`基本面.md` 中“等级资质”按 method 纠正为独立法人+信用信息，不把过期资质证书当现行强制。

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `物业服务合同·起草`；已签履约/催费留痕 → 本套导航履约步骤；已成争 → 争议或物业争议专项。未签且目标是评改已有物业服务文本，才进入本任务。

### 1. 类型锁死与前期/普通切开

标题、核心给付与物业服务一致才继续。商品房、二手房、租赁、装修承揽负触发。前期=建设单位委托；普通=业主大会选聘、业委会签约。

### 2. 主体、招标、资质改革

建设单位或业委会授权；物业服务人独立法人；住宅前期招标或经批准协议；不得要求出示已废止的资质等级证书。

### 3. 服务内容可核验

共有部分清单、电梯、保洁频次、秩序维护量化；公开承诺入合同；秩序≠保管。

### 4. 计费

包干或酬金选定；面积口径；空置/未交付；禁止随时调价；酬金制公示审计。

### 5. 期限与解聘

前期接到新合同生效；保留 946 共同决定解聘；禁止永久前期。

### 6. 撤场、停水停电、公共收益

退出交接清单；删除停水停电；收益归业主共有并公示。

### 7. 格式条款与强制规范

提示说明；全部转委托红线；维修资金不得计入日常物业费成本。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持伪造招标、停水停电自助、拒不撤场、把公共收益改成物业固有收入、保证有效或保证业主必然败诉。
- `字段停止`：住宅前期招标/批准协议未核验；地方指导价或信用备案未核验；业委会决议未见。
- `目标停止`：主目标已变为从零起草（转 `物业服务合同·起草`）、履约交底、争议文书或商品房/租赁整案。

生存级预收多年物业费或个人无限连带且用户拒绝升级：停止“可以签署”建议。
