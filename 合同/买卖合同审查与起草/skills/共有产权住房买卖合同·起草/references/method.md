# 审查方法（锁定 买卖合同 / 共有产权住房买卖合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制普通商品房五证清单、面积误差百分之三、逾期办证九十日主路径，禁止复制经济适用房划拨补缴土地出让金上市主路径。

定性校验：标题、核心给付与本类型一致才继续；普通商品房全产权、经适房补出让金、普通存量二手、担保回购、抵债或中介明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、必然转为商品房全产权、对方必然接受或唯一必得金额。

`search_law` 返回已失效《合同法》《物权法》及其解释、担保法解释时记为噪声，不得写入 `L#`。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突；无法独立核验施行日则该规则字段停止。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。商品房预售或存量房范本只证明是另一类型，不得当作本类型范本。上海、广州等地共有产权示范文本中的“满五年”只证明该地栏目存在，不得写成全国法定期限。

知识库纠正（不回写双文件）：

- `基本面.md` “五年禁售期”：不是全国法律、行政法规固定期限。修改句写 `【待填】` 年，并指向房屋所在地共有产权住房管理办法。
- `基本面.md` “60%/40%”：示例，非法源。
- `基本面.md` “使用权归购房人独立享有”：不得写成可自由出租或可单方设立居住权。
- `框架.md` “满五年购买政府份额转为商品房”：地方可能路径之一，不是唯一出口，不得保证必然转成。
- `框架.md` 土地“出让”相对经适房“划拨”：典型区分；合同写划拨+补出让金则负触发 `经济适用房买卖合同·审查`。
- 民法典第 309 条等额规则不得用来填政策性份额空白。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。封面写商品房、正文有代持份额和资格附件：按核心给付留在本类型，标题必须改。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 共有产权住房；购房人与政府指定代持机构按份共有；价款对应购房人份额 | 本类型 | 正触发 |
| 开发商销售完整产权商品房，无政府代持份额 | 一般商品房 | 负触发 `一般商品房买卖合同·审查` |
| 经济适用房、已购公房；划拨土地；上市以补缴土地出让金换全产权 | 经济适用房 | 负触发 `经济适用房买卖合同·审查` |
| 个人转让普通存量商品房，无代持份额 | 二手房存量 | 负触发 `二手房买卖·审查` |
| 买卖加回购或过户为担保 | 让与担保式买卖 | 负触发 `让与担保式房产买卖·审查` |
| 以房抵工程款或债务 | 以房抵债 | 负触发 `以房抵债工抵房·审查` |
| 报酬绑在促成签约、带看、媒介 | 房屋中介 | 负触发 `存量房买卖或租赁居间带看二手房→` |

支持切开的规范（法律结论须运行时复核）：

- 第 595、597 条：买卖是转移标的物所有权换价款；限制转让的标的物依照其规定——本类型转移的是购房人份额，不是完整商品房所有权。
- 第 298、301、308、309 条及物权编解释（一）第 10–12 条：按份共有、处分同意、份额转让与优先购买。
- 城市房地产管理法（2019 修正）第 38、41 条：共有未经其他共有人书面同意不得转让；合同应载明土地使用权取得方式。
- 商品房买卖合同解释（2020 修正）第 1 条、商品房销售管理办法：商品房销售规则，**不得当本类型默认主法**。
- 已购公有住房和经济适用住房上市出售管理暂行办法：经适房/已购公房路径，**负向切开**。

### 1.3 与经适房 / 商品房切开（硬闸）

| 文本写法 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 无代持、无政府份额、买受人取得完整产权 | 负触发 `一般商品房买卖合同·审查` | 删掉商品房条款后按本类型改完 |
| 划拨土地；满一定年限补缴土地出让金后完全产权；无按份登记 | 负触发 `经济适用房买卖合同·审查` | 把补出让金写成共有产权的标准退出 |
| 共有产权，但夹带面积误差百分之三、五证齐备即可放行、逾期办证九十日等商品房专条 | 可点名质量/交付风险，**不得做成主路径** | 用商品房解释替代份额、资格、转让限制 |
| 已取得共有产权证的家庭转让自身份额给另一符合条件家庭 | 正触发再上市；走节点 4 | 按普通二手 `二手房买卖·审查` 改完 |

最强反方：相对方主张“反正都是买房，按商品房审即可”。现有依据不支持把无政府份额的完整产权销售留在本任务。

### 1.4 虚假资格 / 借名 / 规避限购 / 自由上市停笔（硬闸）

加载后或定性中出现：借用他人社保户籍资格；先按全产权签约再补代持；伪造资格审核文件；为规避限购或保障资格就同一房屋签不同文本；把共有产权改成可自由上市的商品房结构。

动作：

1. 交付告知：可能因违法或违背公序良俗无效（第 153、154 条）；骗购通常触发代持强制回购。不得改写成可履行借名、假资格或自由上市结构。
2. 不写可履行的资格借用路径、体外全产权过户或“先签后改份额”。
3. 风险表只保留识别依据和删除/转出口径。
4. 用户坚持“改到能签且仍做这些事”：整体停止。

## 节点 2　三方主体、资格与授权

### 2.1 主体表

建表：签约名、履行名、付款名、发票名、授权签字人。名称不一致不自动合并。

必须分列三方：

| 角色 | 典型名称 | 不得写成 |
| --- | --- | --- |
| 出卖人 | 房地产开发建设单位，或再上市的原购房家庭 | 代持机构是买房付款人 |
| 买受人 | 经审核的保障对象或其家庭成员 | 资格未核即可购买 |
| 代持机构 | 政府指定的保障房运营管理企业，代表政府持有份额，**不支付购房款** | 普通担保人或见证人；缺席仍可过户 |

缺丙方作为合同当事人签章，或仅在备注出现名称：该签署能力字段停止。修改句：

「丙方【代持机构全称】作为政府产权份额的代持人加入本合同，持有【待填】% 份额，不支付购房款。未经丙方签章，各方不得申请将本房屋登记为买受人单独所有，也不得主张已具备转移登记条件。」

口头“代持那边点头了”不得写成已授权。再上市时，原购房家庭处分自身份额仍须有丙方书面征询记录。

### 2.2 资格（硬闸）

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 无资格审核通过文件、无主管部门查询页 | 字段停止；修改句要求作为附件 | 可以购买；口头说过即已审核 |
| 资格文件姓名、家庭成员与签约人不一致 | 并列冲突；签署能力字段停止 | 自动视为同一家庭 |
| 用户承认借用他人材料或借名 | 停笔告知；不改成可履行 | 过户后再更正即可 |

修改句：

「本合同签署前，乙方应向甲方和丙方出示并作为附件一：房屋所在地主管部门出具的共有产权住房购房资格审核通过文件或官方查询页，载明家庭成员与份额权利人一致。口头说明或销售承诺不视为已完成资格审核。资格被撤销或经查系虚假申报的，丙方有权按本合同约定启动回购，乙方不得请求继续过户。」

部门规章或地方规范性文件的资格管理，不当然导致民事合同无效（解释第 16 条）。本任务只停止“可以购买”表述，不宣告合同当然无效。

## 节点 3　份额、价款与登记（硬闸）

审查清单，缺一项则该字段不得写成已闭环：

1. 产权性质写明“共有产权住房”，登记为“按份共有”。
2. 乙方份额【待填】%、丙方份额【待填】%，二者合计 100%。
3. 乙方应付购房款只对应其份额；另列房屋销售均价或全额参考价，作为回购和再上市基准。
4. 土地取得方式写“出让”并受政策性限制；写“划拨”则回到节点 1.3。
5. 使用权归购房人家庭自住；物业费、专项维修资金、取暖费由购房人承担全部，不按份额分摊给代持——须明示，避免被理解成代持也要缴物业。

| 文本写法 | 动作 |
| --- | --- |
| 只写“双方共有”无比例 | 红线或必须改。禁止引用第 309 条写成等额 |
| 价款写成房屋全价，买受人取得全部产权 | 红线。拆成份额价款 + 全额参考价 |
| 正文份额与附件价款表冲突 | 并列，不选有利版；修改句指定以份额条款为准并改正附件 |
| “未办登记合同无效” | 必须改。第 215 条：未办登记不影响合同效力；登记仍是物权变动条件 |

修改句：

「本房屋为共有产权住房。乙方持有【待填】% 产权份额，丙方代表政府持有【待填】% 产权份额。乙方支付的购房款人民币【待填】元仅对应其持有的上述份额；本合同载明的房屋全额参考价为人民币【待填】元，作为回购、再上市及增值分配的计算基准，不表示乙方已购买全部产权。各方应申请将不动产登记为按份共有并分别记载份额。未办理登记不影响本合同效力，但不发生物权变动。」

定金：必须使用“定金”二字才讨论罚则。约定或推算超过**购房人应付份额价款**百分之二十：超过部分不产生定金效力（第 586 条）。不得以全额参考价做基数抬高定金。无核验引文不得把 20% 写成现行法结论。

开发商初次销售时，质量、交付、保修可按普通房屋买卖点名缺口，但不得用面积误差百分之三或逾期办证九十日替代本节点。

## 节点 4　转让限制与退出（硬闸）

支持依据：第 305 条及物权编解释（一）第 9–12 条（按份共有人优先购买）；第 597 条（限制转让依照其规定）；城市房地产管理法第 38 条（共有未经书面同意不得转让）。禁售年限、再上市对象、是否允许购买政府份额，以房屋所在地共有产权住房管理办法为准，未核则字段停止。

| 文本写法 | 动作 |
| --- | --- |
| 取得产权证后可自由转让，无需代持同意 | 红线删除 |
| 写死“五年”且称为法定期限 | 必须改：年限 `【待填】`，来源为地方办法，不写“法定五年” |
| 满期后可任意出售给市场买家 | 必须改：受让人须符合共有产权住房购买条件，或由丙方回购；不得写成普通商品房上市 |
| 禁售期内因继承、重大疾病等确需退出，无回购程序 | 必须补：书面申请、丙方优先回购、计价基准、价款返还期限 |
| 继承：未约定不符资格继承人的处置 | 必须改：继承人不符合准入条件的，由丙方回购，继承人取得对应回购价款；物权编解释（一）第 9 条不阻止该项约定 |

修改句：

「自本房屋记载于不动产登记簿之日起【待填】年内，乙方不得向丙方以外的主体转让其产权份额，因继承、婚姻关系变化依法发生权利主体变更的除外。前款期限内乙方确需退出的，应书面通知丙方，由丙方按本合同约定的全额参考价及届时地方规则计价回购乙方份额。期满后乙方转让其份额的，应先向丙方发出书面征询函；丙方在同等条件下有权优先回购。丙方决定不回购的，受让人须具备房屋所在地共有产权住房购买资格，并承继本合同对份额、使用和再转让的限制。本条不构成对普通商品房的自由处分授权。」

最强反方：购房人主张优先购买或禁售排除了主要权利。提供方须加黑提示；相对方可要求缩短征询期或明确回购计价，但不得删成自由上市。

## 节点 5　使用、抵押与居住权

### 5.1 自住与出租

房屋仅供购房人及其资格文件载明的家庭成员自住。出租须事先征得丙方书面同意，租金收益按产权份额分配，或按地方规则优先面向保障对象。私下高价出租：现有依据支持约定为违约并追缴应付丙方的收益，不在本任务认定已经违约。

### 5.2 抵押仅限购房人份额

| 文本写法 | 动作 |
| --- | --- |
| 可将整套房屋为任意债务抵押 | 红线 |
| 可为消费贷、经营贷、他人债务抵押 | 红线 |
| 仅就乙方份额、且贷款用途限于支付本合同购房款，并经丙方书面确认 | 可保留；银行因担保物不完整拒贷：标风险，不保证放贷 |

修改句：

「乙方仅可就其持有的【待填】% 产权份额，为支付本合同项下购房款向金融机构设定抵押，并应事先取得丙方书面确认。禁止就丙方份额设定抵押，禁止为本合同购房款以外的债务设定抵押。抵押权实现时，处置范围以乙方份额为限，不得减损丙方份额；丙方有权按本合同回购条款同等条件优先承接乙方份额。」

### 5.3 居住权

第 366–368 条：居住权书面设立、自登记时设立。共有产权场景下，购房人单方设立居住权会把政府份额“套空”。不得写成“居住权条款当然无效”；应禁止未经丙方书面同意申请居住权登记。

修改句：

「未经丙方书面同意，乙方不得为任何人就本房屋设立居住权，也不得单方申请居住权登记。违反本款签署的居住权合同，乙方应负责涤除登记并赔偿因此减损的丙方份额利益。」

## 节点 6　格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 是否格式条款

为重复使用而预先拟定、订立时未与对方协商。开发商或代持机构不得仅以“这次没用过第二次”否认。依据地方示范文本制作，不当然排除格式条款。

审查：份额、禁售、强制回购、资格撤销、抵押限制、管辖/仲裁等异常条款是否有足以引起注意的标识，以及是否按要求说明（第 496 条；解释第 10 条）。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在附件 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

提供方对其已尽提示或说明承担举证责任。相对方立场：修改句要求加黑提示、单独签署确认页。提供方立场：补提示痕迹，并评估该条被主张不成为合同内容的风险。

### 6.2 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的、是否仅行政管理、是否只规制履行行为（第 153 条；解释第 16 条）。禁止用已失效“效力性/管理性”口诀代替解释第 16 条。地方共有产权管理办法多为地方规范：资格未核主要是监管与回购后果，不得单独写成民事合同当然无效。虚假资格、借名、自由上市规避：不改写成有效履行。

## 节点 7　违约、解除与争议

1. 虚假申报骗购：可约定资格撤销、丙方强制回购、违约金和质量/占用损失。只有“依法承担违约责任”视为必须改。回购须写通知、计价基准、腾退期限和已付款返还，避免“回购但钱怎么算空白”。
2. 擅自转让、整套抵押、改变用途、违规出租：分别约定可执行后果。构成违约不等于当然解除。
3. 开发商逾期交付或质量不符：点名减价、修理、解除条件；不把商品房解释第十八条九十日办证规则写成默认法定。
4. 违约金不是必得金额；不在本任务做第 585 条精算。修改句避免“不得调整”或“按全额参考价百分之三十必得”。
5. 争议解决：出现仲裁条款，不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核。不动产专属管辖只标红旗，不选定唯一法院充作法律意见。
6. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。资格撤销和回购通知须书面并送达乙方及丙方。
