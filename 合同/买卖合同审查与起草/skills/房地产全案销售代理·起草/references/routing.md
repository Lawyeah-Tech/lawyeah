# 边界与路由

本技能只审查 **买卖合同 / 房地产全案销售委托代理合同** 的待签文本。中文展示名是「审查房地产全案销售委托代理合同（买卖合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 买断房源或货权过户后再转售，赚差价，滞销不退 | `经销买卖合同·审查`。不得按全案佣金改完货权过户 |
| 自己名义对外成交、货权仍归委托人、对价是贸易报酬 | `购房人终端订立本约，也不自负本约权利义务。以自己名义成交或先买后转→负触发`。不得按驻场代理改完介入权 |
| 概括处理事务、无具体楼盘、无驻场销售团队 | `代签商品房买卖本约概括处理缔约事务→`。不得按全案改完空白授权专章 |
| 不驻场、只做渠道引流和客户报备 | `渠道销售代理·审查`。不得按全案改完报备/洗客专章 |
| 只有驻场销售、无策划前场 | `开发商委托驻场销售但不是渠道引流（权限含代销讲解网签）→`。只分流，不打开、不改写该原子 |
| 商品房买卖本约价款、面积、交付、过户 | `一般商品房买卖合同·审查`。只分流，不打开、不改写该原子 |
| 只撮合买卖双方、自己不成交一方 | `存量房买卖或租赁居间带看二手房→` |
| 底价包销、余房由代理吃进或按包销结算 | 本套导航的类型切开步骤 重新定性。不得当全案佣金放行 |
| 有完整待签文本要评改 | `房地产全案销售代理·审查` | 在本起草原子做签前评改 |
| 无文本、本类型条件已谈妥，要出己方稿 | 留本任务起草并自审 |
| 已签未争、只问结佣/对账/清场留痕 | 本套导航的履约步骤 |
| 已成争 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

全案正文里夹带一份已锁定房号价款的商品房买卖本约样本：本约条款交接 `一般商品房买卖合同·审查`；佣金、策划、驻场、独家和口径条款可继续审。用户坚持本技能把经销、行纪、一般委托、渠道代理、一般房销代理或商品房本约整案改完：`目标停止`。
