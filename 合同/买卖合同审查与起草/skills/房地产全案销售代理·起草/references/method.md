# 审查方法（锁定 买卖合同 / 房地产全案销售委托代理合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制经销买断/RPM/窜货主路径，禁止复制行纪介入权/费用自担主路径，禁止复制一般委托空白授权主路径，禁止复制渠道报备/洗客主路径，禁止打开或改写 `一般商品房买卖合同·审查`、`开发商委托驻场销售但不是渠道引流（权限含代销讲解网签）→` 的 method。

定性校验：标题、核心给付与本类型一致才继续；买断经销、寄售行纪、概括委托、渠道引流、无策划的一般房销代理、商品房本约、包销明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、对方必然接受、独家必然挡住开发商自销，或驻场条款保证不构成劳动关系。

`search_law` 返回已失效《合同法》委托章或买卖章及其解释、已失效《城市房地产中介服务管理规定》、1994 年未修正《城市房地产管理法》第 45 条旧文时记为噪声，不得写入 `L#`。预售条件以 **2020 年《城市房地产开发经营管理条例》第 22、26 条** 交叉核验，不得用 1994 年旧法第 45 条“再转让由国务院规定”充作预售许可条。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。

知识库纠正（不回写双文件）：

- `基本面.md` “任务不达标时委托人单方无损解除权”：可约定考核解除，**不得**写成放弃第 933 条任意解除权且解除无效。提前解除仍可能触发有偿委托的直接损失和可得利益赔偿。
- `基本面.md` “代理方对后续销售款的优先受偿主张权”：佣金债权不是法定优先权。修改句最多写成到期未付可中止后续服务并计逾期违约金，不得写成对购房款享有法定优先受偿。
- `基本面.md` “驻场不构成劳动用工”：合同切割必要，但不能保证劳动仲裁一定采信。混同考勤、由委托人发工资或用工管理的，劳动关系字段停止。
- `框架.md` “网签后付 70%、满一年付 30%”“保护期 3–6 个月”：实务量级，不是法定期限。缺数字用 `【待填】`。
- `框架.md` “包销涉及底价结算及余房处理”：出现即先切开，不得当全案佣金放行。
- 发票税目以税务机关当时口径为准，不把“房地产中介服务”专票名称写成唯一合法税目。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 就特定楼盘做策划并驻场销售，以委托人名义向购房人推介，对价是佣金，房源不转给代理 | 本类型 | 正触发 |

| 概括处理事务，无具体楼盘，无驻场销售团队 | 一般委托 | 负触发 `代签商品房买卖本约概括处理缔约事务→` |

| 只有驻场卖房，无调研/定位/广告策划前场 | 一般房地产销售代理 | 负触发 `开发商委托驻场销售但不是渠道引流（权限含代销讲解网签）→`。不打开该原子 |
| 商品房买卖本约：价款、面积、交付、过户 | 商品房买卖 | 负触发 `一般商品房买卖合同·审查`。不打开该原子 |
| 只报告订约机会或提供媒介，自己不成交一方 | 房屋中介 | 负触发 `存量房买卖或租赁居间带看二手房→` |
| 底价包死、余房由代理吃进或按包销结算 | 房地产包销（P1） | 负触发引擎重新定性。不得当全案佣金放行 |

支持切开的规范（法律结论须运行时复核）：

- 第 919 条：委托是处理委托人事务。
- 第 162 条：代理人以被代理人名义实施的行为，对被代理人发生效力。
- 第 595 条：买卖是转移标的物所有权换价款。买断过户不是本类型。
- 第 951 条：行纪是以自己名义为委托人从事贸易，委托人支付报酬。
- 合同编通则解释第 15 条：不拘泥名称，按内容、结构和履行行为认定。
- 商品房销售管理办法第 4、25、28 条：开发商可自行销售或委托依法设立的房地产中介服务机构；书面委托合同须载明期限和权限；受托机构不得收取佣金以外的其他费用。
- 商品房买卖合同解释第 18 条：包销人诉讼地位另有规则——出现包销结构即切开，不按全案佣金审完。

### 1.4 全案策划销售（硬闸）

全案 = 前场 + 后场。缺一截则不是本类型默认主路径。

| 文本写法 | 动作 |
| --- | --- |
| 前场（调研、定位、价格、广告策划）和后场（驻场接待、带看、网签催款、按揭协助）均有清单 | 正触发；清单空洞则必须改 |
| 只写“负责销售”，无策划前场 | 负触发 `开发商委托驻场销售但不是渠道引流（权限含代销讲解网签）→` |
| 只写“渠道引流、报备到访”，明确不驻场 | 负触发 `渠道销售代理·审查` |
| 只写“处理甲方事务”，无楼盘、无驻场团队 | 负触发 `代签商品房买卖本约概括处理缔约事务→` |

修改句（全案范围）：

「乙方服务范围包括前场与后场，二者同时构成全案，不得拆成单纯渠道分销或单纯驻场临促：（一）前场：市场调研、产品建议、价格策略、广告与媒介策划；（二）后场：按附件配置项目经理及置业顾问驻场，完成接待、带看、认购协助、网签催款和按揭手续协助。未经甲方书面同意，乙方不得将前场或后场整体转交给第三人。」

### 1.5 无证销售 / 违规促销停笔（硬闸）

加载后或定性中出现：未取得预售许可或不符合现售条件仍约定对外销售；返本销售、售后包租、分割拆零；阴阳合同规避限购或税款；伪造预售证或经纪备案。

动作：

1. 交付告知：商品房销售管理办法第 27、42、43 条，城市房地产开发经营管理条例第 22、26 条。不得改写成可履行的无证开盘或“先卖后补证”。
2. 不写可履行的假许可路径、返本/售后包租促销脚本。
3. 风险表只保留识别依据和删除/转出口径。
4. 用户坚持“改到能签且仍做这些事”：整体停止。

部门规章多为管理规范：不轻易写“无许可则代理合同当然无效”，但该签署/销售字段必须停止。

## 节点 2　主体、委托书、资质与文本版本

### 2.1 主体表

建表：签约名、履行名、付款名、发票名、授权签字人、项目经理。名称不一致不自动合并。口头“我们老板同意了”不得写成已授权。

支持依据：商品房销售管理办法第 25 条；城市房地产开发经营管理条例第 28 条。开发商委托中介代理销售，应订立书面委托合同并出具委托书；中介销售时应向购房人出示证明文件和销售委托书。

修改句：

「甲方应向乙方出具《商品房销售委托书》，载明项目名称、授权期限、可否代收定金、可否代甲方签署商品房买卖合同。乙方及置业顾问在售楼处显著位置公示该委托书。未出示委托书和预售/现售证明文件的，不得接待认购。」

### 2.2 预售、现售与经纪备案（硬闸）

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |
| 预售项目，未见预售许可证明 | 字段停止；修改句要求作为附件 | 可以开盘、可以先卖 |
| 现售项目，未见竣工验收或现售条件材料 | 字段停止 | 已具备全部销售条件 |
| 代理方无经纪备案痕迹，或经营范围无房地产经纪/营销策划 | 字段停止 | 已具备全部代理资质 |
| 只有营业执照 | 执照不等于已具备预售条件或经纪备案 | 可以对外销售 |

「本合同项下对外销售开始前，甲方应向乙方出示并作为附件：【商品房预售许可证 / 现售条件证明】及项目权属文件。乙方应向甲方出示并作为附件：营业执照、经营范围含房地产经纪或营销策划的证明，以及项目所在地建设（房地产）主管部门的经纪机构备案查询页。未核验前，任何一方不得主张已具备开盘或驻场销售条件。」

## 节点 3　全案范围、独家与驻场

### 3.1 项目与授权边界

项目备案名、推广名、地址、可售业态、是否含车位/储藏室必须写清。授权是否包含代收定金、代签买卖本约，必须勾选。默认：房款和定金进甲方账户，乙方不代收。

### 3.2 独家与自销佣金

独家须定义：甲方可否自销（高管内购、关系户、团购）、可否再委托其他代理、自销是否仍向乙方付佣。不得把“独家”写成已经挡住甲方一切销售。

修改句（独家）：

「甲方授予乙方就附件《可售房源清单》在【待填】至【待填】期间的【独家 / 非独家】全案代理权。独家指：甲方不得再委托其他机构就同一房源做驻场全案代理；【甲方不得 / 甲方有权】自行销售。甲方自行成交的，【仍应 / 不应】按本协议佣金标准向乙方支付佣金，但须以系统第一接待人或书面报备记录为准。期限届满前【待填】日双方书面确认是否续约，不约定自动续期。」

### 3.3 驻场团队与用工切割

项目经理及核心策划人员名单入附件，非经甲方同意不得擅自更换。驻场人员由乙方招用、发薪、缴社保；售楼处场地、水电、物业通常由甲方承担。

修改句：

「乙方派驻人员与乙方建立劳动关系，由乙方发放工资并缴纳社会保险。驻场本身不在甲乙之间建立劳动关系或劳务派遣。乙方人员应遵守附件《案场管理规范》，但甲方不得直接对其实施开除、调薪或考勤处罚。因混同用工被第三人主张与甲方存在劳动关系的，由乙方负责处理并赔偿甲方因此受到的损失。」

最强反方：派驻人员主张与开发商存在事实劳动关系。合同切割不能写成“一定不构成劳动关系”的保证。

二级分销：须写清乙方是否有权发展渠道、费用是否从总佣金列支、下线违规由谁负责。渠道专条可点名交接 `渠道销售代理·审查`，本任务不展开报备/洗客专章。

## 节点 4　佣金闭环（硬闸）

| 文本写法 | 动作 |
| --- | --- |
| “按销售金额计提”，未写网签总房款还是实际回款 | 必须改：计算基数与支付节点分列 |
| “客户签署认购书即应付佣” | 必须改。认购未签约不得默认计为已销售 |
| 只有费率，无退房扣回、先票后款 | 必须改 |
| 把佣金改称劳务费以规避经纪监管 | 必须改回佣金；佣金已包含乙方人员工资社保成本，但不因此排除劳动关系审查 |

支持依据：商品房销售管理办法第 28 条（不得收取佣金以外的其他费用）；第 919、928 条（完成委托事务支付报酬；不可归责于受托人事由解除或不能完成的，支付相应报酬，另有约定除外）。

修改句：

「佣金以买受人签署网签版《商品房买卖合同》载明的总房款为计算基数，费率为【待填】%。支付以买受人已付首付款到甲方账户（按揭的，以银行放款到账）为前提。仅签署认购书、未网签或未支付首付款的，不计为成交，甲方无支付该套佣金的义务。乙方申请付款时应先开具符合甲方税务要求的增值税发票；未提供合格发票的，甲方有权暂缓付款但不免除到期债务。已结佣后发生退房且不可归责于甲方的，乙方应在【待填】日内退回对应佣金。」

禁止把“逾期支付则代理方对后续销售款享有优先受偿”写成法定优先权。可写：逾期超过【待填】日的，乙方有权中止后续策划和驻场，并按未付佣金的【待填】%/日计违约金；该违约金过分高于损失的，任何一方有权请求依法调整。

## 节点 5　推广费分离与禁止垫资（硬闸）

支持依据：第 921 条。委托人应当预付处理委托事务的费用；受托人垫付的必要费用，委托人应偿还并支付利息。全案实务将广告投放与代理服务分开，避免把垫资做成变相融资。

| 文本写法 | 动作 |
| --- | --- |
| 推广费由甲方直接付给媒体，乙方只报方案、执行 | 可保留；补审批流程 |
| “推广费由乙方垫付，甲方视回款再报销”，无上限、无利息、无逾期 | 必须改或红线 |
| 大代理包干推广费，但无预算审批、无剩余返还、无超支归属 | 必须改：写成预算审批机制 |
| 费用沉默 | 不得写成乙方自担。按第 921 条补预付或直付媒体 |

修改句：

「推广费用（媒介投放、户外、活动执行等）由甲方直接支付给第三方供应商。乙方负责策划方案和执行监督，不垫付推广费。单笔超过人民币【待填】元的投放，须经甲方书面批准后方可下单。任何一方不得将未批准的垫资解释为乙方对项目的出资或包销。」

用户坚持把垫资推广改成可履行的“先垫后分销售款”融资结构：红线。不写成民间借贷或让与担保。

## 节点 6　虚假宣传、格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 统一口径与虚假宣传

支持依据：商品房买卖合同解释（2020）第 3 条；广告法（2021 修正）第 4、26 条；房地产广告发布规定第 6、18 条；商品房销售管理办法第 27 条；民法典第 164、167 条。

销售广告就规划范围内房屋及设施所作具体确定、对订约和房价有重大影响的说明，即使未写入买卖本约，也可成为合同内容。房地产广告不得承诺升值回报，不得以到达时间表示位置，不得对规划中的交通、教育设施作误导，不得承诺办理户口、就业、升学。代理人知道代理事项违法仍实施，或被代理人知道而不反对的，承担连带责任。

| 文本写法 | 动作 |
| --- | --- |
| 统一销售口径须经甲方法务书面签认，口头承诺无效 | 可保留；补签认程序和越权追责 |
| 允许乙方口头承诺学区、户口、返本、售后包租 | **红线**。删除可履行话术 |
| “因虚假宣传导致的退房一律由乙方承担，甲方免责” | 必须改：对外甲方仍可能向购房人承担责任；对内可追偿，但不能写成对购房人免责 |
| 茶水费、私下返佣 | 必须改：禁止向购房人收取佣金以外费用；违者解除并付违约金（可调整） |

修改句：

「乙方及其人员对外发布的广告、海报、话术和认购说明，须使用甲方书面签认的《统一销售口径》。未经签认，乙方不得就学区、户口、升学、投资回报、规划中的地铁或配套作出承诺。因乙方或其人员擅自承诺、虚假宣传导致购房人向甲方主张退房、赔偿或受到行政处罚的，甲方对外依法处理后，有权向乙方全额追偿。本条不构成甲方对购房人的免责。」

### 6.2 格式条款

为重复使用而预先拟定、订立时未与对方协商（第 496 条）。开发商制式全案文本、代理公司制式服务文本均可构成。审查：任务不达标解除、天价茶水费罚则、放弃任意解除、最终解释权、自动续期、管辖是否有显著提示。仅电子勾选不足（解释第 10 条）。

第 497 条无效情形、第 498 条不利解释：只在核验后作为修改理由，不代替修改句。

### 6.3 强制规范

违反法律、行政法规强制性规定不一律无效（第 153 条；解释第 16 条）。禁止用已失效“效力性/管理性”口诀。预售许可、经纪备案多为管理规范：合同可能仍成立，但无法合法开盘构成履行障碍——用中止、解除和责任分担修改句处理，不把无证改成可履行开盘路径。

## 节点 7　任务考核、解除、保护期与清场

### 7.1 任务与解除

分阶段（首开、持销、清盘）去化率入附件。连续未达标可约定转为非独家、部分撤单或解除。

第 933 条：委托人或者受托人可以随时解除委托合同。有偿委托的解除方应当赔偿对方的直接损失和合同履行后可以获得的利益，除非不可归责于该当事人。修改句可约定通知期和赔偿计算。**不得写成“双方放弃任意解除权且解除无效”**。

修改句：

「乙方连续【待填】个季度去化率低于附件《销售任务节点及考核表》约定标准的，甲方有权书面解除本合同或取消独家。任何一方依据法律或本协议解除的，应提前【待填】日书面通知。因解除造成对方损失的，除不可归责于解除方的事由外，解除方应赔偿对方的直接损失和本合同履行后可以获得的利益；双方不得约定排除该赔偿或约定解除当然无效。已成交且符合结佣条件的佣金，不因解除而消灭。」

### 7.2 保护期、清场与成果归属

合同终止后【待填】日内撤离案场，移交客户档案、物料和未用授权文件。保护期内由乙方原报备且系统可核验的客户成交的，甲方仍应支付佣金。策划方案、广告创意、客户名单库归甲方。乙方不得把本项目客户用于其代理的竞品。

修改句（保护期）：

「本合同终止后【待填】个月内，附件《客户保护名单》中由乙方在合作期内首次录入且经甲方系统确认的客户与甲方成交的，甲方仍按本协议标准向乙方支付佣金。保护名单以外或系统无首次录入记录的，甲方无该笔佣金义务。」

第一接待人原则：开发商自销团队与代理团队抢客时，以系统第一录入为准。修改句补电子报备，不编造判重算法。
