# 边界与路由

本技能只审查 **买卖合同 / 房地产包销合同** 的待签文本。中文展示名是「审查房地产包销合同（买卖合同）」。场景分层为 **P1**。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

专业版未收录本原子。若用户拿本类型文本来找专业版：输出 `unavailable`，提示，不得用全案或渠道硬套。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 只有佣金、无余房买断、驻场策划销售 | `房地产全案销售代理·审查`。不得按包销基价和买断改完全案 |
| 不驻场、只引流报备、不接余房 | `渠道销售代理·审查`。不得按余房买断改完渠道 |
| 销售期即货权过户再转售、存货风险归己、赚差价 | `经销买卖合同·审查`。不得按包销销售期代理改完过户 |
| 销售期内以自己名义与购房人订本约、货权仍归开发商 | `购房人终端订立本约，也不自负本约权利义务。以自己名义成交或先买后转→负触发`。不得按出卖人名义改完行纪 |
| 只有驻场卖房，无包销基价和余房买断 | `开发商委托驻场销售但不是渠道引流（权限含代销讲解网签）→`。只分流，不打开、不改写该原子 |
| 商品房买卖本约价款、面积、交付、过户 | `一般商品房买卖合同·审查`。只分流，不打开、不改写该原子 |
| 整栋或批量房屋资产直接买卖、无对外包销期 | `房屋整售合同·审查` |
| 存量房买卖或租赁居间 | `存量房买卖或租赁居间带看二手房→` |
| 概括处理事务、代签本约、无包销结构 | `代签商品房买卖本约概括处理缔约事务→` |
| 有完整待签文本要评改 | `房地产包销合同·审查` | 在本起草原子做签前评改 |
| 无文本、本类型条件已谈妥，要出己方稿 | 留本任务起草并自审 |
| 已签未争、只问结佣/余房过户/保证金抵扣 | 本套导航的履约步骤 |
| 已成争 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

包销正文里夹带一份已锁定房号价款的商品房买卖本约样本或余房认购书：本约条款交接 `一般商品房买卖合同·审查`；基价、买断、对外名义、预售和溢价条款可继续审。用户坚持本技能把全案、渠道、经销、行纪或买卖本约整案改完：`目标停止`。
