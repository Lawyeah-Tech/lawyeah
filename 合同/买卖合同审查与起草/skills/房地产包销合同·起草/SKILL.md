# 房地产包销合同·起草

## 任务目标

在单一立场下，只起草 **房地产包销合同**，并按本类型硬闸自审。交付可编辑草稿、未决项、自审风险表和自审后修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查房地产包销合同（买卖合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、把全案佣金代理/渠道引流/经销买断/行纪/商品房本约整案改完、把无证先卖或假更名避税写成可履行结构。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **包销底价与剩余房屋买断**：附件逐套锁定包销基价。包销期满未售房屋由包销人按包销基价在约定期限内签署买卖本约并付款，另有约定除外。缺基价、缺认购期或写“可视市场决定是否接盘”：必须改。修改句须写明基价计算公式、认购期限和不得以市场或政策拒绝。
2. **代理 vs 包销切开**：对价结构是基价结算 + 余房买断，不是单纯佣金。只有佣金、无余房买断、滞销风险仍归开发商 → 负触发 `房地产全案销售代理·审查`。只引流报备、不包盘、不接余房 → 负触发 `渠道销售代理·审查`。标题写“代理及包销”但正文无买断：按核心给付切开，禁止两套知识混审。
3. **预售许可**：未见预售许可或现售条件而约定对外销售：字段停止；修改句把许可作为对外销售开始条件，不写成已经完成。用户坚持无证先卖、先收购房款后补证、返本销售、售后包租、阴阳合同：停笔。包销协议签署本身不等于已具备对外销售条件。
4. **包销人对外销售身份**：销售期内以出卖人名义对外销售；买受人与开发商签署商品房买卖合同（或网签）；房款进开发商账户或监管账户；现场公示销售委托书和预售/现售证明。销售期内以自己名义与购房人订本约或房款进包销人私户：红线改回；自己名义贸易主轴 → 负触发 `购房人终端订立本约，也不自负本约权利义务。以自己名义成交或先买后转→负触发`。期满余房买入后，包销人才成为该套本约买受人。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿；尚未签署，尚未成争，核心给付是就特定商品房由包销人以出卖人名义销售、按包销基价结算、期满未售由包销人按基价购买。有完整待签文本要评改时转配对审查原子。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 只有佣金、无余房买断、驻场策划销售 → `房地产全案销售代理·审查`；
- 不驻场、只引流报备、不接余房 → `渠道销售代理·审查`；
- 销售期即货权过户再转售、存货风险归己、赚差价 → `经销买卖合同·审查`；
- 销售期内以自己名义与购房人订立本约、货权仍归开发商、对价是贸易报酬 → `购房人终端订立本约，也不自负本约权利义务。以自己名义成交或先买后转→负触发`；
- 只有驻场卖房、无包销基价和余房买断 → `开发商委托驻场销售但不是渠道引流（权限含代销讲解网签）→`；
- 商品房买卖本约价款、面积、交付、过户 → `一般商品房买卖合同·审查`；不得删本约条款后当包销审；
- 整栋或批量房屋资产直接买卖、无对外包销期 → `房屋整售合同·审查`；
- 存量房买卖或租赁居间 → `存量房买卖或租赁居间带看二手房→`；
- 概括处理事务、代签本约、无包销结构 → `代签商品房买卖本约概括处理缔约事务→`；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问结佣、余房过户、保证金抵扣留痕 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁 → `或对应专项领域。` 或对应专项领域。

无证销售、返本销售、售后包租、阴阳合同、规避限购：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（开发商/出卖人侧或包销人侧择一）；相对方；全文及房源基价表/进度表/余房认购书/委托书版本；是否约定期满买断；基价是否逐套锁定；对外以谁的名义签约；购房款账户；预售许可或现售条件痕迹；包销期限与认购期；溢价是否价税分离；保证金还是大额预付包销款；网签限价是否可能低于基价；不可接受事项；法域、项目所在地与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的基价、套数、期限、保证金比例用 `【待填】`，不编造。

## 起草模式

本原子只起草本类型。有完整待签文本要评改时，转 `房地产包销合同·审查`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。同一套本类型硬闸，在落稿时写成正文必写、附件必附或禁止出现，不得审完再补。

**起草必写：** 附件逐套锁定包销基价，期满未售房屋由包销人按包销基价在约定期限内签署买卖本约并付款；写明基价计算公式、认购期限和不得以市场或政策拒绝；对价结构是基价结算 + 余房买断；预售许可或现售条件作为对外销售开始条件，不写成已经完成；销售期内以出卖人名义对外销售，买受人与开发商签署商品房买卖合同（或网签），房款进开发商账户或监管账户，现场公示销售委托书和预售/现售证明；期满余房买入后，包销人才成为该套本约买受人。

**附件必附：** 《包销房源清单及基价对照表》；《各阶段销售目标及进度表》；销售委托书。

**禁止出现：** 缺基价、缺认购期或写“可视市场决定是否接盘”；销售期内以自己名义与购房人订本约或房款进包销人私户；无证先卖、先收购房款后补证、返本销售、售后包租、阴阳合同；只有佣金、无余房买断仍按包销落稿。

出稿后必须用本类型硬闸与 [审查方法](references/method.md) 自审。未过不得宣称起草完成。交付草稿、未决项、自审风险表、自审后修改句。

他类型出稿、已签履约、已成争：仍负触发。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`基本面.md` 中“物权请求权”不得写成包销人对房屋享有法定物权请求权；“全案策划代理及包销”只是命名建议，无买断则切开。`框架.md` 中保证金 5%–10%、拒购违约金 20% 是实务量级，不是法定期限；“更名宽限期”不得写成确定避税。

### 0. 签署状态与成果分流

有完整待签文本要评改 → `房地产包销合同·审查`；无文本且本类型条件已谈妥 → 留本任务起草并自审；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是按已谈妥条件出己方稿，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。全案佣金、渠道引流、经销买断、行纪、商品房本约负触发。

### 2. 对外销售身份、委托书与账户

以出卖人名义；买受人与开发商网签；房款进开发商或监管账户；委托书现场公示。

### 3. 预售许可与现售条件

未见许可：字段停止。无证先卖：停笔。

### 4. 基价、排他与余房买断

基价逐套锁定；包销期内开发商不得自销；期满按基价认购。

### 5. 溢价结算、价税分离、限价补差、保证金

佣金 = 实际售价 − 基价 − 对应税费。网签价低于基价须现金补差。大额预付“包销款”识别变相融资。

### 6. 格式条款与强制规范

无核验引文则法律结论字段停止。

### 7. 违约、解除与争议

拒购余房与越权自销分别有可执行后果。不得写放弃买断或随时解除消灭余房购买。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把无证先卖/返本/售后包租/阴阳合同/规避限购改成可履行结构、坚持删除余房买断却按包销放行、坚持房款进包销人私户。
- `字段停止`：法域、动态规则、预售证号、现售条件、经纪备案、基价数字、地方限价未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。

生存级预付包销款或个人无限连带且用户拒绝升级：停止“可以签署”建议。
