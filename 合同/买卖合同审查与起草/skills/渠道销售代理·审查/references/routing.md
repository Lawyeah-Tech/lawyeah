# 边界与路由

本技能只审查 **买卖合同 / 渠道销售委托代理合同** 的待签文本。中文展示名是「审查渠道销售委托代理合同（买卖合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 驻场接待、全案策划销售、去化对赌、独家包盘 | `房地产全案销售代理·审查` |
| 买断进货、存货风险归渠道、赚差价 | `经销买卖合同·审查` |
| 以自己名义与终端订立本约或先买后转 | `购房人终端订立本约，也不自负本约权利义务。以自己名义成交或先买后转→负触发` |
| 开发商委托销售且权限含案场讲解/网签，但不是渠道引流 | `开发商委托驻场销售但不是渠道引流（权限含代销讲解网签）→` |
| 存量房买卖或租赁居间 | `存量房买卖或租赁居间带看二手房→` |
| 代签本约、概括处理缔约事务 | `代签商品房买卖本约概括处理缔约事务→` |
| 主文件是商品房买卖本约 | `一般商品房买卖合同·审查`。不得删掉本约条款后继续当渠道审 |
| 房地产包销、剩余货值买断 | 引擎重新定性；P1 未装则 `unavailable`，不得用本技能硬套 |
| 无文本、本类型条件已谈妥，要出己方稿 | `渠道销售代理·起草`；不得在本审查原子出稿 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争，或用户要佣金诉讼策略 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

渠道正文里夹带一小段商品房价款或网签操作：专条交接 `一般商品房买卖合同·审查`；报备、结佣、非独家、禁止返佣条款可继续审。用户坚持本技能把全案、经销、行纪或买卖本约整案改完：`目标停止`。
