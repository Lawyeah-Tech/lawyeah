# 审查方法（锁定 买卖合同 / 渠道销售委托代理合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制全案驻场/去化对赌/底价表主路径，禁止复制经销货权过户/窜货/转售限价主路径，禁止复制行纪介入权或对第三人自负主路径。

定性校验：标题、核心给付与本类型一致才继续；全案驻场、买断经销、自己名义成交、存量房中介或商品房本约明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、报备争议渠道必胜、对方必然接受或唯一必得佣金。

`search_law` 返回已失效《合同法》委托章、居间章及其解释、已失效《城市房地产中介服务管理规定》、已失效《经纪人管理办法》、已失效《关于对外贸易代理制的暂行规定》时记为噪声，不得写入 `L#`。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款已被接受。全案代理、经销或行纪范本只证明是另一类型，不得当作本类型范本。

知识库纠正（不回写双文件）：

- `基本面.md` 建议标题为“房地产渠道分销合作协议”：这是命名建议，不是法定名称。标题写成渠道分销、特约渠道引流或渠道销售代理均可，定性看核心给付。
- `框架.md` “属于居间性质的委托服务合同”：核心给付是引流、推介、报备带看。渠道通常不以任何一方名义签署商品房买卖本约，也不驻场销售。获得代签或驻场销售权 → 负触发 `房地产全案销售代理·审查` 或 `开发商委托驻场销售但不是渠道引流（权限含代销讲解网签）→`；以自己名义成交 → 负触发 `购房人终端订立本约，也不自负本约权利义务。以自己名义成交或先买后转→负触发`。
- `框架.md` “开发商通常保留随时终止”：有偿委托解除仍可能发生第 933 条赔偿。修改句必须保留终止前已有效报备且最终成交客户的结佣，不得写成无偿甩客。
- `框架.md` “CRM 中的记录作为判定客户归属的唯一依据”：系统记录可作主要依据，但须与到访确认单或人脸识别对照，并给予渠道方查询与异议期。不得写成开发商单方系统不可复核。
- `基本面.md` “任何私下交易将导致协议无效且追究刑事责任”：民事是否无效按第 153、154 条和解释第 16 条判断；刑事只告知可能，本任务不认定已犯罪，也不把条款写成“当然无效且必然追刑”。
- 经纪管理办法第 1 条仍引用《合同法》：办法 2016 修正本现行有效，不得把失效合同法写入 `L#`。

## 节点 1　类型识别与单目录加载

### 1.1 定性

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符时按核心给付归类，标题冲突写入 `C#`。

必须切开后再加载，禁止两可时灌入两套知识：

| 信号 | 归入 | 本任务动作 |
| --- | --- | --- |
| 引流、推介、报备带看，按确认成交收佣金；不买断存货；不驻场销售 | 本类型 | 正触发 |
| 驻场接待、讲解、催款、协助网签；全案策划；去化指标对赌；独家包盘 | 全案销售委托代理 | 负触发 `房地产全案销售代理·审查` |
| 买断进货、存货风险归己、赚差价、先款后货 | 经销买卖 | 负触发 `经销买卖合同·审查` |
| 以自己名义与购房人或终端订立本约，自负本约权利义务 | 行纪 | 负触发 `购房人终端订立本约，也不自负本约权利义务。以自己名义成交或先买后转→负触发` |
| 开发商委托销售且权限含案场讲解/网签，但不是渠道引流 | 房地产销售代理 | 负触发 `开发商委托驻场销售但不是渠道引流（权限含代销讲解网签）→` |
| 报告二手房或租赁订约机会、带看存量房 | 房屋买卖_租赁中介 | 负触发 `存量房买卖或租赁居间带看二手房→` |
| 授权以委托人名义签署买卖本约、代办网签过户 | 一般委托 | 负触发 `代签商品房买卖本约概括处理缔约事务→` |
| 主给付是商品房所有权换价款 | 一般商品房买卖本约 | 负触发 `一般商品房买卖合同·审查`；不得删本约后硬套 |

支持切开的规范（法律结论须运行时复核）：

- 第 961 条：中介是报告机会或提供媒介，委托人支付报酬——渠道引流接近此结构。
- 第 919 条：委托是处理委托人事务——权限须写清，不得默示全案销售权。
- 第 951 条：行纪是以自己名义从事贸易活动。
- 第 595 条：买卖是转移标的物所有权换价款——买断走 `经销买卖合同·审查`。

### 1.3 渠道佣金非买断 / 非全案 / 非行纪（硬闸）

| 文本写法 | 本任务动作 | 修改句方向 |
| --- | --- | --- |
| 乙方仅引流推介，本约由甲方或全案/自销签署，存货/房源归甲方，对价为佣金 | 正触发，留下本类型 | 首部写明“渠道引流代理，非买断、非全案、非行纪” |

### 1.4 返佣 / 洗客 / 截客 / 商业贿赂停笔（硬闸）

加载后或定性中出现：渠道向购房人私诺回扣或礼品；售楼处门口拦截自然到访并补报；与置业顾问串通把已登记客户洗成渠道客户；账外向案场人员输送利益。

动作：

1. 交付告知：经纪管理办法第 25 条禁止以贿赂等不正当手段招揽、隐瞒信息赚差价；反不正当竞争法要求向中间人支付佣金须明示入账；可能因违法或恶意串通无效（第 153、154 条）。不得改写成可履行回扣或洗客结构。
2. 不写可履行的返佣发放路径、截客话术或体外分账。
3. 风险表只保留识别依据和删除/转出口径。
4. 用户坚持“改到能签且仍做这些事”：整体停止。

未达预售条件仍要带看成交、规避限购或阴阳价：同样只告知，不改成可履行。

## 节点 2　主体、备案与委托书

### 2.1 主体表

建表：签约名、履行名、付款名、发票名、授权签字人。名称不一致不自动合并。渠道方多个门店或关联公司：结算主体必须唯一，下线门店不得各自向开发商请款。

口头“我们老板同意了”不得写成已授权。委托人不是项目开发企业或权利人：该委托能力字段停止。

### 2.2 备案、经营范围与委托书（硬闸）

| 已有事实 | 本任务动作 | 不得写成 |
| --- | --- | --- |

修改句：

「本合同签署前，乙方应向甲方出示并作为附件：所在地建设（房地产）主管部门备案证明或官方查询页（如依法需备案），以及甲方出具的《商品房销售/渠道推介委托书》。委托书载明项目名称、委托期限、委托权限限于引流推介与报备带看，不含代签买卖合同、不含驻场销售。未核验前，不得主张已具备对外推介条件。」

部门规章备案义务不当然导致民事合同无效（解释第 16 条）。本任务只停止“可以展业”表述，不宣告合同当然无效。

## 节点 3　报备—到访—确认与服务范围（硬闸）

### 3.1 服务范围须可核验

审查清单，缺一项则该字段不得写成已闭环：

1. 项目名称、可推介业态或货值范围，或“待甲方书面锁定”。
2. 服务内容分列：线上引流 / 门店推介 / 报备 / 带看到场。明确**不入驻案场、不负责销售讲解、不负责网签和催款**。
3. 非独家：甲方有权同时委托其他渠道并自行销售、委托全案代理。
4. 委托期限起止日。禁止无期限绑定。渠道合作期通常较短，续签须书面。

禁止只写“提供全程营销服务”而无报备标准和成交定义。出现驻场排班或销售指标：按节点 1.3 切开，不在本节点改成全案。

### 3.2 报备闭环

支持依据：知识硬闸；佣金成就以约定事件为准（实务反例，非法源）。

| 文本写法 | 动作 |
| --- | --- |
| 无报备时限，或报备后无限保护 | 必须改。报备有效期用 `【待填】` 小时（知识示例 24–48 小时，非法定期限） |
| 未区分报备期与到访后保护期 | 必须改。报备期=到访前有效；保护期=到访后归属期限，另填 `【待填】` 日 |
| “自然到访也可由渠道补报”“系统已有客户仍接受渠道报备” | 红线删除。系统已存在的自然访客、全案访客不接受渠道报备 |
| 多方报备同一客户无规则 | 必须改：以客户现场确认的推荐方为准；无法判定时以系统第一有效报备且在有效期内到访为准 |
| 到访确认无载体 | 必须改：到访确认单或人脸识别，二者择一写清 |

修改句：

「有效报备是指客户到场前，乙方已在甲方指定系统登记客户姓名及甲方要求的联系方式要素，且该客户在过去【待填】日内未在案场、自销或全案系统有过咨询或登记记录。报备后【待填】小时内未到访的，该次报备失效。客户到场后须签署《客户到访确认单》或完成案场人脸识别，二者之一作为渠道工作凭证。系统已存在的自然到访或全案/自销客户，不接受渠道报备或补报。同一客户被两家以上渠道报备的，以客户本人现场确认的推荐方为准；无法确认的，以系统第一有效报备记录为准。」

最强反方：渠道主张“电话沟通过即可补报”。现有依据不支持把事后补报自然到访写成有效报备。

二级分销：若允许，须书面；渠道对下线违规（洗客、返佣、虚假宣传）承担连带责任；下线不得直接向甲方请款。

## 节点 4　结佣节点、阶梯激励与退房退佣（硬闸）

支持依据：第 964 条；商品房销售管理办法第 28 条（不得收取佣金以外费用）。

| 文本写法 | 动作 |
| --- | --- |
| 客户交纳认购定金或意向金即结全额佣金 | 红线。成交定义为签署商品房买卖合同（或网签）且首付款按约到账 |
| 结佣以按揭贷款全部到账为前提，且无最长期限 | 必须改。首付到账后 `【待填】` 日内发佣；按揭未放不得作为无限拖延理由 |
| 只写“结佣”不写“发佣”时限 | 必须改。结佣=核算数额；发佣=资金到账，写明财务审批时限 |
| 未促成也收取“服务费”“引流费”且无必要费用范围 | 必须改。未促成不得请求报酬；必要费用须列明项目与上限 |
| 发生退房不退佣 | 必须改。已领佣金在 `【待填】` 日内退还或从后续佣金抵扣 |
| 佣金与购房人回扣混写 | 红线。佣金只能由甲方向乙方支付并入账 |

修改句：

「乙方佣金以推荐客户与甲方签署商品房买卖合同（或完成网签）且该合同约定的首付款足额到账为前提。仅交纳定金、意向金或认购书，不视为成交，乙方不得请求该套佣金。甲方应在前述条件成就后【待填】日内完成结佣核算，并在核算后【待填】日内向乙方指定对公账户发佣。甲方不得以按揭贷款尚未全部到账为由无限期停止发佣。因买受人退房、合同解除或未达网签的，乙方应在【待填】日内退还已领取的对应佣金，或同意从后续应付佣金中等额抵扣。乙方未促成任何符合前款的成交的，不得请求支付报酬，但可请求事先书面列明的必要费用，总额不超过人民币【待填】元。」

禁止编造佣金比例或每套金额。框架中的固定金额/套或成交总价比例只是实务量级，不是法源。阶梯激励（跳泵）可保留，但须写清统计周期、套数口径和是否含退房回冲。

## 节点 5　购房款账户、定金与费用

### 5.1 购房款不进渠道私户（硬闸）

| 文本写法 | 动作 |
| --- | --- |
| 购房款、定金转入渠道人员个人账户、微信/支付宝个人码 | 红线删除 |
| 转入渠道公司一般结算户、门店代收 | 红线；改为出卖人账户或项目所在地资金监管账户 |
| 渠道代收代付且指定专用存款账户、划转须双方签章 | 可保留，但须与佣金账户分列；地方监管规则字段停止待核 |

修改句：

「商品房成交价款及定金仅可转入出卖人账户或项目所在地主管部门/银行资金监管账户。禁止转入渠道人员个人账户、个人收款码或乙方一般结算账户。佣金与购房款分户收付，乙方不得以代收房款抵扣佣金，也不得向买受人收取佣金以外的任何费用。」

用户坚持保留私户代收：整体停止，不改成“加收据即可放行”。

### 5.2 定金、订金、意向金

必须使用“定金”二字才讨论罚则。渠道代收的“意向金”在转给开发商前，现有依据不支持写成已发生定金效力，更不支持写成渠道已成交。约定或推算超过主合同标的额百分之二十：超过部分不产生定金效力（第 586 条）。无核验引文不得把 20% 写成现行法结论。

### 6.1 非独家赛马与终止后结佣（硬闸）

| 文本写法 | 动作 |
| --- | --- |
| 授予独家渠道权，禁止甲方自销或其他渠道 | 必须改。除非用户明确要独家并加黑提示；默认按知识改为非独家赛马 |
| “甲方可随时终止，已报备客户一律不再结佣” | 红线。终止前已有效报备且最终成交的，仍应结佣 |
| 无期限或自动永久续期 | 必须改。期限 `【待填】` 个月，续签须书面 |

修改句：

「本协议为非独家渠道合作。甲方有权同时委托其他渠道，并有权自行销售或委托全案代理，无需向乙方就非乙方有效报备客户支付佣金。甲方因项目营销策略调整提前终止本协议的，应书面通知乙方；通知送达前乙方已完成有效报备、且该客户在报备保护期内与甲方成交的，甲方仍应按本合同结佣并在条件成就后【待填】日内发佣。本条不排除有偿委托解除时对方依法可主张的损失，但双方已就已报备成交佣金作出安排的，该部分按本合同结算。」

最强反方：开发商主张第 933 条可随时解除且无需付佣。现有依据不支持把有偿委托解除写成已报备成交佣金归零。渠道主张独家且自销也要付全额佣金：须加黑提示，并允许甲方删除。

防绕开：可约定委托人利用乙方已有效报备的特定客户绕开成交仍付佣，但须限定“利用该报备或带看”，并保留客户自行合法获知或属自然到访的例外。不得把第 965 条写成渠道必胜，也不得把防绕开写成买卖本约无效。

### 6.2 格式条款

为重复使用而预先拟定、订立时未与对方协商。从事经营活动的开发商或渠道不得仅以“这次没用过第二次”否认。依据示范文本制作，不当然排除格式条款。

审查：佣金、防绕开、随时终止、免责、管辖/仲裁等异常条款是否有足以引起注意的标识，以及是否按要求说明（第 496 条；解释第 10 条）。

| 已有事实 | 不得写成 |
| --- | --- |
| 小字印刷、夹在附件 | 已尽提示义务 |
| 仅有网络勾选或弹窗 | 已尽提示或说明义务 |
| 对方未异议 | 条款必然成为合同内容 |

提供方对其已尽提示或说明承担举证责任。

### 6.3 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的、是否仅行政管理、是否只规制履行行为（第 153 条；解释第 16 条）。禁止用已失效“效力性/管理性”口诀代替解释第 16 条。经纪管理办法多为部门规章：未备案主要是监管后果，不得单独写成民事合同当然无效。返佣、洗客、侵占房款、未达预售条件销售：不改写成有效履行。

虚假宣传：渠道在推文、社群中不得使用虚假折扣或夸大学区、地铁等配套。由此产生的投诉与责任由渠道独立承担；不得写成“以甲方事后追认为准即可免责”。广告法第 26 条具体禁止事项运行时复核后再写入 `L#`。

客户数据：渠道不得导出、泄露甲方系统内的客户个人信息或底价政策。批量报备信息的个保法条号运行时复核后再写入 `L#`。

## 节点 7　违约、解除与争议

1. 洗客、截客、私自返佣、虚假宣传：可约定取消合作资格、扣除当期佣金、赔偿直接损失。只有“依法承担违约责任”视为必须改。高额罚金可谈，不得写成“必得且不得调整”。
2. 渠道逾期不报备、提供虚假客户信息：可约定减酬、免酬、解除。
3. 甲方逾期发佣：可约定逾期付款违约金，数字用 `【待填】`；不得把“对后续销售款享有优先受偿”写成法定优先权。
4. 构成违约不等于当然解除。法定解除路径只点名催告或目的不能实现，不在本任务作出已解除结论。
5. 有偿委托解除适用第 933 条时，只点名赔偿范围，不输出必得履行利益金额。
6. 争议解决：出现仲裁条款，不得改写成“应向某法院起诉”并假装已选定诉讼。或裁或诉、机构不明：标待核，修改句改成单一仲裁机构或单一法院连结点。专属管辖可能：只标红旗，不选定唯一法院充作法律意见。
7. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。
8. “小蜜蜂”路口拦车、散发小广告导致城管处罚：由渠道承担，不得转嫁甲方。
