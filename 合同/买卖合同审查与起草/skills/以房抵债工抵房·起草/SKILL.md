# 以房抵债工抵房·起草

## 任务目标

在单一立场下，只起草 **以房抵债（“工抵房”）合同**，并按本类型硬闸自审。交付可编辑草稿、未决项、自审风险表和自审后修改句。

本技能类型锁死。不扫描其他合同类型。本原子只承担本类型起草。待签评改转 `以房抵债工抵房·审查`。场景分层为 **P1**。

`depends-on` 为空。不要求先跑导航。

不交付：他类型起草、履约交底、争议或执行异议文书、有效性／过户／排除查封保证。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿；尚未签署，尚未成争，核心给付是以特定房屋抵偿工程款或其他已主张金钱债权，通常出现开发商、债权人（多为施工方）与买受人（债权人自己或指定人）。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 无债权溯源、无抵销／抵债合意，只是开发企业预售或现售商品房 → `一般商品房买卖合同·审查`；
- 业主出售已取得或应取得产权的存量房，无工程款／抵债结构 → `二手房买卖·审查`；
- 名为买卖、实为借款担保，约定回购、溢价赎回，或履行期届满前过户且到期不还则房屋归债权人 → `让与担保式房产买卖·审查`；
- 文本明显是其他合同类型 → 本套导航的类型切开步骤 或对应场景原子；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问交房、办证、付款留痕 → 本套导航的履约步骤；
- 已成争（催告、解除、索赔、诉讼仲裁），**包括已经过户或已立案后要求排除执行** → 合同争议或执行／建设工程专项，不在本任务做异议之诉评估。

挂靠、违法分包、规避限购、虚构债权逃避执行、施工方未取得所有权即以自己名义对外转售：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；代表开发商、债权人还是指定买受人；相对方；1+N 各份文本版本；房号；原债权项目与金额；不可接受事项；法域与拟签时限。缺立场或无可读文本则不启动实体审查。同时掌握双方或多方秘密时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价格、面积、日期用 `【待填】`，不编造。

## 本类型硬闸

未完成下列切开和落句，不得宣称起草完成。每闸必须有修改句，禁止只打红黄绿。

1. **抵债真实性**。原债权须有可回链的基础合同、结算／对账和欠款确认；债权人书面担保真实性。无依据不得写“债权真实”。虚构或补假债权：整体停止。
2. **工程款基础**。写清项目、已结算额、欠付额、履行期是否届满。届满后抵债：协议可生效，但旧债原则上在抵债义务履行后才消灭，未履行可择一请求。届满前抵债：不得约定到期不还则房屋归债权人所有；未完成权利变动不得主张就该房优先受偿；本质是担保或回购的，转 `让与担保式房产买卖·审查`。
3. **过户与优先受偿／消费者购房切开**。网签、过户、交付、预告登记分列，落空则原金钱债权恢复。不得写工抵房当然优于抵押权或当然排除查封。施工方自己受让通常不是商品房消费者。指定自然人买受人主张消费者保护的，须单独核验居住目的与价款支付；抵销是否构成“已支付价款”依据不足则字段停止。优先受偿权安排不得写成损害建筑工人利益仍有效的概括放弃。
4. **让与担保切 `让与担保式房产买卖·审查`**。回购、流押、过户仅为担保：负触发，不在本任务改成真实买卖外观。
5. **普通买卖切 `一般商品房买卖合同·审查`／`二手房买卖·审查`**。无抵债核心给付：负触发。不得删掉抵债条款后继续当普通买卖审，也不得把普通买卖硬留本技能。

必须有修改句。每个风险回链文本位置。


## 起草模式

本原子只起草本类型。有完整待签文本要评改时，转 `以房抵债工抵房·审查`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。同一套本类型硬闸，在落稿时写成正文必写、附件必附或禁止出现，不得审完再补。

**起草必写：** 原债权须回链基础合同、结算/对账和欠款确认，债权人书面担保真实性；写清项目、已结算额、欠付额、履行期是否届满；届满后抵债则协议可生效，但旧债原则上在抵债义务履行后才消灭，未履行可择一请求；网签、过户、交付、预告登记分列，落空则原金钱债权恢复；施工方自己受让通常不是商品房消费者，指定自然人买受人主张消费者保护的须单独核验居住目的与价款支付；优先受偿权安排不得写成损害建筑工人利益仍有效的概括放弃。

**附件必附：** 《工程款结算单/对账单》；基础合同与欠款确认；债权人真实性担保。

**禁止出现：** 无依据写“债权真实”；虚构或补假债权；届满前抵债约定到期不还则房屋归债权人所有；未完成权利变动主张就该房优先受偿；写工抵房当然优于抵押权或当然排除查封；把回购、流押、过户仅为担保改成真实买卖外观；删掉抵债条款后当普通买卖落稿。

出稿后必须用本类型硬闸与 [审查方法](references/method.md) 自审。未过不得宣称起草完成。交付草稿、未决项、自审风险表、自审后修改句。

他类型出稿、已签履约、已成争：仍负触发。

## 判断节点

以 [审查方法](references/method.md) 为准。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。交付按 [输出合同](references/output-contract.md)。边界见 [路由](references/routing.md)。

入口（细节以 method 为准）：

0. 签署状态分流：已过户／已成争 → 争议；有完整待签文本要评改 → `以房抵债工抵房·审查`；无文本且本类型条件已谈妥 → 留本任务起草并自审；已签履约 → 本套导航履约步骤。
1. 类型切开：让与担保转 s006；无抵债的商品房转 s001；无抵债的存量房转 s014。
2. 抵债真实性：结算附件、书面担保、虚假则停止。
3. 工程款基础：履行期届满前／后分岔；旧债消灭时点。
4. 1+N 主体、指定权、禁止二房东转售、三方会签。
5. 价款对冲、差额、封闭现金流、发票链条。
6. 网签／预告登记／交付／过户；优先受偿与消费者切开。
7. 格式条款、虚假抵债、挂靠、限购；落空回溯与退款路径。
8. 按框架六步出修改句。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验以物抵债届满前／后、流押与让与担保、虚假意思表示与债权人撤销、预售许可、优先受偿放弃、消费者购房条件、抵销、定金、格式条款；`search_practiced` 补审查反例；`search_template` 只借修改句结构。不虚构案件系统。

`search_law` 对法律结论为 required 级节点：不可用时不拒绝执行，只停止法律结论字段。返回已失效《合同法》及其解释或法释〔2002〕16 号时记为噪声，不得写入 `L#`。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；用户坚持伪造结算、倒签履行期、虚构债权逃避执行、规避限购、把二房东转售或无证预售改成可履行结构、保证有效或保证过户／排除查封。
- `字段停止`：结算与履行期未核验；抵押查封未披露；抵销能否计入已付房款未核验；地方网签／监管细则未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议或执行异议文书。

生存级金额或个人无限连带且用户拒绝升级：停止“可以签署”建议。
