# 边界与路由

本技能只审查 **买卖合同 / 以房抵债（“工抵房”）合同**：以特定房屋抵偿工程款或其他已主张金钱债权的待签 1+N 文本。

| 已能支持的事实 | 路由 | 不得写成 |
| --- | --- | --- |
| 待签、有债权溯源和抵债／抵销合意、目标是评改文本 | 留本任务 | 已完成签约、旧债已当然消灭、必然过户 |
| 无欠款背景，开发企业预售或现售其商品房，只有买卖／预售合同 | `一般商品房买卖合同·审查` | 用本技能的抵债硬闸硬套普通商品房 |
| 业主／自然人出售已办或应办存量房产权，无工程款抵债 | `二手房买卖·审查` | 用本技能审户口、阴阳合同主路径 |
| 买卖加固定价或溢价回购、过户仅为担保、届满前约定到期不还则房屋归债权人、借款本息对照房价 | `让与担保式房产买卖·审查` | 删掉回购／流押句后继续当真实工抵房审 |
| 施工方未取得所有权，以自己名义对外签“二手房买卖”转售工抵指标 | 告知违法／履行不能；不改成可履行二手结构。用户只要指定权文本且仍与开发商直签的，可留本任务审指定条款 | 写成可过户的二手买卖 |
| 有完整待签文本要评改 | `以房抵债工抵房·审查` | 在本起草原子做签前评改 |
| 无可读正文，本类型条件已谈妥，要出己方稿 | 留本任务起草并自审 | 已经完成起草；在本起草原子做签前评改 |
| 已签，问网签日、交房日、发票、付款留痕 | 本套导航的履约步骤 | 签前意见 |
| 已过户、已立案、已发催告解除、执行异议、破产债权申报 | `或对应专项领域。` 或建设工程／执行专项 | 继续当签前审查出修改句充作排除执行方案 |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 | 两可时灌入两套知识 |
| C 端大众快检 | 只分流，不回改 | 降成 029 快检 |

挂靠、违法分包、规避限购、虚构债权逃避执行、无证预售：只告知，不改写成可履行文本。用户坚持改到能签：整体停止。

专业版未收录的 P1 场景不会安装本原子。若用户拿本类型文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
