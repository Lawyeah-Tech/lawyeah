# 审查方法（锁定 买卖合同 / 附选择权、转售权的房产销售合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型。禁止复制一般商品房面积 3%/先验房/宣传入学主路径，禁止复制包销余房强制买入/包销基价主路径。

定性校验：标题、核心给付与本类型一致才继续；包销、普通商品房买卖、团购、定制、让与担保、工抵房、二手房明显则负触发，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、必然更名、必然过户、对方必然接受或唯一必得收益。

`search_law` 返回已失效《合同法》及其解释、担保法解释、或商品房买卖合同司法解释（2003）原第 14 条时记为噪声，不得写入 `L#`。未竣工预售再转让的现行口径是《城市房地产管理法》第 46 条“由国务院规定”，不得写成全国一律可以更名。

示范文本只参考结构。民法典第 470 条允许参照示范文本，不证明本约条款或选择权特别约定已被接受；网签范本空白处填写“按规定处理”视为未约定。

知识库纠正（不回写双文件）：

- `基本面.md` 建议把利息改称“资金占用补偿金/溢价分成”以淡化借贷：禁止协助伪装。修改句如实写补偿性质与计算口径，并提示可能被重定性为民间借贷或返本销售。

支持切开的规范（法律结论须运行时复核）：

- 第 595 条：买卖是转移标的物所有权换价款。本类型以特定房屋买卖为载体，但附加选择权或转售权。
- 商品房买卖合同解释（2020 修正）第 16 条：出卖人与包销人订立包销合同，约定交由包销人以出卖人名义销售，期满未售由包销人按包销价格购买——这是包销，不是本类型。
- 合同编通则解释第 15 条：不拘泥名称，按内容、结构和履行行为认定。
- 销售管理办法第 11 条：不得返本销售或变相返本销售；不得售后包租或变相售后包租未竣工商品房。

## 节点 2　预约与本约（硬闸）

支持依据（运行时复核）：民法典第 495 条；合同编通则解释第 6、7 条；商品房买卖合同解释第 5 条；商品房销售管理办法第 16 条。

### 2.1 切开标准

| 事实 | 定性 | 本任务动作 |
| --- | --- | --- |
| 只约定将来一定期限内订立商品房买卖合同，主体和房号可确定，未收房款或未具备第 16 条主要内容 | 预约 | 审预约违约、定金/订金和失败返还。不得宣布本约成立或定金双倍 |
| 具备第 16 条主要内容，且出卖人已按约定收受购房款 | 本约 | 按已成立的商品房买卖加选择权/转售权特别约定审查 |
| 已就标的、数量、价款等主要内容达成合意，未明确将来另订，或一方已履行主要义务对方接受 | 本约（通则解释第 6 条第三款） | 同上 |
| 仅意向、备忘，难以确定主体或标的 | 不构成预约 | 标缺口；不写预约违约 |

第 16 条对照清单（缺项记 `G#`，不补写）：当事人姓名住所；商品房基本状况；销售方式；价款确定方式及总价、付款方式时间；交付条件及日期；装饰设备标准；配套设施承诺；公建产权；面积差异处理；办证；争议解决；违约责任。

### 2.2 选择权与本约成立时点

选择权行权“转为真实买卖”必须写清：书面通知到达之日 / 双方按附件签署商品房买卖合同之日 / 网签完成之日，哪一个使本约成立。不得写成“双方再协商签约条件”。

特别约定优先：选择权、转售/更名、退出补偿、行政障碍补救条款的效力优先于其后使用的网签示范文本。网签不得删除或抵销上述特别约定。

### 2.3 定金

必须使用“定金”二字才讨论罚则。“订金、诚意金、认购金”无定金性质约定的，不得写成定金。数额不得超过主合同标的额 20%。无核验引文不得把 20% 写成已核验法律结论。

| 文本写法 | 动作 |
| --- | --- |
| “本认购书签字即本约成立，定金当然双倍”，但未列第 16 条主要内容且未收房款 | 必须改：按预约处理；未能订立本约时预订款返还，另有合法约定除外 |
| 已收大部分购房款且要素齐全，仍通篇只写“意向” | 必须改：承认已按本约履行，补选择权特别约定与网签义务 |
| “网签范本签署后，此前选择权协议自动失效” | 红线或必须改：特别约定继续有效，冲突时以本协议为准 |

修改句：

「双方确认：在买受人依本协议行使“转为真实买卖”的选择权并按附件签署商品房买卖合同之前，本协议构成预约，任何一方不履行诚信磋商并订立本约的义务的，应承担预约合同违约责任，但不因此视为商品房买卖本约已经成立。买受人已按约定支付的款项性质为【认购款 / 部分购房款】。若本协议已具备《商品房销售管理办法》第十六条所列主要内容且出卖人已按约定收受购房款，则本协议本身构成商品房买卖合同，选择权与转售条款作为特别约定继续有效。此后办理网签所用示范文本不得变更、限制或排除本协议的选择权、转售/更名、退出补偿及行政障碍补救条款；有冲突的，以本协议为准。」

最强反方：“没网签就一定是预约，可以随时不签。”现有依据不支持在已收房款且内容齐全时仍只当预约空转。

## 节点 3　选择权要件（硬闸）

选择权是本类型核心给付之一。未写清下列任一项：必须改。四项皆空且用户仍要“可以签”：不写可签署意见。

### 3.1 必须闭合的五项

1. **行权期限**：起止日历日或“自网签之日起【待填】日 / 至首次登记前”，不得只写“合理期限”或“长期有效”。
2. **行权方式**：买受人以书面通知行使；通知送达地址、电子邮箱或合同约定渠道；到达生效。口头或微信已读不写成已经行权，除非合同把该渠道写成送达且用户要保留。
3. **逾期默认路径（必须择一）**：期满未书面通知的，视为选择继续履行买卖，或视为选择解除。禁止同时写两种“视为”，禁止留空。
4. **退款时限与顺序**：出卖人在收到解除通知后【待填】个工作日内，将全部已付款及约定补偿支付至买受人指定账户；**前述款项到账是办理网签注销、撤销备案或交回合同的前提**。禁止“先撤签再协商退款”。
5. **补偿口径**：写明计算基数（已付款）、计息或补偿期间、年化或固定金额、付税主体。不得保证该口径在争议中一定不被重定性为借贷。超过合同成立时一年期 LPR 四倍的部分标红旗，数字用 `【待填】`，运行时核验。

修改句（选择权）：

「买受人有权（而非应当）在【待填年／月／日】至【待填年／月／日】内，向出卖人发出书面《行使选择权通知书》（格式见附件），选择下列一项：（一）继续履行并按附件签署或维持商品房买卖合同；或（二）解除本协议及已签署的商品房买卖合同。通知自送达出卖人指定地址或指定电子邮箱之日起生效。期限届满买受人未发出书面通知的，视为买受人选择【继续履行买卖 / 解除】。买受人选择解除的，出卖人应在收到通知后【待填】个工作日内，将买受人已支付的全部款项人民币【待填】元及按【待填计算口径】计算的补偿一次性支付至买受人指定账户。出卖人付清前述款项之前，双方不办理网签注销、撤销备案或交回合同原件；出卖人不得以尚未注销备案为由拒绝退款。」

### 3.2 出卖人反向限制

选择权期限内，出卖人不得以买受人未付清余款、未办理按揭或“内部销售政策变化”单方解除，除非买受人构成根本违约且合同已个别商议。修改句：

「在选择权期限内，除买受人严重违约且经书面催告在【待填】日内仍未纠正外，出卖人不得单方解除本协议或商品房买卖合同，不得拒绝接受买受人的行权通知。」

### 3.3 最强反方

- “选择权就是无条件退房，不必写期限。” → 权利长期不确定，必须改。
- “行业惯例先撤网签再退款。” → 现有依据不支持把该惯例写成可放行结构；钱房两空是红线。

## 节点 4　转售权、限购与再销售（硬闸）

### 4.1 转售 / 更名程序

转售权不是把房屋再卖一次的当然权利。预售阶段常见安排是：撤销原网签或办理合同主体变更，由出卖人与第三方直接签署新的买卖合同。产证后则为转让过户，税负与限购规则不同。

必须写清：

- 买受人确定第三方的期限与资格条件（第三方须具备当地购房资格，由第三方自行证明，出卖人配合核验但不保证通过）。
- 出卖人配合办理撤销备案、重新网签或主体变更的时限（`【待填】` 个工作日，自第三方资格核验通过且原买受人行权通知到达之日起算）。
- 溢价归属：市场成交价或新合同总价减去原认购价及约定税费后的差额，归原买受人 / 按【待填】比例分成。
- 结算路径：第三方将全部房价款支付至**该项目预售资金监管账户**；出卖人在到账后【待填】日内将溢价支付至原买受人。禁止第三方把溢价私下打给原买受人或打入非监管户。
- 规费、更名费、可能被税务机关按二次交易征收的税费由谁承担。未核税则 `G#`，修改句写“按实际发生由【待填】承担”，不设计“更名即可避税”。

修改句（转售）：

「买受人有权在选择权期限内为附件所列房屋寻找第三方。第三方应当具备房屋所在地当时有效的购房资格。出卖人应在第三方资格核验通过且收到买受人书面《转售/更名申请书》后【待填】个工作日内，配合办理原合同备案注销或合同主体变更，并与第三方直接签署商品房买卖合同。新合同总价款由买受人与第三方书面确认。第三方应将全部房价款支付至本项目预售资金监管账户【待填户名／账号／监管银行】。出卖人在监管账户到账后【待填】日内，将新合同总价款超出原认购总价及双方书面确认应由买受人承担的税费后的差额支付给买受人。各方不得将更名约定为避税安排；如税务机关按二次交易征税，税负按附件《税费分担》执行，未约定的标为待商事项，不保证更名可以少缴税。」

### 4.2 不得保证更名；行政障碍补救

支持依据：城市房地产管理法第 46 条（未竣工预售再转让由国务院规定）；销售管理办法第 10、39 条（未解除前不得再销售）。地方住建对网签撤销、退房率、更名窗口的限制须运行时核验，未核则字段停止。

修改句（行政障碍补救）：

「双方确认：合同主体变更、撤销备案或预售再转让能否办理，取决于房屋所在地当时有效的限购、网签和登记规则，出卖人不保证一定能够完成更名或再转让。因政策、网签系统、限购或登记机关原因，在买受人书面申请后【待填】日内无法完成更名或与第三方重新签约的，买受人有权改按本协议选择权条款解除合同；出卖人应按第【选择权退款】条在【待填】日内退还全部已付款及约定补偿，或按双方共同指定的评估机构在申请日的评估价回购该房屋权益。评估费由【待填】承担。买受人行使本条权利的，出卖人不得再主张继续履行或没收已付款。」

## 节点 5　主体、预售许可、监管账户与资金性质

1. 建主体表：签约名、土地使用权人、预售证主体、收款账户名、发票名、授权签字人。四名不一致不自动合并。
2. 房号锁定到栋、单元、层、号。只有“某花园一套”视为标的不确定，必须改。
3. 预售：须有覆盖该房号的预售许可。未取得预售许可订立的预售合同应当认定无效，起诉前取得可以认定有效——这是诉讼时点例外，签前意见只能是不签或等证后再签。用户要求把无证预售改成可履行：整体停止。
4. 监管账户：预售购房款必须进入该项目预售资金监管账户。营销户、集团户、个人卡、微信个人码：红线。修改句把账户写成“【监管银行】【待填监管账号】（该项目预售资金监管账户）”。
5. 已付款性质写清是认购款还是部分购房款。不符合销售条件不得收取预订款性质费用。
6. 员工定向：员工名义须真实。强制扣奖金“团购”并承诺转售，标红旗；修改句补自愿确认和退出通道。内部代持若用于规避限购：只告知，不写可履行代持。

不足：字段停止，列出待补，不补证号或账号。

## 节点 6　返本销售、集资、格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 6.1 返本销售与非法集资（停笔）

支持依据：销售管理办法第 11、42 条；防范和处置非法集资条例第 2 条；非法集资刑事解释（2022 修正）第 2 条第一项。

识别信号：面向不特定对象；公开宣传；许诺还本付息或固定投资回报；不以真实购房为主要目的；返本销售、售后包租、约定回购、销售房产份额。

动作：

1. 交付告知：该结构可能违反销售管理办法第 11 条，并可能落入非法集资行政或刑事评价。本任务不宣告已经构成犯罪。
2. 不写可履行的“改称资金占用补偿金即可过关”“对外募集但写成员工认购”路径。
3. 风险表只保留识别依据和删除/转出口径。
4. 用户坚持“改到能签且仍做这些事”：整体停止。

特定员工、真实购房意愿、退出只是个别商议的选择权，且无公开保本宣传：可继续审选择权程序，但仍须提示收益率过高可能被重定性为借贷，补偿数字 `【待填】`。

### 6.2 格式条款

开发企业重复使用的认购及选择权文本、补充协议，订立时未与对方协商的，是格式条款。不得仅以“用了示范文本”否认。保证更名、先撤签后谈退款、单方解释权、放弃限购审查、放弃解除权等异常条款须有足以引起注意的标识并按要求说明。小字、夹在附件、仅网络勾选：不得写成已尽提示或说明义务。

### 6.3 强制规范

违反法律、行政法规强制性规定不一律无效。禁止用已失效“效力性/管理性”口诀代替通则解释第 16 条。预售许可影响合同效力（解释第 2 条）。未备案原则上不影响效力（解释第 6 条）。规避限购、无证预售、返本销售、售后包租未竣工：不改写成有效履行结构。

## 节点 7　违约、解除、争议解决

1. 出卖人逾期退款、拒绝配合更名、拒绝接受行权通知，必须分别有可执行日违约金和达到约定期限的解除或强制履行安排。只有“依法承担违约责任”视为必须改。
2. 违约金不是必得金额。禁止“不得调整”或“按总价 30% 必得”。
3. 构成违约不等于当然解除。不在本任务作出已经解除的结论。
4. 争议解决：不动产纠纷可能专属管辖，约定其他法院只标红旗并建议改为房屋所在地法院。或裁或诉、机构不明：改成单一机构或单一法院连结点。
5. 通知送达：微信已读不写成已经到达，除非合同把该渠道写成送达且用户要保留。

修改句（拒绝配合）：

「出卖人无正当理由拒绝接受买受人行权通知、逾期退款，或在第三方具备购房资格后拒绝配合办理更名或重新签约的，应按未退款项每日【待填】‰向买受人支付逾期付款违约金，并赔偿买受人因此无法实现的转售差额中已书面锁定的部分。该违约金过分高于实际损失的，任何一方有权请求依法调整。」
