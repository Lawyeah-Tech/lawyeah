# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、对方接受、必然更名或必然过户；编造未给出的价款、期限、收益率；把已失效《合同法》或其解释、已被删除的 2003 年商品房解释第 14 条写入结论；把未竣工预售再转让写成全国一律可以办理；把包销余房强制买入或面积 3% 当默认主路径；把对外保本付息或规避限购写成可履行结构。

## 1. 触发、单方立场与成果状态

立场（买受人或开发企业出卖人）、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查附选择权、转售权的房产销售合同（买卖合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》及其解释、已被删除的 2003 年商品房解释第 14 条时，记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `买卖合同`，子级 `附选择权、转售权的房产销售合同`。定性理由、易混切开结果（包销、一般商品房、团购、定制、让与担保、工抵房、二手房）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。规避限购、返本销售、对外保本付息写停笔告知，不填可履行结构。

## 4. 主体、许可、资格与文本版本

主体表：签约名、土地使用权人、预售证主体、履行名、**收款账户名**、发票名、授权签字人、买受人共有方式、是否员工/特定对象。资格表：预售许可或现售备案痕迹；买受人限购/购房资格痕迹。版本表：正文、补充协议、行权通知样张、更名申请样张、员工认购明细、拟使用的网签范本、聊天确认；冲突并列。未核预售许可或限购资格：相应字段停止。

## 5. 给付闭环（本类型必填）

固定回答，缺项标 `G#`，不补商业数字：

- 房号是否锁定到栋、单元、层、号
- 文本是预约、本约，还是选择权行权后才成立本约；判断依据（第 16 条要素 + 是否已收房款）
- 选择权：起止日、书面通知、逾期默认路径是否已择一
- 退出时退款时限；退款是否先于网签注销
- 退出补偿/收益的计算口径、是否可能被重定性为借贷
- 转售/更名：流程、时限、溢价归属、结算路径、规费税费
- 行政障碍补救：无法更名时的退房或回购
- 限购资格与再销售：已披露 / 未披露 / 依据不足
- 收款账户是否预售资金监管账户
- 特别约定是否写明优先于后续网签模板
- 批准、登记、网签、更名写成生效条件或期限，不写成已经完成

不输出一般商品房面积 3% 专章，不输出包销余房强制买入专章。

## 6. 格式条款、强制规范与集资/返本销售

是否构成格式条款；保证更名、先撤签后谈退款、放弃限购审查、最终解释权等异常条款的提示说明痕迹。强制规范只按第 153 条和通则解释第 16 条区分。返本销售、售后包租未竣工、面向不特定对象保本付息：只保留识别与停笔。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。硬闸四项若文本触及或用户立场下原文沉默，必须各有至少一行。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点、不接受时的红线。未给出的商业数字用 `【待填】`。不得把框架里的“5 个工作日”写成法定期限。不得输出“保证完成更名”或“改称补偿金即可避开借贷/集资认定”作为可履行建议句。

## 9. 谈判与签署提醒

谈判顺序：先红线（类型错位、无证预售、非监管户、保证更名、规避限购、对外保本付息/返本销售、先撤签后谈退款），再必须改（选择权要件、预约本约关系、溢价与税费、行政障碍补救、特别约定优先），最后可优化。

签署提醒：预售证范围；监管账户；限购资格查询页；行权通知与更名申请样张入附件；不倒签；不指导先付款后补证；不指导借名或假离婚过限购。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本任务成果是可编辑草稿、未决项、自审风险表和自审后修改句。有完整待签文本要评改转 `附选择权转售权房产销售·审查`。草稿必须落入本类型起草必写 / 附件必附 / 禁止出现。不是履约交底、争议文书、效力保证或更名保证，也不是包销或一般商品房买卖审查。
