# 边界与路由

本技能只审查 **买卖合同 / 附选择权、转售权的房产销售合同** 的待签文本。中文展示名是「审查附选择权、转售权的房产销售合同（买卖合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 包销商以出卖人名义对外销售整盘或批量房源，期满未售须按包销价买入余房 | `房地产包销合同·审查`。不得把余房强制买入当本类型默认主路径继续审 |
| 无选择权、无转售/更名特别约定的一般商品房预售或现售 | `一般商品房买卖合同·审查`。不得把面积 3%、先验房、宣传入学当本类型默认主路径 |
| 按买受人图纸或配置定制建设 | `房产定制销售合同·审查` |
| 仅团购折扣或人数优惠，无退出选择、无更名转售 | `房屋团购合同·审查` |
| 以房抵工程款或债务 | `以房抵债工抵房·审查` |
| 名为买卖、到期回购或过户为担保 | `让与担保式房产买卖·审查` |
| 业主出售存量房，户口迁出、原贷结清过户 | `二手房买卖·审查` |
| 产权式酒店或售后包租未竣工商品房主轴 | `产权式酒店买卖合同·审查` 或引擎重新定性。返本销售/售后包租只告知，不改成可履行 |
| 有完整待签文本要评改 | `附选择权转售权房产销售·审查` | 在本起草原子做签前评改 |
| 无文本、本类型条件已谈妥，要出己方稿 | 留本任务起草并自审 |
| 已签未争、只问交房/办证/付款留痕 | 本套导航的履约步骤 |
| 已成争或已网签后要求解除、索赔、起诉 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

本类型正文另附一份无选择权的标准网签商品房买卖合同文本：网签范本中的面积、交付、办证专条交接 `一般商品房买卖合同·审查`；选择权、转售/更名、预约本约关系、限购再销售可继续审。用户坚持本技能把包销、普通商品房买卖、团购或让与担保整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿本类型文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
