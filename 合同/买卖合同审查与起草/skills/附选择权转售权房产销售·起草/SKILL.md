# 附选择权转售权房产销售·起草

## 任务目标

在单一立场下，只起草 **附选择权、转售权的房产销售合同**，并按本类型硬闸自审。交付可编辑草稿、未决项、自审风险表和自审后修改句。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P1**。中文名必须是「审查附选择权、转售权的房产销售合同（买卖合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性或更名/过户保证、把包销/普通商品房买卖/团购/定制/让与担保整案改完、把规避限购或对外保本付息改成可履行结构。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **选择权 / 转售权要件**：选择权须写清行权期限起止、书面通知、逾期默认路径（转为普通买卖或自动解除，必须择一）、退款时限、收益或占用补偿计算口径。转售权须写清更名或重新签约流程与时限、溢价归属与结算、规费税费分担、行政障碍补救。出卖人退还全部已付款及约定补偿，是办理网签注销的前提。禁止“先撤签再协商退款”。
2. **预约与本约**：仅锁定将来订约的是预约。具备《商品房销售管理办法》第 16 条主要内容且出卖人已按约定收受购房款的，按本约审查。要素不足不得宣布本约成立或定金双倍。选择权行权转为真实买卖须写清本约成立时点。选择权与转售特别约定优先于后续网签模板。
3. **限购与再销售**：限购资格未核则字段停止，不得写可以网签或可以更名。规避限购、借名、假离婚只告知，不改成可履行结构。未竣工预售再转让由国务院规定，不得写成全国一律可以更名。未解除合同前不得再销售。更名受阻必须有退房或回购补救，不得保证更名成功，不得设计避税结构。
4. **与包销切开**：包销是开发商将房屋交包销人以出卖人名义对外销售，期满未售由包销人按包销价购买 → 负触发 `房地产包销合同·审查`。本类型是特定买受人对特定房号的退出或转售/更名权，不承担整盘余房强制买入。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：本类型条件已谈妥、要出己方稿；尚未签署，尚未成争，核心给付是特定买受人对已锁定房号享有单方退出选择权和/或转售更名权。有完整待签文本要评改时转配对审查原子。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 包销商以出卖人名义对外销售，期满未售须按包销价买入余房 → `房地产包销合同·审查`；
- 无选择权、无转售/更名特别约定的一般商品房预售或现售 → `一般商品房买卖合同·审查`；不得把面积 3%、先验房、宣传入学当本类型默认主路径；
- 按买受人要求定制建设、重设计变更与交付标准 → `房产定制销售合同·审查`；
- 仅团购折扣或人数优惠，无退出选择、无更名转售 → `房屋团购合同·审查`；
- 以房抵工程款或债务 → `以房抵债工抵房·审查`；
- 名为买卖、实为担保融资、到期回购 → `让与担保式房产买卖·审查`；
- 业主出售存量房，户口/原贷结清过户 → `二手房买卖·审查`；
- 产权式酒店、售后包租未竣工商品房主轴 → `产权式酒店买卖合同·审查` 或引擎重新定性；返本销售/售后包租只告知，不改成可履行；
- 无文本、本类型条件已谈妥、要出己方稿 → 留本任务起草并自审；
- 已签只问交房、办证、付款留痕 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼、仲裁 → `或对应专项领域。` 或对应专项领域。

规避限购、无证预售、非监管户收款、面向不特定对象保本付息、返本销售：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（买受人或开发企业出卖人择一）；相对方；全文及行权通知/更名申请/员工明细版本；房号是否锁定；选择权期限、通知方式、逾期默认路径；转售/更名流程、溢价、税费、行政障碍补救；已付款性质与收款账户；预售许可痕迹；限购资格痕迹；是否面向不特定对象承诺保本付息；不可接受事项；项目所在城市与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价款、期限、收益率用 `【待填】`，不编造。

## 起草模式

本原子只起草本类型。有完整待签文本要评改时，转 `附选择权转售权房产销售·审查`。

仍只加载本目录 [基本面](references/基本面.md) 与 [框架](references/框架.md)。不另写一套硬闸。

先按框架六步落稿：首部 → 交易条款 → 配套 → 尾部 → 正说反说 → 必写与禁忌。商业数字未给用 `【待填】`。同一套本类型硬闸，在落稿时写成正文必写、附件必附或禁止出现，不得审完再补。

**起草必写：** 选择权写清行权期限起止、书面通知、逾期默认路径（转为普通买卖或自动解除，必须择一）、退款时限、收益或占用补偿计算口径；转售权写清更名或重新签约流程与时限、溢价归属与结算、规费税费分担、行政障碍补救；出卖人退还全部已付款及约定补偿，是办理网签注销的前提；预约与本约切开，选择权行权转为真实买卖须写清本约成立时点，选择权与转售特别约定优先于后续网签模板；更名受阻必须有退房或回购补救。

**附件必附：** 《行使选择权通知书（样本）》；《转售/更名申请书（样本）》。

**禁止出现：** “先撤签再协商退款”；要素不足宣布本约成立或定金双倍；规避限购、借名、假离婚可履行结构；未竣工预售再转让写成全国一律可以更名；未解除合同前再销售；保证更名成功；设计避税结构；承担整盘余房强制买入。

出稿后必须用本类型硬闸与 [审查方法](references/method.md) 自审。未过不得宣称起草完成。交付草稿、未决项、自审风险表、自审后修改句。

他类型出稿、已签履约、已成争：仍负触发。

## 判断节点

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。`基本面.md` 中“淡化借贷色彩”“更名避税”“房屋作为实物担保”不得写成可放行结构。`框架.md` 不得把包销式命名或“5 个工作日更名”当法定期限。

### 0. 签署状态与成果分流

有完整待签文本要评改 → `附选择权转售权房产销售·审查`；无文本且本类型条件已谈妥 → 留本任务起草并自审；已签履约 → 本套导航履约步骤；已成争 → 合同争议。未签且目标是按已谈妥条件出己方稿，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。包销、普通商品房买卖、团购、定制、让与担保、工抵房、二手房负触发。

### 2. 预约与本约

按第 16 条要素和是否已收房款切开。特别约定优先于网签模板。

### 3. 选择权要件

期限、书面通知、逾期择一路径、退款先于撤签、补偿口径。

### 4. 转售权、限购与再销售

更名流程、溢价、税费、行政障碍补救。资格未核字段停止。不得保证更名。

### 5. 资金、预售许可与监管账户

认购款/购房款性质；预售须许可且进监管户。无证或非监管户红线。

### 6. 返本销售、集资与格式条款

对外保本付息、返本销售、售后包租未竣工：只告知。无核验引文则法律结论字段停止。

### 7. 违约、解除与通知

拒绝退款或拒绝配合更名须有可执行后果；违约金可调整。不在本任务宣告已经解除。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效或保证更名、把无证预售/非监管户/规避限购/对外保本付息或返本销售改成可履行结构。
- `字段停止`：法域、动态规则、预售证范围、监管账户、限购资格、当地更名窗口、收益率是否超过保护上限未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。

生存级认购款或个人无限连带且用户拒绝升级：停止“可以签署”建议。
