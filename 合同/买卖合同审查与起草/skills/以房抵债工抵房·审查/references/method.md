# 审查方法（锁定 买卖合同 / 以房抵债（“工抵房”）合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型，禁止打开一般商品房、存量房或让与担保目录“对照一下”。

本文件是工抵房签前判断节点，不是栏目说明书，也不是商品房五证清单或存量房户口清单。禁止把面积误差百分之三、宣传学区、户口迁出写成兜底主路径。禁止把工抵房写成当然优于抵押权或当然排除查封。

每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、必然过户、必然排除执行、旧债已当然消灭、对方必然接受或唯一必得金额。

`search_law` 返回已失效《合同法》《物权法》《担保法》及其解释、合同法解释（二）、法释〔2002〕16 号《关于建设工程价款优先受偿权问题的批复》时记为噪声，不得写入 `L#`。消费者与承包人、抵押权人的顺位改走法释〔2023〕1 号批复和建设工程施工合同解释（一）已核验条文。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突。

示范文本只参考结构。网签商品房示范文本不证明抵债安排已被接受；符合格式条款定义的，仍按格式条款审查。

### 双文件使用

- `基本面.md`：校验 1+N 结构、债权溯源、主体、价款对冲、现金流、落空回溯、三方会签、语言正反说、虚假债权与二房东红旗。
- `框架.md`：供节点 8 按六步出句。其中“超级优先权转化为所有权即更强对抗抵押权”不得升格为现行规则；优先受偿与消费者保护按本方法硬闸 C 降级使用。
- 文件不可用（空、乱码、与工抵房明显无关）：记 `G#`，用本方法节点 0–8 继续，不改去加载 s001／s014 双文件，不编造结算额或地方阈值。

## 节点 1　类型识别：只留真实工抵房

用标题、核心给付、对价方式和用户陈述定性，不用标题单独定性。名实不符按核心给付归类，标题冲突写入 `C#`。两可时禁止同时加载邻类双文件。

### 1.1 本类型正像

同时满足才继续：

- 存在一项被主张的金钱债权，且文本把特定房屋的价款或所有权用于抵销／清偿该债权；
- 房屋处分路径指向开发商与买受人建立买卖关系，或债权人受领该买卖项下的对价；
- 待签、未成争。

典型外观：开发商欠施工方工程款；施工方或指定人作为买受人；买卖合同价款与债权额对冲。买受人可以是债权人自己，也可以是债权人书面指定的第三方。

### 1.2 让与担保切 `让与担保式房产买卖·审查`（硬闸）

出现下列任一主给付，**负触发**，不填本类型十节实体结论：

- 过户或网签的目的是为借款、往来款提供担保，并约定回购、溢价赎回或固定期限赎回；
- 履行期尚未届满，却约定到期不履行则房屋归债权人所有（流押句是主交易，而不是抵债文本里一句待删的病句）；
- 房价只是本金加利息的倒算，双方无真实买卖磋商，债权人也不占有、不办网签，只控制权证。

本任务动作：输出负触发路由到 `让与担保式房产买卖·审查`。**禁止**删掉回购／流押句后继续当真实工抵房审，禁止把让与担保改成“真实买卖”外观以规避流押规则。

若整体仍是届满后真实抵债，仅个别条款写成“到期不还房即归债权人”：留本任务，按硬闸 B 删除该句并改成拍卖、变卖、折价，不得据此转出。

### 1.3 普通买卖切 `一般商品房买卖合同·审查`／`二手房买卖·审查`（硬闸）

| 信号 | 归入 | 本技能动作 |
| --- | --- | --- |
| 无债权溯源、无抵销／抵债合意，开发企业预售或现售商品房 | 一般商品房买卖 | **负触发** → `一般商品房买卖合同·审查`。不得用本方法出实体结论 |
| 业主出售已办或应办存量房，价款现金或按揭支付，无工程款抵债 | 二手房买卖 | **负触发** → `二手房买卖·审查` |
| 封面写“以房抵债”，正文只是普通认购／预售且用户否认存在欠款 | 按核心给付转出 | 标题冲突写入 `C#`，不两套知识并行 |

不得删掉抵债条款后把本约改成普通商品房继续审。

### 1.4 加载协议

只打开本目录 `基本面.md` 与 `框架.md`。禁止读 `types/` 或其他场景原子目录。

### 1.5 违法结构停笔

出现下列任一结构，只出告知，不改写成可履行文本：

- 补假结算、倒签履行期、虚构工程量，以便对抗其他债权人或执行；
- 借用购房资格、假离婚、借名规避限购；
- 无证预售包装成可网签买卖；
- 施工方未取得所有权，以自己名义对外签买卖合同转售“工抵指标”（二房东式转售）。

用户坚持“改到能签／能避开查封／能过限购”：整体停止。合规改道（真实结算后再抵、解封后再处分、买受人与开发商直签）只点名，不在本任务起草规避方案。

基础施工合同存在挂靠、违法分包：告知该基础关系可能无效或被限制，不把无效基础债权改写成可履行抵债；质量合格时工程款请求权另有规则，本任务不展开工程整案。

## 硬闸 A　抵债真实性

本闸改变能否放行。没有可回链的基础债权，不得写“可以抵”。

1. **债权清单必须落到附件**  
   最低配置：基础合同名称与编号、项目位置、已完工或已结算事实、欠付本金（利息／违约金单列，不得默认进入优先受偿范围）、形成时间。修改句把经签章的结算单或对账单、欠款确认书列为附件，与正文冲突时以附件数字为准并设核对程序。

2. **书面真实性担保**  
   修改句要求债权人声明：该债权真实、合法、未全部转让给他人、未被生效法律文书否定；如虚假或被撤销，抵债约定不发生清偿效力，已办理的网签／登记配合回转，并赔偿开发商及其他债权人因此遭受的损失。买受人是指定第三方的，还须声明指定合法、指定人已知悉债权争议风险。

3. **对价合理性**  
   房屋定价明显低于同项目在售价，或债权额明显虚高：标红旗。合同编通则解释第 43 条方向：以明显不合理价格实施以物抵债，影响其他债权人实现债权，相对人知道或应当知道的，可能被撤销。材料不足：字段停止，不补“价格合理”。

4. **恶意串通与虚假意思表示**  
   用户承认“先做一套抵债挡住执行”或相对方是关联空壳：红线。民法典第 146、154 条方向：虚假意思表示无效；恶意串通损害他人合法权益的民事法律行为无效。本任务不设计对抗执行的交易外观。

5. **最强反方**  
   “双方盖章确认欠款，不必再附结算。” → 签前仍必须改。确认函不能代替工程量与价格依据；其他债权人、管理人或执行法院可以否定。  
   “起诉前补结算就行。” → 签前意见只能是：不签，或补齐真实结算后再签。不得写成“可以先签，无效了再补”。

核验失败：真实性字段 `依据不足`，修改句草稿继续，不写“债权真实、可以抵”。用户拒绝提供任何结算材料仍要放行：该部分红线；要求伪造：整体停止。

**本闸修改句最低成品**（数字用 `【待填】`）：

`定位：鉴于＋附件｜原文：双方确认甲方欠乙方工程款若干｜建议改为：截至【日期】，就【项目／合同编号】，经双方核对并作为附件一的结算单记载：已结算价款【金额】，已付【金额】，尚欠本金【金额】（利息、违约金不计入本次抵债本金，除非另页列明）。乙方保证该债权真实、未全部转让、不存在虚构。买受人签署对应买卖合同并完成约定网签（或过户）前，上述债务不视为清偿。｜理由：硬闸 A｜可退让点：用审计报告替代内部对账｜不接受时的红线：无任何结算依据仍签署`

## 硬闸 B　工程款基础（履行期届满前／后）

未切开履行期，不得写旧债已经或即将消灭。

### B.1 先固定“哪一笔债、何时到期”

文本或材料须能回答：付款节点或结算日后的应付日是否已经届满。只有“工程还在做、以后用房子顶”：按届满前处理，不得写成届满后清偿。到期日冲突并列 `D#`／`C#`，不选对用户有利的日期。用户要求倒签到“已到期”：整体停止。

### B.2 履行期限届满后（清偿型抵债）

合同编通则解释第 27 条（运行时复核后写 `L#`）：

- 届满后达成的以物抵债协议，无其他效力瑕疵的，自意思表示一致时生效；
- **履行该协议后**，相应原债务消灭；
- 未按约履行，经催告后合理期限仍不履行，债权人可选择请求履行原债务或以物抵债协议；
- 法院确认书或调解书本身不导致物权变动，也不当然对抗善意第三人；
- 以自己不享有处分权的财产订立的，按无权处分规则处理，不在本任务写成已取得所有权。

修改句必须锁定消灭时点，三者择一并写反说：

- 买受人与开发商完成该房网签备案之日；或
- 转移登记记载于买受人名下之日；或
- 交付占有且开发商出具全额房款确认函之日。

正说：到达该时点，对应金额的原金钱债务消灭。  
反说：未在【待填】日前完成该时点，或房屋被查封、另售、无法网签，则原债务不消灭，债权人可继续按原合同追偿，已作的“视为清偿”记载自动失效。

禁止原文“本协议签署之日工程款即告清偿”而无履行条件。最强反方“诺成合同签了就换了新债”：新债成立不等于旧债已消灭；第 27 条把消灭绑在履行上，除非当事人另有明确且可执行的相反约定，且该约定不能用于损害其他债权人。

### B.3 履行期限届满前（担保嫌疑）

合同编通则解释第 28 条（运行时复核后写 `L#`）：

- 届满前达成的以物抵债，应在审理债权债务关系的基础上认定效力；
- 约定到期未清偿则对抵债财产拍卖、变卖、折价实现债权：有效；
- 约定到期未清偿则抵债财产归债权人所有：该部分无效，但不影响其他部分；债权人仍可请求拍卖、变卖、折价；
- 未将财产权利转移至债权人名下，主张优先受偿：不予支持；
- 已转移的，按担保制度解释第 68 条处理（让与担保：可就变价优先受偿，不能直接请求确认所有权；回购＋到期归债权人的，参照流押处理）。

民法典第 401 条：届满前约定不履行则抵押财产归债权人所有的，只能依法就该财产优先受偿。

本任务动作：

1. 标红旗：届满前工抵房不产生直接所有权转移效力。
2. 删除“到期不还则房屋归乙方所有／自动过户”。
3. 改成：债务到期未获清偿的，双方按折价协议或依法拍卖、变卖实现债权；折价须另行核定当时市场价。
4. 主给付已是借款＋回购：按节点 1.2 转 `让与担保式房产买卖·审查`。
5. 未过户却写“乙方已享有优先于抵押权人的物权”：必须改。

### B.4 工程款范围

建设工程价款优先受偿的范围不含逾期利息、违约金、损害赔偿金（解释（一）第 40 条方向）。抵债本金与利息、违约金必须分列。用房价“打包吃进”全部违约金：标必须改，并提示对价不合理与撤销风险。

承包人行使优先受偿权有最长期限（解释（一）第 41 条：最长十八个月，自发包人应当给付建设工程价款之日起算）。文本把已逾行使期的“优先权”写成仍然附着于该房：字段停止或必须改，不得保证优先权仍在。

**本闸修改句最低成品**：

`定位：抵债效力条｜原文：协议生效即视为甲方已付清全部工程款，房屋归乙方｜建议改为：双方确认，本次抵债所对应的工程款本金债务履行期已于【日期】届满（未届满则不得使用本款，应改为到期未获清偿时就该房折价或拍卖、变卖，禁止约定房屋直接归债权人所有）。买受人与开发商就【房号】完成网签备案（或转移登记，须三方择一写死）之日，甲方对乙方在附件一金额内的本金债务消灭；在该日之前，或因查封、另售、无权处分导致无法完成的，该债务不消灭，乙方有权选择继续主张原金钱债权或请求继续履行本抵债安排。利息、违约金是否一并抵销，另纸列明，不当然计入优先受偿范围。｜理由：硬闸 B｜可退让点：消灭时点可在网签与过户之间协商｜不接受时的红线：签署即清偿且无回溯`

## 硬闸 C　过户、优先受偿与消费者购房切开

本闸改变谈判口径和修改句，不在本任务预判执行异议胜负。

### C.1 三件事拆开

| 行为 | 效果 | 不得写成 |
| --- | --- | --- |
| 抵债协议签字 | 债的安排成立（尚须看效力瑕疵） | 已经取得房屋所有权 |
| 商品房网签／备案 | 交易信息报送；一般不变动物权 | 已经过户；已经排除查封 |
| 预告登记 | 未经同意再处分不发生物权效力 | 已经取得所有权 |
| 转移登记记载于登记簿 | 物权变动 | 交钥匙即完成 |
| 交付占有 | 占有移转；可能影响执行异议第 28 条“合法占有” | 已经是所有权人 |

民法典第 209、214、215 条方向：不动产权利变动原则上记载于登记簿时发生；未登记不影响合同效力。修改句把网签、预告登记、交付、过户写成开发商义务和期限，并写逾期中止抵销、恢复原债或解除。

对应买卖合同若属预售：未取得预售许可的预售合同应当认定无效，起诉前取得的可以认定有效（商品房买卖合同解释第 2 条）。签前只能写：不签，或等证后再签。不得写“先签，无效了再补证”。用户要求把无证预售改成可履行：整体停止。

### C.2 优先受偿权 ≠ 消费者保护 ≠ 已过户

必须在意见里切开三种地位，禁止混写成“工抵房优先”：

1. **承包人工程价款优先受偿权**  
   法定优先权针对工程折价或拍卖价款，优于抵押权和其他债权（批复第 1 条指向解释（一）第 36 条；第 35、36 条全文本窗若未复核，运行时必须再核，不得把记忆条号写成已核验 `L#`）。它不是把某套房屋直接登记到施工方名下的权利。未竣工但质量合格的，可就承建部分主张（第 39 条）。

2. **商品房消费者**  
   法释〔2023〕1 号第 2 条：以居住为目的购买并已支付全部价款的，房屋交付请求权优先于工程价款优先受偿权、抵押权和其他债权；只付部分价款的，一审辩论终结前补足的，可以适用。第 3 条：房屋不能交付且无实际交付可能时，消费者价款返还请求权优先。  
   执行异议复议规定第 29 条（2015 年文本，2020 年修正仍沿用该条结构，运行时核验 2020 修正文本）：查封前已签合法有效书面买卖合同；用于居住且买受人名下无其他居住房屋；已支付价款超过合同总价款百分之五十。第 28 条是一般买受人路径，另需查封前合法占有、价款条件和非因自身原因未过户。

3. **普通金钱债权人或指定受让人**  
   不符合上列条件的，不能因为签署了工抵房协议就主张消费者超级地位。

### C.3 谁可能是消费者，谁不是

| 买受人画像 | 本任务写法 | 不得写成 |
| --- | --- | --- |
| 施工企业自己受让，用于抵债、再销售或给股东 | 不是商品房消费者；走债权实现／优先受偿或普通买受人 | 消费者排除执行 |
| 施工方法定代表人、关联公司、专为挡债设立的个人 | 高度可疑；真实性字段加重；不默认消费者 | 已经符合第 29 条 |
| 与债权人无关联的自然人，陈述自住，另付现金差价或有真实工资抵房 | 可以准备消费者路径的**合同条件**，但结论仍是 `依据不足` 除非材料能支持居住目的与付款事实 | 必然排除抵押和查封 |
| 指定买受人未实际支付，仅靠工程款抵销充“已付款” | 抵销能否视为已支付房款，各地和个案差异大：字段停止 | 已付超过 50%／已付全款 |

知识稿“强调已支付对价（通过债权抵销）且已占有或网签即可符合消费者标准”不得照抄为承诺。修改句只创造可检验事实：直签买卖合同、网签、预告登记、交付书面交接、开发商向买受人出具的房款（含抵销）确认函、买受人居住用途声明。是否被法院认定为消费者，本任务不预判。

### C.4 优先受偿权条款怎么改

- 就**本套房屋对应的抵债本金**，可以写：在约定消灭时点成就后，债权人不再就该金额向开发商重复主张优先受偿。
- **禁止**无条件概括放弃全部工程项目的优先受偿权并写成对开发商、银行一律有效。解释（一）第 42 条：约定放弃或限制优先受偿权损害建筑工人利益的，发包人根据该约定主张承包人已不享有优先受偿权，人民法院不予支持。
- 银行要求“先弃权再放贷”只作为相对方商业条件记录，不在本任务证明弃权有效。
- 折价协议或买卖被认定无效、撤销且承包人有恶意的，实务上存在不得再主张优先受偿的观点；本任务不写成必然，但虚假抵债场景应提示该风险。

### C.5 查封、抵押、另售

材料未提及不得写“无权利负担”。已查封：红线，不得设计“先过户再解封”。已抵押：写出披露、抵押权人书面同意处分、解押与过户顺序；不得写“工抵房当然优先于银行抵押所以不用理抵押权人”。开发商在抵债完成前再售或再押：写成违约并恢复原债、赔偿买受人。

**本闸修改句最低成品**：

`定位：过户与权利冲突条｜原文：乙方取得本协议项下房屋后优于任何抵押权人和申请执行人｜建议改为：开发商应于签署后【待填】日内办理该房网签备案，并配合买受人申请预告登记；于【条件】成就后【待填】日内申请转移登记。网签、预告登记或过户因抵押、查封、另售或无权处分不能完成的，对应金额的原工程款债务立即恢复，买受人有权解除对应买卖合同。买受人为施工方或其关联方的，各方确认其不援引商品房消费者排除执行规则；买受人为指定自然人且主张居住用途的，开发商应向其出具抵销金额的房款确认函，但各方知悉抵销是否构成已支付价款以及能否排除执行，须以届时法律和裁判为准，任何一方不得在合同中保证排除查封或优先于抵押权。债权人仅在附件一金额范围内、于消灭时点成就后停止就该金额重复主张优先受偿；不概括放弃其余工程款优先受偿权，该安排不得解释为损害建筑工人工资权益。｜理由：硬闸 C｜可退让点：消费者声明可单列附件｜不接受时的红线：保证排除执行或工抵房当然优先于抵押`

## 节点 2　1+N 结构、主体、指定买受人

1. 识别三层文件是否齐全：①开发商与债权人的抵债协议；②开发商、债权人、买受人的三方结算或指定协议；③开发商与买受人的买卖／网签合同。缺②却已出现第三方买受人：必须改，否则开发商可抗辩未同意指定。
2. 建主体表：开发商、债权人、买受人、收款账户名、发票名、授权签字人。四名不一致不自动合并。债权人是否具备指定权、债权是否已转让，材料未给则字段停止。
3. 买受人是指定第三方时，修改句写清：债权人仅有推荐权或指定权；**买卖合同由买受人与开发商直接签署**；债权人不得以自己名义向买受人收取房款或再转让房屋。
4. 口头“我们老板同意了”不得写成已授权。国资开发商或上市公司处分库存：内部决议未附则字段停止。
5. 对应买卖合同仍须主体一致：预售证或现售主体与签约开发商不一致，标红线并转述为放行障碍，但不把本任务做成五证专项。

## 节点 3　价款对冲、现金流、差额、发票

1. 总房款、抵债本金、现金补差、剩余债权分列。未给数字用 `【待填】`。房款高于债权：买受人向**开发商**补差，写账户（预售资金监管户优先，户名账号 `【待填】`）。房款低于债权：写明剩余金钱债权是否保留、何时付、是否仍主张优先受偿。
2. **禁止买受人将款项直接支付给施工方**，除非开发商书面授权且该授权不规避预售资金监管。否则开发商可以“未收到房款”拒交付、拒办证、拒开票。用户要求设计场外支付给施工方以绕开监管：整体停止。
3. 语言：用“以其对出卖人享有的等额到期债权冲抵购房款”，避免单独使用含糊的“代付”“内部划账”。抵销通知或三方确认到达即作为开发商已收款的意思，但旧债消灭仍受硬闸 B 时点约束。
4. 发票链条必须写：开发商向买受人全额开具不动产销售发票；债权人向开发商开具等额工程款发票。缺一环标必须改，提示办证和税前扣除障碍。不估算税负。
5. 定金：必须使用“定金”二字才讨论罚则；不得超过主合同标的额百分之二十，超过部分不产生定金效力。无核验引文不得把 20% 写成已核验结论。工抵房场景常无真实定金，勿把抵债金额改写成定金。

## 节点 4　程序、交付、联动解除

把批准、登记、备案、网签写成义务或生效条件，不写成已经完成。

| 文本写法 | 本任务动作 |
| --- | --- |
| 签字即房屋归债权人 | 拆成合同生效 vs 物权变动；回到硬闸 B／C |
| 网签后生效但无谁负责、几日、未完成后果 | 补开发商期限、逾期恢复原债或买受人解除 |
| 工抵房交付标准低于同项目销售房 | 必须改：交付、装修、保修与同项目普通销售房一致 |
| 领钥匙视为验收合格 | 必须改：先验房、书面异议后再签收 |
| 原施工合同无效或解除是否连坐买卖合同 | 必须写联动：基础债权被确认不存在或被撤销的，抵债与对应买卖可解除；已付款（含现金补差）退还**实际支付人** |
| 用户要求倒签网签日或补假预售证 | 整体停止 |

买受人独立救济：指定买受人应有权直接向开发商主张交房、办证、违约金，不须经施工方同意。退款路径锁死：退房时现金部分退买受人，抵销部分恢复债权人的金钱债权，禁止开发商把应退买受人的钱退给施工方。

管辖：建议各关联协议约定同一连结点（通常写房屋所在地人民法院）。**不得**写成“依法专属房屋所在地法院”——普通合同纠纷一般可协议管辖；不动产专属管辖主要针对物权确认等。或裁或诉、机构不明：改成单一机构或单一法院。已有仲裁条款不得擅自改成诉讼并假装已选定。

## 节点 5　格式条款与强制规范

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

开发商或总包重复使用的工抵模板、网签补充协议，订立时未与对方协商的，是格式条款。示范文本不当然排除。免责、单方取消抵债、买受人向施工方付款、放弃一切优先权、最终解释权等，须有足以引起注意的标识。小字、夹在附件、仅勾选：不得写成已尽提示说明义务。

违反法律、行政法规强制性规定不一律无效（第 153 条；合同编通则解释第 16–18 条方向）。禁止用已失效“效力性／管理性”口诀。预售许可影响预售合同效力。虚构债权、恶意串通损害其他债权人：不改成有效履行结构。

---

## 节点 6　违约、解除与落空回溯

1. 无法网签、无法过户、无法交付、开发商另售、房屋被查封，必须分别有可执行后果：原债恢复、买受人解除、已付现金返还、违约金。只有“依法承担违约责任”视为必须改。
2. 构成违约不等于当然解除。本任务不作出已解除结论，不精算违约金。避免“不得调整”或“按总价百分之三十必得”。
3. 正说必须有反说：清偿时点／未完成则不视为清偿。

---

## 节点 7　二房东转售、剩余债权与建筑工人

1. 债权人在未取得所有权前向不特定人售房、收定金、签买卖：停笔告知。可保留的合法结构只有：指定特定买受人＋该人与开发商直签。
2. 剩余工程款是否放弃，必须明示。沉默则解释为未放弃，但优先受偿期限仍可能经过。
3. 建筑工人工资、劳务分包款项：本任务不设计“用本套工抵房消灭全部工人工资请求”的条款。涉及农民工工资保证金或监管账户的，字段停止并建议专项核对。

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。硬闸 A–C 与节点 1 的两项切开，凡触及或原文沉默，必须落句。

| 步 | 本类型重心 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题用《以房抵债协议》或《工程款抵付房款三方协议》；1+N 点名；债权溯源入鉴于；三方主体 | 标题／鉴于／主体修改句 |
| 交易条款 | 履行期届满前／后；折算与差额；封闭现金流；旧债消灭时点；交付与同项目一致 | 闭环修改句；缺数字 `【待填】` |
| 配套 | 落空回溯；买受人独立救济；退款路径；优先受偿安排；消费者口径不保证 | 可执行后果句 |
| 尾部 | 三方会签；生效可挂接交回收据／开具发票；附件：结算单、指定书、收据样张、优先权安排 | 生效与附件修改句 |
| 语言 | 抵销≠代付；签署≠清偿；网签≠过户；定金≠订金；删“原则上”“自动归乙方所有” | 替换空词的句子 |
| 常见问题 | 虚假债权；二房东转售；发票断裂；把工抵房写成当然优先 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（无结算仍要抵、流押主交易、查封房先过户、买受人向施工方场外付款、二房东转售、无证预售、保证排除执行）；
- `必须改`：可谈但签署前要落句（消灭时点、差额、发票、三方会签、预告登记、退款路径、优先权不得概括放弃）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级金额或个人无限连带且用户拒绝升级：停止“可以签署”建议。
