# 边界与路由

本技能只审查 **买卖合同 / 物业服务合同（含前期物业服务合同）** 的待签文本。中文展示名是「审查物业服务合同（含前期物业服务合同）（买卖合同）」。

货架父级在买卖合同下，法律性质是物业服务。禁止使用半截 ID。禁止把商品房买卖或房产租赁审查方法套到本任务。

负触发只写触发判定、路由和最小交接，不填十节实体结论。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 房地产开发企业出售新房、房价过户、五证、预售资金监管为主轴 | `一般商品房买卖合同·审查`；本任务不审过户，不套面积 3% 或监管账户 |
| 业主出售存量房、户口迁出、原贷结清 | `二手房买卖·审查` |
| 房屋占有使用换租金、押金、租期 | `核心给付是房屋占有使用换租金→`；本任务不套二十年租期或买卖不破租赁 |
| 室内装饰装修承揽、装修工程款、工期验收为主轴 | 装饰装修承揽对应原子；未装则回引擎，不得用本技能硬套 |
| 买卖合同夹带物业专条，用户只要改房价过户 | 整案转 `一般商品房买卖合同·审查` 或 `二手房买卖·审查`；专条不单独当本任务完成商品房审查 |
| 买卖合同物业专条已构成可读物业服务安排，用户只要改该专条 | 可就该专条留本任务；仍不审房价过户 |
| 有完整待签文本要评改 | `物业服务合同·审查` | 在本起草原子做签前评改 |
| 无文本、本类型条件已谈妥，要出己方稿 | 留本任务起草并自审 |
| 已签未争、只问催费日、公示或报修留痕 | 本套导航的履约步骤 |
| 已催告、欠费诉讼、解聘纠纷、索赔或要诉讼策略 | `或对应专项领域。` 或 `或C端`；不写诉讼策略 |
| 专项维修资金使用已成争 | `维修资金使用已成争→` |
| C 端大众快检 | 只分流，不回改 |

专业版未收录的 P1 场景不会安装对应原子。若用户拿该文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。

用户坚持本技能给出商品房过户、租赁有效或欠费胜率意见：`目标停止`。
