# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、业主必然受约束、盗窃必然全赔或必然免责、对方必然接受；编造未给出的单价、面积、酬金比例；把已失效《合同法》、1996 收费暂行办法、已废止资质管理办法、2009 解释已删除条文写入结论；把商品房买卖或房产租赁 method 套到本约。

## 1. 触发、单方立场与成果状态

立场（建设单位 / 业委会或业主大会 / 单个业主 / 物业服务人）、授权、签署状态、主要目标。负触发写路由，不启动实体审查。写明中文成果名称是「审查物业服务合同（含前期物业服务合同）（买卖合同）」。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》、1996 收费暂行办法、已废止资质管理办法、2009 解释已删除条文或商品房买卖司法解释时记噪声，不得写入 `L#`。

## 3. 类型与加载路径

父级 `买卖合同`，子级 `物业服务合同（含前期物业服务合同）`。写明法律性质是物业服务，不是房屋买卖。定性理由、前期/普通切开、易混切开结果（商品房 / 二手房 / 租赁 / 装修承揽）。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。知识库与硬闸冲突时，以 method 硬闸为准。挂靠、全部转委托或伪造招标写停笔告知。

## 4. 主体、招标、资质与文本版本

主体表：委托方、物业服务人、收款名、发票名、授权签字人、业委会决议或建设单位身份。住宅前期：招标或批准协议选聘材料。资质：只核独立法人和地方信用，不把已废止资质等级当强制。版本表：正文、附件、买卖合同物业专条、宣传承诺、聊天确认；冲突并列。

## 5. 服务内容、计费与期限

服务区域与共有部分清单；保洁/电梯/秩序频次；秩序维护是否被写成保管；包干或酬金是否选定；面积口径；空置/未交付；前期是否接到新合同生效之日。缺口标 `G#`。

## 6. 交接、公共收益、格式条款与强制规范

撤场清单；是否约定停水停电或拒不退出；公共收益归属与公示；全部转委托；单方调价；维修资金与物业费切开。无 `search_law` 引文则本节点法律结论字段停止，事实摘录和修改句草稿继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔/转出口径。禁止输出无修改句的色块表。

## 8. 修改句

按已加载 `框架.md` 的六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点。未给出的商业数字用 `【待填】`。必须覆盖已触发的硬闸。禁止只给原则、不给句子。

## 9. 谈判与签署提醒

谈判顺序：先红线（未招标拒补、停水停电/拒不撤场、公共收益归物业、无限期前期排除解聘、保管全赔或完全免责），再必须改（计费模式、服务频次、940 衔接、交接清单），最后可优化。签署提醒：业委会决议或建设单位授权、招标/批准附件、服务标准与区域图、日期与计费起始日。不指导倒签或补假招标。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本任务成果是可编辑草稿、未决项、自审风险表和自审后修改句。有完整待签文本要评改转 `物业服务合同·审查`。草稿必须落入本类型起草必写 / 附件必附 / 禁止出现。不是履约交底、争议文书、商品房买卖审查或效力保证。
