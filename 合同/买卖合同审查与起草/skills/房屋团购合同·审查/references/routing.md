# 边界与路由

本技能只审查 **买卖合同 / 房屋团购合同**（以成团规模换优惠、由单位或中间方组织多名拟买受人锁定房源与团购价、待正式商品房买卖合同网签的预约/合作/服务文本）。

| 已能支持的事实 | 路由 | 不得写成 |
| --- | --- | --- |
| 待签、有成团基数或名单、有组织方或中间方、目标是评改团购文本 | 留本任务 | 已完成签约或已生效本约 |
| 无成团结构，文本是开发企业与单个买受人的预售或现售本约 | `一般商品房买卖合同·审查`；该原子不可用则 本套导航的类型切开步骤 | 用本技能把个卖五证/面积 3%/先验房主路径走完 |
| 整栋、整层、多幢打包整体销售 | `房屋整售合同·审查` | 把整售优先购买、共有部分当团购名单问题 |
| 按定作人规格、工期、变更签证后销售 | `房产定制销售合同·审查` | 把定制工期验收当团购成团条款 |
| 出卖人是业主/自然人，标的已办或应办存量房产权，户口/原贷/居间佣金 | `二手房买卖·审查`；该原子不可用则引擎 | 用本技能审二手房过户、户口、居间佣金 |
| 经济适用住房 | `经济适用房买卖合同·审查` | 硬套团购价或商品房预售规则 |
| 产权式酒店、售后包租、返本销售 | `产权式酒店买卖合同·审查` | 把返本/包租改写成团购优惠 |
| 以房抵债 / 工抵房 | `以房抵债工抵房·审查` | 把抵债折价当团购折扣 |
| 开发商把项目包给包销商包销 | `房地产包销合同·审查` | 把包销商当团购组织方 |
| 让与担保式买卖、附选择权转售、共有产权、动产或其他买卖原子 | 对应全 ID 或引擎重新定性 | 两可时灌入两套知识 |
| 无可读正文，本类型条件已谈妥，要出己方稿 | `房屋团购合同·起草` | 已经完成审查；在本审查原子出整稿 |
| 已签，问交房日、办证日、付款留痕、整改通知 | 本套导航的履约步骤 | 签前意见 |
| 已网签或已备案后要求解除、退房、索赔、起诉、仲裁 | `或对应专项领域。` 或新房退房/质量专项 | 继续当签前审查出修改句充作解除方案 |
| 已付款成争，只问能不能退诚意金/罚定金 | 争议或认购书解除专项 | 在本任务宣布本约成立或定金双倍 |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 | 两可时灌入两套知识 |
| C 端大众快检 | 只分流，不回改 | 降成 029 快检 |

挂靠、违法分包、规避限购、阴阳合同、无证预售、中间方代收房款、售后包租/返本销售：只告知违法风险，不改写成可履行文本。用户坚持改到能签：整体停止。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
