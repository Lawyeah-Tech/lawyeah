# 房屋团购合同·审查

## 任务目标

在单一立场下，只审查 **买卖合同 / 房屋团购合同** 的待签文本（团购合作/定向预约/团购服务或入园意向），输出：预约与本约切开、组织模式与资金路径核验、风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他合同类型。场景分层为 **P1**。专业版未收录本原子时输出 `unavailable`，提示，不得用邻类硬套。

`depends-on` 为空。不要求先跑导航。

不交付：他类型起草、履约交底、争议文书、有效性或必然成团/网签沿用团购价的保证。

## 工作边界

正触发：已有可读待签文本要评改；尚未签署，尚未成争，核心给付是以成团规模换取优惠单价并锁定名单/房源，待正式商品房买卖合同（本约）网签。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 无成团规模、无组织方或中间方、文本就是单套预售或现售本约 → `一般商品房买卖合同·审查`；该原子不可用则转 本套导航的类型切开步骤；
- 整栋、整层或整项目打包出售 → `房屋整售合同·审查`；
- 按定作人规格、工期、变更签证定制施工后销售 → `房产定制销售合同·审查`；
- 业主出售已取得产权的存量房 / 二手房 → `二手房买卖·审查`；
- 经济适用住房 → `经济适用房买卖合同·审查`；
- 产权式酒店、售后包租或返本销售 → `产权式酒店买卖合同·审查`；
- 以房抵债 / 工抵房 → `以房抵债工抵房·审查`；房地产包销 → `房地产包销合同·审查`；让与担保式买卖、共有产权或其他买卖合同原子 → 对应全 ID 或引擎重新定性；
- 无文本、本类型条件已谈妥、要出己方稿 → `房屋团购合同·起草`；
- 已签只问交房、办证、付款留痕 → 本套导航的履约步骤；
- 已成争（催告、解除、索赔、诉讼仲裁），**包括已经网签后要求解除或退房** → `或对应专项领域。` 或新房退房/质量专项，不在本任务做解除评估。

挂靠、违法分包、规避限购、阴阳合同、无证预售包装成可履行交易：只出告知，不改写成可履行结构。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成：

1. **预约 / 本约切开**。本协议默认锁定团购优惠与房源，属于预约，不是权属转移本约。须写清转本约条件：最低成团套数或面积**且**取得覆盖该房源的预售许可（或现售条件成就）后【待填】日内启动网签。已写全销售管理办法第 16 条主要内容且已收受购房款的，按本约风险升级，并核预售许可；不得用个卖面积 3%、先验房、五证全表替代本闸。
2. **单位团购 / 中间方切开**。单位是组织者或代办者，不承担房款，也不当然取得产权。须落“指定员工在未明确拒绝时可直接请求开发商按团购条件签署本约”（民法典第 522 条第二款），不能只写“为第三人利益”。中间方须切开：持销售委托书的代理商，还是仅撮合的服务商。三方文本缺开发商或买受人签章（抽位）：红线。
3. **成团规模、阶梯或一口价、最惠待遇、价格独立**。成团基数（不少于【待填】套或【待填】㎡）是享受团购价的前提。必须写明一口价还是阶梯价，禁止“团购价”与“一口价”混用。买受人侧要求最惠：同期对外最低成交价差价补偿。必须有修改句：“本协议价格条款具有独立效力，不受后续单套网签格式价格条款覆盖。”
4. **名单、置换与指定人**。附件必须有盖章的《团购人员名单及份额确认表》和《团购房源一览表及价格表》。正式网签前的置换次数、截止日和资格复核必须落句。单位有权单方指定实际买受人，开发商不得拒绝指定人本身；限购资格另核，不在本任务写成必然可网签。
5. **资金路径与变相无证预售**。购房款、定金、意向金必须直接支付至开发商该项目预售资金监管账户；中间方只收取已标明的固定服务费。中间方、营销户或个人卡代收房款：红线。不符合商品房销售条件的，不得向买受人收取任何预订款性质费用（销售管理办法第 22 条）；不得把“不超过房价 20%”写成可以先收。服务费是否抵扣房款必须写清；“5 万抵 10 万”须拆开前款性质与后款是减免还是计入总价。
6. **成团失败、拒签本约、资格退出**。未达最低成团：已收款项【待填】日内全额无息退还，互不承担违约责任。开发商在符合签约条件后拒绝按团购价与名单人员签本约：对组织方支付违约金，对已交付定金的买受人双倍返还定金（或预约违约金不低于定金双倍）。因限购等政策丧失购房资格：该成员无损退款——只告知退出路径，不写借名、假资格或阴阳价。
7. **网签模板锁定**。附件须有《正式网签合同模板》。核心条件（团购单价或折扣、抵减额、预留房源范围、监管账户、意向金转定金或首付的规则）写入模板且声明后期网签不得单方变更。生效条件写清：达到最低成团**且**买受人身份核实通过。

必须有修改句。禁止只打红黄绿。每个风险回链文本位置。

## 判断节点

以 [审查方法](references/method.md) 为准。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。交付按 [输出合同](references/output-contract.md)。边界见 [路由](references/routing.md)。

入口（细节以 method 为准）：

0. 签署状态分流：已网签要解除 → 争议；无文本且本类型条件已谈妥 → `房屋团购合同·起草`；已签履约 → 本套导航履约步骤。
1. 类型切开：有成团换优惠、有组织方或中间方、预约转本约才留本任务；个卖本约转 `一般商品房买卖合同·审查`。
2. 单位团购 vs 中间方；第三人直接请求权；委托书与抽位签章。
3. 预约/本约 + 预售条件 + 未达销售条件不得收预订款。
4. 名单、置换、指定人、房源锁定、选房顺序。
5. 阶梯/一口价、最惠、价格独立、服务费是否抵扣。
6. 监管账户、成团失败退款、拒签本约、发票主体。
7. 格式条款；限购/阴阳只告知；集中管辖。
8. 按框架六步出修改句。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；用户坚持伪造倒签、补假预售证、规避限购或做阴阳合同、把无证预订款或中间方代收改成可履行结构、保证有效或保证成团/网签沿用团购价。
- `字段停止`：组织模式、预售许可是否覆盖预留房源、监管账户、名单资格、地方限购或监管细则未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议/解除文书，或要求按个卖本约把面积 3%/先验房审完。

生存级诚意金或个人无限连带且用户拒绝升级：停止“可以签署”建议。
