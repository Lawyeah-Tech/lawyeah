# 边界与路由

本技能只审查 **买卖合同 / 房产定制销售合同**。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 标准商品房预售／开发商现售，仅菜单精装或选装，无结构／机电／户型前置定制 | `一般商品房买卖合同·审查` |
| 整栋打包转让、外墙屋顶冠名等整栋控制权，无个性化技术任务书 | `房屋整售合同·审查` |
| 已办证存量房、个人或非定向开发出卖人 | `二手房买卖·审查` |
| 主给付为施工总包、专业分包、监理，不转移房屋所有权 | 工程类场景原子或引擎重新定性 |
| 经济适用房、共有产权、让与担保、以房抵债 | 对应场景原子，不在本技能硬套 |
| 无文本、本类型条件已谈妥，要出己方稿 | `房产定制销售合同·起草`；不得在本审查原子出稿 |
| 已签未争、履约节点 | 本套导航的履约步骤 |
| 已交付或已办证仍要解除、索赔 | 合同争议或房屋专项；不填签前十节 |
| 已成争（催告、立案、仲裁） | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。

本技能不得转去加载 `一般商品房买卖合同·审查`、`房屋整售合同·审查` 或 `二手房买卖·审查` 的双文件完成本类型审查。期房定制出现预售许可，仍留本技能，只把许可当作程序核验项。
