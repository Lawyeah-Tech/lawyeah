# 经济适用房买卖合同·审查

## 任务目标

在单一立场下，只审查 **买卖合同 / 经济适用房买卖合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他类型。场景分层为 **P0**。`depends-on` 为空。不要求先跑导航。

不交付：他类审查、从零起草、履约交底、争议文书、有效性或过户／转商保证、可履行的转让指标／借名／规避限购结构。

## 工作边界

正触发：已有可读待签文本要评改；尚未签署，尚未成争，核心给付是经济适用住房（有限产权、划拨用地、政府定价或已购经适房再转让）的房屋权利转移换价款。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 普通商品房预售或开发商市场价现售（预售许可证、五证主路径、面积误差百分之三、无准购资格）→ `一般商品房买卖合同·审查`；
- 政府与买受人按份共有、份额比例写入权证的共有产权住房 → `共有产权住房买卖合同·审查`；
- 已办证普通存量商品房、无保障房限制，主轴是户口、资金监管、阴阳合同 → `二手房买卖·审查`；
- 让与担保式买卖、以房抵债、中介主文件 → 对应场景原子；
- 无文本、本类型条件已谈妥、要出己方稿 → `经济适用房买卖合同·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已过户或已出现催告、索赔、诉讼仲裁 → 合同争议或对应专项领域。

转让购房指标、借名申购、规避限购、未满五年私下过户包装：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；买方／卖方／保障机构单一立场；相对方；正文、附件、补充协议、资格核准文件版本；房屋坐落与权证号；首次申购还是已购再转让；不可接受事项；房屋所在地与拟签时限。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的价格、面积、补缴比例、起算日用 `【待填】`，不编造。

## 本类型硬闸

审查过程必须逐项点名。禁止用商品房五证清单、共有产权份额表或普通二手房户口／监管清单代替：

1. **申购资格**：买受人须经住房保障部门审核、公示并持有仍在有效期内的准购／核准文件；共同申请人与签约名一致；禁止无资格人员加名或受让指标。
2. **有限产权与划拨**：正文须写明经济适用住房、有限产权、划拨用地；未补缴土地收益前不得写成完全产权或出让商品房。
3. **政府定价与禁止加价**：价款以政府公布的基准价／核准价为上限；装修费、指标费、手续费、捆绑车位等价外加价标红线，不得改成可履行加价结构。
4. **上市交易限制**：自不动产权证登记日或契税完税凭证填发日起算（以地方规则或约定孰先为准，未核验则字段停止）；不满五年不得直接上市，特殊原因走政府原价结合折旧回购；满五年上市须书面征询政府优先购买，并约定土地收益等相关价款的计算基数、比例、承担人和缴纳时点。
5. **骗购与违规处分**：隐瞒收入或住房骗购的收回／解除；取得完全产权前不得出租经营；抵押原则上仅限购房贷款。
6. **类型切开**：出现五证／预售许可主路径而不谈准购，转 `一般商品房买卖合同·审查`；出现政府按份共有份额，转 `共有产权住房买卖合同·审查`；已转商并取得完全产权后的普通存量交易，转 `二手房买卖·审查`。

## 律页能力增强

本技能属于律页法律技能家族，并支持 Lawyeah MCP 按需增强。

- 运行环境提供 Lawyeah MCP 时，执行 Agent 根据当前任务按需使用法律法规、法律实务、裁判案例或文书范本检索。
- 法规用于核验中国大陆现行条件和效力时点；实务用于发现争点、审查反例和路径；案例只比较事实差异与翻转条件，不写成必然结果；范本只借鉴栏目结构，不证明本约条款已被接受。
- 任何结果都要复核法域、效力、时点、地区和与当前事实的差异。不得把已失效《合同法》《物权法》及其解释当作现行规则。不得把商品房预售许可、五证清单、面积误差百分之三、预售资金监管等开发商商品房规则当作本类型默认法。
- 《经济适用住房管理办法》（建住房〔2007〕258 号）是部门规章。运行时核验其条文与地方实施细则；不得把部门规章直接写成“违反即合同必然无效”。
- MCP 未安装、未启用、未暴露、无结果、结果冲突或暂时不可用时，不拒绝执行、不中断主流程。继续使用本技能内置方法和用户材料完成文本与事实审查；依赖未核验规则的法律结论、期限、补缴比例或机关路径保持停止或待核。
- 不向用户索取密钥、令牌或完整凭证。MCP 是可选增强，不是用户运行技能的强制依赖。

## 使用 Lawyeah MCP

宿主可调用时：`search_law` 核验物权变动与合同区分、强制规范与公序良俗、定金上限、格式条款、虚假意思表示、不得转让情形、契税纳税人；核验《经济适用住房管理办法》和地方实施细则的准入、五年限制、回购与土地收益；`search_practiced` 补未满五年转让效力分化等审查反例；`search_template` 只借修改句结构。不虚构案件系统。

`search_law` 对法律结论为 required 级节点：不可用时不拒绝执行，只停止法律结论字段。返回已失效《合同法》《物权法》及其解释时记为噪声，不得写入 `L#`。返回商品房预售或五证专属规则时，不得当作本类型默认法。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无可读文本仍要实体意见；用户坚持伪造倒签以制造满五年、转让指标、借名申购、规避限购、把未满五年私下买卖或价外加价改成可履行过户文本、保证有效或必然转商／过户。
- `字段停止`：准购文件、权证起算日、地方土地收益比例、住房保障部门优先购买程序未核验；关键价款或面积缺失。
- `目标停止`：主目标已变为他类型起草、履约交底或争议文书。

生存级首付或个人无限连带且用户拒绝升级：停止“可以签署”建议。
