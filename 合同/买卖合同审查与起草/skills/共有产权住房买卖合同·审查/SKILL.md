# 共有产权住房买卖合同·审查

## 任务目标

在单一立场下，只审查 **买卖合同 / 共有产权住房买卖合同** 的待签文本，输出风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他 289 类。场景分层为 **P0**。中文名必须是「审查共有产权住房买卖合同（买卖合同）」。

`depends-on` 为空。不要求先跑导航。

不交付：他类文本审查、从零起草、履约交底、争议文书、有效性保证、把普通商品房或经适房改完。

## 本类型硬闸

每闸必须出修改句或明确停笔口径，禁止只打红黄绿。

1. **共有份额**：合同必须量化购房人与代持机构（代表政府）各自产权份额；购房人应付价款只对应其份额；须另载房屋销售均价或全额参考价。缺份额不得写成已取得完整所有权。知识示例“60%/40%”不是法定比例，数字用 `【待填】`。禁止用民法典第 309 条等额规则填政策性份额空白。
2. **转让限制**：禁售期、再上市受让人资格、代持机构同等条件优先回购或优先购买必须落句。不得写成普通商品房自由上市。禁售年限以房屋所在地共有产权住房管理办法为准，不得把知识里的“五年”写成全国法定期限。
3. **资格**：申购资格证明作为附件。未核则签署能力字段停止，不写“可以购买”。虚假申报、借名、伪造资格只告知强制回购与停笔，不改成可履行骗购。
4. **与经适房 / 商品房切开**：划拨土地、无政府按份登记、上市以补缴土地出让金换全产权 → `经济适用房买卖合同·审查`。无代持份额、买受人取得完整产权的普通商品房 → `一般商品房买卖合同·审查`。普通存量二手商品房 → `二手房买卖·审查`。不得删掉代持/份额后按商品房审，也不得把商品房审成本类型。

禁止只打红黄绿。每个风险回链文本位置。必须有修改句。

## 工作边界

正触发：已有可读待签共有产权住房买卖或预售正文，尚未签署，尚未成争，核心给付是共有产权住房所有权份额转移换价款，购房人与政府指定代持机构按份共有，用户问能否签、哪里必须改、怎么回对方。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 普通商品房预售或现售，无政府代持份额 → `一般商品房买卖合同·审查`；
- 经济适用房、已购公房，划拨土地或以补缴土地出让金换全产权为主轴 → `经济适用房买卖合同·审查`；
- 普通存量商品房二手买卖，出卖人为个人且无代持份额 → `二手房买卖·审查`；
- 名为买卖实为担保回购 → `让与担保式房产买卖·审查`；
- 以房抵债、工抵房 → `以房抵债工抵房·审查`；
- 主给付是居间报酬或带看成交 → `存量房买卖或租赁居间带看二手房→`；
- 无文本、本类型条件已谈妥、要出己方稿 → `共有产权住房买卖合同·起草`；
- 已签只问履约节点 → 本套导航的履约步骤；
- 已催告、解除、索赔、诉讼或仲裁，或已发强制回购通知要异议策略 → `或对应专项领域。` 或对应专项领域。

虚假资格、借名购买保障房、规避限购、把共有产权改成可自由上市：只出告知，不改写成可履行结构。

## 建立审查坐标

确认：使用者与授权；单方立场（购房人侧、开发商侧或代持机构侧择一）；相对方；全文及使用承诺书、共有产权协议、代持证明、资格材料版本；是否载明共有产权及各方份额；土地取得方式；价款是份额对应价还是全价；禁售期与再上市对象；抵押范围；不可接受事项；法域、房屋所在地与拟签署日。缺立场或无可读文本则不启动实体审查。同时掌握双方秘密或潜在冲突时，先停止策略输出。

## 来源和判断状态

编号：`S#` 单方陈述；`D#` 材料表面；`A#` 当前一致／承认；`C#` 合同条款定位；`L#` 运行时已核验规则；`I#` 判断；`G#` 缺口。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。冲突版本并列，不自行选取对用户有利的一版。未给出的份额、价款、年限用 `【待填】`，不编造。

执行顺序和停止条件以 [审查方法](references/method.md) 为准。这里只列入口。本技能固定加载：

### 0. 签署状态与成果分流

无文本且本类型条件已谈妥 → `共有产权住房买卖合同·起草`；已签履约 → 本套导航履约步骤；已成争或强制回购争议策略 → 合同争议。未签且目标是评改已有共有产权住房买卖文本，才进入本任务。

### 1. 类型锁死

标题、核心给付与对价方式一致才继续。商品房全产权、经适房补出让金、普通二手、担保回购、抵债、中介负触发。

### 2. 三方主体、资格与授权

开发商、购房人、代持机构分列。资格证明未核：字段停止。缺丙方签章：字段停止。

### 3. 份额、价款与登记

份额量化；价款对应购房人份额；全额参考价单列；权证登记为按份共有并载明份额。

### 4. 转让限制与退出

禁售期 `【待填】`；受让人资格；代持优先回购；不得自由上市。

### 5. 使用、抵押、居住权

自住；出租须同意并分配收益；抵押仅限购房人份额且限于购房贷款；禁止单方设立居住权。

### 6. 格式条款与强制规范

资格撤销、强制回购、禁售等异常条款须提示说明。虚假资格/借名停笔。无核验引文则法律结论字段停止。

### 7. 违约、解除与争议

骗购强制回购须有通知、计价和返还路径。不选定唯一法院充作意见。

### 8. 按框架六步出修改句

必须有可回给对方的修改句或红线。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；无书面文本仍要实体意见；用户坚持倒签、保证有效、把虚假资格/借名/规避限购或自由上市改成可履行结构。
- `字段停止`：法域、地方共有产权管理办法、禁售年限、回购公式、资格文号、代持授权未核验。
- `目标停止`：主目标已变为从零起草、履约交底、争议文书，或已锁他类。
