# 边界与路由

本技能只审查 **买卖合同 / 共有产权住房买卖合同** 的待签文本。中文展示名是「审查共有产权住房买卖合同（买卖合同）」。

负触发只写触发判定、路由和最小交接，不填十节实体结论。禁止使用半截 ID。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定，或名实明显不符 | 本套导航的类型切开步骤 |
| 普通商品房预售或现售，无政府代持份额，买受人取得完整产权 | `一般商品房买卖合同·审查`。不得删掉商品房条款后继续当共有产权审 |
| 经济适用房、已购公房；划拨土地；上市以补缴土地出让金换全产权 | `经济适用房买卖合同·审查`。不得把补出让金写成共有产权退出 |
| 普通存量商品房二手买卖，出卖人为个人且无代持份额 | `二手房买卖·审查` |
| 名为买卖实为担保回购 | `让与担保式房产买卖·审查` |
| 以房抵债、工抵房 | `以房抵债工抵房·审查` |
| 主给付为居间、带看、独家委托 | `存量房买卖或租赁居间带看二手房→` |
| 无文本、本类型条件已谈妥，要出己方稿 | `共有产权住房买卖合同·起草`；不得在本审查原子出稿 |
| 已签未争、只问履约节点 | 本套导航的履约步骤 |
| 已成争，或代持已发强制回购通知要异议策略 | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改 |

封面写商品房、正文有代持份额和资格附件：按核心给付留在本技能，标题必须改，不转 `一般商品房买卖合同·审查`。

已取得共有产权证的家庭转让自身份额：仍走本技能再上市场景，不转 `二手房买卖·审查`。

共有产权正文里夹带一小段中介佣金：佣金专条可交接 `存量房买卖或租赁居间带看二手房→`；份额、资格、转让限制继续审。用户坚持本技能把商品房、经适房或普通二手整案改完：`目标停止`。

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。
