# 房屋整售合同·审查

## 任务目标

在单一立场下，只审查 **买卖合同 / 房屋整售合同** 的待签文本（整体销售专门协议及配套拟网签稿），输出：整体性与「1+N」优先核验、共有部分/租约/解押监管核验、风险表、可回给对方的修改句或红线、谈判与签署提醒。

本技能类型锁死。不扫描其他合同类型。场景分层为 **P0**。

`depends-on` 为空。不要求先跑导航。

不交付：他类型起草、履约交底、争议文书、有效性或整栋过户/税负保证。

## 工作边界

正触发：已有可读待签文本要评改；尚未签署，尚未成争，核心给付是**单一买受人（或其指定主体）打包受让整栋、整层或可独立封闭运营的整宗房屋资产**，目的是取得完全控制权（含外墙、屋顶、大堂等共有部分的使用权与收益权）。

负触发并输出 `触发判定：负触发，未启动本任务`：

- 房地产开发企业向社会**逐套散售**预售或现售 → 转 `一般商品房买卖合同·审查`；
- 业主出售已取得产权的**单套存量房** → 转 `二手房买卖·审查`，若该原子不可用则转 本套导航的类型切开步骤；
- 多个独立买受人集合购买，公有部分仍按份共有 → 转 `房屋团购合同·审查`（房屋团购）；专业版未收录则 `unavailable`，不得用本技能硬套；
- 按买方技术任务书**定向开发/定制** → 转 `房产定制销售合同·审查`；
- 包销方代理销售并在期满**强制购买未售存货** → 转 `房地产包销合同·审查`（房地产包销）；专业版未收录则 `unavailable`；
- 通过收购项目公司股权间接拿房 → 转 `通过收购项目公司股权间接拿房→转`；不含整栋房屋控制权的单项资产收购 → 转 `不含整栋房屋控制权的单项资产收购→转`；
- 无文本、本类型条件已谈妥、要出己方稿 → `房屋整售合同·起草`；
- 已签只问交房、办证、付款留痕 → 本套导航的履约步骤；
- 已成争（催告、解除、索赔、诉讼仲裁），**包括已经批量网签后要求解除** → `或对应专项领域。`，不在本任务做解除评估。

挂靠、违法分包、规避限购、改变规划用途包装成可履行、违反自持期限转让、体外循环解押：只出告知，不改写成可履行结构。

## 本类型硬闸

未完成下列切开和落句，不得宣称审查完成。**禁止把散售商品房的五证清单当作本类型默认主闸。**

1. **整体性切开**。买受人必须是单一主体或其指定主体；交易目的是整栋/整层完全控制权。多名互不隶属买受人且公有部分仍按份共有 = 团购，转出。禁止解释为可部分履行的散售集合。
2. **「1+N」主协议优先**。必须存在（或补写）整体销售专门协议，并约定与网签标准买卖合同冲突时**以主协议为准**。缺优先条款 = `必须改`。
3. **土地出让 / 自持 / 规划用途**。核土地出让合同及补充协议：是否不得分割转让、须整体运营、自持年限、规划用途。拟改变用途或未满自持仍转让：红线，不改成可履行文本。
4. **整体转让权，不是五证表**。重点是出卖人有无权利把整栋打包转让，以及不动产登记簿上的抵押/查封。开发商存货可把证照作为尽调附件，不得用预售证覆盖单套房源那一套默认表替代本闸。
5. **共有部分与冠名权入附件**。屋顶、外墙广告、大堂、管井、避难层、地下车位/人防/机房、建筑冠名权必须有范围界定，不得只列专有部分房号。
6. **租约与工程款**。带租约必须在「清场交付」与「带租约转让」中二选一并处理承租人优先购买通知或书面弃权。工程款未结清、施工方优先受偿未闭合：红线或字段停止。
7. **资金封闭监管 + 先解押后过户**。首笔用于解押的款项必须进三方监管账户并专款脱抵；提前大额解押款须有反担保。进出卖人一般户：红线。
8. **面积与解除的双红线**。按实测调整总价；**单套**与**整栋合计**面积误差均须有解除阈值。禁止只写「按规定」或只抄散售单套 3% 而不写整体红线。任一套因出卖人原因不能过户，买受人有权**整体解除**。

必须有修改句。禁止只打红黄绿。每个风险回链文本位置。

## 判断节点

以 [审查方法](references/method.md) 为准。本技能固定加载：

- [基本面](references/基本面.md)
- [框架](references/框架.md)

禁止打开其他类型目录。交付按 [输出合同](references/output-contract.md)。边界见 [路由](references/routing.md)。

入口（细节以 method 为准）：

0. 签署状态分流：已批量网签要解除 → 争议；无文本且本类型条件已谈妥 → `房屋整售合同·起草`；已签履约 → 本套导航履约步骤。
1. 类型切开：单一买受人打包整栋控制权才留本任务；散售转 `一般商品房买卖合同·审查`；二手转 `二手房买卖·审查`；团购转 `房屋团购合同·审查`；定制转 `房产定制销售合同·审查`；包销转 `房地产包销合同·审查`；股权收购转 `通过收购项目公司股权间接拿房→转`。
2. 整体性语言、1+N 优先、土地用途/自持/分割限制。
3. 主体、国资评估进场、企业购住宅限购、工程款、承租人优先购买。
4. 房号清单、共有部分图、地下/人防、面积双红线、风险转移时点。
5. 大证拆分、批量网签、内部决议、税费预审、国资生效条件。
6. 整体包干价与网签拆分价、三方监管、解押、反担保、定金。
7. 格式条款；改变用途/自持不改结构；税费承担与发票类别。
8. 按框架六步出修改句：部分不能过户=整体解除；排他期；物管撤场。

## 停止与安全

- `整体停止`：立场或授权不明；利益冲突未解；用户坚持伪造倒签、补假解押/假进场、规避限购、把改变规划用途或违反自持改成可履行结构、设计体外循环解押、保证有效或保证整栋过户/税负上限。
- `字段停止`：土地出让限制、抵押状态、工程款、租约清单、国资程序、监管账户、限购资格、地方批量网签规则未核验。
- `目标停止`：主目标已变为他类型起草、履约交底或争议/解除文书。

生存级首付款或个人无限连带且用户拒绝升级：停止「可以签署」建议。
