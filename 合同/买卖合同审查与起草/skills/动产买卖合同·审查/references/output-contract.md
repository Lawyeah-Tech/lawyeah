# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、货物必然合格、所有权保留必然对抗第三人或对方接受；编造未给出的单价、数量、交货日；把已失效《合同法》《物权法》写入结论；把商品房预售或存量房过户规则硬套本类型。

## 1. 触发、单方立场与成果状态

立场（买方／卖方）、授权、签署状态、主要目标。商品房／二手房稿、承揽稿、经销主文件或其他负触发写路由，不启动实体审查。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》《物权法》及其解释时记噪声，不得写入 `L#`。返回商品房预售或存量房过户专属规则时标明“不适用本类型”，不得写入默认法。

## 3. 类型与加载路径

父级 `买卖合同`，子级 `动产买卖合同`。写定性理由和与商品房／二手房／承揽／经销／让与担保的切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。禁止流通或通谋虚假写停笔告知，不填可履行规避结构。

## 4. 主体、授权、资质与文本版本

主体表：签约名、履行名、发货名、收货名、付款名、发票名、授权签字人。特殊动产写许可或登记名义人。版本表：正文、附件清单、技术规格、订单、样板确认、聊天确认；冲突并列，不选对用户有利的一版。

## 5. 给付闭环（本类型必填）

固定检查并回链文本：

- 标的名称、规格型号、数量、计量单位、品牌／批次是否确定到可履行；
- 质量标准（国标／行标／企标／样品／技术协议）及正说反说；
- 权利负担：查封、抵押、质押；材料未提不得写“无权利负担”；
- 交付地点、方式、风险转移时点；签收与验收是否切开；
- 检验期间：外观／隐蔽瑕疵分列，异议通知方式和逾期效果；
- 随附单证清单及缺证时的拒付或补交；
- 价金构成（是否含税、运、保、包装、安装）、支付节点、发票；
- 定金用语与是否超过主合同标的额百分之二十；
- 如有所有权保留：登记、取回、百分之七十五、回赎清算。

缺口标 `G#`，不补商业数字。批准、许可、特殊动产登记写成义务或条件，不写成已经完成。

## 6. 格式条款与强制规范

是否构成格式条款（含卖方制式采购／供货文本）；提示说明痕迹。强制规范只区分是否导致民事行为无效与是否仅造成履行障碍（许可、登记、检验检疫）。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。硬闸六项若文本触及或买方立场下原文沉默，必须各有至少一行，不得用色块代替。

## 8. 修改句

按框架六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点、不接受时的红线。未给出的商业数字用 `【待填】`。禁止只给原则、不给句子。禁止输出商品房面积误差百分之三公式或户口／网签过户句充当修改句。

## 9. 谈判与签署提醒

谈判顺序：先红线（标的无法特定、禁止流通、检验期过短吞没隐蔽瑕疵、场外大额定金），再必须改（单证、风险时点、所有权保留登记、发票），最后可优化。签署提醒：授权与用印、骑缝、日期不得倒签、附件清单与订单确认方式、特殊动产登记办理人。不指导倒签或补假合格证。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本任务成果是审查意见与修改句，不是整份起草终稿。无文本或要出己方稿转 `动产买卖合同·起草`。不是履约交底、争议文书、报关商检代办或效力保证。
