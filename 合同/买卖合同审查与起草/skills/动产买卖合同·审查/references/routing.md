# 边界与路由

本技能只审查 **买卖合同 / 动产买卖合同**。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 商品房预售、开发商现售、预售许可证、五证、未建成房屋 | `一般商品房买卖合同·审查` |
| 二手房／存量房、不动产单元号、网签过户、户口迁出 | `二手房买卖·审查` |
| 经济适用房、已购公房上市限制 | `经济适用房买卖合同·审查` |
| 共有产权住房 | `共有产权住房买卖合同·审查` |
| 名为买卖实为房产担保回购 | `让与担保式房产买卖·审查` |
| 以房抵债、工抵房 | `以房抵债工抵房·审查` |
| 主给付为区域经销、独家转售、渠道指标 | `经销买卖合同·审查` |
| 按定作人要求制作、重劳务过程、材料由定作人提供 | 承揽场景原子或引擎重新定性 |
| 无文本、本类型条件已谈妥，要出己方稿 | `动产买卖合同·起草`；不得在本审查原子出稿 |
| 已签未争、发货／验收／付款留痕 | 本套导航的履约步骤 |
| 已成争（质量异议逾期、催告、解除、索赔、立案、仲裁） | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。

本技能不得转去加载商品房或存量房双文件完成本类型审查。不动产买卖文本一旦出现，立即负触发，不得删掉房屋条款后继续当货物买卖审。
