# 输出合同

正触发固定十节，除安全整体停止外不得省略。负触发只写触发判定、路由和最小交接，不填十节实体结论。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。正触发成果状态只用 `已形成`、`部分形成并明确受限字段`、`因停止条件未形成`。

禁止：只打红黄绿不给修改句；保证有效、必然过户、必然转商或对方接受；编造未给出的房价、面积、土地收益比例；把已失效《合同法》《物权法》写入结论；把商品房五证、预售许可或面积误差百分之三硬套本类型；把有限产权改写成按份共有。

## 1. 触发、单方立场与成果状态

立场（申购人／配售方／已购再转让的买或卖）、授权、签署状态、主要目标、首次申购或已购再转让。商品房五证稿、共有产权稿、已转商普通二手或已过户求解除等负触发写路由，不启动实体审查。

## 2. 来源登记与 MCP 调用表

`S/D/A/C/L/I/G`。MCP 未调用也留一行状态：`not-registered` / `permission-denied` / `error` / `no-result` / `partial` / `conflict` / `verified-result`。`search_law` 返回已失效《合同法》《物权法》及其解释时记噪声，不得写入 `L#`。返回商品房预售或五证专属规则时标明“不适用本类型”，不得写入默认法。部门规章不得直接写入“必然无效”。

## 3. 类型与加载路径

父级 `买卖合同`，子级 `经济适用房买卖合同`。写定性理由和与商品房／共有产权／普通二手房／让与担保／中介的切开结果。加载路径必须写成：`references/基本面.md` 与 `references/框架.md`。写明只读这一对、未通读其他类型。转让指标、借名、规避限购或未满五年私下流转写停笔告知，不填可履行规避结构。

## 4. 主体、授权、资格人与文本版本

主体表：出卖人、买受人、共同申请人、收款名、配偶或其他共有人、受托人、住房保障部门文件号。版本表：正文、补充协议、装修／车位协议、网签稿、核准通知；价格冲突按价外加价处理，不选对用户有利的一版。

## 5. 给付闭环（本类型必填）

固定检查并回链文本：

- 准购／核准文件是否在有效期、姓名与面积是否覆盖拟购房屋；
- 有限产权、划拨用地是否写明，有无被改成完全产权或按份共有；
- 政府公布价与合同价是否一致；有无价外加价；
- 五年起算文件、不满五年是否只保留政府回购；满五年土地收益承担人、基数、比例和优先购买征询；
- 骗购收回、违规出租或处分、抵押用途限制；
- 备案／保障审核、缴税、转移登记的义务主体和未完成后果；
- 超标面积补差、贷款未批或资格被取消时的退出。

缺口标 `G#`，不补商业数字或地方补缴比例。备案、登记写成义务或条件，不写成已经完成。

## 6. 格式条款与强制规范

是否构成格式条款（含保障房示范文本填充）；提示说明痕迹。强制规范只区分是否导致民事行为无效与是否仅造成履行障碍或行政收回。无 `search_law` 引文则本节点法律结论字段停止，事实摘录继续。不得把部门规章五年限制直接写成合同必然无效。

## 7. 风险表（必须回链文本位置）

固定列：`编号｜文本位置｜原文摘录｜问题｜判断｜级别｜修改句或红线｜来源｜最强反方`。

级别只用 `红线`、`必须改`、`可接受可优化`。每一行必须有修改句或明确停笔／转出口径。硬闸六项若文本或事实触及或沉默，必须各有至少一行，不得用色块代替。

## 8. 修改句

按框架六步组织：首部、交易条款、配套、尾部、语言、常见问题。每条含：定位、原句、建议句、理由、可退让点、不接受时的红线。未给出的商业数字用 `【待填】`。禁止只给原则、不给句子。禁止输出商品房面积误差百分之三公式或五证补证路径充当修改句。禁止输出可履行的指标转让或借名安排。

## 9. 谈判与签署提醒

谈判顺序：先红线（无资格、未满五年对第三人转让、价外加价、转让指标），再必须改（五年起算、土地收益、骗购收回、备案），最后可优化。签署提醒：共同申请人到场或核验授权、核准通知原件、用印、日期不得倒签、附件清单、住房保障部门征询回证。不指导倒签或补假核准。

## 10. 缺口、停止项与提示

`G#`、字段停止、整体停止、转介。本任务成果是可编辑草稿、未决项、自审风险表和自审后修改句。有完整待签文本要评改转 `经济适用房买卖合同·审查`。草稿必须落入本类型起草必写 / 附件必附 / 禁止出现。不是履约交底、争议文书、转商代办或效力保证。
