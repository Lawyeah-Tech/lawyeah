# 边界与路由

本技能只审查 **买卖合同 / 经济适用房买卖合同**。

| 主要目标或文本信号 | 路由 |
| --- | --- |
| 类型未定或名实明显不符 | 本套导航的类型切开步骤 |
| 商品房预售、开发商市场价现售、预售许可证、五证主路径、面积误差百分之三、无准购资格 | `一般商品房买卖合同·审查` |
| 政府与买受人按份共有、权证载明份额比例 | `共有产权住房买卖合同·审查` |
| 已转商并取得完全产权后的普通存量交易，不再受保障房处分限制 | `二手房买卖·审查` |
| 权证仍为经适房／有限产权／划拨，个人卖方再转让 | **留本技能**；禁止因已办证改走存量商品房 |
| 名为买卖实为担保回购 | `让与担保式房产买卖·审查` |
| 以房抵债、工抵房 | `以房抵债工抵房·审查` |
| 主给付为居间、带看、独家委托 | `存量房买卖或租赁居间带看二手房→` |
| 廉租住房、公共租赁住房 | 转出租赁／保障专项；不审本类型 |
| 有完整待签文本要评改 | `经济适用房买卖合同·审查` | 在本起草原子做签前评改 |
| 无文本、本类型条件已谈妥，要出己方稿 | 留本任务起草并自审 |
| 已签未争、履约节点 | 本套导航的履约步骤 |
| 已完成转移登记仍要解除、退房、索赔 | 合同争议或房屋专项；不填签前十节 |
| 已成争（催告、立案、仲裁） | `或对应专项领域。` 或对应专项领域 |
| C 端大众快检 | 只分流，不回改、不引用其目录 |

专业版未收录的 P1 场景不会安装本原子。若用户拿 P1 文本来找专业版：输出 `unavailable`，提示，不得用邻类硬套。

本技能不得转去加载商品房双文件、共有产权双文件或存量房双文件完成本类型审查。
