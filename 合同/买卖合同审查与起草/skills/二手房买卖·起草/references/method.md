# 审查方法（锁定 买卖合同 / 二手房（存量房）买卖合同）

本技能不得改换类型。只加载同目录 `基本面.md` 与 `框架.md`。禁止通读其他类型，禁止打开商品房、经适房、共有产权或其他子目录“对照一下”。

本文件是存量房签前判断节点，不是栏目说明书，也不是商品房预售审查清单。禁止把预售许可证、五证、竣工验收备案、面积误差百分之三、销售广告视为要约、逾期办证九十日等开发商销售规则写入本类型结论。

每个会改变放行、修改句或转出结论的节点，必须回链来源编号、规则核验状态、最强反方和停止条件。

判断只用 `现有依据支持`、`现有依据不支持`、`依据不足，无法形成结论`。不得输出必然有效、必然无效、必然过户、户口必然迁出、对方必然接受或唯一必得差价。

`search_law` 返回已失效《合同法》《物权法》及其解释、担保法解释或涉外经济合同法时记为噪声，不得写入 `L#`。返回 1994 年《城市房地产管理法》第 38 条旧义（出让投资百分之二十五）时，改走 2019 修正第 38 条“不得转让”清单。MCP 效力字段与有权机关公布的施行日冲突时，以施行日为准并记录冲突。

示范文本只参考结构。住建存量房示范文本或网签文本不证明本约条款已被接受；符合格式条款定义的，仍按格式条款审查。

### 双文件使用（标题对调时不拒跑）

同目录两份知识文件存在文件名与标题不完全对应的情况。按标题语义使用，不回改正文，不因文件名拒跑：

- 含“首部 / 微观 / 条款审查 / 语言分析”的当框架级条款清单，供节点 8 出句；
- 宏观的类型切开、主体、权属负担、程序顺序、结构红旗由本方法节点承担。
- 文件不可用（空、代码块、与存量房明显无关）：记 `G#`，用本方法节点继续，不得改去加载商品房双文件，不得编造地方监管阈值。

先于类型识别。命中任一项则本任务不填十节实体结论，只交付分流理由和最小交接。

| 已能支持的事实 | 走向 | 不得写成 |
| --- | --- | --- |

## 节点 1　类型识别与预售负触发

### 1.1 本类型正像

同时满足才继续：

- 标的是已建成房屋（含已登记的住宅、公寓、配套车位储藏室等随房权利）；
- 核心给付是出卖人转移房屋所有权、买受人支付价款；
- 出卖人是登记权利人或其代理人，**不是**以商品房预售许可对外销售的房地产开发企业项目销售。

标题写成“房屋买卖协议”“存量房买卖合同”“二手房买卖合同”只是线索。名实不符按核心给付归类，标题冲突写入 `C#`。

### 1.2 必须切开（禁止两套知识）

| 信号 | 归入 | 本技能动作 |
| --- | --- | --- |
| 预售许可证、商品房预售合同、楼栋施工中、五证、出卖人为开发企业销售期房或待售现房 | 一般商品房买卖 | **负触发** → `一般商品房买卖合同·审查`。不得用本方法出实体结论 |
| 经济适用房、已购公房上市限制、补缴土地收益后才能上市 | 经济适用房买卖 | 负触发 → `经济适用房买卖合同·审查` |
| 政府与买受人按份共有、再上市封闭管理 | 共有产权住房 | 负触发 → `共有产权住房买卖合同·审查` |
| 名为买卖、实为借款担保，约定回购或不转移占有 | 让与担保式房产买卖 | 负触发 → `让与担保式房产买卖·审查` |
| 以房抵工程款或抵债，无真实房价磋商 | 以房抵债 | 负触发 → `以房抵债工抵房·审查` |

| 农村宅基地房屋、集体建设用地上房屋向本集体以外转让 | 不适用本类型 | 字段停止并转出，不按城镇存量房出过户修改句 |

预售稿误入是硬闸：一旦出现预售许可或开发商期房销售条款，立即停笔转出。不得删掉预售条款后继续当存量房审。

只打开本目录 `基本面.md` 与 `框架.md`。禁止读 `types/` 或其他场景原子目录。

### 1.4 违法结构停笔（本类型，不是施工挂靠）

出现下列任一结构，只出告知，不改写成可履行文本：

- 两套价格、阴阳合同、虚低网签价避税或虚高套贷；

- 明知查封或权属争议，要求写“照常过户”路径；
- 倒签合同日期以改变计税或限购时点。

用户坚持“改到能签／能避税／能过限购”：整体停止。合规改道（真实补税、真实具备资格后再签、解封后再交易）只点名，不在本任务起草规避方案。

## 硬闸 A　权属与抵押、查封、居住权

本闸改变能否放行。材料未提及不得写成“无权利负担”，只能写 `依据不足`。

1. **权属确定性**  
   坐落、不动产单元号或权证号、面积、用途、土地性质（出让／划拨）、权利人姓名必须与用户材料中的权证或登记簿摘录逐项对照。不一致并列 `D#`／`C#`，修改句要求以登记簿为准并作为附件。  
   未依法登记领取权属证书：按城市房地产管理法 2019 修正第 38 条标红线；暂未取证的存量交易须写清取证条件、预告登记和解除权，不得假装可以立即转移登记。

2. **登记簿优先**  
   权属证书与登记簿不一致，除有证据证明登记簿错误外，以登记簿为准。口头“证在我手里”不得写成已核对负担。

3. **抵押**  
   民法典第 406 条：抵押期间可以转让，抵押权不受影响，另有约定除外。  
   **不得写成“有抵押则买卖合同无效”。**  
   实务红线是：未注销抵押通常无法完成买受人过户。修改句必须锁定：欠款余额查询时点、赎楼或卖方自行解押的期限、资金来源（监管账户内闭环还是担保赎楼）、注销抵押登记的责任人、逾期未解押的解除权和违约金。抵押权人不同意或银行还款路径不明：该过户字段停止。

4. **查封、预查封、冻结**  
   司法机关或行政机关依法查封或以其他形式限制房地产权利的，不得转让。修改句不得设计“先过户再解封”。已有查封：红线；建议解封并出具登记簿清册后再签，或整体不签。用户要求掩盖查封：整体停止。

5. **居住权、预告登记、异议登记**  
   居住权自登记时设立；过户不消灭他人居住权。存在居住权登记：约定先注销再付尾款或拒绝签署。存在他人预告登记：未经该权利人同意的处分不发生物权效力。

6. **一房二卖风险**  
   修改句把网签、过户递件日期和“过户前不得再处分”写成出卖人义务；买方立场可要求办理预告登记。不得把网签写成已经取得物权。

核验失败：负担状态字段停止，事实摘录和修改句草稿继续。

## 硬闸 B　共有人与配偶

1. 建主体表：登记权利人、签约人、收款人、实际占有人、配偶、其他共有人、受托人。名称不一致不自动合并。
2. 处分共同共有不动产须全体共同共有人同意；按份共有处分一般须占份额三分之二以上，另有约定除外。转移登记申请规则与此对齐。
3. 房屋为夫妻共同财产时，即使登记在一方名下，仍应取得配偶签字或独立的书面同意，并作为附件。口头“我爱人没意见”不得写成已授权。
4. 最强反方：无权处分并不当然使买卖合同无效；买受人可主张解除和违约责任；已登记且符合善意取得要件时，配偶可能无法追回房屋。  
   **签前不得假设买受人已经善意取得。** 未闭合则签署能力字段停止，不写“可以盖章”。
5. 承租人：出租人出卖租赁房屋应在合理期限通知；承租人同等条件优先购买，但房屋按份共有人行使优先购买或出卖给近亲属等除外。未通知的，承租人可索赔，**买卖合同效力不受影响**。修改句仍应索取弃权声明或通知回证，避免履行障碍，不得写成“无弃权则合同无效”。
6. 国资、集体、未成年人财产：内部决议或监护人处分手续未附则字段停止。

## 硬闸 C　户口约定

户口不是物权内容。未迁出户口不导致转移登记当然无效，也不等于买受人已取得占有。

1. 查明：谁的户口在册（出卖人、亲属、案外人）、迁出截止日期、迁往何处是否已知、是否以户口入学或资格挂钩。
2. 修改句最低配置：  
   - 正说：出卖人应于过户后【待填】日内将全部户口迁出并注销在册记录；  
   - 反说：逾期按日计付违约金；并可预留户口保证金，迁出并核验后再付。
3. **不得承诺**公安机关、学校或法院必然迁出。行政强制迁户另有程序，本任务不写“判决后一定迁走”。
4. 用户承认户口无法迁出仍要买：作为对用户不利事实写入风险表，标红线或必须改；可以谈降价、保证金或接受占用，但须明示入学、积分、再交易可能受影响。不得把该不利事实改写成“无影响”。
5. 材料未提户口：买方立场仍须补条款；卖方立场须披露在册人员，拒绝披露则字段停止。

## 硬闸 D　资金监管、过户与交房顺序

存量房的核心矛盾是付款安全与权属登记的时间差。

1. **三件事拆开写，禁止互相替代**  
   | 行为 | 法律效果 | 不得写成 |
   | --- | --- | --- |
   | 网签／备案 | 交易信息报送，通常不变动物权 | 已经过户 |
   | 转移登记记载于登记簿 | 物权变动 | 交钥匙即完成 |
   | 交房（钥匙、物业交接单、腾空） | 占有移转 | 已经取得所有权 |

2. **付款节点**必须挂在可核验条件上，例如：解押完成、网签完成、转移登记完成、交房腾空。禁止“签约当日首付款直接转入出卖人个人账户且无监管、无解约退款路径”。
3. **资金监管**：大额房款（首付款、尾款、贷款放款）优先约定存入房屋所在地政府指定监管账户或银行托管。监管账户名称、开户行、释放条件（凭转移登记结果或双方确认）必须写清。地方有强制监管而文本约定场外支付：必须改。地方规则未核验：字段停止，仍给出监管账户修改句草稿。
4. **买方贷款**：写明申贷期限、未获批时是补足现金、延期还是解除及已付款返还。不得把“贷款办不下来视为买方违约且定金没收”一笔带过而不给合理例外。
5. **交房**：以书面交接单为准；交房前的水电气暖物业费由出卖人结清；附属设施按列举清单移交。交房与过户谁先谁后必须选定，并写未按序履行的中止付款或解除权。
6. 禁止不动产所有权保留约定充作物权安排（买卖合同解释第 25 条方向）。安全应用债权：监管、预告登记、解约返还，而不是“登记前所有权仍归卖方所以买方已付款无风险”。

用户要求绕开监管、场外大额现金交割以规避限购或信贷：整体停止。

## 硬闸 E　阴阳合同与税费承担

### E.1 阴阳合同

1. 比对正文成交价、付款附表、网签稿、居间确认书、聊天记录。出现两套价格或“网签价另定、差额现金补”：并列版本，标红线。
2. 民法典第 146 条及合同编通则解释第 14 条：以虚假意思表示订立的合同无效；隐藏行为另按强制规范和批准规定处理。
3. **本任务动作**：要求单一真实成交价；网签价与本约一致；因申报不实导致的补税、滞纳金、罚款和过户延误由责任方承担。  
   **禁止**：设计低价网签、补差价收条、阴阳两套文本“更安全”的改法。用户坚持避税结构：整体停止。

### E.2 税费

1. 逐项列明：契税、增值税及附加、个人所得税、印花税（如适用）、土地出让金或土地收益（划拨地）、中介费。未给税率写 `【待填】`，不估算一个“大概几万”。
2. 契税法定纳税人是权属承受方。当事人可约定由另一方负担税款，该约定只约束内部，不能对抗税务机关；修改句写清“对外缴纳义务人”和“对内承担人”。
3. “卖方净到手价”必须穷尽买方代为承担的税种；新增税种或核定征收时如何分担要有规则。计税依据是合同成交价格；明显偏低且无正当理由的，税务机关可以核定——这与阴阳合同风险重叠。
4. 倒签日期以适用旧税率或满五唯一：拒绝，整体停止该部分。

## 节点 2　标的范围与质量告知

1. 房屋本身之外是否包含车位、储藏室、阁楼；有独立权证的应分列过户。
2. 附属设施用附件列举，禁止“现状交付”而无清单。
3. 出卖人告知：渗漏、改建、邻里纠纷、非正常死亡、市政规划已知信息。未写告知与不实告知的解约／索赔后果：必须改。
4. 面积以登记簿记载为准。**禁止**套用商品房销售面积误差百分之三的法定结算和退房公式。当事人可自行约定误差处理，但须是本约合意，不得写成“依法按 3%”。
5. 划拨土地：补缴土地出让金的义务人、金额确定方式、未补缴则无法过户的解除权。

## 节点 3　对价、定金、意向金

1. 总价、定金、首付、贷款、尾款、户口保证金、监管释放款分列。数字未给用 `【待填】`。
2. 必须使用“定金”二字才讨论罚则。居间阶段“意向金、订金、诚意金”无定金性质约定的，不得写成双倍返还。转化须有书面时点。
3. 定金超过主合同标的额百分之二十：超过部分不产生定金效力。无核验引文不得把 20% 写成已核验结论，但修改句仍应把约定压到不超过 20% 或改为预付款。
4. 禁止编造房价、利率、税率。

## 节点 4　程序与生效

把网签、解押、缴税、转移登记、交房写成**义务和期限**，不写成已经完成。

| 文本写法 | 本任务动作 |
| --- | --- |
| “本合同签字即生效，房屋归买方所有” | 拆成合同生效 vs 物权变动；物权自登记簿记载时发生 |
| “网签后生效”但无谁负责、几日内、未完成后果 | 补主体、期限、未完成则解除或中止付款 |
| 限购资格作为履行条件 | 写成买受人承诺具备资格；政策变化导致无法网签时的解除和返还，不默认买方一定违约 |
| 用户要求倒签或补假网签、假完税 | 整体停止 |

不得把“双方同意视为已过户／已批准”写成可放行结构。

## 节点 5　格式条款、强制规范、限购

运行时核验后再落法律结论。核验失败：摘录条款继续，法律结论字段停止。

### 5.1 格式条款

中介或交易中心提供的重复使用文本、政府示范文本填充版，仍可能构成格式条款。示范文本不当然排除审查。审查免责、单方解约、定金没收、管辖、最终解释权是否有显著提示。仅电子勾选不足。未提示的后果是相对方可主张不成为合同内容，不是自动帮用户改成无效判决。

### 5.2 强制规范

违反法律、行政法规强制性规定不一律无效。区分规范目的是否导致民事行为无效、是否只规制履行或行政管理。禁止用已失效“效力性／管理性”口诀。限购、网签、资金监管多为调控或管理规范：合同可能仍成立，但无法网签或过户构成履行障碍——用解除、返还和责任分担修改句处理，不轻易写“限购导致合同无效”。

规避限购只告知，不写假资格、假社保、假离婚路径。

## 节点 6　违约、解除、争议解决

1. 逾期付款、逾期解押、逾期过户、逾期交房、逾期迁户必须分别有日违约金或固定金额，以及达到【待填】日的解除权。只有“依法承担违约责任”视为必须改。
2. 一房二卖或过户前再处分：买方立场修改句应包含已付款返还、定金罚则（如适用）以及房价上涨差价损失（可得利益）的请求基础。差价不是本任务精算的必得金额。
3. 构成违约不等于当然解除。法定解除只点名催告或目的不能实现，不在本任务作出已解除结论。
4. 违约金避免“不得调整”或“按总价百分之三十必得”。
5. 争议解决：  
   - 已有仲裁条款，不得改成“应向某法院起诉”并假装已选定诉讼；  
   - 或裁或诉、机构不明：改成单一仲裁机构或单一法院连结点；  
   - **不得**把普通存量房买卖写成“依法由房屋所在地法院专属管辖”。不动产专属管辖主要针对物权确认、分割、相邻等；政策性房屋买卖才按不动产纠纷确定管辖。当事人可协议选择与争议有实际联系的地点，房屋所在地可作为约定连结点，但须写成约定而不是“法定专属”。
6. 微信已读不写成已经送达，除非合同把该渠道定为送达。

## 节点 7　借名、未成年、跨境及其他结构

1. 出资人与签约／网签人不一致：标红旗。本任务不起草借名买房协议，不把借名改成可对抗登记权利人的结构。用户要借名规避限购：停笔告知。
2. 未成年人作为买受人或出卖人：监护人处分手续未附则字段停止。
3. 涉外主体或境外付款：准据法不明则停止外国法结论；本类型只审中国大陆登记和人民币价款安排。

## 节点 8　按框架六步出修改句

本节点是成果闸。没有修改句或红线，不得宣称审查完成。禁止只打红黄绿。

对照已加载框架级文件和本方法硬闸，按六步逐段出句。

| 步 | 存量房必须盯的点 | 必须产出 |
| --- | --- | --- |
| 首部 | 标题名实；产权人与配偶／共有人；鉴于只描述权属现状，不把过户写成已完成 | 主体与鉴于修改句 |
| 交易条款 | 坐落面积与登记簿一致；价款单一；监管账户；解押→网签→缴税→过户→交房顺序；附属设施清单 | 闭环修改句；缺数字用 `【待填】` |
| 配套 | 逾期解押／过户／迁户违约金；一房二卖差价；户口保证金；限购或贷款未批的解除返还 | 可执行后果句 |
| 尾部 | 全体产权人及配偶签署；附件：权证、登记簿、配偶同意、弃权声明、设施清单、监管协议 | 生效与附件修改句 |
| 语言 | 正说加反说；定金／订金／意向金；净到手价；网签≠过户≠交房 | 替换空词的句子 |
| 常见问题 | 抵押／查封、阴阳合同、暂未取证、划拨补地价、居住权 | 结构级改法或红线 |

每条修改句固定格式：

`定位（条/款/附件）｜原文｜建议改为｜理由（回链 C# / L# / I#）｜可退让点｜不接受时的红线`

风险表每一行必须能指回上述某条修改句。级别：

- `红线`：不改则建议不签或整体停止（查封、阴阳合同、共有人拒签、无监管的大额场外支付）；
- `必须改`：可谈但签署前要落句（户口、解押时限、税费清单、交房标准）；
- `可接受可优化`：仍要给句子，不得只标绿。

用户不可接受事项优先写成红线。生存级首付或个人无限连带且用户拒绝升级：停止“可以签署”建议。
