# 刑事辩护与刑事代理体系

`conduct-criminal-defense` 面向中国大陆刑事事项中的被追诉方、被害方、控告人、拟委托人及其依法适格的代理人。当前公开版本由一个能力导航 Skill 和 13 个相互独立的 P0 原子 Skill 组成。

## 能力模型

刑事领域按三个维度识别原子能力：

1. **角色与代理立场**：被追诉方、被害方、控告人、自诉人、拟委托关系或依法履职的律师；
2. **程序状态**：接案紧急入口、报案控告与立案、侦查、审查逮捕、审查起诉、审判、上诉及其他法定程序；
3. **独立专业成果**：筛查结论、行动方案、会见成果、申请、证据体系、辩护或代理意见、材料包和救济评估。

原子 Skill 由一个完整用户目标和一个可独立验收成果决定，不按单个法条、文书段落或内部工作步骤拆分。相似 Skill 各自保留完整的角色、程序、证据、期限、安全和输出合同。

## 运行关系

- 领域总 Skill 只说明能力、边界并帮助定位，不是强制入口；
- 每个原子 Skill 可以直接触发，当前 13 个原子 Skill 均无固定 `depends-on`；
- 接案资格与冲突筛查是一项独立法律业务成果，不被设置为其他 Skill 的技术总开关；
- 其他律师、机关、用户或其他 Skill 提供的合格等价成果可以作为输入；
- 不建设固定组合模板，也不根据诉讼时间线强制调用顺序。

## 风险控制

刑事成果可能影响人身自由、刑事责任、法定期限、重大财产或不可逆程序行动。原子 Skill 因此分别设置：

- 身份、授权、利益冲突、角色、程序状态、承办机关和关键日期门禁；
- 事实来源、材料回链、反向证据和规则引文要求；
- 即时人身危险、医疗、自伤、失踪和脆弱人员安全分流；
- 串供、毁证、伪造、冒充、非法取证、威胁证人和泄密拒绝规则；
- 工具不可用、无结果、冲突或关键事实缺失时的停止形状；
- 涉及法律结论、期限、机关路径或对外文书时的专业人员复核要求。

## 跨领域边界

- 企业合规：具体案件的刑事控告、辩护和刑事责任归刑事；以预防整改和治理为目标的内部调查归企业合规。
- 行政争议：刑事强制措施和侦查行为归刑事；行政处罚、许可、行政强制及其复议诉讼归行政。
- 劳动用工：刑事责任和刑事程序归刑事；员工调查、处分、解除及其他用工后果归劳动。
- 人身损害：被害人刑事程序权利归刑事；脱离刑事程序的一般侵权责任和完整赔偿诉讼归人身损害。
- 数据隐私：个案电子数据的刑事证据审查归刑事；数据处理合法性和数据治理归数据隐私。
- 涉外：本包仅处理中国大陆刑事案件；境外当地刑事法和跨法域监管成果另行处理。

同一事实需要多个独立专业成果时分别交由相应领域，不在刑事 Skill 中补造其他领域结论。

## 工具边界

Skill 只在具体判断节点使用稳定命名的标准 MCP 或宿主工具引用。工具增强不保存端点、凭证、用户 ID 或内部集合信息；授权由宿主和对应服务管理。发布阶段核验工具名称、用途、最小输入、结果使用、隐私和不可用行为，不要求真实 MCP 联调或客户数据验收。
