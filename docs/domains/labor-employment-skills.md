# 劳动用工与劳动争议 Skill 路线图

本文件列出 `handle-labor-employment` 的候选原子 Skill 全景和建设优先级。它是能力路线图，不是安装清单、固定组合方案或调用顺序；所有候选在进入领域 Pack 前仍需逐项完成方法研究、测试、专家评审和发布准入。

## 组织原则

- 一个原子 Skill 对应一个真实用户目标和一项可独立验收的专业成果；
- 不按法条、案由、文书名称或单个工作步骤机械拆分；
- 同时覆盖单位与劳动者，但只在事实权限、程序权利、最终行动或不可逆风险实质不同的时候按立场拆分；
- 每个原子 Skill 自包含，默认无固定依赖；其他 Skill、律师、机关或用户提供的等价成果都可以成为输入；
- `P0/P1/P2` 表示建设顺序，不表示法律重要性，也不构成安装子包；
- 劳动领域总 Guide 将独立建设，用于说明能力全貌、触发边界和选择入口，不计入下列原子 Skill 数量。

## 当前数量

- 原子 Skill 候选：85；
- P0：10；
- P1：45；
- P2：30；
- 领域总 Guide：1 个独立导航 Skill，不属于原子 Skill。

数量不是最终发布承诺。任何候选在真实任务中持续表现为同一成果、同一风险和同一输出合同时可以合并；出现独立权限、程序地位、不可逆行动或稳定成果差异时应重新拆分评审。
