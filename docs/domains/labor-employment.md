# 劳动用工与劳动争议体系

本文件是 `handle-labor-employment` 的体系层定义。它已经完成劳动非诉、劳动争议和 Skill 架构三个独立专家角色的多轮阻断评审，可作为原子 Skill 清单设计的基线，但本身不是原子 Skill 清单或固定执行方案。

候选原子能力及建设优先级见[劳动用工与劳动争议 Skill 路线图](labor-employment-skills.md)。

## 体系结论

劳动领域不能仅按“用工治理 / 劳动争议”二分，也不能按工资、社保、解除等法律名词直接建立 Skill。

正式能力模型采用三个分类维度：

1. **业务事项**：用户正在处理哪一种劳动用工关系、人员事件或程序；
2. **专业成果**：用户当前需要评估、测算、文件、实施、谈判、行政办理、程序代理还是执行成果；
3. **上下文参数**：使用者和代理立场、程序阶段、地区、主体类型、行业以及已有材料。

原子 Skill 由一个完整用户目标和一个可独立验收成果决定，不对三维矩阵的每个单元机械建 Skill。

“流程 Skill / 场景知识 Skill”只作为原子 Skill 内部的方法设计视角。当前仓库以自包含原子 Skill 为准，不建设跨领域共享的运行时知识 Skill，也不建立固定组合方案。

## 导航视图

以下视图帮助理解能力全貌，但不是安装子包、Skill ID 前缀或调用顺序：

- 常态用工治理与体系建设；
- 专项人员事件、组织变更与行政办理；
- 集体劳动关系与群体事项；
- 争议评估、协商、仲裁诉讼和权利实现。

混合任务直接按主要目标和最终成果选择原子 Skill，不要求先经过某个导航视图。

## 必须独立审查的程序结构

### 工伤和职业病

至少分别审查：

- 事故响应与工伤认定行政程序；
- 劳动能力鉴定、再次鉴定和复查；
- 工伤待遇、停工留薪、复工安置和待遇争议；
- 工伤行政救济分流、劳动专项实体意见和证据材料，以及第三人侵权竞合中的程序协调。

不得建设一个覆盖全部路径的巨型“工伤 Skill”。

### 社会保险

必须区分：

- 补缴或征缴的行政处理；
- 经办机构登记、核定或拒付待遇的行政救济；
- 无法补办造成的待遇损失或用人单位直接承担待遇的劳动争议。

住房公积金与社会保险分别建模：单位整改、劳动者向住房公积金管理中心提出追缴申请、管理中心处理／拒绝处理／逾期未处理后的劳动专项评估均有独立候选；行政复议诉讼文书和通用程序代理仍转行政争议领域。

### 劳动争议阶段

至少分别审查：

- 争议评估、程序分流和时效期限；
- 协商、调解与和解成果；
- 仲裁申请与仲裁答辩反请求；
- 一审起诉与应诉；
- 二审上诉与应诉；
- 一裁终局下劳动者起诉与用人单位撤裁；
- 保全、先予执行、强制执行和不予执行；
- 再审、检察监督等生效后救济。

庭审提纲、质证意见和代理词通常属于相应阶段成果，不因文书名称不同自动成为原子 Skill。

## 代理立场拆分规则

劳动领域包同时覆盖用人单位、劳动者及其代理人，不按客户身份复制整个体系。

出现以下任一实质差异时，双方立场应拆成不同原子 Skill：

- 可取得的事实和材料权限不同；
- 举证责任、请求、抗辩或程序权利不同；
- 最终行动或不可逆风险不同；
- 谈判利益或调查独立性直接冲突；
- 同一输出合同无法安全复用。

典型需要拆分的事项包括仲裁申请与答辩反请求、解除实施与违法解除救济、竞业追责与劳动者解除限制、工伤申请与单位行政应对、一裁终局起诉与撤裁、执行申请与执行抗辩。

## 跨领域边界

- 合同：劳动合同和用工专项协议归劳动；一般商业外包合同归合同，劳动关系和用工责任仍归劳动。
- 人身损害：工伤认定、鉴定和工伤待遇成果归劳动；第三人侵权责任及侵权赔偿成果归人身损害；竞合案件分别形成专业成果并协调程序。
- 知识产权：竞业限制和劳动关系内保密义务归劳动；商业秘密权利基础、侵权和损失归知识产权。
- 数据隐私：用工目的、劳动程序和劳动法后果的员工信息专项成果归劳动；个人信息处理合法性、影响评估、数据跨境和网络安全专项成果归数据隐私。
- 企业合规：工作场所申诉、公平调查和劳动处分归劳动；企业级舞弊、反商业贿赂和综合整改归企业合规。
- 投资并购：劳动尽调、员工转移和安置专项成果归劳动；交易结构、交割和整体项目归投资并购。
- 破产：职工安置、合同终止和待遇测算归劳动；职工债权申报、确认和分配归破产。
- 行政争议：工伤、社保和劳动监察的分流意见、劳动专项实体条件和证据材料归劳动；行政复议诉讼文书和通用程序代理成果归行政争议。
- 公司治理：高管劳动身份、劳动合同权利和员工激励的劳动后果归劳动；公司职务、股权结构和股东权利归公司治理。
- 税务：薪酬和员工激励的劳动权利及用工后果归劳动；税负、申报和税务争议归税务。
- 涉外：外国人在华用工和中国大陆劳动权益归劳动；境外当地劳动法及跨法域准入监管成果归涉外。
- 刑事：员工涉嫌违法后的劳动调查、处分和用工后果归劳动；刑事控告、辩护和刑事责任归刑事。
- 建设工程：农民工劳动关系、工资和工伤责任归劳动；工程合同、工程价款和施工责任归建设工程。

出现独立专业成果时由相邻领域负责，不在劳动 Skill 内补造结论。

职业危害技术评价、安全生产工程结论和医学诊断不属于劳动法律 Skill，也不强行归入环境能源领域；遇到此类必要前提时停止对应技术结论，要求具有资质的专业机构提供结果后再处理劳动法后果。

## 体系完整性评测

进入原子 Skill 清单前，劳动体系必须证明：

- 业务事项地图中的每一类主要成果有归属或明确排除理由；
- 用人单位侧、劳动者侧、主动救济方和被动应对方均有覆盖；
- 常态治理、专项事件、集体事项、行政程序、仲裁诉讼和执行均有测试；
- 外籍、超龄、平台、派遣、关联企业、职业病接害、女职工特殊期、工会企业、并购和破产场景至少各有边界案例；
- 最低工资、工时休假、医疗期、社保、公积金和待遇等地方参数不足时具有停止条件；
- 与合同、公司治理、数据、知识产权、合规、人身损害、行政、并购、破产、税务、涉外、刑事和建设工程领域均有正例、近似反例和跨领域案例。

## 当前确认状态

本体系模型已通过三个独立 AI 专家角色的结构化评审，并根据异议完成修订：

- 原来的两条主线已经降为导航视角；
- 能力模型改为“业务事项 × 专业成果 × 上下文参数”三个分类维度；
- 增补集体劳动关系、行政型救济、员工数据、招聘权益、工伤分段、社保分流、执行和特殊主体；
- 明确双方立场拆分和跨领域边界。

因此，本文件可以进入候选原子 Skill 任务合同设计。它不等于具体原子 Skill 已通过专业评审；每个原子 Skill 仍须遵守[专家评审治理](../architecture/expert-review.md)，以构造、合成、组合和对抗场景完成测试，并由当前专家组评审收口。
